# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环新一季第 1 轮；本轮灵感：「多端口部署」×「人形机器人」）

> 第 54 轮把技能组合从“能力匹配”推进为“动作-鲁棒性双证书”，并给出云边协同闭环。本轮把“证书到底在哪个身体上成立”摆到第一性问题：**同一个技能或组合方案要部署到多个端口——不同人形本体、不同传感器/执行器接口、不同现场约束、甚至同一台机器人的不同磨损阶段——证书是否仍然成立？** 核心矛盾：H22：第 54 轮的联合证书 `J` 隐含“单一动作空间 + 单一 embodiment”假设，换端口后 `α_S, γ_ce, ρ` 全部失锚，出现“源端口成立、目标端口静默失效”的端口相对性；H23：人形机器人的高自由度、接触切换与平衡约束使动作空间不再是欧氏盒子，而是分层约束流形，普通动作剖面与证书在平衡-接触可行层之外没有物理意义。

## 0. 直觉与动机

**灵感 1（多端口部署 → 证书从“绝对命题”降级为“端口相对命题”）**
直觉：一个技能从来不是在一个万能动作空间里定义的，而是在某个身体上可执行。人形 A（29 DoF、足底摩擦 μ=0.8、力矩裕度 1.3）与人形 B（23 DoF、μ=0.5、裕度 1.0）可以共享语义相同的“搬箱转身”技能，但动作实现、接触调度与失效模式完全不同。因此技能的能力不是 `α_S`，而是 **端口条件剖面 `α_{S|π}` 与端口条件鲁棒性谱 `ρ_{S|π}`**。多端口部署的本质，不是把同一个证书复制 m 份，而是求证书在端口空间 `ℙ` 上的**有效域**：`𝕍(J) = {π ∈ ℙ | J_{S|π} 成立}`。这样，“多端口”同时覆盖“多本体、多现场、多接口、多磨损阶段”四种异构。

**灵感 2（人形机器人 → 动作空间是平衡-接触流形，而非盒子）**
直觉：人形的动作不是任意关节轨迹，而是必须落在**平衡可行层 `B_π`** 上：ZMP 落在支撑多边形内、接触扳手落在摩擦锥内、质心捕获点落在可恢复域内。离开 `B_π` 的动作在仿真里可能“看起来能跑”，在真实人形上直接是跌倒。因此技能剖面要限制在 `B_π` 上，证书必须携带**接触调度 σ** 与**扳手锥裕度 β**，并把“跌倒”提升为独立的失败维度 `d_fall`，而不是塞进原有鲁棒性维度里。

**灵感 3（端口支配格 → 把 m 次重认证压缩为“一次认证 + 支配证明 + 少量复检”）**
直觉：端口之间并非完全无序。若目标端口在任务相关能力上**不弱于**源端口（更大可达域、更高力矩裕度、更保守摩擦假设、更低延迟），则在弱端口上成立的证书可以沿支配关系**单向向上迁移**到强端口。定义偏序 `π_s ⊒ π_t` 与**支配见证 `W_dom`**；这把多端口部署从“每台重新跑完整认证”变成“一次认证 + 格上闭包 + 最小区分动作集复检”。关键是必须证明支配，而不是凭感觉“这台更强”。

**灵感 4（多端口扇出 → 带安全硬约束的预算化最大覆盖）**
直觉：给定一个已认证组合，真正要解的是：在风险预算 `R_max` 与部署预算 `B` 下，选哪个端口子集 `Π` 使任务覆盖最大？风险不是简单相加：端口独立风险之外，还存在**共享策略缺陷**导致的相关失败——同一个视觉捷径或同一条失衡策略可能在 m 个端口同时爆。于是 `R(Π) ≤ Σ_i r_i + κ(Π)·r_shared`。这是“预算化最大覆盖 + 安全硬剪枝”：覆盖目标是子模的、可贪心近似，但安全约束是硬的，绝不能用期望收益换一次真实跌倒。

**灵感 5（端口漂移 → 证书有时效，多端口部署是持续认证）**
直觉：端口会磨损、标定漂移、换负载、换足底。定义**端口指纹 `fp_π`**（关节摩擦、背隙、力矩标度、通信延迟等可辨识参数）。当 `||fp_t - fp_0|| > θ_fp` 时证书失效，必须触发重认证或回滚。多端口部署因此不是一次性发证，而是“指纹监测—漂移定位—局部重认证”的持续过程，否则证书会随磨损一起悄悄过期。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（部署端口）**
部署端口 `π = (E_π, I_π, C_π, Ω_π, fp_π)`，其中：
- `E_π` 为本体（运动学树、自由度 `n_π`、关节限位、质量/惯量、执行器力矩包络）；
- `I_π` 为接口集合（传感器/执行器端口、采样率、通信延迟）；
- `C_π` 为现场上下文（地形、负载、接触面摩擦 `μ_π`）；
- `Ω_π` 为安全包络（速度/力/跌倒限制）；
- `fp_π ∈ ℝ^q` 为端口指纹（摩擦、背隙、力矩标度、延迟等可辨识参数）。
端口空间记为 `ℙ`，一个部署端口既是“一台本体”，也是“一组接口 + 一个现场 + 一个磨损状态”。

**定义 122（端口动作空间与端口投影）**
端口动作空间分解为 `A_π = A_π^bal × A_π^ct × A_π^man`（平衡/接触/操作）。端口投影是部分映射 `φ_{π→π'} : A_π ⇀ A_{π'}`，定义域 `dom(φ)`。投影失真
```
δ_port(φ) = sup_{a ∈ dom(φ)} dist_{π'}(φ(a), a)
```
其中 `dist` 取任务相关度量（末端位姿、接触点、质心轨迹、时序）。**任务覆盖保持**：`φ(A_T^π) ⊇ A_T^{π'}` 且任务语义不变。

**定义 123（端口相对技能证书）**
技能 `S` 在端口 `π` 上的证书
```
J_{S|π} = (π, α_{S|π}, ρ_{S|π}, A_cert, BCert_{S|π}, evidence)
```
其中 `α_{S|π} : A_π → [0,1]`，`ρ_{S|π} : D → [0,1]`，失败维度 `D` 在原有维度外新增 `d_fall`（跌倒）、`d_slip`（接触滑移）、`d_sat`（执行器饱和）。`J_{S|π}` 成立当且仅当 `α, ρ` 在任务动作集 `A_T` 上满足阈值且 `BCert` sound。

**定义 124（人形平衡-接触可行层）**
对全身动作 `a = (q, q̇, σ)`（`σ` 为接触调度），平衡可行 `B_π(a)=1` 当且仅当：
1. ZMP 约束：`p_zmp(a) ∈ P_sup(σ)`，且支撑裕度 `β_zmp(a) ≥ 0`；
2. 扳手锥约束：每个接触 `i` 的扳手 `w_i = (f_i, τ_i) ∈ FC_i(μ_π)`，且扳手裕度 `β_cwc(a) ≥ β_min`；
3. 可恢复约束：捕获点 `ξ(a) = x_com + ẋ_com/ω` 落在可恢复域 `R_rec(σ)` 内，`ω = sqrt(g/z_com)`。
定义平衡可行层 `B_π = {a | B_π(a)=1}`，技能剖面限制为
```
α^B_{S|π}(a) = α_{S|π}(a) · B_π(a)
```
即：**再强的技能，只要动作离开平衡-接触流形，占用度归零。**

**定义 125（平衡-接触证书）**
```
BCert_{S|π} = (σ, β_zmp^min, β_cwc^min, R_rec, W, ε_fall)
```
`W` 为扰动集（推力脉冲、地形高度噪声、负载变化）。BCert sound 当且仅当
```
∀ a ∈ A_T, ∀ w ∈ W : B_π(a; w)=1 ∧ F̂_fall(S, π, W) ≤ ε_fall
```
其中 `F̂_fall` 为在扰动集上的跌倒概率上界估计。BCert 必须随接触调度一起迁移，脱离 `σ` 的平衡证书没有意义。

**定义 126（端口支配与证书迁移方向）**
称 `π_s` 支配 `π_t`，记 `π_s ⊒ π_t`，当且仅当存在投影 `φ_{π_t→π_s}` 与支配见证 `W_dom` 满足：
- (D1) `dom(φ) ⊇ A_T^{π_t}`；
- (D2) `∀ a ∈ A_T^{π_t}: α_{S|π_s}(φ(a)) ≥ α_{S|π_t}(a)`（覆盖不降）；
- (D3) `δ_port(φ) ≤ δ*`；
- (D4) `β_zmp^min(π_s) ≥ β_zmp^min(π_t)` 且 `β_cwc^min(π_s) ≥ β_cwc^min(π_t)`（裕度不降）；
- (D5) `∀ d ∈ D: ρ_{S|π_s}(d) ≥ ρ_{S|π_t}(d)`（鲁棒性不降）。
则证书可**单向向上迁移**：`J_{S|π_t} ∧ (π_s ⊒ π_t) ⇒ J_{S|π_s}`。
方向必须记死：**弱端口成立可推出强端口成立；强端口成立不能反推弱端口。** 支配见证 `W_dom = (φ, D1–D5 的证据)` 本身是证书的一部分，不是口头假设。

**定义 127（端口迁移证书）**
```
PTC(π_tgt | J_src, π_src) = (π_src, π_tgt, φ, W_dom?, δ_port, Δρ, Δβ, fp_drift, decision, evidence)
```
其中 `Δρ = max_d (ρ_{S|π_src}(d) - ρ_{S|π_tgt}(d))`，`Δβ = β^min(π_tgt) - β^min(π_src)`，`fp_drift = ||fp_tgt - fp_src||`。决策 `decision ∈ {in, recheck, out}`：
```
in      ⇐ 覆盖保持 ∧ δ_port ≤ δ* ∧ Δρ ≤ ε_ρ ∧ Δβ ≥ -ε_β ∧ fp_drift ≤ θ_fp
           ∧ (W_dom 有效 ∨ 最小区分动作集复检通过)
recheck ⇐ 指纹漂移可补偿，或仅少数动作越界
out     ⇐ 覆盖丢失 / 失真超界 / 平衡裕度显著下降 / 无法补偿的漂移
```
`recheck` 不跑全量重认证，只在**最小区分动作集** `D_min` 上复检，降低多端口部署成本。

**定义 128（多端口部署证书包与端口扇出）**
部署集合 `Π = {π_1,…,π_m}` 的证书包
```
J_Π = {(π_i, J_{S|π_i}, PTC_i)}_{i=1..m} ∪ (Cov(Π), R(Π), κ(Π), r_shared)
```
其中：
- `Cov(Π) = |(∪_i T_{π_i}) ∩ T_all| / |T_all|` 为任务条件覆盖；
- `r_i = Σ_d (1 - ρ_{S|π_i}(d)) + ε_fall(π_i) + P(δ_port > δ* | π_i)` 为端口独立风险；
- `R(Π) ≤ Σ_i r_i + κ(Π)·r_shared`，`κ(Π) ∈ [0, m-1]` 刻画跨端口共享缺陷的相关放大，`r_shared` 为共享策略缺陷在单端口显形的概率。
`Π` 可部署当且仅当 `∀ i: PTC_i = in` 且 `R(Π) ≤ R_max`。端口扇出问题：
```
Π* = argmax_{Π ⊆ ℙ} Cov(Π)   s.t.  R(Π) ≤ R_max,  |Π| ≤ B,  ∀i PTC_i = in
```

## 2. 关键算法 伪代码

### IP-121 PFP（Port Fingerprinting & Profiling）

```python
def port_fingerprint(port, probes):
    fp = {}
    for j in port.joints:
        resp = port.execute(probes[j])
        fp[j] = estimate_dynamics(resp)   # friction, backlash, torque_scale, latency
    return PortFingerprint(fp, unc=bootstrap_ci(fp))

def fingerprint_drift(pi_a, pi_b, theta_fp):
    d = norm(pi_a.fp.vector - pi_b.fp.vector, weighted=True)
    return d, d > theta_fp
```

### IP-122 BSP（Balance Stratum Projection）

```python
def balance_feasible(a, port, schedule):
    contacts = schedule.contacts(a.t)
    p_zmp = zmp(a, port.mass_model)
    if not in_convex_hull(p_zmp, contacts.support_polygon, margin=port.beta_zmp_min):
        return False, 'zmp'
    w = inverse_dynamics(a, contacts, port)
    beta = wrench_cone_margin(w, contacts, port.mu)
    if beta < port.beta_cwc_min:
        return False, 'wrench_cone'
    xi = capture_point(a, port)
    if xi not in recoverable_region(schedule):
        return False, 'capture_point'
    return True, beta

def balance_stratum(skill, port, A_T, schedule):
    alpha = {}
    for a in A_T:
        ok, beta = balance_feasible(skill.action(a), port, schedule)
        alpha[a] = skill.alpha[a] * (1.0 if ok else 0.0)
    return alpha
```

### IP-123 HBC（Humanoid Balance Certificate）

```python
def balance_certificate(skill, port, schedule, A_T, W, eps_fall):
    bmin = inf
    for a in A_T:
        ok, beta = balance_feasible(skill.action(a), port, schedule)
        if not ok:
            return ('reject', ok, beta)
        bmin = min(bmin, beta)
    fall_bound = disturbed_fall_bound(skill, port, schedule, W)
    if fall_bound > eps_fall:
        return ('reject', 'fall_bound', fall_bound)
    return ('ok', BCert(schedule, bmin, recoverable_region(schedule), W, fall_bound))
```

### IP-124 PTC（Port Transfer Certificate）

```python
def port_transfer_certificate(J_src, pi_src, pi_tgt, phi, theta_fp, eps_rho, eps_beta):
    d, drifted = fingerprint_drift(pi_src, pi_tgt, theta_fp)
    if drifted and not compensable(phi, d):
        return ('recheck', 'fingerprint_drift', d)
    if not task_coverage_preserved(phi, J_src.A_T, pi_tgt):
        return ('out', 'coverage_lost')
    dport = projection_distortion(phi)
    if dport > delta_star:
        return ('out', 'distortion', dport)
    delta_rho = max(J_src.rho[d] - rho_eval(J_src.skill, pi_tgt, d)
                    for d in J_src.rho)
    delta_beta = beta_min(pi_tgt) - beta_min(pi_src)
    if delta_rho > eps_rho or delta_beta < -eps_beta:
        D_min = minimal_distinguishing_set(J_src, pi_src, pi_tgt, phi)
        if not recheck(J_src.skill, pi_tgt, D_min):
            return ('out', 'margin_or_robustness_drop', delta_rho, delta_beta)
        return ('in', PTC(pi_src, pi_tgt, phi, dport, delta_rho, delta_beta,
                          d, mode='recheck_min'))
    if dominates(pi_tgt, pi_src, phi):          # pi_tgt ⊒ pi_src
        return ('in', PTC(pi_src, pi_tgt, phi, dport, delta_rho, delta_beta,
                          d, mode='dominance_shortcut'))
    D_min = minimal_distinguishing_set(J_src, pi_src, pi_tgt, phi)
    if recheck(J_src.skill, pi_tgt, D_min):
        return ('in', PTC(pi_src, pi_tgt, phi, dport, delta_rho, delta_beta,
                          d, mode='recheck_min'))
    return ('out', 'no_transfer')
```

### IP-125 MPF（Multi-Port Fan-out）

```python
def multi_port_fanout(J_src, ports, T_all, R_max, B, kappa, r_shared):
    feasible = []
    for pi in ports:
        ptc = port_transfer_certificate(J_src, J_src.port, pi, phi_for(pi))
        if ptc.decision == 'in':
            feasible.append(PortCandidate(pi, ptc, r_i(pi), cover_set(pi)))
    Pi = []
    while len(Pi) < B and feasible:
        cand = argmax(feasible, key=lambda c: marginal_coverage(c, Pi, T_all))
        if risk_bound(Pi + [cand], kappa, r_shared) > R_max:
            feasible.remove(cand)
            continue
        Pi.append(cand)
    if not Pi:
        return ('fail', 'no_safe_port')
    return ('ok', Pi, coverage(Pi, T_all), risk_bound(Pi, kappa, r_shared))
```

def monitor_port(port, fp0, J, theta_fp, window):
    while port.running:

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| PFP | O(q·T_probe) | O(q) | 探针持续激励、指纹可辨识 |
| BSP | O(|A_T|·(c_contact + c_id)) | O(|A_T|) | ZMP/锥/捕获点判定 sound |
| HBC | O(|A_T|·c_bal + M·c_sim) | O(|A_T|+M) | 扰动集覆盖、跌倒界 sound |
| PTC | O(|A_T|·|φ| + |D|) | O(|A_T|+|D|) | 覆盖保持、失真有界、支配见证有效 |
| MPF | O(m·|A_T| + m·B·|T|) | O(m+|T|) | 子模贪心、安全硬剪枝 |
| PDD | O(q·T_probe) / 窗口 | O(q) | 漂移 > θ_fp 可检出 |

**正确性定理（Multi-Port Humanoid Deployment Soundness）**
承接第 54 轮 (A26)–(A28)，新增假设：
- **(A29)** 端口指纹辨识误差 `≤ ε_fp`，两次认证间漂移 `≤ θ_fp`；
- **(A30)** 端口投影 `φ` 覆盖保持且 `δ_port ≤ δ*`，支配见证 `W_dom` 的 D1–D5 可验证；
- **(A31)** `BCert` 在扰动集 `W` 上 sound，跌倒界关于裕度 `β` 单调；
- **(A32)** 给定端口后各端口独立失败事件条件独立；共享缺陷参量 `r_shared` 与相关放大 `κ(Π)` 有上界。

则对任意 `Π` 且 `∀i: PTC_i = in`：
```
P_fail(Π) ≤ Σ_{π∈Π} [ Σ_{d∈D}(1 - ρ_{S|π}(d)) + ε_fall(π) + P(δ_port > δ* | π) ]
            + κ(Π)·r_shared + P(drift > θ_fp)
```
因此 `P_safe(Π) ≥ 1 - P_fail(Π)`。关键：**端口相对证书先验**、**支配迁移方向正确**、**平衡证书覆盖接触切换瞬态**、**共享故障有相关上界**。

## 4. 实验设计 E162–E166

**实验平台**：MuJoCo + Isaac Lab 双仿真；3 类人形 embodiment（29-DoF / 23-DoF / 19-DoF），2 类地形（平地 / 低摩擦斜坡），3 类负载；真机至少 1 台人形做 sim-to-real 抽检。技能库覆盖行走、转身、搬箱、推门、受击恢复。端口指纹通过正弦关节激励 + 系统辨识获得。

## 6. 本轮最大风险

**一句话**：多端口部署把第 54 轮的“动作-鲁棒性双证书”推广为“端口相对证书包”，人形机器人又把动作空间从欧氏盒子收紧为平衡-接触流形；其 soundness 依赖端口支配关系的可证明性、平衡证书在接触切换处的不破缺、以及跨端口共享故障的相关性上界——一旦端口支配被隐藏耦合（执行器饱和、足底摩擦差异）击穿，或平衡证书在接触切换瞬态失效，扇出到 m 个端口的将不是 m 份安全，而是同一个被放大的系统性跌倒风险，故必须以“能力维度可证明支配 + 接触切换瞬态专项认证 + 相关性上界与灰度扇出”三重护栏，宁可少部署一个端口，也绝不把端口格上的“看起来更强”当作可迁移。

def port_fingerprint(port, probes):
    fp = {}
    for j in port.joints:
        resp = port.execute(probes[j])
        fp[j] = estimate_dynamics(resp)   # friction, backlash, torque_scale, latency
    return PortFingerprint(fp, unc=bootstrap_ci(fp))

def fingerprint_drift(pi_a, pi_b, theta_fp):
    d = norm(pi_a.fp.vector - pi_b.fp.vector, weighted=True)
    return d, d > theta_fp

### IP-122 BSP

```python
def balance_feasible(a, port, schedule):
    contacts = schedule.contacts(a.t)
    p_zmp = zmp(a, port.mass_model)
    if not in_convex_hull(p_zmp, contacts.support_polygon, margin=port.beta_zmp_min):
        return False, 'zmp'
    w = inverse_dynamics(a, contacts, port)
    beta = wrench_cone_margin(w, contacts, port.mu)
    if beta < port.beta_cwc_min:
        return False, 'wrench_cone'
    xi = capture_point(a, port)
    if xi not in recoverable_region(schedule):
        return False, 'capture_point'
    return True, beta

def balance_stratum(skill, port, A_T, schedule):
    alpha = {}
    for a in A_T:
        ok, beta = balance_feasible(skill.action(a), port, schedule)
        alpha[a] = skill.alpha[a] * (1.0 if ok else 0.0)
    return alpha
```

### IP-123 HBC

```python
def balance_certificate(skill, port, schedule, A_T, W, eps_fall):
    bmin = inf
    for a in A_T:
        ok, beta = balance_feasible(skill.action(a), port, schedule)
        if not ok:
            return ('reject', ok, beta)
        bmin = min(bmin, beta)
    fall_bound = disturbed_fall_bound(skill, port, schedule, W)
    if fall_bound > eps_fall:
        return ('reject', 'fall_bound', fall_bound)
    return ('ok', BCert(schedule, bmin, recoverable_region(schedule), W, fall_bound))
```

### IP-124 PTC

```python
def port_transfer_certificate(J_src, pi_src, pi_tgt, phi, theta_fp, eps_rho, eps_beta):
    d, drifted = fingerprint_drift(pi_src, pi_tgt, theta_fp)
    if drifted and not compensable(phi, d):
        return ('recheck', 'fingerprint_drift', d)
    if not task_coverage_preserved(phi, J_src.A_T, pi_tgt):
        return ('out', 'coverage_lost')
    dport = projection_distortion(phi)
    if dport > delta_star:
        return ('out', 'distortion', dport)
    delta_rho = max(J_src.rho[d] - rho_eval(J_src.skill, pi_tgt, d)
                    for d in J_src.rho)
    delta_beta = beta_min(pi_tgt) - beta_min(pi_src)
    if delta_rho > eps_rho or delta_beta < -eps_beta:
        D_min = minimal_distinguishing_set(J_src, pi_src, pi_tgt, phi)
        if not recheck(J_src.skill, pi_tgt, D_min):
            return ('out', 'margin_or_robustness_drop', delta_rho, delta_beta)
        return ('in', PTC(pi_src, pi_tgt, phi, dport, delta_rho, delta_beta,
                          d, mode='recheck_min'))
    if dominates(pi_tgt, pi_src, phi):          # pi_tgt ⊒ pi_src
        return ('in', PTC(pi_src, pi_tgt, phi, dport, delta_rho, delta_beta,
                          d, mode='dominance_shortcut'))
    D_min = minimal_distinguishing_set(J_src, pi_src, pi_tgt, phi)
    if recheck(J_src.skill, pi_tgt, D_min):
        return ('in', PTC(pi_src, pi_tgt, phi, dport, delta_rho, delta_beta,
                          d, mode='recheck_min'))
    return ('out', 'no_transfer')
```

### IP-125 MPF

```python
def multi_port_fanout(J_src, ports, T_all, R_max, B, kappa, r_shared):
    feasible = []
    for pi in ports:
        ptc = port_transfer_certificate(J_src, J_src.port, pi, phi_for(pi))
        if ptc.decision == 'in':
            feasible.append(PortCandidate(pi, ptc, r_i(pi), cover_set(pi)))
    Pi = []
    while len(Pi) < B and feasible:
        cand = argmax(feasible, key=lambda c: marginal_coverage(c, Pi, T_all))
        if risk_bound(Pi + [cand], kappa, r_shared) > R_max:
            feasible.remove(cand)
            continue
        Pi.append(cand)
    if not Pi:
        return ('fail', 'no_safe_port')
    return ('ok', Pi, coverage(Pi, T_all), risk_bound(Pi, kappa, r_shared))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PFP | O(q·T_probe) | O(q) | 探针持续激励、指纹可辨识、置信区间 |
| BSP | O(|A_T|·(c_contact+c_id)) | O(|A_T|) | ZMP/锥/捕获点判定 sound |
| HBC | O(|A_T|·c_bal + M·c_sim) | O(|A_T|+M) | 扰动集覆盖、跌倒界 sound |
| PTC | O(|A_T|·|φ| + |D|) | O(|A_T|+|D|) | 覆盖保持、失真有界、支配见证有效 |
| MPF | O(m·|A_T| + m·B·|T|) | O(m+|T|) | 子模贪心、安全硬剪枝 |
| PDD | O(q·T_probe)/窗口 | O(q) | 漂移 > θ_fp 可检出 |

**正确性定理（Multi-Port Humanoid Deployment Soundness）**
承接第 54 轮 (A26)–(A28)，新增：
- **(A29)** 指纹辨识误差 `≤ ε_fp`，两次认证间漂移 `≤ θ_fp`；
- **(A30)** 投影 `φ` 覆盖保持且 `δ_port ≤ δ*`，支配见证 D1–D5 可验证；
- **(A31)** `BCert` 在扰动集 `W` 上 sound，跌倒界关于裕度 `β` 单调；
- **(A32)** 给定端口后独立失败事件条件独立；共享缺陷 `r_shared` 与相关放大 `κ(Π)` 有上界。

则对任意 `Π` 且 `∀i: PTC_i = in`：
```
P_fail(Π) ≤ Σ_{π∈Π} [ Σ_{d∈D}(1 - ρ_{S|π}(d)) + ε_fall(π) + P(δ_port > δ* | π) ]
            + κ(Π)·r_shared + P(drift > θ_fp)
P_safe(Π) ≥ 1 - P_fail(Π)
```
关键：**端口相对证书先验**、**支配方向单向正确**、**平衡证书覆盖接触切换瞬态**、**共享故障有相关上界**。

## 9. 本轮最大风险

**一句话**：多端口部署把第 54 轮的“动作-鲁棒性双证书”推广为“端口相对证书包”，人形机器人又把动作空间从欧氏盒子收紧为平衡-接触流形；其 soundness 依赖端口支配关系的可证明性、平衡证书在接触切换处的不破缺、以及跨端口共享故障的相关性上界——一旦端口支配被隐藏耦合（执行器饱和、足底摩擦差异）击穿，或平衡证书在接触切换瞬态失效，扇出到 m 个端口的将不是 m 份安全，而是同一个被放大的系统性跌倒风险，故必须以“能力维度可证明支配 + 接触切换瞬态专项认证 + 相关性上界与灰度扇出”三重护栏，宁可少部署一个端口，也绝不把端口格上的“看起来更强”当作可迁移。
