# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS」IP-287~294；新灵感循环第 1 轮；本轮灵感：「在线学习」×「同步定位与建图」）

> R72 把 GAUGE 从「认知层算法」下沉为「具身实时系统」：REG 调度契约、意图隐变量 z、灵巧手接触模式 c、三层反作用与 S2R-UQ 桥接，并确立了「安全侧只增不减、逐指令退化」的姿态。但 R72 有两根**没有写进证书的静态拐杖**：
> - **模型静态拐杖**：BSE、IRL、DMEM、S2R 残差、接触四分量校准，全部默认「部署前冻结、部署后不变」。真实世界里传感器会漂移、灵巧手会磨损、物体分布会变、人的手势/语言会演化——**模型终将过期，而证书不会自己过期**。
> - **参考系静态拐杖**：世界状态 s 与所有证据都默认挂在一个「已知坐标系」上。真实系统里位姿是估计的、地图是拼出来的、外参是标定的、回环是会错的——**残差是否合理，取决于你用哪个参考系去量；而参考系本身也是测量结果**。
>
> 本轮两个灵感正好补这两根拐杖，且它们天然对偶：
> - **在线学习（Online Learning）**：让模型跟着世界变。但它改的不是「世界」，而是「判断世界是否可信的那把尺子」；学习目标、数据选择、审计标准都可能被模型自己的输出污染。**学习是一次测量，被测对象是模型本身，而测量会改变被测对象**——这是「自指计量学」。
> - **同步定位与建图（SLAM）**：让参考系跟着机器人变——用运动把观测拼成轨迹、把轨迹拼成地图。但 SLAM 估计的是「自己的参考系」：全局坐标系不可观测（gauge freedom），回环是长程测量且可能灾难性错误，地图是会被投毒、遗忘、漂移的**空间记忆**。
>
> 两者复合会产生 R72 没有覆盖的第三种失效：**认知近亲繁殖（epistemic inbreeding）**。SLAM 用在线学习到的特征做数据关联 → 在线学习用 SLAM 的伪标签/地图做自监督 → 审计集又从同一张地图采样 → 所有内部控制指标一起变好，而全局真相在悄悄漂移。R72 的风险是「自信地错自己的可执行性」；本轮的风险是**「自洽地错整个世界」**。
>
> 核心命题：**不再问「此刻我的测量链可信吗」，而问「当模型和地图都会随时间变化时，我的测量链还能在租约内、沿轨迹、对锚点兑现风险界吗？」** 把 R72 的「具身点态证书」升级为 **LIFELONG-GAUGE-RAS**（Lifelong, Invariant-frame, Evidence-anchored, Gauge-audited for RAS；终身 × 规范不变 × 锚定证据 × 变化检测的计量闭环）——**可过期的终身计量审计**。

## 0. 直觉与动机

**灵感 1（在线学习 → 模型是仪器，学习是再校准，必须像传感器一样被审计）**
直觉：R72 把校准数据、意图分类器、触觉噪声模型、sim2real 残差都当作「出厂参数」。但真实部署中，触觉阵列随温度漂移、灵巧手随磨损改变接触几何、人的用词随信任变化、环境光照随季节变化。在线学习（在线标定、测试时自适应、持续学习）是唯一现实的应对。问题在于：**再校准需要参考标准；如果参考标准也来自同一个正在被校准的模型，校准就变成了自我确认**。计量学对此有成熟答案——校准必须可追溯到外部基准，必须记录校准证书，必须有「失准（out-of-calibration）」界限与漂移监控。**本轮的第一个动作，就是把在线学习从「训练技巧」重新定义为「仪器再校准」：每次参数更新都是一次带不确定度、带数据来源、带有效期、可回滚的计量事件。**

**灵感 2（SLAM → 参考系也是测量结果，绝对位姿在没有锚点时不可审计）**
直觉：R72 的残差、接触几何、意图证据都默认在一个已知世界坐标系里。真实机器人没有「上帝坐标」：它只有里程计、视觉、激光、触觉，以及它们之间的相对约束。SLAM 的测量模型对**全局刚体变换（甚至单目下的尺度）不变**——你把整条轨迹和整张地图一起平移旋转，所有观测残差一模一样。这意味着「绝对位姿误差 < ε」这种证书在没有外部锚点时**不可识别**。可审计的只能是 **gauge-invariant** 的量：锚点间相对位姿、回环残差、已知几何物体的尺度、负信息（「这里不是那里」）。**SLAM 不是「定位模块」，它是一台估计自己参考系的仪器；对它的审计必须是规范不变的。**

**灵感 3（复合 → 认知近亲繁殖：所有指标都变好，而世界在漂移）**
直觉：把两者接起来，就得到一个危险的闭环：SLAM 用学习到的特征做数据关联；在线学习用 SLAM 的伪标签、地图一致性、回环结果做自监督；审计集又和训练集共享同一张地图、同一个特征空间。于是「关联更准 → 地图更一致 → 伪标签更自信 → 学到的特征更迎合地图 → 关联更准」。**这是一个正反馈，但正反馈的对象是「自洽」，不是「真实」。** 尺寸偏差 5% 的机器人可以建出一张内部完全一致、回环误差极小、审计全过的地图，只是它比真实世界大 5%——直到它去抓一个真实杯子时捏碎。R72 的「自信地错自己的可执行性」是**单点自信**；这里的「自洽地错整个世界」是**系统级自洽幻觉**。

**灵感 4（时间 → 点态证书不能组合成轨迹证书，需要租约、漂移率、检测延迟）**
直觉：R72 的 J_EMB 是「某一时刻有效」的点态证书。但点态有效不能推出轨迹安全：一个每步偏差 1mm 的里程计，每步都「在 ε 内」，一万步后偏差 10m。证书必须带**时间租约（lease）**、**漂移率上界 ρ**、**变化检测延迟上界 τ_d**：在 `[t, t+min(L_max, τ_d)]` 内、且漂移未超过 ρΔt 时有效。更妙的是，τ_d 不是拍脑袋的常数，它由变化检测的虚警率 α 与前后分布散度决定（Lorden 界/GLR）。**于是「证书有效期」第一次和「统计检测理论」硬连接起来。**

**灵感 5（最小锚点原理 → 每个不可观测方向、每个反馈回路，至少要有一个外部锚点）**
直觉：不是「多加传感器」就能破闭环。真正需要的是**与闭环内部信息线性无关的外部约束**：已知尺寸的标定物（尺度锚）、人确认过的少量语义标签（语义锚）、不被学习模型使用的独立模态（跨模态锚）、已知不同的地点（负信息锚）、独立时钟/事件相机（时间锚）。形式化：内部信息矩阵 I_int 有零空间 N（规范自由度 + 学习坍缩方向）；锚点信息 I_A 必须满足 `null(I_int + I_A) = {0}`，否则证书只能限制在可观测子空间上。**审计的强度不取决于数据量，而取决于锚点覆盖了哪些不可观测方向。**

## 1. 形式化定义（增量：定义 366–379）

**定义 366（LIFELONG-GAUGE-RAS 总览）** LIFELONG-GAUGE-RAS = (FG, DAE, MTC, OLA, ANC, CLD, E-RISK†, GAUGE-RAS‡)。六不变式：
(i) **规范不变性优先**：任何证书断言必须在 gauge 群 G 下不变，或由锚点固定规范；绝对量在无锚点时不得进入证书；
(ii) **锚点覆盖充分性**：进入高风险决策的每个不可观测方向、每个学习反馈回路，必须有与内部信息线性无关的锚点覆盖，覆盖率 κ(A) > 0；
(iii) **地图事务隔离**：控制/计量域只读**已提交的不可变地图版本**；未通过一致性检验的地图更新只能隔离，不得提交；提交可回滚；
(iv) **学习影子部署**：在线学习只更新 shadow 模型；production 模型必须是「最近一次通过冻结审计」的版本；晋升是原子的，失败即回滚；
(v) **时间租约**：终身证书携带 (L, ρ, τ_d)；超出 lease 或检测到漂移即失效，不得默认续期；
(vi) **严格退化链**：L 域失效 ⇒ 冻结地图/模型回 R72；锚点覆盖失效 ⇒ 证书投影到可观测子空间并对高风险动作否决；三者全失效 ⇒ R68。**新层只在「参考系可锚定、模型可审计、漂移可检测」时启用。**

**定义 367（帧图 FG）** FG = (V, E, x, Σ, A, G)：
- V 为坐标系/路标节点（map, odom, base, camera, tactile, object, anchor）；
- E ⊆ V×V 为相对测量边，z_ij = x_i^{-1} x_j ⊕ ε_ij，信息矩阵 Ω_ij = Σ_ij^{-1}；
- x 为位姿/路标估计，Σ 为其协方差；
- A ⊆ V 为锚点集（定义 368）；
- G 为 gauge 群（位姿图通常 SE(3)；单目/未标定尺度时 Sim(3)）。
**关键性质**：残差 r_ij = log(z_ij^{-1} x_i^{-1} x_j) 在 x_i → G x_i、x_j → G x_j 下不变。**因此 FG 的原始测量只确定相对结构，不蕴含任何绝对坐标。**

**定义 368（规范不变证书与锚点覆盖 ANC）** 断言 Φ 是规范的（gauge-invariant）若 ∀G∈G, Φ(G·x)=Φ(x)。非不变断言必须写成 (Φ, A)，其中锚点 A 固定规范。设内部信息 I_int、锚点信息 I_A，投影到不可观测子空间 N = null(I_int) 上：
κ(A) = λ_min( P_N^T I_A P_N )。
- κ(A) > 0 ⇒ 不可观测方向被锚点覆盖，绝对断言可审；
- κ(A) = 0 ⇒ 该断言不可识别，**只能**以 gauge-invariant 形式（相对量/回环残差/锚点残差）进入证书，否则视为无效数字。
锚点类型：A_metric（已知尺寸/基线/重力）、A_semantic（人确认的稀疏标签）、A_cross（不被学习模型使用的独立模态）、A_negative（已知不同地点的负信息）、A_temporal（独立时钟/事件）。

**定义 369（数据关联证据 DAE）** 关联假设 a ∈ 𝒜_t（当前观测到地图/历史帧的对应关系）。关联本身是测量：
p(a | y_t, M_v) = softmax_a s_θ(a; y_t, M_v)，关联不确定度
u_da = H[p(a|y_t,M_v)] + λ_mis · P_mis(a)，
其中 P_mis 为错关联概率（由已知几何一致性/独立模态估计）。引入负信息 N_t（「这些地方已确认不是同一处」）作为证据，**负信息只减不增关联支持**。**回环（loop closure）是一类长程关联测量，必须走定义 370 的事务，而不是直接写入地图。**

**定义 370（地图事务 MTC）** 地图更新事务
T_map = (ΔM, prov, 𝒜, tests, v, status)：
- ΔM 为待提交的节点/边/路标增量；prov 为数据来源（传感器帧、时间、模型版本、关联假设）；
- tests = (χ²_local, loop_independent, anchor_residual, temporal_dwell)；
- v 为父版本号；status ∈ {proposed, committed, quarantined, rolled_back}。
**提交规则**：仅当所有 tests 通过且 prov 完整时 status = committed；否则 quarantined。已提交版本 M_v 不可变，读者通过快照读取；回滚即指向 M_{v-1}。**地图是带版本、带事务日志、可回滚的空间记忆，不是一块可随意覆盖的共享内存。**

**定义 371（在线适应算子 OLA）** 适应算子 A_η: (θ_t, D_t) → θ_{t+1}：
θ_{t+1} = argmin_θ L_online(θ; D_t) + (1/2η)‖θ − θ_t‖²_Λ
s.t. ‖θ − θ_t‖_Λ ≤ δ（信任域），
     R_A(θ) ≤ R_A(θ_t) + ε（冻结审计不退化），
     C_anchor(θ) ≤ γ（锚点一致性），
     ChangeDetector = ADAPT（变化检测门控）。
其中 R_A 为冻结审计集上的风险。产出**适应收据** receipt = (θ_t, θ_{t+1}, D_t 摘要, 权重, 约束余量, 回滚点)。**约束不满足即不部署；不是「先学再说」。**

**定义 372（冻结审计集与金丝雀 SEAL-LIFE）** A_SEAL 满足：
(a) 从未参与训练/伪标签生成/模型选择；
(b) 版本化且密封（哈希上链，改动即断链）；
(c) 由外部锚点或人确认维护，不由模型自身更新；
(d) 与部署分布 p_D 的偏差用重要性权重 w(a)=p_D(a)/p_A(a) 校正（IPS/SNIPS）。
**金丝雀探针**：以稀疏、随机、不可预测的方式注入已知答案的探针（已知几何、已知类别、已知位姿），在线估计真实误差，作为「活标准」。**审计集一旦被模型的选择行为污染，就退化为自证集。**

**定义 373（变化检测与漂移 CLD）** 对审计残差/金丝雀残差 e_t 运行 CUSUM：
s_t = log [f_1(e_t) / f_0(e_t)]，C_t = max(0, C_{t-1} + s_t − k)，
当 C_t > h 报警。虚警率 α、前后分布 KL 散度 D(f_1‖f_0)、检测延迟 τ_d 满足 Lorden 界
E[τ_d | ν] ≤ (h + c) / D(f_1‖f_0) + O(1)（已知后验分布）；
后验未知时用 GLR：sup_{f_1} Σ log(f_1(e_t)/f_0(e_t))，延迟随 log(T)/D 增长。
漂移率上界 ρ 由滑动窗口残差斜率 + 置信上界给出。**证书租约 L_lease = min(L_max, τ_d(α, D_min))。**

**定义 374（终身不确定度分解）** 在 R72 的 (U_ale, U_epi, H[b(z)], u_tac) 之外新增：
u_life² = u_frame² + u_map² + u_adapt² + u_da²，
- u_frame：使用点处位姿协方差沿帧图传播（含 gauge 投影后的可观测部分）；
- u_map：地图陈旧度/差异不确定度，随「该区域距上次观测的时间 × 变化率上界」增长，重观测时重置；
- u_adapt：模型参数不确定度 + 自上次校准以来的漂移，由集成/后验或信任域半径给出；
- u_da：关联熵 + 错关联概率。
四项各有独立追溯链 τ_frame, τ_map, τ_adapt, τ_da。**它们不是「误差项」，是四类不同物理/统计机制；合并时用保守上界或协方差交集，不得简单相加后当独立。**

**定义 375（终身风险缩放 L-RISK）** 
λ_LIFE = max( risk_scale(U_ale, U_epi, H[b(z)], u_tac, u_frame, u_map, u_adapt, u_da),
              λ_floor(U_ale + U_epi + H[b(z)] + u_tac + u_frame + u_map + u_adapt + u_da) )。
**非补偿性**：任一维失控都抬高 λ，强制软化动作；没有「地图不准但视觉很准所以没关系」这种补偿逻辑。

**定义 376（终身证书 J_LIFE）** 
J_LIFE = (J_EMB, fg_hash, anchor_coverage_proof, map_version, map_txn_chain,
          model_version, audit_receipt, drift_stat, lease=(L,ρ,τ_d), gauge_projection)。
Valid(t) ⇔ Valid(J_EMB) ∧ 帧图一致性检验通过 ∧ κ(A) > 0（或断言已投影到可观测子空间）∧ 地图事务链完整 ∧ 模型审计收据有效 ∧ 未触发变化报警 ∧ t < t_commit + L。**证书是有条件、有期限、可回滚的；过期不等于错误，但必须重新验证。**

**定义 377（威胁模型 AIC-LIFE）** ℰ_LIFE = ℰ_EMB × ℰ_frame × ℰ_map × ℰ_adapt × ℰ_time：
- ℰ_frame：回环欺骗、外参投毒、尺度攻击、动态物体伪装成静态路标、gauge 锁定攻击（用错误锚点固定规范）；
- ℰ_map：地图投毒、伪标签污染、记忆遗忘（旧区域漂移）、版本回滚攻击、事务日志篡改；
- ℰ_adapt：自确认（训练/审计同源）、灾难性遗忘、数据选择偏差、审计集泄漏、慢漂移规避检测；
- ℰ_time：租约过期后继续使用、利用检测延迟窗口、在两次审计之间做不可逆动作。

**定义 378（终身流水线四域分离）** 在 R72 三域之外新增**终身域 L（Lifelong）**：
- 控制域（1kHz，硬实时，只读快照）；
- 计量域（50Hz，软实时，写快照）；
- 感知域（100Hz，Best-effort，写缓冲）；
- **L 域（事件/分钟级，后台，可抢占、可暂停）**：SLAM 后端、地图事务、shadow 学习、冻结审计、变化检测。
L 域**只提交版本化快照**，从不持有控制/计量域需要的锁；控制域永远读「最近已提交版本」。**学习可以慢、可以停、可以回滚，控制不能。**

**定义 379（终身严格退化链）** 
- L 域失效（学习/地图后端崩溃）⇒ 冻结模型与地图，回 R72；
- 锚点覆盖失效（κ(A)=0）⇒ 证书投影到可观测子空间，高风险动作否决，回 R72 + 相对证书；
- 检测到漂移但无通过审计的替代模型 ⇒ 回滚到最近认证版本并抬高 λ_floor；
- 地图事务未提交 ⇒ 使用最近已提交版本 M_v，忽略隔离中的增量；
- 全部失效 ⇒ R68。
**安全侧只增不减：任何退化都保留 R68 硬安全包络与 R72 λ_floor；效率只在「参考系可锚定、模型可审计、漂移可检测」时获益。**

```python
# IP-295 FGM：帧图与规范不变审计（L 域，后台）
class FrameGraphMetrology:
    def __init__(self, graph, gauge_group):
        self.g, self.G = graph, gauge_group
    def gauge_project(self, J, cov):
        # 把雅可比/协方差投影到可观测子空间，消除 gauge 方向
        N = nullspace(self.g.internal_information())      # 规范零空间
        P = eye(N.shape[0]) - N @ pinv(N.T @ N) @ N.T
        return P @ J, P @ cov @ P.T
    def audit(self, anchors):
        # 只审 gauge 不变量：相对位姿 / 回环残差 / 锚点残差 / 尺度
        r_rel = [log(z.inv() @ x_i.inv() @ x_j) for z, x_i, x_j in self.g.edges()]
        r_anchor = [log(a.z.inv() @ x_a.inv() @ x_anchor) for a in anchors]
        chi2 = sum(r.T @ Om @ r for r, Om in zip(r_rel + r_anchor,
                                                self.g.informations() + anchors.informations()))
        kappa = min_eig(project(anchors.information(), self.g.nullspace()))
        return Audit(chi2=chi2, kappa=kappa, gauge_invariant=all(is_invariant(r) for r in r_rel))
```

## 3. 推导

**引理 33（规范不可识别性：没有锚点就没有绝对证书）** 设 FG 的边测量为相对量 z_ij = x_i^{-1}x_j，gauge 群 G 作用为 x_i → G x_i。则 ∀G，所有边残差 r_ij 不变，而绝对位姿 x_i 改变。因此任何只依赖内部测量的估计器，其绝对位姿/绝对地图误差的断言都不可识别；证书要么使用 gauge 不变量，要么由锚点 A 固定规范（κ(A)>0）。证明：把 G 作用代入残差即得不变性；绝对误差范数在 G 下变化，故不可由不变残差确定。系：**R72 的「世界坐标误差」在无锚点系统里是一个无意义的数字——这正是 SLAM 证书必须重写的原因。**

**引理 34（点态有效不可组合为轨迹有效）** 设每步相对运动估计带系统偏差 b（‖b‖≤ε），每步点态证书均通过。则 T 步后轨迹误差 ≤ T·ε，随 T 无界增长。证明：误差沿轨迹线性累加，点态界不约束累加方向。系：**证书必须携带漂移率上界 ρ ≥ ‖b‖ 与租约 L；否则「每步都合格」与「最终撞墙」可以同时成立。** 这也是 R72 的 J_EMB 不能直接用于长时程的根本原因。

**引理 35（在线学习自确认：同源审计会把误差推向零而不改变真相）** 设模型参数 θ 同时生成伪标签 ŷ_θ 与审计集 A_θ（例如共享同一张地图/同一特征空间），且审计损失为模型预测与自身产物的一致性。存在参数化例子：单目尺度 s 被错估为 1.05；地图用 s 构建，回环残差、审计一致性、伪标签损失全部在 s 下自洽为零；但真实尺度误差恒为 5%。形式化：若 p(A_θ) 依赖 θ，则经验审计风险 R̂_A(θ) → 0 不蕴含部署风险 R_D(θ) → 0；选择偏差项 `E_{p_A}[(p_D/p_A − 1) ℓ]` 不被控制。系：**审计集必须冻结、外部锚定、并与训练数据生成机制解耦；否则「越来越准」只是「越来越自洽」。**

**引理 36（证书租约由检测延迟上界给出）** 在 CUSUM 下，若前后分布已知且 KL 散度为 D，虚警阈值 h，则检测延迟满足 Lorden 界 E[τ_d|ν] ≤ (h+c)/D + O(1)。取 L_lease = min(L_max, (h+c)/D_min) 作为证书有效期，则在漂移发生后的未检测窗口以高概率不超过 L_lease。证明：直接引用 Lorden 不等式并代入 CUSUM 的 ARL 性质；后验未知时用 GLR 的渐近界替换 D。系：**「证书多久过期」不是工程拍脑袋，而是虚警率与可检测漂移强度的函数；慢漂移（D 小）必然导致长租约或高虚警，二者不可兼得。**

**引理 37（地图事务隔离与可回滚）** 在定义 370 下，已提交版本 M_v 不可变，读者只读 M_v；未通过 tests 的 ΔM 只能进入 quarantine；回滚是版本指针切换。则任意读者看到的都是某个一致的已提交版本，不会读到半更新地图；任意提交都可回滚到 M_{v-1}。证明：提交是单点原子指针切换 + 校验和；读路径不持有写锁；quarantine 与已提交版本物理隔离。系：**把 R72 的「快照版本号」从毫秒级控制扩展到小时级空间记忆，且首次给出地图级事务语义。**

**定理 27（终身严格包含与风险单调）** 在 A111–A116（帧图可观测子空间可投影、锚点覆盖可计算、审计集冻结且未污染、变化检测有有限延迟界、地图事务隔离、适应算子满足信任域）下：LIFELONG 在退化条件下逐指令等于 EMBODIED / R71 / R68（定义 379）；且对任意有效执行，其风险界 ≤ R72 风险界（定理 23）。**安全单调不减；效率只在锚定/审计/检测三者同时成立时获益。**

**定理 28（J_LIFE 有效 ⇒ 轨迹级风险界）** 若在 [t_0, t_0+L] 内 J_LIFE 持续有效，且 (i) 锚点覆盖 κ(A)>0（或断言已投影），(ii) 漂移满足 ‖Δx‖ ≤ ρΔt，(iii) 地图事务链完整且只读已提交版本，(iv) 生产模型通过冻结审计且未触发变化报警，则轨迹风险 ≤ ε_life = ε_emb + L·ρ_geo + ε_map + ε_adapt + ε_da。证明：把轨迹误差分解为「点态 R72 误差 + 规范可观测部分的漂移累积 + 地图版本差异 + 模型适应误差 + 关联误差」，逐项用对应界控制，再用三角不等式合并。**证明的重量落在「锚点覆盖」与「审计集未污染」上——这正是引理 33/35 指出的两个不可省前提。**

**定理 29（审计门控的在线学习：有界后悔与有界遗忘）** 在损失凸、梯度有界、信任域 δ 与回放缓冲区容量 B 下：(i) 影子学习的在线后悔 ≤ O(√T)（静态环境）或 O(√(T(1+P_T)))（漂移路径长 P_T）；(ii) 冻结审计门控保证晋升后的生产模型在 A_SEAL 上不劣于上一认证版本超过 ε；(iii) 回放+EWC 使旧任务遗忘 ≤ O(1/√B)（按容量）。**注意：这些是「在审计集代表部署分布」条件下的学习保证，不是安全保证；安全仍由定理 28 的租约承担。**

**定理 30（四域分离无死锁/无活锁）** 控制域只读不可变快照（R72 + 地图版本），L 域只写新版本、从不持有控制/计量域所需锁；感知域异步入队；L 域可被抢占、可暂停、可崩溃。由单向版本化快照 + 原子指针切换，不存在循环等待、优先级反转或活锁；控制环永远能在 δ_ctrl 内完成一个周期。证明：与 R72 定理 25 同构，额外把地图事务的提交点设计为单指针原子切换，并禁止 L 域反向读取/修改控制域状态。系：**学习与建图可以「停」，控制不能「等」。**

```python
# IP-295 FG：帧图与规范不变审计（L 域，后台）
class FrameGraphMetrology:
    def __init__(self, graph, gauge_group):
        self.g, self.G = graph, gauge_group

    def gauge_project(self, J, cov):
        N = nullspace(self.g.internal_information())       # gauge 零空间
        P = eye(N.shape[0]) - N @ pinv(N.T @ N) @ N.T      # 投影到可观测子空间
        return P @ J, P @ cov @ P.T

    def audit(self, anchors):
        # 只审 gauge 不变量：相对位姿 / 回环残差 / 锚点残差 / 尺度
        r_rel    = [log(z.inv() @ x_i.inv() @ x_j) for z, x_i, x_j in self.g.edges()]
        r_anchor = [log(a.z.inv() @ x_a.inv() @ x_anchor) for a in anchors]
        chi2 = sum(r.T @ Om @ r for r, Om in zip(
            r_rel + r_anchor, self.g.informations() + anchors.informations()))
        kappa = min_eig(project(anchors.information(), self.g.nullspace()))
        return Audit(chi2=chi2, kappa=kappa,
                     gauge_invariant=all(is_invariant(r) for r in r_rel))

class OnlineLearningAudit:

# IP-300 CLD：变化/漂移检测（L 域，秒级）
class DriftDetector:
    def __init__(self, alpha, d_min, h):
        self.alpha, self.d_min, self.h, self.C = alpha, d_min, h, 0.0

    def update(self, residual):
        s = loglik_ratio(residual, self.f1, self.f0)
        self.C = max(0.0, self.C + s - self.k)
        return self.C > self.h

    def lease(self):
        return min(self.L_max, (self.h + self.c) / self.d_min)

        M.emb_snapshot.write(b_t, z_d, gate, M.tac_ev, fg_audit)

    # ========== 感知域 (100Hz, Best-effort) ==========
    M.slam.frontend.push(obs)                            # 前端只入队，不建图
    M.y_intent_buf.append(extract_intent_obs(obs, audio, M.last_action))
    tac_ev = M.dmem.update(tac_frame, M.last_action)     # R72 DMEM
    if tac_ev.u_tac > TAU_U_TAC:
        M.tac_ev = None

    # ========== L 域 (后台, 可暂停, 只提交版本化结果) ==========
    if M.life.map_due():
        txn = M.slam.backend.propose()
        if M.mtc.submit(txn.delta, txn.prov, txn.assoc):
            M.map_snapshot.publish(M.mtc.store.head())   # 原子发布新版本
    if M.life.audit_due() or M.cld.alarm():
        M.ola.step(M.life.replay_buffer.recent())        # shadow -> 审计 -> 晋升/回滚
    canary = M.anchors.inject_canary(M.t)
    if canary is not None:
        M.cld.update(canary.residual(M.prod))
    return k, lam, J_LIFE(M)
```

## 4. 推导

**引理 33（规范不可识别性）** FG 边测量为相对量，gauge 群作用不改变任何残差，却改变绝对位姿。故绝对位姿/绝对地图误差的断言不可由内部残差识别；证书要么 gauge-invariant，要么由锚点固规范（κ(A)>0）。系：**无锚点的「世界坐标误差」是无效数字。**

**引理 34（点态有效不可组合）** 每步系统偏差 ‖b‖≤ε 时，T 步轨迹误差 ≤T·ε，随 T 无界；点态界不约束累加方向。系：**J_EMB 不能直接用于长时程，必须加漂移率 ρ 与租约 L。**

**引理 35（在线学习自确认）** 若伪标签与审计集由同一 θ/同一地图生成，则经验审计风险 →0 不蕴含部署风险 →0；存在尺度 s=1.05 的自洽反例：回环/审计/伪标签全为零残差，真实尺度误差恒为 5%。形式化：p(A_θ) 依赖 θ 时选择偏差项 `E_{p_A}[(p_D/p_A−1)ℓ]` 不受控。系：**审计集必须冻结、外部锚定、与训练生成机制解耦。**

**引理 36（租约 = 检测延迟上界）** CUSUM 在前后分布已知、KL 为 D 时，Lorden 界 E[τ_d|ν] ≤ (h+c)/D+O(1)。取 L_lease=min(L_max,(h+c)/D_min)，则漂移后未检测窗口以高概率 ≤L_lease；后验未知用 GLR 渐近界。系：**租约不是拍脑袋，是虚警率与可检测漂移强度的函数；慢漂移必然在「长租约」与「高虚警」间二选一。**

**引理 37（地图事务隔离与可回滚）** 已提交 M_v 不可变、读者只读；未过 tests 的 ΔM 只进 quarantine；回滚=版本指针切换。故读者永远看到一致的已提交版本，提交可回滚到 M_{v-1}。系：**R72 的毫秒级快照版本被扩展到小时级空间记忆，并首次给出地图级事务语义。**

**定理 27（终身严格包含与风险单调）** 在 A111–A116（可观测子空间可投影、κ(A) 可计算、A_SEAL 冻结未污染、变化检测有有限延迟界、地图事务隔离、适应满足信任域）下：LIFELONG 在退化条件下逐指令等于 EMBODIED/R71/R68（定义 379）；任意有效执行的风险界 ≤ R72（定理 23）。**安全单调不减；效率只在锚定/审计/检测同时成立时获益。**

**定理 28（J_LIFE 有效 ⇒ 轨迹级风险界）** 若 [t_0,t_0+L] 内 J_LIFE 持续有效，且 (i) κ(A)>0（或断言已投影），(ii) ‖Δx‖≤ρΔt，(iii) 事务链完整且只读已提交版本，(iv) 生产模型过冻结审计且未报警，则轨迹风险 ≤ ε_life=ε_emb+L·ρ_geo+ε_map+ε_adapt+ε_da。证明：把轨迹误差分解为点态 R72 误差 + 规范可观测漂移累积 + 地图版本差异 + 适应误差 + 关联误差，逐项控制后三角不等式合并。**重量落在「锚点覆盖」与「审计集未污染」——正是引理 33/35 的两个不可省前提。**

**定理 29（审计门控在线学习：有界后悔/有界遗忘）** 凸损失、有界梯度、信任域 δ、回放容量 B 下：(i) 影子学习静态环境后悔 O(√T)，漂移路径长 P_T 时 O(√(T(1+P_T)))；(ii) 冻结审计门控保证晋升后 A_SEAL 风险不劣于上一认证版本超过 ε；(iii) 回放+EWC 使旧任务遗忘 ≤O(1/√B)。**这些是「A_SEAL 代表部署分布」下的学习保证，不是安全保证；安全由定理 28 的租约承担。**

**定理 30（四域分离无死锁/无活锁）** 控制域只读不可变快照（R72+地图版本）；L 域只写新版本、不持控制/计量所需锁；感知域异步入队；L 域可抢占/暂停/崩溃。单向版本化快照+原子指针切换 ⇒ 无循环等待、无优先级反转、无活锁；控制环永能在 δ_ctrl 内完成。系：**学习与建图可以停，控制不能等。**

## 7. 本轮最大风险

**一句话**：LIFELONG-GAUGE-RAS 把安全从「相信一张具身证书」转移到「相信 **锚点覆盖了所有不可观测方向**、相信 **冻结审计集永远代表部署分布**、相信 **变化检测租约总能跑在慢漂移前面**」——**如果锚点本身被系统性偏置（错误标定物、被收买的人标签、与学习模型共享同一物理缺陷的「独立」模态），或者审计集在长尾/跨文化/新环境里悄悄失配，或者漂移缓慢而光滑（D 很小，CUSUM 租约被拉得很长），系统就会进入「帧图自洽、回环残差小、审计全过、事务链完整」的状态，而它在真实世界已整体偏了 5% 尺度、错认了一个房间、忘掉了一半旧模型——直到灵巧手捏碎杯子、撞倒老人，事后审计发现每张 J_LIFE 都「当时有效」，只是所有锚点都锚在了同一个错误的世界上。这就是终身计量层面的「自洽地错整个世界」。**

次级风险与缓解：
1. **锚点同源偏置** → 锚点来源多样性（几何/语义/跨模态/负信息至少两类）；锚点自身不确定度进入 κ(A) 与 λ；定期独立第三方复核。
2. **审计集分布失配** → 冻结+重要性加权+尾部主动采样；部署前做「审计集覆盖审计」，覆盖不足拒绝全自动晋升。
3. **慢漂移规避检测** → 对漂移率做二阶监控（漂移的漂移）；设硬上限 L_max，到期强制重锚定，不因 D 小无限续期。
4. **地图/模型正反馈** → 训练与审计数据在地图版本、特征空间、时间窗三重解耦；禁止生产模型生成的数据直接训练同一模型。
5. **灾难性遗忘** → 回放+EWC+旧任务金丝雀；遗忘超阈即回滚并冻结在线学习。
6. **L 域算力挤占** → L 域严格后台、可暂停、cgroup/CPU 配额隔离；控制 P99 由 R72 RTM 继续兜底。
7. **复杂度爆炸** → 模块上限：锚点 ≤16/类、事务批量 ≤64 边、审计周期 ≥10min、shadow ≤1 份；每个 veto 一条可复算证明。
