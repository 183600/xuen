# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；新一轮灵感循环第 1 轮；本轮灵感：「数据规模」×「任务分解」）

> 第 54 轮把技能组合提升为动作剖面 `α_S` 与云边联合证书 `J`，但仍隐含一个危险假设：**证书的 soundness 与“用了多少数据”无关**。本轮用「数据规模」×「任务分解」两把刀切开这个假设，追问两件事：证书凭什么随数据增长而变窄？任务拆得越细是否一定越好？核心矛盾是 H22：证书宽度应随有效数据规模收缩，但数据复用与任务重叠会破坏独立性，使名义证书过窄；H23：任务分解粒度存在由数据规模决定的最优值 `k*(N)`，过细分解的接缝成本会吞掉专业化收益。

## 0. 直觉与动机

**灵感 1（给证书装误差棒：数据规模 = 证书宽度）**
直觉：第 54 轮的 `J` 是一个“点估计式承诺”，既没有样本量也没有置信度。同一技能用 10 条轨迹校准和用 10^5 条轨迹校准，其可信度天差地别。因此证书必须携带 **证书数据剖面** `D_C = (N, n_eff, κ_cov, δ_conf, family)`：它不记录“硬盘里有多少条数据”，而记录“这些数据能支撑多窄的证书”。数据规模越大，证书越窄；但只有独立且覆盖充分的数据才真正让证书变窄。

**灵感 2（任务分解 = 数据分配决策，而非纯结构选择）**
直觉：把任务 `T` 拆成 `k` 个子任务，本质上等价于把数据预算 `N` 切成 `n_1,...,n_k`。拆得细，每个技能更专一（偏差项下降），但代价有二：① 每个子任务分到的数据更少（统计误差上升）；② 子任务之间出现接缝（组合误差上升）。所以任务分解不是“越细越好”，而是一个 **偏差—统计—接缝三元权衡**，必然存在由数据规模决定的最优粒度 `k*(N)`。

**灵感 3（有效数据规模：复用会把独立样本变成相关样本）**
直觉：技能复用与任务分解会让同一批轨迹被多个子任务“共享”。若直接重复计数，会虚增 `n_eff`，让证书虚假变窄。真正可用的规模是 **有效独立覆盖量**：既按动作/任务桶做覆盖加权（Kish 有效样本量），又按重叠矩阵做相关性折扣。数据规模的价值取决于“覆盖了动作—任务流形上多少个独立区域”，而不是“记录条数”。

**灵感 4（跨轮累积：用 anytime-valid 证书替代一次性检验）**
直觉：本状态文件跨轮保留，数据也会跨轮累积。若每轮都重做一次固定样本量的置信检验，就会遭遇多重检验问题：证书越刷新越不可信。改用 **anytime-valid 置信序列 / e-process**，可在任意时刻、任意数据量读出一个有效下界，使“数据规模”与“跨轮证书刷新”真正兼容。

**灵感 5（数据规模驱动的自适应分解）**
直觉：小数据时，粗分解（少而全的技能）更稳；大数据时，细分解（专而精的技能）才划算。于是分解树应随数据增长“生长”：只有当把某叶节点再拆一刀带来的 **可认证成功率增益** 大于接缝成本与统计代价之和时，才允许拆分。这把任务分解从一次性设计变成随数据规模演化的过程。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（证书数据剖面与数据耦合证书）**
证书数据剖面 `D_C = (N, n_eff, κ_cov, δ_conf, family)`，其中 `N` 为原始样本数，`n_eff` 为有效样本量，`κ_cov` 为覆盖质量，`δ_conf` 为置信水平，`family` 为置信构造族（Hoeffding / empirical-Bernstein / e-process）。数据耦合证书
```
C = (ρ, A_cert, D_C),   cert_width(C) = W(n_eff, δ_conf)
```
即证书宽度只由有效数据规模与置信水平决定，而不是由原始数据量决定。

**定义 122（覆盖质量与有效样本量）**
样本 `d_i=(a_i,T_i,y_i)` 带覆盖权重 `w_i ∈ [0,1]`，Kish 有效样本量 `n_kish = (Σ_i w_i)^2 / Σ_i w_i^2`。覆盖质量 `κ_cov = |∪_i supp(d_i)| / |A × T|`。对分簇相关数据（同一轨迹派生多步），再做相关折扣
```
n_eff = n_kish / (1 + (m-1) ρ̄)
```
其中 `m` 为平均簇大小，`ρ̄` 为簇内相关系数。**定义 122 的要点：`n_eff ≤ N`，且只有在覆盖充分且近似独立时取等号。**

**定义 123（任务分解树与接缝）**
任务分解树 `D_T = (V, E, ℓ)`：根为任务 `T`，叶 `L` 为可执行原子技能，内部节点为分解算子，`ℓ` 给出叶子的数据预算 `n_i`（`Σ_i n_i ≤ N`）。接缝集合 `E_D` 为相邻叶子的组合边界，接缝成本
```
s_e = P(boundary failure) ≤ s_0 + c_s·(1 - compat(e))
```
直接继承第 54 轮的动作兼容性 `compat`：动作交集越小，接缝越贵。

**定义 124（分解—数据损失定律）**
总可认证损失
```
L(N, D_T) = Σ_{i∈L} f_i(n_i) + Σ_{e∈E_D} s_e + Stat(N, {n_i})
```
其中 `f_i` 为子任务真实失败概率，`Stat` 为统计误差。用经验 Bernstein 界并令 `n_i ∝ v_i^{1/3}`（`v_i` 为失败率估计方差），最优分配下
```
Stat* = Θ( (Σ_i v_i^{1/3})^{3/2} / √N )
```
等难度均匀分解（`v_i = v`, `k` 叶）退化为 `Stat* = Θ(k^{3/2}/√N)`。**关键结论：统计误差按 `N^{-1/2}` 收缩，但被一个随分解粒度以 `k^{3/2}` 增长的“分解复杂度”放大。**

**定义 125（可认证成功下界）**
给定分解树与数据分配，逐叶置信下界 `p_i^LCB = p̂_i - ε_i(n_i, δ/k)`，则
```
L_cert(N, D_T) = 1 - Σ_{i∈L} (1 - p_i^LCB) - Σ_{e∈E_D} ŝ_e
```
并断言 `P(S_true ≥ L_cert) ≥ 1 - δ - δ_s`。

**定义 126（分解阈值与最优粒度）**
设专业化弹性 `α`：均匀分解下 `f_i(k) = f_0·k^{-α}`，接缝成本 `s_0` 每条，统计系数 `c`。则
```
L(N, k) = f_0·k^{1-α} + c·k^{3/2}/√N + s_0·(k-1)
```
驻点条件
```
-(α-1)·f_0·k^{-α} + (3/2)·c·k^{1/2}/√N + s_0 = 0
```
- 若 `α ≤ 1`，`L` 关于 `k` 单调递增，**不分解最优**；
- 若 `α > 1`，存在内点最优 `k*(N)`，且大 `N` 的接缝主导区满足 `k*(N) ≍ N`。

由 `k=1` 与 `k=2` 比较得到 **数据规模分解门槛**
```
N_th = [ c(2^{3/2}-1) / ( f_0(1-2^{1-α}) - s_0 ) ]²
```
要求分母为正，即 `f_0(1-2^{1-α}) > s_0`：**专业化收益必须先跑赢接缝成本，增加数据才值得细分。**

**定义 127（数据摊销与有效独立数）**
数据来源图记录每个叶子的数据来源集合 `D_i`。定义重叠矩阵 `O_ij = |D_i ∩ D_j| / |D_i ∪ D_j|`，其非对角谱半径为 `ρ_eff`。有效独立数据量
```
N_indep = N / (1 + ρ_eff)
```
作为证书可用的数据规模。`ρ_eff → 0`（互不重叠）时 `N_indep → N`；`ρ_eff → ∞`（完全复用）时证书不能因“新轮次”而变窄。**这把“数据集规模”和“证据独立性”显式解耦。**

**定义 128（数据感知分解证书 DDC）**
```
C_DDC = (D_T, {C_i}, {s_e}, N_indep, L_cert, δ_conf, evidence)
```
部署条件：`L_cert(N_indep, D_T) ≥ L_min` 且 `κ_cov ≥ κ_min`。若失败，返回“增数据 / 粗化分解 / 补采接缝”三类可执行建议，而不只是拒绝。

## 2. 关键算法 伪代码

### IP-121 DCP（Data-Coupled Certificate）

```python
def certificate_with_data(skill, data, delta, family='eb_cs'):
    n_eff, kappa = effective_data_scale(data, skill.alpha)
    p_hat, v_hat = empirical_success(data)
    eps = anytime_lcb(data.outcomes, delta, family)
    return Cert(rho=skill.rho,
                A_cert=skill.A_cert,
                n_eff=n_eff, kappa=kappa,
                p_lcb=p_hat - eps,
                delta=delta, family=family)
```

### IP-122 EDS（Effective Data Scale）

```python
def effective_data_scale(data, alpha, gamma=1.0):
    w = {d: coverage_weight(d, alpha) for d in data}
    n_kish = sum(w.values())**2 / sum(x*x for x in w.values())
    O = overlap_matrix(data)                  # 按动作/任务桶统计复用
    rho_eff = spectral_radius(offdiag(O))
    return n_kish / (1 + gamma*rho_eff), coverage(data, alpha)
```

### IP-124 ADA（Adaptive Decomposition Allocator）

```python
def allocate_data(nodes, N):
    c = {i: max(node.v_hat, 1e-6)**(1/3) for i, node in enumerate(nodes)}
    s = sum(c.values())
    return {i: max(1, int(N * c[i] / s)) for i in c}

def adaptive_decompose(root, N, theta_gain=0.0):
    tree = Tree(root)
    while True:
        gains = []
        for leaf in tree.leaves:
            left, right = propose_split(leaf)
            n_l, n_r = split_budget(leaf.n)
            gain = (lcb(left, n_l) + lcb(right, n_r)
                    - lcb(leaf, leaf.n)
                    - seam_upper(left, right))
            gains.append((gain, leaf, left, right))
        g, leaf, l, r = max(gains, key=lambda x: x[0])
        if g <= theta_gain:
            break
        tree.split(leaf, l, r)
        tree.reallocate(allocate_data(tree.leaves, N))
    return tree
```

### IP-126 AVC（Anytime-Valid Certificate）

```python
def anytime_lcb(outcomes, delta, family):
    n = len(outcomes)
    if family == 'hoeffding':
        return mean(outcomes) - sqrt(log(1/delta) / (2*n))
    if family == 'eb_cs':                      # empirical-Bernstein 置信序列
        return mean(outcomes) - empirical_bernstein_cs(outcomes, delta)
    return e_process_lcb(outcomes, delta)      # Ville 不等式下的 e-process
```

### IP-128 DDC（Data-aware Decomposition Certificate）

```python
def data_aware_decomposition_cert(T, N, theta_min, delta):
    tree = adaptive_decompose(T, N)
    alloc = allocate_data(tree.leaves, N)
    certs = [certificate_with_data(l.skill, l.data[:alloc[i]], delta)
             for i, l in enumerate(tree.leaves)]
    seam = sum(seam_upper(e) for e in tree.seams)
    N_indep = N / (1 + spectral_radius(offdiag(overlap_matrix(tree))))
    L = 1 - sum(1 - c.p_lcb for c in certs) - seam
    if L < theta_min:
        return ('reject', diagnose(N_indep, certs, seam, tree))
    return ('ok', DDCCert(tree, certs, seam, N_indep, L, delta))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| DCP | O(\|D\| + \|A\|) | O(\|D\|) | 置信构造族有效、`n_eff` 保守 |
| EDS | O(\|D\|·\|A\| + n³) | O(n²) | 重叠折扣不虚增独立性 |
| DDT/ADA | O(\|T\|²·\|A\|) | O(\|T\|) | 每次拆分做增益检验 |
| AVC | O(\|D\|)（增量） | O(\|D\|) | anytime 有效性（Ville） |
| DDC | O(\|T\|²·\|A\| + \|D\|) | O(\|D\|+\|T\|²) | 接缝上界与数据折扣同时 sound |

**正确性定理（Data-Scaled Decomposition Soundness）**
假设承接第 54 轮 (A26)–(A28)，并新增：**(A29)** 置信序列满足 anytime 有效性，`P(∃t: S_true(t) < L_t) ≤ δ`；**(A30)** `N_indep` 对复用数据是保守下界（重叠谱半径估计无偏或偏大）；**(A31)** 接缝失败上界以概率 `≥ 1-δ_s` 成立；**(A32)** 专业化弹性 `α` 由留出集验证。则对任意停止时刻 `t`
```
P( S_true ≥ L_cert(N_indep, D_T) ) ≥ 1 - δ - δ_s - β_est
```
其中 `β_est` 来自 `α` 与接缝模型的估计误差。**相对第 54 轮的关键提升：证书第一次对“数据规模”单调，且跨轮累积不会因反复检验而失效。**

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 数据规模缩放律 | `cert_width` vs `N` 双对数斜率 | ≈ -0.5 |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 复用数据导致 `n_eff` 虚增 | 高 | 重叠谱半径折扣 + 数据来源图审计 |
| 过度分解堆高接缝成本 | 高 | 分解增益检验 + 接缝预算硬阈值 |
| `α` 估计偏差导致 `k*` 失真 | 中 | 留出集验证 + 保守下界 + 粗化回退 |
| anytime 置信序列过保守 | 中 | 混合族（Hoeffding→EB-CS）+ 自适应调参 |
| 覆盖不足时证书仍被误用 | 高 | `κ_cov ≥ κ_min` 作为部署硬门槛 |

## 6. 本轮最大风险

**一句话**：数据规模与任务分解把证书从“点承诺”升级为“带误差棒的可认证下界”，但其有效性同时依赖**有效样本量的保守估计、任务分解接缝的上界、以及 anytime 置信构造的正确性**；一旦复用数据被当作独立新证据、或细分带来的接缝成本被低估，证书会因数据变多而虚假变窄，进而把“数据堆出来的自信”误当作可部署性，故必须以 **数据来源图 + 重叠谱半径折扣 + 接缝预算硬闸** 三重护栏，宁可证书偏宽，也不让规模成为虚假 soundness 的放大器。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-DataScale（DCP×EDS×DDT×DDL×ADA×AVC×DAP×DDC）

> 承接第 54 轮产物 v31（GroundEdge-GenSim+++ / ACS×SCOM×CEC×AEC×JTC）。本轮在“动作—鲁棒性双证书”之上叠加 **数据规模层**，把证书从点估计升级为带 anytime 有效误差棒的可认证下界，并把任务分解从结构设计变成受数据预算约束的优化：
> - **DCP（Data-Coupled Certificate）**：证书携带数据剖面 `(N, n_eff, κ_cov, δ_conf)`；

> - **DAP（Data Amortization Provenance）**：数据来源图与有效独立数 `N_indep`；

### IP-124 DDL（损失评估与粒度选择）

```python
def decomposition_loss(k, N, f0, alpha, c, s0):
    penalty = f0 * k**(1-alpha)          # 专业化收益（k 越大越低，需 alpha>1）
    stat    = c * k**1.5 / sqrt(N)       # 分解复杂度放大统计误差
    seam    = s0 * (k-1)                 # 接缝线性累积
    return penalty + stat + seam

def optimal_granularity(N, f0, alpha, c, s0, k_max=64):
    if alpha <= 1.0:
        return 1                         # 专业化跑不赢，粗分解最优
    return min(range(1, k_max+1), key=lambda k: decomposition_loss(k, N, f0, alpha, c, s0))

def decomposition_threshold(f0, alpha, c, s0):
    denom = f0*(1 - 2**(1-alpha)) - s0
    if denom <= 0:
        return float('inf')              # 永不值得分解
    return (c*(2**1.5 - 1) / denom)**2
```

### IP-125 ADA

```python
def allocate_data(nodes, N):
    c = {i: max(node.v_hat, 1e-6)**(1/3) for i, node in enumerate(nodes)}
    s = sum(c.values())
    return {i: max(1, int(N * c[i] / s)) for i in c}

def adaptive_decompose(root, N, theta_gain=0.0):
    tree = Tree(root)
    while True:
        gains = []
        for leaf in tree.leaves:
            left, right = propose_split(leaf)
            n_l, n_r = split_budget(leaf.n)
            gain = (lcb(left, n_l) + lcb(right, n_r)
                    - lcb(leaf, leaf.n) - seam_upper(left, right))
            gains.append((gain, leaf, left, right))
        g, leaf, l, r = max(gains, key=lambda x: x[0])
        if g <= theta_gain:
            break
        tree.split(leaf, l, r)
        tree.reallocate(allocate_data(tree.leaves, N))
    return tree
```

### IP-126 AVC

```python
def anytime_lcb(outcomes, delta, family):
    n = len(outcomes)
    if family == 'hoeffding':
        return mean(outcomes) - sqrt(log(1/delta) / (2*n))
    if family == 'eb_cs':
        return mean(outcomes) - empirical_bernstein_cs(outcomes, delta)
    return e_process_lcb(outcomes, delta)     # Ville: 任意停止时刻有效
```

```python
def effective_independent_size(data_sets, N):
    O = overlap_matrix(data_sets)             # O_ij=|D_i∩D_j|/|D_i∪D_j|
```

### IP-128 DDC

```python
def data_aware_decomposition_cert(T, N, theta_min, delta):
    tree = adaptive_decompose(T, N)
    alloc = allocate_data(tree.leaves, N)
    certs = [certificate_with_data(l.skill, l.data[:alloc[i]], delta)
             for i, l in enumerate(tree.leaves)]
    seam = sum(seam_upper(e) for e in tree.seams)
    N_indep, O = effective_independent_size([l.data for l in tree.leaves], N)
    L = 1 - sum(1 - c.p_lcb for c in certs) - seam
    if L < theta_min:
        return ('reject', diagnose(N_indep, certs, seam, tree))
    return ('ok', DDCCert(tree, certs, seam, N_indep, L, delta))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DCP | O(\|D\|+\|A\|) | O(\|D\|) | 置信构造族有效，`n_eff` 保守 |
| EDS | O(\|D\|·\|A\|+n³) | O(n²) | 重叠折扣不虚增独立性 |
| DDL | O(k_max) | O(1) | 损失函数关于 `k` 可解析比较 |
| ADA | O(\|T\|²·\|A\|) | O(\|T\|) | 每次拆分做边际增益检验 |
| AVC | O(\|D\|) 增量 | O(\|D\|) | anytime 有效性（Ville） |
| DAP | O(n²) | O(n²) | `N_indep ≤ N`，复用不完全重复计 |
| DDC | O(\|T\|²·\|A\|+\|D\|) | O(\|D\|+\|T\|²) | 接缝上界与数据折扣同时 sound |

**正确性定理（Data-Scaled Decomposition Soundness）**
承接第 54 轮 (A26)–(A28)，新增假设：**(A29)** 置信序列 anytime 有效，`P(∃t: S_true(t) < L_t) ≤ δ`；**(A30)** `N_indep` 为复用数据的保守下界；**(A31)** 接缝失败上界以概率 `≥ 1-δ_s` 成立；**(A32)** 专业化弹性 `α` 由留出集验证。则对任意停止时刻 `t`
```
P( S_true ≥ L_cert(N_indep, D_T) ) ≥ 1 - δ - δ_s - β_est
```
其中 `β_est` 来自 `α` 与 `s_e` 的估计误差。**相对 v31 的核心提升：证书宽度随有效数据规模单调收缩，且跨轮累积不会因反复检验而失效。**

## 6. 本轮最大风险

**一句话**：数据规模与任务分解把证书从“点承诺”升级为“带误差棒的可认证下界”，但其有效性同时依赖**有效样本量的保守估计、任务分解接缝的上界、以及 anytime 置信构造的正确性**；一旦复用数据被当作独立新证据、或细分带来的接缝成本被低估，证书会因数据变多而虚假变窄，进而把“数据堆出来的自信”误当作可部署性，故必须以 **数据来源图 + 重叠谱半径折扣 + 接缝预算硬闸** 三重护栏，宁可证书偏宽，也不让规模成为虚假 soundness 的放大器。
