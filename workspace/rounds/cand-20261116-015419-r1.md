# 第 12 轮（新灵感循环第 2 轮；本轮灵感：「动作分块」×「快速原型」）

> **基线**：第 11 轮 MetricVoiceGauge-GSCF-SRA-JSSE（定义 549–561；引理 92–96；实验 E591–E610）。
> 本轮纪律：**边界不裸奔 + 兜底不止急停**。两个灵感各治一种债：**边界债**——v11 的分块是定长、互不重叠、到界即重算，于是每个块边界都是单点失效：旧证书刚过期、新证书刚生成还没历史、守卫还没来得及积累；单一证书一旦被污染，就没有第二张证书继续约束动作。**兜底债**——v11 的三重守护若同时失效，优雅退化路径根本不存在，只能急停；"安全"被实现成"停"，而不是"换一种可证安全动作"。铁律不变：新模块失效 ⇒ 注入声明中立元，行为严格**等价**（EOC 失效回到 v11 不重叠分块；SPF 失效回到 v11 的 abort/e-stop 路径）或**支配**（SPF 只合成受 v11 证书约束的恢复动作，不扩权）于 v11，绝不行为漂移。

## 0. 直觉与动机

**灵感 1（动作分块 → 重叠分块与共识证书）**
直觉：动作分块本来是一个"预测一段、执行一段"的效率技巧，但 v9–v11 把它用反了——**定长、不重叠、到界重算**。这使块边界成为全系统最脆弱的时刻：旧证书刚失效，新证书刚生成、守卫历史最短；如果新证书被对抗输入或量化误差污染，就没有任何冗余能拦住它。动作分块研究的经验恰恰相反：**重叠预测 + 时间集成（temporal ensembling）**能显著降方差、降抖动。把这条经验从"动作"搬到"证书"上，就是**弹性重叠分块（Elastic Overlap Chunking, EOC）**：以步长 s_g < K 滚动生成分块，使任一步同时被 m=⌈K/s_g⌉ 个已认证分块覆盖；执行命令取覆盖块的时间集成，安全约束取覆盖块证书的**共识**（clearance 取下确界、effort 取上确界、abort 集取交、集成偏差超限即收缩）。核心创新不是"多算"，而是**消除裸奔边界**：任一步至少有两张独立证书兜着，单张被污染时共识自动退到其余证书，而不是直接失控。重叠带来的重复推理用**滚动复用证书**摊销——下一块复用上一块在重叠区的已认证前缀，只对新增 K−s_g 步做新 rollout。高风险区（K_eff 小）自动加密重叠（s_g 小），低风险区放宽——**分块分辨率变成安全预算的函数**。

**灵感 2（快速原型 → 影子合成与原型先行）**
直觉：v11 的最大风险可以压成一句话——**三个守护同时坏时只能急停**。可急停是"停止"，不是"恢复"：在人群/赛场里停在原地可能仍然危险（挡路、阻挡救援、失去平衡、被后续运动物体撞上）。快速原型的工程直觉是"先搭一个能跑的最小原型，在廉价环境里试，跑通再提交"。把它编译进运行时，就是**影子原型锻造（Shadow Prototype Forge, SPF）**：守卫失效时不再直接急停，而是用复用前向模型 + 粗接触模型组成的**影子仿真**快速合成若干恢复分块（回撤、让行、蹲低、靠边），在影子中预演，只有**同时通过 v11 三重守护证书与影子证书**才提交执行；若在硬时限 T_recover 内无解，才回落到 v11 的急停。同一机制上移到治理层：新规范谓词、新策略先以"原型"身份**只进影子、不进执行**，按预注册证据预算评估后**晋升**——把"加功能"从改代码变成带证据的晋升流程。关键纪律：原型**只许收缩不许扩权**（P13 延续），且多次原型试探必须付**多重比较的统计代价**（P18），否则"多试几次总有一个过"就是新的证书套利。

两者咬合：**动作分块给出可复用、可共识的安全单元，快速原型给出在这些单元上安全试探与晋升的流程**——安全从"一次算对"变成"多次覆盖 + 可验证地试错"。证书相应升级为**共识-影子证书 Ĉ^⊙ = (ĝ_min^⊙, ê_max^⊙, β^⊙, Q_abort^⊙, δ_ens, n_cover, Ĉ^S)**。

## 1. 研究问题（轮次升级版）

- **Q1（无裸奔边界）**：如何定义重叠分块的共识证书与时间集成，使任一步都被 ≥2 张独立证书覆盖、单张证书被污染时动作仍被约束，且集成后的聚合轨迹仍满足保守余量——不因"平均"把两条各自安全、方向相反的命令平均成"看起来安全"却穿越障碍？
- **Q2（有恢复的兜底）**：如何在 T_recover≤40ms 内用影子仿真合成并验证恢复分块，使提交行为可证支配于 v11（不扩权），影子-现实失配被证书余量吸收，且无解时严格回落到 v11 急停？
- **Q3（有统计纪律的原型晋升）**：如何让新规范/新策略以影子原型身份评估、按证据预算晋升，并对 N 次原型试探（含策略采样这类隐式候选）做多重比较校正，使晋升不引入未验证行为、不因证书套利而虚高通过率？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 无裸奔边界律（No-Naked-Boundary, EOC）**
任一执行步必须被至少 m≥2 张有效证书覆盖；共识取最保守（clearance 下确界、effort 上确界、abort 集交），集成偏差超过 δ_ens 即判共识无效并收缩；只有重叠覆盖无法维持时才退化为 v11 单证书行为——这是**声明退化**，不是默认路径。

**P17 原型先行律（Prototype-First, SPF）**
未经影子验证的恢复动作与新规范不得进入执行；影子验证失败/超时一律回落到 v11 既有路径（急停或收缩剖面），原型不得扩大可行行为集。

**P18 试探付价律（Trial-Pays-Price, SPF）**
每增加一次原型试探或候选（含策略采样）必须按序贯检验或 Bonferroni 类校正降低单次通过阈值，使族错误率 ≤α_family；禁止"多试择优"绕过证书。隐式搜索（n 个候选里挑最好）与显式原型一视同仁。

## 3. 与基线的接口（如何退化）

- EOC 失效（重叠调度不可用/时钟漂移/复用校验失败）⇒ 回退定长不重叠分块，行为等价 v11（定义 553 原样）；
- 共识不可得（覆盖数<2 或 abort 集交为空）⇒ 收缩到单证书；单证书也失效 ⇒ v11 五检守卫中止；
- SPF 失效（影子模型不可用/超时/仿真发散）⇒ 直接走 v11 abort/e-stop 路径，不产生新行为；
- 原型未晋升 ⇒ 严格 shadow-only，对执行零影响；晋升后首次失败 ⇒ 立即降级并留痕；
- 其余沿 v11 九级退化链（GSCF→SRA→JSSE→STF→NRB→AC→ID→MW→v8）。

## 4. 预期贡献

1. **无裸奔边界的重叠分块证书**：把 v11 块边界的单点失效从结构上消除，单证书污染下动作仍被其余证书约束（引理 97–98）；
2. **有恢复的硬实时兜底**：影子原型在 T_recover 内合成受证书约束的恢复动作，只有无解才急停，急停率显著下降且不扩权（引理 99–100）；
3. **带统计纪律的原型晋升**：新规范/策略的"影子上线—证据评估—晋升/降级"流程 + 多重比较校正，治理不靠改代码而靠证据（引理 101）；
4. **E611–E630** 覆盖共识标定、集成不安全反例、边界注入、复用偏差、影子失配、恢复活性、多重比较、组合压测与长跑。

## 5. 本轮最大风险

**一句话**：时间集成把"各自安全"的分块命令做凸组合，而在接触不连续/非线性动力学下凸组合**未必安全**（绕障左/右两条安全弧的平均线可能正中障碍），影子原型又在失配模型里"验证通过"可能更危险的恢复动作——两者叠加会让系统在"看起来更连续、更有兜底"的外表下产生 v11 根本没有的新失效模式；若多重比较校正只覆盖显式原型而漏掉分块搜索的 n=64 候选，隐式搜索仍能偷偷完成证书套利。

| m | 覆盖重数：m=⌈K/s_g⌉；无裸奔要求 m≥2 |
| C_t | 时刻 t 的覆盖分块集：{ζ_i | t_i ≤ t < t_i+K}，稳态 |C_t|=m |

**定义 562（重叠分块格）** 分块 ζ_i 在 t_i=i·s_g 生成，长度 K（步）。稳态覆盖集 C_t={ζ_i | t_i≤t<t_i+K}，|C_t|=m=⌈K/s_g⌉。无裸奔条件 m≥2。高风险区（K_eff 小）取 s_g=1 最大化重叠；低风险区可取 s_g=K_eff/2，使重叠开销随风险下降。

**定义 563（时间集成与偏差）** u_t^⊕ = Σ_{i∈C_t} w_i(t)u_t^{(i)} / Σ w_i(t)，权重取三角核 w_i(t)=min(t−t_i+1, t_i+K−t)−1>0（近期块权重高）。集成偏差 δ_t=max_i‖u_t^⊕−u_t^{(i)}‖。**注意**：集成不是安全证书，只是命令平滑；安全由定义 564 的共识证书另行保证。

**定义 564（共识证书）** Ĉ_t^⊙ 的分量：
- ĝ_min^⊙ = min_{i∈C_t} ĝ_min^{(i)}（clearance 下确界）；
- ê_max^⊙ = max_{i∈C_t} ê_max^{(i)}（effort 上确界）；
- β^⊙ = max_i β^{(i)} + L·δ_t（L 为残差动力学 Lipschitz 常数）；
- Q_abort^⊙ = ∩_i Q_abort^{(i)}，若非空且两两 Hausdorff 距离 ≤δ_abort；否则 ∅；
- n_cover=|C_t|；valid ⇔ 所有 Ĉ^{(i)} 有效 ∧ Q_abort^⊙≠∅ ∧ δ_t≤δ_ens ∧ δ_proj≤δ_proj^max。
共识是**保守交集**：只有当每一张覆盖证书都允许时，动作才被放行。

**定义 565（滚动复用证书）** 新块 ζ_{i+1} 与 ζ_i 的重叠前缀为 [t_{i+1}, t_i+K)。若 ‖x_{t_{i+1}}−x_{t_i}‖_W≤δ_reuse 且观测偏差 ≤δ_obs，则前缀证书取交集（clearance 取 min、effort 取 max、β 取 max）直接复用，仅对新增 K−s_g 步做新 rollout；否则整块重算。复用计数 r_i 超过 R_max 或任一守卫失败即强制重算。

**定义 566（影子原型）** 候选分块 ζ 在影子模型 Ŝ=(F̂_q, 粗接触模型, C_q_safe) 中从当前状态估计出发预演，得到预测轨迹、ĝ^S（最小间隙）、ê^S（最大力矩）、ρ^S（abort 可达性）、影子证书 Ĉ^S=(ĝ^S, ê^S, ρ^S, β^S)。影子**绝不驱动执行器**。

**定义 567（原型-提交算子）** Commit(ζ) 当且仅当 Ĉ^⊙(ζ) valid ∧ Ĉ^S(ζ) valid ∧ 提交时刻 ≤ 合成起点+T_recover ∧ (ĝ_min^⊙−ε_shadow ≥ d_safe)。任一条不满足即不提交。

**定义 568（快速恢复合成）** 守卫失效时，候选集 R=R_lib（预认证库）∪ Repair(ζ_fail)（模型预测修复：以回撤/让行/蹲低/靠边为目标的采样与局部优化）。按影子余量排序，逐个过 Commit 判据；在 T_recover 内选出第一个通过者提交。全部失败或超时 ⇒ v11 e-stop。

**定义 569（原型晋升）** 新规范谓词或新策略 π 以原型身份注册，携带证据预算 (N_eval, 覆盖集, ε_proto)。影子评估期间 π 对执行零影响；当 Π_promote（含序贯检验）全部通过才晋升；晋升后首次线上失败即降级，并把失败样本回灌证据集。全过程入台账 Λ。

**定义 570（族错误率与选择校正）** 若本轮测试 N_c 个候选（显式原型 + 策略采样），单候选阈值 α'=α_family/N_c（Bonferroni）或采用 SPRT。策略采样取最优时使用**选择校正余量** β_sel=β+z_{1−α_family/N_c}·σ̂；只有 ĝ_min−β_sel≥d_safe 的候选才可提交。隐式搜索不得豁免。

**定义 571（分块风险账）** Λ 扩展记录：每边界 (n_cover, 共识有效性, δ_t, δ_proj, 复用计数 r_i)；每次原型决策 (原型 id, α', 影子证书, 晋升/降级)；恢复事件 (候选数, 影子余量, 是否急停)。哈希链 κ_h=256 不变。

**定义 572（自适应重叠度）** s_g(t)=K_eff(t)（无重叠）当 m 目标无法满足；否则 s_g(t)=max(1, ⌊K_eff(t)/m_target⌋)，m_target=2（默认）或 3（高规范场景）。K_eff 沿 v11 定义 553。

**定义 573（集成投影残差）** δ_proj=‖Proj_{C_q_safe}(u_t^⊕)−u_t^⊕‖_W；δ_proj>δ_proj^max ⇒ 共识无效。投影器沿用 v11 JSSE（定义 557）。

**定义 574（影子失配界）** ε_shadow=sup_{x∈D_val}‖Ŝ(x)−S(x)‖，在验证域 D_val 上由 E615 标定；提交判据用它把影子乐观折算进证书余量。

**定义 575（恢复活性）** 若影子可达集内存在通过 Commit 的候选，则合成在 T_recover 内找到它且概率 ≥1−ε_synth；ε_synth 由 E616 标定（含求解器随机性）。

# IP-365 ElasticOverlapChunker：滚动重叠 + 时间集成 + 共识证书
class ElasticOverlapChunker:
    def __init__(self, base_chunker, m_target=2, delta_ens=0.02,
                 delta_proj_max=0.01, delta_reuse=0.03, R_max=8,
                 alpha_family=0.05):
        self.base = base_chunker          # v11 TriGuardChunkCertifier
        self.m, self.d_ens = m_target, delta_ens
        self.d_proj_max, self.d_reuse = delta_proj_max, delta_reuse
        self.R_max, self.alpha = R_max, alpha_family

    def stride(self, K_eff):              # 定义 572：分辨率=安全预算函数
        if K_eff < 2:
            return K_eff                  # 单步，无重叠
        return max(1, min(K_eff, K_eff // self.m))

    def roll(self, state, ctx, K_eff):
        s_g = self.stride(K_eff)
        cover = self._cover_set(ctx.t)
        # 定义 565：尝试复用重叠前缀证书
        reused = None
        for z in cover:
            if z.state_deviation(state) <= self.d_reuse and z.reuse_ok(R_max=8):
                reused = z.reuse_prefix(state)
                break
        fresh = self._fresh_rollout(state, K_eff)   # 只扩 K_eff-s_g 步
        chunks = cover + [fresh]
        return ConsensusCertifier.combine(chunks, reused, self.d_ens,
                                          self.d_proj_max)

    def _cover_set(self, t):              # 维护 ζ_i，丢弃 t_i+K<=t 的块
        return [z for z in self.active if z.t_i <= t < z.t_i + z.K]

    def _fresh_rollout(self, state, K):
        cert = self.base.generate_chunk(state, ...)   # v11 三重守护
        return cert


class ConsensusCertifier:
    @staticmethod
    def combine(chunks, reused, delta_ens, delta_proj_max):
        valid = [c for c in chunks if c.cert.valid]
        if len(valid) < 2:
            return ConsensusCert(n_cover=len(valid), valid=False)  # 退单证书
        g = min(c.cert.g_min for c in valid)
        e = max(c.cert.e_max for c in valid)
        beta = max(c.cert.beta for c in valid)
        q_abort = intersect_aborts([c.cert.Q_abort for c in valid])
        if not q_abort:
            return ConsensusCert(n_cover=len(valid), valid=False)
        # 时间集成命令 + 偏差
        u_ens, delta_t = temporal_ensemble(valid)
        delta_proj = projection_residual(u_ens)       # 定义 573
        ok = (delta_t <= delta_ens and delta_proj <= delta_proj_max)
        return ConsensusCert(g, e, beta + L_LIP * delta_t, q_abort,
                             delta_t, len(valid), u_ens, valid=ok)


# IP-366 ShadowPrototypeForge：影子合成 → 双证 → 提交/急停
class ShadowPrototypeForge:
    def __init__(self, forward_q, contact_model, jsse, ledger,
                 T_recover=0.040, eps_shadow=0.005, alpha_family=0.05):
        self.Fq, self.contact, self.jsse = forward_q, contact_model, jsse
        self.ledger = ledger
        self.T_rec, self.eps_shadow = T_recover, eps_shadow
        self.alpha = alpha_family
        self.library = {}                  # 预认证恢复分块
        self.prototypes = {}               # 未晋升：shadow-only

    def recover(self, state, consensus, ctx):
        t0 = now()
        candidates = list(self.library.values()) + self._repair(state, ctx)
        candidates.sort(key=lambda z: self._score(z, state), reverse=True)
        # 定义 570：族错误率校正 + 选择校正余量
        n = max(1, len(candidates))
        alpha_adj = self.alpha / n
        z_bonf = norm_ppf(1 - alpha_adj)
        for z in candidates:
            if now() - t0 > self.T_rec:
                break
            shadow = self._shadow_cert(z, state)          # 定义 566
            if not shadow.valid:
                continue
            if not consensus.valid:
                continue
            if not self._commit_ok(consensus, shadow, z, z_bonf):
                continue
            self.ledger.append_recovery(state.t, z.id, shadow, n, alpha_adj)
            return ('commit', z, shadow)
        self.ledger.append_recovery(state.t, None, None, len(candidates),
                                    alpha_adj, aborted=True)
        return ('v11_abort', None, None)                 # 等价 v11 e-stop

    def _commit_ok(self, cons, shadow, z, z_bonf):
        # 定义 567：共识 + 影子 + 失配 + 硬时限
        return (cons.valid and shadow.valid
                and (cons.g_min - self.eps_shadow >= self.d_safe)
                and (shadow.g_min - z_bonf * shadow.sigma >= self.d_safe))

    def _shadow_cert(self, z, state):      # 在 Ŝ 中预演，绝不触执行器
        traj = self.Fq.rollout(state, z.actions)
        g = min_clearance(traj, state.scene)
        e = max_effort(traj, self.contact)
        rho = self.jsse.reachable_within(z.Q_abort, traj)
        return ShadowCert(g, e, rho, self.eps_shadow, valid=rho)

    def _repair(self, state, ctx):         # 回撤/让行/蹲低/靠边 的采样修复
        return model_predictive_repair(self.Fq, state, ctx.goal,
                                       modes=['retreat', 'yield', 'crouch',
                                              'edge'], deadline=self.T_rec)

    def promote(self, proto_id):           # 定义 569：晋升需预注册证据
        p = self.prototypes[proto_id]
        if sequential_test_pass(p.evidence, self.alpha):
            p.promoted = True
        return p.promoted


# IP-354（升级）：共识-影子证书执行器
class ConsensusChunkCertifier(ElasticOverlapChunker):
    def __init__(self, *a, spf=None, **kw):

## 4. 推导

**引理 97（共识证书的保守性与边界消除）**
(a) 对任意覆盖块 i，有 ĝ_min^⊙≤ĝ_min^{(i)}、ê_max^⊙≥ê_max^{(i)}、Q_abort^⊙⊆Q_abort^{(i)}；故在共识下提交 ⇒ 在每一张单独证书下提交，共识**只收紧不放宽**。
(b) 若 s_g≤K/2 则 m=⌈K/s_g⌉≥2，任一步被 ≥2 张证书覆盖，**不存在无证边界**；任一张证书失效时，若剩余覆盖仍 ≥2 且 abort 交集非空，共识继续有效并自动收紧到剩余证书；若不足，则收缩/中止，绝不扩权。
(c) 因此共识行为集 ⊆ v11 单证书行为集（支配性）。证明：min/max/交集均单调，Commit 谓词要求所有覆盖证书有效。∎

**引理 98（时间集成的安全条件与复用界）**
(a) **凸组合不自动安全**：存在两条各自满足 ĝ≥d_safe 的绕障弧 u^{(1)}、u^{(2)}（分别从障碍左、右绕过），其平均 u^⊕ 穿过障碍，ĝ(u^⊕)<d_safe。故仅当以下之一成立才允许集成：(i) 在信任域内约束可线性化且所有 u^{(i)} 位于同一局部凸安全集，凸组合仍可行；(ii) 集成后经 JSSE 投影且投影残差 δ_proj≤δ_proj^max，并对投影结果重新认证。
(b) 若每张证书在 L-Lipschitz 动力学下有 margin β_i，则集成轨迹 margin ≥ min_i β_i − L·δ_t；要求该值 ≥0 即 δ_t≤min_i β_i/L，据此取 δ_ens。
(c) 复用：β(t)=β+L_reuse·‖x_t−x_{t_i}‖，在 ‖x_t−x_{t_i}‖≤δ_reuse 时保守；超限或守卫失败强制重算。∎

**引理 99（影子原型的支配性与非扩权）**
提交要求「共识 valid ∧ 影子 valid ∧ ĝ_min^⊙−ε_shadow≥d_safe ∧ 选择校正余量满足」。故提交的恢复动作同时受 v11 三重守护证书与影子证书约束，并未引入 v11 之外的新行为；若候选集无解或超时，严格回落到 v11 e-stop。因此恢复路径的物理行为集 ⊆ v11 可行集 ∪ {v11 已认证动作} = v11 可行集。证明：Commit 是合取谓词，任一不满足即不提交；回落路径与 v11 逐行相同。∎

**引理 100（恢复活性与急停率下降）**
设预认证库覆盖失效情境的比例为 p_lib，修复搜索在 T_recover 内找到通过 Commit 候选的概率为 p_repair（≥1−ε_synth，定义 575）。则急停概率 P_stop=(1−p_lib)(1−p_repair)+ε_timeout ≤ v11 的 1（v11 在守卫失效时必停）。当 p_lib+p_repair>0 时严格下降；且由引理 99，下降不以扩权为代价。∎

**引理 101（原型晋升的证据守恒与族错误率）**
(a) 晋升前原型 shadow-only ⇒ 零执行影响；晋升门要求 Π_promote 与序贯检验通过，故「未验证原型进入执行」的概率 ≤α_family。
(b) 测试 N_c 个候选并择优会抬高通过率；采用 α'=α_family/N_c 或选择校正余量 β_sel=β+z_{1−α_family/N_c}σ̂ 后，族错误率 ≤α_family；该校正对策略采样的隐式候选同样生效（定义 570），故堵住证书套利。
(c) 晋升后首次失败即降级，失败样本回灌；append-only 台账 + 哈希链保证可审计与不可抵赖。∎

## 8. 本轮最大风险

**一句话**：时间集成把"各自安全"的分块命令做凸组合，而接触不连续/非线性动力学下凸组合未必安全——两条分别从障碍左右绕过的安全弧，其平均轨迹可能正中障碍（引理 98 已把它写成显式反例而非隐藏假设）；影子原型又可能在失配模型里"验证通过"一个现实中更危险的恢复动作（ε_shadow 一旦低估就直接侵蚀 Commit 余量）；两者叠加使系统在"更连续、更有兜底"的外表下产生 v11 根本没有的新失效模式；而若多重比较校正只覆盖显式原型、漏掉分块搜索的 n 个隐式候选，则"多试择优"仍能完成证书套利——这正是 P18 要盯死的漏洞。
