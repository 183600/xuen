# 第 4 轮（灵感循环第 4 轮；本轮灵感：「实例分割」×「本体感知」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。两个新灵感各沿一条轴升级 InstructGauge，且任一环节不可用都必须能一键退回；实例分割与本体感知是增强项、不是依赖项。

## 0. 直觉与动机

**灵感 1（实例分割 → 把「哪个东西」从区域变成可追踪的个体）**
直觉：第 3 轮的接地还停在「类别 + 区域」层面——「左边金属件」可能对应一片像素里的许多候选。人类工程师说的「左边那**一个**金属件」暗含个体同一性：它在时间上是同一个东西，能被指着、能被接触、能跨帧追踪。实例分割（部件级/amodal 掩码 + 跨帧 track id）正好提供这种「可数、可追踪、可指认」的个体身份。于是接地从 `referent → region/class` 升级为 `referent → (instance_id, part_id)`：歧义从「像素归属」变成「身份归属」，后者可被显式度量（唯一性 margin、track 连续性）。
代价是引入新的失败模式：**ID 切换**（merge/split/遮挡后重识别）——一个视觉上稳定的掩码可能指向错误的个体，且错误会随时间持续。

**灵感 2（本体感知 → 把「我以为我做了」变成「我确实做了/碰到了」）**
直觉：第 3 轮的最大隐患是分块把证据陈旧窗口拉长到 K 步。但机器人有一路**不依赖外部感知、频率远高于 50Hz、且与动作因果绑定**的证据：本体感知（关节编码器、力矩、IMU、末端位姿/力）。它天然是「自回执」——每一步动作执行后，扭矩/位形/接触力会立刻反映「是否真的按预测接触了目标、是否撞到了别的东西、是否打滑」。这恰好把「规划摊销（每 K 步一次昂贵决策）」与「物理验证频率（每步甚至每毫秒一次廉价自检）」**解耦**：决策仍按 K 摊薄，但物理异常检测延迟从 (K−1)Δ 收缩到 ~T_p。
但要诚实：本体感知只对**可观测异常**有效。表面缺陷、颜色/反射异常、不引起力矩变化的暗病，它看不见——它的安全收益是**有观测盲区**的，不能当万能证据。

**灵感 3（两者耦合 → 「实例-接触」双模态接地，用物理接触去证伪视觉身份）**
直觉：实例分割说「这是 A 件」，本体感知问「你摸到的力矩/接触力像 A 件还是 B 件？」。两者交叉检验，得到一个**可证伪的具身接地**：只有当视觉身份与接触签名**同时**自洽，才允许把关于 A 件的主张写入证据链。这比任何单一模态都强，因为物理接触很难被视觉幻觉伪造；反过来，接触签名也能**纠正**视觉 ID 切换（「视觉说是 A，但力学像 B」⇒ 报警重接地）。
最危险的耦合不是两者都错，而是**两者错得自洽**：ID 已经切到 B，而接触模型/场景恰好在 B 上也产生相似签名，于是证书「证据链完整、物理自洽」，却把主张绑到错误个体；或者异常在接触签名上根本不可观测。系统会给出**看起来已被物理验证、实际上对象错误**的结论——这是「可审计的假阳性」。

## 1. 研究问题（本轮要回答什么）

- **Q1（实例接地）**：实例分割能否把第 3 轮的语义歧义压下去？其残余失败模式（ID 切换）能否被显式检测与隔离，而不是被掩码的稳定性掩盖？
- **Q2（本体感知的交换条件）**：本体感知能把物理异常检测延迟从 (K−1)Δ 缩到 T_p，但只在可观测子集上成立；可观测性如何形式化，收益与盲区如何同时量化、且不把盲区算进收益？
- **Q3（耦合的可靠性）**：实例分割 × 本体感知的交叉检验，能否在「两者自洽地错」时仍保持可证伪？残余的 consistent-but-wrong 风险如何界住，而不是声称消除？

## 2. 三条设计原则（雏形，正式化见产物区定义 448–466）

**P1 个体同一性优先（Instance Identity before Semantics）**
接地的第一公民是 `instance_id`，而不是类别或像素。只有唯一性 margin 足够、track 连续、且动作下身份稳定的个体才可被指代；否则输出 ⊥（退回默认目标）。形式化方向：`ρ` 合法 ⇔ `id ∈ C_id ∧ conf ≥ τ_id ∧ (top1−top2 ≥ m_id) ∧ track_stable(id, w)`。这把「语义是否对」转成「身份是否唯一且稳定」这个可度量问题。

**P2 具身可观测性（Embodied Observability，诚实边界）**
本体感知只对可观测异常 `Obs(A)` 承诺收缩延迟；对 `A\Obs(A)` 明确不承诺，且必须显式报告「未观测」。安全论证必须写成 `可观测部分 + 不可观测部分` 两段之和，禁止把盲区算进收益。这是本轮最重要的「反自欺」纪律。

**P3 双模态证伪（Bimodal Falsification）**
任何实例主张必须同时通过视觉身份与接触一致性；任一失败即拒绝/重接地，而不是取「多数票」。物理接触优先于视觉幻觉（接触更难伪造），但接触不可观测时降级为纯视觉并**标注置信折减**，绝不静默升格为双模态。

## 3. 与基线的接口（如何退化）

- 实例分割不可用 / 唯一性不足 / ID 不稳定 ⇒ 退回 NLI-Box 的类别-区域接地（InstructGauge）；
- 本体感知不可用 / 延迟 > Δ / 自检故障 ⇒ EVC 退化为 CVC（InstructGauge 的分块验证）；
- 接触模型不可用或不可观测 ⇒ ICB 退化为 NCB（只绑回执），并显式标注 `visual-only`；
- 实例分层样本不足 ⇒ 回退 SC-Cal 的指令层、再回退全局；
- InstructGauge 失效 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个「实例身份优先」的接地口径，把语义歧义换成可度量的身份问题，并显式建模 ID 切换这一新失败模式；
2. 一个「规划摊销与验证频率解耦」的执行器：决策按 K、物理否决按 T_p，并给出**可观测性分级**的延迟收缩界（而非笼统宣称变快）；
3. 一个「实例-接触」双模态证伪绑定，既能检测/纠正 ID 切换，也诚实暴露 consistent-but-wrong 残余；
4. 一条完整可证伪路径：E457–E472 覆盖实例接地、ID 切换、陈旧窗收缩、可观测性分级、执行保真、退化等价与 sim→real 迁移。

## 5. 本轮最大风险

**一句话**：本体感知把「已接触/已执行」误当成「已正确接地」——当 ID 切换让接触签名与错误实例自洽、或缺陷在力矩/位形上不可观测时，系统产出的是**证据链完整、物理自洽但对象错误**的证书；最危险的不是漏检，而是可审计的假阳性。

## 2. 形式化定义（要点）

**定义 448（实例分割与部件掩码）** `Seg_t: I_t → {M_j}_{j=1..n_t}`，`M_j ⊆ Ω_t`；`part: M_j → {p_1..p_m} ∪ {∅}` 给出部件分解；`amodal(M_j)` 给出被遮挡外延。实例类型 `type(M_j) ∈ O_onto`（沿用本体白名单）。分割只提供**单帧分区**，不提供跨帧身份——身份必须由定义 449 显式给出。

**定义 449（实例身份轨道与动作稳定性）** `T_id: {M_j}^{(t)} → {id} ∪ {⊥}` 为跨帧关联器；`track_stable(id, w)` 指 `id` 在窗口 `w` 内连续且 mask 漂移 `≤ δ_m`。**动作稳定性**：执行动作 `a` 后身份不因遮挡/形变/接触而改变，即 `T_id(Seg_{t+1} ∘ f_a) = T_id(Seg_t)`；否则该实例在 `a` 下不可作为接地对象。

**定义 450（实例接地 ρ 与可指认性）** `ρ = (id, part, conf, m_id, C_id)`；接地合法 ⇔ `id ∈ C_id` ∧ `conf ≥ τ_id` ∧ 唯一性 margin `top1 − top2 ≥ m_id` ∧ `track_stable(id, w)` ∧ `type/part ∈ O_onto`。任一失败 ⇒ `ρ = ⊥`。与第 3 轮 `Plan(ι) ⊆ Plan_ToolGauge` 一致，实例只做**子集选择**、不扩能力。

**定义 451（本体感知自状态与自回执）** `σ_t^p = (q, q̇, τ, x_ee, ẋ_ee, W_ee, IMU)`，采样周期 `T_p`（`f_p = 1/T_p ≥ 1/Δ`）。自回执 `RS_t^p = (σ_t^p, t, source)` 是**自因果**证据：只依赖已执行动作与机器人自身，不依赖外部场景重建，因而与外部感知在误差上解耦。

**定义 452（接触签名与预测接触模型）** `χ_t = (τ_res, F_ext, slip, vib)`；`χ̂_{id,part}(a, σ^p)` 为**预注册**接触模型（由 `R_inst` 给出，非在线自由拟合，避免用同一批数据自证）。接触残差 `r_c = d(χ_t, χ̂_{id,part}(a_t))`。

**定义 453（接触一致性检验）** 在层内可交换下用校准集取残差分位 `λ_c`；`still_contacting(ρ, χ) ⇔ r_c ≤ λ_c`。不满足 ⇒ 接触与所声称的 `(id, part)` 不一致：或 ID 切换、或滑移、或误碰。

**定义 454（执行保真度）** `fid_t = 1 − d(σ_t^p, σ̂_t^cmd)/D_scale`；`exec_ok ⇔ fid_t ≥ ρ_min`。持续 `fid < ρ_min` ⇒ 执行器故障或被外力阻断，中止块并报 `exec_failed`。

**定义 455（具身有效性证书 EmbCert）** 扩定义 435：提交边界 `t` 须同时满足 `φ_pre^C(σ_t)`、`still_grounded(ι, σ_t)`、`drift(σ_t, σ̂_t^C) ≤ δ_c`、`still_contacting(ρ, χ_t)`、`exec_ok`、`|τ_res| ≤ τ_max`。任一失败 ⇒ 只执行安全前缀 `a_{1:t−1}`，出证 `EmbCert(C, verified_prefix=t, instance_trace, contact_trace, exec_trace)`。把第 3 轮的「逐格否决」升级为「逐格否决 + 本体否决」。

**定义 456（本体可观测性与分级陈旧界）** 对异常集 `A`，`Obs(A) ⊆ A` 为在 `χ/σ^p` 上可分离的异常子集。检测延迟 `L(A) = T_p + δ_c` 若 `A ∈ Obs(A)`，否则 `L(A) = (K−1)Δ + δ_d`。**安全收益只在 `Obs(A)` 上承诺**，且输出必须显式报告 `A \ Obs(A)`（未观测部分），禁止把盲区计入收益。

**定义 457（有效盲窗）** `K_eff = ⌈K·Δ / T_p⌉`。当 `T_p ≤ Δ` 时 `K_eff = K`（每步都可否决）；本体否决把块从「原子提交」改为「逐格提交」，但**规划决策仍每 K 步一次**——摊销（`c_d/K`）与验证频率（`1/T_p`）就此解耦，这是本轮的核心结构。

**定义 458（实例-接触主张绑定 ICB）** 扩定义 441：`Claim′ = (c, receipt_id, chunk_cert_id, id, χ, verified)`。仅当 `id ∈ C_id` 且 `still_contacting` 且回执命中时保留且 `verified = "bimodal"`；若接触不可观测 ⇒ 保留但 `verified = "visual-only"`；若接触观测到不一致 ⇒ **拒绝**（不取多数票）并触发定义 460。

**定义 459（实例分层共形 ISC-Cal）** `stratum_id(ι, ρ) = (type(id), part, contact_regime, stability_bin)`。逐层取分位 `q_{s|id}` 使 `P(h* ∈ H_s | s, id) ≥ 1−α`；若 `|C_cal^{s}| < n_min` ⇒ 回退指令层 `stratum(ι)`，再回退全局。身份共形集 `C_id` 由同一层校准得到，覆盖 `P(id* ∈ C_id) ≥ 1−α_id`。

**定义 460（ID 切换检测与隔离）** 融合三源：track 不连续、mask 与深度/位姿不一致、接触签名不匹配。任一触发 ⇒ `quarantine(id)` 并触发重接地；隔离实例不得作为任何主张对象，且其历史主张被标 `retracted`（保留审计痕迹，不改已执行的物理事实）。

**定义 461（实例注册表与能力闭包）** `R_inst` 预注册实例/部件类型及接触模型；实例接地只在 `R_inst` 内选择，不得凭空生成实例类型/部件/新物理量。对未注册实例 ⇒ ⊥（延续第 3 轮能力闭包公理，把「语言不能造工具」扩展为「分割不能造对象类别」）。

**定义 462（本体感知失效检测）** 监控：延迟 `> Δ`、力矩饱和、编码器跳变、`fid` 分布漂移。触发 ⇒ 标记 `prop_unavailable`，EVC 退化为 CVC（继续用外部回执），ICB 退化为 NCB 并标 `visual-only`。

**定义 463（接触对齐分块目标）** 扩定义 436：目标增加 `w_contact·A_contact(ι, C)`，`A_contact` 为块预测的接触可验证概率；约束 `shield(ι)`、`|C| ≤ K_MAX(ι)`、`Barrier(C)`、`B_chunk ≤ B_left` 均不变。直觉：优先规划「接触签名可区分目标实例」的探测动作，使物理证伪更有效。

**定义 464（实例分层漂移）** 扩定义 446：按实例层跟踪 `(预测收缩, 实测收缩, 接触残差)`；层内漂移 `> η_s` 连续 `q` 次 ⇒ 重接地或回退全局校准（与 P-Quarantine 共用断路器）。

**定义 465（实例接地证书 GroundCert′）** `GroundCert′ = (ι, ρ, IdentityCert, ContactCert, seg_trace)`，逐项记录身份来源、唯一性 margin、track 证据与接触证据。

**定义 466（修复解释证书 RepairCert″）** `RepairCert″ = (ι, ρ, C, EmbCert, receipts, claims)`，使人类审计可沿「指令 → 实例 → 块 → 自回执 → 主张」五级证据链复现一次修复，并区分 `bimodal` 与 `visual-only` 证据等级。

## 3. 关键算法骨架

```python
# IP-328 ISG：实例接地（注册表闭包 + 唯一性 margin + 身份共形集）
class ISG:
    def ground(self, ell, seg, tracker, registry):
        slots = self.parser(ell)
        if not instance_capability_closed(slots, registry):   # type/part ∈ R_inst
            return None                                       # ⊥：退回类别-区域
        cands = []
        for r in slots.refs:
            m = match_referent(r, seg, registry)              # 先按 type/part 过滤
            if len(m) < 1:
                return None
            top1 = m[0]
            top2 = m[1] if len(m) > 1 else None
            if top2 is not None and top1.score - top2.score < M_ID:
                return None                                   # 唯一性不足 ⇒ ⊥
            id_ = tracker.assign(top1.mask)
            if id_ is None or not tracker.stable(id_, W):
                return None                                   # 身份不稳 ⇒ ⊥
            cands.append(Ref(id_, top1.part, top1.score))
        C_id = identity_conformal(cands, registry, alpha=ALPHA_ID)
        rho  = RefSet(cands, C_id)
        return rho, GroundCertPrime(slots, rho, C_id)

# IP-329 ISV：实例稳定性证书（三源融合，含接触源）
class ISV:
    def verify(self, rho, seg, tracker, chi=None):
        reasons = []
        for id_ in rho.ids:
            if not tracker.continuous(id_, W):        reasons.append(("gap", id_))
            if tracker.mask_drift(id_) > DELTA_M:     reasons.append(("drift", id_))
            if chi is not None and not contact_consistent(rho, chi):
                reasons.append(("contact_mismatch", id_))
        return IdentityCert(rho, ok=not reasons, reasons=reasons)

# IP-330 PSR：本体感知自回执流（低层 ≥1kHz，独立于 50Hz 规划线程）
class PSR:
    def stream(self):
        while True:
            yield SelfReceipt(self.read_state(), t=now(), src="proprio")
    def contact_sig(self, rs):
        return ContactSig(
            tau_res = rs.tau - self.model.tau_nom(rs.q),
            F_ext   = self.ee_wrench(rs),
            slip    = self.slip_est(rs),
            vib     = self.vib_est(rs),
        )

# IP-331 EVC：具身否决（每步 O(1)，异常即截断到安全前缀）
class EVC:
    def commit(self, C, env, rho, psr):
        t = 0
        while t < len(C.actions):
            rs  = psr.latest()
            chi = psr.contact_sig(rs)
            ok = (C.joint_pre(env.snapshot())
                  and still_grounded(rho, env)
                  and drift(env.snapshot(), C.pred[t]) <= C.delta_c
                  and exec_fid(rs, C.cmd[t]) >= RHO_MIN
                  and abs(chi.tau_res) <= TAU_MAX
                  and (contact_consistent(rho, chi) or not psr.available))
            if not ok:
                C = C.truncate(t)                      # 只保留最后安全前缀
                break
            env.apply(C.actions[t]); t += 1
        return C, EmbCert(C, verified_prefix=t)

# IP-332 ICB：实例-接触主张绑定（不一致即拒绝，不取多数票）
def bind_claims_emb(cert, rho, receipts, chi, prop_ok):
    out = []
    for c in cert.nl_claims:
        ev = match(c, receipts)
        if ev is None:
            continue                                   # 无回执 ⇒ 剥离（沿用 NCB）
        if rho.id not in rho.C_id:
            continue                                   # 身份未覆盖 ⇒ 拒绝
        if not prop_ok or chi is None:
            out.append(Claim(c, ev, cert, verified="visual-only"))
        elif contact_consistent(rho, chi):
            out.append(Claim(c, ev, cert, id=rho.id, chi=chi, verified="bimodal"))
        else:
            out.append(Claim(c, ev, cert, verified="rejected"))   # 物理反证
    return out

# IP-333 ISC-Cal：实例分层共形（两级回退）
class ISCCal:
    def threshold(self, rho, cal):
        s = (type(rho.id), rho.part, contact_regime(rho), stability_bin(rho))
        if len(cal.get(s, [])) < N_MIN:
            s = ("instr", stratum(rho.iota))           # 回退指令层
        if len(cal.get(s, [])) < N_MIN:
            s = GLOBAL                                 # 再回退全局
        return conformal_quantile(cal[s], ALPHA)

# IP-334 EmbodiedGauge-8C：I→G→H→C→E/P→C→V→U
def embodiedgauge_8c(M, s, ell):
    out  = M.nlib.ground(ell, M.scene, M.ontology)         # I：指令接地
    iota = out[0] if out else M.default_iota
    g    = M.isg.ground(ell, M.seg, M.tracker, M.registry) # G：实例接地
    if g is None:
        rho = M.default_rho                                # ⊥ ⇒ 类别-区域接地
    else:
        iota, rho = merge(iota, g)
    if not M.isv.verify(rho, M.seg, M.tracker)[0]:
        rho = M.default_rho                                # ID 不稳 ⇒ 退化
    H    = M.lbox.hypothesize(s, M.dbox.R[s], iota)        # H
    C    = M.iac.plan_chunk(iota, H, M.tools, M.budget_left(s), M.drift_bound(s))  # C
    if not M.tcv.verify(C.as_program(), M.budget_left(s))[0]:
        C = M.numeric_fallback(H)
    cert = M.evc.commit(C, M.env, rho, M.psr)              # E/P：执行 + 本体否决
    receipts = cert.receipts
    if len(receipts) < n_min(s):
        return stub_and_red(s, "insufficient")
    mu, Sig = M.apcal.calibrate(receipts, H, s)
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
        return stub_and_red(s, "cross_failed")
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s)
    if not contract_regression(new_ec):
        return stub_and_red(s, "regression")
    M.mreg.hot_replace_at_quiescence(M.dpe, new_ec, cert.boundary)  # C
    bind_claims_emb(cert, rho, receipts, M.psr.last_chi, M.psr.available)  # V
    M.isccal.update(rho, cert)
    M.pquar.record(M.apcal.last_gain, realized_gain(receipts))
    return True                                            # U

# IP-335 主闭环（50Hz 规划不变；本体感知在低层回路异步消费）
def EmbodiedGauge_round(M, obs, audio, tac, depth, det, ell=None):
    M.seg = M.segmenter(obs, depth)          # 异步感知；缓存复用
    M.tracker.update(M.seg)
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            submit_async(embodiedgauge_8c, M, s, ell)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)  # 50Hz 主路径原样
```

## 4. 推导

**引理 59（实例接地的可辨识性与误差分解）** 在注册表闭包 `R_inst` 与唯一性 margin `m_id` 下：若 referent 描述对实例是 `m_id`-分离的，则接地唯一；否则输出 ⊥。接地错误率 `p_g ≤ p_seg + p_switch`，其中 `p_seg` 为分割错误率、`p_switch` 为窗口内 ID 切换率。
*证明骨架*：唯一性 margin 保证 top-1 与其他候选的评分差超过噪声界 ⇒ 选择稳定；身份误差事件是「分割错 ∪ 切换」的并集，用 union bound 得 `p_g`。与第 3 轮类别-区域接地相比，语义错误被替换为**可度量的身份错误**，⊥ 率显式反映歧义。

**引理 60（本体感知收缩检测延迟）** 设本体采样周期 `T_p ≤ Δ`、处理延迟 `δ_c`。若异常 `A ∈ Obs(A)`，则检测延迟 `L_prop = T_p + δ_c ≤ Δ + δ_c`；无本体时 `L_ext = (K−1)Δ + δ_d`。故 `L_prop / L_ext ≈ 1/(K−1)`（当 `δ_c, δ_d ≪ Δ`）。该结论**只对 `Obs(A)` 成立**。
*证明*：自回执每 `T_p` 产生且与已执行动作因果绑定；异常一旦进入 `χ/σ^p` 的可分支撑，即在下一个自回执被检出，至多再加一个控制延迟。

**引理 61（可观测性分级安全界）** 总期望损失 `D = D_obs + D_unobs`，其中 `D_obs ≤ p_a·c_a·(T_p+δ_c)/Δ`（线性于检测延迟），而 `D_unobs` 与第 3 轮引理 56 的界**完全相同**（未被改善）。因此 EmbodiedGauge 的安全收益严格等于 `Obs(A)` 上的延迟收缩，对盲区**零收益**，且必须显式报告 `A\Obs(A)`。
*证明*：按异常集划分求和；不可观测异常不进入 `χ`，其检测仍依赖外部回执/块边界，界不变。这是对「本体感知让一切更安全」这一过度声明的形式化反驳。

**引理 62（接触一致性检验的错误率与检出力）** 在正确身份且层内可交换下，`P(r_c > λ_c | id 正确) ≤ α`（共形保证）。当发生 ID 切换 `A→B` 时，检出力 `1−β ≥ 1 − P(d(χ̂_A, χ̂_B) ≤ 2λ_c)`；即分离度 `d(χ̂_A, χ̂_B)` 越大，接触越能纠正视觉。若两实例接触签名不可分（`d ≈ 0`），检出力退化为随机——这正是 consistent-but-wrong 的源头。
*证明*：共形分位给第一类错误 `≤ α`；第二类错误由两分布的重叠面积控制。

**引理 63（实例-接触绑定的可靠性）** 若 `id ∈ C_id` 且 `still_contacting`，则主张假阳性率 `≤ α_id + α_c + p_bind`；但当「ID 已切换且接触签名不可分」时存在**残余假阳性** `p_cw ≤ p_switch·P(不可分)`，任何后处理都无法消除（信息论下界：两假设在观测上等价）。故 ICB 的正确承诺是「**可证伪**」，而非「零假阳性」。
*证明*：三事件并集界；残余项是两假设在观测上等价的概率，由数据处理不等式给出下界。

**引理 64（实例分层共形覆盖）** 层内可交换下 `P(h* ∈ H_s | s, id) ≥ 1−α`；边缘覆盖 `≥ 1−α − Σ_s π_s TV_s − Σ_id π_id TV_id`。实例条件化进一步破坏可交换性（每实例分布漂移），故必须按 `(type, part, contact_regime, stability)` 分层；低样本两级回退按 `−2η` 优雅降级。由 E464 检验。

**引理 65（8C 严格退化等价）** `prop` 关闭 ⇒ `still_contacting ≡ true`、`exec_ok ≡ true`，EVC 逐指令等价于 CVC；`seg/tracker` 关闭 ⇒ ISG/ISV 输出 `default_rho`，接地等价于 NLI-Box；两者都关闭 ⇒ 8C 逐指令等价于 InstructGauge-7C；再逐级关闭 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。新增的 `claims/traces` 为纯投影，不改数值行为（沿用第 3 轮引理 57）。
*证明*：在关闭开关下逐一将模块替换为恒真谓词/恒等映射，程序的未涉及子图逐指令相同；投影不写回控制路径。

**引理 66（实时性：50Hz 规划与 ≥1kHz 自检分离）** 本体感知在低层回路（≥1kHz）本地消费，不进入 50Hz 规划线程；EVC 每步否决为 O(1) 查表 + 阈值比较。新增规划周期 `< 0.2ms`，继承引理 50/58 的硬实时结论；接触一致性检验为 O(1)（预注册模型 + 分位查表）。
*证明*：唯一新增跨线程共享是只读自回执快照（无锁/双缓冲）；否决路径无分配、无前向推理。

## 8. 本轮最大风险

**一句话**：`EVC` 的接触自洽与 `ISG` 的实例身份可能**同时错且互相印证**——ID 已切换但两实例接触签名不可分，或异常本就落在本体盲区；此时 `EmbCert`/`RepairCert″` 证据链完整、物理自洽，却把主张绑到错误对象。EmbodiedGauge 能承诺的是「可被物理证伪」，不能承诺「物理已证真」；残余 consistent-but-wrong 只能靠 E460/E463/E472 主动暴露，而不能被消除。
