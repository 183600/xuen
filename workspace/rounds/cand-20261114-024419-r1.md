# 第 71 轮（承接第 70 轮「BELIEF-RAS」IP-264~274；灵感循环新循环第 1 轮；本轮灵感：「移动底盘」×「联邦学习」）

> R70（BELIEF-RAS）把 epistemic 从「动作模态」推进到「世界状态后验 b_t」，并用贝叶斯 VoI 选择看/问/触。但它默认两件事：**（a）这个后验只属于一台机器、一个地点、一个数据分布；（b）不确定性只能靠本机再多看/多问来降低**。移动底盘一出现，这两个默认同时破裂：机器人可以**把传感器搬到未知处**，也会**把已知处留在身后**；而联邦学习让一个机队可以**不共享原始数据就共享统计强度**。于是出现一个 R70 无法回答的新问题：**当「开过去看」与「问别的机器人」都能降低不确定性时，应该选哪个？当两者的答案互相矛盾时，又该信谁？**
>
> 本轮两个灵感正好补上两块缺失：
> - **移动底盘**把 epistemic 从「无坐标的标量」变成**有地址的场**：同一台车在地毯、环氧地坪、斜坡、电梯口上的模型有效性完全不同；移动既是获取信息的手段，也是最高风险的 action；
> - **联邦学习**让机队可以**运输统计量而不运输原始数据**，但它同时带来非 IID、拜占庭、覆盖伪造、轨迹隐私与陈旧先验。
>
> 核心命题：**把 b_t 升级为「空间索引、机队分布」的认知场 E_i(x)；把移动与联邦统一为两种信息运输；用传输调整的 VoI 在「开车去查」与「问机队」之间决策；用 FGate + 本地实证 + 个性化残差防止联邦共识幻觉；安全侧仍只由本地认证器负责。** 命名 **FLEET-RAS**（Federated Localized Epistemic Estimation and Transport for Risk-Aware Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「我相信哪个世界状态」，R71 问「**该把车开到哪里去获得证据，又该在多大程度上相信别的车告诉我的事**」——底盘是能把传感器送到未知处的腿，联邦是能借来别人经验的记忆；但记忆可以被投毒，腿也可能把车开进它自以为熟悉的幻觉。

## 0. 直觉与动机

**灵感 1（移动底盘 → epistemic 第一次有了「地址」）**
直觉：R70 的 b_t 是一个「无坐标」的后验——它知道世界可能是什么样，却不知道「我是在哪里知道这件事的」。移动底盘把这个问题逼出来：同一台机器人，在实验室地毯上校准得很准，到了环氧地坪、斜坡、金属格栅、电梯口，轮滑、摩擦、定位漂移、载荷耦合全都变；**模型的有效性本身是空间局部的**。于是「我不知道」不再是一个标量，而是一张地图：哪些区域我有本地证据，哪些区域只有别人的经验，哪些区域谁都没去过。底盘的第一重身份因此不是「会走」，而是**能把传感器搬到信息所在处**。

**灵感 2（移动底盘 → 移动既是信息动作，也是最高风险动作）**
直觉：R69/R70 的信息动作（看、问、触）大多可以原地完成；底盘的「去看」却要消耗能量、改变位置、穿越人群、把机械臂带到新的接触条件。更糟的是，移动会**改变被估计的世界**：轮子打滑改变了里程计，底盘倾斜改变了重力向量，进入新房间改变了光照与语义先验。所以「去获得信息」与「保持安全」第一次在同一动作上直接冲突。移动不能由信息价值单独驱动，必须由**信息价值/风险成本**共同驱动。

**灵感 3（联邦学习 → 统计强度可以运输，但信任不能运输）**
直觉：一台底盘的一生只能覆盖有限的地点与工况；一个机队却可以覆盖几百个家庭、仓库、医院。联邦学习让我们**不共享原始轨迹/图像**也能共享「世界大致怎么运作」。但这里有一个必须说清的边界：FedAvg 可以把参数搬过来，却搬不来**「这个参数在 x 处是否真的被数据支撑过」**。敌意客户端可以声称「我去过 x、那里一切正常」，而聚合算法只会把声明当权重，不会去现场核实。**统计可以联邦，信任必须落地**——这是本轮的关键命题。

**灵感 4（非 IID → 联邦共识幻觉与负迁移）**
直觉：移动底盘天然是非 IID 的极端案例：每台车的轮胎磨损、载荷、传感器外参、常跑楼层都不同。把它们的模型直接平均，会得到一个「哪里都还行、哪里都不精」的全局模型；在某些局部，它甚至比单机模型更差，而且**更自信**。这叫「联邦共识幻觉」：越多机器人同意，越不代表它们真的见过。解法不是拒绝联邦，而是把模型拆成**共享结构 + 本地残差**：共享「世界的一般规律」，保留「这台车在这个地面的校准」；并用一个可测的异质度 `D_het` 做负迁移门控。

**灵感 5（信息运输的统一视角 → 开车去查 vs 问机队）**
直觉：把两件事放在同一张账单上：
- 移动底盘把**传感器运到信息处**，成本是能量、时间、风险；
- 联邦学习把**统计量运到传感器处**，成本是通信、时延、隐私、投毒风险。
两者都是「信息运输」。于是决策不再是「要不要探索」，而是「**用哪种运输方式，单位成本换来的熵下降最多**」。如果机队已经在 x 处有可信覆盖，问比开过去便宜；如果 x 是覆盖空洞，问的收益为零，只能开过去或承认不知道。联邦给方向，底盘给证据；底盘验证后的新证据再以 DP 方式回流机队。这就是一个**联邦主动学习闭环**。

**灵感 6（安全与隐私 → 联邦只能在影子层，底盘必须过双证）**
直觉：安全关键系统不能让云端模型直接写实时控制器。联邦更新只能进入「影子层」：先过 **FGate**（来源、时效、DP 预算、拜占庭报告、本地影子验证），再在版本边界原子换装；实时控制环永远用本地已认证模型。底盘的移动还要过 **BAC**（base-arm coordination certificate）：机械臂是否收拢、重心是否稳定、地面摩擦是否足够、急停距离是否留够。再加上移动带来的物理隐私（摄像头/麦克风进入私人空间）与轨迹隐私（联邦更新可被反演），本轮必须同时交付隐私预算与实证纪律，否则「会走的联邦机器人」就是一个会移动的监控器。

## 1. 形式化定义（增量：定义 331–346）

**定义 331（FLEET-RAS 总览）** FLEET-RAS = (BSE†, SEF, FTM, TAV, MoCoP, FGate, BRA, GDP, BAC, CAA, VQAuditor-III, AIC†, J_FLEET)。四不变式：
(i) **实时流零学习写操作**（继承 R70 定义 310-i）：联邦上传/下载与模型换装都在安全边界，绝不插入实时控制环；
(ii) **联邦隔离**：原始观测/轨迹不出本机；只出有界、加噪、签名、可审计的统计摘要；实时控制永不阻塞于网络；
(iii) **移动安全**：信息驱动的底盘运动必须通过 C-RAS-WM 与 BAC 双重认证，受能量/时间/返回安全集约束；信息收益不能单独授权运动；
(iv) **信任落地**：关于「x 处有数据支撑」的声明，必须由独立物理实证（本机到访/独立多机互证/签名传感器日志）支撑；单客户端自报不计入覆盖信任。

**定义 332（空间认知场 SEF）** 在拓扑图/栅格 W 上，对机器人 i 与地点 x：
`E_i(x) = (H_i(x), H_fleet(x), D_het,i(x), τ_i(x), AoI_i(x))`，
其中 `H_i(x)=H[b_i(s|x)]` 为本地后验熵，`H_fleet(x)` 为机队聚合后验熵，`D_het,i(x)=JS(b_i(·|x) ‖ b_fleet(·|x))` 为异质度，`τ_i(x)∈[0,1]` 为覆盖信任，`AoI_i(x)` 为信息年龄。定义**可信联邦先验**：
`b_fleet^τ(s|x) = (1−τ_i(x))·b_0(s|x) + τ_i(x)·b_fleet(s|x)`。
τ=0 时联邦先验退化为本地先验，任何「机队说 x 已知」都不改变后验。

**定义 333（认知三分解与可约性）** 以 `D_i` 为当前本地数据、`D_fleet` 为机队数据、`D_future` 为未来本地观测/移动，由链式法则：
`H[b_i] = I(s; D_fleet | D_i) + I(s; D_future | D_i, D_fleet) + H[s | D_i, D_fleet, D_future]`。
记 `U_fleet := I(s;D_fleet|D_i)`（联邦可约）、`U_local := I(s;D_future|D_i,D_fleet)`（本地观测/移动可约）、`U_res := H[s|D_i,D_fleet,D_future] = U_ale + U_model`（在当前模型类下不可约：aleatoric + 模型失配 + 真实异质）。**U_res 永不派信息动作去「查」**；`D_het` 是 `U_model` 的可测代理并作为其下界估计。

**定义 334（信息运输动作与传输调整 VoI）** `𝒜_T = {none, query_fleet(x), move(x'), local_probe(x)}`。对动作 g，
`VoI_T(g) = ΔH(g) / c(g)`，
`c(g)=c_energy + c_time + c_risk + c_comm + c_priv(ε_g) + λ_aoi·AoI`。
选择 `g* = argmax_{g∈𝒜_T^safe} VoI_T(g)`，若 `VoI_T(g*) ≤ τ_v` 则不行动。移动与联邦查询是**替代品**：当 `τ(x) ≥ τ_min` 且 `G_fleet(x) ≥ G_move(x)`、`c_comm ≤ c_move` 时，移动被联邦查询支配；当 `τ(x)=0` 时 `G_fleet(x)=0`，只能移动或承认不知道。

**定义 335（可运输联邦模型 FTM）** 模型分解为共享编码器 θ_s（可联邦）、本地任务头 φ_i（不共享）、本地安全/校准头 ψ_i（绝不联邦，绝不被平均）。训练：
`min_{θ_s,{φ_i}} Σ_i w_i L_i(θ_s,φ_i) + λ_p‖φ_i−φ_i^0‖²`，
聚合只作用于 θ_s；φ_i、ψ_i 只在本机更新。任何全局更新不得覆盖 ψ_i，这是「安全校准本地主权」。

**定义 336（联邦验收门 FGate）** 包 `P_k=(θ_s, Σ, calib, SEF, provenance, dp_spent, bra_report, aoi, sig)` 被接受当且仅当：
(a) 签名/来源有效；(b) `AoI ≤ τ_aoi`；(c) `dp_spent ≤ B_DP`；(d) `bra_report.byz_risk ≤ τ_byz`；
(e) **本地影子验证**：在本地留出集上 `ΔNLL ≤ ε_nll`、`ΔECE ≤ ε_ece`，且安全证书不变；
(f) 异质度门：`D_het ≤ τ_het` 或已启用本地个性化残差。
任一失败 ⇒ 拒绝该包，`U_fleet` 视为未约，退回 R70。

**定义 337（覆盖诚实与信任落地）** `τ_i(x)=1−exp(−n_i^ind(x))`，其中 `n_i^ind(x)` 是**独立物理实证**计数（不同机器人、不同轨迹、签名传感器日志、本机到访），自报覆盖计 0。只有 `τ_i(x)≥τ_min` 的地点才允许进入联邦先验；否则视为未知。

**定义 338（拜占庭鲁棒聚合 BRA）** 对 θ_s 用坐标裁剪 + 截尾均值/中位数/Krum 类规则；`f<n/2` 时参数误差有界。**关键边界**：BRA 保护的是参数，不保护「覆盖声明」；覆盖声明走定义 337 的实证通道，不走加权平均。

**定义 339（地理差分隐私 GDP）** 释放空间直方图/认知场摘要时使用平面 Laplace 机制，满足 ε_g-地理不可区分；原始轨迹永不出机。用 RDP/组合定理记账；释放尺度越粗隐私越好但 `D_het` 估计越差，存在可计算的隐私–效用前沿。

**定义 340（移动信息规划 MoCoP）** 在拓扑图上选择路线 `π=(x_0,…,x_k)`：
`max_π E[Σ_j (G_move(x_j) − c_move(x_j))]`
s.t. 非完整约束、速度/加速度上限、地面摩擦锥、动态障碍、人类近邻成本、能量 `≤B_e`、时间 `≤B_t`、**返回安全集**可行。
在条件独立观测下，期望熵下降沿路线单调子模；用带约束的递归贪心求近似解，并报告经验 regret。

**定义 341（底盘–机械臂协同证书 BAC）** `BAC(q, ξ_arm, π)=1` 当且仅当：机械臂处于收拢/认证工作空间，重心稳定裕度 `≥m_s`，地面摩擦锥可支撑加减速，急停距离覆盖速度，动态障碍预测无碰撞，且运动不打断在途接触任务。BAC 不过 ⇒ `move` 的信息收益置零（不是降低，是清零）。

**定义 342（通信感知异步 CAA）** 联邦更新异步、可中断；本地模型无网络也可无限期运行；更新在版本边界原子换装；用 AoI 与陈旧度 `ψ(AoI)` 进入保守项。实时环不等待任何下载；上传仅在安全窗口进行。

**定义 343（联邦证据纪律）** 关于机队先验的任一改变，须至少满足两项：独立物理实证、本地影子验证、跨站点正/负对照（注入已知差异应显著；打乱标签/空更新应≈0）。单客户端、单次更新不得单独改变与安全相关的先验。

**定义 344（风险缩放与两级退避†）** 令
`U_cons = U_ale + U_model + 1[拒绝/无包]·U_fleet + 1[无已验证本地增益]·U_local + ψ(AoI)`，
`λ = max(λ_task, λ_floor(U_cons))`，其中 `U_model ≥ c·D_het` 作为可测下界。
联邦与移动带来的**已验证**熵下降才获得 resolution bonus；拒绝、陈旧、异质、不可约项一律计入保守。R70 是「无联邦、无信息移动」边界，此时 `U_cons = H[b_i]`，逐指令相同。

**定义 345（AIC-FLEET 威胁模型）** `ℰ_FLEET = ℰ_BELIEF × ℰ_byz × ℰ_sybil × ℰ_cov × ℰ_priv × ℰ_stale × ℰ_motion`：拜占庭/女巫更新、覆盖伪造、轨迹反演与物理隐私、陈旧先验、移动诱发分布漂移、底盘–机械臂失稳、免费搭车。每类必须映射到可测指标与门控。

**定义 346（FLEET 证书 J_FLEET）** `J_FLEET=(J_BELIEF, SEF_hash, pkg_hash, FGate_report, dp_spent, AoI_p95, bra_report, coverage_attestation, personalization_ECE, BAC_log, fleet_ver)`。Valid ⇔ Valid(J_BELIEF) ∧ FGate 全通过 ∧ 隐私预算未越界 ∧ 覆盖信任有实证 ∧ BAC 零违规。

## 2. 关键算法骨架

```python
# IP-275 SEF：空间认知场（本地后验 × 机队先验 × 覆盖信任 × 信息年龄）
class SpatialEpistemicField:
    def __init__(self, graph, prior, ao1): self.g, self.prior, self.aoi = graph, prior, ao1

    def update(self, b_i, b_fleet, attest):
        for x in self.g.nodes:
            hi = entropy(b_i.at(x))
            hf = entropy(b_fleet.at(x))
            dh = js_div(b_i.at(x), b_fleet.at(x))
            tau = 1.0 - exp(-attest.independent_count(x))   # 自报覆盖不计
            self.E[x] = (hi, hf, dh, tau, self.aoi(x))

    def trusted_prior(self, x, tau_min):
        hi, hf, dh, tau, _ = self.E[x]
        return self.prior(x) if tau < tau_min else mix(self.prior(x), hf, tau)

# IP-276 TAV：传输调整 VoI —— 开车去查 vs 问机队 vs 原地探测 vs 不动
def choose_transport_action(E, b_i, budget, cert):
    best = None
    cands = [("none", None)]
    cands += [("move", x) for x in top_uncertain(E, k=8)]
    cands += [("query", x) for x in attached(E)]
    for kind, x in cands:
        g = make_information_action(kind, x)
        if not budget.allow(g):            continue
        if kind == "move" and not cert.base_ok(g): continue   # C-RAS-WM + BAC
        dH = expected_gain(kind, x, E, b_i)
        if kind == "query" and E[x].tau < TAU_TAU:
            dH = 0.0                       # 覆盖不可信 => 问不出信息
        score = dH / (cost(g) + 1e-9)      # 信息运输的性价比
        if best is None or score > best.score:
            best = (g, score, dH)
    return best if best and best.score > TAU_V else None

# IP-277 FGate：联邦包验收（来源/时效/DP/拜占庭/本地影子/异质度）
def fgate_accept(pkg, local_shadow, safety):
    if not verify_sig(pkg) or pkg.aoi > TAU_AOI:            return False
    if pkg.dp_spent > DP_BUDGET or pkg.bra_report.byz > TAU_BYZ: return False
    delta = evaluate_on(local_shadow, pkg)
    if delta.nll > EPS_NLL or delta.ece > EPS_ECE:          return False
    if pkg.D_het > TAU_HET and not has_local_residual(pkg): return False
    return safety.invariants_unchanged(pkg)

# IP-278 BRA：拜占庭鲁棒聚合；覆盖声明不参与平均，只认独立实证
def robust_aggregate(updates, attest):
    clipped = [clip_norm(u, C) for u in updates]
    theta_s = trimmed_mean(clipped, f)          # f < n/2
    tau = {x: 1.0 - exp(-attest.independent_count(x)) for x in attest.nodes}
    return theta_s, tau

# IP-279 MoCoP：带返回安全集约束的信息路径规划
def plan_informative_route(E, q0, constr):
    nodes = [x for x in E if E[x].hf > TAU_H and constr.reachable(q0, x)]
    route = constrained_greedy_route(nodes, gain=lambda x: E[x].hi + E[x].hf,
                                     cost=constr.travel_cost, constr=constr)
    return route if route and constr.return_to_safe(route) else []

# IP-280 BAC：底盘-机械臂协同认证
def bac_certify(q, arm_state, route):
    return all(arm_state.stowed_or_certified(step)
               and stability_margin(q, step) >= M_S
               and friction_cone_ok(q, step)
               and e_stop_distance(q, step) <= clear_distance(step)
               and not arm_state.in_contact_unsafe(step)
               for step in route)

# IP-281 主闭环：联邦只在影子层，实时控制环不被网络阻塞
def FLEET_RAS_round(M, o):
    z, o = M.mtm.forward(...)
    b_t = M.bse.step(M.b_prev, o, M.last_action, M.last_g, M.last_y)
    E = M.sef.update(b_t, M.fleet.belief, M.attest)

    pkg = M.fleet.latest()
    accepted = bool(pkg) and M.fgate.accept(pkg, M.shadow, M.safety)
    if accepted:
        b_t = M.bse.rebase(b_t, pkg.prior)       # 只改先验，不改安全头 ψ_i
    else:
        M.budget.mark_unreduced("fleet")         # U_fleet 计入保守项

    g = M.tav.choose(E, b_t, M.budget, M.cert)
    if g and g.kind == "move":
        route = M.mocop.plan(E, M.base.q, M.cert)
        if route and M.bac.certify(M.base.q, M.arm, route):
            M.base.execute(route)                # 低速、可中断、不进入认证前缀
        else:
            M.budget.mark_unreduced("local")
    elif g and g.kind == "query":
        y = M.fleet.query(g.x)
        b_t = M.bse.step(b_t, y)
        M.budget.mark_reduced("fleet", g.expected_gain)

    U_ale, U_res, U_fl, U_lo = M.aud.decompose(b_t, M.budget)
    U_cons = (U_ale + U_res
              + (0.0 if M.budget.reduced("fleet") else U_fl)
              + (0.0 if M.budget.reduced("local") else U_lo)
              + M.caa.staleness_penalty())
    lam = max(M.efs.risk_scale(...), lam_floor(U_cons))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    mode = select_mode_from_belief(M.modes, b_t, lam)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam

    M.audit.submit_async(E, g, U_cons, accepted, M.budget.report())
    M.fleet.stage_dp_update(M.ftm.local_update())  # 只在安全边界上传，实时环不等待
    return k, lam, mode, U_cons
```

## 3. 推导

**引理 23（信息运输对偶与信任开关）** 在条件独立观测、成本可加的模型下，动作选择由 `ΔH/c` 排序；且当 `τ(x)=0` 时联邦查询的期望增益为零。故存在阈值开关：`τ(x) ≥ τ_min` 时「问机队」与「开过去」按单位成本竞争；`τ(x) < τ_min` 时联邦查询被支配，只能移动或承认不知道。系：**覆盖信任不是联邦的一个特征，而是联邦与移动之间的选择器**。

**引理 24（非 IID 负迁移上界）** 设本地风险 `R_i`、异质度 `D_het=JS(p_i(y|o)‖p_fleet(y|o))`、损失对分布满足 L-Lipschitz，则
`R_i(f_fleet) ≤ R_i(f_i) + L·√(D_het/2)`。
故当 `L√(D_het/2)` 超过本地收益边际时，联邦更新必然有害；FGate 的异质度门与个性化残差正是该上界的可执行版本。系：**「个性化」不是工程妥协，而是负迁移上界给出的必要条件**。

**引理 25（覆盖信任不可联邦化）** 设聚合器只接收客户端的自报覆盖向量。对任一真实未到访地点 x，敌意客户端可构造自报使聚合器输出任意高的 `τ(x)`；因此不存在仅基于自报的统计聚合能证明「x 处有支撑」。只有独立物理实证（本机到访、独立轨迹互证、签名日志）才能把 `τ(x)` 从 0 抬起。系：**联邦可以告诉你「去哪里问」，但不能替你证明「那里有人真正看过」；移动验证因此不可省。**

**引理 26（地理隐私–效用前沿）** 平面 Laplace 机制以 `ε_g` 释放空间直方图，满足 `ε_g`-地理不可区分；期望定位误差为 `Θ(1/ε_g)`，`D_het` 的估计误差随释放粒度变粗而增大。`T` 轮组合下的隐私预算按 RDP 复合增长。故存在最粗的可用释放粒度：既能估计异质度，又不至于反演轨迹。系：隐私不是附加项，而是决定 SEF 分辨率的约束。

**定理 20（FLEET 严格包含 R70）** 在 A102–A104（联邦/本地数据可分解、覆盖信任有实证、FGate 本地验证、移动经 C-RAS-WM+BAC 认证）下，FLEET 的期望风险 ≤ R70；且当无联邦包、FGate 拒绝、`τ<τ_min`、`VoI_T≤τ_v` 或 BAC 不过时，两者**逐指令相同**。安全侧不因联邦或移动让步：联邦只改先验/表示，安全头 ψ_i 与实时证书始终本地。

**定理 21（底盘运动安全与无突变）** 信息驱动的移动被分解为经认证的运动原语序列；BAC 保证重心、摩擦、急停、臂–基耦合与在途接触任务不被破坏；任一条件失效即触发最小风险停止并回退 R70。由于底盘只在安全窗口低速执行、且实时控制环与模型换装解耦，控制连续、无突变，R70 的提交/换装不变式保持。

**定理 22（信息路径的近似性）** 在 A105（观测条件独立、路线增益沿边单调子模、边权满足三角不等式）下，带返回安全集约束的递归贪心对信息路线给出常数近似；无 A105 时只报告经验 regret，不作最优性声明。系：MoCoP 的价值不在「证明最优」，而在**把移动信息收益与安全约束放进同一个可审计目标**。

## 6. 本轮最大风险

**一句话**：FLEET-RAS 用联邦先验决定底盘「哪里值得去」，又用底盘到访为联邦先验背书——一旦非 IID 或覆盖伪造让联邦在某个地点**自信地错**，系统就会开向一个由共识盖章的幻觉，而安全证书只证明「这段运动本身不撞」，不证明「这段运动值得走」；**被联邦说服着走向错误，比停在原地承认不知道更危险**。

**次级风险与缓解**：
1. **非 IID 负迁移** → FTM 个性化残差 + `D_het` 门 + FGate 本地影子验证；
2. **覆盖伪造/女巫** → 覆盖声明不参与聚合，只认独立物理实证（定义 337、引理 25）；
3. **移动诱发分布漂移** → 进入新区域即降级校准、BAC 双证、必要时回退 R70；
4. **陈旧/断网** → CAA 异步 + AoI 保守项 + 本地模型无限期自治；
5. **轨迹/物理隐私** → geo-DP + 原始数据不出机 + 私人区域采集策略；
6. **工程复杂度** → 影子层、版本边界换装、原子回滚与 J_FLEET 全链路审计。

## 2. 形式化定义（要点版）

**定义 331（总览与四不变式）** 组件如 IP 表；四不变式为实时零学习写、联邦隔离、移动双证、信任落地。

**定义 332（空间认知场）** `E_i(x)` 五元组；可信先验 `b_fleet^τ`。任何 τ 不足的地点按未知处理，不进入联邦先验。

**定义 333（认知三分解）** 链式法则给出 `H[b_i]=I(s;D_fleet|D_i)+I(s;D_future|D_i,D_fleet)+H[s|D_i,D_fleet,D_future]`；`U_res` 永不派实验去查，`D_het` 是其可测下界。

**定义 334（传输调整 VoI）** `𝒜_T={none,query,move,probe}`；`VoI_T=ΔH/c`；`τ<τ_min` 时 query 的 ΔH=0；`VoI_T≤τ_v` 不行动。

**定义 335（FTM）** 共享 θ_s、本地 φ_i/ψ_i；只聚合 θ_s；ψ_i 是本地安全校准主权，任何全局包不得覆盖。

**定义 336（FGate）** 六重验收：签名、AoI、DP 预算、拜占庭报告、本地影子 NLL/ECE、异质度/个性化。失败即拒绝并回退 R70。

**定义 337（覆盖诚实）** τ 只由独立实证抬高；自报覆盖为 0。覆盖声明不走参数聚合。

**定义 338（BRA）** 参数层用裁剪 + 截尾均值/Krum；`f<n/2` 有界。覆盖层由 337 处理。

**定义 339（GDP）** 平面 Laplace 释放空间摘要，`ε_g`-地理不可区分；RDP 记账；粗粒度换隐私。

**定义 340（MoCoP）** 带约束的信息路径规划；条件独立下单调子模，递归贪心给常数近似；无假设只报经验 regret。

**定义 341（BAC）** 八项检查：臂收拢/认证工作空间、重心裕度、摩擦锥、急停距离、动态障碍、接触任务、速度/加速度、返回安全集。

**定义 342（CAA）** 异步、可中断、版本边界换装；AoI 入保守项；实时环不等待网络。

**定义 343（证据纪律）** 独立实证、本地影子验证、跨站点正/负对照三项中至少两项；单客户端不得改安全先验。

**定义 344（风险缩放）** `λ=max(λ_task, λ_floor(U_cons))`；已验证的联邦/移动收益才获 resolution bonus；拒绝/陈旧/异质/不可约项一律保守。

**定义 345（AIC-FLEET）** 拜占庭、女巫、覆盖伪造、轨迹反演、物理隐私、陈旧、移动漂移、底盘失稳、免费搭车。

**定义 346（J_FLEET）** 证书 Valid 需 J_BELIEF 有效、FGate 全通过、DP 未越界、覆盖有实证、BAC 零违规。

| `B_DP` | 8.0 / 24h | 每机每日隐私预算 | 停止上传，仅本地学习 |
| `ε_g` | 1.0 | 地理不可区分参数 | 调粗释放粒度 |
| `τ_v` | 0.05 nat/J | 信息运输性价比阈值 | 不行动 |
| `m_s` | 0.15 m | 底盘稳定裕度 | 禁止移动 |
| `B_e / B_t` | 5% / 10% | 信息移动能耗/时间占比上限 | 取消非必要移动 |

## 4. 模块接口与主闭环

```python
# 数据平面：认知场（只读快照，供规划器消费）
sef.query(x) -> (H_i, H_fleet, D_het, tau, aoi)
sef.update(b_i, b_fleet, attestation) -> None
sef.trusted_prior(x, tau_min) -> Distribution

# 联邦平面：影子层，绝不进入实时控制环
ftm.local_update() -> Update
ftm.stage_dp_update(update, dp_accountant) -> bool
fleet.latest() -> Package | None
fgate.accept(pkg, local_shadow, safety) -> (bool, GateReport)
bra.aggregate(updates, attestation) -> (theta_s, tau_map)
gdp.release(spatial_histogram, eps_g) -> NoisySummary
caa.commit_at_safe_boundary(pkg) -> VersionToken

# 决策平面：信息运输（低频，10–50Hz）
tav.select(E, b_i, budget, cert) -> Action
mocop.plan(E, q0, constraints) -> Route
bac.certify(q, arm_state, route) -> bool

# 执行平面：实时控制（继承 R70，<3.5ms）
c_ras_wm.certified_prefix(A, ...) -> k
efs.risk_scale(...) -> lambda
```

```python
def FLEET_RAS_round(M, obs):
    b_t = M.bse.step(M.b_prev, obs, M.last_action, M.last_g, M.last_y)
    E   = M.sef.update(b_t, M.fleet.belief, M.attest)

    pkg = M.fleet.latest()
    accepted = bool(pkg) and M.fgate.accept(pkg, M.shadow, M.safety)[0]
    if accepted: b_t = M.bse.rebase(b_t, pkg.prior)      # 只改先验，不改 ψ_i
    else:        M.budget.mark_unreduced("fleet")

    g = M.tav.select(E, b_t, M.budget, M.cert)
    if g and g.kind == "move":
        route = M.mocop.plan(E, M.base.q, M.cert)
        if route and M.bac.certify(M.base.q, M.arm, route):
            M.base.execute(route)                         # 低速/可中断/不进认证前缀
        else:
            M.budget.mark_unreduced("local")
    elif g and g.kind == "query":
        b_t = M.bse.step(b_t, M.fleet.query(g.x))
        M.budget.mark_reduced("fleet", g.expected_gain)

    U_ale, U_model, U_fl, U_lo = M.aud.decompose(b_t, M.budget)
    U_cons = (U_ale + U_model
              + (0.0 if M.budget.reduced("fleet") else U_fl)
              + (0.0 if M.budget.reduced("local") else U_lo)
              + M.caa.staleness_penalty())
    lam = max(M.efs.risk_scale(...), lam_floor(U_cons))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    mode = select_mode_from_belief(M.modes, b_t, lam)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam

    M.audit.submit_async(E, g, U_cons, accepted, M.budget.report())
    M.fleet.stage_dp_update(M.ftm.local_update())        # 安全边界上传，实时环不等待
    return k, lam, mode, U_cons
```

## 5. 推导（结论与用途）

**引理 23（信息运输对偶与信任开关）** `τ(x)=0 ⇒ G_fleet(x)=0`；于是「问」与「去」按 `ΔH/c` 竞争，τ 是两种运输方式的开关。用途：TAV 的选择逻辑无需人为权重。

**引理 24（非 IID 负迁移上界）** `R_i(f_fleet) ≤ R_i(f_i)+L√(D_het/2)`。用途：FGate 的 `D_het` 门与 FTM 个性化残差都有明确理论依据；全局模型不是无条件更好。

**引理 25（覆盖信任不可联邦化）** 仅靠自报覆盖的任何统计聚合都可被敌意客户端操纵；只有独立物理实证能把 τ 从 0 抬起。用途：这是 BRA 的边界，也是 MoCoP 存在的理由——**移动验证不可省**。

**引理 26（地理隐私–效用前沿）** `ε_g` 越大隐私越强、`D_het` 估计越差；存在最粗可用释放粒度。用途：SEF 分辨率与 `B_DP` 必须联合设计，不能事后加隐私。

**定理 20（FLEET 严格包含 R70）** 无联邦包/拒绝/τ 不足/VoI 不足/BAC 不过时逐指令等价；其余情况期望风险不升。用途：允许 FLEET 作为 R70 的**可选增强**上线，而非替换。

**定理 21（底盘运动安全与无突变）** BAC + C-RAS-WM 双证保证信息移动不破坏安全包络、不打断接触任务、不引入控制突变；失败即最小风险停止。用途：移动信息收益永远不能单独授权运动。

**定理 22（信息路径近似性）** A105 下递归贪心给常数近似；无 A105 只报经验 regret。用途：MoCoP 的卖点是**可审计的目标函数**，不是最优性神话。

## 10. 本轮最大风险

**一句话**：FLEET-RAS 的最大风险是**「联邦共识幻觉 × 移动验证成本」的双重陷阱**——联邦先验可以告诉底盘「去哪里值得查」，但覆盖信任无法仅靠参数聚合获得；若系统为了省下物理实证而相信未落地的覆盖声明，它就会以「机队都知道」的自信驶向一个没人真正验证过的地点，而 BAC 只会证明这段运动不撞、不会证明这段运动值得走；**联邦给的是方向，不是证据；把方向当证据，就是本轮最危险的错误。**
