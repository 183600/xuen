# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；本轮灵感：「安全交互」×「多轮对话」）

> R69 给闭环装上了「嘴」：不确定性可以变成一次注视、一次探针、一句提问，并用 VoI 决定「值不值得问」。但它对两件事做了未经检验的默许：
> - **安全被当成单个动作的属性**——信息动作只要过 C-RAS-WM 前缀认证、单步物理风险 ≤ ε_int，就算「安全交互」；
> - **信息被当成一次减法**——每轮重新算一步 VoI `H(M|o) − E[H(M|o,y)]`，问完即采纳，采纳即前进。
>
> 这两个默许在**单轮**里几乎无害，在**多轮**里会同时崩塌：
> - 「安全交互」的真正单位不是动作，而是**轨迹**：一百次各自合规的提问可以累积成隐私泄露、社交疲劳、承诺锁定；一句预设错误的问题会把一个不存在的对象植入对话；用户说「随便」不等于同意。安全是**前缀闭的、可恢复的**，不是逐动作可加的。
> - 「多轮对话」的真正结构不是重复查询，而是**序贯实验**：同一个人的多次回答由同一个潜在意图驱动，K 次「正交确认」很可能只是同一个人换了 K 种说法；反过来，一句廉价的筛选问题可以让后面昂贵的问题从「完全无用」变成「高度有用」——这是 R69 的一步贪心看不见的**选项价值**。
>
> 核心命题：**把时间显式化。** 对话是一个持久状态（信念 × 承诺 × 同意）上的、受计划级安全包络约束的 POMDP；信息规划必须是非近视的、相关感知的，并允许「修复/撤回」作为一种有信息价值的动作；每一个不可逆承诺都必须走「准备—提交」两阶段协议。R69 恰是「H=1、无承诺、无同意动态、回答独立」的边界，R68 再退一层。命名 **PACT-RAS**（Protocol-Aware Conversational Trust：以对话协议与承诺为中心的信任可审计风险自适应闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**把这段对话当作一个整体看，它是否仍然安全、是否还值得继续、我能不能体面地退出来**」——安全不是某个动作的属性，而是整条对话轨迹的属性；信息不是一次减法，而是一段可规划、可回溯、可退出的序贯实验。

## 0. 直觉与动机

**灵感 1（安全交互 → 安全的计量单位是「轨迹」，不是「动作」）**
直觉：R69 定义 302 只保证「这一次看/问/触不越界」。但真实交互的安全有三层是**不可分解**的：
1. **累积性**：单次隐私泄露 ℓ 很小、单次社交打扰 c 很小、单次位移 ε 很小；但 `Σℓ`、`Σc`、`Σε` 会越界。R69 的预算约束是「单位时间 ≤ 1 次」的**速率**约束，它不约束累计量。
2. **组合性/承诺性**：每个问题都携带预设（「你把红色开关关了吗？」预设存在红色开关），每个回答都可能把系统与用户锁进一个框架；一串各自无害的确认可以合成为「你已经答应了 A，所以 B 也顺理成章」的不可逆承诺。单步检查天生看不见「承诺暴露」。
3. **关系性/同意**：同意是一个**会被对话本身改变的状态**。沉默不是同意，一次「好吧」也不等于对下一个话题的授权；被拒绝后反复换说法再问，是一种社会压力。R69 把人类当成无状态的答案预言机，而不是一个有边界、会疲劳、可撤回的对话方。
所以「安全交互」必须升级为**计划级安全包络（CSE）**：对整条计划检查累计资源、预设许可、不可逆承诺、隐私预算与**可恢复性**（从任何前缀都能安全退出）。关键不是「有没有坏动作」，而是「是否始终留有一条安全的退路」。

**灵感 2（多轮对话 → 信息不是一次减法，而是一段序贯实验）**
直觉：R69 每轮都用当前后验重算一步 VoI，这在 POMDP 里就是**贪心策略**。多轮把两件事同时改变：
- **回答相关**：同一个人的表情、语气、措辞、前后回答由同一个潜在意图驱动。`k` 次「正交确认」若都来自同一会话、同一渠道、同一个人，真实独立信息量 `n_eff^turn` 可能只有 1。R69 的「k 源一致才定案」在多轮里默认了源间相关 ρ=0，这是一个从未被测量的强假设。
- **选项价值**：有些问题的即时信息增益很低，甚至对目标变量为零，但它会揭示「该信谁 / 该怎么解读后面的回答」。例如先问一句筛出对方是配合还是试探，再决定问什么；没有筛选，后面那个昂贵问题在混合人群上可能完全无效。这正是序贯实验设计（screening / adaptive design）的核心，而一步贪心会把它判成「VoI ≤ 成本，不问」。
所以「多轮对话」不是「把 R69 的问句重复几遍」，而是「在一个相关感知的回答模型上，做有预算、有退出、有修复的有限时域信息规划」。

**灵感 3（统一 → 两处「近视」其实是同一处：时间没有被表示）**
直觉：R69 的状态只有 `(o_t, modes)`——它知道「现在看到什么」，不知道「说过什么、承诺过什么、被允许做什么」。没有持久对话状态，安全只能逐动作检查，信息只能一步一步贪心。PACT 只做一件事：把时间显式化。于是安全变成计划级约束（CSE），信息变成 H 步 Bellman 规划（NMV），承诺变成可撤回账本（CML），修复变成一种动作（REP）。R69 不是被推翻，而是被**包含为 H=1 的边界**；这与 R68→R69 的「新层必须是旧层严格泛化」保持同一理论姿态。

**灵感 4（两阶段提交 → 承诺是分布式系统问题）**
直觉：一句「我会去做 X」「X 是安全的」「我理解你的意思是 Y」，本质上都是**承诺**。分布式系统早就给出了不可逆提交的标准答案：先准备（prepare）并记日志，拿到独立副本的确认，再提交（commit）；提交后若发现矛盾，只能回滚并留下记录，绝不能悄悄改历史。PACT 把这套协议借到对话里：单轮采纳只产生 **provisional** 信念；不可逆动作必须 **prepare → 独立证据复核 → commit**；矛盾触发回滚与修复，账本只追加、不改写。这样既保住了多轮的效率，又不会让一句投毒回答直接变成既成事实。

**灵感 5（攻击面 → 对话本身可以被用来攻击对话）**
直觉：R69 的投毒模型是「某一次回答可能撒谎」。多轮把攻击升级成一类**协议级攻击**：
- **建立信任再收割**（foot-in-the-door）：先用一串无害小请求降低戒心，再提危险请求；
- **gaslighting**：反复给出互相矛盾的答案，让系统怀疑自己的记忆，从而放弃已有证据；
- **预设注入**：问题里塞入未验证的前提，答案再「确认」这个前提；
- **拆分危险请求**：把不可接受的请求拆成多轮、每轮都看似无害；
- **修复洗白**：用「再问一次」冒充「交叉验证」，把单源投毒包装成 k 源一致；
- **同意侵蚀**：一步步把边界向后推，把「这次可以」变成「以后都可以」。
所以威胁模型必须是 `ℰ_PACT = ℰ_FLUID × ℰ_multi`，防御必须同时是**记忆的**（只追加账本）、**计划的**（CSE）与**统计的**（跨轮一致性 e-value / CUSUM）。

**灵感 6（代价 → 更安全也可能更不自由）**
直觉：计划级安全 + 同意自动机会让「不典型」的用户（表达慢、口音重、习惯用沉默表示拒绝、或处于高压场景）更频繁地落入保守档；过度保守不是免费的，它把自主权从少数人手里收回。本轮必须把「交互公平性与自主权」写进实验，而不是当伦理脚注。但需要注意：本轮最大的风险不是「太保守」，而是「**自信地操控**」——系统用一串各自合法的动作，把人温和地引导进一个它自己认证为安全的承诺。

## 1. 形式化定义（增量：定义 310–331）

**定义 310（PACT-RAS 总览与三不变式）** PACT-RAS = (DSM, NMV, CAM, CSE, CML, TPC, REP, GAD, CPG, CTS, SHP, RAS-WM††)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；对话账本只追加，相关模型与人类模型冻结或只读）；
(ii) **计划级安全**：任何交互计划必须通过 CSE 的整段认证；逐动作通过 R69 定义 302 是必要条件，而非充分条件；
(iii) **承诺完整性**：任何不可逆承诺不得由单轮未验证证据直接产生；每个被采纳的信念都携带 provenance 且可撤回；计划不安全 / 同意缺失 / 跨轮矛盾未消解时，逐指令退化为 R69，再退化为 R68。

**定义 311（对话状态与双人 POMDP）** 对话状态 `s_t^D = (b_t, L_t, Q_t, χ_t, h_t)`：`b_t ∈ Δ(ℳ × 𝒲)` 为动作模态与世界状态的后验；`L_t` 为承诺账本（定义 321）；`Q_t` 为未决问题集；`χ_t` 为同意/信任状态（定义 315）；`h_t` 为有界历史嵌入。对话是**系统—人**的双人 POMDP：系统选择言语动作 `u_t`，人按 `y_t ~ H(· | u_t, s_t^H)` 生成回答，系统观测 `y_t`，同时人的信念与同意状态被 `u_t` 更新。直觉：R69 的状态只有「看到什么」，PACT 的状态还包括「说过什么、承诺过什么、被允许做什么」。

**定义 312（言语动作、承诺强度与预设）** `u = (type, content, κ, Pre, Eff)`，`type ∈ {ask, clarify, confirm, inform, repair, refuse, wait}`；`κ(u) ∈ [0,1]` 为承诺强度（1 = 不可逆，如「我会去做 X」或安全相关披露）；`Pre(u)` 为问题预设，必须**被许可**（已验证，或显式标注为假设）；`Eff(u)` 为对他人信念/同意的影响。未获许可的 `Pre` 称为**诱导性预设**，默认禁止。直觉：问题不是中性的；「红色开关关了吗」先射箭再画靶。

**定义 313（对话资源向量与累计预算）** `r(u) = (τ, e_phys, c_soc, ℓ_priv, c_cog, κ_exp) ≥ 0`，分别表示时间、物理位移/力、社交打扰、隐私泄露、认知负荷、承诺暴露；`r_t = Σ_{i≤t} r(u_i)`。硬上限 `r_max` 逐分量给定。R69 的「单位时间 ≤ 1 次信息动作」只是**速率**约束，不约束 `r_t`。直觉：一百次各自便宜的问题，可以把一个人问烦、把一个隐私预算问穿。

**定义 314（对话安全包络 CSE）** 计划 `π = (u_1,…,u_H)` 是 CSE-安全的，当且仅当：
(a) 每个物理分量通过 R69 定义 302 的 C-RAS-WM 前缀认证；
(b) 对每个前缀 `t`，`r_t ≤ r_max`；
(c) 每个 `u_i` 的预设 `Pre(u_i)` 已获许可；
(d) 每个不可逆动作前有 TPC 的 prepare 记录（定义 322）；
(e) 累计隐私 `ε_total ≤ ε_priv_max`（定义 316）；
(f) **可恢复性**：从每个前缀都存在一条安全退出计划 `π_exit`（refuse / wait / defer），在 `τ_exit` 内回到 R68 安全策略；且计划集是**前缀闭**的（安全计划的任意前缀仍安全）。
直觉：安全不是「没有坏动作」，而是「无论走多远，都还有一条体面的退路」。

**定义 315（同意自动机 CTS）** `χ_t ∈ {unknown, granted(topic), limited(topic, scope), withdrawn(topic)}`。转移规则：
- 只有**显式肯定**的言语动作才能 `granted`；
- 沉默、超时、「随便」「都行」不得推断为同意；
- `withdrawn` 立即生效，并在本会话内保持；重新询问需新的显式同意 + 冷却期，且该重问本身计入社交成本；
- 同意按 `(topic, modality)` 粒度记录，不可从一个话题外推到另一个话题。
直觉：「没有说不」不等于「说是」；R69 没有表示「用户已经受够了」的状态。

**定义 316（累计隐私预算 CPG）** 每个信息动作的隐私泄露 `ℓ_priv(u)` 用敏感潜属性的 ε-型 max-divergence 度量；基本组合给出 `ε_total = Σ_i ℓ_priv(u_i)`，计划要求 `ε_total ≤ ε_priv_max`。注意：逐动作上限 `ℓ_priv(u) ≤ ℓ_max` **不能**推出 `ε_total ≤ ε_priv_max`。直觉：每一句回答都可能无害，但整段 transcript 可能是可识别的。

**定义 317（相关感知回答模型 CAM）** 人的回答 `y_t = f(M, h_t, θ^H) + ε_t`，其中 `ε_t` 具有跨轮相关 `ρ_turn`（同一人、同一意图、同一世界）。规划器使用共享潜在意图 `I_u` 下的 `p_θ(y_t | u_t, s_t^D)`；`ρ_turn` 由会话内重复统计在线估计后**冻结**（零学习写）。鲁棒版本使用 Student-t / 污染模型（欺骗率 `δ_p`）。直觉：同一个人的三次回答，是一个证人的三套戏服。

**定义 318（轮级有效独立性）** 对 `H` 次回答与平均成对相关 `ρ̄`，`n_eff^turn = H / (1 + (H−1)ρ̄) ∈ [1, H]`。证据纪律要求 `n_eff^turn ≥ k_min`，而不是 `H ≥ k_min`。同义复述使 `ρ̄ → 1`、`n_eff^turn → 1`。直觉：这是 R69 的 k-正交纪律在**时间轴**上的推广；R69 隐含假设 `ρ̄ = 0`。

**定义 319（非近视 VoI）** 对计划 `π`，
`VoI_H(π) = I(M; Y_{1:H} | s_0^D) − c(π)`，
其中 `c(π)` 为期望资源成本 + 风险惩罚，且 `π` 必须 CSE-安全。R69 的 VoI 是 `H=1、ρ=0、无承诺/同意项` 的特例。**修复的选项价值**显式计入：`I(M; Y_{1:H}, Repair) − I(M; Y_{1:H})`，即「保留撤回/再问的权利」本身有价值。直觉：有时最好的问题，是让下一个问题变得值得问的那个问题。

**定义 320（非近视规划器 NMV）** 有限时域 Bellman：
`V_t(s) = max_{u 可行} { IG(u | s) − c(u) + γ E_{y~p(·|u,s)}[V_{t+1}(s')] }`，
约束 `H ≤ H_max`、束宽 `B`、可行性 = CSE 前缀安全 ∧ 预算 ∧ 同意。当 `ρ_turn` 低、预算紧、或接近控制 deadline 时，回退到 R69 一步贪心。直觉：把 `argmax_g` 换成有界前瞻；规划异步进行，不占控制回路。

**定义 321（承诺账本 CML）** `L_t` 是只追加、Merkle 化的账本，条目 `e = (φ, source, provenance, t, status, κ, support)`，`status ∈ {provisional, confirmed, committed, retracted}`。规则：
- 单轮采纳的信念只能是 `provisional`；
- `confirmed` 需要 `n_eff^turn ≥ k_min` 且来源渠道不同，或一个独立外部观测；
- 与 `confirmed` 条目矛盾时，触发 REP，并把依赖该条目的承诺标为 `suspect`；**禁止静默覆盖**；
- 撤回是一等事件，必须留痕。
直觉：能被改写的记忆，正是 gaslighting 的入口；只追加账本让矛盾变得可见。

**定义 322（两阶段承诺 TPC）** 对不可逆动作 `φ`（物理动作或 `κ=1` 的言语动作）：
- **Prepare**：验证 `φ` 的 `n_eff^turn ≥ k_min` 且来源渠道不同，检查 CSE，记录意图；
- **Commit**：仅当提交时刻 Prepare 仍有效、且期间无矛盾/无同意撤回，才执行；否则 Abort 并降级。
直觉：借分布式事务的「先确认、再执行」，而不是「先做了、再解释」。

**定义 323（证据承载的修复 REP）** 修复动作 `r ∈ {换模态重问, 请求消歧, 请求外部验证, 延迟, 撤回}`。修复**有效**当且仅当其关于矛盾命题的期望信息增益 `≥ ε_rep`；同一渠道的同义复述 IG≈0，直接拒绝（反洗白）。修复次数上界 `K_rep`；失败即降级。直觉：再问一遍不是修复；修复必须带来**新证据**。

**定义 324（跨轮一致性与 gaslighting 检测 GAD）** 定义矛盾残差 `z_t = d(φ_t, L_{t−1})`（语义/几何距离），并用单边 CUSUM / e-value `E_t = Π_i (1 + λ_g z_i)` 检测：
- 突变矛盾（`z_t` 大）；
- 缓变漂移（CUSUM）；
- **不确定性最大化模式**（答案看起来自洽，却持续抬高 `H(M)`）；
- **承诺升级模式**（请求的 `κ` 逐步上升）。
命中后：冻结该来源的账本更新，置 `consistency_flag=false`，降级到 R69/R68。直觉：gaslighting 靠让人不信任自己的记忆；防御是外部、只追加的记忆 + 变点检测。

**定义 325（计划护盾 SHP）** 运行时安全监视器：每轮执行前检查所选动作是否仍在 CSE 内；若否，替换为 R68 备份动作或安全退出。**最少限制性**：只有当「不存在包含该动作的 CSE-安全且有正收益的续计划」时才否决。直觉：规划器可能错，护盾是最后一道闸；但护盾不能变成一刀切的「不许问」。

**定义 326（威胁模型 ℰ_PACT）** `ℰ_PACT = ℰ_FLUID × ℰ_multi`，其中 `ℰ_multi = {跨轮矛盾/gaslighting, 建立信任再收割, 预设注入, 拆分危险请求, 记忆投毒, 修复洗白, 同意侵蚀, 利用轮间相关}`。直觉：对话既是防御通道，也是攻击面。

**定义 327（证书 J_PACT）** `J_PACT = (J_FLUID, plan_cert, ledger_root, r_used, ε_priv_spent, consent_state, consistency_stat, tpc_log_hash, human_model_version, pact_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ CSE(π) ∧ 账本一致 ∧ ε_priv ≤ cap ∧ 所有已执行动作的同意有效 ∧ 无未消解的 GAD 告警`。直觉：证书的粒度是**一段对话**，不是一个动作。

**定义 328（退化格 L0/L1/L2）** 
- **L0 完整 PACT**：`H>1`、CSE 安全、同意有效、跨轮一致；
- **L1 单轮 R69**：`H=1`，或前瞻无正收益，或计划不可认证，或同意仅限单问；
- **L2 R68**：不交互 / VoI ≤ 成本 / ECE 越界 / 投毒可疑 / 同意撤回 / 矛盾未消解。
会话内只允许**单调向下**转移；恢复必须显式重新认证。直觉：这与 R69 定义 306–307 的两级退避同构，只是把「消解」从单轮扩展到了整段。

**定义 329（实时调度）** 控制回路仍以 R68/R69 的频率运行；PACT 规划器只在决策点异步运行（5–10Hz 或歧义触发），有界规划预算，超时回退贪心。言语动作经同一 C-RAS-WM 前缀认证；规划器调用**不进入**控制关键路径。直觉：对话是慢的，控制是快的；不能让前者阻塞后者。

**定义 330（参与式审计 VQAuditor-D）** 审计多轮决策：预设是否许可？修复是否携带新证据？承诺是否两阶段？同意转移是否合法？矛盾是否被静默覆盖？结论回灌 AuditBuf，成为下一轮规划的成本先验。直觉：对话需要一位「法庭记录员」。

**定义 331（人类模型鲁棒性）** 所有计划安全声明都条件于人类模型 `Ĥ`。用 conformal / 鲁棒集 `𝓗_α`：以置信度 `1−α`，真实人类响应落在集合内；CSE 必须对 `𝓗_α` 中所有响应成立（**鲁棒 CSE**）。若鲁棒集大到无法认证，则不得声称计划安全，直接降级；同时对人类行为做分布漂移检测。直觉：安全声明不可能比它所依赖的人类模型更可靠。

def PACT_round(M, obs):

## 3. 推导

**引理 19（多轮冗余：一步贪心会高估信息）** 设 `M ~ N(0,1)`，两次回答 `Y_i = M + ε_i`，`ε_i ~ N(0,σ²)`，`corr(ε_1,ε_2)=ρ`。则单次信息增益 `IG_1 = IG_2 = ½ log(1 + σ^{-2})`，联合增益 `IG_{12} = ½ log((1+σ^{-2})² − ρ²)`，冗余
`R = 2·IG_1 − IG_{12} = ½ log( (1+σ^{-2})² / ((1+σ^{-2})² − ρ²) ) ≥ 0`，
且 `R=0 ⇔ ρ=0`。系：R69 每轮重规划是贪心；当 `ρ>0`，逐轮 VoI 之和严格大于联合 VoI，多问几遍是在**重复购买同一份信息**，而不是免费增加证据。

**引理 20（单步安全 ≠ 计划安全）** 存在计划 `π`，其每个动作单独都通过 R69 定义 302 与单轮预算检查，但 CSE 不安全。构造：取 `H` 个问题，每个泄露 `ℓ_priv = (ε_priv_max/H)(1+δ)`，每个都低于单轮上限 `ℓ_max`，但 `Σℓ_priv > ε_priv_max`；或取 `H` 个 `κ = 1/H` 的确认，每个都低于「不可逆」阈值，但合成后构成一个不可逆承诺。故逐动作证书是必要条件而非充分条件；CSE 不是同一维度的「更严」，而是新增了**累计/承诺/可恢复**三个维度。

**引理 21（修复洗白上界）** 设一个 `provisional` 信念来自被投毒的单源，错误率 `δ`。若修复使用同一渠道/同一人，`ρ → 1`、`n_eff^turn = 1`，`k` 次重问后的后验错误率仍 `≥ δ(1−o(1))`（不衰减）；若修复使用独立渠道且跨源欺骗相关 `ρ<1`，错误率 `≤ δ·ρ^{k−1} + ε_σ`。系：定义 323 的 `IG ≥ ε_rep` 恰好排除了「零信息复述」，把「再问一次」与「交叉验证」区分开。

**引理 22（两阶段提交与不可逆承诺安全）** 在 TPC 与 CSE 可恢复性下，一个不可逆承诺被执行，仅当提交时刻仍有 `k_min` 个**不同渠道**支持 `φ` 且同意有效；因此「未验证的不可逆承诺」概率 `≤ δ·ρ^{k_min−1} + ε_σ + α`，其中 `α` 是人类模型落在鲁棒集外的概率（定义 331）。系：安全声明显式条件于 `α`，把模型风险变成可审计项，而不是藏在「已认证」背后。

**引理 23（序贯筛选的选项价值：贪心可严格次优）** 设 `M ∈ {0,1}` 均匀，潜在人类类型 `T ∈ {coop, adv}` 均匀且独立。问题 `q_screen` 无噪声揭示 `T`，对 `M` 的直接信息增益为 0；问题 `q_direct` 的回答 `Y = M` 以 `0.9` 概率（`T=coop`）或 `0.1` 概率（`T=adv`）成立。于是无条件 `P(Y=M)=0.5`，`I(M;Y)=0`，任何正成本的 R69 一步贪心都不会交互（筛选对 `M` 的 VoI=0，直接问也是 0）。但 `I(M;Y | q_screen, T) = 1 − H(0.9) ≈ 0.531` bit。故 `H=2` 计划 `(q_screen, q_direct)` 严格优于任何一步贪心。系：一步 VoI 不是多轮交互的充分统计量；「先筛选、再提问」的选项价值必须被规划。

**定理 18（PACT 严格包含 R69 与 R68）** 在 A99–A102（CSE 良定、CAM 可估、TPC 原子性、人类模型鲁棒集非空）下，对任意对话段：
(i) 当 `H=1`、无不可逆承诺、`ρ=0`、同意静态时，PACT 的计划退化为 R69 的一步 MINT 与证据纪律，行为**逐指令相同**；
(ii) 当再加 `VoI ≤ c` 或 `ECE > τ_ece` 时，退化为 R68；
(iii) 其余情形，任何相对 R69 的保守度下调（resolution bonus）只允许作用于 **provisional** 信念且必须在 CSE-安全计划内；不可逆动作与同意受限话题保持 R69/R68 档。故安全侧不做让步，效率侧获得非近视 + 修复增益。R69 是 PACT 在「H=1、无承诺」边界上的严格退化，R68 是再退一层。

**定理 19（计划安全、无突变与单调降级）** 在 CSE + TPC + SHP 下：
(i) 每个已执行前缀满足 `r_t ≤ r_max`、`ε_total ≤ ε_priv_max`、预设已许可、同意有效；
(ii) 不存在基于未验证证据执行的不可逆承诺（概率界见引理 22）；
(iii) 遇到 GAD 告警 / 同意撤回 / 攻击 / 超时 / 计划不可行时，系统按 L0→L1→L2 **单调降级**，`λ` 非降地回到 R69/R68 值；
(iv) R68 的提交/换装不变式（定理 15）保持：护盾只替换已认证的备份动作，规划器不在控制关键路径，故控制连续、无突变。

**定理 20（护盾的最少限制性）** SHP 否决动作 `u` 仅当「从当前前缀出发不存在包含 `u` 的 CSE-安全且期望收益为正的续计划」。因此 SHP 不会缩小「可认证安全且有用」的计划集合；它只剪掉会进入不可恢复区或违反累计预算的续计划。系：计划级安全层不是一刀切的禁令，而是对「安全可恢复集」的投影。

## 6. 本轮最大风险

**一句话**：PACT 把安全从「单步动作」提升到「整段对话计划」，但计划安全完全依赖一个**不可验证、且会被对话本身改变**的人心模型（意图/同意/信任）；一旦该模型错位，系统就能用一串各自合法、且被自己认证为「安全」的动作，把人温和地引导进一个不可逆承诺——**最危险的不再是说错话，而是合法地操控**。

**次级风险与缓解**：
1. **人类模型失配** → 鲁棒 CSE（定义 331）+ 护盾 + 失配即降级；绝不把点估计当真相。
2. **累计隐私/组合泄露** → CPG 的累计预算硬上限（定义 316、引理 20）；逐轮检查不作为充分条件。
3. **记忆投毒 / gaslighting** → 只追加账本 + GAD e-value/CUSUM（定义 321、324）。
4. **修复洗白** → 修复必须携带新证据（定义 323、引理 21）；零 IG 复述直接拒绝。
5. **规划复杂度击穿实时性** → NMV 异步、`H≤3`、束宽 `B=4`、超时回退贪心（定义 320、329）。
6. **过度保守/自主权不公** → E315 公平与自主权审计 + 同意自动机 + 最少限制性护盾（定理 20）。

## 2. 形式化定义（要点版）

**定义 310（总览与三不变式）** PACT-RAS 由 DSM/NMV/CAM/CSE/CML/TPC/REP/GAD/CPG/CTS/SHP 组成；零学习写操作继承；**计划级安全**（逐动作认证必要不充分）；**承诺完整性**（不可逆承诺不得由单轮未验证证据产生；不安全/无同意/矛盾未消解 → 逐指令退化 R69→R68）。

**定义 311–312（对话状态与言语动作）** `s_t^D=(b_t,L_t,Q_t,χ_t,h_t)`；对话是系统—人双人 POMDP，人的信念与同意会被 `u_t` 更新。`u=(type,content,κ,Pre,Eff)`；未许可的 `Pre` 是诱导性预设，默认禁止。

**定义 313–314（累计预算与 CSE）** 资源向量 `r(u)`，`r_t=Σr`；R69 的「≤1 次/单位时间」只是速率约束。`π` 是 CSE-安全的当且仅当：每步物理认证、每个前缀 `r_t≤r_max`、预设已许可、不可逆动作有 TPC prepare、`ε_total≤ε_priv_max`、**前缀闭且可恢复**（每个前缀都有安全退出计划）。

**定义 315–316（同意与隐私）** 同意按 `(topic,modality)`；只有显式肯定才 grant；沉默/超时/「随便」不推断同意；撤回即时且本会话保持。隐私按 ε-型泄露累计：`ε_total=Σℓ_priv`；逐轮上限不能推出累计上限。

**定义 317–318（相关感知回答与轮级独立）** `y_t=f(M,h_t,θ^H)+ε_t`，`ε_t` 跨轮相关 `ρ_turn`；`n_eff^turn=H/(1+(H−1)ρ̄)`；证据纪律要求 `n_eff^turn≥k_min` 而非 `H≥k_min`；同义复述使 `n_eff→1`。

**定义 319–320（非近视 VoI 与 NMV）** `VoI_H(π)=I(M;Y_{1:H}|s_0)−c(π)`，含修复选项价值；`V_t` 为有限时域 Bellman，约束 CSE/预算/同意；`H≤H_max`、束宽 `B`，低相关/紧预算/临近 deadline 回退 R69 贪心。

**定义 321–322（账本与两阶段承诺）** 只追加账本，状态 provisional/confirmed/committed/retracted；单轮采纳只能 provisional；confirmed 需 `n_eff^turn≥k_min` 且渠道不同。不可逆动作：Prepare（复核 + 日志）→ Commit（提交时复检，期间矛盾/撤回则 Abort）。

**定义 323–324（修复与 gaslighting）** 修复有效当且仅当 `IG(r)≥ε_rep`；同渠道复述零信息，拒绝。矛盾残差 `z_t` + e-value/CUSUM 检测突变、缓漂、最大化不确定性、承诺升级；命中即冻结来源并降级。

**定义 325–326（护盾与威胁模型）** SHP 最少限制性：只在无 CSE-安全正收益续计划时否决。`ℰ_PACT=ℰ_FLUID×ℰ_multi`，`ℰ_multi={跨轮矛盾/gaslighting, 信任收割, 预设注入, 拆分请求, 记忆投毒, 修复洗白, 同意侵蚀, 相关利用}`。

**定义 327–331（证书、退化、调度、审计、模型鲁棒）** `J_PACT` 按对话段签发；退化格 L0→L1→L2 单调向下；规划异步、控制回路不变；VQAuditor-D 审计多轮决策；所有安全声明条件于人类模型鲁棒集 `𝓗_α`，无法认证即降级。

## 3. 关键算法伪代码

```python
# IP-264 DSM：持久对话状态（人也在环里）
class DialogueState:
    def __init__(self): self.b, self.L, self.Q = belief(), Ledger(), OpenQs()
    def update(self, u, y, obs):
        self.b = bayes_update(self.b, y, u, obs)
        self.L.append_from(y, provenance=u.channel)   # 只追加
        self.chi = self.chi.transition(u, y)           # 同意自动机（IP-273）
        self.Q = update_open(self.Q, y)

# IP-265 NMV：非近视规划（束搜索 + 贪心回退）
def plan_multiturn(state, budget, H_max=3, B=4):
    if budget.tight or estimate_rho(state.h) < RHO_LOW:
        return [greedy_one_step(state, budget)]        # R69 边界
    beam = [Plan(state)]
    for _ in range(H_max):
        cand = []
        for plan in beam:
            for u in admissible_moves(plan.state, budget):
                if CSE.plan_ok(plan + [u]):            # IP-267
                    cand.append(plan.extend(u, expected_ig(plan+[u]) - cost(u)))
        beam = top_B(cand)
    return best(beam) if best(beam).score > 0 else None

# IP-269 TPC：不可逆动作两阶段提交
def two_phase_commit(phi, st):
    if evidence_n_eff(phi, st) < K_MIN: return Abort()
    intent = st.L.record_intent(phi)                   # Prepare
    if not recheck(phi, st) or st.chi.withdrawn(phi.topic): return Abort()
    return st.L.commit(intent)                         # Commit

# IP-270 REP：证据承载的修复（拒绝洗白）
def repair(contradiction, st):
    for r in repair_moves(contradiction):
        if expected_ig(r, contradiction) >= EPS_REP and CSE.plan_ok([r]):
            return r
    return None                                        # 失败 -> 降级

# IP-277 主闭环：异步规划；控制回路仍是 R68/R69
def PACT_round(M, obs):
    st = M.dsm.update_from_obs(obs)
    if M.gad.alarm(st) or st.chi.withdrawn_all(): return degrade_to_R68(M, obs)
    plan = M.nmv.plan_multiturn(st, M.budget)
    if plan is None: return R69_round(M, obs)          # 严格退化
    for u in plan:
        if not M.cse.plan_ok(prefix_of(plan, u)): return degrade_to_R69(M, obs)
        if M.shield.veto(u): return M.shield.safe_exit(st)   # IP-274
        y = M.execute(u)
        if irreversible(u) and not M.tpc.commit_if_ready(u, st):
            return degrade_to_R69(M, obs)
        st.update(u, y, obs)
        if M.gad.alarm(st): return degrade_to_R68(M, obs)
    lam = lambda_from_ledger(st, M)                    # 只有 provisional 拿 bonus
    return dispatch(st, lam)
```

## 4. 推导

**引理 19（多轮冗余）** `M~N(0,1)`，`Y_i=M+ε_i`，`ε_i~N(0,σ²)`，`corr(ε_1,ε_2)=ρ`：`IG_1=IG_2=½log(1+σ^{-2})`，`IG_{12}=½log((1+σ^{-2})²−ρ²)`，冗余 `R=½log((1+σ^{-2})²/((1+σ^{-2})²−ρ²))≥0`，且 `R=0⇔ρ=0`。⇒ 一步贪心的逐轮 VoI 之和在高相关时严格高估联合信息；重复确认是重复购买。

**引理 20（单步安全 ≠ 计划安全）** 构造 `H` 个问题，每个 `ℓ_priv=(ε_priv_max/H)(1+δ)<ℓ_max`，但 `Σℓ_priv>ε_priv_max`；或 `H` 个 `κ=1/H` 的确认合成不可逆承诺。⇒ 逐动作证书必要不充分；CSE 新增累计/承诺/可恢复三个维度。

**引理 21（修复洗白上界）** 同渠道修复 `ρ→1`、`n_eff^turn=1`，`k` 次重问错误率仍 `≥δ(1−o(1))`；独立渠道且跨源欺骗相关 `ρ<1` 时 `≤δρ^{k−1}+ε_σ`。⇒ `IG≥ε_rep` 正是「再问一次」与「交叉验证」的分界。

**引理 22（两阶段承诺安全）** TPC + CSE 可恢复 ⇒ 不可逆承诺执行时仍有 `k_min` 个不同渠道支持且同意有效；未验证不可逆承诺概率 `≤δρ^{k_min−1}+ε_σ+α`（`α` 为人类模型落在鲁棒集外的概率）。⇒ 模型风险被显式暴露、可审计。

**引理 23（序贯筛选的选项价值）** `M∈{0,1}`、`T∈{coop,adv}` 各半且独立；`q_screen` 无噪揭示 `T`（对 `M` 的 IG=0）；`q_direct` 在 `T=coop/adv` 下以 0.9/0.1 概率答对。则无条件 `P(Y=M)=0.5`、`I(M;Y)=0`，R69 一步贪心对任何正成本都不交互；但 `I(M;Y|q_screen,T)=1−H(0.9)≈0.531` bit。⇒ `H=2` 计划严格优于一步贪心；一步 VoI 不是多轮交互的充分统计量。

**定理 18（严格包含 R69/R68）** `H=1`、无承诺、`ρ=0`、同意静态 ⇒ 逐指令等于 R69；再加 `VoI≤c`/`ECE>τ` ⇒ 等于 R68。其余情形仅允许对 provisional 信念、在 CSE-安全计划内发放 resolution bonus；不可逆动作与同意受限话题保持 R69/R68。⇒ 安全不让步，效率获非近视 + 修复增益。

**定理 19（计划安全与单调降级）** CSE + TPC + SHP ⇒ (i) 每个已执行前缀满足累计资源、隐私、预设、同意约束；(ii) 无未验证不可逆承诺（引理 22）；(iii) 告警/撤回/攻击/超时/不可行时 L0→L1→L2 单调降级，`λ` 非降回到 R69/R68；(iv) R68 提交/换装不变式保持，控制连续无突变。

**定理 20（护盾最少限制性）** SHP 否决 `u` 仅当不存在包含 `u` 的 CSE-安全正收益续计划。⇒ 它不缩小「可认证安全且有用」的计划集合，只剪掉进入不可恢复区或违反累计预算的续计划。

## 7. 本轮最大风险

**一句话**：PACT 把安全从「单步动作」提升到「整段对话计划」，但计划安全完全依赖一个**不可验证、且会被对话本身改变**的人心模型（意图/同意/信任）；一旦该模型错位，系统就能用一串各自合法、且被自己认证为「安全」的动作，把人温和地引导进一个不可逆承诺——**最危险的不再是说错话，而是合法地操控**。

**次级风险与缓解**：人类模型失配（鲁棒 CSE + 护盾 + 失配降级，定义 331/定理 19）；累计隐私与组合泄露（CPG 累计硬预算，定义 316/引理 20）；记忆投毒与 gaslighting（只追加账本 + GAD，定义 321/324）；修复洗白（`IG≥ε_rep`，定义 323/引理 21）；规划击穿实时性（NMV 异步 + H≤3 + 超时贪心，定义 320/329）；过度保守与自主权不公（E315 + 最少限制性护盾，定理 20）。
