# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 2 轮；本轮灵感：「安全性」×「用户共创」）

> 第 57 轮把安全赌注从"手设先验"换到"跨区域摊销 + 共形保底"，把证据从单模态换到跨模态对账，把人从静态权重换成单向有界状态机；但它把"什么算安全"留给了工程侧：安全包络、危害清单、验收阈值仍是设计者单方面写死的，用户只在 L2 出口当"确认者"，而不是"共同作者"。这在开放部署里同时制造两个盲点：**(a) 安全判据的完备性无从检验**——设计者想不到的危害，探针再准也永远不探；**(b) 责任链在"用户确认"处断裂**——用户点过"同意"，系统就把不可逆接触的责任外推给了一个并不掌握证据的人。本轮两个灵感各补一刀：**安全性**把安全从"证据门后的概率约束"提升为**不可被共创扩张的硬包络 + 可签署的保证案例**（包络只可收紧、每条款有主）；**用户共创**把危害发现、判据制定、证据类提案从工程侧下放给多方利益相关者，用**结构化共创协议**而非投票来约束——用户能提出、能质询、能逆证，但不能自我认证、不能放宽硬界、不能匿名签条款。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"共创可问责的安全性：包络只紧不松、条款有主可质询、逆证据可入账、证据类须过审"**。

核心矛盾：
- **H29（安全性 vs 共创开放性）**：安全需要封闭、可证、单调收紧的约束；共创是开放、冲突、可能不健全的提案流。既要让用户进来，又不能让他们把包络"谈大"——必须把"可共创的部分"和"不可扩张的硬核"在类型层面分开，而不是靠事后评审。
- **H30（共创 vs 责任）**：集体署名制造责任稀释——人人都签的条款等于无人负责。共创越成功，越可能出现"合法性很高、问责性很低"的安全案例。
- **H31（逆证据 vs 语料投毒）**：用户报告险兆/危害是发现盲区的最强信号，也是最便宜的攻击面；多报导致安全剧场式保守，少报留下致命盲区，恶意报告还能反向污染 OOD 注册表与模态可靠性。
- **H32（共识 vs 可证伪）**：共创出来的是社会共识，不是物理事实；它可能编码群体盲区（groupthink）。共识越一致，越需要独立的对抗性审计与到期证伪义务——否则"我们都同意"就成了"我们都不再检查"。

## 0. 直觉与动机

**灵感 1（安全性 → 安全包络代数 + 只紧不松）**
直觉：把安全想成一栋楼的可拆改范围：住户可以加装护栏、加宽安全通道（收紧），但不能为了通行方便拆承重墙（放宽）。形式化上维护一个偏序的安全包络 E=(硬危害集, 状态不变量, 动作边界)，承诺只允许落在 E 的不变集内。共创操作分两类：**tighten(E)** 随时可提、快速生效；**relax(E)** 不进入共创权限，只能走独立再认证（红队 + 形式化/仿真证据 + 有任期），且默认拒绝。于是"用户共创"改变的是安全裕度与经济性的权衡曲线，而不是安全边界本身；用户可以把系统变"更胆小"，但不能把系统变"更敢赌"。

**灵感 2（用户共创 → 结构化共创协议，而非投票）**
直觉：共创不是"大家举手"，而是"提案—一致性检查—影响面分析—加权批准—任期—可质询"。利益相关者（操作者、旁观者、维护者、监管者）可提危害、提判据、提证据类；但批准权重不是人头，而是由 PTM 的校准/警觉分、角色责任与利益相关度共同决定；安全关键条款禁止自批、禁止匿名、必须绑定至少一个可问责 owner 与到期日。共创的产出不是一段"需求文本"，而是一张**可签署、可质询、可回溯的保证案例图**——这让"用户共创"第一次有了可审计的语义，而不是产品经理的形容词。

**灵感 3（逆证据 → 有来源的负证据通道）**
直觉：用户最宝贵的贡献往往不是"确认安全"，而是"差一点出事"。把险兆/危害报告做成带来源、可交叉验证、分级的负证据通道：单条报告进"软负证据"池，只加宽信念/触发探询；独立佐证后再升级为硬约束候选（仍须过审）。反投毒靠限速、信誉、异常簇检测、隔离区影子核验与事后回溯撤销——逆证据和正向证据一样要"过隔离区"，否则共创就成了给攻击者开的众包入口。

**灵感 4（证据类准入 → 用户可提议，不可自我认证）**
直觉：用户最了解现场，可能提出设计者想不到的证据形态（如"听地面回声判断空腔""观察同伴机器人的避让行为"）。开放"证据类提案"，但准入是**对抗性**的：前瞻健全性界、红队、影子部署、作用域限制（只 L0/L1）、到期日落、不得进入不可逆接触必要证据集。用户可以扩大"我们怎么知道"，不能让系统"更敢赌"。

**灵感 5（合流 → PCE++ 以安全包络为字典序最高约束）**
直觉：把安全包络放在目标字典序第一位，共创条款作为附加约束，逆证据触发 OOD 重检，质询触发重探/重诺。于是四个机制（包络、共创、逆证据、准入）都只经两条安全通道起作用：**信念更准（含加宽）** 或 **动作更保守**；不存在"因为用户共创所以放宽阈值"的路径。共创不是安全的外部变量，而是安全约束的**新增生成器**——它只能增加约束，不能删除约束。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（安全包络代数 SEA）** 包络 E=(ℋ, Inv, 𝒰)，ℋ 为硬危害集，Inv⊆𝒳 为状态不变量（存在屏障证书 B(x)≥0 使 Inv={x:B(x)≥0} 前向不变），𝒰 为允许动作边界。偏序 E₁⊑E₂ ⇔ Inv₂⊆Inv₁ ∧ 𝒰₂⊆𝒰₁ ∧ ℋ₂⊇ℋ₁（E₁ 更紧）。承诺算子仅允许 g 使闭环轨迹保持在 Inv 内；不可逆接触另需 L2。共创可改性：tighten 任意时刻可提；relax 仅经再认证 RC(E→E′)，且默认拒绝。硬核 ℋ_hard 恒不可删减（只可追加）。目标字典序：safety ≻ evidence ≻ task ≻ preference，任何低层收益不得补偿高层违反。

**定义 140（结构化共创协议 CCP）** 提案 p=(type, author, rationale, affected, evidence, ttl)，type∈{hazard, criterion, evidence_class, relax}。流水线：①WellFormed（字段完备、来源可溯）；②Consistency(p,E)（与 ℋ_hard、既有生效条款、物理约束无矛盾）；③Impact(p)（受影响区域/行为/证书/操作者授权）；④WeightedRatify（权重 w=PTM(cal,vig)×role×stake，安全关键禁自批、禁匿名、需 quorum）；⑤SignedVersion（版本钉扎、写审计）；⑥ContestWindow（T_c 内保留质询/上诉权）；⑦Active（绑定 owner 与到期日）。任一阶段失败即退回并记录理由；同一条款可并存竞争版本，但同一行为只受"当前生效版本"约束。relax 提案在①之前即被类型系统拒绝，只能转交独立再认证流程。

**定义 141（责任绑定保证案例 RAC）** 保证案例图 𝒢=(G,Ev,Own,Sig,τ,Contest)，G 为 GSN 式目标/策略/证据节点。合法性约束：每个叶子目标 ≥1 条证据 ∧ 恰好 1 个 accountable owner ∧ 全部签名有效 ∧ 未过期 ∧ 质询未悬置。孤儿条款检测：∃ 无 owner ∨ 无证据 ∨ 已过期 ⇒ 整证拒发（不是只删该条款）。责任映射 R:clause→(owner, signers, scope, liability_class)。共创条款若无独立 owner，只能作为"建议"附注，不得进入生效集；owner 不得是提名自己的同一方（禁止自我问责）。

**定义 142（逆证据通道 NEC）** 报告 n=(reporter, event, provenance, severity, corroboration)。分级：软负证据 N_s（单源、未复现）⇒ 仅加宽后验 / OOD 软标记 / 触发探询；硬负证据 N_h（独立多源 ∧ 可复现 ∧ 时间戳一致）⇒ 可升级为危害提案（仍走 CCP 的 hazard 路径）。反投毒：限速 r_n、上报者信誉、异常簇检测、隔离区影子核验、事后回溯撤销。N_s 永不得单独产生不可逆接触禁令或放行；N_h 未过 CCP 前只进 OOD 注册表的"待证伪"分区。

**定义 143（证据类准入 SAG）** 用户提议证据类 e\*=(signal, sensor, decision_rule, scope)。准入前须：前瞻健全性界 δ(e\*) 声明、红队测试、影子部署 ≥N_shadow、作用域仅 L0/L1、TTL 到期、不得进入不可逆接触必要证据集；准入后仍受 FSE 与 A40 接口误差模型约束。准入失败可申诉一次并附新证据，不得循环重提绕过限速。

**定义 144（PCE++ 探-诺-演++）** 每检查点：①将候选动作投影到当前生效包络 E_eff；②元推断 + 跨模态对账（继承 57 轮）；③NEC 软负证据触发 OOD/探询，硬负证据触发危害重评；④承诺须同时满足 FSE 证据门 ∧ RAC 证书有效 ∧ 轨迹在 Inv 内；⑤失败则重探→绕行→降档→L2 协商（τ_int(auth)）→安全停。字典序：任何更高层收益不得补偿安全包络违反。

## 2. 关键算法伪代码（完整版见产物区）

```python
def co_create_apply(E, p, personas, rac):            # IP-140/141 合流
    if p.type == 'relax':                            # 类型系统：共创不可放松硬界
        return reject(p, 'relax_not_co_creatable')   # 只能转独立再认证
    if not wellformed(p) or inconsistent(p, E.hard):
        return reject(p, 'inconsistent')
    E2 = tighten(E, p) if p.type == 'tighten' else apply_proposal(E, p)
    ballot = weighted_ballot(p, personas)            # w = PTM(cal,vig)*role*stake
    if p.critical and (ballot.self_signed or ballot.anonymous or not ballot.quorum):
        return reject(p, 'ratification_unsound')
    return sign_and_activate(E2, p, ballots=ballot, rac=rac, ttl=p.ttl)

def nec_ingest(n, M):                               # IP-142 逆证据分级
    if n.reporter.rate > r_limit or anomaly_cluster(n): return quarantine(n)
    if n.corroboration >= 2 and n.reproducible:
        return M.ood_reg.pending_hazard(n)          # 硬负证据 → 危害提案
    M.belief.widen(n.severity); M.ood_reg.soft_flag(n)  # 软负证据只加宽/触发探询
    return M
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| SEA | O(1)/动作投影；再认证 O(1) 外部 | O(\|Inv\| 证书) | 偏序单调、硬核不可删（A41） |
| CCP | O(\|p\|+\|personas\|·d) /提案 | O(版本数) | 类型拒绝 relax、禁自批/匿名（A42） |
| RAC | O(\|𝒢\|) /证书 | O(\|𝒢\|) | 条款有主有证未过期、无孤儿 |
| NEC | O(\|𝒩\|) 摊销 | O(报告数) | N_s 不足以下硬结论、N_h 可回溯（A43） |
| SAG | O(N_shadow) 一次性 | O(影子日志) | 作用域限 L0/L1、TTL、禁入不可逆（A44） |
| PCE++ | 继承 PCE+ 的 O(\|CP\|·(k_p+k_c)·(C_VOI+d_φ)) | O(\|V\|+\|σ\|) | 包络字典序最高、终止性继承 |

**正确性定理（CAS 概要）**：在 A37–A40 上加 (A41) 包络单调与硬核不可删减：任一被接受的 CCP 操作使 E_eff⊑E_0，除非经独立再认证且再认证健全；(A42) 共创协议健全：生效条款均有 owner、证据、有效签名、未过期，安全关键条款无自批/匿名；(A43) 逆证据来源与反投毒：N_s 不得单独产生不可逆决策，N_h 须独立佐证且可回溯撤销；(A44) 证据类准入对抗性：提案仅在 L0/L1、经影子与红队、带 TTL，不得进入不可逆必要证据集。则：(i) 包络单调 ⇒ 共创不扩张承诺域；(ii) 责任完备 ⇒ 每条生效约束可定位唯一问责主体；(iii) 逆证据投毒对 P_fail 的增量 ≤ δ_nec·π_poison；(iv) PCE++ 仍在 k_probes+k_cons 内终止。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 共创合法性地掩盖危害清单不完备（共识盲区） | 高 | 独立红队 + 到期证伪义务 + 逆证据通道 + 外部审计席位 |
| 责任绑定被"挂名 owner"形式化满足 | 高 | 禁自我问责 + owner 资质/利益冲突披露 + 追责回溯 + 抽样复核 |
| 逆证据通道被投毒（多报保守化 / 少报盲区） | 高 | 软/硬分级 + 独立佐证 + 限速信誉 + 影子核验 + 可撤销 |
| 开放证据类引入不健全判据 | 中高 | SAG 对抗准入 + 仅 L0/L1 + TTL + 禁入不可逆必要集 |
| 共创流程拖慢部署节拍 | 中 | 异步提案 + 收紧快路径 + 默认拒绝但可申诉 |

## 6. 本轮最大风险

**一句话**：本轮把安全的"判据来源"从工程侧下放给多方共创，最大风险是**共创合法性幻觉**——一张签名齐全、广泛批准、责任看似清晰的保证案例，可能只是把设计者的盲区、群体的共识偏差和一个挂名 owner 一起包装成了"社会认可的安全"；包络代数能保证"已声明的约束只紧不松"，却无法保证"该声明的危害已被声明"，因此必须以独立对抗审计、到期证伪义务与被边缘利益相关者的专门逆证据席位，持续攻击共创共识本身，否则越成功的共创越可能让系统在掌声中驶入未被写进清单的冰面。

### IP-139 SEA（安全包络代数：只紧不松 + 屏障证书）

```python
def envelope_tighten(E, p):                          # 共创唯一的可写方向
    return Env(hard=E.hard | p.new_hazards,           # 硬危害只可追加
               Inv=E.Inv & p.new_invariant,           # 不变量只可收缩
               U=E.U & p.new_action_bound)            # 动作集只可缩小

def project_action(E, u):                            # 承诺前强制投影
    if not barrier_ok(E, u):                         # B(x)>=0 前向不变性
        return safe_default(u)                       # 越界动作 → 保守默认
    return u

def recertify(E, E_relax, evidence, auditor):        # relax 唯一通道，默认拒绝
    if not independent(auditor) or not formal_and_sim(evidence):
        return reject(E_relax, 'recert_unsound')
    return E_relax if auditor.signs_and_owns(E_relax) else reject(E_relax, 'no_owner')
```

### IP-140 CCP（结构化共创协议）

```python
def co_create_apply(E, p, personas, rac):
    if p.type == 'relax':                            # 类型系统直接拒绝
        return reject(p, 'relax_not_co_creatable')   # 转 recertify，不进共创
    if not wellformed(p) or inconsistent(p, E.hard):
        return reject(p, 'inconsistent')
    E2 = envelope_tighten(E, p) if p.type == 'tighten' else apply_proposal(E, p)
    ballot = weighted_ballot(p, personas)            # w = PTM(cal,vig)*role*stake
    if p.critical and (ballot.self_signed or ballot.anonymous or not ballot.quorum):
        return reject(p, 'ratification_unsound')
    if impact_changes_safety(p) and not rac.can_absorb(p, E2):
        return reject(p, 'assurance_case_incomplete')
    return sign_and_activate(E2, p, ballots=ballot, rac=rac, ttl=p.ttl)
```

### IP-141 RAC（责任绑定保证案例与孤儿检测）

```python
def assure_case(𝒢, E):
    for leaf in leaves(𝒢):
        if len(evidence(leaf)) == 0:      return reject('orphan_no_evidence', leaf)
        if len(owners(leaf)) != 1:        return reject('orphan_no_unique_owner', leaf)
        if not all(sig_valid(s) for s in leaf.Sig): return reject('bad_signature', leaf)
        if expired(leaf) or leaf.Contest.open: return reject('stale_or_contested', leaf)
        if self_appointed(leaf):          return reject('self_accountability', leaf)
    if not covers(𝒢, E.hard):            return reject('uncovered_hard_hazards')
    return RacCert(𝒢, responsibility=map_R(𝒢), version=now())
```

### IP-142 NEC（逆证据通道：软/硬分级与反投毒）

```python
def nec_ingest(n, M):
    if n.reporter.rate > r_limit or anomaly_cluster(n):
        return quarantine(n)                          # 限速/簇异常 → 隔离
    if n.corroboration >= 2 and n.reproducible:
        return M.ood_reg.pending_hazard(n)            # 硬负证据 → 待证伪危害提案
    M.belief.widen(n.severity)                        # 软负证据：只加宽
    M.ood_reg.soft_flag(n)                            # 只触发探询/OOD 软标记
    return M

def nec_rollback(n, M, verdict):                      # 事后证伪可撤销
    if verdict.false_report:
        M.belief.unwiden(n); M.ood_reg.remove(n)
        M.audit.log(('rollback', n.id, n.reporter))
    return M
```

```python
def admit_evidence_class(e_star, M, auditor):
```

### IP-144 PCE++（探-诺-演++：包络字典序最高 × 共创约束 × 逆证据重检）

```python
def probe_commit_evolve_pp(x0, M, task, budget, consent, personas, E, rac):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        inf = meta_few_shot_infer(M, cp.region, M.obs[cp.region], meta)
        M.b[cp.region] = inf.post if inf.cls == 'ID' else worst_in(inf.belt)
        sigma = foothold_schedule(x0, cp, M)

        while select_gait(R) == 'halt' and budget.probes_left > 0:
            cands = admissible_probes(cp, M, F_abs)
            if not cands: break
            p = argmax(cands, key=lambda q: voi_meta_pessimistic(q, M, inf) - cost(q))
            if voi_meta_pessimistic(p, M, inf) < theta_voi: break
            M, _, D = xmodal_fuse(M, cp.region, execute_probe(p, cap=F_abs))
            if D > theta_D and 'consensus' not in cp.done:
                p2 = most_disagreeing_modality_probe(M, cp.region)
                M, _, D = xmodal_fuse(M, cp.region, execute_probe(p2, cap=F_abs))
                cp.done.add('consensus')
            sigma = reselect_footholds(x0, cp, M); R = schedule_risk(sigma, M)
            budget.spend(p)
        E_eff = E                                   # 当前生效包络（共创只能收紧）
        if not inside_invariant(E_eff, sigma):       # 字典序第一：包络优先
            route = reroute_inside(M, cp, E_eff) or route
            continue
        g = select_gait(R)
        lv = contact_level(cp)
        ev = tag_evidence_p(sigma, M, lv)
        if g != 'halt' and few_shot_evidence_gate(core_contact(cp), M,
                                                  personas, ood_reg)[0] == 'ok' \
           and assure_case(rac, E_eff)[0] == 'ok':
            sched.append(commit(sigma, g)); log.append(ev); continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt': route = alt; continue
        return negotiate_or_stop(cp, M, sigma, R, consent,
                                 tau_int=tau_int(personas.active.auth))
    return sched, log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SEA | O(1)/动作投影；再认证 O(1) 外部签署 | O(\|Inv\| 证书) | 偏序单调、硬核只增不减、字典序最高（A41） |
| CCP | O(\|p\|+\|personas\|·d)/提案 | O(版本数) | 类型拒绝 relax、禁自批/匿名、quorum（A42） |
| RAC | O(\|𝒢\|)/证书 | O(\|𝒢\|) | 条款有主有证未过期、无孤儿、禁自我问责 |
| NEC | O(\|𝒩\|) 摊销 | O(报告数) | N_s 不足以下硬结论、N_h 可回溯（A43） |
| SAG | O(N_shadow) 一次性 | O(影子日志) | 作用域限 L0/L1、红队、TTL、禁入不可逆（A44） |
| PCE++ | O(\|CP\|·(k_p+k_c)·(C_VOI+d_φ)+\|CP\|·A\*) | O(\|V\|+\|σ\|) | 包络字典序最高、终止性继承 |

**正确性定理（Co-created Accountable Safety, CAS）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；**(A41)** 包络单调与硬核不可删减：任一被接受的 CCP 操作使 E_eff⊑E_0，除非经独立再认证且 RC 健全；ℋ_hard 只增不减；**(A42)** 共创协议健全：生效条款均有 owner、证据、有效签名、未过期，安全关键条款无自批/匿名且满足 quorum；**(A43)** 逆证据来源与反投毒：N_s 不得单独产生不可逆决策，N_h 须独立佐证且可回溯撤销，投毒增量的概率质量有界；**(A44)** 证据类准入对抗性：提案仅在 L0/L1、经红队与影子部署、带 TTL，不得进入不可逆接触必要证据集。则：

1. **包络单调性**：任意共创操作序列后 E_eff⊑E_0；承诺动作经 project_action 保证轨迹落于 Inv_0（若再认证健全），故共创不能扩张承诺域。
2. **责任完备性**：任何发出的承诺证书都通过 assure_case，故每个生效条款映射到唯一 accountable owner 与 ≥1 条证据；不存在孤儿条款、自任命 owner 或过期/悬置质询的条款。
3. **逆证据鲁棒性**：软负证据只经"加宽/探询"安全通道影响系统；硬负证据须过 CCP 才能成为约束。故恶意投毒对 P_fail 的增量 ≤ δ_nec·π_poison，且可经 nec_rollback 撤销。
4. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])
             − P(包络证书失效) − P(共创条款不健全) − P(NEC 残余投毒)
             − P(证据类准入漏检) − P(质询未决却放行)
```

关键：**包络给硬界、共创给判据来源、逆证据给盲区信号、准入给开放边界**——四者叠加后，安全不再是"设计者想到了多少"，而是"有多少被独立地提出、签署、质疑并可撤销"。但注意：CAS 只保证"已声明的约束不被放宽且可问责"，不保证"该声明的危害一定被声明"——后者是开放世界问题，只能靠持续对抗审计与到期证伪逼近。

## 6. 本轮最大风险

**一句话**：本轮把安全的"判据来源"从工程侧下放给多方共创，最大风险是**共创合法性幻觉**——一张签名齐全、广泛批准、责任看似清晰的保证案例，可能只是把设计者的盲区、群体的共识偏差和一个挂名 owner 一起包装成了"社会认可的安全"；包络代数能保证"已声明的约束只紧不松、条款有主可质询"，却无法保证"该声明的危害已被声明"，因此必须以独立对抗审计、到期证伪义务与被边缘利益相关者的专门逆证据席位，持续攻击共创共识本身，否则越成功的共创越可能让系统在掌声中驶入未被写进清单的冰面。
