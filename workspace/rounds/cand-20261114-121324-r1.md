# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「灵巧操作」×「实时推理」）

> R69 把不确定性一分为二，用「主动交互」去消解 epistemic。但它默认了一件事：**思考可以在动作之前完成，交互可以在需要之前插入**。在灵巧操作里这条假设直接失效——滑移在几毫秒内发生，等你「问」完，物体已经掉了；而 R69 的多模态采样 + VoI 枚举 + 流似然第二意见加起来是毫秒级，放进 1kHz 的接触环里就是永恒。R69 的 resolution bonus 是以「时间免费」为前提的。
>
> 本轮两个灵感正好补上两块缺失：
> - **灵巧操作**：真正难的不是高维连续控制，而是**接触模式（contact mode）这个离散隐状态**——哪个指节在接触、粘着还是滑移、滚动还是撬动。模式一错，约束流形、摩擦锥与安全包络全错；而模式又是**快速切换**的。R69 的「动作多模态」是语义歧义，这里的「接触多模态」是**物理歧义**。
> - **实时推理**：推理不是免费资源，而是**带截止时间的物理资源**。一个晚到 5ms 的正确模式判断，等价于一个错误判断。于是「何时想、想多久、何时问」本身成为控制问题。
>
> 核心命题：把 R69 的「交互消歧」升级为「**时序投机消歧**」——用快反（reflex）守住当前接触模式的安全包络，同时用影子线程在**预测的未来状态**上做慢速 FLUID 推理（多模态采样 / VoI 交互 / 似然第二意见），以「草稿—验证—提交」的投机执行（借自 CPU 投机执行与 LLM 投机解码）决定是否换模；任何超时、失配、时滞越界都自动回落到快反包络（即 R69/R68 保守边界）。命名 **KAIROS-RAS**（Kinesthetic-Aware Interruptible Real-time Orchestration of Speculation）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「测量还准吗」，R69 问「该向谁求证」，R70 问「**什么时候还来得及想、来得及问**」——在接触-rich 的世界里，正确但迟到，就是错误。

## 0. 直觉与动机

**灵感 1（灵巧操作 → 接触模式是离散隐状态，不是连续高维）**
直觉：人们以为灵巧操作的难点是手指数多、自由度大。但真正让转笔、转方块、拧瓶盖失败的不是连续轨迹不够精细，而是**接触图在错误时刻切换**：该粘住时滑了、该滚动时卡了、该松开时夹紧了。接触模式 m（哪些接触、粘/滑、滚/撬）决定动力学是一个混合系统（hybrid system）：每种模式有自己的约束流形 𝒞_m、摩擦锥 ℱ_m 与安全包络。R69 的「动作多模态」描述的是意图歧义；这里的「接触多模态」描述的是**物理歧义**，切换快、后果硬、不可慢慢等。于是 R69 的 (U_ale, U_epi) 需要第三个轴：**接触模式后验 p(m|o)**，且它必须在毫秒内更新。

**灵感 2（实时推理 → 价值随时间衰减，迟到即错误）**
直觉：实时系统的经典教训是「missed deadline 等于错误输出」。在接触-rich 操作里更狠：决策价值不是常数，而是随「距下一次接触事件的时间」指数衰减。R69 的 VoI(g) 假设交互可在任意时刻完成，但「感到滑移再去看/去问」已经太晚。因此 VoI 必须带时间折扣，并回答一个 R69 没问的问题：**在剩余 slack 内，这个信息还值不值**。

**灵感 3（投机执行 → 让慢思考躲在快反应后面）**
直觉：CPU 不会因为 cache miss 就停机，它投机执行；LLM 投机解码用草稿模型猜、用大模型验。灵巧操作可以照搬：**快反网络**（1kHz、无学习写、已认证）是草稿；**FLUID 慢推理**是验证器；只有当慢结论在截止时间前到达、且在真实到达状态上仍然有效（不是对预测状态的幻觉）、且与至少一个正交证据一致时，才**提交**换模；否则**中止**，整个 episode 保持在快反包络内。这样慢推理的收益被吃到，其延迟却被**结构性地**挡在 actuation 关键路径之外。

**灵感 4（slack 是可调度预算 → 该在有余量时问，而不是在打滑时问）**
直觉：灵巧操作有天然节律——抓取、抬起、转运、放下，接触裕度时紧时松。R69 的交互预算是「次数 / 位移 / 社交成本」；R70 增加一个更本质的维度：**时间 slack**。最好的交互不是危机时刻的交互，而是**在 slack 最大、信息价值最高、且不破坏当前接触图**的相位提前做。这把交互从反应式变成**前瞻式调度**：用预测的未来接触相位做 VoI 规划，把一个慢查询安排进未来的空档。

**灵感 5（staleness 是新的「被证实的错误」）**
直觉：R69 的最大风险是「问错比不问更危险」。R70 的对应物是「**想对了，但用在了错的状态上**」：影子线程在预测状态 ŝ_{t+Δ} 上算出 m̂，而真实状态 s_{t+Δ} 已发生模式切换。一个 stale 且自信的结论比没有结论更危险，因为它会以「已验证」的姿态覆盖快反的正确直觉。所以必须引入**时滞有效性（temporal validity）**：提交需慢结论在真实到达状态上仍满足认证，且与快反证据一致；否则视为过期而非有效。

**灵感 6（跨域对偶 → 投机解码的物理版）**
直觉：投机解码的接受率取决于草稿与目标模型的一致性；这里的「接受率」取决于快反模式与慢推理模式的**模态一致性**与**时滞**。这给出一个可测的设计目标：最大化「在 deadline 内被安全接受的慢结论」比例（speculation acceptance α），同时保证 abort 代价有界。实时调度的 value-density 贪心（按 VoI/计算量排序）在可抢占、独立任务下最优——正好用来在接触相位内分配推理预算。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（KAIROS-RAS 总览）** KAIROS-RAS = (CMI, CHP, RFL, TCS, SPX, TVG, PVoI, DGC, RAS-WM‡)。五不变式：
(i) **实时环零学习写**（继承 R68 定义 276-i）；
(ii) **慢推理不在 actuation 关键路径**：任何换模必须经「草稿—验证—提交」，且提交前过 C-RAS-WM 认证；
(iii) **中止优先（abort-first）**：超时 / 失配 / staleness 越界 ⇒ 立即回快反包络，不得等待；
(iv) **时滞有效性**：慢结论只在其预测状态的可达集包含真实状态时有效；
(v) **证据纪律继承**（R69 定义 293-iii）：单源 / 单次交互不得单独定案。

**定义 311（接触模式与混合动力学）** 接触模式 m ∈ ℳ（有限或可数），每个 m 定义约束流形 𝒞_m、摩擦锥 ℱ_m、连续动力学 ẋ = f_m(x,u) 与守卫 / 重置映射 (G_{m→m'}, R_{m→m'})。真实接触轨迹是混合自动机的一条路径。接触模式后验 p(m|o_t) 由 CMI 在毫秒级更新。

**定义 312（时序预算与 slack）** 任务相位 π 有硬截止 D_π（下一接触事件的最晚时刻）。可用计算预算 B_π = ∫ρ(t)dt（ρ 为算力速率）。t 时刻的 slack σ(t) = D_π − t − τ_reflex，其中 τ_reflex 为快反最小反应延迟。推理只能在 σ(t) ≥ 0 的窗口内进行。

**定义 313（接触模式推断 CMI）** 以触觉阵列 a_tac、关节力矩 τ_j、视觉 v_t 为输入，输出 p(m|o_t) 与模式切换率 λ_sw。CMI 分两级：快级（< 0.2ms，触觉 + 力矩，线性 / 浅层）与慢级（影子线程，融合视觉与历史）。快级只回答「模式是否可疑」，慢级回答「是哪个模式」。

**定义 314（接触模式条件流策略 CHP）** 在 R69 FMP 上做混合条件：v_θ(x_s, s | z_t, m)，即速度场以接触模式为条件（mode embedding 或 mode-specific 输出头）。目标 L_CHP = E‖v_θ − (x_1 − x_0)‖² + λ_m·CE(m̂, m)。采样只在慢级进行；快级用 m 条件的 reflex 闭环。

**定义 315（前瞻 VoI，PVoI）** 信息动作 g 安排在未来时刻 t+Δ、预测状态 ŝ_{t+Δ}：
PVoI(g; Δ) = γ(Δ)·[H(M|o_t) − E_y[H(M|o_t, y)]] − c(g) − c_stale(Δ)，
其中 γ(Δ) = exp(−Δ/τ_val) 为价值时间折扣，c_stale(Δ) 为时滞风险成本。选择 (g*, Δ*) = argmax PVoI，s.t. Δ ≤ σ(t)、g 在未来状态可达集内可安全执行。
直觉：Δ 太大 → 价值被 γ 折光且时滞风险高；Δ 太小 → 计算来不及，且交互可能破坏当前接触图。最优 Δ 落在两者之间。

**定义 316（投机执行 SPX）** 影子线程在预测状态 ŝ_{t+Δ} 上运行 CHP + PVoI，得到候选模式 m̂ 与证据 e_slow；快反线程维护 m_ref 与证据 e_fast。提交判据：
Commit ⇔ (m̂ = m_ref) ∧ (e_slow 与 e_fast 至少一个正交源一致) ∧ (τ_slow ≤ D_π) ∧ (Reach(ŝ_{t+Δ}) ∋ s_{t+Δ}) ∧ (C-RAS-WM 认证通过)。
否则 Abort：m ← m_ref，λ ← λ_floor(U_ale + U_epi)（R69 定义 307 的未消解分支）。
「草稿」= m_ref；「验证」= 慢结论 + 认证；「提交」= 换模并执行慢策略产出的前缀。

**定义 317（中止代价与接受率）** 单次投机的中止代价 c_abort（计算浪费 + 可能的姿态扰动）。接受率 α = P(Commit)。设计目标：在给定预算 B_π 下最大化 E[收益] − c_abort·(1 − α)，并保证 P(abort 导致违规) = 0（定义 310-ii/iii）。

**定义 318（时滞有效性 TV）** 慢结论 m̂ 生成于预测状态 ŝ，提交于真实状态 s。若 s ∉ Reach_δ(ŝ)（δ 为预测误差容差），则 m̂ 过期。需满足 P(过期 ∧ 仍提交) ≤ ε_stale；由 CMI 的模式切换率 λ_sw 与预测视界 Δ 给出上界：P(切换于 Δ 内) ≤ 1 − exp(−λ_sw·Δ)。

**定义 319（实时调度器 TCS）** 把相位内推理任务建模为可抢占、带截止的独立任务 {k}，每个任务有 value density V_k/C_k（V 为 PVoI 增量，C 为计算量）。TCS 按 value density 贪心调度（可抢占、独立任务、单处理器下最优）。超预算任务被**降级**（K: 4→1、VoI 枚举剪枝、跳过 FMA 回放）而不是阻塞。

**定义 320（降级阶梯 anytime）** 五档算力配置 L0–L4：L0 纯快反（R68 边界，无慢推理）；L1 快级 CMI + mode_head；L2 K=1 CHP；L3 K=4 + 模态分解；L4 + PVoI 交互 + FMA。TCS 在 deadline 压力下逐档降级，且降级**单调安全**（Lk 的安全侧 ⊆ L(k−1)）。

**定义 321（快反安全包络 RFL）** 快反策略 π_ref 在模式 m_ref 下运行固定阻抗 / 反射规则，满足「对 m_ref 邻域内任何真实模式 m，接触力 ≤ F_max、位移 ≤ ε_g」。这是投机失败时的硬兜底，也是 R66–R69 全部安全约束在 1kHz 尺度的落地。

**定义 322（接触模式校准 CMC）** 触觉 / 力传感器的迟滞、温漂、贴片老化会让 p(m|o) 系统性偏移。用接触事件真值（已知的 make/break、受控滑移台）做温度 / 时间分层校准；ECE_mode > τ_mode ⇒ 禁用 L3+，退回 L1。

**定义 323（接触投毒干扰集 ℰ_contact）** 伪造触觉（假滑 / 假接触）、共振欺骗、以「抖动」掩盖真实滑移、标定漂移诱导误判模式、deadline DoS（注入高频事件耗尽 slack）。并入 AIC：ℰ_KAIROS = ℰ_FLUID × ℰ_contact × ℰ_time。

**定义 324（证书 J_KAIROS）** J_KAIROS = (J_FLUID, P(deadline miss), E[staleness], speculation_acceptance α, abort_risk, ECE_mode, tcs_degrade_count, kairos_ver)。Valid ⇔ Valid(J_FLUID) ∧ P(miss) ≤ ε_D ∧ E[staleness] ≤ ε_s ∧ α ≥ α_min ∧ abort_risk = 0。

**定义 325（时序对偶：快反 vs 慢推理）** 对同一状态，快反给出 m_ref（低延迟、低分辨率），慢推理给出 m̂（高延迟、高分辨率）。二者的一致性是一张实时可测的「第二意见」：长期不一致 ⇒ 快反模型失配或慢推理幻觉；短期不一致 ⇒ 正处于模式切换（应 abort 而非 commit）。这把 R69 的 (r_res, Δa) 对偶扩展到时间轴。

**定义 326（模式切换的可观测性）** 若某次模式切换在触觉 / 力信号上不可观测（同一读数对应两种模式），则 p(m|o) 不可辨识，PVoI 应把它当作 U_ale（不可约），不安排交互去「问」一个物理上不可观测的量——**交互只能消解可观测的歧义**。这是 R69 引理 16「模糊而不可分时交互无益」的接触版。

**定义 327（提交后的无缝换模）** 换模时沿用 R68 定理 15 的换装不变式：新模式下策略前缀必须在旧模式安全包络内起步（bumpless transfer），否则延迟换模到下一个 slack 相位。保证控制连续、无突变。

**定义 328（严格包含关系）** 当 σ(t) < τ_slow 或所有 PVoI ≤ 0 时，KAIROS 冻结在 L0（纯快反），逐指令等价于 R69 的「不交互」分支；当计算无限且无截止时，退化为 R69 完整 FLUID。⇒ KAIROS 是 R69 在「时间受限」边界上的泛化。

# IP-264 CMI：毫秒级接触模式后验（快级 + 慢级）
class ContactModeInference:
    def fast(self, tac, tau_j):              # <0.2ms，关键路径
        return self.fast_head(tac, tau_j)     # p_fast(m), suspicious
    def slow(self, o_hat):                    # 影子线程，预测未来状态
        return self.deep_head(o_hat)          # p_slow(m), lambda_sw

# IP-267 TCS：value-density 调度 + 降级阶梯
def schedule(tasks, B_pi, deadline):
    tasks = sorted(tasks, key=lambda k: k.value / k.cost, reverse=True)
    plan, used = [], 0.0
    for k in tasks:
        if used + k.cost <= B_pi and k.deadline <= deadline:
            plan.append(k); used += k.cost
        else:
            plan.append(downgrade(k))         # K:4->1 / 剪枝 VoI / 跳过 FMA
    return plan

# IP-268 SPX：草稿-验证-提交（abort-first）
def speculative_step(fast, slow, o_t, o_hat, D_pi):
    m_ref, e_fast = fast(o_t)
    t0 = now()
    m_hat, e_slow = slow(o_hat)               # 影子线程
    if now() - t0 > D_pi - tau_reflex:        # 超时
        return Abort(m_ref)
    if not reachable(o_hat, o_t, delta=DELTA_MAX):   # 时滞无效
        return Abort(m_ref)
    if not agree(m_hat, m_ref):               # 快慢不一致 -> 正切换
        return Abort(m_ref)
    if not orthogonal_evidence_agree(e_slow, e_fast):  # 证据纪律
        return Abort(m_ref)
    if not c_ras_wm.certify_mode(m_hat, o_t): # 认证
        return Abort(m_ref)
    return Commit(m_hat)

# IP-270 PVoI：前瞻交互（排进未来 slack，而非危机时刻）
def plan_interaction(modes, phase, sigma):
    best = None
    for g in info_candidates(modes):
        for d in future_slots(phase, max_delta=sigma):
            v = gamma(d) * info_gain(modes, g) - cost(g) - stale_cost(d)
            if best is None or v > best.v:
                best = (g, d, v)
    return best if best and best.v > 0 else None

# IP-275 主闭环（继承 R69，在时间层插入投机）

    m_ref, sus = M.cmi.fast(o.tac, o.tau_j)    # 1kHz 关键路径

## 3. 推导

**引理 19（接触模式价值的时滞衰减）** 设模式切换率 λ_sw、预测视界 Δ。慢结论到达时模式已变的概率 ≥ 1 − e^{−λ_sw Δ}，其信息价值被 γ(Δ) = e^{−Δ/τ_val} 折扣。则 PVoI 对 Δ 的导数在「计算来不及」与「结论已过时」两侧异号，存在唯一内部最优点 Δ*，且 Δ* 随 λ_sw 增大而减小。系：**接触切换越快，越应依赖低延迟证据，而不是更深思熟虑**——实时性不是工程妥协，而是模式动力学的函数。

**引理 20（提交的安全性）** 若满足 abort-first（定义 316）且快反包络对 m_ref 邻域内一切模式安全（定义 321），则任一轮物理风险 ≤ max(R69 保守风险, 认证后慢模式风险)；中止 / 超时 / 失配只减少信息，不增加风险。⇒ 投机不会比 R69 更危险。

**引理 21（value-density 调度最优性）** 在可抢占、独立、单处理器任务下，按 V_k/C_k 降序贪心在满足截止前提下最大化总价值（标准实时调度结论）；降级阶梯（定义 320）单调安全，因此任何降级都不破坏引理 20。

**引理 22（时滞可辨识性）** 若模式切换信号可观测（定义 326），则 CMI 的时滞误差可被「快慢不一致」提前检测：P(过期且提交) ≤ P(切换于 Δ 内)·P(快慢一致 | 切换) = O(λ_sw Δ · ε_agree)。故减小 Δ 或提高快反模式判别力都能压低过期率。

**定理 18（KAIROS 严格包含 R69）** 在 A99–A102 下，KAIROS 期望风险 ≤ R69；当 σ < τ_slow、PVoI ≤ 0 或 ECE_mode 越界时逐指令等价于 R69 的「不交互」分支；当无截止、算力无限时等价于 R69 完整 FLUID。安全侧不让步，效率侧获得「时间维度上的 resolution bonus」。

**定理 19（实时闭环的有界时延）** 快反路径最坏延迟 ≤ τ_reflex + O(1)，慢推理有界时延 ≤ D_π，二者通过 abort 条件解耦；因此 actuation 路径的抖动被快反包络吸收，慢推理的 P99 击穿只影响接受率 α，不影响安全。这是把 E292 的「总延迟」升级为「**关键路径延迟**」的理由。

## 6. 本轮最大风险

**一句话**：KAIROS 的安全性押在「快反包络对 m_ref 邻域内一切真实模式都安全」这一前提上——**若快反的模式判别在切换瞬间本身就有偏、或接触信号不可观测 / 被欺骗，abort-first 会把系统锁死在一个自信的错误模式里**：慢推理永远提交不了（因为总与快反不一致、或总来不及），R69 的「问错比不问更危险」就退化成更糟的「守着一个错误的安全感，连问都不问」。

**次级风险与缓解**：
1. **快反包络过保守**（邻域假设太宽 → 动作僵硬）→ 定义 320 降级阶梯 + 定理 19 关键路径解耦，慢推理只负责扩大动作集；
2. **投机接受率崩塌**（α 太低，慢推理白算）→ PVoI 前瞻调度 + value-density 排序 + E303/E315 Pareto 调档；
3. **时滞过期**（预测状态与真实状态脱节）→ 定义 318 + reachability 门 + E307；
4. **接触投毒 / 时序 DoS** → ℰ_contact 对抗训练 + deadline DoS 预算隔离 + E308；
5. **触觉漂移导致模式校准失效** → CMC 分层校准 + ECE_mode 越界退回 L1（定义 322）。

（本轮最大风险一句话：**快反的模式判别一旦在切换瞬间出错且慢推理永远无法安全提交，abort-first 会把「诚实的不知道」变成「自信的错误」，比 R69 更危险。**）

## 4. 推导

**引理 19（时滞衰减）** 切换于 Δ 内概率 ≥ 1−e^{−λ_sw Δ}，价值折扣 γ(Δ)=e^{−Δ/τ_val}，PVoI 对 Δ 的导数两侧异号 ⇒ 存在唯一 Δ*，且随 λ_sw 增大而减小。系：接触切换越快，越应依赖低延迟证据而非深思熟虑。

**引理 20（提交安全）** abort-first + 快反包络对 m_ref 邻域安全 ⇒ 任一轮风险 ≤ max(R69 保守风险, 认证后慢模式风险)；中止只减信息、不加风险 ⇒ 投机不劣于 R69。

**引理 21（调度最优性）** 可抢占、独立、单处理器任务下，按 V/C 降序贪心在截止内最大化总价值；降级单调安全，不破坏引理 20。

**引理 22（时滞可辨识）** 切换可观测时，快慢不一致可提前检测过期：`P(过期∧提交) ≤ O(λ_sw Δ·ε_agree)`。

**定理 18（KAIROS 严格包含 R69）** A99–A102 下期望风险 ≤ R69；σ < τ_slow、PVoI ≤ 0 或 ECE_mode 越界时逐指令等价于 R69「不交互」分支；无截止 / 算力无限时等价于 R69 完整 FLUID。

**定理 19（关键路径有界时延）** 快反路径 ≤ τ_reflex + O(1)，慢推理有界 ≤ D_π，二者经 abort 条件解耦；actuation 抖动被快反吸收，慢推理 P99 击穿只影响 α、不影响安全。⇒ 「总延迟」指标升级为「关键路径延迟」。

## 7. 本轮最大风险

**一句话**：KAIROS 的安全性押在「快反包络对 m_ref 邻域内一切真实模式都安全」这一前提上——**若快反的模式判别在切换瞬间出错、或接触信号不可观测 / 被欺骗，abort-first 会把系统锁死在一个自信的错误模式里**：慢推理永远提交不了（总与快反不一致或总来不及），R69 的「问错比不问更危险」就退化成更糟的「守着一个错误的安全感，连问都不问」。

**次级风险与缓解**：快反过保守（降级阶梯 + 关键路径解耦让慢推理只扩动作集）；接受率崩塌（PVoI 前瞻 + value-density + E303/E315）；时滞过期（reachability 门 + E307）；接触投毒 / 时序 DoS（ℰ_contact 对抗训练 + 预算隔离 + E308）；触觉漂移（CMC 分层校准 + ECE_mode 越界退回 L1）。
