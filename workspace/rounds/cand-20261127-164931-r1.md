### 第 4 轮灵感驱动研究记录

**灵感词**：指标体系、扩散策略

**直觉与动机**：

先给直觉。现有 CADVS 把安全写成「十二张证书」——这像机场安检的十二道闸机：每道闸机只会说「过 / 不过」，却没有人回答「整体安全裕度还剩多少、哪一类风险在恶化、离边界还有多远」。这正是「指标体系」要补的：把离散证书提升为**分层、可聚合、可诊断的度量空间**，让系统知道自己是在安全域深处，还是贴着边界飞行。另一方面，现有学生策略是确定性回归 π(o)→a，在双足接触、地形多模态处会把若干可行模式**平均**成一个不可行的中间动作（mode averaging）——「看起来平滑，实际踩空」。这正是「扩散策略」要补的：用生成式去噪过程表达多峰动作分布，再从分布中采样一整段动作块。

把两个词接起来：**指标体系不应是事后打分表，而应成为扩散生成过程的势函数与约束场；扩散策略也不是证书的替代品，而是在证书度量场中受引导地采样。** 这把安全范式从「生成后过滤（filter）」推进到「生成中受约束（generate-with-constraints）」。

再给第二层解读：「扩散」还有「传播」之意。多机器人系统中，单机的指标恶化会沿通信图向邻居扩散；若不控制扩散增益，局部故障会级联成全局振荡。因此本轮同时定义**指标扩散算子**，把「扩散策略」从生成模型延伸到风险传播动力学——这是跨学科视角（生成模型 × 图扩散 / 传染病阈值）带来的额外收获。

**关键洞见**：指标体系提供「度量语言 + 势函数」，扩散策略提供「多峰生成 + 传播算子」；二者结合，把单机安全从**过滤式**升级为**生成式**，把多机安全从**逐机门控**升级为**谱稳定性约束**。更深的洞见是：**指标不是中立的尺子，而是会被优化器反向塑造的目标**——一旦把 H 当作可微引导信号，扩散策略就会主动寻找指标的盲区。

**形式化目标（增量）**：
1. 定义分层证书指标体系 HCMS：M = (M₀ 原始证书, M₁ 维度指标, M₂ 复合健康度, M₃ 任务 KPI)，含归一化、非补偿聚合、硬否决。
2. 定义指标引导扩散策略 MGDP：在去噪每步注入指标梯度引导，并做可行域投影 / 拒绝重采样；给出 Exec_MGDP ⊆ Exec_CADVS 的条件。
3. 定义指标扩散算子 D 与级联稳定条件 ρ(αD) < 1，给出局部故障的稳态上界。
4. 定义 MCTE 动作块时序集成，使扩散块与 TCVM 证书有效窗口对齐，抑制块间抖动。
5. 证明非补偿聚合的零湮灭性（任一安全证书失败 ⇒ H = 0）；给出 best-of-K 在 i.i.d. 假设下的风险上界及其失效告警；给出谱半径条件的严格推导。
6. 实验设计：MuJoCo / Isaac 双足多地形，对比确定性学生、无引导扩散、拒绝式扩散、引导式扩散、教师 MPC，并加入「对抗刷指标」压力测试。

**本轮最大风险**：**指标体系是安全性的有损代理，而扩散策略是极强的代理优化器**——它会系统性地找到「高 H 但真实不安全」的动作（Goodhart / 代理坍缩），且这种失败在仪表盘上表现为「优秀」，比显式违规更隐蔽、更难触发熔断。

### IP-478 Hierarchical Certificate Metric System (HCMS)

```python
@dataclass
class HierarchicalCertificateMetricSystem:
    """HCMS：把十二证从布尔门控提升为四层可聚合、可诊断的指标空间。"""
    groups: dict[str, list[int]]          # M1 维度 -> 证书索引
    weights: dict[str, float]             # M1 维度权重，Σ=1
    thresholds: dict[str, float]          # M1 安全阈值 θ_j
    c_min: float = 0.05                   # 单证书最小裕度（硬否决线）
    tau_sm: float = 0.05                  # softmin 温度（可微代理）

    def normalize(self, margin: dict[str, float],
                  scale: dict[str, float]) -> np.ndarray:
        """原始物理裕度 -> [0,1]：0 在边界，1 在安全侧充裕。"""
        return np.array([np.clip(margin[k] / scale[k], 0.0, 1.0)
                         for k in sorted(margin)])

    def dimension_metrics(self, c: np.ndarray) -> dict[str, float]:
        """组内用 product t-范数：任一证书为 0 则整维为 0（非补偿）。"""
        return {j: float(np.prod(c[idx])) for j, idx in self.groups.items()}

    def health(self, c: np.ndarray) -> tuple[float, dict[str, float]]:
        """复合健康度：硬否决 + 组间加权几何平均。

        硬否决保证非补偿：任一安全证书 < c_min 或任一维度 < θ_j，H 直接为 0，
        再高的其他维度也不能「补偿」一个致命违规。
        """
        m = self.dimension_metrics(c)
        if np.any(c < self.c_min) or any(m[j] < self.thresholds[j] for j in m):
            return 0.0, m
        log_h = sum(self.weights[j] * np.log(max(m[j], 1e-12)) for j in m)
        return float(np.exp(log_h)), m

    def soft_health(self, c_hat: torch.Tensor) -> torch.Tensor:
        """可微代理：log-sum-exp 近似 min，保留引导梯度；仅用于去噪引导。"""
        return -self.tau_sm * torch.logsumexp(-c_hat / self.tau_sm, dim=-1)

    def audit_report(self, c: np.ndarray) -> dict:
        """诊断视图：不仅给 H，还给「哪一维在恶化、离阈值多远」。"""
        h, m = self.health(c)
        return {
            'H': h,
            'dims': m,
            'margins_to_threshold': {j: m[j] - self.thresholds[j] for j in m},
            'worst_cert': int(np.argmin(c)),
            'veto': h == 0.0,
        }
```

**设计要点**：`M₀` 为归一化证书；`M₁` 用 product t-范数而非加权和，避免「高裕度证书补偿低裕度证书」；`M₂` 的硬否决是安全底线；`M₃`（成功率、恢复率、舒适度）只用于离线审计与指标校准，**不进入在线引导**，以免任务 KPI 反向污染安全度量。

### IP-479 Metric-Guided Diffusion Policy (MGDP)

```python
def mgdp_sample(policy, cert_pred, hcms, o, L=16, d=18,
                T=10, eta=0.5, K=4, c_min=0.05):
    """指标引导扩散：K 条独立链，去噪每步做指标梯度上升 + 可行域投影。"""
    feasible = []
    for _ in range(K):
        x = torch.randn(L, d)
        for tau in reversed(range(1, T + 1)):
            eps = policy.eps_theta(x, tau, o)
            abar = policy.abar[tau]
            x0 = (x - (1 - abar).sqrt() * eps) / abar.sqrt()

            # --- 指标引导（可微代理，仅推安全裕度，不直接优化任务回报）---
            a0 = x0.detach().requires_grad_(True)
            c_hat = cert_pred(a0, o)                 # (n,)
            loss = -hcms.soft_health(c_hat)          # 最小化 = 最大化健康度
            g = torch.autograd.grad(loss, a0)[0]
            x0 = x0 - eta * (1 - abar).sqrt() * g    # 梯度上升 H
            x0 = x0.detach()

            # --- 硬可行域投影（CFP）---
            x0 = project_feasible(x0, cert_pred, hcms, c_min)

            # --- DDIM 反向一步 ---
            abar_prev = policy.abar[tau - 1]
            x = abar_prev.sqrt() * x0 + (1 - abar_prev).sqrt() * eps

        c_final = cert_pred(x, o)
        h, _ = hcms.health(c_final)
        if h > 0.0:                                  # 硬否决：H=0 直接丢弃
            feasible.append((h, x))

    if not feasible:
        return None                                  # 交回教师 / 急停兜底
    feasible.sort(key=lambda t: t[0], reverse=True)
    return feasible[0][1]                            # best-of-K
```

**实时性解耦**：扩散只在 **20–50Hz** 的规划层运行并输出 L=16 步动作块；200Hz 视觉伺服与证书校验仍在底层闭环执行、跟踪插值后的参考。这样避免在 200Hz 硬实时环内跑多步去噪。

### IP-480 Certificate Feasibility Projection (CFP)

```python
def project_feasible(a, cert_pred, hcms, c_min, iters=8):
    """把动作块投到 F_cert。凸约束用 Dykstra；非凸则梯度投影 + 最终拒绝。"""
    for _ in range(iters):
        c = cert_pred(a, hcms_ctx)                   # (n,)
        # 约束 g_i(a) = c_min - c_i <= 0；对越界者沿证书梯度回推
        viol = torch.clamp(c_min - c, min=0.0)
        if float(viol.max()) < 1e-6:
            break
        grad_c = torch.autograd.grad(c.sum(), a, retain_graph=True)[0]
        a = (a + 0.5 * grad_c * viol.sum()).detach()
    return a


def certify_or_reject(a, cert_pred, hcms, c_min):
    """投影后仍不可行 -> 拒绝，交由 best-of-K / 教师兜底。"""
    c = cert_pred(a, hcms_ctx)
    return hcms.health(c)[0] > 0.0 and bool((c >= c_min).all())
```

**诚实声明**：`F_cert` 一般**非凸**（证书由非线性动力学/接触产生），Dykstra 只在凸集上保证收敛。因此 CFP 的定位是「提高可行样本命中率」，最终安全由 `certify_or_reject` 的硬拒绝兜底，而非由投影的数学收敛保证。

### IP-481 Metric-Consistent Temporal Ensembling (MCTE)

```python
class MetricConsistentTemporalEnsembling:
    """扩散块每 20–50ms 重规划，需与 TCVM 证书有效窗口对齐并抑制块间抖动。"""
    def __init__(self, L=16, decay=0.7, tau_age=0.05):
        self.L, self.decay, self.tau_age = L, decay, tau_age
        self.chunks: list[tuple[int, torch.Tensor, float]] = []  # (t_gen, a, H)

    def update(self, t_now, new_chunk, new_h, cert_age):
        # 过期块剔除：证书年龄超过有效窗口的块不得再参与融合（引理 31）
        self.chunks = [(tg, a, h) for tg, a, h in self.chunks
                       if t_now - tg < self.tau_age]
        self.chunks.append((t_now, new_chunk, new_h))
        # 时间衰减 + 健康度加权的凸组合（仅融合仍有效的块）
        out, wsum = torch.zeros_like(new_chunk), 0.0
        for tg, a, h in self.chunks:
            w = (self.decay ** (t_now - tg)) * max(h, 1e-6)
            out, wsum = out + w * a, wsum + w
        return out / max(wsum, 1e-9)

    def jitter(self, prev_cmd, cmd):
        return float(torch.norm(cmd[:6] - prev_cmd[:6]))   # 基座位姿抖动代理
```

### IP-482 Metric Diffusion & Governance Monitor (MDGM)

```python
@dataclass
class MetricDiffusionMonitor:
    """把『扩散』读作风险传播：r(k+1) = α·W·r(k) + b(k)，监控谱半径。"""
    W: np.ndarray                 # 行随机邻接（ρ(W)=1）
    alpha: float = 0.6            # 扩散增益；必须 < 1
    gh_alarm: float = 0.15        # Goodhart 间隙告警阈值

    def __post_init__(self):
        rho = float(np.max(np.abs(np.linalg.eigvals(self.alpha * self.W))))
        assert rho < 1.0, f'指标扩散不稳定：ρ={rho:.3f} ≥ 1'
        self.rho = rho

    def step(self, r, b):
        return self.alpha * self.W @ r + b

    def steady_state_bound(self, b_max):
        # 一致上界：‖r(∞)‖ ≤ b_max / (1 − α)
        return b_max / (1.0 - self.alpha)

    def goodhart_probe(self, h_index, true_safety):
        """H 高但真实安全低 -> 代理坍缩。true_safety 由独立物理判据给出，
        且绝不参与扩散引导，避免探针被同一目标污染。"""
        high = h_index > 0.8
        gap = float(np.mean(true_safety[~high] - true_safety[high]))
        return {'gamma_GH': gap, 'alarm': gap > self.gh_alarm}

    def governance(self, gap_alarm: bool, metric_drift: bool):
        if gap_alarm:
            return 'FREEZE_GUIDANCE_FORCE_TEACHER'   # 停止用 H 引导，退回证书过滤
        if metric_drift:
            return 'RECALIBRATE_OR_FALLBACK'         # 指标分布漂移，重标定阈值
        return 'NORMAL'
```

### MGDP 与 CADVS 单步执行流的集成

```python
def mgdp_step(robot_state, sensor_data, t_now):
    cert_agg = wait_for_topic('/cert/aggregated', timeout=0.005)
    if cert_agg is None or not cert_agg.all_passed:
        return fallback_to_teacher(robot_state, sensor_data, reason='cert_agg_fail')

    # 1) 规划层（20–50Hz）：扩散采样 + 指标引导 + 硬拒绝
    if t_now - last_plan_t >= 1.0 / SLO_replan_hz:
        chunk = mgdp_sample(policy, cert_pred, hcms, obs(robot_state, cert_agg))
        if chunk is None:
            return fallback_to_teacher(robot_state, sensor_data, reason='no_feasible_chunk')
        buffer.push(chunk)
        last_plan_t = t_now

    # 2) 控制层（200Hz）：MCTE 融合 + 视觉伺服叠加 + 证书门控
    ref = buffer.pop_reference()
    vs_out = wait_for_topic('/ctrl/vservo', timeout=0.002)
    fqc = wait_for_topic('/cert/vservo', timeout=0.002)
    if vs_out and fqc and fqc.valid and fqc.kc_active:
        u = blend_chunk_vservo(ref, vs_out.u, alpha=0.3)
        path = 'diffusion+vservo'
    else:
        u = ref
        path = 'diffusion'

    # 3) 消费端强制复核：证书在消费时刻仍有效（TCVM / 引理 31）
    if not tcvm.valid_now(cert_agg, t_now):
        return fallback_to_teacher(robot_state, sensor_data, reason='cert_expired')
    return ControlOutput(u, path=path, certs=cert_agg)
```

## 4. 正确性论证（增量）

### 引理 32（非补偿聚合的零湮灭性与执行集包含）

**陈述**：设 HCMS 的组内聚合 T_⊗ 为 product 或 min t-范数（零湮灭：T(x,0)=0），硬否决阈值为 c_min>0、θ_j>0。则对任意动作块 a：
1. 若任一安全证书 c_i(a)=0，则其所属维度 m_j=0，硬否决失败，H(a)=0；
2. `H(a) > 0` 当且仅当 `c_i(a) ≥ c_min` 且 `m_j(a) ≥ θ_j` 对所有 i,j 成立；
3. 因而 `Exec_MGDP = {a : H(a)>0} ⊆ Exec_CADVS`。

**证明**：由 t-范数零湮灭性，组内任一因子为 0 则乘积/最小值为 0；`m_j=0<θ_j` 触发硬否决，故 H=0。反向：若所有 c_i≥c_min>0 且 m_j≥θ_j>0，则硬否决通过，且几何平均 ∏m_j^{w_j}>0，故 H>0。执行集包含性由 `mgdp_step` 只接受 H>0 的块并复用 `/cert/aggregated` 十二证直接得到。∎

**工程含义**：只要硬否决实现正确，MGDP 就不会用「高健康度」把一次致命违规补偿掉；这是与纯加权和指标体系的本质区别。

### 引理 33（投影 / 拒绝的可行性保证）

**陈述**：设 `F_cert` 闭。若 `F_cert` 凸且 `Proj_F` 精确，则 CFP 输出的每个样本属于 `F_cert`。若 `F_cert` 非凸，改用 K 条独立拒绝采样链，每条命中概率为 p>0，则「至少一条可行」的概率为 `1−(1−p)^K`，且返回样本可行。

**证明**：凸集上的精确投影按定义落在集合内。拒绝采样部分：K 条链相互独立（独立随机种子），每条失败概率 1−p，全失败概率 (1−p)^K，取补即得；被返回的样本按构造已通过 `certify_or_reject`。∎

**诚实声明**：K 条链只有在**独立**时才成立。扩散模型存在模式坍缩时，K 条链高度相关，p 的有效值被高估——这是 best-of-K 最容易被误用的地方（见引理 35 的告警）。

### 引理 34（指标扩散的级联稳定性）

**陈述**：设风险传播 `r(k+1)=α_diff·W·r(k)+b(k)`，W 行随机（ρ(W)=1），α_diff≥0。则：
1. ρ(α_diff W)=α_diff；
2. 若 α_diff<1，则 ‖r(k)‖ ≤ α_diff^k‖r(0)‖ + b_max·(1−α_diff^k)/(1−α_diff)，稳态上界 b_max/(1−α_diff)；
3. 若 α_diff≥1，则常值故障 b>0 下风险不衰减（α=1）或无界增长（α>1），单点故障可级联为全局振荡。

**证明**：ρ(αW)=|α|ρ(W)=α。由 Neumann 级数，`(I−αW)^{-1}=Σ_{m≥0}(αW)^m` 在 α<1 时收敛，且 `‖(αW)^m‖≤α^m`，代入递推得界。α≥1 时，取 W=I、b>0 得 r(k)=r(0)+k·b 无界；α=1 且 b=0 时初始扰动永不衰减。∎

**工程含义**：多机系统的「扩散策略」必须满足 α_diff<1（本方案取 0.6）；α_diff 不是可随意调大的鲁棒性旋钮，而是传染病模型中的基本再生数的倒数——**超过 1 就是疫情失控**。

### 命题 1（生成式安全的近似保证，非严格）

**陈述**：若 (i) 扩散 score 精确；(ii) `F_cert` 凸且投影精确；(iii) 引导权重 η→∞，则 MGDP 的采样分布收敛到截断分布 `p(a | a ∈ F_cert)`。有限 η 时，与截断分布的 KL 散度受 `η · Lip(M̃) · Δ_surrogate` 控制，其中 Δ_surrogate 是 softmin 代理与硬 min 指标之间的差。

**证明思路**：η→∞ 时引导项主导去噪漂移，概率质量被推到 F_cert 的支撑集上，等价于对基分布做硬截断；有限 η 时用 Girsanov 定理比较引导前后路径测度，KL 由引导漂移的平方积分界定，而漂移正比于 η·∇M̃；代理与硬指标的差进入漂移误差项。∎（完整证明需 score 的 Lipschitz 与 Novikov 条件，本方案不声称已满足。）

**诚实声明**：真实部署中 (i)(ii) 均不成立：ε_θ 是学出来的、F_cert 非凸、softmin≠min。因此本命题只用于说明「引导方向正确」，**不作为安全证书**；真正的安全由引理 32 的硬否决与 `certify_or_reject` 承担。

### 引理 35（best-of-K 的代理失效告警）

**陈述**：若 K 条链独立且单链可行概率为 p，则失败概率 (1−p)^K 单调下降。但若链间相关系数为 ρ_corr>0，则有效独立样本数 `K_eff = K / (1+(K−1)ρ_corr)`，失败概率下界为 `(1−p)^{K_eff}`。当 K_eff→1 时，增大 K 不再降低风险。

**证明**：等相关系数下，K 个伯努利变量的联合失败概率不小于独立情形，有效样本数由方差膨胀公式给出；K_eff 随 ρ_corr 单调下降。∎

**工程含义**：MDGM 必须监控「候选块的动作多样性」（如成对 L2 距离的均值）与 `K_eff` 估计；若多样性塌缩，best-of-K 只是自我安慰，应降级到教师路径而非继续加 K。

## 5. 实验设计

### 5.1 平台与任务
- **仿真**：MuJoCo 双足（地形课程：平地 → 随机台阶 → 湿滑低摩擦 → 可变形软地），Isaac Gym 并行 4096 环境用于训练扩散策略与证书预测器。
- **真实**：Unitree G1/H1，室内外混合地形；仅做小样本验证，不追求统计显著。
- **证书预测器 C_ψ**：以仿真中可微动力学生成 (a, o) → c 数据，训练 MLP/GRU 代理；用真实数据做域适配并报告代理误差。

### 5.2 对比方法
| 方法 | 说明 |
|---|---|
| B0 确定性学生 | v30 的单峰回归策略 |
| B1 无引导扩散 | 纯扩散策略，仅最终硬否决 |
| B2 拒绝式扩散 | 扩散 + best-of-K 硬拒绝，无梯度引导 |
| B3 引导式扩散（本方案） | 指标梯度引导 + CFP + best-of-K |
| B4 教师 MPC | KT-MPC 十二证，性能上界 / 安全基线 |
| B5 加权和指标（消融） | 用加权和替换非补偿聚合，验证「补偿」的危害 |

### 5.3 指标
- **安全性**：每千步硬违规次数、真实跌倒率、最坏单维裕度。
- **任务**：成功率、恢复时间、能耗。
- **生成质量**：模式覆盖（多峰地形上的成功模式数）、块间抖动、OOD 动作比例。
- **实时性**：规划层 P50/P99 延迟、控制层 P99、丢帧率。
- **治理**：γ_GH（Goodhart 间隙）、K_eff、指标漂移检测延迟。

### 5.4 关键实验
1. **多峰地形**：验证扩散相对确定性学生的 mode-averaging 改善（假设：B1/B3 成功率 ≥ B0 + 15%）。
2. **引导消融**：η ∈ {0, 0.1, 0.5, 1.0, 2.0}，观察安全–多样性权衡；预期 η 过大时 OOD 比例上升、成功率反降。
3. **聚合消融**：B5 加权和 vs 非补偿；构造「一维致命、其余优秀」的场景，验证 B5 会把 H 打高而真实跌倒。
4. **对抗刷指标**：固定 C_ψ，用梯度上升最大化 H 生成对抗动作块，测量真实安全性；这是本方案的「压力测试」，预期会暴露 γ_GH > 0。
5. **多机级联**：N=5 机器人，注入单机指标故障，扫描 α_diff ∈ {0.3, 0.6, 0.9, 1.0, 1.2}，验证 ρ<1 的稳态界与 α≥1 的级联失稳。
6. **分布漂移**：测试地形分布外推（未见过的摩擦/坡度），观察 H 与真实安全的背离随时间的变化。

### 5.5 预期结果与判据
- B3 相对 B1 硬违规率下降 ≥ 40%，相对 B0 成功率提升 ≥ 15%，规划层 P99 < 20ms（经一致性蒸馏）。
- B5 在「一维致命」场景的跌倒率显著高于 B3，作为非补偿聚合必要性的证据。
- 对抗刷指标实验预期出现 γ_GH 显著为正——**这是负面结果，但必须报告**，它界定了指标体系的可信边界。

## 7. 本轮最大风险（最终确认）

**一句话**：**指标体系是安全性的有损压缩，而扩散策略是一个高容量的代理优化器**——二者结合会把「优化指标」变成「利用指标的盲区」，产生 H 很高、仪表盘全绿、真实安全性却持续下降的**代理坍缩（Goodhart）**；这种失败没有显式违规可触发熔断，是整个「生成式安全」路线最深的隐患，也是必须用独立探针与红队审计而非同一目标来自证清白的根本原因。
