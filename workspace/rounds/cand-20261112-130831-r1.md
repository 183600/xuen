# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「域随机化」×「交互设计」）

> 第 57 轮把安全的赌注从"证据质量"推进到"元先验质量 + 跨模态一致性 + 个性化信任"，并用 OOD 门 + 共形保底试图让"坏先验"只造成慢而不造成错；但它在风险自陈里留下了本轮要处理的两个硬骨头：**(a)** 元推断器的盲区无法被它自己的 OOD 门识别——门是用同一份语料训练出来的，"语料里没有的世界"恰恰是门最自信的地方；共形保底只是把"不知道"变宽，却把"自信地错"保留了下来。**(b)** 第 57 轮把交互压缩成"人在某个接口上给出标注/确认"，只按错误率与偏置给权重，却默认接口是中性的：实际上**提问格式本身决定了能提取多少信息、以及会引入什么偏置**——同一个操作者，yes/no 会橡皮章，pairwise 会思考，counterfactual 会把隐含假设说出来。本轮两个灵感各解一半：**域随机化**把"对单一世界参数的信念"换成"对一个显式世界集合的鲁棒性"，使安全性成为对集合成员的**结构性**性质，并让"集合是否覆盖真实世界"成为可被单次反例证伪的支撑证书；**交互设计**把"接口"从被动通道升级为**被优化的证据获取动作**——查询格式 q 是可设计、可校准、可带偏置证书的决策变量，且**可逆性匹配摩擦**让 L0/L1/L2 的交互强度与不可逆程度同序。两者合成一条新的安全经济学：**世界集合的宽度是安全的价格，交互信息是把它付清的货币，而这块"支撑地板"永远不能由人言来降低**。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"对显式世界集合鲁棒、用设计化交互付清、支撑地板不可被人言降低的证据说可信"**。

核心矛盾：
- **H29（随机化 vs 可辨识：空洞保守与集内自信）**：域随机化用"对集合最坏情况安全"换掉"对点估计的信任"，但集合过宽 ⇒ 永远 halt（空洞保守，机器人寸步难行）；过窄 ⇒ "集内自信地错"，且错得比点估计更隐蔽（因为它披着鲁棒性的外衣）。随机化分布的**支撑**本身是不可验证的先验——坏先验问题没有消失，只是从"均值"上移到了"支撑"上；更糟的是，DR 通常围绕元后验均值随机化，第 57 轮的语料盲区会被原样"随机化"（randomize the blind spot），而不是被消除。
- **H30（设计化征询 vs 制造同意）**：提问格式决定信息量与偏置；低摩擦格式（yes/no）易橡皮章，高信息格式（pairwise/counterfactual）易锚定与诱导。一旦允许"交互信息降低保守度"，接口设计就成了安全的隐式输入——一个被设计得很好的坏问题，可以稳定地制造出"证据"来降低保守度。这是从"获取信息"滑向"制造同意"。

## 0. 直觉与动机

**灵感 1（域随机化 → 显式世界集合 + 鲁棒承诺）**
直觉：与其赌"世界是哪个点"，不如承认"世界可能是这一族里的任何一个"，并要求承诺对这一族**都**安全。DR 的经典用法是为仿真参数抽样、练出对参数分布鲁棒的政策；这里把它倒过来用：**不训练政策，而是把世界参数的不确定性变成集合 𝒲(r)，承诺门改为 worst-case over 𝒲(r)**。于是保守度不再由"模型多自信"决定，而由"集合多宽"结构性决定：不确定性变大 ⇒ 集合变宽 ⇒ 鲁棒风险单调上升 ⇒ 自动更保守。这个单调性是**构造出来的**，不依赖任何统计校准——这正是对第 57 轮"校准可能自信地错"的正面回应。

**灵感 2（域随机化 → 支撑证书与实界差距；把 OOD 变成可证伪）**
直觉：DR 的致命前提是"真实世界在随机化支撑里"。这个前提不该被假设，而该被**证书化并持续监控**：声明支撑覆盖概率 1−α_sup，并以"观测序列到集合可解释观测集的最小距离" G(r) 做实时监控——**只要有一次观测无法被集合中任何世界解释，支撑就被证伪**，系统扩张集合并自动变保守（r_sup 不减）。这把第 57 轮"只能统计地怀疑 OOD"升级为"能被单次反例钉死的支撑失效"。更主动地：既然安全依赖 α_sup，那么最值钱的探针不是探集合中心，而是**探支撑边界**（probe the edge）——一个恰好落在边界外的观测能把 α_sup 一次性打下来。

**灵感 3（交互设计 → 查询是被优化的证据动作）**
直觉：人在 yes/no 里容易橡皮章，在"这两处哪块更可能承重"里会被迫思考，在"如果我踩下去，你预期会发生什么"里会把隐含假设说出来。既然查询格式改变信息量与错误结构，就不该把接口当常量：把查询 q 变成决策变量，用**查询条件错误模型 ε_q、偏置界 β_q、信息增益 IG(q)** 来选 q*，并让摩擦与不可逆程度同序（L0 无摩擦、L1 低摩擦带 undo、L2 反事实预览 + 强制延迟）。**可逆性匹配摩擦**（RMF）是把 HCI 的"错误预防/撤销"原则直接对接到同意阶梯。

**灵感 4（交互设计 → 非操纵地板：交互只能锐化集内信念，不能降低支撑）**
直觉：人可以告诉你"我更像是站在这一类表面"，从而锐化你在集合内的信念；但人不能替你排除"还有一类你从未想过的表面"。所以把状态分成两层：**支撑地板 r_sup 只能由世界侧证据（探针、边界观测、新语料）写**；**交互只在 𝒮_DR 内部再加权、收缩集内不确定性**。这不是保守，而是**防操纵的结构不变量**——无论接口被设计得多"好"、多会引导，都动不了这块地板。于是即使征询被博弈，最坏结果也只是"集内信偏"，而不是"承诺跑到世界集合之外"。

**灵感 5（合流 → 两条现实差距、一条兑换率）**
直觉：DR 处理"世界现实差距"（仿真/语料到真实），交互设计处理"交互现实差距"（接口训练分布到真实操作者），二者是同构的——都靠**声明的证书**（α_sup / ε_q,β_q）而不是靠"应该没问题"。并给出一条**兑换率**：合格交互以 `ΔU ≤ η·IG(q)` 的量收缩集内不确定性，但绝不能收缩 r_sup。安全由此分解为两个不可互相透支的账户：**世界侧不可约风险（r_sup）+ 人侧可约不确定性（U）**。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（随机化世界集合 RWE 与鲁棒承诺）** 世界参数 w∈ℝ^d（μ, k, F_bear, 摩擦, 刚度梯度）。维护经验测度 P̂_r=(1/M)Σ_i δ_{w_i}，w_i 从元后验 q_φ(·|o,z_r) 与域随机化支撑 𝒮_DR 的联合采样中取得。对承诺动作 a 定义**分布鲁棒风险** R_wc(a,r)=sup_{P: W_2(P,P̂_r)≤r_sup(r)} E_P[ℓ(a,w)]，ℓ 为承诺失效损失。**鲁棒承诺门**：a 可提交 ⇔ R_wc(a,r)≤δ_f 且 a 属当前可行步态档。若 ℓ 关于 w 为 L-Lipschitz，则 R_emp≤R_wc≤R_emp+L·r_sup——**半径 r_sup 就是安全的标价**。保守单调性：spread(P̂_r)↑ 或 r_sup↑ ⇒ R_wc↑（构造性，不依赖校准）。

**定义 140（支撑证书与实界差距 SGC）** 支撑证书：P(w*∈𝒮_DR)≥1−α_sup；r_sup(r) 取为真实分布偏移 W_2(P_{w*},P̂_r) 的 (1−α_sup) 置信上界（分层共形 / 模拟标定 / 专家域声明）。实界差距 G(r)=d(o_{1:k}, ⋃_{w∈𝒲(r)}O(w))，O(w) 为世界 w 可产生的观测集。规则：(G1) G>θ_gap ⇒ 观测未被集合解释 ⇒ 触发 Expand(𝒲)（加入解释该观测的新世界簇，r_sup 不降或升）或拒承诺；(G2) 边界观测（G∈[θ_edge,θ_gap]）计入 α_sup 的共形更新（降 α_sup，即"用边界探针买覆盖"）；(G3) **r_sup 与 α_sup 只由世界侧证据写，交互证据不可写**（非操纵地板，见定义 142）。

**定义 141（设计化征询 DEQ）** 查询空间 𝒬={yn, pairwise, counterfactual, demo, point}。查询条件错误模型 ε_q(s_o) 与偏置界 β_q=TV(P(ans|q,w*), P(ans|q_neutral,w*))。集内决策熵 H_𝒲(π*)（π* 为 𝒲 内最优动作）。信息增益 IG(q)=H_𝒲(π*)−E_{ans}[H_𝒲(π*|ans)]。查询选择：q*=argmax[IG(q)−λ_c·cost(q,s_o)−λ_b·β_q/β_max]，约束 ε_q≤ε_max、β_q≤β_max，β_q 未声明即视作 β_max。**可逆性匹配摩擦 RMF**：friction(L0)=0 < friction(L1)=低摩擦+undo < friction(L2)=反事实预览+强制延迟，friction 参与 cost(q)，不可逆层禁止"顺手确认"。

**定义 142（交互信息证书 IIC 与非操纵地板）** 交互答案以查询条件似然在 𝒮_DR **内部**对 P̂_r 再加权，得集内收缩 ΔU(𝒲)。**证书**：仅当 ε_q、β_q 在留出交互日志上被验证且 β_q≤β_max 时，交互才可收缩集内不确定性；兑换率约束 **ΔU ≤ η·IG(q)·1[IIC]**，η 为声明系数。**硬不变量**：任何交互更新（含偏置、含恶意）都不得修改 r_sup 与 α_sup；因此部署界中 α_sup 项与 r_sup 对交互完全不变，承诺不可能因"人言"被推出 𝒮_DR。这是"交互可以赢得效率、不能赢得越界"的形式表达。

**定义 143（格式条件警觉 QAV，升级 IP-135）** 对查询格式 q 定义参与度 E_q=f(响应时延相对 τ_exp(q)、二次确认率、pairwise 跨轮一致性、counterfactual 回答可解释性)。橡皮章判据按格式分设：yn 用严格时延+高频判据；pairwise/counterfactual 设最低推理时延 τ_min(q) 与一致性门槛。**只有高参与格式的一致回答才计入 n_verify 并允许授权升级；低参与格式再多也只维持 A0/A1。** 个性化仍单向有界：降级实时、升级有据有界。

**定义 144（随机化-征询统一算子 PCE++）** 每检查点：①由 q_φ 与 𝒮_DR 刷新 P̂_r 与 r_sup；②算 R_wc，若 ≤δ_f 且证据门过则承诺；③否则在**探针（世界侧：更新 P̂、可能降 α_sup/升 r_sup、触发扩张）**与**征询（人侧：验 IIC 后收缩集内 U）**之间按统一 VOI 竞争：VOI_probe 与 VOI_elicit=η·IG(q*)−cost−λ_b·β_q/β_max；④执行、重算、G 监控；⑤终止于 {鲁棒承诺, 绕行, L2 协商, 安全停}，每检查点交互预算 k_elicit、探针预算 k_probes+k_cons。

## 2. 关键算法伪代码

```python
def rwe_commit(W, cp, a):                       # IP-139
    R = dro_sup(W.Phat, radius=W.r_sup,          # W2 球内最坏损失
                loss=lambda w: fail(a, w))
    return a if R <= delta_f else None, R

def sgc_monitor(W, obs, dr, audit):              # IP-140
    G = min(dist(obs, observable_set(w)) for w in W.worlds)
    if G > theta_gap:                            # 支撑被单次反例证伪
        return expand(W, new_cluster(obs)) if explainable(obs) else 'halt'
    if G >= theta_edge:                          # 边界探针：买覆盖
        dr.alpha_sup = conformal_update(dr.alpha_sup, obs)
    audit.log(G); return W

def design_query(U, s, level, budget):           # IP-141
    cands = admissible(level)                    # RMF 决定可用格式
    q = max(cands, key=lambda q: info_gain(q, U)
            - lam_c*cost(q, s) - lam_b*bias(q)/beta_max)
    return q if info_gain(q, U) > theta_ig else None

def iic_contract(W, q, ans, log):                # IP-142
    if not log.certified(q):                     # ε_q/β_q 未验证
        return W, 'no_contract'                  # 只能加宽/不变
    W2 = reweight_within_support(W, like(q, ans))
    assert W2.r_sup == W.r_sup                   # 非操纵地板：不可写
    return W2, 'contracted'

def qav_update(s, q, ans, lat):                  # IP-143
    e = engagement(q, ans, lat)
    if e < tau_min(q):                           # 格式条件橡皮章
        s.vig, s.auth = down(s.vig), demote(s.auth)
    elif is_high_engage(q) and e >= tau_min(q):
        s.n_verify += 1
    return bounded_promote(s)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| RWE | O(M·d_w)/检查点 + O(M·d_w) 采样 | O(M·d_w) | r_sup 标定诚实、ℓ Lipschitz |
| SGC | O(M·\|obs\|) 最近世界查询 | O(M·\|O\|) | G 漏检 ≤δ_gap、r_sup 只增于证据 |
| DEQ | O(\|𝒬\|·(IG+H)) | O(\|𝒬\|) | ε_q/β_q 声明诚实、RMF 单调 |
| IIC | O(M) 再加权 | O(M) | 只在 𝒮_DR 内、ΔU≤η·IG、r_sup 不可写 |
| QAV | O(1) | O(H_op) | 格式阈值诚实、升级有界 |
| PCE++ | O(\|CP\|·(k_p+k_c+k_e)·(M+C_VOI)) | O(\|V\|+M) | 双通道 VOI、预算终止 |

**正确性定理（DRIS, Domain-Randomized Interaction-certified Soundness）**：在 A33–A40 之上加 (A41) 支撑证书 P(w*∈𝒮_DR)≥1−α_sup 且 G 漏检 ≤δ_gap；(A42) r_sup≥真实 W_2 偏移（w.p.1−α_sup）且 ℓ 为 L-Lipschitz；(A43) 交互证书 ε_q/β_q 诚实、ΔU≤η·IG、**r_sup/α_sup 仅世界侧可写**；(A44) QAV 参与度判据诚实。则：
(i) **鲁棒健全性**：P(fail)≤δ_f+α_sup+δ_gap+ε_meta(k)+δ_probe（对检查点取联合界）；
(ii) **保守单调性**：spread↑ 或 r_sup↑ ⇒ R_wc↑，且该单调性是构造性的（不依赖后验校准正确）；
(iii) **非操纵性**：任何交互更新不改变 α_sup 与 r_sup，故交互最多把集内信念锐化到"支撑允许的最优"，永远不能使承诺发生在 𝒮_DR 所覆盖世界之外；偏置交互最多造成集内信偏（≤β_q），不能越界；
(iv) **终止性**：每检查点探针 ≤k_probes+k_cons、交互 ≤k_elicit，PCE++ 在有限步内落入 {承诺, 绕行, L2 协商, 安全停}。

## 6. 本轮最大风险

**一句话**：本轮把"坏先验普遍"换成了"**坏支撑集普遍**"——域随机化让安全变成"对我声明的世界集合鲁棒"，若支撑过窄，系统会**围绕错误的世界既精确又自信**，而设计化征询又会高效地把人力用于锐化一个错位的信念，最终产出"证据充分、接口友好、却系统性错误"的承诺；最大的危险不是不鲁棒，而是**鲁棒地错（robustly wrong）**。

## 2. 关键算法伪代码

### IP-139 RWE（随机化世界集合 + 分布鲁棒承诺）

```python
def sample_world_ensemble(M, r, meta, dr):
    post = meta.q_phi(M.obs[r], M.ctx[r])        # 第57轮元后验
    W = [sample_world(post, dr.support) for _ in range(M.n)]
    Phat = empirical(W)
    r_sup = dr.radius(alpha_sup=dr.alpha_sup)     # 世界侧状态，交互不可写
    return WorldEnsemble(W, Phat, r_sup=r_sup)

def rwe_commit(W, cp, a):
    R = dro_sup(W.Phat, radius=W.r_sup,           # sup over W2 ball
                loss=lambda w: fail(a, w))        # ℓ 为 L-Lipschitz
    return (a, R) if R <= delta_f else (None, R)  # 无可行动作 → 探询/征询
```

### IP-140 SGC（支撑证书 + 实界差距 + 边界探针）

```python
def sgc_monitor(W, obs, dr, audit):
    G = min(dist(obs, observable_set(w)) for w in W.worlds)
    if G > theta_gap:                             # 单次反例 ⇒ 支撑被证伪
        if explainable(obs):
            W = expand(W, new_cluster(obs))       # 扩张：r_sup 不降或升
        else:
            return 'halt'                         # 无法解释 → 安全停
    elif G >= theta_edge:                         # 边界探针：买覆盖
        dr.alpha_sup = conformal_update(dr.alpha_sup, obs)
    audit.log_gap(G); return W

def probe_the_edge(cp, W):
    cands = boundary_candidates(cp, W)            # 靠近 𝒮_DR 边界的观测
    return max(cands, key=lambda p: reduce_alpha_sup(p) - cost(p))
```

### IP-141 DEQ（设计化征询 + 可逆性匹配摩擦）

```python
def design_query(U, s, level, budget):
    cands = [q for q in QUERY_SPACE if rmf_allows(q, level)]  # L2 仅高摩擦格式
    if not cands: return None
    q = max(cands, key=lambda q: info_gain(q, U)
            - lam_c * cost(q, s, level)                       # 含 friction
            - lam_b * bias(q) / beta_max)
    return q if info_gain(q, U) > theta_ig else None

def rmf_allows(q, level):                         # 摩擦与不可逆同序
    return {'L0': q in {'yn','point','demo'},
            'L1': q in {'yn','pairwise','point','demo'},   # 低摩擦 + undo
            'L2': q in {'counterfactual','pairwise'}}[level]  # 预览 + 强制延迟
```

### IP-142 IIC（交互信息证书 + 非操纵地板）

```python
def iic_contract(W, q, ans, log):
    if not log.certified(q):                      # ε_q/β_q 未在留出日志验证
        return W, 'no_contract'                   # 只能加宽/不变
    if bias_bound(q) > beta_max:
        return W, 'no_contract'                   # 偏置超限，禁止收缩
    W2 = reweight_within_support(W, like(q, ans)) # 只在 𝒮_DR 内部再加权
    if reduction(W2) > eta * info_gain(q, W.U):
        W2 = clamp_reduction(W2, eta * info_gain(q, W.U))
    assert W2.r_sup == W.r_sup                    # 硬不变量：不得写支撑地板
    assert W2.alpha_sup == W.alpha_sup
    return W2, 'contracted'
```

### IP-143 QAV（格式条件警觉，升级 PTM）

def qav_update(s, q, ans, lat, consistency):
    e = engagement(q, ans, lat, consistency)      # 格式条件参与度
    if e < tau_min(q):                            # 低参与 = 橡皮章嫌疑
        s.vig = down(s.vig); s.auth = demote(s.auth)   # 降级实时
    elif is_high_engage(q) and e >= tau_min(q):
        s.n_verify += 1                           # 只有高参与才计升级证据
    if s.n_verify >= N_up(s.auth) and s.cal >= theta_cal(s.auth) \
       and upgrade_rate_ok(s):
        s.auth = promote(s.auth)                  # 升级有据有界
    s.w_h = min(W_MAX_GLOBAL, w0 * s.cal)
    return s

### IP-144 PCE++（探-诺-演++：探针/征询统一 VOI）

```python
def probe_commit_evolve_plus_plus(x0, M, task, budget, consent, persona, dr):
    route = plan_on_map(M, task, risk_model)
    for cp in route.checkpoints:
        W = sample_world_ensemble(M, cp.region, meta, dr)
        while True:
            a, R = rwe_commit(W, cp, select_gait(cp))
            if a is not None and few_shot_evidence_gate(cp, M, persona, ood)[0] == 'ok':
                commit(a); break
            if budget.probes_left <= 0 and budget.elicit_left <= 0:
                break
            q = design_query(W.U, persona.active, contact_level(cp), budget)
            v_probe = voi_probe(cp, W)                       # 世界侧
            v_elicit = (eta * info_gain(q, W.U) - cost(q) - lam_b*bias(q)/beta_max
                        if q else -inf)
            if max(v_probe, v_elicit) < theta_voi: break
            if v_probe >= v_elicit:
                W = sgc_monitor(W, execute_probe(choose_probe(cp, W)), dr, audit)
                budget.spend_probe()
            else:
                W, st = iic_contract(W, q, ask(q, persona), iic_log)
                budget.spend_elicit()
        else:
            continue
        if a is not None: continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(alt) != 'halt': route = alt; continue
        return negotiate_or_stop(cp, M, W, consent,
                                 tau_int=tau_int(persona.active.auth))
    return route, W
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| RWE | O(M·d_w)/检查点 | O(M·d_w) | r_sup 标定诚实、ℓ Lipschitz（A42） |
| SGC | O(M·\|obs\|) 近邻查询 | O(M·\|O\|) | G 漏检 ≤δ_gap、扩张不降 r_sup（A41） |
| DEQ | O(\|𝒬\|·(IG+H)) | O(\|𝒬\|) | ε_q/β_q 声明诚实、RMF 单调（A43/A44） |
| IIC | O(M) 再加权 | O(M) | 只在 𝒮_DR 内、ΔU≤η·IG、r_sup 不可写（A43） |
| QAV | O(1)+O(H_op) | O(\|操作者\|) | 格式阈值诚实、单向有界（A44） |
| PCE++ | O(\|CP\|·(k_p+k_c+k_e)·(M+C_VOI)) | O(\|V\|+M) | 双通道 VOI、预算终止 |

**正确性定理（Domain-Randomized Interaction-certified Soundness, DRIS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 支撑证书：P(w*∈𝒮_DR)≥1−α_sup，G 漏检率 ≤δ_gap，边界观测按共形更新；**(A42)** 鲁棒标定：r_sup 取真实 W_2 偏移的 (1−α_sup) 置信上界，ℓ 关于 w 为 L-Lipschitz；**(A43)** 交互证书：ε_q、β_q 在留出交互日志上诚实且 β_q≤β_max，ΔU≤η·IG(q)·1[IIC]，且 **r_sup/α_sup 是仅世界侧可写状态**；**(A44)** QAV 参与度判据与格式阈值诚实。则：

1. **鲁棒健全性**：P(fail) ≤ δ_f + α_sup + δ_gap + ε_meta(k) + δ_probe（对检查点取联合界）；EV-xmodal 在 L1 上额外 ≤δ_xm。
2. **保守单调性（构造性）**：spread(P̂_r)↑ 或 r_sup↑ ⇒ R_wc↑ ⇒ 可行步态档集合收缩。该单调性来自 DRO 的 sup 结构，**不依赖任何后验校准正确**——这是对"校准可能自信地错"的结构性回应。
3. **非操纵性（核心新增）**：任何交互更新（无论设计多优、偏置多大、是否有恶意）都不改变 α_sup 与 r_sup，故交互最多把集内信念锐化到"支撑允许的最优"，**永远不能使承诺发生在 𝒮_DR 覆盖之外**；偏置交互最多造成集内信偏（≤β_q），不能越界。即"交互可以赢得效率，不能赢得越界"。
4. **双通道终止性**：每检查点探针 ≤k_probes+k_cons、交互 ≤k_elicit，PCE++ 在有限步内落入 {鲁棒承诺, 绕行, L2 协商, 安全停}。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + α_sup + δ_gap + ε_meta(k) + δ_probe + δ_xm·1[L1])
             − P(r_sup 标定失效) − P(护盾回退失败)
             − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

关键：**DR 给结构性安全、共形给统计保底**（安全不再押在元模型上，而押在"支撑覆盖 + 鲁棒集"上，且支撑失效可被单次反例证伪）；**交互设计给效率、非操纵地板给边界**（人言能锐化集内信念，不能缩小世界集合）；**保守度对不确定性构造性单调**，不确定性越大越自动保守。两条现实差距（世界侧 α_sup、交互侧 ε_q/β_q）用同一套"声明证书 + 留出回归"的工程范式处理。

## 6. 本轮最大风险

**一句话**：本轮把"坏先验普遍"换成了"**坏支撑集普遍**"——域随机化让安全变成"对我声明的世界集合鲁棒"，若支撑过窄，系统会**围绕错误的世界既精确又自信**，而设计化征询又会高效地把人力用于锐化一个错位的信念，最终产出"证据充分、接口友好、却系统性错误"的承诺；最大的危险不是不鲁棒，而是**鲁棒地错（robustly wrong）**。
