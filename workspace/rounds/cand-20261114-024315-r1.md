# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「双臂协作」×「场景理解」）

> R69 把不确定性一分为二，并让系统学会了「问」。但它所有的证据都来自**同一个身体、同一条感知链**——问题问出去、答案回来，系统默认「回答我的是一个独立的世界」。而 R69 自陈的最大风险恰恰是：这套消歧机制建立在「模态分布可信、证据源独立」之上；一旦信念本身是错的、或证据源其实相关，「问对」就退化成「自信地问错」。
>
> 本轮两个灵感给出一个**不撒谎的、可干预的、却会互相欺骗的证据源**：
> - **双臂协作**：两个臂、两个视角、两套接触与本体感受，天然提供两条观测通道；更重要的是，一只臂可以**持稳**，让另一只臂去做**受控实验**。
> - **场景理解**：世界不是一堆待检测的框，而是一个有物理属性（刚性／铰接／摩擦／质量／支撑）与耦合关系（遮挡、连带运动、支撑传递）的结构；这些属性**只能通过干预辨识**，被动视觉永远看不出来。
>
> 核心命题：**双臂不是执行冗余，而是场景理解的第二个观测通道与实时实验台。把「双臂分歧」当作可测的认识论信号，用「一手持稳、一手探询」的受控干预去辨识场景的物理结构；但同一份耦合也能伪造共识——所以任何用于安全认证的共识，必须是「干预分离」的共识，而不是两只手互相回望彼此的回声。** 命名 **BRACE-RAS**（Brace-Referenced Active Consensus Estimation for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我左手看到的，和我右手摸到的，是同一个世界吗？我们的『一致』是真的吗？**」

## 0. 直觉与动机

**灵感 1（双臂 = 两条通道 + 一个实验台）**
直觉：单臂系统里，「看」和「做」是两件事；而在双臂系统里，一只臂可以**不为了完成任务而动作**，它可以专门为了「看清」而动。这只臂提供了两个别人给不了的东西：一个**第二条观测通道**（不同视角、不同接触点、不同光照/遮挡），以及一个**可编程的物理扰动源**（推、压、拉、扭、敲）。于是一个此前无法回答的问题变得可回答：「这个物体是刚性的还是铰接的？这个支撑是真的还是视觉巧合？」——不是靠再看一眼，而是靠**用手问它**。

**灵感 2（场景理解 = 物理结构，而非语义标签）**
直觉：场景理解的输出若只是「这里有个杯子」，对协调毫无帮助。真正决定双臂能否协同的，是**物理属性与耦合结构**：物体是否可形变、抽屉是不是真的能拉开、两个物体是否刚性相连、拿起 A 会不会带动 B、支撑面能不能承受另一只臂的压。这些量在**被动视觉中不可辨识**（视觉只看到表观，不看到刚度），只有对场景施加已知扰动、观测响应，才具备可辨识性。场景理解由此从「识别」变成「辨识」。

**灵感 3（分歧必须三分，而不是二分）**
直觉：R69 把不确定性分成 aleatoric 与 epistemic。双臂一来，这个二分就不够用了：两只臂对场景的判断出现差异，可能来自（i）各自的感知噪声（aleatoric）、（ii）真实的场景歧义（可约 epistemic）、（iii）**因为一只臂的动作改变了另一只臂所看到的东西**（耦合造成的伪分歧）。第三类既不是噪声、也不是可问出答案的歧义——它是**观测装置的串扰**，只能被校正、不能被「消解」。若把 (iii) 误当 (ii) 去探询，系统会越探越乱；若把 (ii) 误当 (iii) 去忽略，系统会漏掉真正的场景不确定。所以本轮必须交付 `D_ale / D_rel / D_echo` 的三分解。

**灵感 4（brace 是受控实验，但 brace 不是中立观察者）**
直觉：要辨识物理属性，最干净的做法是「固定一个自由度、扰动另一个自由度」——这正是实验物理的基本动作。双臂天然能实现：一只臂**持稳**（建立运动学参考系、固定遮挡几何、打断耦合路径），另一只臂施加受控探询。这一步同时完成三件事：锚定相对位姿、打断观测串扰、产生可辨识的激励。但关键的反直觉之处在于：**持稳的手会压进它所测量的世界**——接触力改变物体状态，臂本身改变遮挡与光照，于是「支点」既在消除耦合，又在引入新的耦合。把 brace 当成免费的信息源，是本轮最容易犯的错。

**灵感 5（自证共识：两臂的「一致」可能是回声）**
直觉：这是本轮的核心危险，也是对 R69 最脆弱处的物理补强。两臂共享同一个物体、同一套先验、甚至同一份标定；A 臂的动作会改变 B 臂的观测，B 的「同意」于是部分由 A 制造。极端情形下，系统可以**完全自洽却完全错误**：两只手都基于同一个错误先验，动作与观测互相印证，闭环完美、世界是假的。因此「两臂一致」不能直接当证据；必须先问一个因果问题：**这份一致，是条件独立于「另一臂动作」的吗？** 只有用干预（持稳）切断动作→观测的路径之后仍然成立的一致，才是真证据。这把 R69 的「需要 k 个正交证据源」从**假设**变成了**可构造、可检验**的物理操作——这是本轮最重要的理论贡献。

**灵感 6（严格包含，而非并列替代）**
直觉：与 R68→R69 一样，新层必须是旧层的严格泛化。BRACE-RAS 在以下任一条件下必须**逐指令**退回 R69：耦合模型不可信、独立性门不通过、探询不安全或属性不可辨识、跨臂歧义在预算内消不掉。退避时 `U_rel` 并入 λ_floor，安全侧永不弱于 R69。双臂带来的所有收益都必须在「安全包络不变」的前提下取得，否则就是拿闭环内力量去赌场景理解。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（BRACE-RAS 总览）** BRACE-RAS = (BSG, BDA, BPX, RNC, CMM, JBC)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；跨回合的 κ/φ 更新只进异步审计缓冲，下次装载时带证书生效）；
(ii) **干预分离证据**：任何用于安全认证的场景事实，其证据对必须**条件独立于「另一臂动作」**（至少一对源自 brace 干预分离），否则只能作为弱先验，不得进入证书；
(iii) **耦合安全**：任何协同动作（尤其闭环）必须认证联合内力量与相对位姿包络；独立性门失败或分歧不可消解时，**单调**退回单臂保守边界。

**定义 311（双臂增广场景图 BSG）** 场景图 G_t = (O, R, A; κ)。O 为物体及其位姿/形状/**物理属性** φ（刚性、铰接自由度、质量、摩擦、可形变）；R 为空间/支撑/包含关系；A 为可供性；κ = {κ_{u→v}} 为**有向耦合边**，表示「对 u 的动作会改变 v 的可观测性或状态」（遮挡、连带运动、支撑传递、光照）。信念记为因子图 b_t(G)。

**定义 312（双臂观测与耦合回声）** 臂 i 的观测 `o_i^{(t)} = h_i(s_t) + c_i(a_{¬i,t}) + n_i`，其中 `c_i` 是对**另一臂上一步动作**的显式条件项（遮挡/连带/光照）。由此一般有 `E_echo ≜ I(o_1; o_2 | s) ≥ 0`：给定真实场景后两臂观测仍共享的互信息，即「回声」。`E_echo = 0` 表示两通道条件独立；`E_echo > 0` 表示「一致」中含被耦合制造的部分。

**定义 313（信念分歧三分 BDA）** 跨臂分歧 `D = d(b_1, b_2)`（场景图嵌入上的 2-Wasserstein 或树编辑距离）。分解为
`D = D_ale + D_rel + D_echo`，
其中 `D_ale` 为各臂噪声地板（不可约）、`D_rel` 为**去掉耦合解释后仍存在的真实跨臂歧义**（可约、值得探询）、`D_echo` 为被另一臂动作解释掉的部分（可校正、不应「消解」）。`D_rel` 用干预对比估计：`D_rel ≈ D(b_1,b_2) − D(b_1^{do}, b_2^{do})` 再扣除噪声地板。

**定义 314（支点与参考系）** 持稳动作 `β` 使一只臂在物体/世界的一组接触点上固定，形成运动学参考系 `F_β` 与**观测锚**（固定遮挡几何）。其作用：① 降低相对位姿不确定性（锚定）；② 固定 `a_{¬i}`，**打断耦合边**，使探询臂的观测条件独立；③ 提供可辨识激励的边界条件。代价：占用一臂、限制可达域、施加稳定力、并引入**接触反作用**（支架自身进入被测系统）。

**定义 315（探询动作 BPX）** 探询动作 `π = (方向, 幅值, 时长)` 由自由臂施加，响应 `y = (运动, 力, 声, 视觉变化)`。`(β, π)` 构成一次**受控实验**：对物理属性 φ 施加已知扰动、观测响应以辨识 φ。信息增益 `IG(φ; y | do(β,π))`。选择 `(β,π)* = argmax [IG − c(β,π) − risk(β,π)]`，s.t. 联合安全认证。这是 R69 的 MINT 从「问人」到「问物理」的推广。

**定义 316（物理属性可辨识性）** 属性 φ 在实验 `(β,π)` 下**可辨识**，当且仅当 Fisher 信息 `J(φ) = E[−∂² log p(y|φ;β,π)]` 满秩且 `λ_min(J) ≥ J_min`。刚性/铰接/摩擦等属性在某些支点构型下不可辨识（如整块固定则无法测铰接）——此时**不得宣称已知**，只能维持 `D_rel` 或退回保守。

**定义 317（角色协商与承诺 RNC）** 角色 `ρ ∈ {brace, probe, grasp, transport, support, idle}`。分配是一个带约束的优化：可达性/碰撞可行、力闭合、安全裕度、预算。**承诺语义**：一旦为角色 ρ 承诺时域 H，只有在 `cost(ρ→ρ') ≤ c_dc` 且存在安全解耦轨迹时才允许去承诺；防止角色抖动（双臂版的模式切换），并保证换角色不破坏安全包络。

**定义 318（耦合安全与内力量 WCM）** 当两臂同时抓握同一物体形成闭环，相对位姿误差 `δT_12` 诱发内力量 `w_int = K(φ)·δT_12`。证书要求 `‖w_int‖∞ ≤ w_max(φ)` 且 `δT_12 ∈ 𝕋_safe`。当 `b_1, b_2` 对物体位姿存在分歧时，**用认证后的 `D_rel`（而非 `D_echo`、而非原始 D）放大假设的相对位姿误差**，从而收紧内力量裕度。协同风险标度 `μ = μ(D_rel)` 单调不减。

**定义 319（耦合与公共模式监测 CMM）** 滑窗跟踪两件事：① 回声估计 `Ê_echo`（由 κ 与动作历史回归/干预对比）；② **跨臂残差相关**。后者用于检测**公共模式**场景错误——两臂共享同一错误先验或同一份错误标定，导致错误不会互相抵消。CMM 在 `Ê_echo > τ_echo` 或公共模式告警时禁止把「一致」升级为「已验证」。

**定义 320（证据独立性门 IIG）** 对任一进入安全关键决策的场景事实 f，要求存在**干预分离的证据对**：不同模态，或「一臂持稳、另一臂观测」的条件独立对，或带 do-干预的时间分离对。若只有耦合证据，则 f 记为**未验证**，必须扩大包络或禁止闭环。这是 R69「k 个正交证据源」纪律的可检验版本：不再假设正交，而是**构造并检测**正交。

**定义 321（三级不确定性）** `U_ale`（感知噪声，不可约）、`U_epi`（单臂内歧义，R69 可约）、`U_rel ≜ g(D_rel)`（跨臂真实关系歧义）。三者语义不同：`U_ale + U_epi` 沿用 R69 的 λ 通道；`U_rel` **既不直接进 λ、也不直接驱动探询**，而是先过 IIG/CMM，再决定「可探询」「需校正 D_echo」还是「必须保守」。

**定义 322（自证共识与回声陷阱）** 记共识事件 C：`d(b_1,b_2) ≤ ε`。其证据价值
`EV(C) = I(s; C) − I(s; C | a_{¬i} 历史)`。
若 `EV(C) ≤ 0`，共识是被耦合制造的**空共识**，不得用于消歧或认证。回声陷阱（echo trap）指存在对抗性耦合，使两臂以任意高置信度一致地同意一个**假**场景事实。

**定义 323（联合证书 J_BRACE）** `J_BRACE = (J_FLUID, Ê_echo, D_ale/D_rel/D_echo, independence_cert, role_commit_log, w_int_margin, brace_config, brace_ver)`。Valid ⇔ Valid(J_FLUID) ∧ (Ê_echo ≤ τ_echo 或已校正) ∧ 安全关键事实满足 IIG ∧ `w_int_margin ≥ 0` ∧ 角色承诺自洽。

**定义 324（单调退避边界 FBC）** 若 IIG 失败 / `Ê_echo` 超阈 / `D_rel` 预算内未消解 / 探询不安全 / 属性不可辨识 / 闭环内力越界：禁用闭环与 BPX，退化为 R69 单臂 FLUID-RAS，且 `λ = λ_floor(U_ale + U_epi + U_rel)`（未消解的关系歧义视同 aleatoric）。⇒ R69 是 BRACE 在「禁止协同」边界上的退化。

**定义 325（双臂时序与预算）** 探询频率 ≤ 1 次/单位时间；持稳驻留时长有界；解耦延迟 ≤ τ_dc；角色切换预算 ≤ n_switch/窗口；`J_min` 不达标即放弃该实验。K/采样与 R69 自适应策略共享实时预算。

**定义 326（跨回合耦合图与属性记忆）** κ 与 φ 的后验随每次 brace-probe 更新，但**实时环路只读不写**：更新写入异步审计缓冲，在下次装载时携带证书生效（继承零学习写不变式）。这允许耦合图逐渐变准，同时不把在线不确定性注入实时安全路径。

```python
# IP-264 BSG：双臂场景图（观测显式条件于另一臂动作，记录耦合）
class BimanualSceneGraph:
    def update(self, o1, o2, a1_prev, a2_prev):
        b1 = self.per_arm_belief(o1, cond=a2_prev)   # 条件化耦合项 c_1(a_2)
        b2 = self.per_arm_belief(o2, cond=a1_prev)   # 条件化耦合项 c_2(a_1)
        return b1, b2, self.kappa                      # κ: 有向耦合边

# IP-265 BDA：分歧三分（ale / rel / echo）
def decompose_divergence(b1, b2, echo):
    D      = wasserstein_graph(b1, b2)
    D_ale  = per_arm_noise_floor(b1, b2)
    D_echo = echo * coupling_sensitivity()           # 由 κ/干预对比估计
    D_rel  = max(D - D_ale - D_echo, 0.0)            # 真实可约的跨臂歧义
    return D_ale, D_rel, D_echo

# IP-266 BPX：一手持稳、一手探询（受控实验 + 可辨识性门）
def brace_probe(b1, b2, D_rel, scene, budget):
    best = None
    for (beta, pi) in candidate_experiments(scene):  # 谁持稳、谁探、探哪里
        if not budget.allow(beta, pi):                        continue
        if not c_ras_wm.certify_bimanual(beta, pi):           continue  # 含反作用

        if not identifiable(scene.phi, beta, pi, J_min):      continue  # 定义 316
        score = IG(scene.phi; y | do(beta, pi)) - cost(beta, pi) - risk(beta, pi)
        if best is None or score > best.score: best = (beta, pi, score)
    return best if best and best.score > 0 else None    # 无利可图 → 不探，走退避

# IP-267 RNC：角色承诺与安全解耦
def commit_role(roles, rho_new, horizon):
    if roles.committed and not roles.safe_decommit_exists(tau_dc):
        return roles                                    # 不允许破坏包络的切换
    if roles.switch_cost(rho_new) > c_dc:
        return roles                                    # 抖动抑制
    return roles.commit(rho_new, horizon)

# IP-269/271 JBC+WCM：联合证书与内力保守放大
def joint_certificate(b1, b2, D_rel, E_echo, roles):
    if not independence_cert(b1, b2, E_echo) and closed_chain(roles):
        return INVALID                                  # IIG 失败不许闭环
    w_margin = w_max - norm(K) * (delta_T_nominal + c * D_rel)  # 用 D_rel，不用 D_echo
    return Valid(w_margin >= 0, E_echo, D_rel, roles)

    w_max_eff = M.jbc.deflate_wrench(w_max, D_rel)
    A = M.rnc.plan(roles, b1, b2, w_max_eff)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    # 4) 审计 + 证书（含回声、三分歧、角色日志）
    M.vqa_bi.submit_async(exp, roles, cert, D_rel, M.cmm.echo)
    return k, roles, cert, (D_ale, D_rel, D_echo)
```

## 3. 推导

设 A99：场景图可分解、物理属性 φ 有限维；A100：存在至少一个安全可达的 `(β,π)` 能打断目标耦合路径；A101：耦合算子 κ 在标定窗口内缓变且可由干预对比估计；A102：单臂子系统满足 R69 的 A95–A98。

**引理 19（回声折损：一致不能被双倍计数）** 把两臂观测按独立融合，后验精度 `Λ_ind = Λ_1 + Λ_2`；真实精度 `Λ_true = Λ_1 + Λ_2 − Λ_shared`，其中共享分量满足 `Λ_shared ≥ c·E_echo`（`c>0` 为耦合灵敏度）。故独立融合**系统性过度自信**，且与 `E_echo` 单调正相关；校正后 `Λ_true` 的下界给出保守置信区间。系：`EV(C) = I(s;C) − I(s;C|a_{¬i})` 正是「一致」中被耦合解释掉的部分，只有扣除它之后的共识才可计入证据。

**引理 20（支点探询的可辨识性与信息增益）** 若 `β` 固定 `a_{¬i}` 从而切断耦合路径，则探询臂观测条件独立；对可辨识的 φ，`J(φ) ≥ J_min`，且期望场景事实熵下降 `≥ ½ log(1 + J(φ)·σ_prior²)`。系：刚性、铰接、摩擦、支撑强度这类**被动视觉不可辨识**的属性，当且仅当存在安全可达且能打断耦合的 `(β,π)` 时才可辨识——这正是「用手问世界」的严格理由。

**引理 21（耦合安全的内力放大界）** 闭环下真实相对位姿误差满足 `δT_12 ≤ δT̂_12 + c·D_rel`（`δT̂` 为名义值）。故最坏内力量 `‖w_int‖∞ ≤ ‖K‖(‖δT̂_12‖ + c·D_rel)`。若该上界超过 `w_max(φ)`，闭环不可行，必须解耦退避。系：**跨臂歧义有直接的物理安全代价**——不是任务性能问题，而是压坏/滑脱问题。

**定理 18（BRACE 严格包含 R69）** 在 A99–A102 下，BRACE 的协同策略在任意状态上的期望风险 ≤ R69 单臂策略；且当 IIG 失败、`Ê_echo > τ_echo`、`D_rel` 未消解、探询不安全或闭环内力越界时，两者**逐指令相同**（定义 320–324）。因此 R69 是 BRACE 在「禁止协同」边界上的退化：安全侧不做任何让步，效率侧获得「物理属性可辨识 + 协同消歧」的收益。

**定理 19（自证共识的不可能性 / IIG 的必要性）** 在无 IIG 的系统中，对任意 ε>0，存在耦合构型使两臂以任意高置信度一致同意一个假场景事实（回声陷阱，定义 322）。反之，若用 J_BRACE 且满足干预分离证据纪律并对 `E_echo` 做折损（引理 19），则任何被认证为已验证的事实其真实错误概率 ≤ ε_f。故 IIG 不是可选优化，而是**结论正确性的前提**。这把 R69「需要 k 个正交证据源」从假设升级为可构造、可检测的物理操作。

**定理 20（角色承诺无突变）** RNC 的承诺 + 安全解耦 + 单调退避保证角色切换连续地停留在安全包络内；不存在「两臂互抢同一自由度」的锁定或抖动。证明沿用 R68 定理 15 的换装不变式与 R69 定理 17 的连续性论证，把「动作前缀认证」扩展为「(角色, 动作) 联合前缀认证」。

## 6. 本轮最大风险

**一句话**：BRACE-RAS 全部收益押在「能把回声 `D_echo` 与真实分歧 `D_rel` 分开」这一前提上——但**持稳不是中立观察者**：支点压进它正在测量的场景、改变遮挡与受力、甚至自己成为新的耦合源；一旦 κ 估错或反作用被忽略，系统就会把「两臂自洽」误认作「世界已被验证」，而**两臂越自信地一致，共享的盲区就越致命**——**自洽不等于正确，共识不等于证据，除非它是干预分离的**。

**次级风险与缓解**：
1. **支点的观测反作用**（brace 引入新耦合）→ 定义 314 的反作用项 + 引理 20 的 do-干预对比 + E302/E311；
2. **共享模型的公共模式故障**（两臂共享同一错误先验/标定，错误不互相抵消）→ CMM 公共模式监测 + 证据源去相关 + E305；
3. **闭环内力量被歧义击穿**（压坏/滑脱）→ WCM 用 `D_rel` 保守放大 + 引理 21 + E306；
4. **角色死锁/抖动** → RNC 承诺 + 安全解耦 + 定理 20 + E307；
5. **跨回合 κ/φ 污染**（错误耦合图被写入）→ 实时只读、异步审计缓冲、下次装载带证书（定义 326）+ E314。

```python
def brace_probe(b1, b2, D_rel, scene, budget):
```

## 4. 推导

设 A99 场景图可分解、φ 有限维；A100 存在安全可达的 `(β,π)` 能打断目标耦合；A101 κ 在标定窗口缓变且可估；A102 单臂满足 R69 的 A95–A98。

**引理 19（回声折损）** 独立融合精度 `Λ_ind=Λ_1+Λ_2`，真实精度 `Λ_true=Λ_1+Λ_2−Λ_shared`，`Λ_shared ≥ c·E_echo`。⇒ 独立融合系统性过度自信；一致不能被双倍计数，只有扣除 `I(s;C|a_{¬i})` 后的共识可计入证据。

**引理 20（支点探询可辨识性）** `β` 打断耦合后探询臂观测条件独立；可辨识 φ 满足 `J(φ)≥J_min`，期望熵降 `≥½ log(1+J(φ)σ_prior²)`。⇒ 刚性/铰接/摩擦只能「用手问」，且必须打断耦合才测得准。

**引理 21（内力放大界）** 闭环 `δT_12 ≤ δT̂_12 + c·D_rel`，故 `‖w_int‖∞ ≤ ‖K‖(‖δT̂_12‖+c·D_rel)`。超过 `w_max(φ)` 即闭环不可行，必须解耦。⇒ 跨臂歧义有直接物理安全代价。

**定理 18（BRACE 严格包含 R69）** A99–A102 下期望风险 ≤ R69；当 IIG 失败 / `Ê_echo>τ_echo` / `D_rel` 未消解 / 探询不安全 / 内力越界时逐指令相同。R69 = 「禁止协同」边界。

**定理 19（回声陷阱与 IIG 必要性）** 无 IIG 时存在耦合构型使两臂任意高置信度一致同意假事实；有 J_BRACE + 干预分离纪律 + 回声折损时，已验证事实错误率 ≤ ε_f。⇒ IIG 是结论正确性的前提，把 R69「k 个正交源」从假设变为可构造、可检测的操作。

**定理 20（角色承诺无突变）** RNC 承诺 + 安全解耦 + 单调退避 ⇒ 角色切换停留在安全包络内，无死锁/抖动；由 R68 定理 15 与 R69 定理 17 扩展为「(角色,动作) 联合前缀认证」。

## 7. 本轮最大风险

**一句话**：BRACE-RAS 全部收益押在「能把回声 `D_echo` 与真实分歧 `D_rel` 分开」上——但**持稳不是中立观察者**，支点压进它正在测量的场景、改变遮挡与受力、甚至自己成为新的耦合源；一旦 κ 估错或反作用被忽略，系统就会把「两臂自洽」误认作「世界已被验证」，而**两臂越自信地一致，共享盲区越致命**——**自洽不等于正确，共识不等于证据，除非它是干预分离的**。

**次级风险与缓解**：持稳反作用（定义 314 反作用项 + 引理 20 do-对比 + E302/E311）；共享模型公共模式（CMM 监测 + 证据去相关 + E305）；闭环内力被歧义击穿（WCM 用 `D_rel` 放大 + 引理 21 + E306）；角色死锁/抖动（RNC 承诺/解耦 + 定理 20 + E307）；跨回合 κ/φ 污染（实时只读 + 异步审计缓冲 + 定义 326 + E314）。
