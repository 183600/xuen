# 第 69 轮（承接第 68 轮「CALM-RAS 自标定风险闭环」IP-243~252；本轮灵感：「语义分割」×「指标体系」）

> 第 68 轮把「测量可信度」提升为一等公民，但它的答案仍是一个**全局标量**：标定潜变量 c_t ∈ ℝ¹²、不确定度 U = tr(Σ)、一套全局阈值。这暗含两个未经检验的假设：(a) **可信度在空间上是均匀的**；(b) **一个标量指标足以裁决整个闭环**。R68 自陈的最大风险正是这两个假设的必然结果：落在标定带宽内的缓变故障被全局标定「平均」吸收，系统在「测量越来越准」的假象中失明。
>
> 本轮用两个灵感正面拆掉这两个假设：
> - **语义分割**：可信度不是标量，而是**场（field）**——把场景划分为语义区域（静态背景/操作物/人脸/机械臂/接触面/透明反射面），标定、残差、归因全部下沉到**区域粒度**；分割的静态/动态/边界掩码同时充当「哪些像素有资格参与标定」的守门人。
> - **指标体系**：闭环的裁决不应依赖手调阈值，而应依赖一棵**层级化、方向单调、可审计的指标树**——领先指标（标定健康/覆盖/残差熵）预警，滞后指标（违规/成功率）校验，且每个进入控制回路的指标都必须持有**优化器不可见的审计副本**以抵抗 Goodhart 定律。
>
> 核心命题：**把 R68 的「全局标定不确定度」升级为「语义分区可信度场 × 层级指标证据树」——MOSAIC-RAS（Metric-Ordered Semantic Attribution & Integrity Certificate）。**
>
> 一句话定位：R68 问「我的测量还准吗」，R69 问「**哪里准，凭什么说准**」——任何区域的可信度塌陷只能通过保守通道传导，绝不被平均掉。

## 0. 直觉与动机

**灵感 1（语义分割 → 可信度有几何形状）**
直觉：R68 的 U = tr(Σ) 是空间平均。若一个相机象限、一块触觉垫、一个接触面发生局部漂移/故障，只要其他区域正常，全局 U 仍低、全局残差仍小——故障被「平均」掉了。语义分割给出三样东西：(i) 区域划分把残差**定位**；(ii) 语义类别给出**先验该期待什么残差**（透明面/反射面/边界本就不可靠）；(iii) 动态掩码把「会动的东西」逐出静态标定，避免 R68 的静态段自标定被行人/机械臂污染。更关键：同一物体被视觉与触觉独立测量时，分割给出**实例级环一致**——这是比 R68 全局环一致更锐利的探针。

**灵感 2（指标体系 → 指标本身也是测量，也需要计量学）**
直觉：R68 的 τ_temporal / τ_wm / τ_risk / λ_floor 是四个孤立手调阈值，没有一个统一语义。指标体系给出：(i) 分层（L0 结果 / L1 领先 / L2 诊断），领先指标必须在结果变坏**之前**动；(ii) 方向单调与归一化，聚合不能把坏消息平均掉；(iii) 指标有效性检验（与独立审计副本的秩相关、风险校准、nuisance 不变性）；(iv) **Goodhart 防护**——一旦某指标成为优化目标，它就会失真，所以控制回路应优先看优化器看不见的审计副本。指标体系的递归洞见：**指标是测量，所以 R68 的「测量可信度」问题在指标层复现**——这正是 R69 必须回答的元问题。

**灵感 3（两灵感合流 → MOSAIC-RAS 六组件）**
1. **SDP Semantic Dense Partition**：共享 trunk 的稠密语义头 + panoptic 实例跟踪 + 静态/动态/边界掩码，输出区域格 R_k 与不可归因掩码 ⊥；
2. **RCF Region Credibility Field**：区域标定场 c_t(R_k) = c_t⁰ + d_k（全局 R68 标定 + 局部偏差，层级收缩），输出 U_max、U_avg、覆盖率 Cov_τ；
3. **RAA Region-aware Attribution**：逐区域「先标定后归因」，边界/⊥ 残差不许参与标定，全局故障后验用 worst-region + noisy-OR 聚合，绝不做面积平均；
4. **MIO Metric Indicator Ontology**：L0/L1/L2 指标树 + 归一化/单调/校准约束 + 风险主导合成 CSI = min(mean, softmin)，防稀释；
5. **GAG Goodhart Audit Guard**：每个控制指标配一份优化器不可见的审计副本，CUSUM 监测代理-真值发散，发散即切换并降级；
6. **IAC Indicator-Audited Commit**：CAC 五关升级为七关（加指标约束关、指标完整性关），其余 RAS-WM‡ 继承。

**灵感 4（对 R68 风险的对症下药）**
- 「缓变故障落在标定带宽内被吸收」：若故障空间局部（面积占比 a<1），区域化检验 SNR 提升 1/√a（引理 16）；a=1% 时 10×，原本被全局平均淹没的慢故障浮现；
- 「全局 U 低但其实某区域已坏」：U_max 与 Cov_τ 取代 U，任一区域塌陷即触发保守；
- 「指标平均稀释」：CSI 用 min/软最小而非平均（引理 18），单区域崩溃不可被其余健康区域掩盖；
- 「优化压力使指标失真」：GAG 审计副本 + CUSUM，代理-真值发散即告警（引理 19）。

## 1. 形式化定义（增量：定义 293–308）

**定义 293（MOSAIC-RAS 总览）** MOSAIC = (SDP, RCF, RAA, MIO, GAG, IAC, RAS-WM‡)。四不变式：
(i) 实时流零学习写操作（继承 R68）；
(ii) **区域覆盖不遗漏**：每个像素/力敏元必须被标为某区域 R_k 或 ⊥；任何残差都不得被静默丢弃，⊥ 残差质量必须显式计入指标；
(iii) **指标可追溯**：每个影响控制的标量必须可追溯到指标树叶子，且带方向与独立审计副本；
(iv) **保守聚合**：合成安全指标由最差区域主导（min/软最小），不允许面积平均稀释单区域塌陷。

**定义 294（语义稠密分区 SDP）** SDP: obs_t → (M_t, Π_t, D_t, B_t)：
- M_t: Ω → L，语义标签（背景/操作物/人脸/机械臂/接触面/透明反射面/未知）；
- Π_t 为 panoptic 实例 id（同物体跨模态绑定）；
- D_t ∈ {static, dynamic}；
- B_t 为边界+遮挡+高梯度掩码。
区域格 {R_k} = 相同 (M, Π, D) 的连通分量减去 B_t；⊥ = B_t ∪ {未达置信度 τ_seg 的像素}。面积权重 w_k = |R_k|/|Ω|（力域用 taxel 计数）。分割关键帧 10 Hz，非关键帧用光流传播（摊薄成本）。

**定义 295（区域可信度场 RCF）** 层级标定：c_t(R_k) = c_t⁰ + d_t(R_k)，d_t(R_k) ~ 𝒩(0, Σ_d,k)，c_t⁰ 沿用 R68 COF。区域 EKF 以 c_t⁰ 为先验、以区域残差为观测做经验贝叶斯收缩；u_t(R_k) = tr(Σ_t(R_k))。报告三元组：
U_max = max_k u_t(R_k)；U_avg = Σ_k w_k u_t(R_k)；Cov_τ = Σ_{k: u_k ≤ τ_cal} w_k。
决策只允许用 U_max 与 Cov_τ，**禁止只用 U_avg**（平均会掩盖局部塌陷）。区域有效样本不足时退化为全局 c⁰ 并把该区域标为 coverage-invalid。

**定义 296（区域残差场）** 对区域 R_k，r_t(R_k) = RobustPool_{x∈R_k} r_t(x)（逐像素五元组残差的中位数/截尾均值）；边界不参与标定，只累计不可归因质量 m_⊥ = Σ_{x∈⊥}|r_t(x)| / Σ_{x∈Ω}|r_t(x)|。区域残差同样五元组 (r_geo, r_sync, r_zero, r_emo, r_wm)。

**定义 297（区域感知先标定后归因 RAA）** 对每个区域：
P(cause_k | r(R_k), σ_stat(R_k)) ∝ p(r(R_k) | cause_k)·[σ_stat·p_cal + (1−σ_stat)·p_fault + p_real]，
其中 p(r | cal) = 𝒩(r; r_cal(ĉ(R_k)), R_cal)。全局故障后验用 noisy-OR 聚合：
P(H^trans) = 1 − ∏_k (1 − p_k(H^trans))^{w_k}，并附加最差区域下界 P(H^trans) ≥ max_k p_k(H^trans)。**任何区域的高故障后验都不能被低值区域抵消**。

**定义 298（指标本体 MIO）** 指标树 𝒯 = (V, E) 分三层：
- L0 滞后结果：V_safety（违规/小时）、S_success、E_track；
- L1 领先：H_cal = 1 − U_max/τ_cal、Cov_τ、R_ent（区域残差熵）、W_drift、G_goodhart、B_frac = |⊥|/|Ω|；
- L2 诊断：逐区域 u_k、r_k、w_k、predictive residual。
每个节点 m 有原语 φ_m、归一化 n_m、方向 d_m ∈ {↑好, ↓好}、单调链接 g_m。所有进入控制的指标必须满足定义 300 的有效性。

**定义 299（保守合成安全指标 CSI）** 区域安全分 S_k = σ(Σ_j θ_j φ_j(R_k))。CSI_t = min(mean_k S_k, softmin_α({S_k})，α→0 退化为硬最小）。「无稀释保证」：若某区域 S_k 下降 Δ，则 CSI 下降至少 g(Δ)（引理 18），与 w_k 无关。CSI 时间平滑用滑动 5% 分位下界（LCB）而非均值，防抖但保留塌陷灵敏度。

**定义 300（指标有效性）** 指标 m 有效 ⇔ 四项同时成立：
(a) 秩一致：在审计窗上 Spearman ρ(m, m̃) ≥ 0.8（m̃ 为独立审计副本）；
(b) 风险校准：若 m 用作违规概率预测，ECE ≤ 0.05；
(c) nuisance 不变：标定包络内 |m(T(x)) − m(x)| ≤ ε_nui（光照/增益/时移）；
(d) 优化器不可见：m̃ 不进入任何训练/提交梯度路径。
有效性状态 λ_m ∈ {valid, degraded, invalid}：valid 才可入控制；degraded 走保守回退；invalid 直接剔除并抬升 λ_floor。

**定义 301（Goodhart 审计护栏 GAG）** 设代理指标 m 被优化、审计副本 m̃ 不可见。发散度 G_t = EWMA(|m − m̃|)。CUSUM：S_t⁺ = max(0, S_{t−1}⁺ + (G_t − δ_G − k))。若 S_t⁺ > h_G 或 G_t > δ_G 连续 W 窗，判 Goodhart 告警：控制切换为 m̃（若可用）或退化为保守策略，并把事件写入 AuditBuf。形式假设 A95：无博弈时 m̃ 对真值条件无偏，方差 σ_a²。

**定义 302（边界与盲区保守纪律）** 若 B_frac > β_max 或 m_⊥ > β_mass，声明「检视事件」：冻结 RCF 更新（禁止把不可归因残差当漂移吸收）、λ_floor 抬至 0.8、CSI 置信下界作废、按最坏区域归因。**⊥ 残差永远不能成为标定观测**——这是 R68「故障不可被标定吸收」在空间维度的对偶。

**定义 303（层级一致性约束）** 父子区域可信度满足 u(parent) ≥ aggregate(u(children))，且 H_cal(scene) ≤ min_k H_cal(R_k)。任何父节点不得用平均掩盖坏子节点；一致性违反即判指标树失效（触发 IAC 拒绝）。

**定义 304（指标审计式提交 IAC）** CAC 五关升级为七关：金标回归 / AuditBuf 回放 / 分布界 / 风险界 / canary 不可修复 / **指标约束关**（ΔCSI ≥ −ε 且最差区域 S_k 不降）/ **指标完整性关**（λ_m 全 valid、GAG 未告警、指标树 hash 一致）。全过才双缓冲原子换装。

**定义 305（AIC-MOSAIC 干扰集）** ℰ_MOSAIC = ℰ_CALM × ℰ_seg × ℰ_ind。
ℰ_seg = {语义误标、实例合并/分裂、边界泄漏、透明/反射面、遮挡、开放类未知物}；
ℰ_ind = {Goodhart 博弈、合成稀释、指标漂移、审计副本泄漏、分布外指标失效}。

**定义 306（J_MOSAIC 证书）** J_MOSAIC = (J_CALM, seg_hash, partition_hash, U_max, Cov_τ, CSI, metric_tree_hash, λ_m-vec, goodhart_verdict, commit_verdict, mosaic_ver)。Valid ⇔ Valid(J_CALM) ∧ Cov_τ ≥ Cov_min ∧ GAG 未告警 ∧ λ_m 全 valid ∧ commit_verdict = PASS。

**定义 307（区域可达性/覆盖假设 A96）** 存在 δ_cov，使真实故障支撑集的至少 1−δ_cov 落在被有效语义分区且非 ⊥ 的区域。这是 MOSAIC 检出保证的硬前提——也是本轮最大风险的来源。

**定义 308（管线）** 离线：语义分割/panoptic 预训练（仿真 + 少量标注）→ 区域标定场初始化 → 指标树因果估计与有效性认证 → 部署。在线：MTM 一次前向 + SDP 低频关键帧/传播 → RCF/RAA 区域更新 → MIO 计算 CSI → IAC 60s 提交；GAG 与 VQAuditor-S 异步。

## 3. 推导

**引理 16（区域定位增益）** 设故障在面积占比 a 的区域上注入幅度 δ，噪声 iid 方差 σ²，总像素 N。全局平均检验 SNR_global = aδ√N/σ；区域检验用 aN 像素，SNR_region = δ√(aN)/σ。故 SNR_region/SNR_global = 1/√a。a=1% ⇒ 10×，a=5% ⇒ 4.5×。系：**空间局部的缓变故障即使落在 R68 标定带宽内，也无法再被全局平均淹没**；代价是必须先把区域找对（定义 294/307）。

**引理 17（分割盲区上界）** 若语义分区的不可归因质量占比为 m_⊥，则任何完全落在 ⊥ 内的故障对 RAA 不可见；但定义 302 的纪律把「不可归因质量异常」本身当成风险信号：m_⊥>β_mass ⇒ 冻结标定+保守。因此在 A96（故障支撑 1−δ_cov 可被分区）下，漏检概率 ≤ P(m_⊥>β_mass 未触发) + δ_cov。**分割召回不是免费的：它把 R68 的时间盲区换成了空间盲区。**

**引理 18（保守聚合无稀释）** 设区域安全分 S_k，mean 聚合下区域 k 下降 Δ 只使 CSI 降 w_kΔ；min/softmin_α 聚合下 CSI 下降 ≥ Δ·(1−O(α))，与 w_k 无关。故任何单一区域的灾难性塌陷在 min 聚合下不可被稀释；软最小用温度 α 换取抗噪，但 α 必须随 |R| 校准（α ≤ Δ_min/ln|R|）以保持灵敏度。量化：mean 聚合需区域面积 ≥ τ/Δ 才能触发，min 聚合无面积门槛。

**引理 19（Goodhart 发散检测）** 在 A95 下，无博弈时 G_t 的均值 ≤ δ_G；一旦优化压力使代理 m 系统性偏离而 m̃ 保持无偏，G_t 的漂移被 CUSUM 以平均检测延迟 ~h_G/(drift−k) 捕获，虚警率由 h_G 指数控制。系：**控制回路只看 m̃ 时，代理失真不再直接转化为控制失真**；但若 m 与 m̃ 共享同一数据源（共因），发散不可见——这是指标体系的根本限制（本轮风险之二）。

**定理 16（MOSAIC 端到端风险一致性）** 在 A87–A96 下：
1. P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+**α_seg**+**α_ind**+**α_met**；
2. U_max>τ_cal ∨ Cov_τ<Cov_min ∨ m_⊥>β_mass ⇒ λ_risk≥0.8 ∧ k 收缩 ∧ 标定冻结（保守单行道）；
3. 空间局部（a<1）且非 ⊥ 的故障，检出 SNR 提升 1/√a（引理 16）；完全 ⊥ 内的故障概率被 δ_cov+盲区纪律界住（引理 17）；
4. 任一区域 S_k 下降 Δ ⇒ CSI 下降 ≥ g(Δ)（引理 18），合成指标不可稀释。

**定理 17（指标审计提交安全性）** 七关中指标约束关保证提交后 ΔCSI≥−ε 且最差区域不降；指标完整性关保证 λ_m 全 valid 且 GAG 无告警；canary 关检出率 ≥0.95。联合上界：有害适配器上线且不被指标关拦截的概率 ≤ (1−r_canary)(1−r_metric)+p_common_cause，其中 p_common_cause 为代理与审计副本共因失效率（不可由 GAG 消除，只能由数据源分离降低）。

## 6. 本轮最大风险

**一句话**：MOSAIC 把「测量可信」从标量升级为「语义分区 × 指标树」，但**语义分区本身是一个学习到的、会被透明/反射面、开放类未知物和遮挡系统性骗过的先验；一旦故障或漂移恰好落在分割的 ⊥ 盲区（或与训练分布不同的区域被误判为动态/背景），区域化归因与指标树都会输出「覆盖良好、指标健康」的假象**——R68 的盲区在时间维度（慢到被标定吸收），R69 的盲区被搬到了空间维度（被分割掩码排除），而指标树又可能用「平均/共因」把这一空间塌陷洗白，形成「分区越精细、盲区越可信」的反讽。

**次级风险与缓解**：
1. **小区域数据稀疏 → U 虚高误报**：层级收缩 + 覆盖失效标记 + 面积加权最小样本门限；
2. **指标树过拟合/权重主观**：权重由因果效应估计并纳入 J_MOSAIC 版本链，定期回测；
3. **Goodhart 共因失效**：审计副本用独立传感器/独立数据源，共因率 p_common_cause 显式写入证书；
4. **分割延迟**：关键帧 10 Hz + 光流传播，遮挡/快速运动时降级为保守而非高置信；
5. **指标爆炸/维护复杂度**：指标树节点上限 + 自动剪枝（只保留领先性与有效性双达标者）。

## 2. 形式化定义（要点版）

**定义 293（总览与四不变式）** 实时流零学习写操作；区域覆盖不遗漏（每像素/触元必属 R_k 或 ⊥，⊥ 质量显式入指标）；指标可追溯（控制标量→叶子指标→审计副本）；保守聚合（最差区域主导，禁止面积平均稀释）。

**定义 294（SDP）** `SDP: obs_t → (M_t, Π_t, D_t, B_t)`；区域格为相同 (M,Π,D) 的连通分量减边界；⊥ = 边界/遮挡 ∪ 低置信像素；关键帧 10 Hz 分割 + 非关键帧光流传播。

**定义 295（RCF）** `c_t(R_k)=c_t⁰+d_t(R_k), d_t(R_k)~𝒩(0,Σ_d,k)`；区域 EKF 以 R68 COF 为全局先验做经验贝叶斯收缩；`u_k=tr(Σ_k)`；报告 `U_max=max_k u_k`、`U_avg=Σw_k u_k`、`Cov_τ=Σ_{u_k≤τ_cal}w_k`；决策禁用 U_avg。

**定义 296（区域残差场）** `r_t(R_k)=RobustPool_{x∈R_k}r_t(x)`（中位数/截尾均值）；边界不参与标定，只累计 `m_⊥`；区域残差沿用五元组 (r_geo,r_sync,r_zero,r_emo,r_wm)。

**定义 297（RAA）** 逐区域 `P(cause_k|r(R_k),σ_stat)∝p(r|cause_k)[σ_stat p_cal+(1−σ_stat)p_fault+p_real]`；全局 `P(H^trans)=1−∏_k(1−p_k)^{w_k}` 且 `≥max_k p_k`——区域高后验不可被抵消。

**定义 301–302（GAG / 盲区纪律）** `G_t=EWMA|m−m̃|`，CUSUM `S_t⁺=max(0,S_{t−1}⁺+(G_t−δ_G−k))`，超阈值即告警并切审计副本/退化；`B_frac>β_max ∨ m_⊥>β_mass` ⇒ 冻结 RCF、λ_floor=0.8、CSI 作废、最坏区域归因。

**定义 305–308（干扰集 / 证书 / 覆盖假设 / 管线）** `ℰ_MOSAIC=ℰ_CALM×ℰ_seg×ℰ_ind`；`J_MOSAIC` Valid ⇔ Valid(J_CALM) ∧ Cov_τ≥Cov_min ∧ GAG 无告警 ∧ λ_m 全 valid ∧ PASS；A96 给出 δ_cov；离线分割预训练→区域标定→指标树认证→在线闭环。

```python
    m_perp, b_frac = perp_mass(r_field, perp), area_frac(perp)
    lam_floor = 0.6
    if m_perp > BETA_MASS or b_frac > BETA_MAX:                  # 盲区保守纪律
        M.rcf.freeze(); lam_floor = 0.8
    post = M.raa(r, rc['c'], rc['U_max'])                        # 逐区域先标定后归因
    wm_preds = M.mtm.rollout(z, M.ach.propose_actions(obs, 5))
    met = M.mio.compute(R, rc, r, {'B_frac': b_frac})            # CSI / L1 / L2
    if M.gag.check(met['CSI'], M.audit_csi()) == 'GOODHART_ALARM':
        met = M.mio.conservative()                               # 切审计/退化
    A = M.ach.propose(obs, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, post, min(M.vista.m, M.m_emo),
                                    M.alpha_chunk, wm_preds)
    if rc['U_max'] > TAU_CAL or met['Cov'] < COV_MIN:
        k = min(k, k_cal_shrink(A, rc['U_max']))
    lam = max(M.efs.risk_scale(post), lam_floor,
              0.8 if (b_frac > BETA_MAX or met['CSI'] < CSI_MIN) else 0.6)
    tau = emotion_response_shaping_wm(M.pi_sigma.prefix_dispatch(A[:k])*lam, post, wm_preds)
    M.vqa_s.submit_async(R, perp, rc, met)                       # 异步分区审计
    M.iac.maybe_commit(M.shadow, met, post, dt=M.time_since_last_commit)
    return k, lam, post, rc, met
```

## 4. 推导

**引理 16（区域定位增益）** 故障在面积占比 a 的区域注入幅度 δ、噪声 iid 方差 σ²、总像素 N：全局平均检验 `SNR_global=aδ√N/σ`；区域检验用 aN 像素，`SNR_region=δ√(aN)/σ`；故 `SNR_region/SNR_global=1/√a`。a=1% ⇒ 10×，a=5% ⇒ 4.5×——**空间局部的缓变故障即使落在 R68 标定带宽内，也不会被全局平均淹没**；代价是必须先找对区域（A96）。

**引理 17（分割盲区上界）** 完全落在 ⊥ 内的故障对 RAA 不可见；定义 302 把 m_⊥ 异常本身当风险信号（冻结标定 + 保守）。在 A96 下漏检概率 ≤ P(m_⊥>β_mass 未触发) + δ_cov。**分割召回不免费：R68 的时间盲区被换成空间盲区。**

**引理 18（保守聚合无稀释）** mean 聚合下区域 k 下降 Δ 仅使 CSI 降 w_kΔ（需面积 ≥ τ/Δ 才触发）；min/softmin_α 下 CSI 下降 ≥ Δ(1−O(α))，与 w_k 无关；软最小须 `α ≤ Δ_min/ln|R|` 才能让最差区域占 ≥1/2 权重。故单区域灾难不可被稀释，min 聚合无面积门槛。

**引理 19（Goodhart 发散检测）** A95 下无博弈时 E[G_t] ≤ δ_G；优化压力使代理 m 偏离而审计副本 m̃ 无偏时，CUSUM 平均检测延迟 ~ h_G/(drift−k)，虚警率随 h_G 指数下降。系：**控制只看 m̃ 时代理失真不直接转化为控制失真**；但 m 与 m̃ 共因时发散不可见——指标体系的根本限制。

**定理 16（MOSAIC 端到端风险一致性）** 在 A87–A96 下：
1. `P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_seg+α_ind+α_met`；
2. `U_max>τ_cal ∨ Cov_τ<Cov_min ∨ m_⊥>β_mass ⇒ λ_risk≥0.8 ∧ k 收缩 ∧ 标定冻结`；
3. 空间局部（a<1）且非 ⊥ 的故障检出 SNR 提升 1/√a；完全 ⊥ 内故障概率被 δ_cov+盲区纪律界住；
4. 任一区域 S_k 下降 Δ ⇒ CSI 下降 ≥ g(Δ)，合成指标不可稀释。

**定理 17（指标审计提交安全性）** 指标约束关保证提交后 ΔCSI ≥ −ε 且最差区域不降；指标完整性关保证 λ_m 全 valid 且 GAG 无告警；canary 关检出率 ≥0.95。有害适配器上线且未被拦截的概率 ≤ (1−r_canary)(1−r_metric)+p_common_cause，其中 p_common_cause 为代理/审计副本共因失效率（GAG 无法消除，只能靠数据源分离降低）。

## 7. 本轮最大风险

**一句话**：MOSAIC 把「测量可信」从标量升级为「语义分区 × 指标树」，但**语义分区本身是一个学习到的、会被透明/反射面、开放类未知物和遮挡系统性骗过的先验；一旦故障或漂移恰好落在分割的 ⊥ 盲区（或与训练分布不同的区域被误判为动态/背景），区域化归因与指标树都会输出「覆盖良好、指标健康」的假象**——R68 的盲区在时间维度（慢到被标定吸收），R69 的盲区被搬到了空间维度（被分割掩码排除），而指标树又可能用「平均/共因」把这一空间塌陷洗白，形成「分区越精细、盲区越可信」的反讽。

**次级风险与缓解**：小区域数据稀疏致 U 虚高（层级收缩 + 覆盖失效标记 + 最小样本门限）；指标树权重主观/过拟合（因果效应估计 + 版本链 + 定期回测）；Goodhart 共因失效（独立数据源审计副本 + p_common_cause 写入证书）；分割延迟（关键帧 10 Hz + 光流传播，快速运动降级为保守）；指标爆炸（节点上限 + 只保留领先性与有效性双达标者的自动剪枝）。
