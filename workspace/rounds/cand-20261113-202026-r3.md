# 第 69 轮（承接第 68 轮「CALM-RAS 自标定·自监督·单模型多任务」IP-243~252；灵感循环新循环第 2 轮；本轮灵感：「ROS2」×「真机评测」）

> 第 68 轮的 CALM-RAS 补上了计量层，却在结尾自陈了一条无法在单机内解决的谶语：**标定能力越强，缓变故障越隐形**。其病根不是滤波器不够好，而是「标定」被当成了一个**自洽的解释器**——只要参数 c 能把残差解释掉，系统就相信测量变准了；而「解释掉残差」与「销毁故障证据」在单进程内是同一个操作。可解释性不等于正确性，单机内省天然***不可证伪***。
>
> 本轮两个灵感恰好从两个正交维度补上「外部性」：
> - **ROS2**：真实机器人从来不是 monolithic 函数，而是一个由独立进程/节点、独立时钟、独立故障域组成的**分布式社会**；DDS 的 QoS 契约（DEADLINE / LIVELINESS / RELIABILITY / 时间戳偏斜）由中间件产生，**模型无法学习、无法改写、无法吸收**。这是一类「构造性不可吸收」的物理层证人。
> - **真机评测**：评测的可信度不来自单次自证的漂亮指标，而来自**预注册、分层、留出、带功效分析的外部审计**，以及计量学最古老的两条纪律——**证书有适用范围（envelope），也有有效期（expiry）**。真机评测不是「跑一遍看看」，而是给标定签发/吊销证书的**外部法庭**。
>
> 把两者与 R68 的计量层焊在一起，得到本轮核心命题：
>
> **标定本质上是一次「规范选择（gauge fixing）」：合法漂移是标定群 G 作用下的轨道内移动，轨道内不可辨识；R68 的慢故障盲区，恰好就是这个轨道。GAUGE-RAS 的解法是——把标定限制在轨道内、用轨道外不变量（商空间指纹）与 ROS2 协议见证捕获轨道外故障、用真机外部参照锚打破规范简并、用有限生命周期的证书把「永久隐形」压缩成「有界暴露窗」。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 追问「**凭什么相信这台机器说的『准』，而不是它和故障达成的共谋**」——证书不是自评，而是外部审计签发的、会过期的、可被吊销的有限真理。

## 0. 直觉与动机

**灵感 1（ROS2 → 中间件是唯一不会替模型说谎的证人）**
直觉：模型的残差、标定、后验全都可以被优化到「自圆其说」；但 DDS 的 DEADLINE 是否 miss、LIVELINESS 是否丢失、时间戳是否跳变、样本是否丢、TF 链是否断开，这些是**中间件在自己的进程里、按协议判定的**，标定参数 c 根本不在其生成过程里。形式上 ∂w_t/∂c = 0：标定无法「解释」一个 deadline miss，就像嫌疑人无法解释监控为何断线——断线本身就是证据。R68 的 COF 之所以能把慢故障「标好」，是因为它只吃「值」；ROS2 教会我们同时吃「值之外的元数据」：到达时间、存活、序列号、时钟域、QoS 裁决。**元数据是标定的不可吸收边界。** 更关键的是，ROS2 的节点/进程提供了**独立故障域**：我把标定节点、归因节点、安全监督节点分置，单个进程的黑箱漂移无法同时污染所有证人——这正是 R68 单 trunk 同源一致性所牺牲掉的那部分「独立性」，现在用架构补回来（模型内共模、模型外独立，两层冗余）。

**灵感 2（真机评测 → 评测是法庭，不是成绩单）**
直觉：仿真里 E271–E285 再漂亮，也只是「在模型自己定义的世界里自洽」。真机评测的价值不是再给一个分数，而是提供两样仿真永远给不出的东西：**(a) 外部参照物**——已知质量块、标定板、已知长度基准、已知时延脉冲，它们能**打破规范简并**（把「传感器增益衰减」与「标定把它调回来」区分开）；**(b) 统计外部性**——预注册的假设、按混杂因子分层的随机区组、留出条件、功效分析、非劣界。计量学告诉我们：**没有适用范围和有效期的证书不是证书，是广告。** 于是本轮把「评测」做成运行时的一等公民：审计通过才续证，审计失败即吊销，包络变了即挂起。

**灵感 3（三灵感合流 → 规范理论视角）**
把标定看成李群 G 在测量流形 𝒴 上的作用：零偏是平移、外参是旋转、增益/焦距是尺度、Δt_sync 是时间平移。R68 的 COF 本质上是在估计群元 g_c 以最小化残差——它**只能消除轨道 O_y 的切空间 A 内的分量**。因此：
- 轨道内故障（效果等价于一次合法标定）→ 任何仅依赖测量本身的统计量都**不可辨识**（这是 Noether 式的对称性—不可观测对偶，是**原理性**下界，不是工程缺陷）；
- 轨道外故障 → 商空间坐标 f: 𝒴 → 𝒴/G 必然变化，可检；
- 要看见轨道内故障，只能引入**不在 G 轨道上的外部参照**，用参照把规范「钉住」（gauge fixing）——这正是真机评测里的标准件。
一句话：**R68 缺的不是更强的标定，而是「标定轨道的边界」与「轨道外的坐标系」。**

**灵感 4（合流 → GAUGE-RAS 七组件）**
1. **CGQ Calibration-Group Quotient**：把现有残差重排成规范不变量 f（差/比/相对时序/刚体不变量/多通道增益比/互信息差），监控商空间漂移；标定只允许在 A 内动作。
2. **QCL QoS Contract Layer**：为每条 ROS2 通道定义契约 q_i，产出不可学习的见证事件 w_t（deadline / liveliness / clock jump / drop）。
3. **PVF Provenance Validity Filter**：每条观测带溯源 π_t（节点、时钟域、seq、QoS 裁决、TF 哈希、bag 哈希），只让有效观测进入标定测量集 M_t；被隔离的观测转为故障证据。
4. **ENC Envelope Certificate**：证书带适用范围 ℰ、覆盖率 cov、允许不确定度 U_budget、有效期 T_exp；越界/到期即挂起。
5. **RLC Reticent Lifecycle Controller**：把证书状态映射到 ROS2 managed node 生命周期（unconfigured→inactive→active→finalized），迁移守卫原子化、只追加审计。
6. **EAR Evaluation-as-Audit Runtime**：真机评测 = 预注册 + 分层随机区组 + 留出 + 功效分析 + 非劣界；产出续证/吊销裁决，而非排行榜。
7. **XRA External Reference Anchor**：审计期使用已知标准件打破规范简并，量化「参照预算」b_ℛ 与可观测子空间 O。
**RAS-WM‡ 继承核**：CALM-RAS 的 MTM/COF/CFA/CAC 全部保留，但 COF 的更新空间被 CGQ 投影到 A，CFA 的后验在 SUSPENDED/REVOKED 态被强制走最坏情况。

**灵感 5（对 R68 风险的逐条对症）**
- R68「缓变故障落在标定带宽内」→ 拆成两半：**轨道外缓变**由 CGQ 商空间指纹在漂移早期捕获；**轨道内缓变**由 XRA 外部参照 + 审计在证书到期前捕获；两者都没覆盖的残余，暴露时间被 T_exp 硬性截断（引理 18）。
- R68「CAC 金标集未覆盖该故障」→ EAR 的预注册分层把「未覆盖工况」显式记为 unknown envelope，cov 不足即拒绝续证；不再赌金标集的运气。
- R68「实时流零学习写操作」→ ROS2 节点隔离进一步强化：学习/标定/安全监督分进程，实时节点只读，参数经生命周期迁移原子换装。
- R68「单一防线」→ 本轮防线变成三层异构：**协议层（QoS，构造性）+ 几何层（商空间不变量，统计性）+ 外部层（参照锚+审计，因果性）**，任一层不可被另外两层替代。

## 1. 形式化定义（增量：定义 293–308）

**定义 293（GAUGE-RAS 总览）** GAUGE-RAS = (CGQ, QCL, PVF, ENC, RLC, EAR, XRA, RAS-WM‡)。五条不变式：
(i) **轨道约束**：COF 的估计空间被限制在标定群轨道切空间 A 内，标定不得越轨；
(ii) **可吸收边界**：标定测量集 M_t 只含溯源有效且无 QoS 见证的观测；
(iii) **有限真理**：证书带包络 ℰ 与有效期 T_exp，越界/到期即挂起，非 VALID 态一律收紧；
(iv) **只追加审计**：证书与生命周期迁移、预注册协议、bag 哈希全部写入不可变账本；
(v) **单调收紧**：任何不确定性/异常/审计失败只允许增大 λ、缩小 k，绝不放宽。

**定义 294（标定群与轨道）** 测量流形 𝒴。标定 c ∈ 𝒞 ⊆ ℝ^{12} 经左作用 g_c: 𝒴 → 𝒴 作用于原始测量，合法漂移 y' = g_{δc} y。G = {g_c} 为李群，生成元对应：零偏（平移）、外参（旋转）、增益/焦距（尺度）、Δt_sync（时间平移）、曝光（强度仿射）。轨道 O_y = {g_c y : c ∈ 𝒞}，切空间 A_y = T_y O_y = span{∂(g_c y)/∂c_k}。残差 r 称为**轨道内可吸收**若 r ∈ A_y（一阶近似），否则**轨道外**。R68 的 COF 是在 A 上的投影估计器。

**定义 295（规范不变量与商空间指纹）** 映射 f: 𝒴 → 𝒴/G，满足 f(g_c y) = f(y)，∀c ∈ 𝒞。实现取规范不变的组合（"gauge-invariant combinations"）：
f = ( ΔF/Δload, ‖p_i − p_j‖ / ‖p_j − p_k‖（刚体距离比）, Var(Δt_event 差分), g_i/g_j（多通道增益比）, I(x_vis ; x_tac) − I(x_vis ; x_force)（互信息差）)。
轨道内漂移被 f 商掉（这正是 R68 的盲区），轨道外故障必然改变 f（A95）。f 的参考分布 P_f^ref 由认证审计建立。

**定义 296（外部参照锚与可观测子空间）** 参照集 ℛ = {(y_j, y_j*)}，y_j* 为已知标准（标定质量块、已知长度基准、已知时延脉冲、标准色卡）。参照约束雅可比 R = ∂ρ/∂c，ρ 为参照残差。定义参照下的可观测子空间 O = (A + ker R)^⊥；故障方向 d 可检测 ⇔ proj_O d ≠ 0。**参照预算** b_ℛ = rank(R)/dim(A) ∈ [0,1]：b_ℛ=0 即纯自标定（R68，轨道内全盲），b_ℛ=1 即所有规范方向被钉住。

**定义 297（ROS2 QoS 契约与见证事件）** 通道 i 的契约 q_i = (d_i 截止期, l_i 存活期, r_i 可靠性, ε_i 时间戳偏斜界, s_i 最大丢样, h_i 历史深度)。违约谓词 V_i(t) = 1[∃ 违约]。见证 w_t = (i, type, ts_hw, |violation|)，type ∈ {DEADLINE_MISS, LIVELIVENESS_LOST, CLOCK_JUMP, SAMPLE_DROP, TF_BREAK, RELIABILITY_DROP}。**非吸收性**：w_t 由 DDS/生命周期在自己进程内产生，∂w_t/∂θ = 0，标定无法改变其分布。

**定义 298（溯源与有效测量集）** π_t = (node_id, clock_domain, seq, qos_verdict, tf_chain_hash, bag_hash)。有效溯源集 Π_valid。标定测量集
M_t = { y_s : π_s ∈ Π_valid ∧ ¬V(s) ∧ |ts_s − ts_hw(s)| ≤ ε_s }。
隔离集 Q_t = 其余观测 → 直接进入 fault_head 的 H_sensor^trans 证据，**不得**回流到 COF。构造性结论：ĉ_t 是 σ(M_t) 可测函数，而 w_t ∉ σ(M_t)，故标定更新与见证条件独立。

**定义 299（认证运行包络）** ℰ = (𝒳_env, 𝒬, 𝒰_budget, T_exp, cov)。𝒳_env 为外生条件集（环境温度、地面摩擦、光照、负载、网络负载、电池电压）；𝒬 为契约族；𝒰_budget 为允许不确定度上界；T_exp 为证书有效期；cov 为分层覆盖率。证书仅在 x_t ∈ 𝒳_env ∧ cov ≥ 1−γ 时有效。

**定义 300（指纹漂移检验与重标定准入）** 参考指纹 P_f^ref 由认证审计建立。检验统计量 D_f = MMD²(f_t, P_f^ref)（小样本用 Hotelling T²）。重标定更新 δc **准入** ⇔ (a) 标定后残差下降；(b) D_f(δc) ≤ τ_f(α)（规范不变，未被伪标定拉动）；(c) x_t ∈ 𝒳_env。任一条不满足 → 判为「伪标定（pseudo-calibration）」，升级为 H_sensor^trans 或包络逃逸，而不是被吸收。

**定义 301（证书生命周期与 RLC）** S ∈ {PROVISIONAL, VALID, SUSPENDED, REVOKED, EXPIRED}，与 ROS2 managed node lifecycle 同构映射（unconfigured ↔ PROVISIONAL，inactive ↔ SUSPENDED，active ↔ VALID，finalized ↔ REVOKED/EXPIRED）。迁移守卫：
- 审计通过 ∧ 未过期 ∧ 指纹正常 → VALID；
- QoS 违约率 > τ_w ∨ D_f > τ_f ∨ U > U_budget → SUSPENDED：冻结 ĉ、λ_floor = 0.9、k ≤ k_safe；
- 审计失败 ∨ 红线越界（R68 定义 276-ii）→ REVOKED：k = 0（安全停）；
- 到 T_exp → EXPIRED（须重新审计）。
所有迁移在单线程 executor 中原子执行，并写审计账本。

**定义 302（评估即审计 EAR）** 真机评估 e = (H_P 协议哈希, C 分层条件集, n_e 样本量, 1−β 功效, D_hold 留出集, δ_NI 非劣界, α 显著性, m 检验数)。**预注册**：H_P 必须在开跑前写入账本，运行中不得更改；分层按混杂因子做随机区组；续证判据为 A_e 在 Holm–Bonferroni 校正下通过 δ_NI 且安全裕度非负。禁止测试集复用（H_P 与历史 bag_hash 去重）。

**定义 303（时序规范与有效带宽）** 一律使用硬件时间戳 ts_hw。有效标定带宽 ω_cal(t) = 1/median(Δt_hw)。执行抖动 J_r 修正不确定度：U_eff = U(ĉ)·(1 + J_r/Δt_nom)。DEADLINE 违约的观测不入 M_t。目的：堵死「调度抖动 / 时钟跳变伪装成慢漂移」这条真机特有的攻击面。

**定义 304（AIC-GAUGE 干扰集）** ℰ_GAUGE = ℰ_CALM × ℰ_env × ℰ_qos × ℰ_eval × ℰ_ref：
ℰ_env = {缓变包络漂移, 未建模工况, 热漂移, 负载漂移}；
ℰ_qos = {deadline miss, liveliness loss, clock jump, sample drop, TF break}；
ℰ_eval = {欠功效, 分层泄漏, 测试复用, Goodhart 优化}；
ℰ_ref = {参照污染, 参照共模漂移, 参照过期, 参照被标定同化}。

**定义 305（证书 J_GAUGE）** J_GAUGE = (J_CALM, envelope_hash, cov, T_exp, b_ℛ, witness_log_hash, f_ref_hash, H_P, lifecycle_state, gauge_ver)。Valid ⇔ Valid(J_CALM) ∧ S = VALID ∧ 未过期 ∧ cov ≥ 1−γ ∧ QoS 违约率 ≤ τ_w ∧ D_f ≤ τ_f ∧ b_ℛ ≥ b_min。

**定义 306（参照预算下界）** 设可容忍的轨道内盲区比例为 δ_absorb。为使审计后的不可观测子空间维数满足 dim(A ∩ ker R)/dim(A) ≤ δ_absorb，需 b_ℛ ≥ 1 − δ_absorb。工程取值 b_min ≈ 0.3：至少钉住 30% 的规范方向，否则拒绝签发 VALID（只给 PROVISIONAL）。

**定义 307（管线）** 离线/仿真预训练（继承 R68）→ **真机预审计**（建立 ℰ、P_f^ref，测量参照预算 b_ℛ，签发 PROVISIONAL→VALID）→ **在线运行**（QoS/溯源/指纹监控 + RLC；COF 限定在 A）→ **周期真机审计/续证**（EAR + XRA）→ **伪标定拒绝 / 撤销 / 降级**。rosbag2 全量落盘，审计账本只追加，支持确定性重放。

**定义 308（指纹不变性假设 A95）** 对合法漂移 δc 且 x ∈ 𝒳_env：KL(P_f(·; c) ‖ P_f(·; c+δc)) ≤ ε_f·‖δc‖；对轨道外故障方向 d ∉ A：‖∂f/∂d‖ ≥ g_min > 0。A95 是本方案可检性的全部来源：**它成立多少，方案就有效多少**；它失效的方向就是第 6 节的原理性风险。

```python
            M.append(y)
        else:
            Q.append(y)                     # 隔离，转 H_sensor^trans 证据
    return M, Q


# IP-256/257 ENC+RLC：包络证书 + 生命周期（ROS2 managed node 同构）
class EnvelopeCertificate:
    STATES = ('PROVISIONAL', 'VALID', 'SUSPENDED', 'REVOKED', 'EXPIRED')
    def __init__(self, envelope, t_exp, cov, b_ref):
        self.env, self.t_exp, self.cov, self.b_ref = envelope, t_exp, cov, b_ref
        self.state = 'PROVISIONAL'
    def guard(self, audit_pass, qos_viol_rate, d_f, u_cal, now):
        if self.state == 'REVOKED': return self.state
        if now > self.t_exp: self.state = 'EXPIRED'
        elif not audit_pass or self.redline_violated(): self.state = 'REVOKED'
        elif (qos_viol_rate > TAU_W or d_f > TAU_F
              or u_cal > self.env.u_budget or self.cov < 1-GAMMA):
            self.state = 'SUSPENDED'
        elif audit_pass: self.state = 'VALID'
        return self.state


# IP-258/259 EAR+XRA：真机审计 + 外部参照锚（打破规范简并）
def evaluation_as_audit(system, protocol, strata, n_e):
    assert ledger.contains(protocol.hash), 'protocol must be pre-registered'
    rng = Rng(protocol.seed)
    results = []
    for stratum in strata:                          # 分层随机区组
        for _ in range(n_e // len(strata)):
            ctx = stratum.sample(rng)
            with standard_references(ctx) as refs:  # XRA：已知质量/长度/时延
                results.append(system.run_episode(ctx, refs, holdout=protocol.holdout))
    A_e = protocol.statistic(results)
    return renew_or_revoke(A_e, protocol.delta_NI, holm_bonferroni(protocol.alpha, len(strata)))


# IP-262 主闭环：GAUGE-RAS round
def GAUGE_RAS_round(M, obs):
    # 0) 取证：QoS 见证 + 溯源准入（在标定之前！）
    M_set, Q_set = valid_measurement_set(obs.channels)
    w = [w for y in obs.channels for w in QCL.witness(y.topic, y.meta)]

    # 1) R68 继承：MTM 一次前向 + 残差五元组
    z, o = M.mtm.forward(obs.pack, M.a_prev, M.scene_ctx)
    r = residuals(o, M.wm_residual_cache)

    # 2) COF 只在 A 内、只在 M_t 上更新（轨道约束 + 可吸收边界）
    c, U, thr = M.cof.step(o['cal'], r, sigma_stat(M), mask=M_set, subspace=M.cgq.A)

    # 3) CGQ：商空间指纹 + 重标定准入
    f = M.cgq.invariants(obs)
    d_f = M.cgq.mmd2(f, M.cgq.f_ref)
    pseudo_cal = not M.cgq.admissible(r, delta_c=U, f_now=f)
    if pseudo_cal:
        M.escrow.freeze_calibration()               # 冻结 ĉ，转故障/包络证据

    # 4) CFA：先标定后归因；SUSPENDED/REVOKED 走最坏情况
    joint_post = M.cfa(r, o['pi'], c, U)
    if M.enc.state != 'VALID':
        joint_post = worst_case_post(joint_post)

    # 5) R68 继承：C-RAS-WM 认证前缀 + 风险缩放（单调收紧）
    A = M.ach.propose(M.lsf.fuse(obs), H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, joint_post, min(M.vista.m, M.m_emo),
                                    M.alpha_chunk, M.mtm.rollout(z, A, 5))
    lam = max(M.efs.risk_scale(joint_post), thr['lam_floor'],
              0.9 if (M.enc.state != 'VALID' or pseudo_cal or w) else 0.6)
    if M.enc.state != 'VALID': k = min(k, K_SAFE)

    # 6) ENC-RLC：证书守卫（异步审计结论 + 本帧见证）
    state = M.enc.guard(audit_pass=M.last_audit_pass,
                        qos_viol_rate=rate(w, WINDOW),
                        d_f=d_f, u_cal=U, now=now_hw())
    M.rlc.apply(state, M.live_ptr)                   # 原子换装/冻结/停机

    # 7) 异步：审计账本 + 影子提交（继承 R68 CAC）
    M.ledger.append(dict(w=w, f=f, d_f=d_f, c=c, U=U, state=state, bag=M.bag_hash))
    M.cac.maybe_commit(M.shadow, dt=M.time_since_last_commit)
    return k, lam, joint_post, (c, U, state, d_f, w)
```

## 3. 推导

**引理 16（轨道内不可辨识下界）** 对任意 d ∈ A_y 且参照预算 b_ℛ = 0，考虑残差 r = ε·d。取 δc = ε（沿生成元）可得标定后残差恒为 0，故似然比 L(H_fault)/L(H_cal) ≡ 1，任何仅依赖测量 y 的检验检出概率 ≤ α（水平）。**系 1**：R68 的慢故障盲区恰为 A_y 在无参照约束下的子空间——这是**原理性的规范简并**，不是滤波器带宽问题；R68 的速率限制只限制了 ε 的时序，未限制其子空间。**系 2**：要看见 d，必须引入 ⟨d, R_j⟩ ≠ 0 的外部参照，即可观测子空间 O。

**引理 17（协议见证的构造性非吸收）** 对 QoS/溯源见证 w，由定义 298，M_t 的生成不依赖 w，ĉ_t = φ(M_t) 是 σ(M_t) 可测函数，故 I(w ; ĉ_t | M_t) = 0；且准入规则把 p(w | H_cal) 置零（标定假设不允许跨越违约通道）。因此契约类故障（deadline/liveliness/clock jump/drop/TF break）**不可被标定吸收**，与 ω_cal 无关。**系**：R68 盲区中「以时序/存活/数据完整性退化表现」的那一类，被协议层一次性移出。

**引理 18（包络逃逸的有界暴露）** 设真实条件在 t_0 逃出 ℰ（x_{t_0} ∉ 𝒳_env）。若其在 T_exp 内未触发任何见证/指纹，则由定义 301 证书在 t_0 + T_exp 强制 EXPIRED/SUSPENDED，系统转入收紧/停机。故最长未保护暴露 ≤ T_exp；长期时间平均未保护比例 ≤ (1−cov) + P(escape)·T_exp/T_op。**系**：R68 的「永久隐形慢故障」被压缩为「有界暴露窗」，且窗口长度是可审计、可配置的安全参数，而非未知量。

**定理 16（GAUGE-RAS 端到端风险一致性）** 在 R68 的 A87–A94 与 A95（定义 308）下，输出 τ_cmd 满足：
1. P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + **α_gauge + α_qos + α_env + α_eval + α_ref**；
2. α_qos = 0（引理 17，构造性）；α_gauge ≤ 1 − b_ℛ（引理 16，参照预算）；α_env ≤ (1−cov) + P(escape)·T_exp/T_op（引理 18）；α_eval ≤ β + mα（定理 17）；α_ref 由参照污染模型界定；
3. **S ≠ VALID ∨ pseudo_cal ∨ w ≠ ∅ ⇒ λ_risk ≥ 0.9 ∧ k ≤ K_SAFE**——任何外部/内部异常只导向收缩，绝不放宽（与 R68 定理 14-2 的单调性合并为全序）；

**定理 17（审计可靠性）** 在预注册、分层互斥、参照锚有效下：对真实退化超过 δ_NI 的系统误续证概率 ≤ β + m·α/m = β + α（Holm 校正到全局水平 α），且外部参照把不可观测子空间从 A 收缩到 A ∩ ker R，维数至少下降 rank(R) = b_ℛ·dim(A)。预注册消除 optional stopping 偏置，分层互斥消除测试集泄漏，bag_hash 去重消除测试复用。**系**：b_ℛ 是把「原理性不可辨识」兑换成「工程可观测」的汇率；每次外部参照都是一次对称性破缺。

## 6. 本轮最大风险

**一句话**：GAUGE-RAS 把全部安全性押在 A95「合法漂移不改变商空间指纹、而故障改变它」与「外部参照能打破规范简并」这两条假设上——**若真实故障恰好落在标定轨道 A 内，且其效应与合法增益/零偏漂移属于同一规范轨道（例如全通道等比例灵敏度衰减、均匀温漂被同一 δc 吸收），则商空间不变量、QoS 见证、包络覆盖率与统计审计全都看不见它，只有未污染的外部参照能看见；一旦审计参照本身随慢漂移一起被标定同化（参照共模污染），证书会在「VALID」的外衣下继续续签——我们只是把 R68 的单机自欺，升级成了带证书、带审计、带生命周期的自欺，而自欺的边界由参照预算 b_ℛ 决定，不由算法决定。**

**次级风险与缓解**：
1. **规范简并残余**（轨道内不可辨识）→ XRA + 提高 b_ℛ + 证书只给有限期，绝不给「永恒 VALID」；
2. **评估 Goodhart / 指标游戏化** → 预注册 + 留出 + bag 去重 + 只追加账本 + 审计审计者；
3. **参照污染/共模漂移** → 参照独立溯源、定期送检、参照本身纳入 J_GAUGE 版本链、参照与在役通道物理隔离；
4. **ROS2 中间件非确定性/时钟不可信** → 硬件时间戳 + 单调时钟 + deadline 违约即隔离 + 多时钟域交叉校验；
5. **生命周期振荡** → 迁移迟滞（hysteresis）+ 最短驻留时间 + SUSPENDED 只能经审计回 VALID，防止抖动；
6. **可用性代价** → 证书过期/挂起会降低自主性，需在 E295/E300 中显式度量「安全—可用」帕累托前沿，避免为安全把系统钉死。

**定义 299–300（包络 / 重标定准入）** ℰ = (𝒳_env, 𝒬, U_budget, T_exp, cov)。δc 准入 ⇔ 残差下降 ∧ D_f ≤ τ_f ∧ x∈𝒳_env；否则判伪标定，升级为故障/包络逃逸而非吸收。

**定义 301（生命周期）** 五态与 ROS2 managed node 同构；SUSPENDED 冻结 ĉ、λ_floor=0.9、k≤K_SAFE；REVOKED 停（k=0）；EXPIRED 须重审；迁移原子 + 迟滞。

**定义 302–303（审计 / 时序）** 预注册 H_P（开跑前入账）、分层随机区组、留出、功效、非劣界 δ_NI、Holm 校正、bag 去重。硬件时间戳，ω_cal=1/median(Δt_hw)，U_eff=U(1+J_r/Δt_nom)。

**定义 304–308（干扰 / 证书 / 预算 / 管线 / 假设）** ℰ_GAUGE 五乘积；J_GAUGE Valid ⇔ J_CALM ∧ VALID ∧ 未过期 ∧ cov≥1−γ ∧ 违约率≤τ_w ∧ D_f≤τ_f ∧ b_ℛ≥b_min；b_min≥1−δ_absorb；管线含真机预审计与周期续证；A95 = 指纹对合法漂移不变、对轨道外故障敏感。

```python
class CalibrationGroupQuotient:
    def invariants(self, obs):
        return np.array([dF_over_dload(obs), rigid_distance_ratio(obs),
                         var_of_event_interval_diff(obs), channel_gain_ratio(obs),

    def admissible(self, r, delta_c, f_now):

                and mmd2(f_now, self.f_ref) <= self.tau_f
                and self.envelope.contains(current_conditions()))

# IP-254/255 QCL+PVF：协议见证 + 溯源准入（构造性非吸收）
class QosContractLayer:
    CONTRACT = {'force': (0.01, 0.1, 0.002), 'img': (0.033, 0.2, 0.005),
                'wheel': (0.02, 0.1, 0.002)}   # deadline, liveliness, skew
    def witness(self, topic, meta):
        d, l, e = self.CONTRACT[topic]
        w = []
        if meta.period > d:      w.append(('DEADLINE_MISS', topic))
        if meta.alive_gap > l:   w.append(('LIVELINESS_LOST', topic))
        if abs(meta.ts_hw - meta.ts_pub) > e: w.append(('CLOCK_JUMP', topic))
        return w

def valid_measurement_set(observations):

    for y in observations:

            M.append(y)
        else:
            Q.append(y)                        # 隔离 → H_sensor^trans

# IP-256/257 ENC+RLC：包络证书 + 生命周期（ROS2 managed node 同构）
class EnvelopeCertificate:
    STATES = ('PROVISIONAL', 'VALID', 'SUSPENDED', 'REVOKED', 'EXPIRED')
    def guard(self, audit_pass, qos_viol_rate, d_f, u_cal, now):
        if self.state == 'REVOKED': return self.state
        if now > self.t_exp: self.state = 'EXPIRED'
        elif not audit_pass or self.redline_violated(): self.state = 'REVOKED'
        elif (qos_viol_rate > TAU_W or d_f > TAU_F
              or u_cal > self.env.u_budget or self.cov < 1-GAMMA):
            self.state = 'SUSPENDED'
        elif audit_pass: self.state = 'VALID'
        return self.state

# IP-258/259 EAR+XRA：预注册分层审计 + 外部参照锚
def evaluation_as_audit(system, protocol, strata, n_e):
    assert ledger.contains(protocol.hash)          # 预注册，开跑后不可改
    rng = Rng(protocol.seed); results = []
    for stratum in strata:                          # 分层随机区组
        for _ in range(n_e // len(strata)):
            ctx = stratum.sample(rng)
            with standard_references(ctx) as refs:  # 已知质量/长度/时延
                results.append(system.run_episode(ctx, refs, protocol.holdout))
    A_e = protocol.statistic(results)
    return renew_or_revoke(A_e, protocol.delta_NI,
                           holm_bonferroni(protocol.alpha, len(strata)))

# IP-262 主闭环
def GAUGE_RAS_round(M, obs):
    M_set, Q_set = valid_measurement_set(obs.channels)          # 0) 取证先行
    w = [w for y in obs.channels for w in QCL.witness(y.topic, y.meta)]

    z, o = M.mtm.forward(obs.pack, M.a_prev, M.scene_ctx)       # 1) R68 继承
    r = residuals(o, M.wm_residual_cache)

    c, U, thr = M.cof.step(o['cal'], r, sigma_stat(M),            # 2) 轨道内标定
                           mask=M_set, subspace=M.cgq.A)

    f = M.cgq.invariants(obs); d_f = M.cgq.mmd2(f, M.cgq.f_ref)  # 3) 商空间指纹
    pseudo_cal = not M.cgq.admissible(r, U, f)
    if pseudo_cal: M.escrow.freeze_calibration()                 #    伪标定冻结

    joint_post = M.cfa(r, o['pi'], c, U)                         # 4) 先标定后归因
    if M.enc.state != 'VALID': joint_post = worst_case_post(joint_post)

    A = M.ach.propose(M.lsf.fuse(obs), H=M.vista.H)              # 5) 认证前缀
    k = M.c_ras_wm.certified_prefix(A, joint_post, min(M.vista.m, M.m_emo),
                                    M.alpha_chunk, M.mtm.rollout(z, A, 5))
    lam = max(M.efs.risk_scale(joint_post), thr['lam_floor'],
              0.9 if (M.enc.state != 'VALID' or pseudo_cal or w) else 0.6)
    if M.enc.state != 'VALID': k = min(k, K_SAFE)

    state = M.enc.guard(M.last_audit_pass, rate(w, WINDOW),      # 6) 证书守卫
                        d_f, U, now_hw())
    M.rlc.apply(state, M.live_ptr)                               #    原子迁移

    M.ledger.append(dict(w=w, f=f, d_f=d_f, c=c, U=U,            # 7) 审计账本
                         state=state, bag=M.bag_hash))
    M.cac.maybe_commit(M.shadow, dt=M.time_since_last_commit)    #    R68 CAC 继承
    return k, lam, joint_post, (c, U, state, d_f, w)
```

## 4. 推导

**引理 16（轨道内不可辨识下界）** 对 d∈A、b_ℛ=0，残差 r=εd 可由 δc=ε 完全解释，似然比 ≡1，检出概率 ≤ α。系：R68 盲区 = A 在无参照约束下的子空间；速率限制只限 ε 时序、不限子空间；引入 ⟨d,R_j⟩≠0 的参照才可观测。

**引理 17（协议见证的构造性非吸收）** w ∉ σ(M_t)，ĉ=φ(M_t) 为 σ(M_t) 可测，故 I(w;ĉ|M)=0；准入把 p(w|H_cal) 置零。契约类故障（deadline/liveliness/clock/drop/TF）不可被标定吸收，与 ω_cal 无关。

**引理 18（包络逃逸有界暴露）** 逃逸后 T_exp 内未触发见证/指纹则证书强制 EXPIRED/SUSPENDED；最长未保护暴露 ≤ T_exp；长期比例 ≤ (1−cov)+P(escape)·T_exp/T_op。R68 的「永久隐形」→「有界暴露窗」。

**定理 16（端到端风险一致性）** P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_gauge+α_qos+α_env+α_eval+α_ref；α_qos=0（引理 17）、α_gauge≤1−b_ℛ（引理 16）、α_env≤(1−cov)+P(escape)·T_exp/T_op（引理 18）、α_eval≤β+α（定理 17）；且 S≠VALID ∨ pseudo_cal ∨ w≠∅ ⇒ λ_risk≥0.9 ∧ k≤K_SAFE——只收紧不放宽。

**定理 17（审计可靠性）** 预注册 + 分层互斥 + 参照有效下，对退化 > δ_NI 的系统误续证 ≤ β+α（Holm 全局水平）；参照使不可观测子空间由 A 收缩到 A∩ker R，维数至少降 rank(R)=b_ℛ·dim(A)。预注册消除 optional stopping，分层互斥消除泄漏，bag 去重消除复用。系：b_ℛ 是「原理性不可辨识」兑换「工程可观测」的汇率。

## 7. 本轮最大风险

**一句话**：全部安全性押在 A95「合法漂移不改变商空间指纹、故障改变它」与「外部参照能打破规范简并」上——**若真实故障恰落在标定轨道 A 内且与合法漂移同轨（如全通道等比例灵敏度衰减、均匀温漂被同一 δc 吸收），则商空间不变量、QoS 见证、包络覆盖率与统计审计都看不见它，只有未污染的外部参照能看见；一旦参照本身随慢漂移被标定同化，证书会在 VALID 外衣下继续续签——我们只是把 R68 的单机自欺，升级成了带证书、带审计、带生命周期的自欺，而自欺的边界由参照预算 b_ℛ 决定，不由算法决定。**

**次级风险与缓解**：规范简并残余 → XRA + 提高 b_ℛ + 证书限期；评估 Goodhart → 预注册 + 留出 + bag 去重 + 只追加账本；参照污染 → 独立溯源 + 定期送检 + 纳入 J_GAUGE 版本链；ROS2 时钟/中间件非确定性 → 硬件时间戳 + 单调时钟 + 违约隔离 + 多时钟域交叉校验；生命周期振荡 → 迟滞 + 最短驻留 + 仅审计可回 VALID；可用性代价 → 度量「安全—可用」帕累托前沿，避免为安全把系统钉死。
