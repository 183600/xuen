# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互的不确定性二分闭环」IP-253~263；灵感循环第 3 轮；本轮灵感：「位姿估计」×「双臂协调」）

> R69 把不确定性拆成 aleatoric 与 epistemic，并给 epistemic 配了一张「嘴」——看、问、触。它的全部效率收益押在「流模型的模态分布可信」上，自陈最大风险是**问错比不问更危险**。但 R69 始终站在**单个身体**的视角：它问的是「我对动作的判断歧义吗」，从没问过「**我对世界的几何描述，是否被第二个身体独立确认过**」。
>
> 本轮两个灵感正好补上这块：
> - **位姿估计**揭示：真实歧义常常不是噪声，而是物体对称群作用下的**离散轨道**——瓶子转 180° 就"长一样"。把它当 aleatoric 去收紧、或当 epistemic 去多采样，都是范畴错误；正确对象是 **SE(3)/G 上的分布**。
> - **双臂协调**揭示：两臂同时接触同一物体时构成**物理闭环**，闭环残差只由关节编码器算出，不经过相机、不经过位姿估计器、也不经过策略——这是继 R68 传感器残差、R69 流行为似然之后**第三条独立证据通道**，而且是本体感觉的。
>
> 核心命题：**位姿估计的歧义要按物体对称群取商来分类；双臂闭环给出一个标定层与策略层都无法吸收的几何第二意见；但闭环沿对称方向恒为零信息，两臂可能"一致地错"——因此必须区分「真一致」与「对称别名一致」，并用锚-探针的破对称接触 + 去相关检查来兑现几何证据。** 命名 **TWIN-RAS**（Two-arm World-consistency INvariant Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的两个身体，是否活在同一世界；我能否用身体去验证我看到的几何**」——位姿是单个身体对世界的猜测，双臂闭环是身体对自己的交叉审问。

## 0. 直觉与动机

**灵感 1（位姿估计 → 歧义常常是离散对称轨道，不是噪声）**
直觉：单目/深度 6D 位姿在对称物体上天然多解：圆柱绕轴任意转、方盒转 90°/180°、带法兰的零件绕孔轴旋转，图像几乎不变。这不是"估计得不准"，而是**世界本身存在多个物理等价解释**。R69 把策略歧义建模为动作轨迹的多模态；R70 应把位姿歧义建模为 **SE(3) 上的混合分布，并在物体对称群 G 下取商**。关键区分：**对称别名（alias）是同一物理状态的不同坐标写法，不是 epistemic 不确定性**。若把它当噪声，会过度收紧；若把它当独立模态，会重复计数、过度探询。位姿不确定性的正确对象是 `SE(3)/G` 上的分布。

**灵感 2（双臂协调 → 身体闭环是一条标定/策略都吸收不了的第三通道）**
直觉：两臂同时抓住/接触同一物体时，左臂正运动学推出的物体位姿、右臂正运动学推出的物体位姿，必须在同一个世界坐标系里重合。这个**闭环残差 r_loop** 只需关节编码器和已标定的运动学/抓取偏置，**完全不经过相机与位姿估计器**。R68 的 r_res 测「传感器自洽」，R69 的 Δa 测「行为自洽」，r_loop 测「**身体的几何自洽**」——三条通道，三种不可互相吸收的偏置。两臂天然互为对方的传感器。

**灵感 3（闭环的病理 → 沿对称方向零信息，两臂会一致地错）**
直觉：闭环残差对物体位姿的雅可比 J_loop 有一个零空间。若两臂抓的是对称等价特征，则物体沿对称群 Lie(G) 任意变换，两臂的关节读数可以完全不变——于是 **Lie(G) ⊆ ker J_loop**。这意味着：越是对称、越需要消歧的物体，闭环越是一致地"同意"。**"两臂都同意"在对称物体上是几何同义反复，不是证据**。这把 R69 的"单源采纳"风险升级成"几何共模"：两臂可以自信而一致地错。要破对称，必须引入闭环之外的观测。

**灵感 4（主动消歧 → 一臂为锚、一臂为探针，且必须在零空间之外）**
直觉：人类拆解一个看不清朝向的盒子，会一只手按住，另一只手去摸把手/凸起/质心位置。把这变成可认证的信息动作：**锚臂**维持认证接触、提供参照系；**探针臂**沿某一方向触碰一个**破对称特征**（不对称凸起、把手、或通过倾斜感受质心）。VoI 只有在探针方向落在**破对称子空间**（Lie(G) ∪ ker J_loop 之外）时为正；沿对称方向探测是纯浪费预算。这直接继承 R69 的 VoI 框架，但把信息动作从"看/问/触"升级为"**锚定-探询**"的几何版本。

**灵感 5（共模 → 两臂一致只有在去相关后才算证据）**
直觉：两臂并非天然独立——它们可能共享同一检测器偏置、同一基座漂移、同一物体模型误差。若误差完全相关，两臂即使在世界位姿全错时也会完美一致。因此必须主动**去相关**：改变构型、视点、力方向，使共享偏置在至少一条通道上产生不同投影。判据是：**高相关下一致、低相关下分歧 ⇒ 共模故障**；只有去相关条件下的一致才可定案。

**灵感 6（给 R69 的交互加几何可实现性约束）**
直觉：R69 的信息动作 g=(g_gaze, g_probe, g_ask) 只问"值不值"，没问"身体做不做得到、做的时候安不安全"。双臂系统里，探针动作必须：由一臂执行、另一臂保持认证锚、闭链内力不超限、两臂不自碰撞、闭环雅可比不病态、不落入奇异。多臂协调由此从"两个执行器"升级为"**一个受约束的几何推断器**"。

## 1. 形式化定义（增量：定义 310–322）

**定义 310（TWIN-RAS 总览）** TWIN-RAS = (MPE, SQC, BCC, SAD, DCC, CMG, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i / R68 定义 276-i）；
(ii) **双臂安全包络**：闭链内力 `f_int ≤ f_max`、自碰撞距离 `d_self ≥ d_min`、可操作度 `σ_min ≥ σ_thr`、关节/力矩限，且任何时刻**至少一臂维持认证接触**（交接 handoff 的短暂双松手需显式白名单）；
(iii) **几何证据纪律**：位姿模态定案需 **≥2 条去相关证据通道**一致（感知位姿 / 闭环残差 / 破对称接触）；**闭环单独不得认证对称轨道内任一模态**；单通道或共模一致不得定案。

**定义 311（SE(3) 位姿混合与对称商）** 位姿假设 `p_k=(R_k,t_k)∈SE(3)`，权重 `w_k`，模态内协方差 `Σ_k`。物体对称群 `G⊂SE(3)`（离散 `C_k`/`D_k` 或连续 `S¹`）。轨道 `Orb_G(p)={g·p : g∈G}`。商距离 `d_{SE3/G}(p,q)=min_{g∈G}‖Log(p⁻¹ g q)‖_Σ`。若两假设仅差 `g∈G`，称**对称别名（alias）**，不计作真实歧义。

**定义 312（位姿不确定性三分）** `U_ale^pose = Σ_k w_k tr(Σ_k)`（模态内、不可约）；`U_epi^pose = H(M/G | o)`（对称商后模态熵：遮挡/真多解，可约）；`U_cm`（共模偏差：不可由任何相对检查观测，**单独通道**，不直接并入 λ，而触发去相关探询或冻结）。三者语义不同，不做简单加和。

**定义 313（双臂闭环残差 BCC）** 记左/右臂基座 `T_{W,B_L}, T_{W,B_R}`、正运动学 `FK_L(q_L), FK_R(q_R)`、抓取偏置 `T_{L,O}, T_{R,O}`。两臂推断的物体位姿
`p̂_L = T_{W,B_L}·FK_L(q_L)·T_{L,O}`，`p̂_R = T_{W,B_R}·FK_R(q_R)·T_{R,O}`。
闭环残差 `r_loop = Log(p̂_L⁻¹ p̂_R) ∈ se(3)`，取加权范数 `‖r_loop‖_W`。**只依赖关节编码器与已标定运动学/抓取偏置，不依赖相机与策略** ⇒ 与 `r_res`、`Δa` 正交的第三通道。

**定义 314（闭环对称零空间）** 闭环对物体位姿的雅可比 `J_loop = ∂r_loop/∂p_O ∈ ℝ^{6×6}`，零空间 `N(J_loop)`。若两臂抓取特征在 `G` 下相容，则 `Lie(G) ⊆ N(J_loop)`。定义**对称盲子空间** `𝒩_G = N(J_loop) ∩ Lie(G)` 与**仅供参考子空间** `𝒮 = N(J_loop)^⊥`。闭环只对 `𝒮` 提供信息；对称别名落在 `𝒩_G`，闭环信息增益为 0。

**定义 315（对称商校准 SQC）** 判定哪些 `g∈G` 是**真实物理等价**（对所有观测含触觉/惯性/力都不可分辨），哪些只是**感知别名**（换一个接触或力就能分辨）。定义商校准误差 `ECE_G`：预测"g 不可分辨"与主动实验真值之偏差。`G` 过大会吞掉真实模态（过度自信），过小会把别名当独立模态（过度探询/过度保守）。`G` 合法 ⇔ 存在不对称观测能区分 `p` 与 `g·p`。

**定义 316（破对称主动消歧 SAD）** 信息动作 `g=(arm_anchor, arm_probe, u_probe, f_probe, t_stay)`：一臂保持认证接触作锚，另一臂沿方向 `u_probe` 以力 `f_probe` 触碰可破对称特征。`VoI_G(g)=H(M/G|o) − E_{y}[H(M/G|o,y)]`，约束：`u_probe ∉ (Lie(G) ∪ N(J_loop))`（否则 VoI=0、纯浪费）、锚已认证、闭链可行、内力/自碰撞/奇异满足。`g* = argmax_g [VoI_G(g) − c(g)]`。

**定义 317（双通道几何一致性 DCC）** 两物体路径估计 `p̂_perc`（感知）与两身体路径估计 `p̂_L, p̂_R`（闭环）。证据向量 `e_geo = (Log(p̂_perc⁻¹ p̂_L), Log(p̂_perc⁻¹ p̂_R), r_loop)`，满足余圈约束 `r_loop ≈ Log(p̂_perc⁻¹ p̂_R) − Log(p̂_perc⁻¹ p̂_L)`。其中感知-本体偏差 `r_cons = ‖(Log(p̂_perc⁻¹ p̂_L), Log(p̂_perc⁻¹ p̂_R))‖` 衡量**感知与本体是否描述同一个几何**。这是「位姿第二意见」，与 R69 的 FMA（行为第二意见）并列。

**定义 318（共模治理 CMG）** 通道误差相关 `ρ`。**去相关探询**：主动改变构型/视点/力方向，使共享偏置至少在一个通道上产生不同投影。判据：`ρ>ρ_max` ⇒ 两通道未去相关，一致不作证据，先做去相关；若**高 ρ 下一致、低 ρ 下分歧** ⇒ 判定共模故障；只有低 ρ 下一致才可定案。

**定义 319（双臂安全包络 RAS-WM‡）** 认证双动作前缀 `(anchor, probe)` 满足 `f_int ≤ f_max`、`d_self ≥ d_min`、`σ_min(J_loop) ≥ σ_thr`、关节/力矩限，且任一时刻至少一臂维持认证接触（handoff 白名单除外）。

**定义 320（几何证书 J_TWIN）** `J_TWIN = (J_FLUID, pose_mode_ece, ECE_G, r_loop_p95, r_cons_p95, ρ̂, f_int_max, twin_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ ECE_G ≤ τ_G ∧ 几何证据纪律满足 ∧ 包络未越界`。

**定义 321（三级几何退避）** (a) **几何已解**（闭环 + 破对称接触 + 去相关一致）⇒ 用消歧后位姿模态，`λ = λ_floor(U_ale^pose)`，并把 `U_epi^pose` 从 floor 中释放（resolution bonus）；(b) **未解/超预算/商不可信** ⇒ 位姿协方差膨胀并入 `λ_floor(U_ale^pose + U_epi^pose)`（比 R68 更保守）；(c) **共模可疑** ⇒ **冻结一切依赖位姿的动作**，回 R68/R69 纯保守，并请求外部锚（世界坐标/人/重力对齐惯性）。三级 λ 单调不降。

**定义 322（锚-探询调度与良态性）** 探询轨迹需保持 `σ_min(J_loop) ≥ σ_thr`（否则 `r_loop` 病态、误差异方差放大）；单位时间 ≤1 次探询、位移 ≤ ε_g、锚臂接触不中断；时间预算继承 R69。

# IP-264 MPE：SE(3)/G 多假设位姿（感知歧义显式化为对称轨道）
class MultimodalPoseEstimator:
    def __init__(self, det, group):
        self.det, self.G = det, group
    def predict(self, obs, K=1):
        hyps = self.det(obs, K)                  # [(p_k, Σ_k, w_k)]
        return quotient_modes(hyps, self.G)      # 按群作用归并轨道，得 M/G

# IP-265 SQC：对称商校准（哪些 g 是真物理等价）
def calibrate_quotient(estimator):
    ece = 0.0
    for g in estimator.candidate_group():
        distinguishable = active_contact_distinguishes(g)  # 触觉/惯性/力能否分辨
        ece += quotient_miscalibration(g, distinguishable)
    return estimator.G, ece

# IP-266 BCC：双臂闭环残差（只用关节编码器，不经相机/策略）
def loop_residual(qL, qR, kin, grasp):
    pL = kin.T_WB_L @ kin.fk_L(qL) @ grasp.L
    pR = kin.T_WB_R @ kin.fk_R(qR) @ grasp.R
    return se3_log(pL.inverse() @ pR)            # 第三证据通道

# IP-267 SAD：锚-探针破对称消歧
def choose_probe(modes, qL, qR, group, N_loop, budget):
    best = None
    for gp in probe_candidates(modes, group):
        if in_span(gp.direction, group, N_loop): # 沿对称/零空间探测 = 纯浪费
            continue
        if not budget.allow(gp):                 continue
        if not ras_wm.certify_bimanual(gp, qL, qR): continue
        score = pose_voi(modes, gp) - cost(gp)
        if best is None or score > best.score: best = (gp, score)
    return best if best and best.score > 0 else None

# IP-268 DCC：感知-本体-闭环三证据（余圈约束）
def geometric_consilience(p_perc, pL, pR):
    r_cons = (se3_log(p_perc.inv() @ pL), se3_log(p_perc.inv() @ pR))
    r_loop = se3_log(pL.inv() @ pR)
    return r_cons, r_loop                        # 三者满足 cocycle 约束

# IP-269 CMG：共模检测（高/低相关两种构型下的一致性）
def common_mode_check(ch):
    if ch.rho > RHO_MAX:                          return 'decorrelate'
    if ch.agree_high_rho and not ch.agree_low_rho: return 'common_mode_fault'
    return 'ok'

# IP-276 主闭环（继承 R69，加入几何层）
def TWIN_RAS_round(M, obs):
    qL, qR = M.arms.joints()
    modes  = M.mpe.predict(obs)                   # SE(3)/G 多假设
    pL, pR = M.bcc.object_poses(qL, qR)
    r_loop = M.bcc.loop_residual(qL, qR)
    r_cons, _ = M.dcc.geometric_consilience(M.mpe.map_pose(modes), pL, pR)
    cm = M.cmg.check(r_cons)
    geo_ok = (norm(r_cons) < TAU_CONS) and (cm == 'ok') and (M.sqc.ece_G <= TAU_G)
    # 1) 未解且有利可图 → 锚-探针破对称（必须在闭环零空间之外）
    if (not geo_ok) and M.budget.allow_probe():
        gp = M.sad.choose_probe(modes, qL, qR, M.mpe.G, M.bcc.nullspace(qL, qR), M.budget)
        if gp is not None:
            modes = M.sad.execute_and_update(gp, modes)
    # 2) 共模可疑 → 冻结位姿相关动作，回 R68/R69 纯保守 + 外部锚
    if cm == 'common_mode_fault':
        return conservative_freeze(M)
    U_ale, U_epi = pose_uncertainty(modes, M.mpe.G)
    U_floor = U_ale + (0.0 if geo_ok else U_epi)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    # 3) 双臂认证前缀（内力/自碰撞/奇异/至少一臂锚定）
    k = M.c_ras_wm.certified_bimanual_prefix(...)
    mode = select_pose_mode(modes, U_epi, lam)
    M.vqa_g.submit_async(r_loop, r_cons, cm, geo_ok)   # IP-275 几何审计
    return k, lam, mode, (U_ale, U_epi)

## 3. 推导

**引理 19（闭环对称零空间）** 设物体对称群 `G`，两臂抓取特征在 `G` 下相容。则 `Lie(G) ⊆ ker J_loop`：沿对称轨道移动物体不改变任何一臂的关节构型，故闭环残差恒为零、对"哪个对称别名成立"提供 **0 bit**。系：**闭环只能证明「两臂的相对说法一致」，不能区分对称别名**；对称物体的"两臂一致"是同义反复。

**引理 20（破对称探询的信息下界）** 设探针方向 `u` 在 `Lie(G) ∪ N(J_loop)` 之外的分量为 `‖P_⊥ u‖`。在 A99（接触观测对位姿局部线性、噪声有界）下，一次探询的期望位姿模态熵下降 `≥ c·‖P_⊥ u‖·SNR`；`u` 完全落在盲子空间内时增益为 0。系：**VoI 正比于破对称分量**——歧义大但对称为主导时，应先去相关/换特征，而不是盲目探询。

**引理 21（相对 vs 绝对）** 闭环残差只约束**相对**位姿：`‖p_O − p̂‖ ≤ ‖r_loop‖_W + ‖anchor_err‖ + ‖base_drift‖`。因此两臂一致仍可能有**共同基座漂移**；要约束绝对位姿，必须至少有一个绝对锚（静态世界接触 / 动捕 / 重力对齐惯性）。

**定理 18（TWIN 条件性严格包含 FLUID）** 当第二臂缺失、`J_loop` 病态或闭环不可信时，令 `r_loop` 为无信息通道，TWIN 逐指令退化为 R69 FLUID。在去相关保证与商校准 `ECE_G ≤ τ_G` 下，TWIN 的期望位姿风险 ≤ FLUID；且当几何未解或共模可疑时，λ 单调不降地回到 R68/R69 纯保守。**安全侧不让步，几何侧获得 resolution bonus。**

**定理 19（共模不可分辨性 / 两臂一致地错）** 若两通道相对感知共享同一位姿偏置 `b`（同一检测器/物体模型/基座漂移），则 `r_loop` 与 `p̂_perc` 的误差完全相关，`I(M; r_loop | p̂_perc) → 0`；此时即使 `p_O` 全错，两臂仍可一致。故**高相关下的一致不得提升置信**；唯一出路是主动去相关探询（定义 318）。

**定理 20（双臂协调安全与无突变）** 双动作前缀经 RAS-WM‡ 认证（定义 319）后物理风险 ≤ ε_int；切换锚/探角色时保持至少一臂认证接触、内力连续、`σ_min` 不越界 ⇒ 控制连续、无突变；共模/超时/投毒时按定义 321 单调退避，R68/R69 的提交与换装不变式保持。

## 6. 本轮最大风险

**一句话**：TWIN-RAS 的全部几何收益押在「两臂闭环残差是一条独立证据」这一前提上——但对**对称物体**，闭环沿对称方向恒为零信息，两臂会**一致地错**；此时"两臂都同意"是几何同义反复而非证据，系统会把一个对称别名当成已解决的位姿、自信地抓取或交接——**闭环证明的只是「我的两个身体说法一致」，而不是「世界就是那样」**。

**次级风险与缓解**：
1. **对称商校准错误**（把真歧义商掉、或把别名当独立模态）→ SQC + `ECE_G` 门控 + E302；
2. **共模失败**（共享检测器/物体模型/基座偏置）→ CMG 去相关探询 + 定理 19 + E306；
3. **锚臂失稳/交接掉物** → 至少一臂认证接触 + 内力连续 + E310；
4. **闭环病态**（近奇异、`σ_min` 过小）→ 定义 322 良态性约束 + E313；
5. **探询越界**（探针过力/自碰撞/诱发危险转身）→ RAS-WM‡ 认证 + E308。

# IP-264 MPE：SE(3)/G 位姿（对称别名按轨道归并）
class MultimodalPoseEstimator:
    def predict(self, obs, K=1):
        return quotient_modes(self.det(obs, K), self.G)   # 真实歧义 vs 别名

# IP-266 BCC：闭环残差（纯关节编码器，不经相机/策略）
def loop_residual(qL, qR, kin, grasp):
    pL = kin.T_WB_L @ kin.fk_L(qL) @ grasp.L
    pR = kin.T_WB_R @ kin.fk_R(qR) @ grasp.R
    return se3_log(pL.inverse() @ pR)

# IP-267 SAD：锚-探针破对称（零空间之外才有 VoI）
def choose_probe(modes, qL, qR, group, N_loop, budget):
    best = None
    for gp in probe_candidates(modes, group):
        if in_span(gp.direction, group, N_loop): continue      # 对称方向 = 浪费
        if not budget.allow(gp) or not ras_wm.certify_bimanual(gp, qL, qR): continue
        score = pose_voi(modes, gp) - cost(gp)
        if best is None or score > best.score: best = (gp, score)
    return best if best and best.score > 0 else None

# IP-268/269 DCC + CMG：几何一致性 + 共模判据
def geometric_consilience(p_perc, pL, pR):
    r_cons = (se3_log(p_perc.inv() @ pL), se3_log(p_perc.inv() @ pR))
    return r_cons, se3_log(pL.inv() @ pR)

def common_mode_check(ch):
    if ch.rho > RHO_MAX:                            return 'decorrelate'
    if ch.agree_high_rho and not ch.agree_low_rho:  return 'common_mode_fault'
    return 'ok'

# IP-276 主闭环（继承 R69）
def TWIN_RAS_round(M, obs):

    modes  = M.mpe.predict(obs)
    r_loop = M.bcc.loop_residual(qL, qR)
    r_cons, _ = M.dcc.geometric_consilience(M.mpe.map_pose(modes), *M.bcc.object_poses(qL, qR))
    cm = M.cmg.check(r_cons)
    geo_ok = (norm(r_cons) < TAU_CONS) and (cm == 'ok') and (M.sqc.ece_G <= TAU_G)

    if cm == 'common_mode_fault':

    U_ale, U_epi = pose_uncertainty(modes, M.mpe.G)

## 4. 推导

**引理 19（闭环对称零空间）** 两臂抓取在 `G` 下相容时 `Lie(G) ⊆ ker J_loop`：沿对称轨道移动物体不改变任何关节构型，`r_loop` 恒零，对"哪个别名成立"提供 0 bit。系：对称物体的"两臂一致"是几何同义反复。

**引理 20（破对称信息下界）** 探针方向在 `Lie(G)∪N(J_loop)` 外的分量 `‖P_⊥u‖` 越大，期望模态熵下降 `≥ c·‖P_⊥u‖·SNR`；完全落在盲子空间时增益为 0。系：VoI 正比于破对称分量。

**引理 21（相对 vs 绝对）** `‖p_O−p̂‖ ≤ ‖r_loop‖_W + ‖anchor_err‖ + ‖base_drift‖`：闭环只约束相对位姿，共同基座漂移不可见；绝对位姿需外部锚。

**定理 18（TWIN 条件性严格包含 FLUID）** 无第二臂/闭环病态时 `r_loop` 无信息，TWIN 逐指令退化为 R69；在去相关与 `ECE_G≤τ_G` 下期望位姿风险 ≤ FLUID，未解/共模时 λ 单调不降回 R68/R69 纯保守。

**定理 19（共模不可分辨性）** 两通道共享偏置 `b` 时误差完全相关，`I(M; r_loop|p̂_perc)→0`：即使 `p_O` 全错两臂仍可一致。高相关下的一致不提升置信，唯一出路是主动去相关。

**定理 20（双臂安全与无突变）** 认证后的双动作前缀物理风险 ≤ ε_int；锚/探切换保持至少一臂认证接触、内力连续、`σ_min` 不越界 ⇒ 控制连续、无突变；共模/超时/投毒时按三级退避单调退化。

## 7. 本轮最大风险

**一句话**：TWIN-RAS 的全部几何收益押在「两臂闭环残差是一条独立证据」这一前提上——但对**对称物体**，闭环沿对称方向恒为零信息，两臂会**一致地错**；此时"两臂都同意"是几何同义反复而非证据，系统会把一个对称别名当成已解决的位姿、自信地抓取或交接——**闭环证明的只是「我的两个身体说法一致」，而不是「世界就是那样」**。

**次级风险与缓解**：对称商校准错误（SQC + `ECE_G` 门控 + E302）；共模失败（CMG 去相关 + 定理 19 + E306）；锚臂失稳/交接掉物（至少一臂认证接触 + E310）；闭环病态（`σ_min` 良态性 + E313）；探询越界（RAS-WM‡ 认证 + E308）。
