# 第 44 轮（新循环第 4 轮） · Tactile-Grounded Sim-to-Real：把「力觉锚定」与「模式条件间隙」纳入可验证闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形只保边际覆盖 + 多用户契约求交可空」，但它仍压着两个未言明的**物理**假设：**(H1) 仿真间隙 θ_sim 是一个与任务模式无关的手工标量先验**——视觉通道尚可勉强接受，接触通道（impact/slip/stick）的间隙是模式依赖、非光滑、随摩擦与硬度漂移的；**(H2) 所有证书 margin 都是可比较的标量，可以取 min**——几何裕度是米、力裕度是牛顿与摩擦锥角，量纲不可比，v20 的 `min(m_lookup, m_lease, m_cap)` 在接触期物理上不成立。本轮灵感词「力觉传感」「仿真到现实」精确命中这两点：力觉是唯一能给接触动力学提供**物理接地**的在线测量，可把不可辨识的仿真间隙从「先验常数」变成「可证伪的条件区间」；而接触是非光滑、模式离散的，于是 (H1)(H2) 同时暴露。本轮据此把「间隙」升级为**模式条件共形区间**，把「证书组合」从标量 min 升级为**模式交接代数**，并引入**安全有界的主动触觉标定**，把不确定度主动换成裕度。

## 0. 直觉与动机

**灵感 1（力觉是 sim-to-real 的「物理锚点」）**：视觉 sim-to-real 是**不辨识**的——两种材质可以渲染得一模一样，但接触力天差地别；**力觉是可辨识的**——只要在真实世界复现同一动作并测得六维力/触觉，就得到仿真预测与真实的残差 `r = w_real − w_sim`。把 `r` 按接触模式分层做共形，得到模式条件间隙 `G_m(α)`。类比：视觉 sim-to-real 像「照着照片调色」，力觉 sim-to-real 像「用秤校准」。这是本轮第一个支点：**间隙不再是猜的，而是量出来的、可被证伪的区间**。

**灵感 2（接触证书不是标量，是「锥 + 秩」）**：几何约束是「别撞」，力约束是「别滑、别捏碎、别掉」。前者是距离，后者是摩擦锥内的位置与抓取扳手空间（GWS）的裕度。把两者做 min 等于把米和牛·米相加。正确做法是**按接触模式时序分离 + 模式边界交接集**：自由空间用几何证书，接触期用力觉证书，交界处（guard band）两者必须同时成立。这是本轮对 v20 `min(...)` 的直接修正：**不是更小的数更安全，而是「当前模式下成立的证书」才安全**。

**灵感 3（主动触觉标定：能感觉就能「先摸一下」）**：既然有力觉，就能在承诺高风险接触前用安全有界的小幅探测降低间隙不确定性。这把 v20 的「信任预算 τ_u」从只能被动扣减，升级为**可投资的信息-安全对偶**：花风险预算买不确定度下降。但探测本身可能把系统推入未建模的 impact 模式，收益不单调——必须用证书约束探测动作，并限制探测轮数。

**灵感 4（模式误判是最危险的瞬时）**：impact/slip 边界正是间隙最大、模式最易误判的瞬间。若模式估计错误，就会用错 `G_m` 与错证书，导致「模式条件覆盖」在最需要它的时刻静默失效。因此**模式本身必须持证**：模式证书 `M_cert` 与力觉证书捆绑，歧义只能更保守。

**耦合升级**：TGE（力觉接地间隙估计器）把 (sim, real) 力残差编译成模式条件共形区间；CCA（接触证书代数）把几何证书与力觉证书按模式交接组合；ATC（主动触觉标定）在安全集内主动缩小间隙；CSV（接触仿真验证器）在仿真中枚举接触模式、摩擦/硬度扰动与冲击，把反例回灌 CKB。四层架构由 v8 升级为 v9：在 L0/L1 增加**力觉接地层**，在 L3 用**模式交接代数**替代标量 min。

## 1. 形式化定义（增量：定义 44–50）

**定义 44（接触模式与模式条件仿真间隙）**：接触模式 `m ∈ M = {free, approach, impact, stick, slip, release}`。对同一动作序列在仿真与真实各执行一次，得到配对力/触觉轨迹 `w_sim(t), w_real(t)`，残差 `r(t)=w_real(t)−w_sim(t)`。对每个模式 `m`，取校准集残差范数 `{||r|| : mode(t)=m}`，Mondrian 共形阈值 `G_m(α)=Quantile_{1−α}`。若模式内样本可交换，则 `P(||w_real−w_sim|| ≤ G_m(α) | mode=m) ≥ 1−α`。**认证力区间**取范数球 `B(w_sim, G_m(α))`。**关键**：`θ_sim` 由标量先验降级为**条件区间**，且只在该模式下有效。

**定义 45（力觉证据的可辨识性）**：间隙 `G_m` 在方向 `v∈R^6` 上可辨识，当且仅当探测/执行动作在接触雅可比 `J_c` 的像空间中激励了 `v`，即 `v ∈ range(J_c^T)` 且激励能量 `≥ ε_ex`。若 `v ∉ range(J_c^T)`（如单侧接触、无切向激励），则摩擦/切向间隙在该方向**不可辨识**，证书必须退回先验保守上界 `G_m^prior(v)`。**命题**：不可辨识方向上的任何「实测更小」都不得降低该方向阈值——防止「测不到就当没有」。

**定义 46（接触证书与摩擦锥 / 抓取裕度）**：接触证书 `C_contact = (μ_lo, f_n^max, m_fric, m_fn, m_gws, m_slip)`。摩擦锥裕度 `m_fric = μ_lo·f_n − ||f_t|| ≥ 0`；法向力上限裕度 `m_fn = f_n^max − f_n`；抓取裕度 `m_gws` 由 GWS 内切球半径给出；滑移裕度对多点取最小 `m_slip = min_i(μ_lo·f_{n,i} − ||f_{t,i}||)`。`C_contact` 在实测 `w ∈ B(w_sim,G_m)` 且 `μ_real ≥ μ_lo` 时 sound。**注**：`m_fric` 与几何米制裕度不可比，禁止跨量纲 min。

**定义 47（模式条件证书与模式证书）**：证书 `c` 携带模式标签 `m(c)`，仅当当前模式 `m̂=m(c)` 时可用。模式估计器输出置信集 `M̂(δ)`，要求 `P(m∈M̂) ≥ 1−δ`。**模式证书 `M_cert`**：若 `|M̂|=1` 且该模式证书有效，则可守卫；若 `|M̂|>1`（边界不确定），必须取**所有候选模式证书的最保守交集**或进入安全减速/停机；若真实模式落在 `M̂` 外的概率上界 `> δ`，则该步不可守卫。**命题**：模式歧义只能使证书更保守，绝不更宽松。

**定义 48（异构证书的模式交接代数）**：定义组合算子 `⊗_H`，`H` 为交接集。自由空间证书 `c_geo` 与接触证书 `c_contact` 在模式切换时通过 `H` 交接：要求 `H ⊆ C_geo ∩ C_contact`（几何安全与接触安全在交接带同时成立），且模式自动机的每次转移都经过 `H`。**定理（模式交接 sound）**：若 (i) 自由模式内 `c_geo` 保持；(ii) 接触模式内 `c_contact` 保持；(iii) 所有模式转移的入口/出口都落在 `H`；(iv) `M_cert` 在转移点有效；(v) `G_m` 在该模式覆盖有效，则任意接触模式序列下执行 sound。**推论**：v20 的标量 min 被替换为「当前模式成立 + 交接集非空」，避免跨量纲比较。

**定义 49（主动触觉标定的信息-安全对偶）**：探测策略 `π_probe` 选择动作 `a_p ∈ A_safe(C_global∩Π_u)`，在真实系统上执行并观测残差，更新 `G_m`。**安全约束**：每步探测执行前后证书 `c` 均成立（含力觉证书），且探测幅度 `≤ Δ_p`。**收益**：`I(a_p)=E[G_m − G_m' | a_p]`（区间宽度或互信息的下降）。**定理（探测 sound）**：若每步探测都在 `A_safe` 内且 `M_cert` 有效，则探测不新增违例；探测只改变「未来的保守程度」，不改变「当前安全」。**限制**：`I(a_p)` 一般非单调，必须设预算 `B_probe` 与停止规则；若探测触发 impact（模式变化），立即回退最保守证书。

**定义 50（力觉租约与事件触发衰减）**：力/触觉高频且可在 impact 处突变。租约升级为向量 `ℓ_w=(m,τ,λ_w,κ)`，`λ_w` 由扳手变化率界 `||ẇ|| ≤ L_w·a_max` 给出；并叠加**事件触发**：当 `|w(t)−w(τ)| > ε_w` 或模式变化时租约立即失效，不等时间衰减。**命题**：事件触发 + 时间衰减同时满足时，wrench 租约不误用陈旧力界。**注**：力觉衰减率远高于几何，v20 的单一 `λ` 对接触不安全。

## 2. 新增产出与既有 IP 升级

### 2.1 IP-60 TACTILE-GROUNDED GAP ESTIMATOR（力觉接地间隙估计器 TGE）
1. **配对力残差采集**：同一动作回放 / 数字孪生同步，逐时刻对齐 `w_sim(t), w_real(t)`。
2. **模式条件共形**：按 `M` 分层 Mondrian，输出 `G_m(α)` 与不可辨识方向标记（定义 45）。
3. **漂移检测**：在线残差分布漂移 ⇒ 触发重标定或保守回退。
4. **与 CKB 指纹绑定**：材质、摩擦、硬度、传感器型号、接触模式、残差谱。

### 2.2 IP-61 CONTACT-CERTIFICATE ALGEBRA（接触证书代数 CCA）
1. **接触裕度计算**：摩擦锥、法向力上限、GWS 内切球、滑移最小裕度。
2. **模式条件证书 + 模式证书**：歧义时取最保守交集，绝不静默放行。
3. **模式交接代数** `⊗_H`：交接集验证 + 模式自动机转移守卫。
4. **与几何证书组合**：模式分离 + 交接集，替代 v20 的跨量纲 `min`。

### 2.3 IP-62 ACTIVE TACTILE CALIBRATOR（主动触觉标定器 ATC）
1. **安全探测动作库**：幅度 `≤ Δ_p`，执行前后证书成立。
2. **信息增益估计与预算**：`I(a_p)` 估计、`B_probe` 上限、停止规则。
3. **即时回退**：探测触发 impact/模式变化 ⇒ 立刻切最保守证书。
4. **探测-证书联合审计日志**：供离线复核「探测是否真的安全」。

### 2.4 IP-63 CONTACT-SIM-VALIDATOR（接触仿真验证器 CSV）
1. **接触模式覆盖**：free/approach/impact/stick/slip/release 全覆盖。
2. **物理扰动**：摩擦系数、硬度、传感器偏置/噪声/饱和/丢帧。
3. **冲击/颤振 stress test**：首接触、粘滑振荡、丢失接触。
4. **sim-to-real 残差统计**：验证 `G_m` 条件覆盖与模式混淆矩阵。

## 5. 本轮最大风险

**一句话**：模式条件的共形覆盖依赖模式标签正确且模式内可交换，而 impact/slip 边界正是间隙最大、模式最易误判的瞬间——一旦模式误判或主动探测把系统推入未建模接触，模式条件覆盖与探测 soundness 会同时静默失效；因此 E95（模式条件覆盖）与 E97（交接/误判）必须设为红线，默认回退到「自由空间几何证书 + 已知保守摩擦上界 + 禁止主动探测」这条永不失 sound 的底线。

## 2. 关键算法（伪代码）

### IP-60 TGE：配对残差、模式条件共形与可辨识性
```
def tactile_gap_estimate(paired, alpha):
    G = {}
    for m in MODES:
        R = [norm(w_real(t) - w_sim(t))
             for t in paired if contact_mode(t) == m]
        G[m] = quantile(R, 1 - alpha)          # Mondrian 分层
    return G

def certified_wrench_interval(w_sim, G_m, Jc, v, eps_ex):
    # 只在被激励的可辨识方向上采用实测间隙
    if v not in range_of(Jc.T) or excitation_energy(Jc, v) < eps_ex:
        return Ball(w_sim, G_m_prior(v))       # 不可辨识 => 退回保守先验
    return Ball(w_sim, G_m)                     # 认证区间

def detect_drift(recent_residuals, calib_residuals):
    return kl_divergence(fit(recent_residuals),
                         fit(calib_residuals)) > drift_threshold
```

### IP-61 CCA：接触证书、模式证书与模式交接
```
def contact_certificate(w, params, G_m):
    f_n = w.normal; f_t = norm(w.tangential)
    m_fric = params.mu_lo * f_n - f_t
    m_fn   = params.f_n_max - f_n
    m_gws  = gws_inner_radius(params.grasp_matrix)
    m_slip = min(params.mu_lo * f_ni - norm(f_ti)
                 for f_ni, f_ti in w.contacts)
    ok = (w in Ball(w_sim, G_m)) and all(
        x >= 0 for x in (m_fric, m_fn, m_gws, m_slip))
    return ContactCert(ok, m_fric, m_fn, m_gws, m_slip, mode=w.mode)

def mode_certificate(M_hat, delta):
    if len(M_hat) == 1:
        return ModeCert(single=next(iter(M_hat)), ok=True)
    return ModeCert(single=None, ok=False,
                    conservative=intersect_all(M_hat))   # 歧义 => 最保守

def compose(c_geo, c_contact, H, mode_cert):
    # 禁止跨量纲 min：按模式选择，交接集同时成立才切换
    if not mode_cert.ok:
        return conservative_intersection(c_geo, c_contact, mode_cert)
    if mode_cert.single in FREE_MODES:
        return c_geo
    return c_contact if H.subset_of(c_geo, c_contact) else SAFE_STOP
```

### IP-62 ATC：安全有界主动探测
```
def active_tactile_calibrate(cert, policy, budget, delta_p):
    spent = 0
    while spent < budget:
        a_p = policy.propose(cert, delta_p)      # 幅度 <= Δ_p
        if not cert.holds_before_and_after(a_p):
            break                                # 探测必须全程安全
        w = execute_safe(a_p)
        if contact_mode(w) != cert.mode:         # 触发 impact/模式变化
            return recalibrate_or_fallback(w)    # 立即回退最保守
        gain = expected_gap_reduction(a_p)
        if gain < min_gain:
            break                                # 收益不单调，设停止规则
        cert.update_gap(observe_residual(w))
        spent += 1
    return cert
```

### IP-51/58 升级：模式交接守卫与力觉向量租约
```
def car_guard(e, x, w, mode_cert, c_geo, c_contact, lease_w, t):
    if not mode_cert.ok:
        return conservative_intersection(c_geo, c_contact, mode_cert)
    if mode_cert.single in FREE_MODES:
        return c_geo.holds(e, x)
    if not lease_w_valid(lease_w, t):
        return SAFE_STOP
    return contact_certificate(w, params, G_m).ok and c_geo.holds(e, x)

def lease_w_valid(lease, t):
    if lease.mode != current_mode() or lease.superseded:
        return False                             # 事件触发优先于时间衰减
    bound = lease.m - lease.lam * (t - lease.tau)
    return bound >= lease.theta

def upgrade_persona_force_limit(persona, global_limit):
    return min(global_limit, persona.f_n_max)    # 只收缩，绝不扩张
```

## 6. 本轮最大风险

**一句话**：模式条件的共形覆盖依赖模式标签正确且模式内可交换，而 impact/slip 边界正是间隙最大、模式最易误判的瞬间——一旦模式误判或主动探测把系统推入未建模接触，模式条件覆盖与探测 soundness 会同时静默失效；因此 E95（模式条件覆盖）与 E97（交接/误判）必须设为红线，默认回退到「自由空间几何证书 + 已知保守摩擦上界 + 禁止主动探测」这条永不失 sound 的底线。
