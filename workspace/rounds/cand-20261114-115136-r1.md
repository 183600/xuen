# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环第 3 轮；本轮灵感：「主动交互」×「大语言模型」）

> R69 教会闭环「开口」：把注视/探针/问句当作动作，用 VoI 决定值不值得问，并用流匹配把不确定性拆成有形状的多模态。但它把大语言模型只当成一张**嘴**——把已经算好的软提示 `g_ask` 解码成一句人话。
>
> 真正被漏掉的是：**R69 的假设空间和问题空间其实都是封好的**。模态来自流采样，候选问句来自人工枚举，回答如何变成证据则语焉不详。而人类真正会做、机器真正该学的是——**当一句回答打开了一个模型从未想过的世界时，怎么办**。
>
> 本轮两个灵感正好把这个问题顶到台前：
> - **大语言模型**最擅长的不是回答，而是**提议**。它能把「门打不开」扩展成「锁坏了 / 门被反锁 / 今天闭馆 / 我拿错钥匙了」这类开放式假设，并提出从未被枚举过的问题。但它也会**幻觉**：凭空造出一个不存在的模态、一个不存在的因果。
> - **主动交互**一旦加上开放假设，就从「选一个预设问题」升级为「**设计一个实验**」：把问题及其「答案→证据」映射在发问之前就冻结（预注册），否则人和模型都能在听到答案后偷偷改写解释。
>
> 核心命题：**把大语言模型严格限制在「提议者」一侧，把物理与协议放在「裁判者」一侧；LLM 提供高召回、不可信的假设与问题，接地裁判与预注册契约提供低召回、可信的否决权；未被接地的假设只能抬高不确定性，永远不能降低保守度。** 命名 **HERMES**（Hypothesis Expansion with Registered Multimodal Evidence and Safeguards）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该问什么」，R70 问「**我连该问的是哪一类问题都不知道时，如何让一个会幻觉的模型替我扩展问题空间，又不让它替我把关**」。

## 0. 直觉与动机

**灵感 1（大语言模型 → 假设空间是开的，不是封的）**
直觉：R69 的模态 M 来自流采样，本质是「模型已经想到的多峰」。但开放式交互里，最值钱的信息往往来自**模型没想到的解释**：人一句「今天闭馆」，就引入了一个从未出现在训练分布里的隐变量。封世界里的 VoI 再精确，也只能在错误的假设集合上做最优；假设集合里根本没有正确答案时，算得越准错得越自信。LLM 的正确用法不是「把问题说得更好听」，而是**把假设集合撑开**：给定异常上下文，生成一批候选隐因 h，每个附一条「若 h 为真，应当可观测到什么」的可检验承诺 `commit(h)`。这等价于把「开世界」显式建模成一个**假设扩展算子**。
但必须立刻加一条铁律：扩展出来的假设默认都是**不可信的**。它们只有经过「接地裁判」（能否用可信通道现在检验）与「预注册契约」（能否在发问前冻结证据映射）两道门，才允许进入贝叶斯更新。

**灵感 2（主动交互 → 提问是一次可预注册的实验）**
直觉：R69 的 VoI 是在「问题集合给定」的前提下算的，且默认「问完就能用回答」。真实交互里最危险的动作恰恰是**先问、再解释**：人给出一个模糊、诱导或错误的回答，模型事后挑一个对自己有利的解释（motivated reasoning），再给错误盖上「已交互验证」的章。人类科学给出的解药是**预注册**：在看数据前写死分析方案。把它搬到交互上——每个问题 q 在发出前必须冻结四件事：(a) 答案空间的分割；(b) 每个假设下各答案类别的似然 `L_q`；(c) 中立性证书（问句不得把某个答案设成默认）；(d) 拒答/撒谎模型。注册哈希写入对话日志，回答到达后**只允许**按冻结的映射打分。提问由此从「获取一段文本」变成「执行一次实验」。

**灵感 3（提议者 ≠ 裁判者 → 模型的错误要能被确定性否决）**
直觉：LLM 同时做「提假设、写问句、解析回答」三件事，而这三件事共享同一套幻觉与谄媚偏差。如果让同一个模型既提议又裁判，它的偏差会被自我确认放大。HERMES 的架构性回答是**职责分离**：LLM 只做生成侧，裁判侧由确定性/统计性的接地裁判完成——物理量是否可测、承诺谓词是否成立、回答中的原子主张能否被传感器/一致性/时间逻辑验证。裁判侧不需要聪明，只需要**不会替提议者圆谎**。

**灵感 4（多轮 → 单轮纪律挡不住「温水煮青蛙」）**
直觉：R69 的证据纪律是单轮的（k 个源一致）。但引诱、锚定、共谋是**跨轮累积**的：每一轮都只移动一点点信念，单轮看都「没越界」，多轮下来却把系统带到攻击者想要的位置。所以 R70 必须把审计单位从「一次交互」提升到「一段对话」：维护一个与「中立反事实对话」的后验差异，一旦累积偏移超阈值就冻结对话、整段作废、退回 R69。**要审计的不是某一句话，而是这段对话把你带到了哪里。**

**灵感 5（主动性 → 不问也是动作，问谁比问什么更重要）**
直觉：R69 问「我该向谁求证」，却没有建模**被问者的能力**。问一个不知道的人，得到的不是信息，是噪声；而主动打断一个正在专注工作的人，本身有社交成本。于是主动性变成三方权衡：任务的 VoI、被问者的能力 κ、打扰的成本 `c_social`。加上「沉默」也是合法动作，调度器要学会**在该闭嘴时闭嘴**——主动交互成熟的标志不是问得多，而是问得少而准。

## 1. 形式化定义（增量：定义 310–322）

**定义 310（HERMES 总览与四不变式）** HERMES = (LHP, GR, PRC, ADA, RCM, DSA, DFA, RAS-WM††)。四不变式：
(i) **LLM 永不在控制/安全回路内**（继承 R69 定义 293-i、R68 定义 276-i）：LLM 只能输出「假设 / 问句 / 主张解析」三类结构化对象，任何执行量 (λ, k, τ) 只能由认证控制器产生；
(ii) **隔离单调性**：未经 GR 接地的假设只能增大 U，不能减小 λ；
(iii) **预注册完整性**：问句的证据映射必须在回答到达前冻结，冻结后不可改；
(iv) **对话级退避**：任一门（接地 / 预注册 / 能力 / 审计）失败 ⇒ 逐指令退化为 FLUID-RAS（进而 R68）。

**定义 311（开放假设与承诺）** 隐因假设 h = (desc_h, commit_h)，`desc_h` 为自然语言描述，`commit_h: 𝒪_trusted → {0,1,⊥}` 为可检验承诺（例：「若 h 为真，则热成像应出现门体温度梯度」）。LLM 提议 `H_open = LHP(o, ctx, M_flow)`（高召回，可含幻觉）。承诺必须在可信通道集合 `𝒞 = {r_geo, r_sync, r_zero, r_emo, r_wm, a_score}` 内可表达。

**定义 312（接地裁判与隔离集）** h 在时刻 t **可接地** iff `commit_h` 在预算内可由 `𝒞` 中至少一条通道判定且先验非退化：`H_ground(t) = {h : testable_t(commit_h) ∧ Var_prior(h) > 0}`。隔离集 `Q(t) = H_open \ H_ground(t)`。只有 `H_ground` 可进入信念更新，`Q` 永不参与定案。

**定义 313（隔离质量与方向约束）** 原模态熵扩展为 `H_mode^+ = H(M_ground | o) + H(Q | H_ground)`；隔离集只通过 `U_epi^+ = U_epi + w_Q·H(Q)` 抬高不确定性，且约束 `∂λ/∂H(Q) ≥ 0`、`∂λ/∂U_epi^ground ≤ 0`。即：未接地的假设只能让人更谨慎，不能成为「少保守」的理由。

**定义 314（预注册问句契约 PRC）** 问句 q 的契约 `κ(q) = (𝒜_q, {L_q(a|h)}_{h∈H_ground}, neut(q), lie_q, hash_q)`：`𝒜_q` 为答案空间的有限分割；`L_q` 为冻结似然；`neut` 为中立性证书（对每个答案类别做反事实重述不变性检验）；`lie_q` 为拒答/撒谎模型。执行前 `hash_q` 写入对话日志；执行后**只允许**按 κ(q) 打分，任何对映射的修改都使该证据作废。

**定义 315（回答归因 ADA）** 自然语言回答 y 经 LLM 解析为原子主张集合 `Claims(y) = {c_i}`（schema 约束、可枚举、可拒答）。每条 c_i 被路由到裁决通道：物理型（与 `𝒞` 对账）、逻辑型（与已知事实/前序回答一致性）、社会型（信任模型，弱证据）。主张接地率 `ρ_ground = |{c_i 可裁决}| / |Claims|`；`ρ_ground` 低 ⇒ 该回答按弱证据降权，不参与定案。

**定义 316（受访者能力模型 RCM）** 对受访者 r 与问题类 φ(q)，能力 `κ(r,φ) = P(correct | r, φ)` 以 Beta 后验在线更新。信任门：`κ(r,φ) < κ_min` ⇒ 该回答只作为隔离证据（抬高 U），不降低 λ。避免「问了一个不知道的人，却把噪声当信号」。

**定义 317（对话级审计 DFA）** 维护预注册哈希链 `ℋ` 与信念轨迹 `{b_t}`。定义与中立反事实对话 `D^⊥`（同预算、同问题类、无诱导重述）的后验散度 `G = sup_t D_KL(b_t ‖ b_t^⊥)`。`G > τ_groom` ⇒ 判定跨轮诱导/共谋，冻结对话并把该段证据整体作废，退回 FLUID-RAS。

**定义 318（主动性调度 DSA）** 动作集含「沉默」。发起主动交互 iff `VoI(g)·κ(r,φ) − c_social(g) − c_fatigue(history) > τ_pro > τ_react`（主动阈值严格高于被动阈值）。预算为有限时段 `[0,H]`：`Σ_t c_social + c_phys ≤ B_H`。目标是单位成本净信息增益最大，而非交互次数最大。

**定义 319（LLM 输出防火墙）** LHP 的三类输出（假设 / 问句 / 主张）分别过确定性闸门：schema 校验、承诺可表达性、问句中立性、主张可裁决性。任一不过 ⇒ 丢弃该输出；**丢弃永远安全**（退化为无 LLM）。LLM 不产生任何直接执行量。

**定义 320（异步思辨）** LLM 推理不在实时回路，运行于「思辨缓冲」：触发条件为 `U_epi 高 ∧ (mode_head 饱和 ∨ FMA 异常 ∨ 新颖性高)`，且每 `T_delib` 至多一次。缓冲产物带时间戳与观测版本；若证据年龄 `> τ_stale` 或观测已变，则作废。实时回路 P99 不因 LLM 改变。

**定义 321（证书 J_HERMES）** `J_HERMES = (J_FLUID, ρ_ground, ℋ, κ, G, claim_calibration_ece, llm_ver, dialogue_log_hash)`。Valid ⇔ `Valid(J_FLUID) ∧ ρ_ground ≥ ρ_min ∧ ℋ 完整 ∧ κ ≥ κ_min ∧ G ≤ τ_groom ∧ ECE_claim ≤ τ_ece'`。

**定义 322（干扰模型 ℰ_HERMES 与两级+对话退避）** `ℰ_HERMES = ℰ_FLUID × ℰ_ling`，`ℰ_ling` 含：诱导性提问、答案中注入指令（prompt injection）、谄媚式附和、幻觉假设、跨轮诱导/共谋、受访者无能或伪装。退避：四道门全开且消解成功 ⇒ `λ = λ_floor(U_ale)`（open-world bonus）；任一门失败 ⇒ 逐指令 FLUID-RAS；再失败 ⇒ R68 边界。

## 2. 关键算法骨架

```python
# IP-264 LHP：LLM 只做提议（高召回、不可信、schema 约束）
class LLMProposer:
    def propose_hypotheses(self, o, ctx):
        raw = self.llm.hypotheses(o, ctx)                      # 可能幻觉
        return [H(desc=d, commit=self.schema.commit(c)) for d, c in raw]

    def propose_questions(self, H_ground):
        return [Q.from_spec(s) for s in self.llm.questions(H_ground)]

    def parse_answer(self, y, q):
        return [Claim.from_json(c) for c in self.llm.parse(y, q)]   # 强 schema

# IP-265 GR：接地裁判（确定性，握有否决权）
def admit(h, o, channels):
    return h.commit.expressible_in(channels) and h.commit.testable_now(o)

# IP-266 PRC：预注册契约（发问前冻结证据映射）
def register(q, H_ground):
    kappa = (partition(q), freeze_likelihood(q, H_ground),
             neutrality_cert(q), lie_model(q))
    q.hash = sha256(kappa); dialogue_log.append(q.hash)       # 冻结、上链
    return q

def score(q, claim_classes):                                  # 只按冻结映射打分
    return {h: prod(q.L[a][h] for a in claim_classes) for h in q.H_ground}

# IP-267 ADA：回答归因（把自由文本拆成可裁决原子主张）
def attribute(y, q, channels):
    claims  = proposer.parse_answer(y, q)
    verdict = [channel_verdict(c, channels) for c in claims]   # physical/logical/social
    return Claims(grounded=[c for c, v in verdict if v.ok],
                  weak=[c for c, v in verdict if v.weak])

# IP-268/269 RCM + DSA：问谁、何时问、何时沉默
def competence_ok(r, phi):
    return rcm.posterior(r, phi).mean() >= KAPPA_MIN

def initiate(belief, modes, r, phi, history):
    voi  = entropy(belief.w) - expected_entropy(belief.w, best_info_action(modes))
    gain = voi * rcm.posterior(r, phi).mean() - social_cost(r, phi) - fatigue(history)
    return gain > (TAU_PRO if not history else TAU_REACT)

# IP-270/271 HERMES 主闭环：LLM 完全异步，实时回路与 R69 一致
def HERMES_round(M, o):
    z, o = M.mtm.forward(o); c, U_cal, thr = M.cof.step(o)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes = M.aud.decompose(samples, z)

    # 1) 触发后台思辨（不阻塞、带过期时间）
    if M.owm.trigger(U_epi, z) and M.delib.idle():
        M.delib.submit(lambda: plan_dialogue(M, o, modes))

    # 2) 非阻塞取回；只有四道门全开的证据才允许更新信念
    ev = M.delib.poll(max_age=TAU_STALE)
    if ev is not None and ev.gate_ok:
        U_epi_after, resolved = M.belief.update(ev), True
    else:
        g = M.mint.choose_interaction(modes, o, M.budget)     # R69 反应式兜底
        U_epi_after = M.cia.update_belief(modes, M.cia.execute(g)) if g else U_epi
        resolved = g is not None

    # 3) 风险缩放与认证：与 R69 完全相同
    U_floor = U_ale + (0.0 if resolved else U_epi_after)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_i.submit_async(ev, U_epi, U_epi_after)
    return k, lam, mode, (U_ale, U_epi_after)

# IP-272 后台：开放世界对话规划（LLM 提议 → 确定性裁判 → 预注册 → 审计）
def plan_dialogue(M, o, modes):
    H_open   = M.proposer.propose_hypotheses(o, M.ctx)
    H_ground = [h for h in H_open if admit(h, o, M.channels)]
    if not H_ground: return GateFail("no_grounding")           # 隔离集只抬 U
    Q = [q for q in M.proposer.propose_questions(H_ground)
         if register(q, H_ground).hash]                        # 中立/预算门
    if not Q or not initiate(M.belief, modes, q.respondent, q.phi, M.history):
        return GateFail("no_question")
    q = max(Q, key=lambda q: dsa_score(q))
    y = M.cia.execute(q)                                       # 看/问/触，过 C-RAS-WM
    ev = score(q, attribute(y, q, M.channels))
    if not competence_ok(q.respondent, q.phi): return GateFail("incompetent")
    if M.dfa.divergence(ev) > TAU_GROOM:       return GateFail("groom")
    if ev.rho_ground < RHO_MIN:                return GateFail("ungrounded")
    return Evidence(ev, gate_ok=True)
```

## 3. 推导

**引理 19（隔离单调性与安全支配）** 设信念更新只接受 `H_ground`，则对任意状态 s，`U_epi^+(s) ≥ U_epi(s)` 当且仅当 `Q(s) ≠ ∅`；又 `λ_floor(·)` 单调不减，故在无全门证据时 `λ_HERMES(s) ≥ λ_FLUID(s)`。换句话说，**LLM 的幻觉在此架构下只会踩刹车，不会踩油门**。

**引理 20（预注册对欺骗自由度的收缩）** 设回答到达前的证据映射集合为 Π，单源采纳下对手可事后选择 `π ∈ Π` 最大化似然，其可利用自由度 `|Π|`。预注册把可用映射固定为 `π*`（哈希冻结），使事后重解释的收益从 `max_π log p_π(y|h)` 降为 `log p_{π*}(y|h)`。故谎言/共谋的可利用增益 ≤ `log(max_π p_π / p_{π*})`，且在 `p_{π*}` 校准良好时趋于 0。系：**预注册不是让谎言消失，而是让谎言无法在事后变形**。

**引理 21（能力门控的信息损失上界）** 若真实能力 `κ < κ_min`，则回答与隐因的互信息 `I(answer; h) ≤ κ·log|𝒜_q| + h_b(κ)`（h_b 为二元熵）。把它降级为非证据的损失不超过此上界，却阻止了把「噪声」当「信号」注入信念。故对低能力受访者，**不问的期望风险不高于问**。

**定理 18（条件安全包含链 HERMES ⊇ FLUID-RAS ⊇ CALM-RAS）** 在 A99（接地谓词对物理量可靠：commit(h) 为真且可测 ⇒ h 的物理后果确实可观测）、A100（预注册在回答到达前冻结且哈希不可篡改）、A101（能力后验一致）、A102（对话审计能检出累积偏移）下，HERMES 在任意状态的最坏期望风险 ≤ FLUID-RAS；且当 (i) 所有 LLM 假设被隔离，或 (ii) 无通过预注册的问题，或 (iii) 受访者能力低于门限，或 (iv) 审计告警 时，两者**逐指令相同**。因此 R69 是 HERMES 在「四门至少一门关闭」边界上的退化，R68 是再退化的边界。安全侧不让步，效率侧仅在四门全开时获得 open-world bonus。

**定理 19（异步思辨的实时不变式）** LLM 推理不进入实时回路；控制量 (λ, k, τ) 只依赖 `poll()` 的返回值。若缓冲产物过期或观测版本不匹配，则视同无证据。故闭环最坏延迟与 R69 相同，R68/R69 的实时与无突变保证（R68 定理 15、R69 定理 17）保持不变。

**引理 22（对话级散度的近似可加性）** 若每轮后验 KL 偏移为 `δ_t`，则 `G ≈ Σ_t δ_t + o(Σδ_t^2)`；因此单轮阈值 `δ_t < τ_turn` 不足以保证 `G ≤ τ_groom`，必须显式审计累积量。这是「每轮都合规、整体却越界」的形式化，也是 DFA 存在的理由。

## 6. 本轮最大风险

**一句话**：HERMES 把 LLM 的不可信从「答案」转移到了「**接地谓词与预注册似然**」上——若 `commit(h)` 与 `L_q` 本身仍由同一个会幻觉的模型起草，系统就可能「**在地上稳稳地站错**」，而且因为盖了预注册和接地的章，这种错误比 R69 那种诚实的不知道**更难被审计发现**。

**次级风险与缓解**：
1. **接地谓词是新的单点故障**（弱代理指标冒充物理量）→ 谓词只能由可信通道 + 人工/形式化审核注册；`commit` 与 `L_q` 的作者必须与提议者分离（双模型/双来源）；
2. **预注册似然本身失准** → `claim_calibration_ece` 入证书，越界即禁用 open-world bonus、退回 FLUID-RAS；
3. **谄媚与能力伪装** → RCM 在线后验 + 跨源一致性 + DFA 累积散度，三者任一告警即降级；
4. **多轮对话疲劳与打扰** → DSA 主动阈值严格高于被动 + 有限时段预算 + 沉默动作；
5. **异步证据过期导致行为抖动** → `τ_stale` 与观测版本号硬校验，过期证据视同无证据。

## 3. 关键算法伪代码

```python
# IP-264 LHP：LLM 只提议（高召回、可幻觉、schema 约束）
class LLMProposer:
    def propose_hypotheses(self, o, ctx):
        return [H(desc=d, commit=self.schema.commit(c))
                for d, c in self.llm.hypotheses(o, ctx)]
    def propose_questions(self, H_ground):
        return [Q.from_spec(s) for s in self.llm.questions(H_ground)]
    def parse_answer(self, y, q):
        return [Claim.from_json(c) for c in self.llm.parse(y, q)]

# IP-265 GR：接地裁判（确定性、握否决权）
def admit(h, o, channels):
    return h.commit.expressible_in(channels) and h.commit.testable_now(o)

# IP-266 PRC：预注册契约（回答到达前冻结）
def register(q, H_ground):
    kappa = (partition(q), freeze_likelihood(q, H_ground),
             neutrality_cert(q), lie_model(q))
    q.hash = sha256(kappa); dialogue_log.append(q.hash)
    return q

def score(q, claim_classes):
    return {h: prod(q.L[a][h] for a in claim_classes) for h in q.H_ground}

# IP-267 ADA：回答归因
def attribute(y, q, channels):
    claims  = proposer.parse_answer(y, q)
    verdict = [channel_verdict(c, channels) for c in claims]
    return Claims(grounded=[c for c, v in verdict if v.ok],
                  weak=[c for c, v in verdict if v.weak])

# IP-268/269 RCM + DSA
def initiate(belief, modes, r, phi, history):
    voi  = entropy(belief.w) - expected_entropy(belief.w, best_info_action(modes))
    gain = voi * rcm.posterior(r, phi).mean() - social_cost(r, phi) - fatigue(history)
    return gain > (TAU_PRO if not history else TAU_REACT)

# IP-270~272 主闭环 + 后台对话规划（LLM 完全异步）
def HERMES_round(M, o):
    z, o = M.mtm.forward(o); c, U_cal, thr = M.cof.step(o)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, K), z)
    if M.owm.trigger(U_epi, z) and M.delib.idle():
        M.delib.submit(lambda: plan_dialogue(M, o, modes))     # 不阻塞
    ev = M.delib.poll(max_age=TAU_STALE)                       # 可能 None
    if ev is not None and ev.gate_ok:
        U_epi_after, resolved = M.belief.update(ev), True
    else:
        g = M.mint.choose_interaction(modes, o, M.budget)      # R69 反应式
        U_epi_after = M.cia.update_belief(modes, M.cia.execute(g)) if g else U_epi
        resolved = g is not None
    U_floor = U_ale + (0.0 if resolved else U_epi_after)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_i.submit_async(ev, U_epi, U_epi_after)
    return k, lam, mode, (U_ale, U_epi_after)

def plan_dialogue(M, o, modes):
    H_ground = [h for h in M.proposer.propose_hypotheses(o, M.ctx)
                if admit(h, o, M.channels)]
    if not H_ground: return GateFail("no_grounding")
    Q = [q for q in M.proposer.propose_questions(H_ground)]
    Q = [register(q, H_ground) for q in Q]
    if not Q or not initiate(M.belief, modes, q.respondent, q.phi, M.history):
        return GateFail("no_question")
    q  = max(Q, key=dsa_score)
    y  = M.cia.execute(q)                                      # 过 C-RAS-WM
    ev = score(q, attribute(y, q, M.channels))
    if not M.rcm.competence_ok(q.respondent, q.phi): return GateFail("incompetent")
    if M.dfa.divergence(ev) > TAU_GROOM:            return GateFail("groom")
    if ev.rho_ground < RHO_MIN:                     return GateFail("ungrounded")
    return Evidence(ev, gate_ok=True)
```

## 4. 推导

**引理 19（隔离单调性与安全支配）** 信念更新只接受 `H_ground`；当 `Q ≠ ∅` 时 `U_epi^+ ≥ U_epi`，而 `λ_floor` 单调不减，故无全门证据时 `λ_HERMES ≥ λ_FLUID`。LLM 的幻觉在此架构下只会踩刹车，不会踩油门。

**引理 20（预注册对欺骗自由度的收缩）** 事后选映射使可利用自由度从 `|Π|` 降为 1；谎言/共谋的增益 ≤ `log(max_π p_π / p_{π*})`，校准良好时趋于 0。预注册不是让谎言消失，而是让谎言无法在事后变形。

**引理 21（能力门控的信息损失上界）** 若 `κ < κ_min`，则 `I(answer;h) ≤ κ·log|𝒜_q| + h_b(κ)`；降级为非证据的损失不超过此界，却阻止噪声当信号。故对低能力受访者，不问的期望风险不高于问。

**引理 22（对话级散度近似可加）** `G ≈ Σ_t δ_t + o(Σδ_t^2)`；单轮 `δ_t < τ_turn` 不足以保证 `G ≤ τ_groom`，必须显式审计累积量——这是「每轮合规、整体越界」的形式化。

**定理 18（条件安全包含链 HERMES ⊇ FLUID-RAS ⊇ CALM-RAS）** 在 A99（接地谓词对物理量可靠）、A100（预注册冻结且哈希不可篡改）、A101（能力后验一致）、A102（审计可检出累积偏移）下，HERMES 最坏期望风险 ≤ FLUID-RAS；当（i）全假设隔离 /（ii）无通过预注册的问题 /（iii）能力低于门限 /（iv）审计告警 时逐指令相同。R69 是「四门至少一门关闭」的退化，R68 是再退化边界；安全不让步，效率仅在四门全开时获 open-world bonus。

**定理 19（异步思辨的实时不变式）** LLM 不在实时回路；控制量只依赖 `poll()`。过期或观测版本不匹配即视同无证据。故闭环最坏延迟与 R69 相同，R68 定理 15 / R69 定理 17 的实时与无突变保证保持。

## 7. 本轮最大风险

**一句话**：HERMES 把 LLM 的不可信从「答案」转移到了「**接地谓词与预注册似然**」上——若 `commit(h)` 与 `L_q` 本身仍由同一个会幻觉的模型起草，系统就可能「**在地上稳稳地站错**」，而且因为盖了预注册和接地的章，这种错误比 R69 那种诚实的不知道**更难被审计发现**。

**次级风险与缓解**：接地谓词成为新单点故障 → commit 与 L_q 的作者与提议者分离（双模型/双来源）+ 形式化审核；预注册似然失准 → `ECE_claim` 入证书，越界即退 FLUID-RAS；谄媚与能力伪装 → RCM + 跨源一致 + DFA；多轮疲劳 → DSA 主动阈值更严 + 有限预算 + 沉默动作；异步证据过期 → `τ_stale` 与观测版本硬校验。
