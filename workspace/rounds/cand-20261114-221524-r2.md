# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配×主动交互消歧」IP-253~263；本轮灵感：「基线复现」×「创新点提炼」）

> R66→R69 造了一座四层塔：R66 定控制权、R67 管未来、R68 校准传感器、R69 学会提问。每一层都在补上一层自陈的最大风险——可**没有一层被真正承重测试过**：E286–E300 全是"实验设计"，没有一个跑过；每轮比较的基线都是"上一轮自己报的数"，而上一轮从未被独立复现。于是整条"R69 比 R68 好 12%、R68 比 R67 好、R67 比 R66 好"的证据链，是**建在云上的相对比较**：任何一环的基线被高估，下游所有增量都是幻觉。
>
> 本轮两个灵感不是再加一层，而是**回到地面**：
> - **基线复现**：把"复现"定义为**等价性检验**（不是"没测出差异"），引入**外部锚点**（第三方已发表基线）先把"实验台"校准好；
> - **创新点提炼**：用消融 + 归因 + 算力匹配 + 最短充分组件集，把 11 个 IP 分成**承载 / 条件 / 装饰 / 有害**四类，只保留真正撑住结论的那几个。
>
> 核心命题：**先证明"测量可信"，再证明"改进为真"，最后才谈"创新在哪"。** 命名 **REPLICA-RAS**（Reproducibility-first, Equivalence-tested, Point-wise Lineage & Innovation-Carving Audit）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我该向谁求证**」，R70 问「**我说的『变好了』是真的吗**」——先复现基线，再提炼创新。

## 0. 直觉与动机

**灵感 1（基线复现 → 没有锚的改进不可证伪）**
直觉：R69 宣称成功率 +12%。但"改进"永远是相对量，需要一个可信的零点。现在的零点是 R68 的自报值，而 R68 从未被独立复现。若 R68 的基线被高估 10%，R69 的 +12% 里可能 10% 是虚的。更隐蔽的是**误差沿链累积且同号**：每轮都倾向于把上一轮的最佳种子结果当作基线，偏差会单调叠加而不会抵消。严谨地说：跨轮"链式相对比较"的误差上界是各轮复现误差之和；只有插入**外部锚点**（B1）把误差重置为单轮复现误差，比较才可解释。复现不是形式主义，它是**把相对量重新锚定到绝对量**的唯一手段。

**灵感 2（创新点提炼 → 创新通胀必须去杠杆）**
直觉：R69 一口气加了 11 个 IP，每个都"听起来必要"。但"必要"至少分四种：**承载**（去掉主结论就塌）、**条件**（只在特定故障/歧义/OOD 下才起作用）、**装饰**（去掉在噪声内测不出差别）、**有害**（净收益为负或引入新风险）。不蒸馏，我们既不知道 11 个里真正撑住结论的是 2 个还是 9 个，也无法诊断"越加越脆"的病根——每多一个组件就多一个要独立信任的黑箱。提炼 = 把"创新"从叙事降维成**可测量的边际贡献**。

**灵感 3（测量先于改进 → 与 R68 同构）**
直觉：R68 校准的是**传感器**（"我的测量还准吗"）；R70 校准的是**研究仪器**（"我用来比较的实验台准吗"）。同一个哲学：在信任任何改进之前，先信任产生改进的测量。R68 用外部标准（物理/几何一致性）验传感器，R70 用外部锚点（第三方复现）验实验台。**越是华丽的结论，越需要朴素的锚。**

**灵感 4（复现 ≠ 没差异 → 必须做等价检验）**
直觉：很多"复现成功"其实是"我没测出显著差异"。但 p>0.05 既可能是真等价，也可能是样本太小、功效不足，二者无法区分。正确做法是预注册一个等价边界 δ_rep 做**双单侧检验（TOST）**：只有效应量的置信区间完全落在 [Δ̂−δ_rep, Δ̂+δ_rep] 内，才叫复现；若与容忍区无交叫失败；若相交但不包含叫"未定"（功效不足）。**把"无法拒绝"当"证实"，是复现剧场的第一块砖。**

**灵感 5（算力匹配的零假设 → 很多"创新"其实是算力）**
直觉：FLUID 比 R68 多了 K 采样、Hutchinson 回放、VoI 枚举。如果把这些额外算力直接白送给 R68（多采样取均值、集成、测试时增强、更长规划），它也许也能涨 12%。那么 FLUID 的"算法创新"就只是**包装过的算力**。所以基线不能是"原版 R68"，而必须是**同等算力/延迟预算下的 R68+**（compute-matched null, CMN）。**创新必须击败"白送同样算力"的对手，否则它不叫创新，叫预算。**

**灵感 6（蒸馏即 MDL → 最短充分解释）**
直觉：奥卡姆剃刀的可操作版本：在所有能保住效应与安全的组件子集里，选**描述长度最短**的那个。蒸馏不是"砍功能"，是找**解释效应所需的最小因果集**。这与 R68 的"零学习写操作"一脉相承——系统越简单，能出错的地方越少；能用 2 个组件解释的增益，不需要 11 个组件来背书。

**灵感 7（负结果保全 → 防止幸存者偏差）**
直觉：只在成功时前进、失败时悄悄换题，会让整条研究链变成幸存者偏差的产物。必须有一本**负结果账本（NRL）**：每个失败/未定的 claim 都留在账上并被后续轮次显式引用。负结果不是耻辱，它是**被排除掉的假设空间体积**——省下的是未来无数轮重复踩坑的成本。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（研究主张与账本 CL）** 主张 c = (id, round, statement, metric m, direction, 预测效应 Δ̂_c, 证伪器 F, status)。status ∈ {unverified, reproduced, failed, underdetermined, retired}。账本只追加、不静默删除；retired 保留全部历史。**任何"某某有效"的陈述若无 id 与证伪器，不得进入账本，也不得进入论文。**

**定义 311（复现实验台 ERS）** S = (E, seeds, metric_defs, budget, α, δ_rep, MDE, hardware_fp, code_hash)。其中 E 为环境套件（版本哈希冻结）、seeds 预注册、metric_defs 含方向与 CI 方法、δ_rep 为等价边界、MDE 为最小可检测效应、hardware_fp 为硬件指纹。S 一经 B3 冻结，本轮内不可改；改动须开新版本并重跑 B0。

**定义 312（基线锚定协议 BAP，四道门）**
- **B0 确定性门**：同一 seed 两次运行在容差 τ_bit 内一致（消除不可复现的随机性来源）。
- **B1 外部锚门**：复现一个**第三方已发表**基线数（不是本项目自报），TOST 等价。
- **B2 前轮锚门**：逐条复现 R68、R69 的 headline claim，TOST 判定 reproduced/failed/underdetermined。
- **B3 候选门**：仅当 B0 通过且 B1、B2 全部为 reproduced（或 failed 已被解释并下调基线）时，才允许测量新系统。
GateReport = (pass_B0, pass_B1, {c: status}, ready)。**ready=False 时，任何新 claim 只能标 unverified。**

**定义 313（复现性 / 等价检验）** 效应 Δ 的 bootstrap 置信区间 [L,U]（水平 1−2α）。对 claim c：
- Reproduced(c) ⇔ [L,U] ⊂ [Δ̂_c − δ_rep, Δ̂_c + δ_rep]（TOST 通过）；
- Failed(c) ⇔ [L,U] ∩ [Δ̂_c − δ_rep, Δ̂_c + δ_rep] = ∅；
- Underdetermined(c) ⇔ 其余（相交但不包含，通常因功效不足）。
**"未能拒绝零假设"不构成 Reproduced。** 这是本定义与常见实践的分水岭。

**定义 314（算力匹配零假设 CMN）** 设创新相对基线多消耗预算 b（FLOPs / 延迟 / 采样数 / 规划步数）。CMN(b) = Baseline ⊕ b（把同样预算以基线可用的方式花掉：多采样平均、深度集成、TTA、更长滚动规划）。创新净效应 Δ_net = Δ(innov) − Δ(CMN(b))。若 Δ_net ≤ MDE ⇒ 判定为**算力效应**（compute-decorative），不计入算法创新。**比较必须在同等实时/算力预算下进行；否则一切 +X% 都不可信。**

**定义 315（消融归因矩阵与 Shapley）** 组件指示 x ∈ {0,1}^m，效应向量 y(x)。拟合稀疏交互模型 y(x) = β_0 + Σ_j β_j x_j + Σ_{j<k} β_{jk} x_j x_k（主效应用 LOO 交叉验证选择稀疏度）。对顺序敏感的交互用采样 Shapley φ_j（n_perm 置换）。MDE_j 为逐指标可检测阈值。

**定义 316（承载分类 LBA）** 对每个组件 j：
- **load-bearing**：φ_j > MDE 且移除后主 claim 从 reproduced 跌为 failed；
- **conditional**：仅在触发子集（故障/歧义/OOD/对抗）上 φ_j > MDE，全分布平均 < MDE；
- **decorative**：|φ_j| < MDE 且移除不影响主 claim 的复现状态；
- **harmful**：φ_j < −MDE，或引入安全违规/尾部风险上升。
分类必须同时报告**平均效应**与**尾部效应**（定义 317），不得只报平均。

**定义 317（尾部安全约束）** T(S) = (CVaR_{q=0.9}(risk on worst-decile scenarios), 不变量违规计数, 最差 env 的退化幅度)。蒸馏须满足 T(S*) ≤ T(full)（逐分量不劣化）。**安全守卫组件永不参与 MDL 剪枝**（定义 318-iii）。

**定义 318（最小充分蒸馏 MVS）** 
S* = argmin_{S ⊆ IPs} L(S) = Σ_{j∈S} c_j （c_j 为描述/复杂度代价）
s.t. (i) 每个主指标 effect_retain(S) ≥ (1−δ_d)·effect(full)；
(ii) T(S) ≤ T(full)（尾部不劣化）；
(iii) InvariantGuards ⊆ S（安全/不变量组件不可蒸馏）；
(iv) Δ_net(S) > MDE under CMN。
若可行集为空，返回 full 并标记 **not-distillable**——**这本身是一条重要负结果**（说明"效应高度依赖组件互补，无法用小子集解释"）。

**定义 319（蒸馏证书 J_DISTILL）** J_DISTILL = (S*, L(S*), effect_retain per metric, T(S*), gate_report_hash, CL_version, ablation_hash, seed_ensemble, neg_result_refs)。Valid ⇔ BAP ready ∧ 分类跨种子可复现 ∧ 尾部约束满足 ∧ 负结果被显式引用。

**定义 320（多重比较控制）** 账本累计 N 个 claim，采用分层 Holm–Bonferroni（round → claim）。R66–R69 的全部 headline claim 视为一个 family，控制 family-wise error ≤ α。新 claim 报告校正后 p 值。**研究循环本身就是一个多重检验问题**——轮数越多，"总有某个指标显著"的概率越高。

**定义 321（负结果账本 NRL）** 记录 failed/underdetermined 的 claim、其证伪器、被排除的假设、以及由此对 ERS 的修正（如 MDE 上调、δ_rep 收紧、种子数增加）。后续轮必须在设计里显式引用相关条目，防止重复踩坑与 HARKing。

**定义 322（预注册与盲评 PRB）** 在 B3 之前冻结：指标、δ_rep、MDE、种子、停止规则、分析脚本哈希；评测者对被评系统身份盲化（A/B 编码，评分者不知哪个是 full/MVS/baseline）。防止"看结果再选指标、再调种子"。

**定义 323（跨硬件复现）** 实时性/latency claim 需在至少两类 hardware_fp 上复现；否则该 claim 状态为 underdetermined（既不 failed 也不 reproduced）。**延迟是最容易被单一机器上的一次好运骗过的指标。**

**定义 324（创新净价值 NV）** NV_j = φ_j − λ_c·c_j − λ_t·Δtail_j。蒸馏等价于在约束下最大化保留集合的 Σ NV；λ_c 为复杂度价格，λ_t 为尾部风险价格。当 λ_c=λ_t=0 时退化为"只留有效应者"；λ 越大越保守。**λ 必须在 B3 前预注册，不能事后调。**

**定义 325（研究循环三不变量）**
(i) **无复现不创新**：新 claim 必须建立在 ready 的 BAP 上；
(ii) **无归因不声明**：任何"某组件有效"必须附 LOO/Shapley + CMN；
(iii) **无负结果不前进**：新轮必须引用 NRL 中相关失败条目。
这三条是 R70 对整条 R66–R69 研究链的"安全包络"。

## 2. 关键算法骨架

```python
# IP-264 ERS：复现实验台（冻结、带指纹）
@dataclass(frozen=True)
class Substrate:
    envs: tuple; seeds: tuple; metrics: dict      # metric -> (def, direction, ci)
    budget_ms: float; alpha: float; delta_rep: dict; mde: dict
    hardware_fp: str; code_hash: str
    def fingerprint(self): return sha256(repr(self.__dict__))

# IP-265 BAP：四道门，ready 之前不许测新系统
def anchor_protocol(S, run, claims):
    ok0 = within(run('B0', seed=S.seeds[0]), run('B0', seed=S.seeds[0]), tol=S.tau_bit)
    rep1 = tost(run('published_ref', S), claims['published_ref'], S)   # B1 外部锚
    rep2 = {c.id: tost(run(c.system, S), c, S) for c in claims['rounds']}  # B2 前轮
    ready = ok0 and rep1 == 'reproduced' and all(v != 'failed' for v in rep2.values())
    return GateReport(ok0, rep1, rep2, ready)

# IP-267 TOST：复现是等价声明，不是"没差异"
def tost(estimate, claim, S):
    L, U = bootstrap_ci(estimate, S.alpha, S.metrics[claim.metric])
    lo, hi = claim.delta - S.delta_rep[claim.metric], claim.delta + S.delta_rep[claim.metric]
    if lo <= L and U <= hi: return 'reproduced'
    if U < lo or L > hi:    return 'failed'
    return 'underdetermined'

# IP-268 CMN：把同样的额外算力白送给基线
def compute_matched_null(baseline, b, S):
    return max_over_baseline_budget(baseline, b)   # 多采样/集成/TTA/长规划，同等预算

# IP-269 LBA：LOO + 采样 Shapley + 稀疏交互
def load_bearing(full, ips, S, claims):
    eff_full = evaluate(full, S)
    loo = {ip: delta(evaluate(remove(full, ip), S), eff_full) for ip in ips}
    phi = shapley_sampled(full, ips, S, n_perm=32)
    cls = {}
    for ip in ips:
        if is_guard(ip) or tail_effect(ip, S) > S.mde:   cls[ip] = 'conditional' if avg(phi[ip]) < S.mde else 'load_bearing'
        elif phi[ip] < -S.mde[ip]:                       cls[ip] = 'harmful'
        elif abs(phi[ip]) < S.mde[ip]:                   cls[ip] = 'decorative'
        else:                                            cls[ip] = 'load_bearing'
    return loo, phi, cls

# IP-270 MVS：MDL 最短充分集（贪心 + 尾部门 + 守卫锁）
def distill(full, ips, S, retain=0.90):
    guards = invariant_guards(ips)                      # 定义 318-iii，永不剪
    order  = sorted([ip for ip in ips if ip not in guards],
                    key=lambda ip: nv(ip, S), reverse=True)   # 定义 324，λ 预注册
    S_sel, eff = set(guards), evaluate(compose(guards), S)
    for ip in order:
        cand = S_sel | {ip}
        if retain_ok(evaluate(compose(cand), S), eff_full, retain) \
           and tail_ok(cand, full, S) \
           and net_positive(cand, S):                   # CMN 下净效应 > MDE
            S_sel = cand
    return S_sel if feasible(S_sel) else (set(ips), 'not-distillable')

# IP-274 J_DISTILL + 主元闭环
def REPLICA_round(M, ledger):
    S = M.ers
    gate = anchor_protocol(S, M.run, ledger.claims)
    if not gate.ready:
        return record_unverified(gate)                 # 不创新，只记账
    for c in ledger.new_claims:
        c.status = tost(M.run(c.system, S), c, S)      # 等价检验而非显著性
    loo, phi, cls = load_bearing(M.full, M.ips, S, ledger.claims)
    mvs = distill(M.full, M.ips, S)
    ledger.nrl.add_all(failed_or_underdetermined(ledger))
    return certify(J_DISTILL(mvs, gate, loo, phi, cls, ledger))
```

## 3. 推导

**引理 19（链式比较的误差累积）** 设第 r 轮基线真值 B_r、报告值 B̂_r = B_r + e_r，|e_r| ≤ ε_r。k 轮"相对改进"的累积偏差绝对值 ≤ Σ_{r} ε_r；若各 e_r 同号（每轮都倾向取上一轮最好结果），偏差线性累积而非抵消。系：不插入外部锚点时，"R69 比 R68 好 12%"可能完全是 Σ ε_r 的伪影；B1 把误差重置为单轮 δ_rep。

**引理 20（等价检验的判据强度）** TOST 在标准误 SE、水平 α 下：若真差 d ≥ δ_rep + z_{1−α}·SE 则必然 Failed；若 d ≤ δ_rep − z_{1−α}·SE 则通过。故 Reproduced 是"|真差| ≤ δ_rep"的**置信声明**，而"p>0.05"只意味着"d 未被测出"，两者判据强度不同。系：预注册 δ_rep 与功效分析可把"复现剧场"从判据上排除。

**引理 21（算力匹配的去魅）** 若 Δ(innov) 随额外预算 b 单调增，且 Δ(CMN(b)) ≥ Δ(innov) − o(b)，则 Δ_net ≤ o(b)→0，创新无可测的、超越算力的边际效应。反之 Δ_net > MDE 才可称算法创新。系：**任何未做 CMN 的"X 比 Y 好"都应先默认为算力效应。**

**引理 22（蒸馏的尾部保持）** 若 S* 满足定义 318-(ii)(iii)，则对任一不变量事件 A 与尾部集（最差十分位），Risk_{S*}(A) ≤ Risk_full(A)，且平均效应损失 ≤ δ_d·effect。系：蒸馏可以删"平均有用但尾部无用"的组件，但**绝不能删"尾部有用"的守卫**——这是 MVS 与朴素剪枝的分界线。

**定理 18（复现先行降低错误创新率，且风险单调）** 在账本 family-wise α 控制下，采用 BAP + CMN + LOO 的判定，相对"直接比较未复现基线 + 未校正多重检验"，声称假创新的概率严格不增；当存在基线偏差（引理 19）或算力混淆（引理 21）时严格降低。⇒ 复现先行不是效率的敌人：它把预算从"测量噪声"转移到"真效应"，是**风险单调**的。

**定理 19（MVS 的存在性与近似边界）** 若 effect 对组件集单调、L 严格正，则可行集非空当且仅当 full 可行；在单调 + 子模近似下，按 NV 贪心得到 (1−1/e) 近似的最短充分集；效应完全可加时 LOO 精确恢复 S*；组件强互补/拮抗（非单调）时 MVS 一般 NP-hard，须报告"无法保证最优"（状态 underdetermined，而非伪称 distilled）。

**推论 18.1（装饰组件的可移除判据）** 若 |φ_j| < δ_d·effect(full)/m 且 j 非守卫，则移除 j 不破坏保留约束。即**保留预算 δ_d 应按组件数均摊**，而非被单个大组件独占。

**推论 18.2（负结果的信息量）** 每个 failed claim 至少排除了一个假设方向，使后续轮的有效搜索空间按比例缩小；NRL 的价值 ≈ 避免的重复实验成本。**不记录负结果 = 把已排除的假设重新买一遍。**

## 6. 本轮最大风险

**一句话**：这套方法论最大的风险不是"复现不出来"，而是**把复现本身当成研究目标**——于是循环退化为"复现已知的跑步机"；更危险的是用**平均效应**做蒸馏信号，会系统性切除那些"平均没用、只在罕见尾部救命"的守卫（而基线复现恰好不覆盖尾部），最后得到一个**可复现、无真正创新、且尾部更脆**的最小系统——我们为了证明"改进为真"，反而造出了一个"更不会出错、但也更不会进步、并在最需要时失效"的系统。

**次级风险与缓解**：
1. **复现剧场**（小样本、挑种子、事后选指标）→ 预注册 + 盲评 + 功效分析 + E315 红队；
2. **算力混淆未去魅** → CMN 强制对照 + Δ_net 判据（定义 314）；
3. **多重检验膨胀** → 分层 Holm–Bonferroni（定义 320）；
4. **蒸馏削掉尾部安全** → 守卫锁 + 尾部约束 T(S)（定义 317/318）；
5. **MVS 非单调不可解** → 报告 not-distillable，不伪称最优（定理 19）。

## 3. 关键算法伪代码

```python
# IP-264 ERS：冻结、带指纹的复现实验台
@dataclass(frozen=True)
class Substrate:
    envs: tuple; seeds: tuple; metrics: dict
    budget_ms: float; alpha: float; delta_rep: dict; mde: dict
    hardware_fp: str; code_hash: str
    def fingerprint(self): return sha256(repr(self.__dict__))

# IP-265 BAP：四道门；ready 前不许测量新系统
def anchor_protocol(S, run, claims):
    ok0  = within(run('B0', S.seeds[0]), run('B0', S.seeds[0]), S.tau_bit)
    rep1 = tost(run('published_ref', S), claims['published_ref'], S)     # B1
    rep2 = {c.id: tost(run(c.system, S), c, S) for c in claims['rounds']}  # B2
    ready = ok0 and rep1 == 'reproduced' and all(v != 'failed' for v in rep2.values())
    return GateReport(ok0, rep1, rep2, ready)

# IP-267 TOST：复现是等价声明
def tost(est, c, S):
    L, U = bootstrap_ci(est, S.alpha, S.metrics[c.metric])
    lo, hi = c.delta - S.delta_rep[c.metric], c.delta + S.delta_rep[c.metric]
    if lo <= L and U <= hi: return 'reproduced'
    if U < lo or L > hi:    return 'failed'
    return 'underdetermined'

# IP-269 LBA：LOO + 采样 Shapley + 尾部感知分类
def load_bearing(full, ips, S):
    eff = evaluate(full, S)
    loo = {ip: delta(evaluate(remove(full, ip), S), eff) for ip in ips}
    phi = shapley_sampled(full, ips, S, n_perm=32)
    def classify(ip):
        if is_guard(ip) or tail_effect(ip, S) > S.mde:           # 尾部有用 → 不可删
            return 'load_bearing' if avg(phi[ip]) > S.mde[ip] else 'conditional'
        if phi[ip] < -S.mde[ip]:                                 return 'harmful'
        if abs(phi[ip]) < S.mde[ip]:                             return 'decorative'
        return 'load_bearing'
    return loo, phi, {ip: classify(ip) for ip in ips}

# IP-270 MVS：MDL 最短充分集（守卫锁 + 尾部门 + CMN）
def distill(full, ips, S, retain=0.90):
    guards = invariant_guards(ips)                     # 定义 318-iii，永不剪
    sel = set(guards)
    for ip in sorted([i for i in ips if i not in guards],
                     key=lambda i: nv(i, S), reverse=True):   # λ 预注册
        cand = sel | {ip}
        if retain_ok(evaluate(compose(cand), S), evaluate(full, S), retain) \
           and tail_ok(cand, full, S) and net_positive(cand, S):
            sel = cand
    return sel if feasible(sel) else (set(ips), 'not-distillable')

# IP-274/275 元闭环：锚定 → 复现 → 消融 → 蒸馏 → 认证
def REPLICA_round(M, ledger):
    S = M.ers
    gate = anchor_protocol(S, M.run, ledger.claims)
    if not gate.ready: return record_unverified(gate)          # 不创新，只记账
    for c in ledger.new_claims:
        c.status = tost(M.run(c.system, S), c, S)
    loo, phi, cls = load_bearing(M.full, M.ips, S)
    mvs = distill(M.full, M.ips, S)
    ledger.nrl.add_all(failed_or_underdetermined(ledger))
    return certify(J_DISTILL(mvs, gate, loo, phi, cls, ledger))
```

## 4. 推导

**引理 19（链式比较误差累积）** 各轮报告偏差 `e_r`、`|e_r|≤ε_r` 时，k 轮相对改进的累积偏差 ≤ `Σε_r`；同号则线性累积不抵消。系：缺外部锚时，跨轮增量可能是纯偏差；B1 把误差重置为单轮 `δ_rep`。

**引理 20（等价检验强度）** TOST 下真差 `d ≥ δ_rep + z·SE` 必 failed，`d ≤ δ_rep − z·SE` 必通过。故 reproduced 是"|真差|≤δ_rep"的置信声明；"p>0.05"只是"未测出"。

**引理 21（算力匹配去魅）** 若 `Δ(CMN(b)) ≥ Δ(innov) − o(b)`，则 `Δ_net ≤ o(b)→0`，无超越算力的边际效应；`Δ_net > MDE` 才可称算法创新。

**引理 22（蒸馏尾部保持）** S* 满足尾部约束与守卫锁时，`Risk_{S*}(A) ≤ Risk_full(A)`（不变量/尾部事件），平均效应损失 ≤ `δ_d·effect`。系：可删"平均有用尾部无用"，绝不可删"尾部有用"的守卫。

**定理 18（复现先行风险单调）** 在 FWER≤α 下，BAP+CMN+LOO 判定相对"未复现基线 + 未校正检验"不增加、并在基线偏差/算力混淆存在时严格降低假创新率。⇒ 复现不是效率敌人，而是把预算从噪声转到真效应。

**定理 19（MVS 存在性与近似）** 单调 + L>0 时可行集非空 ⇔ full 可行；单调 + 子模近似下按 NV 贪心为 `(1−1/e)` 近似；效应完全可加时 LOO 精确恢复 S*；强互补/拮抗时一般 NP-hard，须报告 not-distillable。

**推论 18.1** `|φ_j| < δ_d·effect(full)/m` 且 j 非守卫 ⇒ 可移除不破坏保留约束（保留预算按组件数均摊）。**推论 18.2** 每个 failed claim 排除一个假设方向，NRL 价值 ≈ 避免的重复实验成本。

## 9. 本轮最大风险

**一句话**：最大的风险不是"复现不出来"，而是**把复现本身当成研究目标**，让循环退化为复现已知的跑步机；更危险的是用**平均效应**做蒸馏信号，会系统性切除"平均没用、只在罕见尾部救命"的守卫（而基线复现恰好不覆盖尾部），最终得到一个**可复现、无真正创新、且尾部更脆**的最小系统——为了证明改进为真，反而造出一个更不会出错、也更不会进步、并在最需要时失效的系统。

**次级风险与缓解**：复现剧场（预注册+盲评+功效分析+E315 红队）；算力混淆（CMN + Δ_net，定义 314）；多重检验膨胀（分层 Holm–Bonferroni，定义 320）；蒸馏削尾部（守卫锁 + T(S)，定义 317/318）；MVS 非单调不可解（报告 not-distillable，定理 19）。
