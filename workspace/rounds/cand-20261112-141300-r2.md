# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化证据承诺」IP-133~138；灵感循环第 2 轮；本轮灵感：「专利布局」×「演示方案」）

> 第 57 轮把安全的赌注从"模型置信"移到"证据承诺"，又用元推断/跨模态/个性化三条腿把证据做厚；但它的最大风险自陈暴露了一个更深的裂缝：整套机制都在回答"**证据够不够**"，却没人回答"**我们到底在向谁主张什么、主张的边界在哪、演示给谁看时能主张到哪一步**"。第 57 轮的 EV-xmodal、个性化加速、元先验共享，本质上都在**扩大主张**；扩大的主张若没有**范围-证据对照**，就会退化成"自授专利"。本轮两个灵感各补一半：**专利布局**教我们把安全从"一条证明"变成"**一组有边界、有无效条件、有专利族、有自由实施分析的主张组合**"——主张范围不得超过证据范围，未覆盖处必须显式标为"未主张区"；**演示方案**教我们把"演示"从"证明系统安全"降格为"**向特定受众、在声明分布下、转移特定主张的证据协议**"——演示只能把受众信念移动到证据允许的位置，且必须预注册证伪脚本、排练与回退。核心命题由"证据说可信"升级为 **"可主张、可审计、可迁移的安全"（claimable, auditable, transferable safety）**：无主张不承诺，主张不越证据，演示不越主张。

核心矛盾：
- **H29（覆盖 vs 证据）**：主张范围 ≤ 证据范围 ⇒ 覆盖是证据的函数，不是想象的函数；缩主张产生未主张区 U（安全停），补证据有成本——安全与可用在"主张边界"上直接对冲。
- **H30（演示 vs 泛化）**：演示是从声明分布 D_demo 的采样，受众会外推到 D_dep；"为说服而设计"会系统性放大支持错配（Goodhart），"成功演示"可能只是"成功采样"。
- **H31（自证 vs 审计）**：主张图与演示脚本由同一团队构建/导演，存在"自授专利"——组合覆盖的是团队相信的失败空间，而非真实失败空间；必须有防御性披露（已知失败家族）与外部/对抗审计。

## 0. 直觉与动机

**灵感 1（专利布局 → 安全主张组合 SCP）**
直觉：单条"系统安全"证明像单件专利，容易被一个反例绕开；真正的专利布局是一圈"权利要求"——核心权利要求保护主发明，外围权利要求封住显而易见的变体与规避路线，防御性公开把已知现有技术钉死，延续案把未来方向先占住。安全同理：不要把安全写成一句"失败率 ≤ δ"，而要写成一组 **C_i=(行为谓词 φ_i, 范围 scope_i, 上界 δ_i, 证据 ev_i, 无效条件 inv_i, 专利族 fam_i, 举证等级 β_i)**。三条硬约束让它不是法律修辞：**(K1) 范围-证据包含** scope_i ⊆ evidence_scope(ev_i)（主张不得大于证据，越界即"无效权利要求"）；**(K2) 无效条件显式** inv_i（像药品说明书的禁忌症：主张在何处自动失效）；**(K3) 族标记** fam_i（共享证据源/共享假设的主张不算独立佐证——这正治第 57 轮"同一模态问五遍"的病）。于是安全从"真/假"变成"**在多大范围内、以多高举证等级、可被谁挑战**"。

**灵感 2（演示方案 → 演示-部署迁移协议 DP）**
直觉：演示不是证明，是**受控的叙事**：选场景、选观众、写脚本、埋高潮、备回退。它的危险不在"演砸"，而在"演成"——观众会把一次受控采样外推成部署分布上的普遍能力。所以把演示形式化为 D=(A, D_demo, W, Φ, F, τ_A)：受众 A 有先验与决策阈值；D_demo 是**声明的场景采样分布**；W 是**最小见证集**（只演能支撑目标主张的最少证据，不演"炫技"）；Φ 是**预注册证伪脚本**（什么现象出现就必须中止/降级，演示前登记、不可事后改）；F 是回退；τ_A 是**受众校准目标**。关键量是**迁移间隙** G(D)=dist(D_demo,D_dep)：部署失败率 ≤ 演示失败率 + G + 集中项。演示的伦理约束是**主张天花板**：演示后受众信念不得超过证据支持的 warranted posterior；必须显式展示未主张区 U 与无效条件 inv（"禁忌症标签"），而不是只展示高光。

**灵感 3（合流 → 无主张不承诺 + 演示是有限主张）**
直觉：把第 57 轮证据门升级为**主张门**：一次接触在状态 x 处被允许，当且仅当 x 落在某条**有效主张**的有效覆盖内（x∈scope_i \ inv_i）且该主张的举证等级 β_i ≥ 接触风险要求的 β_req(level(x))；x∈U ⇒ 安全停。这就是"**无主张不承诺**"——与第 57 轮"无证据不承诺"同构，但把"证据"提升为"有边界的主张"。演示则被登记为一条**受限主张**（fam="demo"），只覆盖其采样支持集，且因与实跑共享假设，**不得**与实跑证据叠加为独立佐证。

**灵感 4（主张-证据对照表 → 最小见证集与演示经济学）**
直觉：专利律师用 claim chart 把每条权利要求逐元素映射到说明书/附图；安全用 **CEC** 把 scope 的每个元素映射到证据。演示只需求解一个**集合覆盖**：选最小 W⊆Π 使受众决策所需的全部主张被见证（minimal witness set），既省演示成本，又避免"演多了"带来的过度主张。对抗"组合死锁"（外围主张相互冲突导致处处 invalidity）：用**特异性优先 + 保守优先 + 举证等级优先 + 新近优先**的裁决序，保证冲突可判定、不会把整片区域锁死。

**灵感 5（排练 → 演示也走隔离）**
直觉：第 57 轮已把"一切判定器走隔离"；本轮把**演示本身**也送进隔离区：先在数字孪生/历史日志上做 **shadow rehearsal**，测 Φ 触发率、F 延迟、W 见证率与受众理解度，产出演示证书 J_d；排练不过不得上真机。演示因此不是一次性表演，而是**可回归测试的工程件**。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（安全主张组合 SCP）** 主张 C_i=(φ_i,scope_i,δ_i,ev_i,inv_i,fam_i,β_i)：φ_i 为行为谓词（如"在 r 类区域、条件 c 下承诺失效率 ≤ δ_i"），scope_i⊆𝕏=(区域×条件×操作者状态)，ev_i 为证据项集合，inv_i:𝕏→{0,1} 为无效谓词，fam_i 为专利族（共享证据源/共享假设），β_i∈{B0,B1,B2} 为举证等级（B0 仅仿真/回放，B1 有非不可逆实跑，B2 有不可逆实跑+事后证实）。组合 Π={C_i}，部署包络 𝕏_dep。**有效覆盖** V(Π)=∪_i(scope_i\inv_i)；**未主张区** U=𝕏_dep\V(Π)。三硬约束：(K1) scope_i⊆evidence_scope(ev_i)；(K2) inv_i 显式且不可空；(K3) 同族不提供独立佐证。健康度：Cover=|V|/|𝕏_dep|、Gap=|U|/|𝕏_dep|、独立度 Ind(x)=|{fam_i: x∈V_i}|。

**定义 140（主张-证据对照表 CEC）** 对每 C_i 给出映射 χ_i:scope_i→2^{ev_i}，要求 ∀x∈scope_i：χ_i(x)≠∅ 且每项 e∈χ_i(x) 在 x 处有效（支持集含 x、未过期、未被证伪回溯降权）。三性质：**完备**（∀x 被见证）、**可靠**（见证项有效）、**最小**（无冗余见证，供演示经济）。**过度主张** Over(Π)={x: x∈scope_i 但 χ_i(x)=∅ 或见证失效}；安全契约要求 Over(Π)=∅。举证门槛 β_req: L0/L1/L2→B0/B1/B2。

**定义 141（主张裁决与自由实施 FTO）** 冲突：x∈scope_i∩scope_j 且两主张对 x 判定不一致（一判安全、一判无效）。裁决序 ≺：先**特异性**（|scope| 小者优先），再**保守性**（判 inv 者优先），再**举证等级**（β 高者优先），再**新近性**（版本新者优先）。仍不可判 ⇒ x 记**死锁区** D_lock，强制安全停并升级审计。FTO(Π) ⇔ D_lock=∅；**死锁率** LockRate=|D_lock|/|𝕏_dep|。

**定义 142（演示-部署迁移协议 DP）** D=(A,D_demo,W,Φ,F,τ_A,G)。A=(p_A,θ_A) 受众先验与决策阈值；D_demo 为声明采样分布（含支持集与对 𝕏_dep 的 ε-覆盖声明）；W⊆Π 为最小见证集（min|W| s.t. 覆盖受众决策所需主张，集合覆盖）；Φ 为**预注册**证伪谓词；F 为回退（安全停/降级）；τ_A 为受众校准目标。**迁移界**：若 supp(D_demo) 对 𝕏_dep 构成 (ε,α)-覆盖，则 P_fail^{dep} ≤ P_fail^{demo}+G(D)+η(α,n_demo)，G(D)=W_1(D_demo,D_dep)。**主张天花板**：W 中主张须 β_i≥β_req 且 scope_i 被 D_demo 覆盖；演示必须显示 U∩𝕏_dep 与 {inv_i}（禁忌症标签）。

**定义 143（演示排练与证书 RD/J_d）** 排练在数字孪生/历史日志以 shadow 模式执行 D 脚本，产出 J_d=(Φ 触发率, F 延迟分布, W 见证率, 受众理解度, 覆盖声明核验, 版本)。**排练准入**：Φ 触发率≤p_Φ ∧ F 延迟≤τ_F ∧ W 见证率=1 ∧ 受众对 U/inv 复述正确率≥ρ_under；不过则不得上真机。真机后演示结果登记为受限主张 C_demo(fam="demo")，仅覆盖 supp(D_demo)，不得与实跑证据跨族叠加。

**定义 144（主张门 CBG 与演示-部署迁移算子 DDT）** 主张门：commit(x) 允许 ⇔ ∃i: x∈(scope_i\inv_i) ∧ β_i≥β_req(level(x)) ∧ χ_i(x) 完备可靠；x∈U 或 D_lock ⇒ 安全停。DDT 算子：①构建/更新 Π（含防御性披露已知失败族与 prior art）；②CEC 自检（Over=∅）；③FTO 裁决（LockRate=0）；④为 A 求最小见证集 W；⑤shadow 排练得 J_d，过准入；⑥真机演示：预注册 Φ，触发即 F，登记 C_demo；⑦用 G 与受众校准回填组合（fam 去重）；⑧未主张区 U 的补证据计划进入下一轮探询预算。

## 2. 关键算法伪代码（完整版见产物区）

```python
def build_portfolio(M, logs, prior_art, known_fail_families):   # IP-139/140
    Pi = []
    for c in candidate_claims(M, logs):
        c.scope = c.scope & evidence_scope(c.ev)          # K1: 主张缩到证据范围
        c.inv   = infer_invalidity(c, known_fail_families) # K2: 显式无效条件
        c.fam   = family_of(c.ev, c.assumptions)           # K3: 族标记
        Pi.append(c if cec_complete(c) else shrink_to_witnessed(c))
    return Pi, unclaimed(Pi, X_dep), disclose(prior_art, known_fail_families)

def claim_gate(x, Pi, level):                              # IP-141/144
    cand = [c for c in Pi if x in c.scope and not c.inv(x)]
    if not cand: return ('stop', 'UNCLAIMED')              # 无主张不承诺
    c = adjudicate(cand)                                   # 特异性→保守→举证→新近
    if c is None: return ('stop', 'DEADLOCK')
    if c.beta < beta_req(level): return ('reject', 'burden')
    if not cec_complete(c): return ('reject', 'overclaim')
    return ('ok', c)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| SCP 构建 | O(\|C\|·\|𝕏\|) | O(\|C\|·\|scope\|) | 范围-证据包含（A41）、族去重 |
| CEC | O(\|scope\|·\|ev\|) | O(\|scope\|) | 完备/可靠/最小 |
| FTO 裁决 | O(\|C\| log\|C\|)/查询 | O(\|C\|) | 裁决序全序、死锁即停（A42） |
| DP | O(\|C\|·2^{\|need\|}) 集合覆盖（贪心 1+ln） | O(\|C\|) | 最小见证、迁移界上界（A43） |
| RD | O(\|W\|·n_demo) | O(\|J_d\|) | 排练准入、Φ 预注册（A44） |
| CBG/DDT | O(\|CP\|·(\|C\|log\|C\|+\|W\|n_demo)) | O(\|Π\|+\|J_c\|) | 无主张不承诺、审计可复算 |

**正确性定理（Claimable Transferable Safety, CTS 概要）**：在 A37–A40 上加 (A41) 范围-证据包含且 CEC 完备可靠（Over=∅）；(A42) FTO 裁决序确定、死锁即安全停；(A43) 演示迁移界成立（D_demo 覆盖声明诚实、G 取区间上界）；(A44) 排练准入与主张天花板（演示不呈现超 β/超覆盖主张，U/inv 显式）。则：(i) 任何被允许承诺落在某条有效且证据完备的主张内，P(fail)≤δ_i+ε_meta+δ_probe+ε_h，且无越界承诺；(ii) 演示后受众信念 ≤ warranted posterior + τ_A；(iii) LockRate 与 Gap 只降低可用覆盖、不产生升险路径；(iv) 主张组合、CEC、FTO、脚本、Φ、J_d、C_demo 全入 J_c，可被外部复算。

## 6. 本轮最大风险

**一句话**：本轮把"证据承诺"升级为"可主张的安全"，风险从"坏先验普遍"变成"**主张自证**"——专利组合的覆盖图与演示脚本由同一支团队绘制和导演，"无主张不承诺"会把所有新情境推入安全停（安全但无用），而演示的受众校准又会让人把"组合看起来完整"误当成"证据确实覆盖"；一旦未主张区 U 被漏标（把没证据的地方当成已覆盖），系统就会在"合法主张"的外衣下做出与第 57 轮同样的错误承诺，且因为一切看起来都有 claim chart 背书而更难被审计发现。

# 第 58 轮产物 · 创新点清单 v34：Claimable-Transferable-Safety（安全主张组合×主张-证据对照×自由实施×演示-部署迁移，SCP×CEC×FTO×DP×RD×CBG）

> 承接第 57 轮 IP-133~138（MFSL/XMC/PTM/MXI/FSE/PCE+）与第 56 轮 IP-127~132（SMM/PCE/BVK/ISE/TAF/MEC）。本轮把部署前提从"证据承诺"升级为 **"可主张、可审计、可迁移的安全"**：安全不再是一条证明，而是一组**有范围、有无效条件、有专利族、有自由实施分析的主张**；演示不再是"证明系统安全"，而是**向特定受众、在声明分布下、转移特定主张的证据协议**。第 57 轮"一切判定器走隔离"在本轮推广为"**主张与演示也走隔离**"：主张必须过 CEC 自检与 FTO 裁决，演示必须先过 shadow 排练。

### IP-139 SCP（安全主张组合构建）

```python
def build_portfolio(M, logs, prior_art, known_fail_families):
    Pi = []
    for c in candidate_claims(M, logs):
        c.scope = c.scope & evidence_scope(c.ev)            # K1: 主张 ≤ 证据
        c.inv   = infer_invalidity(c, known_fail_families)   # K2: 显式无效条件
        c.fam   = family_of(c.ev, c.assumptions)             # K3: 共享源=同族
        if cec_complete(c):
            Pi.append(c)
        else:                                                # 不可见证部分缩主张
            c2 = shrink_to_witnessed(c)
            Pi.append(c2)
    U = X_dep - union_valid_scope(Pi)                        # 未主张区
    disclosures = disclose(prior_art, known_fail_families)   # 防御性公开
    return Pi, U, disclosures

def family_of(ev, assumptions):
    return hash(tuple(sorted(e.source_id for e in ev))
                + tuple(sorted(assumptions)))                # 同源/同假设 → 同族
```

### IP-140 CEC（主张-证据对照表）

```python
def cec_chart(c, x):
    return [e for e in c.ev if x in e.support and valid(e, x)]

def cec_complete(c):
    return all(cec_chart(c, x) for x in c.scope)             # 每个 scope 元素被见证

def cec_audit(Pi):
    over = {x for c in Pi for x in c.scope if not cec_chart(c, x)}
    return over                                              # 要求 Over = ∅

def shrink_to_witnessed(c):
    c.scope = {x for x in c.scope if cec_chart(c, x)}        # 只保留可见证范围
    return c
```

### IP-141 FTO（主张裁决与自由实施）

```python
def adjudicate(cands, x):
    verdicts = {c.verdict(x) for c in cands}
    if len(verdicts) == 1:
        return min(cands, key=lambda c: len(c.scope))        # 唯一判定：取最特异
    order = sorted(cands, key=lambda c: (len(c.scope),       # 特异性
                                         not c.inv(x),       # 保守优先
                                         -c.beta,            # 举证高优先
                                         -c.version))        # 新近优先
    if len({c.verdict(x) for c in order[:1]}) and \
       any(c.verdict(x) != order[0].verdict(x) for c in order):
        return None                                          # 仍冲突 → 死锁
    return order[0]

def fto(Pi, X_dep):
    D_lock = {x for x in X_dep
              if adjudicate([c for c in Pi if x in c.scope and not c.inv(x)], x) is None}
    return (len(D_lock) == 0), D_lock
```

### IP-142 DP（演示-部署迁移协议）

```python
def select_witness_set(Pi, A, D_demo):
    need = claims_required(A.theta, A.task)                  # 受众决策所需主张
    feas = lambda c: covered(c.scope, D_demo)                # 必须被 D_demo 覆盖
    return greedy_set_cover(need, weight=demo_cost, feasible=feas)

def demo_protocol(Pi, A, D_demo, D_dep, F):
    W  = select_witness_set(Pi, A, D_demo)
    G  = wasserstein_upper(D_demo, D_dep)                    # 区间上界，非点估计
    Phi = preregister_abort(W, A, G)                         # 演示前登记，不可改
    Jd = shadow_rehearsal(W, Phi, D_demo)                    # IP-143: 隔离区排练
    if not rehearsal_admit(Jd): return ('abort', Jd)
    for step in W:
        obs = run_demo_step(step, D_demo)
        if Phi(obs): return ('fallback', F(obs), Jd)         # 触发即回退
    p_star = demo_fail(W) + G + eta(alpha=1-A.conf, n=len(W))
    assert A.belief_after() <= p_star + A.tau                # 主张天花板
    C_demo = make_claim(scope=supp(D_demo), fam='demo', beta=B1)
    return ('ok', Jd, p_star, show(U, invs(Pi)), C_demo)
```

### IP-143 RD（演示排练与证书 J_d）

```python
def shadow_rehearsal(W, Phi, D_demo):
    trig, lat, witnessed = 0, [], 0
    for trial in D_demo.trials:                              # 数字孪生/历史日志
        for step in W:
            obs = replay(step, trial)
            witnessed += int(step_observed(obs))
            if Phi(obs): trig += 1; lat.append(fallback_latency(obs)); break
    return Jd(phi_rate=trig/len(D_demo.trials), f_lat=quantile(lat, 0.95),
              witness_rate=witnessed/(len(W)*len(D_demo.trials)),
              comprehension=audience_quiz(W), coverage_ok=check_cover(D_demo),
              version=now())

def rehearsal_admit(Jd):
    return (Jd.phi_rate <= p_phi and Jd.f_lat <= tau_F
            and Jd.witness_rate == 1.0 and Jd.comprehension.under_recall >= rho_under)
```

### IP-144 CBG（主张门）与 DDT（演示-部署迁移算子）

```python
def claim_gate(x, Pi, level):
    cand = [c for c in Pi if x in c.scope and not c.inv(x)]
    if not cand: return ('stop', 'UNCLAIMED')                # 无主张不承诺
    c = adjudicate(cand, x)
    if c is None: return ('stop', 'DEADLOCK')
    if c.beta < beta_req(level): return ('reject', 'burden_of_proof')
    if not cec_complete(c): return ('reject', 'overclaim')
    return ('ok', c)

def ddt_operator(M, X_dep, A, D_demo, D_dep, prior_art, known_fail_families):
    Pi, U, disc = build_portfolio(M, M.logs, prior_art, known_fail_families)
    assert cec_audit(Pi) == set()                            # Over = ∅
    ok, D_lock = fto(Pi, X_dep)
    if not ok: return ('audit_escalate', D_lock)             # 死锁即停
    st, Jd, p_star, shown, C_demo = demo_protocol(Pi, A, D_demo, D_dep, F=safe_stop)
    if st != 'ok': return (st, Jd)
    Pi = absorb(Pi, C_demo, dedup_family=True)               # fam 去重，不叠加
    plan = probe_plan(U, budget=next_round_voi(U))           # 未主张区补证据
    return ('ok', Jc(Pi, U, D_lock, Jd, C_demo, disc, shown, plan))
```

### IP-138→PCE++（探-诺-演++：主张感知的探询与演示预算）

```python
def probe_commit_evolve_plus_plus(x0, M, task, budget, consent, personas, Pi, U):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        st, claim = claim_gate(cp.state, Pi, contact_level(cp))
        if st == 'stop':                                     # 未主张/死锁 → 不赌
            alt = reroute(M, cp, risk_model)
            if alt: route = alt; continue
            return negotiate_or_stop(cp, M, consent)
        sigma = foothold_schedule(x0, cp, M); R = schedule_risk(sigma, M)
        while select_gait(R) == 'halt' and budget.probes_left > 0:
            p = argmax(admissible_probes(cp, M, F_abs),
                       key=lambda q: voi_claim_aware(q, M, claim, U) - cost(q))
            if voi_claim_aware(p, M, claim, U) < theta_voi: break
            M = observe(M, execute_probe(p, cap=F_abs)); budget.spend(p)
            sigma = reselect_footholds(x0, cp, M); R = schedule_risk(sigma, M)
        if select_gait(R) != 'halt' and claim_gate(cp.state, Pi, contact_level(cp))[0] == 'ok':
            sched.append(commit(sigma, select_gait(R))); log.append(claim); continue
        alt = reroute(M, cp, risk_model)
        if alt: route = alt; continue
        return negotiate_or_stop(cp, M, consent, tau_int=tau_int(personas.active.auth))
    return sched, log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SCP | O(\|C\|·\|𝕏\|) 构建；O(1) 查询 | O(\|C\|·\|scope\|) | 范围-证据包含、族去重（A41） |
| CEC | O(\|scope\|·\|ev\|) | O(\|scope\|) | 完备/可靠/最小、Over=∅ |
| FTO | O(\|C\| log\|C\|)/查询 | O(\|C\|) | 裁决序全序、死锁即停（A42） |
| DP | O(\|C\|·\|need\|) 贪心（1+ln 近似） | O(\|C\|) | 最小见证、迁移界上界（A43） |
| RD | O(\|W\|·n_demo) | O(\|J_d\|) | 排练准入、Φ 预注册（A44） |
| CBG/DDT | O(\|CP\|·(\|C\|log\|C\|+\|W\|n_demo)) | O(\|Π\|+\|J_c\|) | 无主张不承诺、全链可复算 |

**正确性定理（Claimable Transferable Safety, CTS）**
假设 A37–A40（第 57 轮）成立；**(A41)** 范围-证据包含且 CEC 完备可靠：∀i, scope_i⊆evidence_scope(ev_i)，Over(Π)=∅；**(A42)** FTO 裁决序确定，任何未决冲突进入 D_lock 并强制安全停；**(A43)** 演示迁移界成立：supp(D_demo) 对 𝕏_dep 的覆盖声明诚实，G(D) 取区间上界且 P_fail^{dep}≤P_fail^{demo}+G+η；**(A44)** 排练准入与主张天花板：J_d 过阈值才上真机，演示只呈现 β_i≥β_req 且被 D_demo 覆盖的主张，U 与 inv 显式展示，C_demo 仅覆盖 supp(D_demo) 且 fam 去重。则：

1. **主张健全性**：任何被允许的承诺 x 落在某条有效主张内且 χ_i(x) 完备可靠，故 P(fail)≤δ_i+ε_meta(k)+δ_probe+ε_h(w_max)；不存在未主张/过度主张导致的越界承诺（x∈U ⇒ 停，Over=∅）。
2. **演示不过度主张**：演示后受众信念 p_A'≤p*+τ_A，其中 p*=demo_fail+G+η；若 G 被低估则系统性过度主张，故 G 必须取上界。
3. **可用性-安全性分离**：LockRate 与 Gap 只降低可用覆盖（更多安全停/绕行），不产生升险路径；提升覆盖只有"补证据"或"缩主张"两条单调不升险的路。
4. **审计可追溯**：主张组合、CEC、FTO 裁决、演示脚本、Φ 预注册、J_d、C_demo 全入 J_c，外部可复算"范围 vs 证据"。

**部署界**（对检查点与主张取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])
             − P(Over>0) − P(G 低估) − P(Φ 未触发 ∧ 真失败) − P(𝓜 陈旧未检出)
```

关键：**主张范围 ≤ 证据范围**（不能自授专利）；**演示只转移主张、不制造主张**（不能演成证明）；**未主张即安全停**（不能拿想象补覆盖）；**同族不叠加**（demo 与实跑共享假设，不能当独立佐证）。

## 6. 本轮最大风险

**一句话**：本轮把"证据承诺"升级为"可主张的安全"，风险从"坏先验普遍"变为"**主张自证**"——主张组合的覆盖图与演示脚本由同一支团队绘制和导演，"无主张不承诺"会把所有新情境推入安全停（安全但无用），而演示的受众校准又会让人把"组合看起来完整"误当成"证据确实覆盖"；一旦未主张区 U 被漏标（把没证据的地方当成已覆盖），系统就会在"合法主张"的外衣下做出与第 57 轮同样的错误承诺，且因为一切看起来都有 claim chart 背书而更难被审计发现。
