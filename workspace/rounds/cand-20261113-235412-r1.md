# 第 70 轮（承接第 69 轮「FLUID-RAS：流匹配多模态策略 × 主动交互消歧」IP-253~263；本轮灵感：「意图理解」×「技术路线图」）

> R69 把不确定性一分为二，并给了系统一张嘴：不确定就去问。但它问的是「选哪个动作模态」，而模态只是**症状**，不是**病因**。同一个意图可以被拆成三个动作模态（过分割），一个动作模态也可以对应三个意图（欠定）；更糟的是，流模型还会生成没有意图支撑的「幻影模态」。当系统按模态熵去追问，它可能在为**一个不存在的病因**做检查——R69 自陈的「问错，比不问更危险」没有被解决，只是被推迟了。
>
> 本轮两个灵感正好对准这个病因：
> - **意图理解**把「模态」降级为意图的观测：`I → R → M → ξ` 的分层生成模型，让模态被意图**解释掉**，让一次意图级提问压平多个模态，让「没有意图支撑的模态」在问出口之前就被拒绝；
> - **技术路线图**提供两条时间尺度上的「结构」：**任务路线图**（milestone DAG）把 R69 的固定视界 H 换成「当前里程碑 + 偏序计划」，使 VoI 从 myopic 的模态熵变成 plan-level 的 cost-to-go；**能力路线图**（CML 0–4 + 门控注册表）把「系统当前被允许做什么」变成可认证、可审计、可降级的一等对象——这是对 R69「模态不可信却仍驱动交互」的正面回应。
>
> 核心命题：**把 epistemic 从「动作模态的熵」上移到「意图 × 路线图的后验」；只解决行为等价类之间的歧义；用能力门控保证「不可信的能力不能进入控制」。** 命名 **COMPASS-RAS**（Capability-gated, Ontology-grounded, Milestone-Plan-Aware, Self-certifying Strategy for Risk-Adaptive Systems），其意图本体称 **ATLAS**（Annotated Task & Language Attribution Schema）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**对方到底想要什么，而我现在有资格做到哪一步**」——意图是罗盘，路线图是地图，证书是通行证。

## 0. 直觉与动机

**灵感 1（意图是因，模态是果）**
直觉：R69 直接对动作轨迹做聚类，得到「模态」。但聚类是**无监督的症状分组**：一个「想让我先走」的意图，可能生成长视界里的左让、右让、后退三个动作模态（过分割）；而「停在原地观察」与「等待许可」这两个不同意图，可能生成几乎相同的动作（欠定）。于是 R69 的 `U_epi = H_mode·g(Δ_min)` 既可能虚高（为同一病因多问几次），也可能虚低（动作看起来一致，意图却不同，之后突然分歧）。正确做法是引入**共同的因**：意图 `I` 条件生成路线图 `R`，`R` 条件生成模态 `M`，`M` 条件生成轨迹 `ξ`。一旦观测到意图证据，多个模态被**解释掉（explaining away）**；反过来，没有意图支撑的模态就是幻影，应被拒绝而不是被追问。
更进一步，意图理解**不是读心**：只关心会改变动作分布的那部分意图。把意图按「在 H 步内诱导的策略分布之差 ≤ ε_beh」做商空间，得到行为等价类 `𝒬_I`。我们只消解 `𝒬_I` 上的歧义，不窥探与决策无关的私人心理状态——这既降低社交成本，也降低伦理与隐私风险。

**灵感 2（技术路线图的两层含义）**
直觉：R69 的视界是固定的 `H`，VoI 是「下一步问什么」的贪心。但真实任务有**里程碑结构**：先确认对方是否要同行（M1），再决定是否让出通道（M2），最后才是速度与姿态（M3）。这就是**任务路线图**：带前置约束的 milestone DAG。它带来一种 R69 没有的不确定性——**结构不确定性**：不是「参数差多少」，而是「计划本身错了」：漏了一个里程碑、顺序反了、或某个里程碑根本不该存在。固定 H 的模态熵看不见这种错。
第二层是**能力路线图**：R69 有 FMP/AUD/MINT/CIA/FMA 一堆能力，却只有一个 MCG 校准门。若 FMA 在当前工况下不可信、或 FMP 的采样预算被击穿，系统仍可能「带着坏零件上路」。把能力成熟度做成 0–4 级阶梯（规格 → 离线证书 → 影子运行 → 门控在线 → 自主审计），每级有进入/退出准则，运行时由门控注册表决定「这个能力此刻能不能碰控制」。技术路线图由此从「论文里的未来工作」变成**运行时的一等对象**。

**灵感 3（从 myopic VoI 到 plan-level VoI）**
直觉：R69 的 `VoI(g)=H(M|o)−E[H(M|o,y)]` 只问「这个回答能减少多少模态熵」。它可能为一个小模态反复追问（交互疲劳），却漏掉一个能改变整条路线图的问题。计划级 VoI 应直接看**代价-to-go 的期望下降**：`VoI_R(g)=E[J*(I,R|o)−J*(I,R|o,y)]`。在里程碑图上，一个关于「最终目标」的问题可以同时压平后续三个里程碑的分歧；而一个关于「当前步走左边还是右边」的问题，即使熵降很多，也可能不改变计划。**可决策相关性**（decision relevance）比「信息量大」更重要。

**灵感 4（第三个冗余通道：语义一致性）**
直觉：R68 用传感器残差 `r_res` 测「测量自洽」，R69 用流似然差 `Δa` 测「行为自洽」。本轮加第三条：**意图-路线图对偶残差** `r_ir`——把观测到的行为做计划识别（plan recognition）得到「路线图隐含的意图」，与语言/上下文推断的「显式意图」比较。若 `r_ir` 高，要么意图推断错，要么路线图错；此时**不得静默重规划**，必须先问或退回保守。这条通道专门抓 R69 的最大风险：模态分布看起来很好、问答也很顺畅，但系统对「为什么做」的理解已经偏了。三条通道（测量、行为、语义）两两正交，构成比 R68/R69 更难被单一标定层吸收的冗余。

**灵感 5（新攻击面：本体与门禁）**
直觉：一旦系统有「意图本体」，就有了新的单点故障：本体漏掉一种意图，系统会把真实意图归入「未知」或错误标签；本体带有文化/任务偏见，系统会把自己的解释强加给人（intent imposition）。一旦有「能力门禁」，就有了「认证剧场」：门禁测的是错误分布，却全绿放行。再加上人类可以说反话、隐瞒约束、用提问做社交工程，路线图也可能被流模型幻觉出一个不存在的里程碑。因此本轮必须同时交付：开放世界意图（unknown mass 不得被压掉）、行为等价商空间、非诱导问句约束、路线图可采纳编辑集、按工况分层的门禁、以及「语义残差高就降级」的单调退避。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（COMPASS-RAS 总览）** COMPASS-RAS = (IBN, HGM, AIG, RPM, PVO, IQS, MVC, CML, CGR, RMR, RAS-WM‡)。五不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **意图接地**：任何动作/交互都必须由一个显式意图后验支撑，禁止用「未声明的意图」为动作背书；开放世界的未知意图质量 `U_ont` 必须被携带，不得折叠进已知类；
(iii) **行为等价**：只消解会改变策略分布的意图差异（商空间 `𝒬_I`），不追问他人的非决策性心理状态；
(iv) **路线图单调**：安全里程碑不可被静默删除/跳过；任何编辑需重发证书与降级证书，且随时可回退到 FLUID/R68；
(v) **能力门控**：任何能力只有在当前工况下通过其 CML 门禁才可进入控制；门禁 `unknown` 一律按 `fail` 处理（fail-closed）。

**定义 311（意图本体 ATLAS 与行为等价）** ATLAS = (𝒯_I, ≼, Ground, Decide)。意图 `I=(g,σ,κ,c)`：目标 `g`、社会/语用姿态 `σ`（让行、同行、求助、观察…）、约束集 `κ`（禁入区、时间窗、礼貌约束）、承诺度 `c`。`≼` 为特异性偏序（「同行」≼「同行且保持左侧」）。`Ground` 把语言/观察映射到 `𝒯_I` 的子集；`Decide` 给出意图到策略的映射。开放世界：`𝒯_I = 𝒯_known ⊔ {⊥}`，`⊥` 表示「本体外意图」。行为等价：`I₁ ~_π I₂` 当且仅当在 H 步内 `TV(π(·|I₁,o), π(·|I₂,o)) ≤ ε_beh`；商空间 `𝒬_I = 𝒯_I / ~_π`。**意图理解的目标是 `𝒬_I` 上的后验，不是 `𝒯_I` 上的标签分类。**

**定义 312（分层生成模型 HGM）** `p(ξ_{t:t+H}, M, R, I | o) = p(I|o)·p(R|I)·p(M|R,I)·p(ξ|M)`。意图是先验的因，路线图是意图的可执行展开，模态是路线图下的动作假设，轨迹是模态的实现。边缘化模态得 `p(ξ|I,R,o)`；边缘化意图得 R69 的 `p(ξ|o)`。R69 的模态分布是 HGM 在「意图边缘化后」的**粗粒化投影**：`p_R69(M|o)=Σ_I p(M|I,o)p(I|o)`。当意图后验是点质量时二者一致，否则前者会因混叠而失真。

**定义 313（意图后验与可约不确定性）** `p(I|o) ∝ p(o|I)p(I)`，其中语言先验由冻结 LLM 给出、观察先验由多模态证据给出。可约不确定性 `U_epi^I = H(𝒬_I|o)`；开放世界质量 `U_ont = p(⊥|o)`。二者分通道：`U_epi^I` 可由交互降低；`U_ont` 不能靠多问几个已知类降低，只能靠开放式提问、人工接管或保守退避。禁止把 `U_ont` 平摊进已知类（否则就是「强行理解」）。

**定义 314（别名间隙与可辨识性）** 对任意联合分布，`H(M|o) = I(M;I|o) + H(M|I,o)`。定义**别名间隙** `A = H(M|I,o)`（意图解释不了的模态熵）与**可辨识性** `ρ = I(M;I|o)/H(M|o) ∈ [0,1]`。`ρ` 低 ⇒ 模态级追问对意图几乎无信息；`ρ` 高且 `A` 大 ⇒ 模态聚类过分割，应回到意图层。**幻影模态**：若 `sup_{I: p(I|o)>δ} p(m|I,o) ≤ ε_ph`，则模态 `m` 无意图支撑，禁止为它发起追问。

**定义 315（任务路线图 RPM）** `R=(V,E,τ,Φ,Γ,v₀,V_goal)`：`V` 里程碑；`E⊆V×V` 前置偏序（DAG）；`τ(v)` 持续时间分布；`Φ(v)` 前置/后置条件与任务契约；`Γ(v)` 证书门与安全等级（`Γ_safe` 为安全里程碑集合）。当前状态不再用固定 H，而用**前沿** `F(R,o) ⊆ V`（已满足前置、尚未通过的里程碑）。视界由「走到下一个门」自适应决定。

**定义 316（结构不确定性）** `U_epi^R = H(R|o)`，后验用粒子集 `{R^{(j)}, w_j}_{j=1..N}` 表示。可采纳编辑集 `Ω_R={insert, split, merge, reorder, abandon, reparameterize}`；每个编辑有类型约束与先验。计划等价 `R₁ ~_π R₂`：在 H 步内最优动作分布之差 ≤ ε_plan；只需在商空间 `𝒬_R` 上推理。结构后验的粒子数有硬上限，超预算时退化为「当前前沿的单里程碑后验」。

**定义 317（计划级 VoI 控制器 PVO）** `VoI_R(g) = E_{y~p(·|g,o)}[J*(I,R|o) − J*(I,R|o,y)]`，其中 `J*` 为在意图/路线图后验下的期望最优代价-to-go（可用采样近似）。选择 `g* = argmax_g [VoI_R(g) − c(g)]`，约束：`risk(g) ≤ ε_int`、预算未超、问句可回答且可执行、非诱导（定义 318）。若 `max[VoI_R−c] ≤ 0` ⇒ 不交互，退化为 R69 的模态级 VoI，再退化为 R68 的纯保守。

**定义 318（意图级问句合成 IQS）** 问句 `q=Q(g_ask)` 在商空间 `𝒬_I` 上诱导一个划分，信息增益 `IG(I;Y|q,o)`。约束：
(a) **非诱导**：问句与施压/期望答案的互信息 `I(q;Y_desired) ≤ ε_lead`；
(b) **可回答/可验证**：答案必须落在有限答集或可由后续观测验证，否则不计入 `VoI_R`；
(c) **可执行**：答案须能改变至少一个前沿里程碑的决策，否则拒绝提问；
(d) **社交预算**：长度、频率、打断成本计入 `c(g)`。
若无满足条件且净收益为正的 `q`，则不提问。

**定义 319（里程碑验证 MVC）** 里程碑 `v` 在 `t` 时刻**通过**当且仅当：`cert_v` 有效、`Γ(v)` 在当前工况 `regime` 下通过、至少 `k=2` 个正交证据源一致、且无未关闭反例。证据账本 `Ledger` 记录每条证据的来源、时间、证书哈希。允许「临时通过」但降低授权等级；`Γ_safe` 中的安全里程碑只能「完全通过」。

**定义 320（能力成熟度阶梯 CML）** 每个能力 `cap` 处于 `L0–L4`：L0 规格；L1 离线证书；L2 影子运行（只观测不控制）；L3 门控在线（可控制、失败即降级）；L4 自主审计。进入/退出准则绑定具体实验与证书。**只有 ≥L3 的能力可影响控制**；L2 只可写入审计；L1 只可离线。晋级需重新认证，降级自动触发、无需人工。

**定义 321（能力门控注册表 CGR）** 注册表 `cap ↦ (level, gate, regime, expiry, cert_hash)`。门禁 `gate_cap(o,regime) ∈ {pass, fail, unknown}`，`unknown ≡ fail`。采用**双钥匙**：静态证书（编译期/离线）与运行时工况门（在线）同时通过才放行。注册表是控制回路的唯一能力白名单；任何未注册能力不得被调用。门禁必须在**当前工况分布**上校准，ECE ≤ τ_gate。

**定义 322（路线图单调修订 RMR）** 编辑 `e∈Ω_R` 可采纳当且仅当：安全里程碑集合保持（`V_safe ⊆ V'`）、安全前置关系保持、证书重发、被删除能力附降级证书、编辑被记录且可回滚。回退到 FLUID（`R` 为单里程碑、`I` 点质量）或 R68（不交互）永远可采纳。**禁止静默重规划**：`r_ir` 高时先取证，不直接改写路线图。

**定义 323（证书 J_COMPASS）** `J_COMPASS = (J_FLUID, intent_ece, aliasing_gap, identifiability_rho, unknown_mass, roadmap_hash, frontier, milestone_gates, cml_levels, capability_registry_hash, plan_voi_ratio, semantic_residual_p95, compass_ver)`。Valid ⇔ `Valid(J_FLUID) ∧ ECE_intent≤τ_ece ∧ ρ≥ρ_min ∧ 门禁无越权 ∧ 安全里程碑未被跳过`。

**定义 324（AIC-COMPASS 干扰集）** `ℰ_COMPASS = ℰ_FLUID × ℰ_intent × ℰ_roadmap × ℰ_capability`：
`ℰ_intent`：本体遗漏/错标、反话与讽刺、隐藏约束、意图伪装、社交工程；
`ℰ_roadmap`：结构幻觉（多/少里程碑）、顺序错误、里程碑伪造、门禁条件误判；
`ℰ_capability`：门禁误开、工况漂移使旧证书失效、注册表被越权修改。

**定义 325（三级时间尺度调度）** 意图层 `τ_I`（秒级，异步贝叶斯更新）、路线图层 `τ_R`（0.5–2 s，粒子重采样/重规划）、动作层 `τ_a`（毫秒级，R69 流策略）。嵌套 MPC：上层只向下层下发「前沿 + 意图后验 + 授权等级」，下层不得越权。预算耗尽时，任一层立即回退到「上一张有效证书 + R68 保守」，保证 anytime。

**定义 326（意图-路线图对偶残差）** 令 `I_obs` 为从行为做计划识别得到的隐含意图，`I_decl` 为语言/上下文推断的显式意图。`r_ir = d(I_obs, I_decl)`（商空间上的距离）。`r_ir` 高 ⇒ 意图推断与路线图至少一方错；此时触发「取证优先」：先问一个区分力最大的问题或观察一个里程碑，**不得静默重规划**。`(r_res, Δa, r_ir)` 构成测量-行为-语义三通道；三者联合分布用于区分真漂移、缓变故障与语义误解。

## 2. 关键算法骨架

```python
# IP-264 IBN：意图后验（本体约束 + 开放世界 + 行为等价商）
class IntentBelief:
    def posterior(self, o, ctx):
        logits = self.head(o) + self.llm_prior(ctx)      # 已知类 + ⊥_unknown
        p = softmax(logits)
        return quotient(p, eps_beh=self.eps_beh)         # 折叠行为等价类

# IP-266 HGM：意图 -> 路线图 -> 模态 -> 轨迹
def hierarchical_sample(M, o, K, N):
    pI = M.ibn.posterior(o, M.ctx)
    Rs = M.rpm.particles(pI, o, N)                       # 结构粒子，硬上限 N
    modes = []
    for R, wR in Rs:
        for I, wI in topk(pI, M.n_intent):
            modes += M.fmp.sample(o, I, R, K)            # 条件生成，非自由聚类
            modes[-1].weight = wR * wI
    return aggregate(modes), pI, Rs

# IP-267 AIG：别名/可辨识性/幻影门（在问之前拦截）
def aliasing_gate(modes, pI):
    H_M = entropy(mode_weights(modes))
    A   = expected_entropy_given_intent(modes, pI)       # H(M|I,o)
    rho = 0.0 if H_M < EPS else (H_M - A) / H_M          # I(M;I|o)/H(M|o)
    phantom = [m for m in modes
               if max_intent_support(m, pI) < EPS_PH]
    return A, rho, phantom

# IP-268 RPM：任务路线图粒子滤波（结构编辑受限）
def particles(self, pI, o, N):
    R = self.prior_from(pI)
    for _ in range(self.max_edit_rounds):
        cand = [self.propose_edit(R, pI) for _ in range(N)]  # 只在 Ω_R 内
        R = self.resample(weight(cand, o), N)
    return self.topk_exact(R, N)

# IP-269 PVO + IP-270 IQS：计划级 VoI 与意图级问句
def choose_interaction(M, pI, Rs, o):
    best = None
    for g in M.iqs.candidates(pI, Rs, o):                # 看/触/问，≤5 个
        if not M.budget.allow(g): continue
        if not M.c_ras_wm.certify_info(g, o): continue
        if not M.iqs.non_leading(g, pI): continue        # 非诱导
        J0 = M.pvo.cost_to_go(pI, Rs, o)
        J1 = M.pvo.expected_cost(M.update, g, pI, Rs, o)
        score = (J0 - J1) - M.cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-273 CGR：能力门控（fail-closed）
def gate(cap, o, regime):
    e = M.cgr.get(cap)
    if e is None or e.level < L3:            return Fail
    if e.expired or e.regime != regime:      return Fail
    return e.gate(o) if e.gate(o) == Pass else Fail

    elif not semantic_fault and (U_epi_I + U_epi_R > TAU_PLAN) and rho >= RHO_MIN:
        g = M.choose_interaction(pI, Rs, o)

    resolved = (g is not None) and (U_epi_I + U_epi_R < TAU_PLAN)

    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    # 7) 路线图单调修订（安全里程碑不可跳），否则回退
    if semantic_fault:

        Rs = M.rmr.admissible_update(Rs, pI, o)           # 仅 Ω_R，安全集保持

    v = M.rpm.frontier(Rs, o)

    # 9) 审计 + 证书（含意图 ECE、rho、路线图哈希、门禁状态）
    M.vqa_r.submit_async(pI, Rs, g, r_ir, enabled, A, rho)
    return k, lam, v, (U_ale, U_epi_I, U_epi_R, U_ont)
```

## 3. 推导

**假设 A99–A102**：A99 意图覆盖（真实的行为相关意图落在 `𝒬_I` 内，或表现为可检测的 `U_ont`）；A100 计划忠实（真实任务结构在 `Ω_R` 内可表达到计划等价）；A101 门禁校准（`gate_cap` 在当前工况 ECE ≤ τ_gate，工况分类器准确率 ≥ a_regime）；A102 时间尺度分离（意图/路线图变化慢于动作环，缓存有效）。

**引理 19（模态熵的意图分解与别名间隙）** 对任意 `p(M,I|o)`，恒有 `H(M|o) = I(M;I|o) + H(M|I,o)`。令 `A=H(M|I,o)`、`ρ=I(M;I|o)/H(M|o)`。则 R69 的模态级 VoI 至多只能作用于 `ρ·H(M|o)` 这部分「意图可解释」的熵；`A` 部分对意图更新无信息。系 1：当 `A/H(M|o) > 1−ρ₀` 时，任何模态级追问都无法把意图熵降到 `A` 以下，必须改用意图级提问。系 2：模态聚类过分割会**同时**抬高 `H(M|o)` 与 `A`，在 `ρ` 不变时制造虚假的交互需求——这正是 R69 交互疲劳的一个可证明来源。

**引理 20（意图级问句的支配条件）** 设问句 `q` 的意图增益 `ΔH_I=I(I;Y|q,o)`，模态问句 `q_m` 的模态增益 `ΔH_M`。一次完全分辨意图的 `q` 至少消去 `I(M;I|o)=ρH(M|o)` 的模态熵（因为给定 `I` 后模态熵只剩 `A`）。要在模态通道上取得同样效果，至少需要 `⌈ρH(M|o)/ΔH_M⌉` 次 `q_m`。因此当 `I(M;I|o) ≥ ΔH_M` 且 `c(q) ≤ c(q_m)` 时，意图级问句弱支配模态级问句；反之当 `ρ < ρ₀`（即 `I(M;I|o)` 很小）时，模态级追问的期望净收益为负，应直接保守。系：**该不该问，取决于「意图与模态的耦合强度」，而不是模态熵本身。**

**引理 21（幻影模态的拒绝界）** 在 A99 下，若模态 `m` 满足 `sup_{I:p(I|o)>δ} p(m|I,o) ≤ ε_ph`，则 `p(m 为真 | o) ≤ ε_ph/δ + U_ont`。因此把此类模态排除在追问候选之外，误拒概率不超过 `ε_ph/δ + U_ont`。**界中显式保留 `U_ont` 是诚实的**：若真实意图在本体之外，任何基于已知本体的拒绝都可能错——这正是本轮最大风险的来源，不能用定理掩盖。

**引理 22（意图-路线图对偶的可分离性）** 若 `r_ir` 高，且已通过的安全里程碑集合 `V_safe` 上的证据一致，则「意图推断错误」与「路线图错」可由 `(r_ir, V_safe 证据一致性)` 部分分离：安全里程碑证据一致而 `r_ir` 仍高 ⇒ 更可能是意图标签/本体错；安全里程碑证据本身冲突 ⇒ 更可能是路线图结构错。二者都触发取证优先，但取证对象不同（问意图 vs 验证里程碑）。

**定理 18（COMPASS 严格包含 FLUID 与 R68）** 在 A99–A102 下，若意图后验退化为点质量（`U_epi^I=0`, `U_ont=0`）、路线图为单里程碑（`|𝒬_R|=1`）、别名间隙为零（`ρ=1`）、且所有能力门禁放行，则 COMPASS 的 `VoI_R` 逐项等于 R69 的模态级 VoI，风险缩放逐指令等于 `λ_floor(U_ale+未消解 U_epi)`；再令交互预算为零，则两者逐指令等于 R68。由于门控只会**删减**可用动作/能力，永不新增动作，故 COMPASS 在任意状态上的期望风险 ≤ 未门控的 FLUID ≤ R68 的最保守边界。**R69 与 R68 分别是本轮的『单里程碑/点意图』边界与『不交互』边界。**

**定理 19（能力门控的风险界与单调降级）** 设能力 `cap` 的门禁误开概率 ≤ ε_g，误开时相对正确能力的额外风险 ≤ R_max，共 `|C|` 个能力。则 `E[R_gated] ≤ E[R_ungated] + |C|·ε_g·R_max`；若证书健全（误开概率为 0），则不等号取等号且不引入额外风险。降级算子把 `L3→L2→L1`，每步只会缩小可影响控制的动作集，故 `λ` 单调不降、风险单调不增。系：**「宁可不做，不可带病做」可以被写成可审计的偏序，而不是一句口号。**

**定理 20（路线图单调修订的无突变安全）** 任何可采纳编辑 `e∈Ω_R` 保持 `V_safe` 与安全前置关系，且新证书在切换点有效；切换时控制前缀仍由 C-RAS-WM 认证，故安全包络不变。若编辑失败、超时或 `r_ir` 越界，立即回滚到 FLUID 单里程碑（或 R68），且 `λ` 单调不降。因此路线图可以演化，但**不允许在演化中跳过安全门**；控制连续、无突变（继承 R69 定理 17）。

## 7. 本轮最大风险

**一句话**：COMPASS 把 R69 的「模态可信」风险上移为「意图本体可信 + 门禁可信」的双重风险——一旦 ATLAS 遗漏或错标了真实意图，系统会以「无合理解释」为由把真实歧义**解释掉**，再用一张全绿但测错分布的路线图和门禁自信地执行错误意图；**理解错意图，比不理解更危险，因为它会以确定性的姿态犯下方向性的错误。**

**次级风险与缓解**：
1. **本体遗漏/文化偏见**（intent imposition）→ `U_ont` 显式保留、开放式提问、E316；禁止把 unknown 折叠进已知类；
2. **认证剧场**（门禁测错分布）→ 工况分层门禁 + 反例注入 + E309；误开即全局降级；
3. **结构幻觉**（路线图多/少里程碑）→ `Ω_R` 可采纳编辑集 + 计划等价商 + 粒子硬上限；
4. **语用欺骗/反话/隐藏约束** → 非诱导约束 + `k` 正交证据 + `r_ir` 语义残差 + E312/E313；
5. **分层延迟** → 三级时间尺度 + 缓存 + anytime 回退到上一张有效证书/R68；
6. **对 R69 模态校准的残余依赖** → CML 门控把 FMP/AUD 置于 L3 以下时直接回 R68，绝不让坏零件进入控制。

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** COMPASS-RAS 继承零学习写操作；新增：意图接地（动作须有显式意图后验支撑，`U_ont` 不得折叠）、行为等价（只消解 `𝒬_I`）、路线图单调（安全里程碑不可跳）、能力门控（未过门不得进入控制，`unknown≡fail`）。

**定义 311–313（ATLAS、HGM、意图后验）** 意图 `I=(g,σ,κ,c)`，开放世界含 `⊥`；`I₁~_πI₂` 当 H 步策略 TV 距离 ≤ ε_beh；`p(ξ,M,R,I|o)` 分层分解；`U_epi^I=H(𝒬_I|o)` 与 `U_ont=p(⊥|o)` 分通道处置，不能相加成标量。

**定义 314（别名与幻影）** `H(M|o)=I(M;I|o)+A`，`ρ=I(M;I|o)/H(M|o)`；`ρ` 低则模态追问无信息；`sup_{I:p(I|o)>δ}p(m|I,o)≤ε_ph` 的模态为幻影，禁止为它提问（误拒界含 `U_ont`）。

**定义 315–316（任务路线图与结构不确定性）** `R=(V,E,τ,Φ,Γ,v₀,V_goal)`，用前沿 `F(R,o)` 替代固定 H；`U_epi^R=H(R|o)` 由粒子集表示；只在可采纳编辑集 `Ω_R` 与计划等价商 `𝒬_R` 上推理。

**定义 317–318（计划级 VoI 与意图问句）** `VoI_R=E[J*(I,R|o)−J*(I,R|o,y)]`，选 `argmax[VoI_R−c]`；问句须非诱导、可回答/可验证、可执行、守社交预算；无正净收益则不问。

**定义 319–321（里程碑验证、CML、CGR）** 里程碑通过 = 证书 + 工况门禁 + `k=2` 正交证据 + 无反例；能力 L0–L4，只有 ≥L3 可控制；注册表 `cap↦(level,gate,regime,expiry,cert_hash)`，双钥匙、fail-closed、自动降级。

**定义 322–323（单调修订与证书）** `Ω_R` 编辑须保持 `V_safe`、重发证书、附降级证书、可回滚；`J_COMPASS` 并入意图 ECE、`A`、`ρ`、`U_ont`、路线图哈希、里程碑门、CML 等级、计划 VoI 比与 `r_ir` 分位。

**定义 324–326（干扰集、三级调度、语义对偶）** `ℰ_COMPASS=ℰ_FLUID×ℰ_intent×ℰ_roadmap×ℰ_capability`；意图/路线图/动作三级时间尺度嵌套 MPC，任一层失败即 anytime 回退；`r_ir` 高 ⇒ 取证优先，禁止静默重规划。

## 3. 关键算法伪代码

```python
# IP-264 IBN：意图后验（本体约束 + 开放世界 + 行为等价商）
class IntentBelief:
    def posterior(self, o, ctx):
        p = softmax(self.head(o) + self.llm_prior(ctx))   # 已知类 + ⊥_unknown
        return quotient(p, eps_beh=self.eps_beh)           # 折叠 ~_π 等价类

# IP-266 HGM：意图 -> 路线图 -> 模态 -> 轨迹（条件生成，非自由聚类）
def hierarchical_sample(M, o, K, N):
    pI = M.ibn.posterior(o, M.ctx)
    Rs = M.rpm.particles(pI, o, N)                         # 结构粒子，硬上限
    modes = []
    for R, wR in Rs:
        for I, wI in topk(pI, M.n_intent):
            modes += M.fmp.sample(o, I, R, K)
            modes[-1].weight = wR * wI
    return aggregate(modes), pI, Rs

# IP-267 AIG：别名 / 可辨识性 / 幻影门（问之前拦截）
def aliasing_gate(modes, pI):
    H_M = entropy(mode_weights(modes))
    A   = expected_entropy_given_intent(modes, pI)         # H(M|I,o)
    rho = 0.0 if H_M < EPS else (H_M - A) / H_M
    phantom = [m for m in modes if max_intent_support(m, pI) < EPS_PH]
    return A, rho, phantom

# IP-269 PVO + IP-270 IQS：计划级 VoI 与意图级问句
def choose_interaction(M, pI, Rs, o):
    best = None
    for g in M.iqs.candidates(pI, Rs, o):
        if not M.budget.allow(g) or not M.c_ras_wm.certify_info(g, o): continue
        if not M.iqs.non_leading(g, pI): continue          # 非诱导
        J0 = M.pvo.cost_to_go(pI, Rs, o)
        J1 = M.pvo.expected_cost(M.update, g, pI, Rs, o)
        score = (J0 - J1) - M.cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None       # 无利可图 -> R69/R68

# IP-273 CGR：能力门控（fail-closed，双钥匙）
def gate(cap, o, regime):
    e = M.cgr.get(cap)
    if e is None or e.level < L3:       return Fail
    if e.expired or e.regime != regime: return Fail
    return Pass if e.gate(o) == Pass else Fail

# IP-278 COMPASS 主闭环（任一层失败即单调退避）
def COMPASS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal = M.cof.step(...)
    pI = M.ibn.posterior(o, M.ctx)
    U_epi_I, U_ont = entropy(quotient(pI)), pI[UNKNOWN]
    Rs = M.rpm.particles(pI, o, N=M.budget.roadmap_N)
    U_epi_R = M.rpm.entropy(Rs)
    semantic_fault = M.rmr.semantic_residual(o, pI, Rs) > TAU_IR
    modes, pI, Rs = M.hgm.sample(o, pI, Rs, K)
    A, rho, phantom = M.aig.aliasing_gate(modes, pI)
    g = None
    if not semantic_fault and U_ont > TAU_ONT:
        g = M.iqs.open_intent_query(pI) if M.budget.allow_ask() else None
    elif not semantic_fault and (U_epi_I + U_epi_R > TAU_PLAN) and rho >= RHO_MIN:
        g = M.choose_interaction(pI, Rs, o)
    if g is not None:
        y = M.cia.execute(g); pI, Rs = M.ibn.update(y), M.rpm.update(y)
    enabled = {cap for cap in M.used_this_round(o) if M.cgr.pass(cap, o, o.regime)}
    if not {'FMP', 'AUD'} <= enabled:
        return M.r68_round(o)                              # 能力不足 -> R68
    resolved = (g is not None) and (U_epi_I + U_epi_R < TAU_PLAN)
    U_floor = U_ale + (0.0 if resolved and not semantic_fault else U_epi_I + U_epi_R)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if semantic_fault:
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, U_cal))
        Rs = M.rmr.rollback_to_fluid(Rs)
    else:
        Rs = M.rmr.admissible_update(Rs, pI, o)            # 仅 Ω_R，安全集保持
    v = M.rpm.frontier(Rs, o)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(v), ..., wm_preds)
    tau = M.pi_sigma.prefix_dispatch(select_mode(modes, pI, Rs).a[:k]) * lam
    M.vqa_r.submit_async(pI, Rs, g, semantic_fault, enabled, A, rho)
    return k, lam, v, (U_ale, U_epi_I, U_epi_R, U_ont)
```

## 4. 推导

**假设 A99–A102**：A99 意图覆盖（行为相关意图在 `𝒬_I` 内，或表现为可检测 `U_ont`）；A100 计划忠实（真实结构在 `Ω_R` 内可表达到计划等价）；A101 门禁校准（当前工况 ECE ≤ τ_gate）；A102 时间尺度分离（意图/路线图慢于动作环）。

**引理 19（模态熵的意图分解）** `H(M|o)=I(M;I|o)+H(M|I,o)`；令 `A=H(M|I,o)`、`ρ=I(M;I|o)/H(M|o)`。R69 的模态级 VoI 最多作用于 `ρH(M|o)`；`A` 对意图更新无信息。系：过分割同时抬高 `H(M|o)` 与 `A`，在 `ρ` 不变时制造虚假交互需求——这是 R69 交互疲劳的可证明来源。

**引理 20（意图问句的支配条件）** 完全分辨意图至少消去 `I(M;I|o)=ρH(M|o)` 的模态熵，因此等价效果至少需 `⌈ρH(M|o)/ΔH_M⌉` 次模态追问。当 `I(M;I|o)≥ΔH_M` 且 `c(q)≤c(q_m)` 时意图问句弱支配；当 `ρ<ρ₀` 时模态追问净收益为负，应保守。系：**该不该问取决于意图-模态耦合强度，而非模态熵本身。**

**引理 21（幻影拒绝界）** A99 下，`sup_{I:p(I|o)>δ}p(m|I,o)≤ε_ph` ⇒ `p(m真|o)≤ε_ph/δ+U_ont`。误拒界显式含 `U_ont`：本体外的真实意图无法被已知本体保证拒绝正确——这是风险的来源，不能用定理掩盖。

**引理 22（语义对偶可分离）** `r_ir` 高且 `V_safe` 证据一致 ⇒ 更可能意图/本体错；`V_safe` 证据冲突 ⇒ 更可能路线图结构错。二者都触发取证，但取证对象不同。

**定理 18（严格包含 FLUID/R68）** 点意图（`U_epi^I=U_ont=0`）+ 单里程碑 + `ρ=1` + 门禁全放行 ⇒ COMPASS 逐项等于 R69；再令交互预算为零 ⇒ 逐指令等于 R68。门控只删减动作/能力，故期望风险 ≤ 未门控 FLUID ≤ R68 最保守边界。

**定理 19（能力门控风险界）** 门禁误开 ≤ ε_g、误开额外风险 ≤ R_max、能力数 |C| ⇒ `E[R_gated]≤E[R_ungated]+|C|ε_gR_max`；证书健全时等号成立。降级 L3→L2→L1 只缩小控制动作集 ⇒ `λ` 单调不降、风险单调不增。

**定理 20（路线图单调修订无突变）** 可采纳编辑保持 `V_safe` 与安全前置，新证书在切换点有效；前缀仍由 C-RAS-WM 认证 ⇒ 安全包络不变。失败/超时/`r_ir` 越界 ⇒ 回滚 FLUID/R68，`λ` 单调不降；控制连续、无突变（继承 R69 定理 17）。

## 8. 本轮最大风险

**一句话**：COMPASS 把 R69 的「模态可信」风险上移为「意图本体可信 + 门禁可信」的双重风险——一旦 ATLAS 遗漏或错标真实意图，系统会以「无合理解释」为由把真实歧义**解释掉**，再用一张全绿但测错分布的路线图和门禁自信地执行错误意图；**理解错意图，比不理解更危险，因为它会以确定性的姿态犯下方向性的错误。**

**次级风险与缓解**：本体遗漏/文化偏见（保留 `U_ont` + 开放式提问 + E316，禁止 unknown 折叠）；认证剧场（工况分层门禁 + 反例注入 + E309，误开即降级）；结构幻觉（`Ω_R` 限制 + 计划等价商 + 粒子上限）；语用欺骗/反话（非诱导 + k 正交证据 + `r_ir` + E312/E313）；分层延迟（三级调度 + 缓存 + anytime 回退）；对 R69 模态校准的残余依赖（CML 门控低于 L3 直接回 R68）。
