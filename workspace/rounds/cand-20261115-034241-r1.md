# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；本轮灵感：「惯性测量单元」×「预测性维护」）

> R69 问「我该向谁求证、还能问什么」，把不确定性拆成 aleatoric / epistemic，并用主动交互消解后者。但 R69 的整条闭环默认了一个从未被写下来的前提：**发问的这具身体是不朽的、恒定的、永远和标定时一模一样**。所有交互都朝外（看、问、触），没有一次朝向自己；所有时间尺度都是毫秒级的单步决策，没有一个「下个月会怎样」的坐标。真实的机器人不是幽灵：轴承在磨、执行器在衰、IMU 在漂——**发问者本身正在悄悄变成另一个人。**
>
> 本轮两个灵感正好补上这块：
> - **惯性测量单元**是「内感受」：高频、低延迟、直接测自身运动。它的**频谱**（振动）是机械健康最便宜的指纹，而且因果上先于外感受退化——底座一开始抖，IMU 先知道，视觉还没坏。这让 SOMA 拥有一条与 R68 残差、R69 似然都正交的**第三条健康证据通道**。
> - **预测性维护**把「不确定性」拉上**时间轴**：不再只问「这一步是否安全」，而问「我还能这样干多久、什么时候该停」。RUL（剩余使用寿命）分布把安全从瞬时约束升级为**带截止期的约束**。
>
> 核心命题：**在 R69 的「世界不确定性」之外，增加一个「自身不确定性」轴 U_prog（关于自身还能撑多久、随时间演化的认知不确定性），用 IMU 频谱做独立证据，用「诊断性激励」这种新信息动作主动获取它，用 RUL 分布驱动一个慢时间尺度的维护调度；而诊断本身会消耗健康，所以必须给「获取健康信息」本身定价。** 命名 **SOMA-RAS**（Self-Observing, Maintenance-Aware Risk-Adaptive System，自体观测-维护感知风险自适应闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我自己还能撑多久、什么时候必须停下来修**」——不确定性不只是刹车和提问，也可以是一张体检单和一个停机计划。

## 0. 直觉与动机

**灵感 1（IMU = 内感受 → 第三个正交健康通道）**
直觉：R68 的 r_res 测「传感器彼此自洽」，R69 的 Δa 测「行为在策略下自洽」，两者都在问「我感知到的世界对不对」。但它们都分不清一件事：**是世界变了，还是我的身体变了？** 当关节开始磨损，视觉世界完全正常，r_res 也可能干净，Δa 只会缓慢升高（因为策略被迫生成更保守/更抖的动作）。IMU 直接测底座与肢体的高频运动，其**频谱**能抓到磨损的机械指纹（轴承故障频率、齿轮啮合边带、执行器摩擦引起的宽带抬升）。更关键的是**因果先行**：机械退化先污染本体运动，再才污染外感受。故 IMU 是「世界 vs 自身」这一划分的唯一直接证据源——没有它，R68/R69 的一切异常都可能被误归因为「世界在骗我」。

**灵感 2（预测性维护 → 安全从瞬时约束变成带截止期的约束）**
直觉：R69 的风险缩放 λ 是**无记忆**的：它只知道「此刻有多不确定」，不知道「这具身体已经欠了多少债、还能还几天」。预测性维护给出的不是另一个标量，而是一条**分布** p(RUL | 历史)。这把安全约束从「每一步 fail 概率 ≤ ε」升级为「在任务视界 T_m 内 fail 概率 ≤ ε」。于是同一个瞬时状态，若 RUL 远离 T_m，可以拿 resolution bonus 更激进；若 RUL 逼近 T_m，则必须从「降速」升级为「停机/换件」——这是一个 R69 动作空间里根本不存在的动作。

**灵感 3（诊断性激励 → 朝自己发问的信息动作，而且它消耗健康）**
直觉：这是本轮最漂亮的一处对偶。R69 的信息动作（看/问/触）朝外，成本是时间与社交；R70 的信息动作朝内——**要让身体暴露健康，必须激励它**。系统辨识的持续激励（persistent excitation）条件说得很直白：不振就不可能辨识出模态参数。所以「做几个特定频率的微幅摆臂/加减速」就是一种体检动作：它在敏感频带注入能量，把退化参数从不可观变为可观。但**体检本身伤身**：激励的能量会转化为磨损，且可能放大已存在的裂纹。于是 VoI 不再是 VoI − c_社交，而是 VoI − c_社交 − **c_磨损·(预期新增健康损失)**。一句话：**获取健康信息的价格，就是健康本身。** 这迫使我们定义「最优体检频率」——太懒会瞎着跑到失效，太勤则把身体测坏。

**灵感 4（双时间尺度 → 快环与慢环可能互相背书）**
直觉：毫秒级的快环管「这一步别撞」，天级的慢环管「下周去修」。两者若各自只看自己的窗口，会形成一个致命的稳态：快环说「我现在很安全」，慢环说「离维护截止还早」，**两个都成立、两个都不负责**——而健康在这段互相背书的时间里被持续抽干。这是经典的 moral hazard 在多时间尺度控制里的化身，也是本轮必须用「契约 + 不变式」正面处理的硬核心：不能让两个环同时松弛。

**灵感 5（退化模型是「被删失」的历史 → 系统性乐观）**
直觉：预测性维护的训练数据天然带**删失**：只在坏掉时记录寿命，预防性换件会截断样本，没坏就被换掉的部件其「长寿命」信息被丢弃。naive 极大似然会把 RUL 估得系统性偏乐观；再叠加维护日志可被伪造、振动可被贴片信号欺骗，健康模型就是一个**会被喂糖的乐观主义者**。一个乐观的 RUL 模型比没有模型更危险，因为它会把「诚实的不确定」变成「盖章的『还能撑』」。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（SOMA-RAS 总览）** SOMA-RAS = (PIM, HSD, DEX, HMS, MCT, HMF, RAS-WM††)。三不变式：
(i) **实时快环零学习写操作**（继承 R69 定义 293-i；维护决策只在慢环发生）；
(ii) **体检预算硬约束**：诊断性激励的累积磨损 ≤ W_max、单次激励幅值/频带不得越任务安全包络、激励动作必须通过与任务动作相同的 C-RAS-WM 认证；
(iii) **健康证据纪律**：任何维护决策不得由单一未校准 RUL 源定案，需 IMU 频谱、动作似然（R69 FMA）、传感器残差（R68 r_res）中至少两源一致，或健康后验区间宽度低于高置信阈值。

**定义 311（健康状态与风险过程）** 健康状态 h_t ∈ ℋ（退化参数，如磨损深度、执行器增益衰减、IMU 偏置漂移率）；退化过程按非负单调随机过程建模（Gamma 过程 / 带漂移 Wiener 过程 / 学到的 hazard），观测为 IMU 特征流。生存函数 S(τ | h_t) = P(RUL > τ | ℋ_t)，hazard λ_H(τ|h_t)。健康后验 p(h_t | ℋ_t) 是慢环状态，快环只读。

**定义 312（本体感觉特征映射 PIM）** 对 IMU 窗口 w_t ∈ ℝ^{6×N}（三轴加速度 + 三轴角速度，1 kHz），PIM 输出 φ_t = (r_imu, s_t)：其中 r_imu = ‖a−â_kin(z_t)‖ 为「实测惯性 vs 由 R68 运动学/接触预测的惯性」一致性残差（世界 vs 自身的直接判别量），s_t 为频谱指纹（包络谱峰、啮合边带能量、0–500 Hz 分频带能量、谱峭度）。退化参数的可观性由 s_t 的**敏感频带能量**决定（引理 19）。

**定义 313（三向不确定性分解）** 在 R69 的 (U_ale, U_epi) 之外增加**自身时间轴**：
- U_ale = 模态内噪声（R69 定义 297，世界侧，不可约）；
- U_epi = 模态间歧义（R69 定义 297，世界侧，可交互消解）；
- **U_prog = (U_prog^ale, U_prog^epi)**：U_prog^ale 为退化过程的内禀随机性（问也问不出的抖动），U_prog^epi 为退化**速率/参数**的认知不确定（可由激励/更多数据降低）。
三者不做简单加和，各自进不同通道：U_ale、U_epi 走 R69 的 λ/交互；U_prog 走 R70 的体检/维护通道。**注意这是 R69 二分法的自相似递归**：在「自身未来」这一轴内部，再次分裂为不可约随机与可约认知。

**定义 314（诊断性激励动作 DEX）** 信息动作从 R69 的 g（朝外）扩展为 d ∈ 𝒟（朝内）：「在任务允许的姿态/幅值内，对指定关节与频带施加一段微幅、可认证的激励轨迹」。增广动作 ξ = (a, g, d) ∈ 𝒜_task × 𝒜_info × 𝒟。**持续激励条件（PE）**：在敏感频带 Ω_θ 上，d 的功率谱 S_d(ω) 满足 ∫_{Ω_θ} S_d(ω) dω ≥ E_PE（否则 θ 不可辨识）。

**定义 315（自体价值-of-信息 VoI_self）** 对候选激励 d：
VoI_self(d) = I(θ; y_d | ℋ_t) − c_社交(d) − **c_磨损(d)**，其中 y_d 为执行 d 后的 IMU 观测，c_磨损(d) = κ·E[新增退化 | d] 由定义 316 给出。选择 d* = argmax_d VoI_self(d)，s.t. risk(d) ≤ ε_diag、磨损预算未越界。**若 max VoI_self ≤ 0：不体检**——健康系统不该被「为了保险」反复测坏。

**定义 316（激励致损模型）** 定义单次激励的新增期望退化 Δh(d) = ∫ g(ω)·S_d(ω) dω（g(ω) 为频带相关的损伤敏感核，由加速寿命实验或物理模型给出）；累积磨损预算 W_t = Σ_{τ≤t} Δh(d_τ) 单调不降。**观测者效应**：对被测系统的每一次测量都会改变被测系统——这是 SOMA 与 R69 最本质的差别。

**定义 317（健康感知风险缩放与任务视界）** 设任务视界 T_m、允许失效概率 ε_life。定义**安全运行视界** T_safe(h_t) = max{τ : P(RUL < τ | h_t) ≤ ε_life}。快环风险缩放：
λ = λ_floor(U_ale + 未消解 U_epi) · ρ(T_safe/T_m)，其中 ρ: [0,∞)→[1,∞) 单调不增且在 T_safe ≥ T_m 时取 1（健康时完全退化为 R69）。
若 T_safe < T_m：不再只降速，而是把「维护动作」提上快环议程（定义 320）。这把 R69 的「瞬时安全」升级为「带截止期安全」，且**逐指令包含** R69（T_safe = ∞ 时 ρ ≡ 1）。

**定义 318（RUL 校准与删失感知似然 HMF）** 维护截断数据是对寿命的右删失。健康模型用**删失感知似然**训练：L = Π_{失效样本} f(t_i|θ) · Π_{删失样本} S(c_i|θ)。用**保形预测（conformal survival）**给出 RUL 区间的有限样本覆盖率保证：P(RUL ∈ [L_α, U_α]) ≥ 1−α。定义健康校准门 HCG：若实测覆盖率低于名义值（区间过窄 = 过度自信），禁用维护排序、退回「保守定期维护」。

**定义 319（健康证据三角与纪律）** 三源：s_t（IMU 频谱，测机械）、Δa（R69 动作似然，测行为）、r_res（R68 残差，测感知）。判别规则：**世界漂移**≈r_res↑、Δa↑、s_t 平；**自身退化**≈s_t↑、Δa↑（策略被迫抖/保守）、r_res 可能干净。只有两源一致才更新 h_t 的维护决策；单源异常只进「观察名单」，不触发停机。

**定义 320（维护动作空间与慢策略 HMS）** 维护动作 m ∈ {continue, derate, schedule(τ), stop}，成本含停机损失、备件/人力、误停惩罚。慢策略 π_H(m | p(h_t|ℋ_t)) 最小化期望总成本：E[∫操作成本 + 失效损失 + 维护成本]，约束 P(fail in T_m) ≤ ε_life。这是一类**部分可观测的停止/调度问题**（POMDP），与快环的毫秒决策严格分层。

**定义 321（健康租约与双时间尺度契约 MCT）** 快环每轮向慢环签发**健康租约** Lease_t = T_safe(h_t)（在**同一**健康后验下算出的、它敢承诺的安全运营时长），并附签发证据哈希；慢环**必须**在此租约到期前安排满足 π_H 的动作（derate/schedule/stop）。租约随健康证据单调不增（除非有维修事件重置），**两个环不得各自用自己的私有信念算安全**——它们必须读同一个 p(h_t|ℋ_t)。

**定义 322（无相互背书不变式）** 定义快环松弛 F_t = 安全裕度，慢环松弛 M_t = 距维护截止时长。要求：**不存在持续区间使 F_t > 0 且 M_t > 0 而真实 h_t 仍在退化**。实现：定义健康预算 B_t = T_safe(h_t) + 已计提维护储备；契约要求每步 B 的期望不增（除非发生维护，且其成本如实入账），故两环无法同时「白嫖」。若一方违约（快环偷偷按乐观信念放宽，或慢环拖延），另一方的租约检查立即升级为最保守。

**定义 323（退化感知证书 J_SOMA）** J_SOMA = (J_FLUID, rul_interval_coverage, censoring_bias_corrected, excitation_wear_budget_used, health_evidence_agreement, lease_hash, maintenance_log_hash, soma_ver)。Valid ⇔ Valid(J_FLUID) ∧ RUL 覆盖率达标 ∧ 证据纪律满足 ∧ 磨损预算未越界 ∧ 租约链可验证。

**定义 324（威胁集 ℰ_SOMA）** ℰ_SOMA = ℰ_FLUID × ℰ_vibe × ℰ_censor × ℰ_excite × ℰ_goodhart：振动贴片/频谱欺骗（伪造健康）、维护日志投毒与右删失篡改（喂乐观）、恶意激励指令（借体检之名造伤）、Goodhart 抑制（为压低停机指标而滤掉故障频带/调低报警）。并入 AIC 的联合威胁模型。

**定义 325（迟滞带与防抖）** derate↔schedule 之间设迟滞带 H_band：T_safe 落入 [T_m(1−δ), T_m(1+δ)] 时不切换，避免在阈值附近抖动导致既不修也不稳。迟滞带宽度本身入证书，防被调参利用。

**定义 326（严格包含边界）** 令「不朽身体」极限：U_prog ≡ 0、d ≡ ∅、T_safe = ∞、无维护动作。则定义 317 的 ρ ≡ 1、定义 315 无激励、定义 320 无维护，SOMA-RAS **逐指令退化为 FLUID-RAS（R69）**。安全侧永不弱于 R69；新增的只有「能在更早的时刻看见衰败、并在正确时刻停下」。

# IP-264 PIM：本体感觉健康通道（1kHz IMU，快环只读，不写学习）
def pim_features(imu_win, z, kin_model):
    a_hat = kin_model.predict_inertial(z)             # R68 运动学/接触预测
    r_imu = norm(imu_win.acc - a_hat.acc)             # 世界 vs 自身的直接判别
    env   = envelope_spectrum(imu_win)                # 包络谱
    s     = spectral_fingerprint(env)                 # 边带/分频带能量/谱峭度
    return r_imu, s, env

# IP-266 DEX：朝内的诊断性激励（VoI 扣掉磨损成本；无利可图不体检）
def choose_excitation(h_post, budget, c_ras_wm):
    best = None
    for d in excitation_candidates(h_post):           # 关节 × 频带 × 幅值
        if not budget.wear_allow(d):              continue
        if not c_ras_wm.certify_diag(d):          continue  # 激励也过安全认证
        info = fisher_info_gain(h_post, d)             # 引理 19：PE 频带能量
        wear = kappa * expected_damage(d)              # 定义 316：体检伤身
        score = info - social_cost(d) - wear
        if best is None or score > best.score: best = (d, score)
    return best if best and best.score > 0 else None      # 无利可图 → 不体检

# IP-265/268 HSD+HMF：删失感知 hazard 更新与 RUL 区间
def update_health(h_post, y_d, maintenance_log):
    h_post = bayes_update(h_post, y_d, lik='censoring_aware')  # 定义 318
    rul    = conformal_survival(h_post, alpha=ALPHA)           # 有限样本覆盖
    return h_post, rul                                         # (L_alpha, U_alpha)

# IP-269 HMS：慢环维护调度（只在租约到期前决策）
def maintenance_policy(h_post, rul, lease, cost_model):
    if lease < T_MISSION * (1 - DELTA):          # 快环已不敢承诺整个任务
        return argmin_cost(['derate', 'schedule', 'stop'], h_post, rul, cost_model)
    if rul.lower < T_MISSION:                    # 区间下界已触视界
        return 'schedule'
    return 'continue'                            # 健康：不打扰快环

# IP-273 SOMA 主闭环（继承 R69 FLUID；仅在不确定性处置后插入健康层）

    # ---- R69 世界侧（逐指令不变）----
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    g = M.mint.choose_interaction(modes, o, M.budget) if U_epi > TAU_EPI else None
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    # ---- R70 自身侧（新增，读同一份健康后验）----

    agree = health_evidence_agreement(s, a_hat, M.last_r_res)  # 定义 319
    if agree >= K_AGREE: M.h_post = M.hsd.update(M.h_post, s)
    d = M.dex.choose_excitation(M.h_post, M.budget, M.c_ras_wm)  # 体检（可选）
    if d is not None:
        y_d = execute_excitation(d)
        M.h_post, M.rul = M.hsd.update_health(M.h_post, y_d, M.maintenance_log)
    lease = M.mct.derive_lease(M.h_post)                       # 安全运营视界
    # ---- 风险缩放：R69 λ 乘健康因子；两环读同一后验 ----
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor)) * rho(lease / T_MISSION)
    m   = M.hms.maintenance_policy(M.h_post, M.rul, lease, M.cost)  # 慢环
    if m in ('derate', 'stop'):                               # 维护优先于任务
        lam = max(lam, LAM_MAINT)
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_soma.submit_async(d, s, lease, m, agree)            # 审计健康决策
    return k, lam, mode, m, lease
```

## 3. 推导

**引理 19（退化的持续激励可辨识性）** 设 IMU 观测 y_t = f(θ; 激励) + ε_t，退化参数 θ 对激励输入的 Fisher 信息 J(θ) = (1/σ²)∫ |∂f/∂θ · S_d(ω)|² dω。若 d 的激励能量在敏感频带 Ω_θ 上为 0，则 J(θ) = 0，θ 不可辨识，U_prog^epi 无法下降。要点：**不激励就不可能知道身体坏在哪**；信息增益正比于敏感频带的激励能量。系：健康系统在无激励时 U_prog^epi 无法通过被动观测大幅下降（轴承早期的弱故障频率常被运动噪声淹没），这解释了为何「预测性维护」必须主动做「体检式」激励而非只靠被动监测。

**引理 20（体检-磨损的最优权衡 / 观测者效应）** 设单位激励能量带来信息增益 J'(E) 与新增磨损 g·E。净收益 V(E) = v·I(E) − g·E，其中 v 为健康信息对维护决策的边际价值。若 I 关于 E 凹（信息饱和），则最优激励 E* 满足 v·I'(E*) = g，**E* 有限且严格小于最大允许幅值**；当 v·I'(0) < g 时 E* = 0（健康时最优点是「不体检」）。系：**最优体检频率随退化风险升高而升高、随磨损敏感度升高而降低**；把激励设到最大幅值「图省事」在数学上永远次优且会加速失效。

**引理 21（删失下的 RUL 乐观偏差）** 设真实寿命 T ~ F，维护在 c 处右删失。只用失效样本做 naive MLE 得到 F̂，则对任意 t，F̂(t) ≥ F(t)（随机占优意义下低估生存），即 RUL 被系统性低估寿命 / 高估剩余（乐观）。证：删失样本的似然贡献 S(c) 被丢弃，等价于对长寿命截断加权，使估计偏向短寿命 → 反推 RUL 时反而把「未失效」误读为「无信息」。采用定义 318 的删失感知似然可消除该偏差；保形区间进一步给出有限样本覆盖，避免「点估计乐观 + 零宽度区间」的双重自信。

**定理 18（SOMA 严格包含 R69）** 在 A99–A101（退化随机过程单调、激励损伤非负、健康后验可读且覆盖达标）下：在任意状态，SOMA 的期望任务风险 ≤ R69；且在不朽身体极限（U_prog=0、d=∅、T_safe=∞、无维护）时两者**逐指令相同**（定义 317、326）。因此 R69 是 SOMA 在「身体不老化」边界上的退化：世界侧逻辑一字不改，新增的只是更早看见衰败并在正确时刻停下的能力。

**定理 19（无相互背书 / 双时间尺度稳定性）** 在租约契约（定义 321–322）下，必不存在持续区间使快环松弛 F_t>0 与慢环松弛 M_t>0 同时成立而 h_t 仍在退化。证略：健康预算 B_t = T_safe(h_t) + 维护储备在无维修时依退化过程几乎必然单调下降；任一环若按私有乐观信念签发/接受松弛，则租约检查（同后验 hash 校验）失败，另一环强制升级为最保守（derate/stop）。故「两个都说不归我管」的稳态被机制性排除；系统至多在一个时间尺度上松弛，另一个必约束。

**定理 20（维护与激励的平滑降级）** 诊断性激励 d 经 C-RAS-WM 认证后瞬时物理风险 ≤ ε_diag；维护动作 m 只改变 λ 与任务可行性，不改安全包络；T_safe 随健康证据单调不增、λ 经 ρ(·) 单调不降；迟滞带（定义 325）排除阈值抖动 ⇒ 控制连续、无突变，且 R68 定理 15 的换装/提交不变式保持。

## 6. 本轮最大风险

**一句话**：SOMA-RAS 把「停下来修」的希望押在 RUL 分布上，而 RUL 模型恰恰是从**被维护截断、被日志投毒、被振动欺骗**的历史里学出来的乐观主义者；更糟的是**体检本身伤身**——激励既可能被恶意放大成造伤指令，也可能因信息饱和而被系统性地过度使用，于是系统在「我很健康，所以多测几下」与「还能撑，所以先别修」之间，用自己制造的磨损和过度乐观的预测，把可维护的退化拖成不可逆的失效。

**次级风险与缓解**：
1. **体检加速失效**（观测者效应）→ 引理 20 的最优激励幅值 + 磨损预算硬约束 + 定义 316 入证书；
2. **快慢环相互背书** → 定义 321–322 的同后验租约 + 定理 19 的无相互背书不变式；
3. **删失/日志投毒导致 RUL 乐观** → 删失感知似然 + 保形覆盖 + 健康校准门 HCG + 租约哈希可验证；
4. **振动/频谱欺骗** → 三源健康证据三角（IMU/Δa/r_res）+ ℰ_vibe 对抗训练；
5. **Goodhart 抑制报警** → 审计健康监测本身（是否滤掉故障频带）+ E311 盲化检出；
6. **慢环把快环拖进不可预期的任务变更** → 维护动作只在租约到期前触发、经同一 C-RAS-WM 认证、迟滞防抖。

## 3. 关键算法伪代码

# IP-264 PIM：本体感觉健康通道（快环只读）
def pim_features(imu_win, z, kin):
    r_imu = norm(imu_win.acc - kin.predict_inertial(z).acc)  # 世界 vs 自身
    s = spectral_fingerprint(envelope_spectrum(imu_win))     # 边带/分频带/峭度

# IP-266 DEX：朝内的体检（VoI 扣磨损成本；健康时最优点是不体检）
def choose_excitation(h_post, budget, c_ras_wm):

    for d in excitation_candidates(h_post):
        if not budget.wear_allow(d) or not c_ras_wm.certify_diag(d): continue
        score = fisher_info_gain(h_post, d) - social_cost(d) - kappa*expected_damage(d)
        if best is None or score > best.score: best = (d, score)
    return best if best and best.score > 0 else None        # 无利可图 → 不体检

# IP-265/267 HSD：删失感知更新 + 保形 RUL 区间
def update_health(h_post, y_d, maint_log):
    h_post = bayes_update(h_post, y_d, lik='censoring_aware')
    return h_post, conformal_survival(h_post, alpha=ALPHA)  # (L_alpha, U_alpha)

# IP-269 HMS：慢环维护调度（只在租约到期前决策）
def maintenance_policy(h_post, rul, lease, cost):
    if lease < T_MISSION*(1-DELTA): return argmin_cost(['derate','schedule','stop'], h_post, rul, cost)
    if rul.lower < T_MISSION:      return 'schedule'
    return 'continue'

# IP-275 SOMA 主闭环（R69 世界侧不变；读同一份健康后验）
def SOMA_RAS_round(M, obs):
    z, o = M.mtm.forward(...)
    # --- R69 世界侧（逐指令不变）---
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    g = M.mint.choose_interaction(modes, o, M.budget) if U_epi > TAU_EPI else None
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    # --- R70 自身侧（新增）---
    r_imu, s = M.pim(obs.imu, z, M.kin)                    # 第三正交通道
    if M.het.agreement(s, a_hat, M.last_r_res) >= K_AGREE:
        M.h_post = M.hsd.update(M.h_post, s)
    d = M.dex.choose_excitation(M.h_post, M.budget, M.c_ras_wm)
    if d is not None:
        M.h_post, M.rul = M.hsd.update_health(M.h_post, execute_excitation(d), M.maint_log)
    lease = M.mct.derive_lease(M.h_post)                   # 健康租约
    # --- 风险缩放与慢环 ---
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor)) * rho(lease / T_MISSION)
    m   = M.hms.maintenance_policy(M.h_post, M.rul, lease, M.cost)
    if m in ('derate', 'stop'): lam = max(lam, LAM_MAINT)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_s.submit_async(d, s, lease, m)
    return k, lam, mode, m, lease
```

## 4. 推导

**引理 19（退化的持续激励可辨识性）** `J(θ)=(1/σ²)∫|∂f/∂θ·S_d(ω)|²dω`；若激励在敏感频带 `Ω_θ` 上无能量则 `J(θ)=0`，`U_prog^epi` 不可降。系：被动监测抓不到被运动噪声淹没的早期弱故障，**要知健康必须主动体检**。

**引理 20（体检-磨损最优权衡 / 观测者效应）** `V(E)=v·I(E)−g·E`，I 凹 ⇒ 最优 `E*` 满足 `v·I'(E*)=g` 且 `E*<E_max`；当 `v·I'(0)<g` 时 `E*=0`（健康时不体检）。系：把激励设到最大幅值「图省事」永远次优且加速失效。

**引理 21（删失下 RUL 乐观偏差）** 仅用失效样本做 naive MLE 会丢弃删失样本的 `S(c)` 贡献，随机占优意义下低估生存 / 高估剩余寿命；删失感知似然消除偏差，保形区间给出有限样本覆盖，避免「点估计乐观 + 零宽区间」双重自信。

**定理 18（SOMA 严格包含 R69）** `A99–A101` 下 SOMA 期望任务风险 ≤ R69；不朽身体极限（`U_prog=0, d=∅, T_safe=∞`）时逐指令相同；世界侧逻辑一字不改，新增的是更早看见衰败并在正确时刻停下。

**定理 19（无相互背书 / 双时间尺度稳定）** 租约契约下，健康预算 `B_t` 无维修时几乎必然单调下降 ⇒ 不存在 `F_t>0 ∧ M_t>0` 且 h_t 仍退化的持续区间；任一环按私有乐观信念签发/接受松弛即触发同后验哈希校验失败，另一环升级为最保守。故至多一个时间尺度松弛。

**定理 20（维护与激励的平滑降级）** d 经认证后瞬时风险 ≤ ε_diag；m 只改 λ 与任务可行性、不改安全包络；`T_safe` 单调不增、ρ 单调不降、迟滞防抖 ⇒ 控制连续无突变，R68 定理 15 换装/提交不变式保持。

## 7. 本轮最大风险

**一句话**：SOMA-RAS 把「停下来修」的希望押在 RUL 分布上，而 RUL 模型恰恰从**被维护截断、被日志投毒、被振动欺骗**的历史里学成一个乐观主义者；更糟的是**体检本身伤身**——激励既可能被恶意放大成造伤指令，也可能因信息饱和而被系统性过度使用，于是系统在「我很健康，所以多测几下」与「还能撑，所以先别修」之间，用自己制造的磨损和过度乐观的预测，把可维护的退化拖成不可逆的失效。

**次级风险与缓解**：体检加速失效（引理 20 最优幅值 + 磨损硬预算 + 定义 316 入证书）；快慢环相互背书（同后验租约 + 定理 19）；删失/日志投毒致 RUL 乐观（删失感知似然 + 保形覆盖 + HCG + 租约哈希）；振动频谱欺骗（三源三角 + ℰ_vibe 对抗）；Goodhart 抑制报警（审计健康监测本身 + E311）；慢环把快环拖入不可预期任务变更（维护只在租约到期前触发、同一认证、迟滞防抖）。
