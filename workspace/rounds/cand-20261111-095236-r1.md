# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「视觉语言模型」×「语义分割」）

> 第 54 轮已把技能组合推进到动作空间剖面 α_S 与云边动作双证书。本轮补上一直缺席的一环——**从“词”到“像素”再到“动作”的语义接地桥**。核心矛盾：H22：VLM 给出开放词汇的语义先验，但先验是语言的、不是像素的，它能流畅断言“抓住把手”而分割里根本没有对应区域；H23：分割是闭集词表、像素精确的，却缺乏开放概念与跨域泛化，且其误差恰集中在边界带，而边界带正是抓取、放置、避障最危险处。语义与像素的断层，会沿 α_S 一路传导为错误动作。

## 0. 直觉与动机

**灵感 1（双通道：语言先验 × 像素证据）**
直觉：VLM 与分割不是替代关系，而是两条必须互证的通道。VLM 开放、会联想、也会幻觉；分割闭集、像素精确、但词表窄。一个概念只有同时满足“VLM 命名”与“分割有支撑区域”才算接地（grounded）。单通道成立就动作 = 拿幻觉当依据。因此引入双通道一致性 `cons(c)`，把“说得通”降级为“看得见且说得通”。

**灵感 2（语义可供性：把概念接进动作空间）**
直觉：第 54 轮的技能剖面 `α_S(a)` 回答“动作能不能做”，却没回答“在哪个像素上做”。补一层语义可供性 `aff_S(c,x)`：概念 c 在像素 x 上对该技能是否可执行。于是任务语言 ℓ 的落地链变为 `ℓ → C_ℓ=VLM(ℓ) → gr(c,I)（分割区域） → M_T（可供性掩码） → 动作序列`。α_S 是动作维，M_T 是空间维，二者缺一不可。

**灵感 3（边界即风险）**
直觉：分割的像素误差不是均匀的，几乎全部堆在区域边界带 `B_ε`。而抓取点、放置接触面、避障安全距离，往往恰好落在这条带子上。把边界带占比映射为鲁棒性谱的新维度 `ρ_bd`，与第 53 轮的 ρ、第 54 轮的 α_S 联动——这是“感知不确定性如何变成动作风险”的最短路径。

**灵感 4（云语义、边像素：与动作粗细分层同构）**
直觉：VLM 大、慢、开放，适合云端做概念解析与技能序；分割小、快、像素准，适合边端做实时接地与边界监测。云端产出语义计划 `P_s = ⟨C_ℓ, S_1..S_k, A_c⟩`，边端产出接地证据 `G_e = (区域, 置信, 边界距离)`；一旦出现 `ungrounded` 或 `ρ_bd < ρ_min`，经反向信道 `Explain_sem` 回传，云端重映射概念或重规划。这与第 54 轮的 `A_c/A_e` 粗细分层完全同构：**语义粗、像素细**。

**灵感 5（接地证书：让证据否决话术）**
直觉：VLM 的幻觉不能靠“再问一次 VLM”消除，只能靠像素证据否决。故把第 54 轮联合证书扩展为 `J+ = (ρ, A_cert, γ_ce, δ_a, σ_gr, S_evi)`，其中 `σ_gr` 是语义接地质量、`S_evi` 是分割像素证据（区域、cons、边界距离）。没有 `S_evi` 的语义断言一律不进入部署判定。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（语义接地函数）**
给定任务语言 ℓ 与图像 I。VLM 输出概念集合 `C_ℓ = {(c_i, w_i)}`，`w_i∈[0,1]` 为概念置信。分割器 `Seg(I) = (L_map, U_map)`，`L_map: Ω→L∪{∅}` 为像素标签，`U_map: Ω→[0,1]` 为像素不确定度。接地映射 `gr(c,I) = ∪_{l∈h(c)} {x | L_map(x)=l}`，其中 `h: C→2^L` 为概念到闭集标签的映射；若 `h(c)=∅`，记 `gr(c,I)=∅` 且 c 为 `ungrounded`。

**定义 122（语义可供性剖面）**
技能 S 的语义可供性 `aff_S : C × Ω → [0,1]`。给定 C_ℓ，任务可执行掩码
`M_T(ℓ,I) = { x | ∀ c∈C_ℓ, aff_S(c,x) ≥ θ_aff 且 x∈gr(c,I) }`。
接地可行要求 `M_T ≠ ∅` 且 `gr(c,I) ⊇ M_T` 对所有 `c∈C_ℓ` 成立。

**定义 123（双通道一致性）**
`cons(c) = 1 - |w_c - supp(c)|`，其中 `supp(c) = |gr(c,I)| / |Ω_c|` 为归一化像素支撑，`Ω_c` 为图像有效区。接地通过条件：
```
∀ c∈C_ℓ:  cons(c) ≥ θ_cons  ∧  gr(c,I) ≠ ∅
```
否则该概念被标记 `ungrounded/weak`，任务整体不得进入动作规划。

**定义 124（边界敏感风险维度）**
边界带 `B_ε = { x | dist(x, ∂L_map) ≤ ε }`。边界风险
`r_bd(S) = P( M_T ∩ B_ε ≠ ∅ ∧ contact(S) ⊆ B_ε )`，
新增鲁棒性维度 `ρ_bd(S) = 1 - r_bd(S)`，并入 ρ 谱。

**定义 125（语义接地技能图与云边语义契约）**
语义接地图 `G_sem=(V,E_sem)`，边 `(i,j)∈E_sem` 当且仅当：
```
compat_α(S_i,S_j) ≥ θ_a  ∧  compat_sem(S_i,S_j|ℓ,I) ≥ θ_s  ∧  min_c cons(c) ≥ θ_cons
```
其中 `compat_sem = |M_i∩M_j| / |M_i∪M_j|`（可供性掩码 Jaccard）。边证书 `C_sem=(M_overlap, cons_min, ρ_bd)`。
云边语义契约 `C_se = (P_s, G_e, γ_se, Explain_sem, Δ_s)`：`P_s` 云端语义计划；`G_e` 边端接地证据；`γ_se: C→2^L` 保序概念映射；`Explain_sem` 回传 `ungrounded / boundary_risk / weak_cons`；`Δ_s` 语义-像素对齐误差上界。

**定义 126（语义增强联合证书）**
`J+ = (ρ, A_cert, γ_ce, δ_a, σ_gr, S_evi)`，其中 `σ_gr = min_{c∈C_ℓ} cons(c)`，`S_evi` 至少含分割区域、cons、边界距离。部署条件：
```
dom_J(T)=in ∧ δ_a < Θ_a ∧ σ_gr ≥ σ_min ∧ ρ_bd ≥ ρ_min(bd)
```

## 2. 关键算法 伪代码

### IP-121 SAG（Semantic Affordance Grounding）

```python
def semantic_ground(instruction, image, vlm, seg, h):
    concepts = vlm.parse(instruction)              # [(c, w_c)]
    L_map, U_map = seg.predict(image)
    grounding = {}
    for c, w in concepts:
        labels = h(c)                              # 概念 -> 闭集标签
        if not labels:
            grounding[c] = Grounding(c, empty, 0.0, w, 'ungrounded')
            continue
        region = union([(L_map == l) for l in labels])
        supp = area(region) / area(valid(L_map))
        grounding[c] = Grounding(c, region, supp, w, 'candidate')
    return concepts, grounding, (L_map, U_map)

def afford_mask(skill, concepts, grounding, theta_aff=0.5):
    M = full(image_domain, True)
    for c, _ in concepts:
        g = grounding[c]
        M &= {x for x in g.region if skill.aff(c, x) >= theta_aff}
    return M
```

### IP-122 DCC（Dual-Channel Consistency）

```python
def dual_channel_consistency(concepts, grounding, theta_cons=0.6):
    report = {}
    for c, w in concepts:
        g = grounding[c]
        if g.is_empty:
            report[c] = ('ungrounded', 0.0)
            continue
        cons = 1.0 - abs(w - g.support)
        report[c] = ('ok' if cons >= theta_cons else 'weak', cons)
    ok = all(k == 'ok' for k, _ in report.values())
    return ok, report
```

### IP-123 BSR（Boundary-Sensitive Risk）

```python
def boundary_risk(grounding, L_map, epsilon, contact_prior):
    B = dilation(boundary(L_map), epsilon)
    r = 0.0
    for c, g in grounding.items():
        if g.is_empty:
            continue
        frac = area(g.region & B) / max(area(g.region), 1)
        r = max(r, frac * contact_prior.get(c, 1.0))
    return r, 1.0 - r          # (r_bd, rho_bd)
```

### IP-124 SGG（Semantic Grounding Graph）

```python
def build_semantic_graph(skills, instruction, image, theta_a, theta_s, theta_cons):
    concepts, grounding, (L_map, _) = semantic_ground(instruction, image, vlm, seg, h)
    ok, cons = dual_channel_consistency(concepts, grounding, theta_cons)
    if not ok:
        return ('reject', 'semantic_ungrounded', cons)
    G = nx.DiGraph()
    for i, s1 in skills:
        for j, s2 in skills:
            if i == j:
                continue
            if jaccard(s1.alpha, s2.alpha) < theta_a:
                continue
            m1 = afford_mask(s1, concepts, grounding)
            m2 = afford_mask(s2, concepts, grounding)
            if m1 == empty or m2 == empty:
                continue
            sem = jaccard(m1, m2)
            if sem < theta_s:
                continue
            rb, rho_bd = boundary_risk(grounding, L_map, EPS, CONTACT_PRIOR)
            G.add_edge(i, j, compat=jaccard(s1.alpha, s2.alpha), sem=sem,
                       cons_min=min(v[1] for _, v in cons.items()), rho_bd=rho_bd)
    return ('ok', G, grounding)
```

### IP-125 CESC（Cloud-Edge Semantic Coordination）

```python
def cloud_edge_semantic(instruction, G, A_c, edge_seg, gamma_ce, h, rho_min):
    P_s, cost = cloud_semantic_plan(instruction, G, A_c)     # 云端 VLM 慢路径
    P_e, evidence, reports = [], [], []
    for sid, c_set, a_c in P_s:
        a_e = gamma_ce(a_c)
        g_e = edge_seg.ground(c_set, h)                      # 边端像素快路径
        ok, cons = dual_channel_consistency(c_set, g_e, THETA_CONS)
        if not ok:
            reports.append(('ungrounded', sid, explain_sem(cons)))
            continue
        rb, rho_bd = boundary_risk(g_e, edge_seg.last_Lmap, EPS, CONTACT_PRIOR)
        if rho_bd < rho_min:
            reports.append(('boundary_risk', sid, rb))
        evidence.append(g_e)
        P_e.append((sid, a_e, rho_bd))
    if reports:
        return ('reprofile', reports)                        # 反向解释回传
    return ('ok', P_e, evidence)
```

### IP-126 SJC（Semantic Joint Certificate）

```python
def semantic_joint_certificate(skill_seq, grounding, gamma_ce,
                               delta_a_budget, sigma_min, rho_min):
    M = intersection([afford_mask(s, grounding) for s in skill_seq])
    if M == empty:
        return ('reject', 'no_shared_affordance')
    cons_min = min(cons for _, cons in grounding.values())
    r_bd, rho_bd = boundary_risk(grounding, last_Lmap, EPS, CONTACT_PRIOR)
    if cons_min < sigma_min:
        return ('reject', 'semantic_ungrounded', cons_min)
    rho_comp = compose_robustness_chain([s.rho for s in skill_seq], K)
    rho_comp['bd'] = rho_bd
    delta_a = max_alignment_error(gamma_ce, M)
    if delta_a > delta_a_budget or min(rho_comp.values()) < rho_min:
        return ('reject', 'budget_exceeded', delta_a, rho_comp)
    return ('ok', JCertPlus(rho_comp,
                            A_cert=(M, buffer_zone(M, delta_a)),
                            gamma_se=h, sigma_gr=cons_min,
                            evidence=grounding))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SAG | O(|C_ℓ|·|Ω|) | O(|C_ℓ|·|Ω|) | 概念召回、h 覆盖闭集标签 |
| DCC | O(|C_ℓ|) | O(|C_ℓ|) | 置信-支撑校准、θ_cons sound |
| BSR | O(|Ω| + |C_ℓ|·|B_ε|) | O(|Ω|) | 边界带 ε 与接触先验校准 |
| SGG | O(|S|²·|Ω|) | O(|S|²+|Ω|) | 双通道闸门先于图搜索 |
| CESC | O(|P_s|·|C_ℓ|·|Ω| + |V|log|V|) | O(|V|+|E|) | γ_se 保序、Explain_sem 收敛 |
| SJC | O(|S|·|Ω| + |𝔇_ρ|) | O(|Ω|+|𝔇_ρ|) | 接地先验 sound、δ_a 闭合 |

**正确性定理（Semantically Grounded Composition Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** VLM 对任务概念的召回率 ≥ 1-β_V，且 `h: C→2^L` 在闭集标签上保序且覆盖；**(A30)** 分割的像素精度与边界不确定度在校准集上获得可靠估计；**(A31)** `Explain_sem` 往返延迟 ≤ τ_sem；**(A32)** 边界接触先验 `contact_prior` 有界。
则：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
            - β_V - P(σ_gr<σ_min) - P(M_T ∩ B_ε ≠ ∅)
```
关键：**语义断言先由像素证据放行**，**边界风险作为独立维度进入 ρ**，**开放概念必须落到闭集标签才可执行**。

| 风险 | 等级 | 缓解 |

| VLM 概念幻觉被像素支撑误放行 | 高 | 双通道一致性 + 区域最小面积 + 红队反例 |

## 6. 本轮最大风险

**一句话**：语义接地让系统第一次“说得通也要看得见”，但它的 soundness 同时依赖 VLM 概念召回、分割像素校准与概念-标签映射保序；一旦 VLM 幻觉恰好被一个宽而模糊的分割区域“接住”，双通道一致性会给出虚假放行，动作便会在错误像素上执行——这是比纯动作层更隐蔽的负迁移，必须以 **最小支撑面积约束 + 边界带独立否决 + 跨域语义迁移证书** 三重护栏，宁可拒绝开放概念，也不让“看起来很接地的幻觉”进入部署。

```python
        g = grounding[c]
        if g.is_empty:
            report[c] = ('ungrounded', 0.0); continue
        cons = 1.0 - abs(w - g.support)
        report[c] = ('ok' if cons >= theta_cons else 'weak', cons)
    ok = all(k == 'ok' for k, _ in report.values())
    return ok, report
```

### IP-123 BSR

```python
def boundary_risk(grounding, L_map, epsilon, contact_prior):
    B = dilation(boundary(L_map), epsilon)
    r = 0.0
    for c, g in grounding.items():
        if g.is_empty: continue
        frac = area(g.region & B) / max(area(g.region), 1)
        r = max(r, frac * contact_prior.get(c, 1.0))
    return r, 1.0 - r          # (r_bd, rho_bd)
```

```python
def build_semantic_graph(skills, instruction, image, theta_a, theta_s, theta_cons):
```

```python
def semantic_joint_certificate(skill_seq, grounding, gamma_ce,
                               delta_a_budget, sigma_min, rho_min):
    M = intersection([afford_mask(s, grounding) for s in skill_seq])
    if M == empty:
        return ('reject', 'no_shared_affordance')
    cons_min = min(cons for _, cons in grounding.values())

    if cons_min < sigma_min:
        return ('reject', 'semantic_ungrounded', cons_min)

    delta_a = max_alignment_error(gamma_ce, M)
    if delta_a > delta_a_budget or min(rho_comp.values()) < rho_min:
        return ('reject', 'budget_exceeded', delta_a, rho_comp)
    return ('ok', JCertPlus(rho_comp,
                            A_cert=(M, buffer_zone(M, delta_a)),

                            evidence=grounding))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SAG | O(|C_ℓ|·|Ω|) | O(|C_ℓ|·|Ω|) | 概念召回 ≥ 1-β_V，h 覆盖 |
| DCC | O(|C_ℓ|) | O(|C_ℓ|) | 置信-支撑校准，θ_cons sound |
| BSR | O(|Ω| + |C_ℓ|·|B_ε|) | O(|Ω|) | ε 与接触先验有界 |
| SGG | O(|S|²·|Ω|) | O(|S|²+|Ω|) | 双通道闸门先于图搜索 |
| CESC | O(|P_s|·|C_ℓ|·|Ω| + |V|log|V|) | O(|V|+|E|) | γ_se 保序，Explain_sem 收敛 |
| SJC | O(|S|·|Ω| + |𝔇_ρ|) | O(|Ω|+|𝔇_ρ|) | 接地先验 sound，δ_a 闭合 |

**正确性定理（Semantically Grounded Composition Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** VLM 对任务概念召回率 ≥ 1-β_V，且 `h: C→2^L` 保序且覆盖；**(A30)** 分割像素精度与边界不确定度已校准；**(A31)** `Explain_sem` 往返 ≤ τ_sem；**(A32)** 接触先验有界。
则部署成功概率：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
            - β_V - P(σ_gr<σ_min) - P(M_T ∩ B_ε ≠ ∅)
```
关键：**语义断言必须先由像素证据放行**，**边界风险独立进入 ρ**，**开放概念须落到闭集标签才可执行**。

## 5. 本轮最大风险

**一句话**：语义接地让系统第一次“说得通也要看得见”，但它的 soundness 同时依赖 VLM 概念召回、分割像素校准与概念-标签映射保序；一旦 VLM 幻觉恰好被一个宽而模糊的分割区域“接住”，双通道一致性会给出虚假放行，动作便会在错误像素上执行——这是比纯动作层更隐蔽的负迁移，必须以 **最小支撑面积约束 + 边界带独立否决 + 跨域语义迁移证书** 三重护栏，宁可拒绝开放概念，也不让“看起来很接地的幻觉”进入部署。
