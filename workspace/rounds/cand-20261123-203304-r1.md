灵感驱动研究循环·新灵感三元组第 1 轮；本轮灵感：「云边协同」×「动作空间」）

> **基线**：第 2 轮产出 MetricVoiceGauge-NCD-HUTDH-v22+IP-431–435（PGEV 分层能量/机械臂/深度感知层；其上承 v21 的 SDC/CAC/DCL/GIC/HPC+/CFC+、v20 的 PCA/CTS/CFC/HPC、v19 的 DCM/OGCC/CCV/DRS/OGC、v17 的 CLP/S2C/HCG/PSV/APS/AMC）。
> 本轮纪律：**云端只能是"会过期的可验证证据"，永远不是实时安全回路的一环；实时安全必须由边缘本地的、策略无关的动作空间护盾保证**。不推倒 v22：HDL/ACSC/DCSC/HPC-E/CFC++ 全部保留，v21/v20/v19/v17 全部保留。本轮只做一件事：**把 v22 的"计划级、离线、与具体规划器耦合"的证书，下沉为"云端可编译、边缘可独立验证、控制层可 O(1) 投影"的动作空间护盾；并用护盾的可行性替代 v22 中动辄 SafeStop 的退化路径，从而在不扩大认证安全集的前提下挽回活性**。

## 0. 直觉与动机

**灵感 1（云边协同 → 证书是带版本、有效期与证明的"承诺"，边缘必须能独立兑付）**
直觉：v22 把重计算留在车端/边缘本地，代价是每台机器人都要独立承担全局推理（全局地图、规则库编译、conformal 大样本校准、多机让行）。云恰好擅长这些"慢而贵、且可跨机共享"的事。但云有两个致命属性：**时延不可控**（几十到几百毫秒乃至断连）与**内容不可全信**（可能过期、可能被篡改、可能基于错误的全局假设）。因此正确的分工不是"云决策、边缘执行"，而是：**云签发承诺 (commitment)，边缘独立验证 (verification)，控制层本地兑付 (redemption)**。一条云消息不是命令，而是 `C = (payload, proof, version, φ_valid)`：`proof` 可在边缘 O(1) 或 O(log n) 复核，`φ_valid` 显式写出"这条承诺在什么状态、什么时间、什么通信/定位条件下才成立"。一旦 `φ_valid` 被破坏，边缘**不是猜测、而是回落到自己本地就能证明的硬安全集**。核心创新：**云边承诺协议 (Cloud-Edge Commitment Protocol, CECP)** 与 **本地可验证承诺 (Locally Verifiable Cloud Commitment, LVCC)**。

关键反直觉点 1：**云不能"授予"动作，只能"收缩"或"有偿赎回"**。v22 的 P34 已把"自由空间只能被有证赎回"立为铁律；云边协同必须继承它——云端降低保守性（例如用全队证据证明某处无人）只算**赎回**，且赎回额度不得超过边缘本地证书允许的 `A_soft \ A_hard`；云**永远不能**把动作集扩到边缘硬核 `A_hard` 之外。这条"硬核不可云端扩张"性质，正是断连时安全仍可证的根基。

关键反直觉点 2：**断连不是安全故障，只是活性故障**。只要逐点 `A_hard(s) ⊆ A_safe(s) ⊆ A_soft(s)`，云失联、承诺过期、时钟漂移、签名失效都只会让 `A_safe` 从 `A_cloud` 收缩回 `A_hard`：事故率不升，只是更早停车。把"通信质量"从安全属性降级为活性属性，是本轮最重要的结构性收益。

**灵感 2（动作空间 → 证书应当约束"此刻能做什么"，而不是"未来几秒走哪条轨迹"）**
直觉：v22 的 HPC-E 认证的是**计划/轨迹**，它天然与具体规划器耦合，而且一旦计划失败，唯一体面的出口是 SafeStop。可真正的实时系统在每个控制周期只需回答一个更小的问题：**在当前状态 s 下，哪些动作 a 能保证下一状态仍留在已认证安全集内？** 这正是**控制不变集 / 生存核 (viability kernel)** 的语言。令 `K ⊆ S_v22` 为 v22 认证安全状态集内的受控不变子集，`A_safe(s) = { a ∈ A : f(s,a) ∈ K_inner }`。任何策略 π（包括端到端学习策略）都通过**护盾投影** `a = Π_{A_safe(s)} π(s)` 执行。核心创新：**动作空间证书 (Action-Space Certificate, ASC) / 安全护盾 (Shield)**。

关键反直觉点 3：**护盾不是"多一层限制"，而是把"不可行"从"停机"变成"改选"**。v22 的死锁与活性坍缩，本质是"计划一旦全被过滤就只剩 SafeStop"。而只要 `A_safe(s) ≠ ∅`，机器人总能在不变集内换一个动作继续存活——这正是对 v22 最大风险（层级退化振荡、臂能耗过度保守导致活性归零）的直接解药。只有当 `A_safe(s) = ∅`（真正不可生存）时，SafeStop 才是唯一诚实的选择。

关键反直觉点 4：**离散化会制造假的"安全动作"**。无论用离散动作原语表还是连续 CBF-QP，`A_safe` 都只能在**内近似** `K_inner ⊆ K` 上计算；若把边界动作当成安全，量化误差会让真实下一状态落到 `K` 外。故 ASC 必须使用内近似 + 保守裕度，并把"动作空间分辨率"显式计入证书，而非藏在实现细节里。

**灵感 3（统一：动作空间是此前所有证书的"汇合点"）**
直觉：v22 的几何、规范、负信息、能量、机械臂、深度感知，此前各自在不同抽象层上过滤"计划"。但它们在物理上最终都只是对**同一个控制动作 `a`** 的约束：几何约束限制 `a` 不让碰撞裕度变负；DCL 的 F 规则直接收缩 `a` 的允许集，O 规则要求 `a` 的前缀能进入让位集；能量约束要求 `a` 的功率积分不击穿储备；机械臂约束要求 `a` 不穿越配空间边界。于是统一写成：

`A_safe(s) = A_geo(s) ∩ A_dcl(s) ∩ A_energy(s) ∩ A_arm(s) ∩ A_cloud(s) ∩ A_intent(s)`

每一项都由一个既有证书编译而来，**没有引入任何新的授权来源**；交运算天然保证"最严者胜"，也天然保证 `Exec_v23 ⊆ Exec_v22`。云的角色是把其中最贵、最可共享的项（全局几何、规则编译、护盾模板）预编译成 CECP 承诺；边缘负责把本地项与云端承诺求交并投影。

关键反直觉点 5：**护盾会改变被执行的动作分布，因此策略层的 conformal 覆盖对"护盾后"的轨迹不再自动成立**。若 DCSC/GIC 的 1-α 是在原始策略分布上校准的，投影后分布漂移，覆盖可能失效。正确做法是把 conformal 校准对象改成**"策略 + 护盾"的合成系统**，并证明护盾是确定性可测映射；否则所有基于策略分布的统计保证都会在护盾处悄悄漏掉。

## 1. 研究问题（轮次升级版）

- **Q12（云端承诺的本地可验证性与失效安全）**：如何设计 CECP 使一条云承诺在边缘以 O(1)/O(log n) 复核（merkle 版本链 + 简洁证明），并把"过期/断连/时钟漂移/内容篡改/全局假设失配"统一编译为 `φ_valid` 的失败？如何定义 `A_hard ⊆ A_safe ⊆ A_soft` 的逐点包含，使云只能赎回 `A_soft \ A_hard`、永不扩张硬核，从而让断连只损失活性？多机器人共享同一承诺时，版本回滚与分叉如何检测并保守消解？

- **Q13（护盾的不变性、可行性与活性）**：如何从 v22 的 `Exec_v22` 计算内近似受控不变集 `K_inner`（离散：生存核迭代/不动点；连续：CBF-QP / 多面体不变集）？动作空间量化误差如何显式计入不变性证明而不导致空集？何时 `A_safe(s)=∅`（真正不可生存）与何时只是"当前策略没有安全动作"（应改选而非停机）如何区分？1kHz 控制环下投影的 O(1) 复杂度如何保证？

- **Q14（分层动作空间的嵌套与无振荡退化）**：如何保证 `A_op(s) ⊆ A_tac(s) ⊆ A_str(s) ⊆ A(s)`，并在某层不可满足时只降级到父层默认而不到 SafeStop？v22 的层级 PGEV 与动作空间护盾如何对齐，避免"能量层满足/操作层碰撞"的跨层振荡（滞回、单调查询、层级一致性票据）？

- **Q15（护盾-策略合成的统计有效性与时延）**：如何在"策略 + 确定性护盾"的合成分布上重新做 conformal 校准，使 DCSC/GIC 的 1-α 覆盖在投影后仍成立？感知/定位时延 τ_d 使边缘按 `ŝ(t-τ_d)` 投影而真实状态已漂移，如何用状态不确定性膨胀 δ_state 把 `A_safe(ŝ)` 扩成对真实状态仍安全的 `A_safe^δ(ŝ)`，且不因过度膨胀而让 `A_safe` 长期为空？

## 2. 设计原则（在 P37/P41/P42 基础上新增 P43–P46）

**P43 云边证据分层律（Cloud-Edge Evidence Stratification）**
对每个状态 s 定义三个动作集：边缘硬核 `A_hard(s)`（仅由边缘本地可独立验证的 v22 证书交集产生，**永不因云端信息扩张**）、云端承诺集 `A_cloud(s)`（由有效 CECP 承诺给出，要求 `A_hard(s) ⊆ A_cloud(s) ⊆ A_soft(s)`）、保守集 `A_soft(s)`（无任何赎回时的最保守允许集）。实际执行集：若 `φ_valid` 失败则 `A_safe(s) = A_hard(s)`，否则 `A_safe(s) = A_hard(s) ∩ A_cloud(s)`。云只能**在硬核之上收缩、或在 `A_soft \ A_hard` 内赎回**，绝不触碰硬核。故断连、过期、篡改均只使 `A_safe` 收缩，`Exec_v23 ⊆ Exec_v22` 由构造保持。

**P44 动作空间前向不变律（Action-Space Forward Invariance）**
设 `K_inner ⊆ S_v22` 为 v22 认证安全状态集的受控不变内近似，`f` 为带界状态转移，`A_safe(s) = {a ∈ A : f(s,a) ∈ K_inner, a 满足 P43 的三集关系}`。任何策略 π 经 `a = Π_{A_safe(s)} π(s)` 执行。则 `s_t ∈ K_inner ∧ a_t ∈ A_safe(s_t) ⇒ s_{t+1} ∈ K_inner`（归纳即得不变性）。当且仅当 `A_safe(s)=∅` 时进入 SafeStop；只要非空，护盾必须改选而非停机。任何证书分量退化（几何/规范/能量/臂/云）都使 `K_inner` 与 `A_safe` 单调收缩。

**P45 分层动作空间嵌套律（Hierarchical Action Nesting）**
三层规划各诱导动作约束：`A_str(s) ⊇ A_tac(s) ⊇ A_op(s)`（战略设定能量/义务包络，战术细化轨迹族，操作给出即时动作）。任取 `a ∈ A_op(s)` 必然同时满足三层；上层不可满足时，下层退回父层默认动作集而非直接 SafeStop。层级迁移携带时间戳与滞回阈值，控制路径仅做 O(1) 交集查询，禁止在控制环内重算上层。该律把 v22 的分层 PGEV 与 P44 的护盾对齐，消除"能量层满足但操作层碰撞"的跨层振荡。

**P46 护盾-策略合成律（Shield-Policy Composition）**
对任意策略 π，实际执行的是确定性映射 `π̃ = Π_{A_safe} ∘ π`。凡声称 1-α 覆盖的 conformal 保证（DCSC 的检测误差界、GIC 的意图集、SPCC 的状态误差界），必须以 `π̃` 诱导的轨迹分布为校准对象，而非原始 π；否则投影造成的分布漂移使覆盖失效。状态估计不确定性以 δ_state 膨胀：护盾在 `A_safe^δ(ŝ) = {a : ∀ s ∈ Ball(ŝ, δ_state), f(s,a) ∈ K_inner}` 上投影，宁可收缩不可外扩。护盾本身不引入新的安全授权，只执行既有证书的交集。

## 3. 与基线的接口（如何退化）

- 云失联 / 承诺过期 / `φ_valid` 失败 ⇒ `A_safe = A_hard`（边缘硬核）⇒ 只损失活性，安全方向不变；
- 云端承诺被篡改或版本回滚 ⇒ merkle 复核失败 ⇒ 丢弃该承诺并回退硬核，同时记审计事件；
- ASC 求解超时（1kHz 环内）⇒ 退回 v22 的计划级 HPC-E；计划仍有效则按计划执行，否则 SafeStop；
- ASC 内近似为空（`K_inner=∅` 或 `A_safe=∅`）⇒ 真实不可生存 ⇒ SafeStop（唯一合法出口）；
- 动作量化过粗 / 状态不确定膨胀过大 ⇒ `A_safe` 收缩甚至长期为空 ⇒ 活性下降，但不产生假安全动作（内近似 + δ_state 膨胀只向保守）；
- DCSC/CFC++ 退化 ⇒ 对应动作约束项收缩 ⇒ 护盾更保守；
- 三者全失效 ⇒ 完全回退 v22 ⇒ `Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`（沿用引理 162）。
- **安全继承**：P43 保证硬核不被云端扩张；P44 保证不变集内步步安全；P45 保证层级只做交集；P46 保证统计保证作用于真正执行的合成系统。四者共同给出 `Exec_v23 ⊆ Exec_v22`。

## 4. 预期贡献

1. **云端承诺的本地可验证框架**：把"云决策"改写为"云签发可复核承诺 + 边缘独立兑付"，给出 `A_hard ⊆ A_safe ⊆ A_soft` 的三集分层与断连只损失活性的安全证明；
2. **策略无关动作空间护盾**：首次把 v22 的计划级证书编译为逐状态安全动作集 `A_safe(s)`，用受控不变内近似 `K_inner` 给出前向不变性，并把 SafeStop 从"计划失败"改写为"生存核为空"；
3. **分层动作空间嵌套**：`A_op ⊆ A_tac ⊆ A_str` 的嵌套与滞回退化，直接消除 v22 的跨层振荡与"能量满足但操作碰撞"风险；
4. **护盾-策略合成证书**：指出并对齐"投影导致分布漂移"这一统计陷阱，把 conformal 校准对象从策略改为 `π̃ = Π∘π`；
5. **云编译护盾模板与带宽感知刷新**：把最贵的护盾计算放到云，按信息价值/字节调度刷新，硬核永不在刷新路径上；
6. **安全继承闭环**：`Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`，且活性损失被限制在"通信/量化"层，而非安全层。

## 5. 本轮最大风险

**一句话**：护盾把"安全"从计划层下推到每个动作，但其全部保证建立在估计状态 `ŝ` 落在认证不变集 `K_inner` 内这一前提上；一旦定位漂移或时延使真实状态已在 `K_inner` 外、而护盾仍按 `ŝ` 投影，就会得到"从错误状态出发的合法动作"——这把 v22 的"计划误判"换成了更难察觉、且每一步都看似合规的"状态误判"。

## 0. 增量符号体系（定义 926–978）

## 1. 关键算法骨架（在 IP-431–435 骨架上扩展）

```python
from dataclasses import dataclass
from typing import Callable, Sequence

# IP-436 Cloud-Edge Commitment Protocol
@dataclass(frozen=True)
class Commitment:
    payload: dict        # {"kind": "shield_template", "K_inner": ..., "A_cloud": fn, ...}
    version: int
    parent_hash: bytes
    proof: bytes         # merkle 路径 / 签名 / 简洁证明，边缘可复核
    ttl: float
    valid: Callable     # φ_valid(s, now, link) -> bool

class CECP:
    def __init__(self, merkle, A_hard, A_soft_fn):
        self.merkle = merkle
        self.A_hard = A_hard             # 本地硬核，永不依赖云
        self.A_soft_fn = A_soft_fn
        self.current = None
        self.seen_version = -1

    def verify(self, C: Commitment, s, now, link) -> bool:
        if not self.merkle.verify(C.proof, C.h):        # O(log n)
            return False
        if C.version <= self.seen_version:               # 防回滚/重放
            return False
        if now > C.ttl:                                  # TTL 过期
            return False
        if abs(link.clock_skew) > link.delta_clock_max:  # 时钟不可信
            return False
        return bool(C.valid(s, now, link))               # φ_valid

    def redeem(self, s, now, link):
        C = self.current
        if C is None or not self.verify(C, s, now, link):
            return self.A_hard(s), "HARD_CORE"           # 断连/过期/篡改 → 硬核
        A_cloud = C.payload["A_cloud"](s)
        A_hard = self.A_hard(s)
        # 三集约束：硬核不许被扩张，云承诺不许越过保守集
        assert A_hard <= A_cloud <= self.A_soft_fn(s)
        return A_hard & A_cloud, "CLOUD_REDEEM"

    def accept(self, C: Commitment, s, now, link):
        if self.verify(C, s, now, link):
            self.current, self.seen_version = C, C.version
            return True
        return False

# IP-437 Action-Space Certificate / Shield
class ActionSpaceShield:
    def __init__(self, K_inner, dynamics, delta_state, eps_quant):
        self.K_inner = K_inner
        self.dynamics = dynamics
        self.delta_state = delta_state
        self.eps_quant = eps_quant

    def _uncertainty_samples(self, s_hat):
        # 在最坏状态球上取覆盖样本；保守时可取球的两个端点 + 中心
        return self.dynamics.cover_ball(s_hat, self.delta_state)

    def viable_actions(self, s_hat, A_base: Sequence):
        out = []
        for a in A_base:
            a_shrunk = self.dynamics.shrink(a, self.eps_quant)  # 量化内缩
            ok = True
            for s in self._uncertainty_samples(s_hat):
                for w in self.dynamics.worst_case_set():
                    if not self.K_inner.contains(self.dynamics.step(s, a_shrunk, w)):
                        ok = False
                        break
                if not ok:
                    break
            if ok:
                out.append(a)
        return out

    def project(self, s_hat, a_policy, A_base):
        A = self.viable_actions(s_hat, A_base)      # 可缓存 + 增量更新
        if not A:
            return None, "SAFE_STOP"                # 真实不可生存
        return min(A, key=lambda a: self.dynamics.dist(a, a_policy)), "OK"

# IP-439 Hierarchical Action-Space Mediator
class HASM:
    def __init__(self, A_str, A_tac, A_op, hysteresis):
        self.layers = (("op", A_op), ("tac", A_tac), ("str", A_str))
        self.hysteresis = hysteresis

    def mediate(self, s, a_pref):
        a = a_pref
        for name, A in self.layers:                  # 由内到外求交
            allowed = A(s)
            if allowed is None:                      # 该层不可满足
                return self._parent_default(name, s) # 降级，不 SafeStop
            if a not in allowed:
                a = self._nearest(a, allowed)
        return a, "OK"

    def _parent_default(self, level, s):
        # 战略→最大限制模式；战术→静态人距上限；操作→上一层默认
        raise NotImplementedError

# IP-440 Shield-Policy Composition Certificate
class ShieldPolicyCompositionCertificate:
    def __init__(self, alpha_s, delta_state_max):
        self.alpha_s = alpha_s
        self.delta_state_max = delta_state_max
        self.q = None

    def calibrate(self, shield, policy, calib_traj, A_base):
        # 关键：只用“投影后”的轨迹做 conformal，而非原始策略轨迹
        residuals = []
        for s in calib_traj:
            a, st = shield.project(s, policy(s), A_base)
            if st != "OK":
                continue
            residuals.append(shield.dynamics.one_step_residual(s, a))
        self.q = self._conformal_quantile(residuals, self.alpha_s)

    def guaranteed(self, sigma_state):
        return (self.q is not None) and (sigma_state <= self.delta_state_max)

    def _conformal_quantile(self, xs, alpha):
        xs = sorted(xs)
        k = min(len(xs), max(1, int((1 - alpha) * (len(xs) + 1))))
        return xs[k - 1]
```

## 2. 安全继承证明骨架

记 `Traj(Exec_v23)` 为满足 P43–P46 的执行轨迹集合，`S_v22` 为 v22 认证安全状态集。

**引理 A（硬核不被云端扩张）**：由 P43，`A_hard(s)` 的定义只引用边缘本地证书，不含任何云消息；`redeem` 返回 `A_hard(s) ∩ A_cloud(s) ⊆ A_hard(s)`。故对任意链路状态，`A_safe(s) ⊆ A_hard(s) ∪ (A_cloud(s) ∩ A_hard(s)) ⊆ A_soft(s)`，且云失效时退化为 `A_hard(s)`。

**引理 B（护盾前向不变）**：设 `s_t ∈ K_inner` 且 `a_t ∈ A_safe(s_t)`。由 P44 定义，`f(s_t, a_t, w) ∈ K_inner` 对所有 `w ∈ W` 成立（内近似已吸收 ε_quant 与 δ_state）。归纳得 `s_{t+1} ∈ K_inner ⊆ S_v22`。

**引理 C（退化单调）**：任一分量失效（云/几何/规范/能量/臂/量化）只会删除 `A_safe(s)` 中的元素或收缩 `K_inner`，不会新增动作；单调性由交集运算与内近似保持。

**定理（安全继承）**：由引理 B，`Exec_v23` 的每条轨迹的每个状态都属于 `S_v22`，且每个动作都归属于 v22 的合法动作（因为 `A_safe` 由既有证书交集编译，无新授权来源）；故 `Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。SafeStop 仅由 `A_safe(s)=∅`（引理 B 前提被真实违反）触发，而非由计划失败或通信质量触发。

> 注：上述证明的**唯一未闭合前提**是“`s_t` 的估计等于真实状态”。当 `δ_state` 未能覆盖真实漂移/时延时，引理 B 的前提失效；这正是本轮最大风险，见 §5。

### 3.1 假设

- **H1（安全）**：在云断连、承诺过期、承诺篡改、时钟漂移等对抗下，v23 的不安全状态率不高于 v22，且显著低于"信任云命令"的 B1。
- **H2（活性）**：在非空生存核场景，v23 的 SafeStop 次数与死锁率显著低于 v22（HASM + 护盾改选替代停机），吞吐/平均速度更高。

## 4. 本轮结论

把 v22 的"计划级、与策略耦合、动辄停机"的证书体系，重构为**云端签发可复核承诺、边缘本地兑付、控制层策略无关投影的动作空间护盾**：断连与过期只降低活性、不降低安全（P43 硬核不可扩张），`A_safe(s)=∅` 才触发 SafeStop（P44 前向不变），分层动作集嵌套消除跨层振荡（P45），而 conformal 保证被迁移到真正执行的合成映射（P46）。安全继承 `Exec_v23 ⊆ Exec_v22` 在证明骨架中闭合，唯一未闭合前提是"估计状态 = 真实状态"。

**本轮最大风险一句话**：护盾把每一步都认证成"从 `ŝ` 出发的合法动作"，但若 `δ_state` 低估了定位漂移或时延，真实状态可能早已在 `K_inner` 外——机器人会以每一步都"合规"的方式，走出认证安全集。
