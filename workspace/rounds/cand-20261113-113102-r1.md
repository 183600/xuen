# 第 66 轮（承接第 65 轮「VISTA 视觉知情时序归因」IP-214~223；灵感循环第 3 轮；本轮灵感：「末端执行器控制」×「上下文理解」）

> 第 65 轮 VISTA 把「几何可证伪」升级为「故障可归因」，其自述的最大风险是全链条的隐藏假设（A88）：**故障必须落在有限假设集内，且视觉与几何的失效相互独立**。真实故障常是未知类型的组合；透明/镜面/对抗 patch 会让视觉与几何共享同一个分布外失效源，此时 FIR 把未知复合故障强行归入最近假设、只膨胀错误的球，而系统因「已经归因」更自信地继续执行。VISTA 的根病不是「假设集不够大」，而是它的证据**全部来自对同一物理交互的被动观测**——同一个接触事件同时污染视觉与力，两通道天然共线，任何有限标签集都只是在这条共线上切段。本轮换一个**因果**提问方式：
>
> **不再问「这个残差像哪一类故障」，而问「当我们对末端执行器施加一个已知外生激励时，哪个通道的响应错了」。用末端执行器控制把「被动观测」变成「主动干预」，用上下文理解把「枚举故障」换成「枚举模型成立的 regime」，从而把 VISTA 的隐藏假设 A88 替换为可检验、可 abstain 的条件。**

## 0. 直觉与动机

**灵感 1（末端执行器控制 → 系统里唯一的「外生变量」）**
直觉：VISTA 想用两个通道互相校验，但它们不是独立的——都是同一个接触事件的「回声」。可是末端执行器有一个别的传感器没有的性质：**它的指令 u 是我们自己下的，故障无法预先知道我们下一步怎么动**。因果推断里把这种变量叫工具变量（instrumental variable）：它影响所有通道，却不受共同混淆项支配。于是可以不再比较「视觉 vs 力」谁更可信，而是问「给定我们下的 u，每个通道的传递响应 G 是否还对」。这直接绕开「视觉与几何是否独立」——我们不需要它们独立，只需要 u 外生。更准确地说，闭环里真正的内生变量是**实测运动 ẋ**（控制器依据传感器反馈决定它），而指令 u 可以充当 ẋ 的工具变量；这正是闭环系统辨识处理内生性的标准做法。

**灵感 2（末端执行器控制 → 可以在不加力的方向上激励）**
直觉：VISTA 的探针是「按下去」，所以会压坏易损件。但辨识不必靠法向力：可以做**零空间抖动**（沿接触雅可比的零空间、不改变法向力）、**阻抗调制**（改控制器刚度/阻尼而非改位置）、**自由空间宽带抖动**（接触前把传感器偏置与模型误差分开）。这给出「低伤害激励」：用控制器自由度换取观测激励，而不是用物体的安全裕度换。更进一步，**被动柔顺 / 能量罐 / 控制屏障函数（CBF）可以把物理安全从归因正确性里解耦出来**——即使归因错了，低层控制器仍保证法向力与注入能量有界。这直接回应第 65 轮「归因错则更自信地继续执行」的隐患。

**灵感 3（上下文理解 → 不枚举故障，枚举「模型在哪成立」）**
直觉：有限故障集注定漏掉未知复合故障。但可以换一个有限集：**regime / 上下文**——自由空间、刚性接触、软接触、滑动、易损抓取、卡滞……每个 regime 内通道传递模型（增益、偏置、噪声）近似简单且可离线标定。上下文理解的任务不是「猜故障」，而是「判断当前数据能否被某个已知 regime 的模型解释」。若没有任何 regime 能解释 → **模型集不足（open-set）**，此时正确地「我不知道」比错误地「我知道」安全。这把「未知故障被迫归类」换成「未知故障触发 abstain + 安全辨识动作」。但必须诚实：上下文本身是学习的，它可能是新的共因故障源（见第 5 节）。

**灵感 4（两灵感合流 → CONDUIT：Context-conditioned eNd-effector instrUmental Identification for fault aTtribution）**
闭环：低层 CBF/无源性安全包络（与归因无关的物理兜底）→ 中层用已知激励 u 做逐通道工具变量回归，把残差分解成**加性偏置**（intercept）与**乘性模型误差**（slope）→ 上下文理解在模型库中找能解释数据的 regime → 联合后验 (c, H) → 若空集则判**模型不足**、进入安全激励扩充模型库 → 末端执行器按归因切换控制模式（零力窗重标定 / 柔顺 / 视觉伺服 / 安全回退）→ 证书 J_conduit。第 65 轮用「三阶段自然激励」创造可辨识性；CONDUIT 用「主动外生激励」创造更强、可控、可重复的可辨识性，并用上下文把「未知」变成一个合法的一等输出，而不是被迫归类。

**灵感 5（VISTA / GRIP 组件的原位升级）**
- **FIR → IVD + CSA**：从「阶段化静态签名贝叶斯」升级为「逐通道 IV 分解 + 上下文条件化归因」；加性/乘性可分离，且支持**空集 abstain**。
- **VPG / VCV → 保留为通道**：视觉不再是与力「互证」的第二真值，而是一个被已知激励 u 驱动的**被辨识通道**。
- **AFA → EIX**：探针目标从「降低故障假设熵」升级为「最大化 IV 回归的持续激励与 D-最优，并约束在零空间/阻抗域内不增加法向力」。
- **RSC-V → RSC-C**：只更新被 IV 归因的通道参数，且把 intercept（偏置）与 slope（模型）作为两条独立更新通道，不再混在一个球里。
- **CSC / WCV-V**：证书与搜索域改用「上下文条件化的参数不确定度」；**安全由低层 CBF 兜底**，不再把安全押在归因正确上。
- **AIC-V → AIC-C**：干扰集加「上下文伪装 / 别名（context spoofing / aliasing）」与「激励—安全集耦合」两类对抗。
- **J_vista → J_conduit**：证书增 context_posterior、model_insufficiency、excitation_pe_rank、cbf_energy_margin、iv_condition_number。

## 1. 形式化定义（增量：定义 233–243）

- **定义 233（CONDUIT 闭环）**：CONDUIT = (GRIP/VISTA, CSM, MBM, EIX, IVD, CSA, OSA, PSC, CXR, AIC-C, J_conduit)。定位：VISTA 的「因果辨识 + 开集归因 + 控制级安全」升级。不变式：**(i) 物理安全由低层 PSC 保证，与归因正确性无关；(ii) 归因证据来自我们自己设计的外生激励 u，而非通道间被动互证；(iii) 上下文是模型选择器，不是真值，解释不了就 abstain 而不是猜。**
- **定义 234（上下文状态与上下文后验 CSM）**：上下文 c_t=(c_disc, c_cont)，离散 regime（free / rigid_contact / soft_contact / slip / fragile_grasp / jam）与连续参数（负载、温度、表面）。CSM 由历史与多模态观测给后验 P(c_t|ℋ_t)，并用**上下文 conformal 分数** s_c(t)=‖r_t−(d̂_c+Ĝ_c u_t)‖²_{Σ_c⁻¹} 定义「regime c 能否解释当前样本」：能解释 ⇔ s_c≤q_c(α/|𝒞|)（Bonferroni 覆盖）。上下文后验只用于**选模型**，绝不进入物理真值。
- **定义 235（上下文条件化模型库 MBM）**：ℳ={M_c=(d_c,G_c,Σ_c,𝒰_c,ver_c)}_{c∈𝒞}，d_c 为通道基线（含重力补偿/标定偏置），G_c 为指令→实测响应的传递增益，𝒰_c 为该 regime 下合法激励域。支持 merge（两个 regime 不可分则合并）、split（发现子 regime）、expand（拒绝后新增）三种原子操作，全部只在语义流并写版本号。
- **定义 236（末端执行器外生激励 EIX 与持续激励）**：末端指令 u_t∈𝒰_safe 由激励设计器产生（自由空间宽带、接触零空间抖动、阻抗调制），并满足**工具变量条件** E[u_t ε_{k,t}]=0（故障与噪声不依赖我们选择的 u）与**持续激励** rank(E[u_t ẋ_tᵀ])=d_u、E[u_t u_tᵀ]≻0。PE 秩 r_pe 是证书里「可辨识主张」的许可证；激励不足时不得声称区分了加性/乘性。
- **定义 237（IV 残差分解 IVD：加性 vs 乘性）**：对通道 k 与上下文 c，结构模型 y_{k,t}=d_k+G_k ẋ_t+ε_{k,t}，ẋ 为实测运动（闭环内生）。用指令 u 作工具变量做 2SLS：Ĝ_k=(uᵀẋ)^{-1}uᵀy_k，d̂_k=ȳ_k−Ĝ_k ẋ̄。**加性故障（F/T 偏置、漂移）落在 d̂ 偏移；乘性故障（接触模型增益错、刚度错、视觉标定尺度错）落在 Ĝ 偏移**。这是 VISTA 静态签名做不到的分离，且不需要自然出现零力窗/轻触/加载三阶段。
- **定义 238（上下文条件化联合归因 CSA）**：联合后验 P(c,H|ρ,𝒟)=P(ρ|c,H,𝒟)P(H|c)P(c)/Z，其中 𝒟 为 IV 估计对 (d̂,Ĝ) 的证据。H 仍取 VISTA 六假设，但其似然由「残差在 d 方向还是 G 方向偏移」给出：H_force 只改 d_force；H_model 只改 G_force/G_torque；H_vis 改 d_vis 或 G_vis；H_geo 改 G_geo 与视觉落点；H_policy 由块间不一致给出。归因 = 对 (c,H) 边缘化后取 max，且要求后验集中。
- **定义 239（开集模型不足 OSA）**：若 ∀c∈𝒞: s_c>q_c(α/|𝒞|)（当前数据不被任何已知 regime 解释），或 IV 回归残差在 (d,G) 两个方向都显著但无假设能同时解释，则判 `model_insufficiency=True`，**禁止**输出故障标签，进入 CXR。保证（引理 11）：若真实模型到模型库的 conformal 距离超过分位，则被判不足的概率≥1−α；反之，与某已知模型不可分的未知故障**本质不可检测**（ fondamental limit，写入 J_conduit 的 known_blind_spot）。
- **定义 240（安全激励设计与伤害预算）**：EIX 在 𝒰_safe(c)={u: f_n(u,c)≤f_safe, strain≤ε, E_inj≤E_budget, ‖u‖≤u_max, run⊥J_fᵀ} 内选激励。接触中优先取**零空间激励** u∈ker(J_f)（一阶不改变法向力）；无法构造非平凡零空间时退化为**微力调制** f_n∈[f_lo,f_safe]。伤害代理 D(u)=c₂·½‖u‖²·λ_max(∂J_f/∂q)·T（一阶项为零、只剩二阶），并强制 E[D]≤D_budget。
- **定义 241（控制级安全包络 PSC）**：低层阻抗 + 控制屏障函数 h=f_safe−f_n，约束 ḣ+α(h)≥0（用实时测力，不依赖归因/上下文）；能量罐保证注入能量 E_inj≤E_tank，且 EIX 与任务动作共享同一个能量预算。**安全定理以控制层为唯一依赖**：归因/上下文出错时 PSC 仍把法向力与能量夹死，只可能牺牲任务进度，不产生不可逆物理伤害。
- **定义 242（安全扩库恢复 CXR 与证书 J_conduit）**：CXR 在 OSA 时规划一串**最小伤害、最大信息**的辨识动作（先 free-space/null-space，后微力调制），目标 a*=argmax I(c,H; evidence|a) s.t. E[D]≤D_budget、PSC 可行；若无可行动作 → `safe_idle + compliant_retreat`。J_conduit=(J_vista, context_posterior, model_insufficiency, excitation_pe_rank, cbf_energy_margin, iv_condition_number, context_bank_ver, known_blind_spot, aic_c_ver)。Valid ⇔ VISTA 有效 ∧ PSC 可行且能量/力有裕度 ∧ (归因确定 ∨ model_insufficiency 已显式标注并进入 CXR) ∧ 该归因主张的 r_pe 达标 ∧ 模型库版本一致。
- **定义 243（CONDUIT 闭环算子）**：语义流 [LiDAR→LSF→USR/MEL→VPG/ACH→CSM 上下文后验→MBM 选/建模型→EIX 设计激励→执行 k* 步激励→IVD 分解 (d,G)→CSA 联合归因→OSA 空集判定→CXR 扩库/恢复→WCV/CSP 用上下文条件化不确定度→CSC 认证前缀→AIC-C]；实时流 [锚点读→力/运动采集→PSC CBF 投影→阶段判定→CSC 早停→π_σ 前缀派发→J_conduit 构建]，零学习写操作。

## 2. 关键算法骨架

```python
# IVD：用指令 u 作工具变量，把残差拆成加性偏置与乘性模型误差（语义流）
def iv_decompose(y, xdot, u, c):
    # 2SLS：xdot 内生（控制器依赖反馈），u 外生
    G_hat = (u.T @ xdot) @ inv(u.T @ u) @ (u.T @ y) ...   # 一阶 IV
    d_hat = y.mean(0) - G_hat @ xdot.mean(0)
    resid_add = d_hat - d_bank[c]          # 加性方向
    resid_mul = G_hat - G_bank[c]          # 乘性方向
    return d_hat, G_hat, resid_add, resid_mul, pe_rank(u)

# OSA + CSA：上下文条件化归因；解释不了就弃权（不猜）
s = {c: conformal_score(resid, c) for c in BANK}
if min(s.values()) > q_alpha_over_C:
    return model_insufficiency()           # 未知/复合故障 → CXR
post = joint_posterior(s, d_hat, G_hat)    # (c, H) 联合，H 由 d/G 方向偏移决定
if max(post.values()) < 1 - delta_fi:
    return csa_abstain(post)               # 集中不了也弃权
return attribute(argmax(post))

# EIX：在零空间/阻抗域激励，不加法向力，受 CBF 与伤害预算约束
u_star = argmax_{u in U_safe(c)} info_gain(u) \
         s.t. pe_rank(u) >= r_min, E[D(u)] <= D_budget, cbf_feasible(u)

# PSC：与归因无关的物理兜底
f_cmd = cbf_project(f_des, f_n, f_safe, E_tank)   # 任何情况下 f_n <= f_safe, E_inj <= E_tank
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（加性/乘性可辨识）**：若 E[u ε]=0 且 rank(E[u ẋᵀ])=d_u、E[u uᵀ]≻0（持续激励），则 2SLS 的 (d̂,Ĝ) 一致；加性偏置只移动 d̂、乘性模型误差只移动 Ĝ，二者**分别可辨识**，且**不依赖自然三阶段**。这把 VISTA 依赖「零力窗/轻触/加载」的可辨识性从「碰运气出现」变成「按需设计」。
- **引理 10（IV 破除共因）**：若存在混淆项 z 同时影响视觉与力但不影响我们选择的 u，则 E[u(y−d−Gẋ)]=0 对真参数成立，IV 估计不受 z 混淆；而 VISTA 的跨通道一致性 cov(y_vis,y_force|u)≠0 会被 z 污染。故 CONDUIT **不需要**视觉与几何独立（直接否定 A88 的第二个假设），只需 u 外生。
- **引理 11（开集弃权）**：若真实 regime/故障到模型库的 conformal 距离超过 q(α/|𝒞|)，则以 ≥1−α 判 model_insufficiency 而非输出错误标签；若未知故障与某已知模型不可分，则检测本质上不可能，必须写入 known_blind_spot，不得声称覆盖。
- **定理 9（CONDUIT 端到端：安全与归因解耦）**：在 A94–A99（u 外生、PE 达标、模型库内上下文成立、conformal 覆盖、CBF 可行）下：(i) 物理安全 f_n≤f_safe、E_inj≤E_tank 由 PSC 保证，**与归因/上下文是否正确无关**；(ii) 归因误差受 κ_iv 与上下文覆盖控制；(iii) 未知/复合故障以 ≥1−α 触发 abstain 而非强行归类；(iv) 恢复只牺牲任务进度、不越过 CBF。故 VISTA 的 A88 被替换为可检验条件，且「归因错误 → 更自信执行」被控制级兜底切断。
- **命题（低伤害激励）**：零空间激励一阶不改变法向力，伤害代理仅剩二阶项 c₂·½‖u‖²·λ_max(∂J/∂q)·T，且受 D_budget 与 E_tank 双约束；相比 VISTA 的接触探针（直接加载荷），CONDUIT 的辨识伤害可先验界定。
- **实时性**：PSC 为实时路径（CBF 投影 <0.1ms）；IVD/CSA/OSA/CXR 全在语义流；实时流只做力/运动采集、CBF、阶段判定与早停，目标 ≤2.2ms（比 VISTA 少的接触探针预算让给 CBF）。

## 5. 本轮最大风险

## 2. 形式化定义（完整版）

**定义 233（CONDUIT 闭环）** CONDUIT 是 VISTA 的「因果辨识 + 开集归因 + 控制级安全」升级：在 VISTA 的语义流/实时流骨架上挂载 CSM（上下文状态）、MBM（模型库）、EIX（末端激励）、IVD（工具变量分解）、CSA（联合归因）、OSA（开集弃权）、PSC（控制级安全）、CXR（扩库恢复），并原位升级 AIC-V→AIC-C、J_vista→J_conduit。三条不变式：
1. **物理安全由 PSC 保证，与归因/上下文是否正确无关**；
2. **归因证据来自我们自己设计的外生激励 u，而非通道间被动互证**；
3. **上下文是模型选择器不是真值；任何 regime 都解释不了时，abstain 是合法输出，禁止强行归类**。

**定义 234（上下文状态与上下文后验 CSM）** 上下文 c_t=(c_disc,c_cont)，c_disc∈{free, rigid_contact, soft_contact, slip, fragile_grasp, jam}，c_cont 为负载/温度/表面等连续参数。CSM 由历史 ℋ_t 与多模态观测给后验 P(c_t|ℋ_t)。为防止上下文本身成为共因故障，CSM 的输出**不直接用于归因**，而必须先通过**上下文 conformal 检验**：
s_c(t)=‖r_t−(d̂_c+Ĝ_c u_t)‖²_{Σ_c⁻¹}，能解释 ⇔ s_c(t)≤q_c(α/|𝒞|)，
其中 q_c 为标定集上的 split-conformal 分位，Bonferroni 保证全库联合覆盖 ≥1−α。上下文后验只用于给模型库排序与先验，不进入物理真值。

**定义 235（上下文条件化模型库 MBM）** 模型库
ℳ={M_c=(d_c,G_c,Σ_c,𝒰_c,ver_c)}_{c∈𝒞}，
d_c 为通道基线（含重力补偿、标定偏置），G_c 为「指令/运动 → 通道输出」的传递增益，𝒰_c 为该 regime 下的合法激励域。MBM 支持三种原子操作，全部在语义流并写版本号：
- **merge**：若两个 regime 的模型在 conformal 意义下不可分（互相解释），合并以免无意义切分；
- **split**：若某 regime 内残差持续呈双峰，拆出子 regime；
- **expand**：OSA 弃权且 CXR 收集到足够证据后，新增 M_{c_new}。
模型库是**有限但可增长**的，且其覆盖范围由 AIC-C 显式认证（含 known_blind_spot）。

**定义 236（末端执行器外生激励 EIX 与持续激励）** 末端指令 u_t∈𝒰_safe 由激励设计器产生，三种模板：
1. **free-space 宽带**（接触前）：多正弦/伪随机抖动，激励传感器偏置与增益，零接触力；
2. **null-space 抖动**（接触中）：u∈ker(J_f)，沿不改变法向力的方向激励；
3. **impedance 调制**（接触中，无零空间时）：调控制器刚度/阻尼 K_p,D_p，改变 u→y 传递而不改平均位置与平均力。
工具变量条件：E[u_t ε_{k,t}]=0（故障与噪声不依赖我们选择的 u）。持续激励条件：rank(E[u_t ẋ_tᵀ])=d_u 且 E[u_t u_tᵀ]≻0，记 r_pe 与 κ_iv=σ_min/σ_max。**r_pe 是证书中「可辨识主张」的许可证**：激励不足时，IVD 不得声称分离了加性/乘性。

**定义 237（IV 残差分解 IVD：加性 vs 乘性）** 对通道 k 与上下文 c，结构模型
y_{k,t}=d_k+G_k ẋ_t+ε_{k,t}，
其中 ẋ 为实测运动，因控制器依赖传感器反馈而**内生**；指令 u 为工具变量。两阶段最小二乘（2SLS）：
- 一阶段：ẋ=Πu+v，Π̂=ẋuᵀ(uuᵀ)⁻¹，得 ẋ̂=Π̂u；
- 二阶段：y_k 对 [1, ẋ̂] 回归，得 (d̂_k,Ĝ_k)。
在 E[uε]=0 与持续激励下 (d̂,Ĝ) 一致。**加性故障（F/T 偏置、漂移、零漂）只移动 d̂；乘性故障（接触模型增益错、刚度错、视觉标定尺度错）只移动 Ĝ。** 这与 VISTA 依赖「零力窗/轻触/加载」三阶段的静态签名形成互补：CONDUIT 不需要自然出现三阶段，而是**按需设计激励**；VISTA 的签名仍可作为附加证据并入 ρ。

**定义 238（上下文条件化联合归因 CSA）** 联合后验
P(c,H|ρ,𝒟) ∝ P(ρ|c,H,𝒟)·P(H|c)·P(c)，
其中 𝒟=(d̂,Ĝ,Σ_iv) 为 IVD 证据，ρ 为 VISTA 阶段签名（可缺省）。似然按残差方向分解：
- **H_force**：resid_add 在力/力矩通道显著（d̂_force≠d_c），resid_mul 不显著；
- **H_model**：resid_mul 在力/力矩通道显著（Ĝ_force≠G_c），resid_add 不显著；
- **H_vis**：resid_add 或 resid_mul 仅在视觉通道显著；
- **H_geo**：Ĝ_geo 与视觉落点同时偏（接触雅可比/接触点错），但力通道增益不变；
- **H_policy**：块间不一致 d_chunk/集成方差显著，而通道 (d,G) 正常；
- **H0**：两者皆不显著。
归因 = 对 c 边缘化后取 max_H，且要求后验集中（max≥1−δ_fi），否则进入 CSA 弃权。

**定义 239（开集模型不足 OSA）** 若
∀c∈𝒞: s_c(t)>q_c(α/|𝒞|)，
或 IVD 残差在 (d,G) 两方向都显著但无任何 H 能同时解释（联合似然不集中），则判 `model_insufficiency=True`，**禁止输出故障标签**，进入 CXR。保证（引理 11）：若真实模型到模型库的 conformal 距离超过分位，则被判不足的概率 ≥1−α；反之，与某已知模型不可分的未知故障**本质不可检测**，必须显式写入 J_conduit 的 `known_blind_spot`，不得声称覆盖。

**定义 240（安全激励设计与伤害预算）** EIX 在
𝒰_safe(c)={u: f_n(u,c)≤f_safe, strain(u,c)≤ε, E_inj(u)≤E_budget, ‖u‖≤u_max, run(u)⊥J_fᵀ}

**定义 241（控制级安全包络 PSC）** 低层阻抗控制 + 控制屏障函数
h=f_safe−f_n，约束 ḣ+α(h)≥0（α 为 class-𝒦 函数），

### IP-227 IVD（工具变量分解）

```python
class IVDecomposer:
    """用外生指令 u 作工具变量，把闭环内生回归量 xdot 的偏置分离出来。
    只产出 (d_hat, G_hat) 与 PE 秩；不做归因。"""
    def __init__(self, bank, r_min=2):
        self.bank, self.r_min = bank, r_min

    def decompose(self, y, xdot, u, c):
        # 一阶段：xdot = Pi u + v
        uu = u.T @ u
        if np.linalg.matrix_rank(uu) < xdot.shape[1]:
            return None, None, 0.0, None      # 激励不足 → 不许声称可辨识
        Pi = (xdot.T @ u) @ np.linalg.inv(uu)
        xhat = u @ Pi.T
        # 二阶段：y = d + G xhat
        X = np.hstack([np.ones((len(xhat), 1)), xhat])
        beta, *_ = np.linalg.lstsq(X, y, rcond=None)
        d_hat, G_hat = beta[0], beta[1:].T
        # PE 秩与工具变量条件数
        M = u.T @ xdot
        sv = np.linalg.svd(M, compute_uv=False)
        r_pe = int((sv > 1e-6 * sv[0]).sum())
        kappa_iv = float(sv[-1] / sv[0]) if sv[0] > 0 else 0.0
        resid_add = d_hat - self.bank[c].d
        resid_mul = G_hat - self.bank[c].G
        return resid_add, resid_mul, r_pe, kappa_iv
```

### IP-224/228/229 CSM + OSA + CSA（上下文条件化开集归因）

```python
class ContextAttributor:
    def __init__(self, bank, delta_fi=0.15, alpha=0.05):
        self.bank, self.delta_fi, self.alpha = bank, delta_fi, alpha

    def context_scores(self, r, u):
        return {c: mahalanobis(r - (m.d + m.G @ u), m.Sigma)
                for c, m in self.bank.items()}

    def attribute(self, r, u, rho, pe_rank):
        s = self.context_scores(r, u)
        q = {c: self.bank[c].q(alpha=self.alpha / len(self.bank)) for c in s}
        if min(s.values()) > min(q.values()):
            return None, {'model_insufficiency': True, 'scores': s}
        post = self._joint_posterior(s, rho)
        h_star = max(post, key=post.get)
        if post[h_star] < 1 - self.delta_fi or pe_rank < self.bank_pe_min(h_star):
            return None, {'ambiguous': True, 'post': post}
        return h_star, {'post': post, 'context': self._map_context(s)}

    def _joint_posterior(self, s, rho):
        # H 的似然由残差落在 d 方向还是 G 方向决定（定义 238）
        return normalize({(c, h): joint_lik(s, rho, c, h) * prior(c, h)
                          for c in self.bank for h in HYP})
```

```python
class ExcitationDesigner:
```

```python
class PassivitySafetyController:
    """实时层：只读测力与运动，不读归因/上下文。"""
    def project(self, f_des, f_n, f_safe, E_tank, dt):
        h = f_safe - f_n
        f_safe_des = cbf_filter(f_des, h, alpha=CBF_ALPHA)   # 保 ḣ+α(h)≥0
        if E_tank <= 0:
            f_safe_des = soft_retreat(f_safe_des)            # 能量耗尽 → 柔顺回退
        return clip_force(f_safe_des, f_safe)
```

### IP-233 CONDUIT 闭环算子（整合）

```python
def CONDUIT_round(M, obs, delta_f_req):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    # ———— 语义流 ————
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    y_vis = M.f_vis(img, depth, flow)

    # 1) 上下文后验 + 模型库选择（只排序，不作真值）
    c_post = M.csm.infer(M.history, y_vis, W_meas)
    c = M.mbm.select(c_post)

    # 2) 设计低伤害外生激励（PE + 伤害预算 + CBF）
    plan = M.eix.choose(c, M.J_f, M.f_n, M.D_budget, M.E_tank, M.r_min)

    # 3) 执行认证前缀激励，采集 (u, xdot, y)
    k_star = M.csc.certified_prefix(plan.u, M.balls, M.m)
    log = M.realtime_execute(plan.u[:k_star], delta_f_req)

    # 4) IVD：加性 vs 乘性分解（激励不足则拒绝声称）
    resid_add, resid_mul, r_pe, kappa_iv = M.ivd.decompose(
        log.y, log.xdot, log.u, c)

    # 5) CSA + OSA：联合归因；解释不了就弃权
    h_star, info = M.csa.attribute(log.r, log.u, log.rho, r_pe)
    if info.get('model_insufficiency') or h_star is None:
        a, ig = M.cxr.plan(c_post, M.bank, M.D_budget, M.E_tank)
        if a is not None:
            M.execute(a)                                  # 扩库/恢复辨识
        return M, M.psc.retreat(), build_j_conduit(M, info)

    # 6) 定向处置：只更新被 IV 归因的通道参数（intercept/slope 分开）
    M.balls, M.w_vis, M.H = M.fir.directed_demote(
        h_star, M.balls, M.w_vis, M.H)
    M.rsc_c.update(h_star, resid_add, resid_mul, r_pe)

    # 7) 规划 + 认证前缀 + PSC 执行
    goal = M.dms.parse_goal((M.usr.U_ep, M.usr.U_al))
    tau = M.csp_v.plan_chunks(goal, x_prime, M.mbm[c], M.balls, info['post'])
    k_task = M.csc.certified_prefix(tau.A, info['post'], M.m, M.alpha_chunk)
    K_safe, EV_exec = M.psc.execute(tau.A[:k_task], delta_f_req)

    # 8) 在线更新（纯语义流）+ 认证
    M.olp.online_step(M.olp.fuse_evidence(x_prime, W_meas, tactile, y_vis),
                      execution_loss_grad(K_safe, EV_exec, M.balls))
    rho_dir = M.aic_c.certify(tau, x_prime, M.bank, M.post)
    return M, K_safe, build_j_conduit(
        M, info, J_vista=build_j_vista(...), context_posterior=c_post,
        model_insufficiency=info.get('model_insufficiency', False),
        excitation_pe_rank=r_pe, iv_condition_number=kappa_iv,
        cbf_energy_margin=M.psc.margin(), context_bank_ver=M.mbm.ver,
        known_blind_spot=M.mbm.blind_spots(), aic_c_ver=AIC_C_VERSION)
```

## 4. 推导

**引理 9（加性/乘性可辨识）** 设结构模型 y_k=d_k+G_k ẋ+ε，E[uε]=0，且持续激励 rank(E[uẋᵀ])=d_u、E[uuᵀ]≻0。一阶段 Π=E[ẋuᵀ](E[uuᵀ])⁻¹，二阶段回归 [1,ẋ̂] 得 (d̂,Ĝ)。由 E[uε]=0，2SLS 一致：d̂→d_k、Ĝ→G_k。设故障由 (Δd,ΔG) 参数化，则 E[d̂−d_c]=Δd、E[Ĝ−G_c]=ΔG，且二者在回归中分别对应截距与斜率，**互不混叠**。因此加性偏置（H_force）与乘性模型误差（H_model）可分别辨识；该结论只要求激励协方差满秩，**不要求自然出现零力窗/轻触/加载**。当 r_pe<d_u 时 E[uuᵀ] 或 E[uẋᵀ] 退化，(Δd,ΔG) 出现不可辨识方向，故 r_pe 必须作为证书条件。∎

**引理 10（IV 破除共因）** 设存在混淆项 z 同时进入两通道：y_k=d_k+G_kẋ+Λ_k z+ε，z 可为透明/镜面/对抗物体引起的共同分布外失效源。VISTA 的跨通道一致性以 cov(y_vis,y_force|u) 为证据，含 Λ_vis z 与 Λ_force z 的交叉项，故 z≠0 时被污染。CONDUIT 只用矩条件 E[u(y_k−d_k−G_kẋ)]=E[uε]+E[uΛ_k z]。由于 u 由我们选择、故障/混淆项 z 不依赖 u（外生性），E[uΛ_k z]=Λ_k E[uz]=0（在激励零均值且与 z 独立的标定下），故 E[u(y−d−Gẋ)]=0 对真参数成立，2SLS 不受 z 混淆。**因此 CONDUIT 不需要视觉与几何独立，只需 u 外生**——这直接否定 A88 的第二个假设。若故障反过来改变了 u 的实际实现（摩擦、饱和、执行器失效），外生性被破坏，这是本轮首要风险。∎

**引理 11（开集弃权与不可检测边界）** 对每个 regime c，标定集给出 s_c 的 split-conformal 分位 q_c(α/|𝒞|)。由 Bonferroni，P[∃c: s_c>q_c 而真实属于 c]≤α。若真实模型 M* 到库内所有 M_c 的分布距离使 s_c(M*)>q_c，则以 ≥1−α 判 model_insufficiency，而非输出错误标签。反之，若 M* 与某 M_c 在 conformal 意义下不可分（s_c(M*)≤q_c），则任何基于该库的检验都无法区分，**检测本质上不可能**；必须写入 known_blind_spot，并在 AIC-C 中显式计为不可消除盲区。∎

**定理 9（CONDUIT 端到端：安全与归因解耦）** 在 A94–A99 下：
1. **安全与归因解耦**：PSC 的 CBF ḣ+α(h)≥0 只用实时测力 f_n，能量罐保证 E_inj≤E_tank；该约束不引用归因或上下文，故即使 (c,H) 全错，仍保证 f_n≤f_safe、E_inj≤E_tank。归因错误最多导致任务进度损失或安全回退，不产生不可逆物理伤害。
2. **归因一致性**：库内上下文成立且 r_pe 达标时，由引理 9 得 (Δd,ΔG) 一致，CSA 的 H 似然按残差方向分离，归因误差受 κ_iv 与后验集中度控制。
3. **未知不强行归类**：由引理 11，库外故障以 ≥1−α 判 model_insufficiency 并进入 CXR；只有与库内模型不可分的盲区会被漏检，且该盲区已披露。
4. **低伤害**：EIX 限制在 𝒰_safe(c)，零空间激励一阶不改变 f_n，伤害代理仅二阶且受 D_budget 与 E_tank 双约束。
5. **优雅降级**：视觉失效→退化到力/运动通道的 IV；F/T 失效→力通道残差被 PSC 的实测力兜底，归因判 H_force 并重标定；上下文库不足→弃权+扩库；执行器外生性失效→判 model_insufficiency（因为 u 与残差相关），进入安全回退。
故 Valid(J_conduit) ⇒ 物理安全 ∧（归因确定 ∨ 已弃权并扩库）∧ 激励可辨识主张有 r_pe 许可 ∧ 盲区已披露。∎

**命题（低伤害激励的伤害界）** 设零空间激励 u∈ker(J_f)，则一阶法向力变化 Δf_n^{(1)}=J_f u=0；二阶项 Δf_n^{(2)}=½uᵀ(∂J_f/∂q)u≤½‖u‖²λ_max(∂J_f/∂q)。故 D(u)≤c₂·½‖u‖²λ_max(∂J_f/∂q)·T，与 D_budget 比较即可先验约束。相比 VISTA 的接触探针直接加载荷，CONDUIT 把「辨识所需的信息」尽量搬到力的一阶零空间里，把伤害从一阶降到二阶。∎

**命题（上下文别名是自信失明）** 若 CSM 把未知对象误判为已知 c∈ℳ，则存在 (d_c,G_c) 使当前残差被解释（s_c≤q_c），OSA 不触发弃权，IVD 的 (Δd,ΔG) 也落入 c 的正常范围；此时系统**观测不到故障**，而 𝒰_safe(c) 又基于错误 c 估计，可能把实际接触误当自由空间。故错误从「可观测的误归因」退化为「不可观测的自信失明」——这是本轮最大风险的形式化表述。∎

## 7. 已知风险

**一句话**：CONDUIT 的全部可辨识性与安全主张最终都押在「上下文模型库覆盖真实 regime」这一条上；一旦上下文理解发生**别名（aliasing）**——把未知/对抗物体误判进某个已知 regime——系统不仅归因错误，而且残差会被错误模型**解释掉、故障在观测上消失**，同时「安全激励」的安全集 𝒰_safe(c) 也由这个错误上下文导出，于是它会在自以为零力/零风险的激励里撞上真实接触；这比 VISTA「归因错误但至少看到残差」更危险，因为它把失误变成了**自信的失明（confident blindness）**。

**次级风险与缓解**：
1. **外生性被破坏**：执行器摩擦、饱和、失效会让 u 与残差相关，IV 前提失效；缓解：在线检验 E[uε]≈0（残差-激励相关性检验），拒绝即判 model_insufficiency 并回退。
2. **上下文别名 / 共因**：CSM 与几何/视觉共享同一分布外失效源；缓解：上下文只做模型排序、必须过 conformal 检验；引入物理独立通道（IMU/关节电流/本体感觉）做交叉；AIC-C 显式建别名对抗并披露 known_blind_spot。
3. **PE 不足导致假分离**：弱激励下 (Δd,ΔG) 有不可辨识方向，却可能误以为已分离；缓解：r_pe/κ_iv 作为证书硬条件，不足则拒绝声称，降级为 VISTA 签名。
4. **零空间不存在**：点接触/卡滞时 ker(J_f) 平凡，只能微力调制；缓解：退化为阻抗调制 + 严格 D_budget，必要时 abstain。
5. **模型库无限增长**：expand 可能过拟合噪声；缓解：merge/split 由 conformal 可分性驱动，库规模上限 + 版本审计。
6. **CBF 依赖力测量**：若力传感器本身饱和/失效，CBF 的 h 估计错；缓解：能量罐与位置/电流冗余估计，双重夹紧，传感器健康监测。
7. **实时预算**：CBF + 采集逼近 2.2ms；缓解：把 IVD/CSA/OSA/CXR 全留语义流，实时只做 CBF 与早停。
8. **开集弃权过频**：库覆盖不足会让系统频繁 abstain、任务停滞；缓解：CXR 主动扩库 + 允许「安全但保守」的任务降级，并把 abstain 率作为可观测运维指标。
