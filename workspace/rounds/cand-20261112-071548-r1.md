# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环第 1 轮；本轮灵感：「数据采集」×「状态估计」）

> 第 59 轮把「证据承诺」一路接地到电机电流环：BUQ 在线辨识 ξ_exec、ERTC 契约化实时性、EEIS 把 δ_f 编译成阻抗证书、CLEP 让执行证据回流。但它仍默认三件事：**遥测是干净的、时间是对齐的、估计是诚实的**。本轮两个灵感正好从下面顶上来：**数据采集**决定「估计器能知道什么」，**状态估计**决定「控制器敢相信什么」。核心命题：**不要采集你负担不起的信息，不要输出你观测不到的状态；把数据采集从被动管道升级为带成本与安全约束的主动信息获取，把状态估计从点估计升级为带可辨识性证书的方向性估计。**

## 0. 先给直觉

### 0.1 第 59 轮的「接地」还差最后一米

第 59 轮论证链是：执行器物理 → ξ_exec 在线辨识 → 结构化似然 → 阻抗安全编译。听上去闭环了，但它把「观测」当成了免费的、同步的、无损的、且与模型同构的。真实链路是：

```
物理世界 → 传感器 → 模拟前端/ADC → 采样保持 → 时间戳 → 总线/压缩 → 估计器 → 控制器
              ↑抗混叠滤波      ↑量化      ↑时钟偏斜   ↑丢包     ↑模型阶数/可辨识性
```

这条链上任何一环出问题，都不会在 ξ_exec 的协方差里自动显形；相反，UKF 会给出一个**更小、更自信、但方向错了**的协方差。第 59 轮把「执行不确定性」变成了可辨识参数，但**可辨识性本身不是免费的**：没有足够的激励，参数不可辨识；没有足够的采样，信号会混叠；没有可信的时间戳，相位会被伪造；没有独立锚点，电机参数与力估计会互相「自洽」。这就是本轮的抽象泄漏：**感知-估计层的自洽幻觉**。

### 0.2 灵感 1（数据采集）：不是管道，是「动作」

直觉上，数据采集像水管：打开就有数据。但对具身系统，采集是**有成本、有风险、有时序的动作**：

- **成本**：采样占 CPU/总线/功耗；高频力矩/触觉/视觉同时开，会把第 59 轮的 B_exec 吃光。
- **风险**：为了辨识参数而注入 d 轴电流、做慢速整周旋转、施加小幅力调制，都会扰动任务本身；在接触临界点，激励可能直接导致失稳。
- **时序**：电流环 10~20 kHz、力/力矩 1~5 kHz、IMU 1~2 kHz、视觉 30~100 Hz、触觉 100 Hz~1 kHz。多时钟域之间的时间戳偏差会把「接触瞬态」抹成「缓慢漂移」。
- **信息**：总线带宽不够时，最自然的做法是降采样/有损压缩；但降采样会把 6 阶齿槽脉动混叠到低频，估计器于是「辨识」出一组虚假的谐波系数——**数据采集的降采样，直接改写了物理模型**。

所以数据采集必须是**契约化**的：采样率、抗混叠带宽、时间同步上界、标定有效期、量化位数、丢包率、数据来源链。更重要的是，它必须与估计器**协同设计**：估计器告诉采集「哪些方向的信息最值钱」，采集告诉估计器「这条数据能信到什么程度」。这就是本轮的第一个新层：**数据采集契约 DAC + 信息保持采集 IPAC**。

### 0.3 灵感 2（状态估计）：不是「求逆」，是「在可观测方向上求逆」

第 59 轮的 UKF 试图同时辨识 22 个参数（4 个电机参数 + 12 个谐波系数 + 饱和/摩擦/ADC/同步/温度）。但在机器人常见的工况下，这个向量的大部分方向是**不可辨识**的：

- **静止/堵转**：ω_e≈0、i_q≈0，反电动势项消失，λ_pm 与转矩常数不可分；摩擦 c_fric·sign(i_q) 与 ADC 偏移 offset 在单一电流符号下不可分。
- **恒速轻载**：i_d≈0，R 与 ADC 增益 gain 只以乘积形式出现；L_d、L_q 的可辨识性依赖 di/dt 的激励。
- **齿槽谐波**：要分辨 k 阶谐波，需要电角度覆盖足够多周期；只在小角度来回，sin(kθ) 与低阶项近似共线。
- **自指循环**：τ_est 由电流和「正在被估计的电机参数」算出，而参数又用 τ_est 去辨识；探针力预测也由 ξ_exec 算出。没有独立物理锚点（关节力矩传感器、已知惯量自由摆动、已知质量负载），误差可以互相抵消，形成「自洽但错误」的解。

因此状态估计的正确姿势不是「把所有参数都估出来」，而是：**先算 Fisher 信息矩阵（FIM），把参数空间分成可辨识子空间与不可辨识子空间；只在可辨识方向上输出后验，在不可辨识方向上保留先验/膨胀协方差；并且只要求「任务相关方向」可辨识**（例如接触力预测只需要少数几个参数组合，不需要 22 个全准）。这就是第二个新层：**可辨识性感知状态估计 OASIS + 估计一致性监视 ECM**。

### 0.4 合流：数据-估计契约（DEC）

把两者合起来，得到本轮的主循环 DSEP：

```
① 采集契约检查（DAC）→ 不合规则重采/膨胀/降级
② FIM/可辨识性分析（OASIS）→ 任务相关方向是否可观测？
③ 若不可观测：主动激励（DASE）或诚实膨胀（不许假装知道）
④ 信息保持采集/压缩（IPAC）+ 时间戳/来源链
⑤ 状态估计 + 一致性检验（ECM/NEES/NIS）
⑥ 感知-估计证据 EV-se → 只做对账权重，不做标签佐证
⑦ 把 guarded Σ_exec 与 ξ_exec 交给第 59 轮 CLEP/EEIS
⑧ 更新感知预算 B_sense
```

一句话：**第 59 轮问「执行能不能做到」，本轮问「你凭什么知道」。**

## 1. 动笔前的可复现性审计（一个必须先修的账）

在展开之前，我先对第 59 轮的 ξ_exec 做了一次维度审计：文字与定义 145 声明 `state_dim=13`，但观测模型 `h(ξ)` 解包的是 `R, Ld, Lq, λ`（4）+ 6 阶谐波 `{a_k, φ_k}`（12）+ `b_sat, c_fric, gain, offset, dt_sync, T_junc`（6）= **22 维**；实现里的 `Q` 也正好是 `4+12+6=22` 维；而 `state_dim=13`、`chi2.ppf(..., df=13)` 又按 13 维做 OOD 判定。更早的伪代码里 `enumerate(ripple,1)` 把 12 个谐波参数当成 12 个独立项，而不是 6 对 `(a_k, φ_k)`。

这不是吹毛求疵，它恰好是本轮问题的缩影：**参数维度、模型阶数、可辨识性、OOD 阈值四件事没有对齐**。本轮统一记为：

```
d_ξ = 4 + 2·K_ripple + 6,    K_ripple = 6  ⇒ d_ξ = 22
```

并把 `K_ripple` 从「手设常数」升级为**可辨识性驱动的模型阶数选择变量**：FIM 的最小特征值撑不起 k 阶谐波时，就不估 k 阶，或把它归入结构化未建模扰动（协方差膨胀），而不是让 UKF 在零空间里自由漂移。审计结论：**第 59 轮的 13 维链式论证在 22 维实现上不能直接复用，本轮所有证书都以 d_ξ=22、K_ripple 可变重写。**

## 2. 核心矛盾（H32–H34）

- **H32（可辨识性幻觉）**：第 59 轮用「UKF 收敛 + 马氏距离在 χ² 椭球内」判执行 ID。但 UKF 的协方差是**模型自报**的；在无激励方向上，FIM 秩亏，真实 CRLB 无穷大，而 UKF 仍可能给出很小的协方差。结果是「越不激励越自信」。必须用 FIM/CRLB 给协方差设**下限**，并在不可辨识方向保留先验，而不是输出点估计。
- **H33（采集泄漏）**：降采样、抗混叠滤波器群延迟、时间戳偏斜、丢包、有损压缩、量化，都会改变观测的统计特性。最阴险的是**混叠**：低频遥测把高频齿槽脉动折叠成低频「结构」，估计器会把它当成真实参数，且残差很小、校准很好——这是数据采集层制造的「假可辨识性」。必须把采集契约写进证据链，采集违约即数据不可用/协方差膨胀。
- **H34（估计自指循环）**：τ_est 依赖 ξ_exec，ξ_exec 又依赖 τ_est；力预测依赖 ξ_exec，探针结果又反过来校 ξ_exec。没有独立锚点，误差可互相抵消。必须引入**物理锚点集**（关节力矩、已知惯量、已知负载、自由摆动），并把「无锚点 ⇒ 该子空间不可辨识」写进证书，绝不允许执行层拿自指估计去换更硬的阻抗。

## 3. 严谨定义（增量：定义 153–160）

**定义 153（数据采集契约 DAC）** 采集契约
`C_da = (R_s, B_aa, T_sync, C_cal, Q_b, P_drop, H_prov, τ_age)`，
其中 `R_s` 为各通道采样率，`B_aa` 为抗混叠通带，`T_sync` 为最大时间戳偏斜，`C_cal` 为标定有效期，`Q_b` 为量化位数/误差界，`P_drop` 为最大丢包率，`H_prov` 为来源哈希链，`τ_age` 为最大数据年龄。数据包 `p=(ch,t_stamp,y,seq,calib_id,hash)` 被**准入**当且仅当：`|t_stamp−t_true|≤T_sync`、有效采样率 `≥2(B_sig+margin)` 且覆盖 `B_aa`、序号无未声明的缺口、`calib_id` 在有效期内、`hash` 链可验证、`t_now−t_stamp≤τ_age`。输出 `A_cert_d`（采集证书）。违约分三级：`REACQUIRE`（可重采）、`INFLATE`（数据可用但膨胀）、`REJECT`（数据不可用）。

**定义 154（可辨识性证书与方向性后验 OASIS）** 观测模型 `y_t=h(ξ,u_t)+v_t`，`v_t∼N(0,R_t)`。Fisher 信息矩阵
```
F(ξ;D)=Σ_{t∈D} H_t^T R_t^{-1} H_t,   H_t=∂h/∂ξ|_{ξ,u_t}
```
特征分解 `F=VΛV^T`。给定阈值 `λ_min`：可辨识子空间 `S_id=span{v_i:λ_i≥λ_min}`，不可辨识子空间 `S_null` 为其正交补。CRLB 在 `S_id` 上给出 `Cov(ξ)⪰F^+`。**方向性后验**不是单个高斯点估计，而是
```
Σ_guard = Π_id Σ_post Π_id^T + Π_null Σ_prior Π_null^T
          + 沿每个 v_i∈S_id 的 max(Σ_post, 1/λ_i) 修正
```
即：可辨识方向不得低于 CRLB，不可辨识方向不得低于先验。`O_cert=(S_id,S_null,{λ_i},rank(F),κ(F),CRLB,F_φ,anchor_used)`。其中 **任务相关 FIM** `F_φ=J_φ F^+ J_φ^T`，`φ` 是下游真正要用的量（接触力/阻抗/抓取位姿），`J_φ=∂φ/∂ξ`。若 `φ` 的方向不可辨识，`O_cert` 必须显式标记 `task_unobservable=true`，而不是给一个看起来很小的 `Σ_exec`。

**定义 155（估计一致性监视 ECM）** 新息 `ν_t=y_t−h(ξ̂_{t|t−1},u_t)`，新息协方差 `S_t`。NIS `ε_t^NIS=ν_t^T S_t^{-1} ν_t`，NEES `ε_t^NEES=(ξ_t−ξ̂_t)^T Σ_t^{-1}(ξ_t−ξ̂_t)`（有锚点时）。窗口均值应落在 χ² 区间；同时检验新息白性（lag-1 自相关）与协方差匹配。若拒绝一致：`α_inf=clip(ε̄/χ²_{1−α}, 1, α_max)`，令 `Σ←α_inf·Σ`，并置 `EST_OOD=true`；若连续 `N_bad` 次失败，冻结参数辨识、退回先验、要求重新标定/激励。**Q/R 自适应必须带上下界**，防止「把噪声学成模型」的二次自洽。

**定义 156（信息保持采集 IPAC）** 给定比特预算 `B`，采集/压缩策略 `π` 的目标不是最小化原始数据重构误差，而是最小化**估计信息损失**：
```
min_π  E[ d_F( F(ξ;D), F(ξ;π(D)) ) ]
s.t.   bits(π(D)) ≤ B,  P_drop ≤ P_drop^max,  P_alias ≤ P_alias^max,
       |logdet F(ξ;D) − logdet F(ξ;π(D))| ≤ ε_F
```
线性高斯情形下，充分统计量为 `(F,b)=(Σ H_t^T R_t^{-1} H_t, Σ H_t^T R_t^{-1} y_t)`，其维度 `O(d_ξ²)` 与样本数无关；可在 MCU 上递推计算、低频回传（「充分统计量遥测」），并用特征基比特分配/抖动白化量化。事件触发规则：当预测新息马氏距离 `>γ_NIS` 或期望信息增益 `>γ_IG` 时发送，另设心跳保证 `τ_age≤τ_age^max`。

**定义 157（数据-估计协同与主动激励 DASE）** 激励 `e∈E`（d 轴电流注入、慢速整周旋转、小幅力/位置调制、负载变化），采集数据 `D(e)`。任务相关期望信息增益
```
IG_φ(e) ≈ ½ log det( I + F_φ(e) Σ_φ^{prior} )
```
选择
```
e* = argmax_{e∈E}  IG_φ(e) − λ_c·cost_acq(e) − λ_r·Risk(e) − λ_t·Delay(e)
s.t.  e 满足 EEIS 力/位置约束、ERTC 实时契约、B_exec 余量、
      |F|≤F_max, |i|≤i_max, T_junc≤T_max, Σ e_i²≤E_budget
```
若 `max_e IG_φ(e)−cost < 0`，不激励；此时只能膨胀协方差并让动作更保守。这是「对偶控制」：**为学而动的收益必须盖过为动而动的风险**。

**定义 158（感知-估计证据 EV-se 与 XMC++）** `EV-se=(acq_ok,sync_ok,prov_ok,calib_id,obs_rank,nees_ok,nis_ok,crlb_ok,est_ood,τ_age,degraded)`。模态集 `ℳ^{++}=ℳ^{+}∪{sense}`。关键规则：**质量证据不是内容证据**——`EV-se` 不提供关于物体/环境的标签似然，只调整权重与协方差；`degraded=true` 或 `prov_ok=false` ⇒ 该区域后验加宽、`ρ_sense→ρ_min`、并回溯标记历史数据；`EV-se` 绝不能作为 `EV-xmodal/EV-human` 的替代佐证。

**定义 159（DSEP 数据-感知-估计闭环与感知预算 B_sense）** `B_sense=(Sampling_slack,Bus_slack,Compute_slack,Energy_slack,Calib_slack)`。算子：
```
DSEP(M,cp,δ_f^req,budget):
 ① C_da 准入检查；不通过 → REACQUIRE/INFLATE/REJECT/降级
 ② F,O_cert ← FIM(ξ,u,D)；task_unobservable?
 ③ 若不可观测：e* ← DASE.plan(...)；若 e*=∅ 或 IG 不抵成本 → 膨胀并标记
 ④ D ← IPAC.acquire(e*,B_sense)；时间戳/来源链
 ⑤ ξ,Σ ← OASIS/UKF.update(D)；ECM.check → Σ_guard / EST_OOD
 ⑥ EV-se ← build_sense_evidence(...)；XMC++ 对账（仅权重/加宽）
 ⑦ (M,fused,D⁺,EV-exec,Cert) ← CLEP(M,cp,δ_f^req,Σ_guard)
 ⑧ B_sense ← update_sense_budget(...)
```
其中第 ⑦ 步的 `CLEP` 即第 59 轮定义 149，但 `Σ_exec` 一律替换为 `Σ_guard`。

**定义 160（感知-估计证书 J_sense）** `J_sense=(C_da,A_cert_d,O_cert,FIM/CRLB,ECM_log,excitation_log,compression_log,calibration_prov_chain,anchor_log,estimator_version,EV-se_log)`。要求：采集证书可独立重放、FIM/CRLB 可复算、锚点来源可追溯、压缩前后 `logdet F` 差异可审计、任何「无锚点却声称可辨识」的条目一律判无效。

## 4. 关键命题与可证伪预测

**命题 1（CRLB 地板，防过度自信）** 若 `O_cert` 诚实（FIM 模型正确、R 诚实），则对任意 `v∈S_id`，`v^TΣ_guard v ≥ 1/λ_i(F)`；对 `v∈S_null`，`v^TΣ_guard v ≥ v^TΣ_prior v`。因此 UKF 的「收敛」不再能单独作为 ID 证据；只有「收敛 ∧ 可辨识 ∧ 一致」才构成 `EV-se=ok`。

**命题 2（任务相关可辨识性）** 若 `F_φ` 可逆（或 `λ_min(F_φ)≥λ_req`），则下游接触力预测的方差有界，即使部分电机参数不可辨识；反之，若 `F_φ` 奇异，再多的全参数点估计也不能保证力预测可信。**这允许机器人「只学它需要的那几个方向」，从而降低激励成本。**

**命题 3（混叠-相位界）** 要无混叠分辨 `k` 阶齿槽谐波，采样率需 `f_s>2k f_e^max(1+margin)`；时间戳偏斜 `δ_t` 造成的相位误差为 `k ω_e δ_t`，故要求 `T_sync ≤ ε_phase/(k_max ω_e^max)`。以 `f_e=200 Hz, k=6, ε_phase=0.05 rad` 计，`T_sync≤6.6 μs`；普通以太网时间戳做不到，必须硬件触发/PTP 或把 skew 纳入状态并膨胀。

**命题 4（信息保持压缩的率-失真-信息三角）** 充分统计量遥测把回传量从 `O(N·m)` 降到 `O(d_ξ²)`，且 `logdet` 信息损失可界；在 `d_ξ=22` 时约 484 个浮点数/帧，10 Hz 回传约 19 kB/s（32-bit），相比 20 kHz×8 通道×16-bit≈320 kB/s 降低约 17 倍，而 CRLB 退化可控制在 `ε_F` 内。

**命题 5（锚点必要性）** 在无独立锚点的子空间上，任何「参数真值」声明都不可验证；系统必须输出集合/膨胀后验，而不是点估计。锚点可以来自关节力矩传感器、已知惯量自由摆动、已知质量/刚度负载、或受控环境标定。

**命题 6（安全单调性）** 采集违约、估计不一致、任务方向不可观测、激励风险超预算，四者任一发生，只能导致 `Σ_exec` 增大或动作更保守；`EV-se` 的「一致性」不能减少探针/佐证需求。这把第 59 轮「双向契约单向性」延伸到感知层。

**可证伪预测**：
1. 在堵转/恒速轻载工况，朴素 UKF 的 NEES 会显著低于 χ² 下界（过度自信），而 `Σ_guard` 能把 NEES 拉回 95% 带内。
2. 把遥测从 20 kHz 降到 1 kHz（不抗混叠）后，6 阶谐波会被混叠成 1~2 个虚假低频系数，力预测偏差增大；加入 `B_aa` 契约或充分统计量后偏差回落。
3. 在不接触、仅小角度摆动的工况，λ_pm 与 c_fric/offset 的 FIM 条件数爆炸；主动整周旋转 + 负载变化能把 `F_φ` 最小特征值提高一个数量级，但会消耗任务时间/能量。
4. 给定相同总线预算，充分统计量遥测比「降采样原始波形」获得更低的力预测方差与更好的 ECE。
5. 去掉关节力矩/已知负载锚点后，参数与力估计的误差相关性显著上升（自洽循环的可观测证据）。

```python
@dataclass
class ObservabilityCertificate:
    S_id: np.ndarray          # d×r 基
    S_null: np.ndarray        # d×(d−r) 基
    eigvals: np.ndarray
    rank: int
    cond: float
    crlb_diag: np.ndarray
    F_phi: np.ndarray
    task_unobservable: bool
    anchor_used: list
    lam_min: float
    timestamp: float

class ObservabilityAwareEstimator:
    def __init__(self, d_xi=22, K_ripple=6, lam_min=1e-4, lam_req=1e-3):
        self.d = d_xi
        self.K = K_ripple
        self.lam_min = lam_min
        self.lam_req = lam_req
        self.F = np.zeros((d_xi, d_xi))       # 递推 FIM
        self.Sigma_prior = np.eye(d_xi) * 1e2  # 弱先验

    def accumulate(self, H_t, R_t, forgetting=0.999):
        """H_t: m×d_xi 观测雅可比；R_t: m×m 噪声协方差"""
        self.F = forgetting * self.F + H_t.T @ np.linalg.solve(R_t, H_t)

    def certificate(self, J_phi, Sigma_post, anchors):
        w, V = np.linalg.eigh(self.F)                   # 升序
        S_id = V[:, w >= self.lam_min]
        S_null = V[:, w < self.lam_min]
        # CRLB 只在可辨识方向上有限
        crlb = np.array([1.0/wi if wi >= self.lam_min else np.inf for wi in w])
        # 任务相关 FIM：只关心下游 φ 的方向
        F_reg = self.F + 1e-9 * np.eye(self.d)
        F_phi = J_phi @ np.linalg.pinv(F_reg) @ J_phi.T
        task_obs = (np.linalg.matrix_rank(F_phi) == J_phi.shape[0]
                    and np.linalg.eigvalsh(F_phi).min() >= self.lam_req)
        # 无锚点时，强不可辨识方向不得声明为可辨识
        if not anchors:
            S_id = np.zeros((self.d, 0))
            S_null = V
            task_obs = False
        return ObservabilityCertificate(
            S_id=S_id, S_null=S_null, eigvals=w, rank=S_id.shape[1],
            cond=(w[-1]/max(w[0], 1e-12)), crlb_diag=crlb,
            F_phi=F_phi, task_unobservable=not task_obs,
            anchor_used=list(anchors), lam_min=self.lam_min,
            timestamp=time_now()
        )

    def guard_covariance(self, F_phi, Sigma_post, Sigma_prior, cert):
        """可辨识方向 ≥ CRLB；不可辨识方向 ≥ 先验；任务方向额外保护"""
        w, V = np.linalg.eigh(self.F)
        var_post = np.diag(V.T @ Sigma_post @ V)
        var_prior = np.diag(V.T @ Sigma_prior @ V)
        var_guard = var_post.copy()
        for i, wi in enumerate(w):
            if wi >= self.lam_min:
                var_guard[i] = max(var_post[i], 1.0/wi)      # CRLB 地板
            else:
                var_guard[i] = max(var_post[i], var_prior[i])  # 保留先验
        Sigma_id = V @ np.diag(var_guard) @ V.T
        # 任务方向不可辨识：沿 J_phi 方向再加一层保守膨胀
        if cert.task_unobservable:
            Jn = J_phi.T @ np.linalg.pinv(J_phi @ J_phi.T + 1e-9*np.eye(J_phi.shape[0]))
            Sigma_id = Sigma_id + Jn @ (self.sigma_task_floor**2 * np.eye(J_phi.shape[0])) @ Jn.T
        return Sigma_id
```

```python
class EstimatorConsistencyMonitor:
    def __init__(self, alpha=0.01, window=200, alpha_max=25.0, n_bad=3):
        self.alpha = alpha
        self.window = window
        self.alpha_max = alpha_max
        self.n_bad = n_bad
        self.nis_hist = deque(maxlen=window)
        self.nees_hist = deque(maxlen=window)
        self.innov_hist = deque(maxlen=2)
        self.bad_streak = 0

    def update(self, innovation, S, xi_hat, Sigma, xi_anchor=None):
        m = innovation.shape[0]
        d = xi_hat.shape[0]
        nis = float(innovation.T @ np.linalg.solve(S, innovation))
        self.nis_hist.append(nis)
        nees = None
        if xi_anchor is not None:
            err = xi_anchor - xi_hat
            nees = float(err.T @ np.linalg.solve(Sigma, err))
            self.nees_hist.append(nees)
        # 新息白性：lag-1 归一化自相关
        self.innov_hist.append(innovation / np.sqrt(np.diag(S) + 1e-12))
        white = True
        if len(self.innov_hist) == 2:
            rho = np.mean(self.innov_hist[1] * self.innov_hist[0])
            white = abs(rho) < 0.2

        nis_ok = True
        if len(self.nis_hist) >= min(50, self.window):
            mean_nis = np.mean(self.nis_hist) / m
            lo, hi = chi2.ppf(self.alpha/2, m)/m, chi2.ppf(1-self.alpha/2, m)/m
            nis_ok = lo <= mean_nis <= hi
        nees_ok = True
        if len(self.nees_hist) >= min(50, self.window):
            mean_nees = np.mean(self.nees_hist) / d
            lo, hi = chi2.ppf(self.alpha/2, d)/d, chi2.ppf(1-self.alpha/2, d)/d
            nees_ok = lo <= mean_nees <= hi

        ok = nis_ok and nees_ok and white
        Sigma_out = Sigma
        if not ok:
            self.bad_streak += 1
            ratio = (np.mean(self.nis_hist)/m) / max(chi2.ppf(1-self.alpha, m)/m, 1e-9)
            alpha_inf = float(np.clip(ratio, 1.0, self.alpha_max))
            Sigma_out = alpha_inf * Sigma
        else:
            self.bad_streak = 0
        est_ood = self.bad_streak >= self.n_bad
        return Sigma_out, {
            "nis_ok": nis_ok, "nees_ok": nees_ok, "white": white,
            "est_ood": est_ood, "alpha_inf": float(np.clip(
                (np.mean(self.nis_hist)/m) / max(chi2.ppf(1-self.alpha, m)/m, 1e-9),
                1.0, self.alpha_max)) if self.nis_hist else 1.0
        }

    def freeze_policy(self, est_ood):
        """连续不一致：冻结辨识、退回先验、要求重新标定/激励"""
        if est_ood:
            return "FREEZE_ID_AND_REQUEST_CALIB"
        return "CONTINUE"
```

### IP-155 IPAC（信息保持采集）

```python
class SufficientStatisticAccumulator:
    """在 MCU 上递推 (F,b)，只回传 O(d²) 充分统计量，而非原始高频波形。"""
    def __init__(self, d_xi, forget=0.9995):
        self.F = np.zeros((d_xi, d_xi))
        self.b = np.zeros(d_xi)
        self.forget = forget

    def update(self, H_t, R_t, y_t):
        Rinv = np.linalg.inv(R_t)
        self.F = self.forget * self.F + H_t.T @ Rinv @ H_t
        self.b = self.forget * self.b + H_t.T @ Rinv @ y_t

    def packet(self, bits_budget):
        # 特征基比特分配：按 F 的特征值/敏感度分配量化位数
        w, V = np.linalg.eigh(self.F)
        F_eig = np.abs(w)
        alloc = bit_allocation(F_eig, bits_budget)      # 总比特约束
        F_q = quantize_in_basis(self.F, V, alloc)
        b_q = quantize_vector(V.T @ self.b, alloc)
        return CompressedStats(F_q=F_q, b_q=b_q, basis=V, bits=sum(alloc))

def f_phi_after_compression(F, F_q, J_phi):
    F_phi = J_phi @ np.linalg.pinv(F + 1e-9*np.eye(F.shape[0])) @ J_phi.T
    F_phi_q = J_phi @ np.linalg.pinv(F_q + 1e-9*np.eye(F_q.shape[0])) @ J_phi.T
    return F_phi, F_phi_q

def information_loss(F, F_q):
    return abs(np.linalg.slogdet(F + 1e-9*np.eye(F.shape[0]))[1]
               - np.linalg.slogdet(F_q + 1e-9*np.eye(F_q.shape[0]))[1])

class EventTrigger:
    def __init__(self, gamma_nis=9.21, gamma_ig=0.01, heartbeat=0.01, tau_max=0.05):
        self.gamma_nis = gamma_nis
        self.gamma_ig = gamma_ig
        self.heartbeat = heartbeat
        self.tau_max = tau_max
        self.t_last = 0.0

    def should_send(self, innovation, S, ig_est, t_now):
        nis = float(innovation.T @ np.linalg.solve(S, innovation))
        due = (t_now - self.t_last) >= self.heartbeat
        urgent = nis > self.gamma_nis or ig_est > self.gamma_ig
        stale = (t_now - self.t_last) >= self.tau_max
        if urgent or due or stale:
            self.t_last = t_now
            return True, ("urgent" if urgent else "heartbeat" if due else "stale")
        return False, "skip"
```

### IP-156 DASE（数据-估计协同与主动激励）

```python
@dataclass
class Excitation:
    kind: str            # d_axis_injection / full_rev / force_modulation / load_change
    amplitude: float
    duration: float
    schedule: dict
    expected_energy: float

class DataEstimationCoDesign:
    def __init__(self, safety, budgets, lam_c=1.0, lam_r=10.0, lam_t=0.1):
        self.safety = safety
        self.budgets = budgets
        self.lam_c, self.lam_r, self.lam_t = lam_c, lam_r, lam_t

    def plan(self, xi, Sigma, J_phi, task_ctx):
        best, best_score = None, -np.inf
        for e in self._candidates(task_ctx):
            if not self.safety.admissible(e):            # EEIS 力/位置 + ERTC + B_exec
                continue
            F_phi = self._expected_task_fim(e, xi, Sigma)  # E_y[F_φ(e)]
            Sigma_phi = J_phi @ Sigma @ J_phi.T
            ig = 0.5 * np.linalg.slogdet(
                np.eye(Sigma_phi.shape[0]) + F_phi @ Sigma_phi)[1]
            cost = self.budgets.acq_cost(e) + self.budgets.exec_cost(e)
            risk = self.safety.risk(e)                   # 失稳/超力/任务扰动
            delay = e.duration
            score = ig - self.lam_c*cost - self.lam_r*risk - self.lam_t*delay
            if score > best_score:
                best, best_score = e, score
        if best is None or best_score <= 0.0:
            return None, -np.inf    # 不值得激励：诚实地膨胀，而不是假装知道
        return best, best_score

    def _candidates(self, task_ctx):
        yield Excitation("d_axis_injection", amplitude=0.05, duration=0.2,
                         schedule={"i_d": "sin(2π·50t)"}, expected_energy=0.1)
        yield Excitation("full_rev", amplitude=1.0, duration=1.0,
                         schedule={"theta": "0→2π"}, expected_energy=2.0)
        yield Excitation("force_modulation", amplitude=2.0, duration=0.5,
                         schedule={"F": "F0+2sin(2π·2t)"}, expected_energy=0.5)
        yield Excitation("load_change", amplitude=1.0, duration=0.8,
                         schedule={"load": "m→m+Δm"}, expected_energy=0.2)
```

### IP-158 DSEP（数据-感知-估计闭环）与 B_sense

```python
@dataclass
class SenseBudget:
    sampling_slack: float   # Hz 余量
    bus_slack: float        # bytes/s
    compute_slack: float    # ms/周期
    energy_slack: float     # J
    calib_slack: float      # s
    def is_viable(self):
        return min(self.sampling_slack, self.bus_slack,
                   self.compute_slack, self.energy_slack, self.calib_slack) > 0
    def acq_cost(self, e):
        return e.expected_energy / max(self.energy_slack, 1e-9)
    def exec_cost(self, e):
        return e.duration / max(self.compute_slack, 1e-9)

def data_sense_estimate_plan(M, cp, delta_f_req, budget):
    # ① 采集契约
    status, A_cert = M.dac.admit(M.next_packet(cp))
    if status == "REJECT":
        return degrade_exec_mode(M, cp, "ACQ_REJECT")
    # ② 可辨识性分析（当前 ξ, 数据窗口）
    J_phi = M.task_jacobian(cp)                # φ = 接触力/阻抗
    O_cert = M.oasis.certificate(J_phi, M.Sigma_post, M.anchors)
    if status == "INFLATE":
        M.Sigma_post = M.alpha_acq * M.Sigma_post
    # ③ 任务相关方向不可观测：主动激励或诚实膨胀
    if O_cert.task_unobservable:
        if not budget.sense.is_viable():
            M.Sigma_post = M.alpha_unobs * M.Sigma_post
            return degrade_exec_mode(M, cp, "UNOBSERVABLE_NO_BUDGET")
        e_star, score = M.dase.plan(M.xi, M.Sigma_post, J_phi, M.task_ctx)
        if e_star is None:
            M.Sigma_post = M.alpha_unobs * M.Sigma_post
            return degrade_exec_mode(M, cp, "UNOBSERVABLE_NO_EXCITATION")
        status = M.execute_excitation(e_star)   # 激励本身受 EEIS/ERTC 约束
        budget.sense.energy_slack -= e_star.expected_energy
    # ④ 信息保持采集
    D, comp_log = M.ipac.acquire(M.dac, budget.sense)
    if information_loss(M.oasis.F, D.F_q) > M.eps_F:
        return degrade_exec_mode(M, cp, "COMPRESSION_INFO_LOSS")
    # ⑤ 估计 + 一致性
    M.xi, M.Sigma_post, ecm_flags = M.oasis.update(D)
    M.Sigma_guard = M.oasis.guard_covariance(
        O_cert.F_phi, M.Sigma_post, M.Sigma_prior, O_cert)
    if ecm_flags["est_ood"]:
        M.Sigma_guard = M.alpha_est_ood * M.Sigma_guard
    # ⑥ 感知证据（只做对账质量，不作标签佐证）
    EV_se = build_sense_evidence(A_cert, O_cert, ecm_flags, M.anchors,
                                 tau_age=time_now() - A_cert.timestamp)
    M, fused, D_pp = xmodal_fuse_pp(M, cp.region, M.last_inf, M.EV_exec_last, EV_se)
    # ⑦ 交给第 59 轮 CLEP：Σ_exec 必须用 guarded 版本
    M, fused, D_plus, EV_exec, cert = closed_loop_exec_probe(
        M, cp, delta_f_req, budget, Sigma_guard=M.Sigma_guard)
    # ⑧ 预算与证书
    budget.sense = M.measure_sense_slack()
    M.J_sense.append(build_sense_certificate(A_cert, O_cert, ecm_flags, comp_log, EV_se))
    return M, fused, D_pp, EV_exec, cert, EV_se
```

| J_sense | O(1)/接触追加 | O(接触数) | 采集/CRLB/ECM/压缩/来源链可独立重放 |

**正确性定理（Sensing-Estimation Grounded Soundness, SEGS）**
假设 A22–A55（第 53–59 轮）成立；**(A56)** DAC：时间戳/偏斜/采样率/抗混叠/标定/来源链/数据年龄的检查诚实，丢包可检测，混叠上界成立。**(A57)** OASIS：FIM 由正确观测模型计算，`λ_min` 阈值固定；`Σ_guard` 在 `S_id` 上不低于 CRLB、在 `S_null` 上不低于先验；`task_unobservable` 判定不遗漏任务相关零空间。**(A58)** ECM：NIS/NEES/白性检验的显著性水平诚实；`α_inf` 有界，不允许无界缩小协方差；连续不一致会冻结辨识。**(A59)** DASE：激励方案满足 EEIS/ERTC/B_exec 所有硬约束；`IG_φ` 与 `cost_acq` 是诚实估计；无正收益则不激励。**(A60)** IPAC：压缩/量化/事件触发的信息损失界 `ε_F` 与心跳 `τ_max` 诚实；充分统计量递推无偏。**(A61)** EV-se：`sense` 只作为质量权重/协方差加宽，不提供标签似然；`degraded` 或来源链失败会回溯标记。则：

1. **不过度自信**：对任意 `v∈S_id`，`v^TΣ_guard v ≥ 1/λ_i(F)`；对 `v∈S_null`，`v^TΣ_guard v ≥ v^TΣ_prior v`。因此 UKF 的「收敛」不再单独构成 ID 证据。
2. **采集完整性**：若 `C_da` 成立，则数据无静默混叠/偏斜/丢包/未标定；若违约，数据被 `REACQUIRE/INFLATE/REJECT`，估计器不会把违约数据当作干净观测。
3. **任务相关安全**：若 `F_φ` 奇异且无安全激励，则 `Σ_guard` 膨胀，EEIS 得到更大的 `Σ_exec`，只能选择更软阻抗或降级；绝不因「估计收敛」而提高刚度。
4. **自指破除**：无独立锚点时 `S_id=∅`，`task_unobservable=true`，系统不输出「参数真值」点估计；锚点日志可追溯。
5. **安全单调性**：采集违约、估计不一致、任务方向不可观测、激励风险超预算，四者任一发生只能使后验更宽、动作更保守；`EV-se` 的一致性不能减少探针/佐证需求。
6. **终止性**：DSEP 的采集重试/激励/估计循环受 `B_sense` 与 `k_acq` 限制，最终终止于 `{CLEP 承诺(带 Cert_eeis 与 J_sense), 绕行, 降档, L2 协商, 安全停, ACQ/EST/UNOBSERVABLE 降级停}`。
7. **部署界**（对检查点取联合界，在第 59 轮基础上增加感知项）：

```
P_safe ≥ 1 − Σ_cp ( δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                   + δ_ft·1[回滚窗口] + δ_kg·1[检索失败] + δ_ux·1[μ_mis>θ_mis]
```

## 6. 本轮最大风险

**一句话**：本轮把「感知-估计」也纳入证书体系，但 FIM、NEES、CRLB、压缩误差界全部依赖同一个可能错误的模型——若采集契约、噪声模型或任务相关雅可比本身有偏，系统会得到一套「互相自洽、且比第 59 轮更精致」的假证据，因此必须用独立物理锚点、对抗性采集扰动和留出集来打破这个证书回声室，否则最危险的不是不知道，而是「有证书地不知道」。
