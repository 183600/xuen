# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「开放词汇」×「双臂协作」）

> 第 54 轮把技能组合做成动作空间剖面 `α_S` + 组合图 `G_S` + 云边协同 `γ_ce` 的可判定体系。本轮同时捅破两个封闭假设：**开放词汇**捅破"技能库可枚举"，**双臂协作**捅破"动作空间是单臂的"。核心矛盾：H22：开放词汇的语义近邻 ≠ 动作可行，novel 指令易被静默接地到动作不兼容的旧技能；H23：单臂各自可执行的接地，在双臂相对位姿/力闭合/时序耦合下联合不可行；H24：开放词汇撑大候选集、双臂耦合压小可行域，二者叠加使"语义像、单臂能做、联合不可行"的假阳性组合急剧增多。

## 0. 直觉与动机

**灵感 1（语义-动作双向接地，而不是单向语义检索）**
直觉：开放词汇系统通常用 CLIP 式嵌入做"指令→技能"最近邻检索，但语义相似只保证"能指相近"，不保证"所指可执行"。要把接地定义为双向约束：概念 `c` 既要在语义上靠近技能描述 `e(S)`，也要在动作上靠近其剖面 `α_S`。记 **affordance 一致性** `cons(c,S)=sim(e(c),e(S)) − λ·d_A(φ(e(c)),α_S)`。单向检索会让"拿起杯子"与"拿起锤子"因语义近邻而误接地，双向接地则用动作剖面剔除语义假近邻。

**灵感 2（共形开放词汇证书：用预测集表达"不知道"）**
直觉：开放词汇的本质是存在未见过概念，任何单点分类都会在 novelty 上过度自信。引入共形预测：在校准集上算不相似度分数，构造接地集 `Γ_ε(c)`，使其以 `1−ε` 概率包含正确技能。三种决策：单例→可接地；多例→语义歧义，用动作兼容性或上下文消歧；空集→novel，触发技能组合或主动询问。这把"开放词汇"从"必须猜一个"变成"可证明地知道何时不该猜"。

**灵感 3（双臂动作空间是带耦合流形的乘积空间，不是两个单臂的并集）**
直觉：双臂不是 `A_L ∪ A_R`。真正可执行的是耦合流形 `M_bi ⊂ A_L×A_R`：相对位姿在包络内、力闭合有裕度、双臂无碰撞、时序同步偏差受限。双臂技能剖面 `α_{S_bi}(a_L,a_R)` 只在 `M_bi` 上有意义。因此双臂组合的第一性问题不是"两只手各自会不会"，而是"两手的相对关系是否落在耦合流形上"。

**灵感 4（角色分配 + 协同图：开放词汇要决定"谁来做、怎么配合"）**
直觉：开放词汇指令往往只描述目标（"把箱子搬上桌"），不描述左右手分工。需要角色分配 `σ: 概念→{L,R,both,handover}`，以及协同图 `G_bi`：节点是协同原语（共持、交接、主从、独立），边是协同兼容性。开放词汇接地因此在双臂条件下变成"概念接地 × 角色分配 × 协同原语"的三元联合搜索，而非两个独立接地的拼接。

**灵感 5（联合证书：单臂证书在双臂空间中会失效，必须重签）**
直觉：第 54 轮的 `J=(ρ,A_cert,γ_ce,δ_a)` 是单臂证书。双臂需要 `BCC=(R_env,φ_f,τ_sync,h_margin,ρ_bi)`，其中交接安全裕度 `h_margin` 是单臂没有的。开放词汇双臂联合证书 `Ω` 必须同时携带两臂接地集、角色分配、耦合证书与两臂的 `J`；只有当存在一对接地 `(S_L,S_R)` 使耦合流形可行且两臂证书均成立时，才可部署。

**灵感 6（从"动作-鲁棒性双证书"到"语义-动作-协同三层证书"）**
直觉：在第 54 轮金字塔上再加 **开放词汇语义层 `𝕆`** 与 **双臂协同层 `𝔹`**。跨层传递不再是单一 `ρ` 或 `A_cert`，而是三元组 `(Γ_ε, BCC, J)`。这把可判定组合提升为"开放世界下的联合可判定"。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（开放词汇概念空间与语义-动作桥）**
概念空间 `C` 是开放集合（不预先枚举），语义嵌入 `e : C → ℝ^d`，技能 `S` 的语义描述嵌入 `e(S)`。语义-动作桥 `φ : ℝ^d → P(A)` 把语义嵌入映到动作剖面空间（`P(A)` 为剖面集合）。**affordance 一致性**：
```
cons(c,S) = sim(e(c), e(S)) − λ·d_A(φ(e(c)), α_S)
```
其中 `sim` 为余弦相似、`d_A` 为剖面距离、`λ` 为语义-动作权衡系数。

**定义 122（共形接地集）**
校准集 `{(c_i, S_i*)}`（已知概念与其真值技能），不相似度 `s(c,S)=1−cons(c,S)`。取分位数
```
q = Quantile_{⌈(n+1)(1−ε)⌉/n}({s(c_i,S_i*)})
```
定义接地集 `Γ_ε(c) = { S ∈ Skills : s(c,S) ≤ q }`。若概念与校准集可交换，则 `P(S* ∈ Γ_ε(c)) ≥ 1−ε`。

**定义 123（接地决策与开放集风险）**
接地决策 `δ(c) ∈ {GROUND, RESOLVE, NOVEL, ABSTAIN}`：
- `|Γ_ε(c)|=1` 且 `cover(S,A_T)=1` → `GROUND`；
- `|Γ_ε(c)|>1` → `RESOLVE`（按动作兼容性/上下文消歧）；
- `|Γ_ε(c)|=0` → `NOVEL`（触发技能组合）或 `ABSTAIN`（主动询问）。
**开放集风险** `R_ov = P(δ=GROUND ∧ S_grounded≠S*) + P(δ=RESOLVE ∧ 消歧错误)`，目标在预算 `ε_ov` 下最小化 `R_ov`，并控制 `E[|Γ_ε(c)|]`。

**定义 124（双臂耦合动作空间）**
`A_bi = A_L × A_R`。耦合约束
```
C_bi = { r∈ℛ_env, φ_f≥φ_min, ¬collide(a_L,a_R), |t_L−t_R|≤τ_sync }
```
耦合流形 `M_bi = { (a_L,a_R)∈A_bi : (a_L,a_R) ⊨ C_bi }`。双臂技能剖面 `α_{S_bi} : M_bi → [0,1]`；**双臂覆盖** `cover_bi(S_bi,A_T)=1` 当且仅当 `∀(a_L,a_R)∈A_T, α_{S_bi}≥θ_cov`。

**定义 125（角色分配与协同图）**
角色分配 `σ : Concepts → {L,R,both,handover}`。协同原语集 `O = {co-hold, handover, leader-follower, independent}`。协同图 `G_bi=(V_bi,E_bi)`：节点为 `(S_bi,o)`，边附耦合兼容性 `compat_bi` 与候选耦合证书 `BCC`。

**定义 126（双臂耦合证书）**
```
BCC = (R_env, φ_f, τ_sync, h_margin, ρ_bi, evidence)
```
`h_margin` 为交接时刻相对位姿/力的安全裕度。可部署当且仅当：`r∈ℛ_env`、`φ_f≥φ_min`、`τ_sync≤τ_max`、`h_margin≥h_min`、`min ρ_bi≥ρ_min`。

**定义 127（开放词汇双臂联合证书）**
```
Ω = (Γ_ε^L, Γ_ε^R, σ, BCC, J_L, J_R, evidence)
```
**联合可行谓词** `feas_bi(Ω)=1` 当且仅当存在 `(S_L,S_R) ∈ Γ_ε^L × Γ_ε^R` 与角色分配 `σ`，使：
1. `cover_bi(S_L⊗S_R, A_T)=1`，且组合在 `M_bi` 上动作兼容；
2. `BCC` 全部预算闭合（`R_env, φ_f, τ_sync, h_margin, ρ_bi`）；
3. 两臂联合证书 `J_L, J_R` 均成立。
消歧目标：在满足 1–3 的候选中取耦合裕度最大者 `argmax coupling_margin(BCC)`。

## 2. 关键算法 伪代码

### IP-121 OVG（Open-Vocabulary Grounding）

```python
def semantic_action_bridge(concept, skill_lib, phi, lam):
    e = embed(concept)
    alpha_hat = phi(e)
    scored = []
    for S in skill_lib:
        cons = cosine(e, S.text_emb) - lam * action_dist(alpha_hat, S.alpha)
        scored.append((S, cons))
    return scored
```

### IP-122 CPC（Conformal Prediction Certificate）

```python
def conformal_grounding(concept, skill_lib, calib, eps, phi, lam):
    n = len(calib)
    scores = [1.0 - cons(c, S_star, phi, lam) for c, S_star in calib]
    k = math.ceil((n + 1) * (1 - eps))
    q = sorted(scores)[min(k, n) - 1]
    pairs = semantic_action_bridge(concept, skill_lib, phi, lam)
    gamma = [S for S, cons in pairs if (1.0 - cons) <= q]
    return gamma, q

def grounding_decision(gamma, task_actions, ctx):
    if len(gamma) == 0:
        return ('NOVEL', trigger_composition_or_ask(ctx))
    if len(gamma) == 1 and cover_check(gamma[0].alpha, task_actions):
        return ('GROUND', gamma[0])
    feasible = [S for S in gamma if cover_check(S.alpha, task_actions)]
    if not feasible:
        return ('ABSTAIN', 'no_action_consistent_grounding')
    if len(feasible) == 1:
        return ('GROUND', feasible[0])
    return ('RESOLVE', argmax(feasible, key=lambda S: action_compat(S, ctx)))
```

### IP-123 BAS（Bimanual Action Space）

```python
def bimanual_feasible(a_L, a_R, C):
    r = relative_pose(a_L, a_R)
    return (in_envelope(r, C.R_env)
            and force_closure(a_L, a_R) >= C.phi_min
            and not collide(a_L, a_R)
            and abs(time(a_L) - time(a_R)) <= C.tau_sync)
```

### IP-124 BAG（Bimanual Assignment Graph）

```python
def assign_roles(concepts, primitives, coupling_cost):
    best = None
    for sigma in role_assignments(concepts):      # concepts -> {L,R,both,handover}
        G = build_coordination_graph(concepts, sigma, primitives)
        for e in G.edges:
            e.compat = compat_bi(e.u, e.v, sigma)
        if not all(e.compat >= theta_bi for e in G.edges):
            continue
        cost = coupling_cost(G)
        if best is None or cost < best.cost:
            best = (sigma, G, cost)
    return best
```

### IP-125 BCC（Bimanual Coupling Certificate）

```python
def coupling_certificate(seq_L, seq_R, C, rho_min):
    r_ok = all(in_envelope(relative_pose(l, r), C.R_env)
               for l, r in zip(seq_L, seq_R))
    phi_f = min(force_closure(l, r) for l, r in zip(seq_L, seq_R))
    sync = max(abs(time(l) - time(r)) for l, r in zip(seq_L, seq_R))
    h = handover_margin(seq_L, seq_R)
    rho_bi = compose_bimanual_robustness(seq_L, seq_R, K_bi)
    ok = (r_ok and phi_f >= C.phi_min and sync <= C.tau_max
          and h >= C.h_min and min(rho_bi.values()) >= rho_min)
    return ('ok' if ok else 'reject'), BCC(C.R_env, phi_f, sync, h, rho_bi)
```

### IP-126 OBC（Open-vocabulary Bimanual Certifier）

```python
def open_vocab_bimanual_certify(concept, ctx, calib_L, calib_R, C, budgets):
    G_L, _ = conformal_grounding(concept, skills_L, calib_L, eps, phi)
    G_R, _ = conformal_grounding(concept, skills_R, calib_R, eps, phi)
    if not G_L or not G_R:
        return ('NOVEL_OR_ABSTAIN', G_L, G_R)
    best = None
    for sigma in role_assignments(concept):
        for SL in G_L:
            for SR in G_R:
                if not cover_bi(SL, SR, ctx.A_T):
                    continue
                ok, bcc = coupling_certificate(ctx.seq_L, ctx.seq_R, C, ctx.rho_min)
                if not ok:
                    continue
                okL, JL = joint_certificate([SL], ctx.gamma_ce, budgets.delta_a, ctx.rho_min)
                okR, JR = joint_certificate([SR], ctx.gamma_ce, budgets.delta_a, ctx.rho_min)
                if not (okL and okR):
                    continue
                score = coupling_margin(bcc)
                if best is None or score > best.score:
                    best = (sigma, SL, SR, bcc, JL, JR, score)
    if best is None:
        return ('REJECT', 'no_jointly_feasible_grounding')
    return ('OK', Omega(G_L, G_R, *best))
```

### IP-127 RGD（Realization Gap Detector）

```python
def realization_gap(concept, S, sim_model, delta_max):
    d_sem = 1.0 - cosine(embed(concept), S.text_emb)
    d_act = action_dist(phi(embed(concept)), S.alpha)
    sim_ok = sim_model.run(S, concept).success
    gap = d_sem + alpha * d_act + beta * (0.0 if sim_ok else 1.0)
    return ('abstain' if gap > delta_max else 'ok', gap)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| OVG | O(\|Skills\|·d + \|Skills\|·\|A\|) | O(d+\|A\|) | 语义-动作一致、φ Lipschitz |
| CPC | O(n log n + \|Skills\|·d) | O(n+\|Skills\|) | 校准可交换、分数对称 |
| BAS | O(\|A_L\|·\|A_R\|) | O(\|M_bi\|) | 耦合约束 sound、包络保守 |
| BAG | O(\|σ\|·\|Concepts\|²) | O(\|V_bi\|+\|E_bi\|) | 角色分配完备、边兼容 sound |
| BCC | O(k·(\|A\|+\|𝔇_ρ\|)) | O(\|A\|+\|𝔇_ρ\|) | 各预算闭合、h_margin 保守 |
| OBC | O(\|Γ_L\|·\|Γ_R\|·\|σ\|·k) | O(\|Ω\|) | 联合可行穷举、证书 sound |

**正确性定理（Open-Vocabulary Bimanual Joint Soundness）**
承接第 53/54 轮 (A22)–(A28)；新增：
**(A29)** 各臂在其概念分层内校准集与测试概念可交换；
**(A30)** 语义-动作桥 `φ` 在接地邻域内 Lipschitz 常数 `L_φ`；
**(A31)** 耦合流形估计误差 `‖M̂_bi−M_bi‖ ≤ δ_M`，且包络估计保守；
**(A32)** 角色分配 `σ` 的错配概率 `P(σ≠σ*) ≤ β_σ`。
则部署成功概率：
```
P_success(Ω) ≥ 1 − 2ε − P(δ_M>Θ_M) − β_σ − Σ_{arm∈{L,R}} Σ_d (1−ρ_min(d)) − P(ε_ov 超预算)
```
关键：**双中共形**（两臂 union bound 得 `2ε`）、**耦合流形保守**、**角色分配可证**、**两臂鲁棒性谱独立闭合**。

## 6. 本轮最大风险

**一句话**：共形覆盖依赖可交换性、耦合流形假设静态，而开放词汇双臂任务恰恰是**非交换、接触动态强耦合**的——分布漂移会让覆盖率在最需要它的 novel 双臂指令上失效，从而产出"统计上合规、物理上错位"的**假联合证书**；因此必须用 **自适应分层共形 + 接触感知的时变耦合流形 + 强制弃权绊线** 三重护栏，宁可对新型双臂指令说"不知道"，也绝不把"语义合理 + 单臂可做"当作"双臂联合可部署"。

def semantic_action_bridge(concept, skill_lib, phi, lam):

### IP-122 CPC

```python
def conformal_grounding(concept, skill_lib, calib, eps, phi, lam):
    n = len(calib)
    scores = [1.0 - cons(c, S_star, phi, lam) for c, S_star in calib]
    k = math.ceil((n + 1) * (1 - eps))
    q = sorted(scores)[min(k, n) - 1]
    return [S for S, cons in semantic_action_bridge(concept, skill_lib, phi, lam)
            if 1.0 - cons <= q], q

def grounding_decision(gamma, A_T, ctx):
    if len(gamma) == 0:
        return ('NOVEL', trigger_composition_or_ask(ctx))
    feasible = [S for S in gamma if cover_check(S.alpha, A_T)]
    if not feasible:
        return ('ABSTAIN', 'no_action_consistent_grounding')
    if len(feasible) == 1:
        return ('GROUND', feasible[0])
    return ('RESOLVE', argmax(feasible, key=lambda S: action_compat(S, ctx)))
```

def assign_roles(concepts, primitives, coupling_cost):
    best = None
    for sigma in role_assignments(concepts):
        G = build_coordination_graph(concepts, sigma, primitives)
        if any(compat_bi(e.u, e.v, sigma) < theta_bi for e in G.edges):

### IP-125 BCC

```python
def coupling_certificate(seq_L, seq_R, C, rho_min):
    r_ok = all(in_envelope(relative_pose(l, r), C.R_env)
               for l, r in zip(seq_L, seq_R))
    phi_f = min(force_closure(l, r) for l, r in zip(seq_L, seq_R))
    sync = max(abs(time(l) - time(r)) for l, r in zip(seq_L, seq_R))
    h = handover_margin(seq_L, seq_R)
    rho_bi = compose_bimanual_robustness(seq_L, seq_R, K_bi)
    ok = (r_ok and phi_f >= C.phi_min and sync <= C.tau_max
          and h >= C.h_min and min(rho_bi.values()) >= rho_min)
    return ('ok' if ok else 'reject'), BCC(C.R_env, phi_f, sync, h, rho_bi)
```

### IP-126 OBC

```python
def open_vocab_bimanual_certify(concept, ctx, calib_L, calib_R, C, budgets):
    G_L, _ = conformal_grounding(concept, skills_L, calib_L, eps, phi)
    G_R, _ = conformal_grounding(concept, skills_R, calib_R, eps, phi)
    if not G_L or not G_R:
        return ('NOVEL_OR_ABSTAIN', G_L, G_R)
    best = None
    for sigma in role_assignments(concept):
        for SL in G_L:
            for SR in G_R:
                if not cover_bi(SL, SR, ctx.A_T):
                    continue
                ok, bcc = coupling_certificate(ctx.seq_L, ctx.seq_R, C, ctx.rho_min)
                if not ok:
                    continue
                okL, JL = joint_certificate([SL], ctx.gamma_ce, budgets.delta_a, ctx.rho_min)
                okR, JR = joint_certificate([SR], ctx.gamma_ce, budgets.delta_a, ctx.rho_min)
                if not (okL and okR):
                    continue
                score = coupling_margin(bcc)
                if best is None or score > best.score:
                    best = (sigma, SL, SR, bcc, JL, JR, score)
    if best is None:
        return ('REJECT', 'no_jointly_feasible_grounding')
    return ('OK', Omega(G_L, G_R, *best))
```

### IP-127 RGD

```python
def realization_gap(concept, S, sim_model, delta_max):
    d_sem = 1.0 - cosine(embed(concept), S.text_emb)
    d_act = action_dist(phi(embed(concept)), S.alpha)
    sim_ok = sim_model.run(S, concept).success
    gap = d_sem + alpha * d_act + beta * (0.0 if sim_ok else 1.0)
    return ('abstain' if gap > delta_max else 'ok', gap)
```

## 6. 本轮最大风险

**一句话**：共形覆盖依赖可交换性、耦合流形假设静态，而开放词汇双臂任务恰恰是**非交换、接触动态强耦合**的——分布漂移会让覆盖率在最需要它的 novel 双臂指令上失效，从而产出"统计上合规、物理上错位"的**假联合证书**；因此必须用 **自适应分层共形 + 接触感知的时变耦合流形 + 强制弃权绊线** 三重护栏，宁可对新型双臂指令说"不知道"，也绝不把"语义合理 + 单臂可做"当作"双臂联合可部署"。
