### 第 6 轮灵感驱动研究记录

**灵感词**：移动操作、传感器融合

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把「规则提议」升级为「认证的生成式执行」（CGE）：条件流匹配提议 π_θ^FM、嵌入记忆与固化 LMEM-v2、面部情感调制 FAMK，并用定理 6（证书不变性）证明「换提议不换门」。执行集嵌套 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。本轮不推翻 v5，而是补 v5 的两个**隐含前提**（它们一直被当作「环境假设」而非「被认证对象」）：(a) **固定基座假设**——v5 的七门（尤其 BCK 的 ZMP/支撑多边形、EEK 的末端可达）都写在静态世界系里，移动操作让基座成为自由度，「平衡」不再是静态 ZMP，而是浮动基 + 机械臂的整体动力学；(b) **洁净同步感知假设**——v5 的门在「点估计状态」上求值，默认估计即真值；传感器融合带来标定漂移、异步延迟、相关噪声与共模故障，证书可能对估计成立而对真值不成立。两个灵感词统一为主题「认证的移动具身与融合感知」（Certified Mobile Embodiment with Fused Perception, CMEF），形成 CADVS-v6（IP-497~500）。本轮自律：**硬门数量仍不增**（维持七门），把移动与融合作为「门的鲁棒化 + 门谓词的整机推广」处理：BCK 推广为整机动力学 WBKC，所有门在融合置信集上鲁棒化 RFCK，STFAK 只做信任裁决与降级。执行集升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5。

**直觉与动机**：

1. **移动操作 → 平衡门从「静态 ZMP」推广为「整机质心动力学 + 时变支撑」**。直觉上，站在原地的机械臂只要 ZMP 落在脚掌多边形内就稳；但移动机器人一边走一边伸手，支撑多边形随步态/轮地接触不断变化，质心加速度由接触力整体决定，单看 ZMP 会漏掉「基座-机械臂耦合」的失稳（例如伸手瞬间质心偏移 + 轮子打滑）。形式化上，把 v5 的 BCK 推广为整机运动动力学证书 WBKC：以质心动力学 m(ċ−g)=Σf_k、dL/dt=Σ(p_k−c)×f_k+τ_k 为约束，接触力满足逐点摩擦锥/单向锥 CWC_k，支撑区 P(t)=conv(活动接触点投影) 随时间变化，用捕获点/DCM ξ=c+ċ/ω₀ 的可达性替代静态 ZMP 判据。关键性质（定理 12）：基座静止、接触固定、基速为零时，WBKC 精确退化为 v5 的 BCK/ZMP——这是「推广」而非「另起炉灶」的判据，也是执行集嵌套的保证。

2. **传感器融合 → 证书必须对「状态不确定性」鲁棒，而不是对点估计成立**。直觉上，融合给了我们一个估计 ŝ 和协方差 Σ̂，但门要求的是真值 s 满足安全谓词。若只在 ŝ 上判门，标定误差、SLAM 漂移、异步延迟都会让证书「看起来对、实际错」。形式化上引入鲁棒证书 RFCK：用融合置信集 U_δ(ŝ)={s:(s−ŝ)ᵀΣ̂⁻¹(s−ŝ)≤χ²_{n_s}(1−δ)}（或更稳健的 conformal/区间包络）表示真值可能所在区域，门在 U_δ 上取最坏情形：kc_i^rob(x;U_δ)=1 ⟺ ∀s∈U_δ, kc_i(x;s)=1。对仿射边际 aᵀs+b，最坏情形有闭式 aᵀŝ+b−√χ²·‖Σ̂^{1/2}a‖，于是「鲁棒门」= 点估计边际减去一个**不确定性膨胀项**。定理 9 给出可靠性：若 U_δ 以概率 ≥1−δ 覆盖真值，则鲁棒门成立 ⇒ 真值违反门概率 ≤δ。这把「证书」从「对估计的断言」升级为「对真值的概率保证」。

3. **传感器融合的工程真相 → 相关性、故障与共模漂移，必须显式建模为信任问题**。直觉上，多传感器不是简单「越多越准」：轮式里程计打滑、IMU 偏置随机游走、视觉在弱纹理处漂移、LiDAR 在玻璃/雨天退化，且这些误差**相关**（同一次打滑同时污染里程计与 IMU 预积分）。朴素卡尔曼假设独立会把 Σ 估小，直接导致鲁棒证书过度自信。形式化上引入 STFAK：用 NEES/卡方一致性检验监控每个传感器，做故障检测与隔离（FDI），用**协方差交集 CI**（Σ_CI⁻¹=Σ_j ω_jΣ_j⁻¹，Σω_j=1）在未知相关下保持一致性（引理 45），并把「里程计 vs 视觉 vs LiDAR 三角校验」作为共模漂移监测。信任分 w_j 低于地板 → 剔除该源并沿降级阶梯（L0 正常/L1 降速/L2 静态保持/L3 安全停）fail-closed。定理 10 给出信息单调性：融合更多一致传感器 ⇒ Σ_CI 在 Loewner 序下变小 ⇒ U 变小 ⇒ 认证集单调变大；反之丢传感器则收缩——这让「感知退化」与「安全收缩」方向一致。

**关键洞见**：v5 回答「提议=任意生成器时证书边界是否不变」；v6 回答「当基座会动、感知会错时，证书边界还能否保持可靠」。答案是把两个被 v5 当作「环境」的东西拉进「被认证对象」：基座动力学进入 BCK 的推广 WBKC，感知不确定性进入所有门的鲁棒化 RFCK，感知故障进入信任裁决 STFAK。七硬门记号 kc_evidence_forged_v5 原样复用；新增的只有鲁棒边际膨胀、整机动力学约束、时变支撑与信任降级，以及**证书租约**（时变有效性）。执行集 Exec_v6 ⊆ Exec_v5 由「鲁棒门 ⇒ 点估计门（U∋ŝ）+ 整机门 ⇒ 静态门（退化）+ 信任不足则拒绝」三重保证。

**形式化目标（增量）**：
1. 融合状态：真值 s、融合估计 ŝ、CI 协方差 Σ_CI；置信集 U_δ(ŝ)={s:(s−ŝ)ᵀΣ_CI⁻¹(s−ŝ)≤χ²_{n_s}(1−δ)}；鲁棒门 kc_i^rob(x;U_δ)=∀s∈U_δ kc_i(x;s)。
2. WBKC：质心动力学 + 接触锥 CWC + 时变支撑 P(t) + DCM 可达性；静态退化定理。
3. STFAK：NEES 一致性、FDI、信任加权 CI、共模漂移监测、降级阶梯 D∈{L0,L1,L2,L3}。
4. 证书租约：状态速度界 ‖ṡ‖≤v_max 下的有效期 T_lease，超期证书失效。
5. 定理 9（鲁棒可靠性）、定理 10（信息单调性）、定理 11（租约时效）、定理 12（整机退化/嵌套）、定理 13（七锚完备性）。
6. Exec_CADVS-v6 = {x : ∧_i kc_i^rob(x; U_δ, τ_i^6)=1, t−t_cert ≤ T_lease} ⊆ Exec_CADVS-v5。

**本轮最大风险**：**不确定性模型的过度自信**——鲁棒证书的全部可靠性都押在「U_δ 以 1−δ 覆盖真值」上，而协方差标定、CI 的个体一致性前提、共模漂移的可检测性都只能在受控条件下近似成立；一旦 Σ 被系统性低估（打滑、偏置、同步误差、SLAM 共模漂移），U_δ 会漏掉真值，鲁棒门退化为「形式更严、实质更假的保证」，且系统对此无法自证。

```
       ├─ D ≥ L2 ──▶ fail-closed 降级（静态保持/安全停）

                          └─ 幸存 ≤3 ──▶ VACK 鲁棒门 ──▶ WBKC 预览 ──▶ 证书 + 租约

在线控制环（目标 < 0.7 ms）：
  每周期：EEK(kc_ee) 鲁棒边际 + WBKC（事件触发：接触拓扑不变 → 缓存 + 解析内插）
  证书消费：检查 t − t_cert ≤ T_lease；超期 → 重新评估或安全保持
  鲁棒膨胀 infl_i 为仿射闭式，O(n_s²)，可离线预算/在线查表
```

## 3. 复杂度分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 | 实时性指标 |
|---|---|---|---|---|
| STFAK.fuse | O(m·n_s² + n_s³)（CI 求逆） | O(m·n_s²) | m≤8, n_s≤40 | ~0.2–0.6 ms，10–50 Hz |
| RFCK.confidence_set | O(n_s³)（一次 Cholesky） | O(n_s²) | n_s≤40 | <0.1 ms |
| RFCK.robust_affine_margin | O(n_s²)（矩阵-向量） | O(n_s) | 每门一次 | <0.01 ms/门 |
| WBKC.evaluate | 触发 O((n_dof+n_c)³)，否则 O(1) 内插 | O((n_dof+n_c)²) | n_dof≤20, n_c≤8 | 触发率 ~10%，P99 ~0.65 ms |
| WBKC.margin | O(n_c) | O(1) | — | <0.01 ms |
| EFA-v6 硬门 | O(1)（阈值/膨胀预算） | O(1) | — | <0.05 ms |
| 端到端控制环 | — | — | — | **P99 ~0.68 ms（v5 0.55 ms，+24%）** |

**通信开销**：CI 仅需各源 (ŝ_j, Σ_j) 摘要与信任分；原始测量不出端/不出站；标定统计过 DP；租约与降级状态为本地 O(1) 状态。

**实时性说明（诚实）**：移动操作让控制环从「机械臂 7–20 DOF」扩到「基座+臂」，WBKC 的 QP 更大，P99 上升约 24%。缓解：事件触发（接触拓扑不变复用缓存）、DCM/接触锥边际解析内插、鲁棒膨胀预算化。**不宣称**进 1 kHz 硬实时；1 kHz 层只消费缓存证书与租约，WBKC 在 100–500 Hz 事件触发层运行。

## 4. 正确性论证（增量更新）

### 引理 45（CI 在未知相关下的一致性）

**陈述**：设各源估计一致：Σ_j ⪰ E[(ŝ_j−s)(ŝ_j−s)ᵀ]，且对任意交叉相关成立。取 Σ_CI⁻¹=Σ_j ω_jΣ_j⁻¹, ω_j≥0, Σω_j=1，则 Σ_CI ⪰ E[(ŝ_CI−s)(ŝ_CI−s)ᵀ]。∎

**意义**：无需知道传感器间相关结构即可保持一致性——这是「共模/未知相关」下仍能构造 U_δ 的依据。**诚实边界**：前提「各源自身一致」若被违反（标定错误、系统偏置），CI 也救不回来。

### 引理 46（椭球上仿射边际的闭式最坏情形）

**陈述**：U={s:(s−ŝ)ᵀΣ⁻¹(s−ŝ)≤r²}，则 min_{s∈U}(aᵀs+b)=aᵀŝ+b−r‖Σ^{1/2}a‖，且在 s*=ŝ−rΣa/√(aᵀΣa) 取到。∎

**意义**：鲁棒门可 O(n_s²) 精确计算，无需采样。

### 引理 47（NEES 卡方界）

**陈述**：若估计一致且高斯，则 NEES_j ~ χ²_{n_z}；以 [χ²_{n_z}(α/2), χ²_{n_z}(1−α/2)] 做双侧检验，误报率 ≤ α。∎

**诚实边界**：非高斯/相关时仅近似；故 NEES 只用于信任降权，不作安全保证。

### 定理 9（鲁棒证书可靠性）

**陈述**：若 U_δ 以概率 ≥1−δ 覆盖真值 s（即 P(s∉U_δ)≤δ），且 kc_i^rob(x;U_δ)=1，则 P(kc_i(x;s)=0)≤δ。∎

**证明**：kc_i(x;s)=0 且 kc_i^rob=1 ⇒ s∉U_δ；由覆盖假设概率 ≤δ。∎

**工程含义**：证书从「对估计的断言」升级为「对真值的概率保证」，δ 是显式的可信度预算。

### 定理 10（信息单调性）

**陈述**：若融合更多一致传感器使 Σ_CI 在 Loewner 序下不增（Σ_CI(A∪B) ⪯ Σ_CI(A)），则 U_δ(A∪B) ⊆ U_δ(A)，从而 Exec(A∪B) ⊇ Exec(A)。反之剔除传感器则认证集收缩。∎

**证明**：Loewner 序 ⇒ 椭球包含；鲁棒边际 aᵀŝ+b−r‖Σ^{1/2}a‖ 随 Σ 变小而增大 ⇒ 门通过集单调扩。∎

**工程含义**：感知越健康，可认证执行集越大；感知退化时安全集自动收缩——方向一致，无「越坏越敢动」的悖论。

### 定理 11（租约时效性）

**陈述**：设 ‖ṡ(t)‖≤v_max，证书在 t_c 以 U_δ 铸出。则对 t≥t_c，s(t)∈U_δ⊕B(v_max(t−t_c))。取 T_lease=sup{Δ≥0 : ∀x, robust_margin(x; U_δ⊕B(v_maxΔ)) ≥ τ}，则 t−t_c≤T_lease 时证书对真值仍可靠；超期消费不保证可靠。∎

**证明**：状态速度界 ⇒ 状态漂移的 Minkowski 包含；鲁棒边际对膨胀集单调不增。∎

**工程含义**：证书是「易腐品」，必须有 TTL；这堵住了「用旧估计给新时刻背书」的漏洞。

### 定理 12（整机退化与嵌套）

**陈述**：(i) 基座静止、接触固定、基速/基加速度为 0 时，WBKC 的 DCM 判据退化为 ZMP-in-support，P(t) 常值，故 WBKC ≡ v5 BCK；(ii) Σ_CI→0 时 U_δ→{ŝ}，RFCK 退化为点估计门；(iii) 故 Exec_v6 ⊆ Exec_v5，且退化条件下 Exec_v6 = Exec_v5。∎

**证明**：DCM 定义在基速 0 时 ξ=c，与 ZMP 判据一致；U_δ 收缩到点；鲁棒门包含点估计门。∎

### 定理 13（七锚完备性在移动与融合下保持）

**陈述**：v6 不增删锚点：七锚 {3DCF, MSRG, HICK, EEK, LTEM, VACK, BCK} 完备性（v4 定理 4）保持。WBKC 是 BCK 的推广（同锚），RFCK 是「所有门的鲁棒化算子」（非新锚），STFAK 是「感知信任通道」（非新锚），租约是「证书的时间维度」（非新锚）。∎

**证明**：锚点集合不变；WBKC 退化到 BCK；鲁棒化/信任/租约只改变门的求值域与有效期，不引入新的安全谓词类别。∎

### 定理 v6（总装：移动与融合下的认证可靠性）

**陈述**：在 v4 假设 (B1)~(B6)、v5 假设 (B7) 及新增 (B8) 各源估计一致（引理 45 前提）、(B9) ‖ṡ‖≤v_max 成立下：
(i) Exec_v6 ⊆ Exec_v5 ⊆ … ⊆ Exec_v29；
(ii) 鲁棒可靠性：真值门违反概率 ≤ δ（定理 9）；
(iii) 信息单调：感知健康↑ ⇒ 认证集↑（定理 10）；
(iv) 时效：超租约证书不作数（定理 11）；
(v) 退化：静态基 + 完美感知时精确还原 v5（定理 12）；
(vi) 七锚完备性保持（定理 13）。

**证明**：逐条由定理 9–13 与嵌套定义。∎

**诚实声明**：(B8) 依赖各源协方差标定，共模故障可同时破坏多源；(B9) v_max 是保守界，动态任务下可能过保守导致频繁超期；(iii) 的「一致传感器」前提在 Byzantine/欺骗攻击下失效；(vi) 鲁棒化使执行集显著收缩（仿真 ~0.62），存在「过度保守—频繁降级」的可用性代价。

## 7. 本轮最大风险（最终确认）

**一句话**：**不确定性模型的过度自信**——v6 的全部可靠性都押在「融合置信集 U_δ 以 1−δ 覆盖真值」上，而协方差标定、CI 的个体一致性前提、共模漂移的可检测性都只在受控条件下近似成立；一旦 Σ 被系统性低估（打滑、偏置、同步误差、SLAM 共模漂移），鲁棒门就从「更严的保证」退化为「形式更严、实质更假的保证」，且系统对此**无法自证**。
