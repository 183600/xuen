# 第 65 轮（承接第 64 轮「GRIP 接触接地四层闭环」IP-204~213；本轮灵感：「中间件」×「自然语言指令」）

> 第 64 轮用力/触觉把几何先验改造成可证伪假设，其自述的最大风险一针见血：**当力/触觉存在未建模偏置、漂移、饱和，且接触模型本身错误时，CGG 会把"传感器/模型错误"误判为"几何幻觉"——在正确几何上主动降级、在错误几何上放行，力觉从"接地真值"反变为新的单点故障与物理伤害源。**
>
> 根因不在"少了一个模态"，而在**架构**：过去每一轮都把新证据**硬接线**进同一个估计器，用同一个残差同时承担"检测异常"和"解释异常"两件事；模态越多，误差越纠缠，谁错了越不可辨识。而人类意图又一直以**隐含假设**的形式藏在任务里（"小心别洒"到底约束什么？"把杯子放好"的"好"由谁定义？），从未成为可检查的对象。本轮从**中间件**拿到"契约、出处、租约、隔离、可观测"的系统纪律，从**自然语言指令**拿到"意图必须显式化、欠定必须被绑定或被追问"的接口纪律。核心命题是：
>
> **鲁棒性不是继续叠加接地层，而是让每一种证据、每一条指令都成为「有契约、有出处、有租约、可归因、可撤销」的一等公民——冲突显式化、故障被隔离、意图可审计；云/模型/语言只能"建议"，安全只能由边缘"认证"。**

## 0. 直觉与动机

**灵感 1（中间件 → 证据契约与证据总线：ECP + EB）**
直觉：中间件做的第一件事不是"计算得更准"，而是**定义接口**：谁生产什么、以什么格式、有效期多久、出了错谁负责。把 LiDAR 几何、F/T 接触、触觉滑移、云端先验、语言约束全部规范化为**证据契约** ε = (id, 源, 类型, 作用域, 值, 协方差, 发出时刻, 租约 TTL, 出处, 证伪条件, 代价, 权限, 状态)。下游不再"拿到一堆数"，而是"订阅一组仍在有效期内的断言"。这一步把第 64 轮最缺的东西补上：**出处（provenance）**——当残差变大时，系统知道"哪条断言在说话"，而不是笼统地怀疑几何。

**灵感 2（中间件 → 失败隔离与租约/熔断：FIL）**
直觉：中间件的第二件事是**让故障不扩散**：舱壁（bulkhead）、熔断器（circuit breaker）、租约（lease）、隔离区（quarantine）、优雅降级。映射到本轮：如果 F/T 的标定租约已过期或自检失败，那么**力觉根本不是合法证人**，CGG 不许用它去否定几何；如果归因判定是"力觉偏置"，就**隔离力觉源**（而不是降级几何），几何继续工作并膨胀球。第 64 轮的灾难正是"没有隔离层，只能二选一地信/不信几何"。

**灵感 3（中间件 → 非可绕过安全门与 QoS：SBG + QS）**
直觉：中间件里有一类特殊组件——**策略执行点（PEP）**：任何请求都必须穿过它，且它不能被业务代码绕过。机器人里对应的是安全屏障门：语言模型、学习模块、云端计划都只能**提议**，最终派发必须穿过 SBG；SBG 按硬实时通道调度、fail-closed、权限无关、不可被指令关闭。把"安全"从"某个模块的输出"变成"架构上的强制约束"。

**灵感 4（自然语言指令 → 意图契约编译器：ICC）**
直觉：自然语言的强项是表达"要什么"，弱项是精确。正确用法不是让大模型"直接输出动作"，而是**编译成契约**：目标 g、硬约束 H、软偏好 P、翻译假设 Ω、未知槽 U、守卫 G、验证计划 V、权限 a、有效期 TTL、停止条件 S。关键是把"欠定"显式化：**U 里的每个槽位都要么被证据绑定，要么被追问，要么放弃行动**。"小心别洒"不再是一句氛围，而是一条带监控器的硬约束 h："运输段竖直加速度 |a_z| ≤ a_max ∧ 杯口倾角 ≤ θ_max"。

**灵感 5（两灵感合流 → PRISM：Provenance-Routed Instruction & Safety Middleware 出处路由的指令-证据-安全中间件）**
合流为「契约化证据 × 归因隔离 × 意图显式化 × 强制安全门」：证据总线把多模态断言路由成**可归因**的契约；失败隔离层把"谁坏了"变成**隔离谁**而不是"信谁"；自然语言编译器把人类意图变成**可审计、可追问、可撤销**的契约；安全屏障门保证任何语言/云端/学习输出都不能绕过硬约束。**第 63 轮是"几何层"、第 64 轮是"接触层"，PRISM 加的是"中间件层"——不是又一个传感器，而是让前面所有层第一次能说清"证据从哪来、谁该负责、意图是什么、谁有权改"。**

## 1. 形式化定义（增量：定义 217–232）

- **定义 217（PRISM 闭环）**：PRISM = (GRIP, ECP, EB, FIL, SBG, ICC, GCR, LAP, QS, J_prism)。四层：证据层（各模态只产契约）、中间件层（总线/归因/隔离/QoS）、意图层（NL→契约）、安全层（不可绕过门）。不变式：**语言与学习模块只能发布"提议/契约"，永远不能直接写控制；任何派发必须穿过 SBG；SBG 不读语言、不读学习梯度。**
- **定义 218（证据契约 EC）**：ε = (id, src, type, scope, value, cov, t₀, TTL, prov, falsifier, cost, auth, status)，status ∈ {VALID, EXPIRED, QUARANTINED, REVOKED, CONFLICTED}；`Valid(ε,t) ⇔ t ≤ t₀+TTL ∧ status=VALID ∧ calib_lease(src).valid ∧ coverage(scope)≥1−α`。
- **定义 219（误差源分解）**：把跨模态残差写成 e = Aδ + η，δ 为分组稀疏的误差源（机器人偏置 b_i、物类模型误差 m_c、几何幻觉 h_s、触觉标度、时钟/陈旧），A 为**故障签名矩阵**（离线受控注入 + 物理映射得到），η~N(0,Σ)。
- **定义 220（归因检验与隔离策略）**：对每个源 k 计算边际似然/后验 P(k|e₁:ₜ)（组稀疏 MAP + BIC）。若 max_k P(k|e) ≥ 1−α_attr 且 top-2 间隔 ≥ δ_amb → 归因确定，**隔离 k**；否则归因歧义 → 不惩罚任何源，进入保守回退（膨胀 r / safe_idle / 追问）。**只有力觉标定租约有效时，才允许把残差归因给几何**。
- **定义 221（故障隔离层 FIL）**：每源一个熔断器 {CLOSED, OPEN, HALF_OPEN} + 舱壁 + 隔离集 Q + 租约看门狗；源故障只影响其契约作用域，下游用保守集合替代，绝不做"跨源静默代偿"。
- **定义 222（安全屏障门 SBG）**：强制拦截器 SPR = {allow, clamp, hold, retreat}，输入 (候选控制 u, 契约集 E, 安全义务 H_safe)，输出被约束的控制；fail-closed、最高优先级、不可被语言/学习/云端绕过。
- **定义 223（意图契约 IC）**：I = (g, H, P, Ω, U, G, V, a, TTL, S, κ)。g 目标谓词；H 硬约束（每条配可执行义务 o_h 与监控器 m_h）；P 软偏好与权重；Ω 翻译假设及来源；U 带类型的未知槽；G 守卫；V 验证计划；a 权限；TTL 有效期；S 停止/中止条件；κ 人工确认等级。
- **定义 224（未知槽与临界未知）**：u∈U 是**临界**的，当且仅当存在两个可达绑定 w₁,w₂ 使某条 h∈H 或 s∈S 的满足性翻转：`Crit(u) ⇔ ∃h∈H∪S, w₁,w₂∈dom(u): h[w₁] ≠ h[w₂]`。临界未知必须有 VALID 绑定证据，否则不许 ACT。
- **定义 225（NL→契约编译器 ICC）**：ICC(u_nl, ctx) → (I, Amb, conf)，用受类型约束的抽取器把自然语言映射到契约模式，再由批评器检查：每条 h 有监控器、每个临界 u 有类型与域、义务无冲突、权限自洽。检查失败 → 转 ASK/ABSTAIN，绝不用"编造的绑定"补洞。
- **定义 226（接地批评器与 ACT/ASK/ABSTAIN）**：给定证据集 E_t，若所有临界未知被 VALID 绑定、全部硬义务可监控、无未决冲突 → ACT；若存在临界未知且澄清的期望收益 > 风险阈值 → ASK（生成**最小区分问题**）；否则 ABSTAIN（safe_idle 并记录未闭合契约）。
- **定义 227（语言来源与权限格）**：每条指令携带签名出处与声称权限 a_u；权限为格 (P,⊑,⊔)，接受条件 `a_u ⊑ a_issuer`。安全义务 H_safe 位于**指令代数之外**（宪法不变量），任何指令序列不得修改、关闭或提升自身权限；任意更高权限主体可撤销。
- **定义 228（契约感知编译 CGG-A / WCV-C / CSP-C）**：CGG 升级为**归因感知**（定义 220，先归因后决策）；WCV 只在 VALID 契约上求交，失败则膨胀球并标 `unresolved`；CSP 把 H 的硬义务编译成规划约束，插入 ASK/probe 元动作。
- **定义 229（QoS 通道与调度）**：通道 CH-SAFE(D=0.5ms, 不可丢)、CH-CTRL(D=2ms)、CH-EST(D=10ms)、CH-SEM(D=100ms)、CH-LANG(异步尽力)。EDF + 优先级继承；有界队列 + 背压；用响应时间分析 `R_i = C_i + Σ_{j∈hp(i)} ⌈R_i/T_j⌉ C_j ≤ D_i` 验证可调度性。
- **定义 230（可观测性与决策追踪）**：每次决策生成追踪 τ = (契约 id/版本/有效期, 归因结果, 冲突消解, 权限检查, QoS 违约)，哈希链式追加，可供离线审计与回放。
- **定义 231（J_prism 证书）**：J_prism = (J_grip, contract_hash, assumption_ledger, attribution_log, conflict_log, authority_ok, qos_trace, unresolved, intent_ver)。Valid ⇔ Valid(J_grip) ∧ 所有临界未知已绑定 ∧ 归因无未决歧义 ∧ 权限检查通过 ∧ QoS 未违约（或已安全降级）∧ unresolved=∅。
- **定义 232（PRISM 闭环算子）**：证据层 [LSF/FPE/MWS/SLD/云端 → EC] → 中间件层 [EB 路由 → 归因 → FIL 隔离 → 冲突消解] → 意图层 [ICC 编译 → GCR 绑定/追问 → CSP-C 规划] → 安全层 [SBG 拦截 → 实时派发] → 回灌 [RSC-F/OLP-F/DIR/SSB → 新契约]。

## 2. 关键算法骨架

```python
# 证据总线：所有模态只发布契约，不直接改状态
bus.publish(EvidenceContract(src="ft", type="contact_wrench", value=W,
            cov=Sigma_w, t0=now(), TTL=50e-3, prov=calib_id,
            falsifier="chi2_6", auth=SRC_LEVEL, status="VALID"))

# 归因：先问"是谁错了"，再决定信谁
delta = group_sparse_map(e, A, Sigma)          # min 1/2||e-Aδ||^2 + λ||δ||_1
post  = source_posterior(e, A, delta)         # P(k|e), k ∈ {robot, object, geo, tactile}
k_star, amb = argmax_with_margin(post, delta_amb)
if not amb and calib_lease(k_star).valid:
    fil.quarantine(k_star)                     # 隔离坏源，而非盲目降级几何
else:
    wcv.inflate(r); flag_unresolved("attribution_ambiguous")

# NL → 契约：欠定显式化，临界未知必须绑定或追问
I, amb_report, conf = icc.compile(utterance, context)
for u in I.U:
    if crit(u, I) and not bound(u, evidence):
        return gcr.ask_or_abstain(u, I)        # 最小区分问题；否则不动

# 安全屏障门：不可绕过、fail-closed
u_safe = sbg.intercept(u_proposed, evidence, I.H_safe, authority)
dispatch(u_safe)
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 7（归因可辨识性）**：若各源签名 μ_k=A_kθ_k 的最小两两分离为 Δ_min，则 n 个样本下误归因概率 ≤ (K−1)exp(−nΔ_min²/(8σ²))；反之 Δ_min ≤ σ√(8logK/n) 时不可辨识，必须报歧义。**这把"检测到异常"升级为"以可证概率指出谁异常"。**
- **引理 8（租约可靠性）**：若契约仅在 `t−t₀ ≤ TTL ≤ T_deadline−t_compile`（时钟偏斜有界）时被消费，则不会使用陈旧断言；配合标定覆盖率 1−α_cal，合法契约的错误落在声明协方差内的概率 ≥1−α_cal。
- **定理 7（故障隔离）**：隔离源 k 后，信念只通过其余契约的声明作用域受影响；因不做"跨源静默代偿"，k 的误差不能传播到未声明维度——**单点故障不会变成系统性污染**。
- **定理 8（契约有效 ⇒ 安全）**：若每条硬约束都有可监控义务、SBG 不可绕过且 fail-closed、所有临界未知已绑定，则执行违反 H 的概率 ≤ Σα_bind+α_attr+α_source+P(SBG 失效)。**注意：这保证的是"对契约 H 安全"，不是"对人类意图安全"（见风险）。**
- **定理 9（权限单调 / 注入免疫）**：若指令代数在合成下封闭、权限格单调且 H_safe 不可被指令变换触及，则任意有限指令序列都不能提升自身权限或关闭安全；自然语言注入最多产生一条被拒绝/被降权的提议。
- **定理 10（PRISM 端到端）**：Valid(J_prism) ⇒ 几何/接触如 J_grip 被认证或安全降级 ∧ 归因确定或已显式歧义 ∧ 契约闭合 ∧ 权限与安全不变式成立 ∧ QoS 达标或安全降级。
- **实时性**：SBG <0.05ms、EC 校验 <0.02ms、归因（语义流）<5ms、ICC（异步）不占实时预算；CH-SAFE/CH-CTRL 响应时间分析可调度，实时路径仍 ≤2ms（继承 A87，新增 A88–A90）。

## 5. 本轮最大风险

**一句话**：中间件与契约层本身会成为新的单点故障——若契约模式、故障签名矩阵 A 或权限策略有误，系统会**自信地认证一个错误的形式化**（人类说"轻一点"，契约写成"力 ≤ F_max"，于是压碎物体却通过验证）；归因也可能把"签名矩阵没覆盖的新故障"错误地钉在某个无辜源上并隔离它，**用"可审计的确定性"替换了"可证伪的不确定性"**。

## 2. 形式化定义（完整版）

**定义 217（PRISM 闭环）** PRISM 是 GRIP 的"中间件层"升级，分为四层：
1. **证据层**：LSF（几何）、MWS/FPE（接触/物理）、SLD（滑移）、云端先验等只发布证据契约 EC，不直接写共享状态；
2. **中间件层**：EB 路由与去重、ATT 归因、FIL 隔离/熔断、冲突消解、QS 调度；
3. **意图层**：ICC 把自然语言编译为意图契约 IC，GCR 绑定临界未知或追问；
4. **安全层**：SBG 作为强制策略执行点，对候选控制做 allow/clamp/hold/retreat。
不变式：(i) 语言、学习、云端只能发布"提议/契约"，不能直接写执行器；(ii) 任何派发 `dispatch` 必须经过 SBG；(iii) SBG 的实现不读取语言输入与学习梯度；(iv) 所有跨层通信都走 QoS 通道并带追踪。

**定义 218（证据契约 EC）** 证据契约是六元组加状态：
ε = (id, src, type, scope, value, cov, t₀, TTL, prov, falsifier, cost, auth, status)。
- `src`：生产源（lidar/ft/tactile/cloud/language/…）；`type`：断言类型（surface, normal, wrench, contact_set, φ, slip, preference, constraint_hint, …）；
- `scope`：该断言声称有效的状态/时间/空间子集；`value, cov`：点估计与协方差（或集合值）；
- `prov`：标定版本、模型哈希、上游契约 id 链；`falsifier`：可执行的证伪谓词；
- `cost`：获取/续租代价；`auth`：源的权限级；`status`：VALID/EXPIRED/QUARANTINED/REVOKED/CONFLICTED。
有效性：`Valid(ε,t) ⇔ t ≤ t₀+TTL ∧ status=VALID ∧ calib_lease(src).valid ∧ coverage(scope)≥1−α`。**过期/隔离的契约不是"低权重证据"，而是"非法证人"——不得参与任何归因或惩罚性更新。**

**定义 219（故障签名与误差源分解）** 在窗口内把各源残差堆叠为 z∈ℝⁿ（含力旋量残差、几何重投影残差、触觉标度残差、云端陈旧残差）。设误差源 δ 按源分组稀疏，`z = Aδ + η`，η~N(0,Σ)。签名矩阵 A 由**故障签名库 FSL** 构造：对每个源做受控注入（机器人偏置 b_i、物类模型误差 m_c、几何幻觉 h_s=法向翻转/虚假面、触觉标度/漂移、时钟偏斜），记录其残差响应得到 A_k；物理映射（如偏置经 `G_b` 进入旋量）给出列的可解释性。

**定义 220（归因检验与隔离策略）** 求解组稀疏 MAP
`δ̂ = argmin_δ ½‖z−Aδ‖²_{Σ⁻¹} + λ Σ_k ‖δ_k‖₂`。
对每个假设 H_k（"只有源 k 异常"）与 H₀（全正常）计算 BIC 近似边际似然
`log p(z|H_k) = −½‖z−A_kδ̂_k‖²_{Σ⁻¹} − (d_k/2)log n + const`，
得后验 `P(k|z) ∝ π_k exp(log p(z|H_k))`。
- **确定归因**：`max_k P(k|z) ≥ 1−α_attr` 且 `P₁−P₂ ≥ δ_amb` 且 `calib_lease(k*).valid` → 隔离 k*，并对 k* 的契约置 QUARANTINED；
- **归因歧义**：不满足上述条件（含 H₀ 拟合最好） → **不惩罚任何源**，进入保守回退：`r ← min(r_max,κ_infl·r)`、置 `unresolved="attribution_ambiguous"`、必要时 ASK/safe_idle；
- **几何降级的前置条件**：只有当 (a) 力觉/触觉契约全部 Valid，(b) 归因确定指向 H_geo，(c) 签名残差显著偏离 H_force，才允许执行第 64 轮 CGG 的 `demote()`。**力觉租约失效时，力觉无权否定几何。**

**定义 221（故障隔离层 FIL）** 每源维护熔断器状态机 `CLOSED→(连续失败)→OPEN→(冷却+自检)→HALF_OPEN→(参考探针通过)→CLOSED`，以及：
- **租约看门狗**：TTL 到期前必须续租，续租需新鲜证据 + 标定自检；续租失败自动 EXPIRED；
- **舱壁（bulkhead）**：源之间的缓冲、线程、模型实例隔离，一个源的延迟/异常不阻塞其他源；
- **隔离集 Q**：QUARANTINED 源的契约保留用于审计但不参与决策；
- **回退**：故障源在其作用域内被替换为**保守集合**（而非跨源点估计代偿），如 φ 改为 `B(φ̂,r_max)∩…`。
单调性要求：移除任何契约只会让认证集合变大、不会变小（见定理 7）。

**定义 222（安全屏障门 SBG）** SBG 是中间件链上的强制策略执行点：
`(u_safe, act) = SBG(u_prop, E_t, H_safe, a)`，`act∈{allow,clamp,hold,retreat}`。
执行逻辑：
1. 从 E_t 重建 `H_safe` 的当前可行域（仅用 VALID 契约；缺失时用最保守先验）；
2. 对候选控制做投影/截断：`u_safe = Π_{H_safe}(u_prop)`；
3. 若可行域为空或投影不可行 → `hold`（零速/保持阻抗）或 `retreat`（退回安全位）；
4. `h` 的监控器一旦为假，立即覆盖为 `hold`。
SBG 不接收语言 token、不接收学习梯度、不依赖任何可被指令改写的配置；其参数在启动时由独立安全配置签名加载。`dispatch` 的类型签名强制要求 `SBG` 输出，编译期/运行期均不可绕过。

**定义 223（意图契约 IC）** 自然语言指令编译为
`I = (g, H, P, Ω, U, G, V, a, TTL, S, κ)`：
- `g`：目标谓词（世界状态上的可判定条件）；
- `H = {(h_i, o_i, m_i)}`：硬约束、可执行义务、监控器。例："别洒" → `h: 运输段 |a_vert|≤a_max ∧ |tilt|≤θ_max`，`o: 限制加加速度与倾角`，`m: IMU+视觉实时监控`；
- `P`：软偏好与权重（"尽量快"）；
- `Ω`：翻译假设及来源（默认值/常识/用户明示），每条可被证据或用户否定；
- `U`：带类型的未知槽（物体身份、易损性、目标容器、用户偏好、可接受风险）；
- `G`：守卫（前置条件）；`V`：验证计划；`a`：权限级；`TTL`：有效期；`S`：停止/中止条件；`κ`：人工确认等级（0 自主，1 临界未知必须确认）。

**定义 224（临界未知与绑定）** `u∈U` 临界当且仅当
`Crit(u) ⇔ ∃h∈H∪S, w₁,w₂∈dom(u): h[w₁] ≠ h[w₂]`，
即不同绑定会翻转某条硬约束/停止条件的满足性。`bind(u)` 必须引用至少一个 VALID 证据契约（或用户明示确认），并记录在 assumption_ledger；无证据的"默认假设"只能用于非临界槽。**临界未知未绑定 ⇒ 禁止 ACT**（定义 226）。

**定义 225（NL→契约编译器 ICC）** ICC = (Extractor, Critic)：
- **Extractor**：以受类型约束的模式（JSON-schema/语法）从 `(u_nl, ctx)` 抽取 `I`，同时输出 `Amb`（每条约束/槽位的歧义集合与置信度）与 `conf`。Extractor 可调用大模型，但其输出必须通过模式校验；**不允许自由文本直接进入控制**。
- **Critic**：检查 (i) 每条 `h` 有可执行义务与监控器；(ii) 每个临界 `u` 有类型、域与非空绑定计划；(iii) 义务间无矛盾；(iv) 权限自洽；(v) 目标 `g` 可判定。任一失败 → `Amb` 增补并转 GCR/ASK/ABSTAIN。Critic 是确定性程序 + 形式检查，不复用 Extractor 的"自信"。

**定义 226（接地批评器与 ACT/ASK/ABSTAIN）** 给定契约 I 与证据 E_t：
- **ACT**：所有临界未知均被 VALID 绑定 ∧ 所有 `h` 可监控 ∧ 无未决冲突 ∧ 归因非歧义 ∧ QoS 达标；
- **ASK**：存在临界未知未绑定，且澄清的期望收益 `EV(clarify) = ΔRisk·P(可澄清) − Cost_ask` 大于阈值；生成**最小区分问题** `q* = argmin_q H(binding | answer(q))`（信息增益最大、认知负担最小）；
- **ABSTAIN**：无法澄清（无人/超时）或任何行动都有不可接受风险 → `safe_idle`，并写 `unresolved`。
该策略把"自然语言的不确定性"转化为**显式的、可审计的行动许可条件**。

**定义 227（语言来源与权限格）** 指令携带签名出处 `prov_u` 与声称权限 `a_u`。权限格 `(P,⊑,⊔)` 中接受条件为 `a_u ⊑ a_issuer`；安全义务集合 `H_safe` 是**宪法不变量**，位于指令代数之外：
- 任何指令变换 `T_u` 只能作用于 `a_u` 授权的能力集，`T_u(H_safe)=H_safe`；
- 指令不能修改权限映射、不能提升自身或他人权限、不能关闭 SBG；
- 更高权限主体可撤销任意更低权限指令；撤销立即生效并写追踪。
这构成"注入免疫"的**结构性**保证：自然语言注入最多产生一条越权提议，被类型系统拒绝（定理 9）。

**定义 228（契约感知编译 CGG-A / WCV-C / CSP-C）**
- **CGG-A**：第 64 轮 CGG 的 `demote()` 改为 `attribution-gated demote`（定义 220），并新增"隔离源 k 后重估残差"步骤；不再用单一 χ² 直接否定几何。
- **WCV-C**：搜索域只与 VALID 契约求交：`B(φ̂,r) ∩ 𝒢_contract ∩ K(μ̂) ∩ ℱ(f_lim)`，其中 `𝒢_contract` 来自 VALID 几何契约；任何契约过期则对应自由度膨胀到 `r_max` 并标 `unresolved`。禁止跨源静默代偿（例如不能因为力觉坏了就偷偷用几何值替代力觉值）。
- **CSP-C**：把 `H` 的硬义务编译为规划约束，将 ASK/probe 作为显式元动作插入；若契约未闭合，规划器只能生成"信息获取路径"或 safe_idle，不能生成"赌一把"路径。

**定义 229（QoS 通道与调度）** 通道类：
| 通道 | 截止期 D | 可丢 | 优先级 | 承载 |
|---|---|---|---|---|
| CH-SAFE | 0.5ms | 否 | 0（最高） | SBG、力限、滑移、急停 |
| CH-CTRL | 2ms | 否 | 1 | 控制派发、WCV 编译、首技能 |
| CH-EST | 10ms | 部分 | 2 | 接触/滑移/φ 估计 |
| CH-SEM | 100ms | 是 | 3 | 规划、技能选择 |
| CH-LANG | 异步 | 是 | 4（最低） | ICC、追问、云端 |

调度用 EDF + 优先级继承；队列有界，满时对低优先级通道**背压**而非丢弃安全通道消息。可调度性用响应时间分析验证：`R_i = C_i + Σ_{j∈hp(i)} ⌈R_i/T_j⌉ C_j ≤ D_i`。SBG 与其前置检查运行在不可抢占的极小内核上，预算 <0.05ms。

**定义 230（可观测性与决策追踪）** 每次决策生成
`τ = ( consulted_contract_ids+versions, validity_results, attribution_result, conflict_resolutions, authority_check, qos_violations, sbg_action )`，
追加到哈希链 `h_t = H(h_{t-1} ‖ τ_t)`。追踪只存契约 id 与摘要（隐私保护），支持离线回放：任一次"为什么动了"都能追到"用了哪条契约、它当时是否有效、谁授权、是否发生归因歧义"。

**定义 231（J_prism 扩展证书）** 
`J_prism = (J_grip, contract_hash, assumption_ledger, attribution_log, conflict_log, authority_ok, qos_trace, unresolved, intent_ver)`。
验证规则：
`Valid(J_prism) ⇔ Valid(J_grip) ∧ unresolved=∅ ∧ 所有临界未知已绑定（assumption_ledger 完整）∧ 归因无未决歧义（或已按定义 220 保守回退且记录）∧ authority_ok ∧ (QoS 未违约 ∨ 已安全降级并记录) ∧ contract_hash 与 EB 快照一致 ∧ intent_ver 与 ICC 版本一致`。
审计链：`contract_hash` 追溯证据来源与租约；`assumption_ledger` 追溯每个意图假设是谁/被什么绑定；`attribution_log` 追溯"为什么隔离这个源"；`conflict_log` 追溯"矛盾如何消解"；`authority_ok` 追溯"谁有权让机器人这么做"。

**定义 232（PRISM 闭环算子）**
- **证据层（异步/多速率）**：LSF→几何 EC；FPE→φ EC；MWS→接触 EC；SLD→滑移 EC；云端→先验 EC；每条 EC 带租约与证伪条件。
- **中间件层（语义流）**：EB 去重/路由 → ATT 归因 → FIL 隔离/熔断 → 冲突消解（保留冲突，不静默平均）。
- **意图层（异步）**：说话→ICC 编译→Critic→GCR 绑定/ASK→CSP-C 规划（未闭合只能生成信息获取路径）。
- **安全层（实时）**：SBG 拦截 → CH-CTRL 派发 → 监控器回灌 → 追踪哈希。
- **回灌**：RSC-F/OLP-F/DIR/SSB 只消费 VALID 契约并产出新契约。

### IP-214/215 ECP + EB（证据契约与证据总线）

```python
from dataclasses import dataclass, field

@dataclass
class EvidenceContract:
    id: str; src: str; type: str; scope: Scope
    value: object; cov: np.ndarray
    t0: float; ttl: float
    prov: dict            # calibration_id, model_hash, upstream_ids
    falsifier: str        # 可执行证伪谓词名
    cost: float; auth: int
    status: str = "VALID"

    def valid(self, t, calib, coverage, alpha=0.05):
        return (t <= self.t0 + self.ttl
                and self.status == "VALID"
                and calib[self.src].valid
                and coverage[self.scope] >= 1 - alpha)

class EvidenceBroker:
    def __init__(self):
        self.contracts = {}      # id -> EvidenceContract
        self.index = defaultdict(list)   # type -> ids
        self.conflicts = []

    def publish(self, ec: EvidenceContract):
        self.contracts[ec.id] = ec
        self.index[ec.type].append(ec.id)
        self._check_conflicts(ec)        # 只登记冲突，不做静默平均

    def snapshot(self, types, t, calib, coverage):
        active = [self.contracts[i] for t_ in types for i in self.index[t_]
                  if self.contracts[i].valid(t, calib, coverage)]
        return BeliefSnapshot(active, self.conflicts, t)

    def revoke_upstream(self, cid):
        for ec in self.contracts.values():
            if cid in ec.prov.get("upstream_ids", ()):
                ec.status = "REVOKED"     # 出处链失效 → 级联撤销
```

### IP-216/217 ATT + FIL（归因与隔离）

```python
def attribute(z, A, Sigma, groups, alpha_attr=0.05, delta_amb=0.2):
    """z = Aδ + η；按源分组稀疏，返回最可能坏源或歧义。"""
    delta = group_lasso(z, A, Sigma, groups, lam=lam_from_noise(z, Sigma))
    logpost = {}
    for k, cols in groups.items():
        r = z - A[:, cols] @ delta[cols]
        logpost[k] = -0.5 * r.T @ inv(Sigma) @ r - 0.5 * len(cols) * np.log(len(z))
    logpost["H0"] = -0.5 * z.T @ inv(Sigma) @ z - 0.5 * np.log(len(z))
    post = softmax(logpost)
    ranked = sorted(post.items(), key=lambda kv: kv[1], reverse=True)
    (k1, p1), (k2, p2) = ranked[0], ranked[1]
    if k1 == "H0" or p1 < 1 - alpha_attr or (p1 - p2) < delta_amb:
        return None, post, True          # 歧义：不惩罚任何源
    return k1, post, False

def attribution_gated_step(z, A, Sigma, groups, calib, r, phi_geo, phi_force):
    k_star, post, ambiguous = attribute(z, A, Sigma, groups)
    if ambiguous:
        return min(R_MAX, KAPPA_INFL * r), "attribution_ambiguous", phi_geo
    if not calib[k_star].valid:                 # 坏源自己都没资格当证人
        fil.quarantine(k_star)
        return min(R_MAX, KAPPA_INFL * r), f"quarantine:{k_star}", phi_geo
    if k_star == "geometry":                     # 仅在证据充分时才降级几何
        r = min(R_MAX, KAPPA_INFL * r)
        return r, "geo_demoted", phi_force
    if k_star in ("ft", "tactile"):              # 隔离力觉源，几何继续工作
        fil.quarantine(k_star)
        return min(R_MAX, KAPPA_INFL * r), f"quarantine:{k_star}", phi_geo
    fil.quarantine(k_star)                       # 物类/时钟/云端
    return r, f"quarantine:{k_star}", phi_geo

class FailureIsolationLayer:
    def __init__(self, sources):
        self.state = {s: "CLOSED" for s in sources}
        self.lease = {s: 0.0 for s in sources}
        self.quarantine = set()

    def tick(self, source, ok, now, ttl):
        if ok:
            self.lease[source] = now + ttl
            if self.state[source] == "HALF_OPEN":
                self.state[source] = "CLOSED"
                self.quarantine.discard(source)
        else:
            self.state[source] = "OPEN"
            self.quarantine.add(source)

    def may_witness(self, source, now):
        return (self.state[source] != "OPEN" and self.lease[source] >= now
                and source not in self.quarantine)
```

## 4. 推导

**引理 7（归因可辨识性与指数分离）** 设在窗口内各故障假设下的均值签名为 `μ_k = A_kθ_k`（k=0..K，μ₀=0），最小两两分离 `Δ_min = min_{k≠l}‖μ_k−μ_l‖`，噪声 η~N(0,σ²I)。对最大似然/最小距离归因器，单样本误判到最近错误假设的概率由高斯尾界给出
`P_e|k ≤ (K−1) exp(−Δ_min²/(8σ²))`；
n 个独立样本下 `P_e ≤ (K−1) exp(−nΔ_min²/(8σ²))`。等价地，若 `n ≥ 8σ² log((K−1)/β)/Δ_min²`，则归因错误概率 ≤ β。
**推论**：当 Δ_min ≤ σ√(8log((K−1)/β)/n) 时不存在可靠的归因器，必须报告"歧义"——这正是定义 220 的 `δ_amb` 策略所做的事（拒绝在不可辨识时惩罚任何源）。∎

**引理 8（契约租约可靠性）** 设契约只在 `t ≤ t₀+TTL_eff` 被消费，`TTL_eff = TTL − 2ε_clk`（ε_clk 为最大时钟偏斜），且 `TTL_eff ≤ T_deadline − t_compile`。则：(i) 消费时刻的契约必在发出后 `TTL_eff` 内，不会消费陈旧断言；(ii) 在标定覆盖率 `P(真值∈cov)≥1−α_cal` 下，合法契约的误差落在声明协方差内的概率 ≥1−α_cal。因此"用了一条 Valid 契约"意味着"用了一个带可声明误差与时效的断言"；任何超出该范围的使用都是契约违规，必须由 FIL 拦截。∎

**定理 7（故障隔离的保守单调性）** 设认证集合 `B(E)` 是在有效契约集合 E 上通过"求交 + 保守回退"得到的集合，且真值 `θ*∈B(E)`。若从 E 中移除任意契约得到 E'⊆E，并按定义 221 用保守集合替代，则 `B(E') ⊇ B(E)`（去掉断言只会让认证集合变大，不会变小），故 `θ*∈B(E')` 仍成立。隔离源 k 后，k 的误差只能通过其"已声明的 scope"影响结果；由于禁止跨源静默代偿，k 的误差不能注入其他源的未声明维度。于是**单源故障不会造成"自信地错"，只会造成"暂时更保守"**。∎

**定理 8（契约有效 ⇒ 对契约安全）** 设 (A88) 每条 `h∈H` 都有监控器 `m_h`，且从违反发生到监控器置假、再到 SBG 覆盖的时延 ≤ τ_h（τ_h 小于该约束的时间常数）；(A89) SBG 不可绕过、fail-closed，且其 `project` 在可行域上返回满足 H 的控制（可行域为空则 hold/retreat）；(A90) 所有临界未知被 VALID 证据或用户确认绑定，覆盖概率 ≥1−α_bind。则执行违反 H 的概率
`P[violate H] ≤ Σ_{h} P(m_h 失效) + α_bind + α_attr + α_source + P(SBG 失效)`，
其中 `α_attr` 只在归因歧义时进入保守回退，不产生"惩罚正确源"的错误。**注意：该定理保证的是"对契约 H 安全"，而非"对人类真实意图安全"（见命题 1）。** ∎

**定理 9（权限单调与注入免疫）** 设指令变换 `T_u` 只作用于权限 `a_u` 授权的能力，且 `T_u(H_safe)=H_safe`（宪法不变量），权限格满足单调性。对任意有限指令序列 `u₁,…,uₙ`，归纳可得：(i) 每步有效权限 `⊑ a_issuer`；(ii) `H_safe` 不变；(iii) SBG 配置与权限映射不可写。自然语言注入是某个 `u` 声称了超出其出处的权限或试图写 `H_safe`/权限/SBG，被定义 227 的类型检查拒绝。故注入最多产生一条被拒绝/降权的提议。∎

**定理 10（PRISM 端到端）** 假设第 63/64 轮 A77–A87 及 A88–A90，且：
- (A91) 签名库 FSL 覆盖当前运行中的故障模式，或未覆盖故障被"H₀ 不拟合 + 归因歧义"检测为 novel 并进入保守回退；
- (A92) QoS 响应时间分析成立（定义 229），CH-SAFE/CH-CTRL 可调度；
- (A93) 意图契约 H 与人类真实意图的偏差在可接受范围内（**这是外部假设，不能由系统自证**）。
则 `Valid(J_prism) ⇒` 几何/接触如 J_grip 被认证或安全降级 ∧ 归因确定或显式歧义 ∧ 契约闭合（临界未知已绑定）∧ 权限与安全不变式成立 ∧ QoS 达标或安全降级 ∧ 对 H 的安全概率 ≥1−Σα。∎

**命题 1（错误形式化的不可验证性 / 意图保真缺口）** 存在两个意图契约 `I₁ ≠ I₂`，它们在所有可观测执行轨迹上诱导相同的硬义务与监控器，却对应不同的人类意图（例如"轻一点"被形式化为 `F≤F_max` 还是 `F≤0.5F_max`，二者都可满足但后者才是用户本意）。任何只读取执行轨迹与证书 `J_prism` 的监控器都无法区分 `I₁` 与 `I₂`。因此 **`Valid(J_prism)` 只能认证"执行符合契约"，不能认证"契约符合人心"**；意图保真必须依赖外部真相（用户确认、后果反馈、语义审计）。这是本轮架构无法自行闭合的根本缺口。∎

**命题 2（隔离的代价-收益）** 设无隔离时单源故障造成系统性污染的概率为 p_pollute，隔离后该概率为 0，但引入"因保守回退而放弃任务"的概率 p_abstain。则隔离的净收益为正当 `p_pollute·L_pollute > p_abstain·L_abstain`。由于 `L_pollute`（物理伤害/安全违规）通常远大于 `L_abstain`（任务延迟），**在安全关键场景应默认隔离优先**，并让 ASK 去降低 `p_abstain`。∎

## 7. 已知风险

**一句话**：中间件与契约层本身会成为新的单点故障——若契约模式、故障签名矩阵 A 或权限策略有误，系统会**自信地认证一个错误的形式化**（人类说"轻一点"，契约写成"力 ≤ F_max"，于是压碎物体却通过验证）；归因也可能把"签名库未覆盖的新故障"错误地钉在无辜源上并隔离它，**用"可审计的确定性"替换了"可证伪的不确定性"**（命题 1 是这一风险的正式表达）。

**次级风险与缓解**：
1. **错误形式化 / 规格博弈（首要）**：验证只能证明"符合契约"，不能证明"契约符合人心"；缓解：(i) κ 分级，高风险/临界未知强制人工确认；(ii) 契约中同时给出**正例与反例**（"轻"= 不产生可见形变，反例 = 压出凹痕）；(iii) 提供人类可读的"语义 diff"与假设账本；(iv) 后果反馈与在线修订；但**无法根治**（命题 1）。
2. **签名库未覆盖的新故障 → 误归因**：缓解：(i) 增加 H₀/novelty 检验，H₀ 不拟合且无源后验高置信时判为 novel，隔离"所有非安全关键源"并 ASK；(ii) A 的不确定性进入归因（对 A 做鲁棒/贝叶斯处理）；(iii) 定期受控注入更新 FSL；(iv) 任何隔离都可逆（HALF_OPEN 自检）。
3. **NL 编译器幻觉出错误绑定**：缓解：受类型约束的 schema、确定性 Critic、临界未知绝不自动绑定、每个绑定带出处、用户可撤销/修正。
4. **权限伪造 / 提示注入**：缓解：签名出处（不可伪造）、权限格与单调性、安全宪法在指令代数之外、SBG 不读语言、高权限动作要求带外确认；剩余风险是"编译器错误抽取权限"（需形式化/测试）。
5. **中间件成为单点故障/延迟源**：缓解：SBG 极小内核 + 形式验证 + 看门狗 + 双冗余；契约只做 O(1) 谓词检查；重计算（归因、ICC）放语义流/异步；QoS 响应时间分析兜底。
6. **契约爆炸/监控负担**：缓解：schema registry、契约去重与继承、只对硬约束的关键子集建监控器、按 κ 分级、契约生命周期管理（TTL + 级联撤销）。
7. **冲突振荡**：缓解：冲突显式化 + 迟滞 + 归因后验软判决 + 禁止静默平均；对反复冲突的源自动降权/隔离。
8. **ASK 过多导致可用性下降**：缓解：最小区分问题、期望收益阈值、非临界用有界风险默认值、用户偏好学习但**不用于硬化安全约束**。
9. **时钟/租约假设被打破**：缓解：单调时钟 + 最大偏斜界 + TTL_eff = TTL−2ε_clk；租约过期一律视为非法证人（保守）。
10. **审计隐私/安全**：追踪只存 id 与摘要、访问控制、哈希链防篡改；不存原始力/图像。

**优雅降级**：F/T 失效 → FIL 隔离力觉，CGG-A 不降级几何，退化到第 63 轮几何 LIRO；LiDAR 幻觉 → 归因指向几何并降级，力觉主导；NL 编译器失败/歧义 → ASK 或 ABSTAIN，绝不猜；中间件/归因超时 → 保守膨胀 + safe_idle；SBG 失效（不应发生）→ 硬件急停兜底。**任何单层失效都不会静默传播为"自信地错"。**
