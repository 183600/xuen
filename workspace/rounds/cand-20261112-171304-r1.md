# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 1 轮；本轮灵感：「跌倒恢复」×「运动控制」）

> 第 60 轮的 SGEC 把「执行层→证据层」闭环升级为「认知驱动的场景-执行闭环」：SSM 场景先验、CIEC 意图约束、EPIR 证据隔离、SERC 场景感知闭环、SIC 三元校验。但它**默认机器人始终处于「可控、可站立、可准静态操作」的工作域**，三个根本局限尚未触及：
> 1. **工作域的离散假设**：SERC/CESC 假设场景序列 z_i 与阻抗 K_safe 始终落在「可行域」，可真实机器人会**跌倒**——跌落是连续动力学中的不可逆、高能量瞬态；一旦进入「非站立构型」，第 60 轮的阻抗/场景先验全部失效。框架缺乏**「可恢复性」作为一等执行属性**。
> 2. **运动控制的「避免跌倒」偏置**：传统 WBC/MPC 以「保持平衡」为唯一目标，但**有些跌倒是不可避免的**（湿滑、外力、执行器饱和、关节限位）。在不可避免时，「如何跌倒」比「是否跌倒」更重要——受控跌倒（护头、滚动卸力、落入可恢复构型）被现有框架完全忽略。
> 3. **恢复过程的证据真空**：跌倒恢复是安全关键的高风险事件，一旦发生，**恢复轨迹、接触序列、冲击能量、人机保护**必须可审计。第 60 轮 EPIR 只覆盖 EV-exec 的数值回传，缺乏**跌倒事件的因果档案与恢复证书**。

## 0. 直觉与动机

**灵感 1（跌倒恢复 → 可恢复性流形 RMR）**
直觉：与其把「站立」与「跌倒」当作两个离散模式，不如定义一个连续的**可恢复性裕度 ρ(x)**：状态 x 距「还能站起来」的边界的加权距离。正常运动控制＝最大化 ρ；受控跌倒＝用一条轨迹把 x 送回 ρ>0 的区域；恢复＝在 ρ 最小处执行技能序列。关键洞见：**把「防跌倒」「受控跌倒」「恢复」统一到同一个可恢复性标量上**，消除模式切换的突变失效。

**灵感 2（运动控制 → 跌倒预测证书 TPC）**
直觉：人体失衡时会用「捕获点」判断「还能不能迈一步救回来」。机器人同理：用质心动力学与发散分量（DCM）预测「剩余到跌倒时间」τ_ttf，并给出绿/黄/红三色预测证书。关键洞见：**预测必须带证书与不确定性**——不是问「会不会倒」，而是问「在置信度 1−δ 下，τ_ttf 的保守下界是否仍大于反应时间 τ_react」。

**灵感 3（跌倒恢复 → 受控跌倒规划 CFP）**
直觉：当 τ_ttf < τ_react 且无可行动作时，**主动选择跌倒姿态**：护头、屈肘、多接触点滚动（肩→背→髋）分散冲击，并让终止构型落在「可恢复集」内。关键洞见：**把「终止可恢复性 x(T)∈R」写成受控跌倒轨迹优化的硬约束**——跌倒不是失败，而是一次以可恢复构型为终点的运动规划。

**灵感 4（运动控制 → 恢复技能组合 RSC）**
直觉：从地面起身不是单一动作，而是技能序列（俯卧撑起→跪姿→蹲姿→站立）。每个技能有适用域、接触时序、能耗与成功率。关键洞见：**把恢复建模为「接触调度＋全身控制」的技能图搜索**：技能图保证组合可行，WBC/MPC 跟踪接触时序并满足摩擦锥。

**灵感 5（合流 → 恢复感知闭环 FRC＋恢复上下文 RCM）**
直觉：地形（软硬、摩擦、坡度）决定冲击大小与恢复难度；人的保护意图（「护住头」「别压到我」「松手」）是**时变的安全约束**。把第 60 轮 SSM 扩展为接触地形语义、CIEC 扩展为保护意图，一同喂入 FRC。关键洞见：**恢复能力是「状态 × 地形 × 意图」的联合函数**，而非只依赖状态。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（可恢复性流形 RMR）** 状态 x=(q, q̇)∈X，控制 u∈U(x)（关节力矩 τ、接触力 F_c）。恢复目标集 G_rec = {直立、COM 落在支撑多边形内、关节处于恢复技能适用域}。给定恢复策略类 Π_rec，定义**可恢复集**：
```
R = { x ∈ X | ∃π_rec∈Π_rec, ∃T≤T_rec：在 τ≤τ_max、F_c∈摩擦锥、
      关节限位、无自碰撞、冲击≤J_impact_max 下，从 x 到达 G_rec }
```
**可恢复裕度**：ρ(x)=d_W(x, ∂R)（度量 W 下的有符号距离）。在线以可恢复价值 V_rec(x)∈[0,1] 与集成不确定性 σ(x) 估计保守裕度：
```
ρ̂(x) = V_rec(x) − κ·σ(x) − τ_rec
```
三区判定：ρ̂>ρ_safe 名义；ρ_commit<ρ̂≤ρ_safe 边际（允许跌倒规避）；ρ̂≤ρ_commit 已承诺（转入受控跌倒）。

**定义 162（跌倒预测证书 TPC）** 给定支撑多边形 P_sup 与接触不确定性 Σ_c。捕获点（DCM）ξ=c+ċ/ω，ω=√(g/z_com)，c 为 COM 水平位置。到支撑边界距离 d(ξ,P_sup)。预测：
```
τ_ttf = TTF(ξ, d, Σ_c),   P_fall = σ((τ_react − τ_ttf)/s_t)
J_pred = (τ_ttf^LCB, P_fall^UCB, confidence, alert ∈ {green, amber, red})
```
LCB/UCB 为 1−δ 置信界。**红区** ⇔ τ_ttf^LCB < τ_react 且 P_fall^UCB ≥ p_commit。

**定义 163（受控跌倒规划 CFP）** 触发红区且无可行规避动作时，求轨迹 (u(t), C(t))（C 为接触调度）：
```
min J_fall = w_imp·∫‖F_impact(t)‖² dt + w_dmg·Damage(x(T))
           + w_rec·(1 − V_rec(x(T))) − w_prot·Protect(x(t))
s.t. x(0)=x0, 动力学约束, τ≤τ_max, F_c∈摩擦锥,
     x(t) ∉ S_protected（头/人/易碎物）,  x(T) ∈ R
```
两条关键硬约束：**x(T)∈R**（终止可恢复）与 **x(t)∉S_protected**（不可碰区域）。

**定义 164（恢复技能组合 RSC）** 技能库 Π={p_i}，p_i=(A_i 适用域, C_i(t) 接触时序, T_i 时长, s_i 成功率, e_i 能耗)。恢复计划为序列 p_{i1}…p_{ik}，在技能图 G_Π 上求最小期望代价路径：
```
π_rec* = argmin_{p_{i1}…p_{ik}} Σ_j ( e_{ij}/s_{ij} + λ_ttf·T_{ij} )
s.t. 组合可达 G_rec
```
执行由全身控制 WBC/MPC 跟踪接触时序 C_i(t)，接触力在摩擦锥内。

**定义 165（恢复感知闭环 FRC）** 算子 FRC(M, intent)：
```
① x ← estimator.state()；RCM: (z_terrain, P_int) ← context.update(x, terrain, intent)
② ρ̂ ← RMR.margin(x | z_terrain, P_int)；J_pred ← TPC.predict(x, P_sup, Σ_c)
③ if ρ̂ > ρ_safe and J_pred.alert == green:  return normal_motion_control(M)   # SERC/MPC
④ if ρ_commit < ρ̂ ≤ ρ_safe or J_pred.alert == amber:  return fall_avoidance(M, J_pred)
⑤ # committed
   plan ← CFP.plan(x, z_terrain, S_protected=P_int.protected)
   execute(plan); x_fallen ← wait_settle()
⑥ π_rec* ← RSC.compose(x_fallen, z_terrain); execute_to(G_rec)
⑦ J_rec ← issue_recovery_certificate(π_rec*, ρ̂_start, ρ̂_end, plan)
   EPIR.append(fall_event + J_rec)；update V_rec, T_terrain
⑧ return (mode, π_rec*, J_rec, J_pred, fall_event_log)
```

**定义 166（恢复预算 PCE+++++）** B_rec=(B_pred, B_react, B_contact, B_exec)：
- **B_pred**：预测算力/时延；**B_react**：反应时间（须 < τ_ttf）；**B_contact**：接触调度搜索预算；**B_exec**：第 60 轮执行预算。
- 策略：B_pred 耗尽 ⇒ 保守「防御姿态」（下蹲、扩大支撑），停用前瞻；B_react 不足 ⇒ 提前承诺受控跌倒（保守化阈值）；B_contact 耗尽 ⇒ 单技能贪心（sit-up/roll）；B_exec 耗尽 ⇒ 最小冲击保护姿态＋安全停机。

**定义 167（恢复证书 J_rec）**
```
J_rec = (plan_id, π_rec*, ρ̂_start, ρ̂_end, P_success ≥ 1−δ,
        约束裕度向量, 冲击上界 J_impact^UB, timestamp)
```
由 CFP/RSC 签发；若无可行 π_rec*（或 ρ̂ 过低、预算不足），声明 **IRRECOVERABLE** 并执行保护动作（护头、呼救、安全停机）。J_rec 写入 EPIR，保证「跌倒—恢复」链可审计。

**定义 168（恢复上下文模型 RCM）** RCM=(T_terrain, P_intent)：
- **地形接触先验** T_terrain：在第 60 轮 SSM 场景 z 上增加 (μ 摩擦, k_g 地面刚度, θ 坡度, softness 软硬度)，影响 CFP 的冲击模型与 RSC 的可行技能。
- **保护意图** P_intent：ϕ_protect('护头')→S_protected∋头部球；'别压我'→人体禁区球；'松手'→释放夹爪且禁止再抓取。意图锁定 τ_protect，超时释放。
- 二者共同条件化可恢复价值：V_rec(x|z_terrain, P_intent)。

## 2. 关键算法伪代码

### IP-161 RMR（可恢复性流形）

```python
class RecoverabilityManifold:
    def __init__(self, critic, unc_model, goal_set, kappa=2.0, tau_rec=0.02):
        self.V, self.unc = critic, unc_model        # V_rec(x), sigma(x)
        self.G = goal_set
        self.kappa, self.tau_rec = kappa, tau_rec
        self.rho_safe, self.rho_commit = 0.35, 0.15

    def margin(self, x, z_terrain=None, p_intent=None):
        ctx = (z_terrain, p_intent)
        v = self.V(x, ctx)
        sigma = self.unc(x, ctx)                     # ensemble variance
        v_lcb = v - self.kappa * sigma               # lower-confidence bound
        rho = v_lcb - self.tau_rec
        return rho, v, v_lcb, sigma

    def status(self, x, z_terrain=None, p_intent=None):
        rho, *_ = self.margin(x, z_terrain, p_intent)
        if rho > self.rho_safe:   return 'NOMINAL'
        if rho > self.rho_commit: return 'MARGINAL'
        return 'COMMITTED'
```

### IP-162 TPC（跌倒预测证书）

```python
class TipoverPredictor:
    def __init__(self, z_com=0.8, tau_react=0.25, delta=0.05, horizon=1.5):
        self.omega = math.sqrt(9.81 / z_com)
        self.tau_react, self.delta, self.horizon = tau_react, delta, horizon

    def predict(self, x, support_polygon, sigma_contact):
        c, cdot = com_position(x), com_velocity(x)
        xi = c + cdot / self.omega                   # divergent component of motion
        d = signed_dist_to_polygon(xi, support_polygon)
        tau = self._time_to_fall(d, cdot, sigma_contact)
        p = 1.0 / (1.0 + math.exp(-(self.tau_react - tau) / 0.08))
        tau_lcb = tau - self._ttf_quantile(sigma_contact, self.delta)
        p_ucb = min(1.0, p + self.delta)
        alert = ('red' if (tau_lcb < self.tau_react and p_ucb >= 0.85)
                 else 'amber' if tau_lcb < 2 * self.tau_react else 'green')
        return PredictionCertificate(tau_lcb, p_ucb, self.delta, alert)
```

### IP-163 CFP（受控跌倒规划）

```python
def controlled_fall_plan(x0, terrain, protected, rmr, horizon=1.2):
    def cost(traj):
        impact = integrate(lambda t: norm(traj.contact_force(t)) ** 2, 0, horizon)
        dmg = damage_model(traj.x(horizon), terrain.softness)
        rec = 1.0 - rmr.V(traj.x(horizon), terrain)
        prot = protect_penalty(traj, protected)     # 头/人禁区
        return 1.0*impact + 0.5*dmg + 2.0*rec + 5.0*prot
    cons = [
        Dynamics(), TorqueLimit(), FrictionCone(),
        TerminalInRecoverableSet(rmr, terrain),     # x(T) in R
        AvoidRegions(protected),                    # x(t) not in S_protected
    ]
    traj = trajopt(x0, cost, cons, horizon)
    return traj  # includes contact schedule C(t)
```

### IP-164 RSC（恢复技能组合）

```python
class RecoverySkillLibrary:
    def __init__(self, primitives):
        self.P = {p.name: p for p in primitives}    # applicability, contacts, T, s, e

    def compose(self, x_fallen, terrain):
        g = build_skill_graph(self.P, x_fallen, terrain)  # directed, edges=feasible seq
        path = astar(g, start=x_fallen, goal=GoalSet.G_rec,
                     edge_cost=lambda a, b: self.P[b].e / max(self.P[b].s, 1e-3)
                                           + 0.1 * self.P[b].T)
        if path is None:
            return None
        contacts = [self.P[p].contacts for p in path]
        return RecoveryPlan(path, contacts, wbc=WholeBodyMPC())
```

### IP-165 FRC（恢复感知闭环）

```python
def fall_recovery_loop(M, terrain=None, intent=None):
    x = M.estimator.state()
    z_terrain, p_int = M.rcm.update(x, terrain, intent)
    rho, v, v_lcb, sigma = M.rmr.margin(x, z_terrain, p_int)
    pred = M.tpc.predict(x, M.support_polygon, M.sigma_contact)

    if rho > M.rmr.rho_safe and pred.alert == 'green':
        return normal_motion_control(M)                       # SERC/MPC
    if (M.rmr.rho_commit < rho <= M.rmr.rho_safe
            or pred.alert == 'amber'):
        return fall_avoidance(M, pred)                        # stepping/reaction

    plan = M.cfp.plan(x, z_terrain, p_int.protected, M.rmr)
    execute_trajectory(plan)
    x_fallen = wait_settle()

    rec = M.rsc.compose(x_fallen, z_terrain)
    if rec is None:
        J_rec = M.cert.issue_irrecoverable(x_fallen, reason='no_plan')
        M.protect.execute_safe_shutdown(p_int)
    else:
        execute_recovery(rec, until=GoalSet.G_rec)
        J_rec = M.cert.issue(rec, rho_start=rho,
                             rho_end=M.rmr.margin(M.estimator.state())[0])
    M.epir.append({'fall_event': x_fallen, 'pred': pred, 'cert': J_rec})
    M.rmr.update_from_event(J_rec)                            # online V_rec learning
    return M, J_rec, pred
```

### IP-166 PCE+++++（恢复预算）

```python
class RecoveryBudget:
    def __init__(self, b_pred=50, b_react=0.25, b_contact=20, b_exec=None):
        self.B_pred, self.B_react = b_pred, b_react
        self.B_contact = b_contact
        self.B_exec = b_exec or ExecBudget()

    def mode(self, tau_ttf_lcb):
        if self.B_pred <= 0:
            return 'defensive_posture'      # 下蹲、扩大支撑
        if tau_ttf_lcb < self.B_react:
            return 'commit_fall_early'      # 保守化，提前承诺
        if self.B_contact <= 0:
            return 'greedy_single_skill'    # sit-up / roll
        if self.B_exec.exhausted():
            return 'min_impact_safe_stop'
        return 'normal'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| RMR | O(1) 查询 / O(E) 训练 | O(|θ_critic|) | 保守裕度误判率 ≤ α（LCB 修正） |
| TPC | O(1)/周期 | O(1) | τ_ttf 误差 ≤ 100ms，漏报 ≤ 2% |
| CFP | O(N_h·K) 轨迹优化 | O(N_h) | 终止 x(T)∈R，冲击降幅 ≥ 30% |
| RSC | O(|V_Π|+|E_Π|) A* | O(|V_Π|) | 恢复成功率 ≥ 85% |
| FRC | O(闭环) | 复用 | 不可恢复率 ≤ 3%，恢复时间 −35% |

**正确性定理（FRC-Cert）**：设 **A66** 状态与质心动量估计误差 ‖x̂−x‖≤δ_x；**A67** V_rec 的 LCB 是 R 的保守近似（V_rec−κσ≤1 ⇒ x∈R 的假阳率 ≤ α）；**A68** WBC/MPC 跟踪接触时序的力误差满足摩擦锥；**A69** TPC 预测时延 ≤ τ_react 的概率 ≥ 1−δ_pred；**A70** 技能库 Π 覆盖 G_rec 邻域所有落定构型的恢复路径。则：

1. **承诺无过早性**：红区触发后仍存在可行规避的概率 < p_abort（由 A67 保守界保证），故 CFP 不早于必要时刻启动。
2. **终止可恢复性**：CFP 硬约束 x(T)∈R ⇒ 落定后 RSC 成功概率 ≥ 1−δ（A68+A70）。
3. **证据可审计**：J_rec 与 fall_event 经 EPIR 因果校验，恢复链完整性 ≥ 99.9%。
4. **预算安全**：任一 B_rec 耗尽即触发对应保护策略，绝不进入「无证书恢复」。

## 5. 本轮最大风险

**一句话**：最大风险是学到的可恢复价值 V_rec 在分布外地形/跌倒构型上**过度乐观**，导致控制器把承诺时刻拖到「已不可恢复」之后——即「可恢复性幻觉」；必须以「集成方差 LCB 保守裕度」「仿真-真机可恢复性证书校准」「预算耗尽即保护姿态」三重护栏，确保「受控跌倒」永不晚于「最后可恢复时刻」。

## 2. 关键算法伪代码

### IP-161 RMR（可恢复性流形）

```python
class RecoverabilityManifold:
    def __init__(self, critic, unc_model, goal_set, kappa=2.0, tau_rec=0.02):
        self.V, self.unc = critic, unc_model        # V_rec(x), sigma(x)
        self.G, self.kappa, self.tau_rec = goal_set, kappa, tau_rec
        self.rho_safe, self.rho_commit = 0.35, 0.15

    def margin(self, x, z_terrain=None, p_intent=None):
        ctx = (z_terrain, p_intent)
        v = self.V(x, ctx)
        sigma = self.unc(x, ctx)                     # ensemble variance
        v_lcb = v - self.kappa * sigma               # lower-confidence bound
        return v_lcb - self.tau_rec, v, v_lcb, sigma

    def status(self, x, z_terrain=None, p_intent=None):
        rho, *_ = self.margin(x, z_terrain, p_intent)
        if rho > self.rho_safe:   return 'NOMINAL'
        if rho > self.rho_commit: return 'MARGINAL'
        return 'COMMITTED'
```

### IP-162 TPC（跌倒预测证书）

```python
class TipoverPredictor:
    def __init__(self, z_com=0.8, tau_react=0.25, delta=0.05):
        self.omega = math.sqrt(9.81 / z_com)
        self.tau_react, self.delta = tau_react, delta

    def predict(self, x, support_polygon, sigma_contact):
        c, cdot = com_position(x), com_velocity(x)
        xi = c + cdot / self.omega                   # DCM
        d = signed_dist_to_polygon(xi, support_polygon)
        tau = self._time_to_fall(d, cdot, sigma_contact)
        p = 1.0 / (1.0 + math.exp(-(self.tau_react - tau) / 0.08))
        tau_lcb = tau - self._ttf_quantile(sigma_contact, self.delta)
        p_ucb = min(1.0, p + self.delta)
        alert = ('red' if (tau_lcb < self.tau_react and p_ucb >= 0.85)
                 else 'amber' if tau_lcb < 2 * self.tau_react else 'green')
        return PredictionCertificate(tau_lcb, p_ucb, self.delta, alert)
```

### IP-163 CFP（受控跌倒规划）

```python
def controlled_fall_plan(x0, terrain, protected, rmr, horizon=1.2):
    def cost(traj):
        impact = integrate(lambda t: norm(traj.contact_force(t)) ** 2, 0, horizon)
        dmg = damage_model(traj.x(horizon), terrain.softness)
        rec = 1.0 - rmr.V(traj.x(horizon), terrain)
        prot = protect_penalty(traj, protected)          # 头/人禁区
        return 1.0*impact + 0.5*dmg + 2.0*rec + 5.0*prot
    cons = [Dynamics(), TorqueLimit(), FrictionCone(),
            TerminalInRecoverableSet(rmr, terrain),      # x(T) in R
            AvoidRegions(protected)]                     # x(t) not in S_protected
    return trajopt(x0, cost, cons, horizon)              # 含接触调度 C(t)
```

### IP-164 RSC（恢复技能组合）

```python
class RecoverySkillLibrary:
    def __init__(self, primitives):
        self.P = {p.name: p for p in primitives}        # applicability, contacts, T, s, e

    def compose(self, x_fallen, terrain):
        g = build_skill_graph(self.P, x_fallen, terrain)  # edges = feasible sequences
        path = astar(g, start=x_fallen, goal=GoalSet.G_rec,
                     edge_cost=lambda a, b: self.P[b].e / max(self.P[b].s, 1e-3)
                                           + 0.1 * self.P[b].T)
        if path is None:
            return None
        return RecoveryPlan(path, [self.P[p].contacts for p in path],
                            wbc=WholeBodyMPC())
```

### IP-165 FRC（恢复感知闭环）

```python
def fall_recovery_loop(M, terrain=None, intent=None):
    x = M.estimator.state()
    z_terrain, p_int = M.rcm.update(x, terrain, intent)
    rho, v, v_lcb, sigma = M.rmr.margin(x, z_terrain, p_int)
    pred = M.tpc.predict(x, M.support_polygon, M.sigma_contact)

    if rho > M.rmr.rho_safe and pred.alert == 'green':
        return normal_motion_control(M)                     # SERC/MPC
    if (M.rmr.rho_commit < rho <= M.rmr.rho_safe
            or pred.alert == 'amber'):
        return fall_avoidance(M, pred)                      # stepping/reaction

    plan = M.cfp.plan(x, z_terrain, p_int.protected, M.rmr)
    execute_trajectory(plan)
    x_fallen = wait_settle()

    rec = M.rsc.compose(x_fallen, z_terrain)
    if rec is None:
        J_rec = M.cert.issue_irrecoverable(x_fallen, reason='no_plan')
        M.protect.execute_safe_shutdown(p_int)
    else:
        execute_recovery(rec, until=GoalSet.G_rec)
        J_rec = M.cert.issue(rec, rho_start=rho,
                             rho_end=M.rmr.margin(M.estimator.state())[0])
    M.epir.append({'fall_event': x_fallen, 'pred': pred, 'cert': J_rec})
    M.rmr.update_from_event(J_rec)                          # online V_rec learning
    return M, J_rec, pred
```

### IP-166 PCE+++++（恢复预算）

```python
class RecoveryBudget:
    def __init__(self, b_pred=50, b_react=0.25, b_contact=20, b_exec=None):
        self.B_pred, self.B_react = b_pred, b_react
        self.B_contact = b_contact
        self.B_exec = b_exec or ExecBudget()

    def mode(self, tau_ttf_lcb):
        if self.B_pred <= 0:
            return 'defensive_posture'      # 下蹲、扩大支撑
        if tau_ttf_lcb < self.B_react:
            return 'commit_fall_early'      # 保守化，提前承诺
        if self.B_contact <= 0:
            return 'greedy_single_skill'    # sit-up / roll
        if self.B_exec.exhausted():
            return 'min_impact_safe_stop'
        return 'normal'
```

class RecoveryContextModel:
    def update(self, x, terrain, intent):
        z = self.scene_model.update(x)                      # 复用第 60 轮 SSM
        t_prior = TerrainPrior(mu=terrain.mu, k_g=terrain.k_g,

    @staticmethod

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| RMR | O(1) 查询 / O(E) 训练 | O(\|θ_critic\|) | 保守裕度误判率 ≤ α |
| TPC | O(1)/周期 | O(1) | τ_ttf 误差 ≤ 100ms，漏报 ≤ 2% |
| CFP | O(N_h·K) 轨迹优化 | O(N_h) | 终止 x(T)∈R，冲击降幅 ≥ 30% |
| RSC | O(\|V_Π\|+\|E_Π\|) A* | O(\|V_Π\|) | 恢复成功率 ≥ 85% |
| FRC | O(闭环) | 复用 | 不可恢复率 ≤ 3%，恢复时间 −35% |

**正确性定理（FRC-Cert）**：若 A66–A70 成立（估计误差有界 / LCB 保守近似 / WBC 跟踪满足摩擦锥 / TPC 时延 ≤ τ_react / 技能库覆盖落定构型），则：

1. **承诺无过早性**：红区触发后仍存在可行规避的概率 < p_abort ⇒ CFP 不早于必要时刻启动。
2. **终止可恢复性**：CFP 硬约束 x(T)∈R ⇒ 落定后 RSC 成功概率 ≥ 1−δ。
3. **证据可审计**：J_rec 与 fall_event 经 EPIR 因果校验，恢复链完整性 ≥ 99.9%。
4. **预算安全**：任一 B_rec 耗尽即触发对应保护策略，绝不进入「无证书恢复」。

**与第 60 轮的接口**：名义态直接调用 SERC（FRC③）；RMR 的条件化上下文复用 SSM 场景 z；保护意图复用 CIEC 的约束锁定机制；J_rec 与 fall_event 复用 EPIR 的 seq_id+hash 因果协议；B_rec 是 PCE++++ 的预算子集扩展。

## 5. 本轮最大风险

**一句话**：最大风险是学到的可恢复价值 V_rec 在分布外地形/跌倒构型上**过度乐观**，导致控制器把承诺时刻拖到「已不可恢复」之后——即「可恢复性幻觉」；必须以「集成方差 LCB 保守裕度」「仿真-真机可恢复性证书校准」「预算耗尽即保护姿态」三重护栏，确保「受控跌倒」永不晚于「最后可恢复时刻」。
