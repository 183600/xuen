# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「力觉传感」×「放置」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**接触即观测 + 放量即许可 + 失效即保守**。v9 的块证书仍以视觉/几何前向模型 F̂ 为唯一证据源；而放置的最后几厘米恰恰是视觉被手爪与物体遮挡、且成败由接触决定（滑移、冲击、载荷转移、释放）的区间。本轮把力觉/触觉提升为一等证据通道，并把「放置」从开环位姿指令改写为**带证书的接触相位程序**。任一触觉通道不可用时注入**失效安全中立元**，退化到 v9 视觉路径或更保守的保持态，而绝不「缺证据即放行」。

## 0. 直觉与动机

**灵感 1（力觉传感 → 接触成为一等可观测量）**
直觉：视觉告诉你「物体应该在哪」，力觉告诉你「物体此刻是否真的被托住、是否在滑、是否已到底」。在放置末段，视觉被遮挡、标定误差与形变主导，而 F/T 六维力与触觉阵列提供无遮挡、高带宽、直接物理因果的证据。核心创新：**接触状态估计器（ContactStateEstimator, CSE）** + **接触状态证书（ContactStateCertificate, CSC）**：把力/触觉融合为接触状态 c*∈{free, approach, contact, loaded, slip, settle, lost}，每个状态有带迟滞的谓词与界（滑移冲量上界、法向力包络、压力中心 CoP 稳定性）。CSC 作为 v9 块证书 Ĉ 的新字段，使「块内预测」在接触段由「实时物理测量」兜底。

**灵感 2（放置 → 带证书的相位程序，而非一个位姿点）**
直觉：放置不是「到点→松爪」，而是 approach → first-contact → load-transfer → settle → release → retreat 的相位程序；每个相位转移有各自的失效模式（提前接触、冲击、载荷期滑移、提前释放、撤离拖拽）。核心创新：**放置释放证书（PlacementReleaseCertifier, PRC）**：释放是一个受守卫的**单向动作**，必须同时满足（a）几何误差在容差内并保持 τ_dwell；（b）载荷转移证据 ρ≥α（支撑反力达到物体重量的比例）；（c）滑移静默 τ_quiet；（d）证书未降级。任一条不满足即保持夹持并重逼近。**超时永不释放**——释放是正证据事件，不是缺省事件。

**灵感 3（把触觉接入 MetricVoice 的「声部」与中立元代数）**
直觉：v9 已把「指标会说话」形式化为契约 + 中立元退化。触觉同样是一个声部：它给出关于接触安全的 claims，也应能被认证、加权、退化。核心创新：**接触声部（ContactVoice）与失效安全中立元（Fail-Safe Neutral Element）**：F/T、触觉阵列作为 MW 契约端口，失效时注入默认元。但释放谓词是**单向安全谓词**，其代数不是普通恒等元（x⊕0=x），而是**证据格（evidence lattice）**上的保守合成：只有「确证安全」才放行，「未知」一律视为不放行。这与 v9 的对称中立元不同，是本轮最重要的代数修正。

## 1. 研究问题（轮次升级版）

- **Q1（接触证书可靠性）**：在传感器噪声、标定漂移与接触模型误差有界下，如何设计 CSC，使滑移在 N 个控制周期内被检出且滑移冲量不超过界？F/T 与触觉阵列冲突时如何合成而不产生「多数票掩盖危险」？
- **Q2（放置成功的可证定义）**：什么谓词同时保证「物体已被支撑、未楔紧、未拖拽」？几何误差、载荷转移、滑移静默、静置时间如何联合成既充分又不过保守的释放条件？
- **Q3（触觉退化的安全性与活性）**：如何把触觉失效编码为失效安全默认元，使系统绝不「缺证据即释放」，同时在真实放稳时仍在有界时间内释放（无死锁）？退化到 v9 的哪一层，等价性如何界定？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 接触状态证书律（Contact-State Certificate, CSC）**
接触状态与每状态谓词带迟滞；证书携带滑移冲量界 J_slip ≤ J_max 与法向力包络 [f_min, f_max]。接触状态不确定 ⇒ 进入保守接触模式（降速、缩短块长、禁止释放）。

**P14 放置释放证书律（Certified Release, PRC）**
release = true 仅当几何 ∧ 载荷 ∧ 静默 ∧ 证书有效四条件同时成立且持续 τ_dwell；缺证据 ⇒ hold + re-approach；**禁止超时释放**。释放后进入 retreat 守卫，监测撤离拖拽力。

**P15 失效安全中立元律（Fail-Safe Neutral Element, CND）**
单向安全谓词的合成为证据格 ⊓：safe ⊓ safe = safe；任何 unknown 参与 ⇒ unknown；任何 unsafe ⇒ unsafe。触觉端口失效 ⇒ 默认元 = unknown（**不是**「零力 = 安全」）。默认安全档案下 unknown 禁止释放；兼容档案下可显式退回 v9 视觉释放（仅用于基准对照，需人工开启并记录）。

## 3. 与基线的接口（如何退化）

- 触觉/F-T 失效 ⇒ CND 注入 unknown；默认安全档案：保持夹持、请求重逼近；兼容档案：退回 v9 视觉软证书释放，日志标记 `degraded=v9-visual-release`；
- CSC 失效 ⇒ 接触段改由 v9 块证书覆盖，K_eff 收缩，release 需更长 τ_dwell 与更大几何裕度；
- PRC 失效 ⇒ 保持夹持并执行 v9 中止点安全停驻（等价 v9 安全语义，且更保守）；
- v9 ACMD 失效 ⇒ 按 v9 五级链退回 v8；
- 全部失效 ⇒ 完整退回 v7，再退回 v6。

## 4. 预期贡献

1. **接触状态证书（CSC）**：力/触觉融合的滑移与载荷界，给 v9 块证书补上接触段物理证据；
2. **认证式释放（PRC）**：把放置成功定义为「正证据事件」，杜绝超时/缺省释放；
3. **失效安全中立元代数**：区分 v9 的对称中立元与单向安全谓词的证据格合成，并给出「无误放 + 无死锁」的联合条件；
4. **接触声部与最小传感器集**：E571–E590 覆盖接触分类、滑移延迟、提前释放、支撑 vs 楔紧、失效注入、死锁活性、紧配合插装、堆叠、软物体与 sim-to-real。

## 5. 本轮最大风险

**一句话**：释放证书以「力签名 ⇒ 已获支撑」为前提，而夹持摩擦、斜面/柔性支撑与质量标定漂移都能伪造同一力签名——系统可能把「楔紧/卡住」误认证为「放稳」，或者因过于保守的正证据要求而永不释放，在安全与活性两端同时暴露风险。

**新增定义 540（接触观测 ContactObservation）** o^c_t = (w_t, T_t, u_t)：w_t=(f_x,f_y,f_z,τ_x,τ_y,τ_z) 为腕部六维力/力矩；T_t∈R^{m×m}_{≥0} 为触觉阵列压力图（默认 16×16）；u_t 为夹爪开度与指位。采样后按控制周期对齐：F/T 在 1kHz 抗混叠降采样到 50Hz，触觉在 100Hz 上做滑移光流并降采样。

**新增定义 541（接触状态格与相位机 Contact Lattice & Phase FSM）** 接触状态为偏序格，带迟滞的转移规则：
```
free      --approach-->  approach
approach  --(f_n ≥ f_touch 持续 2 周期)-->  contact
contact   --(ρ ≥ α_contact)-->  loaded
loaded    --(J_slip ≥ J_warn)-->  slip
slip      --(J_slip 静默 τ_quiet)-->  settle
settle    --(释放)-->  retreat
{approach,contact,loaded,slip} --(f_n 骤降 ∧ 位姿跳变)-->  lost
```
相位机 `approach → contact → load → settle → release → retreat` 与接触状态正交：前者是任务意图，后者是物理事实；PRC 只在 `phase=release ∧ c*=settle` 时评估。

**新增定义 542（滑移估计与冲量界 Slip Estimate）** 触觉压力图的切向光流给出滑移速度 v_s(t)；滑移段
```
J_slip(t) = ∫_{t_s}^{t_d + N_d·Δt} |f_t(τ)| dτ
```
其中 t_s 为滑移起始、t_d 为检出时刻、N_d 为融合确认延迟。安全要求 J_slip ≤ J_max（由物体脆性与夹持面决定），非等待「零滑移」，而是等待「滑移已被及时制动」。

**新增定义 543（接触状态证书 ContactStateCertificate, CSC）** 块级证书的接触字段：
```
κ^c_t = (c*_t, J_slip, [f_min, f_max], ρ_t, CoP-margin, conf)
```
有效 ⇔ conf ≥ χ ∧ J_slip ≤ J_max ∧ f_n ∈ [f_min, f_max] ∧ CoP 在支撑多边形内。当 F/T 与触觉给出矛盾证据时，不投票，而是对二者各自产出的证据做 ⊓：任一 `unsafe` ⇒ 整证书 `unsafe`；任一 `unknown` ⇒ 整证书 `unknown`；仅二者皆 `safe` 才 `safe`。

**新增定义 544（载荷转移比与力签名 Load Transfer）** ρ_t = (物体重量中由支撑承担的比例) = clip((m̂g − f_z^grip)/(m̂g), 0, 1)（竖直放置；其他朝向用腕力投影）。力签名 S_t = (f_z 轨迹, CoP 轨迹, 接触刚度估计)。期望「支撑」签名：f_z 平滑下降、CoP 收敛于支撑多边形内、刚度有限；「楔紧/卡住」签名：f_z 居高、CoP 偏向夹持侧、刚度异常或出现突变尖峰。

**新增定义 545（认证释放谓词 Certified Release, PRC）** 令 ev_geo、ev_load、ev_quiet、ev_valid 分别为几何、载荷、静默、证书有效性的证据值，则
```
ev_release = ev_geo ⊓ ev_load ⊓ ev_quiet ⊓ ev_valid
release    = [ev_release = S] ∧ dwell(ev_release = S, τ_dwell)
```
缺证据（U）与明确不安全（X）都禁止释放；区别只在响应：U ⇒ hold + 请求重逼近/人工，X ⇒ 立即重逼近或改抓取点。实现层面**不存在**「等待超时后释放」的分支。

**新增定义 546（失效安全默认元与证据格 Fail-Safe Neutral Element）** 证据格 E={S,U,X}，合成算子：
```
X ⊓ e = X;   U ⊓ S = U;   U ⊓ U = U;   S ⊓ S = S
```
即链 X ⊑ U ⊑ S，⊓ = min（按许可度取最小）。注意：⊓ 的**恒等元是 S**，但接触端口失效时注入的是 `v^⊥_c = U`，**不是**恒等元。原因：单向安全谓词若注入恒等元 S，等价于「传感器失效 ⇒ 视为安全 ⇒ 放行」，这是致命的；注入 U 才满足「缺证据不放行」。这修正了 v9 中「中立元 = 恒等元」的对称假设，也是本轮最重要的代数区别。

**新增定义 547（接触感知块长 Contact-Aware Chunk Length）**
```
K_eff^C(t) = min( K_eff(t), K_contact )          c* ∈ {contact, loaded, slip}
           = 1                                    phase ∈ {release, retreat}
```
其中 K_contact=2（默认，E584 扫描）。接触段越接近释放，块越短；释放与撤离阶段强制逐步执行，避免块内跨越相位边界。

**新增定义 548（放置成功事件 Placement Success Event）**
```
Success ⇔ release 时 ev_release=S
        ∧ 释放后 τ_verify 内物体位姿稳定（漂移 ≤ δ_settle）
        ∧ 撤离拖拽力 ≤ f_drag
        ∧ 无掉落/无支撑面塌陷
```
放置成功是「释放 + 释放后验证」的合取，而不是「夹爪张开」本身。

**新增定义 549（撤离守卫 Retreat Guard）** 释放后夹爪以受控速度撤离，监测 f_z 与物体位姿；若拖拽力 > f_drag 或物体被带动 > δ_drag，则判定 `drag`，在允许时重抓并重新放置；同时监测「物体粘连夹爪」（撤离后 f_z 未归零）。

## 2. 形式化定义（要点与升级）

**定义 493（指标层级，v10）** 在 v8/v9 六层基础上新增接触层：
```
M = (M₀, M₁, M₂, M₃, M_dom, M_SLAM, M_C)
M_C = (M_C^slip, M_C^force, M_C^settle, M_C^drag)
```
M₀ 仍为硬检查；M_C^slip 与 M_C^force 为接触段硬约束（越界立即进入保守模式），M_C^settle 与 M_C^drag 为软约束（影响释放评分与重试）。

**定义 495/524（MetaWeight/情感，5 维）** 继承 v9 不变。
**定义 521（DA-OTL）** 继承 v9 不变；接触段 τᵢ(t) 由 CSC 的接触字段复核。
**升级定义 496（软证书，v10）**
```
δ_trigger = {σ < τ_safe ∧ γ_grasp valid ∧ Δ_dom < τ_dom
             ∧ risk_SLAM < τ_SLAM ∧ Ĉ_t valid ∧ κ^c_t valid}
```
六条件同尺度；接触证书失效与块证书失效一样触发 M₀ 硬检查与保守模式，无「块内软通过、接触硬失效」空洞。
**升级定义 531（软硬约束衔接，v10）** M₀ 判据增加接触入口：`c*∈{slip,lost}` 或 `J_slip > J_max` 或 `f_n ∉ [f_min,f_max]` ⇒ 立即进入保守接触模式并禁止释放；PRC 的 `unknown` 不得被任何上层评分覆盖。

        cop = self._center_of_pressure(T) if T is not None else None
        slip, J = self._slip_flow(T) if T is not None else (None, None)
        rho = self._load_ratio(w) if w is not None else None
        state, conf = self._classify(w, T, slip, cop)
        return ContactObs(state, slip, J, rho, cop, conf)

    def _slip_flow(self, T):
        # 触觉压心/纹理的切向位移 → 滑移速度；零流且压力稳定 → 静默
        v = tactile_optical_flow(T) / DT
        J = integrate_abs_force(v)          # 定义 542
        return v, J


# IP-358 ContactStateCertificate：证据格保守合成
SAFE, UNKNOWN, UNSAFE = 2, 1, 0

def meet(*ev):

class ContactStateCertificate:

# IP-359 PlacementReleaseCertifier：单向释放 + 撤离守卫
class PlacementReleaseCertifier:
    def __init__(self, eps_xy=0.005, eps_th=0.03, alpha=0.85,
                 tau_dwell=0.4, tau_quiet=0.2, delta_settle=0.004,
                 f_drag=1.0):
        self.eps_xy, self.eps_th, self.alpha = eps_xy, eps_th, alpha
        self.tau_dwell, self.tau_quiet = tau_dwell, tau_quiet
        self.delta_settle, self.f_drag = delta_settle, f_drag
        self._safe_since = None

    def release_evidence(self, pose_err, obs, cert, now):
        ev_geo = SAFE if (pose_err.xy <= self.eps_xy
                          and pose_err.th <= self.eps_th) else UNSAFE
        ev_load = (UNKNOWN if obs.rho is None else
                   SAFE if obs.rho >= self.alpha else UNSAFE)
        ev_quiet = (UNKNOWN if obs.slip is None else
                    SAFE if obs.slip < self.eps_slip_for(self.tau_quiet)
                    else UNSAFE)
        ev_valid = SAFE if cert == SAFE else cert   # 已是证据值
        return meet(ev_geo, ev_load, ev_quiet, ev_valid)

    def decide(self, pose_err, obs, cert, now, phase):
        if phase != 'release':
            return 'hold'
        ev = self.release_evidence(pose_err, obs, cert, now)
        if ev != SAFE:
            self._safe_since = None
            return 'hold_reapproach' if ev == UNSAFE else 'hold_wait'
        # 正证据持续 τ_dwell 才允许释放
        if self._safe_since is None:
            self._safe_since = now
        if now - self._safe_since >= self.tau_dwell:
            return 'release'                        # 无超时分支
        return 'hold_wait'

    def retreat_guard(self, obs, obj_pose0, obj_pose):
        drag = (obs.f_tangential > self.f_drag
                or dist(obj_pose, obj_pose0) > self.delta_settle)
        return 'drag' if drag else 'ok'

## 4. 推导

**引理 87（滑移检出延迟与冲量界）** 设触觉光流噪声有界 |ε_v|≤ε，滑移位移超过 d_min 才可区分于噪声，控制周期 Δt，融合确认需 N_d 周期。则检出延迟
```
N_delay ≤ ⌈d_min / ((v_s − ε)Δt)⌉ + N_d
```
且若制动前切向力 |f_t|≤f_t^max、接触最多持续 N_delay 周期，则
```
J_slip ≤ f_t^max · N_delay · Δt
```
故取 J_max ≥ f_t^max·N_delay·Δt 即可保证「滑移被及时制动」而非「滑移从未发生」。证明：位移单调于 v_s Δt，噪声界给出最坏可检测时刻；冲量是力的积分，用上界代入即得。∎

**引理 88（认证释放的无误放性，条件性）** 若 PRC 返回 `release`，则 ev_release = S，由 ⊓ 定义，参与合成的 ev_geo、ev_load、ev_quiet、ev_valid 全为 S；于是 ρ ≥ α。在「m̂ 准确且力签名不被楔紧伪造」的前提下，ρ ≥ α 意味着支撑承担至少 α 比例的重量，物体获得有效支撑、未处于纯夹持悬挂。证明：⊓ 返回 S 当且仅当所有输入为 S（定义 546 的吸收律）。∎ 该引理明确暴露其前提——见引理 92 与最大风险。

**引理 89（失效安全：缺证据不放行）** 传感器失效时注入 `v^⊥_c = U`；对任意 e∈{S,U,X}，`U ⊓ e ∈ {U,X}`，永不为 S。故任一接触通道失效 ⇒ ev_release ≠ S ⇒ PRC 不释放。默认安全档案下该性质与标定、相位、评分函数无关。证明：由定义 546 的链式 min；U 与任何元素取 min 至多为 U。∎

**引理 90（活性与有界释放，无死锁）** 设物体确已被支撑且稳定，传感器健康（无 U），标定误差 |ρ̂−ρ|≤δ_ρ 且 α+δ_ρ<1，几何误差在容差内。则 ev_geo、ev_load、ev_quiet、ev_valid 在有限时间后持续为 S，PRC 在 `τ_dwell + τ_quiet + O(1)` 周期内返回 release，不死锁。证明：稳定支撑给出 ρ→1>α+δ_ρ；滑移衰减给出 J_slip→0；健康传感器给证书 S；各条件持续 S 满 τ_dwell 即触发。∎ 该引理把「保守」与「死锁」区分开：死锁只可能由持续 U（失效/不可分辨）引起，而非保守本身。

**引理 91（触觉退化与 v9 的关系）** (i) `compat-v9` 档案显式调用 v9 视觉释放，日志标记，逐位等价 v9 的释放分支；(ii) 默认 `fail-safe` 档案的释放集合是 v9 释放集合的子集（更保守），且不含任何在 U 上释放的行为。故 v10 的默认退化是「v9 的安全子行为」，而不是等价复刻；若论文需逐位对照，使用 `compat-v9` 并单列。证明：(i) 由构造；(ii) 由引理 89，U 上不释放，故可达释放集 ⊆ v9 在视觉 S 时的释放集。∎

**引理 92（支撑 vs 楔紧的可分辨条件）** 设力签名在「支撑」与「楔紧」两类下的最小距离为 Δ_S（在归一化特征空间），标定与传感噪声半径 ≤δ_cal。若 Δ_S > 2δ_cal，则最近邻/间隔分类器可分开两类；若 Δ_S ≤ 2δ_cal，FSC 输出 `unknown`，PRC 因引理 89 拒绝释放。证明：半径 δ_cal 的两球不相交当且仅当中心距 > 2δ_cal；不可分时按定义 544 强制 unknown。∎ 这给出「宁可拒放，不可误放」的形式边界。

**引理 93（接触感知块长的安全保持）** 接触段 K_eff^C ≤ K_contact，释放/撤离阶段 K=1；结合 CSC 的 50Hz 守卫，任一接触违规在 1 个控制周期内被检出并触发保守模式，故接触段安全性由 v9 引理 82（块证书/中止点）与定义 543 的界共同保持。证明：块越短，块内未检查步数越少；K=1 时退化为逐步守卫，等价 v9 逐步语义；CSC 每周期评估，违反即触发。∎

## 8. 本轮最大风险
