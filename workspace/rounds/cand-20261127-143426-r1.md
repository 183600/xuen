### 第 1 轮灵感驱动研究记录

**灵感词**：持续学习、边缘计算

**直觉与动机**：

前几轮把控制架构做成了「离线训练的学生策略 + 十二证运行时准入 + 教师兜底」的证书驱动体系（CADVS）。这套体系隐含了一个被冻结的前提：**学生策略 θ 部署后不再改变**，因此十二证（集成分歧、OOD、KC 裕度、FQC、DLC、时序有效性等）是对一个固定模型标定的。真实边缘部署中，这个前提必然失效：机械磨损、负载变化、地形迁移、传感器老化都会让部署分布 D_new 偏离训练分布 D_train，学生策略的表现会随时间单调退化。

1. **持续学习（continual learning）**：希望学生策略能在设备端在线适应漂移，而不是靠云端重训、整包下发。它带来的核心问题是灾难性遗忘，但在本框架里还有一个更尖锐的问题——**证书语义漂移**。十二证是对旧模型行为标定的：「集成分歧 < 0.10」之所以等价于「误差有界」，是因为该阈值在旧参数分布上做过校准。θ 一旦持续更新，这个「通过 ⇒ 安全」的映射本身会漂移，证书仍然全绿，但绿灯的含义已经变了。

2. **边缘计算（edge computing）**：让更新在机器人本地完成，避免上云的往返延迟、断网风险与数据隐私问题；但边缘的算力、内存、能量都是硬约束。回放库不可能无限大，而**最危险的长尾状态恰恰最少出现、最容易被均匀蓄水池淘汰**。因此边缘约束不是工程细节，而是直接决定安全性的结构性因素。

3. **核心矛盾**：持续学习要求「敢改参数」，证书体系要求「改完仍安全」。二者不是简单的「加个正则项」可以调和，因为冲突发生在**元层**：不是策略违不违规，而是「判定违规的那个评估器还准不准」。这正是本轮要处理的对象。

**关键洞见**：持续学习不只是更新策略，它会同时改变策略、改变输入分布、进而改变证书评估器的校准。因此需要一个「证书的证书」——证书可靠度 S_sound(θ,E) = P(证书通过 ⇒ 真实安全裕度 ≥ 0)。本轮的方案把证书裕度当作**学习信任域半径**（裕度越小，允许的参数位移越小，裕度耗尽则冻结学习），把风险分层回放当作**长尾安全记忆**，把漂移-陈旧监控当作**元证书守护**。这样，持续学习被「关进」证书包容的笼子里，而不是绕过它。

**形式化目标（增量）**：

1. 定义证书裕度函数 m_j(θ,x)（j=1..12）与有限见证集上的稳健裕度 M_S(θ) = min_{x∈S_cert} min_j m_j(θ,x)；定义证书信任域 T(θ_k) = {Δθ : ‖Δθ‖ ≤ r_k}，其中 r_k = (M_S(θ_k) − ε)/L_m，L_m 为 m 对 θ 的一致 Lipschitz 常数（区间界传播/CROWN 估计）。
2. 定义证书约束持续学习更新：θ_{k+1} = θ_k − Π_{T(θ_k)}(α g_k)，其中 g_k = ∇L_new + β∇L_replay；证明该更新保持 M_S(θ) ≥ ε（引理 32）。
3. 定义风险分层边缘回放配额 n_s = M · r_s / Σ_t r_t（r_s 为分层安全关键度），并证明安全加权最坏遗忘有界：max_s r_s F_s ≤ C·Σ_t r_t / M，而频率比例配额 n_s ∝ p_s 在稀有分层上使 r_s F_s ∝ 1/p_s → ∞（引理 33）。
4. 定义证书可靠度元监控：用带真值裕度的探针集估计 Ŝ_sound，并用 Hoeffding 单侧下界触发「冻结-重认证」；给出可靠度估计的样本复杂度（引理 34）。
5. 定义边缘计算感知的更新调度（Lyapunov drift-plus-penalty 的贪心近似）与联邦证书安全蒸馏（只共享低秩证书安全增量，服务端用全局见证集复核）。
6. 证明 Exec_C3L ⊆ Exec_CADVS ⊆ Exec_v29（运行时准入不变），并给出持续更新下的安全违规概率界 ≤ δ_s + δ_stat、安全加权遗忘界与适应滞后界。

**本轮最大风险**：**元证书崩塌（meta-certificate collapse）**——证书评估器 E 的可靠度是在部署前分布上标定的，而边缘持续学习使输入分布与模型同时漂移，且边缘内存限制导致探针集无法保持代表性，于是 Ŝ_sound 系统性乐观偏高；此时十二证全部显示绿灯，但绿灯已不再蕴含安全，这是「关于证书的证书」失效，任何单一证书都无法自检出来。

## 2. 关键算法骨架

### IP-478 Certificate-Constrained Continual Learner (C3L)

```python
@dataclass
class CertificateConstrainedContinualLearner:
    """C3L：证书裕度 → 信任域半径 → 投影更新 → 事后审计"""
    eps: float = 0.10                  # 安全裕度缓冲 ε
    lr_max: float = 1e-3
    L_m: float = 2.5                   # CROWN/IBP 在见证集上估计的 Lipschitz 常数
    beta_replay: float = 0.5           # 回放梯度权重 β
    witness: CertificateWitnessSet     # S_cert
    evaluator: CertificateEvaluator    # 十二证评估器 E
    recert_every: int = 500

    def margin(self, theta: np.ndarray) -> float:
        """M_S(θ) = min over (witness state × 12 certs) of m_j(θ,x)"""
        worst = float('inf')
        for x in self.witness.states:
            for j in range(12):
                worst = min(worst, self.evaluator.margin_j(theta, x, j))
        return worst

    def certified_step(self, theta, g_new, g_replay):
        """证书信任域投影：步长被剩余裕度自动限幅"""
        M = self.margin(theta)
        r = max(0.0, (M - self.eps) / self.L_m)        # 信任域半径 r_k
        g = g_new + self.beta_replay * g_replay
        step = self.lr_max * g
        if np.linalg.norm(step) > r:                    # Π_{T(θ_k)}(α g_k)
            step = step * (r / (np.linalg.norm(step) + 1e-12))
        return theta - step, r

    def update(self, theta, batch_new, replay):
        g_new = self._grad(theta, batch_new)
        g_rep = self._grad(theta, replay.sample_risk_stratified(n=256))
        theta_next, r = self.certified_step(theta, g_new, g_rep)
        # 事后审计：投影是充分条件，但数值/Lipschitz 估计误差需要兜底
        if self.margin(theta_next) < self.eps:
            return theta, UpdateStatus.REJECTED, r        # 回滚，冻结本窗口
        return theta_next, UpdateStatus.ACCEPTED, r
```

**关键性质**：当 M_S(θ_k) → ε⁺ 时 r_k → 0，学习自动停止；当 M_S(θ_k) < ε 时更新被拒绝。学习能力由证书裕度「供能」，而不是由固定学习率决定。

### IP-479 Edge Certificate Replay Reservoir (ECRR)

```python
@dataclass
class EdgeCertificateReplayReservoir:
    """ECRR：证书激活模式分层 + 风险比例配额 + 风险加权蓄水池"""
    capacity: int = 50_000                       # 边缘内存预算 M
    strata: Callable                             # (x, cert_pattern) -> stratum id
    risk: Callable                               # stratum -> r_s ∈ (0,1]

    def __post_init__(self):
        self.buf = defaultdict(deque)
        self.seen = defaultdict(int)
        self.risk_mass = 0.0

    def observe(self, x, cert_pattern):
        s = self.strata(x, cert_pattern)
        if s not in self.buf:
            self.risk_mass += self.risk(s)
        self.seen[s] += 1
        cap_s = self._alloc(s)
        b = self.buf[s]
        if len(b) < cap_s:
            b.append(x)
        elif random.random() < cap_s / self.seen[s]:   # 风险加权蓄水池替换
            b[random.randrange(len(b))] = x

    def _alloc(self, s):
        # n_s = M · r_s / Σ_t r_t   （风险比例，而非频率比例）
        return max(1, int(self.capacity * self.risk(s) / (self.risk_mass + 1e-9)))

    def sample_risk_stratified(self, n):
        strata = list(self.buf.keys())
        w = np.array([self.risk(s) for s in strata], dtype=float)
        w /= w.sum()
        out = []
        for s in np.random.choice(strata, size=n, p=w):
            b = self.buf[s]
            out.append(b[random.randrange(len(b))])
        return out
```

**与常规回放的差别**：常规 ER/均匀蓄水池按频率分配配额，长尾安全分层 p_s → 0 时 n_s → 0，最危险的状态被最先遗忘；ECRR 按风险 r_s 分配，使安全加权遗忘在所有分层上等化（引理 33）。

### IP-480 Certificate Drift & Staleness Monitor (CDSM)

```python
@dataclass
class CertificateDriftStalenessMonitor:
    """CDSM：估计证书可靠度（元证书），低于下限则冻结并重认证"""
    probe: LabeledProbeSet            # {(x_i, m*_i)}，m*_i 为真值安全裕度
    soundness_floor: float = 0.95
    delta: float = 0.01               # Hoeffding 置信参数

    def estimate_soundness(self, theta, evaluator) -> float:
        passed = false_pass = 0
        for x, m_star in self.probe:
            if evaluator.all_pass(theta, x):
                passed += 1
                if m_star < 0:            # 证书通过但实际不安全
                    false_pass += 1
        return 1.0 if passed == 0 else 1.0 - false_pass / passed

    def check(self, theta, evaluator):
        n = len(self.probe)
        s_hat = self.estimate_soundness(theta, evaluator)
        s_lcb = s_hat - np.sqrt(np.log(1.0 / self.delta) / (2.0 * n))
        if s_lcb < self.soundness_floor:
            return RecertAction.FREEZE_AND_RECERTIFY
        return RecertAction.NONE

    def drift(self, state) -> float:
        """输入分布漂移的轻量代理：见证特征空间 MMD / 马氏距离"""
        return self._mmd_to_reference(state)
```

### IP-481 Federated Certificate-Safe Distillation (FCSD)

```python
@dataclass
class FederatedCertificateSafeDistillation:
    """FCSD：只共享低秩证书安全增量；服务端全局见证集复核"""
    rank: int = 8
    dp_sigma: float = 0.05

    def local_delta(self, theta_before, theta_after):
        D = theta_after - theta_before
        U, S, Vt = np.linalg.svd(D, full_matrices=False)
        return (U[:, :self.rank] * S[:self.rank]) @ Vt[:self.rank]

    def aggregate(self, deltas, theta_global, global_witness, evaluator):
        D_bar = np.mean(deltas, axis=0)
        D_bar += np.random.normal(0, self.dp_sigma, D_bar.shape)
        theta_cand = theta_global + D_bar
        if global_witness.margin(theta_cand, evaluator) < 0:
            return theta_global, FedStatus.REJECTED     # 拒绝不安全聚合
        return theta_cand, FedStatus.ACCEPTED
```

### IP-482 Edge Compute-Aware Update Scheduler (ECUS)

```python
@dataclass
class EdgeComputeAwareUpdateScheduler:
    """ECUS：预算约束下决定是否/何时更新；裕度不足优先冻结"""
    V_lyap: float = 1.0
    flops_budget: float = 2e9          # 每窗口
    energy_budget: float = 5.0

    def decide(self, drift_est, cert_margin, flops_left,
               energy_left, queue) -> ScheduleAction:
        if cert_margin < 0.10:
            return ScheduleAction.FREEZE                 # 裕度不足先冻结
        if flops_left <= 0 or energy_left <= 0:
            return ScheduleAction.DEFER
        cost = self._cost(flops_left, energy_left)
        score = self.V_lyap * drift_est - queue * cost   # drift-plus-penalty 贪心
        return ScheduleAction.UPDATE if score > 0 else ScheduleAction.DEFER
```

### C3L 单步执行流（控制 + 低频学习解耦）

```python
def c3l_step(theta, state, sensor, replay, learner, monitor, scheduler, budget):
    # 0) 运行时准入不变：仍走 CADVS 十二证聚合
    cert_agg = wait_for_topic('/cert/aggregated', timeout=0.005)
    if cert_agg is None or not cert_agg.all_passed:
        return fallback_to_teacher(state, sensor, reason='cert_agg_fail')

    # 1) 常规控制（学生 + 视觉伺服叠加 / 教师兜底）
    out = cadvs_step(state, sensor)

    # 2) 低频持续学习（异步，不影响控制周期）
    action = scheduler.decide(
        drift_est=monitor.drift(state),
        cert_margin=learner.margin(theta),
        flops_left=budget.flops_left,
        energy_left=budget.energy_left,
        queue=budget.queue,
    )
    if action == ScheduleAction.UPDATE:
        theta_next, status, r = learner.update(theta, batch_new=collect_recent(), replay=replay)
        if status == UpdateStatus.ACCEPTED and \
           monitor.check(theta_next, learner.evaluator) == RecertAction.NONE:
            theta = theta_next
    replay.observe(state, cert_agg.pattern)
    return out, theta
```

## 4. 正确性论证（增量更新）

### 引理 32（证书信任域更新的安全性保持）

**陈述**：设 m_j(θ,x) 在 θ 上对任意 (j,x) 均为 L_m-Lipschitz，则 M_S(θ)=min_{x∈S_cert} min_j m_j(θ,x) 亦为 L_m-Lipschitz。若第 k 步更新 Δθ_k 满足 ‖Δθ_k‖ ≤ r_k=(M_S(θ_k)−ε)/L_m，则 M_S(θ_k+Δθ_k) ≥ ε。

**证明**：有限个 L_m-Lipschitz 函数的下确仍为 L_m-Lipschitz：|M_S(θ)−M_S(θ')| ≤ max_{x,j}|m_j(θ,x)−m_j(θ',x)| ≤ L_m‖θ−θ'‖。故 M_S(θ_k+Δθ_k) ≥ M_S(θ_k) − L_m‖Δθ_k‖ ≥ M_S(θ_k) − (M_S(θ_k)−ε) = ε。∎

**工程含义**：学习步长不是超参数，而是由剩余证书裕度**导出**的量。裕度越紧，步长越小；裕度耗尽则 r_k=0，学习冻结。这把「持续学习」纳入「证书包容」而非与之竞争。

### 引理 33（风险比例回放的安全加权遗忘界）

**陈述**：设分层 s=1..S，部署频率 p_s、安全关键度 r_s，回放容量 M，分层 s 的配额 n_s。在每步遗忘与 1/n_s 成正比的模型下（线性/Rademacher 界），安全加权最坏遗忘 F_safe = max_s r_s F_s。则：(i) 风险比例配额 n_s ∝ r_s 时，F_safe ≤ C·Σ_t r_t / M，与 p_s 无关；(ii) 频率比例配额 n_s = M p_s 时，F_safe = C·max_s r_s/(M p_s)，当存在 p_s→0 的长尾分层时无界。

**证明**：设 F_s ≤ C/n_s。(i) 取 n_s = M r_s/Σ_t r_t，则 r_s F_s ≤ C r_s/n_s = C Σ_t r_t/M，对所有 s 一致。(ii) 取 n_s=M p_s，则 r_s F_s = C r_s/(M p_s)，对任意固定 r_s>0，当 p_s→0 时发散。∎

**工程含义**：均匀/频率比例回放对「平均任务性能」够用，但对「长尾安全」有结构性缺陷——最致命的状态恰恰最少出现。ECRR 的风险比例配额是引理 33(i) 的直接实现。

### 引理 34（证书可靠度估计的样本复杂度）

**陈述**：若探针集 Probe 独立同分布于 D_cert，规模 N_p，真实可靠度 S_sound，经验估计 Ŝ_sound，则对任意 δ∈(0,1)，以概率 ≥ 1−δ 有 S_sound ≥ Ŝ_sound − sqrt(ln(1/δ)/(2N_p))。要保证可靠度不低于 S_0 的检出功效，需 N_p ≥ ln(1/δ)/(2(S_0−S_hat)²)。

**证明**：Ŝ_sound 是 N_p 个独立 Bernoulli 指示的均值，由 Hoeffding 不等式 P(Ŝ−S ≥ t) ≤ exp(−2N_p t²)，令 t=sqrt(ln(1/δ)/(2N_p)) 即得。∎

**诚实声明**：引理 34 的保证**强依赖探针集代表性**。边缘持续学习中 D_cert 本身在漂移、探针集受内存限制无法重采样，此时 Hoeffding 界仍成立但估计的是「探针分布上的可靠度」而非「部署分布上的可靠度」——这正是本轮最大风险的数学根源（见 §6）。

### 定理（C3L 执行集收缩、持续安全与适应滞后）

**陈述**：在以下假设下：
(A1) 每步更新落在证书信任域内（引理 32，M_S(θ_k) ≥ ε）；
(A2) 每次接受更新前，CDSM 以置信 1−δ_s 验证评估器可靠度 S_sound ≥ S_0（引理 34）；
(A3) 运行时准入沿用 CADVS 十二证，未因持续学习而放宽；
(A4) 回放采用风险比例配额（引理 33(i)）。
则：(i) Exec_C3L ⊆ Exec_CADVS ⊆ Exec_v29；(ii) 单步安全违规概率 ≤ δ_s + δ_stat，δ_stat 为证书统计失效概率；(iii) 累积安全加权遗忘 ≤ K·C·Σ_t r_t/M；(iv) 对漂移速率 ρ_drift 的适应滞后 ≤ ρ_drift·(1+O(1/V_lyap))（ECUS 的 drift-plus-penalty 权衡）。

**证明**：
- (i) 运行时准入逻辑逐字复用 CADVS（A3），持续学习只改变 θ 而不改变准入判据，故任何被执行的 (u,x) 仍须通过同一组证书，执行集只可能收缩。
- (ii) 违规只能来自两类：评估器不可靠（A2 以 δ_s 排除）或证书本身的统计失效（δ_stat）；由联合界得 δ_s+δ_stat。
- (iii) 由引理 33(i) 对每步求和。
- (iv) ECUS 的贪心 drift-plus-penalty 是标准 Lyapunov 框架的近似，队列稳定性与惩罚的 O(1/V_lyap) 折衷给出滞后界。∎

**诚实声明**：(A1) 的 L_m 是估计值，实际网络可能存在局部 Lipschitz 尖峰；(A2) 的探针代表性在分布漂移下不成立；(A3) 的评估器校准会随 θ 漂移（元证书问题）；(A4) 的 r_s 依赖人工安全先验。C3L 通过「事后审计 + 冻结重认证 + 风险分层」管理这些风险，但**不能消除元证书崩塌**。

## 6. 本轮最大风险（最终确认）

**一句话**：**元证书崩塌**——持续学习同时移动了策略、输入分布与评估器校准，而边缘内存约束使可靠度探针集无法保持代表性，于是「证书通过 ⇒ 安全」这一元命题在无人察觉中失效；此时十二证全部显示绿灯，系统表现完全正常，但绿灯已不再蕴含安全，这是整个证书驱动持续学习框架最深、也最不可自检的失败模式。
