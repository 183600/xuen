# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因闭环」IP-214~223；灵感循环第 1 轮；本轮灵感：「最优控制」×「ROS2」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险同样尖锐：归因依赖「故障属于有限假设集、且视觉与几何的失效相互独立」；一旦遇到未知复合故障或共因失效（透明/镜面/对抗 patch 同时骗过视觉与几何），FIR 会把未知故障强行塞进最近假设、只膨胀错误的球，而系统会因为「已经归因」而更自信地继续执行。本轮不换模态，而是换提问视角：第 65 轮问「谁坏了」，本轮问「**在这个信念下，我到底该探测多少、承诺多远、以及这份证书还能信多久**」。核心命题是：
>
> **把 VISTA 的「判定—归因—前缀」从三段启发式流水线，重写为一个带时间有效期的、风险敏感的最优控制问题：状态是（物理状态 × 故障信念 × 时序健康），安全由可达性/不变集而非点归因保证，探测是控制的一部分（对偶控制），而 ROS2 的生命周期/QoS/实时执行把「证书新鲜度」变成可被约束的物理量。**

## 0. 直觉与动机

**灵感 1（最优控制 → 探测、承诺、膨胀本是同一个 Bellman 备份）**
直觉：VISTA 里有三个各自为政的旋钮——AFA 选探针、CSC 选前缀 k*、RSC 选膨胀哪个球。但它们其实强耦合：愿不愿意探测，取决于还能安全承诺多远；能承诺多远，取决于故障信念有多集中；信念多集中，又取决于刚刚探测到了什么。这正是随机最优控制里的**对偶效应（dual effect, Feldbaum）**：控制既改变状态也改变信息。所以正确的对象不是「先归因再执行」，而是在**增广状态 (x, b, τ)** 上的**信念空间最优控制**：探针与执行是同一个 Bellman 备份的两条分支，k* 是一个**最优停止时刻**，膨胀球是该信念下**可达集**的半径。三段启发式被一个目标函数统一，且天然允许「为了未来安全而当下多探一次」这类跨期权衡。

**灵感 2（最优控制 → 用可达性/不变集替掉「点归因 + conformal 球」）**
直觉：VISTA 的安全论证依赖「归因正确 → 膨胀对的球」，可一旦归因错误（第 65 轮最大风险），安全边界就塌了。最优控制给了一个更强的结构：不要去猜「哪个球」，而是求在**整个可能故障集合**上的**最大受控不变集 / 生存核（viability kernel）** Ω(b)。集合对「候选故障集」是**单调**的：候选集越大，Ω 只会越小。于是未知故障或共因失效只会让安全域收缩（更保守），**永远不会把不安全误放行**——这正是把「点归因」换成「集合鲁棒」的关键收益。conformal 球只是 Ω 的一个粗糙外近似，且它把「未知」漏掉了。

**灵感 3（ROS2 → 证书是有保质期的租约，不是一次性判定）**
直觉：VISTA 默认证书是「瞬时且永远新鲜」的，但真实机器人上，故障后验、证书、控制指令都是经 DDS 传输的消息，有延迟、抖动、丢包、乱序和时钟偏移。**一个过期的故障后验本身就是一种故障。** ROS2 提供了把这个直觉工程化的词汇：生命周期节点给出安全的模式切换（unconfigured→inactive→active→finalized）；QoS 的 deadline / lifespan / liveliness / durability 把「新鲜度」写成合同；executor 与 callback group 给出确定性调度；ros2_control 给出实时控制环；intra-process 零拷贝省预算。于是证书变成一枚**租约（lease）**：带 TTL、到期不续就必须降级；时序违约成为一个显式的故障假设 H_time，进入最优控制的状态与代价。

**灵感 4（两灵感合流 → OCTAVE：Optimal Control with Temporal Attribution and Viability Enforcement）**
闭环：VISTA 的签名/归因产出**故障信念** b（含未知质量 b_⊥）→ 时序健康 τ（证书年龄/执行延迟/时钟偏移/抖动）→ 在 z=(x,b,τ) 上解**风险敏感信念空间最优控制**（belief-MDP / CVaR）→ 输出「探还是不探、探哪个、承诺 k* 步、在哪个不变集里」→ ROS2 生命周期监督器把「证书过期 / 时序违约 / viability 失败」映射为安全模式，QoS 合同与确定性 executor 负责让建模假设成立 → 回写信念与时序。第 65 轮是「几何-技能-干扰-接触-归因」五层证书，OCTAVE 加的是**第六层：时间与建模有效性本身**。

**灵感 5（VISTA 组件的原位升级）**
- **FIR → FIR-O（开放世界归因）**：假设集增 H_time（时序违约）、H_unknown（未知质量 b_⊥）；不再强行 argmax，而是保留完整信念，把未知质量交给鲁棒不变集处理。
- **AFA → DC（对偶控制）**：探针从「最大化故障互信息」升级为「最大化信念空间最优控制的价值差 VoI」，与执行统一在同一 Bellman 备份里。
- **CSC → DACSC（deadline-aware）**：k* 同时受不可逆视界 m 与时间预算（TTL−d_replan）约束；做不到就 k*=0 进安全模式。
- **RSC-V → RSC-O**：不再只维护三个球，而维护一个**信念参数化的不变集** Ω(b)；球的膨胀只是 Ω 半径的下界代理。
- **WCV-V → WCV-O**：搜索域用 Ω(b) 交物理/视觉约束，CVaR 尾部对信念 b 采样。
- **CSP-V → CSP-O**：块边需 z∈Ω，并把「续租证书」作为显式元动作。
- **OLP → OLP-O**：在线学习只在语义流；时序健康作为特征，禁止写实时环。
- **AIC-V → AIC-R**：干扰集增 DDS 延迟尾/executor 抖动/时钟跳变/消息丢序/节点崩溃，并做**时序对抗认证**。
- **J_vista → J_octave**：证书增 viability_margin、b_⊥、cert_age/deadline_margin、time_health、lifecycle_state、qos_contract_hash。

## 1. 形式化定义（增量：定义 233–249）

- **定义 233（OCTAVE 闭环）**：OCTAVE = (VISTA, BAM, RS-BMDP, DC, VIAB, TCL, RLC, QDE, TSS, DACSC, AIC-R, J_octave)。定位：VISTA 的「时间有效性与集合鲁棒」升级。不变式：**最优控制求解、可达集计算、信念更新只在语义流；实时流只做信念增量采集、租约校验、确定性执行与安全模式切换，零学习写操作。**
- **定义 234（增广状态）**：z_t=(x_t,b_t,τ_t) ∈ 𝒳 × Δ(ℋ∪{⊥}) × 𝒯。x_t 为物理状态，b_t 为故障信念（单纯形上，含未知质量 b_⊥），τ_t=(a_cert,d_exec,δ_clock,jitter) 为时序健康。真实动力学 x_{t+1}=f(x_t,u_t,w_t;h_t)，h_t 为真实故障；信念更新 b_{t+1}=β(b_t,o_{t+1},u_t)。
- **定义 235（开放世界信念与未知质量）**：b_⊥=1−Σ_{h∈ℋ}b(h) 显式保留，按逃逸先验（Dirichlet 过程/新颖性分数）更新。任何 h∈ℋ 的后验被 b_⊥ 稀释；b_⊥>δ_open 时禁止点归因，只能走集合鲁棒。这是对第 65 轮「强行归入最近假设」的直接反制。
- **定义 236（风险敏感信念空间最优控制 RS-BMDP）**：求解 π*:𝒵→𝒰
  π* = argmin_π E_π[ Σ_t γ^t ( c_task(x_t,u_t) + λ_d·damage(z_t,u_t) + λ_s·s(τ_t) ) ]，s.t. CVaR_α(总代价) ≤ ρ_bar，
  其中 s(τ)=a_cert/TTL+max(0,d_exec−D)/D 为陈旧度。目标同时含任务代价、不可逆伤害、陈旧度；约束用 CVaR 控尾部风险，而非 minimax（避免共因故障下过度保守到不可用）。
- **定义 237（对偶控制与信息价值 VoI）**：对候选动作 u（含物理探针与 null_test），
  VoI(z,u) = E_{o'}[ V*(β(b,o',u), τ') ] − V*(b,τ)（在 u 执行后的状态上评估）。
  最优策略 u*=argmin_u { Q_task(z,u) − λ_i·VoI(z,u) }。AFA 是 VoI 的一步贪心特例；CSC 的 k* 由「继续承诺」对「现在停」的 Bellman 差分决定。探针不再与执行分离：**当且仅当信息价值超过其风险时才探**。
- **定义 238（认证前缀作为最优停止）**：把「继续执行到第 k 步」看成停止问题，停时 τ_stop∈{1,…,H}。认证前缀
  k* = ess sup{ k ≤ min(H,m) : E[继续代价 | F_k] ≤ E[停并重规划代价 | F_k] }，
  即 Snell 包络首次低于持续价值之处；同时硬约束 D_exec(k)+d_replan ≤ TTL（定义 242/247）。
- **定义 239（信念参数化不变集 / 生存核）**：给定信念 b，可容许故障集
  ℋ_b = { h∈ℋ : b(h) ≥ δ_viab } ∪ ( b_⊥ > δ_open ? {⊥ bounded-by-worst-case-model} : ∅ )。
  Ω(b) 为从其中存在策略使 z 对所有 h∈ℋ_b 保持安全的最大受控不变集。Ω 对 ℋ_b 单调不增：ℋ_b 变大 ⇒ Ω 变小。**误归因只会让 Ω 收缩，不会扩张。**
- **定义 240（viability 证书）**：viability_margin(z)=dist(z,∂Ω(b))；Valid_viab ⇔ z∈Ω(b) ∧ margin ≥ ε_viab。用 Ω 取代第 65 轮的 B(φ̂,r) 作为安全域，球只作为 Ω 的一个可计算外近似。
- **定义 241（时序健康与陈旧度）**：τ=(a_cert,d_exec,δ_clock,jitter)。证书年龄 a_cert=t_now−t_issued；执行延迟 d_exec 为指令入队到执行的尾延迟；δ_clock 为节点间时钟偏移；jitter 为 executor 调度抖动。陈旧度 s(τ) 进入代价（定义 236），并在超过 TTL 时触发失效（定义 242）。
- **定义 242（证书租约 TCL）**：证书 = Lease{J_octave, issued_at, TTL, deadline D, lifespan L, durability=TRANSIENT_LOCAL, liveliness=AUTOMATIC(lease)}。Valid_lease ⇔ a_cert≤TTL ∧ 近 deadline 内已收到续租 ∧ pancake 未丢失。续租是一个显式控制动作；**超时未续 ⇒ 证书失效 ⇒ 生命周期降级**。
- **定义 243（ROS2 生命周期安全监督器 RLC）**：把模式映射到 lifecycle：ACTIVE=正常执行；INACTIVE=合规撤退/compliant retreat（保持接触但不推进）；UNCONFIGURED=安全待机（safe_idle）；FINALIZED=急停。转移触发：Valid_lease∧Valid_viab 保持 ACTIVE；任一失效 → INACTIVE；连续 N 次续租失败或时钟失步 → UNCONFIGURED/FINALIZED。转移须在 deadline 内完成且可审计。
- **定义 244（QoS 合同）**：实时安全通道：reliability=RELIABLE、deadline=D_pub、lifespan=L、liveliness=AUTOMATIC(lease)、history=KEEP_LAST(depth)、durability 证书类=TRANSIENT_LOCAL、其余=VOLATILE。**deadline miss 与 liveliness 丢失被定义为故障（H_time），计入 τ 与信念更新**，而非静默重试。
- **定义 245（确定性 executor 与 callback group）**：实时控制链放在专用 executor 的 MutuallyExclusiveCallbackGroup（单线程、固定优先级、禁止动态分配），语义流放独立 ReentrantCallbackGroup；大张量走 intra-process 零拷贝。实时环最坏回调延迟上界
  WCRT = Σ_{高优先级回调} C_i + DDS_tail，须 ≤ deadline D，否则建模假设（定义 239）不成立，判 H_time。
- **定义 246（时间同步签名 TSS 与 H_time）**：所有残差携带 ROS 时间戳；节点间时钟偏移 δ_clock 由有界同步（如 PTP/ROS time + 漂移界）保证。若 |δ_clock|>δ_max、消息乱序或块时序错位 → H_time。签名增加 τ 维度：ρ_time=[a_cert,d_exec,δ_clock,jitter]。
- **定义 247（deadline-aware 认证前缀 DACSC）**：k* = max{ k ≤ min(H,m) : (定义 238 停止条件成立) ∧ D_exec(k)+d_replan ≤ TTL }。若集合为空 → k*=0，转 INACTIVE。这把「长预测、短执行」从几何安全延伸到**时间安全**。
- **定义 248（AIC-R 时序/对抗认证）**：干扰集 ℰ_R=ℰ_V×ℰ_dds×ℰ_sched×ℰ_clock，ℰ_dds 含延迟尾/丢包/乱序，ℰ_sched 含 executor 抖动/优先级反转，ℰ_clock 含跳变/漂移。在最坏时序下重算 viability_margin 与 k*；**共因故障与不可调度性下不要求最优，只要求能被判 invalid 并安全降级。**
- **定义 249（OCTAVE 证书 J_octave）**：J_octave=(J_vista, viability_margin, b_⊥, cert_age, deadline_margin, time_health, lifecycle_state, qos_contract_hash, aic_r_ver)。Valid(J_octave) ⇔ Valid(J_vista) ∧ z∈Ω(b) ∧ Valid_lease ∧ WCRT≤D ∧ b_⊥ 已显式标注且未用于点归因 ∧ aic_r_ver 为当前版本。

## 2. 关键算法骨架

```python
# RS-BMDP：信念空间风险敏感最优控制（语义流）
z = (x, b, tau)
V = solve_belief_mdp(z, horizon=H_sem, risk='CVaR', alpha=ALPHA)
u_plan = argmin_u { Q_task(z, u) - LAMBDA_I * VoI(z, u) }   # 对偶控制：探/执行统一
if b['unknown'] > DELTA_OPEN or entropy(b) > H_MAX:
    u_plan = 'conservative'                                  # 禁止点归因，走集合鲁棒
Omega = viability_kernel(admissible_faults(b), x, tau)       # 集合，不是球
k_star = stopping_prefix(u_plan, b, m, TTL, d_replan)        # 最优停止 + 时间预算

# 证书租约（ROS2 生命周期 + QoS）
lease = acquire_lease(J_octave, TTL=TTL, deadline=D, durability=TRANSIENT_LOCAL)
if age(lease) > TTL or deadline_missed():
    lifecycle.transition('INACTIVE')                         # 合规撤退
if not (x in Omega and margin(x, Omega) >= EPS_VIAB):
    lifecycle.transition('UNCONFIGURED')                     # safe_idle

# 实时链：确定性执行（ros2_control / callback group）
for a in u_plan[:k_star]:
    dispatch_realtime(a)                                     # MutuallyExclusive group
    if residual_cusum_exceeded() or clock_skew() > DELTA_MAX:
        lifecycle.transition('INACTIVE'); break

# 信念回写（仅语义流）
b = belief_update(b, residuals, u_plan[:k])
lease.renew(J_octave) if still_valid(z, b, tau) else lease.invalidate()
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（不变集对故障集合单调）**：若 ℋ₁⊆ℋ₂，则 Ω(ℋ₂)⊆Ω(ℋ₁)。故信念扩张（含 b_⊥ 上升、共因故障）只会缩小安全域；**误归因的后果是更保守，而不是误放行**。这从结构上消解第 65 轮「只膨胀错误的球」的灾难。
- **引理 10（对偶控制不产生无谓探测）**：VoI(z,u)≥0 且当 u 与信息无关时 VoI=0；在 b_⊥<δ_open 且 max_h b(h)≥1−δ_fi 时，最优策略的探针分支被 `λ_i·VoI < 探测风险` 支配而关闭。故 AFA 的「无条件探」被自动收敛为「按信息价值探」。
- **定理 9（OCTAVE 对共因/未知故障的鲁棒安全）**：在 A94–A97 下，若 z_t∈Ω(b_t) 且租约与时序合同成立，则对任意 h∈ℋ_{b_t}（含未知的 worst-case 模型）执行 k* 步后仍安全；误归因只会使 ℋ_b 偏大、Ω 偏小。证书链从「归因正确」升级为「归因错误也安全」。
- **定理 10（时间感知的前缀安全）**：若 D_exec(k*)+d_replan≤TTL、k*≤m、WCRT≤D，则单块内因「执行了陈旧信念/过期证书」导致的越界概率 ≤ α_chunk+δ_viab+P(deadline miss)+P(时钟失步)。故时间违约不再能绕过安全证书。
- **实时性**：最优控制求解、viability、信念更新全在语义流；实时流只增租约校验（<0.02ms）、时钟检查（<0.01ms）、确定性派发，目标 ≤2.0ms，且 WCRT 可静态分析（A94–A97）。

## 5. 本轮最大风险

**一句话**：OCTAVE 的安全论证把赌注押在「可达集/不变集与时间上界能在真实平台上被准确标定」这一假设上；一旦扰动集、故障集合或抖动/延迟尾部被低估，风险敏感最优控制会**精确地优化一个错误的模型**，而 ROS2 的 QoS 合同与生命周期反而给出「有形式保证」的错觉——**用最优性与实时性包装了建模误差与不可调度性**。这是本轮全部 viability 与时序安全论证共同依赖的隐藏假设（A94）。

## 2. 形式化定义（完整版）

**定义 233（OCTAVE 闭环）** OCTAVE 是 VISTA 的「时间有效性 + 集合鲁棒」升级：在 VISTA 的五层（几何-技能-干扰-接触-归因）之上加第六层「时间与建模有效性本身」。组成 BAM（增广状态与开放世界信念）、RS-BMDP（风险敏感信念空间最优控制）、DC（对偶控制探针）、VIAB（信念参数化不变集）、TCL（证书租约）、RLC（ROS2 生命周期监督）、QDE（确定性 executor）、TSS（时间同步签名）、DACSC（deadline-aware 前缀）、AIC-R（时序对抗认证）、J_octave。不变式：**最优控制求解、可达集计算、信念更新只在语义流；实时流只做信念增量采集、租约校验、确定性执行与安全模式切换，零学习写操作。**

**定义 234（增广状态）** z_t=(x_t,b_t,τ_t)∈𝒳×Δ(ℋ∪{⊥})×𝒯。真实动力学 x_{t+1}=f(x_t,u_t,w_t;h_t)，h_t 为真实故障；信念更新 b_{t+1}=β(b_t,o_{t+1},u_t)；观测 o 含力/视觉/触觉残差与时序量。τ_t=(a_cert,d_exec,δ_clock,jitter)。相比 VISTA 只维护物理状态与「归因后验」，OCTAVE 把信念与时间都提升为一等状态。

**定义 235（开放世界信念与未知质量）** 保留 b_⊥=1−Σ_{h∈ℋ}b(h)，用逃逸先验更新：
- 新颖性分数 ν(o)=min_{h∈ℋ} d(o,𝒪_h)（到各假设观测分布的距离）；
- b_⊥ ← softmax-like 更新，ν 越大 b_⊥ 越大。
当 b_⊥>δ_open 时，**禁止点归因**（不允许 argmax 后只膨胀一个球），只能走定义 239 的集合鲁棒路径。这是对第 65 轮「未知故障被强行塞入最近假设」的结构性反制。

**定义 236（风险敏感信念空间最优控制 RS-BMDP）**
π* = argmin_π E_π[ Σ_t γ^t ( c_task(x_t,u_t) + λ_d·damage(z_t,u_t) + λ_s·s(τ_t) ) ]，s.t. CVaR_α(总代价) ≤ ρ_bar。
与期望最优相比，CVaR 关注尾部（共因故障、未知故障、时序违约），与 minimax 相比不至于在信念本已保守时过度收缩到不可用。求解用信念-MDP 点近似 + 风险敏感值迭代（语义流，≤50ms）。

**定义 237（对偶控制与信息价值 VoI）** 对候选动作 u∈𝒰（含 press/rub/tap/lift/visual_probe/null_test 与「直接执行」）：
VoI(z,u)=E_{o'}[V*(β(b,o',u),τ')]−V*(b,τ)。
选择 u*=argmin_u { Q_task(z,u) − λ_i·VoI(z,u) }。AFA 是 VoI 的一步贪心；CSC 的 k* 是「继续」与「现在停」的价值差分（定义 238）。当 b_⊥ 小且 max_h b≥1−δ_fi 时，VoI 项被探测风险支配，自动关闭探针——**探测不再是无条件动作，而是有价的投资**。

**定义 238（认证前缀作为最优停止）** 停时 τ_stop∈{1,…,H}，历史流 F_k。认证前缀
k* = ess sup{ k≤min(H,m) : E[继续代价|F_k] ≤ E[停并重规划代价|F_k] }，
即 Snell 包络首次低于持续价值之处。它对 VISTA 的「贪心最大 k」给出严格改进：一旦继续的边际风险超过重规划代价即停。

**定义 239（信念参数化不变集 / 生存核）** 给定 b，
ℋ_b={h∈ℋ:b(h)≥δ_viab} ∪ (b_⊥>δ_open ? {⊥（worst-case bounded model）}:∅)。
Ω(b) 为存在策略使 z 对所有 h∈ℋ_b 保持安全（x∈𝒳_safe∧力/滑移/几何裕度≥0）的最大受控不变集，由 Hamilton-Jacobi 可达性或其离散近似计算。**单调性**：ℋ_b 增大 ⇒ Ω(b) 减小。故误归因、共因失效、未知故障只会让安全域更小。

**定义 240（viability 证书）** viability_margin(z)=dist(z,∂Ω(b))。Valid_viab ⇔ z∈Ω(b) ∧ margin≥ε_viab。第 65 轮的 B(φ̂,r) 在本轮作为 Ω 的可计算外近似：**B⊇Ω 时用 Ω，B⊉Ω 时收缩 r 直到包含 Ω 的近似**。证书依据从「点归因的球」换成「集合的生存核」。

**定义 241（时序健康与陈旧度）** τ=(a_cert,d_exec,δ_clock,jitter)。a_cert=t_now−t_issued（证书年龄）；d_exec 为指令入队到执行的尾延迟；δ_clock 为节点间时钟偏移；jitter 为 executor 调度抖动。陈旧度 s(τ)=a_cert/TTL+max(0,d_exec−D)/D 进入代价（定义 236），超过 TTL 直接使租约失效（定义 242）。

**定义 242（证书租约 TCL）** 证书 = Lease{payload=J_octave, issued_at, TTL, deadline D, lifespan L, durability=TRANSIENT_LOCAL, liveliness=AUTOMATIC(lease)}。Valid_lease ⇔ a_cert≤TTL ∧ 截止前已收到续租 ∧ 无丢失。续租是显式控制动作（IPC 消息），失败序列触发 RLC（定义 243）。**过期后验不得被执行**——这是对第 65 轮「陈旧信念仍作为真值」的修复。

**定义 243（ROS2 生命周期安全监督器 RLC）** 状态映射：
- ACTIVE：Valid_lease ∧ Valid_viab ∧ WCRT≤D；
- INACTIVE（compliant retreat）：租约临近到期或残差异常，保持接触但不推进；
- UNCONFIGURED（safe_idle）：viability 失败或连续续租失败；
- FINALIZED（急停）：时钟失步或节点崩溃。
所有转移须在 deadline 内完成、可审计（日志含触发原因与时间戳），并与 ros2_control 的控制器切换原子化。

**定义 244（QoS 合同）** 实时安全通道：reliability=RELIABLE、deadline=D、lifespan=L、liveliness=AUTOMATIC(lease)、history=KEEP_LAST(depth)、证书 durability=TRANSIENT_LOCAL、其余 VOLATILE。**deadline miss 与 liveliness 丢失被定义为故障 H_time**，写入 τ 与信念，而非静默重试。QoS 合同哈希写入 J_octave，防止「运行期偷改 QoS 绕过证明」。

**定义 245（确定性 executor 与 callback group）** 实时控制链放专用 executor 的 MutuallyExclusiveCallbackGroup（单线程、固定优先级、禁止动态分配/syscall）；语义流放独立 ReentrantCallbackGroup；大张量走 intra-process 零拷贝。实时环最坏响应时间
WCRT=Σ_{高优先级回调} C_i + DDS_tail + 阻塞项，
须 ≤D；否则不变集假设（定义 239）不成立，判 H_time 并降级。

**定义 246（时间同步签名 TSS 与 H_time）** 所有残差携带 ROS 时间戳；节点间时钟偏移 δ_clock 由有界同步（PTP/ROS time + 漂移界）保证。若 |δ_clock|>δ_max、消息乱序或块时序错位 → H_time。签名增时序维度 ρ_time=[a_cert,d_exec,δ_clock,jitter]，FIR-O 的似然 p(ρ|H_time) 离线由时序注入标定。

**定义 247（deadline-aware 认证前缀 DACSC）** k* = max{ k≤min(H,m) : (定义 238 停止条件成立) ∧ D_exec(k)+d_replan ≤ TTL }。若集合为空 → k*=0，转 INACTIVE。把「长预测、短执行」从几何安全延伸到**时间安全**：即使几何/力都安全，来不及重规划的承诺也不认证。

**定义 248（AIC-R 时序/对抗认证）** 干扰集 ℰ_R=ℰ_V×ℰ_dds×ℰ_sched×ℰ_clock。ℰ_dds 含延迟尾/丢包/乱序；ℰ_sched 含 executor 抖动/优先级反转；ℰ_clock 含跳变/漂移；并保留 ℰ_common 共因故障。在最坏时序与最坏故障下重算 viability_margin 与 k*；**共因故障与不可调度性下不要求最优，只要求能被判 invalid 并安全降级。**

**定义 249（OCTAVE 证书 J_octave）** J_octave=(J_vista, viability_margin, b_⊥, cert_age, deadline_margin, time_health, lifecycle_state, qos_contract_hash, aic_r_ver)。验证：
Valid(J_octave) ⇔ Valid(J_vista) ∧ z∈Ω(b) ∧ Valid_lease ∧ WCRT≤D ∧ (b_⊥ 已显式标注且未用于点归因) ∧ aic_r_ver 为当前版本。
审计链新增：为何此刻安全（viability_margin）、信念有多开放（b_⊥）、证书还剩多久（cert_age/deadline_margin）、时序是否可信（time_health）、处于哪个安全模式（lifecycle_state）。

### IP-224 BAM + IP-235 开放世界信念

```python
class BeliefAugmentedModel:
    """增广状态 (x, b, tau)，b 含未知质量 b_unknown。语义流。"""
    def __init__(self, hyp, delta_open=0.2, delta_viab=0.05):
        self.hyp, self.delta_open, self.delta_viab = hyp, delta_open, delta_viab

    def update_belief(self, b, obs, u):
        scores = {h: self._loglik(h, obs) for h in self.hyp}
        novelty = min(self._dist(obs, self._obs_dist[h]) for h in self.hyp)
        z = softmax(scores)
        b_new = (1.0 - self._escape(novelty)) * z
        b_new['unknown'] = self._escape(novelty)          # b_perp
        if b_new['unknown'] > self.delta_open:
            b_new['_open_world'] = True                    # 禁止点归因
        return b_new

    def admissible_faults(self, b):
        assert abs(sum(b.values()) - 1.0) < 1e-9
        H = {h for h in self.hyp if b.get(h, 0) >= self.delta_viab}
        if b.get('unknown', 0) > self.delta_open:
            H.add('WORST_CASE_UNKNOWN')
        return H
```

```python
def dual_control_policy(z, horizon=H_SEM, alpha=ALPHA_CVAR):
    x, b, tau = z
    V = risk_sensitive_belief_value(z, horizon, alpha, risk='cvar')
    cands = []
    for u in ACTIONS:                                     # 含物理探针 + 'execute' + 'null_test'
        q = expected_task_cost(z, u)
        voi = expected_value_of_information(z, u, V)      # E[V(z')] - V(z)
        cands.append((u, q - LAMBDA_I * voi))
    u_star, score = min(cands, key=lambda t: t[1])
    return u_star, score, V

def expected_value_of_information(z, u, V):
    b, tau = z[1], z[2]
    total = 0.0
    for o, p in predictive_observation(z, u):             # 对 u 的观测分布
        b2 = belief_update(b, o, u)
        total += p * V((z[0], b2, advance_timing(tau, u)))
    return total - V(z)
```

### IP-227 VIAB（信念参数化不变集）

```python
class ViabilityKernel:
    def __init__(self, dynamics, safe_set, grid):
        self.f, self.S, self.grid = dynamics, safe_set, grid

    def omega(self, b, tau, admissible):
        # HJ 可达性离散近似：最大受控不变集
        Omega = self.S.copy()
        while True:
            pre = self._pre(Omega, admissible, timing_budget=tau)  # 对所有 h∈admissible
            new = Omega & pre
            if new.equals(Omega):
                return Omega
            Omega = new

    def margin(self, z, Omega):
        return signed_distance(z, boundary(Omega))

    def valid(self, z, b, admissible, eps=EPS_VIAB):
        Om = self.omega(b, z[2], admissible)
        return contains(Om, z) and self.margin(z, Om) >= eps
```

### IP-228~232 ROS2 侧（租约 / lifecycle / 确定性 / 时序 / deadline 前缀）

```python
# 证书租约：TTL + deadline + liveliness，过期不得执行
class CertificateLease:
    def __init__(self, ttl, deadline):
        self.ttl, self.deadline = ttl, deadline
        self.issued_at, self.payload = None, None
        self.renewed_at = None

    def acquire(self, J_octave, now):
        self.issued_at, self.renewed_at, self.payload = now, now, J_octave
        return {'lifespan': self.ttl, 'deadline': self.deadline, 'liveliness': 'AUTO'}

    def valid(self, now, wcrt):
        return (self.payload is not None
                and now - self.issued_at <= self.ttl
                and wcrt <= self.deadline)


# ROS2 lifecycle 安全监督器
LIFECYCLE = {'ACTIVE': 3, 'INACTIVE': 2, 'UNCONFIGURED': 1, 'FINALIZED': 0}

class LifecycleSupervisor:
    def step(self, z, b, lease, now, wcrt):
        admissible = BAM.admissible_faults(b)
        if not lease.valid(now, wcrt):
            return 'INACTIVE' if now - lease.issued_at <= lease.ttl + GRACE else 'FINALIZED'
        if not VIAB.valid(z, b, admissible):
            return 'UNCONFIGURED'
        if abs(z.tau.delta_clock) > DELTA_MAX:
            return 'FINALIZED'
        return 'ACTIVE'


# deadline-aware 认证前缀
def dacsc_prefix(u_plan, z, b, m, ttl, d_replan):
    V = risk_sensitive_belief_value(z, len(u_plan), ALPHA_CVAR)
    k_best = 0
    for k in range(1, min(len(u_plan), m) + 1):
        cont = expected_continue_cost(z, u_plan[:k], b, V)
        stop = expected_replan_cost(z, u_plan[:k], b, V)
        if cont > stop:                       # Snell 包络被突破 → 停
            break
        if D_exec(k) + d_replan > ttl:        # 时间预算不允许
            break
        k_best = k
    return k_best
```

```python
def OCTAVE_round(M, obs, now, wcrt):
    x, W_meas, tactile, img, depth, flow, residuals = obs
    # ——— 语义流 ———

        if residual_cusum_exceeded() or abs(M.clock.skew()) > DELTA_MAX:
            M.ros2_control.transition('INACTIVE'); break
    # ——— 语义流收尾 ———
    M.olp_o.online_step(fuse_evidence(x, residuals, b), execution_loss_grad(...))
    M.dir.update(sample_batch_from_history(32))
    rho_r = M.aic_r.certify(u_plan, z, Omega, b)
    return M, M.rc.state, J, rho_r
```

## 4. 推导

**引理 9（最大受控不变集对故障集合单调）** 设 ℋ₁⊆ℋ₂，Ω(ℋ)=最大受控不变集（存在策略使状态对 ℋ 内所有故障保持安全）。若 z∈Ω(ℋ₂)，则存在策略 π 对任意 h∈ℋ₂ 保持安全；因 ℋ₁⊆ℋ₂，该策略亦对 ℋ₁ 保持安全，故 z∈Ω(ℋ₁)。于是 Ω(ℋ₂)⊆Ω(ℋ₁)。∎
**推论**：误归因使 ℋ_b 偏大（多算了一个不存在的故障，或漏算了真实故障而由 b_⊥ 补齐），只会使 Ω 变小；因此 VISTA 的「膨胀错误的球导致误放行」在本轮结构上不可能发生——最坏后果是更保守、任务变慢，而非安全违规。

**引理 10（对偶控制不产生无谓探测）** VoI(z,u)≥0（信息不增加期望最优值，Jensen），且当观测 o 与 u 独立时 VoI=0。选择式 u*=argmin_u Q_task−λ_i·VoI。若 u 为物理探针，其 Q_task 含探测风险 λ_d·damage_probe；当 b_⊥<δ_open 且 max_h b≥1−δ_fi（信念已集中），对任意探针 u_p 有 λ_i·VoI(z,u_p) < λ_d·damage_probe(z,u_p)，故 u_p 不被选中。∎
**推论**：AFA 的「无条件探针」是 λ_i→∞ 的退化情形；OCTAVE 用信息的价格把探测量自动压到「刚好够分清楚」的水平。

**定理 9（OCTAVE 对共因/未知故障的鲁棒安全）** 在 A94–A97（时序合同、WCRT 可分析、逃逸先验有界、CVaR 可解）下，设 z_t∈Ω(b_t) 且 Valid_lease。则对任意 h∈ℋ_{b_t}（含 b_⊥ 对应的 worst-case 有界模型）执行 k* 步后状态仍处于安全集；若归因错误（真实 h*∉supp，b_⊥ 上升），则 ℋ_b 增大、Ω 收缩，执行可能被缩短或降级，但不会越界。证书链从「归因正确才安全」升级为「归因错误也安全，只是更慢」。∎

**定理 10（时间感知的前缀安全）** 设 D_exec(k*)+d_replan≤TTL、k*≤m、WCRT≤D。单块内「执行了陈旧信念/过期证书/时序错位数据」的概率受 P(deadline miss)+P(时钟失步)+P(丢包越界) 控制；由联合界，单块越界概率
P[越界] ≤ α_chunk + δ_viab + P(deadline miss) + P(clock skew) + α_vis。
由于 k* 在定义 247 中被时间预算截断，陈旧数据不可能被承诺超过 TTL。∎

**命题（最优停止不劣于贪心前缀）** 第 65 轮 CSC 取「满足安全的最大 k」。停时问题的 Snell 包络给出 k*_stop；对任意贪心前缀 k_g，V(k*_stop)≥V(k_g)（最优停止的最优性）。故在期望代价意义下，DACSC 不劣于 CSC，且严格优于在边际风险超过重规划代价时仍继续的情形。∎

## 7. 已知风险

**一句话**：OCTAVE 的安全论证把赌注押在「可达集/不变集与时间上界能在真实平台上被准确标定」这一假设上；一旦扰动集、故障集合或抖动/延迟尾部被低估，风险敏感最优控制会**精确地优化一个错误的模型**，而 ROS2 的 QoS 合同与生命周期反而给出「有形式保证」的错觉——用最优性与实时性包装了建模误差与不可调度性（A94）。

**次级风险与缓解**：
1. **不变集维数灾难**：Ω(b) 在高维 x 上不可精确计算；缓解：只对安全关键子状态（接触位姿、法向力、滑移）建低维生存核，其余用球外近似；HJ 网格离线 + 在线查表。
2. **信念-MDP 求解近似误差**：点近似可能漏掉重尾；缓解：CVaR 直接约束尾部，语义流用采样 + 保守上界；求解失败即降级。
3. **WCRT 静态分析乐观**：DDS 尾延迟/缓存/优先级反转难界；缓解：AIC-R 注入最坏时序重算，WCRT 留安全系数，超界判 H_time。
4. **QoS 合同运行期漂移**：参数被改或节点不遵守；缓解：合同哈希进 J_octave，运行期监视器比对；不符即失效。
5. **时钟同步不可用**：无 PTP 时 δ_clock 可能大；缓解：退化为逻辑时钟 + 保守 TTL，失步即 FINALIZED。
6. **租约续期本身引入抖动**：续租消息挤占实时带宽；缓解：续租走低频独立通道、预留预算、与语义流解耦。
7. **开放世界逃逸先验难标定**：b_⊥ 过高导致永久保守；缓解：在线重标定新颖性阈值、按任务阶段调整 δ_open，并保留人工复位。
8. **最优性带来的过度自信**：把 π* 当作"正确"而非"在模型内最优"；缓解：J_octave 永远携带 aic_r_ver 与 viability_margin，审计只承诺「集合内安全」，从不承诺「归因正确」。
9. **多维代价权重难调**：λ_d/λ_s/λ_i 强影响行为；缓解：以证书可行性为硬约束、权重只调软偏好，并做敏感性分析（E245）。
10. **ROS2 生态差异**：DDS 实现/中间件不同导致时序行为不同；缓解：AIC-R 跨中间件认证，把中间件版本写入 qos_contract_hash。
