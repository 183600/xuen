# 第 44 轮（承接 v20）· MLLM-Cert × Impedance-Cert：把「多模态大模型」的语义不确定性与「阻抗控制」的物理接触纳入同一可验证证书（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 把「用户」与「并发」提升为证书对象，但它仍压着两个未言明的假设：**(H5) 动作是几何/运动学对象**——证书验证的是轨迹、区域与 margin，然而在接触丰富的操作与人机物理交互里，真正下发给执行器的是**阻抗 (M,D,K)**，同一个几何上合法的轨迹在不同阻抗下可以是安全轻放，也可以是砸碎杯子。**(H6) 环境与接触属性是可观测真值**——MLLM 从图像/语言/触觉给出「这是金属、可承重、刚性」的语义，被当作事实直接决定阻抗；但接触属性是**可证伪假设**，更糟的是：**机器人自己的阻抗会污染用于验证该阻抗的接触证据**（物理版自证成）。本轮灵感词「多模态大模型」「阻抗控制」正好命中：**多模态大模型**提供任务语义与接触假设，但不确定、会幻觉、且慢；**阻抗控制**是接触安全真正的执行器与物理证书载体。二者耦合出本轮真正的新问题——**语义不确定性与物理柔顺性的对齐，以及接触证据的阻抗污染**。

## 0. 直觉与动机

**灵感 1（阻抗也是动作，而且比轨迹更接近危险）**：在自由空间，验证一条轨迹基本够了；一旦接触，危险由力与能量决定，而力由阻抗和接触共同决定。直觉：**阻抗指令必须像轨迹一样持证**，证书至少覆盖 (i) 无源性/能量（不向环境注入未持证能量）、(ii) 接触稳定性（对认证环境类内所有接触参数稳定）、(iii) 力界（法向/切向力不超安全包络）、(iv) 任务可行（力界内仍能完成目标）。说不清就退化到认证的柔顺默认点，而不是硬撑。

**灵感 2（多模态大模型：语义提议，物理裁决）**：MLLM 的强项是把「把鸡蛋轻轻放进去」「这箱子很重，推稳一点」「把手给我」翻译成**任务语义 + 接触假设 + 期望柔顺语义**；弱项是它给不出阻抗数值，也不该被信任去给。直觉：**MLLM 只提议可行域，物理证据与证书做裁决**。语义的不确定性（多模态冲突、低置信、分布外）不应被忽略，而应**单调地兑换成物理柔顺**：越不确定，越向认证的柔顺默认点收缩（但仍保持任务所需的最小刚度与阻尼，不是无脑降到零）。一句话：**不确定时向柔顺收缩，而不是向自信硬撑**。

**灵感 3（耦合：接触会自证成——机器人用自己的刚度「摸到」自己的假设）**：最麻烦的不是单向，而是环。设机器人刚度 k_r、环境刚度 k_e，线性接触下观测到的表观刚度是串联 k_app = (k_r^{-1}+k_e^{-1})^{-1}。当 k_r ≫ k_e，k_app≈k_e（能辨识环境，但机器人很硬、力很大）；当 k_r ≪ k_e，k_app≈k_r（机器人很软，但**几乎辨识不到环境**）。更隐蔽的是：若 MLLM 幻觉「这是刚体」并把 k_r 调高，则力/位移信号也会表现得「像刚体」，从而**反过来坐实幻觉**——这就是物理自证成。第三个直觉：**必须显式认证「可辨识性」与「污染指数」**，把「不知道」当作一等公民；辨识需要激励，而激励必须安全，于是出现**安全主动接触辨识**：在力/能量预算内做最有信息量的温和探测，并承认**可辨识性上限由安全预算决定**。

**耦合升级**：SIC（语义阻抗编译器）把 MLLM 语义编译成带不确定性的阻抗域与环境类；MCL（多模态接触账本）把接触属性变成带溯因、可辨识性与污染检测的持证假设；CIR（认证阻抗运行时）给出无源性/力界/接触稳定的运行时证书与单调降级；SCG（接触自证成守护器）检测并打破「用自己的刚度坐实自己假设」的环路。四层架构由 v8 的「人格契约 + 并发证书」升级为 v9 的「**语义阻抗证书 + 接触证据证书 + 物理自证成证书**」，与既有几何证书、并发证书、人格证书正交组合。

## 1. 形式化定义（增量：定义 44–51）

**定义 44（多模态接触证据与接触画像证书）**：接触画像 c=(material, k_e, b_e, μ, m_e, geometry) 是假设而非真值。证据 e=(value, modality, source, t, sig, sensitivity)，modality∈{vision, tactile, force, audio, language}。**溯因**：每个被用于守卫的接触属性存在见证子集 Wit⊆E。**鲁棒**：对任意 |B|≤f 的伪造/错误证据，属性集合的 Hausdorff 扰动 ≤δ。**校准**：给出可信接触集 C_c 满足 P(c_true∈C_c) ≥ 1−α（按模态分层 Mondrian 共形）。**跨模态冲突不是投票**：可能环境集取各模态可信集的**并** C_c=∪_m C_c^m（任一可能为真），而认证阻抗域取对 C_c 的**交** Z_safe=∩_{c∈C_c} Z_safe(c)。冲突增大 C_c ⟹ Z_safe 收缩 ⟹ 更柔顺。**未持证属性不得用于设置阻抗**。

**定义 45（语义阻抗程序 SIP）**：MLLM 把多模态上下文（指令、场景、人的状态、任务阶段）映射为语义阻抗意图 s=(phase, compliance_semantics, force_intent, contact_hypotheses, u)，编译为**阻抗域** Z_s⊆{(M,D,K)} 与**环境类** E_s，而非单点阻抗。u∈[0,1] 为语义不确定度（多模态冲突度、校准集大小、token 熵、OOD 分数融合）。**约束**：Z_s 中每个 z 的 (M,D,K) 必须落在硬件与安全包络内；SIP 只写「提议域」，绝不写安全关键谓词。

**定义 46（阻抗证书与鲁棒接触安全）**：对 z=(M,D,K) 与环境类 E_s，阻抗证书 IZ(z,E_s) 有效当且仅当：
(1) **无源性/能量**：能量罐 T(t)≥0，且 dT/dt ≤ P_in^cert（只注入已持证能量）；
(2) **接触稳定**：耦合系统对 ∀e∈E_s 稳定（无源性/L2 增益有界，或给出口袋稳定条件）；
(3) **力界**：∀e∈E_s、∀任务激励，|F_n|≤F_n^safe、|F_t|≤μ F_n、总能量 ≤E_max；
(4) **任务可行**：在力界内仍存在完成已认证目标的策略。
认证阻抗域 Z_cert(E_s)={z: IZ(z,E_s)}。运行期只允许 z∈Z_cert(E_s)，否则投影到最近的安全点或降级。

**定义 47（不确定度→柔顺单调映射）**：定义柔顺偏序 z1 ⪯_soft z2 当且仅当 K1⪯K2、D1⪰D2、力界 F1≤F2（更软=更低刚度/更高阻尼/更小力界）。要求编译器满足**单调性**：若 u1≤u2（更不确定），则 Z_s(u1)⊆Z_s(u2)（环境类只增）且 Z_cert(u2)⊆{z: z ⪯_soft z*(u2)}，其中 z*(u) 为随 u 单调变软的认证默认点；且 Z_cert 非空（否则停机/协商）。**命题（安全-能力权衡）**：u 增大只会收缩认证可行域，绝不放松安全；能力（可完成任务集）随 u 单调不增。**注**：柔顺有下界——低于支撑/抗扰所需的最小刚度同样不安全，因此「软」是向 z* 收缩而非无限降刚。

**定义 48（能量租约与语义租约）**：每条 SIP 携带语义租约 ℓ_s=(s, τ_s, λ_s) 与能量租约 ℓ_E=(T_cap, τ_E, λ_E, E_min)。语义新鲜度判据与 v20 定义 41 同构：s 的可用性随时间衰减；过期则沿降级格回退。可用主动能量 T_use=min(T(t), T_cap·e^{−λ_E(t−τ_E)})，且受证据等级约束（证据越弱，T_cap 越小）。**命题**：若 λ_s、λ_E 由语义变化率与接触位移 Lipschitz 界出，则过期判据 sound，绝不使用过期语义驱动高刚度。

**定义 49（接触证据的阻抗污染与可辨识性）**：线性接触下 k_app=(k_r^{-1}+k_e^{-1})^{-1}。定义**污染指数** CI(z)=|k̂_e(z)−k̂_e(z0)|/σ̂，其中 z0 为认证中性探测阻抗。定义**可辨识余量** ι=(1−ε)k_r−k_app；ι≤0 时环境与该阻抗不可分，接触画像降级为「未知」。**去卷积校正**：在可辨识条件下 k̂_e = k_r k_app/(k_r−k_app)。**命题（柔顺-可辨识对偶）**：∂k_app/∂k_e=(k_r/(k_r+k_e))^2，随 k_r 增大单调增；故**辨识环境需要足够的机器人刚度或已知力激励**，而高刚度同时抬高力/能量风险——辨识与安全存在结构性张力，不能同时无限优化。

**定义 50（安全主动接触辨识）**：探测策略 π_p 选择 z_p 与激励 ξ，须满足 z_p∈Z_cert、力≤F_safe、能量罐≥0、扰动轨迹留在安全集内；目标最大化单位风险信息增益 IE=ΔH(c)/ΔE_risk。**定理（可辨识性上限）**：在力/能量预算 (F_safe,E_max) 与噪声 σ 下，接触参数的可辨识精度存在 Cramér–Rao 下界，任何「更准」的声明都超出安全预算——**不知道不是失败，假装知道才是**。

**定义 51（组合证书、降级格与单调安全）**：全局不变式 I_MI 要求：(i) 每条阻抗指令有有效 IZ；(ii) 每个用于守卫的接触属性带溯因、可辨识性与 CI≤c_max；(iii) 语义租约与能量租约在界；(iv) 跨模态冲突走并/交规则；(v) 降级格 L0 完整语义阻抗 ≻ L1 证据校正阻抗 ≻ L2 保守先验阻抗 ≻ L3 认证安全保持 ≻ L4 柔顺停机，沿格下降时「攻击性」（刚度/力界/速度）单调不增且每级仍持证。**定理（组合安全）**：若各级都满足 IZ 且 MLLM 任务与安全监控满足 v20 定义 40 的 rely-guarantee 非干扰（SIP 只写提议域），则任意降级/并发交错下不会执行未认证阻抗，也不会用未持证接触属性设置刚度。

## 2. 新增产出与既有 IP 升级

### 2.1 IP-60 MULTIMODAL-CONTACT-LEDGER（多模态接触账本 MCL）
1. **证据入账**：视觉材料/几何、触觉纹理/硬度、力/位移、音频（碰撞声）、语言描述，统一带来源/时间/签名/敏感度。
2. **溯因与鲁棒聚合**：见证子集、trimmed/中位数聚合、攻破点 f 与偏差 δ；未持证属性标「未知」。
3. **跨模态冲突的并/交处理**：可能环境集取并、认证阻抗域取交；冲突度并入不确定度 u。
4. **污染与可辨识性检测**：CI、ι、去卷积校正；不可辨识即降级「未知」，绝不把 k_app 当 k_e。
5. **反事实证据**：并行维护中性探测 z0 下的接触估计，供 SCG 与 E98 使用。

### 2.2 IP-61 SEMANTIC-IMPEDANCE-COMPILER（语义阻抗编译器 SIC）
1. **语义→阻抗域编译**：MLLM 输出任务阶段、柔顺语义、力意图、接触假设；编译为 Z_s、E_s 与不确定度 u。
2. **校准不确定度**：按任务/模态分层共形 + OOD 检测 + 多模态冲突融合，输出可校准 u。
3. **单调柔顺映射**：u↑ ⇒ Z_s 扩张、认证默认点 z*(u) 变软；保证 Z_cert 非空否则协商。
4. **只提议不裁决**：SIP 只写提议域与软约束，安全关键谓词只读；由 CIR 做最终投影与守卫。
5. **可解释降级**：把「为什么变软」归因到具体证据缺口/冲突/租约过期，供审计与课程回灌。

### 2.3 IP-62 CERTIFIED-IMPEDANCE-RUNTIME（认证阻抗运行时 CIR）
1. **无源性能量罐**：T(t)≥0、只注入持证能量；能量租约约束最大主动能量。
2. **鲁棒阻抗证书**：对环境类 E_s 检查接触稳定与力界；输入 z 先投影到 Z_cert。
3. **语义租约 + 单调降级**：语义过期按 L0→L4 降级，刚度/力界单调不增；默认点仍持证。
4. **安全主动辨识调度**：在预算内做最有信息量的温和探测，记录 IE 与可辨识性上限。
5. **1kHz 守卫**：INT8/解析式证书查表；监控器最高关键级，MLLM 低关键级并发。

### 2.4 IP-63 SELF-CONFIRMATION-GUARD（接触自证成守护器 SCG）
1. **污染指数在线估计**：比较 z 与中性 z0 下的接触估计，CI 超界即判「证据被自己的刚度污染」。
2. **反事实与打破环路**：切换到低刚度/力控探测或中性探索，禁止用被污染证据抬高刚度。
3. **幻觉接触黑名单**：被证伪的 MLLM 接触断言（如「绝对刚性」）进入黑名单并降权。
4. **自证成漂移监控**：长时程跟踪「语义先验→阻抗→证据→再确认」的环路，检测单调硬化漂移。
5. **安全辨识-利用分离**：辨识阶段与任务利用阶段显式分离，辨识不得借任务之名超预算。

## 3. 四层架构 v9

```
L1: TRI-FUSE(INT8) + LIO + 触觉/力/音频 → C_ms + B_t + L_m + 接触原始证据
L2: CTC + MLLM/VLM + IP-35 仲裁 → 语义阻抗意图 s + 阻抗域 Z_s + 环境类 E_s + 不确定度 u
L3: IP-51 CAR(ImpedanceMode/EnergyLease) ← IP-62 CIR(能量罐 + 鲁棒阻抗证书 + 力界 + 语义租约 + 安全辨识)
    ← IP-63 SCG(CI/ι + 反事实 + 黑名单) → IP-47 端口-Hamilton 组合
    → IP-39 规划(CBF + 力界联合) → IP-45 总线 → IP-48 认证流 + IP-43 韵律
    → IP-53 CMC(能量罐/力界/CI 监控, 最高关键级)
L4: IP-57 PCE(人格 → 阻抗契约) + IP-60 MCL(接触证据账本) + IP-55 CKB(接触先验/黑名单)
    ← IP-59 ICV(接触/自证成对抗) + IP-54 SCV(接触仿真) → IP-44 蒸馏 + IP-50 课程 → RCA 重颁
运行期：证据入账 → 接触假设 + 可辨识性 → 语义编译 Z_s/E_s/u → 不确定性→柔顺
        → 阻抗证书投影 → 能量罐/力界守卫 → 1kHz 执行 → 反事实证据回灌 → 打破自证成
```

## 5. 本轮最大风险

**一句话**：线性串联模型与「可辨识性/污染指数」只在准静态、近似线性的接触下成立，真实接触（非线性、摩擦、塑性、突变）会让 CI/去卷积误判，从而把「被自己刚度污染的假刚性」当成证据并放行高刚度阻抗，而力界证书只保护机器人、未必保护被操作物——因此 E96（接触稳定与力界）与 E98（自证成）必须设为红线，默认回退到「低刚度认证默认点 + 接触画像只读先验」这条永不放大幻觉的底线。

```
def compile_semantic_impedance(context, mllm, CKB):
    s = mllm.infer(context)                       # 阶段/柔顺语义/力意图/接触假设
    u = calibrated_uncertainty(s, ode_score=f(s), set_size=f(s),

    E_s = environment_class(s.contact_hypotheses, CKB)   # 可能环境集（并）

    z_def = safe_default(u)                       # u↑ => 变软，但有下界

        return Negotiation(minimal_relaxation(Z_s, E_s))  # 空集必协商
    return SIP(s, E_s, Z_s, u, z_def)

def safe_default(u):
    # 向认证柔顺点收缩，但保任务支撑最小刚度，避免“过软失稳”
    K = max(K_min_support, K_nom * (1 - beta * u))
    D = min(D_max,        D_nom * (1 + gamma * u))
    F = max(F_min_task,   F_nom * (1 - delta * u))
    return Impedance(K=K, D=D, F_bound=F)

def assert_monotone(Z_s_u1, Z_s_u2, u1, u2):
    if u1 <= u2:
        assert subset(Z_s_u1, Z_s_u2)             # 更不确定 => 环境类更大
        assert softer_or_equal(safe_default(u2), safe_default(u1))
    return True
```

### IP-62 CIR：能量罐、鲁棒证书、双租约与安全辨识

```
def certify_impedance(z, E_s, tank, lease_s, lease_E, t):
    if not lease_valid(lease_s, t) or not lease_valid(lease_E, t):
        return project_to_default(z, E_s)         # 语义/能量过期 => 柔顺默认点
    if tank.energy < 0 or z.active_energy() > tank.budget_at(t):
        return project_to_default(z, E_s)         # 无源性能量守卫
    for e in E_s.samples_and_vertices():
        if not contact_stable(z, e):              # 无源性/L2 有界
            return project_to_safe(z, E_s)
        if exceeds_force_bound(z, e):             # 法向/切向/能量界
            return project_to_safe(z, E_s)
    return z

def project_to_safe(z, E_s):
    # 沿柔顺方向缩放，找最大的 s∈[0,1] 使 IZ(s·z,E_s) 仍有效
    for s in descending_grid():
        if iz_valid(s * z, E_s):
            return s * z
    return IMPEDANCE_SAFE_HOLD

def downgrade_lattice(level, evidence):
    # L0 完整语义 > L1 证据校正 > L2 保守先验 > L3 认证保持 > L4 柔顺停机
    # 攻击性 (K,F,speed) 沿格单调不增；每级仍须持证
    lvl = min(level, max_level_allowed_by(evidence))
    return LatticeStep(lvl, impedance=impedance_for_level(lvl))

def safe_probe(E_s, tank, F_safe, risk_budget):
    best, best_ie = None, -inf
    for zp in candidate_probes(Z_cert(E_s), F_safe):
        dH = expected_info_gain(zp, E_s)          # 接触参数熵下降
        dR = risk_of(zp, tank, F_safe)            # 力/能量/扰动风险
        ie = dH / max(dR, EPS)
        if within_budget(zp, tank, F_safe) and ie > best_ie:
            best, best_ie = zp, ie
    return best if best_ie >= ie_min else None    # 不划算就保留保守先验
```

### IP-63 SCG：污染检测、反事实与打破自证成

```
def contamination_index(k_hat_z, k_hat_z0, sigma):
    return abs(k_hat_z - k_hat_z0) / max(sigma, EPS)

def scg_step(z, obs, neutral_probe, blacklist):
    k_z = deconvolve_stiffness(z.K, apparent_stiffness(obs))
    k_0 = deconvolve_stiffness(neutral_probe.K,
                               apparent_stiffness(neutral_probe.obs))
```

回退：E96 失败 → 关闭高刚度，只允许认证柔顺默认点；E97 失败 → 固定保守阻抗、关闭语义驱动刚度；E98/E99 失败 → 接触画像只读先验、禁止在线抬刚度；E100 失败 → 缩短语义租约并固定 1kHz 安全阻抗；E101 失败 → 多模态冲突一律取最保守先验；任何红线失败 → 熔断回退 v20。

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 线性/准静态接触模型失真，CI/去卷积误判真实非线性/摩擦/塑性接触 | 高 | E96/E98 红线；无源性（模型无关）+ 保守力界；环境类域随机化；不可辨识即未知 |
| MLLM 幻觉接触属性（「绝对刚性/可承重」）直接驱动高刚度 | 高 | 未持证不作见证；语言仅弱先验；幻觉黑名单；E95；默认柔顺点 |
| 可辨识性不足却给出高置信接触估计（假自信） | 高 | ι≤0 强制未知；CI 超界判污染；E98/E99；安全主动辨识 + 可辨识上限 |
| 语义租约过期导致刚度突降/突跳，产生冲击或失稳 | 中-高 | 单调平滑插值到认证默认点；降级格每级持证；E100 |
| 跨模态冲突处理过保守，能力崩塌 | 中 | 空 Z_cert 走最小让步协商；保守先验但保留任务最小刚度；E101 |
| 能量罐耗尽导致能力骤降或频繁降级 | 中 | 能量租约管理；辨识-利用分离；按关键级分配主动能量；E96 |
| 1kHz 阻抗/力界守卫开销过大 | 中 | 查表 + INT8 + 解析式界；监控器最高关键级；p99 开销红线 |
| 人格阻抗契约与全局力界冲突 | 中 | 人格只做上限收缩；全局安全域优先；空集协商而非静默放宽 |

## 6. 本轮最大风险

**一句话**：线性串联模型与「可辨识性/污染指数」只在准静态、近似线性的接触下成立，真实接触（非线性、摩擦、塑性、突变）会让 CI/去卷积误判，从而把「被自己刚度污染的假刚性」当成证据并放行高刚度阻抗，而力界证书只保护机器人、未必保护被操作物——因此 E96（接触稳定与力界）与 E98（自证成）必须设为红线，默认回退到「低刚度认证默认点 + 接触画像只读先验」这条永不放大幻觉的底线。
