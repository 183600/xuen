# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感：「灵巧操作」×「评测指标」）

> R69 问「我该向谁求证」。但在求证之前，还有一个更前置的问题：**我到底在优化什么？我的记分牌有没有在骗我？**
> R69 的整套安全论证默认「任务目标 / 评测函数是外生、可信、不可博弈的」——这正是它没有审视的假设。可一旦系统学会了「问」，它也可能学会「问出一个对自己有利的答案」；一旦系统开始优化一个指标，它优化的是指标，不一定是任务。
>
> 灵巧操作把这个问题推到极致：接触丰富、混合动力学（接触建立/断开是离散模式切换）、多指高维、真机昂贵且具破坏性。一次「成功抓取」可能同时意味着滑移、挤压、作弊式兜取、或只是仿真里运气好。「成功率」这个标量把接触相位、力闭包、泛化性全糊在一起；而只要它进了目标函数，策略就会去优化它，而不是去灵巧地操作。
>
> 核心命题：**把「评测」从流程末端的记分牌，升格为闭环内一等公民：接触相位感知、多保真、Pareto 安全、可检测 Goodhart、且在指标本身不可信时允许「弃权」。** 命名 **DEXA-RAS**（DEXterous Assessment-aware Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**什么才算成功，谁来裁判，裁判会不会被骗**」——评测不是 Observer，而是 Loop 的一部分。

## 0. 直觉与动机

**灵感 1（灵巧操作 → 灵巧不是一个标量，而是一串接触相位的向量）**
直觉：「抓起来了」是一句毫无信息量的话。手指是稳稳合拢还是勉强夹住？物体在掌心滑了 2mm 还是 0.2mm？是力闭包还是摩擦锥边缘的临界平衡？是抓握后稳定在手内旋转，还是靠桌面托了一把？灵巧操作的评价天生是**相位结构化**的：接近 → 接触建立 → 抓握闭合 → 在手操作 → 释放。每个相位有自己的物理语义与失败模式。把它们压成一个 0/1 成功率，等于把「在哪一步、因为什么失败」这唯一有用的诊断信息丢掉。**PACE 的第一性原理：评测的首要产出不是分数，而是失败归因。**

**灵感 2（评测指标 → 指标一旦进入目标，就从「测量」变成「可被优化的对象」，于是可被博弈）**
直觉：这是 Goodhart 定律的工程版。若只用 M_opt 训练，策略会找到一切让 M_opt 变高而与真实灵巧无关的捷径：兜取代替抓握、慢到失去实用性的「稳定」、只在评测物体上过拟合、甚至利用仿真接触模型漏洞。单通道评测无法区分「真的变好」与「把尺子掰弯」。DEXA 的答案是**双通道对偶**：M_opt（被优化）与 M_audit（留出、不参与训练、方向尽量与 gaming 正交）。二者出现系统性背离，就是博弈在发生——这是 R69「残差通道 vs 流似然通道」在评测层的镜像。

**灵感 3（评测昂贵 → 「该跑哪一次评测」本身是一个信息动作，VoE 是 VoI 的对偶）**
直觉：真机评测有成本、耗时、甚至损坏硬件；仿真便宜但会撒谎。因此不该均匀地测，而应**主动选测**：测哪个物体、哪种扰动、哪个保真度、哪个指标，能最大程度降低「我对策略真实质量的无知」。这与 R69 的 value-of-information 完全同构：把评测看成带成本的信息动作，选 `argmax[VoE − cost]`。**评测预算（Evaluation Budget）由此成为与交互预算并列的一等资源。**

**灵感 4（安全不能被成功率交易 → 用 Pareto 部分序替代加权和）**
直觉：加权和 `J = α·success − β·violation` 是危险的：只要 α/β 够大，任何安全违规都能被「成功率提升」买走。灵巧操作天然多目标（成功率、轻柔度/峰值力、节拍、对物体位姿变化的泛化）。正确姿态是**偏序而非全序**：先划出安全下界（力/位/温/磨损），在此**前沿之内**再比其它指标；任何「以安全换成功率」的候选直接判为不可选。定理 19 将证明这不会弱于 R69 的选择。

**灵感 5（指标本身也不确定 → 允许弃权，「不可评分」是一等输出）**
直觉：仿真与真机的指标系统性不一致；两个人类评分者对「这次在手旋转算不算成功」也会分歧。此时强行给一个数，是把评测噪声伪装成事实。选择性评测（selective evaluation）告诉我们：**对高分歧/不可识别的样本弃权，可以显著降低已评分集合上的错误率**（引理 22）。弃权不是摆烂，而是触发 R69 的交互去补测或问人——两层闭环在此咬合：**R69 负责「做的时候不确定就问」，R70 负责「评的时候不确定就弃权/补测」。**

**灵感 6（对 R69 的严格包含 → 评测层是外环，内环安全不让步）**
直觉：DEXA 若不满足「退化即 FLUID」，就只是又一个需要独立信任的黑箱。故规定退化边界：指标退化为标量、单一保真、无博弈、单一 Pareto 点、不弃权时，DEXA 的选择与 FLUID-RAS **逐指令相同**。更关键的是，评测层运行在 episode 之间（外环），**绝不进入 R69 的 2.6ms 实时内环**，所以任何评测失败都只影响「下一轮选什么」，不会造成当拍控制突变。这是本轮安全论证的支点。

## 1. 形式化定义（增量：定义 310–323）

**定义 310（DEXA-RAS 总览）** DEXA-RAS = (PACE, TCI, MFE, VoE, GAD, MRG, MET-AB, EBD, RAS-WM††)。四不变式：
(i) **内环隔离**：PACE/MFE/VoE/GAD/MRG 全部在 episode 边界的外环运行，不进入 R69 实时流；内环控制仍由 FLUID-RAS/RAS-WM 认证；
(ii) **配对与预注册**：被优化的指标集 M_opt 与审计指标集 M_audit 在评测前锁定（metric lock），M_audit 不参与任何训练/选型/早停；
(iii) **安全前沿硬约束**：任何候选策略必须满足 `safety(c) ≥ S_floor`，安全不可与成功率做加权交易；
(iv) **证据与弃权纪律**：指标不可识别或评分者分歧 > τ_dis 时，输出 ABSTAIN 而非分数，并进入补测/人类仲裁队列。

**定义 311（接触相位自动机 PACE）** 用触觉事件与接触状态构造混合自动机 𝒫 = (Q, E, δ, q_0)，Q = {接近, 接触建立, 抓握闭合, 在手操作, 释放, 失败}；事件 e ∈ E 含首次接触、接触数变化、滑移超阈、力闭包达成、释放。相位序列 π = q_0 → … → q_T 由观测唯一分段（A99）。轨迹 τ 被切分为 `τ = τ_{q_1} ⊕ … ⊕ τ_{q_T}`。

**定义 312（相位感知指标向量）** 对每相位 q 定义指标向量 m_q = (success_q, slip_q, force_peak_q, closure_margin_q, duration_q, pose_err_q)。整体评测不是标量和，而是 `M_ph(τ) = ⊕_q m_q`；失败归因 `attr(τ) = argmin_q success_q`（若多相位同时失败则给出相位集合）。允许下游按任务语义做**受约束聚合**（先看 safety 相关分量，再看效率分量），但禁止把 safety 分量与效率分量做无约束加权。

**定义 313（触觉接触完整性 TCI）** 由触觉序列得 `TCI = (slip_rate, closure_margin, chatter, force_peak, contact_switch_count)`。TCI 是稠密、因果、难以通过「只看最终状态」作弊的过程指标；它是 M_audit 的核心成分（对应 R69 中「行为似然」的角色）。

**定义 314（多保真评测阶梯 MFE）** 保真度阶梯 ℱ = {sim, twin, real}（可扩展）。对策略 π、保真度 f 得 `M_f(π)`；设保真偏差 `b_{f→real}(π) = E[M_real(π) − M_f(π)]` 在策略参数上 L_b-Lipschitz。偏差校正估计 `M̂_real(π) = M_f(π) + b̂_{f→real}(π)`，b̂ 由标定集学习（A100）。同一策略在多保真上的一致性本身是「可信度」信号：分歧大 ⇒ 提升保真度或弃权。

**定义 315（评测价值 VoE）** 候选评测 e = (物体, 扰动, 保真度 f, 指标子集)；真实质量变量 Q（策略在目标分布上的指标）。`VoE(e) = I(Q; Y_e)`，Y_e 为评测 e 的结果；选择 `e* = argmax_e [VoE(e) − cost(e)]`，s.t. `risk(e) ≤ ε_eval`（不得为评测而危险操作）且评测预算未超。`max[VoE−cost] ≤ 0` ⇒ 不评测，沿用先验。

**定义 316（Goodhart 间隙与检测 GAD）** 令 M_opt 为被优化指标、M_audit 为留出审计指标（近似与 gaming 方向正交）。定义 `g = M_audit − M_opt`。当 `g < −τ_gap` 且持续 K_g 个评测窗 ⇒ 判定 **指标博弈**（metric gaming）。检测器同时报告「干预残差」ε_g：M_opt 上升中不能被真实能力提升解释的部分。

**定义 317（Pareto 安全选择 MRG）** 候选集 C 的可行域 `C_safe = {c ∈ C : safety(c) ≥ S_floor}`；Pareto 前沿 `P_safe = ParetoFront_{M_other}(C_safe)`（M_other 含 success、gentleness、speed、generality）。选择 `c* = argmax_{c ∈ P_safe} tiebreak(c)`（tiebreak 只能是效率类，不得含安全项）。**任何不在 C_safe 的候选，无论成功率多高，一律不可选。**

**定义 318（指标弃权与协商 MET-AB）** 评分者/保真度分歧 `dis = max_{a,b} d(M_a, M_b)`。若 `dis > τ_dis` 或 `attr(τ)` 不唯一且差距 < δ_attr（不可识别）⇒ 输出 ABSTAIN(reason, evidence)，并把「补测请求」作为 R69 的信息动作送入 MINT；人类仲裁结果回流为新的 audit 证据（受 R69 证据纪律约束）。

**定义 319（评测预算与指标锁 EBD）** 评测预算 `B_eval = (真机次数, 仿真机时, 人类评分分钟数)` 硬约束；`metric lock`：评测前哈希锁定指标定义、阈值、统计检验与停止准则，评测后不得更改；所有评测记录入 EvaluationLedger（不可篡改哈希链），供审计复算。这是「防止研究者自己 p-hacking」的工程化。

**定义 320（证书 J_DEXA）** `J_DEXA = (J_FLUID, phase_coverage, tci, fidelity_consistency, goodhart_gap, pareto_compliance, abstain_rate, metric_lock_hash, dex_ver)`。Valid ⇔ Valid(J_FLUID) ∧ phase_coverage ≥ c_ph ∧ |goodhart_gap| ≤ τ_gap ∧ pareto_compliance ∧ metric_lock 未被破坏。

**定义 321（对抗评测集 AIC-DEXA）** `ℰ_DEXA = ℰ_FLUID × ℰ_gaming × ℰ_contact × ℰ_fidelity`：gaming（兜取/过拟合评测物体/利用接触模型漏洞）、contact（接触抖动、临界滑移、力闭包边缘）、fidelity（仿真高真机崩、数字孪生失配）、以及评测投毒（污染 audit 集）。

**定义 322（参与式审计 VQAuditor-D）** 审计对象新增：指标是否被 gaming、audit 是否被泄题、弃权是否被滥用为「藏失败」、评测预算是否被集中浪费在易样本。结论回灌 AuditBuf，成为下一轮 VoE 的先验与 MRG 的 tiebreak 校准。

**定义 323（评测可识别性 A99）** 存在常数 δ_ph > 0，使任意两接触相位的触觉-力签名可分离度 ≥ δ_ph，且接触事件（建立/断开/滑移）在观测中可检测；同时（A100）多保真偏差 b_{f→real} 对策略参数 Lipschitz。A99 保证失败归因可识别，A100 保证偏差校正估计一致。

## 2. 关键算法骨架

```python
# IP-264 PACE：接触相位感知评测（失败归因优先于分数）
def phase_metrics(traj, tactile, contact_events):
    phases = segment_phases(contact_events)          # 接近/建立/抓握/在手/释放/失败
    F = decompose_traj(traj, phases)
    return {q: m_q(F[q], tactile[q]) for q in phases}   # 每相位向量指标

# IP-265 TCI：触觉接触完整性（稠密、难作弊）
def contact_integrity(tactile):
    return dict(slip_rate=slip(tactile),
                closure_margin=closure(tactile),
                chatter=jitter(tactile),
                force_peak=tactile.peak(),
                switch_count=count_switches(tactile))

# IP-266 MFE：多保真评测 + 偏差校正（仿真→孪生→真机）
def multi_fidelity_metric(policy, ladder, calib):
    est = {f: run_eval(policy, f) for f in ladder}       # sim / twin / real
    return debias(est, calib)                            # M̂_real，附 fidelity_consistency

# IP-267 VoE：把「跑哪次评测」当成带成本的信息动作（VoI 的对偶）
def choose_evaluation(policy, belief, budget):
    best = None
    for e in eval_candidates(policy, belief):            # 物体/扰动/保真度/指标子集
        if not budget.allow(e):            continue
        if not risk_ok(e):                 continue      # 不为评测做危险操作
        score = mutual_info(quality; result_of(e)) - cost(e)
        if best is None or score > best.score: best = (e, score)
    return best if best and best.score > 0 else None     # 无利可图 → 不评测

# IP-268 GAD：优化指标 vs 留出审计指标 —— Goodhart 间隙
def goodhart_gap(M_opt_series, M_audit_series):
    g = [a - o for a, o in zip(M_audit_series, M_opt_series)]
    return dict(gap=mean(g[-K_g:]),
                gaming=(mean(g[-K_g:]) < -TAU_GAP),       # 指标在涨、审计在跌
                unexplained=residual_of_ability(M_opt_series))

# IP-269 MRG：Pareto 安全选择——成功率不能交易安全
def pareto_safe_select(candidates, safety_floor):
    safe = [c for c in candidates if c.safety >= safety_floor]
    if not safe: return None                              # 无安全候选 → 不部署
    P = pareto_front(safe, keys=['success','gentleness','speed','generality'])
    return argmax(P, key=lambda c: c.efficiency_tiebreak) # 只在安全前沿内偏序

# IP-270 MET-AB：指标不可识别/分歧大 → 弃权并触发 R69 补测/问人
def score_or_abstain(M_ph, disagreement):
    if disagreement > TAU_DIS or not identifiable_attr(M_ph):
        return ABSTAIN(reason='metric_ambiguous', evidence=M_ph)
    return aggregate_constrained(M_ph)                    # safety 分量不参与加权

# IP-275 DEXA 外环：episode 之间运行，绝不侵入 R69 内环
def DEXA_round(policy, M, ladder):
    traj, tac = rollout(policy)                           # 内环仍由 FLUID-RAS/RAS-WM 管
    M_ph = PACE.phase_metrics(traj, tac, contact_events(tac))
    tci  = TCI.contact_integrity(tac)
    if isinstance(MET_AB.score_or_abstain(M_ph, disagreement(M_ph)), ABSTAIN):
        M.mint, _ = R69_MINT.choose_interaction(...)      # 借用 R69：补测或问人
    est = MFE.multi_fidelity_metric(policy, ladder, M.calib)
    gap = GAD.goodhart_gap(M_ph['opt'], est['audit'])
    if gap['gaming']: M.audit.flag_policy(policy)         # 指标博弈告警
    sel = MRG.pareto_safe_select(M.candidates, M.safety_floor)
    M.vqa_d.submit(M_ph, tci, est, gap, sel)              # 参与式审计 + 台账
    return sel, M.cert(J_DEXA, M_ph, tci, est, gap)
```

## 3. 推导

**引理 19（相位可识别性与失败归因）** 在 A99 下，任意两个接触相位的触觉-力签名可分离度 ≥ δ_ph、接触事件可检测，则相位感知指标能以概率 ≥ 1 − ε_ph 唯一地把失败归因到某一相位；而任何仅基于终态 success 的标量指标，对「在哪个相位失败」的信息量为 0。系：**评测的第一价值是归因，第二才是排序**；归因是 R69「问什么」的上游——不知道哪相位失败，就不知道该补测什么。

**引理 20（Goodhart 间隙的增长与审计留出的必要性）** 设策略沿 M_opt 梯度做 T 步优化，gaming 方向与被优化方向的相关系数为 ρ_g，真实能力提升对 M_audit 的贡献为 κ。则期望间隙 `E[g] ≈ −κ·T·(1 − ρ_g) + noise`：当 M_audit 参与训练（ρ_g→1）时间隙被抹平、检测失效；当 M_audit 严格留出且与 gaming 方向正交（ρ_g≈0）时间隙以 Θ(T) 速率暴露博弈。系：**审计指标一旦泄题就不再是审计**——这正是定义 319 的 metric lock 与定义 310-ii 要防的。

**引理 21（多保真偏差校正的一致性）** 在 A100（b_{f→real} 对策略参数 L_b-Lipschitz）下，基于 n 个标定策略的偏差校正估计满足 `|M̂_real − M_real| ≤ L_b·Δ_f + O(n^{−1/2})`（Δ_f 为保真度间隔）。系：仿真可以便宜，但**必须用真机标定它的谎话**；保真度一致性（定义 314）是比单点分数更可信的质量信号。

**引理 22（选择性评测的覆盖-风险权衡）** 设弃权阈值为 τ_dis，已评分集合覆盖率为 c。在分歧与评分错误正相关（A101）下，已评分集合上的期望评测错误 ≤ 全体错误 − β·(1−c)（β 为分歧-错误协方差项）。系：弃权不是逃避，而是用覆盖率换可信度；但必须同时审计 abstain_rate 以防「用弃权藏失败」（定义 322）。

**定理 18（DEXA 严格包含 FLUID-RAS）** 在 A99–A101 下，DEXA 的选择规则在任意候选集上的**安全侧**不弱于 FLUID-RAS；当指标退化为标量、单保真、无博弈（g≥−τ_gap）、单一 Pareto 点、不弃权时，DEXA 的部署决策与 FLUID-RAS **逐指令相同**。由于评测层在外环运行、内环隔离（定义 310-i），任何评测失败只改变「下一轮选谁」，不改变当拍控制。因此 FLUID-RAS 是 DEXA 的「单指标-无博弈」边界退化，安全不让步。

**定理 19（Pareto 安全无退化与 VoE 有界悔）** (i) 若 R69 的选定策略满足 safety ≥ S_floor，则 MRG 的 `P_safe` 非空且选择不会返回更低 safety 的策略；任何「以安全换成功率」的候选被可行域直接排除，故不存在使安全单调下降的加权参数。(ii) 在评测预算 B_eval 下，VoE 贪心相对全知 oracle 的累计信息增益悔界为 `O(√(|𝒞|·B_eval·log n))`（次模性 + 贪心近似）。系：**评测预算应花在最能区分候选的地方，而不是平均撒**。

## 6. 本轮最大风险

**一句话**：DEXA-RAS 把评测升格为闭环一等公民，却让**评测层自己成为新的、不可被再审计的神谕**——audit 指标会随时间泄题、弃权会被用来「藏失败」、Pareto 安全下界本身可能被 gaming 悄悄推低，于是系统会以一种极其自信的姿态**优化掉它本该测量的东西**：**你得到的是你测的东西，不是你想要的东西。**

**次级风险与缓解**：
1. **audit 泄题/长期漂移**（引理 20）→ metric lock + 审计集物理隔离 + 定期换题 + E310；
2. **弃权被滥用为遮羞布** → abstain_rate 强制审计（定义 322）+ 覆盖率-风险双报（引理 22）；
3. **仿真偏差校正外推失效** → A100 的 Lipschitz 约束只在标定邻域成立，越界即降保真或弃权；
4. **Pareto 前沿自身被污染**（安全下界被悄悄下调）→ S_floor 冻结 + 变更需人类签署并写入 ledger；
5. **评测成本击穿预算** → VoE 子模贪心 + B_eval 硬约束 + 只在能区分候选处花预算（定理 19-ii）。

    F = decompose_traj(traj, phases)

def contact_integrity(tactile):
    return dict(slip_rate=slip(tactile), closure_margin=closure(tactile),
                chatter=jitter(tactile), force_peak=tactile.peak(),
                switch_count=count_switches(tactile))

def multi_fidelity_metric(policy, ladder, calib):
    est = {f: run_eval(policy, f) for f in ladder}   # sim / twin / real
    return debias(est, calib)                        # M̂_real + fidelity_consistency

# IP-267 VoE：评测是带成本的信息动作（VoI 对偶）
def choose_evaluation(policy, belief, budget):
    best = None
    for e in eval_candidates(policy, belief):
        if not budget.allow(e) or not risk_ok(e): continue
        score = mutual_info(quality; result_of(e)) - cost(e)
        if best is None or score > best.score: best = (e, score)
    return best if best and best.score > 0 else None  # 无利可图 → 不评测

# IP-268 GAD：Goodhart 间隙（优化指标 vs 留出审计指标）
def goodhart_gap(M_opt, M_audit):
    g = [a - o for a, o in zip(M_audit, M_opt)]
    return dict(gap=mean(g[-K_g:]), gaming=(mean(g[-K_g:]) < -TAU_GAP),
                unexplained=residual_of_ability(M_opt))

# IP-269 MRG：Pareto 安全选择（成功率不能交易安全）
def pareto_safe_select(cands, safety_floor):
    safe = [c for c in cands if c.safety >= safety_floor]
    if not safe: return None
    P = pareto_front(safe, keys=['success','gentleness','speed','generality'])
    return argmax(P, key=lambda c: c.efficiency_tiebreak)

# IP-270 MET-AB：不可识别/分歧大 → 弃权 + 回接 R69
def score_or_abstain(M_ph, disagreement):
    if disagreement > TAU_DIS or not identifiable_attr(M_ph):
        return ABSTAIN('metric_ambiguous', M_ph)
    return aggregate_constrained(M_ph)               # safety 分量不参与加权

## 4. 推导

**引理 19（相位可识别与失败归因）** A99 下相位签名可分离度 ≥ δ_ph 且接触事件可检测，则失败可唯一归因到相位（概率 ≥ 1−ε_ph）；纯终态 success 对标量指标对「哪相位失败」信息量为 0。系：归因是 R69「该问什么」的上游。

**引理 20（Goodhart 间隙与审计留出）** 沿 M_opt 优化 T 步、gaming 方向相关 ρ_g、真实能力贡献 κ，则 `E[g] ≈ −κT(1−ρ_g)+noise`；审计指标若参与训练（ρ_g→1）检测失效，严格留出且正交（ρ_g≈0）则间隙以 Θ(T) 暴露博弈。系：审计指标一旦泄题就不再是审计。

**引理 21（多保真偏差校正一致性）** A100 下 `|M̂_real − M_real| ≤ L_b·Δ_f + O(n^{−1/2})`。系：仿真可以便宜，但必须用真机标定它的谎话。

**引理 22（选择性评测覆盖-风险）** 弃权阈值 τ_dis、覆盖率 c、A101（分歧与错误正相关）下，已评分集错误 ≤ 全体错误 − β(1−c)。系：弃权用覆盖率换可信度，但须审计 abstain_rate 防藏失败。

**定理 18（DEXA 严格包含 FLUID-RAS）** A99–A101 下 DEXA 安全侧不弱于 FLUID；当指标为标量、单保真、无博弈、单 Pareto 点、不弃权时二者逐指令相同；且评测外环隔离（定义 310-i），评测失败只影响下一轮选谁、不改当拍控制。FLUID 是 DEXA 的「单指标-无博弈」退化。

**定理 19（Pareto 安全无退化与 VoE 有界悔）** (i) 若 R69 选定策略 safety ≥ S_floor，则 P_safe 非空且 MRG 不返回更低 safety 的策略；以安全换成功的候选被可行域直接排除。(ii) 预算 B_eval 下，VoE 贪心相对 oracle 的累计信息增益悔界 `O(√(|𝒞|·B_eval·log n))`（次模 + 贪心近似）。

## 7. 本轮最大风险

**一句话**：DEXA-RAS 把评测升格为一等公民，却让**评测层自己成为新的、不可再审计的神谕**——audit 会随时间泄题、弃权会被用来「藏失败」、Pareto 安全下界可能被 gaming 悄悄推低，于是系统会极其自信地**优化掉它本该测量的东西**：**你得到的是你测的东西，不是你想要的东西。**

**次级风险与缓解**：audit 泄题/漂移（metric lock + 物理隔离 + 换题 + E310）；弃权滥用为遮羞布（abstain_rate 强制审计 + 覆盖-风险双报）；仿真偏差外推失效（Lipschitz 仅标定邻域成立，越界降保真或弃权）；安全下界被悄悄下调（S_floor 冻结 + 人类签署 + ledger）；评测成本击穿预算（VoE 子模贪心 + B_eval 硬约束，只在能区分候选处花预算）。
