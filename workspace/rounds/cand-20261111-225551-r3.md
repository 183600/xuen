# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 1 轮重启；本轮灵感：「状态机」×「消融实验」）

> 第 54 轮把技能组合做成动作空间图 + 云边双证书（ACS/SCOM/CEC/AEC/JTC），但留下两个未解缺口：**(i) 组合是"一次性路径搜索"，没有刻画执行期技能模式切换、故障降级与恢复的时序语义**；**(ii) 动作-鲁棒性双证书的每个组件（α_S、γ_ce、Explain 回传、ρ）从未被单独证伪，无法回答"究竟是哪个机制在起作用"**。本轮用「状态机」补时序，用「消融实验」补归因。核心矛盾：H22：技能组合的"路径可行"不等于"执行期状态迁移安全"，缺失状态不变式会在模式切换处漏检；H23：多机制耦合下，整体性能提升可能来自单一组件甚至评测泄漏，缺乏消融归因的"联合证书"是伪科学。

## 0. 直觉与动机

**灵感 1（状态机：把技能组合从"路径"升级为"可执行自动机"）**
直觉：SCOM 给出的路径 `⟨S_1,...,S_k⟩` 只说明"能连起来"，没说明"跑起来会不会在切换瞬间掉进危险态"。把技能库编译成 **组合状态机 `M_S`**：状态 = 技能模式（approach / grasp / transport / release / recover / safe_stop），迁移 = 动作交接，**迁移守卫 guard** 由第 54 轮的 `compat`、`c_trans`、`ρ_comp` 与 `cover` 共同构成。组合规划于是从"最短路"变为"在乘积自动机上找一条**不变式保持**的接受路径"。这直接补上 H22：**可执行性 = 语言非空 ∧ 全部可达状态满足不变式**。

**灵感 2（执行期故障 → 显式 recover 状态与降级迁移）**
直觉：真实边端一定会有抓取失败、通信抖动、Explain 报错。状态机天然容纳这些：把失败建模为 `fault` 状态，把第 54 轮的 Explain 根因映射为 `fault → recover` 的**标签化迁移**，把"重剖分"映射为 `recover → 重新规划`。于是鲁棒性不再是一个标量谱，而是"**在哪些状态下还能迁回安全域**"的**可达性属性**。这把 ρ、γ_ce、Explain 统一进一个 Kripke 式结构，便于形式化验证。

**灵感 3（消融实验：把"多机制联合"拆成可识别贡献）**
直觉：v16++ 已经有 ACS/SCOM/CEC/AEC/JTC 五个算子，论文式地说"提升了 12%"是没有信息量的。必须做**受控消融**：分别移除 α_S、γ_ce、Explain 回传、ρ 耦合，测 `Δ_c = Perf(full) - Perf(full \ c)`，并报告置信区间。更强的是**因子消融**（2^k 设计）与 **Shapley 归因**，捕捉组件间交互（例如 Explain 只有在 γ_ce 被校准时才有效）。这让"创新点清单"从声明变成**可被证伪的实验命题**。

**灵感 4（消融指纹 → 每个机制都有"必要性证书"）**
直觉：光有平均 Δ 不够，要防止"看似有效其实是评测噪声/数据泄漏"。为每个组件生成 **消融指纹 `F_c = (Δ_c, CI, 交互项, 失效模式)`**，并附 **必要性证书**：只有当 `Δ_c` 的下置信界 > 噪声阈值、且在留出任务族上方向一致时，才允许在主张中称该组件"必要"。这是把统计严谨性写进产物，而不是事后补实验。

**灵感 5（状态机 × 消融的耦合：消融"状态不变式"本身）**
直觉：状态机也提供一个天然的消融维度——**去掉某条守卫 / 某个 recover 迁移**，看危险态可达性如何变化。于是消融不只是"去掉算法模块"，还可以"去掉安全约束"，从而量化**每个不变式的安全边际**。这形成 **机制消融（module ablation）× 约束消融（invariant ablation）** 的双轴实验矩阵，正好回答"这套系统靠的是算法还是靠保守约束"。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（组合执行状态机 CSM）**
技能库编译为标签迁移系统 `M_S = (Q, A, →, q_0, Q_f, I)`：
- `Q` 为模式状态集（含 `safe_stop`、`fault`、`recover`）；
- `A = A_c × A_e` 为第 54 轮动作空间；
- `→ ⊆ Q × A × Q` 为带守卫迁移 `(q,a,q') ∈ →` 当且仅当 `guard(q,a,q') = compat ∧ cover ∧ (c_trans ≤ τ_e)`；
- `I = {I_q}_{q∈Q}`，`I_q` 为状态不变式（`ρ(q) ≥ ρ_min ∧ δ_a(q) ≤ Θ_a ∧ q ∉ Unsafe`）；
- `Q_f ⊆ Q` 为任务接受态。
**可执行组合**当且仅当 `L(M_S) ≠ ∅` 且所有从 `q_0` 可达的 `q` 满足 `I_q`。

**定义 122（乘积自动机与同步）**
多技能组合 `M_{S_1} ⊗ ... ⊗ M_{S_k}`，对共享动作字母表 `A_shared` 做同步积，其余动作交错。组合可行 `feasible(⊗M) = (L(⊗M) ∩ L_task ≠ ∅)`。当 `|Q|` 爆炸时，用动作等价的 **商自动机** `M_S/≈`，`q≈q'` 当且仅当 `I_q=I_{q'}` 且后继守卫标签多重集相同。

**定义 123（状态不变式证书 SIC）**
`C_inv = (Q_reach, {I_q}, witness)`，其中 `Q_reach` 为 BFS 可达状态集，`witness: Q_reach → trace` 为到达该状态的仿真轨迹。**sound** 当且仅当 `∀q∈Q_reach, I_q=⊤`，否则给出反例轨迹 `τ_bad` 与首个违反状态。

**定义 124（消融算子）**
对组件集合 `C = {α, γ_ce, Explain, ρ, recover}`，消融算子 `Ablate(M,c)` 产生 `M^{-c}`（移除该机制的等价功能，其余保持同预算）。**边际贡献** `Δ_c = Perf(M) - Perf(M^{-c})`，`Perf` 可为部署成功率 / 危险态不可达率 / 成功率-成本帕累托。

**定义 125（消融指纹与可识别性）**
指纹 `F = (Δ_c, CI_{1-α}^{boot}, I_{c,d}, failmode_c)`，`I_{c,d}` 为组件 `c` 与 `d` 的交互项（因子设计）。**可识别**当且仅当 `lower(CI(Δ_c)) > ε_noise` 且留出任务族上符号一致率 `≥ 1-β`。不满足者只能称"弱证据"。

**定义 126（必要性证书 ANC）**
`C_nec(c) = (baseline, ablated, Δ_c, CI, ε_noise, heldout_consistency)`，若 `dom(C_nec)=in` 则称 `c` 在任务族上**必要**；否则称**冗余/可替代**。多个组件联合时报告 Shapley 值 `φ_c` 与总和校验 `Σφ_c = Perf(M) - Perf(M^{-C})`。

**定义 127（约束消融安全边际）**
移除守卫集合 `g⊆Guards` 后的危险态可达概率 `P_bad(g)`。**安全边际** `margin(g) = P_bad(g) - P_bad(∅)`。若 `margin(g) > δ_safe`，则该守卫被判定为"承担实质安全职责"，不可在部署中省略。

## 2. 关键算法 伪代码

### IP-121 CSM（Composition State Machine 编译）

```python
def compile_csm(skills, task_spec, theta_a, tau_e, rho_min):
    M = Automaton(states=[], trans=[], init='root', accept=[])
    for s in skills:
        for q in s.modes:                      # approach/grasp/.../recover
            M.add_state(q, invariant=inv(q, s.rho, rho_min))
        for (q, a, q2) in s.transitions:
            g = (compat(s, skills[q2.skill]) >= theta_a and
                 transition_cost(s, q2.skill) <= tau_e and
                 cover(s.alpha, a))
            M.add_trans(q, a, q2, guard=g)
    M.add_state('fault', invariant=True)
    M.add_state('recover', invariant=False)    # 恢复中暂不承诺
    M.add_trans('*', 'FAIL', 'fault', guard=True)
    M.add_trans('fault', 'EXPLAIN_ROOT', 'recover', guard=lambda e: e.converges)
    return quotient(M)                          # 商自动机，抑制状态爆炸
```

### IP-122 SIC（State Invariant Certification）

```python
def certify_invariants(M, sim_model, depth_cap=10_000):
    reach, witness = bfs_reach(M, cap=depth_cap)
    for q in reach:
        if not model_check(M.invariant[q], relations=M.env_relations):
            trace = witness[q] + sim_model.replay(q)
            return ('unsafe', q, trace,
                    explain_failure(trace, sim_model))   # 复用第 53 轮 Explain
    return ('safe', InvCert(reach, {q: M.invariant[q] for q in reach}, witness))
```

### IP-123 ABX（Ablation Engine，因子 + Shapley）

```python
def ablation_suite(config, tasks, seeds, factors=('alpha','gamma_ce','explain','rho','recover')):
    results = {}
    for mask in powerset(factors):              # 2^k 因子设计
        cfg = disable(config, mask)
        results[mask] = [run(cfg, t, s) for s in seeds for t in tasks]
    delta = {c: mean(results[frozenset()]) - mean(results[frozenset([c])])
             for c in factors}
    inter = {frozenset(p): interaction_effect(results, p)
             for p in combinations(factors, 2)}
    shapley = {c: shapley_value(c, factors, results) for c in factors}
    assert approx(sum(shapley.values()), mean(results[frozenset()]) -
                  mean(results[frozenset(factors)]))   # 总和校验
    return AblationReport(delta, inter, shapley, bootstrap_ci(results))
```

### IP-124 AFS（Ablation Fingerprint & Necessity）

```python
def necessity_certificate(c, report, eps_noise, heldout, beta=0.05):
    d, ci = report.delta[c], report.ci[c]
    consistency = sign_agreement(report, heldout, c)
    if ci.lower <= eps_noise:
        return ('weak', 'insufficient_signal', d, ci)
    if consistency < 1 - beta:
        return ('unstable', 'sign_flip_on_heldout', d, ci, consistency)
    return ('necessary', NecessityCert(d, ci, eps_noise, consistency, report.inter))
```

### IP-125 IAB（Invariant Ablation / 安全边际）

```python
def invariant_ablation(M, guards, sim_model, delta_safe):
    base = estimate_p_bad(M, guards, sim_model)
    margins = {}
    for g in guards:
        pg = estimate_p_bad(M, guards - {g}, sim_model)
        margins[g] = pg - base
    must_keep = {g for g, m in margins.items() if m > delta_safe}
    return SafetyMarginReport(margins, must_keep)
```

### IP-126 AGR（Ablation-Guided Runtime Degradation）

```python
def degrade_under_fault(active, failed_component, F):
    # 用消融指纹给出"先降级谁"的顺序，而非拍脑袋
    order = sorted(active, key=lambda c: F[c].delta)   # 贡献小的先降级
    plan = []
    for c in order:
        if c == failed_component: continue
        plan.append(('drop', c))
        if still_feasible(plan): return plan
    return [('safe_stop',)]                              # 宁可停机，不带病运行
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CSM | O(|S|·|Q_s| + |→|) | O(|Q|) | 守卫 sound、商等价保持语言 |
| SIC | O(|Q_reach|·|φ|) | O(|Q_reach|) | 不变式覆盖所有可达态 |
| ABX | O(2^{|C|}·N·T) | O(2^{|C|}·N) | 掩码无泄漏、随机种子配对 |
| AFS | O(|C|·B)（B 为 bootstrap 次数） | O(|C|·B) | CI 有效、留出族独立 |
| IAB | O(|G|·N_sim) | O(|G|) | 反事实采样一致 |

**正确性定理（State-Sound & Ablation-Identifiable Deployment）**
假设第 54 轮 (A26)–(A28) 成立；新增 **(A29)** CSM 的守卫 `guard` 对具体动作空间是 sound 的（即抽象迁移不引入非法跨状态）；**(A30)** 消融掩码不泄漏组件副产物，训练/评测种子配对；**(A31)** 留出任务族与消融任务族同分布（否则只报弱证据）。
则：(i) 若 `SIC=('safe',C_inv)` 且 `L(M_S)∩L_task≠∅`，则执行期不进入 `Unsafe`（在抽象-具体 refinement 成立下）；(ii) 若 `C_nec(c)=('necessary',...)` 且 `Σφ_c` 校验通过，则 `c` 的贡献可归因，部署主张 `Δ_c` 成立。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 状态空间爆炸 | 高 | 商自动机 + 对称约简 + 惰性展开 |
| 抽象状态机与连续动作空间 refinement 失配 | 高 | 精化映射证书 + 反例驱动抽象精化（CEGAR） |
| 消融掩码泄漏（移除 A 顺带改变 B） | 高 | 独立开关 + 副产物审计 + 预算对齐 |
| 多重比较导致假阳性 | 中 | Holm–Bonferroni + 预注册指标 |
| 交互项组合爆炸 | 中 | 只测假设驱动的成对交互 + Shapley 采样近似 |
| 用消融顺序做降级引发新故障 | 中 | 降级前后都过 SIC + safe_stop 兜底 |

## 6. 本轮最大风险

**一句话**：状态机把组合从"路径可行"升级为"可达态安全"，消融实验把"联合提升"升级为"可归因主张"，但两者叠加的最大风险是 **抽象-归因双重失真**——一旦 CSM 的守卫在连续动作空间上不是 sound refinement（抽象安全而具体越界），同时消融掩码又暗含副产物泄漏（移除某机制顺带削弱了另一机制），那么"SIC 通过 + Δ_c 显著"会共同制造一个既**看似安全**又**看似有因果贡献**的部署结论，而真实边端可能在模式切换处系统性失效；故必须以 **CEGAR 精化证书 + 副产物审计/预算对齐 + 留出族符号一致率** 三重护栏，宁可报告"弱证据/unsafe"，绝不把消融出来的显著性当作安全与创新的证明。

```python
def compile_csm(skills, task_spec, theta_a, tau_e, rho_min):
    M = Automaton()
    for s in skills:
        for q in s.modes:
            M.add_state(q, inv=And(GE(s.rho, rho_min), LE(s.delta_a, THETA_A),
                                   NotIn(q, UNSAFE)))
        for (q, a, q2) in s.transitions:
```

### IP-122 SIC（不变式证书 + CEGAR 触发）

```python
def certify_invariants(M, sim_model):
    reach, witness = bfs_reach(M, cap=10_000)
    for q in reach:
        if not model_check(M.inv[q], M.env_relations):
            trace = witness[q] + sim_model.replay(q)
            exp = explain_failure(trace, sim_model)
            if exp.root in M.action_abstraction:
                return ('refine', exp.root, trace)      # 交给 IP-127 CEGAR
            return ('unsafe', q, trace, exp)
    return ('safe', InvCert(reach, {q: M.inv[q] for q in reach}, witness))
```

### IP-123 ABX（因子 + Shapley + CI）

```python
def ablation_suite(config, tasks, seeds, C=('alpha','gamma_ce','explain','rho','recover')):
    R = {}
    for mask in powerset(C):
        cfg = disable(config, mask)
        R[mask] = [run(cfg, t, s, paired=True) for t in tasks for s in seeds]
    base, full = mean(R[frozenset()]), mean(R[frozenset(C)])
    delta = {c: base - mean(R[frozenset([c])]) for c in C}
    inter = {frozenset(p): interaction_effect(R, p) for p in combinations(C, 2)}
    phi = {c: shapley(c, C, R) for c in C}
    assert abs(sum(phi.values()) - (base - full)) < 1e-6   # 总和校验
    return AblationReport(delta, inter, phi, bootstrap_ci(R, n=1000))
```

### IP-124 AFS（必要性证书）

```python
def necessity_certificate(c, rep, eps_noise, heldout, beta=0.05):
    d, ci = rep.delta[c], rep.ci[c]
    cons = sign_agreement(rep, heldout, c)
    if ci.lower <= eps_noise:
        return ('weak', 'insufficient_signal', d, ci)
    if cons < 1 - beta:
        return ('unstable', 'sign_flip_on_heldout', d, ci, cons)
    return ('necessary', NecessityCert(d, ci, eps_noise, cons, rep.inter))
```

```python
def invariant_ablation(M, guards, sim_model, delta_safe):
    base = estimate_p_bad(M, guards, sim_model)
    margins = {g: estimate_p_bad(M, guards - {g}, sim_model) - base for g in guards}
```

其中 `ε_abs` 由 CEGAR 精化轮数控制。**关键**：安全来自状态不变式，归因来自受控消融，两者都必须有**反例/留出集**背书。

## 6. 本轮最大风险

**一句话**：状态机把组合从"路径可行"升级为"可达态安全"，消融实验把"联合提升"升级为"可归因主张"，但两者叠加的最大风险是 **抽象-归因双重失真**——一旦 CSM 的守卫在连续动作空间上不是 sound refinement（抽象安全而具体越界），同时消融掩码又暗含副产物泄漏（移除某机制顺带削弱了另一机制），那么"SIC 通过 + Δ_c 显著"会共同制造一个既**看似安全**又**看似有因果贡献**的部署结论，而真实边端可能在模式切换处系统性失效；故必须以 **CEGAR 精化证书 + 副产物审计/预算对齐 + 留出族符号一致率** 三重护栏，宁可报告"弱证据/unsafe"，绝不把消融出来的显著性当作安全与创新的证明。
