# 第 1 轮 · 灵感词：语音交互 × 续航能力

## 0. 直觉解释（先讲人话）

语音是人和机器人之间最自然的接口，但它也是最不可信的接口：远场噪声、口音、多人同时说话、录音回放、超声波注入，都可能让机器人「听错」，甚至「听到根本没人说过的话」。续航则是机器人最慢、最有状态性的资源：电量不是一次性扣掉的常数，而是随任务、地形、负载、温度、电池老化漂移的随机过程；一个「看起来没问题」的任务，可能在返程途中把机器人变成路障。

把两者放在一起，会出现单独看谁都发现不了的耦合：

1. **语音命令决定能量需求的分布**——「去三楼取件」与「去门口取件」的能耗尾部风险完全不同，不能先理解再单独算电。
2. **电量状态决定哪些澄清是负担得起的**——低电量时反复追问用户会额外耗电，甚至错过安全返航窗口。
3. **两者共享同一个时间视界**——语音理解、确认、重问的延迟，会直接吃掉续航预算。

所以本轮的核心主张不是「再加两个证书」，而是：**语音命令必须被当作「意图提案」而不是「计划」；续航必须被当作「整条计划的概率预算约束」而不是一个标量；二者必须联合认证，并在预算不足或意图歧义时，用「可认证的对话」去收缩而不是扩大可执行集。**

## 1. 严谨定义（最小内核）

**语音观测。** 令 `u` 为一段原始音频，ASR 给出 n-best 候选 `H(u) = {(h_i, p_i)}`。我们只承认「候选内」的意图：若真实意图不在 `H(u)` 中，系统必须输出 `UNKNOWN` 并转入澄清，绝不静默补全。

**意图集。** 以非一致性分数 `s(u,c) = 1 - p_θ(c|u)` 在独立校准集上取 `(1-α)` 分位数 `q̂_α`，定义
`I_α(u) = { c ∈ C(u) : s(u,c) ≤ q̂_α }`。
在可交换性下，`P(y_true ∈ I_α(u)) ≥ 1-α`；但该保证**不覆盖**对抗性声学注入与口音/远场造成的协变量漂移，因此需要额外的硬门（活体、说话人、OOD）。

**活体与说话人。** `Live(u) ≜ fresh_nonce ∧ challenge_match ∧ ultrasonic_band_ok`；`Spk(u) ≜ cos(E(u), E_enrolled) ≥ τ_spk`，阈值按误接受率 `≤ ε_spk` 校准。活体与说话人是**硬门**，不参与 conformal 的统计交换。

**语义接地。** `g: c → 目标谓词`；`Ground(c, Ξ) ≜ Entail(Ξ, g(c))`，其中 `Ξ` 是场景图 + 规范权限集。语音安全谓词要求：意图集中所有「可接地」候选必须要么指向同一个可执行计划，要么触发澄清；禁止在多个可执行候选之间擅自选一个。

**续航谓词。** 电池状态 `b = (SoC, SoH, T)`，计划 `π` 的随机能耗为 `E(π; b, Ξ)`，安全返航/安全停驻能量为 `R_safe(Ξ)`。定义
`Endur_β(π) ≜ P(SoC - E(π) - E_dialog ≥ R_safe) ≥ 1-β`。
为保证计划可组合，实际用相干风险度量 `CVaR_β` 的上界：`SoC - CVaR_β(E) - E_dialog ≥ R_safe`，因为 `CVaR_β ≥ VaR_β`，故可推出上式。

**可认证对话。** 对话动作集 `A = {Clarify, Propose, Confirm(π, hash, nonce), Abort}`。任何 `Confirm` 必须绑定到「当前提案的计划哈希 + 新鲜 nonce」；对话只能收缩候选计划集，不能授予 DCL 之外的新权限。

**联合准入。** `Exec_v24 = Exec_v23 ∩ {π : VoiceSafe(u) ∧ Endur_β(π) ∧ CEND(π, u)}`。其中 `CEND` 只校验「确认是有效的且没有越权」，不重新发明语音/续航判据。

## 2. 研究假设（可证伪）

- **H1（意图覆盖）**：在同分布远场语音上，`I_α(u)` 的经验覆盖率可稳定达到 `1-α`；在回放/超声注入集上，`Live` 的拦截率 `≥99%`，且正常语音误拒 `≤2%`。
- **H2（续航保守性）**：用 CVaR 上界准入的计划，其真实「返航电量违约率」`≤ β + δ`（`δ` 为能耗模型估计失败概率）。
- **H3（对话不扩张）**：引入对话后，`Exec_v24 ⊆ Exec_v23` 恒成立；任何「用户说可以」都不能绕过 `VoiceSafe` 或 `Endur_β`。
- **H4（耦合收益）**：相比「先语音、再单独算续航」的串行基线，联合认证在「低电量 + 远距离语音指令」场景下把「中途抛锚率」降低一个数量级，而任务完成率下降不超过 5%。

## 3. 与 v23 的接口

- 复用 `GIC`（手势意图证书）做跨模态一致性：语音与手势冲突时只允许澄清或安全停驻，绝不取平均。
- 复用 `DCL`（义务层）判断语音意图是否被允许；复用 `ACSC` 估计机械臂动作能耗；复用 `CESC` 的版本五元组，把语音模型/校准器也纳入版本原子切换。
- 新增 `VGLC`（语音接地与活体证书）、`EVC-B`（续航可行性证书）、`CEND`（可认证能量协商）、`HPC-E++`（联合准入门）。

## 4. 下一步

1. 形式化「意图集—计划集—能量尾部」三者的联合单调性；
2. 设计低电量下的对话效用函数（信息增益 vs. 交互能耗 vs. 认知负担）；
3. 构造对抗语音 + 电池老化的联合故障注入实验；
4. 在 50Hz 控制环外做异步语音理解，验证端到端延迟不退化。

## 5. 本轮最大风险（一句话）

**最大的风险是：语音意图的 conformal 覆盖与续航的 CVaR 估计都建立在可交换性/平稳性假设上，而对抗性声学注入与电池老化恰恰可以同时破坏这两个假设，使系统在「意图被误判 + 续航被高估」的双重条件下仍然签发证书。**

```python
# ============================================================
# IP-440 VGLC — 语音意图接地与活体证书
# ============================================================
@dataclass
class VoiceGroundingCertificate:
    asr: 'ASREngine'
    intent_model: 'IntentClassifier'
    calibrator: 'ConformalCalibrator'      # 持有 q̂_α
    speaker_verifier: 'SpeakerVerifier'
    liveness: 'LivenessDetector'
    alpha: float = 0.01
    epsilon_spk: float = 1e-3
    tau_spk: float = 0.85
    ood_detector: 'AcousticOOD' = None

    def liveness_ok(self, u: Audio) -> bool:
        # 随机 nonce 挑战短语 + 超声频带能量检查 + 通道指纹
        return (self.liveness.fresh_nonce(u)
                and self.liveness.challenge_match(u)
                and self.liveness.ultrasonic_band_ok(u))

    def speaker_ok(self, u: Audio) -> bool:
        return self.speaker_verifier.score(u) >= self.tau_spk

    def intent_set(self, u: Audio) -> set[Intent]:
        H = self.asr.nbest(u, k=10)
        C = {h.intent for h in H}
        if not C or self.ood_detector.is_ood(u):
            return set()                      # 空集 → 必须澄清/拒绝
        scores = {c: 1.0 - self.intent_model.posterior(u, c) for c in C}
        q = self.calibrator.quantile(self.alpha)
        return {c for c in C if scores[c] <= q}

    def admits(self, u: Audio, scene: 'Scene', dcl: 'DeonticLayer'
               ) -> tuple[bool, set[Intent], str]:
        if not self.liveness_ok(u):
            return False, set(), "LIVENESS_FAIL"
        if not self.speaker_ok(u):
            return False, set(), "SPEAKER_FAIL"
        I = self.intent_set(u)
        if not I:
            return False, set(), "UNKNOWN_INTENT"

        # 关键：不是「找一个能执行的」，而是「所有候选都必须可接地且被允许」
        plans = set()
        for c in I:
            if not (Ground(c, scene) and Permit(c, scene, dcl)):
                return False, I, "UNGROUNDED_OR_FORBIDDEN"
            plans.add(plan_of(c, scene))

        if len(plans) != 1:
            # 多个可执行候选 → 不允许静默择一，交给 CEND 澄清
            return False, I, "AMBIGUOUS_ACTIONABLE_INTENT"
        return True, I, "OK"


# ============================================================
# IP-441 EVC-B — 续航可行性证书（CVaR 尾部预算）
# ============================================================
class EnduranceViabilityCertificate:
    def __init__(self, energy_model: 'EnergyEnsemble', beta: float = 0.05,
                 delta: float = 1e-3, safety_factor: float = 1.1):
        self.energy_model = energy_model   # 物理模型 + 数据残差集成
        self.beta = beta                   # 尾部违约概率
        self.delta = delta                 # 能耗上界估计失败概率
        self.safety_factor = safety_factor
        self.soc: float = 1.0
        self.soh: float = 1.0
        self.temp: float = 25.0
        self.cvar_residual_q: float = 0.0  # conformal 残差上界

    def update_battery(self, soc: float, soh: float, temp: float):
        self.soc, self.soh, self.temp = soc, soh, temp

    def energy_cvar_upper(self, plan: 'Plan', scene: 'Scene') -> float:
        # 1) 物理基线：运动学 + 负载 + 坡度 + 热管理
        e_phys = self.energy_model.physics(plan, scene)
        # 2) 学习残差的 (1-β) conformal 上界（含 safety_factor）
        e_hat = e_phys + self.cvar_residual_q
        # 3) 电池老化/温度修正：SoH 越低、温度越极端，可用能量越少
        derate = self._derate(self.soh, self.temp)
        return self.safety_factor * e_hat / max(derate, 1e-3)

    def safe_return_energy(self, scene: 'Scene') -> float:
        # 最近的坞站/安全停驻点，含通信信标与不可预见余量
        return min_cost_return(scene) + beacon_energy(scene) + margin(scene)

    def admits(self, plan: 'Plan', scene: 'Scene',
               e_dialog: float = 0.0) -> bool:
        return (self.soc - self.energy_cvar_upper(plan, scene) - e_dialog
                >= self.safe_return_energy(scene))

    def endurance_horizon(self, plan: 'Plan', scene: 'Scene') -> float:
        # 二分搜索最长的可执行时长，使 Endur_β 仍成立
        lo, hi = 0.0, plan.max_duration
        while hi - lo > 1e-2:
            mid = (lo + hi) / 2
            if self.admits(plan.truncate(mid), scene):
                lo = mid
            else:
                hi = mid
        return lo

    def viability_kernel(self, plans: list['Plan'], scene: 'Scene') -> set['Plan']:
        return {p for p in plans if self.admits(p, scene)}


# ============================================================
# IP-442 CEND — 可认证能量协商（对话只收缩、不扩张）
# ============================================================
class CertifiedEnergyNegotiation:
    def __init__(self, vglc: VoiceGroundingCertificate,
                 evc: EnduranceViabilityCertificate,
                 max_turns: int = 2):
        self.vglc = vglc
        self.evc = evc
        self.max_turns = max_turns
        self.pending: Optional['Proposal'] = None

    def propose(self, u: Audio, scene: 'Scene', dcl: 'DeonticLayer'
                ) -> 'Decision':
        ok, I, reason = self.vglc.admits(u, scene, dcl)
        if reason == "AMBIGUOUS_ACTIONABLE_INTENT":
            return self._clarify_intent(I, scene)
        if not ok:
            return Decision.refuse(reason)

        plan = plan_of(next(iter(I)), scene)
        if not self.evc.admits(plan, scene):
            return self._negotiate_energy(plan, I, scene)
        return self._confirm(plan)

    def _clarify_intent(self, I: set[Intent], scene: 'Scene') -> 'Decision':
        # 只允许在 I_α 内追问；选项按「能量可行 + 信息增益」排序
        options = sorted(I, key=lambda c: self._utility(c, scene))
        return Decision.ask(options[:3], e_dialog=self._dialog_cost())

    def _negotiate_energy(self, plan: 'Plan', I: set[Intent],
                          scene: 'Scene') -> 'Decision':
        # 给出收缩后的替代方案：就近目标 / 先返航 / 分阶段执行
        alternatives = [plan.nearer_goal(), plan.return_now(),
                        plan.staged(max_leg=self.evc.endurance_horizon(plan, scene))]
        feasible = [p for p in alternatives if self.evc.admits(p, scene)]
        if not feasible:
            return Decision.safe_stop("ENERGY_INFEASIBLE")
        return Decision.ask_plan_choice(feasible[:2])

    def _confirm(self, plan: 'Plan') -> 'Decision':
        self.pending = Proposal(plan, hash(plan), new_nonce())
        return Decision.ask_confirm(self.pending)

    def handle_confirm(self, u_confirm: Audio, scene: 'Scene') -> 'Decision':
        # 确认也必须过活体/说话人，且必须命中当前计划的 hash + nonce
        if self.pending is None:
            return Decision.refuse("NO_PENDING_PROPOSAL")
        if not (self.vglc.liveness_ok(u_confirm)
                and self.vglc.speaker_ok(u_confirm)):
            return Decision.refuse("CONFIRM_AUTH_FAIL")
        if not self.pending.matches(u_confirm, hash(self.pending.plan)):
            return Decision.refuse("STALE_OR_MISBOUND_CONFIRM")
        # 对话不扩张：确认后仍要复核续航与规范
        if not self.evc.admits(self.pending.plan, scene):
            return Decision.safe_stop("ENERGY_CHANGED")
        return Decision.accept(self.pending.plan)


# ============================================================
# IP-444 CMIC — 跨模态意图一致性
# ============================================================
class CrossModalIntentConsistency:
    def __init__(self, conflict_margin: float = 0.1):
        self.conflict_margin = conflict_margin

    def agrees(self, I_voice: set[Intent], I_gesture: set[Intent]
               ) -> tuple[bool, str]:
        if not I_gesture:
            return True, "VOICE_ONLY"
        inter = I_voice & I_gesture
        if inter:
            return True, "AGREE"
        # 无交集 → 不允许平均/优先级覆盖，只能澄清或安全停驻
        return False, "CONFLICT"


# ============================================================
# IP-443 HPC-E++ — 意图—能量联合准入门
# ============================================================
@dataclass
class HPCEPlusPlus:
    hpce_plus: 'HPCEPlus'
    vglc: VoiceGroundingCertificate
    evc: EnduranceViabilityCertificate
    cend: CertifiedEnergyNegotiation
    cmic: CrossModalIntentConsistency

    def admits(self, plan: 'Plan', u: Audio, scene: 'Scene',
               battery: tuple[float, float, float],
               modules: list[str], gesture: Optional['GestureObs'] = None,
               e_dialog: float = 0.0) -> bool:
        # 1. v23 基础四证（物理接地/云边同步/少样本/IP）
        if not self.hpce_plus.admits(
                plan, scene.x, scene.v, scene.z, scene.E_res,
                scene.margin_req, modules):
            return False

        # 2. 语音意图证书
        ok_v, I_v, _ = self.vglc.admits(u, scene, scene.dcl)
        if not ok_v:
            return False

        # 3. 跨模态一致性（若存在手势）
        if gesture is not None:
            I_g = gesture.intent_set()
            agree, _ = self.cmic.agrees(I_v, I_g)
            if not agree:
                return False

        # 4. 续航可行性（含本轮对话能耗）
        self.evc.update_battery(*battery)
        if not self.evc.admits(plan, scene, e_dialog):
            return False

        # 5. 可认证协商（确认必须绑定当前计划）
        if not self.cend.consistent(plan, u):
            return False

        return True


# ============================================================
# CFC++++：在 CFC+++ 上增加语音/续航/计划哈希一致性
# ============================================================
class CertificateFederatedConsensusPlusPlusPlusPlus(
        CertificateFederatedConsensusPlusPlusHierarchical):
    def consensus_round(self, timeout=5.0):
        results = {}
        for key, votes in self.votes.items():
            base_ok = super()._base_checks(votes)          # 计数/模态/层级/云边/少样本/IP
            voice_ok = all(v.voice_grounded for v in votes.values())
            energy_ok = all(v.endurance_ok for v in votes.values())
            # 关键：同一轮共识必须绑定同一计划哈希，防止把不同语音命令“合并”
            hash_ok = len({v.plan_hash for v in votes.values()}) == 1
            if all([base_ok, voice_ok, energy_ok, hash_ok]):
                results[key] = self._majority_with_outlier_filter(votes)
            else:
                results[key] = "CI"
        return results
```

## 2. 复杂度分析

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| VGLC 活体/说话人 | O(L)（L 为音频帧数） | O(L) | `ε_spk=1e-3`, `α=0.01` |
| VGLC conformal 意图集 | O(K·|C|)（K=n-best） | O(|C|) | `K=10` |

| EVC-B 续航视界二分 | O(log(T/ε)·M·H) | O(1) | `ε=10ms` |
| CEND 单轮协商 | O(|I|·M·H + log T) | O(|I|) | `max_turns=2` |
| CMIC 一致性 | O(|I_v|+|I_g|) | O(1) | — |

## 3. 正确性论证

### 引理 5（语音意图的覆盖—接地联合可靠性）
**陈述**：设校准语音与测试语音可交换，且 ASR 闭世界召回 `P(y ∈ C(u)) ≥ 1−γ`。若 `VGLC.admits(u,Ξ)=True`，则真实意图 `y` 可接地、被规范允许，且执行计划等于 `plan(g(y))` 的概率至少 `1−α−γ`。

**证明**：
1. 可交换性下 conformal 集满足 `P(y ∈ I_α(u)) ≥ 1−α`；闭世界召回给出 `P(y ∈ C(u)) ≥ 1−γ`。故 `P(y ∈ I_α(u)) ≥ 1−α−γ`。
2. `admits` 要求 `I_α(u)` 中**每一个**候选都满足 `Ground ∧ Permit`，因此当 `y ∈ I_α` 时，`y` 必可接地且被允许。
3. `admits` 还要求所有候选的接地计划集合大小为 1；因此 `plan(g(y))` 等于被签发的唯一计划。
4. 活体与说话人是独立硬门，不依赖 conformal 交换性；它们只可能进一步拒绝，不会放宽上述结论。
∎

> 注：该引理在对抗性声学注入/强协变量漂移下不成立（可交换性被破坏）。缓解见 R6：活体硬门 + ACI（自适应 conformal）+ OOD 拒识；此时只保留「拒绝率」保证，不保留覆盖保证。

### 引理 6（CVaR 续航预算的违约界与可组合性）
**陈述**：若 `E_CVaR` 是 `E(π)` 的 `(1−β)` 上界（即 `P(E ≤ E_CVaR) ≥ 1−β`），且 `Endur_β(π)` 成立，则 `P(SoC − E(π) − E_dialog ≥ R_safe) ≥ 1−β`。若能耗非负，则对任意子计划 `π' ⊆ π`，`Endur_β(π) ⇒ Endur_β(π')`。

**证明**：
1. 由 `CVaR_β(E) ≥ VaR_β(E)` 得 `P(E > CVaR_β(E)) ≤ β`；`Endur_β` 用 `CVaR_β` 作预算，故尾部违约概率不超过 `β`。
2. 能耗非负 ⇒ `E(π') ≤ E(π)` 逐点成立；CVaR 对随机变量单调，故 `CVaR_β(E(π')) ≤ CVaR_β(E(π))`，子计划仍满足同一 `R_safe` 约束。
3. 计划拼接：CVaR 满足次可加性 `CVaR_β(E₁+E₂) ≤ CVaR_β(E₁)+CVaR_β(E₂)`，因此分段执行的预算上界可直接相加，不会因组合而低估尾部。
4. 估计误差：若能耗上界以概率 `δ` 失效，则总违约界为 `β+δ`。
∎

### 引理 7（可认证对话不扩张执行集）
**陈述**：对任意对话轨迹，`CEND` 只从 `Exec_v23 ∩ {VoiceSafe} ∩ {Endur_β}` 中选择计划；因此 `Exec_v24 ⊆ Exec_v23`，且重放旧确认不能改变当前计划。

**证明**：
1. `CEND.propose` 只在 `VGLC.admits` 通过后构造计划；`_negotiate_energy` 的候选均由 `plan` 收缩得到（就近目标/返航/分段），不新增权限。
2. `handle_confirm` 校验 `Live ∧ Spk ∧ hash(plan) ∧ nonce`；旧确认的 nonce 或 hash 不匹配即拒绝，故不可重放。
3. 确认后仍复核 `EVC-B`；对话本身不修改 `DCL` 权限集，也不修改 `Exec_v23`。
4. 因此任何对话可达计划都属于 `Exec_v23`，执行集单调不增。
∎

### 引理 8（意图—能量联合单调退化链）
**陈述**：`Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ …` 恒成立；任一层失效只减少可执行计划，不新增。

**证明**：
- `HPC-E++` 是 `HPC-E+` 与 `VGLC/EVC-B/CEND/CMIC` 的合取，合取只会缩小集合。
- 语音不可用 → `VoiceSafe=false` → 退回 `Exec_v23`（纯 v23 能力）；续航不可行 → 进入安全停驻/返航，不执行原计划；对话失败 → 拒绝，不扩张。
- 组合失效取交集，单调性保持。
∎

### 定理（HPC-E++ 的意图—能量联合可靠性）
**陈述**：若 `HPC-E++.admits(π)=True`，则在统计假设（引理 5–6）成立时，π 同时满足：(1) v23 的物理/合规/云边/IP 四证；(2) 真实语音意图以 `≥1−α−γ` 概率被正确接地且被规范允许；(3) 以 `≥1−β−δ` 概率保留安全返航/停驻能量；(4) 对话确认不可越权、不可重放。

**证明**：由 `admits` 的五段合取与引理 5–8 直接可得。必要性：任一条件缺失即拒证或转澄清/安全停驻；充分性：五段全通过时，执行集是 v23 的子集，且语音与续航的统计承诺同时成立。
∎
