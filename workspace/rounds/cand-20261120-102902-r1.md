# 第 2 轮（UniBot 线 · 第 2 轮；本轮灵感：「多机协作」×「语音识别」）

> **延续声明**：不重新基线化。第 1 轮 UniBot-SAGE 的 U1–U12 / L1–L7 / E601–E618 全部保留为 v1；本轮在其上做「两个放大器 + 一个闸门」，新增 U13–U22 / L8–L13 / E619–E632。第 1 轮的剪枝预案（保 IP-06/02/03，IP-01 先过合规）继续有效。

## 0. 上一轮留下的两个「未决口」

1. **路由是硬 argmax**：U2 用 `argmax cos(E_L(ℓ), e_k)` 选任务 token，低于阈值才退通用 token。这是**单点故障**：指令被改写、含未见物体名、或有人插话时，错误 token 会静默地把整条 episode 交给错误专家，且没有任何「我可能错了」的信号。第 1 轮 Q3 只讨论了「多专家是否合规」，没讨论「token 本身错了怎么办」。
2. **双手被当成一只手**：32 任务含双手协调，Dex1 每手只有 1 维开合；第 1 轮把抓握做成单臂隐变量，但没建模「两只手如何分工」。在 Unlock / Open Pill Bottle / Plug In Ethernet 这类任务里，「一只手稳住、一只手操作」往往就是成败分界。

本轮两个灵感词恰好各补一个口子——但不是字面照搬（见 §1 的「不要误读」）。

## 1. 直觉解释（先直觉，后定义）

### 1.1 「语音识别」给的不是语音，是**解码范式**

- **直觉**：ASR 从不「听一个音就定一个词」。它保留声学后验，用语言模型做先验，用 beam search 保留 N-best，用置信度决定「要不要让用户再说一遍」。**它把「识别」当成一个可以晚点再决定、可以主动补证据的过程。**
- **迁移**：UniBot 的 `observation.language` 就是我们的「声学观测」，32 个任务原型是「词表」，任务-阶段语法是「语言模型」，场景里看得见的物体是「视觉重打分」，而「请再说一遍」对应一个**具身探针动作**（移动到能看清 / 能区分的位置）。第 1 轮的 `z_task` 应从「一次 argmax」升级为「带置信度的技能后验 q_t(k)，并允许主动消歧」。
- **不要误读**：我们不假设评测端有语音、也不新增麦克风；迁移的是**解码与置信度机制**，输入仍是文本指令。

### 1.2 「多机协作」给的不是更多机器人，是**角色 + 共享信念**

- **直觉**：协作的本质不是「数量多」，而是「**谁负责哪一部分、彼此对世界有一份共同信念、出问题能换手**」。
- **两个尺度**：
  - **单机双臂（真协作）**：左右臂就是两个 agent，共享一个物体信念 `b_o`（位姿 / 稳定 / 是否被夹住），角色在「稳住（hold）/ 操作（act）」之间分配。很多任务不是「两只手各做各的」，而是「一只手提供约束，另一只手才能完成动作」。
  - **机队服务（弱协作）**：评测端是 N 台**互不通信**的机器人，共享一个后端。「协作」只能发生在**服务层与先验层**：共享的是 playbook（离线标定的先验、延迟预算、批处理调度），**绝不共享 memory（episode 状态）**。这一点必须写成可测的不变量，否则会踩「隔离 / 单模型」红线。
- **不要误读**：我们不做跨机器人通信、不做联邦在线学习；机队层的「协作」严格限定为**离线先验 + 在线调度**。

### 1.3 合成

第 1 轮是「接地（抓握）→ 技能（路由）→ 适应（上下文）→ 工程」。本轮把它升级为一条**决策链**：

**Decode（语言→技能后验）→ Assign（双臂角色）→ Verify（抓握确认）→ Coordinate（换手 / 消歧）→ Serve（机队调度）**。

新增的两个模块都是**放大器**：它们只在「基座已经有一点能力」时放大收益；基座若在插入 / 对齐上根本不会，放大器只会让失败更「有条理」。因此本轮同时引入一个**能力闸门**（competence gate）——这可能是本轮最重要的负结果保护。

## 2. 为什么现在做（可证伪的动机，不靠新数字）

第 1 轮的 teaser 数字继续有效，但本轮不新增榜单事实；以下三条是**结构性假设**，每条都配了能杀死它的实验：

- **H1（语言是 OOD 主通道之一）**：5 类泛化场景里「未见物品 / 人为干扰 / 指令改写」都会让 `ℓ` 与训练分布偏移。若 H1 真，则 N-best + 消歧应显著优于 argmax；若 E619 显示 argmax 已足够稳，则 IP-09 降级。
- **H2（双手子集需要外部约束）**：部分任务在单臂下**原理上**需要环境提供第二个约束（否则物体在操作时会转 / 滑）。若 H2 真，角色分配有正边际；若 E622 显示单臂已能完成，则 IP-10 降级。
- **H3（机队层是可信度风险而非能力风险）**：官方采集 per-step 延迟 / 规律性并评估可信度 ⇒ N 端口下的排队与批处理会直接变成「分数外的风险」。若 E625 显示 p99 已在预算内，则 IP-11 只保留审计、不做调度。

## 3. 研究问题（Q6–Q10）

- **Q6（解码）**：在指令改写 / 未见物体 / 人为干扰下，带置信度与主动消歧的技能后验，能否在**不增加净耗时**的前提下，把「错误路由导致的整段失败」降下来？置信度能否校准到「可用来决定要不要探针」的程度？
- **Q7（双臂）**：把左右臂建成「共享物体信念 + 角色分配 + 换手」的协作策略，是否在双手子集上优于一个统一单策略？收益来自「表达力」还是「数据效率 / 信用分配」？（这两者含义完全不同。）
- **Q8（机队）**：哪些跨端口信息可以共享而不违反隔离与单模型？「共享 playbook、不共享 memory」能否写成可审计的不变量，并用测试证明？
- **Q9（调度）**：在 N 端口并发下，批处理 / 准入控制能否在提升吞吐的同时守住 per-port p99 与动作规律性？前沿曲线长什么样？
- **Q10（闸门）**：这些放大器是否存在一个「能力阈值」——基座成功率低于它时，放大器的边际收益为负（因为探针耗时、角色切换引入抖动）？

## 4. 设计原则（P1–P6 之上加 P7–P10）

- **P7 解码而非分类**：任何「任务 / 阶段」判断都保留后验与置信度；高熵时不硬提交，先问「能不能用一步观测把熵降下来」。
- **P8 协作在 checkpoint 内**：角色分配必须是同一策略网络的条件化（role token），不允许外部编排进程 / 多模型投票，避免「多模型」合规争议。
- **P9 共享 playbook，不共享 memory**：跨端口只允许离线得到的、身份不可反演的聚合先验；在线 episode 状态严格隔离，并写成可测不变量。
- **P10 放大器必须过闸门**：新增模块默认关闭；只有基座代理成功率 ≥ s0 且解码校准 ≤ e0 时才启用，否则预算回流到基座 / 接地。

## 5. 最小闭环与退化链（v2）

**MVP2 = 第 1 轮 MVP（IP-06 代理评测 + IP-02 抓握确认 + IP-03 缝合）+ IP-09 解码器 + IP-10 双臂角色（仅双手子集）+ IP-12 能力闸门。**

退化链（逐级回退，不漂移）：

- 解码后验熵高且探针无收益 ⇒ 退回第 1 轮 argmax（但不静默：记录「低置信路由」计数）；
- 双臂角色置信度低 / 检测到抖动 ⇒ 退回统一单策略；
- 机队先验不可用 ⇒ 退回训练集静态先验；
- 能力闸门不通过 ⇒ **关闭全部放大器**，只提交 v1 SAGE + 基线安全网；
- 任一新增模块异常 ⇒ 整链回退到 v1 的 Level-0…Level-4。

## 6. 预期贡献（可验收）

1. 一套**具身指令解码器**：技能后验 + 校准 + 主动消歧，把「路由单点故障」变成「可观测、可回退的歧义」。
2. 一个**双臂协作形式化**：共享物体信念 + 角色 token + 换手协议，并诚实区分「表达力收益」与「数据效率收益」。
3. 一条**机队隔离不变量**与可审计的 serving 前沿，直接对齐官方可信度口径。
4. 一个**能力闸门**方法论：回答「什么时候该做放大器、什么时候该回去补基座」。

## 7. 本轮最大风险（一句话）

**最大风险是「放大器陷阱」：语言解码与双臂协作都只是把已有能力用得更聪明，若基座在插入 / 对齐上的绝对能力不足（teaser 显示全体模型都卡在最后一环），它们会让失败更体面却不更少，而机队层任何越界的在线共享还可能直接触发隔离 / 单模型合规问题、让整份成绩作废。**

## 8. 下一轮迭代计划

- **深化**：IP-09 从「每 episode 一次解码」升级为**流式解码 + 后验修正**（边执行边用新观测修正任务 / 阶段后验，类似 ASR 的在线重打分）；IP-10 从「固定角色」升级为**学习到的角色 token + 换手滞后**。
- **修剪预案**：E619 若显示指令鲁棒性已足够 → IP-09 降 P2，只保留置信度记录；E622 若双手子集很小或单臂可行 → IP-10 降 P2；E625 若 p99 已达标 → IP-11 只保留审计。
- **保留项**：IP-06、IP-02、IP-03、IP-12（闸门）不砍。

# 第 2 轮产物 · 创新点清单 v2（UniBot 线）：**UniBot-TEAM**

> **TEAM = Task-decoding · Embodied Arm coordination · Auditable Multi-port serving**
> 延续 UniBot-SAGE（第 1 轮），不推翻；本轮新增 IP-09–IP-12，并把第 1 轮 IP-01 的硬路由升级为软路由。
> 编号：定义 U13–U22、引理 L8–L13、实验 E619–E632。第 1 轮 U1–U12 / L1–L7 / E601–E618 保留。
> 数据纪律：沿用第 1 轮已核实来源（§10）；本轮**不新增**赛事事实断言。ASR / MARL 内容为**标准方法类比**（beam search、N-best、WFST、CTDE），不是赛事数据来源。

## 0. 本轮结论摘要

**一句话路线**：在第 1 轮「接地→技能→适应→工程」栈上，把**语言指令当噪声信道来解码**（N-best 技能后验 + 置信度 + 主动消歧），把**左右臂当两个协作 agent**（共享物体信念 + 角色分配 + 换手），把**N 端口当机队来服务**（离线先验 + 准入控制 + 隔离审计），并用**能力闸门**保证放大器只在基座够强时上线。

| 证据 / 结构 | 推出的设计 |
|---|---|
| 5 类泛化含未见物体 / 人为干扰 / 指令改写 ⇒ ℓ 是 OOD 通道（H1） | 用后验 + 置信度替代 argmax；主动探针消歧（IP-09） |
| 32 任务含双手协调；Dex1 每手 1 维（H2） | 双臂角色分配 + 共享物体信念 + 换手（IP-10） |
| 官方 N 端口 + 延迟 / 规律性可信度口径（H3） | 离线机队先验 + 准入控制 + 隔离不变量（IP-11） |
| 放大器在基座弱时可能负收益（第 1 轮 teaser：全体卡在最后一环） | 能力闸门，默认关闭（IP-12） |

**合规红线**：单 checkpoint、单 API；角色 / 后验都是网络内部条件化；跨端口**不共享 episode 状态**；不做硬编码任务分支；探针动作必须来自策略本身且可被安全约束截断。

## 2. 创新点详述

### IP-09 · LangDecode 指令解码器（P0）

- **动机**：U2 硬 argmax 是单点故障；OOD 语言会静默错路由，且错误无法被感知。第 1 轮 Q3 只处理了「多专家合规」，没处理「token 错了怎么办」。
- **与现有方案的差异**：不是「换更大的语言模型」，而是**保留后验 + 校准 + 主动消歧**。ASR 的 N-best 不是为了最终答案更准（Bayes argmax 已是 0-1 最优），而是为了在**下游代价不对称**时能「晚点决定 + 补证据」。我们的下游代价确实不对称：错路由会让整条 episode 报废，而多花 1–2 步探针只损失少量时间。
- **技术可行性**：高。指令 embedding 已有；任务原型来自官方数据；视觉重打分可用现成检测器 / VLM 探针；探针动作可限制在「小幅转头 / 移臂 / 换视角 / 轻触」。
- **所需资源**：小。解码器在线 ≤5 ms；校准集从官方 32 数据集构造；探针原语用数据检索 + 少量真机试错。
- **落地步骤**：
  1. 构造改写 / 加噪指令集：同义改写、插入未见物体名、加干扰从句、跨任务近义指令；
  2. 训练 / 标定后验：log-linear 融合文本相似、视觉存在性、任务-阶段语法先验、历史平滑（U13/U14）；
  3. 温度缩放 + 可靠性图，得到可用置信度（U15）；
  4. 定义 abstain / 探针阈值（高精度、低召回，沿用第 1 轮 P2 的保守介入思想）；
  5. 实现 3–5 个安全探针原语，并给每个原语估「信息增益 / 耗时 / 风险」；
  6. A/B：硬 argmax vs N-best vs N-best + 探针。
- **风险**：①探针耗时（无速度红利但 horizon 有限）⇒ 只在互信息收益 > 机会成本时探；②校准在未见物体上漂移 ⇒ 每 episode 用场景证据自校准；③把语言当唯一信号会忽略场景 ⇒ 必须视觉重打分。

### IP-10 · BiCo 双臂协作（P0 双手子集 / P1）

- **动机**：双手任务被当单臂做；单自由度夹爪下「稳住 + 操作」需要两臂分工。第 1 轮只建模单臂抓握隐变量。
- **与现有方案的差异**：不是「训练一个更大的双手策略」，而是显式建模**角色**（hold / act / idle）+ **共享物体信念** + **换手**，用 role token 条件化同一 checkpoint。角色分解本质是**正则化 / 信用分配**手段，不是表达力扩张（见 L11）。
- **技术可行性**：中。官方数据有左右臂 / 左右腕相机；角色可从数据中用弱监督得到（一只手腕部位移小且夹爪闭合 ⇒ hold）。
- **所需资源**：中。role token + 共享信念编码器；训练约 +30%。
- **落地步骤**：
  1. 从数据自动标注角色片段（位移小 + 夹爪闭合 ⇒ hold；主动位移大 ⇒ act）；
  2. 训练 role-conditioned 策略（同一主干，role token 输入）；
  3. 加共享物体信念（两腕 + 头，编码位姿 / 稳定 / 闭合 / 滑移）；
  4. 换手协议：滑移或死锁触发，带滞后，只在块边界换；
  5. 双手子集 A/B；与 IP-02 抓握确认联动（换手前先确认原手是否真的抓住）。
- **风险**：①角色标注噪声 ⇒ 双标注一致性检查；②换手引入抖动 ⇒ 滞后 + 块边界；③若单臂已够 ⇒ 收益为 0（H2 可被证伪，这是好事）。

### IP-11 · FleetCal 机队校准与服务（P1）

- **动机**：N 端口共享后端；延迟 / 规律性被评估可信度。第 1 轮只做了单机缝合与审计，没有机队层的服务形式化。
- **与现有方案的差异**：把「机队」限制为**离线先验 + 在线调度**；明确**不做在线跨端口状态共享**（这是合规红线，不是工程选择）。见 L12：在线共享几乎必然破坏隔离。
- **技术可行性**：高。准入控制 / 批处理是标准服务端工程；隔离不变量可测。
- **所需资源**：工程活 + 小算力。
- **落地步骤**：
  1. 离线用 32 数据集 + 自建多端口压测得到技能先验 / 延迟分布；
  2. 实现按端口的队列与批处理预算（U21）；
  3. 写隔离不变量测试：注入一个端口的异常状态，断言其他端口动作流逐位不变；
  4. 导出审计（延迟分位、jerk、批等待、降级次数）；
  5. A/B 先验 on/off。
- **风险**：①批处理拉高 p99 ⇒ 准入控制 + 批等待上限；②「共享先验」若含 episode 信息 ⇒ 直接禁用；③过度调度导致动作过于规律 ⇒ 保留策略固有随机性。

### IP-12 · GateKeeper 能力闸门（P0）

- **动机**：放大器陷阱——新增模块可能只在基座够强时有正收益。
- **与现有方案的差异**：把「是否启用」变成**可测闸门**，而不是拍脑袋。这是本轮唯一一个「防止负收益」的创新点，价值可能高于两个放大器本身。
- **技术可行性**：高。
- **落地步骤**：
  1. 在代理评测上估计每个任务簇的基座成功率 `s_base`；
  2. 估计解码校准 `ECE`；
  3. 定义 `G = 1[s_base ≥ s0 ∧ ECE ≤ e0 ∧ E[ΔU_probe] > 0]`（U22）；
  4. 默认关，逐簇开；
  5. 记录「闸门误关 / 误开」。
- **风险**：闸门本身依赖代理评测（第 1 轮最大风险）⇒ 若 E601 相关性不足，闸门退化为保守默认关（宁可不赚，不可负收益）。

## 3. 符号与定义（U13–U22）

| 符号 | 含义 |
|---|---|
| `q_t(k)` | 技能后验：t 时刻任务 / 技能为 k 的概率 |
| `s_l, s_v` | 文本相似证据、视觉存在性重打分证据 |
| `P_LM(k|z_phase)` | 任务-阶段语法先验 |
| `conf_t` | 置信度，`1 − H(q_t)/log K` |
| `A_probe` | 安全探针动作集 |
| `ρ_t=(ρ_L,ρ_R)` | 左右臂角色 ∈ {hold, act, idle}² |
| `b_t` | 共享物体信念（位姿 / 稳定 / 闭合 / 滑移） |
| `S` | 机队离线聚合统计（身份不可反演） |
| `W_max, B` | 批等待上限、批大小 |
| `G(c)` | 任务簇 c 的能力闸门 |

**定义 U13（技能后验）** `q_t(k) = softmax_k( w_l·s_l(ℓ,e_k) + w_v·s_v(o_t,e_k) + w_g·log P_LM(k|z_phase) + w_h·h_t(k) )`，其中 `s_l` 为文本相似，`s_v` 为视觉存在性重打分，`P_LM` 为任务-阶段语法先验，`h_t` 为历史平滑；`w_*` 在留出集上标定。

**定义 U14（任务-阶段语法）** `P_LM(k | z_phase)` 由 32 任务的阶段序列统计得到（小型 n-gram / WFSA）；用于惩罚「任务与阶段不相容」的组合（如 task=Plug In Ethernet 却 phase=topple）。

**定义 U15（置信度与弃权）** `conf_t = 1 − H(q_t)/log K`；当 `conf_t < τ_c` 或 `top1−top2 margin < τ_m` 时标记 `abstain`，进入消歧分支而非硬提交。

**定义 U16（主动消歧）** 探针 `a_p = argmax_{a∈A_probe} I(k; o_{t+1}|ℓ,a) − λ·cost(a)`；`A_probe` 为安全探针集（转头 / 换视角 / 抬腕 / 轻触），`cost` 为耗时与风险，`λ` 为预算权重。

**定义 U17（角色分配）** `ρ_t = (ρ_L, ρ_R) ∈ {hold, act, idle}²`，约束「同一时刻至多一个主动操作臂」，除非任务显式要求双手同步（如双手搬运）。

**定义 U18（共享物体信念）** `b_t = g_b(w_l, w_r, h, a_{t−1})`，编码物体位姿 / 稳定度 / 闭合度 / 滑移概率；左右臂策略与角色分配共享同一 `b_t`。

**定义 U19（换手协议）** 当 `P(slip|b_t) > τ_s` 或检测到死锁（两臂动作互相抵消）时，在块边界交换角色；带滞后 `Δt_h` 防抖，且换手前必须通过抓握确认（IP-02）。

**定义 U20（机队聚合统计）** `S = f({s_e})`，`s_e` 为 episode 摘要；要求 `S` **身份不可反演**且**仅离线**用于先验。在线 `S` 不参与任何端口动作。

**定义 U21（准入控制）** 每端口一个队列；批等待上限 `W_max`，批大小 `B`；硬约束 `W_max + S_p99(B) ≤ τ_budget`。

**定义 U22（能力闸门）** `G(c) = 1[s_base(c) ≥ s0 ∧ ECE(c) ≤ e0 ∧ E[ΔU_probe] > 0]`；`G=0` 时关闭 IP-09 / IP-10 的主动部分，只保留 v1 行为。

```python
# ===== UniBot-TEAM：单 checkpoint、单 API，含解码 / 角色 / 闸门 / 机队 =====
class UniBotTEAMPolicy:
    def __init__(self, ckpt, ports=range(8765, 8768), N=3, tau_budget_ms=105):
        self.model   = load_single_checkpoint(ckpt)   # 主干 + E_1..E_K + role token
        self.decoder = SkillDecoder()                 # IP-09
        self.roles   = RolePolicy()                   # IP-10
        self.gv      = GraspVerifier()                # v1 IP-02
        self.st      = Stitcher()                     # v1 IP-03
        self.fleet   = FleetPriors.load_offline()     # IP-11：只读离线先验
        self.gate    = GateKeeper()                   # IP-12
        self.sessions = {}                            # 每端口独立状态

    def reset(self, port=None):
        self.sessions.setdefault(port, Session()).reset()

    def get_action(self, obs, port=None):
        s, t0 = self.sessions[port], time.perf_counter()

        # ---- IP-09：解码（保留后验，不硬提交）----
        q, conf = self.decoder.posterior(obs)         # U13/U15
        c = task_cluster(obs)
        if self.gate.enabled(c) and conf < self.tau_c:
            probe = self.decoder.probe(obs, q)        # U16
            if probe is not None:
                return self.pack(probe, 1, obs)       # 探针只走一步，可被安全截断
        k = self.decoder.general_token() if conf < self.tau_c else argmax(q)

        # ---- IP-10：角色 + 共享物体信念 ----
        rho, b = self.roles.assign(obs, k, self.fc.predict(obs))  # U17/U18
        if s.should_handoff(b):
            rho = s.handoff(rho)                      # U19：块边界 + 滞后

        # ---- v1：抓握确认（只判"未抓住"，高精度低召回）----
        g = self.gv.prob(obs)
        s.n_retry = s.n_retry + 1 if (g < self.tau_conf and in_grasp_phase(obs)) else 0
        if s.n_retry >= 3:
            prim = self.nonpreh_primitive(obs)
            if prim is not None:
                return self.pack(prim, 1, obs)

        # ---- v1 IP-01（软门控）+ IP-03 缝合 + 审计 ----
        T_a = self.chunk_len(self.fc.predict(obs))
        a = self.model.act(obs, k, q, rho, b, T_a)    # q 做软混合，仍是单 checkpoint
        a = self.st.stitch(a, s.last_action)
        a = self.audit.clamp_and_log(a, obs, t0, self.tau_budget_ms)
        s.last_action = a[-1]
        return self.pack(a, T_a, obs)
```

```python
# ===== IP-09：后验融合 + 探针选择 =====
class SkillDecoder:
    def posterior(self, obs):
        ell = obs["observation.language"]
        s_l = self.text_sim(ell, self.task_prototypes)          # (K,)
        s_v = self.visual_rescore(obs, self.task_prototypes)    # (K,)
        s_g = self.grammar.logprior(self.phase.predict(obs))    # (K,)
        h   = self.history_smooth(obs)                          # (K,)
        logits = self.w_l*s_l + self.w_v*s_v + self.w_g*s_g + self.w_h*h
        q = softmax(logits / self.temperature)
        conf = 1.0 - entropy(q) / math.log(len(q))
        return q, conf

    def probe(self, obs, q):
        best, best_val = None, 0.0
        for a in self.A_probe:                                  # 安全探针集
            mi = self.expected_mutual_info(q, obs, a)           # I(k; o'|l,a)
            val = mi - self.lam * self.cost(a)
            if val > best_val:
                best, best_val = a, val
        return best if best_val > self.tau_probe else None
```

# ===== IP-11：隔离不变量测试（离线 + 运行时断言）=====
def assert_isolation(policy, ports, inject_port, inject_state):
    base = {p: run_episode(policy, p, seed=0) for p in ports}
    policy.sessions[inject_port].__dict__.update(inject_state)  # 注入异常状态
    for p in ports:
        if p == inject_port:
            continue
        after = run_episode(policy, p, seed=0)
        assert after.actions == base[p].actions, f"state leaked to port {p}"

## 5. 推导（引理 L8–L13）

**引理 L8（后验解码相对硬 argmax 的优势条件）** 设潜在技能 `k`、指令 `ℓ`、后验 `q(k|ℓ)`、下游效用 `U(k̂)` 不对称。一次性提交规则在 t=0 选 `k̂`；自适应规则可先选探针 `a∈A_probe`，观测 `o'` 后更新 `q` 再选 `k̂'`。由于 `A_probe=∅` 是自适应规则的特例，自适应规则的最优期望效用 ≥ 一次性提交规则。严格增益当且仅当最优探针的期望效用增益大于其成本。**推论**：N-best 的价值不在 0-1 任务识别精度（Bayes argmax 已最优），而在**期权价值 + 非对称下游损失**。∎

**引理 L9（主动消歧的贪心上界）** 若不同探针在给定 `k` 下条件独立，则信息增益函数次模，贪心选探针在基数预算内达到最优期望熵降的 `(1−1/e)` 以上。净成功增益为正，当且仅当期望熵降对应的下游损失下降大于探针机会成本。∎

**引理 L10（双臂的闭合约束与边际价值）** 把任务建模为需要对自由物体同时施加 `m` 个接触约束。单夹爪最多提供 1 个抓握约束，环境最多提供 `e` 个外部约束。若 `m > 1+e`，单臂原理上不可行。第二臂的边际价值 = `P(m > 1+e) − P(物体已被外部稳定)`；协作只在边际价值 > 0 的子集上有意义。∎

**引理 L11（角色分解是正则而非表达力）** 角色因子化策略 `p(a_L,a_R|o)=p(a_act|o)·p(a_hold|o,a_act)` 是联合策略类的**子集**，在无限数据下不会提高最优值；其收益来自有限数据下的假设复杂度下降与信用分配改善。**条件**：收益为正仅当数据受限且角色标签可识别；数据充足时可能反而有害。∎（这条故意反直觉：不要把「角色」当免费午餐。）

**引理 L12（机队隔离不变量）** 定义隔离：任意两个部署若只在端口 `p` 的 episode `e` 的原始观测上不同，则服务给其他端口 `p'` 的动作序列必须逐位相同。充分条件：(i) 动作只通过**离线**由训练数据算出的 `S` 依赖机队量；(ii) 运行期 episode 摘要不进入 `S`。在 (i)+(ii) 下隔离成立。任何在线跨端口聚合，除非退化为常数，否则违反隔离。∎（这条把 IP-11 限制为「离线先验 + 在线调度」，堵死危险的在线共享。）

**引理 L13（准入控制的 p99 约束）** 批等待 `W ≤ W_max`，服务时间 `S(B)` 随批大小 `B` 增大，则 per-step p99 延迟 ≤ `W_max + S_p99(B)`；可行性要求 `W_max + S_p99(B) ≤ τ_budget`。批处理只有在 `S(B)/B` 下降且约束仍成立时才提升吞吐，否则是纯延迟成本。∎
