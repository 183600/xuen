# 第 58 轮（承接第 57 轮「少样本×多模态×个性化」IP-133~138；新一轮灵感循环第 1 轮；本轮灵感：「机器人基础模型」×「场景驱动创新」）

> 第 57 轮把安全的赌注从"模型置信"换到"证据质量"，再用元先验摊销、跨模态对账、个性化单向信任把赌注继续往下分了层；但它自陈的最大风险——"坏先验普遍"——在本轮两个灵感面前会被放大一个数量级。**机器人基础模型（RFM/VLA）本身就是人类迄今造过的最大一台"先验摊销机"**：它把互联网级语料压成一个会自如生成动作的通用策略，于是它在语料盲区里的自信错误不再是"某个手工先验错了"，而是"整套动作提案都错了、却看起来极其自然"。**场景驱动创新**则指出：技术推动式的能力扩张若不落到具体场景的利害结构里就无法被证伪——同一个动作在仓库、家庭、农田里的失败代价差三个数量级。本轮的核心转向是**把"提案权"与"承诺权"制度性分离**：基础模型只出提案（proposal），场景卡片与物理落地契约出承诺（commitment）。核心命题由第 57 轮的"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"基础模型出提案、场景出政策、落地出证据、包络出边界"**。

核心矛盾：
- **H29（生成力 vs 可证伪）**：RFM 越强，越能生成"看起来对"的提案；提案空间越大，逐条物理落地验证的带宽越跟不上生成带宽——安全验证成了生成力的瓶颈，而不是后者的注脚。
- **H30（通用先验 vs 场景利害）**：一个全局阈值/全局模型把仓库与家庭同权；同一份证据在不同场景里的可采性本就不同，"通用安全"若不参数化到场景，等价于对最危险场景的欠保护与对最安全场景的过保护。
- **H31（场景闭环 vs 安全债务）**：场景驱动创新若只对"已发生残差"做优化，会把边界过拟合到已经出过事的地方——安全变成事件驱动的补丁，下一次事故发生在补丁之外。

## 0. 直觉与动机

**灵感 1（机器人基础模型 → 提案治理而非能力崇拜）**
直觉：把 RFM 当"顾问"而不是"驾驶员"。它极擅长两件事——把模糊语言任务翻译成有序的动作/技能提案，以及在分布内做出流畅的闭环控制；它极不擅长两件事——知道自己不知道，以及把"看起来是把手"兑现成"这个面能承力"。因此安全架构不去追问"模型对不对"，而是制度性地保证**模型的任何提案都必须先落地成可测的物理谓词、并通过第 56/57 轮已有的证据门，才可能变成承诺**。模型语义置信 σ_sem 被显式排除出风险计算：**模型越自信，不能买来越安全**，只能买来更少的采样次数。RFM 的能力边界也不再靠它自夸，而由独立的**能力包络监视器**（新息、落地失败率、技能契约违反率）判定；一旦越界即冻结其权威、退回独立可证的保守技能。

**灵感 2（场景驱动创新 → 场景卡片、场景政策与创新闭环）**
直觉：安全不是标量，而是"场景 × 证据"的函数。把部署场景做成一等公民**场景卡片** S=(地形,动力学,利害,操作者,法规,容错 ε)，由单调的**场景政策** π_S 把 S 映射成证据门的阈值、探针预算、可采证据类与同意阶梯——利害越高、容错越低，政策越严，但**决策规则本体与不可逆接触的必要证据集永不由 S 放宽**。更进一步，"场景驱动创新"被形式化为一个**受约束的外环**：部署残差（近失/落地失败/包络越界/证据拒绝）→ 修订场景卡片 → 生成适配提案 → 在场景回归套件上影子验证 → 只有"覆盖前沿前进且任一既有卡片安全裕度不降"的提案才准入门。创新因此被场景证伪，而不是被 benchmark 平均分掩盖。

**灵感 3（两灵感合流 → 提案-落地-验证-包络四段式，证据门从五类到六类）**
直觉：第 57 轮证据门 EV-probe*/visit/margin/xmodal/human 在本轮新增 **EV-ground**（已被物理落地契约验证的语义前置条件），且 RFM 来源的承诺必须挂 EV-ground 或一条独立的经典证据路径；EV-xmodal 仍限 L1。击穿安全需要：包络漏检 ∧ 落地映射错 ∧ 场景卡片错配 ∧ 证据门失守 ∧ 人也错——纵深从五层到六层。

**灵感 4（SOS 编排算子 → 让通用能力只在"可被场景证伪"的通道里起作用）**
直觉：四段式不是四个并列模块，而是一条强制管线：提案 → 包络闸 → 落地 → 场景证据门 → 承诺/保守回退/协商/停。RFM 的泛化能力只能经"换一个仍需落地的提案"或"更早触发保守回退"这两个通道影响系统，延续第 56/57 轮的交互单调性，并把第 57 轮的"一切判定器走隔离"推广为"**一切提案者走提案治理，一切承诺走场景政策**"。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（基础模型提案与提案治理 RFM-PG）** 提案 p=(a,Pre,Post,σ_sem,κ,prov)，a∈A_skill 为候选动作/技能序列，Pre/Post 为语义前后置条件，σ_sem 为模型语义置信，κ 为模型自声明的能力令牌（场景子域），prov=(模型版本,prompt 哈希,检索上下文) 为溯源。提案集 P_t∼G_RFM(·|task,scene)。治理三条硬规：(P1) **无直接执行通道**——p 只能经定义 144 的管线进入执行；(P2) **前置条件必须落地**——∀q∈Pre(p) 须由定义 140 验证，否则 p 只能进影子/仿真；(P3) **σ_sem 不进入 P_fail**——只影响提案排序与采样数。溯源使定义 143 支持**模型版本级回溯**：某模型版本事后被证伪，可回滚其全部历史承诺的审计状态。

**定义 140（语义-物理落地契约 SGC）** 场景相关落地映射 𝔾_S={q↦(φ_q,τ_q,cal_q,EV-ground)}，φ_q 为可测物理谓词（如"承力≥F"、"摩擦≥μ"、"净空≥h"），τ_q 为物理测试，cal_q 为第 57 轮的校准记录。落地状态 g(p,S)∈{grounded,ungrounded,failed}：`grounded` ⇔ ∀q∈Pre(p) 存在映射 ∧ measurable(φ_q,S) ∧ τ_q passed ∧ cal_q 有效。声明落地假阳性率 P(g=grounded | p 实际不可行)≤δ_g。未落地/落地失败 ⇒ p 仅可影子执行，不得承诺；**EV-ground 为 RFM 来源承诺的必要证据类**（或须有一条独立经典证据路径）。

**定义 141（场景卡片与场景政策 SCD）** 场景卡片 S=(T,D,Σ,O,R,ε)，T 地形/材质簇、D 动力学、Σ 利害等级、O 操作者角色、R 法规约束、ε 容错。场景指纹 φ(S) 与相似度 sim_S 支持政策迁移。场景政策 π_S 把 S 映射为证据门参数 (θ_voi,θ_margin,k_probes,可采证据类 A_S,同意阶梯,τ_int) 与落地映射集 𝔾_S；**单调性**：Σ↑ 或 ε↓ ⇒ 阈值更严、A_S 更窄、探针预算更大。**不变式**：决策规则本体、不可逆接触必要证据集、EV-xmodal 限 L1、个性化单向有界等硬界不因 S 放宽。场景错配/错分概率 ≤δ_S；卡片带版本与审计。

**定义 142（能力边界包络 CBE）** RFM 自声明能力包络 E_RFM（场景特征空间子集，κ 与之对齐）。监视统计量：分布新息 n_t（第 57 轮 OOD 分数）、滚动落地失败率 ĝ_t、技能契约违反率 v_t。越界指示 e_t=1[n_t>θ_n ∨ ĝ_t>θ_g ∨ v_t>θ_v]。e_t=1 ⇒ **冻结 RFM 权威**，切保守模式（速度↓、裕度↑、探针预算↑），记包络事件。漏检率 ≤δ_env，误退率 ≤ρ_env。**关键**：包络外系统必须在"移除 RFM"后仍可证——保守回退是一条独立可证路径。

**定义 143（场景创新闭环 SIL）** 部署日志 L 的残差集 R=R_nearmiss ∪ R_groundfail ∪ R_envexit ∪ R_reject。闭环：R→修订场景卡片 S'=Revise(S,R)→适配提案 C（新模型/技能/探针/政策）→场景回归套件影子验证→**准入规则**：coverage(S') 前进 ∧ ∀既有卡片 S_i，margin(c|S_i) ≥ margin_old(S_i)（Pareto 不劣化）。维护**创新账本** Λ=(提案,残差来源,影子结果,准入判定,版本) 与**场景覆盖前沿** CF=Pareto{(coverage,soundness)}。不变式：任何准入不得在任一卡片上增加风险；闭环只在前沿内扩覆盖或整体抬升健全性，故不会以"平均分"掩盖单场景退化。

**定义 144（场景编排安全算子 SOS）** 每决策四段式：①提案（RFM 采样，附 prov/κ/σ_sem）；②包络闸（e_t=0 且 κ 与当前场景相容，否则保守回退）；③落地（g(p,S)=grounded，否则弃该提案或影子）；④承诺 ⇔ 落地通过 ∧ 场景证据门（定义 137 的 FSE 挂 π_S 参数 ∪ EV-ground）通过；否则按序保守技能→协商→安全停。SOS 保证 RFM 错误只能经"换提案（仍须落地）"或"更早回退"两个安全通道起作用。

## 2. 关键算法伪代码（完整版见产物区）

```python
def rfm_propose(rfm, task, scene, n):                 # IP-139: 提案带溯源
    return [tag(p, prov=(rfm.ver, phash(task), retrieval), kappa=scene.kappa)
            for p in rfm.sample(task, scene, n)]

def competence_gate(p, monitor, E_rfm):               # IP-142: 越界即冻结权威
    if not E_rfm.contains(z_of(p, scene)) or monitor.e_t():
        return False, 'outside_envelope'
    return True, 'inside'

def ground(p, S, G_S):                                 # IP-140: 语义→物理
    for q in p.Pre:
        if q not in G_S:                              return 'ungrounded'
        phi, tau, cal = G_S[q]
        if not measurable(phi, S) or not cal.valid(): return 'ungrounded'
        if not tau.passed(S):                         return 'failed'
    return 'grounded'

def scenario_orchestrate(x, task, scene, rfm, S, evidence):
    S_pol = scenario_policy(S)                         # IP-141: 单调映射
    for p in ranked(rfm_propose(rfm, task, scene, S_pol.n)):
        ok, why = competence_gate(p, monitor, S_pol.E_rfm)
        if not ok: return conservative_skill(x, task, S), why   # 独立可证
        g = ground(p, S, S_pol.G_S)
        if g != 'grounded': evidence.log(p, g); continue
        cand = realize(p, S)                           # 动作+技能契约
        if scenario_evidence_gate(cand, S_pol, evidence).ok:
            return commit(cand, S_pol), 'proposal_grounded'
    return conservative_skill(x, task, S), 'no_grounded_commit'   # 或协商/停
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| RFM-PG | O(n·d_rfm) 提案 | O(n·\|p\|) | 无直通执行、prov 完整、σ_sem 不入风险 |
| SGC | O(\|Pre\|·c_τ) 每提案 | O(\|𝔾_S\|) | 落地映射完整、δ_g 声明诚实 |
| SCD | O(1) 查表 + O(\|𝔾_S\|) | O(\|场景卡片\|) | π_S 单调、硬界不变、δ_S 有界 |
| CBE | O(1)+O(w) 滑窗统计 | O(\|E_RFM\|) | 漏检 ≤δ_env、回退独立可证 |
| SIL | O(\|R\|·c_shadow) 每迭代 | O(\|Λ\|) | Pareto 准入、版本可回滚 |
| SOS | O(n·(\|Pre\|c_τ+C_gate)+C_fb) | O(\|σ\|) | 四段完备、终止 |

**正确性定理（SGP：Scenario-Grounded Proposal soundness 概要）**：在第 57 轮 A37–A40 上加 (A41) 落地契约诚实：𝔾_S 覆盖可承诺提案的语义前置条件，落地假阳性 ≤δ_g，物理测试沿用第 57 轮校准；(A42) 包络监视漏检 ≤δ_env 且包络外保守回退独立可证（健全性 δ_cfb）；(A43) 场景卡片是合法抽象：π_S 单调、硬界不变、场景错配 ≤δ_S；(A44) RFM 无绕过治理的执行通道、溯源完整。则：(i) **提案者错误不入界**：P(fail) ≤ δ_f+ε_meta+δ_probe+ε_h+δ_g+δ_S+δ_env·δ_g，边界中**不含 RFM 泛化误差项**——模型错可以改变"选哪个提案"，但不能改变"什么能承诺"；(ii) 交互单调性：RFM/场景/闭环只能经"换仍需落地的提案"或"更保守参数/更早回退"起作用；(iii) SIL 的 Pareto 准入保证任一既有卡片安全裕度不降；(iv) SOS 在有限提案与有限测试下终止于 {承诺,保守回退,协商,安全停}。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 落地映射盲区（某些语义无物理测试或映射过弱） | 高 | 映射覆盖率审计 + 未落地一律拒承诺 + 对抗性语义陷阱回归 |
| 场景卡片错配（政策过松/过严） | 高 | 卡片版本化 + 错分披露 δ_S + 高利害默认取严 + 人工复核 |
| 包络自夸/漏检 | 高 | 独立监视器（不由 RFM 报告）+ 越界即冻结 + 独立可证回退 |
| 提案多样性塌缩（只见"安全相"提案） | 中 | 提案采样多样性下限 + 效用损失监控 + 影子探索 |
| 闭环过拟合残差（安全债务外移） | 中 | Pareto 准入 + 留出场景卡 + 周期性红队注入 |
| 落地测试的时延/成本 | 中低 | 快慢双通道（粗测/精测）+ 预取 + 可退经典路径 |

## 6. 本轮最大风险

**一句话**：本轮把安全的赌注从"模型先验质量"移到"落地映射 + 场景卡片 + 能力包络的质量"——若落地映射自身存在系统性盲区（某类语义总是被映射到一个过弱的物理测试），RFM 的提案会带着"已验证"的假象穿过治理，而场景创新闭环又会把这些错误当作"经影子验证的创新"合法化；因此整个方案的安全性最终押在**对落地映射与场景卡片的对抗性策展**上，而不是押在基础模型上。

# 第 58 轮产物 · 创新点清单 v34：Scenario-Proposal-Grounding（基础模型提案治理×场景政策×语义-物理落地×能力包络，RFM-PG×SGC×SCD×CBE×SIL×SOS）

def rfm_propose(rfm, task, scene, n):
    Ps = rfm.sample(task, scene, n)
    out = []
    for p in Ps:
        if not well_formed(p) or not p.prov.complete:
            continue                                  # 溯源不全 → 丢弃

    return diversify(out, n_min=K_DIV)                # 多样性下限，防塌缩

def tag_evidence_class(p, S):

def retroactive_invalidate(model_version, ledger):

### IP-140 SGC（语义-物理落地契约）

```python
def ground(p, S, G_S):
    for q in p.Pre:                                    # 只检查前置条件
        if q not in G_S:            return 'ungrounded'
        phi, tau, cal = G_S[q]
        if not measurable(phi, S):  return 'ungrounded'  # 场景不可测
        if not cal.valid():         return 'ungrounded'  # 校准失效 → 拒
        if not tau.passed(S, phi):  return 'failed'      # 物理上不成立
    return 'grounded'

def realize(p, S):                                     # 语义提案 → 可执行动作
    cand = instantiate(p.a, S)
    cand.contract = SkillContract(pre=p.Pre, post=p.Post, frame=S)
    return cand
```

def scenario_policy(S):
    # 单调：利害↑/容错↓ ⇒ 更严、更窄、更多探针
    strict = monotone_score(S.Sigma, S.eps)
    return Policy(
        theta_voi   = f_voi(strict),
        theta_margin= f_margin(strict),
        k_probes    = f_budget(strict),
        allowed_ev  = allowed_classes(strict) & HARD_ALLOWED,  # 硬界取交
        consent     = consent_ladder(strict),
        tau_int     = f_tau(strict),
        G_S         = load_grounding(S, strict),
        E_RFM       = load_envelope(S),
    )

def check_policy_invariants(pol):

    assert pol.theta_margin >= THETA_MARGIN_HARD_MIN
    assert EV_XMODAL_ONLY_L1 and AUTH_ONE_WAY

def envelope_monitor(mon, rfm, x, scene):

### IP-143 SIL（场景创新闭环，Pareto 准入）

```python
def scenario_innovation_loop(deploy_log, S, rfm, regression_suite, ledger):
    R = mine(deploy_log)                               # near-miss/groundfail/envexit/reject
    S2 = revise_scenario_card(S, R)                    # 把漏掉的危害写进卡片
    cands = adaptation_proposals(rfm, R)               # 模型/技能/探针/政策
    admitted = 0
    for c in cands:
        shadow = shadow_validate(c, S2, regression_suite)
        if not shadow.sound:            continue
        if coverage(S2) <= coverage(S):  continue       # 无覆盖增益不进场
        if any(degrades(c, card) for card in existing_cards()):
            continue                                    # Pareto：任一卡不劣化
        admit(c); ledger.append((c, R, shadow, stable_version()))
        admitted += 1
    return S2, rfm, ledger, admitted
```

### IP-144 SOS（场景编排安全算子，替换 PCE+ 外层）

```python
def scenario_orchestrate(x, task, scene, rfm, S, evidence, budget):
    S_pol = scenario_policy(S)
    assert check_policy_invariants(S_pol)
    Ps = rfm_propose(rfm, task, scene, S_pol.n)
    for p in rank(Ps, S_pol):
        if envelope_monitor(monitor, rfm, x, scene):    # ② 包络闸
            return conservative_skill(x, task, S), 'outside_envelope'
        g = ground(p, S, S_pol.G_S)                     # ③ 落地
        if g != 'grounded':
            evidence.log(p, g); continue
        cand = realize(p, S)
        st = scenario_evidence_gate(cand, S_pol, evidence)   # ④ 场景证据门
        if st.ok:
            return commit(cand, S_pol), 'proposal_grounded'
        if budget.can_probe and st.reason == 'probeable':
            M = evidence.probe(cand, S_pol)             # 复用第 57 轮 PCE+
            if scenario_evidence_gate(cand, S_pol, evidence).ok:
                return commit(cand, S_pol), 'probed_then_grounded'
    # 四段完备：回退 → 协商 → 停
    if S_pol.consent.allows_negotiation:
        return negotiate(cand=None, S_pol, tau_int=S_pol.tau_int)
    return safe_stop(x, S_pol), 'no_grounded_commit'
```

### IP-137→FSE-S（证据门新增 EV-ground 与场景政策）

```python
def scenario_evidence_gate(c, S_pol, evidence):
    ok = False; reason = 'none'
    if c.ev == 'EV-ground':
        ok = ground(c.p, S_pol.scene, S_pol.G_S) == 'grounded'
        reason = 'grounding'
    elif c.ev == 'EV-probe*':
        ok = (c.inf.cls == 'ID' and c.inf.ece_k <= eps_meta(c.k)) or \
             (c.inf.cls == 'OOD' and c.region in ood_reg.certified and
              c.region in S_pol.allowed_ev)
        reason = 'probe'
    elif c.ev == 'EV-xmodal':
        ok = c.level == 'L1' and c.indep_declared and D(c.region) <= theta_D
        reason = 'xmodal'
    elif c.ev == 'EV-human':
        ok = persona[c.op].auth >= 'A1' and \
             c.corrob >= quarantine_exit(persona[c.op].auth)
        reason = 'human'
    elif c.ev in ('EV-visit', 'EV-margin'):
        ok = round56_checks(c, c.M); reason = 'classic'
    if c.source_is_rfm and not (c.ev == 'EV-ground' or c.indep_classic_path):
        return Reject('rfm_requires_grounding')         # RFM 承诺必须落地
    if c.irreversible and c.ev not in S_pol.irreversible_required:
        return Reject('irreversible_evidence_missing')
    return Accept() if ok else Reject(reason)

def scenario_certificate(sched, S_pol, M, ledger, evidence):
    for c in contacts(sched):
        st = scenario_evidence_gate(c, S_pol, evidence)
        if not st.ok: return st
    if not all(l2.resolved for l2 in evidence.consent_log):
        return Reject('consent_open')
    if not S_pol.G_S.covers(sched):                     # 落地覆盖审计
        return Reject('grounding_coverage')
    return Accept(Js(M.core, S_pol.fingerprint, grounding_log,
                     probe_log, scenario_version, ledger.version,
                     auth_log, ood_state))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| RFM-PG | O(n·d_rfm) | O(n·\|p\|) | 无直通执行、prov 完整、σ_sem 不入风险（A44） |
| SGC | O(\|Pre\|·c_τ)/提案 | O(\|𝔾_S\|) | 映射完整、δ_g 声明诚实、未落地即拒（A41） |
| SCD | O(1)+O(\|𝔾_S\|) | O(\|场景卡片\|) | π_S 单调、硬界不变、δ_S 有界（A43） |
| CBE | O(1)+O(w) | O(\|E_RFM\|) | 漏检 ≤δ_env、回退独立可证（A42） |
| SIL | O(\|R\|·c_shadow)/迭代 | O(\|Λ\|) | Pareto 准入、版本可回滚 |
| SOS | O(n·(\|Pre\|c_τ+C_gate)+C_fb) | O(\|σ\|) | 四段完备、终止 |

**正确性定理（SGP：Scenario-Grounded Proposal soundness）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；**(A41)** 落地契约诚实：对可承诺提案，𝔾_S 覆盖其语义前置条件，P(grounded 而实际不可行)≤δ_g，物理测试沿用第 57 轮校准且不劣化；**(A42)** 包络监视漏检率 ≤δ_env、越界时保守回退独立可证（健全性 δ_cfb），且监视器不由 RFM 自报；**(A43)** 场景卡片为合法抽象：π_S 单调、硬界不变、场景错配 ≤δ_S、卡片版本可审计；**(A44)** RFM 无绕过治理的执行通道，溯源 prov 完整，σ_sem 不参与任何风险/证据计算。则：

1. **提案者错误不入界（核心）**：对 RFM 来源的承诺，
   `P(fail) ≤ δ_f + ε_meta(k) + δ_probe + ε_h + δ_g + δ_S + δ_env·δ_g`，
   **该界不含 RFM 的泛化误差项**。直观：RFM 只决定"候选集合"，而候选能否承诺由落地（δ_g）与证据门（其余项）决定；模型越强只改变命中率/效率，不改变健全性上界。
2. **包络外界**：越界被检出时走保守回退，界为 δ_cfb，与 RFM 无关；漏检时剩余保护仍为 δ_g+δ_S+证据门，故漏检不是"裸奔"，只是少了一层纵深。
3. **交互单调性**：RFM、场景政策、创新闭环只能经 (a) 更换一个仍须落地的提案，或 (b) 更保守参数/更早回退/更窄证据类 影响系统；σ_sem、κ 自述、模型自评包络均不构成升险通道。π_S 的硬界交集保证场景不能放宽不可逆证据集与 EV-xmodal 的 L1 限制。
4. **闭环不劣化**：SIL 的 Pareto 准入使得 ∀ 既有卡片 S_i，准入后 margin ≥ margin_old；因此创新只能扩覆盖前沿或整体抬升健全性，不能以平均分掩盖单场景退化。
5. **终止性**：有限提案 × 有限落地测试 × 有限探针预算 ⇒ SOS 终止于 {承诺, 保守回退, 协商, 安全停}。

**部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_g + δ_S + δ_env·δ_g)
             − P(𝒮 卡片陈旧未检出) − P(落地映射盲区未审计) − P(安全停失效)
```

关键：**效率交给 RFM、承诺交给场景**（提案权/承诺权分离，RFM 的泛化误差被结构性移出健全性界）；**语义必须兑现为物理**（EV-ground 把"模型说"变成"测试说"，语义置信 σ_sem 明确不买安全）；**场景是证据的函数**（π_S 单调且硬界不变，既防欠保护也防过保护）；**边界不能自评**（CBE 独立监视 + 独立可证回退）；**创新必须被场景证伪**（SIL 的 Pareto 准入把"场景驱动"从口号变成不许退化的约束）。

## 6. 本轮最大风险

**一句话**：本轮把安全的赌注从"模型先验质量"整体移到"落地映射 + 场景卡片 + 能力包络的质量"——若落地映射自身存在系统性盲区（某类语义总是被映射到一个过弱的物理测试），RFM 的提案就会带着"已验证"的假象穿过治理，而场景创新闭环又会把这些错误当作"经影子验证的创新"合法化；因此方案的安全性最终押在**对落地映射与场景卡片的对抗性策展**上，而不是押在基础模型上。
