# 第 1 轮（灵感循环 I 第 1 轮；灵感：「通信延迟」×「语义建图」×「安全交互」）

## 0. 直觉与动机

**灵感 1（通信延迟 → DLT：Delay-Limited Trust 延迟受限信任机制）**
直觉：在分布式机器人协作系统中，通信延迟 τ 常导致协同意图不一致、动作冲突、危险交互。传统方法是通过缓冲/队列消除延迟，或降级为无线性能优化。**关键洞见**：将延迟本身建模为 **受限的可达性约束**——机器人 i 的信息在延迟 τ_i→j 内才能传递到机器人 j，形成 **时延信任网络**。DLT 通过 **延迟感知的信任分数** T_ij(τ) 和 **时延边界下的可达性图** G(τ_max)，在每个控制周期 **预测信息流向**，为后续的语义地图融合提供 **可靠的时空一致性承诺**。

**灵感 2（语义建图 → SME：Semantic Map Engine 语义地图引擎）**
直觉：单机器人局部语义地图（V, T, P, L）仅覆盖自身视野。**关键缺口**：跨机器人协同的语义地图融合缺乏 **时空一致的信任框架**，导致地图拼接时出现语义错位、冲突或孤岛。SME 通过 **DLT 的时延可达性** 过滤可靠信息来源，对每类语义要素（物体类别、功能标签、可操作性）施加 **时延一致性惩罚**。融合后得到 **全局时序语义地图** M_global = ⋃_i T_ij(τ)·M_local_i，显式标记 **"信任-时延-语义" 三元组**，支持 **延迟容错的协同规划**。

**灵感 3（安全交互 → HHI：Hierarchical Hazard Interface 分层危险接口）**
直觉：机器人与人类的安全交互需在 **感知-决策-执行** 三层面实时鉴别。传统方法依赖手工设定的安全距离/速度阈值。**关键创新**：构建 **从低到高抽象** 的危险建模层级：
- **层 1（感知层）**：基于视觉/触觉/本体的 **瞬时危险检测** H_perceive(t)
- **层 2（语义层）**：基于 SME 的 **空间语义危险推断** H_semantic(x) = f_semantic(M_global, x)
- **层 3（交互层）**：基于 DLT 的 **分布式风险传播** H_interact = g_interact(H_perceive, H_semantic, τ_network)

HHI 通过 **分层危险传播** 和 **时延加权的信心融合**，输出 **分层安全决策**，在 DLT 的约束下实现 **延迟容错的安全交互**。

**灵感 4（三灵感合流 → DLMS-HHI：Delay-aware Local Semantic Mapping with Hierarchical Hazard Interface）**
三者咬合：
- **DLT** 提供 **时延受限的信任网络** → 信息只在 τ ≤ τ_max 的机器人间可达 → 防止 **时延脏数据** 破坏语义一致性。
- **SME** 在 **DLT 信任约束** 下融合语义地图 → 输出 **时延标记的全局语义地图** M_global = (S, Ω, T, τ)。
- **HHI** 基于 **M_global 的时延-语义危险** → 输出 **时延感知的安全决策**。

闭环：**通信延迟 → 信任网络 → 语义地图 → 危险推断 → 安全行为**。若 τ > τ_max，DLT 降级为 "局部安全模式" ，HHI 自动进入 **最小化风险-最大化自信** 策略。

## 1. 形式化定义

**定义 1（延迟受限信任网络）**
给定机器人集合 ℛ = {r_1, ..., r_N}，通信延迟 τ_ij ∈ [0, τ_max]，定义时延受限信任函数：
T_ij(τ) = exp(-α·τ_ij/τ_max) · I{τ_ij ≤ τ_max}

其中 α > 0 为时延敏感系数，I 为指示函数。时延可达性图 G(V, E) 中的顶点 V = ℛ，边 E = {(i,j) | τ_ij ≤ τ_max}。

**定义 2（时延感知语义地图）**
本地语义地图 M_i = (S_i, Ω_i, φ_i) ，其中 S_i 为语义空间，Ω_i 为物体集合，φ_i 为每物体的 **语义-时延标记**：
φ_i(o) = (category, confidence, τ_origin, T_origin)

全局语义地图通过 DLT 加权融合：
M_global = (S_global, Ω_global, φ_global)
其中 φ_global(o) = ⨆_{i: (i,j)∈E} T_ij(τ_ij)·φ_i(o)

**定义 3（分层危险表示）**
HHI 的三层危险模型：
- H_perceive(x, t) = (d_min, v_rel, κ_obs) 表示 **瞬时危险特征**（最小距离、相对速度、观察复杂度）
- H_semantic(x, M_global) = P(hazard | x, M_global) 基于全局语义地图的 **空间危险概率**
- H_interact(x, τ_network) = (H_perceive, H_semantic) ⊗ w(τ_network) 其中 w(τ) = (1 - β·τ/τ_max) 为时延权重

**定义 4（时延容错安全准则）**
安全决策满足：
P_danger(x) = 1 - exp(-λ·H_perceive(x) - μ·H_semantic(x) - ν·H_interact(x, τ))
≥ 1 - ε_safety

其中 λ, μ, ν > 0 为危险权重系数，ε_safety 为容许风险阈值。

## 2. 关键算法骨架

### 2.1 DLT 延迟受限信任机制

```
Algorithm DLT_Update(τ_ij, τ_max, α):
    T_ij ← exp(-α·τ_ij/τ_max) if τ_ij ≤ τ_max else 0
    G ← {(i,j) | T_ij > 0}
    return T_ij, G
```

### 2.2 SME 语义地图融合

```
Algorithm SME_Fuse(M_local, G, T, τ):
    for each object o in M_local:
        if τ_origin(o) ≤ τ_max and ∃ path (i,o) in G:
            weight ← T_ij(τ_ij) · confidence(o)
            add to M_global with weight, mark (τ_origin, T_origin)
    return M_global
```

### 2.3 HHI 分层危险推断

```
Algorithm HHI_Detect(x, M_global, τ_network):
    H_perceive ← Detect_InstantHazard(x)
    H_semantic ← Query_SemanticHazard(x, M_global)
    H_interact ← Weight_By_Delays(H_perceive, H_semantic, τ_network)
    P_danger ← 1 - exp(-λ·H_perceive - μ·H_semantic - ν·H_interact)
    if P_danger ≥ 1 - ε_safety:
        return "SAFE", Action_Safe(x)
    else:
        return "DANGER", Action_Evasive(x)
```

## 3. 复杂度分析

| 组件 | 时间复杂度 | 空间复杂度 | 备注 |
|---|---|---|---|
| DLT_Update | O(N²) | O(N²) | 延迟矩阵更新 |
| SME_Fuse | O(|Ω_local|·N) | O(|S_global| + |Ω_global|) | 对象级融合 |
| HHI_Detect | O(1) | O(1) | 实时检测 |

## 4. 正确性论证

**引理 1（时延一致性）** 若 τ_ij ≤ τ_max 对所有信息传递路径成立，则 M_global 中任意对象的时延标记 τ_origin ≤ τ_max。

**定理 1（DLMS-HHI 安全保证）** 在延迟阈值 τ_max = (1-ε_safety)/β 时，若 H_perceive = 0 且 H_semantic = 0，则 P_danger ≤ ε_safety。

## 5. 已知风险

**一句话**：若网络时延分布出现 **极端尾部抖动**（瞬时延迟 τ_ij 突增至数倍于 τ_max），DLT 的指数衰减信任模型将 **错误地标记可达信息为不可达**，导致 SME 误判全局语义一致性、HHI 误触发安全降级——**时延-信任-语义链路的指数放大效应是本轮设计的最大风险**。

## 2. 算法伪代码

### IP-001: DLT 延迟受限信任

```python
def DLT_Update(tau_matrix: np.ndarray, tau_max: float, alpha: float = 1.0):
    """
    计算时延受限信任分数和可达性图
    tau_matrix: N×N 延迟矩阵
    return: (T_matrix, reachable_graph)
    """
    N = tau_matrix.shape[0]
    T_matrix = np.exp(-alpha * tau_matrix / tau_max)
    T_matrix[tau_matrix > tau_max] = 0.0
    
    reachable_graph = {(i, j) for i in range(N) for j in range(N) 
                        if tau_matrix[i, j] <= tau_max and T_matrix[i, j] > 0}
    return T_matrix, reachable_graph
```

### IP-002: SME 语义地图融合

```python
def SME_Fuse(local_maps: List[Dict], 
             trust_graph: set, 
             trust_matrix: np.ndarray,
             tau_matrix: np.ndarray,
             tau_max: float):
    """
    在 DLT 信任约束下融合语义地图
    """
    global_objects = {}
    
    for robot_id, local_map in enumerate(local_maps):
        for obj_id, obj in local_map['objects'].items():
            tau_origin = tau_matrix[robot_id, robot_id]
            
            if tau_origin <= tau_max:
                for (src, dst) in trust_graph:
                    if src == robot_id:
                        weight = trust_matrix[src, dst] * obj['confidence']
                        if obj_id not in global_objects:
                            global_objects[obj_id] = {
                                'category': obj['category'],
                                'position': np.mean([w*obj['position'] 
                                    for w in [trust_matrix[i,j] for i,j in trust_graph 
                                    if i == robot_id and trust_graph]]),
                                'confidence': 0.0,
                                'tau_markers': []
                            }
                        global_objects[obj_id]['confidence'] = max(
                            global_objects[obj_id]['confidence'], weight * obj['confidence'])
    
    return global_objects
```

### IP-003: HHI 分层危险推断

```python
def HHI_Detect(agent_state: np.ndarray,
               global_map: Dict,
               network_delays: np.ndarray,
               tau_max: float,
               safety_threshold: float = 0.95,
               lambda_: float = 1.0,
               mu: float = 1.0,
               nu: float = 1.0):
    """
    三层危险推断
    """
    H_perceive = compute_instant_hazard(agent_state)
    H_semantic = query_semantic_hazard(agent_state, global_map)
    
    mean_tau = np.mean(network_delays)
    tau_weight = max(0.0, 1.0 - 0.5 * mean_tau / tau_max)
    
    H_interact = tau_weight * (lambda_ * H_perceive + mu * H_semantic)
    
    P_danger = 1 - np.exp(-nu * H_interact)
    
    if P_danger >= 1 - safety_threshold:
        action = compute_evasive_action(agent_state)
        return "DANGER", action, P_danger
    else:
        action = compute_safe_continuation(agent_state)
        return "SAFE", action, P_danger
```
