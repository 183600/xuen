# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 7 轮；本轮灵感：「少样本学习」×「多机协作」）

> 第 60 轮用 SSM×CIEC×EPIR×SERC×PCE++++ 把「执行接地层」升级为「认知驱动的场景-执行闭环」，实现了「场景先验提前收敛、意图即时锁定、证据防丢包」。但它仍建立在三个**隐含的封闭世界假设**上：
> 1. **场景先验的封闭世界与冷启动代价**：SSM 需要预先给定 N 个场景及 π_scene(K|z)，Kalman 后验要靠多次接触才收敛；遇到**未见场景 z_new**（新材质、新坡度、新负载）只能退回通用先验 π_scene^general，等于「先执行、后识别」，与第 60 轮「先认知后执行」的初衷相悖。**少样本学习**正是针对「k 次样本泛化到新 task」的解法。
> 2. **意图映射的个体化缺失与单机锁定**：CIEC 的 ϕ_intent→constraint 是固定规则表，无法覆盖新用户的措辞、方言与新意图；且 φ_lock 只锁**单机** ERTC，多台机器人共享工作空间时各自锁定会互相抢占、死锁，缺少**跨机约束协商**。
> 3. **证据链的单边假设**：EPIR 的 seq_id 仅在单机内单调，多机之间没有 happens-before 关系；多播丢包、乱序、甚至恶意节点都会让「全局执行合规性」无法重建。

## 0. 直觉与动机

**灵感 1（少样本学习 → 元场景先验 FSML）**
直觉：把场景识别从「分类问题」重写为「元学习问题」——每个场景 z 是一个 **task**，阻抗参数 K 是 **task-specific 参数**，历史场景构成 task 分布 p(z)。元学习得到的是「如何从接触中推断阻抗」的共享初始化 θ，而不是某个具体场景的阻抗。新场景只需 k 次接触样本 D_k 做内循环贝叶斯更新。关键洞见：**第 59 轮的 B_probe 预算天然就是"样本预算"，k-shot 把冷启动从"多次失败后回退"变成"3 次接触内收敛"**，并且让「先认知后执行」在未见场景上也成立。

**灵感 2（少样本学习 → 意图个性化 MIM）**
直觉：意图-约束映射 ϕ 也应「因人而异」：新用户说「别太用力」与老用户说「轻触」同义，固定规则表无法覆盖。把 ϕ_θ 当作元学习映射，用 k 组 (utterance, constraint) 示范做少样本个性化；当后验熵高（歧义）时主动澄清或回退保守约束，而不是硬映射。关键洞见：**个性化不是"更准的映射"，而是"知道自己不确定"**——歧义度 H(u) 本身是安全信号。

**灵感 3（多机协作 → 场景原型银行 SPB）**
直觉：少样本之所以可行，是因为"样本便宜"。场景原型 (e_z, μ_z, Σ_z) 是低维嵌入 + 高斯参数，远比原始力/轨迹数据便宜。多机之间用 gossip 稀疏共享原型，等价于「每台机器把自己的 k-shot 经验变成队友的先验」，把单机 k-shot 放大为团队 n·k-shot。关键洞见：**共享的是"先验"而非"数据"**——既降低带宽（B_ros），也避免原始数据外泄。

**灵感 4（多机协作 → 约束共识 MCC）**
直觉：多机在同一桌面/同一工件上协作时，ERTC 契约会冲突：两台机器人锁定同一区域、叠加力超限、时间窗重叠。需要分布式契约协商：以共享资源（区域/力/时间窗）为耦合约束，用 ADMM 对偶变量迭代求可行交集；若 τ_consensus 内无解，则**时间复用**（按优先级串行化）或分离执行，而不是各自锁定后死锁。关键洞见：**多机安全不是"各自 K_safe 的交集"，而是"区域-力-时间的联合可行域"**。

**灵感 5（多机协作 → 分布式因果证据链 DCEC）**
直觉：EPIR 的 seq_id 只在单机内单调；多机需**向量时钟 VC** 建立 happens-before。每条 EV-exec 携带 (robot_id, VC, seq, hash)，因果广播只在「所有前驱已交付」时交付，全局证据链是分布式 DAG。即使丢包/乱序，也能重建因果序；对恶意节点用信任加权 + 哈希链做拜占庭鲁棒聚合。关键洞见：**"在前"不再由单机时间戳定义，而由向量时钟的偏序定义**。

**灵感 6（三灵感合流 → FAME 闭环 + 共享预算 SBA + 泛化证书 FGC）**
直觉：FSML 给出新场景元先验 → EEIS 编译 K_safe；MIM 给出个性化约束 → MCC 协商多机契约；SPB 在团队内传播先验；DCEC 保证证据链；SBA 把第 60 轮的四维认知预算从单机扩展为**团队预算**，用拍卖分配 B_probe/B_scene/B_ros。FGC 是「少样本泛化证书」：用原型距离与后验收缩给出未见场景的风险上界，超过阈值就禁止用该先验提前收敛（防止负迁移）。形成闭环：**团队先验→场景编译→意图个性化→多机协商→协同执行→因果证据→原型/信任更新**。

**灵感 7（风险 → 原型投毒 TPB）**
直觉：原型银行引入新攻击面：一台被劫持的机器人可注入「湿滑=高摩擦」的毒原型，经 gossip 扩散污染全队。用信任度加权 + 截尾均值/中位数聚合 + 与 DCEC 证据交叉验证来防御。关键洞见：**少样本先验越"值钱"，投毒一个原型的杠杆就越大**。

## 1. 形式化定义（增量：定义 161–170）

**定义 161（少样本场景元学习 FSML）** 元场景模型 M_scene = (p(z), θ, adapt_k, π_scene^meta)。其中：
- **任务分布**：z ~ p(z)，每个场景是一个 task；
- **元参数**：θ = (e_θ(·), μ_θ(·), Σ_θ(·))，场景嵌入 e_z = e_θ(z)；
- **内循环适应**：给定 k 个接触样本 D_k^z = {(φ_j, y_j)}_{j=1..k}（φ_j 为接触特征，y_j 为该次接触下可行阻抗观测），
  ```
  π_scene(K|z, D_k) = N(K; μ_k, Σ_k)
  μ_k = μ_θ(e_z) + K_{*s}(K_{ss} + σ²I)⁻¹ (y_s − μ_θ(e_z))
  Σ_k = K_{**} − K_{*s}(K_{ss} + σ²I)⁻¹ K_{s*}
  ```
  其中 κ(φ,φ') 为接触特征空间核，K_{ss}=[κ(φ_i,φ_j)]，K_{*s} 为查询-样本协方差；
- **外循环元训练**：θ* = argmin_θ E_{z~p(z)}[ L(π_scene(·|z, D_k^z), D_val^z) ]；
- **场景先验约束**：K_safe^scene = {K : P(K|z,D_k) ≥ τ_scene} ∩ K_safe_base，且要求 k ≤ B_probe^remain。

**定义 162（少样本意图个性化 MIM）** 个性化意图映射 φ_θ: U→Δ(C)，θ 为元参数。给定 k 组示范 D_k^u = {(u_j, C_j)}：
- **后验**：p(θ|D_k^u) ∝ p(D_k^u|θ)p(θ)；
- **预测**：p(C|u, D_k^u) = ∫ φ_θ(u) p(θ|D_k^u) dθ；
- **歧义度**：H(u) = H(p(C|u,D_k^u))；若 H(u) ≥ τ_H 或 max_C p(C|u) < τ_conf，则触发「澄清-回退」：query_clarify(u) 或 C ← C_default^safe；
- **约束入契约**：C_intent^u = argmax_C p(C|u,D_k^u)，且必须满足 C_intent^u ⊆ C_rt^max（不得越过硬安全边界）。

**定义 163（场景原型银行 SPB）** 机器人 i 的本地原型库 B_i = {(e_z, μ_z, Σ_z, n_z, w_z)}。共享与融合：
- **新颖度驱动 gossip**：ω_z = d(e_z, N_k(e_z)) / n_z，优先共享高 ω_z 的"少数派"原型（避免信息冗余）；
- **团队共识原型**：\bar{μ}_z = Σ_i w_i μ_{z,i} / Σ_i w_i（或鲁棒截尾均值，见定义 170）；
- **传输成本**：|prototype| = O(d + |K|²) ≪ |raw_trajectory|；仅当 ΔB_ros 足够时共享；
- **跨机冷启动**：新机器人加入即以团队原型 \bar{π}_z 初始化，再用 k-shot 个性化，实现「先验继承 + 个性化」。

**定义 164（多机约束共识 MCC）** 团队约束协商 Π = (R, {C_i}, solve, fallback)。其中：
- **共享资源**：R = (Ω ⊆ ℝ³, P_max, [t0,t1], W)；
- **机器人契约**：C_i = (K_i, v_i, F_i, Ω_i, T_i)，其中 Ω_i ⊆ Ω，T_i ⊆ [t0,t1]；
- **耦合约束**：∀i≠j：若 T_i∩T_j ≠ ∅ 则 Ω_i∩Ω_j = ∅（或允许重叠时 Σ_{k∈A(x)} F_k ≤ F_cap(x)），且 Σ_i P_i ≤ P_max；
- **协商算子 solve**：min Σ_i cost_i(C_i) s.t. 耦合约束，用 ADMM 对区域/力/时间三类乘子 λ 迭代；
- **无共识回退**：若迭代 > N_cons 或无可行解 → time-multiplex（按优先级串行化 Ω_i）；仍无解 → DEGRADE_COOP；
- **死锁避免**：资源按全局全序编号 + 请求超时自动释放（破坏循环等待）。

**定义 165（分布式因果证据链 DCEC）** 团队证据链 E = (E_i, VC, HB)。其中：
- **事件**：e = (robot_id=i, seq=s_i, VC=(v_1,...,v_n), hash, content)；
- **因果序**：e→f iff VC_e ≤ VC_f（逐分量）且 e≠f；否则 e∥f（并发）；
- **因果交付条件**：deliver(e) at j iff 对所有 k≠i，e 的前驱在 j 已交付（标准 causal delivery）；
- **完整性不变量**：若 e→f 且 f 已交付，则 e 必已交付（链无缺口）；
- **拜占庭鲁棒**：f < n/3，信任加权哈希链，聚合用加权中位数；
- **恢复**：与第 60 轮 EPIR 影子副本结合——跨机缺口按 VC 精确重放，而非按单机 seq 猜测。

**定义 166（FAME 协同执行闭环）** 算子 FAME(M_team, scenes, intents, δ_f^req)：
```
① FSML:  ∀j: π_j(K|z_new, D_k) ← adapt_k(θ*, D_k^z)
② SPB:   gossip 交换场景原型；团队先验 π̄(K|z_new) ← robust_aggregate({π_j})
③ CCM:   ∀i: K_safe^i ← EEIS.compile_with_scene_prior(π̄, δ_f^i)
④ MIM:   ∀i: C_intent^i ← φ_θ(u_i)；若 H(u_i)>τ_H → clarify / C_default^safe
⑤ MCC:   {(K_i,C_i)} ← solve(R, {K_safe^i}, {C_intent^i})；失败 → time-multiplex
⑥ SBA:   分配 B_probe/B_scene/B_intent/B_ros（定义 167）
⑦ Dispatch & Execute: ∀i: dispatch(K_i, Cert_i)；telemetry
⑧ DCEC:  e_i ← (i, seq, VC, hash, EV-exec_i)；causal_broadcast(e_i)
⑨ XMC++/SERC: 融合 EV-exec；更新 z_scene 后验、原型库、信任 τ
⑩ Return: (z_scene, {K_i}, {EV-exec_i}, Cert_coop, DCEC.status)
```

**定义 167（共享认知预算拍卖 SBA）** 团队预算 B_team = (B_probe, B_scene, B_intent, B_ros, B_exec)。
- **竞价**：b_i = VOI_i(ΔB_i) / cost_i(ΔB_i)，VOI_i 复用第 60 轮 PCE++++ 的 voi_cog；
- **分配**：max Σ_i VOI_i(ΔB_i) s.t. Σ_i ΔB_i ≤ B_team（多轮递增拍卖）；
- **公平**：max-min 约束 VOI_i ≥ θ_fair；饥饿保护：连续 N_round 未中标者获得保留额度；
- **耗尽策略**：B_probe 耗尽 → 新场景退回 π_scene^general；B_ros 耗尽 → 停止 gossip，仅用本地原型；B_scene 耗尽 → 冻结场景后验；B_exec 耗尽 → 原有降级；
- **单调性**：预算只减不增，任何分配不得超过剩余额度。

**定义 168（少样本泛化证书 FGC）** 给定新场景原型 e_new、训练原型集 E_train、k-shot 后验 π_k：
- **原型距离**：ρ = min_{e∈E_train} d(e_new, e)；
- **估计误差**：δ_k = O(σ √(d/k))（高斯过程后验收缩速率）；
- **风险上界**：U = L·ρ + δ_k + ε_meta（L 为任务损失的 Lipschitz 常数，ε_meta 为元验证误差）；
- **证书**：Cert_fgc = valid iff U ≤ ε_task ∧ SIC_valid ∧ k ≤ B_probe^remain；
- **失效处理**：若 invalid，则**禁止**用 π_k 提前收敛 K_safe，退回 π_scene^general——这是防止「少样本负迁移」的硬闸门。

**定义 169（协同安全包络 CSE）** 给定团队契约 {C_i} 与工作空间，协同安全证书 J_coop：
- **成对安全**：d(Ω_i(t), Ω_j(t)) ≥ d_min（时间重叠时）；
- **力叠加安全**：∀x, Σ_{i∈A(x)} F_i ≤ F_cap(x)；
- **执行可行性**：∀i, execution_feasibility(K_i|z) = true；
- **证书**：Cert_coop = (J_coop, region_partition, time_schedule, force_budget)；
- **拒绝规则**：Cert_coop 无效 → 拒绝 dispatch（先安全、后协作）。

**定义 170（信任加权原型银行 TPB）** 信任 τ_i ∈ [0,1]，初值 1：
- **信任更新**：τ_i ← τ_i·exp(−D_plus^i / λ)（以 DCEC 证据一致性为准）；
- **鲁棒聚合**：\bar{μ}_z = TrimmedMean_w({μ_{z,i}}, α)；
- **投毒检测**：若 ||μ_{z,i} − median_j(μ_{z,j})|| > θ_poison，则隔离该原型、下调 τ_i 并广播告警；
- **降权传播**：被隔离机器人的原型不参与团队先验，只有本地 SIC 校验通过后才可恢复。

### IP-161 FSML（少样本场景元学习）

```python
class FewShotSceneMetaLearner:
    def __init__(self, meta_theta, kernel, tau_scene=0.7, max_k=3):
        self.theta = meta_theta          # 共享元参数 (e_theta, mu_theta, Sigma_theta)
        self.kernel = kernel
        self.tau_scene = tau_scene
        self.max_k = max_k

    def adapt(self, z_new, support_Dk):
        k = min(len(support_Dk), self.max_k)
        e_z = self.theta.embed(z_new)
        mu0 = self.theta.mu(e_z)
        Sig0 = self.theta.cov(e_z)
        phi = np.array([s.feature for s in support_Dk[:k]])
        y = np.array([s.feasible_impedance for s in support_Dk[:k]])
        Kss = self.kernel(phi, phi) + 1e-3 * np.eye(k)
        Kqs = self.kernel(mu0[None, :], phi)
        mu_k = mu0 + Kqs @ np.linalg.solve(Kss, y - mu0)
        Sig_k = Sig0 - Kqs @ np.linalg.solve(Kss, Kqs.T)
        return GaussianPrior(mu_k, Sig_k, k=k, num_samples=k)

    def safe_set(self, prior, base_safe):
        # 先验置信域与硬安全域的交换
        return intersect(confidence_ellipsoid(prior, self.tau_scene), base_safe)

    def meta_train(self, task_batches, inner_lr=0.01):
        for batch in task_batches:                      # 每个 z 是一个 task
            theta_grad = 0
            for z in batch:
                D_tr, D_val = split(z.samples)
                prior = self.adapt_with(self.theta, z, D_tr)
                theta_grad += grad_theta(loss(prior, D_val))
            self.theta = self.theta - inner_lr * theta_grad / len(batch)
```

### IP-162 MIM（意图个性化）

```python
class MetaIntentMapper:
    def __init__(self, phi_theta, tau_H=0.5, tau_conf=0.6):
        self.phi = phi_theta
        self.tau_H = tau_H
        self.tau_conf = tau_conf

    def map_intent(self, utterance, demos):
        post = self.phi.posterior(utterance, demos)      # p(theta | D_k^u)
        dist = self.phi.predict(utterance, post)         # Δ(C)
        H = entropy(dist)
        c_best = dist.argmax()
        if H >= self.tau_H or dist.max() < self.tau_conf:
            return self._clarify_or_default(utterance)
        return clamp_to_hard_safety(c_best)

    def _clarify_or_default(self, u):
        # 歧义时宁可问一句，也不硬猜
        return IntentResult(constraint=DEFAULT_SAFE, need_clarify=True)
```

```python
def cooperative_contract_consensus(robots, shared_R, N_cons=20, tau_cons=0.2):
    lam = {r.id: init_dual(r, shared_R) for r in robots}   # 区域/力/时间乘子
    for it in range(N_cons):
        for r in robots:                                  # 各自最优响应（对偶上升）

        for r in robots:                                  # 乘子更新

def gossip_prototypes(robot_i, peers, budget_ros):
    candidates = sorted(robot_i.bank.values(),
                        key=lambda p: p.novelty / p.n, reverse=True)
    sent = []
```

### IP-165 DCEC（向量时钟因果链）

```python
class DistributedCausalEvidenceChain:
    def __init__(self, robot_id, n_robots):
        self.id = robot_id
        self.n = n_robots
        self.vc = [0] * n_robots
        self.buffer = defaultdict(list)
        self.delivered = defaultdict(set)      # delivered[j] = set(seq of robot j)
        self.chain = []

    def local_event(self, ev_exec):
        self.vc[self.id] += 1
        e = Event(robot=self.id, seq=self.vc[self.id],
                  vc=list(self.vc), hash=sha256(ev_exec), content=ev_exec)
        self._deliver(e)
        broadcast(e)
        return e

    def on_receive(self, e):
        self.buffer[e.robot].append(e)
        self.buffer[e.robot].sort(key=lambda x: x.seq)
        for cand in list(self.buffer[e.robot]):
            if self._causally_ready(cand):
                self._deliver(cand)
                self.buffer[e.robot].remove(cand)
                self.vc[e.robot] = max(self.vc[e.robot], cand.vc[e.robot])

    def _causally_ready(self, e):
        # e 的所有前驱（逐机 seq 连续）均已交付
        if e.seq != len(self.delivered[e.robot]) + 1:
            return False
        for k in range(self.n):
            if k != e.robot and e.vc[k] > len(self.delivered[k]):
                return False
        return True

    def _deliver(self, e):
```

### IP-161 FSML（少样本场景元学习）

```python
class FewShotSceneMetaLearner:
    def __init__(self, meta_theta, kernel, tau_scene=0.7, max_k=3):
        self.theta = meta_theta
        self.kernel = kernel
        self.tau_scene = tau_scene
        self.max_k = max_k

    def adapt(self, z_new, support_Dk):
        k = min(len(support_Dk), self.max_k)
        e_z = self.theta.embed(z_new)
        mu0, Sig0 = self.theta.mu(e_z), self.theta.cov(e_z)
        phi = np.array([s.feature for s in support_Dk[:k]])
        y = np.array([s.feasible_impedance for s in support_Dk[:k]])
        Kss = self.kernel(phi, phi) + 1e-3 * np.eye(k)
        Kqs = self.kernel(mu0[None, :], phi)
        mu_k = mu0 + Kqs @ np.linalg.solve(Kss, y - mu0)
        Sig_k = Sig0 - Kqs @ np.linalg.solve(Kss, Kqs.T)
        return GaussianPrior(mu_k, Sig_k, k=k)

    def safe_set(self, prior, base_safe):
        return intersect(confidence_ellipsoid(prior, self.tau_scene), base_safe)

    def meta_train(self, task_batches, lr=0.01):
        for batch in task_batches:                 # 每个 z 是一个 task
            g = 0
            for z in batch:
                D_tr, D_val = split(z.samples)
                g += grad_theta(loss(self.adapt_with(self.theta, z, D_tr), D_val))
            self.theta = self.theta - lr * g / len(batch)
```

### IP-165 DCEC（向量时钟因果链）

```python
class DistributedCausalEvidenceChain:
    def __init__(self, robot_id, n_robots):
        self.id, self.n = robot_id, n_robots
        self.vc = [0] * n_robots
        self.buffer = defaultdict(list)
        self.delivered = defaultdict(set)
        self.chain = []

    def local_event(self, ev_exec):
        self.vc[self.id] += 1
        e = Event(robot=self.id, seq=self.vc[self.id], vc=list(self.vc),
                  hash=sha256(ev_exec), content=ev_exec)
        self._deliver(e)
        broadcast(e)
        return e

    def on_receive(self, e):
        self.buffer[e.robot].append(e)
        self.buffer[e.robot].sort(key=lambda x: x.seq)
        for cand in list(self.buffer[e.robot]):
            if self._causally_ready(cand):
                self._deliver(cand)
                self.buffer[e.robot].remove(cand)
                self.vc[e.robot] = max(self.vc[e.robot], cand.vc[e.robot])

    def _causally_ready(self, e):
        if e.seq != len(self.delivered[e.robot]) + 1:
            return False
        return all(e.vc[k] <= len(self.delivered[k])
                   for k in range(self.n) if k != e.robot)
```
