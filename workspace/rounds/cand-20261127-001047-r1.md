灵感驱动研究循环·新灵感二元组第 1 轮；本轮灵感：「运动控制」×「力矩控制」

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v23 + IP-436–439（其上承 v22 的 HDL/ACSC/DCSC、v21 的 SDC/CAC/DCL/GIC，以及 v20/v19/v17 全部证书链）。
> **本轮纪律**：不推倒 v23。感知证书（SDC/CAC/DCSC/ACSC）、规范层（DCL/GIC）、能量层（PGEV）、云边层（CESC/FSVC/IPAM）全部保留。本轮只做一件事：**在 v23 的"计划证书"之下补上"执行证书"——把证书承诺的对象从"计划 π"改为"被有限带宽、饱和、时延的真实控制器执行出来的轨迹管 T_π"，并用力矩/力作为物理硬包络、独立接触证据与限伤手段，封堵"计划安全 ≠ 执行安全"和"缺席幻觉无法兜底"这两个缺口**。

## 0. 直觉与动机

### 灵感 1（运动控制 → 安全的不是计划，而是计划周围的一根管子）
直觉：v23 的所有证书都在为一个"理想执行者"签发：只要 π 的几何、规范、能量都通过，就默认机器人会精确地沿 π 运动。但真实伺服有带宽、时延、饱和、摩擦、齿隙；一条在纸面上离人 5cm 的轨迹，可能在拐角处因跟踪滞后多冲出 8cm。**证书承诺的对象错了**：它承诺的是参考轨迹，而不是实际状态。运动控制给的正是"最后一米"——一个可证明的跟踪误差管（tracking tube）。安全的不是一条线，而是**参考轨迹周围一根随时间变粗变细的管子**：只要这根管子不碰障碍，执行才是安全的。

严谨：设参考轨迹 `x_ref(t)`、实际状态 `x(t)`、跟踪误差 `e(t)=x(t)-x_ref(t)`。若闭环在度量 `M` 下以速率 `λ` 增量指数稳定、扰动界 `d̄`、输入时延 `τ_d`、饱和缺口 `δ_sat`，则
`‖e(t)‖_M ≤ e^{-λt}‖e(0)‖_M + d̄/λ + L_g u_max τ_d + δ_sat ≜ r(t)`。
定义**跟踪管** `T_π(t) = {x : ‖x - x_ref(t)‖_M ≤ r(t)}`。执行安全谓词：
`TubeSafe(π) ≜ (swept(x_ref) ⊕ T_π) ∩ Obs_t = ∅`。
运行时契约：每个控制拍检查 `x(t) ∈ T_π(t)`；一旦越界，立即降级到已认证的保守回退，**而不是继续追 π**。反直觉点：把控制误差从"工程噪声"提升为"证书半径"后，控制器性能不再是安全论证的外部假设，而是证书的一部分——控制器越差，管子越粗，可执行计划集越小，单调性自动成立。

### 灵感 2（力矩控制 → 物理硬包络 + 独立接触证据 + 柔顺限伤）
直觉：力矩是机器人唯一真正"碰到世界"的地方，它同时扮演三个角色。(a) **硬包络**：任何上层证书都不能要求执行器输出超过 `τ_max`、功率 `P_max`、热限；上层可以"想"，力矩层决定"能不能"。(b) **独立证据**：力矩残差 `r_τ = τ_meas - τ_model` 是物理接触的直接证据，与视觉在物理上独立，不可能被一张对抗贴纸欺骗；但它**是反应式的**——只能证明"已经碰到"，不能提前证明"没人"。(c) **限伤**：阻抗控制把"靠近人必须轻柔"这条义务编译成一个**接触力上限** `F_safe`；即使上一轮的缺席幻觉真的发生，撞上的力也被 `F_safe` 封顶。**我们无法消除漏检，但可以给漏检的后果封顶**。

严谨：力矩预算 `B_τ = {τ : |τ_j| ≤ τ_max,j(T), Σ_j |τ_j q̇_j| ≤ P_max}`；末端力界 `‖F‖ ≤ ‖τ‖ / σ_min(J(q))`（`σ_min → 0` 时证书自动拒绝，向保守退化）；阻抗律 `F_ext ≈ K(x-x_d) + D(ẋ-ẋ_d)`，于是
`‖F_ext‖ ≤ ‖K‖·r(t) + ‖D‖·v_max ≤ F_safe`。
接触残差超阈 `‖r_τ‖ > γ_τ` 持续 `Δt_c` 即产生 `ContactEvent`，硬实时反射（退让/零力矩）在 ≤1 个控制拍内完成，并**局部作废该区域 AbsCert**（翻转为"有人/有物"）。力矩通道作为 CFC 的**本体感知模态**，与视觉/手势在物理上不相关，提升模态多样性；它不能预防缺席幻觉，但能限制缺席幻觉的伤害，并让"漏检后仍撞上"这件事至少留下物理证据。

### 两者如何统一（执行接地层 EGL）
统一为 **v23 之下的"执行接地层"（Execution Grounding Layer, EGL）**："执行即证明"——规划器签发的是**管**的证书，控制器每拍必须证明**自己仍在管内**；力矩层是**物理地板**，任何证书都不得穿透。共享状态 `ζ_exec = ζ_ce ∪ (x_ref, r(t), B_τ, r_τ, Z_imp, F_safe, ContactEvent)`。统一准入门 **HPC-E++ = HPC-E+ ∧ TTC ∧ TBC ∧ (CRC ∨ 无需接触证据) ∧ ICC(近人)**，`Exec_v24 = Exec_v23 ∩ Fil_exec ⊆ Exec_v23`。

关键跨层闭环：DCL 的义务 `O("近人轻柔")` 不再只是计划过滤器，而是被**编译为 ICC 的阻抗参数与力上限**——规范第一次落到力矩层，并且**在感知失败时仍然有效**。这是对上一轮最大风险（合规的缺席幻觉）的纵深防御：几何证书可能骗你，力矩封顶不会。用一句话概括本轮立场：**感知证书负责"别撞上"，执行证书负责"撞不狠"；前者可以被漏检击穿，后者不会。**

## 2. 设计原则（在 P34–P42 基础上新增 P43–P46）

**P43 执行接地律（Execution Grounding）**
任何进入执行的计划必须携带跟踪管证书：`Exec_v24 = {π ∈ Exec_v23 : TubeSafe(π) ∧ x(t) ∈ T_π(t) ∀t}`。管子由闭环增量稳定性与扰动/时延/饱和界导出，而非经验余量；控制器性能直接进入证书半径。运行时每拍做成员检查，越界即降级，**不允许"边追边看"**。

**P44 力矩硬包络律（Torque Hard Envelope）**
力矩/功率/热/关节限是**物理地板**，优先于一切上层证书：`τ(t) ∈ B_τ` 是执行的必要条件，任何规划器、合规规则、意图许可都不得要求越界。`B_τ` 失效（传感器故障）时用模型保守估计并降额降速；`σ_min(J) < σ_floor` 时力界证书拒绝，向保守退化。

**P45 接触即证据律（Contact-as-Evidence）**
力矩残差是独立于视觉的第一类证据：`ContactEvent` 触发后，(i) 立即反射退让，(ii) 局部作废接触点邻域的 AbsCert 并翻转为"有人/有物"，(iii) 向 CFC 注入一个**本体感知模态票**。接触证据只增不减，且其时间戳进入 v17 APS 新鲜度阶梯；TTL 过期后仍保持"该邻域曾有人"的保守记忆直到被独立证据清除。

**P46 柔顺限伤律（Compliance Bounds Harm）**
DCL 的近人义务 `O_gentle` 编译为 ICC 的力上限与阻抗参数：`‖K‖·r(t) + ‖D‖·v_max ≤ F_safe`。若该不等式在给定管径/速度下无解，则**降低速度或停机**，而不是放宽 `F_safe`。由此，即使 AbsCert 为假，实际接触力/冲量仍被 `F_safe` 与反射延迟 `Δt_c` 封顶：`Impulse ≤ F_safe·Δt_c`。限伤保证不依赖检测召回率。

## 3. 与基线的接口（如何退化）

- **TTC 失效**（模型不可信/辨识失败）⇒ 将管子膨胀到保守上界 `r_max`（等价静态安全距离），或直接进入扭矩限幅爬行；仍是 `Exec_v23` 的子集，**不是**回到 v23 的完整计划集；
- **TBC 失效**（力矩传感故障）⇒ 用电流估计 + 模型力矩 + 保守降额，速度上限只降不升；
- **CRC 失效**（无法估计残差）⇒ 不做接触证据，但保持 ICC 与降速；AbsCert 不因接触通道失效而放宽；
- **ICC 失效**（阻抗不可实现）⇒ 近人区退回最大柔顺/停机，远人区按 v23 执行；
- **EGL 整体失效** ⇒ 进入"静态管 + 力矩限幅爬行"模式，`Exec_v24` 仍 ⊆ `Exec_v23`；
- **完全回退** ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`。
- **安全继承**：TTC 只加管约束、TBC 只裁剪力矩、CRC 只增接触证据、ICC 只收紧近人力界；四者都是**交/过滤**，故不会扩大执行集。新增的只有"证据"和"更严的界"，没有"新的自由空间"。

## 4. 预期贡献

1. **执行接地证书**：首次把"计划安全"升级为"闭环执行管安全"，用增量稳定性/ISS 给出可证明的跟踪管，并把控制器性能纳入证书半径；
2. **力矩硬包络与力界**：由关节力矩、热、功率与雅可比条件数导出末端力上界，奇异位形自动拒绝，封堵"规划可行但执行器做不到"的伪可行；
3. **接触即证据**：把力矩残差变成独立于视觉的物理证据模态，既提升 CFC 模态多样性，又在漏检后留下不可伪造的接触记录；
4. **柔顺限伤**：把近人义务编译为力上限，使"缺席幻觉"的伤害有硬上界 `F_safe·Δt_c`——这是对上一轮最大风险的纵深防御；
5. **三层频率解耦**：1kHz 力矩反射、50Hz 规划、10Hz 语义各司其职，接触反射不依赖慢速语义层；
6. **HPC-E++ 统一门**：在 v23 四证之上加执行四证，保持 `Exec_v24 ⊆ Exec_v23` 闭环。

## 5. 本轮最大风险

**一句话**：跟踪管的半径完全由**名义模型**（摩擦、齿隙、负载、温度、时延）算出，若模型失配被低估，认证半径会小于真实跟踪偏差——"管径幻觉"使执行证书形式成立而物理越界，此时唯一兜底是**反应式**的力矩反射，而它可能已经太晚。

## 1. 关键算法骨架（在 IP-436–439 骨架上扩展）

```python
# ============================================================
# IP-440 Tracking Tube Certificate (TTC) — 跟踪管证书
# ============================================================
@dataclass
class TrackingTube:
    x_ref: Callable[[float], np.ndarray]
    r0: float                 # 初始误差界
    lam: float                # 收缩速率 λ
    d_bar: float              # 扰动界 d̄
    Lg_umax: float            # Lipschitz(input) * u_max
    tau_delay: float          # 输入时延 τ_d
    delta_sat: float          # 饱和缺口 δ_sat
    T_horizon: float

    def radius(self, t: float) -> float:
        # 增量 ISS / contraction 上界
        return (math.exp(-self.lam * t) * self.r0
                + self.d_bar / self.lam
                + self.Lg_umax * self.tau_delay
                + self.delta_sat)

    def certify(self, obs: 'ObstacleSet', n_samples: int = 200) -> bool:
        """TubeSafe(π)：扫掠参考轨迹 ⊕ 管 与障碍集不相交"""
        for k in range(n_samples):
            t = self.T_horizon * k / max(n_samples - 1, 1)
            if obs.distance(self.x_ref(t)) <= self.radius(t):
                return False
        return True


class TubeMonitor:
    """运行时成员检查：x(t) 是否仍在管内；模型失配在线膨胀"""
    def __init__(self, tube: TrackingTube, M: np.ndarray,
                 alpha_model: float = 0.01):
        self.tube = tube
        self.M = M
        self.alpha_model = alpha_model
        self.eps_model_hat = 0.0

    def calibrate_model_error(self, residuals: list[float]):
        """对历史跟踪残差做 (1-α) 分位数校准，得到保守膨胀 ε̂_model"""
        if len(residuals) < 30:
            self.eps_model_hat = float('inf')   # 样本不足 → 拒绝执行
            return
        self.eps_model_hat = np.quantile(residuals, 1.0 - self.alpha_model)

    def step(self, t: float, x: np.ndarray, eps_model: float) -> str:
        e = x - self.tube.x_ref(t)
        d = math.sqrt(float(e.T @ self.M @ e))
        r_eff = self.tube.radius(t) + max(eps_model, self.eps_model_hat)
        if d <= r_eff:
            return "IN_TUBE"
        if d <= 1.5 * r_eff:
            return "WARN"        # 收缩速度、请求重认证
        return "VIOLATION"       # 触发保守回退（扭矩限幅爬行）


# ============================================================
# IP-441 Torque Budget Certificate (TBC) — 力矩硬包络
# ============================================================
class TorqueBudgetCertificate:
    def __init__(self, tau_max: np.ndarray, P_max: float,
                 q_min: np.ndarray, q_max: np.ndarray,
                 sigma_floor: float = 0.05):
        self.tau_max = tau_max
        self.P_max = P_max
        self.q_min, self.q_max = q_min, q_max
        self.sigma_floor = sigma_floor

    def check(self, tau, q, qdot, temp) -> bool:
        tau_lim = self.tau_max * self._derate(temp)
        if np.any(np.abs(tau) > tau_lim):
            return False
        if np.sum(np.abs(tau * qdot)) > self.P_max:
            return False
        if np.any(q < self.q_min) or np.any(q > self.q_max):
            return False
        return True

    def _derate(self, temp) -> np.ndarray:
        # 热降额：温度越高，可用力矩越低（单调不增）
        return np.clip(1.0 - 0.005 * (temp - 25.0), 0.3, 1.0)

    def force_bound(self, tau, J) -> float:
        sigma_min = float(np.linalg.svd(J, compute_uv=False)[-1])
        if sigma_min < self.sigma_floor:
            return math.inf      # 奇异位形：证书拒绝，向保守退化
        return float(np.linalg.norm(tau) / sigma_min)

    def certify(self, plan, ctx) -> bool:
        return (self.check(ctx.tau, ctx.q, ctx.qdot, ctx.temp)
                and self.force_bound(ctx.tau, ctx.J) <= ctx.F_limit)

# IP-442 Contact Residual Certificate (CRC) — 接触即证据
# ============================================================
@dataclass
class ContactEvent:
    t: float
    point: np.ndarray
    residual: float


class ContactResidualCertificate:
    def __init__(self, gamma_tau: float, dt_contact: float,
                 sigma_noise: float, cusum_k: float = 0.5,
                 cusum_h: float = 5.0):
        self.gamma_tau = gamma_tau
        self.dt_contact = dt_contact
        self.sigma_noise = sigma_noise
        self.cusum_k, self.cusum_h = cusum_k, cusum_h
        self.g_pos = 0.0
        self.t_above = 0.0

    def update(self, tau_meas, tau_model, dt, contact_point) -> ContactEvent | None:
        r = tau_meas - tau_model
        n = float(np.linalg.norm(r))
        self.g_pos = max(0.0, self.g_pos + n - self.cusum_k * self.sigma_noise)
        self.t_above = self.t_above + dt if n > self.gamma_tau else 0.0
        if self.t_above >= self.dt_contact or self.g_pos > self.cusum_h:
            self.g_pos = 0.0
            self.t_above = 0.0
            return ContactEvent(t=time.now(), point=contact_point, residual=n)
        return None

    def reflex(self, event: ContactEvent, actuator, cac):
        """硬实时反射：零力矩退让 + 局部作废 AbsCert（≤1 个控制拍）"""
        actuator.set_torque(np.zeros_like(event.point))   # 退让/背驱动
        cac.invalidate_local(event.point)                 # 翻转为"有人/有物"
        cac.pin_until_cleared(event.point, ttl=10.0)      # 保守记忆

# IP-443 Impedance Compliance Certificate (ICC) — 柔顺限伤
# ============================================================
@dataclass
class Impedance:
    K: float
    D: float
    F_ceiling: float


class ImpedanceComplianceCertificate:
    def __init__(self, F_safe: float):
        self.F_safe = F_safe

    def select(self, r_tube: float, v_max: float,
               task_stiffness: float) -> Impedance | None:
        # 限伤不等式：‖K‖ r(t) + ‖D‖ v_max ≤ F_safe
        K_max = self.F_safe / (2.0 * max(r_tube, 1e-6))
        D_max = self.F_safe / (2.0 * max(v_max, 1e-6))
        K = min(task_stiffness, K_max)
        D = min(2.0 * math.sqrt(max(K, 1e-9)), D_max)   # 临界阻尼
        if K * r_tube + D * v_max > self.F_safe:
            return None          # 无解 → 降速/停机，绝不放宽 F_safe
        return Impedance(K=K, D=D, F_ceiling=self.F_safe)

    def impulse_bound(self, dt_contact: float) -> float:
        return self.F_safe * dt_contact


# ============================================================
# IP-444 Motion-Torque Contract (MTC) — assume-guarantee 运行时契约
# ============================================================
class MotionTorqueContract:
    def __init__(self, tube_monitor, tbc, crc, icc, v_max, dt):
        self.tube_monitor = tube_monitor
        self.tbc = tbc
        self.crc = crc
        self.icc = icc
        self.v_max = v_max
        self.dt = dt

    def step(self, t, ctx) -> tuple[str, dict]:
        # 1) 规划器假设：状态在管内
        status = self.tube_monitor.step(t, ctx.x, ctx.eps_model)
        if status == "VIOLATION":
            return self.degrade("TUBE_VIOLATION")
        if status == "WARN":
            ctx.v_max = min(ctx.v_max, 0.5 * self.v_max)

        # 2) 控制器保证：力矩在硬包络内
        if not self.tbc.check(ctx.tau, ctx.q, ctx.qdot, ctx.temp):
            return self.degrade("TORQUE_ENVELOPE")

        # 3) 接触证据：独立通道，触发即反射
        ev = self.crc.update(ctx.tau, ctx.tau_model, self.dt, ctx.contact_point)
        if ev is not None:
            self.crc.reflex(ev, ctx.actuator, ctx.cac)
            return self.degrade("CONTACT_EVENT")

        # 4) 近人柔顺限伤
        if ctx.near_human:
            imp = self.icc.select(self.tube_monitor.tube.radius(t),
                                  ctx.v_max, ctx.task_stiffness)
            if imp is None:
                return self.degrade("IMPEDANCE_INFEASIBLE")
            ctx.actuator.set_impedance(imp)

        return "OK", {"tube_radius": self.tube_monitor.tube.radius(t),
                      "tau_margin": float(np.min(
                          self.tbc.tau_max * self.tbc._derate(ctx.temp)
                          - np.abs(ctx.tau)))}

    def degrade(self, reason: str) -> tuple[str, dict]:
        # 单调向保守：只降速/停机/收紧，不放开任何界
        return "DEGRADED", {"reason": reason, "mode": "torque_limited_crawl"}

# IP-445 HPC-E++ 统一执行接地准入门
# ============================================================
@dataclass
class HPCEPlusPlus:
    hpc_e_plus: 'HPCEPlus'
    ttc: TrackingTubeCertificate
    tbc: TorqueBudgetCertificate
    crc: ContactResidualCertificate
    icc: ImpedanceComplianceCertificate

    def admits(self, plan, ctx) -> bool:
        # 1) v23 四证：物理接地 ∧ 云边同步 ∧ 少样本有效 ∧ IP 完备
        if not self.hpc_e_plus.admits(
                plan, ctx.x, ctx.v, ctx.z, ctx.E_res, ctx.margin_req,
                ctx.modules):
            return False
        # 2) 执行管：计划证书 → 执行证书
        if not self.ttc.certify(plan, ctx.obs):
            return False
        # 3) 力矩硬包络与末端力界
        if not self.tbc.certify(plan, ctx):
            return False
        # 4) 接触证据通道可用（不可用时降级而非放宽）
        if not ctx.crc_available and not ctx.contact_free_zone:
            return False
        # 5) 近人柔顺限伤可行
        if ctx.near_human:
            if self.icc.select(self.ttc.radius(0.0), ctx.v_max,
                               ctx.task_stiffness) is None:
                return False
        return True
```

## 3. 正确性论证

### 引理 5（跟踪管包含性）
**陈述**：若闭环在 `M` 下满足增量 ISS：`‖e(t)‖_M ≤ e^{-λt}‖e(0)‖_M + d̄/λ + L_g u_max τ_d + δ_sat`，且模型失配 `ε_model ≤ ε̂_model`，则 `P(∀t∈[0,T], x(t) ∈ T_π(t) ⊕ B_{ε̂_model}) ≥ 1-δ_tube`。

**证明**：
1. 增量 ISS 上界由 contraction 理论/输入-状态稳定性直接给出（Lohmiller & Slotine 1998；Sontag 1989），`r(t)` 即其右端。
2. 模型失配项 `ε̂_model` 由历史跟踪残差的 `(1-α)` 分位数校准；在可交换性假设下，新样本残差以 ≥1-α 落入该分位包络（conformal 覆盖）。
3. 将 `ε̂_model` 加到管半径即得实际包含半径；两者取并仍为确定性上界。
4. `TubeSafe` 在离散采样 `n` 点上检查 `obs.distance ≤ r(t)`；对 Lipschitz 障碍距离，采样加密可将漏检概率压到 `O(1/n)`，取 `n=200` 满足 50Hz 规划精度。
∎

### 引理 6（力矩-力界与限伤）
**陈述**：若 `τ ∈ B_τ`、`σ_min(J) ≥ σ_floor`，且 ICC 选出的 `(K,D)` 满足 `K·r(t)+D·v_max ≤ F_safe`，则末端接触力满足 `‖F_ext‖ ≤ F_safe`，且反射延迟内的冲量 `≤ F_safe·Δt_c`。

**证明**：
1. 静力关系 `τ = J^T F` ⇒ `F = J^{-T}τ`，故 `‖F‖ ≤ ‖J^{-T}‖‖τ‖ = ‖τ‖/σ_min(J) ≤ ‖τ‖/σ_floor`，与 `B_τ` 共同给出力上界。
2. 阻抗接触力 `F_ext ≈ K(x-x_d)+D(ẋ-ẋ_d)`；由跟踪管 `‖x-x_d‖ ≤ r(t)` 与速度界 `‖ẋ-ẋ_d‖ ≤ v_max`，得 `‖F_ext‖ ≤ K r(t) + D v_max`。
3. ICC 的 `select` 强制该不等式 ≤ `F_safe`，否则返回 `None` 触发降速/停机；因此只要执行继续，力界成立。
4. 反射在 `Δt_c` 内将力矩置零，接触力作用时间 ≤ `Δt_c`，冲量 `∫‖F‖dt ≤ F_safe·Δt_c`。
∎

### 引理 7（接触证据的独立性与有界延迟）
**陈述**：`ContactEvent` 只依赖 `(τ_meas, τ_model)`，不依赖任何视觉/手势/语义证书；从真实接触到产生事件的延迟 `≤ Δt_c + 1` 个控制拍；该事件可作为 CFC 的独立本体感知模态票。

**证明**：
1. `CRC.update` 的输入仅为关节力矩测量与模型力矩，与 SDC/CAC/GIC 的数据通路无交集，故物理独立。
2. 检测条件为"残差超阈持续 `Δt_c`"或"CUSUM 超限"；最坏情况下事件在真实接触后 `Δt_c` 内触发，反射在下一控制拍执行，故总延迟 ≤ `Δt_c + 1 tick`。
3. 独立性使其不能被视觉对抗样本伪造；有界延迟保证反射在硬实时预算内。
∎

### 引理 8（执行接地层的单调退化链）
**陈述**：任意单点/组合失效下，`Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18` 恒成立。

**证明**：
- `Exec_v24 = Exec_v23 ∩ Fil_tube ∩ Fil_torque ∩ Fil_contact ∩ Fil_imp`，交运算只减不增，故 ⊆ `Exec_v23`。
- TTC 失效 → 管膨胀到 `r_max` 或进入扭矩限幅爬行，仍是 `Exec_v23` 的子集；
- TBC 失效 → 用保守模型/降额，力矩包络只收紧；
- CRC 失效 → 不产生新证据、不放宽 AbsCert，仅降速；
- ICC 失效 → 近人区停机、远人区按 v23；
- 组合失效取交，单调性保持。
∎

### 定理（HPC-E++ 执行接地准入门的安全性）
**陈述**：对任意计划 π，`HPCEPlusPlus.admits(π) = True` ⇒ π 同时满足：
(1) v23 的物理/规范/负信息/能量/云边/少样本/IP 全部条件；
(2) 执行轨迹以 ≥1-δ_tube 概率落在无碰跟踪管内；
(3) 执行力矩在硬包络内且末端力 ≤ `F_limit`；
(4) 接触通道可用，或处于无需接触证据的免接触区；
(5) 近人时存在满足限伤不等式的阻抗参数，且 `‖F_ext‖ ≤ F_safe`。

**证明**：直接由 `admits` 的五个连言条件与引理 5–8 可得。必要性：任一条件缺失即拒证，对应执行层的一类风险未被覆盖。充分性：五条件全满足时，管包含性、力界、接触证据与限伤共同保证执行安全，且由引理 8 保持对 v23 的单调子集关系。
∎
