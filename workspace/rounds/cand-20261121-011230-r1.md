## 0. 情报底座（沿用已核实事实，只保留与本轮视角相关者）

1. **赛事**：UniBot 世界挑战赛 / UniBot World Challenge，宇树发起；UniBot-V1 为「通才模型」赛道，基于 Unitree G1 真机，32 项桌面操作任务（抓取 / 放置 / 双手协调），按**平均成功率 + 平均步骤分**排名，覆盖 5 类泛化场景：位置 / 干扰物 / 背景 / 未见物品 / 人为干扰。
2. **数据**：官方 HF collection 恰好 32 个 LeRobot v3.0 数据集，一任务一份，单任务 969–1533 episodes（合计 ≈32k episodes / 169 h）；G1 + Dex1 夹爪；4 路 480×640@30fps AV1 相机（头 stereo ×2 + 左右腕）。
3. **接口**：选手本地部署 observation→action 服务；策略须暴露 `metadata` / `get_action(obs)` / `reset()`；`control_space` ∈ {`joint`,`ee`} 互斥；`action_chunk_size` 自定；`obs_delta_indices` 同时决定「传输哪些观测」与「时序叠帧方式」；`image_resize` 由评测端 cv2 缩放；token 在 `metadata` 与每步 `meta.token` 两处校验；评测在 N 台真机上随机顺序执行，必须暴露 8765…8765+N−1 连续端口；官方会采集 per-step 延迟及其波动、返回动作的统计规律性并可能据此评估可信度。
4. **teaser 榜结构**（8 个通才模型 × 32 任务，n=256 个 model-task 点）：榜首平均成功率 29.7%；`step_score ≈ 1.337·success + 0.09`（R²=0.9955）；8 个模型跨任务相对优劣的 Kendall τ 均值 0.064；per-task oracle 33.96、top-2 上界 32.22；最难 6 任务为 Plug In Ethernet 17.7 / Unlock 20.1 / Spell robot 21.8 / Organize Stationery 22.5 / Open Pill Bottle 22.7 / Pick Out Battery 23.3（全是插入 / 旋转 / 细粒度摆放）；任务内 corr(时长, 成功) 均值 −0.011。
5. **跨基准对照**：RoboDojo 真机榜最强策略平均成功率 12.8%、人类 100%，失败被描述为「能完成大部分步骤，却在最后的对齐 / 插入 / 放置 / 恢复阶段崩」。这说明「最后一环」是当前具身基座的共性断点，不是 UniBot 独有怪癖。

## 1. 直觉：把「桌面操作」重新看成一次「自主导航」

### 1.1 自主导航的第一性原理

**直觉解释**：导航真正难的不是「让机器动起来」，而是三件带不确定性的事——**我在哪（定位）、我要去哪（规划）、走偏了怎么拉回来（闭环与恢复）**。一个能在空房间里直行的机器人毫无价值；有价值的是能在搬动过的家具、变化的光照、突然出现的人之间，仍然知道自己在哪、并把自己精确地停到充电座上。导航的皇冠不是长距离巡航，而是 **last-mile docking（最后一米对接）**：扫地机回充、无人机降落、船舶靠泊，都是全局规划器把控制权交给一个高频、局部、看误差的伺服环。对接失败的原因几乎从来不是「不会走」，而是「最后两厘米对不准」。

**严谨定义（骨架，D1–D7 在产物区展开）**：把自主导航写成一个部分可观测决策过程：信念 `b_t = P(x_t | o_{1:t}, a_{1:t})`，地图 `M`，全局路线 `R=(v_1,…,v_L)` 定义在图 `G=(V,E)` 上，局部控制器 `π_local(a|b_t,v_i)`，以及一个**重定位 / 闭环事件** `ℓ_t`——当观测与航位推算的预测矛盾超过阈值时，用观测重置信念。核心量是**漂移** `e_t = x̂_t − x_t`：没有闭环，`‖e_t‖` 随步数增长；有闭环，误差被观测精度重新钉住。

### 1.2 映射：桌面操作与导航同构

把桌面任务放进这个框架，不是比喻，而是逐项对应：

| 导航概念 | 桌面操作中的对应物 |
|---|---|
| 构型空间 / 自由空间 | 机械臂关节空间 / 无碰撞的桌面可达空间 |
| 地图 `M` | 任务-子目标拓扑图 + 物体/可供性图（不是米制地图） |
| 定位 `x_t` | 夹爪位姿 + 目标物体位姿 + 任务相位/进度，统一在任务坐标系 |
| 全局路线 `R` | reach→grasp→lift→transport→align→insert→release 的子目标序列 |
| 局部控制器 | 相位条件化的动作块策略（VLA 专家） |
| 代价地图 / 障碍 | 干扰物、桌沿、易碰倒物体、人的手 |
| 航位推算漂移 | 开环动作块累积的位姿误差 |
| 回环 / 重定位 | 用腕部/头部相机重新观测目标，校正相对位姿 |
| Last-mile docking | **对齐 / 插入 / 放置 / 释放**——恰是 teaser 榜最难的一类 |
| 卡死检测与恢复 | 无进展检测、后退、重抓、换路、重新观察 |

这个映射给出一个尖锐的假设：**过去把最后一环失败归因于「抓取不稳」，但按导航视角，它更像「对接段缺少高频相对定位与漂移校正」**。抓取只是导航中的一个局部估计问题；真正缺的是一整层「信念 + 路线 + 对接 + 恢复」。

### 1.3 5 类泛化场景 = 导航的五类经典鲁棒性轴

这是本轮最关键的结构性证据：官方给的 5 类泛化场景，几乎一一对应自主导航几十年来反复研究的五类失效模式。若对应成立，则「泛化」不是玄学，而是可被经典工具逐条拆解的工程问题。

| 官方泛化场景 | 导航中的同构问题 | 对策略的直接含义 |
|---|---|---|
| **位置变化** | 全局定位失败 / 初始位姿先验错 | 不能假设固定初始位姿；需从头部相机做全局重定位，多假设初始化 |
| **干扰物** | 杂乱环境中的数据关联 / 假地标 | 需显式数据关联与风险场，而不是让大模型「自己忽略」 |
| **背景变化** | 外观变化导致感知歧义（perceptual aliasing） | 依赖几何/相对特征做对接，不能只靠纹理匹配 |
| **未见物品** | 开放集地标 / 地图外区域 | 需开放集检测 + 几何退路，检测不到时优雅降级 |
| **人为干扰** | 动态障碍 / 移动主体 | 需滚动时域重规划与风险场膨胀，而非一次性规划 |

> 这条映射的用处：它把「我们的模型在 5 类场景下不够鲁棒」从一句空话，变成 5 个**可分别度量、可分别修复**的模块清单。

### 1.4 第二灵感 UniBot-V1：赛制把「闭环」变成合法且被奖励的对象

UniBot-V1 允许选手自行部署、远程接入、反复提交，并会采集 per-step 延迟与动作统计——这意味着**推理期闭环**是被允许的差异化空间，不必把全部赌注压在训练期域随机化上（那是所有队伍的公共做法，收益已被摊薄）。但赛制同时给了两条硬约束：单 checkpoint、单 API；`reset()` 每 episode 清空状态。因此任何「地图」只能是**离线先验**，任何「在线状态」必须**按端口 episode 隔离**，不能跨 episode 学习。这不是障碍，反而逼出一个干净的合规定位：**导航式闭环只发生在 episode 内，地图是只读先验。**

### 1.5 合成：UniBot-ANCHOR

**ANCHOR = Affordance/topology map · Navigation-style belief localization · Cost/risk field · Hierarchical planner · Online monitor & recovery · Relocalization/loop closure。**

一句话：**给 VLA 装上一套导航栈**——离线学一张任务/物体拓扑图，在线维护「夹爪-物体-进度」的信念，按路线调技能，用风险场避干扰，用无进展检测触发恢复，并在对接前用重定位把漂移钉死。

它与上一版 SAGE 的关系是**包含而非替代**：SAGE 的「抓握接地层」成为 ANCHOR 信念状态里的一个分量；「技能专家」成为路线图上的一条边；「上下文适应」成为对只读地图/风险场的推理期条件化。新增的正是 SAGE 缺失的那层：**空间信念、路线选择、对接闭环与漂移校正**。

## 2. 量化瓶颈：把 teaser 榜翻译成导航语言

| 观测（teaser） | 导航式解读 | 推出的设计 |
|---|---|---|
| `step ≈ 1.337·succ + 0.09`，R²=0.9955 | 终态是唯一货币，中途「多走几步」不计分 | 只优化「是否抵达并对接成功」；不追求快 |
| 跨任务 Kendall τ 均值 0.064 | 专长近似准正交 ⇒ 每个任务的最优「路线/技能组合」不同 | 路线规划有真实上界：oracle 33.96 vs 最好单模型 29.70 = **+4.26** |
| 最难 6 任务全是插入/旋转/细粒度摆放 | 这些是**对接任务**，误差容限极小 | 火力集中在 DockServo（相对位姿闭环 + 漂移校正） |
| 任务内 corr(时长, 成功) −0.011，episode 43.7–45.2 s | 「走得快」没有红利 | 允许减速换精度：对接段降速、短 chunk、高频反馈 |
| 5 类泛化场景 ↔ 5 类导航鲁棒性轴 | 泛化可拆成定位/关联/歧义/开放集/动态障碍 | 每类场景绑定一个可验收模块，而非笼统「域随机化」 |
| RoboDojo「崩在最后对齐/插入/恢复」 | 与 UniBot 同源：全局段能做，对接段崩 | 对接段与恢复段是跨基准可复用的公共瓶颈 |

**一句话结论**：上一轮押「抓握」，这一轮押「对接」。抓握决定「有没有拿住」，对接决定「拿住之后能不能放进那 2 mm」。在 teaser 的难度排序里，后者才是分数的主要流失点。

## 3. 研究问题（轮次版）

- **Q1（漂移是否为主因）**：在官方数据上，用动作航位推算的末端位姿与观测位姿之间的误差，随 chunk / 步数如何增长？最后一环失败中，有多大比例可归因于「位姿漂移超过容限」而非接触/夹持物理？若漂移不是主因，本轮整个重构应被剪掉。
- **Q2（可观测性）**：只有 1 维夹爪标量、无触觉、腕部单目 + 头部双目，能否稳定估计「目标相对夹爪的位姿」与「任务进度」？在背景变化与未见物品下，几何特征还剩多少可用信号？
- **Q3（对接交接）**：全局策略何时把控制权交给 DockServo？交接阈值应基于位姿协方差还是相位分类置信度？早交会放大初始误差，晚交会累积漂移，最优点在哪？
- **Q4（卡死与恢复）**：如何定义「无进展」使其高精度、低误触发？恢复动作集合（重定位 / 重接近 / 回退到上一可信节点 / 重抓 / 换路）的净收益是否为正，边界在哪？
- **Q5（合规与地图边界）**：离线只读地图 + episode 内状态是否满足「单模型、单 API、`reset()` 清空」？地图里若含任务 ID 分支，会不会被视为硬编码？跨 episode 不学习的前提下，地图先验还能兑现多少增益？

## 4. 设计原则

- **P1 对接是唯一计分货币**：所有创新必须能写成「缩短对接段终态误差 / 提高对接成功率」的因果链。
- **P2 信念先于动作**：夹爪位姿、物体位姿、相位、进度一律建模为带协方差的信念，不当作已知量。
- **P3 闭环优于开环，重定位优于平滑**：action chunk 缝合只能让轨迹好看，不能消除漂移；真正的校正来自「重新看一眼目标」。
- **P4 分层而非单体**：全局路线在离散图上选，局部控制在连续空间里做；两层各自可失败、可降级、可审计。
- **P5 地图是只读先验，状态是 episode 局部**：不跨 episode 写地图、不在线更新主干；合规优先于最优。
- **P6 每一类泛化场景绑定一个模块与一个指标**：不做「更鲁棒」这种不可验收的承诺。

## 5. 最小可提交闭环（MVP）与严格退化链

**MVP = NavBench 漂移回放（IP-04） + DockServo 对接伺服（IP-02） + StuckMonitor/Recovery（IP-03） + 通用 VLA 基线。**
理由：IP-04 先用官方数据判定「漂移是否为主因」，这是本轮最便宜、最可证伪的一步；IP-02/IP-03 直接打在对接段与恢复段，不依赖新数据；地图/路线（IP-05）放在其后，因为它需要先证明定位信号可用。

**严格退化链（任一环节不可用 ⇒ 行为回退而非漂移）**：
- **Level-0** 信念定位不可用（协方差过大 / 无有效观测）⇒ 退回开环 VLA，但保留无进展检测。
- **Level-1** DockServo 不可用（相对位姿估计失败）⇒ 退回全局策略原动作块，并在对接前减速。
- **Level-2** 无进展检测不可用（阈值失准）⇒ 退回「不干预」的开环执行，禁用恢复动作。
- **Level-3** 路线图不可用（任务/物体 token 错配）⇒ 退回单一路线（通用专家）。
- **Level-4** 整条新链路失效 ⇒ 退回**纯基线策略**（一份能跑通、可信度合规的最小提交永远保留）。

## 6. 预期贡献（可验收）

1. **一条可测量的漂移定律**：用官方 32 个数据集的 `action` 与 `observation.state.*_ee_pose_gripper_base` 拟合「每步 / 每 chunk 的位姿误差增长率 δ」，给出每个任务的**对接地平线**（误差达到容限前的最大开环步数）——这是全赛道可直接复用的公共品。
2. **一个信念式对接控制器**：把「对齐/插入」从开环动作块变成基于腕部相对位姿的高频伺服，并给出基于协方差的交接判据与校准曲线。
3. **一套导航语言的失败分解**：把 5 类泛化场景映射到定位/关联/歧义/开放集/动态障碍五个因子，替代笼统的「泛化不够」。
4. **量化路线红利**：在 teaser 结构上给出 oracle +4.26 的上界，并测出「从观测推断路线」的可兑现比例。
5. **一套合规形态**：离线只读地图 + episode 局部状态 + 无跨 episode 学习，明确回答 Q5。
6. **可审计的工程层**：延迟、chunk 边界、端口隔离、恢复次数全部可导出，对齐官方可信度口径。

## 7. 本轮最大风险

**一句话**：本轮把「最后一环失败」归因为可被闭环纠正的**定位/漂移**问题，但若真机对接段的主导误差其实是接触力、摩擦与夹持滑移（而非位姿漂移），那么 DockServo 的视觉伺服根本使不上力，整套「导航化」重构就会退化成昂贵的隐喻——因此必须在写任何模型之前，先用官方数据把「漂移占失败的比例」量出来。

## 8. 下一轮迭代计划（深化与修剪）

- **深化**：把 BeliefLocalizer 从单假设升级为**多假设**（应对外观歧义与初始位置变化），把 StuckMonitor 与相位分类器共享特征，把 DockServo 的增益调度与风险场耦合（靠近障碍时主动降速）。
- **修剪预案**：若 E801 显示漂移对终态误差的解释力低于 30%，则**砍掉 DockServo 主线**，只保留 NavBench 与 StuckMonitor/Recovery，把资源退回接触/夹持物理建模。
- **保留项**：IP-04（NavBench，信息价值最高）、IP-03（恢复，机制正确性）、IP-01（信念定位，所有闭环的前提）三项不砍。

## 0. 本轮结论摘要

**一句话路线**：把「桌面操作」重构成一次**自主导航**——离线学一张任务/物体拓扑图，在线维护「夹爪-物体-进度」信念，按路线调技能，用风险场避干扰，用无进展检测触发恢复，并在对接前用**重定位**把航位推算的漂移钉死。

**为什么是导航视角（量化依据，teaser n=256）**：

| 证据 | 数值 | 推出的设计 |
|---|---|---|
| `step_score ≈ 1.337·success + 0.09`，R²=0.9955 | 终态是唯一货币 | 只优化「抵达并对接成功」；不为提速牺牲精度（P1） |
| 8 模型跨任务 Kendall τ 均值 0.064；oracle 33.96 vs best 29.70 | 专长准正交 ⇒ 路线组合有上界 **+4.26** | AnchorMap + RoutePlanner（IP-05）；可兑现比例单独度量 |
| 最难 6 任务全是插入/旋转/细粒度摆放 | 本质是**对接**，容限极小 | DockServo 相对位姿闭环 + 漂移校正（IP-02）为主火力 |
| 时长与成功无关（任务内 corr −0.011） | 快无红利 | 对接段主动降速、短 chunk、高频反馈 |
| 5 类泛化场景 ↔ 导航五类鲁棒性轴 | 泛化可拆成定位/关联/歧义/开放集/动态障碍 | 每类场景绑定一个模块与一个指标（IP-01/05/06） |
| RoboDojo 最强 12.8%、人类 100%，崩在最后对齐/插入/恢复 | 共性断点在最后一段 | 恢复层（IP-03）是跨基准可复用资产 |

**合规红线（P5）**：单一 checkpoint、单一 API；地图只做**离线只读先验**；所有在线状态按端口 episode 隔离，`reset()` 全清；不跨 episode 更新权重；不读取评测侧私有信息；不做「读题即硬编码」的任务分支。

## 2. 创新点详述

### IP-01 · BeliefLocalizer 信念定位 + 重定位（P0）

- **动机**：导航的第一性问题是「我在哪」；桌面操作里对应「目标相对夹爪在哪、我到哪个相位了」。接口只给 1 维夹爪标量、无触觉，但有 4 路相机与 EE 位姿——足以支撑一个几何信念，而不必依赖大模型隐式记住空间关系。
- **与现有方案的差异**：通用 VLA 把空间关系隐式编码在动作块里，开环执行、无协方差、无重定位；我们把「位姿 + 相位 + 进度」显式化为信念，并在观测与航位推算矛盾时**重置**信念。
- **技术可行性**：高。目标相对位姿可由腕部图像 + 头部深度/多视图 + EE 位姿几何求解；协方差可由检测/匹配残差传播；相位由视觉 + 夹爪标量 + EE 速度分类。所有输入都在观测里。
- **所需资源**：检测/匹配器（ViT-S/ResNet18 级）+ 几何求解；单卡数小时训练，在线 ≤8 ms。
- **落地步骤**：①在官方数据上对齐坐标系与键名；②训练目标相对位姿回归/匹配器并做校准；③实现 Bayes 更新与协方差传播；④定义重定位触发（Mahalanobis 距离超阈 / 多假设熵超阈）；⑤在多假设下输出 top-k 目标位姿；⑥消融「有/无重定位」。
- **风险**：①腕部遮挡/反光导致位姿不可观 ⇒ 多假设 + 头部视图兜底；②几何求解误差在未见物体上放大 ⇒ 用几何退路与置信门控；③重定位误触发引入抖动 ⇒ 加迟滞与最小驻留时间。

### IP-02 · DockServo 对接伺服（P0）

- **动机**：teaser 最难任务（Plug In Ethernet 17.7、Unlock 20.1、Spell robot 21.8、Open Pill Bottle 22.7）本质都是「最后几毫米/几度」的对接。开环 chunk 在此处必然累积漂移，且 chunk 边界最易产生尖峰。
- **与现有方案的差异**：别人用更大模型端到端吞掉对接；我们把对接显式拆成「全局接近 → 交给高频相对位姿伺服 → 接触后降速/保持」。这不是新增接口，而是推理期控制结构。
- **技术可行性**：高–中。相对位姿来自 IP-01；若 `control_space=ee`，直接输出末端增量；若 `joint`，用离线回归的 IK 代理把 ee 目标映到关节。接触力不可观测，故只能做「位置伺服 + 减速 + 轻推」而非力控。
- **所需资源**：无新数据；在线 ≤8 ms；算力极小。
- **落地步骤**：①离线用官方数据拟合动作→EE 的 IK 代理并验证（<1 cm）；②实现基于误差与其导数的 PD 伺服（含旋转项）；③定义交接判据（协方差进入捕获域 + 相位为 align/insert）；④实现增益调度：风险场高或接触邻近时降速；⑤在难任务做 A/B（固定 chunk vs DockServo）。
- **风险**：①**若主导误差是接触/摩擦而非位姿漂移，视觉伺服无效**（本轮最大风险，先用 IP-04 证伪）；②短 chunk 增加调用次数与延迟 ⇒ 压测；③ee 与 joint 语义不一致 ⇒ 用 IK 代理并留开环回退。

### IP-03 · StuckMonitor + Recovery 无进展检测与恢复（P0）

- **动机**：导航靠「无进展」检测发现卡死；桌面任务同样会「夹着空、顶着桌沿、插不进去、原地抖」。没有检测，一切失败都变成超时硬失败。
- **与现有方案的差异**：通用策略没有显式卡死概念；我们把「到目标距离是否下降 / 相位是否推进」做成可观测标量，并绑定有限恢复库。
- **技术可行性**：高（规则 + 轻量学习）。全部信号在观测里；恢复动作是有限的、可预算的。
- **所需资源**：无新数据；在线 <1 ms（标量滤波）。
- **落地步骤**：①定义进度信号 ρ_t；②在官方成功/失败回放上标定阈值与窗口；③实现有限恢复：重定位观察 / 后退重接近 / 回退到上一可信节点 / 重抓 / 换路；④每 episode 恢复预算 ≤3 次且恢复后必须验证进度；⑤真机 A/B 检验净收益。
- **风险**：①误触发把正常慢相位判成卡死 ⇒ 高阈值 + 迟滞 + 仅在非 transport 相位启用；②恢复动作破坏场景 ⇒ 恢复库限用于单物体、且有风险场约束；③恢复次数过多被判不可信 ⇒ 审计并限制上限。

### IP-04 · NavBench 漂移回放代理评测（P0）

- **动机**：真机时段极稀缺，而「漂移是否主因」是本轮的总开关。必须先用官方数据给出**可证伪的量化结论**，再决定是否投入 DockServo。
- **与现有方案的差异**：常见代理评测只测「任务成功率」；NavBench 测**动力学量**——由动作航位推算的 EE 位姿与观测 EE 位姿之差，及其随 chunk/步数的增长。
- **技术可行性**：高。官方数据同时含 `action.joint/ee` 与 `observation.state.*_ee_pose_gripper_base`，可直接做一步预测残差；用 P90 累积误差估计对接地平线。
- **所需资源**：数据 = 官方 32 数据集；算力 = 单卡数小时；无接口要求。
- **落地步骤**：①统一解码 action 与 EE 观测；②拟合「一步漂移残差」分布；③按任务给出累积误差曲线与对接地平线 `K*`；④定义「漂移解释的终态误差比例」；⑤与少量真机 A/B 做相关性锚定。
- **风险**：①观测 EE 本身的标定误差会混入漂移估计 ⇒ 用双向一致性检查；②不同任务容限不同 ⇒ 用成功 episode 的末段误差分布估计容限；③相关性不足 ⇒ 预注册剪枝（见 §8）。

### IP-05 · AnchorMap + RoutePlanner 拓扑图与路线规划（P1）

- **动机**：teaser 里模型跨任务准正交（τ≈0.064），per-task oracle 比最好单模型高 +4.26。导航视角把它解释为「每项任务的最优路线/技能组合不同」，于是「通才」= 在图上选对边。
- **与现有方案的差异**：不是训 32 个策略，而是离线建一张**任务-子目标-物体/可供性图**，在线根据语言与观测选一条边序列；单 checkpoint 内以 token 条件化兑现。
- **技术可行性**：中。图可从官方数据自动挖掘（任务→阶段序列、物体共现、可供性标签）；路线选择可用轻量策略或图搜索 + 学习价值函数。
- **所需资源**：数据 + 中等算力；在线 ≤3 ms。
- **落地步骤**：①自动抽取阶段序列与物体/可供性节点；②建图并验证边复用（每条边至少服务 2 个任务）；③训练路线价值函数；④在线按语言 + 信念选路；⑤与 oracle 路由对比，测可兑现比例。
- **风险**：①图过拟合任务 ID ⇒ 用语言/几何节点而非任务编号，避免硬编码；②路线错导致错上加错 ⇒ 低置信退回通用路线；③合规疑问（多专家） ⇒ 先做「单专家 + 路线 token」严格形态。

### IP-06 · RiskField 风险场与动态障碍（P1）

- **动机**：官方 5 类场景里的「干扰物」与「人为干扰」正是导航的静态杂乱与动态障碍。让大模型「学会忽略」既不可解释也不可验收。
- **与现有方案的差异**：显式构建桌面风险场（干扰物、桌沿、易倒物、人手），并让局部规划/伺服在风险高处降速、绕行、等待。
- **技术可行性**：中。可从头部/腕部图像 + 深度估计障碍；人手可用运动检测；滚动时域重规划用短 chunk。
- **所需资源**：在线 ≤5 ms；小算力。
- **落地步骤**：①风险场构建与可视化；②与 DockServo 耦合（风险高 ⇒ 降速/抬升）；③人手进入时暂停/绕行/重规划；④A/B 验证。
- **风险**：①风险场误检把目标当障碍 ⇒ 目标区强制降权；②过度保守拖长时长 ⇒ 时长不计分，可接受，但不得影响成功率；③动态障碍速度估计噪声 ⇒ 膨胀半径取保守上界。

### IP-07 · FrameBridge 坐标系桥接与标定残差（P2）

- **动机**：头/腕/基座坐标不一致是「看起来对准了其实没对准」的隐形来源；不解决它，DockServo 的误差会被系统性偏置吃掉。
- **与现有方案的差异**：多数提交直接用原始 EE 位姿；我们显式估计 `T_base←head`、`T_base←wrist` 的残差并在 episode 内补偿。
- **技术可行性**：中；需要官方相机参数或自标定。收益可能被评测端语义吃掉，故设 P2。
- **落地步骤**：①读取/探测相机外参；②用标定板或场景结构自标定；③估计残差并在线补偿（episode 内）；④验证重投影误差。
- **风险**：外参不可得 / 评测端已校正 ⇒ 收益为 0；先做一次零成本探测再决定。

### IP-08 · AuditLayer 可审计提交层（P2，审计并入 IP-02/03）

- **动机**：官方明确采集 per-step 延迟波动与动作统计规律性并据此评估可信度；成功率接近时，可审计性是相对优势。
- **与现有方案的差异**：把可信度要求变成可导出的工程产物：延迟直方图、chunk 边界连续性断言、恢复次数、N 端口隔离自检。
- **落地步骤**：①埋点；②N 端口 × 8 h 并发压测；③动作离群检测与限幅；④导出报告。
- **风险**：过度平滑/限幅压低成功率 ⇒ 只作用残差；「过于规律」被视为脚本化 ⇒ 保留策略固有随机性。

## 3. 符号与定义（D1–D12）

| 符号 | 含义 |
|---|---|
| `b_t` | 信念状态：目标位姿、夹爪位姿、相位、进度、路线假设 |
| `F` | 任务坐标系（基座或桌面），所有位姿统一到 `F` |
| `e_t` | 漂移：航位推算位姿与真实/观测位姿之差 |
| `M` | AnchorMap：任务-子目标-物体/可供性拓扑图 |
| `R` | 路线（图上的节点/边序列） |
| `C(x)` | 风险场 |
| `ρ_t` | 进度信号 |
| `r_c` | 对接捕获半径（位置 + 角度容限） |
| `H(b)` | 交接判据：是否把控制权交给 DockServo |
| `δ` | 单步漂移残差尺度 |

**定义 D1（信念状态）** `b_t = (μ_t^o, Σ_t^o, μ_t^g, Σ_t^g, p_t^phase, p_t^prog, h_t^R)`，其中 `o` 为目标物体、`g` 为夹爪，`h_t^R` 为路线/定位假设分布。
**定义 D2（任务坐标系与桥接）** 所有位姿用 `T_F←X(t)` 表示；`FrameBridge` 估计并补偿 `T_F←cam` 与 `T_F←ee` 的标定残差。
**定义 D3（定位更新）** `b_t ∝ P(o_t | x_t) ∫ P(x_t | x_{t-1}, a_{t-1}) b_{t-1} dx_{t-1}`；观测模型由相对位姿回归/匹配残差给出。
**定义 D4（漂移与对接地平线）** 航位推算误差满足 `e_{t+1} = e_t + η_t`，`‖η_t‖ ≤ δ`；开环 `K` 步后 `‖e‖ ≤ Kδ`。给定任务容限 `r_c`，**对接地平线** `K* = max{K : P90(‖e_K‖) ≤ r_c}`。
**定义 D5（重定位/回环事件）** 当 `D_M(μ_t^o, o_t) > χ²_α`（或假设熵 `H(h_t^R) > H_max`）时触发 `ℓ_t`：用观测重置 `μ_t^o, Σ_t^o`，并把 `h_t^R` 重加权。
**定义 D6（AnchorMap）** `M = (V, E, A)`：`V` 为子目标/物体/关键帧节点，`E` 为可复用技能边（带前置/效果），`A` 为可供性属性；`M` 离线构建、推理期只读。
**定义 D7（路线与路线价值）** `R = (v_1,…,v_L)`；`V(R) = ∏_{e∈R} P_e · (1 − λ·C_e)`，`P_e` 为技能边成功率、`C_e` 为风险代价。
**定义 D8（分层策略）** `π(a_{t:t+T} | o, ℓ) = π_local(a | b_t, v_i, e_i)`，其中 `R = π_global(b_t, ℓ, M)`，`v_i` 为当前节点，`e_i` 为当前边。
**定义 D9（对接误差与交接）** `e_dock = T_target←gripper`；`H(b) = [e_dock^T Σ_dock^{-1} e_dock ≤ κ²] ∧ [argmax p^phase ∈ {align, insert}] ∧ [ρ_t 稳定]`。
**定义 D10（风险场）** `C(x) = Σ_j w_j exp(−‖x−x_j‖²/2σ_j²) + w_h·(v_h·Δ + d_stop)`，后项为人手动态膨胀。
**定义 D11（进度与卡死）** `ρ_t = −(d_t − d_{t−W})/W + λ_p·Δphase`；`stuck_t = [ρ_t < ε for W consecutive steps]`。
**定义 D12（地图作用域与合规）** `M` 为离线只读先验；`M_ep` 为端口局部临时地图，`reset()` 清空；不写回 `M`，不跨 episode 更新任何权重。

            "obs_delta_indices": {

                "observation.images.cam_left_high":  [0],
                "observation.images.cam_right_high": [0],
                "observation.images.cam_left_wrist":  [-4, -2, 0],
                "observation.images.cam_right_wrist": [-4, -2, 0],
                "observation.state.left_ee_pose_gripper_base":  [-4, -2, 0],
                "observation.state.right_ee_pose_gripper_base": [-4, -2, 0],
                "observation.state.left_gripper":  [-4, -2, 0],
                "observation.state.right_gripper": [-4, -2, 0],
                "observation.state.lower_body": [-2, 0],
            },
            "image_resize": {
                "observation.images.cam_left_high":  [240, 320],
                "observation.images.cam_right_high": [240, 320],
                "observation.images.cam_left_wrist":  [240, 320],
                "observation.images.cam_right_wrist": [240, 320],
            },
            "action_chunk_size": 8,
            "token": os.environ["UNIBOT_SUBMISSION_TOKEN"],
        }

    def reset(self, port=None):
        self.sessions[port] = Session()               # 清空该端口全部 episode 状态

    def get_action(self, obs, port=None):
        s = self.sessions.setdefault(port, Session())
        t0 = time.perf_counter()

        b = self.loc.update(obs, s.b)                 # D3：信念更新 + 协方差
        if self.loc.needs_relocalize(b, obs):         # D5：回环/重定位
            b = self.loc.relocalize(obs, b)
        s.b = b

        C = self.risk.field(obs)                       # D10
        route = self.map.route(b, obs["observation.language"])  # D7/D8

        if self.dock.should_takeover(b, route, C):     # D9：交接判据
            a = self.dock.servo(b, obs, C)             # IP-02：高频相对位姿伺服
        else:
            a = self.model.act(obs, b, route, C)       # 全局接近，短/长 chunk 由相位定

        if self.mon.stuck(obs, b):                     # D11
            a = self.mon.recover(obs, b, s)            # IP-03：有限恢复库
        a = self.audit.clamp_and_log(a, obs, t0, self.tau_budget_ms)
        return self.pack(a, obs)

    def pack(self, a, obs):
        return {
            "meta.token": os.environ["UNIBOT_SUBMISSION_TOKEN"],
            "action.left_gripper":  a["left_gripper"].astype(np.float32),
            "action.right_gripper": a["right_gripper"].astype(np.float32),
            "action.pivot":         a["pivot"].astype(np.float32),
            "action.left_arm":      a["left_arm"].astype(np.float32),
            "action.right_arm":     a["right_arm"].astype(np.float32),
        }
```

# ===== IP-01：信念更新 / 重定位（多假设）=====
class BeliefLocalizer:
    def update(self, obs, b_prev):
        z = self.relative_pose(obs)                   # 腕部 + 头部 → T_target←gripper
        b_pred = self.predict(b_prev, obs["action"])  # 航位推算
        return self.bayes(b_pred, z)                  # 协方差传播

    def needs_relocalize(self, b, obs):
        return (mahalanobis(b.mu_o, b.sigma_o, self.observe(obs)) > self.chi2
                or entropy(b.h_R) > self.H_max)

    def relocalize(self, obs, b):
        hyps = self.multi_hypothesis(obs)             # 应对背景变化 / 初始位置变化
        return self.reweight(b, hyps)                 # D5

# ===== IP-02：对接伺服（位置环 + 降速，无触觉下的保守策略）=====
class DockServo:
    def should_takeover(self, b, route, C):
        return (b.dock_mahalanobis() <= self.kappa**2
                and b.phase in ("align", "insert")
                and b.progress_stable)

    def servo(self, b, obs, C):
        e, de = b.e_dock, b.de_dock                # 位姿误差 + 差分
        u = self.Kp @ e + self.Kd @ de             # 位置/旋转 PD
        u *= self.gain(C, obs)                     # 风险高 ⇒ 降速
        return self.limit(u)                       # 限幅；保留短 chunk 高频闭环
```

# ===== IP-04：NavBench 漂移回放 =====
def fit_drift(episodes):
    """用 action 航位推算 EE，与 observation.state.*_ee_pose 对比，拟合单步漂移。"""
    residuals = []
    for ep in episodes:
        x_hat = ep.obs.ee_pose[0]
        for t in range(len(ep.action) - 1):
            x_hat = fk_or_ik_proxy(x_hat, ep.action[t])     # 一步航位推算
            residuals.append(x_hat - ep.obs.ee_pose[t + 1])
    delta = np.percentile(np.linalg.norm(residuals, axis=1), 90)
    return delta                                            # δ（P90 单步漂移）

def docking_horizon(delta, tolerance):
    return max(k for k in range(1, 200) if k * delta <= tolerance)  # K*

## 5. 推导（引理 L1–L7）

**引理 L1（开环漂移与重定位上界）** 在漂移模型 `e_{t+1}=e_t+η_t, ‖η_t‖≤δ` 下，开环 `K` 步误差 `≤Kδ`；若每隔 `K` 步做一次重定位，且观测误差 `‖ν‖≤ε`，则任意时刻误差 `≤ ε + Kδ`。故存在 `K*` 使误差落入捕获半径 `r_c`；**若 E801 实测 `K*` 远大于真实 episode 长度，说明漂移不是主因，DockServo 前提不成立**。∎

**引理 L2（交接阈值的存在性）** 设 todo 初始对接误差期望随交接提前量增加而增加，累积漂移随交接延后量增加而增加；两者单调，故存在使 `E[‖e_T‖]` 最小的交接点，对应 D9 的 `H(b)`。推论：固定步数交接是次优的，应交由协方差/相位决定。∎

**引理 L3（路线分解与 oracle 上界）** 若技能边在任务间的相对优劣近似独立（teaser τ≈0.064），则 per-task 选边的期望成功率高于任何单一全局路线，其上界由 oracle 给出：`33.96 − 29.70 = +4.26`。实际增益 = 可兑现比例 × 上界；可兑现比例由「路线可观测性」决定，不会自动等于 1。∎

**引理 L4（卡死检测的净收益条件）** 设卡死召回 `r`、误触发率 `α`、恢复收益 `g`、误伤损失 `l`、开销 `c`，净收益 `Δ = r·g − α·l − c`。取阈值使 `α ≤ 0.05` 且 `g ≥ 2l` 时 `Δ>0`。∎

**引理 L5（感知歧义不可由开环消解）** 若两个场景在观测上同分布但目标位姿不同，则任何仅依赖观测的确定性开环策略都无法区分；必须引入**主动探测**（移动到可区分视角）或**多假设信念**。这解释了「位置/背景」两类场景为何需要重定位而非更大模型。∎

**引理 L6（动态障碍的滚动重规划安全性）** 设人手最大速度 `v_h`、重规划周期 `Δ`、机器人停距 `d_stop`；若风险场膨胀半径 `≥ v_h·Δ + d_stop`，则每个周期内障碍无法进入当前已承诺轨迹的碰撞域，滚动时域重规划可保持无碰撞。∎

**引理 L7（开放集退路的优雅降级）** 若检测置信度低于 `τ` 时切换到几何对接（边缘/深度/相对伺服），则终态误差由特征噪声 `σ_f` 与控制器增益决定，存在上界 `O(σ_f/λ_min)`；因此「检测不到」退化为精度下降而非盲目执行。∎
