# 第 70 轮（承接第 69 轮「FLUID-RAS 不确定性二分交互闭环」IP-253~263；灵感循环第 3 轮；本轮灵感：「开放词汇」×「步态规划」）

> R69 教会了闭环「去问」：把不确定性拆成 aleatoric / epistemic，用流匹配的多模态动作显式呈现歧义，用 VoI 选一个信息动作去消解。但 R69 隐含了三个从未被点破的前提：
> - 它的模态是**匿名闭集**：K 个采样聚成 K̂ 个簇，模态权重靠闭集 ECE 校准——它无法表达「我看到的东西根本不在我的词典里」；
> - 它的 VoI **没有截止时间**：可以「等」、可以「慢慢看」，但步态有硬相位，错过摆动/支撑切换，信息当场作废；
> - 它的 λ 是**标量**：可足式机器人的风险随相位脉动，支撑相与摆动相的风险结构根本不是一回事。
>
> 更关键的是，R69 的第二意见是**策略似然**（测「行为是否自洽」）。足式系统还多一条更硬的通道：**接触残差**（测「世界是否如语言所说」）。语言会说谎，地面不太会。
>
> 本轮两个灵感正好补上这三块：
> - **开放词汇**：世界会用我没有的词；词典本身是一个不确定对象，需要第三种不确定性；
> - **步态规划**：每个落脚点都是一次对地面的物理提问，接触响应是语言难以伪造的证词。
>
> 核心命题：**开放词典，但非对称信任**——未认证/新奇的词只能让系统更谨慎；只有经过多次独立接触认证、开放集校准、安全包络验证的词，才允许放松保守性。词不是「学」出来的，是「证」出来的；扩词不发生在实时环，而在可回滚的隔离账本里。**R69 是本轮在「永不扩词」边界上的严格退化。**
>
> 命名 **VOCA-RAS**（**V**ocabulary-**O**pen, **C**ontact-**A**ware **R**isk-**A**daptive **S**ystem：开放词典 × 接触感知步态的置信闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的词典够不够用，新词凭什么可信**」——不确定性不只是「做哪个动作」，也可以是「我有没有词去描述这个世界」。

## 0. 直觉与动机

**灵感 1（开放词汇 → 词典本身是第三种不确定性）**
直觉：R69 把世界压缩进一个闭集：K 个采样聚成匿名模态，再对这些模态做校准与交互。但真实足式机器人面对的往往是「苔藓斜坡」「碎玻璃」「湿钢板」「刚浇过水的木板」——问题不是「这几个已知模态哪个对」，而是「**我根本没有这个词**」。视觉-语言模型能零样本吐出开放词表，却也会对从未见过的地形给出很自信的名字（open-vocabulary hallucination）。所以需要第三种不确定性 `U_ont`：不是 aleatoric 噪声，也不是 R69 的已知模态间歧义（`U_epi`），而是「**当前所需的区分是否落在我的词典里**」。三者语义不同，必须分通道处置，不能相加。

**灵感 2（步态规划 → 每个落脚点都是一次物理提问）**
直觉：固定基座/轮式系统里，「问」是语言动作；足式系统里，**落脚本身就是探询**：脚掌踩下去，滑移、下陷、回弹、接触声音，是对地形最诚实的回答。步态规划天然提供三样东西：（i）离散接触序列 + 连续轨迹的混合动作；（ii）周期相位，使「何时必须知道」变成硬截止；（iii）接触残差，一条语言改不动的第二意见。开放词汇的「词」若不能改变「这一步怎么落」，它对控制就是装饰。

**灵感 3（词义 = 它改写了哪一步 → affordance 接地）**
直觉：开放词表最容易犯的错是「词很漂亮但不影响控制」。一个地形词若不能改变任何可行步态的接触风险或落脚选择，它就应当被禁止影响 λ。于是把接地定义成控制后果：**词 w 在步态族 𝒢 下的接地度，等于把 w 的 affordance 注入后接触风险图变化的最大值**。不是 VLM 说它「像什么」，而是脚会因为这个词「怎么落」——这把符号接地从语义相似度换成了可测量的物理后果。

**灵感 4（语言会说谎，地面不太会 → 语义-物理对偶通道）**
直觉：R69 用流似然做「标定不可吸收」的第二意见。R70 有一条更强、且与语言正交的通道：**接触残差**。语言说「混凝土」，脚却打滑——语义分高而接触残差高，正是「错标 / 新奇地形 / 对抗词」的判别模式。地面物理也不是绝对诚实（可滑、可塌、可被布置），但它与语言来自不同生成过程，二者合起来能够分开四象限：已知真地形、未建模地形、错标/新奇、传感器故障。**语言不能吸收接触残差。**

**灵感 5（开放 = 攻击面 → 词典必须带证明、可回滚）**
直觉：一旦系统能把人类回答或网络文本变成新词，就有了**词投毒**：把危险地形命名为「安全混凝土」，诱导系统放松。所以扩词必须是**隔离区里的、带证明的、可回滚的**：新词先在 shadow lexicon，需 k 次独立接触认证 + 开放集校准覆盖 + 安全包络验证，才能从「只能加谨慎」升级为「可以减谨慎」。安全方向必须**不对称**：未认证词只能收紧，认证词才能放松。否则开放词汇不是进步，而是给 R69 的保守主义配了一个会撒谎的词典。

**灵感 6（步态相位 → 信息有截止时间，风险有相位）**
直觉：R69 的 VoI 是无限时域的，仿佛可以「先慢慢调研再行动」。步态不允许：摆动相一旦进入落脚承诺，再看就来不及了。定义**截止感知 VoI**——一个信息动作的价值要乘以「证据能否在承诺相之前到达」的概率。同时，风险缩放不能是标量 λ，而应是相位索引的 `λ(φ)`：touchdown 邻域最该保守，支撑中段可以更自信。这把「问什么」与「何时问」放在同一权重下，也把 R69 的标量 λ 收成 `γ(φ)≡1` 的特例。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（VOCA-RAS 总览）** VOCA-RAS = (OVL, CAG, OUC, OCG, DVS, PTR, SPC, AGD, VGG, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）：新词只写 shadow lexicon，实时环只读认证词典；
(ii) **非对称安全**：未认证/新奇词只能经收紧算子进入 λ；只有 certified 词可经放松算子进入 λ，且放松受物理包络上界约束；
(iii) **词典预算与账本**：每 N 轮新增词数 ≤ b、词典总大小 ≤ B，账本为哈希链，任一认证可撤销且撤销会传播到所有依赖该词的步态计划。

**定义 311（开放词典 OVL）** 词典 𝒱 = 𝒱_core ∪ 𝒱_shadow，词 w = (e_w, aff_w, prov_w, status_w)。`e_w ∈ ℝ^{d_e}` 为冻结 VLM/LLM 的语言嵌入；`aff_w` 为把词注入后预测接触风险的 affordance 模型；`prov_w` 为来源与交互哈希；`status_w ∈ {candidate, certified, revoked}`。候选词来自无穷的语言空间 ℒ，但 𝒱 始终有限、单调可审计。**开放不等于无界：开放的是候选生成，封闭的是认证。**

**定义 312（本体不确定性 U_ont）** 设当前任务真正需要的语义区分是 `L* ∈ ℒ`。定义
`U_ont = P(L* ∉ Span(𝒱_core) | o)`。
它不是 aleatoric（扩词可降低），也不是 `U_epi`（后者是已知模态之间的歧义）。三分：`U_ale` 不可约噪声，`U_epi` 已知模态歧义，`U_ont` 词典缺口。三者不做简单加和，分别进入定义 320 的三个算子。

**定义 313（混合步态规划 CAG）** 步态计划 `π_g = (σ, τ)`：接触调度 `σ = (c_1, …, c_n)`（落脚词、时序、占空比、接触相位），连续关节轨迹 `τ`。可行域由混合动力学、摩擦锥、ZMP/CWS 稳定裕度、关节可达性共同定义。开放接触词表下，σ 由接触语法生成；新接触词同样受词典认证约束。

**定义 314（相位风险管 PTR）** 相位 `φ ∈ [0,1)`。`λ(φ) = λ_base · γ(φ)`，其中 `γ(φ) ≥ 1` 在 touchdown / liftoff 邻域取峰值，且满足安全包络。R69 的标量 λ 恰为 `γ(φ) ≡ 1` 的特例。相位从步态时钟与接触事件同步估计，不引入新学习写操作。

**定义 315（截止感知 VoI，DVS）** 信息动作 g 在相位 `φ_g` 执行、到证据可用有延迟 `d(g)`。设 `φ_commit` 为该接触决策的承诺相。定义
`VoI_D(g) = P(φ_g + d(g) < φ_commit) · VoI(g)`，
选择 `g* = argmax_g [VoI_D(g) − c(g)]`，受 R69 的交互预算与 C-RAS-WM 认证约束。若 `VoI_D − c ≤ 0`，不交互，走 R69。**信息只有在截止前到达才有价值。**

**定义 316（affordance 接地 AGD）** 词 w 在步态族 𝒢 下的接地度
`Ground(w) = max_{g∈𝒢} ‖R_contact(g | aff_w) − R_contact(g | ∅)‖ / R_scale`。
`Ground(w) < δ` ⇒ w 为 **inert**，禁止影响 λ、DVS 与落脚选择。词义由此定义为「它改写的接触风险集合」。**inert 词不能驱动任何安全动作。**

**定义 317（开放集校准门 OCG）** 用 split-conformal 在接触留出集上构造候选集 `C(o) ⊆ 𝒱_core ∪ {UNKNOWN}`，目标覆盖 `1−α`；定义开放集校准风险
`OSCR = sup_{novelty strata} |coverage − (1−α)|`。
若 `C(o)` 不是单点，或包含 `UNKNOWN`，则**该词不得用于放松**。R69 的闭集 ECE 是 OSCR 在无 novelty 层时的退化。

**定义 318（语义-物理对偶 SPC）** 语义分 `s_w = −log p(w|o)`；接触残差 `c_res = ‖response_contact − ĥ(aff_w, σ)‖`（滑移、下陷、回弹、接触声音）。四象限判据：
- `s_w` 低、`c_res` 低 → 已知真地形（可用）；
- `s_w` 低、`c_res` 高 → 未建模地形（U_ont 高，扩词候选）；
- `s_w` 高、`c_res` 高 → 错标 / 新奇 / 对抗词（禁止放松）；
- `s_w` 高、`c_res` 低 → 可信词（认证证据的一块）。
**语言不能吸收 c_res；接触物理不能吸收 s_w。**

**定义 319（证明携带扩词 PCV）** 新词升级为 certified 需同时满足：
(i) **证据充分**：`prov_w` 含至少 k 个独立接触事件（跨日期/地点/步态，独立性可审计）；
(ii) **接地**：`Ground(w) ≥ δ`；
(iii) **校准**：`OSCR ≤ τ_oscr` 且留出集上 `C(o)` 单点；
(iv) **安全**：对所有认证步态 `g ∈ 𝒢_cert`，`risk(g | w) ≤ ε_lex`；
(v) **账本**：哈希链登记来源、证据、版本。
任一失败 → w 留在 shadow，只能进入收紧算子。撤销 = 追加 `revoked` 记录并重算所有依赖计划。

**定义 320（非对称安全算子与 λ 合成）** 对任意词集合：
`λ_final = max( λ_R69 , Tighten(𝒱_shadow, 𝒱_candidate) , Relax(𝒱_cert) )`，
其中 `Relax(𝒱_cert) ≥ λ_phys`（物理包络下界）。`Tighten` 对任何 status 可用，`Relax` 仅对 certified 可用。于是**未认证词不可能降低安全等级**，只可能让系统更谨慎（可恢复错误），而不是更冒险（不可恢复错误）。

**定义 321（步态词审计 VQAuditor-V）** 审计对象新增：扩词来源、接触证据充分性、affordance 是否被单次滑移诱导、撤销是否传播、词是否被用于超包络放松、inert 词是否泄入决策。结论回灌 AuditBuf，成为下一轮扩词预算与证据先验。

**定义 322（词投毒干扰集 ℰ_lex）** 人类把危险地形说成安全、网络文本注入、VLM 对抗贴片使语义分虚高、单次偶然接触（一次没滑）被误当认证。并入 AIC：
`ℰ_VOCA = ℰ_FLUID × ℰ_lex × ℰ_contact`（ℰ_contact：接触传感器故障 / 伪装地面 / 回弹伪造）。

**定义 323（证书 J_VOCA）** `J_VOCA = (J_FLUID, vocab_hash, OSCR, U_ont_before/after, ground_max, contact_evidence_n, relax_margin, ledger_root, voca_ver)`。Valid ⇔ `Valid(J_FLUID)` ∧ 非对称安全满足 ∧ 扩词证明完备 ∧ 词典预算未越界。

**定义 324（词典预算与语义漂移）** 每 N 轮新增 ≤ b 词、`|𝒱| ≤ B`；监控语义漂移 `D_KL(e_w(t) ‖ e_w(t0))`、撤销率与 inert 词占比。越限则冻结扩词，退回 R69 闭词典路径。**开放词汇也要有代谢率上限。**

**定义 325（严格包含 FLUID-RAS）** 若 `b = 0` 或所有候选词终态为 shadow/revoked，则 VOCA 逐指令退化为 R69：`U_ont` 全部进入收紧算子，`λ_final = λ_R69`。因此 R69 是「闭词典」边界；安全侧不弱于 R69，效率侧可用认证词换 resolution bonus。

**定义 326（相位-词典耦合）** 同一词在不同相位有不同 affordance：`aff_w(φ)`。地形词在摆动相用于选落脚，在支撑相用于调刚度/步频/期望滑移。词的激活是相位的函数，这让开放词表既解释「看到什么」，又解释「怎么落」。

# IP-264 OVL：开放词典（候选生成开放，认证封闭）
class OpenVocabLexicon:
    def __init__(self, embed, core, shadow, budget, ledger):
        self.embed, self.core, self.shadow = embed, core, shadow
        self.budget, self.ledger = budget, ledger      # 哈希链账本

    def candidates(self, o):
        return topk_embedding_neighbors(self.embed(o), self.core | self.shadow, k=8)

    def ground(self, w, gait_family, delta):
        g = max(norm(risk(gait_family, w) - risk(gait_family, None))
                for _ in [0]) / R_SCALE
        return g if g >= delta else 0.0               # 0 ⇒ inert

# IP-265 CAG：接触调度 + 连续轨迹的混合规划（拓扑来自认证接触语法）
def plan_gait(o, sigma_cache, tau_refiner, certified_tokens):
    sigma = contact_grammar_search(o, sigma_cache, allowed=certified_tokens)
    tau   = tau_refiner.refine(sigma, o)               # 仅在可行域内
    return (sigma, tau) if feasible(sigma, tau) else fallback_gait(o)

def decompose_open(o, samples, z, lexicon):

    cands = lexicon.candidates(o)
    U_ont = 1.0 - max(calibrated_match(o, w) for w in lexicon.core)
    grounded = [w for w in cands if lexicon.ground(w, GAITS, DELTA) > 0]
    return U_ale, U_epi, U_ont, modes, grounded

# IP-267 OCG：开放集校准（并发 + UNKNOWN 单列）

def deadline_voi(g, phi_g, phi_commit, d_g, modes, budget):
    p_arrive = arrive_prob(phi_g, phi_commit, d_g)     # 相位时钟 + 延迟分布
    voi = entropy(modes) - expected_entropy(modes, g)
    return p_arrive * voi - cost(g), p_arrive

def phase_tube(phi, lam_base, env):
    gamma = 1.0 + PEAK * gaussian(phi, TOUCHDOWN, WIDTH) + PEAK * gaussian(phi, LIFTOFF, WIDTH)
    return min(lam_base * gamma, env.lambda_max)        # R69 λ 是 γ≡1 特例

def semantic_physical_check(o, sigma, tau, aff, measured_contact):
    s = -semantic_logprob(o, aff.word)
    c = norm(measured_contact - aff.predict(sigma, tau))
    return classify_quadrant(s, c)                     # known / unmodeled / mislabeled / trusted

# IP-272 VGG：证明携带扩词（隔离区 + 回滚）
def try_certify(w, events, calib, gaits, ledger):
    if len(independent(events)) < K_LEX: return "shadow"
    if ground(w, gaits, DELTA) < DELTA: return "shadow"
    if not open_set_gate(w, events, calib): return "shadow"
    if any(risk(g, w) > EPS_LEX for g in gaits): return "shadow"
    ledger.append(w, events, hash_chain=True)
    return "certified"

    q = M.spc.classify(o, M.last_sigma, M.last_tau, M.last_aff, M.last_contact)
    # 4) λ 合成：R69 两级退避 × 相位管，只做非对称增减
    U_floor = U_ale + (U_epi if g is None else 0.0) + (U_ont if not usable else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    lam = M.ptr.tube(phi, lam, M.envelope)
    lam = M.safety.compose(lam, shadow=M.ovl.shadow, certified=M.ovl.certified)  # 定义 320
    if not usable or q == "mislabeled":
        lam = max(lam, LAM_CAUTIOUS)                   # 无词可用 ⇒ 回 R69 保守
    (sigma, tau) = M.cag.plan_gait(o, M.sigma_cache, M.tau_refiner, M.ovl.certified_tokens)
    k = M.c_ras_wm.certified_prefix(sigma, tau, ..., wm_preds)
    # 5) 审计 + 证书
    M.vqa_v.submit_async(usable, U_ont, q, M.vgg.ledger_root)
    return k, lam, (sigma, tau), (U_ale, U_epi, U_ont)
```

## 3. 推导

**引理 19（接地词的可约接触风险）** 设词 w 的 affordance 使接触风险图变化 `ΔR_w = R(c|aff_w) − R(c|∅)`，在步态族上的最小接地度为 `δ_w = Ground(w) > 0`。若用 w 选择落脚，则相对忽略 w 的基线，期望接触失效概率至少下降 `δ_w·(1 − e^{−n_c·κ})`，其中 `n_c` 为独立接触证据数、κ 为证据效率。要点：词的价值随**独立接触证据**指数增长，而不随语言流畅度增长。系：**不能凭一次滑移认词**——这直接推出定义 319-i。

**引理 20（开放集放松的界）** 若 `C(o)` 在接触留出集上覆盖 ≥ `1−α`，且仅当 `C(o)` 为单点 w 时使用 `Relax_w`，则放松后的接触失效概率 ≤ `α + ε_gap`；若 `C(o)` 含 `UNKNOWN`，则放松被禁用。故 OSCR 提供了一个可操作的阈值，而闭集 ECE 在 novelty 层上会**系统性低估**风险（因为从未见过的类不被计入分母）。**系：开放词表下，ECE 不是「略有偏差」，而是「结构性无定义」。**

**引理 21（非对称安全的单调性）** 定义安全偏序 `λ_shadow ≥ λ_R69 ≥ λ_certified ≥ λ_phys`。任何 shadow / candidate / inert 词只能通过 `Tighten` 进入 λ；certified 词的 `Relax` 受 `λ_phys` 下界约束。因此对任意词集合与任意证据序列，`λ_final ≥ λ_R69`（无认证词时）且 `λ_final ≥ λ_phys`（有认证词时）。⇒ **错词的最坏后果是过度谨慎（可恢复），而非过度冒险（不可恢复）。**

**定理 18（VOCA 严格包含 FLUID-RAS）** 在 A99–A101 下，VOCA 的两阶段决策（先判定是否有可用词，再扩词/交互或保守）在任意状态 s 上的期望风险 ≤ R69；且当 `b=0`、或所有候选词终态为 shadow/revoked、或 `OSCR > τ_oscr` 时，两者**逐指令相同**。因此 R69 是 VOCA 在「闭词典」边界上的退化：安全侧不做任何让步，效率侧用认证词换 resolution bonus。

**定理 19（截止感知 VoI 的上界与相位价值）** 若证据在 `φ_commit` 前到达的概率为 `p_d`，则 `VoI_D = p_d·VoI ≤ VoI`；当 `p_d → 0` 时信息价值趋零。R69 的 VoI 是 `p_d ≡ 1` 的无限时域特例。系：**步态让「何时问」与「问什么」同权**；在 touchdown 前一个相位窗口内，最优信息动作可能从「问人」切换为「低头看一眼落脚点」，因为后者的 `p_d` 更高。

**定理 20（词投毒上界）** 若单次接触即可认证，欺骗率 `δ_l` 下错误认证率 ≥ `δ_l`；要求 k 次独立接触、跨步态一致（独立概率 `ρ<1`），再叠加 conformal 覆盖失败概率 α，则错误放松概率 ≤ `δ_l·ρ^{k−1} + ε_σ + α`。系：非对称安全把「错词」的后果限制在「过度谨慎」一侧；**残余风险只来自被系统性伪装的 k 次独立接触**，这正是定义 322 的 ℰ_contact 与定义 321 的审计要盯的地方。

## 6. 本轮最大风险

**一句话**：VOCA-RAS 的全部收益押在「affordance 接地是忠实的」这一前提上——**若新词仅凭少量、同源、可被伪装的接触证据就被认证（一次没滑的湿木板、被布置过的地面、或 VLM 对抗贴片把危险地形命名为安全），系统就会拿着一个「已认证」的假词去放松保守性；开放词汇于是把 R69 的「未知 ⇒ 谨慎」悄悄改写成「自信地误名 ⇒ 冒险」，而错误恰恰发生在安全侧不可恢复的方向。**

**次级风险与缓解**：
1. **单次接触误认证** → 定义 319-i 的 k 次独立证据 + 引理 19/20 + 引理 21 的单调性；
2. **语义-物理共谋伪装**（语言与地面一起演）→ 定义 322 的 ℰ_contact + SPC 四象限 + 审计；
3. **开放集校准在极端 novelty 下失效** → OSCR 门控，越界即冻结扩词、退回 R69；
4. **实时预算被感知/规划击穿** → 词检索预建索引 + 接地只算 top-3 + 规划用缓存接触语法；
5. **词典膨胀/语义漂移** → 定义 324 的 b/B 预算、漂移监控与撤销传播；
6. **相位估计错误导致截止误判** → PTR/DVS 用保守相位边界，且信息动作仍过 C-RAS-WM 认证。

**定义 318（SPC）** `s_w` 与 `c_res` 四象限：known / unmodeled / mislabeled / trusted。语言不能吸收 `c_res`。

**定义 319（PCV）** 认证五条件：k 次独立接触证据、`Ground≥δ`、`OSCR` 达标且单点、全认证步态 `risk≤ε_lex`、哈希账本登记；撤销传播到依赖计划。

# IP-264 OVL：候选生成开放，认证封闭
class OpenVocabLexicon:
    def candidates(self, o):
        return topk(self.embed(o), self.core | self.shadow, k=8)
    def ground(self, w, gaits, delta):
        g = max(norm(risk(gait, w) - risk(gait, None)) for gait in gaits) / R_SCALE
        return g if g >= delta else 0.0                # 0 ⇒ inert

# IP-265 CAG：接触语法 + 轨迹精化
def plan_gait(o, cache, refiner, certified_tokens):
    sigma = contact_grammar_search(o, cache, allowed=certified_tokens)
    tau   = refiner.refine(sigma, o)
    return (sigma, tau) if feasible(sigma, tau) else fallback_gait(o)

# IP-266/271 OUC+AGD：三分不确定性 + 接地筛选
def decompose_open(o, samples, z, lexicon):
    U_ale, U_epi, modes = decompose_closed(samples, z)         # 复用 R69
    U_ont = 1.0 - max(calibrated_match(o, w) for w in lexicon.core)
    grounded = [w for w in lexicon.candidates(o)
                if lexicon.ground(w, GAITS, DELTA) > 0]
    return U_ale, U_epi, U_ont, modes, grounded

def open_set_gate(o, w, calib):

    return (C == {w}) and (open_set_risk(calib) <= TAU_OSCR)

# IP-268/269 DVS+PTR：截止感知 VoI + 相位风险管
def deadline_voi(g, phi_g, phi_commit, d_g, modes):
    p = arrive_prob(phi_g, phi_commit, d_g)
    return p * (entropy(modes) - expected_entropy(modes, g)) - cost(g)

def phase_tube(phi, lam, env):
    gamma = 1 + PEAK*gauss(phi, TOUCHDOWN, W) + PEAK*gauss(phi, LIFTOFF, W)
    return min(lam * gamma, env.lambda_max)                    # R69: gamma == 1

    c = norm(measured - aff.predict(sigma, tau))
    return quadrant(s, c)                                      # known/unmodeled/mislabeled/trusted

    if len(independent(events)) < K_LEX:        return "shadow"
    if ground(w, gaits, DELTA) < DELTA:         return "shadow"
    if not open_set_gate(w, events, calib):     return "shadow"
    if any(risk(g, w) > EPS_LEX for g in gaits):return "shadow"
    ledger.append(w, events, parent=ledger.root); return "certified"

# IP-276 主闭环（继承 R69，在不确定性处置处插入 VOCA 层）
def VOCA_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, U_ont, modes, grounded = M.ouc.decompose_open(
        o, M.fmp.sample(o, K), z, M.ovl)
    usable = [w for w in grounded if M.ocg.gate(o, w, M.calib)]
    phi, phi_commit = M.ptr.phase(o)
    g = (M.dvs.choose(modes, phi, phi_commit, M.budget)
         if (U_epi > TAU_EPI or (U_ont > TAU_ONT and usable)) else None)
    if g is not None:
        ans = M.cia.execute(g)
        U_epi = M.cia.update_belief(modes, ans)
        M.vgg.observe(ans, o)                       # 回答只进 shadow
    q = M.spc.classify(o, M.last_sigma, M.last_tau, M.last_aff, M.last_contact)
    U_floor = U_ale + (U_epi if g is None else 0.0) + (U_ont if not usable else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    lam = M.ptr.tube(phi, lam, M.envelope)
    lam = M.safety.compose(lam, M.ovl.shadow, M.ovl.certified)  # 非对称算子
    if not usable or q == "mislabeled":
        lam = max(lam, LAM_CAUTIOUS)                # 无词可用 → 回 R69 保守
    sigma, tau = M.cag.plan_gait(o, M.sigma_cache, M.tau_refiner, M.ovl.certified_tokens)
    k = M.c_ras_wm.certified_prefix(sigma, tau, ..., wm_preds)
    M.vqa_v.submit_async(usable, U_ont, q, M.vgg.ledger_root)
    return k, lam, (sigma, tau), (U_ale, U_epi, U_ont)
```

## 4. 推导

**引理 19（接地词的可约接触风险）** 设 `δ_w=Ground(w)>0`，用 w 选择落脚后，期望接触失效概率至少下降 `δ_w·(1−e^{−n_c·κ})`（`n_c` 为独立接触证据数）。**系：** 词的价值是「认证次数」的函数，不是「语言流畅度」的函数——不能凭一次滑移认词（定义 319-i）。

**引理 20（开放集放松的界）** 若 `C(o)` 覆盖 ≥`1−α` 且仅当单点 w 时才 `Relax_w`，则放松后失效概率 ≤`α+ε_gap`；含 `UNKNOWN` 时禁用放松。闭集 ECE 在 novelty 层上**系统性低估**风险，因为没见过的类不进分母。**系：开放词表下 ECE 不是「略偏」，而是「结构性无定义」。**

**引理 21（非对称安全的单调性）** 安全偏序 `λ_shadow ≥ λ_R69 ≥ λ_certified ≥ λ_phys`；shadow/candidate/inert 只能 `Tighten`，certified 的 `Relax` 受 `λ_phys` 约束。故任意词集合下 `λ_final ≥ λ_R69`（无认证词）或 `≥ λ_phys`（有认证词）。**错词最坏后果是过度谨慎（可恢复），而非过度冒险（不可恢复）。**

**定理 18（VOCA 严格包含 FLUID-RAS）** A99–A101 下 VOCA 任意状态期望风险 ≤ R69；当 `b=0`、候选词全 shadow/revoked、或 `OSCR>τ_oscr` 时逐指令相同。R69 = 闭词典边界；安全不让步，效率获 resolution bonus。

**定理 19（截止感知 VoI 的上界与相位价值）** `VoI_D=p_d·VoI≤VoI`；`p_d→0` 时信息价值趋零。R69 的 VoI 是 `p_d≡1` 的无限时域特例。**系：** 在 touchdown 前一个相位窗口内，最优信息动作可能从「问人」切换为「低头看落脚点」，因为后者的 `p_d` 更高——步态让「何时问」与「问什么」同权。

**定理 20（词投毒上界）** 单次认证时错误认证率 ≥`δ_l`；k 次独立、跨步态一致（`ρ<1`）并叠加 conformal 覆盖失败 α 后，错误放松 ≤`δ_l·ρ^{k−1}+ε_σ+α`。**系：** 残余风险只来自「被系统性伪装的 k 次独立接触」，这正是 ℰ_contact 与 VQAuditor-V 要盯的。

## 7. 本轮最大风险

**一句话**：VOCA-RAS 的全部收益押在「affordance 接地是忠实的」这一前提上——**若新词仅凭少量、同源、可被伪装的接触证据就被认证（一次没滑的湿木板、被布置过的地面、或 VLM 对抗贴片把危险地形命名为安全），系统就会拿着一个「已认证」的假词去放松保守性；开放词汇于是把 R69 的「未知 ⇒ 谨慎」悄悄改写成「自信地误名 ⇒ 冒险」，而错误恰恰发生在安全侧不可恢复的方向。**

**次级风险与缓解**：单次接触误认证（k 次独立证据 + 引理 19/20 + 非对称单调性）；语义-物理共谋伪装（ℰ_contact + SPC 四象限 + 审计）；极端 novelty 下开放集校准失效（OSCR 门控，越界即冻结扩词、退回 R69）；实时预算被感知/规划击穿（预建词索引 + 只算 top-3 接地 + 缓存接触语法）；词典膨胀与语义漂移（b/B 预算 + 漂移监控 + 撤销传播）；相位估计错误导致截止误判（保守相位边界 + 信息动作仍过 C-RAS-WM 认证）。
