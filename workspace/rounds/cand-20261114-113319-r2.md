# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~301；灵感循环第 2 轮；本轮灵感：「语言指令」×「双足机器人」）

> R73 把计量从具身层推进到**契约层**：证据契约 EC、组合代数 CCA、反作用通道 ΣREFLEX、主张绑定 CPB，并把「换模块零改核心」升为热替换定理。但 R73 的两个盲点恰好被本轮灵感击中：
> - **语言盲点**：R73 的证据全是**物理测量**（深度/接触/音频），噪声被默认成零均值、连续、可标量的。而「语言指令」是完全不同的证据：**符号的、外生的、有意图的、多峰的、对抗的**。它不测量世界的现状，而**陈述世界的应然**（目标、约束、隐含前提），并且能**标注其他模态的失效模式**（"注意玻璃桌"直接告诉深度相机：这里会失效）。把语言塞进 R73 的 `u=σ²` 框架，会犯 R72/R73 反复批判的同型错误：**把语义歧义误读为测量噪声**。
> - **步态盲点**：R73 的退化链假设「模块失效 → stub（u=∞、不产生观测）」。但双足机器人**不能停**——原地冻结会跌倒。步态是**混合动力学**（连续摆动 + 离散落脚冲击），证据有**承诺时域**（脚一旦抬起，落点已不可撤回），迟到证据对当步毫无价值。R73 的 CCA 是**无时间**的：它只校验预算闭合与域交，不校验「证据是否在决策前因果可用」。
>
> 本轮的三块结构性推进：
> - **语言指令 → LEM + AUTH**：语义不确定度是**可信解释集**（credal set）而非标量方差；六分量（指称/辖域/否定/动作义/约束/语用）；语言带**权威等级与来源**，低权威指令只能收缩可行集、绝不能扩张。
> - **双足机器人 → GPM + TCA + 承诺时域**：证据成为带 (因果下界, 截止期, 相位, 新鲜度) 的**时序对象**；组合代数扩展为**时序契约代数**；退化不是 stub 而是**保可行性的安全步态**。
> - **两条主线的交点 → 时序-权威双格 + 指令风险超鞅**：安全不仅取决于「不确定度多小」，还取决于「**在什么时刻、以什么权威、在多长的承诺窗口内**」；一串单独无害的指令可以合谋把系统推过安全边界，需要**累计风险账本**。
>
> 核心命题：**不再问「这条指令/这个传感器是否可信」，而问「证据能否在承诺边界前、以被授权的权威、沿因果顺序抵达——并使系统在语义歧义、指令注入、证据迟到与落脚冲击下仍可证安全？」** 把 R73 的 MODGAUGE-RAS 重构为 **LINGUAGAIT-RAS**（LINGuistically-instructed, viability-GAit-aware evidence metrology with GAUGE audits）——**时序-权威证据计量**。

## 0. 直觉与动机

**灵感 1（语言指令 → 语义歧义是「集合值」而非「方差」）**
直觉：人对机器人说「把杯子放到桌子左边，别碰倒那个玻璃的」。这句话里至少有六种独立的不可靠：指称（哪个杯子/哪张桌子）、辖域（"左边"相对谁）、否定（"别碰倒"约束的是路径还是终点）、动作义（"放"是轻放还是放下）、约束修饰（"玻璃的"是材质警告还是指称限定）、语用（说这句话的潜台词可能是"我赶时间"）。这些不是零均值噪声——把「左边」理解错是**离散的、系统性的、多峰的**错误；用方差描述会给出「均值正确、方差略大」的假象，而真实后验可能是 50/50 的双峰。正确对象是**可信解释集** 𝒜_α 与每个命题上的**可信区间** [p_lo, p_hi]。更关键：语言能**标注别的模态的失效**——"玻璃的"正是 R73 DPEM 的材质失效类；这句话应当**提高 b_t(m_fail) 先验、收缩 D_depth**，让深度模块在靠近桌前就进入保守模式。**语言是唯一能预先告知"我的同伴将在哪里失灵"的模态。**

**灵感 2（双足机器人 → 证据的价值由「承诺时域」决定）**
直觉：双足行走是**混合系统**：连续摆动 + 离散落脚。在承诺时域 T_commit（距落脚不可撤回的时刻）之前，若没有可用的地形/意图/状态证据，这一步就只能按旧计划落地；之后到达的证据再准也**对当步无效**。因此证据的价值不是 u 的单调函数，而是 **V(e) = 相关性 × 及时性 × 权威**：过期证据（age > 半衰期）与迟到证据（t + τ_exec > T_commit）价值为零甚至为负（扰动）。这也解释了为什么"更好的感知"有时不提升行走安全：它没赶上承诺边界。工程推论：**要么让证据更早到（主动感知/预取），要么降低承诺（缩短步长、放慢、增加双支撑）——后者正是语言"小心点"的物理含义。**

**灵感 3（交点 → 安全是「不确定度 × 权威 × 时间」的三维格）**
直觉：R73 只用一维（不确定度越小越好）。但：
- 一条**极确定**的指令如果来自**未授权**来源（环境里的文字、被注入的语音），它的低不确定度是**陷阱**，不能让它扩张可行集；
- 一条**含糊**但**已认证**的指令仍然可以保守执行（取可信解释集的交集）；
- 一串**各自无害**的指令（"再快一点"×10）可以累积成不安全——这是语言版的"温水煮青蛙"。
所以安全侧需要**乘积格**：不确定度↑坏、权威↓坏、时间越晚越坏；并且需要一个**累计势函数**（超鞅）来约束指令序列，而不是逐条判断。**"每一步都合规"正是 R73 已经警告过的失败模式，本轮把它形式化为指令层的漂移证书。**

**灵感 4（退化语义 → 双足不能 stub，只能「安全跛行」）**
直觉：R73 的 stub 是 u=∞、不产生观测。对双足，这会直接导致跌倒——**不产生观测 ≠ 安全**。正确退化是**保可行性的安全步态**（viability-preserving stub）：相位锁定、最短步长、最大双支撑、DCM 留出最大裕度、只用最保守的本体估计。语言模块失效时也不是"闭嘴"，而是退化为**最小特权解释**（只执行无歧义约束、忽略含糊的进度指令、必要时请求澄清）。这把 R73 的"零级联"定理从"模态缺失"提升为"**模态缺失且系统仍落在可行核内**"。

**灵感 5（组合代数 → 从「预算代数」到「时序-权威代数」）**
直觉：R73 的 CCA 三算子只管不确定度传播。加入时间与权威后，每条边还带 (causal_floor, deadline, phase, auth)：串联要求上游截止不早于下游因果起点；并联要求同相位且时间对齐；否决是时序非补偿；指令序列是**时序串联 + 权威取交 + 势函数累计**。组合单调性升级为**因果-截止保持**：任何组合都不能让迟到证据变及时，也不能让低权威指令变高权威——**"没有证据时间旅行，也没有权威洗白"**。

## 1. 形式化定义（增量：定义 383–397）

**定义 383（LINGUAGAIT-RAS 总览）** LINGUAGAIT-RAS = (MODGAUGE-RAS†, LEM, GPM, TCA, AUTH, IRIS, ΣREFLEX†)。八不变式：
(i) **契约完整性**（继承 R73）：无契约不入图；
(ii) **组合单调性**（继承 + 时序版，引理 39）：无凭空变好、无证据时间旅行；
(iii) **反作用通道完备**（扩展 χ_L，定义 389）；
(iv) **主张绑定**（扩展 C4a/C4b，定义 374†）；
(v) **严格退化链**（扩展为保可行性退化，定义 397）；
(vi) **时序因果性**：证据只能在 [t_causal, deadline] 内被消费，决策必须发生在承诺边界前；
(vii) **权威单调性**：可行集对权威单调非减；未授权指令只能取交（收缩）；
(viii) **潜力安全性**：指令累计势 Φ_t 在认证策略下为超鞅（定义 393）。

**定义 384（语言证据 LEM 与语义六分量）** LE = (ℓ, 𝒜, b_t(α), D_sem, χ_L, τ_L, W_L, auth, t_stamp, δ_exec)：
- ℓ：原始指令（文本/语音转写）；𝒜：候选形式化解释集，|𝒜| ≤ K = 16；b_t(α)：解释后验（解析器 + LLM 集成 + 共同知识先验）；𝒜_α = {α : b_t(α) ≥ 1−α_sem}；
- D_sem：语义有效域——共同知识前提（已知物体、地图、已学技能、在场人类）；
- **语义六分量**：u_ref（指称）、u_scope（辖域/依存）、u_neg（否定/极性）、u_verb（动作义/技能选择）、u_constr（约束与修饰）、u_pragma（语用/省略）；
- 每个命题 π 取**可信区间** [p_lo(π), p_hi(π)] = [inf_{α∈𝒜_α} 1[α⊨π], sup_{α∈𝒜_α} 1[α⊨π]]；
- τ_L：语义追溯链（解析树、模型版本、提示词、声源/来源签名）；auth：权威等级与来源（定义 390）；δ_exec：最早可执行延迟。

**定义 385（语义不确定度不可标量化，引理 38）** 对可测任务命题 π，若用单峰方差近似多峰后验 b_t(α)，则存在 α 使 argmax 解释的 p(π) 与真实可信区间端点相差任意大。故 LEM 只输出**可信集/区间**，禁止把 u_sem 压成标量并入 u_depth 式的一维预算；跨模态组合必须在命题层做区间/集合运算。

**定义 386（双足步态相位计量 GPM）** 相位 p ∈ P = {DS, SS_L, SS_R, IMP, SW}，由接触事件驱动（混合自动机）；观测 y_g = (关节编码器, IMU, 足底力/触觉, CoM 估计, 地形估计)。六分量：
u_gait² = u_enc² + u_imu² + u_slip² + u_impact² + u_compl² + u_timing²
（编码器/IMU 漂移/足底打滑/落脚冲击/柔顺地形/相位抖动）。可行性：DCM ξ = c + ċ/ω（ω=√(g/z_c)），支撑多边形 S(p)，裕度 m_v = dist(ξ, ∂S(p⁺))；D_loco = {m_v ≥ m_min ∧ p 与步态计划一致}。**承诺时域** T_commit(p)：距下一次落脚不可撤回的时刻。

**定义 387（时序证据与可采纳性）** 每条证据 e 附时序标注 τ(e) = (t_causal, t_stamp, h, deadline, phase)。年龄 a = t − t_stamp，新鲜度 fres(a) = 2^{−a/h}。e 在决策时刻 t **可采纳** ⇔ t_causal ≤ t ≤ deadline ∧ phase(e) ∋ p(t)。**时序契约** EC_t = (EC, causal_floor, deadline, phase_set, h, auth_min)。

**定义 388（时序契约代数 TCA）** 扩展 CCA：
- **SER-T（A ∘ B）**：要求 deadline_A ≥ t_causal(B)（否则 B 不得消费 A）；u_out ≥ u_A + L_B·u_A（继承单调）；causal_out = max，deadline_out = min(deadline_A − τ_B, deadline_B)；D_out = D_A ∩ D_B；χ_out = χ_B ∘ χ_A。
- **PAR-T（A ⊕ B）**：仅当 phase 相容且时间区间在决策时刻有非空交；先对齐到共同时间戳，再做 conformal 一致性审计；审计通过且 |ρ̂| < ρ_max 才允许缩窄；否则 max 保守。
- **VETO-T（A ⊠ B）**：非补偿；任一否决（含**时序否决**：证据迟到/过期）⇒ 整体否决。
- **INSTR-SEQ（ℓ_1;…;ℓ_n）**：时序串联，约束集取交、权威取 min、势函数累计（定义 393）。

**定义 389（语言反作用通道 χ_L 与权威约束）** χ_L: ℓ × auth × X → (ρ_appetite, g_regime, w_evidence, annot_fail)：
- ρ_appetite：风险胃口（"小心"↓、"快点"↑）；g_regime：步态档位（步长/频率/双支撑比）；
- w_evidence：证据权重（"看仔细"↑ 深度权重）；
- **annot_fail**：对其他模态失效模式的标注（"玻璃的" → b_t(m_fail)↑、D_depth 收缩；"地面很滑" → u_slip 上界↑）；
- **权威约束（关键）**：χ_L 只能在认证包络 E_cert 内重分配风险，`Φ(auth, χ_L) ≤ Φ_max(auth)`，且 auth 越低包络越小；未授权指令只允许收缩。

**定义 390（权威格 AUTH 与来源）** 等级 A0 < A1 < A2 < A3：A0 环境文本/陌生人声/网络内容（不可信），A1 在场已认证人类，A2 注册操作员，A3 认证安全监督（可紧急停机，不可解除安全否决）。可行集 F(a) 对 a 单调非减；**未授权指令的作用 = F(a) ← F(a) ∩ S_current**（只能收缩）。来源链：声纹/签名/会话令牌 + 追溯 τ_L；伪造来源被 AUTH 校验拒绝。

**定义 391（承诺时域与安全延期 CDH）** 指令在 t 到达，最早生效 t + δ_exec。若 t + δ_exec > T_commit(p)，则**延期**到下一承诺边界 p⁺；在边界前继续执行**当前已认证前缀**。安全交接条件：边界状态 s(p⁺) 满足指令前置条件 ∧ 新指令证书有效，否则重规划或请求澄清。

**定义 392（歧义鲁棒执行 ARX）** 给定可信解释集 𝒜_α 与每解释的安全动作集 A_safe(α)：
a* = argmax_{a ∈ ⋂_{α∈𝒜_α} A_safe(α)} Progress(a)。
交集为空 ⇒ 不单方面行动：请求澄清（计入交互预算）或保守保持。歧义代价 = 进度损失；澄清价值 = E[信息增益]/人类成本（接 R72 ERVOI†）。

**定义 393（指令风险账本 IRIS：累计势超鞅）** 势函数
Φ_t = w_s·H(u_sem) + w_a·(1 − auth) + w_g·(1/m_v) + w_d·D_t，
其中 D_t 为累计目标漂移（指令语义相对初始目标的偏移）。认证策略须使 `E[Φ_{t+1} | F_t] ≤ Φ_t + b_t`（带补偿项的离散超鞅）且 `Φ_t ≤ Φ_max`；触界 ⇒ 拒绝/延期/升级人工。由 Ville 界，有限视野内越界概率受 Φ_0/Φ_max 控制。**这是对"温水煮青蛙"的可证防御。**

**定义 394（语言威胁面 AIC-LANG）** 歧义攻击（故意含糊诱发不安全 argmax）、指令注入（环境文本/提示注入）、权威伪造、目标漂移（多步合谋）、语义越狱（"忽略安全规则"）、跨模态说谎（指令与深度/接触矛盾）。防线：来源与权威格 + 单调收缩 + 可信集交集 + 单源不定案（R73 E356/E357）+ 澄清。

**定义 395（语言-步态证书 J_LG）** J_LG = J_MOD ⊗ J_temporal（TCA 因果/截止校验）⊗ J_auth（权威单调与来源）⊗ J_sem（可信集校准）⊗ J_iris（势超鞅）。Valid(J_LG) ⇒ Valid(J_MOD)（R73 证书为特例）。

**定义 396（结构上限扩展）** |𝒜| ≤ 16、|P| ≤ 6、指令链深度 ≤ 8、势状态维数 ≤ 8、T_commit 精度 ≤ 1ms——全部为可审计图/时序性质。

**定义 397（保可行性退化与安全步态 stub）** 对双足，退化不得输出"u=∞ 且停"：
- GPM 失效 ⇒ **安全跛行** stub：相位锁定、步长最短、双支撑最大、m_v 取最大裕度、只用最保守本体估计；仍保证 D_loco 非空；
- LEM 失效 ⇒ **最小特权解释** stub：只执行无歧义约束、忽略含糊进度指令、默认请求澄清；
- 其余继承 R73。**定理**：保可行性 stub 仍落在认证可行核内（引理 40 推论）。

## 2. 推导（增量）

**引理 38（语义不确定度的集合值下界）** 见定义 385。系：**语言不是"带噪声的标签"，而是"带权威的解释集合"——把语义错误当零均值噪声，会系统地错在"最自信的错"上。**

**引理 39（时序组合的因果-截止保持）** 对 TCA 任一组合：deadline_out ≤ min(deadline_i)，causal_out ≥ max(causal_i)，fres_out ≤ min(fres_i)。归纳于组合树 ⇒ 不存在使迟到/过期证据变可采纳的组合路径。系：**组合代数不能创造时间，也不能洗白权威。**

**引理 40（承诺边界的安全延期）** 若当前已认证前缀保持可行性（D_loco ≠ ∅）且新指令延期至下一承诺边界，则 (i) 边界前系统按旧证书运行，安全性由 R73 定理 28 保证；(ii) 边界处若前置条件成立则交接安全，否则回退到旧计划/请求澄清。系：**指令可以等，安全不能等。**

**引理 41（歧义鲁棒执行的保守性）** 若真实解释 α* ∈ 𝒜_α 且 a* ∈ ⋂ A_safe(α)，则执行 a* 在 α* 下安全；交集为空时不存在被所有可信解释共同认可的动作，单方面行动必对某可信解释不安全。系：**歧义的代价是可度量的进度损失，而不是不可控的安全风险。**

**引理 42（权威单调性与注入免疫）** F(a) 对 a 单调非减；未授权指令作用为取交 ⇒ F 不增。故未伪造来源的注入不能扩张可行集。系：**低权威的"确定语气"不构成任何安全权限。**

```python
        M.snapshot.write(b_t, z_dist, d_ev, g_ev, le, M.state, M.phi)
        M.mreg.audit(); M.tca_audit(); M.auth_audit()               # 组合/时序/权威

    # === 控制域（1kHz，硬实时，只读快照，零分配）===
    snap = M.snapshot.read_latest()
    lam = embodied_risk_scale(snap.d_ev.u, snap.g_ev.u, snap.le.u,
                              snap.g_ev.m_v, M.risk_params)         # R73 E-RISK†
    A = M.ach.propose_ctrl(..., pvop_bias=snap.pvop, cmd=snap.cmd)
    k = M.c_ras_wm.certified_prefix(A, lam)
    M.ctrl_out.publish(k, lam)
    M.cert_ctrl.write(k=k, lam=lam, wcet=M.rtm.wcet_us(), breaker=M.breaker.status())
    return k, lam, J_LG(M.mreg)                                     # 定义 395
```

## 4. 推导

**引理 38（语义不确定度的集合值下界）** 多峰语义后验不能用单峰方差近似；遗漏否定/辖域分量会造成系统性、方向性的低估（与 R73 引理 33 同型，条件集从物理机制扩大到语义结构）。系：语言是"带权威的解释集合"。

**引理 39（时序组合的因果-截止保持）** deadline_out ≤ min、causal_out ≥ max、fres_out ≤ min，归纳于组合树。系：组合代数不能创造时间、不能洗白权威。

**引理 40（承诺边界的安全延期）** 旧前缀保持 D_loco ≠ ∅ 时继续执行即由 R73 定理 28 保证；边界处前置条件成立则交接安全，否则回退/澄清。系：指令可以等，安全不能等。

**引理 41（歧义鲁棒执行的保守性）** 真实解释在可信集内且动作属所有解释的安全交集 ⇒ 安全；交集空 ⇒ 无被共同认可的动作。系：歧义代价是进度损失，不是不可控风险。

**引理 42（权威单调与注入免疫）** F(a) 单调；未授权指令作用为取交 ⇒ F 不增。系：确定语气不构成权限。

**引理 43（指令漂移超鞅界）** 带补偿超鞅 + Ville 不等式 ⇒ P(sup Φ_t ≥ Φ_max) ≤ E[Φ_0]/Φ_max。系：逐条安全 ≠ 序列安全。

**定理 30（严格包含）** R73 = LINGUAGAIT 的退化实例（𝒜 单点、auth=A0、χ_L≡id、单相位、deadline=∞）；由定义 383(v) 与引理 39/40 逐指令等价，再退化到 R71/R68。

**定理 31（证书 ⇒ 含跌倒与注入抵抗的系统安全）** Valid(J_LG) ⇒ 模块证书有效 ∧ 时序组合通过 ∧ 权威合法 ∧ 势未越界 ∧ J_MOD 成立 ⇒ 风险 ≤ ε，且在可信解释集与授权范围内不越可行核、不被注入扩张。证明重量在语义分布外校准与补偿项 b_t。

**定理 32（联合预算有限停止）** ΣREFLEX† 含 χ_L 后 B_total 不因任何指令扩大，只允许包络内重分配；边际成本正下界 + 增益非增 ⇒ 有限停止保持。

## 7. 本轮最大风险

**一句话**：本方案把安全寄托在「**可信解释集校准得好、势函数补偿项估得准、承诺时域测得对**」三个统计/时序假设上——一旦真实语义超出解释器族、补偿项在分布漂移下被低估、或 T_commit 在柔顺地形/外力下显著偏移，系统就会在一张**时序因果全通过、权威单调全通过、势超鞅全通过**的证书下，**在规定时刻把一条被错误解释的指令合法地执行进不安全状态**，而日志显示每一步都合规。

次级风险与缓解：
1. 语义校准外推 → conformal + 漂移检测 + 越界回退最小特权；
2. 补偿项 b_t 低估 → 可观测漂移代理保守上界 + 硬阈值；
3. T_commit 偏移 → 在线辨识 + 提前承诺 + 安全步态换时间；
4. 澄清成本滥用 → 澄清预算并入 ΣREFLEX；
5. 跨模态说谎 → 单源不定案 + VETO-T，指令不能单独否决物理证据；
6. 双足 sim-to-real 差距 → 保可行性 stub + 真机硬件限幅双重约束；
7. MBench-4 过拟合 → 预注册 + 密封保持集 + 三方复现。
