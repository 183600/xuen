# 第 3 轮（全局研究第 3 轮／新灵感循环第 1 轮；本轮灵感：「Isaac Sim」×「热管理」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440），
> 上承 **LeanGauge**（IP-310–314；定义 398–415）与 **MODGAUGE** 五不变式。
> **本轮纪律**：在 ToolGauge 上改进，而不是推倒重来——6C 骨架、MTC/TCV、L-Box、MP-Φ/AP-Cal、
> TB-Contract、P-Quarantine、语言审计层与严格退化链全部保留。本轮只升级两个此前被当作「给定」的东西：
> (1) 修复的**验证介质**：从「只在真实系统上验证」升级为「物理一致数字孪生中的阴影执行 + 真实回执」；
> (2) 盲区误差与修复代价的**共同物理因子**：把温度从「被忽略的干扰」升级为一等状态变量与可消耗预算。
> 同时审计并修复第 2 轮遗留的 9 处结构性缺陷（§5）。

## 双轴映射（升级而非重写）

| 灵感词 | 第 2 轮对象 | 升级为 | 一句话动机 |
|---|---|---|---|

**能力包含关系（箭头指向增强方向）**：MODGAUGE ⊆ LeanGauge ⊆ ToolGauge ⊆ **ThermoGauge**；

**核心命题**：把 ToolGauge 的「语义假设 → 契约工具 → 摊销校准 → 交叉验证热替换」升级为
「**语义假设 → 契约编译 → 孪生阴影预演（只有否决权）→ 真实执行 → 热耦合摊销校准 → 交叉验证 → 热归因 → 热替换**」：
温度作为显式状态被估计、建模、预算化；数字孪生只获得**否决权**而不获得**批准权**，
真实回执仍是唯一能提升数值置信的证据。

**不变式保持声明**：
- MODGAUGE 五不变式全部保留；新增「**热反作用通道完备性**」（定义 446）：一切产热/散热副作用必须进入 χ_R 账本；
- 主张绑定不变式的**热扩展**：任何含温度/安全域的语言主张必须引用热观测回执与 θ̂ 证书，否则剥离；
- **严格退化链延长**：ThermoGauge 失效（孪生不可用 / 热观测失效 / 热预算耗尽）⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE；
  退化时**只允许更保守**（减少探测、收紧包络），不允许放宽任何安全约束（定义 445 的单调性）。

## 0. 直觉与动机

**灵感 1（Isaac Sim → 孪生被降格为「只有否决权的预言机」）**
直觉：第 2 轮已经在海量仿真里预训练 MP-Φ，但仿真只被用来「离线喂先验」，部署后一次也没有回到环路里。
这浪费了 Isaac Sim 这类物理一致仿真器最不可替代的两个能力：**确定性回放**与**反事实分叉**。
真实机器人上，一个 TCV 校验通过的探测程序仍可能在接触、力矩、热包络上越界——第 2 轮只能靠 `Pre_t` 的
名义包络兜底，而名义包络恰恰是盲区。孪生能在动真机之前，把 Π_s 与候选补丁在一个分叉副本里跑完，
用物理谓词（接触力、关节力矩、温度、运动学可达）**否决**危险动作，并用受控反事实给盲区贴上局部真值标签。
但必须警惕：孪生自己不真。因此我们把孪生设计成**三值、否决性**的：
`VETO`（可证违规）/ `CLEAR`（不反对，但**不等于批准**）/ `GRAY`（不敢判，退回真实保守预检）。
**语言与孪生都不能进入数值批准通道**——这与第 2 轮对 VLA 的降格审计是同一条纪律的自然延伸。

**灵感 2（热管理 → 温度是跨盲区相关误差的共同混杂因子）**
直觉：第 2 轮的最大风险是 **AP-Cal 的摊销后验在预训练→部署偏移下产生跨盲区强相关偏差**。
但物理上，「所有盲区同时向同一错误方向收缩」最常见的原因不是先验本身坏了，而是存在一个**共享的慢变量**：
芯片结温、传感器壳温、环境温度。温度升高会同时改变内参、外参、暗电流、材料反射率与接触摩擦——
它对所有盲区是**共同混杂因子（common confounder）**。
若忽略它，相关残差看起来就像「先验缺陷」，P-Quarantine 的符号启发式会误杀；
若建模它，跨盲区协方差就暴露为一个**低秩 + 对角**结构，可以显式扣除。
于是我们令 `u_s(θ) = μ_s + B_s(θ−θ_ref) + ε_s`：每个盲区有自己的热响应 B_s，所有盲区共享同一个 θ。
用热敏电阻 + 线性 RC 网络做 Kalman 观测，得到 θ̂；把 AP-Cal 的后验条件在 θ̂ 上（TCA）；
再用**热归因检验**取代符号启发式：相关残差是被 θ 解释（物理、可校正），还是不被解释（真先验缺陷）？

**灵感 3（热管理 → 热是预算与噪声底，「何时探测」变成资源调度问题）**
直觉：探测不是免费的：IR 补测、变光扫描、敲击激励、电机动作、乃至摊销推理本身都在产热；
持续修复会把系统推入热节流与热漂移，**恰好在最需要计量的时候把计量能力烧掉**。
更隐蔽的是，观测噪声随温度上升（暗电流、电阻热噪声），于是信息增益
`Ĝ_t(θ)=½log(1+σ_prior²/σ_obs²(θ))` 在高温下下降，而把后验压到 ε 所需的样本数
`n_min(θ)` 却上升——第 2 轮的 TB-Contract 只计时间与磨损，系统性低估了「热的时候校准更贵」。
因此本轮把预算从 `(时间, 磨损, 风险)` 扩展为 `(时间, 磨损, 风险, 产热)`，并做热感知调度：
最大化信息增益 / 产热比，受热余量与升温速率约束；余量不足就**冷却等待或延后**，而不是硬赌。

## 1. 形式化定义（增量：定义 432–447）

**定义 432（热状态与热观测模型）** 热状态 `θ_t ∈ R^{d_θ}`（结温、壳温、环境温度等 `d_θ≈4–8` 个节点），
遵守线性集总 RC 网络：
`θ_{t+1} = A θ_t + B_q q_t + w_t`，`w_t ~ N(0,Q)`，谱半径 `ρ(A)<1`；
热敏电阻观测 `y_t = C θ_t + v_t`，`v_t ~ N(0,R)`。`q_t` 是**已知指令产热**（计算/驱动/探测），
`θ_amb` 作为边界节点。Θ-Box 运行 Kalman 滤波得到 `(θ̂_t, P_t)`；要求 `(A,C)` 可观测（引理 51）。
与第 2 轮 `Pre_t` 的关系：`Pre_t` 是「执行瞬间不许越界」的硬闸门，Θ-Box 是其**热分量的状态化估计器**。

**定义 433（热响应函数与热耦合误差模型）** 对盲区 `s` 的契约参数 `u_s`（可为多维）：
`u_s(θ) = μ_s + B_s(θ−θ_ref) + ε_s`，`ε_s ~ N(0, Σ_s)`，`B_s ∈ R^{d_u×d_θ}`。
于是跨盲区协方差 `Cov(u_s, u_{s'}) = B_s Σ_θ B_{s'}^T`（`s≠s'`），整体
`Σ_U = B Σ_θ B^T + diag(Σ_s)`——**低秩公共因子 + 对角私有噪声**。
`B_s` 由「孪生受控变温实验 + 真实热循环日志」联合最小二乘/EM 估计；`B_s` 的估计误差进入定义 444 账本。

**定义 434（证书热时效 τ_Θ(s) 与热平稳前置）** 设证书在 `θ_0` 签发，当前 `θ̂_t`；漂移引入的偏差上界为
`||B_s(θ̂_t−θ_0)|| ≤ ||B_s||·||θ_t−θ_0||`。一阶热响应 `θ_t−θ_0 = (θ_∞−θ_0)(1−e^{−t/τ})`，要求偏差 `≤ ε_u`：
令 `γ := ε_u / (||B_s||·||θ_∞−θ_0||)`；
- `γ < 1`：`t_Θ(s) = −τ·ln(1−γ)`（有限时效，证书携带到期时刻）；
- `γ ≥ 1`：稳态漂移本身已超容差 ⇒ **该工作点无有限有效期**，必须重校准或 stub。
**热平稳前置** `Pre_Θ(s)`：`tr(P_t) ≤ P_max` 且 `|dθ̂_t/dt| ≤ rate_max` 且工作点温度跨度 `≤ Δθ_cal`；
不满足 ⇒ 该证书/校准在热瞬态中无效（修复第 2 轮「样本复杂度假设 σ_obs 平稳」的缺陷）。

**定义 435（数字孪生与阴影执行）** 孪生状态 `z_t = (几何, 材质, 热状态 θ, 传感器模型, 接触参数)`；
同步 `z_t ← fuse(真实观测, 上一孪生状态)`（仅在可观测重叠集 `O_t` 上校正）。
`fork(z_t)` 产生隔离副本；`shadow(Π_s, patch, Ξ)` 在场景集合 `Ξ`（部署分布 + 热包络 + 材质扰动）上
于副本内执行程序与候选补丁，返回轨迹、物理谓词值与预测回执，**对真实系统零副作用**。
`replay` 把已录真实 episode 重放到孪生，用作热替换的回归语料。孪生计算全部异步于 50Hz 路径。

**定义 436（孪生保真度与影子残差）** 在重叠集 `O_t` 上
`δ_twin(x) = |ŷ_twin(x) − y_real(x)| / σ_decl(x)`；
全局保真度 `η̂_twin` 取 `δ_twin` 的加权高分位（默认 95%）或 `sup`。
对安全谓词 `g`，设其关于孪生状态是 `L_g`-Lipschitz、孪生状态误差 `≤ ε_z`，则谓词误差 `≤ L_g·ε_z`。
`δ_twin` 与 `ε_z` **在线估计，不是常数**；这是把第 2 轮引理 47 中不可测的偏移 `η` 变成运行时量的第一步。

**定义 437（反事实标签与保真加权共形）** 孪生可在受控变温/变材质下为盲区生成候选标签
`(s, h*_twin, u*_twin)`，赋予保真权重 `w = φ(δ_twin) ∈ [0,1]`（默认 `w = exp(−δ_twin²/2τ_w²)`）。
加权经验分布进入共形分数；在标签噪声率 `ε_label`（由重叠集估计）与漂移 `η′` 下，
覆盖保证修正为 `P(h*∈H_s) ≥ 1−α−2η′−2ε_label`（证明思路见引理 52）。
**仲裁规则**：真实标签权重恒为 1，孪生标签只在真实标签缺失处生效；二者冲突时真实优先且 `η̂_twin` 下调；
**任何语言/VLA 输出不得上调孪生权重**。

**定义 438（否决性预言机与三值判定）** 对安全谓词 `g`（`g>0` 为违规），取裕度 `m = L_g·ε_z`：
- `VETO` 若 `ĝ > +m`：可证违规 ⇒ 中止（零副作用）；
- `CLEAR` 若 `ĝ < −m`：不反对——**不等于批准**，仅撤销孪生的反对票；
- `GRAY` 其余：无法判定 ⇒ 退回真实保守预检或延后。
**权威不对称**：`VETO` 对物理安全是可靠的（引理 53a），但**批准修复**所需的是数值正确性谓词，
它不关于孪生状态 Lipschitz，孪生无法签发；V 阶段的真实回执交叉验证永远不可省（引理 53b）。
当 `δ_twin > ε_z`（保真度跌破其置信上界）时，`GRAY` 区间扩张、`CLEAR` 失效——此时孪生只剩 `VETO`。

**定义 439（热预算契约 Θ-Contract）** `ΘB = (H_head, θ_max, rate_max, cool_policy, heat_ledger)`：
每个工具 `t` 有产热代价 `h_t`（关键节点的预期升温，由孪生阶跃响应预测）；
余量 `H_t = θ_max − θ̂_t^{crit}`；约束：预测峰值 `≤ θ_max − m_θ` 且 `dθ̂/dt ≤ rate_max`。
不可行 ⇒ 按 `cool_policy` 冷却/延后；延后超过 `τ_repair` ⇒ 降级。
**热噪声底**：`σ_obs(θ) = σ_obs,0·sqrt(1 + κ(θ−θ_ref))`，`κ ≥ 0`（暗电流/热噪声的单调代理）。
Θ-Contract 是 TB-Contract（定义 424）的**热维度细化**，不是替代。

**定义 440（热感知探测调度）** 在 `Ĝ_t(h,θ̂)`、`h_t`、TB 与 ΘB 约束下，选择工具子集与顺序，
最大化 `Σ_{t∈S} Ĝ_t(h,θ̂)`，满足 `Σ_{t∈S} h_t ≤ H_t`、`|S| ≤ L_max`、`Σ c_t ≤ B_tools`、逐步升温速率约束。
信息增益关于观测集单调子模、产热可加 ⇒ 预算化子模最大化，贪心给出 `≥(1−1/e)` 近似（引理 54）。
**高温自动降级**：`σ_obs(θ)` 上升使 `Ĝ_t` 下降，`H_t` 下降使可行集收缩 ⇒ 「热的时候探测更贵且更差」是内生的，
而非外挂规则。

**定义 441（热耦合摊销后验 TCA）** 把第 2 轮 AP-Cal 的条件从 `(h, receipts)` 扩展为 `(h, receipts, θ̂, P_θ)`：
`q(u_s | ·) = N(μ_θ(·) + B_s θ̂, Σ_θ(·) + B_s P_θ B_s^T)`；
`B_s θ̂` 是**可共享扣除的公共模态**，`B_s P_θ B_s^T` 是观测器不确定度带来的诚实膨胀。
保留保守性夹紧 `Σ ≽ κ_phys·I`。P-Quarantine 不再直接依据符号序列触发，而先经定义 442 归因。

**定义 442（热归因检验）** 记最近 K 次修复的（预测−实际）收缩残差向量 `r`。
在 `H_Θ`（热解释）下 `r ≈ J θ̃ + 噪声`，`J` 的热敏感列由 `B_s` 与增益模型给出，`θ̃` 为热漂移/估计误差；
在 `H_P`（先验缺陷）下存在不被 `θ` 张成的公共分量。用加权最小二乘投影掉热子空间：
`P_Θ = J(J^T Σ^{-1} J)^{-1} J^T Σ^{-1}`，`r_⊥ = (I−P_Θ) r`，统计量 `T = r_⊥^T Σ^{-1} r_⊥`。
`T > χ²_{1−β}(d)` ⇒ 判定先验缺陷并触发 P-Quarantine；否则判定热漂移，走 TCA 校正并**不**隔离先验。
这把第 2 轮定义 428 的「连续同向」启发式替换为**似然比式检验**（引理 52 系）。

**定义 443（8C 闭环）** `H → C → S → E → C → V → A → U`：
1. H：L-Box 共形假设集（继承 422/425）；
2. C：VLA 编译 Π_s + TCV 四查（继承 418）；
3. **S**：孪生阴影预演（定义 435/438）——`VETO` ⇒ 该程序/补丁淘汰；`GRAY` ⇒ 保守真实预检或延后；
4. E：真实执行，双层闸门 + 回执校验（继承 417/419），并以 `Pre_Θ` 维护热平稳；
5. C：TCA 热耦合校准（定义 441）；
6. V：交叉验证——要求独立回执与拟合回执的**热距离** `||θ̂_indep−θ̂_fit|| ≥ Δθ_min`（否则 `|z|` 小是平凡的），
   再跑契约回归与**热等价性**检查；
7. **A**：热归因检验（定义 442）→ 决定「隔离先验」还是「校正热漂移」；
8. U：热替换 + 带热时效的修复证书（定义 434）+ 更新热账本（定义 446）。

**定义 444（双源偏差账本与总风险）** 部署总偏差预算
`η_total = η_prior + η_twin + η_thermal`：
`η_prior` 为第 2 轮 sim→real 偏移（引理 47 的 η），
`η_twin := c·η̂_twin`（由定义 436 在线估计），
`η_thermal := ||B||·sqrt(tr P_θ)/σ_ref + ||ΔB||·||θ−θ_ref||/σ_ref`（观测器 + 响应辨识误差）。
若 `η_total > η_budget` ⇒ 拒绝热替换（stub + RED）。第 2 轮的 η 从此是**可分配、可告警的账本项**，不再是一句「由 E431 实测」。

**定义 445（热安全退化与保守包络）** 退化触发与行为：
(i) Θ-Box 失效 ⇒ `θ̂ := [θ_min, θ_max]` 保守包络，禁用高产热/高热敏工具；
(ii) 孪生失效 ⇒ 跳过 S（仅丧失否决权，其余照常，退化到 ToolGauge）；
(iii) 热预算耗尽 ⇒ 冷却/延后，超时则降级；
(iv) 单调性：可用信息越少 ⇒ 允许的探测集合**只能更小**（`I₁ ⊆ I₂ ⇒ ProbeSet(I₁) ⊆ ProbeSet(I₂)`）。
退化链：**ThermoGauge ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE**。

**定义 446（热侧效应账本与契约扩展）** χ_R 扩展为含热注入/散热的完整反作用通道：
每次工具调用记录 `(h_t, 实测 Δθ, 冷却时长, 峰值温度)`；任何热安全主张必须引用 θ̂ 回执与定义 434 的时效证书，
否则按定义 423 剥离。补丁级热账本 `ℓ(EC) = 预期热耗散率`；热替换要求
`|ℓ(new)−ℓ(old)| ≤ ε_ℓ`，否则必须重跑定义 440 的热可行性（防止「数值等价但热学上不稳定」的补丁）。

**定义 447（继承与编号约定）** 未被本轮重定义的第 1/2 轮记号沿用定义 398–431。
退化特例：令 `twin=∅`、`θ=∅`（`B_s=0`）、`H_head=∞` ⇒ ThermoGauge ≡ ToolGauge；
再令 `VLA=∅`、`T₀={被动观测}`、`MP-Φ=物理先验 GP` ⇒ ToolGauge ≡ LeanGauge。

```python
class ThetaBox:
    def update(self, y, q):                       # 50Hz 内联，O(d_θ²)
        self.th, self.P = kalman(self.th, self.P, y, q,
                                 self.A, self.Bq, self.C, self.Q, self.R)
        return self.th, self.P

    def half_life(self, s, th0, th_inf, eps_u):
        denom = norm(self.B[s]) * norm(th_inf - th0)
        if denom <= 1e-12: return math.inf
        gamma = eps_u / denom
        if gamma >= 1.0: return 0.0               # 工作点无有限有效期 ⇒ 重校准/stub
        return -self.tau * math.log(1.0 - gamma)

        return (trace(self.P) <= self.P_max) and (abs(dth_dt) <= self.rate_max)

    def shadow(self, prog, candidate_patch, scenarios):

            out.append((traj, pred, safety_predicates(traj)))
```

## 3. 推导

**引理 51（热状态可观测性与误差协方差的「低秩 + 对角」结构）**
设定义 432 的线性高斯 RC 模型 `(A,C)` 可观测、`Q≻0`，则 Kalman 误差 `P_t` 有界并收敛到稳态 `P_Θ`，热状态可辨识。
若 `u_s = μ_s + B_s θ + ε_s`，`θ ~ N(θ̄, Σ_θ)`，则
`Σ_U = B Σ_θ B^T + diag(Σ_s)`，且 `rank(B Σ_θ B^T) ≤ d_θ`。
**证明**：标准 Kalman 收敛 + 线性变换协方差。**系**：第 2 轮所谓「无结构跨盲区相关偏差」，在热模型下只是 `d_θ` 维公共因子；
估计 `θ̂` 后残余跨协方差降为 `B P_Θ B^T`——可解释、可扣除、可监控。

**引理 52（热去趋势的相关性收缩与保真加权共形覆盖）**
令 `ũ_s = u_s − B_s θ̂`（公共模态扣除）。则对 `s≠s'`，
`Cov(ũ_s, ũ_{s'}) = B_s P_Θ B_{s'}^T`，相关系数满足
`|ρ_{ss'}| ≤ ||B_s||·||B_{s'}||·λ_max(P_Θ) / sqrt((||B_s||²λ_max(P_Θ)+σ_s²)(||B_{s'}||²λ_max(P_Θ)+σ_{s'}²))`。
故 `P_Θ→0` 或私有噪声占优时 `ρ→0`：**热去趋势把「系统性相关」压回「可加的独立误差」**。
保真加权共形：真实标签权重 1、孪生标签权重 `w=φ(δ_twin)`，孪生标签错误率 `ε_label`、分布漂移 `η′` 下
`P(h*∈H_s) ≥ 1−α−2η′−2ε_label`。
**证明思路**：标签噪声条件下共形分数的最坏情况偏移 ≤ `2ε_label`（每个错误标签最多改变一个秩），
加权交换性给出 `2η′` 项；真实标签始终比孪生标签权重高，故不会系统性放大噪声。
**系（对第 2 轮风险 1 的回答）**：P-Quarantine 的误报率由「相关残差是否被热子空间解释」决定；
定义 442 的检验在 `H_Θ` 成立时以 `1−β` 概率不触发，从而不再把热漂移误判为先验缺陷。

**引理 53（否决性预言机的可靠性、不完备性与权威边界）**
设安全谓词 `g` 关于孪生状态 `L_g`-Lipschitz，孪生状态误差 `≤ ε_z`，裕度 `m = L_g ε_z`。
(a) `VETO`（`ĝ>m`）⇒ `g ≥ ĝ−m > 0`：**可靠否决，零假否决**；
`CLEAR`（`ĝ<−m`）⇒ `g ≤ ĝ+m < 0`：在其误差界内可证安全。
(b) 但「批准一次修复」的谓词是**数值正确性**（后验与真实契约参数一致），它不关于孪生状态 Lipschitz，
也不在定义 436 的重叠集上可标注 ⇒ 孪生不能签发批准，V 阶段真实回执交叉验证不可省。
(c) 若 `δ_twin > ε_z`（界被高估），(a) 的两个方向同时失效；因此 `ε_z` 必须是 `δ_twin` 的高置信上界，
且随 `δ_twin` 上修而扩大 `GRAY`、收缩 `CLEAR`。**系**：孪生的权力是「否决」而非「认证」，
与第 2 轮「语言不进数值通道」同构。

**引理 54（热预算调度的可行性与近似比）**
高斯观测的信息增益关于已选工具集单调子模，产热可加；故定义 440 是预算化子模最大化，
贪心解满足 `ΣĜ(greedy) ≥ (1−1/e)·OPT`。可行性：若稳态热负载小于散热能力，则存在满足 `θ_max` 的调度；
否则只能延后或降级。**热-样本耦合**：`n_min(θ)=σ_obs(θ)²(ε⁻²−σ_0⁻²)` 在 `κ>0` 时随 θ 单调不减，
而 `Ĝ_t(θ)=½log(1+σ_prior²/σ_obs²(θ))` 单调不增 ⇒ **温度越高，校准既越贵又越没用**——这是内生的、可证明的。

**引理 55（8C 的时序、热安全与不变式保持）**
S/E/C/V/A 全部异步于 50Hz 路径之外；50Hz 周期仅新增 `O(d_θ²)` 的 Kalman 更新与 `O(1)` 回执验证（`< 0.15ms`）。
热替换的**数值**等价性仍由第 2 轮引理 49 保证；新增的热等价性（定义 446）与时效（定义 434）只**收紧**允许的替换，
不会放宽。退化是单调保守的（定义 445）：信息减少只会删除探测、扩大包络 ⇒ 五不变式与新增热反作用完备性保持。
单盲区修复时延 `≤ τ_shadow + L_max·max τ_t + τ_TCA + τ_V + τ_A ≤ τ_repair`（由 Θ-Contract/TB-Contract 共同界定）。

## 6. 本轮最大风险（一句话）

## 2. 形式化定义（要点）

**定义 432–434（热状态 / 响应 / 时效）** 线性 RC + Kalman：`θ_{t+1}=Aθ_t+B_qq_t+w_t`，`y_t=Cθ_t+v_t`；
`u_s(θ)=μ_s+B_s(θ−θ_ref)+ε_s`；证书偏差 `||B_s(θ_t−θ_0)||≤ε_u` 解出
`t_Θ(s)=−τ ln(1−γ)`、`γ=ε_u/(||B_s||·||θ_∞−θ_0||)`；`γ≥1` 即无有限有效期。热平稳前置不满足则不校准。
**定义 435–438（孪生 / 保真 / 反事实 / 否决）** 孪生仅在可观测重叠集 `O_t` 同步；`shadow` 在分叉副本上预演且对真机零副作用；
`δ_twin=|ŷ_twin−y_real|/σ_decl`；反事实标签权重 `w=φ(δ_twin)`，真实标签恒权 1 且优先；
三值判定裕度 `m=L_gε_z`：`VETO(ĝ>m)`/`CLEAR(ĝ<−m)`/`GRAY`，**CLEAR 不是批准**。
**定义 439–440（热预算 / 调度）** 产热 `h_t`、余量 `H_t=θ_max−θ̂^{crit}`、升温速率约束；不可行则冷却/延后；
`σ_obs(θ)` 与 `n_min(θ)` 均随温度单调不利；增益/产热贪心最大化（子模）。
**定义 441–442（TCA / 归因）** `q(u_s|·)=N(μ_θ+B_sθ̂, Σ_θ+B_sP_θB_s^T)`，保留 `Σ≽κ_phys I`；
归因用 `r_⊥=(I−P_Θ)r`、`T=r_⊥^TΣ^{-1}r_⊥`，`T>χ²_{1−β}` 判先验缺陷，否则判热漂移并校正。
**定义 443（8C）** H→C→S→E→C→V→A→U；S 的 VETO 零副作用中止；V 要求热距离 `≥Δθ_min` + 契约回归 + 热等价性；
A 决定隔离先验或热校正；U 签发带热时效的证书并更新热账本。
**定义 444–447（账本 / 退化 / 热通道 / 继承）** `η_total=η_prior+η_twin+η_thermal`，超预算拒绝替换；
热安全单调退化；χ_R 扩展为含热注入/散热的完备反作用通道，补丁热账本 `|Δℓ|≤ε_ℓ`；
`twin=∅, θ=∅, B_s=0, H_head=∞` ⇒ ThermoGauge≡ToolGauge。

## 3. 关键算法骨架

```python
# IP-321 Θ-Box：热状态 + 证书时效
class ThetaBox:
    def update(self, y, q):
        self.th, self.P = kalman(self.th, self.P, y, q, self.A, self.Bq, self.C, self.Q, self.R)
        return self.th, self.P
    def half_life(self, s, th0, th_inf, eps_u):
        denom = norm(self.B[s]) * norm(th_inf - th0)
        if denom <= 1e-12: return math.inf
        gamma = eps_u / denom
        return 0.0 if gamma >= 1.0 else -self.tau * math.log(1.0 - gamma)
    def stationary(self, s, dth_dt):
        return trace(self.P) <= self.P_max and abs(dth_dt) <= self.rate_max

# IP-322 DT-Shadow：阴影预演 + 三值否决
class DTShadow:
    def sync(self, real_obs): self.z = fuse(self.z, real_obs, self.overlap)
    def shadow(self, prog, patch, scenarios):
        return [simulate(fork(self.z, xi), prog, patch) for xi in scenarios]   # 异步/GPU
    def verdict(self, g_hat, eps_z, L_g):
        m = L_g * eps_z
        if g_hat >  m: return "VETO"          # 可证违规
        if g_hat < -m: return "CLEAR"         # 不反对，但≠批准
        return "GRAY"

# IP-323 TCA：热耦合摊销校准
class TCA:
    def calibrate(self, receipts, H, s, th, Pth):
        mu, Sig = self.mp_phi(featurize_ctx(receipts, H, s, th))
        mu  = mu + self.B[s] @ (th - self.th_ref)
        Sig = Sig + self.B[s] @ Pth @ self.B[s].T
        return mu, clamp_min(Sig, KAPPA_PHYS)

# IP-324 Θ-Sched：热预算感知调度
class ThetaSched:
    def schedule(self, H_s, tools, th, headroom, tb, thb):
        sig = sigma_obs(th, thb.kappa)
        cand = [t for t in tools if self.risk_gate(t) and t.cost <= tb.budget_left
                and t.heat <= headroom - thb.margin]
        cand.sort(key=lambda t: info_gain(t, H_s, sig) / max(t.heat, 1e-6), reverse=True)
        return self._fill_knapsack(cand, headroom, tb)

# IP-325 热归因 + 8C 闭环
def attribute(r, J, Sigma, beta):
    P = J @ inv(J.T @ inv(Sigma) @ J) @ J.T @ inv(Sigma)
    r_perp = (np.eye(len(r)) - P) @ r
    T = float(r_perp.T @ inv(Sigma) @ r_perp)
    return "prior_defect" if T > chi2.ppf(1 - beta, len(r)) else "thermal"

def thermogauge_8c(M, s):
    H    = M.lbox.hypothesize(s, M.dbox.R[s])                       # H
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s))       # C
    th, Pth = M.theta.update(M.thermistors(), M.heat_cmd())
    if not M.theta.stationary(s, M.dth_dt()): return defer_or_stub(s, "thermal_transient")
    patch = M.patch_candidate(s)
    for v in M.twin.verdicts(prog, patch, M.scenarios(s)):          # S
        if v == "VETO": return stub_and_red(s, "twin_veto")
        if v == "GRAY" and not M.real_precheck_safe(s): return defer_or_stub(s, "twin_gray")
    receipts = M.tcv.execute(prog, M.env)                           # E
    if len(receipts) < n_min(s, th): return stub_and_red(s, "insufficient_evidence")
    mu, Sig = M.tca.calibrate(receipts, H, s, th, Pth)              # C
    if not M.cross_validate(mu, Sig, M.cross_receipt(s),             # V
                            delta_theta_min=M.dtheta_min):
        return stub_and_red(s, "cross_check_thermally_weak")
    if attribute(M.recent_residuals(s), M.J(s), M.Sigma_r, M.beta) == "prior_defect":
        M.pquar.trigger(s); return stub_and_red(s, "prior_defect")  # A
    new_ec = M.tca.update_contract(M.dpe, mu, Sig, s)               # U
    if not contract_regression(new_ec): return stub_and_red(s, "regression")
    if abs(heat_ledger(new_ec) - heat_ledger(M.dpe)) > M.eps_heat \
       and not M.theta_sched.feasible(new_ec): return stub_and_red(s, "thermal_infeasible")
    M.mreg.hot_replace(M.dpe, new_ec)
    M.dbox.update_from_posterior(s, mu, Sig)
    M.cert.issue(s, new_ec, th,
                 expiry=M.theta.half_life(s, th, M.theta_inf(s), M.eps_u))
    M.heat_ledger.record(receipts, M.heat_cmd())
    return True

# IP-326 主闭环
def ThermoGauge_round(M, obs, audio, tac, depth, det):
    M.theta.update(M.thermistors(), M.heat_cmd())          # 50Hz 内联 O(d_θ²) < 0.1ms
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s); submit_async(thermogauge_8c, M, s)
    if M.pquar.triggered(): M.tca.pause(); M.use_apcal_fallback = True
    if not M.theta_ok():    M.degrade_to_toolgauge("thermal_observer_lost")
    if M.twin_ok() is False: M.use_twin = False            # 仅失去否决权
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 51（热可观测性 & 低秩+对角协方差）** `(A,C)` 可观测、`Q≻0` ⇒ Kalman `P_t` 有界收敛；`u_s=μ_s+B_sθ+ε_s` ⇒
`Σ_U=BΣ_θB^T+diag(Σ_s)`，`rank(BΣ_θB^T)≤d_θ`。故第 2 轮「无结构跨盲区相关」在热模型下只是 `d_θ` 维公共因子。
**引理 52（热去趋势收缩 & 保真加权共形）** `ũ_s=u_s−B_sθ̂` ⇒ `Cov(ũ_s,ũ_{s'})=B_sP_ΘB_{s'}^T`，相关系数被
`||B_s||||B_{s'}||λ_max(P_Θ)/√((||B_s||²λ_max(P_Θ)+σ_s²)(||B_{s'}||²λ_max(P_Θ)+σ_{s'}²))` 上界；
`P_Θ→0` 或私有噪声占优 ⇒ `ρ→0`。加权共形（标签噪声 `ε_label`、漂移 `η′`）覆盖 `≥1−α−2η′−2ε_label`。
系：归因检验在 `H_Θ` 成立时以 `1−β` 概率不误触发 P-Quarantine。
**引理 53（否决可靠性/不完备性/权威边界）** `g` 为 `L_g`-Lipschitz、状态误差 `≤ε_z`、`m=L_gε_z`：
`VETO(ĝ>m)⇒g>0`（零假否决）；`CLEAR(ĝ<−m)⇒g<0`（误差界内可证安全）；
但修复批准谓词是数值正确性，非 Lipschitz、不可由重叠集标注 ⇒ 孪生不能批准，V 阶段不可省；
`δ_twin>ε_z` 时两个方向同时失效 ⇒ `GRAY` 扩张、`CLEAR` 收缩。
**引理 54（热预算调度）** 高斯信息增益单调子模、产热可加 ⇒ 预算化子模最大化，贪心 `≥(1−1/e)OPT`；
`n_min(θ)` 单调不减、`Ĝ_t(θ)` 单调不增 ⇒ 高温下校准「更贵且更没用」；稳态热负载 < 散热能力则可行，否则延后/降级。
**引理 55（8C 时序/热安全/不变式）** S/E/C/V/A 全异步，50Hz 仅 `O(d_θ²)` Kalman + `O(1)` 回执验证 `<0.15ms`；
数值等价同引理 49，热等价/时效只收紧替换；退化单调保守 ⇒ 五不变式 + 热反作用完备性保持。

## 8. 本轮最大风险

**一句话**：孪生与热模型本身是未验证的第二、第三重预言机——热瞬态下 `δ_twin` 与 `B_s/θ̂` 误差同时放大，
系统可能以「孪生已预演、温度已补偿」的强理由批准一个只在孪生里成立、且在真实热瞬态中迅速失效的修复，
从而把随机误差升级为**被两层模型共同认证的系统性偏差**；以 E444/E446/E450/E454 证伪，
并以定义 438 的否决/批准不对称、定义 442 的归因检验与定义 444 的双源账本为结构性兜底。
