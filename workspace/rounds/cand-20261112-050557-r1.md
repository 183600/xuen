# 第 58 轮（承接第 57 轮「少样本元推断×跨模态对账×个性化有界信任」IP-133~138；新灵感循环第 1 轮；本轮灵感：「目标检测」×「状态隔离」）

> 第 57 轮把安全的赌注从"模型置信/证据质量"进一步押到"元先验质量"，并用 OOD 门 + 共形保底 + 跨模态对账 + 单向有界授权四道护栏，使"语料里没有的世界"不至于被自信采信。但它的风险自陈暴露了一个更底层的结构问题：整条研究线一直默认 **(a) 证据能正确归属到它所描述的对象**——区域级信念 b_r 默认"探针触到的就是这个区域的表面"，可真实区域里往往并存多个目标（石块/冰壳/草丛/薄板），探针真正碰到的是"某个目标"，把目标 A 的欺骗性证据记到目标 B 头上，会制造比"没有证据"更危险的**归因污染**；**(b) 信念状态是一份可自由共享的全局账本**——MFSL 从全体区域摊销先验、XMC 把证据汇入区域、证伪回溯降权"该模态全部历史"，于是第 57 轮最大风险"坏先验普遍"本质上不是校准失败，而是**状态共享导致的污染扩散**：一个盲区分片的错误被写进共享先验，污染所有区域；一次错误归因的回溯会误伤无关目标的证据。
>
> 本轮两个灵感正好各修一个隐藏假设：**目标检测**把"区域"细化为"目标 + 归因"，并让检测本身成为一个**受证据门约束的提案者**（检测提议、证据裁决）；**状态隔离**把"单一共享状态"改为"隔离账本 + 审计晋升 + 级联回滚 + 推测分支"，让单点错误的影响被限制在其隔离后代内。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"目标归属可审计、证据状态可隔离、承诺对分支鲁棒的目标接地证据说可信"**。
>
> 一句话动机：**第 57 轮学会了"不要相信语料里没有的世界"，本轮要学会"不要把 A 世界的证据塞进 B 世界，也不要把一次污染扩散成普遍污染"。**

核心矛盾：
- **H29（归因 vs 证据）**：检测器给的是候选目标与候选归属，不是事实；"这根探针到底触到了哪个目标"本身是未观测变量。归因错，则证据越强越有害——它会以高置信污染一个无辜目标，并沿共享路径传染。
- **H30（隔离 vs 泛化）**：状态隔离限制污染，但也切断摊销；隔离越彻底，每目标样本越稀薄、冷启动越贵，等于把第 57 轮辛苦换来的小样本效率又还回去。隔离证书本身也可能变成新的手工先验。
- **H31（检测 vs 承诺）**：检测器是开放世界的、可被对抗补丁欺骗的提案器；一旦让检测参与承诺，攻击面就从"物理证据"扩大到"感知输入"——敌人不必骗过触觉，只需在视觉里伪造一个目标，就能劫持归因、避让或触发/阻止承诺。

## 0. 直觉与动机

**灵感 1（目标检测 → 从区域信念到目标接地信念 + 归因账本）**
直觉：区域是一个"盒子"，目标才是"东西"。探针不是"问区域"，而是"碰到了一个具体的东西"。旧体系把每次探到的证据倒进区域这个盒子，盒子里有几个目标就搅成一锅：冰壳（欺骗性）与旁边石块（良性）同处一区，冰壳的假证据会让整块区域被永久看衰，或者反过来石块的真证据替冰壳背书。目标检测提供的不是"答案"，而是"候选归属"：先问"这一触可能落在哪些目标上、各有多大可能"，再决定这笔证据记到谁的账上。关键设计是 **归因门**：归属后验不过阈值、或最优与次优差距不够大时，证据进入**未归因账户 U_r**——它不参与任何承诺判定，只能用于"下一根探针该往哪打"的 VOI。于是"证据不足"和"证据归属不明"被分开处理；**宁可记不上账，也不记错账**。区域信念降格为"目标信念 + 未归因质量"的保守混合，不再直接作为承诺依据。

**灵感 2（目标检测的不可信性 → EV-detect 与检测证书）**
直觉：检测器会把阴影看成坑、把反光看成冰、在开集世界里遇到没见过的类别，还会被对抗补丁骗出假目标。所以检测**不能**是 commit 的理由，只能是**发起探针的理由**。我们新增证据类 EV-detect，但它必须挂检测证书（存在/类别校准、开集弃权、遮挡比例诚实、位姿不确定度），且在 L2 不可逆接触上**永远不能单独构成必要证据**。这就是"**检测提议、证据裁决**"：检测可以让你更想探、更想绕、更想降档，但永远不能让你"更敢赌"。检测器本身也是判定器，其版本更新继承第 57 轮 CEB++ 的"一切判定器走隔离"。

**灵感 3（状态隔离 → 事务化证据账本与级联回滚）**
直觉：如果证据是一本大家可以随手涂改的公共账本，那么一笔坏账会污染所有人。状态隔离的做法是把它变成**带快照隔离与事务的账本**：每笔证据是一次事务，承诺决策只读"已提交且未撤回"的快照；跨目标/跨区域的共享必须走显式**晋升** π（带 provenance 与覆盖证书），晋升可回滚，且回滚**级联**撤销所有依赖它的下游晋升与承诺候选。这样第 57 轮"事后证伪回溯降权该模态全部历史"从"一刀切"变成"精确制导"：只回滚真正依赖被证伪证据的账目，不误伤无关目标。核心不变量：**承诺只能读已提交、未撤回、归因达标的证据；未归因/隔离中/已回滚证据只能进 P_fail 的悲观项，绝不进乐观项。**

**灵感 4（状态隔离 → 推测分支隔离：承诺对"世界可能是哪个样子"取最坏）**
直觉：目标被遮挡、类别开集未知、归因歧义时，我们其实同时在几个"可能世界"里。旧体系把歧义压成一个平均后验，平均会把两个都危险的分支平均成"看起来还行"。分支隔离让每个可能世界跑在独立沙箱里，各自持有一份隔离账本，互不串证；只有**所有活跃分支都通过证据门**才允许承诺，否则视为未决，转向探针/绕行/降档/L2。这不是更保守一点点，而是把承诺的语义从"平均上安全"改成"**对活跃分支集合一致安全**"。分支预算 K_b 保证终止，VOI 只用于决定先探哪个分支，永远不用于"把分支合并成更敢赌的结论"。

**灵感 5（状态隔离 → 先验分片与治理式共享，专治"坏先验普遍"）**
直觉：第 57 轮的单一元先验是"全租户共用一本教材"，一个盲区章节会教坏所有学生。状态隔离给出正解：按上下文租户 τ=（材质簇×季节×坡度带×任务族）维护**隔离先验分片** {p_τ}，只保留一份经审计的共享骨干 p_0（仅跨租户不变量）；分片间借用必须出示重叠证书与覆盖下界，没证书就退回非参共形区间。全局风险对分片取 **max（悲观）而非平均**：一个分片的盲区不得借共享骨干放大到其他分片。操作者/会话状态同样按租户隔离（继承 PTM），杜绝跨会话信任通胀。

**灵感 6（合流 → 证据门从五类到六类、承诺算子从单状态到分支鲁棒）**
直觉：第 57 轮的 EV-probe*/visit/margin/xmodal/human 六类中，本轮新增 **EV-detect**，并把不可逆接触的必要证据集写死为 {EV-probe* ∨ EV-margin} ∪ 佐证——**EV-detect 与 EV-xmodal 都不得单独构成必要证据**。承诺算子从"读单一全局状态"改为"读已提交快照 × 对活跃分支取最坏 × 归因达标"。击穿安全需要：归因错 ∧ 未归因门漏检 ∧ 检测证书失实 ∧ 所有分支同时错 ∧ 隔离/回滚失效——纵深从五层到六层。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（目标接地与归因 TGA）** 检测器 D 在区域 r 输出候选目标 𝒪_r={(o,ĥ_o,bbox,cls,s_o)}（存在/位姿/类别/置信）。归因变量 a∈𝒪_r∪{∅}。探针 p 的证据 e_p 依接触几何（实际触点 x_p、法向、力）与检测位姿计算归因后验
α(a|p) ∝ p(x_p | o)·p(可触 | o)·s_o，∅ 吸收"未检测到/触点落在目标外"的质量。
归因门：仅当 max_a α(a|p)≥θ_attr ∧ (α_(1)−α_(2))≥θ_am 才把 e_p 记入账本 L_{r,a}；否则记入未归因账户 U_r。目标信念 b_{r,o} 只由 L_{r,o} 更新，**不跨目标直接共享**；区域信念 b_r := ConservativeMix({b_{r,o}}, worst_fill(U_r|𝒪_r))，且 b_r 不直接作为承诺依据。承诺只读 b_{r,o}。

**定义 140（检测证据类 EV-detect 与检测证书 DT-Cert）** 检测是提案不是事实。EV-detect 准入需证书：类别/存在校准 ECE_det≤ε_det；开集弃权（未知即 abstain，不得强行归类）；遮挡比例与掩码诚实（报告 occluded(p)）；位姿不确定度入 P_fail；跨模态对账（定义 134）在 L2 上要求 ≥2 独立模态同侧，否则不得作为不可逆接触佐证。硬规则：**EV-detect 不能单独使 EV-probe 成立，也不能单独构成不可逆接触必要证据**；它只能 (i) 产生归因先验，(ii) 触发探针/绕行/降档，(iii) 在 L1 上提供至多一次佐证。检测器版本更新走隔离区（继承 CEB++）。

**定义 141（事务化证据隔离 TEI）** 证据状态 S={L_{r,o}} 是版本化、只追加账本；每次写入是事务 txn(id,snapshot,writes,parents)。快照隔离：承诺决策只读已提交快照，未提交/隔离中证据对决策不可见。跨目标/跨区域共享仅通过显式晋升 π: local→shared，π 携带 provenance 与覆盖证书，且可回滚；证伪触发**级联回滚**，撤销所有 parents 链上依赖该晋升的下游晋升与承诺候选。不变量（Isolation Soundness）：承诺所用证据必须满足 committed ∧ ¬revoked ∧ attribution_ok；U_r、隔离分支证据、已回滚证据只能进 P_fail 悲观项。

**定义 142（推测分支隔离 SBI）** 对归因/存在/类别存在歧义的目标（α 未过门、开集未知、遮挡），派生 K≤K_b 个隔离分支 {β_k}，各持独立状态副本与独立账本，分支间不共享未提交证据。合并条件：∀i,j TV(b_{β_i},b_{β_j})≤θ_br 且合并后整体过证据门；否则不合并，标为"未决目标"。承诺鲁棒性：检查点 cp 的承诺 ⇔ ∀活跃分支 β：EV-gate_β=ok ∧ R_β≤δ_f(g) ∧ 归因达标；只要存在一个分支不成立，只能探针/绕行/降档/L2。VOI 仅用于选择探索分支，不得用于合并分支以放宽承诺。

**定义 143（先验分片与治理式共享 PSS）** 以租户 τ=(材质簇,季节,坡度带,任务族) 维护隔离先验分片 {p_τ}；共享骨干 p_0 只含经审计的跨租户不变量。分片借用须出示重叠证书 overlap(τ,τ') 与覆盖下界；无证书退回第 57 轮非参共形区间 C_cf。每分片独立校准并跨分片取 union bound；全局风险取 max_τ（悲观），禁止用平均掩盖盲区分片。租户隔离同样约束操作者/会话个性化状态：s_o 与证据不跨租户共享。

**定义 144（目标接地隔离证据门 OGE 与证书 J_s）** 证据类六类：EV-probe*/EV-visit/EV-margin/EV-xmodal(限 L1)/EV-human/EV-detect。不可逆接触必要证据集 = {EV-probe* ∨ EV-margin} ∪ 佐证；EV-detect、EV-xmodal 均不得单独入选。承诺算子 OGE：每检查点先做归因，再对活跃分支集合求最坏分支判定；未决则用目标级 VOI 选探针；探尽→绕行→降档→L2/安全停。J_s = J_p ∪ {target_attr_log, detector_cert, branch_log, isolation_txn_log, promotion_rollback_log, tenant_id, operator_isolation}，继承 J_p 全检。

## 2. 关键算法伪代码（完整版见产物区）

```python
def attribute_and_post(M, r, p, obs, meta):        # IP-139/140 合流
    cands = detect(M, r, obs)                       # 提案：候选目标（非事实）
    if not detector_cert_ok(cands) :                # 开集弃权 / 遮挡失实 / 校准超界
        return M, Unattributed(p, reason='det_uncertified')
    alpha = attribution_posterior(p, cands, obs)    # 接触几何 × 检测位姿
    a = argmax(alpha)
    if alpha[a] < theta_attr or margin(alpha) < theta_am:
        M.U[r].append(p); return M, Unattributed(p)  # 宁可记不上账
    M = txn_write(M, target=(r, a), ev=p)           # IP-141 事务写
    return M, Attributed(r, a)

def txn_write(M, target, ev):
    t = Txn(id=new_id(), snapshot=M.version, writes=[(target, ev)])
    M.pending.append(t); return M

def commit_or_abort(M, t, branch_beliefs):          # IP-141/142
    if any(b.revoked for b in t.parents): return abort(M, t)   # 级联回滚
    if not snapshot_visible(M, t): return M
    M.ledger[t.target].append(t); M.version += 1; return M

def branch_commit(cp, branches, sched):             # IP-142 最坏分支
    live = live_branches(branches)
    if not live: return ('abstain', 'no_live_branch')
    if all(evidence_gate(cp, b) == 'ok' and risk(sched, b).R <= delta_f
           for b in live):
        return ('ok', merge_if_close(live, theta_br))
    return ('defer', worst_branch(live))            # 不合并成"更敢赌"

def prior_shard_infer(r, obs, meta):                # IP-143 分片 + 借用证书
    tau = tenant(r)
    if meta.cert_overlap(tau, meta.obs_shard(tau)) or on_distribution(obs, tau):
        return meta.p_shard[tau].infer(obs)         # 本分片摊销
    return conformal_belt(meta.res[tau], sim=ctx(r), alpha=alpha_conf)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| TGA | O(\|𝒪_r\|·d_det)/探针 | O(\|𝒪\|·d_b) | 归因门误归因 ≤δ_attr、U 不参与承诺 |
| DT-Cert | O(d_det) | O(\|𝒪\|) | 开集弃权、遮挡诚实、EV-detect 不单独成必要证据 |
| TEI | O(H_txn) 提交/回滚 | O(\|ledger\|·V) | 快照隔离、级联回滚完整、只读已提交 |
| SBI | O(K_b·(\|σ\|+d_b)) | O(K_b·\|𝒪\|·d_b) | 分支覆盖真实世界、最坏分支判定 |
| PSS | O(\|𝒯\|·d_φ)/借用 | O(\|𝒯\|·\|𝒟_meta\|) | 借用证书、跨分片悲观 union |
| OGE | O(\|CP\|·K_b·(k_p+k_c)·(C_VOI+d_φ)) | O(\|V\|+\|σ\|+K_b·\|𝒪\|) | 六类证据门、分支终止 |

**正确性定理（OGIS 概要）**：在 A33–A40 上加 (A41) 归因门误归因率 ≤δ_attr 且未归因证据只进悲观项；(A42) 检测证书诚实（ECE_det≤ε_det、开集弃权、遮挡诚实），EV-detect 不单独构成不可逆证据；(A43) 事务隔离完整：承诺只读已提交快照，晋升可回滚且级联完整；(A44) 活跃分支集合覆盖真实世界状态，θ_br 保守。则：(i) 归因健全性：ID 路径 P(fail)≤δ_f+δ_attr+ε_det+δ_probe+ε_h；(ii) 隔离限损：单点证伪在晋升审计完备时跨目标/跨租户污染=0，回滚后污染承诺数不回增；(iii) 分支鲁棒：若真实世界∈活跃分支，则 P(fail)≤max_β(δ_f+δ_attr+ε_det+δ_probe+ε_h)；(iv) 隔离单调性：增加隔离/分支/分片只能收缩可承诺集合，不能扩张；(v) OGE 在 k_probes+k_cons 与 K_b 内终止于 {承诺,绕行,L2,安全停}。

## 5. 风险与缓解

## 6. 本轮最大风险

**一句话**：本轮把安全从"证据质量"进一步押到"归因正确 + 隔离足够"，但隔离与泛化天然对立——隔离越彻底，跨目标摊销越少、每目标证据越稀薄（退回冷启动），而检测器本身成为新的可攻击入口（对抗补丁伪造目标即可劫持归因、避让与承诺）；若隔离证书不完备或分支合并阈值被调松，系统会退化成"单目标看似自洽、整体先验碎片化且仍可相互污染"的状态。

def detect_candidates(M, r, obs):
    cands = detector(obs['vis'], obs.get('depth'), calib=M.det_cal)

    cands = detect_candidates(M, r, obs)
    if not detector_cert_ok(M, cands):
        return ('unattributed', 'det_uncertified')       # 检测不可信 → 不记账

        M.U[r].append(ProbeEv(p, alpha))                 # 未归因：只进 VOI
        return ('unattributed', 'low_attr')
    return ('attributed', a1, alpha[a1])

### IP-141 TEI（事务化证据隔离与级联回滚）

```python
def txn_begin(M, target, ev, parents=()):
    t = Txn(id=M.next_txn(), snapshot=M.version,
            writes=[(target, ev)], parents=list(parents))
    M.pending.append(t)
    return t

def txn_commit(M, t, branch):
    if any(p.revoked for p in t.parents):       # 依赖已回滚 → 本笔不得提交
        t.revoked = True; return abort(M, t)
    if not snapshot_visible(M, t.snapshot, branch):
        return defer(M, t)
    M.ledger[t.writes[0][0]].append(t)
    M.version += 1; M.pending.remove(t)
    return commit(M, t)

def promote(M, target, cert):
    if not coverage_cert_ok(cert) or not provenance_ok(M, target):
        return reject('promotion_unproven')      # 无覆盖证书不得跨目标共享
    pi = Promotion(src=target, cert=cert, parents=dep_dag(M, target))
    M.shared.append(pi); M.audit.log(pi)
    return pi

def cascade_rollback(M, falsified):
    dead = {falsified}
    changed = True
    while changed:                                # 沿 parents 反向闭包
        changed = False
        for t in M.ledger.all():
            if t.parents & dead and t.id not in dead:
                dead.add(t.id); t.revoked = True; changed = True
        for pi in M.shared:
            if pi.parents & dead and pi.id not in dead:
                dead.add(pi.id); pi.revoked = True; changed = True
    M.audit.log(('rollback', dead))
    return M

def isolation_invariant(cand):
    return (cand.committed and not cand.revoked
            and cand.attribution_ok and cand.src != 'U')
```

def evidence_gate(cp, M, personas, ood_reg, level):

                 and c.corrob >= quarantine_exit(personas[c.op].auth)

            return ('reject', 'proposal_on_irreversible')   # 硬禁令
    return ('ok', c)

def probe_commit_evolve_object(cp, M, branches, personas):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TGA | O(\|𝒪_r\|·d_det)/探针 | O(\|𝒪\|·d_b) | 归因门误归因≤δ_attr；U 不进承诺（A41） |
| DT-Cert | O(d_det) | O(\|𝒪\|) | 开集弃权、遮挡诚实、EV-detect 不单独成必要证据（A42） |
| TEI | O(H_txn) 提交/回滚 | O(\|ledger\|·V) | 快照隔离、级联回滚完整、只读已提交（A43） |
| SBI | O(K_b·(\|σ\|+d_b)) | O(K_b·\|𝒪\|·d_b) | 分支覆盖、最坏分支判定（A44） |
| PSS | O(\|𝒯\|·d_φ)/借用 | O(\|𝒯\|·\|𝒟_meta\|) | 借用证书、跨分片悲观 union |
| OGE | O(\|CP\|·K_b·(k_p+k_c)·(C_VOI+d_φ)) | O(\|V\|+\|σ\|+K_b·\|𝒪\|) | 六类门、分支终止、四态完备 |

**正确性定理（Object-Grounded Isolated Soundness, OGIS）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；**(A41)** 归因门：误归因率 ≤δ_attr，未归因证据只进 P_fail 悲观项；**(A42)** 检测证书诚实：ECE_det≤ε_det、开集弃权、遮挡与位姿诚实，EV-detect 不单独构成不可逆接触必要证据；**(A43)** 事务隔离完整：承诺只读已提交快照，晋升可回滚且级联覆盖全部依赖；**(A44)** 分支覆盖与保守合并：真实世界状态 ∈ 活跃分支集合，θ_br 不放大乐观。则：

1. **归因健全性**：ID 路径 P(fail) ≤ δ_f + δ_attr + ε_det + δ_probe + ε_h(w_max)；未归因路径不产生承诺，只可能增加探针成本。
2. **隔离限损**：晋升审计完备时，单点证伪的跨目标/跨租户污染为 0；级联回滚后，依赖被证伪证据的承诺候选全部撤销且不复活（回滚单调）。
3. **分支鲁棒性**：若真实世界 ∈ 活跃分支，则 P(fail) ≤ max_β (δ_f+δ_attr+ε_det+δ_probe+ε_h)；分支发散只导致 defer，不导致更乐观承诺。
4. **隔离单调性**：增加目标隔离、分支、分片或回滚，只能收缩可承诺集合，不能扩张；检测提议不构成升险通道。
5. **终止性**：每检查点共识探针 ≤k_cons、分支 ≤K_b，OGE 终止于 {承诺, 绕行, L2 协商, 安全停}。
6. **部署界**（对检查点与分支取联合界）：

```
P_safe ≥ 1 − Σ_cp Σ_{β∈live(cp)} (δ_f + δ_attr + ε_det + δ_probe + ε_h)
            − P(归因门系统性偏置) − P(事务隔离失效)
            − P(分支集合未覆盖真实世界) − P(级联回滚遗漏)
            − P(护盾回退失败) − P(L2 超时 ∧ 安全停失效)
```

关键：**目标接地把"证据属于谁"从隐含假设变成可审计门**（宁可记不上账，不可记错账）；**检测提议、证据裁决**把开放世界检测器挡在承诺之外；**事务隔离 + 级联回滚**把第 57 轮"坏先验普遍"从校准问题改写为可限损的状态管理问题；**分支鲁棒**把"平均上安全"改成"对可能世界一致安全"。

云边协议 CEB++ → **CEB+++**：云端可下发检测器/先验分片增量，但**检测器与分片晋升同样走隔离区**——影子模式运行，回归测试（ECE_det 不劣化 ∧ 开集弃权率不降 ∧ 跨分片污染=0 ∧ 归因门误归因率不升）通过后才接管；晋升必须带 provenance，边端可发起级联回滚并向上游传播撤回；边端回传归因残差与未归因账户统计，作为云端分片补盲与检测器校准依据。第 57 轮"一切判定器走隔离"在本轮细化为"**一切证据写入走事务、一切跨目标共享走审计晋升、一切承诺对活跃分支取最坏**"。

## 6. 本轮最大风险

**一句话**：本轮把安全从"证据质量"进一步押到"归因正确 + 隔离足够"，但隔离与泛化天然对立——隔离越彻底，跨目标摊销越少、每目标证据越稀薄（退回冷启动），而检测器本身成为新的可攻击入口（对抗补丁伪造目标即可劫持归因、避让与承诺）；若隔离证书不完备或分支合并阈值被调松，系统会退化成"单目标看似自洽、整体先验碎片化且仍可相互污染"的状态。
