# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「移动操作」×「数字孪生」）

> 第 60 轮把「执行层→证据层」升级为「认知驱动的场景-执行闭环」：SSM 场景-阻抗先验、CIEC 意图-约束锁定、EPIR 因果隔离、SERC 场景感知闭环、PCE++++ 四维认知预算、SIC 三元校验。但**三个结构性局限**在本轮灵感下暴露：
> 1. **静态基座假设**：SSM 的 π_scene(K|z) 把场景当作固定工作空间，隐含基座位姿 b 不变。移动操作中基座持续运动，接触点相对基座漂移，轮地滑移 σ_b、定位漂移 ε_b、基座加速度 a_b 会直接注入末端动力学——同一场景在不同基座位姿下的安全阻抗并不相同，SERC 的「场景先验」因此是**位姿不敏感（pose-blind）**的。
> 2. **先验无验证**：SERC 中 K_safe^scene 由先验收窄后**直接 dispatch**，缺少「先在执行前验证一次」的环节。先验一旦错误，只能靠真实执行的下滑 D⁺ 事后发现，即「先失败、后回退」，与第 60 轮想要消除的语义鸿沟同构。
> 3. **影子副本只是记录，不是模型**：EPIR 的 S_shadow 是历史 EV-exec 的**只读存档**，能回答「过去发生了什么」，却无法回答「若基座再偏移 3cm、以 0.2m/s 接近，接触会怎样」——它缺一个可反事实推演的**动力学替身**。

## 0. 直觉与动机

**灵感 1（移动操作 → 基座-臂耦合阻抗 BACI）**
直觉：移动操作不是「基座搬运」+「固定臂操作」两个独立阶段，而是**基座运动持续改写末端有效阻抗**。把机器人看成两层弹簧-阻尼网络：臂端阻抗 Z_arm，经基座雅可比 J_b 反射到末端的基座阻抗 Z_base(b)，实际接触感受到的是二者叠加 Z_ee^eff(b)。当基座速度带宽 ω_base 与接触刚度 K_contact 接近时会共振，接触力出现低频拍振；轮地滑移则引入与基座速度同向的扰动 F_slip。关键洞见：**安全阻抗不是场景的标量函数，而是「场景 z × 基座位姿 b」的联合函数**——先验必须条件化于 b。

**灵感 2（移动操作 → 接触可及流形 CRM）**
直觉：移动底盘让「够得着且稳得住」成为一个随基座位姿变化的**流形**，而非布尔值。接触点 x_c 在基座位姿 b 下可行，需同时满足运动学可达、接触稳定裕度、力可操作度。把 SSM 的场景先验限制在可及流形上：只有落在 M_reach(b) 内的接触位姿才允许用场景先验收窄 K_safe。

**灵感 3（数字孪生 → 孪生内验证 DTIV）**
直觉：执行前先在数字孪生里「预演」一遍：输入候选 K_safe、基座轨迹 b(t)、场景 z，输出预测下滑 D̂⁺、预测峰值力 F̂_peak、预测滑移 ŝ。只有预演通过才允许 commit——**把 Probe→Commit 之间插进一个 Simulate**。孪生不是一次性建好的静态模型，而是随遥测在线校正的「活模型」，因此它提供的是**廉价反事实**而非**绝对真理**。

**灵感 4（数字孪生 → 孪生保真度与现实鸿沟预算 RGB）**
直觉：孪生与现实的差距是根本性的，绝不能假设「孪生 = 现实」。定义可量化的孪生保真度 γ_twin ∈ [0,1]，随同步延迟、未建模动力学、场景变化而衰减。孪生结论只在保真度可信域内有效；若 γ_twin < τ_gap，孪生证据必须**降权为弱证据**并回退真实接触探针。关键洞见：**孪生不能替代现实，只能替代「昂贵的现实」**——它替代的是失败代价高的真实接触，而不是真实本身。

**灵感 5（合流 → 移动孪生闭环 MDTC 与六维预算 PCE+++++）**
直觉：场景 z + 基座 b 生成耦合先验 → 孪生预演 → 真实执行 → EV-exec → **孪生-现实对账**更新 γ_twin → 更新「基座-场景-阻抗」联合信念，闭合成环。为此把第 60 轮四维认知预算拓展为六维： B_twin = (B_sync 同步带宽, B_sim 孪生仿真算力, B_fid 保真度维持, B_scene, B_intent, B_exec)。任一预算耗尽都触发对应的保守策略。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（基座-臂耦合阻抗 BACI）** 基座状态 b = (p_b, R_b, v_b, ω_b, σ_b)，其中 σ_b 为轮地滑移率。末端有效阻抗：
- **阻抗叠加**：Z_ee^eff(s, b) = Z_arm(s) + Z_base^refl(s, b)，其中 Z_base^refl = J_b^T(s) · Z_base(v_b, a_b, σ_b) · J_b(s) 为基座阻抗经基座雅可比 J_b 反射到末端的结果。
- **滑移扰动**：F_slip(b) = D(σ_b) · v_b，D(·) 为与轮地接触相关的耗散矩阵。
- **耦合稳定条件**：ω_c(K_contact) < ω_base,max(b) 且 K_eff = K_arm + K_base(b) ∈ S_stab（接触环路稳定集）。
- **位姿条件先验**：π_scene(K | z, b) = N(K; μ_scene(z) + Δμ_b(b), Σ_scene(z) + Σ_b(b))，即基座位姿对场景先验做一阶偏移与方差膨胀。

**定义 162（接触可及流形 CRM）** 在基座位姿 b 下，接触可及流形：
```
M_reach(b) = { x_c ∈ SE(3) :
    IK(x_c, b) 可行                                   (运动学可达)
    ∧ margin_stab(x_c, b) ≥ ε_stab                   (接触稳定裕度)
    ∧ μ_force(x_c, b) ≥ ε_f }                        (力可操作度)
```
场景先验仅可作用于 M_reach(b) 内的接触：K_safe^scene(z, b) = {K | P(K|z,b) ≥ τ_scene} ∩ K_safe_base ∩ K(M_reach(b))。若 M_reach(b) = ∅，则该基座位姿**不可用于操作**，交由基座重定位。

**定义 163（数字孪生工作空间 DTS）** 孪生状态 DTS(t) = (G_map, O_dyn, R_state, Θ_model)，分别为静态几何地图、动态物体集合、机器人状态估计、模型参数。同步延迟 Δt_sync(t) = t - t_last_update；模型误差 ε_model(t) = ||Θ_model − Θ_true||。DTS 通过遥测增量更新，是 EPIR 影子副本的**可执行升级**：S_shadow 存「过去」，DTS 能推演「如果」。

**定义 164（孪生内验证 DTIV）** 给定候选阻抗 K、基座轨迹 b(t)、场景 z，孪生仿真算子：
```
(D̂⁺, F̂_peak, ŝ_slip) = Simulate(DTS, K, b(t), z)
DTIV_accept ⇔ D̂⁺ ≤ δ_twin ∧ F̂_peak ≤ F_max ∧ ŝ_slip ≤ ε_slip ∧ γ_twin ≥ τ_gap
```
通过则颁发孪生验证证书 Cert_twin = (K, b(t), z, D̂⁺, γ_twin, signature)；否则返回反事实拒绝原因，供 K 搜索收缩边界。

**定义 165（孪生保真度与现实鸿沟 RGB）** 孪生保真度：
```
γ_twin(t) = exp( −λ_s·Δt_sync − λ_m·ε_model − λ_z·D_scene(z_t, ẑ_t) ) ∈ (0,1]
```
**对账更新**：真实执行后，以预测与 EV-exec 的残差更新：
```
γ_twin ← clip( γ_twin · exp(−η·||F̂ − F_real|| − η_D·|D̂⁺ − D⁺|), γ_min, 1 )
```
**可信域**：仅当 γ_twin ≥ τ_gap（建议 0.8）时，Cert_twin 可作为**强证据**参与决策；否则为**弱证据**，必须由真实接触探针补证（`τ_gap` 即现实鸿沟预算阈值）。

**定义 166（移动孪生闭环 MDTC）** 算子 MDTC(M, z, b(t), I, δ_f_req)：
```
① SSM+:    z, b ← scene_model.update_with_base(telemetry), base_state_estimator.update()
② BACI:    π_scene(K|z,b) ← condition_scene_prior(z, b)
③ CRM:     M_reach(b) ← contact_reachability(b)；若为空 → base_relocalize()
④ DTIV:    Cert_twin ← twin_verify(π_scene, b(t), z, δ_f_req)；若不通过 → shrink(K) 重试
⑤ CIEC:    C_intent ← ϕ(intent)；ERTC.lock_constraints(C_intent)
⑥ CLEP+:   K_safe ← EEIS.compile(delta_f_req, fused, ξ_exec, Z_env, π_scene(K|z,b))
⑦ Dispatch:send_impedance_params(K_safe.best, Cert_eeis, Cert_twin)
⑧ Execute: telemetry ← wait_contact_with_base_motion()
⑨ EV-exec: build_exec_evidence(telemetry, b(t), ...)；EPIR.append(EV-exec)
⑩ Reconcile: γ_twin ← twin_reality_reconcile(F̂, D̂⁺, EV-exec)
⑪ Update:  M, fused, D⁺ ← xmodal_fuse_plus(M, region, inf, EV-exec)
⑫ Return:  (z, K_safe, EV-exec, Cert_eeis, Cert_twin, γ_twin, M_reach(b))
```

**定义 167（六维预算 B_twin 与 PCE+++++）** B_twin = (B_sync, B_sim, B_fid, B_scene, B_intent, B_exec)，其中：
- **B_sync** = (Sync_bandwidth, Max_sync_lag)：同步带宽与最大允许延迟
- **B_sim** = (Sim_ops, Sim_deadline)：孪生仿真算力与截止时间
- **B_fid** = (Fidelity_floor, Recalib_budget)：保真度下限与重标定预算
- **B_scene / B_intent / B_exec**：继承第 60 轮

**策略映射**：若 B_sim 耗尽 ⇒ 跳过 DTIV，直接用真实探针（twin-bypass）；若 B_sync 不足 ⇒ γ_twin 下调、Cert_twin 降权；若 B_fid 低于 τ_gap ⇒ 触发孪生重标定并进入保守模式；若 B_scene 耗尽 ⇒ 通用场景先验；若 B_exec 耗尽 ⇒ 原有降级。

**定义 168（移动-孪生证书 MTC）** 三段式执行证书 MTC = (Cert_eeis, Cert_twin, Cert_epir)，并附**反事实集** CF = { (K', b', z') | DTIV_accept(K',b',z') = false }，记录「孪生明确否决过哪些候选」。
- **MTC_valid** = Cert_eeis.valid ∧ (Cert_twin.valid ∨ γ_twin < τ_gap) ∧ Cert_epir.valid
- **反事实可审计性**：CF 使「为何没选另一个 K」可被复核，把「执行合规」扩展为「决策合规」——不仅证明做过什么，还能证明**排除了什么**。

## 2. 复杂度与正确性（概览）

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| BACI | O(dof_b + dof_a) 每控制周期 | O(dof_b²) | 基座耦合阻抗误差 ≤ δ_baci |
| CRM | O(N_cand · IK) | O(N_cand) | 可及流形漏检率 ≤ 1−ε_reach |
| DTS | O(N_sync) 增量同步 | O(N_cells + N_dyn) | 同步延迟 ≤ Δt_max |
| DTIV | O(N_sim · T_horizon) | O(N_sim) | 预演误接受率 ≤ α_twin（受 γ_twin 约束） |
| MDTC | O(闭环 + 一次 DTIV) | 复用 | 移动操作成功率、ΔECE |

**正确性定理（MDTC）**：假设 A66–A70 成立：**(A66)** BACI 的基座反射阻抗在一阶线性化误差内准确；**(A67)** CRM 覆盖所有稳定接触位姿；**(A68)** DTS 同步延迟 ≤ Δt_max 且模型误差有界；**(A69)** γ_twin 的衰减/对账更新是单调可信的；**(A70)** B_twin 六维预算单调消耗。则：
1. **位姿敏感安全**：若 γ_twin ≥ τ_gap 且 K_safe ∈ K(M_reach(b))，则移动操作接触稳定裕度 ≥ ε_stab。
2. **先验证后落地**：DTIV_accept ⇒ 预测 D̂⁺ ≤ δ_twin；真实 D⁺ 与 D̂⁺ 的偏差受 1−γ_twin 约束。
3. **孪生证据有界**：γ_twin < τ_gap 时 Cert_twin 不能单独支撑决策，必须补真实探针。
4. **反事实可审计**：MTC 的 CF 集完整记录被否决候选，决策链可复核。

## 3. 本轮最大风险

**一句话**：数字孪生越逼真，越容易被过度信任——若 γ_twin 被高估、孪生里「预演通过」而现实中基座滑移扰动未被建模，系统会从第 60 轮的「先失败后回退」升级为「仿真里自信、现实里灾难」，移动性会放大这类 sim-to-real 泄漏；必须以「γ_twin 硬阈值门控 + 真实接触探针兜底 + 孪生-现实残差在线对账 + 反事实集可审计」四重护栏，确保孪生只替代昂贵的现实、永不替代现实本身。

## 2. 关键算法伪代码

### IP-161 BACI（基座-臂耦合阻抗）

```python
class BaseArmCoupledImpedance:
    def __init__(self, arm_model, base_model):
        self.arm = arm_model
        self.base = base_model
        self.coupling_gain = 1.0

    def effective_impedance(self, b, K_arm):
        J_b = self.base.jacobian(b)                # 基座->末端雅可比
        Z_base = self.base.impedance(b.v, b.a, b.slip)
        Z_refl = J_b.T @ Z_base @ J_b
        K_eff = K_arm + self.coupling_gain * Z_refl.k
        F_slip = self.base.dissipation(b.slip) @ b.v
        return K_eff, F_slip

    def stable(self, b, K_arm):
        K_eff, _ = self.effective_impedance(b, K_arm)
        omega_c = math.sqrt(max_eig(K_eff))           # 接触环路带宽近似
        return omega_c < self.base.max_bandwidth(b) and in_stable_set(K_eff)

    def condition_prior(self, scene_prior, b):
        d_mu = self.base.prior_shift(b)               # 一阶位姿偏移
        d_sigma = self.base.prior_inflation(b)        # 方差膨胀
        return Gaussian(scene_prior.mu + d_mu, scene_prior.sigma + d_sigma)
```

### IP-162 CRM（接触可及流形）

```python
def contact_reachability(base_pose, arm_model, scene, eps_stab=0.1, eps_f=0.05,
                         n_cand=64):
    candidates = sample_contact_poses(scene, base_pose, n_cand)
    manifold = []
    for x_c in candidates:
        if not arm_model.ik_feasible(x_c, base_pose):
            continue
        m_stab = stability_margin(x_c, base_pose)
        mu_f = force_manipulability(arm_model, x_c, base_pose)
        if m_stab >= eps_stab and mu_f >= eps_f:
            manifold.append(ContactPose(x_c, m_stab, mu_f))
    return ContactManifold(manifold)          # 空则触发 base_relocalize()
```

```python
    def sync(self, telemetry):
        self.G_map.integrate(telemetry.scan)          # 空间锚定
        self.O_dyn.update(telemetry.detections)
        self.R_state.update(telemetry.proprio)
        self.Theta_model.online_update(telemetry.contact)
        self.t_last = telemetry.t

    def sync_lag(self, now):
        return max(0.0, now - self.t_last)

    def simulate(self, K, base_traj, scene, horizon):
        # 一阶/降阶动力学前向仿真
        D_hat, F_peak, slip_hat = self.dynamics.rollout(
            K, base_traj, scene, self.Theta_model, horizon)
        return D_hat, F_peak, slip_hat
```

### IP-164 DTIV（孪生内验证）

```python
def twin_verify(dts, K, base_traj, scene, gamma_twin,
                delta_twin=0.05, eps_slip=0.01, tau_gap=0.8):
    D_hat, F_peak, slip_hat = dts.simulate(K, base_traj, scene, horizon=1.0)
    accept = (D_hat <= delta_twin and F_peak <= F_MAX
              and slip_hat <= eps_slip and gamma_twin >= tau_gap)

        cert = CertTwin(K, base_traj, scene, D_hat, gamma_twin,
                        sign=sign_certificate(K, base_traj, gamma_twin))
        return cert, True
    return RejectReason(D_hat, F_peak, slip_hat, gamma_twin), False
```

### IP-165 RGB（保真度/现实鸿沟对账）

```python
def twin_fidelity(dt_sync, eps_model, d_scene,
                  lam_s=0.5, lam_m=1.0, lam_z=0.4):
    return math.exp(-lam_s*dt_sync - lam_m*eps_model - lam_z*d_scene)

def twin_reality_reconcile(gamma_twin, F_hat, F_real, D_hat, D_plus,
                           eta=0.5, eta_D=0.5, gamma_min=0.2):
    resid = eta*abs(F_hat - F_real) + eta_D*abs(D_hat - D_plus)
    return min(1.0, max(gamma_min, gamma_twin * math.exp(-resid)))
```

```python
def mobile_digital_twin_closed_loop(M, scene, base_traj, intent, delta_f_req):
    M.scene_model.update_with_base(M.telem_force, M.telem_pos, M.base_est)
    b = M.base_est.state()
    prior = M.baci.condition_prior(M.scene_model.prior(scene), b)

    manifold = contact_reachability(b, M.arm, scene)

        return base_relocalize(M)                 # 位姿不可用于操作

    cert_twin, ok = twin_verify(M.twin, prior.mu, base_traj, scene, M.gamma_twin)
    K_arm = prior.mu

        K_arm = shrink_impedance(prior, b, reject_reason=cert_twin)
        cert_twin, ok = twin_verify(M.twin, K_arm, base_traj, scene, M.gamma_twin)
        tries += 1
        M.budget.ops_sim += 1

    if not ok:                                    # B_sim/twin 不可用 → 真实探针兜底
        return probe_with_real_contact(M, scene, delta_f_req)

    M, fused, D_plus, EV_exec, cert_eeis = closed_loop_exec_probe(
        M, M.current_cp, delta_f_req, M.budget)

    M.gamma_twin = twin_reality_reconcile(
        M.gamma_twin, cert_twin.F_peak, EV_exec.F_peak,

    M, fused, D_plus = xmodal_fuse_plus(M, M.current_cp.region, M.inf_latest, epir_msg)
```

```python
class TwinAwareBudget:
    def __init__(self, sync_bw=50, max_lag=0.2, sim_ops=200,
                 sim_deadline=0.1, fidelity_floor=0.8, exec_budget=None):
        self.B_sync = SyncBudget(sync_bw, max_lag)
        self.B_sim = SimBudget(sim_ops, sim_deadline)
        self.B_fid = FidelityBudget(fidelity_floor)
        self.B_scene, self.B_intent = scene_intent_budget()
        self.B_exec = exec_budget or ExecBudget()

    def twin_mode(self, gamma_twin):
        if self.B_sim.exhausted():
            return 'twin_bypass'                  # 跳过孪生，真实探针
        if self.B_sync.lag_exceeded() or gamma_twin < self.B_fid.floor:
            return 'conservative'                 # 孪生证据降权 + 重标定
        return 'normal'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| BACI | O(dof_b + dof_a) / 周期 | O(dof_b²) | 耦合阻抗误差 ≤ δ_baci |
| CRM | O(N_cand·IK) | O(N_cand) | 可及流形漏检率 ≤ 1−ε_reach |
| DTS | O(N_sync) 增量 | O(N_cells+N_dyn) | 同步延迟 ≤ Δt_max |
| DTIV | O(N_sim·T_horizon) | O(N_sim) | 预演误接受率 ≤ α_twin（受 γ_twin 门控） |
| RGB | O(1) 对账 | O(1) | γ_twin 单调且 ∈ (0,1] |
| MDTC | O(闭环 + 一次 DTIV) | 复用 | 移动操作成功率、ΔECE |

**正确性定理（MDTC）**：若 A66–A70 成立，则：
1. **位姿敏感安全**：γ_twin ≥ τ_gap ∧ K_safe ∈ K(M_reach(b)) ⇒ 接触稳定裕度 ≥ ε_stab。
2. **先验证后落地**：DTIV_accept ⇒ D̂⁺ ≤ δ_twin；真实 D⁺ 与 D̂⁺ 偏差受 (1−γ_twin) 上界约束。
3. **孪生证据有界**：γ_twin < τ_gap ⇒ Cert_twin 为弱证据，不可单独支撑 commit，必须真实探针补证。
4. **决策可审计**：MTC 的 CF 集完整记录被否决候选，MTC_valid 要求三段证书一致。
5. **预算安全**：任一 B_twin 分量耗尽 ⇒ 进入 twin_bypass / conservative / 原降级之一。

**关键引理（证明思路）**
- *引理 1（耦合有界）*：由 A66，||Z_ee^eff − Z_ee^true|| ≤ κ_b·||b̂ − b||；CRM 限制 K ∈ K(M_reach) 使接触点不越出稳定域，故稳定裕度下界成立。
- *引理 2（孪生误差传播）*：由 A68、A69，|D⁺ − D̂⁺| ≤ (1−γ_twin)·L_D，其中 L_D 为闭环 Lipschitz 常数；故 γ_twin→1 时孪生误差趋零，γ_twin < τ_gap 时误差不可忽略，须由真实探针补证。
- *定理*：引理 1 保证位姿敏感安全；引理 2 保证「先验证后落地」的误差有界与弱证据回退；MTC 构造保证可审计性；预算映射保证降级安全。
