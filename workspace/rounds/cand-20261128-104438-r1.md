### 第 8 轮灵感驱动研究记录

**灵感词**：动态避障、技能组合

**继承关系**：第 7 轮 CADVS-v7（IP-501~IP-504）以「需求-意图-一致性三角桥」把系统从「指令响应」推进到「意图推导」，EFA-v7 维持七硬门并延长软因子链。本轮回到物理执行层，聚焦「**时空技能编织**」：把「动态避障」与「技能组合」视为同一个问题的两面——**在时空占用图中为若干携带证书的技能管（certified skill tube）安排一个无碰撞的时间表**。由此把 v7 的静态空间拓扑 MCTM 升级为四维动态时空图 DSTM，把单轨迹凿升级为技能格 SCL + 组合证书代数 CSC + 时序重调度 TSR，同时**不新增硬门**（把碰撞约束并入 kc_val 的时空扩展），保持 fail-closed 边界。

**直觉与动机**：

1. **动态避障 → 从「几何绕行」到「时空调度」**。v7 的 MCTM 是静态拓扑，R61 的残余风险正是「突发障碍」。关键洞见：移动障碍物不是在平面上「挡住一条路」，而是在时空里「挖掉一块区域」——绕行等价于让技能在时间轴上推迟/提前，而非一定重画几何路径。因此动态避障的核心对象从「路径」变成「时空占用」。

2. **技能组合 → 从「单次凿刻」到「技能格上的序列」**。复杂任务（抓取→搬运→避让→放置）不是一条整体轨迹，而是若干可认证原语的组合。关键洞见：**组合的安全性可以由局部证书代数推出**——若每个技能单独满足七硬门，且相邻技能的「后置条件 ⊨ 前置条件」成立，则组合整体仍然安全。这把组合爆炸从「联合搜索轨迹」降为「在技能 DAG 上做接口校验 + 调度」。

3. **二者交汇 → 「认证技能管」是同一个对象**。一个技能实例 = 扫掠体积 V_s × 执行时间窗 [t_s, t_s+δ_s] × 证书 κ_s。动态避障要求技能管与障碍物预测管不相交；技能组合要求相邻管满足接口契约与先后约束。于是「组合 + 避障」统一为：**在时空自由区中为技能管找一个满足偏序与接口的时间表 π**。

**关键洞见**：v7 回答「如何推断需求并在证书边界内行动」；v8 回答「如何在移动障碍下组合多个已认证技能，且不破坏 fail-closed」。七硬门原样复用；本轮新增：
- IP-505 DSTM（动态时空图，障碍预测 + 不确定性管），
- IP-506 SCL（技能组合格，类型化技能 DAG + 组合算子），
- IP-507 CSC（组合安全证书代数，证书张量积），
- IP-508 TSR（时序技能重调度，时间平移/技能替换），
- IP-509 EFA-v8（软因子 η_dyn·η_comp 纳入链；碰撞约束并入 kc_val^st，硬门数量不变）

**形式化目标（增量）**：

1. **DSTM（Dynamic Space-Time Map）**：<br>
   - 障碍物预测：对每个障碍 o，给出均值轨迹 μ_o(t) 与协方差 Σ_o(t)，构成不确定性管 U_o = {x : (x-μ_o(t))ᵀΣ_o(t)⁻¹(x-μ_o(t)) ≤ χ²}；<br>
   - 鲁棒膨胀：F_o(t) = U_o(t) ⊕ B_{ρ_rob}（ρ_rob 为鲁棒裕度）；<br>
   - 风险：η_dyn = 1 - max_{s∈σ} TTC_risk(tube_s, F)，TTC_risk ∈ [0,1]。

2. **SCL（Skill Composition Lattice）**：<br>
   - 技能 s = (pre_s, post_s, [δ_s^min, δ_s^max], V_s(·), κ_s)；<br>
   - 接口匹配度 η_comp(s_i, s_{i+1}) = sat(post_{s_i} ⊨ pre_{s_{i+1}}) ∈ [0,1]；<br>
   - 组合 σ = s_1∘…∘s_n 合法当且仅当 ∀i: η_comp(s_i,s_{i+1}) ≥ τ_comp 且 DAG 偏序满足。

3. **CSC（Compositional Safety Certificate）**：<br>
   - 证书半环：κ(σ) = ⊗_{i} κ(s_i) ⊗ ⊗_{i} κ_interface(s_i,s_{i+1})，其中 ⊗ 为「合取 + 收紧」算子；<br>
   - 同态性：κ(σ_1∘σ_2) = κ(σ_1) ⊗ κ(σ_2)（可增量验证，避免重复凿刻）；<br>
   - 单调性：σ' = σ∘s_{n+1} ⇒ Exec(σ') ⊆ Exec(σ)。

4. **TSR（Temporal Skill Rescheduler）**：<br>
   - 冲突集 C = {s_i : tube_{s_i} ∩ F ≠ ∅}；<br>
   - 对 s_i 尝试时间平移 Δ ∈ [δ_i^min-δ_i, δ_i^max-δ_i]，保持几何参数不变；<br>
   - 若所有平移仍冲突，则在 SCL 中寻找替代技能 s'（post 等价、体积更小/更晚），递归修复；<br>
   - 修复失败 ⇒ fail-closed 拒绝。

5. **EFA-v8（软因子链 + 时空硬门复用）**：<br>
   - ECS_v8 = ECS_v7 · η_dyn · η_comp；<br>
   - kc_val^st：把 v6/v7 的 kc_val 从「静态位姿碰撞」扩展为「时空管碰撞」，门数量不变；<br>
   - τ_i^v8 = γ_i·τ_i^v7·η_dyn·η_comp，设计上限仍 ≤ 1.3。

6. **形式化定义**：给定目标 g、技能格 L、时空图 D：<br>
   - Σ = SCL.compose(g, depth≤D)；<br>
   - 对每个 σ ∈ Σ：π = schedule(σ)；若 ∃ 冲突则 π = TSR.repair(σ, π, D)；<br>
   - 若 TSR 失败或 κ(σ) ≠ TRUE：丢弃 σ；<br>
   - x* = argmax_{σ,π} ECS_v8(σ,π)，且逐技能通过七硬门；<br>
   - 若无可行 σ：返回 fail-closed。

**本轮最大风险**：**预测-调度耦合的时序失配**：动态避障依赖障碍物轨迹可预测、技能组合依赖时间窗可平移，但真实障碍可能是非合作、突发、遮挡后出现的；一旦预测在控制环内被证伪，组合证书会在「已认证但已过时」的时空管上给出虚假安全感，而重调度的计算延迟又可能超过碰撞时间尺度。

## 2. 关键算法骨架

### IP-505 DSTM：动态时空图

```python
@dataclass
class DynamicSpaceTimeMap:
    """DSTM：把静态 MCTM 扩展为带障碍预测的四维时空图。"""
    predictor: ObstaclePredictor
    horizon: float = 2.0
    dt: float = 0.05
    rho_rob: float = 0.05
    chi2: float = 5.99  # 95% 2D 置信

    def predict(self, detections, t_now) -> list[ObstacleTube]:
        return [self.predictor.tube(d, t_now, self.horizon, self.dt)
                for d in detections]

    def forbidden(self, tubes, x, t) -> bool:
        """鲁棒禁入判定：χ² 置信管 + 膨胀裕度。"""
        for o in tubes:
            mu, sigma = o.at(t)
            if mahalanobis(x, mu, sigma) <= self.chi2:
                return True
            if dist(x, mu) <= self.rho_rob:
                return True
        return False

    def ttc_risk(self, tube, tubes) -> float:
        """沿技能管采样，返回最早违反的归一化风险 [0,1]。"""
        worst = 0.0
        for (x, t) in tube.samples():
            if self.forbidden(tubes, x, t):
                worst = max(worst, 1.0 - (t - tube.t0) / max(tube.duration, 1e-6))
        return worst
```

### IP-506 SCL：技能组合格

```python
@dataclass
class Skill:
    name: str
    pre: Predicate
    post: Predicate
    duration: tuple[float, float]      # [δ_min, δ_max]
    volume_fn: Callable[[dict], Volume]  # 扫掠体积
    certificate: Certificate             # 七硬门证书模板

@dataclass
class SkillCompositionLattice:
    """SCL：类型化技能 DAG，接口契约校验后枚举合法组合。"""
    skills: dict[str, Skill]
    dag: nx.DiGraph
    depth_max: int = 6
    tau_comp: float = 0.8

    def interface_score(self, a: Skill, b: Skill, ctx) -> float:
        return sat_ratio(a.post, b.pre, ctx)

    def compose(self, goal, ctx) -> list[list[Skill]]:
        out = []
        for path in nx.all_simple_paths(self.dag, 'START', 'GOAL',
                                        cutoff=self.depth_max):
            seq = [self.skills[n] for n in path if n in self.skills]
            if all(self.interface_score(seq[i], seq[i+1], ctx) >= self.tau_comp
                   for i in range(len(seq)-1)):
                out.append(seq)
        return out
```

### IP-507 CSC：组合安全证书代数

```python
@dataclass
class CompositionalSafetyCertificate:
    """CSC：证书半环。组合安全 = 局部证书与接口证书的合取-收紧。"""

    def cert(self, sigma: list[Skill], schedule: dict, ctx) -> Certificate:
        k = Certificate.TRUE
        for s in sigma:
            k = k.tensor(s.certificate)
        for a, b in zip(sigma, sigma[1:]):
            k = k.tensor(Certificate.interface(a.post, b.pre, ctx))
        return k

    # 同态性：cert(σ1∘σ2) = cert(σ1) ⊗ cert(σ2)
    # 单调性：cert(σ∘s) ⪯ cert(σ)（只收紧，不放松）
```

### IP-508 TSR：时序技能重调度

```python
@dataclass
class TemporalSkillRescheduler:
    """TSR：冲突时优先时间平移（证书不变），再技能替换，失败即拒绝。"""
    dstm: DynamicSpaceTimeMap
    lattice: SkillCompositionLattice
    max_repair: int = 8

    def repair(self, sigma, schedule, tubes):
        for _ in range(self.max_repair):
            i = self._first_conflict(sigma, schedule, tubes)
            if i is None:
                return schedule, True
            s = sigma[i]
            shifted = False
            for delta in self._candidate_shifts(s, schedule):
                schedule2 = dict(schedule)
                schedule2[i] = schedule[i] + delta
                if (self._respects_precedence(sigma, schedule2)
                        and not self._collides(sigma, schedule2, tubes, i)):
                    schedule = schedule2
                    shifted = True
                    break
            if shifted:
                continue
            subst = self._substitute(s, sigma, schedule, tubes)
            if subst is None:
                return schedule, False
            sigma, schedule = subst
        return schedule, False
```

### IP-509 EFA-v8：组合凿刻

```python
@dataclass
class EvidenceForgingAssemblerV8:
    """EFA-v8：七硬门逐技能复用 + 组合层软因子 η_dyn·η_comp。"""
    v7: EvidenceForgingAssemblerV7
    dstm: DynamicSpaceTimeMap
    lattice: SkillCompositionLattice
    csc: CompositionalSafetyCertificate
    tsr: TemporalSkillRescheduler
    tau_comp: float = 0.8

    def select(self, goal, t_now, context):
        # 1. 需求门（复用 v7 预检）
        ok, _, _ = self.v7.precheck_demand(goal, t_now, context)
        if not ok:
            return self.v7.select(goal, t_now, context)

        # 2. 组合候选 + 动态时空图
        comps = self.lattice.compose(goal, context)
        tubes = self.dstm.predict(context.detections, t_now)
        best = None
        for sigma in comps:
            schedule = self._initial_schedule(sigma, t_now)
            schedule, feasible = self.tsr.repair(sigma, schedule, tubes)
            if not feasible:
                continue

            # 3. 组合证书（合取-收紧）
            if not self.csc.cert(sigma, schedule, context).is_true():
                continue

            # 4. 软因子
            eta_comp = min(
                (self.lattice.interface_score(a, b, context)
                 for a, b in zip(sigma, sigma[1:])),
                default=1.0)
            eta_dyn = 1.0 - max(
                self.dstm.ttc_risk(self._tube(s, schedule, context), tubes)
                for s in sigma)

            # 5. 逐技能凿刻：七硬门（含 kc_val^st 时空扩展）
            trajs = []
            for s in sigma:
                ok_s, x_s, _ = self.v7.forge_skill(s, schedule, context)
                if not ok_s:
                    trajs = None
                    break
                trajs.append(x_s)
            if trajs is None:
                continue

            score = self._ecs_v8(trajs, eta_dyn, eta_comp)
            if best is None or score > best[0]:
                best = (score, trajs, sigma, schedule, eta_dyn, eta_comp)

        if best is None:
            return False, None, 'COMPOSITION_FAIL_CLOSED'
        return True, best[1], 'FORGED_COMPOSED_V8'

    def _ecs_v8(self, trajs, eta_dyn, eta_comp) -> float:
        return self.v7.ecs_v7(trajs) * eta_dyn * eta_comp
```

### 集成流水线（v7 → v8）

```
离线/慢时域：
  DSTM 预测器训练（障碍轨迹分布 → 不确定性管校准）
  SCL 技能库构建（原语 + pre/post + 证书模板）
  CSC 证书半环验证（单元测试：同态性、单调性）
  TSR 参数标定（时间窗、替换规则、max_repair）

在线准入（亚秒级）：
  DSTM.predict(detections) ──▶ F(t)
  SCL.compose(goal) ──▶ {σ}
  for σ: TSR.repair ──▶ 可行 π；CSC.cert ──▶ κ(σ)
         η_comp, η_dyn
         逐技能 EFA-v7 七硬门（kc_val^st）
  argmax ECS_v8 ──▶ 组合轨迹

在线控制环（目标 < 1.2 ms）：
  DSTM 预测异步 10 Hz 更新；TSR 只在冲突时触发（平均 < 0.3 ms）
  七硬门逐技能复用 v6/v7 缓存；kc_val^st 增量检查
```

## 4. 正确性论证（增量更新）

### 定理 13（组合证书单调性）

**陈述**：设每个技能 s_i 单独通过七硬门（κ(s_i)=TRUE），且所有接口 η_comp ≥ τ_comp，则任意合法组合 σ 满足 Exec(σ) ⊆ ⋂_i Exec(s_i) ⊆ Exec(CADVS-v7)；且追加技能只收紧：Exec(σ∘s) ⊆ Exec(σ)。

**证明**：七硬门对单个技能是合取判定；组合执行是各技能安全集的序列交（每个技能终点须满足下一技能 pre）。证书张量积 ⊗ 定义为合取，故 κ(σ)=TRUE 当且仅当所有局部证书为 TRUE。追加 s 增加一个合取项，交集只减不增。

### 定理 14（时序平移证书不变性）

**陈述**：若七硬门只依赖技能几何参数与相对时序、不依赖绝对墙钟时间，则对技能管做纯时间平移 Δ（几何参数不变）保持 κ(s_i) 不变；因此 TSR 的平移修复不会破坏硬门，只能改变可行性。

**证明**：门函数 g_i(θ, V) 与 t 无关 ⇒ g_i(θ, V) 在平移下不变 ⇒ κ(s_i) 不变。TSR 只改 π(i)，不改 θ、V。

**注意**：该定理依赖「门时间不变」假设；若某门含时变稳定约束（如负载随时间变化），需在诚实声明中标注为条件成立。

### 定理 15（fail-closed 完备性）

**陈述**：若所有组合 σ 均被 TSR 判为不可行、或 CSC 判为 κ(σ)≠TRUE、或任一技能未过七硬门，则 EFA-v8 返回失败，绝不执行未认证组合。

**证明**：select 仅在 feasible ∧ κ(σ)=TRUE ∧ 全部 trajs 非空时进入候选；best 为空即返回 False。TSR 失败路径直接 continue，不回退到未认证轨迹。

### 诚实声明

- DSTM 依赖障碍物可预测；非合作/遮挡后突现障碍会使不确定性管失效；
- 证书半环可能过度保守，导致组合集为空（可用性下降）；
- 「门时间不变」是定理 14 的前提，含时约束需单独审计；
- TSR 的时间平移可能引入等待/抖动，影响任务时长与用户体感；
- 技能库缺失时 SCL 无法组合，退化为 v7 单技能；
- 组合深度与技能数带来枚举成本，depth≤6 是工程折中。

## 5. 实验设计与验证计划（仿真 → 实机）

### 5.1 实验设计（MuJoCo 3.x + MJX）

- **平台**：UR10e（6DOF）+ 移动底盘（2DOF）+ 动态障碍（行人 / 移动箱 / 另一机械臂）+ 深度相机
- **场景**：
  - (a) 横穿行人：技能管与行人预测管冲突 → TSR 时间平移等待
  - (b) 遮挡后突现：不确定性管失配 → kc_val^st 触发重调度
  - (c) 狭窄通道会车：组合深度 2，两障碍反向移动
  - (d) 技能替换：抓取被阻断 → 替换为推挤（post 等价、体积更小）
  - (e) 组合深度 2~6：抓取→搬运→避让→放置
- **对照**：v7-full、v8-full、消融 A21（无 DSTM）、A22（无 TSR）、A23（无 CSC）、A24（仅单技能）、A25（η_dyn 恒 1）
- **指标**：动态避让成功率、组合任务成功率、平均任务时长、控制环 P99、未认证执行次数

## 7. 本轮最大风险（最终确认）

**一句话**：**预测-调度耦合的时序失配**：动态避障依赖障碍物轨迹可预测、技能组合依赖时间窗可平移，但真实障碍可能是非合作、突发、遮挡后出现的；一旦预测在控制环内被证伪，组合证书会在「已认证但已过时」的时空管上给出虚假安全感，而重调度的计算延迟又可能超过碰撞时间尺度。
