# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 7 轮；本轮灵感：「语音识别」×「技能学习」）

> 第 60 轮把「场景→阻抗先验」「意图→执行约束」「EV-exec→证据」串成了认知驱动的场景落地闭环 SSM×CIEC×EPIR×SERC×PCE++++。但**三个深层局限**在本轮暴露：
> 1. **CIEC 的确定性假设**：ϕ_intent→constraint(I) 是一张确定性查表，前提是 ASR 已经给出唯一正确文本。真实语音识别是**流式、n-best、带置信度与时间跨度**的网格；同音、口音、噪声会让「轻触/轻推」「停/顶」混淆。把识别不确定性直接压平成执行约束，等于在风险最高的地方假装确定。
> 2. **技能零积累**：SSM 只提供先验，CIEC 只查表，EV-exec 主要用做实时刻对账后即被丢弃。系统从未把「同一场景×同一意图下的成功阻抗轨迹」固化为**可复用技能**，也从未估计「我有多会做这件事」。
> 3. **学习与安全的二律背反**：第 60 轮的四重护栏是「不学习」的护栏。一旦让系统从证据中学习，就立刻出现**灾难性遗忘、技能漂移、错误证据污染技能库、学歪的危险技能被误触发**四类新风险。会学习但不安全，比不会学习更危险。

## 0. 直觉与动机

**灵感 1（语音识别 → 流式意图格与延迟承诺 SILD）**
直觉：语音识别器输出的从来不是「一句话」，而是随时间滚动的 n-best 网格（lattice）：每个候选句有后验概率、起止时间、稳定性。成熟系统会**延迟决策**——不说「close the...」就急着提交，而是等声学证据足够、或语法约束收敛后再定。映射到执行层：**意图不应在第一个音节就锁死 ERTC**，而应维护意图格 L_t，并按照**风险不对称**的代价决定何时提交。对「停」「危险」这类安全意图，极低置信度也要立即提交（宁可误停）；对「慢一点」「轻触」这类普通意图，等到后验稳定或用户说完再提交（宁可多等 200ms）；超过 deadline 则取 MAP 并附加随不确定性增大的安全裕度 guard。

**灵感 2（语音识别的语言模型/语法 → 执行语法受限解码 EGC）**
直觉：ASR 用发音词典与语言模型把声学后验约束到合法词序列，而不是事后过滤。执行层同样需要一个**可执行语法 G_exec**：由技能库前置/后置条件与已认证安全动作集生成，只包含「物理上可执行且经过安全认证」的意图-参数组合。在解码时用 FST 组合直接抑制非法或危险假设，而不是先执行再回退。关键洞见：**「不说错」比「听对」更重要——让错误意图在解码阶段就无法生成执行动作**。

**灵感 3（技能学习 → 阻抗技能库 ISL）**
直觉：人学技能不是每次从零摸索，而是把「场景×意图→动作参数」固化为可复用原语（类似 DMP / options），并保留一个「熟练度」后验。第 60 轮的 EV-exec 恰好是天然的技能学习数据：每条成功/失败的阻抗轨迹都是对某个技能参数的一次带标签观测。**技能 = 前置条件 + 阻抗策略 + 参数域 + 能力后验**。

**灵感 4（技能学习的遗忘问题 → 证据分层重放与巩固 ESC）**
直觉：学了「湿滑桌面」不能忘掉「楼梯」。技能库更新必须对抗灾难性遗忘：按「场景×意图」**分层重放**历史 EV-exec，保证每个技能都有覆盖；用 EWC 把重要参数钉住；用 CUSUM/Page-Hinkley 检测能力后验的系统性漂移。关键洞见：**重放不是随机采样，而是按技能覆盖度做分层配额**，否则高频场景会淹没低频危险场景。

**灵感 5（合流 → 语音-技能共演闭环 SSCE）**
直觉：用户的澄清（「不是那个，是左边那个」）既是**意图纠正**，也是**技能学习的弱标签**。当意图格不自信时，主动问一个信息增益最大的澄清问题；答案既更新语言模型/发音自适应，也作为 `(音频, 正确意图)` 样本进入技能与外挂语言模型的训练缓冲。于是语音识别与技能库**共同进化**，而不是各自为政。

**灵感 6（预算 → PCE+++++ 语音-技能预算）**
直觉：beam search 宽度、意图格深度、重放/更新算力都是可耗尽的实时资源。把 B_cog 再拓展为 B_ss=(B_asr, B_lat, B_skill, B_exec)：B_asr 耗尽→退化为关键词唤醒+贪心解码并更频繁澄清；B_lat 耗尽→取 MAP + guard；B_skill 耗尽→冻结技能库、只用已认证技能；B_exec 耗尽→沿用第 60 轮降级。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（流式意图格与延迟承诺 SILD）** 意图格 L_t = {ℓ_j = (I_j, p_j(t), [a_j, b_j], h_j)}，其中 I_j ∈ I 为候选意图，p_j(t) 为到时刻 t 的后验，[a_j,b_j] 为语音时间跨度，h_j 为声学/语言证据向量。
- **流式后验更新**：p_j(t) ∝ p(A_{0:t} | I_j) · P_lm(I_j)，逐帧贝叶斯更新并归一化。
- **稳定性**：ρ_j(t) = p_j(t) − p_j(t−Δ)。仅当 p_j ≥ τ_commit(I_j) 且 ρ_j ≥ −ε_stable 才视为稳定。
- **风险不对称代价**：C(I→I*) 表示把真实意图 I* 误判为 I 的代价；安全意图满足 C(普通→危险) ≪ C(危险→普通)，即漏报危险远比误报危险昂贵。
- **承诺策略** π_commit：τ* = inf{ t : ∃j, p_j(t) ≥ τ_commit(I_j) ∧ ρ_j ≥ −ε_stable } ∪ {τ_deadline}；其中安全意图的门限 τ_commit^safe ≪ τ_commit^normal，且不等稳定性。
- **后验风险与最优停止**：R(t) = Σ_j (1−p_j(t))·C(I_j, I*)。若继续等待一步的期望风险下降 E[R(t)]−E[R(t+Δ)] ≤ λ_lat·Δ（等待成本），则立即提交；到 deadline 则取 MAP 并令 guard 随 (1−p_MAP) 单调增大。
- **提交动作**：C_intent = ϕ(I_{j*}) 且附加 guard = g(1−p_{j*})；guard 直接收缩 K_safe 与 F_max，使「越不确定越保守」。

**定义 162（执行语法受限解码 EGC）** 执行语法 G_exec = (Σ_I, N, R, S) 由技能库前置/后置条件与安全动作集生成，语言 L(G_exec) ⊆ I×Θ 为所有「可执行且已认证」的意图-参数串。
- **约束解码**：Î = argmax_{I ∈ L(G_exec)} P(A | I)·P_lm(I)，实现为声学格与语法 FST 的组合（beam 搜索）。
- **拒绝保证**：若可行集为空（OOV 或越界参数），返回 ⊥ 并触发澄清/拒绝，**绝不**退化为最近邻执行。
- **无幻觉执行不变式**：∀ 实际下发的执行意图 I，恒有 I ∈ L(G_exec)。

**定义 163（阻抗技能库 ISL）** 技能 s = (pre_s, post_s, π_s, Θ_s, c_s, ν_s)。其中 pre_s 为场景/意图/力位前置条件；post_s 为期望达成；π_s：(z, I) → K(θ)，θ ∈ Θ_s 为参数化阻抗轨迹（可含 DMP 权重）；c_s ~ Beta(α_s, β_s) 为能力后验；ν_s 为使用计数。
- **检索**：Retrieve(z,I) = {s : pre_s(z,I)=true}，返回 argmax_s E[c_s]·feasible_s(z)。
- **参数学习**：给定 EV-exec 轨迹，θ ← weighted_least_squares(θ, traj, weights)（或 GP 后验）。
- **能力学习**：成功→α_s+1，失败→β_s+1；能力均值 E[c_s]=α/(α+β)，下置信界 LCB_δ(c_s)=E[c_s]−z_δ·√(αβ/((α+β)²(α+β+1)))。

**定义 164（证据驱动技能巩固 ESC）** 分层重放缓冲 D = ∪_{z,I} D_{z,I}，各层用 reservoir 采样保持覆盖；巩固目标
```
L(θ) = L_new(θ) + λ_ewc · Σ_i F_i (θ_i − θ*_i)²
```
其中 F_i 为 Fisher 信息（参数重要性），θ* 为旧技能最优参数。
- **漂移检测**：对能力残差 e_t = c_s^obs − E[c_s] 运行 CUSUM：g_t = max(0, g_{t−1} + e_t − k)，g_t > h 触发告警。
- **遗忘度**：F_t = max_s (c_s^old − c_s^new)⁺。定理（见 §3）给出 F_t 的界。

**定义 165（语音-技能共演闭环 SSCE）** 算子 SSCE(M, audio_stream, z, δ_f_req)：
```
① ASR : L_t ← streaming_decode(audio_{0:t})
② EGC : L_t^exec ← L_t ⊓ L(G_exec)
③ SILD: (I*, guard) ← π_commit(L_t^exec, risk_cost)
        若 ⊥ 且 deadline 未到 → ④；否则跳 ⑤
④ AQC : q* ← argmax_q [IG(I;Y|q) − λ_q·cost(q)]；用答案更新 L_t
⑤ ISL : s* ← Retrieve(z, I*)；若无技能 → bootstrap_from_prior(z,I*)
⑥ Exec: ERTC.lock(ϕ(I*), guard)；K ← π_{s*}(z, δ_f_req)；执行
⑦ EV  : EV-exec ← build_exec_evidence(telemetry)；ESC.add(z, I*, EV-exec)
⑧ Learn: ISL.update(s*, EV-exec, success)；LM.adapt(corrections)
⑨ Gate : SGP.try_promote(s*)；返回 (I*, s*, K, EV-exec, L_t.status)
```

**定义 166（安全门控技能晋升 SGP）** 候选技能 s* 进入运行时的条件：
- **能力门**：LCB_δ(c_s) ≥ τ_skill；
- **安全门**：K(Θ_s) ⊆ K_safe(z)（参数域整体落在安全集内，而非仅均值点）；
- **证书门**：Cert_exec ≠ ∅ 且 J_exec 通过；
- **漂移门**：ESC 漂移未告警。
满足后先进入 **shadow 模式**（只记录不实际执行/低权限执行），累计 n_shadow 次且 shadow 成功率 ≥ τ_shadow 才晋升 production；全程保留一键回滚到旧版本。

**定义 167（语音-技能预算 PCE+++++）** B_ss = (B_asr, B_lat, B_skill, B_exec)：
- B_asr = (beam_width, nbest, asr_latency_budget)
- B_lat = (lattice_depth, commit_deadline)
- B_skill = (replay_ops, update_ops, storage)
- B_exec = (WCET_slack, Bus_bw_slack, Thermal_slack, Prio_headroom)（沿用）
```
voi_ss(π) = VOI_meta_pessimistic(π) − cost_ss(π)
cost_ss = λ_asr·ASR_cost + λ_lat·Latency_cost + λ_skill·Learn_cost + cost_exec
```

降级：B_asr 耗尽→贪心/关键词唤醒+更多澄清；B_lat 耗尽→MAP+guard；B_skill 耗尽→冻结技能库、仅用已认证技能；B_exec 耗尽→第 60 轮降级。

**定义 168（主动澄清查询 AQC）** 问题集 Q，答案随机变量 Y。
- **信息增益**：IG(I;Y|q) = H(I) − E_{Y|q}[H(I|Y,q)]。
- **最优问题**：q* = argmax_{q∈Q} [IG(I;Y|q) − λ_q·cost(q)]，约束 τ_q + τ_answer ≤ τ_deadline。
- **双重用途**：澄清答案 (A, I_correct) 既修正意图格，也作为弱标签写入 ESC 的重放缓冲与语言模型自适应，实现「问一次、学一次」。

### IP-161 SILD（流式意图格与延迟承诺）

```python
class StreamingIntentLattice:
    def __init__(self, deadline=1.5, eps_stable=0.02,
                 safety_intents=('danger', 'stop', 'halt')):
        self.hyp = {}                 # intent -> [logp, a, b]
        self.deadline = deadline
        self.eps_stable = eps_stable
        self.safety = set(safety_intents)
        self.t0 = None
        self.prev = {}

    def update(self, nbest, t):
        if self.t0 is None:
            self.t0 = t
        for intent, p, a, b in nbest:
            self.hyp[intent] = [p, a, b]
        s = sum(max(h[0], 1e-12) for h in self.hyp.values())
        self.hyp = {k: [v[0] / s, v[1], v[2]] for k, v in self.hyp.items()}

    def commit(self, t, risk_cost, lambda_lat):
        if not self.hyp:
            return None, 1.0
        best = max(self.hyp, key=lambda k: self.hyp[k][0])
        p_best = self.hyp[best][0]
        stable = p_best >= self.prev.get(best, 1.0) - self.eps_stable
        self.prev[best] = p_best

        tau = 0.30 if best in self.safety else 0.75
        if best in self.safety and p_best >= tau:
            return best, 1.0 - p_best          # 安全意图：低门限立即提交
        if p_best >= tau and stable:
            risk_now = sum((1 - h[0]) * risk_cost(k) for k, h in self.hyp.items())
            risk_safe = sum((1 - h[0]) * risk_cost(best) for k, h in self.hyp.items())
            if risk_now - risk_safe <= lambda_lat * (t - self.t0):
                return best, 1.0 - p_best
        if t - self.t0 >= self.deadline:
            return best, 1.0 - p_best          # MAP + 随不确定性增大的 guard
        return None, 1.0 - p_best
```

```python
class ExecutionGrammarDecoder:
    def __init__(self, grammar, lm):
        self.fst = compile_fst(grammar)   # 由技能前置/后置条件编译
```

```python
class ImpedanceSkillLibrary:
    def __init__(self, tau_skill=0.8):
        self.skills = {}
        self.tau_skill = tau_skill

        cand = [s for s in self.skills.values() if s.pre(scene, intent)]
```

### IP-164 ESC（分层重放与巩固）

```python
class SkillConsolidator:
    def __init__(self, m_min=20, lambda_ewc=1e3, k=0.05, h=0.4):
        self.replay = defaultdict(lambda: deque(maxlen=m_min * 4))
        self.m_min, self.lambda_ewc = m_min, lambda_ewc
        self.k, self.h = k, h
        self.fisher, self.cusum = {}, defaultdict(float)

    def add(self, scene, intent, ev):
        self.replay[(scene, intent)].append(ev)

    def consolidate(self, skill, new_batch):
        batch = list(new_batch)
        for (z, i), buf in self.replay.items():     # 分层配额，低频场景不被淹没
            quota = max(1, self.m_min // max(1, len(self.replay)))
            batch += sample(buf, min(quota, len(buf)))
        loss = task_loss(skill, batch)
        loss += self.lambda_ewc * ewc_penalty(skill, self.fisher)
        return loss

    def detect_drift(self, sid, residual):
        self.cusum[sid] = max(0.0, self.cusum[sid] + residual - self.k)
        return self.cusum[sid] > self.h
```

### IP-165 SSCE（语音-技能共演闭环）

```python
def speech_skill_coevolution(M, audio_stream, scene, delta_f_req):
    M.lattice.reset()
    for frame in audio_stream:
        M.lattice.update(M.asr.nbest(frame), frame.t)
        M.lattice.hyp = M.egc.filter(M.lattice.hyp)
        intent, guard = M.lattice.commit(frame.t, M.risk_cost, M.lambda_lat)
        if intent is not None:
            break
    if intent is None:
        q = M.aqc.best_question(M.lattice)
        if q is None or q.cost + q.answer_latency > M.lattice.deadline:
            return M, None, 'DEFER_SAFE'
        intent, guard = M.aqc.ask(q)

    skill = M.isl.retrieve(scene, intent)
    if skill is None or skill.mean_competence() < M.isl.tau_skill:
        skill = M.isl.bootstrap_from_prior(scene, intent)

    M.ertc.lock(phi(intent), guard)
    K = skill.policy(scene, delta_f_req)
    M, ev = execute_and_build_evidence(K)
    M.esc.add(scene, intent, ev)
    M.isl.update(skill.id, ev, ev.success)
    if M.isl.competence_dropped(skill.id):
        M.esc.consolidate(skill, [ev])
    M.lm.adapt(M.aqc.corrections())
    M.sgp.try_promote(skill)
    return M, ev, M.lattice.status
```

### IP-166 SGP（安全门控技能晋升）

```python
def lcb(alpha, beta, z=1.64):
    n = alpha + beta
    return alpha / n - z * math.sqrt(alpha * beta / (n * n * (n + 1)))

class SafetyGatedPromoter:
    def try_promote(self, s):
        gates = (lcb(s.alpha, s.beta) >= self.tau_skill
                 and s.domain_contained_in(self.k_safe)
                 and s.cert is not None
                 and not self.drift_alert(s.id))
        if not gates:
            return 'REJECT_OR_HOLD'
        if s.state == 'candidate':
            s.state = 'shadow'                     # 只记录/低权限，可回滚
        elif s.shadow_episodes >= self.n_shadow and s.shadow_success >= self.tau_shadow:
            s.state = 'production'
            s.rollback_point = s.snapshot()
        return s.state
```

### IP-168 AQC（主动澄清查询）

```python
class ActiveQueryClarifier:
    def best_question(self, lattice):
        H = entropy(lattice.posterior())
        best, best_voi = None, -math.inf
        for q in self.questions:
            ig = H
            for y, py in q.answer_distribution(lattice):
                ig -= py * entropy(q.posterior_given(lattice, y))
            voi = ig - self.lambda_q * q.cost
            if voi > best_voi:
                best, best_voi = q, voi
        return best if best_voi > self.min_voi else None

    def ask(self, q):
        y = q.render_and_wait()                    # 用户回答
        self.corrections.append((q.audio_span, y.intent))
        return y.intent, y.guard
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |

**(A66)** 意图格后验已校准（ECE ≤ ε_cal）；**(A67)** G_exec 的安全完备性：合法执行意图 ⊆ L(G_exec)，且危险动作未认证则不入语法；**(A68)** 技能能力 Beta 后验可辨识，EV-exec 标签噪声有界；**(A69)** 分层重放对每个 (z,I) 覆盖 ≥ m_min；**(A70)** EWC 的 Fisher 估计有界且 λ_ewc ≥ λ₀；**(A71)** SGP 门控保证 K(Θ_s)⊆K_safe 且证书有效；**(A72)** B_ss 单调消耗；**(A73)** AQC 信息增益可估且问题时延满足 deadline。

1. **承诺风险界**：R(τ*) ≤ R₀ + λ_lat·Δt + O(ε_cal)；且对任意安全意图，当 p_danger ≥ τ_safe 时必被提交，**不存在「危险意图因过度等待而被错过」的情形**。

### IP-161 SILD（流式意图格与延迟承诺）

```python
class StreamingIntentLattice:
    def __init__(self, deadline=1.5, eps_stable=0.02,
                 safety_intents=('danger', 'stop', 'halt')):
        self.hyp, self.prev = {}, {}
        self.deadline, self.eps_stable = deadline, eps_stable
        self.safety, self.t0 = set(safety_intents), None

    def update(self, nbest, t):
        if self.t0 is None:
            self.t0 = t
        for intent, p, a, b in nbest:
            self.hyp[intent] = [p, a, b]
        s = sum(max(h[0], 1e-12) for h in self.hyp.values())
        self.hyp = {k: [v[0] / s, v[1], v[2]] for k, v in self.hyp.items()}

    def commit(self, t, risk_cost, lambda_lat):
        if not self.hyp:
            return None, 1.0
        best = max(self.hyp, key=lambda k: self.hyp[k][0])
        p_best = self.hyp[best][0]
        stable = p_best >= self.prev.get(best, 1.0) - self.eps_stable
        self.prev[best] = p_best
        tau = 0.30 if best in self.safety else 0.75
        if best in self.safety and p_best >= tau:
            return best, 1.0 - p_best
        if p_best >= tau and stable:
            risk_now = sum((1 - h[0]) * risk_cost(k) for k, h in self.hyp.items())
            risk_best = sum((1 - h[0]) * risk_cost(best) for k, h in self.hyp.items())
            if risk_now - risk_best <= lambda_lat * (t - self.t0):
                return best, 1.0 - p_best
        if t - self.t0 >= self.deadline:
            return best, 1.0 - p_best
        return None, 1.0 - p_best
```

### IP-164 ESC（分层重放与巩固）

```python
class SkillConsolidator:
    def __init__(self, m_min=20, lambda_ewc=1e3, k=0.05, h=0.4):
        self.replay = defaultdict(lambda: deque(maxlen=m_min * 4))
        self.m_min, self.lambda_ewc = m_min, lambda_ewc
        self.k, self.h = k, h
        self.fisher, self.cusum = {}, defaultdict(float)

    def add(self, scene, intent, ev):
        self.replay[(scene, intent)].append(ev)

    def consolidate(self, skill, new_batch):
        batch = list(new_batch)
        for buf in self.replay.values():
            quota = max(1, self.m_min // max(1, len(self.replay)))
            batch += sample(buf, min(quota, len(buf)))
        return task_loss(skill, batch) + self.lambda_ewc * ewc_penalty(skill, self.fisher)

    def detect_drift(self, sid, residual):
        self.cusum[sid] = max(0.0, self.cusum[sid] + residual - self.k)
        return self.cusum[sid] > self.h
```

### IP-165 SSCE（语音-技能共演闭环）

```python
def speech_skill_coevolution(M, audio_stream, scene, delta_f_req):
    M.lattice.reset()
    intent = None
    for frame in audio_stream:
        M.lattice.update(M.asr.nbest(frame), frame.t)
        M.lattice.hyp = M.egc.filter(M.lattice.hyp)
        intent, guard = M.lattice.commit(frame.t, M.risk_cost, M.lambda_lat)
        if intent is not None:
            break
    if intent is None:
        q = M.aqc.best_question(M.lattice)
        if q is None or q.cost + q.answer_latency > M.lattice.deadline:
            return M, None, 'DEFER_SAFE'
        intent, guard = M.aqc.ask(q)

    skill = M.isl.retrieve(scene, intent)
    if skill is None or skill.mean_competence() < M.isl.tau_skill:
        skill = M.isl.bootstrap_from_prior(scene, intent)

    M.ertc.lock(phi(intent), guard)
    K = skill.policy(scene, delta_f_req)
    M, ev = execute_and_build_evidence(K)
    M.esc.add(scene, intent, ev)
    M.isl.update(skill.id, ev, ev.success)
    if M.isl.competence_dropped(skill.id):
        M.esc.consolidate(skill, [ev])
    M.lm.adapt(M.aqc.corrections())
    M.sgp.try_promote(skill)
    return M, ev, M.lattice.status
```

### IP-166 SGP（安全门控技能晋升）

```python
def lcb(alpha, beta, z=1.64):
    n = alpha + beta
    return alpha / n - z * math.sqrt(alpha * beta / (n * n * (n + 1)))

class SafetyGatedPromoter:
    def try_promote(self, s):
        gates = (lcb(s.alpha, s.beta) >= self.tau_skill
                 and s.domain_contained_in(self.k_safe)
                 and s.cert is not None
                 and not self.drift_alert(s.id))
        if not gates:
            return 'REJECT_OR_HOLD'
        if s.state == 'candidate':
            s.state = 'shadow'
        elif s.shadow_episodes >= self.n_shadow and s.shadow_success >= self.tau_shadow:
            s.state = 'production'
            s.rollback_point = s.snapshot()
        return s.state
```

### IP-168 AQC（主动澄清查询）

```python
class ActiveQueryClarifier:
    def best_question(self, lattice):
        H = entropy(lattice.posterior())
        best, best_voi = None, -math.inf
        for q in self.questions:
            ig = H
            for y, py in q.answer_distribution(lattice):
                ig -= py * entropy(q.posterior_given(lattice, y))
            voi = ig - self.lambda_q * q.cost
            if voi > best_voi:
                best, best_voi = q, voi
        return best if best_voi > self.min_voi else None

    def ask(self, q):
        y = q.render_and_wait()
        self.corrections.append((q.audio_span, y.intent))   # 纠错 + 弱标签
        return y.intent, y.guard
```
