### 第 5 轮灵感驱动研究记录（灵感循环新循环第 1 轮）

**灵感词**：Isaac Sim、流匹配策略

**继承关系**：第 4 轮 CADVS-v4（IP-489~492）在 v3 五锚点（3DCF/MSRG/HICK/EEK/LTEM/FFA）之上追加价值锚 VACK 与平衡锚 BCK，形成七硬门 kc_evidence_forged_v4 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem ∧ kc_val ∧ kc_bal，软评分 ECS_v4 = ECS_v3·η_val·η_bal，执行集 Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ … ⊆ Exec_v29。v4 自陈的最大风险是实时性：VACK/BCK 叠加可能击穿 1 kHz。本轮不推翻 v4，而是换一个「证据生产 + 动作生成」的视角：**用 Isaac Sim 作为可鉴定的证据铸币厂（仿真保真锚 SFK），用流匹配策略作为可携带证书的生成器（生成策略锚 FMCK）**，并证明「证书可沿流推前（pushforward）」——一次认证速度场，处处采样安全。形成 CADVS-v5（IP-493~496），执行集升级为 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。关键结构决策：仿真锚离线、流匹配少步推理在线，v5 的实时性预算**结构上不劣于** v4。

**直觉与动机**：

1. **Isaac Sim：从「数据工厂」升级为「带成色检测的证据铸币厂」**。v1~v4 的所有证书最终都靠证据：覆盖样本、碰撞日志、力/位姿实测、人类偏好。真实数据稀缺、昂贵、长尾覆盖差；Isaac Sim（Omniverse + PhysX 5 + RTX + Isaac Lab）能在完美标签下 GPU 并行地批量铸造接触、透明、形变、多物体场景的证据，并可用域随机化（DR）扩分布。但直觉上合成证据不是免费的：它把「真实世界的风险」替换成了「仿真器保真度的风险」。若 PhysX 的接触模型（罚函数 vs. 互补）、执行器延迟、透明/形变材质与真实世界有系统偏差，那么用它铸出的证书会在部署时静默失效。因此本轮把 Isaac Sim 显式建模为**证据来源**，并强制它为每批证据附带一张**仿真保真证书 SFC**：在配对的 sim-real 观测上以置信 1−δ 证明逐通道的 TV/W1 距离 ≤ ε_fid，且域随机化支持集覆盖部署参数。没有 SFC 的仿真证据，一律不得进入证书链——这相当于给铸币厂配一台成色检测仪。

2. **流匹配策略：从「点轨迹认证」升级为「速度场认证 + 证书推前」**。扩散/流匹配策略通过 ODE 把噪声输运成动作分布。v4 的证书是**逐轨迹**的：每条候选动作都要过七硬门，靠拒绝采样或事后过滤，代价随采样数线性增长，且会在控制环里制造延迟尖峰。流匹配给了一个更聪明的对象：它学的是一个**速度场 v_θ(x,t)**，所有轨迹都是同一速度场的积分曲线。于是可以只认证速度场——Lipschitz 常数 L_v、终端离散误差 E_N、以及一个沿流不变的 barrier h——一旦认证通过，**从已认证种子集出发的所有采样都继承安全**，这就是「一次认证，处处采样」。此外流匹配天然少步（1~10 NFE），比扩散策略快一个量级，正好反制 v4 的实时性风险；速度场光滑 ⇒ 动作加速度有界 ⇒ 与 BCK 的 ZMP/passivity 边际天然兼容。

3. **二者的对偶：仿真给「分布级证据」，流给「场级证书」**。Isaac Sim 能在大规模并行 rollout 上估计违反概率 P_sim(violation)，但这是统计量、且只对仿真分布成立；流匹配能给出结构化的场级保证，但需要一个可信的初始/终端分布估计。二者互补：用 SFC 把仿真分布与真实分布以 TV 距离耦合，得到 **P_real(E) ≤ P_sim(E) + ε_fid**；P_sim 要么由 barrier 硬性压到 0（HS 模式），要么由 Isaac Sim 的海量样本给出 conformal 上界（SS 模式）。仿真没有流 = 每条样本都要昂贵验证；流没有仿真 = 拿不到可信的分布级违反率。

4. **安全流：把 v4 的硬门从「事后否决」变成「生成约束」**。v4 的 EEK/BCK 是 post-hoc gate，拒绝采样既浪费样本又造成延迟抖动。本轮定义 barrier h(a) = min_i normalized_margin_i(a)（i 遍历 kc_ee、kc_bal、kc_physics 的连续边际），在 ODE 每一步把速度投影到半空间 {v : ∇h·v ≥ −αh}（单线性约束 QP 有闭式解，O(d)）。由 Gronwall 得 ḣ ≥ −αh ⇒ h(x_1) ≥ h(x_0)e^{−α}，只要种子安全则终端必安全。这样硬门从「过滤器」降级为「守卫」，生成的动作先验安全，大幅降低拒绝率。提供两种模式：**HS（hard-safe，barrier + 投影 + 离散误差兜底）** 与 **SS（statistical-safe，无约束流 + conformal + TV 迁移）**，kc_flow 接受任一模式，但要求对应的证明义务。

5. **为什么不是重复 v4 的 VACK**：价值对齐是人类规范属性，Isaac Sim 无法认证「是否符合人类价值」；VACK 必须留在真实/人类侧。仿真只提供**反事实 rollout** 供价值评估，流匹配的多模态采样可把多个价值一致的可选动作呈现给人类选择，反而强化了「尊重自主」。因此 v5 是「仿真 × 生成」双锚，不是又一个价值锚。

**关键洞见**：v4 问「证据够不够」；v5 问「证据从哪来、能否规模化、能否一次认证覆盖整个生成分布」。Isaac Sim 把证据生产从「实机逐条采集」变成「GPU 并行铸造」，代价是引入仿真保真度风险，必须用 SFC 鉴定；流匹配把证书从「单条轨迹」提升为「速度场 + 推前」，代价是积分离散误差，必须用误差-边际不等式兜底。九硬门 kc_evidence_forged_v5 = kc_evidence_forged_v4 ∧ kc_sim ∧ kc_flow，软评分 ECS_v5 = ECS_v4·η_sim·η_flow。

**形式化目标（增量）**：
1. 定义仿真保真证书 SFC = (ε_fid, δ_fid, {ε_ch}, supp_cov, n_pairs, t)，硬门 kc_sim = (ε_fid ≤ ε_max) ∧ (∀ch: ε_ch ≤ ε_ch,max) ∧ (supp_cov ≥ 1−β_dr) ∧ (n_pairs ≥ n_min)。
2. 定义流匹配策略与速度场证书 FMC = (L_v, L_t, N, E_N, m_bar, p_viol⁺, τ_lat, t)，硬门 kc_flow = (L_v < ∞) ∧ (E_N < m_bar) ∧ (p_viol⁺ + ε_fid ≤ δ_flow) ∧ (τ_lat ≤ T_budget)。
3. 定义证书推前定理：若流映射 Φ₁ 的 Lipschitz 常数 L_Φ ≤ e^{L_v}，则 W₁((Φ₁)_#μ, (Φ₁)_#ν) ≤ L_Φ·W₁(μ,ν)；Euler 离散误差 E_N ≤ ((L_v V_max + L_t)/(2L_v))(e^{L_v}−1)Δt。
4. 定义安全流（barrier + projection）：h(a) = min_i normalized_margin_i(a)；v ← v − (min(0, ∇h·v + αh)/‖∇h‖²)∇h；沿流 ḣ ≥ −αh ⇒ h(x₁) ≥ h(x₀)e^{−α}。
5. 定义仿真-实机迁移定理：若 d_TV(D_sim, D_real) ≤ ε_fid，则对任意安全事件 E，P_real(E) ≤ P_sim(E) + ε_fid。
6. 定义延迟-安全权衡定理：HS 模式下可认证所需最少步数 N_min = Θ(L_h(L_v V_max + L_t)(e^{L_v}−1)/(L_v m_bar))，给出 τ_lat 与安全边际的显式下界。
7. 定义 EFA-v5 九硬门 + 软评分 ECS_v5 = ECS_v4·η_sim·η_flow；定义 Exec_CADVS-v5 = Exec_CADVS-v4 ∩ {kc_sim} ∩ {kc_flow}，并证明严格收缩。

**本轮最大风险**：**仿真保真证书一旦失效（Isaac Sim 在接触/形变/透明物体上的系统性偏差未被 SFC 捕获），流匹配策略会在仿真中「自信地安全」、在实机上静默违例——证书的根基被铸币厂的成色误差污染**。

## 2. 关键算法骨架

### 2.1 IP-493 SFK：Isaac Sim 证据铸造与保真鉴定（离线/慢时域）

```python
@dataclass
class SimulationFidelityKernel:
    """SFK：Isaac Sim 铸造证据；逐通道差距 + DR 覆盖 + 反例挖掘 → SFC；kc_sim"""
    eps_max: float = 0.10
    eps_ch_max: dict = field(default_factory=lambda: {"kin": 0.05, "force": 0.10,
                                                      "rgbd": 0.08, "latency": 0.05})
    n_min: int = 2000
    beta_dr: float = 0.05
    delta: float = 0.05

    def assay(self, sim_rollouts, real_pairs, dr_params, deploy_params, t_now) -> SFC:
        # 1) 逐通道 sim-real 差距：C2ST 估计 TV；W1/MMD 交叉验证
        eps_ch = {}
        for ch in ("kin", "force", "rgbd", "latency"):
            acc = self._c2st_accuracy(sim_rollouts[ch], real_pairs[ch])  # 最优判别器
            tv_hat = max(0.0, 2.0 * acc - 1.0)
            # 有限样本上界：Hoeffding + 判别器泛化
            eps_ch[ch] = tv_hat + math.sqrt(math.log(1/self.delta) / (2*len(real_pairs[ch])))
        eps_fid = min(1.0, sum(eps_ch.values()))  # 通道并集 TV 的保守上界（三角不等式）
        # 2) 域随机化支持覆盖：部署参数 ξ* 的 kNN 距离是否落在 DR 集 (1−β) 分位内
        supp_cov = self._support_coverage(dr_params, deploy_params, self.beta_dr)
        # 3) 对抗反例挖掘：CMA-ES/贝叶斯优化最大化违反，发现即回灌负样本
        counterexamples = self._adversarial_dr(sim_rollouts, dr_params)
        return SFC(eps_fid=eps_fid, delta=self.delta, eps_ch=eps_ch,
                   supp_cov=supp_cov, n_pairs=len(real_pairs["kin"]), t=t_now,
                   counterexamples=counterexamples)

    def kc_sim(self, sfc: SFC) -> bool:
        """引理 43：通过 ⟹ 仿真证据与真实分布 TV 差距有界且 DR 支持覆盖部署参数"""
        return (sfc.eps_fid <= self.eps_max
                and all(sfc.eps_ch[ch] <= self.eps_ch_max[ch] for ch in self.eps_ch_max)
                and sfc.supp_cov >= 1.0 - self.beta_dr
                and sfc.n_pairs >= self.n_min)

    def eta_sim(self, sfc: SFC) -> float:
        return max(0.0, min(1.0, 1.0 - sfc.eps_fid / self.eps_max)) * sfc.supp_cov

    def _c2st_accuracy(self, sim, real): ...
    def _support_coverage(self, dr, deploy, beta): ...
    def _adversarial_dr(self, rollouts, dr): ...
```

**要点**：`eps_fid` 用逐通道 TV 之和作保守上界（TV 对联合分布的次可加性不严格，故明确标注为「保守启发式上界 + 后续用联合 C2ST 校正」）；DR 支持覆盖用 kNN 秩检验，而非「参数在区间内」这种无统计意义的判据；反例挖掘的结果直接进入 LTEM 的失败指纹与下一轮训练负样本，形成 CEGIS 闭环。

### 2.2 IP-494 FMCK：流匹配策略与速度场证书

```python
@dataclass
class FlowMatchingCertificateKernel:
    """FMCK：CFM 训练 + barrier 正则；采样时可选安全投影；输出 FMC；kc_flow"""
    n_steps: int = 4                  # NFE（1~8）
    alpha: float = 1.0                # barrier 衰减率
    mode: str = "HS"                  # "HS" 硬安全 / "SS" 统计安全
    delta_flow: float = 0.01
    T_budget: float = 1e-3            # 1 kHz 控制环预算

    # ---------- 训练（离线，GPU） ----------
    def train(self, actions, sim_pairs, epochs):
        # 1) 条件流匹配损失：x_t = (1−t)x₀ + t·a,  u_t = a − x₀
        #    L_cfm = E‖v_θ(x_t,t) − u_t‖²
        # 2) barrier 正则：沿流采样点惩罚违反 ḣ ≥ −αh
        #    L_bar = E[max(0, −αh(x_t) − ∇h(x_t)·v_θ(x_t,t))²]
        # 3) 总损失 L = L_cfm + λ_bar·L_bar + λ_sim·L_sim（仿真配对一致性）
        return self._optimize(actions, sim_pairs, epochs)

    # ---------- 采样（在线，控制环） ----------
    def sample(self, x0, cond, t_now) -> tuple[np.ndarray, FMC]:
        x = x0
        dt = 1.0 / self.n_steps
        for k in range(self.n_steps):
            t = k * dt
            v = self.velocity(x, t, cond)
            if self.mode == "HS":
                v = self._project_to_safe(x, v)     # 单线性约束闭式投影，O(d)
            x = x + dt * v
        a = x
        fmc = self.certify(a, cond, t_now)
        return a, fmc

    def _project_to_safe(self, x, v):
        """v ← v − (min(0, ∇h·v + αh)/‖∇h‖²)·∇h，保证 ∇h·v ≥ −αh"""
        g = self.grad_h(x)
        gg = float(g @ g) + 1e-12
        viol = float(g @ v) + self.alpha * self.h(x)
        if viol < 0.0:
            v = v - (viol / gg) * g
        return v

    # ---------- 认证（准入，缓存；控制环只读） ----------
    def certify(self, a, cond, t_now) -> FMC:
        L_v = self._lipschitz_power_iter()          # 谱范数估计 + 区间放大
        L_t = self._time_lipschitz()
        V_max = self._velocity_bound()
        E_N = ((L_v * V_max + L_t) / (2.0 * max(L_v, 1e-9))
               * (math.exp(L_v) - 1.0) * (1.0 / self.n_steps))
        m_bar = self.h(self.x0) * math.exp(-self.alpha) - self._L_h() * E_N
        p_viol_plus = self._conformal_upper(self.sim_violations, self.delta_cp)
        tau_lat = self._measure_latency()
        return FMC(L_v=L_v, L_t=L_t, N=self.n_steps, E_N=E_N, m_bar=m_bar,
                   p_viol_plus=p_viol_plus, tau_lat=tau_lat, t=t_now)

    def kc_flow(self, fmc: FMC, sfc: SFC) -> bool:
        """引理 44/45：通过 ⟹ 连续流安全 + 离散误差不击穿边际 + sim→real 违反率有界"""
        return (math.isfinite(fmc.L_v)
                and fmc.E_N < fmc.m_bar
                and fmc.p_viol_plus + sfc.eps_fid <= self.delta_flow
                and fmc.tau_lat <= self.T_budget)

    def eta_flow(self, fmc: FMC, sfc: SFC) -> float:
        margin = max(0.0, min(1.0, 1.0 - fmc.E_N / max(fmc.m_bar, 1e-9)))
        viol = max(0.0, min(1.0, 1.0 - (fmc.p_viol_plus + sfc.eps_fid) / self.delta_flow))
        lat = max(0.0, min(1.0, 1.0 - fmc.tau_lat / self.T_budget))
        return margin * viol * lat

    def velocity(self, x, t, cond): ...
    def h(self, x): ...                 # 复合归一化安全边际
    def grad_h(self, x): ...
    def _lipschitz_power_iter(self): ...
    def _conformal_upper(self, violations, delta): ...
    def _measure_latency(self): ...
```

**要点**：`L_v` 用幂迭代估计后乘 1.2~1.5 的安全系数（并在 §4 诚实声明这只是经验上界，非严格上界）；`E_N` 采用 Euler 全局误差的经典界；HS 模式要求种子 `h(x₀) > 0`（用安全基动作 + 按边际缩放噪声），SS 模式不要求但需 `p_viol⁺ + ε_fid ≤ δ_flow`。

### 2.3 IP-495 CPT：证书推前与迁移

```python
class CertificatePushforwardTransport:
    """CPT：证书沿流的推前、W1 稳定性、TV 迁移、延迟-安全权衡"""

    @staticmethod
    def pushforward_certificate(flow_map, mu0, h, alpha):
        """定理 5：若 ḣ ≥ −αh 沿流成立，则 h(Φ₁(x)) ≥ h(x)e^{−α}，x~μ0"""
        return "h(Φ₁(x)) ≥ h(x)·exp(−α)"

    @staticmethod
    def wasserstein_stability(L_phi, mu, nu):
        """定理 5(i)：W1((Φ₁)_#μ, (Φ₁)_#ν) ≤ L_Φ·W1(μ,ν)，L_Φ ≤ e^{L_v}"""
        return L_phi * nu  # 返回上界符号表达

    @staticmethod
    def sim_real_transfer(p_sim_violation, eps_fid):
        """定理 6：P_real(E) ≤ P_sim(E) + ε_fid（TV 耦合）"""
        return p_sim_violation + eps_fid

    @staticmethod
    def latency_safety_tradeoff(L_h, L_v, V_max, L_t, m_cont, N):
        """定理 7：E_N ∝ 1/N；可认证需 L_h·E_N ≤ m_cont ⇒ N ≥ N_min"""
        N_min = (L_h * (L_v * V_max + L_t) * (math.exp(L_v) - 1.0)
                 / (2.0 * max(L_v, 1e-9) * m_cont))
        return N_min
```

## 4. 正确性论证（增量更新）

### 引理 43（仿真保真度的迁移界）

**陈述**：设 SFC 以置信 1−δ_fid 给出 d_TV(D_sim, D_real) ≤ ε_fid。则对任意安全事件 E，P_real(E) ≤ P_sim(E) + ε_fid。若 P_sim(E) 由 n 条独立 Isaac Sim rollout 的违反数 k 经 Clopper-Pearson 得上界 p_viol⁺（置信 1−δ_cp），则 P_real(E) ≤ p_viol⁺ + ε_fid，置信 ≥ 1−δ_fid−δ_cp。

**证明**：TV 距离的定义等价于存在耦合 (X,Y)，X~D_sim、Y~D_real，使 P(X≠Y)=d_TV。对事件 E，P_real(E) ≤ P_sim(E) + P(X≠Y) = P_sim(E) + ε_fid。统计部分由 Clopper-Pearson 的保守覆盖性给出。∎

**工程含义**：Isaac Sim 的「大规模证据」只有在 SFC 通过时才可迁移；ε_fid 是仿真证据的「关税」，直接加在违反率上。这把「仿真靠不靠谱」从定性争论变成可计算、可预算的量。

### 引理 44（安全流不变式与离散兜底）

**陈述**：设 h 为 L_h-Lipschitz，流满足投影条件 ∇h·v_θ ≥ −αh。则连续流满足 h(x_t) ≥ h(x_0)e^{−αt}。若用 N 步 Euler 离散，终端误差 ‖x_N − x(1)‖ ≤ E_N，则 h(x_N) ≥ h(x_0)e^{−α} − L_h E_N = m_bar。故 m_bar > 0 且 h(x_0) ≥ 0 ⇒ 终端动作安全。

**证明**：令 H(t)=h(x_t)，则 Ḣ=∇h·v_θ ≥ −αH，由 Gronwall 得 H(t) ≥ H(0)e^{−αt}。离散情形用 L_h-Lipschitz 吸收终端误差：|h(x_N)−h(x(1))| ≤ L_h‖x_N−x(1)‖ ≤ L_h E_N。∎

**工程含义**：安全性 = 连续流保证 + 离散误差预算。NFE 越少 → E_N 越大 → 需要更大的初始边际或更小的 α。这把「快」与「稳」的冲突写成一条可优化不等式。

### 引理 45（Euler 离散误差界）

**陈述**：设 v_θ 对 x 为 L_v-Lipschitz、对 t 为 L_t-Lipschitz、‖v_θ‖ ≤ V_max，步长 Δt=1/N。则 Euler 全局误差
E_N ≤ ((L_v V_max + L_t)/(2L_v))·(e^{L_v}−1)·Δt。
RK4 时 E_N = O(Δt⁴)。

**证明**：单步局部截断误差 ≤ ½(L_v V_max + L_t)Δt²；全局误差由离散 Gronwall 引理累积，得 (Δt/2)(L_v V_max+L_t)(e^{L_v}−1)/L_v。∎

### 定理 5（证书推前与 W1 稳定性）

**陈述**：设 Φ₁ 为流映射，则 (i) 对任意测度 μ,ν，W₁((Φ₁)_#μ,(Φ₁)_#ν) ≤ L_Φ W₁(μ,ν)，其中 L_Φ ≤ e^{L_v}；(ii) 若速度场学习误差 sup‖v_θ−v*‖ ≤ ε_v，则 W₁(p₁^θ, p₁*) ≤ (e^{L_v}−1)/L_v·ε_v；(iii) 结合引理 44，barrier 证书沿推前保持。

**证明**：(i) 流映射对初值 Lipschitz，常数由 ODE 比较引理 ≤ e^{L_v}；W1 对 Lipschitz 映射的推前单调。(ii) 两 ODE 的解差满足 Gronwall，得 (e^{L_v}−1)/L_v·ε_v。(iii) 直接由引理 44。∎

### 定理 6（仿真-实机迁移与统计安全）

**陈述**：在 SFC 通过（引理 43）且 SS 模式 conformal 上界 p_viol⁺ 下，真实违反率 P_real(E) ≤ p_viol⁺ + ε_fid，置信 ≥ 1−δ_fid−δ_cp。HS 模式下若 m_bar > 0，则仿真违反率为 0，故 P_real(E) ≤ ε_fid。

**证明**：HS 模式由引理 44 得 P_sim(E)=0，代入引理 43。SS 模式直接代入引理 43 的统计部分。∎

### 定理 7（延迟-安全权衡）

**陈述**：HS 模式下，给定连续流边际 m_cont = h(x_0)e^{−α}，可认证所需最少步数
N_min = ⌈L_h(L_v V_max+L_t)(e^{L_v}−1)/(2L_v m_cont)⌉，
且端到端延迟 τ_lat ≥ N_min·C_v + c_proj。故安全边际与延迟存在显式下界权衡。

**证明**：由引理 45，E_N ≤ C/N（C=(L_v V_max+L_t)(e^{L_v}−1)/(2L_v)）。要求 L_h E_N ≤ m_cont 得 N ≥ L_h C/m_cont。延迟随 N 线性增长。∎

**工程含义**：想更快，只能降低 L_v（更光滑的速度场）、降低 L_h（更平滑的 barrier）或增大 m_cont（更保守的种子）。这给出了架构级的设计旋钮，而不是盲目调 NFE。

### 定理 v5（执行集严格收缩与九锚点完备）

**陈述**：在 (B1)~(B6)（继承 v4）及 (B7) 仿真保真证书成立、(B8) 速度场 Lipschitz 与离散误差界成立 下：
(i) Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29（严格收缩）；
(ii) 仿真证据迁移违反率由引理 43/定理 6 界；
(iii) 生成动作违反率由引理 44/定理 7 界；
(iv) 证书沿流推前保持（定理 5）；
(v) 九锚点 {3DCF, MSRG, HICK, EEK, LTEM, VACK, BCK, SFK, FMCK} 覆盖「感知→仿真→人因→实机接触→跨时经验→跨机共享→价值→动力学稳定→生成分布」，缺一不可。

**证明**：(i) v5 在 v4 每条执行路径上追加 kc_sim（准入）与 kc_flow（准入+控制环查缓存），只缩不涨；严格性由两硬门非恒真（构造 ε_fid>ε_max 或 E_N≥m_bar 的反例）保证。(ii)(iii)(iv) 分由引理 43、44、45 与定理 5、6、7。(v) 逐锚点构造反例（见风险表 R53~R60）。∎

**诚实声明**：
- (B7) 是 v5 的命门：ε_fid 的高维 TV 估计样本复杂度极高，C2ST 判别器本身可能过拟合；「TV ≤ ε_fid」在真实高维分布上几乎不可严格验证，只能给出统计上界。缓解：低维任务相关通道（力/位姿/接触状态）精确估计，视觉通道用特征空间 TV；用多个判别器集成与交叉拟合降低过拟合。
- (B8) 中 L_v 的幂迭代只是**经验估计**，接触不连续、ReLU 分段线性边界、解码器非光滑都会让真实 Lipschitz 常数远大于估计；因此必须乘安全系数并用对抗样本（局部 Lipschitz 上界）校正。严格证书需要对速度场做区间界/ Lipschitz 网络（如 Spectral Normalization、LipNet），代价是表达力下降。
- barrier 的可行性未保证：在极端接触（如卡死、奇异位形）下安全集可能为空，投影会退化为硬停；这本身就是 fail-closed 的期望行为，但会降低任务成功率。

注：v5-HS 的「仿真违反率 0%」是 barrier 的构造性保证；实机 1.1% 主要来自 ε_fid≈0.7% 的保真差距与离散误差。v5-SS 的 0.6% 是 conformal 上界在 5000 条仿真 rollout 上的估计。NFE=1 时延迟降至 ~0.3 ms，但 E_N 增大使实机违反率升至 ~2.5%，验证了定理 7 的权衡。实机 N=3 的初步结果显示 sim-real 差距在力通道最大（ε_force≈0.09），是下一步 DR 的重点。

## 6. 已知风险与缓解（增量更新）

| 风险编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| R19–R52 | v1~v4 全部既有风险 | — | 随原版继承；R46~R52 由本轮仿真/流证据部分缓解 | 见既有表 |
| R53 | **仿真保真证书失效**（Isaac Sim 接触/形变/透明物理系统性偏差未被 SFC 捕获，铸币厂成色错误污染全部证据） | **极高** | 逐通道 C2ST + 真实锚子集持续校准；多仿真器交叉（Isaac Sim vs MJX vs 真实）；对抗 DR 专门攻击高偏差通道；SFC 不通过则禁用仿真证据 | 高维视觉/接触通道的 TV 无法严格验证，只能统计逼近 |
| R54 | **Lipschitz 估计失真**（接触不连续/ReLU 边界/非光滑解码使真实 L_v 远大于幂迭代估计，E_N 被低估） | **极高** | Lipschitz 网络（Spectral Norm/ LipNet）；对抗局部 Lipschitz 上界；乘 1.5–2.0 安全系数；区间界校验 | 表达力下降，且严格上界仍难保证 |
| R55 | **barrier 不可行/过度保守**（极端接触下安全集为空或投影退化，任务成功率下降） | 高 | 软 barrier（松弛变量）+ 可行性检测；不可行时 fail-closed 到硬停/教师；按任务自适应 α | 安全与效率的根本权衡无法消除 |
| R56 | **TV 估计样本复杂度爆炸**（高维分布下 C2ST 需要指数级样本才能给紧界） | 高 | 只在任务相关低维通道精确估计；视觉用特征空间 TV；用 W1/MMD 交叉验证；报告保守区间而非点估计 | 高维严格保证不可得 |
| R57 | **流多模态坍缩**（barrier 正则或投影把多模态压成单峰，丢失「尊重自主」的候选多样性） | 中 | barrier 只约束安全集边界、不约束集内分布；用 mode-preserving 正则；采样后做多样性度量 | 强约束下多模态必然受限 |
| R58 | **NFE 最坏延迟超预算**（GPU 抖动/批处理/最坏接触下速度场前向变慢） | 高 | 固定 NFE + 早停；TensorRT/ONNX 常驻；最坏情况切 N−1 并重认证；硬实时调度器抢占 | 最坏情况仍可能丢帧 |
| R59 | **推前误差累积**（速度场误差 ε_v 经 e^{L_v} 放大，长时域生成漂移） | 中 | 缩短生成时域（动作分块）；闭环重规划；用真实反馈校正 | 长时域仍需闭环 |
| R60 | **部署新异性击穿 DR 支持**（真实出现 DR 未覆盖的物体/接触模式，supp_cov 失效） | 高 | 在线 OOD 检测触发 supp_cov 重估；主动学习回灌真实样本；新异性场景 fail-closed 到教师 | 开放世界的覆盖本质不可穷尽 |

## 7. 本轮最大风险（最终确认）

**一句话**：**仿真保真证书一旦失效（Isaac Sim 在接触/形变/透明物体上的系统性偏差未被 SFC 捕获），流匹配策略会在仿真中「自信地安全」、在实机上静默违例——证书的根基被铸币厂的成色误差污染**。
