# 第 44 轮（新循环第 4 轮） · Map-Cert × Cert-SLAM：把「地图」提升为证书根，让安全证书与主动建图双向闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形只保边际覆盖 + 多用户契约求交为空」，但它仍压着一个被全链路默认、比 H1/H2 更深的单点假设：**(H3) 地图与位姿是可信、静态、带标量误差的已知量**。v20 里所有 `C_global`、`I_u^α`、租约衰减 `λ = L_m·v_max`、几何证书，全部建立在「世界模型 M 已知且准确」之上——而真实系统里 M 是被在线估计的隐变量：会漂移、会因回环闭合**跳变**、会在退化环境下**过度自信**、会因场景变化**过期**。本轮灵感词「SLAM」精确命中 H3：SLAM 不是预处理模块，而是**证书链的根**，根一旦错，叶子再漂亮也是静默不 sound。第二个灵感词「创新点」提醒我们：真正的创新点不是「把 SLAM 接进来」，而是一个**双向闭环**——安全证书消费标定过的地图信念，主动 SLAM 消费安全认证过的风险预算。据此把四层架构 v8 升级为 v9：在地图信念层（MCE）+ 撤销/血缘层（RLR）+ 探索预算层（CSA）。

## 0. 直觉与动机

**灵感 1（地图即根 → 证书必须对「地图信念」而非「地图点估计」鲁棒）**：直觉上，如果机器人「以为」墙在两米外，证书推导得再严密也没用——安全证书的可靠性不可能超过它所依赖地图的可靠性。因此把地图从 `M̂` 单点估计提升为**地图信念** `B_M = (M̂, U_M)`，`U_M(x)` 是按区域标定的不确定度场。定义证书 `c` 为 **M-valid**：对 `∀M ∈ B_M` 相应安全谓词都成立。直接后果是几何证书的 margin 必须**扣掉地图误差**：`m = m_geo − L_g·ε_M(x)`，其中 `L_g` 是碰撞谓词对地图位移的 Lipschitz 常数。这把「地图误差」从一句免责声明变成一个可被审计的减法项。

**灵感 2（回环闭合 → 证书的「世界线」与原子撤销）**：直觉上，回环闭合相当于把整张地图「瞬移」一次；此前签发的证书引用的是旧坐标系，若不处理，就是**静默用错世界**。因此给每张证书绑定 `(map_version, anchor lineage, anchor set)`：回环闭合生成 `v+1` 与变换证书 `T_LC`，凡是锚点落在被 `T_LC` 影响子图、且**无法重锚定证明**的证书一律撤销。撤销是保守方向（宁可多撤）→ 对 soundness 免费；真正的成本是可用性。用 epoch/seqlock 让「版本切换」对监控器**原子可见**，承接 v20 的撕裂读防护。

**灵感 3（退化与动态 → 不确定度的时变、地图租约）**：直觉上，长走廊、隧道、玻璃幕墙、空旷仓库会让 SLAM 退化，协方差严重低估；场景里还有移动物体，地图会「过期」。所以 `U_M` 不是常数：**退化检测**（信息矩阵最小特征值、残差、有效特征数）触发 `ε_M` 膨胀；每个地图区域带**地图租约**寿命，过期区域不确定度随时间上升。这恰好复用 v20 的租约衰减机制，只是把「证书边际时效」扩展到「地图时效」。

**灵感 4（主动 SLAM → 探索是「用风险买信息」的可预算投资）**：直觉上，探索未知区域能降低未来不确定度、从而长期提升安全 margin，但当下有风险。关键不是二选一，而是把探索**纳入证书框架**：只有探索动作的安全证书 sound、**预期风险 ≤ 探索预算 ρ_exp**、且**信息增益下界 IG_lo 足够大**时才允许执行。探索预算由「未来 margin 增益」偿还，形式化为约束 MDP。这样探索从安全的对立面，变成一笔可审计、可回滚的安全投资。

**灵感 5（多智能体合并 → 地图孤岛与变换证书）**：直觉上，多机 SLAM 合并地图时若相对变换不可信，合并会**制造虚假一致性**，比不合并更危险。规则很硬：没有**变换证书**的两张地图只能作为「地图孤岛」并存，禁止签发跨岛几何证书；有证书才允许合并，且合并后 lineage 取并、版本递增、所有跨岛旧证书撤销。

**耦合升级**：PCE/CCR/ICV（v20）之上加三件：**MCE（地图证书引擎）**把用户之外的世界也变成带证书的一等公民；**RLR（撤销-血缘运行时）**保证回环闭合/地图合并时证书更新原子且可线性化审计；**CSA（认证主动 SLAM）**把探索风险预算化。四层架构由此从 v8 的「个性化 + 并发证书」升级为 v9 的「地图信念 + 撤销血缘 + 探索预算」闭环。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（地图信念与地图符合性证书 MCert）**：地图信念 `B_M = (M̂, U_M)`，`M̂` 为地图/位姿估计，`U_M: X → R_{≥0}` 为按区域标定的不确定度上界（含位姿与结构误差）。地图符合性证书 `MCert = (ε_M, δ_M, lineage, version, T_anchor)`，`δ_M` 为标定覆盖率。**M-valid 定义**：几何证书 `c` 对 `B_M` 有效，当且仅当 `∀ M ∈ B_M`，`c` 的安全谓词成立；其充分条件为 `m_geo − L_g·ε_M(x) ≥ θ`。**命题**：若 `ε_M` 是真实地图偏差的上界、`L_g` 为谓词对地图位移的 Lipschitz 常数，则 `m_geo − L_g·ε_M` 是真实 margin 的下界（sound）。**推论**：把地图误差写成减法项，使「地图不确定性」与「感知不确定性」在证书里可加、可审计，而不是混在一个魔数里。

**定义 45（退化感知的不确定度膨胀与 margin 传播）**：设观测信息矩阵 `JᵀJ` 的最小特征值 `λ_min`，退化阈值 `λ*`，膨胀系数 `β`。**有效不确定度** `ε_M^eff(x) = ε_M(x)·(1 + β·max(0, λ* − λ_min)/λ*)`；**传播 margin** `m = m_geo − L_g·ε_M^eff(x)`。**命题（退化健全性）**：若退化导致的后验误差增长被膨胀因子覆盖，则 `m` 仍是真实 margin 下界；反之，若检测不到退化而沿用原 `ε_M`，则存在静默过估（这正是本轮要防的失效模式）。**注**：膨胀只在退化时上调、恢复时按滞回缓慢下调，避免 margin 抖动引发控制抖振。

**定义 46（回环闭合的证书撤销与血缘）**：每张证书 `c` 携带 `(v_c, L_c, A_c)`：地图版本、血缘集合、锚点集合。回环闭合产生 `(v+1, T_LC, MCert_LC)`。**撤销规则**：若存在锚点 `a ∈ A_c` 落在 `T_LC` 影响的子图内，且 `reanchor(c)` 无法给出新证书，则撤销 `c`。**可用性判据**：`c` 可用当且仅当 `v_c = v_current` 且 `anchor_drift(c) ≤ ε_M`。**命题（撤销健全性）**：只做「撤销」或「以新证书重锚定」，不做无证明的原地保留，则在任意回环闭合序列后所有幸存证书仍 sound。**命题（原子切换）**：版本切换经 epoch/seqlock 发布，监控器前后 epoch 一致才接受 ⟹ 不存在跨版本撕裂读（复用定义 40/41 的快照论证）。

**定义 47（认证主动 SLAM 与探索预算）**：动作集合含探索类 `a_exp`。**认证信息增益下界** `IG_lo(a_exp)`：由后验熵下降的保守估计给出（下界而非均值）。**允许条件**：`safety_cert(a_exp) sound ∧ risk(a_exp) ≤ ρ_exp ∧ IG_lo(a_exp) ≥ g_min`。**探索预算动力学**：`ρ_exp ← clip(ρ_exp − risk(a) + η·realized_IG, 0, ρ_max)`，即「用未来信息增益偿还当下风险」。目标为约束 MDP：`max E[Σ IG] s.t. 累积风险 ≤ ρ_max`。**注**：探索预算与 v20 的信任预算 `τ_u` 分账（风险预算 ≠ 个性化信任预算），避免个性化偷偷挪用探索额度。

**定义 48（地图合并证书与地图孤岛）**：智能体 `i,j` 的相对变换证书 `T_ij = (T̂, ε_T)` 当且仅当重观测一致性检验通过才签发。**合并规则**：`M_i ⊕ M_j` 仅在 `T_ij` 有效时允许；否则保持**地图孤岛**，并**禁止跨岛几何证书**。合并后 `lineage = join(L_i, L_j)`、版本递增、所有依赖旧跨岛关系的证书撤销。**命题**：无变换证书的合并是不 sound 的（可构造虚假一致性反例），因此孤岛是「不可用但不失 sound」的安全兜底。

**定义 49（地图租约与动态场景时效）**：每个地图区域 `r` 携带地图租约 `ℓ_M(r) = (t_r, λ_M)`。**时效不确定度** `ε_time(r,t) = λ_M·(t − t_r)`；**总有效不确定度** `ε_M^tot = ε_M^geo + ε_M^eff + ε_time`。当 `ε_M^tot > ε*` 时区域标记 `stale`，引用它的证书必须撤销或触发重观测。**命题**：动态变化检测（变化检测/自由空间翻转）可提前令区域 `stale`，故地图租约给出的是一个可静态审计的、随时间单调的 sound 上界。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 MAP-CONFORMANCE-ENGINE（地图证书引擎 MCE）
1. **地图信念表示**：`B_M=(M̂,U_M)`，按区域维护几何误差界与位姿漂移界；支持占据/ESDF/特征多表示的统一不确定度索引。
2. **MCert 签发与校验**：对每块地图区域签发 `(ε_M, δ_M, lineage, version, T_anchor)`；几何证书查询时自动做 `m_geo − L_g·ε_M` 扣减。
3. **退化检测与膨胀**：监控信息矩阵 `λ_min`、残差、有效特征数；退化时按定义 45 膨胀 `ε_M^eff`，恢复时滞回下调。
4. **地图租约与 stale 标记**：按定义 49 维护区域寿命；变化检测提前失效；与 IP-56 租约表共用单调时钟。

### 2.2 IP-61 REVOCATION-LINEAGE-RUNTIME（撤销-血缘运行时 RLR）
1. **证书-地图血缘图**：记录每张证书依赖的地图版本/锚点/父证书；支持正向（撤销传播）与反向（重锚定）遍历。
2. **回环闭合原子撤销**：`T_LC` 到达即遍历受影响子图，撤销或重锚定；epoch 切换对监控器原子可见，撤销期间默认「拒绝使用」而非「猜测可用」。
3. **撤销日志与线性一致性审计**：撤销/重锚事件带单调序号，供 IP-59 做线性一致性检查（无丢失撤销、无撤销后复用）。
4. **多智能体合并/孤岛管理**：仅在 `T_ij` 证书有效时合并；否则登记为孤岛并阻断跨岛证书；合并后血缘取并、版本递增。

### 2.3 IP-62 CERTIFIED-ACTIVE-SLAM（认证主动 SLAM CSA）
1. **认证信息增益**：对候选探索动作计算 `IG_lo`（保守下界），并给出安全证书；两者缺一不允许执行。
2. **探索预算 CMDP**：按定义 47 维护 `ρ_exp`；探索动作走闸门 `sound ∧ risk ≤ ρ_exp ∧ IG_lo ≥ g_min`。
3. **探索收益回灌**：把实际 `realized_IG` 与后续 margin 增益回灌 IP-50 课程与 IP-55 CKB，形成「探索—建图—证书—课程」闭环。
4. **失败即冻结**：探索触发安全否决或预算耗尽时，冻结地图探索但保持安全监控与已知区域运行，绝不因「想建图」而放宽安全界。

## 5. 本轮最大风险

**一句话**：整条证书链现在以「标定过的地图信念 `B_M`」为根，而 SLAM 的协方差/误差界恰恰是**出了名的过度自信**（回环闭合的相关误差、退化下的低估、动态场景的污染）——一旦 `ε_M` 被低估，所有下游证书会**静默不 sound 且无法从链内自证**，因此必须引入**外部真值/冗余交叉验证**来标定根节点，并默认回退到「冻结测绘地图 + 大 margin」这条根可信的底线。

# 第 44 轮产物 · 创新点清单 v21：Map-Cert × Cert-SLAM（MCE × RLR × CSA）× 地图信念-撤销血缘-探索预算闭环（四层架构 v9）

> 承接第 43 轮产物 v20。本轮**增量插入** IP-60/61/62，并升级 IP-45/47/49/50/51/54/55/56/57/58/59；不推倒任何既有层级。核心是把 v20 的「个性化 + 并发证书」飞轮，补上一直被默认可信的根：**地图**。v21 同时满足 **地图安全（对信念鲁棒）**、**撤销安全（回环原子撤销）** 与 **探索安全（风险预算化）** 的可验证闭环。**本轮创新点主张**：不是「把 SLAM 接入安全链」，而是**证书与建图的双向闭环**——安全证书消费标定过的地图信念，主动 SLAM 消费安全认证过的风险预算。

## 1. 符号体系（增量：定义 44–49 符号）

| 符号 | 含义 | 定义 |
|---|---|---|
| `B_M=(M̂,U_M)` | 地图信念 | 地图/位姿估计 + 按区域标定的不确定度上界 |
| `MCert=(ε_M,δ_M,lineage,version,T_anchor)` | 地图符合性证书 | 误差界、覆盖率、血缘、版本、锚点变换 |
| `L_g` | 几何 Lipschitz 常数 | 碰撞谓词对地图位移的敏感度上界 |
| `ε_M^eff=ε_M·(1+β·max(0,λ*−λ_min)/λ*)` | 退化膨胀后不确定度 | 信息矩阵最小特征值驱动 |
| `ε_time(r,t)=λ_M·(t−t_r)` | 地图时效不确定度 | 区域年老导致的误差增长 |
| `ε_M^tot=ε_M^geo+ε_M^eff+ε_time` | 总地图不确定度 | 三源可加 |
| `(v_c,L_c,A_c)` | 证书血缘 | 地图版本、血缘集合、锚点集合 |
| `T_LC` | 回环变换证书 | 回环闭合产生的相对变换及其误差 |
| `T_ij=(T̂,ε_T)` | 地图合并变换证书 | 智能体 `i,j` 相对变换及误差 |
| `ρ_exp` | 探索风险预算 | `ρ_exp ← clip(ρ_exp−risk+η·realized_IG,0,ρ_max)` |
| `IG_lo(a_exp)` | 认证信息增益下界 | 后验熵下降的保守下界 |
| `g_min` | 信息增益门限 | 低于此生探索不值得冒风险 |

## 2. 关键算法（伪代码）

### IP-60 MCE：地图信念、MCert、退化膨胀与租约
```
def build_map_belief(points, poses, residuals):
    U_M = calibrate_regional_error(points, poses, residuals)  # 区域误差上界
    return Belief(Mhat=optimize(points, poses), U=U_M)

def sign_map_cert(B_M, region, version, lineage):
    eps = B_M.U[region]
    delta = coverage_ratio(B_M, region)                        # 标定覆盖率
    return MCert(eps=eps, delta=delta, lineage=lineage,
                 version=version, T_anchor=B_M.T[region])

def degeneracy_inflate(eps, info_mat, lam_star, beta):
    lam_min = min_eigenvalue(info_mat)
    factor = 1.0 + beta * max(0.0, lam_star - lam_min) / lam_star
    return eps * factor                                        # 定义 45

def geometric_margin(m_geo, L_g, eps_base, info_mat, eps_time):
    eps_eff = degeneracy_inflate(eps_base, info_mat, LAM_STAR, BETA)
    eps_tot = eps_eff + eps_time
    return m_geo - L_g * eps_tot                              # M-valid 的充分条件

def map_lease_uncertainty(region, t):
    return region.lambda_M * (t - region.t_last_observed)     # 定义 49

def region_is_stale(region, t, eps_star):
    return (region.eps_geo + map_lease_uncertainty(region, t)) > eps_star
```

### IP-61 RLR：回环撤销、版本 epoch、合并/孤岛
```
def on_loop_closure(T_LC, new_version, lineage_patch):
    affected = subgraph_affected(T_LC)
    revoked, reanchored = [], []
    for c in certificates:
        if c.map_version != new_version and not c.anchors.isdisjoint(affected):
            c2 = try_reanchor(c, T_LC, new_version)           # 需新证书
            if c2 is not None:
                reanchored.append(c2); retire(c)
            else:
                revoked.append(c); retire(c)                  # 只撤不留，sound
    epoch = epoch + 1                                         # 原子发布
    publish_snapshot(epoch, new_version, lineage_patch)       # seqlock 语义
    log_revocation(revoked, reanchored, epoch)                # 线性一致性审计
    return revoked, reanchored

def cert_usable(c, current_version, current_epoch):
    snap = read_snapshot()                                    # e1==e2 才接受
    if snap is None: return False                             # 撕裂 => 拒绝使用
    return c.map_version == snap.version and anchor_drift(c) <= c.eps_M

def try_merge_maps(M_i, M_j, T_ij):
    if not T_ij.is_valid():                                   # 无变换证书
        return Island(M_i, M_j)                               # 孤岛，禁跨岛证书
    merged = merge(M_i, M_j, T_ij.That)
    merged.lineage = join(M_i.lineage, M_j.lineage)           # 血缘取并
    merged.version = next_version()
    revoke_cross_island_certs(M_i, M_j)                       # 旧跨岛证书撤销
    return merged
```

### IP-62 CSA：认证信息增益、探索闸门与预算
```
def certified_information_gain(a_exp, B_M):
    # 后验熵下降的保守下界，而非期望值
    H0 = entropy(B_M)
    H1_lo = entropy_lower_bound(update(B_M, a_exp))           # 乐观更新给下界
    return H0 - H1_lo

def exploration_admissible(a_exp, B_M, rho_exp):
    if not safety_cert_sound(a_exp, B_M):   return False
    if risk(a_exp) > rho_exp:                return False
    if certified_information_gain(a_exp, B_M) < G_MIN: return False
    return True

def step_exploration(a_exp, B_M, rho_exp):
    if not exploration_admissible(a_exp, B_M, rho_exp):
        return freeze_exploration()                           # 失败即冻结
    execute(a_exp)
    realized = realized_gain(a_exp)
    rho_exp = clip(rho_exp - risk(a_exp) + ETA * realized, 0, RHO_MAX)
    return rho_exp
```

def car_transition_guard_v9(e, x, cert_obj, persona, lease, mcert, t):
    theta = cert_obj.alpha_e[e] * cert_obj.theta_sim[e]

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性保证 |
|---|---|---|---|
| IP-60 地图信念标定 | O(N) 一次性/更新 | 区域误差场 O(#region) | `ε_M` 为真实偏差上界 ⟹ MCert sound |
| IP-60 退化膨胀 | O(特征维数²) 分解 | O(1) | 膨胀覆盖退化误差增长 ⟹ margin 下界 |
| IP-60 地图租约 | O(1) | 每区域 O(1) | `ε_time` 随 t 单调 ⟹ sound 上界 |
| IP-61 回环撤销 | O(|受影响证书|·|锚点|) | 血缘图 O(#证书+#边) | 只撤/需新证书重锚 ⟹ 幸存证书 sound |
| IP-61 版本 epoch 快照 | O(1) 期望，冲突重试 | epoch O(1) | e1==e2 才接受 ⟹ 无跨版本撕裂读 |
| IP-61 合并/孤岛 | O(|地图|) 合并 | 血缘 O(#agent) | 无 `T_ij` 证书不合并 ⟹ 无虚假一致性 |
| IP-62 认证信息增益 | O(d·|B_M|) 保守估计 | 后验 O(d) | `IG_lo` 为下界 ⟹ 不夸大探索收益 |
| IP-62 探索 CMDP | O(动作数) 每步 | 预算 O(1) | 闸门三条件 ⟹ 探索不违安全/不越预算 |
| IP-51 地图感知守卫 | O(|E|) 比较 | 同 L0+租约+MCert | 版本一致+未撤销+扣地图误差 ⟹ 无陈旧放行 |
| IP-59 撤销线性一致性 | O(#事件 log #事件) | 日志 O(#事件) | 检出丢失撤销/撤销后复用 ⟹ 可线性化 |

**双向闭环的收益论证**：`m = m_geo − L_g·ε_M^tot` 说明地图越准 margin 越大、可用性越高；而探索的 `realized_IG` 恰好降低未来 `ε_M`，经 IP-50 课程回灌后进入下一轮证书。于是「安全证书」与「主动建图」不是零和，而是共享同一个不确定度预算的两端：**证书给探索定风险上限，探索给证书降保守下限**。

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| `ε_M` 过度自信（SLAM 协方差低估），根错导致全链静默不 sound | 高 | 外部真值/冗余交叉标定；E95 红线；安全关键区域用测绘先验兜底；默认冻结地图回退 |
| 回环闭合相关误差使「重锚定」本身不 sound | 高 | 重锚必须产出新证书而非复用旧证书；E97/E101 红线；无法证明即撤销 |
| 退化检测漏检或膨胀不足 | 高 | 多指标联合（λ_min/残差/特征数）；E96 红线；滞回防抖；保守下限标定 |
| 主动探索越预算或 IG_lo 估计过于乐观 | 中-高 | 用下界而非期望；E98 红线测诚实率；预算独立分账；失败即冻结 |
| 地图合并制造虚假一致性 | 中-高 | 只认 `T_ij` 证书；无证书即孤岛；E99 红线；合并后全量一致性检验 |
| 撤销风暴导致可用性崩塌 | 中 | 增量重锚、分级撤销、HI 模式保安全；E97 测可用性损失 |
| 地图租约过短导致频繁重观测，过长导致 stale 漏检 | 中 | 按区域可观测性自适应 `λ_M`；E100 红线；变化检测提前失效 |
| persona/探索偏好挪用安全或探索预算 | 中 | 预算分账（`τ_u` ≠ `ρ_exp` ≠ 安全预算）；契约哈希绑定；CI 静态检查 |

## 6. 本轮最大风险

**一句话**：整条证书链现在以「标定过的地图信念 `B_M`」为根，而 SLAM 的协方差/误差界恰恰是**出了名的过度自信**（回环闭合的相关误差、退化下的低估、动态场景的污染）——一旦 `ε_M` 被低估，所有下游证书会**静默不 sound 且无法从链内自证**，因此必须引入**外部真值/冗余交叉验证**来标定根节点，并默认回退到「冻结测绘地图 + 大 margin」这条根可信的底线。
