# 第 71 轮（承接第 70 轮 BELIEF-RAS；灵感循环新循环第 3 轮；本轮灵感：「ROS2」×「云端协同」）

> R70 交付了 BELIEF-RAS：显式世界状态后验 b_t、贝叶斯 VoI 交互、边缘化流似然、基线协议与原型验收。它把「不确定性」从动作模态推进到世界状态，理论链条 R68 ⊂ FLUID ⊂ BELIEF 也基本闭合。但 R70 有一个从未写进假设、却贯穿全部延迟预算（P99<3.5ms）的隐含前提：**整个闭环是一个进程、一个时钟、一个模型版本、一台机器**。真实机器人不长这样。
>
> 真实系统是 **ROS2 图**：感知、规划、控制在独立节点，靠 DDS 话题与 QoS（reliable/best-effort、deadline、liveliness、durability）连接；节点有 lifecycle 状态迁移；每个消息带源时间戳与发布者身份。与此同时，越来越重的模型（世界模型、流策略、VLM、数字孪生、机队先验）被放到**云端**：能力弹性，但延迟非确定、版本会漂、链路会断、结果可能被投毒。
>
> 于是 R70 的 `P99<3.5ms` 不再是算法属性，而是**某个从未被显式声明的部署拓扑的属性**。一旦拓扑改变（云侧推理、跨节点证书传递、机队共享信念），R70 的安全论证会**静默失效**：证书是「为 v 版本、在 t 时刻、基于 w 水位数据」算出来的，却可能在「v+1 版本、t+Δ、w 已回退」的节点上被执行。
>
> 核心命题：**把安全证书从「进程内的一个返回值」升级为「跨 ROS2 图与云边、携带时间/版本/来源租约的一等公民」；边缘永远保留一个不依赖云的本地可证安全内核 ESK；云端只能在租约有效且证据可验证时提供「能力/分辨率红利」，租约失效、版本错配、时钟越界或来源不可信时逐指令退化为 BELIEF-RAS，再退化为 R68。** 命名 **TETHER-RAS**（Trusted Edge–cloud Time-versioned Evidence Runtime，受信边缘—云端时间版本化证据运行时）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「世界到底处于哪个状态」，R71 问「**这份信念和证书，此刻还有效吗——它来自哪个版本、哪个节点、哪条时钟、哪条链路？**」——安全不是一个数，而是一个**带租约、带来源**的数。

## 0. 直觉与动机

**灵感 1（ROS2 → 安全属性必须陈述在「图」上，而不是「循环」里）**
直觉：把证书当成一条普通 ROS2 消息，它立刻获得三样 R70 没有的东西：**源时间戳**（数据何时产生）、**QoS 合同**（能容忍多少丢失/多长延迟，deadline 是否 miss）、**发布者身份**（SROS2/DDS-Security 认证）。把证书发布成 `RELIABLE + TRANSIENT_LOCAL + lifespan + deadline + liveliness`，那么「新鲜度」「可达性」「身份」从口头假设变成可观测、可断言的运行时信号。lifecycle 节点又天然提供「激活/去激活」的显式迁移点——这正是两阶段激活（TPA）需要的原语。**分布不是要消除的噪声，而是要显式建模的约束。**

**灵感 2（云端协同 → 云端输出只能是「带租约的投机建议」）**
直觉：云端算力弹性但不可靠：会慢、会旧、会换版本、会断网、会被投毒。分布式系统里使用「可能过期的远端状态」的正确原语是 **lease**（租约，Gray & Cheriton）：用一个带 TTL 的授权窗口，在窗口内信任远端写下的状态，窗口过期即作废。安全证书天然适合做成租约——它本来就是「在某个时间/版本/数据水位内成立的风险上界」。于是云从「控制器」降级为「建议者」，且是**有明确失效时刻的建议者**。

**灵感 3（有效性偏序 → 「坏云不可伤」是结构性定理，不是经验）**
直觉：不是所有云建议都该被采纳。定义一个偏序：证据 e=(版本 v, 数据水位 w, 剩余寿命 τ_rem, 信任 trust)。若云证据在四者上都不支配本地证据，就不采纳。这样「好云只会放宽能力、坏云被拒绝」成为一个**单调性定理**，而不是「我们测过它没出事」。R70 恰好成为「云永不可达、只采纳本地证据」的边界情形——新层仍是旧层的严格泛化，而非并列替代。

**灵感 4（降级阶梯 → 优雅降级而非断崖式崩溃）**
直觉：网络不是二值可用/不可用，而是**连续退化**：全云 → 云缓存/降频 → 纯边缘 BELIEF → R68 保守。关键是每次下降都**只降能力、不降安全**，且下降过程不能出现「新旧证书都失效」的孤儿窗口。ESK 常驻预热，保证任意时刻至少有一张有效证书。恢复则相反：必须走 TPA 两阶段 + 冷却，绝不因为一个「看起来新」的包就瞬间放大能力。

**灵感 5（共享信念与供应链 → 新的、跨机器的攻击面）**
直觉：云端协同会让多机器人共享先验/世界模型。好处是集体学习，坏处是**一个机器人学坏，整队自信地错**；同时云模型更新是一条**供应链**，错误的版本、被投毒的权重、被回滚的标定都能让「租约有效但语义错误」。所以必须同时交付：来源加权 + Byzantine 鲁棒融合（n≥3f+1）、模型清单钉扎与 canary、版本偏差即证书失效、以及对「云建议采纳链」的审计。否则 TETHER 只是把 R70 的脆弱性从单机搬到了云端。

## 1. 形式化定义（增量：定义 331–345）

**定义 331（TETHER-RAS 总览）** TETHER-RAS = (ESK, CCS, CLL, AVG, RCB, CDU, VOX, PWF, TPA, RAS-WM†, VQAuditor-III)。三不变式：
(i) **边缘独立可证**：ESK 的证书生成不依赖任何云节点存活；云不可用只降低能力上界，不改变 ESK 的可认证性；
(ii) **租约诚实**：任何云建议只有 lease-valid（定义 333）时才能进入决策；租约显式携带版本清单、数据水位、TTL、时钟偏斜界与来源签名；
(iii) **无单源授权**：云建议只是一个证据源；安全相关决策要么被有效性序（定义 334）严格支配地采纳，要么满足 R69/R70 的 k-正交证据纪律，否则保持保守退避。

**定义 332（证书对象与来源）** 证书
C = (claim, ρ_claim, v, h, w, D, t_i, τ, issuer, σ, prov)，
其中 claim ∈ {safe_envelope, posterior, plan, interaction, anomaly}；ρ_claim 为风险上界；v=(v_1,…,v_n) 为模型/代码版本向量；h 为代码哈希；w 为数据水位（逻辑时间/因果戳）；D 为依赖集合（节点、话题、模型、标定文件）；t_i 签发时刻；τ 为 TTL；issuer 为身份；σ 为 SROS2/DDS-Security 签名；prov 为证据来源与历史。RCB 以 `RELIABLE + TRANSIENT_LOCAL + lifespan(τ) + deadline + liveliness` 发布。

**定义 333（租约有效性）** 设边缘单调时钟读数 t_e、时钟偏斜实测上界 δ_clk、RTT 上界 ρ_net。C 在 t_e 时刻 lease-valid 当且仅当：
(1) t_i − δ_clk ≤ t_e ≤ t_i + τ + δ_clk（不早于签发、不晚于过期）；
(2) Verify(σ, issuer, policy) = 1；
(3) ∀d∈D: M_edge(d) = M_C(d)（版本清单逐项一致，无 skew）；
(4) w_C ⊒ w_edge（数据水位因果支配，禁止重放与时间旅行）；
(5) 通道健康：窗口内 deadline miss = 0、liveliness 未丢、丢失率 ≤ ℓ_max。
任一不满足 ⇒ lease-invalid：云建议降级为「提示」（可记录、不可授权）。

**定义 334（有效性偏序与可采纳性）** 证据 e=(v,w,τ_rem,trust)。e1 ⊑ e2 当且仅当 v1 ≤_v v2（版本兼容且 v2 不旧）、w1 ⊑ w2、τ_rem1 ≤ τ_rem2、trust1 ≤ trust2。云证据 c 对本地证据 l **可采纳（admissible）** 当且仅当 l ⊑ c（严格支配），或 c 与 l 正交且通过证据纪律。「支配」语义：用 c 替换 l 不会降低任何可认证下界。非支配/更旧/版本错配/低信任 ⇒ AVG 拒绝，保持 l。

**定义 335（边缘安全内核 ESK）** ESK = (BSE_light, FMP_light 或解析 fallback, λ_floor, C-RAS-WM, ESK-certifier)。常驻、预热、不可被云卸载，预算 ≤ 2.5ms。ESK 必须对任意 t 产出一个有效（可以保守）的证书 C_ESK(t)。它是整个系统的「锚」。

**定义 336（云端能力服务 CCS）** 输出四类**投机建议**：后验精化 b^C、长时程计划 π^C、交互建议 g^C、异常第二意见 a^C。每条建议附证书（定义 332）。云端可以「更好」，但永远是 speculative。

**定义 337（不确定性四分解）** 在 R70 的 U_ale（观测噪声）与 U_epi=H[b_t]（状态歧义）之上增加：
U_comm = φ(staleness s, loss ℓ, skew δ_clk, RTT ρ, jitter j)（通信不确定）；
U_model = D_KL(p_θ_current ‖ p_θ_ref) + λ_v·version_skew（模型/版本不确定）。
安全缩放只用「本地可认证」部分 U_local = U_ale + α·H[b_t]；只有当 lease-valid 且 U_comm ≤ τ_c、U_model ≤ τ_m 时，云建议才允许把 α 降到 0（resolution bonus）；否则 α=1（退化为 R70）。

**定义 338（交换价值 VOX）** 对候选云交换 q（查询/卸载/共享）：
VoX(q) = H[b_t] − E_{y∼p(·|q)}[H[b_{t+1}(y)]] − c_net(q) − c_cloud(q) − κ·U_comm(q)。
q* = argmax VoX(q) s.t. lease-valid ∧ risk(q) ≤ ε_cloud ∧ deadline(q) ≤ Δ_max。VoX ≤ 0 或租约不可满足 ⇒ 不交换，直接走 ESK/BELIEF。它是 MINT（问人）的「问云」对偶。

**定义 339（两阶段激活 TPA）** PREPARE(v,D)：边缘预取依赖、校验版本清单、保持 ESK 活跃；COMMIT(τ_window)：在 ROS2 lifecycle 迁移上原子切换活跃证书（单一 writer 话题 + TRANSITION 状态）；ABORT：任一校验失败立即回滚。形式化保证：**任意时刻至少存在一张 active 且 lease-valid 的证书（ESK 恒真），不存在「两证书皆失效」的孤儿窗口。** TPA 类似 2PC，但保证的是「至少一方永远有效」的 safety，而非 liveness。

**定义 340（来源加权 Byzantine 融合 PWF）** 多机器人共享先验 b^shared。来源权重 w_i = trust_i · freshness_i · provenance_i；聚合用坐标中位数/截尾均值 b = TrimmedMean({b_i}, f)。当 n ≥ 3f+1 且腐败节点 ≤ f 时聚合误差有界（引理 26）；单机故障对共享先验的影响 ≤ ε_share。

**定义 341（模型供应链与版本偏差）** 云模型更新是供应链事件：manifest 钉扎、canary 评估、签名、可回滚。活动证书在其依赖模型版本变化时**立即失效**（lease invalidation）。版本偏差事件定义为 M_edge ≠ M_C：攻击者可「用 v 的证书执行 v+1 的策略」，这是本轮新增的核心威胁。

**定义 342（降级阶梯）** S0 云活跃；S1 云缓存/降频（只用未过期缓存建议）；S2 纯边缘 BELIEF-RAS；S3 R68 保守。转移由 (U_comm, U_model, lease) 阈值触发；**只允许瞬时沿「能力单调下降、安全单调不降」方向切换**，恢复必须走 TPA + 冷却。记能力 Cap 与安全集合 Safe，要求 Safe(S3) ⊇ Safe(S2) ⊇ Safe(S1) ⊇ Safe(S0)。

**定义 343（参与式审计 VQAuditor-III）** 审计新增：租约有效性日志、版本偏差事件、时钟偏斜、跨机器人来源污染、TPA 原子性证据、云建议采纳链。结论回灌 AVG 与 VOX 的先验，成为下一轮的信任度更新。

**定义 344（证书 J_TETHER）** J_TETHER = (J_BELIEF, lease_log_hash, U_comm_p95, U_model_max, manifest_hash, tpa_atomicity_proof, provenance_hash, tether_ver)。Valid ⇔ Valid(J_BELIEF) ∧ 所有被激活云证书 lease-valid ∧ ESK 全程活跃 ∧ 无孤儿窗口 ∧ 来源纪律满足。

**定义 345（退化边界）** 当 U_comm→∞（断网）、U_model 越界、无 lease-valid 云证书、或 VoX≤0 时，TETHER 逐指令等价于 BELIEF-RAS；再叠加 R70 的 H[b_t]≥τ_entropy、VoI≤c、ECE_state>τ_ece 时，逐指令等价于 FLUID 与 R68。安全侧层层包含，效率侧在租约有效时获得 cloud resolution bonus。

## 2. 关键算法骨架

```python
# IP-275 RCB：证书作为 ROS2 一等消息（QoS/时间/版本/签名）
class CertificateBus:
    QOS = dict(reliability='RELIABLE', durability='TRANSIENT_LOCAL',
               lifespan=TAU_TTL, deadline=TAU_DEADLINE, liveliness='AUTOMATIC')
    def publish(self, cert, topic='/safety/cert'):
        self.node.create_publisher(CertMsg, topic, self.QOS).publish(cert)
    def health(self, window_s=1.0):
        return dict(deadline_miss=self.miss(window_s),
                    loss=self.loss(window_s), jitter=self.jitter(window_s))

# IP-276/277 CLL+AVG：租约校验与有效性偏序
def lease_valid(cert, manifest_edge, clock, health, cfg):
    t_e = clock.mono()
    return (cert.t_i - cfg.delta_clk <= t_e <= cert.t_i + cert.tau + cfg.delta_clk
            and verify_sros2(cert.sigma, cert.issuer)
            and all(manifest_edge[d] == cert.M[d] for d in cert.D)   # 无版本偏差
            and dominates_watermark(cert.w, manifest_edge.w)          # 水位不回退
            and health['deadline_miss'] == 0 and health['loss'] <= cfg.l_max)

def admissible(cloud, local):
    return dominates(local.evidence, cloud.evidence) or (
        orthogonal(cloud, local) and passes_evidence_discipline(cloud, local))

# IP-279/280 CDU：四分解 + 云建议门控
def decompose4(b_t, obs_cov, comm, manifest):
    U_ale = expectation(b_t, lambda s: trace(obs_cov(s)))
    U_epi = entropy(b_t)
    U_comm = comm.phi(staleness, loss, skew, rtt, jitter)
    U_model = kl(p_current, p_ref) + lam_v * version_skew(manifest)
    return U_ale, U_epi, U_comm, U_model

def alpha_gate(U_comm, U_model, cfg):
    return 0.0 if (U_comm <= cfg.tau_c and U_model <= cfg.tau_m) else 1.0

# IP-281 VOX：问云值不值（非阻塞）
def choose_exchange(b_t, U_comm, cfg):
    best = None
    for q in cloud_candidates(b_t):                      # 查询/卸载/共享
        if not q.lease_feasible(): continue
        voi = entropy(b_t) - expected_entropy_after(b_t, q)
        vox = voi - q.c_net - q.c_cloud - cfg.kappa * U_comm
        if best is None or vox > best.vox: best = (q, vox)
    return best if best and best.vox > 0 else None

# IP-282 PWF：跨机来源加权 + Byzantine 鲁棒聚合
def fuse_beliefs(beliefs, weights, f):
    return coordinatewise_trimmed_mean([w * b for w, b in zip(weights, beliefs)], f)

# IP-283 TPA：两阶段激活，保证无孤儿窗口
def two_phase_activate(cert, M):
    if not (lease_valid(cert, M.manifest.edge(), M.clock, M.rcb.health(), M.cfg)
            and M.avg.admissible(cert, M.esk.local_evidence())):
        return False
    M.esk.keep_warm()                                     # 先确保锚在
    if not M.tpa.prepare(cert): return False              # 预取依赖/校验
    if not M.tpa.commit(window=M.cfg.tau_window):         # 原子切换
        M.tpa.abort(); return False
    return True

# IP-285 主闭环：ESK 永远先跑，云只提供非阻塞红利
def TETHER_RAS_round(M, obs):
    b_e, C_esk = M.esk.step(obs, M.last_action)           # ≤2.5ms，恒有效
    U_ale, U_epi, U_comm, U_model = M.cdu.decompose4(
        b_e, M.obs_cov, M.rcb.health(), M.manifest)
    q = M.vox.choose_exchange(b_e, U_comm, M.cfg)
    if q is not None: M.ccs.request_async(q)              # 绝不阻塞控制环
    advice = M.avg.admit(M.rcb.poll(timeout=0), M.manifest,
                         M.clock, M.esk.local_evidence())
    activated = advice is not None and M.tpa.activate(advice, M)
    if activated:
        b_t = M.pwf.fuse([b_e, advice.posterior], [1.0, advice.trust], f=M.cfg.f)
        _, U_epi = M.aud.decompose_from_belief(b_t, M.fmp, obs)
        a = M.cdu.alpha_gate(U_comm, U_model, M.cfg)
        lam = lam_floor(U_ale + a * U_epi)                # 租约有效才给 bonus
    else:
        b_t, lam = b_e, M.esk.safe_lambda(b_e)            # 回到 BELIEF 边界
    A = M.ach.propose(M.vista.next, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, b_t, M.wm_preds)
    state = M.ladder.state(b_t, U_comm, U_model, activated)  # S0..S3
    if state >= S2:                                       # 断链/版本漂：收缩
        k = min(k, M.esk.shrink(b_t)); lam = max(lam, M.esk.floor(b_e))
    if state == S3: lam = max(lam, 0.8)                    # R68 最保守
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam
    M.vqa_iii.submit_async(C_esk, advice, U_comm, U_model, M.tpa.log)
    return k, lam, b_t, state
```

## 3. 推导

**引理 23（租约有效性 ⇒ 使用安全）** 若 C lease-valid（定义 333）且其 ρ_claim 在本地模型下 sound，则用 C 决策的实际风险 ≤ ρ_claim + ε_lease，其中 ε_lease 由 (δ_clk, ρ_net, ℓ_max) 显式界定。要点：版本逐项一致消除 skew；水位非回退消除重放与时间旅行；TTL+δ_clk 界定陈旧；deadline/liveliness 界定「决策-执行」错位。故云无法靠一张「看似合法」的旧证书绕过安全。

**引理 24（可采纳性单调 / 坏云不可伤）** 在有效性偏序 ⊑ 下，若 AVG 只采纳满足 l ⊑ c 的云证据，则对任意云质量（含对抗）系统安全集合不劣于只用 l 的情形。即安全对云质量单调：更好的云只会扩大能力，坏的云被结构性拒绝。这把「我们测过云没搞坏安全」升级为「云在结构上不能破坏安全」。

**引理 25（时钟偏斜下无假过期、无早用）** 若 TTL τ ≥ 2δ_clk + ρ_net + τ_slack，且签发方与使用方都取保守时钟，则 lease-valid 判定既不产生「未过期却误判过期」的不必要降级，也不产生「已过期却误判有效」的不安全使用，概率 ≥ 1−ε_clk，边界由 δ_clk 实测上界保证。

**引理 26（Byzantine 融合上界）** n 个机器人中至多 f 个被投毒，采用坐标截尾均值（两侧各截 f 个极值）且 n≥3f+1，则共享先验误差 ≤ (1+η)·median error + O(ε_σ)；单源污染对共享先验的影响 ≤ 1/(n−2f)。故「一个机器人学坏」不会让整队「自信地错」。

**定理 20（TETHER 严格包含 BELIEF 严格包含 FLUID 严格包含 R68）** 在 A102–A105（租约可验证、时钟偏斜有界、版本清单完整、融合满足 Byzantine 界）下，TETHER 的期望风险 ≤ BELIEF ≤ FLUID ≤ R68；在断网/版本错配/租约失效/VoX≤0 边界，四者逐指令相同。安全侧：各降级态 Safe(TETHER) ⊇ 对应基线；效率侧：lease-valid 时获得 cloud resolution bonus。

**定理 21（TPA 无孤儿与连续控制）** TPA 的 PREPARE→COMMIT/ABORT 保证任意时刻存在 lease-valid 的活跃证书（ESK 恒真），且证书切换不改变已提交动作块的安全包络，故控制连续、无突变；云侧 crash/延迟只触发 ABORT→S2/S3，不产生「无证书」窗口。提交/换装不变式（R68 定理 15）与 BELIEF 单调性（R70 定理 18）保持。

## 6. 本轮最大风险

**一句话**：TETHER-RAS 的全部安全性押在「租约校验本身可信」上——**一旦时钟同步、版本清单、SROS2 身份或 QoS 健康信号被错误配置或被伪造，一张「看似合法」的过期/错版本证书就能借 resolution bonus 放宽安全包络，把云从「顾问」变成「权威」；分布式信任根于是成为唯一单点故障，且它的失效是静默的。**

**次级风险与缓解**：
1. **时钟偏斜击穿租约** → δ_clk 取实测上界 + 保守 TTL + 引理 25；
2. **版本清单被绕过** → manifest 钉扎 + 证书依赖逐项校验 + canary；
3. **SROS2 配置错误/密钥泄露** → 默认拒绝 + 独立安全审计 + E337；
4. **云建议语义正确但统计错误**（合法租约下的坏模型）→ 仍受 k-正交证据纪律与 ECE_state 门控，租约只保证「新鲜一致」，不保证「正确」；
5. **降级阶梯震荡** → 冷却时间 + 滞回阈值 + E329/E330；
6. **边缘内核自身被云污染**（清单来自云、标定来自云）→ ESK 依赖闭包必须本地只读且可离线重建，否则「独立可证」退化为口号。

## 3. 关键算法伪代码

```python
# IP-275 RCB：证书总线（QoS + 健康信号）
class CertificateBus:
    QOS = dict(reliability='RELIABLE', durability='TRANSIENT_LOCAL',
               lifespan=TAU_TTL, deadline=TAU_DEADLINE, liveliness='AUTOMATIC')
    def publish(self, cert, topic='/safety/cert'):
        self.pub[topic].publish(cert)                 # 序列化含 prov/signature
    def health(self, w=1.0):
        return dict(deadline_miss=self.n_miss(w),
                    loss=self.loss(w), jitter=self.jitter(w))

# IP-276 CLL：租约五元校验
def lease_valid(C, t_e, M_edge, policy, health, cfg):
    if not (C.t_i - cfg.delta_clk <= t_e <= C.t_i + C.tau + cfg.delta_clk): return False
    if not verify_sros2(C.sigma, C.issuer, policy):                          return False
    if any(M_edge[d] != C.M[d] for d in C.D):                               return False
    if not dominates_watermark(C.w, M_edge.w):                              return False
    if health['deadline_miss'] != 0 or health['loss'] > cfg.l_max:          return False
    return True

# IP-277 AVG：有效性偏序 + 证据纪律
def admissible_cloud(C, local, M):
    if dominates(local.evidence, C.evidence): return True
    if orthogonal(C, local): return passes_evidence_discipline(C, local)  # k>=2 源
    return False

# IP-280 CDU：四分解 + bonus 门控
def decompose4(b_t, obs_cov, health, M):
    U_ale  = expectation(b_t, lambda s: trace(obs_cov(s)))
    U_epi  = entropy(b_t)
    U_comm = phi(health.staleness, health.loss, M.clock.skew(),
                 health.rtt, health.jitter)
    U_model= kl(M.p_current, M.p_ref) + M.cfg.lam_v * version_skew(M.manifest)
    return U_ale, U_epi, U_comm, U_model

def alpha(U_comm, U_model, cfg):
    return 0.0 if (U_comm <= cfg.tau_c and U_model <= cfg.tau_m) else 1.0

# IP-281 VOX：非阻塞问云
def choose_exchange(b_t, U_comm, M):
    best = None
    for q in cloud_candidates(b_t):
        if not q.lease_feasible(): continue
        vox = entropy(b_t) - expected_entropy_after(b_t, q, M) \
              - q.c_net - q.c_cloud - M.cfg.kappa * U_comm
        if best is None or vox > best.vox: best = (q, vox)
    return best if best and best.vox > 0 else None

# IP-282 PWF：Byzantine 鲁棒融合
def fuse(beliefs, weights, f):
    return coordinatewise_trimmed_mean(
        [w * b for w, b in zip(weights, beliefs)], f)

# IP-283 TPA：两阶段激活
def tpa_activate(C, M):
    if not lease_valid(C, M.clock.mono(), M.manifest.edge(), M.policy,
                       M.rcb.health(), M.cfg):                     return False
    if not admissible_cloud(C, M.esk.local_evidence(), M):         return False
    M.esk.keep_warm()                                              # 先保锚
    if not M.tpa.prepare(C):                                       return False
    if not M.tpa.commit(window=M.cfg.tau_window):
        M.tpa.abort();                                             return False
    return True

# IP-285 TETHER 主闭环（非阻塞）
def TETHER_RAS_round(M, obs):
    # 0) ESK 永远先跑，云绝不阻塞
    b_e, C_esk = M.esk.step(obs, M.last_action)                    # ≤2.5ms
    # 1) 四分解
    U_ale, U_epi, U_comm, U_model = decompose4(b_e, M.obs_cov, M.rcb.health(), M)
    # 2) 决定是否问云（异步）
    q = choose_exchange(b_e, U_comm, M)
    if q is not None: M.ccs.request_async(q)
    # 3) 只收割已到达且可采纳的证书
    C = M.rcb.poll(timeout=0)
    ok = C is not None and tpa_activate(C, M)
    # 4) 云只给 bonus，锚定安全界
    if ok:
        b_t = fuse([b_e, C.posterior], [1.0, C.trust], M.cfg.f)
        _, U_epi = M.aud.decompose_from_belief(b_t, M.fmp, obs)
        lam = lam_floor(U_ale + alpha(U_comm, U_model, M.cfg) * U_epi)
    else:
        b_t, lam = b_e, M.esk.safe_lambda(b_e)                     # = BELIEF 边界
    # 5) 认证 + 降级阶梯
    A = M.ach.propose(M.vista.next, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, b_t, M.wm_preds)
    state = M.ladder.state(b_t, U_comm, U_model, ok)
    if state >= S2: k = min(k, M.esk.shrink(b_t)); lam = max(lam, M.esk.floor(b_e))
    if state == S3: lam = max(lam, 0.8)
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam
    # 6) 审计 + 证书
    M.vqa_iii.submit_async(C_esk, C, U_comm, U_model, M.tpa.log)
    return k, lam, b_t, state
```

## 4. 推导

**引理 23（租约有效性 ⇒ 使用安全）** 若 C lease-valid 且 ρ_claim 在本地模型下 sound，则实际风险 ≤ ρ_claim + ε_lease(δ_clk, ρ_net, ℓ_max)。证明要点：版本逐项一致消除 skew；水位非回退消除重放/时间旅行；TTL+δ_clk 界定陈旧；通道健康界定决策-执行错位。

**引理 24（可采纳性单调 / 坏云不可伤）** AVG 只采纳 `l⊑c` 的云证据 ⇒ 对任意云质量（含对抗），系统安全集合不劣于仅用 l。故安全对云质量单调，坏云被结构性拒绝。

**引理 25（时钟偏斜界）** 若 `τ ≥ 2δ_clk + ρ_net + τ_slack` 且双方取保守时钟，则「假过期」与「早用」的联合概率 ≤ ε_clk；边界由 δ_clk 实测上界保证。

**引理 26（Byzantine 融合上界）** n≥3f+1、至多 f 个投毒、坐标截尾均值 ⇒ 共享先验误差 ≤ (1+η)·median + O(ε_σ)，单源影响 ≤ 1/(n−2f)。

**定理 20（TETHER ⊃ BELIEF ⊃ FLUID ⊃ R68）** 在 A102–A105 下期望风险 ≤ 各基线；断网/版本错配/租约失效/VoX≤0 时逐指令相同。安全侧各降级态 Safe ⊇ 对应基线；效率侧 lease-valid 时获 cloud resolution bonus。

**定理 21（TPA 无孤儿与连续控制）** 任意时刻存在 lease-valid 活跃证书（ESK 恒真）；切换不改变已提交动作块的安全包络；云 crash/延迟只触发 ABORT→S2/S3。结合 R68 定理 15 与 R70 定理 18，控制连续、无突变。

## 8. 本轮最大风险

**一句话**：TETHER-RAS 的全部安全性押在「租约校验本身可信」上——**一旦时钟同步、版本清单、SROS2 身份或 QoS 健康信号被错误配置或伪造，一张「看似合法」的过期/错版本证书就能借 resolution bonus 放宽安全包络，把云从「顾问」变成「权威」；分布式信任根于是成为唯一单点故障，且失效是静默的。**

**次级风险与缓解**：
1. 时钟偏斜击穿租约 → δ_clk 实测上界 + 保守 TTL + 引理 25；
2. 版本清单被绕过 → manifest 钉扎 + 依赖逐项校验 + canary；
3. SROS2 配置错误/密钥泄露 → 默认拒绝 + 独立安全审计 + E337；
4. 合法租约下的坏模型 → 租约只保证新鲜一致、不保证正确，仍受 k-正交证据纪律与 ECE_state 门控；
5. 降级震荡 → 冷却 + 滞回 + E329/E330；
6. ESK 依赖闭包被云污染 → 清单/标定必须本地只读可离线重建，否则「独立可证」退化为口号。
