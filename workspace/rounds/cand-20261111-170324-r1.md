# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「域随机化」×「UniBot-V1」）

> 第 54 轮已建立动作-鲁棒性双证书与云边协同闭环。本轮引入两个新变量：**域随机化（DR）** 与 **统一基座策略 UniBot-V1**。核心矛盾——H22：DR 把参数不确定性压进训练分布，却让「证书在哪个域上有效」变得不可见，随机化越宽不等于证书越真；H23：UniBot-V1 是黑箱动作先验，第 54 轮的 ρ/α/J 证书无法直接挂接，必须把 DR 反过来用作「黑箱探针」来提取其可证域。

## 0. 直觉与动机

**灵感 1（域随机化 = 可证域扩张算子，不是训练技巧）**
直觉：把随机化分布 `μ_φ` 看成「证书的作用域」。证书 `C` 不再是无参数的真值断言，而是带 **随机化指纹 `R_φ`** 的条件断言：`C` 仅在 `μ_φ` 覆盖的域上被验证。部署时真正要问的不是「`ρ` 够不够高」，而是「部署分布 `μ_real` 是否落在 `μ_φ` 的可证域内、差多远」。这把 DR 从训练超参提升为证书的第一性元数据。

**灵感 2（盲随机化 → 定向随机化）**
直觉：均匀放宽所有参数既浪费样本，又会把策略推向真实机器人永远不会遇到的区域，制造「过度保守 + 名义性能塌陷」的负迁移。应让第 53 轮的 Explain 指出失败边界 `∂F`，把随机化采样集中到 `∂F` 附近，并约束在物理可行流形 `P` 内：
`max_{μ_φ∈Δ(P)} μ_φ(B_ε(∂F)) - λ·W_1(μ_φ, μ_prior)`。
这样随机化从「撒胡椒面」变成「朝证书边界做功」。

**灵感 3（域差异证书 + Lipschitz 迁移界）**
直觉：若风险 `ℓ(θ)` 对物理参数是 `L_Θ`-Lipschitz，则 sim 上的最坏风险加上 `L_Θ·W_1(μ_sim, μ_real)` 就是真实风险的严格上界。这把「sim-to-real 鸿沟」从经验口号变成可计算的证书预算项 `δ_dom`。随机化分布不是越大越好，而是要在「覆盖真实分布」和「保持 Lipschitz 常数可控」之间取平衡。

**灵感 4（UniBot-V1 = 黑箱动作先验 → 随机化探针）**
直觉：既然不能改 UniBot-V1 的训练，就把 DR 当探针：在随机化环境里批量 rollout，估计它的动作剖面 `α_UB`、鲁棒性谱 `ρ_UB`，以及「局部可证域」`D_UB`。再用 **证书适配器** 决定：这次 UniBot-V1 的输出能否被现有证书背书，不能则回退到第 54 轮的 SCOM 组合。证书体系由此从「自研策略专用」变成「基座模型可插拔」。

**灵感 5（双通道部署 + 随机化闭环）**
直觉：部署时开两条通道——A 通道 UniBot-V1 直出（带证书适配/动作护栏），B 通道 SCOM 验证技能组合回退。边端 Explain 回传既驱动第 54 轮的云侧重剖分，也驱动随机化分布 `μ_φ` 的更新，形成 **「部署失败 → 域重加权 → 探针复估 → 证书刷新」** 的闭环课程。

**灵感 6（金字塔扩展：域层 𝔻）**
直觉：在动作-协同层 `𝔸` 之下加一层域层 `𝔻`：`𝔻_0` 物理参数域，`𝔻_1` 随机化分布，`𝔻_2` 域差异，`𝔻_3` 部署域。跨层证书必须同时携带 `(ρ, A_cert, R_φ, δ_dom)`，否则「在某个域上成立」这句话无法被审计。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（物理参数域与随机化分布）**
物理参数 `θ ∈ Θ`（质量、摩擦、延迟、传感器噪声、执行器增益等）；随机化分布 `μ_φ ∈ Δ(Θ)`，`φ` 为区间/分位/相关结构等超参。`B(θ_0,r)` 表示度量 `d_Θ` 下的球。`P ⊆ Θ` 为物理可行流形（力矩/摩擦/延迟的硬约束）。

**定义 122（随机化指纹与可证域）**
随机化指纹 `R_φ = (axes, quantiles, correlations, N, seed, d_Θ)`。证书 `C` 的可证域 `Dom_φ(C) ⊆ Θ` 为在 `μ_φ` 采样下满足 margin 的 `θ` 集；域覆盖 `cov_φ(D) = μ_φ(D)`。**证书只对支撑落在 `Dom_φ(C)` 内的部署分布生效**——这是本轮把 DR 纳入证书体系的形式化入口。

**定义 123（失败边界与定向随机化目标）**
失败边界 `∂F_ε = {θ : 0 ≤ ℓ(θ) - ℓ_min ≤ ε}`。定向随机化是约束优化：
```
μ_φ* = argmax_{μ_φ∈Δ(P)} [ μ_φ(B_ε(∂F)) - λ·W_1(μ_φ, μ_prior) ]
       s.t. 采样预算 N ≤ B_q
```
`μ_prior` 编码物理可信先验，第二项是对「过度随机化」的显式惩罚。

**定义 124（域差异证书与迁移界）**
域差异证书 `δ_dom = L_Θ·W_1(μ_sim, μ_real)`。若风险 `ℓ` 在 `(Θ,d_Θ)` 上 `L_Θ`-Lipschitz，则
```
E_{μ_real}[ℓ] ≤ sup_{θ∈Dom_φ(C)} ℓ(θ) + L_Θ·W_1(μ_sim, μ_real) + η_cov
```
其中 `η_cov` 为覆盖缺口贡献。当 `δ_dom > Θ_dom` 时，证书必须降级或拒绝迁移。

**定义 125（UniBot-V1 黑箱剖面）**
`π_UB : (o, θ) → a`。探针估计三件套：
- 动作剖面 `α_UB(a) = Pr_{θ~μ_φ}[ d(π_UB(o,θ), a) ≤ ε_a ]`；
- 鲁棒性谱 `ρ_UB(d) = inf_{θ∈B(θ_0,r_d)} success(π_UB, θ)`；
- 局部可证域 `D_UB(δ) = { θ : LCB(success | θ, n) ≥ 1-δ }`。

**定义 126（证书适配器与准入判据）**
适配器 `Admit(π_UB, C, θ̂, μ̂_real) = 1` 当且仅当
```
θ̂ ∈ D_UB(δ) ∩ Dom_φ(C) ∧ δ_dom^ ≤ Θ_dom ∧ margin_C(θ̂) ≥ 0
```
否则触发回退路由 `Route ∈ {guard, SCOM, safe_stop}`。`guard` 把动作裁剪到 `C.A_core`。

**定义 127（加权共形转移证书，可选强化）**
在协变量偏移下，用似然比 `w(θ) = dμ_real/dμ_sim` 做加权共形校准，得到成功率的有限样本下界；权重估计误差以 `TV(ŵ,w)` 折损覆盖。令 `δ_conf` 为共形缺口，则证书预算追加 `δ_conf` 项，用于「无参数分布假设」时的兜底。

## 2. 关键算法 伪代码

### IP-121 CDR（Certified Domain Randomization）

```python
def certify_randomization(mu_phi, C, N, metric, theta_cov):
    R = fingerprint(mu_phi, N, metric)
    dom, ok = set(), 0
    for _ in range(N):
        th = sample(mu_phi)
        if margin(C, th) >= 0:
            dom.add(th); ok += 1
    cov = ok / N
    if cov < theta_cov:
        return ('undercover', R, cov)
    return ('ok', R, dom)
```

### IP-122 FBDR（Failure-Boundary-guided DR）

```python
def targeted_dr(C, explain_fn, P, budget, lam):
    F = locate_failure_boundary(C, explain_fn)   # Explain 给出根因轴与方向
    mu = mu_prior
    for _ in range(budget):
        cand = propose(mu, F, P)                 # ∂F 邻域 + 物理流形投影
        if objective(cand, F, P, lam) > objective(mu, F, P, lam):
            mu = cand
    return mu, fingerprint(mu, budget, P.metric)
```

### IP-123 UBProbe（UniBot-V1 Black-box Profiling）

```python
def probe_unibot(pi_ub, mu_phi, tasks, delta, n, eps_a):
    alpha, rho, D = {o: 0 for o in tasks}, {}, set()
    for _ in range(n):
        th = sample(mu_phi)
        for o in tasks:
            a = pi_ub(o, th)
            alpha[o] += feasible(a, o, th, eps_a)
            succ = rollout(pi_ub, o, th)
            update_spectrum(rho, succ, th)
            if lcb(succ, n) >= 1 - delta:
                D.add(th)
    return normalize(alpha, n), rho, D
```

### IP-124 DTC（Domain Transfer Certificate）

```python
def domain_transfer_cert(C, mu_sim, mu_real_hat, L, theta_dom):
    W = wasserstein(mu_sim, mu_real_hat, C.metric)
    delta_dom = L * W
    eta_cov = coverage_gap(C, mu_real_hat)
    bound = C.worst_risk + delta_dom + eta_cov
    if delta_dom > theta_dom:
        return ('reject', 'domain_gap', delta_dom, bound)
    return ('ok', DTC(C, delta_dom, eta_cov, bound))
```

### IP-125 CAR（Certificate Adapter / Router）

```python
def route(pi_ub, o, th_hat, C, D_ub, mu_hat, theta_dom):
    if th_hat in D_ub and th_hat in C.domain:
        dtc = domain_transfer_cert(C, C.mu, mu_hat, C.L, theta_dom)
        if dtc[0] == 'ok' and margin(C, th_hat) >= 0:
            a = guard(pi_ub(o, th_hat), C.A_core)
            return ('unibot', a, dtc)
    if scom_composable(C):
        return ('scom', compose_skills(C), None)
    return ('safe_stop', None, None)
```

### IP-126 RCL（Randomization Curriculum Loop）

```python
def randomization_loop(C, pi_ub, mu_phi, edge_reports, P):
    for rep in edge_reports:
        if rep.type in ('domain_gap', 'rho_fail'):
            mu_phi = reweight(mu_phi, rep.explain, P)      # 按根因轴重加权
            alpha, rho, D = probe_unibot(pi_ub, mu_phi, ...)
            C = refresh_certificate(C, alpha, rho, D, mu_phi)
    return mu_phi, C
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CDR | O(N·\|C\|) | O(N) | 覆盖可判定、指纹可复现 |
| FBDR | O(B_q·cand_cost) | O(B_q) | 边界收敛、物理流形投影 |
| UBProbe | O(n·\|O\|·T_rollout) | O(\|O\|+\|Θ\|) | 探针 LCB、采样无偏 |
| DTC | O(N log N)（1D）/ O(N³)（多维 LP） | O(N) | W_1 置信上界、Lipschitz 保守 |
| CAR | O(1) + DTC | O(1) | 准入 sound、回退完备 |
| RCL | O(R·(probe+cert)) | O(R) | 重加权收敛、无震荡 |

**正确性定理（Domain-Randomized Transfer Soundness）**
假设承接第 54 轮 `(A26)–(A28)`；新增
**(A29)** `μ_sim` 在 `Dom_φ(C)` 上覆盖部署支持，且 `W_1(μ_sim, μ_real) ≤ ε_W`；
**(A30)** 风险 `ℓ` 对 `θ` 是 `L_Θ`-Lipschitz；
**(A31)** 探针样本 `n` 使 `D_UB(δ)` 的 LCB 成立（Hoeffding / Clopper-Pearson）；
**(A32)** 定向随机化在预算 `B_q` 内收敛到 `∂F` 的 `ε`-邻域。
则对 `θ ~ μ_real`：
```
P_success ≥ 1 - [ sup_{Dom_φ(C)} ℓ(θ) + L_Θ·ε_W + η_cov + β_probe ]
```
其中 `β_probe` 为探针置信折损。**关键**：转移误差由 `W_1` 显式进入预算；若「加宽随机化」反而推高 `L_Θ·W_1`，证书会自动降级——这给「反过度随机化」提供了可计算的理由，而不是靠直觉。

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 随机化覆盖-真实失败率 | `cov_φ` vs real fail rate | 单调负相关 R² ≥ 0.8 |
| E163 定向 vs 均匀 DR | 样本效率 / 名义性能保持 | 同等覆盖省 ≥ 3×；名义性能仅降 ≤ 3% |
| E164 UniBot-V1 探针精度 | `ρ_UB` MAE / `α_UB` IoU | MAE ≤ 0.06；IoU ≥ 0.75 |
| E165 域迁移证书有效性 | 预测界 vs 实测风险 | 界成立率 ≥ 95%，松弛 ≤ 20% |
| E166 适配器 + 回退路由 | 部署成功率 vs 原生 UniBot-V1 | 提升 ≥ 10%，安全停机率 ≤ 2% |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| W_1 小样本估计高方差 | 高 | 两样本检验 + 置信上界 + 分布矩约束 |
| `L_Θ` 被低估导致迁移界失效 | 高 | 局部 Lipschitz 校准 + 对抗采样验证 |
| 定向随机化过拟合 `∂F` | 中 | 物理流形 `P` 投影 + 随机化熵正则 |
| UniBot-V1 探针成本高 | 中 | 分层采样 + 代理模型 + 主动查询 |
| 真实分布漂移使加权共形失效 | 高 | 在线重校准 + 漂移警报 + 保守回退 |

## 6. 本轮最大风险

**一句话**：把域随机化从训练技巧升级为「可证域扩张 + 域差异证书」在形式上更严谨，但它把证书有效性押在 **`W_1` 的可靠估计、`L_Θ` 的保守上界、以及 UniBot-V1 黑箱探针的置信下界** 三者之上；任一项被低估（尤其小样本下 `W_1` 与 `L_Θ` 同时低估）都会让迁移界「看起来成立」而真实部署系统性越界，因此必须以 **置信上界化的 `W_1` + 局部对抗校准的 `L_Θ` + 探针拒绝权** 三重护栏，宁可让证书降级，也不把随机化分布的「覆盖幻觉」当作 sim-to-real 的通行证。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（CDR×FBDR×UBProbe×DTC×CAR×RCL×WCC）

> 承接第 54 轮产物 v31。本轮在「动作-鲁棒性双证书 + 云边协同」之上，增加 **可证域随机化、失败边界定向采样、UniBot-V1 黑箱剖面、域迁移证书、证书适配器/回退路由、随机化闭环课程** 六大算子：
> - **CDR（Certified Domain Randomization）**：给每张证书挂随机化指纹 `R_φ`，把 DR 变成可证域；
> - **FBDR（Failure-Boundary-guided DR）**：Explain 定位 `∂F`，在物理流形内定向采样；
> - **UBProbe（UniBot-V1 Black-box Profiling）**：用 DR 探针提取 `α_UB / ρ_UB / D_UB`；
> - **DTC（Domain Transfer Certificate）**：`δ_dom = L_Θ·W_1` 的迁移界；
> - **CAR（Certificate Adapter / Router）**：UniBot-V1 直出 / 护栏 / SCOM 回退三态路由；
> - **RCL（Randomization Curriculum Loop）**：部署失败驱动域重加权与证书刷新；
> - **WCC（Weighted Conformal Certificate）**：偏移下成功率的有限样本兜底下界。
>
> IP 编号：IP-121~IP-127（共 7 个新增），升级 IP-116/117/118/120 以携带随机化指纹与域差异预算。

        if rep.type in ('domain_gap', 'rho_fail'):
            mu_phi = reweight(mu_phi, rep.explain, P)
            alpha, rho, D = probe_unibot(pi_ub, mu_phi, ...)
            C = refresh_certificate(C, alpha, rho, D, mu_phi)
    return mu_phi, C

def weighted_conformal(scores, w, alpha, w_hat):
    order = argsort(w)
    sw = cumsum([w[i] for i in order])
    q = quantile_weighted(scores[order], sw, 1 - alpha)
    gap = 0.5 * total_variation(w, w_hat)   # 权重估计误差折损
    return ('ok', q, gap) if gap <= delta_conf_budget else ('reject', q, gap)

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CDR | O(N·\|C\|) | O(N) | 覆盖可判定、指纹可复现 |
| FBDR | O(B_q·cand_cost) | O(B_q) | 边界收敛、物理流形投影 |
| UBProbe | O(n·\|O\|·T_rollout) | O(\|O\|+\|Θ\|) | 探针 LCB、采样无偏 |
| DTC | O(N log N) / O(N³) | O(N) | W_1 置信上界、Lipschitz 保守 |
| CAR | O(1) + DTC | O(1) | 准入 sound、回退完备 |
| RCL | O(R·(probe+cert)) | O(R) | 重加权收敛、无震荡 |
| WCC | O(N log N) | O(N) | 加权覆盖、TV 缺口可界 |

**正确性定理（Domain-Randomized Transfer Soundness）**
假设第 54 轮 `(A26)–(A28)` 成立；**(A29)** `μ_sim` 在 `Dom_φ(C)` 上覆盖部署支持且 `W_1(μ_sim,μ_real) ≤ ε_W`；**(A30)** 风险 `ℓ` 对 `θ` 是 `L_Θ`-Lipschitz；**(A31)** 探针 `n` 使 `D_UB(δ)` 的 LCB 成立；**(A32)** 定向随机化在 `B_q` 内收敛到 `∂F` 的 `ε`-邻域。则
```
P_success ≥ 1 - [ sup_{Dom_φ(C)} ℓ(θ) + L_Θ·ε_W + η_cov + β_probe + δ_conf ]
```
关键：**迁移误差以 `W_1` 显式入账**，加宽随机化若推高 `L_Θ·W_1` 则证书自动降级；`δ_conf` 为无分布假设时的兜底。这使「随机化-证书」对偶可审计、可拒绝、可回退。

## 5. 本轮最大风险

**一句话**：把域随机化从训练技巧升级为「可证域扩张 + 域差异证书」在形式上更严谨，但它把证书有效性押在 **`W_1` 的可靠估计、`L_Θ` 的保守上界、以及 UniBot-V1 黑箱探针的置信下界** 三者之上；任一项被低估（尤其小样本下 `W_1` 与 `L_Θ` 同时低估）都会让迁移界「看起来成立」而真实部署系统性越界，因此必须以 **置信上界化的 `W_1` + 局部对抗校准的 `L_Θ` + 探针拒绝权** 三重护栏，宁可让证书降级，也不把随机化分布的「覆盖幻觉」当作 sim-to-real 的通行证。
