# 第 56 轮（承接第 55 轮语义-接触接地；灵感循环第 2 轮；本轮灵感：「机器人操作系统」×「灵巧手」）

> 第 55 轮把视角压到“接触在语义上是否可信、全身耦合下是否可行”。本轮再换一次坐标系：从**单体控制闭环**上移到**ROS 2 分布式计算图**，从**全身支撑接触**下潜到**灵巧手的高频接触拓扑**。两个核心矛盾：**H24（时间条件化）**：所有既有证书都隐含“证据按时到达”，但 ROS 2 的节点调度、DDS QoS、tf 时间戳与 Action 抢占使“证书成立”变成一个依赖端到端时限与可靠性的条件命题，deadline miss 或过期帧会让已验证动作落到错误表面；**H25（接触拓扑优先）**：灵巧手的可部署性由接触拓扑与力闭合裕度决定而非关节位姿，且接触拓扑在毫秒级变化、失败不可逆（掉落/压碎），因此抓取证书必须携带接触转换图与笼络中间态，才能承受抢占与滑移。

## 0. 直觉与动机

**灵感 1（机器人操作系统 → 证书必须“时相条件化”）**
直觉：在 ROS 2 里，一条证据从触觉节点经估计节点到控制器，是一条有 QoS（deadline、liveliness、reliability、history）的消息路径。证书真正断言的不是“状态 x 安全”，而是“**若这条路径在 D 毫秒内可靠送达，则 x 安全**”。于是把每个证书 `φ` 升级为 `φ | A_τ`：以时相契约 `A_τ` 为条件。ROS 不是部署容器，而是证书语义的一部分。

**灵感 2（灵巧手 → 第一性状态是接触拓扑，不是关节角）**
直觉：全身控制里“脚踩实”可以用支撑多边形描述；灵巧手里“抓稳”必须用接触拓扑 `T`、接触力旋量空间 `W(P)` 与力闭合间隙 `ε_fc` 描述。关节角只是实现手段，姿态协同 `σ:R^k→Q_H` 把 k 维意图映到 n 维手指（k≪n），但可部署性应诉诸接触，而非协同坐标本身。

**灵感 3（ROS 2 tf2 → 裕度必须支配时序位姿误差）**
直觉：tf2 是一棵带时间戳的帧树。若手-物接触关键帧的变换已过期 `a_e` 毫秒，物体就会在“以为的位置”上多走 `v_max·a_e`。因此仅检查“帧存在”不够，必须要求 `E_tf ≤ 接触裕度`——**时间误差要被几何/力裕度支配**，否则“坐标看起来对、接触其实错”。

**灵感 4（ROS 2 Action → 抢占是安全事件，不是调度细节）**
直觉：长程灵巧操作常用 Action 的 feedback/preempt/cancel。抓取闭合到一半被 cancel，手可能松脱或压碎。必须定义**安全预抢占集** `S_pre`：只有存在已认证回退（保持抓取或柔顺释放）且风险不增的状态才允许取消；否则先沿认证轨迹投影到 `S_pre` 再回退。

**灵感 5（生命周期节点/组件容器 → 退化格而非布尔可用性）**
直觉：ROS 2 的 lifecycle 与 component container 提示我们，部署状态应是**模式格**：全功能 ⊒ 降级 ⊒ 安全保持 ⊒ 柔顺释放 ⊒ 急停。系统证书不是一个布尔值，而是“在故障格上存在一条风险单调的退化路径”，监控节点必须与规划节点进程/执行器隔离并有独立看门狗。

**灵感 6（认证悖论 → 证书本身也要进 WCET）**
直觉：抓取证书的力闭合 LP、系统证书的组合检查、看门狗心跳、tf 校验都要花 CPU 与带宽。若不把这些开销计入响应时间分析，安全监控会与它守护的控制回路争抢预算，形成“认证导致失守”的自指风险。因此 `C_monitor` 必须进入 `C_v`，且监控处于最高关键性等级。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（灵巧接触拓扑与抓取证书）**
手 `H` 的关节 `q_H∈Q_H⊂R^n`，姿态协同映射 `σ:R^k→Q_H`（k≪n）。物体 `O` 表面 `∂O`，接触集
`P={(p_i,n_i,μ_i,τ_i)}_{i=1}^m`，接触类型 `τ_i∈{点,软指,全面}`，力旋量基 `G_i(p_i,n_i,τ_i)∈R^{6×d_i}`。抓取力旋量空间
`W(P)={Σ_i G_i λ_i | λ_i∈FC(μ_i)}`，`FC(μ)={λ | λ_n≥0, ‖λ_t‖≤μλ_n}`。
力闭合间隙 `ε_fc(P)=dist(0,∂W(P))/‖W_scale‖`；接触裕度 `m_c=min_i dist(p_i,∂O)`；法向裕度 `m_n=min_i arccos(n_i·n_i^*)`。
抓取证书
`G_cert=(T,P_core,ε_fc,m_c,m_n,z_core,ρ_grasp,evidence)`
其中 `T` 为接触拓扑图（接触—手链接—物体特征的关联），`P_core` 为核心接触子集，`z_core=σ^{-1}(q_H)` 核心协同坐标，
`ρ_grasp(δ)=inf_{‖δP‖≤δ} P(ε_fc(P+δP)≥θ_fc ∧ m_c≥θ_c)` 为接触扰动球内的力闭合保持概率。
可部署当 `ε_fc≥θ_fc`、`m_c≥θ_c`、`m_n≤θ_n`、`ρ_grasp(δ_g)≥ρ_min`。
另定义抓取转换图 `G_grasp=(T_i→T_j)`：每条重抓边必须经过**笼络集** `C_cage⊂SE(3)`（不破坏接触则物体无法逸出），保证抢占或滑移时“停在中间”也安全。

**定义 128（QoS 预算契约与端到端时相可行性）**
ROS 2 图 `G_R=(V,E)`，`V` 为节点（触觉、估计、规划、控制、安全监控），`E` 为 topic/service/action 通道。节点 `v` 有 WCET `C_v`、周期 `T_v`、抖动 `J_v`、阻塞 `B_v` 与 QoS 元组
`Q_v=(reliability, deadline D_v, lifespan, liveliness L_v, history, durability)`。
路径 `π=v_0→…→v_k` 的最坏端到端时延
`L_π^wc=Σ_{i=0}^k (C_i+B_i+J_i)+Σ_{e∈π}(trans_e^wc+q_e^wc)`。
时相契约 `C_τ(π)=(D_π,r_π,L_π^wc)`，满足当 `L_π^wc≤D_π` 且 `r_π=Π_{e∈π}r_e≥r_min`。
称证书 `φ` 在
`A_τ={∀π∈Π_crit: L_π^wc≤D_π ∧ r_π≥r_min}`
下**时相条件化**，记 `φ|A_τ`：证书只在证据路径的时限与可靠性假设成立时有效。

**定义 129（坐标帧证书）**
tf2 帧图 `F=(Frames,Edges)`，接触关键帧集 `F_c`，变换边 `e` 的时间戳 `τ_e`。龄期 `a_e(t)=t-τ_e`，时钟偏斜 `s`。时序诱导位姿误差上界
`E_tf(t)=max_{e∈path(F_c)} (v_max·a_e(t)+s·v_max·T_win+ε_cal(e))`。
帧证书 `χ_F(t)=1` 当且仅当 `F` 在 `F_c` 上为树（无环、唯一父）、`∀e: a_e≤a_max`、`|s|≤s_max`、且拒绝 `TF_OLD_DATA`。
**裕度支配原则**：要求 `E_tf ≤ m_c` 且 `E_tf ≤ m_n·r_reach`，即时间/坐标不一致诱导的位姿误差必须被几何与力裕度支配。

**定义 130（动作语义契约）**
ROS 2 action `A=(goal,feedback,result,cancel)`，状态机 `pending→active→{succeeded,aborted,canceled}`。安全预抢占集
`S_pre={x∈X | ∃u_fb: x_fb=step(x,u_fb)∈K(Σ) ∧ (G_cert(x_fb)保持 ∨ 物体被安全释放)}`。
动作契约 `A_cert=(S_pre,u_fb,D_cancel,R_mono)`，其中 `R_mono: R(x_fb)≤R(x)`（预抢占不增加风险）。
可部署当且仅当：`goal` 携带所需 `G_cert` 与关键性等级；取消只在 `S_pre` 执行，或沿已认证测地线在 `D_pre` 内投影到 `S_pre` 再回退；`feedback` 不得携带过期状态。

**定义 131（混合关键性退化格）**
模式集 `M={M_full,M_degraded,M_safe-hold,M_compliant-release,M_estop}`，`⊑` 为退化偏序。每个 `m∈M` 有不变量 `I_m⊆X` 与允许动作集 `U_m`。退化映射 `D:M×Fault→M` 满足**风险单调** `R(D(m,f))≤R(m)` 且 `I_m⊆I_{D(m,f)}`。证书要求单故障可操作：任意单节点故障 `f` 下，`D` 在 `T_deg` 内到达已认证模式；安全监控节点与规划节点进程/执行器隔离并受独立看门狗守护。

**定义 132（DexROS 系统图证书）**
`S_cert=(G_R,{C_τ(v)},{A_cert},G_cert,χ_F,M_lattice,ρ_sys,δ_sys,evidence)`。
系统鲁棒谱
`ρ_sys(δ)=inf_{‖f‖≤δ} P(安全 ∧ G_cert保持 | A_τ,A_tf,A_pre)`，
扰动 `f` 覆盖时延抖动、丢包、帧过期、单节点故障与接触扰动。可部署当且仅当：
(i) 所有接触关键路径满足时相契约；(ii) `χ_F=1` 且裕度支配成立；(iii) 每个 action 满足 `A_cert`；
(iv) `G_cert` 在 `δ_g` 内鲁棒；(v) 退化格覆盖单故障且 `T_deg≤T_recover`；(vi) `ρ_sys(δ)≥ρ_min`。
组合采用 assume-guarantee：节点 `v` 的保证以其输入通道的 QoS/时间假设为条件，避免全图状态爆炸。

## 2. 关键算法 伪代码

### IP-127 DGC（Dexterous Grasp Certificate）

```python
def grasp_certificate(hand, obj, contacts, sigma, delta_g, theta):
    W = wrench_space([wrench_basis(p) for p in contacts])
    eps = dist_origin_boundary(W) / obj.wrench_scale
    m_c = min(surface_distance(p.point, obj.mesh) for p in contacts)
    m_n = min(normal_margin(p.normal, obj, p.point) for p in contacts)
    rho = robust_grasp_prob(contacts, delta_g, theta)   # 接触扰动球内最坏保持概率
    z = sigma.project(hand.q)
    T = contact_topology(contacts, hand.links, obj.features)
    if eps < theta.fc or m_c < theta.c or m_n > theta.n or rho < theta.rho:
        return ('reject', eps, m_c, m_n, rho)
    return ('ok', G_cert(T, contacts, eps, m_c, m_n, z, rho))

def regrasp_plan(T0, T1, caging_cert):
    # 每条重抓边必须经过笼络中间态，保证取消/滑移时不掉落
    return shortest_path(G_grasp, T0, T1, require=in_caging(caging_cert))
```

### IP-128 QBC（QoS Budget Contract）

```python
def qos_budget_contract(graph, wcet, jitter, qos, critical_paths, safety_factor=1.2):
    contract = {}
    for v in graph.nodes:
        R = response_time(v, wcet[v], jitter[v], interference(v))
        if R > qos[v].deadline:
            return ('reject', 'node_deadline', v, R)
        contract[v] = R
    for pi in critical_paths:
        L = sum(wcet[v] + jitter[v] + blocking[v] for v in pi) + link_latency(pi)
        D = min(qos[v].deadline for v in pi)
        if L * safety_factor > D:
            return ('reject', 'path_deadline', pi, L, D)
        contract[pi] = (L, D, reliability(pi))
    return ('ok', contract)
```

### IP-129 TFC（Transform-Frame Certificate）

```python
def transform_frame_certificate(tf, frames_c, v_max, a_max, s_max, margin):
    if not is_tree(tf, frames_c):
        return ('reject', 'frame_graph_not_tree')
    E_tf = 0.0
    for path in contact_paths(tf, frames_c):
        for e in path:
            age = now() - tf.stamp(e)
            if age > a_max:
                return ('reject', 'stale_transform', e, age)
            E_tf = max(E_tf, v_max*age + s_max*v_max*tf.window(e) + tf.calib(e))
    if E_tf > margin:
        return ('reject', 'margin_not_dominant', E_tf, margin)
    return ('ok', chi=True, E_tf=E_tf)
```

### IP-130 ASC（Action-Semantics Contract）

```python
def preemption_safe_action_server(goal, skill, gcert, D_cancel, D_pre):
    if not goal.admissible(gcert):
        return ('abort', 'uncertified_goal')
    S_pre = certified_preemption_set(skill, gcert)   # 回退在 K 内且抓取保持/安全释放
    def on_cancel(x, t):
        if x in S_pre:
            return fallback(x)                       # hold 或 compliant release
        x_pre, tau = project_to_pre(x, S_pre, certified_geodesic)
        if tau > D_pre:
            return emergency_compliant_release(x)
        goto(x_pre)
        return fallback(x_pre)
    return ('ok', ActionServer(goal, on_cancel, feedback=timestamped_only))
```

### IP-131 XSC（eXecutor Safety Contract / 退化格）

```python
def mixed_criticality_executor(nodes, mode, fault_monitor):
    order = sort_by_criticality(nodes)   # safe > grasp > plan > cloud
    run(order, budget=mode.budget)
    f = fault_monitor.poll()
    if deadline_missed() or f is not None:
        new_mode = degradation_lattice.step(mode, f)
        mode = atomic_switch(new_mode, timeout=T_deg)
        assert invariant(mode) and risk(mode) <= risk(old_mode)
    return mode
```

### IP-132 SGC（System Graph Certificate）

```python
def system_graph_certificate(G_R, contracts, tf_cert, gcert, actions, lattice):
    if not contracts.all_critical_feasible:
        return ('reject', 'temporal_contract')
    margin = min(gcert.m_c, gcert.m_n_eff)
    if not tf_cert.chi or tf_cert.E_tf > margin:
        return ('reject', 'tf_or_margin', tf_cert.E_tf, margin)
    for a in actions:
        if not (a.preemption_safe and a.goal_admissible):
            return ('reject', 'action', a.id)
    for f in single_faults(G_R):
        if lattice.reach_safe(mode0, f) > T_deg:
            return ('reject', 'degradation', f)
    rho = empirical_system_robustness(perturb(timing, tf, contacts, faults))
    if rho < rho_min:
        return ('reject', 'robustness', rho)
    return ('ok', S_cert(G_R, contracts, tf_cert, gcert, actions, lattice, rho))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| DGC | O(m·LP + N_g·m) | O(m) | 力闭合 LP 精确、扰动球覆盖 |
| QBC | O(\|V\|·\|E\| + \|Π\|·\|π\|) | O(\|V\|+\|E\|) | WCET 保守、响应时间分析 sound |
| TFC | O(\|F_c\|·depth) | O(\|F\|) | 帧树性、时间戳单调、偏斜有界 |
| ASC | 预计算 O(\|X\|) + 取消 O(1) | O(\|S_pre\|) | 回退 ∈ K∩(G_cert 保持) |
| XSC | O(\|V\| log\|V\|) 每轮 | O(\|V\|+\|M\|) | 原子切换、风险单调 |
| SGC | O(\|Π\|+\|Fault\|·\|M\|+N·\|X\|) | O(\|V\|+\|M\|) | assume-guarantee 闭合 |

**正确性定理（DexROS System Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** `C_v`、`trans_e^wc` 为经硬件在环标定的 sound 上界，且监控开销已计入 `C_v`；**(A34)** tf 时间戳单调、时钟偏斜有界 `|s|≤s_max`；**(A35)** action 取消在 `S_pre` 内于 `D_cancel` 被兑现；**(A36)** 退化切换原子、安全监控与规划隔离。
则单步端到端安全概率
```
P_safe ≥ 1 - P(¬A_τ) - P(¬χ_F ∨ E_tf>margin) - P(¬A_pre)
          - P(G_cert 失效) - P(退化失效) - P(语义扰动越界)
```
（并集界，事件可不独立）。关键：**证书必须与其证据路径的时限/可靠性一起成立**；**时序误差必须被接触裕度支配**；**抢占与故障都走已认证的回退/退化路径**。

| 风险 | 等级 | 缓解 |

| tf 过期或时钟偏斜静默失效 | 高 | 龄期闸门 + 裕度支配 + 时间同步监测 |

| 认证/监控开销挤占实时预算 | 高 | 监控计入 WCET、最高关键性、独立进程看门狗 |

## 6. 本轮最大风险

**一句话**：把证书升级为 ROS 2 图级实时契约后，系统安全性**三重依赖 WCET/网络时延界的 soundness、tf 时间戳与帧树的一致性、以及抢占/退化回退的实时兑现**；而认证与监控自身又要消耗它所守护的实时预算，一旦时延界在真实硬件上被突破，或在抓取闭合中途发生未被 `S_pre` 覆盖的取消，所有下游接触证书会集体失效，导致灵巧手在“自认为已认证”的抓取里掉落或压碎物体——因此必须把监控开销计入 WCET、以硬件看门狗与笼络中间态兜底，宁可降级柔顺释放，绝不把“图上看起来可调度”当作“物理上按时刻达”。

# 第 56 轮产物 · 创新点清单 v32：DexROS-Cert（DGC×QBC×TFC×ASC×XSC×SGC）

> 承接第 55 轮语义-接触接地（SCG/WBV/SSF/SCC/SRS/CEB）。本轮把“单体控制证书”升级为“ROS 2 计算图上的实时契约体系”，并把灵巧手的接触拓扑、力闭合裕度与抢占安全纳入同一证书框架。核心思想：**证书是带时间条件的对象**——`φ` 只有在证据路径的时限/可靠性假设 `A_τ` 成立时才有效；**可部署性 = 抓取证书 × 时相契约 × 帧一致性 × 抢占安全 × 退化格**。
>
> IP 编号：IP-127~IP-132（共 6 个新增），并升级 IP-115/118/125 以携带 ROS 2 图级时间维度。

## 2. 关键算法 伪代码

### IP-127 DGC（Dexterous Grasp Certificate）

```python
def grasp_certificate(hand, obj, contacts, sigma, delta_g, theta):
    W = wrench_space([wrench_basis(p) for p in contacts])
    eps = dist_origin_boundary(W) / obj.wrench_scale
    m_c = min(surface_distance(p.point, obj.mesh) for p in contacts)
    m_n = min(normal_margin(p.normal, obj, p.point) for p in contacts)
    rho = robust_grasp_prob(contacts, delta_g, theta)
    z = sigma.project(hand.q)
    T = contact_topology(contacts, hand.links, obj.features)
    if eps < theta.fc or m_c < theta.c or m_n > theta.n or rho < theta.rho:
        return ('reject', eps, m_c, m_n, rho)
    return ('ok', G_cert(T, contacts, eps, m_c, m_n, z, rho))

def regrasp_plan(T0, T1, caging_cert):
    return shortest_path(G_grasp, T0, T1, require=in_caging(caging_cert))
```

### IP-128 QBC（QoS Budget Contract）

```python
def qos_budget_contract(graph, wcet, jitter, qos, critical_paths, safety_factor=1.2):
    contract = {}
    for v in graph.nodes:
        R = response_time(v, wcet[v], jitter[v], interference(v))
        if R > qos[v].deadline:
            return ('reject', 'node_deadline', v, R)
        contract[v] = R
    for pi in critical_paths:
        L = sum(wcet[v] + jitter[v] + blocking[v] for v in pi) + link_latency(pi)
        D = min(qos[v].deadline for v in pi)
        if L * safety_factor > D:
            return ('reject', 'path_deadline', pi, L, D)
        contract[pi] = (L, D, reliability(pi))
    return ('ok', contract)
```

### IP-129 TFC（Transform-Frame Certificate）

```python
def transform_frame_certificate(tf, frames_c, v_max, a_max, s_max, margin):
    if not is_tree(tf, frames_c):
        return ('reject', 'frame_graph_not_tree')
    E_tf = 0.0
    for path in contact_paths(tf, frames_c):
        for e in path:
            age = now() - tf.stamp(e)
            if age > a_max:
                return ('reject', 'stale_transform', e, age)
            E_tf = max(E_tf, v_max*age + s_max*v_max*tf.window(e) + tf.calib(e))
    if E_tf > margin:
        return ('reject', 'margin_not_dominant', E_tf, margin)
    return ('ok', chi=True, E_tf=E_tf)
```

### IP-130 ASC（Action-Semantics Contract）

```python
def preemption_safe_action_server(goal, skill, gcert, D_cancel, D_pre):
    if not goal.admissible(gcert):
        return ('abort', 'uncertified_goal')
    S_pre = certified_preemption_set(skill, gcert)
    def on_cancel(x, t):
        if x in S_pre:
            return fallback(x)
        x_pre, tau = project_to_pre(x, S_pre, certified_geodesic)
        if tau > D_pre:
            return emergency_compliant_release(x)
        goto(x_pre)
        return fallback(x_pre)
    return ('ok', ActionServer(goal, on_cancel, feedback=timestamped_only))
```

def mixed_criticality_executor(nodes, mode, fault_monitor):
    order = sort_by_criticality(nodes)   # safe > grasp > plan > cloud
    run(order, budget=mode.budget)
    f = fault_monitor.poll()
    if deadline_missed() or f is not None:
        new_mode = degradation_lattice.step(mode, f)

### IP-132 SGC（System Graph Certificate）

```python
def system_graph_certificate(G_R, contracts, tf_cert, gcert, actions, lattice):
    if not contracts.all_critical_feasible:
        return ('reject', 'temporal_contract')
    margin = min(gcert.m_c, gcert.m_n_eff)
    if not tf_cert.chi or tf_cert.E_tf > margin:
        return ('reject', 'tf_or_margin', tf_cert.E_tf, margin)
    for a in actions:
        if not (a.preemption_safe and a.goal_admissible):
            return ('reject', 'action', a.id)
    for f in single_faults(G_R):
        if lattice.reach_safe(mode0, f) > T_deg:
            return ('reject', 'degradation', f)
    rho = empirical_system_robustness(perturb(timing, tf, contacts, faults))
    if rho < rho_min:
        return ('reject', 'robustness', rho)
    return ('ok', S_cert(G_R, contracts, tf_cert, gcert, actions, lattice, rho))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DGC | O(m·LP + N_g·m) | O(m) | 力闭合精确、扰动球覆盖 |
| QBC | O(\|V\|·\|E\| + \|Π\|·\|π\|) | O(\|V\|+\|E\|) | WCET 保守、响应时间 sound |
| TFC | O(\|F_c\|·depth) | O(\|F\|) | 帧树性、时间戳单调、偏斜有界 |
| ASC | 预计算 O(\|X\|) + 取消 O(1) | O(\|S_pre\|) | 回退 ∈ K∩G_cert |
| XSC | O(\|V\| log\|V\|) 每轮 | O(\|V\|+\|M\|) | 原子切换、风险单调 |
| SGC | O(\|Π\|+\|Fault\|·\|M\|+N·\|X\|) | O(\|V\|+\|M\|) | assume-guarantee 闭合 |

**正确性定理（DexROS System Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** WCET/网络界经硬件在环标定且监控开销计入 `C_v`；**(A34)** tf 时间戳单调、偏斜有界；**(A35)** 取消在 `S_pre` 内于 `D_cancel` 兑现；**(A36)** 退化切换原子、监控隔离。则
```
P_safe ≥ 1 - P(¬A_τ) - P(¬χ_F ∨ E_tf>margin) - P(¬A_pre)
          - P(G_cert 失效) - P(退化失效) - P(语义扰动越界)
```
关键：**时相条件化**（证书必须连同证据路径时限成立）、**裕度支配**（`E_tf ≤ 接触裕度`）、**抢占/故障走已认证回退与退化路径**。

## 5. 本轮最大风险

**一句话**：DexROS-Cert 把证书从静态谓词升级为 ROS 2 图级实时契约，但其 soundness **三重依赖 WCET/网络时延界的保守性、tf 帧树与时间戳的一致性、以及抢占/退化回退的实时兑现**，而认证与监控自身又挤占它所守护的实时预算；一旦时延界在真实硬件上被突破或抓取闭合中途发生未覆盖的取消，下游接触证书会集体失效，灵巧手将在“已认证”的抓取中掉落或压碎物体——故必须以 **监控计入 WCET + 硬件看门狗 + 笼络中间态** 三重护栏，宁可降级柔顺释放，绝不把“图上可调度”当作“物理按时到达”。
