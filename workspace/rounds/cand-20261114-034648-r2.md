# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环；本轮灵感：「角色一致性」×「无刷电机」）

> R69 教会系统「去问」：把不确定性拆成 aleatoric 与 epistemic，前者收紧、后者用流匹配多模态策略显形，再用注视/探针/问句主动消解，并用流似然做标定不可吸收的第二意见。它回答的是「**我该向谁求证、还能问什么**」。但 R69 有一个从未被检验的前提：**被问的人、被驱动的身体、正在执行的策略，其身份是已知且稳定的**。它算的是「世界是什么」，却默认「这条证据属于谁、这个动作由谁执行、换手之后还是不是同一个角色」都不成问题。
>
> 现实部署里，这个前提最先坏：
> - 证据会**串台**：A 的回答被记到 B 头上，关节 3 的标定被套到关节 5，一个策略的能力估计被另一个策略的动作污染；
> - 身体会**换装**：无刷电机维修更换、减速器重装、关节重映射之后，「同一个角色」换了「同一个本体」，控制器不知道；
> - 更隐蔽的是，**无感 FOC 的控制律本身依赖电机内部参数**（`R_s、L_d、L_q、ψ_f/Ke、换相偏置`）。这些参数随温度与老化缓慢漂移，外部传感器残差却可能仍然很小——R68 以为「测量还准」，R69 以为「该去问世界」，而真正的病灶在**身体的身份**上。
>
> 本轮两个灵感正好补上这块：
> - **角色一致性**给出「身份」的正确形式化——不是外观不变，而是**在干预下仍可判别的不变量**（物理/行为/语义/指称四类）；它天然对应交接、换装、多人多策略、跨具身。
> - **无刷电机**给出身体身份的**可测物理锚点**——电参数与谐波指纹短期稳定、长期漂移；更妙的是，主动辨识所需的 d 轴小信号注入，正好是 R69「信息动作」在电气域的延伸：**激励也是一种可以认证、可以计价、可以审计的探询**。
>
> 核心命题：**不确定性除了「大小」（R68）与「可约性」（R69），还有「来源/归属」（provenance）。先把不确定性归因到世界/传感器/执行器/角色/模型五类之一，再选择处置：世界→交互求证，传感器→重标定，执行器→主动辨识+降额，角色→交接审计，模型→回滚重加权；归因不可信则做身份退避（κ 降额 + 冻结换手）。** 命名 **IDENT-RAS**（Identity-consistent, Drift-aware, Electromechanical-provenance, Non-transferable role-ledger, Trust-anchored Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这条不确定到底是谁的问题——是世界、是我的传感器、是我的身体，还是我认错了角色**」——**归因错了，再好的刹车和再好的提问都是用错药**。

## 0. 直觉与动机

**灵感 1（角色一致性 → 身份是干预下的不变量，而不是外观的像素）**
直觉：动画里的「角色一致性」常被误解为每一帧长得像；真正的要求是——换了画师、换了姿态、换了表情、甚至换了画风，观众仍能判别「这是同一个角色」。可判别性来自一组**受保护的不变量**（发色、伤疤、比例、口癖），而允许**受控的变化**（姿势、光照、情绪）。机器人系统同理：任务角色（「左腿髋关节」「主操作者」「当前主策略」）必须在一连串干预——交接、换装、重标定、交互、长时程漂移——之后仍可判别；否则系统会把「另一个实体的证据」当成「这个实体的证据」。这把 R69 的「证据纪律」推进了一层：R69 只要求多个证据源一致，却没问**这些证据是不是属于同一个实体**。身份不一致时，"多源一致"可以是多个错误源的一致。
形式化抓手：把角色拆成**类型（role contract）**与**实例（entity id）**。同一角色可以换本体（维修），但必须重新认证；同一本体也可以换角色（重映射），但不是「平滑混合一下」就行。这与编程里的类型/实例、数据库里的主键/外键同构。

**灵感 2（无刷电机 → 身体身份有可测量、可漂移、可被冒用的指纹）**
直觉：无刷电机的「身份」不玄学，它就写在电压方程和谐波里：`v_q = R_s i_q + L_q di_q/dt + ω_e ψ_f`（d 轴类似）。`R_s、L_d、L_q、ψ_f(≡K_e)、极对数 p、换相偏置 δ_c`，再加上齿槽转矩谐波 `{c_k}`、摩擦 `B_f`、齿隙 `β_backlash`，共同构成一个**短期稳定、长期随温度/老化漂移**的电身份指纹。工程上有两个关键事实：
1. **控制依赖身份**：无感 FOC 用反电动势估转子位置，位置估计直接吃 `ψ_f` 与 `δ_c`；参数错了，转矩/位置就系统性偏，而外部编码器/视觉可能完全看不出。
2. **身份可被主动激发**：给 d 轴注入小幅高频信号，可以在几乎不产生净转矩的前提下，让 `R_s、L_d、L_q、ψ_f` 在多个工作点上变得可辨识；低频正负转矩脉冲则能探齿隙与摩擦。这些激励**就是信息动作**，只不过探的不是世界，是身体。
由此得到一个重要的诊断学直觉：**电机参数漂移与外部负载变化在单一工作点上常常是秩亏的**（都表现为「同样电流下转矩变小」）；必须换工作点、换频率，才能把「身体变了」和「世界变了」分开。这正是 R69 缺失的「主动实验设计」，只是实验对象从人变成了自己的关节。

**灵感 3（归因先于处置 → R68/R69 是「身份已知」的边界情形）**
直觉：R68 的处方是「任何不确定 → 收紧」，R69 的处方是「epistemic → 去问」。两者都隐含一个**归因已完成**的假设：前者默认不确定来自测量/噪声，后者默认可约的不确定来自世界。可当病灶在电机身份或角色绑定时：
- 去「问世界」不会降低 `U_A`（执行器参数不确定），R69 的 VoI 是在**错误的模型类**上计算的，会把预算花在幻影上；
- 去「收紧」虽然安全，但会把一个可辨识、可修复的换装/漂移当成永久噪声，长期降额、效率塌陷；
- 最危险的是「平滑混合」：把 A 策略的积分项、B 电机的摩擦参数直接混在一起，产生慢性偏置，且**任何单通道残差都不会报警**。
因此本轮的理论姿态是：**R68 = 「来源=传感器、身份已知」的边界；R69 = 「来源=世界、身份已知」的边界；IDENT-RAS 必须先做来源路由，再分别退化为它们。** 新层必须是旧层的严格泛化，否则每加一层就多一个必须独立信任的黑箱。

**灵感 4（主动身份辨识 → 激励是信息动作，而且比提问更危险）**
直觉：R69 的信息动作是看/问/触，最坏后果是「问错」；R70 的身份探针是给电机注入电流/转矩脉冲，最坏后果是**在接触任务中直接诱发振动、过力、温升**。所以身份探针必须满足三条：与任务动作相同的 C-RAS-WM 认证、与 R69 共享的交互预算、以及「单次探针不得单独定案」的证据纪律。积极的一面是：辨识所需的信息量可以精确计价——在身份假设 `H_id` 上算 VoI，并且**只在被动观测秩亏时才主动激励**（能靠正常运行数据辨识就不额外注入）。这把「主动学习」从「到处戳」变成「只在不可辨识的方向上做最小激励」。

**灵感 5（角色一致性 ≠ 实体同一性 → 类型/实例分离与身份攻击面）**
直觉：一致性不是「永远不换」，而是「换得可追溯、可认证、可解释」。维修换电机是合法的（角色合同不变，实例变了）；未标定策略冒名已标定策略是攻击（实例没变，声明变了）；把账本回滚到「换装前」是攻击（历史被篡改）。因此需要：append-only 身份账本、制造公差 PUF（齿槽/反电动势谐波指纹）、双源交叉证据、以及**对用户讲的故事必须与账本一致**（叙事一致性审计）。但必须诚实：指纹可以被克隆、行为签名可以被模仿，所以**指纹只是证据，不是根信任**；关键动作仍需外部物理证据或人工确认。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（IDENT-RAS 总览）** IDENT-RAS = (IDL, CCC, BFP, PAR, RCH, RAS-WM††)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；账本与指纹参考更新都在实时环外）；
(ii) **先认证后处置**：任何 remedy（收紧/求证/激励/交接）执行前必须先给出 provenance 后验，禁止「边猜边治」；
(iii) **身份探针即信息动作**：BFP 激励纳入 R69 的 `𝒜_info`，共享交互预算并过 C-RAS-WM 认证；
(iv) **身份证据纪律**：单源证据只能更新似然、不得修改角色绑定 `β_t`，需 ≥2 个正交源（电指纹/行为签名/外部物理证明/人工确认）一致，否则 `U_id` 保持未消解并走身份退避。

**定义 311（来源格 Provenance Lattice）** 令 `P = {W, S, A, R, D}` 分别表示世界、传感器、执行器/身体、角色/代理、数据/模型。不确定性按来源分解：
`U = Σ_{p∈P} U_p + U_×`，其中 `U_p` 是「可由 p 类原因解释」的不确定性质量，`U_×` 是交互项（多因共谋）。处置映射 `ρ: P → {interact, calibrate, identify+derate, handover+audit, rollback+reweight}`。
注意：这不是 R69 的 ale/epi 二分——**那是「大小-可约性」，这里是「归属-处置」**；两者正交，拼成一张 5×2 的不确定性处置表（定义 323）。

**定义 312（角色账本 IDL）** `IDL_t = {(e, type, β_t, I_e, π_e, θ_e)}`：`e` 为实体 ID（策略 / 操作者 / 被交互对象 / 关节电机），`type ∈ {agent, human, object, actuator}`；`β_t` 为角色绑定（functional role → entity），要求**单射**（无别名、无一实体多主）；`I_e` 为不变式模板；`π_e` 为来源证明（签名 / 指纹 / 审计哈希）；`θ_e` 为可漂移参数。账本 append-only + Merkle 哈希链，实时环路只读，写操作在实时环外并需双源同意。

**定义 313（角色一致性 Character Consistency）** 对时间窗 `[t0,t1]` 与任意干预（交接、换装、交互、重标定），角色一致当且仅当四类不变式同时满足：
- **物理不变式**：`D_m(θ_e(t), θ_e(t0)) ≤ δ_e`（电机指纹漂移有界，漂移需可被温度/老化模型解释）；
- **行为不变式**：同一 `e` 的动作签名在角色合同 `C_role` 下统计不可区分（`MMD ≤ ε_b`）；
- **语义不变式**：对人/物体身份后验 `p(e|o) ≥ 1−ε_s`，且不被单次交互翻转；
- **指称不变式**：`β_t` 单射且跨时保持，交换两个角色会改变至少一个可观测不变量（可判别性）。
一致性分数 `CCS = min_类 (1 − 归一化违背量)`。要点：**角色一致性不是「外观不变」，而是「受保护的不变量不变、非保护的变化允许」**。

**定义 314（无刷电机电身份指纹 BFP）** `θ_m = (R_s, L_d, L_q, ψ_f≡K_e, p, δ_c, {c_k}, B_f, β_backlash)`。通过安全激励（d 轴高频小信号注入 / 低频正负转矩脉冲）得到回归 `ψ(ω,i,temp)`，用温度条件递推最小二乘 / UKF 估计。指纹距离 `D_m = (θ̂−θ_ref)ᵀ Σ_θ^{-1} (θ̂−θ_ref)`，`Σ_θ` 按温度分层。漂移模型：
`θ_m(t) = θ_m0 + Δ_th(T) + Δ_age(t) + Δ_fault`。
只有 `Δ_fault` 或换装产生**不可解释跳变**；正常漂移应被温度/时间模型吸收，但这种「吸收」只能在实时环外、且需双源同意（与 R68 引理 13 对偶）。

**定义 315（来源感知路由 PAR）** 给定残差三元组 `r = (r_ext, r_flow, r_act)`：`r_ext` 为 R68 外部残差，`r_flow` 为 R69 流似然异常 `Δa`，`r_act` 为电机模型电流/转矩预测残差。计算 `p(p|r) ∝ p(r|p) p(p)`，`p* = argmax p(p|r)`，路由：
- `W →` R69 MINT（看/问/触）；`S →` R68 COF（重标定）；`A →` BFP 主动辨识 + 力矩降额（**不向世界提问**）；`R →` RCH 交接审计 + IDL 核验；`D →` 冻结该模型 / 回滚 / 重加权；
- `H(p|r) > τ_prov` 或两通道结论冲突 → 身份退避（定义 319）。
**误归因代价** `M = E[cost(ρ(p̂)) − cost(ρ(p*))]`；本轮的全部价值在于压低 `M`。

**定义 316（角色一致交接 RCH）** 控制权从 `e_src` 切到 `e_dst` 时，除状态 `x` 外必须转移**身份耦合状态**：观测器偏置、积分项、摩擦/齿隙、能力与信任估计，全部按 `e_id` 打标签。交接连续性：若二者共享角色合同 `C_role`，则切换前后动作分布 `MMD ≤ ε_h`；否则视为**角色变更**，必须重新认证，而不是平滑混合。反例：把 A 策略的积分项直接交给 B 策略——「同一角色换了灵魂」，产生任何单通道都不报警的慢性偏置。

**定义 317（身份攻击面 ℰ_ident）** 电机换装/重放、指纹克隆、角色冒名（未标定策略自称已标定）、账本回滚、供应链替换、行为签名模仿。并入 `ℰ_IDENT = ℰ_FLUID × ℰ_ident`。反制：制造公差 PUF（齿槽/反电动势谐波）+ 签名账本 + 交叉证据；但**不把指纹当唯一根信任**。

**定义 318（身份探针安全与预算）** 身份激励 `g_id ∈ 𝒜_info` 扩展（d/q 轴注入幅度与频率、脉冲宽度），必须过 C-RAS-WM 认证：转矩脉动 `≤ Δτ_max`、温升 `≤ ΔT_max`、接触/负载敏感任务中禁触发；与 R69 的注视/探针/问句共享交互预算（`≤1 次/单位时间`）。身份探针的 VoI 定义在身份假设 `H_id` 上，且只在被动观测秩亏时启用（定义 320 / 引理 20）。

**定义 319（身份退避与 κ 降额）** 若身份不一致且在预算内不可消解：`κ = κ(CCS, D_m) ∈ (0,1]`，力矩/速度上限乘以 `κ`，冻结角色交接与学习写操作，退回「按最坏身份」的 R68 安全包络。`κ` **只降不升**，直到双源一致；`⇒` R68/R69 是「身份已知」边界。

**定义 320（身份证据纪律与被动优先）** 身份结论需 ≥2 个正交源（电指纹、行为签名、外部签名/物理 PUF、人工确认）一致；单源只更新似然。身份探针的启用条件：被动数据回归矩阵 `Ψ` 的条件数 `cond(Ψ) > τ_pe`（不可辨识）才主动激励；能被动辨识就绝不额外注入。这是「主动学习的节能版」。

**定义 321（漂移/故障分离的时序检验）** 对 `θ_m(t)` 与 `CCS(t)` 做温度条件 CUSUM / 变点检测：`Δ_th + Δ_age` 平滑可解释 → 正常漂移（更新参考，写操作在实时环外）；`Δ_fault` 阶跃 / 不可解释 → 身份故障。**标定层不得吸收身份故障**：参考更新只能来自慢时间尺度，且需双源同意。

**定义 322（证书 J_IDENT）** `J_IDENT = (J_FLUID, CCS_min, D_m_p95, H(p|r)_p95, handover_mmd, ledger_root_hash, ident_ver)`。Valid ⇔ `Valid(J_FLUID) ∧ CCS ≥ τ_ccs ∧ D_m ≤ τ_m ∧` 账本链完整 ∧ 身份探针未越界。

**定义 323（二维不确定性处置表）** 将 R69 的 `(ale, epi)` 与 R70 的 provenance 组合成 5×2 表，每格默认处置不同：
`A/ale`（齿槽转矩噪声）→ 前馈补偿；`A/epi`（电机参数未知）→ 主动辨识；`W/epi`（动作歧义）→ R69 交互；`R/epi`（角色归属歧义）→ 交接审计；`S/ale`（传感器噪声）→ 滤波；`S/epi`（标定偏置）→ R68 重标定；`D/epi`（模型错设）→ 回滚/重加权。**R68 只是 S 行，R69 只是 W 行**。

**定义 324（叙事一致性审计 VQAuditor-ID）** 系统的自我解释（「我为什么问这个/为什么换手/为什么降额」）必须与账本一致：谁在控制、哪台电机、哪个证据源、哪次认证。用可追溯 provenance 图；不一致即审计事件。这是「角色一致性」在**解释层**的对应物：不能对用户讲一个和账本矛盾的故事。

**定义 325（跨具身角色合同 C_role）** 任务角色（如「左腿髋关节」）与具体电机解耦：`C_role` 规定接口、能力边界与安全不变量；换装/跨具身时只换 `e_id`，角色合同不变。**角色一致性 ≠ 实体同一性**：同一角色可换本体（维修，需重新认证）；同一本体也可换角色（重映射，需核验指称）。这是「类型 vs 实例」的分离。

## 3. 推导

**引理 19（来源可辨识性）** 设残差对潜在原因的响应为 `r = J p + ε`，`J = ∂r/∂p`。若 `J` 列满秩，则来源后验局部可辨识，参数误差 `‖p̂−p‖ ≤ cond(J)‖ε‖`。若秩亏（典型：磁链 `ψ_f` 下降与外部负载上升在同一工作点都表现为「同电流、力更小」），则**任何被动观测都无法区分二者**；此时只有沿 `J` 行空间外的方向做主动激励才能恢复可辨识性。系：BFP 的 d 轴注入不是「更努力地看」，而是**专门去打破秩亏**——这解释了为什么 R68/R69 在此处必然失效。

**引理 20（电机身份的可辨识性与温度混淆）** 无刷电机稳态电压方程给出回归 `v_q − ω_e ψ_f = R_s i_q + L_q di_q/dt`。若任务长期 `ω_e ≈ 0`（静止保持）或 `i_q` 近似常数，则 `R_s` 与 `ψ_f` 的回归列近似共线，不能分别辨识，只能辨识其组合。持续激励条件：d 轴多频注入 + 至少两个工作点/转速。温度造成共模慢漂移 `ΔR_s = α_R ΔT`、`Δψ_f = α_ψ ΔT`，需联合温度状态估计（或引入热敏电阻/热模型）才能把 `ΔT` 与 `Δ_fault` 分开。系：**没有主动激励与温度建模，"换电机"和"电机变热"不可区分**。

**引理 21（角色交接的连续性）** 若 `e_src` 与 `e_dst` 共享角色合同且身份耦合状态被正确转移，则对 Lipschitz 策略，动作差 `≤ L_x‖x_src−x_dst‖ + L_s‖s_src−s_dst‖`，可压到 `≤ ε_h`。若角色合同不同，动作差下界为两角色的**最小动作间距**（role gap），此时平滑混合必然产生有偏轨迹。系：交接连续性的充要条件不是「状态相同」，而是「**角色合同相同 + 身份耦合状态已转移 + 指称单射**」。

**引理 22（模型误设下 VoI 的高估）** R69 的 VoI 只在世界模态假设 `M_W` 上计算。若真实主导来源是执行器 `A`，则对任意信息动作 `g`，`H(M_W|o) − E[H(M_W|o,y)]` 可以很大，但 `U_A` 对 `g` **不变**，故真实可获收益 `VoI_true(g) ≤ VoI_R69(g)`，缺口由 `U_A` 项给出。当 `U_A` 主导时，`VoI_true − c ≤ 0` 而 `VoI_R69 − c > 0`，系统会**过度提问**。系：来源路由必须先于 VoI；否则 R69 的「问」是在给错误的病因开药。

**定理 18（来源感知严格包含 R68/R69）** 在 A99–A101 下，且当来源后验熵超过阈值时退化为候选处置中**最保守**者，IDENT 的期望风险 `≤ min(R68, R69)`。当 `p = W` a.s. 时与 R69 逐指令相同；当身份已知且 `p = S` 时与 R68 逐指令相同。证明要点：校准后验下 `ρ(p̂)` 的期望代价不超过任一固定处置；不确定时取 min 保证不劣于最保守边界；`κ` 单调不升故安全侧不被削弱。因此 R68/R69 是本轮的两个退化面，而不是被替代的旧版本。

**定理 19（身份退避的安全性与无突变）** 身份不一致时 `κ` 降额 + 冻结换手，使电机身份误差诱发的转矩误差 `≤ κ·Δτ_max`；`κ` 在双源一致前单调不升；认证前缀仍落在 R68 安全包络内；角色变更走重新认证而非平滑混合 ⇒ 控制连续、无突变，且安全侧不弱于 R68。系：身份退避是 R68「λ_floor」在身份维度的单调镜像（`κ` 对应 `λ`，只收紧）。

**定理 20（双源身份证据的投毒上界）** 单源身份采纳的错误率 `≥ δ_id`（冒名/克隆）。采用 `k` 个正交源多数一致，各源欺骗相关 `ρ_c < 1`，则错误采纳率 `≤ δ_id·ρ_c^{k−1} + ε_σ`。但必须诚实：**行为签名与策略本身强相关，不是真正交源**；只有电 PUF 与外部物理证据近似正交。因此 `k` 的有效值应小于名义源数，关键动作仍需人确认。系：身份安全不能只靠「多问几个模型」，必须引入**非模型来源**的物理证据。

## 6. 本轮最大风险

**一句话**：IDENT-RAS 的全部安全性押在「身份账本与电机指纹模型没有被标定层同化」这一前提上——**若『角色不一致』可以被解释成『正常温漂/老化』并被账本自己盖章，系统就会更自信地错认自己的身体与角色；更糟的是，辨识身份所需的主动激励本身会注入转矩脉动与热负载，证明『我是谁』的动作可能先让系统失稳**。

**次级风险与缓解**：
1. **指纹克隆 / 供应链替换** → 制造公差 PUF + 外部物理证据 + 人工确认，绝不把电指纹当唯一根信任（定理 20 的诚实边界）；
2. **对称/同构角色不可辨识**（两个行为与电参数都相同的关节）→ 主动探针 + 指称约束 + 操作时序；不可辨识时冻结换手而非猜测；
3. **温度混淆** → 引理 20 的多工作点激励 + 联合热状态估计，禁止单工作点定身份；
4. **来源后验错设** → E304/E305 校准 + 熵超阈值即退最保守处置，永不「自信地错」；
5. **实时账本延迟/一致性问题** → append-only + 实时只读缓存 + 写操作全部移出实时环；
6. **跨具身过度泛化** → 角色合同 `C_role` 显式建模能力边界，换本体必须重新认证，不把「角色相同」当成「本体相同」。

| `r = (r_ext, r_flow, r_act)` | 三通道残差：R68 外部 / R69 行为似然 / 机电模型 |
| `p(p|r)` | 来源后验；`H(p|r) > τ_prov` 即身份退避 |
| `κ(CCS, D_m) ∈ (0,1]` | 身份退避降额因子；只降不升（对应 R68 的 `λ_floor`） |
| `M = E[cost(ρ(p̂)) − cost(ρ(p*))]` | 误归因代价（本轮要压低的量） |
| `J_IDENT` | 证书：J_FLUID + CCS + D_m + 来源熵 + 交接 MMD + 账本根哈希 |

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** `IDENT-RAS=(IDL,CCC,BFP,PAR,RCH,RAS-WM††)`；零学习写操作继承；先认证后处置；身份探针即信息动作（共享预算 + C-RAS-WM 认证）；单源证据不得改角色绑定，需 ≥2 正交源一致。

**定义 311（来源格）** `P={W,S,A,R,D}`；`U=ΣU_p+U_×`；处置映射 `ρ`：世界→交互，传感器→重标定，执行器→辨识+降额，角色→交接审计，模型→回滚。与 R69 的 `(ale,epi)` 正交，拼成 5×2 处置表。

**定义 312–313（IDL 与角色一致性）** 账本 append-only + Merkle 链、实时只读；角色一致 = 物理（指纹漂移有界）/ 行为（动作签名 MMD ≤ ε_b）/ 语义（身份后验 ≥ 1−ε_s）/ 指称（`β_t` 单射且可判别）四类不变式同时成立；`CCS` 取最小值。

**定义 314（BFP 电身份指纹）** `θ_m` 由安全激励下的温度条件 RLS/UKF 估计；`D_m` 马氏距离；漂移拆成温度/老化/故障三项，只有不可解释跳变算身份故障。

**定义 315（PAR 来源路由）** `p(p|r) ∝ p(r|p)p(p)`；按 `argmax` 分诊；熵超阈值或通道冲突 → 身份退避；以误归因代价 `M` 为目标。

**定义 316（RCH 交接）** 转移身份耦合状态并打 `e_id` 标签；共享角色合同且切换前后动作 MMD ≤ ε_h 才算交接，否则视为角色变更、重新认证；禁止把不同角色的状态平滑混合。

**定义 317（身份攻击面）** 换装/重放、指纹克隆、冒名、账本回滚、供应链；`ℰ_IDENT=ℰ_FLUID×ℰ_ident`；PUF + 签名账本 + 外部物理证据；指纹不是唯一根信任。

**定义 318–320（探针安全/退避/证据纪律）** 激励受 `Δτ_max、ΔT_max`、接触约束与共享预算约束；秩亏（`cond(Ψ)>τ_pe`）才主动激励；身份不一致且不可消解 → `κ` 降额 + 冻结换手；单源只更新似然。

**定义 321（漂移/故障分离）** 温度条件 CUSUM/变点；平滑可解释 = 正常漂移（参考更新在实时环外，需双源）；阶跃/不可解释 = 身份故障；标定层不得吸收身份故障。

**定义 322–326（证书/二维表/审计/角色合同/保证）** `J_IDENT` 并入 CCS、D_m、来源熵、交接 MMD、账本哈希；5×2 处置表（R68=S 行，R69=W 行）；VQAuditor-ID 审叙事一致性；`C_role` 分离类型与实例；A99–A101 下风险 `≤ min(R68,R69)`，归因错误时由 `κ` 与双源纪律上界。

## 4. 推导

**引理 19（来源可辨识性）** `r = J p + ε`。`J` 列满秩 ⇒ 来源局部可辨识，误差 `≤ cond(J)‖ε‖`；秩亏（如 `ψ_f` 下降 vs 外部负载上升）⇒ 被动观测不可区分，必须沿 `J` 行空间外方向主动激励。系：R68/R69 在该情形必然失效，BFP 是打破秩亏的最小实验。

**引理 20（电机身份可辨识性与温度混淆）** 静止/恒流时 `R_s` 与 `ψ_f` 回归列共线，只能辨识组合；需 d 轴多频注入 + 多工作点（PE）。温度共模 `ΔR_s=α_RΔT, Δψ_f=α_ψΔT` 需联合热状态估计才能与 `Δ_fault` 分离。系：没有主动激励与温度建模，「换电机」与「电机变热」不可分。

**引理 21（角色交接连续性）** 共享角色合同 + 正确转移身份耦合状态 ⇒ 动作差 `≤ L_x‖Δx‖+L_s‖Δs‖ ≤ ε_h`；合同不同 ⇒ 动作差下界为 role gap，平滑混合必有偏。系：交接连续性 = 合同相同 + 状态已转移 + 指称单射。

**引理 22（模型误设下 VoI 的高估）** R69 的 VoI 只在 `M_W` 上算；若真实来源为 `A`，则 `U_A` 对任意 `g` 不变，`VoI_true ≤ VoI_R69`，缺口由 `U_A` 给出；`U_A` 主导时 `VoI_true−c≤0` 而 `VoI_R69−c>0` ⇒ 过度提问。系：来源路由必须先于 VoI。

**定理 18（来源感知严格包含 R68/R69）** A99–A101 下且熵超阈值时取最保守处置，IDENT 期望风险 `≤ min(R68,R69)`；`p=W` 时与 R69 逐指令相同，`p=S` 且身份已知时与 R68 逐指令相同。R68/R69 是两个退化面。

**定理 19（身份退避的安全性与无突变）** `κ` 降额 + 冻结换手使转矩误差 `≤ κ·Δτ_max`；`κ` 单调不升；认证前缀仍在 R68 包络内；角色变更走重新认证 ⇒ 控制连续、无突变、安全不弱于 R68。`κ` 是 `λ_floor` 在身份维度的镜像。

**定理 20（双源身份证据投毒上界）** 单源错误率 `≥ δ_id`；`k` 个正交源、欺骗相关 `ρ_c<1` 时错误率 `≤ δ_id·ρ_c^{k−1}+ε_σ`。但行为签名与策略强相关，只有电 PUF 与外部物理证据近似正交，关键动作仍需人工确认。

## 7. 本轮最大风险

**一句话**：IDENT-RAS 的安全性押在「身份账本与电机指纹模型没有被标定层同化」上——**若『角色不一致』被解释成『正常温漂/老化』并由账本自己盖章，系统会更自信地错认身体与角色；而辨识身份所需的主动激励本身会注入转矩脉动与热负载，证明『我是谁』的动作可能先让系统失稳**。

**次级风险与缓解**：指纹克隆/供应链（PUF + 外部物理证据 + 人工确认，不把指纹当根信任）；对称角色不可辨识（主动探针 + 指称约束 + 不可辨识即冻结换手）；温度混淆（多工作点激励 + 联合热估计）；来源后验错设（E304/E305 校准 + 熵超阈值退最保守）；账本实时性（append-only + 只读缓存 + 写操作移出实时环）；跨具身过度泛化（`C_role` 显式建模能力边界）。
