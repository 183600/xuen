# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；新灵感循环第 1 轮；本轮灵感：「双足机器人」×「最优控制」）

> 第 60 轮把「场景语义 SSM → 认知意图 CIEC → 阻抗编译 EEIS → 闭环执行 CLEP → 证据 EV-exec」串成了认知驱动的场景落地闭环，并用 EPIR 保证 ROS 消息因果性、用 PCE++++ 管理四维预算。但它仍有**三个根本局限**：
> 1. **静态阻抗点无法表达混合欠驱动动力学**：第 60 轮的 `K_safe` 是一个准静态参数点；双足运动却是「连续摆动 + 落地冲击 + 接触模式切换」的混合系统。安全不是「某个 K 是否落在区间内」，而是「当前状态是否存在一条未来可行、代价有界的接触时序与落步序列」。
> 2. **场景/意图只做了局部编译，没有预测性代价**：SSM 给先验、CIEC 锁约束，二者本质上仍是反应式的；系统无法回答「现在多走一步，是否会在两步后失稳」。最优控制能提供 lookahead 与 cost-to-go，但实时 OCP 的非凸性、计算延迟和模型利用又会引入新的失效模式。
> 3. **证据层只校验「执行合规」，不校验「计划可行/接触时序正确」**：EV-exec 记录「执行了什么」，却不记录「接触事件是否按预测发生、计划是否仍在可行核内、最优性证书是否还有效」。接触调度一旦错位，证据链仍然“合规”，但系统已经不安全。

## 0. 直觉与动机

**灵感 1（双足机器人 → 混合接触调度 HCS）**
直觉：双足走路不是一条连续轨迹，而是一连串接触模式的拼接：左脚支撑 → 右脚离地 → 右脚落地 → 左脚离地……每一次落地都是一个**离散事件**，伴随冲击与状态重置。把「接触时序 σ」当作一等公民，而不是最优控制内层的附属变量。
关键洞见：第 60 轮的 `K_safe` 是「肌肉张力」，HCS 的 `σ` 是「骨骼时序」；时序错了，阻抗点再准也会在错误的时刻接触或离地。双足安全的第一性问题不是「选哪个 K」，而是「在什么时刻、用哪只脚、以什么冲击接触」。

**灵感 2（最优控制 → 最优可行核 OVK）**
直觉：安全不是「当前这个 K 是否安全」，而是「从这个状态出发，是否存在一条未来可执行、代价有界的轨迹」。这正是最优控制的值函数与可行核：`V(x)` 越小，说明未来越“有余地”；`V(x) ≤ α` 的状态集合就是代价有界的可行域。
关键洞见：把安全集从**参数空间**搬到**状态-代价空间**——`V_α = {x | 存在 σ,u 使 J ≤ α 且满足约束}`；阻抗编译不再独自决定安全，而是只在最优计划诱导的「鲁棒管」内选 `K`。安全由「可行核 + 管」保证，阻抗只是管内的低层实现。

**灵感 3（融合 → 场景-混合先验 SHP + 意图代价整形 ICS）**
直觉：场景决定「可能怎么接触」，意图决定「偏好哪条轨迹」。楼梯场景先验给出「抬脚更高、双支撑更长」的接触调度；「轻一点」不应把 `K_p` 硬改成 0.5，而应提高峰值接触力在代价中的权重；「稳一点」应提高 CoM/角动量偏差与接触力变化率的权重。
关键洞见：**场景是混合模式的先验，意图是代价泛函的权重，安全约束是二者都不能触碰的硬边界**。这把第 60 轮的「场景→K、意图→约束」升级为「场景→σ 先验、意图→β 代价」；静态约束表退化为代价整形的一个特例，系统从“查表执行”变成“在安全可行域内做偏好排序”。

**灵感 4（实时性 → 随时最优证书 AOC + 接触调度对账 CSR）**
直觉：双足 OCP 不可能每次都在毫秒级求出全局最优。诚实的契约不是「我最优」，而是「我可行、我的次优界是多少、这个证书在多长时间内有效」。一旦接触事件与预测不符，证书立即失效并触发重规划。
关键洞见：**把最优性证书拆成「安全证书 `C_safe`」与「性能证书 `C_opt`」双轨**：安全只依赖可行性、约束裕度与鲁棒管；最优性只影响性能与预算。执行后用接触事件序列对账预测的接触调度，失配即失效。这样「最优」永远不会被误当成「安全」。

**灵感 5（合流 → PIVOT 闭环 + PCE-OC 预算）**
直觉：SHP 给接触调度先验 → ICS 给代价 → OVK 给可行核 → OCP 在核内求解 → AOC 签发双轨证书 → 低层全身 QP/阻抗执行 → CSR 对账接触事件 → 更新场景先验与值函数缓存。形成 **「场景→调度→代价→可行核→最优计划→证书→执行→接触证据→场景」** 的预测性闭环。
关键洞见：**最优性是一种计算资源**。PCE-OC 在原有 `B_exec` 上新增 `B_ocp`（求解时间/迭代）、`B_hyb`（接触模式分支）、`B_rob`（鲁棒性/证伪采样）。任一预算耗尽都必须回退到**已认证的可行策略**，而不是回退到“更快的近似最优”。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（混合接触模型与调度 HCS）** 双足混合系统 `H = (M, E, f, Δ, G, W)`。其中：
- **模式集**：`M = {double_support, left_stance, right_stance, flight, ...}`；状态 `x ∈ X ⊂ R^n`（n 为广义坐标+速度维数），输入 `u ∈ U ⊂ R^m`。
- **连续动力学**：`ẋ = f_m(x, u)`，`x ∈ X_m`。
- **离散转移**：`e = (m → m') ∈ E`，守卫 `G_e ⊂ X_m`，重置映射 `Δ_e: X_m → X_{m'}`（落地冲击、脚交换、接触点更新）。
- **接触约束**：接触力旋量 `w_m ∈ W_m`，`W_m` 编码单边约束、摩擦锥、CoP 位于支撑多边形内、关节力矩上限。
- **接触调度**：`σ = ((m_0, t_0), (m_1, t_1), ..., (m_H, t_H))`，`0 = t_0 < t_1 < ... < t_H = T`，相邻模式由 `E` 连接，且在 `t_k` 时刻轨迹穿越 `G_{e_k}`。
- **可行调度集**：`Σ_feas = {σ | ∃u，使混合轨迹满足动力学、重置、守卫与接触约束}`。

HCS 的核心不是“再解一次 OCP”，而是把 `σ` 从内层变量提升为**可采样、可先验、可对账、可认证**的外层对象。

**定义 162（最优可行核 OVK）** 给定 `H`、场景混合参数 `φ`、意图代价 `β`、扰动集 `W`、时域 `T`：
```
J_σ(x_0; u, φ, β) = Φ(x(T)) + ∫_0^T l(x(t), u(t), m(t); β) dt
V_{φ,β}(x_0) = min_{σ∈Σ_feas} min_u max_{w∈W} J_σ(x_0; u, φ, β)
```
`α`-最优可行核定义为：
```
V_α(φ, β) = { x_0 | V_{φ,β}(x_0) ≤ α，且存在 σ∈Σ_feas、u 使
              x(t)∈X_safe、w_m(t)∈W_m、x(T)∈X_goal }
```
鲁棒管与阻抗管：
```
T_ρ(t) = { x | ||x - x*(t)||_{P(t)} ≤ ρ(t) }
K_tube(t) = { K | ∀x∈T_ρ(t), ∀w∈W: x^+ = f_σ(x, K, w) ∈ T_ρ(t+Δt)，接触约束成立 }
K_safe^PIVOT(t) = K_safe^scene(t) ∩ K_tube(t)
```
因此，第 60 轮的 `K_safe` 是 `T_ρ` 退化为一个点时的特例；PIVOT 把「阻抗点安全」升级为「计划诱导的鲁棒管安全」。

**定义 163（意图代价整形 ICS）** 意图空间 `I`，代价基
```
b(x,u,m) = [1, ||u||², ||v-v_ref||², F_peak², ||Ḟ||², ||L||², ||p_com-p_com^ref||², smoothness]
```
意图映射 `B: I → (β_I, C_hard(I))`，其中 `β_I ∈ R_+^d`，代价 `l = β_I^T b`，硬约束 `C_hard(I)` 满足：
```
∀I: C_hard(I) ⊆ C_hard^base        （只允许收紧，绝不允许放松）
```
偏好序 `≼_I` 由 `J` 诱导；安全保持条件为 `β_I ≥ 0` 且 `C_hard(I) ⊆ C_hard^base`。若 `I'` 比 `I` 更保守，则要求 `C_hard(I') ⊆ C_hard(I)`，且 `β_{I'}` 在安全相关分量上逐项不小于 `β_I`。静态表 `ϕ(I) → (v_max, K_p, F_max)` 是 ICS 的硬约束特例；ICS 额外允许“轻/稳/快/省”在安全域内连续折中。

**定义 164（场景-混合先验 SHP）** 场景 `z` 不再只给阻抗先验，而给混合模式先验：
```
π_scene(σ, φ | z) = P(σ | z) · p(φ | z)
φ = (μ, k_t, h_t, τ_d, ρ_dist, ...)
```
其中 `P(σ|z)` 是定义在**调度模板库** `Σ_z` 上的分布（如楼梯→交替抬脚模板，湿滑→短步+低 CoM 模板，碎石→高鲁棒裕度模板）；`p(φ|z)` 是摩擦、地形刚度、高度误差、时延与扰动半径的先验。接触证据 `E` 到达后：
```
P(σ, φ | z, E) ∝ P(E | σ, φ) · π_scene(σ, φ | z)
```
第 60 轮的 `π_scene(K|z)` 被替换为「先采样 `(σ,φ)`，再由 OVK/OCP 生成 `K_tube`」；场景先验从“阻抗分布”升级为“混合模式 + 动力学参数分布”。

**定义 165（随时最优证书 AOC）** 双轨证书
```
C_ocp = (C_safe, C_opt, C_val)
C_safe = (feas, m_con, ρ_rob, t_valid, σ_hash, x_tube_hash)
C_opt  = (J_ub, J_lb, ε_opt, scope),  ε_opt = (J_ub - J_lb) / max(|J_ub|, ε_0)
C_val  = (A66–A72, model_version, falsification_report, timestamp)
```
- `feas ∈ {0,1}`：当前 incumbent 是否满足全部硬约束与接触约束。
- `m_con = min_t 约束裕度`；`ρ_rob` 为鲁棒管裕度；`t_valid = min(t_next_guard, t_cert_horizon, t_model_valid)`。
- `scope ∈ {local, global, empirical}`：下界 `J_lb` 的可信范围；无严格下界时只能签发 `empirical`，不得用于安全门控。
- **签发规则**：仅当 `feas=1 ∧ m_con≥0 ∧ ρ_rob≥ρ_min ∧ t_valid≥τ_react` 时 `C_safe` 有效；`C_opt` 只用于性能与预算决策，**永远不能覆盖 `C_safe`**。
- **随时单调性**：`J_ub` 随迭代不增、`J_lb` 不降、`ε_opt` 不增；求解被中断时，最后一个可行 incumbent 的安全证书仍在其 `t_valid` 内有效；否则回退 `π_safe`。

**定义 166（接触调度对账 CSR）** 预测事件序列 `Ê = {(τ_i, m_i, foot_i, Ĵ_i, p̂_i)}`，观测事件序列 `E = {(t_i, m_i, foot_i, J_i, p_i, slip_i)}`。失配度：
```
d_σ(E, Ê) = min_alignment [ w_t · Σ|t_i-τ_i|/T
                          + w_J · Σ||J_i-Ĵ_i||/(||Ĵ_i||+ε)
                          + w_m · edit(m_seq, m̂_seq) ]
```
硬失配：滑移 `slip_i=1`、漏接触、接触提前/滞后超过 `τ_event`、接触力旋量越出摩擦锥。触发规则：`d_σ > τ_σ` 或任一硬失配 ⇒ 证书失效并在一个控制周期内重规划。`EV-contact` 扩展第 60 轮的 `EV-exec`，EPIR 的 `seq_id + timestamp + hash` 机制继续适用。

**定义 167（PCE-OC 预算）** `B_oc = (B_ocp, B_hyb, B_rob, B_exec)`：
- `B_ocp = (t_solve_slack, iter_slack, warm_start_quality)`：最优控制求解预算。
- `B_hyb = (branch_budget, switch_budget)`：接触模式分支与切换次数预算。
- `B_rob = (falsification_samples, tube_margin)`：鲁棒性证伪采样与管裕度预算。
- `B_exec = (WCET_slack, Bus_bw_slack, Thermal_slack, Prio_headroom)`：第 60 轮执行预算。
```
cost_oc = λ_ocp·solve_time + λ_hyb·branches + λ_rob·samples + λ_exec·exec_cost
voi_oc(π) = VOI_meta_pessimistic(π) - cost_oc(π)
```
降级优先级：**安全 > 可行性 > 最优性**。`B_ocp` 耗尽 ⇒ 返回 incumbent；若 `C_safe` 无效 ⇒ `π_safe`。`B_hyb` 耗尽 ⇒ 固定保守调度（双支撑/短步）。`B_rob` 耗尽 ⇒ 放大 `ρ`、降速、增加双支撑。`B_exec` 耗尽 ⇒ 第 60 轮降级。

**定义 168（PIVOT 算子）** `PIVOT(M, scene, intent, x_0)`：
```
① SSM.update → z；SHP → top-k (σ, φ)
② ICS → β_I, C_hard(I)
③ OVK → 载入 V̂，检查 x_0 ∈ V_α；若不在核内，先生成恢复落步
④ Anytime hybrid OCP over top-k σ → incumbent (x*, u*, σ), J_ub, J_lb
⑤ AOC → C_safe, C_opt；C_safe 无效则 π_safe 回退
⑥ EEIS.compile_tube → K_tube；dispatch(x*, u*, σ, K_tube, C_ocp)
⑦ Execute：全身 QP + CBF 安全滤波 + 阻抗跟踪
⑧ CSR → d_σ；失配则用更新后的后验重规划
⑨ EPIR.append(EV-contact, C_ocp)；更新 SHP 与 V̂ 缓存
⑩ Return (z, σ, x*, K_tube, C_ocp, EV-contact, status)
```
PIVOT 的三层时标：10–20 Hz 做 `σ`/OCP/证书，100–200 Hz 做质心 MPC/值函数跟踪，1 kHz 做全身 QP + 安全滤波 + 阻抗。`t_valid` 必须覆盖至少一个“规划-执行”时标周期。

### IP-161 HCS（混合接触调度）

```python
class HybridContactScheduler:
    def __init__(self, hybrid, templates):
        self.H = hybrid
        self.templates = templates

    def sample_schedules(self, z, shp, k=3):
        dist = shp.schedule_distribution(z)
        return top_k(dist, k)

    def check_schedule(self, sigma, x0, phi):
        for (m, t) in sigma:
            if not self.H.mode_valid(m, phi):
                return False
        return self.H.contact_consistency(sigma, x0, phi)

    def guard_sequence(self, sigma):
        return [(self.H.guard(e), self.H.reset(e))
                for e in self.H.edges(sigma)]
```

### IP-162 OVK（拟合值迭代/可行核）

```python
class OptimalViabilityKernel:
    def __init__(self, hybrid, alpha, gamma=0.99):
        self.H = hybrid
        self.alpha = alpha
        self.gamma = gamma
        self.V_hat = None

    def fit(self, sampler, schedules, beta, phi, iters=200):
        X = sampler.states()
        for _ in range(iters):
            targets = []
            for x in X:
                best = float("inf")
                for sigma in schedules:
                    for u in self.H.sample_inputs(x, sigma, phi):
                        x_next, c = self.H.step(x, u, sigma, phi)
                        best = min(best, c + self.gamma * self.V_hat(x_next))
                targets.append(best)
            self.V_hat = self.fit_regressor(X, targets)

    def in_kernel(self, x, phi, beta):
        return self.V_hat(x) <= self.alpha

    def induce_tube(self, x_star, rho, phi, sigma):
        return RobustTube(x_star, rho, phi, sigma)
```

### IP-163 ICS（意图代价整形）

```python
class IntentCostShaper:
    def __init__(self, beta_basis, hard_base):
        self.beta_basis = beta_basis
        self.hard_base = hard_base

    def shape(self, intent):
        beta = self.beta_basis[intent]
        hard = self.hard_constraints[intent]
        if not hard <= self.hard_base:
            raise SafetyViolation("intent must not relax base constraints")
        return beta, hard

    def cost(self, x, u, m, beta):
        b = feature_basis(x, u, m)
        return float(beta @ b)
```

### IP-165 AOC（随时最优证书）

```python
def anytime_hybrid_ocp(x0, schedules, phi, beta, t_budget):
    incumbent = None
    lower_bounds = []
    t0 = now()
    for sigma in schedules:
        solver = HybridOCPSolver(x0, sigma, phi, beta)
        while now() - t0 < t_budget and not solver.converged():
            solver.step()
            if solver.has_feasible_incumbent():
                incumbent = argmin_cost(incumbent, solver.incumbent())
            lower_bounds.append(solver.lower_bound())
        if incumbent is not None and lower_bounds:
            J_lb = min(lower_bounds)
            eps = (incumbent.J - J_lb) / max(abs(incumbent.J), 1e-6)
            cert = make_certificate(incumbent, J_lb, eps, solver, scope="local")
            if cert.C_safe.valid:
                return incumbent, cert
    return incumbent, make_fallback_certificate()
```

### IP-166 CSR（接触调度对账）

```python
def reconcile_contacts(predicted, observed, w, tau_sigma, tau_event):
    align = dtw(predicted, observed, cost=event_distance)
    d_sigma = (w.t * align.time_error / horizon +
               w.J * align.impulse_error +
               w.m * align.mode_edit)
    hard = any(e.slip or e.missed or e.late > tau_event for e in observed)
    invalid = hard or d_sigma > tau_sigma
    return d_sigma, hard, invalid, align
```

### IP-168 PIVOT（预测性最优闭环）

```python
def pivot_loop(M, scene, intent, x0):
    z = M.ssm.update(M.telem_force, M.telem_pos)
    sigmas = M.hcs.sample_schedules(z, M.shp, k=3)
    beta, hard = M.ics.shape(intent)

    if not M.ovk.in_kernel(x0, M.shp.phi(z), beta):
        sigmas = [M.hcs.recovery_schedule(x0, z)] + sigmas

    plan, cert = anytime_hybrid_ocp(x0, sigmas, M.shp.phi(z), beta, M.budget.t_ocp)
    if not cert.C_safe.valid:
        plan = M.safe_fallback.policy(x0)
        cert = M.safe_fallback.certificate()

    tube = M.ovk.induce_tube(plan.x, cert.C_safe.rho_rob, M.shp.phi(z), plan.sigma)
    K_tube = M.eeis.compile_tube(tube, hard)
    dispatch(plan.x, plan.u, plan.sigma, K_tube, cert)

    telemetry = wait_contact()
    ev = build_contact_evidence(telemetry, plan, cert)
    d_sigma, hard_bad, invalid, _ = reconcile_contacts(
        plan.events, ev.events, M.csr_w, M.tau_sigma, M.tau_event)
    M.epir.append(ev, cert_hash=cert.hash)

    if invalid:
        M.shp.update_from_contact(ev, z)
        return pivot_loop(M, scene, intent, telemetry.x)

    M.shp.update_from_contact(ev, z)
    M.ovk.cache_update(plan.sigma, plan.x, cert.C_opt)
    return z, plan, K_tube, cert, ev, "ok"
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性/指标 |
|---|---|---|---|
| HCS | 最坏 `O(|M|^H)`；先验 top-k 下 `O(k·H)` | `O(H)` | 可行调度召回 ≥ 90%，模式切换抖动 −50% |

**条件性假设 A66–A72**：
- **A66（混合模型保真）**：`||f_actual − f_model|| ≤ ε_f`，重置误差 `≤ ε_Δ`，接触事件观测延迟 `≤ δ_e`。
- **A67（场景先验校准）**：真实 `(σ, φ)` 以至少 `1−α` 概率落在 `π_scene` 的高密度区，先验误配不超过 `ε_prior`。
- **A68（随时求解器）**：求解器返回可行 incumbent 与**可验证**下界 `J_lb`；若只有启发式下界，则证书 scope 只能是 `empirical`，不得用于安全门控。
- **A69（意图安全分离）**：`C_hard(I) ⊆ C_hard^base` 对所有 `I` 成立，`β_I ≥ 0`；意图只改变软代价或收紧硬约束。
- **A70（接触可观）**：足端接触事件可检测，延迟 `≤ δ_e`；冲量与 CoP 测量误差 `≤ ε_J`。
- **A71（回退不变性）**：`π_safe` 从回退集内任意状态出发，对 `∀w∈W` 保持 `x(t)∈X_safe`；预算消耗单调。
- **A72（值函数近似）**：`||V̂ − V||∞ ≤ ε_V`，且 `V_α` 按 `ε_V/α` 膨胀后仍被 `X_safe` 包含。

**条件性定理（PIVOT-Safe）**：
1. **可行核安全性**：若 A66–A72 成立、`x_0 ∈ V_α`、`C_safe` 有效且安全滤波 QP 可行，则 PIVOT 在 `[t_0, t_0+t_valid)` 内对所有 `w∈W` 保持 `x(t)∈X_safe` 与接触约束。证明要点：值函数下降 + 鲁棒管不变性 + 安全滤波的 CBF 约束 + 回退不变性。
2. **意图安全分离**：若 ICS 只修改 `β` 且只收紧 `C_hard`，则任意在 `I` 下可行的计划在 `I'` 下仍可行；意图变化不可能放松安全边界。证明：`C_hard(I') ⊆ C_hard(I) ⊆ C_hard^base`，代价不进入可行性判定。
3. **随时证书单调性**：若求解器返回有效 incumbent 与有效下界，则 `J_ub` 不增、`J_lb` 不降、`ε_opt` 不增；中断求解不会破坏 `C_safe`，因为 `C_safe` 与 `C_opt` 独立。证明：incumbent 取优 + 下界取最大 + 安全证书只依赖可行性与管。
4. **对账触发完整性**：若实际接触序列偏离满足 `d_σ>τ_σ` 或出现硬失配，则 CSR 在一个控制周期内触发重规划；在 A70 下不会静默执行失效调度。证明：事件可观 + 触发规则 + 证书失效。
5. **预算安全**：若任一 `B_oc` 耗尽，降级映射到已认证的 `π_safe` 或保守调度；在 A71 下回退集不变。证明：预算单调 + 降级映射 + 回退不变性。

```python
    def __init__(self, hybrid, templates):
        self.H = hybrid
        self.templates = templates

    def sample_schedules(self, z, shp, k=3):
        dist = shp.schedule_distribution(z)
        return top_k(dist, k)

    def check_schedule(self, sigma, x0, phi):
        for (m, t) in sigma:
            if not self.H.mode_valid(m, phi):
                return False
        return self.H.contact_consistency(sigma, x0, phi)

    def recovery_schedule(self, x0, z, phi):

        if dcm > self.H.support_max:
            return self.H.step_schedule("right", target=dcm)
        if dcm < self.H.support_min:
            return self.H.step_schedule("left", target=dcm)
        return self.H.double_support_schedule()
```

```python
class OptimalViabilityKernel:
    def __init__(self, hybrid, alpha, gamma=0.99):
        self.H = hybrid
        self.alpha = alpha
        self.gamma = gamma
        self.V_hat = None

    def fit(self, sampler, schedules, beta, phi, iters=200):
        X = sampler.states()
        for _ in range(iters):
            targets = []
            for x in X:
                best = float("inf")
                for sigma in schedules:
                    for u in self.H.sample_inputs(x, sigma, phi):
                        x_next, c = self.H.step(x, u, sigma, phi)
                        best = min(best, c + self.gamma * self.V_hat(x_next))
                targets.append(best)
            self.V_hat = self.fit_regressor(X, targets)

    def in_kernel(self, x, phi, beta):
        return self.V_hat(x) <= self.alpha

    def induce_tube(self, x_star, rho, phi, sigma):
```

### IP-165 AOC（随时最优证书）

```python
def anytime_hybrid_ocp(x0, schedules, phi, beta, t_budget):
    incumbent = None
    lower_bounds = []
    t0 = now()
    for sigma in schedules:
        solver = HybridOCPSolver(x0, sigma, phi, beta)
        while now() - t0 < t_budget and not solver.converged():
            solver.step()
            if solver.has_feasible_incumbent():
                incumbent = argmin_cost(incumbent, solver.incumbent())
            lower_bounds.append(solver.lower_bound())
        if incumbent is not None and lower_bounds:
            J_lb = min(lower_bounds)
            eps = (incumbent.J - J_lb) / max(abs(incumbent.J), 1e-6)
            cert = make_certificate(incumbent, J_lb, eps, solver, scope="local")
            if cert.C_safe.valid:
                return incumbent, cert
    return incumbent, make_fallback_certificate()

def make_certificate(incumbent, J_lb, eps, solver, scope):

        feas=incumbent.feasible,
        m_con=incumbent.min_constraint_margin,
        rho_rob=solver.robust_margin(),
        t_valid=min(solver.next_guard_time(), solver.cert_horizon()),
        sigma_hash=hash(incumbent.sigma),
    )
    opt = Optimality(J_ub=incumbent.J, J_lb=J_lb, eps=eps, scope=scope)
    return CertificateBundle(safe=safe, opt=opt, val=solver.validity())
```

## 4. 解析推导：为什么静态 `K_safe` 不够（LIP/DCM 可行核）

线性倒立摆（LIP）：
```
ẍ = ω²(x − p),   ω = √(g/h),   p ∈ [p_min, p_max]
```
定义发散分量（DCM / capture point）：
```
ξ = x + ẋ/ω
ξ̇ = ω(ξ − p)
```
- 若 `ξ ∈ [p_min, p_max]`，取 `p=ξ` 即可让 `ξ̇=0`，不落步即可稳定。
- 若 `ξ > p_max` 或 `ξ < p_min`，`ξ` 会继续发散，必须落步；单步可停位置近似 `p_step ≈ clip(ξ, [p_min,p_max])`，再受步长、摩擦锥与力矩上限约束。
- 因此 `α`-可行核不是 `(x, ẋ)` 的“位置盒子”，而是 `(ξ, 可落步集合)` 上的可达集；`V_α` 同时编码“还能不能停/能不能落步”。

数值示例（仅解析推演，待 E192/E196 验证）：`h=1.0 m ⇒ ω≈3.13 rad/s`，`x=0.02 m`，`ẋ=0.5 m/s`，则 `ξ=0.02+0.5/3.13≈0.18 m`。支撑域取 `[−0.1,0.1] m`，`ξ` 已越界；但单看位置 `x=0.02∈[−0.1,0.1]` 会误判为“安全”。这直接说明第 60 轮以静态位置/阻抗为中心的安全判据在双足动态中会产生**假安全**。

**预期对照（假设，待验证）**：在相同场景/意图下，第 60 轮 `K_safe` 在 `ξ` 越界时仍可能判定安全；PIVOT 的 `V_α` 会提前要求落步或放大鲁棒管。该差异应在 E192 中通过“假安全率”与“提前落步率”量化，而不是直接当作已证结论。

| SHP | `O(N_scene·|Σ_z|)` | `O(|Σ_z|)` | 先验校准误差 ≤ `ε_prior` |
| AOC | `O(1)` 检查 + 求解器 | `O(1)` | `C_safe` 在 `t_valid` 内可靠 |
| CSR | `O(L²)` DTW | `O(L)` | 失配检测 ≤ 1 控制周期 |
| PCE-OC | `O(1)` | `O(1)` | 预算单调，耗尽即认证回退 |

**条件性定理（PIVOT-Safe）**：若 A66–A72 成立，则：
1. `x_0∈V_α` 且 `C_safe` 有效 ⇒ 在 `t_valid` 内对所有 `w∈W` 保持 `x(t)∈X_safe` 与接触约束。
2. `C_hard(I)⊆C_hard^base` ⇒ 意图整形不会放松安全边界；任意 `I` 下的可行计划仍满足基础安全。
3. `C_safe` 与 `C_opt` 独立 ⇒ 求解中断/次优不破坏安全；`C_opt` 只影响性能与预算。
4. `d_σ>τ_σ` 或硬失配 ⇒ CSR 在一个控制周期内触发重规划；A70 下不会静默执行失效调度。
5. 任一 `B_oc` 耗尽 ⇒ 降级到认证 `π_safe` 或保守调度；A71 下回退集不变。

## 7. 本轮最大风险

**一句话**：最优性证书可能被误读为安全证书——在模型误差或接触事件失配时，低代价计划往往贴着约束边界执行，越“最优”越接近灾难；必须以「双轨证书（`C_safe` 与 `C_opt` 分离）+ 鲁棒管 + 接触事件触发失效 + 认证回退」四重护栏，保证最优性永远不凌驾于可行性之上。
