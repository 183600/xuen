# 第 43 轮（新循环第 3 轮） · 证书竞技场（Cert-Arena）：排行榜驱动的对抗式证书进化与竞赛式验证预算分配（四层架构 v8）

> 承接第 42 轮 v19（Sim-Cert-RAG 飞轮）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉」：两者其实是同一个病——**评价者与被评价者同源**，D_sim 与 KB 既是训练集又是考卷，证书只要在有限场景集上通过就被误认为全域 sound。本轮灵感词「排行榜」「竞赛策略」给出的解法不是更强的模型，而是**改变评价机制**：把证书放进持续对抗的竞技场，让独立红队用赏金攻击它、蓝队用证书防守它，用**保守下界的排行榜**决定谁获得下一轮验证预算；用 racing（逐轮淘汰）而非穷举分配稀缺仿真算力；用 Elo/TrueSkill 匹配「刚好打不过」的对手与任务，让课程与证书共同进化。排行榜在此不是荣誉墙，而是**预算分配器 + 反例生成器 + 防自欺审计器**。

## 0. 直觉与动机

### 灵感 1（排行榜 → 把「一次性验收」变成「持续公开的排名压力」）

直觉上，安全证书最大的敌人不是某个攻击者，而是**考卷泄露**。第 42 轮里证书在 D_sim 的有限采样上达标，就被授予 `SimValidated` 标记；但 D_sim 同时是 SCV 的测试场和 CKB 的训练源，天然存在「在考卷上过拟合」。排行榜的启示是：**只要评价是公开的、反复的、可被挑战的，评价本身就会进化**。

据此建立证书排行榜：每条记录 = (证书 C_i, 适用域 (φ_i, ψ_i), 赛季 s, 评估轨迹集, 名次)。三条设计原则：

1. **悲观排序**：按边际的置信下界 LCB 排序，而非点估计；只有当「C_i 的 LCB > C_j 的 UCB」时才宣称 i 严格优于 j，否则给出带不确定区间的偏序。排行榜本身不能成为新的 soundness 漏洞。
2. **升降级即退化告警**：证书名次连续下滑 → 触发复核；跌出安全区 → 自动隔离（quarantine），从 L0 表与热更新清单中摘除。
3. **公开对抗即长尾采样**：红队持续提交反例，比域随机化更主动地搜索「守卫面附近」的稀有失效。

### 灵感 2（竞赛策略 → 红蓝自博弈、赏金、Racing、匹配、机制设计）

- **红蓝自博弈**：攻击者策略 π_A 最大化「违例严重度 × 新颖度 − 重复度」，防守者（证书合成器）最大化「覆盖率 − 保守度」。二者交替训练，自动补第 42 轮域随机化覆盖不全的洞，且攻击者会主动寻找「证书最自信却最脆弱」的区域。
- **竞赛式预算分配（racing / successive halving / Hyperband）**：证书候选不必都在全部轨迹上评估。分阶段淘汰「下界明显落后」的候选，把算力集中到有希望者。这是对第 42 轮「离线预算换在线预算」的进一步优化：**不是所有候选都配得上完整考卷**。
- **匹配（Elo / TrueSkill）**：给任务与证书打能力分，优先匹配胜率约 50% 的对手/任务（最近发展区 ZPD），课程难度自适应，替代手调难度曲线。
- **机制设计**：赏金必须奖励「边际新颖且可复现」的反例；对隐瞒失败要有审计与惩罚，否则参赛者会选择性上报，排行榜退化为公关榜。

### 灵感 3（与 v7 飞轮的耦合）

Arena 是 SCV 的「红队外挂」、CKB 的「难例索引」、LCS 的「预算调度器」、课程引擎的「匹配器」、漂移监控的「赛季时钟」。第 42 轮飞轮是 Sim→RAG→Edge→Sim；本轮在评价层插入一个**独立裁判**，把「自评」升级为「他评 + 对抗评」：

```
红队赏金 → 反例 Ξ → CKB 难例索引 → 证书修订
   ↑                                  ↓
赛季/隐藏测试 ← 排行榜(LCB) ← Racing 评估 ← 证书候选
   ↓                                  ↑
漂移告警 → 新赛季 → 重新匹配任务 → 课程/证书共同进化
```

## 1. 形式化定义（增量：定义 38–45）

**定义 38（证书竞技场博弈）**：竞技场是二人零和博弈 G = (𝒞, 𝒜, X, u)。防守方选证书 C ∈ 𝒞（含阈值 θ_C、不变式、保持时间）；攻击方选轨迹分布 a ∈ 𝒜（D_sim 支撑集上的任意分布，含对抗扰动）。支付

  u(C, a) = E_{ξ∼a}[ 1( m_ξ < θ_C ) ] + λ_c·Cost(C),

其中第一项是违例率、第二项是保守度代价（保守证书虽安全但降低可用性）。竞技场值 V* = min_{C} max_{a} u(C, a)。排行榜估计的是**每一对 (C, a) 的局部值**，而非一次性全局 V*——这正是持续对抗的意义。

**定义 39（保守排行榜分数与前缀 soundness）**：对证书 C 在场景流上采样得到边际 m_1, …, m_n，定义

  S_δ(C) = LCB_{1−δ}(m) − λ·Cost(C),

其中 LCB 由 anytime-valid 置信序列（如 empirical-Bernstein CS）给出，允许中途查看与停止。**前缀 soundness 命题**：若将候选按 S_δ 降序排列为 C_(1), …, C_(K)，且对某 k 有 S_δ(C_(k)) > max_{j>k} UCB_{1−δ}(m_j)，则以概率 ≥ 1−δ，C_(k) 的真实期望边际严格大于所有 j>k 的候选。故「榜首」只有在与所有挑战者的置信区间分离时才被认证。

**定义 40（Elo / TrueSkill 证书-任务匹配）**：证书或任务的能力分 R_i 按成对比较更新：

  R_i ← R_i + K·( s_ij − σ((R_i − R_j)/s) ),

s_ij ∈ {0,1} 为在一批场景上 i 是否优于 j，σ 为 logistic。TrueSkill 版本用高斯 (μ_i, σ_i²) 并显式保留不确定性。**匹配策略** π_match 选择使信息增益最大的配对（约 50% 胜率、双方 σ 最大），用于课程难度与红队强度调度。注意成对比较可能**非传递**（A>B、B>C 但 C>A），故排行榜必须保留偏序与不确定性，不能只留一个标量名次。

**定义 41（Racing 证书搜索）**：候选集 𝒞_0，第 r 阶段用 n_r = n_0·η^{−r} 条轨迹评估存活候选，按 S_δ 淘汰底部 1/η，直到预算耗尽或只剩一个。等价于 successive halving；多个 η 并行即 Hyperband。**命题**：若最优与次优候选的真实边际间隔 ≥ ε，则以概率 ≥ 1−δ，racing 在总预算 O((N/ε²)·log|𝒞|·log(1/δ)) 内返回最优候选，较穷举的 O(|𝒞|·N) 在 |𝒞| 大时显著节省。

**定义 42（对抗反例赏金）**：攻击者提交轨迹 ξ，奖励

  R(ξ) = w_1·severity(ξ) + w_2·novelty(ξ | Ξ_KB) − w_3·dup(ξ | Ξ_KB),

severity(ξ) = max_t (θ − m_t)/θ（越负越严重），novelty 为与 KB 中已有反例的最小语义距离（状态抽象空间中的核密度或嵌入距离），dup 为重复惩罚。赏金预算按「先探索后利用」调度：早期提高 w_2 鼓励多样性，后期提高 w_1 逼近最严重失效。

**定义 43（赛季、隐藏测试与反古德哈特协议）**：公开榜 L_pub 在 D_pub 上评估；另有封存的 D_hidden ∼ D_shift，只在赛季末揭榜。赛季长度 T_s。**污染检测**：向 D_pub 注入唯一可识别的金丝雀轨迹（canary），若其语义指纹出现在 CKB 训练集或证书合成日志中，则判定考卷泄露；辅以成员推断 AUC。**迁移缺口** G = 1 − Kendall-τ(rank_pub, rank_hidden)。若 G > τ_G，则赛季提前重置、相关证书隔离、公开榜成绩作废。

**定义 44（匹配式课程 / 最近发展区）**：任务难度 d(φ) 由 TrueSkill 能力分估计；课程选择期望成功率 p ∈ [0.4, 0.6] 的任务（ZPD），并按「证书 regret」升序排列相位序列 Π。regret = 当前证书在该任务上的 S_δ 与榜首证书 S_δ 之差；regret 大者优先进入课程，但需经匹配器确认难度合适。

**定义 45（竞技场感知的 RAG 检索）**：检索分数在嵌入相似度上叠加难度与时效：

  sim'(φ, ψ) = sim_embed(φ, ψ) − β·hardness_rank + γ·recency(season),

并要求返回 **Top-k 成功模板 + Top-k 失败/反例**（对比检索）。失败样本进入差集补全的初始种子，避免第 42 轮「只检索相似成功案例 → 重复同样的盲区」。

## 2. 四大产出设计（增量 IP-57/58/59 + 升级 IP-54/55/52/51/50/45/47）

### 2.1 IP-57 CERT-ARENA（证书竞技场 CA）

1. **保守排行榜服务**：按定义 39 用 anytime-valid CS 维护每条证书的 (LCB, UCB, 名次区间)；名次变化触发升降级与隔离。
2. **红队赏金引擎**：攻击器用 CMA-ES / 强化学习 / 梯度引导（对可微仿真）在「守卫面附近」搜索；提交经去重、可复现性检查（同种子重放）与自动归因后入库。
3. **赛季与隐藏测试**：赛季时钟与漂移监控对齐；隐藏测试封存、金丝雀污染检测、赛季末揭榜与迁移缺口审计。
4. **机制层**：赏金奖励函数、审计概率 p_audit 与惩罚 P；**命题**：当 p_audit·P > 隐瞒失败的私人收益时，如实上报是（弱）占优策略，抑制选择性上报。

### 2.2 IP-58 RACE-CERT（竞赛式证书搜索 RC）

1. **候选生成**：来自 CKB 检索模板、参数扰动、组合模板、以及上一赛季「差一点」的淘汰者（复活赛）。
2. **Racing 调度**：Hyperband 多臂并行；每阶段用定义 39 的 LCB/UCB 淘汰，预算记账到 COT。
3. **早停安全阀**：被淘汰候选不立即销毁，进入「复活池」；若其 UCB 在后继阶段反超，可重新入场（防止高方差误杀）。
4. **证书质量-成本帕累托**：输出 (S_δ, Cost, WCET) 的帕累托前沿，交由 LCS 选档。

### 2.3 IP-59 MATCH-CURRICULUM（匹配式对抗课程 MC）

1. **双能力分**：任务难度分与证书能力分；匹配器选 ~50% 胜率配对。
2. **红队强度调度**：按证书当前 Elo 选择攻击器强度，避免「一直打菜鸟」或「一直被吊打」。
3. **课程相位**：按 regret 与 ZPD 排序；相位通过率曲线反馈给 IP-50。
4. **组合技能**：乘积自动机的子证书各带 Elo，组合时优先检索「能力互补」而非仅相似。

## 4. 实验设计（E87–E94 硬门槛，承接 E79–E86）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E87 排行榜排序 soundness | LCB/UCB 分离下的前缀正确率；与穷举真值 Kendall-τ | 前缀正确率 ≥ 99%；τ ≥ 0.9 |
| E88 赏金反例发现力 | 每千仿真小时新失效模式数；严重度 vs 随机采样 | 新失效 ≥ 5/千小时；严重度提升 ≥ 3x |
| E89 Racing 预算效率 | 达到同等证书质量所需轨迹数；anytime 覆盖率 | 省 ≥ 5x；覆盖率 ≥ 95% |
| E90 反古德哈特 | 隐藏测试 τ、金丝雀污染检测 AUC、赛季重置后掉点 | τ ≥ 0.8；AUC ≥ 0.9；掉点 < 3pp |
| E91 匹配式课程 | 达到目标通过率的时间；ZPD 命中率 | 加速 ≥ 2x；ZPD 命中 ∈ [0.4, 0.6] |
| E92 多赛季共同进化 | 连续 10 赛季：不安全事件、攻击成功率、Nominal 占比 | 0 起；攻击成功率降后平台化；Nominal ≥ 80% |
| E93 竞技场成本 | 总仿真成本 vs v19；鲁棒性增益；人工赏金复核时长 | 成本 ≤ 1.5x；增益 ≥ 10pp；复核 < 10min/条 |
| E94 组合技能竞技 | 乘积证书通过率、名次稳定性、接口契约冲突率 | 100%；名次区间不跨 3 档；冲突率 < 1% |

回退：E87 排序不 sound → 退回点估计 + 人工复核，禁止自动升降级；E88 赏金只产出重复样本 → 提高新颖度权重或回退随机域随机化；E89 racing 误杀严重 → 提高每阶段样本数、扩大复活池；E90 迁移缺口大 → 停止自动认证，赛季改为人工揭榜；E91 匹配无效 → 回退第 42 轮固定难度曲线；E92 攻击成功率不降 → 竞技场降级为纯审计工具。

## 5. 本轮最大风险

**一句话**：竞技场把「安全」压缩成一个可优化的排行榜分数，一旦**排行榜被古德哈特化**（红蓝双方对公开榜过拟合、选择性上报或共谋），证书会带着「榜首」的社会证明在隐藏/真实分布上静默失效——这比第 42 轮的仿真偏差更危险，因为偏差从「无人知道」升级为「所有人都相信」；因此 E90（隐藏测试迁移缺口 + 金丝雀污染）与 E87（排序 soundness）必须作为红线，任一不达标即关闭自动认证、回退到 v19 的人工审计。

### IP-57 CA：保守排行榜、赏金与赛季审计

```
# 保守排行榜：用 anytime-valid 置信序列维护 LCB/UCB
def update_leaderboard(cert_id, margins, delta=0.05):
    cs = empirical_bernstein_cs(margins, delta)   # 支持 optional stopping
    lcb, ucb = cs.lower(), cs.upper()
    score = lcb - lambda_cost * cost(cert_id)
    entry = LB[cert_id]
    entry.update(lcb=lcb, ucb=ucb, score=score, n=len(margins))
    # 名次区间：所有可能被排到前面的候选数
    entry.rank_lo = 1 + sum(1 for j in LB if j != cert_id and LB[j].lcb > entry.ucb)
    entry.rank_hi = 1 + sum(1 for j in LB if j != cert_id and LB[j].ucb > entry.lcb)
    if entry.rank_hi > SAFE_RANK: quarantine(cert_id)     # 跌出安全区
    return entry

# 前缀 soundness：只有当 LCB 与所有后继 UCB 分离才认证榜首
def certified_top(entries):
    ranked = sorted(entries, key=lambda e: e.score, reverse=True)
    for k, e in enumerate(ranked):
        if e.lcb > max((x.ucb for x in ranked[k+1:]), default=-inf):
            return ranked[:k+1], True
    return ranked[:1], False

# 红队赏金：严重度 × 新颖度 − 重复度
def bounty_step(attacker, KB, cert, budget_sim):
    xi = attacker.propose(cert, KB, budget=budget_sim)   # CMA-ES / RL / 梯度引导
    if not reproducible(xi, seeds=3): return None        # 可复现性闸门
    sev = max((cert.theta - m) / cert.theta for m in margins(xi))
    nov = semantic_distance(xi, KB.counterexamples)      # 状态抽象空间最小距离
    dup = KB.nearest_dup(xi)
    reward = w1 * sev + w2 * nov - w3 * dup
    if reward > 0 and dup < DUP_EPS:
        KB.insert_counterexample(auto_attribute(xi), season=current_season)
        return {'xi': xi, 'reward': reward, 'labels': auto_attribute(xi)}
    return None

# 赛季审计：隐藏测试 + 金丝雀污染检测
def season_audit(public_ranks, hidden_ranks, canary_ids, train_fingerprints):
    tau = kendall_tau(public_ranks, hidden_ranks)
    gap = 1.0 - tau
    leaked = any(c in train_fingerprints for c in canary_ids)
    auc = membership_inference_auc(train_fingerprints, hidden_fingerprints)
    if gap > TAU_G or leaked or auc > AUC_MAX:
        reset_season(); quarantine_by_rank(public_ranks)
        return {'status': 'RESET', 'gap': gap, 'leaked': leaked, 'auc': auc}
    return {'status': 'OK', 'gap': gap}
```

### IP-58 RC：Racing / Hyperband 证书搜索

```
def race_certificates(candidates, eval_fn, budget_total, eta=3, delta=0.05):
    # 多 bracket Hyperband：不同初始样本数 n0
    brackets = hyperband_brackets(budget_total, eta)
    survivors_all = []
    for bracket in brackets:
        alive = list(candidates)
        n = bracket.n0
        for r in range(bracket.rounds):
            # 每阶段用 n_r 条轨迹评估存活者（增量复用已评估样本）
            for c in alive:
                c.margins += eval_fn(c, n_samples=n)
                update_entry(c, c.margins, delta)
            # 淘汰底部 1/eta；但保留进复活池
            alive.sort(key=lambda c: c.lcb, reverse=True)
            eliminated = alive[len(alive) - len(alive)//eta:]
            revive_pool.extend(eliminated)
            alive = alive[:len(alive) - len(alive)//eta]
            # 复活：若被淘汰者的 UCB 反超当前最差存活者的 LCB
            for c in list(revive_pool):
                if c.ucb > min(a.lcb for a in alive):
                    revive_pool.remove(c); alive.append(c)
            n = max(1, n // eta)
        survivors_all.extend(alive)
    # 返回质量-成本帕累托前沿
    return pareto_front(survivors_all, keys=['lcb', 'cost', 'wcet_us'])
```

### IP-59 MC：Elo/TrueSkill 匹配式课程

```
def matchmake(tasks, certs, skill, n_pairs):
    pairs = []
    for _ in range(n_pairs):
        # 选择信息增益最大（双方 sigma 大、期望胜率≈0.5）的配对
        best = max(((t, c) for t in tasks for c in certs),
                   key=lambda tc: info_gain(skill[t], skill[c]))
        pairs.append(best)
    return pairs

def update_skill(skill, i, j, outcome, K=32):
    # Elo 更新（TrueSkill 用高斯消息传递）
    e = 1.0 / (1.0 + 10 ** ((skill[j].mu - skill[i].mu) / 400.0))
    skill[i].mu += K * (outcome - e)
    skill[j].mu += K * ((1 - outcome) - (1 - e))
    skill[i].sigma *= 0.97; skill[j].sigma *= 0.97

def select_zpd_tasks(tasks, skill, cert, lo=0.4, hi=0.6):
    scored = []
    for t in tasks:
        p = win_prob(skill[t], skill[cert])   # 期望成功率
        if lo <= p <= hi: scored.append((t, p))
    # 同 ZPD 内按证书 regret 升序（更容易先学）
    return sorted(scored, key=lambda tp: certificate_regret(cert, tp[0]))
```

```
# IP-55 CKB：成功 Top-k + 失败 Top-k 对比检索
def arena_retrieve(phi, psi, KB, k=5, beta=0.3, gamma=0.2):
    sims = [sim_embed(phi, psi, r) - beta * r.hardness_rank + gamma * r.recency
            for r in KB.records]
    succ = top_k(sims, k, filter=lambda r: r.success)
    fail = top_k(sims, k, filter=lambda r: not r.success)   # 失败/反例也检索
    return succ, fail

# IP-52 LCS：用 LCB/UCB 分离决定是否继续升档
def certify_light_v3(x, guards, budget_us=200, delta=0.05):
    b = cert_lookup_L0(x)
    if decided(b, guards): return b, -1                 # T-1 决策等价
    if budget_us < 110: return downgrade_monotone(b), -1
    status, margin = monitor_step_INT8(quantize_obs(x))  # T0
    b.m_lo = margin
    if separated(b, guards, delta): return b, 0          # 置信分离即停
    return downgrade_monotone(b), 0

# IP-51 CAR：赛季戳 + 隔离位
def car_guard(e, x, cert_obj):
    if cert_obj.season != current_season or cert_obj.quarantined[e]:
        return False                                     # 过期/隔离 → 保守拒绝
    theta_real = cert_obj.alpha_e[e] * cert_obj.theta_sim[e]
    return cert_lookup_L0(x).m_lo[e] >= theta_real
```

## 6. 本轮最大风险

**一句话**：竞技场把「安全」压缩成一个可优化的排行榜分数，一旦**排行榜被古德哈特化**（红蓝双方对公开榜过拟合、选择性上报或共谋），证书会带着「榜首」的社会证明在隐藏/真实分布上静默失效——这比第 42 轮的仿真偏差更危险，因为偏差从「无人知道」升级为「所有人都相信」；因此 E90（隐藏测试迁移缺口 + 金丝雀污染）与 E87（排序 soundness）必须作为红线，任一不达标即关闭自动认证、回退到 v19 的人工审计。
