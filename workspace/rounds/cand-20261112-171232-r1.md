# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；新灵感循环第 1 轮；本轮灵感：「多任务学习」×「对比实验」）

> 第 60 轮的 SGEC 把「场景→意图→约束→阻抗→执行→证据」串成闭环，但留下两个结构性缺口：
> 1. **认知任务各自为战**：SSM、CIEC、EEIS、J_exec 是四个相互独立的模型/规则，共享同一批遥测（力、位、电流、滑移），却重复编码、各自训练；更严重的是——**场景（慢时间尺度、跨回合稳定）与意图（快时间尺度、瞬时）被塞进同一表示空间后相互污染**：一句「轻触」的意图，可能被「粗糙桌面」的强场景先验淹没（或反之），导致第 60 轮的 K_safe 先验在错误的任务上收敛。
> 2. **闭环缺乏因果证据**：「SSM 提升 15%」「CIEC 响应 500ms」「EPIR 99.9%」全部是**自评的相关性数字**——没有对照臂、没有配对、没有显著性、没有多重比较校正。一条「场景先验让 K_safe 收敛更快」的结论，可能只是因为它多跑了 3 个接触周期。**没有对比实验的闭环，只是在自我确认，不是在自我改进。**

## 0. 直觉与动机

**灵感 1（多任务学习 → 共享-私有-多时标认知解耦 SPC）**
直觉：场景识别、意图推断、阻抗编译不是三个独立问题，它们共享同一个「物理交互表征」——接触力轨迹、等效刚度、滑移事件、速度响应。但它们的**时间尺度完全不同**：场景是慢变（跨回合、分钟级），意图是快变（秒级、单次），阻抗是动作级（毫秒级）。朴素的多任务共享（一个 encoder + 三个 head）会把慢变场景的梯度灌进快变意图头，造成**时间尺度负迁移**。关键洞见：**共享必须发生在「时标分层」的表征上**——慢通道 h_slow 供场景与阻抗先验，快通道 h_fast 供意图与瞬态约束，阻抗用双通道门控拼接；共享的是「物理不变性」（刚度、耗散、摩擦），私有的是「时标特定动力学」。一句话：**不是所有知识都该共享，只有不变的那部分才该共享。**

**灵感 2（对比实验 → 反事实配对重放 CPR）**
直觉：机器人实验昂贵、不可重复、每个场景通常只能跑一次，传统 A/B 在具身智能里几乎不可行。但第 60 轮的 EPIR 已经在边端**持久化了带时间戳/序列号/哈希的执行证据**。若把它从「证据存档」升级为「可重放检查点」——记录机器人状态、环境状态、RNG 种子、控制器内部状态、观测缓冲——就能对同一初态、同一种子做**配对反事实重放**：处理臂 u^X（启用模块 X）与对照臂 u^∅（关闭 X），配对差分 Δ_u = J(u^X) − J(u^∅)。关键洞见：**证据链（evidence chain）可以变成实验链（experiment chain）**——第 60 轮为「可信」建的 EPIR，恰好是第 61 轮「可证伪」的实验底座；而「可证伪」正是科学方法在具身系统里最缺的一环。

**灵感 3（两者合流 → 实验驱动多任务权重 ESM）**
直觉：多任务学习最难的从来不是网络结构，而是任务权重 w_k 怎么定——网格搜索昂贵、手工设定主观、不确定性下更无从谈起。既然 CPR 能给出「任务 k 的边际贡献 Δ_k」（启用 vs 关闭的配对差分），就用它反过来设定 w_k：w_k ← w_k·exp(η·Δ_k/σ̂_Δ)。关键洞见：**多任务权重不该由先验驱动，而应由可复现的对比实验驱动**——「哪个任务真的有用」由反事实配对回答，而不是由设计者直觉回答；同时用收缩估计与权重上下界防止小样本方差把权重推向极端。

**灵感 4（合流闭环 → MTCE）**
直觉：把 SPC 的多任务认知、CPR 的因果对照、ESM 的实验权重嵌回第 60 轮的 SERC 闭环，形成 **MTCE（多任务对比执行）**：联合推断（场景/意图/阻抗）→ 执行 → EPIR 存档（升级为可重放检查点）→ 反事实配对 → 边际贡献 → 任务权重重标定 → 下一轮联合推断。闭环从「自我确认」升级为「可证伪的自我改进」。

**灵感 5（预算 → 统计功效预算 B_exp）**
直觉：对比实验不是免费的——每对重放消耗算力、时间，还可能扰动真实任务。PCE+++++ 必须新增 **B_exp（实验预算）**：不仅限制「跑多少次」，更要保证「跑够多少次才有统计功效」——n_pairs ≥ n_min(δ_effect, α, 1−β)。若实验预算不足以达到目标功效，**宁可不做实验**（VOI_exp < 0），而不是做一个「看起来显著」的伪结论。**功效不足的显著性，比没有显著性更危险。**

## 1. 形式化定义（增量：定义 161–168）

**定义 161（共享-私有-多时标认知解耦 SPC）** 多任务认知模型 𝒞 = (Φ_slow, Φ_fast, {Φ_priv^k}, {g^k})，任务集 K = {scene, intent, impedance}（可扩展 evidence/ros）：
- **共享慢通道**：h_slow = Φ_slow(o_{t−T:t}; θ_s)，大感受野、强时间平滑，供 scene/impedance
- **共享快通道**：h_fast = Φ_fast(o_{t−τ:t}; θ_f)，小感受野、低延迟，供 intent/impedance
- **私有头**：Φ_priv^k：ℝ^{2d}→𝒴_k；**门控** g^k(h_slow,h_fast) = (g_s^k, g_f^k) ∈ [0,1]²，任务 k 的输入为 z_k = [g_s^k·h_slow ; g_f^k·h_fast]
- **联合损失**：
  L(θ) = Σ_{k∈K} w_k·L_k(θ_s, θ_k) + λ_slow·L_slow + λ_sep·L_sep
  其中 L_slow = E_t[‖h_slow(t) − h_slow(t−1)‖²]（慢通道平滑正则），L_sep = Σ_{k≠l} cos²(Φ_priv^k, Φ_priv^l)（私有头解耦正则）。
  注意：L_slow 只惩罚慢通道、**不惩罚快通道**，这是时标分离的关键；朴素 MTL 没有这一项，等价于强迫快任务服从慢平滑先验。

**定义 162（任务亲和图 TAG）** 无向加权图 G = (V, E, A)，V = {scene, intent, impedance}：
- **亲和度**：a_{kl} = EMA_W[ cos(∇_{θ_s} L_k, ∇_{θ_s} L_l) ] ∈ [−1, 1]，在共享参数上计算、窗口 W 个 batch 做指数滑动；
- **共享边**：a_{kl} > τ_aff ⇒ 允许共享通道；**冲突边**：a_{kl} < −τ_neg ⇒ 强制隔离/调和；
- **结构先验**：scene↔impedance 常为正亲和（场景决定阻抗），intent↔impedance 常为正亲和（意图改阻抗），scene↔intent 因时标差异常为负亲和——这正是朴素 MTL 失败的根源。

**定义 163（梯度调和护栏 GHG）** 对共享参数 θ_s 的冲突梯度对 (g_k, g_l)：
- **投影**：若 a_{kl} < −τ_neg 且 g_k·g_l < 0，则 g_k ← g_k − (g_k·g_l / ‖g_l‖²)·g_l；此时 g'_k·g_l = 0 且 g'_k·g_k = ‖g_k‖² − (g_k·g_l)²/‖g_l‖² ≥ 0（Cauchy–Schwarz），即**投影方向仍是 L_k 的一阶下降方向**；
- **负迁移检测 NTD**：更新后若 L_k↑ 且 L_l↓ 且 a_{kl} < −τ_neg，记一次「负迁移事件」，回滚该 batch 的 θ_s；
- **护栏语义**：GHG 不追求「全局最优」，只保证「冲突时谁都不被对方的梯度强行拖升」。

**定义 164（反事实配对重放 CPR）** 重放检查点 c = (x_robot, x_env, s_rng, s_ctrl, o_buffer, seq_epir)：
- **可重放性**：ε_rep(c) = d(x_robot(T; c), x_robot^replay(T; c))，用同臂二次重放的终态偏差度量；ε_rep ≤ ε_tol 才 eligible；
- **配对单元**：同 c、同 s_rng 的处理臂 u^X（启用 X）与对照臂 u^∅（关闭 X），配对差分 Δ_u = J(u^X) − J(u^∅)；
- **估计与检验**：Δ̂ = (1/n)ΣΔ_u；bootstrap 置信区间 CI_{1−α}；配对 Wilcoxon 符号检验；族错误率用 Holm–Bonferroni，探索性分析用 BH（FDR）；
- **偏差界**：若 J 对终态是 L_J-Lipschitz，则 |E[Δ̂] − ATE| ≤ L_J·ε_rep——所以**重放非确定性不是小事，它会直接、线性地进入因果估计的偏差**。

**定义 165（PCE+++++ 认知-实验双预算）** B = (B_cog, B_exp)，其中：
- B_cog = (B_scene, B_intent, B_ros, B_exec)（第 60 轮）
- B_exp = (n_pairs_budget, power_target, replay_stability, multiple_compare_budget)
- **配对样本量下界**：n_min = ⌈(z_{1−α/2} + z_{1−β})²·σ_Δ² / δ_effect²⌉
- **实验 VOI**：VOI_exp = E[gain | A/B] − cost_replay·n_min − risk_disturb
- **安全门**：若 n_pairs_budget < n_min 或 replay_stability < θ_rep，则**拒绝实验**，回退到第 60 轮「无实验模式」；若 B_cog 耗尽，退回单任务/默认约束。

**定义 166（实验驱动多任务权重 ESM）** 对任务 k：
- **边际贡献**：Δ_k = Δ̂_k（CPR 配对估计），并用经验贝叶斯/James–Stein 收缩 Δ_k^shrink = Δ̂_k·σ̂_prior²/(σ̂_prior² + σ̂_Δ²)
- **权重更新**：w_k ← clamp(w_k·exp(η·Δ_k^shrink/σ̂_Δ), w_min, w_max)，再归一化 Σw_k = 1
- **防坍缩**：w_max/w_min ≤ R；只有 J_stat 判定为 ADOPT 的实验允许更新，REJECT/INCONCLUSIVE 一律保持原权重。

**定义 167（MTCE 闭环算子）** MTCE(M, intent, δ_f^req)：
```
① SPC: (h_slow, h_fast) = (Φ_slow(o_slow), Φ_fast(o_fast))
② 多头: ẑ_scene, Î_intent, K̂_prior = heads(h_slow, h_fast)
③ SERC(第60轮): 场景先验 + 意图约束 + EEIS 编译 K_safe
④ Execute: 执行并生成 EV-exec
⑤ EPIR+: 存档可重放检查点 c = checkpoint(M)（在证据链上追加 replay 字段）
⑥ CPR: 对候选改进 e（如 use_GHG / use_scene_prior / use_intent_lock）做配对重放
        → Δ̂_e, CI, p（同一 c、同一 s_rng、处理/对照各 n 对）
⑦ ESM: 仅对 ADOPT 的任务更新 w_k；否则保持
⑧ J_stat: 生成统计有效性证书；下一轮联合推断使用新 (w, θ)
⑨ Return: (ẑ_scene, K_safe, EV-exec, J_stat, w)
```

**定义 168（统计有效性证书 J_stat）** J_stat = (n_pairs, Δ̂, CI_{1−α}, p_adj, correction_method, power, replay_stability, decision)：
- **有效条件**：power ≥ 1−β ∧ ε_rep ≤ ε_tol ∧ 配对可交换性成立
- **三态决策**：ADOPT（CI 全正且校正后显著）/ REJECT（CI 全负）/ INCONCLUSIVE（CI 跨 0 或功效不足）
- **铁律**：INCONCLUSIVE 不得作为「改进」写入 ESM；这是防 p-hacking 与自欺的唯一硬闸门。

### IP-161 SPC（共享-私有-多时标认知解耦）

```python
class SharedPrivateCognition(nn.Module):
    def __init__(self, d_obs=64, d_h=128, n_scenes=10, n_intents=5, d_K=6):
        super().__init__()
        self.phi_slow = SlowEncoder(d_obs, d_h)          # 大感受野 + 低通
        self.phi_fast = FastEncoder(d_obs, d_h)          # 小感受野 + 高通
        self.priv = nn.ModuleDict({
            'scene': PrivateHead(2 * d_h, d_h, n_scenes),
            'intent': PrivateHead(2 * d_h, d_h, n_intents),
            'impedance': PrivateHead(2 * d_h, d_h, d_K),
        })
        self.gate = Gate(2 * d_h, len(self.priv))        # 每任务 2 维门控

    def forward(self, slow_obs, fast_obs):
        h_s = self.phi_slow(slow_obs)
        h_f = self.phi_fast(fast_obs)
        out = {}
        for k, head in self.priv.items():
            g = self.gate(k, torch.cat([h_s, h_f], -1))  # [g_s, g_f]
            z = torch.cat([g[..., 0:1] * h_s, g[..., 1:2] * h_f], -1)
            out[k] = head(z)
        return out, h_s, h_f

def total_loss(out, targets, w, h_s, priv_reps):
    L = sum(w[k] * task_loss(out[k], targets[k]) for k in w)
    L_slow = smoothness_penalty(h_s)                     # 仅惩罚慢通道
    L_sep = sum(cos_sq(priv_reps[k], priv_reps[l])
                for k in w for l in w if k < l)
    return L + 0.1 * L_slow + 0.05 * L_sep
```

### IP-162/163 TAG + GHG（亲和图与梯度调和）

```python
class TaskAffinityGuard:
    def __init__(self, tau_aff=0.10, tau_neg=0.05, ema=0.9):
        self.a = defaultdict(float)
        self.tau_aff, self.tau_neg, self.ema = tau_aff, tau_neg, ema
        self.ntd_events = 0

    def update_affinity(self, grads):                    # grads: {task: grad_shared}
        for k, l in combinations(grads, 2):
            c = cosine(grads[k], grads[l])
            self.a[(k, l)] = self.ema * self.a[(k, l)] + (1 - self.ema) * c

    def harmonize(self, grads):
        g = dict(grads)
        for (k, l), a in self.a.items():
            if a < -self.tau_neg and dot(g[k], g[l]) < 0:
                g[k] = g[k] - (dot(g[k], g[l]) / (norm(g[l]) ** 2 + 1e-12)) * g[l]
        return g

    def detect_negative_transfer(self, loss_before, loss_after):
        for (k, l), a in self.a.items():
            if (a < -self.tau_neg and loss_after[k] > loss_before[k]
                    and loss_after[l] < loss_before[l]):
                self.ntd_events += 1
                return True
        return False
```

### IP-164 CPR（反事实配对重放）

```python
class CounterfactualPairedReplay:
    def __init__(self, epir, eps_tol=1e-3):
        self.epir, self.eps_tol = epir, eps_tol

    def checkpoint(self, M):
        return {
            'robot': M.robot.state_dict(), 'env': M.env.state_dict(),
            'rng': M.rng.get_state(), 'ctrl': M.controller.state_dict(),
            'obs': list(M.recent_obs), 'seq': M.epir.last_received,
        }

    def eligible(self, c):
        x0 = replay(c, treatment=False).robot_state_T
        x1 = replay(c, treatment=False).robot_state_T
        return dist(x0, x1) <= self.eps_tol          # 同臂二次重放的自一致性

    def paired_experiment(self, c, treatment, control, metric, n_pairs):
        deltas = []
        for _ in range(n_pairs):
            deltas.append(metric(replay(c, treatment)) - metric(replay(c, control)))
        return paired_inference(deltas)

def paired_inference(deltas, alpha=0.05, n_boot=10000):
    d = np.asarray(deltas)
    boot = [np.random.choice(d, len(d), replace=True).mean() for _ in range(n_boot)]
    lo, hi = np.percentile(boot, [100 * alpha / 2, 100 * (1 - alpha / 2)])
    p = wilcoxon(d).pvalue if np.any(d != 0) else 1.0
    return {'delta': d.mean(), 'ci': (lo, hi), 'p': p, 'n': len(d)}
```

### IP-166 ESM（实验驱动权重）

```python
class EmpiricalTaskWeights:
    def __init__(self, tasks, eta=0.1, w_min=0.05, w_max=0.60):
        self.w = {k: 1.0 / len(tasks) for k in tasks}
        self.eta, self.w_min, self.w_max = eta, w_min, w_max

    def update(self, margins, sigmas, stats):
        for k, d in margins.items():
            if stats[k]['decision'] != 'ADOPT':          # 只接受通过 J_stat 的实验
                continue
            shrink = d / max(sigmas[k], 1e-6)
            self.w[k] = np.clip(self.w[k] * np.exp(self.eta * shrink),
                                self.w_min, self.w_max)
        s = sum(self.w.values())
        for k in self.w:
            self.w[k] /= s
```

### IP-165/168 功效与多重比较

```python
def min_pairs(delta, sigma, alpha=0.05, power=0.8):
    z_a, z_b = norm.ppf(1 - alpha / 2), norm.ppf(power)
    return int(np.ceil((z_a + z_b) ** 2 * sigma ** 2 / delta ** 2))

def holm(pvals, alpha=0.05):
    order = np.argsort(pvals)
    m, adj, prev = len(pvals), np.empty(len(pvals)), 0.0
    for rank, idx in enumerate(order):
        prev = max(prev, (m - rank) * pvals[idx])
        adj[idx] = min(1.0, prev)
    return adj
```

def multi_task_comparative_execution(M, intent, delta_f_req):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SPC | 前向 O(2·d_h·d_obs) + 多头 O(3·d_h²) | O(d_h²) | 慢/快时标分离，负迁移率 ≤ 10% |
| TAG/GHG | O(|E|·d_s) 每次梯度更新 | O(|E|) | 冲突梯度投影后仍为各任务一阶下降方向 |
| CPR | O(n_pairs·T_replay) | O(n_pairs) | ε_rep ≤ ε_tol 时 Δ̂ 无偏；偏差 ≤ L_J·ε_rep |
| ESM | O(|K|) | O(|K|) | 权重有界 [w_min,w_max] 且 Σ=1，仅 ADOPT 更新 |
| J_stat | O(n_pairs) | O(n_pairs) | 功效 ≥ 1−β 且 Holm 校正后 FWER ≤ α |

**命题 1（GHG 一阶下降性）** 对冲突对 (g_k, g_l) 且 g_k·g_l < 0，令 g'_k = g_k − (g_k·g_l/‖g_l‖²)g_l，则 g'_k·g_l = 0 且 g'_k·g_k = ‖g_k‖² − (g_k·g_l)²/‖g_l‖² ≥ 0。故沿 −g'_k 更新时 L_k 一阶不增，且不再被 g_l 的上升方向拖拽。

**命题 2（CPR 无偏性）** 若重放确定性使 ε_rep → 0，且处理/对照来自同一检查点与同一种子，则配对差分 Δ_u 是同一单元上平均处理效应（ATE）的无偏样本，Δ̂ 无偏；若 ε_rep > 0 且 J 为 L_J-Lipschitz，则 |E[Δ̂] − ATE| ≤ L_J·ε_rep。因此 ε_tol 不是工程参数，而是**因果结论的偏差上界**。

**命题 3（统计有效性）** 若 n_pairs ≥ n_min(δ, σ_Δ, α, power) 且采用 Holm–Bonferroni，则 FWER ≤ α；仅当 CI 不含 0 且 p_adj < α 时判定 ADOPT，故假阳性率受控。

**命题 4（ESM 有界性）** 权重始终落在 [w_min, w_max] 且归一化，且只有 ADOPT 实验能改变权重，故权重既不会坍缩到单任务，也不会追随未经统计验证的噪声。

**定理（MTCE 不自我欺骗性）** 在命题 1–4 与 A66–A70 下，MTCE 每一轮的权重更新要么来自通过 J_stat 的有效改进（期望验证目标不降），要么保持原权重（INCONCLUSIVE 不动），故**验证目标序列在期望上单调不降，且不存在「未验证即采纳」的路径**。

### IP-161 SPC（共享-私有-多时标认知解耦）

```python
class SharedPrivateCognition(nn.Module):
    def __init__(self, d_obs=64, d_h=128, n_scenes=10, n_intents=5, d_K=6):
        super().__init__()
        self.phi_slow = SlowEncoder(d_obs, d_h)          # 大感受野 + 低通
        self.phi_fast = FastEncoder(d_obs, d_h)          # 小感受野 + 高通
        self.priv = nn.ModuleDict({
            'scene': PrivateHead(2 * d_h, d_h, n_scenes),
            'intent': PrivateHead(2 * d_h, d_h, n_intents),
            'impedance': PrivateHead(2 * d_h, d_h, d_K),
        })
        self.gate = Gate(2 * d_h, len(self.priv))

    def forward(self, slow_obs, fast_obs):
        h_s = self.phi_slow(slow_obs)
        h_f = self.phi_fast(fast_obs)
        out = {}
        for k, head in self.priv.items():
            g = self.gate(k, torch.cat([h_s, h_f], -1))  # [g_s, g_f]
            z = torch.cat([g[..., 0:1] * h_s, g[..., 1:2] * h_f], -1)
            out[k] = head(z)
        return out, h_s, h_f

def total_loss(out, targets, w, h_s, priv_reps):
    L = sum(w[k] * task_loss(out[k], targets[k]) for k in w)
    L_slow = smoothness_penalty(h_s)                     # 仅惩罚慢通道
    L_sep = sum(cos_sq(priv_reps[k], priv_reps[l])
                for k in w for l in w if k < l)
    return L + 0.1 * L_slow + 0.05 * L_sep
```

### IP-162/163 TAG + GHG（亲和图与梯度调和）

```python
class TaskAffinityGuard:
    def __init__(self, tau_aff=0.10, tau_neg=0.05, ema=0.9):
        self.a = defaultdict(float)
        self.tau_aff, self.tau_neg, self.ema = tau_aff, tau_neg, ema
        self.ntd_events = 0

    def update_affinity(self, grads):                    # grads: {task: grad_shared}
        for k, l in combinations(grads, 2):
            c = cosine(grads[k], grads[l])
            self.a[(k, l)] = self.ema * self.a[(k, l)] + (1 - self.ema) * c

    def harmonize(self, grads):
        g = dict(grads)
        for (k, l), a in self.a.items():
            if a < -self.tau_neg and dot(g[k], g[l]) < 0:
                g[k] = g[k] - (dot(g[k], g[l]) / (norm(g[l]) ** 2 + 1e-12)) * g[l]
        return g

    def detect_negative_transfer(self, loss_before, loss_after):
        for (k, l), a in self.a.items():
            if (a < -self.tau_neg and loss_after[k] > loss_before[k]
                    and loss_after[l] < loss_before[l]):
                self.ntd_events += 1
                return True
        return False
```

### IP-164 CPR（反事实配对重放）

```python
class CounterfactualPairedReplay:
    def __init__(self, epir, eps_tol=1e-3):
        self.epir, self.eps_tol = epir, eps_tol

    def checkpoint(self, M):
        return {
            'robot': M.robot.state_dict(), 'env': M.env.state_dict(),
            'rng': M.rng.get_state(), 'ctrl': M.controller.state_dict(),
            'obs': list(M.recent_obs), 'seq': M.epir.last_received,
        }

    def eligible(self, c):
        x0 = replay(c, treatment=False).robot_state_T
        x1 = replay(c, treatment=False).robot_state_T
        return dist(x0, x1) <= self.eps_tol          # 同臂二次重放自一致性

    def paired_experiment(self, c, treatment, control, metric, n_pairs):
        deltas = []
        for _ in range(n_pairs):
            deltas.append(metric(replay(c, treatment)) - metric(replay(c, control)))
        return paired_inference(deltas)

def paired_inference(deltas, alpha=0.05, n_boot=10000):
    d = np.asarray(deltas)
    boot = [np.random.choice(d, len(d), replace=True).mean() for _ in range(n_boot)]
    lo, hi = np.percentile(boot, [100 * alpha / 2, 100 * (1 - alpha / 2)])
    p = wilcoxon(d).pvalue if np.any(d != 0) else 1.0
    return {'delta': d.mean(), 'ci': (lo, hi), 'p': p, 'n': len(d)}
```

### IP-165/168 功效、多重比较与统计证书

```python
def min_pairs(delta, sigma, alpha=0.05, power=0.8):
    z_a, z_b = norm.ppf(1 - alpha / 2), norm.ppf(power)
    return int(np.ceil((z_a + z_b) ** 2 * sigma ** 2 / delta ** 2))

def holm(pvals, alpha=0.05):
    order = np.argsort(pvals)
    m, adj, prev = len(pvals), np.empty(len(pvals)), 0.0
    for rank, idx in enumerate(order):
        prev = max(prev, (m - rank) * pvals[idx])
        adj[idx] = min(1.0, prev)
    return adj

def build_stat_certificate(stats, alpha=0.05, power_target=0.8):
    keys = list(stats)
    adj = holm([stats[k]['p'] for k in keys], alpha)
    cert = {}
    for k, pa in zip(keys, adj):
        s = stats[k]
        if s['n'] < min_pairs(s['delta'], s['sigma'], alpha, power_target):
            decision = 'INCONCLUSIVE'
        elif s['ci'][0] > 0 and pa < alpha:
            decision = 'ADOPT'
        elif s['ci'][1] < 0 and pa < alpha:
            decision = 'REJECT'
        else:
            decision = 'INCONCLUSIVE'
        cert[k] = {**s, 'p_adj': pa, 'decision': decision}
    return cert
```

### IP-166 ESM（实验驱动多任务权重）

```python
class EmpiricalTaskWeights:
    def __init__(self, tasks, eta=0.1, w_min=0.05, w_max=0.60):
        self.w = {k: 1.0 / len(tasks) for k in tasks}
        self.eta, self.w_min, self.w_max = eta, w_min, w_max

    def update(self, margins, sigmas, stats):
        for k, d in margins.items():
            if stats[k]['decision'] != 'ADOPT':          # 只接受通过 J_stat 的实验
                continue
            shrink = d / max(sigmas[k], 1e-6)
            self.w[k] = np.clip(self.w[k] * np.exp(self.eta * shrink),
                                self.w_min, self.w_max)
        s = sum(self.w.values())
        for k in self.w:
            self.w[k] /= s
```

**一句话**：若把**不可复现的执行轨迹误当作反事实对照**——接触物理、机械磨损、传感器噪声让重放终态漂移，使配对差分 Δ_u 混入混杂项，而 ESM 又把被污染的 Δ̂ 固化为多任务权重——系统就会在「对比实验越做越多、J_stat 证书越来越漂亮」的同时，悄悄把共享主干推向一个**自洽但错误**的因果世界，形成「实验越做越自信、系统越学越偏」的漂移闭环；必须以「ε_rep 门槛 + 同臂自一致性预检 + 功效不足即拒做实验 + INCONCLUSIVE 不改权重」四重护栏，确保**证据链转为实验链之前，先证明它可重放**。
