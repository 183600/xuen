# 第 2 轮（灵感循环第 2 轮；本轮灵感：「因果推理」×「常识推理」）

> **基线**：上一轮（灵感「大语言模型」×「机器人」×「智能体」）MetricVoiceGauge-NCD-HUTDH-v17（定义 657–674；引理 137–142；实验 E691–E710）。
> 本轮纪律：**常识只提议，因果只裁决，证书仍是唯一授权**。不推倒 v17：v17 的 CLP/S2C/HCG/PSV/APS/AMC 与 v16 的 BTS/TRM/WBC/CSC/NCS/MCA/WCB、v13 的 AIO/RTIC/CPD/DGC/DDL/RTCR、v14 的 SCD/DSD/DCA/EDC、v12 的 USG/TGC/BAA/GAGP/UC、v11 的 HAS/HCC/HATD/HDT、v10 的 NGE/DSL/CC/CWM/CAE/NCP、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 与历轮不变式全部保留。六个新组件——CTM（因果转移模型）、CHG（常识假设生成器）、CGA（因果接地审计器）、PIB（部分识别界）、CTR（因果传输重校准器）、CCM（因果常识记忆）——一律以**中立元接入 v17 之上**，失效即严格退回 v17（引理 143），再沿 v17→v16→v15→…→v6 退化链退回。本轮只做三件事：把 v17 的"共形相似"改写为**机制可迁移的因果证书**、把"常识推理"改写为**因果图的缺失边提议器**、把"新颖组合不安全"改写为**部分识别上界**。

## 0. 直觉与动机

**灵感 1（因果推理 → 从"共形相似"到"机制可迁移"）**
直觉：v17 的软肋是共形证书只在"校准集与当前计划可交换"时成立，而 LLM 的价值正是产出前所未见的组合。共形推理回答"这个计划像不像我见过的计划"（相似性），因果推理回答"这个计划的每一步**为什么**会成立、换到新环境还成不成立"（机制）。核心创新：**因果转移模型（Causal Transition Model, CTM）**——把每个计划缝 `SC_i = Post_{n_i} ∩ Pre_{n_{i+1}}` 视为一次干预 `do(exit_{n_i}=x)`，用结构因果模型刻画状态变量的转移机制 `K_i(x'|x)`，并把"新颖"拆成两种：**组合新颖**（已知局部机制的新排列，可由因果图因子化，可给证书）与**机制新颖**（出现校准集与因果图都没有的因果边，共形分数最看不见）。关键反直觉点：**新颖性本身不是共形性的敌人——只要新颖组合能被已识别的局部机制因子化，因果图就能为组合签发证书；真正危险的是机制新颖**。但因果效应不一定可识别，因此核心纪律是：不可识别 ⇒ 输出部分识别区间 `[L_i,U_i]` ⇒ 安全只认上界 `U_i ≤ margin_causal`，否则 ⊥。这把 v17 的"外推假设"降格为"可检验的界"。

**灵感 2（常识推理 → 常识不是知识，是因果图的缺失边提议器）**
直觉：常识（"杯子会碎""湿地会滑""递东西要先松手"）在 LLM 里很流畅，但不可验证、跨文化不一致、会被幻觉污染。传统做法要么把它当事实注入（危险：虚假常识直通执行器），要么完全丢弃（浪费：最有价值的世界先验被浪费）。核心创新：**常识假设生成器（Commonsense Hypothesis Generator, CHG）+ 因果接地审计器（Causal Grounding Auditor, CGA）**。CHG 只把常识转成**候选因果假设**（候选变量、候选边、候选前置条件、候选危害），写入假设集 H；CGA 用观测数据的后门调整或主动干预去识别/证伪每条假设；只有被识别的边才进入 CTM。关键反直觉点：**常识的最大价值不是"知道答案"，而是"知道该问什么"**——它把因果图的空白边指出来，让系统知道哪里必须去测、哪里必须保守；未被接地的常识假设只能收紧余量（增加保守），永远不能放宽授权。

**灵感 3（两者如何统一 → 因果-常识双闸）**
统一：CTM 管"机制"，CHG/CGA/PIB 管"未知机制如何被安全地表达为界"，CTR 管"漂移下校准集如何因果重加权而非朴素可交换"，CCM 管"记忆记录干预而非相关"。v17 回答"哪些语言计划能被编译、认证与调度"（`Exec_v17`）；v18 回答"这些计划在机制层为什么成立、当机制新颖时其上界是否仍安全"（`Exec_v18`）。共享状态扩展 `ζ_ca=(..., G, H, ground, [L,U], w_transport, ccm_index, mech_novelty)`。**CHG 回答"该怀疑什么"，CGA 回答"这条怀疑能否被识别"，CTM 回答"识别后的机制是什么"，PIB 回答"识别不了时最坏能坏到哪"，CTR 回答"这套机制能否迁移到当前分布"，CCM 回答"历史干预能否作为证据"**。六者不是六个补丁，而是"提议—接地—建模—定界—迁移—记忆"的实现链。

## 1. 研究问题（轮次升级版）

- **Q1（因果图与可识别性）**：如何把缝转移写成 SCM `M=(G,F,P_U)`？哪些边可后门识别、哪些需主动干预、哪些只能部分识别？"组合新颖"与"机制新颖"如何用图结构判定（新边 vs 新排列）？误设（图缺变量）如何被检出而非被点估计掩盖？
- **Q2（常识接地）**：如何把自由文本常识转成可检验的候选边/变量？CGA 的证伪标准与统计功效如何设定？虚假常识（"玻璃杯可以坐上去"）的误接地如何被 PIB 兜底？接地样本量与主动干预预算如何分配？
- **Q3（部分识别的安全语义）**：`U_i=+∞` 的判定与传播规则？多缝复合上界如何组合（保守和、联合界、还是图上传播）？区间过宽导致计划通过率塌缩时，如何在不放宽安全的前提下恢复活性？
- **Q4（因果传输与记忆）**：CTR 的正性（positivity）与图匹配如何检验？传输假设失败时如何确定性回退？CCM 如何记录干预而非相关、如何避免混淆偏差污染 AMC 的剪除？

## 2. 设计原则（在 P28–P30 基础上新增 P31–P33）

**P31 因果裁决律（Commonsense Proposes, Causality Adjudicates）**
常识输出只能进入假设集 H：`h_k = (候选变量, 候选边, 候选前置/危害)`；任何假设在 `ground(h_k) ≠ identified` 之前**不得**进入 CTM、不得修改 S2C 锚集、不得放宽 HCG/PSV/APS 的任何阈值。被接地的因果命题**只能收紧**（缩小 `[L,U]` 的可行域或增大有效 margin），不得放宽。**常识层对授权集合的扩容基数恒为零**。

**P32 部分识别保守律（Unidentified Means Unsafe）**
对任一缝效应 `τ_i`，CTM 输出点估计仅当可识别；否则输出部分识别区间 `[L_i,U_i]`（由观测等价类/工具变量/边界分析给出）。因果缝证书 `CSC_i` 成立当且仅当 `U_i ≤ margin_causal`；不可识别且无法给出有限上界时取 `U_i=+∞`，等价于 `CSC_i=⊥`。**未知被显式编码为不安全，而不是被点估计的自信掩盖**。

**P33 因果传输律（Transport, Not Naive Exchangeability）**
漂移下 HCG 重校准不得默认"新样本与旧校准集可交换"；CTR 必须用选择图（selection diagram）给出传输权重 `w(x)=P_target(x)/P_source(x)`，并按因果图因子化，仅当（i）图结构在源/目标一致、（ii）正性 `P_source(x)>0` 于目标支撑上成立时才允许重加权；任一检验失败即回退 v17 的保守 α 或白名单。**传输假设是可检验的前提，不是默认成立的公理**。

## 3. 与基线的接口（如何退化）

- CTM 失效（因果图/结构学习不可用）⇒ 关闭因果裁决，退回 v17 HCG 共形（保守 α）——**等价 v17（更保守）**；
- CHG 失效（常识生成不可用）⇒ 假设集 H 为空，CTM 只含已识别边——**等价 v17（活性下降）**；
- CGA 失效（无法接地）⇒ 所有常识假设标 `unidentified`，PIB 取 `U=+∞`，只允许单节点/白名单计划——**等价 v17（单步执行）**；
- PIB 失效 ⇒ 一律按 `U=+∞` 处理，`CSC_i≡⊥`——**等价最保守 v17**；
- CTR 失效 ⇒ 退回 v17 朴素共形重校准或白名单——**等价 v17**；
- CCM 失效 ⇒ 空因果记忆，AMC 退回 v17 相关记忆——**等价 v17**；
- 六者全失效 ⇒ MetricVoiceGauge-NCD-HUTDH-v17，再沿 v17→v16→v15→v14→v13→v12→v11→v10→v9→v8→v7→v6 退化；
- **安全继承**：CTM 只收紧/拒绝，CHG 只增假设，CGA 只接地/证伪，PIB 只取上界，CTR 只重加权，CCM 只记录干预；六端口互不相交，均不能新增授权或放宽任何阈值；`Exec_v18⊆Exec_v17` 由引理 143 保证。

## 4. 预期贡献

1. **因果缝证书**：首次把计划缝从"采样覆盖"升级为"机制可迁移"，区分组合新颖与机制新颖，证明组合新颖可在因果图因子化下安全通过，而机制新颖被显式拒绝；
2. **部分识别安全语义**：给出 `[L,U]` 上界判据与 `U=+∞` 的保守语义，把 v17 的"外推假设"改写为"可检验的界"，使"未知"从隐患变为硬约束；
3. **常识假设接地**：给出"常识只提议、因果才裁决"的可实现管线，使 LLM 常识从不可信事实源降格为有用的假设生成器；
4. **因果传输重校准**：用选择图与正性检验替代朴素可交换性，修复 v17 风险 2（漂移下共形失效）；
5. **因果常识记忆**：记忆记录干预而非相关，剪除受因果调整约束，关闭混淆偏差污染记忆的攻击面；
6. **提议—接地—建模—定界—迁移—记忆六层分离**：v17 管"哪些计划可编译调度"，v18 管"这些计划为何成立、机制新颖时上界是否安全"，用 `Exec_v18⊆Exec_v17⊆Exec_v16⊆…` 把因果、常识、语言、行为、路线、动力学、实时全解耦；E711–E730 覆盖因果识别、部分识别覆盖、机制新颖、常识接地、传输校准、记忆抗混淆、端到端与消融。

## 5. 本轮最大风险

**一句话**：CTM 的因果图与可识别性依赖"我们选对了变量与边"，而常识提议的恰恰是**我们没见过的变量**；若真实致因变量从未进入图，后门调整会给出一个"看起来已识别"的错误点估计，PIB 也会因未观测混淆而以窄区间自信地覆盖错误——即"因果图缺变量、部分识别区间过窄、而真实机制在未建模变量上"的、可识别却因果错误的证书。

```python
# IP-415 Causal Transition Model：缝转移 SCM + 组合/机制新颖判定
class CausalTransitionModel:
    def __init__(self, graph, mechanisms, exo_prior, seam_table):
        self.G = graph              # G=(V,E)，仅含 E_identified
        self.F = mechanisms         # 每个 v 的结构方程
        self.PU = exo_prior
        self.seams = seam_table     # (n_i, n_{i+1}) -> 变量作用域

    def transition(self, n_i, n_j, x):
        # 干预：固定 exit 状态为 x，前向传播结构方程
        do = {v: x[v] for v in scope_exit(n_i)}
        return self.F.forward(self.G, do, self.PU)

    def seam_effect(self, n_i, n_j, x, pib):
        if not self.identifiable(n_i, n_j, x):
            return pib.bound(n_i, n_j, x)        # -> [L, U]，可能 U=+inf
        dist = self.transition(n_i, n_j, x)
        tau = prob_outside(dist, Pre(n_j))
        return (tau, tau)                        # point identified

    def identifiable(self, n_i, n_j, x):
        # 后门/前门/工具变量任一识别准则成立，且无未观测混淆
        return self.G.adjustment_identifies(n_i, n_j, x) \
           and not self.G.has_latent_confounder(n_i, n_j)

    def classify_novelty(self, nodes):
        # 组合新颖：节点与边都在 G_ground 中，只是新排列 -> 可因子化
        # 机制新颖：需要 G 外的边/变量 -> 不可因子化 -> U=+inf
        edges = transition_edges(nodes)
        if all(e in self.G.E for e in edges):
            return 'combination'
        return 'mechanism'


# IP-416 Commonsense Hypothesis Generator：常识只提议
class CommonsenseHypothesisGenerator:
    def __init__(self, llm, budget):
        self.llm = llm
        self.budget = budget

    def propose(self, ctx, plan, graph):
        # 让 LLM 指出"图里缺什么边/什么前置/什么危害"，而非给结论
        raw = self.llm.generate(
            prompt_hypotheses(ctx, plan, missing_edges(graph)),
            max_tokens=self.budget)
        return [parse_hypothesis(s) for s in raw]   # -> H，未接地，无裁决权


# IP-417 Causal Grounding Auditor：后门调整 / 主动干预
class CausalGroundingAuditor:
    def __init__(self, data, intervention_budget, alpha_test):
        self.data = data
        self.budget = intervention_budget
        self.alpha = alpha_test

    def audit(self, h, G):
        if h.edge is None and h.var is None:
            return 'unidentified'
        if backdoor_estimable(self.data, G, h):
            est, ci = backdoor_adjust(self.data, G, h, self.alpha)
            return 'identified' if ci.significant() else 'refuted'
        if self.budget > 0:
            self.budget -= 1
            est, ci = intervene_and_test(h)      # 主动干预
            return 'identified' if ci.significant() else 'refuted'
        return 'unidentified'                    # 预算耗尽 -> 保守


# IP-418 Partial-Identification Bound：不可识别 = 不安全
class PartialIdentificationBound:
    def __init__(self, margin_causal):
        self.margin = margin_causal

    def bound(self, n_i, n_j, x):
        # 观测等价类上的 τ 上下界；无法给出有限上界 -> +inf
        L, U = obs_equivalence_bounds(n_i, n_j, x)
        if U is None:
            U = float('inf')
        return (L, U)

    def certified(self, interval):
        L, U = interval
        return U <= self.margin            # 只认上界；U=+inf 必假

    def combine(self, intervals):
        # 多缝复合：保守用并集上界（max U）而非独立假设求积
        return (min(L for L, _ in intervals),
                max(U for _, U in intervals))


# IP-419 Causal Transport Recalibrator：传输而非可交换
class CausalTransportRecalibrator:
    def __init__(self, source_log, graph, alpha=0.05):
        self.src = source_log
        self.G = graph
        self.alpha = alpha

    def transport(self, target_ctx):
        # 1) 图匹配：源/目标选择图 S 上机制是否一致
        if not self.G.selection_compatible(self.src, target_ctx):
            return None                     # 图失配 -> 回退 v17 保守/白名单
        # 2) 正性检验：目标支撑上 P_source>0
        w = importance_weights(self.src, target_ctx)
        if not positivity_ok(w):
            return None                     # 正性失败 -> 回退
        scores = [r.score * w[r.idx] for r in self.src]
        return finite_sample_quantile(scores, 1 - self.alpha)


# IP-420 Causal Commonsense Memory：记录干预，抗混淆
class CausalCommonsenseMemory:
    def __init__(self, store, graph_version, poison_filter):
        self.store = store
        self.gver = graph_version
        self.pf = poison_filter

    def record(self, ctx, intervention, outcome, ground, conf_adj):
        if self.pf.suspect(ctx, intervention, outcome):
            return                          # 疑似投毒：不入库
        self.store.append((ctx, intervention, outcome, self.gver, ground, conf_adj))

    def evidence(self, h):
        # 只有 ground=identified 且 conf_adj 记录的干预证据可用于收紧界
        return [r for r in self.store
                if r.ground == 'identified' and r.conf_adj is not None
                and matches(r, h)]

    def prune_candidates(self, plans):
        # 剪除仍只移除/重排序；因果证据只提高"该剪"的置信度，不新增候选
        return [p for p in plans if not self.store.causally_unsafe(p)]


# 主闭环集成：MetricVoiceGauge-NCD-HUTDH-v18（因果-常识层）
def metricvoicegauge_round_18_causal_commonsense(M, s, obs, ...):
    # ---- v17 主路径原样保留（CLP/S2C/HCG/PSV/APS/AMC + v16 行为层）----
    results = middleware.run_cycle(runners={...}, ctx=ctx)

    # ---- 常识只提议：低频、异步，不进关键路径 ----
    if ctx.cycle_idx % ctx.hyp_period == 0:
        H_new = ctx.chg.propose(obs, ctx.last_plan, ctx.ctm.G)
        ctx.H = ctx.H | set(H_new)

    # ---- 因果接地审计：识别/证伪，未识别标 unidentified ----
    if ctx.cycle_idx % ctx.audit_period == 0:
        for h in ctx.H - ctx.grounded:
            g = ctx.cga.audit(h, ctx.ctm.G)
            ctx.ground[h] = g
            if g == 'identified':
                ctx.ctm.G.add_edge(h)       # 只有已识别边进图
            ctx.ccm.record(obs, h, g, ctx.ctm.G.version, None)

    # ---- 计划因果裁决：缝效应 -> 部分识别界 -> CSC ----
    def causal_certify(nodes):
        if ctx.ctm.classify_novelty(nodes) == 'mechanism':
            return False                    # 机制新颖：不可因子化 -> ⊥
        for (n_i, n_j) in pairs(nodes):
            interval = ctx.ctm.seam_effect(n_i, n_j, obs, ctx.pib)
            if not ctx.pib.certified(interval):
                return False                # U > margin 或 U=+inf -> ⊥
        return True

    # ---- v17 认证 + v18 因果上界，双闸同时通过才接受 ----
    ctx.aps.poll(now(), obs, m_star, h_max, ctx.clp, ctx.hcg, ctx.s2c, ctx.psv)
    plan_nodes, rung = ctx.aps.current(now(), drift)
    if plan_nodes is not None and not causal_certify(plan_nodes):
        plan_nodes, rung = None, 'V17_DEFAULT'   # 因果不通过 -> 退回 v17

    if rung in ('FULL', 'PREFIX'):
        plan_nodes, seam_state = ctx.psv.runtime_guard(plan_nodes, obs)

    action, c_low, c_up, fb, m_exec, h_exec = ctx.csc.schedule(
        x=obs, plan_nodes=plan_nodes,
        hw_state=hw_state, sw_cert=sw_cert, data_cov=data_cov, drift=drift)
    tau_cmd = ctx.wbc.compute_control(obs, task_spec=action)
    execute(tau_cmd if h_exec > 0 else fb)

    # ---- CTR：漂移时因果重校准，失败即回退 ----
    if ctx.cycle_idx % T_recalib == 0:
        q = ctx.ctr.transport(obs)
        if q is not None:
            ctx.hcg.q = q
        else:
            ctx.hcg.recalibrate_conservative(ctx.amc.store.recent(k))

    C, spatial_cert, claims, metrics, rewards = M.inherited_v17_path(ctx)
    return C, spatial_cert, claims, metrics, rewards
```

## 2. 推导

**引理 143（因果投影安全 / Exec_v18 ⊆ Exec_v17）** 若 CHG 只向假设集 H 增候选、CGA 只在 `ground=identified` 时向 `G` 加边、PIB 只取上界、CTM 只对机制新颖输出 ⊥、CTR 只在传输检验通过时替换 `q̂`、CCM 只剪除/重排序，则对任意输入与任意常识/记忆内容，`Exec_v18 ⊆ Exec_v17`，且因果层新增授权基数 `|NewAuth|=0`。证明：v18 的接受是 `HCG∧PSV∧CSC` 的合取，其中 `HCG`、`PSV` 由 v17 提供；`CSC` 是新增的**额外**合取项，只能把 v17 的接受集进一步过滤。CHG/CGA 只改变 `G`（影响 `CSC` 的计算），不改变 S2C 锚集与 v16 证书；PIB 只产生更紧的约束；CTR 若替换 `q̂` 也只在校验通过后替换为同样满足有限样本覆盖的量，且失败回退。所有端口都是"过滤/收紧/回退"，无任何端口能新增节点或放宽阈值。∎ 推论：**因果-常识层的最坏失效是活动性下降；相对 v17 的不安全率恒为零**。

**引理 144（部分识别上界保守性）** 设真实缝失效概率为 `τ_i`，PIB 输出满足 `τ_i ∈ [L_i,U_i]`（当 `ident=none` 时 `U_i=+∞`）。若 `CSC_i` 成立即 `U_i ≤ margin_causal`，则 `τ_i ≤ margin_causal`。证明：由区间包含性 `τ_i ≤ U_i`；`U_i ≤ margin` 传递得 `τ_i ≤ margin`。`U=+∞` 时 `certified` 恒假，故不可识别机制绝不通过。∎ 推论：**安全不依赖点估计正确，只依赖区间包含真实值；未知被编码为 `+∞`，从而"未知=不安全"是定理而非口号**。

**引理 145（常识接地的不可扩性）** 设 `H` 中未被 `ground=identified` 的假设 `h` 不修改 `G`、不修改任何阈值；被接地的假设只允许 `G` 增边（可能使 `CSC` 更严）或收紧 `[L,U]`。则对任意常识内容（含幻觉/对抗常识），`Exec_v18` 不增。证明：`CSC` 是关于 `G` 与 `[L,U]` 的单调约束：增边只会增加需检验的缝机制、收紧只会降低 `U` 的可行域，二者都不会使原本不满足 `U≤margin` 的缝变为满足；未接地假设不进入 `G`。故常识只能减少通过集。∎ 推论：**虚假常识的最大后果是"让系统更保守"，而不是"让系统更冒险"**。

**引理 146（因果传输校准的有效性）** 设源/目标选择图 `S` 上机制一致、正性成立、传输权重按因果图因子化，则 CTR 重加权后的接受规则在目标分布上满足 `P(接受真无效计划) ≤ α`；若图失配或正性失败，CTR 返回 `None` 并回退 v17 保守 α 或白名单。证明：在机制一致与正性下，重加权把目标分布的分数分布恢复为源分布的可识别变换，秩论证（引理 138）在加权经验分布上仍成立，故有限样本分位数保持 `≤α`；检验失败时不做任何替换，覆盖性由 v17 原规则保证。∎ 推论：**漂移不再是"共形假设被悄悄破坏"，而是"传输检验显式失败并确定性回退"**。

**引理 147（因果记忆抗混淆）** 设 CCM 只记录带 `conf_adj` 的干预/调整证据，且 `prune_candidates` 只移除/重排序候选、不新增 token、不改锚集/分位数/余量，则对任意记忆内容（含投毒），`Exec_v18` 不增；且由混淆产生的伪因果不能进入 `evidence`。证明：`evidence` 过滤要求 `ground=identified ∧ conf_adj≠None`，未调整的观测相关被排除；`prune` 的输出是输入子集（同引理 141）；记忆不作用于裁决边界。故记忆只能减少活动性。∎ 推论：**记忆投毒的最坏后果是"变笨"，不是"变危险"，且混淆偏差被结构性挡在证据之外**。

**引理 148（机制新颖遏制）** 设 `classify_novelty(π)=mechanism` 当且仅当计划转移需要 `G` 外的边或变量，此时 CTM 直接输出 ⊥。则任何机制新颖计划不被执行，且该拒绝只造成活性损失。证明：由定义，机制新颖意味着存在无法在 `G_ground` 中因子化的转移，`seam_effect` 无法给出可识别的有限上界，PIB 取 `U=+∞`，`CSC=⊥`；v18 接受要求 `CSC` 全成立，故拒绝。拒绝路径退回 v17 默认，`Exec_v17⊆Exec_v16` 由引理 137 保证安全。∎ 推论：**v17 风险中"校准集从未覆盖的缝隙暂态"被转化为"机制新颖检测 + 显式拒绝"，代价是新颖任务完成率，收益是不再有外推证书**。

## 6. 已知风险与失效模式

1. **因果图缺变量（未观测混淆）**：真实致因变量不在 `V` 中，后门调整给出"看起来可识别"的错误点估计，PIB 区间过窄。缓解：常识主动提议候选变量、负对照检验、敏感性分析（E-value）、图不确定时强制 `partial`。
2. **可识别性误判**：把仅相关当因果、把前门/工具变量条件用错。缓解：多重识别准则交叉验证、主动干预优先于观测调整、误识别审计。
3. **常识幻觉与误接地**：LLM 编造"看起来合理"的边并通过弱检验。缓解：严格显著性 + 效应量门槛、多源常识一致率、PIB 兜底、来源可信度加权。
4. **部分识别区间过宽**：`U` 长期 `>margin`，计划通过率塌缩，系统退化为 v17 默认。缓解：增加干预预算、分层识别、任务子空间投影、活性监视报警。
5. **主动干预代价与安全**：为识别因果边需真实试错，可能造成物理风险。缓解：仅在仿真/低风险状态干预、干预预算硬上限、干预前过 v16 证书。
6. **传输假设失败被漏检**：图结构差异隐蔽、正性在尾部失败。缓解：选择图差异检验、重叠诊断、尾部截断、失败即回退。
7. **因果计算延迟**：结构学习/区间计算可能昂贵。缓解：离线预计算、增量更新、计划接受时只做 O(\|V\|+\|E\|) 查询。
8. **CCM 记录偏差**：只记录"被执行的干预"，幸存者偏差使证据偏乐观。缓解：记录被拒计划的反事实、倾向得分加权、审计抽样。
9. **多缝复合上界过保守**：保守并集 `max U` 随计划长度线性增长，长计划几乎必被拒。缓解：图上传播代替独立并集、缝共享机制、分段接受。
10. **与 v17 计划缓存/BT 热更新交互**：因果图版本与计划缓存锚不一致，旧计划引用已删边。缓解：计划携带 `G_ver`，版本不符整体失效。
11. **常识与因果循环论证**：常识提议的变量又被同一 LLM 用于"验证"，误差相关。缓解：提议者与审计者分离、CGA 只用数据/干预不用 LLM 判断、独立校准。
12. **过度保守导致长期退化**：三层（PC∩HCG∩CSC）叠加使通过率趋零。缓解：加权而非纯合取、动态 `margin_causal`、证书族共享、活性报警与人工复核。

## 7. 本轮最大风险

**一句话**：CTM 的因果图与可识别性依赖"我们选对了变量与边"，而常识提议的恰恰是我们没见过的变量；若真实致因变量从未进入图，后门调整会给出一个"看起来已识别"的错误点估计，PIB 也会因未观测混淆而以窄区间自信地覆盖错误——即"因果图缺变量、部分识别区间过窄、而真实机制在未建模变量上"的、可识别却因果错误的证书。
