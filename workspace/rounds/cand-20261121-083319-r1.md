# 第 2 轮（新灵感循环第 2 轮；本轮灵感：「夹爪控制」×「鲁棒性」）

> **基线**：上一轮（灵感「大语言模型」×「机器人」×「智能体」）MetricVoiceGauge-NCD-HUTDH-v17（定义 657–686；引理 137–142；实验 E691–E710）。
> 本轮纪律：**证书从"点"升级为"球"，裕度从"可加"降为"取最小"**。不推倒 v17：v17 的 CLP/S2C/HCG/PSV/APS/AMC、v16 的 BTS/TRM/WBC/CSC/NCS/MCA/WCB、v13–v8 全部保留。六个新组件——GCC（抓取接触证书）、RME（鲁棒裕度引擎）、HCT（混合接触切换证书）、SLG（滑移遏制守卫）、DRC（分布鲁棒校准器）、RBB（鲁棒性预算经纪）——以**接触层 + 鲁棒性审计层**双身份接入 v17 执行侧与全塔，失效即严格退回 v17（引理 143），再沿 v17→v16→…→v6 退化。本轮只做三件事：把"抓取安全"改写为**力闭合 + 滑移裕度的接触证书**、把"证书成立"改写为**扰动球内的球证书（侵蚀集）**、把"多层叠加更安全"改写为**裕度预算不可膨胀的审计**。

## 0. 直觉与动机

**灵感 1（夹爪控制 → 接触是"点证书"失效最快的地方）**
直觉：v8–v17 的证书几乎都是**状态集合成员证书**——状态 x 落在 Pre/Run/Post 内即安全。但夹爪的安全性根本不在"状态在不在集合里"，而在**接触力是否落在摩擦锥内、是否力闭合、是否即将滑移**。同一状态 x（手指闭合、物体在指间）可以是稳固抓取，也可以是"看起来抓住、实则零摩擦裕度"的假抓取。核心创新：**抓取接触证书（Grasp Contact Certificate, GCC）**——把安全判据从"x ∈ S"升级为"存在接触力 f 使 Gf = −w_ext 且 f ∈ Π FC_i(μ_i)，且摩擦裕度 σ_i = μ_i f_{i,n} − ‖f_{i,t}‖ ≥ σ_min"。关键反直觉点：**接触证书不是状态证书的补集，而是它的严格加细**——状态证书说"手在这里"，接触证书说"手在这里且能持续对抗重力/惯性而不滑"。夹爪是整座证书塔里"状态成员"与"物理可行"差距最大的一层。

**灵感 2（鲁棒性 → 证书必须对扰动球成立，而非对估计点成立）**
直觉：v17 及其前身都隐含一个**标称性假设**——每个证书都在一个估计点/估计模型上计算，裕度被当作"点上的余量"。但真实系统有质量误差、质心偏移、摩擦系数不确定性、位姿误差、力跟踪误差、时延。核心创新：**鲁棒裕度引擎（Robust Margin Engine, RME）+ 侵蚀集球证书**。把证书 C 的鲁棒半径定义为 ε*(C) = sup{ε : C ⊖ B_ε 在 B_ε 扰动下前向不变}（C ⊖ B_ε 为 C 的 ε-侵蚀）。只有 ε*(C) ≥ ε_req 才接受。关键反直觉点：**"裕度"不是可加的**——十七层各留 5% 余量，不等于系统有 85% 余量；共享扰动下系统鲁棒半径是**各层的最小值**，不是和。多层堆叠最容易制造的错觉就是"层数越多越安全"，而实际上每多一层就多一个"假设自己有完整扰动预算"的漏洞。

**灵感 3（夹爪 × 鲁棒性 → 混合接触模式与滑移是鲁棒性的真正考场）**
直觉：夹爪控制是**离散-连续混合系统**：自由→接近→接触→抓取→抬起→搬运→放下→释放，每次模式切换都是一次"接触图拓扑变化"，正是 v17 计划缝 SC 在接触层的对应物，但更危险——缝隙里可能发生**冲击、掉落、滑移**。核心创新：**混合接触切换证书（Hybrid Contact Transition, HCT）+ 滑移遏制守卫（Slip Limit Guard, SLG）**。HCT 要求每次模式切换有切换证书 TC(i→j)（前模式后置 ∩ 后模式前置非空 + 力连续性 + 禁止切换黑名单：载重下释放、未力闭合就抬起）；SLG 监测滑移裕度 σ_i 与初始滑移征兆，裕度不足则**在力上限与物体易碎上限之间**增力，或退回 SAFE_HOLD。关键反直觉点：**抓取的最坏情况不是"没抓住"，而是"抓住了、抬起了、搬运中滑了"**——失败被延迟到不可恢复的时刻；所以滑移裕度必须在抬起前就被鲁棒证书覆盖，而不是在滑移发生后才补救。

**三者如何统一**
统一为 **v17 之上的"接触—鲁棒"审计层**：v17 回答"哪些语言计划被编译与调度"（`Exec_v17`），v18 回答"被调度的动作在接触层是否力闭合、在扰动球内是否仍力闭合、在接触模式切换时是否被切换证书覆盖"（`Exec_v18`）。GCC 是接触侧（力闭合），RME 是鲁棒侧（侵蚀球），HCT 是切换侧（模式图），SLG 是滑移侧（反馈遏制），DRC 是校准侧（分布鲁棒分位数），RBB 是审计侧（裕度预算不可膨胀）。共享状态 `ζ_ct=(contact_mode, GC, ε*, σ_min, U_set, μ̂, q̂_rob, budget_ledger, slip_flag)`。**GCC 回答"这个动作在接触上可行吗"，RME 回答"离不可行还有多远且扰动多大仍可行"，HCT 回答"模式切换被覆盖吗"，SLG 回答"现在滑了吗/快滑了吗"，DRC 回答"校准在漂移下还成立吗"，RBB 回答"这些裕度能不能相加"**。六者不是补丁，而是"接触—鲁棒—切换—滑移—校准—审计"的闭环。

## 1. 研究问题（轮次升级版）

- **Q1（接触证书与状态证书的关系）**：GCC 的力闭合判据如何与 v16 NC 的 Pre/Run/Post 合成而不冲突？接触力可行域 Π FC_i 的边界如何与状态集边界对齐？参数化抓取（抓哪里、多大力）如何投影到既有锚节点的参数域并同时满足力闭合？
- **Q2（鲁棒半径的可计算性）**：ε*(C) 在何种动力学/度量下可解析或可采样估计？侵蚀集 C ⊖ B_ε 在高维下如何表示与验证？共享扰动与独立扰动的预算如何区分？鲁棒半径估计本身的置信度如何给出（元鲁棒性）？
- **Q3（接触模式切换的覆盖）**：TC(i→j) 如何定义才能既覆盖冲击暂态又不过度保守？禁止切换黑名单如何证明完备？运行时切换失败（如抬起时检测到滑移）回退到哪个模式、如何保证回退本身也被覆盖？
- **Q4（滑移、校准与预算的活性边界）**：SLG 增力与物体易碎上限冲突时如何仲裁？DRC 的 Wasserstein 半径 ρ 如何在线估计？RBB 的"最小而非求和"会不会让系统过度保守而长期退化为 v17？裕度预算的分配如何随里程碑自适应？

## 2. 设计原则（在 P28–P30 基础上新增 P31–P33）

**P31 接触证书支配状态证书律（Contact Dominates State）**
任何涉及夹爪接触的动作，除满足 v16/v17 的状态证书外，必须携带接触证书 `GC = (力闭合标志, 摩擦裕度 σ, 扳手裕度 ρ_w, 接触图)`，且 `σ ≥ σ_min ∧ ρ_w ≥ ρ_w,min`。状态证书是接触证书的**必要条件而非充分条件**；不得以"状态在 Run 内"替代"力闭合成立"。接触力上限同时受执行器上限 f_max 与物体易碎上限 f_break 约束。

**P32 鲁棒裕度预算律（Robustness Budget Conservation）**
每个证书必须显式声明其扰动预算 D_i 与侵蚀半径 ε_i；系统级鲁棒半径在共享扰动度量下为 `ε_sys = min_i ε_i / L_i`（L_i 为各层度量到公共度量的 Lipschitz 常数），**禁止将各层裕度相加**。任何一层不得默认拥有完整扰动预算；RBB 负责审计与分配，发现"预算超卖"即拒绝该证书组合并回退。

**P33 接触模式切换闭合律（Contact Mode Transition Closure）**
接触模式图 M 上每条被允许的边 (i→j) 必须有切换证书 `TC(i→j)`（前模式后置 ∩ 后模式前置非空 + 力/速度连续性 + 非冲击约束）；禁止边黑名单（载重下释放、未力闭合抬起、滑移中搬运）硬阻断；运行时切换前复验 TC，失败即退到 SAFE_HOLD（其本身被证书覆盖），**不得从失败切换直接进入自由模式**。

## 3. 与基线的接口（如何退化）

- GCC 失效（力估计/接触模型不可用）⇒ 夹爪只执行 v17 单步动作、禁止多步抓取——**等价 v17（更保守）**；
- RME 失效（扰动集无法估计）⇒ ε* 取 0，退回标称证书——**等价 v17（名义安全，鲁棒性未证）**；
- HCT 失效 ⇒ 只允许"抓取—保持—释放"最小模式集，禁止抬起/搬运——**等价 v17（不移动负载）**；
- SLG 失效 ⇒ 抓取力固定为标称值、滑移仅靠 v16 守卫——**等价 v17**；
- DRC 失效 ⇒ 退回 v17 共形分位数（非鲁棒）——**等价 v17**；
- RBB 失效 ⇒ 保守取各层预算最小值——**等价 v17（不膨胀）**；
- 六者全失效 ⇒ MetricVoiceGauge-NCD-HUTDH-v17，再沿 v17→v16→v15→…→v6 退化；
- **安全继承**：GCC 只加接触约束，RME 只收缩证书为侵蚀集，HCT 只增切换约束，SLG 只增滑移约束，DRC 只收紧阈值，RBB 只做预算取最小。六端口互不相交，均不能新增授权或放宽任何阈值；`Exec_v18⊆Exec_v17` 由引理 143 保证。

## 4. 预期贡献

1. **接触证书层**：首次把"抓取安全"从状态集合成员升级为力闭合 + 摩擦/扳手裕度 + 接触图的联合证书，填补 v8–v17 在接触层的空白；
2. **球证书与侵蚀集鲁棒性**：把"证书成立"改写为"扰动球内成立"，给出鲁棒半径定义、最坏情形约简（摩擦取 μ⁻、质量取 m⁺）与可计算性；
3. **裕度预算不可膨胀**：指出十七层堆叠的"裕度可加"错觉，证明共享扰动下系统鲁棒半径取最小，给出 RBB 审计与分配；
4. **混合接触切换证书**：把 v17 计划缝推广为接触模式图的切换证书，覆盖冲击/掉落/滑移暂态，给出禁止切换黑名单与回退；
5. **滑移遏制与分布鲁棒校准**：给出滑移裕度、初始滑移检测、受限增力仲裁，以及 Wasserstein 鲁棒分位数替代共形分位数，直接回应 v17 最大风险（校准不可交换）；

## 5. 本轮最大风险

**一句话**：GCC 的力闭合与 RME 的鲁棒半径都依赖**接触模型与扰动集 U 的正确性**，而真实接触（软指、点/线/面接触、摩擦各向异性、物体形变、传感器迟滞）恰恰是建模误差最大的地方——系统可能对"模型内的扰动球"鲁棒，却对"模型外的接触非线性"完全不设防，形成"鲁棒证书覆盖了所有被建模的扰动、却漏掉了唯一真实发生的那类扰动"的鲁棒性幻觉。

# IP-415 Grasp Contact Certifier：力闭合 + 摩擦/扳手裕度
class GraspContactCertifier:
    def __init__(self, grasp_map, f_max, sigma_min, rho_min):
        self.G = grasp_map              # 6×m 抓取矩阵
        self.f_max = f_max              # 执行器上限
        self.sigma_min = sigma_min      # 摩擦裕度下限
        self.rho_min = rho_min          # 扳手裕度下限

    def friction_margin(self, f, mu):
        return [mu[i] * f[i].n - norm(f[i].t) for i in range(len(f))]

    def wrench_margin(self, mu, w_ext):
        # W(mu) = {G f : f in Π FC_i(mu_i), f_n <= f_max}
        W = achievable_wrench_polytope(self.G, mu, self.f_max)
        return inscribed_ball_radius(W) - norm(w_ext)

    def certify(self, f, mu, w_ext, graph):
        sig = min(self.friction_margin(f, mu))
        rho = self.wrench_margin(mu, w_ext)
        ok = (sig >= self.sigma_min
              and rho >= self.rho_min
              and force_closure(self.G, mu, self.f_max))
        return GraspCert(ok, sig, rho, graph)

    def __init__(self, dynamics, metric, epsilon_req, horizon):
        self.dyn = dynamics
        self.metric = metric            # 扰动/状态公共度量
        self.eps_req = epsilon_req
        self.H = horizon

    def erosion(self, C, eps):
        return {x for x in C if self.metric.dist_to_boundary(x, C) >= eps}

    def robust_radius(self, C, eps_grid):
        # eps* = sup{eps : C⊖B_eps 在 B_eps 扰动下 H 步前向不变}
        best = 0.0
        for eps in sorted(eps_grid):
            C_eps = self.erosion(C, eps)
            if C_eps and self.dyn.forward_invariant(C_eps, eps, self.H):
                best = eps
            else:
                break
        return best

    def worst_case_reduce(self, U):
        # 单调性：W(mu) 随 mu 递减、外扰随 m/质心偏移递增
        return U.worst_vertex()          # (mu^-, m^+, c_max)

    def certify(self, C, U):
        eps_star = self.robust_radius(C, U.eps_grid)
        return RobustCert(eps_star >= self.eps_req, eps_star, U)


# IP-417 Hybrid Contact Transition：接触模式切换证书
class HybridContactTransition:
    FORBID = {('LIFT', 'RELEASE'), ('TRANSPORT', 'RELEASE'),
              ('SLIP_RECOVERY', 'FREE'), ('APPROACH', 'LIFT'),
              ('CONTACT', 'TRANSPORT')}

    def __init__(self, nc_contact, force_continuity_tol):
        self.nc = nc_contact
        self.tol = force_continuity_tol

    def transition_cert(self, i, j, f_i, f_j):
        if (i, j) in self.FORBID:
            return False, 'FORBIDDEN'
        overlap = intersect(self.nc[i].Post, self.nc[j].Pre)
        if overlap is None or overlap.volume() == 0:
            return False, 'NO_OVERLAP'
        if norm(f_j - f_i) > self.tol:
            return False, 'IMPULSE'
        return True, 'OK'

    def runtime_guard(self, mode, next_mode, kappa, slip_flag):
        if slip_flag and next_mode in ('LIFT', 'TRANSPORT', 'RELEASE'):
            return 'SAFE_HOLD', 'SLIP_BLOCK'
        ok, why = self.transition_cert(mode, next_mode, kappa.f, kappa.f_next)
        return (next_mode if ok else 'SAFE_HOLD'), why


# IP-418 Slip Limit Guard：滑移遏制
class SlipLimitGuard:
    def __init__(self, sigma_min, f_break, force_rate_max):
        self.sigma_min = sigma_min
        self.f_break = f_break
        self.rate = force_rate_max

    def update(self, f, mu_min, slip_flag, fragile):
        sig = [mu_min[i] * f[i].n - norm(f[i].t) for i in range(len(f))]
        if min(sig) >= self.sigma_min and not slip_flag:
            return f, 'HOLD'
        # 增力受执行器 f_max、易碎 f_break、变化率三重上限
        target_n = [min(f[i].n + self.rate, self.f_break if fragile else INF)
                    for i in range(len(f))]
        if any(target_n[i] < f[i].n for i in range(len(f))):
            return f, 'SAFE_HOLD'       # 无法增力：保持，不动
        return with_normal(f, target_n), 'TIGHTEN'


# IP-419 Distributionally Robust Calibrator：Wasserstein 鲁棒分位数
class DistributionallyRobustCalibrator:
    def __init__(self, scores, alpha, wasserstein_radius, lipschitz=1.0):
        self.scores = scores
        self.alpha = alpha
        self.rho = wasserstein_radius
        self.L = lipschitz

    def robust_quantile(self):
        # W1 球内最坏 (1-alpha) 分位数上界：经验分位数 + L*rho（引理 146）
        q_emp = finite_sample_quantile(self.scores, 1 - self.alpha)
        return q_emp + self.L * self.rho

    def accept(self, score):
        return score <= self.robust_quantile()

    def recalibrate(self, recent_scores, drift_level):
        self.scores = recent_scores
        self.rho = estimate_wasserstein_radius(self.scores, drift_level)


# IP-420 Robustness Budget Broker：裕度预算不可膨胀
class RobustnessBudgetBroker:
    def __init__(self, lipschitz):
        self.L = lipschitz             # 各层度量→公共度量的 Lipschitz 常数

    def compose(self, certs):
        # 共享扰动：取最小；禁止求和（引理 147）
        eff = [c.eps / self.L[c.name] for c in certs if c.active]
        return min(eff) if eff else 0.0

    def audit(self, certs, eps_req):
        eff = self.compose(certs)
        oversold = [c.name for c in certs
                    if c.active and c.eps / self.L[c.name] < eps_req]
        return (eff >= eps_req), eff, oversold

## 3. 推导

**引理 143（接触-鲁棒层的授权不增）** 设 GCC 只对动作施加"力闭合 ∧ σ ≥ σ_min ∧ ρ_w ≥ ρ_w,min"谓词，RME 只把证书集 C 替换为侵蚀集 C⊖B_ε ⊆ C，HCT 只禁止 E_M 中的边、SLG 只在既有可行力区间 [f, min(f_max,f_break)] 内改写力的大小，DRC 只抬高接受阈值，RBB 只做预算取最小与拒绝，则对任意输入分布（含对抗输入）`Exec_v18 ⊆ Exec_v17`，且新增授权基数 `|NewAuth| = 0`。证明：六个算子都是作用在 v17 动作集上的过滤/收缩：侵蚀是子集运算，力闭合与裕度是额外谓词，HCT 删除边，SLG 不改变动作集只改变同一动作的力幅值（且落在原可行域内），DRC 减少接受，RBB 删除证书组合。过滤的复合仍为过滤，故可执行集单调不增。∎ 推论：**接触层与鲁棒层的失效模式只有单向——活动性下降；不安全率相对 v17 不升**。

**引理 144（鲁棒力闭合的最坏顶点约简）** 设 W(μ) 对每个 μ_i 单调不增（摩擦越小可达扳手集越小），外扰扳手范数 ‖w_ext(m,c)‖ 对质量 m 与质心偏移 ‖c‖ 单调不减，则 `inf_{u∈U} ρ_w(u) = ρ_w(worst(U))`，其中 worst(U)=(μ⁻, m⁺, c_max)。证明：ρ_w(u) = inscribed_ball_radius(W(μ(u))) − ‖w_ext(u)‖，两项分别在 μ 最小、m/c 最大处取最坏；对盒/球不确定集，单调函数的下确界在顶点取得（凸分析的标准结论），故整体下确界在组合最坏顶点取得。∎ 推论：**鲁棒力闭合无需遍历 U，只需评估有限最坏顶点**——这是 RME 可实时化的关键。

**引理 145（侵蚀球证书的鲁棒前向不变）** 设标称动力系统 F 在度量 d 下 1-Lipschitz，单步扰动满足 `d(x_{t+1}, F(x_t)) ≤ ε` 对一切 ‖d‖ ≤ ε 成立。若 `x_t ∈ C ⊖ B_{2ε}`，则 `x_{t+1} ∈ C ⊖ B_ε`。归纳得：C⊖B_{2ε} 在 ε-扰动下 H 步保持于 C。证明：F(x_t) ∈ C 且 d(F(x_t), ∂C) ≥ 2ε（因 x_t 侵蚀 2ε 且 F 1-Lipschitz 不放大距离），扰动再引入 ≤ ε，故 d(x_{t+1}, ∂C) ≥ ε，即 x_{t+1} ∈ C⊖B_ε ⊆ C。∎ 推论：**v17 的静态余量 vol(SC) ≥ margin 只有在 margin ≥ 2ε*（缝度量下）时才是鲁棒证书，否则只是标称证书**——这解释了为何"看起来有裕度"仍可能失稳。

**引理 146（分布鲁棒校准的有效性）** 设经验分数来自 P̂，真实分布 P 满足 `W_1(P̂, P) ≤ ρ_W`，非一致性分数映射对数据 1-Lipschitz。取 `q̂_rob = q̂_α + ρ_W`，则 `P(s > q̂_rob) ≤ α`。证明：W_1 对偶给出对任意 1-Lipschitz φ，`E_P[φ] ≤ E_{P̂}[φ] + ρ_W`；取 φ 为阈值指示的 Lipschitz 平滑近似，得 CDF 界 `F_P(t) ≥ F_{P̂}(t − ρ_W)`。于是 `P(s > q̂_α + ρ_W) = 1 − F_P(q̂_α + ρ_W) ≤ 1 − F_{P̂}(q̂_α) ≤ α`（最后一步由经验共形分位数的定义）。∎ 推论：**DRC 用"有界 Wasserstein 漂移"替换 v17 的"可交换性"**，直接回应 v17 风险 2；但 ρ_W 必须被可靠上界估计，否则界变空。

**引理 147（裕度预算不可膨胀）** 设证书 C_1,…,C_k 各自对扰动集 D_i（度量 d_i 下半径 ε_i）鲁棒，且真实扰动 d 为**共享**（同一 d 作用于所有层）。则复合保证成立当且仅当 `d ∈ ⋂_i D_i`；在公共度量 d_0 下等价于 `‖d‖ ≤ min_i ε_i / L_i`。特别地，`Σ_i ε_i` 不是有效保证；存在范数为 `min_i ε_i/L_i + δ` 的共享扰动使至少一层失效。证明：球之交是半径最小者；任何范数超过最小半径的 d 至少落在一个 D_i 之外，该层证书失效。独立扰动时可用联合界放宽，但共享扰动（同一次碰撞、同一质量误差）下不能。∎ 推论：**堆叠层数不能制造鲁棒性；RBB 必须取最小并标记超卖**，这证伪了"17 层 × 余量"的直觉。

**引理 148（滑移遏制不越界）** 设 SLG 仅在 `[f, min(f_max, f_break)]` 内按变化率上限增力，无法增力即转 SAFE_HOLD。则 (a) 不违反执行器/易碎上限，(b) 摩擦固定时 σ_i 随法向力单调不减，动作仍属 Exec_v18；(c) 若最大许用力下仍滑移，则 SAFE_HOLD 由 GCC 的静态抓取证书覆盖，不发生载重释放。证明：力更新被裁剪到可行集；σ_i = μ_i f_{i,n} − ‖f_{i,t}‖ 关于 f_{i,n} 单调增；SAFE_HOLD 保持当前力闭合抓取，GCC 在其上成立；载重释放属于禁止边（P33）。∎ 推论：**滑移遏制的最坏后果是"卡住保持"（活性损失），不是"掉落"**。

**引理 149（接触模式切换覆盖）** 若 M 上每条允许边 (i→j) 均有 TC(i→j)（Post_i ∩ Pre_j ≠ ∅ 且力连续），禁止边被硬阻断，运行时复验失败即转 SAFE_HOLD（其自身被证书覆盖），则执行不会进入禁止模式、不会在载重下滑移/释放。证明：图可达性被限制在允许边上；运行时守卫在切换前拦截；SAFE_HOLD ∈ 被认证模式集，且由引理 148(c) 覆盖。∎ 推论：**接触层的"缝"被切换证书逐边覆盖**，这是 v17 计划缝 SC 在混合系统上的严格推广。

## 7. 已知风险与失效模式

1. **接触模型外扰动（鲁棒性幻觉）**：GCC/RME 只对建模的 U 鲁棒；软指、形变、各向异性摩擦、传感器迟滞等未建模非线性可绕过证书。缓解：模型失配检测、残差监控、域随机化训练、保守兜底 SAFE_HOLD、周期性实物标定。
2. **最坏顶点约简的单调性前提失效**：若 W(μ) 在某些区域非单调（如接触点随摩擦改变拓扑），顶点约简低估风险。缓解：验证单调性、非单调区域补采样、拓扑变化触发重算。
3. **鲁棒半径估计过乐观**：侵蚀集在离散网格/采样下高估鲁棒半径，真实扰动更易越界。缓解：保守下界、网格加密、形式化验证工具、在线越界监测。
4. **预算超卖与接口不透明**：层间 Lipschitz 常数难以准确获得，RBB 可能低估预算或误报。缓解：层接口强制声明 (ε_i, L_i)、离线标定、超卖即拒绝的硬门。
5. **切换证书过度保守**：TC 要求力连续与重叠，可能使大量合法切换被阻断，系统退化为不动。缓解：分级 TC（宽松/严格）、过渡节点、自适应 δ_f、活性监视。
6. **SLG 与易碎上限冲突**：需增力防滑但物体易碎，可能陷入"滑移或压碎"两难。缓解：多接触点分散力、柔顺抓取、先降载再增力、任务级放弃策略。
7. **初始滑移检测滞后**：滑移征兆在低速/低摩擦下不明显，检出太晚。缓解：多模态融合（触觉/振动/编码器）、预测性滑移模型、保守 σ_min。
8. **Wasserstein 半径估计困难**：高维分布下 ρ_W 难以上界，DRC 界可能过松或过紧。缓解：低维分数嵌入、分位数跟踪、保守 ρ_W、按任务分族校准。
9. **接触图拓扑误判**：点/线/面接触误分类导致 G 错误，力闭合判定失真。缓解：接触分类器置信度门、多假设 G、拓扑变化重认证。
10. **实时性开销**：扳手多面体内切球与侵蚀集验证可能超预算。缓解：预计算/缓存、抓取时离线算、在线只查表、ANN/多面体近似。
11. **SAFE_HOLD 的活性代价**：频繁 SAFE_HOLD 使系统"安全但不动"，长期退化为 v17。缓解：活性报警、快速恢复路径、自适应阈值、任务重规划。
12. **与 v17 语言层的耦合**：v17 计划缝与 v18 接触切换证书可能重复约束或冲突。缓解：分层仲裁（接触层优先）、统一证书接口、冲突日志审计。

## 8. 本轮最大风险

**一句话**：GCC 的力闭合与 RME 的鲁棒半径都依赖接触模型与扰动集 U 的正确性，而真实接触（软指、点/线/面接触、摩擦各向异性、物体形变、传感器迟滞）恰恰是建模误差最大的地方——系统可能对"模型内的扰动球"鲁棒，却对"模型外的接触非线性"完全不设防，形成"鲁棒证书覆盖了所有被建模的扰动、却漏掉了唯一真实发生的那类扰动"的鲁棒性幻觉。
