### 第 4 轮灵感驱动研究记录（本轮为当前循环第 1 轮）

**灵感词**：故障诊断、激光雷达

**直觉与动机**：

先给直觉。前三轮 CADVS 的证书体系回答的是「此刻这条通道能不能用」（validation），却没有回答三个更接近临床的问题：它是否正在「带病工作」？若多条证书同时报警，病根在哪个子系统？它还能撑多久？证书像一张「此刻能否上岗」的健康证，故障诊断则像体检报告——给出隐疾、病灶定位与预后。一个证书仍然通过、但正在缓慢退化的系统，比一个证书已经失败的系统更危险，因为它制造的是「虚假安全感」。

再看激光雷达。它不是「再多一个传感器」，而是一种与相机、GNSS **失效模式近似正交**的几何锚：相机怕光照与纹理缺失，GNSS 怕遮挡，LiDAR 怕雨雾、反光与几何退化（长走廊、隧道、空旷场）。这种正交性有两个价值：其一，作为独立米制锚，直接缓解视觉伺服的深度模糊（R29）与差分定位退化（R30）；其二，作为**故障隔离的证据源**——当相机证书失效而 LiDAR 证书健康且几何可观测时，可判定故障是「视觉特异」而非「定位全局」，从而避免把健康传感器一起降级。

**关键洞见**：把「故障诊断」提升为一等证书（first-class certificate），并让恢复策略由**诊断结果**而非「任一证书失败」驱动。证书回答「能不能用」，诊断证书回答「为什么不能用、还能用多久、该换哪条路」。二者组合，使 CADVS 从「被动熔断」升级为「主动预后 + 定向重构」。

**严谨定义**：

1. **LiDAR 几何锚证书（LGAC）**。对点到面配准残差线性化，构造几何 Hessian
   `M_geo = Σ_i w_i [n_i; p_i×n_i][n_i; p_i×n_i]^T ∈ R^{6×6}`，
   做特征分解 `λ_1 ≤ … ≤ λ_6`。取 `ε = max(ε_abs, ε_rel·λ_6)`，定义退化子空间 `D_deg = span{u_j : λ_j < ε}`。证书 `LGAC = (M_geo, λ_min, λ_max, D_deg, ρ_inlier, s_weather)`，KC 规则
   `kc_lidar_observable = (λ_min ≥ ε_abs) ∧ (ρ_inlier ≥ r_min) ∧ (s_weather ≤ w_max)`。
   注意退化是**方向性**的：`D_deg` 告诉控制器「哪些自由度不要信 LiDAR」，而不是一刀切弃用。

2. **故障诊断证书（FDCert）**。故障模式集 `F = {none, cam, lidar_geom, lidar_weather, gnss, imu_bias, actuator}`。由残差/新息构造归一化新息平方 `d_k = r_k^T S_k^{-1} r_k`，再用 CUSUM 累积 `g_k = max(0, g_{k-1} + d_k − ν)`，`g_k > h` 判为有故障。诊断矩阵 `D_diag ∈ {0,1}^{|F|×|Certs|}` 编码每种故障模式预期的证书违规签名；观测违规向量 `v` 与 `D_diag` 的各列做加权最小距离匹配得 `f*`，置信度 `η` 用最近两列的距离间隔比定义。`FDCert = (f*, mode, η, severity, onset)`。

3. **早期故障与预后（IFPM）**。对每条通道维护健康指数 `H_i(t)`，用指数退化模型 `H_i(t) = a_i e^{b_i t} + c_i`（或线性漂移），粒子滤波在线更新参数后验；`RUL_i = inf{τ>0 : H_i(t+τ) ≥ H_thresh}`。当 `RUL_i < t_react` 且置信足够时，提前触发优雅降级，而不是等证书硬失败。

4. **诊断条件恢复（DCRP）**。映射 `π: (FDCert, CertState) → ControlMode`，`ControlMode ⊆ {student, student+vservo, lidar_anchored_pbvs, teacher, emergency_stop}`。仅当 `η ≥ η_min` 且预后支持时才执行定向恢复；否则退回与 v30 相同的保守通用回退。

5. **形式化目标（增量）**：
   - 定义 `Exec_DCADVS`，并证明 `Exec_DCADVS ⊆ Exec_v30`（诊断只做「选择」，不引入绕过证书的新动作）；
   - 证明在单故障 + 诊断矩阵满列秩 + 噪声有界下，隔离唯一且间隔有下界（引理 34）；
   - 证明低置信度诊断被拒绝时，DCRP 的期望成功率不劣于通用回退（fail-safe 性质）；
   - 目标指标：单故障隔离准确率 ≥ 90%，并发故障 ≥ 70%；早期故障平均检测延迟较单样本 χ² 降低 ≥ 40%；RUL 的 RMSE ≤ 1.5s；无谓回退率降低 ≥ 50%；故障自由场景下任务成功率相对 v30 无退化。

**本轮最大风险**：**诊断层的「自信地误诊」**——诊断本身没有被证书化，一旦在并发或遮蔽故障下把 LiDAR 几何退化误判为传感器故障（或反之），系统会高置信度地切到最不该用的模态，把一次可恢复的退化升级为灾难性失效；这比「不诊断、只保守回退」更危险，因为错误被包装成了确定性。

### IP-478 LiDAR Geometric Anchor Certificate (LGAC)

```python
import numpy as np
from dataclasses import dataclass


@dataclass
class LGAC:
    valid: bool
    evals: np.ndarray          # 升序，6 个特征值
    evecs: np.ndarray          # 6×6，列 = 特征向量
    D_deg: np.ndarray          # 6×k，退化方向
    rho_inlier: float
    s_weather: float
    M: np.ndarray


@dataclass
class LiDARGeometricAnchorCertificate:
    """IP-478 LGAC：点到面几何 Hessian 的方向性可观测性证书 + 逐自由度门控"""
    eps_abs: float = 0.05
    eps_rel: float = 0.02
    r_min: float = 0.60
    w_max: float = 0.50

    def compute(self, points, correspondences) -> LGAC:
        # correspondences: [(p, q, n)]，p 源点，q 目标面点，n 单位法向
        M = np.zeros((6, 6))
        for (p, q, n) in correspondences:
            J = np.concatenate([n, np.cross(p, n)])   # 1×6 点到面雅可比
            M += np.outer(J, J)
        evals, evecs = np.linalg.eigh(M)               # 升序
        eps = max(self.eps_abs, self.eps_rel * evals[-1])
        deg_idx = np.where(evals < eps)[0]
        D_deg = evecs[:, deg_idx]                      # 6×k
        rho = len(correspondences) / max(len(points), 1)
        s_weather = self._weather_score(points)
        valid = (deg_idx.size == 0) and (rho >= self.r_min) and (s_weather <= self.w_max)
        return LGAC(valid, evals, evecs, D_deg, rho, s_weather, M)

    def _weather_score(self, points) -> float:
        # 由回波强度分布、近距盲区比例、回波缺失率合成 [0,1]；越差越接近 1
        if len(points) == 0:
            return 1.0
        intensity = np.asarray([pt.intensity for pt in points], dtype=float)
        near_frac = np.mean(np.asarray([pt.range for pt in points]) < 1.0)
        missing = 1.0 - len(points) / max(getattr(points, 'expected', len(points)), 1)
        return float(np.clip(0.5 * (1 - np.mean(intensity) / 255.0)
                             + 0.3 * near_frac + 0.2 * missing, 0.0, 1.0))

    def observable_projector(self, lgac: LGAC) -> np.ndarray:
        eps = max(self.eps_abs, self.eps_rel * lgac.evals[-1])
        U = lgac.evecs[:, lgac.evals >= eps]
        return U @ U.T                                 # 6×6 投影到可观测子空间

    def per_dof_gate(self, lgac, H, P, R):
        """逐自由度 Kalman 增益门控：只在可观测子空间注入 LiDAR 信息"""
        P_obs = self.observable_projector(lgac)
        H_g = H @ P_obs                                # 退化方向观测行置零
        S = H_g @ P @ H_g.T + R
        K = P @ H_g.T @ np.linalg.pinv(S)
        return K, P_obs
```

### IP-479 Fault Diagnosis Certificate Kernel (FDCK)

```python
@dataclass
class FDCert:
    fault_id: int
    mode: str
    confidence: float
    severity: float
    onset: float


@dataclass
class FaultDiagnosisCertificateKernel:
    """IP-479 FDCK：NIS + CUSUM 检测，诊断矩阵签名匹配隔离"""
    nu: float = 1.0
    h_thresh: float = 8.0
    eta_min: float = 0.75
    modes: tuple = ('none', 'cam', 'lidar_geom', 'lidar_weather',
                    'gnss', 'imu_bias', 'actuator')
    # 行 = 故障模式，列 = [cam, lidar, gnss, imu, loc, vs]
    D: np.ndarray = field(default_factory=lambda: np.array([
        [0, 0, 0, 0, 0, 0],   # none
        [1, 0, 0, 0, 0, 1],   # cam
        [0, 1, 0, 0, 1, 0],   # lidar_geom
        [0, 1, 0, 0, 0, 0],   # lidar_weather
        [0, 0, 1, 0, 1, 0],   # gnss
        [0, 0, 0, 1, 1, 0],   # imu_bias
        [0, 0, 0, 0, 1, 1],   # actuator
    ], dtype=float))

    def __post_init__(self):
        self.g = 0.0
        self.onset = {}

    def update(self, violation: np.ndarray, residual: np.ndarray,
               S: np.ndarray, t: float) -> FDCert:
        d = float(residual @ np.linalg.solve(S, residual))    # NIS
        self.g = max(0.0, self.g + (d - self.nu))             # CUSUM 累积
        if self.g <= self.h_thresh:
            return FDCert(0, 'none', 1.0, 0.0, t)
        v = violation.astype(float)
        dists = np.linalg.norm(self.D - v[None, :], axis=1)
        order = np.argsort(dists)
        f1, f2 = int(order[0]), int(order[1])
        # 距离间隔比作为置信度：最近列越独占，诊断越可信
        eta = float((dists[f2] - dists[f1]) / (dists[f2] + 1e-9))
        onset = self.onset.setdefault(self.modes[f1], t)
        return FDCert(f1, self.modes[f1], eta,
                      float(self.g / self.h_thresh), onset)
```

### IP-480 Cross-Modal Fault Isolation (CMFI)

```python
@dataclass
class CertificateDependencyGraph:
    """IP-480 CMFI：证书依赖图 + 正交签名，用于多证书同时报警时的根因定位"""
    parents: dict = field(default_factory=lambda: {
        'loc': {'gnss', 'lidar', 'imu'},
        'vs': {'cam', 'loc'},
        'student': {'loc', 'vs'},
    })

    def root_cause(self, violated: set) -> set:
        # 若某违规节点的所有父节点都未违规，则它是根因
        roots = {c for c in violated
                 if not (self.parents.get(c, set()) & violated)}
        return roots or set(violated)

    def isolate(self, violated: set, fdc: FDCert) -> FDCert:
        """图根因与签名诊断交叉验证：一致则接受，冲突则降级为 none（fail-safe）"""
        roots = self.root_cause(violated)
        graph_ok = self._mode_matches_roots(fdc.mode, roots)
        if fdc.mode == 'none' or graph_ok:
            return fdc
        return FDCert(fdc.fault_id, 'none', 0.0, fdc.severity, fdc.onset)

    def _mode_matches_roots(self, mode: str, roots: set) -> bool:
        table = {'cam': {'cam'}, 'lidar_geom': {'lidar', 'loc'},
                 'lidar_weather': {'lidar'}, 'gnss': {'gnss', 'loc'},
                 'imu_bias': {'imu', 'loc'}, 'actuator': {'loc', 'vs'}}
        return bool(roots & table.get(mode, set()))
```

### IP-482 Diagnosis-Conditioned Recovery Policy (DCRP)

```python
from enum import Enum, auto


class ControlMode(Enum):
    STUDENT = auto()
    STUDENT_VSERVO = auto()
    LIDAR_ANCHORED_PBVS = auto()
    TEACHER = auto()
    EMERGENCY_STOP = auto()


@dataclass
class DiagnosisConditionedRecoveryPolicy:
    """IP-482 DCRP：诊断结果条件化的恢复选择；低置信度 fail-safe"""
    eta_min: float = 0.75

    def select(self, fdc: FDCert, cert_state) -> ControlMode:
        if fdc.confidence < self.eta_min or fdc.mode == 'none':
            return self._generic_fallback(cert_state)
        if fdc.mode == 'cam':
            return ControlMode.LIDAR_ANCHORED_PBVS
        if fdc.mode in ('lidar_geom', 'lidar_weather'):
            return (ControlMode.STUDENT_VSERVO
                    if cert_state.cam_ok and cert_state.vs_ok
                    else self._generic_fallback(cert_state))
        if fdc.mode in ('gnss', 'imu_bias'):
            return ControlMode.TEACHER
        if fdc.mode == 'actuator':
            return ControlMode.EMERGENCY_STOP
        return ControlMode.STUDENT

    def _generic_fallback(self, cert_state) -> ControlMode:
        # 与 v30 的 FallbackAction 语义一致：保守通用回退
        if cert_state.student_ok and cert_state.cert_all_passed:
            return ControlMode.STUDENT
        if cert_state.teacher_ok:
            return ControlMode.TEACHER
        return ControlMode.EMERGENCY_STOP
```

### DCADVS 统一执行流（单步）

```python
def dcadvs_step(robot_state, sensor_data, t) -> ControlOutput:
    """诊断条件 CADVS：LiDAR 锚与诊断均为旁路（10–50Hz），不进入 200Hz 伺服硬实时环"""
    # 0) 证书聚合（同 v30）
    cert_agg = wait_for_topic('/cert/aggregated', timeout=0.005)

    # 1) LiDAR 几何锚证书：逐自由度门控只影响 EstimatorNode 的测量更新
    lgac = lidar_anchor.compute(sensor_data.points, sensor_data.corr)
    if not lgac.valid:
        estimator.set_lidar_observable_subspace(lgac.D_deg)

    # 2) 故障诊断证书（旁路）
    violation = cert_agg.violation_vector()          # [cam, lidar, gnss, imu, loc, vs]
    fdc = fdck.update(violation, cert_agg.residual, cert_agg.S, t)
    fdc = cmfi.isolate(set(cert_agg.violated), fdc)

    # 3) 预后证书
    pcert = ifpm.update('loc', cert_agg.health('loc'), t)

    # 4) 诊断条件恢复：仅当诊断被接受且/或预后告警时改变模态
    if not cert_agg.all_passed or fdc.mode != 'none' or pcert.degrade:
        mode = dcrp.select(fdc, cert_agg)
        return execute_mode(mode, robot_state, sensor_data)

    # 5) 无故障：退回 v30 正常路径
    return cadvs_step(robot_state, sensor_data)
```

## 3. 复杂度分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 | 实时性指标 |
|---|---|---|---|---|
| LGAC Hessian 构造 | O(N_corr) | O(1) | N_corr≈5000 | ~1–2ms @10Hz |
| LGAC 特征分解 | O(6³) | O(36) | — | < 0.05ms |
| 逐自由度门控 | O(m·6²) | O(m·6) | m=6–18 | < 0.05ms |
| FDCK NIS + CUSUM | O(m³) | O(1) | m≤18 | < 0.05ms |
| CMFI 签名匹配 | O(|F|·|Certs|) | O(1) | 7×6 | < 0.01ms |
| 证书依赖图根因 | O(|Certs|·|E|) | O(|Certs|) | ≤12 节点 | < 0.01ms |
| IFPM 粒子滤波 | O(N_p) | O(N_p) | N_p=256, 10Hz | ~0.2ms |
| DCRP 选择 | O(1) | O(1) | — | < 0.01ms |
| **端到端诊断链路** | **O(N_corr + N_p)** | **O(N_corr)** | **旁路 10–50Hz** | **< 3ms，不影响 200Hz 伺服** |

**与 v30 时序 SLO 的关系**：LiDAR 与诊断都部署在**旁路**（10–50Hz），只向 EstimatorNode 提供方向性子空间、向恢复策略提供模态选择；200Hz 视觉伺服环不等待 LiDAR，故不引入新的硬实时负担。这直接回应上一轮 R28 的时序张力。

## 4. 正确性论证（增量更新）

### 引理 32（逐自由度门控对近退化方向的一致性保护）

**陈述**：设 LiDAR 点到面几何 Hessian `M_geo` 的特征分解为 `{(λ_j, u_j)}`。对任意 `λ_j < ε`，若滤波器沿 `u_j` 方向注入非零增益，则当 `λ_j → 0` 时该方向的有效信噪比趋于 0，而后验协方差沿 `u_j` 被虚假削减，估计器出现过度自信（不一致）；将观测投影到可观测子空间 `P_obs = Σ_{λ_j≥ε} u_j u_j^T` 后，沿退化方向的后验协方差保持不变，且可观测子空间内的信息增益有下界 `ε`，估计器保持一致。

**证明（要点）**：`M_geo` 的二次型 `ξ^T M_geo ξ = Σ_i (n_i^T ξ + (p_i×n_i)^T ξ)²` 度量观测对位姿扰动 `ξ` 的敏感度；沿 `u_j` 的敏感度为 `λ_j`。当 `λ_j → 0`，测量对 `ξ_j` 几乎无信息，其等效测量噪声方差按 `1/λ_j` 放大，故该方向 SNR → 0。若仍以未正则化的增益更新，等价于把「无信息」当作「强信息」，使 `P_jj` 被削减到低于 Cramér–Rao 下界，后续与其他传感器融合时会被错误地赋予高权重。投影 `P_obs` 将 `u_j` 方向置零，等价于贝叶斯意义上「无信息方向不做更新」，故 `P_jj` 不变、可观测方向增益有界。∎

**工程含义**：`D_deg` 不是「弃用 LiDAR」的开关，而是「哪些自由度不要信 LiDAR」的方向清单；这正是长走廊（沿轴退化）、隧道（绕轴退化）等场景的关键。

### 引理 33（CUSUM 对早期故障的最优检测延迟）

**陈述**：设故障前 / 后 NIS 序列 `d_k` 独立同分布，均值分别为 `ν_0 < ν_1`。在所有满足平均误报间隔 `ARL_0 ≥ γ` 的停止规则中，以漂移 `ν = (ν_0+ν_1)/2` 的 CUSUM `g_k = max(0, g_{k-1} + d_k − ν)` 在 `g_k > h` 停止，可最小化最坏情况平均检测延迟 `sup_τ E_τ[(T−τ)^+ | T>τ]`。

**证明**：这是 Lorden（1971）与 Moustakides（1986）关于 CUSUM 的经典 minimax 最优性结果；本文不重复证明，仅将其作为 IFPM 采用 CUSUM 而非单样本 χ² 阈值的理论依据。∎

**工程含义**：单样本 χ² 只能发现「大而瞬时」的故障，对缓慢漂移（IMU 零偏、LiDAR 视场污染累积）不敏感；CUSUM 通过累积微小偏移，在给定误报预算下取得最短检测延迟，正是「早期故障」需要的性质。

### 引理 34（满秩诊断矩阵下的单故障唯一隔离与间隔下界）

**陈述**：设恰有一个故障模式 `f` 激活，观测违规向量 `v = D_diag e_f + δ`，其中 `e_f` 为单位向量、`‖δ‖₂ ≤ δ_max`。若 `D_diag` 的列两两可区分且
`δ_max < ½ · min_{f≠g} ‖D_diag e_f − D_diag e_g‖₂ =: ½ d_min`，
则最近列匹配 `f* = argmin_g ‖v − D_diag e_g‖₂` 唯一等于 `f`。

**证明**：由三角不等式，对任意 `g≠f`，
`‖v − D_diag e_g‖ ≥ ‖D_diag e_f − D_diag e_g‖ − ‖δ‖ ≥ d_min − δ_max > δ_max ≥ ‖v − D_diag e_f‖`，
故 `f` 严格优于任何 `g`。唯一性由 `d_min > 0` 保证。∎

**工程含义**：诊断矩阵的列间距 `d_min` 是「可隔离性」的度量；若两种故障的证书签名过于接近（如 lidar_geom 与 lidar_weather 都只触发 lidar 证书），则无论算法多好都无法隔离。CMFI 通过引入正交证据（几何可观测性 vs 强度/回波统计）把列间距拉开。

### 定理（DCADVS 执行集包含性与 fail-safe 不劣性）

**陈述**：在假设
(A1) 至多一个故障模式激活；
(A2) `D_diag` 满列秩且满足引理 34 的间隔条件；
(A3) 诊断置信度 `η` 经校准（`η ≥ η_min ⇒` 最近列匹配正确）；
(A4) DCRP 的所有输出模态均取自预先审计的集合 `V = {student, student+vservo, lidar_anchored_pbvs, teacher, emergency_stop}`；
下成立：
(i) `Exec_DCADVS ⊆ Exec_v30`；
(ii) 对任一证书违规事件，DCRP 的期望任务成功率不低于 v30 的通用回退策略。

**证明**：
(i) 诊断层只读取证书与残差，输出是对 `V` 中元素的**选择**，不生成新的、绕过证书校验的控制动作；每个被选模态仍须满足其自身的证书前提（如 student 需 `cert_agg.all_passed`）。故新增执行路径均在 `Exec_v30` 的允许集合内，且诊断失败时退回通用回退，因此 `Exec_DCADVS ⊆ Exec_v30`。
(ii) 分两种情形。若 `η < η_min` 或 CMFI 判为冲突，DCRP 调用 `_generic_fallback`，与 v30 完全一致，成功率相等。若 `η ≥ η_min`，由 (A1)(A2)(A3) 隔离正确，DCRP 选择针对真实故障的模态；而通用回退会丢弃所有非教师通道（包括仍健康的通道），定向恢复保留健康通道，故在该故障模式下可行动作集是通用回退的超集，成功率不低于通用回退。综上取期望不劣。∎

**诚实声明**：定理的关键假设 (A1)(A3) 在真实系统中**不恒成立**：并发 / 遮蔽故障会破坏单故障假设，置信度校准也可能随分布漂移失效。DCADVS 用 CMFI 的图-签名交叉验证、`η_min` 拒绝选项与 fail-safe 回退来缓解，但不能消除——这正是本轮最大风险的来源。

## 7. 本轮最大风险（最终确认）

**一句话**：**诊断层的「自信地误诊」**——诊断本身没有被证书化，一旦在并发或遮蔽故障下把 LiDAR 几何退化误判为传感器故障（或反之），系统会高置信度地切到最不该用的模态，把一次可恢复的退化升级为灾难性失效；这比「不诊断、只保守回退」更危险，因为错误被包装成了确定性。
