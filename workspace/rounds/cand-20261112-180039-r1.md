# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「多模态大模型」×「意图理解」）

> 第 60 轮用 SGEC 把「场景语义 → 阻抗先验 → 意图约束 → 执行证据」闭合成环（SSM×CIEC×EPIR×SERC×PCE++++），但其认知层仍是**封闭世界**：
> 1. **意图是有限枚举**：CIEC 的 I = {'慢点','加紧','轻触','稳定','危险'} 是手写映射，无法覆盖开放词表、组合语义与上下文指代（"把那个挪开一点，别碰倒旁边的杯子"）。
> 2. **场景先验是手工标定的**：SSM 的 10 个场景与 π_scene(K|z) 需人工配置，遇到新物体、新材料、新 affordance 只能落进 `unknown`。
> 3. **「理解即执行」的同构假设**：第 60 轮默认"意图一旦被理解就应立刻变成约束"。但多模态大模型（MLLM）的语义输出是**高延迟、随机、可能幻觉**的；若把它的自然语言结论直接写进 ERTC，就是把"不确定的语义"伪装成"确定的约束"——这正是本项目一路警惕的抽象泄漏，而且这一次泄漏发生在**最上游**，下游的证据链再完备也无法救回一个错误意图。

## 0. 直觉与动机

**灵感 1（MLLM 是"语义传感器"，不是"控制器"）**
直觉：摄像头 + 麦克风 + 力/触觉可以喂给一个 MLLM，让它用自然语言说出"用户想让我轻拿左边的玻璃杯"。但 MLLM 的输出与力传感器读数在认识论上不同：力传感器**可重复、有量纲、可证伪**；MLLM 的一句话是**一次采样、无常量、不可直接证伪**。因此正确姿势是把 MLLM 当作**一个带 provenance 的可疑语义观测器**——它只能"提议"，不能"下令"。执行约束必须由确定性编译器生成，并接受物理证据的复核。

**灵感 2（开放词表意图 → 类型化意图帧）**
直觉：人说的话是开放的，但机器人能执行的约束是封闭的。桥接方式不是让 LLM 直接输出 `K_p=0.5`，而是让它输出一个**类型化意图帧**（动词槽、对象槽、区域槽、程度槽、否定槽、作用域），再由本体映射到 ERTC/EEIS 的已知约束轴。"轻一点"→程度槽=轻→F_max↓、K_d↑；"别碰蓝色杯子"→否定槽+对象槽→区域排除约束。未知槽值不许猜，必须变成"澄清问题"或"安全默认"。

**灵感 3（语义-物理一致性：用一次"探针"来接地）**
直觉：MLLM 说"这是易碎品，要轻"，但当前力读数已经在上升——语义与物理打架。此时最省事的不是继续相信某一方，而是做一个**最小探针动作**（如 0.5mm 微位移轻触），用接触刚度 / 滑移事件去证伪其中一个假设。"意图理解"因此不是一次性推理，而是**主动实验**：每一次探针都在缩小语义假设集合。

**灵感 4（保形校准：让"我不知道"成为合法输出）**
直觉：MLLM 的 softmax 置信度在分布外会系统性过度自信。与其相信它报的 0.95，不如用一小批标定样本做**保形预测（conformal prediction）**：对每个观测给出一个*意图集合* C(x)，使真实意图以 ≥ 1-α 的概率落在集合里。若 |C(x)|=1 → 可执行；|C(x)|>1 → 歧义，追问或探针；C(x)=∅ → 拒识，回退默认。这样"我不知道"不再是失败，而是一等公民。

**灵感 5（异步双通道 + 安全单调修订）**
直觉：MLLM 推理可能要 300ms~2s，而控制周期是毫秒级。等它想清楚，机会已经过去。方案是**快慢双通道**：快通道用小型意图分类器 / 意图记忆先给出一个**保守**约束并立即锁定；慢通道的 MLLM 稍后返回，可以做"更紧"的修订，但**默认不得放宽**已生效的安全约束（除非重新走完整验证）。这把第 60 轮"认知先行"的单向时序，升级为"先保守占位、后语义精修"的可撤销契约。

**灵感 6（意图记忆账本与漂移检测）**
直觉：同一个用户的"轻一点"在不同天可能含义不同（今天手受伤了→更轻）。把意图-约束映射连同证据与作用域记入**意图记忆账本（IML）**，可复用、可溯源、可撤销；同时用执行证据监测**偏好漂移**，一旦漂移显著就冻结记忆、回到在线推断。

**灵感 7（合流 → 接地多模态意图闭环 GEM）**
直觉：MLLM 产出开放意图 → 保形校准给可信集合 → 意图帧编译器落成契约 → 物理探针证伪/确认 → 快慢通道安全修订 → 证据回写记忆。形成"**语义提议—统计担保—契约编译—物理接地—安全修订**"五段式闭环。核心口号：**语义可以开放，执行必须闭合；模型可以出错，契约必须可证伪。**

## 1. 形式化定义（增量：定义 161–168）

**定义 161（多模态意图假设 MIH）** 给定多模态观测 o = (I_rgb, I_depth, L, F_{1:T}, Q_{1:T}, H)，其中 L 为语言、F 为力/触觉、Q 为本体感知、H 为交互历史。MLLM 以温度 T>0 采样 k 次，按**语义等价**（意图帧规范化后相等）聚类得到 m 个假设：

  MIH(o) = {(h_i, p_i, prov_i)}_{i=1}^{m}，
  - **意图帧** h_i = (v, obj, region, deg, pol, scope)，见定义 162；
  - **自洽置信** p_i = n_i / k（簇频次归一），并满足 Σ p_i = 1；
  - **溯源** prov_i ⊆ (模态 × 区域/时间片) 是支持该假设的证据跨度集合。
  MIH 是"语义先验"，**不得**直接作为控制输入。

**定义 162（类型化意图帧与本体映射）** 意图帧 τ = (verb, object, region, degree, polarity, scope)。本体 O 给出类型：Verb、Object、Region、Degree∈[0,1]、Polarity∈{+,−}、Scope∈{instant, task, session}。约束轴 A = {v_max, F_max, K_p, K_d, ε_traj, E_region, τ_hold, …}。映射 M: 槽值 × 极性 × 程度 → 对若干约束轴的有向改写。
- **组合规则**：极性（negation）支配（否定槽优先收紧或排除）；程度做 min/max 合并；作用域决定约束的保持时长。
- **良型（well-typed）**：所有*任务关键槽*（verb、object/region）非 ⊥。存在关键槽为 ⊥ 时称 τ 为**欠定（underspecified）**，必须澄清或回退。
- 映射 M 是**确定性的、版本化的**：同一 (τ, 本体版本) 必产出同一约束集，且每个轴可回溯到具体槽位（为定义 165 的证书提供 provenance）。

**定义 163（保形意图校准 CIC）** 设标定集 D_cal = {(o_j, y_j)}_{j=1}^{n} 与测试观测 o 可交换（exchangeable）。用自适应预测集（APS）打分：
  s(o, y) = Σ_{y' : p̂(y'|o) ≥ p̂(y|o)} p̂(y'|o)，
  q̂ = Quantile_{⌈(n+1)(1−α)⌉/n}({s(o_j, y_j)})。
  预测集 C(o) = { y : s(o, y) ≤ q̂ }。
- **覆盖率担保**：在可交换性下 P(Y_{true} ∈ C(o)) ≥ 1−α。
- **准入策略**：
  - `|C(o)|=1` 且 top1 概率 ≥ p_min → **Admit**（进入定义 165）；
  - `2 ≤ |C(o)| ≤ m_max` → **Clarify**（追问或触发定义 164 探针）；
  - `C(o)=∅` → **Reject**（回退安全默认）。
- **OOD 闸门**：以嵌入距离 d(o) 对照标定集分布；若 d(o) > d_q（标定分位数），可交换性被破坏，**暂停覆盖率担保**，强制转入 Clarify/探针并触发增量重标定。

**定义 164（语义-物理一致性接地 SGP）** 设语义后验 p_sem = p_i，物理证据 e_phys = (接触事件, 刚度估计 k̂, 滑移指示 σ, 力曲线)。接地间隙
  g(o, H) = H(p_sem) + λ·D(p_sem ‖ p_phys)，
  其中 p_phys 为 e_phys 对假设的似然后验，H 为熵，D 为 KL 散度。**一致性算子** Φ(h, e_phys) ∈ {support, refute, neutral}，实现为"每个意图帧对可观测量的事前预测"与实测的匹配。
- **探针选择**：a* = argmax_a E[ H(H) − H(H | z_a) ] − λ_p·cost_probe(a)，s.t. 探针在**所有**假设下均满足当前安全包络（否则该探针不可选）。
- **停机**：后验熵 < τ_H，或接地预算 B_grd 耗尽（耗尽则退回 Clarify）。

**定义 165（意图契约编译器 ICC）** 编译器 CC: (τ, C(o), e_phys) → (C_intent, Cert_intent) | Clarify | Reject。
- **可采纳性**：C_intent ⊆ R_safe(当前 ERTC 契约)（契约只能是安全域的子集）。
- **证书** Cert_intent = (provenance_hash, conformal_margin = 1−s(o,y), grounding_hash, expiry, revocation_token, compiler_version)。
- **偏序**：C₁ ⊑ C₂ 当且仅当 C₁ 的可行域 ⊆ C₂ 的可行域（C₁ 更紧或相等）。此偏序是定义 166 单调修订的基础。
- 编译失败（欠定/冲突/越界）→ 输出 Clarify 或**安全默认**，绝不"自由发挥"。

**定义 166（异步双通道与安全单调修订 SMR）** 快通道 f_fast 在 t₀ 用小型分类器 / IML 检索给出保守约束 C_fast，且要求 C_fast ⊑ C_default（默认安全包络）；慢通道 f_slow 在 t₀+Δ 由 MLLM 给出 C_slow。修订规则：
  - C_slow ⊑ C_fast → **自动改约**（只收紧，安全）；
  - C_slow ⊐ C_fast → **升级**：必须通过完整 CC + 单例保形 + 物理支撑才可放宽，否则保留 C_fast 并记录冲突；
  - Δ > τ_response → C_slow 视为**过期**丢弃，作为新请求重入（保证"认知不可逆"不会把旧意图强加于新状态）。
  由此得到**安全单调性**：在无完整重验证的情况下，生效契约的可行域只减不增。

**定义 167（意图记忆账本 IML）** 条目 e = (context_sig, τ, C_intent, provenance, ttl, confidence, drift_stat)。按相似度检索复用；漂移用 Page-Hinkley 统计量对执行证据做序贯检验，报警即**冻结**相关条目并转在线推断。所有条目可撤销（revocation_token），且写入与删除均留痕。

**定义 168（接地多模态意图闭环 GEM 与 PCE+++++ 预算）** 算子 GEM(M, o, task)：
```
① MLLM.observe(o) → MIH
② CIC.admit(MIH, D_cal) → Admit / Clarify / Reject
③ if 语义-物理不一致: SGP.probe(选 a*, 采集 z) → 更新 MIH
④ ICC.compile(τ, C(o), e_phys) → (C_intent, Cert_intent) | Clarify
⑤ SMR: 快通道占位 → 慢通道收紧/升级
⑥ ERTC.lock(C_intent, Cert_intent) → 执行
⑦ EV-exec ← 执行证据；IML.write(条目, 证据)
⑧ XMC+++: 用语义+物理+执行三源更新场景/意图信念
⑨ Return (C_intent, Cert_intent, EV-exec, IML.status)
```
预算 PCE+++++ 在 B_scene/B_intent/B_ros/B_exec 之外增加：
  B_sem = (MLLM 调用次数, token 预算, 延迟预算)，
  B_grd = (探针次数, 探针位移预算)，
  B_ver = (集成采样数 k, 验证器调用数)。
  VOI 扩展：voi_sem = VOI_belief − cost_sem − cost_grd − cost_exec；任一子预算耗尽即按**降级阶梯**回退：全量 GEM → 无 MLLM（仅 IML/小模型）→ 无记忆（仅在线小模型）→ 纯保守默认。

## 2. 关键算法伪代码

### IP-161 MIU（多模态意图理解）

```python
class MultimodalIntentUnderstanding:
    def __init__(self, mllm, k_samples=8):
        self.mllm = mllm
        self.k = k_samples

    def infer(self, obs):
        raw = [self.mllm.sample_frame(obs, temperature=0.7)
               for _ in range(self.k)]
        clusters = {}
        for frame, prov in raw:
            key = canonicalize(frame)          # 规范化槽位后作键
            clusters.setdefault(key, {"frame": frame, "n": 0, "prov": set()})
            clusters[key]["n"] += 1
            clusters[key]["prov"] |= prov
        mih = []
        for c in clusters.values():
            mih.append({"frame": c["frame"],
                        "p": c["n"] / self.k,
                        "prov": frozenset(c["prov"])})
        mih.sort(key=lambda x: -x["p"])
        return mih                         # 语义先验，不直接下发给执行
```

### IP-163 CIC（保形意图校准）

```python
class ConformalIntentCalibrator:
    def __init__(self, alpha=0.05, p_min=0.6, ood_quantile=0.99):
        self.alpha = alpha
        self.p_min = p_min
        self.q_hat = None
        self.scores = []
        self.ood_threshold = None

    def fit(self, cal_obs, cal_labels, score_fn, embed_fn):
        self.scores = [score_fn(o, y) for o, y in zip(cal_obs, cal_labels)]
        n = len(self.scores)
        level = math.ceil((n + 1) * (1 - self.alpha)) / n
        self.q_hat = np.quantile(self.scores, min(level, 1.0))
        d = [embed_fn(o) for o in cal_obs]
        self.ood_threshold = np.quantile(d, self.ood_quantile)

    def gate(self, o, probs, score_fn, embed_fn):
        labels = range(len(probs))
        C = [y for y in labels if score_fn_from_probs(probs, y) <= self.q_hat]
        if embed_fn(o) > self.ood_threshold:
            return "Clarify", C, "ood"           # 担保失效，强制澄清
        if len(C) == 0:
            return "Reject", C, "empty"
        if len(C) == 1 and probs[C[0]] >= self.p_min:
            return "Admit", C, "singleton"
        return "Clarify", C, "ambiguous"
```

### IP-164 SGP（语义-物理一致性探针）

```python
class SemanticPhysicalGrounder:
    def __init__(self, tau_H=0.5, lambda_p=0.2):
        self.tau_H = tau_H
        self.lambda_p = lambda_p

    def should_probe(self, mih, phys_likelihood):
        p_sem = np.array([h["p"] for h in mih])
        p_phys = normalize(phys_likelihood)
        gap = entropy(p_sem) + kl_div(p_sem, p_phys)
        return gap > threshold_from(self.tau_H)

    def choose_probe(self, mih, probe_actions, safe_envelope):
        best, best_ig = None, -np.inf
        for a in probe_actions:
            if not all(within_safe(a, h["frame"], safe_envelope) for h in mih):
                continue                        # 探针必须在所有假设下安全
            ig = expected_info_gain(mih, a) - self.lambda_p * cost(a)
            if ig > best_ig:
                best, best_ig = a, ig
        return best                             # None ⇒ 无安全探针，转 Clarify
```

### IP-165 ICC（意图契约编译）

```python
class IntentContractCompiler:
    def compile(self, frame, conf_set, phys_evidence, ertc):
        if is_underspecified(frame):
            return Clarify(reason="missing_critical_slot")
        axes = ontology_map(frame)              # 槽位 → 约束轴（确定性）
        C = Compose(axes, polarity=frame.polarity,
                    degree=frame.degree, scope=frame.scope)
        if not C.subset_of(ertc.safe_region):
            return Clarify(reason="exceeds_safe_envelope")
        cert = Certificate(
            provenance_hash=hash(frame + phys_evidence),
            conformal_margin=1 - conf_set.score,
            grounding_hash=hash(phys_evidence),
            expiry=now() + frame.scope.ttl,
            revocation_token=uuid4(),
            compiler_version=COMPILER_VERSION)
        return C, cert
```

### IP-166 SMR（安全单调修订）

```python
def safe_monotone_revision(C_fast, C_slow, full_check, now, t0, tau_response):
    if now - t0 > tau_response:
        return C_fast, "stale_discarded"
    if C_slow.leq(C_fast):                       # 更紧或相等
        return C_slow, "tightened"
    if full_check(C_slow):                       # 放宽需完整重验证
        return C_slow, "reverified_relax"
    return C_fast, "relax_rejected"
```

### IP-168 GEM（接地多模态意图闭环）

```python
def grounded_embodied_multimodal_loop(M, obs, task):
    mih = M.miu.infer(obs)
    status, C, why = M.cic.gate(obs, probs_of(mih), score_fn, embed_fn)
    if status == "Reject":
        return defaultsafe(M), "reject"
    if M.sgp.should_probe(mih, M.phys_likelihood()):
        a = M.sgp.choose_probe(mih, M.probe_actions, M.ertc.safe_region)
        if a is None:
            status = "Clarify"
        else:
            z = M.execute_probe(a)
            mih = M.miu.refine(mih, z)
    if status == "Clarify":
        C_intent, cert = M.icc.compile(default_frame(task), ...)
    else:
        C_intent, cert = M.icc.compile(mih[0]["frame"], C, M.evidence)
    C_fast = M.fast_path.predict(obs)                  # 保守占位
    C_final, mode = safe_monotone_revision(
        C_fast, C_intent, M.icc.full_check, now(), t0, M.tau_response)
    M.ertc.lock(C_final, cert)
    ev = execute_and_build_evidence(M, C_final)
    M.iml.write(obs, mih[0]["frame"], C_final, ev)
    M = xmodal_fuse_plus_plus_plus(M, obs, mih, ev)
    return M, C_final, cert, ev, mode
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证（在假设成立时） |
|---|---|---|---|
| MIU | O(k·C_mllm) | O(m·\|frames\|) | 自洽聚类给出语义后验，m ≤ k |
| CIC | O(n log n) 拟合 / O(m) 推理 | O(n) | 可交换下覆盖率 ≥ 1−α |
| SGP | O(\|A_probe\|·m) 选探针 | O(m) | 探针不越出安全包络 |
| ICC | O(\|A\|) 编译 | O(\|A\|) | C_intent ⊆ R_safe，且逐轴可溯源 |
| SMR | O(1) 判序 | O(1) | 生效契约可行域单调不增（无重验证时） |
| GEM | O(闭环) | 复用 | 五段式闭环，任一级失败均有降级 |

**正确性定理（GEM）**：假设 A66–A72 成立——**(A66)** MLLM 采样簇构成对真实意图的合理覆盖；**(A67)** 标定集与测试观测可交换，α∈(0,1)；**(A68)** SGP 的探针均满足当前安全包络；**(A69)** ICC 的本体映射确定且版本一致；**(A70)** ERTC 的安全域定义良构；**(A71)** SMR 的偏序 ⊑ 与可行域包含一致；**(A72)** IML 条目带有效未过期 revocation_token。则：
1. **统计担保**：在 A67 成立且未触发 OOD 闸门时，P(Y∈C(o)) ≥ 1−α；触发 OOD 时不主张担保，强制 Clarify。
2. **执行安全**：若 ICC 成功编译，则 C_intent ⊆ R_safe；若编译失败，输出安全默认而非越界约束。
3. **单调安全修订**：在无完整重验证时，SMR 使生效契约可行域单调不增；放宽必经过 full_check。
4. **可追责性**：任一生效契约都携带 provenance + 证书，可回溯到具体意图帧、物理证据与编译器版本。
5. **预算安全**：B_sem/B_grd/B_ver 任一耗尽，按降级阶梯回退，绝不静默继续。

> 注意：定理 1 的可交换性在多模态分布漂移下**并不自动成立**，这是本方案最脆弱的环节，见第 5 节。

### IP-161 MIU（多模态意图理解）

```python
class MultimodalIntentUnderstanding:
    def __init__(self, mllm, k_samples=8):
        self.mllm, self.k = mllm, k_samples

    def infer(self, obs):
        clusters = {}
        for _ in range(self.k):
            frame, prov = self.mllm.sample_frame(obs, temperature=0.7)
            key = canonicalize(frame)
            c = clusters.setdefault(key, {"frame": frame, "n": 0, "prov": set()})
            c["n"] += 1
            c["prov"] |= prov
        mih = [{"frame": c["frame"], "p": c["n"] / self.k,
                "prov": frozenset(c["prov"])} for c in clusters.values()]
        return sorted(mih, key=lambda x: -x["p"])
```

### IP-163 CIC（保形意图校准）

```python
class ConformalIntentCalibrator:
    def __init__(self, alpha=0.05, p_min=0.6, ood_q=0.99):
        self.alpha, self.p_min, self.ood_q = alpha, p_min, ood_q

    def fit(self, cal_obs, cal_labels, score_fn, embed_fn):
        self.scores = [score_fn(o, y) for o, y in zip(cal_obs, cal_labels)]
        n = len(self.scores)
        level = math.ceil((n + 1) * (1 - self.alpha)) / n
        self.q_hat = np.quantile(self.scores, min(level, 1.0))
        self.ood_threshold = np.quantile([embed_fn(o) for o in cal_obs], self.ood_q)

    def gate(self, o, probs, score_fn, embed_fn):
        C = [y for y in range(len(probs)) if score_fn(probs, y) <= self.q_hat]
        if embed_fn(o) > self.ood_threshold:
            return "Clarify", C, "ood"          # 担保失效，强制澄清
        if not C:
            return "Reject", C, "empty"
        if len(C) == 1 and probs[C[0]] >= self.p_min:
            return "Admit", C, "singleton"
        return "Clarify", C, "ambiguous"
```

### IP-164 SGP（语义-物理一致性探针）

```python
class SemanticPhysicalGrounder:
    def should_probe(self, mih, phys_likelihood, tau=0.5):
        p_sem = np.array([h["p"] for h in mih])
        p_phys = normalize(phys_likelihood)
        return entropy(p_sem) + kl(p_sem, p_phys) > tau

    def choose_probe(self, mih, actions, safe_env, lam=0.2):
        best, best_ig = None, -np.inf
        for a in actions:
            if not all(within_safe(a, h["frame"], safe_env) for h in mih):
                continue                        # 探针必须在所有假设下安全
            ig = expected_info_gain(mih, a) - lam * cost(a)
            if ig > best_ig:
                best, best_ig = a, ig
        return best                             # None ⇒ 无安全探针，转 Clarify
```

```python
def safe_monotone_revision(C_fast, C_slow, full_check, now, t0, tau):
    if now - t0 > tau:
        return C_fast, "stale_discarded"
    if C_slow.leq(C_fast):                 # 只紧不改松
        return C_slow, "tightened"
    if full_check(C_slow):                 # 放宽需完整重验证
```

### IP-168 PCE+++++（语义-接地-验证预算）

```python
class SemanticBudget:
    def __init__(self, mllm_calls=4, tokens=4096, latency=1.0,
                 probes=2, ver_samples=8):
        self.B = {"mllm_calls": mllm_calls, "tokens": tokens,
                  "latency": latency, "probes": probes, "ver": ver_samples}
        self.used = {k: 0 for k in self.B}

    def spend(self, key, amount=1):
        if self.used[key] + amount > self.B[key]:
            return False
        self.used[key] += amount
        return True

    def degradation_level(self):
        if self.used["mllm_calls"] >= self.B["mllm_calls"]:
            return "no_mllm"        # 仅 IML / 小模型
        if self.used["probes"] >= self.B["probes"]:
            return "no_probe"       # 歧义直接澄清
        return "full"
```
