# 第 2 轮（灵感循环第 2 轮；本轮灵感：「续航能力」×「社会规范理解」）

> **基线**：第 7 轮 MetricVoiceGauge-OTL-GC-ER（定义 493–529；引理 73–76；实验 E513–E525）。
> 本轮纪律：**能量即证书寿命 + 规范即道义约束**。两个灵感分别把「续航」从 M₂ 的一个效率项提升为**会令证书失效的一等资源**，把「社会规范」从指令字面语义之外提升为**带不确定性、可冲突、非补偿的道义约束**。两者必须可分离、可审计、可退化；非补偿约束的退化方向是**更保守**，不是消失。

## 0. 直觉与动机

**灵感 1（续航能力 → 证书有“半衰期”）**

第 7 轮的指标体系会把“能耗”当作 M₂ 效能层的一个标量：省电更好，但省电与否不改变“这张证书是否仍然算数”。这在短程演示里成立，在长时任务里是错的。

直觉上，任何证书都隐含一个前提：**机器人还有足够的能量完成当前动作、安全中止、并返回/停靠**。电量下降不是让某个 KPI 变差，而是让证书的**有效期**缩短。于是“续航”不应只被建模为效率项，而应被建模为：

- 一个单调递减的资源 `E(t)`；
- 一个带概率下界的**返航可行性不变量**；
- 一个随电量下降而触发的、预声明的**退化阶梯**。

关键设计判断：低电量时最危险的不是“任务做不完”，而是系统为了做完任务而**悄悄削掉安全/规范余量**。因此能量退化只能削减可选增强模块与任务范围，不能削减硬安全；并且要**提前**退化，而不是等到最后一刻突然关机。形象地说，证书不该在电池耗尽时才失效，而应在“还能安全回家”的边界到来之前就主动降级。

**灵感 2（社会规范理解 → 规范是潜在道义约束，不是礼貌标签）**

语音指令不只是“动作字符串”，它同时是一次**社会行为**。“请让一下”“别靠太近”“等行人先过”“小声一点”都可能在运动学上完全安全，却在社会意义上不可接受。现有 VoiceCommandTyping / GCT 处理的是字面任务语义，缺少对“谁在什么情境下、依据什么规范、期待什么行为”的建模。

直觉上，社会规范具有四个特征：

1. **潜在性**：规范很少被完整说出，需要从措辞、语境、共处对象、既往反馈中推断；
2. **道义性**：规范不是普通偏好，而有“禁止 / 应当 / 允许”的模态，禁止性规范通常不可用效率或电量来补偿；
3. **可冲突性**：让路可能违反“按时到达”，隐私规范可能违反“拍照取证”，需要优先级与例外；
4. **文化/情境依赖性**：同一距离在不同场景、不同人群、不同文化中含义不同，不能硬编码一套“万能礼貌”。

因此“理解”至少包含：语音行为识别 → 规范候选生成 → 潜参数（距离、等待时间、音量、路径侧）推断 → 合规风险证书 → 冲突消解 → 不确定时主动澄清。规范不确定性不能被“默认没有规范”消解；更安全的默认是**保守行为或询问**。

**灵感 3（合流 → “绿色-礼貌悖论”）**

续航与规范并非两个独立插件，它们会相互拉扯：

- 规范合规往往**耗能**：等待行人、绕行、减速、保持更大距离、降低音量都可能增加时间与基础功耗；
- 能量压力会**诱导规范侵蚀**：电量越低，系统越有动机“快速穿过人群”“省略等待”“贴近通过”，而这些恰恰发生在长时共处场景中；
- 若把能量当作可与规范交换的效用，低电量会系统性地把禁止性规范挤出去，且证书表面仍然“合规”。

所以本轮的核心不是“再加两个模块”，而是建立一条**非补偿性的仲裁序**：

```
硬安全 M₀  >  禁止性规范 F  >  返航可行性  >  义务性规范 O  >  任务进度  >  能耗/可选模块
```

能量只允许削减最后两项（任务范围、可选模块），不允许补偿前四项。若低电量到了连“履行义务性规范并返航”都不可行的地步，系统应进入**规范死锁保护**：安全停等并请求人类澄清/接管，而不是静默违规。这样，“续航”负责让系统活得久，“规范”负责让系统活得体面，二者由仲裁器而不是由标量权重耦合。

## 1. 研究问题（本轮升级版）

- **Q1（续航作为证书有效期）**：如何把剩余能量、返航能量与规范预留能量统一为带概率保证的预算证书，使“证书半衰期”可计算、可监控、可提前退化？
- **Q2（规范的表示、推断与证书）**：如何从语音行为与上下文中推断“禁止/应当/允许”规范及其潜参数，给出带覆盖保证的合规证书，并在规范冲突或低置信时安全澄清？
- **Q3（能量-规范非补偿仲裁）**：如何形式化并证明“能量压力不能诱发禁止性规范违背”，同时避免规范合规把任务预算饿死？
- **Q4（规范保持的退化）**：当 EBC/NGG/仲裁器失效时，如何保证退化方向是“更保守/停等”，而不是“悄悄丢掉非补偿约束”？

## 2. 设计原则（在 P7–P9 基础上升级为 P10–P12）

**P10 续航预算证书（Endurance Budget Certificate, EBC）**

能量不再只是 M₂ 的效率项，而是证书有效性的约束：

```
Ê_α(t+Δ) = E(t) − P_max·Δ − z_{1−α}·σ_E·√Δ
S_E(t)   = Ê_α(t+Δ) − (E_res + R_dock(t) + N_res(t))
EBC 有效 ⇔ S_E(t) ≥ 0
```

其中 `R_dock(t)` 是保守返航能量上界，`N_res(t)` 是为当前活跃规范预留的最坏情况能量。证书半衰期定义为

```
T½(t) = max { Δ ≥ 0 : S_E(t, Δ) ≥ 0 }
```

系统必须在 `T½` 耗尽前进入下一级能量阶梯，而不是等到电量见底。

**P11 社会规范接地阶梯（Norm Grounding Ladder, NGL）**

规范不是标签，而是可失效的道义约束：

```
n = (scope, modality, condition, audience, priority, source, confidence, TTL)
modality ∈ {F 禁止, O 应当, P 允许}
```

- 从语音行为（请求、命令、提醒、抱怨）与语境生成候选规范；
- 对潜参数（最小距离、等待时长、音量上限、通行侧）维护后验，而不是点估计；
- 禁止性规范映射到 M₀ 的非补偿否决；义务性规范映射到 M₁/M₃ 的软硬混合约束；允许性规范只界定边界；
- 冲突消解采用 `F > O > P`，同模态按“特异性 > 优先级 > 来源权威 > 新近性”；
- 低置信或不可消解时，进入**澄清/停等**，而不是猜测。

**P12 能量-规范仲裁与规范预留（EcoNorm Arbitration, ENA + Norm Reserve, NRS）**

先做可行性过滤，再做字典序优化：

```
A_feas = A_safety ∩ A_F ∩ A_dock
J(a)   = (J_hard, J_F, J_dock, J_义务, J_任务, −J_能耗)   字典序
N_res(t) = max_{活跃规范的可行履行计划} 最坏情况能量
mission_budget = Ê_α − E_res − R_dock − N_res
```

`N_res` 在任务预算之前扣除：能量紧张时先缩小任务，而不是先放弃规范。若 `mission_budget < 0`，削减任务/可选模块；若连 `N_res` 都不可行，进入规范死锁保护（安全停等 + 请求接管）。

## 3. 与基线的接口（如何退化）

- **EBC / 能量阶梯失效** ⇒ 使用静态保守预留 `E_static = 25%·E_cap` 与固定返航余量，关闭预测性续航优化；等价于“R7 + 静态能量守卫”（记作 v7-E0）。
- **NGG / 规范冲突消解失效** ⇒ 退回字面 GCT + 最近一次已认证规范（带 TTL）；TTL 过期后使用保守社会安全包络（更大距离、让行、减速）或停等询问。**已认证的禁止性规范不因模块失效而消失**；它要么保留，要么触发保守停等。
- **ENA / NRS 失效** ⇒ 退回静态优先级“安全 > 任务”与固定预留；等价于 R7。
- **三者均失效** ⇒ 严格退回 MetricVoiceGauge-OTL-GC-ER（v7）。
- **关键不对称**：可选的“规范细节增强”可以退化为 v7；但已经成为非补偿硬约束的禁止性规范，退化方向只能是**更保守**，不能是“回到没有规范”。这条不对称是本轮区别于普通插件式退化的核心。

## 4. 预期贡献

1. **续航即证书有效期**：EBC、返航不变量与证书半衰期，把能耗从效率项提升为可验证的资源约束；
2. **规范接地与合规证书**：带不确定性、来源、例外与 TTL 的道义规范表示，以及可审计的合规风险上界；
3. **非补偿性能量-规范仲裁**：字典序可行域 + 规范能量预留，证明能量压力不能购买禁止性违规；
4. **规范保持的退化链**：模块失效时非补偿约束只向更保守方向退化，避免“安全层先掉线”；
5. **主动澄清策略**：把规范不确定性转化为可计算的询问/停等决策，减少沉默误判；
6. 实验覆盖 E526–E543：能量标定、返航保证、阶梯抖动、规范侵蚀红队、跨情境稳健、形式验证、端到端与人因评估。

## 5. 本轮最大风险

**一句话**：最大的风险是把社会规范当成可学习、可量化的软约束——规范误读、文化偏差与能量-规范耦合会让系统在低电量或规范冲突时频繁进入“停等-询问”死锁，表面安全合规，实则任务不可用，即系统因过度追求礼貌而失去行动力。

**定义 530（续航预算证书 EBC）** 能量演化与证书有效性：

```
E(t+Δ) = E(t) − ∫_t^{t+Δ} P(τ)dτ + ξ,   P(τ) ∈ [0, P_max],   ξ ~ subG(σ_E)
Ê_α(t+Δ) = E(t) − P_max·Δ − z_{1−α}·σ_E·√Δ
S_E(t, Δ) = Ê_α(t+Δ) − (E_res + R_dock(t) + N_res(t))
EBC(t) 有效 ⇔ ∃Δ>0: S_E(t, Δ) ≥ 0
T½(t) = sup { Δ ≥ 0 : S_E(t, Δ) ≥ 0 }        # 空集时约定 T½(t)=0
β_E(t) = clip(S_E(t, T½(t)) / E_cap, 0, 1)
```

**定义 531（能量退化阶梯 EL）** 用迟滞与驻留避免抖动：

```
θ₀ > θ₁ > θ₂,  δ_h > 0,  τ_h > 0
Λ_E(t+1) = Λ_E(t)+1   若 β_E < θ_{Λ_E} − δ_h 且 Λ_E < 3 且驻留已满
         = Λ_E(t)−1   若 β_E > θ_{Λ_E−1} + δ_h 且 Λ_E > 0 且驻留已满
         = Λ_E(t)     其他
Shed(0)=∅
Shed(1)={ER}
Shed(2)={ER, OTL, GCT_extra}
Shed(3)={ER, OTL, GCT_extra, MISSION}
```

不变式：`∀Λ_E`，`M₀`、`F 否决`、`EBC 返航检查` 不被 `Shed(Λ_E)` 削减。

**定义 532（道义规范模式 Norm Schema）** 规范不是标量偏好，而是可失效的道义项：

```
n = (scope, μ, kind, κ, aud, π, s, c, TTL)
scope = (x_pred, region, agents)      # 适用上下文
μ ∈ {F, O, P}                         # 禁止 / 应当 / 允许
kind ∈ {descriptive, injunctive}      # 描述性规范 / 命令性规范
κ = (condition, exceptions)           # 触发条件与例外
aud = 受众/受益者
π ∈ ℕ                                 # 同模态内优先级
s ∈ {explicit, observed, feedback, prior}
c ∈ [0,1], TTL > 0
```

层级映射：`F → M₀ 非补偿否决`；`O → M₁/M₃ 软硬混合（硬下限 + 软惩罚）`；`P → 边界条件`。

**定义 533（规范推断与置信）** 对潜参数维护后验而非点估计：

```
p(θ_n | x, ℓ, h) ∝ p(ℓ | θ_n, x) · p(θ_n | x, h)
c_n = 1 − H(p(θ_n | x, ℓ, h)) / log |Θ_n|
```

仅当 `c_n ≥ c_min` 且 `\bar r_n ≤ α_μ` 时才签发 `NCC_n`；否则规范保持“候选”状态，不进入硬否决，但可触发澄清。

**定义 534（规范合规证书 NCC）** 用风险上界而非平均准确率：

```
r_n(ξ) = Pr_{θ_n ~ p}(ξ 违反 n)
\bar r_n = UCB_δ({r_n(ξ_i)}_{i=1..m})        # conformal / Hoeffding 上界
NCC_n = (n, \bar r_n, α_μ, TTL, provenance)
NCC_n 有效 ⇔ \bar r_n ≤ α_μ
```

**定义 535（道义冲突消解 NCR）**：

```
Conflict(n_F, n_O, a) ⇔ a ∉ Sat(n_F) ∧ a ∈ Sat(n_O)
优先级：F > O > P
同模态：specificity > π > source_authority > recency
若仍不可消解 ⇒ DEADLOCK ⇒ HOLD/ASK
```

**定义 536（非补偿可行性过滤）**：

```
A_safety = { a : M₀(a) = true }
A_F      = { a : ∀n ∈ F_active, \bar r_n(a) ≤ α_F }
A_dock   = { a : S_E(a, Δ_exec) ≥ 0 }
A_feas   = A_safety ∩ A_F ∩ A_dock
```

`A_F` 与能量无关；这是“能量不能购买禁止性违规”的结构性保证。

**定义 537（EcoNorm 字典序仲裁）**：

```
J(a) = ( s_hard(a), −max_{n∈F_active} \bar r_n(a), s_dock(a),
         sat_O(a), progress(a), −energy(a) )
a* = lexmax_{a∈A_feas} J(a)
若 A_feas = ∅ ⇒ HOLD/ASK
```

**定义 538（规范能量预留 NRS）**：

```
N_res(t) = max_{π ∈ Π_active} C_norm(π)        # 满足所有活跃 F/O 的最坏能量
mission_budget(t) = Ê_α(t+Δ) − E_res − R_dock(t) − N_res(t)
```

`N_res` 在任务预算之前扣除：能量紧张时先减少任务，不先减少规范。

**定义 539（双证书合成 ECC）**：

```
ECert = (EBC, {NCC_n}_{n∈N_active}, Λ_E, arbiter_trace, provenance, TTL)
ECert 有效 ⇔ EBC 有效 ∧ ∀n: NCC_n 有效 ∧ 无未消解冲突
TTL(ECert) = min(TTL(EBC), min_n TTL(NCC_n))
```

**定义 540（能量诱导规范侵蚀 Ero）**：

```
Ero(t) = 1[ 选择动作 a_t，且 ∃n∈F_active: \bar r_n(a_t) > α_F ]
```

`Ero=0` 是 ENA 的硬性安全目标；它与任务奖励、剩余电量无关。

**定义 541（规范保持的退化）** 设 `𝒜_full` 为全模块可行域，`𝒜_fail` 为某模块失效后的可行域。规范保持退化要求：

```
𝒜_fail ⊆ 𝒜_full ∪ {HOLD/ASK}
且 F_active(fail) ⊇ F_active(full) ∩ {TTL 未过期}
```

即失效只能缩小可行域或进入停等，不能扩大“可违规”的空间。

**定义 542（规范澄清策略 NCP）**：

```
EVCI(q) = E[ loss(a_guess) − loss(a_after_q) ] − cost(q)
询问 ⇔ (c_n < c_min ∨ DEADLOCK) ∧ EVCI(q) > 0
```

其中 `loss` 对 F 规范取非补偿损失（违规即 `+∞`），因此澄清在禁止性不确定时优先于猜测。

**定义 543（EcoNorm 联合闭环）**：

```
Φ_EcoNorm = (EBC, EL, NGG, NCR, NRS, ENA, NCP, ECC)
```

import math
from dataclasses import dataclass, field
from typing import Dict, List, Optional, Sequence, Tuple

Z_95 = 1.6448536269514722


def clip(x: float, lo: float, hi: float) -> float:
    return max(lo, min(hi, x))


# ---------- IP-351 / IP-352: 续航与能量阶梯 ----------
@dataclass
class EnduranceBudgetCert:
    E_cap: float
    E_res: float
    P_max: float
    sigma_E: float
    alpha: float = 0.05

    def z(self) -> float:
        return Z_95 if abs(self.alpha - 0.05) < 1e-12 else 2.326347874  # 0.01 保守值

    def lower_bound(self, E: float, dt: float) -> float:
        return E - self.P_max * dt - self.z() * self.sigma_E * math.sqrt(max(dt, 0.0))

    def slack(self, E: float, dt: float, R_dock: float, N_res: float) -> float:
        return self.lower_bound(E, dt) - (self.E_res + R_dock + N_res)

    def valid(self, E: float, dt: float, R_dock: float, N_res: float) -> bool:
        return self.slack(E, dt, R_dock, N_res) >= 0.0

    def half_life(self, E: float, R_dock: float, N_res: float,
                  dt: float = 0.5, T_max: float = 600.0) -> float:
        if not self.valid(E, 0.0, R_dock, N_res):
            return 0.0
        lo, hi = 0.0, T_max
        for _ in range(40):
            mid = 0.5 * (lo + hi)
            if self.valid(E, mid, R_dock, N_res):
                lo = mid
            else:
                hi = mid
        return lo

    def health(self, E: float, R_dock: float, N_res: float) -> float:
        return clip(self.slack(E, 0.0, R_dock, N_res) / max(self.E_cap, 1e-9), 0.0, 1.0)


class EnergyLadder:
    SHED = {
        0: (),
        1: ("ER",),
        2: ("ER", "OTL", "GCT_EXTRA"),
        3: ("ER", "OTL", "GCT_EXTRA", "MISSION"),
    }

    def __init__(self, theta=(0.45, 0.25, 0.10), hyst=0.05, dwell=2.0):
        self.theta = theta
        self.hyst = hyst
        self.dwell = dwell
        self.level = 0
        self.t_last = -1e18

    def update(self, beta_E: float, t: float) -> int:
        target = self.level
        if self.level < 3 and beta_E < self.theta[self.level] - self.hyst:
            target = self.level + 1
        elif self.level > 0 and beta_E > self.theta[self.level - 1] + self.hyst:
            target = self.level - 1
        if target != self.level and t - self.t_last >= self.dwell:
            self.level = target
            self.t_last = t
        return self.level

    def shed(self) -> Tuple[str, ...]:
        return self.SHED[self.level]


# ---------- IP-353 / IP-354: 规范接地与冲突消解 ----------
@dataclass(frozen=True)
class Norm:
    scope: str
    modality: str          # F / O / P
    kind: str              # descriptive / injunctive
    condition: str
    audience: str
    priority: int
    source: str
    confidence: float
    ttl: float


@dataclass(frozen=True)
class NormCert:
    norm: Norm
    risk_ub: float
    alpha: float
    ttl: float


class NormGroundingGauge:
    def __init__(self, alpha_F: float = 1e-3, alpha_O: float = 0.05,
                 c_min: float = 0.7, delta: float = 0.05):
        self.alpha_F = alpha_F
        self.alpha_O = alpha_O
        self.c_min = c_min
        self.delta = delta

    def parse(self, text: str, context: Dict) -> List[Norm]:
        rules = [
            ("不要", "F", "proximity"), ("别", "F", "proximity"),
            ("请等", "O", "yield"), ("请让", "O", "yield"),
            ("小声", "O", "noise"), ("可以", "P", "none"),
        ]
        out: List[Norm] = []
        for keyword, modality, scope in rules:
            if keyword in text:
                out.append(Norm(
                    scope=scope, modality=modality, kind="injunctive",
                    condition="context", audience="human", priority=1,
                    source="explicit", confidence=0.85, ttl=30.0,
                ))
        return out

    def infer(self, candidates: Sequence[Norm], context: Dict,
              history: Sequence[Norm]) -> List[Norm]:
        # 伪代码：真实实现用后验更新；这里保留置信门控与上下文过滤
        return [n for n in candidates if n.confidence >= self.c_min]

    def ucb(self, violations: Sequence[float]) -> float:
        m = len(violations)
        if m == 0:
            return 1.0
        p_hat = sum(violations) / m
        return min(1.0, p_hat + math.sqrt(math.log(1.0 / self.delta) / (2.0 * m)))

    def certify(self, norm: Norm, violation_samples: Sequence[float]) -> Optional[NormCert]:
        alpha = self.alpha_F if norm.modality == "F" else self.alpha_O
        ub = self.ucb(violation_samples)
        if ub <= alpha and norm.confidence >= self.c_min:
            return NormCert(norm=norm, risk_ub=ub, alpha=alpha, ttl=norm.ttl)
        return None


class NormConflictResolver:
    ORDER = {"F": 3, "O": 2, "P": 1}

    def _applies(self, norm: Norm, action: Dict) -> bool:
        return norm.scope in action.get("contexts", set())

    def resolve(self, norms: Sequence[Norm], action: Dict) -> Tuple[str, Optional[Norm]]:
        applicable = [n for n in norms if self._applies(n, action)]
        if not applicable:
            return "ok", None
        fs = [n for n in applicable if n.modality == "F"]
        os_ = [n for n in applicable if n.modality == "O"]
        shared_scope = {n.scope for n in fs} & {n.scope for n in os_}
        if shared_scope:
            return "deadlock", None
        if fs:
            return "veto", max(fs, key=lambda n: (n.priority, n.confidence))
        return "ok", max(applicable, key=lambda n: (
            self.ORDER[n.modality], n.priority, n.confidence))


# ---------- IP-355 / IP-356 / IP-358: 预留、仲裁、证书合成 ----------
class NormReserveScheduler:
    def compute(self, active_norms: Sequence[Norm], plans: Sequence[Dict]) -> float:
        feasible = [p for p in plans
                    if all(self._satisfies(n, p) for n in active_norms)]
        if not feasible:
            return float("inf")  # 无可行履行计划 ⇒ 触发 HOLD/ASK
        return max(float(p.get("energy", 0.0)) for p in feasible)

    def _satisfies(self, norm: Norm, plan: Dict) -> bool:
        return norm.scope in plan.get("satisfied", set())


class EcoNormArbiter:
    def __init__(self, alpha_F: float = 1e-3):
        self.alpha_F = alpha_F
        self.resolver = NormConflictResolver()

    def feasible(self, actions: Sequence[Dict], norms: Sequence[Norm],
                 certs: Sequence[NormCert], E: float, dt: float,
                 R_dock: float, N_res: float, ebc: EnduranceBudgetCert) -> List[Dict]:
        out: List[Dict] = []
        for a in actions:
            if not a.get("safe", False):
                continue
            if not ebc.valid(E - a.get("energy", 0.0), dt, R_dock, N_res):
                continue
            status, _ = self.resolver.resolve(norms, a)
            if status in ("veto", "deadlock"):
                continue
            if self._f_risk(a, certs) > self.alpha_F:
                continue
            out.append(a)
        return out

    def _f_risk(self, action: Dict, certs: Sequence[NormCert]) -> float:
        risks = [c.risk_ub for c in certs
                 if c.norm.modality == "F" and c.norm.scope in action.get("contexts", set())]
        return max(risks) if risks else 0.0

    def select(self, actions: Sequence[Dict], norms: Sequence[Norm],
               certs: Sequence[NormCert], E: float, dt: float,
               R_dock: float, N_res: float, ebc: EnduranceBudgetCert) -> Optional[Dict]:
        feasible = self.feasible(actions, norms, certs, E, dt, R_dock, N_res, ebc)
        if not feasible:
            return None  # HOLD / ASK

        def key(a: Dict):
            return (
                a.get("safety_slack", 0.0),
                -self._f_risk(a, certs),
                a.get("dock_slack", 0.0),
                a.get("obligation_sat", 0.0),
                a.get("task_progress", 0.0),
                -a.get("energy", 0.0),
            )

        return max(feasible, key=key)


@dataclass
class EcoNormCert:
    ebc_valid: bool
    energy_slack: float
    ladder_level: int
    ncerts: List[NormCert] = field(default_factory=list)
    arbiter_trace: Dict = field(default_factory=dict)
    provenance: Dict = field(default_factory=dict)

    @property
    def valid(self) -> bool:
        return self.ebc_valid and all(c.risk_ub <= c.alpha for c in self.ncerts)


# ---------- IP-359: EcoNorm 主闭环（叠加在 R7 上） ----------
def metricvoicegauge_econorm(M, s, obs, t, audio_stream=None, ell=None,
                             ebc: Optional[EnduranceBudgetCert] = None,
                             ladder: Optional[EnergyLadder] = None,
                             ngg: Optional[NormGroundingGauge] = None,
                             arbiter: Optional[EcoNormArbiter] = None,
                             R_dock: Optional[float] = None,
                             N_res: Optional[float] = None):
    E = M.energy.state()
    dt = M.control_period
    R_dock = M.energy.return_cost(s) if R_dock is None else R_dock
    active = list(M.active_norms)
    N_res = M.norm_reserve.compute(active, M.norm_plans) if N_res is None else N_res
    ebc = ebc or M.ebc
    ladder = ladder or M.energy_ladder

    ebc_ok = ebc.valid(E, dt, R_dock, N_res)
    slack = ebc.slack(E, dt, R_dock, N_res)
    level = ladder.update(ebc.health(E, R_dock, N_res), t)

    # 1) 语音事件：字面解析 + 规范接地（NGG 只在非生存层级运行）
    iota = M.default_iota
    voice_ok = False
    if audio_stream is not None and ngg is not None and level <= 1:
        text, conf = M.asr.recognize(audio_stream)
        if conf >= M.tau_voice:
            cands = ngg.parse(text, M.context)
            new_norms = ngg.infer(cands, M.context, M.norm_history)
            M.update_norms(new_norms, t)
            active = list(M.active_norms)
            N_res = M.norm_reserve.compute(active, M.norm_plans)
            iota, voice_ok, _ = M.gct.process(audio_stream)
    elif audio_stream is not None and level >= 2:
        iota, voice_ok, _ = M.gct.process_base(audio_stream)  # 只保留基础类型检查

    # 2) R7 可选模块按能量阶梯削减
    tau = M.otl.get_thresholds() if level <= 1 else M.metric_ladder.thresholds
    emo = 0.0
    if M.er is not None and level == 0 and audio_stream is not None:
        emo = M.er.extract_emotion(M.audio_features(audio_stream), M.text_features(ell))

    # 3) 规范证书 + 非补偿仲裁
    actions = M.planner.candidates(s, obs, iota)
    certs = []
    for n in active:
        samples = M.compliance_samples(n, actions)
        c = ngg.certify(n, samples) if ngg is not None else None
        if c is not None:
            certs.append(c)
    chosen = arbiter.select(actions, active, certs, E, dt, R_dock, N_res, ebc) \
        if arbiter is not None else actions[0] if actions else None
    if chosen is None:
        return M.safe_hold(reason="norm_deadlock_or_endurance_infeasible")

    # 4) 执行 R7 主路径（使用冻结/在线阈值、可能为空的语音指令、可能为 0 的情感）
    C, spatial_cert, claims, metrics, rewards = M.v7_step(
        s, chosen, obs, iota if voice_ok else M.default_iota, tau, emo)

    # 5) 双证书合成与发布
    ecert = EcoNormCert(
        ebc_valid=ebc_ok, energy_slack=slack, ladder_level=level,
        ncerts=certs, arbiter_trace={"chosen": chosen, "level": level},
        provenance={"EBC": "IP-351", "NGG": "IP-353", "ENA": "IP-356"},
    )
    return C, spatial_cert, claims, metrics, rewards, ecert

## 4. 推导

**引理 77（EBC 下界可靠性）**
设功率 `P(τ) ∈ [0, P_max]`，能量模型残差 `ξ` 为 `σ_E`-sub-Gaussian，取 `z_{1−α}` 为标准正态 `1−α` 分位数，则
```
Pr( E(t+Δ) ≥ Ê_α(t+Δ) ) ≥ 1 − α
```
因此若 `S_E(t,Δ) ≥ 0`，则“剩余能量足够覆盖安全预留、返航与规范预留”成立的概率至少 `1−α`；`T½` 是该保证的有效期下界。

*证明*：`E(t+Δ) = E(t) − ∫P + ξ ≥ E(t) − P_max Δ + ξ`。对 `ξ` 用 sub-Gaussian 尾界，`Pr(ξ < −z_{1−α}σ_E√Δ) ≤ α`，整理即得。∎

**引理 78（非补偿否决：能量不能购买禁止性违规）**
对任意已认证 `F` 规范 `n` 与动作 `a`，若 `\bar r_n(a) > α_F`，则 `a ∉ A_F`，从而 `a ∉ A_feas`，与任务奖励、剩余能量、其他软权重无关。因此 ENA 的选择满足 `Ero(t)=0`。

*证明*：`A_F` 的定义只依赖 `\bar r_n` 与 `α_F`，不依赖 `E`、`R`、`w`；`A_feas ⊆ A_F`。字典序 `J` 只在 `A_feas` 内比较，故任何被选动作都满足所有已认证 F 规范的风险上界。∎

**引理 79（规范死锁不产生静默违规）**
若同一动作同时被 `F` 与 `O` 规范覆盖，且不存在同时满足二者的动作，则 `A_feas = ∅`，仲裁器返回 `HOLD/ASK`，而不是任选一个动作。

*证明*：`NCR` 对 `F` 与 `O` 同时适用的动作返回 `deadlock`，该动作被可行性过滤排除；若所有候选均被排除，`select` 返回 `None`，主闭环进入 `safe_hold`。`F` 的否决不因 `O` 的存在而放松。∎

**引理 80（规范保持退化）**
EBC/EL/NGG/NCR/NRS/ENA/ECC 任一失效时，按定义 541 的退化映射得到的可行域满足 `𝒜_fail ⊆ 𝒜_full ∪ {HOLD/ASK}`，且未过期的已认证 `F` 规范仍然生效。

*证明*（逐项）：
1. EBC/EL 失效 ⇒ 用更保守的静态预留 `E_static ≥ N_res + R_dock` 替代预测下界，`A_dock` 只会缩小；`E_static` 按最坏情况设定，故不会新增违规。
2. NGG/NCR 失效 ⇒ TTL 内保留已认证规范；TTL 外使用保守默认包络 `N_0`（更大距离、让行、减速），其可行域是原可行域的子集或触发 `HOLD`；禁止性规范不会被删除。
3. NRS/ENA 失效 ⇒ 固定预留与静态优先级“安全 > 任务”只减少可选任务动作，不增加 F 违规；若无法保证，进入 `HOLD`。
4. ECC 失效 ⇒ 不发布 EcoNorm 证书，但 R7 的 M₀/SpatialCert 仍生效；系统不得声称 EcoNorm 合规，只能按 R7 运行。
合并后仍满足 `𝒜_fail ⊆ 𝒜_full ∪ {HOLD/ASK}`。∎

**引理 81（能量-规范单调性）**
设 `E₁ ≤ E₂`（同一状态、同一规范集、同一动作集）。则
```
A_feas(E₁) ⊆ A_feas(E₂)
```
因此能量下降不会增加可选的 F 违规动作；若 `E₁` 下 `A_feas` 为空，系统进入 `HOLD/ASK`，而不是放松规范。

*证明*：`A_F` 与 `E` 无关；`S_E` 关于 `E` 单调不减，故 `A_dock(E₁) ⊆ A_dock(E₂)`；`A_safety` 不变。交集保持包含关系。∎

**引理 82（规范风险上界校准）**
若校准样本与部署样本可交换，且 `\bar r_n` 为 conformal 上界，则边际覆盖率满足
```
Pr( r_n(ξ) ≤ \bar r_n ) ≥ 1 − δ
```
若使用 Hoeffding 上界，则 `m` 个独立样本下同样有 `Pr(r_n ≤ \bar r_n) ≥ 1 − δ`。

*证明*：conformal 分位数的标准覆盖定理；Hoeffding 不等式直接给出尾界。∎

**引理 83（规范预留可行性）**
若在 `t` 时刻 `mission_budget(t) ≥ 0`，且 `N_res(t)` 是活跃规范在规划时域内的最坏履行能量上界，则字典序调度器可以在不违反 F 规范的前提下完成当前任务段并保留返航能量；若 `mission_budget(t) < 0`，则先削减任务/可选模块，仍不削减 `N_res`。

*证明*：`mission_budget` 已从 `Ê_α` 中扣除 `E_res`、`R_dock`、`N_res`；调度器只在 `A_dock` 内选择动作，且 `N_res` 在任务执行前预留。若预算为负，`EL` 只下调 `Shed(Λ_E)` 中的可选模块与任务范围，`N_res` 与 `A_F` 不变；若连 `N_res` 都不可行，则进入 `HOLD/ASK`。∎

## 6. 实验设计 E526–E543（含本轮预实验）

### 6.1 预实验（合成，非正式；仅用于 sanity check）

本轮以纯合成数据做三组快速检查，不作为正式证据：

| 检查 | 设置 | 结果 | 解释 |
|---|---|---|---|
| EBC 统计下界覆盖率 | `α=0.05`，`N=2×10⁵`，`P~N(1.0,0.35)` 截断到 `[0,2]`，`Δ=5`；用 `μΔ+zσ√Δ` 作为 `P_max` 未知时的近似下界 | 经验覆盖率 **0.950** | 与 `1−α` 吻合；正式 EBC 用硬 `P_max`，会更保守 |
| 能量阶梯抖动 | 20,000 步，`β_E` 带正弦+噪声，阈值 0.47 | 无迟滞 **1987** 次切换；有迟滞 **95** 次 | 切换减少 **95.2%**，迟滞有效 |
| 能量诱导规范侵蚀 | 20,000 次随机 64 动作实例；F 动作奖励略低但能耗更低；补偿效用 `r−λ·energy` | λ=0/2/4/8/16 时 F 违规率 **0.14%/3.11%/16.68%/64.45%/98.12%**；字典序否决 **0.00%** | 能量影子价格越高，补偿式决策越侵蚀规范；否决式仲裁不受影响 |

**预实验结论**：EBC 统计下界与迟滞阶梯在合成条件下符合设计预期（正式 EBC 的硬 `P_max` 版本更保守，其保守度需由 E526 标定）；“能量价格上升 ⇒ 规范违规率上升”在补偿式效用下非常显著，而字典序否决把违规率压到 0。正式实验必须验证真实功率模型、真实语音规范与真实人类评价下的同类结论。

## 8. 本轮最大风险

**一句话**：最大的风险是把社会规范当成可学习、可量化的软约束——规范误读、文化偏差与能量-规范耦合会让系统在低电量或规范冲突时频繁进入“停等-询问”死锁，表面安全合规，实则任务不可用，即系统因过度追求礼貌而失去行动力。
