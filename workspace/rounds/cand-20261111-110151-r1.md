# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「安全交互」×「多模态大模型」）

> 第 54 轮已把技能组合提升为「动作剖面 α_S + 云边协同 γ_ce + 动作-鲁棒性联合证书 J」。本轮引入 **人类在环的安全交互** 与 **多模态大模型（MLLM）语义意图**。核心矛盾：H22：MLLM 能把视觉-语言-语音熔铸为「看似合理」的意图与动作，但语义合理性不可验证，而安全交互要求的是可验证的物理/社会安全边界；H23：安全不是单个动作的属性，而是「动作 × 人的意图 × 人的状态」的关系属性，MLLM 给出的意图分布带有校准误差与分布漂移，直接用它裁剪安全包络会把幻觉变成物理风险。

## 0. 直觉与动机

**灵感 1（安全交互包络 → 把「安全」变成动作空间的硬约束子集）**
直觉：第 54 轮的 `α_S` 只回答「技能能做哪些动作」，没回答「人在旁边时哪些动作可以做」。引入 **安全交互包络** `E_safe(S,h)`：给定人类状态 `h`（位姿、速度、朝向、注视、语音韵律、生理线索），用控制屏障函数（CBF）刻画 **硬安全集** `E_hard`（前向不变、绝不可越），用最小距离/接触力/速度裕度做硬约束，再用社会舒适度刻画 **软安全集** `E_soft`。可部署动作 = `α_S ∩ E_hard`。安全不再是事后检查，而是动作空间的第一性裁剪。

**灵感 2（意图条件化 → 安全包络依赖「人想干什么」）**
直觉：同一个递物动作，在「人想接杯子」与「人想后退」两种意图下安全性完全不同。定义 **意图条件包络** `E_safe(S,h,i)`：每个意图 `i` 绑定各自的禁止区、期望距离与交互节奏。MLLM 融合多模态观测 `o` 输出意图分布 `P(i|o)`。关键不是取 `argmax`，而是 **对意图不确定性做鲁棒化**：只有在所有「可信意图」下都安全的动作才允许执行。

**灵感 3（共形意图集 → 把 MLLM 的不确定性变成有覆盖保证的集合）**
直觉：温度缩放只能让概率「看起来校准」，给不出覆盖保证。改用 **共形预测**：在校准集上得到非一致性分数阈值 `q_δ`，构造意图集 `I_δ(o) = {i : s(i,o) ≤ q_δ}`，在可交换性下有 `P(i* ∈ I_δ) ≥ 1-δ`。再定义 **分布鲁棒安全包络** `E_rob(S,h,o) = ∩_{i∈I_δ(o)} E_hard(S,h,i)`。这把「MLLM 可能理解错」转化为一个可计算的集合交，而不是拍脑袋的安全折扣。

**灵感 4（安全门 + 澄清动作 → MLLM 只做提议者，不做控制者）**
直觉：让 MLLM 生成动作提议 `a ~ π_MLLM(o)`，但 **安全门 SVG** 拥有否决权：`a ∉ E_hard` 直接投影/替换为包络内动作；`a ∉ E_rob` 且意图歧义高则触发 **澄清动作**（询问、停顿、展示、减速），把交互从「猜」变成「问」。这形成 **神经提议 - 形式验证 - 澄清回退** 的双通道，天然适配「安全交互」而非纯性能最大化。

**灵感 5（安全交互金字塔 + 风险账本 → 跨轮可传递的安全证书）**
直觉：在第 54 轮动作-鲁棒性双证书上再加 **安全语义层 𝕊**：`𝕊_0` 物理不变集，`𝕊_1` 硬安全包络，`𝕊_2` 意图鲁棒包络，`𝕊_3` 社会/隐私安全。并用 **安全交互风险账本** 把一次交互的总风险预算 `R_0` 按回合分摊，使得整段交互的累计失败概率满足 `Σ_t r_t ≤ R_0` 的上界，安全证书因此可跨层、跨回合传递。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（人类状态与安全交互包络）**
人类状态 `h ∈ H`，包含位姿 `x_h`、速度 `v_h`、朝向 `θ_h`、注视 `g_h`、语音韵律 `π_h` 与可选生理信号。技能 `S` 的 **硬安全包络**
```
E_hard(S,h) = { a ∈ A_S : φ(a,h) ≥ 0 ∧ d_min(a,h) ≥ d_safe ∧ f_max(a,h) ≤ f_safe }
```
其中 `φ` 为控制屏障函数，`d_min` 为最小人-机距离，`f_max` 为最大接触力。**软安全包络**
```
E_soft(S,h) = { a ∈ E_hard(S,h) : ψ_soc(a,h,o) ≥ ψ_min }
```
`ψ_soc` 为社会舒适度（速度平滑性、朝向、可预测性）。记 `E_safe = (E_hard, E_soft)`。

**定义 122（意图条件安全包络）**
意图本体 `I = {i_1,…,i_m}`（接物、避让、共走、递物、求助等）。对每个意图 `i`，以意图锚点 `(d_safe(i), f_safe(i), ψ_min(i))` 细化：
```
E_hard(S,h,i) = { a ∈ A_S : φ_i(a,h) ≥ 0 ∧ d_min(a,h) ≥ d_safe(i) ∧ f_max(a,h) ≤ f_safe(i) }
```
`E_safe(S,h,i)` 同时依赖人的状态与意图，是「关系安全」而非「绝对安全」。

**定义 123（共形意图集与分布鲁棒包络）**
校准集 `{(o_k,i_k)}_{k=1..n}`，非一致性分数 `s(i,o) = 1 - P_cal(i|o)`。取
```
q_δ = Quantile_{⌈(n+1)(1-δ)⌉/n}({s(i_k,o_k)})
I_δ(o) = { i ∈ I : s(i,o) ≤ q_δ }
```
在可交换性下有 `P(i* ∈ I_δ(o)) ≥ 1-δ`。**分布鲁棒安全包络**
```
E_rob(S,h,o) = ⋂_{i ∈ I_δ(o)} E_hard(S,h,i)
```
若 `I_δ(o) = ∅`（异常/拒绝），则定义 `E_rob = ∅`，强制进入澄清流程。鲁棒包络是「对 MLLM 误判取交集」的保守下界。

**定义 124（多模态安全门）**
安全门 `SVG(a,o,h)`：
```
SVG(a,o,h) =
  a                                  若 a ∈ E_hard ∩ E_rob 且 charge(risk(a))
  clarify(o)                          若 E_rob = ∅ 或 H(P(i|o)) > H_max
  shield_project(a, E_rob)            其余（投影到鲁棒包络内最近动作）
```
`H` 为意图分布熵，`H_max` 为歧义阈值。澄清动作 `clarify` 本身必须属于 `E_hard`。

**定义 125（交互安全证书）**
```
S_cert = (E_hard, E_rob, I_δ, δ, m_min, GSP, cal_err, priv_witness)
```
- `m_min = min_{a∈A_core} d_min(a,h)` 为最小安全裕度；
- `GSP` 为 **接地安全谓词集**：每条安全相关断言必须绑定可测量的传感器谓词与见证 `(predicate, witness_segment)`，禁止不可验证的自然语言断言；
- `cal_err` 为共形集的经验失配率；
- `priv_witness` 为隐私处理见证（人脸/声纹脱敏、数据最小化）。
部署条件：`E_rob ≠ ∅`、`A_core ⊆ E_hard`、`GSP` 全部通过独立传感器复核、`cal_err ≤ ε_cal`、`priv_witness` 有效。

**定义 126（安全交互风险账本）**
账本 `L = (R_0, {r_t})`，其中 `r_t = P(unsafe_t | F_{t-1})` 为第 `t` 回合的条件不安全概率上界，约束
```
Σ_{t=1}^{T} r_t ≤ R_0
```
不安全事件定义为「硬包络被违反」或「某条 GSP 被独立传感器证伪」。则
```
P(∪_{t≤T} unsafe_t) ≤ Σ_t P(unsafe_t) ≤ Σ_t r_t ≤ R_0
```
账本把「一次交互总风险」显式货币化，允许把风险预算动态分配给高价值动作。

## 2. 关键算法 伪代码

### IP-121 SIE（Safe Interaction Envelope）

```python
def safe_envelope(skill, h, cbf, intent=None):
    d_safe, f_safe = (intent.d_safe, intent.f_safe) if intent else (D_SAFE, F_SAFE)
    E_hard, E_soft = set(), set()
    for a in skill.action_domain():
        if cbf.phi(a, h) >= 0 and min_dist(a, h) >= d_safe and max_force(a, h) <= f_safe:
            E_hard.add(a)
            if social_score(a, h) >= PSI_MIN:
                E_soft.add(a)
    return E_hard, E_soft
```

### IP-122 MIGC（Multimodal Intent Grounding + Conformalization）

```python
def intent_grounding(mllm, obs, cal):
    p = cal.calibrate(mllm.intent_dist(obs))            # 温度缩放后的概率
    scores = {i: 1.0 - p[i] for i in p}
    q_delta = cal.qhat(obs)                             # 校准集分位数
    I_delta = {i for i, s in scores.items() if s <= q_delta}
    return p, I_delta
```

### IP-123 DRS（Distributionally Robust Safety Envelope）

```python
def robust_envelope(skill, h, obs, I_delta, cbf):
    if not I_delta:
        return None
    E = None
    for i in I_delta:
        E_i, _ = safe_envelope(skill, h, cbf, intent=i)
        E = E_i if E is None else (E & E_i)
    return E if E else None
```

### IP-124 SVG（Safety Verifier Gate）

```python
def safety_gate(proposal, E_hard, E_rob, intent_entropy, ledger):
    if proposal not in E_hard:                       # 硬安全：无条件否决
        return shield_project(proposal, E_hard)
    if E_rob is None or intent_entropy > H_MAX:      # 歧义：先问再做
        return clarify(proposal.obs)
    if proposal not in E_rob:                        # 鲁棒安全：投影
        return shield_project(proposal, E_rob)
    if not ledger.charge(proposal.risk):             # 预算不足：降级
        return shield_project(proposal, E_rob)
    return proposal
```

### IP-125 IXC（Interaction Safety Certificate）

```python
def interaction_certificate(skill_seq, h, obs, mllm, cal, cbf):
    p, I_delta = intent_grounding(mllm, obs, cal)
    E_hard = reduce(intersection, [safe_envelope(s, h, cbf)[0] for s in skill_seq])
    E_rob  = reduce(intersection, [robust_envelope(s, h, obs, I_delta, cbf)
                                   for s in skill_seq])
    gsp = [independent_check(claim, obs) for claim in mllm.safety_claims(obs)]
    if E_rob is None or not all(gsp):
        return ('reject', 'unsafe_envelope', gsp)
    if not action_core(skill_seq).issubset(E_hard):
        return ('reject', 'core_violates_hard', E_hard)
    if cal.err > EPS_CAL:
        return ('reject', 'calibration_drift', cal.err)
    return ('ok', SCert(E_hard, E_rob, I_delta, delta,
                        m_min=min_margin(E_hard, h), GSP=gsp,
                        cal_err=cal.err, priv_witness=privacy_witness(obs)))
```

### IP-126 SRL（Safety Risk Ledger）

```python
class RiskLedger:
    def __init__(self, R0):
        self.R0, self.spent = R0, 0.0

    def charge(self, r_t):
        if self.spent + r_t > self.R0:
            return False
        self.spent += r_t
        return True

    def bound(self):
        return self.spent        # P(any unsafe) <= spent <= R0（并集上界）
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SIE | O(\|A_S\|·\|Φ\|) | O(\|A_S\|) | CBF 前向不变、数值证书 |
| MIGC | O(\|I\| + n log n) | O(\|I\|+n) | 可交换性、共形覆盖 |
| DRS | O(\|I_δ\|·\|A_S\|) | O(\|A_S\|) | 意图集非空、交集单调 |
| SVG | O(log\|E\|)（投影索引） | O(\|E\|) | 门控 sound、澄清属于 E_hard |
| IXC | O(\|S\|·\|I_δ\|·\|A_S\|) | O(\|A_S\|+\|I_δ\|) | 接地谓词独立可验 |
| SRL | O(1)/回合 | O(T) | 风险上界、并集界 |

**正确性定理（Safe-Interaction Certificate Soundness）**
承接第 54 轮 (A26)–(A28)；新增假设：
- **(A29)** `φ` 为有效 CBF，硬包络前向不变，数值实现误差 ≤ `β_V`；
- **(A30)** 校准集与部署分布可交换，共形覆盖 `≥ 1-δ`；
- **(A31)** 意图本体封闭且 `cal_err ≤ ε_cal`（开放集意图另行处理）；
- **(A32)** 风险估计 `r_t` 为真实条件不安全概率的上界，误差 ≤ `β_R`。

则
```
P(safe interaction over T) ≥ 1 - δ - δ_env - β_V - β_R - R_0
```
证明思路（失败模式分解 + 并集界）：不安全只可能来自四条互斥路径——(i) 真实意图 `i* ∉ I_δ`，概率 ≤ `δ`；(ii) 意图在集内但包络模型与真实安全集偏差，概率 ≤ `δ_env`；(iii) CBF/投影数值误差导致越界，概率 ≤ `β_V`；(iv) 账本内被接受动作的残余风险，概率 ≤ `Σ_t r_t + β_R ≤ R_0 + β_R`。对四者取并集界即得。关键：**MLLM 只提供提议与意图候选，安全由 CBF + 共形集 + 风险账本三重独立机制兜底**。

## 6. 本轮最大风险

**一句话**：安全交互证书的 soundness 同时押注在「CBF 的不变集模型准确」「共形集的可交换性成立」「意图本体对真实意图封闭」三块地基上，任一地基在开放世界漂移（新人体动力学、新语言/文化意图、新传感器视角）都会让鲁棒包络要么漏掉真实危险意图、要么收缩到空集而使机器人瘫痪，故必须以 **OOD 弃权 + 可达集鲁棒 CBF + 持续共形再校准** 作为三根承重柱，宁可先澄清、绝不把 MLLM 的语义自信当作物理安全的通行证。

## 2. 关键算法 伪代码

### IP-121 SIE

```python
def safe_envelope(skill, h, cbf, intent=None):
    d_safe, f_safe = (intent.d_safe, intent.f_safe) if intent else (D_SAFE, F_SAFE)
    E_hard, E_soft = set(), set()
    for a in skill.action_domain():
        if cbf.phi(a, h) >= 0 and min_dist(a, h) >= d_safe and max_force(a, h) <= f_safe:
            E_hard.add(a)
            if social_score(a, h) >= PSI_MIN:
                E_soft.add(a)
    return E_hard, E_soft
```

### IP-122 MIGC

```python
def intent_grounding(mllm, obs, cal):
    p = cal.calibrate(mllm.intent_dist(obs))     # 温度缩放
    q_delta = cal.qhat(obs)                      # 校准集共形分位数
    I_delta = {i for i in p if (1.0 - p[i]) <= q_delta}
    return p, I_delta
```

### IP-123 DRS

```python
def robust_envelope(skill, h, obs, I_delta, cbf):
    if not I_delta:
        return None
    E = None
    for i in I_delta:
        E_i, _ = safe_envelope(skill, h, cbf, intent=i)
        E = E_i if E is None else (E & E_i)
    return E if E else None
```

### IP-124 SVG

```python
def safety_gate(proposal, E_hard, E_rob, intent_entropy, ledger):
    if proposal not in E_hard:
        return shield_project(proposal, E_hard)          # 硬安全无条件否决
    if E_rob is None or intent_entropy > H_MAX:
        return clarify(proposal.obs)                     # 歧义：先问再做
    if proposal not in E_rob:
        return shield_project(proposal, E_rob)           # 鲁棒安全：投影
    if not ledger.charge(proposal.risk):
        return shield_project(proposal, E_rob)           # 预算不足：降级
    return proposal
```

### IP-125 IXC

```python
def interaction_certificate(skill_seq, h, obs, mllm, cal, cbf):
    p, I_delta = intent_grounding(mllm, obs, cal)
    E_hard = reduce(intersection, [safe_envelope(s, h, cbf)[0] for s in skill_seq])
    E_rob  = reduce(intersection, [robust_envelope(s, h, obs, I_delta, cbf)
                                   for s in skill_seq])
    gsp = [independent_check(claim, obs) for claim in mllm.safety_claims(obs)]
    if E_rob is None or not all(gsp):
        return ('reject', 'unsafe_envelope', gsp)
    if not action_core(skill_seq).issubset(E_hard):
        return ('reject', 'core_violates_hard', E_hard)
    if cal.err > EPS_CAL:
        return ('reject', 'calibration_drift', cal.err)
    return ('ok', SCert(E_hard, E_rob, I_delta, delta,
                        m_min=min_margin(E_hard, h), GSP=gsp,
                        cal_err=cal.err, priv_witness=privacy_witness(obs)))
```

### IP-126 SRL

```python
class RiskLedger:
    def __init__(self, R0):
        self.R0, self.spent = R0, 0.0

    def charge(self, r_t):
        if self.spent + r_t > self.R0:
            return False
        self.spent += r_t
        return True

    def bound(self):
        return self.spent       # P(any unsafe) <= spent <= R0
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SIE | O(\|A_S\|·\|Φ\|) | O(\|A_S\|) | CBF 前向不变、数值证书 `β_V` |
| MIGC | O(\|I\| + n log n) | O(\|I\|+n) | 可交换性 → 共形覆盖 `≥1-δ` |
| DRS | O(\|I_δ\|·\|A_S\|) | O(\|A_S\|) | 交集单调、空集即弃权 |
| SVG | O(log\|E\|) | O(\|E\|) | 门控 sound、澄清动作 ∈ `E_hard` |
| IXC | O(\|S\|·\|I_δ\|·\|A_S\|) | O(\|A_S\|+\|I_δ\|) | GSP 独立可验、证书分量齐全 |
| SRL | O(1)/回合 | O(T) | 并集上界 `P(∪unsafe) ≤ R_0` |

**正确性定理（Safe-Interaction Certificate Soundness）**
承接第 54 轮 (A26)–(A28)；新增 (A29) CBF 有效且数值误差 `≤β_V`；(A30) 校准/部署可交换，共形覆盖 `≥1-δ`；(A31) 意图本体封闭且 `cal_err≤ε_cal`；(A32) `r_t` 为真实条件风险上界，误差 `≤β_R`。则
```
P(safe interaction over T) ≥ 1 - δ - δ_env - β_V - β_R - R_0
```
失败分解（并集界）：(i) 真意图 `∉ I_δ` → `δ`；(ii) 集内包络模型偏差 → `δ_env`；(iii) CBF/投影数值越界 → `β_V`；(iv) 账本内残余风险 → `Σr_t + β_R ≤ R_0 + β_R`。关键不变式：**MLLM 只提议，安全由 CBF + 共形集 + 风险账本三重独立机制兜底**。
