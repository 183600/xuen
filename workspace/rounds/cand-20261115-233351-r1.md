# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「电池管理」×「深度学习」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**能量全局证书 + 区间化深度学习 + 功率/热中立元退化**。两个灵感互为约束：电池管理要求把能量当作硬约束，深度学习给出电池状态的估计，但学习模型本身不可信——因此所有学习输出必须区间化、共形标定、OOD 可检测，且任一新模块失效时注入中立元，严格等价退回 v9。安全关键证书永不被“省电”降级。

## 0. 直觉与动机

**灵感 1（电池管理 → 从局部空间安全到全局能量活性）**
直觉：v9 的块证书回答“未来 200ms 会不会撞”，却不回答“照这条路走下去，我还有没有电回家”。一个机器人可以每一步都局部安全，最后停在一个无法充电、无法返回的角落——安全但没有活性。电池管理的第一性事实是：能量是**标量、可加、全局守恒**的资源。于是它可以充当一个跨块传递的势函数：只要每次执行都保证“剩余能量 ≥ 执行本块消耗 + 从块末回家的能耗 + 安全储备”，局部证书就能通过简单算术复合成全局的“不搁浅”证书。核心创新：**能量-归航不变式（Energy-to-Home Invariant, EHI）** 与 **能量储备证书器（EnergyReserveCertifier, ERC）**。这把 v9 的“局部安全”补成“局部安全 + 全局活性”。

**灵感 2（深度学习 → 从点估计到带失效边界的区间观测）**
直觉：电池的 SoC/SoH/内阻/温度是不可直接观测的潜变量；深度序列模型（物理信息 TCN/GRU）能从电压-电流-温度窗口里学到比库仑计数更准的估计。但安全系统不能把点估计当真理：学习模型在老化、低温、高倍率这些最需要余量的工况下误差最大。核心创新：**深度电池观测器（DeepBatteryObserver, DBO）**——物理约束的深度状态空间模型 + 分裂共形区间 + 自适应共形（ACI）漂移跟踪 + OOD 门控；安全路径只使用保守端点（s⁻、h⁻、R⁺、T⁺），OOD 时退到数据手册/等效电路的最坏界。**深度学习负责“看得更准”，电池管理负责“只信下界”**。

**两条灵感的合成**：电池管理提供“能量守恒与功率/热包络”这一物理骨架，深度学习提供“潜状态的非线性修正”；而 v9 的分块执行恰好是能量证书的天然载体——块越短，能耗上界越紧，归航余量越容易守恒。与 v9 的动作分块耦合后，系统形成“空间证书 × 时间分块 × 能量势”的三重证书：空间证书防撞，时间分块控算力，能量证书防搁浅。

## 1. 研究问题（轮次升级版）

- **Q1（能量全局证书）**：如何定义能量-归航不变式，使“每个块都能量可行”能归纳出“整条任务轨迹不搁浅”？归航能耗上界如何处理地图/SLAM 不确定性、充电桩可用性与交通绕行？
- **Q2（学习观测的可信边界）**：深度电池观测器在什么统计假设下给出覆盖保证？当电池老化、低温、高倍率导致分布偏移时，OOD 门控与物理回退能否保证安全路径不出现“静默低估”？
- **Q3（功率-热-算力耦合）**：如何把电池功率包络与热约束接入 v9 的契约中间件，使“省电/降温”只通过中立元等价路径发生，且不牺牲 50Hz 与安全关键证书？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 能量-归航不变式（EHI）**
系统在任何时刻都必须满足：可用能量下界 − 安全储备 ≥ 从当前位置按认证归航路径返回最近充电桩的能耗上界。每个动作块必须携带能量证书 Ê_t=(E_rem⁻, E_cons⁺, E_home⁺, P_peak⁺, T_peak⁺)，其中 E_rem⁻ 是观测区间下界、E_cons⁺/E_home⁺ 是能耗上界、P_peak⁺/T_peak⁺ 是功率/温升上界；证书无效则拒绝该块。

**P14 区间电池契约（IBC）**
所有安全相关的电池量只以区间端点参与决策：能量用下界、能耗/内阻/温度用上界；深度观测器的点估计不得直接进入安全路径。区间由共形标定给出名义覆盖，由 ACI 跟踪慢漂移，由 OOD 门控触发物理最坏界回退；观测器失效时能量层整体旁路（等价 v9 的“未观测电池”假设）。

**P15 功率-热中立元退化（WND）**
契约表为每个模块追加功率 J_m、单次能耗 E_m 与热耦合系数 θ_m；WCB 在 P_max(SoC,T,SoH) 与 T_lim 下做 EDF+功率+热量三重可行性检查。不可行时只允许按“每焦耳安全贡献”顺序关闭 φ^elig=true 的可选模块（注入 v^⊥），或降低块长/速度；φ^elig=false 的安全模块永不被关。若仍不可行，进入低功耗安全模式并请求充电，绝不通过延长截止期来“省电”。

## 3. 与基线的接口（如何退化）

- ERC 失效（能量证书不可算/归航路径不可认证）⇒ 关闭能量过滤，K_eff^E≡K_max、P_t^E≡P_t，等价 v9 的块证书与中止点集；
- DBO 失效（模型加载失败/连续 OOD/标定过期）⇒ 能量层整体旁路，等价 v9 的隐含“电池充足”假设（这是 v9 原本就有的风险，本轮把它显式化，而不是新增风险）；
- WCB 失效 ⇒ 关闭功率/热调度，回到 v9 的纯 EDF 契约；
- CAP 失效（无充电桩/地图失效）⇒ 默认将能量层整体旁路回 v9；若操作员显式选择保守模式，则 E_home 退化为“沿已认证返回路径的保守常量”，该模式不属于 v9 等价；
- 电池真实耗尽且无认证归航路径 ⇒ 安全停驻 + 告警，这是**活性失败**而非安全违背，必须在日志中与碰撞区分；
- v9 的 AC/MW/ID 失效 ⇒ 按 v9 引理 82–86 逐级退回 v8；v8 的 DA/SPR/Cal 失效 ⇒ 退回 v7；全失效 ⇒ v6。

## 4. 预期贡献

1. **能量-归航不变式**：给出第一个“跨块可复合”的全局活性证书——能量作为标量势，使 v9 的局部块安全可以归纳为整条任务不搁浅；
2. **区间化深度电池观测**：物理信息深度状态空间 + 共形/ACI 区间 + OOD 物理回退，把学习模型从“点预测风险”变成“可审计的区间契约”；
3. **功率-热-算力统一契约**：把电池功率包络、热约束与 v9 的 EDF/WCET 契约合并，给出“省电不降安全”的代数退化条件；
4. **三重证书闭环**：空间证书（防撞）× 时间分块（算力）× 能量证书（防搁浅）；E571–E590 覆盖观测覆盖、OOD、归航、热、功率、退化等价与长时任务。

## 5. 本轮最大风险

**一句话**：能量-归航不变式把“剩余电量下界”和“归航能耗上界”都托付给深度电池观测器，而这两者的误差恰在电池老化、低温、高倍率——也就是最需要安全余量的工况——同时放大；若 OOD 门控与共形区间在这些工况下“静默失准”，系统会在电量其实已不足时仍签发 EHI 有效证书，把“不会搁浅”从物理保证降级为一次深度学习外推。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-BRIDGE**（Battery-aware Reserve Invariant with Deep-calibrated Guaranteed Energy）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮灵感：「电池管理」×「深度学习」
> **继承纪律**：MetricVoiceGauge 九不变式（CVC-闭环、SpatialCert、RT-CVC、FaultCert、PrimitiveGraph、严格退化链、OTL、GCT、ER）全部保留；v8 的 DA-ML/SPR/Cal 与 v9 的 AC/MW/ID 原样继承。新组件一律为**可选增强**：任一环节不可用 ⇒ 能量层整体旁路或注入中立元，严格等价退回 v9（引理 91），而非行为漂移。能量层只做减法：它只能拒绝动作块、缩短块长、降低速度、关闭可选模块，绝不放大动作集，也绝不修改 M₀/SpatialCert/FaultCert。

**新增定义 540（电池潜状态与可信区间）** 真实电池状态 x_B(t)=(s_t,h_t,R_t,T_t,v_t)，其中 s_t∈[0,1] 为 SoC，h_t∈(0,1] 为 SoH（当前容量/标称容量），R_t>0 为等效内阻，T_t 为电芯温度，v_t 为可测端电压。深度观测器 DBO 将测量窗口 u_{t−W:t}=(v,i,T,T_amb) 映射为区间族：
```
DBO(u_{t−W:t}) = ([s⁻,s⁺], [h⁻,h⁺], [R⁻,R⁺], [T⁻,T⁺])
```
区间由分裂共形标定给出名义覆盖 1−α（定义 547）。称区间在 t 时刻**有效**，若真实状态落入全部区间；安全路径只消费端点集 σ⁻=(s⁻,h⁻,R⁺,T⁺)，点估计 f(u) 不进入任何安全判据。

**新增定义 541（可用能量下界与功率包络）** 设标称容量 C_nom、标称电压 V_nom、放电效率 η_dis、保留 SoC s_res。可用能量下界与功率包络定义为：
```
E⁻(t) = max(0, s⁻(t) − s_res) · h⁻(t) · C_nom · V_nom · η_dis
P_max(t) = min{ P_cell(T⁺), V_min·I_max, (T_lim − T⁺)/R_th,
                P_conn, P_soc(s⁻) }
```
其中 P_cell(·) 为数据手册的温度降额曲线，V_min 为截止电压，I_max 为电芯/连接器电流上限，R_th 为热阻，P_conn 为连接器额定功率，P_soc(s⁻)=0 当 s⁻≤s_cut。计算配额 P_alloc(t)=P_max(t)−P_motion_res(t)−P_safety_res，其中 P_motion_res 为当前速度/坡度下运动控制预留，P_safety_res 为感知与安全证书预留。

**新增定义 542（块级能量证书）** 对 v9 的动作块 ζ_t=(a^{1:K},Ĉ_t,P_t)，能量模型 F_E 由等效电路模型（ECM）与深度残差网络组成，预测每步能耗区间 [e_k⁻,e_k⁺] 与温升区间 [ΔT_k⁻,ΔT_k⁺]。定义：
```
E_cons⁺(ζ_t) = Σ_{k=1..K} e_k⁺ + E_comp(ζ_t)
E_brake⁺(s) = 保守制动/停驻能耗上界
E_home⁺(s) = min_{d∈D, π∈Π_cert(s,d)} Σ_{step∈π} e_step⁺
Ê_t = (E_rem⁻, E_cons⁺, E_home⁺, P_peak⁺, T_peak⁺)
```
能量证书有效当且仅当：
```
(1) E_rem⁻ ≥ E_cons⁺ + E_home⁺(s_K) + E_res + E_brake⁺(s_K)
(2) P_peak⁺ ≤ P_max(t)
(3) T_peak⁺ ≤ T_lim − ΔT_safe
(4) 归航路径 π_home 的几何/SLAM/门宽/坡度证书有效
```
其中 E_rem⁻=E⁻(t)，E_comp 是执行该块的计算能耗（由 WCB 给出），E_res 为硬安全储备。

**新增定义 543（能量-归航不变式 EHI）** 系统在 t 时刻满足能量-归航不变式，记为 EHI_t：
```
EHI_t ⇔ 已停靠(docked)
       ∨ ( E⁻(t) ≥ E_home⁺(s_t) + E_res + E_brake⁺(s_t)
           ∧ ∃d∈D: Π_cert(s_t,d)≠∅ )
```
EHI 是**全局活性**谓词：它不保证不撞（那是 v9 空间证书的职责），而保证在任意后续时刻都存在一条能耗可行的归航路径。EHI 只使用区间下界与能耗上界，因此是保守的。

**新增定义 544（能量门控块长与能量中止点集）** 对候选动作序列，定义：
```
K_eff^E(t) = max{ k∈{1..K_max} : ∀j≤k,
                 EHI 在前缀 a^{1:j} 末状态成立 ∧ P_t^E(j)≠∅ }
K_eff(t) = min( K_eff^v9(t), K_eff^E(t) )
P_t^E = { p∈P_t : E⁻(p) − E_brake⁺(p) − E_home⁺(s_p) ≥ E_res }
```
若 K_eff^E(t)=0，不执行任务块，进入**归航模式**（定义 548）。若 K=1 的逐步 fallback 仍无能量有效中止点，则只允许执行认证归航动作或安全停驻；此时若 EHI 也不成立，记录为活性失败（liveness failure），与碰撞/安全违背分开统计。

**新增定义 545（功率-热契约）** 每个模块契约扩展为：
```
κ_m^E = (In, Out, D_m, Ŵ_m, v_m^⊥, π_m, φ_m^elig, J_m, E_m, θ_m)
```
其中 J_m 为运行功率（W），E_m 为单次调用能耗（J），θ_m 为热耦合系数。WCB 在每控制周期检查：
```
(1) Σ_{m∈A_t} J_m · (Ŵ_m/T_c) ≤ P_alloc(t)
(2) Σ_{m∈A_t} E_m ≤ E⁻(t) − E_home⁺(s_t) − E_res
(3) T_{t+τ}⁺ ≤ T_lim − ΔT_safe,  τ 为热预测时域
```
不可行时，按 c_m^E 从低到高关闭 φ_m^elig=true 的可选模块（注入 v_m^⊥ 并跳过计算）；随后缩短 K_eff；再降低速度；最后进入低功耗安全模式并请求充电。**任何情况下都不延长 D_m、不关闭 φ_m^elig=false 的安全模块、不使用“省电”作为跳过 M₀ 硬检查的理由。**

**新增定义 546（热-算-运动耦合模型）** 电芯温度按集总热模型演化：
```
T_{t+1} = T_t + Δt/C_th · [ J_total(t) + J_motion(t)
                           − κ_T · (T_t − T_amb) ]
```
其中 J_total=Σ_m J_m·(Ŵ_m/T_c)，J_motion 为运动功率，C_th 为热容，κ_T 为散热系数。C_th、κ_T、J_motion 由 DBO 的物理信息分支给出区间，热预测只使用上界。热治理器的优先级与定义 545 相同：先关可选模块，再缩短块长，再降速，最后停驻散热；禁止通过“多算一会儿来预测得更准”突破 T_lim。

**新增定义 547（共形区间、ACI 与 OOD 门）** 对每个标量状态维度，分裂共形给出：
```
q_{1−α} = Quantile({score_i}, ⌈(n+1)(1−α)⌉/n)
C(x) = [f(x) − q_{1−α}, f(x) + q_{1−α}]
```
在线用自适应共形推断跟踪慢漂移：
```
α_{t+1} = clip( α_t + γ·(α_target − err_t), α_min, α_max )
err_t = 1{ true_state_t ∉ C_t }
```
OOD 分数 o_t 取潜空间马氏距离与重构误差的归一化最大值；若 o_t>τ_OOD、传感器时间戳过期或标定集过期，则丢弃学习区间，改用数据手册 + 库仑计数 + ECM 的最坏界：
```
s⁻ ← max(0, s_coulomb − ε_c),  R⁺ ← R_max,  T⁺ ← T_measured + ΔT_sensor
```
交换性下共形给出边际覆盖 ≥1−α；慢漂移下 ACI 给出长期覆盖；任意分布偏移下**没有保证**，这是引理 92 明确划出的失效边界。

**新增定义 548（认证归航与充电调度）** 充电桩集合 D={d_i}，每个 d_i 携带认证位姿、可用性、充电功率与热约束。归航能耗上界为：
```
E_home⁺(s) = min_{d∈D} min_{π∈Π_cert(s,d)} E_π⁺(s,d)
```
Π_cert 中的路径必须通过地图版本、SLAM 不确定性、门宽、坡度、限速与充电桩可用性证书；任一失效则 E_home⁺=∞，EHI 不成立。停靠后，充电目标 s_target 由任务队列、当前温度与老化代价决定：优先避开高 SoC×高温区间以减缓容量衰减；充电调度是非安全功能，失败只影响任务吞吐，不进入安全证书。

**新增定义 549（每焦耳安全贡献）** 在 v9 的贡献向量 c_m 上定义：
```
c_m^E = c_m / max(E_m, ε)
```
ID 的休眠判据与 WCB 的关停顺序都可使用 c_m^E；φ_m^elig=false 的安全模块不参与该排序。关闭可选模块的效果等价于 v9 的 dormant：注入 v_m^⊥，不改变任何安全证书。若能量感知归因不可用，退回 v9 的 c_m 排序，行为等价 v9。

## 2. 形式化定义（要点与升级）

- **定义 493/495/521/524/532–539 全部继承**，不改语义。
- **升级定义 533（块证书 v10）**：Ĉ_t 仍是空间/力/抓取证书；新增 Ê_t 作为**附加**能量证书。两者是合取关系：Ĉ_t 失效走 v9 的中止/停驻路径，Ê_t 失效只拒绝该块或缩短块长，不替代、不弱化 Ĉ_t。
- **升级定义 496（软证书 v10）**：
```
δ_trigger = {σ<τ_safe ∧ γ_grasp valid ∧ Δ_dom<τ_dom ∧ risk_SLAM<τ_SLAM
             ∧ Ĉ_t valid ∧ EHI_t ∧ Ê_t valid}
```
新增两项只作用于“是否允许执行新的任务块/动作”，不修改 M₀ 硬检查的输入空间。若 EHI 或 Ê 失效，系统仍可执行认证归航动作，因此不会把“电量不足”误判为“碰撞风险”。

# IP-357 DeepBatteryObserver：物理信息深度区间观测器
class DeepBatteryObserver:
    def __init__(self, model, conformal, ood, phys_fallback,
                 alpha_target=0.01, gamma=0.005):
        self.model = model          # ECM 残差 + TCN/GRU，输出 (s,h,R,T)
        self.calib = conformal
        self.ood = ood
        self.phys = phys_fallback   # 库仑计数 + 数据手册最坏界
        self.alpha = alpha_target
        self.alpha_target = alpha_target
        self.gamma = gamma

    def update(self, window):
        if self.calib.expired or self.ood.score(window) > self.ood.tau:
            return self.phys.worst_case(window)      # 保守回退
        y = self.model(window)                       # 点估计仅供校准中心
        q = self.calib.quantile(self.alpha)
        return Interval([y[d] - q[d] for d in range(4)],
                        [y[d] + q[d] for d in range(4)])

    def aci_update(self, true_state):
        err = 0 if self.last_interval.contains(true_state) else 1
        self.alpha = clip(self.alpha + self.gamma
                          * (self.alpha_target - err), 1e-3, 0.2)


# IP-358 EnergyReserveCertifier：能量-归航不变式
class EnergyReserveCertifier:
    def __init__(self, energy_model, return_planner, E_res=0.05,
                 dT_safe=2.0, T_lim=45.0, K_max=10):
        self.F_E = energy_model
        self.home = return_planner
        self.E_res, self.dT_safe, self.T_lim = E_res, dT_safe, T_lim
        self.K_max = K_max

    def certify_chunk(self, state, chunk, batt, t):
        E_rem = batt.available_lower()                       # 定义 541
        E_cons = self.F_E.upper_energy(state, chunk) + chunk.E_comp
        s_end = self.F_E.rollout_end(state, chunk)
        E_home = self.home.upper_energy(s_end)               # 定义 542/548
        E_brake = self.F_E.upper_brake(s_end)
        if E_rem < E_cons + E_home + self.E_res + E_brake:
            return None
        if chunk.P_peak > batt.p_max(t):
            return None
        if chunk.T_peak > self.T_lim - self.dT_safe:
            return None
        if not self.home.path_cert_valid(state, s_end):
            return None
        return EnergyCert(E_rem, E_cons, E_home,
                          chunk.P_peak, chunk.T_peak)

    def effective_K(self, state, state_end_fn, chunk_prefixes, batt, t):
        for k in range(self.K_max, 0, -1):
            if all(self._prefix_ok(state, chunk_prefixes[j], batt, t)
                   for j in range(1, k + 1)):
                return k
        return 0                                          # 归航模式

    def ehi_holds(self, state, batt, t):
        return (batt.available_lower()
                >= self.home.upper_energy(state)
                   + self.E_res + self.F_E.upper_brake(state))


# IP-359 WattContractBroker：功率 + 热 + EDF 三重可行性
class WattContractBroker:
    def __init__(self, thermal_model):
        self.thermal = thermal_model

    def allocate(self, contracts, batt, t):
        P_alloc = batt.p_alloc(t)
        E_budget = batt.energy_budget(t)
        mandatory = [c for c in contracts if not c.distill_eligible]
        optional = sorted([c for c in contracts if c.distill_eligible],
                          key=lambda c: c.safety_per_joule, reverse=True)
        active = list(mandatory)
        for c in optional:
            trial = active + [c]
            if (self.power_ok(trial, P_alloc)
                    and self.energy_ok(trial, E_budget)
                    and self.thermal.ok(trial)):
                active.append(c)
            else:
                c.force_neutral = True                    # 注入 v_m^⊥
        if not (self.power_ok(mandatory, P_alloc)
                and self.energy_ok(mandatory, E_budget)
                and self.thermal.ok(mandatory)):
            return LOW_POWER_MODE                         # 定义 545
        return active

## 4. 推导

**引理 87（区间观测的保守性）** 设 DBO 区间在 t 时刻有效；E⁻ 关于 s、h 单调递增，关于 R、T 单调递减；E_cons⁺、E_home⁺ 关于速度、坡度、R、T 单调递增。则用端点 σ⁻ 计算得到的 E⁻ 是真实可用能量的下界，E_cons⁺ 与 E_home⁺ 是真实能耗的上界；任何点估计都不能使能量证书比端点计算更乐观。证明：由区间有效性与单调性逐项比较；E_cons⁺、E_home⁺ 的每个加项都取上界，求和保序。∎

**引理 88（EHI 的归纳保持 / 不搁浅）** 若 EHI_t 成立，且每个执行的块 ζ 满足定义 542 的能量证书（其中 E_home⁺ 在块末状态计算），中块守卫在每个执行步复核 EHI，则 EHI 在块末与所有中间步保持；归纳至停靠或任务结束，系统始终存在一条带 E_res 储备的认证归航路径。证明：由证书 (1)，E⁻(t+K) ≥ E⁻(t) − E_cons⁺ ≥ E_home⁺(s_{t+K}) + E_res + E_brake⁺(s_{t+K})，即 EHI 在块末成立；中块守卫把同一不等式施加于每个中止状态 p*；对块序列归纳即可。若中途充电，E⁻ 单调不降，EHI 只会更易成立。∎

**引理 89（能量证书的跨块复合性）** 对块序列 ζ_1,…,ζ_n，若每块保持 EHI，则拼接序列保持 EHI；复合证书只需对每块的 E_cons⁺、E_home⁺ 取算术和/最小值，不需要任何几何重叠或同伦兼容条件。证明：能量是标量且消耗可加，E⁻(t_n) ≥ E⁻(t_0) − Σ_i E_cons⁺(ζ_i) ≥ E_home⁺(s_{t_n}) + E_res；逐块不等式望远镜求和即得。∎ 这是本轮与“路径管道证书”最本质的区别：空间证书需要几何复合，能量证书只需算术复合。

**引理 90（功率-热契约的可行性与 50Hz 保持）** 设 (i) 安全模块集合 M_safe 满足 Σ_{m∈M_safe} J_m·(Ŵ_m/T_c) ≤ P_alloc 且 Σ_{m∈M_safe} Ŵ_m ≤ B_dec；(ii) WCB 只通过注入 v_m^⊥ 关闭 φ^elig=true 的可选模块；(iii) 热预测上界 T⁺ 是保守的。则 WCB 调度满足功率、能量、温度与截止期约束；若 M_safe 本身不可行，则进入低功耗安全模式而不是延长截止期。可选模块的关停使系统落在 v9 退化格点上。证明：功率/能量/热约束由 allocate 的可行性检查逐项保证；EDF 对安全模块的可行性由 (i) 与 v9 引理 86 继承；关闭可选模块等价于 v9 的 dormant（引理 83/91）。∎

**引理 91（能量层的严格退化等价）** 定义能量增强算子 E=(DBO,ERC,WCB,CAP)。将其整体旁路（任一组件失效即触发）后，决策函数、候选动作集、中止点集与可观测日志与 v9 逐位一致：ERC 恒等（K_eff^E=K_max、P_t^E=P_t）、WCB 不施加功率/热约束、DBO/CAP 不被调用。证明：按结构归纳 v9 主循环的每个分支；能量层只出现在 AC 之后的过滤与 WCB 的调度顺序中，旁路后这些位置均变为恒等映射；v9 的随机种子/候选采样未被修改，故日志逐位一致。∎ 需要强调：这种等价意味着 v9 的“电池充足”隐含假设重新生效；它是退化契约，不是安全改进。

**引理 92（深度区间标定的覆盖与失效边界）** 若标定序列与部署序列可交换，分裂共形给出 P(x_t∈C_t) ≥ 1−α；若分布慢漂移，ACI 在 γ→0、Σγ=∞ 的标准条件下给出长期覆盖率趋近 1−α；若 OOD 门触发且物理回退界有效，则安全路径仍保守。反之，若 OOD 静默失准（o_t≤τ_OOD 但真实状态落在区间外），则不存在覆盖保证，EHI 可能被错误签发。证明：前两项为共形/ACI 的标准结论；第三项由引理 87 的单调性；最后一项给出反例：构造一个落在潜空间高密度区、但真实内阻因突发老化跃迁的样本，任何仅依赖 o_t 的门都无法识别。∎

## 8. 本轮最大风险

**一句话**：能量-归航不变式把“剩余电量下界”和“归航能耗上界”都托付给深度电池观测器，而这两者的误差恰在电池老化、低温、高倍率——也就是最需要安全余量的工况——同时放大；若 OOD 门控与共形区间在这些工况下“静默失准”，系统会在电量其实已不足时仍签发 EHI 有效证书，把“不会搁浅”从物理保证降级为一次深度学习外推。
