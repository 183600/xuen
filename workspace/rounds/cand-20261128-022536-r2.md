### 第 6 轮灵感驱动研究记录（本循环第 2 轮）

**灵感词**：视觉感知、多传感器融合

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把提议从离散规则升级为条件流匹配、把记忆升级为「检索+固化」、把人因从意图 veto 升级为「情感调制」，并用定理 5/6/7/8 守住「同门 + 阈值只紧 + 提议无关」的单调收缩。本轮不推翻 v5，而是补 v5 一个更靠底层的短板：**七硬门消费的始终是一个点估计 ŝ**（物体 6D 位姿、几何、接触状态、外力）。提议再会生成、记忆再会反哺、情绪再会收紧，只要 ŝ 错了，证书就是「在错误世界上正确」。两个灵感词统一为主题「认证的感知条件执行」（Certified Perception-Conditioned Execution, CPCE），形成 CADVS-v6（IP-497~500）。本轮自律：**硬门数量仍不增**（维持七门），感知只走「条件化 + 前置准入 + 阈值膨胀」三条非侵入通道，执行集嵌套升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **视觉感知 → 把证书的信任根从「提议器」下移到「世界状态估计」，用集合证书替代点证书**。直觉上，v5 的证书像一张写满数字的体检单，但体检仪本身没校准：流策略可以提出漂亮轨迹，门却在错误的物体位姿上判「安全」。正确做法不是再给轨迹空间加一道门，而是承认「我们只知道 ŝ 落在一个置信集里」，把门从点谓词升级为集合谓词。技术上用**共形预测**把视觉 6D 位姿/几何/接触包成分布无关的置信集 C_α(ŝ)（仅需可交换性，不需高斯假设），再用门的 **Lipschitz 裕度**把阈值抬到 τ_i^6 = τ_i^5 + L_i·ε_i：只要在 ŝ 上以膨胀后的阈值通过，就保证 C_α 内所有真实状态都以原阈值通过。这一步把「统计学习的覆盖保证」接到了「控制证书」上，是本轮的理论主轴（定理 9）。

2. **多传感器融合 → 融合本身必须先被认证，而不是先被信任**。直觉上，RGB-D、事件相机、触觉阵列、六维力/力矩、本体感知的误差不是独立的；把它们的协方差直接相加会得到「假自信」——看起来方差变小，实际可能把系统性偏差藏起来。改用**协方差交叉（CI）**：P_f = (Σ w_i P_i^{−1})^{−1}，对任意未知互相关都给出 PSD 一致上界，宁保守不冒进；再用 **χ² / parity-space 新息残差**做传感器一致性检验，得到不一致指数 δ。融合不是「提高精度的工具」，首先是一本「不确定性的诚实账本」：一致则正常，轻度不一致则放大 ε（只紧），重度不一致则拒绝认证、fail-closed 降级（减速/停/请求重标定）。这样「多传感器融合」被纳入 fail-closed 语义，而不是绕过它。

3. **不新增门 → 感知只走「条件化 + 前置准入 + 阈值膨胀」三条非侵入通道**。视觉/融合特征只允许进入流提议的条件 c_ctx 和不确定度 ε，**永不给任何门放松权限**；感知一致性是「认证之前是否允许认证」的可准入条件（admissibility），不是第八个轨迹谓词门——不满足时系统根本不进入选证，而是走安全降级。七锚 {3DCF, MSRG, HICK, EEK, LTEM, VACK, BCK} 完备性保持（定理 12），执行集由「同门 + 阈值只紧 + 前置准入 + 提议支撑受限」四重保证只缩不涨。

**关键洞见**：v4 回答「提议=规则时，七门够不够」；v5 回答「提议=任意生成器时，门还守不守得住」；v6 回答「连世界状态都是估出来的、且估计可能自相矛盾时，门还守不守得住」。答案是：**点证书必须升级为集合证书**——共形覆盖（统计层）+ CI/χ² 一致性（融合层）+ Lipschitz 裕度膨胀（控制层）三者合成，才能让同一套七门对感知误差稳健。本轮新增的只有：PFK（感知融合核）、PRC（感知鲁棒证书）、FCK（一致性/标定核）、EFA-v6；软评分 ECS_v6 = ECS_v5 · η_perc，其中 η_perc 随不确定度单调下降。

**形式化目标（增量）**：
1. 共形 6D 位姿：非一致性分数 r(ξ, ξ̂) = d_SE3（对称物体用 ADD-S）；校准集分位数 q_{1−α}；C_α(ξ̂) = {ξ : r(ξ, ξ̂) ≤ q_{1−α}}，在可交换假设下 P(ξ ∈ C_α) ≥ 1−α。
2. CI 融合：P_f = (Σ_i w_i P_i^{−1})^{−1}，Σ_i w_i = 1，w_i ≥ 0；对任意互相关给出协方差 PSD 上界（引理 46）。
3. 一致性：χ² 新息检验 + 不一致指数 δ = max_{i,j} ‖z_i − H_i ŝ‖²_{Σ_{ij}^{−1}}；δ > δ_abort ⇒ Exec_v6 = ∅（fail-closed 降级）。
4. 鲁棒裕度：τ_i^6 = τ_i^5 + L_i·(ε_i + ε_cal + ε_sync)，其中 s_i 对状态分量 L_i-Lipschitz；连续门用裕度、离散接触门对置信集内所有接触假设取合取。
5. 定理 9（感知鲁棒证书/覆盖转移）、定理 10（融合单调与一致性 fail-closed）、定理 11（提议-感知正交/无门泄漏）、定理 12（七锚完备性保持）。
6. Exec_v6 = {x ∈ supp(π_θ^FM) : admit(δ, ε) ∧ ∧_i kc_i(x, ŝ; τ_i^6) = 1} ⊆ Exec_v5。

**本轮最大风险**：**感知层假认证**——共形覆盖依赖可交换性，一旦视觉域漂移或被对抗补丁/透明物体欺骗，真实状态可能被挤出 C_α(ξ̂)，而鲁棒裕度只保证「相对置信集」的稳健、不保证置信集本身正确，系统会在「覆盖率 1−α」的假象下放行错误轨迹；CI 与 χ² 只能识别传感器「互相矛盾」，识别不了「全体一致地错」。

### IP-498 PRC：感知鲁棒证书（离线算 L_i；在线 O(|gates|)）

```python
@dataclass
class PerceptionRobustCertificate:
    """PRC：点证书 → 集合证书。
    红线：τ_i^6 ≥ τ_i^5 恒成立，任何感知输入都不能放松门（定理 11）。"""
    lipschitz: dict             # L_i：门分数对相关状态分量的局部 Lipschitz 上界
    gate_state_dep: dict        # 门 i 依赖的状态分量：'pose'|'geo'|'contact'

    def inflate(self, tau5: dict, eps: dict) -> dict:
        tau6 = {}
        for i, L in self.lipschitz.items():
            dep = self.gate_state_dep[i]
            e = eps[dep] + eps['cal'] + eps['sync']
            tau6[i] = tau5[i] + L * e              # 只抬，不降
        return tau6

    def robust_pass(self, i, x, s_hat, tau6_i) -> bool:
        if self.gate_state_dep[i] == 'contact':
            # 离散接触门：对 H 内所有一致假设取合取；任一假设失败即失败
            return all(self._continuous_score(i, x, c) >= tau6_i for c in s_hat.H)
        # 连续门：点分数已在 tau6 中扣除 Lipschitz 裕度
        return self._continuous_score(i, x, s_hat) >= tau6_i

    def certify(self, x, s_hat, tau5: dict, eps: dict) -> tuple[bool, dict]:
        tau6 = self.inflate(tau5, eps)
        ok = all(self.robust_pass(i, x, s_hat, tau6[i]) for i in tau6)
        return ok, tau6
```

**Lipschitz 上界的三种来源（按可验证性排序）**：(a) 解析界（几何/碰撞距离对位姿的 1-Lipschitz 平移分量、旋转的 r·‖·‖ 界）；(b) 区间界传播（对门内部网络做 IBP/CROWN）；(c) 采样 + 局部线性化经验界，附保守放大因子。无界情形（接触拓扑突变）不走 Lipschitz，而走假设集合取合取。

### IP-500 EFA-v6：七硬门 + 感知鲁棒阈值 + 一致性前置准入

```python
@dataclass
class EvidenceForgingAssemblerV6:
    pfk: PerceptionFusionKernel
    prc: PerceptionRobustCertificate
    fck: FusionConsistencyCalibrationKernel
    v5: EvidenceForgingAssemblerV5        # 复用 FMPP/LMEM/FAMK/VACK/BCK 全套

    def select(self, obs, t_now, rule_id, context):
        p = self.pfk.estimate(obs, t_now)                     # 集合值感知
        cons = self.fck.check(obs.z, p.s_hat, p.P_xi)
        if cons.abort:
            return self._degrade('PERCEPTION_INCONSISTENT')   # fail-closed
        eps = {k: v * cons.eps_mult for k, v in p.eps.items()}  # 只放大
        if max(eps.values()) > self.fck.eps_max:
            return self._degrade('PERCEPTION_UNCERTAIN')
        gamma = self.v5.famk.gamma(self.v5.famk.observe(context.face, t_now))
        tau5 = {i: gamma[i] * TAU4[i] for i in gamma}         # v5 阈值
        tau6 = self.prc.inflate(tau5, eps)                    # 只抬
        c = build_ctx(context, p, self.v5.lmem)               # 视觉/融合嵌入作条件
        cands = self.v5.fmpp.propose(c, self.v5.fmpp.K)       # K=8，异步准入时域
        surv = [x for x in cands if self._cheap_gates_robust(x, p, tau6)]
        if not surv:
            return self._fallback_rule_proposal(tau6)         # 回退 v4/v5 规则提议
        surv.sort(key=lambda x: self._prefilter_score(x), reverse=True)
        finals = []
        for x in surv[:3]:
            vac = self.v5.v4.vack.evaluate(x, context_with(p), t_now)
            if self.prc.robust_pass('val', x, p.s_hat, tau6['val']):
                finals.append(x)
        ok = [x for x in finals if self._bck_preview_robust(x, p, tau6)]
        if not ok:
            return self._degrade('ALL_CANDIDATES_REJECTED')
        best = max(ok, key=certified_margin)                  # 边际最大者
        return True, best, 'FORGED_CPCE'

    def ecs_v6(self, ..., eps_norm: float) -> float:
        eta_perc = math.exp(-self.lam_perc * eps_norm / self.eps_ref)
        return self.v5.ecs_v5(...) * eta_perc                 # 仅排序/监控
```

### 集成流水线（v5 → v6）

```
离线/慢时域：
  共形校准：留出校准集 ──▶ 非一致性分数分位数 q_{1−α} ──▶ 版本化只读
  Lipschitz 标定：门内部区间界传播/解析界 ──▶ L_i 表（附保守因子）
  标定基线：手眼/触觉外参 ──▶ 漂移阈值 ──▶ CUSUM 参数
  联邦：视觉嵌入原型/融合残差统计（DP）──▶ 安全聚合 ──▶ 下发 q、L_i、标定先验

在线准入（异步，秒级）：
  PFK.estimate (10–30 Hz) ──▶ ŝ + C_α + ε + H
  FCK.check ──┬─ abort ──▶ 安全降级（STOP/SLOW/RECALIBRATE）
              └─ ok ──▶ ε 放大（只紧）
  PRC.inflate：τ^6 = τ^5 + L·(ε+ε_cal+ε_sync)（每感知帧预计算）
  FMPP.propose(K=8) ──▶ 廉价门（鲁棒版）──▶ VACK（τ^6）──▶ BCK 预览（假设集合取）
       └─ 全灭/无可认证 ──▶ fail-closed 回退规则提议或降级

在线控制环（目标仍 < 0.6 ms）：
  每周期：EEK(kc_ee, 位姿置信集) + BCK（融合接触后验触发）
  只消费预计算的 τ^6 与缓存证书；感知融合不在 1 kHz 环内
```

## 4. 正确性论证（增量更新）

### 引理 45（共形覆盖，分布无关）

**陈述**：设校准样本与测试样本 (ŝ_i, s_i) 可交换，非一致性分数 r 固定，q_{1−α} 为校准集 r 的经验 (1−α) 分位数，则 P(r(s, ŝ) ≤ q_{1−α}) ≥ 1−α，即 P(s ∈ C_α(ŝ)) ≥ 1−α。∎

**诚实边界**：这是**边际**覆盖，不是条件覆盖；可交换性一旦被域漂移或对抗视觉破坏，保证失效（见 §6 R60/R61）。共形集是「模型 + 校准数据」的产物，不能防御模型本身的对抗性偏移。

### 引理 46（CI 一致性，互相关无关）

**陈述**：对任意未知互相关 Σ_ij，CI 融合协方差 P_f = (Σ_i w_i P_i^{−1})^{−1}（Σw_i=1）满足 P_f ⪰ P_true（PSD 意义），即不低估真实不确定度。∎

**证明**：在信息形式下，Σ_i w_i P_i^{−1} ⪯ Σ_i w_i P_true^{−1} = P_true^{−1}（利用 P_i ⪰ P_true 与 w_i 归一），取逆保序即得。∎

**含义**：CI 宁保守不冒进；代价是融合精度可能低于朴素加权（见 R62）。

### 引理 47（Lipschitz 裕度）

**陈述**：若门分数 s_i(x, ·) 对相关状态分量 L_i-Lipschitz，且真实状态 s ∈ C_ε(ŝ)（半径 ε），则 s_i(x, s) ≥ s_i(x, ŝ) − L_i·ε。因此若 s_i(x, ŝ) ≥ τ_i^5 + L_i·ε，则 s_i(x, s) ≥ τ_i^5。∎

### 定理 9（感知鲁棒证书 / 覆盖转移）——本轮理论主轴

**陈述**：在引理 45~47 下，令 τ_i^6 = τ_i^5 + L_i·(ε_i+ε_cal+ε_sync)。若轨迹 x 在 ŝ 上以 τ^6 通过全部门（接触门对假设集合取），则对 C_α(ξ̂) 内任意真实状态 s，x 以 v5 阈值 τ^5 通过全部门；因此以概率 ≥ 1−α，真实世界中的 x 满足 v5 证书。于是假认证概率 ≤ α + P(执行/跟踪假设失效)。

**证明**：由引理 47 逐门得 s_i(x,s) ≥ s_i(x,ŝ) − L_i ε_i ≥ τ_i^5 + L_i(ε_cal+ε_sync) ≥ τ_i^5；接触门由假设集合合取覆盖所有一致状态。再对「s ∈ C_α」用引理 45 取概率。∎

**工程含义**：这是把「统计覆盖」变成「控制证书」的桥：门本身不改，只把阈值按不确定度抬高，就能把点证书升级为对感知误差稳健的集合证书。

### 定理 10（融合单调与一致性 fail-closed）

**陈述**：(i) Exec_v6 对 ε 与 δ 单调不增：ε′ ≥ ε、δ′ ≥ δ ⇒ Exec_v6(ε′,δ′) ⊆ Exec_v6(ε,δ)；(ii) δ > δ_abort 或 max ε > ε_max ⇒ Exec_v6 = ∅（安全降级，不选证）；(iii) CI 融合不低估不确定度（引理 46），故不会因融合而「凭空」扩大执行集；(iv) Exec_v6 ⊆ Exec_v5。

**证明**：(i) τ_i^6 随 ε 单调升，各门通过集单调缩；(ii) 前置准入 admit 直接为 0；(iii) 由引理 46；(iv) τ_i^6 ≥ τ_i^5 且 admit 为附加合取。∎

### 定理 11（提议-感知正交 / 无门泄漏）

**陈述**：视觉/融合特征与 ε 只能影响提议分布 π 与阈值膨胀 τ^6，不能降低任何门阈值或跳过任何门。形式化：对任意视觉输入 v，若 τ^6 由 PRC 生成，则 Exec_v6(v) ⊆ Exec_v5 恒成立；且存在视觉输入使 Exec_v6 严格缩小（不确定度大），但不存在使 Exec_v6 严格扩大的视觉输入。

**证明**：τ_i^6 = τ_i^5 + L_i·e，L_i ≥ 0、e ≥ 0 ⇒ τ^6 ≥ τ^5；提议不参与门谓词（v5 定理 6 的感知版）。∎

**含义**：对抗视觉最多让系统更保守或降级，不能让它「更放行」；但注意这只防「放松」，不防「全体一致地错」（见 R60）。

### 定理 12（七锚完备性在感知条件下保持）

**陈述**：v6 不增删锚点：七锚 {3DCF, MSRG, HICK, EEK, LTEM, VACK, BCK} 完备性（v4 定理 4 / v5 定理 8）保持。PFK/FCK 是感知前置条件，PRC 是阈值膨胀通道，均非新锚；感知一致性是 admissibility，不是第八个轨迹谓词门。

**证明**：锚点集合不变；感知只经「条件化 + 前置准入 + 阈值只紧」进入；由定理 10(iv)/11 得执行集只缩。∎

### 定理 v6（执行集四重收缩与集合证书，总装）

**陈述**：在 v4 假设 (B1)~(B6)、v5 假设 (B7) 及新增 (B8) 共形可交换、(B9) 门分数局部 Lipschitz 界有效、(B10) 传感器时间同步误差有界下：
(i) Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29；
(ii) 集合证书：以概率 ≥ 1−α，v6 通过者在真实状态上满足 v5 证书（定理 9）；
(iii) 融合单调与 fail-closed（定理 10）；
(iv) 无门泄漏（定理 11）；(v) 七锚完备性保持（定理 12）；
(vi) 视觉/融合特征只进提议与 ε，控制环仍消费预计算 τ^6。

**诚实声明**：(B8) 可交换性在域漂移/对抗视觉下失效，边际覆盖不保证条件覆盖；(B9) 接触拓扑突变处 L_i 可能无界，只能退回假设集合并枚举，组合复杂度随遮挡/多接触上升；(B10) 传感器硬同步难以保证，陈旧感知会用旧状态证书「追新轨迹」；(iv) CI 保守导致高不确定时执行集塌缩（R62）；(v) 「全体传感器一致地错」无法被一致性检验识别（R60），这是本轮原理性盲区。

## 7. 本轮最大风险（最终确认）

**一句话**：**感知层假认证**——共形覆盖依赖可交换性，一旦视觉域漂移或被对抗补丁/透明物体欺骗，真实状态可能被挤出 C_α(ξ̂)，而 Lipschitz 鲁棒裕度只保证「相对置信集」的稳健、不保证置信集本身正确，CI 与 χ² 又只能识别传感器「互相矛盾」、识别不了「全体一致地错」，系统会在「覆盖率 1−α」的假象下放行错误轨迹；多模态交叉验证、红队、在线覆盖监控与高不确定降级只能限损，无法根除。
