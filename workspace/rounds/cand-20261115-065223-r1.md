# 第 4 轮（承接第 3 轮 InstructGauge v3（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）；新灵感循环第 1 轮；本轮灵感：「具身智能」×「用户测试」）

> **基线**：第 3 轮 InstructGauge（Instruction-Grounded, Chunked Probing Metrology）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。具身条件与用户测试都是可选增强：身体模型不可用 ⇒ 退回 ToolGauge 的 body-agnostic 路径；用户研究不可用 ⇒ 退回 InstructGauge 的原始解释与默认信任策略。

## 0. 直觉与动机

**灵感 1（具身智能 → 盲区不是几何属性，而是「身体相对」属性）**
直觉：同一块被遮挡的金属件，对「当前基座 + 当前臂展 + 当前腕部相机 + 当前工具」是盲区，对换一个基座姿态或换一把细长探针却可能完全可测。反过来，一个在视野里但机械臂够不到的区域，根本不是合法的测量目标。第 3 轮把盲区当成场景里的静态区域，这是** disembodied 的错觉**。具身智能的第一条不是「更大的 VLA」，而是：**可达性、可观测性、可接触性都由身体状态 β 参数化**。因此动作集不是 `T₀`，而是 `T₀ ∩ E(β)`；身体只能**过滤**工具与目标，绝不能凭空增加工具或物理量。
形式化落点：能力包线 `E(β)` 与身体条件化计划 `Plan(ι,β) ⊆ Plan_ToolGauge`（定义 449/459，引理 59）。

**灵感 2（本体感受与接触 → 比视觉更便宜的「身体回执」）**
直觉：探测计量里，「我摸到了边缘」往往比「我看到了边缘」更强。关节力矩、外力、末端挠度、滑移、关节限位、温度与工具磨损，都是直接的物理证据；它们不需要再跑一次昂贵的视觉前向，却与「是否真的接触、接触是否可靠」强相关。但接触证据稀疏、有摩擦/柔顺混淆、且容易被一次坏读数污染。正确做法不是把接触塞进视觉置信度，而是给它**独立的证据类型与独立的证书**：视觉、本体、接触三类回执分别校准，保守融合，未知一律 fail-closed。
形式化落点：本体可负担性证书 `PAC(a,β,W) ∈ {yes,no,unknown}`，`unknown` 禁止接触式动作（定义 450/451，引理 60）。

**灵感 3（具身间隙 → 证书不能免费从 sim 迁移到 real）**
直觉：第 3 轮只把 sim→real 当成「性能退化 ≤10%」的系统指标，但证书本身是在 sim 里校准的。若真实身体的可达集、柔顺性、摩擦或时延与 sim 不同，一张 sim 证书可能是**自信地错误**的。具身智能要求把「身体差异」显式建模：估计可达集之间的 Hausdorff 距离与遥测残差，得到一个上置信界 `g_emb⁺`；只有 `g_emb⁺ ≤ δ_emb` 才允许迁移，否则必须在真机上重新校准或退回单步数值路径。
形式化落点：具身间隙上界与迁移门 `g_emb⁺ ≤ δ_emb`（定义 452，引理 61）。

**灵感 4（用户测试 → 不是演示，而是对人机接口的测量仪器）**
直觉：一张修复证书，如果人类操作员看不懂、信错或不用，它就不是有效接口。用户测试因此不该是「找几个人来点赞」，而应像计量一样预注册、分层、可证伪：任务成功率、测量时间、干预次数、工作负荷、解释理解度，以及最关键的**过度依赖 / 依赖不足**。用户不是无噪声的 oracle；用户测试是**有偏、有方差的测量**，必须有自己的误差模型与样本量。
形式化落点：预注册用户测试协议 `UTP` 与用户测试证书 `UTC`（定义 453/458，引理 65）。

**灵感 5（信任共形 → 解释的置信度必须与用户实际成功率共形）**
直觉：直接显示模型置信度，会把「模型自信」误当成「用户该信」。真正要校准的是**依赖策略**：当系统显示 `p̃` 时，用户按契约接受，实际成功概率应至少为 `p̃ − α`；于是「过度依赖率」可以被一个共形上界夹住。这里借的是共形预测的**单侧过度自信分数**：只在「预测成功但实际失败」时计分，取分层上分位 `q_s`，只有 `p̂ > q_s` 才显示置信度，否则显示「不确定，请升级确认」。这把「解释」从文案问题变成带统计保证的接口问题。
形式化落点：`A_i = 1{Y_i=0}·p̂_i`，`q_s` 为层内 `1−α` 上分位，`p̃ = p̂` 仅当 `p̂ > q_s`（定义 454/455，引理 62）。

**灵感 6（联合能力闭包 → 人类 override 也只能在身体包线内选择）**
直觉：最危险的耦合不是机器人自己乱动，而是**用户被一张高置信解释说服，手动把机器人推出身体包线**。第 3 轮的能力闭包只约束了自然语言；本轮必须把它扩展到人类输入：人类 override 是**过滤器/选择器**，不是能力授予。联合可采纳集是 `A_joint(β,u) = E_cons(β) ∩ A_human(u)`，任何越出 `E_cons(β)` 的 override 一律拒绝或升级到独立复核。
形式化落点：联合能力屏障 `JCB` 与 `A_joint ⊆ E_cons(β)`（定义 456/460，引理 63）。

**灵感 7（用户作为弱证据源 → 不能让人成为安全旁路）**
直觉：用户反馈能揭示规格歧义、缺失的本体项与解释盲点，但用户也会被误导、会疲劳、甚至被对抗性提示操纵。因此用户反馈只能进入**本体候选与解释措辞**的更新通道，带敏感度/特异度与独立用户数门槛；绝不能进入 `E(β)`、`T₀`、`M_phys` 或安全证书通道。否则「用户说没事」就会变成绕过物理约束的后门。
形式化落点：用户 oracle 噪声模型与通道隔离（定义 457，引理 64）。

## 1. 研究问题（本轮要回答什么）

- **Q1（具身条件化）**：当可达性、可观测性与接触可行性都依赖身体状态 β 时，如何给出「身体不能扩权、未知必须 fail-closed」的能力闭包？身体模型本身有误差时如何退化？
- **Q2（用户测试的可证伪性）**：用户测试能否从演示变成测量？能否定义并保证「信任校准」这一接口性质，而不是只报告满意度？
- **Q3（耦合放大）**：当具身证书与人类信任耦合，是否会产生「有理由的过度信任」——即证书看起来可信、用户因此更敢接受、从而把身体误差放大？联合包线与信任屏障能否把这种放大压回可界？

## 2. 设计原则

**P4 身体条件化（Embodiment Conditioning）**
所有能力、证书与计划都以身体状态 β 为索引：`Plan(ι,β) ⊆ Plan_ToolGauge ∩ E_cons(β)`。β 不可观测或标定过期 ⇒ 使用保守包线 `E_cons^min`，接触式动作强制 K=1，必要时退回 body-agnostic 的 ToolGauge。

**P5 接触证据分层（Contact Evidence Stratification）**
视觉回执、本体回执、接触回执分别校准；融合规则保守：任一 `no` ⇒ `no`，任一 `unknown`（且无 `no`）⇒ `unknown`，只有全部必需回执为 `yes` 才返回 `yes`。未知不是「大概可以」，而是「禁止执行接触式动作」。

**P6 联合能力闭包（Joint Capability Closure）**
语言（第 3 轮）与人类 override（本轮）都只能做子集选择，不能扩大物理可行域；真正能限制动作的是身体包线 `E_cons(β)` 与不可逆屏障。人类权威不能替代物理可行性。

**P7 信任共形（Trust Conformality）**
解释的显示置信度必须按用户 stratum 校准，并绑定一个明确的依赖契约；在该契约下，过度依赖率有共形上界。解释同时受认知预算 `B_cog` 约束，避免「解释过载」反向伤害可靠性。

## 3. 与基线的接口（如何退化）

- β 不可观测 / 本体标定过期 ⇒ 退回 ToolGauge 静态工具模型，接触式动作强制 K=1；
- PAC 为 `unknown` / 接触回执缺失 ⇒ 禁用接触式动作，退回纯视觉 ToolGauge；
- `g_emb⁺ > δ_emb` ⇒ 丢弃 sim 证书，改用 on-body 校准；校准样本不足 ⇒ 退回 LeanGauge 数值路径；
- 用户研究不可用 / 无 `UTC` / `TCE` 校准层样本不足 ⇒ 使用 InstructGauge 原始解释（raw confidence），不声称 user-validated；
- 人类 override 通道不可用 ⇒ 机器人自主默认，JCB 不启用；
- InstructGauge 失效 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个**身体条件化能力包线**与**本体可负担性证书**，把「盲区」从场景几何量改成身体相对量，并让接触证据成为可审计的独立回执；
2. 一个**具身间隙迁移界**，把 sim→real 从性能指标升级为「证书是否仍然有效」的条件；
3. 一个**信任共形解释**与**预注册用户测试协议**，使「过度依赖率」成为可被统计保证约束的接口指标；
4. 一个**联合能力屏障**，证明人类 override 与自然语言一样不能扩权，从而切断「信任 → 物理越界」的放大链；
5. 一条完整可证伪路径：E457–E472 覆盖身体闭包、接触证书、具身间隙、信任校准、用户任务、工作负荷、对抗用户与跨站点外部效度。

## 5. 本轮最大风险

**一句话**：真正的残余风险是「校准器的校准器」——具身间隙估计器与信任校准模型本身也是估计出来的，一旦它们自信地错了，就会制造「看起来有理由」的过度信任，使用户接受并放大身体侧的错误，而不是让两个误差相互抵消。

## 2. 形式化定义（要点）

**定义 448（本体状态 β）** `β_t = (q, q̇, τ, F_ext, T_base, κ, c, w, h)`。其中 `q` 关节位置、`q̇` 关节速度、`τ` 关节力矩、`F_ext` 六维外力、`T_base` 基座位姿、`κ` 手眼/工具尖/运动学偏置标定、`c` 末端柔顺/刚度、`w` 工具磨损、`h` 热与执行器健康。`β_t` 由本体感知异步估计并带时间戳；超过 `T_β` 未更新视为不可观测。

**定义 449（具身能力包线 E 与内近似 E_cons）**
`E(β) = {(a,x) ∈ T₀ × X : Reach(a,x,β) ∧ Clear(a,x,β) ∧ Dyn(a,x,β) ∧ ContactSafe(a,x,β)}`。
`Reach` 为运动学可达，`Clear` 为从当前基座无碰，`Dyn` 为力矩/速度/热约束内，`ContactSafe` 为接触力与柔顺在包线内（非接触动作恒真）。由于 `E(β)` 一般非凸且难以精确判定，证书只使用**内近似** `E_cons(β) ⊆ E(β)`：由预认证的可达盒、无碰管与力/柔顺区间取并集得到。`E_cons` 的保守性由引理 59 保证。

**定义 450（本体可负担性证书 PAC）** `PAC(a,β,W) = (aff, conf, χ, valid_until)`，`aff ∈ {yes,no,unknown}`。判定规则：
- 若任一必需回执与几何/力预测矛盾 ⇒ `no`；
- 若任一必需回执缺失、过期、传感器健康不足或标定哈希不匹配 ⇒ `unknown`；
- 只有全部必需回执为 `yes` 且保守检验通过 ⇒ `yes`。
`χ` 为回执证据链，`valid_until` 绑定回执时域。**关键纪律**：`unknown` 不是「默认可行」，而是「禁止接触式动作」。

**定义 451（身体回执 r_body）** `r_body = (t, id, β_t, τ, F, Δx, slip, T, w, κ_hash, sig)`。`Δx` 为末端位移/挠度，`slip` 为滑移估计，`T` 为温度，`sig` 为不可篡改签名。身体回执与视觉回执、工具回执并列，不互相替代。

**定义 452（具身间隙与迁移门）** 设 `E_cons(β_real)` 与 `E_cons(β_sim)` 为同一认证器在真机/仿真上产出的包线，定义
`g_emb = d_H(E_cons(β_real), E_cons(β_sim)) + λ·resid_telemetry`，
其中 `d_H` 为末端位姿/力能力集上的 Hausdorff 距离，`resid_telemetry = ‖τ_real − τ_sim‖ / τ_max`。用分层保形/回归校准得到上置信界 `g_emb⁺`（置信度 `1−α_g`）。**迁移门**：仅当 `g_emb⁺ ≤ δ_emb(cls)` 时，sim 证书可迁移，并按 `L·g_emb⁺` 膨胀阈值；否则 `on_body_only`，即只信真机现场校准，样本不足则退回 LeanGauge 数值路径。

**定义 453（用户测试协议 UTP）** `UTP = (H, T, S, M, n, α, β_power, prereg_id, stop, excl)`：`H` 预注册假设，`T` 任务集（与 E441–E456 的计量任务同分布但独立采样），`S` 分层（新手/专家、领域知识、机器人经验、指令歧义等级），`M` 指标（成功率、测量时间、干预次数、OTR、UTR、ECE_trust、NASA-TLX、解释理解度），`n` 每层样本量，`stop` 停止规则，`excl` 排除标准。**用户测试不是演示**：必须预注册、盲法或至少评分者盲、报告效应量与置信区间。

**定义 454（信任共形解释 TCE）** 对每个用户 stratum `s`，在校准集 `C_cal^s` 上计算过度自信分数 `A_i = 1{Y_i=0}·p̂_i`，取上分位
`q_s = Quantile_{⌈(n_s+1)(1−α)⌉/n_s}({A_i})`。
显示规则：
`p̃ = p̂` 若 `p̂ > q_s`；否则 `p̃ = ⊥`（输出「不确定，请升级确认/双人复核」）。
解释模板 `e` 只描述「依据哪条回执、哪条证书、哪条主张」，不引入新的数值断言。`R_contract` 明确要求用户只在 `p̃ ≥ τ_u` 时接受自动动作。

**定义 455（依赖契约与信任校准）** 用户依赖策略 `R_u: p̃ → {accept, reject, override}`，契约版本为「`p̃ ≥ τ_u` 才接受；`p̃ = ⊥` 必须询问或拒绝；override 只能选择 `E_cons(β)` 内动作」。定义
`OTR = P(accept ∧ Y=0)`，`UTR = P(reject ∧ Y=1)`，
`ECE_trust = E[ |1{accept} − 1{p ≥ τ*}| ]`，其中 `τ* = c_over/(gain + c_over)` 为代价最优接受阈值。**注意**：`OTR` 是安全侧指标，`UTR` 是效率侧指标，二者不可用一个「满意度」分数混同。

**定义 456（联合可采纳集与 JCB）** `A_joint(β,u) = E_cons(β) ∩ A_human(u)`。联合能力屏障
`JCB(a,β,u) = 1{a ∈ A_joint(β,u)}`。
若人类 override 请求 `a ∉ E_cons(β)`：返回 `Refuse`，或升级为「K=1 + 独立身体证书 + 双人确认」；但**任何情况下不得执行** `a ∉ E_cons(β)`。人类权威是过滤器，不是能力授予。

**定义 457（用户 oracle 噪声与通道隔离）** 用户反馈 `y_u` 是真实规格 `spec*` 的噪声观测：`P(y_u=1|spec=1)=se`，`P(y_u=0|spec=0)=sp`。用户反馈只允许更新 `O_onto` 的候选集与解释措辞，禁止写入 `E_cons`、`T₀`、`M_phys`、`PAC` 或安全证书。更新需满足：独立用户数 `m ≥ m_min`、似然比 `Λ ≥ Λ_min`、且 `se,sp > 0.5`；否则忽略并记录为「弱证据」。

**定义 458（用户测试证书 UTC）** `UTC = (prereg_id, n_eff, strata, effect_sizes, CI, OTR, UTR, ECE_trust, TLX, conclusion)`。仅当每个 stratum 的 `n_s ≥ n_min`、预注册主要终点 CI 不含 0、且安全侧 `OTR ≤ α_otr` 时，`conclusion = user_validated`；否则 `inconclusive`。`UTC` 是「可以声称 user-validated」的唯一凭据。

**定义 459（身体条件化接地 Γ_β）** `Γ_β: L_NL × Scene × O_onto × B → (ι, GroundCert) ∪ {(⊥, Suggestion)}`。能力闭包公理：
`tools(ι) ⊆ T₀ ∧ mag(ι) ⊆ M_phys ∧ Plan(ι,β) ⊆ Plan_ToolGauge ∩ E_cons(β) ∧ ¬∃ free-text→actuator`。
若指令要求的目标不在 `E_cons(β)` 内，`Γ_β` 返回 `(⊥, Suggestion)`，其中 `Suggestion` 只能从预注册的身体重配置集合（换基座、换工具、换腕部姿态）中选择，**不得**生成新的物理动作。

**定义 460（过度信任屏障 TrustBarrier）** 若 `p̃ = ⊥`，或 `PAC(a)=unknown`，或 `g_emb⁺ > δ_emb`，或证书过期，则：
- 禁止自动执行；
- 要求双人确认或硬件使能；
- 若用户仍请求 override，仅允许 `E_cons(β)` 内动作，并记录为「高冲突事件」。
屏障与第 3 轮不可逆屏障正交：`TrustBarrier` 管「人是否该信」，`Barrier` 管「动作是否可逆」。

**定义 461（具身感知分块目标 IAC_β）**
`C* = argmax_C [ ΔH(C) + w_align·A(ι,C) + w_ens·smooth(C) + w_contact·ΔH_contact(C) − λ_cost·c(C) − λ_body·c_body(C) ]`
`s.t. C ⊆ E_cons(β), prefix_closed(C), Barrier(C), |C| ≤ K_MAX(ι)·body_derate(β), B_chunk ≤ B_left`。
`ΔH_contact` 为接触回执的期望信息增益，`c_body` 为能量/热/磨损代价；`body_derate(β) ≤ 1` 在关节力矩或温度接近上限时收紧块长。

**定义 462（认知预算 B_cog）** `B_cog(u)` 为用户可承受的解释长度/时间上限。解释策略必须满足 `cost(e) ≤ B_cog(u)`；若超预算，退化为「最小解释 + 显式置信度 + 升级按钮」，不得用长篇文字挤占操作时间。

**定义 463（EmbodiGauge 证书 J_EG）** `J_EG = (J_Instruct, β_snapshot, E_hash, PAC_ids, g_emb⁺, UTC_id, TCC_id, claims)`。`Valid(J_EG)` 要求：`J_Instruct` 有效、β 未过期、`E_hash` 与认证器一致、PAC 所有必需项为 `yes`（接触动作）或非接触、`g_emb⁺ ≤ δ_emb`（若使用 sim 证书）、`UTC` 与 `TCC` 未过期。`claims` 仍为纯投影，不改变数值路径。

class EmbodimentEnvelope:
    def admissible(self, a, beta):
        if beta is None or expired(beta):
            return NON_CONTACT(a) and PER_STEP(a)          # 退回 body-agnostic
        if not (self.reach(a, beta) and self.clear(a, beta)
                and self.dyn(a, beta)):
            return False
        if is_contact(a) and not self.contact_safe(a, beta):
            return False
        return self.inner_box.contains(a, beta)            # E_cons ⊆ E

# IP-329 PAC：本体可负担性证书（保守融合，unknown 禁止接触动作）
class PAC:
    def certify(self, a, beta, W, receipts):
        if beta is None or not receipts:
            return PAC("unknown", 0.0, [], horizon=0)
        req = [r for r in receipts if r.action_id == a.id]
        if any(r.contradicts(a, W) for r in req):
            return PAC("no", 0.0, req, horizon=0)
        if any(r.missing() or r.stale() or not r.healthy()
               or r.kappa_hash != beta.kappa_hash for r in req):
            return PAC("unknown", 0.0, req, horizon=0)
        return PAC("yes", min(r.conf for r in req), req,
                   horizon=min(r.valid_until for r in req))

# IP-330 EGE：具身间隙上界与迁移门
class EmbodimentGap:
    def gate(self, real, sim, cls):

        g += LAMBDA * telemetry_residual(real, sim)
        g_ucb = self.calibrator.upper(g, alpha=ALPHA_G)    # 置信上界
        if g_ucb > DELTA_EMB[cls]:
            return "on_body_only", g_ucb
        return "transfer", g_ucb

# IP-331 TCE：信任共形解释
class TrustCalibratedExplainer:

        scores = [(0.0 if y == 1 else p) for (p, y) in cal]
        q_s = conformal_upper_quantile(scores, alpha=ALPHA_T)

        return ABSTAIN, self.template(user, "uncertain"), CONTRACT

# IP-332 UTP：预注册用户测试与 UTC

        if any(len(trials.stratum(s)) < prereg.n_min for s in prereg.strata):

# IP-333 JCB：人类 override 也只能在身体包线内选择
def joint_capability_barrier(a, beta, user_cmd, envelope):
    if not envelope.admissible(a, beta):
        return "refuse"                                   # 物理不可行
    if user_cmd is not None and not envelope.admissible(user_cmd, beta):
        return "refuse_or_escalate"                       # 人不能扩权

# IP-334 EmbodiGauge-8C 闭环：I→B→H→C→E→C→V→U
def embodigauge_8c(M, s, ell, user):
    beta = M.body.latest()                                # B：身体条件
    out  = M.nlib.ground_beta(ell, M.scene, M.ontology, beta)
    iota = out[0] if out else M.default_iota               # ⊥ ⇒ ToolGauge 目标

        return M.toolgauge_fallback(s, iota)

## 4. 推导

**引理 59（具身能力闭包）** 设 `Plan_β(ι) = {Π ∈ Plan(ι) : ∀a∈Π, a ∈ E_cons(β)}` 且 `E_cons(β) ⊆ E(β)`。若 `Γ_β(ℓ) = (ι,·)`，则 `Plan_β(ι) ⊆ Plan_ToolGauge ∩ E_cons(β)`；每一次执行的动作都落在 `E_cons(β)` 内。若 β 不可观测，取保守包线 `E_cons^min` 并强制接触动作 K=1，结论仍成立。
*证明骨架*：`Plan_β` 是 `Plan(ι)` 与 `E_cons(β)` 的交；由第 3 轮引理 51，`Plan(ι) ⊆ Plan_ToolGauge`；交集对子集单调，故 `Plan_β ⊆ Plan_ToolGauge`。执行归纳：每步动作由 CVC 提交且经 ECE 过滤，故每步都在 `E_cons(β)` 内；保守包线情形由内近似传递性给出。**推论**：身体与语言都只能减少动作，不能增加工具或物理量。

**引理 60（PAC 保守融合的可靠性）** 设每个必需身体回执 `r_i` 的可靠性为 `1−α_i`，融合规则为「任一 `no` ⇒ `no`；否则任一 `unknown` ⇒ `unknown`；只有全 `yes` ⇒ `yes`」。则 `P(affordance true | PAC=yes) ≥ 1 − Σ_i α_i`。若滑移检测的漏检率为 `γ`，则未检测滑移的期望损失 `≤ γ·c_slip`。
*证明*：`PAC=yes` 要求所有必需回执通过，按联合界，至少一个回执失效的概率不超过 `Σα_i`；融合规则在失效时返回 `no/unknown` 而非 `yes`。滑移项由漏检率定义直接得到。该引理只给出**条件可靠性**；若传感器模型本身有偏，保守融合仍可能错，因此必须有定义 452 的间隙门与 E458 的现场检验。

**引理 61（具身间隙迁移界）** 设真实成功率 `s(a,β)` 对 β 满足 `L`-Lipschitz：`|s(a,β) − s(a,β′)| ≤ L·d(β,β′)`，且 `d(β_real,β_sim) ≤ g_emb⁺` 以置信度 `1−α_g` 成立。则对任意 sim 认证动作 `a`，
`|s_real(a) − s_sim(a)| ≤ L·g_emb⁺`。
因此 sim 阈值 `τ` 可迁移为真机阈值 `τ + L·g_emb⁺`；若 `g_emb⁺ > δ_emb := (1−τ)/L`，则不存在非平凡迁移证书，必须走 `on_body_only`。此外，若 `a ∉ E_cons(β_real)`，无论 sim 证书多高都不可执行（JCB 直接拒绝）。
*证明*：Lipschitz 与三角不等式给成功率差界；阈值平移由差界得到；`g_emb⁺ > (1−τ)/L` 时即使 `s_sim=1` 也可能 `s_real < τ`，故无迁移价值。可达性部分由引理 59 的集合包含直接得到。**注**：这是保守界，`L` 应由 `E_cons` 的认证数据估计，并在 E459 中检验其覆盖率。

**引理 62（信任共形与过度依赖上界）** 在 stratum `s` 内假设可交换，令 `A_i = 1{Y_i=0}·p̂_i`，`q_s` 为 `A_i` 的 `⌈(n_s+1)(1−α)⌉/n_s` 分位，显示规则为 `p̃ = p̂` 当且仅当 `p̂ > q_s`，否则 `⊥`。则对任意 `τ > q_s`，
`P(Y=0 ∧ p̃ ≥ τ) ≤ α`。
若用户遵守依赖契约 `R_u`（`p̃ ≥ τ_u` 才接受），则 `OTR ≤ α`。代价是：当 `p̂` 与真实成功率都低但 `q_s` 较高时，系统会更频繁地 `⊥`，即 `UTR` 上升；这是安全方向的保守性。
*证明*：由共形分位的覆盖性，`P(A_new ≤ q_s) ≥ 1−α`。若 `Y=0` 且 `p̂ > q_s`，则 `A_new = p̂ > q_s`，与 `A_new ≤ q_s` 互斥；故该事件概率不超过 `α`。用户接受意味着 `p̃ ≥ τ_u > q_s`，于是接受且失败的概率不超过 `α`。**注**：该界是单侧的，不能同时保证 `UTR`；`UTR` 需用另一侧分数或经验置信区间报告（E465）。

**引理 63（联合能力闭包 / 人类不能扩权）** `A_joint(β,u) = E_cons(β) ∩ A_human(u) ⊆ E_cons(β)`。若 JCB 对 `a ∉ E_cons(β)` 返回拒绝或升级到「K=1 + 独立身体证书」，则由引理 59，升级路径执行的动作仍在 `E_cons(β)` 内。因此人类 override 只能缩小、不能扩大可执行动作集；过度信任不能转化为物理越界，最多转化为拒绝/确认/低效。
*证明*：集合交的子集性；升级路径的动作仍须通过 ECE 与 CVC，由引理 59 归纳。**推论**：第 3 轮的能力闭包（语言）与本轮的 JCB（人类输入）共同构成「双通道闭包」：两条人机接口都不能绕过身体包线。

**引理 64（用户 oracle 噪声不污染安全路径）** 设用户反馈仅用于 `O_onto` 候选与解释措辞，且 `se,sp > 1/2`、`m ≥ m_min`。在条件独立假设下，用似然比阈值 `Λ_min` 更新，错误本体更新的概率随 `m` 指数下降（Chernoff 界）。由于 `E_cons`、`T₀`、`M_phys`、`PAC`、安全证书的更新通道不读取用户反馈，任何用户噪声都不能直接产生不安全动作；最坏后果是解释变差或本体建议被延迟。
*证明*：把用户反馈视为二元假设检验，`m` 个独立观测的似然比对数期望为正比于 `m·KL`，尾概率由 Chernoff 界指数衰减；通道隔离由定义 457 的类型约束保证（用户反馈在类型上不能写入安全通道）。**注**：这不排除「用户操纵 UI 直接发动作」——那由 JCB 与 ZTS 拦截，不由本引理覆盖。

**引理 65（用户测试的统计有效性与外部效度）** 对两臂预注册研究，每臂 `n`、基线成功率 `p₀`，在显著性 `α`、功效 `1−β_power` 下最小可检测差异约为
`δ_min ≈ (z_{1−α/2} + z_{1−β_power})·√(2p₀(1−p₀)/n)`。
若主要终点 CI 含 0 或宽度超过预注册等价界，则 `UTC = inconclusive`，不得声称 user-validated。分层结论要求每层 `n_s ≥ n_min`；外部效度要求至少两个站点/队列且交互项不显著。
*证明*：两比例正态近似；预注册逻辑把「结论」限制为协议内可检验的陈述。**注**：这是方法学引理，不替代 E464–E468 的实测；它的作用是防止事后挑选终点与「小样本演示」被写成有效性声明。

**引理 66（严格退化等价）** 若 β 不可观测、PAC 为 `unknown`、`g_emb⁺ > δ_emb`、TCE/UTP 不可用或 JCB 关闭，则 EmbodiGauge 在同一输入上的决策与 InstructGauge 完全一致；而 InstructGauge 在自身失效时按第 3 轮引理 57 退到 ToolGauge/LeanGauge/MODGAUGE。
*证明*：对每个守卫做情况分析。ECE 在 β 缺失时返回 `NON_CONTACT ∧ PER_STEP`，等价于 ToolGauge 的逐步非接触路径；PAC unknown 时禁用接触动作，等价于纯视觉 ToolGauge；gap 门失败时丢弃 sim 证书，等价于 InstructGauge 的现场校准/数值回退；TCE 不可用时使用原始置信度，等价于 InstructGauge；JCB 关闭时人类 override 行为回到第 3 轮接口。新组件均为**过滤器或包装器**，失败时返回基线调用，故语义等价。

## 8. 本轮最大风险

**一句话**：`EGE` 的间隙上界与 `TCE` 的信任校准都是**二阶估计**——它们一旦自信地错了，就会给出「看起来有理由」的证书与解释，使用户更敢接受、从而放大身体侧误差；因此真正的残余风险不是单个模块失效，而是「校准器的校准器」在人机接口处发生相关误差，必须用 E459/E463/E469/E472 的独立现场检验主动证伪。
