# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim++；灵感循环第 6 轮；本轮灵感：「多机协作」×「安全性」）

> 第 54 轮把单机技能组合提升为「动作-鲁棒性双证书」J=(ρ, A_cert, γ_ce, δ_a)。本轮把执行主体从单机扩展到 **n 机联合体 M={m_1..m_n}**，聚焦 **协作安全包络、假设-保证契约、分布式安全证书、安全预算共识、跨机不变量、可中断接管**。核心矛盾：H22：多机安全不是各机安全的合取——存在只有 ≥2 台机器同时动作才会显形的「涌现危险」；H23：安全风险预算在分布式下会被「双花」，每台机器都合规但全局超支；H24：假设-保证契约存在循环担保时，组合推理规则失效（互相担保，却无人真正担保）。

## 0. 直觉与动机

**灵感 1（协作安全包络 → 从单机 Safe Set 到联合安全流形）**
直觉：单机安全是状态-动作对落在包络 E_i 内；多机安全是联合轨迹落在 **联合安全流形** `𝓜_safe(φ)` 内，φ 是定义在联合轨迹上的 STL 公式（「任意两机距离 > d_min」「共享区互斥」「无死锁」）。`𝓜_safe` 不是 `∏ E_i`：它含有跨机约束，维度更高、边界更复杂。这把安全从「逐点约束」升级为「流形上的可达性」。

**灵感 2（涌现危险 → 单机不可见的最小致因集）**
直觉：危险 H 是 k-涌现的，若其最小致因集需要 k 台机器联合。单机监控根本看不到 k≥2 的危险。定义 **致因秩** `rank(H)=min{|C| : C⊆M 联合导致 H}`；只有 `rank(H)=1` 时单机证书才足以覆盖。多机安全的第一性任务是枚举并优先监控 `rank≥2` 的跨机不变量。

**灵感 3（假设-保证安全契约 → 让每台机器「有条件地」担保）**
直觉：m_i 不能对任意队友担保安全，只能承诺 `G_i`，前提是队友满足 `A_i`。契约 `C_i=(A_i,G_i,ρ_i^safe)`。组合安全 = 所有 `A_i` 被其余 `G_j` 满足。但循环依赖（m_1 假设 m_2 让行，m_2 又假设 m_1 让行）会让组合规则「空洞成立」，必须用 **良基序 / 不动点** 排除循环担保。

**灵感 4（分布式安全证书 → 拜占庭鲁棒的保守聚合）**
直觉：每台机器有本地证书 `cert_i=(ρ_i,E_i,ev_i)`。全局证书 `F=⊕_i cert_i` 需要 **单调且拜占庭鲁棒** 的聚合算子：坐标中位数 / 截尾均值，使 f 台故障机不能把全局安全下界抬高。证书不是标量而是格，聚合取保守 meet（交集）。

**灵感 5（安全预算共识 → 风险不能被双花）**
直觉：系统有总风险预算 B（如每小时碰撞概率上界），每台机器消耗 b_i。分布式若各机独立记账，就会双花，`Σb_i > B`。把预算建模为 **带序号的信用凭证**，分配需法定人数证书（quorum certificate）；通信分区时退化为静态预分配分区，保证 **安全降级** 而非超支。

**灵感 6（可中断接管 + 责任归因 → 安全兜底与事后解释）**
直觉：任何时刻监督机必须能在 τ_int 内把联合体带入 **联合安全停机集**；每个停机动作本身必须对他人安全（停机集是联合安全的）。事故后用反事实 Explain 计算 **责任谱** `resp_i`，回答「若 m_i 当时采取安全动作，危险是否可避免」，把第 54 轮的单机 Explain 扩展为多机责任归因。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（协作安全包络）**
联合状态 `s=(s_1,...,s_n)∈𝓢=∏𝓢_i`，联合动作 `a=(a_1,...,a_n)∈𝓐=∏𝓐_i`。给定 STL 公式 φ，联合安全流形 `𝓜_safe(φ) = { (s,a) | (s,a) ⊨ φ }`。协作安全包络 `𝓔 = { (s,a) | ∀i:(s_i,a_i)∈E_i } ∩ 𝓜_safe(φ)`。注意 `𝓔 ⊊ ∏E_i`，差额即涌现危险区。

**定义 122（致因秩与涌现危险）**
危险 H 的致因集 `C⊆M` 若去掉 C 中任一机器则 H 不发生，则 C 为最小致因集。`rank(H)=min|C|`。若 `rank(H)≥2`，H 为 **涌现危险**，单机证书 `cert_i` 无法覆盖。多机安全的覆盖判据：`cover_M(φ) = ⋀_{H⊆¬φ} (rank(H)=1 ? cert_i 覆盖 : φ_X 监控覆盖)`。

**定义 123（假设-保证安全契约）**
`C_i=(A_i,G_i,ρ_i^safe)`：`A_i` 为对环境与队友的假设，`G_i` 为本机保证，`ρ_i^safe` 为安全维度鲁棒谱。契约组合 `⊗`：`C_1⊗...⊗C_n` 安全当且仅当存在良基序 `≺` 使每个 `A_i` 只依赖 `≺` 更小的 `G_j`，且 `A_i ⊆ ⋂_{j≺i} G_j`。**禁止循环担保**（循环使蕴含链无基，组合规则不可靠）。

**定义 124（分布式安全证书与鲁棒聚合）**
本地证书 `cert_i=(ρ_i,E_i,ev_i)`。全局证书 `F=⊕_{i∈Q} cert_i`，⊕ 为坐标中位数（或截尾均值）与格 meet 的复合，Q 为法定人数。若故障机数 `f < n/3`，则 `F` 的安全下界不被抬高（`F` 只会更保守，不会更乐观）。

**定义 125（安全预算与信用凭证）**
总预算 B，凭证 `t_i=(seq_i,b_i,σ_i,sig_i)`：`seq_i` 单调递增，`σ_i` 为 quorum 证书。合法消费满足 `Σ_i b_i ≤ B` 且 `seq_i` 无回滚。分区时退化为预分配 `b_i^0`，`Σ_i b_i^0 ≤ B`（宁可降低并行度，不可超支）。

**定义 126（跨机不变量与可中断接管）**
跨机不变量 `φ_X` 为不可分解为 `⋀_i φ_i` 的联合谓词（互斥、连通、无死锁）。联合监控 `Mon_X` 在 τ_mon 内检测 `¬φ_X`。可中断性：`∀s∈𝓔, ∃π_int` 使 `π_int(s)` 在 τ_int 内落入联合安全停机集 `𝓢_stop ⊆ 𝓔`；且 `π_int` 对任意队友动作均安全（停机集联合安全）。

## 2. 关键算法 伪代码

### IP-121 CSC（Collaborative Safety Contract）

```python
def build_contract(machine, phi_local, rho_safe):
    A_i = infer_assumptions(machine.env, machine.teammates)
    G_i = synthesize_guarantee(machine, phi_local, rho_safe)
    return Contract(A_i, G_i, rho_safe)

def compose_contracts(contracts):
    deps = build_dependency_graph(contracts)   # A_i -> G_j
    order = topo_sort(deps)
    if order is None:
        return ('reject', 'circular_assumption', find_cycle(deps))
    for i in order:
        for j in deps[i]:
            if not subset(contracts[i].A, contracts[j].G):
                return ('reject', 'assumption_violated', (i, j))
    return ('ok', ContractBundle(order, contracts))
```

### IP-122 FSC（Federated Safety Certificate）

```python
def federated_certificate(certs, dims, f):
    rho_agg = {d: coordinate_median([c.rho[d] for c in certs]) for d in dims}
    E_agg = meet_all([c.E for c in certs])          # 保守交集
    ev = union_evidence(certs)
    if byzantine_count_upper(certs) > f:
        return ('degrade', rho_agg, E_agg)          # 降低保证等级，不抬高下界
    return ('ok', FederatedCert(rho_agg, E_agg, ev))
```

### IP-123 SBA（Safety Budget Allocation）

```python
def allocate_budget(B, demands, quorum):
    proposal = water_filling(B, demands)
    if sum(proposal.values()) > B:                  # 预算不变量
        return ('reject', 'over_budget')
    cert = collect_quorum(proposal, quorum)         # 防双花
    if not cert.valid:
        return ('fallback', static_partition(B))    # 分区安全降级
    return ('ok', BudgetLedger(proposal, cert))
```

### IP-124 XMI（Cross-Machine Invariant Monitor）

```python
def monitor_cross_invariants(joint_state, invariants, tau_mon):
    # rank 高的优先，通信预算内调度
    for inv in sorted(invariants, key=lambda x: -x.rank):
        if inv.cost > comm_budget: continue
        if not inv.check(joint_state):
            cause = minimal_cause(inv, joint_state)
            return ('violation', inv, cause, elapsed() < tau_mon)
    return ('ok', None)
```

### IP-125 MSS（Multi-machine Safety Shield）

```python
def multi_machine_shield(a_proposed, safe_set, weights, budget):
    a_safe = project(a_proposed, safe_set)          # 联合投影到 𝓔
    cost = sum(weights[i]*dist(a_proposed[i], a_safe[i]) for i in M)
    if cost > budget:
        return ('safe_stop', joint_safe_stop_set)   # 保底：联合安全停机
    return ('ok', a_safe, cost)
```

### IP-126 SRA（Safety Responsibility Attribution）

```python
def responsibility_spectrum(trajectory, failure, safe_policy):
    resp = {}
    for i in M:
        cf = counterfactual(trajectory, i, safe_policy[i])
        resp[i] = safe_improvement(failure, cf)     # 反事实安全增益
    z = sum(resp.values()) or 1.0
    return {i: v/z for i, v in resp.items()}
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CSC | O(n²·|A|) | O(n²) | 依赖图无环、假设被保证蕴含 |
| FSC | O(n·|𝔇_ρ|·log n) | O(|𝔇_ρ|) | 聚合单调、拜占庭界 sound |
| SBA | O(n log n + Q) | O(n) | 预算不变量、quorum 防双花 |
| XMI | O(|Φ_X|·|𝓢|) | O(|Φ_X|) | rank 排序、最小致因完备 |
| MSS | O(|𝓐|·|𝓔|) | O(|𝓐|) | 投影安全、停机集联合安全 |
| SRA | O(n·|τ|) | O(n) | 反事实可计算、归因归一 |

**正确性定理（Multi-Machine Safety Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 单机安全包络 E_i 经结构化仿真校准且 sound；**(A30)** 契约依赖图经拓扑/不动点验证无循环担保；**(A31)** 故障机比例 `f < n/3`；**(A32)** 预算消费经 quorum 且分区回退为静态预分配；**(A33)** 跨机监控在 τ_mon 内检出所有 `rank≥2` 的涌现危险。则联合体安全违反概率：
```
P_violate ≤ Σ_i b_i + P(rank≥2 未被 τ_mon 检出) + P(f ≥ n/3) + P(循环契约漏检) + β_E
```
关键：**安全先验分解为单机包络 + 跨机不变量**，**契约无环**，**证书聚合只保守不乐观**，**预算不双花**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 涌现危险枚举不完备 | 高 | 形式化 STL 挖掘 + 红队多机对抗 + rank 优先 |
| 契约循环担保隐蔽 | 高 | 依赖图拓扑检查 + 不动点求解 + 保守拒绝 |
| 拜占庭聚合被腐蚀 | 高 | 中位数/截尾均值 + quorum + 证据交叉验证 |
| 安全预算双花 | 高 | 单调序号 + quorum 证书 + 分区静态预分配 |
| 联合盾干预过大 | 中 | 最小干预投影 + 干预预算 + 分级降级 |
| 责任归因反事实失真 | 中 | 多世界仿真 + 置信区间 + 人工复核 |

## 6. 本轮最大风险

**一句话**：多机协作安全把单机双证书扩展为「联合安全流形 + 假设-保证契约 + 拜占庭鲁棒聚合 + 预算共识」，但其 soundness **四重依赖涌现危险的完备枚举、契约依赖的无环性、故障机比例 f<n/3、以及跨机监控的实时性**；一旦 rank≥2 的危险被漏枚举、或循环担保绕过拓扑检查、或通信分区下预算回退失效，联合体就会出现「每台机器都自证安全、整体却系统性失稳」的灾难性盲区，故必须以 **形式化不变量挖掘 + 无环契约验证 + 拜占庭界硬约束 + 分区安全降级** 四重护栏，宁可保守停机，绝不把「各机安全的合取」误当作「联合体安全」。

# 第 55 轮产物 · 创新点清单 v32：CoSafe-Mesh（CSC×FSC×SBA×XMI×MSS×SRA）

> 承接第 54 轮产物 v31（GroundEdge-GenSim+++）。本轮在单机「动作-鲁棒性双证书」J 之上，增加 **多机协作安全的六个算子**：
> - **CSC（Collaborative Safety Contract）**：假设-保证安全契约，禁止循环担保；
> - **FSC（Federated Safety Certificate）**：拜占庭鲁棒的分布式安全证书聚合；
> - **SBA（Safety Budget Allocation）**：带 quorum 的安全预算分配，防双花；
> - **XMI（Cross-Machine Invariant Monitor）**：跨机不变量监控与涌现危险致因；
> - **MSS（Multi-machine Safety Shield）**：最小干预联合盾与联合安全停机；
> - **SRA（Safety Responsibility Attribution）**：反事实多机责任谱。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-118/120 以纳入多机联合维度。

| XMI | O(|Φ_X|·|𝓢|) | O(|Φ_X|) | rank 排序、最小致因完备 |
| MSS | O(|𝓐|·|𝓔|) | O(|𝓐|) | 投影安全、停机集联合安全 |
| SRA | O(n·|τ|) | O(n) | 反事实可计算、归因归一 |

**正确性定理（Multi-Machine Safety Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** E_i 结构化校准且 sound；**(A30)** 契约依赖图无循环担保；**(A31)** 故障机比例 `f<n/3`；**(A32)** 预算经 quorum 且分区回退静态预分配；**(A33)** 跨机监控 τ_mon 内检出所有 rank≥2 危险。则：
```
P_violate ≤ Σ_i b_i + P(rank≥2 未检出) + P(f≥n/3) + P(循环契约漏检) + β_E
```
关键：**安全先验分解为单机包络 + 跨机不变量**，**契约无环**，**聚合只保守不乐观**，**预算不双花**。

## 5. 本轮最大风险

**一句话**：多机协作安全把单机双证书扩展为「联合安全流形 + 假设-保证契约 + 拜占庭鲁棒聚合 + 预算共识」，但其 soundness **四重依赖涌现危险的完备枚举、契约依赖的无环性、故障机比例 f<n/3、以及跨机监控的实时性**；一旦 rank≥2 的危险被漏枚举、或循环担保绕过拓扑检查、或通信分区下预算回退失效，联合体就会出现「每台机器都自证安全、整体却系统性失稳」的灾难性盲区，故必须以 **形式化不变量挖掘 + 无环契约验证 + 拜占庭界硬约束 + 分区安全降级** 四重护栏，宁可保守停机，绝不把「各机安全的合取」误当作「联合体安全」。
