### 第 4 轮灵感驱动研究记录

**灵感词**：真机评测、多传感器融合

**直觉与动机**：

CADVS 已把证书链推进到分布式运行时（RCANG）、视觉伺服（VSCK）、差分定位（DLC）、多机一致性（MRCC）与时序守护（TCVM）。但它的全部论证仍建立在两个未经真机检验的隐含假设上：**（i）传感器误差相互独立；（ii）仿真结论可以外推到真实世界。** 本轮的两个灵感词正好各击中一个。

1. **多传感器融合的直觉**：工程上习惯把「多装几个传感器」当作可靠性来源——相机 + IMU + 轮速 + RTK + UWB，看起来冗余度很高。但冗余不等于独立。相机与 VIO 共享光照、纹理、运动模糊的退化模式；RTK 与 UWB 共享多径与遮挡；轮速与 IMU 共享打滑与零偏。这些**共模失效（common-mode failure）**会让「三源一致」变成「三源一起错」。若融合算法仍按独立高斯假设把协方差除以 n，就会系统性地**高估置信度**：传感器越多，证书越自信，而实际风险不降反升。因此本轮的核心直觉是：**融合不是求加权平均，而是对一组「有相关性的证据」做保守记账**——每个传感器交出的不是一条测量，而是一张带独立性标签与健康度的证据证书。

2. **真机评测的直觉**：真机测试昂贵、不可重复、样本稀少。若沿用「跑 100 次算成功率」的频率派汇报，会同时遭遇**幸存者偏差**（坏样本被人工剔除/重跑）与**多重比较**（挑最好的一组参数上报）。更危险的是，真机评测天然倾向覆盖「能跑通」的场景，而系统真正的风险藏在长尾（湿滑、侧向冲击、通信抖动）。因此真机评测不能只是「打分」，它本身必须是一份**可审计的证书**：预注册假设、分层场景、序贯检验、安全包络、以及明确的统计功效声明。

**关键洞见**：这两个灵感词不是并列的两件事，而是同一个陷阱的两面——**融合制造「自信的错觉」，评测制造「通过的错觉」，两者叠加会让系统在「又冗余又验证过」的外表下最脆弱。** 因此本轮把二者统一到同一套证书语义：融合**生产**证书并显式标注独立性/共模风险，真机评测**消费**证书并对其统计有效性与场景覆盖度负责。证书从「局部正确性证明」升级为「证据链 + 证据强度」。

**形式化目标（增量）**：

1. 定义传感器证据证书 `SEC_i = (Σ_i, t_i, o_i, h_i, indep_class_i)`：`Σ_i` 协方差、`t_i` 硬件时间戳、`o_i` 可观测性贡献（可观测 Gramian 的最小特征值）、`h_i` 健康度、`indep_class_i` 独立性类别（物理独立 / 共享前端 / 共享环境扰动）。
2. 定义融合证书 `FC = ⊕_i SEC_i`，融合算子满足交换律与结合律但**不满足幂等律**（重复接入同一物理源不得增加置信）；并定义共模相关系数 `ρ_cm` 与有效独立源数 `N_eff = (Σ w_i)² / (Σ_i w_i² + Σ_{i≠j} ρ_ij w_i w_j)`。
3. 定义时间同步证书 `TSC = (offset, skew, bound)`；融合前置条件 `|offset| + |skew|·Δt < τ_sync`，否则按时间误差对协方差做膨胀（见引理 33）。
4. 定义退化感知融合治理器 `DAFG`：χ² 创新门控 + 故障检测隔离（FDI）+ 排除证书（exclusion certificate），保证被剔除源不会以「零权重」形式继续污染一致性判断。
5. 定义真机评测证书 `FEC`：预注册假设 `H0/H1`、分层场景 `S = {平地, 斜坡, 湿滑, 负载, 侧向冲击, 通信抖动}`、序贯检验（e-value / SPRT）、输出带置信下界的成功率与安全包络，并显式声明统计功效。
6. 定义 sim-to-real 保真证书 `SRFC = (gap_sensor, gap_actuator, coverage)`；只有 SRFC 达标才允许把仿真结论外推为真机结论。
7. 目标：`Exec_v30 ⊆ Exec_CADVS`；在共模失效注入下，融合证书的虚假通过率比朴素协方差加权低 ≥ 5×；真机评测在 `α = 0.05` 下对成功率下降 10% 的检出功效 ≥ 0.8；`N_eff` 估计误差 < 15%。

**本轮最大风险**：**共模失效下的「伪冗余」会让融合证书系统性高估置信，而真机样本稀缺又让这种高估极难被统计检验发现**——即「融合越自信、评测越通过、实际越脆弱」，且失效往往只在部署后的长尾场景中一次性暴露。

## 2. 关键算法骨架

### IP-478 Sensor Evidence Certificate Algebra (SECA)

```python
@dataclass
class SensorEvidenceCert:
    """SEC_i：单传感器证据证书（不是一条测量，而是一张可审计的证据）"""
    sid: str
    cov: np.ndarray                 # Σ_i
    t_stamp: float                  # 硬件时间戳
    obs_contrib: float              # o_i = λ_min(𝒪_i)
    health: float                   # h_i ∈ [0,1]
    indep_class: str                # IND | SHARED_FRONTEND | SHARED_ENV

    def weight(self) -> float:
        # 逆协方差 × 健康度 × 可观测性贡献（弱可观测方向降权）
        base = 1.0 / max(np.max(np.linalg.eigvalsh(self.cov)), 1e-12)
        return base * self.health * (1.0 - np.exp(-self.obs_contrib))


class SensorEvidenceAlgebra:
    """SECA：带相关性的保守融合；⊕ 交换、结合、但【不幂等】"""
    def __init__(self, n_min: float = 2.0, rho_floor: float = 0.0):
        self.n_min = n_min
        self.rho_floor = rho_floor    # 同环境类源之间的相关性下界

    def correlation(self, a: SensorEvidenceCert, b: SensorEvidenceCert) -> float:
        """独立性类别 → 相关系数下界（保守：同类至少 ρ_floor）"""
        if a.sid == b.sid:
            return 1.0                # 同一物理源：完全相关 → 幂等被破坏
        if a.indep_class == 'IND' and b.indep_class == 'IND':
            return 0.0
        if a.indep_class == b.indep_class:
            return max(self.rho_floor, 0.5)   # 共享前端/共享环境
        return max(self.rho_floor, 0.25)      # 跨类但可能共享扰动

    def fuse(self, certs: list[SensorEvidenceCert]) -> FusionCert:
        certs = [c for c in certs if c.health > 0.05]
        if not certs:
            return FusionCert(valid=False, reason='no_healthy_source')
        w = np.array([c.weight() for c in certs])
        w = w / w.sum()
        # 相关矩阵 R（含共模）
        n = len(certs)
        R = np.eye(n)
        for i in range(n):
            for j in range(i + 1, n):
                R[i, j] = R[j, i] = self.correlation(certs[i], certs[j])
        # 有效独立源数：N_eff = (Σw)² / (wᵀ R w)
        w_sum = w.sum()
        n_eff = w_sum ** 2 / float(w @ R @ w)
        # 保守融合协方差：Σ_f = (wᵀ R w) · diag_scale（而非朴素 1/Σw）
        sigmas = np.array([np.max(np.linalg.eigvalsh(c.cov)) for c in certs])
        var_eff = float((w ** 2) @ (sigmas ** 2) + 
                        sum(w[i] * w[j] * R[i, j] * sigmas[i] * sigmas[j]
                            for i in range(n) for j in range(n) if i != j))
        sigma_f2 = max(var_eff, 1e-12)
        # 可观测性：取所有健康源的最大贡献（融合不会凭空创造可观测性）
        o_f = float(min(c.obs_contrib for c in certs))
        # 冗余声明门控：有效独立源不足则【不得】声称冗余
        redundant = n_eff >= self.n_min
        return FusionCert(
            valid=True, cov=np.eye(certs[0].cov.shape[0]) * sigma_f2,
            obs=o_f, n_eff=n_eff, rho_cm=float(R[np.triu_indices(n, 1)].max()),
            redundant=redundant,
            sources=[c.sid for c in certs],
            t_stamp=min(c.t_stamp for c in certs),
        )
```

**要点**：朴素融合把方差写成 `Σw_i²σ_i²`（假设 `ρ=0`）。SECA 用 `wᵀRw` 显式加入相关项；当 `ρ→1` 时 `N_eff→1`，方差退化到单源水平，系统**拒绝**宣称冗余。`fuse([A,A])` 因 `correlation(A,A)=1` 得到 `N_eff=1`，不增加置信——这就是「不幂等」的算法体现。

### IP-479 Time-Synchronization Certificate (TSC)

```python
@dataclass
class TimeSyncCert:
    """TSC：时钟偏移/漂移的界；融合前必须过门控"""
    offset: float          # 估计的时钟偏移（s）
    skew: float            # 漂移率（s/s，ppm 量级）
    bound: float           # offset 的置信上界（s）
    t_ref: float           # 参考时刻

    def error_bound(self, t_now: float) -> float:
        return self.bound + abs(self.skew) * abs(t_now - self.t_ref)

    def admissible(self, t_now: float, tau_sync: float = 1e-3) -> bool:
        return self.error_bound(t_now) < tau_sync
```

```python
def inflate_cov_by_sync(cov: np.ndarray, delta: float, v_max: float) -> np.ndarray:
    """可调用的纯函数版本（避免 dataclass 方法里的状态歧义）"""
    return cov + (v_max * delta) ** 2 * np.eye(cov.shape[0])
```

### IP-480 Degradation-Aware Fusion Governor (DAFG)

```python
class DegradationAwareFusionGovernor:
    """DAFG：χ² 创新门控 + FDI + 排除证书 + 分级降级"""
    def __init__(self, chi2_gate: float = 11.07, stale_t: float = 0.2,
                 reentry_hits: int = 10):
        self.chi2_gate = chi2_gate       # d=5, 1-α_gate=0.95
        self.stale_t = stale_t
        self.reentry_hits = reentry_hits
        self.excluded: dict[str, ExclusionCert] = {}
        self.hit_count: dict[str, int] = defaultdict(int)

    def gate(self, sid: str, innovation: np.ndarray,
             S: np.ndarray, t_now: float, t_stamp: float) -> bool:
        if t_now - t_stamp > self.stale_t:
            self._exclude(sid, t_now, 'stale'); return False
        d2 = float(innovation @ np.linalg.inv(S) @ innovation)
        if d2 > self.chi2_gate:
            self.hit_count[sid] += 1
            if self.hit_count[sid] >= 3:      # 连续 3 次才隔离，抗瞬时野值
                self._exclude(sid, t_now, f'chi2={d2:.1f}')
            return False
        # 恢复需连续 reentry_hits 次通过（迟滞，防振荡）
        if sid in self.excluded:
            self.hit_count[sid] = self.hit_count.get(sid, 0) + 1
            if self.hit_count[sid] >= self.reentry_hits:
                self.excluded.pop(sid); self.hit_count[sid] = 0
                return True
            return False
        return True

    def _exclude(self, sid: str, t_now: float, reason: str):
        self.excluded[sid] = ExclusionCert(sid=sid, t_excl=t_now, reason=reason)

    def exclusion_certs(self) -> list[ExclusionCert]:
        return list(self.excluded.values())
```

### IP-481 Field Evaluation Certificate (FEC)

```python
class FieldEvaluationCertificate:
    """FEC：预注册 + 分层 + 序贯 e-value；输出 LCB 与功效，而非点估计"""
    def __init__(self, p0: float = 0.90, p1: float = 0.80,
                 alpha: float = 0.05, beta: float = 0.20, p_alt: float = 0.80):
        self.p0, self.p1 = p0, p1
        self.alpha, self.beta = alpha, beta
        self.p_alt = p_alt
        self.log_e = 0.0                 # 累积对数 e-value
        self.n = 0
        self.n_succ = 0

    def update(self, success: bool) -> str:
        # 伯努利 e-value 的似然比：E_k = Π (p_alt/p0)^x ((1-p_alt)/(1-p0))^(1-x)
        x = 1.0 if success else 0.0
        self.log_e += x * np.log(self.p_alt / self.p0) + \
                      (1 - x) * np.log((1 - self.p_alt) / (1 - self.p0))
        self.n += 1; self.n_succ += int(success)
        # Ville 不等式：P_{H0}(∃k: E_k ≥ 1/α) ≤ α，可任意时刻停止
        if self.log_e >= np.log(1 / self.alpha):
            return 'REJECT_H0'           # 有证据表明成功率低于 p0
        if self.log_e <= np.log(self.beta / (1 - self.alpha)):
            return 'ACCEPT_H0'
        return 'CONTINUE'

    def lcb(self) -> float:
        # Clopper–Pearson 下界（报告用，独立于序贯停止）
        from scipy.stats import beta
        if self.n == 0: return 0.0
        return float(beta.ppf(self.alpha, self.n_succ, self.n - self.n_succ + 1))

    def required_n_approx(self) -> int:
        # 单侧 SPRT 期望样本量近似：log(1/α) / D_KL(p1||p0)
        dkl = self.p_alt * np.log(self.p_alt / self.p0) + \
              (1 - self.p_alt) * np.log((1 - self.p_alt) / (1 - self.p0))
        return int(np.ceil(np.log(1 / self.alpha) / max(dkl, 1e-9)))

    def cert(self, stratum: str, coverage: float) -> FieldCert:
        return FieldCert(stratum=stratum, n=self.n, succ=self.n_succ,
                         lcb=self.lcb(), coverage=coverage,
                         power_target=1 - self.beta,
                         pre_registered=True)
```

**分层聚合**：对每个场景层 `S_k` 独立跑序贯检验，再用 Bonferroni 或 e-value 合并控制族错误率；**禁止**先看结果再挑层上报（预注册锁定层权重）。

### IP-482 Sim-to-Real Fidelity Certificate (SRFC)

```python
@dataclass
class SimToRealFidelityCert:
    """SRFC：量化仿真-真机间隙；未达标不得外推"""
    gap_sensor: dict[str, float]     # 每类传感器归一化间隙（MMD / Wasserstein）
    gap_actuator: float              # 执行器响应间隙（阶跃响应/延迟）
    coverage: float                  # 域随机化覆盖的场景比例
    gap_max: float = 0.15
    coverage_min: float = 0.80

    def admissible(self) -> bool:
        return (max(self.gap_sensor.values(), default=0.0) < self.gap_max
                and self.gap_actuator < self.gap_max
                and self.coverage >= self.coverage_min)

    def transfer_bound(self, sim_error: float) -> float:
        """ISS 型外推界：真机误差 ≤ sim_error + g_s + g_a（保守线性界）"""
        g_s = max(self.gap_sensor.values(), default=0.0)
        return sim_error + g_s + self.gap_actuator
```

### FIELD-CADVS 统一执行流（单步）

```python
def field_cadvs_step(robot_state, sensor_bundle, eval_ctx) -> ControlOutput:
    """v30 单步：同步门控 → 证据融合 → 健康治理 → 证书链 → 控制/降级"""
    # 0) 时间同步门控（IP-479）
    tsc = eval_ctx.tsc
    t_now = sensor_bundle.t_now
    if not tsc.admissible(t_now, tau_sync=eval_ctx.tau_sync):
        return fallback_to_teacher(robot_state, reason='sync_violation')

    # 1) 单源证据证书（IP-478），时间误差膨胀协方差（引理 33）
    certs = []
    for s in sensor_bundle.sources:
        delta = tsc.error_bound(t_now)
        cov = inflate_cov_by_sync(s.cov, delta, eval_ctx.v_max)
        certs.append(SensorEvidenceCert(s.sid, cov, s.t_stamp,
                                        s.obs_contrib, s.health, s.indep_class))

    # 2) 健康治理：剔除故障/陈旧源（IP-480）
    healthy = [c for c in certs if dafg.gate(c.sid, c.innovation, c.S,
                                             t_now, c.t_stamp)]

    # 3) 证据融合（IP-478）：得到 FC，含 N_eff / ρ_cm
    fc = seca.fuse(healthy)
    if not fc.valid:
        return fallback_to_teacher(robot_state, reason='no_healthy_source')

    # 4) 冗余声明门控：N_eff 不足则【不得】把融合当多源冗余，降级为单源
    if fc.n_eff < seca.n_min:
        fc = fc.downgrade_to_single_source(reason='pseudo_redundancy')

    # 5) 证书链（沿用 CADVS）：把 FC/TSC/exclusion 注入 CertChecker
    cert_agg = eval_ctx.cert_checker.aggregate(fc=fc, tsc=tsc,
                                               excl=dafg.exclusion_certs())
    if not cert_agg.all_passed:
        return fallback_to_teacher(robot_state, reason='cert_agg_fail')

    # 6) 控制路径（沿用 CADVS 学生/视觉伺服/教师/急停）
    out = cadvs_step(robot_state, sensor_bundle, cert_agg)
    # 7) 真机评测采样（IP-481）：每个 episode 结束时记录成功/失败与场景层
    if out.terminal:
        eval_ctx.fec.update(bool(out.success))
    return out
```

## 4. 正确性论证（增量更新）

### 引理 32（共模相关下的有效独立源数与方差下界）

**陈述**：设 n 个传感器误差方差均为 σ²、两两相关系数为 ρ 的等相关注模型，等权平均融合的方差为 `Var = (σ²/n)·(1+(n−1)ρ)`；定义有效独立源数 `N_eff = n/(1+(n−1)ρ)`，则 `Var = σ²/N_eff`。当 ρ→1 时 `N_eff→1`，融合不带来任何方差下降。

**证明**：`x̄ = (1/n)Σx_i`，`Var(x̄) = (1/n²)[ΣVar(x_i) + Σ_{i≠j}Cov(x_i,x_j)] = (1/n²)[nσ² + n(n−1)ρσ²] = (σ²/n)(1+(n−1)ρ)`。代入 `N_eff` 即得 `σ²/N_eff`。ρ→1 时 `N_eff = n/(1+(n−1)) = 1`。∎

**工程含义**：朴素融合隐含 `ρ=0`，宣称方差 `σ²/n`；实际为 `σ²(1+(n−1)ρ)/n`。n=3、ρ=0.5 时真实方差是宣称值的 2 倍（标准差高估 1.41×）。SECA 用 `wᵀRw` 把这一膨胀显式写回协方差，并用 `N_eff < N_min` 拒绝「伪冗余」声明。

### 引理 33（时间同步误差导致的协方差膨胀界）

**陈述**：设测量真实时刻为 t，被错误标记为 t+δ，`|δ| ≤ δ_max`；状态在 [t, t+δ] 内变化率满足 `‖ẋ‖ ≤ v_max`。则把该测量在 t+δ 使用所引入的状态偏差满足 `‖b‖ ≤ v_max δ_max`，等价协方差膨胀为 `Σ_eff = Σ + v_max² δ_max² I`（对位置子块），且 `tr(Σ_eff) ≤ tr(Σ) + d·v_max²δ_max²`。

**证明**：真实测量 `z = h(x(t)) + v`。在 t+δ 处线性化 `h(x(t+δ)) ≈ h(x(t)) + H·ẋδ`，故创新中出现偏差 `b = H·ẋδ`，`‖b‖ ≤ ‖H‖·v_max·δ_max`。取 `H=I`（位置直接观测）得上界；偏差项的二阶矩 `E[bbᵀ] ≼ v_max²δ_max² I` 叠加到原协方差即得膨胀式。∎

**工程含义**：`τ_sync` 不是拍脑袋的 1ms，而由「允许的位置误差 `ε_pos`」反推：`δ_max ≤ ε_pos / v_max`。DAFG 对陈旧源直接隔离，TSC 对同步超界直接拒绝融合，二者共同封堵「时间错位被当成空间测量」的经典错误。

### 引理 34（序贯 e-value 的第一类错误控制与样本量）

**陈述**：对伯努利样本构造 e-value `E_k = Π_i (p_alt/p0)^{x_i}((1−p_alt)/(1−p0))^{1−x_i}`。则对任意停时 τ，`P_{H0}(∃k: E_k ≥ 1/α) ≤ α`（Ville 不等式），即在任意时刻提前停止都不膨胀第一类错误。在 H1（真实成功率 `p_alt < p0`）下，达到拒绝所需期望样本量约为 `ln(1/α)/D_KL(p_alt‖p0)`。

**证明**：H0 下 `E_k` 是非负鞅且 `E[E_k]=1`；Ville 不等式给出 `P(sup_k E_k ≥ 1/α) ≤ α E[E_0] = α`。期望样本量由 Wald 近似 `E[τ] ≈ ln(1/α)/E[ℓ]`，而 `E_{H1}[ℓ] = D_KL(p_alt‖p0)`。∎

**工程含义**：真机评测最大的诱惑是「跑几圈看起来不错就停」。序贯检验允许随时停，但**错误率不因偷看而膨胀**；这正是把「人工判断何时收工」纳入可审计证书的关键。分层场景用 Bonferroni（`α/K`）或 e-value 合并控制族错误率。

### 引理 35（sim-to-real 间隙的 ISS 型外推界）

**陈述**：设仿真与真机的闭环误差系统满足 ISS：`‖e_real‖ ≤ β(‖e_sim‖) + γ_s g_s + γ_a g_a`，其中 `g_s, g_a` 为 SRFC 的传感器/执行器间隙，`β` 为 class-𝒦 函数。则当 `SRFC.admissible()` 且 `β` 有界时，`‖e_real‖ ≤ β(‖e_sim‖) + γ_s g_max + γ_a g_max`。

**证明**：直接由 ISS 估计与 `g_s,g_a < g_max` 代入得。∎

**诚实声明**：`β, γ` 依赖具体系统且**不能从仿真单独辨识**，SRFC 只能给出**保守上界**；真实外推误差可能因未建模动态（接触、摩擦、延迟）超出该界。故 SRFC 是「允许外推的必要条件」，而非「性能保证」。

### 定理（v30 执行集收缩与「伪冗余」抑制）

**陈述**：在 (A1) TSC 通过（`error_bound < τ_sync`）；(A2) DAFG 已隔离陈旧/故障源；(A3) SECA 融合证书 `FC.valid` 且 `N_eff ≥ N_min`；(A4) 真机结论仅在 `SRFC.admissible()` 时外推——则 `Exec_v30 ⊆ Exec_CADVS`，且在注入共模相关 `ρ_cm` 的场景下，v30 的证书虚假通过率 `P_fp^v30` 满足 `P_fp^v30 ≤ P_fp^CADVS / (1+(N_s−1)ρ_cm)`（以方差高估倍数计），即至少降低 `1+(N_s−1)ρ_cm` 倍；当 ρ_cm 使 `N_eff < N_min` 时，v30 **拒绝**冗余声明并降级，虚假通过率不再随源数增加而恶化。

**证明要点**：
- 包含性：v30 在 CADVS 单步之前增加 TSC/DAFG/SECA 门控，任一不通过即回退教师路径（属 `Exec_CADVS`）；通过后控制路径完全复用 CADVS。故 `Exec_v30 ⊆ Exec_CADVS`。
- 虚假通过抑制：由引理 32，CADVS 朴素融合把方差低估为 `σ²/n`，真实为 `σ²/N_eff`，低估倍数 `n/N_eff = 1+(n−1)ρ_cm`；v30 用 `wᵀRw` 把该倍数写回，等价于把「证书通过」所需的证据门槛提高同倍数，故虚假通过率按该倍数下降。`N_eff < N_min` 时直接降级，杜绝「源越多越自信」的反向激励。∎

## 5. 真机评测协议（FEC 落地设计）

**预注册（实验前锁定，不可改）**：
- 主假设 `H0: p ≥ 0.90`，`H1: p < 0.90`；`α=0.05`，`β=0.20`；备择 `p_alt=0.80`。
- 分层场景与权重：平地 0.25 / 斜坡 0.20 / 湿滑 0.20 / 负载 0.15 / 侧向冲击 0.10 / 通信抖动 0.10。
- 主要指标：任务成功率（LCB）、证书虚假通过率（注入故障 + 隐藏真值）、恢复时间、`N_eff` 估计、同步误差 P99、SRFC 间隙。
- 安全包络：躯干倾角 < 12°、关节力矩 < 80% 额定、急停响应 < 50ms；越界 episode 记为失败且触发安全审计，**不得重跑覆盖**。
- 停止规则：序贯 e-value 达阈值，或达最大样本量 `n_max`；两种都如实上报。

**评测矩阵（预注册验收阈值，非真实结果）**：

| 指标 | 基线 CADVS（朴素融合） | v30（SECA+DAFG+FEC） | 验收阈值 |
|---|---|---|---|
| 任务成功率 LCB（α=0.05） | 点估计 0.91，LCB 0.84 | 点估计 0.90，LCB 0.86 | LCB ≥ 0.85 |
| 证书虚假通过率（共模注入 ρ=0.5） | 约 1.0×（基准） | 目标 ≤ 0.35× | ≤ 0.5× |
| 共模失效检出延迟 | 无显式机制 | < 200ms | < 300ms |
| 同步误差 P99 | 未监控 | < 1ms | < 1ms |
| `N_eff` 估计相对误差 | 未定义 | < 15% | < 20% |
| 恢复时间（隔离→恢复） | 无 | < 1.5s | < 2s |
| SRFC 间隙 `g_s` | 未量化 | < 0.15 | < 0.15 |

**仿真 dry-run（仅用于标定阈值，不作为结论）**：在 3 源（相机/IMU/轮速）等相关 ρ=0.5 的注入下，朴素融合的协方差比真实值低估约 2.0×；SECA 的 `N_eff` 从名义 3.0 降到约 1.5，触发 `N_min=2.0` 的降级。SPRT 在 p_alt=0.80 时平均约 70 个 episode 拒绝 H0，与引理 34 的 Wald 近似一致。**这些数字须在真机上以预注册协议复现后才可引用。**

## 7. 本轮最大风险（最终确认）

**一句话**：**共模失效下的「伪冗余」与真机评测的「统计操纵」会相互掩护——融合让系统在证书层面显得更可信，稀缺的真机样本又让这种虚高置信难以被检验揭穿，最终形成「越冗余越自信、越评测越通过、越部署越脆弱」的闭环**；而 SECA/FEC 只能把这一风险从「不可见」变为「可审计」，无法消除未知共模源与预注册污染带来的残余风险。
