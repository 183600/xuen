# 第 11 轮（新灵感循环第 2 轮；本轮灵感：「通信延迟」×「力矩传感」）

> **基线**：第 10 轮 MetricVoiceGauge-STF-NRB-LS（定义 540–548；引理 87–91；实验 E571–E590）。
> 本轮纪律：**时序诚实 + 物理兜底**。两个灵感各拆掉 v10 的一处"隐式前提"：**时间前提**（"1 帧=20ms""freshness≤2s"都默认感知-计算-执行同步、通信无延迟；真实系统是分布式的、有时延、可被延迟注入攻击）与**证据前提**（v10 的显著/非显著二分全部来自同一外感受觉-学习模型通道；对抗纹理能让两类前提"相关地"同时失效）。必须保持 v10 铁律：新模块失效 ⇒ **等价**或**支配**（更保守）于 v10，禁止行为漂移。

## 0. 直觉与动机

**灵感 1（通信延迟 → 证书从"瞬时谓词"变成"带有效区间的时标证书"）**
直觉：v10 把安全论证写成"守卫在 1 帧（20ms）内触发"，但这个 20ms 只在**回路时延为 0** 时成立。真实链路有 D_s（曝光+检测+STF）、D_c（多机共享地图的网络单程）、D_p（块规划）、D_a（总线+伺服）。证书是在 t−D_s 的观测上算的，却在 t+D_p+D_a 才作用于世界——它从来不是"当前为真"，而是"在一段区间内为真"。**延迟不是噪声参数，是证书的一个坐标。** 核心创新：**时标证书（Timed Certificate, TC）**——Ĉ‡ 携带有效区间 [t_o, t_a]、延迟包络 D̂ 与认证上界 D_max；停车距离改为 d_stop(v;D)=vD+v²/(2a_max)+d_safe；中止点集在**含延迟的预测轨迹**上求。D̂>D_max 或命令龄期超限 ⇒ 证书作废 ⇒ K=1/安全停（P16）。配套**本地死手看门狗（Deadman）**：一枚不依赖网络与操作系统的硬件/RT 定时器，命令超过 D_max 未刷新即本地执行认证停驻剖面——这是对抗"延迟注入/分区/时钟欺骗"的唯一可靠机制，因为它的时钟不在被攻击的链路上。
第二层直觉：多机共享语义图时，消息不是"点值"而是"带龄期的区间"。**延迟老化信任（Delay-Aged Trust, DAT）**：地标信任随龄期单调变保守（ν⁺=min(1, ν̄+κ_a·a⁺)，a⁺ 含时钟偏斜上界），合并取 max（幂等交换结合单调 ⇒ 安全保守的 CRDT）。妙处：通信越差，ν⁺ 越快饱和到 1 ⇒ K_eff 自然收缩到 1——**延迟的退化路径恰好就是 v10 已有的保守路径，不需要新特例**。

**灵感 2（力矩传感 → 把"可检测性二分"从表征空间搬到物理空间，并界定后果）**
直觉：v10 最大风险是"分割面 τ_sem 是经验校准的，对抗纹理可让语义通道静默"。根子不在阈值，而在**两个前提共用一个通道**（检测嵌入 + 学习前向模型）：一旦表征被欺骗，显著/非显著会**相关地**一起错。力矩传感提供**本体感受**通道：关节力矩是机器人与世界真实交互的直接物理观测量（惯性、重力、接触、负载、摩擦），在因果上位于"语义解释"的下游、"物理后果"的上游。用**广义动量观测器**得到外部力矩残差 ρ_t≈τ_ext，它与"学习到的 F̂ 错在哪"高度相关，却只依赖**刚体项**（可标定），不依赖被欺骗的语义。
于是关键一步：**不承诺"检测到一切"，只承诺"漏检也有界"。** 即使语义与力矩双双漏检，只要 (a) 力/能量治理器把接触力 F≤F_max、功率 P≤P_max，(b) 时延包络 D̂≥D_true，则一次未被预测的接触所传递的能量被**无条件**界定：E_contact ≤ ½m_eff·v² + F_max·v·D + P_max·D ≤ E_limit。这是把安全目标从"预测所有障碍"（对抗感知下不可证）改成"界定任何未预测接触的后果"（物理可测）。力矩传感让后者可执行（力控/阻抗投影）；**通信延迟直接抬高这个界**（D 越大，同力度注入的能量越多）——两个灵感在此**咬合**：时延是后果界的乘子，力矩是后果界的限幅器。
附加收益：力矩残差可做**有界参数辨识（TIMI）**——负载/惯量变化正是 Δ_dom 要 20 帧才看见的域漂移；用集合成员辨识得到**认证参数盒 Θ**，β_τ=g(Θ,η_τ,D̂) 随盒收缩而收紧，并用投影+留出验证窗防投毒。

三者与 v10 咬合：时标证书管"信息何时还成立"，力矩残差管"物理错到什么程度、漏了会怎样"，二者共同把 Ĉ⁺ 升级为**物理-时序双证 Ĉ‡**。

## 1. 研究问题（轮次升级版）

- **Q1（时序诚实）**：当 D_s+D_c+D_p+D_a 可测但可抖动、可被延迟攻击时，如何给出一个"在有效区间内可消费"的时标证书，使含延迟的停车不变式在最坏 D_max 下仍可证成立，且延迟注入/分区下不发生 fail-open？
- **Q2（后果界定）**：力矩残差能否提供与语义通道**可论证部分独立**的物理见证，并在两通道同时漏检时仍把接触能量界定在 E_limit 内（**不依赖检测概率**）？
- **Q3（有据收紧且不投毒）**：如何用转矩残差做有界参数辨识，在不破坏证书保守性的前提下收紧 β，并防止"低慢"扰动把参数盒/残差基线慢慢"教会"？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 时标诚实律（Timing Honesty, TC）**
任何证书必须携带有效区间与延迟上界；禁止在 D̂>D_max 或命令龄期超限时消费证书；安全停驻必须由**本地时钟**看门狗兜底，其正确性不依赖通信。时延进入停车距离与后果界，而非被忽略。

**P17 后果先于检测律（Consequence-Before-Detection, IFG）**
安全论证不得只诉诸"检测到"；必须给出"漏检后果 ≤ E_limit"的物理界；该界由可测的力/能量治理与时延包络给出，且作为证书**合取项**，不是事后补丁。

**P18 通道独立性与有界自适应律（Channel Independence & Bounded Adaptation, TRM/TIMI）**
两通道共享的依赖（关节编码器、指令）必须显式声明并单独监控；自适应参数只许在**认证参数盒**内更新，且必须通过留出验证窗才可收缩 β；不得用点估计替代集合界。

## 3. 与基线的接口（如何退化）

- 力矩通道失效（饱和/卡死/丢帧/一致性检查失败）⇒ 丢弃 β_τ 与 E_contact 兜底 ⇒ **降速至 v_soft 并收紧 Δ_dom 门控**（对 v10 是**支配**：更保守，不是等价）；
- 延迟监测失效 ⇒ 取 D̂=D_max、K_eff≤2、死手看门狗照常（保守）；
- 通信分区 ⇒ 地标图冻结、龄期老化使 ν⁺→1 ⇒ K_eff→1（v10 Level-1 的自然结果，无需特例）；
- TIMI 失效/验证不通过 ⇒ 保持上一认证参数盒（等价 v10 的 β_STF）；
- STF/NRB/AC/ID/MW/v8 失效 ⇒ 完全沿用 v10 六级链（本层不改变其语义）。

## 4. 预期贡献

1. **时标证书 + 本地死手**：把"20ms 保障"从"假设零延迟"改成"含 D_max 的可证区间"，延迟注入/分区下无 fail-open（引理 92）；
2. **力矩残差物理见证**：与语义通道部分独立、1 个采样内响应（引理 93），并给出**不依赖检测概率**的接触后果界（引理 94）——正面回应 v10"对抗纹理下双前提相关失效"；
3. **延迟老化信任 + 有界参数辨识**：多机共享地图的安全保守合并（引理 95）、β 有据收紧且抗投毒（引理 96），并给出"时延-速度-力"三者的可交换预算（推论 97）；
4. **E591–E610** 覆盖延迟注入、对抗欺骗+力兜底、参数投毒、长跑漂移等。

## 5. 本轮最大风险

**一句话**：后果界的两根支柱——力矩噪声底 η_τ 与延迟上界 D_max——都是"标定/估计"出来的而非结构保证的；一个"低慢"攻击（亚噪声底机械扰动 + 恰在 D_max 内的延迟抖动）可以让两个见证同时静默地累积位置误差，而 TIMI 的集合盒又可能被缓慢投毒使 β_τ 在真模型漂移时反而收紧，于是"漏检也有界"的后果界是在**陈旧且误识别的模型**上求值——双通道的相关性恰好在它被设计来覆盖的区域里出现。

**新增定义 549（时延分解与延迟包络）** D_total=D_s+D_c+D_p+D_a；D̂(t)=滑动窗最大值 + 抖动分位修正；延迟违约 ⇔ D̂>D_max ∨ (t−stamp(cmd))>D_max。D_max 为部署期认证常数（E595），非在线估计。

**新增定义 550（时标证书）** Ĉ_t^‡=(payload(Ĉ_t⁺), t_o, t_a, D̂, D_max, eid)。usable(now) ⇔ now≤t_a+τ_slack ∧ D̂≤D_max ∧ h_τ 不降级判断已并入负载。**证书的每个证书合取项都必须在 [t_o,t_a] 内解释**；区间外不作任何保证（P16）。

**新增定义 551（延迟补偿停车与非中止点集）** d_stop(v;D)=vD+v²/(2a_max)+d_safe。中止点集 P*(ζ)={p : ∃ t'∈[t,t+D_total], d(p, obs(t'))≥d_stop(v(t');D̂)}；在含延迟的 F̂_q rollout 上求，而非用上一帧观测的瞬时值。

**新增定义 552（力矩残差见证）** 动量观测器：p=M(q)q̇；ṙ=K_O(p−p₀−∫(τ_m+C^T q̇−g+r)dt)。ρ_t=r 为外部力矩估计，收敛时间常数 1/K_O。健康位 h_τ=¬sat(τ_m)∧¬stuck(τ_m)∧consistent(dq)∧(编码器健康)。h_τ=0 ⇒ Level-1。注意：**只用刚体项 (M,C,g)，不调用 F̂_q 或语义嵌入**（独立性来源）。

**新增定义 553（力-能量治理与接触后果界）** 伺服层投影算子 Π_FE：τ_cmd↦argmin‖τ−τ_cmd‖² s.t. ‖J^{−T}τ‖_n≤F_max, |(J^{−T}τ)·q̇|≤P_max。漏检接触后果界 E_contact(v,D)=½m_eff v²+F_max v D+P_max D。证书要求 E_contact(v_cert, D̂)≤E_limit。

**新增定义 554（延迟老化区间信任）** 对地标 ℓ 的更新 (ν̄_ℓ,t_ℓ) 在本地时刻 t 的保守龄期 a⁺=(t−t_ℓ)+ε_clk；ν⁺_ℓ=min(1, ν̄_ℓ+κ_a·a⁺)，ν⁻_ℓ=max(0, ν̄_ℓ−κ_a·a⁺)。场 T⁺ 用 ν⁺。合并 ⊔：ν⁺←max、ν⁻←min、t←max、eid 取并。安全判定**只用上界**。

**新增定义 555（物理-时序双证）** Ĉ‡ valid ⇔ ĝ_min≥d_safe ∧ ê_max≤τ_eff ∧ γ̂_grasp valid ∧ n_t 通过 ∧ U_t^sem ∧ **D̂≤D_max** ∧ **E_contact(v_cert,D̂)≤E_limit** ∧ **h_τ=1**。任一合取项失败 ⇒ K=1 或安全停（按定义 557 的优先级）。

**新增定义 556（七检守卫）** 50Hz 中块守卫（全 O(k+n)，k≤8 近邻地标，n 关节数）：(0) 时标可用性；(1) v9 证书有效性；(2) v9 停车不变式（距离换成 d_stop(v;D̂)）；(3) STF 语义创新度；(4) NRB 快规范；(5) 力矩残差 ‖w‖≤W_cert 且 h_τ=1；(6) 能量/延迟预检 E_contact(v;D̂)≤E_limit。任失败 ⇒ 最近中止点或 safe-stop。总预算 ≤0.6ms。

**新增定义 557（中止优先级）** 若失败项 ∈ {0,6} ⇒ 立即 safe-stop（时序/后果已不可信，不再追求任务）；若 ∈ {1,2,5} ⇒ 最近中止点 p*（可达性由 551 保证）；若 ∈ {3,4} ⇒ p* 或 v10 路径。优先级保证"越接近不可逆（接触/过期）越走停驻"。

**新增定义 558（本地死手看门狗）** 独立 RT 线程/硬件定时器，周期 1kHz，读本地单调时钟。若 now−stamp(last_cmd)>D_max ⇒ 输出认证停驻剖面（与网络、OS 调度、上层进程无关）。看门狗自身的认证：其时钟漂移 ≤ε_clk 且其停驻剖面已在部署期验证（E597）。

**新增定义 559（时延溯源台账）** EthicsLedger 记录扩展为 H(prev‖t_o‖t_a‖D̂‖eid‖logical_clock‖verdict‖repair‖utterance)；逻辑时钟用 Lamport 计数防跨机时钟回拨；审计复现以 (t_o,eid) 为主键。

# IP-361 TimedCertificate：时标证书
class TimedCertificate:
    def __init__(self, inner, t_obs, t_apply, D_hat, D_max, eid):
        self.inner, self.t_obs, self.t_apply = inner, t_obs, t_apply
        self.D_hat, self.D_max, self.eid = D_hat, D_max, eid
    def usable(self, now, tau_slack=0.0):
        return (now <= self.t_apply + tau_slack
                and self.D_hat <= self.D_max)


# IP-364 TorqueResidualMonitor：广义动量观测器（仅刚体项）
class TorqueResidualMonitor:
    def __init__(self, rigid, K_O=30.0, eta_tau=0.5, eps=1e-6):
        self.M, self.C, self.g = rigid.M, rigid.C, rigid.g   # 标定刚体模型
        self.K_O, self.eta_tau = K_O, eta_tau
        self.r = np.zeros(rigid.n); self.integ = np.zeros(rigid.n)
        self.p_prev = None; self.stuck_cnt = 0
    def step(self, q, dq, tau_m, dt, enc_ok=True):
        p = self.M(q) @ dq
        if self.p_prev is None: self.p_prev = p
        self.integ += (tau_m + self.C(q, dq).T @ dq - self.g(q)
                       + self.r) * dt
        self.r = self.K_O * (p - self.p_prev - self.integ)
        w = damped_pinv_T(self.jacobian(q)) @ self.r       # 关节→笛卡尔
        h = (enc_ok and not self.saturated(tau_m)
             and not self.is_stuck(tau_m) and self.consistent(dq))
        self.p_prev = p
        return Residual(r_joint=self.r, w=w, W=norm(w),
                        eta=self.eta_tau, h_tau=h)


# IP-365 InteractionForceGovernor：伺服层力/能量投影（1kHz）
class InteractionForceGovernor:
    def __init__(self, F_max, P_max, eps_g=1e-3):
        self.F_max, self.P_max, self.eps_g = F_max, P_max, eps_g
    def enforce(self, tau_cmd, q, dq):
        w = damped_pinv_T(self.jacobian(q)) @ tau_cmd
        # 法向力与功率双投影；超限则按比例回缩（保持方向）
        scale = min(1.0, self.F_max / max(norm_n(w), 1e-9),
                     self.P_max / max(abs(dot(w, ee_vel(q, dq))), 1e-9))
        return scale * tau_cmd


# IP-366 TorqueInformedIdentifier：集合成员参数盒（1Hz）
class TorqueInformedIdentifier:
    def __init__(self, theta_box, eta_tau, feasible_box):
        self.box, self.eta_tau, self.feasible = theta_box, eta_tau, feasible_box
        self.holdout = RingBuffer(200)
    def update(self, q, dq, ddq, tau_m):
        Y = regressor(q, dq, ddq)                       # τ = Y(q)θ
        box_new = set_membership_intersect(self.box, Y, tau_m, self.eta_tau)
        box_new = intersect(box_new, self.feasible)      # 投影：有界
        if self.validation_residual(box_new) < self.validation_residual(self.box):
            self.box = box_new                            # 仅验证窗改善才接受
        return self.box
    def beta_tau(self, D_hat):
        return bound_from_box(self.box, self.eta_tau, D_hat)  # 见引理 96


# IP-367 七检守卫（50Hz）
def midchunk_guard_tpt(chunk, k, obs, stf, nrb, trm, clock):
    cert = chunk.cert
    if not cert.usable(clock.now):                        # 检 0：时标
        return ('stop', None)
    if not cert.inner.cert_still_valid(obs):              # 检 1（v10）
        return ('abort', chunk.nearest_abort(k))
    if (obs.nearest_clearance - d_stop(obs.speed, cert.D_hat)
            - d_safe) < chunk.remaining_len(k):           # 检 2：含时延
        return ('abort', chunk.nearest_abort(k))
    if stf.surprise_near(obs.pose) > stf.tau_sem:         # 检 3（v10）
        return ('abort', chunk.nearest_abort(k))
    if nrb.fast_norms(obs).violated:                      # 检 4（v10）
        return ('abort', chunk.nearest_abort(k))
    res = trm.step(obs.q, obs.dq, obs.tau_m, obs.dt, obs.enc_ok)
    if (not res.h_tau) or res.W > cert.W_cert:            # 检 5：力矩见证
        return ('abort', chunk.nearest_abort(k))
    if E_contact(obs.speed, cert.D_hat) > cert.E_limit:   # 检 6：后果预付
        return ('stop', None)
    return ('continue', k + 1)

## 4. 推导

**引理 92（时标证书的区间可靠性与死手 fail-safe）**
假设 (D1) D̂≥D_true 以概率 ≥1−ε_D（E595）；(D2) 看门狗时钟独立于被攻击链路且龄期 >D_max 必触发（定义 558）；(D3) 中止点集在含 D 的预测轨迹上求（定义 551）。则在有效区间 [t_o,t_a] 内消费的 Ĉ‡，其停车不变式成立的概率 ≥1−ε_D；且在延迟注入/通信分区下不产生 fail-open。证明：v10 定义 534 的停车不变式只需把距离项换成 d_stop(v;D̂)，由 D̂≥D_true 与 a_max≤实测减速度使不等式单调收紧；看门狗触发路径不经过网络与上层进程，故延迟伪造/分区无法延迟其停驻。对比 v10：v10 隐含 D=0，D_true>0 时其"1 帧内"结论不成立。∎

**引理 93（力矩见证的响应性与通道独立性）**
(i) 对阶跃 τ_ext，观测器误差以 1/K_O 收敛；对带宽 ≪K_O 的持续扰动，稳态 ‖ρ−τ_ext^J‖≤η_τ（E592 标定）。(ii) 该残差只用到 (M,C,g) 与 (q,q̇,τ_m)，不调用语义嵌入或学习 F̂_q ⇒ 在"表征被欺骗而刚体/传感正常"的攻击面上，其失效事件与 STF 语义通道的失效事件不共享同一随机源（可加性论证）。(iii) **显式共享依赖**：两通道都依赖编码器 (q,q̇) 与指令 τ_cmd；该共享依赖若失效（编码器故障）则独立性声明不成立，故必须由 h_τ 的 enc_ok 与 v9 的传感器健康监控单独覆盖。∎

**引理 94（漏检后果界——不依赖检测概率）**
在治理器满足 F≤F_max、P≤P_max（伺服投影）且 D̂≥D_true 下，任一未被任何通道预测/检测的接触，其向环境传递的能量满足
E_contact ≤ ½ m_eff v_cert² + F_max v_cert D_total + P_max D_total。
若部署标定满足该式 ≤E_limit，则**无论两通道是否漏检**，接触严重度被界定。证明：接触瞬间可释放动能为 ½m_eff v_cert²；治理器使接触后法向力与功率有上界，接触持续至 T_rxn≤D_total+δ_g（死手/伺服兜底），对 F·v 积分取上确界即得。注：v_cert 由时标证书给出，D_total 由引理 92 界定——**这是"漏检"路径唯一的物理保证**。∎

**引理 95（延迟老化信任的保守单调性）**
(a) ν⁺ 对 a⁺ 单调不减（κ_a≥0）；(b) 合并 ⊔ 的分量 max/min 具有幂等、交换、结合、单调性 ⇒ 形成 join-semilattice，任意消息顺序/重复/迟到下收敛到同一保守上界；(c) 安全判定只用 ν⁺ ⇒ 中间态与最终态都不过度乐观。证明：逐条用 max/min 性质与 κ_a≥0；收敛性由有限地标集上的单调有界序列。∎

**引理 96（有界辨识的保守性与抗投毒）**
(a) 集合成员更新 Θ_{k+1}=Θ_k∩{θ:‖Y(q,q̇,q̈)θ−τ_m‖≤η_τ} 并投影到可行盒，只要每次测量误差 ≤η_τ，则真参数恒在 Θ_k 内 ⇒ β_τ=g(Θ_k) 始终是有效上界（保守）。(b) 采用"仅当留出验证窗残差下降才接受收缩"的门控：若投毒使 Θ 误缩，必须同时使**验证窗**残差下降；对时间上可分离的"低慢"投毒，验证窗（干净段）与投毒段不重叠，故单段投毒不能同时满足，β_τ 不会被投毒收缩——**该结论依赖"干净验证窗存在"的可检测性假设（E605/606 检验，非定理）**。(c) 投影保证 Θ 有界，避免自适应漂移导致证书失效。∎

**推论 97（时延-速度-力可交换预算）**
由 ∂E_contact/∂D>0、∂E_contact/∂F_max>0、∂E_contact/∂v>0，证书可行域
F_cert={(v,D,F): ½m_eff v²+F v D+P D≤E_limit, D≤D_max}
给出三者的可交换预算：延迟上升必须以 v 或 F 下降补偿。这是"通信延迟"与"力矩传感"写进**同一张证书**的形式表达，也是两灵感"咬合"的定义级落点。∎

## 8. 本轮最大风险

**一句话**：后果界的两根支柱——力矩噪声底 η_τ 与延迟上界 D_max——都是"标定/估计"出来的而非结构保证的；一个"低慢"攻击（亚噪声底机械扰动 + 恰在 D_max 内的延迟抖动）可以让两个见证同时静默地累积位置误差，而 TIMI 的集合盒又可能被缓慢投毒使 β_τ 在真模型漂移时反而收紧，于是"漏检也有界"的后果界是在**陈旧且误识别的模型**上求值——双通道的相关性恰好在它被设计来覆盖的区域里出现。
