## 1. 直觉解释

### 1.1 「商业模式」→ 得分经济学（Scoring Economics）

把参赛者想成一家公司：**得分是营收，延迟/算力是销货成本，可信度是信用评级，人为干扰是"退款/拒付"，已拿到的步骤分是现金流，重做是理赔，验证是保费。** 第一轮问"我能不能做这个任务"，本轮问"**哪一个边际动作值得买**"：多一次检查点、多一次重做、少堆一帧图像，都要有正的投入产出比。这样，v2 里一堆"看起来都该做"的机制被迫排优先级，不再是一份愿望清单。

更狠的一层：**Unitree 的四足业务模型是"硬件平台 + SDK + 垂直应用"**——底座被商品化，利润在应用层。对照本赛题：基础视觉-语言策略正在被开源基座商品化，**真正稀缺、且可自建的是"恢复数据 + 计分调度 + 部署可靠性"这一应用层**。所以本轮把"自研大世界模型"彻底移出投资组合。

### 1.2 「四足机器人」→ 分层恢复与接触调度

四足最成熟的不是"走路"，而是**被推一下不摔倒**：分层控制（规划/MPC/全身控制/力矩环）+ 推倒恢复（原地调整→迈步→保护性跌倒）+ 接触调度（哪只脚何时着地）。桌面操作面对的人为干扰在结构上**完全同构**：*被推一下，不要丢失已得进度*。差别只在：四足的恢复动作是连续的、毫秒级、有本体感知；操作的恢复动作是离散的（重抓/重对准/重新插入），观测只在**块边界**发生，且折叠/插入等接触**不可逆**。

这个差别本身就是结论：**既然块内不能反馈，就必须把"反射"下沉为合规控制与检查点设计，把"恢复决策"抬到块边界**。四足的分层速率给了我们一个严格的"反应周期"标尺。

## 2. 严谨定义

### 2.1 得分经济学（SEM）的决策模型

**定义 1（计分向量）**：任务 $j$ 有计分步权重 $w=(w_1,\dots,w_m)$，$\sum_i w_i=100$。设已完成的最长前缀为 $L$，则步骤分 $S_{\text{step}}=\sum_{i\le L} w_i$。若人扰把第 $r$ 步撤回，则 $L\to r-1$，**处于风险中的后缀分**为
$$\mathrm{VaR}(r)=\sum_{i=r}^{m} w_i.$$

**定义 2（介入与成本）**：在每个块边界可选动作 $a\in\{\text{continue},\text{checkpoint},\text{redo},\text{recover}_p,\text{safe-park}\}$。每个动作有**延迟成本** $c(a)$（往返 RTT + 计算 + 抖动）、**可信度风险** $\delta(a)$（动作规律性偏离/超时概率）。设每 episode 延迟预算 $B$。

**定义 3（边际价值）**：在步 $r$ 处加密检查点的期望收益为
$$\mathrm{MV}(r)=p_r\cdot q_r\cdot \mathrm{VaR}(r),$$
其中 $p_r=P(\text{第 }r\text{ 步被撤回}\mid\text{到达 }r)$，$q_r=P(\text{恢复成功}\mid\text{检测到})$。**只有当 $\mathrm{MV}(r) > \lambda\,c(r)$ 才值得做**，$\lambda$ 是延迟预算的影子价格（每毫秒的分值）。

**定义 4（预算配速）**：$\lambda$ 用对偶上升在线更新
$$\lambda_{t+1}=\lambda_t\cdot\exp\!\big(\eta\,(c_t-B/T)\big),$$
即广告投放里的 **budget pacing**：花超了就抬价（少检查），花少了就降价（多检查）。

**定义 5（稳健排序）**：榜单聚合函数 $f(S,P)$ 未公开。不假设它是线性的，而是对一族单调 $f$（含字典序与加权和）求**最坏情况**下的表现，输出 Pareto 前沿上的"膝点"策略——这是对"商业模式未知"的正式对冲。

> 这套模型把 v2 的启发式全部变成可算的量：什么时候该重做、块该多短、要不要保险，都归结为 $\mathrm{MV}(r)$ 与 $\lambda c$ 的比较。

### 2.2 进度可行性集与恢复原语（PVR）

**定义 6（混合阶段）**：一个任务是一个混合自动机，阶段 $\phi$ 携带活动接触集 $C_\phi$、目标物体轨迹与终止谓词。四足的"步态相位"在这里变成"操作接触相位"（抓取中 / 插入中 / 折叠中 / 搬运中）。

**定义 7（反应周期）**：接口只在块边界返回观测，故决策周期 $T_r=k\Delta t$（$k$ 为块长，$\Delta t$ 为控制步长）。**块内不存在反馈通道**。

**定义 8（进度可行性集）**：令 $x$ 为任务相关状态（物体位姿、抓取状态、已完成前缀 $L$），扰动 $w\in W$ 有界。定义 $k$ 时刻的可行性核
$$\mathcal V_k=\{x:\ \exists\ \text{容许恢复序列 } u_{k:m},\ \forall w\in W,\ \text{在剩余预算内到达成功}\}.$$
若鲁棒估计 $\hat x_k\notin\mathcal V_k$（或到边界的安全裕度不足），触发恢复。开环块下用**可达集**近似：若预测的块末状态集合与 $\mathcal V_k^c$ 相交，则**提前缩短块**（与 2.4 / UIP-13 联动）。

**定义 9（恢复阶梯）**：仿四足"原地→迈步→保护性跌倒"，定义代价递增的恢复原语
$$P_0\prec P_1\prec P_2\prec P_3\prec P_4$$
$P_0$ 合规/重跟踪（不重抓）；$P_1$ 退避重对准；$P_2$ 重抓/换手；$P_3$ 回访已得分步（仅当几何/顺序允许）；$P_4$ **safe-park**：放弃当前步、锁住前缀分、停到可观测静止位。
选择规则：$\arg\min_{P}\ \mathrm{cost}(P)$ s.t. 执行后 $\hat x\in\mathcal V_k$ 且不破坏前缀。**当所有 $P_{0..3}$ 都不划算时，$P_4$ 是止损，而不是失败**——这正是"商业模式"教给恢复的：知道何时止损，比盲目重做更能保住总分与可信度。

### 2.3 检查点块契约（CPC）

**定义 10（安全终止态）**：块末状态 $s$ 是检查点，当且仅当
1. 准静态（速度范数 $<\epsilon_v$）；
2. 抓取状态已知且可恢复；
3. 所有相关物体在已声明相机键内可见；
4. 无物体处于不稳定平衡；
5. 进度谓词可判定。

**定义 11（块契约）**：策略承诺每个返回块都终止在安全终态；调度器在生成块时**从长到短搜索**满足契约的 $k$。若无法满足，强制拆分/降速。**永远不要把块截断在插入中途、拉链半开或折叠半程。**

> 这是本轮最便宜的机制：不改模型、不改接口，只改"块在哪里结束"，就能把块边界的可恢复性从"碰运气"变成"契约"。

### 2.4 接口忠实神谕（IFO）

**定义 12（保真度阶梯）**：一个离线神谕对真机的忠实度分四层：① 消息/控制语义一致；② 接触/摩擦一致；③ 视觉/渲染一致；④ 任务分布一致。`unitree_mujoco`+`unitree_sdk2` 在①上最强（`unitree_hg` 与真机同族，四足已验证），Gazebo 在②③的资产生态更强，视频回放只有③。

**推论**：**用 `unitree_mujoco` 判"接口/顺序/恢复"（①），用 Gazebo 补"接触/视觉资产"（②③），两者都不当"像素级成败裁判"（④）。** 这直接修正了 v2 把 Gazebo 同时当几何与成败裁判的隐患。

## 4. 瓶颈假设 v3

- **H1（最高杠杆，承接）**：人扰会反向消耗步骤分，而公开数据零覆盖 ⇒ "检测撤回 + 最小成本恢复"是唯一同时救成功率与步骤分的机制。
- **H2（本轮新）**：块内无反馈 ⇒ 反应性上限由 $T_r=k\Delta t$ 决定；接触密集步必须靠**合规控制 + 检查点**，而不是靠"更聪明的块内策略"。
- **H3（本轮新）**：接触丰富的步骤（插网线/合盖/拉链/折叠）用"端到端关节回归"学不稳，需**接触显式调度 + 阻抗/力控**（四足 WBC 迁移）。
- **H4（本轮新）**：最大风险从"仿真过拟合"转为"**优化了错的货币**"——若榜单聚合/步骤分语义与模型不符，SEM 会把资源配错。
- **H5（本轮新）**：`unitree_mujoco` 的接口忠实度可验证、但需确认我们的动作空间到 `LowCmd` 的映射；若接口只收关节目标而我们是 ee，需要 IK，保真度降一层。

## 1. UIP-16 · SEM（得分经济学元控制器）

### 1.1 目标
把"要不要检查/重做/重抓"统一为一个带预算的期望得分最大化问题，并把未知的榜单聚合当成**稳健优化**而非点估计。

### 1.2 形式化
任务计分向量 $w=(w_1..w_m)$，$\sum w=100$；已完成前缀 $L$；若第 $r$ 步被撤回，风险后缀
$$\mathrm{VaR}(r)=\sum_{i\ge r} w_i.$$
介入 $a$ 的期望边际收益与成本：
$$\mathrm{MV}(a)=p_r\,q_a\,\mathrm{VaR}(r),\qquad \mathrm{cost}(a)=\lambda\,c(a)+\mu\,\delta(a).$$
选择
$$a^\*=\arg\max_{a}\ \mathrm{MV}(a)-\mathrm{cost}(a)\quad\text{s.t.}\quad \mathrm{CVaR}_{\alpha}(L)\le L_{\max},\ \ \textstyle\sum c(a)\le B.$$
其中 $\lambda$ 为延迟影子价格（分/ms），$\mu$ 为可信度影子价格，$c(a)$ 为 RTT+计算，$\delta(a)$ 为动作规律性/超时风险。

**预算配速（budget pacing，借自广告投放）**：
$$\lambda_{t+1}=\lambda_t\exp\!\big(\eta\,(c_t-B/T)\big),$$
花超→抬价→少介入；花少→降价→多介入。

**稳健聚合**：设 $f_\rho(S,P)=\rho S+(1-\rho)P/100$，$\rho\in[0,1]$ 未知；离线评估时报告 $\min_\rho$ 与 Pareto 膝点，若某策略只在单一 $\rho$ 下占优则判为"过拟合榜单"。

### 1.3 P&L 账本（可学习的定价器）
用 IFO 回放把每次介入记成一行流水：
`(task, r, action, p_r_hat, q_hat, VaR, latency_ms, outcome, delta_score)`
在线/离线估计 $\hat p_r,\hat q$，并拟合 $\lambda$。**这是把"研究直觉"变成"可审计会计"的关键**：没有账本，SEM 只是空想的效用函数。

### 1.4 伪代码
```python
class ScoringEconomy:
    def __init__(self, weights, budget_ms, alpha=0.9, Lmax=1500, eta=0.05):
        self.w = weights; self.B = budget_ms
        self.lam = 1e-3                     # points per ms
        self.alpha, self.Lmax, self.eta = alpha, Lmax, eta

    def var(self, r):                       # suffix points at risk
        return sum(self.w[r:])

    def mv(self, r, p, q, action):
        return p * q * self.var(r)

    def decide(self, r, p, q, c_ms, delta):
        # recover/redo only if it beats the shadow prices
        return self.mv(r, p, q, None) > self.lam * c_ms + self.mu * delta

    def pace(self, spent_ms, elapsed_frac):
        target = self.B * elapsed_frac
        self.lam *= math.exp(self.eta * (spent_ms - target) / self.B)
```

## 2. UIP-09″ · PVR（进度可行性恢复）

### 2.1 阶段与可行性
任务=混合自动机，阶段 $\phi$ 携带活动接触集 $C_\phi$ 与终止谓词。决策周期 $T_r=k\Delta t$。定义**进度可行性核**
$$\mathcal V_k=\{x:\exists u_{k:m},\ \forall w\in W,\ \text{在剩余预算内成功}\},$$
$x$=物体位姿+抓取状态+前缀长度。离线用 IFO 采样 $10^4$ 条"状态→恢复 rollout"标注，训练一个廉价分类器 $g(x)\approx P(\text{可从 }x\text{ 恢复})$；在线 $g(\hat x)<\tau$ 触发恢复。开环块内用**可达集近似**判断块末是否会掉出 $\mathcal V_k$。

### 2.2 恢复阶梯（四足"原地→迈步→保护性跌倒"的操作版）
| 原语 | 动作 | 典型成本 | 适用 |
|---|---|---|---|
| $P_0$ 合规/重跟踪 | 阻抗保持、微调跟踪 | 0–1 块 | 小滑移、小偏差 |
| $P_1$ 退避重对准 | 退回预接触位再进 | 1–2 块 | 插入偏斜、对孔失败 |
| $P_2$ 重抓/换手 | 松开重抓/换手 | 2–5 块 | 抓取退化、姿态翻转 |
| $P_3$ 回访已得分步 | 回退到前一步重做 | 高 | 仅当几何/顺序允许 |
| $P_4$ safe-park | 锁前缀分、停到安全位 | 低 | 恢复都不划算时止损 |

选择：
$$P^\*=\arg\min_{P}\ c(P)\ \text{s.t.}\ \hat x'\in\mathcal V_k,\ \text{PPC 成立};$$
若不存在可行且划算的 $P_{0..3}$，或 $q_P\,\mathrm{VaR}(r)\le \lambda(c_P-c_{P_4})$，则 **$P_4$**。

> 关键区别 vs v2：v2 检测到 `regressed` 就无脑重做；v3 先问"还能不能救、救的值不值"，把**止损**当作一等公民。

### 2.3 伪代码
```python
RECOVERY = [P0_comply, P1_reapproach, P2_regrasp, P3_revisit]

def pvr(obs, r, V, lam, econ):
    x = estimate_state(obs)                       # IFO-trained estimator
    if viability(x, V) > tau:                     # still healthy
        return "continue"
    best = None
    for P in RECOVERY:
        x2, c = P.predict(x)
        if viability(x2, V) > tau and prefix_preserved(x2, r):
            gain = econ.p_hat(r) * P.q * econ.var(r)
            if gain > lam * c and (best is None or c < best.c):
                best = (P, c)
    return best[0] if best else P4_safe_park
```

## 3. UIP-18 · CPC（检查点块契约）

### 3.1 契约
策略承诺：**每个返回块都终止在安全可观测态**（速度≈0、抓取状态已知、物体全可见、无不稳定平衡、进度谓词可判定）。若一刀切不死，就**缩短块**直到满足；这是"把可控性买回来"的最便宜方式。

```python
SAFE = lambda s: (s.vel_norm < EPS_V and s.grasp_known and s.objs_visible
                  and s.no_unstable_eq and s.progress_decidable)

def make_chunk(policy, obs, k_max, k_min=1):
    for k in range(k_max, k_min-1, -1):
        A = policy.forward(obs, k)
        s_end = light_rollout(obs, A)      # 低成本前向模型 or IFO 缓存
        if SAFE(s_end):
            return A
    return decelerate_and_park(obs)        # 最后的安全兜底
```

### 3.2 为什么值得
接口在块内不可打断，**块边界是唯一救生口**。把块截在"拉链半开/插头半插/毛巾半折"等于把不可逆坏状态交给下一次调用。CPC 把这种坏边界从"概率事件"变成"违反契约"。代价是更多块/更高 RTT，因此由 SEM 的 $\lambda$ 决定是否值得（不是永远越短越好）。

## 4. UIP-11′ · IFO（接口忠实神谕）

### 4.1 结构
```
policy.get_action(obs_chunk)
        │  (joint targets or ee poses)
        ▼
   action adapter  ──►  LowCmd (G1: unitree_hg)  ──►  unitree_mujoco
```

## 5. 旗舰整合：EC-RHPV（UIP-01″）

```python
class ECRHPV:
    def __init__(self, policy, ifo, econ, viability, k_max=8, tau=0.6):
        ...
    def reset(self):
        self.g = 0; self.L = 0; self.spent = 0; self.buf = []
    def get_action(self, obs):
        # 1) 只在块边界做决策（接口事实）
        if not self.buf:
            # 2) PVR: 先判断进度是否仍可行
            action = pvr(obs, self.L, self.viability, self.econ.lam, self.econ)
            if action == P4_safe_park:
                return safe_park_chunk(obs)
            if action != "continue":
                obs = self._goto_recovery(action, obs)
            # 3) SEM: 选择检查点密度 + CPC: 保证安全终止
            k = self._pick_k(obs)                    # UIP-13 RPS ∩ UIP-16
            self.buf = list(make_chunk(self.policy, obs, k))   # UIP-18
            # 4) PPC: 拒绝会扰动已得分前缀的块
            self.buf = ppc_filter(self.buf, self.L, obs)
        self.spent += self.econ.rt_ms
        self.econ.pace(self.spent, self._elapsed_frac())
        return self.buf.pop(0)
    def _pick_k(self, obs):
        # 反应周期 + 经济性：接触密集→小 k；搬运→大 k
        phase = self._phase(obs)
        k = phase.k_star
        while k > 1 and not self.econ.should_pay_for_checkpoint(k):
            k -= 1
        return k
```

## 6. UIP-17 · WBC-CS（接触调度全身控制）

- **机制**：阶段 $\phi$ 给出活动接触集 $C_\phi$ 与物体目标轨迹；解一个小型 QP 生成块内关节目标：
$$\min_{\ddot q}\ \|J\ddot q+\dot J\dot q-a^\*\|^2+w_\tau\|\tau\|^2$$
$$\text{s.t. } J_c\ddot q+\dot J_c\dot q=0\ (c\in C_\phi),\ \ \tau\in[\tau_{\min},\tau_{\max}],\ \ \text{摩擦锥}.$$
输出带阻抗 $K_p,K_d$ 的关节位置序列；块末由 CPC 强制准静态。
- **为何用四足经验**：四足 WBC 早已把"接触集切换"做成稳定工程；桌面插入/拉链/折叠就是接触集频繁切换的混合系统。
- **可行性**：⚠️ 取决于 metadata 动作空间。关节目标→可直接；ee→需 IK；若评测端只接受其自身低层控制器，则退化为"生成更平滑的关节轨迹"。
- **风险**：QP 在推理期可能拖延迟 ⇒ 离线预计算接触阶段轨迹 + 在线只做小幅修正；否则只对最难 5–8 个任务启用。

## 7. UIP-13″ · RPS（反应周期调度）

块长即反应周期 $T_r=k\Delta t$。按阶段设上下限，再由 SEM 定价：
$$k^\*=\arg\max_k\ \mathbb E[\text{score}\mid k]-\lambda\,\frac{\mathrm{RTT}}{k\Delta t}.$$
直觉上与库存 **EOQ** 同构：每次调用是"订货成本"（RTT），块太长是"持有/迟钝成本"。搬运/大位移→大 $k$；插入/合盖/拉链/折叠→小 $k$。**但要服从 CPC**：宁可多一次调用，也不要把块截在坏状态。

## 8. UIP-08″ · QDS（四足级部署栈）

从四足控制回路的工程习惯借 7 条：
1. **单写者/端口**：每端口独立状态机与缓冲，绝不共享可变状态。
2. **看门狗**：策略超时→返回最近的安全保持块（且满足 CPC），而非崩溃或乱序。
3. **有界队列 + 背压**：积压超阈值即降级（减堆叠帧/降分辨率/减 k）。
4. **确定性时序**：固定控制循环、预分配缓冲、热路径无 GC。
5. **限幅与状态校验**：动作形状/dtype/范围/NaN 在出口统一校验。
6. **健康与指标**：p50/p99 延迟、抖动、队列深度、超时率可观测。
7. **可复现**：固定种子，便于离线复现线上事故。

## 9. UIP-14′ · SMP（技能模块组合）

- 把 32 任务压缩为约 8 个技能（抓/放/插/倒/拉链/折叠/堆叠/分拣/开合/挑取），**共享骨干 + 轻量技能头/适配器**，满足单模型合规。
- 用"范围经济"度量复用价值：$E=1-\frac{\text{联合训练成本}}{\sum\text{独立训练成本}}$；按每个技能头的**边际得分/显存**排序，砍掉长期低利用率的头。
- **本轮降级理由**：v2 的 15 个技能太碎，路由与显存成本超过收益；先做 6–8 个、可回退到通用头。

## 10. UIP-02″ · PPC（前缀保护约束）

**任何恢复/重抓/重做动作都不得使已完成的前缀步失效。** 形式化为可行性过滤：动作 $a$ 仅在
$$\text{prefix}(x,a)\ge L\quad\text{且}\quad \text{disturb}(a,\{1..L\})=0$$
时允许。这防止"为了救第 5 步，把第 1–4 步碰倒"的负收益恢复；也是 $P_4$ 止损的理论依据。

## 11. UIP-12′ · DRF（扰动-恢复-接触调度数据工厂）

- 每条样本记录 `(阶段 φ, 接触集 C_φ, 干扰类型, 撤回步 r, 恢复原语, 结果)`；既训 `g(x)` 可行性分类器，也训恢复策略。

## 14. 合规与风险

- **单模型**：共享骨干；验证器优先几何/规则或骨干蒸馏小头；外部 VLM 可能被判"非单模型"。
- **接口红线**：块形状/dtype/块长/索引严格按 README；返回块长与声明不一致、动作统计异常都会伤可信度。
- **仿真的角色**：IFO/Gazebo 只做结构/顺序/恢复裁判，不做像素级成败裁判。
- **定价风险**：$f(S,P)$、$p_r$、$q$ 都可能估错；SEM 必须带稳健性与 kill criteria，不能把仿真账本当真实营收。
- **手册缺口**：位置/干扰物/背景三轴与评测轮次/时限/控制频率仍需飞书手册公开后核实。
