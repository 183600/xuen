# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「开源软件」×「创新点」）

> R69 让系统学会了「问」，并诚实地承认：它的效率全押在「流模型的模态分布可信」上。但这句话暴露了一个更深的结构性事实——**七十轮下来，我们的系统已经长成了一个由几十个学习模块组成的依赖图**：trunk、流策略、mode_head、COF 标定、VoI 控制器、CIA、FMA、审计器……每一层都来自不同轮次、不同数据、不同假设，却要在一个实时环路里共同对安全负责。R69 的最大风险（模态权重未校准 → 自信地追问幻影 / 给误导回答盖章）本质上不是"某个模块不够好"，而是**我们无法证明这个组合还是我们以为的那个组合**。
>
> 「开源软件」给出了一个反直觉的答案：开源生态能信任一个由无数陌生人写的、深度嵌套的代码库，**不是靠相信作者，而是靠让每个产物都可追溯、可复现、可回滚，并让每次合并都必须通过累积测试**。信任从"作者信誉"迁移到"过程可验证"。
>
> 「创新点」则给出另一个刺痛的问题：我们每轮都声称 IP-xxx 是"创新"，但**创新点到底是什么**？在开源语境里，一个有价值的贡献不是"我加了一个文件"，而是一个**最小的、可复现的、能杀死基线的 diff**——它必须带测试、可被独立重建、且移除后能力确实下降。用这个标准回看七十轮，很多 IP 可能只是"通过了我们想得到的测试"，而非真正贡献了能力。
>
> 核心命题：**R70 不再加一个能力层，而是给整座累积栈加一层"认证外壳"——把每个模块变成带 provenance 的包、把每个决策变成可复现的重放、把每次升级变成语义化版本迁移、把每个"创新点"变成可被基线杀死的差分、把"不确定"新增一条无需标签的分叉分歧通道；一旦外壳发现栈已不是被认证的那个栈，就回滚到已知良好快照，而不是继续减速。** 命名 **FORGE-RAS**（Forkable, Observable, Reproducible, Gated Evolution for Risk-adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这个决策能重建吗、谁为它背书、出事了能退回哪**」——安全不再只是"更慢"，也可以是一次可验证的构建、一次诚实的回滚。

## 0. 直觉与动机

**灵感 1（开源软件 → 信任来自可复现，而非作者）**
直觉：我们的机器人策略几乎必然是"开源式"的：主干来自预训练大模型，控制器来自某轮论文，标定来自另一批数据，连"安全包络"都是人写的假设。要求每个部件都正确不现实；开源软件的做法是**不要求每行都对，而要求每个二进制都能从源码重建、每个依赖都被钉死、每个变更都可 bisect**。机器人版就是：每个模块有行为物料清单（BBOM），每个决策可用"输入+版本+种子"重放，任何"同版本不同行为"都被行为指纹抓住。**可复现性是审计的前提，审计是信任的前提。**

**灵感 2（分叉 fork → 一条不需要标签的错误检测通道）**
直觉：R69 的模态可信度只能靠"校准"来估计，而校准本身可能错（这正是它的最大风险）。开源/容错计算的经典答案是 **N-version programming + differential testing**：让两个**来源不同**的实现并行，它们的分歧就是一个不需要 ground truth 的错误信号。把"来源不同"从代码换成 **provenance 多样**（不同数据种子、架构、训练配方，同一接口与包络）的两个策略分叉，则 `U_fork = W_p(π_A, π_B)` 直接度量"这件事到底有多确定"。**单模型的置信度是自评，双分叉的分歧是第三方证词。**

**灵感 3（语义化版本 semver → 行为升级必须分类）**
直觉：开源最贵的教训之一是"悄悄升级一个 patch 版本，行为却变了"。机器人栈更糟：重标定、微调、换量化精度都会改变行为，却没有版本记录。于是 R69 的"缓变故障被标定吸收"有了精确的供应链解释——**未记录的漂移就是一次未经审查的推送**。定义 patch/minor/major 三级：patch 只许在 ε 内抖动、minor 必须通过全部累积回归、major 必须重新认证且禁止运行时自动升级；运行时钉死版本向量，"浮动依赖"在安全关键栈里是禁止的。

**灵感 4（创新点 → 可被基线杀死的差分，而不是一句声称）**
直觉：研究里"创新点"常被当成叙事单位，而不是可检验对象。开源给了它一个硬标准：一个 patch 若不能通过 CI、不能复现、删掉它测试也不变，它就不该被合并。于是定义 **IP = (Δ, T, P)**：最小行为差分 Δ、含判别测试的测试集 T、完整 provenance P；**可采纳 ⇔ 判别测试在基线上失败、在新栈上通过，且去掉 Δ 的任一 hunk 判别测试就失败**（最小性 = 可归因）。再加一条消融账本：若移除某 IP 后性能不降，它就是"冗余创新点"。这把"创新"从修辞变成**可证伪的因果贡献**。

**灵感 5（供应链攻击 → 正面回应 R69 的投毒与标定吸收）**
直觉：开源最大的现实威胁不是代码烂，而是**供应链**：typosquatting、依赖混淆、恶意更新、被污染的构建产物。R69 的威胁（人类撒谎、幻影模态、标定吸收缓变故障）在结构上同构：都是"看起来是可信来源的东西，行为却不是它声称的那样"。R70 用三件事回应：装载时**行为指纹**（同版本必须同行为）、运行时**未授权漂移检测**（走了版本流程才算合法变更）、以及**认证回滚**（回到上一个被完整认证的栈快照，而不是只把 λ 调大）。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（FORGE-RAS 总览）** FORGE-RAS = (PPM, RDP, BVM, RGT, IPL, DFF, SCA, CRB, RAS-WM§)。四条不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **依赖闭包认证**：任何模块进入运行时栈，其全部传递依赖必须有有效 PPM 与未过期证书；任一缺失即拒绝装载并退回钉死的已知良好快照；
(iii) **可复现性**：每个决策必须能由 (日志输入, 钉死版本向量, 采样种子/数值模式) 重放到 ε_rep 内，否则该决策证书作废；
(iv) **安全单调**：任何被采纳的 IP 不得降低已认证安全包络，且必须通过累积回归集 RGT。

**定义 311（行为物料清单 PPM / BBOM）** 对模块 m：
PPM(m) = (h_artifact, h_data, h_cal, iface, Ω_m, fail_m, deps, sigs, ver)。
iface 为接口契约（输入/输出域、单位、时序延迟、前提条件）；Ω_m 为认证工况集（观测分布、速度/力矩/温度范围）；fail_m 为已知失效模式；deps 为依赖及其版本约束；sigs 为训练者/审阅者签名。**BBOM** = 根模块的传递闭包 DAG {PPM(m)}；BBOM 必须无版本冲突且签名全部可验。

**定义 312（可复现决策路径 RDP）** 决策日志 L_t = (o_t, seed_t, v_t, cal_state, interaction_log)，其中 v_t 为版本向量。重放 ξ̂ = Replay(L_t; v_t)。复现散度 D_rep = d(ξ̂, ξ_log)/scale。决策可复现 ⇔ D_rep ≤ ε_rep。流采样必须记录基础噪声 x_0（或等价种子）与 ODE 步数/精度，使"采样"在重放下成为确定性函数——这是"可复现构建"在决策层的同构：源码 = 输入+版本+种子，二进制 = 决策。

**定义 313（行为语义化版本 BVM）** 版本 ver = major.minor.patch，变更分类器 Class(Δ)：
- **patch**：仅标定/数值精度变化，要求 ∀s∈Ω，行为距离 d(π_new, π_old) ≤ ε_patch 且 RGT_patch 通过；
- **minor**：新增能力，要求 iface 不变、Ω 不缩小、RGT_cum 全通过；
- **major**：接口或包络改变，必须重认证、重新签发 PPM，且**运行时禁止自动升级**。
运行时钉死 v_t：major 不可变、minor 仅在白名单、patch 自动但每次需过 RGT_patch。**浮动依赖在安全关键栈中不被允许。**

**定义 314（累积回归测试集 RGT）** RGT = ⋃_{rounds≤r} T_i，三层：**safety**（必须零违规）、**capability**（≥ 历史最优 − ε_cap）、**regression**（旧能力不回退）。每个 IP 必须贡献"判别测试"与"保持测试"；RGT 是运行时可否采纳新 IP 的唯一门槛。RGT 的覆盖度而非体量决定保证强度（见引理 21 与第 6 节）。

**定义 315（创新点作为已验证差分 IP = (Δ, T, P)）** 相对基线 b 的 IP：Δ 为最小行为差分；T = RGT_b ∪ {t_disc}；P 为 provenance。**Admissible** ⇔
(a) T 全通过；
(b) t_disc 在 b 上失败、在 b⊕Δ 上通过（判别性，非空洞）；
(c) Δ 最小：去掉任一 hunk 后 t_disc 失败（**最小性 = 可归因性**）；
(d) P 完整可验；
(e) Ω(b⊕Δ) ⊇ Ω(b)（安全包络不缩小）；
(f) t_disc 对语义保持变换不变（抗"应试"/Goodhart 的第一道闸）。
**创新点从"声称"变为"可被基线杀死的差分"。**

**定义 316（双分叉差分测试 DFF）** 维护 ≥2 个 **provenance 多样**的分叉 π_A, π_B（不同数据种子/架构/训练配方，同一 iface 与 Ω）。分歧 U_fork = W_p(π_A(·|o), π_B(·|o))（动作分布 p-Wasserstein）或模态身份不一致率。门限：U_fork ≤ τ_agree ⇒ 一致执行；τ_agree < U_fork ≤ τ_trip ⇒ 降级（保守 + 可选 R69 交互）；U_fork > τ_trip ⇒ 拒绝执行并进入 CRB。要点：U_fork **不需要标签**，它测的是"独立来源是否同意"，而非"模型自信不自信"。

**定义 317（供应链证明 SCA）** 装载/周期校验：(1) artifact 哈希与签名；(2) **行为指纹**——在固定探针集 𝒫 上运行模块得到 fp，必须与 PPM 注册值一致（抓"同版本不同行为"的权重偷换）；(3) 依赖闭包无冲突、无 typosquatting（接口相似但 provenance 不同者标记）；(4) 标定集哈希与 COF 实际使用的一致。任一失败 ⇒ 拒绝装载。

**定义 318（认证回滚 CRB）** 维护已知良好栈快照 {σ_j}：每个 σ_j = (版本向量, 标定状态, 证书, Ω_σ)。当 U_fork 超阈、D_rep 超阈、SCA 失败或 J_FORGE 失效 ⇒ 回滚到最近 σ_j 并记录触发原因。回滚是**行为空间的 git checkout**：恢复到一个曾被完整认证的状态，而非仅仅减速。回滚可行性要求当前状态 s_t ∈ Ω_{σ_j}；否则退化为失败安全（fail-safe）。

**定义 319（组合证书 J_FORGE）** J_FORGE = (J_FLUID, h_BBOM, v_t, D_rep, RGT_pass, U_fork, SCA_ok, rollback_target, forge_ver)。Valid ⇔ Valid(J_FLUID) ∧ BBOM 完整 ∧ D_rep ≤ ε_rep ∧ RGT 全通过 ∧ SCA_ok ∧ (U_fork ≤ τ_agree ∨ 已回滚/降级)。

**定义 320（组合信任偏序与包络交）** 组合认证包络 Ω_comp = ⋂_{m∈BBOM} Ω_m（并须满足所有 iface 契约）。Ω_comp 为空 ⇒ 组合不可认证（**"许可证不兼容"的机器人版**）。组合安全下界 s(comp) ≥ min_{m} s(m)（短板），差分与回归只能改善"错误采纳"界，不能凭空提高单模块安全。

**定义 321（漂移与比特腐烂）** 行为漂移 δ_m(t) = d(π_m(t), π_m(t_0)) 在探针集上的度量。若 δ_m 超过 ε_patch 却未走 BVM 流程记录 ⇒ **未授权漂移**，SCA 行为指纹判失败。这是 R69"标定吸收缓变故障"的供应链表述：**没有版本记录的漂移，等于一次未经审查的推送。**

**定义 322（创新点消融账本）** 对每个已采纳 IP_i 维护因果贡献 c_i = Perf(full) − Perf(full ⊖ IP_i)（在 RGT 上）。若 c_i ≤ 0 且其测试仍通过 ⇒ 标记 **冗余创新点**（novelty without contribution），进入清理候选。IP 数量不是指标，**可证因果贡献**才是。

**定义 323（分叉采纳与合并协议）** 候选分叉 π_C 合并进主栈：shadow 评估 → RGT_cum → 与主分叉差分 → 安全场景一致且能力场景更优 ⇒ 合并；否则仅作 shadow，不进入运行时。这是 **PR + CI + review** 的机器人版；合并的最小单元仍是定义 315 的 IP。

**定义 324（威胁模型 ℰ_FORGE）** ℰ_FORGE = ℰ_FLUID × ℰ_supply × ℰ_fork。ℰ_supply = {权重偷换, 同版本行为偷换, 依赖混淆/typosquatting, 未授权漂移, 回滚快照投毒}；ℰ_fork = {共模故障（分叉同源）, 分叉共谋, 分叉同步退化}。

**定义 325（退化包含性）** 当 (i) 全部模块 provenance 完整且 δ_m = 0，(ii) D_rep = 0，(iii) 只运行单分叉（U_fork 不参与决策），(iv) 无回滚触发 ⇒ FORGE 逐指令等于 FLUID（R69）；再令 VoI ≤ 成本 ⇒ 等于 CALM（R68）。故 **R68 ⊂ R69 ⊂ R70**，安全侧单调不减。

**定义 326（开放治理与审计账本）** 审计对象新增：BBOM 变更、版本迁移、回滚事件、IP 消融账。账本 append-only、可由独立第三方重放验证。**"开源"的实质不是公开代码，而是公开可验证的 provenance 与测试**——同样的标准适用于机器人策略。

## 2. 关键算法骨架

```python
# IP-264 PPM / BBOM：行为物料清单（依赖闭包 + 包络交）
@dataclass
class PPM:
    h_artifact: str; h_data: str; h_cal: str
    iface: Interface; envelope: Envelope; fail: list
    deps: dict; sigs: list; ver: tuple

def build_bbom(root):
    dag = transitive_closure(root, key=lambda m: m.deps)
    for m in dag:
        assert verify_sigs(m.sigs) and pins_satisfied(m, dag)
    omega = intersect(m.envelope for m in dag)
    if omega.is_empty(): raise Uncertifiable(root)     # 定义 320
    return BBOM(dag, omega, hash_manifest(dag))

# IP-265 RDP：可复现决策（记录噪声/种子/版本，重放必须一致）
def replay_and_check(log, stack):
    xi_hat = replay(log.obs, log.seed, stack.pinned_versions, log.cal_state)
    return behavior_distance(xi_hat, log.xi) <= EPS_REP

# IP-266 BVM：行为语义化版本（patch / minor / major）
def classify_change(delta, old, new):
    if not iface_equal(old.iface, new.iface):           return "major"
    if delta.shrinks_envelope() or not rgt_cum.pass_(new): return "major"
    if max_shift(old, new, PROBES) <= EPS_PATCH:        return "patch"
    return "minor"

# IP-267/268 RGT + IPL：创新点 = 可被基线杀死的、最小的差分
def admissible_ip(delta, baseline, cand, tests, prov):
    d = tests.discriminating
    return (d.fails_on(baseline) and d.passes_on(cand)       # 判别性
            and tests.regression.all_pass(cand)              # 不回退
            and delta.is_minimal(d)                          # 可归因
            and d.invariant_under(SEMANTIC_PRESERVING)       # 抗应试
            and prov.verifiable() and envelope(cand) >= envelope(baseline))

# IP-269 DFF：provenance 多样的双分叉作为无标签错误检测
def differential_gate(forkA, forkB, o):
    u = wasserstein(forkA.sample(o), forkB.sample(o))
    if u <= TAU_AGREE: return "execute", u
    if u <= TAU_TRIP:  return "degrade", u        # 保守 + 可选 R69 交互
    return "rollback", u                          # 交给 CRB

# IP-270 SCA：供应链证明（同版本必须同行为）
def attest(module, probes):
    if sha(module.weights) != module.PPM.h_artifact:  return False
    if distance(run_probes(module, probes),
                module.PPM.registered_fp) > EPS_FP:   return False  # 行为偷换
    if dependency_confusion(module.deps):             return False
    return True

# IP-275 主闭环（R68 计量 + R69 消歧 + R70 认证外壳）
def FORGE_RAS_round(M, obs):
    if not M.sca.all_attested(): return M.crb.rollback_or_failsafe("supply")
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)    # R68
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4                 # R69
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, K), z)
    verdict, u_fork = M.dff.differential_gate(M.forkA, M.forkB, o) # R70
    if verdict == "rollback": return M.crb.rollback_or_failsafe("fork")
    g = M.mint.choose_interaction(modes, o, M.budget) if U_epi > TAU_EPI else None
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))          # R68/R69
    if verdict == "degrade": lam = max(lam, LAM_DEGRADE)          # 分叉分歧
    xi = M.select_mode(modes, U_epi, lam)
    k  = M.c_ras_wm.certified_prefix(xi.a[:M.vista.H], ..., wm_preds)
    if not M.rdp.replay_ok(M.last_log):                           # 可复现性
        return M.crb.rollback_or_failsafe("replay")
    M.audit_p.submit(h_BBOM=M.stack.bbom_hash, v=M.stack.version_vector,
                     d_rep=M.last_d_rep, u_fork=u_fork, verdict=verdict)
    return k, lam, xi, J_FORGE(M.cert, M.stack, M.last_d_rep, u_fork, verdict)
```

## 3. 推导

**引理 19（未授权漂移的探针可检出性）** 设探针集 𝒫 中 n 个独立样本，漂移使行为分布相对注册指纹的 KL 散度 ≥ δ。则行为指纹检验的漏检率 ≤ exp(−nδ)（Chernoff 界）。系：**标定吸收的缓变故障在 provenance 通道下以指数速率暴露**——R69 用动作似然做第二意见，R70 再加一条与训练流程正交的"是否还是注册的那个模块"通道。

**引理 20（N-version 差分采纳错误上界）** 设两分叉独立故障概率 p_A, p_B，故障相关 ρ<1，且 U_fork > τ 时拒绝采纳（A102）。则错误采纳率 ≤ p_A p_B + P(U_fork ≤ τ | 双错) ≤ p² + ε_d；三路多数时为 O(p³)。系：**provenance 多样性比单纯加大模型容量更能降低"自信地错"**，而代价是与一致率成反比的误拒（可用 τ_agree 调 Pareto，见 E307–E308）。

**引理 21（最小差分的可归因性）** 若 IP 满足定义 315(b)(c)，则其在 t_disc 上的因果贡献 ≠ 0，且不存在更小的、仍能独立通过 t_disc 的子差分 ⇒ 该 IP 是可归因原子。反之，若 RGT 不完备，存在"通过测试但无贡献"的空洞 IP（定义 322 的消融账本以正概率检出）。系：**不能靠堆模块刷创新点**；创新点的可信度上界就是测试集的覆盖。

**引理 22（组合包络的短板与回滚保证）** Ω_comp = ⋂Ω_m；若各模块在其包络内，组合安全下界 ≥ min_m s(m)。若回滚目标 σ_j 满足当前状态 s_t ∈ Ω_{σ_j}，则回滚后 J_FORGE 重新 Valid 且风险 ≤ 认证时风险；若 s_t ∉ Ω_{σ_j}，回滚不可行，只能失败安全（A104）。证明要点：回滚恢复的是曾完整认证的 (版本, 标定, 状态域) 三元组，而非任意历史。

**定理 18（FORGE 是 FLUID 的认证外壳，而非替代）** 在 A102–A107 下：
(i) 任意状态，FORGE 的有效执行要么与 FLUID 逐指令相同，要么是"回滚/降级/失败安全"⇒ 安全侧不弱于 FLUID；
(ii) 退化条件（定义 325）下与 FLUID 逐指令相同；
(iii) 在"自信错误"集上（U_fork > τ_trip 而单模型高度自信），FLUID 以正概率执行错误分叉，FORGE 以概率 ≥ 1 − ε_d 拒绝（引理 20）⇒ FORGE 严格更优。
故 R70 不是新能力层，而是 R69 的 **供应链/认证外壳**；能力提升只能来自通过门槛的分叉采纳与回归改进。

**定理 19（版本单调与无突变）** 若所有升级走 BVM/RGT 且运行时钉死版本，则安全包络随版本单调不缩小；回滚/降级按字典序（先安全后性能）选择，并沿用 R68 提交不变式（定理 15）⇒ 控制连续、无突变；回滚后组合证书恢复 Valid（引理 22）。

**定理 20（创新点账本的（条件）不可伪造性）** 在签名不可伪造、账本可被第三方重放、RGT 完备且探针集不被投毒的假设下：空洞 IP 会被定义 322 的消融账本标记，伪造 provenance 会被 SCA 行为指纹以引理 19 的指数速率检出。**这是条件性保证**：账本只能证明"相对于测试集"的贡献；测试集不完备时，账本会被"通过测试但无贡献"的 IP 欺骗。

## 6. 本轮最大风险

**一句话**：FORGE-RAS 的全部保证都相对于**回归测试集与探针集的覆盖**——若测试不完备或可被优化器"应试"（Goodhart），它会签发一张自洽却空洞的证书，把"通过我们想得到的测试"误当成"安全且创新"；**开源式可复现只保证过程可审计，不保证被审计的对象是对的**。

**次级风险与缓解**：
1. **共模故障**（分叉同源，违背 A102）→ provenance 多样性审计 + 引入第三种模态（不同传感器/架构）+ E307；

4. **实时预算被双分叉+重放击穿** → 分叉周期触发/仅歧义触发 + 重放摊薄 + E313；
5. **版本/包络管理开销拖慢迭代** → patch 通道自动放行 + minor 白名单 + 分层 CI（E304）。

```python
    M.audit_p.submit(h_BBOM=M.stack.bbom_hash, v=M.stack.version_vector,
                     d_rep=M.last_d_rep, u_fork=u_fork, verdict=verdict)
    return k, lam, xi, J_FORGE(M.cert, M.stack, M.last_d_rep, u_fork, verdict)
```

## 4. 推导

**引理 19（未授权漂移的探针可检出性）** n 个独立探针、漂移 KL ≥ δ 时，行为指纹漏检率 ≤ exp(−nδ)。系：标定吸收的缓变故障在 provenance 通道下指数暴露。

**引理 20（N-version 差分采纳错误上界）** 两分叉独立故障 p_A,p_B、相关 ρ<1，超阈即拒绝，则错误采纳率 ≤ p² + ε_d；三路多数为 O(p³)。系：**provenance 多样性比模型容量更能压制「自信地错」**，代价是误拒（τ_agree 调 Pareto）。

**引理 21（最小差分的可归因性）** 满足判别+最小的 IP 是可归因原子；RGT 不完备时存在「过测试但无贡献」的空洞 IP，消融账本以正概率检出。系：**不能靠堆模块刷创新点**，创新点可信度上界 = 测试覆盖。

**引理 22（组合包络短板与回滚）** Ω_comp = ⋂Ω_m；组合安全 ≥ min_m s(m)。若 s_t ∈ Ω_σ，回滚后证书重新 Valid 且风险不升；否则只能失败安全。回滚恢复的是曾认证的 (版本, 标定, 状态域) 三元组。

**定理 18（FORGE 是 FLUID 的认证外壳）** 任意状态，FORGE 要么与 FLUID 逐指令相同，要么回滚/降级/失败安全 ⇒ 安全不弱于 FLUID；退化条件下逐指令一致；在「自信错误」集上 FLUID 以正概率执行错误分叉，FORGE 以 ≥ 1−ε_d 拒绝 ⇒ 严格更优。能力提升只来自过门槛的分叉采纳与回归改进。

**定理 19（版本单调与无突变）** 升级走 BVM/RGT 且钉死版本 ⇒ 安全包络单调不缩；回滚/降级按字典序选择并沿用 R68 提交不变式 ⇒ 控制连续、无突变；回滚后证书恢复 Valid。

**定理 20（创新点账本的条件不可伪造性）** 在签名不可伪造、账本可第三方重放、RGT 完备、探针不被投毒下，空洞 IP 被消融账本标记，伪造 provenance 被 SCA 以引理 19 的指数速率检出。**条件性**：账本只证明「相对于测试集」的贡献。

## 7. 本轮最大风险

**一句话**：FORGE-RAS 的全部保证都相对于**回归测试集与探针集的覆盖**——若测试不完备或可被优化器「应试」（Goodhart），它会签发一张自洽却空洞的证书，把「通过我们想得到的测试」误当成「安全且创新」；**开源式可复现只保证过程可审计，不保证被审计的对象是对的**。

**次级风险与缓解**：共模故障（provenance 多样性审计 + 第三模态 + E307）；回滚快照投毒（快照签名 + 第三方重放 + ℰ_supply）；测试覆盖不足/应试（判别测试的语义不变性 + 红队新测试 + E315）；实时预算被双分叉+重放击穿（按需触发 + 重放摊薄 + E313）；版本/包络管理拖慢迭代（patch 自动 + minor 白名单 + 分层 CI）。
