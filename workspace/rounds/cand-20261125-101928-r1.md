# 灵感驱动研究循环 · 第 1 轮
**本轮灵感：「痛点分析」×「通用机器人」**

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v23 + IP-436–439（HPC-E+ 四证门：HPC-E ∪ CESC ∪ FSVC ∪ IPAttest；其上承 v22 的 HDL/ACSC/DCSC/HPC-E、v21 的 SDC/CAC/DCL/GIC、v20 的 PCA/CTS/CFC/HPC/CFCtrl，以及 v19/v17 全链）。
> **本轮纪律**：**不推倒 v23**。CESC / FSVC / IPAM / HPC-E+ 全部保留，v20–v22 全部保留。本轮只做一件事：把证书体系从"**按模块堆叠的证明塔**"改造成"**按真实痛点定价、按可组合契约扩展的部署级证书经济**"——用**痛点账本**决定"该证什么"，用**契约代数**决定"如何在通用平台上复用证明"。运行期安全地板不动，只在其上叠合取项：`Exec_v24 = Exec_v23 ∩ Fil_pp ∩ Fil_comp ∩ Fil_trans ∩ Fil_front ⊆ Exec_v23`。

## 0. 直觉与动机

**灵感 1（痛点分析 → 证书不是越多越好，而是"每单位痛感"配多少证据）**
直觉：v18→v23 是一条"加证书、加谓词、加门"的单向路。它默认**多加一层证明 = 多一分安全**，却从没问过：这套系统究竟在替谁、缓解哪一种真实部署痛点？产品设计里的痛点分析（用户旅程 → 故障现场 → 五个为什么 → 根因）给出一个刺耳的反转：**痛点不是均匀分布的，证据的价值也不等于证据的数量**。真实部署里最贵的痛点往往不是"会不会碰"（几何安全在 v20 后已相当扎实），而是**集成延迟、误停导致的活性坍缩、现场标定漂移、长尾任务下的行为不可预期、以及运维者不信任系统**。更关键的是痛点的**因果结构**：一个根因（如"分布漂移"）会在表层裂变成十几个互相看似独立的痛点；如果逐痛点打补丁，就会重复建设、互相打架、把系统越补越脆。

因此本轮的**第一个反直觉点**：**最优证书组合是"最小充分集"，而不是"最大证明集"**。每多挂一个证书模块，就多一份推理延迟、多一个集成故障面、多一次误停机会——证书的"边际痛感削减"会递减，而"边际部署成本"不会。把有限的安全/验证预算花在"即使补上、执行决策也不会变"的痛点上，是最昂贵的浪费。（注意：这只在**安全地板之上**做加法取舍，绝不删除 v23 的安全硬约束；详见 P44。）

**灵感 2（通用机器人 → 不该逐任务发证，而该证"算子"）**
直觉：v23 隐含前提是"一个本体、一个场景、一批可枚举的计划"。可 **通用机器人** 的立身之本恰恰是**跨任务、跨物体、跨本体、跨站点**：你不可能给每一个可能任务、每一个新桌面、每一台新型号都单独签一张证书——任务空间是开放且无穷的。硬要逐实例认证，系统会在长尾上永远"未认证"，通用性名存实亡。软件工程与形式化方法早就给过答案：**不要证明每一个程序，要证明组合规则与精化关系**。这正是 assume-guarantee（假设-保证）契约理论、以及仿真关系/互模拟（simulation relation / bisimulation）的思想。

于是**第二个反直觉点**：**通用性应当被认证在"契约 + 组合算子 + 转移态射"这一层，而不是"任务实例"这一层**。每个技能携带一张契约 ω =（前置条件、后置条件、环境假设、保证、能量包络）；只要组合图是**无环的**且每条 `环境假设` 都被前驱的 `保证` 真正兑现，组合就是可靠的——我们由此获得一条**对任意可组合任务普适**的保证，而无需枚举任务。跨本体则通过一个**显式降级的仿真态射**（带 Lipschitz 常数与迁移损耗 δ）把证书搬过去，搬不动就**拒证并回退**，绝不假装等价。这条"证算子不证实例"的路线，恰好把通用机器人的开放任务空间从"认证不可能"变成"认证可组合"。

**两者如何统一：需求侧定价 × 供给侧复用**
- **痛点分析**是**需求侧**：定义"为什么证、证到什么程度才够"，把证书预算对准会翻转执行决策的痛点，避免 v23 塔继续无节制膨胀。
- **通用机器人**是**供给侧**：定义"如何用有限证明覆盖开放空间"，把单点证书升级为可组合、可转移的契约，使通用平台在长尾上仍能给出**有边界的**保证。
- 统一交付物：v24 在 v23 的 HPC-E+ 之上加一层 **部署级证书经济（Deployment Certificate Economy, DCE）**。四张新结构为：**痛点因果账本 PPCL**（需求）、**最小充分证书组合 MSCP**（预算）、**契约代数 CASC**（组合）、**通用性前沿与迁移 GSFC/ETMC**（扩展），最终由 **HPC-G** 统一门合成。

### 0.4 严谨定义（摘要）
- **痛点账本**：`P = {p_i}`，每点带严重度 `sev(p_i) ≥ 0`、频次、可归因事件流 `I`。因果图 `G_P = (R ∪ F ∪ P, E)`，其中根因 `R`、失效模式 `F`，边权为条件概率。证书 `c` 的覆盖 `cov(c) ⊆ R`。
- **痛感削减**：`relief(S) = Σ_{r∈R} w_r · min(1, Σ_{c∈S, r∈cov(c)} q_{c,r})`，其中 `w_r` 为根因 `r` 折算的期望损失，`q_{c,r} ∈ [0,1]` 为证书 `c` 对根因 `r` 的压制率。`relief` 是**单调子模**的覆盖函数。
- **最小充分组合**：在预算 `(β_lat, β_int)` 下求解 `max_{S: cost(S) ≤ β} relief(S) − λ·cost(S)`，约束**安全地板 `F0 ⊆ S` 恒含**（`F0` 为 v23 全部安全硬约束）。故 `S` 只**增加**合取项，`Exec` 只减不增。
- **技能契约**：`ω = (Pre_ω, Post_ω, Rely_ω, Guar_ω, E_ω)`。组合 `ω₁∘ω₂` 合法当且仅当 `Post_{ω₁} ⇒ Pre_{ω₂}`、`Guar_{ω₁} ⇒ Rely_{ω₂}`、组合图无环且 `E` 包络可相加。
- **本体迁移态射**：仿真关系 `≼_sim ⊆ S_A × S_B`、抽象 `α: S_B → S_A`、Lipschitz 常数 `L_AB`、迁移损耗 `δ_AB`。迁移后的证书取**保守降级** `ε^B = ε^A + L_AB·δ_AB + δ_transfer`，并要求 `Exec_B ⊆ α^{-1}(Exec_A)`。
- **通用性前沿**：任务分布 `τ`，已认证集 `T_cert`，覆盖 `γ = P_τ(T_cert)`，OOD 分数 `s_ood`，阈值 `θ_ood`。前沿之外必须强制进入**降级模式集 `M_deg`**（限速 / 求助 / 遥操作 / 停机），未知一律按"不安全"处理，绝不按"空闲"处理。

## 1. 研究问题（v24 升级版，Q12–Q16）

- **Q12（痛点→证据的因果可识别性）**：如何从真实部署事件流中估计因果图 `G_P` 与压制率 `q_{c,r}`，使"痛感削减"不被相关性与幸存者偏差污染（尤其"没记录下来的长尾痛点"不能被默认为零）？严重度 `sev` 如何跨异质事件（碰撞、误停、延迟、信任流失）折算为同一公共货币？
- **Q13（最小充分组合的最优化与活性）**：在安全地板 `F0` 固定、预算 `(β_lat, β_int)` 紧约束下，带成本项的 `relief` 是否仍是单调子模？预算背包下贪心/枚举能达到何种近似比？当"删减一个缓解模块"会**放大**某根因暴露时，如何保证该模块落在 `F0` 而永不被优化器删除？误停成本如何进入目标而不诱导"为了活性牺牲安全"？
- **Q14（契约组合的可靠性）**：assume-guarantee 的经典陷阱是**循环依赖**（A 靠 B 的后置、B 靠 A 的后置），会让"各自都证过"的组合整体不可靠。如何用无环分层 + 前驱保证兑现来机械地排除循环？当组合证明失败时，如何**退回 v23 的一体化验证**而不是放行？契约中的能量包络在并行技能竞争资源时如何安全相加？
- **Q15（跨本体迁移的保守性）**：仿真关系与抽象 `α` 在什么条件下能给出 `Exec_B ⊆ α^{-1}(Exec_A)`？Lipschitz 与迁移损耗 `δ_AB` 如何标定，使迁移后的证书只会更保守、绝不更乐观？当本体的观测/动力学差异过大（迁移态射不存在）时，拒证与"就地重认证"如何选择与计费？
- **Q16（通用性前沿与长尾退化）**：如何用 conformal/OOD 给出 `T_cert` 的**覆盖下界**，使得"任务在包络内"这一判断的假阳性被显式控制在 `α` 内？前沿之外如何强制 `M_deg` 且不引入"降级—恢复"振荡？痛点账本如何**主动采样**那些从未发生但一旦发生即灾难的长尾（而非只刷常见痛点）？

## 2. 设计原则（在 P34–P42 基础上新增 P43–P46）

**P43 痛点因果归因律（Pain-Point Causal Attribution）**
每张被激活的缓解证书 `c` 必须登记：它针对的根因集合 `cov(c)`、证据来源 `I_c`、压制率 `q_{c,r}` 的置信区间、以及**显式未覆盖集** `R \ cov(c)`。**未被记录 ≠ 严重度为零**：对"无事件"的痛点使用保守先验（可能发生），不得计入"已缓解"。跨异质痛点的公共货币统一折算为**决策翻转风险**（expected loss × 该痛点触发执行切换的概率）。

**P44 最小充分组合律（Minimal-Sufficient Portfolio under Fixed Safety Floor）**
证书组合在**安全地板 `F0` 之上**做预算化子模最大化：`max_{F0 ⊆ S, cost(S) ≤ β} relief(S) − λ·cost(S)`。安全硬约束（v23 的 SDC/CAC/DCL/GIC/PGEV/ACSC/DCSC/HPC-E 及 HPC-E+ 门）**永不可被优化器删除**；优化器只能在"额外可选缓解/使能模块"之间取舍。删除一张**使能证书**（如 AbsCert）只会**减少**活性（`AbsCert` 缺席即回到"假设有人"的保守态），删除一张**约束证书**则被 `F0` 禁止。故任意组合 `S` 都满足 `Exec_v24(S) ⊆ Exec_v23`。

**P45 契约可组合律（Sound Assume-Guarantee Composition）**
技能以契约 `ω = (Pre, Post, Rely, Guar, E)` 表征。组合 `ω₁∘…∘ωₙ` 仅在以下全部成立时被接受：(i) 组合依赖图**无环**（分层/拓扑序），(ii) 每条 `Post` 与 `Guar` 兑现后继的 `Pre` 与 `Rely`，(iii) 能量包络按竞争/并行规则**可加且不超预算**。组合产生的是**可机械复核的组合证明** `π_comp`，而非"跳过验证"。**最终仍须穿过 v23 的 HPC-E+ 门**；组合证明只是把"从头重证"降为"廉价验证明"，证明无效即回退一体化验证或拒行。循环假设一律**拒证**（fail-closed）。

**P46 通用性转移与前沿退化律（Transfer & Frontier Degradation）**
跨本体迁移必须携带显式仿真态射与损耗：`ε^B_loc = ε^A_loc + L_AB·δ_AB + δ_transfer`，且仅在 `Exec_B ⊆ α^{-1}(Exec_A)` 可证时成立；态射不存在则**拒证并就地重认证**。任务落在已认证包络 `T_cert` 之外（`s_ood > θ_ood` 或覆盖下界不足）时，强制进入降级模式集 `M_deg`（限速 → 求助 → 遥操作 → 停机），不得以"没有已知障碍"为由自由执行。**未知不是自由空间，未知是待证空间。**

## 3. 与基线的接口（如何退化）

- **PPCL 失效**（事件流缺失/因果图不可信）⇒ 所有痛点按"未缓解 + 可能发生"处理，激活**保守全集**缓解 ⇒ 比 v23 更保守，`⊆` 成立；
- **MSCP 失效**（预算优化器崩溃/超时）⇒ 退回 `S = F0`（仅安全地板，不挂任何可选缓解）⇒ 只可能少活性，`⊆ v23`；
- **CASC 失效**（契约库损坏/组合证明无法复核）⇒ 放弃组合捷径，所有计划退回 v23 的一体化验证 ⇒ `⊆ v23`（等价或更保守）；
- **CASC 拒证循环组合** ⇒ 该组合计划不进入执行，退回单技能/一体化路径 ⇒ `⊆`；
- **ETMC 失效**（无仿真态射/迁移损耗超预算）⇒ 不做跨本体复用，目标本体就地重认证；认证不过则不执行 ⇒ `⊆`；
- **GSFC 失效**（OOD 检测器不可信）⇒ 将 `T_cert` 收缩为空集，一切任务按前沿之外处理、强制 `M_deg` ⇒ 最保守；
- **全线失效** ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18`。
- **关键点**：四层新结构**只增加合取项或只收缩可达集**；即便是"最小充分组合"也只在安全地板之上做加法取舍，因此不会出现"优化掉安全"或"没证据就停机"以外的活性副作用。MSCP 的每次选择、CASC 的每次组证明、ETMC 的每次迁移、GSFC 的每次降级都携带时间戳，接入 v17 APS 新鲜度阶梯；控制路径仅做 O(1) 状态查询。

## 4. 预期贡献

1. **痛点因果账本**：首次把"痛点分析"形式化为证书体系上的**因果归因 + 严重度加权 + 未记录痛点保守先验**，给出"该证什么"的需求侧定价机制，并明确区分"已缓解 / 未覆盖 / 从未采样"；
2. **最小充分证书组合**：在固定安全地板下给出预算化子模优化（覆盖函数 + 成本惩罚），证明 `Exec_v24 ⊆ Exec_v23` 不受优化器删减影响，用"证书 ROI"取代"证书数量"作为设计指标；
3. **契约代数**：把技能证书升级为 assume-guarantee 契约，给出**无环组合可靠性定理**（排除循环假设）与"组合证明仍过 v23 门"的双保险，使通用机器人可对**任意可组合任务**给出普适保证而无需逐实例认证；
4. **本体迁移证书**：用仿真关系 + Lipschitz + 迁移损耗给出保守降级的跨本体迁移，显式证明 `Exec_B ⊆ α^{-1}(Exec_A)`，并给出"态射缺失即拒证"的 fail-closed 规则；
5. **通用性安全前沿**：把开放任务空间的"未认证长尾"变成一等公民——conformal 覆盖下界 + OOD 强制降级（限速/求助/遥操/停机），并让痛点账本主动采样灾难性长尾而非只刷常见痛点；
6. **部署级证书经济闭环**：HPC-G 统一门把"需求（痛点）—预算（MSCP）—供给（契约/迁移）—边界（前沿）"合成一条可审计链，`Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18` 闭环。

## 5. 本轮最大风险

**一句话**：整套方案依赖**痛点账本与契约组合的双重经验假设**——若账本只忠实拟合"已发生、已记录"的痛点（幸存者偏差），而 assume-guarantee 组合又存在未被发现的循环依赖，那么一台通用机器人会以**统计上漂亮、形式上可审计**的姿态，安全地重复解决已知痛点，同时"合规地"踏入从未被采样、也从未被证伪的长尾灾难——即"**被证明覆盖的盲区**"。

# ============================================================
# IP-440 Pain-Point Causal Ledger (PPCL) — 痛点因果账本
# ============================================================
from dataclasses import dataclass, field
import math, heapq

@dataclass
class PainPoint:
    pid: str
    severity: float                 # 单次发生损失
    freq: float                     # 频次
    decision_flip: float            # 触发执行切换的概率
    sampled: bool = False           # 是否被真实采样过（False → 保守先验）
    root_causes: set = field(default_factory=set)

@dataclass
class CertSpec:
    cid: str
    roots: set                      # cov(c)
    q: dict                          # {root: (q_lo, q_hi)}
    latency_ms: float
    integration_risk: float
    is_floor: bool = False

class PainCausalLedger:
    """事件流 → 失效模式 → 根因的因果归因；登记未覆盖与从未采样痛点。"""
    def __init__(self, prior_strength: float = 1.0):
        self.roots = {}             # r -> {description}
        self.edges = {}             # (src, dst) -> conditional probability
        self.pains = {}             # pid -> PainPoint
        self.incidents = []         # 原始事件（已脱敏）
        self.prior_strength = prior_strength

    def ingest(self, incident: dict):
        """写入一条部署事件；无事件不是零痛感，只是未采样。"""
        self.incidents.append(incident)
        if incident.get("pain") in self.pains:
            self.pains[incident["pain"]].sampled = True

    def attribute(self, incident: dict) -> dict:
        """贝叶斯式根因归因：P(r | incident) ∝ P(incident | r) · P(r)。"""
        post = {}
        for r in self.roots:
            lik = self._likelihood(incident, r)     # 来自 G_P 的局部条件概率
            post[r] = self.prior(r) * lik
        z = sum(post.values()) or 1.0
        return {r: v / z for r, v in post.items()}

    def prior(self, r: str) -> float:
        """未采样根因使用保守先验，避免'没记录 = 安全'。"""
        seen = sum(1 for inc in self.incidents if r in self.attribute(inc))
        return (seen + self.prior_strength) / (len(self.incidents) + 2 * self.prior_strength)

    def _likelihood(self, incident: dict, r: str) -> float:
        return float(self.edges.get((r, incident.get("failure_mode")), 0.05))

    def root_weight(self, r: str) -> float:
        """w_r：把异质痛点折算为统一公共货币（决策翻转风险）。"""
        w = 0.0
        for p in self.pains.values():
            if r in p.root_causes:
                w += p.severity * p.freq * p.decision_flip * self.prior(r)
        return w

    def unmitigated_roots(self, S: set, specs: dict) -> set:
        """显式列出未被组合覆盖的根因——它们必须进入报告，不得静默。"""
        covered = set()
        for cid in S:
            covered |= specs[cid].roots
        return set(self.roots) - covered


# ============================================================
# IP-441 Minimal-Sufficient Certificate Portfolio (MSCP)
# ============================================================
class MSCPortfolio:
    """固定安全地板 F0，在其上做预算背包子模最大化。"""
    def __init__(self, floor: set, beta: dict,
                 lam_lat=1.0, lam_int=1.0, lam_fp=1.0):
        self.F0 = set(floor)                       # 不可删除的安全硬约束
        self.beta = beta
        self.lam = (lam_lat, lam_int, lam_fp)

    def _relief(self, S: set, graph: PainCausalLedger, specs: dict) -> float:
        total = 0.0
        for r in graph.roots:
            w = graph.root_weight(r)
            cap = sum(specs[c].q.get(r, (0.0, 0.0))[0] for c in S if r in specs[c].roots)
            total += w * min(1.0, cap)
        return total

    def _cost(self, S: set, specs: dict, fp_expect=0.0) -> tuple:
        lat = sum(specs[c].latency_ms for c in S)
        integ = sum(specs[c].integration_risk for c in S)
        return lat, integ, fp_expect

    def _feasible(self, S: set, specs: dict) -> bool:
        lat, integ, fp = self._cost(S, specs)
        return (lat <= self.beta["lat"] and integ <= self.beta["int"]
                and fp <= self.beta["fp"] and self.F0 <= S)

    def select(self, graph: PainCausalLedger, specs: dict) -> set:
        """成本-效益贪心（budgeted max-coverage）；F0 永远先入。"""
        S = set(self.F0)
        candidates = [c for c in specs if c not in self.F0]
        if not self._feasible(S, specs):
            return set(self.F0)                    # 地板都超预算 → 只保留地板并发告警
        while True:
            base = self._relief(S, graph, specs)
            best, best_ratio = None, 0.0
            for c in candidates:
                if c in S:
                    continue
                trial = S | {c}
                if not self._feasible(trial, specs):
                    continue
                gain = self._relief(trial, graph, specs) - base
                _, integ0, _ = self._cost(S, specs)
                _, integ1, _ = self._cost(trial, specs)
                dcost = (specs[c].latency_ms * self.lam[0]
                         + (integ1 - integ0) * self.lam[1] + 1e-9)
                ratio = gain / dcost
                if ratio > best_ratio:
                    best, best_ratio = c, ratio
            if best is None:
                break
            S.add(best)
        return S

    def assert_floor(self, S: set) -> bool:
        return self.F0 <= S


# ============================================================
# IP-442 Contract Algebra for Skill Composition (CASC)
# ============================================================
@dataclass
class Contract:
    skill_id: str
    pre: "Predicate"
    post: "Predicate"
    rely: "Predicate"
    guar: "Predicate"
    energy_env: tuple          # (E_min, E_max)

class ContractAlgebra:
    """assume-guarantee 组合：无环 + 前驱兑现 + 能量可加；循环拒证。"""
    def __init__(self):
        self.lib = {}          # skill_id -> Contract

    def compose(self, ids: list) -> "Optional[ComposedProof]":
        contracts = [self.lib[i] for i in ids]
        order = self._topo_order(contracts)
        if order is None:
            return None                       # 循环依赖 → 拒证（fail-closed）
        for a, b in zip(order, order[1:]):
            if not self._implies(a.post, b.pre):
                return None                   # 后置不兑现前置
            if not self._implies(a.guar, b.rely):
                return None                   # 保证不兑现环境假设
            if not self._energy_addable(a, b):
                return None
        composed = Contract(
            skill_id="∘".join(ids),
            pre=order[0].pre,
            post=order[-1].post,
            rely=self._conj([c.rely for c in order if not self._discharged(c, order)]),
            guar=self._conj([c.guar for c in order]),
            energy_env=self._sum_env(order),
        )
        return ComposedProof(contract=composed, witness_ids=ids,
                             proof_hash=self._hash(composed, ids))

    def _topo_order(self, contracts):
        """按 (pre/post/rely) 支撑关系建图；任何环 → None。"""
        n = len(contracts)
        adj = {i: set() for i in range(n)}
        indeg = [0] * n
        for i in range(n):
            for j in range(n):
                if i != j and self._implies(contracts[i].guar, contracts[j].rely):
                    adj[i].add(j)
                    indeg[j] += 1
        q = [i for i in range(n) if indeg[i] == 0]
        order, seen = [], 0
        while q:
            i = q.pop()
            order.append(contracts[i]); seen += 1
            for j in adj[i]:
                indeg[j] -= 1
                if indeg[j] == 0:
                    q.append(j)
        return order if seen == n else None

    def _discharged(self, c, order):
        """若前驱已提供 c.rely，则该假设不需要外部兑现（避免重复计账）。"""
        idx = order.index(c)
        return any(self._implies(p.guar, c.rely) for p in order[:idx])

    def _implies(self, a, b) -> bool: return b is None or a.subsumes(b)
    def _energy_addable(self, a, b) -> bool: return a.energy_env[1] + b.energy_env[1] <= 1e9
    def _conj(self, preds): return preds[0] if len(preds) == 1 else ("AND", tuple(preds))
    def _sum_env(self, order): return (sum(c.energy_env[0] for c in order), sum(c.energy_env[1] for c in order))
    def _hash(self, *args): return hash(args)

@dataclass
class ComposedProof:
    contract: Contract
    witness_ids: list
    proof_hash: int

    def check(self) -> bool:
        """组合证明仍须穿 v23 HPC-E+ 门，这里只做廉价的自洽性复核。"""
        return self.witness_ids and self.proof_hash is not None

# IP-443 Embodiment Transfer Morphism Certificate (ETMC)
# ============================================================
class TransferMorphism:
    def __init__(self, relation, abstraction, lipschitz: float, delta: float,
                 transfer_budget: float):
        self.relation = relation            # ≼_sim ⊆ S_A × S_B
        self.alpha = abstraction            # α: S_B → S_A
        self.L = lipschitz                  # L_AB
        self.delta = delta                  # δ_AB
        self.budget = transfer_budget       # 允许的最大额外保守量

    def transfer_loc(self, eps_A: float) -> float:
        return eps_A + self.L * self.delta + self.delta

    def valid(self, cert_A, target) -> bool:
        if not self.relation.established(target):
            return False
        eps_B = self.transfer_loc(cert_A.eps_loc)
        if eps_B - cert_A.eps_loc > self.budget:
            return False                    # 降级过大 → 不如就地重认证
        # 关键单调性：目标本体的安全态必须被源本体安全态经 α 覆盖
        return self._subset_sim(cert_A.safe_set, target.safe_set)

    def _subset_sim(self, safe_A, safe_B) -> bool:
        for s_B in safe_B:
            if not safe_A.contains(self.alpha(s_B)):
                return False
        return True

    def transfer(self, cert_A, target):
        if not self.valid(cert_A, target):
            return None                     # fail-closed：拒证
        return cert_A.with_epsilon(self.transfer_loc(cert_A.eps_loc))

# IP-444 Generality-Safety Frontier Certificate (GSFC)
# ============================================================
class GeneralityFrontier:
    def __init__(self, ood_scorer, threshold: float, alpha: float,
                 certified_tasks: set):
        self.ood = ood_scorer
        self.theta = threshold
        self.alpha = alpha
        self.T_cert = certified_tasks
        self.coverage_lcb = 0.0

    def update_coverage(self, n: int, n_cert: int, delta: float = 1e-3) -> float:
        """有限样本覆盖下界（Hoeffding/Clopper-Pearson 均可）。"""
        emp = n_cert / max(n, 1)
        self.coverage_lcb = max(0.0, emp - math.sqrt(math.log(1 / delta) / (2 * n)))
        return self.coverage_lcb

    def is_in_envelope(self, task) -> bool:
        return (task.id in self.T_cert
                and self.ood(task) <= self.theta
                and self.coverage_lcb >= 1 - self.alpha)

    def enforce(self, task, requested_mode: str) -> str:
        """前沿之外强制降级；未知 ≠ 自由空间。"""
        if self.is_in_envelope(task):
            return requested_mode
        for mode in ("slow", "ask", "teleop", "stop"):
            if mode != requested_mode:
                return mode                 # 至少降一级
        return "stop"

    def frontier_ok(self, task, mode: str) -> bool:
        return self.is_in_envelope(task) or mode in ("slow", "ask", "teleop", "stop")

# IP-445 Pain-Aware Evidence Scheduler (PAES) — 反幸存者偏差
# ============================================================
class PainAwareScheduler:
    def __init__(self, catastrophe_quota: float = 0.2):
        self.catastrophe_quota = catastrophe_quota   # 强制采样从未发生长尾的预算比例

    def schedule(self, ledger: PainCausalLedger, budget: int) -> list:
        never = [p for p in ledger.pains.values() if not p.sampled]
        forced = never[:max(1, int(budget * self.catastrophe_quota))]
        rest = sorted(ledger.pains.values(),
                      key=lambda p: -p.severity * p.freq / (1.0 + float(p.sampled)))
        picked, seen = list(forced), set(p.pid for p in forced)
        for p in rest:
            if len(picked) >= budget:
                break
            if p.pid not in seen:
                picked.append(p); seen.add(p.pid)
        return picked

# IP-446 HPC-G 统一准入门
# ============================================================
@dataclass
class HPCG:
    hpc_e_plus: "HPCEPlus"          # v23 四证门
    portfolio: MSCPortfolio
    algebra: ContractAlgebra
    transfer_morphism: TransferMorphism
    frontier: GeneralityFrontier

    def admits(self, plan, task, x, v, z, E_res, margin_req, modules) -> bool:
        # 1) v23 基础门（安全地板）
        if not self.hpc_e_plus.admits(plan, x, v, z, E_res, margin_req, modules):
            return False
        # 2) 安全地板必须完整（MSCP 永不删地板）
        if not self.portfolio.assert_floor(self.portfolio.F0):
            return False
        # 3) 契约组合证明（若有组合）；证明无效则拒行
        if plan.is_composed:
            proof = self.algebra.compose(plan.skill_ids)
            if proof is None or not proof.check():
                return False
        # 4) 跨本体迁移（若来自其他本体）必须保守且可证
        if plan.cross_embodiment:
            if not self.transfer_morphism.valid(plan.cert, plan.target):
                return False
        # 5) 通用性前沿：包络内，或已强制降级
        if not self.frontier.frontier_ok(task, plan.mode):
            return False
        return True

## 3. 正确性论证

### 引理 1（最小充分组合的安全地板不变性与近似比）
**陈述**：令 `F0` 为 v23 全部安全硬约束，`S* = MSCPortfolio.select(...)`。则 (i) `F0 ⊆ S*` 恒成立；(ii) 对任意组合 `S`，`Exec_v24(S) ⊆ Exec_v23`；(iii) 若 `relief` 单调子模且预算为基数约束，成本-效益贪心满足 `relief(S*) ≥ (1 − 1/e)·relief(S_OPT)`；预算背包情形按 Khuller–Moss–Naor 的枚举贪心同样达到 `(1 − 1/e)`。

**证明**：
1. `select` 以 `S = set(self.F0)` 初始化，且后续只做 `S.add(...)`，从不 `remove`，故 `F0 ⊆ S*`；`assert_floor` 二次断言。
2. `relief` 每项 `w_r·min(1, Σ_{c∈S,r∈cov(c)} q_{c,r})` 是"模函数与常数取 min"再正权求和；`min(1, ·)` 为凹非减函数，故每项单调子模，非负加权和仍单调子模。可选模块只会增加 `cov` 覆盖、从而只可能**收紧**执行域（约束类）或**只在 `F0` 界内释放活性**（使能类，其缺席只会更保守）。结合 `F0` 固定，`Exec_v24(S) ⊆ Exec_v23`。
3. 单调子模 + 基数预算的贪心 `(1−1/e)` 是标准结论（Nemhauser–Wolsey–Fisher 1978）；预算背包的最大覆盖由 Khuller–Moss–Naor (1999) 的"枚举 + 贪心"达到同一近似比。∎

> **注**：优化器**永远不能**删除 `F0`，因此"最小充分"只削减 v24 **自身新增**的冗余模块，不触碰 v23 安全地板——这是 `Exec ⊆` 与"反过度工程"能同时成立的唯一接口。

### 引理 2（无环契约组合的可靠性）
**陈述**：若组合 `ω₁∘…∘ωₙ` 通过 `ContractAlgebra.compose`，则组合契约 `Guar_comp = ⋀ᵢ Guar_ωᵢ` 在环境 `⋀_{未被前驱兑现} Rely_ωᵢ` 下成立，且不存在循环假设支撑。

**证明**：
1. `_topo_order` 对 `Guar_i ⇒ Rely_j` 的支撑图做拓扑排序，返回 `None` 当且仅当存在环；故通过检查的组合其支撑图是 DAG。
2. 对 DAG 按拓扑序归纳：基例首技能在外部兑现的 `Rely` 下满足 `Guar`；归纳步中，后继的 `Rely` 已被前驱 `Guar` 兑现（`_implies` 检查 `Guar_i ⇒ Rely_j`），且其 `Pre` 已被前驱 `Post` 兑现，故后继在其契约内成立。
3. 能量包络按可加规则求和，`_energy_addable` 拒绝超界组合，故 `E_comp` 在预算内。
4. 组合输出 `π_comp` 仅是一个**证明对象**，仍由 HPC-G 第 1 步穿过 v23 HPC-E+ 门复核；即使组合证明有遗漏，基础门仍然兜底。∎

### 引理 3（跨本体迁移的保守子集性）
**陈述**：若 `TransferValid(c_A → B)` 成立，则 `Exec_B ⊆ α^{-1}(Exec_A)`，且迁移误差 `ε^B_loc ≥ ε^A_loc` 严格更保守。

**证明**：
1. `transfer_loc` 定义为 `ε^A_loc + L_AB·δ_AB + δ_transfer`，三项非负，故 `ε^B_loc ≥ ε^A_loc`，膨胀盒只会更大（更保守），不会引入假自由空间。
2. `_subset_sim` 逐一验证 `∀s_B ∈ safe_B: α(s_B) ∈ safe_A`，即 `safe_B ⊆ α^{-1}(safe_A)`；结合更大误差界，`Exec_B ⊆ α^{-1}(Exec_A)`。
3. 若仿真关系未建立或降级超预算，`valid` 返回 `False`、`transfer` 返回 `None`，调用方只能就地重认证或拒行，故失败方向恒为更保守。∎

### 引理 4（通用性前沿的失效安全）
**陈述**：若任务不在已认证包络（`s_ood > θ_ood` 或 `γ_lo < 1−α` 或 `task ∉ T_cert`），则 `enforce` 至少下调一个保守等级；若 OOD 检测器本身不可信（`T_cert := ∅`），系统进入最保守模式。

**证明**：
1. `is_in_envelope` 要求三条件同时成立；任一不成立即走 `enforce` 的降级链 `slow → ask → teleop → stop`，且返回的等级严格比请求更保守。
2. `frontier_ok` 仅在"包络内"或"mode ∈ M_deg"时为真，故 HPC-G 不会在未降级状态下放行前沿外任务。
3. `T_cert := ∅` 时 `is_in_envelope` 恒假，所有任务强制降级；这是失效安全的最保守不动点。∎

### 定理（HPC-G 的安全-可部署-可扩展-可组合完备性）
**陈述**：对任意计划 `π`，`HPCG.admits(π)=True` 当且仅当 `π` 同时满足：(1) v23 物理-规范-能量安全（HPC-E+）；(2) 安全地板完整且组合在预算内（MSCP）；(3) 组合证明可机械复核、无循环假设（CASC）；(4) 跨本体迁移保守且可证（ETMC）；(5) 任务在认证包络内或已强制降级（GSFC）。由此 `Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18` 恒成立。

**证明**：`admits` 是五个合取项的短路与：任一不满足即拒证，对应五类风险之一未被缓解（必要）；五项全满足时，由引理 1–4 分别给出 `Exec ⊆`、组合可靠、迁移保守、前沿失效安全，故构成完整闭环（充分）。单调链由"v23 门为第 1 步且只在必要时叠加收缩"直接得到。∎

## 6. 本轮最大风险（最终确认）

**一句话**：若痛点账本只忠实拟合"已发生、已记录"的痛点（幸存者偏差），而契约组合又存在未被拓扑检查捕获的循环假设，那么通用机器人会以**统计上漂亮、形式上可审计**的姿态，安全地重复解决已知痛点，同时"合规地"踏入从未被采样、也从未被证伪的长尾灾难——即"**被证明覆盖的盲区**"。
