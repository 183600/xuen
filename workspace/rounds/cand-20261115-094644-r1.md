# 第 70 轮（承接第 69 轮「FLUID-RAS 标定感知自监督多任务闭环——不确定性二分与主动多模态交互」IP-253~263；灵感循环第 3 轮；本轮灵感：「视觉定位」×「通信延迟」）

> R69 把不确定性拆成 aleatoric/epistemic，并让 epistemic 去「问」——看、问、触。但它对「证据」做了一次极其干净、也极其危险的抽象：**证据是一个定义在「当下、此处、这个对象」上的似然 p(r | mode)**。这个抽象悄悄假设了两件从未被验证的事：(1) 我知道**我在问哪一个**；(2) 我知道**答案什么时候到、到时还算不算数**。本轮两个灵感恰好各刺穿一个假设——**视觉定位**决定「哪一个」（空间指代），**通信延迟**决定「还算不算数」（时间有效期）。
>
> 更致命的是，R69 的看家防御「k 个正交证据源一致」证明的是**一致性**，不是**共指性**。只要所有证据都被同一个定位误差指向同一个诱饵，它们会兴高采烈地一致同意一个错误答案——**一致，不等于说的是同一个它**。于是 R69 的投毒上界藏着一个与 k 无关的隐藏下界 P_mis：加证据源永远压不掉它。
>
> 核心命题：**证据必须被「接地」（grounded）——绑定到空间指代 ρ 与时间有效期 [t_e, t_e+D)。未接地（指代混叠或时间过期）的证据不是「降权」，而是「不可采信」；此时不提问，逐指令退回 R69，再退回 R68。** 命名 **RELAY-RAS**（Referent-grounded, Expiry-aware, LAtest-valid Yield：指代锚定 × 时延有效期的证据接地闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我到底在问哪一个，它现在还成立吗**」——开口之前先确认你问的是它，采纳之前先确认它还没过期。

## 0. 直觉与动机

**灵感 1（视觉定位 → 指代混叠：问错对象比答错更隐蔽）**
直觉：R69 的信息动作（注视、探针、问句）都以「指向某物」为前提，而这个「某物」由视觉定位给出。若定位误差把查询指向了相邻的杯子，人仍会诚实回答——但回答的是「那个杯子」。证据的似然、置信、时间戳全都自洽，唯独**指代**是错的。这是比投毒更阴险的失败：**投毒是答案骗你，指代混叠是世界骗你，而且骗得毫无破绽。** 空间上的判别条件很朴素：指代间距必须显著大于定位误差（空间 Nyquist），否则「看/问/触」全在对着影子做实验。

**灵感 2（通信延迟 → 陈旧确认：把「不知道」升级成「过时的知道」）**
直觉：R69 默认「问了就知道、知道了就用」。但答案要经过延迟 τ 才回来，而模态可能在 τ 内翻转。于是你拿到的是一条关于**过去状态**的证据，却拿它给**当前决策**盖章。世界变化越快、时延越大，这条证据的「有效期」越短。超过相干时间后，它不再是信息，而是**反向信息**——把你从「诚实的不知道」推向「自信的错误」。这正是 R69 那句「问错比不问更危险」在时间轴上的镜像。

**灵感 3（统一视角 → 空间与时间是同一个混叠）**
直觉：采样定理说，信号频率高于采样率就会混叠到错误的频率上。证据也有两个「采样维度」：空间采样（定位分辨指代）与时间采样（时延分辨模态）。当定位误差 ≥ 指代间距的一半，或时延 ≥ 模态相干时间，证据就混叠到错误的「指代/时相」上。因此本轮不需要两套理论，只需要**一个接地判据**：`σ_loc ≪ Δ_ref` 且 `τ ≪ T_c`，两个不等式成立才允许证据进入信念。

**灵感 4（正面击穿 R69 的防御 → 一致 ≠ 共指）**
直觉：R69 用「k 个正交源多数一致」防投毒，其隐含前提是所有源都在回答**同一个对象**。但攻击者不必投毒答案，只需劫持**问题的主语**——伪造一个地标/反射诱饵/GPS 欺骗，让几何定位把所有源都指向诱饵。此时 k 个源会完全一致（因为它们确实在诚实回答关于诱饵的问题），R69 的 `δ_p·ρ^{k−1}` 上界完全失效，错误率出现一个**与 k 无关的 P_mis 地板**。结论：一致性是必要条件，共指性才是充分条件；必须新增「共指验证」。

**灵感 5（接地是一张证书，不是一个权重）**
直觉：R69 对不确定性的处置是「降权/收紧」。但指代错误与证据过期不能用权重表达——把一条指向诱饵的证据降权到 0.3，仍然是「关于诱饵」的证据。接地的正确语义是**准入门（admissibility gate）**：不满足指代与时间条件就直接判为不可采信，退回保守。这样新一轮不再是又一层可被调参的黑箱，而是一条硬边界。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（RELAY-RAS 总览）** RELAY-RAS = (REF, LPU, TVOI, CHAN, TBL, CORE, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **接地不变式**：任何进入信念的证据，必须与查询的指代共指、且在有效期内（G-valid，定义 315）；不接地证据**不可采信**，不是降权；
(iii) **单调退化链**：接地失效/预算耗尽/疑似劫持 ⇒ 逐指令退回 FLUID-RAS；FLUID 拒绝 ⇒ 逐指令退回 CALM-RAS；R70 安全侧永不让步（定义 325，定理 18）。

**定义 311（证据溯源元 / provenance tuple）** 每条观测或回答 e 携带 `π(e) = (ρ, Σ_ρ, t_e, t_arr, τ, D, s_e, κ)`：ρ 为指代 id（对象/地标/区域），Σ_ρ 为指代在度量系下的协方差（视觉定位传播而来），t_e 为底层状态的**事件时间**，t_arr 为到达时间，τ = t_arr − t_e 为时延，D 为有效期上界，s_e 为来源 id，κ 为可认证的溯源签名。R69 的证据没有 π，这正是它无法区分「答错」与「问错」的根因。

**定义 312（指代不确定性）** 候选指代集 R = {ρ_i}；关联后验 p(ρ | z, T_t)，其中 T_t 为当前位姿信念。共指熵 `H_ref = −Σ_i p(ρ_i) log p(ρ_i)`；指代间距 `Δ_ref = min_{i≠j} d(ρ_i, ρ_j)`（度量系），归一化间距 `Δ_ref/σ_loc`，`σ_loc = √(λ_max(Σ_ρ))` 为指代点位置的等效标准差。

**定义 313（视觉定位误差传播 LPU）** 位姿信念 p(T_t) ∈ SE(3)，协方差 Σ_pose。指代位置协方差 `Σ_ρ = J_ρ Σ_pose J_ρᵀ + Σ_det`（J_ρ 为指代坐标对位姿的雅可比，Σ_det 为检测方差）。注视/探针的指向误差由 Σ_ρ 与执行机构误差叠加：`Σ_gaze = Σ_ρ + R Σ_act Rᵀ`。**σ_loc 不是常数，是随场景/视角变化的量**——这就是接地门必须在线估计、并可能被欺骗的地方。

**定义 314（时间有效性与证据半衰期）** 模态身份过程 m(t) 具有相干时间 `T_c(m)`（模态保持不变的期望时长，可由流策略的模态持续/hazard 估计）。时延 τ 下证据的时间有效性 `ν_t = exp(−τ/T_c)`；硬截止为决策时窗 D。`ν_t < ν_min` 或 `t_arr > D` 判为过期。

**定义 315（接地条件 G-valid）** 证据 admissible ⇔ GREF ∧ GTIME ∧ GINT：
- **GREF（共指）**：`p(ρ_e = ρ_q) ≥ 1 − δ_ref`，等价于 `Δ_ref ≥ 2σ_loc` 且 `H_ref ≤ τ_ref`；
- **GTIME（时效）**：`t_arr ≤ D` 且 `ν_t ≥ ν_min`；
- **GINT（完整）**：π(e) 的签名 κ 可认证，且指代 id 与时间戳不可被单独伪造（A101）。
不满足任一项的证据**不得进入信念**（定义 320），只能进入审计与「为何不可采信」记录。

**定义 316（时延感知 VoI / VoI_τ）** `VoI_τ(g) = P(t_arr(g) ≤ D)·ν_t(g)·IG(g) − c(g) − c_wait(τ(g))`，其中 `IG(g) = H(M|o) − E_y[H(M|o,y;π)]` 为按接地证据重算的信息增益。**只计「及时到达且仍然有效」的信息**。若 `max_g VoI_τ(g) ≤ 0`：不交互，退回 R69（定义 325）。这把 R69 的 VoI 变成 `σ_loc→0, τ→0` 的边界情形。

**定义 317（指代优先探询 referent-first）** 信息动作分两级：先消解**指代**（移动产生视差、注视地标、问「你指的是哪一个」），再消解**模态**（「它是满的还是空的」）。若 `H_ref` 或 `σ_loc` 越界，则任何模态级提问都**无效**（它必然关于错对象），必须先把预算花在指代上。序贯选择：`argmax_{g∈G_ref∪G_mode} VoI_τ(g)/c(g)`，但 `G_mode` 在 GREF 未过时被屏蔽。

**定义 318（共指验证 CORE）** 多源一致性被采纳前，须验证来源**共指**：对任意两源 `p(ρ_i = ρ_j) ≥ 1−δ`，并用**正交定位通道**（几何 SLAM vs 语义地标 vs 触觉接触）交叉校验指代位姿；不一致即判「疑似指代劫持」。CORE 把 R69 的 `k`-一致纪律从「一致性」升级为「共指一致性」，因为**一致只在共指时才意味着可信**。

**定义 319（信道模型 CHAN）** 信道 `C = (b, p_τ, ε_ch, L)`：带宽 b、时延分布 p_τ、擦除率 ε_ch、量化级数 L。问题与回答都是受限消息；回答是**有损、延迟、可能乱序**的码。信道预算与定位预算、交互预算共同构成总预算（定义 324）。迟到答案必须按事件时间处理，不得盲目套用当前信念。

**定义 320（时间戳信念账本 TBL）** 维护信念 `b_t(M, ρ)` 与事件时间水位线。更新规则：按 t_e 排序应用证据（乱序时要么有界回卷、要么丢弃过晚者）；过期证据按 ν_t 衰减；**应用前先过 G-valid**。目的：杜绝「用一条 t_e 很早的答案去确认 t_arr 时的状态」。

**定义 321（陈旧确认风险 SCR）** `SCR(g) = (1 − ν_t(g))·P(m 在 τ 内翻转)`。当 `SCR > ε_scr`：即使 VoI_τ 名义为正也不提问——因为提问会在旧模态上盖一个「已证实」的章。SCR 是 R69「问错更危险」在时间轴上的可计算版本。

**定义 322（指代劫持攻击 ℰ_refhijack 与延迟重放 ℰ_stale）** 攻击者不投毒答案，而投毒**问题的主语**：伪造地标/反射诱饵/GPS 欺骗，使所有诚实回答都共指到诱饵 ρ′；或重放/延迟注入旧回答（旧 t_e 冒充新）。故 `ℰ_RELAY = ℰ_FLUID × ℰ_refhijack × ℰ_stale`。

**定义 323（接地证书 J_RELAY）** `J_RELAY = (J_FLUID, co_ref_rate, H_ref_p95, σ_loc_p95, τ_p95, ν_t_min, SCR_p95, grounding_fail_cnt, channel_hash, relay_ver)`。Valid ⇔ Valid(J_FLUID) ∧ 接地失败率 ≤ τ_g ∧ 共指通过 ∧ SCR ≤ ε_scr。

**定义 324（定位–通信–探询三方预算）** 总预算在三处分配：降低 σ_loc（多视角/视差/靠近）、降低 τ（换信道/预测式提问）、消解模态（R69 的看/问/触）。最优分配使期望 `VoI_τ/c` 最大（带决策截止的背包/bandit）。**新问题：把一次交互花在「看得更清」上，还是花在「问得更快」上？**

**定义 325（接地退避链）** 若 G-valid 失败、SCR 越界或疑似指代劫持：不使用交互证据；若机载流策略仍能分辨模态则退回 FLUID（λ = λ_floor(U_ale + 未消解 U_epi)），否则退回 CALM 纯保守。**单调性**：退化时 λ 不减、k 不增，安全侧不弱于任一旧层。

**定义 326（时延同步的自适应采样）** 提问节奏与相干时间同步：不高于证据可保持有效的频率重复提问（避免用重复的过期证据自我强化）；高时延信道下用**预测式门控**——只有当预测残差（来自与当前证据正交的通道）足够大时才值得花一次往返。**警惕循环**：不能用被检验的同一模型去预测「是否需要检验」，否则残差恒小、永不提问。

# IP-264 REF：指代绑定与视觉定位误差传播（空间 Nyquist 门）
class ReferentBinder:
    def bind(self, z, pose_belief):
        R = self.detect_referents(z)                      # 候选指代 {ρ_i}
        post = self.associate(R, z, pose_belief)          # p(ρ | z, T)
        Sigma_rho = self.propagate(pose_belief, R)        # J Σ_pose Jᵀ + Σ_det
        sigma_loc = sqrt(max_eig(Sigma_rho))              # 等效点位置标准差
        return post, sigma_loc, spacing(R)                # H_ref, Δ_ref

# IP-265 LPU/TVOI：时延感知的 VoI，只计及时且有效的证据
def timed_voi(g, modes, w, chan, deadline):
    tau, p_arr = chan.latency_predict(g)                  # 往返延迟分布
    nu_t = exp(-tau / coherence_time(modes))              # 时间有效性
    ig   = entropy(w) - expected_entropy(w, g)            # 接地后的信息增益
    return p_arr * nu_t * ig - cost(g) - waiting_cost(tau)

# IP-266 CORE：共指验证（一致 ≠ 共指）
def co_reference_ok(evidences, pose_belief):
    for e in evidences:
        if not GINT(e.provenance): return False           # 溯源签名/时间戳
    for ei, ej in pairs(evidences):
        if p_coresident(ei.rho, ej.rho, pose_belief) < 1 - DELTA:
            return False                                  # 指代不一致
    # 正交定位交叉校验，防“一致地被劫持”
    return geom_pose_agree(semantic_landmarks(evidences),
                           geometric_slam(evidences), pose_belief)

# IP-267 主闭环（继承 R69，仅在证据准入处插入接地层）
def RELAY_RAS_round(M, obs):
    z, o = M.mtm.forward(...)
    c, U_cal, _ = M.cof.step(...)
    post, sig_loc, d_ref = M.ref.bind(z, M.pose_belief)   # 1) 指代与定位
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    # 2) 空间 Nyquist：指代不可辨时，先做 referent-first，不问模态
    ref_ok = (d_ref >= 2.0 * sig_loc) and (entropy(post) <= TAU_REF)
    g = None
    if ref_ok:
        g = M.mint.choose_interaction_timed(modes, o, M.budget, M.deadline)
    elif M.budget.allow_ref():
        g = M.ref.disambiguate(modes, post)               # 移动视差 / 看地标
    # 3) 执行并收集带溯源元的证据
    ev = []
    if g is not None:
        ans = M.cia.execute(g)                            # 带 CHAN 延迟
        ev  = [M.chan.attach_provenance(ans, g, post)]
    # 4) 接地准入：过期 / 不共指 / 疑似劫持 → 不可采信
    grounded = [e for e in ev if G_valid(e, post) and
                M.core.co_reference_ok([e], M.pose_belief)]
    stale    = len(grounded) < len(ev)
    scr      = M.tvoi.stale_confirmation_risk(g, modes) if g else 0.0
    if g is not None and (scr > EPS_SCR or not grounded):
        g = None; grounded = []                           # 不采信，回退
    if g is not None:
        U_epi = M.tbl.update_belief(modes, grounded)      # 时间戳账本
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if stale or scr > EPS_SCR:
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    mode = select_mode(modes, U_epi, lam)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_i.submit_async(g, post, sig_loc, grounded, scr)
    return k, lam, mode, (U_ale, U_epi)

## 3. 推导

**引理 19（指代混叠界）** 两个等方差高斯指代中心相距 Δ_ref、位置标准差 σ_loc，最近邻关联的错配概率 `P_mis = Q(Δ_ref / (2σ_loc))`。故：`Δ_ref = 2σ_loc ⇒ P_mis ≈ 0.159`；要 `P_mis ≤ 1%` 需 `Δ_ref ≥ 4.66σ_loc`。系：**当 σ_loc ≥ Δ_ref/2（空间 Nyquist 被破坏），任何模态级证据都是关于相邻错对象的；其信息增益上界退化为与该诱饵的互信息，VoI 可变为负。** 此时最优策略是 referent-first，而非模态提问。

**引理 20（时延过期与负信息）** 设模态翻转服从速率 `1/T_c` 的指数 hazard，则证据时效 `ν_t = e^{−τ/T_c}`，陈旧确认率 `(1−ν_t)`。证据表观信息增益 `≈ ν_t·IG`，而错误模态被强化的代价 `≈ (1−ν_t)·IG_wrong`。当 `ν_t < IG_wrong/(IG+IG_wrong)`（对称情形即 `ν_t < 1/2`，`τ > T_c ln 2`）期望后验熵不降反升——**问，比不问更差**。这把 R69 的「问错更危险」从定性口号变成可计算的 VoI_τ ≤ 0 判据。

**引理 21（一致性 ≠ 共指性：R69 上界的隐藏地板）** R69 引理 18 的错误界 `δ_p·ρ^{k−1}+ε_σ` 默认所有源共指同一对象。设指代被劫持概率 `P_hij`，且劫持时 k 个源全部诚实共指诱饵（一致但错）。则实际错误率 `≥ P_hij`，**与 k 无关**；增加证据源只会降低第二项，无法穿透 `P_hij` 地板。系：CORE（定义 318）是让 `P_hij` 可测、可拒的唯一办法；共指验证不是锦上添花，而是 R69 防御的结构性补洞。

**定理 18（RELAY 严格包含 FLUID ⊂ CALM）** 在 A99–A102 下，RELAY 的任意状态期望风险 ≤ FLUID ≤ CALM；当 `σ_loc→0, τ→0`（接地恒成立）时 RELAY 逐指令等于 FLUID；当 `VoI_τ ≤ 0`、G-valid 失败、SCR 越界或疑似劫持时逐指令等于 FLUID 的「never-interact」边界，再按定义 325 退回 CALM。**证明要点**：接地门只会拒绝证据，不引入新动作；被拒时 λ 取未消解 U_epi 的 floor，正是 FLUID 的保守分支；FLUID 的保守分支又等于 CALM（R69 定理 16）。故安全侧严格单调，效率侧仅在 G-valid 时获得 resolution bonus。

**定理 19（接地安全与无突变）** 未接地证据从不进入 TBL（定义 315、320），因此不存在「基于过期答案的自信执行」；迟到/乱序证据要么被有界回卷、要么被丢弃，误差不累积；指代优先动作（平移视差、注视、近距探询）同样过 C-RAS-WM 前缀认证（继承定义 302），且只改变「看哪个/何时看」不改变安全包络；退化时 λ 单调不降 ⇒ 控制连续、无突变；提交/换装不变式（R68 定理 15）保持。

## 6. 本轮最大风险

**一句话**：RELAY 的全部收益押在「系统对自身接地质量的自估是可信的」这一前提上——**σ_loc 与模态相干时间 T_c 本身就是估计量**；若视觉定位「自信地错」（Σ_pose 过度乐观）或世界比预期翻转得更快（T_c 被高估），接地门会**放行未接地证据**，系统于是在「我已验证共指」的错觉下持续拷问一个诱饵、或拿过期答案盖章——而 J_RELAY 仍显示 Valid。**接地门自己没被接地，它的失败是静默的**，比 R69 的「问错」更隐蔽。

**次级风险与缓解**：
1. **位姿协方差过度自信**（σ_loc 被低估 → 空间 Nyquist 假通过）→ 用 NEES/χ² 一致性检验在线标定 Σ_pose，协方差膨胀作为默认；E303/E313；
2. **相干时间误判**（世界比 T_c 更快）→ 用 hazard 在线更新 T_c，SCR 门控偏向保守；E305；
3. **指代劫持与延迟重放**（不投毒答案、只劫持主语/时相）→ CORE 正交定位交叉校验 + 溯源签名 + ℰ_refhijack/ℰ_stale 对抗；E306–E308；
4. **预测式提问的循环论证**（用被检验模型预测残差 → 永不提问）→ 残差必须来自与当前证据正交的通道，禁止自证；
5. **三方预算被定位吃光**（追精度而错过决策时窗）→ 带硬截止的分配，超时即回退，绝不无限追精度。

class ReferentBinder:
    def bind(self, z, pose_belief):
        R, post = self.detect(z), self.associate(z, pose_belief)
        Sigma_rho = self.propagate(pose_belief, R)       # J Σ_pose Jᵀ + Σ_det

def timed_voi(g, modes, w, chan, deadline):

    nu_t = exp(-tau / coherence_time(modes))
    ig   = entropy(w) - expected_entropy(w, g)
    return p_arr * nu_t * ig - cost(g) - waiting_cost(tau)

## 4. 推导

**引理 19（指代混叠界）** 等方差高斯指代相距 Δ_ref、位置标准差 σ_loc，最近邻错配 `P_mis = Q(Δ_ref/(2σ_loc))`；`Δ_ref=2σ_loc ⇒ 15.9%`，`P_mis≤1%` 需 `Δ_ref≥4.66σ_loc`。系：`σ_loc ≥ Δ_ref/2` 时任何模态证据都关于相邻错对象，VoI 可转负；此时 referent-first 最优。

**引理 20（时延过期与负信息）** 指数 hazard 下 `ν_t = e^{−τ/T_c}`；表观增益 `≈ν_t·IG`，强化错模态代价 `≈(1−ν_t)·IG_wrong`；当 `ν_t < IG_wrong/(IG+IG_wrong)`（对称即 τ > T_c ln2）期望后验熵反升——问不如不问。把「问错更危险」变成 `VoI_τ≤0` 判据。

**引理 21（一致 ≠ 共指：R69 的隐藏地板）** R69 界 `δ_p·ρ^{k−1}+ε_σ` 默认共指同一对象。设劫持概率 P_hij、劫持时 k 源全部诚实共指诱饵，则错误率 `≥ P_hij` 且**与 k 无关**；加源只压第二项，穿不透地板。系：CORE 是唯一能测/拒 P_hij 的机制。

**定理 18（RELAY 严格包含 FLUID ⊂ CALM）** A99–A102 下 RELAY 期望风险 ≤ FLUID ≤ CALM；`σ_loc→0,τ→0` 时逐指令等于 FLUID；`VoI_τ≤0`、G-valid 失败、SCR 越界或疑似劫持时逐指令等于 FLUID 的 never-interact 边界，再退 CALM。接地门只拒证据不加新动作，安全侧严格单调，效率侧仅在 G-valid 时获 resolution bonus。

**定理 19（接地安全与无突变）** 未接地证据从不入 TBL ⇒ 无「基于过期答案的自信执行」；乱序/迟到有界回卷或丢弃、误差不累积；指代优先动作过 C-RAS-WM 前缀认证，只改「看哪个/何时看」不改安全包络；退化时 λ 单调不降 ⇒ 控制连续、无突变；提交/换装不变式（R68 定理 15）保持。

**A99–A102** A99 空间 Nyquist：`Δ_ref ≥ 2σ_loc` 且共指可辨识；A100 时间 Nyquist：`T_c ≥ 2τ_p95`；A101 溯源完整性：攻击者不能在不被检测下同时伪造指代 id 与时间戳；A102 流策略条件 Lipschitz（继承 R69 A98）。

## 7. 本轮最大风险

**一句话**：RELAY 的全部收益押在「系统对自身接地质量的自估可信」这一前提上——**σ_loc 与相干时间 T_c 本身是估计量**；若视觉定位「自信地错」（Σ_pose 过度乐观）或世界比预期翻转更快（T_c 被高估），接地门会放行未接地证据，系统在「我已验证共指」的错觉下持续拷问诱饵或拿过期答案盖章，而 J_RELAY 仍显示 Valid——**接地门自己没被接地，失败是静默的**，比 R69 的「问错」更隐蔽。

**次级风险与缓解**：位姿协方差过度自信（NEES/χ² 在线标定 + 协方差膨胀默认，E303/E313）；相干时间误判（hazard 在线更新 T_c，SCR 偏向保守，E305）；指代劫持与延迟重放（CORE 正交交叉校验 + 溯源签名 + ℰ_refhijack/ℰ_stale，E306–E308）；预测式提问循环论证（残差须来自正交通道，禁止自证）；三方预算被定位吃光（带硬截止分配，超时即回退）。
