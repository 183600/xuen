## 0. 直觉与动机

**灵感 1（技术融合 → 三锚三角测量，而非单源自证）**
直觉：单一参照系无法自证。计量学的老规矩是任何测量都要溯源到一条不断链的基准；而「自标定」本质上是用同一把尺子校准自己。R68 的 COF 再精巧，也只是在「机器记忆」这一条基线上做相对对齐，其信息视界被滤波器存储长度 T_m ≈ 1/ω_cal 截断。比 T_m 更慢的故障，在机器看来与「参照系漂移」数学同构——**不可分辨**。破解只有一条路：引入**更长基线且统计独立**的第二参照。物理标准（出厂计量溯源，月级）、仿真先验（Sim2Real，可注入已知漂移）、人的长时记忆（天级，能说「最近它手感不对」）三者基线长度不同、失效模式也不同。三角测量：三条基线两两不一致的方向，才指向真实世界变化；一致的方向可能只是共同偏差。

**灵感 2（交互设计 → 交互不是界面，是测量仪器）**
直觉：传统把交互当「输出通道」，即把 λ 显示给人。交互设计视角反过来说：**交互首先是输入通道**——人的判断、迟疑、纠正、指认都是关于世界的测量，只是这台「人肉传感器」有偏置（锚定、回忆偏差）、有噪声（疲劳）、会策略性迎合（偷懒/讨好），而且会被**你给他看的东西污染**。经典结论：先展示机器估计再问人，人的回答会被锚定到机器值，独立性被吃掉。于是「透明」与「证据独立」天然冲突——这给出一个真正的设计张力，而不是又加一个模块。交互设计的任务变成：设计查询协议（盲问 → 揭示 → 复核）、用适当评分规则（proper scoring rule）激励诚实、用延迟验证结算可信度、把信任维持在「校准带」内。

**灵感 3（两灵感合流 → TRIAD-RAS 六组件）**
技术融合给出「三锚 + 去相关融合」的证据结构，交互设计给出「主动查询 + 信任校准 + 共同地基」的采集与治理结构。合成闭环：
1. **PAF Provenance-Aware Fusion**：带溯源标签的证据图，按有效样本数 n_eff 折扣相关证据，杜绝「一个见证人说了两遍」被当成两个独立见证；
2. **HTM Human Testimony Model**：结构化人证本体（相对比较/异常标记/指认/纠正/偏好）+ 锚定与回忆偏差显式建模；
3. **IAP Interaction Anchor Protocol**：以信息增益为目标的 POMDP 查询策略，**盲问优先**、受打扰预算与信任校准约束；
4. **TCG Trust Calibration Governor**：从接管率/响应时延/复核率估计信任，只允许把信任拉回校准带，禁止以「接受率」为奖励；
5. **CGA Common-Ground Auditor**：审计机器指代与人类指代是否对齐，失配即判「不可通信」而非「故障」；
6. **TRIAD† 继承核**：CALM-RAS / SimRAS / RAS-WM† 全部保留，λ 与 k 由 (机器后验, 人证, 共同地基, 信任) 共同门控。

**灵感 4（对症下药：解开 R68 的缓变故障死结）**
- **长基线外锚打破自指**：慢故障在机器端被 COF 吸收（机器以为「越来越准」），但在人的长时参照里仍残留（人觉得「最近不对」）→ 跨锚不一致统计量 D_triad 成为新的检出通道，其灵敏度不由 ω_cal 决定，而由外锚基线 T_h 与独立性 κ_h 决定。

- R67「黑箱前瞻误放宽」：人证可作为对 WM 前瞻的独立核对（「你预测它要往左，人却说往右」），D_triad 同时校准前瞻。

## 1. 形式化定义（增量：定义 293–308）

**定义 293（TRIAD-RAS 总览）** TRIAD-RAS = (PAF, HTM, IAP, TCG, CGA, TRIAD†)。四条不变式：
(i) **外部锚点原则**：任何超出机器自指视界 T_m 的结论，必须由至少一个独立锚点支撑，否则判 UNGROUNDED（不是故障，而是「不可知」）；
(ii) **证据独立性原则**：融合权重必须按溯源去相关，相关证据按有效样本数 n_eff 折扣；
(iii) **盲问优先原则**：采集人的独立判断前不得揭示机器后验，揭示后置于回答之后（delayed reveal）；
(iv) **信任校准不变量**：交互策略不得以最大化接受率/顺从率为目标，只允许把信任维持在带内。

**定义 294（三锚与视界）** 锚点集 A = {A_phys, A_sim, A_human}。锚 a 有基线长度 T_a（可分辨的最慢时间尺度）与独立性 κ_a ∈ [0,1]（与机器残差通道的相关系数）。机器自指视界 T_m = 1/ω_cal。若故障时间尺度 τ_f > T_m 且不存在独立锚满足 T_a > τ_f、κ_a < κ̄，则该故障**结构不可观测**（structural unobservability）。

**定义 295（人证通道）** h_t = (h_type, h_content, h_conf)。h_type ∈ {相对比较, 异常标记, 指认, 纠正, 偏好}；观测模型
p(h_t | w_t, c_t, H_t) = 𝒩(g_a(w_t) + β_anc·(μ_M − μ_prior)·1[revealed] + β_rec·m_recall(t), σ_h²)，
其中 μ_M 为机器后验，β_anc 为锚定敏感度，β_rec 为回忆偏差系数。γ_h 为策略性说谎倾向，通过延迟验证结算（定义 302）。

**定义 296（锚定污染与揭示比率）** 揭示比率 ρ_reveal ∈ [0,1]（0=盲问，1=先展示机器后验再问）。人证有效独立性
κ_h(ρ) = 1 − α₀·(1 − ρ_reveal)，α₀ ∈ [0,1] 为人的锚定易感度。κ_h 越高，人证与机器证据越同源，可提供的新信息越少。

**定义 297（溯源标签与去相关融合）** 每条证据 e 带溯源 π(e) ⊆ {sensor, sim, human} 与共享源标记。n 条证据平均两两相关 ρ̄ 时，有效样本数
n_eff = n / (1 + (n−1)·ρ̄)。
融合后验 ∝ ∏_e p_e^{w_e}，w_e ∝ 1/n_eff(π(e))（再归一化）——语义：**同源多证 = 一证**。当所有证据同源（ρ̄→1）时 n_eff→1，融合退化为单源，避免虚假置信。

**定义 298（三角不一致统计量）** 在锚点公共子空间上，令 δ_machine = 机器相对其短期参照的偏差（被 COF 标定后≈0），δ_human = 人相对其长时参照的偏差，δ_sim = 仿真先验偏差。三角不一致统计量
D_triad = ‖δ_machine − δ_human‖² + ‖δ_human − δ_sim‖² + ‖δ_sim − δ_machine‖²（加权最小二乘残差）。
归因方向：(a) 三锚两两不一致且无共同方向 ⇒ 真实世界变化（真故障/真漂移）；(b) 两锚一致、一锚偏离 ⇒ 偏离锚自身漂移（可能是人的偏置，也可能是机器吸收）；(c) 三锚全一致 ⇒ 无变化或**共同偏差**（需扰动实验或第四锚才能分辨）。

**定义 299（交互锚定协议 IAP）** 部分可观测决策过程 M_IAP = (S, Q, T, R)：状态 s = (c_t, H_t, g_t, u_t)（标定、故障、共同地基、信任）；动作 q ∈ Q = {盲问相对比较, 异常标记请求, 指认请求, 延迟揭示+复核, 解释, 交还控制, 不打扰}；目标
max_π E[ Σ_t ( I(c_t; h_t | q_t) − c_int·1[q_t ≠ 不打扰] − c_trust·miscal(u_t) ) ]，
subject to 打扰预算 Σ q_t ≤ B 与盲问约束（定义 293-iii）。实时流只执行「不打扰」分支；查询异步排队。

**定义 300（信任校准调节器 TCG）** 信任 u_t ∈ [0,1] 由行为遥测（接管率、响应时延、注意力占比、主动复核率）经卡尔曼/逻辑模型估计；校准带 [u_lo, u_hi]。失配代价
miscal(u) = max(0, u − u_hi) + max(0, u_lo − u)。
TCG 只通过「透明度、挑战查询、交还控制」把 u 拉回带内；**严禁**以接受率、顺从率、满意度为奖励（否则推向过度信任）。

**定义 301（共同地基审计 CGA）** 共同地基匹配度 g_t ∈ [0,1] 由机器与人对实体/区域/事件三元组的指代对齐度给出。失配率 r_ground(t) = 1 − g_t。当 g_t < τ_g 时触发「重新对齐」交互（指认/复述/演示），并冻结高风险动作——判为**不可通信**，而非故障。

**定义 302（延迟验证与诚实结算）** 人证在 τ_verify 后，用当时已揭示的世界状态按适当评分规则（Brier 或 log loss）结算。累积分数 s_h 进入人证权重 w_human。由于 proper scoring rule 的性质，长期收益下诚实报告为（弱）占优策略；策略性撒谎不占优。

**定义 303（三角风险估计 TRE）** 最终风险与动作前缀不只看机器后验，而看四元组：
λ_triad = f_PAF(joint_post, D_triad, g_t, u_t)，k_triad = g_PAF(k_ras, U, r_ground, u_t)。
任何锚点缺失或 UNGROUNDED ⇒ 保守回退：λ ≥ λ_floor，k ≤ k_cal_shrink，且标记 `ungrounded=true` 写入证书。

**定义 304（TRIAD 干扰集）** ℰ_TRIAD = ℰ_CALM × ℰ_ground × ℰ_testimony × ℰ_trust；
ℰ_ground = {误指代、共同地基发散、手势指称歧义}；
ℰ_testimony = {策略性误报、回忆偏差、锚定污染、逢迎}；
ℰ_trust = {过度信任（橡皮图章）、信任不足（接管抖动）、信任振荡反馈环}。

**定义 305（J_TRIAD 证书）** J_TRIAD = (J_CALM, anchor_provenance_vec, D_triad, g_t, u_t, s_h, ungrounded_flag, triad_ver)。
Valid ⇔ Valid(J_CALM) ∧ 三锚溯源非空 ∧ g_t ≥ τ_g ∧ ungrounded_flag = false ∧ 信任在校准带内（或已记录偏离）。

**定义 306（管线）** 离线：出厂物理溯源（A_phys）→ Sim2Real 漂移注入标定（A_sim）→ 人证本体与评分规则初始化。在线：机器自指环（CALM-RAS）照常运行；异步 IAP 按预算发起查询，TCG/CGA 持续更新；每轮把 (D_triad, g_t, u_t) 融入 TRE 并写入 J_TRIAD。

**定义 307（有效视界扩展）** 记独立锚集合 A_ind = {a : κ_a < κ̄}。系统有效视界
T_eff = max( T_m , max_{a∈A_ind, T_a > T_m} T_a·(1 − κ_a) )。
语义：外锚把可观测时间尺度按独立性折扣地延长；κ_a→1（同源）时扩展归零，退回 T_m——这正是 R68 的盲点边界。

**定义 308（透明–独立–信任三难前沿）** 三目标：透明 T = H(μ_M)（向人传递机器信念）、证据独立 I = 1 − κ_h(ρ_reveal)、信任校准 C = 1 − miscal(u)。它们的可达集边界满足
I(T) ≥ I_0 − c₁·T（透明吃掉独立），C(T) ≥ C_0 − c₂·(T − T*)²（过少或过多透明都伤校准）。
**盲问后揭示（ρ 时间上先 0 后 1）** 可同时取得较高 I 与较高 T——顺序，而非总量，是解三难的关键。

# IP-253 PAF：溯源感知、去相关融合
class ProvenanceAwareFusion:
    def fuse(self, evidence):                    # evidence: [(p_e, provenance, shared_tag)]
        groups = group_by_shared_source(evidence) # 同一相机/同一场景假设归组
        weights = {}
        for g in groups:
            rho = mean_pairwise_corr(g)
            n_eff = len(g) / (1 + (len(g)-1)*rho) # 定义 297 design effect
            for e in g:
                weights[e.id] = 1.0 / n_eff
        return normalize({e.id: (e.p ** weights[e.id])
                          for e in evidence}), weights

class InteractionAnchorProtocol:
    QUERIES = ['blind_compare','anomaly_flag','point','delayed_reveal_recheck',
               'explain','handover','silent']
    def choose(self, belief, budget, trust_band):
        best, best_val = 'silent', -1e9
        for q in self.QUERIES:

        lam = max(lam, LAM_FLOOR); k0 = min(k0, K_CAL_SHRINK)
    k = k0

    # 6) 异步：查询 + 信任治理 + 审计 + 影子提交
    q = M.iap.choose(M.belief(c,U,g,u), M.budget, (U_LO, U_HI))
    if q != 'silent': M.iap.enqueue(q)                     # 实时流不阻塞
    M.tcg.step(M.telemetry(obs)); M.cga.log(cg)
    M.vqa_c.submit_async(None, {'D_triad': D_triad, 'g': g, 'u': u, 'cause': cause})
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)

    M.j_triad.write(dict(J=M.calm.j_calm(), anchors=['phys','sim','human'] if delta_human
                         else ['phys','sim'], D=D_triad, g=g, u=u, ungrounded=(cause=='UNGROUNDED')))
    return k, lam, fused, (D_triad, cause)
```

## 3. 推导

**引理 16（自指视界不可观测性）** 设机器标定通道为带宽 ω_cal 的低通/一阶跟踪器，记忆视界 T_m = 1/ω_cal。机器残差只观测到「真实变化 − 参照系变化」之差 r(t) = δ_true(t) − δ_ref(t)。若故障时间尺度 τ_f > T_m（频谱支撑落在截止频率以下），则对任意观测 r 与任意 δ_ref，都存在 δ_true = r + δ_ref 与之观测等价。故该故障与参照系漂移**不可辨识**；R68 的缓变故障盲点是结构性的，不是调参能消除的。

**引理 17（三角测量视界扩展）** 设存在独立外锚 A_h，其参照基线 T_h > τ_f、与机器通道独立性 κ_h(ρ) < 1，观测 y_h = δ_true + ε_h（相对其长时参照）。跨锚差 d = y_h − E_machine[δ | history]；由于机器已把 δ_true 吸收进 ĉ，E_machine[δ]≈0，故 d 的均值仍含 δ_f，检测 SNR ≈ |δ_f|·√(1 − κ_h(ρ)) / σ_h。**该通道对慢故障的响应不被 ω_cal 抑制**；T_eff 由定义 307 给出。系：外锚把「不可观测」变为「可观测」，代价是查询延迟、打扰成本与人对偏置的鲁棒性。

**引理 18（相关证据重复计数上界）** 设 n 条近独立假设的证据平均两两相关 ρ̄，真实后验方差为 (σ²/n)·(1+(n−1)ρ̄)。若按独立融合（n_eff = n），后验方差被低估 [1+(n−1)ρ̄] 倍，导致过度自信；在可靠性图上的期望校准误差 ECE ≳ Φ⁻¹(1−δ)·(√[1+(n−1)ρ̄] − 1)·σ/√n。按定义 297 用 n_eff 折扣可恢复校准。系：这是 R68 引理 15「同源共模抵消」的**反面**——同源在检验统计量里抵消噪声是有利的，在证据融合里把同源当独立则是灾难性的；两者必须用溯源标签区分处理。

**定理 16（三角测量端到端风险一致性）** 在 A87–A94 与 A95–A98（锚点可靠性与独立性假设）下：
1. P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + **α_ground + α_testimony + α_trust**；
2. UNGROUNDED（任一锚缺失/共同地基破裂/人证过期）⇒ λ ≥ λ_floor ∧ k ≤ k_cal_shrink——**不可知永远导向保守**；
3. 存在独立长基线外锚 ⇒ 引理 16 的不可观测集被引理 17 的检出域覆盖（T_eff ≥ τ_f 时），R68 的缓变故障死结被打开；
4. 相关证据若按定义 297 折扣，则融合后验校准误差 ≤ 由引理 18 给出的界；若误按独立处理，则退化为过度自信（并可能越过安全阈值）。

**定理 17（透明–独立 Pareto 前沿与顺序解）** 设人证 h = w + α₀(1−ρ_reveal)(μ_M − μ_prior) + ε。把机器后验揭示放在提问前（ρ_reveal=1）使 I(h; w) 下降 α₀ 比例，但提升透明 T；盲问（ρ_reveal=0）最大化 I 却牺牲透明。若透明的边际价值递减、打扰成本线性，则存在内点最优 ρ* ∈ (0,1)。**盲问后揭示**（先 ρ=0 取证据，再 ρ=1 传信念）在时间维度上把 ρ 拆开，可在不牺牲 I 的前提下取得接近全额 T——定理说明**解的维度是「时序」而非「总量」**。

**定理 18（信任校准稳定性 / 反橡皮图章）** 若 TCG 以接受率/顺从率为奖励，则系统收敛到**过度信任均衡**：人停止主动复核 ⇒ 人证独立性退化为 κ_h→1 ⇒ T_eff→T_m ⇒ 外锚塌陷，系统退回 R68 盲点（且因「有人同意」而更自信）。为维持校准，必须保持一个人证验证行为的「存活率」；存在最小挑战查询率 q_min ∝ 1/T_h，使得在该频率下人的复核行为不被遗忘。配合定义 302 的延迟验证，诚实报告为弱占优策略，故 q_min 可达且不诱导撒谎。

## 6. 本轮最大风险

**一句话**：TRIAD-RAS 把安全性的最后一环押在「人」这个外锚上，而人恰恰是唯一会疲劳、会逢迎、会被机器显示锚定、会被信任校准环养成橡皮图章、且在无人值守时直接缺席的传感器——**信任校准本身可以制造出「有人同意」的假象，让外锚在需要它时悄悄退化为同源回声（κ_h→1、T_eff→T_m），系统于是在更自信的语气里退回 R68 的自指盲点**。

**次级风险与缓解**：

5. **共同地基攻击/误指**：指代对齐被诱导 → CGA 冻结高风险动作 + 复述/指认再对齐 + E300；
6. **交互延迟与可用性**：查询打扰影响任务完成 → 打扰预算 + 异步 + E296 权衡；人缺席时保守降级而非静默。

class ProvenanceAwareFusion:
    def fuse(self, evidence):                     # [(p_e, provenance, shared_tag)]
        groups = group_by_shared_source(evidence)
        w = {}
        for g in groups:
            rho   = mean_pairwise_corr(g)
            n_eff = len(g) / (1 + (len(g)-1)*rho)  # design effect
            for e in g: w[e.id] = 1.0 / n_eff
        return normalize({e.id: e.p ** w[e.id] for e in evidence}), w

# IP-262 主闭环
def TRIAD_RAS_round(M, obs):
    k0, lam0, joint_post, (c, U) = M.calm.calm_ras_round(obs)   # 继承自指环
    d_m = residual_after_calibration(obs, c)                    # ≈0（被吸收）
    d_h = M.htm.last_human_delta(obs) if M.htm.fresh else None
    d_s = M.sim_prior.delta(obs)
    if d_h is not None: D_triad, cause = triangle_inconsistency(d_m, d_h, d_s)
    else:               D_triad, cause = float('inf'), 'UNGROUNDED'
    cg = common_ground_check(M.scene.refs, M.htm.refs)          # IP-257
    fused, _ = M.paf.fuse([(joint_post, {'sensor','sim'}, M.scene.src),
                           (M.htm.evidence, {'human'}, M.scene.src)])  # IP-253
    lam = M.tre.risk_scale(fused, D_triad, cg['g'], M.tcg.u)    # IP-258
    if cause == 'UNGROUNDED' or not cg['grounded']:
        lam = max(lam, LAM_FLOOR); k0 = min(k0, K_CAL_SHRINK)
    q = M.iap.choose(M.belief(c, U, cg['g'], M.tcg.u), M.budget, (U_LO, U_HI))
    if q != 'silent': M.iap.enqueue(q)                          # 异步，不阻塞
    M.tcg.step(M.telemetry(obs)); M.cga.log(cg)
    M.vqa_c.submit_async(None, {'D_triad': D_triad, 'g': cg['g'],
                                'u': M.tcg.u, 'cause': cause})
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)
    M.j_triad.write(dict(J=M.calm.j_calm(),
                         anchors=['phys','sim','human'] if d_h else ['phys','sim'],
                         D=D_triad, g=cg['g'], u=M.tcg.u,
                         ungrounded=(cause == 'UNGROUNDED')))
    return k0, lam, fused, (D_triad, cause)
```

## 4. 推导

**引理 16（自指视界不可观测性）** 标定通道为带宽 ω_cal 的低通，记忆视界 T_m=1/ω_cal。机器残差只观测 `r=δ_true−δ_ref`。若 τ_f>T_m，则对任意 r 与 δ_ref 都存在 δ_true=r+δ_ref 与之观测等价 ⇒ 慢故障与参照系漂移不可辨识。R68 的缓变盲点是结构性的。

**引理 17（三角测量视界扩展）** 独立外锚（T_h>τ_f、κ_h<1）给 y_h=δ_true+ε_h；机器已把 δ_true 吸收（E[δ]≈0），故跨锚差 d 仍含 δ_f，SNR≈|δ_f|·√(1−κ_h)/σ_h。**该通道对慢故障不被 ω_cal 抑制**；T_eff 见定义 307。

**引理 18（相关证据重复计数上界）** n 条证据平均相关 ρ̄ 时真实后验方差 (σ²/n)(1+(n−1)ρ̄)；按独立融合会低估 [1+(n−1)ρ̄] 倍，ECE 随之上升；用 n_eff 折扣恢复校准。这是 R68 引理 15「同源共模抵消」的**反面**：检验统计量里同源抵消噪声有利，证据融合里把同源当独立是灾难，必须用溯源标签区分。

**定理 16（三角端到端风险一致性）** A87–A94、A95–A98 下：`P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_ground+α_testimony+α_trust`；UNGROUNDED ⇒ λ≥λ_floor ∧ k≤k_cal_shrink；有独立长基线外锚 ⇒ 引理 16 不可观测集被引理 17 检出域覆盖；按 n_eff 折扣则融合校准误差受引理 18 约束。

**定理 17（透明–独立 Pareto 前沿与顺序解）** 人证 h=w+α₀(1−ρ_reveal)(μ_M−μ_prior)+ε。先揭示降低 I(h;w) 但提升透明 T；盲问反之。盲问后揭示（时间上先 ρ=0 后 ρ=1）可在不牺牲 I 的前提下取得接近全额 T——解的维度是「时序」而非「总量」。

**定理 18（信任校准稳定性 / 反橡皮图章）** 以接受率为奖励 ⇒ 收敛到过度信任均衡：人停止复核 ⇒ κ_h→1 ⇒ T_eff→T_m ⇒ 外锚塌陷，系统退回 R68 盲点且更自信。需最小挑战查询率 q_min ∝ 1/T_h 维持复核行为；配合延迟验证，诚实报告为弱占优策略。

## 8. 本轮最大风险

**一句话**：TRIAD-RAS 把安全性的最后一环押在「人」这个外锚上，而人恰恰是唯一会疲劳、会逢迎、会被机器显示锚定、会被信任校准环养成橡皮图章、且在无人值守时直接缺席的传感器——**信任校准本身可以制造出「有人同意」的假象，让外锚在需要它时悄悄退化为同源回声（κ_h→1、T_eff→T_m），系统于是在更自信的语气里退回 R68 的自指盲点**。

**次级风险与缓解**：锚定污染（盲问 + delayed reveal + E289）；证据重复计数（溯源标签 + n_eff + E288）；橡皮图章（禁用接受率奖励 + q_min + E291/E292）；人证过期（新鲜度门控 + 过期即 UNGROUNDED）；共同地基攻击（CGA 冻结 + 复述再对齐 + E300）；交互延迟（打扰预算 + 异步 + E296，缺席保守降级）。
