### 第 4 轮灵感驱动研究记录（承接第 3 轮）

**灵感词**：成本控制、语言指令

**直觉与动机**：

第 3 轮的 KT-MPC/KTCG 已把「常识—证书」做成九证准入，但它默认了两件从未被计价的事：**证书是免费的，语言是精确的**。

1. **成本控制**：在真实双足平台上，验证一条常识证书要采样、求解、比对模型；跑一次九证准入要 20ms 量级算力；每一次为了安全而收紧的约束都要多耗一点力矩。电池、算力、散热、时间都是有限预算。若把这些当作「零成本」，那么「已认证安全」其实只对一个「永远不会为认证本身耗尽资源」的机器人成立。成本不该只是代价函数里的一项权重，而应是**认证过程自身的预算约束**：先保证「还有余力继续认证」，才谈得上「认证结果安全」。直觉上，安全不是一个瞬时谓词，而是一条**随时间可续的承诺**——续不起，就失效。

2. **语言指令**：操作员说「慢一点，绕过前面的水坑」。这不是形式规范：哪个水坑？多慢？「绕过」是左绕还是右绕？语言必须先被**落地（grounding）** 成形式约束，而落地本身要花预算——追问、采样多种解释、试运行、校准。现有框架没有记录「这条约束从哪句话来、是否忠实于人的意图」。一个被错误落地的指令，会让系统在「完全合规」的表象下做错事。

**关键洞见**：成本与语义是耦合的。固定预算下，不可能解析所有歧义、也不可能每一步重验所有证书；于是系统必须在「买确定性」与「买语义」之间做分配。把预算想成一只**安全钱包**：每次验证是买一份确定性，每次追问是买一份语义；理性代理先买「每焦耳安全增益最大」的那一份。危险恰在这里——一份便宜但错误的语义，看起来像是一笔划算的买卖。

因此本轮不造新控制器，而是给「认证」与「语义」同时记账：用**预算屏障**守住资源，用**实时调度**守住证书新鲜度，用**信息价值**守住语义解析，用**权限单调性**保证语言只能收缩、不能扩张已认证的可行集。换句话说：把「认证」从一次性动作变成**可续租的服务**，把「语言」从真理来源降级为**受预算约束的建议来源**。

**形式化目标（增量）**：
1. 定义语言落地证书 LGC = (ℓ, {(φ_j, p_j)}, a, δ_amb, prov)：语言到形式规范的后验分布；歧义 1−max p_j > δ_amb 时**弃权**而非猜测。
2. 定义成本控制证书 CCC：资源状态 B、成本率 c(x,u)、预算屏障 B_{k+1} ≥ B_min + (1−α)(B_k − B_min)，保证预算永不击穿储备。
3. 定义随时证书调度器 ACS：陈旧度 τ_i、有效视界 ν_i、验证成本 v_i；关键证书集利用率 U = Σ v_i/ν_i ≤ 1 时 EDF 可调度。
4. 定义语言权限单调性：a(ℓ) ≤ 1 时 Exec_v29(ℓ) ⊆ Exec_v28，语言永不扩张安全集。
5. 定义信息价值门控：仅当 VoI(q) = 预期风险下降 − 查询成本 > 0 才解析歧义。
6. 定义 IG-MPC 与 BIG-CG：在 v28 可行集内优化语言目标 + 解释鲁棒风险 + 预算约束；Exec_v29 = Exec_v28 ∩ Fil_lang ∩ Fil_budget ∩ Fil_sched ⊆ Exec_v28。
7. 可检验命题：预算屏障下预算耗尽事故为 0；弃权策略把灾难性误解执行率降低 ≥80%（代价是追问率上升）；U<1 时关键证书陈旧违规为 0；预算收紧时「廉价解释偏好」会可测量地上升。

**本轮最大风险**：**成本诱导的语义漂移**——在预算压力下，落地与验证的联合回路会系统性地偏向「容易验证/便宜」的解释，而不是「人真正想要」的解释；所有证书都成立，但成立的是错误规范。系统表现完全合规，人的意图却被悄悄替换，而且没有任何一张证书会报警，因为每张证书都在为它自己那份（错误的）规范背书。

**设计原则 P38（预算即安全边界）**：任何「已认证」结论都附带一个有效期与一份资源凭证。没有预算凭证的证书不得进入准入；预算余量低于储备 B_min 时，系统必须 fail-safe 停机，而不是继续用超支换取任务完成。

**设计原则 P39（语言从属安全）**：自然语言只能塑造目标或收缩可行集，绝不扩张 Exec_v28。越权指令（a ≥ 2）一律转人工确认，不得由控制器自行解释执行。

### IP-467 Language Grounding Certificate (LGC)

```python
from dataclasses import dataclass, field
from typing import Callable, Any


@dataclass
class FormalSpec:
    """语言落地后的形式规范片段（时序逻辑/代价约束的轻量封装）"""
    name: str
    predicate: Callable[[Any], bool]      # 状态或轨迹谓词
    kind: str = "constraint"              # constraint | objective | cost
    weight: float = 1.0


@dataclass
class LanguageGroundingCertificate:
    """LGC：把一句自然语言指令落地为带后验的形式规范分布"""
    utterance: str
    interpretations: list[tuple[FormalSpec, float]]   # {(φ_j, p_j)}, Σp_j=1
    authority: int = 1                     # 0=建议 1=硬约束 2=越权
    delta_amb: float = 0.10                # 可容忍歧义
    provenance: dict = field(default_factory=dict)   # 来源、时间、校准版本

    def ambiguity(self) -> float:
        return 1.0 - max(p for _, p in self.interpretations)

    def is_adequate(self) -> bool:
        return self.ambiguity() <= self.delta_amb

    def best(self) -> FormalSpec:
        return max(self.interpretations, key=lambda t: t[1])[0]

    def plausible_set(self) -> list[FormalSpec]:
        """累计概率质量达到 1-delta_amb 的最小解释集合 I_δ(ℓ)"""
        ranked = sorted(self.interpretations, key=lambda t: t[1], reverse=True)
        out, mass = [], 0.0
        for spec, p in ranked:
            out.append(spec)
            mass += p
            if mass >= 1.0 - self.delta_amb:
                break
        return out

    def interpretation_risk(self, traj,
                            severity: Callable[[FormalSpec], float]) -> float:
        """对高概率解释集取最坏违规代价（分布鲁棒）"""
        risk = 0.0
        for spec in self.plausible_set():
            if not all(spec.predicate(x) for x in traj):
                risk = max(risk, severity(spec))
        return risk


class LanguageGroundingCompiler:
    """受约束的语义解析器 + 概率校准；校准失败即拒答"""

    def __init__(self, parser: Callable, calibrator,
                 delta_amb: float = 0.10):
        self.parser = parser
        self.calibrator = calibrator
        self.delta_amb = delta_amb

    def compile(self, utterance: str) -> LanguageGroundingCertificate | None:
        raw = self.parser(utterance)                  # [(φ, score)]
        if not raw:
            return None
        probs = self.calibrator.normalize(raw)        # 校准到概率单纯形
        if not self.calibrator.is_calibrated(probs):  # 校准失效 → 不猜
            return None
        return LanguageGroundingCertificate(
            utterance=utterance,
            interpretations=list(zip([r[0] for r in raw], probs)),
            authority=self._infer_authority(utterance),
            delta_amb=self.delta_amb,
            provenance={"parser": type(self.parser).__name__,
                        "calibrator": type(self.calibrator).__name__},
        )

    def _infer_authority(self, u: str) -> int:
        if any(k in u for k in ("必须", "务必", "must", "不许")):
            return 1
        if any(k in u for k in ("覆盖", "override", "无视安全", "强制")):
            return 2
        return 0
```

### IP-468 Cost Control Certificate (CCC)

```python
@dataclass
class CostControlCertificate:
    """CCC：把资源预算作为一阶状态，用离散屏障函数守住下限"""
    B0: float
    B_min: float
    alpha: float = 0.05        # 每步最多花掉剩余余量的 alpha
    w_act: float = 1.0
    w_ver: float = 1.0
    w_query: float = 1.0
    w_comp: float = 1.0

    def __post_init__(self):
        if self.B0 <= self.B_min:
            raise ValueError("初始预算必须高于 fail-safe 储备")
        self.B = self.B0
        self.ledger = []       # 成本流水，供事后审计

    def step_cost(self, c_act=0.0, c_ver=0.0,
                  c_query=0.0, c_comp=0.0) -> float:
        return (self.w_act * c_act + self.w_ver * c_ver
                + self.w_query * c_query + self.w_comp * c_comp)

    def barrier_allows(self, cost: float) -> bool:
        # 离散 CBF: B' - B_min >= (1-alpha)(B - B_min)
        return cost <= self.alpha * (self.B - self.B_min)

    def commit(self, cost: float, tag: str = "") -> bool:
        if cost < 0.0 or not self.barrier_allows(cost):
            return False
        self.B -= cost
        self.ledger.append((tag, cost, self.B))
        return True

    def is_alive(self) -> bool:
        return self.B > self.B_min

    def horizon_estimate(self, mean_cost_per_step: float) -> float:
        """在当前策略下的剩余可运行步数下界（几何级数求和）"""
        if mean_cost_per_step <= 0:
            return float("inf")
        return (self.B - self.B_min) / mean_cost_per_step
```

### IP-469 Anytime Certificate Scheduler (ACS)

```python
@dataclass
class CertificateRecord:
    name: str
    verify_cost: float        # v_i
    validity_horizon: int     # ν_i（步）
    severity: float           # s_i
    critical: bool
    last_verified: int = 0

    def staleness(self, k: int) -> int:
        return k - self.last_verified

    def is_valid(self, k: int) -> bool:
        return self.staleness(k) <= self.validity_horizon


class AnytimeCertificateScheduler:
    """ACS：把证书验证当成可抢占的实时任务来调度"""

    def __init__(self, records: list[CertificateRecord]):
        self.records = records

    def critical_utilization(self) -> float:
        return sum(r.verify_cost / max(1, r.validity_horizon)
                   for r in self.records if r.critical)

    def is_schedulable(self) -> bool:
        # Liu–Layland 型利用率判据（验证可抢占，故充分）
        return self.critical_utilization() <= 1.0

    def schedule(self, k: int, budget_ver: float) -> list[str]:
        # 1) 关键集：EDF（最早失效优先）
        critical = sorted(
            [r for r in self.records
             if r.critical and not r.is_valid(k)],
            key=lambda r: r.last_verified + r.validity_horizon)
        chosen, spent = [], 0.0
        for r in critical:
            if spent + r.verify_cost <= budget_ver:
                chosen.append(r.name)
                spent += r.verify_cost
        # 2) 非关键集：按风险密度做分数背包
        optional = sorted(
            [r for r in self.records
             if not r.critical and not r.is_valid(k)],
            key=lambda r: r.severity / max(1e-9, r.verify_cost),
            reverse=True)
        for r in optional:
            if spent + r.verify_cost <= budget_ver:
                chosen.append(r.name)
                spent += r.verify_cost
        return chosen

    def mark_verified(self, names: list[str], k: int) -> None:
        for r in self.records:
            if r.name in names:
                r.last_verified = k

    def all_critical_valid(self, k: int) -> bool:
        return all(r.is_valid(k) for r in self.records if r.critical)
```

@dataclass
class InstructionGroundedMPC:
    """IG-MPC：在 Exec_v28 内优化语言目标，并服从预算与语义风险"""
    ktcg: 'KnowledgeTransilientCertificationGate'
    dynamics: Callable
    horizon: int = 20
    gamma_risk: float = 5.0     # 解释鲁棒风险权重
    lambda_cost: float = 0.1    # 动作成本权重

    def solve(self, x0, lgc: LanguageGroundingCertificate,
              ccc: CostControlCertificate,
              acs: AnytimeCertificateScheduler) -> dict:
        # 0) 语义门控：歧义过大就弃权（请求澄清），绝不猜测
        if lgc is None or not lgc.is_adequate():
            return {"status": "defer", "reason": "ambiguous",
                    "ambiguity": None if lgc is None else lgc.ambiguity()}

        # 1) 权限检查：越权指令必须人工确认
        if lgc.authority >= 2:
            return {"status": "defer", "reason": "authority_override"}

        # 2) 预算与证书新鲜度预检
        if not ccc.is_alive():
            return {"status": "fail_safe", "reason": "budget_exhausted"}
        if not acs.all_critical_valid(0):
            return {"status": "fail_safe", "reason": "stale_critical_cert"}

        # 3) 语言规范：建议只塑形目标；硬约束才进入可行集
        spec = lgc.best()
        hard_specs = lgc.plausible_set() if lgc.authority == 1 else []

### IP-471 Budgeted Instruction-Grounded Cert Gate (BIG-CG)

```python
@dataclass
class BudgetedInstructionGroundedCertGate:
    """BIG-CG：KTCG ∪ LGC ∪ CCC ∪ ACS 的联合准入"""

    ktcg: 'KnowledgeTransilientCertificationGate'
    ccc: CostControlCertificate
    acs: AnytimeCertificateScheduler

    def admits(self, plan, lgc: LanguageGroundingCertificate, k: int) -> bool:
        # 1) 语言可落地（歧义在容忍内，权限不越界）
        if lgc is None or not lgc.is_adequate() or lgc.authority >= 2:
            return False
        # 2) 预算仍有安全余量
        if not self.ccc.is_alive():
            return False
        # 3) 关键证书全部新鲜
        if not self.acs.all_critical_valid(k):
            return False
        # 4) 原 v28 九证准入（安全底座不变）
        if not self.ktcg.admits(plan):
            return False
        # 5) 语言硬约束（仅 a=1）必须被计划满足
        if lgc.authority == 1:
            for spec in lgc.plausible_set():
                if not self._satisfies(plan, spec):
                    return False
        return True

    def _satisfies(self, plan, spec: FormalSpec) -> bool:
        return all(spec.predicate(x) for x in plan.trajectory)
```

### IP-472 Cost-Aware Knowledge Acquisition (CAKA)

```python
class CostAwareKnowledgeAcquisition:
    """CAKA：用信息价值门控是否花钱消歧或补验证"""

    def __init__(self, ccc: CostControlCertificate, threshold: float = 0.0):
        self.ccc = ccc
        self.threshold = threshold

    def value_of_information(self, lgc, query, risk_fn) -> float:
        risk_before = lgc.interpretation_risk_proxy(risk_fn)
        risk_after = query.expected_residual_risk(lgc)
        return risk_before - risk_after - query.cost

    def should_query(self, lgc, query, risk_fn) -> bool:
        voi = self.value_of_information(lgc, query, risk_fn)
        # 只有「值」为正、且屏障付得起，才发起查询
        return voi > self.threshold and self.ccc.barrier_allows(query.cost)

    def maybe_verify(self, acs: AnytimeCertificateScheduler, k: int,
                     budget_ver: float, severity_floor: float = 0.0):
        names = acs.schedule(k, budget_ver)
        acs.mark_verified(names, k)
        return names
```

## 3. 复杂度分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| LGC 编译（解析 + 校准） | O(k·|φ|) + 校准摊销 O(1) | O(k·|φ|) | k ≤ 8 个候选解释 |
| LGC 风险 / 解释集 | O(k·H) | O(k) | H ≤ 20 |
| CCC 记账 / 屏障 | O(1) per step | O(T_ledger) | 流水长度受轮次上限约束 |
| ACS 调度 | O(n log n) | O(n) | n ≤ 9 张证书 |
| IG-MPC 求解 | O(|I_δ|·N·n_x³) | O(N·n_x) | |I_δ| ≤ 3；最坏退化为单场景 O(N·n_x³) |
| BIG-CG 总体 | O(N·n_x³ + k·H + n log n) | O(N·n_x + n) | MPC 仍为主瓶颈 |

**实时性**：N=20, n_x=12, n_u=6 时 MPC 典型 5–15ms；ACS 调度 <0.1ms；CCC 记账 <0.01ms；LGC 编译仅在收到新指令时触发（可异步），风险评估 <1ms。多解释场景求解仅在 a=1 的硬约束下发生，且限制 |I_δ| ≤ 3，单步总开销仍 <25ms，满足 50Hz 控制周期。预算紧张时可主动把 |I_δ| 降为 1 并进入「最坏解释」模式，以时间换语义精度。

## 4. 正确性论证（增量更新）

### 引理 26（LGC 的意图保真度）

**陈述**：若解析器后验经校准，且 LGC 满足 is_adequate()（即 amb(ℓ) ≤ δ_amb），则 argmax 解释等于真实意图的概率至少为 1−δ_amb。

**证明**：设 p_max = max_j p_j。由 amb(ℓ) = 1 − p_max ≤ δ_amb 得 p_max ≥ 1−δ_amb。在后验校准的前提下，真实意图等于第 j 个解释的概率就是 p_j，故真实意图等于 argmax 的概率为 p_max ≥ 1−δ_amb。∎

**注**：该引理把「语言正确」从无法验证的断言，降为一个**可校准、可拒答**的概率保证；校准失败时 compile 返回 None，系统弃权，故不存在「未校准也宣称保真」的情形。

### 引理 27（预算屏障不变式）

**陈述**：设 B_0 > B_min，且每一步 commit 的成本满足 cost_k ≤ α(B_k − B_min)，则对所有 k 有 B_k ≥ B_min，且 B_k − B_min ≥ (1−α)^k (B_0 − B_min)。

**证明**：对 k 归纳。B_{k+1} − B_min = (B_k − B_min) − cost_k ≥ (B_k − B_min) − α(B_k − B_min) = (1−α)(B_k − B_min)。由 B_0 − B_min > 0 且 1−α ≥ 0，归纳得 B_k − B_min ≥ (1−α)^k(B_0 − B_min) ≥ 0。∎

**推论**：预算永不低于储备 B_min；若每步平均成本 c̄ > 0，则剩余可运行步数至少为 (B−B_min)/c̄，可用于触发提前的 fail-safe。

### 引理 28（关键证书的 EDF 可调度性）

**陈述**：若关键证书集的利用率 U = Σ_{i∈C_crit} v_i/ν_i ≤ 1，验证任务可抢占（随时停检、下次续检），且初始 τ_i(0) ≤ ν_i，则 EDF 能在每个 ν_i 步内至少验证证书 i 一次，从而关键证书永不陈旧。

**证明**：把每张关键证书看成周期 ν_i、执行时间 v_i、相对截止期等于周期的可抢占任务。EDF 在单处理器可抢占模型下是最优的；Liu–Layland 利用率判据给出：Σ v_i/ν_i ≤ 1 时全部任务满足截止期。每次在截止期前完成验证即刷新 last_verified，故 τ_i ≤ ν_i 恒成立。∎

### 引理 29（语言的非扩张性）

**陈述**：对任意指令 ℓ，若其权限 a(ℓ) ≤ 1，则 BIG-CG 准入的计划集 Exec_v29(ℓ) ⊆ Exec_v28。

**证明**：BIG-CG 的准入是 KTCG（即 v28 的九证）与 LGC/CCC/ACS 三组谓词的合取。a=0 时语言仅进入目标函数，不改变约束集；a=1 时语言以合取方式追加硬约束。任何在原有约束上再合取新谓词得到的集合，都是原集合的子集。故 Exec_v29(ℓ) = Exec_v28 ∩ Fil_lang ∩ Fil_budget ∩ Fil_sched ⊆ Exec_v28。∎

**意义**：语言不可能「解锁」被安全证书禁止的动作；它只能在已认证的安全空间内重新分配偏好。这条单调性是把语言安全地接到 v28 之上的关键。

### 定理（BIG-CG 的联合健全性）

**陈述**：若解析器已校准、B_0 > B_min、ACS 可调度、初始关键证书有效，且 BIG-CG.admits(π, ℓ, k) = True，则：
1. π ∈ Exec_v28（安全底座不变）；
2. 执行 π 期间预算永不低于 B_min；
3. 每个关键证书在每一步都有效；
4. 实际执行的解释等于人类真实意图的概率 ≥ 1−δ_amb。

**证明**：(1) 由 admits 的第 4 项 KTCG 子句与引理 29；(2) 由引理 27 与 CCC 屏障；(3) 由引理 28 与 ACS 的关键集调度；(4) 由引理 26 与 LGC 的 adequacy 检查。四项互相独立地成立，故合取成立。∎

### 命题（VoI 的单步最优性）

**陈述**：对二值决策「查询 / 不查询」，当且仅当 VoI(q) = 预期风险下降 − 查询成本 > 0 时查询，能使当前步的期望「风险 + 成本」最小。

**证明**：设查询前后期望风险为 R_0、R_1，查询成本为 c_q。不查询的总代价为 R_0；查询的总代价为 R_1 + c_q。查询更优当且仅当 R_1 + c_q < R_0，即 (R_0 − R_1) − c_q = VoI(q) > 0。∎

**注**：这是**短视最优**，不保证全局最优；在多步场景下查询还可能带来后续收益，故 CAKA 只把它当作「是否值得花这笔钱」的必要门槛，而非充要策略。

## 5. 实验设计

**平台与任务**：复用现有双足仿真 harness，场景取平地 / 湿滑 / 台阶三类；指令集为 30 条模板化自然语言命令，按歧义度分层（低/中/高），每条附人工标注的规范真值。

**对照**：
- B1：v28 + 固定全量验证（忽略预算）；
- B2：v28 + 随机子集验证（有预算但无调度）；
- B3：v28 + 贪心 argmax 落地（无弃权、无 VoI）；
- B4：完整 BIG-CG。

**实验与假设**：
1. **E1 预算-安全曲线**：B_0 取 {1.0, 0.7, 0.5, 0.3}×名义值。指标：预算击穿次数、安全违规率、任务成功率。假设：B4 击穿 0 次、违规 0 次，成功率随预算平滑下降；B1 在低预算下击穿频发。
2. **E2 语义落地**：注入高歧义指令。指标：误解执行率、弃权/追问率、澄清后正确率。假设：B3 灾难性误解率显著高于 B4；B4 以追问率上升换取误解率下降 ≥80%。
3. **E3 证书调度**：扫描 U ∈ {0.7, 0.9, 1.0, 1.1}。指标：陈旧关键证书被准入的次数。假设：U ≤ 1 时为 0；U > 1 时急剧上升，验证引理 28 的临界性。
4. **E4 语义漂移探针（风险实验）**：固定一条歧义指令，把预算从高到低扫描，统计所选解释相对人工真值的分布。定义**廉价解释偏好** bias = P(选中便宜解释 | 低预算) − P(选中便宜解释 | 高预算)。假设：即便各解释的 severity 相等，bias 仍随预算收紧而显著为正——这正是本轮最大风险的可测形态。

**指标表**：安全违规率、任务成功率、预算击穿率、误解执行率、追问率、关键证书陈旧率、单步耗时、语义漂移 bias。

## 7. 本轮最大风险（最终确认）

**一句话**：**成本诱导的语义漂移**——在预算压力下，落地与验证的联合回路会系统性地偏向「容易验证、便宜」的解释，而不是「人真正想要」的解释；所有证书都成立，但成立的是错误规范。系统表现完全合规，人的意图却被悄悄替换，而且没有任何一张证书会报警，因为每张证书都在为它自己那份（错误的）规范背书。
