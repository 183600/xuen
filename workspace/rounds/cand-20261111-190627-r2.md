# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「故障诊断」×「比赛策略」）

> 第 54 轮已把技能组合建模为动作空间图 `G_S`，并以 `J=(ρ,A_cert,γ_ce,δ_a)` 回答“组合前是否可行、云边是否对齐”。但该层是**静态可行性层**：执行期默认“要么健康、要么拒绝/降级”，仍缺两个环节：(i) 失败已经发生后，如何用有限观测**定位故障模式**，而不是只会说“这里失败了”；(ii) 比赛是计分驱动的序列决策，**何时保守止损、何时冒险抢分、何时主动试探以换取诊断信息**，缺乏与故障信念耦合的策略层。本轮提出 **诊断-策略闭环（Diagnosis×Strategy Loop）**：把第 54 轮的动作空间与证书当作“可探测的假设空间”，让系统在比赛中同时执行任务、辨识故障、调整风险-得分策略。
>
> 核心矛盾：**H22（误诊风险）**：`Explain` 是单次反事实，不等于跨时间的故障模式辨识；观测欠定 + 故障模式开放集会导致误诊，进而“错误降级”或“错误坚持”。**H23（策略-证书脱节）**：现有证书只给可行性/鲁棒性下界，不告诉策略“这个动作值多少分、值得冒多大风险、顺带能诊断出什么”；纯保守证书在比赛中会系统性输给风险校准的策略。

## 0. 直觉与动机

**灵感 1（故障不是标签，而是残差流上的模式）**
直觉：把执行期观测 `o_t`（位姿误差、力/电流残差、动作跟踪误差、`ρ` 维度退化、`Explain` 反事实）汇成残差向量 `r_t = φ(o_t,a_t,s_t)`。每种故障 `f` 有一个签名分布 `P(·|σ_f)`，而诊断不是“分类一次”，而是维护故障信念 `b_t∈Δ(F)` 并做贝叶斯更新，其中 `f_0` 表示健康。关键点是：签名**可校准**（结构化仿真 + 边端日志），不是人工规则表。

**灵感 2（可辨识性有限，所以诊断必须主动）**
直觉：有些故障在当前动作下观测分布几乎重合（如“轮子打滑”与“编码器偏置”），再等也分不开。可辨识度 `κ` 应定义为给定探针动作集 `A_probe` 下的期望互信息。比赛策略因此多了一个自由度：用小幅度、低风险、高信息量的**探针动作**主动制造可区分性。第 54 轮的动作空间正好给出探针的合法域：探针必须落在 `A_core` 安全域内且不破坏得分预算。

**灵感 3（比赛策略 = 风险-得分前沿，而不是单一策略）**
直觉：比赛不是“成功率最大化”，而是“在时间/次数预算内最大化期望得分，并控制灾难性失败概率”。得分泛函应显式包含时间成本与灾难惩罚；策略在（期望得分，`CVaR_β` 尾部风险）平面上选点。风险预算 `β(t)` 随剩余时间、当前排名、领先/落后而变：领先→保守，落后→提高风险偏好，但“提高风险”必须受证书约束，不能越过 `ρ_min` 与 `A_cert`。

**灵感 4（诊断与策略是同一个 POMDP 的两面）**
直觉：每个动作同时有任务价值 `V_task(a)` 与诊断价值 `V_info(a)=λ·I(F;o'|a,b)`。合成 `Q_diag(s,a)=V_task+λV_info-risk_penalty`，于是“为了赢而试探”和“为了诊断而试探”被统一。故障信念变化会驱动策略 regime 切换：健康→正常抢分；局部可恢复故障→降级但保留高分技能；不可恢复或高不确定→保守止损并集中探针。

**灵感 5（三证书体系：可执行 J + 可诊断 D + 可得分 S）**
直觉：第 54 轮的 `J` 回答“能不能做”；本轮补两张证书：`D_cert=(F_cover,δ_sep,N_probe,α_diag,abstain)` 回答“失败时能不能分清原因”，`S_cert=(Score_LCB,CVaR_β,Regret_bound)` 回答“这套策略在比赛里最坏能拿多少”。只有当 `J∧D∧S` 同时成立才允许“高风险抢分”模式；否则自动退到 diagnosis-safe 策略。证书不再是静态门槛，而是**策略风险预算的约束面**。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（故障模式空间与残差签名）**
故障模式空间 `F = {f_0,f_1,...,f_m} ∪ F_open`，`f_0` 为健康模式，`F_open` 为未建模故障集合。观测 `o_t∈O`，残差映射 `r_t = φ(o_t,a_t,s_t)∈R^k`。故障 `f` 的签名 `σ_f` 是 `r_t` 在 `f` 下的条件分布 `P(r|f)`；`σ_f` 由仿真校准数据集 `D_cal` 估计，并保留校准误差界 `ε_cal`。

**定义 122（故障信念与诊断算子）**
故障信念 `b_t∈Δ(F)`，初值 `b_0` 由先验给出。贝叶斯更新：
```
b_{t+1}(f) = η · P(o_{t+1} | f, a_t) · b_t(f),   η = 1/Σ_f (...)
```
诊断算子 `D(o_{1:t},a_{1:t}) = b_t`；点诊断 `f̂_t = argmax_f b_t(f)`。当 `max_f b_t(f) < θ_bel` 或 `b_t(F_open) > θ_open` 时**弃权（abstain）**，而不是强行给出故障标签。

**定义 123（可辨识度与 ε-可辨识）**
对探针动作集 `A_probe`，可辨识度
```
κ(A_probe) = I(F; O_{1:N} | A_probe) / H(F)          （归一化互信息）
```
若 `κ(A_probe) ≥ ε_κ` 且任意 `f≠g` 的签名分离度 `d_TV(σ_f,σ_g) ≥ δ_sep`，则称 `(F,A_probe)` 是 **ε-可辨识** 的。`d_TV` 为全变差距离。该定义把“能不能诊断”变成一个可在动作空间上优化的量，而不是事后感慨。

**定义 124（比赛得分泛函与风险预算）**
策略 `π: (s,b,τ_rem,rank) → Π` 为从状态、故障信念、剩余时间、排名到技能/选项分布的映射。得分泛函：
```
Score(π) = E[ Σ_t ( value(a_t)·1(success) - c_time·Δt - c_fail·1(catastrophic) ) ]
```
风险度量取条件风险价值 `CVaR_β(π)`。风险预算 `β(t)∈[0,1]` 是时变参数；比赛策略要求 `CVaR_β(π) ≤ B_risk`，其中 `B_risk` 随“领先/落后”动态调整。

**定义 125（诊断-任务耦合价值）**
```
Q_diag(s,a,b) = V_task(s,a) + λ·I(F; O' | s,a,b) - μ·Risk(a) - c_probe(a)
```
其中 `I(F;O'|s,a,b)` 为执行 `a` 后的期望信息增益，`c_probe` 为探针的时间/动作成本。`λ=0` 退化为纯任务策略；`λ→∞` 退化为纯诊断策略；比赛策略在两者之间取平衡。

**定义 126（故障感知降级格）**
在选项集 `Π` 上定义偏序 `≼_d`：`π_a ≼_d π_b` 表示 `π_a` 在故障 `f` 下**不劣于** `π_b`（得分不低于、灾难概率不高于）。故障到可容许选项的映射 `Adm: F → 2^Π` 必须满足：`π∈Adm(f)` 当且仅当 `J.in(π) ∧ ρ(π)≥ρ_min` 且 `Score_LCB(π|f) ≥ S_min`。这给出“哪一级降级仍是可接受的”的形式化边界。

**定义 127（三联合证书）**
```
T = (J, D_cert, S_cert)
D_cert = (F_cover, δ_sep, N_probe, α_diag, abstain)
S_cert = (Score_LCB, CVaR_β, Regret_bound)
```
部署规则：高风险抢分模式仅当 `J.in ∧ D.in ∧ S.in`；否则退到 `Adm(f)` 中的 diagnosis-safe 选项。`D.in` 要求 `F_cover ⊇ F_model`、`δ_sep ≥ δ_min`、`N_probe ≥ N_min`；`S.in` 要求 `Score_LCB ≥ S_min` 且 `CVaR_β ≤ B_risk`。

## 2. 关键算法 伪代码

### IP-121 FDI（Fault Diagnosis Interface）

```python
def update_fault_belief(b, o, a, fault_lib, theta_open):
    r = residual(o, a)
    lik = {f: fault_lib[f].likelihood(r) for f in fault_lib.modeled}
    unk = fault_lib.open_set_score(r)
    post = {f: b[f] * lik[f] for f in lik}
    post[OPEN] = b[OPEN] * unk
    b2 = normalize(post)
    if max(b2[f] for f in b2 if f != OPEN) < 0.5 or b2[OPEN] > theta_open:
        return b2, 'abstain'
    return b2, argmax(b2, exclude=OPEN)
```

### IP-122 ADX（Active Diagnosis eXploration）

```python
def choose_probe(b, A_probe, J, budget):
    if entropy(b) <= H_stop:
        return None
    best, best_net = None, 0.0
    for a in A_probe:
        if not J.A_cert.allows(a):          # 复用第 54 轮动作证书
            continue
        if budget.remaining < cost_probe(a):
            continue
        ig = mutual_information(F, O_next, a, b)
        net = ig - lambda_c * cost_probe(a) - mu_r * risk(a)
        if net > best_net:
            best, best_net = a, net
    return best
```

### IP-123 CSR（Competition Strategy Reasoner）

```python
def competition_policy(b, state, G, T_cert, rank, tau_rem):
    if b[HEALTHY] >= theta_healthy:
        regime = 'score_max'
    elif b[OPEN] > theta_open or entropy(b) > H_crit:
        regime = 'probe_then_safe'
    elif any_recoverable(b, F):
        regime = 'degrade_hold'
    else:
        regime = 'safe_abort'

    beta = risk_budget(tau_rem, rank)        # 领先→小 beta，落后→大 beta
    opts = []
    for opt in Adm(regime, b, F):            # 定义 126 的降级格
        if not (T_cert.J.in_(opt) and T_cert.D.in_(opt, b) and T_cert.S.in_(opt, beta)):
            continue
        score_lcb = lower_confidence_score(opt, b)
        cvar = cvar_beta(opt, beta)
        opts.append((opt, score_lcb, cvar))
    return argmax_risk_adjusted(opts, beta)  # 例如 max score_lcb s.t. cvar <= B(beta)
```

### IP-124 DCL（Diagnosis-Strategy Closed Loop）

```python
def diagnosis_strategy_loop(env, G, T_cert, horizon):
    b, t = prior(), 0
    while t < horizon and not env.done():
        b, f_hat = update_fault_belief(b, env.obs, env.last_action, fault_lib, theta_open)
        if needs_probe(b):
            a = choose_probe(b, env.A_probe, T_cert.J, env.budget) or safe_action(env)
        else:
            a = competition_policy(b, env.state, G, T_cert, env.rank, horizon - t)
        obs, reward, done = env.step(a)
        T_cert = refresh_certificates(T_cert, b, obs, reward)
        if T_cert.D.violated(b):             # 误诊风险升高 → 收紧风险预算
            T_cert = tighten_risk_budget(T_cert)
        t += 1
    return b, T_cert
```

### IP-125 FDL（Fault-aware Degradation Lattice）

```python
def build_degradation_lattice(faults, skills, J, rho_min, S_min_per_fault):
    lattice = {}
    for f in faults:
        adm = []
        for s in skills:
            if not J.in_(s): continue
            if min(s.rho.values()) < rho_min: continue
            if lower_confidence_score(s, f) < S_min_per_fault[f]: continue
            adm.append(s)
        lattice[f] = sorted(adm, key=lambda s: score_lcb(s, f), reverse=True)
    return lattice
```

### IP-126 TJC（Tri-joint Certificate）

```python
def tri_joint_certify(J, D_cert, S_cert):
    if not J.in_:
        return ('reject', 'not_executable')
    if D_cert.alpha_diag > alpha_max or D_cert.N_probe < D_cert.N_min:
        return ('reject', 'not_diagnosable')
    if S_cert.Score_LCB < S_min or S_cert.CVaR_beta > B_risk:
        return ('reject', 'not_scoreable')
    return ('ok', TriCert(J, D_cert, S_cert))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| FDI | `O(|O|·|F|)` | `O(|F|)` | 签名校准误差 `ε_cal` 有界、open-set 分数可用 |
| ADX | `O(|A_probe|·|F|)` | `O(|F|)` | 互信息估计无偏、探针在 `A_cert` 内 |
| CSR | `O(|Π|·log|Π|)`（筛选+排序） | `O(|Π|)` | `Score_LCB` 有效、降级格偏序 sound |
| DCL | `O(H·(|F|+|Π|))` | `O(|F|+|Π|)` | 信念收敛、风险预算单调收紧 |
| TJC | `O(|J|+|D|+|S|)` | `O(1)` | 三证书合取 sound |

**正确性定理（Diagnosis-Aware Competition Strategy Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增：
**(A29)** 真实故障要么属于 `F_model`，要么被 open-set 检测出的概率至少 `1-α_open`；
**(A30)** 在 `A_probe` 上任意 `f≠g∈F_model` 的签名满足 `d_TV(σ_f,σ_g) ≥ δ_sep`，且探针数 `N ≥ log(1/α_diag)/C_min`（`C_min` 为最小 Chernoff 信息）；
**(A31)** 得分估计器给出的 `Score_LCB` 以概率 `1-α_s` 为真实得分的下界。

则部署策略 `π` 满足：
```
P(catastrophic) ≤ P(f∈F_open) + α_diag + P(δ_a>Θ_a)
Score(π) ≥ Score_LCB - Regret_ADX - Regret_CSR
```
其中 `Regret_ADX` 来自探针选择的有限样本互信息估计误差，`Regret_CSR` 来自风险-得分前沿上的策略选择误差。定理的实质是：**可诊断性不是免费获得的，它由探针预算 N 与签名分离度 δ_sep 共同定价；得分下界也只有在诊断正确时才成立。**

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 开放集故障导致误诊 | 高 | open-set 检测 + abstain + 人工/规则兜底 |
| 主动探针损伤本体或丢分 | 高 | 探针限制在 `A_core`、动作幅度/时长预算、紧急回滚 |
| 故障签名随对手/场地漂移 | 高 | 在线校准 + 滑动窗口签名 + 非平稳检测 |
| 策略对得分模型过拟合 | 中 | `Score_LCB` + 鲁棒优化 + 多场景交叉验证 |
| 诊断/策略 regime 频繁切换震荡 | 中 | hysteresis + 最小驻留时间 + 冷启动锚点 |
| 探针预算与比赛时限冲突 | 中 | 时变风险预算 + 领先时压缩 `N_probe` |

## 6. 本轮最大风险

**一句话**：诊断-策略闭环让系统第一次具备“失败后分清原因、并按得分-风险前沿自适应抢分/止损”的能力，但其安全性**双重依赖开放集故障的可检测性与主动探针的代价可控性**；一旦遇到未建模故障且 open-set 分数失效，系统会在“高置信地误诊”后进入错误降级或错误抢分 regime，把一次可恢复故障放大成比赛级灾难，因此必须以 **open-set 弃权 + 探针安全域硬约束 + 三证书合取门控** 作为不可绕过的护栏，宁可弃权保分，绝不以“高置信误诊”驱动高风险策略。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim-DxS（FDI×ADX×CSR×DCL×FDL×TJC）

> 承接第 54 轮产物 v31（`GroundEdge-GenSim+++`）。本轮在第 54 轮“动作空间 + 鲁棒性联合证书 `J`”之上，增加 **故障诊断、主动诊断、比赛策略、诊断-策略闭环** 四个算子，并把证书体系从“可执行”扩展为 **可执行 J + 可诊断 D + 可得分 S** 的三联合证书：
> - **FDI（Fault Diagnosis Interface）**：残差签名 + 故障信念 `b_t` + open-set 弃权；
> - **ADX（Active Diagnosis eXploration）**：在动作证书 `A_cert` 内最大化互信息的探针选择；
> - **CSR（Competition Strategy Reasoner）**：风险-得分前沿 + 信念驱动的 regime 切换；
> - **DCL（Diagnosis-Strategy Closed Loop）**：诊断→风险预算→策略→新观测的闭环；
> - **FDL（Fault-aware Degradation Lattice）**：故障模式到可容许技能/降级选项的偏序格；
> - **TJC（Tri-joint Certificate）**：`T=(J,D_cert,S_cert)` 合取门控。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-117/118/120 以纳入故障信念与得分维度。

| `r_t=φ(o_t,a_t,s_t)` | 残差向量（位姿/力/电流/跟踪误差等） |
| `σ_f=P(r|f)` | 故障签名分布 |
| `b_t∈Δ(F)` | 故障信念 |
| `κ(A_probe)=I(F;O|A_probe)/H(F)` | 归一化可辨识度 |
| `δ_sep` | 签名最小全变差分离度 |
| `C_min` | 最小 Chernoff 信息（决定所需探针数） |
| `Score(π)` | 含时间成本与灾难惩罚的比赛得分泛函 |
| `CVaR_β(π)` | 尾部风险（条件风险价值） |
| `β(t)` | 时变风险预算 |
| `Q_diag(s,a,b)` | 任务价值 + 信息增益 - 风险 - 探针成本 |
| `Adm(f)` | 故障 `f` 下可容许选项集（降级格） |
| `D_cert=(F_cover,δ_sep,N_probe,α_diag,abstain)` | 可诊断证书 |
| `S_cert=(Score_LCB,CVaR_β,Regret_bound)` | 可得分证书 |
| `T=(J,D_cert,S_cert)` | 三联合证书 |

## 2. 关键算法 伪代码

### IP-121 FDI

```python
def update_fault_belief(b, o, a, fault_lib, theta_open, H_crit):
    r = residual(o, a)
    lik = {f: fault_lib[f].likelihood(r) for f in fault_lib.modeled}
    unk = fault_lib.open_set_score(r)
    post = {f: b[f] * lik[f] for f in lik}
    post[OPEN] = b[OPEN] * unk
    b2 = normalize(post)
    top = max((b2[f] for f in b2 if f != OPEN), default=0.0)
    if top < 0.5 or b2[OPEN] > theta_open or entropy(b2) > H_crit:
        return b2, 'abstain'
    return b2, argmax(b2, exclude=OPEN)
```

### IP-122 ADX

```python
def choose_probe(b, A_probe, J, budget, lambda_c, mu_r):
    if entropy(b) <= H_stop:
        return None
    best, best_net = None, 0.0
    for a in A_probe:
        if not J.A_cert.allows(a):            # 第 54 轮动作证书硬约束
            continue
        if not budget.can_afford(a):          # 时间/次数预算
            continue
        ig = mutual_information(F, O_next, a, b)
        net = ig - lambda_c * cost_probe(a) - mu_r * risk(a)
        if net > best_net:
            best, best_net = a, net
    return best
```

### IP-123 CSR

```python
def competition_policy(b, state, G, T_cert, rank, tau_rem):
    if b[HEALTHY] >= theta_healthy:
        regime = 'score_max'
    elif b[OPEN] > theta_open or entropy(b) > H_crit:
        regime = 'probe_then_safe'
    elif any_recoverable(b, F):
        regime = 'degrade_hold'
    else:
        regime = 'safe_abort'

    beta = risk_budget(tau_rem, rank)         # 领先→小 beta，落后→大 beta
    feasible = []
    for opt in Adm(regime, b, F):             # IP-125
        if not (T_cert.J.in_(opt)
                and T_cert.D.in_(opt, b)
                and T_cert.S.in_(opt, beta)):
            continue
        feasible.append((opt,
                         lower_confidence_score(opt, b),
                         cvar_beta(opt, beta)))
    return argmax_risk_adjusted(feasible, beta)
```

### IP-124 DCL

```python
def diagnosis_strategy_loop(env, G, T_cert, horizon):
    b, t = prior(), 0
    while t < horizon and not env.done():
        b, f_hat = update_fault_belief(
            b, env.obs, env.last_action, fault_lib, theta_open, H_crit)
        if needs_probe(b):
            a = choose_probe(b, env.A_probe, T_cert.J, env.budget,
                             lambda_c, mu_r) or safe_action(env)
        else:
            a = competition_policy(
                b, env.state, G, T_cert, env.rank, horizon - t)
        obs, reward, done = env.step(a)
        T_cert = refresh_certificates(T_cert, b, obs, reward)
        if T_cert.D.violated(b):              # 误诊风险升高
            T_cert = tighten_risk_budget(T_cert)
        t += 1
    return b, T_cert
```

### IP-125 FDL

```python
def build_degradation_lattice(faults, skills, J, rho_min, S_min_per_fault):
    lattice = {}
    for f in faults:
        adm = []
        for s in skills:
            if not J.in_(s):
                continue
            if min(s.rho.values()) < rho_min:
                continue
            if lower_confidence_score(s, f) < S_min_per_fault[f]:
                continue
            adm.append(s)
        lattice[f] = sorted(adm, key=lambda s: score_lcb(s, f), reverse=True)
    return lattice

def Adm(regime, b, F):
    if regime == 'safe_abort':
        return only_safe_abort_options()
    return lattice[argmax(b, exclude=OPEN)]
```

### IP-126 TJC

```python
def tri_joint_certify(J, D_cert, S_cert, alpha_max, S_min, B_risk):
    if not J.in_:
        return ('reject', 'not_executable')
    if D_cert.alpha_diag > alpha_max or D_cert.N_probe < D_cert.N_min:
        return ('reject', 'not_diagnosable')
    if S_cert.Score_LCB < S_min or S_cert.CVaR_beta > B_risk:
        return ('reject', 'not_scoreable')
    return ('ok', TriCert(J, D_cert, S_cert))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| FDI | `O(|O|·|F|)` | `O(|F|)` | 签名校准误差 `ε_cal` 有界，open-set 有分数 |
| ADX | `O(|A_probe|·|F|)` | `O(|F|)` | 互信息估计无偏，探针在 `A_cert` 内 |
| CSR | `O(|Π|·log|Π|)` | `O(|Π|)` | `Score_LCB` 有效，降级格偏序 sound |
| DCL | `O(H·(|F|+|Π|))` | `O(|F|+|Π|)` | 信念收敛，风险预算单调收紧 |
| FDL | `O(|F|·|S|·|ρ|)` | `O(|F|·|S|)` | 偏序 `≼_d` 传递、`Adm(f)` 证书闭合 |
| TJC | `O(|J|+|D|+|S|)` | `O(1)` | 三证书合取 sound |

**推导要点（探针数下界）**
对 `f≠g`，设其签名分布为 `P_f,P_g`。由样本复杂度与 Chernoff–Stein 引理，达到误诊概率 `α_diag` 的似然比检验至少需要
```
N ≥ log(1/α_diag) / C(σ_f,σ_g),   C(σ_f,σ_g) 为 Chernoff 信息
```
取 `C_min = min_{f≠g} C(σ_f,σ_g)`，即得 `N_probe ≥ log(1/α_diag)/C_min`。这就是 `D_cert.N_probe` 的下界来源：**可辨识性是用探针次数买来的，不是证书自带的**。若 `δ_sep` 太小导致 `C_min→0`，则任何有限探针都无法保证诊断，`D_cert` 必须判 `out` 并 abstain。

**正确性定理（Diagnosis-Aware Competition Strategy Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增：
**(A29)** 真实故障要么属于 `F_model`，要么被 open-set 检测出的概率至少 `1-α_open`；
**(A30)** `A_probe` 上任意 `f≠g∈F_model` 满足 `d_TV(σ_f,σ_g)≥δ_sep` 且 `N_probe ≥ log(1/α_diag)/C_min`；
**(A31)** `Score_LCB` 以概率 `1-α_s` 为真实得分下界。

则部署策略 `π`：
```
P(catastrophic) ≤ P(f∈F_open) + α_diag + P(δ_a > Θ_a)
Score(π) ≥ Score_LCB - Regret_ADX - Regret_CSR
```
关键：**诊断正确是得分下界成立的前提**；`D_cert` 不满足时，`S_cert` 的 `Score_LCB` 不再可信，故三证书必须合取。

## 6. 本轮最大风险

**一句话**：诊断-策略闭环让系统第一次具备“失败后分清原因、并按得分-风险前沿自适应抢分/止损”的能力，但其安全性**双重依赖开放集故障的可检测性与主动探针的代价可控性**；一旦遇到未建模故障且 open-set 分数失效，系统会在“高置信地误诊”后进入错误降级或错误抢分 regime，把一次可恢复故障放大成比赛级灾难，因此必须以 **open-set 弃权 + 探针安全域硬约束 + 三证书合取门控** 作为不可绕过的护栏，宁可弃权保分，绝不以“高置信误诊”驱动高风险策略。
