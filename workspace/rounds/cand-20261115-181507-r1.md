# 第 1 轮（新灵感循环；灵感：「运动规划」×「论文发表」；系统版本 v9）
> **基线**：第 8 轮 MetricVoiceGauge-DA-SPR-Cal（定义 493–540；引理 77–81；实验 E531–E550）。
> 本轮纪律：**双时间尺度**。内环（50Hz 控制）引入「计划证书」；外环（离线/每轮）引入「发表级证据闭合」。外环**只能收紧**内环安全包络、绝不放宽；任一外环组件失效 ⇒ 退回 v8 内环 + 草稿模式。

## 0. 直觉与动机

**灵感 1（运动规划 → 计划证书，而非动作序列）**

直觉：现有指标体系监控的是「执行后的轨迹」，但真正致命的失误发生在「计划本身不可证」——规划器给出了一条看起来可行、却在 clearance、动力学可行性或最优性下界上没有保证的轨迹。运动规划研究里的 **anytime + certificate** 范式给了答案：规划器随计算时间单调改进解，并**始终持有一个可独立验证的上界/可行性凭证**；证书一旦失效，执行层立即拒绝该计划，而不是等碰撞发生。

关键跃迁：把规划器从「动作生成器」升级为「**证书生成器**」。新增第 7 层 `M_plan`，监控三类量：路径最小间隙 `c(π)`、动力学可行性余量 `ρ(π)`、anytime 上界间隙 `g(π)`；证书是执行的门控条件，而非事后统计。

**灵感 2（论文发表 → 声明-证据闭合，而非文字产出）**

直觉：一个研究系统最隐蔽的失效不是「跑不出实验」，而是「**声明与证据脱钩**」：孤儿声明（有 claim 无实验）、孤儿实验（有实验不支撑任何 claim）、事后挑选判据（p-hacking）、不可复现的随机种子。把「论文发表」当作一面镜子，它要求的正是**每条声明都能被追溯到定理 + 实验 + 可反驳条件 + 独立复现**。

关键跃迁：把「发表」建模为外环的**对抗审稿器**：`Claim-Evidence Ledger (CEL)` 强制声明与证据二部图闭合；`AdversarialReviewer (AR)` 主动采样扰动找反例；`ReproducibilityManifest (RM)` 固化代码/数据哈希、种子、算力预算。最重要的架构判断：**发表是慢时间尺度审计，不能塞进 50Hz 内环，否则会污染硬实时**。

**统一洞察（本轮的核心 IP）**

两个灵感共享同一抽象：**可验证凭证（verifiable credential）**。运动规划给控制以「计划证书」，论文发表给研究以「证据证书」。系统因此成为一个 **证书双环（Dual-Certificate Loop）**：
- **内环**：50Hz，实时签发/验证计划证书，保证动作执行安全；
- **外环**：每轮/离线，签发/审计证据证书，保证研究结论可信；
- **耦合接口**：外环只经「安全包络」收紧内环阈值（TTSE），且只允许单调收紧。

## 1. 研究问题（轮次升级版）

- **Q1（计划证书可验证性）**：如何设计一个 anytime 规划器，使其证书在 ≤ 2ms 内可验证、且证书通过 ⇒ 执行轨迹必满足 clearance 与动力学约束（soundness）？
- **Q2（证据闭合可量化）**：如何把「一条声明是否有足够证据」形式化为可计算、可单调审计的标量，并驱动下一轮研究而非沦为形式主义？
- **Q3（双环安全耦合）**：外环审计结果如何在不污染 50Hz WCET 的前提下驱动内环，并形式化保证「外环只会让系统更保守、不会更冒险」？

## 2. 设计原则（在 P7–P9 基础上升级为 P10–P12）

**P10 证书化 anytime 规划（Certified Anytime Planning, CAP）**

每次规划产出四元组 `Cert_plan = (π, c, ρ, g)`，其中 `π` 为轨迹、`c` 为最小间隙、`ρ` 为动力学余量、`g` 为相对下界的次优间隙。执行门控：

```
execute(π) ⟺ c ≥ c_min ∧ ρ ≥ ρ_min ∧ g ≤ g_max ∧ age(Cert_plan) ≤ TTL
```

否则退回短视界滚规划（receding horizon）或安全停机。anytime 性质要求 `g(t)` 随计算时间单调不增。

**P11 声明-证据账本（Claim-Evidence Ledger, CEL）**

把每轮产物解析为二部图 `CEL=(C,E,L)`：`C` 为声明（定理/经验/设计三类），`E` 为实验，`L ⊆ C×E` 为支撑关系。每条声明必须携带：定理引用、实验引用、**可反驳条件（falsifier）**、复现状态。定义**证据闭合度 CEC** 作为外环主指标，并显式惩罚孤儿声明与孤儿实验。

**P12 双时间尺度安全包络（Two-Timescale Safety Envelope, TTSE）**

外环对新阈值 `τ^new` 的提交遵循单调约束：对安全相关层 `i ∈ {0,1,dom,SLAM,plan}`，仅允许 `τ_i^new ≤ τ_i^old + ε_approve`（收紧/微调），放宽必须携带人工审批令牌 `approve_token`。提交在相位屏障处原子交换，绝不打断内环当前周期。

## 3. 与基线的接口（如何退化）

- CAP 失效 ⇒ 退回 v8 的 IAC 分块规划：仍执行，但无证书门控，仅保留原有安全监控；
- CEL / AR 失效 ⇒ 外环跳过审计，产物标记 `draft` 置信度，内环不受影响；
- RM 失效 ⇒ 仅标记 `unreproducible` 标志位，不阻断内环与任务执行；
- TTSE 失效 ⇒ 外环结果不提交，内环冻结在最后一个已认证阈值快照。

## 4. 预期贡献

1. **计划证书层 M_plan**：把运动规划的可验证性纳入指标阶梯，实现「证书通过才允许执行」的在环门控；
2. **声明-证据账本 CEL / 证据闭合度 CEC**：把「论文发表」的可追溯性形式化为可审计标量，自动检测孤儿声明/孤儿实验；
3. **对抗审稿器 AR**：以扰动采样估计每条声明的存活率，产出审稿风险 `risk_REV`，作为下一轮研究优先级信号；
4. **双时间尺度安全包络 TTSE**：形式化保证外环审计只收紧内环安全包络，且提交不污染 50Hz WCET；
5. 完整 **计划-执行-证据-发表** 四元闭环：E551–E570 覆盖证书 soundness、anytime 收敛、证据闭合、对抗审稿、可复现性与双环实时隔离。

## 5. 本轮最大风险

**一句话**：外环「审稿风险」若被误当作内环奖励信号，可能诱导系统为讨好假想的审稿人而自我审查——规划器过度保守（证书阈值越收越紧）、任务成功率下降；再叠加对抗审稿器的假阳性与 TTSE 原子交换的时序抖动，三者合卷下，「系统为追求发表级证据闭合而过度保守，牺牲了真实任务能力」。

**新增定义 541（规划度量层 Planning Metric Layer, M_plan）** 将规划器输出形式化为可监控的三元余量：
```
c(π) = min_{t∈[0,T]} dist(s_t, O)
ρ(π) = min_{t,k} (u_max,k − |u_{t,k}|)
g(π) = J(π) − J_lb,   J_lb 由松弛问题（如无障碍最短路径）给出
M_plan 满足 ⟺ c(π) ≥ c_min ∧ ρ(π) ≥ ρ_min ∧ g(π) ≤ g_max
```
`M_plan` 违背映射 `δ_plan: M_plan → M₀`：任一余量不足即触发 M₀ 硬约束检查（减速/停/重规划），与 M_dom、M_SLAM 到 M₀ 的退化映射同构。

**新增定义 542（计划证书 PlanCertificate）** 证书为可独立验证的六元组：
```
Cert_plan = (π, c, ρ, g, t_issue, h_π),  h_π = H(π)
valid(Cert_plan, t) ⟺ c ≥ c_min ∧ ρ ≥ ρ_min ∧ g ≤ g_max ∧ (t − t_issue) ≤ TTL
                              ∧ H(π) = h_π
```
`h_π` 绑定「被验证的轨迹」与「将执行的轨迹」，防止验证后轨迹被替换（TOCTOU 攻击）。

**新增定义 543（证书执行门控 Certified Execution Gate）** 执行层唯一入口：
```
execute(π) ⟺ valid(Cert_plan, t) ∧ ∧_{i∈{0,1,dom,SLAM,plan}} (M_i 满足)
```
否则进入 RHF（短视界降级规划）；若 RHF 亦无法在 `TTL` 内产出有效证书，则安全停机。

**新增定义 544（规划风险分量 PlanRisk）** 将证书余量压缩为第 6 维真实值风险：
```
risk_PLAN(s) = σ( w_c·(c_min − c)/c_min + w_ρ·(ρ_min − ρ)/ρ_min
                + w_g·max(0, g − g_max)/g_max + w_age·age/TTL )
```
其中 `σ(·)` 为 logistic 压缩到 [0,1]，权重 `w_· ≥ 0`。证书越接近边界、越陈旧，risk_PLAN 越大，直接注入 MetaWeight 抬高安全层权重。

**新增定义 545（声明-证据账本 Claim-Evidence Ledger）** 外环核心数据结构：
```
CEL = (C, E, L),   L ⊆ C × E
每条声明 c ∈ C 携带：type(c) ∈ {theorem, empirical, design}
                     thm(c) ⊆ 定理编号, exp(c) ⊆ 实验编号
                     fal(c) 为可反驳条件（否则视为不可证伪，权重降为 0）
                     rep(c) ∈ {replicated, single-run, unknown}
孤儿声明: c ∈ C 且 (thm(c)=∅ ∧ exp(c)=∅)
孤儿实验: e ∈ E 且 ∄c: e ∈ exp(c)
```
账本由产物解析器自动构建：定理引用来自「引理/定理」段，实验引用来自「实验设计」表，可反驳条件来自预注册表。

**新增定义 546（证据闭合度 Evidence Closure）** 外环主指标：
```
CEC = ( Σ_{c∈C} ω(c)·clos(c) ) / ( Σ_{c∈C} ω(c) )
clos(c) = 1[thm(c)≠∅] · 1[exp(c)≠∅] · 1[fal(c) 非空] · 1[rep(c)=replicated]
```
性质：`CEC` 对支撑边集合 `L` 单调不减，对声明集合 `C` 的**新增**单调不增（见引理 85）。因此新声明必须自带证据方可准入。

**新增定义 547（对抗审稿器 Adversarial Reviewer）** 用扰动采样估计声明脆弱性：
```
risk_REV(c) = 1 − (1/K) Σ_{k=1}^{K} survive(c, δ_k)
δ_k ~ D_rev  （超参 ±10%、随机种子、数据切片、判据缩放、噪声注入）
risk_REV(系统) = Σ_c ω(c)·risk_REV(c) / Σ_c ω(c)
```
`D_rev` 为审稿扰动分布。存活率低 ⇒ 声明依赖偶然设置，优先级上调以补实验或弱化措辞。

**新增定义 548（可复现清单与距离 Reproducibility Manifest）** 固化复现所需最小信息：
```
M_repro = (h_code, h_data, seeds, env(版本/依赖/硬件), budget(算力/时长), h_prereg)
d_repro = Σ_f α_f · 1[field_f 不一致] / Σ_f α_f,   α_f ≥ 0
```
`h_prereg` 为预注册文件哈希，绑定「预先登记的判据」与「实际执行的判据」，防止事后改判据。

**新增定义 549（双时间尺度安全包络 Two-Timescale Safety Envelope）** 外环对安全层阈值的单调提交：
```
对 i ∈ L_safe = {0,1,dom,SLAM,plan}:
    τ_i^new ≤ τ_i^old + ε_approve                 （自动微调，只能收紧）
    τ_i^new > τ_i^old + ε_approve ⟹ 需 approve_token  （人工审批放宽）
对 i ∈ L_perf = {2,3}: 允许双向，但单轮变化 |Δτ_i| ≤ ε_perf
```
TTSE 保证：外环审计**只会**让系统更保守；若审计误判，最坏结果是性能下降而非安全性下降。

**新增定义 550（外环污染隔离 Outer-Loop Contamination Isolation）** 外环与内环的进程/时序隔离：
```
外环产出写入 double-buffer
内环在相位屏障（周期边界，非中断）处原子 swap
内环每周期读取的是不可变快照，无锁、无阻塞
外环最长计算时长 ≤ T_outer，但绝不在内环关键路径上
```

```python
# IP-354/355/356：证书化 anytime 规划 + 验证器 + 短视界降级
import numpy as np, hashlib

class CertifiedAnytimePlanner:
    def __init__(self, planner, c_min=0.15, rho_min=0.05, g_max=0.2,
                 ttl=0.1, verifier=None):
        self.planner = planner          # 底层次优规划器（RRT*/轨迹优化）
        self.tau_plan = dict(c_min=c_min, rho_min=rho_min,
                             g_max=g_max, ttl=ttl)
        self.verifier = verifier or PlanCertificateVerifier()

    def plan(self, s0, goal, obstacles, time_budget):
        """anytime：在 time_budget 内持续改进，返回最优证书与轨迹"""
        best = None
        for pi, j_lb in self.planner.anytime(s0, goal, obstacles, time_budget):
            c = self._clearance(pi, obstacles)
            rho = self._dyn_margin(pi)
            g = max(0.0, pi.cost - j_lb)
            cert = dict(pi=pi, c=c, rho=rho, g=g,
                        t_issue=self._now(),
                        h_pi=hashlib.sha256(pi.tobytes()).hexdigest())
            if best is None or g < best['g']:   # anytime 单调改进
                best = cert
        return best   # 可能为 None / 不可行证书

    def _clearance(self, pi, obstacles):
        return min(obstacles.distance(s) for s in pi.states)

    def _dyn_margin(self, pi):
        return float(np.min(pi.u_max[None, :] - np.abs(pi.controls)))


class PlanCertificateVerifier:
    def verify(self, cert, now, tau_plan):
        if cert is None:
            return False, 'no_cert'
        if now - cert['t_issue'] > tau_plan['ttl']:
            return False, 'stale'
        if hashlib.sha256(cert['pi'].tobytes()).hexdigest() != cert['h_pi']:
            return False, 'tampered'
        if cert['c'] < tau_plan['c_min']:   return False, 'clearance'
        if cert['rho'] < tau_plan['rho_min']: return False, 'dyn'
        if cert['g'] > tau_plan['g_max']:   return False, 'gap'
        return True, 'ok'


class RecedingHorizonFallback:
    def __init__(self, planner, horizon=0.3):
        self.planner, self.horizon = planner, horizon
    def plan(self, s0, obstacles, budget):
        # 只规划短视界，保证 TTL 内可返回；无全局最优性保证，但安全
        return self.planner.short_horizon(s0, obstacles, self.horizon, budget)


# IP-359/360：声明-证据账本与证据闭合度（外环，离线）
class ClaimEvidenceLedger:
    def __init__(self, claims, experiments, links, falsifiers, repro):
        self.C = claims
        self.E = experiments
        self.L = set(links)
        self.fal = falsifiers          # {claim: str}
        self.rep = repro               # {claim: 'replicated'|'single-run'|'unknown'}
        self.omega = {c: 1.0 for c in claims}

    def orphan_claims(self):
        return [c for c in self.C
                if not any((c, e) in self.L for e in self.E)]

    def orphan_experiments(self):
        return [e for e in self.E
                if not any((c, e) in self.L for c in self.C)]

    def closure(self, c):
        has_thm = bool(self.fal.get(c, '') or c.startswith('定理'))
        linked = [e for (cc, e) in self.L if cc == c]
        return float(has_thm and linked and self.fal.get(c)
                     and self.rep.get(c) == 'replicated')

    def cec(self):
        tot = sum(self.omega.values())
        return sum(self.omega[c] * self.closure(c) for c in self.C) / tot \
            if tot else 0.0


# IP-361：对抗审稿器（外环）
class AdversarialReviewer:
    def __init__(self, claim_tester, K=32, seed=0):
        self.tester, self.K = claim_tester, K
        self.rng = np.random.default_rng(seed)

    def risk_rev(self, claim, base_config):
        alive = 0
        for _ in range(self.K):
            delta = self._sample_perturbation(base_config)
            alive += int(self.tester(claim, delta))
        return 1.0 - alive / self.K

    def _sample_perturbation(self, cfg):
        return {k: v * (1 + self.rng.uniform(-0.1, 0.1))
                if isinstance(v, float) else v for k, v in cfg.items()}


# IP-363/364：双时间尺度安全包络 + 外环污染隔离
class TwoTimescaleSafetyEnvelope:
    L_SAFE = ('0', '1', 'dom', 'SLAM', 'plan')
    L_PERF = ('2', '3')
    def __init__(self, tau, eps_approve=0.02, eps_perf=0.05):
        self.tau = dict(tau)
        self.eps_approve, self.eps_perf = eps_approve, eps_perf

    def submit(self, tau_new, approve_token=None):
        for i, v in tau_new.items():
            old = self.tau[i]
            if i in self.L_SAFE:
                if v <= old + self.eps_approve:
                    self.tau[i] = v
                elif approve_token is not None:
                    self.tau[i] = v
                # 否则拒绝放宽：保持旧值（安全默认）
            elif i in self.L_PERF:
                if abs(v - old) <= self.eps_perf:
                    self.tau[i] = v
        return self.tau


class OuterLoopContaminationIsolation:
    def __init__(self):
        self.committed = None      # 当前内环可见的不可变快照
        self._pending = None       # 外环写缓冲
    def stage(self, payload):
        self._pending = payload    # 外环只写缓冲，绝不碰 committed
    def commit_at_barrier(self):
        if self._pending is not None:
            self.committed = self._pending   # 相位边界原子 swap
            self._pending = None
    def snapshot(self):
        return self.committed      # 内环无锁读取

def metricvoicegauge_round_9(M, s, obs, goal, obstacles, now,
                             cap=None, verifier=None, rhf=None,
                             ttse_snapshot=None):
    """内环：证书门控 + 六维风险；外环组件全部通过快照读取，零阻塞"""
```

## 4. 推导

**引理 82（计划证书 soundness）** 若 `valid(Cert_plan,t)` 为真且执行器严格执行 `π` 的前 `T` 步，则执行轨迹满足 `c(π) ≥ c_min` 与 `ρ(π) ≥ ρ_min`。证明：`valid` 定义直接蕴含两不等式；`h_π = H(π)` 保证被验证轨迹与被执行轨迹同一，排除验证后替换。对离散执行，需额外假设执行扰动 `‖u_t − u_t^π‖ ≤ ε_trk`，此时结论弱化为 `c(π) − L_ε·ε_trk ≥ c_min`，其中 `L_ε` 为 Lipschitz 常数。

**引理 83（anytime 单调性与不可行证书）** CAP 在计算时间上返回的次优间隙 `g(t)` 单调不增；若上界 `J_ub(t)` 与下界 `J_lb(t)` 在 `time_budget` 内未收敛到 `g ≤ g_max`，规划器返回显式**不可行/未证证书**而非「看似可行」的轨迹。证明：`best` 仅在 `g` 严格减小时更新；下界 `J_lb` 由松弛问题给出且随搜索收紧单调不减，故 `g = J_ub − J_lb` 在不更新上界时可能非单调——因此实现需保留历史最小 `g`（代码中 `if best is None or g < best['g']` 已保证单调）。不可行分支返回 `None`，由门控拒绝执行。

**引理 84（M_plan 退化无空洞）** `M_plan` 违背 ⇒ `δ_plan` 直接触发 `M₀` 硬约束检查；`M₀` 判据 `τ₀` 与 `c_min/ρ_min` 同尺度（均为物理余量下界），故「计划层软通过、硬层却失」不可能发生。证明同引理 81 的尺度对齐论证：`τ₀` 定义为 `c ≥ c_min ∧ ρ ≥ ρ_min` 的下界，任意 `M_plan` 违背都等价于 `M₀` 不满足。

**引理 85（证据闭合度的单调性）** 固定 `C`，增加任一支撑边 `(c,e)∈L` 不会降低 `CEC`；固定 `L`，新增一条无证据声明 `c'` 会降低 `CEC`（除非其 `ω(c')` 为 0）。证明：`clos(c)` 关于 `L` 逐项单调不减，加权平均保序；新增 `c'` 使分母增 `ω(c')`、分子增 `ω(c')·clos(c') ≤ ω(c')`，故比值不增。推论：**准入规则**——新声明必须自带「定理 + 实验 + 可反驳条件」，否则 `CEC` 下降，外环将其标为待补证据。

**引理 86（审稿风险有界性与集中）** `risk_REV(c) ∈ [0,1]` 恒成立。若 `survive(c,δ_k)` 对独立扰动为独立同分布伯努利，则 `K` 次采样估计的偏差满足 Hoeffding 界 `P(|risk_REV_hat − risk_REV| ≥ ε) ≤ 2exp(−2Kε²)`；取 `K=32, ε=0.2` 时失败概率 ≤ 3.4×10⁻³。故审稿风险可用小样本可靠估计，无需昂贵穷举。

**引理 87（TTSE 实时隔离与安全单调）** 由定义 549，安全层阈值更新满足 `τ^new ≤ τ^old + ε_approve`，故 `τ_i` 沿时间单调不增（不许放宽），系统保守性单调不减；由定义 550，外环仅写 double-buffer，内环在相位屏障读取不可变快照，外环计算时长完全不在内环关键路径上，故内环 WCET 与 v8 相同（≤22ms），不受外环负载影响。证明：内环代码路径不调用任何外环函数，只做一次指针读取（O(1)）。

**引理 88（三级退化正确性）** 任意单模块失效：CAP/PCV 失效 ⇒ `cert_ok≡True`，内环退化为无门控 IAC 规划（等价 v8）；CEL/AR/PGP 失效 ⇒ 外环跳过、产物 `draft`，内环等价 v8；RM 失效 ⇒ 仅置标志，内环等价 v8；TTSE/OLCI 失效 ⇒ 外环不提交，内环用最后快照（等价 v8 固定阈值）。各接口正交：CAP 只改执行门控，CEL/AR 只写外环产物，RM 只写标志，TTSE 只改阈值提交，互无级联。全失效 ⇒ 完整退回 v8。证明：逐组件检查接口写入集合互不相交。

## 8. 本轮最大风险

**一句话**：若把外环的「审稿风险 / 证据闭合度」误接成内环奖励信号，系统会为讨好假想审稿人而自我审查——规划证书阈值越收越紧、任务成功率下降；再叠加对抗审稿器的假阳性（把稳健声明判为脆弱）与 TTSE/OLCI 在相位屏障的时序抖动，三者合卷下，「系统为追求发表级证据闭合而过度保守，牺牲真实任务能力」——因此必须用引理 87 把外环严格挡在 WCET 之外，并规定 `risk_REV` 只用于**下一轮研究优先级**，绝不进入当前轮的 execute/reward 路径。
