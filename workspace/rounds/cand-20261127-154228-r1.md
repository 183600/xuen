### 第 1 轮灵感驱动研究记录（TALC：力矩感知的长程证书）

**灵感词**：力矩控制、长程任务

**直觉与动机**：

现有 CADVS/v29 证书链隐含两个未经审视的假设：证书是「瞬时」的，且是「运动学」的。KT-MPC 与视觉伺服签发的是速度/位姿层面的安全断言，但真正驱动机械系统的是关节力矩 τ；而证书按步签发，却没有回答「这些逐步断言能否在几十秒的任务中组合成一条全局安全轨迹」。本轮两个灵感词恰好对应这两道裂缝。

1. **力矩控制（向下接地）**：证书说「这个位姿/这条空间速度安全」，并不等于「存在一组满足 τ_max、τ̇_max、关节热约束与接触摩擦锥的力矩能实现它」。运动学可行并不蕴含执行器可行。在高动态或接触丰富场景中，真正的失效往往不是几何碰撞，而是力矩饱和、关节过热、摩擦锥滑移。因此需要一张「力矩可行性证书」TFC，把任务空间证书向下接地到执行器，并把 TFC 作为任务证书的**必要条件**：若 TFC 不可行，上层证书必须作废，而不是继续被消费。

2. **长程任务（向时间延展）**：证书逐 step 有效，但长程任务会累积模型误差、接触模式切换、热积累与证书裕度漂移。局部安全的逐点合取并不蕴含全局安全——这是控制里的老问题，也是形式化方法里的组合难题。解决思路不是让单张证书「永远有效」，而是给证书定义「寿命」与「预算」：证书是一次可消耗的资源，会随步数衰减，需要在对的时刻、以计算代价重新签发。于是「何时刷新证书」变成一个受计算预算约束的安全调度问题。

**关键洞见**：力矩控制提供「执行器维度的接地」，长程任务提供「时间维度的延展」。二者合力要求证书从「点」升级为「时空体」：既要在执行器空间可行（TFC），又要在一段时域内可组合、可刷新、可证伪（寿命 / 预算 / 超鞅）。这使安全论证从「每一步都对」升级为「整条长程轨迹以概率 1−δ 安全，且每一步的力矩都真实可实现」。

**形式化目标（增量）**：
1. 定义力矩可行性证书 TFC = (m_τ, m_ṙ, m_T, m_c) 与全身动力学 QP 的可行性判据。
2. 定义证书寿命 L(m) = ⌊(m − ε) / δ_max⌋ 与证书预算动力学 B_{k+1} = max(0, B_k − δ_k) + r_k。
3. 定义长程安全超鞅证书 Φ 与带漂移的移位技巧 Ψ_k = Φ_k + b(H − k)，导出 P(到达不安全集) ≤ Φ_0 + bH。
4. 定义证书刷新调度：在刷新代价 c_r 与风险预算 δ 下最小化期望刷新次数。
5. 证明 Exec_TALC ⊆ Exec_CADVS ⊆ Exec_v29，并给出长程 N 段 option 复合的联合界。

**本轮最大风险**：长程超鞅证书的漂移界 b 必须同时「可靠」与「不保守」，但 b 只能由有限数据与模型估计；一旦接触模式切换或分布漂移使超鞅性失效，证书会在形式上「存活」而经验上「失真」，产生力矩级 / 长程级的虚假安全——这比瞬时证书失效更隐蔽，因为系统能长时间不报警却已悄然越过安全边界。

## 2. 关键算法骨架

### IP-478 Torque Feasibility Certificate (TFC)

```python
@dataclass
class TFCMargins:
    m_tau: float      # 力矩裕度
    m_rate: float     # 力矩变化率裕度
    m_therm: float    # 热裕度
    m_contact: float  # 摩擦锥裕度
    def min(self) -> float:
        return min(self.m_tau, self.m_rate, self.m_therm, self.m_contact)

@dataclass
class TorqueFeasibilityCertificate:
    """TFC：把任务空间证书向下接地到执行器。
    核心断言：任务证书只有在全身动力学 QP 可行且四类裕度 ≥ ε 时才是 actuation-realizable。
    """
    tau_max: np.ndarray
    tau_dot_max: np.ndarray
    T_max: np.ndarray
    mu: float = 0.6
    eps: float = 0.05
    thermal_a: float = 0.02      # 温升系数
    thermal_cool: float = 0.01   # 散热系数

    def margins(self, tau, tau_dot, temps, contacts) -> TFCMargins:
        m_tau = float(np.min((self.tau_max - np.abs(tau)) / self.tau_max))
        m_rate = float(np.min((self.tau_dot_max - np.abs(tau_dot)) / self.tau_dot_max))
        m_therm = float(np.min((self.T_max - temps) / self.T_max))
        # contacts: list[(f_n, f_t)]，摩擦锥线性化后的法向/切向力
        m_contact = min(
            (self.mu * fn - abs(ft)) / (self.mu * fn + 1e-9)
            for fn, ft in contacts
        )
        return TFCMargins(m_tau, m_rate, m_therm, m_contact)

    def thermal_update(self, temps, tau, dt) -> np.ndarray:
        # 一阶热模型：dT/dt = a·τ² − c·(T − T_amb)
        return temps + dt * (self.thermal_a * tau**2 - self.thermal_cool * temps)

    def solve(self, model, x, qdd_ref, contact_set, tau_prev, dt):
        """全身动力学 QP（优先级 / 软约束版本）。

        decision z = (tau, f_c, s)
        minimize   ||J_task^T f_c − w_des||² + ρ||s||²
        s.t.       M(q)q̈ + C(q,q̇)q̇ + g(q) = S τ + J_c^T f_c
                   τ_min − s ≤ τ ≤ τ_max + s
                   |τ − τ_prev| ≤ τ̇_max·dt
                   −μ f_n ≤ f_t ≤ μ f_n,  f_n ≥ 0
                   s ≥ 0（松弛变量，仅用于诊断不可行来源）
        返回 (tau*, feasible, margins*, active_slack)
        """
        q, qd = x.q, x.qd
        n, nc = model.n, len(contact_set)
        # 组装等式与不等式约束（此处省略稀疏矩阵细节）
        A_dyn, b_dyn = model.dynamics_equality(q, qd, qdd_ref, contact_set)
        A_ineq, b_ineq = model.inequality_constraints(
            tau_prev, dt, self.tau_max, self.tau_dot_max,
            self.mu, contact_set)
        z = solve_qp(A_dyn, b_dyn, A_ineq, b_ineq, cost_weights=...)
        tau_star, f_c, slack = unpack(z)
        feasible = (np.max(slack) <= 1e-6)
        m = self.margins(tau_star, (tau_star - tau_prev) / dt,
                         x.temps, f_c)
        return tau_star, feasible, m, slack

    def gate(self, feasible: bool, m: TFCMargins) -> bool:
        # KC 规则 kc_torque_feasible：可行性 ∧ 四类裕度全部达标
        return feasible and m.min() >= self.eps
```

**关键设计**：TFC 不是「又一个软性打分」，而是**任务证书的必要条件**。上层十二证通过后，若 TFC.gate 为假，则上层证书被显式降级为 `void`，触发教师/保守 option，而非继续消费——这保证 Exec_TALC 是 Exec_CADVS 的真子集。

### IP-479 Certificate Lifetime & Budget Algebra (CLBA)

```python
@dataclass
class CertificateLifetimeAlgebra:
    """CLBA：把「瞬时证书」升级为「可消耗、可组合、可刷新」的时序资源。"""
    eps: float = 0.05
    delta_max: float = 0.01          # margin 单位 / step
    switch_penalty: float = 0.02     # 每次接触模式切换的 margin 惩罚

    def lifetime(self, margin: float) -> int:
        # 引理 33：若每步衰减 ≤ δ_max，则 L(m) 步内裕度仍 ≥ ε
        return max(0, int(np.floor((margin - self.eps) / self.delta_max)))

    def compose(self, segments) -> int:
        """segments: list[(margin, n_switch_before)]。
        组合寿命 = Σ L(m_i) − Σ ⌈c_sw/δ_max⌉（切换会吃掉预算）。"""
        total = 0
        for margin, n_switch in segments:
            total += self.lifetime(margin)
            total -= int(np.ceil(n_switch * self.switch_penalty / self.delta_max))
        return max(0, total)

    def min_refreshes(self, H: int, margin: float) -> int:
        L = self.lifetime(margin)
        if L <= 0:
            return float('inf')
        # 初始证书覆盖第一段，其余需刷新
        return max(0, int(np.ceil(H / L)) - 1)


class CertificateBudget:
    """预算动力学：B_{k+1} = max(0, B_k − δ_k) + r_k。安全要求 B_k ≥ 0。"""
    def __init__(self, B0: float = 0.0):
        self.B = B0
        self.min_B = B0
        self.log = []

    def spend(self, drift: float):
        self.B = max(0.0, self.B - drift)
        self.min_B = min(self.min_B, self.B)

    def refresh(self, margin: float):
        self.B += max(0.0, margin - self.eps)

    def alive(self) -> bool:
        return self.B > 0.0
```

### IP-480 Long-Horizon Refresh Scheduler (LHRS)

```python
def optimal_refresh_dp(H, L, c_refresh, p_extra_drift):
    """在 H 步长程任务上最小化期望刷新次数。
    状态 (h, l)：剩余 h 步、当前证书剩余寿命 l。
    动作：不刷新（以 p_extra_drift 概率多掉一格）或刷新（代价 c_refresh，l←L）。
    """
    INF = float('inf')
    V = np.full((H + 1, L + 1), INF)
    policy = np.zeros((H + 1, L + 1), dtype=bool)  # True = refresh
    V[0, :] = 0.0
    for h in range(1, H + 1):
        for l in range(L + 1):
            best, act = INF, False
            if l >= 1:
                keep = ((1 - p_extra_drift) * V[h - 1, max(0, l - 1)]
                        + p_extra_drift * V[h - 1, max(0, l - 2)])
                best, act = keep, False
            refresh = c_refresh + V[h - 1, L]
            if refresh < best:
                best, act = refresh, True
            V[h, l], policy[h, l] = best, act
    return V, policy


class LongHorizonRefreshScheduler:
    """在线阈值策略 + 离线 DP 校准；同时受计算预算与风险预算约束。"""
    def __init__(self, clba: CertificateLifetimeAlgebra,
                 c_refresh: float, risk_budget: float):
        self.clba = clba
        self.c_refresh = c_refresh
        self.risk_budget = risk_budget

    def should_refresh(self, remaining_horizon, current_margin,
                       remaining_compute_budget, msc: "MartingaleSafetyCertificate",
                       x) -> bool:
        L = self.clba.lifetime(current_margin)
        # 1) 硬约束：当前证书无法覆盖剩余时域 → 必须刷新
        if L < remaining_horizon:
            return remaining_compute_budget >= self.c_refresh
        # 2) 风险约束：超鞅上界逼近风险预算 → 提前刷新
        bound = msc.phi(x) + msc.drift_bound * remaining_horizon
        if bound > 0.5 * self.risk_budget:
            return remaining_compute_budget >= self.c_refresh
        return False
```

### IP-481 Martingale Safety Certificate (MSC)

```python
@dataclass
class MartingaleSafetyCertificate:
    """MSC：长程概率安全证书。
    Φ(x) ≥ 1 在不安全集上；E[Φ_{k+1}|F_k] ≤ Φ_k + b。
    引理 34：Ψ_k = Φ_k + b(H−k) 为非负超鞅，故 P(sup_{k≤H} Φ_k ≥ 1) ≤ Φ_0 + bH。
    """
    phi: Callable[[Any], float]
    drift_bound: float

    def certify(self, x0, H: int) -> float:
        return self.phi(x0) + self.drift_bound * H   # ≤ δ 即安全

    def composed_bound(self, segments) -> float:
        """N 段 option 的联合界（union bound）。
        segments: list[(x0_i, H_i, b_i)]。"""
        return sum(self.phi(x0) + b * H for x0, H, b in segments)


def build_torque_barrier(eps, tau_max):
    """把力矩裕度并入势函数：Φ = Φ_task + λ·Σ_j max(0, 1 − |τ_j|/τ_max,j)⁻¹。
    工程上更常用倒数/指数形式，使 Φ→∞ 当力矩逼近边界。"""
    def phi(x):
        m = float(np.min((tau_max - np.abs(x.tau)) / tau_max))
        task_term = x.task_potential
        torque_term = 1.0 / max(m - eps, 1e-6) if m > eps else 1e6
        return task_term + torque_term
    return phi
```

### IP-482 Hierarchical Option Certificate (HOC)

```python
@dataclass
class CertifiedOption:
    """已认证 option：技能本身携带长程证书与力矩证书。"""
    name: str
    init: Callable[[Any], bool]
    terminate: Callable[[Any], bool]
    policy: Callable[[Any], np.ndarray]      # 输出任务加速度 / 期望 wrench
    msc: MartingaleSafetyCertificate
    lifetime: int
    tfc: TorqueFeasibilityCertificate

    def handoff(self, x) -> bool:
        """技能切换时的证书交接：终止状态必须仍满足下一技能 init 且力矩裕度 > ε。"""
        return (self.terminate(x) and self.tfc.gate(True, self.tfc.margins(
            x.tau, x.tau_dot, x.temps, x.contacts)))


class HierarchicalCertificateScheduler:
    def __init__(self, options: list[CertifiedOption],
                 clba: CertificateLifetimeAlgebra, budget: CertificateBudget):
        self.options = options
        self.clba = clba
        self.budget = budget

    def select(self, x, task):
        # 1) 过滤 init 成立、MSC 可证、预算非负的 option
        feasible = [
            o for o in self.options
            if o.init(x) and o.msc.certify(x, o.lifetime) <= task.risk_budget
            and self.budget.alive()
        ]
        if not feasible:
            return self.options[0]        # 保守兜底 option
        # 2) 在可行集中选「证书预算消耗率最低」者
        return min(feasible, key=lambda o: o.msc.drift_bound / max(o.lifetime, 1))
```

### TALC 统一执行流（单步，力矩出口）

```python
def talc_step(x: RobotState, task: TaskSpec, ctx: TALCContext) -> ControlOutput:
    """
    TALC 单步：
      高层：选择已认证 option（HOC + LHRS）
      中层：CADVS 十二证 + 视觉伺服（沿用 v29/CADVS）
      低层：任务加速度 → TFC QP → 关节力矩 τ
    任一环节失败 → 证书 void → 降级/教师/急停。
    """
    # 1) 高层 option 选择
    opt = ctx.hier_scheduler.select(x, task)
    if opt is None:
        return safe_stop(reason='no_certified_option')

    # 2) 中层 CADVS 证书聚合（十二证 + 视觉伺服）
    cert_agg = ctx.cert_checker.snapshot()
    if not cert_agg.all_passed:
        return ctx.fallback.to_teacher(x, reason='cert_agg_fail')

    # 3) 低层力矩证书：任务加速度 → 全身动力学 QP
    qdd_ref = opt.policy(x)
    tau_star, feasible, m, slack = opt.tfc.solve(
        ctx.model, x, qdd_ref, ctx.contact_set, x.tau_prev, ctx.dt)
    if not opt.tfc.gate(feasible, m):
        # 力矩不可行：上层证书作废，绝不继续消费
        return ctx.fallback.degrade(x, reason='tfc_infeasible',
                                    active_slack=slack)

    # 4) 预算更新与刷新决策
    ctx.budget.spend(ctx.clba.delta_max)
    if ctx.refresh_scheduler.should_refresh(
            task.remaining_steps, m.min(), ctx.remaining_compute,
            opt.msc, x):
        ctx.budget.refresh(m.min())
        ctx.recompute_option(opt, x)      # 重新签发证书（花费 c_refresh）

    # 5) 输出关节力矩
    return ControlOutput(
        tau=tau_star,
        path='talc',
        certs=(cert_agg, m),
        budget=ctx.budget.B,
        option=opt.name,
    )
```

## 3. 复杂度分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 | 实时性指标 |
|---|---|---|---|---|
| TFC 全身动力学 QP | O((n+n_c)³) 最坏，稀疏 active-set 近 O(n²) | O(n² + n·n_c) | n≈23，n_c≤4 | < 1.5ms @ 1kHz |
| TFC 裕度计算 | O(n + n_c) | O(1) | — | < 0.01ms |
| 热模型更新 | O(n) | O(n) | — | < 0.01ms |
| CLBA 寿命/预算 | O(1) / O(N_seg) | O(1) | δ_max | < 0.01ms |
| LHRS 离线 DP | O(H·L) | O(H·L) | H≤2000，L≤200 | 离线，秒级 |
| LHRS 在线决策 | O(1) | O(1) | — | < 0.01ms |
| MSC 评估 | O(cost Φ)，通常 O(n²) | O(1) | — | < 0.05ms |
| HOC option 选择 | O(N_opt) | O(N_opt) | N_opt≤16 | < 0.02ms |
| **端到端（1kHz 力矩环）** | **期望 < 1.6ms** | **O(n² + n·n_c)** | **P99 < 2ms** | **满足 1kHz** |
| **高层重规划（option 切换）** | **≤ 20ms** | **同 CADVS** | **低频 5–20Hz** | **不劣化 CADVS** |

**通信/计算开销**：TFC 在关节控制层本地求解，不跨网；MSC/CLBA 只需 (Φ, B, L) 三个标量随证书摘要广播，额外带宽 < 64 bytes/条。

## 4. 正确性论证（增量更新）

### 引理 32（力矩可实现性：任务证书的必要条件）

**陈述**：给定任务空间期望 wrench w_des 与接触模式集合 C，若对所有 c ∈ C，全身动力学 QP（含力矩盒约束、力矩率约束、线性化摩擦锥）均不可行，则不存在任何关节力矩轨迹 τ(·) 能实现 w_des；因此上层任务证书必须被声明为 void。反之，若 QP 可行且四类裕度 ≥ ε，则 w_des 在该线性化模型下是 actuation-realizable 的。

**证明**：QP 的可行域正是「满足动力学等式、力矩/力矩率盒、摩擦锥」的 (τ, f_c) 集合。若该集合为空，则不存在满足物理约束的力矩实现 w_des，矛盾。反向由构造：QP 解 z* 逐条满足约束，故可实现；线性化摩擦锥的误差由内接多面体保证保守（内接 ⇒ 真实锥的超集约束 ⇒ 可行解仍满足真实锥的子集近似）。∎

**工程含义**：TFC 把「几何安全」与「执行器安全」显式分离。CADVS 的十二证保证前者，TFC 保证后者；二者是**合取**关系，因此 Exec_TALC ⊆ Exec_CADVS。

### 引理 33（证书寿命的保守性）

**陈述**：若证书裕度序列满足 |m_{k+1} − m_k| ≤ δ_max，且 m_0 ≥ ε，则对任意 k ≤ L(m_0) = ⌊(m_0 − ε)/δ_max⌋，有 m_k ≥ ε。

**证明**：由三角不等式 m_k ≥ m_0 − k·δ_max ≥ m_0 − L(m_0)·δ_max ≥ ε。∎

**工程含义**：δ_max 可由裕度对状态/控制输入的 Lipschitz 常数与扰动界估计得到；它是「证书能活多久」的唯一标定参数。L(m) 给出的是**最坏情况**寿命，实际可更久。

### 引理 34（带漂移超鞅的 Ville 界）

**陈述**：设 Φ(x) ≥ 0，且 E[Φ_{k+1} | F_k] ≤ Φ_k + b。定义 Ψ_k = Φ_k + b(H − k)。则 {Ψ_k} 是非负超鞅，且 P(sup_{0≤k≤H} Φ_k ≥ 1) ≤ Φ_0 + bH。

**证明**：
E[Ψ_{k+1}|F_k] = E[Φ_{k+1}|F_k] + b(H−k−1) ≤ Φ_k + b + b(H−k−1) = Φ_k + b(H−k) = Ψ_k，故 Ψ 为超鞅。由 Ville 不等式，P(sup_k Ψ_k ≥ 1) ≤ E[Ψ_0] = Φ_0 + bH。又 Ψ_k ≥ Φ_k，故 P(sup_k Φ_k ≥ 1) ≤ P(sup_k Ψ_k ≥ 1) ≤ Φ_0 + bH。∎

**工程含义**：只要把不安全集嵌入 Φ ≥ 1 的 level set，且能在线估计漂移上界 b，就能得到**不依赖马尔可夫链混合时间**的长程概率安全界。b 的估计质量决定界的可用性。

### 定理（TALC 执行集收缩与长程复合安全）

**陈述**：在以下假设下：
(A1) 每步 TFC 可行且裕度 ≥ ε（引理 32）；
(A2) 证书寿命按引理 33 标定，δ_max 为真实上界；
(A3) 每个 option 的 Φ_i 满足引理 34 的超鞅条件，漂移界为 b_i；
(A4) 预算调度使 B_k ≥ 0 对所有 k 成立；
则：
(i) **执行集收缩**：Exec_TALC ⊆ Exec_CADVS ⊆ Exec_v29；
(ii) **长程复合安全**：对分解为 N 段、总时域 H = Σ H_i 的任务，
P(在 H 内任一时刻进入不安全集) ≤ Σ_{i=1}^N (Φ_i(x_{i,0}) + b_i H_i)。

**证明**：
(i) TALC 单步要求 CADVS 十二证全通过（中层）**且** TFC.gate 为真（低层）。后者是新增的合取条件，故 TALC 允许的控制序列是 CADVS 的子集；CADVS 已证 ⊆ Exec_v29，传递得证。
(ii) 对每段 i，由引理 34，P(段 i 内进入不安全集) ≤ Φ_i(x_{i,0}) + b_i H_i。对 N 段取 union bound，得总概率上界。预算条件 (A4) 保证段间不会因证书过期而出现未计入的「空窗」。∎

**诚实声明**：上述界的可用性取决于三个「不恒真」的前提：(A1) 接触模式突变、执行器故障会让 QP 不可行；(A2) δ_max 是估计值，分布漂移会使其被低估；(A3) 超鞅性在接触切换、载荷突变时会失效，b_i 需在线重估。TALC 用「TFC 硬门控 + 预算硬门控 + 刷新」管理这些风险，但**不能消除**模型失配带来的伪证书风险。

## 5. 实验设计

**平台**：MuJoCo（Unitree G1 人形、四足、7-DoF 机械臂）；真实平台小规模验证（关节温度与力矩饱和）。

**任务（长程）**：
- T1：30–120s 搬箱行走（负载变化 + 台阶）；
- T2：长程 loco-manipulation（走到桌前 → 抓取 → 转身 → 放置）；
- T3：接触丰富装配（持续接触 + 模式切换）。

**基线**：CADVS（仅运动学证书）、固定间隔刷新、鲁棒 MPC + CBF、无热约束 TFC。

**指标**：安全违规次数 / 千步；力矩饱和占比；峰值关节温度；任务成功率随时域长度的曲线；预算最小值 min B；刷新次数；QP 求解 P99。

**消融**：仅 TFC / 仅 CLBA / 仅 MSC / 仅 HOC / 全量。

**预期（可证伪的量化假设）**：
- H1：TFC 使「力矩饱和导致的跌倒」下降 ≥ 40%；
- H2：CLBA + LHRS 使 120s 任务的安全违规率较固定刷新下降 ≥ 50%，且刷新次数 ≤ 固定方案的 60%；
- H3：MSC 的预测界在 95% 置信下不被违反（校准曲线贴近对角线）；
- H4：全量 TALC 的成功率随时域长度的衰减斜率显著小于 CADVS（p < 0.05）。

## 7. 本轮最大风险（最终确认）

**一句话**：**长程超鞅证书的漂移界 b 必须同时「可靠」与「不保守」，但 b 只能由有限数据与模型估计；一旦接触模式切换或分布漂移使超鞅性失效，证书会在形式上「存活」而经验上「失真」，产生力矩级 / 长程级的虚假安全——系统能长时间不报警却已悄然越过安全边界，这是 TALC 从「可证」走向「可信」的生死线。**
