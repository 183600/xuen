# 第 3 轮（灵感循环续轮；本轮灵感：「竞品分析」×「可靠性」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440），
> 其下为第 1 轮 **LeanGauge**（IP-310–314；定义 398–415；引理 42–45；实验 E411–E425）与 **MODGAUGE**。
> **本轮纪律**：不造更大的闭环，也不替换任何数值模块，只补 ToolGauge 的两个**证明缺口**：
> （1）**自证缺口**——V 阶段的「独立回执」仍来自同一工具库 T₀ 与同一物理假设，属于**同源自证**；
> （2）**时证缺口**——一次局部后验方差下降，不能推出系统在任务时间轴上持续正确。
> MODGAUGE 五不变式、ToolGauge 的 TCV / 双层下注 / AP-Cal / P-Quarantine 全部保留；
> 并把 6C 扩为 7C（第 7 段 R = Reliability），退化链延长为
> `TrustGauge ⇐ ToolGauge ⇐ LeanGauge ⇐ MODGAUGE`。

## 0. 双轴映射（补证明，而非重写）

| 灵感词 | 第 2 轮的结构性缺口 | 升级为 | 一句话动机 |
|---|---|---|---|
| 竞品分析 | V 阶段「独立回执」仍由同一 T₀ 产生，只能证明**自洽**，证明不了**正确** | **C-Panel 竞品委员会 + DiffCert 差异认证** | 可靠性不能自证：部署前必须在预注册基准组上与独立竞品分出**统计显著差异**，否则判定「不可区分」并拒绝切换 |
| 可靠性 | 6C 只做「单点方差修复」，没有失效率、可用性、冗余、共因分析与长期增长检验 | **R-Ledger 可靠性账本 + 多样冗余表决 + 增长门** | 修复的价值应由**任务可靠性增长**证明，而不是由后验方差证明；「修好一次」 ≠ 「长期可靠」 |

**核心命题**：`TrustGauge = ToolGauge + C-Panel + R-Ledger`。
ToolGauge 的信任是「自证 + 瞬时」的；本轮把它升级为「**他证 + 时证**」：
- **横向（他证）**：用竞品差异认证回答「你凭什么比现有方案好」，并诚实承认竞品只能测**相对**优势；
- **纵向（时证）**：用可靠性账本回答「这次替换在长时间尺度上是否真的降低了失效」，并把「修复」当作可失效的再配置而非免费增益。

三条可检验主张：
1. 差异认证能显著降低**过拟合式热替换**（相对基线单点 V 阶段），但在共因 β→1 时检出力趋于 0，故必须配正交锚；
2. 可靠性增长检验（Crow-AMSAA）能识别「局部方差下降但长期失效不降」的伪修复；不完美修复会使表观增长指数系统性偏乐观；
3. 在不改变 50Hz 数值路径与五不变式的前提下，可靠性门与影子部署可把「部署即污染」变为「可回滚的金丝雀」，退化链保持 fail-safe 取向。

## 0.1 直觉解释（先直觉，后定义）

**灵感 1：竞品分析 = 把「自洽」换成「可比的相对优越」。**
第 2 轮的 V 阶段让 `cross.modal` 回执与拟合结果比对，看起来是独立验证，但两者共享同一工具库、同一标定链、同一安装基准。
直觉上这像「用同一把可能弯了的尺子去校验自己」——只能发现随机误差，发现不了共同偏差。
竞品分析（competitive analysis）的工程智慧恰好是解药，但它的边界也必须讲清：
- 预注册基准组（不能事后挑对自己有利的题）；
- 多个**独立性三元组不同**的实现（数据源 / 物理原理 / 模型族）；
- 用**差异 margin + 显著性检验**代替「我很好」的绝对断言；
- 当所有竞品在统计上无法分离时，正确结论是**不可区分 → 不切换**（缺失证据不是证据）；
- 竞品分析测的是**相对**优势：若大家都错在同一处（共因偏差），竞品一起错，系统会**更自信地错**。
所以必须显式引入**正交锚**（物理独立的外部计量/标准件/人工抽检）来测共同偏差 b；`|b|` 超限时整块认证暂停。

**灵感 2：可靠性 = 把「修复事件」纳入失效过程，而不是当作一次性胜利。**
可靠性工程（reliability engineering）的核心不是「修好了」，而是「在任务时间内不失效的概率」：
失效是随机过程，需要 MTBF、MTTR、可用性 A、任务可靠度 R(T)、浴盆曲线、FMEA、可靠性增长（Crow-AMSAA / Duane）、
加速寿命（Weibull / Arrhenius）、降额（derating）、冗余与共因 β 因子、影子/金丝雀发布。
映射到本系统：
- 每个格的契约是一个**可修复部件**；盲区再次出现 / V 失败 / 回归失败 / 金丝雀漂移都是**失效事件**；
- 热替换是**再配置**（reconfiguration），可能引入新失效模式（新工具依赖、表决器开销），因此替换前必须有**可靠性门**；
- 局部后验方差下降只是「瞬时精度指标」，必须用**可靠性增长检验**证明失效率长期下降，否则判为伪修复；
- 安全关键格用 **k-of-n 多样冗余**，但冗余必须**多样**（物理原理不同）以压低共因 β，且表决器本身是单点失效，需自检。

**综合**：竞品分析给「横向他证」，可靠性给「纵向时证」；两者都**不进入数值真值通道**，
只作为**准入闸门**与**账本证据**；语言层关于「更可靠」的主张必须引用账本统计量（定义 445），否则剥离。
这样既正面回应第 2 轮最大风险（跨盲区相关偏差），又避免把「可信」外包给一个更大的黑箱。

## 1. 形式化定义（增量：定义 432–447）

**定义 432（竞品估计器 Competitor）** 竞品 c = (M_c, cost_c, Ind_c)：
- M_c : Context → (μ_c, σ_c)，把盲区上下文映射为契约参数估计与声明不确定度；
- cost_c：归一化推理/部署代价；
- **独立性三元组** Ind_c = (数据源, 物理原理, 模型族)。两个竞品「独立」当且仅当三元组两两不同；
  仅换随机种子或仅换超参不算独立（防「同一先验的多个副本」）。

**定义 433（竞品委员会与预注册基准组 C-Panel / 𝔅）** C = {c_1,…,c_n} ∪ {c_0 = 当前 MODGAUGE 契约}；
基准组 𝔅_s = {(τ_k, ctx_k, y*_k)} 在部署前**一次性预注册**，含留出任务、压力场景与真值来源；
真值 y*_k 只能来自正交锚（定义 436），不得来自任何竞品自身。
C-Panel 的输出是每个竞品在 𝔅_s 上的配对得分矩阵，不产生任何动作。

**定义 434（差异认证 DiffCert）** 候选契约 q 通过认证，当且仅当对参考 c_ref（当前契约或 MODGAUGE 基线）同时满足：
(i) **Pareto 非支配**：在（精度、覆盖率、代价）上不被 c_ref 全面支配；
(ii) **差异 margin**：性能差 Δ = perf(q) − perf(c_ref) 的单侧置信下界 LCB_Δ ≥ δ_diff；
(iii) **显著性**：配对检验在族错误率 α_d 下显著（Holm–Bonferroni 多重比较校正）。
三项缺一不可；认证输出 (pass, LCB_Δ, p_adj) 全部写账。

**定义 435（不可区分与保守不切换）** 若 Δ 的置信区间包含 0，或所有候选的区间互相重叠，则判 **INDISTINGUISHABLE**：
保持当前契约（或维持 stub），**不热替换**。此定义把「无证据」显式映射为「不行动」，
是比第 2 轮「V 通过即替换」更强的保守性约束（负向安全）。

**定义 436（共因失效、有效独立度与正交锚）** 竞品误差建模为 e_i = b + ξ_i，b 为共享偏差，ξ_i 独立。
β 因子模型：P(两竞品同时失效) = β·min(P_i, P_j)，有效独立度 n_eff = n / (1 + (n−1)β)。
**正交锚** A = {a_1,…,a_m}：物理独立的外部参照（标准件、外部计量、人工抽检），用于估计 |b|；
认证规则：DiffCert 只证**相对**优越；绝对正确性要求 |b| ≤ ε_anchor。
若 |b| > ε_anchor 或 A 不可用 ⇒ 暂停 DiffCert，退回 ToolGauge（退化第 1 级）。
**诚实声明**：β→1 时 n_eff→1，竞品差分对 b 完全不敏感——这是竞品分析的原理性上限，不是实现缺陷。

**定义 437（可修复系统与可靠性账本 R-Ledger）** 每个格的契约视为可修复部件。
失效事件集 F_s = {盲区重现, V 交叉验证失败, 契约回归失败, 金丝雀漂移告警, 冗余表决冲突}。
账本记录 (t_k, 失效模式, 修复动作, 修复时长 T_rep, 删失标记)；失效计数过程 N_s(t)，任务时间 T_mission。
账本**只追加、不可篡改**（与回执签名同源哈希链），供引理 52 与定义 445 引用。

**定义 438（可靠性增长 Crow-AMSAA 与增长门）** E[N_s(t)] = a_s·t^{b_s}，瞬时失效率
λ_s(t) = a_s b_s t^{b_s−1}，瞬时 MTBF_s(t) = 1/λ_s(t)。
**增长门**：声称「本次修复提高了可靠性」需同时满足 (i) b_s ≤ 1 − δ_g；(ii) 拟合优度检验 p > 0.05；
(iii) 与修复前区间不重叠。任一不满足 ⇒ 该主张降级为「局部精度改善」，不得写入可靠性结论。
（b<1 表示累积失效次线性增长、MTBF 上升；b=1 为齐次泊松，b>1 为可靠性退化。）

**定义 439（任务可靠性与可用性）** A_s = MTBF_s / (MTBF_s + MTTR_s)；
任务可靠度 R_mission,s(T) = P(在 [0,T] 内无失效)（Weibull/指数按账本拟合选择，用 AIC）。
系统级 A_sys、R_mission,sys 由可靠性框图 RBD（串联/并联/k-of-n）合成；
安全关键格必须满足 R_mission,s(T) ≥ R_min 且 A_s ≥ A_min。

**定义 440（可靠性重要性与预算分配）** Birnbaum 重要性 I_s = ∂A_sys/∂A_s；FMEA 风险优先数 RPN = S·O·D。
修复预算 B_repair 分配问题：max A_sys(x) s.t. Σ cost_s x_s ≤ B_repair。
当目标对「改善量」次模时，按 I_s/cost_s 贪心得 (1−1/e) 近似（引理 54）；
同一格的多竞品按「可靠性每代价」而非「精度」择优。

**定义 441（多样冗余表决 k-of-n）** 安全关键格部署 n 个 **Ind 三元组两两不同**的契约副本，
表决器 V 以可靠性权重 w_i ∝ 1/σ_i²（或对数几率）融合；输出有效当且仅当 ≥k 个副本在容差 τ_vote 内一致。
冗余度量须用 β 因子修正：R_red = f_k,n(β)，且系统可靠度 R_total = R_voter · R_red。
表决器本身是单点失效（λ_v），必须有自检/锁步；n 的选取使边际可靠度增益 > 边际代价（引理 53）。

**定义 442（影子部署与金丝雀提升）** 候选契约先在 shadow 模式运行 T_shadow（无执行器副作用），
与在位契约做逐任务配对比较；提升需同时满足：
(a) DiffCert 通过；(b) 增长门通过；(c) 金丝雀无回归；(d) 回滚预案就绪且回滚时延 ≤ τ_rollback。
任一不满足 ⇒ 不提升；影子运行本身不改变数值路径。

**定义 443（加速寿命与降额）** 加速应力因子（光照、运动、遮挡、温度）经加速模型（Arrhenius / 逆幂律）
换算为现场失效率 λ_field = λ_stress / AF；降额 d 表示只在认证包络内使用契约，包络外须先做降额验证。
加速寿命用于**部署前预认证**，其外推误差写入风险账本。

**定义 444（可靠性门 Rel-Gate，6C→7C 的第 7 段 R）** 热替换前要求：
A_sys(new) ≥ A_sys(old) − ε_A 且 R_mission,sys(new) ≥ R_mission,sys(old) − δ_R；
不满足则保持旧契约或 stub。Rel-Gate 只读取 R-Ledger 与 C-Panel 输出，不修改数值结果。
7C = H→C→E→C→V→**R**（Reliability），R 段不通过则不进入 U 热替换。

**定义 445（可靠性/竞品主张绑定）** 推广定义 423：任何关于「更可靠 / MTBF 提升 / 优于竞品」的语言主张 c
必须携带证据引用 evidence(c) ⊆ {R-Ledger 统计量(含 N、T、拟合参数、CI), DiffCert 的 (LCB_Δ, p_adj, β, n_eff)}；
无引用或引用失效的主张在契约序列化时剥离。剥离为纯投影，不改变任何数值行为（主张绑定不变式扩展）。

**定义 446（可靠性感知退化链）** `TrustGauge ⇐ ToolGauge ⇐ LeanGauge ⇐ MODGAUGE`。
卸载条件：正交锚不可用 / |b|>ε_anchor / 账本样本不足（N_s < n_min^rel）/ 增长门连续 2 次失败 / 表决冲突不可解。
退化取向为 **fail-safe**：宁可保留经证实的旧契约或 stub，也不部署未通过 Rel-Gate 的候选。
退化只减少增强项，不改变五不变式与 50Hz 时序结论。

**定义 447（继承与编号约定）** 未重定义记号沿用定义 398–431（R、s、λ、γ、M_ver、N_bl、EC、MReg、TB-Contract、AP-Cal 等）。
TrustGauge 以 ToolGauge 为退化特例：C=∅、R-Ledger 关闭、k=1、T_shadow=0、Rel-Gate 恒真 ⇒ TrustGauge ≡ ToolGauge；
再由定义 431 退化为 LeanGauge 与 MODGAUGE。

# IP-321 竞品委员会：预注册基准 + 独立性三元组
class Competitor:
    def __init__(self, name, est, cost, indep):   # indep=(数据源,物理原理,模型族)
        self.name, self.est, self.cost, self.indep = name, est, cost, indep

class CPanel:
    def __init__(self, comps, current):
        self.comps = comps + [current]
        self.dup = find_nonindependent(self.comps)      # 三元组重复 => 降级为副本
    def justify(self, s, anchor):                       # 定义 436
        b = anchor.estimate_common_bias(s)              # 正交锚
        if b is None:            return False, "no_anchor"
        if abs(b) > EPS_ANCHOR:  return False, "common_bias"
        beta = estimate_beta(self.comps, s)             # 共因 β
        self.n_eff = len(self.comps) / (1 + (len(self.comps)-1)*beta)
        return self.n_eff >= 2, f"beta={beta:.2f},n_eff={self.n_eff:.2f}"
    def scores(self, s, battery):                       # 配对得分，不产生动作
        return {c.name: [c.est(ctx) for (ctx, _) in battery[s]] for c in self.comps}

# IP-322 差异认证：Pareto + margin + Holm 校正（定义 434/435）
class DiffCert:
    def certify(self, cand_scores, ref_scores, delta, alpha_d=0.05):
        d  = paired_diff(cand_scores, ref_scores)
        if not lower_confidence_bound(d, alpha_d) >= delta:
            return False, lower_confidence_bound(d, alpha_d), "margin"
        p  = holm_corrected_test(cand_scores, ref_scores, alpha_d)
        if p > alpha_d:
            return False, lower_confidence_bound(d, alpha_d), "n.s."
        return True, lower_confidence_bound(d, alpha_d), "ok"
    def indistinguishable(self, cand, ref):
        return ci_contains_zero(paired_diff(cand, ref))      # => 保守不切换

# IP-323 可靠性账本：Crow-AMSAA + 可用性（定义 437–439）
class RLedger:
    def record(self, s, t, mode, repair_time, censored=False):
        self.log[s].append(Entry(t, mode, repair_time, censored))   # 只追加，哈希链
    def crow_amsaa_mle(self, s, t_now):
        # E[N(t)] = a t^b；MLE 对数线性回归/数值优化
        a, b, ci = mle_power_law(self.log[s], t_now)
        return a, b, ci
    def mtbf(self, s, t_now):
        a, b, _ = self.crow_amsaa_mle(s, t_now)
        lam = a * b * t_now ** (b - 1)                 # 瞬时失效率
        return 1.0 / lam
    def availability(self, s, t_now):
        m = self.mtbf(s, t_now)
        return m / (m + self.mttr(s))
    def growth_ok(self, s, delta_g=0.05):
        a, b, (lo, hi) = self.crow_amsaa_mle(s, self.now())
        return b <= 1 - delta_g and hi < 1.0 and gof_p(self.log[s]) > 0.05

# IP-324 多样冗余表决（定义 441）
class DiverseVoter:
    def fuse(self, replicas):
        assert pairwise_independent(r.indep for r in replicas)
        w = [1.0 / r.var for r in replicas]
        mu = sum(wi * r.mu for wi, r in zip(w, replicas)) / sum(w)
        agree = sum(abs(r.mu - mu) <= TAU_VOTE for r in replicas)
        return (mu, "ok") if agree >= K and self.selfcheck() else (None, "vote_fail")

# IP-326 TrustGauge 7C 闭环（ToolGauge 6C + R 段）

    receipts = M.tcv.execute(prog, M.env)                         # E
    if len(receipts) < n_min(s): return stub_and_red(s, "insufficient")
    mu, Sig  = M.apcal.calibrate(receipts, H, s)                  # C
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):   # V
        mu, Sig = M.apcal.calibrate(receipts, ["UNKNOWN"], s)
        if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
            return stub_and_red(s, "cross_failed")
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s)
    if not contract_regression(new_ec): return stub_and_red(s, "regression")

    ok, why = M.cpanel.justify(s, M.anchor)
    if not ok: return M.degrade(s, why)                           # 退化链第 1 级
    cands = M.cpanel.candidates(s)
    ref   = M.cpanel.scores(s, M.battery)["current"]
    best, best_stats = None, None
    for c in sorted(cands, key=lambda c: rel_per_cost(M, s, c), reverse=True):
        pass_c, lcb, why = M.diffcert.certify(M.cpanel.scores(s, M.battery)[c.name], ref, DELTA)
        if pass_c:
            if M.rledger.has_history(s) and not M.rledger.growth_ok(s):
                continue                                          # 上次修复未增长 => 不叠加
            if not M.relgate_admits(s, c):  continue              # A/R_mission 不得下降
            best = c; best_stats = (lcb, why); break
    if best is None:
        return M.keep_current(s, "indistinguishable_or_relgate")  # 保守不切换
    if not M.canary.promote(best, M.current(s), T_SHADOW):
        return M.keep_current(s, "canary_failed")
    M.mreg.hot_replace(M.dpe, best.contract)                      # U：仅通过 R 段后
    M.rledger.start_monitoring(s, best.contract)
    M.dbox.update_from_posterior(s, mu, Sig)
    bind_claims(new_ec, H, prog, receipts,
                diff_cert=best_stats, rel_stats=M.rledger.stats(s))  # 定义 445
    M.pquar.record(M.apcal.last_gain, realized_gain(receipts))
    return True

# 主闭环：50Hz 路径完全不动；可靠性维护全异步
def TrustGauge_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s); submit_async(trustgauge_7c, M, s)
    if M.pquar.triggered():
        M.apcal.pause(); M.use_bpcal_fallback = True
    if M.rledger.due_for_growth_test():
        submit_async(M.rledger.growth_test, M.cells)              # 离线
    return MODGAUGE_round(M, obs, audio, tac, depth, det)

## 3. 推导

**引理 51（竞品差异认证的可检测性下界与共因极限）**
设竞品误差 e_i = b + ξ_i，ξ_i 独立 σ-亚高斯，b 对所有竞品相同；配对差异统计量 D = mean(e_q) − mean(e_ref)。
则 E[D] = 0（q 与 ref 共享 b 时），故**竞品差分对绝对偏差 b 不可辨识**；Var[D] ≤ 2σ²/|𝔅|。
有效独立度 n_eff = n/(1+(n−1)β)。在 β 因子模型下，差异认证的最小可检测相对优势
δ_min ≈ c·σ·√(2/(|𝔅|·n_eff))；当 β ≥ β_max 使 n_eff < 2 时认证无效。
**系**：绝对正确性必须由 |b| ≤ ε_anchor 保证；竞品分析只能证相对优越，不能证绝对正确（这正是定义 436 的动机）。

**引理 52（不完美修复下的可靠性增长偏差）**
Crow-AMSAA 的增长结论建立在**完美修复**（修复如新）之上。设修复成功概率 p，失败修复以 1−p 回到旧失效率 λ_0。
则有效增长指数 b_eff = b·g(p)（g(p)<1），渐近 MTBF 上界为 1/((1−p)λ_0)。
**系**：b<1 是可靠性增长的必要非充分条件；必须同时从账本估计 p（修复成功率）。
若 p ≤ p_min，则无论 b 多小，MTBF 有上界，不得声称可靠；Rel-Gate 应拒绝该类候选（定义 438/444）。

**引理 53（多样冗余的共因饱和与表决器单点）**
k-of-n 多样冗余在 β 因子下 R_red ≥ Σ_{j=k}^{n} C(n,j)(1−β)^j β^{n−j}·(副本可靠度项)，
且当 n→∞ 时 R_red → 1−β。系统 R_total = R_voter·R_red，表决器失效率 λ_v 使 A_total 存在上界。
**系**：冗余的边际收益被 β 与 λ_v 双重截断；存在 n*（边际可靠度增益 < 代价）后不再加副本（定义 441/440）。

**引理 54（可靠性预算分配的贪心近似）**
设 A_sys 对各格可靠度改善量单调且次模，则按 Birnbaum 重要性/代价比贪心分配修复预算，得 (1−1/e) 近似最优。
**系**：把有限 B_repair 投给高重要性盲区，优于第 2 轮的「先到先修」；与 C-Panel 的「可靠性每代价」择优一致。

**引理 55（非干涉与不变式保持）**
C-Panel、DiffCert、R-Ledger、Rel-Gate 均只读或只作准入判定，不进入 50Hz 数值通道；影子运行无执行器副作用；
主张剥离（定义 445）为纯投影；退化（定义 446）只删除增强项。
故子图数值等价性同第 2 轮引理 49、硬实时与预算同引理 50；五不变式保持。

## 2. 形式化定义（要点）

**定义 432/433（竞品与委员会）** 竞品是 `Context → (μ,σ)` 的估计器 + 代价 + 独立三元组。只有三元组两两不同才算独立，

**定义 434/435（差异认证）** 候选须相对参考 Pareto 非支配、差异 LCB ≥ δ_diff、且 Holm 校正后显著；

**定义 436（共因与正交锚）** e_i = b + ξ_i；DiffCert 对 b 不可辨识；n_eff = n/(1+(n−1)β)；
绝对正确性要求 |b| ≤ ε_anchor，锚不可用则暂停认证并退化。
**定义 437–439（账本与可靠性）** 契约=可修复部件；失效事件只追加哈希链；Crow-AMSAA 瞬时 MTBF=1/(a b t^{b−1})；
A = MTBF/(MTBF+MTTR)；R_mission 按 AIC 选 Weibull/指数；RBD 合成系统级指标。
**定义 440/441（预算与冗余）** 按 Birnbaum 重要性/代价比贪心分配（次模 ⇒ 1−1/e）；安全关键格 k-of-n 多样冗余，
表决器自检，冗余收益被 β 与 λ_v 截断。
**定义 442/443（部署与预认证）** 影子运行—金丝雀无回归—回滚就绪才提升；加速应力经 Arrhenius/逆幂律外推现场失效率，降额保护包络外使用。
**定义 444/445（Rel-Gate 与主张绑定）** 热替换前要求 A 与 R_mission 不下降超容差；关于「更可靠/优于竞品」的语言主张
必须引用 R-Ledger 统计量与 DiffCert 输出，否则序列化时剥离（纯投影）。
**定义 446/447（退化与继承）** fail-safe 可靠性感知退化；C=∅、账本关闭、k=1、T_shadow=0、Rel-Gate 恒真 ⇒ TrustGauge ≡ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。

# IP-321/322 C-Panel + DiffCert（只读证明层）
class CPanel:
    def justify(self, s, anchor):
        b = anchor.estimate_common_bias(s)
        if b is None or abs(b) > EPS_ANCHOR: return False, "anchor"
        beta = estimate_beta(self.comps, s)
        self.n_eff = len(self.comps) / (1 + (len(self.comps)-1)*beta)
        return self.n_eff >= 2, f"beta={beta:.2f}"

class DiffCert:
    def certify(self, cand, ref, delta, alpha_d=0.05):
        lcb = lower_confidence_bound(paired_diff(cand, ref), alpha_d)
        if lcb < delta: return False, lcb, "margin"
        if holm_corrected_test(cand, ref, alpha_d) > alpha_d: return False, lcb, "n.s."
        return True, lcb, "ok"

# IP-323 可靠性账本（可修复系统）
class RLedger:
    def record(self, s, t, mode, repair_time): self.log[s].append((t, mode, repair_time))
    def mtbf(self, s, t_now):
        a, b, _ = mle_power_law(self.log[s], t_now)      # E[N]=a t^b
        return 1.0 / (a * b * t_now ** (b - 1))          # 瞬时 MTBF
    def availability(self, s, t_now):
        m = self.mtbf(s, t_now); return m / (m + self.mttr(s))
    def growth_ok(self, s, delta_g=0.05):
        a, b, (lo, hi) = mle_power_law(self.log[s], self.now())
        return b <= 1 - delta_g and hi < 1.0 and gof_p(self.log[s]) > 0.05

        ok = sum(abs(r.mu - mu) <= TAU_VOTE for r in reps) >= K and self.selfcheck()

def trustgauge_7c(M, s):

    prog     = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s))  # C

    if len(receipts) < n_min(s): return stub_and_red(s, "insufficient")
    mu, Sig  = M.apcal.calibrate(receipts, H, s)                   # C
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):    # V
        mu, Sig = M.apcal.calibrate(receipts, ["UNKNOWN"], s)
        if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
            return stub_and_red(s, "cross_failed")
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s)
    if not contract_regression(new_ec): return stub_and_red(s, "regression")
    # ---- R：可靠性段 ----
    ok, why = M.cpanel.justify(s, M.anchor)
    if not ok: return M.degrade(s, why)
    ref = M.cpanel.scores(s, M.battery)["current"]
    for c in sorted(M.cpanel.candidates(s), key=lambda c: rel_per_cost(M, s, c), reverse=True):

## 4. 推导

**引理 51（差异认证的可检测性下界与共因极限）** e_i=b+ξ_i，ξ_i 独立 σ-亚高斯 ⇒ E[D]=0，竞品差分对 b 不可辨识；
Var[D] ≤ 2σ²/|𝔅|；n_eff=n/(1+(n−1)β)；最小可检测相对优势 δ_min ≈ c·σ·√(2/(|𝔅|·n_eff))。
β 使 n_eff<2 时认证无效。系：绝对正确性只能由 |b|≤ε_anchor 保证，竞品分析只证相对优越。

**引理 52（不完美修复下的增长偏差）** 完美修复假设下 Crow-AMSAA 给出 b<1 的增长；修复成功概率 p 时
b_eff=b·g(p)，渐近 MTBF ≤ 1/((1−p)λ_0)。系：b<1 是必要非充分条件，须同估 p；p≤p_min 时 MTBF 有上界，
不得声称可靠，Rel-Gate 拒绝该类候选。

**引理 53（多样冗余的共因饱和与表决器单点）** R_red 随 n 增大趋于 1−β；R_total=R_voter·R_red 被 λ_v 截断；
存在 n* 使边际可靠度增益 < 边际代价。系：冗余不是免费的，必须与 β、λ_v、代价联合优化。

**引理 54（预算分配的贪心近似）** A_sys 对各格改善量单调次模 ⇒ 按 Birnbaum 重要性/代价比贪心得 (1−1/e) 近似。
系：有限 B_repair 应投给高重要性盲区，优于「先到先修」。

**引理 55（非干涉与不变式）** C-Panel/DiffCert/R-Ledger/Rel-Gate 只读或只作准入；影子无副作用；
主张剥离为纯投影；退化只删增强项。故数值等价性同第 2 轮引理 49、硬实时同引理 50，五不变式保持。

## 8. 本轮最大风险

**一句话**：竞品委员会可能只是「同一先验的多个副本」——若 n 个竞品共享预训练数据、工具库或物理假设，
则 β→1、n_eff→1，DiffCert 与 R-Ledger 会一致地把「可靠的错误」认证为可靠，
系统将以极高置信度**稳定地错下去**；独立三元组与正交锚是唯一但脆弱的防线，
而正交锚的绝对正确性本身又无法被系统内证明。以 E441/E443/E450/E453 证伪，
以「独立性三元组强制 + β 上限 + 不可区分不切换 + fail-safe 退化」四重兜底。
