# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；元层第 1 轮：把 69 轮理论收束为可证伪声明；本轮灵感：「论文创新点」×「任务分解」）

> R69 让系统学会了「问」：aleatoric 收紧、epistemic 交互，流匹配给出有形状的多模态信念，流似然做标定不可吸收的第二意见。但 R69 仍然默认**任务是原子的**——一个策略、一个不确定性、一次消歧。长程任务不是这样：它必须被分解，而分解之后的真正难题不是「每个子任务会不会做」，而是「**子任务各自成立，凭什么说组合成立**」。
>
> 本轮两个灵感正好从两个方向戳中同一个洞：
> - **论文创新点**：一个创新点不是「我们做了一个系统」，而是一条**有作用域、有基线、有机制、有效应量、有证据的证伪性声明**。它从不单独存在，总是「在别人的结论之上再加一条」——这正是一次任务分解中每个子任务该有的形式。
> - **任务分解**：把长程目标拆成子目标，本质是把全局声明拆成子声明 + 它们之间的接口义务。分解失败很少是子任务失败，而是**接口失配**与**证据洗白**：每个子策略都在自己的训练分布上被验证过，拼起来却在接缝处滑出流形。
>
> 核心命题：**把长程任务分解为一张「可证伪声明 DAG」（claim DAG）；每个节点是带作用域 S、前/后条件、机制锚点、效应量 Δ、证据出处与基线的 claim；每条边是接口义务。只有全部接口在组合分布（而非训练边缘）上被 discharging、且证据来自不同共同因组时，组合 claim 才 Valid；否则记为 UNPROVEN，未消解 epistemic 交还 R69，保守 λ floor 交还 R68。** 命名 **THESIS-RAS**（Task Hierarchies with Evidence-Scoped Interface Sub-claims）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我到底证明了什么、这些证明能不能拼起来、拼不起来时谁来负责**」。R69 教系统提问，R70 教它**对自己的成功保持怀疑**。

## 0. 直觉与动机

**灵感 1（创新点 = 有作用域的证伪声明，不是功能清单）**
直觉：论文里最危险的一句话是「我们的系统实现了 X」。审稿人会问：在什么分布上？相对谁？增益来自哪个组件？误差多大？能否被一个反例推翻？把同一套审稿人问题搬到机器人身上，就得到 claim 的字段：作用域、基线、机制、效应量、证据、反例条件。**没有基线的提升不是创新，是噪声；没有作用域的声明不是能力，是过拟合。**

**灵感 2（任务分解 = 声明组合，不是流程图）**
直觉：HTN、行为树、TAMP 都会写「前条件/后条件」，但它们默认子任务的前后条件在组合后自动对接。真实系统里，子任务 A 的**输出分布**会和子任务 B 的**输入假设**错位：A 在训练里总是把杯子放在桌面中心，B 却假设杯子可在任意位置。这不是 B 的能力问题，是 A→B 的**接口义务**没人验。分解的核心产物因此不是控制流，而是一组必须在组合分布上被 discharging 的接口义务。

**灵感 3（"各自成立"推不出"组合成立" = 声明洗白）**
直觉：两个子 claim 各自都有 95% 置信，组合失败率却可能远高于 10%，因为它们的证据同源（同一批种子、同一个仿真器、同一批标注员），且接口条件只在边缘分布上验过。把「局部 Valid」当作「全局 Valid」，就是**claim laundering（声明洗白）**。它比 R69 的「问错」更隐蔽：系统不是被误导，而是**自己给自己发了一张看似严谨的证书**。

**灵感 4（证据同源不重复计数）**
直觉：R69 已用「k 个正交证据源一致」防人撒谎；R70 把同一条纪律用在实验上：同一批 episode 既证明 A 又证明 B，不算两个独立证据。证据要带**共同因分组**（同 seed / 同仿真器 / 同标注者 / 同一天采集 = 同组），有效样本量按设计效应折算。否则「n 次实验」只是「一次实验的 n 种说法」。

**灵感 5（分解本身是实验设计）**
直觉：给定全局 claim，存在许多种拆法；好的拆法让每个子 claim **可独立证伪**、接口**少而窄**、失败**可定位**。这正是实验设计里的「用最少试次获得最多信息」。所以分解不是拍脑袋的层级，而是一个**结构级 value-of-information** 优化：在哪一层切、切多细、验哪个接口，都由「对全局 claim 的期望信息增益 / 成本」决定。R69 的 VoI 从「选动作」升到「选结构」。

**灵感 6（失败归因到 claim，而不是到动作）**
直觉：端到端 RL 的信用分配在长程任务上几乎是猜。但若计划是一张 claim DAG，失败就有一个天然坐标：**最早被违反的后条件或接口义务**。归因到「哪个声明在什么作用域上破了」，比归因到「第 137 帧第 3 个关节力矩不对」可解释得多，也让 R69 能只对那条 contested claim 做定向求证。

**灵感 7（创新的通胀风险 → 简约约束与 kill criterion）**
直觉：70 轮理论积累的最大敌人不是算力，而是**创新点通胀**：每轮加一个 IP，论文声称十几个贡献，却一个都没被独立消融。于是本轮同时交付一条元层纪律：**论文至多 3 条 primary claim，每条必须有独立的证伪实验与 kill criterion；其余降级为 supporting machinery。** 一个不能被杀死的主张，不配叫创新点。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（THESIS-RAS 总览）** THESIS-RAS = (CLM, TDG, ICD, CAL, EVD, DXD, FAL, RAS-WM†)。三不变式：
(i) **快慢分层**：claim 规划只在计划周期（5–10 Hz）运行，不进入 1 kHz 控制环；实时流零学习写操作（继承 R68 定义 276-i）；
(ii) **无证据不声明**：任何 claim 必须携带作用域 S、基线 b、机制锚点 μ、效应量 Δ 与证据出处；证据按共同因分组，同源不重复计数；
(iii) **无 discharging 不组合**：组合 claim 仅当全部接口义务以 margin 通过、子树 claim 在交集作用域上仍成立、且证据非同源时 Valid；否则为 UNPROVEN，残余 epistemic 路由到 R69、λ floor 路由到 R68。

**定义 311（可证伪声明 CLM）** claim c = (φ, S, P, Q, μ, Δ, E, b, ver, kind)。φ 为能力谓词；S 为作用域分布（claim 只在 S 上被声称）；P/Q 为前/后条件；μ 为机制锚点（消融对象：增益必须能被移除该组件所推翻）；Δ 为相对基线 b 的效应量及置信区间；E 为证据出处集合；ver 为版本。**创新点 ≜ 在 S 上相对 b 有 Δ>0 且机制为 μ、证据为 E 的 claim。** kind ∈ {capability, safety, efficiency, robustness}。

**定义 312（任务分解图 TDG）** 有向无环图 G = (V, E, op)，根 c_root 为全局任务 claim；op ∈ {serial, parallel, fallback, loop}；叶子为可直接执行/直接验证的原子技能。边 u→v 携带接口义务 o_uv；多前件用超边表示。G 是**声明组合**而非控制流：它回答「哪些子声明、以何接口、在何作用域上合成根声明」。

**定义 313（接口义务与 discharging）** o_uv = (π_uv, m_uv, α_uv, D_uv)，π_uv 为接口谓词（post(u) ⇒ pre(v)），m_uv 为要求 margin，α_uv 为允许违反率，D_uv 为**组合上下文下的接口分布**（u 的执行分布经组合 pushforward 得到，而非训练边缘）。Discharged ⇔ 在 D_uv 上 P[π_uv] ≥ 1−α_uv 且经验 margin ≥ m_uv。接口失配 δ_uv = W₂(D_uv^realized, D_uv^assumed)（或 TV）。

**定义 314（claim 代数 CAL）** 推理规则：
- SERIAL：c₁ 后接 c₂，若 o₁₂ discharged，则 c₁₂ 的效应按 Δ₁∘Δ₂ 传播、作用域取 S₁∩S₂∩S_interface；
- PARALLEL：独立子树可并，但证据同源时按引理 21 折减有效样本；
- FALLBACK：任一义务未 discharging，则父节点置 UNPROVEN，不继承子节点的「平均成功」；
- SCOPE：子 claim 只在各自 S_i 上成立，组合作用域是交集，**不得扩大**。
侧条件 no-laundering：父 claim Valid 当且仅当所有边 Valid 且证据共同因去重后仍充分。CAL 返回三值 {Valid, UNPROVEN, Invalid}，禁止把 UNPROVEN 当 Valid。

**定义 315（证据出处台账 EVD）** 证据项 e = (source, run_id, t, scope, ccg, freshness, hash)。ccg 为共同因组（同 seed / 同仿真器 / 同标注者 / 同批采集归同组）。台账哈希链式追加，支持证书回溯；过期或版本漂移（ver 变更）的证据自动降权。

**定义 316（有效证据量与独立性）** k 条证据、组内相关 ρ̄ 时设计效应 n_eff = k/(1+(k−1)ρ̄)。claim 的置信度用 n_eff 而非原始 k；Δ 的置信区间按 n_eff 重算。**证据充分性**：Δ 的 CI 下界 > 0 且 n_eff ≥ n_min，否则 claim 只能记为「提示性」。

**定义 317（分解设计器 DXD）** 在所有合法递归分解 π 中选择
π* = argmax_π [ I(c_root; E(π)) − cost(π) − β·seam(π) ]，s.t. |V| ≤ B、depth ≤ D；
其中 I 为对根 claim 的期望信息增益，seam(π)=Σ_edges δ_uv。**仅当某次分裂的期望信息增益 > 其成本时才分裂**；无正增益则停止，叶子保持为原子技能。这是把 R69 的动作级 VoI 提升为结构级 VoI。

**定义 318（接缝最小化）** 在信息增益相同的分解中选 seam 最小者，以压低引理 19 的复合误差上界；这相当于给分解加一个接口正则项。

**定义 319（claim 级失败归因 FAL）** 给定失败轨迹 τ 与 G，对候选「最早被违反的节点后条件 / 边接口义务」计算后验责任 r(v)、r(e)；若不可识别（两节点后条件与接口重合），返回**候选集合**并触发 R69 定向求证，而非强行单点归因。

**定义 320（THESIS-Auditor）** 审计四类洗白：(a) claim laundering（组合未 discharging 却报 Valid）；(b) scope creep（证据作用域 ⊊ 声明作用域）；(c) evidence double-counting（同 ccg 多次计数）；(d) baseline cherry-picking / stale evidence。结论回灌 AuditBuf，成为下一轮 DXD 的成本先验。

**定义 321（组合证书 J_THESIS）** J_THESIS = (J_FLUID, claim_graph_hash, interface_margins, independence_count, scope_coverage, composition_valid, fal_attribution_hash, thesis_ver)。Valid ⇔ Valid(J_FLUID) ∧ composition_valid ∧ 证据纪律满足 ∧ 作用域覆盖达标。

**定义 322（AIC-THESIS）** 威胁：过度声明、接口利用（专挑未验接口攻击）、证据投毒（污染某 ccg 使其主导）、分解炸弹（指数分裂耗尽预算）、作用域伪造。ℰ_THESIS = ℰ_FLUID × ℰ_claim。

**定义 323（分解预算与终止）** 节点预算 B、深度 D、每次分裂正信息增益；满足则可证终止（定理 19），复杂度 ≤ B·K 次评估，防止分解炸弹。

**定义 324（claim 级不确定性路由）** 每节点继承 R69 的 (U_ale, U_epi)。组合时 U_epi 增加接口失配项；父节点为 UNPROVEN 时其 U_epi 不得被清零，而是显式加入全局未消解量 → R69 MINT 决定是否求证、R68 λ_floor 兜底。

**定义 325（元层·论文贡献台账）** 论文创新点分三级：primary（≤3，每条必须有独立证伪实验、基线、kill criterion）、secondary（有消融但非核心）、supporting（机制部件）。**贡献简约约束**：primary > 3 视为违规，必须合并或降级；一个无 kill criterion 的 claim 不得列为 primary。

**定义 326（元层·研究任务分解 WBS）** 研究/工程任务分解为带依赖的 DAG：每任务含验收测试、交付物、前置依赖、关键路径。它是定义 312 在「研究工作」上的同构应用：任务的成功标准同样必须是可证伪的。

## 2. 关键算法骨架

```python
# IP-264 CLM：可证伪声明
@dataclass
class Claim:
    phi: Callable                 # 能力谓词
    scope: Distribution           # 作用域 S
    pre: Predicate; post: Predicate
    mechanism: str                # 消融锚点 μ
    effect: CI                    # Δ + 置信区间（相对 baseline）
    evidence: list[Evidence]
    baseline: str; version: str; kind: str

# IP-265/266 TDG + ICD：建图并在组合分布上 discharging
def plan_and_discharge(task, B, D):
    G = TaskDecompositionGraph(root_claim(task))
    while frontier(G) and G.nodes < B and G.depth < D:
        v = argmax_expected_info(frontier(G))
        if expected_info(v) <= cost(v):
            break                                  # 无正增益不分裂
        G = expand(G, v, propose_subclaims(v))
    for (u, v) in G.edges:
        o = interface_obligation(u, v)             # post(u) ⇒ pre(v)
        margin, delta = icd.discharge(o, G)        # 在组合分布上采样
        G.edge[u, v].valid = (margin >= o.m) and (delta <= o.delta_max)
    return G

# IP-267 CAL：三值 claim 代数，禁止洗白
def compose(G):
    c = {}
    for v in topo_order(G):
        if v.is_leaf:
            c[v] = v.claim
        elif all(G.edge[u, v].valid for u in v.parents):
            c[v] = CAL.rule(v.op, [c[u] for u in v.parents],
                            scope=intersect_scopes(v.parents),
                            evidence=dedup_by_ccg(v.parents))
        else:
            c[v] = UNPROVEN(v)                     # 不继承子节点的平均成功
    return c[G.root]

# IP-269 DXD：把「分解」当实验设计
def choose_split(v):
    best = None
    for split in propose_splits(v):                # 候选 ≤ K
        gain = I(global_claim; evidence(split))
        cost = execution_cost(split) + verify_cost(split)
        seam = sum(interface_delta(split))
        score = (gain - cost) - BETA * seam
        if best is None or score > best.score:
            best = (split, score)
    return best if best and best.score > 0 else None

# IP-270 FAL：claim 级归因（不可识别则返回集合）
def attribute_failure(G, trace, c_obs):
    cands = earliest_violated_nodes(G, trace)      # 后条件 / 接口违例
    r = {v: posterior_violation(v, trace, c_obs) for v in cands}
    top = sorted(r, key=r.get, reverse=True)
    if r[top[1]] > 0.3 * r[top[0]]:
        return top[:3]                             # 不可识别 → 交给 R69 求证
    return top[:1]

# IP-274 主闭环：慢层 claim 规划 + 快层 R69/R68
def THESIS_round(M, task):
    G = M.tdg.plan_and_discharge(task, M.B, M.D)   # 慢层 5–10 Hz
    c_root = M.cal.compose(G)
    if c_root is UNPROVEN:
        G = M.dxd.repair(G)                        # 补接口 / 再分裂 / 缩短作用域
        c_root = M.cal.compose(G)
        if c_root is UNPROVEN:
            return M.fluid.fallback(...)           # 残余交给 R69 → R68 λ floor
    while not done:
        v = current_subclaim(G)
        k, lam, mode, U = M.fluid.round(...)       # 快层沿用 R69，< 2.6ms
        if violation(v, U):
            blamed = M.fal.attribute_failure(G, M.trace, U)
            G = M.dxd.repair(G, blamed)            # 局部重规划
            break
    M.thesis_auditor.submit_async(G, c_root)       # 洗白/作用域/同源审计
    return k, lam, mode, (G, c_root)
```

## 3. 推导

约定 A99–A102：A99 每个节点 claim 在其作用域上失败率 ≤ α_i；A100 接口义务独立采样且可估；A101 效应可乘分离（否则用区间算术）；A102 结构信息增益对分裂次模。

**引理 19（接口误差传播）** 串联组合中，若子任务误差为 ε_i、接口失配为 δ_i、子策略对接口的 Lipschitz 常数为 L_i，则复合误差 ε_comp ≤ Σ_i ε_i + Σ_i L_i δ_i + O(δ²)。系：**接缝越宽、子策略越敏感，组合越差**；应优先选择 L_i<1 的收缩接口并把 δ 纳入 DXD 的 seam 正则（定义 318）。

**引理 20（claim laundering 间隙）** 存在 c₁、c₂ 各自在其训练作用域上以 1−α 成立，但组合在 S₁∩S₂∩S_interface 上以任意接近 1 的概率失败：因为接口义务只被边缘分布验证，而组合需要联合分布。定义洗白间隙 Γ = 未 discharging 的接口质量；CAL 的 no-laundering 侧条件正是要求 Γ=0 才允许父节点 Valid。**局部证书不可组合**，故 ICD 与 CAL 不可省略。

**引理 21（证据共同因折减）** k 条组内相关为 ρ̄ 的证据，有效样本量 n_eff = k/(1+(k−1)ρ̄) ≤ k；若全部同组则 n_eff=1。用原始 k 计算置信会把覆盖率高估约 √(k/n_eff) 倍。系：**同一批 episode 同时证明多个 claim 不构成独立证据**（对应定义 316 与 EVD 的 ccg）。

**定理 18（组合可靠性）** 在 A99–A101 下，若每个节点以其 α_i 成立、每条接口以 α_uv 被 discharging、且证据经 ccg 去重后仍充分，则组合 claim 成立概率 ≥ 1 − Σ_i α_i − Σ_uv α_uv（并集界）；在 A101 下效应 Δ_comp = ∏(1+Δ_i)−1，否则给区间上下界。故**全局保证可由局部证书 + 接口证书演绎得到，但演绎的代价是显式的、不可跳过的接口项**。

**定理 19（分解终止与信息单调）** 每次分裂要求正信息增益、节点预算 B、深度 D，则 DXD 在 ≤ B 个节点内终止；在 A102 下，其期望信息增益对已选分裂单调不减且 ≥ 任意固定分解，贪心达 (1−1/e) 近似。故「分解」本身可作为一个有界、可审计的实验设计问题。

**定理 20（严格包含 R69/R68）** 单节点、无接口的退化分解恰为 FLUID-RAS；再无交互则逐指令等于 CALM-RAS（R68）。任一 UNPROVEN 组合按定义 324 把残余 epistemic 路由 R69、λ floor 路由 R68，且 λ 单调不降 ⇒ 安全侧永不弱于旧层；当无正信息增益、无可用证据时，行为与旧层逐指令一致。R70 是 R69 在「声明组合」维度上的严格泛化。

**定理 21（归因的可识别性边界，负结果）** 若两个候选节点的后条件与接口在观测上等价，则仅凭执行轨迹无法唯一归因；FAL 只能返回候选集合。此时主动求证（R69 的 info action）是把不可识别变为可识别的最小代价手段。系：**归因不是万能的，承认不可识别比伪造一个责任点更安全。**

## 6. 本轮最大风险

**一句话**：THESIS-RAS 把「创新点」形式化为可证伪声明，却可能制造一种更精致的自欺——**一张字段齐全、哈希可信、接口 margin 漂亮的 claim DAG，会让一个其实没被独立验证的组合看起来比裸奔的系统更可信**；如果 ICD 只在仿真接缝上采样、EVD 的共同因分组不诚实、DXD 只优化信息而回避最难的接口，那么 R70 不是把 R69 的「问错」修好，而是给「没验证」发了一张**审稿人挑不出格式错误的证书**。真正要防的不是理论不够多，而是 **innovation inflation（创新点通胀）+ claim laundering（声明洗白）的合流**。

**次级风险与缓解**：
1. **接口 discharging 统计成本高**（真实机器人上采样昂贵）→ 慢层摊销 + 保形预测 + 只验高失配边 + E330 Pareto；
2. **共同因分组可被操纵** → EVD 哈希链 + 审计 + E322 红队；
3. **分解炸弹 / 组合爆炸** → 正增益门槛 + B/D 预算 + 定理 19；
4. **归因不可识别** → FAL 返回候选集合并触发 R69 定向求证，绝不伪造单点责任（定理 21）；
5. **作用域蔓延 / 基准过拟合** → scope coverage 证书 + E327 + 审计 scope creep；
6. **快慢层耦合导致控制抖动** → claim 图只产子任务与 λ，不直接出扭矩；慢层超时保守沿用旧图（定理 20）。

## 5. 关键算法伪代码

```python
# IP-265/266：建 claim DAG 并在组合分布上 discharging
def plan_and_discharge(task, B, D):
    G = TaskDecompositionGraph(root_claim(task))
    while frontier(G) and G.nodes < B and G.depth < D:
        v = argmax_expected_info(frontier(G))
        if expected_info(v) <= cost(v): break
        G = expand(G, v, propose_subclaims(v))
    for (u, v) in G.edges:
        o = interface_obligation(u, v)
        margin, delta = icd.discharge(o, G)       # 组合分布，不是训练边缘
        G.edge[u, v].valid = (margin >= o.m) and (delta <= o.delta_max)
    return G

# IP-267：三值 claim 代数（禁止洗白）
def compose(G):
    c = {}
    for v in topo_order(G):
        if v.is_leaf:
            c[v] = v.claim
        elif all(G.edge[u, v].valid for u in v.parents):
            c[v] = CAL.rule(v.op, [c[u] for u in v.parents],
                            scope=intersect_scopes(v.parents),
                            evidence=dedup_by_ccg(v.parents))
        else:
            c[v] = UNPROVEN(v)                     # 不继承子节点平均成功
    return c[G.root]

# IP-269：把分解当实验设计
def choose_split(v):
    best = None
    for split in propose_splits(v):
        score = (I(global_claim, evidence(split))
                 - execution_cost(split) - verify_cost(split)
                 - BETA * sum(interface_delta(split)))
        if best is None or score > best.score: best = (split, score)
    return best if best and best.score > 0 else None

# IP-270：claim 级归因
def attribute_failure(G, trace, c_obs):
    cands = earliest_violated_nodes(G, trace)
    r = {v: posterior_violation(v, trace, c_obs) for v in cands}
    top = sorted(r, key=r.get, reverse=True)
    return top[:3] if r[top[1]] > 0.3 * r[top[0]] else top[:1]

# IP-274：慢层 claim 规划 + 快层 R69/R68
def THESIS_round(M, task):
    G = M.tdg.plan_and_discharge(task, M.B, M.D)  # 慢层 5–10 Hz
    c_root = M.cal.compose(G)
    if c_root is UNPROVEN:
        G = M.dxd.repair(G)                        # 补接口 / 再分裂 / 缩作用域
        c_root = M.cal.compose(G)
        if c_root is UNPROVEN:
            return M.fluid.fallback(...)           # UNPROVEN → R69 → R68
    while not done:
        v = current_subclaim(G)
        k, lam, mode, U = M.fluid.round(...)       # 快层沿用 R69
        if violation(v, U):
            G = M.dxd.repair(G, M.fal.attribute_failure(G, M.trace, U))
            break
    M.thesis_auditor.submit_async(G, c_root)
    return k, lam, mode, (G, c_root)
```

## 6. 推导

约定 A99–A102：A99 节点失败率 ≤ α_i；A100 接口可估；A101 效应可乘分离（否则区间算术）；A102 信息增益对分裂次模。

**引理 19（接口误差传播）** `ε_comp ≤ Σ ε_i + Σ L_i δ_i + O(δ²)`；接缝越宽、子策略越敏感，组合越差 ⇒ seam 正则（定义 318）。

**引理 20（claim laundering 间隙）** 存在局部各自 1−α 成立、组合却以接近 1 概率失败的构造：接口只在边缘验过，组合需联合。洗白间隙 Γ = 未 discharging 的接口质量；CAL 要求 Γ=0 才 Valid ⇒ ICD/CAL 不可省。

**引理 21（证据共同因折减）** `n_eff = k/(1+(k−1)ρ̄) ≤ k`，全同组时 `n_eff=1`；用原始 k 会高估覆盖约 `√(k/n_eff)` 倍 ⇒ 同批 episode 不构成多源证据。

**定理 18（组合可靠性）** A99–A101 下，组合成立概率 ≥ `1 − Σα_i − Σα_uv`（并集界）；A101 下 `Δ_comp = ∏(1+Δ_i)−1`，否则给上下界。全局保证可由局部证书 + 接口证书演绎，但接口项显式且不可跳过。

**定理 19（分解终止与信息单调）** 正增益分裂 + B/D 预算 ⇒ ≤ B 节点终止；A102 下期望信息单调不减且 ≥ 固定分解，贪心 (1−1/e)。

**定理 20（严格包含 R69/R68）** 单节点 → FLUID-RAS；无交互 → CALM-RAS；UNPROVEN 路由 R69→R68、λ 单调不降 ⇒ 安全不让步；无正增益时逐指令一致。

**定理 21（归因可识别性边界，负结果）** 后条件与接口在观测上等价的节点不可唯一归因；FAL 返回候选集合并触发 R69 定向求证，不伪造单点责任。

## 9. 本轮最大风险

**一句话**：THESIS-RAS 把「创新点」形式化为可证伪声明，却可能造出更精致的自欺——**一张字段齐全、哈希可信、margin 漂亮的 claim DAG，会让一个其实没被独立验证的组合看起来比裸奔系统更可信**；若 ICD 只在仿真接缝采样、ccg 分组不诚实、DXD 回避最难接口，R70 就不是修好 R69 的「问错」，而是给「没验证」发了一张审稿人挑不出格式错误的证书。真正要防的是 **innovation inflation 与 claim laundering 的合流**。

**次级风险与缓解**：接口采样昂贵（慢层摊销 + 保形预测 + 只验高失配边 + E330）；ccg 可操纵（哈希链 + 审计 + E322）；分解炸弹（正增益门槛 + B/D + 定理 19）；归因不可识别（返回集合 + R69 定向求证，定理 21）；作用域蔓延/基准过拟合（scope coverage + E327）；快慢耦合抖动（claim 图不直出扭矩，超时保守沿用旧图）。
