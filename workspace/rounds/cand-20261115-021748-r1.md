# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「无刷电机」×「轮足机器人」）

> R69 把不确定性从「我的测量准吗」推进到「我该向谁求证」，用流匹配的多模态分布 + 主动交互把 epistemic 歧义消解掉。但它仍默认一件事：**只要我决定了动作，身体就会把它兑现**。R69 的所有证书都写在「指令空间」里——λ 缩放的是动作，C-RAS-WM 认证的是前缀，却没有任何一层检查「这条扭矩指令真的变成了扭矩吗、我这条腿还举得起来吗」。对轮足机器人，这个默认恰恰最危险：它靠无刷电机的电流环产生力矩，靠反电动势/编码器估计转子角，靠轮-地接触把力矩变成运动；而**低速大扭矩（抬腿、起身、爬台阶、锁轮）正是无刷电机换相与力矩估计最不可观测的工况**。
>
> 本轮两个灵感正好落在同一个物理界面上：
> - **无刷电机**把「动作」变成一个可被电气量审计的物理过程——dq 轴电压/电流、反电动势、磁链、绕组温度。力矩不再是一个抽象指令，而是 `τ_e ≈ (3/2)p λ_m i_q`；同一组相电流既在产生力矩，也在泄露转子位置、负载、温度与健康状态。
> - **轮足机器人**把「身体」变成一个可重构系统——轮行/足行/混合三种模式，各自有不同的接触图、风险几何与观测质量；模式切换本身就是一个离散的、有风险的元动作。
>
> 核心命题：**把 R69 的不确定性再推一层——从「我信什么」到「我的动作被兑现了多少、我的身体还能兑现什么」；把作动不确定性拆成 delivery（不可约纹波/摩擦）与 realization（可约的负载/故障歧义），并用一条不能被机械自适应吸收的电气签名通道做第二意见；轮足模式切换作为「改变风险几何」的元动作，必须带转换证书。** 命名 **EFF-RAS**（Efference-grounded, Field-Oriented, Fault-aware Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的身体真的照做了吗、它还能做吗**」——不确定性不仅能变成提问，也能变成一次自检电流、一次减速滑行、一次从轮行到足行的换挡。

## 0. 直觉与动机

**灵感 1（无刷电机 → 动作是一个可审计的电气过程）**
直觉：有刷电机时代，力矩≈电流，简单但换相靠机械电刷。无刷电机把换相交给电子：必须先知道转子电气角 θ_e，才能把电流投到 q 轴产生力矩。于是「动作」变成一个闭环的物理断言——`τ_e=(3/2)p[λ_m i_q+(L_d−L_q)i_d i_q]`。这句话既是执行器，也是传感器：**同一组相电流既在产生力矩，也在泄露转子的位置、负载、温度和健康状态**。R69 的「交互」是向外问人；R70 的第一发现是：**机器人可以先向自己的电机问**。这不是隐喻——d 轴注入、速度扫掠、微力矩纹波都是真实可执行、可测量、有成本的信息动作。

**灵感 2（轮足机器人 → 身体可以换一种风险几何）**
直觉：轮行在平地上高效、连续接触，但看不清脚下；足行能上台阶、离散接触、每一步都是一次准静态的受控事件，但速度慢、低速大扭矩。人不会永远用一种方式走路：看到楼梯就「换挡」。所以**模式切换不是控制器的附属逻辑，而是一个能改变安全包络形状的元动作**——它改变可达动作集、改变观测质量、也改变故障传播路径。R69 的信息动作只改变「信念」；R70 的模式动作直接改变「风险模型本身」。更妙的是，模式切换还是**故障容错手段**：一个轮电机退化，可以靠腿分担、靠换模式继续完成任务。

**灵感 3（低速大扭矩 → 两个灵感在物理上恰好相撞）**
直觉：反电动势 `e=k_e ω`，速度趋零时它趋零，无感换相的角度估计信噪比随之崩塌；而抬腿、起身、锁轮这些轮足机器人最关键的瞬态，恰恰是低速大扭矩。于是 **足行模式的标称工作点，正是无刷电机可观测性最差的点**。这不是两个独立话题的拼贴，而是一个真实的耦合：**身体越需要力量的时候，它越说不清自己出了多大力**。R70 的安全包络必须把「换相置信度」显式写进去，否则「足行更安全」这个直觉会在低速重载时反转为「足行更不可观测」。

**灵感 4（自适应会吞掉故障 → 行动侧的「标定吸收」）**
直觉：R68 的最大风险是慢变传感器故障被标定解释掉；R69 用流似然做了第二意见。行动侧有完全同构的陷阱：电机退磁、绕组匝间短路、轴承磨损会让「同样电流出力变小」，而在线的参数辨识（自适应 λ̂_m、R̂_s）会把这种偏差解释成「负载变了/温度变了」，把机械残差 ε_act 压回零——**故障被自适应完美地隐藏了**。所以 R70 必须提出同一条铁律的行动版：**可辨识才自适应；不可辨识就不要让自适应替你解释，按故障处理并收缩包络**。这是对 R68/R69「任一不确定 → 只收紧」的第三次呼应，只不过这次收紧的对象是「自适应本身」。

**灵感 5（自检也是动作 → 需要新的安全约束）**
直觉：R69 的探针/问句本身要过安全认证；R70 的自检电流（d 轴注入、速度扫掠、微力矩纹波）同样会扰动接触与力矩。**向身体提问也会改变身体的状态**。所以 VoI 自检必须在「不破坏当前平衡/接触」的包络内进行，且单次自检不得单独定案（与 R69 的证据纪律同构）。一个在单腿支撑时注入大力矩纹波的「自检」，会把诊断变成摔倒。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（EFF-RAS 总览）** EFF-RAS = (FOC-E, EMM, CSC, TDR, HMR, HCA, SIA, ESA, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **作动诚实性**：每条力矩指令 τ_cmd 附带可计算的实现置信 ρ_act 与实现包络，未兑现部分在下一拍进入安全裕度——不允许「指令即事实」；
(iii) **可辨识才自适应**：在线参数更新 Δθ̂_e 仅在堆叠可辨识矩阵满秩时允许；否则冻结自适应、按故障收缩包络；
(iv) **模式切换认证**：任何 m→m′ 是离散元动作，必须通过转换证书（接触、力矩连续、滑移、目标模式不变式）。

**定义 311（动作空间与实现映射）** 任务动作 a=(τ_cmd, q̇_cmd) ∈ 𝒜_task；模式动作 m ∈ ℳ={W,L,H}。实现映射 τ_real = F(x_e, τ_cmd) + d，其中 x_e=(i_d,i_q,ω_e,θ_e,T_w,T_m) 为电气/热状态，d 为外载/接触扰动。实现残差 ε_act = τ̂ − τ_cmd，其中 τ̂=(3/2)p[λ̂_m i_q+(L̂_d−L̂_q)i_d i_q] 为观测器力矩。实现置信 ρ_act = P(|τ_real−τ_cmd| ≤ δ_τ | ℱ_t)。

**定义 312（FOC 电气模型与可辨识参数）** 表贴式 PMSM（L_d≈L_q）：
`v_d = R_s i_d − ω_e L_q i_q + L_d di_d/dt`，
`v_q = R_s i_q + ω_e L_d i_d + ω_e λ_m + L_q di_q/dt`，
`τ_e = (3/2)p λ_m i_q`。
参数 θ_e=(R_s, L_d, L_q, λ_m)。温度：R_s(T)=R_0(1+α(T−T_0))，λ_m(T_m)=λ_0(1+β(T_m−T_0))，β<0。饱和：L(i)。可在线辨识的仅是可观测子空间，不是全部参数。

**定义 313（换相置信 CSC）** 无感观测器的角度误差方差满足 σ²_θ(ω) ≳ σ²_v/(k_e²ω²)（A100，观测器线性化）。定义 κ_comm(ω,i) = 1/(1+σ_θ(ω)/σ_max)，换相可信域 Ω_κ = {x_e : κ_comm ≥ κ_min}。低速大扭矩工况 x_e ∉ Ω_κ 时，力矩指令必须按 ρ_act(κ_comm) 折扣，或改用编码器/Hall 冗余。**κ_comm 不是常量，是工作点的函数**。

**定义 314（热-磁降额与热债）** 连续力矩上限 τ_max(T_w,T_m) 随温度下降；定义热债 D_th(t)=∫_0^t (i²R_s − h(T_w))⁺ dτ，约束 D_th ≤ D_max。热是慢变量（A100 准静态），可预测、可规划；这把它与突发故障区分开——**慢变量可以被计划，快故障只能被拦截**。

**定义 315（轮足模式与接触图）** m=W：连续滚动接触，非完整约束，高效、观测差（轮子把地形「碾」过去）；m=L：离散足端接触，高扭矩低速，观测丰富（足端力/接触事件）；m=H：混合（如前轮后足）。每模式有接触图 G_m、可达动作集 𝒜_m、不变式 ℐ_m。

**定义 316（模式风险元组）** R_m=(r_safe^m, u_obs^m, e_cost^m, v_max^m, τ_regime^m)。模式选择不是标量最优，而是**安全优先的字典序**：先要求 r_safe^m ≤ ε_m ∧ 𝒜_m 在当前健康状态下可行，再在可行模式中最小化 (e_cost − λ_v v_max + λ_u u_obs)。这避免「为了快而进入安全不可行的模式」。

**定义 317（模式切换转换证书）** 切换 a_{m→m′} 需同时满足：
(a) 转换期间至少一个认证接触（或受控飞行相，时长 ≤ T_air）；
(b) 力矩连续：|τ(t⁺)−τ(t⁻)| ≤ Δτ_max；
(c) 轮-地啮合滑移 ≤ slip_max，且轮速与地速匹配；
(d) 目标模式 ℐ_{m′} 在切换后成立；
(e) 转换本身在 Ω_κ 内（低速大扭矩转换需编码器冗余或分阶段升力矩）。
任一不满足 ⇒ 拒绝切换，保持 m 并收缩包络。

**定义 318（作动不确定性二分）**
- U_deliv：纹波、齿槽、PWM 量化、摩擦、齿隙——不可约，进「交付裕度」（类比 aleatoric）；
- U_real：ε_act 的来源歧义——是地形/负载（可解释、可自适应），还是电机退化（不可用负载解释）？——可约，但**不能靠问人**，只能靠电气自检/跨电机一致性/速度扫掠（类比 epistemic）。
二者不做标量相加；U_deliv 直接进 τ_max 折扣，U_real 进「是否允许自适应」的判据（定义 320）。

**定义 319（自检动作与 VoI）** 自检动作 g_e ∈ 𝒜_self = {d 轴注入 i_d^inj、力矩纹波、速度扫掠 ω-sweep、相电流签名窗}。VoI_e(g_e) = H(h|ℱ_t) − E[H(h|ℱ_t, y(g_e))]，h 为健康状态。选择 g_e* = argmax[VoI_e − c_e]，s.t. 自检扰动在安全包络内（|Δτ|≤δ_inj、|Δq|≤δ_q、不破坏接触）且预算允许。若 VoI_e ≤ c_e：不自检，按当前 ρ_act 保守执行。**「问身体」也要先算值不值得问**。

**定义 320（可辨识门 AIG）** 设机械残差对（负载 d、健康 h）的雅可比为 J_mech，电气签名对内部参数的雅可比为 J_elec。堆叠可辨识矩阵 M=[J_mech; J_elec]。若 rank(M)=dim(d⊕h)，则负载与故障可分，允许自适应；若故障方向落在 J_mech 的零空间而 J_elec 可辨，则「只诊断不吸收」；若二者都不可辨，则 **冻结自适应 + 按最坏故障收缩包络**（「不确定 → 不解释」）。

**定义 321（电气签名与健康流形）** 在运行点归一化后提取 S_e = Φ(v_dq,i_dq,ω_e)，含：λ̂_m/λ_0、2ω_e 与 6ω_e 谐波、dq 交叉耦合残差、负序电流、单位转速摩擦功率。健康流形 ℳ_H 与故障流形 {ℳ_D(退磁), ℳ_W(绕组), ℳ_B(轴承), ℳ_S(传感增益)}。D_e = dist(S_e, ℳ_H)，ĥ = argmin_h dist(S_e, ℳ_h)。A99：归一化签名对外载一阶不变，对内部参数敏感。

**定义 322（健康感知控制分配 HCA）** 给定期望广义力 w，求 τ 使 `B(m)τ=w`，`0 ≤ τ ≤ ρ_act ⊙ τ_max(T)`，并最小化 `Σ τ_i²/(ρ_act,i τ_max,i)²`（健康加权）。若不可行，则依次尝试：降额任务 → 切换模式 m′ → 安全停机。可行性是模式切换的触发条件之一。

**定义 323（作动置信的包络收缩）** 在安全证书中一律用 τ_eff = ρ_act · τ_cmd（worst-case）替代 τ_cmd。于是最大减速度 a_max=ρ_act τ_max/m，制动距离 ∝ 1/ρ_act，可达集随 ρ_act 单调收缩。ρ_act 由 κ_comm、D_th、D_e、电流传感置信联合给出（保守取最小或按定理 19 合成）。

**定义 324（合成证书与严格包含）** J_EFF = (J_FLUID, ρ_act^p05, κ_comm^min, D_e, U_deliv, U_real, ĥ, m, transition_hash, D_th, eff_ver)。Valid ⇔ Valid(J_FLUID) ∧ ρ_act^p05 ≥ ρ_min ∧ (κ_comm ≥ κ_min ∨ 编码器冗余) ∧ D_th ≤ D_max ∧ 转换证书有效 ∧ 证据纪律满足。当 ρ_act=1、κ_comm=1、D_e=0、m 固定、D_th=0 时，J_EFF 逐项退化为 J_FLUID（严格包含）。

**定义 325（模式滞回与驻留）** 切换需满足驻留时间 τ_dwell 与滞回带 h_m，防止在模式边界抖振（Zeno）。模式切换次数在任意长度 T 的区间内 ≤ ⌈T/τ_dwell⌉。切换不是免费的：每次切换都消耗转换预算并承担转换风险。

**定义 326（实时预算与自适应监测）** FOC 电流环 10–20 kHz；RAS/健康层 1 kHz；电气签名利用既有电流采样，不额外加传感器；签名窗 10 ms；自检动作仅在 VoI 门控触发，单位时间 ≤ 1 次。安全层新增延迟 < 60 µs，不进入电流环实时路径。

class EfferenceMonitor:

# IP-270 SIA：向自己的身体提问（自检 VoI）
def choose_self_probe(h_post, rho_act, budget, envelope):
    best = None
    for g in [D_AXIS_INJECT, SPEED_SWEEP, TORQUE_RIPPLE]:
        if not budget.allow(g) or not envelope.safe(g): continue   # 自检本身不得越界
        voi = entropy(h_post) - expected_entropy(h_post, g)
        score = voi - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

    return tau if feasible else None       # 交给 fallback_ladder：降额 → 换模式 → 停机

    tau_hat, eps_act, rho_act = M.emm.step(tau_cmd, M.i_dq, M.omega_e, M.theta_e, M.T_w)
    kappa = M.csc.commutation_confidence(M.omega_e, M.k_e, M.sigma_v)
    # 2) 电气签名：机械自适应吞不掉的第二意见
    S = M.esa.electrical_signature(M.v_dq, M.i_dq, M.omega_e, M.T_w)
    D_e, h_hat = M.esa.audit_health(S)
    # 3) 可辨识门：能解释成负载才自适应；否则冻结并按故障收缩
    _, frozen = M.foc_e.update(M.v_dq, M.i_dq, M.omega_e, M.dt)
    if frozen: rho_act = min(rho_act, rho_fault(h_hat, D_e))
    # 4) 自检：VoI>成本且不破坏接触时，向电机注入一个小探针
    g_e = M.sia.choose_self_probe(M.h_post, rho_act, M.budget, M.envelope)
    if g_e is not None:
        y = M.sia.inject(g_e); M.h_post = bayes_update(M.h_post, y)
    # 5) 健康感知分配；不可行则走「降额→换模式→停机」阶梯
    tau = M.hca.allocate(M.w_des, M.mode, rho_act, M.tau_max(M.T_w))
    if tau is None:
        M.mode = M.hmr.maybe_switch(M.mode, M.risk_tuple, M.h_post, M.last_switch_t)
        tau = M.hca.allocate(M.w_des, M.mode, rho_act, M.tau_max(M.T_w))
        if tau is None: tau = M.safe_stop()
    # 6) 用 worst-case 作动置信收缩安全包络（继承 R69 的 λ，只收紧）
    lam = max(M.efs.risk_scale(...), lam_floor(U_cal + U_epi))
    lam = max(lam, lam_act(rho_act, kappa))
    k = M.c_ras_wm.certified_prefix(tau, ..., wm_preds)
    M.vqa_a.submit_async(eps_act, D_e, h_hat, M.mode, g_e, rho_act)
    return k, lam, tau, rho_act, M.mode
```

## 3. 推导

**引理 19（作动置信的包络收缩）** 若 ρ_act 是力矩交付的下置信界（P(|τ_real−τ_cmd|≤δ_τ)≥1−α），则用 τ_eff=ρ_act τ_cmd 计算的制动距离/可达集是真实集的保守外近似；且 a_max=ρ_act τ_max/m，制动距离 d_stop ∝ 1/ρ_act，随 ρ_act 单调。系：ρ_act 下降时 λ 单调不降（作动侧只收紧），与 R69 的安全姿态一致；当 ρ_act→0 时退化为「不可执行，停机」。

**引理 20（低速换相的可观测性界）** 反电动势 e=k_e ω，角度估计的噪声放大满足 σ_θ ≳ σ_v/(k_e|ω|)（A100、观测器线性化）。故 κ_comm 随 |ω| 单调下降；抬腿/起身/锁轮等低速大扭矩瞬态的 κ_comm 最小，必须以编码器冗余或力矩降额补偿。系：**足行模式的安全裕度天然小于轮行模式**，除非有直接角度传感——这解释了为什么「换模式更安全」不能无条件成立。

**引理 21（电气签名的不可吸收性）** 在 A99 下，内部参数变化 Δθ_e 使签名位移 D_e ≥ L_e‖Δθ_e‖−η；而机械自适应可把 ε_act 驱动到 0（吸收）。因此 (ε_act≈0, D_e↑) 是「被自适应吞掉的作动器退化」的判别模式，与 R69 引理 17 的 (r_res↓,Δa↑) 同构。**标定吸收的是残差，自适应吸收的是作动偏差；两者都需要一条不能解释掉的物理冗余通道。**

**引理 22（负载-故障可辨识）** 设机械残差对 (负载 d, 健康 h) 的雅可比为 J_mech，电气签名为 J_elec。若 rank([J_mech;J_elec])=dim(d⊕h)，则存在一个线性观测器把 d 与 h 分离；若 h 的方向落入 J_mech 零空间且 J_elec 可辨，则「只诊断不吸收」；若两者皆不可辨，则任意自适应都会把 h 投影成 d，必须冻结。系：**可辨识性不是全局性质，而是工作点相关的**——高速时负载可辨，零速时可能不可辨。

**定理 18（EFF 严格包含 FLUID）** 在 A99–A102 下，当 ρ_act=1、κ_comm=1、D_e=0、D_th=0 且模式固定时，EFF 的每条指令与 FLUID 逐项相同；一般情况下 EFF 的可行动作集 ⊆ FLUID 的可行动作集（作动收缩 + 模式约束只减不增），故期望任务风险 ≤ FLUID。安全侧不做任何放松，只在健康时可获得「作动宽裕」的效率回报（类比 R69 的 resolution bonus）。

**定理 19（合成证书的保守性）** 若各失效通道（感知/信念、作动交付、作动健康、模式转换、热）在给定条件下相互独立，则 J_EFF 有效 ⇒ 真实风险 ≤ Σ_i ε_i（并集界）；若存在正相关（如热同时降额并加剧参数漂移），保守起见用 max_i ε_i + 相关修正项。关键是：**证书只在所有子证书同时有效时有效**，任一不确定即失效并退化为最保守模式（与 R68/R69 的「任一不确定 → 只收紧」一致）。

**定理 20（无 Zeno 与混合安全）** 在驻留时间 τ_dwell > 0 与滞回 h_m > 0 下，任意有限区间内模式切换次数有限；结合定义 317 的转换证书，混合轨迹的风险 ≤ max_m r_safe^m + r_trans，且切换点处安全函数不增。因此 EFF-RAS 的混合闭环不产生抖振诱发的失稳。

# IP-264 EMM：作动实现监测（efference copy vs reafference）
def efference_step(tau_cmd, i_dq, omega_e, lam_hat, Ld_hat, Lq_hat, p):
    tau_hat = 1.5 * p * (lam_hat * i_dq[1] + (Ld_hat - Lq_hat) * i_dq[0] * i_dq[1])
    eps_act = tau_hat - tau_cmd
    rho_act = delivery_confidence(eps_act, omega_e)
    return tau_hat, eps_act, rho_act

# IP-266 CSC：低速换相置信
def commutation_confidence(omega_e, k_e, sigma_v):
    if abs(omega_e) < 1e-3: return 0.0
    return 1.0 / (1.0 + (sigma_v / (k_e * abs(omega_e))) / SIGMA_MAX)

# IP-272 AIG：可辨识才自适应
def adapt_gate(residual, J_mech, J_elec):
    M = stack_rows(J_mech, J_elec)
    if rank(M) == M.shape[1]:
        return "ADAPT"           # 负载与故障可分
    if rank(J_elec) == J_elec.shape[1]:
        return "DIAGNOSE_ONLY"   # 机械零空间，电气可辨
    return "FREEZE_AND_TIGHTEN"  # 都不可辨 → 按最坏故障

# IP-271 ESA：电气签名（自适应不可吸收的第二意见）
def electrical_signature(v_dq, i_dq, omega_e):
    S = dict(lambda_ratio = flux_from_backemf(v_dq, omega_e),
             harm2       = harmonic(i_dq, omega_e, order=2),
             harm6       = harmonic(i_dq, omega_e, order=6),
             dq_cross    = dq_cross_residual(v_dq, i_dq, omega_e),
             neg_seq     = negative_sequence(i_dq),
             fric_power  = (v_dq @ i_dq - mech_power(omega_e)) / max(abs(omega_e), EPS))
    return normalize_by_operating_point(S)

def audit_health(S):
    return min(dist(S, M) for M in HEALTH_MANIFOLDS), \
           argmin_h dist(S, HEALTH_MANIFOLDS[h])

# IP-270 SIA：向自己的身体提问
def choose_self_probe(h_post, budget, envelope):
    cands = [D_AXIS_INJECT, SPEED_SWEEP, TORQUE_RIPPLE]
    cands = [g for g in cands if budget.allow(g) and envelope.safe(g)]
    return max(cands, key=lambda g: entropy(h_post) - expected_entropy(h_post, g) - cost(g),
               default=None)

# IP-269 HCA：健康感知控制分配
def allocate(w_des, m, rho_act, tau_max):
    W = diag(1.0 / (rho_act * tau_max + EPS))
    tau = argmin ||W @ tau||^2 s.t. B(m) @ tau == w_des, 0 <= tau <= rho_act * tau_max
    return tau if feasible else None

# IP-268 HMR：模式切换（转换证书 + 驻留/滞回）
def maybe_switch(m, risk_tuple, health, last_switch_t):
    m_star = lexicographic_mode_select(risk_tuple, health)
    if m_star == m or (now - last_switch_t) < TAU_DWELL: return m
    return m_star if transition_certificate(m, m_star, health) else m

# IP-276 主闭环（继承 FLUID-RAS）
def EFF_RAS_round(M, obs):
    z, o = M.mtm.forward(...); M.cof.step(...)                      # R68/R69 感知层
    tau_cmd = M.pi_sigma.prefix_dispatch(...)
    tau_hat, eps_act, rho_act = M.emm.step(tau_cmd, M.i_dq, M.omega_e, M.T_w)
    kappa = M.csc.commutation_confidence(M.omega_e, M.k_e, M.sigma_v)
    S = M.esa.electrical_signature(M.v_dq, M.i_dq, M.omega_e)
    D_e, h_hat = M.esa.audit_health(S)
    mode = M.aig.adapt_gate(eps_act, M.J_mech, M.J_elec)            # ADAPT / DIAGNOSE / FREEZE
    if mode != "ADAPT": rho_act = min(rho_act, rho_fault(h_hat, D_e))
    g_e = M.sia.choose_self_probe(M.h_post, M.budget, M.envelope)
    if g_e: M.h_post = bayes_update(M.h_post, M.sia.inject(g_e))
    tau = M.hca.allocate(M.w_des, M.mode, rho_act, M.tau_max(M.T_w))
    if tau is None:
        M.mode = M.hmr.maybe_switch(M.mode, M.risk_tuple, M.h_post, M.last_switch_t)
        tau = M.hca.allocate(M.w_des, M.mode, rho_act, M.tau_max(M.T_w)) or M.safe_stop()
    lam = max(M.efs.risk_scale(...), lam_floor(U_cal + U_epi), lam_act(rho_act, kappa))
    k = M.c_ras_wm.certified_prefix(tau, ..., wm_preds)
    M.vqa_a.submit_async(eps_act, D_e, h_hat, M.mode, g_e, rho_act)
    return k, lam, tau, rho_act, M.mode
```

## 4. 推导

**引理 19（作动置信的包络收缩）** ρ_act 为力矩交付下置信界 ⇒ 用 `τ_eff=ρ_act τ_cmd` 的制动距离/可达集是真实集的保守外近似；`a_max=ρ_act τ_max/m`，`d_stop∝1/ρ_act`，随 ρ_act 单调。

**引理 20（低速换相可观测性界）** `e=k_e ω` ⇒ `σ_θ≳σ_v/(k_e|ω|)`；κ_comm 随 |ω| 单调降。系：足行模式的标称工作点天然比轮行更不可观测，除非有直接角度传感。

**引理 21（电气签名不可吸收性）** A99 下 `D_e ≥ L_e‖Δθ_e‖−η`，而机械自适应可把 ε_act→0；故 `(ε_act≈0, D_e↑)` 判别「被自适应吞掉的退化」，与 R69 引理 17 的 `(r_res↓,Δa↑)` 同构。

**引理 22（负载-故障可辨识）** `rank([J_mech;J_elec])=dim(d⊕h)` 才可分离；故障方向落入 J_mech 零空间时「只诊断不吸收」；两者皆不可辨则必须冻结自适应，否则 h 被投影成 d。

**定理 18（EFF 严格包含 FLUID）** A99–A102 下，`ρ_act=1, κ_comm=1, D_e=0, D_th=0, m 固定` 时逐指令相同；一般情况可行动作集 ⊆ FLUID，期望风险 ≤ FLUID。安全不让步，健康时获作动宽裕回报。

**定理 19（合成证书保守性）** 各失效通道独立时 `风险 ≤ Σ_i ε_i`；正相关时用 `max_i ε_i + 修正项`。任一子证书失效 ⇒ 整证失效，退化为最保守模式。

**定理 20（无 Zeno 与混合安全）** `τ_dwell>0, h_m>0` ⇒ 有限区间切换次数有限；结合转换证书，`风险 ≤ max_m r_safe^m + r_trans`，切换点安全函数不增。

## 7. 本轮最大风险

**一句话**：EFF-RAS 的全部安全论证押在「电气签名对负载、温度与故障条件可分」这一前提上——**若签名被负载谐波、磁饱和与温漂污染（A99 失效），那么「不可吸收的第二意见」本身就被吸收，系统会把地形误判成电机退化（频繁降额/换模式，过度保守甚至因换挡失稳），或把退化误判成地形（继续全扭矩，直到摔倒）——误诊，比不诊断更危险。**

**次级风险与缓解**：自检扰动破坏接触（定义 319 包络 + 单腿支撑禁注入 + E309）；模式切换是最危险瞬态（定义 317 转换证书 + 分阶段升力矩 + 定理 20）；可辨识矩阵病态（条件数阈值 + 冻结 + 最坏收缩）；热模型失配（保守上界 + 在线校正 + E305）；传感增益攻击伪装退化（DC 母线功率交叉校验 + 谐波/负序 + E314）。
