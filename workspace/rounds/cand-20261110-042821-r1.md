# 第 41 轮 · 双灵感落地 v8：部署期在线证书过程 × 人形接触条件全身适应（四层架构 v6）

> 承接第 40 轮（v17：可认证流匹配执行 × 度量语义几何锚定 × 证书驱动课程引擎，四层架构 v5）。本轮灵感词「在线学习、人形机器人」驱动一次**时间尺度上的迁移**：第 40 轮把证书从「文档」推进到「训练期闭环」，本轮把它推进到「部署期在线可维护」——证书不再是颁发后静止的承诺，而是带动态遗憾界、任意时刻有效性和撤销开关的**在线证书过程**。人形机器人被选为最严苛的载体：浮动基、欠驱动、离散接触切换、硬件非平稳，它会把「离线证书」的所有隐含假设逐一击穿。

## 0. 直觉与动机

**灵感 1（在线学习 → 证书的「保鲜期」与「撤销开关」）**：第 40 轮的证书仍是「离线一次性颁发」的世界观：训练完、测一遍、签个字、上总线。但人形机器人恰恰是这种世界观最不适用的对象——负载会变（搬箱子、背电池）、地面会变（瓷砖→地毯→油污）、关节会磨损、电池电压会掉、接触模式每 0.3 秒切换一次。静态证书在这些变化下不是「保守」，而是**悄悄失真**：它仍然声称成立，但已不再覆盖真实分布。在线学习给出三件互补的武器：a) **在线凸优化/动态遗憾**给出非平稳下的累积后悔界，告诉我们「边用边学」最多付出多少性能代价；b) **在线共形预测/自适应共形推断（ACI）**在分布漂移下仍给出长期覆盖率保证，把证书边际变成数据自适应的分位数；c) **e-process / Ville 不等式**给出**任意时刻有效**（anytime-valid）的检验——不需要对帧数做 union bound，证书可以在观察到足够反证时被**随时撤销并重颁**。

**关键反转**：第 40 轮的最大焦虑是「证书太松，沦为装饰品」。在线学习给出的回答不是「把离线界算得更紧」，而是「放弃一次性紧致，换取在线自适应 + 可撤销 + 免 union bound」。这带来一个更诚实的安全性叙事：证书不是「永远为真」，而是「在任一时刻，若它仍被系统采信，则它要么为真、要么已被 e-process 以高概率撤销」。代价是 anytime 界天然比离线界宽——这条张力就是本轮的中心矛盾。

**灵感 2（人形机器人 → 证书必须接触条件化）**：人形机器人不是「带腿的机械臂」，而是浮动基、欠驱动、接触离散切换的高维系统。这给证书三条硬约束：a) 证书不能建立在关节空间单点不等式上，必须建立在**质心/ZMP/DCM/摩擦锥/力矩**等多边际上，因为浮动基的 6 个自由度不可直接驱动；b) 支撑多边形在接触切换瞬间**跳变**，第 40 轮 CBF 的连续性/Lipschitz 假设在切换点失效，必须引入**切换守卫集**（viability kernel / capture region）而不是朴素 CBF；c) 接触模式 σ 本身是**被估计的隐变量**，证书必须对接触不确定性取 (1−δ) 可信集上的最坏边际，否则「单脚支撑」误判为「双脚支撑」会让所有安全边际瞬间作废。

**两灵感的耦合（本轮关键）**：在线学习提供「更新机制」，人形机器人提供「更新对象与安全边界」，护盾提供「更新的准入控制」。三者合成一个部署期闭环：**数据流 → IP-51 在线证书过程（监控/漂移检测/撤销）→ IP-52 接触条件全身适应（按 σ 学习残差）→ 护盾准入（不可证则回滚）→ IP-46 重颁证书 → IP-45 契约热更新**。第 40 轮的课程闭环发生在训练期，本轮的在线闭环发生在部署期，二者共享同一套「证书赤字」语言。

**为什么是收束而非扩张**：四十轮已累积 50 个 IP，继续加模块只会让系统更不可搭建。本轮只**新增 2 个 IP（IP-51/52）**，升级 7 个既有 IP，并第一次显式定义「证书生命周期」：颁发 → 监控 → 漂移告警 → 撤销 → 重颁/回滚。在线学习不是又一层网络，而是给整套证书体系装上「代谢系统」。

## 1. 形式化定义

**定义 27（接触条件人形动力学与多边际证书状态）**：人形机器人位形 q = (q_b, q_j)，q_b ∈ SE(3) 为浮动基，q_j ∈ R^{n_j} 为关节。接触模式 σ_t ∈ Σ 为有限集合（双脚/左脚/右脚/手接触的组合）。动力学：

M(q)q̈ + h(q,q̇) = Sᵀτ + J_σᵀλ_σ，  J_σq̈ + J̇_σq̇ = 0，  λ_σ ∈ K_σ(μ_σ)，

其中 K_σ(μ_σ) 为摩擦锥。证书状态定义为 C_t = (m_t, B_t, θ_t, p_t(σ))，多边际向量

m_t = (m_zmp, m_dcm, m_fric, m_trq, m_flow)，

m_zmp = dist(p_zmp, ∂P_σ)（ZMP 到支撑多边形边界的有符号距离），m_dcm = dist(ξ, C_σ)（capture point 到捕获域），m_fric = min_i dist(λ_i, ∂K_i)，m_trq = min_j(τ_max,j − |τ_j|)，m_flow 复用第 40 轮 ε_tol − ε_ode(N*)。记归一化总边际 m_t = min_i m_i/c_i。

**定义 28（任意时刻有效的在线证书过程 OCP）**：对一条待证命题（如「m_t* ≥ 0」），构造检验统计量 X_t ∈ [0,1]（边际违约指示或共形非一致性分数）。e-process 为 E_t = ∏_{s≤t}(1 + λ_s(X_s − μ₀))，λ_s 可预测，且在零假设 H₀（证书已失真）下 E[X_s | F_{s−1}] ≤ μ₀，故 (E_t) 为非负上鞅，E₀=1。由 Ville 不等式，对任意停时与任意时域 T：

P_{H₀}(∃t ≤ T : E_t ≥ 1/δ) ≤ δ。

定义证书的**有效寿命** τ(δ) = inf{t : E_t ≥ 1/δ}；t < τ 时证书被采信，t ≥ τ 时立即撤销并进入重颁流程。边际的量化用在线共形 + ACI：m_t = Q_t(1−α_t)，α_{t+1} = α_t + γ(α − err_t)，err_t = 1[m_t* < m_t]；长期覆盖率满足 (1/T)Σ err_t ≤ α + O(1/(γT))，无需平稳性。

**定义 29（证书动态遗憾与在线适应）**：在线残差参数 θ_t 的第 t 步证书损失定义为

f_t(θ) = [c − m_t*(θ)]₊ + (ρ/2)‖θ − θ_{t−1}‖²，

其中第一项是证书赤字（hinge），第二项是切换代价。令 θ_t* = argmin_θ f_t(θ)，动态遗憾与路径长度分别为

Reg_T^d = Σ_{t=1}^T [f_t(θ_t) − f_t(θ_t*)]，  P_T = Σ_{t=1}^{T−1}‖θ_{t+1}* − θ_t*‖。

采用在线镜像下降（OMD）且 η_t = η/√t，在 f_t 凸、梯度有界的条件下有 Reg_T^d ≤ O(√(T(1+P_T)))；若 f_t 强凸则收紧到 O((1+P_T)log T)。**工程约束**：只对证书头（最后一层/线性读出）凸化，主干在每个部署窗口内冻结，否则凸性假设不成立，该界只能作为设计目标而非宣称的定理。

**定义 30（证书保持的护盾更新）**：设备份控制器 π_b（由 IP-38 升级）拥有鲁棒控制不变集 I_b 与接管时延 τ_b。一次在线更新 θ → θ′ 被护盾**准入**，当且仅当：

(i) x_t ∈ I_b；
(ii) 在预测时域 [t, t+H] 内，以 anytime-valid 不确定集 U_t 构造的 CBF-QP 对新参数 θ′ 可行；
(iii) IP-51 的 e-process 未拒绝新证书声明。

否则回滚 θ′ → θ；若连回滚后的 CBF-QP 也不可行，则立即切换 π_b。**定理（护盾安全归纳）**：若 I_b 对 π_b 不变、切换满足一步可接管假设，则对**任意**学习算法（包括对抗性探索），系统在整个部署期保持在安全集内，且 P(发生不可撤销的安全违约) ≤ δ。证明：对 t 归纳；准入分支由 CBF 不变性保持，拒绝分支由 I_b 不变性保持。∎

**定义 31（接触后验与鲁棒边际）**：由足底六维力、IMU、编码器维护接触模式后验 p_t(σ)（HMM/贝叶斯滤波 + 变点检测）。取 (1−δ) 可信集 Σ_t(δ) = argmin{|S| : Σ_{σ∈S} p_t(σ) ≥ 1−δ}，定义鲁棒边际

m_t^rob = min_{σ ∈ Σ_t(δ)} m_t(σ)。

证书仅在 m_t^rob ≥ 0 时成立。**命题（切换守卫）**：若在计划切换 σ→σ′ 的时刻满足 p_zmp(t) ∈ int(P_{σ′}) 且 ξ(t) ∈ C_{σ′}，且剩余单脚支撑相内 DCM 可被驱动进 C_{σ′}，则存在满足接触约束的全身控制序列；反之，若 p_zmp(t) 落在 P_{σ′} 的一步可达集之外，则任何满足刚性接触模型的 (λ, τ) 都无法避免本步内的失衡。由此得到切换守卫集 G_{σ→σ′}，只有 x_t ∈ G_{σ→σ′} 才允许切换。∎（证明要点：捕获点/线性倒立摆的可达性分析。）

## 2. 两大产出设计

### 2.1 IP-51 ONLINE-CERT-PROCESS（在线证书过程）

1. **逐条款 e-process 监控**：为 CertBundle 的每条条款（L_v/κ、B_t、h_min、m_zmp、m_dcm、m_fric）各配一个 e-process；条款失效互不掩盖，撤销可局部发生。
2. **在线共形边际量化**：ACI 自适应 α_t，使 m_t 在漂移下既不长期过松（覆盖率塌陷）也不长期过紧（ValidRegion 空集）；共形分数按接触模式分层。
3. **漂移检测与撤销状态机**：valid → suspect（连续 k 步 e-value 上升）→ revoked（E_t ≥ 1/δ）→ reissuing → valid/rollback；带最小驻留时间与滞回，防止撤销抖动。
4. **重颁触发**：撤销后调用 IP-44 蒸馏/IP-46 重颁；若重颁失败，总线回退到上一份仍有效的证书（版本化 CertBundle）。
5. **与 IP-46/IP-45 的接口**：每个 CertBundle 增加 `{E_t, τ(δ), valid_until, version, revoke_reason}`；总线网关把「证书已撤销」作为第五类熔断触发器。

### 2.2 IP-52 HUMANOID-CONTACT-ADAPT（人形接触条件全身在线适应）

1. **接触后验**：足底力 + IMU + 关节编码器 → HMM 后验 p_t(σ) → 可信集 Σ_t(δ)；接触模糊时主动降级为最坏模式。
2. **接触条件残差**：π(a|o,σ) = π₀(a|o,σ) + Δθ_σ(o)，按接触模式维护独立残差头；共享主干、模式专属低秩适配，避免模式间灾难性干扰。
3. **凸化在线更新**：主干冻结，仅证书头用 OMD/AdaGrad 最小化定义 29 的 f_t；每步梯度由证书赤字 + 跟踪损失构成，更新前做梯度裁剪与参数投影。
4. **护盾准入**：定义 30 的准入 + 回滚；备份为 IP-38 的恢复控制器，其不变集 I_b 由降阶质心模型离线认证。
5. **切换守卫 + 全身 QP**：接触调度器只在 x_t ∈ G_{σ→σ′} 时切换；全身 QP 的约束用 B_t 膨胀后的摩擦锥与力矩上限。
6. **数据充分性门控**：某模式样本不足或 e-process 已拒绝时，Δθ_σ 收缩回先验（shrinkage），避免小样本过拟合导致的错误自信。

## 4. 实验设计（E73-E78 硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E73 任意时刻有效性 | 10⁵ 步 × 20 次分布突变下的覆盖率与误撤销率 | 覆盖率≥99%（δ=0.01）；误撤销≤1/5000 步 |
| E74 在线紧致性 | ACI 区间宽度 / 离线 oracle 宽度；ValidRegion 非空率 | 宽度比≤1.5；非空率≥99%；撤销抖动≤2 次/小时 |
| E75 非平稳适应 | 负载 +5kg、摩擦 0.6→0.3、坡度突变下的恢复步数与动态遗憾 | 恢复≤200 步；归一化 Reg_T^d ≤ 固定 θ 基线的 0.5× |
| E76 护盾安全 | 1000 次随机推搡 + 湿滑地面的摔倒数与 CBF 违约 | 护盾组摔倒=0；CBF 违约=0；备份接管≤10% |
| E77 接触切换 | 500 次切换（含双支撑歧义）的守卫误放行/误拒绝 | 误放行=0；误拒绝≤5%；切换成功率≥95% |
| E78 端到端 | 30 分钟连续运行 + 在线更新的扰动成功率/证书违约 | 成功率≥85%；违约<0.1%；摔倒=0 |

**回退路径**：E73/E74 不达标 → 冻结在线边际量化，回退第 40 轮静态证书 + 安全系数，IP-51 降级为离线监控工具；E76/E77 不达标 → 禁止真机在线更新，仅在仿真中启用 IP-52，保留护盾与切换守卫作为纯安全层。

## 5. 本轮最大风险

**一句话**：「任意时刻有效」必然比离线界更宽——若 e-process/共形区间在真实人形上放大到使 ValidRegion 缩为空集、护盾持续回滚，系统会退化成「永远不敢更新」的静态证书，本轮的全部在线收益将归零，故 E73/E74 必须作为第一守门实验。

## 2. 关键算法

### IP-51 在线证书过程（伪代码）
```
def ocp_step(cert_bundle, obs, delta=0.01, gamma=0.05):
    cert = cert_bundle.current
    for clause in cert.clauses:                       # 逐条款并行
        X = clause.test_statistic(obs)                # ∈[0,1]
        clause.E = clause.E * (1 + clause.lam * (X - mu0))
        if clause.E >= 1/delta:                       # Ville: 任意时刻有效
            state_machine.revoke(clause, reason="e_value")
        err = 1[clause.true_margin(obs) < clause.m]  # 事后校准
        clause.alpha = clip(clause.alpha + gamma*(alpha0 - err), 0, 1)
        clause.m = online_conformal_quantile(clause.scores, 1 - clause.alpha)
    if state_machine.state == "revoked":
        ok = IP44.recertify(cert) and IP46.reissue(cert)
        Registry.hot_swap(cert.version, fallback=ok is False)
    return state_machine.state

def online_conformal_quantile(scores, q, mode_sigma):
    S = scores.filter(mode=mode_sigma)                # 按接触模式分层
    return quantile(S, q, interpolate="higher")
```

### IP-52 人形接触条件适应（伪代码）
```
def contact_posterior(force, imu, enc, prev):
    p = hmm_update(prev.p, force, imu, enc)           # 足底力+IMU+编码器
    credible = smallest_set(p, mass=1-delta_sigma)
    return p, credible

def robust_margin(margins, credible):
    return min(margins[sigma] for sigma in credible)   # 最坏接触模式

def shielded_update(policy, theta, x, batch, H):
    grads = [cert_loss(b, theta) + rho*(theta - theta_prev) for b in batch]
    theta_new = omd_step(theta, mean(grads), eta=eta0/sqrt(t))
    theta_new = project(theta_new, radius=R)          # 参数投影
    if x not in backup.invariant_set:  return rollback(theta)
    if not cbf_qp_feasible(policy, theta_new, x, H, U=ocp.uncertainty()):
        return rollback(theta)                         # 不可证则拒绝更新
    if ocp.rejected(theta_new):        return rollback(theta)
    return theta_new                                   # 护盾准入

def whole_body_control(x, policy, theta, sigma_target):
    if sigma_target != sigma_current:
        if x not in switch_guard(sigma_current, sigma_target):
            sigma_target = safest_reachable_mode(x)   # 守卫拦截
    u = policy(x, theta, sigma_target)
    return cbf_qp(u, x, sigma_target, inflation=B_t)   # 摩擦锥/力矩膨胀
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 正确性保证 |
|---|---|---|
| e-process 更新 | 每条款 O(1)，逐条款并行 | **定理**：Ville ⇒ P(∃t≤T 误采信)≤δ，对任意 T 同时成立 |
| ACI 共形量化 | 每步 O(log n)（有序分数树） | 长期覆盖 ≤ α+O(1/(γT))，无需平稳性 |
| 接触后验 | HMM O(|Σ|²)/步；变点检测 O(1) 摊销 | 可信集覆盖真实模式概率 ≥1−δ |
| 动态遗憾更新 | O(d) 每步（证书头）；O(√(T(1+P_T))) 后悔 | 凸证书头 + 有界梯度下成立 |
| 护盾准入 | CBF-QP O(H·n³)；备份查询 O(1) | **定理**：准入/回滚归纳 ⇒ 任意学习算法下保持安全 |
| 切换守卫 | 捕获点/可达集查询 O(n²) | ZMP 支撑多边形 + DCM 捕获域 + 一步可达的必要条件 |
| 版本化证书路由 | O(1) 查表 + O(|V|) 校验 | 组合契约仅接受同一时间窗内有效版本 |

## 8. 本轮最大风险

**一句话**：「任意时刻有效」必然比离线界更宽——若 e-process/共形区间在真实人形上放大到使 ValidRegion 缩为空集、护盾持续回滚，系统会退化成「永远不敢更新」的静态证书，在线学习的全部收益归零，故 E73/E74 是本轮成败判据。
