# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因」IP-214~223；灵感循环第 1 轮；本轮灵感：「力矩控制」×「隐私保护」）

> 第 65 轮用视觉与动作分块把「可证伪」升级为「可归因」，其自述的最大风险很清楚：**故障归因建立在"故障属于有限假设集、且视觉与几何的失效相互独立"之上；真实故障常是未知类型的复合，透明/镜面/对抗 patch 会让视觉与几何共享同一个分布外失效源，于是 FIR 把未知复合故障强行归入最近假设、只膨胀错误的球——系统还会因为"已经归因"而更自信地继续执行。** 更根本地看，VISTA 把安全越来越押在"必须被看见、被上传、被归因"的证据上：这既在认识论上脆弱，也在隐私上昂贵。本轮换一个更底层的提问：
>
> **安全能不能不依赖任何"必须被观测"的证据？**
>
> 本轮核心命题：**把安全底座从「概率推断」下沉为「物理不变式」——用关节力矩残差（JTR）作为与视觉/末端 F-T 失效模式独立的第三通道，用关节力矩/能量包络（TSE）作为不依赖任何学习模型的执行器级硬地板；隐私保护由此不再是安全的对价，而是一条把安全架构从"必须观测"逼回"只需不变式"的约束。归因只在隐私与可观测性允许时作为性能增强，而不是安全的必要条件。**

## 0. 直觉与动机

**灵感 1（力矩控制 → 伤害真正发生的物理层，也是第三条独立通道）**
直觉：前 65 轮的安全都是"证书说这个计划安全"；但无论几何幻觉、F/T 偏置、接触模型错还是视觉被骗，**最终都要经过关节力矩与运动才能造成伤害**。力矩控制给了两个别处没有的东西：(i) **执行器级硬地板**——在 1kHz 上直接约束关节力矩、力矩变化率、接触力上界与交互能量，任何上层命令（哪怕归因完全错误）都无法把超过预算的能量注入环境；(ii) **关节力矩残差**——由 `r_τ = τ_meas − τ_model(q,q̇,q̈)` 反推外部接触，它不经过相机、不经过末端 F/T，是 VISTA 明确列为"未来工作"的**第三个物理独立通道**。且它低维、无纹理/无面部信息，是**隐私廉价**的。必须诚实：`r_τ` 只在 `J_c^T` 的可观测子空间里能反推接触，模型误差（摩擦、负载、柔性、磨损）本身就是一个新故障源 `H_torque`，不能把"不可观测"当成"没有接触"。

**灵感 2（隐私保护 → 先分清"本地安全"与"外发/留存/审计"）**
直觉：把隐私等同于"给数据加噪"是粗糙的。真正要分四层：**(a) 外发隐私**——原始图像/点云/力波形/触觉不出机器人，只外发任务充分统计量的 DP 版本；**(b) 留存隐私**——原始证据只进短时环形缓冲，加密、限期、可删除，安全审计只依赖不可逆摘要；**(c) 本地策略门控**——私人区域/未授权场景直接禁止相机，这是**本地可用性**的减少，而不是噪声；**(d) 审计隐私**——对外证明"证书有效、隐私预算核算正确"而不披露原始证据，同时保护操作者的技能参数与故障库 IP。关键诚实点：**外发 DP 噪声本身不降低本地安全**（本地安全用原始数据）；真正侵蚀安全的是"门控让模态消失""DP 化的车队先验变差""留存限制让事后诊断变弱"。还有一条易被忽视的统计事实：隐私门控是 **MNAR（非随机缺失）**——相机恰恰在可识别的私人场景被关掉，缺失与场景/故障相关，朴素边缘化会让归因产生系统偏差。

**灵感 3（合流 → PACT：Privacy-budgeted Attribution with Certified Torque envelope，隐私预算感知的力矩认证安全闭环）**
闭环：**JTR + TSE 不变式硬地板（永远在线）** → 隐私状态与可用性掩码 → 缺失感知的阶段化签名 → PACT-FIR（新增 `H_torque/H_priv/H_act`，且"没看"绝不当"看错"）→ 可观测时按归因定向膨胀（RSC-P 新增 `r_tau/r_priv`），不可观测时做**模态替代 MSA**（视觉被禁 → 力矩+F/T+TSE 主导）→ 隐私预算分配 PBA（只影响外发/车队学习/审计）→ 块级认证前缀 CSC 在 TSE 可行域内规划 → DP 故障库 + 零知识审计 → 隐私对抗认证 AIC-P。VISTA 是"用更多证据把安全推断得更准"；PACT 是"先把安全做成不需要推断的不变式，再用推断去改善诊断与性能"。

**灵感 4（反直觉主张 → 隐私与安全在此架构下可以对齐，而不是必然对价）**
主流叙事是"隐私要少采数据 → 感知变差 → 安全变差"。PACT 的主张是：**如果把安全底座放在低维物理不变式上，数据最小化与安全反而同向**，因为不变式几乎不需要可识别数据。代价不是消失，而是**转移**：隐私门控让**诊断**变慢、变弱——伤害被包络限制住，但故障可能要到力矩/能量层面才暴露；慢变/软故障可能长期不被命名。于是本轮给出一个可证伪的"隐私-安全前沿"：**硬地板对隐私预算近似不变，归因/诊断质量随隐私预算单调下降**。这也把 VISTA 的"归因后过度自信"从根上拆掉：安全不再取决于"我们归因对了没有"。

**灵感 5（VISTA/GRIP 组件的原位升级）**
- **FIR → PACT-FIR**：假设集增 `H_torque`（力矩偏置/动力学模型错）、`H_priv`（缺失由隐私门控造成，不是故障）、`H_act`（饱和/驱动故障）；似然显式建模缺失掩码 `m` 与 MNAR；缺失绝不作为阴性证据。
- **新增 JTR**：把 VISTA 里那个标量 `ē_torque` 升级为带可观测椭球的结构化关节力矩残差通道（含多接触歧义与零空间不可观测）。
- **新增 TSE**：力矩/力矩变化率/接触力/表观刚度/能量罐五重约束的 1kHz QP 安全滤波，作为执行器级硬地板。
- **RSC-V → RSC-P**：球拆为 `r_geo/r_force/r_model/r_tau/r_priv`；隐私门控只膨胀 `r_priv`，**绝不**因"没看"而膨胀 `r_geo`。
- **WCV-V → WCV-P**：搜索域增 `T_safe` 与可用性约束 `O(π_priv)`；隐私使域过宽时退化为力矩限幅柔顺模式，而不是无限膨胀几何。
- **AFA → AFA-P**：探针在隐私预算与 TSE 下选择；需要相机进入私人区域的探针禁用；信息增益按泄露风险折价。
- **CSP-V → CSP-P**：每条块边需 `Safe(J_pact)` 且存在 TSE 可行解；新增 `torque_probe`（无需视觉的安全力矩激励，辨识接触/动力学）与 `privacy_blackout`（降级模式）。
- **AIC-V → AIC-P**：威胁集增成员推断、隐私预算耗尽 DoS、用"类 DP 噪声"掩盖真实故障、力矩欺骗、把机器人诱入相机禁区的利用。
- **OLP/DIR/SSB**：只在本地短时缓冲或 DP 释放数据上学习；加入保留期、遗忘与来源追踪。
- **J_vista → J_pact**：证书增 `jtr_obs`、`tau_margin`、`energy_tank`、`privacy_policy_hash`、`privacy_budget_used`、`privacy_unobservable`、`dp_provenance`、`zk_audit`、`unlearn_ver`；并区分**双路径有效性** `Safe`（不变式）与 `Rich`（不变式+归因）。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（PACT 闭环）**：`PACT = (VISTA, JTR, TSE, PACT-FIR, PBA, MSA, RSC-P, WCV-P, AFA-P, CSP-P, DFL, ZKA, AIC-P, J_pact)`。定位：VISTA 的"隐私预算感知 + 执行器级硬地板"升级。核心不变式：**安全底座不依赖任何学习模型，也不依赖任何被本地隐私策略禁止采集的数据；隐私只约束"外发/留存/审计披露"，不约束本地力矩级不变式的执行。** 安全有两条独立路径：**不变式路径**（永远可用）与**归因路径**（可观测且预算允许时增强）。
- **定义 234（关节力矩残差 JTR 与接触可观测性）**：由 `τ_meas = τ_act + τ_ext`、刚体动力学 `τ_model = M(q)q̈ + C(q,q̇)q̇ + g(q) + τ_f(q̇)`，定义 `r_τ := τ_meas − τ_model = J_c^T(q) w_c + b_model + ν_τ`，`w_c` 为接触力旋量，`b_model` 为未建模项，`ν_τ` 为力矩传感噪声。加权最小二乘 `ŵ_c = (J_c Σ_τ^{-1} J_c^T)^{-1} J_c Σ_τ^{-1} r_τ`（`J_c` 行满秩时）；可观测椭球 `E_obs = {J_c^T w : ‖w‖_{Σ_τ^{-1}} ≤ 1}`，零空间方向**不可辨识**、不得归因。JTR 与视觉、末端 F/T 的**失效模式**条件独立（不同传感器、不同模型误差），但其可观测方向受 `J_c` 约束。
- **定义 235（力矩安全包络 TSE 与能量罐）**：`T_safe(q,q̇,φ) = {τ : |τ_i| ≤ τ_i^max, |τ_i − τ_i^prev| ≤ Δτ_i, ‖Λ_c J_c^{-T} τ‖ ≤ f_max(φ), K_app(q,τ) ≤ K_max, E_tank ≥ 0}`。实时求解 `τ_safe = argmin_τ ‖τ − τ_ref‖²  s.t. τ ∈ T_safe`（小维 QP/主动集）。能量罐 `E_{t+1} = clip(E_t + Δt(τ_safe^T q̇) − Δt P_out, 0, E_max)`；仅当更新后 `E ≥ 0` 才允许该命令。结论：**交互能量与接触力被预算硬界住，与上层归因是否正确无关。**
- **定义 236（两级隐私状态与释放机制）**：隐私状态 `π_priv = (a_t ∈ {0,1}^d, ε_total, δ, retention, zone, consent)`，`a_t` 为本地允许的模态集合。本地安全与控制使用原始数据；**外发**只允许任务充分统计量 `f(evidence)` 经 `(ε,δ)`-DP 机制 `M_ε` 释放；**留存**走最小化、加密、限期与可删除；**审计**只走承诺与零知识/选择性披露。记 `ε` 的 Rényi/zCDP 组合账本为 `ε_used(t)`。
- **定义 237（隐私诱发不可观测性与 MNAR）**：`privacy_unobservable(m_t)` 表示某模态因隐私策略本地不可用。缺失掩码 `m_t` 的分布依赖潜在场景 `s`（私人区域才关相机），故一般 **MNAR**：`p(ρ_obs, m | H) = ∫ p(ρ_obs | ρ_mis, H) p(ρ_mis | H) p(m | s, H) dρ_mis ds`。朴素按 `p(ρ_obs|H)` 边缘化会在 `p(m|H)` 与 `H` 相关时产生偏差；用重要性比重界或显式 `p(m|H)` 建模做敏感性分析。**硬规则：缺失只能降低可观测性，不能作为否定几何/否定接触的证据。**
- **定义 238（PACT-FIR 假设集与缺失感知归因）**：`ℋ_P = ℋ_VISTA ∪ {H_torque, H_priv, H_act}`；`H_torque` 为关节力矩偏置/动力学模型错（摩擦、负载、柔性、磨损），`H_priv` 为缺失由隐私门控造成（**非故障**），`H_act` 为饱和/驱动故障。后验 `P(H | ρ_obs, m) ∝ p(ρ_obs, m | H)P(H)`。处置：`H_torque → r_tau↑` 并触发零负载/自由空间辨识；`H_priv →` 不膨胀任何物理球，只置 `privacy_unobservable` 并进入 MSA；`H_act →` TSE 立即限幅 + 柔顺/制动，不走学习层。
- **定义 239（隐私-可辨识性前沿）**：只保留可观测证据 `ρ_obs`，令 `S_obs` 为对应签名子矩阵、`Σ_ρ(ε,m) = Σ_0 + diag(σ²(ε))`。可辨识裕度 `κ_fi(ε,m) = λ_min(S_obs^T Σ_ρ^{-1} S_obs) / λ_max(S_obs^T Σ_ρ^{-1} S_obs)`。`κ_fi` 对 `ε` 单调不减、对门控模态数单调不增；存在阈值 `ε_min` 使 `κ_fi < κ_min`，此时任何归因器正确率不优于随机，**唯一合法策略是不变式路径 + 保守降级**。
- **定义 240（隐私预算分配 PBA）**：`max_{ε_m ≥ 0} Σ_m U_m(ε_m)  s.t. Σ_m ε_m ≤ ε_total`，`U_m` 为释放模态 `m` 对诊断/车队先验的期望效用，按泄露风险折价。`U_m` 凹 → 注水法；次模 → 贪心 `(1−1/e)`。PBA **只影响外发/车队学习/审计**；预算耗尽 → 停止外发与学习更新，**不触发安全降级**（本地不变式继续）。
- **定义 241（模态替代 MSA）**：给定可用集 `a_t`，替代映射 `σ_subst` 把依赖被禁模态的推断替换为等价保守推断：视觉被禁 → `VCV` 失效、由 `JTR + F/T + TSE` 主导；深度被禁 → 力矩/本体感觉主导的接近限速。替代后的可观测性与性能折损写进证书；**禁止用替代后的缺失去否定几何先验**。
- **定义 242（RSC-P 隐私感知球校准）**：维护 `r_geo, r_force, r_model, r_tau, r_priv`，融合 `r = √(r_geo² + r_force² + r_model² + r_tau² + r_priv²)`。规则：`H_geo→r_geo↑`；`H_force→r_force↑`；`H_model→r_model↑`；`H_torque→r_tau↑`；`H_priv`/门控→`r_priv↑`（**绝不动 `r_geo`**）；`H_act→` 不进规划、直接 TSE 降级。这把"我们选择不看"与"几何是错的"彻底分开。
- **定义 243（WCV-P 与 CSP-P）**：搜索域 `B(φ̂,r) ∩ 𝒢(g) ∩ K(μ̂) ∩ ℱ(f_lim) ∩ 𝒱 ∩ T_safe ∩ O(π_priv)`。若隐私使域过宽（交集为空或过保守），退化为**力矩限幅柔顺模式**而非无限膨胀几何球。CSP-P 每条块边需 `Safe(J_pact)` 且存在 TSE 可行解；可插入 `torque_probe`（安全力矩激励辨识接触/动力学，无需相机）与 `privacy_blackout`（降级执行）。
- **定义 244（DP 故障库与安全聚合 DFL）**：车队以联邦方式估计 `p(ρ|H)`，更新经安全聚合 + DP（`ε_lib` 账本）；单机数据不可被反推；支持**认证遗忘**（certified unlearning）与来源哈希 `dp_provenance`。FIR 的先验必须携带 DP 来源与预算，禁止使用未核算来源的"免费"先验。
- **定义 245（零知识/选择性披露审计 ZKA）**：对证书与证据摘要做 `C = Commit(J_pact, digest, salt)`；在块边界生成零知识证明，证明 (i) 全前缀满足 `T_safe` 约束、(ii) DP 核算正确、(iii) `J_pact` 的公开字段满足 `Safe/Rich` 规则；验证者只学到"有效 + 公开元数据"，不学原始证据；同时隐藏技能参数与故障库（操作者 IP）。遗忘通过遗忘证明 `unlearn_ver` 与删除摘要链体现。**注意：ZK 证明的是"计算与约束被正确执行"，不是"传感器物理为真"。**
- **定义 246（隐私对抗威胁模型 AIC-P）**：`ℰ_P = ℰ_V × ℰ_priv × ℰ_tau`；`ℰ_priv` 含成员推断、隐私预算耗尽 DoS、用类 DP 噪声掩盖真实故障、把机器人诱入相机禁区的利用；`ℰ_tau` 含力矩传感欺骗、负载突变造成的模型失配。最坏情况保证：**即使全部隐私攻击成功，TSE + 硬件力矩限幅仍然成立**；若力矩通道本身被攻破，判 `H_torque` 并退到硬件/机械限位 + 安全停。
- **定义 247（PACT 证书 J_pact 与双路径有效性）**：`J_pact = (J_vista, jtr_obs, tau_margin, energy_tank, privacy_policy_hash, privacy_budget_used, privacy_unobservable, dp_provenance, zk_audit, unlearn_ver, aic_p_ver)`。定义：
  - `Safe(J_pact) ⇔` TSE 不变式已验证 ∧ 硬件限幅在位 ∧ 隐私核算一致 ∧（`privacy_unobservable ⇒` 未把缺失当阴性证据）；
  - `Rich(J_pact) ⇔ Safe(J_pact) ∧ Valid(J_vista) ∧` 归因可辨识（`κ_fi ≥ κ_min`）∧ 未引用不可用模态的结论。
  规划中凡使用归因/几何细分者需 `Rich`；仅执行保守安全动作只需 `Safe`。审计链新增：为何可用归因（`jtr_obs`）、为何此刻安全（`tau_margin/energy_tank`）、隐私花了多少（`privacy_budget_used`）、是否看过（`privacy_unobservable`）。
- **定义 248（PACT 闭环算子）**：语义流 `[LiDAR→LSF→USR/MEL→VPG/ACH→阶段切分→PACT-FIR（缺失感知）→RSC-P→WCV-P/CSP-P→CSC→ZKA→DFL→AIC-P]`；实时流 `[JTR 残差→阶段判定→TSE 1kHz QP→安全前缀派发→能量罐更新→硬件限幅→早停]`。不变式：实时流零学习写操作，且**实时流不依赖任何外发/DP 数据**。

## 2. 形式化定义（完整版）

**定义 233（PACT 闭环）** PACT 是 VISTA 的"隐私预算感知 + 执行器级硬地板"升级，在 VISTA 的"语义流 ∘ 实时流"骨架上新增 JTR（关节力矩残差）、TSE（力矩安全包络）、PBA（隐私预算分配）、MSA（模态替代）、DFL（DP 故障库）、ZKA（零知识审计），并原位升级 FIR→PACT-FIR、RSC-V→RSC-P、WCV-V→WCV-P、AFA→AFA-P、CSP-V→CSP-P、AIC-V→AIC-P、J_vista→J_pact。核心不变式：

1. **安全底座与学习/归因解耦**：`T_safe` 与能量罐在实时流执行，只依赖本体感觉、力矩与几何硬约束，不依赖世界模型、故障后验或任何外发数据。
2. **隐私只约束外发/留存/审计披露**：本地安全可用原始数据；原始数据不出机器人；外发只允许 DP 的任务充分统计量；审计只披露证明与公开元数据。
3. **缺失不是阴性证据**：因隐私门控而缺失的模态，只能降低可观测性，不能被解释为"没有接触/几何正确/几何错误"。
4. **双路径有效性**：`Safe` 永远可用，`Rich` 只在可观测且预算允许时可用；归因失败不导致安全失败，只导致诊断/性能降级。

**定义 234（关节力矩残差 JTR 与接触可观测性）** 将关节力矩测量写作 `τ_meas = τ_act + τ_ext`，刚体动力学给出 `τ_model = M(q)q̈ + C(q,q̇)q̇ + g(q) + τ_f(q̇)`。定义残差

`r_τ := τ_meas − τ_model = J_c^T(q) w_c + b_model + ν_τ`，

其中 `b_model` 汇集未建模摩擦、负载、连杆柔性、磨损与传感偏置，`ν_τ ∼ N(0, Σ_τ)` 为力矩噪声。给定 `J_c` 与 `Σ_τ`，接触旋量的加权最小二乘估计为

`ŵ_c = (J_c Σ_τ^{-1} J_c^T)^{-1} J_c Σ_τ^{-1} r_τ`（`J_c` 行满秩时）。

可观测椭球 `E_obs = {J_c^T w : ‖w‖_{Σ_τ^{-1}} ≤ 1}`；`ker(J_c^T)` 方向**不可辨识**，不得归因，也不得据此否定接触。多接触时 `r_τ = Σ_k J_{c,k}^T w_{c,k} + b_model + ν_τ`，存在**力矩接触歧义**（多个接触旋量组合可产生同一残差），需用稀疏/支撑先验或额外激励 `torque_probe` 消歧。JTR 与视觉、末端 F/T 的**失效模式条件独立**：相机对抗 patch 不改变关节力矩残差，末端 F/T 偏置也不改变 `τ_meas`（除非同一物理原因同时导致，见 A94/A95）；因此 JTR 是 VISTA 所缺的第三物理通道。但它把"力矩通道 + 动力学模型"变成新的单点假设。

**定义 235（力矩安全包络 TSE 与能量罐）** 定义允许力矩集

`T_safe(q,q̇,φ) = {τ : |τ_i| ≤ τ_i^max ∀i；|τ_i − τ_i^prev| ≤ Δτ_i；‖Λ_c J_c^{-T} τ‖ ≤ f_max(φ)；K_app(q,τ) ≤ K_max；E_tank ≥ 0}`，

其中 `Λ_c` 为接触空间惯性，`K_app` 为表观刚度上界（防止"力虽小但硬顶"造成脆性损伤）。每个控制周期求解小维 QP：

`τ_safe = argmin_{τ} ‖τ − τ_ref‖²_{W_τ}  s.t.  τ ∈ T_safe(q,q̇,φ)`。

能量罐递归 `E_{t+1} = clip(E_t + Δt(τ_safe^T q̇) − Δt P_out, 0, E_max)`；只接受使 `E_{t+1} ≥ 0` 的命令。结论：无论上层给出何种 `τ_ref`（包括由错误归因、未知复合故障、对抗策略产生的命令），执行器注入环境的累计能量与接触力都被 `E_0 + Σ补给` 与 `f_max` 硬界住。TSE 是**执行器级硬地板**，不是另一个概率证书。

**定义 236（两级隐私状态与释放机制）** 隐私状态 `π_priv = (a_t, ε_total, δ, retention, zone, consent)`，`a_t ∈ {0,1}^d` 表示本地允许使用的模态（RGB/深度/末端 F/T/触觉/力矩/本体）。隐私分四层：

1. **外发**：原始数据不出机器人；只释放任务充分统计量 `f(evidence)` 经 `(ε,δ)`-DP 机制 `M_ε`（Laplace/高斯 + RDP/zCDP 组合账本 `ε_used(t)`）。
2. **留存**：原始证据仅存短时加密环形缓冲，按 `retention` 限期删除；跨轮学习只用摘要/统计量；支持按来源删除。
3. **本地策略**：`zone/consent` 可禁止某些模态在本地采集（例如私人区域禁相机）——这减少**本地可用性**，不是加噪。
4. **审计**：证书与证据摘要做承诺，用零知识/选择性披露证明有效性，不披露原始证据。

关键：**外发 DP 噪声不进入本地 TSE 与实时控制**；它只影响车队学习与审计披露。因此"加噪"不直接降低本地安全下限。

**定义 237（隐私诱发不可观测性与 MNAR）** 记 `privacy_unobservable(m_t)` 为某模态因隐私策略本地不可用。缺失掩码 `m_t` 的分布依赖潜在场景 `s` 与故障 `H`：

`p(ρ_obs, m | H) = ∫ p(ρ_obs | ρ_mis, H) p(ρ_mis | H) p(m | s, H) dρ_mis ds`。

由于相机恰恰在可识别的私人场景被关闭，`p(m|H)` 与 `H` 通常相关，故缺失是 **MNAR**。朴素地只用 `p(ρ_obs|H)` 做边缘化，会得到有偏后验。缓解：(i) 显式建模 `p(m|H)`（把隐私门控当作一个已知的"观测策略"）；(ii) 用重要性比重 `w = p(m|s,H)/p(m)` 做敏感性界；(iii) 只在不改变归因结论的稳健区域内使用缺失样本。硬规则：**`privacy_unobservable ⇒` 不得把缺失当作否定几何/否定接触的证据**，只能降低置信度并触发 MSA。

**定义 238（PACT-FIR 假设集与缺失感知归因）** 扩展假设集

`ℋ_P = {H0, H_geo, H_force, H_model, H_vis, H_policy, H_torque, H_priv, H_act}`，

其中 `H_torque` 为关节力矩偏置/动力学模型错（摩擦、负载、柔性、磨损），`H_priv` 为缺失由隐私门控造成（**非故障**），`H_act` 为饱和/驱动故障。后验

`P(H | ρ_obs, m) ∝ p(ρ_obs, m | H) P(H)`。

定向处置：

- `H_geo`：`r_geo↑`，且仅在 VCV 观测到接触斑/法向确实不符时允许（否则降权）。
- `H_force`：`r_force↑` + 零力窗重标定，不动几何。
- `H_model`：`r_model↑` + 切柔顺。
- `H_vis`：`w_vis↓`，VCV 降权，退回 F/T+JTR。
- `H_policy`：`H↓, k↓`，强制重规划。
- `H_torque`：`r_tau↑`，触发空载/自由空间辨识（`torque_probe` 或慢速正弦激励）；若 `J_c` 零空间过大，标注 `torque_unobservable`。
- `H_priv`：不膨胀任何物理球，只置 `privacy_unobservable` 并进入 MSA。
- `H_act`：不进规划，TSE 立即限幅 + 柔顺/制动。
- `ambiguous`（`max_H P(H|ρ_obs,m) < 1−δ_fi`）：不强行归因；走 MSA + 只膨胀 `r_priv`；安全仍由 TSE 兜底。

**定义 239（隐私-可辨识性前沿）** 只保留可观测证据 `ρ_obs`，令 `S_obs` 为对应签名子矩阵，`Σ_ρ(ε,m) = Σ_0 + diag(σ²(ε))` 为加入 DP 噪声与缺失后的证据协方差。可辨识裕度

`κ_fi(ε,m) = λ_min(S_obs^T Σ_ρ^{-1} S_obs) / λ_max(S_obs^T Σ_ρ^{-1} S_obs)`。

性质：`κ_fi` 对 `ε` 单调不减（噪声方差随 `ε` 减小），对缺失模态数单调不增（可观测行减少）。存在阈值 `ε_min` 与 `κ_min` 使 `κ_fi < κ_min` 时任何归因器正确率不优于随机（信息不足）。此时唯一合法策略是**不变式路径 + 保守降级**。这给出可量化的"隐私-可辨识性前沿"：隐私预算不只影响准确率，还决定"归因是否还有意义"。

**定义 240（隐私预算分配 PBA）** 设模态集合 `M`，释放预算 `ε_m ≥ 0`，诊断/学习效用 `U_m(ε_m)`（按泄露风险 `L_m` 折价），求解

`max Σ_m U_m(ε_m)  s.t. Σ_m ε_m ≤ ε_total, ε_m ≥ 0`。

`U_m` 凹时用注水法；次模时用贪心得 `(1−1/e)` 近似。PBA **只决定外发/车队学习/审计披露**；预算耗尽时停止外发与学习更新，但**不触发安全降级**，TSE 与本地归因继续使用原始数据。这样"隐私预算耗尽"从安全事件降级为"学习/审计暂停"事件。

**定义 241（模态替代 MSA）** 给定本地可用集 `a_t`，定义替代映射 `σ_subst`，把依赖被禁模态的推断替换为不需要该模态的保守推断：

- 视觉被禁：`VCV` 失效，由 `JTR + 末端 F/T + TSE` 主导；接触搜索从"视觉落点"退化为"力矩可观测椭球内的保守接触集"。
- 深度/点云被禁：接近段限速到力矩可检测速度；几何球按 `r_priv` 保守膨胀（**不是 `r_geo`**）。
- 末端 F/T 被禁：JTR 主导 + 更小 `f_max`。

替代后的可观测性、性能折损与新增保守量写进证书；**禁止用替代后的缺失去否定几何先验**。

**定义 242（RSC-P 隐私感知球校准）** 维护 `r_geo, r_force, r_model, r_tau, r_priv`，融合

`r = √(r_geo² + r_force² + r_model² + r_tau² + r_priv²)`。

规则：`H_geo→r_geo↑`；`H_force→r_force↑`；`H_model→r_model↑`；`H_torque→r_tau↑`；`H_priv`/门控/`ambiguous`→`r_priv↑`；`H_act→` 不进规划、TSE 降级。与 VISTA 的 RSC-V 相比，新增两个正交方向：`r_tau`（力矩模型可信度）与 `r_priv`（隐私导致的不可观测）。这一拆分的核心是：**"我们选择不看"与"几何是错的"必须落在不同的球上**；否则隐私策略会伪装成几何故障，正是 VISTA 式误归因的隐私版本。

**定义 243（WCV-P 与 CSP-P）** 搜索域

`B(φ̂,r) ∩ 𝒢(g) ∩ K(μ̂) ∩ ℱ(f_lim) ∩ 𝒱 ∩ T_safe ∩ O(π_priv)`。

若隐私使交集为空或过度保守，退化为**力矩限幅柔顺模式**（降低 `τ^max`、切低刚度、限速），而不是无限膨胀几何球。CSP-P 在块级 A* 上要求每条块边 `Safe(J_pact)` 且存在 TSE 可行解；可插入元技能：

- `torque_probe`：在无相机条件下做安全力矩激励（慢速正弦/微小脉冲），辨识接触与动力学，降低 `r_tau`；
- `privacy_blackout`：进入隐私禁区时的降级执行模式（TSE + JTR + 限速 + 柔顺）；
- `null_test` / `visual_probe` / `fi_probe`：沿用 VISTA，但受 `a_t` 与 `ε` 约束。

**定义 244（DP 故障库与安全聚合 DFL）** 车队以联邦方式估计各假设下的签名似然 `p(ρ|H)`：各机器人本地更新，梯度/统计量经**安全聚合**（服务器只见和，不见单机）并加 DP 噪声（`ε_lib` 账本）；单机数据不可被反推。支持**认证遗忘**：用 SISA/牛顿更新等可验证遗忘机制提供 `unlearn_ver`，并记录 `dp_provenance`（机制、ε、δ、数据来源哈希）。FIR 的先验必须携带 DP 来源与预算；禁止使用未核算来源的"免费"先验。注意：车队 DP 只影响先验质量，**不影响本地 TSE**。

**定义 245（零知识/选择性披露审计 ZKA）** 对证书与证据摘要做 `C = Commit(J_pact, digest, salt)`。在块边界生成零知识证明，证明：

1. 执行前缀的每个控制周期满足 `T_safe`（力矩/力/刚度/能量约束）；
2. DP 核算满足 `Σ ε_m ≤ ε_total` 且机制正确（`dp_provenance` 一致）；
3. `J_pact` 的公开字段满足 `Safe`/`Rich` 规则；
4. 若声明删除，`unlearn_ver` 与摘要链一致。

验证者只学到"有效 + 公开元数据"，不学原始证据；同时隐藏技能参数与故障库（操作者 IP）。**ZK 证明的是"计算与约束被正确执行"，不是"传感器物理为真"**；因此它不能替代 JTR/TSE 的物理假设，只能替代"审计必须看原始数据"。

**定义 246（隐私对抗威胁模型 AIC-P）** 干扰集

`ℰ_P = ℰ_V × ℰ_priv × ℰ_tau`，

`ℰ_priv` 含成员推断（从梯度和/或证书反推单机数据）、隐私预算耗尽 DoS（用大量合法请求耗尽 `ε_total`，迫使停止学习/审计）、用类 DP 噪声掩盖真实故障（让 `r_τ`/视觉残差看起来"只是隐私噪声"）、把机器人诱入相机禁区的策略利用；`ℰ_tau` 含力矩传感欺骗、负载突变造成的模型失配、关节饱和。认证要求：

- 即使全部隐私攻击成功，`TSE + 硬件力矩限幅` 仍成立（最坏情况安全）；
- 若力矩通道被攻破，判 `H_torque` 并退到硬件/机械限位 + 安全停，不允许"用归因修复物理层故障"；
- `ρ_dir` 在 `ℰ_P` 上重算（`n_cert 128→160`，其中 32 给隐私/力矩对抗）；`J_pact` 增 `aic_p_ver`。

**定义 247（PACT 证书 J_pact 与双路径有效性）** 定义

`J_pact = (J_vista, jtr_obs, tau_margin, energy_tank, privacy_policy_hash, privacy_budget_used, privacy_unobservable, dp_provenance, zk_audit, unlearn_ver, aic_p_ver)`。

其中 `jtr_obs` 记录可观测椭球的秩/条件数与 `torque_unobservable` 标注，`tau_margin` 为最坏方向力矩裕度，`energy_tank` 为块末能量水平。双路径有效性：

- `Safe(J_pact) ⇔` TSE 不变式已验证 ∧ 硬件限幅在位 ∧ 隐私核算一致 ∧（`privacy_unobservable ⇒` 未把缺失当阴性证据）。
- `Rich(J_pact) ⇔ Safe(J_pact) ∧ Valid(J_vista) ∧ κ_fi(ε,m) ≥ κ_min ∧` 未引用不可用模态的结论。

执行规则：**任何动作只需 `Safe`；凡使用归因、几何细分、主动探针结论者需 `Rich`。** 当隐私门控使 `Rich` 失效时，系统自动退到 `Safe` 下的保守/柔顺执行，而不是伪造归因。审计链新增：为何可用归因（`jtr_obs/κ_fi`）、为何此刻安全（`tau_margin/energy_tank`）、隐私花了多少（`privacy_budget_used`）、有没有看过（`privacy_unobservable`）。

**定义 248（PACT 闭环算子）** 语义流：

`[LiDAR→LSF→USR/MEL→VPG/ACH→阶段切分→PACT-FIR（缺失感知）→RSC-P→WCV-P/CSP-P→CSC→TSE 可行域校验→ZKA→DFL→AIC-P]`；

实时流：

`[JTR 残差→阶段判定→TSE 1kHz QP→安全前缀派发→能量罐更新→硬件限幅→早停]`。

不变式：实时流零学习写操作、不依赖任何外发/DP 数据；语义流可被隐私门控降级，但**不得把门控缺失写入物理故障球**。

### IP-224 JTR（关节力矩残差与可观测性）

```python
class JointTorqueResidual:
    """第三物理通道：不同传感器、不同模型误差，与视觉/F-T 失效模式独立。"""
    def __init__(self, dyn, sigma_tau, b_model_bound):
        self.dyn, self.Sigma, self.b_bound = dyn, sigma_tau, b_model_bound

    def residual(self, q, qdot, qddot, tau_meas, tau_fric):
        tau_model = self.dyn.M(q) @ qddot + self.dyn.C(q, qdot) @ qdot \
                    + self.dyn.g(q) + tau_fric
        return tau_meas - tau_model            # = Jc^T w + b_model + nu

    def solve(self, r, Jc, Sigma=None):
        Sigma = Sigma or self.Sigma
        S_inv = np.linalg.inv(Sigma)
        A = Jc.T @ S_inv @ Jc                   # 可观测 Gram
        rank = np.linalg.matrix_rank(A, tol=1e-6)
        if rank == 0:
            return None, {'observable': False, 'rank': 0,
                          'reason': 'contact_wrench_in_nullspace'}
        # 只在可观测子空间求伪逆，零空间方向显式标记不可辨识
        w_hat = np.linalg.pinv(A) @ Jc.T @ S_inv @ r
        eig = np.linalg.eigvalsh(A)
        eps = self.b_bound / max(np.sqrt(max(eig[-1], 1e-12)), 1e-9)
        return w_hat, {'observable': True, 'rank': int(rank),
                       'cond': float(eig[-1] / max(eig[0], 1e-12)),
                       'err_bound': float(eps)}
```

### IP-225 TSE（力矩安全包络与能量罐）

```python
class TorqueSafetyEnvelope:
    """执行器级硬地板：与上层归因/世界模型完全解耦。"""
    def __init__(self, tau_max, dtau_max, f_max, K_max, E_max, dt):
        self.tau_max, self.dtau_max = tau_max, dtau_max
        self.f_max, self.K_max = f_max, K_max
        self.E_max, self.dt = E_max, dt

    def qp_project(self, tau_ref, q, qdot, phi, Jc, E_tank, tau_prev):
        # 小维 QP：min ||tau - tau_ref||^2  s.t. T_safe
        cons = [
            ('box', -self.tau_max, self.tau_max),
            ('rate', tau_prev - self.dtau_max, tau_prev + self.dtau_max),
            # 接触力/表观刚度（线性化后为二阶锥/线性约束）
            ('force', lambda tau: contact_force(tau, Jc, q)),
            ('stiff', lambda tau: apparent_stiffness(tau, q, phi)),
        ]
        tau_safe = solve_small_qp(tau_ref, cons)          # 主动集/ADMM
        # 能量罐：只接受使 E>=0 的命令；否则投影到边界（被动）
        E_next = E_tank + self.dt * float(tau_safe @ qdot) - self.dt * P_out
        if E_next < 0:
            tau_safe = scale_toward_zero(tau_safe, E_tank / max(-E_next, 1e-9))
            E_next = 0.0
        return tau_safe, float(np.clip(E_next, 0.0, self.E_max))
```

class PACTFaultIsolation:
    HYP = ('H0', 'H_geo', 'H_force', 'H_model',
           'H_vis', 'H_policy', 'H_torque', 'H_priv', 'H_act')

    def __init__(self, lik, mnar, prior=None, delta_fi=0.15):
        self.lik, self.mnar = lik, mnar          # p(rho_obs, m | H)
        self.prior = prior or {h: 1.0 / len(self.HYP) for h in self.HYP}
        self.delta_fi = delta_fi

    def attribute(self, rho_obs, mask):
        logp = {h: np.log(self.lik[h](rho_obs, mask) + 1e-12)
                   + np.log(self.prior[h]) for h in self.HYP}
        post = softmax(logp)
        h_star = max(post, key=post.get)
        ambiguous = post[h_star] < 1.0 - self.delta_fi
        observable = mask.any() and self.mnar.kappa_fi(mask) >= KAPPA_MIN
        return post, h_star, ambiguous, observable

    def directed_demote(self, h_star, balls, H, m):
        if h_star == 'H_geo':
            balls['r_geo'] = inflate(balls['r_geo'])
        elif h_star == 'H_force':
            balls['r_force'] = inflate(balls['r_force'])
        elif h_star == 'H_model':
            balls['r_model'] = inflate(balls['r_model'])
        elif h_star == 'H_torque':
            balls['r_tau'] = inflate(balls['r_tau'])
            request_torque_identification()       # torque_probe / 空载辨识
        elif h_star == 'H_priv':
            balls['r_priv'] = inflate(balls['r_priv'])   # 不动物理球！
            mark_privacy_unobservable(m)
        elif h_star == 'H_act':
            raise TorqueEnvelopeFallback()        # 交给 TSE，不走规划
        elif h_star == 'H_policy':
            H = max(H_MIN, H // 2)
        return balls, H

## 4. 推导

**引理 9（JTR 的独立性与可观测性）** 在刚体动力学与有界模型误差 `‖b_model‖ ≤ b̄` 下，`r_τ = J_c^T w_c + b_model + ν_τ`。设 `J_c` 在接触旋量子空间行满秩，`σ_min(J_c)` 为最小奇异值，则 WLS 估计满足

`‖ŵ_c − w_c‖ ≤ b̄/σ_min(J_c) + ‖(J_c Σ_τ^{-1} J_c^T)^{-1} J_c Σ_τ^{-1} ν_τ‖`。

零空间 `ker(J_c^T)` 方向不可辨识；多接触时需稀疏/激励消歧。JTR 与视觉、末端 F/T 的失效模式条件独立（不同传感器、不同模型误差），故在视觉与末端 F/T 被同一对抗源同时欺骗时，JTR 仍能提供接触存在性/定位证据（除非 `b_model` 同时漂移，见 A94）。这直接补上 VISTA 的"共因失效"缺口，但把"力矩通道 + 动力学模型"变成新的单点假设。∎

**引理 10（隐私对可辨识性的侵蚀与 MNAR 偏差）** 由于 `Σ_ρ(ε,m)=Σ_0+diag(σ²(ε))`，`σ²(ε)` 随 `ε` 减小而减小，故 `S_obs^T Σ_ρ^{-1} S_obs` 在 Loewner 序下随 `ε` 增大而增大，`κ_fi(ε,m)` 对 `ε` 单调不减；缺失模态删除 `S` 的行，`κ_fi` 对缺失数单调不增。当 `κ_fi < κ_min` 时，签名对故障幅度 `θ` 的 Fisher 信息不足，由 Le Cam 下界，任何归因器的最坏情况错误率 `≥ (1 − √(κ_fi/κ_min))/2`，即不优于随机。MNAR 下，朴素后验 `q_naive(H) ∝ p(ρ_obs|H)P(H)` 与真实后验 `p(H|ρ_obs,m)` 的 TV 距离满足

`TV(q_naive, p) ≤ (1/2) E[|w(m) − 1|]`，`w(m)=p(m|s,H)/p(m)`，

故当门控与故障强相关时朴素法有系统偏差；显式建模 `p(m|H)` 或做敏感性界可消除主导项。∎

**引理 11（TSE 的能量罐不变式与接触能量界）** 令 `E_t ≥ 0`，`τ_t ∈ T_safe`，则

`E_{t+1} = clip(E_t + Δt τ_t^T q̇_t − Δt P_out, 0, E_max) ≥ 0`。

定义机器人-环境交互能量 `W_int = ∫(−τ^T q̇) dt`（取流出机器人为正）。由能量罐构造，`W_int ≤ E_0 + Σ_t Δt(τ_t^T q̇_t)^+ − Σ P_out ≤ E_0 + Σ补给`。又 `T_safe` 强制 `‖Λ_c J_c^{-T} τ‖ ≤ f_max` 与 `K_app ≤ K_max`，故接触力与表观刚度有硬界。该界不依赖上层策略、世界模型或 `P(H|ρ)`，只依赖力矩测量/执行与能量罐实现；因此即使 VISTA 式归因完全错误，伤害仍被界住。∎

**定理 9（PACT 双路径端到端安全）** 在 A94–A99（力矩/本体本地可用且可信、动力学误差有界、硬件限幅在位、DP 机制与承诺/证明正确）下：

1. **硬地板**：任意上层命令（含错误归因、未知复合故障、隐私门控缺失、对抗策略）经 TSE 后满足 `W_int ≤ E_0 + Σ补给`、`f ≤ f_max`、`K_app ≤ K_max`（引理 11）。故 `Safe(J_pact)` 足以保证物理安全下限。
2. **归因是增强而非前提**：`Rich(J_pact)` 时归因正确则只膨胀正确的球（RSC-P），几何不被错误降级；归因失效或 `κ_fi<κ_min` 时自动退到 MSA + `r_priv↑`，`Safe` 仍成立。
3. **隐私不制造故障**：`privacy_unobservable` 只降低可观测性，不进入几何/力/模型球；MNAR 偏差由显式 `p(m|H)` 或敏感性界控制（引理 10）。故隐私门控不会把"没看"变成"看错"。
4. **打破共因**：视觉与末端 F/T 共因失效时，JTR 提供独立证据（引理 9），归因不再被迫在"几何 vs 力"间二选一；但若 `b_model` 同时漂移，JTR 可被判 `H_torque` 并触发辨识。
5. **隐私攻击不越地板**：成员推断/预算耗尽只影响外发与学习；噪声掩盖若使归因退化，只损失 `Rich`；力矩欺骗被判 `H_torque` 并退硬件限幅/安全停（AIC-P）。
6. **可审计而不泄露**：`zk_audit` 证明 TSE/DP/证书规则被正确执行，验证者不获原始证据；`unlearn_ver` 支持遗忘（命题 4）。
7. **实时性**：TSE/JTR 全在实时流，`≤2.5ms`，零学习写操作。∎

**定理 10（隐私-安全前沿的对齐与分离）** 在 A94 下，TSE 只使用本地力矩/本体与几何硬约束，不使用任何 `ε` 相关的外发数据；因此**硬地板对 `ε` 与门控不变**（引理 11）。另一方面，归因效用由 `κ_fi(ε,m)` 决定（引理 10），对 `ε` 单调不增、对门控单调不增。于是隐私-安全前沿在"地板"维度是平的、只在"诊断/性能"维度下降：

`SafetyFloor(ε) = const`，`Diagnosis(ε) ↓`，`∂Safety/∂ε ≈ 0`（在地板意义下）。

存在 `ε_min`，其下 `κ_fi<κ_min`，最优策略退化为"纯不变式 + 保守柔顺"。这给出反直觉但可证伪的结论：**合理的隐私约束不会降低安全下限，只会降低故障被命名/预测的速度**；把安全放在低维不变式上，使隐私与安全从对立转为部分对齐。该结论的边界正是 A94：若隐私制度连力矩/本体本地使用都禁止，或力矩模型无法维护，则地板不再可信，定理失效。∎

**命题 4（审计不泄露与可遗忘）** 承诺 `C` 隐藏 `digest`（计算隐藏性），零知识证明只泄露"约束成立"与公开元数据（零知识性），可靠性保证伪造证明不可通过（可靠性）。DP 故障库给出成员推断的 `(ε,δ)` 上界；认证遗忘保证被删样本对发布模型的影响被 `unlearn_ver` 界住。注意：ZK 证明的是"计算与约束被正确执行"，**不是**"传感器物理为真"；它不能替代 A94，只能替代"审计必须看原始数据"。∎

**命题 5（归因降低过度保守的隐私版）** VISTA 在视觉不可观测时容易把"看不见"当"几何可疑"，膨胀 `r_geo`。PACT 在 `H_priv`/门控时只膨胀 `r_priv`，`r_geo` 不变；若真实情况是隐私门控而非几何错误，几何搜索域体积仅为 VISTA 式的 `1/κ_infl^{d_φ}`（几何分量），避免"因隐私而误降级几何"。∎

## 7. 已知风险

**一句话**：PACT 把安全从"推断"下沉到"力矩/能量不变式"，但这条硬地板只在**关节力矩传感可信、刚体动力学模型足够准、且力矩/本体感觉在隐私制度下仍被允许本地使用**时成立——一旦力矩传感被偏移/欺骗、摩擦/负载/柔性/磨损让 `b_model` 漂出界、或隐私制度连维持模型所需的本地本体数据都限制留存，硬地板就只是"名义上的"，而架构又因"我们有不依赖观测的硬地板"而更自信地继续执行，**隐私恰好成为掩盖地板静默退化的最佳掩护，安全会在隐私最强的场景里悄悄归零**（对应隐藏假设 A94）。

**次级风险与缓解**：

1. **力矩通道成为新单点**：JTR/TSE 依赖力矩传感与动力学模型；缓解：双套力矩传感/电流冗余、硬件力矩限幅与机械限位作为最后防线、定期空载辨识、`H_torque` 显式建模与退化到安全停。
2. **动力学模型漂移**：负载、摩擦、柔性、磨损使 `b_model` 时变；缓解：在线辨识只在安全激励下进行、`r_tau` 只用于保守方向、误差界进入 `T_safe`（按 `b̄` 收紧 `f_max`）。
3. **可观测性为零空间**：某些接触方向在 `J_c^T` 零空间；缓解：显式 `torque_unobservable`、`torque_probe` 激励、多姿态冗余、绝不在零空间方向归因。
4. **MNAR 偏差**：隐私门控与场景/故障相关；缓解：显式 `p(m|H)`、敏感性界、只在稳健区域使用缺失样本。
5. **隐私预算耗尽 DoS**：恶意请求耗尽 `ε_total`；缓解：本地安全不依赖 `ε`，耗尽只停外发/学习；对请求做速率限制与来源认证。
6. **"类 DP 噪声"掩盖真实故障**：攻击者注入与机制同分布的噪声；缓解：机制随机数本地秘密保存并做承诺（不泄露值）、多通道一致性、CUSUM 漂移检测、`H_torque` 与 `H_priv` 的似然区分。
7. **ZK 证明的语义边界**：证明"计算正确"不等于"传感器为真"；缓解：证书显式声明信任边界、硬件根信任/安全启动、`aic_p_ver` 版本绑定；不把 ZK 当作物理安全证明。
8. **DP 先验质量下降**：车队 `ε_lib` 太小使 `p(ρ|H)` 不准，误判 `H_policy/H_vis`；缓解：本地先验优先、DP 先验只作弱正则、报告先验来源与预算。
9. **TSE 过度保守**：能量/力/刚度约束可能使任务变慢或不可达；缓解：分层约束（安全关键通道严格、非关键通道放宽）、任务级能量预算重分配、与 CSP-P 联合规划。
10. **遗忘与审计冲突**：删除原始数据后无法复现历史故障；缓解：只保留不可逆摘要与 ZK 证明、删除前先把必要证据转为统计量、接受"可审计但不可复现原始数据"的边界。
11. **实时预算**：TSE QP 与小维求解在低端控制器上可能超时；缓解：主动集热启动、固定迭代 ADMM、约束预编译、把非实时部分全部移到语义流。
12. **隐私与安全的语义混淆**：把"隐私门控"误报为故障，或把"故障"误判为"隐私噪声"；缓解：`H_priv` 与 `H_torque` 双假设、机制参数承诺、缺失掩码显式入似然、审计链记录 `privacy_unobservable`。
