# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「意图理解」×「嵌入式系统」）

> 第 54 轮已经用 `J=(ρ,A_cert,γ_ce,δ_a)` 回答“这个技能组合能不能在动作空间里被执行”。本轮引入两个互补视角：**意图理解**追问“它是不是用户真正想要的那件事”，**嵌入式系统**追问“这份证书能不能在真实端侧的资源与时限内被验证”。核心矛盾：**H22：联合证书 `J` 只证明可执行性，不证明意图一致性；意图本身是欠定的开放集合，点估计式理解会把“像是对的”当成“就是对的”；H23：意图推断与证书校验都默认云端算力，而部署终点是 WCET/内存/能耗/抖动都硬受限的 MCU/RTOS，一份来不及在截止期内被检查的证书等于没有证书。**

## 0. 直觉与动机

**灵感 1（意图是约束区域，不是任务标签）**
直觉：用户说“把杯子拿过来”，真正的意图不是一个字符串，而是动作序列空间里的一个**受约束区域**：硬约束（不能碰倒花瓶、必须用右手避开烫的表面）+ 软偏好（尽量快、别洒水）+ 不确定性（哪个杯子）。把意图建模为 `I=(A_T^hard, w_pref, c_I)`，技能组合不仅要覆盖任务动作 `A_T`，还必须**落在意图硬约束区内**。这把第 54 轮的动作覆盖 `cover(S,A_T)` 扩展为**意图覆盖** `icover(P,I)`：动作可达但意图越界的计划，判为不可部署。

**灵感 2（意图理解必须 anytime + 校准，端侧期限强制“提前下注”）**
直觉：嵌入式端不可能无限推理，推断是**anytime**的：随算力增加逐步细化，但 RTOS 在 `τ_commit` 必须交出结果。正确形态不是最可能的单点意图，而是**可信意图集合** `Î_δ`（满足 `P(I*∈Î_δ)≥1-δ` 的 conformal/credible set）。最大危险是**意图幻觉**：模型给出高置信单点 `Ĩ`，而真意图 `I*∉Ĩ`。因此提交规则必须“集合化 + 校准 + 置信地板”，宁可带着一个小集合进入保守规划，也不拿一个自信的错点去执行。

**灵感 3（嵌入式可行性是一等维度，不是部署细节）**
直觉：第 54 轮的 `J` 在云端成立，但端侧要跑意图推断、证书校验、控制回路三件事，共享一个 CPU。引入**嵌入式可行性剖面** `ε_S=(WCET,ROM,RAM,E,jitter)` 与预算 `B_e`，部署前提变为 `dom(J)=in ∧ ε_{S⊕M}⊑B_e`。WCET 不是平均延迟，而是**最坏执行时间**；缓存、中断、DMA 抖动都可能让“理论上可校验”变成“实际上超时”。这把实时系统分析直接接进证书体系。

**灵感 4（证书压缩为运行时监控器：可携带证明的意图）**
直觉：端侧 ROM/RAM 放不下完整 `J`，也没时间重算。把 `J` 编译成一个**确定性监控自动机** `M_J`（watchdog + 有限状态约束检查）加一个承诺哈希 `h_J`（`J` 的 Merkle 根），形成 `J_emb=(M_J,h_J,δ_c)`。`M_J` 在动作轨迹上在线检查硬约束、`A_core`、`δ_a`，复杂度有界 `WCET(M_J)≤τ_M`；离端时再用 `h_J` 展开完整证书。若抽象损失记为 `δ_c`，则监控器是**对违规 sound、对小于 δ_c 的违规近似完备**——这正是 proof-carrying code 与运行时验证在端侧的合体。

**灵感 5（意图漂移 → 实时重协商协议，安全停车永远可调度）**
直觉：真实交互中意图会中途改变（用户改口、指了另一个物体）。需要**意图修订协议**：检测 `drift_I=d(I_t,I_{t-1})>θ_I` 时触发重规划，`τ_rev` 内完成；在重规划未收敛期间，执行器只能走**当前可信意图集内**的动作。**安全停车（safe-stop）必须是最高临界级且永远可调度**，这样最坏情况是“停下来等”，而不是“自信地做错”。

**灵感 6（跨域同构：意图理解 ≈ 规格推断，嵌入式 ≈ 资源有界实时验证）**
直觉：意图理解本质上是从少量、含噪、多模态观察中**推断规格**（spec inference）；嵌入式系统本质上是**在资源与时限内做可判定验证**。二者交汇处正是本轮的核心对象：**可携带意图证明（proof-carrying intent）**——云端把意图规格与 `J` 编译成端侧可校验的小监控器，端侧用有界资源在截止期内证明“当前动作轨迹仍在该意图的硬约束内”，否则触发修订或安全停车。混合临界级（mixed-criticality）让硬意图享有更紧的 WCET 预算，软偏好在资源紧张时可被降级丢弃。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（意图区域与意图证书）**
意图区域 `I = (A_T^hard, w_pref, c_I, amb)`：`A_T^hard ⊆ (A_e)^*` 为动作序列的**硬约束集**（安全/语义不可违），`w_pref` 为软偏好权重，`c_I∈[0,1]` 为校准置信，`amb` 为歧义描述子。意图证书
```
J_I = (I, evidence, calib, prov)
```
`evidence` 为多模态观察与反事实样例，`calib` 为校准曲线/覆盖率凭证，`prov` 为来源证明。`dom(J_I)=in` 当且仅当 `A_T^hard≠∅`、`calib.coverage ≥ 1-β_I`、`prov.verify()=1`。**意图覆盖**
```
icover(P, I) = 1  ⇔  ∀ seq∈traces(P): seq∈A_T^hard
                     ∧ E_{seq∼P}[1(seq∈A_T^hard)] ≥ 1-β_I
```

**定义 128（AnyTime 嵌入式意图推断剖面）**
推断器 `π_I` 的资源剖面 `(acc(t), WCET_π, RAM_π, E_π)`：在任意时刻 `t` 可给出当前精度 `acc(t)`；在提交期限 `τ_commit` 输出**可信意图集**
```
Î_δ = { I' | score(I'|o) ≥ q_δ }，   P(I* ∈ Î_δ) ≥ 1-δ
```
`q_δ` 由 conformal/温度校准确定。**意图幻觉**定义为 `|Î_δ|=1 ∧ I*∉Î_δ`；提交规则要求 `|Î_δ|≥1`、`calib` 通过、且在 `τ_commit` 前完成，否则进入保守集合或安全停车。

**定义 129（嵌入式可行性剖面，含混合临界级）**
技能与监控器合并的剖面
```
ε_{S⊕M} = (WCET_HI, WCET_LO, ROM, RAM, E, jitter)
```
预算 `B_e=(WCET_HI^B, WCET_LO^B, ROM^B, RAM^B, E^B, jitter^B)`。**可行** `ε⊑B_e` 当且仅当每个分量（含安全裕度 `m_e`）满足上界；高临界级（硬意图/安全停车）只计入 `WCET_HI` 且不得被低临界任务抢占，低临界偏好可在超预算时被丢弃（criticality masking）。

**定义 130（证书压缩与运行时监控器）**
压缩算子 `κ_c: J ↦ J_emb=(M_J, h_J, δ_c, τ_M)`：
- `M_J` 为确定性有限监控自动机，输入动作轨迹前缀，输出 `accept/reject`；
- `h_J = MerkleRoot(canon(J))` 为完整证书承诺，供离端展开校验；
- `δ_c` 为抽象验证间隙，`τ_M` 为监控器最坏检查时延。
**监控器 sound**：`M_J(tr)=reject ⇒ tr ⊭ J`；**近似完备**：若 `dist(tr, J)>δ_c` 则 `M_J` 在 `τ_M` 内 reject。校验损失 `L(J_emb) ≤ δ_c`。

**定义 131（意图修订协议）**
修订算子 `rev(P_t, o_t, I_t) ↦ (P_{t+1}, I_{t+1}, stop)`，满足：
1. **安全单调**：`P_{t+1}` 的每个即时动作 `a` 满足 `a∈proj_1(A_{T,t+1}^hard)`，或 `stop=safe`；
2. **时限**：`latency(rev) ≤ τ_rev`；
3. **漂移触发**：`drift_I = d(I_t, I_{t-1}) > θ_I` 或监控器 reject 时必触发；
4. **安全停车可调度**：`ε_{stop} ⊑ B_e^{HI}` 且 `WCET(stop) ≤ τ_stop`。

**定义 132（意图-嵌入式联合证书）**
```
J_IE = (J, J_I, ε, J_emb, rev, prov_IE)
```
部署判定为六项合取：
```
dom(J_IE)=in ⇔ dom(J)=in                               # 动作-鲁棒性可行
             ∧ icover(P, I) ∧ dom(J_I)=in               # 意图一致且校准
             ∧ ε_{S⊕M} ⊑ B_e                            # 嵌入式资源/时限可行
             ∧ L(J_emb) ≤ δ_c^budget ∧ M_J sound        # 端侧可校验且有界
             ∧ rev 满足时限与安全单调                    # 意图可变时仍安全
             ∧ prov_IE.verify()=1                       # 意图来源不可伪造
```

## 2. 关键算法 伪代码

### IP-127 ICR（Intent Constraint Region）

```python
def intent_region(observations, intent_model, beta_I):
    hard = intent_model.hard_constraints(observations)      # LTL/automaton
    pref = intent_model.soft_weights(observations)
    cand = intent_model.sample(observations, n=N_CAND)
    covered = conformal_quantile([score(c, observations) for c in cand], beta_I)
    credible = {c for c in cand if score(c, observations) >= covered}
    if not hard.is_consistent() or calibration_error(intent_model) > beta_I:
        return ('reject', 'intent_underspecified')
    return ('ok', IntentRegion(hard, pref, credible, beta_I))

def intent_cover(P, I, beta_I):
    return all(seq in I.hard for seq in traces(P)) and \
           empirical_cover(P, I.credible) >= 1 - beta_I
```

### IP-128 AEI（Anytime Embedded Intent Inference）

```python
def infer_anytime(o, model, tau_commit, delta, ram_budget):
    t0 = now(); parts = []
    while now() - t0 < tau_commit and mem_ok(model, ram_budget):
        parts = model.refine(o, deadline=tau_commit)         # incremental
        if model.confidence(parts) >= CONF_FLOOR: break
    S = model.credible_set(parts, delta)                     # conformal
    if not S or model.wcet_exceeded(tau_commit) or calibration_fail(model):
        return ('safe_stop', 'intent_uncommittable')
    return ('ok', IntentRegion.from_set(S, model.hard(o)), model.anytime_stats())
```

### IP-129 EFP（Embedded Feasibility Profile）

```python
def embedded_feasible(skill, monitor, B_e, criticality='hi'):
    prof = wcet_analyze(skill, monitor, interrupts=True, caches=True)
    prof += {k: jitter_upper(skill, monitor, k) for k in JITTER_DIMS}
    masked = apply_criticality_mask(prof, criticality, B_e)
    return all(masked[k] + MARGIN[k] <= B_e[k] for k in masked)
```

### IP-130 CCM（Certificate Compression / Monitor Synthesis）

```python
def compress_certificate(J, max_states, tau_M):
    spec = conj(J.hard_constraints, J.A_core, J.delta_a_bound)
    M, gap = automaton_synth(spec, max_states=max_states)     # abstraction
    assert monitor_sound(M, spec)                            # no false accept
    if wcet(M) > tau_M or gap > DELTA_C_BUDGET:
        return ('reject', 'monitor_infeasible', wcet(M), gap)
    h = merkle_root(canonical(J))
    return ('ok', JEmb(M, h, gap, tau_M))

def monitor_trace(tr, J_emb):
    s = J_emb.M.start
    for a in tr:
        s = J_emb.M.step(s, a)
        if s is REJECT:
            return ('reject', now())                         # sound
    return ('accept', now())
```

### IP-131 IRP（Intent Revision Protocol）

```python
def revise(P_t, o_t, I_t, J_emb, tau_rev):
    t0 = now()
    drift = intent_distance(I_t, I_t.prev)
    if drift <= theta_I and monitor_trace(trace(P_t), J_emb)[0] == 'accept':
        return ('ok', P_t, I_t)
    I_new = infer_anytime(o_t, model, tau_rev, delta, RAM_BUDGET)
    if I_new[0] != 'ok':
        return ('ok', safe_stop_plan(), None)                # always schedulable
    P_new = re_plan(P_t, I_new[1], deadline=tau_rev - (now()-t0))
    if P_new is None or now()-t0 > tau_rev:
        return ('ok', safe_stop_plan(), I_new[1])
    if not intent_cover(P_new, I_new[1], beta_I):
        return ('ok', safe_stop_plan(), I_new[1])
    return ('ok', P_new, I_new[1])
```

### IP-132 IEJ（Intent-Embedded Joint Certificate）

```python
def intent_embedded_certificate(J, I, eps, J_emb, rev, prov, B_e, delta_c):
    if J.status != 'ok':                 return ('reject','action_robust_invalid')
    if not intent_cover(J.plan, I):      return ('reject','intent_mismatch')
    if not J_I_valid(I):                 return ('reject','intent_uncertain')
    if not eps.subset(B_e):              return ('reject','embedded_overrun')
    if J_emb.gap > delta_c or not J_emb.sound: return ('reject','monitor_gap')
    if not rev.bounded_and_monotone():   return ('reject','revision_unsafe')
    if not prov.verify():                return ('reject','intent_provenance')
    return ('ok', JIE(J, I, eps, J_emb, rev, prov))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| ICR | O(N_CAND·|o| + |A_T^hard|) | O(N_CAND) | 硬约束一致、conformal 覆盖达标 |
| AEI | O(τ_commit·refine + |S|) | O(RAM_π) | anytime 单调、校准、期限可提交 |
| EFP | O(|S|·|π| + WCET 分析) | O(|ε|) | WCET sound、临界级掩码正确 |
| CCM | O(|spec|·2^{max_states}) | O(max_states) | 监控器 sound、间隙有界、τ_M 闭合 |
| IRP | O(τ_rev·(infer+replan)) | O(|P|) | 修订安全单调、safe-stop 可调度 |
| IEJ | O(|I|+|ε|+|M_J|) | O(|J_IE|) | 六项合取、证明可验 |

**正确性定理（Intent-Embedded Deployment Soundness）**
承接第 54 轮 (A22)–(A28)；新增假设：
**(A29)** 意图可信集已校准：`P(I*∈Î_δ) ≥ 1-δ_I`，且硬约束提取 sound；
**(A30)** 监控器 `M_J` 对违规 sound，且 `WCET(M_J) ≤ τ_M`；
**(A31)** 嵌入式 WCET/内存/能耗分析 sound：`ε_{S⊕M}⊑B_e ⇒ 实际不超预算` 的概率 `≥ 1-β_E`；
**(A32)** 修订协议在 `τ_rev` 内完成或转入可调度的安全停车，且动作始终在可信意图集内。

则对满足 `dom(J_IE)=in` 的部署：
```
P_success^IE ≥ 1 - Σ_d(1-ρ_min(d)) - P(δ_a>Θ_a) - P(compat<θ_a)
                 - δ_I - δ_c - β_E - P(rev_miss)
```
且最坏安全性（灾难性失败）被安全停车兜底：`P(catastrophic) ≤ P(stop_unschedulable)`。关键：**意图误差、压缩间隙、端侧超预算、修订超时是四个独立失败源，按 union bound 相加**；任一不可验证都应降级到“文本 + 原技能 + 安全停车”，绝不“带病部署”。

## 4. 实验设计 E167–E171

| 实验 | 指标 | 目标 |
|---|---|---|
| E167 意图可信集校准 | 实际覆盖率 vs `1-δ`、ECE | 覆盖率 ≥ 1-δ-0.02，ECE ≤ 0.03 |
| E168 anytime 推断端侧可行性 | P99 推断时延、RAM、能耗 | ≤ `τ_commit`，RAM ≤ 64KB，能耗 ≤ 预算 |

| E170 意图-嵌入联合部署成功率 | vs 意图无关基线 / 安全停车可用率 | 成功率 ↑ ≥ 12%，安全停车 100% 可调度 |
| E171 意图漂移修订 | 漂移检测时延、重规划成功率、越界动作数 | 时延 P95 ≤ `τ_rev`，越界动作 = 0 |

**消融**：去掉可信集（测意图幻觉）、去掉 WCET 分析（测端侧超时）、去掉监控器抽象间隙界（测假接受）、去掉安全停车（测最坏安全）、去掉意图硬约束（测动作可达但意图越界）。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 意图幻觉：高置信单点但真意图不在集合 | 高 | conformal 可信集 + 置信地板 + 拒提交 |
| 监控器抽象间隙过松导致假接受 | 高 | sound-by-construction + 间隙预算 + 反例回灌 |
| WCET 分析在缓存/中断/DMA 下不 sound | 高 | 多种 WCET 工具交叉 + 测量上界包络 + 裕度 |
| 意图推断抢占控制回路导致抖动 | 高 | 临界级隔离 + budget server + 安全停车优先 |
| 意图修订振荡/频繁改口 | 中 | hysteresis + 最小驻留时间 + 稳定集 |
| 多模态观察被欺骗/仿冒 | 中 | 来源证明 `prov` + 多通道一致性 + 物理可行性 |

## 6. 本轮最大风险

**一句话**：本轮把“意图理解”与“嵌入式系统”接入证书体系，最深的危险是**把开放的意图错当成一个点、又让端侧预算逼迫提前下注**——一个校准良好却仍可能漏掉真意图的可信集、加上一个“对违规 sound 但对小违规近似完备”的压缩监控器，再叠加不 sound 的 WCET 分析，三者在同一截止期内耦合，就可能把“执行得漂亮但不是用户要的、且超时到没来得及拦住”的计划认证为可部署；因此必须以 **可信集而非点估计、监控器间隙硬预算、WCET 交叉验证、以及永远可调度的安全停车** 作为四重底线，宁可停下来问，绝不自信地做错。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（ICR×AEI×EFP×CCM×IRP×IEJ）

> 承接第 54 轮产物 v31。本轮在动作-鲁棒性联合证书 `J` 之上，增加 **意图约束区域、anytime 校准推断、嵌入式可行性、证书压缩监控、意图修订、联合证书** 六个算子，把“可执行”升级为“**是用户要的、且在端侧时限内可被证明的**”：
> - **ICR（Intent Constraint Region）**：意图建模为动作序列的硬约束区 + 软偏好 + 可信集；
> - **AEI（Anytime Embedded Intent Inference）**：`τ_commit` 内输出校准可信意图集，杜绝意图幻觉；
> - **EFP（Embedded Feasibility Profile）**：`ε=(WCET,ROM,RAM,E,jitter)`，混合临界级资源预算；
> - **CCM（Certificate Compression / Monitor）**：`J ↦ J_emb=(M_J,h_J,δ_c,τ_M)`，端侧有界校验；
> - **IRP（Intent Revision Protocol）**：意图漂移触发的实时重协商，安全停车永远可调度；
> - **IEJ（Intent-Embedded Joint Certificate）**：`J_IE=(J,J_I,ε,J_emb,rev,prov)` 六项合取方可部署。
>

## 2. 关键算法 伪代码

### IP-127 ICR

```python
def intent_region(observations, intent_model, beta_I):
    hard = intent_model.hard_constraints(observations)       # LTL / DFA spec
    pref = intent_model.soft_weights(observations)
    cand = intent_model.sample(observations, n=N_CAND)
    q = conformal_quantile([score(c, observations) for c in cand], beta_I)
    credible = {c for c in cand if score(c, observations) >= q}
    if not hard.is_consistent() or calibration_error(intent_model) > beta_I:
        return ('reject', 'intent_underspecified')
    return ('ok', IntentRegion(hard, pref, credible, beta_I))

def intent_cover(P, I, beta_I):
    return all(seq in I.hard for seq in traces(P)) and \
           empirical_cover(P, I.credible) >= 1 - beta_I
```

### IP-128 AEI

```python
def infer_anytime(o, model, tau_commit, delta, ram_budget, conf_floor):
    t0 = now(); parts = model.init(o)
    while now() - t0 < tau_commit and mem_ok(model, ram_budget):
        parts = model.refine(o, deadline=tau_commit)
        if model.confidence(parts) >= conf_floor:
            break
    S = model.credible_set(parts, delta)                     # conformal
    if not S or model.wcet_exceeded(tau_commit) or calibration_fail(model):
        return ('safe_stop', 'intent_uncommittable')
    return ('ok', IntentRegion.from_set(S, model.hard(o)), model.anytime_stats())
```

### IP-129 EFP

```python
def embedded_feasible(skill, monitor, B_e, criticality='hi', margin=MARGIN):
    prof = wcet_analyze(skill, monitor, interrupts=True, caches=True, dma=True)
    prof.update({k: jitter_upper(skill, monitor, k) for k in JITTER_DIMS})
    masked = apply_criticality_mask(prof, criticality, B_e)   # HI 不可抢占/不可降级
    return all(masked[k] + margin[k] <= B_e[k] for k in masked)
```

### IP-130 CCM

```python
def compress_certificate(J, max_states, tau_M, delta_c_budget):
    spec = conj(J.hard_constraints, J.A_core, J.delta_a_bound)
    M, gap = automaton_synth(spec, max_states=max_states)      # abstraction
    assert monitor_sound(M, spec)                             # M reject => J violated
    if wcet(M) > tau_M or gap > delta_c_budget:
        return ('reject', 'monitor_infeasible', wcet(M), gap)
    h = merkle_root(canonical(J))
    return ('ok', JEmb(M, h, gap, tau_M))

def monitor_trace(tr, J_emb):
    s = J_emb.M.start
    for a in tr:
        s = J_emb.M.step(s, a)
        if s is REJECT:
            return ('reject', now())                          # sound, bounded
    return ('accept', now())
```

### IP-131 IRP

```python
def revise(P_t, o_t, I_t, J_emb, tau_rev, theta_I):
    t0 = now()
    drift = intent_distance(I_t, I_t.prev)
    if drift <= theta_I and monitor_trace(trace(P_t), J_emb)[0] == 'accept':
        return ('ok', P_t, I_t)
    I_new = infer_anytime(o_t, model, tau_rev, delta, RAM_BUDGET, CONF_FLOOR)
    if I_new[0] != 'ok':
        return ('ok', safe_stop_plan(), None)                  # always schedulable
    P_new = re_plan(P_t, I_new[1], deadline=tau_rev - (now() - t0))
    if P_new is None or now() - t0 > tau_rev:
        return ('ok', safe_stop_plan(), I_new[1])
    if not intent_cover(P_new, I_new[1], beta_I):
        return ('ok', safe_stop_plan(), I_new[1])
    return ('ok', P_new, I_new[1])
```

### IP-132 IEJ

```python
def intent_embedded_certificate(J, I, eps, J_emb, rev, prov, B_e, delta_c):
    if J.status != 'ok':                          return ('reject','action_robust_invalid')
    if not intent_cover(J.plan, I):               return ('reject','intent_mismatch')
    if not J_I_valid(I):                          return ('reject','intent_uncertain')
    if not eps.subset(B_e):                       return ('reject','embedded_overrun')
    if J_emb.gap > delta_c or not J_emb.sound:    return ('reject','monitor_gap')
    if not rev.bounded_and_monotone():            return ('reject','revision_unsafe')
    if not prov.verify():                         return ('reject','intent_provenance')
    return ('ok', JIE(J, I, eps, J_emb, rev, prov))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ICR | O(N_CAND·|o| + |A_T^hard|) | O(N_CAND) | 硬约束一致，conformal 覆盖达标 |
| AEI | O(τ_commit·refine + |S|) | O(RAM_π) | anytime 单调，期限可提交，校准 |
| EFP | O(|S|·|π| + WCET 分析) | O(|ε|) | WCET sound，临界级掩码正确 |
| CCM | O(|spec|·2^{max_states}) | O(max_states) | 监控 sound，间隙 `≤δ_c`，`τ_M` 闭合 |
| IRP | O(τ_rev·(infer+replan)) | O(|P|) | 安全单调，safe-stop 可调度 |
| IEJ | O(|I|+|ε|+|M_J|) | O(|J_IE|) | 六项合取，承诺可展开验证 |

**正确性定理（Intent-Embedded Deployment Soundness）**
承接第 54 轮 (A22)–(A28)；新增假设：
**(A29)** 意图可信集已校准：`P(I*∈Î_δ) ≥ 1-δ_I`，硬约束提取 sound；
**(A30)** 监控器 `M_J` 对违规 sound，`WCET(M_J) ≤ τ_M`；
**(A31)** WCET/内存/能耗分析 sound：`ε_{S⊕M}⊑B_e ⇒ 实际不超预算` 的概率 `≥ 1-β_E`；
**(A32)** 修订协议 `τ_rev` 内完成或转入可调度安全停车，动作始终在可信意图集内。

则对满足 `dom(J_IE)=in` 的部署：
```
P_success^IE ≥ 1 - Σ_d(1-ρ_min(d)) - P(δ_a>Θ_a) - P(compat<θ_a)
                 - δ_I - δ_c - β_E - P(rev_miss)
```
且灾难性失败被安全停车兜底：`P(catastrophic) ≤ P(stop_unschedulable)`。
关键：**意图误差、压缩间隙、端侧超预算、修订超时是四个独立失败源，按 union bound 相加**；任一项不可验证即降级为“文本 + 原技能 + 安全停车”。

## 5. 本轮最大风险

**一句话**：本轮把“意图理解”与“嵌入式系统”接入证书体系，最深的危险是**把开放的意图错当成一个点、又让端侧预算逼迫提前下注**——一个校准良好却仍可能漏掉真意图的可信集、加上一个“对违规 sound 但对小违规近似完备”的压缩监控器，再叠加不 sound 的 WCET 分析，三者在同一截止期内耦合，就可能把“执行得漂亮但不是用户要的、且超时到没来得及拦住”的计划认证为可部署；因此必须以 **可信集而非点估计、监控器间隙硬预算、WCET 交叉验证、以及永远可调度的安全停车** 作为四重底线，宁可停下来问，绝不自信地做错。
