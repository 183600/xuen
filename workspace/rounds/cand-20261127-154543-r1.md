### 第 1 轮灵感驱动研究记录

**灵感词**：最优控制、真机评测

**一、直觉解释（先讲人话）**

前几轮我们把 KEMPC / CADVS 做成「证书驱动」：证书像体检报告，聚合通过才放行学生策略，否则退回教师 MPC。但这里有个隐含软肋——常识规则（KC）目前只是**代价函数里的软惩罚**（权重 λ_i）。权重再怎么自适应，本质仍是「尽量不违反」，而不是「保证不违反」。这就像开车时把「别压线」写成扣分项，而不是物理护栏。

「最优控制」这个灵感词提示我们换一个视角：**把证书从代价项升格为状态约束**。每条 KC 规则 c_i 对应一个安全集 C_i = {x | h_i(x) ≥ 0}；只要能选出一个控制量使 h_i 沿动力学不下降，安全集就是**前向不变**的。这正是最优控制里控制障碍函数（CBF）与生存核（viability kernel）的语言：安全不再是「优化出来的副产品」，而是「可行域的硬边界」。于是整个问题变成**证书约束最优控制（CCOC）**：在证书定义的可行域内求代价最小、且对扰动鲁棒的轨迹。学生策略是该问题的近似最优解，教师 MPC 是滚动时域求解器，价值网络（HVPM）给出 cost-to-go——三者第一次有了统一的数学坐标，不再靠拍脑袋的 α=0.3 混合，而是用「谁的一步前瞻 Q 值更低」来仲裁。

但最优控制再漂亮，也只是在模型里成立。这就引出第二个灵感词「真机评测」：CBF 的前向不变性依赖 ẋ=f(x,u) 的精确性与零延迟假设；真实机器人却有执行器延迟、关节柔顺、传感器噪声、地面打滑、机械磨损。**模型没算进去的那部分，恰恰是安全证明失效的地方**。因此真机评测不是「最后验收」，而是**对证书本身做有效性实验**：必须把仿真标定的证书按实测残差「膨胀/收紧」，并在硬件上检验「证书通过 ⇒ 实际安全」这条蕴含是否成立。直觉上，这是给安全证明加「置信区间」：理论给的是条件性保证，真机给的是这些条件到底成不成立的经验证据。

**二、严谨定义（把直觉钉死）**

1. **KC→CBF 编译**：对每条常识规则 c_i 定义安全函数 h_i: X→ℝ 与 class-κ 函数 α_i，要求 h_i(x) ≥ 0 ⇔ c_i 满足。规则分两类：
   - 状态型（支撑多边形、CoM、关节限位）：h_i 由状态代数直接给出；
   - 感知型（FQC、DLC）：h_i 由证书量构造，如 h_FQC = κ_max − κ(J_s)，h_DLC = λ_thresh − λ_max(Σ_rel)。
   离散时间 CBF（DCBF）约束：h_i(x_{k+1}) ≥ (1−γ_i) h_i(x_k)，γ_i ∈ (0,1]。

2. **证书约束最优控制（CCOC）**：
   min_{u_{0:N−1}} Σ_k [ℓ(x_k,u_k) + Σ_i λ_i·max(0,−h_i(x_k))]（软松弛仅用于诊断）
   s.t. x_{k+1} = f̂(x_k,u_k) + w_k，w_k ∈ W_tube；
        h_i(x_{k+1}) ≥ (1−γ_i) h_i(x_k) ∀i；
        u_k ∈ U；证书聚合 z_cert 有效。
   记其最优值 V*(x; z_cert)，即「证书条件化 cost-to-go」。

3. **最小侵入安全滤波（SCOQF）**：给定名义动作 u_nom（学生/教师/混合），求
   u* = argmin_u ½‖u−u_nom‖²_W s.t. DCBF 与 U 约束。
   可行则 u* = u_nom（不改变已安全的名义策略）；不可行则引入松弛 s_i ≥ 0 并升级到教师/急停。

4. **鲁棒价值与仲裁**：用 HVPM 集成估计 V̂、σ̂，取下置信界 V_LCB = V̂ − βσ̂；对候选 a ∈ {student, teacher} 比较 Q_LCB(x,a) = ℓ(x,a) + V_LCB(f̂(x,a))，取低者，并加迟滞带 Δ_hys 防抖。

5. **真机证书校准**：设仿真阈值 θ_sim，实测残差分位数 q_{1−δ}(‖residual‖)，定义膨胀因子 ρ_sr = q_{1−δ} / bound_sim；真实证书取 Σ_real = ρ_sr² Σ_sim，κ_max^real = κ_max^sim / ρ_sr。若 ρ_sr 超过上限，判定「证书不可迁移」，禁用对应学生路径。

6. **真机评测协议（RREB）**：分层测试台 T0 数字孪生 → T1 龙门/吊挂 → T2 仪表化场地 → T3 非结构化；预注册指标（成功率、证书违规率、干预率、cost-to-go 后悔、sim-to-real gap、恢复时间）；用 Wilson 区间与 SPRT 做统计判定，并做消融与负对照。

**三、关键洞见**

把「证书」从代价项搬到约束集，本质是把安全从**优化目标**变成**可行域几何**：学生策略再激进，也只能在 CBF 定义的不变集里活动；而真机评测则是对「这个几何是否与物理世界同构」的假设检验。两者合起来，才让「证书通过」从一句日志变成一条可证伪的科学命题。

**四、形式化目标（增量）**

1. 把全部 KC 编译为 DCBF，证明 CCOC 可行域 ⊆ CADVS 执行集；
2. 证明 SCOQF 的最小侵入性与可行性单调性；
3. 给出 tube 半径与最优性间隙 ε 的显式界；
4. 用 ρ_sr 把 sim-to-real 残差纳入证书，给出校准的可靠性下界；
5. 在 T2/T3 真机上以 ≥95% 置信度检验「证书通过 ⇒ 无物理违规」的非劣性。

**本轮最大风险**：**安全证明的前提在真机上不可自证**——CBF 的前向不变性依赖「模型准确 + 零延迟 + 证书可信」，而真机恰在这些前提上系统性偏离；一旦膨胀因子 ρ_sr 被低估，证书会在激进机动时「合法地」放行实际不安全的动作，日志却显示一切正常，形成比仿真更危险的「证明-现实」错位。

### IP-478 Certificate Control Barrier Function Compiler (CCBFC)

```python
@dataclass
class KCBarrier:
    kid: str
    h: Callable[[State], float]
    gamma: float                     # DCBF 衰减
    kind: str                        # 'state' | 'perception'
    source_cert: Optional[str] = None
    alpha: Callable[[float], float] = lambda v: v   # 缺省恒等

class CCBFC:
    """把 KC 规则编译为 DCBF；感知型 h 依赖证书量，需先过 TCVM 时效校验。"""
    def __init__(self, cert_bounds: dict):
        self.b = cert_bounds          # 如 {'kappa_max': 50.0, 'lambda_thresh': 0.02}

    def compile(self, kc) -> KCBarrier:
        if kc.type == 'support_polygon':
            return KCBarrier(kc.id, lambda x: signed_dist_polygon(x, kc.vertices),
                             gamma=0.10, kind='state')
        if kc.type == 'com_limit':
            return KCBarrier(kc.id, lambda x: x.com_z - kc.z_min,
                             gamma=0.15, kind='state')
        if kc.type == 'fqc':
            return KCBarrier(kc.id, lambda x: self.b['kappa_max'] - x.fqc.kappa,
                             gamma=0.20, kind='perception', source_cert='vservo')
        if kc.type == 'dlc':
            return KCBarrier(kc.id, lambda x: self.b['lambda_thresh'] - lam_max(x.dlc.sigma),
                             gamma=0.20, kind='perception', source_cert='diff_loc')
        raise ValueError(f'unknown KC type: {kc.type}')

    def dcbf_residual(self, bar: KCBarrier, x: State, x_next: State) -> float:
        """返回约束残差；≥0 表示满足。感知型证书过期则直接置负（触发回退）。"""
        if bar.kind == 'perception' and not cert_fresh(bar.source_cert):
            return -1.0
        return bar.h(x_next) - (1.0 - bar.gamma) * bar.h(x)
```

### IP-479 Safety-Critical Optimal Control QP Filter (SCOQF)

```python
class FilterStatus(Enum):
    NOMINAL = 0; RELAXED = 1; INFEASIBLE = 2

def safety_filter(u_nom: np.ndarray, x: State, barriers: list[KCBarrier],
                  f_hat, W: np.ndarray, u_lo, u_hi,
                  slack_penalty: float = 1e3) -> tuple[np.ndarray, FilterStatus]:
    """
    min_u 0.5 (u-u_nom)^T W (u-u_nom) + p * sum(s)
    s.t.  h_i(f_hat(x,u)) - (1-gamma_i) h_i(x) + s_i >= 0
          u_lo <= u <= u_hi,  s_i >= 0
    """
    n_u, n_b = u_nom.size, len(barriers)
    # 变量 z = [u; s]
    H = block_diag(W, 2.0 * slack_penalty * np.eye(n_b))
    g = np.concatenate([-W @ u_nom, np.full(n_b, slack_penalty)])
    # 线性化 DCBF（对 u 一阶展开，SQP 内循环迭代）
    A_ineq, b_ineq = [], []
    for i, bar in enumerate(barriers):
        h0 = bar.h(x)
        grad_u = finite_diff(lambda u: bar.h(f_hat(x, u)), u_nom)  # ∂h(f(x,u))/∂u
        row = np.zeros(n_u + n_b); row[:n_u] = -grad_u; row[n_u + i] = -1.0
        A_ineq.append(row)
        b_ineq.append(-(h0 - (1 - bar.gamma) * h0))   # 松弛后 RHS
    sol = solve_qp(H, g, A_ineq, b_ineq,
                   lb=np.concatenate([u_lo, np.zeros(n_b)]),
                   ub=np.concatenate([u_hi, np.full(n_b, np.inf)]))
    if sol.status != 'optimal':
        return None, FilterStatus.INFEASIBLE
    if np.sum(sol.z[n_u:]) < 1e-6:
        return sol.z[:n_u], FilterStatus.NOMINAL
    return sol.z[:n_u], FilterStatus.RELAXED


def hierarchical_execute(u_student, x, barriers, teacher_mpc):
    u, st = safety_filter(u_student, x, barriers, f_hat, W, u_lo, u_hi)
    if st == FilterStatus.NOMINAL:
        return u, 'student+filter'
    u, st = safety_filter(teacher_mpc(x), x, barriers, f_hat, W, u_lo, u_hi)
    if st == FilterStatus.NOMINAL:
        return u, 'teacher+filter'
    return emergency_stop(x), 'emergency_stop'   # 不满足 DCBF 的最后兜底
```

### IP-480 Certificate-Conditioned Robust Value Function (CCRVF)

```python
@dataclass
class CertificateConditionedValue:
    ensemble: list           # V_theta(x, z_cert) 集成
    beta: float = 1.96       # LCB 置信系数
    hyst: float = 0.05       # 仲裁迟滞

    def lcb(self, x: State, z_cert: np.ndarray) -> float:
        vals = np.array([net(x, z_cert) for net in self.ensemble])
        return vals.mean() - self.beta * vals.std(ddof=1)

    def q_lcb(self, x, a, f_hat, ell, z_cert) -> float:
        return ell(x, a) + self.lcb(f_hat(x, a), z_cert)

    def arbitrate(self, x, cand: dict, f_hat, ell, z_cert, last=None):
        q = {k: self.q_lcb(x, a, f_hat, ell, z_cert) for k, a in cand.items()}
        best = min(q, key=q.get)
        if last is not None and q[last] - q[best] < self.hyst:
            return last, q          # 迟滞防抖
        return best, q


def tube_radius(dlc, delay_bound, v_max, disturbance_bound, dt) -> float:
    """tube 横截面半径：定位不确定 + 执行延迟等效位移 + 扰动增长。"""
    r_loc = float(np.sqrt(np.max(np.linalg.eigvals(dlc.sigma_rel))))
    r_delay = delay_bound * v_max
    r_dist = disturbance_bound * dt
    return r_loc + r_delay + r_dist
```

### IP-481 Real-Robot Evaluation Protocol & Bench (RREB)

```python
@dataclass
class RealRobotEvalProtocol:
    tiers: tuple = ('T0', 'T1', 'T2', 'T3')
    alpha: float = 0.05              # 显著性水平
    margin: float = 0.05             # 非劣性裕度
    delta_ni: float = 0.05

    @staticmethod
    def wilson_ci(k: int, n: int, z: float = 1.96) -> tuple[float, float]:
        if n == 0: return (0.0, 1.0)
        p = k / n
        d = 1 + z**2 / n
        c = (p + z**2 / (2*n)) / d
        half = z * np.sqrt(p*(1-p)/n + z**2/(4*n*n)) / d
        return (max(0.0, c-half), min(1.0, c+half))

    @staticmethod
    def required_n(p0: float, p1: float, alpha=0.05, power=0.8) -> int:
        # 两比例检验的近似功效分析（单侧）
        z_a, z_b = 1.645, 0.8416
        pbar = (p0 + p1) / 2
        num = (z_a*np.sqrt(2*pbar*(1-pbar)) + z_b*np.sqrt(p0*(1-p0)+p1*(1-p1)))**2
        return int(np.ceil(num / (p1 - p0)**2))

    def run_block(self, policy, task, n_episodes: int, seed: int):
        """随机化分块：预注册指标、rosbag2 + 硬件时间戳 + 证书轨迹。"""
        results = []
        for ep in range(n_episodes):
            ep_seed = seed * 100003 + ep
            rng = np.random.default_rng(ep_seed)
            log = rollout_on_hardware(policy, task, rng,
                                      record=['/state/est', '/cert/aggregated',
                                              '/ctrl/cmd', '/safety/filter'])
            results.append(dict(
                success=log.task_success,
                violation=log.physical_violation or log.cert_violation,
                interventions=log.teacher_interventions,
                cost=log.cumulative_cost,
                j_regret=log.cumulative_cost - log.teacher_cost,
                sim_gap=log.sim_cost - log.cumulative_cost,
                recovery_time=log.recovery_time,
                seed=ep_seed))
        return results

    def analyze(self, results) -> dict:
        n = len(results); k = sum(r['success'] for r in results)
        v = sum(r['violation'] for r in results)
        return dict(
            success_rate=k/n, success_ci=self.wilson_ci(k, n),
            violation_rate=v/n, violation_ci=self.wilson_ci(v, n),
            j_regret=float(np.mean([r['j_regret'] for r in results])),
            sim_gap=float(np.mean([r['sim_gap'] for r in results])),
            n=n)
```

### IP-482 Sim-to-Real Certificate Calibration (SRCC)

```python
@dataclass
class SimToRealCalibrator:
    delta: float = 0.01              # 残差尾概率
    rho_cap: float = 1.5             # 可迁移膨胀上限
    sim_bound: dict = field(default_factory=dict)  # 各证书仿真界

    def measure_residuals(self, logs) -> dict:
        """从真机日志提取残差：执行延迟、跟踪误差、打滑、传感器噪声。"""
        return dict(
            actuator_delay=np.abs(logs['cmd_t'] - logs['state_t']),
            tracking_err=np.linalg.norm(logs['state'] - logs['state_pred'], axis=-1),
            slip=np.linalg.norm(logs['odom'] - logs['vicon'], axis=-1),
            sensor_noise=np.std(logs['sensor'] - logs['sensor_smooth'], axis=-1))

    def inflation_factor(self, residuals: dict, cert_key: str) -> float:
        q = np.quantile(residuals[cert_key], 1 - self.delta)
        return float(q / self.sim_bound[cert_key])

    def calibrate(self, cert, rho: float):
        if rho > self.rho_cap:
            return None              # 证书不可迁移 → 禁用学生路径
        return Cert(
            sigma=cert.sigma * rho**2,
            kappa_max=cert.kappa_max / rho,
            lambda_thresh=cert.lambda_thresh / rho,
            rho=rho)
```

### CCOC 统一执行流（单步）

```python
def ccoc_step(x: State, sensors: SensorData) -> ControlOutput:
    # 0) 证书聚合 + 时效校验（TCVM 已在 IP-477 实现）
    z_cert = get_cert_aggregate()
    if z_cert is None or not z_cert.timing_valid:
        return fallback_teacher(x, sensors, reason='cert_stale')

    # 1) 编译 KC → DCBF（缓存，规则变更时重建）
    barriers = ccb_dcbf.compile_all(active_kcs(x))

    # 2) 名义动作：学生高频；教师低频
    u_student = student_policy(x)
    u_teacher = teacher_mpc.solve(x, z_cert)

    # 3) 价值仲裁（证书条件化 LCB + 迟滞）
    choice, q = ccvf.arbitrate(
        x, {'student': u_student, 'teacher': u_teacher},
        f_hat, stage_cost, z_cert, last=last_choice)
    u_nom = u_student if choice == 'student' else u_teacher

    # 4) 最小侵入安全滤波 + 分级升级
    u_cmd, path = hierarchical_execute(u_nom, x, barriers, teacher_mpc)

    # 5) 记录证书轨迹（供 RREB / SRCC 离线分析）
    trace = dict(t=x.t, choice=choice, q=q, path=path,
                 h={b.kid: b.h(x) for b in barriers}, z_cert=z_cert)
    return ControlOutput(u_cmd, path=path, certs=z_cert, trace=trace)
```

## 4. 正确性论证（增量更新）

### 引理 32（DCBF 前向不变性）

**陈述**：设安全函数 h，γ ∈ (0,1]，初始 h(x_0) ≥ 0。若 ∀k 有 h(x_{k+1}) ≥ (1−γ) h(x_k)，则 ∀k，h(x_k) ≥ (1−γ)^k h(x_0) ≥ 0，即 C = {x | h(x) ≥ 0} 前向不变。

**证明**：对 k 归纳。k=0 由假设。若 h(x_k) ≥ (1−γ)^k h(x_0) ≥ 0，则 h(x_{k+1}) ≥ (1−γ)h(x_k) ≥ (1−γ)^{k+1} h(x_0) ≥ 0（因 1−γ ∈ (0,1]）。∎

**工程含义**：DCBF 把「常识不违反」从软惩罚变成可逐步衰减但永不越界的不变集；γ 控制收敛到边界的内缩速度，越大越保守。

### 引理 33（SCOQF 的最小侵入性与可行性单调）

**陈述**：设名义动作 u_nom 满足 DCBF 与 U 约束。则 QP 最优解 u* = u_nom，目标值为 0。若 u_nom 不可行，则松弛问题总可行当且仅当存在 u ∈ U 使所有硬约束在松弛变量非负下可满足；且最小松弛量 s* 随约束收紧（h 减小或 γ 增大）单调不减。

**证明**：若 u_nom 可行，取 u=u_nom、s=0 得目标 0，而目标非负，故最优。松弛问题中 s_i 只出现在非负约束与目标，给定 u 时最优 s_i = max(0, −(h_i(f̂)−(1−γ_i)h_i))，可行域关于 u 连续；约束收紧使该 max 项逐点不减，故 s* 单调不减。∎

**工程含义**：安全滤波在名义策略已安全时**完全不改变**它，只在越界时做最小修正——这是「不干扰学生性能」的理论依据。

### 引理 34（tube 鲁棒性与最优性间隙界）

**陈述**：设真实扰动 w_k ∈ W_tube，tube 半径 r_tube 由定位协方差、执行延迟、扰动增长三项构成。若 CCOC 名义解在无扰动下满足 DCBF，则存在 ε > 0 使得 ∀w_k ∈ W_tube 约束满足，且最优性间隙 J(u*) − V* ≤ ε，其中 ε = O(r_tube + s* + ‖f̂−f‖)。

**证明（骨架）**：DCBF 残差对状态/控制 Lipschitz 连续；扰动导致 x_{k+1} 偏移 ≤ r_tube，残差偏移 ≤ L_h·r_tube；延迟等效为控制输入滞后，贡献 ≤ L_f·r_delay。将偏移吸收进松弛上界 s*，由引理 33 得可行解与目标上界，故间隙 ≤ 松弛代价 + 模型误差项。∎

### 引理 35（sim-to-real 证书膨胀的可靠性）

**陈述**：设真实残差 R 满足 P(R ≤ ρ_sr·bound_sim) ≥ 1−δ。若用膨胀因子 ρ_sr 校准证书（Σ_real = ρ_sr²Σ_sim、阈值按 1/ρ_sr 收紧），则校准后证书在真机上的有效性成立概率 ≥ 1−δ。

**证明**：证书有效性等价于真实残差落在仿真界内。按定义，事件 {R ≤ ρ_sr·bound_sim} 即校准后证书有效；其概率 ≥ 1−δ。∎

**推论**：ρ_sr 必须由**真机残差的经验分位数**估计，而不能沿用仿真假设；这正是 RREB 存在的必要性——它是 ρ_sr 的唯一合法来源。

### 引理 36（真机非劣性检验的统计保证）

**陈述**：对成功率 p 的 n 次独立试验，Wilson 区间覆盖真实 p 的概率 ≥ 1−α（近似）；给定基线 p0 与裕度 δ_ni，所需样本量 n_req 由两比例功效公式给出，当 n ≥ n_req 时，若观测成功率 ≥ p0 − δ_ni，则可在水平 α 下拒绝「真机显著劣于基线」。

**证明（骨架）**：Wilson 区间基于二项分布的正态近似并做方差稳定修正，覆盖误差 O(1/√n)；功效公式由单侧两比例检验推导。∎

### 定理（CCOC 的安全性、最优性间隙与真机可证伪性）

**陈述**：在假设
(A1) DCBF 约束在每一步被 SCOQF 满足（引理 32/33）；
(A2) 真机残差落在 SRCC 膨胀界内以概率 ≥ 1−δ（引理 35）；
(A3) 证书聚合 z_cert 时序有效（IP-477 TCVM 无违规）；
(A4) RREB 试验数 n ≥ n_req（引理 36）
下，有：
(i) **安全性**：Exec_CCOC ⊆ C = ∩_i C_i ⊆ Exec_CADVS；
(ii) **最优性间隙**：J(u*) − V* ≤ ε(r_tube, s*, ‖f̂−f‖)；
(iii) **真机可证伪性**：以置信度 ≥ 1−α 判定「证书通过 ⇒ 无物理违规」是否成立；若观测违规率显著高于 p0，则拒绝该蕴含并触发证书重标定。

**证明**：
- (i) 由引理 32，每步满足 DCBF 则轨迹不离开 C_i；CCOC 的每条约束均弱于/等价于 CADVS 十二证的可行性条件（证书硬约束 ⊇ 原软惩罚可行域），故执行集收缩。
- (ii) 由引理 34 直接得到。
- (iii) 由引理 36 的假设检验框架，违规率是「证书通过⇒安全」蕴含的反例频率；显著超出基线即证伪。∎

**诚实声明**：(A1)–(A4) 在真机上**并非恒真**。ρ_sr 可能被低估（(A2) 失效）、QP 在高动态下可能不可行（(A1) 局部失效）、真机样本受成本/安全约束而不足（(A4) 失效）。CCOC 通过**分级回退 + 在线重标定 + 序贯检验**管理这些风险，而不是假设它们不存在。安全是「带置信度的经验命题」，不是无条件定理。

## 6. 本轮最大风险（最终确认）

**一句话**：**安全证明的前提在真机上不可自证**——CBF 的前向不变性、SCOQF 的可行性、证书的时效性都建立在「模型准确 + 零延迟 + 残差可界」之上，而真机评测本身既依赖这些前提来保证测试安全，又需要它们被证伪才能推进认知；一旦 ρ_sr 被低估，系统会在日志「全绿」的情况下合法放行危险动作，形成「证明—现实」的闭环错位，这比纯仿真中的失效更隐蔽、也更致命。
