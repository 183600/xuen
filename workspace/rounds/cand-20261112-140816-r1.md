# 第 58 轮（承接第 57 轮「少样本×多模态×个性化」IP-133~138；灵感驱动研究循环第 1 轮；本轮灵感：「虚实迁移」×「商业模式」）

> 第 57 轮把安全的赌注从"模型置信"换成了"少样本可校准、跨模态可对账、个性化有界的证据承诺"，但它的风险自陈暴露出三个尚未被正面处理的**经济学**问题：**(a) 证据从哪里来最便宜？** 真实探针昂贵且稀少，仿真探针几乎免费却不等价于真实——第 57 轮的元语料默认了训练与部署同分布，"仿真"只是隐含在语料里，从未被当成一个有偏来源来审计；**(b) 谁为证据付钱、谁为错误买单？** 探针、标注、绕行、降档都是成本，但没有任何一方对"系统声称的安全"承担财务责任，于是"过度自信"在组织里是免费的；**(c) 安全等级的边际价格是多少？** 每提高一个数量级的 δ_f 需要多少探针、多少现实锚点、多少资本，无人标价，安全预算只能拍脑袋。本轮两个灵感各补一条腿：**虚实迁移**把证据从"一个池子"拆成"带来源与迁移间隙的双账本"——仿真只是风洞，不是证人；**商业模式**把"敢赌"变成一份有价格、有抵押、有第三方观测的合约——让声称安全的人先押上资本。核心命题由"证据说可信"升级为 **"来源可追溯、间隙可保险、承诺可定价的证据说可信"**。

核心矛盾：
- **H29（虚实同证 vs 有效现实含量）**：仿真探针便宜且高度相关，若与真实证据同账相加，一千次仿真只是把同一个模拟器偏差问了一千遍；有效样本量不是探针数，而是去相关后的现实锚点数。
- **H30（迁移证书自证 vs 间隙盲区）**：迁移间隙无法仅由仿真自身证明；域随机化可以制造"仿真很丰富"的假象，却系统性缺席真实世界的某种偏差；而现实锚点又稀少，回到第 57 轮的小样本困境。
- **H31（商业激励 vs 安全诚实）**：安全若自证且不定价，运营方有动机夸大以省探针与时间；若定价，运营方又控制证据日志、能隐藏失败——没有外部结果观测，市场会以错误价格清算（安全柠檬市场）。
- **H32（资本门槛 vs 可及性）**：让"声称安全"押上约 V/δ_f 的资本，使每多一个九变成十倍资本要求；低利润部署可能被挤出，若允许压低债券上限或买通保费，金融合约就变成事实上的安全等级。
- **H33（成本外部性 vs 监管地板）**：经济最优可能把探针/标注成本转嫁给不承担风险的第三方；必须有一条不可被市场交易掉的监管地板（最低 δ_reg、最低资本、强制结果上报）。

## 0. 直觉与动机

**灵感 1（虚实迁移 → 证据双账本：仿真只是风洞，不是证人）**
直觉：风洞能告诉你"哪几种翼型值得真机试飞"，但没有一架飞机能只靠风洞数据取证。仿真探针也一样：它能替你**少走弯路**，不能替你**多长见识**。所以本轮不再把仿真证据与真实证据放进同一个可加池子，而是给每条证据记 `prov∈{sim,real,mixed}`，并把仿真证据按"同一模拟器的组内相关"折算成**有效现实含量**——十万次相关仿真，去相关后可能只值几个真实锚点。再加一条硬约束：**现实比特预算** `B_real(r)=β·N_anchor(r)`，仿真最多只能把后验从真实先验推开这么多信息量，超了就按 KL 投影截断。结论很直观：仿真可以降低"找探针"的成本，不能降低"承诺"所需的证据门槛。

**灵感 2（虚实迁移 → 迁移间隙是一份可保的未知）**
直觉：仿真与现实的差距本身是一个**不确定量**，可以在少量现实锚点上估计出一个上界 G_ub，然后"投保"：一份迁移证书声明"在锚点覆盖的这类区域上，仿真与真实的偏差不超过 G_ub"。G_ub 小，仿真证据可用；G_ub 大，仿真降级为"仅探索"。间隙以"税"的形式进入后验——按 G_ub 加宽区间、以 G_ub 折损覆盖，而不是假装它不存在。关键是**证书不能自证**：它必须由现实锚点背书，锚点就是让仿真变得可用的保费；漂移监测负责续保。

**灵感 3（虚实迁移 → 数字孪生实验：先筛后探、双向校准）**
直觉：把仿真当成"探针预筛实验室"。它只做两件事：给候选探针排序、剔除已被锚点确认无信息的探针；它**永远不向承诺证据集添加任何东西**。真实结果再反哺仿真（系统辨识），但仿真器的每次更新也要走影子隔离——延续第 57 轮"一切判定器走隔离"，**仿真器也是判定器**。这形成一个良性循环：现实锚点 → 更好的仿真 → 更便宜的预筛 → 省下的预算买更多现实锚点。

**灵感 4（商业模式 → 让"敢赌"有人赔：安全债券）**
直觉：今天说"I'm 99.9% sure"是免费言论；明天应是一份金融承诺。每次承诺托管一笔偿付债券 `B*=(1−δ_f)(V−π)/δ_f`。若真实失效率为 p，承诺的期望收益是 `(1−p)(V−π)−p·B*`，它恰在 `p=δ_f` 处为零、`p>δ_f` 为负——**债券自己完成筛选**：只有真够安全的承诺才值得押。这把统计安全等级 δ_f 直接翻译成资本要求 `B*≈V/δ_f`，也让"多一个九"第一次有了明确价格。反直觉之处：按期望损失定价的普通债券 `B∝q` 会让"声称更安全"更便宜，恰好奖励过度自信；必须用**信心债券** `B∝1/δ_f`（越安全的声明押得越多）。

**灵感 5（商业模式 → 证据经济：安全即服务，但地板不可交易）**
直觉：证据是被生产出来的商品，有供给方（真实探针、人工标注、仿真预筛、第三方审计）。按**经济 VOI** 分配预算：每单位成本带来的"保费下降 + 期望债券损失下降"最大者优先。参与方是多方：厂商、部署运营方、场地方、承保人、监管者。市场可以在底板之上定价与分配，但监管地板（最低安全等级、最低资本、强制结果上报）**不可交易**——否则金融合约本身就成了事实上的安全等级。

**灵感 6（合流 → 五类证据门升为"带来源与经济担保的证据门"）**
直觉：EV-probe* 从此必须声明来源与有效现实含量；仿真永远不能单独成为承诺证据类；EV-visit/margin/xmodal/human 各自保留第 57 轮检查；整个承诺还要过一道经济门（债券已托管、保费已付、结果观测器已注册、地板满足）。击穿安全现在需要：仿真偏差 ∧ 迁移证书失效 ∧ 无现实锚点 ∧ 跨模态无一致 ∧ 无裕度 ∧ 人也错 ∧ 债券被低估——纵深从五层到七层。最深层的变化是：**安全与经济共用同一本账，"谁付钱"成为"什么为真"的一部分**。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（虚实证据账本 SRTL）** 证据 e=(o_e,y_e,prov_e,r_e,w_e,s_e)，prov_e∈{sim,real,mixed}，s_e 为产生它的模拟器/策略族。设计效应 deff(e)=[(Σw)²/Σw²]·[1+(k−1)ρ_sim]（ρ_sim 为同一模拟器内残差组内相关）。**有效现实含量** ERC(e)=n_eff(e)·t(e)，t(real)=1，t(sim)=1/deff，且强制 ERC(e)≤κ·N_anchor(r)；不同来源证据不直接相加。**现实比特预算** B_real(r)=β·N_anchor(r)：虚拟证据对后验的总信息增益 I_sim(r)=Σ_{e:sim}KL(p_e^post‖p_e^prior)≤B_real(r)，超出则按 KL 投影截断。

**定义 140（迁移间隙证书 STC）** 间隙 G(r)=sup_{f∈ℱ}|E_sim f−E_real f|，以锚点集上的 MMD/对抗判别估计并取上置信界 G_ub(r)。证书 τ(r)=(N_anchor,G_ub,anchor_cov,drift_state)，可迁移 ⇔ N_anchor≥n_min ∧ G_ub≤θ_gap ∧ 无漂移。带隙后验 p̃=(1−G_ub)p+G_ub·u（u 为无信息先验）或区间按 G_ub 加宽；来源加权共形给 P(Y∈C)≥1−α−G_ub。G_ub>θ_gap ⇒ 仿真降级为"仅探索"。

**定义 141（数字孪生实验 DTX）** 模拟器 S_ψ、虚拟探针 π_sim；预筛只做两件事：排序候选探针、剔除"锚点确认后仍无信息"的探针；**虚拟探针永远不进入承诺证据集**。真实结果经系统辨识更新 ψ，更新走影子隔离（回归测试：ECE 不劣化 ∧ G_ub 不升 ∧ 负迁移率不升）后才可影响预筛。成本 c_sim≪c_real，负迁移风险 r_neg 由锚点不一致率估计；当 sim 与锚点对 VOI 符号不一致时征"锚点税"——照跑真实探针。

**定义 142（风险定价承诺债券 RPB）** 承诺 c、真实失效率 p、任务价值 V、安全地板 δ_f；承诺须声明上界 q≤δ_f。**偿付债券** B*(c)=(1−δ_f)(V−π(c))/δ_f；失败由外部**结果观测器** O 验证并没收，成功返还。单次激励相容：真实 p 的运营方承诺期望收益=(1−p)(V−π)−pB*，在 p=δ_f 处为 0、p>δ_f 为负——**债券自我筛选**。重复博弈再以对数评分押金校准 q。关键反直觉：普通期望损失债券 B∝q 会奖励过度自信，必须是信心债券 B∝1/δ_f。

**定义 143（证据经济契约 EEC）** 参与方 Ag={vendor,operator,site,underwriter,regulator}，各有预算与效用；资源分配 max E[U] s.t. P_fail≤δ_reg、cost≤budget；**经济 VOI** EVOI(π)=Δπ_premium+ΔE[bond loss]−cost(π)。保费 π(cert) 由审计后的 J_e 定价，**不由自报 q 定价**。监管地板 δ_reg、B_cap≥V/δ_reg、强制结果上报为不可交易约束；市场只在底板之上定价与分配。控制机器人的一方承担严格责任下限，风险不得完全外部化。

**定义 144（经济证据门 EEG 与证书 J_e / PCE$）** 证据类：EV-probe*（须 prov+ERC+STC，sim 不得单独成类）/EV-visit/EV-margin/EV-xmodal（限 L1）/EV-human（auth）。经济检查：债券 B* 已托管、保费已付、结果观测器已注册、J_e 通过审计、监管地板满足。J_e=(J_p,prov_log,ERC_log,gap_cert,sim_shadow_log,quote,bond,premium,oracle_reg,econ_audit)。承诺算子 PCE$：①元推断（第 57 轮）；②对账（第 57 轮）；③**虚实预筛**（DTX 排序/剔除，不造证据）；④**经济定价与押金**（RPB，押金成功才允许承诺）；⑤承诺/绕行/降档/L2/安全停；任何一步失败即降级。

## 2. 关键算法伪代码（完整版见产物区）

```python
def fuse_with_reality_budget(L, r, cert, anchors):     # IP-139/140 合流
    post = real_prior(L, r); budget = beta * anchors.count(r); used = 0.0
    for e in sorted(L.evidence(r), key=info_gain, reverse=True):
        if e.prov == 'sim' and not cert.transferable(r):
            continue                                    # 仿真：仅探索
        cand = bayes_update(post, e.like, w=erc(e, anchors))
        gain = kl(cand, post)
        if used + gain > budget:
            cand = project_kl(cand, post, budget - used)
        post = cand; used += kl(cand, post)
    return inflate_by_gap(post, cert.G_ub(r))           # 间隙税

def self_selecting_bond(V, delta_f, premium):           # IP-142
    B = (1 - delta_f) * (V - premium) / delta_f         # 在 p=delta_f 处期望收益=0
    return B                                            # p>delta_f ⇒ 承诺期望为负
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| SRTL | O(\|L\| log\|L\|)/区域 | O(\|L\|) | 来源可分、ERC 封顶、比特预算 |
| STC | O(N_anchor·d) | O(N_anchor) | G_ub 诚实、覆盖 ≥1−α−G_ub |
| DTX | O(K_sim+K_real) | O(K_sim) | 虚拟不成证据、影子隔离 |
| RPB | O(1)/承诺 | O(1)/承诺 | B* 自我筛选、观测器不可篡改 |
| EEC | O(\|Ag\|) | O(\|Ag\|) | 地板不可交易、保费不依赖自报 q |
| PCE$ | 前四轮 + O(K_sim) | O(\|V\|+\|σ\|) | 四态完备、预算与押金双闸 |

**正确性定理（SimReal-Economic Soundness, SRES 概要）**：在第 57 轮 A33–A40 之上加 (A41) 来源诚实、ERC 封顶与现实比特预算；(A42) 迁移证书有效且漂移漏检 ≤δ_drift，带隙覆盖 ≥1−α−G_ub；(A43) 仿真永不单独构成承诺证据、DTX 负迁移护栏开启；(A44) 债券 B*≥(1−δ_f)(V−π)/δ_f、结果观测器外部且防篡改、资本上限 B_cap≥V/δ_reg；(A45) 监管地板不放宽、保费不依赖自报 q、审计完备。则：(i) **虚实承诺健全性**：P(fail)≤δ_f+ε_meta+δ_probe+ε_h+G_ub，仿真路径额外 ≤δ_ood·α_conf+G_ub，间隙证书失效时仿真贡献为 0；(ii) **自我筛选**：真实 p≥δ_f ⇒ 承诺期望收益 ≤0，过度自信不可获利；(iii) **经济单调性**：仿真预筛与定价灵活性只能降成本或增保守，不能降低安全地板；任何放宽都必须以现实锚点或更高债券换取；(iv) PCE$ 在既有预算内终止。

### IP-139 SRTL（虚实证据账本：有效现实含量与现实比特预算）

```python
def design_effective(k, weights, rho_sim):        # 相关去重 + Kish
    kish = sum(weights) ** 2 / sum(w * w for w in weights)
    return kish / (1 + (k - 1) * rho_sim)         # 同一模拟器的设计效应

def erc(e, anchors):
    if e.prov == 'real':
        return e.n_eff
    if e.prov == 'sim':
        raw = design_effective(len(e.batch), e.weights, rho_sim(e.simulator))
        return min(raw, kappa * anchors.count(e.region))   # 锚点封顶
    return e.real_part + min(e.sim_part, kappa * anchors.count(e.region))

def ledger_add(L, r, e, anchors):
    e.erc = erc(e, anchors)
    L.add(r, e)                                    # 保留来源，不合并成同一条
    return L

def fuse_reality_budget(L, r, cert, anchors):
    post = real_prior(L, r)
    budget = beta * anchors.count(r)               # 现实比特预算
    used = 0.0
    for e in sorted(L.evidence(r), key=info_gain, reverse=True):
        if e.prov == 'sim' and not cert.transferable(r):
            continue                               # 仿真：仅探索，不入承诺
        cand = bayes_update(post, e.like, w=e.erc)
        gain = kl(cand, post)
        if used + gain > budget:                   # KL 投影截断
            cand = project_kl(cand, post, budget - used)
        post = cand
        used += kl(cand, post)
    return inflate_by_gap(post, cert.G_ub(r))      # 间隙税：加宽，不收紧
```

def source_weighted_conformal(scores, prov, alpha):

### IP-141 DTX（数字孪生实验：先筛后探、双向校准）

def dtx_prescreen(candidates, S_psi, anchor, budget_real):
    ranked = sorted(candidates, key=lambda p: sim_voi(S_psi, p), reverse=True)
    keep = []
    for p in ranked:
        if anchor_confirms_uninformative(p):       # 锚点确认无用：剔除
            continue
        if sign(sim_voi(S_psi, p)) != sign(anchor_voi(p)):
            p.cost += anchor_tax(p); p.flag = 'sign_conflict'
        keep.append(p)
    return keep[:budget_real]                      # 只决定"先探哪个"，不作证

def dtx_update(S_psi, real_outcomes):              # 现实 → 仿真，需过隔离
    cand = system_identify(S_psi, real_outcomes)
    if regression_ok(cand, tests={'ece': '<=', 'gap': '<=', 'neg_transfer': '<='}):
        return shadow_adopt(cand)                  # 影子回归通过才接管预筛

### IP-142 RPB（自我筛选债券与外部结果观测器）

```python
def quote_and_bond(V, delta_f, cert, market):
    premium = market.price(cert)                   # 按审计证书定价，不看自报 q
    B_star = (1 - delta_f) * (V - premium) / delta_f
    B_star = max(B_star, V / delta_reg if hasattr(market, 'delta_reg') else 0)
    if B_star > market.B_cap:                      # 资本上限不足 ⇒ 不许承诺
        return Quote(admissible=False, reason='capital_cap')
    escrow.post(B_star); oracle_reg.register(c.operator, c.region)
    return Quote(admissible=True, B=B_star, premium=premium)

def settle(c, B, outcome_y, O):                    # y=1 失败
    sig = O.verify(c.id, outcome_y)                # 外部签署，防运营方篡改
    if not sig.valid:
        return ('reject', 'oracle_untrusted')
    if outcome_y == 1:
        escrow.slash(B, to='underwriter'); regulator.report(c, sig)
        market.raise_premium(c.operator)
    else:
        escrow.release(B)
    return ('settled', outcome_y, sig)

def logscore_deposit(q, y, B):                     # 重复博弈：校准 elicitation
    q = clip(q, 1e-6, 1 - 1e-6)
    return B * (y * log(q) + (1 - y) * log(1 - q))  # proper scoring，真报最优
```

### IP-143 EEC（证据经济契约：预算、保费、监管地板）

```python
def allocate_evidence_budget(budget, candidates, cert, market):
    # 经济 VOI = 保费下降 + 期望债券损失下降 − 证据成本
    def evoi(pi):
        d_prem = market.premium_without(pi) - market.premium_with(pi)
        d_bond = expected_bond(cert) - expected_bond(cert.assume(pi))
        return d_prem + d_bond - pi.cost
    chosen, spent = [], 0.0
    for pi in sorted(candidates, key=evoi, reverse=True):
        if evoi(pi) <= 0 or spent + pi.cost > budget:
            break
        chosen.append(pi); spent += pi.cost
    return chosen, spent

def floor_check(c, cert, market):
    if cert.delta_f > market.delta_reg:            # 技术地板不得低于监管地板
        return ('reject', 'delta_floor')
    if market.B_cap < c.V / market.delta_reg:      # 资本上限不可被市场压低
        return ('reject', 'capital_floor')
    if not market.mandatory_reporting:             # 强制结果上报不可交易
        return ('reject', 'oracle_floor')
    return ('ok',)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SRTL | O(\|L\| log\|L\|)/区域融合；O(1)/证据入账 | O(\|L\|) | 来源可分、ERC 封顶、比特预算（A41） |
| STC | O(N_anchor·d)；共形 O(N log N) | O(N_anchor) | G_ub 诚实、覆盖 ≥1−α−G_ub（A42） |
| DTX | O(K_sim log K_sim + K_real) | O(K_sim) | 虚拟不成证据、影子隔离（A43） |
| RPB | O(1)/报价；O(1)/结算 | O(1)/承诺 | B* 自我筛选、观测器防篡改（A44） |
| EEC | O(\|Ag\|·\|π\|) 预算分配 | O(\|Ag\|+\|π\|) | 地板不可交易、保费不依赖自报 q（A45） |
| PCE$ | 前四轮 + O(K_sim log K_sim) | O(\|V\|+\|σ\|) | 四态完备、探针/资本双闸 |

**正确性定理（SimReal-Economic Soundness, SRES）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 来源诚实：prov 不可伪造，ERC 按定义封顶，现实比特预算 I_sim(r)≤β·N_anchor(r)；(A42)** 迁移证书有效：G_ub 为上置信界且漂移漏检率 ≤δ_drift，来源加权共形覆盖 ≥1−α−G_ub；(A43)** 仿真证据永不单独进入承诺证据集，DTX 预筛只排序/剔除且更新走影子回归；(A44)** 债券 B*≥(1−δ_f)(V−π)/δ_f、结果观测器外部且防篡改、B_cap≥V/δ_reg；(A45)** 监管地板 δ_reg 不被放宽、保费由审计证书而非自报 q 定价、经济审计完备。则：

1. **虚实承诺健全性**：ID 路径 P(fail) ≤ δ_f+ε_meta(k)+δ_probe+ε_h+G_ub；仿真参与路径额外 ≤ δ_ood·α_conf+G_ub；若 τ(r) 失效，仿真对 P_fail 的贡献为 0（仅探索）。
2. **自我筛选（激励相容）**：真实失效率 p 的运营方承诺期望收益为 `(V−π)(δ_f−p)/δ_f`；故 p≥δ_f 时期望收益 ≤0，过度自信不可通过债券获利。等价的资本门槛为 `B*=(1−δ_f)(V−π)/δ_f≈V/δ_f`——**每多一个九，资本要求约十倍**。
3. **经济单调性**：仿真预筛、动态保费与预算分配只能经 (a) 降低证据成本或 (b) 增加保守性（更大债券、更宽区间、更多锚点）影响系统；任何降低安全地板的行为都必须以现实锚点或更高资本显式换取，不能由市场默认放松。
4. **终止性**：每检查点真实探针 ≤k_probes、共识探针 ≤k_cons，预筛不消耗真实预算；PCE$ 在 k_probes+k_cons 内终止于 {承诺, 绕行, L2 协商, 安全停}。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + G_ub)
             − P(间隙漂移未检出) − P(结果观测器被俘获) − P(B_cap < V/δ_reg)
```

关键：**仿真给效率、锚点给保底**（风洞与证人分离）；**间隙给可保的未知**（G_ub 加宽而非隐藏）；**债券给安全的价签**（B*≈V/δ_f，过度自信自付）；**地板给不可交易的下限**（价格不能替代安全）。四者合流，使"谁付钱"成为"什么为真"的一部分。

## 6. 本轮最大风险

**一句话**：本轮把安全的最后担保从技术证书转移到一份可交易的金融合约，最大风险是当结果观测被俘获、债券上限被市场压低或保费被买通时，系统会用"买得起"替代"真的安全"——账面上有价格、有审计、有赔付，风险却被转移给无法评估它的第三方。
