# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「实时推理」×「零样本泛化」）

> 第 54 轮已把技能组合提升为动作-鲁棒性双证书 `(ρ, A_cert, γ_ce, δ_a)`。本轮引入 **实时推理的截止时间语义** 与 **零样本泛化的域外证书**。核心矛盾：H22：实时推理必须在 τ 内给出结论，而零样本任务位于证据稀疏区，证书所需证据量随新颖度增长——"快"与"泛化"在证据维度上直接冲突；H23：若把零样本泛化当作"必须成功部署"，系统会在证据不足时被迫发出虚假证书；若把它当作"必须安全"，最优策略退化为"永远拒绝"，可用性归零。故本轮的核心不是"更强的泛化器"，而是 **把零样本泛化改写为"在 τ 内可证书化的新颖度半径"，并允许校准化拒绝**。

## 0. 直觉与动机

**灵感 1（实时推理 → 证书从"结论"变为"带缺陷界的随时包络"）**
直觉：实时系统里没有"算完"，只有"到点"。因此证书不应是静态断言，而应是随时间改进的 **包络** `C(t) = (ρ(t), A_cert(t), E(t), ε(t))`，其中 `ε(t)` 是当前证据缺口（evidence deficit）的 sound 上界。到截止 τ 时交付 `C(τ)`；能否部署只取决于 `ε(τ) ≤ ε_budget`，而不是"有没有算完"。这把实时推理从"必须收敛"改造为"任何截断点都可安全判定"。

**灵感 2（零样本泛化 → 新颖度是一等预算，而非布尔标签）**
直觉："零样本"不是"见过/没见过"的二元属性，而是连续量：任务 T* 到已认证记忆 M 的距离 `ν(T*,M)`。可证书化的成功概率应写成 `f(ν, τ)`，于是存在 **新颖度-延迟前沿**：给定 τ，系统能安全认证的最大新颖度半径 `r(τ)`。超出 `r(τ)` 就拒绝或降级，而不是硬着头皮泛化。这把不可判定的"任意零样本"问题，化为可判定的"预算内零样本"问题。

**灵感 3（零样本组合化 → 用分解把"未见任务"化归为"已见部件 + 可界组合缝"）**
直觉：真正值得追求的零样本不是"凭空泛化"，而是 **组合泛化**。若 T* 可沿第 54 轮的技能组合图 `G_S` 分解为 `T_1⊕...⊕T_k`，每个部件都在已认证覆盖内，则 T* 虽整体未见，其证书可由部件证书 + **组合缝 `g_⊕`** 拼出。新颖度满足 `ν(T*) ≤ Σ ν_i + g_⊕`。工程路径因此明确：**先分解，再认证，缝太大就拒绝**。

**灵感 4（实时与零样本的联立 → 预算化证据调度）**
直觉：在 τ 内，计算该花在哪里？三类花费：检索（从 M 取类比）、仿真（补证据）、验证（检查证书）。每种动作的 **单位时间证据增益** 不同，且随任务新颖度变化。把证书生成建模为 **价值信息（VoI）/时间的背包**：用子模贪心在 `{retrieve, simulate, verify, decompose}` 间分配预算，使 `ε(τ)` 最小。第 53/54 轮的 `Explain` 反向解释恰好是最强 VoI 信号——它直接指出缺哪一维证据。

**灵感 5（安全侧的必然出口 → 校准化拒绝与回退）**
直觉：若 `ε(τ,ν) > ε_budget`，唯一 sound 的动作是 **拒绝部署** 并给出回退策略 F（保守技能 / 人工接管 / 减速）。但"全部拒绝"是退化解，因此必须同时约束 **可用性下界** 与 **拒绝校准**：被拒绝的任务中真实会失败的比例应 ≥ 1−δ（拒绝有理由），被接受的任务失败率 ≤ ε_budget（接受可信）。这把安全性与可用性放进同一个 selective-risk 框架。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（随时证书包络）**
对任务 T，随时证书过程在时刻 t 返回 `C(t) = (ρ(t), A_cert(t), E(t), ε(t))`：
- `ρ(t)`：当前鲁棒性谱下界；
- `A_cert(t)`：当前动作占用证书；
- `E(t)`：已累积证据集；
- `ε(t)`：证据缺口上界，满足 `P(fail | deploy at t) ≤ ε_base + ε(t)`。

**随时有效性**：若 `ε(t)` 来自 confidence sequence，则对任意停时 τ 有 `P(∃t≤τ : fail(t) > ε_base + ε(t)) ≤ α`。允许 `ε` 非单调，但以 running minimum `ε̄(t)=min_{s≤t} ε(s)` 作为部署判据。

**定义 122（任务新颖度）**
给定认证记忆 `M = {(T_i, C_i)}` 与嵌入 `φ`，新颖度 `ν(T*,M) = min_i ||φ(T*) − φ(T_i)||_Σ`（马氏距离），并定义认证半径 `ν_0`：`ν ≤ ν_0` 为分布内，`ν > ν_0` 为零样本区。

**定义 123（零样本组合可证书性）**
T* 是 `(θ,τ)`-零样本可证书的，若存在沿 `G_S` 的分解 `T* = T_1⊕...⊕T_k`，使
```
∀i: ν(T_i,M) ≤ ν_0  ∧  Σ_i ν(T_i,M) + g_⊕(T_1..T_k) ≤ θ  ∧  ε̄(τ) ≤ ε_budget
```
其中 `g_⊕` 为组合缝，定义为部件间动作转换成本、鲁棒性耦合差与语义接口失配之和。此时无需 T* 的直接证据即可签发组合证书。

**定义 124（新颖度-延迟前沿）**
`r(τ) = max{ ν : ε(τ,ν) ≤ ε_budget }`，前沿 `𝔉 = {(τ, r(τ))}`。系统对 T* 的判定为：`ν(T*,M) ≤ r(τ)` 则部署，否则拒绝/回退。𝔉 单调不减，其凹性由 VoI 子模性保证（见 A31）。

**定义 125（预算化证据调度）**
调度动作 `a ∈ {retrieve, simulate, verify, decompose}`，`VoI(a|E) = E[ε(E) − ε(E ∪ evidence(a))]`。调度问题：
```
max_π  E[ 1 / ε̄(τ) ]   s.t.  Σ_t t_a ≤ τ,  a_t = π(E_t)
```
以子模贪心近似，预算约束下近似比 `1−1/e`。

**定义 126（校准化拒绝证书）**
若 `ν(T*,M) > r(τ)`，输出 `REFUSE(F, κ)`：
- `F` 为回退策略；
- `κ` 为拒绝理由证书（引用缺失维度 `d*` 与 Explain 根因）；
- **校准约束**：`P(fail | refuse) ≥ 1−δ`（拒绝精确率），`P(fail | accept) ≤ ε_budget`（接受风险），并在可用性下界 `cov ≥ cov_min` 下求解阈值，三者在 risk-coverage 曲线上同时约束。

## 2. 关键算法 伪代码

### IP-121 ARC（Anytime Reasoning Certificate）

```python
def anytime_certificate(T, tau, verifier):
    E, eps_bar = EvidenceSet(), float('inf')
    t0 = now()
    while now() - t0 < tau and not converged(E):
        e = verifier.next_evidence(T, E)          # confidence-sequence valid
        E.update(e)
        eps_bar = min(eps_bar, eps_bound(E, T))   # running minimum
        yield Cert(robustness(E), action_cert(E), E, eps_bar)
    return Cert(robustness(E), action_cert(E), E, eps_bar)
```

### IP-122 NOVA（Novelty Estimation）

```python
def novelty(T_star, memory, phi, sigma):
    z = phi(T_star)
    dists = [mahalanobis(z, phi(Ti), sigma) for Ti, _ in memory]
    return min(dists) if dists else float('inf')

def certified_radius(tau, frontier):
    return interpolate(frontier, tau)             # 查表/插值 𝔉
```

### IP-123 ZSCC（Zero-Shot Compositional Certificate）

```python
def zs_compose_certify(T_star, G_S, M, phi, tau, theta, eps_budget):
    best = None
    for decomp in enumerate_decompositions(T_star, G_S, depth=k_max):
        nus = [novelty(Ti, M, phi, sigma) for Ti in decomp.parts]
        gap = composition_gap(decomp, G_S)        # 动作转换 + 耦合 + 接口
        if max(nus) <= nu0 and sum(nus) + gap <= theta:
            c = combine_certs([M.cert(Ti) for Ti in decomp.parts], gap)
            if c.eps <= eps_budget:
                best = argmin(best, c, key=lambda c: c.eps)
    return best or ('refuse', 'no_certifiable_decomposition')
```

### IP-124 BES（Budgeted Evidence Scheduler）

```python
def schedule_evidence(E, tau_left, actions):
    for a in actions:
        a.voi  = estimate_voi(a, E)               # Explain 作为特征
        a.cost = estimate_cost(a, E)
    return greedy_knapsack(actions, budget=tau_left)   # 子模背包
```

### IP-125 CRO（Calibrated Refusal）

```python
def deploy_or_refuse(cert, tau, frontier, cov_min, delta):
    r = certified_radius(tau, frontier)
    if cert.nu <= r and cert.eps <= eps_budget:
        return ('deploy', cert)
    F = fallback_policy(cert.failure_dims)
    return ('refuse', RefusalCert(F, reason=cert.explain, delta=delta))
```

### IP-126 ZCT（Zero-Shot Certificate Transfer）

```python
def transfer_certificate(T_star, memory_index, phi, tau):
    T_src, C_src = memory_index.retrieve(phi(T_star))    # ANN
    drift = domain_drift(phi(T_src), phi(T_star))
    C_tr = transfer_cert(C_src, drift)                    # 复用第 54 轮 JTC
    if C_tr.eps > eps_budget:
        return realtime_repair(C_tr, T_star, tau)         # 局部补证
    return C_tr
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| ARC | O(τ/Δt · |E|) | O(|E|) | confidence sequence 随时有效 |
| NOVA | O(log|M|·d) | O(|M|·d) | ν 估计一致 + 半径校准 |
| ZSCC | O(b^k · |S|) | O(k·|A|) | 分解完备 + 缝上界 sound |
| BES | O(K log K) per step | O(K) | VoI 子模 + 预算可行 |
| CRO | O(log|𝔉|) | O(bins) | 阈值校准 + 可用性下界 |

**正确性定理（Zero-Shot Real-Time Deployment Soundness）**
承接第 54 轮 (A26)–(A28)；新增：**(A29)** `ε̄(t)` 为 anytime-valid confidence sequence（任意停时有效）；**(A30)** `ν` 在 φ 上 L_ν-Lipschitz，且零样本区有 conformal 覆盖保证；**(A31)** `VoI` 关于证据集子模；**(A32)** 组合缝 `g_⊕` 存在可计算上界且 `A_core` 在分解间可对齐。
则对任意停时 τ：
```
P(fail | accept at τ) ≤ ε_base + ε̄(τ) + L_ν·(ν − r(τ))_+ + g_⊕ + β_ν
```
且 `P(fail | refuse) ≥ 1−δ`、`cov ≥ cov_min` 由 CRO 的校准约束给出（阈值可行域非空时）。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 证书包络非单调、截断处失效 | 高 | anytime confidence sequence + running min + 停时校验 |
| 零样本区 ν 外推失真 | 高 | conformal/共形预测 + 集成 + 远端红队 |
| 组合缝 g_⊕ 低估 | 高 | 保守上界 + 组合反例注入 + 缝预算硬约束 |
| 拒绝退化为"全拒绝" | 高 | 可用性下界 cov_min + risk-coverage 联合约束 |
| 调度饥饿 / Explain 抖动 | 中 | VoI 平滑 + hysteresis + 冷启动锚点 |

## 6. 本轮最大风险

**一句话**：把零样本泛化改写为"τ 内可证书化的新颖度半径"并辅以校准化拒绝，方向正确，但其 soundness 同时押在 **随时证书包络在任意停时都有效、新颖度 ν 在域外仍被校准、组合缝 g_⊕ 被保守上界包住** 三件事上；任一条在远离认证记忆处失效，系统就会在"最需要零样本"的区域发出"自信但错误"的证书，或以"全拒绝"把可用性悄悄归零——因此必须以 **anytime 置信序列 + conformal 新颖度 + 缝预算硬约束 + 可用性下界** 四重护栏，宁可少认、不可错认。

## 3. 推导：组合新颖度界与失败上界

**引理 1（组合新颖度界）**
设 `φ` 为 `L_φ`-Lipschitz 嵌入，分解 `T*=T_1⊕...⊕T_k`，每条组合边的缝由动作兼容性缺口、耦合谱差与接口失配组成：
```
g_⊕ = Σ_edges [ c_a·(1−compat(edge)) + c_ρ·||Δρ(edge)|| + c_ι·δ_ι(edge) ]
```
则由 `φ` 上的三角不等式与接口项可加性：
```
ν(T*,M) ≤ Σ_i ν(T_i,M) + g_⊕
```
*证明要点*：沿分解树把 `T_i` 依次拼接，每拼接一条边，`φ` 空间中最多增加 `L_φ` 倍的动作/谱/接口差异，累加即得；`c_a,c_ρ,c_ι` 为对应 Lipschitz 常数。故 `g_⊕` 是可计算而非估计的 **保守上界**——这正是把零样本组合certification 从"经验判断"变为"预算约束"的关键。

**定理（Zero-Shot Real-Time Deployment Soundness）**
承接 (A26)–(A28)；**(A29)** `ε̄(t)` 为 anytime-valid confidence sequence；**(A30)** `ν` 在 φ 上 `L_ν`-Lipschitz 且零样本区有 conformal 覆盖；**(A31)** `VoI` 关于证据集子模；**(A32)** `g_⊕` 有可计算上界且 `A_core` 跨分解可对齐。则对任意停时 τ：
```
P(fail | accept at τ) ≤ ε_base + ε̄(τ) + L_ν·(ν − r(τ))_+ + g_⊕ + β_ν
```
其中 `β_ν` 为 ν 估计误差项；又由 CRO 的阈值校准（可行域非空）：
```
P(fail | refuse) ≥ 1−δ ,   cov ≥ cov_min
```

**推论（零样本的"预算化"判定）**
`τ` 固定时，可认证集为 `{T : ν(T,M) ≤ r(τ), g_⊕ ≤ g_budget}`。随着 τ 增大，`r(τ)` 单调不减，故"更长思考时间"换"更大零样本半径"。这给出一个可测试的预测：E165 中 `r(τ)` 应随 τ 上升并趋于平台，平台位置由 `ε_base` 决定。

| E167 证书迁移索引 | 检索命中率 / 补证时间 | 命中 ≥ 80%，P95 ≤ τ |

**预期实验结果（可按 E162–E167 复核的预测）**
- E165 曲线应呈"快速上升—平台"：`τ < 50ms` 时 `r(τ)` 由检索主导，`τ ∈ [50,200]ms` 由仿真主导，平台由 `ε_base` 封顶；
- E164 中组合分解在 `ν ∈ (ν_0, 2ν_0]` 区间收益最大，`ν ≫ ν_0` 时因 `g_⊕` 超预算而回落到拒绝——这正好验证"缝预算"是有效约束；
- E166 若 `cov_min` 设得过高，accept risk 会突破 `ε_budget`，说明可用性与安全性确实互相挤压，必须显式权衡而非同时最大化。

## 7. 本轮最大风险

**一句话**：本方案把零样本泛化改写为 `{ν ≤ r(τ)} ∧ {g_⊕ ≤ g_budget}` 的可判定部署谓词，思想严密，但它的 soundness 同时依赖 **任意停时有效的 `ε̄(t)`、域外仍校准的 `ν`、以及保守可算的 `g_⊕`**；三者中任意一个在远离认证记忆处失效，系统就会在"最需要泛化"的区域发出"自信但错误"的证书，或为了"绝不犯错"退化成"全拒绝"而把可用性归零——所以必须把 anytime 置信序列、conformal 新颖度、缝预算硬约束与 `cov_min` 可用性下界同时写进部署判定，宁可少认、不可错认。
