## 1. 直觉

**灵感 A｜分层规划。** 32 个任务都是数秒到数十秒的长程任务，却被当作「一次前向出一个 chunk」来解。扁平策略把「现在该做哪个子任务」（秒级）与「这一帧关节怎么动」（百毫秒级）压在同一时间尺度上：180s 预算无处分账；被人干预后只能整段重来；步骤分本是里程碑式，却没有显式载体。分层把时间轴切成 任务 → 技能 → 控制 三层。**反直觉点：分层的真正红利不是「更聪明」，而是「更便宜地重规划」——世界被改写时只作废当前技能选项，而非丢弃整段轨迹。**

**灵感 B｜关节驱动。** 多数队伍把 `control_space` 当实现细节、默认选 `ee`。但 F9 显示：关节模式下我们同时拿到「目标关节位置 q\*」与「实测关节状态 q」。二者之差 `r = q − q*` 是被所有人丢掉的免费通道——在没有力 / 触觉的平台上（F8），它等价于一个虚拟力 / 接触传感器。**反直觉点：所谓「无触觉」不是观测缺失，而是我们扔掉了「指令 vs 实测」这条现成残差；关节驱动把结构性短板变成可测信号。**

**合流。** 分层需要一个「何时切换技能」的物理信号，残差正好提供「接触 / 受阻 / 被人推动」的证据；残差需要「在哪一层响应」的决策结构，分层正好提供「只在技能边界重规划」的廉价入口。本轮主线 = **残差触觉驱动的分层技能策略（Residual-Tactile Hierarchical Skill Policy）**。

**诚实评估。** 名义执行下，扁平 VLA 可能已经足够；分层的边际收益集中在 2/10 的人为干扰、失败恢复与步骤分。因此本轮把 H2（残差）排在 H1（分层）之前——H2 对约 6–8 个接触族任务也有独立增益，是更根本的押注。

## 2. 严格定义

**定义 1（分层策略 / 选项 / SMDP）。** 选项 `ω = (I_ω, π_ω, β_ω)`：`I_ω` 启动集、`π_ω` 内部策略、`β_ω` 终止概率；分层策略 `π_H: S → Ω`。其诱导过程是半马尔可夫决策过程（SMDP），时间延展动作的 Bellman 期望对选项时长取期望。本文把选项实例化为技能段 {approach, grasp, transport, align/insert, place, retract}，`β` 由进度头与残差异常共同决定；两个时间尺度：技能边界（秒级）+ 控制 chunk（T_a 步）。

**定义 2（关节驱动与残差）。** 关节策略输出每臂目标 `q* ∈ R^7`。设底层为位置控制 `τ = K_p(q* − q) − K_d q̇ + g(q)`。定义残差 `r_t = q_t − q*_t`（实测减指令）。准静态（q̈≈0、q̇≈0）下外部关节力矩 `τ_ext = K_p r_t`，笛卡尔接触力 `F_ext ≈ J(q)^{−T} K_p r_t`。夹爪残差 `r_g = g_obs − g*`：闭合指令下持续 `r_g > 0` 表示闭合被物体阻挡（接触 / 抓取证据）。

**定义 3（里程碑与步骤分）。** 设步骤分是里程碑序列 `m_1 … m_K` 的单调函数。分层计划显式枚举里程碑，进度头 `p_t ∈ [0,1]` 估计当前里程碑；步骤分代理 = 已完成里程碑数。预算按各选项期望时长分配，形成「截止时间感知」的 SMDP 价值 `V(s, t_remaining)`。

## 3. 研究问题（本轮立项 Q1–Q5）

- **Q1 分层粒度 × 单模型边界**：如何在一个网络内实现「技能级 + 控制级」双时间尺度（层级 action chunk / option head），而不触发「多模型混用」红线？
- **Q2 残差标定**：K_p 与重力 / 摩擦补偿未知时，`r → 接触事件` 的单调标定能否只用公开数据 + 免费单任务通道完成？快速运动段的动态污染如何用短窗 / 学习式残差模型补偿？
- **Q3 残差驱动的终止与重规划**：如何用「技能预期残差 profile vs 实测」做异常检测，触发 abort / retry（带偏移）/ yield（让人），并用滞回避免抖动？
- **Q4 关节 vs 笛卡尔泛化权衡**：关节空间是否牺牲位置泛化？能否用「高层笛卡尔子目标（等变）+ 内部解析 IK + 关节残差伺服」三者兼得？
- **Q5 预算与可信度**：分层调度如何把 180s 分账，同时保证关节动作界内、平滑、统计正常（F11）？

## 4. 设计原则（PR1–PR5）

- **PR1 计分轴对齐律**：每个决策必须指明作用于哪条计分轴（5 类泛化 × 步骤分 × 180s），指不出不做。
- **PR2 单模型边界律（本轮强化）**：参赛实体 = 一个策略服务。高层优先用「同一网络的层级输出」或「非参数化规则调度」；**独立训练的第二个网络（尤其 VLM 高层规划器）在书面确认前视为红线**。
- **PR3 残差即物理证据律（本轮新立）**：接触 / 受阻 / 人推的判断优先用 `q − q*`、`g_obs − g*`；视觉手部检测只作补充与冗余确认。
- **PR4 干预安全律**：残差或视觉检测到人手 / 异常外力 → 降速 / 停持 / 让位 → 场景重估 → 续做；停持动作界内平滑。
- **PR5 部署预算律**：p99 延迟 + 关节动作健康度（界内、速度 / 加速度 / 加加速度受限）是发布门禁；先过本地 stub 再上真机。

## 6. 本轮最大风险（一句话）

**分层会把「合规」与「正确」两处风险叠在一起：若高层用独立训练的第二网络，可能被判「多模型混用」而丧失资格；若强行压进单网络，高层错误的终止 / 重规划会把低层拖入比扁平 VLA 更差的级联失败。**

## 7. 下轮迭代计划（深化与修剪）

- **深化**：H2（残差标定协议 + 动态污染补偿 + 抓取判定真值表）、H1（层级 action chunk 的单网络实现与 option head 终止学习）。

# UniBot-V1 参赛方案（本轮 v2.0 · 分层规划 × 关节驱动）

> 检索日期 2026-11-27。本轮把上一版 I1–I8 重组为 H1–H6，核心两条：分层规划提供「廉价重规划」的时间结构，关节残差提供「无触觉平台上的虚拟接触」信号。清单只增改不重置。

## 0. 创新点清单（动机 / 差异 / 可行性 / 资源 / 落地步骤 / 风险）

### H1 分层里程碑技能策略 ★★★★★
- **动机**：32 任务均为长程，扁平策略把子任务选择与控制混在同一时间尺度，180s 无处分账、干预后整段重来、步骤分无显式载体。
- **差异**：不是「加一个大模型规划器」，而是在**同一策略网络内**做层级 action chunk——高层输出技能 latent / 选项 + 粗粒度子目标（秒级、每个选项约 T_skill 步），低层输出细动作 chunk（T_a 步）；或退化为「VLA + 非参数规则调度器」。
- **可行性**：高。数据有 `language`（F9）可作任务条件；`reset()` 每 episode 一次、策略常驻（F10）天然支持选项 FSM；官方 Base 支持微调（F6）。
- **资源**：LoRA 微调 4–8×A100 数天；H6 分段数据 1×A100。
- **步骤**：①用 H6 把 32 任务演示切成技能段并打里程碑标签；②训练带 option head 的层级 VLA（高层终止 + 低层 chunk）；③在单任务通道验证「技能边界切换」与「扁平基线」A/B；④进度头作为终止 / 步骤分代理联合训练。
- **风险**：高层终止错误级联（缓解：终止用进度头 + 残差异常双证据，且允许回退到扁平执行）；单模型边界（见 §5）。

### H2 关节残差虚拟触觉 ★★★★★
- **动机**：观测无力 / 触觉（F8）；但关节模式下「目标关节位置 q\*」与「实测关节 q」同时可得（F9），其差 `r = q − q*` 是免费接触通道。
- **差异**：多数队伍只用 q 作输入、把 q\* 当输出，二者之差被丢弃；本点把 r 显式建成「虚拟力 / 接触」观测，零额外传感器、近零训练。**控制空间无关性**：joint 模式给 7 维 / 臂的力矩对齐残差（首选）；ee 模式退化为 6 维位姿残差；夹爪残差 `r_g = g_obs − g*` 两种模式都可用。
- **可行性**：高。准静态下 `τ_ext = K_p r`、`F_ext ≈ J^{−T}K_p r`（§1.1 推导）；夹爪残差可直接判抓取（§1.2）。K_p 未知时只需**单调标定**，不求绝对牛顿值。
- **资源**：1 人周工程 + 免费单任务通道做标定；无 GPU 训练（可选小 MLP 拟合动态残差）。
- **步骤**：①在数据集上回放，统计 r 的基线分布与「接触 / 自由」分离度；②单任务通道做三类标定事件（轻触、插孔受阻、人推）；③拟合 r→事件 的单调阈值 + 短窗滤波；④夹爪残差抓取判定真值表上线；⑤**接触段把 `action_chunk_size` 降到 1–2 以提高残差采样率（残差带宽 = 1/T_a）**，自由段放大。
- **风险**：底层若为高刚度 / 强补偿，r 信噪比低；快速运动动态污染（缓解：准静态窗 + 学习式残差模型 + 视觉冗余；信噪比不足则降级为「夹爪残差 + 视觉」）。

### H3 残差条件的分层重规划 ★★★★
- **动机**：人为干扰轴真人移动物品（F2）；无感知策略对新现实重复旧动作；失败恢复又是步骤分免费分（F3）。
- **差异**：把 H2 的残差 profile 作为「世界被改写」的证据，触发**技能级**重规划而非整段重来：abort 当前选项 → 重新观测 → 重新选择（重试带偏移 / yield 让人 / 换技能）。
- **可行性**：高。异常检测 = 预期残差 profile（H6 学得）vs 实测的偏离度；状态机外挂 `get_action`，不侵入模型。
- **资源**：1 人周工程；复用 H2。
- **步骤**：①每技能学残差 profile 的均值 / 方差；②定义偏离度分数与滞回；③三类响应：插入受阻→微搜索（wiggle），被人推→yield，抓空 / 脱手→retry；④单任务通道验证误触发率 <5%、恢复成功率 >60%。
- **风险**：误触发打断正常执行（缓解：滞回 + 每 episode 次数上限 + TTL）。

### H4 分层时间预算与步骤分对齐 ★★★★
- **动机**：180s 硬上限 + 步骤分（F3）；扁平策略没有「剩余时间—剩余里程碑」的账本。
- **差异**：SMDP 价值带剩余时间状态 `V(s, t_remaining)`；每个选项有期望时长，超时则高层在「放弃重试 vs 部分完成」间权衡，按「成功率 → 步骤分」字典序最大化。
- **可行性**：高。里程碑来自 H6；期望时长可由演示统计。
- **资源**：纯调度逻辑 + 演示统计；1 人周。
- **步骤**：①演示统计各技能时长分布；②实现 deadline-aware 选项选择；③在 180s 约束下做「贪心完成里程碑」策略；④单任务通道验证超时率下降。
- **风险**：时长估计偏差导致过早放弃（缓解：在线更新时长估计；保留最小重试预算）。

### H5 关节空间动作健康度 ★★★
- **动机**：官方按动作统计规律评估可信度并可能公示（F11）；关节模式输出的是目标关节位置，天然有界、易平滑。
- **差异**：ee 模式经内部 IK 可能产生跳变 / 奇异；关节模式可直接做界内裁剪 + 速度 / 加速度 / 加加速度限制 + 零空间姿态正则。
- **可行性**：高（纯后处理）。
- **资源**：1 人周；无训练。
- **步骤**：①对 q\* 做关节限位裁剪；②jerk-limited 插值；③双臂 / 躯干协调的零空间正则；④本地 stub 统计动作健康度并作 PR5 门禁。
- **风险**：过度平滑降低反应性（缓解：仅对超阈值分量平滑，残差 / 干预态放宽）。

### H6 分层演示自动分段（数据引擎）★★★★
- **动机**：H1/H3 需要技能段与里程碑标签，官方数据无子任务标注。
- **差异**：用关节速度、夹爪开合、ee 轨迹的变化点检测（change-point）自动切段，并用残差统计给每段建 profile；无需人工标注。
- **可行性**：高。3.2 万 eps 可离线批处理。
- **资源**：1×A100 数天；磁盘约 2TB。
- **步骤**：①每任务抽样 50 eps 人工校验分段；②全量分段 + 里程碑标签；③产出 option 训练数据与残差 profile 先验；④分段质量作为 H1 的前置门禁。
- **风险**：分段边界与真实技能不一致（缓解：抽样校验 + 下游 A/B 反证）。

## 1. 关键推导

### 1.1 关节残差 → 接触力（虚拟力传感）
刚体机械臂动力学：`M(q)q̈ + C(q,q̇)q̇ + g(q) = τ_cmd + τ_ext`。
底层位置控制：`τ_cmd = K_p(q* − q) − K_d q̇ + g(q)`。
代入并取准静态 `q̈≈0, q̇≈0`：
```
g = K_p(q* − q) + g + τ_ext  ⇒  τ_ext = −K_p(q* − q) = K_p(q − q*) = K_p r
F_ext ≈ J(q)^{−T} τ_ext = J(q)^{−T} K_p r,   r := q − q*
```
要点：①`r` 的方向指示外力方向，模长随接触加深单调增；②K_p、g 未知时只需标定单调映射 `r → 事件`，不求绝对力；③快速段用短窗或学习式残差模型吸收惯性 / 摩擦项。

### 1.2 夹爪残差 → 抓取判定
令 `g*` 为闭合指令、`g_obs` 为实测开合，`r_g = g_obs − g*`：
| 情形 | g_obs 行为 | r_g | 判定 |
|---|---|---|---|
| 空抓闭合 | 趋近 g* | ≈0 | 抓空（无物体） |
| 抓到物体 | 停在物体宽度 | 持续 >0 | 抓取接触 / 成功证据 |
| 物体被抽走 | 突然趋近 g* | 由 >0 骤降 | 抓取丢失（触发 H3 retry） |
| 夹持中被人推开 | g_obs 抖动 / 异常 | 突变 | 外力事件（触发 H3 yield） |

### 1.3 分层 vs 扁平的重规划成本
扁平：干预后需从当前状态重新前向整段轨迹（或至少一个长 chunk），代价 `O(T_horizon)`。
分层：只在技能边界作废当前选项，低层 chunk 重算，代价 `O(T_a)` + 高层一次决策 `O(1)`。**这正是「更便宜地重规划」的量化含义。**

### 1.4 截止时间感知的 SMDP 价值
```
V(s, b) = max_ω [ R(s,ω) + γ^{τ_ω} E[ V(s', b − τ_ω) ] ],   s.t. b ≥ τ_ω
```
`b` 为剩余 180s 预算；目标按字典序：先最大化成功（完成全部里程碑），再最大化已完成里程碑数（步骤分）。

## 2. 关键伪代码

### 2.1 残差接触估计器（H2）
```python
class ResidualContactEstimator:
    def __init__(self, kp_scale, jac_fn, win=5):
        self.kp_scale, self.jac_fn, self.win = kp_scale, jac_fn, win
        self.buf = deque(maxlen=win)

    def update(self, q_cmd, q_obs, g_cmd, g_obs):
        r = q_obs - q_cmd                       # 残差 = 实测 - 指令
        self.buf.append(r)
        r_f = np.mean(self.buf, axis=0)         # 短窗抑噪
        tau_ext = self.kp_scale * r_f           # 虚拟关节力矩（单调标定）
        F_ext = self.jac_fn(q_obs).T @ tau_ext  # 虚拟笛卡尔力
        rg = g_obs - g_cmd                       # 夹爪残差
        return {"r": r_f, "F": F_ext, "r_gripper": rg,
                "contact": norm(F_ext) > TH_CONTACT,
                "grasp_blocked": rg > TH_GRIP}
```

### 2.2 残差触觉驱动的分层策略（H1+H3+H4，单服务内）
```python
class HierarchicalSkillPolicy:          # 唯一参赛实体：一个 PolicyService
    def __init__(self):
        self.net = load_hier_vla()      # 单网络：option head + fine action chunk
        self.res = ResidualContactEstimator(...)
        self.prog = ProgressHead()      # 里程碑进度（可作 option head 辅助头）
        self.reset()

    def reset(self):
        self.opt, self.t, self.retries = None, 0, {}
        self.last_cmd, self.last_g = None, None
        self.was_grasping = False

    def get_action(self, obs):
        q_obs = concat(obs["observation.state.left_arm"],
                       obs["observation.state.right_arm"])
        g_obs = concat(obs["observation.state.left_gripper"],
                       obs["observation.state.right_gripper"])
        est = self.res.update(self.last_cmd, q_obs, self.last_g, g_obs)
        self.was_grasping = est["grasp_blocked"]

        # 1) 技能边界 / 异常 → 高层重规划（秒级）
        if self.opt is None or self.terminated(obs, est) or self.anomaly(est):
            self.opt = self.net.select_option(obs, est, progress=self.prog(obs),
                                              retries=self.retries)
            self.opt_t0 = self.t

        # 2) 低层细动作 chunk（百毫秒级）
        q_star = self.net.act_chunk(obs, self.opt)          # 关节目标
        q_star = joint_limit_clip(q_star)
        q_star = jerk_limited(self.last_cmd, q_star, max_jerk=J_MAX)
        g_cmd = self.g_cmd_for(self.opt)
        self.last_cmd, self.last_g = q_star, g_cmd
        self.t += 1
        return {"action.left_arm": q_star[:7], "action.right_arm": q_star[7:],
                "action.left_gripper": g_cmd[:1], "action.right_gripper": g_cmd[1:],
                "action.pivot": self.pivot_cmd()}

    def anomaly(self, est):
        if self.was_grasping and est["r_gripper"] < 0.3 * TH_GRIP:
            return "grasp_lost"                       # 抓取丢失
        if norm(est["F"]) > TH_HUMAN:
            return "external_push"                    # 异常外力 / 人推
        if self.stuck(est, self.prog):
            return "blocked"                          # 卡滞
        return None
```
