# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~301；灵感循环第 4 轮；本轮灵感：「研究空白」×「人形机器人」）

> R73 把 GAUGE 从认知层/具身层推进到「模块契约 + 组合代数」：MMS（证据契约 EC）/ DPEM（深度六分量）/ CCA（SER-PAR-VETO）/ ΣREFLEX（通道化反作用）/ CPB（主张-证明绑定）/ J_MOD（组合证书）。它把「全系统审计」的负担转移到了两处：**(a) 契约的表达力**、**(b) 隐共享物理过程下的一致性审计校准**。R73 自己写下了最尖锐的警告——系统可能**每个模块证书都有效、每条组合校验都通过，却自信地组合出一个错误的世界**，而审计日志证明「每一步都合规」。
>
> 本轮不修补这个风险，而是**把它升格为理论对象**。两个灵感正好构成一对：
> - **研究空白** → 不再只把「空白」当文献综述里的一句 motivation，而是形式化为**认证缺口（certification gap）**：系统必须携带**负证书（Gap Certificate）**，显式声明「我在哪些状态/动作上不敢声称安全、这片区域有多大、见证是什么、何时过期」。CPB 扩展为 **CPG（Claim-to-Gap binding）**：每条主张不仅绑定证明，还必须绑定**证伪边界与缺口台账**。
> - **人形机器人** → 它是模块独立性最彻底的反例：浮基、共享自由度、接触、能量/热/功率总线。R73 的 CCA 假设「串联加性、并联近独立」，但人形全身雅可比会在近奇异姿态把局部不确定度**任意放大**，产生任何单一模块内部都不存在的**涌现缺口（emergent gap）**——每块模块都合格，整机却不可认证。
>
> 核心命题：**不再问「证据能否可组合地保持安全」，而问「认证缺口能否被显式表示、单调传播、并被主动收敛或被保 viability 的退化所包含——使人形机器人知道自己在哪里不可认证，并在那里仍然活着？」** 把 R73 的计量契约代数重构为 **GAP-GAUGE-RAS**（Gap-aware, Whole-body metrology with GAUGE audits for RAS）——**缺口计量学**。

## 0. 直觉与动机

**灵感 1（研究空白 → 负证书：把「不知道」做成可审计的一等公民）**
直觉：科学论文的「future work / limitation」段是研究空白的软表达，但它不可执行、不可组合、不可追责。工程认证里真正危险的从来不是「已知失效」，而是**未被声明的失效**——系统在一大片状态上其实没有任何证据，却因为「没报错」而被当成安全。所以研究空白的第一性形式不是「哪里还没人做」，而是「**当前主张的证明覆盖不到哪里**」。R73 的 CPB 只绑定「主张 → 证明」，缺了一半：**主张 → 缺口**。一张只有证据、没有缺口的证书是**不完整因而危险**的证书，因为读者无法区分「已经证明安全」与「还没来得及检查」。因此：Gap Certificate 必须形如（主张，已认证域，缺口流形，见证，缺口测度，包含方式，过期预算，过近似方法）；组合证书 J_MOD 升级为 J_GAP = J_MOD ⊗（每条主张的负证书）。这把 R73 的 biggest risk 从「隐藏假设」变成「必须公开申报的负债」。

**灵感 2（人形机器人 → 模块独立性的破产：共享物理总线与雅可比放大）**
直觉：一个机械臂的腕部相机坏了，可以 stub 它、降级抓取；一个人形机器人一条腿的接触估计变差，**不能 stub 这条腿**——因为你无法「局部地」保持平衡。平衡、动量、地面反作用、力矩/功率/热预算，都是**共享物理总线**上的量：任何模块的不确定度都通过全身雅可比 `J_i = ∂Φ/∂x̂_i` 耦合进同一个整机状态。近奇异构型（伸直腿、手臂远伸、接触切换瞬间）`||J_i||` 可以很大，于是 `J_i Σ_i J_iᵀ` 远超 `Σ_i`——**局部小不确定度 → 整机大不确定度**。R73 的 CCA 串联用 `u_out ≥ u_A + L_B u_A` 是标量、加性、且隐含「模块之间没有共享状态」；并联用「|ρ̂|<ρ_max 才缩窄」处理了两两相关，却没有处理**由身体运动学/动力学强制的结构性相关**。因此人形需要第二层图：**物理耦合超图 H_body**（超边 = CoM / 动量 / 地面反作用 / 关节力矩 / 功率 / 热），以及耦合组合算子 **COMP-COUPLE** 的协方差输运与放大因子 κ。模块图的 DAG 只保证**信息流**合法；H_body 保证**物理流**合法——两张图都必须过审。

**灵感 3（研究空白 × 人形机器人 → 涌现缺口：每个模块都对，整机却错）**
直觉：把灵感 1 和 2 相乘，就得到本轮最核心、也最危险的对象——**涌现认证缺口**。定义：一个状态-动作对 `(x,u)`，若 (i) 所有相关模块的契约域都满足、(ii) 每张模块证书都有效、(iii) 所有 R73 组合校验都通过，但 (iv) 耦合输运后的整机协方差违反风险界，或整机 viability 裕度 γ 低于阈值——则它属于涌现缺口。它是「组合正确性」的补集：**R73 的组合代数证明了「不会凭空变好」，但没有证明「不会凭空变坏」**。humanoid 恰好提供了构造性反例（近奇异姿态）。所以本轮必须把「缺口」作为组合运算的输出之一，且它**只会扩张、不会自发收缩**（缺口单调性），除非由外部证据（标定/测量/新模块）给出闭合证书。

**灵感 4（缺口的两种合法处置：减小 vs 包含 —— 人形只能更多靠「包含」）**
直觉：对缺口你可以做两件事：**减小它**（补数据、加标定、改进模型 → GDAC 主动认证），或**包含它**（承认这片区域不可认证，但保证落进去时系统退化到一个残余风险 ≤ ε 且仍然 viability 的姿态）。机械臂上「包含」容易（松手、停住）；人形上「包含」必须**保持不倒**：站 → 撑（用手扶） → 跪/蹲（降低 CoM） → 坐 → 保护性跌倒 → 安全停。这就是 **VPD（Viability-Preserving Degradation）退化格**：越深一层，viability 集越大、任务能力越小、残余风险越低，三者沿格单调。R73 的 stub（模态置空）在这里不适用——人形退化是**全身姿态的重新协商**，不是**模态的移除**。缺口 + VPD 一起，才能给出「缺口非空时的安全主张」：`safe ⇔ 缺口被 VPD 包含 ∨ 缺口不可达`。

**灵感 5（把 R73 的 CPB 蒸馏纪律升级为 CPG + 研究缺口台账）**
直觉：R73 要求每个组件绑定一条主张，否则降级为工程附件。本轮再加一列：**每条主张必须申报自己的缺口**（覆盖域、缺口过近似、包含层级、过期版本）。研究缺口台账（Research Gap Ledger, RGL）是**可被审稿人/红队直接攻击的对象**：审稿人问「你的保证在分布外成立吗」，答案是「不宣称成立——这是缺口，这是见证，这是包含它的退化级，这是它的过期预算」。这把「局限」从文章末尾的软话，变成证书里的一条硬字段。同时它天然定义下一轮的研究议程：**缺口质量最大的地方，就是下一步该做的研究**——研究空白从「文献属性」变成「系统运行时产生的、可测量的、可优化的信号」。

## 1. 形式化定义（增量：定义 383–400）

**定义 383（GAP-GAUGE-RAS 总览）** GAP-GAUGE-RAS = (MMS†, DPEM†, CCA⁺, ΣREFLEX†, GCERT, HBODY, WBVM, VPD, GDAC, CPG, J_GAP)。在 R73 五不变式上扩展为六不变式：
(i) **契约完整性**（继承 R73）：无 EC 不入图；
(ii) **组合单调性**（继承 R73）：无「凭空变好」路径；
(iii) **反作用通道完备**（继承 R73）：ΣREFLEX 预算闭合；
(iv) **主张-缺口完备**（新增）：每条主张必须同时绑定证明与负证书（缺口流形 + 包含方式 + 过期预算），缺一即 J_GAP 无效；
(v) **物理耦合合法性**（新增）：H_body 上每条物理超边的守恒/约束必须被至少一个模块的 WBEC 覆盖，否则整机不可认证；
(vi) **严格退化链扩展**（升级）：模块级失效 → stub（R73）；**整机 viability 受胁 → VPD 退化格逐级下降，且每一级保持 viability 单调**；安全侧只增不减。

**定义 384（缺口证书 GCert）** 对主张 C，GCert_C =（C, D_C, G_C, W_C, μ_C, κ_C, E_C, m_C）：
- D_C ⊆ S×A：**已认证域**（该域内 C 的证明有效）；
- G_C ⊆ S×A：**认证缺口**，要求在给定可达集过近似下 ⊇ 真正未认证区域；
- W_C：缺口见证族（有限个可复算的入/出例，红队可攻击）；
- μ_C：缺口测度（默认对可达分布加权质量，亦可为最坏情形计数）；
- κ_C：包含映射（把 G_C 的每个可达点映到某个 VPD 层级，或标为「不可达」）；
- E_C =（契约版本, 校准集版本, 过期步数预算, 漂移触发条件）；
- m_C ∈ {HJ-reach, interval, occupancy, sampled-witness}：缺口过近似方法（必须在证书中显式，因为它是新的证明负担来源）。
**不完整证书**（缺 W_C 或 m_C）不得进入 J_GAP——「有证据无缺口」与「有缺口无证据」一样非法。

**定义 385（缺口流形与缺口质量）** G_C = (Reach^{over}(S_0) ∩ (S×A)) \ D_C，其中 Reach^{over} 是可达集的**过近似**（Hamilton-Jacobi / 区间 / 占据栅格），D_C 是已认证域的**欠近似**。二者方向相反，保证 G_C 是真实未认证集的过近似 → 风险记账保守。缺口质量 μ_C = ∫_{G_C} w(x,u) dμ，w 为任务/人类接近度权重（人机共存时靠人越近权重越高）。

**定义 386（物理耦合超图 H_body）** H_body = (X, ℰ, Φ, J)：X 为整机状态（浮基位姿、关节 q/q̇、接触集、能量状态）；ℰ 为物理超边集，每条超边 e 表示一个**共享物理量**（CoM、线/角动量、地面反作用旋量、关节力矩上界、功率、热）；Φ_e: Π_i X_i → X_e 为模块估计到共享量的映射；J_{e,i} = ∂Φ_e/∂x̂_i。**关键**：H_body 不是信息流图（那是 MReg），而是**物理守恒/约束图**；两条图必须同时过审。超边标签给出该守恒量的**不确定性预算**（例如 CoM 的 σ 预算、能量预算）。

**定义 387（全身证据契约 WBEC）** WBEC = EC ⊕ (σ_couple, J_spec, V_pred, e_edges)：在 R73 的 EC 上增加：耦合签名 σ_couple（该模块对哪些物理超边贡献不确定度）、雅可比规格 J_spec（解析或界）、viability 谓词 V_pred、覆盖的物理超边集 e_edges。WBEC 是能进入 H_body 的模块的必要条件；普通 EC 模块只能在 H_body 之外做纯感知/记录。

**定义 388（耦合组合算子 COMP-COUPLE 与放大因子）** 给定模块估计 x̂_i、协方差块 Σ_i、跨模块块 Σ_ij（共享过程：同一 IMU 偏置、同一地面柔顺、同一温度场）：
Σ_x = Σ_i J_i Σ_i J_iᵀ + Σ_{i≠j} J_i Σ_ij J_jᵀ + Σ_model，
κ = max_i ||J_i||₂（放大因子）。**耦合抵抗子空间** R_κ = {v : ||J_iᵀ v||₂ ≤ (1+δ) ∀i}；在 R_κ 上 R73 的标量单调性仍成立，在补集上必须使用协方差界且**允许不确定度被放大**。COMP-COUPLE 输出 (Σ_x, κ, G_em)，其中 G_em 为涌现缺口（定义 389）。

**定义 389（涌现缺口）** G_em = {(x,u) : ∀i, (x,u) ∈ D_i ∧ cert_i 有效 ∧ R73 组合校验通过，但 [λ_max(Σ_x) > ε_C ∨ γ(x) < γ_min]}。即**逐模块合格而整机不合格**的区域。G_em 是 COMP-COUPLE 相对 R73 CCA 的**新增输出**；它不可能是任何单模块缺口的子集（构造性定理 33）。

**定义 390（全身 viability 计量 WBVM）** 输出 ViabilityEvidence =（capture point cp, ZMP, 接触力旋量锥 C_w, 裕度 γ, 裕度不确定度 Σ_γ）：
γ(x) = dist(cp, support_polygon) / √(λ_max(Σ_cp))（以不确定度为单位的边界距离，越小越危险）；
V_safe† = {γ − z_γ·√tr(Σ_γ) ≥ γ_min}。WBVM 是**不可 stub** 的模块：stub 它等于放弃整机 viability 主张（见定义 392）。

**定义 391（viability 裕度与风险界）** 整机执行风险界：Risk ≤ ε_cert · 1[(x,u)∈D_C] + ε_deg · 1[(x,u)∈G_C 且被 VPD 包含] + ∞ · 1[(x,u)∈G_C 且未包含]。最后一项是纪律：**未被包含的缺口不允许被赋予有限风险**——不允许用「大概没事」填补。

**定义 392（VPD 保 viability 退化格）** 退化格 L = {L0 站立/行走, L1 支撑（用手/环境扶）, L2 跪/蹲（降 CoM）, L3 坐, L4 保护性跌倒（收头/护关节）, L5 安全停}。每级定义 (V_k, Task_k, Risk_k)：
- V_0 ⊆ V_1 ⊆ … ⊆ V_5（viability 集单调扩张）；
- Task_0 ⊇ Task_1 ⊇ … ⊇ Task_5（任务能力单调收缩）；
- Risk_0 ≥ … ≥ Risk_5，且 Risk_5 ≤ ε_safe。
退化函数 degrade(x, VEv)：返回最小的 k′ > k 使 x ∈ V_{k′} 且 Risk_{k′} ≤ ε_safe；不存在则 L5 + 硬停。**单调性引理见引理 40。**
与 R73 stub 的区别：stub 移除**模态**；VPD 重新协商**全身姿态**。人形不能局部退场，只能整体换一个「还站得住」的平衡点。

**定义 393（缺口传播规则）** 对任意组合：
- **Gap-SER**：G_out ⊇ G_A ∪ Φ_B^{-1}(G_B)（后者为 B 的缺口在 A 输出空间的原像）；
- **Gap-PAR**：G_out ⊇ G_A ∪ G_B ∪ {跨模态残差 r ∉ C_α}（审计失败区同样是缺口，不能只当保守界）；
- **Gap-VETO**：G_out ⊇ G_A ∪ G_B ∪ {任一否决触发区}；
- **Gap-COUPLE**：G_out ⊇ π_J(∪G_i) ∪ G_em ∪ {κ > κ_max}，其中 π_J 为缺口经雅可比的像。
**缺口单调性（引理 39）**：任何组合都只能使缺口集合包含式扩大；无闭合证书时不可能缩小。

**定义 394（缺口导向主动认证 GDAC）** 给定主张 C、缺口证书 GCert_C、预算 B_info、候选动作集（走位/换视角/触碰标定物/改变负载/主动激励）：
a* = argmax_{a} E[μ_C(G_C) − μ_C(G_C^{(a)})] / cost_info(a)，
s.t. Σ cost_info ≤ B_info ∧ 新证据经 conformal/SEAL 校准。
**次模性**：缺口质量对证据动作的边际下降非增（见引理 41）⇒ 贪心有 (1−1/e) 近似保证。GDAC 与 R73 的 PVOP 对偶：PVOP 为**任务**选动作以最大化证据质量；GDAC 为**认证**选动作以最大化缺口缩减（或为包含争取时间）。

**定义 395（主张-缺口绑定 CPG 与研究缺口台账 RGL）** CPG 表（组件 → 主张 → 基准 → 消融 → 指标 → **缺口列**）：
- C1 物理感知证据计量 ← (DPEM†, DMEM†) ← MB1 ← AB1 ← (ECE, 覆盖率, 碰撞率, 误抓率) ← 缺口：材质连续谱/超距外；
- C2 反作用预算组合 ← (ΣREFLEX†, PVOP†) ← MB2 ← AB2 ← (交互次数, 人类负担, 停止方差) ← 缺口：极端入射角/近场 χ_v 失真；
- C3 契约式模块化 ← (MMS†, CCA, J_MOD†) ← MB3 ← AB3 ← (逐指令等价, 认证成本比, 迁移行数) ← 缺口：跨本体雅可比差异；
- C4 全身耦合与缺口计量 ← (GCERT, HBODY, CCA⁺, WBVM, VPD, GDAC) ← MB4 ← AB4 ← (涌现缺口检出率, κ 界紧致度, VPD 包含率, 缺口感知风险) ← 缺口：耦合交叉协方差建模误差/可达集过近似粗糙。
**RGL** 是 CPG 缺口列的可执行表：每行 =（主张，缺口过近似方法，缺口质量，包含层级，过期版本，最后复验时间）。RGL 未申报缺口的主张视为无效主张。

**定义 396（缺口闭合与过期）** 闭合证书 closure_C =（新证据源，覆盖的新区域，conformal 覆盖保证，复验结果）。闭合算子 Close：G_C ← G_C \ NewCovered，且必须同时更新 D_C 与 E_C。**过期**：若漂移触发（温度/负载/本体/固件变更）或超过过期步数，则 D_C 回退到该证据源上次校准时的域（不得沿用旧覆盖）——缺口**只会因过期而变大**，绝不会因时间流逝而变小。

**定义 397（缺口感知风险 J_GAP）** J_GAP = J_MOD ⊗ (⊗_{C} GCert_C)。Valid(J_GAP) ⇒（各模块 cert 有效）∧（MReg 组合校验）∧（H_body 物理耦合校验）∧（每条主张的缺口被 VPD 包含或标为不可达）∧（缺口未过期）。**未包含且可达的缺口 ⇒ J_GAP 无效 ⇒ 不允许输出「安全」结论**，只能输出「未认证」。

**定义 398（缺口感知 MReg 审计与结构上限）** 每轮审计新增三项：H_body 超边覆盖检查、缺口单调性检查（G 不得缩小而无闭合证书）、VPD 层级合法性检查（k′ 必须使 x ∈ V_{k′}）。结构上限扩展：|V_M| ≤ 32、组合深度 ≤ 5、|ℰ_body| ≤ 12、|L| = 6、|G_C 的见证| ≤ 64、κ ≤ κ_max——全部为可审计图/数值性质。人形允许比 R73 的 |V_M|≤24 稍大，但新增的 H_body 约束必须闭合。

**定义 399（人形威胁面 AIC-HUMANOID）** ℰ_humanoid = {近奇异姿态诱导的耦合放大攻击（把机器人逼到伸直腿/远伸臂）、接触切换瞬态欺骗（在支撑切换时注入接触假象）、共享过程投毒（同时污染 IMU 与深度，使两模块「一致地错」从而绕过 PAR 审计）、VPD 误触发（伪造 viability 裕度逼机器人跌倒）、能量/热耗尽型慢攻击、人流逼近（把缺口权重 w 抬高）}。防线：H_body 超边独立见证（力/热/电不应全部来自同一估计器）、涌现缺口主动探测（GDAC）、VPD 触发需多源确认、单源不定案（继承 E356/E357）。

**定义 400（缺口认证成本 CertGapCost 与研究空白驱动纪律）** CertGapCost = Σ_主张 (缺口过近似计算 + 见证复算 + 包含校验) + H_body 覆盖校验 + 过期检查。C4 的可证伪形式：缺口感知审计相对全系统重认证的额外成本 ≤ 预注册上限，且能检出人工注入的、所有模块都合格但整机失效的涌现缺口。**研究空白驱动纪律**：每轮必须报告 RGL 中 μ_C 最大的三条缺口，并说明它们对应的下一轮研究动作——研究议程由运行时缺口信号生成，而非由作者偏好生成。

# IP-302 GCert：缺口证书（负证书）
@dataclass(frozen=True)
class GapCertificate:
    claim: str                      # 服务的主张 C1..C4
    covered: Domain                 # 已认证域 D_C（欠近似）
    gap: Domain                     # 认证缺口 G_C（可达集过近似 ∩ ¬D_C）
    witness: Tuple[State, ...]      # 缺口见证（可复算，红队可攻击）
    measure: Callable               # μ_C：缺口质量（人机接近度加权）
    containment: Containment | None # 缺口 → VPD 层级的包含映射
    expiry: Tuple[str, int, float]  # (契约版本, 过期步数, 漂移预算)
    method: str                     # 'HJ-reach' | 'interval' | 'occupancy' | 'sampled'

# IP-303 HBody：物理耦合超图与协方差输运
class CouplingHypergraph:
    EDGES = ('com', 'momentum', 'ground_reaction', 'joint_torque', 'power', 'thermal')
    def transport(self, ests, blocks, model):
        J = [self.jacobian(i) for i in ests]        # J_i = ∂Φ/∂x̂_i
        S = sum(Ji @ Si @ Ji.T for Ji, Si in zip(J, blocks.diag))
        S += sum(Ji @ Sij @ Jj.T for i, j, Sij in blocks.cross)  # 共享物理过程
        S += model.Sigma_model
        kappa = max(norm(Ji, 2) for Ji in J)          # 放大因子
        return S, kappa

# IP-304 CCA+：耦合组合（扩展 R73 的 SER/PAR/VETO）
def compose_plus(a, b, op, audit, hbody):
    if op in ('SER', 'PAR', 'VETO'):
        ev = compose_r73(a, b, op, audit)             # R73 保守下界
        ev.gap |= a.gap | b.gap                        # 缺口只增
        return ev
    if op == 'COUPLE':
        S, kappa = hbody.transport([a.est, b.est],
                                   [a.Sigma, b.Sigma, a.cross(b)], MODEL)
        emergent = (kappa > KAPPA_MAX) or (viability_margin(S) < GAMMA_MIN)
        return Ev(u=sqrt(trace(S)), D=a.D & b.D, Sigma=S, kappa=kappa,
                  gap=a.gap | b.gap | ({'EMERGENT_COUPLING'} if emergent else set()))

# IP-305 WBVM：全身 viability 计量（不可 stub）
class WholeBodyViabilityMetrology:
    def update(self, q, qd, contacts, Sigma_contact):
        cp  = capture_point(q, qd)
        zmp = zmp_from_contacts(contacts)
        C_w = contact_wrench_cone(contacts, Sigma_contact)   # 接触力旋量锥

        return ViabilityEvidence(gamma=gamma, Sigma=S_gamma,
                                 safe=(gamma - Z_GAMMA * sqrt(trace(S_gamma)) >= GAMMA_MIN))

# IP-306 VPD：保 viability 退化格
LADDER = ['stand', 'brace', 'kneel', 'sit', 'protected_fall', 'safe_stop']
def degrade(level, x, v_ev):
    for k in range(level + 1, len(LADDER)):
        if viability_ok(LADDER[k], x, v_ev) and residual_risk(LADDER[k]) <= EPS_SAFE:
            return k, LADDER[k]
    return None, 'safe_stop'                         # 无合法层级 → 硬停

# IP-307 GDAC：缺口导向主动认证（与 PVOP 对偶）
def gap_directed_certify(gcert, budget, candidate_actions):
    best = None
    for a in candidate_actions:                      # 走位/换视角/触碰标定物/主动激励
        d_gap = expected_gap_reduction(gcert, a)      # 解析 χ 通道 + 可达集过近似
        c = information_cost(a)
        if budget.can(a, c) and (best is None or d_gap / c > best.score):
            best = Action(a, d_gap, c, score=d_gap / c)
    return best                                      # 次模 ⇒ 贪心 (1−1/e)

# IP-309 GAP-GAUGE 主闭环（人形整机）
def GAPGAUGE_round(M, obs, depth, tact, q, qd, contacts):
    # === 感知/计量域 ===
    d_ev = M.dpe.update(depth, M.rgb, M.cam_state, M.motion, M.peers)
    t_ev = M.dmem.update(tact, M.last_g)
    v_ev = M.wbvm.update(q, qd, contacts, t_ev.Sigma_contact)          # IP-305
    S_x, kappa = M.hbody.transport([d_ev.est, t_ev.est, v_ev.est],
                                   [d_ev.Sigma, t_ev.Sigma, v_ev.Sigma, M.cross],
                                   M.model)                             # IP-303
    gaps = M.gcert.estimate(M.claims, S_x, kappa)                       # 缺口过近似

    M.mreg.audit_gap(gaps)                                              # 缺口单调性 + H_body

## 3. 推导

**引理 38（耦合放大界与逐模块界的不足）** 设 `Σ_x = Σ_i J_i Σ_i J_iᵀ + Σ_{i≠j} J_i Σ_ij J_jᵀ + Σ_model`。则 `λ_max(Σ_x) ≤ (Σ_i ||J_i||₂ √λ_max(Σ_i) + Σ_{i<j} ||J_i||₂ ||J_j||₂ √λ_max(Σ_ij))² + λ_max(Σ_model)`；且存在方向 v 使 `vᵀΣ_x v ≥ ||J_iᵀ v||₂² λ_min(Σ_i)`。⇒ 当 `||J_i||₂` 大（近奇异构型）时，任何仅由 `λ_max(Σ_i)` 给出的逐模块界都无法界定整机 `λ_max(Σ_x)`。系：**逐模块证书全有效 ⇏ 整机有界**——这是「涌现缺口」的解析根源，也是人形对 R73 加性 CCA 的直接反例。**

**引理 39（缺口单调性：组合不产生免费认证）** 对 SER/PAR/VETO/COUPLE，按定义 393 的传播规则，`G_out ⊇ ∪_i G_i`，且 COUPLE 额外并入 `G_em` 与 `{κ>κ_max}`。仅当存在闭合证书 closure 时 `G` 才可缩小；闭合证书必须携带新证据源与复验结果。⇒ **缺口只能被证据缩小、不能被组合缩小**；被时间/漂移侵蚀时只能变大（定义 396）。系：R73 的「组合不产生认知免费午餐」升级为「**组合不产生认证免费午餐**」。

**引理 40（VPD 的 viability 单调性与安全性）** 退化格 L 的构造保证 `V_0 ⊆ … ⊆ V_5`、`Task_0 ⊇ … ⊇ Task_5`、`Risk_5 ≤ ε_safe`。若 degrade 返回 k′，则 `x ∈ V_{k′}` 且 `Risk_{k′} ≤ ε_safe`；若返回 None 则走 L5 硬停（最保守）。归纳于 k′：每次下降都不减少 viability、不增加残余风险上界。系：**人形退化是「能力换 viability」的单调交易**，而不是 R73 的模态移除；它使「缺口非空时仍可声称安全（在包含意义下）」。

**引理 41（GDAC 的次模性与贪心保证）** 缺口质量 `μ_C(G_C)` 对证据动作集的边际下降非增（新增证据对已覆盖区域的增益递减，且可达集过近似只会因新证据收缩）⇒ `μ_C` 的缩减函数是次模的。在预算约束下，贪心选择达到最优缺口缩减的 `1−1/e` 近似。系：**研究空白可以被「按性价比主动收敛」**，且收敛有理论保证；GDAC 与 PVOP 对偶（任务 vs 认证）。

**引理 42（缺口证书的可靠性条件）** 若 (i) `Reach^{over}` 是真实可达集的过近似；(ii) `D_C` 是真实已认证集的欠近似；(iii) 见证族 W_C 覆盖 `G_C` 的每个连通分量；(iv) 过期/漂移检查有效，则 `G_C` 是真实未认证集的过近似。配合 VPD 包含，`Risk ≤ ε_cert`（D_C 内）+ `ε_deg`（包含的缺口内），未包含缺口风险记为 ∞（定义 391）。系：**证明负担从「契约表达力」转移到「可达集过近似 + 耦合交叉协方差 + 见证覆盖」——更显式、更可攻击、更可实验证伪。**

**定理 30（GAP-GAUGE 严格包含 MODGAUGE）** 取 `G_C = ∅`、`H_body` 为空（`J_i = I`、`Σ_ij = 0`）、`L = {L0}`、`κ_max = 1`：GAP-GAUGE 逐指令退化为 R73 的 MODGAUGE；进一步 stub 深度/接触与无缺口申报，退化为 R72/R71/R68。且对非空缺口/非平凡耦合，GAP-GAUGE 给出 R73 无法表达的保守结论（未认证或 VPD 包含）。**安全侧严格不减，表达力严格增强。**

**定理 31（缺口感知风险可靠性：无隐藏缺口）** 若 `Valid(J_GAP)` 且引理 42 的条件成立，则实际执行风险 ≤ `ε_cert + ε_deg`（缺口被包含时），或系统拒绝输出安全结论（缺口可达且未包含时）。反之，若存在可达且未申报的缺口，则 J_GAP 审计因「缺口单调性 + H_body 覆盖 + RGL 完备性」失败。⇒ **R73 的「所有模块都对、整机却错」不再能通过审计**：它必须被申报为 G_em 并被 VPD 包含，否则证书无效。这是把 R73 biggest risk 制度化的直接结果。

**定理 32（VPD 下整机 viability 的保持）** 在引理 40 与 WBVM 校准有效（A114：γ 的尾部校准成立）下，任意从 L0 到 L5 的退化序列都保持 viability 单调（V 单调扩张）且残余风险非增；因此「缺口包含」不会把系统从「可能不安全」变成「确定不安全」。证明：沿格归纳 + 每级 `x ∈ V_k` 与 `Risk_k ≤ ε_safe` 的构造性校验。系：**人形可以在不可认证的区域里安全地「不做那件事」，而不是冒险继续。**

**定理 33（涌现缺口的存在性与逐模块审计的不足）** 存在人形构型序列 `x_n` 与模块估计，使每个模块的 `(x_n,u)` 都满足其契约域、证书有效、R73 组合校验通过，但 `||J_i(x_n)||₂ → ∞`，从而 `λ_max(Σ_x) → ∞`，`γ(x_n) < γ_min`。由引理 38 与定义 389，`(x_n,u) ∈ G_em` 且 `G_em ⊄ ∪_i G_i`。⇒ **任何仅检查模块内部与 R73 组合的审计都无法发现该缺口**；必须显式建模 H_body 与 κ。这是 C4 主张的可证伪核心（E392/E400）。

## 6. 本轮最大风险

**一句话**：GAP-GAUGE 把 R73 的隐性风险显式化为「缺口」，但并没有消除它——它只是把不可证的负担从「契约表达力」转移到了**耦合交叉协方差 Σ_ij 与可达集过近似 Reach^{over}**；如果这两者被低估（共享物理过程比建模的更相关、可达集抽象太粗、或见证族没覆盖缺口的某个连通分量），系统就会持有一份「缺口为空/已被包含」的**合法负证书**，从而在审计完全合规的情况下，**把一个真实存在的涌现缺口认证成了安全**——缺口证书本身成了新的、更有说服力的「自信地组合出错误世界」的方式。

次级风险与缓解：
1. **缺口过近似不可计算（人形状态维数高）** → 分级抽象（任务相关子空间 + 区间包络）+ 采样见证兜底 + 显式记录方法 m_C 与其失效域。

4. **κ 界过松使缺口爆炸、系统过度保守** → 分姿态/分任务细化的 κ 界 + 缺口导向标定（GDAC）主动收紧。
5. **GDAC 次模性不成立（证据动作相互作用）** → 预注册检查次模性；不成立时退回枚举小候选集并报告近似缺口。

## 4. 推导

**引理 38（耦合放大界）** `Σ_x = Σ_i J_i Σ_i J_iᵀ + Σ_{i≠j} J_i Σ_ij J_jᵀ + Σ_model`，则 `λ_max(Σ_x) ≤ (Σ_i ||J_i||₂√λ_max(Σ_i) + Σ_{i<j}||J_i||₂||J_j||₂√λ_max(Σ_ij))² + λ_max(Σ_model)`；且 `∃v: vᵀΣ_x v ≥ ||J_iᵀv||₂²λ_min(Σ_i)`。近奇异处 `||J_i||₂→∞` ⇒ 逐模块界不足以界定整机。系：**涌现缺口的解析根源。**

**引理 39（缺口单调性）** 按定义 393，`G_out ⊇ ∪G_i`，COUPLE 额外并入 G_em 与 `{κ>κ_max}`；只有闭合证书能缩小缺口。⇒ **组合不产生认证免费午餐**；过期只能使缺口变大。

**引理 40（VPD viability 单调）** `V_0⊆…⊆V_5`、`Task_0⊇…⊇Task_5`、`Risk_5≤ε_safe`；degrade 返回 k′ ⇒ `x∈V_{k′}` 且 `Risk_{k′}≤ε_safe`，否则硬停。⇒ 人形退化是「能力换 viability」的单调交易。

**引理 41（GDAC 次模 + 贪心）** 缺口质量对证据动作的边际缩减非增 ⇒ 次模；预算约束下贪心达 `1−1/e`。⇒ 研究空白可被按性价比主动收敛。

**引理 42（负证书可靠性）** Reach^{over} 过近似 + D_C 欠近似 + 见证覆盖每个连通分量 + 过期有效 ⇒ `G_C` 是真实未认证集的过近似；配合 VPD 包含得 `Risk ≤ ε_cert + ε_deg`，未包含缺口风险为 ∞。⇒ **证明负担转移到「可达集过近似 + 交叉协方差 + 见证覆盖」——更显式、更可证伪。**

**定理 30（严格包含）** 取 G_C=∅、H_body 空（J_i=I, Σ_ij=0）、L={L0}、κ_max=1 ⇒ 逐指令退化为 R73 MODGAUGE，再退化为 R72/R71/R68。非空缺口/非平凡耦合时给出 R73 无法表达的保守结论。**安全侧严格不减，表达力严格增强。**

**定理 31（无隐藏缺口）** Valid(J_GAP) 且引理 42 成立 ⇒ 实际风险 ≤ ε_cert+ε_deg（缺口包含）或系统拒绝输出安全结论。存在可达且未申报缺口 ⇒ 审计（缺口单调性 + H_body 覆盖 + RGL 完备性）失败。⇒ **R73 的「模块全对、整机却错」必须被申报为 G_em 并被 VPD 包含，否则证书无效。**

**定理 32（VPD 下 viability 保持）** 在引理 40 与 WBVM 尾部校准（A114）下，任意 L0→L5 退化序列保持 V 单调扩张、残余风险非增。⇒ **包含缺口不会把「可能不安全」变成「确定不安全」；人形可以在不可认证区域里安全地「不做那件事」。**

**定理 33（涌现缺口存在性）** 存在构型序列 `x_n`：各模块契约域满足、证书有效、R73 组合校验通过，但 `||J_i(x_n)||₂→∞` ⇒ `λ_max(Σ_x)→∞`、`γ(x_n)<γ_min`；由定义 389，`(x_n,u)∈G_em` 且 `G_em ⊄ ∪G_i`。⇒ **仅检查模块内部与 R73 组合的审计无法发现它；必须显式建模 H_body 与 κ。** 这是 C4 的可证伪核心（E392/E400）。

## 7. 本轮最大风险

**一句话**：GAP-GAUGE 把 R73 的隐性风险显式化为「缺口」，但没有消除它——它把不可证的负担从「契约表达力」转移到了**耦合交叉协方差 Σ_ij 与可达集过近似 Reach^{over}**；如果这两者被低估（共享物理过程比建模更相关、可达集抽象太粗、见证族没覆盖缺口某个连通分量），系统就会持有一份「缺口为空/已被包含」的**合法负证书**，在审计完全合规的情况下把一个真实的涌现缺口认证成安全——**负证书本身成为更可信、更危险的「自信地组合出错误世界」的方式。**

次级风险与缓解：
1. **缺口过近似不可算（高维人形）** → 任务相关子空间抽象 + 区间包络 + 采样见证兜底 + 显式记录 m_C 失效域。
2. **交叉协方差低估** → 超边独立见证（力/热/电/视觉不同源）+ 共因审计 + 怀疑相关时禁 PAR 缩窄并强制缺口扩张。
3. **VPD 误触发/退化有害** → 多源确认 + 退化代价入风险界 + L4 保护性跌倒单独校准。
4. **κ 界过松致过度保守** → 分姿态/分任务细化 κ + GDAC 主动收紧。
5. **GDAC 次模性不成立** → 预注册检查；不成立时枚举小候选集并报告近似缺口。
6. **RGL 沦为免责声明** → 见证可复算 + 三方红队（E398）+ 未申报缺口一票否决。
7. **MB4 过拟合** → SEAL-MB4 密封保持集 + 预注册 + 三方复现（E409 回归）。
