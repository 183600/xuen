# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「多模态大模型」×「创新点挖掘」）

> 第 57 轮把承诺的根据从"证据承诺"细化为"少样本可校准、跨模态可对账、个性化有界"，但留下两个结构性缺口：**(a) 语义浅**——𝓜 里只有材质簇和手工特征，读不懂自然语言指令、开放词汇物体与"看起来像什么、可能因此发生什么"的常识；跨模态对账只能在事后发现分歧，无法事前提出"该去验证什么"，探针选择仍靠手设 VOI。**(b) 创新叙事化**——IP 清单逐轮增厚，却没有回答"哪一个机制真正承重、撤掉它安全界会变差多少；哪些只是界面变化、哪些与旧机制同义反复"。本轮两个灵感正好各补一刀：**多模态大模型**把开放语义与跨模态常识带进来，但只允许它当"提议者"——提出假设、排序探针、生成解释，绝不裁决证据；**创新点挖掘**从"再加一个模块"变成"在安全界的残差项上做有归因的机制设计"，每个创新点必须同时拿到可证伪预测、分离性证明与沙普利承重证书。核心命题升级为 **"少样本可校准、跨模态可对账、个性化有界、语义可接地、创新可归因的证据说可信"**。

核心矛盾：
- **H29（语义广度 vs 接地预算）**：多模态大模型能给出开放词汇的材质/可 affordance/风险假设，但这些命题天然未接地；逐条接地要花真实探针与时延，接地太少就继承幻觉，接地太多就吃光探询预算。语义的价值在于"少走弯路"，其代价必须可计量，否则它只是把"坏先验"换成"巧舌如簧的坏先验"。
- **H30（提议 vs 裁决 / 自证循环）**：若同一个模型既提出"这里是冰"又参与选择/解读"验证它是冰"的探针，就形成自我确认：它总能挑一个自己容易通过的测试。语义捕获（semantic capture）比单模态共谋更隐蔽——不是物理世界骗了它，而是它替物理世界出了题。
- **H31（创新 vs 可归因性）**：机制层层叠加，"新"可以来自真实的新承重项，也可以来自与旧机制同义、或只改界面不改安全界的装饰。没有残差定位与消融归因，创新点会通货膨胀；反过来，只追求"能发论文的新"又会脱离部署风险。

## 0. 直觉与动机

**灵感 1（多模态大模型 → 有想象力但不可当法官的"实习生"）**
直觉：多模态大模型像一位读过很多论文、能看图能读指令的实习生：它能说"这块湿瓷砖的纹理像抛光石材，遇水可能很滑""这个门把手看起来是下压式的，从当前末端姿态抓不住"，于是机器人不必对每个新区域都从零开始猜。但实习生也会一本正经地编造。正确的用法不是让它签字，而是让它**提案**：把它的语义先验当作探针排序的先验和解释的素材；一旦涉及"能不能接触/能不能承诺"，必须回到物理证据。语义扩大的是**假设空间**和**探询效率**，不是**证据权威**。

**灵感 2（命题-探针编译 → 波普尔式的接地契约）**
直觉：一个不能被任何探针证伪的语义命题，对承诺系统等于噪声。于是把每条语义命题编译成"假设 H1=该命题 / H0=其否定 + 一个可执行、非破坏的探针 + 一个判决统计量 + 一个似然比阈值"。更关键的是**双侧**：验证"它是冰"时，测试必须同时有区分"它不是冰"的能力；只与命题一致、不能与否定拉开距离的观测不算接地。再用**提议-验证分离**保证验证探针由独立的、标签对称的信息增益准则选出，而不是由提出命题的那一方挑选——不让它给自己的卷子打分。

**灵感 3（语义隔离区 → 只在"提议/加保守/解释"三个口子出现）**
直觉：不要靠提示词约束大模型"请勿越权"，而要用**类型与接口**约束：大模型输出的是 `Proposal`，证据门只接收 `Evidence`，二者之间没有强制转换。它的输出只允许流入三个汇：①重排合法探针（不新增集合外探针）；②作为异常信号**只抬高** P_fail（绝不降低）；③生成带证据标签的解释（未接地命题必须标注为假设）。这样"语义"在架构上根本没有加宽接受域的写权限。

**灵感 4（创新点挖掘 → 承重项，而不是新盒子）**
直觉：一个创新点若不能在安全界里指认一个残差项、并证明撤掉它该项变差，它就只是叙事。于是把创新挖掘做成四步：**残差优先**（先看部署界里哪一项 slack 最大/最不确定）→ **单调机制**（新机制只能经"信念更准"或"动作更保守"两个通道，继承第 57 轮单调性）→ **分离性**（可独立开关、不改决策规则本体与全局硬界）→ **沙普利归因**（在对抗留出集上估计该机制对安全边际的边际贡献，取置信下界；并检查旧机制的消融是否已解释同一效应，解释不了才算真新）。这同时允许我们诚实地**降级**一些旧"创新"：它们可能是体验创新而非安全创新。

**灵感 5（PCE++ → 语义只改探针顺序与解释，不改判决）**
直觉：语义 VOI 只用于在 `P_adm` 内部排序探针，接地预算 k_gnd 与探询预算并列受控；每个检查点先异步取提案，再按双侧信息增益接地，最后仍由第 57 轮的证据门裁决。语义最坏情况下的效果是"浪费了一点探针/时延"，而不是"让系统更敢赌"。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（多模态大模型语义提议器 MSP）** 提议器 π_ψ: (I, 𝓜, o_{≤t}; B_sem) → 𝒞_t，其中每条命题 c=(pred, r, q, fam, e)：pred 为开放词汇谓词（材质/可操作性/危险/物体/指令接地），r 为区域，q∈[0,1] 为自报置信（**不假设已校准**），fam⊆P_fam 为建议探针族，e 为解释草稿。接口契约：π_ψ 对 𝓜.core、阈值、证据权重、证据门**只读**；调用异步、版本钉死；输出类型固定为 `Proposal`；语义预算 B_sem=(n_sem,t_sem,cost_sem) 显式计入节拍。

**定义 140（命题-探针编译器与双侧接地 CPG）** 编译器 Γ: 𝒞 → 𝒯∪{⊥}，𝒯=(p\*,H1=c,H0=¬c,s,ι,λ_sem)，p\*∈P_adm（继承 A34 非破坏过滤）。验证探针按**标签对称信息增益**选取：p\*=argmax_{p∈P_adm} I_p(S;H1,H0)，要求 ι_{p\*}≥ι_min，且排序只依赖 H1/H0 的对称统计量（不因"把谁当正例"而变），从而实现提议-验证分离。执行后对数似然比 ℓ=log[P(s|H1)/P(s|H0)]。接地状态 g(c)∈{U（不可证伪）,C（已编译未决）,G+（支持）,G−（反驳）}；仅 G± 需 |ℓ|≥λ_sem。接地错误率 ≤δ_ground；接地成本 ≤B_gnd（条数 k_gnd、探针 k_gprobe）。U 命题权重恒为 0，只能进解释且必须标注为假设。

**定义 141（语义隔离区 SQ）** 任何 π_ψ 输出只能进入三个 sink：(a) ProposalSink——在 P_adm 内部重排探针，**不得新增 P_adm 之外的探针**；(b) AnomalySink——只能令 P_fail' = max(P_fail, f_sem(𝒞))，即只增不减，并可触发保守回退；(c) ExplanationSink——按命题逐句挂证据节点，未接地语句必须渲染为"假设"。禁止：写 𝓜.core/阈值/证据权重；选择自己的接地验证探针；作为不可逆接触的唯一必要证据。形式化不变量：对任意未达 G+ 的语义输出集合，决策函数满足 D(𝓜,EV∪sem)=D(𝓜,EV)；G+ 语义只允许以受限权重进入 L1 佐证。

**定义 142（安全沙普利归因与创新点证书 SSA/IPC）** 机制集 M={m_1,…,m_K}，联盟价值 v(S)=在对抗留出集上仅启用 S 时的期望安全边际（或 1−P_safe）。沙普利值 φ_i=Σ_{S⊆M\{i\}} |S|!(K−|S|−1)!/K!·[v(S∪{i})−v(S)]，用置换采样+自助法取置信下界 LCB(φ_i)。**残差优先挖掘算子 RIM**：①按部署界逐项估计 slack 与不确定性，取主导残差项 τ\*；②只提出经"信念校准/动作保守"两通道且与 τ\* 对齐的候选机制 Δ；③分离性过滤：Δ 可独立开关、不改决策规则本体与全局硬界；④归因：LCB(φ_Δ)≥τ_attr 且目标项实际下降 ≥Δ_τ；⑤非包含性：把 Δ 的效应对旧机制做消融回归，残差 ≥θ_nov 才算"新"，否则判为冗余/体验创新。**IPC**=(机制, 目标残差项, 分离性证明, LCB(φ_Δ), 非包含性残差, 可证伪预测, 消融方案)。承重（load-bearing）⇔ LCB(φ_Δ)≥τ_attr ∧ 目标项下降 ≥Δ_τ。

**定义 143（语义证据门 FSE+ 与证书 J_q）** 证据类扩为六类：EV-probe\*/EV-visit/EV-margin/EV-xmodal（限 L1）/EV-human/**EV-sem**。EV-sem 条件：g(c)=G+ ∧ 双侧 ∧ 提议-验证分离（ι≥ι_min）∧ 权重上限 w_sem≤w_sem^max<1 ∧ 仅 L1 ∧ 非不可逆接触。不可逆接触必要证据集仍为 {EV-probe\*∨EV-margin}∪佐证，**显式排除 EV-xmodal 与 EV-sem**。J_q=J_p + (mllm_version, B_sem, claim_ledger, grounding_log, grounding_cal_log, ipc_ledger, explanation_coverage)；L2 解释要求接地覆盖率 ≥ρ_exp。

**定义 144（探-诺-演++ PCX+）** 每检查点：①若 B_sem 允许，异步取 𝒞_t；②按语义 VOI 取前 k_sem 条编译；③用独立双侧验证探针在 B_gnd 内接地；④在 P_adm 内用"物理 VOI + 已接地语义 VOI"排序执行探询（语义只排序）；⑤仍由 FSE+ 裁决是否承诺；⑥生成解释并校验接地覆盖率；探尽/接地尽→绕行→降档→L2 协商或安全停。终止于 k_probes+k_cons+k_gprobe，语义最坏只增加预算消耗，不改变接受域。

## 2. 关键算法伪代码（完整版见产物区）

```python
def semantic_propose_and_ground(M, r, ctx, budget):
    claims = mllm.propose(ctx, M, budget.sem)          # 只读 𝓜，类型=Proposal
    claims = rank_by(claims, q)                        # 仅排序，不改证据
    ledger = {}
    for c in claims[:budget.k_sem]:
        T = compile_claim(c)                           # c -> (p,H1,H0,s,iota,lambda)
        if T is None:
            ledger[c.id] = ('U', 0.0); continue        # 不可证伪 -> 零证据权重
        p = select_verifier(T, P_adm)                  # 双侧信息增益，label-symmetric
        if T.iota < IOTA_MIN or physical_voi(p) < THETA_GND:
            ledger[c.id] = ('C', 0.0); break
        s = execute_probe(p, cap=F_abs)                # A34 非破坏
        l = T.log_lr(s)
        if abs(l) >= T.lambda_sem:
            ledger[c.id] = ('G+' if l > 0 else 'G-', l)
        else:
            ledger[c.id] = ('C', l)                    # 未决：只允许抬高不确定
        budget.spend(p)
    return ledger

def semantic_quarantine(claims, sink):
    assert sink in ('proposal', 'anomaly_raise', 'explanation')
    if sink == 'proposal':     return reorder_within(P_adm, claims)
    if sink == 'anomaly_raise':return {'P_fail': max(P_fail, f_sem(claims))}
    return tag_by_evidence(claims)                     # U 必须标成"假设"
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| MSP | O(d_ψ)+O(1)/检查点（异步） | O(\|𝒞\|) | 只读、版本钉死、B_sem 受限 |
| CPG | O(k_sem·(C_compile+C_gnd)) | O(\|𝒯\|) | 双侧、label-symmetric、ι≥ι_min |
| SQ | O(1) 类型检查 | O(1) | 无写权限；P_fail 只增不减 |
| SSA/IPC | O(R·K·E_abl) 离线 | O(K·\|holdout\|) | 置换采样、LCB、非包含性 |
| FSE+ | O(\|σ\|) | O(\|σ\|) | EV-sem 限 L1、非不可逆、权重上限 |
| PCX+ | O(\|CP\|·(k_p+k_c+k_g)·(C_VOI+d_φ+d_ψ)) | O(\|V\|+\|σ\|+\|𝒞\|) | 语义只排序、预算终止 |

**正确性定理（SGAS 概要）**：在 A37–A40 上加 (A41) 语义隔离：π_ψ 对 𝓜.core/阈值/证据权重/验证选择只读，未接地语义不改变任何决策；(A42) 接地健全：验证探针双侧且 label-symmetric，ι≥ι_min，似然比诚实，假接地率 ≤δ_ground；(A43) 归因健全：v(S) 在对抗留出集上定义良好、消融可独立开关、非包含性检验无重复计数。则：(i) **语义不加宽**：任何用到 EV-sem 的承诺仍须核心物理证据，不可逆接触必要集不含语义；部署界仅增加 δ_ground·1[EV-sem∧L1]；(ii) **单调性延伸**：语义只能 (a) 重排 P_adm 内探针（效率），(b) 抬高 P_fail/触发保守回退（安全），(c) 以受限权重进入 L1 佐证；不存在升险写通道；(iii) **归因有效性**：报告为承重的机制集以概率 ≥1−α_ssl 是真实承重集的子集，冗余机制被降级；(iv) PCX+ 在 k_probes+k_cons+k_gprobe 内终止。

| 风险 | 等级 | 缓解 |
|---|---|---|
| 语义幻觉被弱接地放行 | 高 | 双侧接地 + label-symmetric 验证 + 假接地率监控 + EV-sem 限 L1 |

## 6. 本轮最大风险

**一句话**：本轮最大的风险是**语义捕获 + 归因自欺**——MLLM 既提出"世界可能是什么"，又参与设计/解读"验证它"的探针，若验证不是严格双侧且由独立标签对称准则选出，它就能用自己出的题通过自己的考试；而沙普利归因若在同一有偏留出集上估计，会把这种伪承重机制评为"创新"。必须以"语义只提议、物理才裁决"的隔离硬边界、双侧独立接地、以及对抗留出集上的置信下界归因为三重护栏，宁可让大模型只当探针排序器和解释器，也绝不让它触碰接受域。

### IP-139 MSP（语义提议器，只读接口）

def mllm_propose(I, M, obs, budget):
    if not budget.can_sem(): return []                 # 预算耗尽即静默跳过
    raw = mllm.run(prompt_version=PINNED, image=obs.rgb,
                   depth=obs.depth, tactile=obs.tap, instr=I)  # 只读上下文
    claims = []
    for x in raw:
        c = Claim(pred=x.pred, r=x.region, q=x.conf,
                  fam=restrict(x.fam, P_fam),                # 只允许已知探针族
                  e=x.explain)
        if target_in(c.r, M) and c.pred is not None:
            claims.append(c)
    budget.charge_sem(raw.cost)
    return rank_by_semantic_voi(claims, M)             # 仅排序，不写 𝓜.core

### IP-140 CPG（命题-探针编译与双侧接地）

```python
def compile_claim(c):
    h1, h0 = c.pred, negate(c.pred)                    # H1=c, H0=¬c
    fam = [p for p in c.fam if admissible(p, F_abs)]   # A34 非破坏过滤
    if not fam: return None                            # 不可证伪 -> U
    p = argmax(fam, key=lambda q: mutual_info(q, h1, h0))  # 双侧、label-symmetric
    if mutual_info(p, h1, h0) < IOTA_MIN: return None
    return Test(p=p, H1=h1, H0=h0, stat=stat_of(p),
                iota=mutual_info(p, h1, h0), lam=LAMBDA_SEM)

def ground_claims(claims, M, budget):
    ledger = {}
    for c in claims[:budget.k_sem]:
        T = compile_claim(c)
        if T is None:
            ledger[c.id] = ('U', 0.0); continue
        if physical_voi(T.p) < THETA_GND:
            ledger[c.id] = ('C', 0.0); continue        # 不值/没预算 -> 未决
        s = execute_probe(T.p, cap=F_abs); budget.spend(T.p)
        l = log(T.lik(s, T.H1) / T.lik(s, T.H0))       # 诚实似然比
        ledger[c.id] = (('G+', l) if l >= T.lam else
                        ('G-', l) if l <= -T.lam else ('C', l))
        audit.grounding(c.id, T, s, l)
    return ledger
```

### IP-141 SQ（语义隔离区，类型级不可越权）

```python
def semantic_sink(claims, ledger, kind):
    if kind == 'proposal':                             # 只在 P_adm 内部排序
        return reorder_within(P_adm, claims)
    if kind == 'anomaly_raise':                        # P_fail 只增不减
        p = f_sem(claims)
        return {'P_fail': max(M.P_fail, p),
                'fallback': p > THETA_ANOM}
    if kind == 'explanation':                          # 逐句挂证据，未接地=假设
        return [Sentence(text=c.e, tag=('fact' if ledger[c.id][0] == 'G+'
                                        else 'hypothesis'), ev=evidence_of(c))
                for c in claims]
    raise TypeError('IllegalProposalWrite')            # 编译期/运行时禁止

def assert_quarantine_capability(mllm):
    assert not mllm.can_write('M.core', 'theta', 'evidence_weight', 'verifier')
    assert mllm.output_type is Proposal                 # 不能被 cast 成 Evidence
```

### IP-142 SSA/IPC（残差优先创新挖掘 + 安全沙普利归因）

```python
def residual_first_mining(bound, prior_IPs, holdout, R=2000):
    slack = {t: estimate_slack_ci(bound, t, holdout) for t in bound.terms}
    tgt = max(slack, key=lambda t: slack[t].mean + slack[t].std)
    certs = []
    for d in propose_monotone_mechanisms(tgt):         # 只走信念/保守两通道
        if not separable(d): continue                  # 可独立开关、不改规则本体
        if not non_increasing_risk(d, holdout): continue
        phi = shapley_lcb(d, prior_IPs, holdout, perms=R)
        resid = novelty_residual(d, prior_IPs, holdout)  # 旧机制消融回归残差
        drop = slack[tgt].mean - with_mechanism(d, tgt, holdout)
        ok = phi.lcb >= TAU_ATTR and drop >= DELTA_TERM and resid >= THETA_NOV
        certs.append(IPC(d, tgt, drop, phi, resid, ok))
    return certs

def shapley_lcb(d, prior, holdout, perms):
    vs = [v(S, holdout) for S in permutation_samples(prior + [d], perms)]
    phi = mean(marginal(vs, d)); lo, _ = bootstrap_lcb(phi)
    return {'phi': phi, 'lcb': lo}
```

```python
def fse_plus_gate(c, M, persona, ood_reg, sem):
    if   c.ev == 'EV-probe*':
        ok = (c.inf.cls == 'ID' and c.inf.ece_k <= eps_meta(c.k)) or \
             (c.inf.cls == 'OOD' and c.region in ood_reg.certified)
    elif c.ev == 'EV-sem':                             # 新增：语义证据
        ok = (c.level == 'L1' and not c.irreversible
              and sem.ledger[c.claim_id][0] == 'G+'
              and sem.test[c.claim_id].two_sided
              and sem.test[c.claim_id].iota >= IOTA_MIN
              and sem.weight[c.claim_id] <= W_SEM_MAX)
    elif c.ev == 'EV-xmodal':
        ok = c.level == 'L1' and c.indep_declared and D(c.region) <= theta_D
    elif c.ev == 'EV-human':
        ok = persona[c.op].auth >= 'A1' and \
             c.corrob >= quarantine_exit(persona[c.op].auth)
    elif c.ev in ('EV-visit', 'EV-margin'):
        ok = round56_checks(c, M)
    else:
        return ('reject', 'no_evidence_class', c)
    if not ok: return ('reject', 'evidence_insufficient', c)
    if c.irreversible and c.ev in ('EV-xmodal', 'EV-sem'):
        return ('reject', 'semantic_on_irreversible', c)   # 硬禁令
    return ('ok', c)

def certificate_q(sched, log, M, consent, auth_log, ood_reg, sem, ipc):
    r = certificate_p(sched, log, M, consent, auth_log, ood_reg)
    if r[0] != 'ok': return r
    if sem.explanation_coverage < RHO_EXP and any(c.level == 'L2' for c in sched):
        return ('reject', 'explanation_ungrounded')
    return ('ok', Jq(r[1], sem.mllm_version, sem.budget, sem.claim_ledger,
                     sem.grounding_log, sem.grounding_cal, ipc.ledger))
```

### IP-144 PCX+（探-诺-演++：语义只排序，物理才裁决）

```python
def probe_commit_explain_plus(x0, M, task, budget, consent, personas, sem):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        claims = mllm_propose(task.instruction, M, M.obs[cp.region], budget.sem)
        gnd = ground_claims(claims, M, budget.gnd)     # 双侧独立接地
        sem.adopt(cp.region, gnd)
        M.P_fail = max(M.P_fail, f_sem(claims))        # AnomalySink：只增
        sigma, R = foothold_schedule(x0, cp, M), schedule_risk(cp, M)
        while select_gait(R) == 'halt' and budget.probes_left > 0:
            cands = admissible_probes(cp, M, F_abs)    # 语义不得扩张此集合
            cands = reorder_within(cands, claims)      # ProposalSink：只排序
            p = argmax(cands, key=lambda q: voi_meta(q, M) - cost(q))
            if voi_meta(p, M) < theta_voi: break
            M, _, D = xmodal_fuse(M, cp.region, execute_probe(p, cap=F_abs))
            if D > theta_D and 'consensus' not in cp.done:
                p2 = most_disagreeing_modality_probe(M, cp.region)
                M, _, D = xmodal_fuse(M, cp.region, execute_probe(p2, cap=F_abs))
                cp.done.add('consensus')
            sigma, R = reselect_footholds(x0, cp, M), schedule_risk(sigma, M)
            budget.spend(p)
        g, lv = select_gait(R), contact_level(cp)
        if g != 'halt' and fse_plus_gate(core_contact(cp), M, personas,
                                         ood_reg, sem)[0] == 'ok':
            sched.append(commit(sigma, g)); log.append(tag_evidence(sigma, M, lv))
            continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt': route = alt; continue
        return negotiate_or_stop(cp, M, sigma, R, consent,
                                 tau_int=tau_int(personas.active.auth))
    return sched, log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MSP | O(d_ψ)+O(1)/检查点（异步） | O(\|𝒞\|) | 只读、版本钉死、B_sem 受限（A41） |
| CPG | O(k_sem·(C_compile+C_gnd)) | O(\|𝒯\|) | 双侧、label-symmetric、ι≥ι_min、δ_ground（A42） |
| SQ | O(1) | O(1) | 三 sink；无接受域写权限；P_fail 只增不减 |
| SSA/IPC | O(R·K·E_abl) 离线 | O(K·\|holdout\|) | 置换采样、LCB、非包含性（A43） |
| FSE+ | O(\|σ\|) | O(\|σ\|) | EV-sem 限 L1、非不可逆、w_sem≤w_sem^max |
| PCX+ | O(\|CP\|·(k_p+k_c+k_g)·(C_VOI+d_φ+d_ψ)+R·K·E_abl) | O(\|V\|+\|σ\|+\|𝒞\|) | 语义只排序、k_p+k_c+k_g 终止 |

**正确性定理（Semantic-Grounded Attribution Soundness, SGAS）**
设 A22–A32、A33–A36、A37–A40 成立，且：**(A41)** 语义隔离——π_ψ 对 𝓜.core、阈值、证据权重与验证选择只读，未接地语义不改变决策函数；**(A42)** 接地健全——验证探针双侧且 label-symmetric，ι≥ι_min，似然比估计诚实，假接地率 ≤δ_ground；**(A43)** 归因健全——v(S) 在对抗留出集上定义良好，机制可独立消融，非包含性检验无重复计数。则：

1. **语义不加宽接受域**：任何使用 EV-sem 的承诺仍需核心物理证据；不可逆接触必要证据集显式排除 EV-sem/EV-xmodal。EV-sem 只在 L1 贡献，且权重受 w_sem^max 截断。
2. **交互单调性延伸**：语义只能经 (a) 在 P_adm 内重排探针（效率）、(b) 抬高 P_fail/触发保守回退（安全）、(c) 受限权重 L1 佐证。不存在"语义让系统更敢赌"的写路径。
3. **归因有效性**：报告为承重的机制集以概率 ≥1−α_ssl 是真实承重集的子集；在留出集上无边际贡献的机制被降级为体验/解释创新或拒绝。
4. **终止性**：每检查点接地探针 ≤k_gprobe，PCX+ 在 k_probes+k_cons+k_gprobe 内终止于 {承诺, 绕行, L2 协商, 安全停}。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf
                   + δ_xm·1[L1] + δ_ground·1[EV-sem∧L1])
             − P(𝓜 陈旧未检出) − P(护盾回退失败) − P(SQ 隔离失效)
             − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

关键：**语义给效率、物理给权威**（大模型只排序/解释，接地才作数）；**双侧 + 提议-验证分离**把自证循环挡在架构外；**沙普利归因**让"创新"从叙事变成可证伪的承重项，并允许诚实降级旧机制。

## 7. 本轮最大风险

**一句话**：本轮最大的风险是**语义捕获 + 归因自欺**——MLLM 既提出"世界可能是什么"，又参与设计/解读"验证它"的探针，若验证不是严格双侧且由独立标签对称准则选出，它就能用自己出的题通过自己的考试；而沙普利归因若在同一有偏留出集上估计，会把这种伪承重机制评为"创新"。必须以"语义只提议、物理才裁决"的隔离硬边界、双侧独立接地、以及对抗留出集上的置信下界归因为三重护栏，宁可让大模型只当探针排序器和解释器，也绝不让它触碰接受域。
