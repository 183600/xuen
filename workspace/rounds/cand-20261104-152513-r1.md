# 第 16 轮（研究线累计；本轮灵感循环第 1 轮）· MF-SR-REG-VLA：多模态融合 + 点云配准驱动的成功率感知信任门

> 检索/复核日期：**2026-11-04（UTC）**。赛事身份不变：宇树 UniBot 世界挑战赛，G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API。本轮三个灵感词是「多模态融合」「成功率」「点云配准」。**不推倒**第 10–15 轮成果；本轮在 ZEST-VLA 胜任力层之上加一层**成功率感知多模态融合**：用点云配准残差稠化几何一致性，用多模态融合统一 RGB 语义、深度几何、 proprioception，用自监督成功率估计动态调门。

## 0. 先给直觉：第 15 轮学会了“不信任”，但还没学会“提前知道会不会成功”

第 15 轮 ZEST-VLA 把推理期自监督搬到残差三元组 + conformal/CUSUM 信任门，实现了受控降级。它解决了“执行后才发现错”，但留下两个硬问题：

1. 残差稀疏且延迟：`r_tmp/r_geo/r_goal` 都是块后统计，几何一致性依赖末端位姿和粗光流，对部分遮挡、透明/反光、细粒度接触不敏感。
2. 胜任力是事后二值：CUSUM 只说“惊不惊讶”，没有“这一步成功率有多大”的量化，导致 VOI 调度只能用软胜任力 `c_t` 近似，无法做风险受控的预算分配。

直觉是：**把几何一致性从稀疏位姿提升到稠密点云配准，把单模态残差提升到多模态融合，把二值信任提升到成功率校准。** 点云配准给出 commanded→observed 的稠密几何差；多模态融合把 RGB 语义边界、深度不连续、关节限幅、点云配准误差合成一个可解释的融合分数；成功率用自归一化 conformal 在推理期校准，形成可行动的概率估计 `p_succ(t)`。门控不再只是“惊讶就停”，而是“成功率低于阈值就降级/重规划”，预算分配也随成功率动态调整。

一句话押注：

> 第 15 轮用残差决定信不信；本轮用点云配准稠化几何一致性 + 多模态融合统一语义几何 + 成功率校准把信任门变成风险受控的成功率门，让 VOI 调度在动作前就能量化失败风险。

三个词落地：

| 词 | 落地 | 不做什么 |
|---|---|---|
| 多模态融合 | RGB 语义边界、深度不连续、点云配准误差、 proprioception 限幅四路残差自归一化后线性融合；权重固定、无学习 | 不训练融合网络；不做跨模态表征学习 |
| 成功率 | 用校准集上的融合分数构建 conformal 分位数，映射为 `p_succ = 1 - F(s)` 的边际估计；进入 VOI 成功模型和动态阈值 | 不用监督标签；不做 test-time weight update |
| 点云配准 | 用头双目 + 正运动学生成预测点云 `P_pred`，与观测点云 `P_obs` 做点对点 ICP，输出配准误差 `e_icp` 与收敛标志作为稠密几何残差 | 不假设腕部相机内参；不使用深度图作为唯一信号；透明/反光时降权 |

## 1. 研究日志：为什么是这一层

### 1.1 第 15 轮留下的未付费假设

- A1. 几何一致性可由末端位姿 + 光流近似。实际桌面有遮挡、透明、细粒度接触，稀疏信号会漏检。
- A2. 胜任力二值化足够。CUSUM 的 `e_t` 丢失了“差多少”的强度信息，导致预算分配粗糙。
- A3. 所有模态同等可信。RGB 在反光下失效，点云在低纹理下失效，单一模态残差会产生假警报。

### 1.2 三个新判断

1. **点云配准是免费的稠密几何自监督**。`P_pred` 来自 commanded 运动 + 正运动学，`P_obs` 来自头双目；配准误差不需要标签，本身就是动作-观测一致性的稠密体现。它对平移/旋转敏感，对部分遮挡鲁棒。
2. **成功率是可以校准的一维量**。多模态融合分数 `s_fuse` 在 ID 上可交换，用 split conformal 得到边际保证的阈值，再映射为成功率估计。成功率不是模型输出，是统计校准结果，符合单模型规则。
3. **融合 > 单模态，且必须可证伪**。如果多模态融合不能提升 AUROC 或成功率，剪枝回 ZEST-VLA。融合权重固定，避免引入学习。

## 2. 机制草图

### 2.1 点云配准残差

块 `b` 结束时：
```
P_pred = T_cmd * P_ref
e_icp , converged = ICP(P_pred , P_obs , init = T_fk)
r_pcd = norm(e_icp) / ( ||Δx_cmd|| + ε ) * I[converged]
```
`T_cmd` 来自 commanded Cartesian delta，`T_fk` 来自正运动学。未收敛或遮挡率 > τ 时 `r_pcd` 置零并降权。

### 2.2 多模态融合

四路残差：
- `r_rgb` : 语义边界 IoU 下降量
- `r_depth` : 深度不连续一致性
- `r_pcd` : 上述配准误差
- `r_prop` : 关节限幅 `r_dyn`

自归一化 `z_k = r_k / σ_k`，滑动 MAD 估计 `σ_k`。融合分数：
```
s_fuse = w_rgb*z_rgb + w_depth*z_depth + w_pcd*z_pcd + w_prop*z_prop
```
权重固定，例如 `w_pcd=2, w_rgb=1, w_depth=1, w_prop=3`。

### 2.3 成功率校准

校准集上收集 `s_fuse`，取分位数 `q_α`。定义边际成功率估计：
```
p_succ(t) = clip( 1 - (s_fuse(t)-s_min)/(q_α - s_min) , 0, 1 )
```
或更保守地用 conformal 置信下界。`p_succ` 进入 VOI 成功模型：
```
P_succ(SERVO) ≈ p_succ(t) * b_max * f(p)
```
信任门阈值动态化：
```
h_t = h0 / max(p_succ(t), ε)
```
成功率低时门更敏感。

### 2.4 调度与降级

继承 ZEST-VLA 动作集 `{SERVO, LOOK, VLA, FALLBACK, COMMIT, HOLD}`。新增规则：
- `p_succ < θ_low` 且域检查通过 → 优先 `FALLBACK`
- `p_succ < θ_crit` → 禁用 `SERVO`，强制 `VLA` 重规划或 `HOLD`
- 复检探针频率随 `p_succ` 调整

## 3. 可证伪假设

| 编号 | 假设 | 证伪条件 |
|---|---|---|
| H1 | 点云配准残差在 OOD-E 上 AUROC ≥0.85，优于末端位姿残差 | AUROC <0.75 |
| H2 | 多模态融合 `s_fuse` 在 ID/OOD 区分上优于任一单模态，AUROC 提升 ≥5pp | 无提升 |
| H3 | 成功率感知调度在 OOD 上成功率提升 ≥5pp，ID 不回归 >2pp | 未达标 |
| H4 | 成功率估计的校准误差 |E[p_succ]-acc| ≤0.1 | 误差 >0.15 |
| H5 | 点云配准在透明/反光场景降权后不增加假警报 | ID 假警报 >10% |

## 4. 什么情况下放弃

- 点云配准在真实桌面上收敛率 <60% 或 p99 >80ms → 成本过高，退回 ZEST-VLA。
- 多模态融合未提升 AUROC，且增加假警报 → 剪枝融合，只保留 `r_pcd` 作为独立残差。
- 成功率校准在不同任务间漂移严重，conformal 假警报 >15% → 回到固定阈值门。
- `p_succ` 导致调度过度保守，ID 成功率下降 >3pp → 提高 θ_low。

## 5. 一句话押注

第 15 轮用残差决定信不信；本轮用点云配准稠化几何一致性 + 多模态融合统一语义几何 + 成功率校准把信任门变成风险受控的成功率门。

## 6. 本轮最大风险

点云配准在低纹理、透明、严重遮挡的桌面场景下收敛失败或产生虚假低误差，导致多模态融合的成功率估计被系统性高估，信任门失效且 VOI 调度过度乐观，最终在 OOD-E 上出现隐性自信错误。

# 第 16 轮产物 · MF-SR-REG-VLA 技术报告

> 检索/复核日期：**2026-11-04（UTC）**。对象：宇树 UniBot 世界挑战赛 G1 + Dex1，32 项桌面任务，通才单模型赛道。本报告是研究线累计第 16 轮产物，在第 15 轮 ZEST-VLA 胜任力层之上加入多模态融合、成功率校准、点云配准残差，形成成功率感知信任门。不训练新参数、不引入第二学习模型。

## 0. 结论与边界

### 0.1 一句话结论
ZEST-VLA 用自监督残差做二值信任；本轮用点云配准稠化几何一致性，用 RGB/深度/点云/proprioception 四路自归一化残差做多模态融合，用 split conformal 校准得到可行动的成功率估计 `p_succ(t)`，并以此动态调门阈值和 VOI 调度。零样本泛化仍是系统级降级承诺，不承诺 VLA 在未见任务上必成。

### 0.2 证据等级
A 官方规则/API；B 公式/合成分析；C 需真机验证；U 未核验。

### 0.3 不做什么
不训练融合网络；不做 test-time weight update；不假设腕部相机内参/深度图/F/T；不承诺解决 OOD-G。

## 1. 承接：第 15 轮解决了什么、没解决什么

已解决：VOI-MAP 目标分布+预算，ZEST-VLA 自监督残差+conformal/CUSUM 信任门+几何原语降级。
未解决：几何一致性稀疏、胜任力二值化、单模态脆弱。本轮补充点云配准稠密几何、多模态融合抗噪、成功率校准量化风险。

## 2. 符号与形式化

设冻结 VLA `π_θ` 输出 30 步块 `A_t`，5 步块执行。观测 `o_t = {rgb_t, depth_t, pc_t, q_t, qdot_t}`。语义地图 `M_t`。

残差定义：
- 时序 `r_tmp` 如第 15 轮
- 几何 `r_geo` 如第 15 轮
- 目标进度 `r_goal` 如第 15 轮
- 动力学 `r_dyn` 如第 15 轮
- 点云配准 `r_pcd`：
```
P_pred = T_cmd * P_ref
e_icp, converged = ICP(P_pred, P_obs, init=T_fk)
r_pcd = converged * ||e_icp|| / (||Δx_cmd||+ε)
```
- RGB 语义边界残差 `r_rgb = 1 - IoU(边缘_t, 边缘_{t-1} ∘ T_cmd)`
- 深度不连续残差 `r_depth = ||∇depth_obs - ∇depth_pred|| / σ_depth`

自归一化 `z_k = r_k / σ_k`，`σ_k = 1.4826 MAD_{W}`。

融合分数：
```
s_fuse = Σ w_k z_k ,  w_pcd=2, w_prop=3, w_rgb=1, w_depth=1
```

成功率校准：校准集 `{s_i}` 取分位数 `q_α`。边际估计：
```
p_succ(t) = clip( 1 - (s_fuse(t)-s_min)/(q_α - s_min) , 0 ,1 )
```
或用 conformal 置信下界 `p_succ^L = 1 - α - …`。

动态阈值：
```
h_t = h0 / max(p_succ(t), ε)
k_t = k0 * (1 - p_succ(t))
```

VOI 成功模型升级：
```
P_succ(SERVO) ≈ p_succ(t) * b_max * f(p)
```

## 3. 算法

### 3.1 离线校准
在 5 个 ID 任务 ×10 episodes 收集 `s_fuse`，计算 `q_α`, `s_min`, 滑动 MAD 窗长 W。冻结 `w_k`, `h0`, `k0`, `θ_low`, `θ_crit`。

### 3.2 在线循环
get_action:
1. 更新 `M_t`, 相位
2. 计算允许动作集 `A_adm` 由当前模式 `TRUST/FALLBACK`
3. 若 `p_succ < θ_crit` → 强制 `VLA` 或 `HOLD`
4. 在 `A_adm` 上按 `Δ/cost` 选择动作，`p_succ` 进入收益估计
5. 执行 5 步块

on_block_finished:
1. 计算四路残差 + `r_pcd`
2. 自归一化 → `s_fuse`
3. 更新 `p_succ(t)`, CUSUM `S_t = max(0, S_{t-1}+e_t - α - k_t)`，`e_t = 1[s_fuse>q_α]`
4. 若 `S_t>h_t` → 切 `FALLBACK`；否则若在 `FALLBACK` 且探针成功 → 回 `TRUST`
5. 更新软胜任力 `c_t` 与 VOI 参数

### 3.3 伪代码片段
```python
def compute_multimodal_residuals(obs0, obs1, plan, M):
    r = {}
    r['tmp'] = ...
    r['geo'] = ...
    r['goal'] = ...
    r['dyn'] = ...
    # 点云配准
    P_pred = transform_pointcloud(obs0.pc, plan.delta)
    e_icp, conv = icp(P_pred, obs1.pc, init=fk(obs1.q))
    r['pcd'] = (norm(e_icp)/(norm(plan.delta)+1e-6) if conv else 0.0)
    # RGB/深度
    r['rgb'] = 1 - edge_iou(obs0.rgb, obs1.rgb, plan)
    r['depth'] = depth_discontinuity_error(obs0.depth, obs1.depth, plan)
    return r

def fuse(r, scales):
    z = {k:r[k]/(scales[k]+1e-6) for k in r}
    return 2*z['pcd']+3*z['dyn']+1*z['rgb']+1*z['depth']+z['tmp']+z['geo']+z['goal']
```

## 4. 性质、复杂度与正确性

### 4.1 标签无关性
所有残差为确定性函数，conformal 只用 `s_fuse` 分布，无成功标签。命题同 ZEST-VLA。

### 4.2 ID 假警报控制
split conformal 给出 `Pr(s_fuse>q_α) ≤ α` 在可交换假设下成立。动态阈值 `h_t` 单调于 `p_succ`，不破坏边际保证。

### 4.3 OOD 检测延迟
CUSUM 漂移 `α' - α - k_t`，`k_t` 随 `p_succ` 下降而增大，低成功率时更敏感。期望延迟 `E[τ]≈ h_t/(α' - α - k_t)`。

### 4.4 安全降级
动作集仍为第 13/14 轮安全集子集，点云配准仅用于诊断，不产生关节指令。

### 4.5 复杂度
ICP 用下采样 2048 点，KD-Tree，约 15-30 ms/块；其余残差 <0.6 ms。整体 CPU <40 ms，仍在块间空隙执行，不阻塞关键路径。内存 `O(N+W+|P|)` < 30 MB。
