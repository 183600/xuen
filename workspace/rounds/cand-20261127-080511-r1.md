### 第 1 轮灵感驱动研究记录

**灵感词**：灵巧手、可解释性

**直觉与动机**：
前序工作（SRC-USC / Exec_v25）已把物理接地、结构、力控、语义、重构、多机协同串成七证单调退化链，但其"感知-决策"仍停留在**刚体 / 单接触点**抽象：它假设机器人以末端执行器整体接触世界，无法刻画多指手的**接触模式、摩擦锥、抓取内力与手指步态**；同时，证书链越叠越长（v18→v25），任何一次拒证都只返回一个布尔值，人类运维者无法回答"为什么被拒、改哪里才能通过"——**证书的可信度在增长，可审计性却在坍塌**。

受「灵巧手」启发：灵巧操作的本质是**高维接触证书的在线生成**。抓取不是"抓住 / 没抓住"的二元事件，而是在摩擦锥、单边约束、关节限位、接触模式切换构成的高维可行域内维持一条连续的力 / 位姿轨迹；每根手指、每个接触点都在消费与生成局部证书，手掌把它们汇成一个对象级证书。

受「可解释性」启发：证书门本身应被当作一个**可解释模型**来审计——拒证必须给出**最小失败割（minimal failing cut）**与**对比式修复建议（contrastive repair）**，而不是黑箱布尔值；解释必须对策略**忠实（faithful）**、对扰动**稳定（stable）**、对操作者**可执行（actionable）**。

核心洞见：**灵巧手是证书维度的"膨胀器"（接触模式组合爆炸），可解释性是证书维度的"压缩器"（把高维拒证压成最小可执行原因），二者是对偶的。** 因此本轮不是简单再加两个证书，而是让"证书生成"与"证书解释"互为约束：解释必须是某条真实证书检查的**因果溯源**，而灵巧操作的每次接触模式切换都必须留下可解释的证书边。

**形式化目标**：
1. 定义灵巧操作证书（DMC）：抓取矩阵 G 的稳健力封闭（∃ 内力 f∈int(K)，Gf=0，摩擦锥裕度 ≥ γ_slip）；接触无滑移（‖f_t‖≤μf_n−γ_slip，|τ_t|≤μ_t f_n−γ_tor）；可操作度 σ_min(J_h)≥σ_min^req 与条件数 κ≤κ_max；接触模式切换 σ(t)∈Σ 的动力学 / 阻抗连续性。
2. 定义可解释性证书（XPC）：(δ,ε)-忠实性（充分性 |f(x)−f(x_S)|≤ε 与必要性 |f(x)−f(x_{\S})|≥δ）、局部 Lipschitz 稳定性、最小基数充分子集、对比式可执行修复 d_repair≤δ_r。
3. 构建证书溯源 DAG（𝒫/CPEG）：把每个 (子)证书检查作为节点、依赖作为边；拒证时输出**最小失败割**，保证"解释即证据"，禁止幻觉理由。
4. 构建可解释灵巧统一准入门（XDUC）：USMC ∪ SMC ∪ RMC ∪ MCC ∪ DMC ∪ XPC 九证一体，Exec_v26 = Exec_v25 ∩ Fil_dex ∩ Fil_expl ⊆ Exec_v25。
5. 证明九位一体单调退化链在抓取失稳 / 接触模式跳变 / 解释失真下的保持性，并证明"每个拒证都可被最小失败割完全归因"。

## 1. 关键算法骨架（在 IP-447 骨架上扩展）

```python
# ============================================================
# IP-448 Dexterous Manipulation Certificate (DMC) — 灵巧操作证书
# ============================================================
@dataclass
class DexterousManipulationCertificate:
    """稳健力封闭 + 接触无滑移 + 灵巧度 + 接触模式切换连续性"""
    G: Tensor                         # [6, m] 抓取矩阵
    contacts: list['Contact']         # 法向/切向/扭转摩擦、接触坐标系
    J_h: Tensor                       # [6, n_q] 手部雅可比
    q: Tensor
    qd: Tensor
    qdd: Tensor
    f_ext: Tensor                     # [6] 对象所受外力旋量
    contact_modes: list['ContactMode']  # σ(t)
    gamma_slip: float = 0.10          # 切向防滑裕度
    gamma_tor: float = 0.05           # 扭转防滑裕度
    mu_lower: float = 0.50            # 摩擦系数稳健下界
    sigma_min_req: float = 0.05       # 最小可操作度
    kappa_max: float = 20.0           # 条件数上限
    delta_mode: float = 1e-3          # 模式切换残差容差

    def verify_force_closure(self) -> bool:
        """稳健力封闭：∃ f∈int(K), Gf=0，且对任意单位外力有裕度。
        将摩擦锥线性化为多面体 K̂（内接近似），解 LP：
            find f  s.t.  Gf = 0,  f ∈ K̂,  f ≥ gamma_slip
        再求稳健旋量裕度 min_{‖w‖=1} max_{f∈K̂} wᵀGf ≥ gamma_slip"""
        K_hat = self._linearized_friction_polytope(mu=self.mu_lower)
        feasible, f_int = solve_lp(G=self.G, cone=K_hat,
                                   obj=torch.zeros(K_hat.m),
                                   margin=self.gamma_slip)
        if not feasible:
            return False
        return self._robust_wrench_margin(self.G, K_hat) >= self.gamma_slip

    def verify_no_slip(self) -> bool:
        """接触无滑移：‖f_t‖ ≤ μ f_n − γ_slip 且 |τ_t| ≤ μ_t f_n − γ_tor"""
        f = self._solve_contact_forces(self.f_ext, self.G)  # 分配接触力
        for i, c in enumerate(self.contacts):
            fn, ft, tau_t = f[i, 0], f[i, 1:3], f[i, 3]
            if fn <= 0.0:                                    # 单边约束
                return False
            if torch.norm(ft) > c.mu * fn - self.gamma_slip:
                return False
            if abs(tau_t) > c.mu_t * fn - self.gamma_tor:
                return False
        return True

    def verify_dexterity(self) -> bool:
        """灵巧度：σ_min(J_h) ≥ σ_min^req 且 κ(J_h) ≤ κ_max"""
        sv = torch.linalg.svdvals(self.J_h)
        if sv.min() <= 1e-9:
            return False
        return (sv.min().item() >= self.sigma_min_req and
                (sv.max() / sv.min()).item() <= self.kappa_max)

    def verify_contact_mode_transition(self, model: 'HandModel') -> bool:
        """接触模式切换连续性：切换前后对象旋量/冲量不跳变"""
        for pre, post in zip(self.contact_modes[:-1], self.contact_modes[1:]):
            w_pre = self._object_wrench(pre, model)
            w_post = self._object_wrench(post, model)
            if torch.norm(w_pre - w_post) > self.delta_mode:
                return False
            if self._impulse_jump(pre, post) > self.delta_mode:
                return False
        return True

    def verify_all(self, model: 'HandModel') -> bool:
        return (self.verify_force_closure() and
                self.verify_no_slip() and
                self.verify_dexterity() and
                self.verify_contact_mode_transition(model))


# ============================================================
# IP-449 eXplainability Certificate (XPC) — 可解释性证书
# ============================================================
@dataclass
class Explanation:
    subset: frozenset            # 关键因子子集 S
    attribution: Tensor          # 归因 φ ∈ ℝ^d
    repair: Optional['Repair']   # 对比式修复 ρ

@dataclass
class ExplainabilityCertificate:
    """忠实性 + 稳定性 + 最小性 + 可执行性 + 证书溯源"""
    model_fn: Callable                    # f: x -> 评分
    decision_fn: Callable                 # x -> bool（是否准入）
    provenance: 'CertificateProvenanceGraph'
    epsilon_suff: float = 1e-2            # 充分性容差 ε
    delta_nec: float = 5e-2               # 必要性下界 δ
    lipschitz_L: float = 1.0              # 局部 Lipschitz 常数
    radius_r: float = 0.05                # 稳定性检验半径
    delta_repair: float = 0.10            # 修复距离上限
    max_card: int = 8                     # 解释最大基数
    n_perturb: int = 32

    def verify_faithfulness(self, x: Tensor, e: Explanation) -> bool:
        """(δ,ε)-忠实：充分性 |f(x)-f(x_S)|≤ε，必要性 |f(x)-f(x_{\\S})|≥δ"""
        S = e.subset
        suff = abs(self.model_fn(x) - self.model_fn(self._keep(x, S))) <= self.epsilon_suff
        nec = abs(self.model_fn(x) - self.model_fn(self._delete(x, S))) >= self.delta_nec
        return suff and nec

    def verify_stability(self, x: Tensor, e: Explanation) -> bool:
        """局部 Lipschitz：‖φ(x)-φ(x')‖ ≤ L‖x-x'‖，∀‖x-x'‖≤r"""
        for _ in range(self.n_perturb):
            xp = x + self.radius_r * random_unit_like(x)
            ep = self.explain(xp)
            if torch.norm(e.attribution - ep.attribution) > \
                    self.lipschitz_L * torch.norm(x - xp):
                return False
        return True

    def verify_minimality(self, x: Tensor, e: Explanation) -> bool:
        """最小基数充分子集：S 必要，且去掉任一元素即失去充分性"""
        S = set(e.subset)
        if len(S) > self.max_card:
            return False
        for i in S:
            reduced = S - {i}
            if abs(self.model_fn(x) - self.model_fn(self._keep(x, reduced))) <= self.epsilon_suff:
                return False
        return True

    def verify_actionability(self, x: Tensor, e: Explanation) -> bool:
        """对比修复可执行：修复后准入且修复距离 ≤ δ_repair"""
        if e.repair is None:
            return False
        x_rep = e.repair.apply(x)
        return (self.decision_fn(x_rep) and
                torch.norm(x_rep - x) <= self.delta_repair)

    def explain(self, x: Tensor) -> Explanation:
        """解释 = 证书溯源 DAG 上的最小失败割 + 归因 + 对比修复"""
        cut = self.provenance.minimal_failing_cut(x)     # 不可约失败检查集 C*
        S = self.provenance.factors_of(cut)              # 映射到可解释因子
        phi = self._attribution(x, S)                    # 忠实归因（Shapley/IG）
        repair = self._contrastive_repair(x, cut)        # 沿可行动因子做最小代价投影
        return Explanation(frozenset(S), phi, repair)

    def verify_all(self, x: Tensor, e: Explanation) -> bool:
        return (self.verify_faithfulness(x, e) and
                self.verify_stability(x, e) and
                self.verify_minimality(x, e) and
                self.verify_actionability(x, e))


# ============================================================
# 证书溯源 DAG（CPEG）与最小失败割
# ============================================================
@dataclass
class CertificateProvenanceGraph:
    nodes: list['CertNode']                 # 每个节点 = 一次子证书检查
    edges: list[tuple[int, int]]            # u -> v 表示 v 依赖 u
    root: int                               # 总准入判定节点

    def minimal_failing_cut(self, x) -> frozenset:
        """从 root 反向遍历，取所有失败叶的最小割（按解释成本加权最大流/最小割）"""
        failed = [i for i, n in enumerate(self.nodes)
                  if n.is_leaf() and not n.check(x)]
        if not failed:
            return frozenset()
        # 构建单位容量网络，求 root 与失败叶集合之间的最小割，
        # 割边即"阻断该失败路径所需的最少检查集合"
        return self._weighted_min_cut(failed, weight=self.nodes_weight)

    def factors_of(self, cut: frozenset) -> set:
        """把失败割映射回用户可理解的输入/参数因子"""
        out = set()
        for i in cut:
            out.update(self.nodes[i].factor_ids)
        return out

    def audit(self, x) -> dict:
        """可解释审计报告：每个节点状态、证据、依赖路径"""
        return {i: {'check': self.nodes[i].name,
                    'passed': self.nodes[i].check(x),
                    'evidence': self.nodes[i].evidence(x)}
                for i in range(len(self.nodes))}


# ============================================================
# IP-450 XDUC — 可解释灵巧统一准入门
# ============================================================
@dataclass
class ExplainableDexterousUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'
    dmc: DexterousManipulationCertificate
    xpc: ExplainabilityCertificate

    def admits(self, plan, sensor_data, hand_model) -> tuple[bool, dict]:
        # 1) 先过 v25 七证（单机 + 语义 + 重构 + 协同）
        if not self.src_usc.admits(plan, sensor_data):
            expl = self.xpc.explain(sensor_data['x'])
            return False, {'stage': 'v25', 'explanation': expl,
                           'cut': self.xpc.provenance.minimal_failing_cut(sensor_data['x'])}

        # 2) 灵巧操作证书
        if not self.dmc.verify_all(hand_model):
            expl = self.xpc.explain(sensor_data['x'])
            return False, {'stage': 'DMC', 'explanation': expl,
                           'failed': self._failed_dmc_subchecks()}

        # 3) 可解释性证书：解释必须忠实/稳定/最小/可执行
        expl = self.xpc.explain(sensor_data['x'])
        if not self.xpc.verify_all(sensor_data['x'], expl):
            return False, {'stage': 'XPC', 'explanation': expl,
                           'reason': 'unfaithful_or_unstable_explanation'}

        return True, {'stage': 'admit', 'explanation': expl,
                      'audit': self.xpc.provenance.audit(sensor_data['x'])}

    def _failed_dmc_subchecks(self) -> dict:
        return {
            'force_closure': self.dmc.verify_force_closure(),
            'no_slip': self.dmc.verify_no_slip(),
            'dexterity': self.dmc.verify_dexterity(),
            'mode_transition': self.dmc.verify_contact_mode_transition,
        }


# ============================================================
# 端到端流水线：在 v25 之上加入灵巧-可解释环
# ============================================================
class ExplainableDexterousPipeline:
    def __init__(self, config: dict):
        self.xduc = ExplainableDexterousUnifiedCertificate(
            src_usc=config['src_usc'],
            dmc=DexterousManipulationCertificate(
                G=config['G'], contacts=config['contacts'], J_h=config['J_h'],
                q=config['q'], qd=config['qd'], qdd=config['qdd'],
                f_ext=config['f_ext'], contact_modes=config['contact_modes'],
                gamma_slip=config['gamma_slip'], gamma_tor=config['gamma_tor'],
                mu_lower=config['mu_lower'],
                sigma_min_req=config['sigma_min_req'], kappa_max=config['kappa_max'],
                delta_mode=config['delta_mode']),
            xpc=ExplainabilityCertificate(
                model_fn=config['model_fn'], decision_fn=config['decision_fn'],
                provenance=config['provenance'],
                epsilon_suff=config['epsilon_suff'], delta_nec=config['delta_nec'],
                lipschitz_L=config['lipschitz_L'], radius_r=config['radius_r'],
                delta_repair=config['delta_repair'], max_card=config['max_card']))

    def step(self, plan, sensor_data, hand_model) -> tuple[bool, dict]:
        admitted, info = self.xduc.admits(plan, sensor_data, hand_model)
        # 无论准入与否，都输出可审计解释，供人机协同与事后复盘
        info['human_readable'] = self._render_explanation(info)
        return admitted, info

    def _render_explanation(self, info: dict) -> str:
        # 把最小失败割渲染成"因为 X 未满足，建议把 Y 调整到 Z"的对比句
        return render_contrastive(info.get('cut'), info.get('explanation'))
```

## 2. 复杂度分析（增量）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |

| XPC 忠实性 | O(d) 两次前向 | O(d) | d≤10⁴ 输入维 |
| XPC 稳定性 | O(n_perturb·(d+C_expl)) | O(d) | n_perturb=32 |
| XPC 最小性 | O(|S|·d) 前向 | O(d) | |S|≤8 |
| XPC 最小失败割 | O(𝒱·ℰ_p·log 𝒱) 最大流 | O(𝒱+ℰ_p) | 𝒱≤64 证书节点 |

**实时性保证**：DMC 只在**抓取规划 / 接触模式切换事件**触发时求解完整 LP（低频，≤10Hz），控制环内仅做 O(m) 的无滑移逐接触检查；XPC 的稳定性检验在**拒证或高风险决策**时执行，正常准入路径仅构造一次解释，不进入扰动采样。故 50Hz 控制环关键路径不增加。

## 3. 正确性论证（增量）

### 引理 13（灵巧操作证书的封闭-防滑-灵巧-切换四重保证）
**陈述**：`DMC.verify_all(model) = True` ⟹ 抓取同时满足：
(1) 稳健力封闭：∃ f∈int(K̂)，Gf=0，且对任意单位外力旋量裕度 ≥ γ_slip；
(2) 接触无滑移：∀i，f_n,i>0，‖f_t,i‖≤μ_i f_n,i−γ_slip，|τ_t,i|≤μ_{t,i} f_n,i−γ_tor；
(3) 灵巧度：σ_min(J_h)≥σ_min^req 且 κ(J_h)≤κ_max；
(4) 模式切换连续：相邻接触模式的对象旋量差与冲量跳变均 ≤ δ_mode。

**证明**：
1. `verify_force_closure` 在摩擦锥内接近似 K̂ 上解 LP，feasible 给出内力存在性；`_robust_wrench_margin` 对所有单位旋量取最坏情形下界，下界 ≥ γ_slip 即把"存在内力"升级为"对任意外力仍有裕度"的稳健封闭（参考 Murray-Li-Sastry 抓取理论中 force closure 的旋量空间刻画）。
2. `verify_no_slip` 直接逐接触核验库仑锥 + 扭转摩擦锥的严格内点条件；减去 γ 即保留安全余量，故在摩擦系数不确定性 μ∈[μ_lower,μ_upper] 下仍不滑移（单调性：μ 越大锥越大，取 μ_lower 为最坏情形）。
3. SVD 给出 J_h 的奇异值谱，σ_min 是末端任意方向可产生单位速度所需关节速度的上界倒数，κ 刻画各向同性；两约束共同排除"某些方向几乎不可动"的奇异抓取。
4. 模式切换处用逆动力学残差与冲量跳变度量；≤ δ_mode 保证切换前后对象加速度场不出现不可跟踪的跳变，等价于广义坐标下的 C⁰/C¹ 拼接。
4 条分别对应"抓得住、抓得稳、动得了、换得顺"，缺一不可。∎

### 引理 14（可解释性证书的忠实-稳定-最小-可执行四重保证）
**陈述**：`XPC.verify_all(x,e) = True` ⟹ 解释 e 同时满足：
(1) (δ,ε)-忠实：充分性 |f(x)−f(x_S)|≤ε 且必要性 |f(x)−f(x_{\S})|≥δ；
(2) 局部 Lipschitz 稳定：∀‖x−x'‖≤r，‖φ(x)−φ(x')‖≤L‖x−x'‖；
(3) 最小性：S 是基数 ≤ max_card 的充分子集，且去掉任一元素即不充分；
(4) 可执行性：存在修复 ρ，使 decision(x_ρ)=True 且 d_repair(x,x_ρ)≤δ_r。

**证明**：
1. 充分性说明"保留 S 已足以复现原评分"，必要性说明"删除 S 会显著改变评分"，二者合取排除"解释与模型无关"的空洞归因（与 ERASER/ comprehensiveness-sufficiency 判据一致）。
2. 对半径 r 内的扰动采样核验 Lipschitz 比；有限采样是对连续 Lipschitz 条件的经验证书，配合区间界可推广到邻域（见风险 R18）。
3. 逐元素删除检验是子集最小性的直接判定：若删任一 i 仍充分，则 S 非最小，返回 False；基数上限把解释限制在人可读范围。
4. 修复由对比反事实投影给出，并**实际前向验证** repair 后 decision=True，故"建议"不是猜测而是可复核的证书。
四个条件分别约束"准不准、稳不稳、简不简、改不改得动"。∎

### 引理 15（最小失败割的归因完备性与无幻觉性）
**陈述**：设证书溯源 DAG 𝒫 的根为总准入判定。若 `admits(x)=False`，则 `C* = minimal_failing_cut(𝒫,x)` 非空，且 𝒫 中每条从根到失败叶的路径至少经过 C* 中一个节点；并且删除 C* 中任一节点都会使某条失败路径不再被阻断（C* 不可约）。因此"解释即证据"：解释中每个原因都对应一次真实失败的子证书检查。

**证明**：
1. 由 `admits=False` 且根节点是对所有子证书的合取/依赖汇聚，至少一个叶检查失败，故 failed 集合非空。
2. 对 𝒫 做加权最小割：把根与失败叶集合分离的最小边集即 C*。由最小割-最大流定理，任何根→失败叶路径必穿过割，故 C* 覆盖所有失败见证。
3. 不可约性由最小割的极小性保证：删去任一割边都会留下一条未被切断的根→失败叶路径。
4. 由于 `factors_of(C*)` 只映射真实证书节点的 factor_ids，解释不含任何未参与检查的凭空因子，故无幻觉理由；`audit()` 进一步给出每个节点的通过/失败与证据，可人工复核。∎

### 引理 16（九位一体单调退化链 v26 延伸）
**陈述**：任意单点/组合失效下，`Exec_v26 ⊆ Exec_v25 ⊆ Exec_v24 ⊆ ... ⊆ Exec_v18` 恒成立。

**证明**：`XDUC.admits = src_usc.admits ∧ DMC ∧ XPC`，故 Exec_v26 是 Exec_v25 与两个新过滤器的交集。增加三种退化路径：
- 抓取失稳 / 力封闭失败 / 接触模式跳变 → `DMC.verify_all=false` → `XDUC` 拒证 → 退回 `Exec_v25`（放弃灵巧操作，退化为末端整体夹持或吸盘等单接触策略）。
- 解释失真 / 最小割为空 / 修复不可执行 → `XPC.verify_all=false` → `XDUC` 拒证 → 退回 `Exec_v25`（保留已验证七证执行，但强制转人工复核，不自动执行不可解释决策）。
- 两者组合失效：取交集，单调性由集合交的传递性保持。
另：解释层只在**拒证或高风险**时增加约束，正常准入不会扩张执行集，故不会出现 Exec_v26 ⊄ Exec_v25。∎

**陈述**：对任意计划 π，`XDUC.admits(π)=True` ⟺ π 同时满足：
