# 第 13 轮（新循环第 1 轮）· SKILL-SEG：给 CHUNK-SERVO 装上「自监督技能骨架」

> 检索/复核日期：**2026-10-31（UTC）**。赛事身份不变：宇树 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API。沿用第 12 轮状态文件，因此按总轮次编号；本轮是新灵感循环第 1 轮，三个词是「**技能学习**」「**自监督学习**」「**研究空白**」。本轮不推倒第 10 轮 FACT-VLA、第 11 轮 GEO-RESIDUAL、第 12 轮 CHUNK-SERVO，而是在它们之上补一层三者都没有显式建模的东西：**技能（skill）**。

## 0. 先给结论：CHUNK-SERVO 解决了「多久看一次」，没解决「现在处于哪个技能」

第 12 轮把 30 步开环 chunk 切成 6 个 5 步执行块，反馈周期从 1s 降到 167ms。方向是对的，但它有一个隐含假设：**所有阶段的 5 步块、增益、终止条件都一样**。真实操作不是这样：

- 自由空间接近：希望块长一点，摊薄 VLA 推理；增益可以低；不需要接触终止。
- 预接触/对齐：希望块短一点；需要 PBVS/IBVS 混合；需要“对准了没有”的判据。
- 接触/插入/拧/挂：希望块更短；法向增益要降；需要“插进去了没有/滑了没有”的判据。
- 释放/撤离：希望块可以长；需要“松开了没有”的判据。

同一个 5 步块不可能同时最优。更关键的是：**VLA 没有显式的技能状态**。它输出 30 步动作，但不会告诉你“现在是插入阶段，插入已经卡住 0.4 秒，应该退出来重试”。它只能等下一个 chunk，再用新图重新猜。

所以本轮押注 **SKILL-SEG**：

> 用 33k 条无技能标签的成功演示，自监督地发现一个跨任务共享的技能词表（reach / grasp / lift / align / insert / twist / place / release …）和技能转移图；用同一个 WLA checkpoint 加一个技能辅助头，把技能伪标签学进去；在线用技能图 + Viterbi 解码当前技能，再用确定性技能执行器决定块长、增益、终止和回退。**VLA 仍是唯一学习策略；技能层不是第二个策略，而是“相位骨架 + 调度器”。**

一句话：**第 12 轮把“1 秒开环”改成“167ms 闭环”；第 13 轮要回答“这 167ms 应该属于哪个技能、该执行多久、何时算完成”。**

## 1. 直觉：33k 演示里最便宜、最被浪费的监督信号是「时间结构」

### 1.1 技能在数据里重复

32 个任务、33,276 条成功演示、18.28M 帧。表面上看是 32 种任务，拆开看是少数几种技能在重复：

- 接近（reach）：夹爪从当前位姿到目标附近；
- 抓取（grasp）：闭合夹爪、确认夹住；
- 抬起/搬运（lift/transport）：保持夹持、移动到下一处；
- 对齐（align）：把物体/夹爪对准受器；
- 插入/挂/叠（insert/hang/stack）：接触密集的最后 3 厘米；
- 旋转/拧/拉（twist/zip/unlock）：需要力矩和相位；
- 放置/释放（place/release）：张开夹爪、撤离。

这些技能在 32 个任务里反复出现，只是参数（目标位姿、物体、语言）不同。**如果能把技能从演示里抽出来，32 个任务就不再是 32 个独立策略，而是“技能词表 + 技能图 + 任务条件”。**

### 1.2 技能边界是免费的监督信号

演示没有技能标签，但有时间结构：同一技能内的帧相似，跨边界的帧突变。这个结构可以用自监督方法免费提取：

- 时序对比学习（CPC）：同一段内的帧互为正样本，跨段/跨 episode 的帧为负样本；
- 变点检测（change-point detection）：在特征空间里找“段内相似度最高、段数最少”的分割；
- 聚类：把跨演示的段描述子聚成 K 个技能原型。

这三步都不需要人工标签。人工只需要在 5 个任务 × 20 条演示上抽检边界，用来验证，不用来训练。

### 1.3 技能在任务间共享，是研究空白

技能学习（skill learning）不是新词：options、DIAYN、SPiRL、skill-based imitation 都做过。但它们通常假设：

- 可以训一个独立的技能策略（违反“单模型”规则）；
- 或者可以在线 RL/探索（比赛不允许）；
- 或者技能是人工定义的（不可扩展）。

VLA 这边也不是没有“阶段”：ACT、Diffusion Policy、π0、WLA 都输出 action chunk，但 chunk 是**平坦的**：没有显式技能状态，没有技能级终止，没有技能级调度。自监督学习这边，时序对比/变点检测主要用来做表示或视频分割，很少被用来给 VLA 生成技能伪标签并驱动执行。

所以研究空白可以写成一句话：

> **在“单模型 + 无深度/无力觉 + 固定 action_chunk_size + 远程 API”的约束下，如何用无标签演示自监督地发现可执行的技能词表和技能图，并让同一个 VLA checkpoint 用技能状态来调度 chunk 长度、伺服增益和终止/恢复？**

这正是 SKILL-SEG 要填的空白。

### 1.4 为什么不是“再训一个技能策略”

因为规则。所有任务须基于同一模型完成，不得混合多个模型。一个独立的技能策略、一个独立的技能分类器、一个独立的残差网络，都有被判定为“第二个模型”的风险。SKILL-SEG 的合规策略是：

- 技能分割、聚类、技能图：**离线**，只产生伪标签和统计量，不参与在线决策；
- 技能头、转移头、时序对比头：**同一个 WLA checkpoint 的辅助头**，联合训练，不加载第二个模型；
- 在线执行器：**确定性**的 Viterbi/查表/伺服/终止谓词，没有学习权重；
- 如果官方对“模型”作最宽解释：回退到 C1（只用离线标签调 chunk/增益）或 C2（不加载技能头，用 VLA 动作与技能原型的 DTW 匹配）。

### 1.5 三个灵感词怎么落地

| 灵感词 | 落到哪里 | 不做什么 |
|---|---|---|
| **技能学习** | 自监督技能分割 + 技能词表 + 技能图 + 技能条件 chunk 调度 | 不训独立技能策略；不做在线 RL |
| **自监督学习** | 时序对比/变点检测产生技能伪标签；同一 checkpoint 的技能/转移辅助损失 | 不引入第二个在线编码器；不依赖人工阶段标签 |
| **研究空白** | 填补 VLA 平坦 chunk 与确定性伺服之间的“技能中间层”；在单模型/固定 chunk/远程 API 约束下验证 | 不重复“更大 VLA”“世界模型”“逐任务策略”的红海 |

## 2. 诊断：平坦 chunking 的四笔账

把 CHUNK-SERVO 的一次执行拆开：

```text
VLA plan:  [reach .... grasp .... lift .... align .... insert .... release]
执行块:     5步        5步        5步       5步       5步        5步
            ↑          ↑          ↑         ↑         ↑          ↑
          同一增益   同一增益   同一增益  同一增益  同一增益   同一增益
          同一终止   同一终止   同一终止  同一终止  同一终止   同一终止
```

四笔账：

1. **块长账**：自由空间 5 步太短，VLA 推理被浪费；接触段 5 步太长，反馈还是慢。固定 H 是折中，不是最优。
2. **增益账**：自由空间需要高增益快速接近；接触段需要低法向增益避免顶死。固定 K 必然在某一端保守。
3. **终止账**：没有技能级终止，VLA 只能等下一个 chunk 才发现“没插进去”；恢复延迟至少一个 chunk。
4. **复用账**：32 个任务共享 reach/grasp/lift，但每个 chunk 都是任务特定动作；技能没有被显式复用，长程任务（ToolboxStorage 37.6s、PackBag、SpellRobot）的复合误差没有技能级约束。

## 3. 方法草图：离线发现技能，训练时学技能，在线用技能调度

```text
离线（无标签）                         训练（同一 checkpoint）              在线（确定性）
┌──────────────────────┐          ┌──────────────────────┐          ┌──────────────────────┐
│ 33k demos            │          │ WLA action head       │          │ VLA plan (30步)       │
│  ├─ 特征 f_t          │          │  + skill head         │          │  + skill logits       │
│  ├─ 自监督分割 B      │  ──────▶ │  + transition head    │  ──────▶ │  ↓                    │
│  ├─ 技能聚类 K        │  伪标签   │  + contrastive aux    │  同一模型 │ Viterbi + skill graph │
│  ├─ 技能库/技能图     │          │  (冻结 VLM, 训头)     │          │  ↓                    │
│  └─ 技能成本 σ,ρ      │          └──────────────────────┘          │ 技能执行器：H/gain/终止 │
└──────────────────────┘                                            │  ↓                    │
                                                                    │ CHUNK-SERVO 伺服       │
                                                                    └──────────────────────┘
```

四个组件：

1. **自监督技能分割**：在降采样特征上用 RFF 核变点检测 + DP，得到每条演示的技能边界；在 30Hz 上局部细化。
2. **技能词表与技能图**：把段描述子聚类成 K 个技能；统计每个技能的特征分布、时长、归一化轨迹、出口原型、接触风险；统计技能转移矩阵。
3. **同一 checkpoint 的技能头**：WLA 的 action head 旁边加 skill/transition 辅助头，用伪标签 + 转移标签 + 时序对比损失联合训练；仍然只有一个 checkpoint。
4. **在线技能调度**：VLA 输出动作 + 技能 logits；Viterbi 在技能图上解码当前技能；技能执行器选择承诺步数 h_k、增益 K_k、终止谓词 T_k；剩余动作仍由 CHUNK-SERVO 伺服修正。

## 4. 关键设计选择与自我反驳

### 4.1 为什么用自监督分割，而不是人工标 94 个步骤？

人工标 94 个评分步骤只能覆盖“任务级”阶段，不能覆盖每条演示里的技能边界；33k 条演示人工标不起。自监督分割的噪声可以用三件事控制：降采样 + 最小段长 + 人工抽检 5×20 条；技能聚类的 K 用 held-out BIC/轮廓系数选；伪标签置信度低的帧不参与技能头损失。

### 4.2 为什么需要技能图，而不是只做技能分类？

因为长程任务。技能分类只告诉你“现在是什么”，技能图告诉你“下一步可能是什么”。在 ToolboxStorage、PackBag、SpellRobot 这类 20–38s 任务里，技能转移先验可以约束 VLA 的解码，减少“插入后突然去抓别的东西”这类复合错误。技能图是**软先验**，不是硬约束；置信度低时回退到无图 Viterbi。

### 4.3 为什么技能执行器是确定性的？

单模型合规。技能执行器只做四件事：查表（h_k、K_k、T_k）、Viterbi、几何伺服、终止判断。没有学习权重，不是第二个策略。技能头是同一 checkpoint 的辅助头，不是新模型。

### 4.4 如果 API 的 action_chunk_size 是固定值，怎么“按技能变块长”？

这是本轮必须写清楚的约束。README 说 `action_chunk_size` 固定；如果它是**整个提交固定**，就不能在线改反馈周期。SKILL-SEG 的处理是：

- **离线**选一个全局 `H_fixed`（例如 5），用技能频率加权的最优 chunk 成本来选；
- **在线**在固定长度的 chunk 内做“技能承诺”：前 h_k 步属于当前技能，后 H_fixed−h_k 步属于预测的下一个技能或安全保持；
- 如果实测允许每次调用改 `action_chunk_size`，再把 h_k 直接当反馈周期。

这样既不假设 API 支持变长 chunk，又保留了技能级调度的收益。**这是本轮最大的接口风险，必须在单任务通道先验证。**

### 4.5 如果技能分割错了怎么办？

三层回退：

1. 技能头置信度低（熵高/ECE 差）→ 回退到 CHUNK-SERVO 的固定 5 步，不启用技能调度；
2. 技能图解码的边际概率低 → 去掉图先验，只用技能头；
3. 技能终止连续失败 → 回退到 VLA 开环 + 重规划。

技能层是增益，不是安全关键路径；它永远不能阻止一个合法动作的返回。

## 5. 与第 10/11/12 轮的关系：保留、升级、剪枝

**保留**：

- FACT-VLA 的相位化 BC、CAC 柔顺执行、EGP 证据门控；
- GEO-RESIDUAL 的动作条件化残差、米制表面距离、编辑检测；
- CHUNK-SERVO 的双频执行、DG-KEYFRAME 相对目标、虚实标定、竞赛组合；
- 官方 WLA 基座、33k 演示、单任务通道。

**升级**：

- 固定 5 步 → 技能条件承诺 h_k + 固定 H_fixed 的 intra-chunk 组合；
- 固定增益 → 技能条件增益 K_k（自由空间/接触/释放不同）；
- 无技能终止 → 技能出口距离 + 时长 + 几何谓词；
- 手工相位 → 自监督技能伪标签 + 同一 checkpoint 技能头；
- 单任务 chunk → 技能图约束的长程解码。

**剪枝**：

- 不训独立技能策略/独立技能分类器/独立残差网络（单模型风险）；
- 不做在线 RL/技能探索（比赛不允许）；
- 不做人工 94 步阶段标签（不可扩展）；
- 不做 30Hz 广域网高频技能切换（RTT 不允许）；
- 不把技能图当硬约束（会锁死恢复）；
- 不假设 `action_chunk_size` 可变（未验证）。

## 6. 实验门 S0–S5

| 门 | 问题 | 通过标准 | 失败动作 |
|---|---|---|---|
| S0 | 自监督分割是否稳定？ | 人工抽检边界 F1 ≥0.7；边界抖动 ≤3 帧 | 降采样/加最小段长；改用固定相位 |
| S1 | 技能词表是否可复用？ | K=8–16；轮廓系数 ≥0.25；接触技能接触纯度 ≥0.8 | 调 K/特征；退回任务级相位 |
| S2 | 技能头是否校准？ | top-1 ≥0.8；ECE ≤0.05；转移图 held-out 似然优于均匀 | 温度缩放/降权；C2 无头模式 |
| S3 | 技能条件 chunk 是否优于固定 5 步？ | 仿真接触族 +5pp；oracle 与预测差距 ≤3pp | 只保留增益/终止，砍掉 h_k |
| S4 | 技能图是否改善长程？ | 长程任务 +3pp；短任务不回归 | 去图先验；只保留技能头 |
| S5 | 真机单任务是否涨点？ | ≥3/5 任务 +10pp；FoldTowel 不回归 >5pp；p99 ≤150ms | 不提交技能版；回退 CHUNK-SERVO |

继承第 12 轮的 G0–G7：腕部标定、演示检索、伺服收敛、真机涨点、干扰恢复、延迟、端口隔离、消融。S0–S5 是技能层新增的门；任何一门不过，技能层不进入正式提交。

## 7. 最大的风险

**技能伪标签和技能词表可能只拟合了演示里的任务分布，迁移不到比赛的 5 类泛化轴；一旦技能头在位置/背景/未见物品/人为干扰下退化成噪声相位分类器，技能调度就会把 CHUNK-SERVO 的稳定 5 步闭环拖成错误的相位切换。** 所以本轮把“技能头置信度低就回退固定 5 步”写成硬门，而不是可选优化。

## 8. 一句话押注

**用 33k 无标签演示自监督地发现技能词表和技能图，把技能伪标签学进同一个 WLA checkpoint，再用确定性技能调度器决定每个技能的执行长度、增益和终止——在不新增第二个策略模型的前提下，把 CHUNK-SERVO 的“固定 5 步闭环”升级为“按技能相位的闭环”。**

最大风险一句话：**技能层不是免费的——如果自监督分割学到的“技能”只是任务外观的聚类而不是可迁移的接触相位，它会用一个更自信的错误调度取代 CHUNK-SERVO 的保守固定块。**

# 第 13 轮产物 · SKILL-SEG 技术报告

> 检索/复核日期：**2026-10-31（UTC）**。对象：宇树 **UniBot 世界挑战赛**（G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API）。本报告是第 13 轮（新循环第 1 轮）想法区「SKILL-SEG」的工程化产物；不替换第 10 轮 FACT-VLA、第 11 轮 GEO-RESIDUAL、第 12 轮 CHUNK-SERVO，而是在它们之上增加“自监督技能分割 + 技能图 + 技能条件执行”层。**本轮没有新增真机实验数据；所有数字是设计目标、门限或待验证假设，不是实测结果。**

## 0. 结论与边界

### 0.1 一句话结论

CHUNK-SERVO 把反馈周期从 1s 降到 167ms，但对所有阶段使用同一 chunk 长度、同一伺服增益、同一终止条件；SKILL-SEG 用 33k 条无标签成功演示自监督地发现跨任务技能词表和技能图，把技能伪标签学进同一个 WLA checkpoint 的辅助头，在线用技能图 + Viterbi 解码当前技能，再用确定性执行器选择承诺步数、增益和终止谓词。它不新增第二个学习策略，目标是让“最后 3 厘米”的闭环按技能相位分配，而不是平均分配。

### 0.2 证据等级

| 等级 | 含义 | 本报告中的例子 |
|---|---|---|
| A | 官方文档、提交模板、数据集元数据、排行榜 JSON 直接核实 | 规则、API、33,276 eps、WLA `chunk_size=30`、单模型规则 |
| B | 在公开数据/网页上做的分析，可复现 | 榜单 `step~success` 回归、任务时长、技能重复性先验 |
| C | 设计假设，需 S0–S5/G0–G7 验证 | 自监督分割 F1、技能头校准、技能条件 chunk 涨点 |

### 0.3 本轮不做什么

- 不从零训 VLA/World Model；官方 WLA 已开源 6B 基座。
- 不训独立的技能策略/技能分类器/残差网络；技能头必须是同一 checkpoint 的辅助头。
- 不做在线 RL/技能探索；比赛不允许，数据也不支持。
- 不做人工 94 步阶段标签；自监督分割是唯一可扩展的标签来源。
- 不假设 `action_chunk_size` 可在线变化；先按“整个提交固定”设计，变长只作为待验证的加速项。
- 不做 30Hz 广域网高频技能切换；技能切换仍受 RTT 和固定 chunk 约束。
- 不把技能图当硬约束；它只是软先验，置信度低时回退。
- 不把 CHUNK-SERVO 的 5 步/相对目标/视觉伺服替换掉；技能层是它们上面的调度层。

### 0.4 与 CHUNK-SERVO 的接口

SKILL-SEG 不改变 CHUNK-SERVO 的动作生成主路径：

```text
VLA 30-step plan
   ↓
[SKILL-SEG 新增] 技能解码 → 当前技能 k、承诺步数 h_k、增益 K_k、终止谓词 T_k
   ↓
[CHUNK-SERVO 保留] 相对目标检索 + IBVS/PBVS 伺服 + 接触相位
   ↓
action adapter → 挑战赛 API
```

技能层只决定“这段动作属于哪个技能、执行多久、何时停/切”，不直接生成新的动作分布。这样即使技能层失效，系统仍能回退到第 12 轮的 CHUNK-SERVO。

## 1. 事实与约束（只列会改变算法的）

### 1.1 规则与 API（A）

沿用第 12 轮已核实的事实：

| 项 | 约束 | 对 SKILL-SEG 的影响 |
|---|---|---|
| 模型 | 所有任务须基于同一模型，不得混合多个模型 | 技能头必须是同一 checkpoint；离线分割/聚类不能在线加载 |
| 任务 | 32 项桌面任务，每任务 10 次 | 技能词表要跨任务共享，不能 32 个任务各一套 |
| 泛化 | 位置/干扰物/背景/未见物品/人为干扰各 2 次 | 技能头必须对视觉/位置扰动鲁棒；低置信度回退 |
| 时限 | 单次真机 180s | 长程任务需要技能级约束，减少复合误差 |
| 部署 | N 台机器人，8765 起连续端口，reset 隔离 | 技能库只读共享；每端口独立技能状态 |
| 动作 | `joint` 或 `ee` 互斥；EE 为绝对位姿 | 技能执行器输出仍走 EE 绝对位姿 |
| chunk | `action_chunk_size` 固定；chunk 内无新观测 | 不能假设在线变长；用固定 H_fixed + intra-chunk 组合 |
| 观测 | 4 路 RGB 480×640；无 depth/force/tactile | 技能终止只能用视觉/本体/夹爪代理信号 |
| 监控 | 评测端记录延迟、波动、动作统计 | 技能切换不能引入异常抖动；需要平滑混合 |

**关键推论 2**：无深度/无力觉意味着技能终止不能依赖“插入深度/接触力”的真值，只能用 GEO-RESIDUAL 的 `d_t, n_t, r_static, r_grasp`、EE 速度滞止、夹爪开合、视觉出口距离等代理。

### 1.4 关键推论：平坦 chunk 的“相位盲”

把 CHUNK-SERVO 的一个 30 步 plan 按技能切开，理想情况是：

```text
[reach 8步][align 4步][insert 5步][twist 3步][release 4步][...]
```

但 CHUNK-SERVO 实际执行是：

```text
[5步][5步][5步][5步][5步][5步]
```

两者的边界不对齐。后果：

1. 一个 5 步块可能横跨“对齐→插入”两个技能，伺服增益用错；
2. 技能终止发生在块中间，evaluator 仍会执行完整个块；
3. 下一个块开始时，VLA 才知道技能已经完成/失败，恢复慢一个块；
4. 长程任务没有技能图约束，VLA 可能在错误技能上继续采样。

### 2.2 特征定义

对每一帧定义

```math
f_t=\left[\ \mathrm{norm}(f^{\mathrm{prop}}_t)\ ;\ \mathrm{norm}(f^{\mathrm{vis}}_t)\ \right]\in\mathbb R^d,
```

其中：

- $f^{\mathrm{prop}}_t=[p^{\mathrm{ee}}_t(3),\,\mathrm{rpy}^{\mathrm{ee}}_t(3),\,g_t(2),\,\dot q_t(14),\,q^{\mathrm{lower}}_t(15)]$；
- $f^{\mathrm{vis}}_t$ 有两种模式：
  - **C2 模式（保守）**：手工特征，HSV 颜色直方图（48 维）+ ORB bag-of-words（64 维）+ 图像矩（7 维），不加载第二个学习编码器；
  - **C3 模式（主推）**：冻结的 WLA 视觉编码器输出（同一 checkpoint，256 维），只做特征，不做决策。
- `norm` 用演示集统计量做 z-score；图像特征做 L2 归一化。

**为什么不用任务 ID/语言作为技能特征**：防止技能词表退化成“任务分类器”。任务 ID 只用于技能图的 backoff 和检索过滤，不进入 $f_t$。

### 2.3 自监督技能分割

给定一条演示的特征序列 $f_{1:T}$，分割目标为

```math
Q(B)=\sum_{j=1}^{m} C(S_j)\;-\;\lambda\,m,
```

（等价于对每个边界罚 $\lambda$，只差一个常数 $\lambda$。）其中

```math
C(S)=\frac{1}{|S|^2}\sum_{u,v\in S}\kappa(f_u,f_v),
```

$\kappa(f,f')=\exp(-\|f-f'\|^2/(2\sigma^2))$ 是正定核，$\lambda>0$ 控制段数。约束每个段长 $|S_j|\ge L_{\min}$。

**解释**：$C(S)$ 是段内平均相似度；$Q(B)$ 奖励“段内相似”，惩罚“段太多”。这是无标签的核变点目标，不需要技能标签。

用随机傅里叶特征（RFF）近似核：

```math
z(f)=\sqrt{\frac{2}{r}}\left[\cos(\omega_1^\top f+b_1),\dots,\cos(\omega_r^\top f+b_r)\right],
```

其中 $\omega_i\sim\mathcal N(0,I/\sigma^2)$，$b_i\sim U[0,2\pi]$。于是

```math
\kappa(f,f')\approx z(f)^\top z(f'),\qquad
C(a,b)=\left\|\frac{1}{b-a+1}\sum_{t=a}^{b}z_t\right\|^2.
```

令 $Z_0=0$，$Z_t=\sum_{u=1}^{t}z_u$，则

```math
C(a,b)=\left\|\frac{Z_b-Z_{a-1}}{b-a+1}\right\|^2.
```

### 2.4 技能词表与技能库

对每个段 $S$，定义描述子

```math
\psi(S)=\left[\ \bar f_S;\ \log|S|;\ \Delta p^{\mathrm{ee}}_S;\ \Delta \mathrm{rpy}^{\mathrm{ee}}_S;\ \phi^{\mathrm{grip}}_S;\ \bar v_S;\ v^{\max}_S;\ \ell_S\ \right],
```

其中 $\bar f_S$ 是段内平均特征，$\Delta p^{\mathrm{ee}}_S$ 是段首到段尾的 EE 位移，$\phi^{\mathrm{grip}}_S$ 是夹爪开合统计（开/闭帧比例），$\bar v_S,v^{\max}_S$ 是 EE 速度统计，$\ell_S$ 是路径长度。

对全部段描述子做层次聚类（Ward），得到 $K$ 个技能。$K$ 用 held-out BIC/轮廓系数选择，并加一个“接触纯度”约束：接触技能中 $d_t<d_c$ 的帧比例 $\ge 0.8$。

每个技能 $k$ 的库条目：

```math
\Theta_k=\left(\mu_k,\Sigma_k,p_k^{\mathrm{dur}},E_k^{\mathrm{in}},E_k^{\mathrm{out}},\bar\tau_k^{\mathrm{traj}},h_k^*,T_k,\rho_k,\sigma_k^2\right).
```

- $\mu_k,\Sigma_k$：技能帧特征的均值/对角协方差；
- $p_k^{\mathrm{dur}}$：时长分布（对数正态拟合）；
- $E_k^{\mathrm{in}},E_k^{\mathrm{out}}$：入口/出口原型（段首/段尾各 3 帧的特征集合）；
- $\bar\tau_k^{\mathrm{traj}}$：EE 相对段首的归一化轨迹（重采样到 20 点）；
- $h_k^*$：由 §2.6 的成本函数得到；
- $T_k$：终止谓词（§2.7）；
- $\rho_k$：接触风险比例（段内 $d_t<d_c$ 的帧比例）；
- $\sigma_k^2$：EE 二阶差分（加速度）在段内的方差，作为扰动/曲率代理。

### 2.5 技能图与 HSMM

技能转移计数 $n_{kk'}$，用 Dirichlet 平滑：

```math
W_{kk'}=\frac{n_{kk'}+\alpha}{n_k+\alpha K},\qquad \alpha>0.
```

可选任务条件 backoff：

```math
W^{(t)}=(1-\beta)W+\beta W_t,\qquad \beta\in[0,0.3],
```

其中 $W_t$ 是任务 $t$ 的转移计数平滑结果。任务条件只用于长程任务的软先验，不进入技能特征。

把技能序列建模为隐半马尔可夫模型（HSMM）：

- 隐状态 $s_t\in\{1,\dots,K\}$；
- 时长 $d_t$，转移
  ```math
  p(s_{t+1}=k'\mid s_t=k,d_t)=
  \begin{cases}
  W_{kk'}, & d_t\ge d_{\min,k},\\
  \mathbf 1[k'=k], & d_t<d_{\min,k};
  \end{cases}
  ```
- 时长先验 $p_k(d)$；
- 发射 $p(f_t\mid s_t=k)=\mathcal N(f_t;\mu_k,\Sigma_k)$；
- VLA 技能头给出 $p_\theta(k\mid o_t)$。

在线后验：

```math
p(s_{1:H}\mid o_{1:H})\propto
\prod_{t=1}^{H}p_\theta(s_t\mid o_t)\;
\prod_{t=2}^{H}p(s_t\mid s_{t-1},d_{t-1})\;
\prod_{j}p_{s_j}(d_j).
```

主实现用一阶 HMM + 时长终止谓词（$O(HK^2)$）；完整 HSMM 作为可选扩展（$O(HK^2D_{\max})$）。

### 2.6 技能条件 chunk 调度

对技能 $k$，定义 chunk 成本

```math
J_k(H)=\underbrace{\frac{1}{2}w_e\sigma_k^2H^2}_{\text{开环漂移}}
+\underbrace{w_d\left(\frac{H}{f_c}+\tau\right)}_{\text{反馈延迟}}
+\underbrace{w_c\frac{c_{\mathrm{inf}}}{H}}_{\text{推理摊销}}
+\underbrace{w_r\rho_kH}_{\text{接触风险}}.
```

解释：

- 开环漂移：无反馈时误差随 $H$ 二次增长（常加速度/曲率）；
- 反馈延迟：$H/f_c+\tau$；
- 推理摊销：每个 chunk 一次 VLA 推理，$c_{\mathrm{inf}}/H$；
- 接触风险：接触技能越长，顶死/滑移风险越大。

一阶条件：

```math
J_k'(H)=w_e\sigma_k^2H+\frac{w_d}{f_c}+w_r\rho_k-\frac{w_cc_{\mathrm{inf}}}{H^2}=0.
```

令 $a=w_e\sigma_k^2$，$b=w_d/f_c+w_r\rho_k$，$c=w_cc_{\mathrm{inf}}$，得到

```math
aH^3+bH^2-c=0.
```

因为 $a,b,c>0$，三次函数在 $H>0$ 严格递增（导数 $H(3aH+2b)>0$），从 $-c$ 到 $+\infty$，所以**存在唯一正根**。又

```math
J_k''(H)=a+\frac{2c}{H^3}>0,
```

所以 $J_k$ 严格凸，唯一正根就是全局最优。用 Newton/二分求解，再裁剪到 $[H_{\min},H_{\max}]$ 并取整。

**固定 API chunk 的处理**：

- 离线选全局
  ```math
  H_{\mathrm{fixed}}^*=\arg\min_{H\in\mathcal H}\sum_{k}\pi_kJ_k(H),
  ```
  其中 $\pi_k$ 是技能频率，$\mathcal H=\{3,4,5,6,8,10,15,30\}$；
- 在线承诺
  ```math
  h_k=\min\left(H_{\mathrm{fixed}},\ \mathrm{round}(H_k^*)\right);
  ```
- 若实测允许每次调用变长，则直接用 $H_k^*$ 作为反馈周期；否则用 §3.6 的 intra-chunk 组合。

### 2.7 技能终止与恢复

出口距离：

```math
\delta_k(t)=\min_{f'\in E_k^{\mathrm{out}}}\|f_t-f'\|_{\Sigma_k^{-1}}.
```

终止谓词：

```math
T_k(o_t)=
\left[\delta_k(t)<\varepsilon_{\mathrm{exit}}\right]
\land
\left[d_t\in[d_{\min,k},d_{\max,k}]\right]
\land
G_k(o_t),
```

其中 $G_k$ 是技能相关的几何谓词：

- reach/transport：EE 到目标距离 $< \varepsilon_p$；
- align：视觉对齐误差 $< \varepsilon_a$；
- insert/hang/stack：$d_t\le d_c$ 且 EE 速度 $<v_\epsilon$ 连续 $n_{\mathrm{hold}}$ 帧；
- twist/zip/unlock：旋转增量达到目标或 $r_{\mathrm{grasp}}$ 稳定；
- release：夹爪张开且 EE 远离目标。

恢复触发：

```math
\text{recover if }
\left[\delta_k(t)\ \text{连续 } W \text{ 个 chunk 上升}\right]
\lor
\left[\text{duration}>d_{\max,k}\right]
\lor
\left[\text{skill head entropy}>\eta\right].
```

恢复动作：停 → 重定位 → 更新目标 → 继续；连续失败则回退 VLA 开环 + 重规划。

### 2.8 单模型合规的形式化

定义在线策略为

```math
\Pi_{\mathrm{online}}=(\theta,\mathcal D_{\mathrm{det}}),
```

其中 $\theta$ 是唯一 checkpoint，$\mathcal D_{\mathrm{det}}$ 是确定性函数集合（技能查表、Viterbi、伺服、终止、回退）。合规条件：

1. 在线推理只加载 $\theta$ 一份学习参数；
2. 技能头、转移头、时序对比头都是 $\theta$ 的一部分，联合训练；
3. 离线自监督编码器 $\psi$ 不在线加载；它只产生伪标签和原型；
4. $\mathcal D_{\mathrm{det}}$ 没有学习权重，不构成第二个策略；
5. 若官方对“模型”作最宽解释，回退 C1/C2（§9.1）。

## 3. 算法

### 3.1 总览

```text
离线阶段 A：特征 + 自监督分割
  33k demos → f_t → 5Hz 降采样 → RFF → DP 变点 → 30Hz 边界细化
离线阶段 B：技能词表 + 技能图
  段描述子 → Ward 聚类 → K 技能 → 技能库 Θ_k → 转移矩阵 W
训练阶段：同一 checkpoint 的辅助头
  WLA action head + skill head + transition head + contrastive aux
在线阶段：技能解码 + 技能条件执行
  VLA plan + skill logits → Viterbi → k, h_k, K_k, T_k → CHUNK-SERVO → API
```

### 3.2 离线阶段 A：自监督分割

```text
输入：演示集 D，特征映射 f，最小段长 L_min，惩罚 λ，RFF 维度 r
输出：每条演示的边界 B_i

for each τ_i in D_discovery:
    f_t ← features(o_t), t=1..T_i
    f'_u ← mean(f_t in 5Hz window), u=1..T'_i
    z_u ← RFF(f'_u) ∈ R^r
    Z_0 ← 0; Z_u ← Z_{u-1}+z_u
    D[0] ← 0; back[0] ← -1
    for t=1..T'_i:
        D[t] ← -∞
        for s=0..t-L_min:
            C ← ||(Z_t-Z_s)/(t-s)||^2
            score ← D[s] + C - λ
            if score > D[t]:
                D[t] ← score; back[t] ← s
    B_i ← backtrack(back, T'_i)
    B_i ← refine_boundaries(B_i, f, window=±5 frames)  # 30Hz 局部搜索
```

**边界细化**：对每个降采样边界 $b$，在 30Hz 上搜索 $b'\in[b-5,b+5]$，最大化左右窗口的核两样本统计量（或用同一 $Q$ 的局部增量）。这样既省算力，又保留 30Hz 的边界精度。

**子集策略**：阶段 A 只用分层子集 $\mathcal D_{\mathrm{disc}}$（32 任务 × 100 条 = 3,200 条）发现技能词表；阶段 B 用原型匹配把技能标签推广到全部 33k 条（$O(NTKd)$），避免对 33k 条都做 $O(T^2)$ DP。

### 3.3 离线阶段 B：技能词表与技能图

```text
输入：所有段的描述子 ψ(S)，K 范围，接触阈值 d_c
输出：技能库 {Θ_k}，转移矩阵 W，技能伪标签 k_t

for K in K_range:
    clusters ← Ward(ψ(S), K)
    score ← heldout_BIC(clusters) + contact_purity(clusters)
K* ← argmax score

for each cluster k:
    μ_k, Σ_k ← mean/cov of frames in k
    E_in, E_out ← first/last 3 frames of each segment
    p_dur ← lognormal_fit(durations)
    traj ← resample(EE_relative_to_segment_start, 20)
    ρ_k ← fraction of frames with d_t < d_c
    σ_k^2 ← var(second_difference(EE_position))
    h_k* ← solve_chunk_cost(σ_k^2, ρ_k)
    T_k ← termination_predicate(k)
    Θ_k ← (μ_k,Σ_k,p_dur,E_in,E_out,traj,h_k*,T_k,ρ_k,σ_k^2)

count transitions n_kk' in discovery set
W ← Dirichlet_smooth(n_kk')
k_t ← nearest_prototype(f_t) for all demos (or VLA skill head after training)
```

**接触纯度**：对每个技能，计算段内 $d_t<d_c$ 的帧比例；如果某个技能被标为“接触技能”但纯度低，说明聚类把自由空间和接触混在一起，需要增大 $K$ 或换特征。

### 3.4 训练阶段：同一 checkpoint 的技能辅助头

WLA 的 action head 旁边加三个轻量头：

- skill head：$p_\theta(k\mid o_t)$，线性/2 层 MLP，输出 $K$ 类；
- transition head：$p_\theta(k_{t+1}\mid o_t)$，输出 $K$ 类；
- contrastive projection：$g_\theta(o_t)\in\mathbb R^{64}$，用于时序对比。

总损失：

```math
\mathcal L=
\mathcal L_{\mathrm{act}}
+\alpha\mathcal L_{\mathrm{skill}}
+\beta\mathcal L_{\mathrm{trans}}
+\gamma\mathcal L_{\mathrm{CPC}}.
```

其中

```math
\mathcal L_{\mathrm{skill}}=-\sum_t w_t\log p_\theta(k_t^*\mid o_t),
```

$w_t$ 是伪标签置信度权重：

- 距边界 $>3$ 帧：$w_t=1$；
- 距边界 $\le3$ 帧：$w_t=0.5$；
- 分割置信度低/多分割不一致：$w_t=0$。

```math
\mathcal L_{\mathrm{trans}}=-\sum_t\log p_\theta(k_{t+1}^*\mid o_t),
```

```math
\mathcal L_{\mathrm{CPC}}=-\sum_t\log
\frac{\exp(\mathrm{sim}(g_t,g_{t+\Delta})/T)}
{\sum_{g_-\in\mathcal N_t}\exp(\mathrm{sim}(g_t,g_-)/T)}.
```

正样本 $g_{t+\Delta}$ 取同段内未来帧；负样本 $\mathcal N_t$ 取其他 episode/其他段的帧。$\Delta$ 取 3–5 帧（0.1–0.17s）。

**训练细节**：

- 冻结 VLM（与 WLA 默认一致），只训 action head + robot-state projector + 三个辅助头；
- 辅助头参数量 <1M，不改变 24GB 显存预算；
- 伪标签来自阶段 B；训练/验证按 episode 划分，避免同一 episode 的相邻帧跨 split；
- 辅助损失权重 $\alpha=0.1,\beta=0.05,\gamma=0.05$，在验证集上扫。
- 如果辅助损失导致 action loss 回归 >2%，降低 $\alpha,\beta,\gamma$ 或只训 skill head（C2/C3 折中）。

### 3.5 在线阶段：`get_action`

```text
输入：obs_t，技能库，转移矩阵 W，H_fixed，token
输出：合法 action chunk（H_fixed × 21）

1. 更新相位/编辑观测（GEO-RESIDUAL）
2. 异步取 VLA plan：
     if plan cache valid: A[1:30], p_skill[1:30]
     else: 用旧 plan + 伺服；冷启动同步请求
3. 技能解码：
     if p_skill available:  # C3
         s_seq ← Viterbi(p_skill[1:H], W)
     else:                 # C2
         scores ← DTW_match(A[1:H], skill_prototypes)
         s_seq ← Viterbi(scores, W)
     k ← s_seq[1]; k_next ← s_seq[2]
4. 技能参数：
     h_k ← min(H_fixed, round(H_k*))
     K_k ← gain_table[k]
     goal ← goal_library.get(k, obs_t)  # CHUNK-SERVO 相对目标
5. 组合 chunk：
     C ← compose_chunk(A, k, k_next, h_k, obs_t, goal, K_k)
6. 终止/恢复：
     if T_k(obs_t): mark skill complete; 下一个 chunk 从 k_next 开始
     elif recover_condition: hold; re-localize; replan
7. 安全回退：
     if any exception/NaN/shape error: return last_valid_chunk or hold
8. return adapter.to_api(C, obs_t, token)
```

**Viterbi（HMM 主实现）**：

```text
logp[t,k] ← log p_theta(k|o_t)
delta[1,k] ← log pi_k + logp[1,k]
for t=2..H:
    for k'=1..K:
        delta[t,k'] ← max_k (delta[t-1,k] + log W[k,k']) + logp[t,k']
        psi[t,k'] ← argmax_k
backtrack from argmax_k delta[H,k]
```

**DTW 匹配（C2 模式）**：把 VLA 的前 $H$ 步动作与每个技能的原型轨迹 $\bar\tau_k^{\mathrm{traj}}$ 做 DTW，取负距离作为技能分数；再用 Viterbi 平滑。复杂度 $O(KH^2)$，$H=30,K=12$ → 10,800，可忽略。

### 3.6 技能条件 chunk 组合（固定 API 的关键）

```text
输入：A[1:H_fixed]，当前技能 k，下一技能 k_next，承诺 h_k，obs，goal
输出：C[1:H_fixed]

for j=1..h_k:
    C[j] ← servo(A[j], k, obs, goal, K_k)
for j=h_k+1..H_fixed:
    if confidence(k_next) > θ_switch:
        C[j] ← servo(A[j], k_next, obs, goal, K_{k_next})
    else:
        C[j] ← hold_or_retract(A[j])   # 安全保持/撤离
C ← min_jerk_blend(C, boundary=h_k, B=2)  # 2 步平滑
```

**为什么需要 intra-chunk 组合**：evaluator 会执行完整个 chunk 才再次调用 `get_action`；如果技能在 $h_k$ 步完成，剩余 $H_{\mathrm{fixed}}-h_k$ 步不能浪费在旧技能上。组合器把剩余步数交给下一个技能或安全保持，减少“技能完成后继续顶住”的接触风险。

**边界**：如果 $k_{\mathrm{next}}$ 置信度低，不要猜下一个技能；用 hold/retract，等下一个观测再决定。这保证安全，但会损失一点时间；在接触任务里，安全优先。

### 3.7 回退与安全

```text
if skill_head_entropy > η:           disable skill scheduling; use fixed H=5
if skill_graph_margin < m0:         drop graph prior; use skill head only
if goal_confidence < θ_c:           use CHUNK-SERVO PBVS/VLA fallback
if servo_error > δ_max for 3 chunks: hold; re-localize; replan
if skill termination fails > R:     abort skill; VLA replan
if any exception:                   last_valid_chunk or hold
```

所有分支都返回固定形状的合法动作；技能层永远不是安全关键路径。

## 4. 复杂度分析

### 4.1 离线

| 阶段 | 复杂度 | 说明 |
|---|---|---|
| 特征提取 | $O(NTd)$ | 图像编码器主导；可缓存 |
| 分割（子集 DP） | $O(N_{\mathrm{sub}}T'^2r)$ | $N_{\mathrm{sub}}=3{,}200$，$T'\approx T/6$，$r=64$ |
| 分割（全量，可选） | $O(NT'\log T'\,r)$ | 二分变点，贪心但快 |
| 边界细化 | $O(N_{\mathrm{sub}}mwr)$ | $w=5$ 帧 |
| 聚类 | $O(MKdI)$ | $M\approx16$k 段，$I\approx50$ 次迭代 |
| 技能库 | $O(Md+Kd^2)$ | 可忽略 |
| 全量伪标签 | $O(NTKd)$ | 矩阵乘；可 GPU 加速 |

数值估算：$N_{\mathrm{sub}}=3{,}200$，$T'=100$，$r=64$ → $3{,}200\times10^4\times64\approx2.0\times10^9$ 次乘加；在 32 核 CPU/单 GPU 上数小时可完成。全量伪标签 $33{,}276\times500\times12\times128\approx2.6\times10^{10}$，用 GPU 矩阵乘可压到小时级。

**存储**：

- 18.28M 帧 × 128 维 × 2 字节（fp16）≈ 4.7GB；只存降采样/关键帧可降到 <1GB；
- 技能库：K=12，每技能 <1MB，总计 <100MB；
- 技能图：$K^2$ 浮点，可忽略。

### 4.2 训练

与 WLA action-head 微调同阶：6B 模型，冻结 VLM，只训 action head + projector + 辅助头；单张 24GB GPU 可跑。辅助头 <1M 参数，显存/算力增量可忽略；数据加载和特征缓存是瓶颈。

### 4.3 在线

| 操作 | 复杂度 | 典型耗时 |
|---|---|---|
| VLA 推理 | 30 步 plan，4 步去噪 | 100–300ms（异步/缓存） |
| Viterbi | $O(HK^2)$ | $30\times144=4{,}320$，<1ms |
| DTW（C2） | $O(KH^2)$ | $12\times900=10{,}800$，<1ms |
| 技能查表 | $O(1)$ | 可忽略 |
| 伺服 | 特征 + 控制 | 几 ms |
| 组合/混合 | $O(H_{\mathrm{fixed}})$ | 可忽略 |

**关键**：VLA 推理仍是主延迟；技能层不能增加一个同步模型调用。技能头是同一 checkpoint 的前向，已经包含在 VLA 推理里；Viterbi/DTW 是 CPU 微秒级。

### 4.4 与 CHUNK-SERVO 的增量

- 离线：+ 分割/聚类/技能库（一次性，数天）；
- 训练：+ 三个辅助头（<1M 参数，<5% 训练时间）；
- 在线：+ Viterbi/查表（<1ms），无额外模型加载；
- 存储：+ <100MB 技能库；
- 风险：+ 技能伪标签/技能头校准（需要 S0–S2 门）。

## 5. 正确性论证

### 5.1 命题 1（分割 DP 最优性）

**命题**：在目标 $Q(B)=\sum_j C(S_j)-\lambda m$、最小段长 $L_{\min}$ 下，§3.2 的 DP 返回全局最优分割。

**证明**：设 $D[t]$ 为前缀 $1..t$ 的最优分数。任意前缀 $1..t$ 的最优分割的最后一个段必为 $s+1..t$（$0\le s\le t-L_{\min}$），前缀 $1..s$ 与最后一段独立，故
$D[t]=\max_s\{D[s]+C(s+1,t)-\lambda\}$。
对 $t$ 归纳：$D[0]=0$ 是空前缀最优；若 $D[s]$ 对所有 $s<t$ 最优，则上式枚举了所有可能的最后一段，取最大即 $D[t]$ 最优。回溯 `back[t]` 重建 argmax。$\square$

**注**：RFF 近似核会带来近似误差；误差随 $r$ 增大而减小。我们把它当作设计选择，S0 门用人工抽检验证。

### 5.2 命题 2（Viterbi 最优性）

**命题**：对一阶 HMM，转移 $W$、发射 $p_\theta(k\mid o_t)$，§3.5 的 Viterbi 返回 MAP 技能序列。

**证明**：标准动态规划。设 $\delta_t(k)$ 为到时刻 $t$ 为止、$s_t=k$ 的最优路径分数。最优路径在 $t-1$ 的前缀必须是到某个 $k'$ 的最优路径；否则替换前缀会得到更高总分。因此
$\delta_t(k)=\max_{k'}\{\delta_{t-1}(k')+\log W_{k'k}\}+\log p_\theta(k\mid o_t)$。
回溯得到 argmax。$\square$

**注**：HSMM 版本把“状态转移”换成“状态+时长”的半马尔可夫递归，最优性证明类似；主实现用 HMM + 时长终止谓词，是 HSMM 的近似。

### 5.3 命题 3（chunk 成本凸性与唯一解）

**命题**：$J_k(H)=\frac12w_e\sigma_k^2H^2+w_d(H/f_c+\tau)+w_cc_{\mathrm{inf}}/H+w_r\rho_kH$ 在 $H>0$ 严格凸，存在唯一全局最优；最优解是 $aH^3+bH^2-c=0$ 的唯一正根，其中 $a=w_e\sigma_k^2,b=w_d/f_c+w_r\rho_k,c=w_cc_{\mathrm{inf}}$。

**证明**：
$J_k''(H)=w_e\sigma_k^2+2w_cc_{\mathrm{inf}}/H^3>0$，故严格凸。
$J_k'(H)=aH+b-c/H^2$；当 $H\to0^+$，$J_k'\to-\infty$；当 $H\to\infty$，$J_k'\to+\infty$。由连续性，存在零点；由严格凸性，零点唯一，且是全局最小。
令 $J_k'=0$ 两边乘 $H^2$，得 $aH^3+bH^2-c=0$。三次函数导数 $H(3aH+2b)>0$（$H>0$），从 $-c$ 严格递增到 $+\infty$，故唯一正根。$\square$

### 5.4 命题 4（稳定性）

简化误差动态（每块一次修正，延迟 $d$ 块）：

```math
e_{n+1}=e_n-g\,e_{n-d},\qquad g=K_kh_k.
```

特征方程：

```math
z^{d+1}-z^d+g=0.
```

- $d=0$：$z=1-g$，稳定 iff $0<g<2$；
- $d=1$：$z^2-z+g=0$，稳定 iff $0<g<1$；
- $d\ge2$：稳定域随 $d$ 缩小；没有简单的“$g<1$”充要条件。

**实践**：对测得的 $\tau$ 和 $h_k$，用数值根轨迹选最大稳定 $g$；保守默认 $g\le0.5$，并随 $\tau$ 降档。接触技能 $g\le0.3$。这不是一个充要定理，而是一个可验证的设计规则；S3/G2 在仿真里扫 $\tau\in\{0,50,100,150\}$ms 验证。

### 5.5 命题 5（安全/合法性）

**命题**：§3.5 的 `get_action` 在任何分支都返回形状为 $H_{\mathrm{fixed}}\times21$ 的合法动作，不返回 NaN/Inf。

**证明**：构造上，所有异常分支返回 `last_valid_chunk` 或 `hold_chunk`；`last_valid_chunk` 在冷启动时初始化为零动作（合法保持）；`adapter.to_api` 对形状/数值做校验和裁剪。技能层失败只影响动作质量，不影响合法性。$\square$

### 5.6 假设与失效条件

| 假设 | 内容 | 失效后果 | 检测/回退 |
|---|---|---|---|
| A1 | 分割边界对应物理技能转换 | 技能头学到外观聚类 | S0 人工抽检；F1<0.7 回退固定相位 |
| A2 | 技能原型跨任务/扰动平稳 | 技能匹配漂移 | S1/S2；置信度低回退 |
| A3 | 技能头校准 | 错误相位切换 | ECE/熵阈值；C2 无头模式 |
| A4 | 技能图是软先验 | 长程任务被锁死 | 边际概率低去图 |
| A5 | `action_chunk_size` 固定 | 不能在线变长 | API 门先验证；intra-chunk 组合 |
| A6 | 成本模型 $J_k$ 近似真实误差 | $h_k$ 选择次优 | 仿真扫参；保守裁剪 |

**结论**：SKILL-SEG 的正确性是“条件正确性”：在 A1–A6 成立时，分割/Viterbi/成本最优性成立；假设失效时，回退路径保证系统退化为 CHUNK-SERVO，而不是崩溃。

## 6. 技能库与技能图的细节

### 6.1 关键帧与边界细化

- 分割边界在 5Hz 上得到，30Hz 上 ±5 帧细化；
- 接触技能：取“首次接触前 1–3 帧”和“接触稳定后 1 帧”作为入口/出口候选；
- 挂/叠/插入：取“目标进入腕部视野且夹爪距离 <5cm”的帧；
- 拉链/锁：取“夹爪咬合前”的帧；
- 变形任务：不建精确相对目标，只建相位/语义技能；伺服不启用。

### 6.2 技能描述子与聚类

描述子包含本体 + 视觉 + 时长 + EE 位移 + 夹爪统计。**不包含任务 ID/语言**，避免技能词表变成任务分类器。聚类用 Ward 层次聚类，K 用 held-out BIC/轮廓系数 + 接触纯度选择。

### 6.3 跨任务共享与任务条件

- 技能词表全局共享；任务条件只用于转移矩阵 backoff（$\beta\le0.3$）和目标检索过滤；
- 如果某任务需要专属技能（如 SyringeWaterTransfer 的推液），允许技能库包含任务特有技能，但技能头仍共享；
- 技能图剪枝：计数 <3 的边去掉；保留自环；对长程任务保留多条候选边。

### 6.4 数据划分与防泄漏

- 按 episode 划分，不按帧；
- 发现子集 $\mathcal D_{\mathrm{disc}}$ 与验证子集 $\mathcal D_{\mathrm{val}}$ 的 episode 不相交；
- 对 5 类泛化轴，尽量按 session/物体/背景分组；如果元数据不足，用视觉聚类近似分组；
- 技能头训练只用训练 episode 的伪标签；验证 episode 只用于选 K/超参；
- 不把测试任务的演示混入技能发现（如果官方测试任务与训练任务同分布，仍按 episode 隔离）。

### 6.5 技能库规模

- K=8–16；A 档 19 任务约 19k episodes；每 episode 3–8 个技能段 → 约 60–150k 段；
- 每段描述子 ~128 维 + 元数据；技能库 <100MB；
- 检索/匹配按任务/阶段分片；N 端口只读共享（copy-on-write）。

| 实验 | 变量 | 指标 | 门 |
|---|---|---|---|
| 技能条件 chunk | flat 5 vs SKILL-SEG（oracle/predicted） | 成功率、收敛、超调 | S3: 接触族 +5pp；oracle-predicted ≤3pp |
| 技能图 | 有图/无图 | 长程成功率、恢复 | S4: 长程 +3pp；短任务不回归 |
| 延迟 | $\tau=0,50,100,150$ms | 稳定域、p99 | G2 继承 |
| 扰动 | 位置/遮挡/背景/目标移动/人手 | 恢复率、检测延迟 | G4 继承 |
| 消融 | 技能头/图/h_k/增益/组合 | 成功率、误差 | S3/S4 |

每个组合至少 50 次仿真；报告成功率、收敛时间、超调、恢复率、p99。仿真只用于找稳定域和相对排序，不预测真机绝对成功率。

### 7.3 真机单任务

| 项 | 设计 |
|---|---|
| 任务 | PlugInEthernet、HangCup、ZipUp、StackBowls、FoldTowel（防回归） |
| 次数 | 每任务 5 次 A/B：CHUNK-SERVO vs SKILL-SEG |
| 初始条件 | 同一位置/背景；尽量配对 |
| 指标 | 成功、步骤分、耗时、p99、恢复次数、技能切换次数 |
| chunk | 先固定 H_fixed=5；通过后扫 3/8 |
| 通过 | ≥3/5 任务 +10pp；FoldTowel 不回归 >5pp；p99 ≤150ms |
| 统计 | 配对差值 + bootstrap 95% CI；5 次/任务只能看方向 |

### 7.4 全量

| 项 | 设计 |
|---|---|
| 任务 | 32×10 |
| 端口 | N 个连续端口 8765..8765+N−1 |

### 7.5 消融

1. 技能分割 on/off（固定相位 vs 自监督技能）。
2. 技能头 on/off（C2 DTW vs C3 skill head）。
3. 技能图 on/off。
4. 技能条件 $h_k$ vs 固定 $h_k=5$。
5. 技能条件增益 vs 固定增益。
6. intra-chunk 组合 on/off。
7. 分割特征：本体 only vs 本体+手工视觉 vs 本体+WLA 编码器。
8. K 扫描：6/8/12/16/24。
9. 伪标签噪声注入：随机翻转 5%/10%/20% 边界，测技能头鲁棒性。
10. RTT/延迟扫描：0/50/100/150ms。

### 7.6 门 S0–S5 与继承 G0–G7

| 门 | 问题 | 通过标准 | 失败动作 |
|---|---|---|---|
| S0 | 分割稳定？ | 人工抽检 F1≥0.7；抖动≤3 帧 | 降采样/加最小段长；回退固定相位 |
| S1 | 技能词表可复用？ | K=8–16；轮廓≥0.25；接触纯度≥0.8 | 调 K/特征；退回任务级相位 |
| S2 | 技能头校准？ | top-1≥0.8；ECE≤0.05；转移似然优于均匀 | 温度缩放/降权；C2 无头模式 |
| S3 | 技能条件 chunk 优于固定 5？ | 仿真接触族 +5pp；oracle-predicted≤3pp | 只保留增益/终止，砍 h_k |
| S4 | 技能图改善长程？ | 长程 +3pp；短任务不回归 | 去图；只保留技能头 |
| S5 | 真机单任务涨点？ | ≥3/5 +10pp；FoldTowel 不回归；p99≤150ms | 不提交技能版；回退 CHUNK-SERVO |
| G0–G7 | 第 12 轮的标定/检索/伺服/干扰/延迟/端口/消融 | 同第 12 轮 | 同第 12 轮 |

**总原则**：S0–S5 是技能层新增门；任何一门不过，技能层不进入正式提交。技能层是增益层，不是安全关键路径。

### 7.7 统计

- 320 trials 下，$p\approx0.25$ 时 $\mathrm{SE}(S)\approx2.42$pp；不要声称 +1–2pp 是结论。
- 单任务 A/B 用配对差值；5 次/任务只报方向 + bootstrap CI。
- 离线分割用 episode-level bootstrap；报告 95% CI。
- 消融报告效应量 + CI，不只报均值。

## 9. 风险与合规

### 9.1 单模型合规的三种模式

| 模式 | 做法 | 风险 | 建议 |
|---|---|---|---|
| C1 离线标签 | 技能分割/聚类只离线产生标签；在线只有 WLA + CHUNK-SERVO；技能层只用于离线调 H/增益/终止 | 最低 | 保守首选 |
| C2 确定性匹配 | 在线 WLA + DTW/原型匹配 + 确定性执行器；不加载技能头 | 低 | 主推的保守版 |
| C3 同 checkpoint 技能头 | 技能/转移/对比头是同一 WLA checkpoint 的辅助头，联合训练 | 低–中；需说明 | 主推的性能版 |

禁止：加载第二个学习策略/残差网络/独立视觉编码器做在线决策；离线自监督编码器只用于伪标签，不参与在线推理。

### 9.2 风险表

| 风险 | 影响 | 缓解 |
|---|---|---|
| 技能伪标签噪声 | 技能头学错相位 | 置信度加权；边界 margin；多分割一致性；S0/S2 门 |
| 技能词表不迁移 | 泛化轴掉点 | K 扫描；任务条件 backoff；低置信度回退固定 5 步 |
| 技能图过约束 | 长程任务锁死 | 软先验；边际概率低去图；保留自环/多候选边 |
| 单模型解释 | 被判定第二个模型 | C1/C2/C3；离线编码器不线上；提交材料写清楚 |
| `action_chunk_size` 固定 | 不能在线变长 | 先验证；H_fixed 离线选；intra-chunk 组合 |
| 成本模型失配 | h_k 次优 | 仿真扫参；保守裁剪；S3 门 |
| 技能头校准差 | 错误切换 | 温度缩放；熵阈值；C2 回退 |
| 数据泄漏 | 离线指标虚高 | episode/session/object 分组；相邻帧不跨 split |
| 计算量大 | 离线分割慢 | 子集发现 + 全量原型匹配；RFF；降采样；GPU 并行 |
| 评测噪声 | +1–2pp 假阳性 | 配对 A/B；bootstrap；重复实验；320 trials SE≈2.4pp |
| 安全 | 技能切换抖动/碰撞 | 限速/限幅；min-jerk 混合；hold/retract；最大重试 |
| 技能终止误判 | 提前释放/继续顶住 | 多信号与门；连续 hold 帧；恢复重定位 |

### 9.3 最大风险

**技能伪标签和技能词表可能只拟合了演示里的任务分布，迁移不到比赛的 5 类泛化轴；一旦技能头在位置/背景/未见物品/人为干扰下退化成噪声相位分类器，技能调度就会把 CHUNK-SERVO 的稳定 5 步闭环拖成错误的相位切换。** 这是本轮方案的最大风险，也是 S0/S1/S2/S5 门要优先回答的问题。

## 11. 一句话押注与最大风险

**一句话押注**：用 33k 条无标签演示自监督地发现技能词表和技能图，把技能伪标签学进同一个 WLA checkpoint，再用确定性技能调度器决定每个技能的执行长度、增益和终止——在不新增第二个策略模型的前提下，把 CHUNK-SERVO 的“固定 5 步闭环”升级为“按技能相位的闭环”。

**最大风险一句话**：技能层不是免费的——如果自监督分割学到的“技能”只是任务外观的聚类而不是可迁移的接触相位，它会用一个更自信的错误调度取代 CHUNK-SERVO 的保守固定块。
