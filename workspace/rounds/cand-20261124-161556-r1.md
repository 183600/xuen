动研究循环·新灵感二元组第 1 轮；本轮灵感：「全身控制」×「SLAM」

> **基线**：第 2 轮产出 MetricVoiceGauge-NCD-HUTDH-v22+IP-431–435（HDL/ACSC/DCSC/HPC-E/CFC++；其上承 v21 语义-规范层 SDC/CAC/DCL/GIC 与 v20 联邦感知证书）。本轮只做一件事：**把"已知地图上、底座与手臂分开的点碰撞证书"升级为"带漂移的不确定地图上、全身构型轨迹的可认证管（certified tube）"**。不推倒 v22：语义/义务/意图、分层 PGEV、臂配空间能量、深度 conformal 全部保留。

## 0. 直觉与动机

**灵感 1（全身控制 → 安全是构型集合的不变性，不是点的属性）**
直觉：v22 把底座和机械臂当作两个几乎独立的证书对象——底座负责平面避障，手臂负责配空间能量与臂端 CertBox。但真实的机器人是一个**耦合动力学系统**：抬臂可以挪动质心、收臂可以"让出间隙"、侧身可以让底座挤过窄门。因此"这个点安不安全"这个问法本身就不完整，正确的对象是"**这条全身构型轨迹能否被一条已验证的控制律保持在安全核内**"。反直觉点：主动重构既是解药也是毒药——"为了不碰撞而改变姿态"本身引入新的失效源（自碰撞、支撑多边形缩小、关节极限、动态失稳），而且在两个可行姿态间来回切换会造成**主动振荡**。于是本轮的核心从"点避障"升级为**前向不变性（forward invariance）**：安全核 `K_wbc` 是一个集合，只要初始状态在核内、控制律满足不变性见证 `W_inv`，整个执行期都留在核内。

**灵感 2（SLAM → 证书必须携带地图版本与相对不确定性）**
直觉：此前所有证书都默认"地图已知、位姿已知"。SLAM 说两者都是带漂移、带协方差的估计，而且循环依赖：用地图定位、用位姿建图。最危险的时刻是**回环闭合（loop closure）**——一张地图会"跳变"，旧的自由空间可能突然变成障碍、走廊可能"折叠"。关键反直觉点：**不要直接用绝对位姿协方差去膨胀证书，那会过度保守**。因为在同一张地图里，机器人与障碍的位姿误差高度**相关**；碰撞裕度真正需要的是两者之间的**相对变换协方差 `Σ_rel`**，而 `Σ_rel ⪯ Σ_ξ + Σ_obs`。用相对帧评估碰撞，既保持声音性（soundness），又大幅减少绝对协方差带来的活性损失。代价是证书必须绑定地图版本：回环跳变超过局部度量一致性半径 `ρ_map` 时，所有引用旧地图版本的证书必须被**追溯失效**，只能重新认证（更保守）或 SafeStop，绝不静默打补丁。

**统一：自指闭环与它的解法**
全身构型 `q=(q_b,q_a)` 同时扮演三重角色：(a) WBC 的控制变量，(b) SLAM 的估计状态，(c) 证书的判定变量。这构成危险的**自指闭环**：机器人的动作改变了它所依赖地图的不确定性，而它又用这张地图去认证这个动作——证书可能"自我实现却错误"。本轮不假装消除这个闭环，而是给它一个可审计的结构：用**收缩性（contraction）/ 单调 Lyapunov** 论证把主动感知的收益当作"预算"来花，并要求每个证书携带 `(地图版本哈希, 局部度量半径, 相对协方差上界, 不变性见证)` 四元组。共享状态扩展为 `ζ_wbc = ζ_pgev ∪ (Σ_ξ, Σ_rel, m_t, ρ_map, W_inv)`；统一准入门 **HPC-W = (HPC-E, WBSK 不变性, 相对帧证书, 地图溯源有效)**，任一缺失向 v22 甚至更保守退化。`Exec_v23 ⊆ Exec_v22` 仍成立。

## 2. 设计原则（在 P37–P42 基础上新增 P43–P46）

**P43 全身构型一致性律（Whole-Body Configuration Coherence）**
证书定义在 `q=(q_b,q_a)` 上，而非底座与手臂两套独立证书。任何底座运动计划必须与它所诱导的臂重构**联合**认证；自运动（抬臂/收臂/侧身）只有在**整条过渡管**可行时才被允许——端点安全不蕴含过程安全。证书必须能检出并拒绝在两个可行姿态间的高频切换（主动振荡守卫）。

**P44 前向不变性证书律（Forward-Invariance Certification）**
安全 = `s(0) ∈ K_wbc ∧ W_inv(π_wbc, K_wbc)`，其中 `W_inv` 要求在模型误差 `d_gap` 被扣除后的**鲁棒裕度**下，核沿控制律收缩/不变。`W_inv` 失败（模型超界、支撑多边形消失、自碰撞）⇒ 退回 v22 的分离证书并冻结构型（保守），不得用未认证的主动重构"赌"过去。

**P45 相对帧证书律（Relative-Frame Certificate Soundness）**
碰撞裕度在机器人-障碍**相对帧**评估，使用 `Σ̂_rel ⪰ Σ_rel^true`（含交叉项）；仅当跨子图/低相关/动态障碍使 `Σ̂_rel` 不可证时，才回退绝对帧 + 全协方差膨胀（更保守）。硬约束：相对帧**永不得**取低于真实相对不确定的界（声音性优先于活性）。

**P46 地图溯源与回环失效律（Map Provenance & Loop-Closure Invalidation）**
每个证书绑定 `(Hash(M_t), ρ_map, Σ̂_rel, W_inv)`。回环跳变 `δ_lc > ρ_map` 时，所有引用旧地图版本的证书按依赖半径**追溯失效**；失效只能导致重新认证（加保守）或 SafeStop，绝不静默修补地图后继续复用旧证书。故 `Exec_v23 = Exec_v22 ∩ Fil_wbc ∩ Fil_relframe ∩ Fil_map`，且过滤器只做交/删除：`Exec_v23 ⊆ Exec_v22`。

## 3. 与基线的接口（如何退化）

- WBC 失效 / `K_wbc` 不可计算 ⇒ 冻结构型，退回 v22 的底座+臂分离证书 ⇒ 子集；
- `W_inv` 见证失败（动力学超 `d_gap`、自碰撞、支撑多边形消失）⇒ 静态站立 + v21 静态人距上限 ⇒ 子集；
- 相对帧不可证（`Σ̂_rel` 无上界/低相关）⇒ 绝对帧 + 全协方差膨胀 ⇒ 比 v22 更保守，安全方向不变；
- 地图版本过期或回环未复核 ⇒ 该区域证书作废，退回"可能有人/可能有物"的保守假设 ⇒ 子集；
- 主动感知误判 ⇒ 禁止主动，退回被动保守 ⇒ 子集；
- 全部失效 ⇒ 完全回退 v22 ⇒ `Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20`。
- **安全继承**：WBSK 只认更小的核、WBRT 只认更短的管、RFSC 只认可证的上界、MPLAC 只删不增；任意失效都向更保守方向退化，绝不因主动重构而扩大执行集。

## 4. 预期贡献（在 1–9 基础上延伸）

10. **全身不变性证书**：首次把碰撞安全从"点条件"升级为"全身构型集合的前向不变性 + 可达管"，并显式给出主动重构的振荡守卫与空集降级路径；
11. **相对帧 SLAM 证书**：利用位姿相关性的**声音且更紧**的碰撞证书，减少绝对协方差系统性导致的活性损失，并给出退化到绝对帧的充分条件；
12. **地图溯源与回环追溯失效**：可审计的地图版本链与依赖半径受限的追溯失效，堵住"回环把自由空间变障碍/折叠"的静默风险；
13. **主动感知-认证耦合**：以收缩性/单调 Lyapunov 切断"动作改变它据以认证的地图"的自证闭环，把感知收益显式预算化；
14. **HPC-W 统一准入门**：`HPC-W = HPC-E ∪ WBSK 不变性 ∪ 相对帧 ∪ 地图溯源`，形成 `Exec_v23 ⊆ Exec_v22` 的单调安全闭环。

## 5. 本轮最大风险

**一句话**：全身主动重构与 SLAM 不确定性构成一个**自指闭环**——机器人为"创造间隙"而移动身体，而这个动作同时改变了它据以认证的地图；一旦可行核 `K_wbc` 的动力学模型与现实差距超出 `d_gap`（打滑、未建模负载、接触非线性），"前向不变"会在仿真中成立、在现实中失效，形成比静态保守更危险的"**主动自证幻觉**"。

## 2. 关键算法骨架（在 IP-431–435 骨架上扩展）

from dataclasses import dataclass, field
import numpy as np

@dataclass
class WholeBodyState:
    q_base: np.ndarray      # 底座位姿
    q_arm: np.ndarray       # 臂关节
    qdot: np.ndarray        # 全身速度
    t: float = 0.0

class WholeBodySafetyKernel:               # IP-436
    def __init__(self, model, d_gap, m_stab, margin_req):
        self.model, self.d_gap, self.m_stab = model, d_gap, m_stab
        self.margin_req = margin_req

    def com(self, q):
        return self.model.whole_body_com(q.q_base, q.q_arm)

    def support_polygon(self, q):
        return self.model.contact_support(q.q_base, q.q_arm)

    def is_in_kernel(self, s, obs):
        """K_wbc 的成员判定：CoM 在收缩后的支撑多边形内 + 关节极限 + 自碰撞 + 外部碰撞。"""
        if not self.model.within_joint_limits(s.q_arm):
            return False
        if self.model.self_collision(s.q_arm):
            return False
        if not self.model.com_in_support(self.com(s), self.support_polygon(s), self.m_stab):
            return False
        margin = self.model.min_signed_distance(s, obs)   # 全身（含臂）到障碍的最小有符号距离
        return margin >= self.margin_req

    def invariance_witness(self, s, policy, horizon, dt):
        """W_inv：沿控制律的鲁棒前向不变见证。
        要求：名义管内的最小安全裕度扣除模型误差 d_gap 后仍 > 0，
        且一个单调 Lyapunov/barrier 函数 V 沿闭环满足 V̇ ≤ -c·(V - V*)（收缩）。"""
        min_robust_margin = float("inf")
        prev_V = self.model.barrier(s, self.support_polygon(s))
        for k in range(int(horizon / dt)):
            u = policy(s)
            s = self.model.integrate(s, u, dt)
            if not self.is_in_kernel(s, self.model.obstacles_at(s.t)):
                return False, "KERNEL_ESCAPED"
            min_robust_margin = min(min_robust_margin,
                                    self.model.min_signed_distance(s, self.model.obstacles_at(s.t)) - self.d_gap)
            V = self.model.barrier(s, self.support_polygon(s))
            if V - prev_V > 0 and V > self.model.V_star:   # 违反收缩
                return False, "CONTRACTION_VIOLATED"
            prev_V = V
        return min_robust_margin > 0, "OK"

class WholeBodyReachableTube:              # IP-437
    def __init__(self, kernel, model, d_gap, switch_eps=1e-2):
        self.kernel, self.model, self.d_gap = kernel, model, d_gap
        self.switch_eps = switch_eps

    def certify(self, s0, plan, horizon, dt):
        """认证整条过渡管：逐状态在核内 + 端点/中间点双向可达 + 振荡守卫。"""
        if not self.kernel.is_in_kernel(s0, self.model.obstacles_at(0.0)):
            return False, "S0_OUTSIDE_KERNEL"
        prev_cfg_signature = None
        flips = 0
        s = s0
        for k in range(int(horizon / dt)):
            s = self.model.integrate(s, plan.control(s, k * dt), dt)
            if not self.kernel.is_in_kernel(s, self.model.obstacles_at(s.t)):
                return False, "TUBE_LEAVES_KERNEL"
            # 主动振荡守卫：相邻时刻构型"切换意图"是否高频反转
            sig = self.model.reconfiguration_intent(s, plan)
            if prev_cfg_signature is not None and sig * prev_cfg_signature < 0:
                flips += 1
            prev_cfg_signature = sig
        if flips > self.model.max_reconfig_flips:
            return False, "ACTIVE_OSCILLATION"
        return True, "OK"

class RelativeFrameSLAMCertificate:        # IP-438
    def __init__(self, slam, k_sigma=3.0):
        self.slam, self.k_sigma = slam, k_sigma

    def relative_covariance(self, robot_id, obs_id):
        """从因子图边缘化导出相对协方差，显式保留交叉项 Σ_ro。"""
        Sigma_r, Sigma_o, Sigma_ro = self.slam.marginals_and_cross(robot_id, obs_id)
        J = self.slam.relative_transform_jacobian(robot_id, obs_id)
        Sigma_rel_true = J @ (Sigma_r + Sigma_o - 2.0 * Sigma_ro) @ J.T
        # 声音上界：加行列式/范数安全余量，确保 Σ̂_rel ⪰ Σ_rel_true
        return Sigma_rel_true + self.slam.bound_slack * np.eye(Sigma_rel_true.shape[0])

    def sound_margin(self, robot_pose, obs_box, Sigma_rel_hat):
        """相对帧碰撞裕度：有符号距离减去 k·σ_max(Σ̂_rel)。"""
        sigma_max = float(np.sqrt(np.linalg.eigvalsh(Sigma_rel_hat).max()))
        d = self.slam.signed_distance_relative(robot_pose, obs_box)
        return d - self.k_sigma * sigma_max

    def certify(self, robot_id, obs_id, obs_box, min_margin):
        if self.slam.cross_terms_available(robot_id, obs_id):
            Sigma_rel_hat = self.relative_covariance(robot_id, obs_id)
            if self.sound_margin(self.slam.pose(robot_id), obs_box, Sigma_rel_hat) >= min_margin:
                return True, "REL_FRAME"
        # 回退：绝对帧 + 全协方差膨胀（更保守）
        Sigma_abs = self.slam.marginal(robot_id) + self.slam.marginal_obs(obs_id)
        sigma_max = float(np.sqrt(np.linalg.eigvalsh(Sigma_abs).max()))
        d = self.slam.signed_distance_absolute(robot_id, obs_box)
        return (d - self.k_sigma * sigma_max >= min_margin), "ABS_FRAME_CONSERVATIVE"

class MapProvenanceAudit:                  # IP-439
    def __init__(self, rho_map):
        self.rho_map = rho_map
        self.deps = {}          # cert_id -> (map_hash, dependent_region)
        self.valid = {}         # cert_id -> bool

    def register(self, cert_id, map_hash, region):
        self.deps[cert_id] = (map_hash, region)
        self.valid[cert_id] = True

    def on_loop_closure(self, delta_lc, old_map_hash, dist_fn):
        """回环跳变超过一致性半径：按依赖半径追溯失效，只删不增。"""
        if delta_lc <= self.rho_map:
            return []           # 跳变在容差内，证书仍有效
        invalidated = []
        for cert_id, (h, region) in self.deps.items():
            if h == old_map_hash and dist_fn(region) <= self.rho_map:
                self.valid[cert_id] = False
                invalidated.append(cert_id)
        return invalidated      # 调用方须重认证或 SafeStop，绝不静默复用

class ActivePerceptionCertificationController:   # IP-440
    def __init__(self, kernel, tube, rfsc, budget_max):
        self.kernel, self.tube, self.rfsc = kernel, tube, rfsc
        self.budget_max = budget_max

    def choose(self, s, candidates):
        """在"不破坏不变性/收缩性"的候选动作中，选不确定性降低最大者。
        收益预算 J_cert 不得超过 budget_max，防止用安全裕度偷偷购买观测。"""
        best, best_gain = None, 0.0
        for a in candidates:
            if not self.kernel.is_in_kernel(self._step(s, a), self.kernel.model.obstacles_at(s.t)):
                continue
            ok, _ = self.tube.certify(s, self._plan(a), horizon=0.5, dt=0.02)
            if not ok:
                continue
            gain = self.rfsc.expected_uncertainty_reduction(s, a)
            if 0.0 < gain <= self.budget_max and gain > best_gain:
                best, best_gain = a, gain
        return best, best_gain   # None ⇒ 保持被动保守

class HPCW:                                # IP-441
    def __init__(self, hpce, kernel, tube, rfsc, audit):
        self.hpce, self.kernel, self.tube = hpce, kernel, tube
        self.rfsc, self.audit = rfsc, audit

    def admits(self, plan, s0, obs_id, obs_box, map_ctx):
        # HPC-E（几何∧规范∧负信息∧能量∧证伪）原样保留
        if not self.hpce.admits(plan.theta, plan.x, plan.v, plan.z, plan.E_res, self.kernel.margin_req):
            return False, "HPCE_FAIL"
        # 全身安全核与不变性见证
        in_k = self.kernel.is_in_kernel(s0, plan.obstacles_at(0.0))
        w_ok, w_why = self.kernel.invariance_witness(s0, plan.control, plan.horizon, plan.dt)
        if not (in_k and w_ok):
            return False, f"WBSK_FAIL:{w_why}"
        # 全身过渡管（含振荡守卫）
        tube_ok, tube_why = self.tube.certify(s0, plan, plan.horizon, plan.dt)
        if not tube_ok:
            return False, f"WBRT_FAIL:{tube_why}"
        # 相对帧证书（不可证则绝对帧更保守，仍可放行但记录）
        rel_ok, rel_mode = self.rfsc.certify(plan.robot_id, obs_id, obs_box, self.kernel.margin_req)
        if not rel_ok:
            return False, "RFSC_FAIL"
        # 地图溯源：证书必须绑定当前有效地图版本
        if not self.audit.valid.get(map_ctx.cert_id, False) or self.audit.deps[map_ctx.cert_id][0] != map_ctx.map_hash:
            return False, "MAP_PROVENANCE_INVALID"
        return True, f"OK:{rel_mode}"

## 3. 形式化推导（引理 163–166）

**引理 163（前向不变性蕴含执行期安全）**
设 `Viable_T ⊇ K_wbc` 为 `T`-步可行核。若 `s0 ∈ K_wbc`，且存在控制律 `π_wbc` 与见证 `W_inv`，使对任意模型误差 `e`（`‖e‖ ≤ d_gap`）有名义安全裕度 `m_nom(t) - d_gap > 0` 且障碍函数沿闭环满足 `V̇ ≤ -c(V - V*)`，则闭环轨迹 `s(t) ∈ K_wbc, ∀t ∈ [0,T]`。由 `K_wbc` 定义（CoM 在收缩支撑多边形内、关节/自碰撞/外部碰撞裕度均 ≥ `margin_req`）知执行期不碰撞。**证**：反设首次离开时刻 `t*`，由 `W_inv` 的鲁棒裕度与收缩条件，`t*` 前 `V` 被压向 `V*` 且核边界不可穿越，与"首次离开"矛盾。∎
（推论：端点安全 ≠ 过程安全，故必须认证整条 `Tube_T`，见 P43/IP-437。）

**引理 164（相对帧证书的声音性与紧致性）**
设机器人与障碍位姿的联合协方差为 `Σ = [[Σ_r, Σ_ro],[Σ_roᵀ, Σ_o]]`。绝对帧裕度使用 `Σ_r + Σ_o`；相对帧使用 `Σ_rel^true = J(Σ_r + Σ_o - 2Σ_ro)Jᵀ`。当 `Σ_ro ⪰ 0`（正相关）时 `Σ_rel^true ≼ J(Σ_r + Σ_o)Jᵀ`。故：用 `Σ̂_rel ⪰ Σ_rel^true` 的相对帧证书**声音**；若直接以绝对帧 `Σ_r + Σ_o` 评估，则**过于保守**（多扣了 `2Σ_ro` 对应项）。因此 RFSC 在保持声音性的同时获得更紧的裕度；当交叉项不可得或 `Σ_ro` 非正时，必须回退绝对帧（P45 硬约束）。∎

**引理 165（回环追溯失效保持单调安全）**
失效操作只把证书从有效集移除（`valid: true → false`），从不新增证书或放宽裕度，故失效后执行集是失效前的子集。由 P46，`δ_lc > ρ_map` 时调用 `on_loop_closure` 仅失效 `Dep(c)` 半径内引用旧 `Hash(M_t)` 的证书，其余保持；因此 `Exec_v23` 在回环事件前后单调不增。级联上界由依赖半径 `ρ_map` 限制；若依赖半径覆盖全域，则退化为全域 SafeStop（保守但安全）。∎

**定理 166（HPC-W 安全继承）**
`HPC-W = HPC-E ∧ WBSK_inv ∧ WBRT ∧ RFSC ∧ MapProvValid`。五个合取项各自或原样保留 v22 门（`HPC-E`）、或只收紧构型集（`WBSK_inv, WBRT`）、或只在相对/绝对帧中取更保守者（`RFSC`）、或只删除证书（`MapProvValid`）。每个合取项失败都只会把计划从准入门中删除，不会加入 v22 不允许的计划。因此 `Exec_v23 = Exec_v22 ∩ Fil_wbc ∩ Fil_relframe ∩ Fil_map ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20`。∎

## 4. 实验设计

- **平台**：轮式底座 + 6-DoF 机械臂；室内杂乱环境（窄门、走廊退化、动态行人）；ORB-SLAM3 / 因子图后端，人工注入回环闭合。
- **对照**：(A) v22（底座/臂分离、绝对帧、静态地图假设）；(B) v23 去 RFSC（绝对帧）；(C) v23 去 WBRT（只认端点）；(D) 完整 v23。
- **指标**：碰撞率、任务成功率（活性）、假自由空间率（AbsCert 失效处）、管认证率、回环失效级联规模、主动振荡次数、平均相对协方差。
- **消融/对抗**：
  1. 回环把走廊"折叠"（旧自由空间变障碍）→ 检验 MPLAC 追溯失效；
  2. 负载/打滑超出 `d_gap` → 检验 `W_inv` 失败降级而非伪造不变性；
  3. 机械臂自运动在两个可行姿态间高频切换 → 检验振荡守卫；
  4. 主动感知为降不确定性而贴近障碍 → 检验 `J_cert` 预算与收缩约束。
- **预期**：完整 v23 在保持零碰撞（相对 v22 不退化）的前提下，任务成功率显著高于"绝对帧全协方差"基线；回环事件后允许短期活性下降但无静默碰撞。

## 5. 本轮产物结论与最大风险

**结论**：v23 把全身控制的形式化为构型集合的前向不变性（WBSK/WBRT），把 SLAM 的形式化为证书的地图版本 + 相对协方差（RFSC/MPLAC），并用主动感知预算（APCC）与 HPC-W 统一门闭合成 `Exec_v23 ⊆ Exec_v22`。

**一句话风险**：可行核 `K_wbc` 的"前向不变"只是**模型内**的不变；当打滑、未建模负载与接触非线性使现实超出 `d_gap`，而主动重构又按旧地图认证时，系统会得到一份"仿真中成立、现实中失效"的主动自证幻觉。
