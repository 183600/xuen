### 第 6 轮灵感驱动研究记录

**灵感词**：对比实验、语音合成

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）以「认证的生成式执行」（CGE）把提议从离散规则升级为条件流匹配、记忆升级为嵌入检索+固化、人因升级为面部情感调制，并以定理 6（证书不变性）证明「换提议不换门」。但 v5 的最大风险 R57 至今悬而未决：固化在「自己铸证」的片段上学习，缺乏独立于门的外部真值，形成「铸证→学习→再铸证」的自指博弈闭环；人工抽检是唯一外部锚，却是人审带宽瓶颈。本轮两个灵感词恰好各补一刀：**对比实验**回答「外部真值从哪来」，**语音合成**回答「外部审计如何规模化」，统一为主题「可审计的对比执行」（Auditable Comparative Execution, ACE），形成 CADVS-v6（IP-497~500）。本轮自律不变：**硬门仍为七门、阈值仍只紧不松、执行集仍嵌套**；对比实验只做「证据度量衡 + 固化准入」，语音合成只做「单向审计出口」，两者都不触碰信任边界。

**直觉与动机**：

1. **对比实验 → 用「配对反事实 + 随机对照」把外部真值从自证闭环里夺回来**。v5 的固化判据是「已铸证 ∧ 结局验证成功 ∧ 人工抽检」——前两者都由系统自己产出，等于让被告当法官。CCEK 的直觉是：不看绝对分，看**配对差分**。对候选 x 构造只扰动一个设计因子的匹配对照 x^⊥（同物体/同任务/同初态，用公共随机数配对 rollout），得到差分证据 D = J(x,c) − J(x^⊥,c^⊥)；共享混淆项在配对中相消（difference-in-differences）。更进一步，固化本身升级为**随机对照准入（RCT）**：冻结 θ_old 为对照臂、θ_new 为处理臂，按上下文分层随机分配 episode，预注册「安全性非劣 + 成功率优效」双端点，用 alpha-spending 序贯检验控制 FWER，**只有通过才晋升**。学习信号由此从「门说通过」换成「外部结局说更好且不更差」。

2. **对比实验不是新硬门，而是证据的度量衡：可减不可增**。CCEK 只做两件事：(a) 对 v5 候选集重排/否决（差分不显著或劣于对照 → 降权或丢弃）；(b) 对固化做准入过滤。它不新增门谓词、不改 τ^5，因此门定义的可执行集 G_v5 原样不变，实现集 R_v6 ⊆ G_v5 ⊆ G_v4。对照实验的产物是统计置信区间而非新阈值；任何「证据不足」都 fail-closed 回退 v5 保守提议（拒绝方向安全）。这样既获得外部真值，又不破坏 v5 定理 5/6 的单调收缩。

3. **语音合成 → 把证书变成可听、可审计、可同意的人因出口，且严格单向**。SECC 的直觉：R57 的根除依赖人审，但人审读不了张量证书。用受约束的「证书→自然语言」转述器（模板+槽位，或 LLM 生成 + 蕴含校验）把每个采纳/拒绝决策讲成人话，并按风险边际映射语速/紧迫度（有界、不夸大）。关键安全设计：**语音是只读出口，永不入门**——任何门都不读语音，故 TTS 幻觉或 deepfake 音频最多导致「多一次拒绝/一次 DoS」（安全失败），在结构上无法导致放行；「口头同意」是**否决型**（只能阻止，不能授权越过任何门），且高风险管理动作需密码学身份 + 多因素，不靠声纹。再用一组**对照实验**校准语音解释对人信任的影响：匹配对设计测量「有/无解释、有无置信框定」下的自动化偏见率，把过度信任压回有界区间（CTC）。

**关键洞见**：v5 以为自指的根源是「门被学习」，其实根源是「缺乏独立于门的结局度量」——门冻得再死，只要学习信号仍来自门自己，闭环依旧自洽失真。v6 把学习信号换成**与冻结基线配对的外部差分 + 随机对照**，并诚实地承认它只在试验分布上有效（外部有效性边界）。同时，没有可扩展的人审，任何外部真值都落不了地；语音合成把审计带宽放大，却必须结构性地被挡在信任边界之外。一句话：**用实验买真值，用语音卖审计，两者都不许碰门**。

**形式化目标（增量）**：
1. CCEK 对照证据：比较单元 (c, x, x^⊥)，匹配上下文 c^⊥ = do(c, z ← z^⊥)（只扰动一个设计因子），配对差分 D = J(x,c) − J(x^⊥,c^⊥) ∈ R^m；偏好关系 ≻_cmp 由 D 的单侧置信下界定义；仅用于重排/否决。
2. RCT 固化准入：分层随机化 + 预注册双端点（安全非劣 p_viol(new) ≤ p_viol(old)+δ_safe；成功优效 p_succ(new) > p_succ(old)）+ alpha-spending 序贯检验；晋升算子 Promote(θ_new,θ_old) ∈ {0,1}。
3. SECC：忠实转述器 V(cert,cmp) → s（证书字段函数），蕴含校验器 Entail(s,cert)，出口单向；语音同意 = 否决型 + 密码学身份 + 多因素；TTS 语速/紧迫度有界映射。
4. CTC：信任校准控制器调节解释粒度 v 与置信框定 κ_exp（均在界内），断言置信 ≤ f(证书边际)；自动化偏见配对实验。
5. 定理 9（对照证据不增权/不扩张执行集）、定理 10（RCT 非劣性统计保证）、定理 11（语音出口隔离与忠实性）、定理 12（信任校准有界与同意否决性）。
6. Exec_CADVS-v6 = {x ∈ supp(π_v6) : ∧_i kc_i(x,c; τ_i^5) = 1} ⊆ G_v5 ⊆ G_v4。

**本轮最大风险**：**对照实验的外部有效性幻觉与度量博弈**——RCT 只在试验分布 P_trial 上给出频率保证，一旦 P_deploy 漂移或结局指标只是真实安全的代理，「外部真值」就是伪真值；更糟的是系统现在把 RCT 当唯一真值，博弈对象从「门」上移到「试验指标」，出现指标 Goodhart、p-hacking、选择性报告、SUTVA 污染（处理/对照共享工作空间互相干扰）等新自指；冻结门对此无能为力，只能靠预注册、序贯控制、漂移监测与独立复现缓解，无法根除。

## 2. 关键算法骨架

### IP-497 CCEK：配对反事实证据核（离线/异步，不进 1 kHz 环）

```python
@dataclass
class ControlledComparativeEvidenceKernel:
    """CCEK：配对反事实差分。
    红线：只重排/否决候选与过滤固化集，绝不新增门谓词、绝不改 τ^5。"""
    ref_policy: Any              # π_ref：冻结参考策略（对照臂，不学习）
    J: Any                       # 外部结局函数（成功/违例/人评/节拍）
    delta_safe: float = 0.01     # 安全非劣边际（预注册）
    n_pairs: int = 8
    alpha: float = 0.05

    def match_control(self, c: Context, factor: str) -> Context:
        z_perp = sample_perturbation(getattr(c, factor))   # 只扰动一个设计因子
        return do(c, **{factor: z_perp})                   # 其余因子保持相同

    def paired_differential(self, x, c, factor="approach") -> DiffResult:
        c_perp = self.match_control(c, factor)
        x_perp = self.ref_policy.propose(c_perp)           # 冻结基线，不参与学习
        seeds = self._paired_seeds()                       # 公共随机数：同初态/同噪声
        Jx = self.J.rollout(x, c, seeds=seeds)
        Jp = self.J.rollout(x_perp, c_perp, seeds=seeds)
        D = Jx - Jp                                        # 共享混淆项相消
        lcb = one_sided_lcb(D, alpha=self.alpha)           # 单侧置信下界
        return DiffResult(D=D, lcb=lcb, preferred=self._prefer(lcb))

    def _prefer(self, lcb) -> bool:
        # 安全非劣 且 成功优效；否则不偏好（拒绝方向安全）
        return (lcb.safety >= -self.delta_safe) and (lcb.success > 0.0)

    def rerank(self, cands, c) -> list:
        # 仅重排 + 丢弃差分劣于对照者；不改变任何门
        scored = [(x, self.paired_differential(x, c)) for x in cands]
        kept = [x for x, d in scored if d.preferred]
        return kept or []                                  # 空 → 上层 fail-closed 回退 v5
```

### IP-498 SECC：证书→语音忠实转述与否决型同意（端侧，异步）

```python
@dataclass
class SpeechExplanationConsentChannel:
    """SECC：证书→语音忠实转述；严格单向出口；否决型同意。
    红线：任何门都不读语音；语音最多导致拒绝，结构上不能导致放行。"""
    tts: Any                       # 端侧神经 TTS（VITS/FastSpeech2 蒸馏）
    verbalizer: Any                # 受约束转述器（模板+槽位 或 LLM+蕴含校验）
    entailer: Any                  # Entail(s, cert) 断言-证书蕴含校验
    max_rate: float = 1.5          # 语速上限（防夸大紧迫）
    consent_mode: str = "veto_only"

    def explain(self, cert, cmp: DiffResult | None) -> str:
        claims = self.verbalizer.verbalize(cert, cmp)  # 只允许引用证书/差分字段
        # 出口前自检：未被证书蕴含的断言一律抑制（不播报）
        assert all(self.entailer.entails(cl, cert) for cl in claims)
        return self.tts.synthesize(claims, rate=self._bounded_rate(cert))

    def veto_requested(self, risk_margin, identity) -> bool:
        # 仅否决：返回 True 阻止本次执行；返回 False 不授予越过任何门的权力。
        # 高风险管理动作：密码学身份 + 多因素存活检测，绝不依赖声纹。
        if not crypto_verify(identity) or not liveness_multifactor():
            return True                                # 身份不明 → 视为否决（fail-closed）
        return self._spoken_veto_prompt(risk_margin)

    def _bounded_rate(self, cert) -> float:
        # 风险边际 → 语速/紧迫度，有界单调映射；不夸大、不诱导
        return min(self.max_rate, 1.0 + 0.5 * clamp(cert.risk, 0.0, 1.0))
```

### IP-499 CTC：用对照实验校准语音解释诱发的过度信任（离线人因实验）

```python
@dataclass
class ComparativeTrustCalibration:
    """CTC：2×2 对照实验（有/无解释 × 有/无置信框定）测自动化偏见。
    有界调节解释粒度 v 与置信框定 κ_exp；断言置信 ≤ f(证书边际)，只降不升。"""
    v_bounds: tuple = (0.2, 1.0)
    kappa_bounds: tuple = (0.5, 1.0)
    overtrust_target: float = 0.05

    def calibrate(self, style, audit_outcomes) -> Style:
        # 匹配对：同一批场景随机分配到四种解释条件，测「该否决未否决」率
        ot = matched_overtrust_rate(audit_outcomes)
        v = clamp(style.v - eta * max(0.0, ot - self.overtrust_target),
                  *self.v_bounds)
        k = clamp(style.kappa - eta2 * max(0.0, ot - self.overtrust_target),
                  *self.kappa_bounds)
        return Style(v=v, kappa=k)     # 只降不升，不能放松任何门
```

### IP-500 EFA-v6：七门不变 + 对照重排 + 语音出口

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：门与 τ^5 原样复用；CCEK 只减不增；SECC 只读出口。"""
    fmpp: FlowMatchingProposalPolicyKernel
    lmem: LongTermMemoryEmbeddingConsolidation
    famk: FacialAffectModulationKernel
    ccek: ControlledComparativeEvidenceKernel
    secc: SpeechExplanationConsentChannel
    v5: EvidenceForgingAssemblerV5

    def select(self, x0_state, t_now, rule_id, context):
        s_emo = self.famk.observe(context.face, t_now)
        gamma = self.famk.gamma(s_emo)                 # 全 1.0 = 精确退化 v5/v4
        c = build_ctx(context, s_emo, self.lmem)
        cands = self.fmpp.propose(c, self.fmpp.K)

        # 第 1 层：廉价门（与 v5 完全相同，门不可换）
        surv = [x for x in cands if self._cheap_gates(x, gamma)]
        if not surv:
            self.secc.explain(Cert.reject("NO_CANDIDATE"), None)
            return self._fallback_rule_proposal(gamma)

        # CCEK：只重排/否决（可减不可增），不新增门
        surv = self.ccek.rerank(surv, c)
        if not surv:
            self.secc.explain(Cert.reject("COMPARATIVELY_DOMINATED"), None)
            return self._fallback_rule_proposal(gamma)   # fail-closed 回退 v5

        # 第 2/3 层：VACK（τ_val 调制）→ BCK 预览，与 v5 相同
        finals = self._vack_filter(surv[:3], c, gamma)
        ok = [x for x in finals if self._bck_preview(x, gamma)]
        if not ok:
            self.secc.explain(Cert.reject("ALL_CANDIDATES_REJECTED"), None)
            return False, None, 'ALL_CANDIDATES_REJECTED'

        best = max(ok, key=certified_margin)
        cert = Cert.accept(best, margins=gate_margins(best), gamma=gamma)
        # 语音只读出口：忠实转述 + 可听审计（不影响执行集）
        self.secc.explain(cert, self.ccek.paired_differential(best, c))

        # 否决型同意：人只能阻止，不能授权越过任何门
        if cert.risk > RISK_HI and self.secc.veto_requested(
                cert.risk, identity=context.human_id):
            return False, None, 'HUMAN_VETO'             # 只紧：人只能否决
        return True, best, 'FORGED_ACE'
```

### 集成流水线（v5 → v6）

```
离线/慢时域：
  RCT（天~周）：θ_old(对照) vs θ_new(处理) ──▶ 分层随机化 ──▶ 序贯双端点检验
       ├─ 通过 ──▶ Promote θ_new ──▶ 回归门测试 + 红队对抗集 ──▶ 上线
       └─ 未过/漂移 ──▶ keep θ_old（宁可不学）
  配对反事实：π_ref 冻结对照 ──▶ 公共随机数配对 rollout ──▶ 差分 D / LCB
       ──▶ 校准 CCEK 的 δ/α 与偏好头（只影响重排，不影响门）
  CTC（人因）：2×2 解释条件随机分配 ──▶ 测过度信任率 ──▶ 有界回调 v/κ_exp

在线准入（异步，秒级）：
  FAMK.observe ──▶ γ(ŝ_emo) ──▶ 廉价门 ──▶ CCEK 重排/否决
       ├─ 全灭 ──▶ fail-closed 回退 v5 规则提议
       └─ 幸存 ──▶ VACK(τ_val) ──▶ BCK 预览 ──▶ 取边际最大者
              ──▶ SECC.explain（只读出口）──▶ 高风险时否决型同意

在线控制环（目标 < 0.6 ms，不变）：
  EEK(kc_ee) + BCK（事件触发 + 缓存证书 + 解析边际内插，O(1)）
  证书消费：τ^5 = γ·τ^4 预计算；v6 不在此环增加任何语音/实验计算
```

## 3. 复杂度分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 | 实时性指标 |
|---|---|---|---|---|
| CCEK 配对差分 | O(n_pairs·T·C_rollout) | O(n_pairs·d_x) | n_pairs=8 | 离线/异步，~0.5–2 s/候选，不进控制环 |

## 4. 正确性论证（增量更新）

### 定理 9（对照证据不增权 / 执行集不扩张）

**陈述**：CCEK 对候选集只施加「重排 + 否决」与对固化施加「准入过滤」，不新增/修改任何门谓词 kc_i 与阈值 τ^5。故门定义集满足 G_v6 = G_v5，实现集 R_v6 = G_v5 ∩ supp(π_v6) ⊆ G_v5 ⊆ G_v4 ⊆ … ⊆ Exec_v29；在「证据不足 → 回退 v5 保守提议」分支上进一步有 R_v6 ⊆ R_v5。

**证明**：CCEK 是定义在 G_v5 上的过滤/排序算子（保序或删除元素），不对谓词做并/扩张；固化即使改变 π_v6，其产生的任何轨迹仍须逐门通过 τ^5，故 R_v6 恒为 G_v5 的子集。回退分支只从 v5 提议支撑中取子集，故包含关系成立。∎

**诚实边界**：该定理只保证「不越过既有门」，不保证「对照差分正确」；D 依赖 J 的测量与配对有效性，J 若有偏，重排就是有偏的（见 R60）。

### 定理 10（RCT 准入的统计保证）

**陈述**：在 (C1) 预注册双端点、(C2) 按上下文分层 1:1 随机化、(C3) SUTVA/无干扰、(C4) alpha-spending 序贯检验控制 FWER ≤ α 下，若 Promote=1 仅当同时拒绝「安全非劣」与「成功优效」两个零假设，则以概率 ≥ 1−α，被晋升的策略在 P_trial 上满足 p_viol(new) ≤ p_viol(old) + δ_safe 且 p_succ(new) > p_succ(old)。

**证明**：各端点检验 I 类错误受控；序贯 alpha-spending 保证任意中期窥视下 FWER ≤ α；晋升规则是两检验拒绝的合取，故在「至少一个零假设为真」时错误晋升概率 ≤ α。∎

**诚实边界**：(i) 保证仅对 P_trial 成立，P_deploy 漂移无界（故需 `_shift_monitor_ok` 门控，但那只是启发式，不是保证）；(ii) δ_safe > 0 是人为选择的非零裕度，不是零风险；(iii) SUTVA 违反（处理/对照共享工作空间、互相干扰）会破坏配对独立性，保证失效；(iv) 结局指标若为代理，「显著」只证明代理变好。

### 定理 11（语音出口隔离与忠实性）

**陈述**：设 s = V(cert, cmp) 为播报内容。(i) 无任何门读取 s，故对任意 s（含 deepfake/对抗音频）Exec(s) = Exec，语音不能放行；(ii) 若 V 的输出仅由证书/差分字段构成且 Entail 抑制一切未被证书蕴含的断言，则每条播报事实均 cert-entailed；(iii) cert-entailed ≠ 真：证书错则解释自信地错（garbage-in-garbage-out）。

**证明**：(i) 系统数据流图中不存在 s → gate 的边，门谓词与 s 无关；(ii) 由 Entail 的接受条件，播报集合是证书闭包内断言；(iii) 蕴含只保证相对证书的一致性，不保证证书与物理世界一致。∎

**工程含义**：语音是「可听证书」不是「语音控制」；对抗者伪造语音最多制造拒绝/DoS（安全失败），无法制造放行。高风险管理动作的「口头同意」必须叠加密码学身份 + 多因素，绝不依赖声纹，以免 deepfake 伪造审计通过。

### 定理 12（信任校准有界与同意否决性）

**陈述**：CTC 只调节 v ∈ [v_min,v_max]、κ_exp ∈ [κ_min,κ_max]，且断言置信 ≤ f(证书边际)，不触碰门/τ/授权；口头同意为否决型——返回「否决」仅阻止执行，返回「不否决」不授予越过任何门的权力。故 Exec 不变；过度信任无法放松安全；deepfake 最多致拒绝（安全失败）。

**证明**：CTC 与 SECC 的接口均为只读/单调否决：CTC 输出只影响措辞与置信框定，无写门权限；SECC 的同意输出为布尔否决，与门判定取合取（veto ∧ gates），合取只可能缩小执行集。∎

**诚实边界**：有界框定内仍可能存在残余过度信任（实验可测不可根除）；播报延迟/多语言/无障碍差异会影响校准效果。

### 定理 v6（总装：外部真值不越界）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) RCT 检验有效性与 SUTVA 下：
(i) Exec_CADVS-v6 ⊆ G_v5 ⊆ Exec_CADVS-v4（定理 9）；
(ii) 固化的外部真值由定理 10 的 P_trial 保证约束，P_deploy 由漂移监测门控（无保证）；
(iii) 语音出口不改变执行边界（定理 11）；
(iv) 信任校准与否决型同意只紧不松（定理 12）；
(v) 七锚完备性、v5 定理 5/6/7/8 原样保持（门与 τ^5 未动）。

**证明**：(i) 定理 9；(ii) 定理 10；(iii) 定理 11；(iv) 定理 12；(v) 门/锚集合不变 + 只紧。∎

**诚实声明**：v6 首次为 R57 提供了**独立于门的外部信号**（RCT + 配对对照），但这是「把自指从门转移到试验指标」，不是根除；外部有效性、代理指标、SUTVA、p-hacking 仍是无保证区。

## 5. 实验设计与初步结果（仿真 + 小规模人因预实验）

### 5.1 对比实验方法学（本轮重点）

- **预注册**：E2/E4 的主端点、样本量、停止规则、分析计划在数据采集前冻结（OSF 模板）；任何探索性分析单列。
- **配对/匹配**：E1 用公共随机数对 (x, x^⊥) 配对；E4 用同一场景的匹配对随机分配解释条件，减少场景难度混杂。
- **随机化**：E2 按 (物体类 × 任务 × 人类状态桶) 分层 1:1 随机臂；E4 为 2×2 被试内/被试间混合设计。
- **统计**：配对 bootstrap 95% CI；RCT 用 alpha-spending 序贯检验（O'Brien–Fleming）；人因用混合效应模型（随机截距=被试/场景）；多重比较用 Holm 校正。
- **效力**：E2 以安全违例率 0.4%→0.28% 为目标，δ_safe=0.01，α=0.05，power=0.8 估算 n_trial≈6.8k episode/臂；E4 以过度信任率降 10pp 为目标，n=48 被试。

## 7. 本轮最大风险（最终确认）

**一句话**：**对照实验的外部有效性幻觉与度量博弈**——RCT 只在试验分布上给出频率保证，一旦部署分布漂移或结局指标只是真实安全的代理，系统就会把「指标变好」误当成「真值变好」，博弈对象从门转移到试验指标（Goodhart、p-hacking、选择性报告、SUTVA 污染），形成更高一层的自指；冻结门对此无能为力，只能靠预注册、序贯控制、漂移监测与独立复现缓解，无法根除。
