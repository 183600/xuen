# 第 66 轮（承接第 65 轮「VISTA 故障可归因闭环」IP-214~223；灵感循环第 3 轮；本轮灵感：「单模型多任务」×「安全交互」）

> 第 65 轮把「可证伪」升级为「可归因」，其自述最大风险极其准确：**归因依赖「故障属于有限假设集」与「视觉和几何失效相互独立」；真实故障常是未知类型的组合，透明/镜面/对抗 patch 又让视觉与几何共享同一个分布外失效源，于是 FIR 把未知复合故障强行归入最近假设、只膨胀错误的球——系统反而因为「已经归因」而更自信地继续执行。** 本轮不再追问「谁是坏的」，而是换一个更根本的提问：当**能力、归因与安全判断共享同一个多任务模型**时，还能不能让它给自己发安全许可证？PACT 的回答是：**不能——必须把「提议」与「授权」分开**。本轮核心命题：
>
> **把「模型自证安全」升级为「提议-授权分离的交互契约」：用单一多任务模型做高容量提议者，用冻结、可验证、物理独立的安全内核做唯一授权者；学习头只能否决、永不能授权；用 STL 交互不变量（力/空间/可预测/可中断/同意/可读）把安全从机器人自身推广到人机交互；并用共模敏感度显式度量单模型多任务带来的共享失效，让归因从「发许可证」降级为「只做建议」。**

## 0. 直觉与动机

**灵感 1（单模型多任务 → 共享表征既是能力来源，也是共模故障源）**
直觉：一个 trunk 同时服务动作、视觉接地、故障判别与能力估计，样本效率、跨任务迁移与部署统一性都更好；但它把「一个输入改变 ⇒ 所有输出一起改变」变成结构性事实：一个对抗 patch、反光或传感器漂移可以同时骗过动作头、视觉头与故障头。第 65 轮的内部证据（跨头一致性、故障后验）本质上读的都是同一个 trunk 的下游，所以「系统说自己健康」是循环论证。必须诚实：单模型多任务是能力上的正确选择，却是「自证安全」的错误基座。安全不能建立在模型对自己的判断上。

**灵感 2（安全交互 → 安全不是机器人的属性，而是双方可共同维持的关系）**
直觉：传统安全 = 不碰撞 / 不超力。但真正的人机安全还包括：人能不能**预测**机器人下一步（可预测/可读）、机器人能不能被**及时打断**（可中断/可逆）、是否尊重**个人空间**、危险动作是否得到**同意**、系统不确定时会不会「硬试」而不是「让/问/停」。这些是**交互不变量**，可用信号时序逻辑（STL）表达，且**不依赖**策略模型是否聪明——它们是契约，而非能力。把它们写成契约，安全便从「相信模型」变成「审计模型」。

**灵感 3（两者的碰撞 → 安全权威必须与能力基座解耦）**
直觉：既然单模型多任务是共享失效率最高的地方，就不能让这个模型成为安全的最终权威。正确架构不是给模型加一个「安全头」，而是**把安全从模型里拿出来**：模型只提议（propose），一个冻结、外部可验证、物理独立的安全内核才授权（authorize）。学习信号只能**否决/收缩**动作集，绝不能**授权/扩张**。于是即使模型被完全骗过、甚至被恶意改坏，执行的安全上界不变。这正是对第 65 轮「因已归因而更自信」的结构性修复：归因不再能发许可证，只能收许可证。

**灵感 4（合流 → PACT：Proposer–Authority inTeraction Contract，提议-授权分离的交互契约闭环）**
闭环：单一多任务提议者 UIM 产出类型化提议 → 共模看门狗 CMW 估 κ_cm 与跨头一致性、只投否决票 → 提议-授权契约 PAC 保证「只收缩」 → 交互契约 ICON（STL 不变量） → 冻结安全内核 FKERNEL 做可达集/力限/停止距离校验 → 独立通道证明 ICA 保证每条安全不变量都有物理独立、可溯源的感知 → 契约认证前缀取 min(VISTA k*, 契约 k) → 递延交互 DEFER（不确定就慢/停/问/让） → 定向保守 RSC-P/WCV-P → AIC-P 认证共模/通道/对抗人 → J_pact。VISTA 的归因降级为「性能与保守度的建议」，不再承担安全保证。

**灵感 5（VISTA 组件的原位升级）**
- **FIR → FIR-adv**：仍在语义流归因，但输出只进入 PAC 当作 **veto 候选**，不进入授权路径；归因错误只影响保守度与成功率。
- **CSC → CSC ∩ CSC-C**：执行长度取 VISTA 的 k* 与契约认证 k 的**最小值**；契约可截断、不可延长。
- **RSC-V / WCV-V → RSC-P / WCV-P**：保守半径由契约内核与独立通道的下界决定；归因只能**减少**额外保守（可选优化），不能低于契约下界。
- **CGG-VCV / VPG**：继续提供接触前证据，但只作为 veto 与建议，不作为授权依据。
- **AIC-V → AIC-P**：干扰集增共模 patch、共享时钟/标定/总线故障、对抗人类；并认证「独立通道真的独立」。
- **J_vista → J_pact**：增加 kernel_hash、STL robustness 向量、veto_mask、κ_cm、channel_attestation、deferential_flag；且**不再要求归因正确**才 Valid（安全性不再依赖归因）。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（PACT 闭环）**：PACT = (VISTA, UIM, CMW, PAC, ICON, FKERNEL, ICA, DEFER, RSC-P, WCV-P, AIC-P, J_pact)。定位：VISTA 的「授权分离 + 单模型多任务安全交互」升级。不变式：**提议者只提议；授权只由冻结内核依据交互契约与独立通道给出；学习头只能否决（缩减动作集），永不能授权（扩张动作集）；学习写操作只在语义流。**
- **定义 234（单一多任务提议者 UIM 与类型化提议）**：g_θ=(φ_θ 共享 trunk；heads {h_act,h_vis,h_fault,h_comp,h_intent})。类型化提议 Π=(A_chunk, intent, env_announce, self_risk, cert_hints)。**Π 是提议者到授权者的唯一通道**；授权者不得读取 UIM 内部激活（禁止「自省式安全」）。
- **定义 235（共模敏感度与跨头一致性）**：在扰动族 Δ（纹理/光照/patch/漂移/时钟偏移）下记 Δz_m=z_m(ξ+δ)−z_m(ξ)，D(δ)=[Δz_1,…,Δz_M]。κ_cm(δ)=σ_1(D)²/Σσ_i(D)²，κ_cm=E_Δ[κ_cm(δ)]。跨头一致性 c_cons 为各头对同一共享量（接触点/意图/可承载性）预测的加权差异。**κ_cm 高 ⇒ c_cons 不可作为安全证据。**
- **定义 236（提议者不可信与单边否决）**：A_adm(Π)=A_contract(x_obs,c_worst) ∩ ⋂_m Veto_m(Π)，Veto_m∈{⊤,⊥}。授权（grant）只来自 A_contract，与 Π 无关。故 ∀Π: A_adm(Π)⊆A_contract；增加否决只收缩，移除否决最多恢复到 A_contract。**单模型被破坏时只会更保守，不会更冒险。**
- **定义 237（交互契约 𝒞 与交互不变量）**：𝒞={φ_1,…,φ_L} 为信号时序逻辑公式，作用于力 f(t)、速度 v(t)、人-机距离 d(t)、播报包络 E(t)、授权位 a_h(t)。含：力/动能上界、个人空间、可预测（越出 E 必须提前播报）、可逆/可中断（m 内可安全停）、同意（高风险动作需显式授权）、可读（低能力时必须降速/播报）。
- **定义 238（契约鲁棒度与契约认证）**：STL 鲁棒度 ρ_φ(π,x)（≥0 ⇔ 满足）。前缀 π 被契约认证 ⇔ 在冻结动力学包络 R(·) 与独立通道误差界下 ∀t≤|π|,∀φ: ρ_φ≥0。鲁棒度即证书中的定量裕度。
- **定义 239（冻结安全内核 FKERNEL）**：一个小规模、非学习（或形式化验证/认证）的模块 A，计算可达集、力限、停止距离、个人空间边界；参数离线标定并哈希冻结，在线无梯度写入。A 是实现「授权」的唯一实体。
- **定义 240（独立通道与来源证明 ICA）**：对每条安全不变量 φ，存在通道 c_φ 满足：(i) 物理独立（不同模态/总线/时钟/标定源）；(ii) 来源可证明（签名标定、单调时钟校验、总线隔离）；(iii) 误差有 conformal 界。证明失败 ⇒ 该不变量视为不可验证 ⇒ 契约不允许任何高风险前缀（fail-safe）。
- **定义 241（契约认证前缀）**：k_contract=max{k≤m: 前 k 步均满足定义 238}。执行长度 k_exec=min(k*,k_contract)；契约只能截断 VISTA 前缀，不能延长。
- **定义 242（递延交互模式 DEFER）**：当 h_comp 低、c_cons 低、κ_cm 高或 ICA 不完整时进入模式 D：降速至 v_def、播报意图、在 m 内可停、问/让/停。D 中只允许「安全空闲/退避/请求」类动作；**绝不允许「再试一次」式的主动物理探测**。
- **定义 243（提议者无关安全假设 A_PA）**：(i) FKERNEL 对契约执行 sound；(ii) 每条关键不变量有独立通道且误差有界；(iii) 单边否决在实现层成立；(iv) 内核冻结。四者合起来使安全性不依赖 UIM 与归因的正确性。
- **定义 244（任务条件化契约与意图误分类最坏化）**：契约参数 θ_contract=W(c)，c 为由 h_intent 声明的任务上下文；实现取 θ_contract=strictest{c'∈N_ε(c)}，即在意图不确定集中取**最严格**参数。**意图误分类只会收紧、不会放松。**
- **定义 245（定向保守 RSC-P / 联合压缩 WCV-P）**：保守半径下界由 (契约下界, ICA 误差界, 内核模型不确定) 决定；归因后验仅可在此基础上**减少**额外保守（若归因确定且被独立通道佐证），不可低于契约下界。WCV-P 搜索域=B(φ̂,r)∩𝒢∩K∩ℱ∩𝒞_rob。
- **定义 246（AIC-P 共模/通道/对抗人认证）**：ℰ_P=ℰ_V×ℰ_cm×ℰ_chan×ℰ_human；ℰ_cm 含共享 trunk 对抗 patch 与任务坍缩；ℰ_chan 含共享时钟/标定/总线/供电故障；ℰ_human 含对抗性人类、误授权、突然进入。ρ_dir 在 ℰ_P 上重算（n_cert 160→192），J_dir 增 kernel_ver、channel_attest_ver。
- **定义 247（PACT 证书 J_pact）**：J_pact=(J_vista, uim_version, contract_hash, kernel_hash, stl_robustness, admitted_prefix, veto_mask, κ_cm, deferential_flag, channel_attestation, human_auth_token)。Valid ⇔ Valid(J_vista) ∧ 契约认证 ∧ 内核哈希为冻结版本 ∧ 每条关键不变量有独立通道证明 ∧ (κ_cm 高或证明不全 ⇒ 处于 DEFER 或已获人工授权) ∧ 单边否决被遵守。**注意：Valid 不再要求归因正确。**
- **定义 248（授权泄漏审计）**：L_auth(Π)=max(0, |A_adm(Π)|−|A_0|)，A_0 为不读提议者信息、按最保守上下文算出的契约动作集。要求关键不变量上 L_auth=0；审计记录每个被接受动作的反事实（改用相反意图/故障声明时是否仍被接受），以检测实现层的授权泄漏。

## 2. 关键算法骨架

```python
# 语义流：提议 → 共模体检 → 单边否决 → 契约认证（只收缩）
Pi = uim.propose(obs)                       # 类型化提议，唯一通道
kappa_cm = cmw.common_mode(obs)             # 共享 trunk 共模敏感度
veto = {'H_fault': fir_adv.advice(obs),     # 归因建议：只能投否决票
        'consistency': cmw.consistency(Pi),
        'competence': uim.h_comp(Pi)}
adm = pac.admit(Pi, x_obs, veto)            # A_adm ⊆ A_contract（单边否决）
k_contract = icon.certified_prefix(adm.prefix, kernel, chan_bounds, m)
k_exec = min(vista_k_star(Pi), k_contract)  # 契约只能截断
if cmw.risky(kappa_cm) or not ica.attested(icon.critical):
    mode = 'DEFER'; k_exec = defer.plan(adm, m)
execute(adm.prefix[:k_exec]); audit.log_counterfactual(Pi, adm)

# ICON：STL 鲁棒度 + 冻结核可达集（实时，预计算边界）
def certified_prefix(prefix, kernel, chan_bounds, m):
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **命题 9（内部一致性不能自证安全）**：UIM 的输入到输出映射在真实感知下是多对一的（遮挡/透明/对抗），故存在不安全物理状态与安全状态产生相同内部输出；任何只依赖 UIM 内部输出的证书都可被伪造。**单模型多任务越强，越不能当自己的安全裁判。**
- **引理 9（授权包含）**：∀Π，A_adm(Π)⊆A_contract；执行前缀 ⊆ A_contract。故安全性由契约而非归因决定。
- **定理 9（提议者无关的交互安全）**：在 A_PA 下，对任意（含被完全破坏的）UIM，执行前缀满足全部交互不变量，概率 ≥1−α_kernel−Σ_φ α_chan,φ。**归因正确与否只影响保守度与成功率，不影响安全上界。** 这直接消解第 65 轮的「未知复合故障/共因」致命路径：它们降级为性能损失，而非安全越界。
- **命题 10（风险转移）**：VISTA 的失败概率≈P(误归因)；PACT 的失败概率≈P(假证明/内核模型错)。通常前者 ≫ 后者，但后者更罕见、更灾难、且跨通道相关——这是本轮的代价。
- **命题 11（容量与相关失效的设计律）**：能力可以共享，授权不可共享。共享带来的样本效率收益与失效相关度 ρ_fail 反向权衡；ρ_fail 超过阈值时，安全关键量必须移出共享 trunk（独立内核/独立认证头）。
- **实时性**：UIM 推理同第 65 轮；新增 CMW 仅在语义流（Jacobian/有限差分 <10ms），ICON 实时 STL 监视 <0.1ms、FKERNEL 预计算包络查询 <0.05ms、ICA 校验 <0.02ms；实时路径目标 ≤2.6ms（较第 65 轮 +0.1ms）。

## 5. 本轮最大风险

**一句话**：PACT 把「归因错误」这个高频软失效，换成了「**契约内核/独立通道本身被同一深层故障攻破的假证明**」这个低频硬失效——当所谓「独立」通道在实际部署中共享同一个时钟、同一条总线、同一份标定源、同一个感知预处理或同一套供电时，共模故障会同时骗过提议者与授权者，内核会一边越界一边签发「安全」证书；安全性从「可能误判」退化为「可信根整体被污染」，而系统恰因分离架构而更信任这份证书。

# 第 66 轮产物 · 创新点清单 v4：PACT（Proposer–Authority inTeraction Contract：单模型多任务 × 安全交互的提议-授权分离交互契约闭环；UIM×CMW×PAC×ICON×FKERNEL×ICA×DEFER×RSC-P×WCV-P×AIC-P×J_pact）

> 承接第 65 轮 IP-214~223（VISTA：VPG×ACH×FIR×VCV×VSP/AFA×CSC×RSC-V×WCV-V×CSP-V×AIC-V×J_vista）。第 65 轮把几何先验从「可证伪」升级为「可归因」，但其自述风险一针见血：归因依赖「故障属于有限假设集」与「视觉/几何失效相互独立」；未知复合故障与共因（透明/镜面/对抗 patch）会让 FIR 强行归类、只膨胀错误的球，系统反因「已归因」而更自信地继续执行。本轮从根上换问法：**当能力、归因与安全判断共享同一个多任务模型时，能不能让它给自己发安全许可证？** PACT 的回答是不能——**把「提议」与「授权」分离**：单一多任务模型只做高容量提议者，冻结、外部可验证、物理独立的安全内核做唯一授权者；学习头只能否决、永不能授权；安全用 STL 交互不变量从「机器人自身」推广到「人机共同可维持的关系」；归因从「发许可证」降级为「只做建议」。核心目标：**「被破坏的模型只能让机器人更保守，不能让它更冒险；安全不再依赖归因是否正确。」**
>
> IP 编号：IP-224~IP-233（共 10 个），含新增与对第 65 轮组件的原位升级。

## 2. 形式化定义（完整版）

**定义 233（PACT 闭环）** PACT 是 VISTA 的「授权分离 + 单模型多任务安全交互」升级：保留 VISTA 的语义流/实时流骨架与几何-视觉-力证据，在其上新增单一多任务提议者 UIM、共模看门狗 CMW、提议-授权契约 PAC、交互契约 ICON、冻结安全内核 FKERNEL、独立通道证明 ICA、递延交互 DEFER，并原位升级 RSC-V→RSC-P、WCV-V→WCV-P、AIC-V→AIC-P、J_vista→J_pact。不变式：**提议者只提议；授权只由 FKERNEL 依据 ICON 与 ICA 给出；学习头只能否决（缩减 A_adm），永不能授权（扩张超出 A_contract）；世界模型、归因、适配、证书只在语义流，实时流只做契约监视、前缀截断、DEFER 与派发，零学习写操作。**

**定义 234（UIM 与类型化提议）** UIM 为单一多任务模型 g_θ=(φ_θ,{h_m})，共享 trunk φ_θ，heads 含动作 h_act、视觉接地 h_vis、故障判别 h_fault、能力/不确定度 h_comp、任务意图 h_intent。类型化提议
Π=(A_chunk, ĉ_intent, E_announce, r_self, H_cert)，
其中 A_chunk∈ℝ^{H×d_a} 为候选动作块，ĉ_intent 为声明任务上下文（含风险等级），E_announce 为播报给人类的轨迹包络，r_self 为自评风险（仅作用否决提示），H_cert 为证书提示（**不得含授权位**）。**Π 是提议者到授权者的唯一通道**；PAC 禁止读取 UIM 的内部激活、梯度或 hidden state——即禁止「自省式安全」。

**定义 235（共模敏感度与跨头一致性）** 给定威胁扰动族 Δ。对 δ∈Δ 与任务头 m，记 Δz_m(δ)=z_m(ξ+δ)−z_m(ξ)，构造 D(δ)=[Δz_1(δ),…,Δz_M(δ)]。定义
κ_cm(δ)=σ_1(D(δ))² / Σ_i σ_i(D(δ))²，κ_cm=E_{δ∼Δ}[κ_cm(δ)]。
κ_cm→1 表示所有头几乎沿同一方向响应——单个输入改变可协同移动所有头（共模失效）；κ_cm→0 表示各头独立响应。跨头一致性
c_cons = Σ_{m<m'} w_{mm'}·dist(z_m^{(shared)}, z_{m'}^{(shared)})，
度量各头对同一共享量（接触点、意图、可承载性）预测的一致程度。**c_cons 只对「非共模」故障敏感；κ_cm 高时 c_cons 不可作为安全证据（命题 9）。**

**定义 236（提议者不可信与单边否决）** 设 A_contract(x_obs,c_worst) 为按最保守上下文与契约算出的动作集，Veto_m(Π)∈{⊤,⊥} 为学习头否决票。定义
A_adm(Π)=A_contract(x_obs,c_worst) ∩ ⋂_{m} Veto_m(Π)。
授权（grant）只来自 A_contract，与 Π 无关；学习头只能通过 Veto_m=⊥ 收缩 A_adm。因此
∀Π: A_adm(Π) ⊆ A_contract(x_obs,c_worst)，
且否决集合增大使 A_adm 单调不增；移除否决最多恢复到 A_contract，绝不超出。**这就是「被破坏的模型只能更保守」。**

**定义 237（交互契约 𝒞）** 𝒞={φ_1,…,φ_L}，每个 φ 为信号时序逻辑（STL）公式，作用于实时信号。至少包含：
- φ_force: □( f(t) ≤ f_max(d(t),v_rel(t)) )；
- φ_space: □( d(t) ≥ d_min(v_rel(t)) )；
- φ_predict: □( x(t)∉E_announce(t−Δ) ⇒ ◇_{[0,τ_a]} announce )；
- φ_interrupt: □( stopping_distance(x(t),v(t)) ≤ m ∧ reversible_within(x(t),m) )；
- φ_consent: ( risk_level ≥ r_hi ) ⇒ □( a_h(t)=1 )；
- φ_legible: ( u_comp(t) ≥ u_hi ) ⇒ □( v(t) ≤ v_def ∨ announced(t) )。
契约刻画**人机共同可维持的关系**，不依赖 UIM 是否聪明；其中风险等级、v_def、d_min 等参数由定义 244 在最坏意图下取严格值。

**定义 238（STL 鲁棒度与契约认证）** STL 定量语义给出 ρ_φ(π,x)（≥0 ⇔ 满足，数值即裕度）。前缀 π 被契约认证 ⇔ 在 FKERNEL 的动力学包络 R(·) 与 ICA 通道误差界下，
∀t≤|π|，∀φ: ρ_φ(π,x(t)) ≥ 0。
认证鲁棒度 ρ_𝒞(π)=min_{t,φ} ρ_φ(π,x(t))。契约认证只依赖 R 与通道界，不依赖归因、世界模型或 UIM 输出。

**定义 239（冻结安全内核 FKERNEL）** A 为非学习（或形式化验证/可认证）模块，计算保守可达集 R(·)、距离-速度相关力限 f_max(d,v)、停止距离与个人空间边界 d_min(v)。参数 θ_kernel 离线标定，哈希 H_kernel=sha256(θ_kernel) 冻结；在线只读，无梯度、无自适应写入。**A 是实现「授权」的唯一实体。**

**定义 240（独立通道与来源证明 ICA）** 对每条安全关键不变量 φ∈𝒞_crit，要求存在通道 c_φ 满足：
(i) **物理独立**：不同传感模态/总线/时钟/标定源（如力/触觉、近距雷达、独立看门狗相机；不得与提议者共享相机与预处理）；
(ii) **来源可证明**：签名标定、单调时钟单调性校验、总线隔离与权限证明；
(iii) **误差界**：conformal 或标定上界 |e_{c_φ}|≤α_chan,φ。
对 φ 的证明记 Att_φ。若任一 (i)–(iii) 不满足，则 Att_φ=⊥，契约把 φ 视为不可验证，**不允许任何高风险前缀**（fail-safe）。

**定义 241（契约认证前缀）** k_contract(Π,x)=max{k≤m : 前缀 Π.A_chunk[:k] 在定义 238 下被认证}。实际执行长度
k_exec = min(k*, k_contract)，
其中 k* 为 VISTA 的 CSC 认证前缀。**契约只能截断、不能延长。** 若 k_contract=0，进入 DEFER 或安全空闲。

**定义 242（递延交互模式 DEFER）** 触发条件：h_comp<u_hi，或 c_cons<τ_c，或 κ_cm>τ_cm，或 Att_φ=⊥（某关键不变量），或人工撤销授权。模式 D 只允许：
- 安全空闲 safe_idle；
- 退避 retreat（沿可逆方向、在 m 内可停）；
- 请求 ask（播报不确定并要求人类授权/指路）。
D 中**禁止「再试一次」式的主动物理探测**（对冲第 65 轮 AFA 在易损物体上的伤害风险）。D 的退出需人工授权，或不确定性回落且 Att 恢复。

**定义 243（提议者无关安全假设 A_PA）** 四条假设：
(A_PA1) FKERNEL 对契约执行 sound：包络 R 覆盖真实可达集；
(A_PA2) 每条关键不变量有独立通道且误差有界（Att_φ=⊤）；
(A_PA3) 单边否决在实现层成立（A_adm⊆A_contract，L_auth=0）；
(A_PA4) θ_kernel 冻结且哈希可校验。
**安全性 = f(A_PA1..A_PA4)，与 UIM、归因、世界模型无关。**

**定义 244（任务条件化契约与意图误分类最坏化）** 设上下文 c 的风险等级经映射 θ_contract=W(c) 得到契约参数（力限、安全距离、速度上限等）。为防 h_intent 误分类放松安全，实现取
θ_contract = strictest{ W(c') : c'∈N_ε(c) }，
其中 N_ε(c) 为意图不确定集，strictest 按安全严格序取最严格参数（最小力限、最大安全距离、最低速度）。**误分类只收紧。**

**定义 245（RSC-P / WCV-P）** 保守半径下界由三部分决定：
r_min = ⊕( r_kernel(θ_kernel), r_chan(α_chan), r_model(模型不确定) )。
RSC-P 维护按区域/因子的半径，但不得低于 r_min；归因确定且被独立通道佐证时，可在 r_min 之上**减少**额外保守。WCV-P 搜索域
B(φ̂,r) ∩ 𝒢(g) ∩ K(μ̂) ∩ ℱ(f_lim) ∩ 𝒞_rob，
其中 𝒞_rob 为契约鲁棒可行集；交集为空回退并置 `contract_conflict=True`。

**定义 246（AIC-P）** 干扰集
ℰ_P = ℰ_V × ℰ_cm × ℰ_chan × ℰ_human，
ℰ_cm 含共享 trunk 对抗 patch、光照/透明、任务坍缩（各头退化为任务无关输出）；ℰ_chan 含共享时钟偏移、共享标定投毒、总线/供电共因；ℰ_human 含对抗性人类、误授权、突然进入、诱导性指令。ρ_dir 在 ℰ_P 上重算（n_cert 160→192，其中 32 给共模/通道/人因），J_dir 增 kernel_ver、channel_attest_ver。

**定义 247（J_pact）** J_pact=(J_vista, uim_version, contract_hash, kernel_hash, stl_robustness, admitted_prefix, veto_mask, κ_cm, deferential_flag, channel_attestation, human_auth_token)。验证规则：
Valid(J_pact) ⇔ Valid(J_vista)
∧ 前缀被契约认证（定义 238）
∧ H_kernel 等于冻结版本
∧ ∀φ∈𝒞_crit: Att_φ=⊤
∧ ( κ_cm>τ_cm ∨ ∃φ:Att_φ=⊥ ⇒ deferential_flag=⊤ 或 human_auth_token 有效 )
∧ L_auth=0（单边否决无泄漏）。
**与 J_vista 不同：Valid 不要求归因正确。** 审计链新增：为何被接受（契约鲁棒度）、为何只能这么长（k_contract）、安全凭什么成立（kernel_hash + channel_attestation）。

**定义 248（授权泄漏审计）** 对每个被接受动作记录反事实：把提议中的意图/故障声明替换为相反值，契约是否仍接受。定义
L_auth(Π)=max(0, |A_adm(Π)|−|A_0|)，
A_0 为不读任何提议者信息、按最保守上下文算出的契约集。实现要求关键不变量上 L_auth=0。审计同时输出「契约敏感点」——哪些接受决定对提议者声明敏感，供人工复核。

### IP-226 PAC（提议-授权契约 + 单边否决）

```python
class ProposerAuthorityContract:
    """模型只提议；授权只来自冻结内核。学习头只能否决。"""
    def admit(self, Pi, x_obs, veto):
        c = Pi.intent
        A_contract = contract_action_set(x_obs, strictest_context(c))  # 定义 244
        A_adm = A_contract
        for m, v in veto.items():
            if not v:                      # 学习头的否决：只收缩
                A_adm = A_adm.restrict(m)
        assert A_adm.subset_of(A_contract)  # A_PA3，运行时断言
        return Admission(A_adm, prefix=Pi.A_chunk, grant=('contract',))
```

### IP-237/241 ICON + FKERNEL（STL 鲁棒度与契约认证前缀）

```python
CONTRACT = ('phi_force', 'phi_space', 'phi_predict',
            'phi_interrupt', 'phi_consent', 'phi_legible')

def certified_prefix(prefix, kernel, chan_bounds, m):
    best = 0
    for k in range(1, min(len(prefix), m) + 1):
        R = kernel.reach_enclosure(prefix[:k])            # 冻结、确定性包络
        rho = min(min_t(stl_robust(phi, prefix[:k], R, chan_bounds))
                  for phi in CONTRACT)
        if rho < 0:
            return best
        best, last_rho = k, rho
    return min(len(prefix), m)

class FrozenKernel:
    def __init__(self, params):
        self.params = params
        self.hash = sha256(params)                        # 冻结版本
    def reach_enclosure(self, prefix):
        return conservative_reachable(prefix, self.params)  # 包络，非点估计
    def force_limit(self, d_human, v_rel):
        return self.params.f_max / (1.0 + self.params.kappa * v_rel)
```

### IP-225 CMW（共模看门狗，只产 veto）

```python
class CommonModeWatchdog:
    def common_mode(self, obs):
        energies = []
        for delta in THREAT_SUITE:                        # 纹理/光照/patch/漂移/时钟
            D = np.column_stack([head_delta(obs, delta, m) for m in HEADS])
            s = np.linalg.svd(D, compute_uv=False)
            energies.append(s[0] ** 2 / (s ** 2).sum())
        return float(np.mean(energies))                   # kappa_cm

    def risky(self, kappa_cm):
        return kappa_cm > TAU_CM              # 只触发 DEFER，不改 A_contract
```

### IP-233 PACT 闭环算子（整合）

```python
def PACT_round(M, obs, delta_f_req):
    # ———— 语义流（10–100Hz）————
    Pi = M.uim.propose(obs)                               # 唯一通道
    kappa_cm = M.cmw.common_mode(obs)
    c_cons = M.cmw.consistency(Pi)
    veto = {'fault': M.fir_adv.advice(obs),
            'consistency': c_cons > TAU_C,
            'competence': M.uim.h_comp(Pi) > U_HI}
    adm = M.pac.admit(Pi, M.x_obs, veto)                  # A_adm ⊆ A_contract
    assert M.audit.leakage(adm) == 0                      # L_auth = 0

    # 契约认证：只依赖冻结内核与独立通道
    k_contract = M.icon.certified_prefix(adm.prefix, M.kernel, M.chan_bounds, M.m)
    k_star = M.csc.certified_prefix(adm.prefix, M.vista_post, M.m, M.alpha_chunk)
    k_exec = min(k_star, k_contract)

    # 双钥匙：共模/证明不全/人类撤销 → DEFER
    if M.cmw.risky(kappa_cm) or not all(ica.attested(p) for p in M.icon.critical):
        M.mode = 'DEFER'
        k_exec = M.defer.plan(adm, M.m)
    if k_exec == 0:
        M.mode = 'SAFE_IDLE'

    # ———— 实时流：只做监视/截断/派发，零学习写操作 ————
    for a in adm.prefix[:k_exec]:
        if not stl_monitor_ok(a, M.kernel): break          # 鲁棒度越界即停
        dispatch(a)
    M.audit.log_counterfactual(Pi, adm)                    # 反事实授权审计
    return M, build_j_pact(adm, k_exec, kappa_cm, M)
```

## 4. 推导

**命题 9（内部一致性不能自证安全）** 设物理状态空间 S，UIM 内部输出映射 O:S→Z。真实感知（遮挡、透明、多对一投影、对抗 patch）使 O 非单射：存在安全状态 s_s 与不安全状态 s_u 使 O(s_s)=O(s_u)。任何仅依赖内部输出的证书函数 C:Z→{安全,不安全} 满足 C(O(s_s))=C(O(s_u))，不能同时正确。故不存在 sound 的 UIM 自证证书；一个足够强的多任务模型恰恰最容易产生「内部一致但物理错误」的表示。∎

**引理 9（授权包含）** 由定义 236，A_adm(Π)=A_contract∩⋂_m Veto_m⊆A_contract。执行前缀 π⊆A_adm⊆A_contract，且对任意 Π 成立，与 Π 是否被破坏无关。∎

**引理 10（契约前缀安全）** 在 A_PA1、A_PA2 下，k_exec≤k_contract，故对每个 t≤k_exec、每个 φ，真实状态落在包络 R 内且通道误差在界内（w.p.≥1−α_kernel−Σ_φ α_chan,φ）；由定义 238 鲁棒度非负得 φ 满足。∎

**定理 9（提议者无关的交互安全）** 在 A_PA 下，对任意 UIM（含被对抗破坏），执行轨迹满足交互契约 𝒞 的全部不变量，概率 ≥1−α_kernel−Σ_{φ∈𝒞_crit}α_chan,φ。且安全性不依赖 FIR 归因正确性（定义 247 不要求归因正确）。于是第 65 轮的未知复合故障、共因失效、视觉-几何共享失效，只会通过 veto/DEFER 降低性能与增加保守，不能造成安全越界。∎

**命题 10（风险转移）** VISTA 的安全失败概率下界≈P(误归因且误归因导致越界)；PACT 的安全失败概率≈P(A_PA1 失效 ∨ A_PA2 失效 ∨ A_PA3 被实现 bug 破坏)。一般 P(假证明)≪P(误归因)，但假证明一旦发生，往往同时污染提议者与授权者（同源），且证书仍显示安全，属灾难性高相关失效。这是把「高频软失效」换成「低频硬失效」的显式交易。∎

**命题 11（容量共享与授权隔离的设计律）** 设任务相似度 s 决定共享收益（样本效率约 ∝1/(1−s)）与失效相关度 ρ_fail(s)（s↑⇒ρ_fail↑）。安全所需有效样本 n_eff≈n(1−ρ_fail)/(1+ρ_fail)。存在阈值 s*：s<s* 时共享 Pareto 更优；s>s* 时 ρ_fail 使 n_eff 崩塌，安全关键量必须移出共享 trunk。结论：**能力可以共享，授权不可共享**——把安全关键量放进独立 FKERNEL 或独立认证头。∎

**定理 10（PACT-Complete）** 综合定义 233–248 与定理 9：PACT 在 A_PA 下同时保证 (i) 交互不变量（力/空间/可预测/可中断/同意/可读）；(ii) 提议者无关安全（任意 UIM 破坏下安全上界不变）；(iii) 归因只影响保守度与成功率，不影响安全；(iv) 证书诚实（Valid 不宣称超出契约的保证）；(v) 优雅降级（共模高/证明缺失/人类撤销 ⇒ DEFER 或 safe_idle）。∎

## 7. 已知风险

**一句话**：PACT 把「归因错误」这个高频软失效，换成了「**契约内核/独立通道本身被同一深层故障攻破的假证明**」这个低频硬失效——当所谓「独立」通道在实际部署中共享同一个时钟、同一条总线、同一份标定源、同一个感知预处理或同一套供电时，共模故障会同时骗过提议者与授权者，内核会一边越界一边签发「安全」证书；安全性从「可能误判」退化为「可信根整体被污染」，而系统恰因分离架构而更信任这份证书。

**次级风险与缓解**：
1. **通道独立性名存实亡**：共享时钟/总线/标定/预处理；缓解：硬件级隔离、签名标定、单调时钟校验、ICA 强制证明、定期红队注入共模故障。
2. **FKERNEL 模型错误（A_PA1 失效）**：软接触/未建模动力学/参数漂移；缓解：保守包络、在线残差监测（只报警不授权）、定期再标定并版本化。
3. **单边否决的实现泄漏（A_PA3）**：代码 bug 让声明影响授权；缓解：属性测试/形式化检查、L_auth 审计、双实现交叉校验、运行时包含关系断言。
4. **过度保守/可用性下降**：契约 + DEFER 可能降低成功率；缓解：归因与能力只用于在 r_min 之上减少保守；人因实验量化舒适-效率权衡。
5. **对抗人类/误授权**：人本身成为风险源；缓解：授权令牌 + 二次确认 + 可撤销；不把人类授权当作物理安全的替代。
6. **共模 patch 规避 κ_cm 检测**：κ_cm 是统计量，可被刻意规避；缓解：与独立通道交叉、随机化威胁集、κ_cm 只作 veto 不授权。
7. **实时预算**：STL 监视 + 内核查询逼近预算；缓解：离线预计算包络、ROI/事件触发、CMW 全部放语义流。
8. **证书语义漂移/伪造**：J_pact 可能被错误构建；缓解：哈希链、独立 verifier、证书与执行日志对账。
