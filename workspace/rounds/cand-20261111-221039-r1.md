# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；新灵感循环第 1 轮；本轮灵感：「动力学」×「用户测试」）

> 第 54 轮把技能组合推进到动作-鲁棒性双证书 `J`，但 `J` 本质上是一张**静态快照**：它在发证时刻、在脚本化仿真分布上成立。真实部署是一个**闭环动力学系统**——技能会漂移、云边延迟会变化、用户会适应机器人；而「用户测试」恰恰是这套系统里最容易被忽略的非平稳环节。核心矛盾：**H22**：证书没有时间维度，静态 `ρ` 会在漂移中悄悄越界，而系统仍拿着旧证书宣称安全；**H23**：用户是动力学系统的一部分而非独立裁判，用户测试分布随机器人行为漂移，导致“测过即安全”的假象。

## 0. 直觉与动机

**灵感 1（动力学 → 证书是轨迹上的管道，不是点）**
直觉：`ρ(d)` 不该是标量，而应是随时间的下包络 `ρ(d,t)`。器件磨损、环境缓慢变化、技能在线微调都会让它单调下滑。证书应当像控制里的“管道（tube）”：只要漂移率不超过 `λ`，就能算出它还能撑多久——**有效期 `T_valid`**。过了这个时刻证书自动失效，必须重测。这把证书从一次性结论变成**带保质期的契约**。
严谨化：把 `α_S`、`ρ_S` 提升为时间函数并给出 Lipschitz 漂移界，则 `T_valid` 可由“当前余量 / 漂移率”直接下界，成为可计算的量。

**灵感 2（动力学 → 组合的稳定性而非空间交集）**
直觉：第 54 轮用动作 Jaccard 交集判断兼容，但两个技能动作重叠**不代表拼起来稳定**。真正的兼容是**复合转移映射压缩**：扰动在交接处不被放大。若复合 Jacobian 谱半径 ≥ 1，动作交集再大也会在闭环里振荡或发散。于是 `compat` 要从“空间重叠”升级为“**动力学可容许**”。
严谨化：`compat_dyn(S_i,S_j) = compat(S_i,S_j) ∧ (γ_{ij} < 1)`，其中 `γ_{ij}` 是转移区 `ΔA` 上复合映射在某个度量 `M` 下的压缩系数。

**灵感 3（用户测试 → 用户是闭环里的一环，不是裁判）**
直觉：用户看到机器人行为会调整自己的指令与节奏（共适应）。因此用户测试产生的轨迹来自 `D_test(θ_u)`，而用户策略参数 `θ_u` 本身随机器人策略演化。用固定用户、固定脚本测出来的证书，在自适应用户面前会系统性高估。必须把用户策略写进联合状态，并用**测试-部署分布散度 `d_TV`** 给证书“打折”。
严谨化：人-机闭环是一个耦合动力系统，`ρ(d|θ_u)` 为用户条件鲁棒性；证书迁移误差由 `d_TV(D_test,D_deploy)` 控制。

**灵感 4（用户测试 → 主动的、可证伪的测试预算分配）**
直觉：用户测试时间有限。与其随机让人试，不如选**最可能推翻证书**的用例（信息增益最大）。这把用户测试从“验收演示”变成“**主动证伪实验**”，并要求报告统计功效 `β_user`：在预算 `B` 内漏检违规的概率。
严谨化：把证书健全性设为零假设，用户测试是序贯假设检验，证书必须同时报告 `1-β_user(B)` 与测试覆盖，而非只报 pass/fail。

**灵感 5（动力学 × 用户测试 → 证书生命周期）**
直觉：把“发证—监控—老化—定向重测—重签”串成闭环：在线监控残差 → CUSUM 漂移报警 → 触发定向用户重测 → 重签证书。证书不再是一张纸，而是一个带**签名、有效期、监控统计量、用户覆盖证据、测试功效**的活对象。
严谨化：重验证调度器 `π_reval` 在“漏检风险”与“测试成本”之间最小化期望风险，形成可分析的生命周期策略。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（动力学增强技能模型）**
技能 `S` 为受控动力系统 `ẋ = f_S(x,a,t) + w`，`y = h_S(x)`。动作剖面时间化 `α_S : A × [0,T] → [0,1]`，满足漂移界 `|α_S(a,t) - α_S(a,0)| ≤ λ_α·t`；鲁棒性谱时间化 `ρ_S(d,t)`，满足 `|ρ_S(d,t) - ρ_S(d,0)| ≤ λ_ρ(d)·t`。`λ_ρ(d)` 由标定集给出置信上界。

**定义 122（动力学可容许组合）**
设复合转移映射为 `Φ_{ij} : ΔA → ΔA`。称 `S_i,S_j` 动力学可容许，当且仅当存在度量 `M` 与压缩系数 `γ_{ij} < 1`，使得 `∀x,x'∈ΔA: ||Φ_{ij}(x) - Φ_{ij}(x')||_M ≤ γ_{ij}·||x - x'||_M`。记
```
compat_dyn(S_i,S_j) = compat(S_i,S_j) ∧ (γ_{ij} < 1) ∧ (ρ_spec(∂Φ_{ij}) < 1)
```
第 54 轮定义 116 是本定义在“压缩项恒真”时的特例。

**定义 123（证书有效期 / Validity Horizon）**
给定当前谱 `ρ_S(d,0)`、漂移上界 `λ_ρ(d)` 与要求 `ρ_min(d)`：
```
T_valid(S) = min_d (ρ_S(d,0) - ρ_min(d)) / λ_ρ(d),  λ_ρ(d) > 0
```
若某维已低于 `ρ_min` 则 `T_valid = 0`。组合链的有效期 `T_valid(⊗) = min_{S∈chain, e∈edges} T_valid`，边缘因 `γ_{ij}` 与转换漂移额外折减。用置信下界记 `T_valid^{LCB}`。

**定义 124（用户在环测试模型）**
人-机闭环状态 `(x, θ_u)`，用户策略 `π_u(a_u | x; θ_u)`，共适应更新 `θ_u(t+1) = U(θ_u(t), behavior_robot)`。用户测试分布 `D_test(θ_u)`，部署分布 `D_deploy`。用户条件鲁棒性 `ρ(d | θ_u)`。测试-部署散度 `d_TV = sup_{θ_u} TV(D_test(θ_u), D_deploy)`，覆盖 `cov(𝔗) = P_{x~D_deploy}[x ∈ 𝔗]`。证书只在 `d_TV` 小且 `cov` 高时才对部署有约束力。

**定义 125（用户测试统计功效）**
以“证书健全”为零假设 `H0`，用户测试预算 `B` 的序贯检验功效定义为
```
β_user(B) = P(接受 H0 | 存在幅度 ≥ Δ_min 的违规)
```
证书须附带 `(B, Δ_min, β_user(B), 测试用例族)`；`β_user` 大意味着“测了但测不出”。

**定义 126（证书老化与重验证策略）**
在线残差 `e_t = y_t - ŷ_t`，CUSUM 统计量 `m_t = max(0, m_{t-1} + |e_t| - ν)`，报警阈值 `h`。重验证调度 `π_reval` 的触发条件为 `m_t > h` 或 `t ≥ T_valid^{LCB}`。期望风险
```
R(π_reval) = P(未被发现的违规) + c · E[#重测次数]
```
目标是选取 `(h, π_reval)` 使 `R` 最小。

**定义 127（时空-用户联合证书）**
```
J* = (J, T_valid^{LCB}, λ_bound, {γ_{ij}}, cov_test, d_TV, β_user, sig, expiry)
```
部署条件：
```
dom_J(T)=in ∧ δ_a<Θ_a ∧ T_valid^{LCB} ≥ T_mission
∧ d_TV ≤ ε_u ∧ β_user ≤ β_max ∧ cov_test ≥ c_min
```
`expiry = issue_time + T_valid^{LCB}`；过期后 `J` 仅作历史证据，不得用于在线放行。

## 2. 关键算法 伪代码

### IP-121 DAP（Dynamics-Aware Profiling）

```python
def drift_profile(skill, A, T, calib_traj, alpha=0.05):
    rho0 = estimate_robustness(skill, calib_traj)          # 当前谱
    lam = {}
    for d in dimensions:
        # 用时间差分回归 + 单侧置信上界估漂移速率
        lam[d] = one_sided_upper_bound(drift_rate(skill,d,calib_traj), alpha)
    alpha_t = time_indexed_profile(skill, A, T)            # α_S(a,t)
    return TemporalModel(rho0, lam, alpha_t)
```

### IP-122 TVH（Temporal Validity Horizon）

```python
def validity_horizon(rho0, lam, rho_min):
    t_valid = {}
    for d in rho0:
        if lam[d] <= 1e-9:
            t_valid[d] = float('inf') if rho0[d] >= rho_min[d] else 0.0
        else:
            t_valid[d] = max(0.0, (rho0[d] - rho_min[d]) / lam[d])
    return min(t_valid.values()), t_valid
```

### IP-123 DCC（Dynamical Compatibility Certificate）

```python
def dynamical_compat(s1, s2, delta_A, eps=0.1):
    if not static_compat(s1.alpha, s2.alpha):
        return ('reject','no_overlap')
    Phi = compose_transition(s1.f, s2.f)
    gamma = contraction_estimate(Phi, delta_A)      # 采样 + 局部 Jacobian
    spec  = spectral_radius(jacobian(Phi, delta_A))
    if gamma >= 1 - eps or spec >= 1:
        return ('reject','non_contractive', gamma, spec)
    return ('ok', DCC(gamma, spec, delta_A))
```

### IP-124 HILT（Human-in-the-Loop Test Protocol）

```python
def hilt_test(cert, user_pool, budget, delta_min, max_beta):
    tests, traces = [], []
    while budget_used() < budget:
        x = active_select(cert, user_pool, traces)   # 见 IP-126
        theta_u = sample_user(user_pool, cond_on=x)
        trace = rollout_human_robot(cert.skill_seq, x, theta_u)
        tests.append((x, theta_u, trace))
        if violates(trace, cert, delta_min):
            return ('falsified', trace)
    d_tv = estimate_divergence(tests, cert.deploy_dist)
    beta = estimate_miss_rate(tests, delta_min, conf=0.95)
    if d_tv > cert.eps_u or beta > max_beta:
        return ('inconclusive', d_tv, beta)
    return ('supported', d_tv, beta, coverage(tests, cert.domain))
```

### IP-125 CAL（Certificate Aging Lifecycle）

```python
def monitor_and_revalidate(cert, stream, h, nu):
    m = 0.0
    for t, (x, y) in enumerate(stream):
        y_hat = cert.model.predict(x)
        m = max(0.0, m + abs(y - y_hat) - nu)
        if m > h or t >= cert.T_valid_lcb:
            return request_revalidation(cert, reason=('drift' if m>h else 'expiry'))
    return ('alive', m)
```

### IP-126 ATS（Active Test Selection）

```python
def active_select(cert, user_pool, history):
    # 以“距离证书边界最近 / 后验违规概率最高”为信息增益代理
    candidates = sample_candidates(user_pool, cert.domain, n=256)
    scores = [expected_info_gain(c, cert, history) for c in candidates]
    return candidates[argmax(scores)]
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| DAP | O(|A|·|T| + |calib|·|d|) | O(|A|·|T|) | 漂移界单侧置信有效、标定分布覆盖 |
| TVH | O(|d|) | O(|d|) | `λ_ρ` 上界 sound、余量非负 |
| DCC | O(|ΔA|·|samples|) | O(|ΔA|) | 压缩估计保守、谱半径下界可靠 |
| HILT | O(B·|trace|) | O(B·|trace|) | 用户覆盖、检验功效可估 |
| CAL | O(T·|x|) | O(1) | CUSUM 阈值标定、漂移可检出 |
| ATS | O(n·|cert|) | O(n) | 信息增益代理单调、无重复偏置 |

**正确性定理（Temporal-User Soundness）**
承接第 54 轮 (A22)–(A28)，新增：**(A29)** 漂移界以概率 `≥ 1-ε_λ` 成立；**(A30)** 每条组合边满足 `γ_{ij}<1` 且谱半径 `<1`；**(A31)** `d_TV(D_test,D_deploy) ≤ ε_u`；**(A32)** 用户检验对幅度 `≥ Δ_min` 的违规有功效 `1-β_user`。则对 `T_mission ≤ T_valid^{LCB}`：
```
P(部署违规未被发现) ≤ ε_λ + ε_u + β_user + P(δ_a > Θ_a) + P(compat_dyn 失效)
```
**退化检验**：令 `T_valid→∞`、`d_TV→0`、`β_user→0`，则退化为第 54 轮定理，说明 v31 是本框架的“静态切片”，本轮是其**时间-用户扩展**而非替代。

## 4. 实验设计 E162–E167

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 漂移界准确度 | `T_valid` 预测误差 / 实际越界时间 | 相对误差 ≤ 15%，且预测偏保守 |
| E163 动力学兼容判定 | `γ` 估计误差 / 非压缩误放行率 | 误放行 ≤ 3% |
| E164 用户测试覆盖 | `cov_test` vs 部署失败发现率 | 发现率随覆盖单调，低覆盖显著漏检 |
| E165 证书老化监控 | 漂移检出延迟 / 误报率 | 延迟 ≤ 2 个监控窗，误报 ≤ 5% |
| E166 共适应用户压力测试 | 自适应用户下的成功率 | 优于静态证书 ≥ 10% |
| E167 主动测试效率 | 达到同功效所需样本数 | 比随机选样少 ≥ 40% |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 漂移界标定偏乐观导致 `T_valid` 高估 | 高 | 单侧置信上界 + 分布外检测 + 强制保守裕度 |
| 压缩系数估计在非光滑交接处失真 | 高 | 局部谱分析 + 保守 `γ` 上界 + 交接处护栏 |
| 用户测试功效被脚本用户虚高 | 高 | 多样用户池 + 共适应建模 + `d_TV` 打折 |
| CUSUM 阈值与重测成本耦合震荡 | 中 | 双阈值 + 滞回 + 成本感知调度 |
| 生命周期策略导致证书频繁重签 | 中 | 事件触发 + 增量重签 + 证据缓存 |

## 6. 本轮最大风险

**一句话**：把证书从静态快照升级为“带有效期、带用户测试功效、带漂移监控”的活对象，理论上让安全声明拥有了时间与人群维度，但整个 soundness 现在**同时押注在漂移界标定的保守性、压缩系数估计的可靠性、以及用户测试分布与部署分布的可比性**上——三者任一被低估，`T_valid` 就会变成“看起来还能用”的乐观外推，用户测试也会退化为自我确认的仪式；因此必须以 **单侧置信漂移界 + 非压缩硬护栏 + `d_TV` 显式打折** 作为不可绕过的三道否决线，宁可提前重测，绝不把“测过且还没坏”当作安全证明。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-Temporal（DAP×TVH×DCC×HILT×CAL×ATS）

> 承接第 54 轮产物 v31。本轮把静态的“动作-鲁棒性双证书”升级为**带时间维与人群维的活证书**，新增六个算子：
> - **DAP（Dynamics-Aware Profiling）**：把动作剖面与鲁棒性谱时间化，显式给出漂移界；
> - **TVH（Temporal Validity Horizon）**：由“余量/漂移率”计算证书有效期；
> - **DCC（Dynamical Compatibility Certificate）**：把技能组合从“空间重叠”升级为“压缩稳定”；
> - **HILT（Human-in-the-Loop Test）**：把用户测试建成带覆盖与统计功效的序贯证伪；
> - **CAL（Certificate Aging Lifecycle）**：CUSUM 漂移监控 + 到期/报警触发重验证；
> - **ATS（Active Test Selection）**：以信息增益挑选最可能推翻证书的用户测试用例。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/116/118/120 以纳入时间与用户维度。体系代号 v16+++ → **v17 Temporal**。

```python
def hilt_test(cert, user_pool, budget, delta_min, max_beta):
    tests, traces = [], []
    while budget_used() < budget:
        x = active_select(cert, user_pool, traces)
        theta_u = sample_user(user_pool, cond_on=x)
        trace = rollout_human_robot(cert.skill_seq, x, theta_u)
        tests.append((x, theta_u, trace))
        if violates(trace, cert, delta_min):
            return ('falsified', trace)
    d_tv = estimate_divergence(tests, cert.deploy_dist)
    beta = estimate_miss_rate(tests, delta_min, conf=0.95)
    if d_tv > cert.eps_u or beta > max_beta:
        return ('inconclusive', d_tv, beta)
    return ('supported', d_tv, beta, coverage(tests, cert.domain))
```

### IP-125 CAL

```python
def monitor_and_revalidate(cert, stream, h, nu):
    m = 0.0
    for t, (x, y) in enumerate(stream):
        m = max(0.0, m + abs(y - cert.model.predict(x)) - nu)
        if m > h or t >= cert.T_valid_lcb:
            return request_revalidation(cert, reason=('drift' if m>h else 'expiry'))
    return ('alive', m)
```

```python
def issue_temporal_cert(skill_seq, gamma_ce, calib, test_budget, mission_T):
    J = joint_certificate(skill_seq, gamma_ce, delta_a_budget, rho_min)
    if J[0] != 'ok':
        return ('reject', J)
    tm = [drift_profile(s, A, mission_T, calib) for s in skill_seq]
    t_valid = min(validity_horizon(m.rho0, m.lam, rho_min)[0] for m in tm)
    for s1, s2 in pairwise(skill_seq):
        dcc = dynamical_compat(s1, s2, transition_region(s1, s2))
        if dcc[0] != 'ok':
            return ('reject', dcc)
    hil = hilt_test(J[1], user_pool, test_budget, delta_min, beta_max)
    if hil[0] != 'supported':
        return ('reject', hil)
    if t_valid < mission_T:
        return ('reject', 'expired_before_mission', t_valid)
    return ('ok', TUC(J[1], t_valid, hil.d_tv, hil.coverage, hil.beta, sign(J), expiry=t_valid))
```

**正确性定理（Temporal-User Soundness）**
承接第 54 轮 (A22)–(A28)，新增 **(A29)** 漂移界以概率 `≥1-ε_λ` 成立；**(A30)** 组合边 `γ_{ij}<1` 且谱半径 `<1`；**(A31)** `d_TV ≤ ε_u`；**(A32)** 对幅度 `≥Δ_min` 的违规检验功效 `1-β_user`。则对 `T_mission ≤ T_valid^{LCB}`：
```
P(部署违规未被发现)
  ≤ ε_λ + ε_u + β_user + P(δ_a > Θ_a) + P(compat_dyn 失效)
```
**退化检验**：`T_valid→∞, d_TV→0, β_user→0` 时退化为第 54 轮定理，故本轮是 v31 的严格扩展并保留其全部保证。

## 6. 本轮最大风险

**一句话**：把证书升级为“带有效期、带用户测试功效、带漂移监控”的活对象，理论上让安全声明拥有了时间与人群维度，但整个 soundness 现在**同时押注在漂移界标定的保守性、压缩系数估计的可靠性、以及用户测试分布与部署分布的可比性**上——三者任一被低估，`T_valid` 就会退化为“看起来还能用”的乐观外推，用户测试也会沦为自我确认的仪式；因此必须以 **单侧置信漂移界 + 非压缩硬护栏 + `d_TV` 显式打折** 作为不可绕过的三道否决线，宁可提前重测，绝不把“测过且还没坏”当作安全证明。
