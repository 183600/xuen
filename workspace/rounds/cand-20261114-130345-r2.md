# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~302；灵感循环续轮；本轮灵感：「结构优化」×「记忆检索」）

> R73 用证据契约 EC、组合代数 CCA、热替换定理把「具身计量」做成了可组合的模块系统，并用 CPB 蒸馏出三条可证伪主张。但 R73 仍把两件事当成**外生给定**：
> - **拓扑是给定的**。MReg 的节点与边由工程师手工设计；CCA 只回答「给定结构如何安全组合」，不回答「**应该长成什么结构**」。|V_M|≤24、组合深度≤4 只是审计上限，不是优化变量；热替换定理只覆盖「同契约换实现」，不覆盖**加节点、删节点、改边、合并冗余证据**。换一只灵巧手仍要人重新设计图。
> - **证书是失忆的**。每次部署都从零重跑 SEAL/conformal/RTA；上一轮在相似场景里已经付过的校准成本、已经踩过的失效案例、已经验证过的成功拓扑，全部被丢弃。R73 自己承认最大风险是「契约表达力」，却没有**记住那些恰好落在契约之外的案例**的机制——经验无法回流，错误可以被重复支付。
>
> 本轮两个灵感正好补这两块：
> - **结构优化** → **STR/STO**：把结构本身变成待优化的证据决策变量。定义一组**带局部证书增量的结构重写规则**（加/删/重连/并联/插入否决/去重），每一个重写只需在受影响的 k-邻域重新认证，于是「热替换」从**节点级**升级为**图级**；再用分支定界/任意时间搜索在安全不变式下综合拓扑。
> - **记忆检索** → **SM/ROM**：把过去的（上下文 → 契约 → 证书 → 结果 → 违例）存成**结构记忆**，按上下文描述子检索复用。但检索有一个统计上的毒点：conformal 的有效性依赖**可交换性**，而记忆与当前上下文不可交换。于是把「记忆」提升为一等证据源，并引入**检索条件覆盖税**（TV 距离上界 ⇒ 覆盖损失上界），使复用既能摊销认证成本，又不静默破坏覆盖率。
> - **两者相乘** → **MAS + NTR**：结构搜索昂贵，用记忆热启动；但记忆会把搜索锁进历史偏置，于是用**新奇度触发重认证**与**覆盖率关键集遗忘策略**给记忆装上「反确认偏误」阀门。
>
> 核心命题转换：R73 问「证据计量能否成为可组合的契约」；本轮问——**证据系统的「形状」本身能否被安全地优化，且过去的认证经验能否被诚实地复用——使系统在结构增删、场景漂移、经验老化下，用局部证书增量而非全系统重审来保持系统级安全？** 把 MODGAUGE-RAS 推进为 **SOMA-GAUGE-RAS**（Structural Optimization & Memory-Augmented GAUGE for RAS；SOMA 亦取「身体」义）——**结构重写 × 检索条件覆盖 × 记忆加速的结构综合**。

## 0. 直觉与动机

**灵感 1（结构优化 → 结构是被优化的决策变量，重写必须有局部证明增量）**
直觉：机械里的拓扑优化（SIMP）不是问「这块材料安不安全」，而是问「在应力约束下材料该怎么分布最省」；它之所以可做，是因为每次局部密度变化带来的平衡方程残差可以在**局部**更新，而不是全局重解。R73 的 MReg 正缺这一层：它给定了「材料分布」，只证明「当前分布安全」。如果给 MReg 一组**重写规则**（增加一个深度模块、删掉冗余接触模块、把两条串联边重结合、把一个并联降级为保守串联、插入一个独立否决源、合并两个证书等价的重复模块），并且每条规则携带一个只依赖局部邻域的**证书增量 ΔJ**，那么结构优化就变成「在安全约束下走一条合法的重写路径」。这与 R73 的热替换定理同构，但粒度从「同契约换实现」升到「换图」。必须诚实：结构优化天然会**利用模型误差**——优化器会把不确定度推向契约未覆盖的角落，所以每条重写必须被审计，目标函数必须风险感知，且「变便宜」必须有来源（审计、等价性、或记忆覆盖税）。

**灵感 2（记忆检索 → 证书可复用，但检索破坏可交换性，必须收覆盖税）**
直觉：人类工程师不会每个项目都从头推导安全边界，而是检索「上一个类似场景是怎么做的」。R73 的 J_MOD 每次重算，是**失忆的审计**。若把过去的（上下文 c、契约、证书、实际结果、违例）存起来，按 c 检索，就能摊销 SEAL/conformal/RTA 的成本，甚至用历史违例提前收缩有效域。但这里有严格的统计陷阱：conformal 的 1−α 覆盖保证依赖校准集与测试集的**可交换性**；记忆条目来自不同场景，不可交换。若直接拿旧阈值，覆盖率会静默下降——这恰是 R73 最担心的「契约表达力外溢」的另一种形态。严谨的做法不是「别用记忆」，而是让记忆**显式携带不确定性**：用两样本检验/密度比给出 TV 距离上界 δ，再令 α_eff = α − δ，用「更大的预测集」买回覆盖率。记忆因此成为带 u_mem 与追溯链的一等证据源，而不是免费的权威。

**灵感 3（两者相乘 → 结构记忆：搜索轨迹本身是可检索经验，但会锁进历史偏置）**
直觉：结构优化是组合搜索，昂贵；记忆检索把它摊销——把「上下文 → 重写序列 → 结果拓扑 → 证书增量 → 后悔值」存起来，下次从检索到的序列热启动。但这制造了一个反馈环：系统会越来越偏好「长得像记忆里成功案例」的拓扑， novelty 被压低，真正的更优结构（或新的危险）被忽略——**记忆诱导的确认偏误**。人类组织也有这个问题（路径依赖）。所以必须有一条硬规则：当新奇度 ν(c) 超过阈值、或检索差异 δ 超过可认证范围时，**强制从头认证并允许探索性拓扑**，且把这次的探索结果写回记忆。记忆必须能被「反事实审计」，否则它只是把过去的错误固化成今天的默认值。

**灵感 4（记忆本身是模块 → 检索反作用通道 χ_mem）**
直觉：检索质量依赖于**当前查询/动作如何改变上下文分布**：主动探索会走到记忆稀疏区，检索命中率下降，证据质量随之下降；保守运动停留在记忆密集区，命中率高但信息增益低。这与 R73 的视角反作用 L4 同构——动作改变证据质量。因此把「记忆检索」也写成一个带反作用通道 χ_mem 的证据模块：动作 g 调制未来上下文与检索命中率，命中率下降等价于 u_mem 上升；进入 ΣREFLEX† 的通道预算。这样「记忆好不好用」不再是一个实现细节，而是一个被预算约束、可拒绝、可审计的系统量。

**灵感 5（蒸馏纪律 → 新增两条可证伪主张 C4/C5）**
直觉：R73 的 C1–C3 覆盖「物理证据计量 / 反作用预算 / 契约模块化」。本轮必须回答「结构优化与记忆复用的净收益是否真实」。于是：
- **C4（结构重写的安全可证）**：带局部证书增量的重写 + 任意时间结构搜索，能在**保持系统级安全性质**的同时，比手工拓扑或全量重搜索获得更低的期望代价（不确定度 + 反作用 + 时延 + 认证成本）。
- **C5（记忆条件覆盖的诚实复用）**：带覆盖税的记忆复用能在**维持 1−α 覆盖**的同时显著摊销认证成本；而不收税的朴素复用会可测地破坏覆盖率。
每条绑定最小基准、隔离消融、预注册指标；不服务主张的组件降级为工程附件。

## 1. 形式化定义（增量：定义 383–397）

**定义 383（SOMA-GAUGE-RAS 总览）** SOMA-GAUGE-RAS = (MReg†, SM, ROM, STR, STO, MAS, CM, CCA†, ΣREFLEX†, CPB†)。在 R73 五不变式上增加两条，共七不变式：
(i) **契约完整性**：无完整 EC 不入图（继承定义 366(i)）；
(ii) **组合单调性**：SER/PAR/VETO 经 CCA 校验，无凭空变好（继承定义 370、引理 34）；
(iii) **反作用通道完备**：每个证据模块声明 χ_R，ΣREFLEX 预算闭合（继承定义 371）；
(iv) **主张绑定**：组件 ∈ {C1,…,C5, 工程附件}（扩展定义 374）；
(v) **严格退化链**：模块级 stub → 系统级性质不变，安全侧只增不减（继承定义 375、381）；
(vi) **重写可靠性（新）**：任何结构变化必须是有限条**已认证局部重写**的复合；每条重写携带局部证书增量 ΔJ；任何使 U 或代价下降的重写，必须有审计、等价性证书或覆盖税作为代价来源，否则拒绝；
(vii) **记忆诚实性（新）**：任何复用的证书必须携带检索条件覆盖声明（δ 上界 + 覆盖税）；无法给出有效 δ 上界的记忆条目**禁止参与认证决策**，只能作为提示，系统回退到从头认证。

**定义 384（结构记忆 SM）** SM = (M_sem, M_epi, IDX, ρ_evict)：
- M_sem（语义记忆）：以 (EC_hash, seal_version) 为键，存契约、模块证书、校准统计、有效域；跨部署持久；
- M_epi（情节记忆）：条目 e = (c, a, y, outcome, violation, t, prov)，c 为上下文描述子，prov 为来源/签名/追溯链；
- IDX：上下文描述子 → top-k 条目的近似最近邻索引（ANN + 精确重排）；
- ρ_evict：容量受限（|SM| ≤ M_max）下的遗忘策略，必须保 **覆盖关键集**（定义 391）。
记忆条目只提供**证据**，不提供**权威**（继承 E356/E357「单源不定案」）。

**定义 385（上下文描述子与检索算子）** c_t = (b_t^coarse, v, m̂, u_vec, task_phase, morphology_id, env_fingerprint)。检索 R_k(c) = {(e_i, s_i)}_{i=1..k}，s_i 为校准后的相关度。定义**检索差异**
δ(c) := 一个经校准的 TV(P_query, P_mem | e ∈ R_k(c)) 上界，由两样本检验 / 密度比估计 + conformal 修正得到；δ 本身必须是保守的（估计器只允许高估，不允许低估）。

**定义 386（检索条件覆盖与覆盖税）** 设记忆上以水平 α_eff 校准的 conformal 集 C_mem(·; α_eff) 满足 P_mem(Y ∈ C) ≥ 1 − α_eff。令
α_eff(c) = max(α − δ(c), α_min)，δ(c) ∈ [0, α − α_min]。
**引理 38**：若 TV(P_query, P_mem|c) ≤ δ(c)，则 P_query(Y ∈ C_mem) ≥ 1 − α。**覆盖税** t := δ(c)：用更大的预测集（更小 α_eff）买回漂移下的覆盖率。若 δ(c) 无法认证到 α − α_min 以下，则**禁止复用**（α_eff 无定义，回退从头认证）。

**定义 387（结构重写系统 STR）** 一条重写规则 ρ: (MReg, c) → (MReg′, ΔJ)，ρ = (pre, post, ΔJ, k)，k 为受影响的邻域半径（k ≤ 2）。规则集：
- **R_ADD(m)**：前置 = EC_m 完整 ∧ 预算闭合 ∧ D_m ∩ D_downstream ≠ ∅ ∧ 主张绑定已填；后置 = MReg 增节点与边；ΔJ = J(m) ⊗ J_connect(m)。
- **R_DROP(m)**：前置 = m 能投否决的每个安全关键命题，仍被 MReg∖{m} 中某模块覆盖；后置 = 删节点；ΔJ = J_recheck(neighbors)。不满足则**拒绝**（保守，继承非补偿）。
- **R_REWIRE(e₁,e₂)**：前置 = CCA 的串联结合律（或 PAR 的分配律）在子图上成立；后置 = 重结合；ΔJ 只重算子链。
- **R_PAR(i)**：前置 = 有可用的跨模态一致性审计且 |ρ̂| < ρ_max；后置 = 插入 PAR 边；ΔJ = J_audit。
- **R_SER(i)**：把 PAR 降级为保守 SER/max——**永远允许**（只收紧），ΔJ = 保守标记。
- **R_VETO(i)**：插入一个独立第三方否决源——**永远允许**（单调收紧），ΔJ = J(第三方)。
- **R_DEDUP(a,b)**：前置 = a,b 证书等价（同 EC 且在 SEAL 上统计不可区分）；后置 = 合并；ΔJ = J_equiv。

**定义 388（局部证书增量与图级热替换）** ΔJ(ρ) 只依赖 N_k(ρ)（k ≤ 2 邻域），大小 ≤ ℓ。结构证书 J_rewrite(ρ₁…ρₙ) = ⊗ᵢ ΔJ(ρᵢ)，且 J(MReg′) = J(MReg) ⊗ J_rewrite。对照：R73 热替换是 **O(模块)** 重认证；SOMA 重写是 **O(邻域)** 增量，且允许改变图的形状。

**定义 389（结构拓扑优化 STO）** 在重写路径空间上求解
min_{ρ₁…ρₙ} E[ Σ_t ( λ·U_t + Σ_i c_reflex^i + w_L·L_t ) ] + w_C·CertCost(MRegₙ)
s.t. 不变式 (i)–(vii)、|V_M| ≤ 24、depth ≤ 4、覆盖率 ≥ 1−α、重写可靠性。
搜索用**分支定界/任意时间 MCTS**：下界由引理 34（组合下界）与单调收缩给出；上界是当前可行拓扑。任意时刻返回可行 MReg 与单调不增的上界。

**定义 390（记忆加速结构搜索 MAS）** 检索 (c → 重写序列, 结果, 后悔值) 作为提议分布热启动；每个提议的重写仍须逐条局部认证（**记忆不能替代证明**）；搜索结束后写回 (c, 序列, 结果, regret)。摊销度量：相对从零搜索节省的认证节点数与 CertCost。

**定义 391（记忆巩固与遗忘 CM）** 情节记忆按上下文单元巩固为语义统计（经验覆盖率、失效频率、域收缩量）；遗忘时优先淘汰对最坏覆盖税影响最小的条目，且**覆盖关键集**（移除后使某上下文单元 δ 上界超阈值的条目集合）不可淘汰。**引理 42**：若覆盖关键集被保留，则任意上下文单元的最坏 α_eff 有下界，记忆有界不破坏覆盖税的可认证性。

**定义 392（记忆投毒威胁面 AIC-MEM）** 攻击：伪造证书注入、过期上下文回放、检索索引投毒、来源伪造。防线：provenance 签名（绑定 SEAL）、多源佐证（单源不定案）、staleness 衰减、隔离区 + 强制重认证、跨来源一致性审计。**记忆是证据，不是权威**。

**定义 393（新奇度触发重认证 NTR）** 新奇度 ν(c) = 到最近语义簇的距离 / OOD 分数。触发条件：ν(c) > τ_nov ∨ δ(c) > δ_max ∨ 检索 top-k 来源单一。触发 ⇒ 强制从头认证 + 允许探索性重写，并把探索结果写回记忆（打破锁死）。

**定义 394（结构-记忆联合证书 J_SOMA）** J_SOMA = J_MOD(MReg) ⊗ J_rewrite(ρ₁…ρₙ) ⊗ J_mem(R_k(c), δ) ⊗ J_STO(任意时间界/最优性间隙)。Valid(J_SOMA) ⇒ 在记忆复用与结构重写下的系统安全（取决于 δ 上界的有效性与 provenance）。

**定义 395（严格退化链）** 记忆为空 ⇒ ROM 返回空 ⇒ SOMA 逐指令等于 R73 MODGAUGE；STR 仅恒等 ⇒ 固定拓扑；δ 不可认证 ⇒ 从头认证；STO 不可行 ⇒ 回退 R73 手工拓扑；再退化 = R72/R71/R68。

**定义 396（检索反作用通道 χ_mem）** χ_mem: g ↦ (Δc, Δδ, Δhit)，动作 g 改变未来上下文分布、检索差异与命中率；对应成本 c_reflex^mem = E[Δu_mem | g]，进入 ΣREFLEX† 的通道预算。命中率下降 ⇒ u_mem 上升 ⇒ 等效证据质量下降（与 L4 视角通道同构）。

**定义 397（复杂度与预注册指标）** 结构界：|SM| ≤ M_max、重写深度 ≤ R_max、k ≤ k_max、|ΔJ| ≤ ℓ、|V_M| ≤ 24、depth ≤ 4。预注册指标：安全违例率、覆盖率、CertCost、结构变动率（churn）、后悔值、记忆命中率、δ 有效率。

## 2. 关键算法骨架

```python
# IP-303 SM：结构记忆（语义 + 情节 + 索引 + 来源）
@dataclass(frozen=True)
class Episode:
    c: ContextDesc; seq: Tuple[str, ...]        # 上下文 → 重写序列
    topology_hash: str; outcome: Outcome
    violation: FrozenSet[str]; t: float; prov: Provenance   # 来源/签名/追溯
    regret: float

class StructuredMemory:
    def __init__(self, cap): self.sem, self.epi, self.idx, self.cap = {}, [], ANN(), cap
    def store(self, e):                            # 写回经验（含 provenance）
        self.epi.append(e); self.idx.add(e.c, e)
        if len(self.epi) > self.cap: self.evict()  # 定义 391：保覆盖关键集
    def retrieve(self, c, k) -> List[Tuple[Episode, float]]:
        cand = self.idx.topk(c, 4*k);               # ANN 粗排
        return exact_rerank(cand, k)                # 精确重排 + 相关度校准
    def evict(self):
        crit = coverage_critical_set(self.epi)      # 移除此集合会抬升 δ 上界
        drop = min((e for e in self.epi if e not in crit),
                   key=lambda e: worst_case_delta_impact(e))
        self.idx.remove(drop.c, drop); self.epi.remove(drop)

# IP-304 ROM：检索条件覆盖税（记忆作为一等证据）
def retrieve_with_coverage(c, alpha, mem: StructuredMemory):
    hits = mem.retrieve(c, K_MAX)
    if not hits: return MemoryEvidence(empty=True, delta=0.0, fallback='FROM_SCRATCH')
    delta = conservative_tv_bound(c, [e for e, _ in hits])   # 只许高估
    if delta > alpha - ALPHA_MIN:                             # δ 不可认证
        return MemoryEvidence(empty=True, delta=delta, fallback='FROM_SCRATCH')
    alpha_eff = alpha - delta                                 # 覆盖税
    certs = [e.prov.cert for e, _ in hits if e.violation == frozenset()]
    return MemoryEvidence(empty=False, delta=delta, alpha_eff=alpha_eff,
                          certs=certs, u_mem=delta, tax=delta,
                          provenance_ok=multi_source_ok(hits), fallback=None)

               for p in critical)                           # 否则拒绝（非补偿）

# IP-306 STO：任意时间分支定界结构搜索
def optimize_structure(MReg0, c, budget_nodes):
    best, best_cost = MReg0, total_cost(MReg0, c)           # 上界：当前可行解
    frontier = [(MReg0, 0.0, [])]
    while frontier and budget_nodes > 0:
        node, path_cost, path = pop_best(frontier)
        if path_cost + admissible_lower_bound(node, c) >= best_cost:
            continue                                        # 剪枝：组合下界（引理 34）
        for rho in feasible_rewrites(node, c):              # 定义 387
            nxt, dJ = rewrite(node, rho, c)
            cost = path_cost + step_cost(dJ)
            if cost < best_cost:
                best, best_cost = nxt, cost
            frontier.push((nxt, cost, path + [rho.name]))
            budget_nodes -= 1
    return best, best_cost                                  # 任意时间：始终可行 + 上界单调不增
```

## 3. 推导

**引理 38（检索覆盖税的正确性）** 设事件 A = {Y ∈ C_mem}，A 为有界指示。对任意两个分布，|P_query(A) − P_mem(A)| ≤ TV(P_query, P_mem)。若记忆上 conformal 满足 P_mem(A) ≥ 1 − α_eff 且 δ ≥ TV，则 P_query(A) ≥ 1 − α_eff − δ。取 α_eff = α − δ 得 P_query(A) ≥ 1 − α。系：**记忆复用不是免费午餐，税就是可认证的分布漂移上界；δ 估计器必须只高估不低估。**

**引理 39（重写可靠性）** 对每条规则 ρ，若 pre 成立且 MReg 满足不变式 (i)–(v)，则 MReg′ 仍满足，且 ΔJ 只引用 N_k(ρ)。证明按规则分类：R_DROP/R_SER 只收紧（单调保守，继承引理 34）；R_ADD/R_PAR/R_DEDUP 仅在闭包/审计/等价前提下允许；R_VETO 单调收缩有效域。对重写序列归纳。系：**结构变化的安全性可以局部证明，不必全图重来。**

**引理 40（重写无免费午餐）** 任何使 U 或期望代价下降的重写路径，必须至少满足其一：(a) 经过 CCA 一致性审计（PAR 缩窄）；(b) 证书等价（DEDUP）；(c) 记忆复用并支付覆盖税 δ > 0。否则由组合下界与有效域单调性，U 不下降，重写被拒绝。系：**结构优化只能在「已挣得的认知收益」内变好。**

**引理 41（记忆摊销）** 设命中率为 h、从零认证成本 C_full、局部增量成本 C_local、检索成本 C_ret，则期望认证成本 E[CertCost] ≤ (1−h)·C_full + h·(C_local + C_ret)，且当 h > C_ret/(C_full − C_local) 时严格优于失忆审计。**引理 42（有界记忆的覆盖税）** 若遗忘保留覆盖关键集，则各上下文单元的最坏 δ 不随记忆容量下降而恶化，α_eff 有下界。

**定理 30（SOMA 严格包含）** 空记忆 + 恒等重写 + STO 关闭 ⇒ SOMA 逐指令等于 R73 MODGAUGE；再由定理 27 退化为 R72/R71/R68。**安全单调不减；记忆与结构优化只在契约与 δ 有效时获益。**

**定理 31（记忆条件安全）** 在 A114–A116（δ 上界保守有效、provenance 不可伪造、重写引理 39 成立）下，Valid(J_SOMA) ⇒ 物理执行风险 ≤ ε_phys + δ_cov，其中 δ_cov 为覆盖税累积界。**证明重量落在 δ 的有效性与来源不可伪造上，而非检索算法本身。**

**定理 32（图级热替换）** 合法重写序列 ρ₁…ρₙ 使系统级性质（退化链、风险单调、时序隔离、审计覆盖）逐指令保持；认证成本从 R73 的 O(系统)→O(模块) 进一步降为 **O(邻域)**，结构变动率 ≤ R_max。**定理 33（任意时间结构优化）** 分支定界在任意预算下返回可行 MReg，上界单调不增；给定可采纳下界时，最终解与最优解间隙 ≤ ε_STO。**定理 34（记忆锁死的可检测性）** 若新奇度与 δ 触发被正确执行，则任何上下文单元的探索性重写概率 ≥ p_min > 0，故 top-1 拓扑的历史占有率不构成吸收态。

## 6. 本轮最大风险

**一句话**：SOMA 把安全证明从「契约表达力」进一步押注到「**分布漂移上界 δ 的可认证性**」与「**记忆来源的不可伪造性**」上——在开放世界里 δ 只能用有限样本与两样本检验去估，任何低估都会让覆盖税变成摆设，系统于是用一套**结构合法、局部证书齐全、审计日志完美**的图，系统性地把历史经验当成当前真相，而结构优化又会把这种偏差固化成拓扑偏置；次级风险与缓解：①δ 低估 → 只许保守估计 + 多检验并用 + 无法认证即从头认证；②记忆投毒 → provenance 签名 + 多源佐证 + 隔离区；③结构振荡 → churn 惩罚 + 任意时间上界单调；④记忆锁死 → NTR 强制探索 + 反事实审计；⑤有界记忆偏置 → 覆盖关键集保留 + 定期 SEAL-Mem 重校准；⑥搜索利用模型误差 → 重写无免费午餐引理 + 风险感知目标。

**本轮最大风险一句话**：如果「记忆与当前上下文之间的分布漂移上界 δ」被低估或来源被伪造，SOMA 会在所有局部证书都有效、所有重写都合规的情况下，用历史经验系统性地低报不确定度，并把这种错误固化为结构偏置——即**记忆诱导的自信错误**。

| `C4 / C5` | 新增主张：结构重写安全可证 / 记忆条件覆盖诚实复用 |

## 2. 形式化定义（要点版）

**定义 383（总览与七不变式）** 契约完整性 / 组合单调性 / 反作用通道完备 / 主张绑定 / 严格退化链（R73 五条）+ **重写可靠性**（结构变化=已认证局部重写之复合，无免费变好）+ **记忆诚实性**（复用必须携带 δ 上界与覆盖税，否则禁止参与认证）。

**定义 384（结构记忆 SM）** 语义记忆存契约/证书/校准（持久）；情节记忆存上下文→重写→结果→违例（带 provenance 与时间）；ANN 索引粗排 + 精确重排；容量 M_max，遗忘保覆盖关键集。记忆只提供证据、不提供权威。

**定义 385（上下文与检索）** c_t 由状态粗摘要、视角、材质后验、不确定度向量、任务阶段、形态 id、环境指纹组成；R_k(c) 返回 (e_i, s_i)；δ(c) 为经保守校准的 TV(P_query, P_mem|R_k) 上界。

**定义 386（检索条件覆盖与覆盖税）** 忆上 conformal 满足 P_mem(Y∈C)≥1−α_eff；由 TV 有界性 P_query(Y∈C) ≥ 1−α_eff−δ；取 α_eff=α−δ 恢复 ≥1−α。**引理 38**。δ 不可认证（>α−α_min）⇒ 禁止复用。

**定义 387（结构重写 STR）** 七规则：
- **R_ADD(m)**：EC 完整 ∧ 预算闭合 ∧ 域交非空 ∧ 主张已绑定；ΔJ = J(m)⊗J_connect；
- **R_DROP(m)**：m 的安全关键否决命题仍被其他模块覆盖，否则拒绝；ΔJ = J_recheck(neighbors)；
- **R_REWIRE(e₁,e₂)**：串联结合律/并联分配律在子图成立；ΔJ 只算子链；
- **R_PAR(i)**：需 conformal 一致性审计且 |ρ̂|<ρ_max；ΔJ = J_audit；
- **R_SER(i)**：PAR→保守 SER/max，永远允许（只收紧）；
- **R_VETO(i)**：插入独立第三方否决源，永远允许（单调收紧）；
- **R_DEDUP(a,b)**：证书等价（同 EC + SEAL 统计不可区分）才可合并；ΔJ = J_equiv。

**定义 388（局部证书增量与图级热替换）** ΔJ(ρ) 只依赖 N_k(ρ)（k≤2，大小≤ℓ）；J(MReg′)=J(MReg)⊗J_rewrite。认证成本：R73 O(模块) → SOMA O(邻域)。

**定义 389（STO）** min E[Σ(λU + Σc_reflex + w_L L)] + w_C·CertCost s.t. (i)–(vii)、|V_M|≤24、depth≤4、覆盖率≥1−α；分支定界/任意时间 MCTS，下界取组合下界（引理 34）。

**定义 390（MAS）** 检索 (c→序列→结果→regret) 热启动；提议须逐条局部认证；搜索后写回 regret。摊销度量：节点数与 CertCost。

**定义 391（巩固/遗忘 CM）** 情节→语义统计；覆盖关键集不可淘汰；**引理 42**：保留关键集 ⇒ 有界记忆不恶化最坏 δ。**定义 392（AIC-MEM）** 伪造注入/过期回放/索引投毒/来源伪造；防线=签名+多源+staleness+隔离+重认证。**定义 393（NTR）** ν(c)>τ_nov ∨ δ>δ_max ∨ 单源 ⇒ 强制从头认证 + 探索性重写。

**定义 394（J_SOMA）** J_MOD⊗J_rewrite⊗J_mem⊗J_STO；Valid ⇒ 记忆复用与结构重写下的系统安全（依赖 δ 有效性与 provenance）。**定义 395（严格退化链）** 空记忆/恒等重写/δ 失效/STO 不可行 ⇒ 依次回退 R73→R72→R71→R68。**定义 396（χ_mem）** 动作调制未来上下文/δ/命中率，c_reflex^mem=E[Δu_mem|g] 入 ΣREFLEX†。**定义 397（界与指标）** |SM|≤M_max、R_max、k≤2、ℓ、|V_M|≤24、depth≤4；指标=安全违例/覆盖/CertCost/churn/regret/hit/δ 有效率。

```python
# IP-303 SM：结构记忆
@dataclass(frozen=True)
class Episode:
    c: ContextDesc; seq: Tuple[str, ...]; topology_hash: str
    outcome: Outcome; violation: FrozenSet[str]; t: float
    prov: Provenance; regret: float

class StructuredMemory:
    def __init__(self, cap): self.sem={}; self.epi=[]; self.idx=ANN(); self.cap=cap
    def store(self, e):
        self.epi.append(e); self.idx.add(e.c, e)
        if len(self.epi) > self.cap: self.evict()      # 定义 391
    def retrieve(self, c, k):
        return exact_rerank(self.idx.topk(c, 4*k), k)  # 粗排 + 精确重排
    def evict(self):
        crit = coverage_critical_set(self.epi)          # 移除会抬升 δ 上界
        drop = min((e for e in self.epi if e not in crit),
                   key=worst_case_delta_impact)
        self.idx.remove(drop.c, drop); self.epi.remove(drop)

# IP-304 ROM：覆盖税（记忆作为一等证据）
def retrieve_with_coverage(c, alpha, mem):
    hits = mem.retrieve(c, K_MAX)
    if not hits: return MemoryEvidence(empty=True, fallback='FROM_SCRATCH')
    delta = conservative_tv_bound(c, [e for e,_ in hits])   # 只许高估
    if delta > alpha - ALPHA_MIN:
        return MemoryEvidence(empty=True, delta=delta, fallback='FROM_SCRATCH')
    certs = [e.prov.cert for e,_ in hits if not e.violation]
    return MemoryEvidence(empty=False, delta=delta, alpha_eff=alpha-delta,
                          certs=certs, u_mem=delta, tax=delta,
                          provenance_ok=multi_source_ok(hits))

# IP-305 STR：局部证书增量
def rewrite(MReg, rho, c):
    assert rho.pre(MReg, c)
    MReg2 = rho.apply(MReg)
    delta = local_certify(MReg2, neighborhood(MReg, rho, k=rho.k))  # k≤2
    validate_invariants(MReg2, delta)                                # I–VII
    return MReg2, delta

def R_DROP_pre(MReg, m, c):
    critical = safety_critical_vetoes(m, c)
    return all(any(o.can_veto(p) for o in MReg.nodes if o is not m)
               for p in critical)                  # 否则拒绝（非补偿）

# IP-306 STO：任意时间分支定界
def optimize_structure(MReg0, c, budget_nodes):
    best, best_cost = MReg0, total_cost(MReg0, c)   # 上界：可行解
    frontier = [(MReg0, 0.0, [])]
    while frontier and budget_nodes > 0:
        node, pc, path = pop_best(frontier)
        if pc + admissible_lower_bound(node, c) >= best_cost: continue
        for rho in feasible_rewrites(node, c):
            nxt, dJ = rewrite(node, rho, c)
            cost = pc + step_cost(dJ)
            if cost < best_cost: best, best_cost = nxt, cost
            frontier.push((nxt, cost, path + [rho.name])); budget_nodes -= 1
    return best, best_cost                          # 任意时间可行 + 上界单调

# IP-307 MAS：记忆热启动（提议，不替代证明）
def memory_accelerated_search(MReg0, c, mem):
    warm = [e.seq for e,s in mem.retrieve(c, K_WARM) if s > S_MIN]
    seeds = [MReg0] + [replay(seq, MReg0) for seq in warm]
    MReg, cost = optimize_structure(best_feasible(seeds), c, NODES)
    mem.store(Episode(c, path_of(MReg), hash(MReg), {}, frozenset(),
                      now(), provenance(MReg), cost - LOWER_BOUND(c)))
    return MReg, cost

# IP-308 CM/NTR：投毒防御与强制重认证
def admit_memory(e, mem):
    if not verify_provenance(e.prov): return REJECT
    if not multi_source_ok(mem.retrieve(e.c, K_MAX)): return QUARANTINE
    if staleness(e) > T_STALE: return REJECT
    return ACCEPT

def needs_recertification(c, mem):
    hits = mem.retrieve(c, K_MAX)
    return (novelty(c, mem.sem) > TAU_NOV
            or conservative_tv_bound(c, [e for e,_ in hits]) > DELTA_MAX
            or single_source(hits))

# IP-309 J_SOMA 主闭环（复用 R73 三域）
def SOMA_round(M, obs, audio, tac_frame, depth_img, ctx):
    d_ev = M.dpe.update(depth_img, rgb, M.cam_state, M.motion, M.peers)
    if not d_ev.valid: d_ev = stub(M.dpe)                     # 继承定义 381
    if needs_recertification(ctx, M.sm):
        M.dpe = recertify_depth(M.dpe, ctx)                   # 定义 393
    mem_ev = retrieve_with_coverage(ctx, M.alpha, M.sm)       # IP-304
    if M.clock.due_metric():
        if M.clock.due_struct():                              # 低频结构优化
            M.mreg, _ = memory_accelerated_search(M.mreg, ctx, M.sm)
        b_t = M.bse.step_full(..., d_ev=d_ev, mem_ev=mem_ev)  # BSE† 吃带税记忆
        g = M.ervoi.choose(..., M.budget, M.fmp, M.bse)
        if g:
            s2, cost = sigmareflex_step(M.mods, g, M.state, M.budget)  # 含 χ_mem
            if s2 is not None: M.last_g, M.state = g, s2
        M.sm.store(episode_from(M, ctx, g)) if g else None
        M.snapshot.write(b_t, d_ev, mem_ev, M.state, J_SOMA(M.mreg, mem_ev))
    snap = M.snapshot.read_latest()
    lam = embodied_risk_scale(snap.U_ale, snap.U_epi, snap.H_z,
                              max(snap.t_ev.u, snap.d_ev.u), snap.mem_ev.u_mem,
                              M.risk_params)
    k = M.c_ras_wm.certified_prefix(M.ach.propose_ctrl(..., pvop_bias=snap.pvop), lam)
    M.ctrl_out.publish(k, lam)
    return k, lam, J_SOMA(M.mreg, mem_ev)
```

## 4. 推导

**引理 38（覆盖税正确性）** |P_query(A)−P_mem(A)| ≤ TV ≤ δ；P_mem(A) ≥ 1−α_eff ⇒ P_query(A) ≥ 1−α_eff−δ = 1−α。**系：复用要交税，税=可认证漂移上界。** **引理 39（重写可靠性）** 每条规则在 pre 下保不变式 (i)–(v) 且 ΔJ 只引用 N_k(ρ)（分类讨论 + 归纳）。**引理 40（重写无免费午餐）** 降 U/降代价必须来自审计/等价/覆盖税之一，否则由组合下界与域单调性拒绝。**引理 41（记忆摊销）** E[CertCost] ≤ (1−h)C_full + h(C_local+C_ret)，h > C_ret/(C_full−C_local) 时严格优。**引理 42（有界记忆）** 保覆盖关键集 ⇒ 最坏 δ 不随容量下降恶化。

**定理 30（SOMA 严格包含）** 空记忆 + 恒等重写 + STO 关闭 ⇒ 逐指令等于 R73 MODGAUGE（再退化 R72/R71/R68）；安全单调不减。**定理 31（记忆条件安全）** 在 δ 保守有效、provenance 不可伪造、引理 39 成立时，Valid(J_SOMA) ⇒ 风险 ≤ ε_phys + δ_cov。**定理 32（图级热替换）** 合法重写序列保系统级性质；认证 O(邻域)，churn ≤ R_max。**定理 33（任意时间）** 分支定界任意预算返回可行解且上界单调不增，间隙 ≤ ε_STO。**定理 34（锁死可检测）** 若 NTR 正确执行，探索性重写概率 ≥ p_min>0，top-1 历史占有率非吸收态。

## 8. 本轮最大风险

**一句话**：SOMA 把安全证明从「契约表达力」进一步押注到「分布漂移上界 δ 的可认证性」与「记忆来源的不可伪造性」——一旦 δ 被低估或来源被伪造，系统会用一套结构合法、局部证书齐全、审计日志完美的图，系统性地把历史经验当成当前真相，并由结构优化把偏差固化为拓扑偏置。

次级风险与缓解：
1. **δ 低估** → 只许保守估计 + 多检验并用 + 无法认证即从头认证（定义 386）。
2. **记忆投毒** → provenance 签名 + 多源佐证 + staleness + 隔离区 + 强制重认证（定义 392）。
3. **结构振荡** → churn 惩罚 + 任意时间上界单调 + 重写深度 ≤ R_max（定义 389、定理 33）。
4. **记忆锁死** → NTR 强制探索 + 反事实审计 + 周期 SEAL-Mem 重校准（定义 393、定理 34）。
5. **有界记忆偏置** → 覆盖关键集保留 + 分层巩固（定义 391、引理 42）。
6. **搜索利用模型误差** → 重写无免费午餐引理（引理 40）+ 风险感知目标 + 保守重写优先。
7. **主张被记忆收益掩盖** → C4/C5 隔离消融必须与 R73 静态管线、朴素复用、无记忆三基线同跑（E398/E401/E410/E415）。

**本轮最大风险一句话**：若「记忆与当前上下文之间的分布漂移上界 δ」被低估或来源被伪造，SOMA 会在所有局部证书有效、所有重写合规的情况下，用历史经验系统性低报不确定度，并把错误固化为结构偏置——即记忆诱导的自信错误。
