# 第 3 轮（灵感循环新阶段第 1 轮；研究线累计第 3 轮；本轮灵感：「夹爪控制」×「灵巧操作」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E439），其下承第 1 轮 **LeanGauge**（IP-310–314；定义 398–415；引理 42–45）与 **MODGAUGE**。
> **本轮纪律**：不推倒 6C 闭环、MTC/TCV 工具契约、风险门 λ 与增益注 β、MP-Φ/AP-Cal、L-Box 共形假设、MODGAUGE 五不变式、严格退化链与 50Hz 硬实时约束；只正面攻击 ToolGauge 的四个未言明假设，并把「感知计量」扩展为「接触计量」。

## 0. 直觉与动机（先给直觉，再给定义）

### 0.1 ToolGauge 把机器人想成了「带工具的观察者」

ToolGauge 的世界观是**观察者模型**：机器人先在自由空间里看、照、敲、测，把盲区补上，再据此行动。它隐含两条公理：

- **观测公理**：探测是「读」不是「写」——TCV 拒绝或前置失败即零副作用，PROBING 只是把探测公开化；
- **场景公理**：盲区是场景属性（几何 / 材质 / 位姿）的未知，标定一次，同模态内处处可用。

这两条在**自由空间**近似成立，在**接触丰富操作**里同时破裂。夹爪一碰物体，测量通道与被测对象就耦合了；摩擦锥、接触刚度、滑移阈值、力闭合裕度这些量根本不存在于「静态场景」里，只存在于**闭环动作**里。

### 0.2 灵感 1（夹爪控制 → 探测即干预：把「读」升级为「有账本的写」）

直觉上，夹爪不是外挂探头，而是**唯一的、可编程的接触计量仪**：可控力斜坡能扫出法向刚度，微滑能标定摩擦比，切向振荡能激发粘滑前兆，多指对压能测局部柔顺。这些是视觉永远测不到的量。

但同一个动作既是测量也是干预：挤压改变接触面积，滚动改变位姿，释放可能直接掉件。ToolGauge 的「零副作用探测」在接触域不是理想化，而是**错误的安全叙事**。

因此第一条升级是：**取消「零副作用探测」神话，改为「有界、记账、可恢复的扰动」**。每个接触探针必须声明：
(i) 最坏扰动包络 Δ_dist（位姿 / 动量 / 能量 / 塑性应变 / 磨损）；
(ii) 可逆性等级 R0–R3；
(iii) 一个**提交点 commit point**，以及提交前必须可达的**已认证 SAFE-HOLD**。

R0 只读（不改变接触）；R1 弹性可逆（挤压-释放、微剪切）；R2 状态可变但可跟踪恢复（手内滚动、受控重抓）；R3 一经提交不可撤销（释放、大幅塑性变形、越过不可返回位形），必须 at-most-once + 恢复控制器兜底。这样，「回执是否有效」就被升级为「**这次测量对物体做了什么、做完能不能回到安全态**」。

### 0.3 灵感 2（灵巧操作 → 手内重构即主动感知，但手指不是独立样本）

直觉上，多指手的计量优势不是「摸得更准」，而是**可以主动改变物体与传感器 / 相机 / 触觉阵列的相对位姿**：手内滚动能把从未被看到的表面转到镜头前，能用不同接触面重复测同一材质，能通过换指组合制造**独立观测**。这是「动作即测量」。

但灵巧操作带来两个陷阱：

- **机械耦合**：四根手指同时感到滑移，往往不是四个独立证据，而是同一个物体状态的四个投影。把它们当独立样本，会把后验方差压得过小，产生**虚假自信**。
- **不可逆性**：手内重构一旦越过某点就回不去；每次重构都累积位姿漂移、磨损与掉落风险。

因此第二条升级是：**接触模态条件化 + 机械独立性判据**。证据只在采集它的接触模态内有效；跨模态只能作先验。多指证据的有效样本量由敏感度矩阵的谱决定（参与率 / 有效秩），而不是手指数。手内重构本身是一个受扰动预算约束的**主动感知规划**问题。

### 0.4 合流：DexGauge = 探测即干预 + 手内重构 + 后向作用感知标定

两条灵感合流后，ToolGauge 的「假设 → 契约探测 → 摊销校准 → 验证 → 热替换」需要加三层：

1. **G-Box（抓握计量）**：把 MTC 扩展为接触契约 GTC，加入控制程序、扰动包络、可逆性等级与提交语义；
2. **κ-Box（接触模态）**：接触模式是混合、部分可观的；盲区升级为 `(s, c, χ)`，契约按模态存储，证据不跨模态复用；
3. **B-Cal（后向作用感知的闭环辨识）**：接触参数只能在闭环中辨识，而测量本身改变被辨识对象；用**对称探针对**（加压-卸压、正切-负切、顺/逆时针滚）一阶抵消后向作用，用工具变量处理不可对称的损伤型后向作用。

一句话：**ToolGauge 问「证据可不可信」；DexGauge 进一步问「这次接触测量对物体做了什么、手指的证据是不是独立、标定有没有把自己的干预误当成物体属性」。**

### 0.5 为什么这不是换皮

| 维度 | ToolGauge | DexGauge |
|---|---|---|
| 测量通道 | 外挂工具（IR / 光照 / 敲击 / 双目） | 夹爪 + 触觉 + 本体感受；工具可含接触动作 |
| 探针语义 | 观测，零副作用；PROBING 公开化 | 干预，有界扰动；提交点 + SAFE-HOLD 回退 |
| 盲区定义 | 场景格子 `(d,m,i)` 的静态未知 | 接触条件化 `(s,c,χ)`；含摩擦 / 刚度 / 滑移阈值 / 闭合裕度 |
| 证据单位 | 一条有效回执 = 一个样本 | 一个**独立接触方向** = 一个有效样本；`n_eff` 由敏感度谱决定 |
| 校准对象 | 静态契约参数的后验 | 闭环接触参数；显式建模测量后向作用 |
| 热替换 | 感知子图替换 | 感知 + 接触控制器契约；必须有 checkpoint 与无扰切换 |
| 最坏失败 | 局部修复误差扩散 | 以「已认证安全」姿态逼近掉落 / 损伤边界 |

## 1. 形式化定义（增量：定义 432–447）

**定义 432（接触模式与接触段）** 接触状态
`c ∈ C = {FREE, APPROACH, STICK, SLIP, ROLL, MULTI, SEP}`。
一次接触事件由法向力 `f_n`、切向力 `f_t`、接触点/面片质心、接触雅可比 `J_c`、相对滑移速度 `v_s`、触觉阵列图像 `T`、接触拓扑 `K`（哪些指 / 物体 / 工具参与）描述。
模式映射 `σ(f_n, f_t, v_s, K, T)` 带迟滞量化。**接触段**是模式恒定的最大时间区间，身份 `seg_id` 是证据新鲜度边界：**证据不跨段复用**，因为跨段意味着模式切换，旧证据只在旧模式内有效。模式由定义 441 的混合观测器在线估计。

**定义 433（接触条件化盲区与覆盖张量）** 盲区从 ToolGauge 的格子 `s` 升级为
`s_c = (s, c, χ)`，其中 `χ` 为接触集（指-物-工具配对与面片）。
覆盖从矩阵升级为张量 `E[s, c, χ]`。`s_c` 是盲区当且仅当
`E[s,c,χ]` 的**有效独立**回执数 `< n_min(c,χ)`，或最新回执的 `seg_id` 已失效，或模式后验置信度不足。
契约参数扩展为 `u_s = (μ, k_n, k_t, τ_slip, m_fc, δ_def)`：摩擦系数、法/切向接触刚度、滑移起始阈值、力闭合裕度、局部变形参数。

**定义 434（抓握计量工具与接触契约 GTC）** 抓握工具
`g = (Schema_g, Pre_g, Post_g, Ctrl_g, c_g, τ_g, Ĝ_g, Δ_dist, rev, commit)`：
- `Schema_g`：类型化参数与返回值；
- `Pre_g`：抓握前置（预抓握位姿、力闭合裕度、温度、关节限位、物体包络）；
- `Post_g`：接触回执，除 `(μ, σ_decl, sig, ts, seq)` 外还含接触特征向量 `(f_n, f_t, patch, J_c, v_s, T_hash)`；
- `Ctrl_g`：力 / 阻抗 / 导纳轨迹，必须含 abort 与 recovery 分支；
- `c_g, τ_g, Ĝ_g`：代价、最坏时延、模态条件信息增益；
- `Δ_dist`：最坏扰动包络；`rev ∈ {R0,R1,R2,R3}`：可逆性等级；`commit`：提交点（R3 必填）。
工具库 `T_g = {force.ramp, squeeze.hold, shear.osc, micro.slip, roll.inhand, regrasp, tactile.sweep, tap, release}`，全部预注册物理包络与失败指纹。

**定义 435（可逆性等级与扰动账本）** 扰动账本
`D = (Δpose, Δv, ΔE, ε_p, w)`，分别记位姿偏移、动量、能量、塑性应变、磨损。
提交前硬约束：`Σ_g Δ_dist(g) ≤ D_budget` 且 `P(lose_grasp | Π) ≤ δ_hold`。
R0 不改变接触状态；R1 在弹性包络内可逆；R2 状态可变但必须由恢复控制器跟踪回安全集；R3 提交后不可撤销，执行 at-most-once，且必须携带恢复策略。**任何 R3 之后的失败都记入不可逆事故账本，不得被后续校准「抹平」。**

**定义 436（探测-抓握程序与 TCV-C）** 程序
`Π_s = ((g₁,a₁),…,(g_L,a_L))`，`L ≤ L_max`，允许 DAG 依赖（后调用参数可引用前回执）。
TCV-C 在 TCV 四查（schema / 前置 / 预算 / 循环）之外增加三查：
⑤ **状态可达性**：预接触态与每步后态在恢复控制器的可达集内；
⑥ **扰动预算**：累计扰动不超 `D_budget`；
⑦ **可逆性单调**：R3 不得早于所需证据收齐或显式提交规划；
⑧ **稳定性门**：`P(slip | g, q) ≤ δ_slip` 且执行后力闭合裕度 `m_fc ≥ m_min`。
执行语义：每步闭环执行；abort 不是「停」，而是**执行已认证恢复轨迹到 SAFE-HOLD**（定义 444）。这把 ToolGauge 的「零副作用」替换为「有界、记账、可恢复」。

**定义 437（接触信息增益、稳定性门与扰动效率，推广定义 419）**
- **风险门 λ**（继承）：`λ(a,s) = σ_pred − σ_decl ≥ γ`；
- **增益注 β**（继承并模态化）：`β_g = Ĝ_c(g) − c_g ≥ γ_B`，其中 `Ĝ_c(g) = I(u_s; r_g | history, c)`；
- **稳定性门 σ**（新增）：`P(slip | g, q) ≤ δ_slip` 且 `m_fc(after g) ≥ m_min`；
- **扰动效率门 η**（新增）：`η_g = Ĝ_c(g) / (c_g + λ_D·Δ_dist(g)) ≥ γ_D`。
四门同过才执行。信息量最大的探针往往最接近滑移边界，所以**高增益必须通过机会约束**，而不是以增益为名放松安全。

**定义 438（机械独立性与触觉交叉验证）** 第 i 个接触对参数 `u` 的归一化敏感度
`s_i = ∂r_i/∂u`。定义敏感度信息矩阵 `Σ_s = Σ_i s_i s_iᵀ`，有效样本量
`n_eff = (tr Σ_s)² / tr(Σ_s²)`（参与率）。
性质：全共线 ⇒ `n_eff = 1`（无论多少指）；两两正交 ⇒ `n_eff = n`。
**独立性证书**要求：`n_eff ≥ n_min(s_c)`，且最大成对余弦 `max_{i≠j}|cos(s_i,s_j)| ≤ ρ_indep`，且共享扰动协方差低于阈值。
V 阶段以 `n_eff` 而非回执条数作为样本门槛；不满足即不得校准、不得热替换。

**定义 439（手内重构探针与覆盖规划）** 手内重构动作 `ρ`（滚动 / 换指 / 重抓）改变物体相对手与相机的位姿，暴露新表面与新接触面。
覆盖目标：`max_ρ [Σ_{surface,modality} 1(observed) − λ_d·drift(ρ) − λ_t·time(ρ)]`，
约束 `Δ_dist(ρ) ≤ D_remaining`、`P(slip | ρ) ≤ δ_reconfig`。
手内位姿漂移观测器以触觉 + 本体感受估计 `x̂_obj`；漂移超过阈值即 abort 到 SAFE-HOLD。

**定义 440（后向作用感知的闭环辨识与对称探针对）** 观测模型
`r(a) = h(x(a), u, a) + ε`，`x(a) = x₀ + B a + O(a²)`。
后向作用 `b(a) = (∂h/∂x)(∂x/∂a)`。对称探针对取 `(a, −a)`，估计
`û = [r(a) + r(−a)] / (2 G_u)`，其中 `G_u = ∂h/∂u`。
一阶后向作用与一阶执行器偏置相消，偏差 `O(||a||²)`。
若 `h` 具迟滞 / 塑性 / 磨损（对称对不可交换），则称**损伤型后向作用**，对称对不可用；改用工具变量（指令力 / 位置作为工具）或直接弃权。定义后向作用偏差审计量，超过阈值即拒绝该次辨识。

**定义 441（混合接触模式观测器与模态条件契约）** 以 IMM / 粒子滤波维护
`q(c_t | r_{1:t})` 与 `q(u_s | c_t, r_{1:t})`；模式转移带守卫（力/滑移/接触拓扑突变）。
契约按模式分裂：模态不变参数（质量、惯量等）共享；模态相关参数（μ、k_t、τ_slip）按 `c` 隔离。
**只有当前模式的契约可被热替换**；模式新颖（无校准支持）⇒ 弃权，退回 ToolGauge 或 SAFE-HOLD。

**定义 442（PG-6C 闭环）** 在 ToolGauge 6C 外增加快速接触内环：
`H（模态化假设）→ C（TCV-C 编译）→ E（1kHz 接触内环执行 + 扰动账本）→ C（B-Cal 模态条件辨识）→ V（独立接触交叉验证 + 对称对一致性 + 契约回归）→ U（checkpoint + 无扰切换 + 分模式热替换）`。
E 阶段的执行器是接触控制器，不是开环工具调用；V 阶段的独立回执来自**机械独立**的接触方向；U 阶段对 R2/R3 变更强制回滚点。

**定义 443（回滚点与无扰切换）** 热替换前保存
`checkpoint = (x̂_obj, contract_ver, controller_θ, grasp_plan)`。
参数切换在 `τ_blend` 内按平滑插值 `θ(τ) = (1−s(τ))θ_old + s(τ)θ_new`，每步检查 `m_fc ≥ m_min` 与被动性。
若切换路径离开已认证被动集或裕度跌破阈值，立即回滚到 checkpoint 并进入 SAFE-HOLD。
**接触契约热替换不是感知子图替换**：它可以直接导致掉件，必须比感知替换更保守。

**定义 444（接触安全包络与 SAFE-HOLD）** 安全集
`S_safe = {x : m_fc ≥ m_min, no_slip, no_damage, joint_limits, force_limits, energy_limits}`。
动作 `g` 可准入的必要条件：存在恢复策略 `π_rec`，使从 `g` 的任意 abort 点出发，在 `τ_safe` 内以概率 `≥ 1−δ_safe` 到达 `S_safe`。
**若 SAFE-HOLD 不可达，动作直接不可准入**——这比「停机」强：停机可能停在单指悬吊或力闭合退化位形。

**定义 445（接触模式的严格退化链）** `DexGauge ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE`。
触发降级：无触觉/力传感、模式新颖、独立性不达标、扰动预算耗尽、SAFE-HOLD 不可达、后向作用不可辨识、接触内环超时。
降级单向快速；回升须重新认证。DexGauge 是增强项，不是安全依赖项。

**定义 446（接触主张-证据绑定与证书）** 扩展定义 423 / 427：任何接触相关语言主张（如「μ≈0.4，抓握稳定」）必须引用
`(模态条件回执, 独立性证书, 扰动账本)`；数值必须逐字引自回执。缺任一即在契约序列化时剥离。主张不在任何数值路径上。

**定义 447（继承与退化特例）** 未被本轮重定义的第 1/2 轮记号沿用定义 398–431。
令灵巧度 = 0、无主动接触探针、`C = {FREE}`、扰动账本为空 ⇒ `DexGauge ≡ ToolGauge`；
再令 VLA = ∅、T₀ = {被动观测}、MP-Φ = 物理先验 GP ⇒ `ToolGauge ≡ LeanGauge`。

## 2. 关键算法骨架

```python
# IP-321 GTC：抓握计量工具契约（接触版 MTC）
@dataclass
class GraspTool:
    name: str
    schema: Callable[[dict], bool]                 # ① 参数类型/范围
    pre:    Callable[["ContactSnapshot"], bool]    # ② 抓握前置（闭合裕度/位姿/温度）
    ctrl:   Callable[["ContactSnapshot", dict], "Traj"]  # ③ 力/阻抗轨迹（含 abort/recover）
    post:   Callable[[Raw], "ContactReceipt|None"] # ④ 回执 + 接触特征
    cost: float; tau: float
    info_gain: Callable[["Hyp", "ModePosterior"], float]
    dist: DisturbanceSpec                          # 最坏 Δpose/Δv/ΔE/塑性/磨损
    rev: RevClass                                  # R0/R1/R2/R3
    commit: Optional[CommitPoint]                  # R3 必填

# IP-322 TCV-C：TCV 四查 + 状态可达 / 扰动预算 / 可逆单调 / 稳定性
class TCVC:
    def verify(self, prog, budget, q_mode, ctx):
        seen = set(); cum = 0.0
        for g, args in prog:
            if not g.schema(args):                    return False, "schema"
            if (g.name, canon(args)) in seen:         return False, "loop"
            if not g.pre(ctx.snapshot()):             return False, "pre"
            budget -= g.cost
            if budget < 0:                            return False, "budget"
            cum += g.dist.worst
            if cum > ctx.D_budget:                    return False, "disturbance"
            if g.rev == R3 and not planned_commit(g): return False, "irreversible"
            if q_mode.slip_prob(g) > ctx.delta_slip:  return False, "slip_risk"
            if q_mode.margin_after(g) < ctx.m_min:    return False, "margin"
            if not ctx.reachable_safe_hold(g):        return False, "no_safe_hold"
        return True, "ok"

    def execute(self, prog, env, ledger):
        receipts = []
        for g, args in prog:
            traj = g.ctrl(env.snapshot(), args)       # 含 abort / recovery 分支
            try:
                r = env.run_closed_loop(traj, hz=1000)  # 1kHz 接触内环
            except AbortToSafe:
                ledger.record_abort(); return receipts
            if not g.post(r):                          fail += 1; continue
            ledger.record(g.dist.realized(r))          # 实际扰动入账
            receipts.append(r)
        return receipts
```

## 3. 推导

**引理 51（扰动账本的可加界与 SAFE-HOLD 回退）** 设探针程序提交前有 L 步，每步受控扰动满足 `||Δx_i|| ≤ Δ_i`，状态转移 1-Lipschitz；提交前任一 abort 由恢复控制器以概率 `≥ 1−δ_r` 到达已认证 SAFE-HOLD。则
`||x_L − x_0|| ≤ Σ_{i=1}^L Δ_i + L·ε_drift`，且 `P(abort 后不在 SAFE-HOLD) ≤ L·δ_r`。
证明：三角不等式 + 并集界。要点：把 ToolGauge 的「零副作用」替换为**可加扰动预算**，而非取消安全约束。
**系 51.1**：力闭合裕度满足 `m_fc(x_L) ≥ m_fc(x_0) − L_m Σ Δ_i`；当右端低于 `m_min` 时，程序在 TCV-C 阶段即被拒绝。

**引理 52（机械耦合下的有效样本量）** 观测 `r_i = s_iᵀu + ε_i`，令 `Σ_s = Σ_i s_i s_iᵀ`，
`n_eff = (tr Σ_s)²/tr(Σ_s²)`。则 `1 ≤ n_eff ≤ rank(Σ_s) ≤ n`；全共线时 `n_eff=1`，两两正交时 `n_eff=n`。
若按 n 个独立样本更新后验，则至少存在一个方向的后验方差被低估 `n/n_eff` 倍。
证明：参与率是谱的 Schur 凹函数；在最小特征方向 `v` 上信息量 `vᵀΣ_s v` 只由独立方向数决定，与回执条数无关。
**系 52.1**：四指同时滑移的 n 条回执可能只有 `n_eff≈1`；V 阶段必须以 `n_eff` 作为门槛，否则「多指交叉验证」是自我欺骗。

**引理 53（对称探针对的一阶后向作用消除）** 设 `r(a)=h(x(a),u,a)+ε`，`x(a)=x_0+Ba+O(a²)`，h 一阶可微。则
`[r(a)+r(−a)]/2 = h(x_0,u,0) + G_u u + O(a²)`，
一阶后向作用与一阶执行器偏置相消；`û` 偏差 `O(a²)`。
若 h 具迟滞 / 塑性，`r(a)+r(−a)` 不可交换，残差由滞回环面积界定；此时对称对不可用，改用工具变量或弃权。
证明：Taylor 展开，奇次项相消；滞回情形由 Preisach 分解给出残差界。
**系 53.1**：耗散型参数（阻尼、滑移阈值）只能从反对称组合或 IV 辨识，且必须显式扣除执行器偏置。

**引理 54（接触模态条件共形覆盖）** 模态 c 内可交换 ⇒ `P(u* ∈ C_c) ≥ 1−α`；校准-部署模态 TV 距离 `η_c` ⇒ `≥ 1−α−2η_c`；新颖模式无校准支持 ⇒ 覆盖无定义，必须弃权。
证明：标准共形 + TV 传输不等式；全期望分解 `Σ_c π_c·coverage_c + π_novel·(无定义)`。

**引理 55（无扰切换的稳定性保持）** 若旧 / 新接触阻抗控制器均属于被动参数集 P（正阻尼、能量耗散），切换在 `τ_blend` 内按凸插值保持于 P，且 `m_fc ≥ m_min`，则闭环 Lyapunov 函数不增，切换稳定。若插值路径离开 P 或裕度跌破阈值，必须在下一步前回滚。
证明：被动系统凸组合仍被动；能量函数 `V = ½ eᵀMe + ½ eᵀKe` 沿轨迹单调不增。
**系 55.1**：接触契约若不属于被动集，**不得无扰切换**，只能停机重认证——这是与感知子图热替换的本质区别。

**引理 56（PG-6C 的嵌套实时性）** 设 1kHz 接触内环 WCET ≤ 200μs，50Hz 感知环新增模式查表与扰动账本 O(1) < 0.3ms，计量 6C 全异步。则 50Hz 硬实时（引理 45）保持；单盲区接触修复时延 `≤ L_max·max τ_g + τ_recover + τ_cal ≤ τ_repair`；提交点后不可抢占恢复段 `≤ τ_safe`。
证明：固定优先级调度 + WCET 分析；内环最高优先级，计量任务在空闲预算内运行。

## 2. 形式化定义（要点）

**定义 432（接触模式与接触段）** 接触状态由 `(f_n,f_t,patch,J_c,v_s,T,K)` 描述，模式映射带迟滞；模式恒定的最大区间为接触段，`seg_id` 是证据新鲜度边界。证据不跨段复用。
**定义 433（接触条件化盲区）** 盲区升级为 `s_c=(s,c,χ)`；覆盖为张量 `E[s,c,χ]`；盲区判据由有效独立回执数、段有效性、模式置信度共同决定；契约参数扩展到摩擦/接触刚度/滑移阈值/闭合裕度。
**定义 434（GTC 抓握工具契约）** 工具 = 类型 schema + 抓握前置 + 接触回执 + 力/阻抗控制程序（含 abort/recovery）+ 代价 + 时延 + 模态条件信息增益 + 扰动包络 + 可逆性等级 + 提交点。
**定义 435（可逆性等级与扰动账本）** 提交前 `ΣΔ_dist ≤ D_budget` 且 `P(lose_grasp) ≤ δ_hold`；R0 只读、R1 弹性可逆、R2 可跟踪恢复、R3 不可撤销（at-most-once + 恢复策略）；不可逆失败记入事故账本，不被后续校准抹平。
**定义 436（TCV-C）** 四查之外增加：⑤ 状态可达性；⑥ 扰动预算；⑦ 可逆性单调（R3 不得早于证据收齐/提交规划）；⑧ 稳定性门 `P(slip)≤δ_slip ∧ m_fc≥m_min`。执行时 abort 必须恢复到已认证 SAFE-HOLD，而非简单停机。
**定义 437（四门）** 风险门 λ（安全）、增益注 β（模态条件信息增益 − 代价）、稳定性门 σ（滑移机会约束 + 闭合裕度）、扰动效率门 η（单位扰动信息增益）。四门同过才执行；高增益不得以放松安全为代价。
**定义 438（机械独立性与触觉交叉验证）** 敏感度矩阵 `Σ_s`，`n_eff` 为参与率；要求 `n_eff≥n_min`、最大成对余弦 `≤ρ_indep`、共享扰动协方差低于阈值；以 `n_eff` 而非回执条数作为 V 阶段门槛。
**定义 439（手内重构探针）** 滚动/换指/重抓改变物体相对位姿以暴露新表面；目标为覆盖增益减漂移与时间成本，约束扰动预算与滑移概率；漂移观测器超阈值即 abort。
**定义 440（后向作用感知辨识）** 观测 `r(a)=h(x(a),u,a)+ε`，`x(a)=x₀+Ba+O(a²)`；对称对估计 `û=[r(a)+r(−a)]/(2G_u)` 抵消一阶后向作用与执行器偏置，偏差 `O(a²)`；迟滞/塑性/磨损型后向作用不可对称，改用 IV 或弃权。
**定义 441（混合模态观测器）** IMM/粒子滤波维护 `q(c_t|r_{1:t})` 与 `q(u|c_t,r)`；模式转移带守卫；模态不变参数共享，模态相关参数隔离；只有当前模式契约可热替换；模式新颖即弃权。
**定义 442（PG-6C）** `H→C→E→C→V→U`：H 模态化假设；C 用 TCV-C 编译；E 为 1kHz 接触内环 + 扰动账本；C 为 B-Cal 模态条件辨识；V 为独立接触交叉验证 + 对称对一致性 + 契约回归；U 为 checkpoint + 无扰切换 + 分模式热替换。
**定义 443（回滚点与无扰切换）** 切换前保存 checkpoint；参数在 `τ_blend` 内平滑凸插值，逐步检查 `m_fc≥m_min` 与被动性；离开被动集或裕度跌破即回滚并 SAFE-HOLD。接触契约热替换不得照搬感知子图热替换。
**定义 444（接触安全包络与 SAFE-HOLD）** `S_safe={x:m_fc≥m_min,no_slip,no_damage,joint_limits,force_limits,energy_limits}`；动作准入要求存在恢复策略在 `τ_safe` 内以 `≥1−δ_safe` 到达 `S_safe`；不可达即不可准入。
**定义 445（严格退化链）** `DexGauge⇒ToolGauge⇒LeanGauge⇒MODGAUGE`；触发条件见上；单向快速，回升须再认证。
**定义 446（接触主张绑定）** 接触相关语言主张必须引用 `(模态条件回执, 独立性证书, 扰动账本)`；数值逐字引自回执；缺任一即剥离；主张不在数值路径。
**定义 447（继承与退化特例）** 沿用定义 398–431；灵巧度=0、无接触探针、`C={FREE}`、空扰动账本 ⇒ `DexGauge≡ToolGauge`；再退化 ⇒ `ToolGauge≡LeanGauge`。

```python
# IP-321 GTC：抓握计量工具
@dataclass
class GraspTool:
    name: str
    schema: Callable[[dict], bool]
    pre:    Callable[["ContactSnapshot"], bool]
    ctrl:   Callable[["ContactSnapshot", dict], "Traj"]   # 力/阻抗轨迹，含 abort/recovery
    post:   Callable[[Raw], "ContactReceipt|None"]
    cost: float; tau: float
    info_gain: Callable[["Hyp", "ModePosterior"], float]
    dist: DisturbanceSpec
    rev: RevClass                 # R0/R1/R2/R3
    commit: Optional[CommitPoint] # R3 必填

# IP-322 TCV-C：四查 + 接触四查
class TCVC:
    def verify(self, prog, budget, q_mode, ctx):
        seen=set(); cum=0.0
        for g,args in prog:
            if not g.schema(args):                    return False,"schema"
            if (g.name,canon(args)) in seen:          return False,"loop"
            if not g.pre(ctx.snapshot()):             return False,"pre"
            budget -= g.cost
            if budget < 0:                            return False,"budget"
            cum += g.dist.worst
            if cum > ctx.D_budget:                    return False,"disturbance"
            if g.rev == R3 and not planned_commit(g): return False,"irreversible"
            if q_mode.slip_prob(g) > ctx.delta_slip:  return False,"slip_risk"
            if q_mode.margin_after(g) < ctx.m_min:    return False,"margin"
            if not ctx.reachable_safe_hold(g):        return False,"no_safe_hold"
        return True,"ok"
    def execute(self, prog, env, ledger):
        receipts=[]
        for g,args in prog:
            traj = g.ctrl(env.snapshot(), args)
            try:
                r = env.run_closed_loop(traj, hz=1000)     # 1kHz 接触内环
            except AbortToSafe:
                ledger.record_abort(); return receipts       # 已恢复至 SAFE-HOLD
            if not g.post(r): continue
            ledger.record(g.dist.realized(r))                # 实际扰动入账
            receipts.append(r)
        return receipts

# IP-323 κ-Box：混合接触模态观测器
class ModeObserver:
    def update(self, receipt, dt):
        self.post = imm_predict_update(self.post, receipt, dt, self.guards)
        return self.post
    def contract_by_mode(self, u):
        return {c: q(u|c) for c in self.post.support if self.post.conf(c) > eps}

# IP-324 H-Box：手内重构 + 机械独立性
class HandBox:
    def plan(self, s_c, remaining):
        return argmax(self.candidates(s_c),
                      key=lambda p: self.coverage_gain(p)/(p.dist.worst+1e-9))
    def independence(self, receipts):
        S = sensitivity_matrix(receipts)
        Sig = S.T @ S
        n_eff = (trace(Sig)**2)/trace(Sig@Sig)   # 共线=1，正交=n
        return n_eff, IndependenceCert(S, n_eff, max_cos(S))

# IP-325 B-Cal：后向作用感知辨识
class BackActionCal:
    def identify(self, pairs, q_mode):
        num=[rp.mu+rm.mu for rp,rm in pairs]     # 对称对：一阶后向作用相消
        u_hat=solve_ls(num,[2*gain(p) for p in pairs])
        return u_hat, audit_backaction(pairs)    # 滞后/损伤型 ⇒ significant
    def identify_iv(self, receipts, q_mode):
        return iv_estimate(receipts, instrument=cmd_force)

# IP-326 PG-6C：接触条件化 6C
def dexgauge_pg6c(M, s_c):
    H    = M.kbox.hypothesize(s_c)                         # H
    prog = M.tbox.compile(H, M.grasp_tools)                # C
    if not M.tcvc.verify(prog, M.budget_left(s_c), M.mode_post, M.ctx)[0]:
        return M.toolgauge_fallback(s_c)                   # 退化
    receipts = M.tcvc.execute(prog, M.contact_env, M.ledger)   # E
    if not M.mode_post.confident(): return safe_hold_or_degrade(s_c,"mode_ambiguous")
    if M.mode_post.novel():        return M.toolgauge_fallback(s_c)
    u_hat, bias = M.bcal.identify(receipts.pairs, M.mode_post) # C
    if bias.significant(): u_hat = M.bcal.identify_iv(receipts, M.mode_post)
    n_eff, indep = M.hbox.independence(receipts)               # V
    if n_eff < n_min(s_c):
        return safe_hold_or_degrade(s_c,"insufficient_independent_evidence")
    if not M.verify_cross(receipts, u_hat, indep):
        return safe_hold_or_degrade(s_c,"cross_failed")
    ckpt = checkpoint(M)                                        # U
    new_contract = M.bcal.update(M.dpe, u_hat, s_c)
    if not bumpless_transfer(M, new_contract, ckpt):
        rollback(M, ckpt); return safe_hold_or_degrade(s_c,"transfer_unstable")
    M.mreg.hot_replace_mode(M.dpe, new_contract, mode=s_c.c)
    bind_contact_claims(new_contract, receipts, indep, M.ledger)
    return True

# 主闭环：50Hz 感知路径不动，接触计量异步
def DexGauge_round(M, obs, audio, tac, depth, det):
    for s_c in M.kbox.detect_contact_blind_spot(M.dbox, M.mode_post):
        if s_c not in M.inflight:

    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 51（扰动账本可加界与 SAFE-HOLD 回退）** 提交前 L 步、每步 `||Δx_i||≤Δ_i`、转移 1-Lipschitz、abort 恢复成功率 `≥1−δ_r`，则 `||x_L−x_0|| ≤ ΣΔ_i + Lε_drift`，且 `P(abort 后不在 SAFE-HOLD) ≤ Lδ_r`。系：`m_fc(x_L) ≥ m_fc(x_0) − L_mΣΔ_i`，低于 `m_min` 时 TCV-C 拒绝。
**引理 52（机械耦合有效样本量）** `r_i=s_iᵀu+ε_i`，`Σ_s=Σs_i s_iᵀ`，`n_eff=(trΣ_s)²/tr(Σ_s²)`；`1≤n_eff≤rank(Σ_s)≤n`；全共线 `n_eff=1`，正交 `n_eff=n`；按 n 个独立样本更新会在某方向低估方差 `n/n_eff` 倍。系：四指同时滑移可能只有 `n_eff≈1`。
**引理 53（对称对一阶后向作用消除）** `r(a)=h(x(a),u,a)+ε`、`x(a)=x_0+Ba+O(a²)` ⇒ `[r(a)+r(−a)]/2 = h(x_0,u,0)+G_u u+O(a²)`；一阶后向作用与执行器偏置相消，偏差 `O(a²)`；迟滞/塑性时残差由滞回环界定，改用 IV 或弃权。系：耗散型参数只能用反对称组合或 IV。
**引理 54（模态条件共形覆盖）** 模态内可交换 ⇒ `P(u*∈C_c)≥1−α`；模态 TV `η_c` ⇒ `≥1−α−2η_c`；新颖模式无定义 ⇒ 弃权。
**引理 55（无扰切换稳定性）** 旧/新接触阻抗控制器均属被动集 P，且切换在 `τ_blend` 内按凸插值保持于 P、`m_fc≥m_min`，则 Lyapunov 函数不增；离开 P 或裕度跌破即回滚。系：不属被动集的接触契约不得无扰切换，只能停机重认证。
**引理 56（PG-6C 嵌套实时性）** 1kHz 内环 WCET ≤ 200μs；50Hz 新增 O(1) < 0.3ms；计量全异步 ⇒ 50Hz 硬实时保持，修复时延 `≤τ_repair`，恢复段 `≤τ_safe`。

## 8. 本轮最大风险（一句话）

**一句话**：DexGauge 的全部安全论证最终压在一个**循环依赖**上——它用「预测滑移概率 ≤ δ」批准最接近滑移边界的探针，而滑移概率模型与 SAFE-HOLD 可达性正是它要从这些探针中估计的量；模型一旦偏乐观，系统就会以「已认证安全」的姿态反复逼近掉落边界，且扰动账本与语言证书会让这种冒险显得比实际更有依据。
