# 第 58 轮（承接第 57 轮「少样本×多模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「长期记忆」×「场景理解」）

> 第 57 轮的最终风险不是"某个探针错了"，而是"语料里没有的世界被自信地补上了"——共形保底能兜住统计意义上的分布外，却兜不住认识论意义上的盲区：机器人只会把"已经想到要探的东西"写进语料，从未被想到的区域连负样本都不是。本轮两个灵感正好从两侧刺入这个盲区。**长期记忆**让经验跨会话累积，使一次目击可以在未来继续起作用；**场景理解**让经验从"某坐标的历史"提升为"某类场景的结构"，从而可迁移、可补全、可预测。但它们也把风险从"坏先验普遍"升级为"坏世界模型自洽"：场景理解把"未知"折叠进"已知的一类"，长期记忆把这个折叠固化成跨会话默认事实，探针又被同一套场景先验导向"可能危险的地方"——错误于是不只没被采样，连"应该问什么问题"都被改写。本轮的核心设计因此不是"记得更多、理解更深"，而是给记忆与理解各自上锁：**记忆只是带来源、场景签名与再验证义务的假设；场景理解对记忆只有失效权、没有确认权；遗忘对正例可宽、对教训必须吝啬；一切记忆写入先过隔离区。**核心命题由第 57 轮"少样本可校准、跨模态可对账、个性化有界的证据说可信"进一步升级为 **"来源可分型、场景可失效、遗忘非对称、写入有隔离的证据说可信"**。

核心矛盾：

- **H29（记忆长寿 vs 证据时效）**：证据门默认"记得的探针仍是当前场景的观测"，但记忆越长，这个"场景未变"的隐含前提越可能失效。场景理解本应验证它，可场景理解自身也会错——记忆把一次历史观测变成当前证据时，实际上偷偷引入了一个未计价的假设。
- **H30（场景先验 vs 未知）**：场景模式既决定"这是什么"，也决定"哪里值得探"。错的模式不只是给出错标签，而是生成一个自洽的世界：它让机器人只去验证自己相信的危险，从而永远不采样反例。未知不是"还没标定"，而是"连问题都没被提出"。
- **H31（遗忘 vs 记忆完整性）**：从不遗忘会积累陈旧与毒化记忆；过度遗忘会丢掉曾经救命的伤疤。更麻烦的是，非对称持久化本身是双向攻击面：伪造"安全记忆"可诱导冒进，伪造"事故墓碑"可诱导过度保守与拒绝服务。

## 0. 直觉与动机

**灵感 1（长期记忆 → 来源分型，而不是更大的地图）**
直觉：人的记忆天然分来源——"我亲眼见过"、"我根据格局推断"、"别人告诉我"、"我从别处读来"。只有第一种能当目击证词；后三种能提示你去哪里看，却不能替你作证。第 57 轮的地图把所有来源压成同一个 `b_r`：场景补全出来的"厨房水槽边大概是干的"和亲手探过的"这里是干的"享有同等证据权。本轮引入来源偏序 **W ≻ {I,R,X}**（目击/场景推断/人类告知/他机或云端继承）：**证据门本质上是目击门，不是记忆门**；I/R/X 只能进入探针候选集与路线先验。记忆可以很旧、很大，但"能不能当证据"只由来源与场景有效性决定，不由置信度决定。

**灵感 2（场景理解 → 只做记忆的失效器与假设发生器）**
直觉：场景理解对记忆最有价值的输出，不是"这是什么房间"，而是"这已经不是上次那个场景了"——家具移动、地面变湿、季节结冰、光照改变。记忆的每一条都应带一个**低层场景签名**（几何/外观，而非语义标签），复用时先比对签名；签名变了，记忆就从 W 降为 I，必须重新目击。同时，场景图与模式库负责生成"去哪里看"的假设：排水口附近可能有水、冬季背阴处可能结冰、施工围挡旁可能不稳。但这些只是 I，永远不能直接支撑承诺。关键的非对称授权是：**场景理解可以让记忆更快失效，不能让记忆更可信。**

**灵感 3（长期记忆 × 场景理解 → 认知闭环及其解药）**
直觉：最危险的循环是——场景模式 S 把未到访区域补全为"干燥厨房地面"，写成 I；下一次同一套 S 又认出"这还是那个厨房"，于是用同一个签名"验证"了这条 I；探针又被 S 导向它认为可能的危险处，反例永远不被采样。错误在跨会话上越来越自洽，这不是"一条坏记忆"，而是**认识论闭环**。解药有四味：来源分型（I 永不作证）、**签名与语义标签解耦**（不能用"厨房"这个标签去验证"厨房里的推断"）、**强制 ε-探索**（一部分探针预算逆着场景先验，在未知与"低可能"区域均匀采样）、以及把"未知"保留为一等记忆状态——未知既不等于安全，也不等于危险。

**灵感 4（记忆经济学 → 非对称遗忘与墓碑）**
直觉：长期记忆必须回答"忘什么"。正例（"这里可以走"）会随场景变化而失真，应当衰减、软遗忘；负例（"这里曾发生过一次假承诺 / 这条先验被证伪 / 这个视觉线索骗过人"）是伤疤，必须在很长的半衰期内存留，并按**场景类**而非精确坐标继承给其他机器人。可以忘记地图，不可以忘记伤疤。但墓碑也必须防伪：只有目击到的失败才能成为强墓碑，报告来的失败只能提高谨慎、不能改变任何阈值方向；墓碑只能让系统更保守，永远不能让它更敢赌。

**灵感 5（合流 → 记忆不是第六类证据，而是所有证据的保存形式）**
直觉：很容易顺手新增一个 "EV-memory" 证据类，但那是概念错误。记忆不是一种新证据，它是旧证据的**缓存**，缓存必须带来源、保质期和再验证义务。因此第 57 轮的五类证据不扩类，而是统一挂上 ⟨π, valid⟩ 标签：`EV-probe*` 只在 π=W 且场景有效时成立；`EV-visit` 新增"目击刷新"用途；`EV-margin`/`EV-xmodal`/`EV-human` 继承并同样受来源约束。探-诺-演升级为 **PCE++**：检索 → 验证 → 刷新或补全 → 承诺，刷新本身成为有独立 VOI 的动作（把 stale/I 变回 W 的价值）。三个新机制仍只经"信念更准（含降级为未知）"或"动作更保守"两个通道生效。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（分型长期记忆 TLM）** 记忆记录 `m=(k, s_m, π_m, β_m, E_m, t_m^w, t_m^c, h_m)`：记忆键 k（场景角色/区域类，而非仅坐标）、写入时场景签名 s_m、来源 π_m∈{W,I,R,X}、信念 β_m、证据引用 E_m、最近目击时间 t_m^w、创建时间 t_m^c、墓碑引用 h_m。来源偏序 W ≻ {I,R,X}；只有本机传感目击使 `wit(m)=1`。升级 `Promote(m,W)` 仅当存在签名一致的目击事件；降级由场景失效或事后证伪触发（保留记录、失去证据权）。**证据准入**：`Evidence(m) ⇔ wit(m)=1 ∧ Valid(m) ∧ ¬Contradicted(m)`。记忆是场景条件的：同一 k 可按不同场景签名保留多个模态版本，检索时按当前场景相似度加权，**禁止把不相容的季节/工况版本先边缘化再平均**。巩固算子 C 满足**来源单调性** `π(C(m)) ⊑ π(m)`：反复回忆、摘要、跨机器人同步都不得把 I 洗成 W（禁止来源洗白）。

**定义 140（场景条件化再验证 SCR）** 场景状态 `s_t=(G_t, ξ_t, U_t)`：场景图 G_t、低层几何/外观签名 ξ_t（**不含语义标签**，避免自证）、场景不确定性 U_t。变化分 `Δ(m,s_t)=d_ξ(ξ_m,ξ_t)+λ_g·GED(G_m,G_t)+λ_e·1[change_event]`。有效谓词 `Valid(m) ⇔ π_m=W ∧ Δ(m,s_t)≤θ_scene ∧ t_now−t_m^w≤τ_r(cls(k))`。失效记录进入 stale 集，用作证据前必须**目击刷新** `Refresh(m)`：以 ≤k_ref 次非破坏探针/到访重新取得目击；刷新失败则永久降为 I 并禁止支撑承诺。开放集场景拒识：若 `U_t>θ_U`，场景理解必须输出"未知场景"而非最近邻标签，并触发探索预算。

**定义 141（场景模式补全假设 SCH）** 模式库 𝒮，补全算子 `Comp(G_t,𝒮)→ℋ(s_t)`；每个 `h∈ℋ` 带 π=I、支撑度 σ_h、覆盖义务 O_h（必须目击的最小证据量，或显式开放世界风险上界）。规则：(C1) ℋ 永不进入证据门，只进入探针候选集与路线先验；(C2) 若承诺区域 r 的唯一依据是补全，必须目击 r 或在开放世界假设下声明风险上界，二者皆无则拒绝承诺；(C3) 未补全且未到访的区域记为 U（unknown），**U≠safe**；每 N 个检查点强制 ε-探索预算在 U 与模式"低可能"区域采样，切断"只验所信"的认知闭环。

**定义 142（非对称遗忘与墓碑 AFT）** 记忆重要性 `α(m)∈{claim,lesson}`。claim 的保留权 `w(m)` 随场景失效次数、矛盾次数、未再目击时长指数衰减，低于 θ_forget 时软遗忘（摘要移入冷存、保留审计指针与可回滚窗口）。lesson（墓碑）`t=(场景类,失败原因,反事实,来源,签名类)`，半衰期 ≥τ_tomb，跨机器人继承，且满足**谨慎单调性**：墓碑只能提高谨慎（收紧阈值/增加佐证/降低步态），永远不能放宽任何安全参数。遗忘算子只能作用于 claim；墓碑与审计不可被删除；每轮披露遗忘清单。

**定义 143（记忆写入隔离 MWQ）** 写入事件 `w=(m,src,π,depth)` 先进入隔离区 Q_w。晋升为证据承载记录需同时满足：本机目击证明、场景签名完整、与既有 W 及墓碑一致。R/X 的多跳来源按 `ρ(m)=∏ρ_i` 衰减，`depth>d_max` 或 ρ<ρ_mem 时自动降为 I。云端/他机记忆先影子运行，仅在"校准不劣化 ∧ 覆盖不下降 ∧ 与本地 W 冲突率不上升"后采纳。毒化检测是双向的：伪造安全记忆（假正例）与伪造事故记忆（假墓碑）都须被来源分型、深度衰减与一致性检查阻断。

**定义 144（记忆感知探-诺-演 PCE++）** 每检查点：①检索 `Retrieve(r,s_t)` 取场景条件候选；②验证 `Validate`：来源/签名/时效/墓碑；③刷新或补全：stale 与 I 进入刷新/补全队列；④承诺或探询：证据门要求每条被引用记忆 `Evidence(m)`，记忆感知 VOI 为 `VOI_mem=E[风险避免]+λ_w·E[来源增益]+λ_u·E[未知缩减]−cost`，其中来源增益=期望把 I 刷成 W 的条数、未知缩减=期望 U 测度下降；⑤协商/停。终止：每检查点 ≤k_probes+k_cons+k_ref；刷新失败即降级且不得以该记忆支撑承诺。

## 2. 关键算法伪代码

```python
def retrieve_and_validate(tlm, r, scene):
    valid, stale, blocked = [], [], []
    for m in tlm.query(key=key_of(r), scene=scene):   # 场景条件检索，不做跨版本平均
        if m.provenance == 'W' and scene_valid(m, scene) and not tombstone_conflict(m):
            valid.append(m)                           # 可作证据
        elif m.provenance in ('I', 'R', 'X') or not scene_valid(m, scene):
            stale.append(m)                           # 只能作先验/刷新候选
        if tombstone_conflict(m):
            blocked.append(m)                         # 墓碑冲突：额外谨慎
    return valid, stale, blocked

def witness_refresh(m, r, scene, budget):
    for p in cheapest_witnesses(r, budget.k_ref):     # 有界刷新
        obs = execute_probe(p, cap=F_abs)
        if scene_changed(obs, m):                     # 场景已变：记忆失效
            demote(m, to='I'); return 'scene_changed'
        budget.spend(p)
        if consistent(obs, m):
            promote(m, to='W', witness=obs); return 'refreshed'
    demote(m, to='I'); return 'unrefreshed'

def scene_complete(G, S, scene):
    H = schema_complete(G, S, scene)                  # 全部 π=I，绝不入证据门
    for h in H:
        h.provenance = 'I'
        h.obligation = coverage_obligation(h, G)
    U = unknown_cells(scene) - {h.key for h in H}
    return H, U

def asymmetric_forget(tlm, audit):
    for m in tlm.claims():                            # 只碰 claim
        m.w = decay(m.w, scene_invalidations(m), contradictions(m), age(m))
        if m.w < theta_forget:
            soft_forget(m, keep_audit=True)           # 可回滚的软遗忘
    for t in tlm.tombstones():                        # 墓碑：只增不减
        t.half_life = max(t.half_life, tau_tomb)
        assert t.monotone_caution                     # 只能更谨慎
    audit.log(tlm.forgotten_this_round)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| TLM | O(log\|𝒦\|+k_ret) 检索 | O(\|𝒦\|·d_β+\|E\|) | 来源单调、I 永不作证 |
| SCR | O(d_ξ+\|G\|) / 检查点；刷新 O(k_ref) | O(\|V\|·d_ξ) | 签名与语义解耦、场景变化漏检 ≤δ_scene |
| SCH | O(\|G\|·\|𝒮\|) | O(\|ℋ\|) | 补全只作先验、未知≠安全 |
| AFT | O(\|claims\|) / 轮 | O(\|claims\|+\|tomb\|) | 只忘 claim、墓碑单调谨慎 |
| MWQ | O(\|writes\|·\|W\|) 一致性 | O(\|Q_w\|) | 毒化写入不可晋升、来源深度有界 |
| PCE++ | O(\|CP\|·(k_p+k_c+k_r)·(C_VOI+d_φ)) | O(\|V\|+\|σ\|+\|𝒦\|) | 每检查点刷新有界、四态完备 |

**正确性定理（Memory-Sound Scene-Conditioned, MSSC）** 在 A33–A40 上增加：**(A41)** 来源诚实：所有承担证据作用的记忆均为 W 且有本机目击证明，巩固不提升来源等级；**(A42)** 场景有效性：场景变化检测漏检 ≤δ_scene，刷新在 k_ref 内终止；**(A43)** 非对称遗忘：遗忘只作用于 claim，墓碑谨慎单调且不可删；**(A44)** 写入隔离：未过隔离区/无目击的写入不能晋升为证据，毒化双向阻断；**(A45)** ε-探索：每个 N 检查点至少将 ε 比例探针预算分配给 U 与模式低可能区。则：

1. **记忆证据健全性**：任何由记忆支撑的承诺都可归约为"在场景变化分≤θ_scene 下的一次本机目击"，故 `P(fail) ≤ δ_f + ε_meta(k) + δ_scene + δ_probe + ε_h(w_max) + δ_poison`；A44 下 δ_poison=0。
2. **盲区不闭锁**：补全 I 不能作证（A41/SCH），因此未到访区域的承诺只能靠目击或显式开放世界风险；A45 保证 U 的未采样测度以 ≥ε 的节奏下降，"连问题都没想到"的残差被压到 `(1−ε)^{⌊T/N⌋}` 量级。
3. **遗忘安全单调**：遗忘 claim 不会提高失败率（claim 无目击即非证据）；遗忘墓碑被禁止，故"旧伤复发"不因遗忘而上升；墓碑只增谨慎，代价是效率而非安全。
4. **终止性**：每检查点至多 k_probes+k_cons+k_ref 次物理动作，刷新失败即降级并退出承诺分支。

**部署界**：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_scene + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])
             − P(场景理解自信地错 ∧ ε-探索未覆盖)
             − P(记忆写入毒化被晋升) − P(墓碑被抑制)
             − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

关键：**来源分型把"记忆"从证据降格为证据的缓存**；**场景理解只拿失效权、不拿确认权**，签名层与语义层解耦以防自证；**遗忘对正例宽、对教训严**，使长期记忆的积累在安全方向上单调；**ε-探索**是对"坏世界模型自洽"唯一有效的结构性解药。

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |

**正确性定理（Memory-Sound Scene-Conditioned, MSSC）**
假设 A33–A40 成立；新增 **(A41)** 来源诚实与巩固单调：承担证据作用的记忆必为 W 且有本机目击证明，`π(C(m))⊑π(m)`；**(A42)** 场景有效性：变化检测漏检 ≤δ_scene，刷新在 k_ref 内终止；**(A43)** 非对称遗忘：遗忘只作用于 claim，墓碑不可删且谨慎单调；**(A44)** 写入隔离：未过隔离区或无目击的写入不能晋升，假安全记忆与假墓碑双向阻断；**(A45)** ε-探索：每 N 检查点将 ε 比例探针预算分配给未知与模式低可能区。则：

1. **记忆证据健全性**：由 A41/A42，任何记忆支撑的承诺可归约为"场景变化分≤θ_scene 下的一次本机目击"，故
   `P(fail) ≤ δ_f + ε_meta(k) + δ_scene + δ_probe + ε_h(w_max) + δ_poison`，A44 下 δ_poison=0。
2. **盲区不闭锁**：补全 I 不能作证（定义 141 C1），未到访区域的承诺只能靠目击或显式开放世界风险；A45 使未采样测度以 `(1−ε)^{⌊T/N⌋}` 衰减，"连问题都没想到"的残差被显式定价而非被默认安全。
3. **遗忘安全单调**：遗忘 claim 不提高失败率（无目击即非证据）；墓碑不可遗忘，故旧事故复发不因遗忘上升；墓碑只增谨慎，其代价是效率而非安全。
4. **终止性**：每检查点至多 k_probes+k_cons+k_ref 次物理动作，刷新失败即降级并退出承诺分支。

**部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_scene + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])
             − P(场景理解自信地错 ∧ ε-探索未覆盖)
             − P(记忆写入毒化被晋升) − P(墓碑被抑制)
             − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

关键：**来源分型把记忆从"证据"降格为"证据的缓存"**；**场景理解只拿失效权、不拿确认权**，低层签名与语义标签解耦以防自证；**遗忘对正例宽、对教训严**，让长期记忆在安全方向上单调；**ε-探索**是对"坏世界模型自洽"唯一有效的结构性解药。

其中新增记忆字段：`π_m/s_m` 来源与场景签名；`valid(m)` 场景有效性；`tombstone` 墓碑引用；`unknown_set` 一等未知集；`refresh_log` 目击刷新记录；`write_quarantine_log` 写入隔离审计；`scene_sig` 低层场景签名。

云边协议 CEB++ → **CEB^M**：云端/他机记忆同步必须先进入边端写入隔离区并以影子模式运行；只有校准不劣化、覆盖不下降、与本地 W 冲突率不上升时才可采纳。来源深度超过 d_max 或链式可靠性低于 ρ_mem 的记忆自动降为 I。**墓碑的同步优先级高于正例记忆**，且任何云端正例不得覆盖本地墓碑；边端回传场景变化事件、证伪事件与遗忘清单，作为云端语料补盲与风险再定价的依据。第 57 轮"一切判定器（含元模型）走隔离"在本轮推广为"**一切记忆写入走隔离**"。

## 6. 本轮最大风险

**一句话**：本轮最大的风险是"场景理解成为长期记忆的立法者"——一旦场景分类器系统性出错，它会用同一套错误签名同时完成写入、再验证与探针选址，使错误跨会话自洽；来源分型与墓碑只能防外部污染，防不了这种内生自证，必须用与语义解耦的低层签名、开放集场景拒识和强制 ε-探索把"未知"保留为一等状态。
