# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「单模型多任务」×「演示方案」）

> 第 57 轮把安全的赌注从"模型置信"换到"证据质量"，用 MFSL 摊销先验、XMC 分账对账、PTM 单向有界信任补上三条腿，却在自陈里留下"坏先验普遍"的尾巴：语料存在系统性盲区时，元模型会在 OOD 门学会识别的模式之外给出高度自信的错误后验，而跨模态一致加成与个性化加速会把错误更快送进承诺。本轮两个灵感把这条尾巴推到**模型经济学与展示经济学**：**单模型多任务**用一副主干同时承担导航、运动、操作、对话与安全监控，换来数据效率与跨任务泛化，却让"多任务都同意"退化成**同一个主干被数了很多遍**；**演示方案**用一套精心编排的场景在有限时间内展示能力，换来可看性与传播力，却让"演示成功"成为**经过选择与调参的样本**，天然高估部署表现。二者合流制造一个更隐蔽的病症：**模型和演示共享同一副眼睛——任务头的一致性来自共享主干，演示的覆盖面来自同一批设计者选定的维度**；当盲区恰好落在两者共同的分布外角落，系统会用"多任务多种成功"与"演示多格通过"把同一次无知复述很多遍。本轮把安全赌注由"元先验质量"转成 **"任务间证据血缘可独立 + 演示可证伪可传输"**，核心命题升级为 **"单模型只许提议、跨任务一致不算独立证人、演示只算盲格审计证据"的证据承诺**。

核心矛盾：
- **H29（多任务效率 vs 共干相关）**：单主干多任务头共享表征，数据效率与跨任务泛化都真实存在；但正因为共享，跨任务一致不是多个独立证人，而是同一祖先的多次复述——`N 个头一致 ≤ 1 个独立证人`。按血缘折扣会损失效率，不折扣则让"多任务共识"成为最廉价的伪证据。
- **H30（多任务优化 vs 安全单点）**：联合训练/顺序更新会把安全头的决策边界推着走（负迁移、灾难性遗忘、梯度冲突）；安全头恰恰又与它监督的任务共享同一主干。完全隔离安全头会毁掉单模型的效率动机，不隔离则让任务优化压力慢慢侵蚀红线。
- **H31（演示表现 vs 部署真实）**：演示是经过场景选择、种子筛选、人工兜底与反复调参的样本，演示成功率是有偏估计；把演示做严谨（预注册、盲格、最坏格）会削弱观赏性，把演示做漂亮又等于主动制造 demo inflation。更麻烦的是：未知未知无法被预注册覆盖，演示矩阵只能覆盖设计者想得到的维度。

## 0. 直觉与动机

**灵感 1（单模型多任务 → 共享主干是共同祖先，不是一群证人）**
直觉：一个机器人只背一个模型很诱人——同一套视觉编码器既看地形又看物体，同一套语言空间既接指令又解释决策，算力、内存、数据都省。但安全上必须换一个隐喻：它不是"五个专家开会"，而是"**一个专家用五种口音说话**"。五个头都说"前面能走"，可能只是同一个视觉先验在五个任务上重复表态。正确用法是**给任务头换一个动词**：不是"作证"，而是"**提议**"——提议探针、提议动作候选、提议语义解释、提议演示脚本；跨任务一致只有在任务血缘可证明独立、且仅限非不可逆接触时，才允许折算成一次弱证据。

**灵感 2（单模型多任务 → 安全头是一等任务 + 负迁移证书）**
直觉：多任务训练最危险的不是某个任务做得差，而是**做差的那个恰好是安全**。安全头不能只是主干的又一个头，它必须享受"一等任务"待遇：显式的**无伤害约束**（多任务版安全风险不得高于安全单任务基线）、显式的**干扰检测**（任务梯度与安全梯度冲突、共享表征漂移）、显式的**隔离手段**（任务 adapter、梯度投影、回放、冻结共享层），以及一条最后的退路——**独立浅层安全头**。当证书不过时，宁可牺牲单模型的优雅，退回"独立安全头 + 任务专家"的笨办法；安全不能用效率来买。

**灵感 3（演示方案 → 演示即证伪，不是表演）**
直觉：比赛演示天然是"挑最好的给你看"，于是它系统性地隐藏了三样东西：失败、边界、代价。要把演示从营销材料变成研究仪器，就得让它**先可证伪、再可展示**：演示前冻结一张**压力矩阵**（任务×组合×地形材质×光照×载荷×人角色×通信），每格写清脚本、故障注入、期望的安全行为；留出一批**盲格**不预演、不调参；必须包含**负演示**（已知失败如何被安全停接住）；评分只看**最坏格 + 覆盖率下界**，不看均值。演示方案因此不是"怎么演得好看"，而是"**怎么演才能让失败无处可藏**"。

**灵感 4（演示方案 → 演示-部署传输证书）**
直觉：即便演示诚实，它也只是部署分布的一个样本。演示场地更平整、光照更好、操作者更配合、通信更稳——**演示分布与部署分布的系统性差距**会把演示成功率通胀成部署幻觉。需要一张**传输证书**：用未参与演示选择的 held-out audit 估计 `d_demo`，把演示证据按 `1−d_demo/θ_demo` 折扣；用演示与审计的成功率差 `Δ_demo` 检测 **demo inflation**，一旦显著为正，整批演示证据作废并触发补测。演示轨迹若要回流成训练数据，必须带血缘、过审计、且盲格轮换后永不再训——否则模型会把"演示过的那几格"背下来，形成"越演越会、越会越假"的闭环。

**灵感 5（合流 → 单模型-演示证据门从五类到七类，任务组合风险显式化）**
直觉：第 57 轮五类证据在本轮只加两类，且都带单边性：**EV-task**（跨任务一致，限 `κ≥κ_0` ∧ 仅 L1）与 **EV-demo**（演示盲格，限审计盲格 ∧ 传输证书）；不可逆接触的必要证据集仍是 `{真实 EV-probe* ∨ EV-margin} ∪ 佐证`，EV-task/EV-demo/EV-xmodal 一律不得入集。同时单模型让"任务组合"成为新的风险源：边负重边导航、边操作边对话、边运动边安全监控——联合风险不是各任务取 max，而是 `R_comp=G_task·max_t R_t`，只有耦合增益 `G_task=1` 的子域才允许分离论证。演示矩阵必须显式覆盖这些组合格，而不是只演单项绝活。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（统一多任务主干与任务血缘 UTN）** 单模型 `ℱ_θ=(θ_sh,{θ_t}_{t∈𝒯},θ_s)`，`𝒯={nav,loco,manip,dial,…}` 为任务头集，`θ_sh` 为共享主干，`θ_s` 为安全头（含共享路径 `θ_s^sh` 与独立浅层回退 `θ_s^iso`）。每个任务头带**任务血缘** `𝓛_t=(trunk_ver,adapter_id,data_mixture_hash,calib_batch,seed,sim_seed)`；`κ(t,t')=1−CorrDep(𝓛_t,𝓛_t')` 为有效独立度，同主干同适配器 ⇒ `κ=0`。**提议语义（硬约束）**：任务头只可写"探针候选/动作候选/语义声明/解释渲染/演示脚本候选"，不得直接写证据门、不得直接授权；唯一例外是安全头可发起**否决**，且否决只能使动作更保守。血缘伪造或隐瞒按"证据洗钱"处理：拒绝聚合并记入证书。

**定义 140（跨任务证据折旧 XTD 与任务分歧 D_task）** 跨任务一致 `agree(t,t')` 成立 ⇔ 两任务头在共享决策量上同侧 ∧ `κ(t,t')≥κ_0` ∧ `D_task(r)≤θ_D` ∧ `level=L1`。任务分歧 `D_task(r)=Σ_{t<t'}[TV(b_t,b_{t'})+|Q_μ^t(0.9)−Q_μ^{t'}(0.9)|/μ_scale]`，其中 `b_t` 是任务 t 在区域 r 的诱导信念。高分歧 ⇒ 融合后验强制加宽（不确定性下限）。EV-task 最多顶替一次 L1 佐证，**不得进入不可逆接触必要证据集**；`κ<κ_0` 时 EV-task 直接禁用，不做"部分折扣后仍当强证据"的灰色操作。

**定义 141（负迁移证书与安全头护盾 SNC）** 多任务版安全风险相对安全单任务基线的退化 `Δ_s=R_s(θ_sh,{θ_t},θ_s;𝒯)−R_s(θ_sh^0,θ_s^0;safe)`；**无伤害约束** `Δ_s≤ε_int`。干扰检测：任务-安全梯度余弦 `I(t,s)=cos(∇_{θ_sh}L_t,∇_{θ_sh}L_s)` 与共享表征漂移 `drift(φ_sh)`；`I<0`（冲突）或 `drift>θ_drift` ⇒ 触发**任务隔离**（adapter/LoRA、梯度投影/PCGrad、回放、冻结共享层）。证书 `J_int=(Δ_s,{I(t,s)},drift,isolation_log,audit(θ_s^iso),safety_head_ver)`；J_int 不过 ⇒ 安全头切换到 `θ_s^iso`，且 EV-task 对安全相关承诺永久禁用。**安全头护盾不可被任务平均收益投票关闭。**

**定义 142（演示压力矩阵 DPM）** 演示方案 `𝒟={c=(x_c,script_c,fault_c,expected_c,blind_c,n_c,hash_c)}`，覆盖维度 `𝒳=(task,composition,terrain/material,illumination,payload,human_role,comms)`；每维分层，**盲格** `blind_c=1` 在演示前冻结，不预演、不调参、不选种；每格至少 `n_c` 次独立 trial，预注册 `h(𝒟)`，事后删格/换种/改期望一律记为违规并使受影响格证据失效。评分用**最坏格成功率 + 覆盖率下界 + 置信下界**，禁止用均值或最佳格替代。**负演示**：必须至少包含一个已知失败/安全停格，展示"失败如何被安全接住"；不允许只演示成功路径。

**定义 143（演示-部署传输证书 DTC）** 演示分布 `P_demo` 与部署先验 `P_dep` 的传输差距 `d_demo=MMD(P_demo,P_dep)`（由未参与演示选择的 held-out audit 估计，并给置信上界）。**演示证据** `EV-demo(c)` 可用 ⇔ `blind_c=1 ∧ n_c≥n_min ∧ d_demo≤θ_demo`，权重 `w_demo=1−d_demo/θ_demo`；EV-demo 只能支持 L0/L1 的可逆结论，不得替代不可逆接触必要证据。**Demo inflation** `Δ_demo=succ_demo−succ_audit`，其上置信界 `>δ_demo` ⇒ 全部 EV-demo 作废、触发补测并审计演示脚本选择过程。演示轨迹回流训练需带血缘、过审计，盲格轮换后永不再训；否则视为污染。

**定义 144（多任务-演示证据门 DTG 与算子 SMA）** 证据类七类：`EV-probe*/EV-visit/EV-margin/EV-xmodal/EV-human`（继承第 57 轮）+ **EV-task**（限 `κ≥κ_0 ∧ D_task≤θ_D ∧ L1`）+ **EV-demo**（限审计盲格 ∧ DTC ∧ L1）。不可逆接触必要证据集 `={真实 EV-probe* ∨ EV-margin} ∪ 佐证`；EV-task/EV-demo/EV-xmodal 均不得入集。证书 `J_sm=(J_p,J_int,κ,D_task,DPM hash,DTC,Δ_demo,lineage_log,isolation_log,demo_audit_log)`，继承 J_p 全检。**算子 SMA（Single-Model Multi-task Assess）** 每检查点：①任务分解与头提议；②血缘与负迁移检查（J_int，失败即切独立安全头）；③任务组合风险 `R_comp=G_task·max_t R_t`（仅 `G_task=1` 子域可分离论证）；④若处于演示/审计模式，检查盲格与 DTC，禁止用非盲格证据补洞；⑤证据门 DTG；⑥承诺 ⇔ `R_comp≤δ_f ∧` 证据门过；否则元悲观 VOI 选探 → 换独立血缘/模态 → 绕行 → 降档 → L2 协商 → 安全停。演示审计预算 `B_demo` 与探针预算分离记账，但共享总时延上界。

## 2. 关键算法伪代码（完整版见产物区）

```python
def task_lineage_and_no_harm(F, t, ledger):            # IP-139/141
    kappa = 1 - corr_dep(lineage(F, t), lineage(F, 'safe'))
    I = cos(grad(F, t), grad(F, 'safe'))
    drift = rep_drift(F.phi_sh, ref=ledger.ref_phi)
    if I < 0 or drift > theta_drift:
        isolate_task(F, t)                             # adapter/PCGrad/freeze
        ledger.isolation_log.append((t, I, drift))
    d_s = safety_risk(F) - ledger.safety_only_risk
    J_int = (d_s <= eps_int) and audit_iso_head(F)
    if not J_int:
        F.switch_safety(iso=True)                      # 独立浅层安全头
    return kappa, J_int

def cross_task_evidence(b_t, b_t2, kappa, D_task, level):   # IP-140
    if level != 'L1' or kappa < kappa_0 or D_task > theta_D:
        return None                                    # 不做灰色折扣
    return 'EV-task' if agreeing_side(b_t, b_t2) else None

def demo_matrix_audit(D, trial_log, P_demo, P_dep):    # IP-142/143
    if trial_log.prereg_hash != hash(D):
        D.invalidate(affected_by_deviation(trial_log))
    d_demo = mmd_upper(P_demo, P_dep, audit_heldout)
    infl = succ_upper(trial_log.demo) - succ_lower(trial_log.audit)
    if d_demo > theta_demo or infl > delta_demo:
        D.invalidate_all('EV-demo'); request_supplement()
    for c in D.cells:
        c.ev = 'EV-demo' if (c.blind and c.n >= n_min) else None
    return D, d_demo, infl
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| UTN | O(\|𝒯\|) 头推理/检查点 | O(\|θ_sh\|+Σ\|θ_t\|) | 头只提议、安全头可否决（A41） |
| XTD | O(\|𝒯\|²·d_b)/区域更新 | O(\|V\|·\|𝒯\|·d_b) | κ 保守、同源置 0、EV-task 限 L1（A41） |
| SNC | O(\|𝒯\|·d_θ)/更新；O(1) 在线 | O(\|𝒯\|+d_θ) | 无伤害约束、隔离有效（A42） |
| DPM | O(\|cells\|·n_c) 离线 | O(\|cells\|) | 预注册、盲格不可预演（A43） |
| DTC | O(N_audit) 离线 | O(N_audit) | 传输界保守、inflation 检出（A43） |
| SMA | O(\|CP\|·(\|𝒯\|·C_head+k_p·C_probe+\|𝒯\|²·d_b)) | O(\|V\|+\|σ\|) | 组合风险、双预算终止 |

**正确性定理（Single-model Multi-task Demo-soundness, SMDS 概要）**：在 A33–A40 之上加 **(A41)** 任务血缘诚实、κ 估计保守、同主干/同适配器自动置 0；**(A42)** 负迁移证书诚实、`Δ_s≤ε_int`、隔离与独立安全头回退有效；**(A43)** 演示预注册与盲格诚实、DTC 覆盖部署分布、无事后选种；**(A44)** 单模型共享结构被显式建模，任何 EV-task/EV-demo 仅限 L1。则：
(i) **不可逆健全性不因多任务或演示而放宽**：EV-task/EV-demo 禁入必要集，不可逆路径失效率 ≤ 第 57 轮界 + `δ_int`（负迁移漏检）+ `P(演示未覆盖的未知未知)`；
(ii) **演示声称健全性**：对任意盲格，部署性能由 DPM 最坏格 + DTC 传输界给出，demo inflation 未被检出的概率 ≤ `δ_demo`；
(iii) **交互单调性**：多任务头只提议、演示只审计，二者只能经"探针更准/信念加宽"或"动作更保守"影响系统，不存在升险路径；
(iv) **终止性**：`k_p+k_cons+B_demo` 有限，SMA 终止于 {承诺, 绕行, L2 协商, 安全停}。

部署界（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp(δ_f + ε_meta + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])
             − P(负迁移漏检) − P(demo inflation 漏检) − P(演示矩阵未知未知)
```

关键：**单模型给效率、独立安全头给保底**；**任务头给提议、血缘给折扣**；**演示给覆盖、盲格与传输证书给诚实**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|

| 多任务负迁移侵蚀安全头 | 高 | 无伤害约束 Δ_s、干扰检测、任务隔离、独立浅层安全头回退 |
| 演示选集/调参造成 demo inflation | 高 | 预注册压力矩阵、盲格、最坏格评分、DTC、负演示 |
| 单模型难调试、单点崩溃 | 中 | 任务 adapter、逐任务诊断、可回退专家集、影子模式 |
| 演示矩阵维度爆炸/时延 | 中 | 分层抽样 + 盲格轮换 + 离线审计，审计预算与探针预算分离 |

## 6. 本轮最大风险

**一句话**：单模型与演示方案共享同一副"眼睛"——任务头的一致来自共享主干，演示的覆盖来自同一批设计者选定的维度；当盲区恰好落在两者共同的分布外角落，系统会用"多任务的多种成功"和"演示的多格通过"把同一次无知数了很多遍，而 EV-task/EV-demo 的便利性与单模型的算力优势会让这种复述更快进入对外声明；必须以"EV-task/EV-demo 仅限 L1、安全头可独立回退、演示盲格预注册 + 传输证书 + 负演示"三重护栏，宁可承认"演示没覆盖到、模型不知道"，也不把相关成功当独立证据。

### IP-140 XTD（跨任务证据折旧）

```python
def cross_task_discount(b, tasks, F, level):
    ev = []
    for t, t2 in pairs(tasks):
        kappa = 1 - corr_dep(lineage(F, t), lineage(F, t2))
        if kappa <= 0:                              # 同主干/同适配器
            continue
        D = task_disagreement(b[t], b[t2])
        if D > theta_D:                             # 分歧即不确定性下限
            b[t] = widen(b[t], D); b[t2] = widen(b[t2], D)
            continue
        if kappa >= kappa_0 and agreeing_side(b[t], b[t2]) and level == 'L1':
            ev.append(('EV-task', t, t2, kappa))
    return b, ev

def aggregate_task_evidence(ev_list):               # N_eff 而非头数
    w = [e.kappa for e in ev_list]
    rho = pairwise_corr(ev_list)
    N_eff = (sum(w) ** 2) / sum(w[i]*w[j]*rho[i][j]
                              for i in range(len(w)) for j in range(len(w)))
    return N_eff, (len(ev_list) if N_eff >= 1.0 else int(N_eff))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| UTN | O(\|𝒯\|) 头推理/检查点 | O(\|θ_sh\|+Σ\|θ_t\|) | 头只提议、安全头可否决（A41） |
| XTD | O(\|𝒯\|²·d_b)/区域更新 | O(\|V\|·\|𝒯\|·d_b) | κ 保守、同源置 0、EV-task 限 L1（A41） |
| SNC | O(\|𝒯\|·d_θ)/更新；O(1) 在线 | O(\|𝒯\|+d_θ+|θ_s^iso|) | 无伤害约束、隔离有效（A42） |
| DPM | O(\|cells\|·n_c) 离线 | O(\|cells\|) | 预注册、盲格不可预演（A43） |
| DTC | O(N_audit) 离线 | O(N_audit) | 传输界保守、inflation 检出（A43） |
| SMA | O(\|CP\|·(\|𝒯\|·C_head+k_p·C_probe+\|𝒯\|²·d_b)) | O(\|V\|+\|σ\|) | 组合风险、双预算终止 |

**正确性定理（Single-model Multi-task Demo-soundness, SMDS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 任务血缘诚实，κ 估计保守，同主干/同适配器自动置 0，血缘伪造按证据洗钱拒绝；**(A42)** 负迁移证书诚实，`Δ_s≤ε_int`，任务隔离与独立安全头回退有效；**(A43)** 演示预注册与盲格诚实，DTC 覆盖部署分布，无事后选种/删格，demo inflation 检出有效；**(A44)** 单模型共享结构被显式建模，EV-task/EV-demo 仅限 L1。则：

1. **不可逆承诺健全性不因多任务或演示而放宽**：EV-task/EV-demo 禁入不可逆必要证据集，故不可逆路径失效率 ≤ 第 57 轮界 `δ_f+ε_meta+δ_probe+ε_h+…`，额外仅承担负迁移漏检 `δ_int` 与演示未知未知 `δ_unk`。
2. **演示声称健全性**：对任意盲格，部署性能的最坏格估计由 DPM + DTC 给出；`P(demo inflation 未被检出) ≤ δ_demo`。演示证据只在 L1 可逆结论上生效，且按 `w_demo` 折扣。
3. **交互单调性**：任务头只提议、演示只审计；二者只能经 (a) 更准的探针/信念（含强制加宽）或 (b) 更保守的动作参数（隔离、独立安全头、降档、绕行、安全停）影响系统，不存在升险路径。安全头否决不可被任务平均收益投票关闭。
4. **终止性**：每检查点共识探针 ≤ `k_cons`，演示审计预算 `B_demo` 有限，SMA 在 `k_p+k_cons+B_demo` 内终止于 {承诺, 绕行, L2 协商, 安全停}。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp(δ_f + ε_meta + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])
             − P(负迁移漏检) − P(demo inflation 漏检) − P(演示矩阵未知未知)
```

关键：**单模型给效率，独立安全头给保底**（效率与安全解耦，赌注不押在共享主干上）；**任务头给提议，血缘给折扣**（N 个头 ≤ N_eff 个独立证人，同源自动为 0）；**演示给覆盖，盲格与传输证书给诚实**（演示成功不是部署成功，最坏格不是平均格）。

其中新增：`θ_sh/{θ_t}/θ_s` 单主干与任务/安全头；`κ_task` 任务间有效独立度；`D_task` 任务分歧；`J_int` 负迁移证书；`Δ_s` 安全退化；`DPM_hash` 演示矩阵预注册；`d_demo/Δ_demo` 传输差距与演示通胀；`J_sm` 单模型-演示证书。

云边协议 CEB++ → **CEB-D**：云端可下发多任务主干/头增量（带版本与血缘），但更新必须过**任务隔离影子区**与**演示盲格审计**——影子期内 `Δ_s≤ε_int`、安全头 AUC 不降、任务组合格不塌、盲格审计不复用旧演示数据，才允许接管；边端回传任务血缘、干扰日志、演示盲格结果与传输差距，作为云端再训练与语料补盲依据。第 57 轮"一切判定器走隔离"在本轮推广为"**一切共享表征与演示声称都走血缘与盲格隔离**"。

## 6. 本轮最大风险

**一句话**：单模型与演示方案共享同一副"眼睛"——任务头的一致来自共享主干，演示的覆盖来自同一批设计者选定的维度；当盲区恰好落在两者共同的分布外角落，系统会用"多任务的多种成功"和"演示的多格通过"把同一次无知数了很多遍，而 EV-task/EV-demo 的便利性与单模型的算力优势会让这种复述更快进入对外声明；必须以"EV-task/EV-demo 仅限 L1、安全头可独立回退、演示盲格预注册 + 传输证书 + 负演示"三重护栏，宁可承认"演示没覆盖到、模型不知道"，也不把相关成功当独立证据。
