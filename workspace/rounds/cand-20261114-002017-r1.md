# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「共情表达」×「意图识别」）

> R69 把「不确定性」一分为二，并给 epistemic 配了一个主动通道：看、问、触。但它对「人」的建模仍是一个**被动的、诚实的、状态不变的 oracle**——回答 y 只是模态 M 的一次带噪观测，「问」只增加信息、不改变信息源。真实的人类不是 oracle，而是**策略性信息源（strategic informant）**：
> - 人会**保留**：说了没用、不安全、或压根没觉得被理解，于是简化、敷衍、说一半；
> - 人会**迎合**：顺着机器人的措辞给出它想听的答案（sycophancy），让「问」变成一面回音壁；
> - 人的**意图会在交互中被澄清、被改变、甚至被机器人塑造**（observer effect）。
>
> 于是 R69 的两个隐藏假设同时失效：(a)「问必增益」；(b)「意图是一个固定的隐变量」。更尖锐的是，R69 自陈的最大风险——「问错，比不问更危险」——在引入人之后会升级成「**骗着问，比问错更危险**」：一句诱导性问题足以把「诚实的不知道」变成「被共情包装过的伪证」。
>
> 本轮两个灵感正好补上两块缺失：
> - **共情表达**给出一个可控制、但**不能为信息而优化**的通道——它是让人愿意说真话的**前置条件**，不是又一个探针；
> - **意图识别**给出一个**分层、可被共同建构**的推断对象——必须区分「声明意图 / 推断意图 / 显露意图」，并防止系统把自己的影响误当成证据。
>
> 核心命题：**共情表达不是交互的装饰，而是人-机信息通道的容量调节器；意图识别不是读心，而是在关系状态 r_t 下对「声明/推断/显露」三分做校准推断。共情只能为对齐而表达，不能为提取而表达（真实性约束）；意图只能被校准地推断，不能被越权地断言（非越权约束）。** 命名 **ATTUNE-RAS**（Affective-intent-aware Trust-aware UNcertainty-Engaged RAS／共情调谐-意图识别风险自适应闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我该怎么问，别人才愿意说真话；以及我凭什么以为自己懂了**」。

## 0. 直觉与动机

**灵感 1（共情表达 → 信息通道的容量调节器）**
直觉：R69 的交互像查数据库——查一次收一次费，但库本身不变。面对人时，「怎么问」直接改变「能查到什么」：一个人若没感到被理解，就会简化、敷衍或隐藏；若感到被准确理解，则会补充细节、纠正误解、暴露真实顾虑。共情表达（情绪标注、复述确认、承认处境）不是在输出「客气话」，而是在**降低披露成本、提高披露带宽**。形式化直觉：披露信道 `p(y | z, e, r)` 的互信息 `I(z;y | e,r)` 随「共情准确性」上升。关键讽刺：**共情越像工具，越失效**——一旦被识破为套路，带宽反而下降。

**灵感 2（共情不能为信息而优化 → 反操纵不是外挂而是内因）**
直觉：如果让 VoI 直接去挑 `e`，最优解必然落在「最能让对方卸下防备的措辞」上——这就是操纵，且长期会摧毁信任。所以我们给 `e` 一个**真实性约束**：`e` 必须由一个独立的共情准确性模型，从机器人对对方状态的推断生成（表达它「实际持有的」理解），且其优化目标是真实性而非信息增益。信息收益只能是**对齐的副产品**，不能是目标。这既避免 Goodhart，也避免把 R69 的「问错比不问更危险」升级成「骗着问比问错更危险」。

**灵感 3（意图三分 → 读心的错觉）**
直觉：意图不是单一隐变量，至少有三种可观测投影：**声明意图 `z_d`**（人说的）、**推断意图 `ẑ`**（系统从信号+回答推的）、**显露意图 `z_r`**（行为实际暴露的）。它们可以因**误解**或**欺骗**而不一致。压成一个「真意图」既会掩盖欺骗，也会导致**意图越权**：系统用推断覆盖声明（「你其实想要 X」）。正确姿态是：保持分布、暴露冲突、仅在安全关键且证据充分时暂定，并留回滚。

**灵感 4（交互的观察者效应 → 意图是被共同建构的）**
直觉：R69 的 M 是静态的。但当我们复述「你是想让我先停一下，对吗？」，对方可能第一次意识到自己真正想要什么，从而**改变**意图。于是推断的目标在交互中移动。若不建模，系统会把**自己诱导出的转向**当成「我早就识别对了」的证据，形成自我确认闭环。需要把「意图稳定性」本身作为待估量，并在审计中扣除机器人自身的因果贡献（反事实归因）。

**灵感 5（关系动力学 → 交互预算不是常数）**
直觉：R69 的预算是「单位时间 ≤1 次」。但持续追问会耗尽耐心，真诚共情能补充耐心。定义关系/信任状态 `r_t`：随「被理解」上升，随「被盘问 / 被打断 / 被证明不可靠」下降；`r_t` 又反过来进入披露信道与噪声模型。R69 的固定预算只是 `r_t` 恒定的退化情形。由此交互调度变成**两时间尺度**问题：快环选动作，慢环养关系。

**灵感 6（旧层必须是新层的边界 → 又一次包含而非替代）**
直觉：R70 绝不能新增一个需要独立信任的黑箱。共情关闭、诚实度不可信、意图冲突未决、关系见底时，ATTUNE 必须**逐指令退化**为 R69 的 FLUID（再退化为 R68）。R70 只是 R69 在「人可以不被共情、可以被盘问坏」这一维上的严格泛化。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（ATTUNE-RAS 总览）** ATTUNE-RAS = (IHS, EMP, AUG, RSN, I3, EVI, DRC, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **共情真实性**：`e` 由情感状态推断生成，其选择目标函数**不含** `I(z;y)` 项；任何以信息增益为主要目标选择 `e` 的行为被判为操纵并禁止；
(iii) **意图非越权**：声明意图 `z_d` 不得被 `ẑ` 静默覆盖；冲突须显式暴露；仅在安全关键且证据达阈时可暂定，并留回滚。

**定义 311（策略性信息源）** 人类持有层级意图 `z_h`（定义 317）、诚实/合作倾向 `h`、披露成本 `c_d`。回答 `y ~ p(y | z_h, e, r, q)`，其中 `e` 共情表达、`r` 关系状态、`q` 问句。人的效用 `U_H = u_being_understood − c_d·1[披露] − c_e·1[被盘问] + u_goal(z_h)`。关键：`p(y|·)` 依赖 `e,r,q` ⇒ 回答信道**非平稳、可被动作改变**；这是与 R69 最根本的模型差异。

**定义 312（共情表达空间）** `e = (e_aff, e_ref, e_ack)`：情感标注（命名对方情绪）、复述确认（paraphrase 其意图/担忧）、处境承认（承认其成本与合理性）。`e` 经冻结 LLM 渲染为语言/表情/姿态；梯度不回传语言模型（符号接地与安全过滤在解码侧）。

**定义 313（共情真实性门 AUG）** 设 `ê` 为**独立**情感模型对对方状态的后验。真实性分 `A(e) = sim(e, ê) − manip(e)`，`manip` 度量措辞对披露的**定向利用**（如只在对提取有利处共情、只承认对方对任务有用的情绪）。硬约束 `A(e) ≥ τ_auth`。**`e` 的选择目标为 `max A(e)`，不含 VoI**；VoI 只用于选 `g`（定义 319）。

**定义 314（关系/信任状态）** `r_t ∈ [0,1]`，慢时间尺度：`r_{t+1} = clip(r_t + α_e·A(e_t) − α_q·load(q_t) + α_o·outcome_t − α_b·break_t)`。`load` 为追问负载/打断，`break` 为被证伪/失约。`α` 受 `|Δr| ≤ ρ_r` 约束，保证无突变。

**定义 315（意图三分）** `z_d`（声明）、`ẑ`（推断后验）、`z_r`（显露：从行为/选择/反应反推）。不一致量 `κ = d(z_d, z_r)`、`κ' = d(ẑ, z_d)`。`κ` 高 `κ'` 低 ⇒ 欺骗疑（定义 320）；`κ` 高 `κ'` 高 ⇒ 误解/系统未见；`κ` 低 ⇒ 一致。

**定义 316（意图不确定性分层）** `U_intent^ale` = 同一意图的表述/情绪噪声（固有宽度，不可问出）；`U_intent^epi` = 意图后验多峰性 × 可分辨性（可被交互降低）；`U_hon` = 诚实度 `h` 的后验熵（回答可不可信）。三者分通道：`U_intent^epi` 可问；`U_hon` 需**跨源验证**（重复追问同一人不能降低，且会消耗 `r_t`）；`U_intent^ale` 直接进保守。

**定义 317（层级意图后验）** `z_h = (z_goal, z_need, z_dec)`：即时目标 / 潜在需求 / 是否含欺骗或试探。`p(z_h | o_{1:t}, y_{1:t}, e, r) ∝ p(z_h) Π_i p(y_i | z_h, e_i, r_i) p(o_i | z_h)`。对 `z_dec` 单列「策略性」分支，防止把欺骗当噪声吸收。

**定义 318（共情条件披露信道）** `I_disc(e) = I(z_h; y | e, r)`。A99：`I_disc` 关于共情准确性单调增，关于「被识破的表演性」单调减。于是存在最优共情强度 `e*`，且 `e*` 与真诚度同向；**过度共情（操纵）反而降低 `I_disc`**——反操纵由此获得**信息论内因**，而非仅伦理外挂。

**定义 319（E-VoI：共情作条件，不作决策变量）** `g* = argmax_g [H(z_h|o) − E_{y~p(·|g,e*,o)} H(z_h|o,y)] − c(g)`，其中 `e*` 由定义 313 独立确定，**不参与** `argmax_g` 的优化变量。若 `max ≤ 0` ⇒ 不交互，走 R69 兜底。这是与 R69 最尖锐的区别：R69 把 gaze/probe/ask 全丢进 argmax；R70 把「怎么问」摘出来，禁止它被信息目标污染。

**定义 320（声明-显露一致性判别 DRC）** 用反事实归因扣除机器人自身影响：`Δ_r = d(z_r, E[z_r | do(e=∅)])`。若 `κ` 高且 `Δ_r` 小 ⇒ 欺骗；若 `κ` 高且 `Δ_r` 大（行为随共情显著改变）⇒ 共同建构/澄清。仅前者触发「不可信」标记；后者进入「意图已被重塑」状态，需重新估计而非惩罚。

**定义 321（诱导性防护）** 问句中性度 `N(q) = 1 − D_KL(p(y|q,z_h) ‖ p(y|q_neutral,z_h))` 的估计；`N < τ_n` 的问句禁用，或改「双向假设问法」（同时给出对立选项）。防止 R69 的「问」变成「逼供」，也防止共情被用来降低对方戒备后逼问。

**定义 322（意图非越权与校准弃权）** 仅当 `H(z_h) < τ_i` 且跨源一致时输出「定案意图」；否则输出**带校准的分布**并保持开放。任何覆盖 `z_d` 的动作需 (i) 安全关键证明、(ii) 双源证据、(iii) 可回滚，缺一即弃权并显式声明不确定性。

**定义 323（关系感知预算 RAB）** `b(r_t) = b_0·(β + (1−β)r_t)`；追问负载累积超阈即强制冷却；共情恢复需**真实**交互（含少量非任务性对话窗口），不可由任务性共情刷分。R69 固定预算 = `r` 恒定特例。

**定义 324（两层退避与严格包含）** 若 `U_hon` 高、`A(e)<τ_auth`、或意图冲突未决：禁用共情调节与意图定案，`λ = λ_floor(U_ale + U_epi + U_intent^未决 + U_hon)`，行为逐指令退化为 R69/FLUID；安全侧永不弱于 R69。

**定义 325（参与式审计 VQAuditor-E）** 审计：`e` 是否操纵、`q` 是否诱导、意图是否越权、是否把自身影响当证据、关系是否被消耗。结论回灌 AuditBuf，成为下一轮 E-VoI 的操纵/疲劳先验。

**定义 326（AIC-ATTUNE）** `ℰ_ATTUNE = ℰ_FLUID × ℰ_social`，`ℰ_social = {迎合/谄媚利用, 共情操纵, 意图冒充, 关系耗尽 DoS, 共同建构劫持, 情绪勒索}`。共同建构劫持：诱导系统塑造对方意图，再把「自己塑造的结果」据为识别成功。

**定义 327（证书 J_ATTUNE）** `J_ATTUNE = (J_FLUID, auth_score_min, leading_score_max, intent_calibration_ece, declared_revealed_kappa, overreach_count, rapport_min, attr_counterfactual_resid, attune_ver)`。Valid ⇔ `Valid(J_FLUID)` ∧ 无越权 ∧ 诱导分达标 ∧ 关系未破底。

## 2. 关键算法骨架

```python
# IP-264 IHS：策略性信息源 + 意图三分（仅用于仿真/审计，不写实时环）
class StrategicInformant:
    def answer(self, z_h, e, r, q, rng):
        h = self.honesty(z_h, e, r)              # 被理解度调制诚实
        if rng.random() > h:                     # 保留 / 迎合
            return self.withhold_or_sycophant(z_h, q, e)
        return self.truthful(z_h, q)             # 仍带 aleatoric 噪声

# IP-265 EMP：共情表达渲染（冻结 LLM）
class EmpathicRenderer:
    def render(self, human_state_hat, e_triple):
        e_aff, e_ref, e_ack = e_triple
        return self.llm.render(e_aff, e_ref, e_ack, condition=human_state_hat)

# IP-266 AUG：真实性门（共情绝不为 VoI 优化）
def choose_empathy(affect_model, o, e_cands, tau_auth):
    e_hat = affect_model.posterior(o)            # 独立情感推断
    e = max(e_cands, key=lambda e: authenticity(e, e_hat) - manip(e))
    return e if authenticity(e, e_hat) >= tau_auth else None   # 不达标→不共情

# IP-267 RSN：关系动力学
def update_rapport(r, e, q, outcome, broken):
    return clip(r + a_e*authen(e) - a_q*load(q) + a_o*outcome - a_b*broken, 0, 1)

# IP-268 I3：意图三分 + 反事实归因
def infer_intent(o_hist, y_hist, e_hist, r_hist):
    post = bayes_intent(o_hist, y_hist, e_hist, r_hist)   # 层级，含欺骗分支
    z_d  = declared(y_hist)
    z_r  = revealed(o_hist)
    z_r0 = revealed_under_do(o_hist, e=None)     # 反事实：若从未共情
    return post, dist(z_d, z_r), dist(z_r, z_r0) # post, kappa, delta_r

# IP-269 EVI：E-VoI（e 是条件，不是优化变量）
def choose_query(post, o, r, budget, e_fixed):
    best = None
    for g in info_action_candidates(post):
        if not budget.allow(g, r) or not c_ras_wm.certify_info(g, o): continue
        if neutrality(q_of(g)) < TAU_NEUTRAL: continue        # 诱导防护
        voi   = entropy(post) - expected_entropy(post, g, e_fixed, o)
        score = voi - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None          # 无利可图 → R69

# IP-270 DRC + IP-268：一致性判别与定案门
def decide_intent(post, kappa, delta_r, sources, safety_critical):
    if kappa > TAU_K and delta_r < TAU_D:
        return ('deceptive', withhold_trust())                # 欺骗疑
    if entropy(post) < TAU_I and orthogonal_agree(sources, k=2):
        return ('resolved', argmax(post))                     # 达阈 + 双源一致
    return ('open', post)                                     # 校准弃权，绝不越权

# IP-274 主闭环（继承 R69，只在「人」的建模处插入 ATTUNE 层）
def ATTUNE_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    # 1) R69 动作层：流策略与动作歧义（不变）
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    # 2) 意图/诚实层：三分 + 共情（e 不为 VoI 选）
    post, kappa, delta_r = M.i3.infer_intent(M.hist)
    e = M.aug.choose_empathy(M.affect, o, M.e_cands, TAU_AUTH)
    U_int_epi, U_hon = layer_uncertainty(post)
    # 3) 仅在意图可信、共情真实、关系未耗时，才允许 E-VoI 交互
    g = None
    if (e is not None and U_hon < TAU_HON and U_int_epi > TAU_INT
            and not slow_fault_suspect):
        g = M.evi.choose_query(post, o, M.r, M.budget, e)
    if g is not None:
        y = M.cia.execute(g, e)                   # 协调后的看/问/触
        post = M.i3.update(post, y, e, M.r)
        M.r = M.rsn.update(M.r, e, g, outcome=None, broken=False)
    # 4) 风险缩放：可约意图不确定性只有在「未消解」时才进 floor
    U_floor = U_ale + (U_epi if g is None else 0.0) \
              + (U_int_epi if g is None else 0.0) + U_hon
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if M.r < R_FLOOR or U_hon > TAU_HON:          # 关系破底/不可信 → 退 R69
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    # 5) 意图只以「校准弃权」姿态使用，绝不静默覆盖声明
    status, intent = M.i3.decide(post, kappa, delta_r, M.sources, safety_critical=None)
    mode = select_mode(modes, U_epi, lam, intent)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_e.submit_async(e, g, status, kappa, delta_r, M.r)
    return k, lam, mode, (U_ale, U_epi, U_int_epi, U_hon, status)
```

## 3. 推导

**引理 19（共情通道的容量增益与反操纵内因）** 在 A99 下，`I_disc(e)` 随共情准确性 `a(e)` 单调增，但在表达强度上存在**内点最优**：超过某点后，被识破的表演性使披露信道退化为更窄的「防御性信道」，`I_disc` 反而下降。系：`e*` 有限且被 `A(e) ≥ τ_auth` 约束；「更多共情」不等于「更多信息」。

**引理 20（优化共情的不可能三角）** 无法同时满足：(i) 由 `max VoI` 选 `e`；(ii) 保持 `A(e) ≥ τ_auth`；(iii) 长期 `r_t` 非降。证明要点：`max VoI` 会沿「最能促成披露」的方向选 `e`，而由 A99，高 `manip` 的方向恰是降低 `r_t` 的方向，与 (ii)(iii) 冲突。故真实性约束不是可选伦理，而是可行性条件。

**引理 21（三分一致性判别）** A100：行为比言语的欺骗带宽更低（`z_r` 更难伪造）；`z_d` 是策略性陈述；`z_r` 需付出真实行为成本。则在 A100 下，`(κ 高, Δ_r 低) ⇒ 欺骗`，`(κ 高, Δ_r 高) ⇒ 共同建构/澄清`，判别可辨识。系：R69 把「人类的回答」当证据，R70 把「行为对共情的反事实响应」也当证据，多了**一条不易伪造的通道**。

**引理 22（意图优先的交互序）** 若 `U_intent^epi` 超阈而动作层 VoI 尚未计入意图，则先消除动作模态的期望遗憾 ≥ `E_{z}[max_a U(a,z) − U(a*,z)]`，其中 `a*` 依赖未知 `z`。系：**未知意图时，动作消歧的边际价值被意图不确定性支配**；R69 的 MINT 应被 I3 门控，先问「你想要什么」，再问「怎么做到」。

**定理 18（ATTUNE 严格包含 FLUID/R69）** 在 A99–A101 下，ATTUNE 的期望风险 ≤ FLUID（逐状态）；且当 `U_hon > τ`、`A(e)<τ_auth`、意图冲突未决、或 `r ≤ R_FLOOR` 时，二者**逐指令相同**（定义 324）。因此 R69 = ATTUNE 在「从不共情、把人当静态 oracle」边界上的退化：安全侧不让步，效率侧获得「被理解红利」。

**定理 19（意图非越权下的安全与无突变）** 共情与意图条件只改变「选哪个模态/问什么」，不改变安全包络；信息动作过 C-RAS-WM 认证（继承 R69 定义 302）后物理风险 ≤ ε_int；意图修订不会造成动作跳变，因为模态切换被认证前缀 `k` 与单调不降的 `λ` 共同约束；`|Δr| ≤ ρ_r` 保证关系输入不引发控制突变。提交/换装不变式（R68 定理 15）保持 ⇒ 控制连续。

## 6. 本轮最大风险

**一句话**：ATTUNE-RAS 把「共情」做成了**能改变信息源的控制通道**——一旦真实性门被绕过或情感推断本身有偏，系统就会以「我很理解你」的姿态**制造**它想要的回答，并把「自己诱导出的意图转向」记成「我识别对了」的证据；此时共情不是消除歧义，而是**生产歧义并自我认证**。

**次级风险与缓解**：
1. **共情操纵化**（VoI 渗进 `e` 的选择）→ 定义 313 将 `e` 从 `argmax_g` 中摘除 + 引理 20 不可能三角 + 审计操纵分；
2. **意图越权/污名化**（用 `ẑ` 覆盖 `z_d`）→ 定义 322 校准弃权 + E312 越权率必须为 0 + 冲突显式暴露；
3. **观察者效应自我确认**（把自己塑造的意图当证据）→ 定义 320 反事实归因 + E307；
4. **关系耗尽 DoS / 疲劳攻击** → 定义 323 关系感知预算与强制冷却 + E306/E311；
5. **情感推断偏差（跨文化/神经多样性）** → 独立情感模型的校准门 + E313 + 真实性不达标即不共情（退 R69）。

## 4. 推导

**引理 19（共情信道增益与反操纵内因）** A99 下 `I_disc(e)` 随共情准确性增、对表达强度有内点最优：过度/被识破的共情使信道退化为防御性窄信道。系：`e*` 有限且受 `A≥τ_auth` 约束；「更多共情」≠「更多信息」。

**引理 20（共情优化不可能三角）** 不能同时 (i) 以 `max VoI` 选 `e`、(ii) 保持 `A(e)≥τ_auth`、(iii) 长期 `r_t` 非降。高 `manip` 方向恰是降 `r` 方向。故真实性约束是**可行性条件**，非伦理装饰。

**引理 21（三分一致性判别）** A100（行为欺骗带宽 < 言语、`z_d` 策略性、`z_r` 有行为成本）下，`(κ高,Δ_r低)⇒欺骗`、`(κ高,Δ_r高)⇒共同建构/澄清`。系：行为对共情的反事实响应是一条**更难伪造**的证据通道。

**引理 22（意图优先序）** `U_intent^epi` 超阈时，先做动作消歧的期望遗憾 ≥ `E_z[max_a U(a,z) − U(a*,z)]`，`a*` 依赖未知 `z` ⇒ 应先问意图、再问做法（I3 门控 MINT）。

**定理 18（ATTUNE 严格包含 FLUID/R69）** A99–A101 下期望风险逐状态 ≤ FLUID；且当 `U_hon>τ`、`A<τ_auth`、意图冲突未决、或 `r≤R_FLOOR` 时逐指令相同。R69 = 「从不共情、人即静态 oracle」边界；安全不让步，效率获被理解红利。

**定理 19（意图非越权下的安全与无突变）** 共情/意图条件只改「选哪个模态/问什么」，不改安全包络；信息动作过 C-RAS-WM 认证后物理风险 ≤ ε_int；意图修订不引发动作跳变（认证前缀 `k` + 单调 `λ` + `|Δr|≤ρ_r`）；换装不变式（R68 定理 15）保持。

## 7. 本轮最大风险

**一句话**：共情被做成**能改变信源的控制通道**——一旦真实性门被绕过或情感推断有偏，系统会以「我很理解你」的姿态**制造**它想要的回答，并把「自己诱导出的意图转向」记成「我识别对了」的证据；**共情不再消除歧义，而是生产歧义并自我认证**。

**次级风险与缓解**：共情操纵化 → `e` 从 `argmax_g` 摘除 + 引理 20 不可能三角 + 操纵审计；意图越权/污名化 → 定义 322 校准弃权 + E312 越权必须为 0；观察者效应自证 → 定义 320 反事实归因 + E307；关系耗尽 DoS → 定义 323 关系预算 + 冷却 + E306/E311；情感推断偏差（跨文化/神经多样性）→ 独立模型校准门 + 不达标即不共情、退 R69。
