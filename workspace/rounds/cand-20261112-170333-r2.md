# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；本轮为灵感驱动研究循环第 2 轮；本轮灵感：「需求洞察」×「数据标注」）

> 第 60 轮用 SSM×CIEC×EPIR×SERC 把「场景→意图→约束→阻抗→执行→证据」闭合成 SGEC，安全性来自「场景置信度回退 + 意图约束锁定 + EPIR 双保险 + SIC 三元校验」。但它把整条链的**知识来源**当成了既成事实，三个结构性缺口被闭环的成功掩盖了：
> 1. **需求是手写字典，不是被发现的**：`Z_scene` 的 10 个场景、`I` 的 5 个意图、`π_scene` 的先验、`ϕ_intent→constraint` 的映射全部由人预先枚举。真实用户的需求往往是隐含的（「别把杯子捏响」「递给我之前先停一下」），它不在字典里，于是只能静默走默认约束——**系统既不报错也不澄清，产生「看起来听懂了、其实没约束」的静默失效**。
> 2. **证据是未开采的监督矿山**：第 60 轮的 EV-exec、操作者纠偏、急停接管、重做动作，是最贴近真实分布的监督信号，但 EPIR 只保证它们「到达、有序、未被篡改」，**从未把它们转化为需求标签或约束先验**。数据完整性做得很重，数据价值却被完全浪费。
> 3. **标注被当成离线人工劳动，而非安全闭环的一环**：没有主动选样、没有标注噪声模型、没有溯源、没有「标注→约束」的语义。一条错误标注可以无声地编译进 `K_safe`；标注完全处在安全包络之外，这与第 60 轮「构造性安全」的精神背道而驰。

## 0. 直觉与动机

**灵感 1（需求洞察 → 需求潜变量模型 RLM）**
直觉：用户说「轻一点」只是**表层观测**；真正的需求是「接触力峰值 ≤ 5N 且抓取成功后不得重试」这类**轨迹谓词**。操作者的纠偏、接管、重做不是噪声，而是对潜需求的**间接测量**——人只有在需求被违反时才出手。关键洞见：**把需求洞察写成逆约束学习（inverse constraint learning）**：以「违反程度驱动纠偏概率」为观测模型，从纠偏轨迹反演需求的类型、作用域与硬度，而不是让人把需求手工翻译成参数。

**灵感 2（数据标注 → 标注是测量，不是标签 AQC）**
直觉：同一个片段让不同人标，会得到不同答案；同一个人疲劳时也会漂移。标注不是「真相」，而是**带噪声、带来源、带置信度的测量**。关键洞见：**先建标注者噪声模型（混淆矩阵），再聚合**；一条标注必须绑定它所指的 EV-exec 哈希、标注者身份、方法与时间戳，形成**标注溯源原子**，否则它不配进入约束编译。

**灵感 3（需求洞察 × 数据标注 → 主动标注 AAL）**
直觉：不是所有片段都值得标注。给一片「已经稳稳抓住」的轨迹贴标签，对安全边界毫无影响；真正值钱的是**恰好落在可行性边界附近、标错就会改变 `K_safe`** 的片段。关键洞见：**主动标注的价值 = 需求后验熵的下降 × 该片段对安全可行域的影响**；把标注预算花在决策边界上，可用远少于全量标注的样本收敛需求。

**灵感 4（数据标注 → 标注-约束编译 A2C）**
直觉：如果每个标注诱导的约束都只能与基础安全域做**交（meet）**、只能收紧不能放宽，那么无论标注对错，编译结果永远是 `C_base` 的子集。**错标注只让机器人更保守、更笨，绝不会让它更危险**。关键洞见：把「标注不确定性」转译为「可行域的单调收缩」；要放宽，必须由更高权限的人显式指名被放宽的约束并出示安全证书，系统绝不自动放松。

**灵感 5（需求洞察 → 需求冲突检测 RCD）**
直觉：用户常说自相矛盾的话（「快一点」又「稳一点」），不同操作者的需求也会打架，新需求可能和硬安全约束直接矛盾。三条约束投票不是办法——**交集为空时必须停下来澄清，而不是偷偷选一个**。关键洞见：冲突检测要给出**最小不可满足核（MUS）**，让澄清问题指向「到底哪两条需求不能同时满足」。

**灵感 6（需求洞察 → 需求漂移检测 RDD）**
直觉：需求会随时间、操作者、任务而变。昨天的「轻触」今天可能变成「压紧」。把需求当永久常量，会让系统用过期的意图驱动执行。关键洞见：**用纠偏率的变点（CUSUM）识别需求漂移**，把需求集版本化；漂移只能自动改动软需求/偏好，硬安全需求的变更必须走人工授权与重新认证。

**灵感 7（合流 → 需求-标注闭环 RAL × PCE+++++）**
直觉：第 60 轮的 SERC 负责「场景→执行」，本轮在其上叠加「证据→需求→标注→约束」的知识层：`EV-exec → 主动选样 → 人工标注 → 噪声聚合 → 需求后验 → 冲突/漂移检查 → 标注-约束编译 → ERTC/EEIS → 执行 → 新证据`。预算从四维认知预算扩展为**六维** `B_scene/B_intent/B_ros/B_exec/B_req/B_annot`；任一耗尽都只允许系统更保守（fail-closed），绝不允许绕过安全基线。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（需求潜变量模型 RLM）** 需求空间 `𝓡 = (P, ⪯, H, S, Γ)`，其中：
- **谓词基元**：`P = {p_force, p_velocity, p_contact, p_retry, p_handover, p_scope_bind}`，每个基元把轨迹片段 `τ ∈ 𝒯` 映射为**违反裕度** `g_p(τ) ∈ ℝ`；`g_p(τ) ≤ 0` 表示满足。
- **需求**：`r = (g_r, h_r, s_r, γ_r)`，`g_r` 由基元经有限组合算子（∧、∨、时序 `◇/□`）生成；`h_r ∈ {H, S, Pr}` 为硬/软/偏好；`s_r = (z, T, ρ, phase)` 为场景-任务-区域-阶段作用域；`γ_r` 为溯源。
- **偏序**：`r_a ⪯ r_b` 表示 `r_a` 比 `r_b` 更保守（可行域更小）。
- **需求先验**：`P(R)` 由需求语法给出，偏好「少量、强解释」的需求集（稀疏先验）。
- **纠偏观测模型**：给定当前策略 `π` 与需求集 `R`，在时刻 `t` 出现纠偏事件 `c_t ∈ {0,1}` 的似然
  ```
  P(c_t=1 | R, τ_t) = σ( β · ( max_{r∈R} g_r(τ_t) + b ) )
  ```
  即违反裕度越大，人越可能出手；`β` 为敏感度，`b` 为偏置。
- **后验推断**：`P(R | D) ∝ P(R) · Π_{(τ,c)∈D} P(c | R, τ)`，用增量 MCMC / 遗传式结构搜索维护，操作符为 `add / refine / merge / retire`。

**定义 162（主动标注 AAL）** 候选片段池 `U`，采集函数
```
a* = argmax_{u∈U} [ E_{ℓ}[ H(R|D) − H(R|D ∪ {(u,ℓ)}) ] · impact(u) − λ_c · c(u) ]
```
其中：
- **安全影响**：`impact(u) = P( u 的标注会改变 K_safe )`，用「片段轨迹到当前可行域边界 `∂K_safe` 的距离」近似；边界附近 `impact` 高，深处为 0。
- **标注代价**：`c(u) = c_human·len(u) + c_comm`。
- **停止准则**：`VOI_annot(u*) ≤ 0` 或 `B_annot` 耗尽即停止；仅当 `impact(u) ≥ θ_impact` 的片段进入标注队列（边界感知采样）。

**定义 163（标注-约束编译 A2C）** 编译器 `𝒞: (R, C_base) → C_req`：
- **单需求约束**：`C_r = { τ : P(g_r(τ) ≤ 0 | D) ≥ 1 − α_r }`（机会约束，`α_r` 为风险预算）。
- **硬需求合成**：`C_req = C_base ∩ ⋂_{r∈R_H, corroborated} C_r`。
- **晋升规则**：`r` 只有在 `P(r|D) ≥ τ_promote` **且** 被 `≥ k` 条相互独立的证据佐证时，才从软需求晋升为硬约束，防止单条噪声标注直接收紧执行。
- **软需求**：不进入交集，而是进入目标函数/代价项 `J_soft = Σ_r w_r · max(0, g_r(τ))`。
- **单调性（构造性安全）**：同一版本内 `∀t: C_req^{t+1} ⊆ C_req^t`；放宽只允许经由权限 `auth(annotator) ≥ auth(r)` 的显式 `relax` 请求，并附 `Cert_relax`（放宽带、理由、复核签名）。
- **可靠性定理（合流）**：`∀R, 𝒞(R, C_base) ⊆ C_base`，即任何标注结果都不可能撑破基础安全域。

**定义 164（标注质量与溯源 AQC）** 标注 `ℓ_{ij}` 为标注者 `j` 对片段 `i` 的标签，噪声模型 `Q_j(a,b)=P(ℓ_{ij}=a | r_i=b)`。
- **聚合后验**：`p_i = P(r_i | {ℓ_{ij}}_j, {Q_j})`，用 Dawid-Skene EM 联合估计 `Q_j` 与 `p_i`。
- **溯源原子**：`Ann = (label, annotator_id, confidence, ts, ev_exec_hash, method, signature)`。
- **质量门控**：`p_i < τ_label` 的标注进入仲裁/复标，不得直接编译；`Q_j` 持续劣化的标注者降权。
- **一致性指标**：Fleiss' κ、标注者校准误差 ECE_ann、溯源完整率。

**定义 165（需求-标注闭环 RAL）** 算子 `RAL(M, U)`：
```
① 证据切分：从 EV-exec 抽取候选片段 U_t，附 (seq_id, hash)
② AAL：按 impact×VOI 选 u*，生成标注查询
③ AQC：聚合标注 → p_i，更新 Q_j，质量门控
④ RLM：P(R|D) ← update(P(R|D), {(u*, p_i)})，执行 add/refine/retire
⑤ RCD：冲突检测；若存在硬冲突 → HALT/CLARIFY，返回 MUS
⑥ A2C：C_req ← 𝒞(R, C_base)；EEIS 在 C_req 上编译 K_safe
⑦ ERTC：锁定/下发约束；执行并采集新 EV-exec
⑧ RDD：更新纠偏率统计，检测需求漂移
⑨ return (P(R|D), C_req, K_safe, AnnLedger, drift_flag)
```

**定义 166（六维预算 PCE+++++）** `B = (B_scene, B_intent, B_ros, B_exec, B_req, B_annot)`，其中：
- **B_req** = (Inference_compute, Elicitation_rounds, Posterior_memory)
- **B_annot** = (Label_quota, Human_seconds, Query_bandwidth)
```
voi_req(π) = VOI_meta_pessimistic(π) − cost_cog(π) − cost_exec(π) − cost_req(π) − cost_annot(π)
cost_req   = λ_inf · Inference_cost(R) + λ_elicit · Elicitation_rounds
cost_annot = λ_label · N_label + λ_human · Human_seconds
```
降级顺序（只能更保守）：`B_annot` 耗尽 ⇒ 仅允许自监督伪标签，且伪标签**永不晋升**为硬约束；`B_req` 耗尽 ⇒ 冻结需求集于当前保守版本；两者皆耗尽 ⇒ 回退手写基线 `R_base` 并本地闭环。

**定义 167（需求冲突检测 RCD）** 冲突谓词：
- **可行域冲突**：`Feas(C_base ∩ ⋂ C_r) = ∅`；
- **证据冲突**：`P(R|D)` 多峰且各峰对同一轨迹给出相反判定（如「快」与「稳」同时高置信）；
- **作用域冲突**：两条需求在同一 `s_r` 上给出相反单调方向。
检测用区间/SMT 可行性 + 后验多峰检验；输出**最小不可满足核** `MUS ⊆ R`。规则：**任何硬冲突一律 HALT/CLARIFY，禁止系统擅自二选一**。

**定义 168（需求漂移检测 RDD）** 纠偏率 `λ_t = #corrections / #trials`，基线 `λ_0`；CUSUM 统计量
```
S_t = max(0, S_{t−1} + (λ_t − λ_0 − ν))
```
`S_t > h_drift` 触发漂移。漂移时：需求集版本 `R_v → R_{v+1}`，过时软需求按 `age(r)` 衰减/退役；**硬需求变更必须走人工授权与重新认证**，安全基线 `C_base` 不因漂移而放宽。

## 2. 关键算法伪代码

### IP-161 RLM（需求潜变量反演）

```python
class RequirementLatentModel:
    def __init__(self, primitives, alpha=0.05, promote_thr=0.9, k_support=3):
        self.primitives = primitives          # 基元谓词 g_p(tau)
        self.posterior = {}                   # r -> P(r|D)
        self.alpha = alpha
        self.promote_thr = promote_thr
        self.k_support = k_support

    def violation_margin(self, req, tau):
        return max(self.primitives[p](tau) for p in req.g)   # max 违反裕度

    def correction_likelihood(self, reqs, tau, beta=4.0, b=-1.0):
        m = max((self.violation_margin(r, tau) for r in reqs), default=-1e9)
        return 1.0 / (1.0 + math.exp(-beta * (m + b)))

    def update(self, D_segment, corrected):
        for r in self._candidate_requirements(D_segment):
            ll = self.correction_likelihood([r], D_segment)
            prior = self.posterior.get(r, self._grammar_prior(r))
            post = prior * (ll if corrected else 1.0 - ll)
            self.posterior[r] = self._normalize(post)
        self._prune_and_merge()

    def promoted_requirements(self):
        return [r for r, p in self.posterior.items()
                if p >= self.promote_thr and self._support_count(r) >= self.k_support]
```

### IP-162 AAL（主动标注）

```python
def active_annotation_query(model, pool, K_safe, budget, lambda_c=1.0):
    best, best_voi = None, 0.0
    H0 = model.entropy()
    for u in pool:
        impact = boundary_proximity(u.traj, K_safe)      # 0..1
        if impact < 0.05:
            continue
        H1 = expected_entropy_after(model, u)            # 贝叶斯 D-最优近似
        voi = (H0 - H1) * impact - lambda_c * u.cost
        if voi > best_voi:
            best, best_voi = u, voi
    if best is None or best_voi <= 0 or budget.label_quota <= 0:
        return None
    budget.label_quota -= 1
    budget.human_seconds -= best.cost
    return best
```

### IP-163 A2C（标注-约束编译）

```python
class AnnotationToConstraintCompiler:
    def __init__(self, C_base, risk_alpha=0.05, authority_table=None):
        self.C_base = C_base
        self.alpha = risk_alpha
        self.auth = authority_table or {}
        self.compiled = C_base

    def compile(self, reqs, label_posteriors, relax_requests=()):
        C = self.C_base
        for r in reqs:
            if not r.is_hard:
                continue
            p = label_posteriors.get(r, r.confidence)
            if p < self.alpha_safe_margin(r):
                continue
            C = C.intersect(self.chance_constraint(r, p))   # 只做交，只收紧
        for req in relax_requests:
            if not self.authorized(req):
                raise SafetyViolation("relax requires higher authority + Cert_relax")
            C = C.relax(req.zone, req.band, cert=req.cert)
        if not C.is_feasible():
            raise RequirementConflict(minimal_unsat_core(reqs, self.C_base))
        assert C.subset_of(self.C_base)
        self.compiled = C
        return C
```

### IP-164 AQC（噪声聚合与溯源）

```python
def aggregate_labels(annotations, max_iter=50, tol=1e-4):
    Q = {j: np.full((2, 2), 1.0) for j in annotators(annotations)}
    p = {i: 0.5 for i in segments(annotations)}
    for _ in range(max_iter):
        for j in Q:                                  # M-step: 估标注者混淆矩阵
            for i, lbl in annotations_of(j, annotations):
                Q[j][lbl, 0] += (1 - p[i]); Q[j][lbl, 1] += p[i]
            Q[j] = Q[j] / Q[j].sum(axis=1, keepdims=True)
        for i in segments(annotations):              # E-step: 聚合后验
            lik1 = np.prod([Q[j][lbl, 1] for j, lbl in annotations_of_seg(i)])
            lik0 = np.prod([Q[j][lbl, 0] for j, lbl in annotations_of_seg(i)])
            p[i] = lik1 / (lik0 + lik1 + 1e-12)
    return p, Q

def gate(p_i, tau_label=0.85):
    return "compile" if p_i >= tau_label else "arbitrate"
```

### IP-165 RAL（需求-标注闭环）

```python
def requirement_annotation_loop(M, pool):
    segs = split_evidence(M.ev_exec_log, seq_hashes=True)
    u = active_annotation_query(M.rlm, pool + segs, M.K_safe, M.budget)
    if u is None:
        return M, M.rlm.posterior, M.K_safe, "no_voi"
    labels = request_human_annotation(u)                 # Ann with hash+signature
    p_i, Q = aggregate_labels(labels)
    if gate(p_i[u.id]) != "compile":
        return M, M.rlm.posterior, M.K_safe, "arbitrate"
    M.rlm.update(u.traj, corrected=(p_i[u.id] > 0.5))
    if detect_conflict(M.rlm.posterior, M.C_base):
        return M, M.rlm.posterior, M.K_safe, "HALT_CLARIFY"
    C_req = M.a2c.compile(M.rlm.promoted_requirements(), p_i)
    M.K_safe = M.eeis.compile_on(C_req, M.delta_f_req)
    M = execute_and_record(M)                            # EPIR append
    if detect_drift(M.correction_stats):
        M.rlm.version += 1
    return M, M.rlm.posterior, M.K_safe, "ok"
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| RLM | O(\|P\|·\|R\|) / 更新 | O(\|R\| + \|D\|) | 需求召回 ≥ 80%，误判需求不进入硬约束 |
| AAL | O(\|U\|·\|R\|) / 查询 | O(\|U\|) | 达同等需求精度所需标注量 ≤ 全量 50% |
| A2C | O(\|R_H\|·poly(d)) | O(\|R_H\|) | **∀R: C_req ⊆ C_base**（构造性安全） |
| AQC | O(iter·N_ann) | O(N_ann + N_ann·\|annotators\|) | 标签后验校准误差 ECE_ann ≤ 0.05 |
| RAL | O(闭环) | 复用 | 新需求适应 ≥ 80%，冲突全部被拦截 |
| RDD | O(1) / 周期 | O(1) | 漂移检测延迟 ≤ 20 片段，误报率 ≤ 5% |

**正确性定理（RAIL）**：假设 A22–A70 成立；**(A66)** RLM 的观测模型正确刻画纠偏生成过程，且需求语法有限；**(A67)** AAL 的 VOI 估计为真实信息增益的下界；**(A68)** A2C 只执行交集与授权放宽，且 `C_base` 已认证；**(A69)** AQC 的 Dawid-Skene EM 收敛到标注者噪声的局部极大；**(A70)** RDD 的 CUSUM 在漂移前后纠偏率有正间隔。则：
1. **构造性安全**：`∀R, labels: 𝒞(R, C_base) ⊆ C_base`，标注错误只会导致过度保守，绝不会放宽执行。
2. **需求一致性**：若 `P(R|D)` 单峰且晋升条件满足，则编译后的 `K_safe` 满足被晋升的硬需求（机会约束以 `1−α` 覆盖）。
3. **冲突完备性**：若 `Feas(C_base ∩ ⋂ C_r)=∅`，RCD 必定在编译前返回非空 MUS 并阻断执行。
4. **预算安全**：任一 `B_*` 耗尽触发的降级路径均满足 `K_safe^{degraded} ⊆ K_safe^{normal}`。
5. **漂移安全**：RDD 触发的自动变更只作用于软需求；硬需求变更必须经授权，故 `C_base` 不随时间放宽。

## 4. 实验设计 E192–E197

| 实验 | 指标 | 目标 |
|---|---|---|
| E192 RLM | 需求召回率/精确率；纠偏反演对比手写字典 | 召回 ≥ 80%；新需求覆盖 +50% |
| E193 AAL | 达到目标需求精度的标注量；边界命中率 | 标注量 ≤ 全量 50%；边界命中 ≥ 70% |
| E194 A2C | 10k 条含噪标注下的约束扩张次数；保守性代价 | 扩张 = 0；性能损失 ≤ 10% |
| E195 AQC | 标签后验 ECE；标注者可靠性排序准确率 | ECE ≤ 0.05；排序 AUC ≥ 0.9 |
| E196 RAL | 新需求适应时间；冲突拦截率；vs 第 60 轮字典法 | 适应 ≤ 5 轮；拦截 100% |
| E197 RDD | 漂移检测延迟；误报率；硬需求误改次数 | ≤ 20 片段；≤ 5%；= 0 |

**消融**：去 AAL（随机标注）、去 AQC（取多数票）、去 A2C 单调性（允许放宽）三组，分别验证「标注效率」「噪声稳健」「安全单调」的贡献。

## 5. 本轮最大风险

**一句话**：若需求语法本身不完整（真实需求根本无法由 `P` 的基元组合表达），或人把「偏好」误标成「硬需求」，那么再严密的单调编译也只会把系统锁进一个**错误但自洽的约束盒**，越标注越自信、越自信越保守——因此必须用「需求可表达性审计 + 软/硬标注分离 + 冲突即停 + 漂移版本化」四重护栏，确保「洞察」不会退化为「固执」。

### IP-161 RLM（需求潜变量反演）

```python
class RequirementLatentModel:
    def __init__(self, primitives, alpha=0.05, promote_thr=0.9, k_support=3):
        self.primitives = primitives          # 基元谓词 g_p(tau)
        self.posterior = {}                   # r -> P(r|D)
        self.promote_thr, self.k_support = promote_thr, k_support

    def violation_margin(self, req, tau):
        return max(self.primitives[p](tau) for p in req.g)   # max 违反裕度

    def correction_likelihood(self, reqs, tau, beta=4.0, b=-1.0):
        m = max((self.violation_margin(r, tau) for r in reqs), default=-1e9)
        return 1.0 / (1.0 + math.exp(-beta * (m + b)))

    def update(self, tau, corrected):
        for r in self._candidate_requirements(tau):
            ll = self.correction_likelihood([r], tau)
            prior = self.posterior.get(r, self._grammar_prior(r))
            post = prior * (ll if corrected else 1.0 - ll)
            self.posterior[r] = self._normalize(post)
        self._prune_and_merge()

    def promoted_requirements(self):
        return [r for r, p in self.posterior.items()
                if p >= self.promote_thr and self._support_count(r) >= self.k_support]
```

### IP-162 AAL（主动标注）

```python
def active_annotation_query(model, pool, K_safe, budget, lambda_c=1.0):
    best, best_voi = None, 0.0
    H0 = model.entropy()
    for u in pool:
        impact = boundary_proximity(u.traj, K_safe)      # 0..1
        if impact < 0.05:
            continue
        H1 = expected_entropy_after(model, u)            # D-最优近似
        voi = (H0 - H1) * impact - lambda_c * u.cost
        if voi > best_voi:
            best, best_voi = u, voi
    if best is None or best_voi <= 0 or budget.label_quota <= 0:
        return None
    budget.label_quota -= 1
    budget.human_seconds -= best.cost
    return best
```

### IP-163 A2C（标注-约束编译）

```python
class AnnotationToConstraintCompiler:
    def __init__(self, C_base, risk_alpha=0.05, authority_table=None):
        self.C_base, self.alpha = C_base, risk_alpha
        self.auth = authority_table or {}
        self.compiled = C_base

    def compile(self, reqs, label_posteriors, relax_requests=()):
        C = self.C_base
        for r in reqs:
            if not r.is_hard:
                continue
            p = label_posteriors.get(r, r.confidence)
            if p < 1 - self.alpha:
                continue
            C = C.intersect(self.chance_constraint(r, p))   # 只做交，只收紧
        for req in relax_requests:
            if not self.authorized(req):
                raise SafetyViolation("relax requires higher authority + Cert_relax")
            C = C.relax(req.zone, req.band, cert=req.cert)
        if not C.is_feasible():
            raise RequirementConflict(minimal_unsat_core(reqs, self.C_base))
        assert C.subset_of(self.C_base)                      # 构造性安全
        self.compiled = C
        return C
```

### IP-164 AQC（噪声聚合与溯源）

```python
def aggregate_labels(annotations, max_iter=50):
    Q = {j: np.full((2, 2), 1.0) for j in annotators(annotations)}
    p = {i: 0.5 for i in segments(annotations)}
    for _ in range(max_iter):
        for j in Q:                                  # M-step
            for i, lbl in annotations_of(j, annotations):
                Q[j][lbl, 0] += (1 - p[i]); Q[j][lbl, 1] += p[i]
            Q[j] /= Q[j].sum(axis=1, keepdims=True)
        for i in segments(annotations):              # E-step
            lik1 = np.prod([Q[j][lbl, 1] for j, lbl in annotations_of_seg(i)])
            lik0 = np.prod([Q[j][lbl, 0] for j, lbl in annotations_of_seg(i)])
            p[i] = lik1 / (lik0 + lik1 + 1e-12)
    return p, Q

def gate(p_i, tau_label=0.85):
    return "compile" if p_i >= tau_label else "arbitrate"
```
