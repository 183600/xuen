# 第 1 轮（新灵感循环；承接 ToolGauge 基线；本轮灵感：「地形适应」×「竞品分析」）

> **基线继承**：前序 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440），
> 上承 **LeanGauge**（IP-310–314；定义 398–415）与 **MODGAUGE** 五不变式。
> **本轮纪律**：不推倒重来。6C 闭环、MTC/TCV、L-Box、MP-Φ/AP-Cal、TB-Contract、
> P-Quarantine、语言审计层与严格退化链全部保留；只升级两个此前被 ToolGauge 当作「给定」的东西：
> (1) **部署的异质性**：从「单一部署分布 + 全局先验 + 固定阈值」升级为「地形图 + 分层收缩 + 稳定适应」；
> (2) **判断谁更对的基准**：从「单条 cross.modal 回执 + 无基准的修复顺序」升级为「竞品竞技场 + 竞争预算」。
> 同时审计并修复第 2 轮遗留的 9 处结构性缺陷（§5）。

## 双轴映射（升级而非重写）

| 灵感词 | ToolGauge 中被当作给定的东西 | 升级为 | 一句话动机 |
|---|---|---|---|
| 地形适应 | 单一部署分布；AP-Cal 单一全局先验；γ、γ_B、ε_cross、α 为全局常数 | **G-Box 地形图 + HP-Cal 分层收缩 + ARC 稳定适应** | 同一套步态走不了所有地形；但也不能每块地重学——正确姿势是**部分池化**与**带滞回的切换** |
| 竞品分析 | V 阶段仅一条 cross.modal 回执；修复优先级由 D-Box 覆盖缺口隐式决定 | **A-Box 竞品竞技场 + C-Box 竞争预算** | 没有绝对真值时，相对劣势是最诚实的盲区信号；但相对永远不等于绝对 |
| 二者相乘 | P-Quarantine 只能事后检测「跨盲区相关偏差」，不知道偏差长在哪、先修哪 | **地形坐标 + 相对基准 + 绝对锚** | 相关误差不是随机噪声，它有地形坐标；修复顺序应由「竞争缺口 × 流量 × 严重度」决定，并由数值回执最终签发 |

**核心命题**：把 ToolGauge 的
「语义假设 → 契约工具 → 摊销校准 → 交叉验证热替换」
升级为
「**地形定位 → 地形条件假设 → 契约编译/落脚点选择 → 执行与滑移见证 → 分层摊销校准 → 绝对交叉验证 + 相对竞技场 → 稳定适应 + 局部热替换**」。
一句话：**地形解释误差为什么成片相关，竞技场回答先修哪一片；两者都只有提名权，数值真值仍由计量层独占。**

**集成链与退化方向**：MODGAUGE ⊆ LeanGauge ⊆ ToolGauge ⊆ **ArenaGauge**；失效时沿链**反向**退化。
令地形数 |𝒯|=1、对手集 ℛ=∅、ARC 关闭、C-Box 均匀分配，则 ArenaGauge ≡ ToolGauge（定义 445）。

**不变式保持声明**：
- MODGAUGE 五不变式全部保留；
- 新增 **竞技场—计量隔离不变式**（定义 442）：竞技场只能输出「优先级/假设/提名」，不得写入任何数值字段；
- 主张绑定不变式的**地形—相对扩展**（定义 444）：涉及地形或「优于/劣于某对手」的语言主张必须引用地形后验、对决回执与多样性证书，否则序列化时剥离；
- **适应单调性**：ARC 的任何切换只允许更保守（收紧闸门、降低探测强度、增大池化），不允许在证据不足时放宽安全约束（引理 54、定义 445）；
- **严格退化链延长**：ArenaGauge 失效（地形图不稳定 / 竞技场共模 / 自适应预算耗尽）⇒ ToolGauge 全局模式 ⇒ LeanGauge ⇒ MODGAUGE。

## 0. 直觉与动机

### 灵感 1（地形适应 → 部署不是一块地，而是一张「误差地形图」）

直觉：ToolGauge 的 AP-Cal 把整个部署环境当成同分布，用一个全局先验去校准所有盲区。
但真实部署像越野：瓷砖、地毯、玻璃、室外反光、坡面、不同摩擦与光照，其误差结构完全不同。
步态控制器的智慧不是「为每块地重新学走路」，也不是「用一套步态走所有地」，而是维护一张**地形图**：
按地形切换步态、用本体感觉检测打滑、在边界处保守。对应到计量层：

- **地形 = 误差同分布的区域**，不是单纯的语义标签。它的外延包括表面材质、光照、摩擦、热惯性、使用模式；
  它的内涵是「共享同一组误差统计量的状态等价类」。
- **不能每块地从零校准**：数据稀疏地形会过拟合、产生负迁移；也**不能全局一个先验**：地形间系统差异会被平均掉。
  正确姿势是**分层贝叶斯部分池化**：数据多的地形用自己的后验，数据少的地形向全局收缩，收缩强度由证据决定。
- **地形图不是一次性的**：部署中会发生地形切换、误分类、渐进漂移。需要**滑移检测**（残差 CUSUM）、
  **证书时效**、**带滞回与切换预算的适应控制器**，避免「地形抖动 → 反复热替换 → 系统churn」。
- **探测也有地形**：同一工具在不同地形上的风险、代价、信息增益不同；「在哪探测」（落脚点/foothold）
  与「探测什么」同样重要。

### 灵感 2（竞品分析 → 没有绝对真值时，用相对劣势定位盲区）

直觉：ToolGauge 的 V 阶段默认那条 cross.modal 回执「独立」，但独立从未被检验；
而修复优先级由覆盖缺口隐式决定，缺少「和谁比、差多少」的基准。
竞品分析的严谨版本不是营销式对标，而是**成对、盲测、预注册的比较实验**：

- 维护一组可执行的**对手契约**（不同预训练先验、不同传感器模态、解析物理模型、上一版本、人类基线）；
- 在匹配分层（地形 × 流量）上做**成对对决**，对手身份对 VLA 隐藏，损失函数与裕度预注册；
- 用相对劣势 `Δ_{m,r}` 的置信下界来提名「相对盲区」，用「竞争缺口 × 流量 × 严重度 / 代价」分配修复预算。

但必须写下一条硬边界：**成对比较只能识别相对差异**。
若把所有模型的误差同时加上一个共同偏差 `c(x)`，任何成对差值都不变——共模分量落在所有对比的**零空间**里。
因此竞技场可以回答「你比对手差在哪」，永远不能回答「你是否绝对正确」。
绝对正确只能由计量回执与物理锚签发；竞技场只有**提名权**，没有**批准权**。

### 灵感 3（二者相乘 → 相关误差有地形坐标，修复顺序有相对基准）

直觉：ToolGauge 的最大风险是「AP-Cal 的摊销后验在偏移下产生跨盲区强相关偏差」，
而 P-Quarantine 只是一个滞后的符号断路器。地形视角给出偏差的**坐标**：
共享地形的地形单元会同时漂移，跨地形协方差呈「低秩公共因子 + 私有噪声」。
竞技场给出偏差的**相对坐标**：在哪个地形上，哪个对手稳定地击败当前契约。
两者相乘，系统第一次能回答三个此前回答不了的问题：
(1) 这片误差是地形共同因子还是真先验缺陷？(2) 先修哪一片收益最大？(3) 修完后是否真的比对手好，而不是只比自己的旧版本好？
答案仍须由绝对回执确认——这正是「提名 vs 签发」的分工。

## 1. 形式化定义（增量：定义 432–446）

**定义 432（地形单元、地形图与共形地形集）**
设部署状态 `x ∈ X`。地形单元 `τ ∈ 𝒯` 是误差同分布等价类，由隐马尔可夫链 `z_t ∈ 𝒯` 生成：
`P(z_t=τ' | z_{t-1}=τ) = A_{ττ'}`，自转移占优（粘性），最小驻留 `T_dwell`。
发射为当前契约的标准化残差签名 `ξ_t` 与被动上下文描述子 `d(x)`（反射率、纹理、摩擦代理、热惯性、照度）。
地形图 `𝔾: x ↦ (τ̂(x), Γ(x))`，其中 `Γ(x)` 是**共形地形集**：在可交换性下
`P(τ*(x) ∈ Γ(x)) ≥ 1−β`；漂移下按引理 48 的 TV 修正降至 `1−β−2η′`。
`τ` 是统计等价类，不是语言标签；VLA 可以**提议**地形解释，但必须通过残差签名与 SNC 指纹验证（定义 425 延用），
且地形标签本身不进入数值通道。

**定义 433（地形条件契约与分层先验 HP-Cal）**
对盲区 `s`（其上下文地形为 `τ(s)`）的契约参数：
`u_s = μ_0 + η_{τ(s)} + ε_s`，`η_τ ~ N(0, Σ_τ)`，`ε_s ~ N(0, Σ_s)`。
`μ_0` 是全局先验（ToolGauge 的 MP-Φ/物理锚），`η_τ` 是地形偏移，`ε_s` 是盲区私有噪声。
观测 `y_j = u_s + ν_j`，`ν_j ~ N(0, Σ_obs)`。HP-Cal 的后验均值为**精度加权收缩**：
`û_s = W_τ·μ̂_τ + (I−W_τ)·μ̂_0`，`W_τ = (Σ_τ⁻¹ + n_τ Σ_obs⁻¹)⁻¹ (n_τ Σ_obs⁻¹)`（标量时 `w_τ = n_τ/(n_τ+κ_τ)`，`κ_τ = tr Σ_τ / tr Σ_obs`）。
跨地形协方差为 `Cov(u_s,u_{s'}) = Σ_τ`（同地形）或 `0`（异地形，除非另有共享状态），
整体呈**低秩公共因子 + 对角私有噪声**。
当 `η_τ` 不显著（Hotelling 检验 p > p_pool）时强制 `W_τ → 0`（完全池化）；
当 `n_τ ≫ κ_τ` 时 `W_τ → I`（接近独立校准）。这就是「部分池化」：**让证据决定地形该有多特殊**。

**定义 434（地形歧义与保守并集策略）**
若 `|Γ(x)| > 1` 或 `max_τ P(τ|x) < p_min`，进入**地形歧义态**：
- 闸门取候选集上的**最保守包络**：`γ_eff = max_{τ∈Γ} γ_τ`、`γ_B,eff = min_{τ∈Γ} γ_B,τ`；
- 先验取候选地形的混合 `Σ_τ∈Γ w_τ q_τ`，且协方差做**膨胀**（不允许歧义态输出更窄后验）；
- 禁止对该状态做地形专属热替换；只能使用并集包络下的全局安全策略。
**安全单调性**：地形误判只可能让约束更紧，不可能让约束更松。性能损失的上界由候选集直径控制（引理 52）。

**定义 435（计量通行性图与落脚点选择）**
对地形 `τ` 与工具 `t ∈ T₀`，维护 **通行性三元组**
`M(τ,t) = (risk(τ,t), cost(τ,t), Ĝ(τ,t))`：
`risk` 为在该地形执行该工具的物理/信息风险（打滑、反光饱和、透明失效、热扰动），
`cost` 为时间+磨损+产热，`Ĝ` 为期望信息增益。
**落脚点选择（foothold）**：在程序编译时选择
`(a,τ) = argmax UCB[ (Ĝ(a,τ) − λ_r·risk(a,τ)) / cost(a,τ) ]`，
UCB 项负责探索未充分建模的地形；若 `risk` 的置信下界超过硬阈值则**不执行**。
**步态（gait）**：同一假设在不同地形上编译为不同的工具序列模板（例如镜面地形优先 cross.modal + 变光，
透明地形优先双目基线 + 敲击），但模板只能引用预注册工具（定义 416）。
这一步把 ToolGauge 的「选什么工具」扩展为「在哪个地形、以什么顺序、用多大强度」。

**定义 436（滑移检测、地形证书与时效）**
对契约残差定义标准化量 `z_t = (y_t − ŷ_t) / sqrt(σ_pred² + σ_obs²)`。
CUSUM 统计量 `S_t = max(0, S_{t−1} + z_t − k)`；当 `S_t > h` 判定**地形滑移（slip）**：
当前地形后验、地形专属契约与修复证书立即失效，系统进入 PROBING（定义 430 延用）并重估地形或退回保守并集。
地形证书 `TerraCert(s) = (τ, d_τ, 签发时刻, 有效期, 允许漂移 Δ_d, 回执集)`：
当 `||d(x_t) − d_τ|| ≤ Δ_d` 且 `tr(P_τ) ≤ P_max` 时证书有效；否则必须重校准。
CUSUM 的阈值 `(k,h)` 由误报平均运行长度 `ARL_0` 的 SLA 反解（引理 53）。

**定义 437（稳定适应控制器 ARC 与切换契约）**
每地形维护一个策略 `π_τ ∈ Π`（池化强度、探测强度、闸门、预算分配、工具组合），
策略选择是一个**带切换代价的上下文 Bandit**。
ARC 的状态机：
- **保持**：默认沿用当前策略；
- **提议**：若候选策略相对当前策略的改进置信下界 `LCB(Δ) > h_switch` 且驻留 `> T_min`，才允许切换；
- **切换预算**：单位时间切换次数 `≤ B_switch`，超预算则只允许向**更保守**方向切换；
- **基线专家**：ToolGauge 的全局固定策略永远在策略集中，作为「永不比基线更差」的锚。
安全约束：任何切换不得放宽 `Pre_t` 的物理包络；放宽型切换必须重新走 V 阶段（定义 421.5）。

**定义 438（对手注册表与成对盲测对决）**
对手 `r ∈ ℛ` 是可执行契约：`r = (contract_r, provenance_r, version_hash_r, data_attestation_r, calibration_receipts_r)`。
对手可以是不同预训练先验、不同骨干、不同传感器模态、解析物理模型、上一版本或人类基线。
**对决协议 Duel(s, r, r′, X_duel)**：
1. 从匹配分层 `X_duel`（地形 × 流量 × 严重度）采样状态，保证对手与在位契约看到**同分布输入**；
2. 随机化评估顺序与评估通道，对手身份对 VLA 与语言层隐藏（盲测）；
3. 损失函数 `𝓁`、裕度 `δ_duel` 与样本量**预注册**，不得事后更改；
4. 每个对决由独立计量回执评估并签名，形成 `DuelReceipt = (s, r, r′, 𝓁_r − 𝓁_{r′}, sig, ts, seq)`；
5. 涉及安全谓词的对决必须使用绝对回执，不允许只靠对手间投票。

**定义 439（相对评分与相对盲区）**
用 Bradley–Terry 或成对差值估计对手强度 `θ_r`（含成对 bootstrap 置信区间）。
相对劣势 `Δ_{m,r} = E[𝓁(y,m) − 𝓁(y,r)]`。
**相对盲区** `B_rel = {(s,τ): 存在 r 使 LCB(Δ_{m,r}) > δ_duel}`。
注意：`Δ` 只度量相对差异；`θ` 只在相差一个可加常数意义下可识别（引理 55）。
相对盲区是**修复提名**，不是数值错误证明。

**定义 440（共模零空间、多样性与竞技场可信度证书）**
设各模型误差 `e_m(x) = y(x) − ŷ_m(x)`。所有成对差分为 `e_m − e_{m′}`，对任意共同分量 `c(x)` 不变：
`e_m + c − (e_{m′} + c) = e_m − e_{m′}`。因此共同偏差 `c` 落在对比矩阵的**零空间** `span{1}` 中。
**多样性证书** `DivCert(ℛ) = (provenance 独立性, 传感器/预训练共享源比例, 误差相关矩阵, 有效对手数 R_eff = 1/Σ p_r², 绝对锚覆盖率 a)`。
若共享源比例过高、`R_eff < R_min` 或 `a = 0`，竞技场只能提名，且所有「无显著差异」结论必须改写为**未知**；
若 `a > 0`，绝对锚只来自计量回执，不来自对手排名。

**定义 441（竞争预算与 C-Box）**
地形/区域的修复优先级
`P_τ = traffic_τ · max(0, LCB deficit_τ) · severity_τ / cost_τ`。
**安全覆盖**：任何含安全关键盲区的地形获得绝对优先，不参与流量加权；
**长尾下限**：每个地形至少获得 `b_min` 的修复预算，防止「只修高频、不修致命」。
C-Box 在预算 `B_repair` 下做带下限的背包/注水分配；分配结果只影响**顺序**，不影响数值校准与 V 阶段。

**定义 442（竞技场—计量隔离不变式）**
竞技场、C-Box、地形图允许输出：`priority`、`hypothesis`、`nomination`、`policy hint`。
**禁止**：直接写 `EC` 的数值字段、直接修改 `u_s`、直接批准热替换、直接把相对排名当作绝对真值。
任何由竞技场提名的修复仍须经过 H→C→E→C→V→U 全链路，其中 V 必须包含**绝对独立回执**交叉验证。
这是 MODGAUGE「主张绑定」不变式在相对信息上的扩展：**相对信息只能影响注意力，不能影响真值**。

**定义 443（ArenaGauge 七段闭环 T-H-C-E-C-V-U）**
1. **T（Terrain）**：G-Box 更新地形图，输出 `(τ̂, Γ(x))`；歧义时进入保守并集（定义 434）。
2. **H（Hypothesize）**：L-Box 在 `Γ(x)` 条件下生成共形假设集 `H_s`，SNC 过滤（定义 422/425 延用）。
3. **C（Compile）**：T-Box 按地形通行性选择工具与落脚点，编译 `Π_s`，TCV 校验（定义 416–419 延用）。
4. **E（Execute）**：逐工具执行，滑移监测并行运行；slip ⇒ 中止并转 PROBING，已执行前缀的回执仍按定义 417 校验。
5. **C（Calibrate）**：HP-Cal 以地形为条件做分层收缩，输出 `q_τ(u_s)`；保守夹紧 `Σ ≽ κ_phys I` 保留。
6. **V（Verify）**：绝对交叉验证（未参与拟合的独立回执）+ 地形一致性检验 + 竞技场**咨询性**比较；
   只有绝对验证通过才允许进入 U；竞技场只能降低/提高优先级，不能替代验证。
7. **U（Update）**：局部热替换 + 更新地形后验/策略 + 绑定语言修复证书（定义 427/444 延用）。

**定义 444（地形—相对语言主张绑定）**
EC 的 `claims` 字段扩展两类主张：
- **地形主张**（「在地形 τ 上参数为 …」）必须引用：`TerraCert`、至少一条未参与拟合的绝对回执、地形后验；
- **相对主张**（「本契约优于对手 r」）必须引用：`DuelReceipt`、`DivCert`、以及预注册的损失与裕度。
无引用、引用无效、或 `DivCert` 失效的相对主张在序列化时剥离；剥离是纯投影，不改变数值行为。

**定义 445（严格退化与等价性证明义务）**
退化条件与目标：
- 地形图不可用 / 滑移率超 SLA / `|Γ|` 持续 > 1 ⇒ 令 `|𝒯|=1`，退回 ToolGauge 全局 AP-Cal；
- 对手集为空 / 共模审计失败 / `R_eff < R_min` ⇒ 关闭 A-Box，修复顺序退化为 D-Box 覆盖缺口 + 安全优先；
- ARC 预算耗尽 / 切换震荡 ⇒ 冻结为 ToolGauge 固定保守策略；
- HP-Cal 收缩不一致或地形样本不足 ⇒ 退化为 AP-Cal 全局校准。
**等价性**：令 `|𝒯|=1`、`ℛ=∅`、ARC 关闭、C-Box 均匀分配，则定义 432–444 退化为定义 416–431，ArenaGauge ≡ ToolGauge。
退化只允许更保守：减少探测、收紧包络、增大池化；绝不允许放宽 `Pre_t` 或跳过 V。

**定义 446（联合预算契约 AB-Contract）**
`AB = (B_tools, B_duel, B_switch, B_repair, τ_repair, recovery)`：
单盲区工具预算、竞技场对决预算、策略切换预算、修复总预算、修复时延上限、恢复条件。
地形更新、对决、分层校准、ARC 全部异步于 50Hz 路径；50Hz 周期只做缓存策略指针读取 `O(1)`。
预算是**硬顶**：任何一项耗尽 ⇒ 按定义 445 降级，不允许「借预算赌博」。

```python
# IP-321 G-Box：地形图 + 共形地形集 + 保守并集
class GBox:
    def update(self, x, residual):
        self.hmm.step(residual)                       # 粘性 HMM，最小驻留 T_dwell
        return self.hmm.posterior()

    def terrain_set(self, x, alpha_beta=0.05):
        return conformal_set(self.cal, featurize(x), beta=alpha_beta)   # 定义 432

    def conservative(self, gamma_set):
        if len(gamma_set) > 1:                        # 定义 434：歧义态
            return dict(gamma=max(g["gamma"] for g in gamma_set),
                        gamma_B=min(g["gamma_B"] for g in gamma_set),
                        prior=inflate(mixture(gamma_set)))
        return gamma_set[0]

# IP-322 HP-Cal：地形条件分层收缩
class HPCal:
    def calibrate(self, receipts, s, terrain_post):
        mu0, S0 = self.global_prior(s)                # ToolGauge 的 MP-Phi / 物理锚
        num = np.zeros_like(mu0); den = np.zeros_like(S0)
        for tau, w in terrain_post.items():
            m, S = self.terrain_posterior(tau, s, receipts)
            P = np.linalg.inv(S0 + S)                 # 精度加权
            num += w * (P @ m); den += w * P
        mu = np.linalg.solve(den, num)
        Sig = clamp_min(np.linalg.inv(den), KAPPA_PHYS)  # 保留保守夹紧
        return mu, Sig

    def consistency_test(self, tau, receipts, p_pool=0.05):
        # Hotelling：地形偏移不显著则强制池化（定义 433）
        return hotelling_p(self.terrain_offsets(tau), receipts) > p_pool

# IP-323 ARC：带滞回与切换预算的稳定适应
class ARC:
    def propose(self, terrain, stats):
        cand = self.policy_class(terrain)
        cur  = self.current[terrain]
        if self.switches_left <= 0: return cur
        best = max(cand, key=lambda p: p.lcb_gain(stats))
        if (best.lcb_gain(stats) > self.h_switch
                and stats.dwell > self.T_min):
            self.switches_left -= 1
            return best                            # 定义 437
        return cur

    def safe_apply(self, old, new, env):
        if new.relaxes(old):                       # 放宽型切换必须重走 V
            return self.revalidate(new, env)
        return new

# IP-324 A-Box：对手注册、成对盲测、相对盲区
class Arena:
    def duel(self, m, r, strata):
        X = matched_sample(strata)                 # 地形 x 流量 x 严重度匹配
        order = randomize_order(X)                 # 盲测：对手身份对 VLA 隐藏
        l = [(loss(m, x, self.receipt(x)), loss(r, x, self.receipt(x)))
             for x in order]
        return signed_duel_receipt(m, r, l)        # 定义 438

    def relative_blind_spots(self, m, delta):
        out = []
        for r in self.rivals:
            d = paired_deficit(self.duels(m, r))
            if d.lcb > delta: out.append((r, d))   # 定义 439
        return out

    def cert(self):
        return DivCert(self.provenance, self.error_corr,
                       R_eff=1 / sum(p * p for p in self.shares),
                       anchor_coverage=self.anchor_cov)   # 定义 440

# IP-325 C-Box：竞争预算（安全覆盖 + 长尾下限）
class CBox:
    def allocate(self, blind_spots, B, traffic, severity, gaps):
        prio = {s: traffic[s] * max(0, gaps[s]) * severity[s] / cost[s]
                for s in blind_spots}
        safety = {s for s in blind_spots if is_safety_critical(s)}
        return water_fill(prio, B, must=safety, floor=b_min)

# IP-326 ArenaGauge：七段闭环
def arena_gauge_repair(M, s):
    tau, Gamma = M.gbox.map(M.context(s))                 # T
    gates = M.gbox.conservative([M.policy[t] for t in Gamma])  # 定义 434
    H = M.lbox.hypothesize(s, M.dbox.R[s], terrain=Gamma)    # H
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s),
                         traversability=M.gbox.traversability(tau))  # C（含落脚点）
    prog = [c for c in prog if not M.gbox.risk_veto(c, Gamma)]
    receipts = M.tcv.execute(prog, M.env, slip_watch=M.slip) # E
    if M.slip.triggered(s): return probing_and_reestimate(s) # 定义 436
    if len(receipts) < M.hpcal.n_min(s, tau): return stub_and_red(s, "insufficient")
    mu, Sig = M.hpcal.calibrate(receipts, s, M.gbox.posterior(s))  # C
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):    # V：绝对锚
        mu, Sig = M.apcal.calibrate(receipts, ["UNKNOWN"], s)
        if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
            return stub_and_red(s, "cross_failed")
    # 竞技场只提供咨询：差于对手则提高优先级，不得替代 V
    M.arena.note_repair(s, M.arena.relative_blind_spots(M.current, DELTA))
    new_ec = M.hpcal.update_contract(M.dpe, mu, Sig, s, tau)
    if not contract_regression(new_ec): return stub_and_red(s, "regression")
    M.mreg.hot_replace(M.dpe, new_ec)
    M.gbox.update_certificate(s, tau, receipts)            # TerraCert
    M.arc.propose_and_apply(tau, M.stats)                  # 稳定适应（异步）
    bind_claims(new_ec, H, prog, receipts, tau, M.arena)   # 定义 444
    return True

def ArenaGauge_round(M, obs, audio, tac, depth, det):
    M.gbox.online_update(obs, depth, audio)                # 异步，50Hz 外
    if M.slip.sla_violated() or M.arena.common_mode_alert():
        M.enter_global_mode()                              # 定义 445 退化
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s); submit_async(arena_gauge_repair, M, s)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)  # 主控不动
```

## 3. 推导

**引理 51（分层收缩的自适应风险界）**
在定义 433 的高斯分层模型下，设 `R_pool`、`R_sep` 分别为完全池化与完全独立校准的每地形风险，
`κ_τ = tr Σ_τ / tr Σ_obs`，`N = Σ_τ n_τ`。则 HP-Cal 的后验均值满足（至多相差常数因子）
`R_hier ≤ min(R_pool, R_sep) + O(d_u log|𝒯| / N)`。
稀疏地形 `n_τ ≪ κ_τ` 时 `w_τ → 0`，行为趋近池化；稠密地形 `n_τ ≫ κ_τ` 时 `w_τ → 1`，行为趋近独立校准。
**证明思路**：经验贝叶斯/James–Stein 收缩；先验方差由矩估计或分层证据下界估计；二次损失的偏差—方差分解。
系：只要地形偏移的总体方差有界，部分池化不会产生无界负迁移；显著地形通过一致性检验后自动获得独立校准。

**引理 52（地形歧义的保守安全界）**
设共形地形集覆盖率 `P(τ* ∈ Γ) ≥ 1−β`。在定义 434 的保守并集策略下：
(a) 新增安全约束违反概率为 0（并集只会收紧闸门）；
(b) 当 `τ* ∈ Γ` 时，性能相对 oracle 地形的损失 `≤ L_Γ · diam(Γ)`，其中 `L_Γ` 是性能对地形参数的 Lipschitz 常数；
(c) 总期望损失 `≤ β·R_max + (1−β)·L_Γ·diam(Γ)`。
**证明思路**：(a) 逐坐标取 max/min 的单调性；(b)(c) Lipschitz 与全概率公式。
系：地形误判的代价被限制在**性能**通道，不进入**安全**通道；这与「竞技场只有提名权」是同一条隔离纪律。

**引理 53（滑移检测的误报—延迟权衡）**
对 CUSUM `S_t = max(0, S_{t−1}+z_t−k)`、阈值 `h`：
在无滑移下平均运行长度 `ARL_0 ≥ exp(2kh)/(2k²)`（Lorden 型下界）；
在标准化漂移 `δ > k` 下，检测延迟 `E[τ_d] ≤ h/(δ−k) + O(1)`。
**系**：给定滑移误报 SLA `ARL_0 ≥ A`，取 `h ≈ log(2A k²)/(2k)`；
在延迟上界内系统保持当前证书，但延迟超过 `T_slip` 则强制进入 PROBING；滑移期间禁止热替换。

**引理 54（ARC 的无遗憾与安全切换）**
设策略集大小 `K`、总轮数 `T`、切换预算 `S`、基线专家为 ToolGauge 固定策略。
采用「LCB 改进 > h_switch 才切换」的带滞回 Bandit，则：
(a) 期望遗憾 `Regret_T ≤ O(√(T K log K) + S·s_switch)`；
(b) 切换次数 `≤ S`；
(c) 以概率 `1−δ`，任何切换发生前其真实改进的 LCB 为正，故累计性能不低于基线的 `O(√(T log(1/δ)))` 邻域；
(d) 放宽型切换必须重走 V，故安全约束不被适应过程放宽。
**证明思路**：带切换代价的 EXP3/UCB 分析 + 置信下界的事件分解 + (d) 由定义 437 的 safe_apply 强制。
系：地形适应可以「越用越好」，但不能「越适应越冒险」，也不能无限抖动（预实验 C：切换次数 52 → 5.1）。

**引理 55（成对比较的零空间与共模不可识别）**
设有 `M` 个模型，误差向量 `e(x) ∈ R^M`。任意成对比较统计量只依赖对比矩阵 `P e`，
其中 `P` 的零空间为 `span{1}`。因此：
(a) 对任意共同偏差 `c(x)`，所有对决结果、Bradley–Terry 评分、相对盲区集合**完全不变**；
(b) 仅凭成对比较，无法区分「所有模型都正确」与「所有模型共享同一偏差」；
(c) 若绝对锚覆盖率为 `a`，绝对误差的可辨识上界至少为 `(1−a)·prior_error`；`a=0` 时不可辨识。
**证明思路**：`P(e+c1)=Pe`；对比矩阵秩为 `M−1`；可辨识性要求至少一个绝对参照。
系：**「击败所有对手」不等于「正确」**；竞技场必须与绝对计量锚同时使用，且不得签发数值真值。
（预实验 B：加共同偏差 5 后，成对胜率相关 = 1.0000，绝对 |loss| = 5.000。）

**引理 56（竞技场隔离保持热替换等价性）**
A-Box/C-Box/ARC 只改变调度、优先级、假设与策略指针，不写 `EC` 数值字段；
HP-Cal 的地形条件参数只有在 V 阶段绝对交叉验证通过后才允许进入 `EC`；
地形歧义态使用保守并集，不产生新的数值自由度。
因此子图数值等价性同 ToolGauge 引理 49；`claims` 剥离仍是纯投影；退化链保持。
系：新增的两个灵感轴不破坏 MODGAUGE 五不变式。

**引理 57（时序与预算保持）**
G-Box、HP-Cal、A-Box、C-Box、ARC 全部异步于 50Hz 计量路径；
50Hz 周期新增开销仅为缓存策略指针与地形标签读取 `O(1)`（实测目标 < 0.1ms）；
对决与地形更新受 `AB-Contract` 硬预算约束；预算耗尽按定义 445 降级。
故 ToolGauge 引理 50 的硬实时与预算不变式保持。

## 6. 本轮最大风险（一句话）

**一句话**：竞技场的「对手」可能共享同一预训练骨干、同一传感器套件、同一地形误分类器，
于是「击败所有对手」只是一种**共模竞技幻觉**——所有模型一起错、相对排名却互相背书，
而地形适应又会把这种共同偏差按地形放大并固化成看似可信的证书；
因此 ArenaGauge 必须始终保留绝对计量锚，并让竞技场只提名、不签发。

**次级风险与缓解**：
1. **共模对手** → DivCert + 共享源审计 + 绝对锚覆盖率 `a`；`a=0` 时禁止任何「无显著差异」结论（引理 55）；
2. **地形误判** → 共形地形集 + 保守并集 + 只在单元素集上做地形专属热替换（引理 52）；
3. **负迁移** → 分层收缩的一致性检验 + 基线专家 + 安全切换（引理 51/54）；
4. **地形适应抖动/churn** → 滞回 + 最小驻留 + 切换预算（预实验 C：52 → 5.1 次）；
5. **竞技场被博弈** → 对手 provenance/版本签名、预注册损失、盲测、对决回执签名（定义 438）；

## 2. 形式化定义（要点）

**定义 432（地形图）** 地形是误差同分布等价类，由粘性 HMM 生成；地形图输出 `(τ̂, Γ(x))`，
`P(τ*∈Γ) ≥ 1−β`。地形标签不是语言标签，VLA 只能提议、必须通过残差签名与 SNC 验证。
**定义 433（HP-Cal）** `u_s = μ_0 + η_τ + ε_s`，`η_τ ~ N(0,Σ_τ)`；
后验为精度加权收缩 `û_s = W_τ μ̂_τ + (I−W_τ) μ̂_0`；Hotelling 不显著 ⇒ 强制池化；
`n_τ ≫ κ_τ` ⇒ 接近独立校准。跨地形协方差呈低秩公共因子 + 对角私有噪声。
**定义 434（歧义保守并集）** `|Γ|>1` 或后验置信不足时：`γ_eff = max γ_τ`、`γ_B,eff = min γ_B,τ`、
先验混合并膨胀协方差、禁止地形专属热替换。安全只收紧、不放松。
**定义 435（通行性与落脚点）** `M(τ,t)=(risk,cost,Ĝ)`；选 `argmax UCB[(Ĝ−λ_r·risk)/cost]`；
风险下界超阈值则不执行；不同地形编译不同工具模板（步态），但只引用预注册工具。
**定义 436（滑移与地形证书）** CUSUM `S_t=max(0,S_{t−1}+z_t−k)`，`S_t>h` ⇒ slip：证书失效、进入 PROBING、重估地形。
证书在描述子漂移 `≤Δ_d` 且后验协方差 `≤P_max` 时有效。
**定义 437（ARC）** 策略切换需 `LCB(Δ)>h_switch` 且驻留 `>T_min`，受 `B_switch` 限制；
ToolGauge 固定策略永远是基线专家；放宽型切换重走 V。
**定义 438（竞技场）** 对手 = 可执行契约 + provenance + 版本哈希 + 数据声明 + 校准回执；
对决必须匹配分层、随机化、盲测、预注册损失与裕度、独立回执签名。
**定义 439（相对盲区）** Bradley–Terry/成对差值；`B_rel = {LCB(Δ_{m,r}) > δ_duel}`；只是修复提名。
**定义 440（共模零空间与 DivCert）** 成对差分对共同偏差不变，共同分量在对比矩阵零空间 `span{1}`；
`DivCert` 记录共享源、误差相关、`R_eff`、绝对锚覆盖率 `a`；`a=0` 时禁止绝对/无差异结论。
**定义 441（C-Box）** `P_τ = traffic·max(0,LCB deficit)·severity/cost`；安全地形绝对优先；
每地形 `b_min` 预算下限；只影响顺序。
**定义 442（竞技场—计量隔离）** 竞技场只输出 priority/hypothesis/nomination/policy hint；
禁止写 EC 数值字段、禁止直接批准热替换、禁止把相对排名当绝对真值。
**定义 443（七段闭环）** T→H→C→E→C→V→U；V 含绝对独立回执 + 地形一致性 + 竞技场咨询；
只有绝对验证通过才进入 U。
**定义 444（地形—相对主张绑定）** 地形主张引用 TerraCert + 绝对回执 + 地形后验；
相对主张引用 DuelReceipt + DivCert + 预注册损失；否则剥离。
**定义 445（严格退化与等价）** 四类退化条件；`|𝒯|=1、ℛ=∅` 时严格退化为 ToolGauge；退化只允许更保守。
**定义 446（AB-Contract）** 工具/对决/切换/修复四类硬预算；新计算全部异步，50Hz 只读缓存指针。

## 3. 关键算法骨架

```python
# IP-321 G-Box：地形图、共形集、保守并集
class GBox:
    def update(self, x, residual):
        self.hmm.step(residual)                                  # 粘性 HMM
        return self.hmm.posterior()
    def terrain_set(self, x, beta=0.05):
        return conformal_set(self.cal, featurize(x), beta)       # P(tau* in Gamma) >= 1-beta
    def conservative(self, policies):
        if len(policies) == 1: return policies[0]
        return Policy(gamma=max(p.gamma for p in policies),
                      gamma_B=min(p.gamma_B for p in policies),
                      prior=inflate(mixture([p.prior for p in policies])))
    def traversability(self, tau):
        return self.M[tau]                                       # (risk, cost, info_gain)

# IP-322 HP-Cal：分层收缩（精度加权）
class HPCal:
    def calibrate(self, receipts, s, terrain_post):
        mu0, S0 = self.global_prior(s)
        num = np.zeros_like(mu0); den = np.zeros_like(S0)
        for tau, w in terrain_post.items():
            m, S = self.terrain_posterior(tau, s, receipts)
            P = np.linalg.inv(S0 + S)
            num += w * (P @ m); den += w * P
        mu = np.linalg.solve(den, num)
        return mu, clamp_min(np.linalg.inv(den), KAPPA_PHYS)

# IP-323 ARC：安全切换
class ARC:
    def propose(self, tau, stats):
        if self.switches_left <= 0: return self.current[tau]
        best = max(self.policy_class(tau), key=lambda p: p.lcb_gain(stats))
        if best.lcb_gain(stats) > self.h_switch and stats.dwell > self.T_min:
            self.switches_left -= 1; return best
        return self.current[tau]
    def apply(self, old, new, env):
        return self.revalidate(new, env) if new.relaxes(old) else new

# IP-324 A-Box：成对盲测与相对盲区
class Arena:
    def duel(self, m, r, strata):
        X = matched_sample(strata)                # 地形 x 流量 x 严重度
        X = blind_randomize(X)                    # 对手身份对 VLA 隐藏
        diffs = [loss(m, x, receipt(x)) - loss(r, x, receipt(x)) for x in X]
        return signed_duel_receipt(m, r, diffs)
    def relative_blind_spots(self, m, delta):
        return [(r, d) for r in self.rivals
                if (d := paired_deficit(self.duels(m, r))).lcb > delta]
    def cert(self):
        return DivCert(self.provenance, self.error_corr,
                       R_eff=1 / sum(p*p for p in self.shares),
                       anchor_coverage=self.anchor_cov)

# IP-325 C-Box：安全覆盖 + 长尾下限
def allocate(spots, B, traffic, severity, gaps):
    prio = {s: traffic[s] * max(0, gaps[s]) * severity[s] / cost[s] for s in spots}
    must = {s for s in spots if safety_critical(s)}
    return water_fill(prio, B, must=must, floor=b_min)

# IP-326 七段闭环
def arena_gauge_repair(M, s):
    tau, Gamma = M.gbox.map(M.context(s))                       # T
    gates = M.gbox.conservative([M.policy[t] for t in Gamma])
    H = M.lbox.hypothesize(s, M.dbox.R[s], terrain=Gamma)        # H
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s),
                         M.gbox.traversability(tau))             # C
    receipts = M.tcv.execute(prog, M.env, slip_watch=M.slip)     # E
    if M.slip.triggered(s): return probing_and_reestimate(s)
    if len(receipts) < M.hpcal.n_min(s, tau): return stub_and_red(s, "insufficient")
    mu, Sig = M.hpcal.calibrate(receipts, s, M.gbox.posterior(s))  # C
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):    # V：绝对锚
        mu, Sig = M.apcal.calibrate(receipts, ["UNKNOWN"], s)
        if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
            return stub_and_red(s, "cross_failed")
    M.arena.note_repair(s, M.arena.relative_blind_spots(M.current, DELTA))
    new_ec = M.hpcal.update_contract(M.dpe, mu, Sig, s, tau)
    if not contract_regression(new_ec): return stub_and_red(s, "regression")
    M.mreg.hot_replace(M.dpe, new_ec)
    M.gbox.update_certificate(s, tau, receipts)
    M.arc.propose_and_apply(tau, M.stats)                        # 异步
    bind_claims(new_ec, H, prog, receipts, tau, M.arena)          # 定义 444
    return True
```

## 4. 推导（引理 51–57）

**引理 51（分层收缩自适应界）** `R_hier ≤ min(R_pool,R_sep)+O(d_u log|𝒯|/N)`；
稀疏地形趋近池化，稠密地形趋近独立校准；有界地形方差下无无界负迁移。
**引理 52（地形歧义保守界）** 保守并集不新增安全违反；`τ*∈Γ` 时性能损失 `≤L_Γ·diam(Γ)`；
总损失 `≤βR_max+(1−β)L_Γ diam(Γ)`。误判只伤性能，不伤安全。
**引理 53（滑移检测）** 无滑移 `ARL_0 ≥ exp(2kh)/(2k²)`；漂移 `δ>k` 时延迟 `≤h/(δ−k)+O(1)`；
给定误报 SLA 可反解 `h`；滑移期间禁止热替换。
**引理 54（ARC）** 遗憾 `≤O(√(TK log K)+S·s_switch)`；切换次数 `≤S`；
以 `1−δ` 概率不劣于基线专家；放宽型切换重走 V ⇒ 适应不放宽安全。
**引理 55（共模零空间）** 成对对比矩阵秩 `M−1`，零空间 `span{1}`；共同偏差不可识别；
「击败所有对手」≠「正确」；`a=0` 时绝对误差不可辨识。竞技场只能提名。
**引理 56（隔离保持等价）** 竞技场/C-Box/ARC 不改数值字段；HP-Cal 参数须经 V 才入 EC；
歧义态用保守并集；子图数值等价性同 ToolGauge 引理 49；claims 剥离为纯投影。
**引理 57（时序预算）** 新计算全异步；50Hz 只读缓存指针 `O(1)<0.1ms`；CUSUM `<0.05ms`；
对决/地形更新受 AB-Contract 硬顶；预算耗尽按定义 445 降级 ⇒ 硬实时保持。

| 1 | 1.007 | 0.995 | **0.532** | **+46.6%** |
| 2 | 0.971 | 0.499 | **0.341** | **+31.6%** |
| 4 | 0.956 | 0.249 | **0.203** | **+18.5%** |
| 8 | 0.948 | 0.124 | **0.112** | **+10.0%** |

结论：稀疏地形上分层收缩显著优于「全局」与「独立」两种极端，且随样本增多自动趋近独立校准——与引理 51 一致。

**B. 共模不变性（R=6，N=4000，共同偏差 b=5）**
- `corr(成对胜率 | b=0, 成对胜率 | b=5) = 1.0000`；
- 绝对平均损失 `|loss| = 5.000`，竞技场完全不可见；
- 最优模型选择一致率 `100.0%`。
结论：成对比较对共同偏差严格不变——「击败所有对手」不等于「正确」，验证引理 55。

**C. 适应 churn（4000 tick，两臂缓慢交替，窗口 50）**
- 朴素「谁当前均值高就切」：平均切换 **52.0** 次；
- 带 `h=0.5` 滞回：平均切换 **5.1** 次。
结论：滞回 + 最小驻留可将 churn 降一个数量级，支撑定义 437/引理 54。

## 9. 本轮最大风险

**一句话**：竞技场的对手可能共享同一预训练骨干、传感器套件与地形误分类器，
使「击败所有对手」成为**共模竞技幻觉**——所有模型一起错、相对排名互相背书，
地形适应再把共同偏差按地形放大并固化成看似可信的证书；唯一兜底是始终保留绝对计量锚，
并让竞技场只提名、不签发。
