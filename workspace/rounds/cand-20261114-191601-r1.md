# 第 75 轮（承接第 74 轮「SENTGAUGE-RAS 哨兵审计闭环」IP-303~309；灵感循环第 1 轮；本轮灵感：「柔顺控制」×「原型验证」）

> R74 把审计做成 anytime-valid 哨兵，把 R73 的「自信地组合一个错误世界」改造成「诚实地发现并退出错误世界」。但 R71–R74 的退化链末端始终是**软件语义**：stub = 不产生证据、u=∞、否决一切、冻结/停机。这个末端在**物理接触**下是空的——位置控制的刚性臂在接触中「冻结」会持续累积接触力并可能违反力/能量约束；而所有上层安全界（定理 24/28/31）都仍以「契约表达力 + 分布内」为前提，一旦模型全错，系统**没有任何不依赖模型正确性的物理下界**。同时，R71–R74 的 397 个定义、C1–C4、E1–E410 从未作为**一个整体**被端到端证伪：组件基准可以全绿，而组合系统失败（定义-实验漂移、集成债、真值循环、sim2real 间隙）。本轮两个灵感正好补这两个结构性缺口，而且互为前提。
>
> - **柔顺控制** → **CIM（Compliance-Interaction Metrology）**：把力/能量证据与阻抗状态纳入计量契约。柔顺不是控制参数，而是**三合一增益**——同时决定力风险、接触信息增益与扰动吸收。由此得到 **χ_K 刚度反作用通道**（与 χ_v/χ_obj 同构）、**CP 柔顺-信息权衡**（更硬更准但更危险，存在 Pareto 前沿）、**KAP 主动柔顺探测**（用受控刚度换取可辨识性，是 PVOP 的对偶）。更关键的是 **EPT 能量罐 + 被动性证书**：它给出一个**只依赖能量记账与硬件无源性、不依赖任何证据契约**的力/能量上界；被动性在串/并联与 VETO 下封闭，构成与 CCA 平行但更硬的**物理安全代数**。退化链末端由此从「软件 stub」升级为 **PS 物理 stub（变软、增阻尼、限力、被动撤退）**——「柔顺」成为最后一道安全层。
> - **原型验证** → **MFP（Minimum Falsification Prototype）+ VEC（Validation Evidence Contract）+ EDC（Executable Definition Closure）+ STAGE（G0–G3 分级门）**。验证本身也是证据计量：每条主张必须绑定最小可证伪原型、预注册指标、**有效性威胁预算**（构念/内部/外部/统计四类，非补偿合取）；每个被主张引用的定义必须编译成可执行检查，否则标为 PROSE、不得进入认证路径；端到端 **tracer-bullet slice** 对组件级「全绿」拥有**证伪优先权**，因为**有效性不可组合**（这是与不确定度组合单调性相反的一条元定理）。
>
> 两块灵感的交汇点是本轮核心命题：**安全需要两个此前缺失的支点——一个是不依赖模型正确性的物理安全地板（柔顺/被动性），另一个是可安全失败、端到端可证伪的参考原型；前者使后者在伦理与工程上可行，后者使前者与全部上层主张可被检验。** 把 SENTGAUGE 重构为 **COMPGAUGE-RAS**（COMPliance-grounded, Prototype-validated, GAuged evidence metrology for RAS）——**柔顺基座 × 原型证伪的计量契约代数**。
>
> IP 编号：IP-317~323。理论姿态延续：**物理地板是旧安全界的严格增强（无源退化为软件 stub），验证层是旧主张包的可证伪化（无原型退化为 C1–C4 的声明域）；安全侧只增不减，退化链逐指令等价。**

## 0. 直觉与动机

**灵感 1（柔顺 = 把认知误差换成有界机械功）**
直觉：刚性位置控制把机器人当成「理想约束」，它不管世界是什么样都坚持自己的位姿；于是模型对世界的一点点错误都会变成很大的接触力。柔顺控制把机器人变成「可编程弹簧」：世界几何估计错了，弹簧只是被压缩，力仍然有界。所以**柔顺性把认知不确定性转译成有界的机械功**，用位置权威换安全裕度。严格的对应物是**无源性（passivity）**：若控制器满足能量罐守恒 `Ṫ = -P_cmd + P_ext`、`T ≥ 0`，则向环境输出的总机械功不超过罐容量 `∫|F·v|dt ≤ T(0)`（被动环境下），且该结论**不使用任何噪声模型或分布假设**。这正是 R74 最大风险（声明族先验/校准集代表性）所缺的「模型无关底」。

**灵感 2（刚度是三合一增益 → 柔顺-信息权衡）**
直觉：刚度 `K_r` 同时是控制增益（决定跟踪）、安全裕度（峰值力 ∝ K_r·δ）与测量增益（SEA/力传感器把力读成位移，`δ̂ = F/K_r`，信息 ∝ K_r²/σ_F²）。于是「更硬更准但更危险、更软更安全但更瞎」不是调参现象，而是**结构性的 Pareto 权衡**。一维线性接触下可写清：为安全分辨最小错位 `δ`，必须 `K_r ≤ F_max/δ`；故接触定位 Fisher 信息上界 `≤ F_max²/(δ²σ_F²)`——**力预算除以错位尺度**。这意味着不存在同时任意高精度、任意低接触力的固定刚度控制器；但**时变刚度**（接近期软、探测期硬）可以优于任何固定刚度——这就是 KAP。

**灵感 3（被动性是可组合的物理代数）**
直觉：无源子系统在串/并联与反馈互联下仍无源，能量罐在互联下按功率守恒相加。这与 R73 的 CCA 形状完全一致，但对象是**能量而非不确定度**，且**不引用证据契约**。于是我们可以把「物理安全」从「审计出来的软件性质」变成「由物理与能量记账保证、可组合的硬性质」：即使所有证据模块同时失效、所有哨兵都 RED、所有声明族都选错，能量罐仍然把伤害限在 `E_tank` 与 `F_max` 内。这是本轮最重要的结构性收获。

**灵感 4（物理 stub：退化链末端必须有物理语义）**
直觉：R74 的 stub 让证据消失，但没说机器人**身体怎么办**。在接触中，「不动」可能比「动」更危险（环境在动、力在积累）。正确的末端不是冻结，而是**变柔顺**：`K_r→K_min`、`D_r→D_max`、`F_max→F_low`、限功率、被动慢撤退。这个 PS 是可证无源的，因此安全不再依赖「证据是否还在契约内」。物理 stub 与软件 stub 组合：软件 stub 负责「不采信」，物理 stub 负责「不伤人」。

**灵感 5（原型 = 可校准的证伪仪器，而不是 demo）**
直觉：原型验证常被做成「跑通即成功」的 demo，这是**构造效度**灾难。正确姿势是 **tracer bullet / walking skeleton**：一条很薄但**端到端**的切片，串起所有主张的关键路径，用预注册指标判定通过/失败。关键定理式观察：**有效性不可组合**——存在「每个组件都通过各自基准、组合系统却失败」的构型（定义-实验漂移、接口语义丢失、真值循环、sim2real 间隙）。因此端到端切片的**失败对组件级全绿拥有否决权**（证伪优先），这与 R73「不确定度组合只能变差」是两套相反方向的代数：不确定度单调、有效性非组合。

**灵感 6（验证 = 带威胁预算的证据计量）**
直觉：每个实验都有四类威胁——构念（测的是不是想测的）、内部（因果是否被混杂）、外部（能否外推）、统计（样本/多重比较）。把它们做成 **VEC 的威胁预算**：每类威胁声明最大效应膨胀因子，按最坏情况**非补偿**合取（像 VETO，不允许「外部效度差但 p 值好」来补偿）。同时 **EDC** 要求：凡被主张引用的定义必须编译成对日志的可执行谓词，否则降级为 PROSE 并移出认证路径——这直接回应「397 个定义到底有几个能被检验」。

**灵感 7（两灵感的交汇：地板使证伪可行）**
直觉：端到端证伪试验会故意把系统推到失效边界（注入传感器失效、对抗证据、超域接触）。若没有物理安全地板，这类实验在伦理与工程上不可做，于是主张永远停在「组件级仿真全绿」。**柔顺/被动性地板是原型作为证伪仪器的前置条件**：只有失败被物理地限制住，才敢测试到失败。这是本轮把两个灵感绑成一个方案而不是两个补丁的原因。

## 1. 形式化定义（增量：定义 398–412）

**定义 398（COMPGAUGE-RAS 总览）** COMPGAUGE-RAS = (CIM, EPT, KAP, MFP, VEC, EDC, STAGE, SENTGAUGE†)。七不变式：
(i) **契约完整性**（继承 R73 定义 366(i)）；
(ii) **组合单调性**（继承引理 34）；
(iii) **反作用通道完备**（继承定义 371，扩展 χ_K，定义 401）；
(iv) **主张绑定**（继承定义 374，扩展 C5/C6，定义 412）；
(v) **物理地板**：每条控制律必须挂接 EPT 被动性证书（定义 402），否则不得进入控制域；
(vi) **可证伪性**：每条主张的每个被引用定义必须通过 EDC（定义 409）或标 PROSE；
(vii) **验证门序**：主张只有在 STAGE（定义 410）对应级别通过后才可提升，未过门的主张不得进入正文结论。

**定义 399（柔顺契约 CC）** CC = (K_r(t), D_r(t), M_r, F_max, P_max, E_tank, χ_K, D_c, seal_ref)：
- `K_r, D_r, M_r`：阻抗/导纳参数（刚度、阻尼、惯量），可在控制域按调度改变；
- `F_max, P_max`：力与功率硬上限（写入控制域 RTA，越界即饱和并触发 PS）；
- `E_tank`：能量罐容量与当前储量；
- `χ_K: 𝒢 × X → Θ_force × D′`：刚度反作用通道（定义 401）；
- `D_c`：接触模式有效域（自由/接触/冲击/滑移/人机共融）；
- `seal_ref`：SEAL-Force / SEAL-Passivity 密封审计集。
柔顺契约是**物理执行契约**，与证据契约 EC 平行；两者在 MReg 中通过边耦合，但 EPT 的保证不读取 EC。

**定义 400（交互力证据计量 CIM）** 观测 `y_F = (F/T 六维, 关节力矩, SEA 形变, 阻抗状态, 接触模式)`。条件似然
`p_F(y_F | s, c, κ_c, m) = 𝒩(y_F; h_F(s, c, κ_c, m), Σ_F(s, c, κ_c, m))`，
七分量：
`u_force² = u_bias² + u_noise² + u_dyn² + u_fric² + u_sat² + u_geom² + u_thermal²`
（零点偏置 / 电噪声 / 惯性-科氏动态误差 / 摩擦迟滞 / 饱和削顶 / 接触几何（力作用点/面）不确定 / 温漂）。每个分量独立追溯链 `τ_F,i`。有效域 `D_F = {|F|≤F_max} ∧ {非饱和} ∧ {c 在已标定模式集} ∧ {u_geom ≤ τ_geom}`。与 DPEM 六分量同构：接触模式 `c` 是「手与环境的关系」，阻抗 `κ_c` 是「手以多硬的方式去感知」。

**定义 401（刚度反作用通道 χ_K）** `χ_K: g ↦ (ΔK_r, ΔD_r) ↦ (Θ_force, D_F)`：动作（含刚度调度）如何调制 CIM 噪声与有效域。具体地，`u_dyn`, `u_noise`, `u_geom` 与 `K_r` 单调相关（硬→动态误差与冲击更敏感），`u_sat` 与 `F_max` 相关。K 通道进入 ΣREFLEX†（R74 定义 390）预算，`c_reflex^K = E[Δu_F | K_r′]`，稳态集 `S_safe = {E[u_F^{next}] ≤ τ_F}`。**刚柔性因此成为可被审计、可被规划、可被组合的一等证据调制量**，而非控制器内部隐参数。

**定义 402（能量罐与被动性证书 EPT）** 控制律在控制域维护存储函数 `T(t) ≥ 0`：
`Ṫ = σ(F_max, P_max) · P_ext − P_cmd − P_diss`，其中 `P_cmd = F_cmd·v`，`P_ext = F_ext·v`（符号约定：向环境输出为正），`σ = sat(F/F_max)·sat(P/P_max)`。**饱和策略**：若请求功率会使 `T` 跌破 0，则按比例缩放 `K_r`（变软）直至可行。被动性证书 `Cert_pass = (T(0), F_max, P_max, 采样率, 能量记账误差界 ε_E)`；证书成立 ⇔ `0 ≤ T(t) ≤ T_max` 在采样区间内可复算。**力/能量保证**：对任意外力序列（含对抗），向环境输出的累计机械功 `W_out ≤ T(0) + ε_E·t`，峰值力 `≤ F_max`，峰值功率 `≤ P_max`。

**定义 403（被动性组合律 PL）** 在 CCA（定义 370）上增加第四个算子语义：
- **串联 PL-SER**：若 A、B 均无源，则 A∘B 无源；罐容量相加 `T_AB = T_A + T_B`；证书 `Cert_pass` 合并取和。
- **并联 PL-PAR**：多个执行器共同作用于同一负载时，无源性在功率加权意义下保持；若无法保证非负罐，禁用并联（退化为单执行器）。
- **否决 PL-VETO**：VETO 不改变物理动力学，只收缩允许动作集，故保持无源。
**结论**：物理地板对组合封闭，且**不引用任何 EC/I⊥/χ_R**——它是与证据代数正交的「更硬的代数」。这是与引理 34 并行的**组合下界（能量侧）**。

**定义 404（物理 stub PS）** 软件 stub（定义 381）触发或 EPT 证书失效时，控制域切换到 PS：
`K_r → K_min, D_r → D_max, M_r → M_r,nom, F_max → F_low, P_max → P_low`，速度指令限幅为被动慢撤退 `v_retreat`，禁止任何位置保持型高刚度动作。
**语义**：PS 输出「可执行的最小权威」——不承诺精度、不采信证据、只保证不伤害。PS 是可证无源的（阻尼主导），因此**证据全失效时的安全性由定义 403 保证，而不是由哨兵保证**。软件 stub 与 PS 的关系：软件 stub 决定「信不信」，PS 决定「动不动、怎么动」。

**定义 405（柔顺-信息权衡 CP）** 一维线性接触、力上限 `F_max`、力噪声 `σ_F`、需安全分辨的最小错位 `δ`：
(i) 可行刚度 `K_r ≤ F_max/δ`；
(ii) 接触定位 Fisher 信息 `I(δ) ≤ K_r²/σ_F² ≤ F_max²/(δ²σ_F²)`；
(iii) 峰值力 `F_peak ≈ K_r·δ`。
**Pareto 前沿**：`{(I, F_peak) : I·F_peak² ≤ F_max²/σ_F²}`。不存在同时最大化 (I) 与最小化 (F_peak) 的**固定** `K_r`。时变刚度的收益见 KAP（定义 406）。系：**柔顺性不是免费的可用性旋钮，而是有信息代价的安全预算**——它必须与不确定度一起被摊销与审计（接入 ΣREFLEX†）。

**定义 406（主动柔顺探测 KAP）** 在接触邻域求解刚度/探测轨迹调度：
`(K_r^*, g^*) = argmax_{K_r(·), a} [ I_contact(K_r, a) − λ_F·E[F_peak] − Σ_i c_reflex^i ]` s.t. EPT 证书、`D_F`、REG 时序。
**对偶性**：PVOP（定义 372）用视角换深度信息，KAP 用刚度换接触信息；两者都是「花动作预算买证据质量」，共用 ΣREFLEX† 预算与解析通道收益。KAP 的独特处：探测本身就是安全风险来源，因此预算必须**同时**计入信息收益与力风险。

**定义 407（最小可证伪原型 MFP）** MFP = (硬件, 仪器, 软件栈, 任务切片, 预注册)。本方案实例 **MFP-1**：2-DOF 平面柔顺臂（SEA + 六维 F/T + 关节力矩）+ RGB-D + 二指欠驱动夹爪 + 可变阻抗控制 + 可注入失效的传感器总线。任务切片覆盖 C1–C6 的关键路径：
T1 自由空间深度计量；T2 守卫式接近→接触（冲击）；T3 透明/新物体抓取（损伤阈值）；T4 人机交接（约定意图 + 力限）；T5 任意单模态失效注入→PS。
**可安全失败**：MFP-1 必须满足 EPT 证书与物理限力，才允许跑「证伪到失效」的 E 系列实验——这是 定义 402 与 407 的耦合条件。

**定义 408（验证证据契约 VEC 与威胁预算）** VEC = (claim_id, hypothesis, population, instrument, metric, threshold, power, threats, threat_budget, gt_independence, repro_pkg)：
- threats 四类：`construct, internal, external, statistical`；
- `threat_budget = (b_c, b_i, b_e, b_s)`，每类声明允许的效应膨胀上界；
- 组合**非补偿**：`b_total = max` 或最坏情形乘积，**不得**用一类优势抵消另一类缺陷；
- 通过条件：预注册指标方向正确 **且** 每类威胁落在预算内 **且** 真值独立（`gt_independence` 不得用被测模块自身输出作真值）。
系：**验证本身是带预算的证据**，与 CCA 的 SER/PAR/VETO 语义同构，但对象是有效性威胁。

**定义 409（可执行定义闭包 EDC）** 映射 `EDC: Def → {executable(predicate over logs), PROSE}`。**闭包条件**：一条主张引用的每个定义都必须 executable，或其 PROSE 依赖已被显式声明为「不计入认证」的假设。定义覆盖率 `Cov_def = |executable ∩ claim_refs| / |claim_refs|`。未闭包的主张不得写入正文结论、不得进入 J_COMP。系：**把「397 个定义」从规模指标变成可审计的覆盖率指标**——PROSE 是允许的，但必须诚实地被标出并隔离。

**定义 410（STAGE 分级验证门）** 四级门与晋升规则：
- **G0 单元/仿真**：分量辨识与校准（对应 E411–E417）；
- **G1 硬件在环 HIL**：真实控制器 + 仿真环境（对应 E418–E419）；
- **G2 台架原型**：MFP-1 上端到端 slice（对应 E419–E426）；
- **G3 受控现场**：带 EPT 地板的多场景/多人（对应 E427–E428）。
晋升条件：本级 VEC 全通过 ∧ 下一级**预注册**冻结 ∧ 物理地板证书有效。任一级失败 ⇒ 主张被**降级**回上一级，不得「跳级用仿真结论覆盖台架失败」。系：**门序是有效性的时序契约**，防止用低级证据为高级结论背书。

**定义 411（组合证书 J_COMP）** `J_COMP = J_SENT ⊗ Cert_pass(EPT) ⊗ J_VEC ⊗ J_EDC ⊗ J_STAGE`。校验：
(i) R74 的 J_SENT 全部条件；(ii) EPT 证书在采样区间可复算且罐非负；
(iii) 每条主张的 VEC 威胁预算闭合；(iv) 主张引用定义 EDC 闭包；
(v) STAGE 门序合法且当前级别 ≥ 主张级别。
`Valid(J_COMP) ⇒ (R74 定理 31 结论) ∧ (物理伤害有界) ∧ (主张在已验证分布上可证伪且未被证伪)`。**范围声明**：`Valid` 不蕴含对未验证分布的外推（这是显式边界，不是缺陷）。

**定义 412（CPB†：主张扩展 C5/C6）**
- **C5（物理安全地板）** ← (CIM, EPT, PS, PL) ← MB5 ← AB5（有/无 EPT × 有/无 PS × 固定/时变刚度）←（证据全失效下的峰值力、累计功、伤害率、任务完成率）。

## 3. 推导

**引理 42（物理地板不依赖证据）** 设 EPT 能量记账误差有界 `|ε_记账| ≤ ε_E`，且硬件执行器在 `F_max/P_max` 饱和下无源。则对**任意**证据序列（含全部 RED、声明族被对抗选择、EC 全部违约），`W_out(t) ≤ T(0) + ε_E·t` 且 `|F(t)| ≤ F_max`。证明：定义存储函数 `T` 非负，`Ṫ = σP_ext − P_cmd − P_diss ≤ σP_ext − P_cmd`；对区间积分并用 `T ≥ 0` 得 `∫P_cmd ≤ T(0) + ∫σP_ext`；被动环境下 `∫P_ext ≤ 0`（或按 `σ≤1` 缩放），故输出功有界。**关键**：证明只用到能量记账与饱和，不读取 `p_depth`、`p_F`、`p_I` 或任何 EC。系：**R74 最大风险（声明族先验）在物理层被绕开**——模型全错时，安全不再依赖模型对。

**引理 43（柔顺-信息权衡，无免费午餐）** 定义 405 的 (i)–(iii) 成立时，固定刚度控制器的 `(I, F_peak)` 落在 `I·F_peak² ≤ F_max²/σ_F²` 之下；故不存在固定 `K_r` 同时任意提高接触定位精度与任意降低峰值力。证明：`I ≤ K_r²/σ_F²`，`F_peak = K_rδ`，消去 `K_r`。系：**时变刚度是唯一能同时「接近期安全 + 探测期准确」的自由度**——这正是 KAP 的存在理由，也是把 `K_r` 纳入 ΣREFLEX† 预算的理由（刚度调度消耗反作用预算）。

**引理 44（物理 stub 的被动性）** PS（定义 404：`K→K_min, D→D_max`、力/功率限幅、被动慢撤退）在接触中无源，因此满足引理 42 的界；且相比「冻结」在环境运动时不会累积弹性势能。证明：阻尼主导项 `D_max·v² ≥ 0` 提供耗散，位置刚度取最小；限幅保证 `P ≤ P_low`。系：**退化链末端从「不采信」升级为「不伤人」**；软件 stub 与 PS 正交组合，前者管认知、后者管物理。

**引理 45（被动性组合律）** 无源模块在 PL-SER / PL-PAR / PL-VETO（定义 403）下组合仍无源，且证书与能量罐按功率守恒可加；组合证书的验证复杂度为 `O(|V_M|)`。证明：无源性定义基于 supply rate 的非负存储函数存在性，串/并联与反馈互联的无源性保持是标准结论；VETO 只缩小动作集。系：**物理安全是与 CCA 形状相同、但前提更弱的组合代数**——它不要求 EC 有效，只要求能量记账。

**引理 46（有效性非组合与 tracer-bullet 否决权）** 存在构型 `𝔖`，其每个组件 `m_i` 在各自 VEC 下通过，但组合系统在端到端 slice 上违反预注册阈值。因此「组件级全绿」不蕴含系统级有效性；反之，端到端 slice 失败对组件级全绿具有**证伪优先权**（若 slice 覆盖所有 claim-critical 路径）。证明：构造两个组件在接口处对同一物理量的语义不一致（如触觉 `u` 被下游压成标量、深度 `σ` 被误读为几何 `σ`），各自基准不覆盖接口语义，组合后误差叠加；或真值循环使组件基准共享同一偏差。系：**不确定度组合单调（引理 34）与有效性非组合（本引理）是方向相反的两套代数**——这正是必须增设 STAGE/EDC 的原因。

**定理 32（COMPGAUGE 严格包含）** 在 A111–A116 与新增 A117–A119（能量记账误差有界 / 硬件饱和无源 / 原型仪器已独立校准）下：SENTGAUGE（R74）是 COMPGAUGE 的「`K_r→∞`（刚性）、EPT 关闭、PS 退化为软件 stub、MFP 退化为仅仿真」实例化；退化链逐指令等于 R74→R73→R72→R71→R68。安全侧只增不减（新增物理界为额外下界）。

**定理 33（证据全失效下的有界伤害）** 若 EPT 证书有效且 PS 可达，则即使 `all sentinels = RED`、`all EC violated`、对抗选择声明族，物理伤害满足引理 42 的界；且任务失败可被显式检测（PS 状态写入证书）。**证明重量从「契约表达力 / 声明族先验」转移到「能量记账与硬件无源性」**——这两者可用硬件限力、独立功率测量与 SEAL-Passivity 注入实验检验，因而比 R74 的 C4 更接近可证伪。

**定理 34（J_COMP 的验证闭包与范围声明）** `Valid(J_COMP)` ⇒ (i) R74 定理 31 全部结论；(ii) 物理伤害 ≤ 定理 33 界；(iii) 每条主张的 VEC 威胁预算闭合、EDC 覆盖率达预注册门槛、STAGE 门序合法。**且显式声明**：`Valid` 仅保证「在 MFP-1 与已验证分布/场景上，主张未被证伪且通过预注册阈值」，**不保证**对未验证分布的外推——外推是新的、必须重新过 G2/G3 的主张，而不是由证书自动继承。系：**把「可复现的证伪」而非「普适的证明」作为本轮的可交付确定性**。

## 6. 本轮最大风险

**一句话**：本轮把安全从「审计出来的软件性质」押到「被动性/能量记账」上，但能量罐的保证只在**记账正确 + 硬件饱和真无源 + 采样离散化误差有界**时成立——非共置传感（力传感器不在接触点）、未建模的执行器动力学/储能元件（弹簧、气动、线缆）、离散更新导致的罐「透支」、以及对抗性功率测量注入，都会让证书在「每一步都合规」的情况下给出错误的物理界；与此同时，MFP-1 只是**一个极窄的分布切片**，C5/C6 的通过极易被误读为普适结论，而定理 34 的「范围声明」恰恰是审稿人和部署者最容易忽略的一行——**系统可能在一个物理假设被静默破坏、验证分布极窄的原型上，同时收获「有界伤害」与「端到端通过」两块错误的安心**。

> - **柔顺控制** → CIM 力/能量七分量 + χ_K 刚度通道 + CP 柔顺-信息权衡 + KAP 主动探测；**EPT 能量罐**给出只依赖能量记账与硬件无源的物理界；**PL 被动性组合律**构成与 CCA 平行、前提更弱的组合代数；**PS 物理 stub** 把退化链末端变成「变软不伤人」。

>
> 核心命题：**安全需要两个此前缺失的支点——不依赖模型正确性的物理安全地板（柔顺/被动性），与可安全失败、端到端可证伪的参考原型；前者使后者在伦理与工程上可行，后者使前者与全部上层主张可被检验。**

## 2. 形式化定义（要点版）

**定义 398（总览与七不变式）** R74 六不变式 + **物理地板**：每条控制律必须挂接 EPT 证书；证据完备性之外新增**可证伪性**（EDC 闭包）与**验证门序**（STAGE 合法）。

**定义 399（柔顺契约 CC）** 阻抗参数、力/功率上限、能量罐、χ_K、接触模式有效域、密封审计引用。物理执行契约，与 EC 平行且 EPT 不读取 EC。

**定义 400（CIM）** 七分量力证据 + 接触模式条件似然 + 独立追溯链 + 有效域硬边界（饱和/几何/功率）；有效域外 ⇒ 力证据降级。

**定义 401（χ_K）** 刚度调度对 `u_dyn/u_noise/u_geom/u_sat` 与 `D_F` 的调制；进入 ΣREFLEX† 预算，`S_safe={E[u_F^next]≤τ_F}`。

**定义 402（EPT）** 存储函数非负、损耗非负、饱和缩放；罐将耗尽时按比例变软直至可行，而非停机。力/能量界只依赖记账与硬件无源。

**定义 403（PL 被动性组合律）** SER 罐相加、PAR 功率加权、VETO 缩动作集；组合仍无源。物理地板对组合封闭，复杂度 `O(|V_M|)`。

**定义 404（PS 物理 stub）** 变软、增阻尼、限力、限功率、被动慢撤退；可证无源；与软件 stub 正交（认知 vs 物理）。

**定义 405（CP 柔顺-信息权衡）** 固定刚度下 `I·F_peak² ≤ F_max²/σ_F²`；无固定刚度可同时最优；时变刚度是唯一解耦自由度（KAP 依据）。

**定义 406（KAP）** 在 EPT/`D_F`/REG 约束下求解刚度-探测轨迹，目标 = 信息 − 力风险 − 反作用预算；与 PVOP 共用解析通道与预算。

**定义 407（MFP）** 硬件+仪器+软件+任务切片+预注册；MFP-1 覆盖 T1–T5；可安全失败前置 = EPT 证书 + 硬件限力。

**定义 408（VEC）** 四类威胁预算非补偿合取；真值不得由被测模块自身产生；通过 = 方向正确 ∧ 预算闭合 ∧ 真值独立。

**定义 409（EDC）** 主张引用定义必须 executable 或 PROSE 显式隔离；`Cov_def` 可审计；未闭包不得进正文/J_COMP。

**定义 410（STAGE）** G0–G3 门序、禁跳级、预注册冻结、任一级失败降级；防止低级证据为高级结论背书。

**定义 411（J_COMP）** J_SENT + EPT 证书 + VEC/EDC/STAGE 校验；`Valid` 附**范围声明**（不外推未验证分布）。

**定义 412（CPB†）** 新增 C5/C6 绑定表；新组件先填 C1–C6 并过 EDC 才能入 MReg。

## 3. 关键算法伪代码

```python
# IP-318 EPT：物理地板必须常开、先于一切证据（控制域 1kHz，零分配）
def passivity_gate(cmd, cc, dt):
    P_cmd = cmd.F.dot(cmd.v); P_ext = cmd.F_ext.dot(cmd.v)
    sigma = sat(cmd.F, cc.F_max) * sat(P_cmd, cc.P_max)
    T_next = cc.E_tank + dt*(sigma*P_ext - P_cmd - cc.P_diss)
    if T_next < 0:                                  # 透支 → 变软，而非冻结
        cc.K_r = max(cc.K_min, cc.K_r*(1 - cc.dK_rate*dt))
        cc.D_r = min(cc.D_max, cc.D_r*(1 + cc.dK_rate*dt))
        return passivity_gate(cmd.soft(), cc, dt)
    cc.E_tank = min(T_next, cc.T_max)
    return cmd, Cert_pass(cc.E_tank, cc.F_max, cc.P_max, cc.eps_E)

# IP-317 CIM：力证据七分量（1kHz）
def cim_update(ft, tau_j, sea, kappa_c, mode, cc):
    u = (calib.zero_drift(ft)**2 + calib.electrical_noise(ft)**2
         + calib.inertial_coriolis(tau_j, sea, kappa_c)**2
         + calib.friction_hysteresis(sea)**2
         + calib.saturation_margin(ft, cc.F_max)**2
         + calib.contact_geometry(mode, sea)**2
         + calib.thermal(ft, temp)**2) ** 0.5
    valid = (mode in calib.modes) and (u_sat < TAU_SAT) and (u_geom < TAU_GEOM)
    return ForceEvidence(u=u, valid=valid, mode=mode, chi_K=chi_K(kappa_c))

# IP-319 KAP：刚度换接触信息（与 PVOP 共用 ΣREFLEX† 预算）
def kap_plan(contact_belief, cc, mods, risk):
    J = lambda K: (expected_contact_information(K, contact_belief, cc.sigma_F)
                   - risk.lam_F*expected_peak_force(K, contact_belief)
                   - sum(m.reflex_cost_estimate(m.state, m.ec.chi_R(a)) for m in mods))
    return optimize(K, J, s.t=[EPT_cert(cc), D_F, REG_timing])

# IP-321 VEC/EDC：主张 → 可执行检查（PROSE 显式隔离）
def compile_claim(claim):
    edc = {d: to_predicate(d) for d in claim.definitions}
    if not edc.closure_ok(): return VEC(claim, status='PROSE_BLOCKED')
    return VEC(claim, edc=edc, threshold=claim.prereg_threshold,
               threats=claim.prereg_threats,
               gt_independence=claim.gt_source != claim.modules)

# IP-322 STAGE：门序晋升（禁跳级）
def stage_promote(claim, level, ev):
    if level > claim.level + 1: return 'BLOCKED_SKIP'
    if not ev.vec.passed or not ev.vec.threat_budget_closed: return 'BLOCKED_VEC'
    if not ev.jcomp.cert_pass.valid: return 'BLOCKED_PASSIVITY'
    if not ev.prereg.frozen_for(level + 1): return 'BLOCKED_PREREG'
    return 'PROMOTED'

# IP-323 COMPGAUGE 主闭环（物理地板常开，先于一切证据）
def COMPGAUGE_round(M, depth, ft, det):
    d_ev = M.dpe.update(...); o_ev = M.oem.update(...); f_ev = M.cim.update(...)
    for ev, mod in ((d_ev,M.dpe),(o_ev,M.oem),(f_ev,M.cim)):
        st,_ = mod.sent.step(ev.resid, M.hist)
        if st == 'RED': ev = stub(mod)                       # 软件 stub：不采信
    if M.clock.due_metric():
        K_seq = kap_plan(M.bse.contact, M.cc, M.mods, M.risk)
        g = M.ervoi.choose(...)
        if g: M.state = sent_reflex_step(M.mods, g, M.state, M.budget)[0]
        M.cert = write_sent_cert(M)
    snap = M.snapshot.read_latest()
    cmd = (physical_stub(M.cc) if snap.degraded() else
           M.ach.propose_ctrl(..., K_seq=snap.K_seq))
    cmd, cert = passivity_gate(cmd, M.cc, M.dt)              # 物理 stub：不伤人
    M.envelope.check0(cmd, cert)
    return cmd, cert, J_COMP(M)
```

## 4. 推导（要点）

- **引理 42（地板不依赖证据）**：`T≥0` + 饱和 ⇒ `W_out ≤ T(0)+ε_E·t`，`|F|≤F_max`，证明不读取任何 EC/哨兵；R74 的声明族风险在物理层被绕开。
- **引理 43（柔顺-信息权衡）**：消去 `K_r` 得 `I·F_peak² ≤ F_max²/σ_F²`；固定刚度无免费午餐，时变刚度是唯一解耦自由度。
- **引理 44（PS 被动性）**：阻尼主导 + 限力 + 最小刚度 ⇒ 无源；比冻结更安全（不累积弹性势能）。
- **引理 45（被动性组合）**：SER/PAR/VETO 保无源，罐可加，`O(|V_M|)` 校验；物理地板与 CCA 同形但前提更弱。
- **引理 46（有效性非组合）**：存在组件全绿而组合失败的构型 ⇒ 端到端 slice 对组件级全绿有证伪优先权。
- **定理 32（严格包含）**：`K_r→∞` + EPT 关闭 + PS≡软件 stub + 仅仿真 ⇒ 逐指令退化为 R74→R73→R72→R71→R68。
- **定理 33（全失效有界伤害）**：全 RED + 全 EC 违约 + 对抗声明族下，伤害仍由引理 42 界定；证明重量移至可检验的「能量记账 + 硬件无源」。
- **定理 34（验证闭包与范围声明）**：`Valid(J_COMP)` ⇒ R74 定理 31 + 物理界 + VEC/EDC/STAGE 合法；显式不承诺未验证分布外推。

## 7. 本轮最大风险

**一句话**：本轮把安全从「审计出来的软件性质」押到「被动性/能量记账」上，但能量罐的保证只在**记账正确 + 硬件饱和真无源 + 采样离散化误差有界**时成立——非共置传感、未建模的执行器动力学与储能元件、离散更新的罐透支、对抗性功率测量注入，都会让证书在「每一步都合规」时给出错误的物理界；而 MFP-1 只是极窄的分布切片，C5/C6 的通过极易被误读为普适结论，而定理 34 的「范围声明」恰是最容易被忽略的一行——**系统可能在一个物理假设被静默破坏、验证分布极窄的原型上，同时收获「有界伤害」与「端到端通过」两块错误的安心**。
