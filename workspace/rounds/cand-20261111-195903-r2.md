# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「视觉问答」×「可靠性」）

> 第 54 轮把技能组合与云边协同推进为“动作-鲁棒性双证书”体系。但证书最终要被人和运维质询：系统究竟看到了什么、能不能做、有多大把握？本轮把 **视觉问答（VQA）从演示能力提升为可证书化的自然语言质询接口**，并把“可靠性”拆成可度量、可校准、可弃权的剖面。核心矛盾：H22：VQA 答案流畅 ≠ 答案可靠，语言先验会制造高置信但无视觉接地的答案；H23：基准上的边际可靠性（accuracy/ECE）无法条件化到“此刻这个问题”，闭环分布漂移会击穿 conformal 的可交换性假设。

## 0. 直觉与动机

**灵感 1（VQA 作为质询接口，而非炫技）**
直觉：人不会读张量证书，但会问“杯子在左还是右？”“这个抓取稳吗？”“你现在能完成 A_T 吗？”。若系统能对这些问题的回答附带证据区域与置信度，甚至回答“我不确定”，那么第 54 轮的证书就有了一致的自然语言入口。VQA 的价值不在答对多少题，而在于**把内部证书翻译成可审计的断言**。

**灵感 2（可靠性是剖面，不是标量）**
直觉：一个 VQA 系统可以总体准确率很高，却在遮挡、反事实、细粒度计数上系统性失败。可靠性应像第 53 轮的鲁棒性谱 ρ 一样，拆成多维剖面 `ρ_V = (acc, ece, rc, g, ood)`：正确性、校准、选择性风险-覆盖、视觉接地、分布外稳健。单看 accuracy 会把“自信地胡说”判成可靠。

**灵感 3（弃权是一等输出，conformal 给覆盖保证）**
直觉：可靠系统必须会说“我不知道”。用 split conformal 构造答案集 `C_α(I,Q)`，在可交换性下保证 `P(Y∈C_α) ≥ 1-α`；当答案集过大或为空时弃权。弃权不是失败，而是**用覆盖率换风险的显式契约**，正好嵌入第 54 轮的部署否决逻辑。

**灵感 4（双通道验证，避免自证）**
直觉：若只让 VQA 验证自己，感知主干共享会导致相关失败——看起来两个通道都通过，其实同一个盲点。让形式化证书 `C_sym`（ρ、A_cert、J）与 VQA 自然语言断言做交叉验证，测双通道分歧率 `δ_vq`。分歧不是噪声，而是“证书欠规范”或“答案未接地”的告警，触发审计而非直接部署。

**灵感 5（可靠性路由，云边再分工）**
直觉：不是所有问题都值得上云。边端用小模型答简单问题（低延迟），云端答高不确定问题（高精度），路由器 `π_q` 按预测风险与延迟预算决策。这把第 54 轮的云边协同从“动作映射”扩展到“质询映射”，并给出延迟-可靠性的 Pareto 曲线。

**灵感 6（主动问题红队，把 VQA 变成证伪器）**
直觉：与其等部署后暴露幻觉，不如主动生成反事实问题（换颜色、移走物体、加遮挡、改空间关系）来逼出“高置信但未接地”的答案。这些反例直接喂给第 53/54 轮的 Explain 通道与重剖分流程，形成“质询→反例→证书修正”的闭环。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（可靠性感知 VQA 系统）**
VQA 系统 `V: (I,Q,Θ) → (A, u, e)`，其中 `I` 图像/场景，`Q` 问题，`A` 答案（可为答案集或弃权 `⊥`），`u∈[0,1]` 为校准置信度，`e ⊆ I` 为证据区域。`V` 必须支持 `answer_set(I,Q,α)` 与 `evidence(I,Q,A)` 两个接口。

**定义 122（VQA 可靠性剖面）**
`ρ_V = (acc, ece, rc(·), g, ood)`：
- `acc` 分布内准确率；
- `ece` 期望校准误差；
- `rc(τ)` 在置信阈值 τ 下的风险-覆盖曲线；
- `g = E[ground(I,e,A)]` 视觉接地一致性；
- `ood` 分布外退化斜率。可靠判据：存在 τ 使 `rc(τ) ≤ r_max` 且 `coverage(τ) ≥ c_min`。

**定义 123（选择性答案集与 conformal 覆盖）**
校准集 `D_cal = {(I_i,Q_i,Y_i)}`，非一致性分数 `s_i = 1 - V.conf(I_i,Q_i,Y_i)`，阈值 `q̂ = Quantile(s, ⌈(n+1)(1-α)⌉/n)`。答案集 `C_α(I,Q) = {a | V.conf(I,Q,a) ≥ 1-q̂}`。若可交换，则 `P(Y∈C_α) ≥ 1-α`。弃权规则：`|C_α| > k_max` 或 `C_α=∅` 时输出 `⊥`。

**定义 124（接地一致性）**
给定证据区域 `e`，独立接地检查器 `ground(I,e,A) ∈ [0,1]` 度量答案是否由图像区域支持。接地一致性 `G = P(ground ≥ θ_g | A≠⊥)`。**幻觉**定义为 `u ≥ θ_u` 且 `ground < θ_g`，即高置信未接地。

**定义 125（双通道一致性证书）**
`J_vq = (C_sym, ρ_V, δ_vq, P_res, evidence)`：
- `C_sym` 为第 54 轮形式化证书（ρ、A_cert、J）；
- `ρ_V` 为 VQA 可靠性剖面；
- `δ_vq = (1/|P_res|) Σ_{q∈P_res} 1[C_sym ⊭ q(a) ∧ V 作答 a]`，`P_res` 为保留探针问题集；
- `evidence` 含接地区域、校准集摘要、反事实反例。仅当 `δ_vq ≤ Θ_vq` 且 `rc(τ) ≤ r_max` 时才允许 VQA 断言进入部署证据链。

**定义 126（可靠性路由）**
路由器 `π_q : Q → {edge, cloud, abstain}`：
```
π_q(q) = argmin_{m∈{edge,cloud}} [ risk_m(q) + λ·latency_m(q) ]，若 min risk ≤ r_max；否则 abstain
```
其中 `risk_m(q)` 为通道 m 的预测风险，`λ` 为延迟-风险兑换率。

## 2. 关键算法 伪代码

### IP-121 VQC（VQA Reliability Characterization）

```python
def vqa_reliability(vqa, calib_set, alpha=0.1):
    ece = expected_calibration_error(vqa, calib_set)
    rc  = risk_coverage_curve(vqa, calib_set)
    scores = [1.0 - vqa.conf(I, Q, Y) for (I, Q, Y) in calib_set]
    qhat = quantile(scores, ceil((len(scores)+1)*(1-alpha)) / len(scores))
    return ReliabilityProfile(acc=accuracy(vqa, calib_set), ece=ece, rc=rc, qhat=qhat)
```

### IP-122 SCV（Selective Conformal VQA）

```python
def selective_answer(vqa, I, Q, qhat, k_max=3):
    C = vqa.answer_set(I, Q, qhat)          # {a : conf >= 1 - qhat}
    if len(C) == 0 or len(C) > k_max:
        return ('abstain', C)
    a = max(C, key=lambda c: vqa.conf(I, Q, c))
    return ('answer', a, C)
```

### IP-123 GCV（Grounding Consistency Verifier）

```python
def grounding_check(vqa, I, Q, a, theta_g=0.5):
    e = vqa.evidence(I, Q, a)               # region / attention map
    g = ground(I, e, a)                     # independent checker
    return ('grounded' if g >= theta_g else 'ungrounded', g)

def hallucination_rate(vqa, probes, theta_u=0.8, theta_g=0.5):
    bad = 0
    for (I, Q, _) in probes:
        a, u = vqa.answer_with_conf(I, Q)
        if u >= theta_u and ground(I, vqa.evidence(I,Q,a), a) < theta_g:
            bad += 1
    return bad / len(probes)
```

### IP-124 DCC（Dual-Channel Certificate）

```python
def dual_channel_certify(sym_cert, vqa, probes, delta_budget, r_max):
    disagree = 0
    for (q, expected) in probes:
        status, a, _ = selective_answer(vqa, q.I, q.text, vqa.qhat)
        if status == 'answer' and not sym_cert.entails(q.text, a):
            disagree += 1
    delta_vq = disagree / max(1, len(probes))
    if delta_vq > delta_budget:
        return ('reject', 'channel_disagreement', delta_vq)
    if vqa.profile.rc_at(vqa.tau) > r_max:
        return ('reject', 'selective_risk', vqa.profile.rc)
    return ('ok', DualCert(sym_cert, vqa.profile, delta_vq))
```

### IP-125 RQR（Reliability-Aware Query Router）

```python
def route_question(q, edge, cloud, r_max, lam):
    r_e, r_c = edge.risk(q), cloud.risk(q)
    l_e, l_c = edge.latency(q), cloud.latency(q)
    scores = {'edge': r_e + lam*l_e, 'cloud': r_c + lam*l_c}
    m = min(scores, key=scores.get)
    if scores[m] > r_max:
        return ('abstain', None)
    return (m, (edge if m == 'edge' else cloud).selective_answer(q))
```

### IP-126 AQR（Active Question Red-teaming）

```python
def active_redteam(vqa, scene, n=100):
    failures = []
    for q in counterfactual_questions(scene, n):   # swap/remove/occlude/relate
        a, u = vqa.answer_with_conf(scene.I, q)
        g = ground(scene.I, vqa.evidence(scene.I, q, a), a)
        if u >= 0.8 and g < 0.5:
            failures.append(Counterexample(q, a, u, g, scene))
    return failures
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| VQC | O(|D_cal|) | O(|D_cal|) | 校准集代表部署分布 |
| SCV | O(|A|·C_infer) | O(|A|) | 可交换性 / 在线更新 |
| GCV | O(C_infer + C_ground) | O(|e|) | 接地检查器独立且低误报 |
| DCC | O(|P_res|·C_infer) | O(|P_res|) | 探针覆盖证书语义、δ_vq 有界 |
| RQR | O(C_infer) per query | O(1) | 风险估计校准、延迟可测 |

**正确性定理（Reliability-Contract Soundness for VQA Certificate）**
假设第 54 轮 (A26)–(A28) 成立；新增 **(A29)** 探针问题与部署问题在同一上下文内可交换，或由在线 conformal 维持近似覆盖；**(A30)** 接地检查器误报率 ≤ ε_g；**(A31)** 双通道分歧 `δ_vq ≤ ε_d`。则被部署的 VQA 断言误导的概率满足：
```
P(mislead) ≤ α + ε_cal + ε_g + ε_d + P(shift)
```
其中 `α` 来自 conformal 覆盖、`ε_cal` 来自校准误差、`P(shift)` 为上下文漂移超出在线更新能力的概率。关键：**覆盖保证只在可交换性成立时有效**；闭环部署必须用自适应 conformal + 漂移检测，否则定理退化为安慰剂。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 闭环漂移击穿可交换性 | 高 | 在线/自适应 conformal + 漂移检测 + 定期重校准 |
| 接地检查器自身不可靠 | 高 | 多检查器投票 + 人工抽检 + 与形式证据交叉 |
| VQA 与形式通道共享感知盲点 | 高 | 独立证据源（几何/力觉/时序）+ 通道多样性 |
| 语言先验走捷径 | 高 | 反事实 QA、视觉消融、文本置换对照 |
| 弃权过多影响可用性 | 中 | 风险-覆盖感知的交互降级 + 分层回退 |
| 基准泄漏/评测过拟合 | 中 | 留出 embodied episode + 跨场景评测 |

## 6. 本轮最大风险

**一句话**：把 VQA 提升为“可证书化质询接口”能让证书被人理解并交叉验证，但其可靠性保证 **本质上依赖校准集与部署问题的可交换性、接地检查器的独立性、以及双通道的误差不相关**；一旦闭环分布漂移或两通道共享同一感知盲点，conformal 覆盖会失效、`δ_vq` 会系统性低估真实分歧，系统将以“有覆盖保证”的姿态输出高置信的未接地断言，故必须以 **在线 conformal + 独立证据源 + 主动反事实红队** 三重护栏，宁可否证，绝不把自然语言的流畅当作可靠性的证明。

# 第 55 轮产物 · 创新点清单 v32：GroundVQA-Rel（VQC×SCV×GCV×DCC×RQR×AQR）

> 承接第 54 轮产物 v31。本轮把视觉问答从“感知能力”升级为 **可靠性质询层**，在既有动作-鲁棒性双证书之上增加：
> - **VQC（VQA Reliability Characterization）**：把可靠性拆成可度量剖面 `ρ_V`；
> - **SCV（Selective Conformal VQA）**：带覆盖保证的答案集与一等弃权；
> - **GCV（Grounding Consistency Verifier）**：接地检查，显式定义幻觉；
> - **DCC（Dual-Channel Certificate）**：形式证书与自然语言断言交叉验证；

> - **AQR（Active Question Red-teaming）**：反事实问题驱动的证伪与重校准。

**正确性定理（Reliability-Contract Soundness for VQA Certificate）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 探针/部署问题在同一上下文内可交换，或在线 conformal 维持近似覆盖；**(A30)** 接地检查器误报率 ≤ ε_g；**(A31)** `δ_vq ≤ ε_d`。则：
```
P(mislead) ≤ α + ε_cal + ε_g + ε_d + P(shift)
```
关键：**覆盖只在可交换性成立时有效**；闭环必须用自适应 conformal、漂移检测与独立证据源，否则证书是安慰剂。

## 6. 本轮最大风险

**一句话**：VQA 质询层让证书可被人理解和交叉验证，但其可靠性保证 **本质上依赖校准集与部署问题的可交换性、接地检查器的独立性、以及双通道误差的不相关性**；一旦闭环漂移或两通道共享感知盲点，conformal 覆盖失效、`δ_vq` 系统性低估分歧，系统会以“有覆盖保证”的姿态输出高置信未接地断言，故必须以 **在线 conformal + 独立证据源 + 主动反事实红队** 三重护栏，宁可否证，绝不把自然语言的流畅当作可靠性的证明。
