# 第 68 轮（承接第 67 轮「SimRAS 仿真增强闭环」IP-233~242；本轮灵感：「视觉问答」×「跌倒恢复」）

> 第 67 轮 SimRAS 把闭环推进到「离线仿真预训练 + 在线世界模型推理 + 视觉问答审计」，但它仍隐含一个乐观假设：系统**基本不会真的倒下**。VQA 是后台审计员，世界模型是对未来的外推，认证前缀只在名义流形附近成立。真正击穿整套体系的是**跌倒**——证书失效、动力学进入接触丰富/强自遮挡/分布外区域，世界模型和 VQA 同时最不可信。此时继续问「未来风险怎么演化」已经太晚，正确的问题是「**已经倒下之后，如何用最少的语义猜测、最可证伪的证据，认证一条恢复路径**」。
>
> 本轮的核心命题是：
>
> **把「认证不失败」升级为「认证失败后的恢复」：让 VQA 从审计员降格为「可证伪的语义传感器」——它的答案不是事实，而是待检验的恢复主张；只有能被物理探针或跨模态证据接地的 claim 才能进入硬安全约束；恢复执行必须落在「认证恢复前缀」内，否则安全冻结并求助。**
>
> VQRec 问的不是「会不会摔」，而是「**摔了以后，哪些语义判断可以被证实，哪条恢复路径可以被认证，证不了的时候如何体面地停住**」。

## 0. 直觉与动机

**灵感 1（视觉问答 → 从“看懂”到“可证伪的断言”）**
直觉：VQA 输出的是自然语言，直接把它当事实喂给安全控制器是灾难性的。正确接口不是「答案 → 动作」，而是「答案 → **恢复主张（recovery claim）** → 证据检验 → 授权等级」。一条 claim 只有在能被本体感觉、触觉、深度、多视角一致性或**安全微探针**检验时，才有资格成为硬约束。换句话说：**可证伪性即授权**。不可安全检验的 VQA 断言最多只能做软偏好或提问线索，绝不能单独授权恢复动作。

**灵感 2（跌倒恢复 → 从“避免失败”到“失败后的相变”）**
直觉：跌倒不是普通故障，而是一次**状态相变**：支撑多边形崩塌、接触模式突变、姿态估计与语义理解同时退化。恢复也不要求势函数单调上升——从仰卧到侧滚再到跪姿，重心可能先降后升。因此需要**阶段漏斗（phase funnel）**：每个阶段允许的最低恢复势 + 总下降预算，而不是简单的单调约束。这样既允许“先滚再站”，又能保证不会滚进更糟的稳定态。

**灵感 3（两速闭环 → 反射先活下来，审议再爬起来）**
直觉：VQA 单次问答 30–80ms，等它想明白，人可能已经二次受伤。恢复必须拆成两层：
- **反射层（Reflex Guard）**：预编译的护头、收拢、柔性落定策略，<10ms，完全不依赖 VQA；
- **审议层（Deliberation）**：VQA 提问、物理证伪、契约编译、恢复规划与认证，0.3–2s。
反射层保证“先不更糟”，审议层负责“如何变好”。这直接回应了第 67 轮“双黑箱拖垮实时性”的隐患。

**灵感 4（主动提问 → 只问能改变恢复可行性的问题）**
直觉：跌倒后不该让 VQA 泛泛描述场景，而应只问**能改变恢复可行性判断**的问题。例如“左前臂是否被躯干压住”会直接决定能否双臂撑起；“地面是否有支撑物”会决定能否爬向墙角。问题选择最大化「恢复可行性」的互信息，并优先询问**关键主张**（一旦翻转就改变可行性的 claim）。这把 VQA 从“描述器”变成“实验设计者”。

**灵感 5（人在回路 → 不能对人做物理探针）**
直觉：如果跌倒的是人、或人倒在机器人旁边，物理证伪测试的伦理边界立刻变化：机器人不能为了验证“对方是否清醒”去推人。因此 `HUMAN` 类 claim 的授权规则必须不同——只有本人明确回应/同意时才能进入硬约束；未知时只能执行**非接触恢复 + 呼叫求助**。这条伦理红线必须写进证书，而不是留给运行时临时判断。

**灵感 6（灵感合流 → VQRec：Visual Question-grounded Recovery）**
VQRec 从 SimRAS 继承时序骨架，换装为：
1. **RG ReflexGuard**：预认证跌倒反射，VQA 无关；
2. **FDD Fall Detector & Diagnoser**：检测跌倒阶段与类型；
3. **RQ RecoveryQuestioner**：按恢复可行性信息增益主动提问；
4. **AGK Answer Grounding Kernel**：把答案解析为 typed claim 并做证据接地；
5. **PFT Physical Falsification Tester**：用有界微动作做物理证伪；
6. **RCC Recovery Contract Compiler**：把接地 claim 编译为硬/软/未知三层约束；
7. **PRM Primitive Recovery Manifold**：恢复原语库上的阶段漏斗规划；
8. **VQ-Cert Certified Recovery Prefix**：认证恢复前缀 `k*_R`；
9. **SF/DE Safe-Freeze & Dialectic Explainer**：认证失败时安全冻结 + 辩证解释；
10. **AIC-VQR / J_VQR**：把 VQA 幻觉、场景文本注入、探针二次跌倒、答案时效纳入干扰集与证书。

- **定义 287（恢复原语库与合成）**：`Prim = {p_1, ..., p_P}`，每个原语 `p = (pre_p, post_p, force_env_p, ΔΦ_p, dur_p, human_contact_p)`。`PRM.Plan(s_t, K_t, k_max)` 搜索满足前/后置链、力包络、阶段漏斗与原语时长约束的序列，目标最大化 `Φ(s_T)`。

- **定义 289（安全冻结与求助回退）**：`SAFE_FREEZE(s) = argmin_{a ∈ A_hold} max(0, Φ(a) - Φ(s))`，约束为 `force_env`、`human_contact = False`、`airway_preserved = True`，并触发 `CALL_HELP`。不变式：冻结引起的 `Φ` 下降不超过 `ε_freeze`，接触压力不超过 `p_max`。
- **定义 290（主动问题选择）**：`q* = argmax_{q ∈ Q_bank} [IG(q) + λ_crit·P(q 改变关键主张)] - β_c·cost(q)`，其中 `IG(q) = H(Feasible | G_t) - E_{a~VQA(·|q)} H(Feasible | G_t ∪ {a})`，`Feasible = [∃π: co_feasible]`。若 `IG(q*) < τ_ig`，停止提问，按当前 `G_t` 规划或冻结。

- **定义 292（人在回路同意与辅助恢复）**：`consent ∈ {GIVEN, ABSENT, UNKNOWN}`，`assist_level ∈ {OBSERVE, CALL, NON_CONTACT_SUPPORT, PHYSICAL_ASSIST}`。`PHYSICAL_ASSIST` 必须满足 `consent = GIVEN` 且无脊柱/头部损伤 claim；`consent = UNKNOWN` 时只允许 `OBSERVE/CALL` 或非接触支撑。

- **定义 296（恢复单调不变式）**：执行前缀内每个状态满足阶段漏斗与下降预算；恢复成功时 `s_T ∈ U ∧ Φ(s_T) ≥ 1 - ε_U`。这是 VISTA 安全不变式在“失败后”的对应物。
- **定义 297（双层时标）**：`T_reflex ≤ 10ms`，`T_deliberation ∈ [0.1s, 2s]`；反射层预编译、永不调用 VQA；认证前缀只在审议层计算。
- **定义 298（主张-证据可分离矩阵）**：`S_ground = diag(S_vqa, S_phys)`。若跨模态协方差为零，则 `κ_ground = min(κ_vqa, κ_phys)`；若存在共模失效，则 `κ_ground < min(κ_vqa, κ_phys)`，这正是最难防的情形。

# IP-246/247 AGK + PFT：答案接地与物理证伪
class AnswerGroundingKernel:
    def __init__(self, probe, tau_g=2.0):
        self.probe, self.tau_g = probe, tau_g

    def ground(self, claim, evidence):
        lr = likelihood_ratio(claim, evidence)
        rec = {'claim': claim, 'evidence': evidence, 'lr': lr, 'probe': None}
        if lr >= self.tau_g:
            rec.update(grounded=True, authority='CERTIFIED_HARD')
            return rec
        if claim.testable and self.probe.is_safe(claim):
            res = self.probe.run(claim)
            rec['probe'] = res
            rec['grounded'] = res.consistent
            rec['authority'] = 'CERTIFIED_HARD' if res.consistent else 'SOFT'
        else:
            rec.update(grounded=False, authority='ADVISORY')
        return rec

                and not self.cert.would_contact_human(u)

# IP-248 RCC：恢复契约编译与约束传播
class RecoveryContractCompiler:
    def compile(self, grounded):
        H, S, U = [], [], []
        for g in grounded:
            c = g['claim']
            if c.type in ('BODY', 'HUMAN') and g['authority'] == 'CERTIFIED_HARD':
                H.append(Constraint(c.region, c.y, c.h))
            elif c.type in ('SCENE', 'AFFORDANCE'):
                S.append(Preference(c.region, c.y, c.p))
            else:
                U.append(c)
        # 主张图上的前向传播：pinned → 对应原语不可用
        H = propagate_implications(H, grounded)
        return RecoveryContract(H, S, U, grounded)

    def feasible(self, G):
        return co_feasible(RecoveryContractCompiler().compile(G))


# IP-249 PRM：阶段漏斗上的恢复原语规划
class PrimitiveRecoveryManifold:
    def __init__(self, prim_lib, funnel):
        self.prim, self.funnel = prim_lib, funnel

    def plan(self, s_t, contract, k_max=4):
        plans = search_sequences(self.prim, s_t, contract.H, k_max)
        plans = [p for p in plans
                 if self.funnel.admissible(s_t, p) and contract_ok(p, contract)]
        return max(plans, key=lambda p: self.funnel.final_phi(s_t, p),
                   default=[])


# IP-250 VQ-Cert：认证恢复前缀
class VQRecoveryCertificate:
    def __init__(self, vista_cert):
        self.vista = vista_cert

    def certified_prefix(self, plan, s_t, contract):
        k_best = 0
        for k in range(1, len(plan) + 1):
            if not self.funnel.ok(s_t, plan[:k]):
                break
            if not all(self.vista.safe(plan[i], h) and
                       contract.authority_ok(plan[i])
                       for i in range(k) for h in contract.H):
                break
            k_best = k
        return k_best

    # 0) 反射层：先不更糟
    if M.fdd.fall_pending(obs):
        M.execute(M.rg.on_fall(s_t, obs.pose.fall_dir))

    # 1) 跌倒确认与分型
    F = M.fdd.detect(obs.imu, obs.pose, obs.tactile)
    if F is None:
        return nominal_loop(M, obs)

    # 2) 初始证据 + 初始 claim
    G = [M.agk.ground(c, M.evidence.collect(s_t, obs))
         for c in M.rq.initial_claims(F)]

    # 3) 主动提问 + 物理证伪（审议层）
    while not M.rcc.feasible(G) and M.rq.budget_left():
        q = M.rq.next_question(obs.scene, G, M.rq.budget)
        if q is None:
            break
        claim = M.rq.ask(obs.scene, q)
        G.append(M.agk.ground(claim, M.evidence.collect(s_t, obs)))
        M.rvb.record(obs.scene_hash, G[-1])

    # 4) 编译契约、规划、认证
    contract = M.rcc.compile(G)
    plan = M.prm.plan(s_t, contract)
    k_R = M.vqcert.certified_prefix(plan, s_t, contract)

    # 5) 执行或安全冻结
    if k_R >= 1:
        for a in plan[:k_R]:
            M.execute(a)
            s_t = M.observe()
    else:
        fb = M.sf.fallback(s_t, contract)
        M.execute(fb['action'])
        M.call_help(fb['explain'])

    return M.vqcert.emit(F, contract, plan, k_R, s_t)
```

## 3. 推导

**引理 13（可证伪授权的乘性降险）** 设 VQA claim 为假的概率为 `ε_v`，物理探针/独立证据对假 claim 的误接受率为 `α_p`。若证据在给定真值下与 VQA 错误条件独立，则假 claim 获得 `CERTIFIED_HARD` 授权的概率不超过 `ε_v·α_p`；若 `m` 个证据通道相互独立，则不超过 `ε_v·∏_j α_p^{(j)}`。例如 `ε_v = 0.15, α_p = 0.1` 时，硬授权错误率降到 1.5%。**这正是“可证伪性即授权”的定量含义：把单通道幻觉转成多通道乘积。**

**引理 14（阶段漏斗不引入新跌倒）** 设跌倒检测阈值为 `Φ_fall`，且对恢复计划所有阶段有 `Φ_i^min ≥ Φ_fall + ε_m`。若原语序列满足 `pre_1`、`post_i ⊆ pre_{i+1}` 与力包络约束，则对任意 `i`，`s_i` 不触发新跌倒；且若终态 `Φ(s_T) ≥ 1 - ε_U`，则 `s_T ∈ U`。证明：对原语序号归纳；`post_i` 保证下一步前置条件，漏斗保证每一步都不进入“比跌倒更差”的稳定域，下降预算 `B_desc` 保证不会无限损失势能。

**定理 14（VQRec 端到端恢复安全）** 在 A87-A91、引理 13、探针安全与答案时效失效条件下，对实际执行的恢复前缀：
1. `P(执行动作违反 H) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa·α_probe + α_stale`；
2. `k*_R = 0 ⇒ SAFE_FREEZE`，且 `P(Φ 下降超过 ε_freeze) ≤ α_freeze`；
3. 若 `k*_R = m` 且 `Φ(s_T) ≥ 1 - ε_U`，则恢复成功率不低于 `1 - (α_chunk + δ_fi + α_emotion + α_wm + α_vqa·α_probe + α_stale)`；
4. 若 `consent ≠ GIVEN`，则 `P(未同意的物理接触) = 0`（由授权规则构造性保证）。

**定理 15（主动提问的样本复杂度）** 设 `p_t = P(Feasible | G_t)`，且当 `p_t ∈ (δ, 1-δ)` 时每个被选问题的互信息满足 `IG(q) ≥ g_min`。则经过 `N = O((1/g_min)·log(1/δ))` 次提问后，`Feasible` 的后验熵降到 `h(δ)` 以下（可判定可行或不可行）；而随机提问的最坏情形需要 `Ω(1/δ)` 次。关键主张过滤进一步把问题集限制在“翻转后改变可行性”的 claim 上，因而实际 VQA 调用次数显著低于熵上界。

**推论 15.1（解释即最小解锁）** 若 `k*_R = 0`，`DE` 输出的 `minimal_unlock_claim` 给出使 `co_feasible` 成立所需的最小额外证据集；在主张图无环时，该集合可由一次反向可达性搜索得到，复杂度 `O(|G| + |E_implies|)`。

## 6. 本轮最大风险

**一句话**：VQRec 的全部安全性都押在「物理证伪测试与 VQA 误差条件独立」这一假设上，而跌倒场景恰恰是最典型的共模失效——同一次碰撞会同时破坏位姿/深度估计、造成自遮挡并诱导 VQA 给出自信但错误的语义判断，此时“独立证据”并不独立，幻觉 claim 可能通过接地并授权一条把伤情加重的恢复路径。

**次级风险与缓解**：
1. **探针二次伤害**：探针只能从离线预认证的微动作库选择，且人在场时自动禁用接触类探针；
2. **人类 claim 不可探**：`HUMAN` 类硬约束只接受本人明确同意/回应，未知时只做非接触恢复 + 求助；
3. **Φ 估计失真**：柔软衣物/非刚体接触使 `CoM` 与支撑多边形估计有区间误差，采用区间 `Φ`，宽度超阈值即冻结；
4. **VQA 延迟**：反射层完全独立于 VQA，审议层允许 0.3–2s，必要时先冻结再慢慢问；
5. **答案过期**：场景指纹 + 时效双阈值，任何显著变化都使 claim 退回 `U_t`；
6. **镜像/左右混淆**：多视角 + 身体坐标系规范化 + 专门消歧问题，关键 claim 需双侧一致性。

F = (t_f, φ, κ, s_{t_f}),  φ ∈ {PRE_IMPACT, IMPACT, POST_IMPACT, RECOVERY, STABLE}

U = {s : proj_xy(CoM(s)) ∈ Spt(s) ⊖ margin_u}

`Spt(s)` 为接触点凸包（支撑多边形），`⊖` 为内缩。

**定义 279（恢复进度势与阶段漏斗）** 恢复进度势

Φ(s) = w1·h_norm(CoM_z) + w2·margin_norm(Spt) + w3·(1 - p_contact(s)) + w4·upright_align(s)

`Φ ∈ [0,1]`，`Φ=1` 表示直立稳定。阶段漏斗 `Funnel = {(i, Φ_i^min)}` 与总下降预算 `B_desc`。恢复计划 `p_1..p_m` 可接受当且仅当：

2. `Σ_{i≤m} max(0, Φ_{i-1} - Φ_i) ≤ B_desc`；

```
只追加、不可篡改。主张图 `CG_t = (G_t, E_implies)`，例如
```
pinned(left_forearm, torso) ⇒ ¬available(prone_pushup)
human_under_torso ⇒ ¬available(roll_toward_human)
```
约束传播在 RCC 中完成。

**定义 285（恢复约束集）**
```
RCS_t = (H_t, S_t, U_t)
H_t = {(r, y, h) : authority(c) = CERTIFIED_HARD}
S_t = {(r, y, w) : authority(c) ∈ {BINDING_SOFT, ADVISORY} 且类型为 SCENE/AFFORDANCE}
U_t = {c : ¬grounded(c)}
```
`U_t` 只驱动提问，不驱动约束。

**定义 286（恢复契约）**
```
K_t = (H_t, S_t, U_t, G_t, L_A, ρ_t, h_t),  h_t = hash(H_t,S_t,G_t,L_A,scene_hash)
co_feasible(K_t) ⇔ ∃π_R ∈ PRM: H(τ)=⊤ ∧ violation(S,τ) ≤ ε_S
```
契约哈希进入最终证书，保证“执行的就是被认证的那一份”。

**定义 287（恢复原语库与合成）**
```
Prim = {tuck, roll_left, roll_right, prone_pushup, kneel, sit_to_stand,
        crawl_to_support, brace_wall, freeze, call_help}
p = (pre_p, post_p, force_env_p, ΔΦ_p, dur_p, human_contact_p)
```
`PRM.Plan(s_t, K_t, k_max)` 搜索满足 `pre/post` 链、力包络、阶段漏斗与原语时长约束的序列，目标最大化 `Φ(s_T)`；`k_max ≤ 4`。

**定义 288（认证恢复前缀）**
```
k*_R = max{k ≤ m :
  ∀i≤k: Cert_VISTA(a_i) ∧ authority_ok(a_i) ∧ force_env(a_i)
         ∧ Φ(s_i) ≥ Φ_i^min
         ∧ Σ_{j≤i} max(0, Φ_{j-1} - Φ_j) ≤ B_desc
         ∧ λ_risk(s_i)·ρ_safe(s_i) ≥ 0}
```
若不存在 `k ≥ 1`，则 `k*_R = 0`，进入安全冻结。

**定义 289（安全冻结与求助回退）**
```
SAFE_FREEZE(s) = argmin_{a ∈ A_hold} max(0, Φ(a) - Φ(s))
s.t. force_env(a), human_contact(a)=False, airway_preserved(a)=True
```
同时触发 `CALL_HELP`。不变式：`Φ` 下降 ≤ `ε_freeze`，接触压力 ≤ `p_max`，气道风险不升高。

**定义 290（主动问题选择）**
```
q* = argmax_{q ∈ Q_bank} [IG(q) + λ_crit·P(q 改变关键主张)] - β_c·cost(q)
IG(q) = H(Feasible | G_t) - E_{a~VQA(·|q)} H(Feasible | G_t ∪ {a})
```
`Feasible = [∃π: co_feasible(K_t)]`。关键主张 `c` 定义为翻转后改变 `co_feasible` 的 claim。若 `IG(q*) < τ_ig`，停止提问。

**定义 291（场景指纹与答案时效）**
```
scene_hash = hash(q, contacts, support_set, human_bbox, object_layout)
```
claim `c` 在 `t_c` 获得，在 `t` 时刻有效当且仅当
```
dist(scene_hash_t, scene_hash_{t_c}) ≤ τ_scene ∧ t - t_c ≤ τ_stale
```
否则退回 `U_t`，必须重问或重探。该机制防止过期 VQA 语义授权恢复（TOCTOU）。

**定义 292（人在回路同意与辅助恢复）**
```
consent ∈ {GIVEN, ABSENT, UNKNOWN}
assist_level ∈ {OBSERVE, CALL, NON_CONTACT_SUPPORT, PHYSICAL_ASSIST}
```
`PHYSICAL_ASSIST` 必须满足 `consent = GIVEN` 且无脊柱/头部损伤 claim；`consent = UNKNOWN` 时只允许 `OBSERVE/CALL` 或非接触支撑；`consent = ABSENT` 时只允许非接触动作并呼叫。

**定义 293（恢复可解释性）**
```
DE(K_t, k*_R) = (blocking_constraints, minimal_unlock_claim,
                 counterfactual_recovery, risk_trace)
```
若 `k*_R = 0`，输出“哪条未接地 claim 阻塞了哪个原语”，并给出最小额外证据集与反事实恢复路径。

**定义 294（AIC-VQR 干扰集）**
```
E_VQR = E_VISTA × E_vqa × E_fall × E_probe × E_stale × E_human
E_vqa    = {幻觉, 场景文本提示注入, 镜像/左右混淆, 光照, 低分辨率}
E_fall   = {自遮挡, 接触丰富动力学, 非刚体衣物, 非常规姿态}
E_probe  = {探针诱发二次跌倒, 探针接触人, 探针不可行}
E_stale  = {审议期间场景变化, 人体移动, 物体被移走}
E_human  = {人不应答, 误导性手势, 痛苦/恐慌}
```
共因故障：跌倒事件同时破坏位姿/深度估计并诱导 VQA 产生自信错误。

**定义 295（J_VQR 证书）**
```
J_VQR = (J_VISTA, fall_hash, claim_ledger_hash, probe_log_hash,
         recovery_plan_hash, progress_trace, question_trace,
         scene_hash, consent_state, aic_vqr_ver, vqa_model_ver)
```
Valid ⇔ `Valid(J_VISTA)` ∧ 所有 `H`-claim 均 `CERTIFIED_HARD` ∧ `((k*_R ≥ 1 ∧ 执行未越界) ∨ (k*_R = 0 ∧ J_freeze valid))`。

**定义 296（恢复单调不变式）** 执行前缀内每个状态满足阶段漏斗与下降预算；恢复成功时 `s_T ∈ U ∧ Φ(s_T) ≥ 1 - ε_U`。这是 VISTA 安全不变式在“失败后”的对应物，也是 VQRec 与普通 fall-recovery 策略的本质区别。

**定义 297（双层时标）**
```
T_reflex ≤ 10ms,  T_deliberation ∈ [0.1s, 2s]
```
反射层预编译、永不调用 VQA；认证前缀只在审议层计算。两层的接口是“反射层保证当前状态不更糟，审议层在安全状态下寻找可行恢复”。

**定义 298（主张-证据可分离矩阵）**
```
S_ground = diag(S_vqa, S_phys)
```
若跨模态协方差为零，则 `κ_ground = min(κ_vqa, κ_phys)`；若存在共模失效，则 `κ_ground < min(κ_vqa, κ_phys)`。后者是 VQRec 最需要防御的情形。

**定义 299（恢复成功判据）**
```
s_T ∈ U ∧ Φ(s_T) ≥ 1 - ε_U ∧ J_VQR.Valid ∧ 在 T_hold 内无新跌倒
```
否则记为部分恢复/失败，并保留 `DE` 报告。

**定义 300（部署不变式）** 实时回路只含 `RG, FDD` 与预认证派发；`VQA/AGK/PFT/RCC/PRM` 只在审议层；答案账本只追加；任何学习模块不得直接写硬约束；安全冻结永远可用且不依赖 VQA。

class RecoveryQuestioner:
    def __init__(self, vqa, prim_lib, tau_ig=0.1):
        self.vqa, self.prim, self.tau_ig = vqa, prim_lib, tau_ig

    def next_question(self, scene, G, budget):

        for q in QUESTION_BANK:

# IP-246 AGK：答案接地核
class AnswerGroundingKernel:
    def __init__(self, probe, tau_g=2.0):
        self.probe, self.tau_g = probe, tau_g

    def ground(self, claim, evidence):
        lr = likelihood_ratio(claim, evidence)
        rec = {'claim': claim, 'evidence': evidence, 'lr': lr, 'probe': None}
        if lr >= self.tau_g:
            rec.update(grounded=True, authority='CERTIFIED_HARD')
            return rec
        if claim.testable and self.probe.is_safe(claim):
            res = self.probe.run(claim)
            rec['probe'] = res
            rec['grounded'] = res.consistent
            rec['authority'] = 'CERTIFIED_HARD' if res.consistent else 'SOFT'
        else:
            rec.update(grounded=False, authority='ADVISORY')
        return rec

# IP-248 RCC：恢复契约编译与约束传播
class RecoveryContractCompiler:
    def compile(self, grounded):
        H, S, U = [], [], []
        for g in grounded:
            c = g['claim']
            if c.type in ('BODY', 'HUMAN') and g['authority'] == 'CERTIFIED_HARD':
                H.append(Constraint(c.region, c.y, c.h))
            elif c.type in ('SCENE', 'AFFORDANCE'):
                S.append(Preference(c.region, c.y, c.p))
            else:
                U.append(c)
        H = propagate_implications(H, grounded)   # 主张图前向传播
        return RecoveryContract(H, S, U, grounded)

    def feasible(self, G):
        return co_feasible(RecoveryContractCompiler().compile(G))


# IP-249 PRM：阶段漏斗上的恢复原语规划
class PrimitiveRecoveryManifold:
    def __init__(self, prim_lib, funnel):
        self.prim, self.funnel = prim_lib, funnel

    def plan(self, s_t, contract, k_max=4):
        candidates = search_sequences(self.prim, s_t, contract.H, k_max)
        candidates = [p for p in candidates
                      if self.funnel.admissible(s_t, p) and contract_ok(p, contract)]
        return max(candidates, key=lambda p: self.funnel.final_phi(s_t, p),
                   default=[])


# IP-250 VQ-Cert：认证恢复前缀
class VQRecoveryCertificate:
    def __init__(self, vista_cert):
        self.vista = vista_cert

    def certified_prefix(self, plan, s_t, contract):
        k_best = 0
        for k in range(1, len(plan) + 1):
            if not self.funnel.ok(s_t, plan[:k]):
                break
            if not all(self.vista.safe(plan[i], h)
                       and contract.authority_ok(plan[i])
                       for i in range(k) for h in contract.H):
                break
            k_best = k
        return k_best

# IP-252 主回路：反射优先，审议随后
def VQRec_round(M, s_t, obs):
    # 0) 反射层：先不更糟
    if M.fdd.fall_pending(obs):
        M.execute(M.rg.on_fall(s_t, obs.pose.fall_dir))

    # 1) 跌倒确认与分型
    F = M.fdd.detect(obs.imu, obs.pose, obs.tactile)
    if F is None:
        return nominal_loop(M, obs)

    # 2) 初始证据 + 初始 claim
    G = [M.agk.ground(c, M.evidence.collect(s_t, obs))
         for c in M.rq.initial_claims(F)]

    # 3) 主动提问 + 物理证伪（审议层）
    while not M.rcc.feasible(G) and M.rq.budget_left():
        q = M.rq.next_question(obs.scene, G, M.rq.budget)
        if q is None:
            break
        claim = M.rq.ask(obs.scene, q)
        G.append(M.agk.ground(claim, M.evidence.collect(s_t, obs)))
        M.rvb.record(obs.scene_hash, G[-1])

    # 4) 编译契约、规划、认证
    contract = M.rcc.compile(G)
    plan = M.prm.plan(s_t, contract)
    k_R = M.vqcert.certified_prefix(plan, s_t, contract)

    # 5) 执行或安全冻结
    if k_R >= 1:
        for a in plan[:k_R]:
            M.execute(a)
            s_t = M.observe()
    else:
        fb = M.sf.fallback(s_t, contract)
        M.execute(fb['action'])
        M.call_help(fb['explain'])

    return M.vqcert.emit(F, contract, plan, k_R, s_t)

## 4. 推导

**引理 13（可证伪授权的乘性降险）** 设 VQA claim 为假的概率为 `ε_v`，物理探针/独立证据对假 claim 的误接受率为 `α_p`。若证据在给定真值下与 VQA 错误条件独立，则假 claim 获得 `CERTIFIED_HARD` 授权的概率不超过 `ε_v·α_p`；若 `m` 个证据通道相互独立，则不超过 `ε_v·∏_j α_p^{(j)}`。数值上 `ε_v=0.15, α_p=0.1` 时，硬授权错误率从 15% 降到 1.5%。这给出“可证伪性即授权”的定量解释：**把单通道幻觉转成多通道乘积**。

证明：`P(假 ∧ 授权) = P(假)·P(授权|假) ≤ ε_v·α_p`，第二步用条件独立与误接受定义；多通道重复应用独立性即可。

**引理 14（阶段漏斗不引入新跌倒）** 设跌倒检测阈值为 `Φ_fall`，且对恢复计划所有阶段有 `Φ_i^min ≥ Φ_fall + ε_m`。若原语序列满足 `pre_1`、`post_i ⊆ pre_{i+1}` 与力包络约束，则对任意 `i`，`s_i` 不触发新跌倒；若终态 `Φ(s_T) ≥ 1 - ε_U`，则 `s_T ∈ U`。

证明：对原语序号归纳。`post_i` 保证 `p_{i+1}` 前置条件成立；阶段漏斗保证每个中间状态 `Φ(s_i) ≥ Φ_i^min ≥ Φ_fall + ε_m`，因此不会落入检测器的跌倒区域；下降预算 `B_desc` 保证势能损失不会导致“滚入更深稳定域”。终态条件直接由 `U` 的定义得到。

**定理 14（VQRec 端到端恢复安全）** 在 A87-A91、引理 13、探针安全与答案时效失效条件下，对实际执行的恢复前缀：
1. `P(执行动作违反 H) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa·α_probe + α_stale`；
2. `k*_R = 0 ⇒ SAFE_FREEZE`，且 `P(Φ 下降超过 ε_freeze) ≤ α_freeze`；
3. 若 `k*_R = m` 且 `Φ(s_T) ≥ 1 - ε_U`，则恢复成功率不低于 `1 - (α_chunk + δ_fi + α_emotion + α_wm + α_vqa·α_probe + α_stale)`；
4. 若 `consent ≠ GIVEN`，则 `P(未同意的物理接触) = 0`（由定义 292 的授权规则构造性保证）。

证明：对每个执行步应用 VISTA 安全证书与恢复契约授权，再用联合界合并 `k` 步误差；`k*_R` 的构造保证每一步都在前缀内；`SAFE_FREEZE` 由定义 289 的势能界直接给出。第 4 条是授权规则的结构性结论，不依赖概率模型。

**定理 15（主动提问的样本复杂度）** 设 `p_t = P(Feasible | G_t)`，且当 `p_t ∈ (δ, 1-δ)` 时每个被选问题的互信息满足 `IG(q) ≥ g_min`。则经过 `N = O((1/g_min)·log(1/δ))` 次提问后，`Feasible` 的后验熵降到 `h(δ)` 以下；而随机提问最坏需要 `Ω(1/δ)` 次。

证明：每次提问使熵至少下降 `g_min`，初始熵 `H_0 ≤ 1 bit`，终止熵 `h(δ) = O(δ log(1/δ))`，故 `N ≤ (H_0 - h(δ))/g_min = O(log(1/δ)/g_min)`。随机提问在对抗性答案分布下每次最多下降 `O(δ)`，下界为标准结果。

**推论 15.1（解释即最小解锁）** 若 `k*_R = 0`，`DE` 输出的 `minimal_unlock_claim` 给出使 `co_feasible` 成立所需的最小额外证据集；在主张图无环时，该集合可由一次反向可达性搜索得到，复杂度 `O(|G| + |E_implies|)`。

## 7. 本轮最大风险

**一句话**：VQRec 的全部安全性都押在「物理证伪测试与 VQA 误差条件独立」这一假设上，而跌倒场景恰恰是最典型的共模失效——同一次碰撞会同时破坏位姿/深度估计、造成自遮挡并诱导 VQA 给出自信但错误的语义判断，此时“独立证据”并不独立，幻觉 claim 可能通过接地并授权一条把伤情加重的恢复路径。

**次级风险与缓解**：
1. **探针二次伤害**：探针只能从离线预认证的微动作库选择，且人在场时自动禁用接触类探针；
2. **人类 claim 不可探**：`HUMAN` 类硬约束只接受本人明确同意/回应，未知时只做非接触恢复 + 求助；
3. **Φ 估计失真**：柔软衣物/非刚体接触使 `CoM` 与支撑多边形估计有区间误差，采用区间 `Φ`，宽度超阈值即冻结；
4. **VQA 延迟**：反射层完全独立于 VQA，审议层允许 0.3–2s，必要时先冻结再慢慢问；
5. **答案过期**：场景指纹 + 时效双阈值，任何显著变化都使 claim 退回 `U_t`；
6. **镜像/左右混淆**：多视角 + 身体坐标系规范化 + 专门消歧问题，关键 claim 需双侧一致性。
