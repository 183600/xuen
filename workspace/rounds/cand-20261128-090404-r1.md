### 第 8 轮灵感驱动研究记录（新一轮循环第 1 轮）

**灵感词**：状态隔离、记忆检索

**继承关系**：第 7 轮 CADVS-v7（IP-501~IP-504）把系统从「指令驱动」推进到「需求驱动」：DIM 从历史推断 ρ_demand，DRC 用 LLM 推理链量化 η_demand，DAC 用表情调制探索度，EFA-v7 以软因子链收紧七硬门。但 v7 有一个未展开的结构性前提：DIM、STM、FMPP 共享同一个长期记忆池 LMEM，所有用户、任务、会话、时间片的记录被压进同一嵌入空间。于是「需求推断」可能被上一任务的残留状态污染，「记忆检索」可能把别人的成功轨迹当作自己的先验。本轮以「状态隔离」与「记忆检索」为双灵感，提出「隔离式记忆检索」（Isolated Retrieval Memory, IRM）：先把记忆切成不可穿透的状态胶囊，再在能力允许的胶囊格内做带证书的检索；隔离不是软因子，而是检索的前置类型约束。

**直觉与动机**：

1. **状态隔离 → 从「共享记忆池」到「状态胶囊格」**。直觉上，记忆不是一袋可互换的嵌入向量，而是一组有因果作用域的状态快照：一条「杯子在桌上」的记忆，只在「某个用户、某次会话、某个任务、某个因果纪元」内成立。把它和另一个用户的记忆混在一起，不是「更多证据」，而是「错误证据」。因此引入「状态胶囊记忆」（State Capsule Memory, SCM）：每次写入必须携带 (principal, session, task, epoch) 四元组与来源证明，读取必须出示能力凭证；检索只能在允许的胶囊集合内进行。关键洞见是：**隔离先于相似**——先决定「谁有权被看见」，再决定「谁最相似」。

2. **记忆检索 → 从「Top-k 相似」到「带证书的隔离检索」**。直觉上，一个记忆即使语义高度相似，也可能因为过期、被污染、或来自另一个主体而不可用。第 7 轮的 `Top-k(Retr_M(q, K=4))` 只优化相似度，没有回答「这条记忆凭什么可信」。本轮引入「隔离感知检索」（Isolation-Aware Retrieval, IAR）：分数由相似度、新鲜度、来源可靠度、隔离裕度共同决定；每次检索返回一张「检索证书」，记录允许胶囊、实际选中胶囊、Merkle 根、桥接证书与差分隐私预算。关键洞见是：**检索的输出不只是记忆，还有「记忆的可审计性」**。

3. **隔离与迁移的张力 → 从「一刀切」到「可审计桥接」**。直觉上，完全隔离会让机器人永远从零开始：上一个任务学到的「抓杯子要避开杯柄」无法迁移到新任务。但直接打通又会重新引入污染。因此引入「桥接证书」（Bridge Certificate）：跨胶囊读取必须显式声明理由、风险参数 λ_b 与泄漏预算 δ_b，并写入审计日志；η_iso 随桥接风险连乘衰减，风险过高则 fail-closed 到无记忆提议。关键洞见是：**迁移不是默认权限，而是一次需要留痕的降级授权**。

4. **三层状态隔离**。把「状态隔离」从记忆扩展到运行时：L1 物理状态隔离（每个任务纪元重置世界状态快照，执行器不继承上一任务的接触力/速度状态）；L2 估计器状态隔离（DIM/STM 的隐状态按纪元门控，避免 ρ_demand 跨任务漂移）；L3 记忆状态隔离（SCM 胶囊）。本轮形式化重点放在 L3，但实验同时监测 L1/L2 的残留污染。

**关键洞见**：第 7 轮回答「如何从用户需求出发主动推导行为」；第 8 轮回答「在推导之前，如何保证被检索的历史确实是『这个主体、这个任务、这个时刻』的历史」。七硬门 kc_evidence_forged_v5 与 v7 的 kc_demand 原样复用；本轮新增：
- IP-505 SCM（状态胶囊记忆），
- IP-506 IAR（隔离感知检索），
- IP-507 MCR（记忆冲突消解器），
- IP-508 EFA-v8（隔离式证据融合，软因子链扩展为 η_iso、η_ret）

**形式化目标（增量）**：

1. **SCM（State Capsule Memory）**：
   - 胶囊键 c = (p, s, t, e) ∈ C，分别为主体、会话、任务、因果纪元；
   - 记忆记录 r = (k, v, τ_w, ttl, prov, qos, tags)，其中 prov 为写入者签名与父哈希；
   - 存储 M = ⊎_{c∈C} M_c（不相交并），写入需 write 能力，读取需 read 能力；
   - 纪元失效：e < e_now 的记录默认不可读，除非通过「提升证书」重新观测验证。

2. **IAR（Isolation-Aware Retrieval）**：
   - 能力 κ = (p, s, t, e, L_read, bridges, ε_dp)；
   - 允许集 A(κ) = {c : π(κ, c) = read}；
   - 检索 R(q, κ) = TopK_{c∈A(κ)} ⋃_c TopK_{r∈M_c} s(q, r)，其中 s = cos(q,k)·fresh·qos·iso_margin；
   - 输出检索证书 cert = (A(κ), chosen, {Merkle(M_c)}, bridges, η_iso, η_ret, ε_dp, timestamp)。

3. **MCR（Memory Conflict Resolver）**：
   - 若 η_ret < τ_ret，尝试主动重观测（re-observe）或纪元提升；
   - 若同纪元胶囊间出现位姿/位置冲突，优先新纪元；无法消解则无记忆回退；
   - 任何回退都不把冲突记忆喂给 DIM/FMPP。

4. **EFA-v8（隔离式证据融合）**：
   - 质量因子 η_iso, η_ret ∈ (0,1]；收紧乘子 μ_iso = 1/η_iso，μ_ret = 1/η_ret；
   - τ_i^v8 = min(τ_i^max, τ_i^v7 · μ_iso · μ_ret) ≥ τ_i^v7；
   - ECS_v8 = ECS_v7 · η_iso · η_ret；
   - 不新增硬门；隔离是结构不变式：任何越界检索直接 fail-closed。

5. **形式化定义**：给定指令 L、能力 κ、记忆 M：
   - q_L = STM(L)；
   - res = IAR.retrieve(q_L, κ)；
   - d = MCR.resolve(q_L, res, env, κ)；
   - 若 d.use_memory = false：执行 v7 的无记忆提议路径（FMPP + 七硬门）；
   - 若 d.use_memory = true：以 d.records 替换 v7 的 m_topk，以 SCM.history(κ) 替换 v7 的历史，执行 EFA-v7 流程，并用 μ_iso·μ_ret 收紧阈值。

**v7 单调性漏洞修补**：v7 的 η_affect = 1 + affect/3 ∈ [2/3, 4/3]，当 affect < 0 时 η_affect < 1，会使 τ_i^v7 下降、执行集扩张，与「软因子只收紧」的定理 11 矛盾。v8 统一把质量因子重参数化为收紧乘子 μ_j = 1/η_j ≥ 1（或对 η_j 截断到 (0,1]），从而在结构上恢复 fail-closed。

**本轮最大风险**：**隔离与迁移的结构性矛盾**：胶囊边界越清晰，跨任务经验越难复用；一旦为了冷启动放宽桥接，污染又会从桥接证书这个「被信任的例外」重新渗入，而桥接证书的信任根本身并不在隔离范围内。

### 0.3 v7 单调性漏洞修补

v7 的软因子链声称「只收紧」，但 η_affect = 1 + affect/3 在 affect < 0 时小于 1，会使 τ_i^v7 下降，破坏定理 11。v8 的修补分两步：

1. 对每个质量因子 η_j 定义截断质量 `η_j^+ = clip(η_j, 0, 1)`；
2. 定义收紧乘子 `μ_j = 1 / max(η_j^+, ε)`，其中 ε = 1e-6，于是 μ_j ≥ 1。

对原本可能大于 1 的因子（如 η_affect），取 `μ_j = max(1, 1/η_j)`，只允许收紧、不允许放宽。v8 的阈值统一写成：

```
τ_i^v8 = min(τ_i^max, τ_i^v7 · μ_iso · μ_ret · μ_affect^+)
```

### IP-505 SCM：状态胶囊记忆

```python
@dataclass(frozen=True)
class CapsuleKey:
    principal: str
    session: str
    task: str
    epoch: int

@dataclass(frozen=True)
class Provenance:
    writer: str
    signature: bytes
    parent_hash: str

@dataclass(frozen=True)
class MemoryRecord:
    key: torch.Tensor              # 语义键嵌入
    payload: dict                  # 轨迹 / 位姿 / 任务参数
    written_at: float
    ttl: float
    provenance: Provenance
    qos: float                     # [0,1]，离线验证的成功率/校准分
    tags: frozenset[str]

class StateCapsuleMemory:
    """SCM：不相交并的胶囊化记忆。
    写入需要 write 能力；读取需要 read 能力；任何跨胶囊读取必须显式桥接。"""

    def __init__(self, policy, verifier, clock):
        self._caps: dict[CapsuleKey, list[MemoryRecord]] = {}
        self._merkle: dict[CapsuleKey, str] = {}
        self.policy = policy
        self.verifier = verifier
        self.clock = clock

    def write(self, c: CapsuleKey, r: MemoryRecord, κ: Capability) -> None:
        self.policy.require(κ, c, "write")
        if not self.verifier.verify(r.provenance):
            raise ProvenanceError(c)
        if r.written_at + r.ttl < self.clock.now():
            raise StaleWrite(c)
        self._caps.setdefault(c, []).append(r)
        self._merkle[c] = merkle_append(self._merkle.get(c, EMPTY), r)

    def read(self, c: CapsuleKey, κ: Capability) -> tuple[MemoryRecord, ...]:
        self.policy.require(κ, c, "read")
        return tuple(self._caps.get(c, ()))

    def allowed(self, κ: Capability) -> tuple[CapsuleKey, ...]:
        return tuple(c for c in self._caps if self.policy.permits(κ, c))

    def history(self, κ: Capability) -> tuple[MemoryRecord, ...]:
        return tuple(r for c in self.allowed(κ) for r in self.read(c, κ))

    def merkle(self, c: CapsuleKey) -> str:
        return self._merkle.get(c, EMPTY)
```

### IP-506 IAR：隔离感知检索

```python
@dataclass(frozen=True)
class Capability:
    principal: str
    session: str
    task: str
    epoch: int
    read_level: int
    bridges: tuple[BridgeCert, ...] = ()
    dp_epsilon: float = 0.0

@dataclass(frozen=True)
class RetrievalCertificate:
    allowed: tuple[CapsuleKey, ...]
    chosen: tuple[CapsuleKey, ...]
    merkle: dict[CapsuleKey, str]
    bridges: tuple[BridgeCert, ...]
    eta_iso: float
    eta_ret: float
    dp_epsilon: float
    timestamp: float

@dataclass(frozen=True)
class RetrievalResult:
    records: tuple[MemoryRecord, ...]
    cert: RetrievalCertificate
    status: str

class IsolationAwareRetrieval:
    """IAR：只在 A(κ) 内检索，per-capsule quota 防止单一胶囊垄断 Top-k。"""

    def __init__(self, scm, policy, clock, k=4, quota=2, T_margin=0.1):
        self.scm, self.policy, self.clock = scm, policy, clock
        self.k, self.quota, self.T_margin = k, quota, T_margin

    def retrieve(self, q: torch.Tensor, κ: Capability) -> RetrievalResult:
        allowed = self.scm.allowed(κ)
        scored = []
        for c in allowed:
            recs = self.scm.read(c, κ)
            top = heapq.nlargest(
                self.quota, recs, key=lambda r: self.score(q, r, c, κ)
            )
            scored.extend((self.score(q, r, c, κ), c, r) for r in top)

        scored.sort(key=lambda x: (x[0], x[1].epoch), reverse=True)
        topk = scored[: self.k]
        eta_iso = self.isolation_quality(topk, κ)
        eta_ret = self.retrieval_quality(q, topk)

        cert = RetrievalCertificate(
            allowed=allowed,
            chosen=tuple(c for _, c, _ in topk),
            merkle={c: self.scm.merkle(c) for c in allowed},
            bridges=κ.bridges,
            eta_iso=eta_iso,
            eta_ret=eta_ret,
            dp_epsilon=κ.dp_epsilon,
            timestamp=self.clock.now(),
        )
        if eta_iso <= 0.0:
            return RetrievalResult((), cert, "ISOLATION_FAIL_CLOSED")
        return RetrievalResult(tuple(r for _, _, r in topk), cert, "OK")

    def score(self, q, r, c, κ) -> float:
        return (
            cosine(q, r.key)
            * self.freshness(r)
            * r.qos
            * self.policy.isolation_margin(κ, c)
        )

    def freshness(self, r) -> float:
        age = max(0.0, self.clock.now() - r.written_at)
        return math.exp(-age / max(r.ttl, 1e-6))

    def isolation_quality(self, topk, κ) -> float:
        # 结构不变式：越界或来源不可验证，直接 fail-closed
        if any(not self.policy.permits(κ, c) for _, c, _ in topk):
            return 0.0
        if any(not self.scm.verifier.verify(r.provenance) for _, _, r in topk):
            return 0.0
        # 桥接是显式降级：风险连乘
        risk = 1.0
        for b in κ.bridges:
            if not self.policy.valid_bridge(b, κ):
                return 0.0
            risk *= (1.0 - b.lambda_risk) * (1.0 - b.delta_leak)
        return risk

    def retrieval_quality(self, q, topk) -> float:
        if not topk:
            return 0.0
        s = [x[0] for x in topk]
        s_next = s[self.k] if len(s) > self.k else 0.0
        margin = 1.0 - math.exp(-max(0.0, s[0] - s_next) / self.T_margin)
        weights = [math.exp(x - s[0]) for x in s]
        support = sum(
            w * r.qos * self.freshness(r)
            for w, (_, _, r) in zip(weights, topk)
        )
        support /= max(sum(weights), 1e-9)
        return float(min(1.0, max(0.0, margin * support)))
```

### IP-507 MCR：记忆冲突消解器

```python
@dataclass(frozen=True)
class Resolution:
    use_memory: bool
    records: tuple[MemoryRecord, ...]
    reason: str

class MemoryConflictResolver:
    """MCR：低置信 / 过期 / 冲突记忆不得直接进入 DIM 与 FMPP。"""

    def __init__(self, tau_ret=0.6, conflict_eps=0.05):
        self.tau_ret = tau_ret
        self.conflict_eps = conflict_eps

    def resolve(self, q, res: RetrievalResult, env, κ) -> Resolution:
        if res.status != "OK":
            return Resolution(False, (), "ISOLATION_FAIL_CLOSED")

        # 1. 低置信：尝试主动重观测或纪元提升
        if res.cert.eta_ret < self.tau_ret:
            if env.can_reobserve():
                obs = env.reobserve()
                if self.verify_against(obs, res.records):
                    return Resolution(True, res.records, "REOBSERVED")
            return Resolution(False, (), "LOW_RETRIEVAL_CONFIDENCE")

        # 2. 跨胶囊冲突：同纪元无法消解则无记忆回退
        conflicts = self.detect_conflicts(res.records)
        if not conflicts:
            return Resolution(True, res.records, "OK")
        if self.epoch_resolvable(conflicts):
            return Resolution(True, self.keep_newest(conflicts), "EPOCH_RESOLVED")
        return Resolution(False, (), "UNRESOLVED_CONFLICT")

    def detect_conflicts(self, records) -> list[Conflict]:
        # 同一语义槽（object_pose / location / task_goal）跨胶囊差异 > eps
        return find_slot_conflicts(records, self.conflict_eps)

    def epoch_resolvable(self, conflicts) -> bool:
        return all(max(c.epochs) > min(c.epochs) for c in conflicts)

    def keep_newest(self, conflicts) -> tuple[MemoryRecord, ...]:
        return tuple(c.newest for c in conflicts)
```

### IP-508 EFA-v8：隔离式证据融合

```python
@dataclass
class EvidenceForgingAssemblerV8:
    """EFA-v8：复用 v7 七硬门 + kc_demand；隔离是结构前置条件，不新增硬门。"""
    v7: EvidenceForgingAssemblerV7
    scm: StateCapsuleMemory
    iar: IsolationAwareRetrieval
    mcr: MemoryConflictResolver
    tau_max: float = 0.95

    def select(self, L, t_now, context, κ) -> tuple[bool, Trajectory | None, str]:
        # 1. 隔离检索（替代 v7 对 LMEM 的直接读取）
        q_L = self.v7.stm.forward(L)
        res = self.iar.retrieve(q_L, κ)
        decision = self.mcr.resolve(q_L, res, context.env, κ)

        # 2. 隔离失败或低置信：不把污染记忆喂给 DIM/FMPP
        if not decision.use_memory:
            return self.v7.select_memory_free(L, t_now, context)

        # 3. 用隔离后的记忆替换 v7 的 m_topk / history
        ctx = dataclasses.replace(
            context,
            memory=decision.records,
            history=self.scm.history(κ),
            retrieval_cert=res.cert,
        )

        # 4. 阈值收紧：μ_iso·μ_ret ≥ 1，只收紧不放宽
        mu = self.tightening(res.cert.eta_iso, res.cert.eta_ret)
        ok, x, tag = self.v7.select(
            L, t_now, ctx, tau_scale=mu, tau_max=self.tau_max
        )
        if not ok:
            return self.v7.select_memory_free(L, t_now, context)
        return True, x, f"{tag}|IRM:{decision.reason}"

    def tightening(self, eta_iso, eta_ret) -> float:
        mu_iso = 1.0 / max(eta_iso, 1e-6)
        mu_ret = 1.0 / max(eta_ret, 1e-6)
        return max(1.0, mu_iso) * max(1.0, mu_ret)
```

  res = IAR.retrieve(q_L, κ)          # 只在 A(κ) 内，per-capsule quota

## 4. 正确性论证（增量更新）

### 定理 13（检索无干扰性 / State Noninterference）

**陈述**：给定查询 q、能力 κ 与两个记忆存储 M、M'。若对所有 c ∈ A(κ) 都有 M_c = M'_c，则 `IAR.retrieve(q, κ; M)` 与 `IAR.retrieve(q, κ; M')` 返回相同的记录序列与相同的证书（证书中的 Merkle 根只覆盖 A(κ)）。此外，对任意 c ∉ A(κ) 的写入或删除，都不改变检索输出。

**证明**：IAR 只遍历 `allowed(κ) = A(κ)`；对每个 c，per-capsule Top-k 只依赖 M_c；全局排序只依赖这些候选；证书只包含 A(κ) 的胶囊、其 Merkle 根与桥接列表。因此整个输出是 M|_{A(κ)} 的确定性函数。c ∉ A(κ) 的记录从未进入候选集，故其任何变化都不影响输出。∎

**推论 13.1**：在无桥接（bridges = ∅）且能力只覆盖当前 (p,s,t,e) 时，跨用户、跨会话、跨任务、跨纪元的记忆对检索结果零影响。这是「状态隔离」的结构性保证，不依赖相似度阈值。

### 定理 14（v8 的 fail-closed 单调性）

**陈述**：设 η_iso, η_ret ∈ (0,1]，μ = (1/η_iso)(1/η_ret) ≥ 1，τ_i^v8 = min(τ_i^max, μ·τ_i^v7)。则对任意记忆条件化提议 x：

- 若 x 被 v8 接受，则 x 必被 v7 接受，即 `Exec_v8^mem ⊆ Exec_v7`；
- ECS_v8(x) = ECS_v7(x)·η_iso·η_ret ≤ ECS_v7(x)；
- 若 η_iso = 0 或 η_ret < τ_ret，则 MCR 返回 `use_memory = false`，不产生任何记忆条件化执行。

**证明**：μ ≥ 1 ⇒ τ_i^v8 ≥ τ_i^v7；硬门判定 1[s_i ≥ τ_i^v8] ≤ 1[s_i ≥ τ_i^v7]，故执行集只收缩。ECS 乘以两个 (0,1] 因子，单调不增。隔离失败时 `resolve` 在构造候选前返回 false，故记忆条件化路径不存在。v7 中 η_affect > 1 的放宽被 0.3 节的 `μ_affect^+ = max(1, 1/η_affect)` 截断，不再破坏单调性。∎

**注**：无记忆回退路径不受 μ 收紧；它只受七硬门约束。因此「隔离失败」否决的是记忆条件化提议，而不是所有可行动作。这是有意的：隔离是记忆的准入条件，不是机器人的停机条件。

### 命题 1（污染影响上界）

**假设**：IAR 使用 per-capsule quota q_c 与鲁棒聚合（trimmed mean 或 median）；每个允许胶囊中最多有 δ 比例的被污染记录；qos 与新鲜度独立于污染标签。

**结论**：Top-k 聚合结果对污染记录的敏感度上界为 O(δ·q_c·k)；η_ret 随 δ 单调不增；当 δ > δ* = 1 - τ_ret 时，MCR 以高概率拒绝使用记忆。

**证明要点**：quota 把单个胶囊的污染记录数限制在 q_c，鲁棒聚合的击穿点为 1/2，故污染对聚合均值的偏移不超过 O(δ·q_c·k)。η_ret 的 support 项按 qos·fresh 加权，污染记录不增加 support；margin 项在污染记录挤入 Top-k 时下降。阈值 τ_ret 给出拒绝条件。∎

### 诚实声明

- 隔离会降低召回与跨任务迁移：冷启动任务可能比 v7 更差，这是结构性代价，不是调参能消除的。
- provenance 的信任根（签名密钥、验证器、Merkle 日志）不在隔离范围内；根被攻破时定理 13 的前提失效。
- 因果纪元依赖事件排序与时钟；乱序写入、时钟回拨会导致 epoch 错配，进而误判过期/新鲜。
- 检索证书本身泄露结构元数据（胶囊数量、活跃时间、桥接频率）；DP 只覆盖统计量，不覆盖证书正文。
- 胶囊数量随用户/任务线性增长，需要归档/压缩；压缩可能破坏 Merkle 审计链，必须保留可验证摘要。
- η_ret 的校准依赖 qos 标签质量；qos 本身可能被污染，形成「用污染标签评估污染记忆」的回路。

  - v7-full、v8-full

  - (a) 跨用户污染：用户 B 说「把我的杯子拿来」，扁平记忆检索到用户 A 的杯子 → v8 必须拒绝跨胶囊读取

- **指标**：
  - 跨胶囊检索率（目标 0）、过期记忆使用率、污染攻击成功率
  - 检索 precision@4、η_ret 对坏记忆的 AUROC、证书审计完整率
  - 常规任务成功率、冷启动任务成功率、七硬门通过率
