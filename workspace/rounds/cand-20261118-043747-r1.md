# 第 1 轮（UniBot 线 · 动力学/关节空间控制子线；本轮灵感：「动力学」×「关节空间控制」）

> **续线与编号声明**：保留 UniBot-SAGE 第 1 轮已核实的官方事实，以及 U1–U12 / L1–L7 / E601–E618 基线；并行阻抗子线占用 U25–U36 / L15–L21 / E639–E656。本子线新增 **U37–U48 / L22–L28 / E657–E674**（U13–U24 继续留给并行决策子线，不占用）。SAGE 的 IP-02（抓握确认）、IP-03（chunk 缝合）、IP-06（代理评测）与本轮不冲突；本轮回答的是更底层的问题：**在只有位置目标、固定 chunk、隐藏低层控制器的接口上，怎样把“动力学”变成可用的控制变量？**
>
> **背景事实（沿用 SAGE 第 1 轮核实，检索日期 2026-11-17）**：宇树 UniBot-V1 通才模型赛道基于 Unitree G1 真机，32 项桌面操作任务（抓取 / 放置 / 双手协调），按平均成功率 + 平均步骤分排名，覆盖位置 / 干扰物 / 背景 / 未见物品 / 人为干扰 5 类泛化场景；官方数据集为 32 个 LeRobot v3.0 任务数据集，G1 + Dex1 夹爪，4 路 480×640@30fps 相机；提交接口为本地部署 observation→action 服务（websockets + msgpack + numpy），`control_space` ∈ {`joint`,`ee`} 二选一互斥，`action_chunk_size` 由选手声明，评测端可能采集 per-step 延迟与动作统计并用于可信度评估。榜单 `leaderboard_data.json` 是 **teaser / 占位表**（`gen_leaderboard.py` 生成、官方尚未正式发布），只作结构参考，不作调参依据。
>
> **接口复核（2026-11-18）**：动作目录只有**位置目标**——`joint` 下 7 维关节目标或 `ee` 下 6 维末端位姿，加 `left/right_gripper` 标量、`pivot` 7 维；**没有力矩、没有速度目标、没有刚度、没有 F/T、没有夹爪力**。`action_chunk_size` 是握手期声明的固定整数 `T_a≥1`，每个 chunk 按 index 0…T_a−1 顺序执行，官方未声明插值/平滑。⇒ 本文所称“动力学控制”只能是**在位置参考层做动力学补偿**，不是下发力矩的阻抗/力控。
>
> **数据纪律**：本轮新增数字来自本地官方数据缓存 `exp/duo_rows_cache/`（15/32 任务、91 episodes、42,800 帧、30 Hz，仅 state/action，不含图像）与四个可复算脚本；这是**子集探针**，不是完整 UniBot 基准。脚本与结果：`exp/dynamics_probe.py`、`exp/dynamics_probe2.py`、`exp/plantid_probe.py`、`exp/dart_sim.py`；结果 `exp/dynamics_probe_results.json`、`exp/dynamics_probe2_results.json`、`exp/plantid_probe_results.json`、`exp/dart_sim_results.json`。

## 0. 一句话直觉

UniBot 的动作不是“力矩”，而是一串**位置参考**；它进入一个未知的、有约 100 ms 纯延迟和约 0.5 s 残差收敛时间的低层闭环。真正决定成败的，不是把每个位置点预测得更准，而是**在参考层提前把低层动力学的滞后“预卷”进去**：让机器人到你想要的位置时，正好是你想要的时间。关节空间给了我们做这件事的自由度——可以直接塑造 7 维参考轨迹、保持冗余姿态、避开 IK 奇异，而不是把控制权交给一个看不见的逆解器。

## 1. 直觉与第一性原理

### 1.1 位置接口 = 未知低通环节，而不是理想执行器

设策略在时刻 `t` 输出位置参考 `u_t`，低层控制器与机械臂把观测状态推到 `s_{t+1}`。最朴素的近似是一个带纯延迟 `d` 的一阶闭环：

`s_{t+1} = s_t + α (u_{t−d} − s_t),  α = 1 − exp(−Δt/τ)`。

这里 `d` 是纯延迟，`τ` 是残差收敛时间常数。策略若把 `u_t` 当成“机器人此刻就在 `u_t`”，就会系统性高估自己的位置；在自由空间这只是跟踪误差，在接触/插入相位则会变成**侧向力、卡死或顶飞物体**。因此，第一性原理不是“学一个更大的策略”，而是**先把这个低通环节辨识出来，再在参考层反演它**。

### 1.2 我们从官方数据里量到的两个硬约束

对 15 个任务、91 个 episode、42,800 帧的官方 state/action 做离线探针（`dynamics_probe.py`）：

- **纯延迟 ≈ 3 帧（100 ms）**：对每个任务，`action[t]` 与 `observation.state[t+k]` 的中位关节空间误差在 `k=3` 处最小（15/15 任务一致）；`k=3` 的中位误差约 0.040–0.055 rad，`k=0` 约 0.053–0.063 rad。也就是说，数据里的命令语义比“当前状态”超前约 100 ms。
- **残差收敛 ≈ 0.5 s**：令 `e_t = s_t − u_{t−3}`，拟合 `e_{t+1} = a e_t + c`，得到误差衰减时间常数中位数 `τ ≈ 0.47 s`；硬接触组（8 个插入/旋转/细粒度任务）中位 `τ ≈ 0.53 s`，易任务组中位 `τ ≈ 0.43 s`。`τ` 与 teaser 平均成功率 Spearman `ρ = −0.571`（`p = 0.026`）：**越难的任务，残差收敛越慢**（接触阻力/摩擦/负载让误差更“粘”）。

这两个数不是“控制器规格”，而是**从数据反推出来的有效动力学**；它们足以支撑一个参考层的补偿器，但不足以证明评测端的控制器与遥操数据完全同源——这正是本轮最大风险。

### 1.3 chunk 不是“轨迹分辨率”问题，而是“反应量子”问题（反直觉负结果）

常见直觉是“接触相位要用短 chunk，因为需要高频反馈”。但官方数据给出了相反的信号：把关节轨迹按每 `L` 帧取一个路点、其余线性插值，归一化到该任务关节标准差后：

- 硬接触组的慢速帧（观测末端速度最低 30%）：`L=8` 的插值误差仅 **1.0%**，`L=16` 为 **2.8%**；
- 同一组的快速帧：`L=8` 为 **5.2%**，`L=16` 为 **13.9%**；
- 易任务组同样呈现“慢速相位更可压缩”（`L=8`：慢 1.9% vs 快 7.5%）。

也就是说，**接触相位本身是低带宽的**：它不需要更细的轨迹点，反而是自由空间的高速段更吃时间分辨率。长 chunk 在接触相位的真正代价不是“表示不了轨迹”，而是**反应量子**：

`R = d/f + T_a/f + τ_net + τ_settle`。

以 `d=3`、`f=30 Hz`、`T_a=8`、`τ_net≈50 ms` 计，`R≈0.10+0.27+0.05≈0.42 s`，再叠加约 0.5 s 的残差收敛，策略从“看到异常”到“真正改变状态”接近 1 s。**所以本轮不把“缩短 chunk”当作默认答案**；默认答案是把 chunk 内的参考提前规划好（DART），只有在“必须对突发事件反应”的任务上才用短 `T_a`，并用真实网络/延迟预算来选 `T_a`。

### 1.4 关节空间 vs 笛卡尔空间：选关节空间做动力学补偿

- **关节空间**：动作就是 7 维关节目标，和官方数据标签同构；低层控制器按关节闭环，我们辨识的 `A,B` 也是关节空间的。没有 IK 歧义，不会在插入点附近因为逆解跳变而制造伪动作。
- **笛卡尔空间**：视觉对齐更直观，但评测端要做 IK；在接近奇异、腕部受限或需要大范围姿态调整时，`ee` 目标的微小变化可能对应关节空间的大跳变，反而放大跟踪误差。
- **数据侧证据**：用观测关节速度与 6 维末端速度拟合经验 Jacobian，15 个任务的 6D 条件数中位数约 20–43，零空间运动能量占比约 8–14%；但条件数与 teaser 成功率**没有显著相关**（`ρ≈−0.07`，`p≈0.81`）。⇒ 奇异规避是“次要先验”，不是主红利；选关节空间的核心理由是**动力学可辨识、参考可直接塑造**，不是“关节空间一定更接近奇异”。

因此本子线声明 `control_space = joint`；`ee` 只作为 SAGE IP-07 的对照实验，不改变提交声明。

### 1.5 动力学残差是免费的接触/负载代理

如果模型能根据历史命令预测下一状态，定义残差 `r_t = s_t − ŝ_t`。在自由空间，`r_t` 主要是模型误差；在接触/负载/堵转时，`r_t` 会出现相位相关的偏移或尖峰。它不能替代力传感器，但可以作为**低成本的接触/滑移/堵转门控**，与 SAGE 的抓握确认器互补。注意：原始残差不是力读数，必须做相位条件化与 episode 内自校准，只做相对门控，不做绝对力阈值。

## 3. 研究问题（本轮）

- **Q1（可辨识性）**：在只有位置命令与关节状态的条件下，能否用每任务/每关节的线性或轻非线性模型，把 `d`、`τ`、`A,B` 辨识到“多步开环预测优于持久性/最后命令”的程度？跨任务共享多少参数才不悬？
- **Q2（参考整形）**：在固定 `T_a` 与网络延迟下，基于模型预测的 chunk 边界衔接 + 前馈预卷 + 小反馈，能否在不增加接触峰值力的前提下降低跟踪误差与 jerk？增益应该多保守？
- **Q3（轨迹参数化）**：把“逐步位置”换成“少量控制点 + 最小 jerk 展开”，能否同时降低命令 jerk、保持接触相位可表达性，并让 chunk 边界 C1/C2 连续？
- **Q4（关节空间 vs 笛卡尔）**：同一数据/算力下，joint 策略 + DART 是否在插入/旋转任务上不劣于 ee 策略？若劣，差距多大、是否值得切换 `control_space`？
- **Q5（反应量子与 `T_a`）**：给定实测 `d`、`τ_net`、`τ_settle`，`T_a` 的最优值是多少？是“长 chunk + 预卷”还是“短 chunk + 更频繁重规划”更划算？
- **Q6（安全与合规）**：动力学残差能否可靠地做接触/堵转门控（高精度、低召回）？模型失配时如何无扰回退到 SAGE 原始动作，且仍满足“单 checkpoint、单 API、无任务硬编码”？

## 4. 设计原则（继承 SAGE P1–P6，新增 D1–D4）

- **P1 单一计分货币**：只优化终态成功率；跟踪误差/jerk 只有能翻译成“最后一环被完成”时才保留。
- **P2 隐状态显式化**：延迟、残差、接触、负载都建模为带不确定性的量，不当作已知。
- **P3 技能/相位条件化**：复用 SAGE 的 `z_task × z_phase`；动力学代价按相位调度。
- **P4 推理期吸收偏移**：复用 SAGE 的上下文调制；本轮不扩大在线权重更新。
- **P5 合规优先**：单 checkpoint、单 API；不读取评测侧私有信息；不按任务名硬编码分支。
- **P6 单模型单空间**：对外只声明一个 `control_space`（本线选 `joint`），不把双空间当两个策略。
- **D1 先辨识、再控制**：任何“动力学”声明必须有离线/在线可复算的辨识与验证；没有模型就不做预卷。
- **D2 anticipate, don’t react**：优先把滞后预卷进参考；反应是昂贵的，不能把短 chunk 当万能药。
- **D3 平滑但可表达**：最小 jerk 参数化必须保留接触相位所需的局部修正能力；过度平滑会降低成功率。
- **D4 失配即回退**：模型不确定/残差异常/延迟超预算 ⇒ 退回 SAGE 原始动作；回退本身不能引入新的不稳定。

## 5. 方案总览：UniBot-DART

**DART = Dynamics-Aware Reference Trajectory**（动力学感知参考轨迹）。

四层：

1. **PlantID（离线 + 轻在线）**：用官方 state/action 拟合带延迟的关节空间模型 `s_{t+1}=A s_t + B u_{t−d}+c`；估计每关节 `τ`、噪声与不确定度；用阶跃探针在官方 client 上复核 `d`。
2. **RefGovernor（在线）**：在每个 chunk 边界预测“新 chunk 真正开始执行时机器人会在哪”，从预测状态而不是最后命令出发；用逆模型做前馈预卷，再用小反馈修正；加 jerk/加速度约束，输出 `T_a` 个位置目标。
3. **TrajToken（在线/离线）**：策略不再逐步回归位置，而是预测少量控制点（如每 chunk 3–5 个），解码时用最小 jerk 多项式展开到 30 Hz；chunk 边界可强制 C1/C2 连续。
4. **DynResidual + Audit（在线）**：用预测残差做接触/堵转门控（只做高精度低召回）；记录延迟、jerk、模型误差、回退次数；与 SAGE/CLAMP 的审计口径对齐。

**MVP（P0）**：PlantID + 边界状态预测 + 前馈预卷 + 最小 jerk 解码 + 回退。**P1**：反馈项、相位条件化代价、残差门控。**P2**：零空间姿态先验、在线模型微调。

**与 SAGE/CLAMP 的关系**：SAGE 决定“抓什么/何时抓”，CLAMP 决定“接触后怎么让”，DART 决定“命令怎么发”。DART 是动作解码器外层的参考整形器，不改变策略输出语义；模型失效时直接旁路。

## 6. 关键判断（本轮的可执行结论）

1. **先把 100 ms 延迟显式化**：任何 chunk 缝合/动作外推都必须从“预测的当前状态”出发，而不是“上一条命令”。SAGE 的 `a^{prev}_T + Δt·v` 是运动学外推；DART 改成模型外推。
2. **`T_a` 由反应预算决定，不由轨迹分辨率决定**：接触相位低带宽，长 chunk 不会“表示不了”；真正的硬约束是 `R`。先用官方 client 测 `d,τ_net`，再在 `T_a∈{2,4,8}` 中选净收益最高者。
3. **难任务要“慢而准”，易任务要“快而稳”**：数据上 jerk/停顿与成功率的相关方向相反；全局一个平滑系数会同时伤害两端。用 `z_phase` 调代价。
4. **关节空间是主空间，ee 是对照**：关节空间让模型辨识与参考整形都在同一坐标系里，避免 IK 奇异带来的伪动作；但若 E663 显示 ee 明显更好，则切 ee 并把 DART 改为末端空间模型。
5. **模型误差不是一票否决**：玩具实验显示 20% 参数误差下前馈仍有 ~73% 的 RMSE 降幅；关键是残差反馈 + 保守增益 + 回退。

## 7. 本轮最大风险

**一句话**：我们测到的 100 ms 延迟与 0.5 s 残差收敛来自**遥操数据**，评测端真实低层控制器可能更快、更硬或带未知滤波；若把遥操延迟当成评测延迟来做前馈，预卷可能把误差放大而不是抵消，尤其在 `T_a` 较大、接触相位需要快速反应时。

# 第 1 轮产物 · 创新点清单 v1（UniBot 动力学/关节空间子线）：**UniBot-DART**

> **DART = Dynamics-Aware Reference Trajectory**（动力学感知参考轨迹）。
> **续线**：SAGE 线的 U1–U12 / L1–L7 / E601–E618 作为已封存基线继续引用（本文件不重复展开）；阻抗子线占用 U25–U36 / L15–L21 / E639–E656；本子线新增 **U37–U48 / L22–L28 / E657–E674**（U13–U24、L8–L14、E619–E638 留给并行决策子线）。

## 0. 本轮结论摘要

**一句话路线**：把“动力学”从策略内部的隐式能力，变成动作解码器外层的**可辨识、可反演、可回退**的参考整形器：先用官方 state/action 辨识关节空间低层模型与延迟，再在 chunk 边界预测真实状态、做前馈预卷与最小 jerk 解码，最后用残差门控与回退保证模型失配时不伤基线。

**四条硬结论（均可复算）**：

| # | 结论 | 证据 | 设计含义 |
|---|---|---|---|
| C1 | 动作到状态存在约 **3 帧（100 ms）纯延迟** | 15/15 任务 `action[t]` 与 `state[t+3]` 的中位关节误差最小；`k=3` 误差 0.040–0.055 rad | chunk 缝合必须从“预测状态”出发，不能从“最后命令”出发 |
| C2 | 残差收敛约 **0.5 s**，难任务更慢 | 误差衰减 `τ` 中位 0.47 s；硬任务 0.53 s vs 易任务 0.43 s；`ρ=−0.571`（`p=0.026`） | 只发位置不够；需要模型预测 + 小反馈 |
| C3 | 接触相位是**低带宽**的，长 chunk 的代价是反应量子而非表示能力 | 慢速帧 `L=8` 插值误差 1.0%，快速帧 5.2%（硬任务组） | 不默认“接触就缩短 chunk”；用反应预算选 `T_a` |
| C4 | 线性关节模型**足够做补偿**，但不完美 | 一步 RMSE 0.0108 vs 持久性 0.0136（好 15.2%）vs 最后命令 0.0244（好 62.2%）；13/15 优于持久性 | 模型 + 残差反馈 + 回退，而不是“模型即真理” |

**本轮押注**：C1+C2 是接口的物理事实，C3 是反直觉但可检验的负结果，C4 给出可行的工程路径。四者合起来支持一个很窄但很硬的主张：**在位置接口上，先做动力学辨识与参考预卷，比继续堆策略容量更靠近“最后一毫米”的瓶颈。**

## 2. 创新点详述

### IP-09 · PlantID 关节空间动力学辨识（P0）

- **动机**：官方动作是位置目标，低层控制器是黑箱；SAGE 的 chunk 缝合用“上一条命令 + 一阶外推”，隐含假设机器人已经在上一条命令处。但数据表明 `action[t]` 要到 `state[t+3]` 才最接近，且残差需要约 0.5 s 收敛。这个假设在自由空间只造成小误差，在接触/插入相位会把“参考跳变”变成“力尖峰”。
- **与现有方案的差异**：现有 VLA 把低层控制器当作理想执行器，最多在训练时做动作平滑；我们把低层控制器当作一个**需要辨识的受控对象**，显式估计 `d`、`τ`、`A`、`B` 与噪声，并把不确定度传给上层。它不是“再学一个世界模型”，而是一个**低维、可解释、可复算的系统辨识**。
- **技术可行性**：高。官方数据同时给出 `observation.state.*_arm` 与 `action.*_arm`，天然是 step-response 数据；每任务约 3000 帧、7 关节，线性 ARX 的参数量仅 `7×7 + 7×7 + 7`，ridge 最小二乘秒级可解。
- **所需资源**：数据 = 官方 32 数据集（本轮缓存仅 15 任务）；算力 = CPU/单卡分钟级；接口 = 无新增字段（纯离线 + 策略内部状态）。
- **落地步骤**：
  1. 统一解码官方 32 个 LeRobot v3.0 数据集的 `state.*_arm` / `action.*_arm`，按连续段切分；
  2. 用“命令-状态误差曲线”估计 `d`（`k=0…5` 取中位误差最小），并在官方 client 上做阶跃探针复核；
  3. 对每任务/每关节拟合 `s_{t+1}=A s_t+B u_{t−d}+c`，用 ridge + 时间切分验证；
  4. 估计残差协方差与每关节 `τ`；对不确定度高的关节收缩到“共享模型”；
  5. 导出多步开环预测器（horizon 4/8/16），与持久性/最后命令/线性外推三条基线对比；
  6. 给 RefGovernor 提供 `(d, A, B, c, τ, Σ)` 与一个“模型可信度”标量。
- **风险**：①遥操数据的延迟可能来自采集管线而非评测控制器 ⇒ 必须用官方 client 阶跃探针复核；②低层控制器可能是非线性/变增益 ⇒ 用局部线性 + 残差反馈兜底；③跨任务共享可能抹平接触差异 ⇒ 采用“共享主干 + 每任务低秩适配”，并保留每任务独立版作对照。

### IP-10 · RefGovernor 延迟补偿参考整形（P0）

- **动机**：给定 `d` 与 `τ`，策略输出 `u_t` 后，机器人不会立刻到达；如果每个 chunk 都从“上一条命令”续起，参考轨迹会在边界处产生一个低层控制器必须追赶的跳变。正确做法是：在 chunk 开始时预测“新 chunk 真正被执行时机器人会在哪”，从这个预测状态出发规划，并把 `u` 提前 `d+τ` 预卷。
- **与现有方案的差异**：SAGE 的 `Stitcher` 是运动学外推（`a_T + Δt·v + r`）；DART 是**模型预测 + 逆模型前馈**。前者只保证参考连续，后者保证“参考连续 + 低层动力学补偿”。两者可叠加：先用 DART 预测状态，再用 SAGE 的 C0 缝合做最后一道保险。
- **技术可行性**：中–高。一阶/二阶线性模型的前馈可写成闭式；小反馈可用比例项；完整 QP 只有 `7×T_a` 个变量（`T_a=8` 时 56 维），CPU 上 <2 ms。
- **所需资源**：模型 = IP-09；在线算力 = 每个 chunk 一次矩阵乘法 + 小 QP；接口 = 仍是单 `get_action`，不新增字段。
- **落地步骤**：
  1. 用官方 client 复刻评测闭环，测出真实 `d`、`τ_net`、chunk 执行语义；
  2. 实现边界状态预测：`ŝ_{t+T_a} = A^{T_a} s_t + Σ A^{i} B u_{...}`；
  3. 实现前馈逆模型：对一阶模型 `u_t = x*_{t+d} + (x*_{t+d+1}−x*_{t+d})/α`；对二阶模型用状态空间逆；
  4. 加小反馈：`u ← u + K(x*−ŝ)`，`K` 由模型不确定度与延迟决定；
  5. 加 jerk/加速度约束与限幅，输出 `T_a` 个位置目标；
  6. 与 SAGE 原始动作、SAGE Stitcher、纯前馈、前馈+反馈做 A/B；
  7. 记录模型误差、回退次数、延迟 p99。
- **风险**：①模型误差在前馈中被放大（尤其高频）⇒ 20% 误差下仍有增益，但 100% 误差下几乎无增益，必须用残差反馈与保守增益；②QP/矩阵运算增加延迟 ⇒ 只在小维度做，热点路径避免 Python 循环；③评测端若自带强滤波/插值，前馈可能被抵消 ⇒ 以真机 A/B 决定是否启用（默认可旁路）。

### IP-11 · MinJerkToken 最小 jerk 轨迹参数化（P0）

- **动机**：逐步回归 30 Hz 位置会把“动作”当成独立标签，产生高频抖动；chunk 边界也容易出现速度/加速度不连续。最小 jerk 多项式是关节空间轨迹生成的经典基，天然 C2 连续，且只需少量控制点。
- **与现有方案的差异**：常见 VLA 输出每步动作或固定长度的 action chunk；我们让策略输出**控制点/样条系数**，由解码器展开为 30 Hz 位置参考。这样策略的“预测负担”从 `T_a×7` 个独立数降到 `3–5×7` 个控制点，同时把平滑性变成结构先验，而不是事后滤波。
- **技术可行性**：高。最小 jerk 基是闭式；数据侧可用最小二乘把每段轨迹拟合成控制点，作为训练标签；解码耗时 <0.1 ms。
- **所需资源**：数据 = 官方数据（拟合控制点）；算力 = 小；接口 = 无。
- **落地步骤**：
  1. 对官方每段关节轨迹做分段最小 jerk 拟合，选控制点数量 `K∈{3,5,8}` 与分段长度；
  2. 训练策略头预测控制点（可复用 SAGE 的动作头，只改输出维度/损失）；
  3. 解码器把控制点展开为 `T_a` 个位置，强制 chunk 边界位置/速度连续；
  4. 与逐步位置基线比较 jerk、跟踪误差、成功率；
  5. 保留“控制点 + 残差”形式：接触相位允许在控制点之外加小残差，避免过度平滑。
- **风险**：①过度平滑会抹掉接触相位的微调 ⇒ 控制点数量按相位可调，并保留残差通道；②控制点拟合误差会改变示教动作分布 ⇒ 用重构误差筛选训练样本；③如果评测端要求逐 step 语义，展开后的位置仍然合法，不改变接口。

### IP-12 · PhaseDyn 相位条件化动力学代价（P1）

- **动机**：数据上“易任务更抖、难任务更慢更常停顿”（jerk 与成功率 `ρ=+0.564`，停顿比例 `ρ=−0.538`）。这说明不存在一个全局最优的平滑/带宽；自由空间要快，接触相位要慢而准。
- **与现有方案的差异**：现有做法通常固定平滑系数或固定 chunk；我们让代价与反馈增益随 SAGE 的 `z_phase`（reach/grasp/lift/transport/align/insert/release）切换：transport 允许高速度/低 jerk 权重，align/insert 提高位置精度权重、降低速度、增大反馈。
- **技术可行性**：中。相位标签可由 SAGE 的相位分类器在线给出；离线可用 VLM/规则伪标。
- **所需资源**：小；接口无新增。
- **落地步骤**：①复用 SAGE 相位标签；②定义每相位的 `(w_pos, w_vel, w_jerk, K_fb, T_a 建议)`；③在 RefGovernor 中按相位切换；④消融：固定代价 vs 相位代价；⑤检查相位错分时的退化（低置信退回统一代价）。
- **风险**：相位错分会把“慢而准”用到搬运，或把“快”用到插入 ⇒ 低置信时退回保守统一代价；相位边界要加迟滞。

### IP-13 · NullSpacePrior 零空间姿态先验（P2）

- **动机**：7 自由度机械臂对 6 维末端任务是冗余的；数据中零空间运动能量占比约 8–14%，说明示教确实使用了冗余。保持可操作度/避开限位可以降低“够不到/姿态别扭”导致的失败。
- **与现有方案的差异**：纯末端策略通常把冗余交给 IK 随机解；我们在关节空间显式加一个零空间姿态先验（朝向示教均值/高可操作度方向），只在零空间内作用，不改变末端任务。
- **技术可行性**：中。需要经验 Jacobian 或简化运动学；数据可估计每任务的平均姿态与可操作度。
- **所需资源**：小；接口无新增。
- **落地步骤**：①从数据估计每任务/相位的关节姿态分布与经验 Jacobian；②定义零空间代价 `‖N(q−q_prior)‖²`；③加入 RefGovernor QP；④在边界/高位任务 A/B；⑤若无效则剪掉。
- **风险**：数据中条件数与成功率无显著相关（`ρ≈−0.07`），所以收益可能很小；若与策略学习冲突则降为 P2 或砍掉。

### IP-14 · DynResidual 动力学残差门控（P1）

- **动机**：有了 `ŝ_t`，残差 `r_t=s_t−ŝ_t` 是免费的“模型没解释掉的运动”。接触、负载、堵转、滑移都会让残差出现相位相关的变化；它可以补充 SAGE 的抓握确认器（后者只看夹爪/腕部）。
- **与现有方案的差异**：不是把残差当力传感器，而是做**相位条件化 + episode 内自校准的相对门控**：只在“残差显著高于该相位基线”时触发保守动作（停止盲搜/减速/回退），高精度低召回。
- **技术可行性**：高（纯软件）；难点是模型误差与接触信号的混淆。
- **所需资源**：极小；接口无新增。
- **落地步骤**：①在离线数据上计算每任务/每相位的残差分布；②用 robust z-score 或分位数定阈值；③在线只做门控，不做绝对力估计；④与 SAGE `g_t` 做与/或逻辑，避免双重误报；⑤真机 A/B 验证误报成本。
- **风险**：模型误差在未见物品上漂移 ⇒ 阈值按 episode 自校准；残差门控只在高置信时触发；若 AUROC <0.65 则砍掉，只保留审计。

## 3. 符号与定义（U37–U48）

| 符号 | 含义 |
|---|---|
| `s_t ∈ R^7` | 左右臂各 7 维关节观测状态（单手；双侧分别建模） |
| `u_t ∈ R^7` | 关节位置命令（`action.*_arm`） |
| `d` | 命令→状态的纯延迟（帧） |
| `τ` | 残差收敛时间常数（秒） |
| `A, B, c` | 关节空间线性模型参数 |
| `ŝ_t` | 模型预测状态 |
| `x*_t` | 策略/规划器给出的期望状态轨迹 |
| `r_t` | 动力学残差 `s_t−ŝ_t` |
| `R` | 反应量子（秒） |
| `T_a` | 官方 action chunk 长度 |
| `K_fb` | 反馈增益矩阵/标量 |
| `C_phase` | 相位条件化代价权重 |

**定义 U37（关节空间受控对象）** `s_{t+1} = A s_t + B u_{t−d} + c + ε_t`，`ε_t` 为零均值有界噪声；`A,B,c` 由 IP-09 辨识。
**定义 U38（纯延迟估计）** `d = argmin_{k∈{0..5}} median_t ‖s_{t+k} − u_t‖`；在官方 client 上用阶跃响应复核，若不一致以真机为准。
**定义 U39（残差收敛时间）** 对 `e_t = s_t − u_{t−d}` 拟合 `e_{t+1}=a e_t+c`，`τ = −Δt / ln a`（`0<a<1`）。
**定义 U40（参考整形）** `u_{1:T_a} = argmin Σ_t ‖ŝ_t − x*_t‖²_{W_p} + λ_v‖Δu_t‖² + λ_j‖Δ²u_t‖² + λ_f‖u_t−u^{policy}_t‖²`，s.t. `ŝ_{t+1}=Aŝ_t+Bu_{t−d}+c`，`|Δu_t|≤v_max`，`|Δ²u_t|≤a_max`。
**定义 U41（最小 jerk 基）** 对起止 `(x_0,x_1)` 与时长 `T`，`x(t)=x_0+(x_1−x_0)(10s³−15s⁴+6s⁵)`，`s=t/T`；其三阶导最大值为 `60‖x_1−x_0‖/T³`。
**定义 U42（控制点 token）** 策略输出 `K` 个控制点 `{(t_k,x_k)}`，解码器用分段最小 jerk/三次样条展开到 30 Hz；`K` 可随相位在 `{3,5,8}` 中选。
**定义 U43（相位代价）** `C_phase(z_phase) = (W_p,W_v,W_j,K_fb)`，由离线调参 + 在线低置信回退组成。
**定义 U44（边界预测）** `ŝ_{t+T_a} = A^{T_a} s_t + Σ_{i=0}^{T_a−1} A^{T_a−1−i} B u_{t+i−d} + (Σ A^i)c`。
**定义 U45（残差门控）** `contact_flag = 1` 当且仅当 `r_t` 的相位条件化 robust z-score `> z_hi` 且持续 `m` 帧；否则 0。
**定义 U46（反应量子）** `R = d/f + T_a/f + τ_net + τ_settle`；`f=30 Hz`，`τ_net` 为网络往返，`τ_settle` 为残差收敛。
**定义 U47（安全投影）** 把 `u` 投影到集合 `{u: |Δu|≤v_max, |Δ²u|≤a_max, q_min≤q≤q_max}`；无精确限位时用数据分布的 1%/99% 分位作软限位。
**定义 U48（回退谓词）** `fallback = 1` 若 `model_confidence<θ_m` 或 `|r_t|>θ_r` 连续 `m` 帧或 `R>R_budget`；回退到 SAGE 原始动作，并保持当前 episode 状态隔离。

## 4. 关键算法骨架

```python
# ===== IP-09: 关节空间系统辨识（离线） =====
def fit_plant(segments, d_grid=range(6), ridge=1e-3):
    # segments: list of (S[n,7], U[n,7])
    # 1) delay: median joint error of U[t] vs S[t+k]
    d = pick_delay(segments, d_grid)
    X, Y = [], []
    for S, U in segments:
        for t in range(d, len(S) - 1):
            X.append(np.concatenate([S[t], U[t - d], [1.0]]))
            Y.append(S[t + 1])
    X, Y = np.array(X), np.array(Y)
    W = np.linalg.solve(X.T @ X + ridge * np.eye(X.shape[1]), X.T @ Y)
    A, B, c = W[:7], W[7:14], W[14]
    resid = Y - X @ W
    return {"d": d, "A": A, "B": B, "c": c, "cov": np.cov(resid.T)}

# ===== IP-10: 参考整形（在线，每 chunk 一次） =====
class RefGovernor:
    def __init__(self, plant, K_fb=0.3, v_max=1.5, a_max=8.0):
        self.p = plant; self.K = K_fb; self.vmax = v_max; self.amax = a_max
        self.s_hat = None; self.u_hist = []

    def reset(self, s0):
        self.s_hat = s0.copy(); self.u_hist = []

    def predict_boundary(self, s_now, u_prev):
        # U44: rollout A,B over T_a steps with the previous chunk
        s = s_now.copy()
        for u in u_prev:
            s = self.p["A"] @ s + self.p["B"] @ u + self.p["c"]
        return s

    def shape(self, x_star, u_policy, s_now, u_prev, phase_weights):
        # 1) start from predicted state, not the last command
        s0 = self.predict_boundary(s_now, u_prev)
        # 2) inverse-model feedforward (U40) + small feedback
        u = []
        s = s0.copy()
        for t in range(len(u_policy)):
            alpha = 1.0 - np.exp(-(1/30) / self.p["tau"])
            j = min(t + self.p["d"], len(x_star) - 1)
            jn = min(j + 1, len(x_star) - 1)
            u_ff = x_star[j] + (x_star[jn] - x_star[j]) / max(alpha, 1e-6)
            u_fb = u_ff + self.K * (x_star[t] - s)
            u.append(np.clip(u_fb, u_policy[t] - 0.15, u_policy[t] + 0.15))
            s = self.p["A"] @ s + self.p["B"] @ u[-1] + self.p["c"]
        # 3) jerk/accel projection and blend with policy action (U40/U47)
        u = smooth_and_clip(np.array(u), self.vmax, self.amax)
        return u

# ===== IP-11: 最小 jerk 解码（在线） =====
def min_jerk_decode(control_points, T_a):
    # control_points: [(t_k, x_k)], x_k in R^7
    out = []
    for t in range(T_a):
        # piecewise min-jerk between bracketing control points
        out.append(eval_min_jerk(control_points, t))
    return np.array(out)   # shape (T_a, 7)

# ===== IP-14: 残差门控（在线） =====
class DynResidual:
    def __init__(self, thr=2.5, m=3):
        self.thr, self.m = thr, m; self.buf = []

    def update(self, s, s_hat):
        r = s - s_hat
        self.buf.append(r); self.buf = self.buf[-self.m:]
        z = robust_z(r)                      # phase-conditioned, episode-calibrated
        return z > self.thr and len(self.buf) >= self.m
```

## 5. 推导（引理 L22–L28）

**引理 L22（延迟可辨识性）** 若命令-状态误差曲线 `E(k)=median‖s_{t+k}−u_t‖` 在 `k=d` 处有唯一最小值，且噪声/运动速度有界，则 `d` 的估计误差不超过 ±1 帧；当速度趋近 0 时 `E(k)` 变平，`d` 不可辨识 ⇒ 必须在有明显运动的片段上估计。官方 15 任务均在 `k=3` 取最小，说明数据中运动片段足够。∎

**引理 L23（一阶前馈的误差界）** 对 `s_{t+1}=s_t+α(u_{t−d}−s_t)`，若命令 `u_t=x*_{t+d}+(x*_{t+d+1}−x*_{t+d})/α`，则无噪声、模型精确时 `s_t=x*_t`。若模型参数 `α̂` 有相对误差 `δ`，则前馈残差量级为 `O(δ‖Δx*‖/α)`；因此模型误差对**高速段**更敏感，接触相位（低速）反而更稳。这解释了为什么 20% 模型误差下前馈仍有增益，而 100% 误差时几乎失效。∎

**引理 L24（边界预测优于最后命令）** 设真实状态 `s_t` 与最后命令 `u_{t−1}` 的差为 `e_t=s_t−u_{t−1}`。SAGE 式缝合把新 chunk 首命令设成 `u_{t−1}+Δ`，边界参考跳变为 `e_t+Δ`；DART 从 `ŝ_t` 出发，跳变为 `(ŝ_t−s_t)+Δ`。只要 `‖ŝ_t−s_t‖<‖e_t‖`，DART 的边界跳变更小。数据上 `action[t]` 与 `state[t+3]` 更接近，说明 `e_t` 不小；模型预测误差通常小于 `e_t`，故 DART 有优势。∎

**引理 L25（最小 jerk 的连续性）** 五次最小 jerk 多项式 `x(s)=x_0+(x_1−x_0)(10s³−15s⁴+6s⁵)` 满足 `x(0)=x_0, x(1)=x_1, x'(0)=x'(1)=0, x''(0)=x''(1)=0`，即位置、速度、加速度在控制点处连续；其三阶导最大值 `60‖x_1−x_0‖/T³` 给出 jerk 上界。⇒ 用控制点解码可在结构上保证 C2 连续，并给出可检查的 jerk 预算。∎

**引理 L26（反应量子下界）** 在固定 `T_a`、纯延迟 `d`、网络 `τ_net`、残差收敛 `τ_settle` 下，策略从“观测到异常”到“状态开始改变”的时间至少为 `R=d/f+T_a/f+τ_net`；若要求异常被抑制到阈值以下，还需加 `τ_settle`。⇒ 不能通过“更好的策略”把 `R` 降到 0；只能减小 `T_a`、降低 `d/τ_net`，或**提前预测**（DART）把“反应”变成“预判”。∎

**引理 L27（残差门控的可分性）** 若自由空间模型误差上界为 `ε`，接触引起的状态偏离为 `Δ_c`，且 `Δ_c>2ε`，则存在阈值把两者分开；代价是 `ε` 越大，可检测的最小接触越弱。用相位条件化与 episode 内自校准可降低 `ε` 的有效值，但不能消除模型失配。⇒ 只做高精度低召回门控，不做绝对力估计。∎

**引理 L28（回退不劣于基线）** 若回退谓词只依赖模型置信度/残差/延迟，且回退动作就是 SAGE 原始动作，则回退后的行为与基线逐动作相同；DART 只在“模型可信且未超预算”时改变动作。因此最坏情况是“浪费了在线计算”，而不是“比基线更差”。前提是回退切换本身不引入状态污染（每端口状态隔离、`reset()` 清空）。∎
