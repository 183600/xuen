# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「嵌入式系统」×「激光雷达」）

> 第 54 轮把技能组合推进为动作-鲁棒性双证书（`α_S`、`A_cert`、`γ_ce`）。但该体系隐含两个未言明的前提：证据在「理想传感器 + 充足算力」上采集，且证书一经签发便全域有效。真实部署却发生在 **资源受限的嵌入式端** 与 **有物理缺陷的激光雷达** 上：点云带运动畸变、时间戳抖动、反射率衰减与多径鬼点，CPU 频率、功耗、热节流又随时改变可用算法。本轮把 **物理测量契约** 与 **资源预算** 提升为证书的一等公民。核心矛盾：H22：证书缺少「定义域」，宿主/仿真上成立的 `ρ` 在嵌入式 LiDAR 上会静默失效；H23：感知本身是动作且消耗预算，鲁棒性应写成 `ρ(d|p,σ)` 并按「每焦耳」认证；H24：动作会反过来改变测量（高速→运动畸变），认证因此是自指不动点问题。

## 0. 直觉与动机

**灵感 1（点云不是几何，而是物理测量契约的产物）**
直觉：同一间屋子的「几何真值」只有一个，但激光雷达给出的点云取决于扫描周期、时间同步误差、目标反射率、环境光、温度与运动速度。也就是说，点云是 `(几何, 物理条件)` 的联合投影，而不是几何本身。我们给每一帧附加 **物理溯源向量** `p = (Δt_sync, ε_deskew, n_eff, r_ref, g_ghost, T_die, P_inst)`，并定义其 **畸变包络** `D`。只有 `p ∈ D` 的帧才是「可被证书引用的测量」。这把传感器从「透明管道」变成「有契约、会违约的测量仪器」。

**灵感 2（证书必须有定义域，而不是一个全域标量）**
直觉：第 53–54 轮的鲁棒性谱 `ρ_S(d)` 被当成放之四海皆准的标量。但在嵌入式端，同一技能的鲁棒性随热节流、功耗档位、点云稀疏度而连续变化。因此正确对象是 **资源-物理条件鲁棒性曲面** `ρ_S(d | p, σ)`，其中 `σ` 为资源状态（频率、内存、结温、电量）。证书不再是数字，而是一张 **带边界的映射**：`V_S(ρ_min) = {(p,σ) : min_d ρ_S(d|p,σ) ≥ ρ_min}`。部署 = 检查当前 `(p,σ)` 是否落在 `V_S` 内，而不是相信一个离线数字。

**灵感 3（感知也是动作，鲁棒性要按每焦耳认证）**
直觉：嵌入式 LiDAR 允许我们选择扫描模式、ROI 加密、帧率、积分时间、降采样率——这些既改变感知质量，也改变功耗与时延。所以应引入 **感知动作空间 `A_s`**，把总动作写成 `A = A_c × A_e × A_s`。于是技能组合不仅要问「动作是否兼容」，还要问「在给定能量预算下，这个感知配置能否维持证书」。这把鲁棒性从「能不能」变成「每焦耳能维持多少」，天然适配嵌入式系统的能量-算力-时延三角。

**灵感 4（自指失真：动作会改写自己的测量，形成认证速度上限）**
直觉：机器人加速会增大 LiDAR 运动畸变与时间戳错位，而畸变又直接侵蚀用于认证该动作的感知质量：`a → p(a) → ρ(d|p(a),σ)`。于是「这个速度是否被认证」变成一个不动点：认证所依赖的测量，正是该动作自己破坏的。我们定义 **认证操作包络** `O_S = {a : (Ψ_P(a), Ψ_Σ(a)) ∈ V_S}`，其边界常常表现为一条「认证速度上限」`v*(S)`。这条上限不是控制器写进去的，而是 **传感器物理 + 资源预算替机器人写下的**，且它在高速时自我收紧。

**灵感 5（从仿真证据到嵌入式证据：可移植性证书）**
直觉：第 53–54 轮的证书多在宿主/仿真上生成，直接搬到嵌入式目标会因 INT8 量化、降采样、调度抖动而发生「静默语义漂移」。若感知特征映射 `Φ` 对点云 Wasserstein 距离是 `L`-Lipschitz 的，则目标端扰动 `δ_emb` 可被宿主证据加常数界住：`||Φ(P_target) − Φ(P_host)|| ≤ L·δ_emb`。这把「部署间隙」变成一张 **可移植性证书 PDC**：明确记录量化、降采样、抖动预算与 Lipschitz 常数，超预算即拒绝部署。证据本身也要「可搬运」。

**灵感 6（证书会过期：新鲜度与优雅降级阶梯）**
直觉：热节流和电量下降是慢变量，但会在几分钟内把 `(p,σ)` 推出 `V_S`。因此证书必须有 **TTL 与漂移绊线**（CFR）：`fresh / stale / invalid` 三态，任一帧 `p ∉ D` 或 `σ ∉ Σ_op` 立即失效。失效后不应硬撑，而应沿 **降级阶梯 DGL** 有序列地削减能力（降帧率、缩 ROI、降速度、切换轻量特征），同时保持核心安全不变量 `I_safe`。优雅降级 = 保证书的能力卸载。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（LiDAR 物理溯源向量与畸变包络）**
一帧测量的物理溯源向量
```
p = (Δt_sync, ε_deskew, n_eff, r_ref, g_ghost, T_die, P_inst) ∈ P
```
分别表示同步偏差、去畸变残差、有效点密度、平均反射率、鬼点比例、结温、瞬时功率。畸变包络 `D = ∏_i [l_i, u_i]`。**可引用帧** 当且仅当 `p ∈ D`。诱导几何误差满足
```
δ_geo(p) ≤ v·(|Δt_sync| + τ_scan/2) + c_1/n_eff + c_2·(1−r_ref) + c_3·g_ghost
```
其中 `v` 为自车速度，`τ_scan` 为扫描周期。右侧第一项即运动畸变主项，显式把「动作」与「测量误差」耦合。

**定义 122（资源状态与操作包络）**
资源状态 `σ = (f_cpu, m_used, T_die, P_batt, e_rem) ∈ Σ`。**操作包络**
```
Σ_op = {σ : deadline_met(σ) ∧ T_die ≤ T_trip ∧ e_rem ≥ e_min}
```
资源压力 `π(σ) ∈ [0,1]` 为归一化负载。`Σ_op` 之外不允许签发任何实时证书。

**定义 123（资源-物理条件鲁棒性谱与有效域）**
技能 `S` 的鲁棒性谱推广为
```
ρ_S : 𝔇_d × P × Σ → [0,1],   (d,p,σ) ↦ ρ_S(d|p,σ)
```
假设其对 `δ_geo(p)` 与 `π(σ)` 单调不增。**有效域**
```
V_S(ρ_min) = {(p,σ) : ∀d∈𝔇_d, ρ_S(d|p,σ) ≥ ρ_min}
```
证书对象为三元组 `Cert_S = (ρ_S, V_S, evidence)`。**关键语义转变**：证书是带定义域的映射，不再是标量。

**定义 124（感知动作空间、动作-感知耦合与认证包络）**
感知动作
```
a_s = (scan_pattern, ROI, frame_rate, integration, downsample) ∈ A_s
```
总动作空间 `A = A_c × A_e × A_s`。耦合映射 `Ψ = (Ψ_P, Ψ_Σ) : A → P × Σ`，表示动作如何诱导测量畸变与资源占用。动作 `a` **可认证** 当且仅当
```
p(a) = Ψ_P(a),  σ(a) = Ψ_Σ(a),  (p(a),σ(a)) ∈ V_S(ρ_min)
```
**认证操作包络** `O_S = {a ∈ A : a 可认证}`。其速度截面给出 **认证速度上限**
```
v*(S, a_s) = sup{v : (v, a_s) ∈ O_S}
```
由于 `δ_geo` 随 `v` 增大，`O_S` 通常是非凸且随 `a_s` 收缩的。

**定义 125（嵌入式可移植性证书 PDC）**
设感知特征映射 `Φ` 对点云 1-Wasserstein 距离满足 `L`-Lipschitz。目标端相对宿主证据的扰动
```
δ_emb = L·(δ_quant(q) + δ_down(s) + v_max·δ_jitter(j)) + δ_sensor
```
其中 `q` 为量化配置、`s` 为降采样率、`j` 为调度抖动。**可移植性证书**
```
PDC = (L, q, s, j, δ_emb, evidence),  部署间隙 G_emb = δ_emb / Θ_pdc
```
仅当 `G_emb ≤ 1` 且 `V_target ⊇ V_host ∩ D_deploy` 时允许部署。

**定义 126（证书新鲜度与续证）**
证书年龄 `τ = now − t_issued`，漂移
```
Δ_drift = ||p ⊖ p_0||_D + ||σ ⊖ σ_0||_Σ
```
状态
```
state ∈ {fresh, stale, invalid}
invalid 若 p ∉ D ∨ σ ∉ Σ_op
stale   若 τ > T_cert ∨ Δ_drift > θ_drift
fresh   其他
```
续证需重跑 `(p,σ)` 局部校准并带 hysteresis，避免 fresh/stale 抖动。

**定义 127（资源-感知-动作联合证书 JEC）**
```
J_emb = (ρ_S(·|p,σ), V_S, A_cert, PDC, state, I_safe, evidence)
```
部署可判定条件：
```
(p,σ) ∈ V_S ∧ G_emb ≤ 1 ∧ state = fresh ∧ I_safe ⊨ true
```
其中 `I_safe` 为与具体任务无关的硬安全不变量（不碰撞、不失稳、不越界）。任一条不满足则拒绝，**未知一律按拒绝处理**。

**定义 128（优雅降级阶梯 DGL）**
降级层级 `ℓ = 0..k`，每层给出 `(a_s^ℓ, b_ℓ, C_ℓ, I_ℓ)`：感知配置、资源预算、任务能力、保持的不变量。**安全保序降级** 要求
```
∀ℓ, I_safe^core ⊆ I_ℓ,   且   ℓ→ℓ+1 时 C_{ℓ+1} ⊆ C_ℓ
```
降级策略 `π_deg : Σ → {0..k}`。一次层级切换必须同时满足：目标层资源可行、核心安全不变量仍成立、当前证书未被切换动作本身破坏（即 `(p(a^{ℓ+1}),σ(a^{ℓ+1})) ∈ V_S`）。

## 2. 关键算法 伪代码

### IP-121 LPP（LiDAR Physical Provenance）

```python
def lidar_provenance(frame, imu, clock, thermal, max_pts=2048):
    pts = frame.subsample(max_pts)                 # 限算力，O(N_s)
    dt = clock.offset(imu.t, frame.t)
    eps = deskew_residual(pts, imu, dt)            # v*dt + scan/2 残差
    n_eff = effective_density(pts, frame.range_bins)
    r_ref = mean_reflectivity(pts)
    g_ghost = ghost_ratio(pts, reflectivity_model)
    return Provenance(dt, eps, n_eff, r_ref, g_ghost,
                      thermal.t_die, thermal.p_inst)

def frame_admissible(p, D):
    return all(D[i].lo <= p[i] <= D[i].hi for i in range(len(D)))
```

### IP-122 REV（Resource-Elastic Validity）

```python
def build_validity_domain(skill, D, Sigma_op, dims, rho_min, sampler):
    V, surf = set(), {}
    for (p, sigma) in sampler.cover(D, Sigma_op):   # HIL 扫掠 + 主动设计
        rho = measure_rho_hil(skill, dims, p, sigma)  # 实测或代理
        surf[(p, sigma)] = rho
        if min(rho[d] for d in dims) >= rho_min:
            V.add((p, sigma))
    model = fit_monotone_envelope(surf)             # 对 δ_geo、π 单调
    return ValidityDomain(V, model)

def in_domain(p, sigma, V, model, margin=0.05):
    if (p, sigma) in V:
        return True
    return model.predict(p, sigma) - margin >= min_rho
```

### IP-123 SAP（Sensing-Action Profile + 自指不动点）

```python
def certified_operating_point(skill, a_s, v0, D, Sigma_op, V, K=8):
    v = v0
    for _ in range(K):
        a = (v, a_s)
        p, sigma = psi(a)                    # 动作诱导的测量与资源状态
        if frame_admissible(p, D) and sigma in Sigma_op and (p, sigma) in V:
            return ('ok', v, p, sigma)
        v = max(v_min, 0.9 * v)              # 降速以削减运动畸变
    return ('reject', 'no_certified_point', None, None)

def plan_sensing(task, skills, D, Sigma_op, energy_budget):
    best = None
    for a_s in enumerate_sensing_actions(task):
        out = certified_operating_point(skills, a_s, task.v_max, D, Sigma_op, V)
        if out[0] != 'ok':
            continue
        e = energy_of(a_s, out[1])
        if e <= energy_budget and dominates(out, best):
            best = (a_s, out)
    return best
```

### IP-124 PDC（Portability / Deployment-Gap Certificate）

```python
def portability_certificate(E_host, target, Phi, L, Theta_pdc):
    delta_q = quantization_error(target.q, Phi)
    delta_s = downsample_error(target.s, Phi)
    delta_j = target.v_max * target.jitter
    delta_emb = L * (delta_q + delta_s + delta_j) + target.sensor_bias
    if delta_emb > Theta_pdc:
        return ('reject', 'deployment_gap', delta_emb)
    return ('ok', PDC(L, target.q, target.s, target.j,
                      delta_emb, E_host))
```

### IP-125 CFR（Certificate Freshness & Renewal）

```python
def certificate_state(cert, p, sigma, now):
    if not frame_admissible(p, cert.D) or sigma not in cert.Sigma_op:
        return 'invalid'                      # 硬绊线，立即失效
    if now - cert.issued > cert.T_cert:
        return 'stale'
    if drift(p, sigma, cert.anchor) > cert.theta_drift:
        return 'stale'
    return 'fresh'

def renew_if_needed(cert, p, sigma, now, hysteresis=0.8):
    s = certificate_state(cert, p, sigma, now)
    if s == 'fresh':
        return cert
    if s == 'invalid':
        return None                            # 不可续，触发 DGL
    return recalibrate_local(cert, p, sigma, margin=hysteresis)
```

### IP-126 JEC（Joint Embedded Certificate）

```python
def joint_embedded_certificate(skill_seq, p, sigma, PDC, A_cert, I_safe):
    if (p, sigma) not in V_S:
        return ('reject', 'validity_domain')
    if PDC.delta_emb > Theta_pdc:
        return ('reject', 'deployment_gap')
    if not preserves(I_safe, skill_seq, p, sigma):
        return ('reject', 'safety_violation')
    rho = compose_rho_chain(skill_seq, p, sigma)
    if min(rho.values()) < rho_min:
        return ('reject', 'robustness_fail', rho)
    return ('ok', JEC(rho, V_S, A_cert, PDC, state='fresh', I_safe))
```

### IP-127 DGL（Degradation Ladder）

```python
def degradation_step(sigma, level, cert, levels, now):
    while level < len(levels) - 1 and not resource_ok(sigma, levels[level]):
        level += 1
    cand = levels[level]
    p_new, sigma_new = psi(cand.a_s)
    if not preserves(cand.I, cert.I_safe) or (p_new, sigma_new) not in V_S:
        return ('emergency_stop', None)
    if cert.state != 'fresh' and not resource_ok(sigma, level):
        return ('hold', level)                 # hysteresis，避免抖动
    return ('degrade', cand)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| LPP | O(N_s) | O(N_s) | 子采样无偏、包络保守 |
| REV | O(|\mathcal{S}ample(D×Σ)|·|𝔇_d|) | O(|V|) | 单调代理 sound、边界不低估 |
| SAP | O(K·|A_s|) | O(|A_s|) | 不动点收敛、下降步长安全 |
| PDC | O(|Φ|·|P_target|) | O(|Φ|) | L 上界成立、扰动项可测 |
| CFR | O(1) | O(1) | TTL/漂移阈值保守、绊线及时 |
| JEC | O(|S|·|𝔇_d|) | O(|S|·|𝔇_d|) | 四条件合取 sound |
| DGL | O(k·|A_s|) | O(k) | 不变量保序、切换不自毁证书 |

**正确性定理（Embedded-Deployment Soundness）**
承接第 54 轮 (A22)–(A28)，新增：
- **(A29)** 溯源估计误差 `||\hat p − p|| ≤ δ_p`，失效检测延迟 `≤ τ_p`；
- **(A30)** `ρ` 在 HIL 上校准误差 `≤ δ_ρ`，且对 `δ_geo` 与 `π(σ)` 单调；
- **(A31)** `Φ` 为 `L`-Lipschitz，且目标端扰动满足定义 125 的 `δ_emb` 上界；
- **(A32)** 新鲜度监控在 `τ_f` 内检出漂移，且 `T_cert` 小于热/电量漂移时间尺度。

则对任意部署序列，
```
P_success ≥ 1 − P((p,σ) ∉ V_S) − P(G_emb > 1) − P(drift undetected)
            − Σ_d (1 − ρ_min(d)) − P(I_safe violated) − β_E
```
其中每一项都是 **可在线检查或可标定** 的量，而不是离线签发的常量。这正是本轮相对第 54 轮的本质改进：把「相信证书」换成「持续验证证书的定义域」。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 物理溯源模型过拟合单一 LiDAR/场景 | 高 | 多型号 HIL 校准 + 在线残差 + 包络保守外扩 |
| 资源-鲁棒性曲面采样爆炸 | 中 | 主动实验设计 + 单调代理 + 增量更新 |
| 自指不动点振荡/不收敛 | 中 | 阻尼迭代 + 保守 `v_min` + 失败回滚 |
| 量化/调度导致静默语义漂移 | 高 | 特征层 Lipschitz 证书 + 影子模式 + 反例回灌 |
| 证书续证抖动（fresh/stale 抖动） | 中 | hysteresis + 分层 TTL + 锚点续证 |

```python
def lidar_provenance(frame, imu, clock, thermal, max_pts=2048):
    pts = frame.subsample(max_pts)                 # 限算力，O(N_s)
    dt = clock.offset(imu.t, frame.t)
    eps = deskew_residual(pts, imu, dt)            # v*dt + scan/2
    n_eff = effective_density(pts, frame.range_bins)
    r_ref = mean_reflectivity(pts)
    g_ghost = ghost_ratio(pts, reflectivity_model)
    return Provenance(dt, eps, n_eff, r_ref, g_ghost,
                      thermal.t_die, thermal.p_inst)

def frame_admissible(p, D):
    return all(D[i].lo <= p[i] <= D[i].hi for i in range(len(D)))
```

### IP-122 REV

```python
def build_validity_domain(skill, D, Sigma_op, dims, rho_min, sampler):
    V, surf = set(), {}
    for (p, sigma) in sampler.cover(D, Sigma_op):   # HIL 扫掠 + 主动设计
        rho = measure_rho_hil(skill, dims, p, sigma)
        surf[(p, sigma)] = rho
        if min(rho[d] for d in dims) >= rho_min:
            V.add((p, sigma))
    return ValidityDomain(V, fit_monotone_envelope(surf))

def in_domain(p, sigma, V, model, margin=0.05):
    if (p, sigma) in V:
        return True
    return model.predict(p, sigma) - margin >= min_rho
```

### IP-123 SAP

```python
def certified_operating_point(skill, a_s, v0, D, Sigma_op, V, K=8):
    v = v0
    for _ in range(K):
        p, sigma = psi((v, a_s))               # 动作诱导的测量与资源状态
        if frame_admissible(p, D) and sigma in Sigma_op and (p, sigma) in V:
            return ('ok', v, p, sigma)
        v = max(v_min, 0.9 * v)                # 降速削减运动畸变
    return ('reject', 'no_certified_point', None, None)

def plan_sensing(task, skills, D, Sigma_op, energy_budget):
    best = None
    for a_s in enumerate_sensing_actions(task):
        out = certified_operating_point(skills, a_s, task.v_max, D, Sigma_op, V)
        if out[0] != 'ok':
            continue
        e = energy_of(a_s, out[1])
        if e <= energy_budget and dominates(out, best):
            best = (a_s, out)
    return best
```

### IP-124 PDC

```python
def portability_certificate(E_host, target, Phi, L, Theta_pdc):
    delta_q = quantization_error(target.q, Phi)
    delta_s = downsample_error(target.s, Phi)
    delta_j = target.v_max * target.jitter
    delta_emb = L * (delta_q + delta_s + delta_j) + target.sensor_bias
    if delta_emb > Theta_pdc:
        return ('reject', 'deployment_gap', delta_emb)
    return ('ok', PDC(L, target.q, target.s, target.j,
                      delta_emb, E_host))
```

### IP-125 CFR

```python
def certificate_state(cert, p, sigma, now):
    if not frame_admissible(p, cert.D) or sigma not in cert.Sigma_op:
        return 'invalid'                       # 硬绊线，立即失效
    if now - cert.issued > cert.T_cert:
        return 'stale'
    if drift(p, sigma, cert.anchor) > cert.theta_drift:
        return 'stale'
    return 'fresh'

def renew_if_needed(cert, p, sigma, now, hysteresis=0.8):
    s = certificate_state(cert, p, sigma, now)
    if s == 'fresh':
        return cert
    if s == 'invalid':
        return None                             # 不可续，触发 DGL
    return recalibrate_local(cert, p, sigma, margin=hysteresis)
```

### IP-126 JEC

```python
def joint_embedded_certificate(skill_seq, p, sigma, PDC, A_cert, I_safe):
    if (p, sigma) not in V_S:
        return ('reject', 'validity_domain')
    if PDC.delta_emb > Theta_pdc:
        return ('reject', 'deployment_gap')
    if not preserves(I_safe, skill_seq, p, sigma):
        return ('reject', 'safety_violation')
    rho = compose_rho_chain(skill_seq, p, sigma)
    if min(rho.values()) < rho_min:
        return ('reject', 'robustness_fail', rho)
    return ('ok', JEC(rho, V_S, A_cert, PDC, state='fresh', I_safe))
```

### IP-127 DGL

```python
def degradation_step(sigma, level, cert, levels, now):
    while level < len(levels) - 1 and not resource_ok(sigma, levels[level]):
        level += 1
    cand = levels[level]
    p_new, sigma_new = psi(cand.a_s)
    if not preserves(cand.I, cert.I_safe) or (p_new, sigma_new) not in V_S:
        return ('emergency_stop', None)
    if cert.state != 'fresh' and not resource_ok(sigma, level):
        return ('hold', level)                  # hysteresis，避免抖动
    return ('degrade', cand)
```

| JEC | O(|S|·|𝔇_d|) | O(|S|·|𝔇_d|) | 四条件合取 sound |
| DGL | O(k·|A_s|) | O(k) | 不变量保序、切换不自毁证书 |

**正确性定理（Embedded-Deployment Soundness）**
承接第 54 轮 (A22)–(A28)，新增 (A29) 溯源误差 `≤δ_p` 且失效检测延迟 `≤τ_p`；(A30) `ρ` 的 HIL 校准误差 `≤δ_ρ` 且对 `δ_geo`、`π(σ)` 单调；(A31) `Φ` 为 `L`-Lipschitz 且 `δ_emb` 上界成立；(A32) 新鲜度监控在 `τ_f` 内检出漂移且 `T_cert` 小于漂移时间尺度。则：
```
P_success ≥ 1 − P((p,σ) ∉ V_S) − P(G_emb > 1) − P(drift undetected)
            − Σ_d (1 − ρ_min(d)) − P(I_safe violated) − β_E
```
关键：**证书的每个前提都成为在线可检查项**；未知 `(p,σ)` 一律拒绝。
