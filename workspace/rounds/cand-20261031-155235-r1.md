# 第 13 轮 · ARGUS：把「动态避障 / 多视角 / 双足」翻译成 VLA 之外的事件门控层

> 检索/复核日期：**2026-10-31（UTC）**。赛事身份确认：宇树 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1，32 项桌面任务，通才单模型赛道；宇树另有一个 World Physical AI Competition，不是本赛。本轮是状态文件第 13 轮、灵感循环第 1 轮，三个词是「动态避障」「多视角视觉」「双足机器人」。本轮不换基座、不训第二个模型、不推翻第 12 轮 CHUNK-SERVO；它补的是 CHUNK-SERVO 没回答的问题：**当世界在动、目标被挡住、人的手伸进来、移动目标需要提前量时，谁在 167ms 内做决定？**

## 0. 结论：29.7% 的共同瓶颈，是“静态世界假设”

截至 2026-10-31，官网榜单仍是 8 个模型：MolmoAct2 29.7%、WALL-OSS-0.5 28.5%、DreamZero 27.9%、Spirit-v1.5 25.9%、DM0 23.5%、π0.5/PI-0.5 22.8%、GigaBrain-0 22.6%、GR00T N1.5 20.5%。`leaderboard_data.json` 的 `Published Time` 仍是 **2026-10-08 15:35:03 GMT**，`generated_from=gen_leaderboard.py`；runs 页 256/256 条，per-task 成功率出现 26.2%、23.5%、42.0% 等非 10% 整数倍，详情视频仍是占位。**这不是可以直接当 SOTA 或难度表的真榜，但它足以说明：8 个公开方案共享同一个“静态世界假设”。**

这个假设有三层：

1. **输入静态**：WLA/大多数 VLA 用 3 路图（左头 + 双腕）；`cam_right_high` 这一路在公开方案里基本被浪费。没有双目深度、没有跨视角一致性、没有遮挡推理。
2. **执行开环**：官方 WLA 默认 30 步 @30Hz，chunk 内不看新观测；挑战赛的 `action_chunk_size` 又在握手时固定，evaluator 每 T 步才调一次 `get_action`。T=30 时盲区 1 秒；T=5 时盲区 167ms。**T 不是推理参数，是感知盲区。**
3. **身体静态**：动作里只有 `action.pivot` 能碰下身，且逐维语义未文档化；公开方案几乎不主动用腰腿换视角/可达。数据又证明 `waist`/`legs` 在任务中确实动——所以“双足”不是让你走路，而是让你把**准静态站姿**当成一个可审计的自由度。

所以本轮押注 **ARGUS**（All-view Risk-Gated Unified Supervisor）：

> 在 VLA 和 action chunk 之间加一个**无学习权重、事件门控、四目动态工作区监督器**：头双目做米制深度，双腕做近距 2D/遮挡，右头相机补第四视角；它平时不打扰 VLA，只在 `VIEW_LOSS / TARGET_SHIFT / INTRUSION / SELF_COLLISION / INTERCEPT / PLAN_STALE / STANCE_LIMIT` 事件触发时，接管 3–5 步的修正（重瞄准、让行、提前量拦截、换视角或请求重规划）。

一句话：**VLA 负责“做什么”，CHUNK-SERVO 负责“最后 3 厘米”，ARGUS 负责“世界变了怎么办”。**

## 1. 本轮核实（只列会改变方案的）

### 1.1 赛事/规则
- 32 项桌面任务；每任务 10 次；5 类泛化各 2 次（位置/干扰物/背景/未见物品/人为干扰）；单次 180s；排名先总平均成功率、再总平均步骤分、再更早提交；N 台机器人，从 8765 起暴露 N 个连续端口，`reset()` 隔离；另有不计分单任务测试通道。
- 结论：**人为干扰轴占 20% trials，是最大的单一边际；** 动态/遮挡不是“锦上添花”，是直接计分项。

### 1.2 API/协议
- 4 路 RGB 480×640；无 depth/camera_info/force/tactile；`control_space` 仅 `joint` 或 `ee` 互斥；`action_chunk_size` 握手时固定；`action.pivot` [7] 是唯一的共享下身动作，**没有 `action.lower_body`**。
- `get_action` 每个 chunk 调一次；chunk 内无新观测、无打断；`obs_delta_indices` 可声明历史帧，但最新帧仍是 chunk 边界。
- 结论：**要闭环看世界，T 必须小；T=5 是“167ms 盲区”的上限。** `pivot` 必须先审计，不能假设它能做完整站姿。

### 1.3 数据
- 32 个 HF 数据集合计 **33,276 episodes / 18,282,246 frames / 169.28 h / 30 fps**；单任务 969–1,533 eps。
- **纠正第 12 轮**：32/32 数据集的腕部相机都有内参；`wrist_left` color ≈ `fx=436.4058, fy=435.9215, cx=323.9217, cy=242.9332`。缺的是腕部到 EE 的**外参**，不是内参。头双目基线 **58.2526 mm**，`fx≈282.37`。
- 结论：头双目可做 0.3–0.8m 的米制深度（0.5m 处约 7.6mm 误差）；腕部可做 10–20cm 近距 2D/遮挡（10cm 处视场约 14.7×11.0cm）。**不需要重建整个场景，只需要工作区里的目标/手/障碍。**

### 1.4 动作/状态统计
- `action.base_command=[vx,vy,angle_z,height]`；`action.pivot` 7D 的名字是 `[vx,vy,angle_z,pivot_3,pivot_4,pivot_5,height]`，`pivot[4]` 常为 0.15。
- 稳健统计（q01–q99）：HangCup waist 范围约 [0.027,0.007,0.005] rad、leg 最大 0.012；ConveyorSorting waist [0.026,0.006,0.003]、leg 0.009；OrganizeTools waist [0.132,0.036,0.246]、leg 0.054；Unlock waist [0.035,0.004,0.004]、leg 0.010；PackBag waist [0.057,0.007,0.006]、leg 0.023；ZipUp waist [0.032,0.006,0.005]、leg 0.013。
- 结论：**大多数任务是准静态站立 + 小幅腰/腿姿态调整；OrganizeTools 的腰 yaw/pitch 是明显例外。** 这支持“小姿态换视角/可达”，不支持“走路”。

### 1.5 榜单
- 8 个模型、320 trials、平均时长 43.7–45.2s；模型间 per-task 成功率平均相关仅 **0.098**（最低 -0.21，最高 0.35）；step score 对 success 的线性回归 R²≈0.999999，斜率 1.31–1.37。
- 结论：**任务成功率几乎是步骤分的唯一驱动；不同模型的失败任务高度不相关。** 这意味着两件事：不要指望“换一个更强的基座”通吃；要做**按失败模式分诊**的增益层。合成榜的细节不可信，但“成功率主导、模型差异大”这个结构可信。

### 1.6 新文献
- **DynamicVLA**（arXiv 2601.22153v2）：0.4B、latency-aware、Latent-aware Action Streaming 丢弃过期动作前缀；说明“延迟感知 + 流式动作”是 2026 年的活跃方向。
- **VLPSA**（arXiv 2609.22462v1）：vision-language-Poisson-safe actions，CBF-QP 全身安全过滤；SafeLIBERO 碰撞避免 23.1%→91.2%，Franka FR3 部署。说明**安全过滤可以不改基座**。
- **D²-VLA**（arXiv 2609.34792）：双记忆、双频；**MVUCF**（arXiv 2608.01826）：RGB-only 多相机统一相机场；**AR-WAM**（arXiv 2609.09158）：视觉条件世界动作模型；**SocialVLA**（检索片段：G1 人机交互，检测 47.9ms/保持 336ms，待核）；**WholeBodyVLA**（ICLR 2026）；**ActiveVLA / TANGO / OpenHLM / HuMI** 也在检索结果中出现。
- 结论：**“多视角 + 动态 + 安全/延迟”已被验证有增益，但公开工作多是新模型/新训练；本赛的单模型规则反而给“确定性事件层”留了空位。**

## 2. 三个词的正确落点

| 灵感词 | 有用的翻译 | 证据 | 死路（本轮不做） |
|---|---|---|---|
| **动态避障** | 动态**事件层**：目标被移动/被遮挡、人的手/臂进入抓取通道、传送带目标需要提前量、双臂自碰撞 | 5 类泛化里 20% 是人为干扰；ConveyorSorting 是显式动态任务；bimanual 任务多 | 移动底盘避障/导航；全场景动态 SLAM；为“避障”训一个新策略 |
| **多视角视觉** | **四路分工**：头双目米制深度 + 双腕近距 2D/遮挡 + 右头第四视角；跨视角一致性 | 4 路 RGB 都在 API 里；WLA 只用 3 路；头双目有基线/内参/外参；腕部有内参、缺外参 | 训练大 3D 重建/NeRF；把 4 路图简单拼给 VLA；为多视角再训一个检测器 |
| **双足机器人** | **准静态站姿/腰腿姿态**作为可审计的感知/可达自由度；`pivot` 审计后小步使用 | 数据里 waist/legs 确实动；但 base 平移多数任务很小；动作里只有 pivot 能碰下身 | 走路/步态/上下桌；完整全身控制；把 pivot 当已知语义 |

**一句话：** 三个词都不是“更大的模型”，而是“VLA 之外的三类状态变化”：**目标变了、视角挡了、身体够不着。** ARGUS 只处理这三类。

## 3. ARGUS 设计

### 3.1 结构

```
4×RGB ──> 4V Tracker ──> Event Bus ──> Intervention Selector ──> Action Composer ──> chunk
              │               │                    │                     │
        head stereo      event scores        safety filter          stance audit
        wrist 2D         hysteresis          lead pursuit           pivot gating
```

- **4V Tracker**：头双目 SGBM/块匹配 + 稀疏光流；腕部 2D 检测/光流 + 夹爪几何；把所有目标/手/障碍投到 base 系，维护带协方差的 track。
- **Event Bus**：每个 track 计算 visibility、motion、TTC、distance-to-corridor、cross-view disagreement；用滞回阈值产生事件。
- **Intervention Selector**：事件→动作的有限状态机；优先级 `INTRUSION > SELF_COLLISION > INTERCEPT > TARGET_SHIFT > OCCLUSION > PLAN_STALE > STANCE_LIMIT`。
- **Action Composer**：把 VLA/CHUNK-SERVO 的 chunk 与干预动作合成；无事件时原样透传；有事件时替换 chunk 的前 k 步，其余步保持安全。
- **Safety Filter**：URDF 胶囊体 + 工作区障碍；只做运动学 CBF-QP，不做全身动力学。
- **Stance Audit**：先用单任务通道测 `pivot` 的 7 维效果；通过才启用小姿态库，否则只用零 pivot。

### 3.2 事件表

| 事件 | 触发 | 典型任务 | 干预 |
|---|---|---|---|
| `VIEW_LOSS` | 目标可见度 < τ_v 或跨视角重投影差 > τ_r | 遮挡/未见物品 | 换视角/用预测/请求重规划 |
| `TARGET_SHIFT` | 目标 3D 位移 > 1.5cm 或速度 > 2cm/s | 人为干扰/物体被移动 | 更新目标、重瞄准、重检索 |
| `INTRUSION` | 人手/障碍进入抓取走廊，TTC < 0.5s | 人为干扰 | 刹车/让行/后退，2s 上限 |
| `SELF_COLLISION` | 双臂胶囊距离 < 3cm | 双手任务 | 约束 QP/分开双臂 |
| `INTERCEPT` | 移动目标速度 > 2cm/s | ConveyorSorting | 提前量 + 闭合时机 |
| `PLAN_STALE` | 计划与当前观测偏差 > 阈值 | 所有动态 | 请求 VLA 重规划 |
| `STANCE_LIMIT` | 目标在可达/视野边缘 | OrganizeBookshelf/OrganizeTools | 小姿态（审计后） |

### 3.3 风险自适应（在固定 T 下）

协议上 T 固定，不能运行时改。所以 ARGUS 不声称“动态改 chunk size”，而是：

- **提交级**选 `T=5`（167ms 盲区）；如果 RTT/推理太慢，退 `T=6` 或 `T=8`。
- **chunk 内**：前 k 步执行 VLA/伺服；后 T−k 步用“保持/回撤/让行”填充；事件触发时 k 变小。
- **风险分数** `r = w1·TTC^{-1} + w2·occlusion + w3·cross_view + w4·target_speed`；`r` 高时 k=2–3，`r` 低时 k=5。
- **重规划**：`PLAN_STALE` 时异步请求 VLA；在等待期用 last-good plan + servo，不空等。

### 3.4 安全过滤

- 机器人几何：URDF 胶囊体（上臂/前臂/夹爪/抓取物）；障碍：动态 track、人手、非目标物。
- 约束：`h(x) ≥ 0`，`\dot h + α h ≥ 0`；用单积分运动学近似，解最小二乘 QP 修改 EE 速度；不可行则刹车。
- **保守门控**：只有 `TTC < 0.5s` 且障碍进入抓取走廊才启用；避免“处处减速”拖垮步骤分。
- **让行恢复**：人手离开后 0.5s 重新检测；目标位移则重定位；最多让行 2s，之后低速继续。

### 3.5 拦截

- 估计目标 `p(t)`、`v`；总延迟 `τ = τ_obs + τ_infer + τ_exec + τ_close`；目标点 `p_d = p(t) + v·τ`；夹爪速度前馈 `v`。
- 闭合条件：相对距离 < `r_grasp` 且相对速度 < `v_close`；先闭合再接触，避免“追着夹”。
- ConveyorSorting：用光流估计带速；若带速未知，用目标 track 的 `v` 代替；先慢后快，别过冲。

### 3.6 站姿审计

- **G0**：单任务通道，命令 `pivot` 的小偏移（height ±1cm、yaw ±0.05、pivot_3/4/5 ±0.02），观察 `state_torso`/`state_d435`/`lower_body` 的响应与平衡。
- 通过标准：可重复、无急停、无大幅振荡；否则**只用零 pivot**，放弃站姿。
- 通过后：7 个微姿态（neutral、lean L/R、forward、squat、rotate L/R），每个 ≤0.05 rad / 0.5s，每次切换后至少 3s 再切；液体任务（SyringeWaterTransfer）抓取后不换姿态。

## 4. 与 CHUNK-SERVO / GEO-RESIDUAL 的关系

- **CHUNK-SERVO**：解决最后 3cm 的闭环；输出 5 步执行块。ARGUS 直接接在它的输出后面，不重复造伺服。
- **GEO-RESIDUAL**：解决几何残差/标定；ARGUS 复用它的相机外参/深度尺度。
- **FACT-VLA**：解决事实/语义；ARGUS 不碰语义，只碰“世界变了”。
- 无事件时：ARGUS 是零开销透传；有事件时：ARGUS 只改 3–5 步。**它是“保险丝”，不是“第二个大脑”。**

## 5. 创新点清单（按 `q_t×Δ/cost` 排序）

| ID | 创新点 | 动机/差异 | 成本/风险 | 结论 |
|---|---|---|---|---|
| A1 | **4V-OCCLUSION TRACKER** | 用满 4 路；头双目米制 + 腕部近距；公开方案少用第 4 路 | 中；腕部外参/遮挡 | **主押注** |
| A2 | **EVENT-GATE** | 事件触发而非持续接管；保护 VLA 意图和步骤分 | 低；阈值调参 | **主押注** |
| A3 | **DYN-YIELD** | 人为干扰轴的让行/恢复；TTC+走廊门控 | 中；误停/安全 | **主押注** |
| A4 | **CONVEYOR-INTERCEPT** | ConveyorSorting 单任务高 ROI；延迟补偿 + 提前量 | 低；带速/遮挡 | **保留** |
| A5 | **ARM-ARM CLEARANCE** | 双手任务自碰撞；URDF 胶囊距离 | 低；过保守 | **保留** |
| A6 | **MV-AGREEMENT** | 跨视角一致性触发重规划；未见物品/遮挡 | 低；误报 | **保留** |
| A7 | **LATENCY-STREAM** | 丢弃过期前缀；与 5 步块结合 | 低；边界抖动 | **保留** |
| A8 | **PIVOT AUDIT + STANCE** | 腰腿小姿态换视野/可达；先审计再启用 | 中；语义未知/平衡 | **观察** |
| A9 | **4V-DROPOUT FINE-TUNE** | 给 WLA 加第 4 路 + 随机遮挡；同一模型内 | 高；架构/算力 | **观察** |
| A10 | **DYNAMIC AUG** | 合成人手/遮挡/位移，补数据缺口 | 低；sim gap | **保留** |

**剪枝：**
- 走路/步态/全身控制：数据不支持、动作接口只有 pivot、风险高。
- 全 3D 重建/NeRF/SLAM：算力/延迟不划算，工作区很小。
- 学习型分割/检测器：可能违反单模型；用经典几何/光流/VLA 特征。
- 完整动力学 CBF：没有动力学参数；运动学 CBF 足够做“保险丝”。
- 为每个任务训策略：明确违反通才单模型。

## 6. 竞赛策略与预期

### 6.1 先做失败分诊（F0）
在 5 个代表任务（ConveyorSorting、PackBag/ZipUp、OrganizeTools、PackDoll）上各收 10 次失败，分 6 类：没到位/抓空/接触失败/目标移动/遮挡/超时。**如果“动态+遮挡” < 20% 的失败，ARGUS 降级为 A4/A5 两个小模块；如果 > 30%，全力做 A1–A3。**

### 6.2 任务组合
- 动态：ConveyorSorting。
- 遮挡/双手：PackBag、ZipUp、StorePaddle、StoreEarphones、PackPhone、OrganizePencilCase、ToolboxStorage、PackDoll。
- 可达/视野：OrganizeBookshelf、OrganizeTools、ArrangePlates。
- 人为干扰：全部 32 任务的第 4 类泛化（20% trials）。
- 注：官网任务编号与数据集顺序未在公开手册中稳定映射；本文用任务名，避免把 T 编号写错。

### 6.3 预期增益（粗算）
| 轴 | trials | 假设提升 | 全局 |
|---|---:|---:|---:|
| 人为干扰 | 64 | +10~20pp | +2.0~4.0pp |
| ConveyorSorting | 10 | +20pp | +0.6pp |
| 8 个遮挡/双手 | 80 | +5pp | +1.25pp |
| 4 个可达 | 40 | +5pp | +0.6pp |
| **合计** | 194 | — | **+2.5~6.5pp** |

保守取 **+2~4pp**；注意 320 trials 的未配对 SE 约 **2.8pp**，所以必须做配对 A/B（同一任务、同一天、交替跑）并重复，不能拿一次涨点当结论。

### 6.4 提交策略
- 先交安全基线（CHUNK-SERVO）锁“更早提交”的 tie-break；再逐步加 A4/A5/A1/A2/A3。
- N 端口按官方建议：N 小就一进程一端口；N 大就共享推理后端，但每端口状态隔离。
- 监控：每次提交记录 RTT、chunk 执行时间、事件触发率、误停率；事件触发率 > 30% 说明阈值太松。

## 7. 风险与合规

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|

## 2. 问题形式化

### 2.1 事件驱动的部分可观测控制

- 观测：`o_t = (I_t^1..4, q_t, u_t, l)`，其中 `q_t` 是关节/EE/夹爪，`u_t` 是 `lower_body`/`state_d435`，`l` 是语言。
- 动作：chunk `a_{t:t+T-1}`，`T=5`。
- 隐藏事件：`e_t ∈ {none, occlusion, shift, intrusion, self_collision, intercept, stale, stance}`。
- 监督器：`a' = G(a, o_t, ê_t)`，`ê_t = E(o_t)`。
- 目标：`max E[success] - λ E[intervention]`，约束安全、180s、步骤分。
- 因为 evaluator 只在 chunk 边界给新观测，`ê_t` 是分段常数；**事件延迟 = 检测延迟 + T/f_c + 推理延迟**。

### 2.2 多视角观测模型

- 针孔投影：`u = π(K T_{cam←base} X)`。
- 头双目：`Z = f b / d`；`f≈282.37 px`，`b=0.0582526 m`。
- 腕部：单目；已知 `K`，未知 `T_{cam←ee}`；先用 2D，手眼标定后用 3D。
- 跨视角：把 3D 假设投到每个视角，得可见度 `v_j` 和重投影误差 `r_j`；融合权重 `w_j ∝ exp(-r_j^2/σ^2)·v_j`。
- Track：`x=[p,v]`，常速度 Kalman；`Σ` 协方差；遮挡时只预测，不更新；重识别用 HSV 直方图 + 3D 位置。

### 2.3 动态风险与 chunk

- 盲区：`Δ_b = T/f_c`；T=5、30Hz → 167ms。
- 人手最坏位移：`d_h = v_h(Δ_b + τ_i)`；`v_h=1m/s`、`τ_i=100ms` → 26.7cm。
- TTC：`τ = d/\dot d`；触发 `τ<0.5s`。
- 风险：`r = w1·exp(-τ/0.3) + w2·o + w3·δ + w4·min(||v||/0.2,1)`，`Σw=1`。
- chunk 内容：`k = clip(round(5(1-r)), 2, 5)`；前 k 步执行，后 `5-k` 步保持/回撤。**T 不变，变的是内容。**

### 2.4 安全包络

- 机器人胶囊 `C_i`（上臂/前臂/夹爪/抓取物）；障碍点 `O_j`。
- 安全函数：`h = min_{i,j} dist(C_i,O_j) - r_safe`。
- 运动学 CBF：`\dot h + α h ≥ 0`；单积分 `\dot p = u`。
- QP：`min ||u-u_des||^2` s.t. `∇h^T u + α h ≥ 0`，`||u||≤u_max`。
- 不可行 → `u=0`/后退；**这是“保险丝”，不是严格安全保证。**

### 2.5 拦截

- 目标 `p(t)`、`v`；总延迟 `τ=τ_obs+τ_infer+τ_exec+τ_close`。
- 瞄准点：`p_d = p + vτ`；前馈 `v`；反馈 `K(p_d-p_g)`。
- 闭合：`||p_g-p||<r_g` 且 `||v_g-v||<v_close`；先闭合再接触。
- ConveyorSorting：光流估带速；未知时用 track `v`；限制加速度，避免过冲。

### 2.6 站姿

- `pivot` 7D；审计映射 `f: pivot → (state_torso, state_d435, lower_body)`。
- 姿态库 `S`；评分 `J(s)=0.4·vis+0.3·reach+0.2·balance-0.1·transition`。
- 只在阶段边界切换；`balance>0.6`；每次 ≤0.05 rad/0.5s；切换间隔 ≥3s。
- 审计失败 → `S={neutral}`，零 pivot。

## 3. 系统设计

### 3.1 拓扑

```
                    ┌──────────────── VLA / CHUNK-SERVO ────────────────┐
4×RGB ──> 4V Tracker ──> Event Bus ──> Intervention Selector ──> Composer ──> chunk
   │            │              │                  │                  │
   │      head stereo     event scores       safety QP          stance audit
   │      wrist 2D        hysteresis         lead pursuit       pivot gating
   └────> state/URDF ─────> self-collision ──> geometry ────────> base frame
```

- 线程：感知 30Hz；事件 30Hz；VLA 异步（100–300ms）；composer 30Hz。
- 状态：每 episode `reset()` 清 track/event/stance/replan 缓存。
- 输出：严格符合 action spec 的 `(T, dim)` float32。

### 3.2 4V Tracker

**头双目：**
1. 取 `cam_left_high`/`cam_right_high`；若未校正，用 `camera_params.head` 校正。
2. 缩到 240×320，ROI 取工作区（目标/手/障碍），SGBM 半全局匹配。
3. 左右一致性检查；中值滤波；无效深度置 NaN。
4. 用 `state_d435` + 头外参把点投到 base 系。
5. 目标/手用颜色+光流+深度聚类；不做学习检测器。

注意：若左右头不是硬件同步，动态场景不要硬做 SGBM；用左头 + 稀疏光流估计运动，右头只做静态一致性/遮挡验证。同步性用 G1 的标定实验确认。

**腕部：**
1. 取 `cam_left_wrist`/`cam_right_wrist`；用已知 `K` 做 2D。
2. 近距目标用颜色/光流；夹爪开合度给尺度先验。
3. 手眼标定通过后，把 2D+深度投到 EE 系，再投 base。
4. 未标定 → 只输出 2D 框、遮挡分数、相对夹爪方位。

**融合：**
- 每个 3D 假设投到 4 个视角，得 `v_j`、`r_j`。
- 融合权重 `w_j`；协方差交集（CI）避免重复计数。
- 目标 track：Kalman；遮挡计数；丢失 >0.5s 转 `VIEW_LOSS`；丢失 >2s 请求重规划。

### 3.3 Event Bus

| 分数 | 定义 | 初始阈值 | 滞回/去抖 |
|---|---|---|---|
| `visibility` | 有效深度/2D 框在 4 视角的加权可见度 | <0.35 | 0.45 恢复；3 帧 |
| `shift` | 目标 3D 位移/速度 | >1.5cm 或 >2cm/s | 0.5cm 恢复；3 帧 |
| `ttc` | 人手/障碍到抓取走廊的 TTC | <0.5s | 0.7s 解除；2 帧 |
| `corridor` | 障碍到 EE-目标线段的距离 | <8cm | 12cm 解除 |
| `self_dist` | 双臂胶囊最小距离 | <3cm | 5cm 解除 |
| `cross_view` | 跨视角重投影误差 | >8px | 5px 解除 |
| `plan_error` | 计划 EE 与观测 EE 偏差 | >3cm/10° | 2cm/6° 解除 |

事件优先级：`INTRUSION > SELF_COLLISION > INTERCEPT > TARGET_SHIFT > VIEW_LOSS > PLAN_STALE > STANCE_LIMIT`。每个事件有最大持续时间；超时强制退出，避免卡死。

### 3.4 Intervention Selector

| 事件 | 动作 | 时长 | 退出 |
|---|---|---|---|
| `VIEW_LOSS` | 换视角/小姿态/用预测；请求重规划 | 0.5s | 可见度>0.45 |
| `TARGET_SHIFT` | 更新目标；重瞄准；重检索 | 0.3s | 误差<1cm |
| `INTRUSION` | 刹车/让行/后退；保持夹爪 | ≤2s | TTC>0.7s 且走廊清空 |
| `SELF_COLLISION` | QP 分开双臂；降速 | 0.3s | 距离>5cm |
| `INTERCEPT` | 提前量 + 前馈；闭合夹爪 | 到抓取 | 抓住/超时 |
| `PLAN_STALE` | 异步重规划；last-good plan + servo | 0.5s | 新计划到达 |
| `STANCE_LIMIT` | 小姿态（审计后） | 1s | 目标进入可达 |

### 3.5 Safety Filter

- 几何：URDF 胶囊 + 抓取物包围球；障碍 track 点云/包围盒。
- 只在 `TTC<0.5s` 且 `corridor<8cm` 时启用；否则旁路。
- QP 变量：EE 速度修正 `Δu`；目标函数 `||Δu||^2 + λ||Δu-Δu_prev||^2`。
- 约束：CBF + 速度/加速度限幅；不可行 → 刹车/后退。
- 频率：30Hz；求解 <2ms；用 OSQP/小规模有效集。

### 3.6 Interception

- 输入：目标 track `p,v,Σ`；延迟 `τ`；夹爪 `p_g`。
- 瞄准：`p_d=p+vτ`；期望速度 `v_d=v+K(p_d-p_g)`。
- 闭合：`||p_g-p||<r_g` 且 `||v_g-v||<v_close`；`r_g` 按物体尺寸；`v_close` 取 5cm/s。
- 传送带：`v` 由 track 估计；若目标被遮挡，用带速光流；限制 `a_max` 防过冲。
- 失败：错过 → 不追出工作区；回到 `TARGET_SHIFT` 重定位。

### 3.7 Stance Audit（G0）

**命令（单任务通道，每次只改一个维度）：**
- `pivot[6]` height：±0.5cm、±1cm。
- `pivot[2]` yaw：±0.02、±0.05 rad。
- `pivot[3:6]`：各 ±0.02 rad。
- 每段保持 1s，回 neutral 1s；重复 3 次。

**观测：** `state_torso`、`state_d435`、`lower_body`、是否急停、是否振荡。

**通过：** 响应单调/可重复；无急停；`lower_body` 变化 <0.1 rad；`state_d435` 平移 <3cm；重复误差 <20%。

**失败：** 只用零 pivot；把 A8 降级为“只用现有姿态做上下文”，不主动切换。

**通过后：** 7 个微姿态；每个 ≤0.05 rad/0.5s；切换间隔 ≥3s；`balance` 低于阈值立即回 neutral；SyringeWaterTransfer 抓取后不换姿态。

### 3.8 与 CHUNK-SERVO 的集成

```
obs ──> 4V Tracker ──> Event Bus ──> events
                                      │
obs ──> VLA 30-step plan ──> CHUNK-SERVO 5-step chunk ──> Composer ──> action
                                      │                    │
                                      └── last-good plan ───┘
```

- 无事件：composer 原样返回 CHUNK-SERVO 的 5 步。
- 有事件：composer 用干预动作替换前 k 步；后 `5-k` 步保持/回撤。
- `PLAN_STALE`：异步请求 VLA；等待期用 last-good plan + servo。
- `reset()`：清 track/event/stance/plan 缓存。

### 3.9 伪代码

```python
def reset(self):
    self.tracks = TrackManager()
    self.events = EventBus()
    self.plan = None
    self.stance = "neutral"

def get_action(self, obs):
    tracks = self.tracks.update(obs)
    events = self.events.classify(tracks, obs)
    base = self.chunk_servo.plan(obs, self.plan)
    if events:
        base = self.intervene(base, events, tracks)
    base = self.safety_filter(base, tracks)
    return self.compose(base, events, T=5)
```

```python
def intervene(base, events, tracks):
    if "INTRUSION" in events:
        return yield_or_retreat(base, tracks, max_time=2.0)
    if "SELF_COLLISION" in events:
        return separate_arms(base, tracks)
    if "INTERCEPT" in events:
        return lead_pursuit(base, tracks)
    if "TARGET_SHIFT" in events:
        return reaim(base, tracks)
    if "VIEW_LOSS" in events:
        return view_recovery(base, tracks)
    if "PLAN_STALE" in events:
        return hold_and_replan(base)
    if "STANCE_LIMIT" in events:
        return micro_stance(base, tracks)
    return base
```

## 4. 推导

### 4.1 双目深度误差

`σ_Z = Z^2 σ_d / (f b)`，`f=282.37 px`，`b=0.0582526 m`，`σ_d=0.5 px`：

| Z | σ_Z |
|---:|---:|
| 0.3m | 2.7mm |
| 0.5m | 7.6mm |
| 0.8m | 19.5mm |
| 1.0m | 30.4mm |

**用法：** 0.3–0.8m 工作区，7.6–19.5mm 精度；足够判断 1.5cm 目标位移。`σ_d=1px` 时误差翻倍，仍可用。

### 4.2 腕部视场

`W=Z·640/fx`，`H=Z·480/fy`，`fx=436.4058`，`fy=435.9215`：

| Z | 视场 W×H |
|---:|---:|
| 0.10m | 14.7×11.0cm |
| 0.15m | 22.0×16.5cm |
| 0.20m | 29.3×22.0cm |
| 0.30m | 44.0×33.0cm |

**用法：** 腕部在 10–20cm 覆盖夹爪附近；抓取时目标/手通常在视场内；适合遮挡判断和闭合时机。

### 4.3 三角化/协方差

- 线性化：`δX = (J^T Σ_d^{-1} J)^{-1} J^T Σ_d^{-1} δd`；`J` 是投影对 3D 的雅可比。
- 两视角融合：`Σ = (Σ_1^{-1}+Σ_2^{-1})^{-1}`；相关时用 CI：`Σ_c = (ωΣ_1^{-1}+(1-ω)Σ_2^{-1})^{-1}`。
- 工程简化：头双目给 `Σ_head`；腕部 2D 给方位约束，不给完整 3D；用 CI 融合，避免过自信。

### 4.4 TTC/CBF

- `τ = d/\dot d`；人手 1m/s：

| 距离 | TTC |
|---:|---:|
| 0.3m | 0.30s |
| 0.5m | 0.50s |
| 0.8m | 0.80s |

- 触发 0.5s；T=5 盲区 167ms；加 100ms 推理，1m/s 人手走 26.7cm。
- CBF：`h(x)≥0`，`\dot h+αh≥0`；`α=2.0`；只对抓取走廊内的障碍启用。

### 4.5 提前量

`p_d=p+vτ`；τ=0.2/0.3/0.5s：

| v | τ=0.2s | τ=0.3s | τ=0.5s |
|---:|---:|---:|---:|
| 0.05m/s | 1.0cm | 1.5cm | 2.5cm |
| 0.10m/s | 2.0cm | 3.0cm | 5.0cm |
| 0.20m/s | 4.0cm | 6.0cm | 10.0cm |

**用法：** 传送带 0.1–0.2m/s 时，提前量 2–6cm；对手指级抓取，这是成功/失败的分界。

### 4.6 风险/chunk

`r = w1·exp(-τ/0.3)+w2·o+w3·δ+w4·min(||v||/0.2,1)`；`w=[0.4,0.2,0.2,0.2]`。

- `r=0.2` → `k=4`；`r=0.4` → `k=3`；`r=0.6` → `k=2`。
- `T=5` 不变；后 `5-k` 步用 hold/retreat；事件解除后恢复 `k=5`。
- 这是“内容自适应”，不是“协议自适应”；避免违反固定 chunk。

### 4.7 站姿评分

`J(s)=0.4·vis+0.3·reach+0.2·balance-0.1·transition`。

- `vis`：目标在 4 视角的可见度；`reach`：目标到肩-臂可达球的距离；`balance`：支撑多边形/CoM 余量；`transition`：从当前姿态的关节距离。
- 只有 `J(s)-J(neutral)>0.1` 且 `balance>0.6` 才切换；否则保持 neutral。
- 液体任务：`SyringeWaterTransfer` 抓取后 `transition=∞`，禁止切换。
