# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因」IP-214~223；灵感循环第 2 轮；本轮灵感：「推理延迟」×「成功率」）

> 第 65 轮把「不可辨识」升级为「可归因」，但其论证里藏着一个被当作基础设施常数的量：**推理是"瞬时"的**。VISTA 把世界模型、FIR、AFA、CSP-V 全放进语义流，并宣称实时流 ≤2.5ms；可一旦策略/世界模型换成 VLA 或扩散策略，端到端推理延迟 L 是**几十到几百毫秒、重尾、且与场景难度正相关**的随机变量。更关键的是，第 65 轮的「长预测、短执行」暗中要求 **k·dt ≥ L** 才能藏住延迟，而安全又要求 **k ≤ m**（不可逆视界）；这两个不等式第一次把「推理延迟」与「成功率」放进同一个约束系统。本轮核心命题是：
>
> **把推理延迟从"被隐藏的常数成本"升级为与任务难度耦合、可观测、可调节、可归因的状态变量；把优化目标从"动作/预测精度"换成"截止期条件下的成功率"；把时间（执行速度）提升为与几何、力并列的第三类安全执行器。**

## 0. 直觉与动机

**灵感 1（推理延迟 → 延迟不是成本，而是与难度共变的状态）**
直觉：多数具身系统把延迟当作"跑一次模型要花的时间"，于是只报平均毫秒数。但真实延迟有三件事被平均值掩盖：(i) **重尾**——GPU 争用、批处理排队、调度抖动、通信重传会让 P99 比均值大一个数量级；(ii) **内生性**——场景越乱、物体越多、动态越强，模型往往要处理更多 token/候选，于是**难场景既让观测更易过期，又让推理更慢**，误差与延迟同向放大；(iii) **可观测**——与几何/力故障不同，延迟有硬件时间戳作"半个真值"，可以测量、预测、并主动调节。结论：延迟不是被动成本，而是一个**条件分布 + 可测状态**，必须进入控制状态。

**灵感 2（成功率 → 目标应是截止期条件成功率，而不是无时限成功率）**
直觉：论文里的 success rate 常在"推理随便跑多久"的前提下测；部署里任务有硬截止期（比赛计时、产线节拍、人类等待、电池窗口）。一个更准但更慢的策略，可能在截止期前完成不了，于是**精度更高、成功率反而更低**。因此需要把成功率定义成截止期的函数 DCSR(D)=P(成功 ∧ 完成时间≤D)，并比较**延迟-成功率 Pareto 前沿**，而不是一个孤立点。延迟不是分母上的小惩罚，它直接改变可行策略集合。

**灵感 3（动作分块 → 延迟缓冲与安全约束的正面冲突）**
直觉：动作分块天然是延迟缓冲：执行当前块的同时异步算下一块，把推理藏进执行时间。但缓冲要成立，必须 **k·dt ≥ L+δ**（块执行时间不短于下一次推理加重规划余量）。而第 65 轮的安全约束是 **k ≤ m(v)**（执行前缀不能越过不可逆视界）。两式联立给出本轮最重要的"硬墙"：
**L+δ ≤ m(v)·dt = τ_irr(v)**。
若延迟超过不可逆时间，**没有任何 k 能同时藏住延迟并保证安全**；此时唯一出路是降低执行速度 v（时间膨胀），或改变任务以把不可逆点推远。动作分块由此从"提速技巧"变成"实时可行性问题"。

**灵感 4（推理延迟 → anytime 推理 + 推测执行 + 计算的边际价值）**
直觉：既然不能总等完整推理，就让模型"随时可停"：先给粗动作，再逐步精化。但**早停的动作可能危险**，所以不能以置信度作停止准则，必须以"安全验收"作准则——只有当剩余时间内仍能刹车/柔顺退避时，才允许执行草稿。更激进的是**推测执行**：快策略先出草稿并立即执行，慢策略在后台验证；若验证在不可逆点之前完成且否决草稿，则中止并恢复。这把 CPU 的 speculative execution 搬到物理世界，但验收条件从"分支预测正确"换成"**可恢复性**"。同时，继续计算只在"预期成功增益 / 延迟代价"超过阈值时才值得——这是计算的价值（VOC）与最优停止问题。

**灵感 5（三灵感合流 → PACE：Pacing-Aware Certified Execution，节拍感知的认证执行闭环）**
闭环：延迟状态建模（LSM）→ 时序故障隔离（TFI，新增 H_lat）→ 认证截止期分块（CDC，联合选 H/k/v/计算预算）→ 推测动作执行（SAX）与随时推理（VOC-AI）→ 成功率下界证书（SRL）→ 时间膨胀/速度调节 → 再归因。对第 65 轮组件的原位升级：
- **FIR → TFI**：ℋ 增 H_lat；用"时间戳 + 过期观测回放残差"把 H_lat 与 H_policy/H_vis 分开。
- **CSC → CDC**：从"给定块选 k"升级为"联合选 H、k、速度 v、计算预算 b"，把延迟分布与截止期纳入。
- **RSC-V → RSC-T**：增 r_lat，只在 H_lat 时膨胀，并用**调速**而非**膨胀几何**来处置。
- **WCV-V → WCV-T**：搜索域增时间/速度维度与截止期约束。
- **CSP-V → CSP-T**：块边带截止期标签，规划目标从"安全"扩到"截止期内成功"。
- **J_vista → J_pace**：证书增 latency_quantile、deadline_slack、k*、v*、DCSR_lcb、speculation_accept、latency_state_hash。
- **AIC-V → AIC-T**：干扰集增注入延迟、straggler、优先级反转、时钟偏斜、抖动，以及"在不可逆点前故意拖慢"的截止期攻击。

## 1. 形式化定义（增量：定义 233–245）

- **定义 233（PACE 闭环）**：PACE = (VISTA, LSM, DCSR, CSQ, TST, TFI, SAX, VOC-AI, CDC, SRL, RSC-T/WCV-T/CSP-T, AIC-T, J_pace)。定位：VISTA 的"时敏 + 成功率"升级。不变式：**没有动作结果可以在其观测年龄未被认证、且其截止期不可行时被执行；没有执行前缀可以在所选速度下失去不可逆点之前的可恢复性。**
- **定义 234（延迟状态与 LSM）**：端到端延迟 L_t=t_ready−t_capture，分解为感知/通信/推理/调度四项。给定场景难度 c_t、计算预算 b_t、硬件 h，L_t∼F_L(·|c,b,h)。LSM 维护工作点估计与条件分位数 q_L(α|c,b)，尾部用极值理论（GPD）拟合、分位用 split-conformal 校准；漂移检测触发在线重标定。**延迟是状态，不是常数。**
- **定义 235（截止期条件成功率 DCSR 与延迟-成功率前沿）**：DCSR_π(D)=P_π(S ∧ T_complete≤D)，其中 S 含任务正确且无安全违规。π₁ 支配 π₂ 当且仅当 ∀D，DCSR₁(D)≥DCSR₂(D) 且某处严格。标准 success rate 是 D→∞ 的极限。比较策略用前沿，不用单点。
- **定义 236（块饥饿队列 CSQ）**：执行一个 k 步块耗时 T_k=k·dt；预取下一块从块首开始，需 L_next+δ 可用。单块缓冲的**饥饿事件**为 L_next>T_k−δ；B 块缓冲为 L_next>B·T_k−δ。利用率 ρ=E[L]/(B·T_k)，稳定需 ρ<1。以 q_L(α_lat)≤B·k·dt−δ 选择 k 或 B，使饥饿概率 ≤α_lat。
- **定义 237（时间可行性、不可逆视界与速度包络 TST）**：τ_irr(v,φ) 为在当前计划下仍可在最坏扰动中刹车/柔顺退避到非不可逆状态的最长时间；m(v)=⌊τ_irr(v)/dt⌋，且 τ_irr 关于速度 v 单调不增。安全要求 k≤m(v)，藏延迟要求 k≥(q_L(α_lat)+δ)/dt。存在整数 k 当且仅当
  **ceil((q_L(α_lat)+δ)/dt) ≤ ⌊τ_irr(v)/dt⌋**；
  连续化（忽略一步整数舍入）即 q_L(α_lat)+δ≤τ_irr(v)。
  定义**延迟墙** Λ(φ)=τ_irr(v_min)。若在最小可行速度下整数条件仍不成立，则当前任务在当前可逆性结构下**不可能**既藏延迟又安全，必须改变任务（推远不可逆点/改抓取方式/允许柔顺接触）或停机。可行时，v_max=max{v:ceil((q_L+δ)/dt)≤⌊τ_irr(v)/dt⌋}，最小减速因子 s*=v_nom/v_max。
- **定义 238（时序故障假设 H_lat 与 TFI）**：ℋ 增 H_lat（延迟/抖动/饥饿导致的过期动作）。时序证据 τ=[Δ_ts, r_replay, 1_starvation, verifier_lag, q_L_ratio]，其中 Δ_ts 为实测端到端延迟相对标称的偏移，**回放残差** r_replay=‖a_t−π_θ(y_{t−L})‖ 表示"把策略重新喂给过期观测是否仍产生同一动作"。若 Δ_ts 大而 r_replay 小，则延迟足以解释异常→H_lat；若 r_replay 大而时间戳正常→H_policy；若 e_vis 大而时间戳正常→H_vis。**时间戳让 H_lat 成为可辨识的"半个真值"故障。**
- **定义 239（推测动作执行与安全验收 SAX）**：快策略在 L_d 内给出草稿 A^d，慢策略在 L_v 内给出 A^v。执行草稿前 j 步，验收条件为：∀s≤j，草稿动作的安全裕度 ρ_rec(a_s^d;v)≥0，且
  **L_v+δ_abort ≤ τ_irr(v)−s·dt**（验证与恢复必须在不可逆点之前完成）。由此得推测视界 j_spec=⌊(τ_irr(v)−L_v−δ_abort)/dt⌋。若 j_spec≤0，禁止推测，退化为"先验证后执行"。
- **定义 240（计算价值与 anytime 推理 VOC-AI）**：设计算预算 b 下预期成功概率 p(b) 单调不减，延迟的影子价格为 λ(t)（越接近截止期越大）。继续计算当且仅当
  **(p(b+Δb)−p(b))/Δb ≥ λ(t)**。
  在有限视界 MDP 下，最优停止策略是"后验成功概率增益阈值"策略；多细化臂时可用 Gittins 型索引作调度启发式。
- **定义 241（认证截止期分块 CDC）**：联合选择 (H,b,k,v)，最大化 P_success，约束为 k≤m(v)、q_L(α_lat|b)+δ≤k·dt、b≤B_remaining(D)、以及 VISTA 的几何/力/归因安全约束。输出 (H*,b*,k*,v*)；执行 k* 步后强制重规划与再归因。H 只影响前瞻/一致性，k 与 v 才承担安全承诺。
- **定义 242（成功率下界证书 SRL）**：把失败事件分解为安全、延迟/饥饿、截止期、任务、视觉五类；若 P(F_i)≤α_i，则
  **DCSR(D) ≥ 1−Σ_i α_i**。
  另以 n 个标定回合的经验成功率给高概率下界 DCSR_LCB；最终证书取两个有效下界中较保守者，并记录其置信度与假设。
- **定义 243（RSC-T / WCV-T / CSP-T）**：在 VISTA 的 r_geo/r_force/r_model 外增 r_lat；H_lat 时只膨胀 r_lat 并降速/加缓冲，不动几何与力标定。WCV-T 的搜索域增时间维度与截止期约束；CSP-T 的块边带 deadline 标签与最低 k* 要求。
- **定义 244（AIC-T 对抗延迟认证）**：ℰ_T=ℰ_V×ℰ_time，ℰ_time 含注入延迟、straggler、优先级反转、时钟偏斜、抖动、以及"临近不可逆点故意拖慢"的截止期攻击；在 ℰ_time 上取最坏 q_L 重算 ρ_dir，J_dir 增 latency_calib_ver、sched_ver。
- **定义 245（PACE 算子与 J_pace）**：语义流 [VISTA 语义流→LSM→TFI→VOC-AI→CDC→SRL]；实时流 [时间戳采集→延迟/饥饿监测→SAX 验收→保护前缀派发→调速执行]。J_pace=(J_vista,latency_quantile,deadline_slack,k*,v*,DCSR_lcb,speculation_accept,latency_state_hash,sched_ver)。Valid ⇔ Valid(J_vista) ∧ 延迟分位已标定 ∧ 时间可行 ∧ J_pace 各版本一致。

## 2. 关键算法骨架

# LSM：条件延迟分位 + 漂移检测（语义流）
q_lat = lsm.quantile(context=c, budget=b, alpha=alpha_lat)   # conformal + EVT 尾部
if lsm.drift_detected(recent_L, q_lat):
    lsm.recalibrate(); J_pace.latency_calib_ver += 1

# TFI：把"过期动作"从"策略 OOD"里分出来（语义流）
tau = [delta_ts, replay_residual(a_t, y_t_minus_L, policy),
       starvation_flag, verifier_lag, q_lat_ratio]
post = tfi.attribute(phases, tau)          # 在 VISTA 的 6 假设上加 H_lat
if post['H_lat'] >= 1 - delta_fi:
    r_lat *= kappa_infl; v = speed_envelope(q_lat, phi_hat)   # 调速而非膨胀几何

# CDC：时间可行的认证前缀（语义流）
k_min = ceil((q_lat + delta) / dt)
k_max = floor(tau_irr(v, phi_hat) / dt)
if k_min > k_max:
    action = 'slow_down_or_change_task'     # 延迟墙：当前任务不可行
else:
    k_star = cdc.certified_prefix(A, post, k_min, k_max, D_remaining)
    H_star, b_star, v_star = cdc.choose_compute_and_speed(A, k_star, D_remaining)

# SAX：草稿先执行、验证可否决（实时流）
j_spec = floor((tau_irr(v) - L_verify - delta_abort) / dt)
if j_spec > 0 and recoverable(A_draft[:j_spec], v):
    execute_speculative(A_draft[:j_spec])
    if verifier_rejects(A_verify) and time_left_before_irreversible():
        abort_to_compliant_hold()

# VOC-AI：只在计算值得时继续（语义流）
while remaining_budget > 0:
    gain = success_gain_per_second(b, b + db, post)
    if gain < lambda_t(D_remaining):
        break
    b += db; refine_action_or_world_model()
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（块饥饿）**：单块预取下，块内无饥饿当且仅当 L_next≤k·dt−δ；B 块缓冲时为 L_next≤B·k·dt−δ。故给定 α_lat，需 k≥(q_L(α_lat)+δ)/dt（或 B 相应增大）。重尾下缓冲必须按分位而非均值设计，否则"平均延迟够用、P99 必饿"。
- **引理 10（时间可行性 / 延迟墙）**：安全要求 k≤m(v)，藏延迟要求 k≥(q_L+δ)/dt。存在整数 k 当且仅当 ceil((q_L+δ)/dt)≤⌊τ_irr(v)/dt⌋（连续化即 q_L+δ≤τ_irr(v)）。若在最小可行速度下仍不成立，则当前任务结构不可行；否则最小减速因子由该整数条件反解。**这是"延迟-安全-速度"三难的第一性约束，不是工程调参。**
- **定理 9（PACE 端到端成功率下界）**：在延迟分位、VISTA 安全、视觉与任务误差各自被 α_i 控制且事件可联合界时，DCSR(D)≥1−Σα_i，且安全违规概率≤α_safe。CDC 的 k*、v*、SAX 的 j_spec 均按此预算求解。
- **定理 10（VOC 阈值最优性）**：在有限视界、p(b) 单调、延迟代价可加的停止问题中，最优策略是"边际成功增益≥影子价格"的阈值策略；λ(t) 随截止期逼近单调上升，故越接近截止期越早停、越偏向快策略。多细化臂下 Gittins 索引给出可计算的调度近似。
- **命题（精度不必等于成功率）**：存在策略 π_slow（动作更准、L 更大）与 π_fast（略差、L 更小），使 DCSR(π_fast)>DCSR(π_slow) 而 accuracy(π_slow)>accuracy(π_fast)。原因是慢策略把延迟耗在截止期预算里，且重尾下饥饿概率非线性上升。故**不能只报无时限 success rate**。
- **命题（推测执行的安全性）**：若 j_spec>0 且草稿前缀逐步可恢复，则 SAX 的可行轨迹集合是"先验证后执行"的子集；因此不降低安全，只把验证时间与执行时间重叠，从而降低有效延迟、提高 DCSR。
- **实时性**：LSM 分位查询、TFI 时序特征、SAX 验收、调速都在实时流；重标定、EVT 拟合、CDC 搜索、VOC 规划在语义流。目标实时路径 ≤3.0ms（A94 契约，需硬件时间戳与零拷贝观测环形缓冲）。

## 5. 本轮最大风险

**一句话**：延迟分布是**内生且非平稳**的——控制器一改速度、计算预算或任务分解，延迟与场景难度也随之改变，于是 LSM 的条件分位与 SRL 的成功率下界可能在反馈回路中系统性失准；此时系统会"用自己校准出的乐观延迟"去认证一个实际上来不及的截止期，最坏情况下比不做延迟建模更自信地越过失败点。

## 2. 形式化定义（完整版）

**定义 233（PACE 闭环）** PACE 是 VISTA 的"时敏 + 成功率"升级：在 VISTA 的语义流/实时流骨架上挂载 LSM（延迟状态）、TFI（时序故障隔离）、SAX（推测执行）、VOC-AI（计算价值随时推理）、CDC（认证截止期分块）、SRL（成功率下界），并原位升级 RSC-V→RSC-T、WCV-V→WCV-T、CSP-V→CSP-T、AIC-V→AIC-T、J_vista→J_pace。不变式：
1. **年龄不变式**：任何被消费的动作结果都必须携带自己的观测年龄与延迟分位；
2. **可恢复不变式**：任何执行前缀在所选速度下都必须保留不可逆点之前的刹车/柔顺退避能力；
3. **目标不变式**：优化/比较/认证的对象是 DCSR(D)，不是无时限 success rate；
4. **流隔离不变式**：EVT 拟合、CDC 搜索、VOC 规划、重标定只在语义流；实时流只做时间戳采集、饥饿/延迟监测、SAX 验收、保护前缀派发与调速。

**定义 234（延迟状态与 LSM）** 端到端延迟分解为
L_t = L_sense + L_comm + L_infer(c_t,b_t,h) + L_sched，
其中 c_t 为场景难度（物体数、动态程度、遮挡、token 长度、候选数），b_t 为计算预算。LSM 维护：
- 工作点模型 μ_L(c,b,h)；
- 条件分位 q_L(α|c,b)：对超过阈值 u 的尾部用广义 Pareto 分布（GPD）拟合，P(L>u+x|L>u)≈(1+ξx/β)^{−1/ξ}，ξ≥0 时按 EVT 分位公式外推；对残差用 split-conformal 校准；
- 漂移检测：以滑动窗口的 KS 统计量、超分位频率、以及"场景难度—延迟"残差的相关性为触发；触发即重标定并递增 `latency_calib_ver`。
延迟不是已知常数，而是**可测、可预测、可被控制决策改变的状态**。

**定义 235（截止期条件成功率 DCSR 与延迟-成功率前沿）** 对任务 π 与截止期 D：
DCSR_π(D) = P_π(S ∧ T_complete ≤ D)，
其中 S = 任务正确完成 ∧ 无安全违规 ∧ 无不可逆损伤。标准 success rate 为 lim_{D→∞} DCSR_π(D)。策略比较用 Pareto 支配：π₁≻π₂ 当且仅当 ∀D，DCSR₁(D)≥DCSR₂(D) 且至少一处严格。**报告单点 success rate 会奖励"无限等待"的策略，DCSR 前沿才对应部署现实。** 对多任务/多回合，可进一步定义 DCSR 的几何平均或最坏任务下界。

**定义 236（块饥饿队列 CSQ）** 块策略输出 H 步块、执行前缀 k 步。执行一个块耗时 T_k=k·dt。预取下一块从当前块首开始，需 L_next+δ 可用；单块缓冲的饥饿事件
E_starve = {L_next > T_k − δ}；
B 块缓冲为 {L_next > B·T_k − δ}。利用率 ρ=E[L]/(B·T_k)，稳定预取需 ρ<1。给定饥饿预算 α_lat，选
k ≥ (q_L(α_lat)+δ)/dt（或 B ≥ (q_L(α_lat)+δ)/(k·dt)）。
重尾下用均值设计缓冲会得到"平均不饿、P99 必饿"的假安全；CSQ 强制按分位设计。饥饿时的回退不是"继续执行过期块"，而是进入定义 239 的保护动作（柔顺保持/减速/重新观测）。

**定义 237（时间可行性、不可逆视界与速度包络 TST）** 令 τ_irr(v,φ) 为：在当前计划、速度 v、几何/接触状态 φ 下，从此刻起仍能在最坏扰动中刹车或柔顺退避到非不可逆状态的最长时间。假设 τ_irr 关于 v 单调不增（越快，留给反应/刹车的时间越短），并令 m(v)=⌊τ_irr(v)/dt⌋。安全执行前缀要求
k ≤ m(v)。
藏住下一次推理要求
q_L(α_lat)+δ ≤ k·dt。
存在整数 k 同时满足，当且仅当
ceil((q_L(α_lat)+δ)/dt) ≤ ⌊τ_irr(v)/dt⌋。
连续化（忽略一步整数舍入）即 q_L(α_lat)+δ ≤ τ_irr(v)。定义**延迟墙**
Λ(φ) = τ_irr(v_min,φ)。
若 q_L(α_lat)+δ > Λ(φ)，则当前任务在当前可逆性结构下不可能既藏延迟又安全：必须 (i) 改变任务以推远不可逆点（改抓取/改接触策略/增加支撑），(ii) 允许柔顺接触把刚性不可逆点变成可恢复过程，或 (iii) 停机。若可行，定义最大可行速度
v_max = max{v : ceil((q_L+δ)/dt) ≤ ⌊τ_irr(v)/dt⌋}，
最小减速因子 s* = v_nom/v_max。**速度第一次成为与几何/力并列的安全执行器：不改变"往哪走"，只改变"来不来得及救"。**

**定义 238（时序故障假设 H_lat 与 TFI）** 在 VISTA 的 ℋ={H0,H_geo,H_force,H_model,H_vis,H_policy} 上增 H_lat（延迟/抖动/饥饿导致的过期动作）。时序证据
τ = [Δ_ts, r_replay, 1_starve, verifier_lag, q_L_ratio]，
其中 Δ_ts 为实测端到端延迟相对标称的偏移，r_replay=‖a_t−π_θ(y_{t−L})‖ 为把策略重新喂给过期观测后的动作回放残差。后验
P(H|ρ,τ) ∝ p(ρ|H)·p(τ|H)·P(H)，
不重训 VISTA 的 15 维签名似然，只在时序特征上增一个因子。判别逻辑：
- Δ_ts 大、r_replay 小 → **H_lat**：延迟足以解释异常，策略本身没坏；
- Δ_ts 正常、r_replay 大 → **H_policy**：策略在正常时序下也偏离；
- Δ_ts 正常、e_vis 大 → **H_vis**：视觉观测错；
- Δ_ts 大且力/几何残差同时异常 → 共因/复合故障，判 ambiguous（沿用 VISTA 的 AFA）。
时间戳使 H_lat 成为**可辨识的"半个真值"故障**，这是它相对 H_geo/H_model 的结构性优势。

**定义 239（推测动作执行与安全验收 SAX）** 快策略 π_d 在 L_d 内产出草稿块 A^d，慢策略/验证器 π_v 在 L_v 内产出 A^v。执行器可先执行草稿前 j 步，同时等待验证。验收条件：
1. **可恢复性**：∀s≤j，执行 a_s^d 后仍存在可行控制使系统在不可逆点前进入非不可逆状态，记 ρ_rec(a_s^d;v)≥0；
2. **验证时限**：L_v+δ_abort ≤ τ_irr(v)−s·dt（验证与恢复必须在不可逆点前完成）。
由 2 得推测视界
j_spec(v) = ⌊(τ_irr(v)−L_v−δ_abort)/dt⌋。
若 j_spec≤0，禁止推测，退化为"先验证后执行"（严格安全但慢）。若验证在 j_spec 内否决草稿，则立即中止并进入保护动作（柔顺保持/减速/重观测）。**草稿是否被接受由"可恢复性"决定，而不是由模型置信度决定。**

**定义 240（计算价值与 anytime 推理 VOC-AI）** 模型支持从粗到细的随时输出：动作 token 逐步细化、扩散去噪步数递增、或世界模型 rollout 步数递增。设计算预算 b 下的预期成功概率 p(b)（单调不减、边际递减），延迟的影子价格 λ(t) 由截止期剩余时间与任务价值反解（越接近截止期越大）。继续计算当且仅当
(p(b+Δb)−p(b))/Δb ≥ λ(t)。
在有限视界、p 单调、延迟代价可加的停止问题中，最优策略是"后验成功增益阈值"策略；多细化臂（动作维度、物体、技能）下用 Gittins 型索引作可计算近似。**早停不是"省算力"，而是"用延迟换成功率的边际定价"。**

**定义 241（认证截止期分块 CDC）** 对块 A_t，联合选择 (H,b,k,v)，求解
max_{H,b,k,v} P_success
s.t. k ≤ m(v), q_L(α_lat|b)+δ ≤ k·dt,
     b ≤ B_remaining(D),
     VISTA 的几何/力/归因/视觉约束,
     k*≥1。
输出 (H*,k*,v*,b*) 与最小安全裕度；执行器只执行 k* 步，然后强制重规划与再归因。H 只影响前瞻一致性与方差，k/v 才承担安全承诺；CDC 是第 65 轮 CSC 在"延迟-截止期"维度的严格扩展（当 L→0 且 D→∞，CDC 退化为 CSC）。

**定义 242（成功率下界证书 SRL）** 把失败分解为
F = F_safe ∪ F_lat ∪ F_deadline ∪ F_task ∪ F_vis。
若 P(F_i)≤α_i，由联合界
DCSR(D) ≥ 1 − (α_safe+α_lat+α_deadline+α_task+α_vis)。
另用 n 个标定回合的经验成功率给高概率下界（Hoeffding/Beta/Clopper-Pearson）。最终证书取两个有效下界中较保守者，并记录其置信度、样本量与假设。**证书输出的是"截止期内成功的下界"，不是"平均成功率"的点估计。**

**定义 243（RSC-T / WCV-T / CSP-T）** 在 VISTA 的 r_geo/r_force/r_model 外增 r_lat：
- H_lat → 只膨胀 r_lat，并降速/加缓冲/重标定时间戳；**不膨胀几何、不怀疑力标定**；
- WCV-T 搜索域 B(φ̂,r)∩…∩𝒱∩𝒯，𝒯 为时间可行域（速度、截止期、k 上下界）；CVaR 尾部在"延迟分位 × 故障后验"上边缘化；
- CSP-T 的块边带 deadline 标签与最低 k* 要求；规划代价增 λ_D·hinge(T_complete−D)+λ_lat·H(P(H|ρ,τ))；技能块签名分布增时序特征，偏离即 OOD。

**定义 244（AIC-T 对抗延迟认证）** 干扰集
ℰ_T = ℰ_V × ℰ_time，
ℰ_time 含：注入端到端延迟、straggler、优先级反转、时钟偏斜、抖动、批处理队头阻塞、以及**截止期攻击**（在临近不可逆点时故意触发慢推理/慢验证）。在 ℰ_time 上取最坏延迟分位 q_L^worst 重算 ρ_dir，并设置**硬件看门狗**：若验证/派发超过 W_max 且 W_max>τ_irr，则强制刹车（此路径不依赖任何学习组件）。J_dir 增 latency_calib_ver、sched_ver；J_pace 记录是否触发看门狗。

**定义 245（PACE 算子与 J_pace）** 语义流：
[VISTA 语义流 → LSM 延迟分位 → TFI 时序归因 → VOC-AI 计算预算 → CDC 联合选 (H,k,v,b) → SRL 成功率下界 → CSP-T 规划]。
实时流：
[硬件时间戳采集 → 延迟/饥饿监测 → SAX 验收 → 保护前缀派发 → 调速执行 → 看门狗]。
J_pace = (J_vista, latency_quantile, deadline_slack, k*, v*, DCSR_lcb, speculation_accept, latency_state_hash, sched_ver)。
Valid(J_pace) ⇔ Valid(J_vista)
∧ 延迟分位已标定且未漂移（或已重标定）
∧ 时间可行（k* 在 [k_min,k_max] 内）
∧ DCSR_lcb ≥ 1−Σα_i
∧ 推测前缀满足可恢复性
∧ 各版本号一致。
审计链新增：为何选这个 k*（延迟分位与可用时间）、为何选这个速度（不可逆视界）、草稿是否被推测执行、成功率下界是多少、是否触发看门狗。

from collections import deque

class LatencyStateModel:
    def __init__(self, alpha=0.01, win=256):
        self.alpha = alpha
        self.ref = deque(maxlen=win)
        self.xis, self.betas, self.u = None, None, None

    def fit_tail(self, latencies):
        u = np.quantile(latencies, 0.9)
        exc = latencies[latencies > u] - u
        self.xis, self.betas = fit_gpd_mle(exc)       # EVT 尾部
        self.u = u

    def quantile(self, c, b, alpha):
        base = self.mean_model.predict(c, b)          # 工作点
        tail = gpd_quantile(alpha, self.u, self.xis, self.betas)
        raw = max(base, tail)
        return conformal.upper(raw, alpha)            # split-conformal 校准

    def drift_detected(self, recent):
        if ks_2samp(recent, self.ref).pvalue < 1e-3:
            return True
        return np.mean(np.asarray(recent) > self.last_q) > 2 * self.alpha

    def update(self, L, c, b):
        self.ref.append(L)
        if self.drift_detected(list(self.ref)):
            self.fit_tail(list(self.ref)); self.recalibrate()
```

### IP-228 TFI（时序故障隔离）

```python
class TemporalFaultIsolation:
    HYP = ('H0', 'H_geo', 'H_force', 'H_model', 'H_vis', 'H_policy', 'H_lat')

    def temporal_features(self, log, policy, obs):
        L = log.end_to_end_latency()
        a_t = log.action
        y_stale = obs.at_time(obs.t - L)
        replay = np.linalg.norm(a_t - policy(y_stale))
        return np.array([log.delta_ts, replay, log.starved,
                         log.verifier_lag, L / self.nominal_L])

    def attribute(self, phases, tau):
        rho = signature(phases)                        # VISTA 15 维
        logp = {}
        for h in self.HYP:
            logp[h] = (np.log(self.lik_rho[h](rho) + 1e-12)
                       + np.log(self.lik_tau[h](tau) + 1e-12)
                       + np.log(self.prior[h]))
        post = softmax(logp)
        h_star = max(post, key=post.get)
        return post, h_star, post[h_star] < 1.0 - self.delta_fi
```

class SpeculativeExecutor:
    def speculation_horizon(self, tau_irr, L_verify, dt, delta_abort):
        return int(np.floor((tau_irr - L_verify - delta_abort) / dt))

    def step(self, A_draft, A_verify_future, v, tau_irr, dt):
        j = self.speculation_horizon(tau_irr, self.verifier_eta, dt, DELTA_ABORT)
        if j <= 0:
            return self.wait_then_act(A_verify_future)   # 退化：先验证

                return self.compliant_hold()             # 不可恢复即停

            if self.verifier_rejects_now() and time_before_irr(s, tau_irr, dt):

        return self.continue_with_verifier(A_verify_future)

### IP-230 VOC-AI（计算价值）

```python
class ValueOfComputation:
    def shadow_price(self, D_remaining, task_value):
        return task_value / max(D_remaining, EPS)      # 越近截止期越贵

    def run(self, post, b0, db, D_remaining):
        b = b0
        while b + db <= self.max_budget:
            p0 = self.success_prob(post, b)
            p1 = self.success_prob(post, b + db)
            if (p1 - p0) / db < self.shadow_price(D_remaining, self.task_value):
                break
            b += db
            self.refine(b)
        return b, self.action_at(b)
```

### IP-231 CDC（认证截止期分块）

class CertifiedDeadlineChunker:
    def plan(self, A, post, phi, q_lat, D_remaining, dt):
        k_min = int(np.ceil((q_lat + DELTA) / dt))
        best = None
        for v in candidate_speeds(phi):                 # 由慢到快
            k_max = int(np.floor(tau_irr(v, phi) / dt))
            if k_max < k_min:
                continue                                # 该速度下延迟墙
            for b in compute_budgets(D_remaining):
                if latency_quantile_at(b) > q_lat:
                    continue
                for k in range(k_min, min(k_max, len(A)) + 1):
                    if safety_margin(A[:k], post, v) < 0:
                        break
                    p = success_prob(A[:k], post, v, b, D_remaining)
                    if best is None or p > best.p:
                        best = Candidate(p, H=self.H, k=k, v=v, b=b)
        return best if best is not None else 'infeasible_delay_wall'

## 4. 推导

**引理 9（块饥饿）** 设单块预取，块执行时间 T_k=k·dt，下一次推理延迟 L，派发余量 δ。若 L≤T_k−δ，则下一块在缓冲区耗尽前就绪，块内无饥饿；若 L>T_k−δ，则在第 k 步前缓冲区为空，发生饥饿。B 块缓冲把条件替换为 L≤B·T_k−δ。故给定饥饿预算 α_lat，取 k≥(q_L(α_lat)+δ)/dt 或 B≥(q_L(α_lat)+δ)/(k·dt) 即可保证 P(饥饿)≤α_lat。对重尾分布，E[L] 可以远小于 q_L(α_lat)，因此"按均值选 k"会系统性低估饥饿率；而饥饿的代价不是线性延迟，而是**块间不连续/停机/重规划**，会以阶跃方式破坏成功率。∎

**引理 10（时间可行性 / 延迟墙）** 安全要求 k≤m(v)=⌊τ_irr(v)/dt⌋；藏延迟要求 k≥ceil((q_L(α_lat)+δ)/dt)。整数 k 存在当且仅当 ceil((q_L+δ)/dt)≤⌊τ_irr(v)/dt⌋；连续化后即 q_L+δ≤τ_irr(v)。若在最小可行速度 v_min 下仍不成立，则对任何速度都不成立，当前任务结构不可行（延迟墙 Λ=τ_irr(v_min)）。反之，τ_irr 关于 v 单调不增，故可行速度集合是一个下闭区间，最大可行速度 v_max 由 τ_irr(v)=q_L+δ 反解；最小减速因子 s*=v_nom/v_max。该结论只依赖"不可逆点存在 + 速度越快反应时间越短"两个假设，不依赖具体控制器。∎

**定理 9（PACE 端到端成功率下界）** 在 A94–A99 下：
(A94) 延迟分位 q_L(α_lat) 在标定分布内覆盖真实延迟，且漂移被检测/重标定；
(A95) τ_irr(v) 关于 v 单调不增且可保守下界；
(A96) VISTA 安全证书给出的安全违规概率≤α_safe；
(A97) 视觉 conformal 覆盖≥1−α_vis；
(A98) 任务模型误差导致的失败概率≤α_task；
(A99) 截止期违反概率在 CDC 的 k*、v* 选择下≤α_deadline。
令 F=F_safe∪F_lat∪F_deadline∪F_task∪F_vis。由联合界
P(F)≤α_safe+α_lat+α_deadline+α_task+α_vis，
故
DCSR(D)=P(S∧T≤D)=1−P(F) ≥ 1−Σ_i α_i。
CDC 在求解时对每个候选 (H,k,v,b) 逐一检查上述约束，故输出的 k*、v*、b* 满足预算；SAX 的 j_spec 由同一 τ_irr 计算，因此推测执行不额外消耗安全预算。证毕。∎

**定理 10（VOC 阈值最优性）** 考虑有限视界停止问题：剩余时间 T、计算预算 b、状态后验 post。选择停止或继续一个 Δb 的计算步，继续获得成功概率增量 Δp=p(b+Δb)−p(b)，支付延迟代价 λ·Δb（λ 为截止期影子价格）。由有限视界动态规划，值函数 V(b,post) 关于 b 的差分单调递减（p 边际递减）时，最优策略是阈值策略：继续当且仅当 Δp/Δb≥λ。λ(t) 随剩余时间减少而增大（截止期越近，单位延迟越贵），故策略自然从"多算"过渡到"早停/用快策略"。多细化臂时，若各臂成功增益可加且相互独立，Gittins 索引给出每臂的优先级；否则用一步 lookahead 近似。证毕。∎

**命题（精度不必等于成功率）** 构造单决策任务：策略 A 的动作正确率 0.99，但推理延迟 200ms；策略 B 正确率 0.95，延迟 40ms；任务截止期 D=150ms，且动作必须在 D 前执行。则 DCSR_A=0，DCSR_B=0.95，尽管 accuracy(A)>accuracy(B)。更一般地，在重尾延迟下，成功率是 accuracy 与 P(T≤D) 的乘积型耦合；当延迟尾部质量不可忽略时，提高 accuracy 的边际收益可能被截止期惩罚抵消。因此第 65 轮只报"安全 + success"不够，必须报延迟-成功率前沿。∎

**命题（SAX 的安全性）** 若对草稿前缀的每一步都有 ρ_rec(a_s^d;v)≥0，且 j_spec 满足验证与恢复都在 τ_irr 前完成，则从任意草稿轨迹出发，系统仍能在不可逆点前进入非不可逆状态；故 SAX 的可达安全轨迹集合包含于"先验证后执行"的可恢复集合，安全不降低。SAX 的收益来自把 L_v 与执行时间重叠：有效等待从 L_v 降到 max(0,L_v−j·dt)，从而在同等 D 下提高 DCSR。若 j_spec≤0，SAX 自动退化为严格先验证后执行，故该命题不要求延迟足够小。∎

**命题（时间膨胀的代价）** 降速提高 τ_irr，从而扩大可行 k 区间、降低饥饿/越界概率；但降速同时增加完成时间 T_complete，可能违反截止期。故 DCSR 关于 v 一般非单调：存在内点 v* 平衡"来得及救"与"来得及做完"。CDCL 的一维搜索即为该权衡的在线求解；若 v_min 下仍越墙，则 DCSR 的可行域为空，必须改变任务而不是继续调参。∎

## 7. 已知风险

**一句话**：延迟分布是内生且非平稳的——控制器改变速度、计算预算或任务分解会反过来改变延迟与场景难度，LSM 的条件分位与 SRL 的成功率下界可能在反馈回路中系统性失准；系统会"用自己校准出的乐观延迟"去认证一个实际上来不及的截止期，最坏情况下比不做延迟建模更自信地越过失败点。

**次级风险与缓解**：
1. **内生性/反馈回路**：v、b、k 改变延迟分布，conformal 的可交换性假设被破坏。缓解：按 (c,b,v) 分层标定；漂移检测 + 在线重标定；报告条件覆盖而非边际覆盖；对最坏 ℰ_time 取上界。
2. **延迟墙误判**：τ_irr 的估计依赖接触/几何/制动模型，模型错会把"可行"判成"不可行"或反之。缓解：τ_irr 用保守下界；与 VISTA 的 r_geo/r_force/r_model 联合；越墙时优先安全停机而非激进调速。
3. **推测执行的安全验收依赖验证器时限**：L_v 本身重尾，验证可能赶不上不可逆点。缓解：j_spec 用 q_L(α) 而非均值；硬件看门狗独立兜底；验证器超时即中止草稿。
4. **时间膨胀导致活锁/截止期失败**：不断降速可能永远做不完。缓解：DCSR 目标显式含截止期；设最小速度与最大减速因子；越墙即改任务/停机，不无限降速。
5. **VOC 的成功概率模型偏差**：p(b) 的估计本身可能错，导致过早停或过度算。缓解：用标定回合拟合 + 保守下界；截止期临近时偏向快策略；保留最小计算预算。
6. **测量误差与时钟偏斜**：时间戳不同步会污染 Δ_ts 与 r_replay。缓解：硬件同步/PTP；时钟偏斜作为 AIC-T 的显式干扰；用单调时钟与到达时间双记录。
7. **多机/多任务资源争用**：批处理与优先级反转让延迟对其他机器人内生。缓解：预留实时核/优先级继承；跨机调度纳入 ℰ_time；本地看门狗不依赖网络。
8. **DCSR 被"刷分"**：只挑容易在截止期内完成的任务会虚高。缓解：固定任务分布与截止期；报告最坏任务/分层 DCSR；同时报告 safety 与损伤。
9. **仿真到现实的延迟失配**：仿真推理延迟与真机不同，策略在仿真里"来得及"、真机"来不及"。缓解：在仿真中注入真实延迟分布（域随机化延迟）；真机标定后重新认证 J_pace。
10. **过度归因 H_lat**：把所有异常都归为延迟会掩盖真实策略/视觉故障。缓解：回放残差与时间戳双证据；复合故障判 ambiguous；保留 VISTA 的 AFA 主动判别。
