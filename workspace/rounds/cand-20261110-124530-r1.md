# 第 44 轮（新循环第 4 轮） · LiDAR-Teacher × Delay-Cert：把「激光雷达」移出部署链、把「远程延迟」纳入证书时间维度（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 把个性化与并发纳入证书，但仍压着两个未言明的假设：**(H3) 几何证书的输入在部署时可得**——v20 的 IP-49/LIO 默认机器人带 LiDAR/深度；**(H4) 证书的新鲜度只由本地调度决定**——v20 的租约假设本地串行/并发计算，忽略了远程策略服务引入的**公网 RTT + 动作块开环执行**。本轮灵感词「激光雷达」「UniBot-V1」精确命中这两个假设：**激光雷达**既是最强几何真值，又恰恰是 UniBot-V1 观测 schema 中**不存在**的传感器（只有 4 路 RGB + 本体感受）；**UniBot-V1** 是一个真实硬件、远程 WebSocket 服务、按动作块顺序执行、并公开记录延迟与动作规律性的比赛。于是本轮核心转向：**把 LiDAR 从「部署传感器」降级为「离线教师/验证 oracle」，把部署几何证书建立在「校准过的 RGB 深度区间」上；把延迟从「工程噪声」升级为「证书时间维度的显式变量」，用延迟条件可达管 + 动作块证书 + 最小干预安全滤波，在真实比赛约束下既不静默不 sound，也不因过度保守而丢分。**

## 0. 直觉与动机

**灵感 1（LiDAR 不在部署链上 → 教师-学生与「区间即抽象」）**：直觉上，比赛只给 RGB，那就别假装有 LiDAR。但实验室/仿真里 LiDAR 是真值，可以当**教师**：用 (RGB, LiDAR 深度) 对训练单目度量几何，再用 **Mondrian 分层共形预测**产出深度区间 `D^α(x)=[d_lo,d_hi]`，保证 `P(d^L ∈ D^α) ≥ 1−α`。关键不是“预测得准”，而是“**区间是 sound 抽象**”：只要真值深度落在区间内，用区间内**最坏深度**算出的几何裕度 `m_geo^α = min_{d∈D^α} m(d)` 必是真实裕度的下界，因此拿它做守卫绝不误放。LiDAR 由此从“传感器依赖”变成“**精度迁移 + 验证真值 + 数字孪生先验**”三合一，而部署链保持纯 RGB。

**灵感 2（UniBot-V1 → 远程服务 + 动作块，承诺即负债）**：比赛策略跑在自己的服务器上，观测经公网来、动作块回去顺序执行，评测还记录延迟与延迟稳定性。这意味着一份证书一旦签发，就要为**整个动作块的开环执行窗口**背书：陈旧时间 `Δ=Δ_net+Δ_inf+H·Δt` 会持续膨胀状态不确定球。于是把 v20 的“点时刻新鲜度”升级为**延迟条件可达管** `T(x_τ,Δ,H)`，动作块证书要求整条管留在安全集内；管证不出来就**缩短 horizon**，再不行退**安全伺服/保持**。延迟不再是“偷偷吃掉裕度”的敌人，而是被显式计入证书的变量。

**灵感 3（耦合 → 盲测下的「无静默失效」与「不只会说 no」）**：UniBot-V1 用未知真机 + 公网，是典型盲测。证书必须**硬件无关**（只靠标定表随传感器指纹切换），并满足**无静默失效**：任何不 sound 都必须被运行时哨兵提前/同步报警并单调降级。另一方面，排行榜按成功率 + 步骤分排序，一个“永远停机”的安全层等于零分。因此必须在认证集内做**最小干预选择**：挑最接近 VLA 原动作、且动作变化最小的块，让“安全”与“动作规律性/步骤分”同向而非对立。

**耦合升级**：LTG（LiDAR 教师）把几何变成带覆盖保证的区间抽象；DCC（延迟-动作块证书器）把时间不确定性变成管证书与回退层级；HAS（硬件无关哨兵）守住盲测下的“无静默失效”。四层架构由 v8 的“个性化-并发证书”升级为 v9 的“**RGB-only 空间-时间证书闭环**”：LiDAR 在校准链与验证链，延迟在证书的每一层。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（观测受限证书与抽象可靠性）**：部署观测 `O^dep=(I_1..I_4, q_{1:14}, p_ee, g, q_lb, ℓ)` 仅含 RGB 与本体感受。证书分解为 `C=(C_geo, C_dyn, C_sem)`，几何证书只能通过观测抽象 `A: O^dep → (D^α, ŝ, x̂)` 获得。称 `A` **sound**，当且仅当真实几何 `g*` 属于 `A(O^dep)` 所表示的集合（含深度区间与分割不确定域）。**命题（抽象传递）**：若 `A` sound 且 `C` 在 `A(O^dep)` 上 sound，则部署证书 sound。这把“需要 LiDAR”改写为“需要 sound 的观测抽象”。

**定义 45（LiDAR 教师与共形深度区间）**：离线教师 `T_L` 在标定对 `{(I_i, d_i^L, pose_i)}` 上训练单目度量几何（深度/法向/自由空间）。按分层 `s`（物体类、距离段、纹理）计算非一致性分数并取秩统计阈值 `q_s`，得
`D^α(x)=[d_lo−q_s, d_hi+q_s]`，可交换性下满足 `P(d^L ∈ D^α(x)) ≥ 1−α`。
设几何裕度 `m(d)` 关于深度满足 Lipschitz 常数 `L_m`。定义**证书裕度** `m_geo^α = inf_{d∈D^α} m(d)`。**引理（保守 sound）**：若真值 `d*∈D^α`，则 `m_geo^α ≤ m(d*)`；故用 `m_geo^α` 作守卫下界绝不误放，且保守量由**区间宽度**（“几何不确定性税”）直接控制。**注**：覆盖是分布/分层意义，OOD 由定义 49 的哨兵兜底。

**定义 46（延迟条件可达管与动作块证书）**：观测时刻 `τ`，块内第 `j` 步执行时刻 `t_j=τ+Δ_net+Δ_inf+j·Δt`。定义**陈旧时间** `Δ=Δ_net+Δ_inf+H·Δt` 与可达管
`T(x_τ,Δ,H) = Reach(F, B(x_τ, v_max·Δ+ρ_obs), W, H·Δt)`，
其中 `F` 为动力学集合、`W` 为扰动界、`ρ_obs` 为观测不确定半径。**块证书** `c_chunk` 有效当且仅当 `T(x_τ,Δ,H) ⊆ S_θ`（安全集按裕度 θ 内缩）。**定理（块 sound）**：若 `Δ ≤ Δ_max`、`x_τ` 真值在初始球内、真实动力学属于 `F`，且 `c_chunk` 有效，则整块开环执行期间状态不出 `S_θ`。动作块的开环性由“对整条管负责”补偿，而非由在线反馈补偿。

**定义 47（最小干预认证选择与回退层级）**：设认证块集合 `A_cert={a : c_chunk(a) valid}`。非空时
`a* = argmin_{a∈A_cert} [ cost_task(a) + γ·||a_1−a_prev||² ]`，
即在安全前提下尽量贴近任务最优并抑制动作抖动（保步骤分与动作规律性）。为空时按**回退层级** `L2 全块 → L1 短块（H↓）→ L0 安全伺服/保持` 依次降级。**命题（时间覆盖）**：若每个时刻要么存在有效块证书、要么 L0 安全伺服证书成立，则执行序列在任意时刻都有 sound 证书；回退只减少自主性，不放松阈值。

**定义 48（RTT 租约与抖动鲁棒新鲜度）**：证书租约升级为 `ℓ=(m, τ, λ, λ_net, Δ_budget, κ)`，其中 `Δ̂_{1−β}` 是由历史 RTT 得到的共形延迟上界。**新鲜度判据**：
`m_eff(t) = m − λ·(t−τ) − λ_net·Δ̂_{1−β} ≥ θ` 且 `Δ̂_{1−β} ≤ Δ_budget`。
**漂移检测**：用延迟序列的共形 p 值；若 `p<β_shift`（分布漂移显著），**全体租约立即作废**并进入安全保持。**命题**：在延迟可交换且覆盖有效时，误用陈旧边际的概率不超过 `β+β_shift`；漂移时宁可不发租约，也不发“看起来新鲜”的租约。

**定义 49（硬件无关哨兵与「无静默失效」）**：哨兵 `S(O^dep, cert, delay_hist) → {NOMINAL, DEGRADE_GEO, DEGRADE_SEM, SAFE_HOLD, SMOOTH}` 只依赖部署观测与证书/延迟历史。称发生**静默失效**，若存在一条轨迹在部署上不 sound 而哨兵在违例前始终为 NOMINAL。**要求（monitorability）**：`unsound ⟹ 哨兵在违例前/同时非 NOMINAL`。**可移植证书**：证书语义与机型无关，仅标定表按 `(相机内参, 传感器指纹, 执行器延迟)` 索引——这正是盲测排行榜下唯一可审计的做法。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 LIDAR-TEACHER-GEOMETRY（几何教师 LTG）
1. **教师训练**：离线/实验室用 (RGB, LiDAR 深度, 位姿) 训练单目度量几何，LiDAR **永不进入部署链**。
2. **Mondrian 共形深度区间**：按物体类/距离段/纹理分层校准，输出 `D^α(x)` 与区间宽度（保守性预算）。
3. **区间→裕度单调编译**：把 `D^α` 编译为 `m_geo^α` 与 CBF/守卫阈值，保证“区间越宽越保守、绝不更激进”。
4. **验证 oracle 与数字孪生**：LiDAR 提供 E95/E96 真值与 Isaac Sim 几何先验，用于离线认证与回归。

### 2.2 IP-61 DELAY-CHUNK-CERTIFIER（延迟-块证书器 DCC）
1. **延迟账本**：显式记账 `Δ_net + Δ_inf + H·Δt`，按步更新，不把 RTT 当常数。
2. **延迟条件管证书**：整块开环执行的可达管必须内于安全集；管证书用最坏深度区间膨胀。
3. **自适应 horizon + 回退层级**：`H: 8→4→2→1`，全失败走 L0 安全伺服，绝不硬发未证块。
4. **最小干预认证滤波**：认证集内选“最像 VLA、且动作最平滑”的块，兼顾成功率、步骤分与动作规律性。

### 2.3 IP-62 HARDWARE-AGNOSTIC-SENTINEL（硬件无关哨兵 HAS）
1. **深度区间一致性**：实测几何与预测区间系统性冲突（或区间宽度爆炸）→ DEGRADE_GEO。
2. **语义 OOD**：分布外物体/纹理/光照 → DEGRADE_SEM（缩裕度或转保守策略）。
3. **延迟漂移**：RTT 共形 p 值显著偏移 → SAFE_HOLD + 作废租约。
4. **动作规律性异常 + 无静默失效审计**：抖动/切换异常 → SMOOTH；所有降级写审计日志，强制“报警先于/同步于违例”。

## 3. 四层架构 v9

```
L0: 安全伺服/保持(急停、退让) —— 永远可证、永远可用的底线
L1: 4×RGB(480×640) + proprio → IP-60 LTG(单目度量几何 + 共形深度区间 D^α)
    LiDAR(离线/实验室) ──教师──→ 标定表 / 验证真值 / 数字孪生几何先验
L2: UniBot-V1 VLA(远程 WebSocket) → 动作块候选 {a^(1..b)}
L3: IP-61 DCC(延迟账本 + 延迟条件管 + 自适应 H) ← IP-58 CCR(租约 v2)
    → IP-51 CAR(守卫 min(m_geo^α, m_tube, 租约)) → IP-53 CMC(区间保守监控)
    → 最小干预认证滤波(贴近 VLA + 抑制抖动) → IP-45 总线(块/延迟/降级审计)
L4: IP-62 HAS(深度一致性/OOD/延迟漂移/规律性哨兵)
    + IP-57 PCE(个性化契约) + IP-55 CKB(标定指纹) + IP-54 SCV(LiDAR 真值 + RTT 注入)
    → IP-44 蒸馏 / IP-50 课程 → RCA 重颁 → 标定表热更新
运行期：RGB→D^α→m_geo^α → VLA 出块 → 延迟建管 → 块证书 → 最小干预选择
        证不出 → 降 H → 仍证不出 → L0 安全伺服；任意降级写审计，禁止静默放行
```

## 4. 实验设计（E95–E102 硬门槛，承接 E87–E94）

回退：E95 覆盖失效 → 关闭认证扩张，退回“粗区间+全局保守阈值”；E96 不达标 → 提高区间下界保守量、缩小可行域；E97 管不 sound → 增大 `Δ_max` 上界并缩短 H，仍不行则只跑 L0；E98 成功/步骤分显著下降 → 增大认证集（换更松但 sound 的阈值）或降低 γ；E99 漂移漏检 → 全量租约作废并安全保持；E100/E101 出现静默失效 → **全链路熔断回退 v20 + 串行监控**。任何红线失败优先保“无静默失效”。

## 5. 本轮最大风险

**一句话**：整套 v9 的 soundness 现在挂在两个统计假设上——**共形深度区间的实际覆盖**与**延迟上界 `Δ̂` 的有效性**；而 UniBot-V1 恰是“未知真机 + 公网重尾延迟”的盲测，一旦测试分布越过校准分布，证书会从“保守”退化为“静默不 sound”——因此 E95/E97/E100 必须设为红线，且部署默认守住“**区间/延迟违规即保守降级到 L0 安全伺服**”这条永不失 sound 的底线。

## 2. 关键算法（伪代码）

### IP-60 LTG：LiDAR 教师、共形深度区间与裕度编译
```
def train_lidar_teacher(calib_pairs):
    # calib_pairs: (rgb, lidar_depth, pose, intrinsics)
    geom = MonocularGeometryNet()
    geom.fit([(p.rgb, p.lidar_depth) for p in calib_pairs])
    return geom                     # LiDAR 仅离线；部署链永不读取

def conformal_depth_interval(rgb, geom, alpha, calib):
    d_lo, d_hi = geom.predict_bounds(rgb)          # 点估计的上下分位
    s = stratum_of(rgb)                            # 物体类/距离段/纹理
    q = rank_quantile(calib.scores[s], 1 - alpha)  # Mondrian 校准（LiDAR 真值）
    lo = max(0.0, d_lo - q); hi = d_hi + q
    return DepthInterval(lo, hi, width=hi-lo)

def geometric_margin(interval, state, task_geom):
    # m(d) 关于 d 有 Lipschitz 界：最坏深度给裕度下界
    return min(signed_distance(state, task_geom, d)
               for d in interval.extremes())       # 端点/极值足够

def geo_guard(interval, state, task_geom, theta):
    m = geometric_margin(interval, state, task_geom)
    return Guard(ok = interval.width <= W_max and m >= theta, margin=m)
```

### IP-61 DCC：延迟账本、管证书、自适应 horizon 与最小干预
```
def delay_tube(x_tau, delta_net, delta_inf, H, dt, v_max, rho_obs, W, reach):
    delta = delta_net + delta_inf + H * dt
    init  = Ball(x_tau, v_max * delta + rho_obs)
    return reach(F, init, W, H * dt)               # 整块开环可达管

def certify_chunk(chunk, x_tau, depth_iv, ctx, H):
    T = delay_tube(x_tau, ctx.d_net, ctx.d_inf, H, ctx.dt,
                   ctx.v_max, ctx.rho_obs, ctx.W, ctx.reach)
    Ts = inflate_by_depth(T, depth_iv, ctx.L_m)    # 几何区间膨胀
    m  = min_signed_distance(Ts, ctx.S)
    return Cert(valid=(m >= ctx.theta), margin=m, H=H)

def choose_chunk(cands, x_tau, depth_iv, ctx, a_prev, gamma):
    for H in (8, 4, 2, 1):                         # 自适应 horizon
        ok = [(a, c) for a in cands
              for c in [certify_chunk(a, x_tau, depth_iv, ctx, H)] if c.valid]
        if ok:
            # 最小干预：贴近任务最优 + 抑制首步抖动
            return min(ok, key=lambda ac: ac[1].cost + gamma*norm(ac[0][0]-a_prev))[0]
    return safe_servo(x_tau, depth_iv, ctx)        # L0：永远可证的底线

def lease_valid_v2(lease, theta, t, delta_hat):
    m_eff = lease.m - lease.lam*(t-lease.tau) - lease.lam_net*delta_hat
    return m_eff >= theta and delta_hat <= lease.delta_budget
```

### IP-62 HAS：哨兵与无静默失效
```
def sentinel_step(obs, cert, delay_hist, reg_hist):
    if interval_conflict(obs, cert.depth_iv) or cert.depth_iv.width > W_max:
        return DEGRADE_GEO                        # 区间不一致/宽度爆炸
    if ood_score(obs) > tau_ood:
        return DEGRADE_SEM                        # 语义分布外
    if conformal_p_value(delay_hist) < beta_shift:
        invalidate_all_leases()
        return SAFE_HOLD                          # 延迟漂移，宁停不发租约
    if jerk(reg_hist) > tau_reg:
        return SMOOTH_ONLY                        # 动作规律性异常
    return NOMINAL

def assert_no_silent_failure(trace, cert_trace, sentinel_trace):
    # 红线性质：任何违例前/同时，哨兵必须已非 NOMINAL
    for t, unsound in enumerate(trace.violations):
        if unsound and all(s == NOMINAL for s in sentinel_trace[:t+1]):
            return False
    return True
```

### IP-51/53 升级：区间保守守卫与监控快照
```
def car_transition_guard(e, x, cert_obj, lease, depth_iv, tube_cert, t, delta_hat):
    theta   = cert_obj.alpha_e[e] * cert_obj.theta_sim[e]
    m_geo   = geometric_margin(depth_iv, x, cert_obj.task_geom[e])
    m_lease = lease.m - lease.lam*(t-lease.tau) - lease.lam_net*delta_hat
    m_tube  = tube_cert.margin
    return min(m_geo, m_lease, m_tube) >= theta and lease_valid_v2(lease, theta, t, delta_hat)

def monitor_step_v4(obs, depth_iv):
    # 监控器只用区间上下界，保守传播；绝不用区间中值当真相
    lo = monitor_step_INT8(quantize(obs, depth_iv.lo))
    hi = monitor_step_INT8(quantize(obs, depth_iv.hi))
    return min(lo.margin, hi.margin)               # 最坏一侧
```

## 6. 本轮最大风险

**一句话**：整套 v9 的 soundness 现在挂在两个统计假设上——**共形深度区间的实际覆盖**与**延迟上界 `Δ̂` 的有效性**；而 UniBot-V1 恰是“未知真机 + 公网重尾延迟”的盲测，一旦测试分布越过校准分布，证书会从“保守”退化为“静默不 sound”——因此 E95/E97/E100 必须设为红线，且部署默认守住“**区间/延迟违规即保守降级到 L0 安全伺服**”这条永不失 sound 的底线。
