# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「遥操作」×「迭代验证」）

> R69 给了系统一张嘴：不确定就去看、去问、去触，用 VoI 决定值不值得问，用「k 个正交证据源一致」来防一句谎话被盖章。但它默认了一个从未被检验的前提——**被问者当场、可靠，而且讲的正是此刻的世界**。真实部署几乎从不满足：人在远端（遥操作），回答要穿过网络延迟与丢包；人的情境意识（SA）本身由滞后视频流构成，是过时的；机器人与人对同一场景的判断，发生在**不同的时间切片**上。于是 R69 的 `update_belief(modes, answer)` 埋着一个时间 bug：它把一条关于 t−τ 时刻的证据，当作 t 时刻的证据用了。
>
> 本轮两个灵感正好补上缺失的时间维：
> - **遥操作**把人从「同步神谕」降格为「延迟、丢包、带签名、可能诚实但过时」的**远端证据通道**；权威不是瞬时开关，而是一份必须按时续租的**租约**。
> - **迭代验证**把「验证」从一次盖章改造成一个**收敛过程**：提出假设 → 执行判别动作 → 用**新鲜的本地残差**核对 → 检查残差是否逐轮收缩（r_{k+1}/r_k < ρ）；收敛才发证，不收敛（或证据已过时到无法与当下对齐）就退回保守。
>
> 核心命题：**可验证性由时间尺度决定。只有当「模式寿命 τ_mode」显著长于「往返延迟 τ_rtt + 验证窗口」时，远端（人）才能真正消解 epistemic 歧义；否则那段歧义对远端通道而言等价于 aleatoric，只能靠本地快探针消解，或直接走 R68 保守。** 命名 **RELAY-RAS**（Remote Evidence, Latency-aware, iterAtively Validated, Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**等答案回来时，我问的还是同一个世界吗**」——验证不只关乎「对不对」，更关乎「还赶不赶得上」。

## 0. 直觉与动机

**灵感 1（遥操作 → 证据有年龄）**
直觉：R69 的 `answer` 是一个没有时间戳的值。可遥操作里一切都有年龄：视频流、操作员判断、控制指令。一句 800ms 前的「左边是对的」，说的是 800ms 前的岔口；如果模式（岔口是否还在）已经切换了，这条证据不是「错」，而是「**过时**」——它精确地描述了另一个世界。过时比噪声更危险：噪声可以被平均掉，而过时证据会以极高置信度指向一个已不存在的模态。所以第一条铁律：证据 =（值，观测时刻 t_obs，到达时刻 t_recv，来源，签名，租约 id）；**没有年龄的证据不是证据，只是一段故事**。

**灵感 2（模式寿命 vs 往返延迟 → 可验证性的 Nyquist 条件）**
直觉：设模态以速率 κ 切换（平均寿命 1/κ），则年龄为 a 的证据仍描述当前模式的概率约为 e^{−κa}。于是远端交互的价值存在一个**硬期限** τ*(ε)=ln(1/ε)/κ；越过它，问与不问在信息上等价。把往返延迟也算进来，可验证性要求 κ·(τ_rtt+验证窗口) ≪ 1——这是人机环路版的 Nyquist 条件：**采样（问）的周期必须短于世界变化的周期，否则采到的是混叠**，即对旧世界的判断。这把 R69 的 VoI 变成一个带时效折扣的量，也把 epistemic 按**时间尺度**再切一刀：快的部分，远端根本救不了。

**灵感 3（迭代验证 → 单次验证是伪命题，收敛才是证书）**
直觉：R69 防的是「一次撒谎」，用 k 源一致。但遥操作里更常见的失败是**诚实但错误**：操作员基于滞后画面做了合理判断，只是世界已经变了。对此「多数一致」失效——大家都盯着同一段旧视频。正解是**迭代**：让机器人在本地用新鲜残差逐轮核对人的判断，得到残差序列 r_0, r_1, r_2…；只有当序列**收缩**（r_{k+1}/r_k < ρ）并稳定若干轮，才认定「人的判断与当下世界对齐」，发验证证书；若残差平台化或振荡（不收缩），说明无法与当下对齐（或有人故意拖住验证），立即退回保守。**证书不是「我验证了」，而是「我的验证在收敛」。**

**灵感 4（权威是租约，不是开关）**
直觉：R66 决定「谁控制」，但那是静态分配。遥操作里权威必须**随时间续租**：人的意图只在「被新鲜证据持续确认」的时段内有效；一旦延迟超过租期，权威自动回到机器人的安全策略（R68）。这既避免「人在远端失联时机器人傻等」，也避免「一条迟到的旧指令把车开进沟里」。租期有下界——必须大于往返延迟（否则人永远在验证上一份租约，陷入芝诺式错位）；也有上界——必须短于模式寿命（否则租约还没到期，世界已经换过了）。

**灵感 5（遥操作的新威胁：不是撒谎，而是拖时间）**
直觉：R69 的威胁是投毒（撒谎）。遥操作的杀手锏却是**时间**：重放旧的有效回答（replay）、放大延迟让「停止」晚到、把意图信号与明确回答解耦（意图欺骗）、故意维持残差不收缩以拖住机器人（收敛停滞攻击）。这些攻击的共同点不是伪造证据，而是**操纵证据的年龄与到达时刻**——让系统在错误的时间相信一个正确的旧事实。所以安全边界必须包含「时效完整性」（freshness integrity），而不只是「内容完整性」。

**灵感 6（对 R69 的姿态：不是替代，而是加一维）**
直觉：R69 把不确定性按**性质**分成 aleatoric / epistemic；本轮不推翻它，而是按**时间尺度**给 epistemic 再加一条切线：U_epi = U_epi^remote（慢、远端在其寿命内可验证）+ U_epi^local（快、远端到达时世界已变）。R69 是 (τ_rtt=0, κ=0) 的边界；R68 是「没有远端意图」的边界。这样每加一层都不是新增黑箱，而是上一层的严格泛化。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（RELAY-RAS 总览）** RELAY-RAS = (TCC, EVR, ETS, IVL, ALA, SAL/CIA†, RAS-WM††)。四不变式：
(i) 继承 R69 的实时流零学习写操作；
(ii) **证据必须带年龄与来源签名**，无有效 EVR 的证据降级为先验，不得单独定案；
(iii) **权威以租约形式存在**，租期 ttl ∈ (τ_rtt+τ_val, τ_mode)，到期未续则自动回落 LOCAL_SAFE（R68）；
(iv) **验证必须收敛**：只有残差序列收缩并稳定后，才允许把 U_epi 视为已消解；否则按未消解处理（走 R69 定义 307 的保守分支）。

**定义 311（遥操作通道契约 TCC）** TCC = (τ_rtt 的上界/分布, p_loss, bw, auth_scheme, clock_skew)。给定 TCC，定义证据新鲜度函数 Fresh(a) = e^{−κ̂·a}，a = t_now − t_obs 为证据年龄，κ̂ 为模式切换速率的在线估计（定义 313）。TCC 是「这条通道能把多少信息带到当下」的契约，所有交互决策都必须以它为约束。

**定义 312（证据有效性记录 EVR）** 证据 e = (val, t_obs, t_recv, src, sig, lease_id)。有效判据 Valid(e) ⇔ Verify(sig, src) ∧ |(t_recv − t_obs) − τ̂_rtt| ≤ δ_τ ∧ age(e) ≤ τ*(ε)。有效证据进入似然；无效证据降级为「历史先验」，不得参与定案（强化 R69 定义 293-iii）。

**定义 313（模式寿命与切换速率）** 设模式身份 m(t) 为分段常值随机过程，切换率 κ，即 P(m(t+a)=m(t)) = e^{−κa}。在线估计 κ̂ 由 (a) R67 VISTA 的模态持续性预测头、(b) 历史模式停留时长经验分布，二者贝叶斯融合；模式寿命 τ_mode = 1/κ̂。

**定义 314（epistemic 的时间尺度二分 ETS）** 在 R69 的 U_epi 上按「相对往返延迟是否可救」再分：
U_epi^remote = U_epi · e^{−κ̂·(τ_rtt+τ_val)}（慢模态，远端可在其寿命内验证）；
U_epi^local = U_epi − U_epi^remote（快模态，远端到达时世界已变，只能本地探针或按 aleatoric 处理）。
与 aleatoric 不同：U_epi^local 并非永久不可约，只是**对远端通道不可约**。

**定义 315（时效折扣 VoI）** VoI_eff(g) = VoI(g)·(1 − p_loss(g))·e^{−κ̂·τ_rtt(g)} − c(g) − c_deadline·P(τ_rtt > τ_deadline)。选择 g* = argmax VoI_eff，s.t. risk(g) ≤ ε_int 且预算未超。R69 定义 298 是本式在 (κ=0, p_loss=0, τ_rtt=0) 的边界。

**定义 316（迭代验证环 IVL）** 状态为模式后验 b_k 与残差 r_k = H(b_k)。第 k 轮：
(1) 选判别动作 u_k ∈ {本地快探针（注视/触，延迟≈0）, 远端查询（延迟 τ_rtt）}；
(2) 执行后用**新鲜本地残差** z_k（几何/同步/行为似然，复用 R68 五元组与 R69 FMA）核对预测；
(3) b_{k+1} = T(b_k, u_k, z_k, e_{k−d})，其中 d = ⌈τ_rtt/Δt⌉，e_{k−d} 为延迟到达的证据；
(4) 收敛判据：r_{k+1} ≤ ρ·r_k 且连续 m=2 轮成立，且 b 在两个独立残差流下一致。满足 ⇒ 发验证证书；超预算 N_iter 仍不满足 ⇒ 判「不可验证」，退回 R68。

**定义 317（验证收缩证书 VSC）** C_val = (ρ̂, {r_k}, N_iter, fresh_ratio, cross_agree)，其中 ρ̂ = median_k r_{k+1}/r_k。Valid(C_val) ⇔ ρ̂ ≤ ρ_max ∧ fresh_ratio ≥ f_min ∧ cross_agree。若 ρ̂ ≥ 1（平台化或振荡）⇒ 非收缩 ⇒ 触发定义 324 的退回。

**定义 318（权威租约 ALA）** 四态：LOCAL_SAFE（R68 纯保守）、LOCAL_VALIDATED（本地探针已消解）、REMOTE_PROVISIONAL（收到远端意图，正在迭代验证）、REMOTE_CONFIRMED（验证收敛且租约未过期）。转移只允许经 PROVISIONAL；每条租约 lease = (intent, issue_time, ttl, evidence_id)，ttl ∈ (τ_rtt+τ_val, τ_mode)。到期未续 ⇒ 自动降级到 LOCAL_SAFE。

**定义 319（租约驻留与无抖振）** 设驻留时间 D（同一权威态的最短停留）。要求 D ≥ τ_rtt+τ_val（保证人的反馈针对同一租约区间）且 D ≤ τ_mode（保证不过期）。区间内权威态单调、不来回切换；跨态切换经 PROVISIONAL 的混合执行（对动作做凸组合），保证控制连续。

**定义 320（时效感知跨模态融合 SAL/CIA†）** 升级 R69 定义 300：证据按新鲜度加权，
b(m) ∝ b_prev(m) · Π_i L_i(r_i | m)^{Fresh(age_i)}，
其中 Fresh(age_i) = e^{−κ̂·age_i}。过时证据的指数权重 → 0，自动退化为先验；R69 的等权融合是本式在 age=0 的边界。

**定义 321（本地自验证）** 不依赖远端时，用 R69 FMA 的 Δa 与 R68 残差做本地一致性核对；本地探针（注视/触）延迟≈0，专用于消解 U_epi^local。本地自验证的证书不得外推为远端意图的确认（二者是正交证据源）。

**定义 322（遥操作威胁模型 ℰ_relay）** 重放攻击（旧的有效回答重放）、延迟注入/放大（让 STOP 晚到）、意图欺骗（遥操作信号与明确回答解耦）、收敛停滞攻击（维持残差不收缩以拖住系统）、诚实过时操作员（基于滞后 SA 的合理但过时判断）。并入 AIC：ℰ_RELAY = ℰ_FLUID × ℰ_relay。

**定义 323（证书 J_RELAY）** J_RELAY = (J_FLUID, tcc_id, p95_age, fresh_ratio, ρ̂, N_iter, lease_log_hash, rtt_p95, ece_delayed)。Valid ⇔ Valid(J_FLUID) ∧ Valid(C_val) ∧ 租约未过期 ∧ 时效完整性（无重放、无未签名证据）通过。

**定义 324（三级退避）** (a) 远端验证收敛且租约有效 ⇒ λ = λ_floor(U_ale)（resolution bonus，继承 R69）；(b) 远端不可用/不收敛/过期 ⇒ 只做本地验证，λ = λ_floor(U_ale + U_epi^remote + 未消解 U_epi^local)，其中远端部分计入 aleatoric 兜底；(c) 连本地也不可信（FMA 异常）⇒ 全保守 λ = λ_floor(U_ale + U_epi)，等同 R68。安全侧单调不弱于 R69/R68。

**定义 325（延迟意图推断）** 遥操作信号 s_{t:t+H}（摇杆/注视/语音）是操作员意图的**连续、带延迟**观测。用 FMP 的同一条件编码推断意图后验 p(intent | s_{t−τ:t})，并把「显式回答」与「信号推断意图」作为两个正交证据源；二者冲突超出噪声 ⇒ 判为意图欺骗或操作员困惑，不得定案。

**定义 326（严格包含关系）** 记 RELAY 的行为算子在 (τ_rtt=0, p_loss=0, κ=0, 无重放) 下为 R·；则 R· 与 R69 逐指令相同；若进一步禁用一切远端意图（纯本地），则与 R68 相同。故 RELAY ⊃ R69 ⊃ R68，且安全侧永不弱化。

# IP-265 EVR + IP-269 SAL：带年龄的证据与新鲜度加权
def validate_evidence(e, tcc, kappa_hat, now):
    if not verify(e.sig, e.src):                              return 0.0
    if abs((e.t_recv - e.t_obs) - tcc.rtt) > DELTA_TAU:       return 0.0
    age = now - e.t_obs
    if age > freshness_horizon(kappa_hat, EPS):               return 0.0
    return math.exp(-kappa_hat * age)                         # Fresh(a)

def fuse_modes(prior, evidence_list, tcc, kappa_hat, now):
    logb = np.log(prior + 1e-12)
    for e in evidence_list:
        w = validate_evidence(e, tcc, kappa_hat, now)
        if w == 0: continue                                   # 过时 -> 降级为先验
        logb += w * np.log(likelihood(e.val) + 1e-12)
    return softmax(logb)

# IP-266 ETS：按时间尺度切 epistemic
def split_epistemic(U_epi, kappa_hat, tau_rtt, tau_val):
    rem = U_epi * math.exp(-kappa_hat * (tau_rtt + tau_val))
    return rem, U_epi - rem                                   # (U_epi_remote, U_epi_local)

# IP-267 IVL：迭代验证（新鲜残差 + 收缩判据）
def iterative_validate(b0, tcc, budget, kappa_hat, now):
    b, rs, fresh_ok = b0, [], True
    for k in range(budget.N_iter):
        u = pick_discriminative_action(b, tcc)                # 本地快探针优先（延迟≈0）
        z = execute_and_observe_fresh(u)                      # 新鲜本地残差
        e = receive_delayed_evidence(tcc)                     # 可能 None / 过时
        b = update(b, u, z, e, kappa_hat)
        rs.append(entropy(b))
        fresh_ok &= (e is not None and validate_evidence(e, tcc, kappa_hat, now()) > 0)
        if len(rs) >= 2:
            rho = median([rs[i+1] / max(rs[i], 1e-9) for i in range(len(rs)-1)])
            if rho < RHO_MAX and fresh_ok:
                return b, VSC(rho, rs, k+1, fresh_ok, cross_agree=True)
    return b, VSC(rho, rs, budget.N_iter, fresh_ok, cross_agree=False)  # 非收缩

# IP-268 ALA：权威租约状态机
def authority_arbiter(state, intent, val_cert, tcc, now):
    if intent is not None and Valid(intent.evr) and state in (LOCAL_SAFE, LOCAL_VALIDATED):
        state = REMOTE_PROVISIONAL
        lease = IssueLease(intent, ttl=clamp(tcc.rtt + TAU_VAL, tcc.rtt + 1e-3, tau_mode))
    if state == REMOTE_PROVISIONAL and val_cert and val_cert.converged:
        state = REMOTE_CONFIRMED
    if state == REMOTE_CONFIRMED and (now > lease.expiry or not renew(val_cert)):
        state = LOCAL_SAFE                                    # 到期自动回落，傻等即危险
    return state, lease

# IP-274 主闭环（继承 R69，仅替换不确定性处置的时间维）
def RELAY_RAS_round(M, obs, now):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    modes = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(modes, z, M.fmp.mode_head)
    kappa_hat    = M.ets.estimate_kappa(modes, M.vista)       # R67 持续性头
    U_rem, U_loc = M.ets.split_epistemic(U_epi, kappa_hat, M.tcc.rtt, TAU_VAL)
    # 1) 时效折扣后还值钱吗？
    g = M.mint.choose_interaction_eff(modes, o, M.budget, M.tcc, kappa_hat)
    # 2) 远端或本地：只能经迭代验证 + 租约仲裁定案
    if g is not None and g.is_remote:
        b, cert = M.ivl.iterative_validate(modes, M.tcc, M.budget, kappa_hat, now)
        state, lease = M.ala.authority_arbiter(M.state, g.intent, cert, M.tcc, now)
        resolved = cert.converged and state == REMOTE_CONFIRMED
    elif g is not None:                                        # 本地快探针
        b, cert = M.ivl.iterative_validate(modes, FastTCC(), M.budget, kappa_hat, now)
        state, lease = M.ala.authority_arbiter(M.state, None, cert, M.tcc, now)
        resolved = cert.converged
    else:
        cert, state, resolved = None, LOCAL_SAFE, False
    # 3) 三级退避：远端只消解 U_rem，未消解的一律兜底
    if resolved:
        U_floor = U_ale + U_loc
    else:
        U_floor = U_ale + U_epi + U_rem
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if not resolved and M.fma.anomalous(...):
        lam, k = max(lam, 0.8), k_cal_shrink(...)              # (c) 全保守 = R68
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(modes, cert, lam)
    M.vqa_t.submit_async(g, cert, state, lease)                # 参与式审计
    return k, lam, mode, (U_ale, U_rem, U_loc, state)

## 3. 推导

**引理 19（证据时效上界）** 对切换率 κ 的分段常值模式，年龄 a 的证据仍描述当前模式的概率 = e^{−κa}；故其相对信息 ≤ (1 − e^{−κa})·H(M|o)。当 a ≥ τ*(ε)=ln(1/ε)/κ，证据对当前模式的互信息 ≤ ε。系：R69 的交互在 κτ_rtt ≫ 1 时信息增益趋零，此时「问」在信息论上等价于「不问」，必须本地化或保守（遥操作版 Nyquist 条件）。

**引理 20（U_epi 的时间尺度可分性）** 令 U_epi^remote = U_epi·e^{−κ(τ_rtt+τ_val)}，则 U_epi^local = U_epi − U_epi^remote ≥ 0；当 τ_rtt+τ_val → 0 时 U_epi^local → 0（R69 边界）；当 κ(τ_rtt+τ_val) → ∞ 时 U_epi^remote → 0（远端完全不可救，全归本地/aleatoric）。二者对通道的语义不同，不可混同加总（继承 R69 定义 297 的分通道原则）。

**引理 21（迭代验证的几何收敛）** 设每轮新鲜残差给出的更新满足 Dobrushin 收缩系数 γ ∈ (0,1)（观测对模式判别有下界信息），则验证环以速率 ρ = 1−γ 几何收敛：H(b_k) ≤ (1−γ)^k H(b_0)。达到置信 1−δ 所需轮数 N = ⌈ln(δ/H(b_0))/ln(1−γ)⌉。若因模式寿命 < 延迟导致有效信息 γ ≤ 0（残差平台化），序列不收缩，可被 ρ̂ ≥ 1 检测为「不可验证」。

**引理 22（时延下权威切换的驻留稳定性）** 若租约驻留 D ∈ (τ_rtt+τ_val, τ_mode)，且 LOCAL_SAFE 以 R68 安全集为不变集、REMOTE_CONFIRMED 以验证证书为约束，则混合/切换系统在任意切换信号下保持安全集前向不变；又因 D > τ_rtt，人的延迟反馈总针对同一租约区间，排除芝诺式错配与抖振。

**定理 18（RELAY 严格包含 R69 与 R68）** 在 A99–A101（模式分段常值、TCC 已知、验证收缩）下，RELAY 在任意状态 s 的期望风险 ≤ R69 ≤ R68；当 τ_rtt=0、p_loss=0、κ=0 时三者逐指令相同（定义 326）；当远端失效或验证不收敛时，RELAY 逐指令退化为 R69 的保守分支，再退化为 R68。安全侧永不弱化，效率收益只来自「证据确实新鲜且验证确实收敛」的那部分。

**定理 19（时效完整性对时间攻击的防御）** 在 EVR 签名 + 时效校验 + 租约过期自动降级下：重放攻击至多使系统回到「该证据被忽略」的先验状态；延迟注入无法推迟 LOCAL_SAFE 的本地安全包络（继承 R68）；收敛停滞攻击被 ρ̂ ≥ 1 检测后转为保守而非停摆。故时间攻击不降低安全集，只损失效率（且可审计）。

## 6. 本轮最大风险

**一句话**：RELAY-RAS 把全部赌注押在「我们能准确估计模式寿命 κ 与延迟分布」上——一旦 κ̂ 被低估（把过时证据当新鲜），时效折扣会失效，迭代验证会「收敛」到旧世界的固定点，得到一份**自信而错误**的验证证书；反之 κ̂ 被高估则系统永远不敢用远端权威，退化成昂贵而保守的本地循环。

**次级风险与缓解**：
1. **κ̂ 估计偏差** → 用区间而非点估计，并对折扣取悲观下界（safe discount）；
2. **租期与延迟估计失配** → 租期下界取 τ_rtt 的 P99 并留安全裕度，过期即降级，不赌；
3. **假收敛（同时污染残差与延迟证据）** → 要求「新鲜本地残差」与「延迟证据」两源正交，且 ρ̂ 需在两个独立残差流上一致；
4. **远端不可达时性能塌陷** → LOCAL_VALIDATED 快探针 + 本地自验证，保证「没有遥操作也能活」；
5. **意图推断误读** → 显式回答优先于信号推断，二者冲突即不定案（定义 325）。

def validate_evidence(e, tcc, kappa_hat, now):
    if not verify(e.sig, e.src):                          return 0.0
    if abs((e.t_recv - e.t_obs) - tcc.rtt) > DELTA_TAU:   return 0.0

    if age > freshness_horizon(kappa_hat, EPS):           return 0.0

def fuse_modes(prior, evidence_list, tcc, kappa_hat, now):
    logb = np.log(prior + 1e-12)
    for e in evidence_list:
        w = validate_evidence(e, tcc, kappa_hat, now)
        if w == 0: continue                               # 过时 -> 先验
        logb += w * np.log(likelihood(e.val) + 1e-12)
    return softmax(logb)

## 4. 推导

**引理 19（证据时效上界）** 切换率 κ 下，年龄 a 的证据仍描述当前模式的概率 = e^{−κa}，其相对信息 ≤ (1−e^{−κa})·H(M|o)；`a≥ln(1/ε)/κ` 时对当前模式互信息 ≤ ε。系：`κτ_rtt≫1` 时远端交互信息增益趋零——遥操作版 Nyquist 条件。

**引理 20（U_epi 时间尺度可分性）** `U_epi^remote=U_epi·e^{−κ(τ_rtt+τ_val)}`，`U_epi^local=U_epi−U_epi^remote≥0`；τ→0 时 local→0（R69 边界）；κτ→∞ 时 remote→0（远端不可救）。二者分通道处置，不可混同加总。

**引理 21（迭代验证的几何收敛）** 若每轮新鲜残差更新满足 Dobrushin 收缩 γ∈(0,1)，则 `H(b_k)≤(1−γ)^k H(b_0)`，达到置信 1−δ 需 `N=⌈ln(δ/H(b_0))/ln(1−γ)⌉` 轮；若有效信息 γ≤0（模式寿命<延迟、残差平台化），序列不收缩，被 ρ̂≥1 判为不可验证。

**引理 22（时延下权威切换的驻留稳定性）** 驻留 `D∈(τ_rtt+τ_val, τ_mode)` 且 LOCAL_SAFE 以 R68 安全集不变、REMOTE_CONFIRMED 以验证证书为约束 ⇒ 任意切换信号下安全集前向不变；`D>τ_rtt` 保证延迟反馈针对同一租约区间，排除芝诺错配与抖振。

**定理 18（RELAY 严格包含 R69 与 R68）** A99–A101 下，RELAY 任意状态期望风险 ≤ R69 ≤ R68；(τ=0,p_loss=0,κ=0) 时逐指令相同；远端失效/不收敛时逐指令退化为 R69 保守分支，再退化为 R68。安全不让步，收益只来自「确实新鲜且确实收敛」的部分。

**定理 19（时效完整性的防御）** EVR 签名 + 时效校验 + 租约过期降级下：重放至多使系统回到先验；延迟注入无法推迟 LOCAL_SAFE 本地安全包络；收敛停滞被 ρ̂≥1 检测后转保守而非停摆。时间攻击不降安全集，只损效率且可审计。

## 7. 本轮最大风险

**一句话**：RELAY-RAS 把全部赌注押在「我们能准确估计模式寿命 κ 与延迟分布」上——一旦 κ̂ 被低估（把过时证据当新鲜），时效折扣会失效，迭代验证会「收敛」到旧世界的固定点，得到一份**自信而错误**的验证证书；反之 κ̂ 被高估则系统永远不敢用远端权威，退化成昂贵而保守的本地循环。

**次级风险与缓解**：κ̂ 偏差（区间估计 + 悲观下界折扣）；租期/延迟失配（取 P99 留裕度、过期即降级）；假收敛（本地残差与延迟证据两源正交、双残差流一致）；远端不可达塌陷（LOCAL_VALIDATED 快探针 + 本地自验证）；意图误读（显式回答优先，冲突即不定案）。
