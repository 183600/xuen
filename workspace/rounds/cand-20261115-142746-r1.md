# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；本轮灵感：「最小可行产品」×「云边协同」）

> R69 把不确定性拆成 aleatoric / epistemic，并用「流匹配多模态策略 + 主动交互」在**单回合内**消解 epistemic。但它留下三个未被承认的窟窿：
> 1. **没有记忆**——R68 的「实时零学习写」不变式使边缘永远不能把「这次问出来的答案」沉淀成下次的先验。同一个岔口，明天再问一遍；歧义被消解，却从未被**偿还**。这是《土拨鼠之日》式的学习。
> 2. **标定者是一个未解释的神谕**——模态权重 ECE、问句接地、FMP 条件编码都假设离线已校准，却没人回答「谁校准、如何送到边缘、边缘凭什么信」。
> 3. **复杂度无纪律地膨胀**——FMP/AUD/MINT/CIA/FMA 每加一层就多一个必须独立信任的黑箱；R69 自陈全部收益押在「模态分布可信」上，而这条前提正是一个没付过租金的黑箱。
>
> 本轮两个灵感正对症：
> - **最小可行产品（MVP）**给出**范围纪律**：先交付一条端到端可用的最薄切片（安全内核），能力是可选增量；每个增量必须证明自己值回票价，否则删掉。不要最小化不确定性，要最小化**改变决策所需的知识**。
> - **云边协同**给出**成长基质**：边缘不能学，但云能学；把单回合消解不了的 epistemic **延后（defer）**到云，用机队数据消解，再以「已认证的能力胶囊」原子地送回边缘。学习不发生在实时环路里，而发生在两次部署之间的「认证蜕变」。
>
> 核心命题：**epistemic 不确定性按「谁能消解它」分成三段——now（交互）、defer（云端学习）、arch（边缘容量，只能靠新能力）——并配一本「认知债务账本」：延后不是遗忘，而是记账；安全在每一瞬时由 R68 兜底，知识在长时程由云边协同偿还。** 命名 **SEED-RAS**（Safety-certified Epistemic-deferred Edge Deployment）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**此刻最小够用是什么，我缺失的知识该托付给谁、何时收回**」——安全是瞬时的，但知识是长时程的；能一直安全而什么都不学，是一种新的失败。

## 0. 直觉与动机

**灵感 1（MVP → 最小可行自我：先有安全地基，再谈能力）**
直觉：MVP 的第一性原理不是「功能少」，而是**端到端可用 + 可验证地增长**。照此，边缘首先要能「零技能也存在」：一个冻结、只读、永远保守的最小安全内核 BASE（R68 的 λ_floor 路径）。BASE 就是产品的「walking skeleton」——安全但低效。FMP、MINT、CIA 都是**可选增量**，只在各自守卫区域内接管，且永不拓宽安全包络。这把 R69 的「层层叠黑箱」变成「能力租约」：任何技能必须用可测的边际价值支付其复杂度租金，付不起就删。R69 的最大风险（模态不可信）因此被降级为「某个技能没通过租金审查」，而不是「整个闭环押在一个黑箱上」。

**灵感 2（云边协同 → 缺失的学习能力在别处）**
直觉：R68 禁止实时学习写入是对的（安全），但它把「学习」整个禁掉了，而不是**分层**：实时层不许学，不代表离线层不许学。云边协同给出正确分工——边缘守毫秒级安全，云守分钟~天级的统计与校准。于是 R69 的「未消解 epistemic」不必永远当作 aleatoric 压死，而可以**延后**：边缘把「我在这里分不清、问了也问不出」压缩成一条带出处的账目，云端聚合机队数据把它解掉，产出一个新的能力胶囊，经认证后原子地送回。关键姿态：**延后 ≠ 遗忘**；延后要记账，账要还。

**灵感 3（合流 → epistemic 三分，R69 是「零增长」边界）**
直觉：R69 只按「能不能在回合内问出来」二分。真实上还有第三类：问不出来，但**换更多数据/更大模型就能知道**（defer），以及**再怎么加数据也没用、必须换观察方式或加新能力**（arch，压缩导致的认知缺口）。三分之后，三类各自有专属「消解器」：交互 / 云端数据 / 新 MVS。并且 R69 恰好是「技能集为空、账本为空、断网」的边界——安全侧位不变，效率侧获得长时程的**认知还债**。这继承 R69 的理论姿态：新层必须是旧层的严格泛化。

**灵感 4（MVP 的决策观 → 从「减少熵」到「减少遗憾」）**
直觉：MVP 最深刻的一句是「不要做不会改变结果的功能」。R69 的 VoI 是**信念中心**的：最大化模态熵的下降。但高熵不等于值得问——若两个模态导出**同一个动作**（绕左/绕右都撞不到、接住/避让都安全），熵再大，问了也不改变决策，纯属打扰。决策论的正解是**决策中心的 VoI**：期望价值 of information（EVSI/EVPI），只买「能改变 argmax 的信息」。这就是「最小可行提问」：问最少的话，把**决策**而不是**信念**推到确定。它同时压低交互疲劳与 R69 的「追问幻影」风险。

**灵感 5（云边是新攻击面 → 认知权威会中心化，也会被投毒）**
直觉：一旦知识从云流向边缘，云就成了**单点认知故障源**。被攻陷的边缘可以投毒机队后验，再以「已认证」的名义把错误铺满全网——R69 的「被证实的错误」从单机升级为**供应链接管**。更隐蔽的是：账本可能变成**只写内存**（只记录、永不偿还），系统瞬时永远安全、长期一无所知——「最小可行产品」退化成「最小永久产品」。所以本轮必须同时交付：认证准入（单调安全 + 灰度 + 回滚）、机队鲁棒聚合、认知破产保护、以及能审计「债务是否真的被还」的审计器。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（SEED-RAS 总览）** SEED-RAS = (BASE, MVS*, ETD, DLED, EVSI-MINT, CIE, CAP, FLEET-AGG, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **地基不可变 + 守卫精化**：BASE 冻结只读，任何技能只在守卫区 `φ_i(o)=1` 内接管，且其动作必须落在 BASE 的认证安全集内（`π_i(o) ∈ SafeSet_BASE(o)`），故组合**永不拓宽**安全包络；
(iii) **成长只走认证准入**：一切能力变更只能在静默点（无在途动作）经 CAP 原子换装，带签名、可复现、可回滚；
(iv) **认知偿付能力**：在高 defer 上下文运营需要历史偿付记录；账本必须被偿还，债务超限触发保守升级（不是永久压死，而是「不许再花没还的信用」）。

**定义 311（边缘装配与守卫组合）**
`π_edge(o) = π_{i*(o)}(o)`，其中 `i*(o)` 为所有 `φ_i(o)=1` 且证书有效的技能里优先级最高者，否则回 `BASE.act(o)`。附加包络包含约束：`∀o, φ_i(o) ⇒ π_i(o) ∈ SafeSet_BASE(o)`。于是 `π_edge` 是 BASE 的**安全精化**：支撑集外永远等于 BASE，支撑集内也绝不越出 BASE 的安全包络。

**定义 312（最小可行技能 MVS 胶囊）** `c = (φ, π, K, cert, prov)`：`φ: O→{0,1}` 为守卫（仅在已验证支撑集上为真）；`π` 为残差策略；`K` 为安全契约（前后条件 + 风险上界 + 失效模式）；`cert` 为证书；`prov` 为出处（数据摘要、训练/编译哈希、签名者、红队报告）。MVS 是云→边传输的**最小单位**，不是整模型。

**定义 313（认知时间尺度三分）** 设信息集 `I_now ⊂ I_cloud`。给定交互预算内最优查询 `g*`：
- `U_epi^now(o) = H(M|o) − E_{y~p(·|g*,o)}[H(M|o,y)]`（回合内可消解，消解器=交互）；
- `U_epi^defer(o) = E[H(M|o, I_now^+)]_edge − E[H(M|o)]_cloud`（同一观测下、边缘缺数据/参数造成的差，消解器=云端学习）；
- `U_epi^arch(o) = ` 由边缘观察/表征瓶颈造成的部分，用 CIE（定义 316）估计（消解器=新 MVS/新观察）；
- 一致性：`U_epi(o) ≈ U_epi^now + U_epi^defer + U_epi^arch`（估计误差内）。三者**语义不同、消解器不同、时间尺度不同**，绝不简单相加为「该慢多少」。

**定义 314（延后账本与认知债务 DLED）** 账本 `L = {(sig(o), sig(M), U_defer, g_tried, t)}`（隐私压缩后的充分统计，非原始数据）。认知债务 `D(t) = Σ_{(e,t_e)∈L, 未偿还} e.U_defer`。偿还：云端解掉某条目并让其 MVS 经 CAP 准入后，该条目销账。偿付率 `ρ(t)=resolved(t)/added(t)`。**偿付能力约束**：仅当 `ρ ≥ λ_min` 且 `D(t) ≤ D_max` 时才允许在高 defer 上下文运营；否则退到 BASE 保守子集。操作含义见引理 21。

**定义 315（决策充分 VoI 与最小可行提问）** 值函数 `Q(a,ω)`，`V(o)=max_a E_ω[Q(a,ω)|o]`。信息动作 `g` 的期望价值：
`EVSI(g) = E_{y~p(·|g,o)}[ max_a E_ω[Q(a,ω)|o,y] ] − V(o)`。
最小可行提问 `g* = argmax_g [EVSI(g) − c(g)]`，s.t. 安全、预算、且**决策相关性**（存在 `y` 使 argmax 改变）。若无 `g` 满足，`g*=∅`（不打扰）。对比 R69 的熵型 `VoI(g)=H(M|o)−E[H(M|o,y)]`：后者是信念中心，前者是决策中心（见引理 19）。

**定义 316（压缩诱发的认知缺口 CIE）** `Δ_ce(o) = D(p_e(ξ|o) ‖ p_c(ξ|o))`，可用边缘策略与「云端蒸馏影子头」的分布散度（KL/TV）或采样不一致率估计；它度量边缘瓶颈相对云端**多出的**歧义（引理 20）。**两用通道**：
(a) `Δ_ce` 高且 `U_epi` 高 ⇒ 边缘缺知识 → 延后/申请新 MVS；
(b) `Δ_ce` 高但边缘自信 ⇒ 可能边缘错，也可能云过时 → CAP 必须仲裁，运行时作**绊线**；
(c) `Δ_ce` 低 ⇒ 一致，允许影子更新。这是 R69 的 FMA（标定不可吸收）在**架构侧**的镜像。

**定义 317（认证准入协议 CAP）** 候选技能 `c` 被准入当且仅当：
(a) `c.signed ∧ c.reproducible`（出处与可复现构建）；
(b) **不劣化**：`Risk(c, D_cert) ≤ Risk(current, D_cert)` 且 `Value(c, D_cert) ≥ Value(current, D_cert) + δ`；
(c) **新奇门**：`support(φ) ⊆ support(D_cert)`，支撑集外一律回 BASE（构造性保守）；
(d) **灰度 + 回滚**：`canary=ε` 起步，命中 CIE/审计告警即自动回滚；
(e) **不动地基**：BASE 哈希不变，换装只在静默点。
失败任一条 ⇒ 拒绝，账本条目保持未偿还。

**定义 318（单调准入契约）** 定义精化偏序 `c_old ⊑ c_new`：在 `D_cert` 上风险不升、价值不降。CAP 只准入精化；BASE 是所有技能的底（`BASE ⊑ c`）。部署序列是此偏序上的一条链 ⇒ 认证分布上安全单调。

**定义 319（复杂度租金）** 技能 `c` 的租金余量 `μ(c)=ΔV(c | 当前技能集, D_replay) − κ·complexity(c)`。保留当且仅当 `μ ≥ δ` 且安全增量非负；`μ<0` 则剪枝。复杂度预算由**已证明的价值**支付，而非由「架构完整感」支付。

**定义 320（机队聚合与鲁棒性）** `n` 个边缘上传，至多 `f` 个 Byzantine；聚合器 `A` 为 `f`-鲁棒，若 `TV(A(entries), A(clean)) ≤ ε(f/n)`。采用截尾均值/坐标中位数/Krum 类；每边出处与准入贡献上限（单边不得把某技能决策边界推动超过 `δ`）；必要时加差分隐私限制反演。

**定义 321（云边威胁模型 ℰ_CE）** `ℰ_CE = ℰ_FLUID × {更新供应链投毒、被攻陷边缘的数据投毒、旧版本重放、脑裂/回滚攻击、隐私反演}`。并入 AIC：`ℰ_SEED = ℰ_CE`。

**定义 322（版本偏斜 / 脑裂 / 离线自治）** 每边维护版本向量；断网时运行**最后认证版本**（安全继承）；更新只在静默点；重连后若云版本更新则验签换装，若出现两个「已认证」冲突版本则按仲裁策略（法定数/优先级）择一；**永不 mid-episode 换装**，保持控制连续。

**定义 323（账本即路线图）** 云端 backlog 按债务加权需求排序：
`priority(topic) = Σ_{e:topic} U_defer(e)·freq(e)·criticality(e) / cost(MVS)`。
只造「偿还最多债务的最小技能」——这是把 MVP 的「先做最小价值切片」变成**产品化学习循环**：账本不是日志，是待办。

**定义 324（证书 J_SEED）** `J_SEED = (J_FLUID, mvs_registry_digest, ledger_digest, cie_stats, update_provenance, deploy_version, repayment_rate, base_kernel_hash)`。Valid ⇔ `Valid(J_FLUID) ∧ 出处有效 ∧ repayment_rate ≥ λ_min ∧ 未偿还债务 ≤ D_max ∧ BASE 哈希不变`。

**定义 325（参与式审计 VQAuditor-CE）** 审计新增：每次提问是否 `EVSI>0`（无必要提问）、账本条目是否被偿还（非只写内存）、更新是否有有效出处且过不劣化、CIE 告警是否被处置、守卫支撑是否被越界。

**定义 326（对 R68/R69 的严格包含）** SEED 在「技能集为空 ∧ 账本为空 ∧ 断网」时**逐指令等于 FLUID-RAS**；在「禁用交互」时逐指令等于 R68。故 `R68 ⊂ R69 ⊂ R70` 是三条边界；安全地基继承，效率/知识在边界之内增长。

```python
# IP-264 边缘最小可行安全内核：冻结、只读、零技能也可用（安全但低效）
class MinViableKernel:
    def act(self, o):
        # 仅 R68/R69 最保守路径：无交互、无技能、λ_floor
        return self.r69.fluid_round(o, allow_interaction=False, skills=[])

# IP-265 技能胶囊 + 守卫组合（支撑集外永远回 BASE）
def compose(o, base, registry):
    for c in registry.by_priority():
        if c.guard(o) and c.cert.valid():
            assert c.policy(o) in safe_set(base, o)   # 包络包含：不得拓宽
            return c.policy(o)
    return base.act(o)

# IP-266 认知时间尺度三分
def epistemic_split(U_epi, o, edge, cloud_shadow, budget):
    U_now = decision_sufficient_residual(o, budget)        # 交互可消解
    U_def = max(0.0, U_now - cloud_shadow.residual(o))     # 云端数据可消解
    U_arch = cie_gap(edge, cloud_shadow, o)                # 架构/压缩，需新能力
    return U_now, U_def, U_arch

# IP-268 决策充分交互：EVSI 取代熵，只买「能改变决策」的信息
def mvp_query(o, modes, budget):
    V, best = max_action_value(o), None
    for g in query_candidates(modes):
        if not budget.allow(g) or not safe(g):        continue
        if not decision_relevant(o, g, modes):         continue   # 答案不改变 argmax → 不问
        evsi = expected_best_value(o, g) - V
        if evsi <= cost(g):                            continue
        if best is None or evsi - cost(g) > best.score:
            best = Query(g, evsi - cost(g))
    return best.g if best else None                    # None ⇒ 不打扰

# IP-269 CIE：架构性认知差（两用：申请知识 / 否决更新）
def cie_gap(edge, cloud_shadow, o):
    return divergence(edge.policy_dist(o), cloud_shadow.policy_dist(o))

# IP-270 CAP：认证准入（不劣化 + 新奇门 + 灰度 + 回滚 + 不动地基）
def certified_admit(cand, edge, replay):
    if not (cand.signed() and cand.reproducible()):        return REJECT
    if not no_worse(cand, edge.current, replay.D_cert):    return REJECT
    if not cand.guard.support <= replay.support:           return REJECT  # 支撑集外回 BASE
    if cand.base_hash != edge.base.hash():                 return REJECT
    edge.stage(cand, canary=1e-2, rollback_on=cie_or_audit_alarm())
    return ADMIT

# IP-277 边缘 tick（实时、零学习写、静默点才换装）
def SEED_edge_tick(M, o):
    U_ale, U_epi, modes = M.r69.decompose(o)               # R69 一次前向
    U_now, U_def, U_arch = M.etd.split(U_epi, o, M.edge, M.shadow, M.budget)
    g = M.mint.mvp_query(o, modes, M.budget) if U_now > TAU else None
    if g is not None:
        U_now = M.cia.execute_residual(g, modes)           # 交互后残差（可能仍>0）
    # 未消解的三段一律按 R68 兜底：瞬时安全永不让步
    lam = lam_floor(U_ale + U_now + U_def + U_arch)
    # 技能组合（仅在守卫区接管，包络不拓宽）
    act = compose(o, M.base, M.registry)
    # 记账：可延后部分异步入账（压缩充分统计 + 出处）
    if U_def > TAU_LEDGER:
        M.ledger.append(compress(o, U_def, g), async_=True)
    # 认知破产保护：债务过高 → 只许在 BASE 保守子集运营
    if M.ledger.debt() > D_max or M.ledger.repay_rate() < LAMBDA_MIN:
        act = M.base.conservative(act)
    M.audit_ce.submit_async(o, g, U_now, U_def, U_arch, act)
    return act

# IP-277 云端周期（离线、可学习、只产出候选，不直接下发）
def SEED_cloud_cycle(fleet, ledger, backlog):
    entries = ledger.pull()                                # 各边压缩后的债务摘要
    post    = robust_aggregate(entries, f_byzantine)       # Byzantine-robust（引理 23）
    topics  = backlog.prioritize(entries)                  # 账本即路线图
    for topic in topics.topk(K):
        cand = train_min_skill(topic, post, support=topic.support)
        if rent_positive(cand, fleet.replay):              # 复杂度租金（定义 319）
            publish_signed(cand)                           # 交给 CAP 灰度准入
    audit_ledger_repayment(ledger)                         # 只写内存 → 告警
```

## 3. 推导

**引理 19（决策充分性：EVSI 严格优于熵型 VoI）**
设 `Q` 有界、`sup|Q| = L_Q`。任一信息动作 `g`：(a) `EVSI(g) ≤ EVPI(o)`，且 `EVSI(g) ≤ (L_Q/2)·√(2 I(ω; y_g|o))`（Pinsker 型界）——决策价值受信息量控制；(b) 反之不成立：存在「平坦价值歧义」使 `H(M|o)` 很高但 `EVSI=0`（两模态导出同一动作），也存在「熵增很小但价值极不对称」的情形使 `EVSI>0` 而熵型 VoI 近零。**系**：R69 的 MINT 以熵为目标，既可能把预算浪费在改变不了决策的歧义上（追问幻影的决策版），也可能漏掉真正值钱的判别。R70 改用 EVSI 后，「最小可行提问」是对交互预算的**决策论正确**用法。

**引理 20（边缘瓶颈的认知下界）**
设边缘经一个（随机）压缩通道 `C` 观察世界，`o_e=C(o)`。由数据处理不等式 `I(ω; o_e) ≤ I(ω; o)`，故期望后验熵 `H(ω|o_e) ≥ H(ω|o)`，且多出的歧义**恰等于通道丢弃的互信息**：`H(ω|o_e) − H(ω|o) = I(ω;o) − I(ω;o_e) ≥ 0`。CIE 的散度 `Δ_ce` 是该差的一个一致估计量（在 `C` 可识别时）。**系**：`Δ_ce` 能把「缺数据（defer，可用云端先验补）」与「缺容量/观察（arch，只能换技能）」分开——前者是参数更新，后者是通道改变；这正是 R69 无法区分的。

**引理 21（认知债务的偿付动力学）**
设每轮新增债务 `a_t`，每个云周期以概率 `≥1−ε` 偿还比例 `ρ_c`。则 `E[D_{t+1}|D_t] ≤ (1−ρ_c(1−ε))D_t + a_t`。当 `ρ_c(1−ε) > a_t/D_t` 时债务是上鞅、有界；当连通率跌破 `λ_min` 时债务线性增长 ⇒ **认知破产**必然发生，可在 `D(t)>D_max` 时被检出并降级。**系**：`D(t)` 是一个可观测的「知识健康度」指标；「一直安全但账本只增不减」是可被形式化识别的新型故障，而非道德劝诫。

**引理 22（CAP 在认证分布上的安全单调）**
若每次准入满足不劣化（定义 317-b）与守卫包络包含（定义 311），且换装只在静默点，则在 `D_cert` 上 `Risk(π_{n+1}) ≤ Risk(π_n)` 且 `Value(π_{n+1}) ≥ Value(π_n)+δ`。故认证分布上风险不升、价值不降。**注意**：该保证**仅**对 `D_cert` 成立；分布漂移时失效（见定理 20 与本轮风险）。

**引理 23（机队投毒上界）**
若聚合器为 `f`-鲁棒且 Byzantine 边 `<f`，则 `TV(post_byz, post_clean) ≤ ε(f/n)`；单边贡献上限 `δ` 进一步把单点影响限制在 `δ`。**系**：相关投毒（多个被同时攻陷且分布一致）会破坏 `f`-鲁棒假设——需要出处多样性/证明（attestation）与独立的红队重放，否则「认证」只是把单机攻击放大成全网点攻击。

**定理 18（SEED 严格包含 R69/R68）**
在「技能集为空 ∧ 账本为空 ∧ 断网」时，SEED 的边缘 tick 逐指令等于 FLUID-RAS；禁用交互时逐指令等于 R68。且在连通率 `≥λ_min` 与 `f`-鲁棒聚合下，`E[D(t)]` 有界且非增（引理 21）。因此 R69 是 R70 的「零增长边界」：安全侧不让步，效率侧获得长时程的**认知还债**。

**定理 19（部署安全与无突变）**
CAP + 静默点原子换装 + BASE 不可变 + 回滚 ⇒ (a) 认证分布上风险不升（引理 22）；(b) 任何更新都不能拓宽安全包络（守卫精化）；(c) mid-episode 禁止换装 ⇒ 控制连续、无突变（继承并强化 R69 定理 17）；(d) 回滚把系统带回某个先前已认证状态，故回滚也是安全保持的。

**定理 20（MVP 租金上界与反膨胀）**
在边际价值递减（近子模）假设下，按租金余量贪心保留技能集，所得价值 ≥ `(1−1/e)` 最优子集；且保留技能数 `≤ V_max/δ`。故复杂度由已证明价值上界约束，**不会无界膨胀**。**边界**：租金是在 `D_replay` 上测的；若 replay 不代表性，租金门也会被「刷分」——这正是审计器与 CIE 绊线要交叉验证的原因。

## 6. 本轮最大风险

**一句话**：SEED-RAS 把「学习」整体外包给云，于是**云成为唯一的认知故障源**，而 CAP 的「不劣化」只在**昨天的认证分布**上成立——当分布漂移、云被投毒、或连通长期不足使账本只写不还时，边缘会「每一瞬时都安全，却长期一无所知甚至吸收错误知识」：MVP 退化为「最小永久产品」，安全变成一种**没有认识论的安全**。

**次级风险与缓解**：
1. **认知债务静默累积**（断网/云故障）→ 定义 314 偿付能力约束 + 引理 21 破产检测 + 超限降级；
2. **机队投毒与更新供应链攻击** → f-鲁棒聚合 + 出处/证明 + 单边贡献上限 + 红队重放 + CIE 运行时绊线；
3. **认证分布 ≠ 部署分布** → 新奇门 + 支撑集外回 BASE + 周期再认证 + 漂移检出即回滚；
4. **过度延后（边缘退化为瘦客户端）** → defer 预算 + 本地最小技能 + 偿付率约束；
5. **租金门可被刷分** → 独立审计 + held-out replay + 与 CIE/审计交叉验证；
6. **隐私反演** → 只传充分统计 + 差分隐私 + 本地聚合。

**定义 317–318（CAP 与单调契约）** 准入 = 签名 ∧ 可复现 ∧ 不劣化（`Risk ≤` 且 `Value ≥ +δ` on `D_cert`）∧ 新奇门（`support(φ)⊆support(D_cert)`）∧ 灰度/回滚 ∧ 地基哈希不变。精化偏序 `c_old⊑c_new` 只许风险不升/价值不降；`BASE` 是底。

**定义 319–320（租金与机队鲁棒）** `μ(c)=ΔV−κ·complexity`，`μ≥δ` 且安全非负才保留；`n` 边中 `<f` Byzantine，聚合器 `f`-鲁棒使 `TV ≤ ε(f/n)`，单边贡献上限 `δ`。

**定义 321–322（威胁与版本）** `ℰ_CE = ℰ_FLUID × {更新供应链投毒、被攻陷边缘、旧版重放、脑裂/回滚攻击、隐私反演}`；版本向量 + 离线自治（跑最后认证版）+ 静默点换装 + 冲突仲裁 + 永不 mid-episode 换装。

**定义 323–326（路线图/证书/审计/包含）** 账本即路线图：`priority=Σ U_defer·freq·criticality/cost`，只造偿还最多债务的最小技能；`J_SEED` 并入注册表/账本/CIE/出处/偿付率/地基哈希；`VQAuditor-CE` 审提问必要性、债务偿还、更新出处与不劣化、CIE 处置、守卫越界；空技能/空账本/断网时逐指令等于 FLUID-RAS，禁交互时等于 R68。

```python
class MinViableKernel:

def compose(o, base, registry):
    for c in registry.by_priority():
        if c.guard(o) and c.cert.valid():
            assert c.policy(o) in safe_set(base, o)
            return c.policy(o)
    return base.act(o)

# IP-266 认知时间尺度三分
def epistemic_split(U_epi, o, edge, cloud_shadow, budget):
    U_now = decision_sufficient_residual(o, budget)
    U_def = max(0.0, U_now - cloud_shadow.residual(o))
    U_arch = cie_gap(edge, cloud_shadow, o)
    return U_now, U_def, U_arch

# IP-268 最小可行提问：EVSI 取代熵
def mvp_query(o, modes, budget):
    V, best = max_action_value(o), None
    for g in query_candidates(modes):
        if not budget.allow(g) or not safe(g):      continue
        if not decision_relevant(o, g, modes):       continue   # 不改变 argmax → 不问
        evsi = expected_best_value(o, g) - V
        if evsi <= cost(g):                          continue
        if best is None or evsi - cost(g) > best.score:
            best = Query(g, evsi - cost(g))
    return best.g if best else None

# IP-269 CIE 架构性认知差（申请知识 / 否决更新）
def cie_gap(edge, cloud_shadow, o):
    return divergence(edge.policy_dist(o), cloud_shadow.policy_dist(o))

# IP-270 CAP 认证准入
def certified_admit(cand, edge, replay):
    if not (cand.signed() and cand.reproducible()):      return REJECT
    if not no_worse(cand, edge.current, replay.D_cert):  return REJECT
    if not cand.guard.support <= replay.support:         return REJECT
    if cand.base_hash != edge.base.hash():               return REJECT
    edge.stage(cand, canary=1e-2, rollback_on=cie_or_audit_alarm())
    return ADMIT

# IP-278 边缘 tick（实时零写，静默点换装）
def SEED_edge_tick(M, o):

    U_now, U_def, U_arch = M.etd.split(U_epi, o, M.edge, M.shadow, M.budget)
    g = M.mint.mvp_query(o, modes, M.budget) if U_now > TAU else None
    if g is not None:
        U_now = M.cia.execute_residual(g, modes)
    lam = lam_floor(U_ale + U_now + U_def + U_arch)   # 未消解一律 R68 兜底
    act = compose(o, M.base, M.registry)
    if U_def > TAU_LEDGER:
        M.ledger.append(compress(o, U_def, g), async_=True)
    if M.ledger.debt() > D_max or M.ledger.repay_rate() < LAMBDA_MIN:
        act = M.base.conservative(act)                 # 认知破产保护
    M.audit_ce.submit_async(o, g, U_now, U_def, U_arch, act)
    return act
```

## 4. 推导

**引理 19（EVSI 严格优于熵型 VoI）** `sup|Q|=L_Q` 时，`EVSI(g) ≤ EVPI(o)` 且 `EVSI(g) ≤ (L_Q/2)√(2I(ω;y_g|o))`（Pinsker 型界）；反之不成立：存在「平坦价值歧义」使 `H(M|o)` 高但 `EVSI=0`（两模态导出同一动作），也存在熵增极小但价值极不对称使 `EVSI>0` 的情形。系：R69 的熵型 MINT 既可能浪费预算追问不改变决策的幻影，也可能漏掉真正值钱的判别；「最小可行提问」是对预算的决策论正确用法。

**引理 20（边缘瓶颈的认知下界）** 设边缘经压缩通道 `C` 观察，`o_e=C(o)`。由数据处理不等式 `I(ω;o_e) ≤ I(ω;o)`，故 `H(ω|o_e) ≥ H(ω|o)`，多出的歧义恰等于通道丢弃的互信息：`H(ω|o_e)−H(ω|o)=I(ω;o)−I(ω;o_e) ≥ 0`，`Δ_ce` 是其一致估计。系：`Δ_ce` 能把「缺数据（defer，云端先验可补）」与「缺容量/观察（arch，只能换技能）」分开——R69 无法区分。

**引理 21（债务偿付动力学）** 每轮新增 `a_t`，每云周期以概率 `≥1−ε` 偿还比例 `ρ_c`，则 `E[D_{t+1}|D_t] ≤ (1−ρ_c(1−ε))D_t+a_t`。当 `ρ_c(1−ε) > a_t/D_t` 时债务上鞅、有界；连通率跌破 `λ_min` 时线性增长 ⇒ 认知破产可在 `D(t)>D_max` 被检出并降级。系：「一直安全但账本只增不减」是可被形式化识别的**新型故障**。

**引理 22（CAP 认证分布上的安全单调）** 若准入满足不劣化（定义 317-b）与守卫包络包含（定义 311）且只在静默点换装，则 `D_cert` 上 `Risk(π_{n+1}) ≤ Risk(π_n)`、`Value(π_{n+1}) ≥ Value(π_n)+δ`。注意：**仅**对 `D_cert` 成立，分布漂移时失效。

**引理 23（机队投毒上界）** `f`-鲁棒聚合且 Byzantine 边 `<f` 时 `TV(post_byz,post_clean) ≤ ε(f/n)`；单边贡献上限 `δ` 进一步限制单点影响。系：相关投毒破坏 `f`-鲁棒假设，需出处多样性/证明与独立红队重放，否则「认证」会把单机攻击放大成全网点攻击。

**定理 18（SEED 严格包含 R69/R68）** 空技能 ∧ 空账本 ∧ 断网时边缘 tick 逐指令等于 FLUID-RAS；禁交互时逐指令等于 R68；连通率 `≥λ_min` 且 `f`-鲁棒聚合下 `E[D(t)]` 有界非增。故 R69 是 R70 的「零增长边界」，安全不让步、效率侧获得认知还债。

**定理 19（部署安全与无突变）** CAP + 静默点原子换装 + BASE 不可变 + 回滚 ⇒ 认证分布上风险不升；任何更新不拓宽安全包络（守卫精化）；禁止 mid-episode 换装 ⇒ 控制连续、无突变（强化 R69 定理 17）；回滚回到先前已认证态，故亦安全保持。

**定理 20（MVP 租金上界与反膨胀）** 边际价值递减（近子模）下，按租金余量贪心保留集价值 ≥ `(1−1/e)` 最优；保留技能数 `≤ V_max/δ`，复杂度受已证明价值上界约束。边界：租金在 `D_replay` 上测，replay 不代表性时租金门会被刷分——需审计器与 CIE 绊线交叉验证。

## 7. 本轮最大风险

**一句话**：SEED-RAS 把「学习」整体外包给云，于是**云成为唯一的认知故障源**，而 CAP 的「不劣化」只在**昨天的认证分布**上成立——当分布漂移、云被投毒、或连通长期不足使账本只写不还时，边缘会「每一瞬时都安全，却长期一无所知甚至吸收错误知识」：MVP 退化为「最小永久产品」，安全变成一种**没有认识论的安全**。

**次级风险与缓解**：认知债务静默累积（定义 314 偿付能力约束 + 引理 21 破产检测 + 超限降级）；机队投毒/更新供应链（f-鲁棒 + 出处/证明 + 单边上限 + 红队重放 + CIE 绊线）；认证分布≠部署分布（新奇门 + 支撑集外回 BASE + 周期再认证 + 漂移回滚）；过度延后瘦客户端化（defer 预算 + 本地最小技能 + 偿付率）；租金门刷分（独立审计 + held-out + CIE 交叉验证）；隐私反演（充分统计 + 差分隐私 + 本地聚合）。
