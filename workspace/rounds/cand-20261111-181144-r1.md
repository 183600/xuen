# 第 56 轮（承接第 55 轮语义-接触层；灵感循环第 2 轮；本轮灵感：「真机评测」×「动态避障」）

> 第 55 轮把技能的可行性下探到“语义-接触是否可信、全身耦合下是否可行”。本轮再往下追问一层：**这些证书本身是在仿真里签发的，真实机器人凭什么相信它？当障碍会动时，一张静态安全地图还能撑多久？** 核心矛盾：**H24**：真机评测不是证书的终点，而是证书的协变量——sim-to-real gap 会系统性平移安全边界（执行器饱和、延迟、打滑、材质摩擦），而此前所有证书都把仿真当成了真实，造成了“证书在仿真里成立”被误读成“部署后成立”；**H25**：动态避障让安全集时变，静态生存核 `K(Σ)` 只在障碍预测地平线内 sound；“当前可行”不等于“到达前仍可行”，证书必须带时间戳与有效期，过期即失效。

## 0. 直觉与动机

**灵感 1（真机评测 → 证书的“现实会签”，而非最后一道考试）**
直觉：以往真机评测是“跑一遍看成功率”，是终点。但 sim-to-real gap 不是通过/不通过，而是一个**可测量的残差分布** `δ_r`（跟踪误差、接触力、延迟、打滑）。应把每个真机 episode 变成证书的会签：证书必须携带 `δ_r` 及其置信上界与真实证据；真机数据的作用不是打分，而是持续收缩或暴露仿真证书的不可信区域。于是“真机评测”从一个 benchmark 动词，变成 **证书维护算子**。

**灵感 2（动态避障 → 生存核长在时间轴上，而不是一张静态地图）**
直觉：第 55 轮的 `K(Σ)` 是静态的；动态障碍意味着“此刻安全”的位姿下一时刻可能被占据。安全集应写成 `K_t(Σ_t, O_{t:t+H})`，并且 `x_t∈K_t` 必须递归地要求存在一段动作使 `x_{t+1}∈K_{t+1}`。避障不是外挂规划器，而是 **生存核的时间维扩展**；动态障碍把“安全”从状态属性变成时空属性。

**灵感 3（证书有效期 → 证书会过期，过期即失效）**
直觉：动态环境里没有“一次认证、永久部署”。证书必须带 **TTL** `τ_val`，由三件事取最小：障碍预测不确定度增长到阈值的时间、真机-仿真漂移累积到预算的时间、语义需要重检的周期。部署条件从“证书成立”升级为“**证书新鲜度 ≥ 所需避障前置时间**”。这把安全从“有没有证”变成“证还新不新”。

**灵感 4（延迟即约束 → 避障裕度必须含反应时间）**
直觉：动态避障失败往往不是没看见，而是“看见 → 计算 → 执行”这段 `τ_react` 里障碍已经越界。把感知-计算-执行延迟显式塞进动作可达集：用 `τ_react` 后的可达集与障碍预测占据集求距离，再扣除制动距离，得到 `m_dyn`。这样“距离障碍 0.5m”不再自动等于安全。

**灵感 5（主动证伪评测 → 真机评测是“找证书漏洞”的实验设计）**
直觉：真机预算有限，随机跑场景信息量低。应把评测当作主动实验设计：选择最能区分“证书成立/被推翻”的动态场景（高速横穿、遮挡后突然出现、低摩擦与动态障碍耦合），最大化单位真机成本的证伪率。这样评测不是给模型打分，而是 **给证书做压力测试与版本维护**。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（时空生存核）**
给定时刻 `t`、语义图 `Σ_t`、障碍预测占据集 `O_{t:t+H}`（含预测不确定度），定义
`K_t(Σ_t,O_{t:t+H}) = {x_t | ∃ u_{t:t+H}∈A_WB^H, λ_{t:t+H} : x_{s+1}=f(x_s,u_s,λ_s) ∧ x_s∈𝒳_free(O_s) ∧ supp(λ_s)⊆C^+(Σ_s) ∧ λ_s∈FC(μ)}`。
递归形式：`x_t∈K_t ⇔ x_t∈𝒳_free(O_t) ∧ ∃u_t: x_{t+1}∈K_{t+1}`。它是时变自由空间中最大的受控不变集；`K_t` 随障碍预测滚动前移。

**定义 128（真机-仿真残差泛函）**
令可观统计 `z=(e_track, f_contact, ℓ_latency, s_slip)`，在策略 `π` 下
`δ_r(π) = W_1(P_real(z|π), P_sim(z|π))`（或 MMD 等积分概率度量）。
用分位数/保形预测给出置信上界 `δ_r^+`，要求 `P(δ_r ≤ δ_r^+) ≥ 1-α`。`δ_r` 是向量化的：允许不同物理通道有不同漂移。

**定义 129（证书有效期 / TTL）**
`τ_val(J_rt) = min{ τ_pred, τ_drift, τ_sem }`：
- `τ_pred`：障碍预测不确定度 `U_O(t+τ)` 首次超过 `θ_o` 的时间；
- `τ_drift`：漂移模型下 `δ_r^+(t+τ)` 首次超过 `Θ_r` 的时间；
- `τ_sem`：语义-接触层要求的最长重检间隔。
证书在 `t` 时刻可用，当且仅当 `t - t_issued + τ_lead^req ≤ τ_val`，其中 `τ_lead^req` 是任务要求的避障前置时间。

**定义 130（避障前置时间裕度）**
对动作 `u`、障碍 `o`，令 `Reach_{τ_react}(x,u)` 为含感知-计算-执行延迟的可达集，`B_brake(u)` 为制动包络：
`m_dyn(x,u,t) = min_{o∈O} [ dist(Reach_{τ_react}(x,u), O_o(t+τ_react)) - r_brake(u) ]`。
安全要求 `m_dyn ≥ θ_lead > 0`。注意阈值大于零：必须留出“已经决定但还没生效”的那段时间。

**定义 131（主动证伪评测）**
评测 episode `e=(场景, 初始状态, 障碍脚本)` 的证伪价值
`V(e) = I(δ_r ; outcome_e | J) / cost(e)`，或等价地 `P(J 被 e 推翻)/cost(e)`。
选择 `e* = argmax_e V(e)`，使真机预算优先花在“最可能证明证书是错的”场景上。

**定义 132（现实-时间联合证书）**
`J_rt = (J_s, δ_r^+, τ_val, N_real, ρ_lead, O_horizon, evidence_real)`：
- `J_s`：第 55 轮语义-接触证书；
- `N_real`：会签真机 episode 数与配对初始状态；
- `ρ_lead(ε_r,ε_o) = inf_{||δ_r||≤ε_r, O∈Ball(O_pred,ε_o)} P(全程安全 | J_rt)`：现实-时间鲁棒性谱；
- `evidence_real`：真机日志、被推翻的证书、边界反例。
部署判定：`J_s` 有效 ∧ `δ_r^+ ≤ Θ_r` ∧ `τ_val ≥ τ_lead^req` ∧ `ρ_lead ≥ ρ_min` ∧ 当前 `x∈K_t` ∧ 证书未过期。

## 2. 关键算法 伪代码

### IP-127 RWE（Reality Witness Evaluation）

```python
def reality_witness(policy, real_env, sim_env, n_pairs, stat_fn, alpha):
    z_real, z_sim = [], []
    for i in range(n_pairs):
        s0 = paired_initial_state(i)       # 真机/仿真同初态、同扰动脚本
        z_real.append(stat_fn(run(real_env, policy, s0)))
        z_sim.append(stat_fn(run(sim_env, policy, s0)))
    delta_r = wasserstein1(z_real, z_sim)
    delta_hi = conformal_upper(z_real, z_sim, alpha)
    return RealityWitness(delta_r, delta_hi, z_real, z_sim)
```

### IP-128 DTK（Dynamic-Temporal Viability Kernel）

```python
def temporal_viability_kernel(t, Sigma, O_pred, horizon, mu, eps):
    K = {x for x in sample_states() if free(x, O_pred[t])}
    for s in reversed(range(t, t + horizon)):
        K_prev = set()
        for x in sample_states():
            if not free(x, O_pred[s]):
                continue
            if any(succ(x, u, lam) in K
                   for u in A_WB
                   for lam in FC(mu)
                   if contact_subset(lam, C_plus(Sigma[s]))):
                K_prev.add(x)
        K = K_prev
    return KernelApprox(K, outer_hull(K, eps), margin=min_margin(K))
```

### IP-129 CTC（Certificate TTL Clock）

```python
def certificate_ttl(J, drift_model, O_pred, budgets):
    tau_pred = first_time(lambda tau: O_pred.uncertainty(tau) > budgets.theta_o)
    tau_drift = drift_model.time_to_exceed(J.delta_r_hi, budgets.Theta_r)
    tau_sem = budgets.semantic_recheck_interval
    return min(tau_pred, tau_drift, tau_sem)

def deployable(J, t_now, tau_lead_req, budgets):
    if not J.semantic_ok or J.delta_r_hi > budgets.Theta_r:
        return False, 'reality_gap'
    if (t_now - J.issued_at) + tau_lead_req > J.tau_val:
        return False, 'certificate_expired'
    return True, 'ok'
```

### IP-130 ARE（Active Refutation Evaluation）

```python
def active_refutation_eval(J, scenario_space, budget, cost_fn, update_fn):
    D = []
    while budget > 0:
        e = max(scenario_space, key=lambda e: expected_info_gain(J, e) / cost_fn(e))
        outcome = run_real(e)
        D.append((e, outcome))
        J = update_fn(J, D)                # 收紧或推翻，不允许无证据放松
        if J.refuted:
            return J, D, 'refuted'
        budget -= cost_fn(e)
    return J, D, 'survived'
```

### IP-131 ALR（Avoidance Lead-time Robustness）

```python
def avoidance_lead_margin(x, u, t, O_pred, tau_react, r_brake):
    reach = reachable_set(x, u, tau_react)
    return min(dist(reach, O_pred[o][t + tau_react]) - r_brake for o in O_pred)

def avoidance_robustness(J, eps_r, eps_o, sampler):
    worst = 1.0
    for dO in sampler.ball_O(eps_o):
        for dr in sampler.ball_r(eps_r):
            p = empirical_avoidance_success(J, dO, dr)
            worst = min(worst, p)
    return worst    # rho_lead
```

### IP-132 RTC（Reality-Temporal Certificate）

```python
def reality_temporal_certificate(J_s, RWE, K_t, O_pred, ALR, budgets):
    if RWE.delta_r_hi > budgets.Theta_r:
        return ('reject', 'reality_gap', RWE.delta_r_hi)
    tau_val = certificate_ttl(RWE.to_J(), budgets.drift_model, O_pred, budgets)
    if tau_val < budgets.tau_lead_req:
        return ('reject', 'certificate_ttl_too_short', tau_val)
    rho_lead = ALR.robustness(RWE.delta_r_hi, budgets.eps_o)
    if rho_lead < budgets.rho_min:
        return ('reject', 'dynamic_robustness_fail', rho_lead)
    if not K_t.contains(current_state()):
        return ('reject', 'outside_temporal_kernel')
    return ('ok', RealityTemporalCert(J_s, RWE, tau_val, rho_lead, evidence=D))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| RWE | O(N_pairs·T·C_stat) | O(N_pairs·d) | 配对初态、保形上界覆盖 |
| DTK | O(H·|X|·|A_WB|·|FC|) | O(|X|·H) | 反向可达 sound、障碍外近似 |
| CTC | O(H) | O(1) | 漂移模型有界、延迟计入 |
| ARE | O(N_eval·(T+IG)) | O(N_eval·d) | 信息增益估计、更新单调 |
| ALR | O(N_adv·T·|O|) | O(|X|) | 可达集外近似、预测球覆盖 |
| RTC | O(证书合成) | O(|J|) | 五项条件合取、过期即拒 |

**正确性定理（Reality-Temporal Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** `δ_r^+` 是真实残差的有效置信上界且分布漂移在 `τ_val` 内平稳；**(A34)** 障碍预测可达集 `O^+` 以概率 `≥1-α_o` 外近似真实占据集；**(A35)** `τ_val` 的计时包含感知-计算-执行延迟，且重评估在过期前完成；**(A36)** 主动证伪只会收紧证书，不得无证据放松；**(A37)** 回落动作 `u_stop` 在当前 `K_t` 内可行。
则单次部署窗口内的安全概率：
```
P_safe ≥ 1 - P(δ_r > δ_r^+) - P(O_true ⊄ O^+) - P(τ_val 被高估)
          - P(J_s 失效) - P(x ∉ K_t) - P(u_stop 不可行)
```
关键：**真机残差进证书、生存核带时间、证书带过期时间、延迟进裕度、评测主动找反例**。五层任一层失守，都不允许把“仿真里证书成立”当成“真机上部署成立”。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 真机分布漂移导致 `δ_r^+` 低估 | 高 | 在线保形重校准 + 漂移检测 + 硬 TTL 上限 |
| 障碍预测突然失效（遮挡后出现） | 高 | 可达集外近似 + 最小风险制动 + 遮挡专用评测 |
| TTL 被延迟/调度抖动高估 | 高 | 端到端时间戳 + 预算扣除 + 过期即拒 |
| 时空生存核计算爆炸 | 中 | 滚动时域 + 分层核 + GPU 批采样 |
| 主动评测过拟合到少数场景 | 中 | 场景空间分层 + 保留集 + 反例入库 |
| 真机评测成本高、样本少 | 中 | 配对仿真预筛 + 方差自适应分配 |

## 6. 本轮最大风险

**一句话**：把真机评测升级为“证书会签”、把动态避障升级为“带有效期的时空生存核”，其 soundness **三重重依赖现实残差上界的有效性、障碍预测可达集的外近似、以及 TTL 计时的完整性**；一旦真实世界发生校准集外的分布漂移（新光照、新地面、执行器磨损），`δ_r^+` 会低估 gap、TTL 会被高估，系统就会把一张已经过期的证书当成新鲜证书，在动态障碍突然出现时仍按旧核放行动作——因此必须坚持 **在线保形重校准 + 硬性 TTL 上限 + 预测失效即制动** 三重护栏，宁可频繁重证，绝不把“仿真里签过字”当作“真机上仍然有效”。

```python
def temporal_viability_kernel(t, Sigma, O_pred, horizon, mu, eps):
    K = {x for x in sample_states() if free(x, O_pred[t])}
    for s in reversed(range(t, t + horizon)):
        K_prev = set()
        for x in sample_states():
            if not free(x, O_pred[s]):
                continue

                   for u in A_WB
                   for lam in FC(mu)
                   if contact_subset(lam, C_plus(Sigma[s]))):
                K_prev.add(x)
        K = K_prev
    return KernelApprox(K, outer_hull(K, eps), margin=min_margin(K))
```

```python
def certificate_ttl(J, drift_model, O_pred, budgets):
```

### IP-130 ARE

```python
def active_refutation_eval(J, scenario_space, budget, cost_fn, update_fn):
    D = []
    while budget > 0:
        e = max(scenario_space, key=lambda e: expected_info_gain(J, e) / cost_fn(e))
        outcome = run_real(e)
        D.append((e, outcome))
        J = update_fn(J, D)          # 只允许有证据收紧，不允许无证据放松
        if J.refuted:
            return J, D, 'refuted'
        budget -= cost_fn(e)
    return J, D, 'survived'
```

```python
def avoidance_robustness(J, eps_r, eps_o, sampler):
```

```python
def reality_temporal_certificate(J_s, RWE, K_t, O_pred, ALR, budgets):
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| RWE | O(N_real·T·C_stat) | O(N_real·d) | 配对初态、保形上界覆盖 |
| DTK | O(H·|X|·|A_WB|·|FC|) | O(|X|·H) | 反向可达 sound、障碍外近似 |
| CTC | O(H) | O(1) | 漂移有界、延迟计入、过期即拒 |
| ARE | O(N_eval·(T+IG)) | O(N_eval·d) | 信息增益估计、更新单调 |
| ALR | O(N_adv·T·|O|) | O(|X|) | 可达集外近似、预测球覆盖 |
| RTC | O(证书合成) | O(|J_rt|) | 五条件合取 |

**正确性定理（Reality-Temporal Soundness）**
假设第 55 轮 (A29)–(A32) 与第 54 轮 (A26)–(A28) 成立；**(A33)** `δ_r^+` 为有效置信上界且 `τ_val` 内分布平稳；**(A34)** 障碍可达集 `O^+` 以概率 `≥1-α_o` 外近似真实占据；**(A35)** TTL 计时覆盖感知-计算-执行延迟且重评估及时完成；**(A36)** ARE 只收紧不放松证书；**(A37)** 回落制动 `u_stop` 在当前 `K_t` 内可行。
则部署窗口内：
```
P_safe ≥ 1 - P(δ_r > δ_r^+) - P(O_true ⊄ O^+) - P(τ_val 高估)
          - P(J_s 失效) - P(x ∉ K_t) - P(u_stop 不可行)
```
关键：**现实残差会签、时空核滚动、证书带 TTL、延迟进裕度、评测主动证伪**。任一层失守都不允许把“仿真证书成立”当作“真机部署成立”。

## 6. 本轮最大风险

**一句话**：现实-时间联合证书把“真机会签”和“时空生存核”接入体系，但其 soundness **三重重依赖 `δ_r^+` 在校准集外仍然有效、障碍预测可达集外近似不漏、TTL 计时覆盖全部延迟**；一旦真实世界发生分布漂移（新地面/新光照/执行器磨损），残差上界会低估、TTL 会高估，系统便把过期证书当新鲜证书使用，在动态障碍突现时仍按旧核放行动作——因此必须以 **在线保形重校准 + 硬 TTL 上限 + 预测失效即制动** 三重护栏，宁可频繁重证，绝不把“仿真里签过字”当作“真机上仍然有效”。
