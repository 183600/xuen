## 1. 直觉与动机（两个灵感的碰撞）

**灵感 1（迭代验证 → 缺的不是想法，是分辨信号与噪声的能力）**
直觉：清单已有 I1–I9，任何一条都值得做；但真机预算只有约 320 次量级（32 任务 × ~10 次）。用最粗的统计算一笔账：若单任务成功率 p≈0.2、每任务只测 2 次，**非配对 A/B 的最小可检测效应（MDE）约 20 个百分点**——我们计划中的大多数「+3~8 分」改进，在现有试验次数下与噪声不可区分。反直觉点：**第一优先的创新不是更强的策略，而是更强的实验；先造尺子，再造东西。** 迭代验证的正确形态是「预注册假设 → 配对/共同随机数 → 达到 MDE 才升级到计分通道 → 结果回填决策台账」，而不是「改一版、跑一次、看分数涨没涨」。

**灵感 2（评测指标 → 指标不是真理，是一台有噪声、有结构、可标定的仪器）**
直觉：官方是双指标（F20），步骤分是部分信用（F17），排行榜聚合权重还未知。把评测当测量科学（metrology）而不是当分数：它有方差分量（任务/策略、场次/机器人、重复随机性），有锚点可校准，有部分信用可降方差，有聚合方式可反推。三个直接推论：(a) **步骤分是免费的降方差工具**——只盯成功率会扔掉每次昂贵试验的大部分信息，把步骤分当协变量可显著降低成功率估计的方差；(b) **场次漂移必须用参考锚扣除**——同一策略不同天分数不同，不做区组/锚定就会把「机器人今天状态好」误判成「改动有效」；(c) **未知聚合权重可以从榜单反推**——观测若干模型的 (成功率, 步骤分, 名次) 三元组，用逆优化拟合出最可能的权重或字典序。反直觉点：**在低成功率区间，步骤分比成功率更「可测」；把 I5 的恢复增益做成步骤分增益，可能比 I2 的成功率迁移更快被证明有效。**

**二者统一（本轮论点）**：迭代验证回答「差异何时为真」，评测指标回答「我们到底在测什么、测得有多准」。合起来是两件资产：一台**评测仪器**（方差分解 + 功效预算 + 锚定 + 控制变量）与一套**决策规程**（验证防火墙 + 因果台账 + 组合投资 + 最优停时）。本轮结论：**中后盘的胜负手从「数据效率」转向「测量效率」——谁能用更少的真机次数证明更大的增益，谁就能在同样预算下多迭代几轮。**

# UniBot-V1 参赛创新点清单（第 3 轮 v1.2：评测仪器 × 迭代验证）

> 检索日期：2026-11-27（本轮）。承接 v1.1（I1–I9）：新增 I10–I12，I8 升 v3，I5 升格；其余维持。清单只增改不重置。来源见 §6。

## 0. 评测指标的形式化（本轮基座）

### 0.1 目标向量与未知聚合

设任务 \(t=1..32\)，试验 \(j=1..N_t\)，成功指示 \(Y_{tj}\in\{0,1\}\)，步骤分 \(S_{tj}\in[0,100]\)。榜单（待核实）近似为

\[
M_{\text{succ}}=\frac1{32}\sum_t \frac1{N_t}\sum_j Y_{tj},\qquad
M_{\text{step}}=\frac1{32}\sum_t \frac1{N_t}\sum_j S_{tj}.
\]

**严谨定义（未知聚合）**：存在单调函数 \(f:\mathbb R^2\to\mathbb R\)，排名 \(=f(M_{\text{succ}},M_{\text{step}})\)；\(f\) 未公布，候选族为
\(\mathcal F=\{\lambda M_{\text{succ}}+(1-\lambda)M_{\text{step}}/100:\lambda\in[0,1]\}\cup\{\text{字典序（成功率优先）}\}\)。
本轮不假设 \(f\) 已知，所有决策必须在 \(f\in\mathcal F\) 上稳健（§2.3）。**待核实 A1**：均值是否为等权、步骤分是否只对成功 eps 计。

### 0.2 方差分解（Gauge R&R，测量系统分析）

对同一任务 \(t\)、场次 \(s\)、重复 \(r\)，随机效应模型

\[
S_{tsr}=\mu+\tau_t+\beta_s+(\tau\beta)_{ts}+\varepsilon_{tsr},\qquad
\sigma^2_{\text{total}}=\sigma^2_{\text{task}}+\sigma^2_{\text{session}}+\sigma^2_{\text{repeat}}+\sigma^2_{\text{int}}.
\]

- \(\sigma^2_{\text{repeat}}\)：同一策略同一场次的随机性（流匹配采样、环境微扰）。
- \(\sigma^2_{\text{session}}\)：场次/机器人/光照漂移（P10）。
- **%GRR** \(=(\sigma^2_{\text{session}}+\sigma^2_{\text{repeat}})/\sigma^2_{\text{total}}\)。若 %GRR > 30%，说明测量系统主导，任何 A/B 都不可信，必须先锚定/增重复。

### 0.3 最小可检测效应（MDE）

双侧 \(\alpha=0.05\)、功效 \(1-\beta=0.8\) 时，\(z_{0.975}+z_{0.8}=2.80\)：

\[
\text{MDE}=2.80\cdot \mathrm{SE}(\Delta).
\]

配对（按任务配对，比较每任务差 \(\Delta_t\)）：\(\mathrm{SE}=\mathrm{sd}(\Delta_t)/\sqrt{32}\)；
非配对两组：\(\mathrm{SE}=\sqrt{2\sigma^2/n}\)。**关键：任务间难度差异远大于任务内，按任务配对能消掉最大的一项方差；池化比较是最差做法。**

**算例**（p≈0.2，\(\sigma_{\text{succ}}^2=0.16\)；步骤分归一化后 \(\sigma_{\text{step}}=0.25\) 即 25 分）：

| 设计 | 成功率的 MDE | 步骤分的 MDE |
|---|---|---|
| 非配对，n=320（每任务 10 次） | **8.9 pp** | 5.5 分 |
| 配对，ρ=0.8，n=320 | **4.0 pp** | 3.0 分（ρ=0.7） |
| 非配对，n=64（每任务 2 次） | **19.8 pp** | 12.4 分 |
| 配对，ρ=0.8，n=64 | **8.9 pp** | 6.8 分（ρ=0.7） |

**结论（本轮最重要定量结论）**：在约 320 次预算下，成功率上 +3~4pp 的改进基本不可测；而步骤分的同等相对改进可测。**因此 I5（步骤分恢复）应优先于 I2（成功率迁移）占用真机验证预算**——不是 I5 更重要，而是 I5 的增益更「可测」。

### 0.4 步骤分作控制变量（免费降方差）

用步骤分 \(S\) 作成功率 \(Y\) 的协变量：

\[
\hat p_{\text{cv}}=\bar Y+\hat\beta(\bar S-\mathbb E[S]),\qquad
\hat\beta=\widehat{\mathrm{Cov}}(Y,S)/\widehat{\mathrm{Var}}(S).
\]

方差缩减因子 \(1-\rho_{YS}^2\)。若 \(\rho_{YS}=0.7\)，方差降 51%，**等效样本量近乎翻倍**。这把「双指标」从负担变成礼物：步骤分不是第二名次，而是成功率的免费方差缩减器。

### 0.5 参考锚与双重差分（去场次漂移）

固定一个「锚任务 + 锚策略」（如 Base 模型在简单任务上），每场次先跑锚。场次偏移估计 \(\hat\beta_s=a_s-\bar a\)，校正后 \(S'_{tsr}=S_{tsr}-\hat\beta_s\)。跨场次比较用 DID：

\[
\hat\Delta_{\text{DID}}=(\bar Y_{\text{treat,post}}-\bar Y_{\text{treat,pre}})-(\bar Y_{\text{anchor,post}}-\bar Y_{\text{anchor,pre}}).
\]

## 1. 创新点清单（每点：动机 / 与现有方案差异 / 技术可行性 / 所需资源 / 落地步骤 / 风险）

### I10 评测仪器：方差分解 + 功效预算 + 步骤分控制变量 + 参考锚 ★★★★★（新）
- **动机**：双指标（F20）+ 单任务调试通道（F21）+ 约 320 次预算，使「测不准」成为比「做不好」更紧的约束（P9/P10/P11）。
- **与现有方案差异**：常规队伍「跑一次看分数」；本点把评测当仪器：先测仪器的噪声（%GRR），再算能测多小的效应（MDE），再用配对/控制变量/锚定把 MDE 压低，最后才做实验。
- **技术可行性**：高。全部是统计与脚本，不需新模型。
- **所需资源**：1 人周实现；标定阶段 3 任务 × 3 场次 × 3 重复 ≈ 27 次单任务调试时段（可与后续实验共用）。
- **落地步骤**：①选 3 个代表性任务（易/中/难）+ 固定锚策略；②跑 Gauge R&R，估计 \(\sigma^2\) 三分量；③实现 MDE 计算器与功效表；④实现配对分析、控制变量、DID；⑤把「达到 MDE 才升级到计分通道」写成脚本门禁（PR6）。
- **风险**：Gauge R&R 需要跨场次重复，若预约不到足够时段则方差估计不稳；缓解：先用 2 场次 + 自助法置信区间，随轮次滚动更新。

### I11 迭代防火墙 + 提交级因果台账 + 未知聚合稳健决策 ★★★★★（新）
- **动机**：跨轮反复对同一代理/同一小样本调参会产生 Goodhart 与选择偏差（P9）；聚合权重未知（F20），标量化本身就是决策风险。
- **与现有方案差异**：常规做法用全部 32 任务结果决定下一步，等价于在测试集上选择；本点把「选择」与「确认」在制度上隔离，并对未知 \(f\) 做稳健决策。
- **技术可行性**：高。dev/val/test 划分 + 预注册表 + 盲化读取脚本。
- **所需资源**：流程 0.5 人周；无额外算力。
- **落地步骤**：
  1. **分层划分**：按任务族与难度把 32 任务分为 dev(16) / val(8) / test(8)，固定不轮换；test 仅用于计分多任务确认。
  2. **预注册**：每次改动先登记「改了哪个因子、对 \(M_{\text{succ}}\)/\(M_{\text{step}}\) 的预测方向与幅度、预期 MDE、决策规则」。
  3. **盲化读取**：自动化脚本只从 dev/val 生成「升级/放弃」建议；test 的逐任务结果延迟到决策锁定后解密展示。
  4. **因果台账**：每次提交记录预测 vs 实测；能单因子就单因子，不能则析因；跨场次用锚定 DID。
  5. **未知聚合稳健决策**：维护候选模型的 \((M_{\text{succ}},M_{\text{step}})\) 帕累托前沿；只有「帕累托改进」或「在可行权重集上极小极大后悔最优」才提交（见 §2.3）。
- **风险**：test 只有 8 个任务，最终确认的方差仍大；缓解：test 上做重复 + 用步骤分控制变量，并把「最终排名」而非「test 均值」当作目标。

### I12 任务组合投资 + 信息价值调度 + 最优停时 ★★★★（新）
- **动机**：32 任务边际分数价值近似均等（各 1/32），但可修性、成本、方差、族间相关性高度异质；轮次有限，探索/利用需显式权衡（P11）。
- **与现有方案差异**：常规按「哪个任务分低修哪个」；本点按「边际期望分数增益 / 成本」并扣除不确定性与族间相关性，且把评测时段当作「购买信息」的资源，用 VOI 而非任务重要性分配。
- **技术可行性**：中-高。模型是表格 + 简单优化，不需训练。
- **所需资源**：0.5–1 人周；与 I10/I11 共用数据。
- **落地步骤**：
  1. **任务卡**：每任务记录基线分、估计增益 \(\Delta_t\)、成本 \(c_t\)、方差、所属族。
  2. **组合优化**：\(\max\sum_t w_t\mathbb E[\Delta_t]\) s.t. \(\sum c_t\le C\)，加族间分散惩罚（避免同族同时失败）。
  3. **VOI 分配**：每个待测改动计算「该时段能降低多少决策不确定性」，按时段做贪心/背包分配。
  4. **最优停时**：贝叶斯后验下，继续探索当且仅当 \(\mathbb E[\max(0,\Delta)]\cdot V>c_{\text{slot}}\) 且剩余轮次 >0；否则锁定提交。
  5. **Moonshot 预算**：固定预留 15–20% 时段给「高方差、单次难测、但可能多任务同涨」的改动，以捆绑评测或视频定性复核代替单点显著性检验，防止 MDE 门禁误杀（§6 风险的制度解）。
- **风险**：增益/成本估计本身有误差，组合优化会「精确地分配错」；缓解：用区间而非点估计，每轮重估并保留探索。

### I8 v3 评测运营闭环 + 分级消融注册表（升格为基础设施）
- 承 v1.1 的 L0/L1/L2 分级消融与离线-在线相关性注册表；本轮扩展：
  - 注册表 schema 增加**双指标**（succ/step）、**场次 ID**、**锚分**、**设计类型**（配对/非配对）、**MDE**、**预注册预测**、**盲化状态**。
  - L0 代理与真机的相关性按「指标 × 任务族 × 场次」分层计算；相关性未达 0.6 前，L0 只做筛选不做准入（承 v1.1）。
  - 新增「公开 Runs 挖掘」期权：榜单上线后，用公开的逐模型逐任务视频/分数做失败分类与泛化轴覆盖统计（离线、只用于选题与增广设计，不做行为克隆，见合规）。
- **风险**：注册表字段过多导致填写负担；缓解：脚本自动从评测输出填充，人工只填预注册预测。

```python
from statistics import NormalDist
Z = NormalDist().inv_cdf(0.975) + NormalDist().inv_cdf(0.8)   # 2.80

def mde_paired(deltas, alpha=0.05, power=0.8):
    # deltas: 每任务 A/B 差（配对）；返回总体均值差的最小可检测效应
    n = len(deltas)
    se = stdev(deltas) / sqrt(n)
    return Z * se

def mde_unpaired(sigma2, n_per_arm):
    return Z * sqrt(2 * sigma2 / n_per_arm)

def neyman_alloc(tasks, total_slots, cost=None):
    # 为「估计当前均值」最小化 SE：n_t ∝ sigma_t / sqrt(cost_t)
    cost = cost or {t: 1 for t in tasks}
    w = {t: tasks[t].sigma / sqrt(cost[t]) for t in tasks}
    s = sum(w.values())
    return {t: max(1, round(total_slots * w[t] / s)) for t in tasks}

def gauge_rr(scores):   # scores[(task, session, repeat)] -> variance components
    # 两/三因素方差分析；返回 (sigma2_task, sigma2_session, sigma2_repeat, pct_grr)
    return anova_components(scores)

def gate(effect_pred, design):        # PR6：未达 MDE 不得升级到计分通道
    mde = design.mde()
    return {"promote": abs(effect_pred) >= mde, "mde": mde,
            "note": "低于 MDE：改设计（配对/锚定/加重复）或转 moonshot 捆绑"}
```

### 2.2 控制变量与锚定（I10）

```python
def success_cv(Y, S, S_ref_mean):
    # 用步骤分作协变量估计成功率；返回点估计与方差缩减因子
    beta = cov(Y, S) / var(S)
    p_hat = mean(Y) + beta * (mean(S) - S_ref_mean)
    return p_hat, 1 - corr(Y, S)**2          # 方差缩减因子

def anchor_correct(score, session, anchor_scores):
    offset = anchor_scores[session] - mean(anchor_scores.values())
    return score - offset                     # 去场次漂移

def did(treat_pre, treat_post, anchor_pre, anchor_post):
    return (mean(treat_post) - mean(treat_pre)) - (mean(anchor_post) - mean(anchor_pre))
```

### 2.3 未知聚合的稳健决策（I11）

```python
def feasible_weights(obs):
    # obs: [(model, M_succ, M_step, rank)]；求能复现名次的 lambda 集合
    # 归一化 step 到 [0,1]，分数 = lambda*succ + (1-lambda)*step
    lo, hi = 0.0, 1.0
    for a in obs:
        for b in obs:
            if a.rank < b.rank:               # a 应优于 b
                # (sa-sb)*l + (pa-pb)*(1-l) >= 0  -> 线性不等式收紧 [lo,hi]
                lo, hi = tighten(lo, hi, a, b)
    return (lo, hi) if lo <= hi else None

def robust_choice(candidates, weight_interval):
    if weight_interval is None:               # 无一致权重 -> 字典序：成功率优先
        return max(candidates, key=lambda c: (c.succ, c.step))
    # 极小极大后悔：在每个候选上取最坏权重下的名次，选最坏名次最好的
    return min(candidates, key=lambda c: max(rank_of(c, lam) for lam in grid(weight_interval)))

def may_submit(new, incumbent, weight_interval):
    if dominates(new, incumbent): return True          # 帕累托改进
    return robust_choice([new, incumbent], weight_interval) is new
```
