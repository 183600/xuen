# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「末端位姿」×「场景落地」）

> 第 54 轮已把技能组合推到动作空间剖面 α_S、云边协同与动作-鲁棒性联合证书 J。本轮把整条抽象链**下沉到末端位姿**，并把验证从「单场景通过」推进到「场景分布上的可落地」。核心矛盾：H22：动作空间兼容不等于末端位姿可达与精度兼容——`A_i ∩ A_j ≠ ∅` 仍可能在 SE(3) 容差域内没有共同可达位姿；H23：场景落地是分布问题，仿真/实验室单场景的位姿成功无法外推到部署场景分布，缺少可证伪的落地契约。

## 0. 直觉与动机

**灵感 1（末端位姿是所有抽象动作的物理锚点）**
直觉：无论 `α_S`、`compat`、`γ_ce` 做得多细，机器人真正交付的是末端位姿轨迹 `ξ:[0,T]→SE(3)`。因此给技能加一层**位姿接地下沉**：`π_pose: A → Traj(SE(3))`，技能位姿足迹 `𝓟_S = π_pose(A_S)`。组合的第一性检查从「动作交集非空」前移为「存在共同可达位姿，且该位姿落在任务容差域内」。动作空间只是位姿空间的粗坐标，位姿才是验收对象。

**灵感 2（把"落地"字面化：位姿容差域与位姿裕度）**
直觉：任务验收不是"到达目标点"，而是末端位姿落入以目标 `g_T` 为中心的容差域 `Ω_T`（位置半径 `ε_p`、姿态角 `ε_r`）。定义**位姿裕度** `m(g)=1-d_W(g,g_T)`，成功即 `m≥0`。这让"场景落地"有了物理标量：不是丢点命中率，而是位姿裕度分布。裕度还给出可比较的余量，便于在组合阶段就做保守剪枝。

**灵感 3（位姿误差沿技能链用 Adjoint 传播）**
直觉：每个技能的位姿误差不是独立噪声，而是随 SE(3) 链式复合被 Adjoint 放大。用李代数把误差 `ξ∈ℝ⁶` 传播：`ξ_out ≈ Ad_{g2^{-1}}ξ_1 + ξ_2`，协方差 `Σ_out = Ad Σ_1 Ad^T + Σ_2`。于是可给出**端到端位姿证书** `P_cert=(Σ_final, m_min, κ_pose)`，并检验 `P(m≥0) ≥ 1-δ_pose`。这把第 54 轮的"动作对齐"升级为"位姿精度对齐"。

**灵感 4（场景落地 = 场景分布上的风险控制）**
直觉：部署场景是分布 `D_scene`（物体布局、初始/目标位姿、遮挡、光照）。"落地"应定义为 `R(π)=E_{s~D_scene}[1(m_s<0)] ≤ α`。用 conformal risk control 在标定场景集上给出**分布无关的落地风险上界** `D_cert`，把"落地"从一次性 demo 变成可审计的统计承诺。单场景零误差不再是卖点，"在场景分布上以 1-δ_conf 置信、风险 ≤ α" 才是。

**灵感 5（影子→金丝雀的落地闸门）**
直觉：真实部署不能一步到位。影子模式（记录云端计划位姿 vs 边端执行位姿，不驱动）→ 金丝雀（小比例真实执行）→ 全量。每级用 SPRT 对位姿裕度与鲁棒性谱做序贯检验，达到证据阈值才放行。落地闸门 `DLG` 用位姿证据而非抽象指标做 go/no-go，避免"证书漂亮、一落地就位姿错位"。

**灵感 6（金字塔再加位姿落地层 ℙ）**
直觉：在 `𝕃`（鲁棒性）、`𝔸`（动作协同）之上叠加 `ℙ`：`ℙ_0` SE(3) 物理可达极限，`ℙ_1` 技能位姿足迹，`ℙ_2` 位姿误差传播，`ℙ_3` 场景分布落地风险。跨层证书必须同时闭合 `ρ`、`A_cert`、`P_cert`、`D_cert` 四个量，任一不闭合即否决落地。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（末端位姿投影与足迹）**
`π_pose: A → Traj(SE(3))` 把抽象动作映为末端位姿轨迹。技能 `S` 的位姿足迹 `𝓟_S = {π_pose(a) | α_S(a) ≥ θ_cov}`。位姿接地剖面 `β_S(g) = sup_{a: π_pose(a)=g} α_S(a)`，即同一末端位姿可被多少动作占用支撑。

**定义 122（位姿容差域与位姿裕度）**
目标位姿 `g_T=(R_T,t_T)`，容差 `(ε_p,ε_r)`。加权 SE(3) 距离
```
d_W(g,g_T) = sqrt( ||t - t_T||² / ε_p² + ( arccos((tr(RᵀR_T)-1)/2) )² / ε_r² )
```
容差域 `Ω_T = {g ∈ SE(3) | d_W(g,g_T) ≤ 1}`，位姿裕度 `m(g)=1-d_W(g,g_T)`，验收成功 `m(g) ≥ 0`。轨迹 `ξ` 的离域风险 `risk(ξ)=1` 当且仅当 `∃t, m(ξ(t))<0`。

**定义 123（位姿接地兼容性）**
两技能位姿接地兼容性 `compat_pose(S_i,S_j) = |𝓟_i ∩_Ω 𝓟_j| / |𝓟_i ∪_Ω 𝓟_j| ≥ θ_p`，其中 `∩_Ω` 要求在共同位姿上两者裕度均 `≥0`，且转换轨迹 `ξ_trans` 全程 `m≥0`。注意它比第 54 轮动作 Jaccard 更严格：动作交集非空只是必要非充分。

**定义 124（位姿误差传播证书）**
对技能链 `S_1…S_k`，末端误差协方差
```
Σ_final = Σ_i Ad_{G_{i:k}^{-1}} Σ_i Ad_{G_{i:k}^{-1}}ᵀ ,   G_{i:k}=g_i···g_k
```
其中 `Ad_g = [[R, [t]_× R],[0,R]]`。位姿证书 `P_cert=(Σ_final, m_min, κ_pose)`，`κ_pose` 为线化残差上界。可部署条件：存在 `δ_pose` 使 `P( m(g_final) ≥ 0 ) ≥ 1-δ_pose`。

**定义 125（场景分布与落地风险）**
场景 `s~D_scene` 给出初始位姿、目标位姿与扰动参数；策略 `π` 的落地风险 `R(π)=E_s[1(m_s<0)]`。标定集 `S_cal~D_scene^N`，conformal 风险上界 `D_cert=(R̂, α, 1-δ_conf)`，满足 `P(R(π) ≤ α) ≥ 1-δ_conf`。

**定义 126（落地契约）**
`L = (Ω_T, D_scene, α, δ_conf, P_cert, D_cert)`。当 `R̂ + q ≤ α`（`q` 为 conformal 分位修正）且 `P_cert` 通过时，契约可签发；否则即使 `ρ`、`A_cert` 全绿也不得部署。

**定义 127（影子-金丝雀落地闸门）**
三级闸门 `DLG=(shadow, canary, full)`，每级对位姿裕度序列做 SPRT：`H_0: R≤α` vs `H_1: R>α`，对数似然比 `Λ_n`；`Λ_n ≥ A` 拒绝、`Λ_n ≤ B` 接受、否则继续采样。放行需 `P(误放行) ≤ β_land`，且每级放行门槛随真实执行比例收紧。

## 2. 关键算法 伪代码

### IP-121 PPG（Pose Projection Grounding）

```python
def pose_footprint(skill, action_sampler, theta_cov=0.8):
    P = {}
    for a in action_sampler.covered_actions(skill):
        if skill.alpha(a) < theta_cov:
            continue
        traj = skill.forward_kinematics(a)      # -> [g_0,...,g_T]
        for g in traj:
            P[pose_key(g)] = max(P.get(pose_key(g), 0.0), skill.alpha(a))
    return P                                  # 位姿接地剖面 β_S

def compat_pose(Pi, Pj, Omega_T, theta_p):
    common = [g for g in Pi if g in Pj and in_tolerance(g, Omega_T)]
    if not common:
        return 0.0
    return len(common) / (len(Pi) + len(Pj) - len(common))
```

### IP-122 PTA（Pose Tolerance Acceptance）

```python
def pose_margin(g, g_T, eps_p, eps_r):
    dp = norm(g.t - g_T.t)
    dR = acos(clip((trace(g.R.T @ g_T.R) - 1) / 2, -1.0, 1.0))
    dW = sqrt((dp / eps_p) ** 2 + (dR / eps_r) ** 2)
    return 1.0 - dW, dW

def trajectory_risk(traj, g_T, eps_p, eps_r):
    margins = [pose_margin(g, g_T, eps_p, eps_r)[0] for g in traj]
    return 1 if min(margins) < 0 else 0, min(margins)
```

### IP-123 PEP（Pose Error Propagation）

```python
def propagate_pose_cov(skill_seq, Sigma_list, poses):
    Sigma = Sigma_list[-1]
    for i in range(len(skill_seq) - 2, -1, -1):
        G = compose(poses[i+1:])              # G_{i+1:k}
        Ad = adjoint(inverse(G))
        Sigma = Ad @ Sigma_list[i] @ Ad.T + Sigma
    return Sigma

def pose_certificate(Sigma_final, m_min, delta_pose, kappa):
    # 用协方差半正定界估计 m<0 概率上界
    p_fail = chebyshev_bound(Sigma_final, m_min) + kappa
    return ('ok', PoseCert(Sigma_final, m_min, kappa)) if p_fail <= delta_pose \
           else ('reject', 'pose_precision', p_fail)
```

### IP-124 SDR（Scenario Deployment Risk，conformal risk control）

```python
def conformal_risk_bound(scores_cal, alpha, delta_conf):
    n = len(scores_cal)
    # scores = 1(m_s < 0)，风险控制取 R̂ 的上置信修正
    R_hat = mean(scores_cal)
    q = sqrt(log(1 / delta_conf) / (2 * n))   # Hoeffding/经验 Bernstein 修正
    return R_hat + q, (R_hat + q <= alpha)

def deployment_certificate(policy, scene_sampler, alpha, delta_conf, N):
    cal = [trajectory_risk(policy.run(s))[0] for s in scene_sampler.sample(N)]
    bound, ok = conformal_risk_bound(cal, alpha, delta_conf)
    return ('ok', DCert(bound, alpha, 1 - delta_conf)) if ok \
           else ('reject', 'deployment_risk', bound)
```

### IP-125 DLG（Deployment Landing Gate，SPRT）

```python
def sprt_gate(margins, alpha, A, B):
    lam = 0.0
    for m in margins:
        p1 = alpha + 0.1                     # H1 下的失败率下界（可标定）
        p0 = alpha
        lam += log((m < 0) * p1 + (1 - m < 0) * (1 - p1)) \
             - log((m < 0) * p0 + (1 - m < 0) * (1 - p0))
        if lam >= A: return 'reject'
        if lam <= B: return 'accept'
    return 'continue'

def rollout(policy, stages=('shadow','canary','full'), alpha=0.05):
    for st in stages:
        margins = collect_margins(policy, st)
        if sprt_gate(margins, alpha, A=log(19), B=log(1/19)) != 'accept':
            return ('halt', st)
    return ('landed', 'full')
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| PPG | O(|A_S|·T·|S|) | O(|𝓟|) | 位姿采样完备、FK 标定 |
| PTA | O(T) | O(1) | SE(3) 距离度量一致、容差标定 |
| PEP | O(k·6³) | O(6²) | Adjoint 正确、线化残差界 κ_pose |
| SDR | O(N·T) | O(N) | 场景可交换、calibration 独立同分布 |
| DLG | O(n) 期望 | O(1) | 似然比正确、α 标定可信 |

**正确性定理（Pose-Grounded Deployment Soundness）**
假设 (A22)–(A28) 承接第 54 轮；**(A29)** `π_pose` 由标定过的正运动学给出，足迹采样覆盖 ≥ 95%；**(A30)** 位姿误差 ψ 线性化残差 `‖ψ‖ ≤ κ_pose`；**(A31)** 标定场景与部署场景可交换（exchangeability）；**(A32)** SPRT 的 `α`、`β_land` 在影子阶段已标定。
则部署成功率满足
```
P(success) ≥ 1 - α - δ_conf - δ_pose - β_land - P(compat_pose < θ_p)
```
关键：**动作兼容必须由位姿共同可达背书**，**端到端位姿误差有上界**，**落地风险是场景分布上的统计承诺而非单点 demo**。

## 6. 本轮最大风险

**一句话**：把抽象证书下沉到末端位姿并引入场景分布落地风险，使体系第一次真正"落地可审计"，但其 soundness **同时押在位姿足迹采样完备、Adjoint 线化残差可控、以及场景可交换性三条假设上**；一旦位姿足迹欠采样把不可达位姿误判为可达，或部署场景分布漂移破坏可交换性，conformal 上界会给出"统计上安全、物理上错位"的假落地，故必须以**位姿足迹主动采样 + 分段 Adjoint 线化 + 在线漂移检测/回退影子模式**三重护栏，宁可推迟放行，绝不把分布假设下的风险上界当作物理位姿可达性的证明。

```python
def conformal_risk_bound(scores_cal, alpha, delta_conf):
    n = len(scores_cal)
    R_hat = mean(scores_cal)
    q = sqrt(log(1 / delta_conf) / (2 * n))         # 有限样本上置信修正
    return R_hat + q, (R_hat + q <= alpha)

def deployment_certificate(policy, scene_sampler, alpha, delta_conf, N):
    cal = [trajectory_risk(policy.run(s))[0] for s in scene_sampler.sample(N)]
    bound, ok = conformal_risk_bound(cal, alpha, delta_conf)
    if ok:
        return ('ok', DCert(bound, alpha, 1 - delta_conf))
    return ('reject', 'deployment_risk', bound)
```

### IP-125 DLG

```python
def sprt_gate(margins, alpha, A, B):
    lam, p1 = 0.0, alpha + 0.1                      # H1 失败率下界（影子阶段标定）
    for m in margins:
        fail = (m < 0)
        lam += log(p1 if fail else (1 - p1)) - log(alpha if fail else (1 - alpha))
        if lam >= A: return 'reject'
        if lam <= B: return 'accept'
    return 'continue'

def rollout(policy, stages=('shadow', 'canary', 'full'), alpha=0.05):
    for st in stages:
        margins = collect_margins(policy, st)
        if sprt_gate(margins, alpha, A=log(19), B=log(1/19)) != 'accept':
            return ('halt', st)
    return ('landed', 'full')
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PPG | O(|A_S|·T·|S|) | O(|𝓟|) | 位姿采样覆盖 ≥ 95%，FK 已标定 |

| DLG | O(n) 期望 | O(1) | 似然比正确、α/β_land 可信 |

**正确性定理（Pose-Grounded Deployment Soundness）**
假设第 54 轮 (A22)–(A28) 成立；**(A29)** `π_pose` 由标定过的正运动学给出且足迹采样覆盖 ≥ 95%；**(A30)** 位姿误差线性化残差 `‖ψ‖ ≤ κ_pose`；**(A31)** 标定场景与部署场景可交换；**(A32)** SPRT 的 `α`、`β_land` 已在影子阶段标定。
则部署成功率：
```
P(success) ≥ 1 - α - δ_conf - δ_pose - β_land - P(compat_pose < θ_p)
```
关键：**动作兼容必须由位姿共同可达背书**，**端到端位姿误差有上界**，**落地风险是场景分布上的统计承诺而非单点 demo**。

## 5. 本轮最大风险

**一句话**：把抽象证书下沉到末端位姿并引入场景分布落地风险，使体系第一次真正"落地可审计"，但其 soundness **同时押在位姿足迹采样完备、Adjoint 线化残差可控、以及场景可交换性三条假设上**；一旦位姿足迹欠采样把不可达位姿误判为可达，或部署场景分布漂移破坏可交换性，conformal 上界会给出"统计上安全、物理上错位"的假落地，故必须以**位姿足迹主动采样 + 分段 Adjoint 线化 + 在线漂移检测/回退影子模式**三重护栏，宁可推迟放行，绝不把分布假设下的风险上界当作物理位姿可达性的证明。
