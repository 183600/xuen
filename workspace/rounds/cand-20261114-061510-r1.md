# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「嵌入式系统」×「多模态交互」）

> R69 教会系统「问」，但它对「问」的物理假设是隐形的，而且几乎全错：`execute(g)` 被当成一个**同步原子调用**——问出去，答案回来，回来后再做决策；代价被压成一个标量 c(g)；整条认知流水线（K 次流采样、ODE 积分、Hutchinson 散度、LLM 解码问句）被默认为跑在一台**资源无限、无截止期、可认证**的机器上。真实系统里，这三条一条都不成立：
> 1. **时间**：语音提问 + 人类思考是 1–3 秒量级，而控制回路是毫秒量级。答案往往在**必须动的那一刻之后**才到；R69 的「先 update_belief 再 select_mode」在慢模态上物理不可实现。
> 2. **资源**：流策略与 LLM 要和刹车控制器抢同一个嵌入式 ECU 的算力、内存带宽、功耗与总线；它们没有硬实时保证，也永远不会通过安全认证。
> 3. **认证**：R69 试图用 MCG 在环路内**校准**一个不可信的模态分布。但校准不等于可调度，也不等于可认证——你无法证明一个会幻觉的模型「这一次没有幻觉」。
>
> 本轮两个灵感正好把这三条翻成设计约束：
> - **嵌入式系统**给出的是**时序与关键级**的语言：硬截止期、WCET、混合关键级、时间触发调度、分区/分离内核、看门狗、可认证安全内核。它说：交互首先是一个**实时任务集**，不是一次函数调用。
> - **多模态交互**给出的是**节奏**的语言：看（几十毫秒）、触（百毫秒）、说（秒级）、等（不可界）——模态不是并列的，而是**由便宜到昂贵、可随时中断的级联**。
>
> 核心命题：**把「交互消歧」从 R69 的同步原子动作降格为「带契约、可抢占、可丢弃的混合关键级任务」；用一个可认证的时序隔离内核（只接收经网关校验的有界证据）包住不可认证的多模态流策略；用截止期折扣 VoI + 模态级联 + 投机预问，让「问得慢」从安全问题降级为效率问题。** 命名 **TEMPO-RAS**（Time-triggered Embedded Mixed-criticality Partial-information Orchestration for Risk-adaptive Autonomy）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我等得起这个答案吗？答案到之前，谁在替我安全地开车**」——信任不仅要可验证，还必须**赶得上**。

## 0. 直觉与动机

**灵感 1（嵌入式系统 → 交互首先是调度问题，不是推理问题）**
直觉：在人机对话里，「问一句」意味着等一下；在嵌入式控制里，「等一下」意味着控制回路空转或降级，是有代价甚至危险的。刹车不会等你问完「前面是人还是纸板」。所以交互的第一约束不是信息增益，而是**时序可行性**：这份证据能否在决策截止期前到达？到达时世界还是不是同一个？若答案迟到，它不但无用，还可能把系统从一个安全的保守态拉回一个**过期的自信态**。更反直觉的是，嵌入式视角给出了一条救赎：控制回路根本不需要等——它先按保守策略执行，交互在旁路异步进行，证据到达后只影响**下一次**决策。于是「同步问」变成「异步更新 + 双缓冲」，安全路径与认知路径被彻底解耦。

**灵感 2（多模态交互 → 模态不是并列的，而是有节奏的级联）**
直觉：人不会一上来就开口问。先看一眼（快、便宜、信息少），不够就指一下/触一下，再不够才开口问（慢、贵、信息多），最后可能干脆不问了、先安全停下。这是一条**由便宜到昂贵的证据瀑布**，而且可以**随时停**。R69 一次性采 K 个样本、再用「k 个正交源一致」判定，是「批量抽样 + 启发式阈值」，不是「级联检验」。用序贯检验（SPRT / e-process）替换它，好处不只是省算力：**中断安全**——无论在哪一步停下，结论在 α 水平上都有效，不会因为「问到一半」而给出被污染的定案。这也顺手把 R69 那条略显拍脑袋的证据纪律换成了一个可证明的统计保证。

**灵感 3（混合关键级 → 用「包含」替代「信任」来对付不可信）**
直觉：R69 的 MCG 想在环路内校准流模型的模态权重。但嵌入式安全认证的哲学恰恰相反：**不可认证的组件不该出现在安全论证的关键路径上**。所以不要试图证明模型可信，而是把它放进一个 LO 关键级分区，只让它的输出以**有界、带类型、可回放、带时效**的证据 token 形式，穿过一个 HI 关键级网关。模型再怎么幻觉，最多只能让系统「少获得一点效率」，不能让它越出安全包络。这就是**用包含（containment）替代信任（trust）**：不是问「这个模型准不准」，而是问「它错到什么程度都无所谓」。

**灵感 4（投机预问 → 交互可以预取）**
直觉：既然慢模态的答案要几秒，而未来几秒后大概率会遇到某类岔路，那就**现在就把问题问出去**，把答案放进一个带过期时间的缓存；真遇到就用，不遇到就丢掉。这与 CPU 的 speculative execution / prefetch 同构，也像人「提前问清楚、把话撂在这儿」。它把交互延迟从关键路径上移走，代价是可能白问——只要白问的成本被预算约束住，这就是纯赚的期权。

**灵感 5（时序即攻击面 → 时间投毒）**
直觉：一旦系统对时序敏感，攻击者根本不必伪造答案，只要**让答案变慢**：慢回答 → 错过截止期 → 系统反复退回保守 → 任务失败（拒绝服务）；或者更阴险，等系统已经降级后，再投递一个「迟到但看起来正确的旧答案」，诱使它恢复自信（重放/过期注入）。交互的**节奏**本身变成了可攻击的信道。所以必须配套：单调时间戳、防重放、时效半衰期，以及最关键的——**降级立即、恢复缓慢且需多证据**的棘轮（hysteresis）。安全只能被快速拿走，不能被轻易还回来。

**灵感 6（理论姿态 → R69 必须是本轮在「慢模态不存在、单分区、无投机」处的退化）**
直觉：任何新层若只是平行替换，就会多出一个需要独立信任的黑箱。本轮要求：把截止期 d→∞、模态延迟 L=0、单分区、无投机、无级联代入 TEMPO，得到的必须**逐指令等于 R69**。这样 R69 的全部结论（含其严格包含 R68）都被继承，而 TEMPO 只新增「时间维度」上的保守性。安全侧仍然不做任何让步。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（TEMPO-RAS 总览）** TEMPO-RAS = (TIA, DAV, CAS, MCS, SEP, SIP, DRT, SK, RAS-WM††)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **时序契约**：每个信息动作带契约 κ = (r, L, C, E, d, τ_stale)，只有在其到达概率、WCET 与预算同时满足时才可用；
(iii) **关键级隔离**：HI 控制路径的 WCET 预算不被 LO 认知负载侵占，LO 超载只触发降级、绝不导致 HI 超时；
(iv) **证据网关单调性**：进入 HI 的每个证据 token 必须通过 schema/范围/时效/来源校验，且安全恢复是棘轮式的（降级立即、恢复缓慢）。

**定义 311（时序标注动作空间）** 任务动作 a ∈ 𝒜_task；信息动作 g ∈ 𝒜_info 扩展为 g = (g_gaze, g_probe, g_ask) 并附加契约 κ_g。增广动作 ξ = (a, g) 再带时序标签。按是否可在当前决策截止期前等待，划分为**同步信息动作** 𝒜_info^sync（如注视，L ≪ d）与**异步信息动作** 𝒜_info^async（如语音提问，L 可能 > d）。

**定义 312（交互契约 Contract）** 对每个模态通道 ch，供给方（人/环境/传感器）承诺延迟分布 p_ch(L | load, human) 与可靠性 ρ_ch。系统**只依赖保守下界**：可用性 P_ch(d) = Pr[L ≤ d] 取在线估计的置信下界，而不是点估计。契约还包括最坏执行时间 C_ch（系统侧处理该证据的 WCET）、能量 E_ch、时效半衰期 τ_stale。

**定义 313（截止期感知 VoI，DAV）** 对信息动作 g：
VoI_d(g) = P_g(L ≤ d) · [H(M|o) − E_{y∼p(·|g,o)} H(M|o,y)] − c(g) − λ_E E(g)。
若 P_g(L ≤ d) = 0、预算不足或 g 未过认证，则 VoI_d(g) := 0。选择 g* = argmax_g VoI_d(g)。R69 的 VoI 是 d→∞、P=1、E=0 的退化。

**定义 314（模态级联与 anytime 证据，CAS）** 通道按「单位时间期望证据增益 / 单位成本」排序为 ch_1, ch_2, …。第 i 步累积对数似然比（或 e-value）Λ_i = Λ_{i−1} + log[p(y_i|m)/p(y_i|¬m)]。停止规则（任一满足即停）：后验确定（Λ 越界）、α 预算耗尽、时间/能量预算耗尽。停止时间 τ 是随机变量；要求证据过程为 **anytime-valid**：对任意停时 τ，Pr[接受错误模态] ≤ α（Ville 不等式）。

**定义 315（混合关键级调度，MCS）** 双关键级：HI 集合 = 安全控制、证据网关、看门狗、SK；LO 集合 = 流策略、LLM、聚类、DAV、CAS。预算 (B_HI, B_LO, B_energy)。调度采用时间触发 + 预算服务器：LO 只能在分配给它的时间窗内运行。若 LO 负载超过 B_LO（过载），立即触发关键级切换：挂起全部 LO，HI 仅以 R68 保守策略运行，λ 走棘轮。

**定义 316（分离与证据网关，SEP/TPG）** 系统划分为互不共享可变状态的 P_HI 与 P_LO；唯一通信通道是**时间触发网关** TPG。TPG 对每个 token 做固定 WCET 的校验：token = (evidence_type, value, source, t_mono, ttl, confidence, proof_hash)。校验失败 ⇒ 丢弃并写审计，绝不「尽力解释」。P_HI 从不直接读取模型原始输出、模态嵌入或概率分布。

**定义 317（证据时效与信念双缓冲）** 每个证据带单调时间戳 t_mono 与生存期 ttl。belief 双缓冲：控制路径读稳定副本 B_stable，认知分区写候选副本 B_cand；只有在 TPG 校验通过且 t_mono 未过期时，才原子切换 B_stable ← B_cand。过期证据视为「未到达」，不允许把旧信念重新拉高置信。

**定义 318（投机交互管道，SIP）** 用 R69 的 mode_head 与未来歧义预测器，对决策点 t+Δ 预测歧义，提前发出异步信息动作 g；答案存入带 ttl 的投机缓存。命中且未过期则供 t+Δ 使用，否则丢弃。投机预算 B_spec 与社交成本 c_spec 硬约束；投机失败不得触发任何降级或恢复。

**定义 319（降级棘轮 DRT）** 定义状态机 {NORMAL, DEGRADED, SAFE_HOLD, RECOVERING}。NORMAL→DEGRADED/SAFE_HOLD 立即；恢复到 NORMAL 需要连续 n 个正交一致证据且持续时间 ≥ T_recover，且期间无时序违规。保证对抗性抖动下无 chattering（有限时间内切换次数有界）。

**定义 320（时序投毒干扰集 ℰ_tempo）** 慢回答拒绝服务、过期/重放注入、时钟漂移与时间戳伪造、通道洪泛、优先级反转诱导、分区侧信道（通过共享缓存/带宽）。并入 AIC：ℰ_TEMPO = ℰ_FLUID × ℰ_tempo。

**定义 321（可认证安全内核 SK）** 确定性、无动态分配、定点运算、WCET 可静态分析的内核；输入只有经 TPG 校验的 token 与传感器原始值；输出 (mode, λ) 且 mode ∈ 认证候选集、λ ∈ [λ_floor, 1]。SK 是唯一被允许驱动执行器的组件。

**定义 322（证书 J_TEMPO）** J_TEMPO = (J_FLUID, wcet_report, deadline_miss=0, mode_switch_log, partition_attestation, gateway_reject_rate, staleness_violations=0, ratchet_trace, tempo_ver)。Valid ⇔ Valid(J_FLUID) ∧ 所有 HI 截止期满足 ∧ 分区证明有效 ∧ 无时效违规。

**定义 323（默认拒绝网关策略）** 任一字段越界、来源未知、时间戳非单调、ttl 过期、proof_hash 不匹配 ⇒ 拒绝。拒绝不是异常，而是正常的安全结果；拒绝率进入审计并反馈 MINT 的成本先验。

**定义 324（预算与能量分割）** 总能量预算 B_e 在 HI、LO、交互三处硬分割；交互能量 E(g) 计入 DAV 成本。能量不足时只削减 LO 与交互，不削减 HI。

**定义 325（时间感知的严格包含）** 称 R69 为 TEMPO 在边界 β_0 = {d→∞, L≡0, 单分区, 无投机, 无级联, ttl≡∞} 上的退化。命题：在 β_0 下 TEMPO 的每一条决策指令与 R69 相同。

**定义 326（回答到达模型）** 延迟分布 p(L|ch, load, human) 在线估计，并强制使用保守下界（例如经验分位数的 Clopper–Pearson 下界）；人类因负荷/情绪导致的延迟上漂移必须在契约中显式建模，否则该通道被降级为不可用。

**定义 327（认知层的调用许可）** LO 分区可以调用 R69 的 FMP/AUD/MINT，但其输出一律视为**建议**，必须经 SEP 才能影响 HI；若 TPG 拒绝率高或时效违规出现，认知层被整体禁用（等价于 R69 的「永不交互」边界）而 HI 继续安全运行。

# IP-268 SEP/TPG：固定 WCET 的证据网关（默认拒绝）
def tpg_validate(tok, now):
    if tok.source not in TRUSTED_SOURCES:            return REJECT
    if not monotonic(tok.t_mono, now):               return REJECT   # 时钟/重放
    if now - tok.t_mono > tok.ttl:                   return REJECT   # 过期
    if not in_range(tok.value, tok.evidence_type):   return REJECT
    if not hash_ok(tok.proof_hash):                  return REJECT
    return ACCEPT                                    # 唯一合法出口

# IP-265 DAV：截止期折扣的 VoI（答案赶不上 = 0）
def deadline_voi(g, modes, o, d, budget):
    if not budget.allow(g) or not c_ras_wm.certify_info(g, o): return 0.0
    p_arrive = contract_lower_bound(g.ch, d)         # 保守下界，不是点估计
    if p_arrive <= 0.0: return 0.0
    gain = entropy(modes.w) - expected_entropy(modes.w, g, o)
    return p_arrive * gain - cost(g) - LOW_CRIT_WEIGHT * g.energy

# IP-266 CAS：模态级联 + anytime 序贯证据（可随时停）
def modal_cascade(o, modes, budget, alpha):
    evidence, logLR = [], 0.0
    for ch in order_by_evidence_per_cost(CHANNELS, modes):
        if budget.exhausted() or alpha.spent(): break
        y = acquire(ch, o, deadline=budget.deadline(ch))   # 可被抢占/超时
        if y is None: continue                             # 超时=未到达
        logLR += log_likelihood_ratio(ch, y, modes)
        evidence.append((ch, y, logLR))
        if abs(logLR) >= alpha.threshold(): break          # 后验足够确定
    return decide_anytime(evidence, alpha)                 # 任意停时都有效

# IP-267/272 MCS + SK：时间触发调度，LO 过载即切关键级
def mixed_criticality_round(M, obs, now):
    # HI 路径：只读稳定 belief 与已验证 token，WCET 有静态上界
    tok   = M.tpg.take_one(now)                            # 最多一个，固定预算
    if tok is not None: M.belief.commit(tok)               # 原子、单调
    a_safe, lam = M.sk.step(M.sensor, M.belief.stable)     # 认证安全内核
    # LO 路径：预算服务器内尽力而为，超载不影响 HI
    if M.budget_server.lo_overrun():
        M.drt.downgrade("LO_OVERRUN")                      # 立即降级 + λ 棘轮
        return a_safe, max(lam, LAM_CONSERVATIVE)
    z = M.lo.trunk(obs)
    for g in M.sip.ready(now):                             # 投机答案先到先用
        if M.tpg_validate(g, now): M.belief.offer(g)
    g = M.dav.best(M.aud.modes(z), obs, deadline=now + M.slack)
    if g is not None:                                      # 异步：发出即返回
        M.sip.dispatch(g, decision_horizon=now + M.slack)
    return a_safe, lam

# IP-269 SIP：投机预问（白问不伤安全）
def sip_dispatch(self, g, decision_horizon):
    if not self.budget.take(g): return
    self.inflight.add(g)
    self.cache.schedule(deadline=decision_horizon + g.contract.ttl)

# IP-270 DRT：降级立即、恢复缓慢
def on_evidence(self, k_agree, clean_for):
    if self.state != NORMAL: return
    if self.state == RECOVERING and k_agree >= N and clean_for >= T_recover:
        self.state = NORMAL
    elif self.risk_high: self.state = DEGRADED

## 3. 推导

**引理 19（截止期折扣 VoI）** 设信息动作 g 的答案在决策截止期 d 前到达的概率为 p_d，则其相对 R69 同步 VoI 的实际期望收益满足 E[Δerror] = p_d·VoI_sync(g) − c(g) − λ_E E(g)，且当 p_d = 0 时严格非正。系：**慢模态在紧截止期下必须被自动排除，而不是被「更谨慎地采用」**；R69 的同步 VoI 是 d→∞ 的上界。

**引理 20（级联的 anytime 有效性）** 若每个通道的条件似然比在真实模态下构成非负鞅（A99：通道条件独立、标定满足名义覆盖率），则对任意停时 τ，Λ_τ 仍满足 Ville 不等式，故 Pr[接受错误模态] ≤ α。系：定义 314 的级联把 R69 的「k 个正交源一致」从启发式升级为**可证明的序贯检验**，且允许「问到一半就停」。

**引理 21（投机无伤与条件占优）** 设投机问题只进入 LO、带 ttl、且失败不触发任何状态变化。则 SIP 不改变当前决策分布（无伤）；若目标决策的提前量 Δ ≥ L 的高分位数、且投机预算未被挤占，则 SIP 的期望任务误差 ≤ 纯反应式交互。系：**交互延迟被移出关键路径，前提是预测歧义的位置大致正确**。

**定理 18（混合关键级无截止期违约）** 在 A100–A102（HI 任务 WCET 有静态上界、时间触发调度、LO 由预算服务器隔离）下，任意 LO 负载（含有界恶意负载）都不会使 HI 任务错过截止期；LO 过载只会触发关键级切换，且切换本身 WCET 有界。⇒ R69 定理 17 的「无突变」被扩展到**时间维度**：不只动作连续，**时序保证**也连续。

**定理 19（包含式安全 / 对 R69 最脆弱风险的正面回应）** 在 SEP 与 SK 下，P_LO（含流策略、模态后验、LLM、被投毒的回答）的任何行为，只能改变「在认证候选集内选哪个 mode」与「λ ∈ [λ_floor, 1] 的取值」，不能改变安全包络、不能删除认证候选、不能让 HI 读取未验证状态。因此 R69 的最大风险（模态幻觉/误导回答 → 自信地执行错误模态）在 TEMPO 中被**降格为效率损失**而不是安全违规。⇒ 这是「用包含替代校准」的形式化：不证明模型对，只证明模型错也无害。

**定理 20（严格包含 R69）** 在边界 β_0（定义 325）下，TPG 恒接受、CAS 退化为单批、SIP 为空、MCS 无过载、DRT 不触发，TEMPO 的闭环逐指令等于 R69；且对任意配置，TEMPO 的安全侧不弱于 R69（λ 下界相同，mode 候选集相同或更保守）。故 R69 是 TEMPO 的「零延迟 / 无限算力 / 单分区」退化。

**引理 22（时间投毒上界）** 对单调时间戳 + ttl + 默认拒绝的网关，重放/过期注入被接受的概率为 0；对慢回答 DoS，若 HI 的 WCET 与调度保证成立，则攻击只能降低任务成功率、不能造成安全违规，且降级棘轮使状态切换次数在任意时间窗内 ≤ ⌈T/T_recover⌉ + 2。系：**时序攻击的破坏力被限制在可用性维度，不进入安全性维度**。

## 6. 本轮最大风险

**一句话**：TEMPO 把「信任模型」换成了「信任时序与隔离」——**若 WCET 上界偏乐观、或分区在真实硬件上并不真正隔离（共享缓存、内存带宽、GPU、DMA、DVFS 让 LO 的负载悄悄侵占 HI 的时间），那么定理 18–19 的全部保证会在一台「看起来通过了认证」的机器上静默失效：证书说零违约，硬件却已经在关键那一刻迟到**；此时 R69 的错误最多是「问了不该问的」，而 TEMPO 的错误是「以为自己在安全地不问」——**安全论证被自己的计时器骗过，比模型幻觉更难发现**。

**次级风险与缓解**：
1. **延迟分布估计偏差**（人类疲劳/情绪使 L 上漂）→ 保守下界 + 契约失配即禁用该通道（定义 312/326）；
2. **级联的通道相关性**破坏 anytime 有效性 → 相关性校正 + e-value 而非朴素 LLR（定义 314、E306）；
3. **投机白问的社交成本** → B_spec/c_spec 硬约束 + E304 人类研究；
4. **TRUSTED_SOURCES 本身被攻破** → 来源证明 + 默认拒绝 + E309 故障注入；
5. **过度降级导致可用性崩溃** → 棘轮参数 (n, T_recover) 经 E313 标定，与「永不交互」边界对照。

def tpg_validate(tok, now):
    if tok.source not in TRUSTED_SOURCES:          return REJECT
    if not monotonic(tok.t_mono, now):             return REJECT   # 重放/时钟

def deadline_voi(g, modes, o, d, budget):
    if not budget.allow(g) or not c_ras_wm.certify_info(g, o): return 0.0
    p = contract_lower_bound(g.ch, d)              # 保守下界
    if p <= 0.0: return 0.0
    return (p * (entropy(modes.w) - expected_entropy(modes.w, g, o))
            - cost(g) - LOW_CRIT_WEIGHT * g.energy)

# IP-266 CAS：模态级联 + anytime 序贯证据
def modal_cascade(o, modes, budget, alpha):
    ev, lr = [], 0.0
    for ch in order_by_evidence_per_cost(CHANNELS, modes):
        if budget.exhausted() or alpha.spent(): break
        y = acquire(ch, o, deadline=budget.deadline(ch))   # 可抢占/超时
        if y is None: continue
        lr += log_likelihood_ratio(ch, y, modes); ev.append((ch, y, lr))
        if abs(lr) >= alpha.threshold(): break
    return decide_anytime(ev, alpha)                # 任意停时有效

def tempo_round(M, obs, now):
    tok = M.tpg.take_one(now)                        # 固定预算，最多一个
    if tok is not None: M.belief.commit(tok)         # 原子、单调
    a_safe, lam = M.sk.step(M.sensor, M.belief.stable)
    if M.budget_server.lo_overrun():
        M.drt.downgrade("LO_OVERRUN"); return a_safe, max(lam, LAM_CONSERVATIVE)
    z = M.lo.trunk(obs)
    for g in M.sip.ready(now):
        if M.tpg_validate(g, now): M.belief.offer(g)
    g = M.dav.best(M.aud.modes(z), obs, deadline=now + M.slack)
    if g is not None: M.sip.dispatch(g, M.slack)     # 发出即返回（异步）
    return a_safe, lam

## 4. 推导

**引理 19（截止期折扣 VoI）** `E[Δerror] = p_d·VoI_sync(g) − c(g) − λ_E E(g)`；`p_d=0` 时严格非正。系：慢模态在紧截止期下应被**自动排除**，而非「更谨慎地采用」；R69 的 VoI 是 d→∞ 上界。

**引理 20（级联 anytime 有效性）** 通道条件独立且标定满足名义覆盖（A99）时，Λ_τ 对任意停时满足 Ville 不等式 ⇒ `Pr[接受错误模态] ≤ α`。系：把 R69 的「k 个正交源一致」从启发式升级为可证明的序贯检验，并允许「问到一半就停」。

**引理 21（投机无伤与条件占优）** SIP 只进 LO、带 ttl、失败不改状态 ⇒ 当前决策分布不变；若目标决策提前量 Δ ≥ L 高分位且预算未被挤占，则期望任务误差 ≤ 纯反应式交互。

**定理 18（混合关键级无截止期违约）** A100–A102 下，任意 LO 负载都不使 HI 错过截止期；过载只触发有界 WCET 的关键级切换。⇒ R69 定理 17 的「无突变」扩展到时间维度。

**定理 19（包含式安全）** SEP+SK 下，P_LO（流策略、模态后验、LLM、被投毒回答）只能改变认证候选集内的 mode 选择与 λ∈[λ_floor,1]，不能改变安全包络、不能删除候选、不能污染 HI。⇒ R69 的最大风险（幻觉模态/误导回答 → 自信执行错误模态）被降格为**效率损失**，而非安全违规；这是「用包含替代校准」。

**定理 20（严格包含 R69）** 在 β_0 下 TPG 恒接受、CAS 单批、SIP 空、MCS 无过载、DRT 不触发 ⇒ 逐指令等于 R69；任意配置下安全侧不弱于 R69。R69 = TEMPO 的「零延迟 / 无限算力 / 单分区」退化。

**引理 22（时间投毒上界）** 单调时间戳 + ttl + 默认拒绝 ⇒ 重放/过期接受率为 0；慢回答 DoS 只损害可用性，不造成安全违规；棘轮使任意时间窗内切换次数 ≤ `⌈T/T_recover⌉+2`。

## 7. 本轮最大风险

**一句话**：TEMPO 把「信任模型」换成了「信任时序与隔离」——**若 WCET 上界偏乐观，或分区在真实硬件上并不真正隔离（共享缓存、内存带宽、GPU、DMA、DVFS 让 LO 负载悄悄侵占 HI 的时间），定理 18–19 会在一台「看起来已认证」的机器上静默失效：证书说零违约，硬件却已在关键那一刻迟到**；R69 的错误最多是「问了不该问的」，而 TEMPO 的错误是「以为自己在安全地不问」——**安全论证被自己的计时器骗过，比模型幻觉更难发现**。

**次级风险与缓解**：延迟分布上漂（保守下界 + 契约失配即禁用，定义 312/326）；通道相关性破坏 anytime 有效性（e-value + 相关校正，E306）；投机白问的社交成本（B_spec/c_spec + E304）；TRUSTED_SOURCES 被攻破（来源证明 + 默认拒绝 + E309）；过度降级致可用性崩溃（棘轮 (n,T_recover) 经 E313 标定）。
