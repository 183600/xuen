# 第 56 轮（承接第 55 轮想法与 v31 产物；灵感循环第 1 轮；本轮灵感：「意图理解」×「材料选型」）

> 第 55 轮已把“语义标签”升级为“语义-接触约束”，并给出全身语义生存核与联合证书。本轮再下探一层：**接触不仅要落在语义可信的表面上，还要落在“用户真正想要的那件事”和“材料真正承受得住的那种用法”上**。核心矛盾：**H24（意图-材料共轭性）**：从被动观测（语言/视觉/单次力）出发，`(意图 I, 材料 θ_m)` 到观测的映射是多对一的——同一个接触力既可解释为“意图是轻放、材料偏硬”，也可解释为“意图是按压、材料偏软”，而两种解释对动作可行性的结论可能相反；**H25（材料选型是控制决策而非感知标签）**：换一个接触对象（更粗糙的地面、更刚性的扶手、更柔顺的垫面）可能比继续提高感知精度更能扩张生存核，因此材料选型必须与意图、动作联合优化，而不是事后挑一个“识别置信最高”的物体。

## 0. 直觉与动机

**灵感 1（意图理解 → 意图是“接触签名”，不是目标标签）**
直觉：说“把杯子给我”并不足以决定动作；真正决定动作的是**以什么方式接触**。把意图写成 `I=(g,c,r)`：目标 `g`、接触模式 `c∈{抓取,托举,按压,倚靠,避让}`、材料需求 `r`（最低摩擦、最大压强、柔顺区间、易碎标记）。意图理解的输出应是**可标定、可落地为接触约束的分布** `P(I|o)`，而不是一个孤立类别。这样“听懂”才等价于“知道能怎么碰”。

**灵感 2（材料选型 → 可供性从 `κ(l,c)` 变为 `κ(l,c;θ_m)`）**
直觉：第 55 轮的 `κ` 是一张“语义→接触”的查表，隐含“同类标签材料一致”的强假设。材料参数 `θ_m=(μ_s,μ_k,E,ν,σ_y,ρ_load)` 一进入，摩擦锥变成 `FC(μ(θ_m))`、接触稳定性随柔顺 `E` 改变、承载上限由 `σ_y` 决定。于是**材料选型 = 在候选面/物体集合 `ℳ` 中，为给定意图挑一个使鲁棒生存核最大的接触对象**；它有时比“把分割再提准两个点”更值钱。

**灵感 3（意图-材料共轭 → 被动观测不可辨识，必须主动消歧）**
直觉：只看一眼，无法同时确定“他想干什么”和“这东西是什么材料”。轻触杯壁：力大可能是“杯子硬 + 意图轻”，也可能是“杯子软 + 意图重”。要拆开这对共轭变量，只能**用一次安全的探针去读材料力学响应**（点按、缓推、微载荷转移、轻微滑移测试）。但探针本身就是一次接触，于是“理解”第一次有了**接触成本与不可逆风险**。

**灵感 4（材料选型 → 在可信意图集上做鲁棒选择，而非期望最优）**
直觉：意图后验不是一个点，而是一个可信集 `A_ε`。若按 MAP 选材料，可能选到“在最可能意图下最优、但在次可能意图下灾难”的面。正确做法是对 `A_ε` 做 **minimax / CVaR 选择**：让所选 `(m,c)` 在**所有可信 `(I,θ_m)`** 下都不掉出生存核，得到比第 55 轮 `K(Σ)` 更强的 `K_rob(Σ,A_ε)`。

**灵感 5（证书 → 把“意图会改、材料会退化”写进可部署条件）**
直觉：人可以中途改主意（“别放那儿，放下”），材料也会在反复接触下退化（软垫压塌、纸箱折皱、涂层磨损）。因此联合证书必须携带**意图修订预算**与**材料退化预算 `ψ`**，并保留云边通道：云端存意图先验与材料本体，边端测真实力响应，边界/响应不一致时触发**重选材 + 重接地**。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（意图-接触签名）**
意图 `I=(g,c,r)`，其中 `g∈G` 为目标，`c∈C={抓取,托举,按压,倚靠,避让}`，材料需求 `r=(μ_req,p_max,[E_lo,E_hi],fragile)`。观测 `o=(ℓ,γ,d,x)`（语言、手势、示教、上下文）。意图理解是标定后的映射 `β:o↦Δ(ℐ)`；称其**可执行**，当且仅当存在约束生成算子 `Γ` 使 `Γ(I)⊆𝒞_contact`，即意图能被翻译成接触模式、力与位姿约束。

**定义 128（材料状态与材料条件可供性）**
材料状态 `θ_m=(μ_s,μ_k,E,ν,σ_y,ρ_load,ψ)`（静/动摩擦、杨氏模量、泊松比、屈服强度、承载、退化状态）。材料条件可供性 `κ(l,c;θ_m)∈[0,1]` 为在标签 `l`、接触模式 `c`、材料 `θ_m` 下接触成功的标定概率。语义-材料接触集
`C(Σ;θ_m)={(p,c) | κ(Σ̄(p),c;θ_m)≥θ_κ ∧ conf(Σ(p))≥θ_conf ∧ m_s(p)≥θ_m}`，
摩擦锥与接触力约束显式依赖材料：`λ∈FC(μ(θ_m))`。

**定义 129（意图-材料共轭歧义集与歧义间隙）**
给定观测 `o` 与力/运动响应 `y`，解释集
`A_ε(o,y)={(I,θ_m) | D(P(·|I,θ_m), P(·|o,y))≤ε}`。
对计划 `π`，记其在解释 `(I,θ_m)` 下的可行性/成功值为 `V_π(I,θ_m)`，定义
`Δ_amb(π)=max_{(I,θ_m)∈A_ε} V_π − min_{(I,θ_m)∈A_ε} V_π`。
`Δ_amb>θ_amb` 时计划**不可部署**——哪怕 MAP 解释下看起来很好。

**命题 1（被动共轭不可辨识性）**
若观测模型 `o=φ(I,θ_m)+ν` 在 `(I,θ_m)` 上多对一（存在 `(I,θ)≠(I',θ')` 使 `φ(I,θ)=φ(I',θ')`），则仅凭 `o` 无法判定 `V_π(I,θ)` 的符号；必须引入对 `θ_m` 敏感、对 `I` 条件化的响应观测 `y`（力/位移/滑移）。这正是定义 131 主动消歧的形式动机。

**定义 130（意图-材料鲁棒生存核）**
`K_rob(Σ,A_ε)={x | ∀(I,θ_m)∈A_ε, ∃u∈A_WB,λ: f(x,u,λ)=ẋ ∧ supp(λ)⊆C^+(Σ;θ_m) ∧ λ∈FC(μ(θ_m)) ∧ Γ(I) 被满足 ∧ x_{t+1}∈𝒳_safe}`。
当 `A_ε={(I*,θ*)}` 时退化为第 55 轮的 `K(Σ)`；一般地 `K_rob⊆K(Σ)`，是“对解释不确定性 ∀-鲁棒”的可行动集。

**定义 131（主动消歧探针策略）**
探针空间 `A_probe`，预算 `B_p=(F_p,T_p,irrev)`。选择
`a_p*=argmax_{a_p} I(I,θ_m; y_{a_p} | o, a_p)`，
s.t. `P(x_{t+τ_p}∈𝒳_safe)≥1−δ_p`、`cost(a_p)≤B_p`、且探针全程存在安全回退。探针结果 `y` 同时更新 `P(I|o)` 与 `θ_m` 置信椭球。

**定义 132（意图-材料联合证书）**
`J_im=(I_core, θ_m_core, A_core, Δ_amb, K_margin, ρ_im, ψ_budget, probe_evidence)`：
- `I_core` 为标定后的可信意图集（如 HPD），`θ_m_core` 为材料参数置信椭球，`A_core=A_ε∩(I_core×θ_m_core)`；
- `Δ_amb` 为定义 129 的歧义间隙，`K_margin=min_{x∈轨迹}dist(x,∂K_rob(Σ,A_core))`；
- `ρ_im=inf_{(I,θ)∈A_core}P(viable|I,θ)`，`ψ_budget` 为允许的材料退化量；
- `probe_evidence` 记录探针动作、力响应与对 `A_core` 的收缩量。
**可部署** 当且仅当：意图/材料后验标定通过、`Δ_amb≤θ_amb`、`K_margin≥θ_K`、`ρ_im≥ρ_min`、`ψ≤ψ_budget`。

**材料选型的决策形式**
`(m*,c*)=argmax_{(m,c)∈ℳ×C} min_{(I,θ_m)∈A_core} V(x,I,c,θ_m)`，并在次优解中按期望值破平，避免“为鲁棒而鲁棒”的过度保守。需要强调：选材不是感知输出，而是一个带鲁棒约束的控制决策。

def intent_contact_posterior(o, Sigma, kappa, prior):
    particles = sample_intents(prior, N)          # each = (g, c, r)
    for p in particles:

### IP-128 MCS（Material-Conditioned Selection）
```python
def material_conditioned_selection(Sigma, intent_post, probes):
    A = credible_set(intent_post, alpha=0.95)
    best = None
    for m in candidate_materials(Sigma):
        theta = estimate_material_ellipsoid(m, probes)   # mu, E, sigma_y ...
        for c in CONTACT_TYPES:
            pairs = robust_pairs(A, theta)               # (I, theta') over ellipsoid
            worst = min(viability(x, I, c, theta) for (I, theta) in pairs)
            exp_v = expect(viability(x, I, c, theta) for (I, theta) in pairs)
            if best is None or (worst, exp_v) > (best.worst, best.exp_v):
                best = Selection(m, c, theta, worst, exp_v)
    return best
```

### IP-129 IMA（Intent-Material Ambiguity）
```python
def intent_material_ambiguity(o, y, model, eps):
    explanations = []
    for (I, theta) in enumerate_credible(o):
        if divergence(model.response(I, theta), y) <= eps:
            explanations.append((I, theta))
    if len(explanations) <= 1:
        return 0.0, explanations
    vals = [model.viability(I, theta) for I, theta in explanations]
    return max(vals) - min(vals), explanations
```

### IP-130 ADQ（Active Disambiguation Query）
```python
def active_disambiguate(A_eps, x, safe_backup, B_p, delta_p):
    best, best_ig = None, -inf
    for a_p in probe_space(x):
        if cost(a_p) > B_p: continue
        if P_safe(x, a_p, horizon) < 1 - delta_p: continue
        if not has_backup(x, a_p, safe_backup): continue
        ig = expected_info_gain(A_eps, a_p)
        if ig > best_ig:
            best, best_ig = a_p, ig
    return best, best_ig        # 无安全高增益探针时返回 None，转保守回退
```

### IP-131 IMK（Intent-Material robust Viability Kernel）
```python
def robust_viability_kernel(Sigma, A_core, x0, n_scen, beta):
    K, margins = set(), []
    for x in sample_states(x0):
        feasible_all = True
        for (I, theta) in sample_scenarios(A_core, n_scen, beta):
            if not exists_control(x, I, theta, Sigma, mu(theta)):
                feasible_all = False; break
        if feasible_all:
            K.add(x); margins.append(dist_to_infeasible(x, A_core))
    return inner_hull(K), (min(margins) if margins else 0.0)   # 场景鲁棒内近似
```

### IP-132 IMC（Intent-Material Certificate）
```python
def intent_material_certificate(traj, Sigma, A_eps, budgets):
    I_core = credible_intents(A_eps, alpha=0.95)
    theta_core = material_ellipsoid(traj.probes)
    Delta = ambiguity_gap(A_eps)
    if Delta > budgets.theta_amb:
        return ('reject', 'ambiguity', Delta)
    K_margin = min_robust_margin(traj, Sigma, A_eps)
    if K_margin < budgets.theta_K:
        return ('reject', 'viability', K_margin)
    rho = robust_success(A_eps, traj)
    if rho < budgets.rho_min:
        return ('reject', 'robustness', rho)
    psi = estimate_degradation(traj, theta_core)
    if psi > budgets.Theta_psi:
        return ('reject', 'material_degradation', psi)
    return ('ok', CertIM(I_core, theta_core, Delta, K_margin, rho, psi, traj.probes))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| ICI | O(N·(|o|+|Ω|)) | O(N) | 意图后验标定、接触一致性 |
| MCS | O(|ℳ|·|C|·|A_core|·QP) | O(|ℳ|·|A_core|) | 材料椭球覆盖、鲁棒选择 |
| IMA | O(|A_ε|·|y|) | O(|A_ε|) | 解释集枚举完备、ε 标定 |
| ADQ | O(|A_probe|·|A_ε|) | O(|A_ε|) | 探针安全、信息增益估计 |
| IMK | O(|X|·N_scen·QP) | O(|X|) | 场景覆盖、内近似 sound |
| IMC | O(|轨迹|·|A_core|) | O(|A_core|) | 预算闭合、歧义间隙可测 |

**正确性定理（Intent-Material Robust Deployment Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** 意图后验经校准，ECE ≤ ε_cal；**(A34)** 材料椭球以概率 ≥ 1−α 覆盖真实 `θ_m`；**(A35)** 真实解释 `(I,θ_m)∈A_ε` 的概率 ≥ 1−δ；**(A36)** 探针 ∈ 安全集且始终存在回退；**(A37)** 材料退化 `ψ ≤ ψ_budget`。则部署后安全概率
```
P_safe ≥ 1 − P((I,θ_m)∉A_ε) − P(θ_m∉ellipsoid) − P(K_rob 内近似不 sound) − P(probe 不安全) − P(ψ > ψ_budget)
```
且当 `A_core` 收缩为单点、材料固定、不做探针时，退化为第 55 轮的 `P_safe` 下界。

**选型引理（Selection Dominance）**
若候选 `(m,c)` 的鲁棒值 `min_{A_core}V` 不低于默认 `(m_0,c_0)`，且期望值不劣，则替换不降低部署安全下界；否则保持默认。这把“材料选型”约束为**不会让证书变差**的动作，避免为追求分数而引入新风险。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 意图后验过度自信（语言/手势歧义） | 高 | 温度/分位数校准 + 歧义集专门校准 + 拒部署 |
| 材料椭球在未见材质上不覆盖 | 高 | 材质分层先验 + 在线力响应更新 + 保守膨胀 |

| 选材改变分布引发负迁移 | 中 | 选型支配引理 + 跨材料回归测试 |

## 6. 本轮最大风险

**一句话**：意图-材料共轭意味着系统可能“目标听对了却选错材料”或“材料看对了却会错意图”，而被动观测对二者多对一；一旦可信解释集欠覆盖、或探针本身不安全，联合证书就会在“错误解释下才成立”的伪鲁棒核里放行动作，第一次不可逆接触便是揭穿它的实验——因此必须以 **歧义集校准 + 安全探针 + 选型支配约束** 三重护栏，宁可拒部署，绝不把“意图的高置信”当作“材料与用法的已证实”。

### IP-128 MCS

```python
def select_material_contact(Sigma, intent_post, probes):
    A = credible_set(intent_post, alpha=0.95)
    best = None
    for m in candidate_materials(Sigma):
        theta = estimate_material_ellipsoid(m, probes)
        for c in CONTACT_TYPES:
            pairs = robust_pairs(A, theta)     # 椭球内的 (I, theta')
            worst = min(viability(x, I, c, theta) for I, theta in pairs)
            exp_v = expect(viability(x, I, c, theta) for I, theta in pairs)
            if best is None or (worst, exp_v) > (best.worst, best.exp_v):
                best = Selection(m, c, theta, worst, exp_v)
    return best
```

### IP-129 IMA

```python
def ambiguity(o, y, model, eps):
    expl = [(I, th) for (I, th) in enumerate_credible(o)
            if divergence(model.response(I, th), y) <= eps]
    if len(expl) <= 1:
        return 0.0, expl
    vals = [model.viability(I, th) for I, th in expl]
    return max(vals) - min(vals), expl
```

### IP-130 ADQ

```python
def active_disambiguate(A_eps, x, safe_backup, B_p, delta_p):
    best, best_ig = None, -inf
    for a_p in probe_space(x):
        if cost(a_p) > B_p: continue
        if P_safe(x, a_p, horizon) < 1 - delta_p: continue
        if not has_backup(x, a_p, safe_backup): continue
        ig = expected_info_gain(A_eps, a_p)
        if ig > best_ig:
            best, best_ig = a_p, ig
    return best, best_ig          # None -> 保守回退
```

### IP-131 IMK

```python
def robust_kernel(Sigma, A_core, x0, n_scen, beta):
    K, margins = set(), []
    for x in sample_states(x0):
        ok = all(exists_control(x, I, th, Sigma, mu(th))
                 for I, th in sample_scenarios(A_core, n_scen, beta))
        if ok:
            K.add(x); margins.append(dist_to_infeasible(x, A_core))
    return inner_hull(K), (min(margins) if margins else 0.0)
```

### IP-132 IMC

```python
def intent_material_certificate(traj, Sigma, A_eps, budgets):
    I_core = credible_intents(A_eps, alpha=0.95)
    theta_core = material_ellipsoid(traj.probes)
    Delta = ambiguity_gap(A_eps)
    if Delta > budgets.theta_amb:
        return ('reject', 'ambiguity', Delta)
    K_margin = min_robust_margin(traj, Sigma, A_eps)
    if K_margin < budgets.theta_K:
        return ('reject', 'viability', K_margin)
    rho = robust_success(A_eps, traj)
    if rho < budgets.rho_min:
        return ('reject', 'robustness', rho)
    psi = estimate_degradation(traj, theta_core)
    if psi > budgets.Theta_psi:
        return ('reject', 'material_degradation', psi)
    return ('ok', CertIM(I_core, theta_core, Delta, K_margin, rho, psi, traj.probes))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ICI | O(N·(|o|+|Ω|)) | O(N) | 后验标定、接触一致性 |
| MCS | O(|ℳ|·|C|·|A_core|·QP) | O(|ℳ|·|A_core|) | 椭球覆盖、鲁棒支配 |
| IMA | O(|A_ε|·|y|) | O(|A_ε|) | 解释集完备、ε 标定 |
| ADQ | O(|A_probe|·|A_ε|) | O(|A_ε|) | 探针安全、IG 估计 |
| IMK | O(|X|·N_scen·QP) | O(|X|) | 场景覆盖、内近似 sound |
| IMC | O(|轨迹|·|A_core|) | O(|A_core|) | 预算闭合、间隙可测 |
| IMR | O(|o|) | O(1) | 修订阈值、重接地收敛 |
| MDG | O(|轨迹|) | O(1) | 退化估计、预算约束 |

**正确性定理（Intent-Material Robust Deployment Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** 意图后验 ECE ≤ ε_cal；**(A34)** 材料椭球以概率 ≥ 1−α 覆盖真实 `θ_m`；**(A35)** 真实解释 `(I,θ_m)∈A_ε` 的概率 ≥ 1−δ；**(A36)** 探针 ∈ 安全集且始终存在回退；**(A37)** 退化 `ψ ≤ ψ_budget`。则
```
P_safe ≥ 1 − P((I,θ_m)∉A_ε) − P(θ_m∉ellipsoid) − P(K_rob 内近似不 sound) − P(probe 不安全) − P(ψ > ψ_budget)
```
当 `A_core` 收缩为单点、材料固定、不做探针时，退化为 v31 的 `P_safe` 下界。

**命题 1（被动共轭不可辨识）**
若被动观测 `o=φ(I,θ_m)+ν` 多对一，则存在 `(I,θ)≠(I',θ')` 使 `V_π` 符号相反而 `o` 相同；故仅靠视觉/语言无法判定计划安全，必须用对材料敏感的力响应 `y` 消歧。

**选型引理（Selection Dominance）**
若 `(m,c)` 的鲁棒值 `min_{A_core}V` 不低于默认 `(m_0,c_0)` 且期望值不劣，则替换不降低安全下界；否则保持默认。选材被约束为“不使证书变差”的动作。

## 6. 本轮最大风险

**一句话**：意图-材料共轭让系统可能在“听对目标、选错材料”或“看对材料、会错意图”两种同观测状态下都给出高置信，而被动观测对二者多对一；一旦可信解释集欠覆盖或探针不安全，IMC 会在“错误解释下才成立”的伪鲁棒核里放行动作，第一次不可逆接触便是揭穿它的实验——因此必须以 **歧义集校准 + 安全探针 + 选型支配约束** 三重护栏，宁可拒部署，绝不把“意图的高置信”当作“材料与用法的已证实”。
