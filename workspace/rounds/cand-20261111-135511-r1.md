# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环新一轮；本轮灵感：「决策规划」×「热管理」）

> 第 54 轮把动作空间剖面化、技能组合可判定化、云边协同闭环化，形成动作-鲁棒性双证书。本轮引入两个此前被当作“工程外设”的维度：**决策规划的时间尺度**与**热管理的状态惯性**。核心矛盾：H22：决策规划默认算力/执行带宽恒定，而热节流（thermal throttling）会随温度非线性削减算力与动作带宽，使同一策略在不同热状态下可行性不同；H23：热状态是慢变量、具惯性与迟滞，决策是快变量，二者构成双时间尺度耦合闭环，短视规划会诱发“热失控—节流—更长计算—更多发热”的正反馈。

## 0. 直觉与动机

**灵感 1（热是慢速预算货币 → 把热管理写进决策约束）**
直觉：把热当作一种**慢速、不可即时再生、带迟滞的预算货币**。快决策（10–100ms）花的是“热预算”，慢热管理（分钟级）负责“充值”（被动散热/主动风扇）。于是规划从 MDP 变成**带热预算约束的 CMDP**：不再只问“能不能做”，而问“在剩余热预算与冷却时间常数下，这条动作序列是否可持续”。

**灵感 2（热退化动作剖面 → α 与 ρ 变成 θ 的函数）**
直觉：第 54 轮的 `α_S(a)` 是静态的，但电机/SoC 过热会让高扭矩动作不可持续、感知算力下降让鲁棒性 ρ 下降。所以 `α_S(a|θ)`、`ρ_S(d|θ)` 应按热状态**退化（derating）**。动作空间的可行性边界是热状态的函数，而不是常数——这把动作空间从“静态集合”升级为“热参数化族”。

**灵感 3（热记忆与迟滞 → 朴素马尔可夫会系统性失败）**
直觉：只记当前温度 `θ_t` 不够——热量在绕组/壳体/电池之间存在**内部梯度与热惯性**，即“热记忆”。同一 `θ_t` 可能来自升温还是降温路径，后续升温速率不同。因此热状态必须扩维为 `(θ_surf, θ_core, 历史窗)`，否则规划会系统性低估峰值，把“表面凉、核心烫”误判为安全。

**灵感 4（双时间尺度热调度 → 云端长时预算分配 + 边端短时重规划）**
直觉：利用时间尺度分离：云端做**分钟级热调度 `T_dispatch`**（把热预算分配给未来若干决策回合，做全局、跨设备的热公平分配），边端做**毫秒级热感知重规划**（在预算内选动作、逼近阈值时降级）。热是慢通道，云边同步成本低、带宽小，反而比高频状态更**适合**云边协同。

**灵感 5（热-鲁棒性-动作三证书融合）**
直觉：把热可行性证书 `TFC` 并入第 54 轮联合证书 `J`，形成 `(ρ(·|θ), A_cert, γ_ce, TFC)` 的**三元证书**；部署前提增加“热包络不越界、预测误差受控、节流风险受限”。热不再是被动散热，而是与动作、鲁棒性并列的**一等规划资源**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（热状态与集总热动力学）**
热状态 `θ_t∈Θ⊆ℝ^m`（各执行器/SoC/电池节点温度）。集总 RC 模型：
```
C_i · dθ_i/dt = P_i(t) − (θ_i − θ_amb)/R_i
```
离散化：`θ_{t+1} = A_θ θ_t + B_θ ℓ_t + c_θ`，其中 `A_θ=diag(e^{−Δt/(R_iC_i)})`，`c_θ` 为环境耦合项，`τ_th,i=R_iC_i` 为热时间常数（分钟级）。`ρ(A_θ)<1`，故热系统是**收缩的**——这是后面误差界可证的根源。

**定义 122（热负载、热预算与热记忆）**
动作 `a` 在状态 `s` 的热负载 `ℓ(a,s)∈ℝ_+^m`（单位时间温升）。H 步累计温度：
```
θ_H = A_θ^H θ_0 + Σ_{k=0}^{H-1} A_θ^{H-1-k} B_θ ℓ_k
```
软/硬上限 `Θ_soft < Θ_max`。热裕度 `m_θ(t)=Θ_soft−θ_t`，热债 `D_θ=Σ_t max(0, θ_t−Θ_soft)`。**热记忆状态** `h_t=(θ_t,θ_{t-1},…,θ_{t-w})` 或物理分解 `(θ_surf,θ_core)`，用于捕捉迟滞与内部梯度。

**定义 123（Thermo-MDP，热约束马尔可夫决策过程）**
`M_θ=(S×Θ×H, A, P, R, C_θ)`，可行策略集：
```
Π_θ = { π : Pr(θ_t ≤ Θ_max, ∀t≤H) ≥ 1−δ }
```
目标：
```
max_π E[Σ_t γ^t R]  s.t.  Pr(θ_t≤Θ_max)≥1−δ  ∧  (第 53/54 轮鲁棒性与动作约束)
```
用拉格朗日松弛 `max E[ΣR] − λ_θ·E[D_θ]`，`λ_θ≥0` 即**热影子价格**，度量“一度热债值多少任务回报”。

**定义 124（热退化动作剖面与热退化鲁棒性）**
```
α_S(a|θ) = α_S(a) · g(θ),        g: Θ→[0,1]
ρ_S(d|θ) = ρ_S(d) · q_d(θ)
```
`g,q_d` 为热退化函数，要求单调不增、在 `Θ_soft` 之后快速下降，由热扫频标定。当 `θ≥Θ_max` 时 `g=0`（动作物理不可行）。

**定义 125（热可行性证书 TFC）**
```
TFC = (θ_0, θ̂_{0:H}, m_θ^min, t_cool, τ_throttle, δ_model, h_t)
```
其中 `θ̂_{0:H}` 为预测温度轨迹，`m_θ^min` 为最小裕度，`t_cool` 为所需冷却时间，`τ_throttle` 为预测节流时长，`δ_model` 为热模型误差界。可行条件：
```
m_θ^min ≥ 0 ∧ δ_model ≤ Δ_model ∧ Pr(throttle) ≤ β_thr ∧ t_cool ≤ T_slack
```

**定义 126（云边热协同契约）**
```
C_θ,ce = (θ_model_c, θ_state_e, T_dispatch, ε_θ, Loop_θ)
```
- `θ_model_c`：云端全局热模型（跨设备、长时）；
- `θ_state_e`：边端实测热状态与节流事件；
- `T_dispatch`：τ_th 量级的热预算调度（把预算分配给未来回合/设备）；
- `ε_θ`：热状态陈旧度上界（慢变量，允许较大但需显式）；
- `Loop_θ`：当 `|θ_e−θ_c|>ε_θ` 或 `m_θ<τ_m` 触发热感知重规划。

## 2. 关键算法 伪代码

### IP-121 TSE（Thermal State Estimation）

```python
def thermal_ekf(theta_prev, P, heat_input, y_sensor, model):
    # model 提供 A_theta, B_theta, c_theta, H_obs；y = H_obs·theta + noise
    theta_pred = model.A @ theta_prev + model.B @ heat_input + model.c
    P_pred = model.A @ P @ model.A.T + model.Q
    K = P_pred @ model.H.T @ inv(model.H @ P_pred @ model.H.T + model.R)
    theta_hat = theta_pred + K @ (y_sensor - model.H @ theta_pred)
    P = (np.eye(len(theta_prev)) - K @ model.H) @ P_pred
    model.adapt(theta_hat, y_sensor)   # 遗忘因子最小二乘辨识 R_i,C_i（老化/风扇漂移）
    return theta_hat, P
```

### IP-122 TAP（Thermal-Aware Planning）

```python
def thermal_aware_plan(s, theta, h, H, R_fn, lam_theta):
    def shaped_reward(s, a, theta, h):
        theta_next = predict_theta(theta, h, load(a, s))
        debt = max(0.0, max(theta_next) - Theta_soft)
        return R_fn(s, a) - lam_theta.value * debt, theta_next

    plan = mpc_search(s, (theta, h), H, shaped_reward,
                      feasible=thermal_feasible)
    tfc = TFC(plan, theta, h)
    if tfc.m_min < 0 or tfc.delta_model > Delta_model:
        return ('reject', 'thermal_infeasible', tfc)
    return ('ok', plan, tfc)
```

### IP-123 TDC（Thermal Derating Calibration）

```python
def thermal_derating_sweep(skill, theta_grid, actions, t_hold):
    prof = {}
    for theta in theta_grid:
        for a in actions:
            ok, conf = sustained_execute(skill, a, theta, t_hold=t_hold)
            prof[(a, theta)] = conf if ok else 0.0
    g = fit_monotone_noninc(prof, theta_grid)   # 单调不增 + 平滑约束
    return g, prof
```

### IP-124 THC（Thermal-Aware Composition）

```python
def thermal_composition_feasible(path, theta0, model, Theta_soft, T_slack):
    theta, traj = theta0, []
    for skill, a in path:
        theta = model.step(theta, load(skill, a))       # 含热记忆 h 的推演
        traj.append(theta)
        if max(theta) > Theta_soft:
            cool = cooldown_time(theta, Theta_soft)
            if cool > T_slack:
                return False, TFC(theta0, traj)
            theta = wait_cool(theta, cool)              # 插入冷却等待
    return True, TFC(theta0, traj)
```

### IP-125 TSD（Thermal Scheduling / 云边热调度）

def thermal_dispatch(cloud_model, fleet_state, horizon_minutes):

### IP-126 TJC（Thermo-Joint Certificate）

```python
def thermo_joint_certificate(skill_seq, theta0, H, gamma_ce,
                             delta_a_budget, rho_min):
    rho_theta = {d: min(robustness_spectrum(s, theta=theta0)[d]
                        for s in skill_seq) for d in dimensions}
    A_core = reduce(intersection, [s.alpha_theta(theta0) for s in skill_seq])
    tfc = thermal_predict(skill_seq, theta0, H)
    if (tfc.m_min < 0 or tfc.delta_model > Delta_model
            or tfc.throttle_risk > beta_thr):
        return ('reject', 'thermal_infeasible', tfc)
    if min(rho_theta.values()) < rho_min:
        return ('reject', 'robustness_fail', rho_theta)
    return ('ok', JointCert(rho_theta, A_cert=(A_core, buffer_zone(A_core)),
                            gamma_ce=gamma_ce, tfc=tfc))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| TSE | O(m³·T) | O(m²) | RC 模型可辨识、传感器可观测 |
| TAP | O(b^H·m)（树搜索）/ O(H·m²)（MPC） | O(H·m) | 热预测单调、λ_θ 收敛 |
| TDC | O(|A|·|Θ_grid|·T_hold) | O(|A|·|Θ_grid|) | 退化函数单调不增、扫频覆盖 |
| THC | O(|path|·m) | O(|path|·m) | 热记忆推演准确、冷却可达 |
| TSD | O(|fleet|·H_min·m) | O(|fleet|·m) | 加权公平、预算守恒 |
| TJC | O(|S|·|A| + H·m²) | O(|A|+H·m) | TFC sound、三项预算闭合 |

**正确性定理（Thermal-Aware Decision-Planning Soundness）**
假设第 53/54 轮 (A22)–(A28) 成立；新增
**(A29)** 集总热模型在 H 步内 ε-准确：`‖θ̂_t−θ_t‖≤ε_model, ∀t≤H`；
**(A30)** 退化函数 `g` 单调且 `L_g`-Lipschitz；
**(A31)** 云边热状态陈旧度 `≤ε_θ`。
则对任意满足 TFC 的计划：
```
P_success ≥ 1 − Σ_d(1−ρ_min(d|θ)) − β_E − P(δ_a>Θ_a)
            − P(throttle>β_thr) − P(ε_model>Δ_model)
```
且热约束违反率 `≤ δ + P(ε_model>Δ_model)·L_g`。

**证明要点**：`ρ(A_θ)<1` 使预测误差沿 RC 动态收缩，峰值误差被 `ε_model/(1−ρ(A_θ))` 放大但有界；`g` 的 Lipschitz 性把温度误差线性映射为动作可行域误差；`λ_θ` 的拉格朗日对偶保证 CMDP 约束在期望意义下满足。核心是**热误差有界 + 退化有界 ⇒ 计划可行性可传递**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 集总模型失配/老化漂移 | 高 | 在线辨识 + 集员误差界 + 保守裕度 |

## 6. 本轮最大风险

**一句话**：把热写进决策规划的关键不是“多一个温度约束”，而是承认热是**慢速、带记忆、非马尔可夫**的资源，其风险在于集总模型失配与内部热点不可观测会同时污染 `θ̂`、`α(·|θ)` 与 `ρ(·|θ)`，一旦“表面凉、核心烫”被误判为安全，规划器会在长时任务中累积热债并触发不可逆降频；因此必须用**在线辨识 + 集员误差界 + 热记忆扩维 + 迟滞断路器**共同封顶，宁可少做一步，绝不把“热模型的名义安全”当作真实安全。

def thermal_composition_feasible(path, theta0, model, Theta_soft, T_slack):
    theta, traj = theta0, []

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TSE | O(m³·T) | O(m²) | RC 可辨识、观测可及 |
| TAP | O(b^H·m) / O(H·m²) | O(H·m) | λ_θ 收敛、热预测单调 |
| TDC | O(|A|·|Θ_grid|·T_hold) | O(|A|·|Θ_grid|) | 退化函数单调不增 |
| THC | O(|path|·m) | O(|path|·m) | 热记忆推演准确、冷却可达 |
| TSD | O(|fleet|·H_min·m) | O(|fleet|·m) | 预算守恒、加权公平 |
| TJC | O(|S|·|A|+H·m²) | O(|A|+H·m) | 三元预算闭合、TFC sound |

**正确性定理（Thermal-Aware Decision-Planning Soundness）**
假设第 53/54 轮 (A22)–(A28) 成立；新增 **(A29)** 热模型 ε-准确：`‖θ̂_t−θ_t‖≤ε_model`；**(A30)** `g` 单调且 `L_g`-Lipschitz；**(A31)** 云边热陈旧度 `≤ε_θ`。则：
```
P_success ≥ 1 − Σ_d(1−ρ_min(d|θ)) − β_E − P(δ_a>Θ_a)
            − P(throttle>β_thr) − P(ε_model>Δ_model)
```
热约束违反率：
```
Violation ≤ δ + P(ε_model>Δ_model)·L_g
```
关键：**热误差收缩有界（ρ(A_θ)<1）**、**退化 Lipschitz**、**λ_θ 对偶约束**，三者共同保证热可行性可传递。

## 6. 本轮最大风险

**一句话**：把热写进决策规划的关键不是“多一个温度约束”，而是承认热是**慢速、带记忆、非马尔可夫**的资源，其风险在于集总模型失配与内部热点不可观测会同时污染 `θ̂`、`α(·|θ)` 与 `ρ(·|θ)`，一旦“表面凉、核心烫”被误判为安全，规划器会在长时任务中累积热债并触发不可逆降频；因此必须用**在线辨识 + 集员误差界 + 热记忆扩维 + 迟滞断路器**共同封顶，宁可少做一步，绝不把“热模型的名义安全”当作真实安全。
