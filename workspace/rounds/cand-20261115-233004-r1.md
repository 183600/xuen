# 第 11 轮（新灵感循环第 2 轮；本轮灵感：「触觉感知」×「材料选型」）

> **基线**：第 10 轮 MetricVoiceGauge-STF-NRB-LS（定义 540–548；引理 87–91；实验 E571–E590）。
> 本轮纪律：**接触为独立见证 + 材料为条件包络 + 取证不扩权**。两个灵感共同治理 v10 自认的最大风险——**单一视觉-语义分割面 τ_sem 的承重性**：对抗纹理/长尾语义新颖可在 ν≤τ_sem 下同时骗过语义守卫与前向模型，β_STF 按非显著误差校准，失效比 v9 更隐蔽；INT8 进一步压缩安全边际。触觉提供**不同失效指纹的物理通道**，材料选型把“接触安全”从硬件经验变成**可证包络**。铁律不变：任一新模块失效 ⇒ 退回 v10 等价行为或更保守剖面 Π_t，动作集绝不扩大。

## 0. 直觉与动机

**灵感 1（触觉感知 → 从“看起来像”到“碰起来是”）**
直觉：v10 的 STF 无论多精细，仍是**视觉-语义通道**——它判断“这块纹理像什么”，而不是“这个物体实际是什么”。对抗纹理与长尾新颖恰好攻击嵌入流形，τ_sem 只是一个经验切点。触觉是物理上不同的通道：法向/切向力、接触几何、接触刚度、微滑移振动、热传导。纹理可以被画出来，接触阻抗不能只靠“看起来”伪造；它测的是材料的真实力学/热学响应（在传感器带宽与量程内）。核心创新：**触觉见证器（TactileWitness, TW）**——把触觉观测变成三个可证量：(i) 安全相关材料属性估计 ψ̂；(ii) 材料后验与可信集 M_ε；(iii) **材料创新度 μ**（视觉类原型预测的材料属性与实测属性之间的马氏距离）与**滑移裕量 s_slip**。但必须诚实：触觉只在接触后出现，它不能替代接触前的避障；它保护的是**不可逆的接触决策**（抓取、推、交接、工具使用），并把“语义被骗”的后果限制在**首次取证的低力探测**内。为此新增**有护探测（GuardedTouch）**：在不可逆加力前，先以对“所有先验可接受材料”都安全的力做一次短探测；只有后验收缩、滑移裕量与材料创新度都过门，才沿**力升级梯**逐级加力。

**灵感 2（材料选型 → 从经验选材到证据预算下的条件包络）**
直觉：材料选型通常被当作离线硬件问题（软硬、摩擦、耐磨、传感灵敏度），但它其实是**接触安全证书的定义域**：同样 20N 的法向力，落在软硅胶、硬塑料、薄玻璃、人手上，峰值压力、摩擦锥、破损风险完全不同。Ashby 式多目标选材（约束 + 材料指数 + Pareto 前沿）给了现成语言，但缺少“证据”：材料属性有不确定度、批次差异、磨损漂移、表面涂层与本体不一致。核心创新：**材料条件包络（MaterialConditionedEnvelope, MCE）**——对机器人指尖材料 a 与物体材料（或其**接触安全等价类** [b]_τ）给出一张可证包络 E(a,b) = (F_max, p_max, μ_min, v_slip_max, 磨损预算)；未知材料取**可信集上的交** E(a,M_ε)=∩_{b∈M_ε}E(a,b)，因而“不知道”只会更保守，绝不会更乐观。离线选材则升级为**带证据预算的稳健选材**：每个候选材料必须携带属性置信域、测试覆盖与退化路径（材料证据台账 MEL），且要同时满足**安全（软接触降峰值压力）**与**可辨识（指尖太软会把物体刚度信息淹没）**这对矛盾。

**咬合**：TW 在线测材料并检测“表里不一”，MCE 把测得材料转成力/压力/滑移的硬包络，GuardedTouch 把“取证动作”本身也纳入包络并逐级解锁力。三者把 v10 的 Ĉ⁺ 升级为**接触证书 Ĉ_t^T = (ĝ_min, ê_max, γ̂_grasp^T, β_STF, n_t, E_ops, μ̂, s_slip, h_t)**。关键不是“再加一个传感器”，而是把 v10 的单通道经验切点换成**双通道独立证据 + 物理包络 + 有界升级**：视觉可以继续被骗，但后果被限制在探测力内，且材料不匹配会在力升级前被触觉揭穿。

## 1. 研究问题（轮次升级版）

- **Q1（独立接触见证）**：如何把触觉观测形式化为与视觉语义**失效指纹独立**的证据通道，使 (a) 安全判定只做合取、绝不用加权平均抬高置信；(b) 材料不匹配在首次有护接触后被检出，检出率 ≥99%（对可接触区分的等价类）；(c) 触觉不可用/饱和/漂移时行为退回 v10 或更保守，而不是悄悄放宽？
- **Q2（材料条件包络）**：如何把离线选材与在线材料识别统一为带不确定度的条件包络，使 (a) 未知材料只取可信集交集，真实材料落在可信集内时运行包络 ⊆ 真实材料包络（概率 ≥1−ε）；(b) 选材同时满足压力安全、摩擦/滑移、耐磨与**刚度可辨识性**；(c) 每次选材/识别都有证据预算与出处，无证据的材料不得上线？
- **Q3（有界取证与退化）**：如何设计力升级梯与探测策略，使“为取证而接触”的最大接触冲量有可证上界，且在 TW/MCE/GTP/MEL 任一失效时动作集 ⊆ v10、50Hz 与 25W 预算不破？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 接触独立见证律（Contact Independent Witness, TW）**
触觉是与视觉-语义**独立**的安全证据通道；安全判定只许合取（两者都过才过），禁止加权平均/投票式融合抬高置信；触觉不可用时不得用视觉高置信“补位”，而应退回 v10 或更保守剖面 Π_t。新增可观测（材料后验、滑移、探测事件）只进审计与门控，不回灌成“放宽裕量”的理由。

**P17 材料条件包络律（Material-Conditioned Envelope, MCE）**
任何接触动作的力/压力/滑移/磨损上限，必须由**已认证材料对**的包络给出；未知或表里不一 ⇒ 取可信集交集的最坏包络（只会更小）；离线选材必须携带属性置信域、测试覆盖与退化路径（MEL），无证据的材料不得进入部署链。包络对“更多证据”单调：后验收缩只许在真实材料包络内放宽，绝不许越过它。

**P18 探测有险律（Probing Has Risk, GTP）**
主动触觉探测本身是接触动作；探测计划必须在**最坏先验材料**下满足包络，并受“信息增益 vs 风险”预算约束；VOI 低于探测成本、或不存在安全探测时，正确行为是**弃权/求助**（非接触或人工），而不是“碰一下看看会不会坏”。力升级只能逐级、可回退，任何一级不满足证书即停在当前级或安全撤离。

## 3. 与基线的接口（如何退化）

- **TW 失效**（掉线/饱和/标定过期/接触特征不可信）⇒ h_TW=0：只允许对已注册且材料类已认证的物体接触，F_n≤F_0，禁止自主升级，K_eff≤2；未知材料 ⇒ 不接触；行为 ⊆ v10；
- **MCE 失效**（材料库/标定不可用、后验不可算）⇒ 取全材料最坏包络；包络为空 ⇒ 不接触（接触无关的导航/语音路径仍按 v10）；
- **GTP 失效**（探测规划超时/无安全探测）⇒ 停在当前力级或安全撤离，不新增抓取/推压；
- **MEL 缺口**（漏写/校验失败/材料证据过期）⇒ 下一块强制 Π_t 并标记，直到重验；
- STF 失效 ⇒ K_eff←1、β←β_base（v10 Level-1）；NRB 失效 ⇒ Π_r（v10 Level-2）；AC/ID/MW/v8 沿 v9/v10 原退化链。

## 4. 预期贡献

1. **独立接触见证**：TW + 材料创新度 μ + 滑移裕量，把 v10 的单语义分割面改为“视觉-语义 ∧ 触觉-材料”的合取证据；给出非扩张性与不匹配检出界（引理 92）；
2. **有界取证**：力升级梯把“静默全力抓错”改造成“低力探测—检测—中止/回退”，首次取证前接触冲量有可证上界（引理 93）；
3. **材料条件包络与稳健选材**：可信集交集包络 + Ashby/可辨识性联合选材 + 证据台账，未知材料只会更保守（引理 94–95）；
4. **E591–E610** 覆盖材料识别、表里不一、滑移、包络覆盖、探测风险、非补偿消融、磨损长跑、传感器退化、对抗材料与竞赛回归。

## 5. 本轮最大风险

**一句话**：触觉证据总在第一次接触之后才到，而第一次接触本身已不可逆——若对象是“薄软壳包裹刚性/高质心本体”、或触觉在饱和/磨损下把壳层误判为本体，则“为取证而做的低力探测”本身就可能致伤/致损；同时最坏材料包络若过度保守，会把系统逼向“安全但不可用”，诱发人工绕过而把安全机制架空。

**新增定义 549（触觉观测与特征）** o^τ(t) 为上述多模态接触观测。特征化映射 Φ_τ: o^τ ↦ (ψ̂, s_slip, μ_t, conf) 在 50Hz 输出，内部 1kHz 仅做滑移/冲击检测；所有特征带置信与量程标志，饱和/越量程直接置 conf=0（触发 T1）。

**新增定义 550（安全相关材料属性与接触等价类）** ψ_safe(m) 如符号表。定义 m ~_τ m′ ⇔ ‖ψ_safe(m)−ψ_safe(m′)‖_{Σ_obs} ≤ δ_obs。所有包络只依赖等价类 [m]_τ：若两种材料在安全相关属性上不可区分，则它们在接触证书中可以互换——不可辨识性因此不再是安全漏洞，而是等价类内的正常保守。

**新增定义 551（材料后验与可信集）** 材料库 M（\|M\|≤16）上维护后验 p(m\|o^τ_{0:t})，由贝叶斯更新与视觉类原型先验耦合。M_ε 为后验质量 ≥1−ε_est 的最小最高密度集；若最高密度集仍覆盖全库，则 M_ε=M（完全未知）。可信集是包络的唯一入口：**绝不用点估计的最大后验类直接放宽包络**。

**新增定义 552（材料条件包络）** 对指尖材料 a 与物体等价类 [b]_τ：

```
a_c = (3 F_n R_eff / (4 E*))^{1/3}
p_0 = 3 F_n / (2π a_c²)                       # 赫兹接触峰值压力
E(a,[b]) = { (F_n,F_t,v_slip) :
    F_n ≤ min(F_pressure(p_lim,[b]), F_frag([b]), F_human, F_robot)
  ∧ p_0(F_n,E*) ≤ p_lim([b])
  ∧ F_t ≤ μ_min([b]) · F_n · (1−s_min)
  ∧ v_slip ≤ v_slip_max([b])
  ∧ 磨损率(F_n,F_t,v_slip,H) ≤ W_wear([b]) }
E_ops(a,M_ε) = ∩_{b∈M_ε} E(a,[b])
```
其中 F_pressure 由 p_0≤p_lim 反解，F_frag 为脆性阈值，F_human 为人因压力上限。**关键性质**：若真实 b*∈M_ε，则 E_ops(a,M_ε) ⊆ E(a,b*)——不知道只会更保守。

**新增定义 553（材料创新度）** 设视觉类原型 c 给出材料属性先验 (μ_c,Σ_c)，接触实测 ψ̂：
```
μ_t = clip( sqrt((ψ̂−μ_c)^T Σ_c^{-1}(ψ̂−μ_c)) / τ_mat , 0, 1 )
```
μ_t>τ_mat 即“表里不一”（外观语义与接触力学不一致）。若视觉类未知，则 μ_t=0（不假装能检测），由 v10 的 STF 语义新颖度负责；两者是**不同失效指纹**的并联证据。

**新增定义 554（滑移裕量与触觉抓取有效性）** 力基滑移裕量 s_slip^F = 1−max(0,F_t/(μ̂F_n))；振动微滑移给 s_slip^vib；取 s_slip=min(s_slip^F,s_slip^vib)。触觉抓取有效 γ^tac = 1[s_slip≥s_min ∧ p_0≤p_lim ∧ μ_t≤τ_mat ∧ conf]。接触证书中的 γ^T = γ^vis ∧ γ^tac（合取，不补偿）。

**新增定义 555（力升级梯与探测证书）** L=(F_0,…,F_K)，F_k=min(F_0·2^k, E_ops.F_max)。升级到 k+1 需同时满足：
1. F_{k+1} ≤ E_ops(a,M_ε^{(k)}).F_max 且 p_0(F_{k+1}) ≤ p_lim；
2. 后验熵 H(m\|o^τ_{0:t}) ≤ H_{k+1}（识别足够确定）；
3. s_slip ≥ s_min 且 μ_t ≤ τ_mat；
4. 探测/升级计划在可信集上鲁棒安全（定义 557）。
任一不满足 ⇒ 停在 k 级或回退；回退也失败 ⇒ 安全撤离。**首次取证前的最大接触冲量上界**为 J_0=F_0·T_0。

**新增定义 556（接触证书）** Ĉ_t^T=(ĝ_min,ê_max,γ̂_grasp^T,β_STF,n_t,E_ops,μ̂,s_slip,h_t)。有效 ⇔
- v10 的 Ĉ⁺ valid（含 β_STF、n_t、freshness、U_t^sem）；且
- 非接触动作：无需接触条件；或
- 接触动作：F̂_q 预测的法向/切向力与峰值压力 ∈ E_ops，s_slip≥s_min，μ̂≤τ_mat，材料类在已认证库中（未知则只允许 F_0 级）；且
- h_t 对应的 T1–T4 回退已应用。
因 v10 Ĉ⁺ 是合取项，Ĉ^T valid ⇒ Ĉ⁺ valid（引理 92）。

**新增定义 557（有护探测计划与 VOI 停止）** π_probe=(u_c,n,F_0,T,微动)。对 M_ε 的鲁棒安全条件：∀b∈M_ε，π_probe 的力/压力/滑移轨迹 ∈ E(a,[b])。风险 r(π)=max_{b∈M_ε} p_0(π,b)/p_lim(b)；信息增益 ΔH(π)=H(M_ε)−E[H(M_ε\|o^τ_π)]。选择
```
π* = argmax_{π∈Π} [ΔH(π) − λ_r·r(π)]   s.t.  r(π) ≤ r_max
```
若最大 VOI < c_probe 或不存在鲁棒安全 π ⇒ **弃权/求助**（不接触或人工确认）。弃权是合法输出，不是失败。

**新增定义 558（材料证据台账）** MEL 为 Λ 的扩展（同一 append-only 哈希链），记录：离线候选集、每个候选的属性置信域/测试覆盖/退化路径/证据预算、Ashby 指数、最终选材与 Pareto 依据；在线材料后验更新、μ 与 s_slip 超阈事件、每次探测与力升级/回退、包络版本与切换。证据预算定义为 (n_tests, 置信水平, 属性不确定度上界, 覆盖的任务类)；过期或缺口 ⇒ T4。

**新增定义 559（健康向量与限制性接触剖面）** h_t=(h_TW,h_MCE,h_GTP,h_MEL)，由心跳、数据新鲜度、标定有效期、包络表版本一致性给出。Π_t = {
仅对已注册且材料类已认证物体接触；F_n≤F_0；禁止自主升级；K_eff≤2；d_eth←d_eth+δ_t；强制语音披露；未知/脆性材料不接触 }。
Π_t 只加约束，故其可执行动作集 ⊆ v10 可行集。

```python
# IP-365 TactileWitness：独立物理见证（不参与视觉加权）
class TactileWitness:
    def __init__(self, library, tau_mat=0.3, eps_est=0.01,
                 s_min=0.25, delta_obs=0.1):
        self.lib, self.tau_mat, self.eps_est = library, tau_mat, eps_est
        self.s_min, self.delta_obs = s_min, delta_obs
        self.post = library.uniform_prior()      # |M|<=16
        self.psi_hat, self.mu, self.s_slip = None, 0.0, 1.0
        self.healthy, self.conf = True, 1.0

    def update(self, o_tau, visual_class):
        if not o_tau.in_range or o_tau.calib_stale:
            self.healthy, self.conf = False, 0.0    # T1
            return
        self.psi_hat = self.estimate_properties(o_tau)   # E, mu, H, ...
        self.post = bayes_update(self.post, self.psi_hat, o_tau)
        self.M_eps = credible_set(self.post, self.eps_est)
        self.mu = mahalanobis_surprise(
            self.psi_hat, self.lib.visual_prior(visual_class))
        self.s_slip = min(force_slip_margin(o_tau, self.post),
                          vib_slip_margin(o_tau))

    def grasp_valid(self):
        return (self.healthy and self.conf > 0
                and self.s_slip >= self.s_min
                and self.mu <= self.tau_mat)


# IP-366 MaterialConditionedEnvelope：包络求交（预计算表 + 取 min/max）
class MaterialConditionedEnvelope:
    def __init__(self, table, a):           # table[(a, cls)] = E(a,[cls])
        self.table, self.a = table, a

    def intersect(self, M_eps):
        caps = [self.table[(self.a, cls)] for cls in M_eps]
        if not caps:
            return None                      # T2：不接触
        return Envelope(
            F_max=min(e.F_max for e in caps),
            p_lim=min(e.p_lim for e in caps),
            mu_min=min(e.mu_min for e in caps),
            v_max=min(e.v_max for e in caps),
            wear=min(e.wear for e in caps))

    def admits(self, E_ops, F_n, F_t, p0, v_slip):
        return (F_n <= E_ops.F_max and p0 <= E_ops.p_lim
                and F_t <= E_ops.mu_min * F_n * (1 - self.s_min)
                and v_slip <= E_ops.v_max)


# IP-367 GuardedTouchPlanner：取证本身受包络约束，无安全探测则弃权
class GuardedTouchPlanner:
    def __init__(self, mce, probe_lib, tau_mat, r_max=0.5,
                 c_probe=0.01, lam_r=1.0):
        self.mce, self.probes = mce, probe_lib   # |probes|<=8
        self.tau_mat, self.r_max = tau_mat, r_max
        self.c_probe, self.lam_r = c_probe, lam_r

    def plan(self, prior_M_eps):
        best = None
        for pi in self.probes:
            E_ops = self.mce.intersect(prior_M_eps)
            if E_ops is None:
                return ABSTAIN                         # 无安全接触
            if not robust_safe(pi, prior_M_eps, E_ops):
                continue
            risk = max_pressure(pi, prior_M_eps) / E_ops.p_lim
            if risk > self.r_max:
                continue
            score = expected_info_gain(pi, prior_M_eps) - self.lam_r * risk
            if best is None or score > best.score:
                best = Probe(pi, score, risk, E_ops)
        if best is None or best.score < self.c_probe:
            return ABSTAIN                              # VOI 不足
        return best


# IP-367 力升级梯：逐级解锁，失败即停/退
def escalate(level, tw, mce, H_sched, ladder):
    while level < len(ladder) - 1:
        E_ops = mce.intersect(tw.M_eps)
        if E_ops is None or tw.mu > tw.tau_mat:
            return ABORT
        if ladder[level + 1] > E_ops.F_max:
            return HOLD(level)                      # 包络不允许更高力
        if entropy(tw.post) > H_sched[level + 1]:
            return HOLD(level)                      # 识别不够确定
        if tw.s_slip < tw.s_min:
            return RETREAT(max(0, level - 1))       # 先回退再中止
        level += 1
    return COMMIT(level)


# IP-354（升级）：接触感知的结构化证书执行器
class StructuredChunkCertifier(ActionChunkCertifier):
    def __init__(self, *a, Fq=None, tw=None, mce=None, gtp=None,
                 beta_base=0.02, lam=0.1, **kw):
        super().__init__(*a, **kw)
        self.Fq, self.tw, self.mce, self.gtp = Fq, tw, mce, gtp
        self.beta_base, self.lam = beta_base, lam

    def generate_chunk(self, state, ctx, stf, nrb):
        K = self.effective_K(ctx.delta_dom, ctx.tau_dom,
                             trust_ok=stf.trust_ok(ctx),
                             contact_ok=self.tw.grasp_valid(),
                             health=self.health)
        if K == 1:
            return self._single_step_fallback(state)
        best = None
        for cand in self.policy.sample_sequences(state, K, n=64):
            pred = self.Fq.rollout(state, cand)
            beta = self.beta_base + self.lam * stf.field_on_footprint(
                pred.corridor)
            g_min = pred.min_clearance - beta
            e_max = pred.max_effort + beta
            if g_min < self.d_safe or e_max > state.tau_eff:
                continue
            if pred.requires_contact:
                E_ops = self.mce.intersect(self.tw.M_eps)
                if E_ops is None:
                    continue                             # T2：不接触
                if not self.mce.admits(E_ops, pred.F_n, pred.F_t,
                                       pred.p0, pred.v_slip):
                    continue
                if not self.tw.grasp_valid():
                    continue
            pts = self._abort_points(state, cand, pred)
            if not pts:
                continue
            cert = CertT(g_min, e_max, beta, self.tw.M_eps,
                         self.tw.psi_hat, self.tw.s_slip, self.health)
            chunk = Chunk(cand, cert, pts)
            chunk, verdict = nrb.review_chunk(chunk, stf, ctx)
            if chunk is None:
                continue
            score = self.policy.score(chunk, pred)
            if best is None or score > best.score:
                best = chunk
        return best or self._single_step_fallback(state)

    def midchunk_guard(self, chunk, k_exec, live, stf, nrb):
        # 检 1–4：v10 原样
        if not chunk.cert_still_valid(live):
            return self._nearest_abort(chunk, k_exec)
        if (live.nearest_clearance - self.d_brake(live.speed)
                - self.d_safe) < chunk.remaining_len(k_exec):
            return self._nearest_abort(chunk, k_exec)
        if stf.surprise_near(live.pose) > stf.tau_sem:
            return self._nearest_abort(chunk, k_exec)
        if nrb.fast_norms(live).violated:
            return self._nearest_abort(chunk, k_exec)
        # 检 5：接触包络/滑移（仅接触时非平凡）
        if live.in_contact:
            E_ops = self.mce.intersect(self.tw.M_eps)
            if E_ops is None or not self.mce.admits(
                    E_ops, live.F_n, live.F_t, live.p0, live.v_slip):
                return self._deescalate_or_abort(chunk, k_exec)
            if self.tw.s_slip < self.tw.s_min:
                return self._deescalate_or_abort(chunk, k_exec)
        # 检 6：材料创新度（表里不一）
        if live.in_contact and self.tw.mu > self.tw.tau_mat:
            return self._deescalate_or_abort(chunk, k_exec)
        return ('continue', k_exec + 1)

# 离线：带证据预算的稳健选材（Ashby 约束 + 可辨识性）
def select_fingertip(candidates, object_classes, req, mel):
    front = []
    for a in candidates:
        lo, hi = mel.confidence_region(a, cover=1 - req.eps_prop)
        ok, worst_margin, worst_disc = True, +inf, +inf
        for b in object_classes:
            E = robust_envelope(a, b, lo, hi)       # 对置信域取交集
            A_a = (1 - hi.nu**2) / lo.E             # 皮肤柔度上界
            A_b = (1 - lo.nu_b**2) / hi.E_b
            disc = A_b / (A_a + A_b)                # 刚度可辨识度
            if E is None or E.F_max < req.F_min[b] or disc < req.D_min:
                ok = False
                break
            worst_margin = min(worst_margin, E.margin)
            worst_disc = min(worst_disc, disc)
        if ok:
            front.append((a, worst_margin, worst_disc,
                          mel.durability_lcb(a)))
    return pareto_max(front)                        # 安全/辨识/耐久三目标
```

## 4. 推导

**引理 92（触觉独立见证、非扩张与不匹配检出界）** 设 (A1) v11 证书把 v10 的 Ĉ⁺ 作为合取项；(A2) 给定材料类时视觉与触觉失效条件独立；(A3) 触觉对安全相关等价类 [m]_τ 的识别错误率 ≤ε_τ；(A4) 真实材料落入可信集的概率 ≥1−ε_est。则：
(i) **非扩张**：∀s，A_v11(s) ⊆ A_v10(s)。因为 v11 只增加合取条件、包络上限与力级限制；故 v11 下任何物理违背在 v10 下同样可能，v11 不会引入新的物理行为（伦理/安全支配）。
(ii) **不匹配检出**：若视觉把材料类 c 判对但物体真实材料与 c 的安全相关属性差超过 δ_obs（表里不一），v10 的视觉语义新颖度可能仍 ≤τ_sem（纹理伪装），但首次有护接触后 μ_t>τ_mat 的概率 ≥(1−ε_τ)(1−ε_est)；检出前接触力受定义 555 的力升级梯约束（引理 93）。
(iii) **非补偿唯一性**：任何加权融合只要在“视觉失败、触觉通过”时仍放行，其通过集就严格包含合取通过集；故对安全判定，合取是唯一不扩大动作集的融合。若两通道独立失效，漏检概率 ≤ε_s ε_τ + ε_est（并集界）。
证明：(i) 合取/上限的单调性；(ii) A3+A4 与 μ 的定义；(iii) 集合包含与融合函数的单调性。∎

**引理 93（首次取证前的有界伤害）** 设力升级梯 F_0<…<F_K，F_0 = E_ops(a,M_prior).F_max，升级到 k+1 必须满足定义 555 四条件。若真实 b*∈M_prior，则对任意时刻 t，接触法向力 F_n(t) ≤ F_{k(t)}，且首次取证前的总冲量 J_0 ≤ F_0·T_0；在 k 级发现 μ>τ_mat 或 s_slip<s_min 时，系统在施加 F_{k+1} 前停止/回退，故峰值接触力 ≤ F_k ≤ E(a,b*).F_max。
证明：对升级级数归纳。基础级由 F_0 对 M_prior 的鲁棒包络保证；归纳步由定义 555 条件 1（F_{k+1}∈E_ops）与引理 94(A)（E_ops⊆E(a,b*)）保证；一旦条件 2–4 失败则不升级，故峰值不超过当前级。∎
**诚实边界**：若对象“任何接触都会坏”（如薄玻璃、危险品），则 F_0 不安全；此时 MCE 可能返回空包络或 GTP 返回 ABSTAIN，系统必须弃权/求助——本引理只保证“在存在安全探测时”的伤害上界，不保证“总能安全取证”。

**引理 94（包络的保守性、单调性与等价类无关性）** (A) 若 b*∈M_ε，则 E_ops(a,M_ε)=∩_{b∈M_ε}E(a,[b]) ⊆ E(a,b*)。
(B) 后验收缩 M_ε′⊆M_ε ⇒ E_ops(a,M_ε′) ⊇ E_ops(a,M_ε)（约束更少，包络只会变宽），但始终 ⊆ E(a,b*)；无证据只可能更保守。
(C) 若 m~_τ m′，则 E(a,[m])=E(a,[m′])，因为包络只依赖 ψ_safe；不可辨识但安全等价的材料不构成漏洞。
(D) 若真实材料不在可信集（概率 ≤ε_est），则包含关系可能失效——这是本方案唯一的统计残余风险。
证明：集合交的单调性、min/max 的单调性、等价类定义。∎

**引理 95（稳健选材、证据预算与安全-可辨识性权衡）** 设候选指尖材料 a 的属性置信域 Ψ_a 由 MEL 给出、覆盖概率 ≥1−ε_prop。稳健包络 E^- = ∩_{ψ∈Ψ_a,b∈B}E(ψ,b)。若选材满足：(i) E^- 非空且覆盖任务所需 F_min；(ii) 对每个任务类 b，刚度可辨识度 D(a,b)=A_b/(A_a+A_b) ≥ D_min；(iii) 耐磨/热/食品接触等约束在置信下界满足；则部署后真实包络包含于 E^- 的概率 ≥1−ε_prop，即选材不会乐观越界。
权衡：dD/dA_a = −A_b/(A_a+A_b)² < 0，故皮肤越软（A_a 越大）越不利于辨识物体刚度；而峰值压力 p_0 ∝ (E*)²ᐟ³ 随 A_a 增大而降低，故越软越安全。二者方向相反，可行域是“安全约束 ∩ 辨识约束”；当交集为空时，只能采用任务专用指尖、接受更粗的等价类，或放弃该任务类——这正是材料选型必须显式化的代价，而不是在线偷偷调阈值。∎

**引理 96（退化支配与等价）** 若 h_t 任一分量为 0，按 T1–T4 应用 Π_t 或最坏包络。Π_t 只增加力上限、禁止未知材料接触、禁止升级、缩短块长，故其动作集 ⊆ v10 动作集；若四个新模块全部失效且材料任务不涉及接触，则 v11 与 v10 的证书与控制器完全相同（未增加任何合取项），即**严格等价**而非仅支配。MEL 缺口在 1 块内触发 Π_t；TW 掉线时已进行的接触不得升级，故不会出现“失去触觉后反而加力”。证明：逐条失效路径检查合取项与上限的单调性。∎

**引理 97（50Hz 与复杂度保持）** TW 特征更新 O(N_τ)，N_τ≤256（下采样 taxel），后验 O(\|M\|p²)，\|M\|≤16，包络求交 O(\|M\|)，探测规划 O(\|Π\|)，\|Π\|≤8 且仅 5Hz；六检守卫 ≤0.6ms。决策侧合计典型 ≤8ms、p99 ≤20ms；新增内存 ≤100KB（材料库 32KB + 特征 8KB + 台账 64KB，台账与 v10 Λ 共用环形空间）；功耗 ≤25W。证明：逐项操作计数与 v10 预算表相加，均未触碰关键路径。∎

## 8. 本轮最大风险

**一句话**：触觉证据总在第一次接触之后才到，而第一次接触本身已不可逆——若对象是“薄软壳包裹刚性/高质心本体”、或触觉在饱和/磨损下把壳层误判为本体，则“为取证而做的低力探测”本身就可能致伤/致损；同时最坏材料包络若过度保守，会把系统逼向“安全但不可用”，诱发人工绕过而把安全机制架空。
