# 第 58 轮（承接第 57 轮「小样本×多模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「域随机化」×「碰撞检测」）

> 第 57 轮把安全的赌注押在"少样本可校准、跨模态可对账、个性化有界"的证据承诺上，并把兜底交给 OOD 门 + 共形带。但它的风险自陈暴露了更底层的裂缝：**(a)** 元先验的"分布内"是从历史语料摊销出来的，而语料只是某个**未言明的世界分布**的一次采样——我们从没声明过这个分布是什么、支持集多大、尾巴多厚；`ε_meta(k)` 的"诚实"是手工签字，不是从世界覆盖推出来的。**(b)** 证据仍在**离散检查点**上评估，而不可逆接触发生在**连续时间**里：一个足够薄的脆壳、一段足够快的抬腿，可以在两个检查点之间被"隧穿"——检查点看不到、地图不记录，"这里没碰过危险"这条坏证据就这样长寿。**(c)** 探针预算在为整张地图买单，而绝大多数区域对当前约束**可证明地无关**；缺少"廉价且保守地剔除无关区域"的机制，于是把探针浪费在不可能出事的地方，又在真正模糊的边界上探得不够。本轮两个灵感恰是两把互补的尺子：**域随机化**给"世界维"的覆盖声明（把"分布内"变成可审计的支持集卡 + 尾部界 + 逐点提升引理），**碰撞检测**给"时间维"的不漏保证（宽相保守剪枝 + 连续保守推进，把"检查点没看到"变成"区间内不可能发生"）。核心命题从"证据说可信"升级为 **"支持集可声明、区间内不漏检的证据说可信"**。

核心矛盾：
- **H29（随机化覆盖 vs 逐点安全）**：DR 只在随机化分布 P_φ 上给平均意义保证，而部署是单个世界 W*；"在支持集内"若没有 Lipschitz/覆盖数把期望界抬成逐点上界，就只是把假设写成证书；未随机化轴是默认盲区，放宽 ranges 又有保守性与性能代价。
- **H30（离散检查 vs 连续隧穿）**：检查点证据对"薄障碍 + 快速运动"天然漏检；连续保守推进能补上，但依赖诚实的距离下界与运动上界，且可能过度保守，导致探针浪费甚至死锁。
- **H31（宽相剪枝 vs 漏检）**：廉价筛选的算力收益与安全性是同一枚硬币：非保守筛选会静默丢掉真危险（最坏的一类坏证据），只有过近似危险集（safe ⇒ 真安全）才能既省探针又不漏；但保守界越松，模糊前沿越宽，探针压力越大。

## 0. 直觉与动机

**灵感 1（域随机化 → 支持集证书，而不是"相信随机化"）**
直觉：DR 常被当成"多随机化一点就能迁移"的咒语，但严格说它只声明了一件事——**训练世界来自某个分布**；它没有说部署世界也来自这个分布。真正可审计的对象不是策略，而是**覆盖卡**：随机了哪些轴、每轴范围 I_a、尾部概率 δ_tail、模型失配 γ_gap，以及**哪些轴根本没随机**（𝒜_null）。规则很简单：**没被随机化的轴，默认就是 OOD**——不是因为它危险，而是因为我们对它没有任何覆盖声明。元先验只在"W*∈𝒮_DR ∧ 轴∈𝒜_rand"时才允许出任一证据；否则退回探针/共形/停。

**灵感 2（DR 的期望界 → 逐点界的提升引理）**
直觉：DR 给的是 E_{W~P_φ}[失败率]≤ε，部署却是一点 W*。要把平均变成最坏，需要两块砖：**Lipschitz**（世界参数动一点，失败率不跳变太多）与**覆盖数**（支持集可被有限个 ε-球盖住）。有这两块砖，有限次随机化仿真就能给出 sup_{W∈𝒮_DR} 的置信上界，而不只是均值。于是 ε_meta(k) 从"签字"变成"覆盖数 + Lipschitz 常数 + 样本数推出来的证书"；推不出来，就诚实地说"逐点保证不可得"，退回逐点探针——**不把不可得包装成可得**。

**灵感 3（碰撞检测 → 连续保守推进，堵住时间维的隧穿）**
直觉：检查点像马路上的测速摄像头，足够快、足够薄的违规会从两个摄像头之间穿过去。碰撞检测早就解决了这个：**连续碰撞检测（CCD）+ 保守推进（conservative advancement）**——用真实距离的**下界**与速度/加速度的**上界**，一步步算出"到下一次可能接触至少还有多久"，只要推不到接触就发证书。搬到证据上：不可逆接触必须持有**区间证书** EV-interval，声明"在整个 [t0,t1] 内，要么分离度 ≥ d_safe，要么接触力 ≤ F_bear"；离散探针不能替代它。隧穿从"小概率运气"变成"在诚实界下概率为 0 的不可能事件"。

**灵感 4（碰撞检测的另一半 → 宽相/窄相就是证据预算的剪枝）**
直觉：碰撞检测能在巨大场景里实时，不靠精确计算，靠**宽相**先用 AABB/BVH 廉价剔除绝大多数不可能相撞的对，只把模糊的一小撮交给**窄相**精算。探针预算正是被"整张地图"拖垮的。于是把地图单元分三类：`safe`（任何 W∈𝒮_DR 下都不可能违反，**可证明**）、`unsafe`（**可证明**会违反）、`ambiguous`（剩下的一条薄前沿）。探针只花在 ambiguous 上，按 VOI 排序。关键纪律：宽相必须**保守**（危险集的过近似，safe ⇒ 真安全）；一个会漏检的快筛比不筛更坏，因为它生成的是"看起来安全"的坏证据——这类坏证据必须随世界模型版本变更而**整体失效重算**。

**灵感 5（两把尺子合流 → 时空双证书 + 假设正交性）**
直觉：DR 管"世界维"，CD 管"时间维"，失败模式对偶：DR 漏的是**支持集外的世界**，CD 漏的是**采样点之间的时间**。联合承诺是"W* 在支持集内 ∧ 轨迹在区间内被证明"，残余风险 = 支持集缺口 ∪ 区间界违反。但有个不显眼的陷阱：若两张证书都建立在**同一张世界轴清单与同一个刚体接触模型**上，失败事件是**相关**的——联合界不能简单相加，真实风险是取 max。因此额外要求**假设正交性**：两张证书的承重假设不得共享同一个未审计的世界模型部件；共享时必须显式标注相关失败，并用相关界替代 union bound。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（随机化覆盖卡与支持集证书 DRC）** 世界参数 W∈𝒲（摩擦 μ、柔顺 κ、质量、时延、地形高度场…），随机化分布 P_φ，支持集 𝒮_DR=supp(P_φ)。覆盖卡 𝒞_DR=(𝒜_rand,𝒜_null,{I_a},P_φ,δ_tail,γ_gap,L_Lip,N_ε)。支持缺口事件 G={∃a∈𝒜_rand:W*_a∉I_a}∪{∃a∈𝒜_null:W*_a≠a_0}，要求 P(G)≤δ_tail（按轴 union bound；未随机化轴若无另证贡献 1）。条件元校准 ECE_k(q_φ|¬G)≤ε_meta(k)。**逐点提升引理**：若 P_fail(·) 在 𝒮_DR 上 L_Lip-Lipschitz、𝒮_DR 有 ε-覆盖数 N_ε、m 个 i.i.d. 仿真世界，则 w.p.≥1−η：sup_{W∈𝒮_DR}P_fail(W) ≤ max_j P̂_fail(W_j)+2L_Lip·ε+√(log(2N_ε)/2m)。推不出（缺 Lipschitz 或覆盖数）⇒ 逐点保证不可得，元先验不得单独出任证据。

**定义 140（随机化-共形保底 CDR）** 共形带在随机化残差 {res(W_j)} 上校准，覆盖只对 W~P_φ 成立。现实世界用失配膨胀：C_cf^DR(r)=C_cf^{sim}(r)⊕[−γ_gap,γ_gap]，γ_gap 为 |sim−real| 的已证上界（配对试验或物理失配模型）；γ_gap 未知 ⇒ 带仅在 𝒮_DR 内有覆盖声明，𝒮_DR 外**不是证据**（禁 EV-probe*，只能探针/停）。这修掉第 57 轮把 sim 共形覆盖默认迁移到现实的隐含假设。

**定义 141（连续接触证据 CCD-E）** 接触机动参数 s∈[0,1]，位形 x(s)，运动学上界 ‖ẋ‖≤v_max、‖ẍ‖≤a_max（声明诚实）。保守距离 d̃(s)≤d_true(s)（真距离的下界，可由 BVH/SDF 保守化得到）。保守推进：Δs_j=d̃(s_j)/(v_max+½a_maxΔτ)。证书 EV-interval ⇔ 推进到终点且 ∀j d̃(s_j)≥d_safe（或已接触时 f≤F_bear）。**不隧穿定理**：在 A42（d̃ 为真下界且运动界诚实）下，区间内若发生碰撞，推进必提前终止 ⇒ 不存在"碰撞了却发了证书"。不可逆接触必要证据集升级为 {EV-probe*∨EV-margin}∪{EV-interval}∪佐证。

**定义 142（宽窄相探针调度 BP-NP）** 地图单元 𝒞，保守界 B(c)∈{safe,unsafe,ambiguous}，soundness：B(c)=safe ⇒ ∀W∈𝒮_DR 无违反（危险集过近似）。宽相 O(|𝒞|·c_b)，用 𝒮_DR 上的参数极值构造 AABB 式区间界；仅 ambiguous 进窄相，按 VOI_元 排序，花费 k_probes。**不漏检定则**：A43 下宽相 safe 单元内的危险概率为 0；探针数 ∝ |Ambiguous| 而非 |𝒞|。世界模型/支持集版本变更 ⇒ 所有 B(c) 失效重算（坏证据不得长寿）。

**定义 143（随机化补盲闭环 DR-IR）** 每次 OOD/证伪事件 e：由 CD-DR 残差定位差异轴，提出新增轴 a+ 或扩宽 I_a；在增强系综下做**影子仿真**（第 57 轮"判定器走隔离"的延伸：随机化更新本身也走隔离）。若增强后元先验仍"自信地错"，判为**轴不可知**（unknown unknown），永久路由到探针/共形，不得再进元先验快速路。任何随机化更新须通过校准回归（ECE 不劣化 ∧ OOD 检出率不降 ∧ 区间证书不退化），并审计可回滚。

**定义 144（碰撞-随机化一致性核对 CD-DR）** 区域 r 的机动：仿真系综最小裕度 M_sim=min_{W~P_φ}M(W)，现实区间证书裕度 M_real。一致性残差 χ(r)=max(0,M_sim−M_real)（或事件 {M_sim≥ε_safe ∧ M_real≤ε_near}）。χ>θ_χ ⇒ 覆盖缺口告警（𝒮_DR 缺轴/范围不足），喂给 DR-IR。价值：**用连续的真实接触做免标注的 DR 覆盖 oracle**——不需要真值标签，只需"仿真说一定安全，现实却擦边"。

## 2. 关键算法伪代码（完整版见产物区）

```python
def support_certified_infer(M, r, obs, meta):        # IP-139/140 合流
    if gap_risk(r, meta.card) > 0:                   # 未随机化轴或可能出支持集
        return Inf(cls='OOD_SUPPORT', belt=conformal_dr(meta.card, r))
    post = meta.q_phi(obs, z=ctx(r))
    if not meta.per_point_bound_available(post):     # 无 Lipschitz/覆盖数证书
        return Inf(cls='NO_POINTWISE', post=post)    # 元先验不得单独出任证据
    return Inf(cls='ID', post=post, bound=meta.uniform_bound(post, meta.card))

def broad_phase(map_cells, card):                    # IP-142: 保守过近似
    out = {}
    for c in map_cells:
        if   provably_safe_under(c, card):   out[c] = 'safe'
        elif provably_unsafe_under(c, card): out[c] = 'unsafe'
        else:                                out[c] = 'ambiguous'
    return out                                       # safe ⇒ 真安全（A43）

def continuous_contact_cert(x, motion):              # IP-141: 保守推进
    s = 0.0
    while s < 1.0:
        d = conservative_distance(x(s))              # 真距离的下界
        if d < d_safe: return Cert(False, s)         # 提前终止 = 命中风险
        s += d / (motion.v_max + 0.5 * motion.a_max) # 到下一次可能接触的时间下界
    return Cert(True, 1.0)                           # 区间内无碰撞（A42 下确定性）
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| DRC | O(1) 查卡；提升 O(m·N_ε) | O(\|𝒜_rand\|+N_ε) | δ_tail / L_Lip / N_ε 声明诚实 |
| CDR | O(N_cal) 校准 | O(N_cal) | γ_gap 有限且诚实，否则只在 𝒮_DR 内 |
| CCD-E | O(#推进步)=O(1/d_safe) | O(1) | 距离下界 + 运动上界诚实（A42） |
| BP-NP | O(\|𝒞\|·c_b+\|Amb\|·c_n) | O(\|𝒞\|) | 宽相危险集过近似（A43） |
| DR-IR | 影子仿真 O(m·T_sim) | O(\|𝒜\|) | 隔离回归 + 可回滚审计 |
| CD-DR | O(m) 仿真裕度 | O(1)/区域 | 残差阈值 + 告警回溯 |

**正确性定理（SCIS 概要）**：在 A37–A40 上加 (A41) 覆盖卡诚实（δ_tail、γ_gap、L_Lip、N_ε 与未随机化轴声明）；(A42) 保守距离下界与运动界诚实；(A43) 宽相危险集过近似；(A44) 随机化更新走隔离且审计可回滚。则：(i) 承诺失效 ≤ [δ_f+ε_meta+δ_probe+ε_h+δ_interval]+δ_tail(+γ_gap 膨胀项)，且支持集外元先验不贡献任何正证据；(ii) 连续隧穿在 A42 下为 0，残余只有"界失真"事件；(iii) 宽相 safe 单元零漏检，探针数与模糊前沿成正比；(iv) 两证书不满足假设正交性时，联合界退化为 max 而非 sum，须显式声明相关失败。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 未随机化轴 = 未声明的盲区 | 高 | 覆盖卡显式列出 𝒜_null 并默认 OOD；补盲闭环；审计 |
| 保守界不保守（距离下界/运动上界失真） | 高 | 界验证 + 在线残差监控 + 一旦可疑即撤销区间证书 |
| 宽相非保守 → 静默漏检（最坏坏证据） | 高 | 只允许过近似；版本化失效；safe 单元抽样复审 |
| 逐点提升假设（Lipschitz/覆盖数）不成立 | 中高 | 推不出就退回逐点探针，诚实标注"不可得" |
| 过度随机化 → 保守退化/死锁 | 中 | 随机化预算与性能损失联合优化；分级 ranges |
| 两证书假设相关 → 联合界虚假乐观 | 中高 | 假设正交性审查；相关时用 max 界并标注 |

## 6. 本轮最大风险

**一句话**：我们给"世界分布"和"连续轨迹"各发了一张证书，但两张证书共用同一张**世界轴清单**与同一个**刚体接触模型**——真正的新物理若不在轴清单里（或让接触变柔顺），支持集证书会把它判成分布内、连续推进会用刚性距离下界判成无碰撞，两道保底因同一个未建模维度而**同时**失效，联合界退化为最坏的那个。

# 第 58 轮产物 · 创新点清单 v34：Support-Interval（域随机化支持集×连续碰撞检测区间，DRC×CDR×CCD-E×BP-NP×DR-IR×CD-DR）

### IP-139 DRC（随机化覆盖卡与支持集证书）

```python
def build_coverage_card(ensemble, null_axes, tail_claim):
    card = Card()
    card.A_rand = ensemble.axes                      # 真正随机化过的轴
    card.A_null = set(null_axes)                     # 声明为"未随机化"=默认盲区
    for a in card.A_rand:
        card.I[a] = (ensemble.lo[a], ensemble.hi[a]) # 支持区间
    card.delta_tail = tail_claim                     # P(G) 的声明上界
    card.L_Lip = ensemble.certified_lipschitz        # 失败率对 W 的 Lipschitz 常数
    card.N_eps = covering_number(ensemble.support, eps=card.L_Lip * tail_claim)
    card.gamma_gap = ensemble.sim_real_bound          # 可为 None
    return card

def support_gap_risk(r, card, world_est):
    risk = 0.0
    for a in card.A_rand:                            # 轴 union bound
        if not within(world_est[a], card.I[a]):
            risk += tail_prob(card, a)
    for a in card.A_null:                            # 未随机化轴：默认 OOD
        if world_est.get(a, None) is not None and \
           not declared_equal(world_est[a], card.nominal[a]):
            risk += 1.0                              # 无覆盖声明 ⇒ 视为出支持集
    return risk

def pointwise_lift(empirical, card, m, eta):
    if card.L_Lip is None or card.N_eps is None:
        return None                                  # 逐点保证不可得，诚实返回
    return max(empirical) + 2 * card.L_Lip * card.eps \
           + sqrt(log(2 * card.N_eps) / (2 * m))     # 支持集上的置信上界
```

> 直觉：DR 不是"相信随机化"，而是"声明我覆盖了哪些轴、覆盖到什么程度、尾巴多厚"。未随机化的轴是**明写的盲区**，必须默认 OOD，而不是被"分布内"顺手收编。

### IP-140 CDR（随机化-共形保底）

```python
def conformal_dr(card, r, alpha_conf):
    sim_belt = weighted_conformal(card.residuals, sim=csim(ctx(r), card.Z),
                                  alpha=alpha_conf)
    if card.gamma_gap is None:                       # 失配界未知
```

### IP-141 CCD-E（连续接触区间证书）

```python
def continuous_contact_cert(x_of_s, motion, d_safe, F_bear):
    s, steps = 0.0, []
    while s < 1.0:
        d = conservative_distance(x_of_s(s))         # 真距离的下界（BVH/SDF）
        steps.append((s, d))
        if d < d_safe:
            if contact_force_leq(x_of_s(s), F_bear):
                return Cert(True, 'contact_bounded', s)   # 受控接触仍可接受
            return Cert(False, 'risk_hit', s)             # 提前终止 = 发现风险
        step = d / (motion.v_max + 0.5 * motion.a_max)    # 时间下界 ⇒ 空间下界
        s += max(step, motion.dt_min)                      # 防零步死循环
    return Cert(True, 'separated', 1.0)                    # 区间内无碰撞（A42）

def interval_evidence_gate(contact, cert):
    if contact.irreversible and cert.kind != 'ok':
        return ('reject', 'no_interval_certificate')  # 不可逆接触硬要求
    return ('ok', cert) if cert.ok else ('reject', 'interval_risk')
```

> 直觉：离散探针问"此刻安全吗"，区间证书回答"整段时间里不可能不安全"。前者会被隧穿，后者在诚实界下不会。薄壳/快速抬腿正是前者的天敌。

### IP-142 BP-NP（宽窄相探针调度）

```python
def broad_phase(cells, card):
    out = {}
    for c in cells:
        lo, hi = param_envelope(c, card.S_DR)         # 参数极值 ⇒ 结果极值
        if provably_no_violation(lo, hi, c.constraint):
            out[c] = 'safe'                          # 过近似 ⇒ 真安全
        elif provably_violation(lo, hi, c.constraint):
            out[c] = 'unsafe'
        else:
            out[c] = 'ambiguous'
    return out

def narrow_phase(route, B, budget, M, inf):
    frontier = [c for c in route.cells if B[c] == 'ambiguous']
    frontier.sort(key=lambda c: -voi_meta_pessimistic(c, M, inf))
    probed = []
    for c in frontier:
        if budget.probes_left <= 0: break
        probed.append(probe(c, M)); budget.spend()
    return probed, ('halt' if any(B[c] == 'unsafe' for c in route.cells)
                    else 'continue')
```

> 直觉：宽相是"证据的 AABB"——廉价、保守、只会说"一定安全/一定危险/拿不准"。把探针花在"拿不准"上，才算把预算从整张地图压成一条前沿。非保守宽相会静默漏检，是最坏的坏证据。

### IP-143 DR-IR（随机化补盲闭环）

```python
def dr_iterative_repair(event, card, shadow_sim):
    a_diff = localize_axis(event)                    # 由 CD-DR 残差定位差异轴
    proposal = widen(a_diff, event) if a_diff in card.A_rand \
               else add_axis(a_diff, event)
    if a_diff in card.A_null:                        # 碰到从未随机化的轴
        card.A_null.discard(a_diff); card.A_rand.add(a_diff)
    pilot = shadow_sim.run(proposal, mode='shadow')  # 隔离：影子模式
    if not pilot.passes(ECE_non_degrade=True, ood_recall_non_degrade=True,
                        interval_non_degrade=True):
        return quarantine(proposal), 'rejected_in_regression'
    if pilot.still_confident_wrong():                # 增强后仍自信地错
        card.axis_registry.mark_unknown(a_diff)      # 轴不可知 ⇒ 永久走慢路
        return card, 'axis_unknowable'
    return commit_isolated(card, proposal), 'promoted'
```

> 直觉：补盲不是"悄悄把范围调宽"，而是"发现差异轴 → 影子仿真 → 校准回归 → 隔离上线"。增强后仍自信地错，说明这不是"范围不够"而是"轴没想到"，只能永久降级到探针/共形，不能继续喂给元先验。

### IP-144 CD-DR（碰撞-随机化一致性核对）

```python
def collision_dr_consistency(r, maneuver, card, cert):
    M_sim = min(collision_margin_under(r, maneuver, W) for W in card.ensemble)
    M_real = cert.margin                              # 连续区间证书给出的现实裕度
```

> 直觉：仿真说"这批世界一定安全"，现实却擦边——不需要真值标签，这个矛盾本身就指向"支持集缺了某根轴"。用连续接触当 DR 覆盖的 oracle，是两把尺子最紧的咬合点。

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DRC | O(1) 查卡；提升 O(m·N_ε) | O(\|𝒜\|+N_ε) | δ_tail/L_Lip/N_ε 声明诚实、未随机化轴默认 OOD（A41） |
| CDR | O(N_cal) 校准 | O(N_cal) | γ_gap 诚实或仅 𝒮_DR 内有效（A41） |
| CCD-E | O(1/d_safe) 推进步 | O(1) | 距离下界 + 运动上界诚实（A42） |
| BP-NP | O(\|𝒞\|·c_b+\|Amb\|·c_n) | O(\|𝒞\|) | 危险集过近似、safe⇒真安全（A43） |
| DR-IR | O(m·T_sim) 影子仿真 | O(\|𝒜\|) | 隔离 + 校准回归 + 可回滚（A44） |
| CD-DR | O(m) 仿真裕度 | O(1)/区域 | 残差阈值 + 盲轴定位 |
| FSE⁺ | O(\|σ\|) | O(\|σ\|) | 不可逆接触必须 EV-interval |
| PCE⁺⁺ | O(\|CP\|·(\|Amb\|·C_VOI + 1/d_safe) + \|𝒞\|·c_b) | O(\|V\|+\|𝒞\|) | 宽相剪枝、双证书、四态完备 |

**正确性定理（Support-Certified Interval-Soundness, SCIS）**
假设 A22–A32、A33–A36、A37–A40 成立；**(A41)** 覆盖卡与支持集诚实：𝒮_DR、{I_a}、δ_tail、γ_gap、L_Lip、N_ε 声明诚实，未随机化轴被显式声明并默认 OOD；**(A42)** 保守界诚实：d̃(s) 是真实有符号距离的下界，v_max/a_max 是真实运动上界；**(A43)** 宽相保守：B(c)=safe ⇒ 对 ∀W∈𝒮_DR 无约束违反；**(A44)** 随机化更新走隔离区且审计可回滚。则：

1. **支持集健全性**：P(承诺失败 | ¬G) ≤ δ_f + ε_meta(k) + δ_probe + ε_h + δ_bnd；P(G) ≤ δ_tail。支持集外，元先验不贡献任何正证据（EV-probe* 失效），失效只能来自探针/区间/人。
2. **连续不隧穿**：A42 下，区间 [t0,t1] 内发生未受控碰撞而 EV-interval 仍为真的概率为 0；残余风险仅来自"界失真"事件 δ_bnd（距离界被低估错误或运动界被低估）。
3. **宽相不漏检**：A43 下，宽相判 safe 的单元内存在违反的概率为 0；探针数 ∝ |Ambiguous|，与 |𝒞| 解耦。
4. **DR 的诚实负结果**：仅凭 DR 的期望界不能推出逐点安全；除非给出 L_Lip 与 N_ε 并做提升，否则 `sup_{W∈𝒮_DR} P_fail` **不可声明**，系统必须退回逐点探针。
5. **假设正交性与联合界**：DR 证书（承重假设 A41）与 CCD 证书（承重假设 A42）若共享同一未审计的世界模型部件，则失败事件相关，联合界退化为 `max(δ_tail, δ_bnd)` 而非相加；部署时必须显式声明正交性审查结果。
6. **终止性**：宽相一次 O(|𝒞|)；窄相 ≤k_probes；推进步有限（step≥dt_min）；PCE⁺⁺ 终止于 {承诺, 绕行, L2 协商, 安全停}。

**部署界**（对检查点取联合界；若不满足假设正交性，`δ_tail+δ_bnd` 项改为 `max`）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h) − δ_tail − δ_bnd
             − P(宽相非保守) − P(𝓜 陈旧未检出) − P(护盾/协商失效)
```

关键：**支持集给"世界维"的覆盖、连续推进给"时间维"的不漏**；DR 的效率收益（摊销先验）与安全兜底（共形/探针）继续解耦，且本轮把"分布内"从签字变成证书、把"检查点安全"变成"区间安全"。

其中新增：`𝒞_DR/δ_tail/γ_gap/L_Lip/N_ε` 覆盖卡与逐点提升参数；`axis_registry` 世界轴注册表（随机化状态与盲轴标记）；`EV-interval/d̃(·)` 连续区间证书与保守距离界；`B(c)` 宽相保守分类；`χ(r)` 碰撞-随机化一致性残差；`J_s` 支持-区间证书。

云边协议 CEB++ → **CEB+++**：云端可下发随机化系综与覆盖卡增量（带版本与 δ_tail 声明），但**覆盖卡更新同样走隔离区**——影子模式下重算宽相分类、校准回归（ECE 不劣化 ∧ OOD 检出率不降 ∧ 区间证书不退化 ∧ 宽相 safe 抽样复审通过）后才接管证据门；边端回传 χ(r) 残差、目标隧穿事件与盲轴告警，作为云端补盲与随机化轴发现的校准集。第 57 轮"一切判定器走隔离"在本轮推广为"**世界分布的声明与更新也走隔离**"。

## 6. 本轮最大风险

**一句话**：本轮给"世界分布"和"连续轨迹"各发了一张证书，但两张证书的承重假设落在同一张**世界轴清单**与同一个**刚体接触模型**上——真正的新物理若不在轴清单里（或让接触变柔顺），支持集证书会把它判成分布内、连续推进会用刚性距离下界判成无碰撞，两道保底因同一个未建模维度而**同时**失效；因此必须以"未随机化轴默认 OOD + 假设正交性审查（相关时用 max 界）+ 影子仿真补盲 + 区间证书可撤销"四重纪律，坦然承认 DR 只覆盖我们想到的世界、CCD 只证明我们建模的碰撞。
