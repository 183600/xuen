# 第 44 轮（新循环第 4 轮） · Silicon-Cert × Wrist-Observability：把「嵌入式实现」与「腕部视角」纳入可验证证书闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形边际覆盖被欺骗 + 多用户契约求交为空」，但它仍压着两个更底的单点假设：**(H1) 证书只是数学对象**——一张 guard 谓词被默认为能在真实 MCU/加速器上被忠实执行，忽略了从谓词到监控器程序之间的语义鸿沟（定点舍入、中断、cache、DVFS、栈溢出、编译器重排）；**(H2) 感知被默认为全向且始终可信**——而决定接触安全的「最后厘米」恰恰由**腕部相机**提供，它窄视场、易被夹爪自遮挡、运动模糊、rolling shutter、标定漂移。本轮灵感词「嵌入式系统」「腕部相机」精确命中这两个假设：**嵌入式系统**迫使我们把「执行」从工程细节提升为证明义务（证书精化 + WCET/内存/能量 + 硬件根信任）；**腕部相机**迫使我们把「可观测性」提升为证书有效性的一部分（可观测锥 + 盲区回退）。二者耦合处是**光子到执行器的信任桥**：相机本身就是嵌入式传感器，其标定证书、延迟与带宽共同决定最后厘米的证书年龄。

## 0. 直觉与动机

**灵感 1（嵌入式 → 证书要「精化」而非「移植」）**：把高层的 `m ≥ θ` 守卫搬到 MCU 上，最危险的不是写不出代码，而是「写出来的代码看起来对、却在边界处不 sound」：浮点被换成定点后舍入方向错、编译器把检查挪到执行之后、异步中断在临界区写坏证书状态、栈在中断嵌套下溢出、DVFS 降频让 WCET 悄悄超 deadline。因此本轮的核心不是「优化嵌入式实现」，而是引入**证书精化关系 g ⊑ M**：要求存在模拟关系，使监控器 M 的任何 `allow` 都蕴含高层守卫 g 成立，并附带可静态审计的 WCET/内存/能量界（定义 44/45）。此外，监控器本身就是整个系统的**可信基（TCB）**，它必须尽量小、可穷举验证，并由**硬件根信任**为租约背书（签名 + 单调计数器 + 镜像度量，定义 46），否则上一轮的时间租约可以被「重放旧证书」绕过。一句话：**能证明它在硅上照做，才算有证书**。

**灵感 2（腕部相机 → 证书要「按可观测性条件化」）**：腕部相机是机器人离接触点最近的「眼睛」，但也是最脆弱的眼睛：夹爪自己会挡住目标、快速接近会拖出运动模糊、rolling shutter 让「帧时刻」本身有歧义、碰撞后的标定漂移让几何证书悄悄失准。直觉上，安全系统不能假装「看不见」等于「没危险」，也不能因为看不见就放手去碰。于是把证书有效性从「时间新鲜」扩展为「可观测覆盖」：定义四元可观测度 O（锥覆盖 / 模糊 / 标定漂移 / 自遮挡），只有 O ≥ O_min 时证书才可用于守卫（定义 47/48）；一旦看不见，就切**盲区策略**（后退重观测 / 安全停机），且该策略在编译期被验证恒在全局安全集内。**可观测性失效因此只损失可用性，不损失 soundness**。

**灵感 3（耦合 → 光子到执行器的信任桥）**：腕部相机本身是嵌入式传感器：曝光时刻由硬件打点、帧经 DMA 零拷贝、rolling shutter 使「取帧时刻」≠「曝光时刻」，而标定参数也需要像代码一样被度量与背书。若只按「租约测量时刻 τ」判新鲜，却不计「光子何时进入镜头、执行器何时动」，最后厘米的证书年龄会被系统性低估。于是定义**光子到执行器年龄 A = t_act − t_photon**，把时间（租约衰减）、空间（可观测锥）、标定（漂移证书）、年龄（A ≤ slack）合并为**四维有效性**（定义 49），并由 IP-62 信任桥在硬件层度量。至此「证书」不再只是一张集合，而是一条**从光子到执行器的监管链**，每一环都带自己的界与签名。

**耦合升级**：v8 的 persona×concurrent 闭环之上，本轮插入 **CSC（证书精化编译器）→ WOC（腕部可观测证书）→ STB（光子-执行器信任桥）** 的硅-传感精化层，形成 v9「仿真-检索-边缘飞轮 + 人格契约层 + 并发证书层 + 硅/可观测精化层」。四层架构的每一层结论，从此都必须回答两个新问题：**它能被精化到硅上吗？它看得见自己守卫的那最后厘米吗？**

## 1. 形式化定义（增量：定义 44–49）

**定义 44（证书精化关系 g ⊑ M）**：设高层守卫 g: S→{allow,deny}，嵌入式监控器 M=(Q, δ, q0, out) 运行于联合状态 (s,q)。称 M **精化** g（记 g ⊑ M），若存在模拟关系 R ⊆ S×Q 满足：(i) **初始化** (s0,q0)∈R；(ii) **模拟步** R(s,q) ∧ q→q' ∧ s→s' ⟹ R(s',q')；(iii) **门控** out(q')=allow ⟹ g(s')（监控器说放行，守卫必须真的成立）；(iv) **执行门** 不对执行器发出任何 g 不允许的动作。**命题**：若 g ⊑ M，则 M∘plant 的可观测行为包含于 g 守卫下的允许行为集，即精化保持 soundness。**实现侧义务**：(ii)(iii) 必须落到**向外取整的定点 interval/affine 抽象**、无动态分配、有界循环、以及「屏蔽写证书状态的异步中断」的原子临界区上。

**定义 45（可证资源界与实时契约）**：监控器 M 的静态最坏执行时间 C^wc、峰值内存 M^mem、峰值能量 E^max，均在**最低工作频率 f_min 与最坏中断负载**下定义。**实时契约**：C^wc(f_min) ≤ D（D 为控制周期 deadline）∧ M^mem ≤ M_hw ∧ E^max ≤ E_budget。**命题（无「先动后查」）**：若实时契约成立，且临界区屏蔽一切会写证书状态的异步中断，则监控决策从不晚于其守卫的 act。**注**：这把上一轮的「预算」从软性运行参数升级为可被静态审计的硬约束；也意味着「降频省电」与「安全」在 f_min 处正面冲突，必须显式裁决。

**定义 46（硬件根租约与防重放）**：租约 ℓ=(m,τ,λ,κ) 之外附 (n, σ, h_img)：n 为硬件单调计数器，σ = Sign_root(H(ℓ‖n))，h_img 为监控器镜像哈希（secure boot 时度量）。**验证** verify(ℓ) 要求签名有效 ∧ n > 本地已见最大计数 ∧ h_img 与当前运行镜像一致。**命题**：单调计数器 + 签名 ⟹ 任何过期或回滚的租约都不可被重放；因此定义 49 的年龄判据不会被「重放旧证书」绕过。**注**：这把「可信」从「软件自称可信」推进到「硬件保证没被换过」。

**定义 47（腕部可观测锥与覆盖证书）**：腕部相机在状态 x 与位姿 ξ 下定义可观测锥 Cone(x,ξ)。**四元可观测度**
O(x) = min{ 1, r_cov/r_req, b_max/b(x), (δ_max−δ(x))/δ_max, 1−o(x) }，
其中 r_cov 为锥覆盖风险几何的半径、b(x) 为运动模糊半径、δ(x) 为在线标定漂移、o(x) 为自遮挡比例。**覆盖判据**：O(x) ≥ O_min 才认为「看得见」。**命题**：O 的每一项都由可在线测量的量给出（曝光与角速度、重投影残差、分割掩码），故可实时守卫，不含不可观测量。

**定义 48（可观测条件证书与盲区回退）**：C_obs = { s ∈ C_global∩Π_u : O(s) ≥ O_min }。**有效性**：证书只在 C_obs 上可用于守卫；离开 C_obs 即视为失效，触发盲区策略 π_blind ∈ {retreat-and-reobserve, safe-stop}，且要求 π_blind 的任意执行恒在 C_global 内。**命题（安全只降可用性）**：因 π_blind ⊆ C_global，可观测性失效只会造成任务暂停/后退，不产生安全违例。这正是把「传感器看不见」从安全风险降级为可用性代价的机制。

**定义 49（光子到执行器年龄与四维有效性）**：A = t_act − t_photon，其中 t_photon 由**曝光开始时刻**的硬件时间戳给出（防 rolling shutter 的取帧歧义）。一条用于守卫的结论须同时满足：**时间** m−λ(t−τ) ≥ θ；**空间** s ∈ C_obs；**标定** δ ≤ δ_max 且标定证书未过期；**年龄** A ≤ slack ∧ ||x(t_act)−x(t_photon)|| ≤ v_max·A；再叠加定义 44 的实现精化与定义 46 的硬件背书。**定理（端到端 soundness）**：若 g⊑M、实时契约成立、四维有效性成立或已切盲区策略，则执行动作 ∈ C_global∩Π_u；否则由 π_blind 退回安全集。**注**：这是把 v8 的「时间新鲜度」扩展为「时间 × 空间 × 标定 × 年龄」的联合有效性。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 CERT-SILICON-COMPILER（证书精化编译器 CSC）
1. **守卫 IR → 定点监控器**：把 IP-51 CAR 的 `min(查表, 租约衰减, persona 上限)` 编译为定点算术，用 interval/affine 抽象证明舍入方向 sound（一律向外取整），拒绝任何需要不可分析构造的输入。
2. **可分析代码生成**：无动态分配、有界循环、无异常/递归、临界区屏蔽写证书状态的异步中断；产出静态 WCET/栈/内存/能量界（定义 45）。
3. **Translation validation**：对可达状态穷举 + 差分 fuzz（高层守卫 vs 编译后监控器），任何不一致即拒绝部署（定义 44 的工程化证明）。
4. **硬件根**：监控器镜像哈希进 secure boot 度量；租约签名绑定 (n, σ, h_img)（定义 46）。

### 2.2 IP-61 WRIST-OBSERVABILITY-CERTIFICATE（腕部可观测证书 WOC）
1. **在线可观测度**：曝光/角速度→模糊界，重投影残差→标定漂移，分割/深度→自遮挡比例，锥覆盖→风险几何覆盖（定义 47）。
2. **证书条件化**：把 IP-49 几何证书与 IP-51 CAR 的 margin 再与 O_min 求交，得到 C_obs；`margin ← min(查表, 租约衰减, persona 上限, 可观测余量)`。
3. **盲区策略**：retreat-and-reobserve（后退到能看见接触点的位姿后重观测）/ safe-stop；策略在编译期验证 ⊆ C_global。
4. **标定漂移证书**：腕部相机标定本身作为一条独立租约，漂移超限即整体降级为盲区策略（不让几何证书悄悄失准）。

### 2.3 IP-62 SENSOR-TRUST-BRIDGE（传感器信任桥 STB）
1. **光子时间戳**：曝光开始硬件打点 + rolling shutter 元数据，计算 A = t_act − t_photon（定义 49）。
2. **零拷贝快照**：DMA + cache-safe 双缓冲 + seqlock，保证监控器读到的帧与其时间戳同源一致（不撕裂）。
3. **带宽/能量预算**：腕部相机帧率/分辨率随剩余能量与 deadline 自适应，但「降帧率」只允许**收紧** O_min，绝不允许放宽安全阈值。
4. **标定硬件背书**：内参/外参与标定哈希进可信度量，防「张冠李戴」（承接上轮 persona 阈值表错索引风险）。

## 3. 四层架构 v9

```
L0: 腕部相机(裸金属驱动, 曝光硬件时间戳) + IP-62 STB → 帧 + t_photon + 无撕裂快照
L1: TRI-FUSE(INT8) + IP-49 LIO → C_ms + B_t + L_m
    可观测度 O(x) = min(锥覆盖, 模糊, 标定漂移, 自遮挡) → C_obs, A = t_act−t_photon
L2: CTC + VLM + IP-35 仲裁 → R_φ(w) 分支池(b 候选, 并行投机)
L3: IP-51 CAR(四源 min 守卫 + BlindMode) ← IP-58 CCR(租约 + RG + 混合关键级 + IP-46 硬件根租约)
    → IP-60 CSC 精化监控器(WCET 有界, 最高关键级)
    → IP-47 精化接口组合 → IP-39 规划(CBF margin=min(查表, 租约, persona, 可观测余量))
    → IP-53 CMC(定点只读监控器) → IP-45 总线(observability/photon-age/attestation)
L4: IP-57 PCE(人格契约) + IP-61 WOC(可观测证书 + 盲区策略) + IP-55 CKB(相机-接触指纹)
    ← IP-59 ICV(交错/线性一致/人格对抗) + IP-54 SCV(模糊/自遮挡/漂移/热降频)
    → IP-44 蒸馏 + IP-50 课程 → RCA 重颁(含 WCET 界 + 可观测签名) → 契约热更新
运行期：光子时间戳 → A 计算 → 可观测守卫 → 硬件背书租约 → 精化监控器在 WCET 内决策 → actuation
失效路径：O<O_min → 盲区策略(后退重观测/停)
         WCET 超界 / 镜像度量不符 / 年龄超界 → 硬件无关「停-看-再动」 → 反例回灌 Sim/CKB
```

## 4. 实验设计（E95–E102 硬门槛，承接 E87–E94）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E95 精化等价性 | 差分 fuzz 不一致次数；可达状态穷举覆盖 | 0；100% 可达 |
| E96 WCET/内存/能量 | 实测 p99 vs 静态界；最坏中断下栈溢出；先动后查 | 实测 ≤ 界；0；0 |
| E97 硬件根防重放 | 重放/回滚租约成功次数；镜像度量不一致未拦截 | 0；0 |
| E98 可观测覆盖 | 盲区检出率/误报率；失效到盲区切换时延 | ≥95% / <5%；<20ms |
| E99 标定漂移 | 漂移检出早于证书违例；δ 估计误差 | 100%；<20% |
| E100 光子-执行器年龄 | 实测 A vs 界；陈旧结论进入守卫 | 实测 ≤ 界；0 |
| E101 盲区安全与可用性 | 盲区期安全违例；重观测成功率；吞吐下降 | 0；≥90%；<20% |
| E102 嵌入式长时程 | 热降频/低电量下 100h 违例；WCET 抖动；线性一致违例 | 0；<10%；0 |

回退：E95/E96 不达标 → 监控器退回已验证的小状态机（更强保守），牺牲性能；E97 失败 → 禁用租约复用，每决策重测；E98/E99 失败 → 关闭「最后厘米」操作，全程走盲区停-看-再动；E100 失败 → 拉高 O_min、缩短曝光/帧率，牺牲速度；E101 失败 → 默认 safe-stop，取消自主 retreat；E102 失败 → 锁定 ≥ f_min、取消 DVFS；任何红线失败 → 全链路熔断回退 v20。

## 5. 本轮最大风险

**一句话**：端到端 soundness 现在压在**硬件最坏情况模型**上（WCET/cache/DVFS/热降频/硅 errata），而腕部相机窄视场 + 自遮挡又让失效恰好发生在最需要它的接触点、且**不可观测**——一旦硬件模型偏离，证书会在最后厘米静默失效，因此 E95/E96/E99/E101 必须设为红线，并默认回退到硬件无关的「停-看-再动」安全模式。

# 第 44 轮产物 · 创新点清单 v21：Silicon-Cert × Wrist-Observability（CSC × WOC × STB）× 从光子到执行器的可验证硅-传感精化闭环（四层架构 v9）

> 承接第 43 轮产物 v20。本轮**增量插入** IP-60/61/62，并升级 IP-45/47/49/50/51/52/53/54/55/56；不推倒任何既有层级。核心是把 v20 的「仿真→检索→边缘→仿真 + 人格契约 + 并发证书」飞轮，升级为**证书可精化到硅上（refinement + WCET/内存/能量 + 硬件根信任）**、且**按可观测性条件化（腕部可观测锥 + 盲区回退）**的端到端闭环，把「时间新鲜」扩展为「时间 × 空间 × 标定 × 年龄」的四维有效性。

## 0. 核心 IP 设计

| 编号 | 名称 | 类型 | 关键改进 |

## 2. 关键算法（伪代码）

### IP-60 CSC：守卫精化到硅
```
def compile_guard_to_silicon(g, hw):
    ir = lower_to_fixedpoint(g, word_bits=hw.word_bits, rounding=OUTWARD)  # 向外取整 => sound
    assert no_dynamic_alloc(ir) and bounded_loops(ir) and not uses_float(ir)
    crit = mark_critical_section(ir, writes=CERT_STATE)   # 屏蔽写证书状态的异步中断
    C_wc, M_mem, E_max = static_bound(ir, f_min=hw.f_min, worst_irq=True)
    if C_wc > hw.deadline or M_mem > hw.mem or E_max > hw.energy:
        return Reject("实时契约不可满足")               # 定义 45
    return Monitor(image=ir, bound=(C_wc, M_mem, E_max), crit=crit)

def validate_refinement(g, M, reachable):
    # translation validation：可达状态穷举 + 差分 fuzz（定义 44）
    for s in reachable:
        if M.out(s) == ALLOW and not g(s):   return False   # 门控反例
        if M.step(s) != g.step(s):           return False   # 模拟反例
    return fuzz_diff(g, M, N=10**7) == 0

def attest_lease(lease, root):
    n   = root.monotonic_counter_bump()
    sig = root.sign(hash(lease) + n)          # 硬件根签名
    return AttestedLease(lease, n=n, sig=sig, h_img=root.image_hash())  # 定义 46
```

### IP-61 WOC：可观测证书与盲区策略
```
def observability(x, cam, motion):
    r_cov = cone_covers_risk_geometry(cam.pose, cam.intrinsics, risk_geom(x))
    b     = blur_radius(cam.exposure, motion.omega, cam.rolling_shutter)
    delta = reprojection_drift(cam.calibration, cam.recent_frames)
    occ   = self_occlusion_ratio(cam.segmentation, cam.depth)
    O = min(1, r_cov/R_REQ, B_MAX/b, (DELTA_MAX-delta)/DELTA_MAX, 1-occ)  # 定义 47
    return O, {r_cov, b, delta, occ}

def condition_certificate(C, O, O_min, persona):
    if O >= O_min:
        return ObservedCert(intersect(C, persona), O)        # 证书仍有效
    return BlindPolicy.retreat_or_stop(intersect(C, persona))  # 盲区：安全只降可用性（定义 48）
```

### IP-62 STB：光子到执行器的信任桥
```
def photon_to_actuation_age(frame):
    t_photon = frame.hw_timestamp_exposure_start   # 曝光开始，而非取帧时刻
    return monotonic_now() - t_photon              # 定义 49 的 A

def bridge_valid(frame, lease, x_prev, v_max):
    A = photon_to_actuation_age(frame)
    return (A <= lease_slack(lease)
            and displacement_bound(x_prev, v_max, A) <= lease.slack_pos
            and not frame.tear_detected)           # seqlock 无撕裂快照
```

### IP-51/53 升级：四源守卫与定点只读监控器
```
def car_transition_guard_v9(e, x, cert, persona, lease, O, t):
    theta    = cert.alpha_e[e] * cert.theta_sim[e]
    m_lookup = cert_lookup_L0(x).m_lo[e]
    m_lease  = lease.m - lease.lam * (t - lease.tau)
    m_cap    = persona_cap[e](persona)
    m_obs    = observability_margin(O, O_MIN)      # 可观测余量
    ok = min(m_lookup, m_lease, m_cap, m_obs) >= theta and lease_valid(lease, theta, t)
    return ok or enter_blind_mode(persona)         # 不满足 => 暂不执行，切盲区

def certify_light_v4(x, guards, persona, budget_us, criticality, frame):
    b, lease = cert_lookup_L0(x), acquire_lease('lcs', x, guards.theta, criticality)
    if not bridge_valid(frame, lease, x, V_MAX):
        return BlindPolicy.safe_stop(), lease        # 年龄/一致性失效
    O, _ = observability(x, WRIST_CAM, motion_est(x))
    b, lease = condition_certificate(b, O, O_MIN, persona)
    if enter_blind(b): return b, lease
    return b, lease if not undecided_guards(b, guards) else downgrade_monotone(b), lease
```

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 硬件最坏情况模型偏离（cache/DVFS/热/硅 errata），WCET 界失真导致「先动后查」 | 高 | E96 红线；f_min 下静态界 + 最坏中断注入；模型识别实验（实测 p99 vs 界）；超界即硬件无关停-看-再动 |
| 腕部相机盲区/自遮挡恰在接触点，失效不可观测 | 高 | E98/E101 红线；四元可观测度实时守卫；盲区策略编译期验证 ⊆ C_global；默认 safe-stop 兜底 |
| 标定漂移让几何证书悄悄失准 | 高 | E99 红线；标定作为独立租约；重投影残差在线监测；超限整体降级盲区策略 |
| 定点舍入方向错误或编译器重排导致门控失效 | 高 | E95 红线；一律向外取整；translation validation + 差分 fuzz；禁用不可分析构造 |
| 租约重放/回滚绕过年龄判据 | 中-高 | E97 红线；硬件单调计数器 + 签名 + 镜像度量；verify 失败即拒绝 |
| 光子时间戳歧义（rolling shutter 取帧时刻 ≠ 曝光时刻） | 中 | 曝光开始硬件打点；帧与时间戳同源 seqlock 快照；E100 实测 A |
| 降帧率/降分辨率省电时悄然放宽安全阈值 | 中 | 自适应只允许收紧 O_min；能量/带宽预算硬约束；E102 红线 |
| 标定参数哈希「张冠李戴」（相机/硬件版本错配） | 中 | 相机内参/外参与硬件版本绑定哈希进可信度量；部署前全量相机回归 |

## 6. 本轮最大风险

**一句话**：端到端 soundness 现在压在**硬件最坏情况模型**上（WCET/cache/DVFS/热降频/硅 errata），而腕部相机窄视场 + 自遮挡又让失效恰好发生在最需要它的接触点、且不可观测——一旦硬件模型偏离，证书会在最后厘米静默失效，因此 E95/E96/E99/E101 必须设为红线，并默认回退到硬件无关的「停-看-再动」安全模式。
