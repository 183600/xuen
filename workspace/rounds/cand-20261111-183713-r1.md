# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「谐波减速器」×「运动学」）

> 第 54 轮已把技能从能力黑箱提升为动作占用剖面 α_S 与云边联合证书 J。但 α_S 仍活在“抽象命令空间”里，暗含“命令即结果”。本轮用谐波减速器的传动物理与运动学误差传播，为动作空间补上**物理接地**：命令动作经谐波减速器的运动学误差、非线性扭转刚度、迟滞与热漂移映射为真实关节角，再经雅可比放大为任务空间误差。核心矛盾：**H22** 命令空间中的动作覆盖可能是“虚假覆盖”，物理层因传动误差与奇异位形放大而失效；**H23** 技能组合在物理层是非马尔可夫的，谐波减速器的迟滞状态跨技能携带，逐对兼容不等于路径级兼容。

## 0. 直觉与动机

**灵感 1（谐波减速器把动作空间从欧氏格点弯成“传动流形”）**
直觉：谐波减速器不是理想减速比 N，而是一个带记忆的非线性算子 `T : (q_cmd, τ, h, θ) → q_act`。其中有四项不可忽略：周期性运动学误差 `ε_kin`（波发生器椭圆变形，2 次谐波为主）、负载相关扭转柔度 `g(τ)`（小扭矩区“软上弦”）、Preisach 型迟滞 `Δq_h`（卸载与加载路径不重合）、热/磨损漂移 `ε_th`。于是“动作 a 可达”不再是一个 0/1 判定，而是一条**误差管**：命令相同的动作，在负载历史不同时物理结果不同。

**灵感 2（运动学放大：小关节误差在奇异位形处爆炸）**
直觉：`δx = J(q)·δq`。任务空间误差不是关节误差的等比例搬运，而是被雅可比条件数 `κ(J)` 放大。靠近奇异位形 `σ_min(J)→0`，微小的传动误差会变成巨大的末端偏差。因此动作空间里存在**奇异性空洞** `A_sing`：几何上覆盖、物理上不可用。动作剖面必须被运动学条件数“打折”。

**灵感 3（迟滞使技能组合非马尔可夫 → 状态增广组合图）**
直觉：技能 `S2` 的初始传动误差取决于 `S1` 结束时的迟滞状态 `h`。把技能当无记忆节点，逐对 `compat` 再高，也可能在组合时因迟滞状态错配而崩。于是组合图节点应从 `S` 升级为 `(S,h)`，边不仅要求动作兼容，还要求 `h` 的转移落在容差内，或插入一个**迟滞复位动作**（卸载/回零），其成本计入 `c_trans`。这正好为第 54 轮的 H20“组合前兼容、执行时冲突”给出物理根因。

**灵感 4（传动指纹作为仿真-现实对齐的物理证据通道）**
直觉：每个谐波减速器的 `ε_kin` 频谱、刚度曲线、迟滞环宽度是制造与装配留下的“指纹”。它能验证仿真模型是否真的对齐了这台硬件：若 `F_sim` 与 `F_real` 距离过大，则 GenSim 的证据链无效。这把上一轮的“仿真证据”从软件层落到物理层，也可作设备身份与迁移溯源的物理水印。

**灵感 5（柔度是天然的 A_buffer，把安全证书变成能量预算）**
直觉：上一轮的 `A_buffer` 是抽象容错带。谐波减速器的扭转柔度天然储能 `E = ½ k_eff Δq²`，它给出可承受冲击的物理上界。于是 `A_buffer` 有了物理解释：`Δq_safe = sqrt(2 E_safe / k_eff)`，安全证书从“经验带宽”变为“能量预算 + 峰值力约束”。

**灵感 6（金字塔补一层物理传动层 𝕂）**
直觉：在第 54 轮 `𝕃/𝔸` 之下再加 `𝕂`：`𝕂_0` 谐波减速器物理（刚度/迟滞/传动误差/热）；`𝕂_1` 关节误差管；`𝕂_2` 经雅可比放大的任务误差；`𝕂_3` 物理接地的动作剖面与证书。上层所有 `ρ、α、J` 都必须能追溯到 `𝕂` 的物理量，形成“物理接地”的可解释链。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（谐波传动算子）**
谐波减速器作用为带状态算子
```
q_act(t) = T(q_cmd, τ, h, θ) = q_cmd + ε_kin(q_cmd) + g(τ) + Δq_h + ε_th(θ)
```
其中 `ε_kin(q)=Σ_{k=1}^{K} a_k sin(k q + φ_k)` 为运动学误差（`k=2` 为主谐波）；`g = k_eff^{-1}` 为非线性扭转柔度；`Δq_h = H[τ]` 为 Preisach 迟滞；`ε_th` 为热/磨损漂移；迟滞状态更新 `h' = Φ(h, τ)`。记辨识模型为 `T̂`，辨识误差 `ε_T = ||T - T̂||_∞`。

**定义 122（运动学误差管）**
对命令动作 `a = (q_cmd(·), τ(·))`，任务空间误差集合
```
E(a) = { J(q_cmd) e + ½ eᵀ H_FK(q_cmd) e : e = T(q_cmd,τ,h,θ) - q_cmd, h∈H }
```
误差管半径 `r(a) = sup_t ||E(a)(t)||`，跟踪裕度 `m(a) = tol_task(a) - r(a)`。一阶近似给出 `||δx|| ≤ κ(J)·||e|| + ½ L_J ||e||²`。

**定义 123（物理接地动作剖面与奇异性空洞）**
```
α_S^phys(a | h) = α_S(a) · 1[m(a) ≥ 0] · w_κ(a)
w_κ(a) = min(1, σ_min(J(q(a))) / σ_ref)
```
覆盖率判定 `cover_phys(S, A_T | h) = 1` 当且仅当 `∀a∈A_T, α_S^phys(a|h) ≥ θ_cov`。**奇异性空洞** `A_sing = {a : κ(J(q(a))) > κ_max}`，其中 `κ = σ_max/σ_min`。物理兼容性 `compat_phys(S_i,S_j|h) = |A_i^phys ∩ A_j^phys| / |A_i^phys ∪ A_j^phys|`。

**定义 124（迟滞状态与状态增广组合）**
迟滞状态空间 `H`；技能 `S` 的力矩剖面 `τ_S(·)`；状态转移 `h' = Φ(h, τ_S)`；复位动作 `r_h` 满足 `Φ(r_h(h), 0) = h_0`。状态增广技能图 `G_S^h = (V×H, E_h)`，边 `(S_i,h_i) → (S_j,h_j)` 存在当且仅当
```
compat_phys(S_i,S_j|h_i,h_j) ≥ θ_a
∧ |h_j - Φ(h_i, τ_{S_i})| ≤ ε_h
∧ c_trans(S_i,S_j) + c_reset·1[需复位] ≤ τ_e
```
组合可行当且仅当存在从 `(S_0,h_0)` 到 `(S_k,h_k)` 的**状态一致路径**。这把组合从“逐对兼容”升级为“路径级状态可传递”。

**定义 125（传动指纹与仿真证据有效性）**
传动指纹 `F_S = (spec(ε_kin), k_eff(·), w_h(·), rms(ε_kin), e_lost)`，`w_h` 为迟滞环宽度，`e_lost` 为失动量。仿真-现实距离
```
d_F(F_sim,F_real) = w1·W_1(spec_sim,spec_real) + w2·||k_eff^sim - k_eff^real||
                 + w3·|w_h^sim - w_h^real| + w4·|e_lost^sim - e_lost^real|
```
其中 `W_1` 为一阶 Wasserstein 距离。**仿真证据有效**当且仅当 `d_F ≤ Θ_F`；否则 GenSim 推出的 `ρ、α` 不得作为部署证据。

**定义 126（物理联合证书）**
```
J^phys = (ρ, A_cert, γ_ce, δ_a, T̂, h, F, E_safe, ε_T, ε_h)
```
部署条件同时满足：`dom_J = in`、`δ_a < Θ_a`、`d_F ≤ Θ_F`、`∀a∈A_core` 有 `r(a) ≤ tol_task(a)`、且存在状态一致路径。`E_safe` 为柔度储能预算，`ε_h` 为迟滞状态估计误差界。

## 2. 关键算法 伪代码

### IP-121 TGM（Transmission-Grounded Mapping）

```python
def transmission_tube(skill, q_traj, tau_traj, h0, model):
    e, h = [], h0
    for q, tau in zip(q_traj, tau_traj):
        q_act = (q + model.eps_kin(q) + model.compliance(tau)
                   + model.hysteresis(tau, h) + model.thermal())
        h = model.phi(h, tau)
        e.append(q_act - q)
    return e, h

def physical_profile(skill, A, model, tol):
    alpha_phys = {}
    for a in A:
        e, h = transmission_tube(skill, a.q, a.tau, a.h0, model)
        r = max(task_error_radius(a.q, e))       # J(q)e + ½eᵀH_FK e
        alpha_phys[a] = skill.alpha[a] * (1.0 if r <= tol(a) else 0.0) * cond_weight(a.q)
    return alpha_phys
```

### IP-122 HSC（Hysteresis State Composition）

```python
def state_augmented_search(G, h0, goal, eps_h, tau_e, h_buckets):
    # 节点 (skill_id, h_bucket)；边带状态转移与复位成本
    dist = {(goal_start, bucket(h0)): 0.0}
    pq = [(0.0, goal_start, bucket(h0), [])]
    while pq:
        cost, sid, hb, path = heappop(pq)
        if sid == goal:
            return cost, path
        h = h_buckets[hb]
        for nxt in G.successors(sid):
            h_pred = Phi(h, tau[sid])
            hb_pred = nearest_bucket(h_pred, h_buckets)
            c = G[sid][nxt]['cost']
            if bucket_dist(h_pred, h_buckets[hb_pred]) <= eps_h and c <= tau_e:
                relax((nxt, hb_pred), cost + c, path + [(sid, hb)])
            c_reset = G[sid][nxt]['cost'] + reset_cost(sid)
            if c_reset <= tau_e:
                relax((nxt, bucket(h0)), cost + c_reset, path + [(sid, 'reset')])
    return None, None          # 无状态一致路径 → 组合不可行
```

### IP-123 KSA（Kinematic Singularity-Aware coverage）

```python
def cond_weight(q, kappa_max=10.0, sigma_ref=0.05):
    s = svdvals(jacobian(q))
    kappa = s[0] / max(s[-1], 1e-12)
    if kappa > kappa_max:
        return 0.0                          # 奇异性空洞
    return min(1.0, s[-1] / sigma_ref)

def puncture_singularities(A, q_of, kappa_max):
    return [a for a in A if condition_number(jacobian(q_of(a))) > kappa_max]
```

### IP-124 TFP（Transmission Fingerprint Protocol）

```python
def extract_fingerprint(log):
    spec = welch_psd(log.eps_kin, fs=log.fs)
    k_curve = fit_stiffness(log.tau, log.dq)          # 分段非线性刚度
    w_h = hysteresis_loop_width(log.tau, log.dq)
    lost = lost_motion(log.forward, log.reverse)
    return Fingerprint(spec, k_curve, w_h, lost)

def sim_real_evidence(F_sim, F_real, Theta_F):
    d = (w1 * wasserstein1(F_sim.spec, F_real.spec)
         + w2 * norm(F_sim.k_curve - F_real.k_curve)
         + w3 * abs(F_sim.w_h - F_real.w_h)
         + w4 * abs(F_sim.lost - F_real.lost))
    return d <= Theta_F, d
```

### IP-125 CBC（Compliance Buffer Certificate）

```python
def compliance_buffer(k_eff, E_safe, m_eff):
    dq_safe = sqrt(2.0 * E_safe / k_eff)       # 弹性转角预算
    impulse_max = sqrt(2.0 * E_safe * m_eff)   # 可吸收冲击动量上界
    return Buffer(dq_safe, impulse_max)
```

### IP-126 PJC（Physical Joint Certificate）

```python
def physical_joint_certificate(skill_seq, T_hat, F_sim, F_real, h0, budgets):
    ok_F, dF = sim_real_evidence(F_sim, F_real, budgets.Theta_F)
    if not ok_F:
        return ('reject', 'fingerprint_mismatch', dF)
    path = state_augmented_search(build_graph(skill_seq, T_hat), h0,
                                  goal=skill_seq[-1], eps_h=budgets.eps_h,
                                  tau_e=budgets.tau_e, h_buckets=budgets.H)
    if path is None:
        return ('reject', 'state_inconsistent')
    r = max(tube_radius(s, T_hat) for s in skill_seq)
    if r > budgets.tol:
        return ('reject', 'kinematic_violation', r)
    buf = compliance_buffer(T_hat.k_eff, budgets.E_safe, budgets.m_eff)
    return ('ok', PhysicalJointCert(rho=compose_robustness_chain(skill_seq),
                                    A_cert=physical_buffer(buf), T_hat=T_hat,
                                    h=path[-1][1], F=F_real, dF=dF, r=r))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| TGM | O(\|A\|·N_traj·K) | O(N_traj) | 辨识误差 `ε_T` 有界、误差管外扩 |
| HSC | O(\|H\|·\|V\|·log(\|H\|\|V\|) + \|H\|²\|E\|) | O(\|H\|\|V\|) | 状态转移 Lipschitz、复位可达 |
| KSA | O(\|A\|·d³) | O(\|A\|) | SVD 稳定、`κ_max` 硬阈值 |
| TFP | O(N log N + M) | O(N) | 频谱/刚度/迟滞可比、指纹不漂移 |
| CBC | O(1) | O(1) | 线性弹性区间内保守 |
| PJC | O(\|S\|·\|A\|) | O(\|A\|) | 各预算闭合、证书 sound |

**正确性定理（Kinematic-Transmission Grounded Composition Soundness）**
承接第 54 轮 (A22)–(A28)；新增 **(A29)** `sup ||T - T̂||_∞ ≤ ε_T`；**(A30)** `J(q)` 为 `L_J`-Lipschitz，且规划管上 `κ(J) ≤ κ_max`；**(A31)** 迟滞状态估计误差 `≤ ε_h`，复位动作可把 `h` 拉回 `|h-h_0| ≤ ε_reset`。
则对任意状态一致路径 `P`：
```
||x_act - x_cmd|| ≤ κ(J)·(ε_T + ε_h + ε_comp) + ½ L_J·(ε_T + ε_h + ε_comp)²
```
且部署成功概率
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - P(κ·ε_T > δ_x) - P(state mismatch) - β_E - P(δ_a > Θ_a)
```
关键：**命令空间覆盖必须被物理误差管与条件数共同收紧**，**组合可行性必须在迟滞状态上闭合**，**仿真证据必须通过传动指纹校验**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 迟滞/传动误差辨识不足 | 高 | 多负载扫频 + Preisach 辨识 + 置信区间传播 |
| 奇异位形附近模型失真 | 高 | `κ_max` 硬约束 + 保守误差管 + 降级慢速模式 |
| 误差管过保守吞噬动作空间 | 高 | 自适应管宽 + 任务容差重分配 + 分段线性化 |
| 指纹随温度/磨损漂移 | 中 | 在线指纹更新 + 漂移告警 + 定期重标定 |
| 状态增广图规模爆炸 | 中 | 迟滞状态分桶 + 支配剪枝 + 局部重规划 |
| 柔度缓冲被误当绝对安全 | 中 | 能量预算 + 峰值力实测校验 + 硬限幅 |

## 6. 本轮最大风险

**一句话**：本轮把抽象动作空间重新钉在谐波减速器的“传动流形”上，用 `(q_act, ε_kin, k_eff, h, F)` 把覆盖、组合与证据全部物理化，但其 soundness **强依赖迟滞与传动误差的可辨识性、雅可比条件数在规划管内的有界性、以及传动指纹在温度/磨损下不漂移**；一旦辨识模型系统性低估迟滞或奇异区误差，物理接地反而会制造“比抽象模型更可信的假证书”，故必须以 **多工况辨识 + 条件数硬闸 + 指纹在线校验** 三重护栏，宁可在模型不确定处缩小动作空间，也绝不把“物理接地的精确假象”当作部署前提。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-KineTrans（TGM×HSC×KSA×TFP×CBC×PJC）

> 承接第 54 轮产物 v31。第 54 轮把技能组合提升为“动作-鲁棒性双证书”，但动作空间仍是抽象命令空间。本轮新增 **物理传动层 𝕂**，用谐波减速器的传动物理与运动学误差传播给动作空间做物理接地：
> - **TGM（Transmission-Grounded Mapping）**：把命令动作经传动算子映射为真实关节角与任务误差管；
> - **HSC（Hysteresis State Composition）**：迟滞状态增广的技能组合图，修复组合的非马尔可夫性；
> - **KSA（Kinematic Singularity-Aware coverage）**：用雅可比条件数刻画奇异性空洞，收紧动作剖面；
> - **TFP（Transmission Fingerprint Protocol）**：以传动指纹校验仿真-现实对齐，作为物理证据通道；
> - **CBC（Compliance Buffer Certificate）**：把柔度储能变成 `A_buffer` 的物理实现与冲击预算；
> - **PJC（Physical Joint Certificate）**：整合为 `J^phys`，使 `ρ、α、J` 可追溯到物理量。
>

| `k_eff(τ)` | 非线性扭转刚度；`g=k_eff^{-1}` 柔度 |
| `h, Φ(h,τ)` | 迟滞状态及其转移 |
| `Δq_h = H[τ]` | Preisach 迟滞响应 |
| `E(a), r(a)` | 任务空间误差集 / 误差管半径 |
| `m(a)` | 跟踪裕度 `tol_task - r` |
| `α_S^phys(a\|h)` | 物理接地动作剖面 |
| `w_κ, A_sing, κ_max` | 条件数权重、奇异性空洞、奇异阈值 |
| `G_S^h=(V×H,E_h)` | 状态增广技能组合图 |
| `F_S, d_F, Θ_F` | 传动指纹、仿真-现实距离、证据阈值 |

## 2. 关键算法 伪代码

### IP-121 TGM

```python
def transmission_tube(skill, q_traj, tau_traj, h0, model):
    e, h = [], h0
    for q, tau in zip(q_traj, tau_traj):
        q_act = (q + model.eps_kin(q) + model.compliance(tau)
                   + model.hysteresis(tau, h) + model.thermal())
        h = model.phi(h, tau)
        e.append(q_act - q)
    return e, h

def task_error_radius(q, e, H_FK):
    J = jacobian(q)
    return max(norm(J @ ei) + 0.5 * abs(ei @ H_FK @ ei) for ei in e)

def physical_profile(skill, A, model, tol):
    alpha_phys = {}
    for a in A:
        e, h = transmission_tube(skill, a.q, a.tau, a.h0, model)
        r = task_error_radius(a.q, e, model.H_FK)
        alpha_phys[a] = (skill.alpha[a]
                         * (1.0 if r <= tol(a) else 0.0)
                         * cond_weight(a.q))
    return alpha_phys
```

### IP-122 HSC

```python
def state_augmented_search(G, h0, goal, eps_h, tau_e, h_buckets):
    dist = {(start, bucket(h0, h_buckets)): 0.0}
    pq = [(0.0, start, bucket(h0, h_buckets), [])]
    while pq:
        cost, sid, hb, path = heappop(pq)
        if sid == goal:
            return cost, path
        h = h_buckets[hb]
        for nxt in G.successors(sid):
            h_pred = Phi(h, tau[sid])
            hb_pred = nearest_bucket(h_pred, h_buckets)
            c = G[sid][nxt]['cost']
            if bucket_dist(h_pred, h_buckets[hb_pred]) <= eps_h and c <= tau_e:
                relax((nxt, hb_pred), cost + c, path + [(sid, hb)])
            if c + reset_cost(sid) <= tau_e:          # 迟滞复位分支
                relax((nxt, bucket(h0, h_buckets)),
                      cost + c + reset_cost(sid), path + [(sid, 'reset')])
    return None, None        # 不存在状态一致路径 → 组合不可行
```

### IP-123 KSA

```python
def cond_weight(q, kappa_max=10.0, sigma_ref=0.05):
    s = svdvals(jacobian(q))
    kappa = s[0] / max(s[-1], 1e-12)
    if kappa > kappa_max:
        return 0.0                     # A_sing：奇异性空洞
    return min(1.0, s[-1] / sigma_ref)

def physical_compatibility(Ai, Aj, q_of, h, kappa_max):
    Api = {a for a in Ai if cond_weight(q_of(a), kappa_max) > 0}
    Apj = {a for a in Aj if cond_weight(q_of(a), kappa_max) > 0}
    return len(Api & Apj) / max(len(Api | Apj), 1)
```

### IP-124 TFP

```python
def extract_fingerprint(log):
    spec = welch_psd(log.eps_kin, fs=log.fs)
    k_curve = fit_stiffness(log.tau, log.dq)
    w_h = hysteresis_loop_width(log.tau, log.dq)
    lost = lost_motion(log.forward, log.reverse)
    return Fingerprint(spec, k_curve, w_h, lost)

def sim_real_evidence(F_sim, F_real, Theta_F, w=(.3,.3,.2,.2)):
    d = (w[0] * wasserstein1(F_sim.spec, F_real.spec)
         + w[1] * norm(F_sim.k_curve - F_real.k_curve)
         + w[2] * abs(F_sim.w_h - F_real.w_h)
         + w[3] * abs(F_sim.lost - F_real.lost))
    return d <= Theta_F, d
```

### IP-125 CBC

```python
def compliance_buffer(k_eff, E_safe, m_eff):
    dq_safe = sqrt(2.0 * E_safe / k_eff)
    impulse_max = sqrt(2.0 * E_safe * m_eff)
    return Buffer(dq_safe=dq_safe, impulse_max=impulse_max,
                  evidence=('energy_budget', E_safe))
```

### IP-126 PJC

```python
def physical_joint_certificate(skill_seq, T_hat, F_sim, F_real, h0, budgets):
    ok_F, dF = sim_real_evidence(F_sim, F_real, budgets.Theta_F)
    if not ok_F:
        return ('reject', 'fingerprint_mismatch', dF)
    path = state_augmented_search(build_graph(skill_seq, T_hat), h0,
                                  goal=skill_seq[-1], eps_h=budgets.eps_h,
                                  tau_e=budgets.tau_e, h_buckets=budgets.H)
    if path is None:
        return ('reject', 'state_inconsistent')
    r = max(tube_radius(s, T_hat) for s in skill_seq)
    if r > budgets.tol:
        return ('reject', 'kinematic_violation', r)
    buf = compliance_buffer(T_hat.k_eff, budgets.E_safe, budgets.m_eff)
    return ('ok', PhysicalJointCert(
        rho=compose_robustness_chain(skill_seq),
        A_cert=(physical_buffer(buf), buffer_zone(buf.dq_safe)),
        gamma_ce=T_hat.gamma_ce, delta_a=budgets.delta_a,
        T_hat=T_hat, h=path[-1][1], F=F_real, E_safe=budgets.E_safe,
        eps_T=budgets.eps_T, eps_h=budgets.eps_h, r=r, dF=dF))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TGM | O(\|A\|·N_traj·K) | O(N_traj) | 辨识误差 `ε_T` 有界，误差管外扩保守 |
| HSC | O(\|H\|·\|V\|·log(\|H\|\|V\|) + \|H\|²\|E\|) | O(\|H\|\|V\|) | 状态转移 Lipschitz，复位可达 |
| KSA | O(\|A\|·d³) | O(\|A\|) | SVD 稳定，`κ_max` 硬阈值 |
| TFP | O(N log N + M) | O(N) | 指纹可比且漂移可检测 |
| CBC | O(1) | O(1) | 线性弹性区间内保守 |
| PJC | O(\|S\|·\|A\| + \|H\|\|V\|log) | O(\|A\|+\|H\|\|V\|) | 各预算闭合，证书 sound |

**正确性定理（Kinematic-Transmission Grounded Composition Soundness）**
假设第 54 轮 (A22)–(A28) 成立；新增 **(A29)** `sup ||T-T̂||_∞ ≤ ε_T`；**(A30)** `J(q)` 为 `L_J`-Lipschitz 且规划管上 `κ(J) ≤ κ_max`；**(A31)** 迟滞状态估计误差 `≤ ε_h`，复位可把状态拉回 `|h-h_0| ≤ ε_reset`。则对状态一致路径 `P`：
```
||x_act - x_cmd|| ≤ κ(J)(ε_T + ε_h + ε_comp) + ½ L_J (ε_T + ε_h + ε_comp)²
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - P(κ·ε_T > δ_x) - P(state mismatch) - β_E - P(δ_a > Θ_a)
```
三个新增“闸门”：**误差管闸**（物理覆盖）、**状态一致闸**（组合非马尔可夫）、**指纹有效闸**（仿真证据）。任一闸门未过，证书 `dom_J = out`。

## 6. 本轮最大风险

**一句话**：本轮把抽象动作空间重新钉在谐波减速器的“传动流形”上，用 `(q_act, ε_kin, k_eff, h, F)` 把覆盖、组合与证据全部物理化，但其 soundness **强依赖迟滞与传动误差的可辨识性、雅可比条件数在规划管内的有界性、以及传动指纹在温度/磨损下不漂移**；一旦辨识模型系统性低估迟滞或奇异区误差，物理接地反而会制造“比抽象模型更可信的假证书”，故必须以 **多工况辨识 + 条件数硬闸 + 指纹在线校验** 三重护栏，宁可在模型不确定处缩小动作空间，也绝不把“物理接地的精确假象”当作部署前提。
