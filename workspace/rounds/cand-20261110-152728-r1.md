# 第 46 轮（承接第 45 轮 v10；本轮灵感：灵巧手 × 模型蒸馏） · Contact-Distill：接触证书 × 保证书蒸馏的灵巧手边缘部署（四层架构 v11）

> 承接第 45 轮 v10 Energy-Context-Depth。v10 把感知从「永远在线」升级为能量租约约束下的上下文门控，但隐含假设 H5：末端执行器是单刚体，抓取成功可由末端位姿证书 P_t 完全刻画，且姿态/上下文/校准模型都能在机载算力上实时运行。UniBot 换装灵巧手后 H5 的两条腿同时断裂：**灵巧手**把操作变成 n 指接触的力闭合/滑动/形变问题，末端位姿正确但接触状态错误照样掉物；**模型蒸馏**是把 v10 的 VLM 上下文预测器与分层共形校准压到指尖边缘控制器的唯一现实路径，但蒸馏会把证书所依赖的稀有退化层先验压掉，并让学生在这些层上过自信。两个灵感词因此把问题推进到：**如何在蒸馏近似误差存在、接触退化层数据稀缺、能量与延迟双重预算下，签发从姿态到接触都 sound 的联合证书，并在学生不可信时及时升级或保守化**。

## 0. 直觉与动机

**灵感 1（灵巧手 → 从姿态证书到接触-抓取证书）**
直觉：末端位姿证书只回答「手在哪」，不回答「抓不抓得住」。灵巧手引入 n 指接触集合 K_t、摩擦锥、力闭合裕度 γ_t 与切向滑动裕度 s_t；透明/形变/手内遮挡会让纯视觉的接触估计退化，必须引入触觉模态。于是姿态证书旁边必须长出一个接触证书 G_t，且接触退化层 Ω_contact 与 v10 的可观测性层 Ω 交叉，形成联合分层 Ω^+ = Ω ∪ Ω_contact。抓取安全谓词不再是 φ(X_t)，而是 φ(X_t) ∧ ψ(G_t)。

**灵感 2（模型蒸馏 → 保证书蒸馏与蒸馏租约）**
直觉：v10 的上下文预测器 + 分层共形校准是重模型，指尖边缘控制器只有 <5ms 延迟、<2W 的预算，根本跑不动。蒸馏是唯一路径，但学生不是教师的无损拷贝：蒸馏间隙 δ_ω 在头部常见层很小、在稀有接触退化层却很大。证书链里一旦插入近似算子，若仍用教师半径签发学生证书，soundness 会静默泄漏。因此蒸馏必须被做成带分层间隙上界 δ̂_ω、带租约 ℓ_d、带弃权头的「保证书蒸馏」，而不是一次性的模型压缩。

**灵感 3（耦合 → 三级路由与风险前置升级）**
直觉：接触控制需要高频，而教师（VLM/大校准器）只能低频、高功耗、常驻云端。灵巧手被迫做三级路由 ρ_t ∈ {学生 S, 教师 T, 保守 C}，而路由本身又受能量租约 ℓ_e 约束。最尖锐的矛盾是：学生最不可信的层（滑动、透明、手内遮挡）正是最需要及时升级的层；若用学生自报置信度决定是否升级，就会在最危险处不升级。必须用独立审计的分层 δ̂_ω 和接触状态 κ 触发升级，绝不能用学生自报置信。

**耦合升级**：在 v10 四层架构上新增 **接触证书层** 与 **蒸馏信任层**。根信任层由「姿态租约 ℓ_p + 能量租约 ℓ_e」扩展为「ℓ_p + ℓ_e + 接触租约 ℓ_c + 蒸馏租约 ℓ_d」；L1 几何层从末端位姿扩到手指接触帧；L2 上下文层加入接触预测与蒸馏学生；L3 CAR 守卫升级为 v7，同时守卫姿态/接触/能量/蒸馏一致性；L4 DCL 采集滑动、接触丢失与蒸馏失误样本。四层 v11 = Pose-Cert × Contact-Cert × Distill-Cert × Data-Cert。

## 1. 形式化定义（增量：定义 54–58）

**定义 54（接触状态与力闭合证书）**
灵巧手 n 指，指尖接触集合 K_t ⊆ [n]，接触力 f_i ∈ R^3，摩擦锥 C_i(μ_i)。抓取矩阵 G_t = Σ_{i∈K_t} Ad_{T_i}^{-1} diag(...)。力闭合裕度
γ_t = min_{‖w‖=1} max_{f∈C(K_t)} wᵀ G_t f，
滑动裕度 s_t = min_{i∈K_t} (1 − ‖f_i^τ‖ / (μ_i f_i^n))_+。
接触证书 G_t = (κ_t, γ_t, s_t, ℓ_c)，其中接触层 κ_t ∈ K_strata = {firm, incipient-slip, slip, contact-loss, deformable}。
**接触 soundness**：P(grasp stable on [t,t+Δ] | G_t valid) ≥ 1−α_g，且 γ_t ≥ γ_min(κ_t)、s_t ≥ s_min(κ_t)。失效时 ψ(G_t) 为假，CAR 不得放行。

**定义 55（接触退化层与触觉-视觉联合可观测性）**
扩展分层 Ω^+ = Ω ∪ Ω_contact，Ω_contact = {手内遮挡, 透明抓取, 形变物体, 快速滑动, 接触丢失}。模态扩展 m ∈ M^+ 含 Tactile。联合可观测性
P(ω, κ | c_t, m) = Cat(θ_{c,m})，
触觉增益 G^tac_κ(m) = max(0, r_κ(m) − r_κ(m ∪ Tactile))，深度增益用于手内遮挡层。**预测性分层**由 ω̂ 扩展为 (ω̂, κ̂) 联合预测，深度/触觉的激活由联合退化概率驱动。

**定义 56（保证书蒸馏与蒸馏租约）**
教师 f_T、学生 f_S。分层蒸馏间隙
δ_ω = E_{x∼μ_ω}[ d(f_T(x), f_S(x)) ]，
其共形上界 δ̂_ω 满足 P(δ_ω ≤ δ̂_ω) ≥ 1−β。学生证书半径膨胀
r_ω^S(m) = r_ω^T(m) + L_f · δ̂_ω。
**Soundness 迁移**：若教师证书在层 ω 覆盖 ≥ 1−α_p，且 δ̂_ω 有效覆盖 ≥ 1−β，则学生证书覆盖 ≥ 1−α_p−β。
蒸馏租约 ℓ_d = (student_id, version, {δ̂_ω}, τ_d, cov(ω))。若某层标定样本不足 n_min 或漂移检测触发，则令 δ̂_ω = ∞，该层禁止学生单独决策，必须升级或保守化。

**定义 57（边缘-云-保守三级路由）**
路由 ρ_t ∈ {S, T, C}，延迟预算 L_max，学生功耗 P_S ≪ 教师 P_T。
U_d(ρ) = E[证书宽度缩减(ρ)] / (L(ρ) + λ_e P(ρ))，s.t. L(ρ) ≤ L_max、E(t+Δ) ≥ E_min。
**升级规则（风险前置）**：若 H(P(ω,κ|c_t)) > τ_H，或 (ω,κ) ∈ Ω_contact 且 δ̂_ω > δ_max，或 ℓ_d 过期，则 ρ_t ≥ T；若教师不可达，则 ρ_t = C（降速、增大 γ_min、冻结抓取）。学生弃权头经共形校准，保证 P(abstain | unsafe) ≥ 1−γ_a。

**定义 58（联合姿态-接触-蒸馏证书）**
联合证书 J_t^+ = (P_t, G_t, ℓ_p, ℓ_e, ℓ_c, ℓ_d, m_t, ρ_t)。
**联合 soundness**：
P( X_t ∈ P_t ∧ grasp stable | 全部租约有效 ) ≥ 1 − (α_p + α_g + β)。
**边际转移**：m_true ≥ m̂ − L_φ·rad(P_t) − L_g·(γ_min−γ_t)_+ − L_s·(s_min−s_t)_+ − L_e·(B_min−E(t))_+。
任一租约失效或路由不一致 ⇒ fail-closed 到保守抓取或安全停机。

## 2. 新增产出与既有 IP 升级

**IP-66 CONTACT-CERT ENGINE**
- 触觉-本体-视觉融合的接触集合 K_t 与接触层 κ_t 估计
- 力闭合裕度 γ_t、滑动裕度 s_t 的在线计算与分层共形校准
- 接触租约 ℓ_c 签发与级联失效

**IP-67 DISTILL-CERT ADAPTER**
- 分层蒸馏间隙 δ̂_ω 的独立审计集标定，样本不足层置 ∞
- 证书感知蒸馏目标：稀有层重加权 + 弃权头 + 覆盖违约罚项
- 学生半径膨胀 r_ω^S = r_ω^T + L_f·δ̂_ω；蒸馏租约 ℓ_d 与漂移检测

**IP-68 EDGE-ESCALATION SCHEDULER**
- 学生/教师/保守三级路由 U_d 求解
- 风险前置升级：用 κ 与 δ̂_ω 触发，而非学生自报置信

## 3. 算法骨架

每控制周期（接触环 1kHz，证书环 100Hz，蒸馏审计离线/低频）：
1. 读触觉、本体、力矩、视觉；CONTACT-CERT 估 K_t、γ_t、s_t、κ_t 并签发 ℓ_c
2. 读 ℓ_e、ℓ_d、c_t；EDGE-ESCALATION 按 κ_t、δ̂_ω、能量与延迟选 ρ_t
3. 若 ρ_t = S：用 student_radius 签发学生证书；若 δ̂_ω = ∞ 或弃权 → 升级 T 或保守 C
4. 若 ρ_t = T：教师签发，学生间隙用于下一轮审计
5. PSE 签发 P_t ∧ G_t；CAR v7 联合守卫，任一租约失效即 fail-closed
6. DCL 回灌滑动/接触丢失/蒸馏失误样本，触发 δ̂_ω 重标定

## 4. 本轮最大风险

**一句话**：蒸馏间隙在接触退化层（滑动/透明/手内遮挡）最大而学生恰恰在这些层上过自信，若蒸馏租约用学生自报置信或全层平均 δ̂ 校准，就会在最关键的抓取瞬间同时低估接触证书与姿态证书的误差并级联到安全谓词；因此必须以分层独立审计集校准 δ̂_ω、对样本不足层置 δ̂_ω=∞、并在升级不可达时降级为保守抓取。

## 2. 关键算法 伪代码

### IP-66 CONTACT-CERT ENGINE
```
def contact_cert(tactile, force, proprio, calib_c, t):
    K = detect_contacts(tactile)                 # 指尖接触集合
    gamma = force_closure_margin(K, force)       # 力闭合裕度
    s = slip_margin(tactile, force)              # 切向滑动裕度
    kappa = contact_stratum(K, gamma, s, tactile)
    ok = (gamma >= gamma_min[kappa]) and (s >= s_min[kappa])
    return G_t(kappa, gamma, s, lease_c(tau=t, valid=ok))

def contact_margin(G_t, e):
    return L_g[e]*max(0, gamma_min[G_t.kappa]-G_t.gamma) \
         + L_s[e]*max(0, s_min[G_t.kappa]-G_t.s)
```

### IP-67 DISTILL-CERT ADAPTER
```
def distill_gap_bound(teacher, student, audit_by_stratum, alpha_d, n_min):
    delta = {}
    for omega, D_omega in audit_by_stratum.items():
        if len(D_omega) < n_min:
            delta[omega] = INF        # 样本不足：禁止学生单独决策
            continue
        gaps = [dist(teacher(x), student(x)) for x in D_omega]
        delta[omega] = conformal_quantile(gaps, 1 - alpha_d)
    return delta

def student_radius(omega, m, calib, delta, L_f):
    if delta.get(omega, INF) == INF:
        return INF                    # 触发升级或保守
    return calib.r_T[omega][m] + L_f * delta[omega]

# 证书感知蒸馏目标：稀有/安全敏感层上权 + 弃权头 + 覆盖违约罚
# L = L_task + lambda*sum_w w_w*relu(cov_viol_w - eps) + mu*L_abstain
# abstain 头用独立集共形校准，保证 P(abstain|unsafe) >= 1 - gamma_a
```

### IP-68 EDGE-ESCALATION SCHEDULER
```
def edge_route(c_t, kappa, delta, lease_d, B_t, teacher_online, student):
    if not lease_d.valid() or energy_risk(B_t) > tau_e:
        return CONSERVATIVE if not teacher_online else TEACHER
    if (kappa in Omega_contact) or delta.get(kappa, INF) > delta_max:
        return TEACHER if teacher_online else CONSERVATIVE
    if student.entropy(c_t) > tau_H or student.abstain(c_t):
        return TEACHER if teacher_online else CONSERVATIVE
    return STUDENT

def conservative_grasp():
    # 降速、增大力闭合裕度、冻结新抓取
    return set_speed(v_safe), raise_gamma(gamma_safe), freeze_grasp()
```

### IP-51 CAR 升级守卫 v7
```
def car_guard_v7(e, x, cert, G_t, lease_p, lease_e, lease_c, lease_d, m_t, rho_t, t):
    if not (pose_lease_valid(lease_p,t) and energy_lease_valid(lease_e,t,E_min(e))
            and contact_lease_valid(lease_c,t) and distill_lease_valid(lease_d,t)):
        cascade_invalidate('pose_energy_contact_distill')
        return FailClosed()
    if not route_consistent(rho_t, lease_d):
        return FailClosed()
    r = student_radius(x.stratum, m_t, cert.calib, lease_d.delta, L_f) \
        if rho_t == STUDENT else radius_lookup(x.stratum, m_t, cert.calib)
    m_pose = L_phi[e] * r
    m_contact = contact_margin(G_t, e)
    m_energy = L_e * max(0, B_min - E(t))
    m = min(cert.lookup, lease_p.m, lease_c.m, persona_cap) - m_pose - m_contact - m_energy
    return m >= theta(e)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CONTACT-CERT | O(n·|K_strata|) 每 1ms | O(n) | 触觉/本体融合 + 分层共形 ⇒ P(stable|G_t)≥1−α_g |
| Distill Gap 标定 | O(Σ_ω |D_ω|) 离线 | O(|Ω^+|) | 分层共形上界 ⇒ P(δ_ω≤δ̂_ω)≥1−β |
| Edge Routing | O(|Ω^+|) 每 10ms | O(|Ω^+|) | 风险前置 ⇒ 学生仅在 δ̂_ω<∞ 且低熵层运行 |
| 联合证书 J_t^+ | O(1) | O(V+E) | 四租约有效 ∧ 路由一致 ∧ P_t,G_t 覆盖 ⇒ φ∧ψ |
| CAR v7 | O(1) | - | fail-closed 级联 ⇒ 无陈旧/透支/接触失效放行 |

**正确性定理**：若 ℓ_p、ℓ_e、ℓ_c、ℓ_d 均有效，教师证书在层 ω 满足条件覆盖 ≥1−α_p，δ̂_ω 在活跃层满足覆盖 ≥1−β，路由 ρ_t 满足（T 或 S 且 δ̂_ω<∞），且 P_t、G_t 满足定义 44/54 覆盖条件，则联合证书 J_t^+ 在能量、延迟与接触约束下 sound，覆盖下界 1−(α_p+α_g+β)。任一条件失效 ⇒ fail-closed 到保守抓取或安全停机。

## 4. 实验设计 E109–E114

| 实验 | 指标 | 门槛 |
|---|---|---|
| E109 接触证书 soundness | 滑动/掉物违例率；力闭合裕度保持 | 0 起；γ_t≥γ_min 占比 ≥99.9% |
| E110 蒸馏间隙标定覆盖 | 分层 δ̂_ω 实际覆盖率；稀有层样本充足率 | ≥1−β(β=0.05)；Ω_contact 层 ≥95% |
| E111 蒸馏后姿态证书 soundness | 学生 vs 教师 rad 比；学生覆盖违约 | rad 膨胀 ≤1.5×；违约 0 起 |
| E112 边缘路由实时性 | p99 延迟；平均功耗；教师升级率 | ≤5ms；≤2W；升级率 ≤15% |
| E113 灵巧手接触退化层 | 透明/滑动/手内遮挡抓取成功率；保守降级正确率 | ≥95%；≥99% |
| E114 100h 联合闭环 | 综合安全违例；最坏层覆盖保持；安全停机次数 | 0 起；覆盖≥1−α_p−β；0 起 |

**回退**：E110 稀有层样本不足 → 该层 δ̂=∞ 并强制升级；E112 延迟超标 → 降低教师升级频率并扩大保守路由；E109/E114 接触违例 → 回退 v10 姿态-only 证书并限制灵巧手抓取模式；E111 学生覆盖违约 → 关闭学生路由，全量教师或保守。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 蒸馏间隙在接触退化层被低估 | 高 | 分层独立审计 + 样本不足置 ∞ + 学生弃权头 |
| 学生过自信导致不升级 | 高 | 用 κ 与 δ̂_ω 触发升级，禁用学生自报置信作为唯一判据 |
| 教师不可达时误抓 | 高 | 保守抓取降级：降速/增力闭合裕度/冻结新抓取 |
| 触觉标定漂移导致 γ/s 估计偏差 | 中 | 在线残差监测 + 定期触觉重标定 + 接触租约快速过期 |
| 高频接触环与证书环时序错配 | 中 | 双环时间戳对齐 + 接触证书短租约 + 帧失配加速过期 |
| 蒸馏学生引入控制抖动 | 中 | 滞环路由 + 最小驻留时间 + 保守路由平滑切换 |

## 6. 本轮最大风险

**一句话**：蒸馏间隙在接触退化层（滑动/透明/手内遮挡）最大而学生恰恰在这些层上过自信，若蒸馏租约用学生自报置信或全层平均 δ̂ 校准，就会在最关键的抓取瞬间同时低估接触证书与姿态证书的误差并级联到安全谓词；因此必须以分层独立审计集校准 δ̂_ω、对样本不足层置 δ̂_ω=∞、并在升级不可达时降级为保守抓取。
