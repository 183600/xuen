# 第 6 轮（本轮灵感：「技能学习」×「激光雷达」）

> **基线**：第 5 轮 InstructGauge-RTDI（IP-334–339；定义 468–492；引理 63–68；实验 E473–E492）。第 1–4 轮 LeanGauge / MODGAUGE / ToolGauge / InstructGauge-WR 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。技能学习只扩展「经过准入的原语/选项」，激光雷达只提供「可证伪的几何见证」；二者任一不可用都必须退回 v5 的脚本原语 + 相机 SpatialCert，不能成为安全依赖。

## 0. 直觉与动机

**灵感 1（技能学习 → 带契约的「计划缓存」，而不是自由策略）**
直觉：人类修盲区时并不是每一步都从头规划；「接近—侧扫—偏振—擦拭」是一段被反复调用、越用越熟的动作单元。技能学习的真正价值，是把这类重复片段编译成可复用的 option，从而把每步规划开销摊薄。但一个学到的策略只是**训练分布上的压缩先验**：它会过拟合场景几何、会负迁移、会在前提不成立时仍然自信地输出动作。因此正确的接口不是「让技能直接接管执行器」，而是「技能 = 带前置/后置/不变式/工具集/回退的契约化选项」；进入系统前必须通过**准入证**（类型、能力闭包、契约证明、共形失效上界、OOD、回退完备），运行中必须被契约监控器约束。技能是缓存，缓存必须可失效、可撤销、可版本化。

**灵感 2（激光雷达 → 可证伪的「几何见证」，而不是几何真值）**
直觉：相机给语义，激光雷达给米制几何；它对遮挡后的自由空间、金属反光件、弱纹理表面尤其有用。但 LiDAR 不是 oracle：镜面/透明表面会丢回波或产生鬼影，稀疏扫描会漏小障碍，运动畸变会错位点云，外参标定会漂移。最危险的不是「看不见」，而是**静默地把未知报成自由**。因此 LiDAR 的正确角色是**见证者**：只对「多射线支持、入射角受限、无提前回波」的体素声明自由；其余一律输出 `UNKNOWN`；并用健康度 `h_t` 与标定残差 `ε_cal` 对自由空间做保守膨胀。见证只能**收紧**可行域，绝不能放宽。

**灵感 3（两者耦合 → 几何前提门控，必须被「技能级回退」切碎）**
直觉：技能选择依赖几何可供性（平面、边缘、空腔、可达区），而几何见证的假阳性会让技能在错误前提上启动；一个技能又往往连续执行几十步，错误会被技能长度放大。解法不是禁用技能或禁用 LiDAR，而是三根结构支柱：**技能契约继承**（技能不能扩权、后置必须蕴含父任务）、**几何见证单调性**（不确定即 `UNKNOWN`，只收紧不放宽）、**负迁移屏障 + 技能级回退**（OOD/契约/几何违背 ⇒ 截断到安全前缀并退回脚本原语；跨不可逆动作强制 K=1）。这样，感知误差最多导致一次「技能级中止」，而不是一条不可追回的物理轨迹。

## 1. 研究问题（本轮要回答什么）

- **Q1（技能准入）**：学到的技能如何在不扩权、不破坏安全契约的前提下进入原语库？准入条件能否被类型检查、契约证明与共形校准共同保证？
- **Q2（LiDAR 证书）**：如何把点云转成可审计的几何证书，并在镜面/透明/稀疏/运动畸变/标定漂移下保持「宁可 `UNKNOWN`、不可假自由」的保守性？
- **Q3（耦合放大）**：几何条件化的技能选择是否会把感知误差放大成技能级失败？能否用门控、契约组合与回退把它压回线性、可界？

## 2. 三条设计原则（雏形，正式化见产物区定义 493–500）

**P1 技能契约继承与准入（Skill Contract Inheritance）**
技能 `s = (pre, post, inv, β, tools, FB, v, hash)` 只能在预注册工具集内行动（`tools(s) ⊆ T₀`），且 `post_s ⇒ post_parent`；准入必须同时满足类型检查、SMT 契约证明、留出集共形失效上界、OOD 门槛与回退完备。任一项 `unknown` 一律拒绝（default deny）。技能库版本化、可撤销，漂移超阈自动失效。

**P2 几何见证单调性（Geometric Witness Monotonicity）**
LiDAR 证书 `W_t = (F_t, O_t, r_t, h_t, ε_t)` 只声明「多射线支持 + 入射角受限 + 无提前回波」的自由体素；健康度低、射线残差高、标定膨胀超界时输出 `UNKNOWN`。`UNKNOWN` 在规划中等价于「不可用」，只能退回相机 SpatialCert，绝不被当作自由空间。证书只能收紧可行域。

**P3 负迁移屏障与技能级回退（Negative-Transfer Barrier）**
技能仅在「几何前提已接地 + OOD 分数低于阈值 + 共形失效上界低于 α」时启用；技能链必须满足 `post_i ⇒ pre_{i+1}`，链长受限；执行中任一契约/几何违背 ⇒ 截断到最后一个安全前缀并退回脚本原语 `Π`；跨不可逆动作强制 K=1（继承 v3 的不可逆屏障）。

## 3. 与基线的接口（如何退化）

- LiDAR 不可用 / `h_t < h_min` / `r_t > r_max` / `ε_t > ε_max` ⇒ `W_t = UNKNOWN` ⇒ 退回 v5 相机 SpatialCert；
- 技能未准入 / OOD 超阈 / 几何前提 `UNKNOWN` / 契约链不成立 ⇒ 退回 v5 PrimitiveGraph 的脚本原语；
- 技能执行中契约或几何见证被违背 ⇒ 截断到最后安全前缀 + 回退脚本；跨不可逆动作 K=1（v5 屏障）；
- GSL 全部增强失效 ⇒ 行为等价于 InstructGauge-RTDI；RTDI 失效 ⇒ InstructGauge-WR；后续同 v5 退化链。

## 4. 预期贡献

1. 一个**技能准入证**口径，把技能学习纳入能力闭包：类型 + 契约 + 共形失效 + OOD + 回退，五项缺一不可；
2. 一个带健康度膨胀与 `UNKNOWN` 语义的**LiDAR 几何见证证书**，给出「漫反射 + 标定有界」前提下的条件 soundness，并显式拒绝镜面/透明场景；
3. 一个**几何门控的技能选择与负迁移界**，把技能级失败压到 `α + δ` 量级，并在不可逆处退化为单步；
4. 一条完整可证伪路径：E493–E512 覆盖准入 soundness、契约组合、复用收益、负迁移、见证 soundness、镜面/透明对抗、遮挡增益、50Hz 时序与全链路退化等价。

## 5. 本轮最大风险

**一句话**：LiDAR 的米制精度会制造「几何已经看清」的错觉，而镜面/透明/运动畸变会把**未知静默写成自由**；学到的技能又恰好依赖这些几何前提被选中并连续执行，于是错误可以满足几何契约却在语义上完全错误——真正的残余风险是「语义—几何错配」被技能长度放大，而非单个组件失效。

## 2. 形式化定义（要点）

**定义 493（技能契约 SkillContract）**
技能 `s` 是一个带契约的类型化 option：
```
s = (pre_s, post_s, inv_s, β_s, tools_s, FB_s, v_s, hash_s)
β_s : S → A^{≤L_s},  β_s.stop ∈ {success, fail, timeout}
tools_s ⊆ T₀,        FB_s ∈ Π_script ∪ {⊥}
```
语义三元组 `{pre_s} β_s {post_s}`，并要求 `inv_s` 在 `β_s` 执行期间归纳保持；`post_s ⇒ post_parent`（技能不能弱化父任务的后置）。`β_s` 内部跨不可逆动作的片段必须拆成 K=1 的独立提交，继承 v3 的不可逆屏障。`hash_s` 覆盖契约、策略参数与训练数据指纹；任一变更即新版本。

**定义 494（技能准入证 SkillAdmissionCert）**
```
Adm(s) = (type_ok, tools_ok, contract_ok, calib_ok, ood_ok, fallback_ok)
```
- `type_ok`：`s` 的类型签名与声明一致（`pre/post/inv` 的谓词类型、参数域、`β_s` 的输入输出类型）；
- `tools_ok`：`tools_s ⊆ T₀`；
- `contract_ok`：SMT 证明 `pre_s ⇒ pre_parent`、`post_s ⇒ post_parent`，且 `inv_s` 在 `β_s` 下归纳保持；不可证即拒绝，不做「运行时再说」；
- `calib_ok`：在留出集 `D_cal` 上，split-conformal 给出 `\hat f_s(α) ≤ α_target`；
- `ood_ok`：OOD 检测器在 `D_val` 上 FPR ≤ δ 且对已知负迁移技能召回 ≥ 1-δ；
- `fallback_ok`：`FB_s` 可终止，且其契约覆盖 `inv_s` 被违背后的状态。
```
Admit(s) ⇔ ∀ x ∈ Adm(s): x = pass
```
任一项为 `unknown` 一律拒绝（default deny）。

**定义 495（受证技能库 CertifiedSkillLibrary）**
```
L ⊕ s = L ∪ {(s, Adm(s), v_s, hash_s)}   若 Admit(s)
L ⊖ s = L \ {(s, ·, ·, ·)}                若 revoked(s) ∨ drift(s) > δ_drift
```
同一 `skill_id` 允许多版本共存；选择时只考虑「已准入 ∧ 未撤销 ∧ 漂移未超阈」的版本。热加载走 ROS Service，新增条目必须携带 `Adm`；撤销是 O(1) 标记，不阻塞在线执行。

**定义 496（LiDAR 几何见证 GeoWitness）**
给定点云 `P_t`、位姿 `T_t`、标定 `c_t`、健康向量 `h_t`：
```
W_t = (F_t, O_t, r_t, h_t, ε_t)
ε_t = ε_0 + κ · (1 - h_t) + ε_cal(c_t)
```
- `F_t`（保守自由空间）：体素 `x ∈ F_t` 当且仅当至少 `m` 条独立射线穿过 `x`、入射角 `≤ θ_max`、在 `x` 之前无回波、且多回波一致性通过；否则 `x ∉ F_t`（记为 `UNKNOWN`，不是自由）；
- `O_t`（占据空间）：回波点按 `ε_t` 膨胀后的占据体素；
- `r_t`：scan-to-map 射线残差（中位数与 p95）；
- `h_t`：回波率、强度正态性、标定残差、运动畸变估计的归一化健康度；
- 若 `h_t < h_min ∨ r_t > r_max ∨ ε_t > ε_max`，则 `W_t = UNKNOWN`。
`UNKNOWN` 在规划中等价于「该区域不可用」，只能退回相机 SpatialCert。

**定义 497（几何可供性 GeoAffordance）**
```
Γ_geo(P_t) = A_t = {(a_type, pose, params, conf)}
a_type ∈ {planar_patch, edge, cavity, free_corridor, reachable_region, clearance_gap}
```
前置条件接地：`Ground(pre_s, A_t) ∈ {true, false, unknown}`。只有 `true` 且 `conf ≥ 1-δ_geo` 才允许技能启用；`unknown` 视同 `false`。可供性参数必须来自 `F_t` 的多射线支持区域，不能从单条射线外推。

**定义 498（门控技能选择 GatedSkillSelection）**
```
s* = argmax_{s ∈ L} U(s | g, c)
s.t. Admit(s), Ground(pre_s, A_t) = true,
     OOD(s, o_t) ≤ δ,  \hat f_s(α) ≤ α_target
```
若可行集为空，则回退到 v5 的脚本原语 `Π`（PrimitiveGraph 实例化）。负迁移屏障直接体现在约束中：OOD 超阈或共形上界超阈的技能被排除，而不是靠事后补救。

**定义 499（技能链与契约组合 SkillChain）**
```
Chain = [s_1, …, s_k],  k ≤ K_max
∀ i: post_{s_i} ⇒ pre_{s_{i+1}}
tools(Chain) = ⋃_i tools_{s_i} ⊆ T₀
```
链的语义由 Hoare 组合给出：若每个 `{pre_i} β_i {post_i}` 成立且相邻蕴含成立，则 `{pre_1} β_1;…;β_k {post_k}` 成立。任一相邻蕴含不可证，规划器拒绝该链，退回单技能或脚本。

**定义 500（GSL-8C 闭环）**
```
W: 感知 (WristCam + LiDAR + 本体感受)
R: 推理 (Hypothesis + 技能检索)
S: 技能选择 (Γ_geo 可供性 + 门控 + OOD/共形约束)
C: 契约规划 (SkillChain + IAC + RT-CVC-TaskModel)
E: 执行 (option 执行；PP_C 可抢占；不可逆动作 K=1)
G: 几何见证 (W_t 生成与执行轨迹的几何一致性检查)
V: 验证 (CVC + SpatialCert + 技能契约监控 + FaultCert)
U: 更新 (技能统计 + 共形校准更新 + 漂移撤销 + 主张绑定)
```
v5 的 Diag/Recover 保留在 E/V 内部：契约或几何违背先走 `FaultCert`，恢复预案本身也必须是已准入技能或脚本原语。

## 3. 关键算法骨架

```python
# IP-340/IP-341 技能契约与准入
class SkillAdmission:
    def __init__(self, type_checker, smt, conformal, ood_detector, t0):
        self.tc = type_checker
        self.smt = smt
        self.conf = conformal
        self.ood = ood_detector
        self.T0 = t0

    def certify(self, s, parent_task, calib_set, val_set):
        """六项准入；unknown 一律拒绝"""
        type_ok = self.tc.check_signature(s) and self.tc.check_domains(s)
        tools_ok = s.tools.issubset(self.T0)
        # 契约证明：pre => parent.pre, post => parent.post, inv 归纳保持
        contract_ok = (self.smt.prove(s.pre, parent_task.pre) and
                       self.smt.prove(s.post, parent_task.post) and
                       self.smt.inductive(s.inv, s.beta))
        # split-conformal 失效上界
        f_hat = self.conf.upper_bound(calib_set, s, alpha=s.alpha)
        calib_ok = f_hat <= s.alpha_target
        # OOD 检测器：验证集 FPR 与负迁移召回
        ood_ok = (self.ood.fpr(val_set) <= s.delta and
                  self.ood.recall_negative(val_set) >= 1 - s.delta)
        # 回退完备：回退可终止且覆盖 inv 违背后的状态
        fallback_ok = (s.fallback is not None and
                       s.fallback.terminates and
                       self.smt.prove(s.inv_violated, s.fallback.pre))
        cert = SkillAdmissionCert(type_ok, tools_ok, contract_ok,
                                  calib_ok, ood_ok, fallback_ok, f_hat)
        return cert

    def admit(self, s, cert):
        return cert.all_pass()  # 任一项 unknown/fail 即 False

# IP-343 LiDAR 几何见证
class GeoWitnessBuilder:
    def __init__(self, m_support=2, theta_max=60.0, eps0=0.01,
                 kappa=0.05, eps_cal_max=0.02, h_min=0.6, r_max=0.03):
        self.m, self.theta_max = m_support, theta_max
        self.eps0, self.kappa = eps0, kappa
        self.eps_cal_max, self.h_min, self.r_max = eps_cal_max, h_min, r_max

    def build(self, cloud, pose, calib, health):
        if health.score < self.h_min:
            return GeoWitness.UNKNOWN
        pts = deskew(cloud, pose, health.motion_distortion)
        rays = raycast(pts, pose)
        # 保守自由空间：至少 m 条独立射线支持、入射角受限、无提前回波
        F = conservative_free(rays, m=self.m, theta_max=self.theta_max)
        O = inflate(pts, eps=health.eps_cal + self.eps0)
        r = scan_to_map_residual(pts, pose)
        eps = self.eps0 + self.kappa * (1 - health.score) + health.eps_cal
        if r > self.r_max or eps > self.eps_cal_max:
            return GeoWitness.UNKNOWN
        # 镜面/透明风险：低回波率 + 强度异常 + 大入射角 => 降级为 UNKNOWN
        if health.specular_risk > health.specular_max:
            return GeoWitness.UNKNOWN
        return GeoWitness(F=F, O=O, r=r, h=health.score, eps=eps)

# IP-344/IP-345 几何门控 + 技能选择 + 回退
class GatedSkillExecutor:
    def __init__(self, library, geo, cvc, monitor, scripted_pi):
        self.L, self.geo = library, geo
        self.cvc, self.mon = cvc, monitor
        self.Pi = scripted_pi

    def select(self, goal, obs, W, context):
        A = self.geo.affordances(W)          # Γ_geo
        feasible = []
        for s in self.L.admitted_versions():
            if self.geo.ground(s.pre, A) is not True:
                continue
            if s.ood_score(context) > s.delta:
                continue
            if s.f_hat > s.alpha_target:
                continue
            feasible.append((s, s.utility(goal, context)))
        if not feasible:
            return None                       # 退回脚本原语
        return max(feasible, key=lambda x: x[1])[0]

    def run_chain(self, chain, obs):
        executed = []
        for s in chain:
            ok, state = self._run_skill(s, obs)
            executed.append((s, ok))
            if not ok:
                # 技能级回退：截断到安全前缀，退回脚本
                safe_prefix = self.mon.last_safe_prefix()
                self.cvc.truncate_to(safe_prefix)
                return self.Pi.fallback(s.FB, safe_prefix)
        return executed

    def _run_skill(self, s, obs):
        if not self.cvc.joint_pre(s.pre):
            return False, obs
        for t, a in enumerate(s.beta(obs)):
            if a.irreversible and t > 0:
                # 不可逆动作绝不与后续动作捆绑
                self.cvc.commit_k1(a)
            if not self.cvc.joint_pre(a.pre):
                return False, obs
            self.cvc.apply(a)
            # 契约监控 + 几何见证一致性
            if not self.mon.contract_holds(s.inv, obs):
                return False, obs
            if not self.mon.geo_consistent(s, self.geo.latest()):
                return False, obs
        return True, obs

# IP-346 主闭环
def instructgauge_gsl(M, s, ell=None):
    """GSL 增强闭环：LiDAR 见证 + 技能准入/选择；任一失败退回 v5"""
    # 1. 几何见证（不可用 => v5 相机路径）
    W = M.geo.build(M.lidar.latest(), M.env.pose(), M.calib, M.health)
    if W is UNKNOWN:
        return instructgauge_rtdi(M, s, ell)          # v5 退化

    # 2. 技能选择（未准入/OOD/前提未知 => v5 脚本原语）
    chain = None
    if ell:
        goal = M.pgraph.parse(ell)
        skill = M.gsl.select(goal, M.obs, W, M.context)
        if skill is not None:
            chain = M.skill_planner.compose(skill, goal, M.L, W)
    if chain is None:
        return instructgauge_rtdi(M, s, ell)          # v5 退化

    # 3. 技能链 + RT-CVC 任务建模
    tau = M.rt_model.make_chain_task(chain, M.env.time())
    if not M.rta.verify({tau}):
        return instructgauge_rtdi(M, s, ell)

    # 4. 执行 + 契约/几何监控 + 技能级回退
    result = M.gsl.run_chain(chain, M.obs)

    # 5. 更新技能统计、共形校准与撤销
    M.L.update_stats(chain, result)
    M.L.revoke_on_drift(M.drift_estimator)
    return result
```

## 4. 推导

**引理 69（技能准入保持能力闭包）** 若 `Admit(s)`，则 `tools_s ⊆ T₀`；对任意由已准入技能组成的链 `Chain`，`tools(Chain) ⊆ T₀`。证明：准入证含 `tools_ok`；链的工具集是各技能工具集的并集，闭包对并集封闭。

**引理 70（技能链的契约组合 soundness）** 若 `∀i, {pre_i} β_i {post_i}`，且 `∀i<k, post_i ⇒ pre_{i+1}`，则 `{pre_1} β_1;…;β_k {post_k}`；若每个 `β_i` 归纳保持 `inv_i` 且初始 `inv_1` 成立，则链结束时 `inv_k` 成立。证明：Hoare 组合规则 + 相邻蕴含；归纳步骤由 `contract_ok` 的 SMT 证明保证。

**引理 71（几何见证的条件 soundness）** 在以下假设下：(A1) 表面为漫反射且非透明；(A2) 外参标定误差 ≤ `ε_cal`；(A3) `h_t ≥ h_min`、`r_t ≤ r_max`、`ε_t ≤ ε_max`；则对任意 `x ∈ F_t`，真实占据面到 `x` 的距离 ≥ `ε_t - ε_cal`，即 `F_t` 中不存在被漏报的占据体素（在膨胀界内）。证明：`F_t` 要求 `m` 条独立射线支持、入射角受限且无提前回波，排除单射线镜面鬼影；`O_t` 的 `ε_t` 膨胀覆盖标定与位姿误差；健康门控排除已知失效模式。若 A1 不成立，镜面/透明会导致低回波率或强度异常，按定义 496 触发 `UNKNOWN`，因此证书不会在违反前提时继续声明自由。**注意：这是条件性保证，不是无条件几何真值。**

**引理 72（负迁移界）** 设 `D_cal` 与部署分布可交换，split-conformal 给出分布内失效概率 `P(fail) ≤ α`。若部署分布与 `D_cal` 的总变差距离 ≤ `δ_TV`，则 `P(fail) ≤ α + δ_TV`。门控要求 `OOD(s,o_t) ≤ δ`，其验证集估计满足 `δ_TV ≤ δ + ε_est`，故被选技能的期望失效 ≤ `α + δ + ε_est`。证明：共形有效性 + 总变差耦合不等式；`OOD` 门槛把分布偏移限制在可估界内。**注意：`δ` 是经验估计，不是形式化证明。**

**引理 73（技能摊销收益与失效条件）** 设每步从头规划成本为 `c_plan`，技能检索成本 `c_ret`，技能平均长度 `L_s`，单位时间失效/撤销率 `λ`，回退成本 `c_fb`。使用技能后的每步决策成本为
```
c_skill = c_ret / L_s + c_monitor + λ · c_fb
```
技能复用有净收益当且仅当 `c_plan > c_ret / L_s + c_monitor + λ · c_fb`。证明：按更新过程做摊销；每次失效触发一次回退，长期失效率为 `λ`。该不等式直接给出「何时该禁用技能、退回脚本」的判据。

**引理 74（退化等价性）**
- `W = UNKNOWN`（LiDAR 不可用/健康度低/残差高/标定膨胀超界/镜面风险高）⇒ 调用 `instructgauge_rtdi`，等价 v5 相机 SpatialCert 路径；
- 无可选技能（未准入/OOD/几何前提未知/契约链不成立）⇒ 调用 v5 PrimitiveGraph 脚本原语；
- 技能执行中契约或几何见证违背 ⇒ 截断到 `last_safe_prefix` 并回退 `FB_s`，跨不可逆动作 K=1，等价 v5 的截断/屏障行为；
- 关闭 GSL 全部增强 ⇒ 行为与 InstructGauge-RTDI 逐调用等价（diff=0）。
证明：每个退化分支都以相同输入调用 v5 的对应函数；GSL 不新增工具、不改 v5 契约；分支条件是 `UNKNOWN`/空可行集/违约，均为显式可检测事件。

## 8. 本轮最大风险

**一句话**：**LiDAR 的米制精度会制造「几何已经看清」的错觉，而镜面/透明/运动畸变会把未知静默写成自由；学到的技能又恰好依赖这些几何前提被选中并连续执行，于是错误可以满足几何契约却在语义上完全错误**——技能长度把「语义—几何错配」放大成一段看似合规的物理轨迹，而契约监控器只检查几何/状态谓词，无法识别语义错误；缓解必须依赖**主动弃权（`UNKNOWN`）+ 技能级回退 + 不可逆屏障**，而不是假设 LiDAR 或技能契约本身足够可靠。
