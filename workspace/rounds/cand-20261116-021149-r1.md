# 第 12 轮（新灵感循环第 3 轮；本轮灵感：「末端位姿」×「仿真到现实」）
> **基线**：第 11 轮 MetricVoiceGauge-GSCF-SRA-JSSE（定义 549–561；引理 92–96；实验 E591–E610）。
> 本轮纪律：**共同锚点 + 有界证据**。v11 的三重守护（GSCF/SRA/JSSE）把安全拆进语义场、任务空间、关节空间三种坐标，却只用 β_GSCF 与一次性标定的 ε_fk 做桥；上轮最大风险正是遮挡、动态、标定漂移下三者同时失效。v12 的两个灵感分别治理两种债：**坐标债**（三个守护没有共同可测量锚点）与**证据债**（β、γ_min、ε_fk、ε_sra 都是真实数据上一次性标定的静态常数，无法覆盖稀有/危险场景）。铁律不变：任一新增模块失效 ⇒ 注入声明中立元，行为严格**等价**于 v11（EPCA/S2RC/DTAP 失效）或**支配**于 v11（额外收缩），绝不出现新物理行为。

## 0. 直觉与动机

**灵感 1（末端位姿 → 从三套坐标到共同锚点）**
直觉：v11 的块证书 Ĉ_t⁺⁺ 同时承诺三件不同空间里的事——GSCF 说「语义/几何场可信」，AC 说「任务空间中止点是 p*」，JSSE 说「关节空间中止集合是 Q_abort 且 FK(q_abort)=p*±ε_fk」。三者之间只有两个标量桥：β_GSCF 与 ε_fk。真正的问题是 **ε_fk 是离线标定的静态常数**：负载变化、热漂移、连杆柔性、接触力都会让真实末端位姿偏离 FK 预测；一旦偏离，JSSE 以为自己在 p*，实际不在，v11 的「等价中止」只是名义等价。末端位姿恰好是唯一同时可被三处独立测量的变量：任务规划器可命令 T^cmd，关节编码器+标定运动学可计算 T^fk，外部感知/动捕/标定相机可观测 T^obs。于是 v12 的核心创新是 **末端位姿共识锚（End-Effector Pose Consensus Anchor, EPCA）**：把三套坐标统一到 SE(3) 残差 e_t^pose 与位姿证书管 ρ_p 上；块证书与中止映射都必须携带「位姿见证」，1kHz JSSE 循环新增 e_t^pose ≤ ρ_base 检查。理论上关键一步：把「ε_fk 是可信常数」这个不可在线检验的强前提，换成「位姿残差在线可测且落在 ρ_base 内」这个每秒 1000 次可检验的弱前提；观测不可用时退回 ε_fk，等价 v11；观测可用时只增加约束、只收缩动作集。

**灵感 2（仿真到现实 → 把仿真从神谕降为有界证据）**
直觉：证书里的 β、γ_min、ε_fk、ε_sra、ε_jsse 都是真实数据上一次性标定的静态常数，而稀有危险场景（高加速中止、透明/反光物体、人与机器人抢道、接触丰富的抓取）在真实世界采样成本高、伦理上不能穷举。仿真可以穷举这些场景，但 sim-to-real gap 未知；直接信仿真等于把「标定一次」的静态风险换成「仿真保真度未知」的更大静态风险。v12 的做法不是「用仿真替代现实」，而是把仿真降为 **假设生成器 + 危险场景试验台**：在配对仿真-现实数据上，用分层共形预测为每个证书相关泛函 f（最小间隙、中止时间、跟踪误差、接触冲量）给出有限样本现实差距上界 Δ_f^{1−α}(b)，并把差距做成**状态相关场** Δ_f(s)——v10 把信任变成语义场，v11 把几何自洽变成几何场，v12 把仿真-现实差距变成**现实差距场（Reality Gap Field, RGF）**。任何仿真派生量都必须支付该场给出的「现实税」；真实状态落在未标定支撑层之外时 Δ=∞，自动退回 v11 的真实标定证书，而不是静默信任。

**三者咬合**
EPCA 提供可测的位姿见证与中止等价误差；S2RC 提供有限样本现实差距界与支撑域；DTAP（数字孪生中止预认证器）用仿真预筛中止轨迹，但签发必须同时满足「仿真差距界覆盖」与「现实位姿见证一致」的**双见证规则**。三者的关系是：**仿真提出候选，现实签发证书**；任一见证缺失时退回 v11，两个见证都自称有效但互相矛盾时收缩到 Π_r 并位姿保持，绝不选择「更乐观」的一方。块证书因此从 v11 的 Ĉ_t⁺⁺ 升级为锚定证据证书 Ĉ_t⁺⁺⁺。

## 1. 轻量形式化（完整定义见产物区 562–577）

- **位姿共识残差**：e_t^pose = d_SE3(T_t^fk, T_t^obs) + d_SE3(T_t^cmd, T_t^fk)，其中 d_SE3 为 SE(3) 加权测地距离；e_t^pose 同时度量「本体感觉 vs 外部观测」与「命令 vs 执行」两条链的偏差。
- **位姿证书管**：ρ_base 为真实标定的共识半径，ε_obs 为外部观测误差上界，ρ_p = ρ_base + ε_obs。若 e_t^pose ≤ ρ_base，则 d_SE3(T_t^cmd, T_t^true) ≤ ρ_p（引理 97）。
- **位姿见证中止**：Q_abort^pose = {q ∈ Q_abort | d_SE3(FK(q), p*) ≤ ρ_p, q ∈ C_q_safe}；q_abort ∈ Q_abort^pose 才签发中止证书，否则退回 v11 映射或保持。
- **现实差距场**：对每个 f，按支撑层 b(s) 分层共形校准 Δ_f^{1−α}(b)；Δ_f(s) = Δ_f^{1−α}(b(s)) 当该层可校准，否则 Δ_f(s)=∞。证书变为 β_S2RC = β_GSCF + sup_ζ Δ_clearance(s)，ρ_p^S2RC = ρ_base + ε_obs + Δ_pose(s)。
- **双见证**：n_t^wit = 1 当且仅当 s_t 在已校准支撑层、S2RC 差距界有效、且现实位姿观测与数字孪生预认证的终端位姿在 ρ_p^S2RC 内一致；否则不签发 DTAP 证书。
- **共模失效语义**：若 EPCA 与 DTAP 都自称有效但位姿差超过 τ_wit，或两条证据链同时不可用 ⇒ K_eff←2（Π_r）+ 位姿保持；这是对 v11 的**支配**而非等价。

## 2. 研究问题（轮次升级版）

- **Q1（位姿共识锚）**：如何以末端位姿为共同锚点，把 v11「FK(q_abort)=p*±ε_fk」的静态标定假设升级为可在线检验的位姿共识证书，使中止等价误差被 ρ_p 连续界定，并把 1kHz 额外开销压到 ≤0.05ms、不破 JSSE 的 0.8ms 时限？
- **Q2（有界 Sim2Real）**：如何把仿真到现实差距形式化为「分层共形上界 + 支撑域 + 状态相关场」，使任何仿真预认证的中止轨迹都携带有限样本现实余量，且 OOD/支撑缺失时 Δ=∞ 自动退回 v11，而非静默信任仿真？
- **Q3（双见证与共模防护）**：位姿见证与仿真见证如何在 5Hz 块生成/50Hz 守卫/1kHz 投影三级时间尺度上组合，使「两见证一致」可计算、可留痕、可审计，并在两见证矛盾或同时失效时收缩而不产生新物理行为？

## 3. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 位姿共识律（Pose Consensus, EPCA）**
任何跨空间证书（任务空间 p* ↔ 关节空间 q ↔ 感知位姿）不得仅依赖离线运动学常数；只要存在独立于语义/几何感知栈的外部位姿观测，就必须以 SE(3) 共识残差在线见证。位姿分歧只许收缩动作空间或退回 v11，不许扩权；观测不可用时显式退回 ε_fk，并标记证据等级。

**P17 仿真假设律（Simulation-as-Hypothesis, S2RC）**
仿真只能生成候选、预筛危险轨迹、提供先验，不能直接签发安全证书。任何仿真派生量必须携带：配对数据版本、分层共形差距界、支撑层编号与样本量；支撑层不可校准或真实状态越出支撑域时 Δ=∞，必须退回真实标定证书。**仿真负责提出，现实负责签发。**

**P18 双见证与共模防护律（Two-Witness & Common-Mode, DTAP）**
中止决策需要至少两条**异质**证据链：本体/外部位姿共识（EPCA）与仿真-现实差距证书（S2RC）。单见证只允许 v11 等价行为；双见证一致才允许 DTAP 预认证；双见证矛盾或同时失效 ⇒ 收缩到 Π_r 并位姿保持。禁止在两见证不一致时做插值或选择更乐观的一方。

## 4. 与基线的接口（如何退化）

- **EPCA 失效**（无外部位姿/标记丢失/时间同步失败/观测超时）⇒ ρ_base←ε_fk、删除位姿检查、Q_abort 使用 v11 最近点映射：行为**等价 v11**；
- **S2RC 失效**（配对数据过期、共形校准失败、支撑层样本不足、支持监控 OOD）⇒ Δ←∞、关闭仿真证据、使用 v11 真实标定 β_GSCF/ε_fk：行为**等价 v11**；
- **DTAP 失效**（孪生缓存缺失、预认证超时、仿真版本不匹配）⇒ 不做仿真预认证、使用 v11 中止映射：行为**等价 v11**；
- **双见证矛盾**（EPCA 与 DTAP 都自称有效，但终端位姿差 > τ_wit）⇒ K_eff←2（Π_r 级）+ 位姿保持，物理行为**支配**于 v11（只收缩不扩权）；
- **GSCF/SRA/JSSE 失效** ⇒ 沿 v11 Level-1/2/3 退化；STF/NRB/AC/ID/MW/v8 失效 ⇒ 沿 v11 → v10 → v9 → … 原退化链；
- **ID**：EPCA/S2RC/DTAP 一律 φ^elig=false 永不消融；仅「仿真数据版本/支撑层统计」可作为离线蒸馏对象；**MW** 契约表增列 EPCA/S2RC/DTAP 的 D_m/Ŵ_m/M_m/E_m 配额行。

## 5. 预期贡献

1. **位姿共识证书**：把 v11 中止等价性的静态 ε_fk 假设替换为在线可测的 SE(3) 共识半径 ρ_p，使「JSSE 投影后偏离 p*」这一上轮风险从不可观测变成可触发中止的可观测量（引理 97–98）；
2. **现实差距场**：用分层共形 + 支撑域把 sim-to-real 差距变成状态相关、有限样本有效的证书余量，使仿真能安全地参与稀有/危险中止场景的预认证（引理 99–100）；
3. **双见证共模防护**：EPCA 与 S2RC 的异质证据在 DTAP 中锁合，矛盾即收缩，专门治理 v11「三守护同时失效只剩急停」的共模风险（引理 101）；
4. **E611–E630** 覆盖位姿共识标定、负载/热漂移、共形覆盖、支撑 OOD、孪生预认证、双见证对抗、长跑与竞赛。

## 6. 本轮最大风险

**一句话**：分层共形界的有效性依赖配对数据的可交换性与支撑覆盖，一旦真实分布发生未检测的漂移（新接触材质、负载突变、强反光/透明物体、光照变化），Δ 会被系统性低估，而外部位姿观测可能与语义/几何感知共享同源退化，于是数字孪生会以「有证据」的方式预认证一条现实中不安全的轨迹——这是比 v11 更隐蔽的共模失效，因为 v12 的错误不再是「没有证据」，而是「证据本身同时错了」。

**新增定义 562（位姿共识三元组与 SE(3) 残差）** 每控制周期维护三个末端位姿估计：T_t^cmd（来自 AC 任务轨迹）、T_t^fk（由关节编码器与标定运动学 FK 计算）、T_t^obs（由独立外部位姿传感器观测）。在局部无奇异邻域内定义加权测地距离 d_SE3(T₁,T₂)=‖log(T₁⁻¹T₂)‖_W，W 对平移与旋转分别加权。共识残差：
```
e_t^prop  = d_SE3(T_t^fk,  T_t^obs)
e_t^track = d_SE3(T_t^cmd, T_t^fk)
e_t^pose  = e_t^prop + e_t^track
```
e_t^pose 同时度量「本体感觉 vs 外部观测」与「命令 vs 执行」两条链的偏差。要求 T_t^obs 来自独立于 GSCF/STF 检测栈的传感模态（动捕、标定相机、工具标记），否则不构成异质见证。

**新增定义 563（位姿证书管）** 位姿证书管 P_ρ(T)={T′ | d_SE3(T′,T)≤ρ}。ρ_base 由 E611 标定，覆盖编码器分辨率、FK 标定误差、连杆柔性、热漂移与负载引起的慢变偏差；ε_obs 由 E611 标定，为外部位姿观测误差上界。若 S2RC 有效，Δ_pose(s_t) 为现实差距场给出的位姿差距上界，否则 Δ_pose=0。定义：
```
ρ_p^S2RC(t) = ρ_base + ε_obs + Δ_pose(s_t)
```
有效条件：e_t^pose ≤ ρ_base（观测可用时）；若观测不可用，EPCA 关闭并退回 v11 的 ε_fk。

**新增定义 564（任务空间位姿安全集与位姿有效域）** P_safe(t) 为任务空间位姿安全集：满足工作空间边界、工具/夹爪无碰撞、抓取可行域、姿态限位、任务速度/加速度约束的位姿集合。位姿有效域：
```
U_t^pose = fresh(T_t^obs, T_pose) ∧ sync(T_t^obs, T_t^fk) ≤ τ_sync
           ∧ e_t^pose ≤ ρ_base ∧ T_t^fk ∈ P_safe(t)
           ∧ independence(T_t^obs, GSCF/STF)
```
其中 τ_sync 为时间同步阈值（E611），independence 要求外部位姿观测不依赖语义检测/嵌入，避免与 GSCF 共模。

**新增定义 565（位姿见证中止）** 给定任务空间中止点 p*，v11 的 Q_abort 只要求 FK(q)=p*±ε_fk。v12 改为位姿见证中止集合：
```
Q_abort^pose(p*) = { q ∈ Q_abort | d_SE3(FK(q), p*) ≤ ρ_p^S2RC, q ∈ C_q_safe }
q_abort = argmin_{q∈Q_abort^pose(p*)} ‖q − q_current‖_{W_q}
```
若 Q_abort^pose 为空，则不签发位姿见证中止证书：EPCA 有效时退回 v11 最近点映射并标记证据降级；若位姿残差已越界，则直接位姿保持。

**新增定义 566（仿真-现实配对泛函与单样本差距）** 对每个证书相关泛函 f∈F（最小间隙 clear、中止时间 abort、跟踪误差 track、接触冲量 impulse、位姿误差 pose），在配对复位协议下采集：
```
D_n^pair = { (s_i, a_i, f_i^sim, f_i^real) }_{i=1..n}
Δ_f(s_i,a_i) = | f_i^real − f_i^sim |
```
配对协议要求同一初始状态、同一命令序列、同一复位点；仿真与现实的时钟/单位/坐标先做标定对齐。D_n^pair 的哈希 H(D_pair) 与仿真版本 V_sim 写入契约与台账。

**新增定义 567（分层共形现实差距上界）** 将状态空间按仿真 kNN 密度与任务特征分为支撑层 b(s)（如密度分位 5 层 × 任务类型 4 类）。对每层 b 的 n_b 个校准样本，定义单侧共形分位：
```
Δ_f^{1−α}(b) = Quantile_{ ⌈(n_b+1)(1−α)⌉ / n_b }( { Δ_f(s_i,a_i) : b(s_i)=b } )
```
若 n_b < n_min 或层内可交换性被拒绝（E617 检验），置 Δ_f^{1−α}(b)=∞。在层内可交换假设下，对新样本有边际覆盖 P(Δ_f ≤ Δ_f^{1−α}(b) | b) ≥ 1−α。对时间相关数据使用块共形（块长=相关长度）或在线共形更新；对 |F| 个泛函可用 Bonferroni（α/|F|）或同时共形带。

**新增定义 568（仿真支撑域与支持违规）** 在归一化特征空间中定义 D_k(s) 为 s 到第 k 个仿真状态的距离；δ_sup 由仿真分布校准，使仿真样本落入 S_sim 的概率 ≥1−β_sup。S_sim=∪_{b:n_b≥n_min} b。支持违规分数：
```
supp_viol(s) = max(0, D_k(s) − δ_sup) / δ_sup
```
s∉S_sim 时，任何仿真派生量的保证失效，必须取 Δ=∞。

**新增定义 569（现实差距场）** 对每个 f，定义状态相关现实差距场：
```
Δ_f(s) = Δ_f^{1−α}(b(s))   若 s ∈ S_sim 且 b(s) 可校准
       = ∞                 否则
```
仿真证据有效域：
```
U_t^s2r = (s_t ∈ S_sim) ∧ (V_sim = V_sim^cert) ∧ (H(D_pair)=H_cert)
          ∧ (age(D_pair) ≤ T_pair) ∧ (Δ_clearance(s_t) < ∞)
```
s_t 为当前块/中止轨迹上的状态；轨迹上取 sup 时 Δ 逐点计算后取最大。

**新增定义 570（S2RC 膨胀证书）** 在 v11 证书余量上叠加现实差距场：
```
β_S2RC(ζ) = β_GSCF(ζ) + sup_{s∈traj(ζ)} Δ_clearance(s)
ĝ_min^S2RC = min_k F̂_q,clearance − β_S2RC
ρ_p^S2RC(t) = ρ_base + ε_obs + Δ_pose(s_t)
```
若 S2RC 失效，β_S2RC←β_GSCF、Δ_pose←0、ρ_p^S2RC←ρ_base+ε_obs，并在证书上标记 `s2r=off`；此时所有含 β_S2RC/Δ 的项按 v11 值计算，行为等价 v11。

**新增定义 571（DTAP 数字孪生中止预认证）** 数字孪生以 V_sim 版本生成候选中止轨迹 {τ_j^sim}。预认证过滤器：
```
sim_margin_j ≥ d_safe + β_S2RC(state) + L_p·ρ_p^S2RC
sim_terminal_pose_j ∈ P_safe(t)
```
通过者预计算 Q_abort^DT，并缓存 τ_j^sim 的终端位姿 T_j^sim 与最小间隙。仿真**只提案**：Q_abort^DT 不得直接执行，必须经双见证规则签发。若孪生缓存缺失/版本不匹配/预认证超时，DTAP 关闭，使用 v11 中止映射。

**新增定义 572（双见证规则）** 定义三个见证位：
```
n_t^pose = 1  若 U_t^pose（EPCA 有效）
n_t^s2r  = 1  若 U_t^s2r（S2RC 有效）
n_t^wit  = 1  若 n_t^pose=1 ∧ n_t^s2r=1
              ∧ d_SE3(T_t^obs, T_t^sim(q_abort)) ≤ τ_wit
```
其中 τ_wit=ρ_p^S2RC+δ_wit，δ_wit 为见证时间对齐余量（E611）。若 n_t^pose=n_t^s2r=1 但 n_t^wit=0，标记**见证矛盾**（witness_contradiction=1），触发 K_eff←2 + 位姿保持；若两者皆 0，同样收缩，不尝试插值或选择乐观一方。单见证（仅 pose 或仅 s2r）只允许 v11 等价行为。

**新增定义 573（锚定证据块证书）** 升级 v11 定义 552：

Ĉ_t⁺⁺⁺ = (ĝ_min, ê_max, γ̂_grasp, β_GSCF, n_t, n_t^reason, Q_abort,

- **锚定模式**：EPCA、S2RC、DTAP 均有效时，要求 v11 条件 ∧ U_t^pose ∧ U_t^s2r ∧ n_t^wit=1 ∧ Q_abort^pose≠∅。任一不满足 ⇒ 证书无效，按定义 574 收缩。

**新增定义 574（门控与有效块长）** 在 v11 定义 553 上增加位姿/仿真/见证项：

# IP-365 EndEffectorPoseConsensusAnchor：末端位姿共识锚（1kHz）
class EndEffectorPoseConsensusAnchor:
    def __init__(self, kin, eps_obs, rho_base, tau_sync=0.002, delta_wit=0.002,
                 clock=None):
        self.kin, self.eps_obs, self.rho_base = kin, eps_obs, rho_base
        self.tau_sync, self.delta_wit = tau_sync, delta_wit
        self.T_cmd = self.T_fk = self.T_obs = None
        self.e_pose = math.inf
        self.fresh = False
        self.clock = clock

    def d_se3(self, T1, T2):
        return np.linalg.norm(se3_log(T1 @ np.linalg.inv(T2)), ord='fro')

    def update(self, T_cmd, q, T_obs, t_obs):
        T_fk = self.kin.fk(q)
        self.T_cmd, self.T_fk, self.T_obs = T_cmd, T_fk, T_obs
        self.e_prop = self.d_se3(T_fk, T_obs)
        self.e_track = self.d_se3(T_cmd, T_fk)
        self.e_pose = self.e_prop + self.e_track
        self.fresh = (T_obs is not None and
                      abs(self.clock.now() - t_obs) <= self.tau_sync)
        return self.e_pose

    def pose_ok(self):
        return self.fresh and self.e_pose <= self.rho_base

    def certified_radius(self, delta_pose=0.0):
        return self.rho_base + self.eps_obs + delta_pose

    def map_abort_pose(self, p_star, Q_abort, q_current, delta_pose=0.0):
        rho = self.certified_radius(delta_pose)
        cand = [q for q in Q_abort
                if self.d_se3(self.kin.fk(q), p_star) <= rho]
        if not cand:
            return None
        return min(cand, key=lambda q: np.linalg.norm(q - q_current))


# IP-366 Sim2RealRealityGapCertificate：现实差距场 + 分层共形（5Hz）
class Sim2RealRealityGapCertificate:
    def __init__(self, alpha=0.05, n_min=30, k=8, T_pair=86400.0):
        self.alpha, self.n_min, self.k = alpha, n_min, k
        self.T_pair = T_pair
        self.strata = {}          # b -> {delta: {f: value}, n: int, version}
        self.V_sim = None
        self.H_pair = None
        self.calibrated_at = -math.inf

    def calibrate(self, pairs, V_sim, H_pair, now):
        # pairs: [(s, f_sim, f_real)]
        self.strata = self._build_strata(pairs)
        for b, items in self.strata.items():
            n_b = len(items)
            if n_b < self.n_min:
                for f in F_KEYS:
                    items['delta'][f] = math.inf
                continue
            for f in F_KEYS:
                scores = sorted(abs(it['f_real'][f] - it['f_sim'][f])
                                for it in items)
                rank = math.ceil((n_b + 1) * (1 - self.alpha))
                items['delta'][f] = scores[min(rank, n_b) - 1]
        self.V_sim, self.H_pair, self.calibrated_at = V_sim, H_pair, now

    def in_support(self, s):
        b = self._stratum(s)
        return b in self.strata and self.strata[b]['n'] >= self.n_min

    def delta(self, f, s):
        b = self._stratum(s)
        if not self.in_support(s):
            return math.inf
        return self.strata[b]['delta'][f]

    def s2r_valid(self, s, V_sim, H_pair, now):
        return (V_sim == self.V_sim and H_pair == self.H_pair and
                (now - self.calibrated_at) <= self.T_pair and
                self.delta('clearance', s) < math.inf)

    def inflate_clearance(self, beta_gscf, traj_states):
        return beta_gscf + max(self.delta('clearance', s) for s in traj_states)

    def inflate_pose(self, rho_base, eps_obs, s):
        d = self.delta('pose', s)
        return math.inf if math.isinf(d) else rho_base + eps_obs + d

            return None
        okay = [tau for tau in sim_trajs
                if tau.margin >= self.d_safe + chunk.cert.beta_gscf + delta_c
                and tau.terminal_pose in chunk.p_safe]
        if not okay:
            self.cache[key] = None
            return None
        best = min(okay, key=lambda tau: tau.cost)
        self.cache[key] = best
        return best

    def witness(self, q_abort, state, sim_traj, now):
        # 双见证：外部位姿 vs 孪生预期终端位姿
        if not self.epca.pose_ok():
            return False
        if not self.s2rc.s2r_valid(state, self.V_sim, self.H_pair, now):
            return False
        T_sim = self.twin.pose_at(q_abort)
        rho = self.s2rc.inflate_pose(self.epca.rho_base, self.epca.eps_obs, state)
        tau_wit = rho + self.epca.delta_wit
        return self.epca.d_se3(self.epca.T_obs, T_sim) <= tau_wit


# IP-354（v12 升级）：锚定证据分块执行器
class AnchoredEvidenceChunkCertifier(TriGuardChunkCertifier):
    def __init__(self, *a, epca=None, s2rc=None, dtap=None, **kw):
        super().__init__(*a, **kw)
        self.epca, self.s2rc, self.dtap = epca, s2rc, dtap

    def generate_chunk(self, state, ctx, stf, gscf, sra, nrb):
        if self.epca is None or not self.epca.pose_ok() or self.s2rc is None:
            return super().generate_chunk(state, ctx, stf, gscf, sra, nrb)  # v11
        K = self.effective_K(ctx, self.epca, self.s2rc)   # 定义 574
        if K == 1:
            return self._single_step_fallback(state)
        best = None
        for cand in self.policy.sample_sequences(state, K, n=64):
            pred = self.Fq.rollout(state, cand)
            beta_gscf = self.beta_base + self.lam * gscf.field_on_footprint(pred.corridor)
            delta_c = max(self.s2rc.delta('clearance', s) for s in pred.states)
            if math.isinf(delta_c):
                continue
            beta_s2rc = beta_gscf + delta_c
            g_min = pred.min_clearance - beta_s2rc
            e_max = pred.max_effort + beta_s2rc
            if g_min < self.d_safe or e_max > state.tau_eff:
                continue
            pts = self._abort_points(state, cand, pred)
            if not pts:
                continue
            q_abort = self.epca.map_abort_pose(
                pts[0], self._Q_abort_for(pts[0]), state.q_current,
                delta_pose=self.s2rc.delta('pose', state))
            if q_abort is None:
                continue
            chunk = Chunk(cand, AnchoredCert(g_min, e_max, beta_gscf, beta_s2rc,
                                             self.epca.certified_radius(
                                                 self.s2rc.delta('pose', state)),
                                             pts, q_abort), pts)
            chunk, verdict = nrb.review_chunk(chunk, stf, ctx)
            if chunk is None:
                continue
            n_reason, _ = sra.reason_on_chunk(chunk, stf, gscf, ctx)
            chunk.cert.n_reason = n_reason
            if not all(n_reason):
                continue
            sim_traj = self.dtap.precertify(chunk, state, ctx.now) if self.dtap else None
            if sim_traj is not None and self.dtap.witness(q_abort, state, sim_traj, ctx.now):
                chunk.cert.n_wit = 1
                chunk.cert.Q_abort = q_abort
            else:
                chunk.cert.n_wit = 0   # 单见证/无见证 ⇒ 仅 v11 等价行为
            score = self.policy.score(chunk, pred)
            if best is None or score > best.score:
                best = chunk
        return best or self._single_step_fallback(state)

    def midchunk_guard(self, chunk, k_exec, live_obs, stf, gscf, nrb, jsse):
        """50Hz：五检语义不变；证书有效性含位姿/仿真/双见证。"""
        verdict = super().midchunk_guard(chunk, k_exec, live_obs, stf, gscf, nrb, jsse)
        if verdict[0] != 'continue':
            return verdict
        if self.epca is not None and not self.epca.pose_ok():
            return ('abort', self._pose_witnessed_abort(chunk, k_exec))
        if chunk.cert.witness_contradiction:
            return ('shrink', 2)       # K_eff←2 + 位姿保持
        return verdict


# 1kHz JSSE 循环内新增：位姿见证停止不变式（定义 576）
def jsse_tick(q_cmd_raw, q_current, epca, jsse, chunk, s2rc, now):
    if epca is not None and epca.pose_ok():
        rho = epca.certified_radius(s2rc.delta('pose', jsse.state()) if s2rc else 0.0)
        if epca.e_pose > epca.rho_base:
            q_abort = epca.map_abort_pose(chunk.p_star, chunk.Q_abort,
                                          q_current, delta_pose=rho - epca.rho_base)
            return ('pose_hold', q_abort if q_abort is not None else q_current)
    return ('project', jsse.project(q_cmd_raw))

## 4. 推导

**引理 97（位姿共识三角界与双空间安全）**
设 (A1) d_SE3 满足三角不等式且在局部无奇异邻域内；(A2) 外部位姿观测误差有界：d_SE3(T_t^obs,T_t^true)≤ε_obs；(A3) EPCA 有效且 e_t^pose≤ρ_base。则
```
d_SE3(T_t^cmd, T_t^true) ≤ d_SE3(T_t^cmd,T_t^fk) + d_SE3(T_t^fk,T_t^obs)
                          + d_SE3(T_t^obs,T_t^true)
                        ≤ e_t^track + e_t^prop + ε_obs
                        = e_t^pose + ε_obs
                        ≤ ρ_base + ε_obs = ρ_p.
```
若任务空间安全泛函 φ（如工具尖端到障碍物的有符号距离）对位姿满足 L_p-Lipschitz：|φ(T₁)−φ(T₂)|≤L_p·d_SE3(T₁,T₂)，则
```
φ(T_t^true) ≥ φ(T_t^cmd) − L_p·ρ_p.
```
因此当 φ(T_t^cmd)>d_safe+L_p·ρ_p 时，真实位姿仍保有 d_safe 间隙。联合 q∈C_q_safe，实际构型同时位于已认证关节安全集与位姿证书管内，得到双空间安全证书。∎

**引理 98（EPCA 的支配性与 v11 等价）**
EPCA 只新增两类约束：(i) 位姿残差检查 e_t^pose≤ρ_base；(ii) 中止映射的位姿见证 Q_abort^pose⊆Q_abort。二者都是对可行动作集的合取过滤。当 EPCA 关闭时，令 ρ_base←ε_fk、删除 (i)、令 Q_abort^pose←Q_abort，则控制器逐项退化为 v11。因此对任意状态，v12-EPCA 的物理行为集 ⊆ v11 行为集；EPCA 关闭时取等。位姿误报只会触发收缩/保持，绝不会扩大动作集。∎

**引理 99（分层共形现实差距的有限样本有效性）**
在层内可交换假设下，对每层 b 与泛函 f，校准分数与测试分数同分布，标准 split-conformal 分位给出
```
P( Δ_f(s_test) ≤ Δ_f^{1−α}(b) | b(s_test)=b ) ≥ 1−α
```
（边际覆盖；分层 Mondrian 共形）。若 n_b<n_min 或层内可交换性检验拒绝，定义 Δ=∞，不签发任何仿真证据，故不会产生虚假覆盖。对 |F| 个泛函使用 α/|F| 或同时共形带，可得联合覆盖 ≥1−α。时间相关数据用块共形，块长取混合时间；在线更新用 ACI/在线共形。由此，β_S2RC 的额外余量以概率 ≥1−α 覆盖真实 sim-real 差距，且当支撑失效时自动退回 v11。∎

**引理 100（DTAP 双见证的保守性）**
设 n_t^pose=n_t^s2r=n_t^wit=1，DTAP 预认证 τ_j^sim 且其 sim_margin≥d_safe+β_GSCF+Δ_clearance。由共形界（引理 99），以概率 ≥1−α 有真实间隙
```
clearance_true ≥ sim_margin − Δ_clearance ≥ d_safe + β_GSCF.
```
位姿见证给出 d_SE3(T_t^obs,T_t^sim(q_abort))≤τ_wit；结合 d_SE3(T_t^obs,T_t^true)≤ε_obs 与 d_SE3(T_t^sim(q_abort),p*)≤ρ_p^S2RC，得
```
d_SE3(T_t^true, p*) ≤ 2ρ_p^S2RC + ε_obs + δ_wit.
```
若 n_t^wit=0 而两见证皆有效，则见证矛盾，定义 574 强制 K_eff←2 并位姿保持；若仅一个见证有效，则退回 v11 等价模式；若两见证皆无效，则收缩到 Π_r。因此 DTAP 签发的任何中止都带可计算的真实余量与位姿界，绝不比 v11 更乐观。∎

**引理 101（v12 联合保守性与预算）**
在 (A1)–(A3)、引理 97–100 与 v11 假设下，任一 v12 认证的块要么走 v11 等价模式（EPCA/S2RC/DTAP 任一关闭），要么走锚定模式（三项均有效），且两条路径的物理行为集都 ⊆ v11 可行集；见证矛盾时严格收缩到 Π_r。失效概率由并集界给出：
```
P_fail ≤ P_fail^v11 + ε_obs + ε_sup + |F|α + ε_wit,
```
其中 ε_sup 为支撑监控漏检率，ε_wit 为见证误接受率（E618/E621 标定）。预算：EPCA 在 1kHz 循环内为 O(1)（≤0.05ms，JSSE 总 p99≤0.8ms）；S2RC 在 5Hz 块边界为 O(|F|+k)（≤0.3ms，摊销≤0.06ms）；支撑监控 ≤0.1ms；DTAP 预认证 2ms@5Hz（摊销≤0.1ms）；决策侧典型 ≤10ms，p99≤22ms；内存 ≤60MB，功耗 ≤25W。∎
