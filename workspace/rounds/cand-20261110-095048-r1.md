# 第 43 轮（新循环第 3 轮）· Event-Time Certificate Kernel：事件相机把证书推进到微秒时间域，虚拟仿真把它放进「可微对抗风洞」（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR）。第 42 轮点出了「仿真偏差 + 检索幻觉」两大风险，却漏掉一个更根本的盲区：**所有证书都活在控制拍（10–100 ms）的离散时间轴上**，守卫只在网格点求值；两个控制拍之间的高速侵入、突现障碍、接触瞬变，是整套体系的时间盲区。本轮灵感词「事件相机」正面命中该盲区：它是只报告亮度变化的「差分视网膜」，微秒级时间戳、约 140 dB 高动态、无运动模糊、低功耗，能在帧相机尚未积分完一帧时就看见危险；「虚拟仿真」则补上事件相机最稀缺的资源——**时间真值**：连续时间渲染 + 事件生成模型（ESIM/v2e）能给出每条事件相对真实穿越时刻的精确时延，且事件生成近似可微，于是可以**反向搜索最坏事件流**，把第 42 轮的「空间域随机化压力测试」升级为「时间域对抗证伪」。

## 0. 直觉与动机

**灵感 1（事件相机 → 从「空间边际」到「时间边际」）**：帧相机的安全链是 曝光 → 读出 → 推理 → 决策，端到端延迟 30–80 ms，且会随光照与算力恶化；事件相机只对变化发事件，延迟可压到微秒量级。直觉上，安全证书真正关心的不是「我离障碍多远」（空间边际 m_lo），而是「我还有多少时间」（时间边际 τ = TTV − 反应预算）。事件相机天然输出**变化的时间戳**，正好用来估 time-to-violation（TTV）：迎面障碍在事件流上表现为「事件密度/发散度的指数增长」（looming），侧滑表现为「切向事件流的突变」。于是证书有了第二个维度：不仅要求 m_lo ≥ θ，还要求估计剩余时间 \hat{TTV} ≥ Δ_react。但事件相机是差分传感器：**低纹理、慢速蠕变、匀光场景下几乎不发事件**，而这恰恰可能是最危险的「静默逼近」——这条「事件饥饿」失效链是本轮的核心敌人。

**灵感 2（虚拟仿真 → 可微事件流生成器与「时间风洞」）**：真实事件相机拿不到像素级时间真值（需要高速相机 + 动捕对齐），但仿真可以：连续时间渲染 radiance L(x,t)，按对数亮度阈值跨触发事件，每条事件的真实穿越时刻已知。更妙的是事件生成模型（阈值跨、折射期、噪声）**近似可微**（用替代梯度），可以对场景纹理、运动轨迹、光照、传感器阈值做梯度上升，**专门把检测时延推到最大**——即「找出让证书最晚报警的那个世界」。这不是普通域随机化，而是**对抗式时间证伪**：仿真不再只是「多采样本」，而是「主动造最坏样本」。仿真的价值从「覆盖分布」升级为「搜索失效边界」。

**灵感 3（耦合 → 给飞轮补上时间轴）**：第 42 轮的 SCV 是按帧压力测试，CKB 检索的是静态证书模板，ECR 的 WCET 假设输入速率固定。三者都缺时间。本轮：SCV → DSF（可微事件证伪，产时间反例）；CKB → T-CKB（事件签名 + 时延 CDF 模板）；ECR → 事件率有界运行时（token bucket 把「数据依赖的事件率」重新变成「确定性 WCET」）。飞轮从「空间域进化」变成「时空双域进化」，且**任一时刻事件流密度骤降（事件饥饿）本身就是触发仿真重跑的漂移信号**。

**耦合升级（一句话）**：事件相机提供微秒级时间边际，虚拟仿真提供可微的时间真值与最坏事件流，T-CKB 把「时间反例 + 时延分布」变成可检索资产，ECR 用 token bucket 保证事件率再高 WCET 也有界。

## 1. 形式化定义（增量：定义 38–44）

**定义 38（事件相机连续时间观测模型与事件可观测度）**：设场景对数亮度 L(x,t)（x∈Ω 像素平面）。事件在 t_k 触发当且仅当 |log L(x_k,t_k) − log L(x_k,t_k−)| ≥ C（对比度阈值），输出 E = {(x_k,t_k,p_k)}_{k=1}^{N}。事件率 λ(t) ≈ ∫_Ω ρ(|∂_t log L(x,t)|; C, τ_ref) dx，其中 τ_ref 为折射期。关键量 **事件可观测度**：对区域 S 与危险逼近族 A，O(S) = inf_{a∈A} ∫_S λ_a(x,t) dx。若 O(S) < λ_min，则称 S 在该逼近下处于**事件饥饿盲区**。传感器参数 θ_e = (C, τ_ref, p_noise, λ_bg, t_lat, σ_jitter)，域随机化 D_dvs = D_scene ⊗ Δ(θ_e)。

**定义 39（事件时间证书 ETC）**：设守卫面 g(x)，穿越时刻 T_cross = inf{t : g(x(t)) ≤ 0}。事件看门狗 W(E; θ) 在事件时间 t_f 报警并输出剩余时间估计 \hat{TTV}(t_f)。称 **ETC(Δ_react, δ) 有效**，若 P_{D_real}( \hat{TTV}(t_f) ≤ T_cross − t_f ) ≥ 1 − δ。因为 \hat{TTV} 是真实剩余时间的**下界**（宁可低估、提前停），故当 \hat{TTV}(t_f) ≤ Δ_react 触发停车时，真实剩余 ≥ Δ_react。**命题 39**：若 \hat{TTV} 的下界性成立，则 ETC 触发后 SafeStop 在 Δ_react 内完成的概率 ≥ 1−δ（忽略执行器故障）。这与第 42 轮的空间证书是**与（AND）**关系：C_new = C_space ∧ C_time。

**定义 40（事件率有界运行时与确定性 WCET）**：事件率 λ(t) 是数据依赖且可突增的，直接跑事件核会破坏 WCET。引入 token bucket：容量 B，补充率 λ_max，每控制拍最多处理 B 个事件。则单拍 WCET ≤ c_fixed + B·c_evt（c_evt 为单事件处理成本），**与真实事件率无关**。**失效安全规则**：若 bucket 溢出（事件过载，通常意味着剧烈运动），不得丢事件硬跑，而必须**直接降级 SafeStop**——过载被视为危险证据而非计算事故。

**定义 41（可微事件仿真与时间证伪）**：事件生成 E = G(L(scene, motion); θ_e) 用替代梯度近似可微。时间证伪问题：E* = argmax_{scene, θ_e ∈ D_dvs} Δt_detect(E) = T_cross − t_f(E)，s.t. 轨迹必然穿越 g，且 θ_e 在物理可行域内。若 sup Δt_detect > Δ_react − slack，则 ETC 被**证伪**；输出最坏事件流 E*、参数 θ_e*、场景标签，作为时间反例写入 T-CKB。**DST（Differentiable Sim-to-Test）**：仿真从「采样」变为「对抗搜索」。

**定义 42（时间 Sim-to-Real 迁移界）**：设检测时延分布 F_sim(τ)、F_real(τ)。**命题 42**：若事件时序分布满足 W_1^{time}(P_real, P_sim) ≤ ε_t，则 F_real^{-1}(1−δ) ≤ F_sim^{-1}(1−δ) + κ·ε_t，其中 W_1^{time} 是按最近时间戳匹配后的事件时序 1-Wasserstein 距离，κ 为时延对时序扰动的 Lipschitz 常数。据此定义**时间迁移系数** α_t ≥ 1，实机反应预算 Δ_react^real = α_t·Δ_react^sim。

**定义 43（事件签名与时间知识库 T-CKB）**：KB 记录扩展为 (φ, ψ, C, Ξ, Π, Σ, Λ, Ω_obs)：Σ = 事件签名（HATS/time-surface 描述子 + 事件计数直方图），Λ = 该案例的检测时延 CDF 模板，Ω_obs = 事件可观测度地图（哪些状态-视角组合会饥饿）。检索 R(φ, ψ, Σ) → Top-k；**时间模板合并**取「时延分位数取 max + slack」「盲区取并集」，保证合并后仍保守。

**定义 44（时空联合成本）**：总成本 COT_time = C_sim^DST/N + C_edge^event·T + C_guard^blind·P_blind·T。事件相机稀疏性使 C_edge^event 与事件数（而非像素数）成正比，功耗常低于帧相机；但 C_guard^blind 惩罚「因事件饥饿必须降速/切帧回退」的时间占比——这是事件方案的真实代价，必须显式计入 Pareto。

## 2. 产出设计（新增 IP-57/58/59 + 升级 IP-51/52/53/54/55/56/49/50/45/47）

### 2.1 IP-57 EVENT-CERT-KERNEL (ECK / 事件时间证书核)
1. **时间表面与 TTV 估计**：逐像素指数衰减时间表面 S(x,t)=exp(−(t−t_last(x))/η)，由 S 估事件光流 u(x,t)；对候选障碍（帧分支给出的语义框）算发散度 ∇·u，looming 模型给 \hat{TTV} = c/∇·u（保守常数 c 由 DSF 标定）。
2. **双通道匹配**：事件流给「何时危险」，帧/VLM 给「什么危险」；事件通道只对已确认的语义目标做 TTV，避免把事件噪声当障碍。
3. **下界化**：\hat{TTV} 取「几何下界 + 经验分位修正」的 min，保证不过高估计（定义 39）。
4. **可观测度自检**：滑动窗统计局部 λ；若 λ < λ_min 且存在候选危险 → 宣布盲区，降速至可被帧分支覆盖的速度上限 v_blind，并上报飞轮。
5. **确定性调度**：token bucket（定义 40）；溢出直接 SafeStop。

### 2.2 IP-58 DVS-SIM-FALSIFIER (DSF / 可微事件证伪器)
1. **连续时间仿真链路**：Isaac Sim 高帧率/光追渲染 radiance → v2e/ESIM 生成事件，随机化 θ_e 与纹理/光照/运动。
2. **对抗搜索**：以 Δt_detect 为目标，对场景纹理对比度、目标运动切向速度、光照变化、阈值 C 做替代梯度上升 + CMA-ES 局部精修；冻结安全约束（轨迹必须真的穿越守卫面）。
3. **时间反例归因**：把最坏事件流切片，标注根因（低纹理、逆光、慢速蠕变、折射期饱和、噪声淹没）。
4. **迁移界标定**：少量实机「动捕 + 高速相机」标定对，估 ε_t、κ、α_t。
5. **回归集**：每个时间反例成为固定回归用例，证书版本升级必须全部通过。

### 2.3 IP-59 TEMPORAL-CERT-KB (T-CKB / 时间知识库)
1. **事件签名嵌入**：HATS/time-surface 描述子 → 向量；与 φ、ψ 做联合对比学习。
2. **时延档案**：每条记录存 F(τ) 的若干分位点 + 观测条件。
3. **检索与保守合并**：按签名近邻检索，时延分位取 max、盲区取并、Δ_react 取 max。
4. **反事实检索**：「若换成这个纹理/光照会怎样」——用邻接案例的 Λ 做条件外推，给出候选风险预警。

## 4. 实验设计（E87–E94 硬门槛，承接 E79–E86）

| 实验 | 指标 | 门槛 |
|---|---|---|

| E90 确定性 WCET | token bucket 下 p99.9 单拍 WCET；过载降级正确率 | ≤ B·c_evt 的 1.2x；100% |
| E91 对抗证伪力 | DSF 找到的时延违例数 vs 纯随机采样 | ≥ 10x；回归全过 |

| E93 时间 RAG | 时延档案检索准确率；合成加速 | Top-1 ≥ 85%；加速 ≥ 10x |
| E94 功耗/成本 | 事件+MCU 功耗 vs 帧相机；COT_time | 降 ≥ 3x |

回退：E87/E89 不达标（饥饿盲区过大）→ 事件通道只做「加速度计式提示」，不签证书，退回第 42 轮纯帧方案；E88 时延超预算 → 提高 λ_max/缩短曝光，或只用事件核做触发 AD 不直接签 ETC；E91 证伪过强导致证书不可用 → 收窄 D_dvs 并显式标注适用域；E92 迁移界失效 → 扩大实机标定集；E94 功耗不达标 → 事件核常开、帧分支休眠的占空比调度。

## 5. 本轮最大风险

**一句话**：事件时间证书的致命弱点是**事件饥饿**——低纹理 / 慢速蠕变 / 逆光场景下事件相机几乎静默，而虚拟仿真渲染的纹理天然「事件丰富」，会系统性低估真实环境的检测时延，使 ETC 在「看起来有微秒级余量」的假象中静默失效；因此 E89（饥饿覆盖）与 E92（时间迁移界）必须作为红线实验，且必须引入实机纹理/光照标定而非只信仿真。

## 2. 关键算法（伪代码）

### IP-57 ECK：事件时间看门狗与确定性调度
```
class TokenBucket:
    def __init__(self, B, lam_max, tick_dt):
        self.B, self.lam_max, self.dt = B, lam_max, tick_dt
        self.tokens = B
    def admit(self, n_events):
        self.tokens = min(self.B, self.tokens + self.lam_max * self.dt)
        if n_events > self.tokens:
            return False          # 过载 -> 触发 fail-safe，不丢事件硬跑
        self.tokens -= n_events
        return True

def event_watchdog(E_batch, theta, semantics, bucket):
    # 定义 40：过载即视为危险证据，直接 SafeStop
    if not bucket.admit(len(E_batch)):
        return SafeStop(reason='event_overload')
    # 时间表面 S(x,t)=exp(-(t-t_last)/eta) 与事件光流
    S = time_surface(E_batch, eta=theta.eta)
    u = event_optical_flow(S)
    # 双通道：只在已确认的语义目标上估 TTV，避免事件噪声误报
    for obj in semantics.confirmed_targets:
        div = divergence(u, obj.roi)          # looming 发散度
        if div <= theta.div_min:
            continue
        ttv_hat = conservative_ttv(div, obj, c=theta.loom_c)
        # 定义 39：ttv_hat 取几何下界与经验分位修正的 min
        ttv_hat = min(ttv_hat, empirical_quantile_lower(obj, theta))
        if ttv_hat <= theta.Delta_react:
            return Trip(t=now(), ttv=ttv_hat, obj=obj.id)
    # 事件饥饿自检：事件稀疏但存在候选危险 -> 宣布盲区并降速
    if local_rate(E_batch, semantics) < theta.lambda_min \
       and semantics.has_candidate:
        return BlindZone(speed_cap=theta.v_blind, omega_obs=make_obs_map(S))
    return None
```

### IP-58 DSF：可微事件仿真与时间证伪
```
def differentiable_event_sim(scene, motion, theta_e):
    # 连续时间渲染 radiance，再按 log 亮度阈值跨生成事件（v2e/ESIM）
    L = render_continuous(scene, motion, fps=1e4)
    E = threshold_cross(L, C=theta_e.C, tau_ref=theta_e.tau_ref,
                        noise=theta_e.p_noise, latency=theta_e.t_lat)
    return E

def adversarial_event_search(scene0, motion0, theta_e0, budget=2000):
    best = {'dt': 0.0, 'params': None}
    scene, motion, theta_e = scene0, motion0, theta_e0
    for _ in range(budget):
        E = differentiable_event_sim(scene, motion, theta_e)
        t_cross = true_crossing_time(motion)      # 仿真时间真值
        t_f = event_watchdog_offline(E, theta_e) # 用 IP-57 逻辑求报警时刻
        dt = t_cross - t_f
        # 替代梯度回传：最大化检测时延
        g = surrogate_grad(dt, [scene, motion, theta_e])
        scene, motion, theta_e = ascend(scene, motion, theta_e, g)
        scene, motion, theta_e = project_feasible(scene, motion, theta_e)
        if dt > best['dt']:
            best = {'dt': dt, 'params': (scene, motion, theta_e),
                    'event': E, 'cause': attribute_delay(E, scene, motion)}
    # 定义 41：找到超过预算的最坏事件流即证伪
    return best, best['dt'] > theta.Delta_react - SLACK

def attribute_delay(E, scene, motion):
    labels = []
    if scene.texture_contrast < scene.tau_tex: labels.append('low_texture')
    if motion.speed < motion.tau_slow:       labels.append('slow_creep')
    if scene.backlight > scene.tau_back:     labels.append('backlight')
    if E.saturated_ratio > 0.2:              labels.append('refractory_saturation')
    if E.noise_rate > E.signal_rate:         labels.append('noise_swamp')
    return majority_vote(labels)
```

### IP-59 T-CKB：事件签名检索与时间模板合并
```
def retrieve_temporal(phi, psi, Sigma, KB, k=5, delta=1e-3):
    cand = KB.hnsw_temporal(phi, psi, Sigma, k)   # HNSW 近邻
    # 保守合并：时延分位取 max + slack；盲区取并；Delta_react 取 max
    Delta_react = max(c.Lambda.quantile(1 - delta) for c in cand) + SLACK
    blind = union_over(c.Omega_obs for c in cand)
    # 反事实预警：邻接案例的条件外推
    warn = [c for c in cand if c.Lambda.quantile(1e-2) < Delta_react]
    return Delta_react, blind, warn

def merge_temporal_templates(cands):
    return TemporalCert(
        Delta_react=max(c.Delta_react for c in cands),
        latency_bound=pointwise_max([c.Lambda.cdf for c in cands]),
        Omega_obs=union([c.Omega_obs for c in cands]),
        alpha_t=max(c.alpha_t for c in cands))
```

### IP-51/52/56 升级：时空联合守卫与运行时
```
# CAR：事件守卫最高优先级 + 空间守卫（第 42 轮迁移修正阈值）
def car_guard(e, x, cert):
    if cert.event_trip(e, x):                 # 时间守卫，微秒级
        return True
    return cert_lookup_L0(x).m_lo[e] >= cert.alpha_e[e] * cert.theta_sim[e]

# LCS v3：新增 T-2 档，预算含事件通道
def certify_light_v3(x, guards, budget_us, event_batch):
    # T-2: 事件时间核（仅在有事件且已确认语义目标时开跑）
    trip = event_watchdog(event_batch, theta, semantics, bucket)
    if trip is not None:
        return trip, -2
    # T-1 / T0 与 v19 相同（L0 查表 -> L1 INT8）
    b = cert_lookup_L0(x)
    if not undecided_guards(b, guards):
        return b, -1
    if budget_us < 110:
        return downgrade_monotone(b), -1
    status, margin = monitor_step_INT8(quantize_obs(x))
    b.m_lo = margin
    return b, 0

# ECR：事件累加器把数据依赖事件率钳成固定上限
def edge_event_runtime(E_stream, bucket):
    batch = accumulate_until_tick(E_stream)   # 每拍聚合
    if not bucket.admit(len(batch)):
        return SafeStop(reason='overload')    # 定义 40 的 fail-safe
    S = int8_time_surface(batch)              # INT8 时间表面
    hist = int8_event_histogram(batch)        # 供 L1 监控器
    return S, hist
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性保证 |
|---|---|---|---|
| IP-57 ECK 看门狗 | O(N_batch)，N_batch ≤ B | 时间表面 O(\|Ω\|) | \hat{TTV} 下界性 + token bucket ⟹ ETC sound（无执行器故障） |
| IP-57 饥饿自检 | O(\|Ω\|) 滑窗统计 | O(\|Ω\|) | λ<λ_min 且存在候选 ⟹ 降速至帧覆盖上限，不越权签证书 |
| IP-58 DSF 对抗搜索 | 离线 O(budget·N_evt·T_sim) | 事件日志 O(N_evt) | 替代梯度无全局保证，但**证伪单边 sound**：找到的违例必为真 |
| IP-59 T-CKB 检索 | HNSW O(log N) + 重排 O(k·d) | 索引 O(N·d) | 保守合并（分位 max、盲区并、Δ_react max）⟹ sound |
| IP-56 token bucket | O(1)/拍 | O(1) | 单拍 WCET ≤ c_fixed + B·c_evt，与 λ(t) 无关；溢出即 SafeStop |
| IP-51 时空守卫 | O(\|E\|) 查表+比较 | 同 L0 | 事件守卫与空间守卫取并 ⟹ 只多报不漏报 |
| IP-52 LCS v3 | 有事件时 +O(N_batch)，否则同 v19 | 同 L0+L1+事件缓冲 | T-2 决策与 ECK 一致；过载单调降级 |
| 时间迁移界 | O(N_calib) 标定轨迹 | O(1) | F_real^{-1}(1−δ) ≤ F_sim^{-1}(1−δ)+κ·ε_t ⟹ α_t 保守 |

## 4. 实验设计（E87–E94，硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E87 ETC 下界性 | \hat{TTV} ≤ TTV 的实际比例；漏报率 | ≥99.9%；漏报 < 1e-3 |
| E88 检测时延 | p99.9 时延 vs 动捕真值；反应预算余量 | p99.9 ≤ 5ms；余量 > 2x |
| E89 事件饥饿覆盖 | 危险场景中 λ≥λ_min 的比例；盲区召回 | ≥95%；盲区识别召回 ≥98% |
| E90 确定性 WCET | token bucket 下 p99.9 单拍 WCET；过载降级正确率 | ≤ B·c_evt 的 1.2x；100% |
| E91 对抗证伪力 | DSF 找到的时延违例数 vs 纯随机采样 | ≥ 10x；回归全过 |
| E92 时间迁移界 | 实机时延 CDF 分位 vs 迁移上界 | 实测 ≤ 上界；W_1^time 误差 < 2x |
| E93 时间 RAG | 时延档案检索准确率；合成加速 | Top-1 ≥ 85%；加速 ≥ 10x |
| E94 功耗/成本 | 事件+MCU 功耗 vs 帧相机；COT_time | 降 ≥ 3x |

回退：E87/E89 不达标（饥饿盲区过大）→ 事件通道只做「加速度计式提示」，不签证书，退回第 42 轮纯帧方案；E88 时延超预算 → 提高 λ_max/缩短曝光，或只用事件核做触发 AD 不直接签 ETC；E91 证伪过强导致证书不可用 → 收窄 D_dvs 并显式标注适用域；E92 迁移界失效 → 扩大实机标定集；E94 功耗不达标 → 事件核常开、帧分支休眠的占空比调度。

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 事件饥饿：低纹理/慢速/逆光下几乎无事件，时间证书记录「安全」实则盲 | 高 | E89 红线；可观测度自检 + 盲区降速 v_blind；饥饿即触发飞轮重跑 |
| 仿真纹理过富：渲染场景事件率远高于真实，α_t 系统性低估 | 高 | E92 红线；引入实机纹理/光照标定对；纹理域随机化按实测统计校准 |
| 时间同步：事件时间戳与 IMU/帧/执行器时钟偏移，Δ_react 被侵蚀 | 高 | IP-45 时钟同步话题；偏移误差显式写入证书并扣减预算；硬件触发对齐 |
| 对抗过拟合：DSF 找到的最坏样本只对特定渲染器成立 | 中 | 多渲染器交叉验证；证伪用例入固定回归集；保留随机采样基线对照 |
| token bucket 溢出频繁：剧烈运动时反复 SafeStop，可用性下降 | 中 | λ_max 自适应（按任务阶段）；溢出原因分桶统计；与 LCS 降级联合调度 |
| 事件光流在遮挡/高速下失效，TTV 估计发散 | 中 | 与帧分支几何 TTC 融合取 min；光流置信度低时退回盲区降速 |
| 时间 RAG 检索到不相似时延档案 | 中 | 保守合并（分位 max + slack）；适用域显式标注；反事实预警人工确认 |

## 6. 本轮最大风险

**一句话**：事件时间证书的致命弱点是**事件饥饿**——低纹理 / 慢速蠕变 / 逆光场景下事件相机几乎静默，而虚拟仿真渲染的纹理天然「事件丰富」，会系统性低估真实环境的检测时延，使 ETC 在「看起来有微秒级余量」的假象中静默失效；因此 E89（饥饿覆盖）与 E92（时间迁移界）必须作为红线实验，且必须引入实机纹理/光照标定而非只信仿真。
