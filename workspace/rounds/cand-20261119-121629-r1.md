# 第 14 轮（新灵感循环第 1 轮；本轮灵感：「谐波减速器」×「运动学」）

> **基线**：第 13 轮 MetricVoiceGauge-NCD-HUTDH v15（技能扩散版；当前产物区 IP-378–401；定义 607–626；引理 125–130；实验 E661–E670）。
> **本轮纪律**：不推倒 v15。v6–v15 的九个不变式、v13 的 AIO/CPD/DDL/RTCR、v15 的 SCD/DSD/DCA/EDC 全部保留。四个新组件——TEC（传动包络证书）、KCC（运动学条件证书）、NTR（零空间传动正则）、HWS（谐波磨损监督）——一律以**中立元**接入，失效即严格退回 v15 的 nominal-FK 路径，再沿 v15→v14→…→v6 退化链回收。本轮只做三件事：把“关节编码器角度”改写为“含回差、滞回、柔度的输出角集合”；把“正运动学”改写为“带奇异条件数的可证传播”；把二者合成一条“传动—运动学预算”。

## 0. 直觉与动机

**灵感 1（谐波减速器 → 输出角不是点，而是带记忆的区间）**
直觉：v15 默认 `θ_o = θ_m/N + ε_cal`，把谐波减速器当成一个带固定偏置的减速比。但谐波减速器的误差不是这样工作的：柔轮、波发生器与刚轮之间的齿隙形成**回差（lost motion）**，柔轮与轴承的**扭转柔度**让输出角随负载力矩偏转，齿面接触与油膜又形成**滞回**。同一编码器读数、同一力矩，在“正转”和“反转”的历史下可以对应两个不同的输出角；误差在换向时不是连续漂移，而是跨过一条宽度为 `L` 的滞回环。于是“用平均偏置校准掉误差”在平均意义下可能很漂亮，却在每一次换向的瞬间最危险。核心创新：**传动包络证书（Transmission Envelope Certificate, TEC）**。它不再估计一个最优点，而是维护一个带记忆的**输出角集合** `E_i(t)`，并用回差上界、刚度下界、温度/校准余量给出其宽度上界。关键反直觉点：**安全关键路径上不要“校准得更准”，而要“把不确定性包成集合”；换向越少，集合越窄，运动规划本身因此成为收紧证书的手段。**

形式化预告：令 `e_i = θ_{o,i} − θ_{m,i}/N_i`。TEC 给出 `E_i(t)=[e_i^-(t), e_i^+(t)]`，其宽度满足
`w_i(t) ≤ L_i + |τ_i(t)|/K_i^min + ε_i^cal + ε_i^temp`；
在假设 A1–A4（回差有界、刚度有下界、无跳齿、校准残差有界）下，真实 `e_i(t)` 对所有 `t` 落在 `E_i(t)` 内。

**灵感 2（运动学 → 奇异位形是安全预算的放大器）**
直觉：v15 用名义正运动学 `f(θ)` 检查笛卡尔安全余量，但运动学不是坐标变换，而是**安全预算的放大器**。在奇异位形附近，Jacobian 的最小奇异值 `σ_min` 趋近于零：为了完成一个很小的笛卡尔位移 `d`，最小范数逆解 `J^+d` 需要很大的关节位移；同样的传动回差、同样的力矩柔度，经过 `κ = σ_max/σ_min` 放大后，可能把末端推过接触/障碍边界。反过来，如果只做前向区间传播，关节误差到笛卡尔误差只被 `σ_max` 放大，似乎并不可怕；真正可怕的是“为了维持任务位移而不得不走更大的关节行程”，这个逆映射放大才是 `κ` 的来源。核心创新：**运动学条件证书（Kinematic Conditioning Certificate, KCC）**。它把关节盒 `Θ` 经区间正运动学映射为笛卡尔集合 `X`，给出半径 `r_K`，并同时检查 `σ_min(J(θ)) ≥ σ_*` 与条件数 `κ`；任何任务步长 `d` 都必须满足“安全余量 ≥ 传动—运动学预算”。关键反直觉点：**近奇异时最安全的动作常常不是“更精确地算同一个动作”，而是缩小步长、改变冗余解、或拒绝。**

**灵感 3（谐波 × 运动学 → 传动—运动学预算与零空间正则）**
直觉：冗余机械臂的零空间里有许多关节解能实现同一个末端位姿，但它们经过的谐波传动滞回路径不同、`σ_min` 不同、关节限位余量不同。既然传动误差与运动学放大是同一个预算的两项，就不该分别“补偿传动”和“回避奇异”，而应在零空间里直接选一个让预算最小的解：尽量提高 `σ_min`、减少换向次数、降低力矩峰值，同时不改变末端任务。核心创新：**零空间传动正则（Null-space Transmission Regularizer, NTR）** 与 **传动—运动学预算（Transmission-Kinematic Budget, TKB）**。预算写成
`B_TK(d) = σ_max^Θ (L_cert + τ_max/K_min + ε_cal + ε_temp) + c_h κ_eff ||d|| + ε_model`，
绝对回差项由 `σ_max` 放大，换向/相对项由 `κ` 放大。磨损、温升或跳齿会让 `L_cert` 变大；**谐波磨损监督（HWS）** 一旦检出越界，就膨胀包络、降速或塌缩，而不是继续使用旧证书“赌一把”。

**三者如何统一**
统一为 **v15 语义/时限层之上的“物理可信层”**：v15 回答“哪些动作在语义上被允许、在本帧时限内能执行多少”（`Exec_v15`）；v16 回答“这些动作的传动—运动学实现是否可证”（`Acc_v16`）。硬包含关系为
```
Acc_v16(x) ⊆ Acc_v15(x)，  Exec_v16 ⊆ Exec_v15
```
TEC 把关节输出从点变成带记忆的区间；KCC 把区间经运动学传播成笛卡尔半径并检查奇异条件；NTR 在零空间内重新分配预算；HWS 监督 TEC 的模型假设是否仍然成立。共享状态 `ζ_tk = (E, L_cert, K_min, Θ, X, r_K, σ_min, κ, B_TK, mode)`。**TEC 回答“关节到底可能在哪”，KCC 回答“这个不确定性到末端会被放大多少”，NTR 回答“换一个冗余解能否把预算压小”，HWS 回答“这些界现在还可信吗”。**

## 1. 研究问题（轮次升级版）

- **Q1（传动包络的可证语义与紧致性）**：如何定义带记忆的谐波传动包络，使“任意换向历史下的输出角”都被包含？A1–A4 应如何写成可在线检验的假设？多关节同时换向、力矩耦合、温度与磨损如何进入宽度界？包络过松会导致活动性塌缩，过紧会失去可靠性，如何量化这一权衡？
- **Q2（运动学区间传播与奇异证书）**：如何在一个关节盒上高效计算 `σ_min(J(θ))` 的下界与 `r_K` 的上界？区间算术、Lipschitz 界、Weyl 不等式与 Taylor 界如何组合才既不漏又不至于过度保守？近奇异时“前向半径”与“逆映射行程”应如何同时进入任务余量？任务空间的方向性（某些方向放大、某些方向收缩）如何利用？
- **Q3（零空间正则的可证性与实时性）**：如何在零空间内选择 `q*` 使 `σ_min` 提高、换向激励下降，同时保证 `f(q*)=x_d`、关节限位与包络约束？优化是非凸的，局部极小与解切换本身会引入新的换向；如何给出“切换不增加预算”的证书？NTR 的 `O(n^3)` 在线开销能否守住 50Hz？
- **Q4（与 v15 的兼容、活性与退化）**：TEC/KCC 是否可能被 v15 的 SCD/DSD 旁路？v15 的共形余量 `U_d`、数据集覆盖 `ρ_cov`、技能扩散温度 `τ` 与 v16 的 `B_TK` 会不会误差叠加或相互抵消？HWS 能否区分“负载变化导致的柔度偏转”与“真实磨损/跳齿”？塌缩到 reduced/collapsed 是否会长时清空可行集、导致频繁 `a_ask`？

## 2. 设计原则（在 P25–P27 基础上新增 P28–P30）

**P28 传动集合律（Transmission as Set, Not Point）**
安全关键路径上禁止用单一传动偏置/平均回差放行动作。每个关节命令必须携带带记忆的输出角区间 `E_i(t)`；区间的宽度必须由回差上界、刚度下界、校准/温度余量显式构成。任何跨越滞回方向的平均、插值或“学习补偿”都只能用于排序/预筛，不能用于放行。若 `E_i(t)` 无法认证，则该关节不得进入 `Acc_v16`。

**P29 奇异预算律（Singularity as Budget Amplifier）**
任何笛卡尔证书都必须同时携带 `(r_K, σ_min, κ, B_TK)`。禁止只用名义正运动学或名义 Jacobian。近奇异时只允许三种选择：缩小任务步长 `d`、在零空间内换一个 `σ_min` 更大的解、或拒绝/回退；不得用“更精确的 IK”声称消除了 `κ` 放大。`σ_min` 的下界必须在整个关节盒 `Θ` 上成立，而不是只在名义点成立。

**P30 磨损/模型有效性塌缩律（Model-Validity Collapse）**
TEC 的有效性依赖 A1–A4；HWS 必须在线监测回差、刚度下界与跳齿迹象。一旦 `L_t` 超过 `L_cert`、`K_t` 低于 `K_min`、或出现相位跳变，必须膨胀 `L_cert` 并重算预算；若超过 `L_max` 或无法重校准，则进入 reduced/collapsed 模式，只允许降速、缩小步长、回退或 `a_ask`。禁止在模型假设已被证伪后继续使用旧 TEC。

## 3. 与基线的接口（如何退化）

- TEC 失效 ⇒ 本层不再提供传动认证，严格退回 v15 的 nominal-FK 证书路径；若 HWS 同时不可用，则只允许低速/非接触任务，并禁止把该路径用于安全关键接触；
- KCC 失效 ⇒ 只保留名义 Jacobian/名义运动学，不再检查 `σ_min` 与 `κ`，**等价 v15 的运动学检查路径**；
- NTR 失效 ⇒ 使用 v15 的名义冗余解（如最小范数解），TEC/KCC 仍生效；
- HWS 失效 ⇒ 使用离线最坏情形 `L_max, K_min` 的静态包络，预算更保守但不再在线膨胀/塌缩，**等价“静态 TEC + v15”**；
- 四者全失效 ⇒ MetricVoiceGauge-NCD-HUTDH v15（技能扩散版），再沿 v15→v14→v13→v12→…→v6 退化链回收；
- **安全继承**：TEC 只给出输出角集合，KCC 只检查并拒绝，NTR 只在零空间内换解，HWS 只做膨胀/塌缩。四端口均不能新增授权或放宽 v15 阈值；`Exec_v16 ⊆ Exec_v15` 由引理 137 保证。运行时仍与 v15 的时限/守卫结果取交。

## 4. 预期贡献

1. **谐波传动包络证书**：把谐波减速器从“减速比 + 标定偏置”改写为“带回差/滞回/柔度记忆的输出角集合”，第一次把换向历史纳入安全授权，使“平均校准正确、换向瞬间错误”的结构性风险可证；
2. **运动学条件证书**：把正运动学从坐标变换改写为“区间传播 + `σ_min/κ` 条件 + 任务余量”的预算，显式给出近奇异位形下关节误差到末端误差的放大链；
3. **传动—运动学预算与零空间正则**：把“传动补偿”和“奇异回避”合并为同一个 `B_TK`，用冗余零空间选择来缩小预算，而不是分别打补丁；
4. **磨损监督与可拔插退化**：给出 `Acc_v16 ⊆ Acc_v15` 的包含关系与 reduced/collapsed 语义，使物理模型失效时系统能降速/回退而不是继续“按证书赌”；E671–E690 覆盖包络覆盖、奇异放大、零空间收益、磨损塌缩、端到端与消融。

## 5. 本轮最大风险

**一句话**：TEC 的可靠性依赖“回差有界、刚度有下界、不发生跳齿”这一模型类假设；一旦磨损、温升、冲击或润滑变化使实际回差超出认证界，而近奇异位形又把这一微小超界放大 `κ` 倍，系统就会在“每一步都通过包络、每个区间都包含名义轨迹”的表象下执行一个物理上已越界的动作——即**证书自洽、模型失配、却被奇异放大成真实危险的安全决定**。

## 1. 关键算法骨架

```python
# IP-402 Transmission Envelope Certificate：带记忆的谐波传动包络
class TransmissionEnvelopeCertificate:
    def __init__(self, reduction, L_cert, K_min, eps_cal, eps_temp,
                 c_h, alpha=0.05):
        self.N = reduction                 # [N_1, ..., N_n]
        self.L = L_cert                    # 回差上界 [L_1, ..., L_n]
        self.K = K_min                     # 刚度下界 [K_1, ..., K_n]
        self.eps_cal = eps_cal             # 校准残差上界
        self.eps_temp = eps_temp           # 温度/油膜余量
        self.c_h = c_h                     # 换向/速度激励系数
        self.alpha = alpha
        self.E = [(-L_i, L_i) for L_i in self.L]
        self.prev_dir = [0] * len(self.N)

    def update(self, theta_m, tau, delta_theta):
        """按本帧编码器角、力矩和关节位移更新输出误差包络。
        返回: E（每关节区间）, reversal（换向指示）
        """
        E_new, reversal = [], []
        for i in range(len(self.N)):
            W = (self.L[i] + abs(tau[i]) / self.K[i]
                 + self.eps_cal[i] + self.eps_temp[i])
            direction = 1 if delta_theta[i] > 1e-9 else (
                -1 if delta_theta[i] < -1e-9 else 0)
            rev = (direction != 0 and self.prev_dir[i] != 0
                   and direction != self.prev_dir[i])
            reversal.append(rev)

            if rev:
                # 换向：必须张开到完整滞回宽度，禁止沿用单侧分支
                lo, hi = -W, W
            else:
                # 同向：包络可以按已走行程收紧，但不得窄于物理界
                step = self.c_h[i] * abs(delta_theta[i])
                lo = max(-W, self.E[i][0] - step)
                hi = min(W, self.E[i][1] + step)
            E_new.append((lo, hi))
            if direction != 0:
                self.prev_dir[i] = direction
        self.E = E_new
        return self.E, reversal

    def certified(self, L_max):
        # 任何关节的包络宽度超过最坏规格，TEC 失效
        return all((hi - lo) <= L_max[i] + 1e-12
                   for (lo, hi), L_max_i in zip(self.E, L_max))

    def joint_box(self, theta_m):
        return [(theta_m[i] / self.N[i] + self.E[i][0],
                 theta_m[i] / self.N[i] + self.E[i][1])
                for i in range(len(self.N))]


# IP-403 Kinematic Conditioning Certificate：区间运动学 + 奇异条件
class KinematicConditioningCertificate:
    def __init__(self, fk, jacobian, L_J, sigma_star, rho_star, eps_model):
        self.fk = fk
        self.J = jacobian
        self.L_J = L_J              # Jacobian 对关节角的 Lipschitz 常数
        self.sigma_star = sigma_star
        self.rho_star = rho_star
        self.eps_model = eps_model

    def certify(self, theta_box, x_nominal):
        theta_c = [(lo + hi) / 2 for lo, hi in theta_box]
        half = [(hi - lo) / 2 for lo, hi in theta_box]
        Jc = self.J(theta_c)
        U, S, Vt = np.linalg.svd(Jc)
        dtheta = np.linalg.norm(half)
        # Weyl + Jacobian Lipschitz：在盒上给出奇异值界
        sigma_min_lb = max(0.0, S[-1] - self.L_J * dtheta)
        sigma_max_ub = S[0] + self.L_J * dtheta
        kappa_ub = (sigma_max_ub / sigma_min_lb
                    if sigma_min_lb > 1e-9 else float('inf'))
        # 区间正运动学给出笛卡尔包围半径
        X, r_K = interval_fk(self.fk, theta_box)
        valid = (sigma_min_lb >= self.sigma_star) and (r_K <= self.rho_star)
        return {
            'theta_c': theta_c, 'X': X, 'r_K': r_K,
            'sigma_min_lb': sigma_min_lb, 'sigma_max_ub': sigma_max_ub,
            'kappa_ub': kappa_ub, 'valid': valid
        }

    def budget(self, kin, L_cert, tau_max, K_min, eps_cal, eps_temp,
               c_h, d, U_d):
        W = (L_cert + tau_max / K_min + eps_cal + eps_temp)
        return (kin['sigma_max_ub'] * W
                + c_h * kin['kappa_ub'] * float(np.linalg.norm(d))
                + self.eps_model + U_d)


# IP-404 Null-Space Transmission Regularizer：零空间重分配预算
class NullSpaceTransmissionRegularizer:
    def __init__(self, fk, jacobian, sigma_star, q_lo, q_hi,
                 weights, lam=0.5, mu=1e-3, iters=8):
        self.fk, self.J = fk, jacobian
        self.sigma_star = sigma_star
        self.q_lo, self.q_hi = q_lo, q_hi
        self.w, self.lam, self.mu, self.iters = weights, lam, mu, iters

    def hysteresis_cost(self, q, q_prev, tau):
        cost = 0.0
        for i in range(len(q)):
            if (q[i] - q_prev[i]) * (q_prev[i] - self.q_prev2[i]) < 0:
                cost += self.w[i] * (self.w.L[i] + abs(tau[i]) / self.w.K[i])
        return cost

    def solve(self, x_des, q_ref, q_prev, tau):
        q = np.array(q_ref, dtype=float)
        for _ in range(self.iters):
            Jq = self.J(q)
            U, S, Vt = np.linalg.svd(Jq)
            rank = int(np.sum(S > 1e-6))
            N = Vt[rank:].T                     # 零空间基
            # 数值梯度：提高 sigma_min、降低换向滞回、远离限位
            g = (np.zeros_like(q)
                 - self.lam * self._grad_sigma_min(q)
                 + self._grad_hysteresis(q, q_prev, tau)
                 + self.mu * self._grad_limit_barrier(q))
            dq = -N @ (N.T @ g)
            # 线搜索：末端误差、关节限位、sigma_min 都不能被破坏
            alpha = 1.0
            for _ in range(6):
                q_new = np.clip(q + alpha * dq, self.q_lo, self.q_hi)
                if (np.linalg.norm(self.fk(q_new) - x_des) <= 1e-4
                        and np.linalg.svd(self.J(q_new))[1][-1]
                        >= self.sigma_star):
                    q = q_new
                    break
                alpha *= 0.5
        return q


# IP-405 Harmonic Wear Supervisor：回差/刚度漂移与跳齿监督
class HarmonicWearSupervisor:
    def __init__(self, L_cert, K_min, h_L=5.0, h_K=5.0,
                 k_L=0.5, k_K=0.5, delta_r=0.02, eta=0.1):
        self.L_cert, self.K_min = L_cert, K_min
        self.h_L, self.h_K = h_L, h_K
        self.k_L, self.k_K = k_L, k_K
        self.delta_r = delta_r
        self.eta = eta
        self.C_L, self.C_K = 0.0, 0.0
        self.mode = 'normal'

    def update(self, L_hat, K_hat, phase_jump):
        self.C_L = max(0.0, self.C_L
                       + (L_hat - self.L_cert) / max(self.L_cert, 1e-9)
                       - self.k_L)
        self.C_K = max(0.0, self.C_K
                       + (self.K_min - K_hat) / max(self.K_min, 1e-9)
                       - self.k_K)
        ratcheting = phase_jump > self.delta_r
        if ratcheting or self.C_L > self.h_L or self.C_K > self.h_K:
            self.mode = 'collapsed'
            return self.mode, self.L_cert, True
        if L_hat > self.L_cert or K_hat < self.K_min:
            self.L_cert = max(self.L_cert, (1.0 + self.eta) * L_hat)
            self.K_min = min(self.K_min, K_hat)
            self.mode = 'reduced'
            return self.mode, self.L_cert, False
        self.mode = 'normal'
        return self.mode, self.L_cert, False
```

## 2. 形式定义（定义 627–646）

**定义 627（谐波传动误差与输出包络）**
对第 `i` 个谐波关节，令 `θ_{m,i}` 为电机侧编码器角，`θ_{o,i}` 为输出侧角，`N_i` 为减速比，定义传动误差
```
e_i(t) = θ_{o,i}(t) − θ_{m,i}(t)/N_i .
```
称区间 `E_i(t)=[e_i^-(t), e_i^+(t)]` 为一个**输出包络**，若对所有满足 A1–A4 的传动轨迹，
```
e_i(t) ∈ E_i(t),   w_i(t) = e_i^+(t) − e_i^-(t)
      ≤ L_i(t) + |τ_i(t)|/K_i^min + ε_i^cal + ε_i^temp + c_{h,i}|δθ_i(t)| .
```
其中 `δθ_i(t)` 为本帧关节位移，`c_{h,i}` 为换向/速度激励系数的保守上界。包络带记忆：换向时必须张开到完整滞回宽度，同向时可沿当前分支收紧，但不得窄于物理界。

**定义 628（传动包络证书 TEC）**
二元组 `(E_i, 1−α_i)` 是关节 `i` 的传动包络证书，若在 A1–A4 下，对预测时域 `T` 内的任意 `t`，
```
P( e_i(t) ∈ E_i(t) ) ≥ 1 − α_i ,
```
且该式对模型容许的所有换向历史一致成立。`α_i` 只吸收校准/温度残差的随机性；回差与刚度的最坏情形由确定性上界 `L_cert, K_min` 承担。若 `α_i=0`，称 TEC 为确定性包络。

**定义 629（传动模型假设 A1–A4）**
- **A1（回差有界）**：对所有 `t`，`L_i(t) ≤ L_i^cert`；
- **A2（刚度有下界）**：`K_i(t) ≥ K_i^min > 0`；
- **A3（无跳齿/ratcheting）**：输出始终处于同一齿啮合分支，未发生齿跳；
- **A4（残差有界）**：`|ε_i^cal(t)| ≤ ε_i^cal`，`|ε_i^temp(t)| ≤ ε_i^temp`。
HWS 负责在线证伪 A1–A3；A4 由块共形校准给出。任一假设失效，TEC 立即失效或膨胀，不得继续使用原始窄包络。

**定义 630（关节盒与运动学区间）**
由 TEC 定义输出关节盒
```
Θ(t) = ∏_i [ θ_{m,i}(t)/N_i + e_i^-(t),  θ_{m,i}(t)/N_i + e_i^+(t) ] .
```
其笛卡尔像为 `X(t)=f(Θ(t))`，包围半径
```
r_K(t) = max_{x,x'∈X(t)} ||x − x'|| / 2 .
```
若 `f` 在 `Θ` 上 C¹，`L_f=sup_{θ∈Θ}||J(θ)||_2`，则 `r_K ≤ L_f · ||δθ||_2`，其中 `δθ` 为关节盒半宽向量。区间正运动学给出更紧的 `X`，Lipschitz 界作为后备上界。

**定义 631（运动学条件证书 KCC）**
给定关节盒 `Θ`、名义中心 `θ_c`、Jacobian Lipschitz 常数 `L_J`，定义
```
σ_min^-(Θ) = max(0, σ_min(J(θ_c)) − L_J ||δθ||_2) ,
σ_max^+(Θ) = σ_max(J(θ_c)) + L_J ||δθ||_2 ,
κ^+(Θ) = σ_max^+(Θ) / σ_min^-(Θ)   (若 σ_min^- > 0) .
```
`KCC(Θ)=(σ_*, ρ_*)` 有效，若
```
σ_min^-(Θ) ≥ σ_*  > 0   且   r_K(Θ) ≤ ρ_* .
```
`σ_*` 是任务要求的最小运动学权威；`ρ_*` 是允许的末端位置不确定半径。两者均由任务/接触安全边界预注册。

**定义 632（传动—运动学预算 TKB）**
对任务空间步长 `d`，定义
```
B_TK(d) = σ_max^+(Θ) · ( L_cert + τ_max/K_min + ε_cal + ε_temp )
        + c_h · κ^+(Θ) · ||d||_2
        + ε_model .
```
第一项是**绝对回差/柔度项**，经正向运动学 `σ_max` 放大；第二项是**换向/相对项**，经逆映射 `κ` 放大；`ε_model` 覆盖连杆参数、基座位姿与未建模柔顺。`B_TK` 是本帧执行 `d` 时认证的笛卡尔误差上界。

**定义 633（传动—运动学授权集 TKA）**
以 v15 授权集为硬边界，定义
```
Acc_v16(x) = { a ∈ Acc_v15(x) :
               KCC(Θ(a)) 有效  且
               m_task(a,x) ≥ B_TK(d_a) + U_d } ,
Exec_v16 = Acc_v16 ∩ G_v15 ,
```
其中 `G_v15` 是 v15 的运行时守卫/时限结果，`U_d` 是 v15 的共形余量。`Acc_v16` 只做交集与不等式收紧，不新增任何动作。

**定义 634（零空间传动正则 NTR）**
令
```
Q(x_d) = { q ∈ [q_lo, q_hi] :
          ||f(q) − x_d|| ≤ ε_task ,
          σ_min(J(q)) ≥ σ_* } .
```
定义换向/滞回代价
```
J_h(q) = Σ_i w_i · 1[sign(q_i−q_i^prev) ≠ sign(q_i^prev−q_i^prev2)]
              · (L_i + |τ_i|/K_i) + w_τ Σ_i |τ_i| ,
```
并取
```
q* = argmin_{q∈Q(x_d)} [ J_h(q) − λ σ_min(J(q)) + μ φ(q) ] ,
```
`φ(q)` 为关节限位障碍函数。NTR 只在 `f^{-1}(x_d)` 的零空间内移动，故 `f(q*)=x_d`；它改变的是预算 `B_TK`，不是末端任务集。

**定义 635（谐波磨损监督 HWS）**
HWS 在线估计 `\hat L_t, \hat K_t`，并维护
```
C_L(t) = max(0, C_L(t−1) + (\hat L_t − L_cert)/L_cert − k_L) ,
C_K(t) = max(0, C_K(t−1) + (K_min − \hat K_t)/K_min − k_K) ,
```
以及相位跳变指示 `Δφ_t`（由编码器/输出侧残差的突跳或力矩-角度迟滞环的断裂检测）。若
```
Δφ_t > δ_r  或  C_L(t) > h_L  或  C_K(t) > h_K ,
```
则判定 A1–A3 失效，进入 `collapsed`；若仅 `\hat L_t > L_cert` 或 `\hat K_t < K_min`，则膨胀 `L_cert ← max(L_cert, (1+η)\hat L_t)` 并进入 `reduced`。

**定义 636（传动层模式与退化）**
- `normal`：完整 v16，允许 `Acc_v16` 中的动作；
- `reduced`：`L_cert` 膨胀、`d ≤ d_max`、`v ≤ v_max`，只允许安全余量更大的子集；
- `collapsed`：只允许 `Fallback ∪ a_ask`，禁止任何依赖 v16 传动认证的接触动作。
四类模块逐项失效时，按第 3 节分别退化为 v15 的 nominal-FK、名义 Jacobian、名义冗余解、静态包络；四者全失效严格退回 v15，再沿 v15→…→v6 回收。

**定义 637（授权保留率与假拒绝）**
`ρ_auth = |Acc_v16| / max(1, |Acc_v15|)`；`FRR_TK` 为因 TEC/KCC/NTR/HWS 过保守而拒绝、但 v15 实际可安全执行的动作比例。`ρ_auth` 对 `B_TK` 单调不增，对 `σ_min` 单调不减。

## 3. 推导（引理 131–140）

**引理 131（TEC 的归纳可靠性）**
设 A1–A4 成立，`e_i(0)∈E_i(0)`，且区间更新 `E_i(t)` 是真实传动动力学的一个单调外近似（即任意可行状态的下一步误差仍落在更新后的区间内）。则对所有 `t≤T`，`e_i(t)∈E_i(t)`。
证明：对 `t` 归纳。初始包含由假设给出。若 `t−1` 包含成立，A1 给出回差上界，A2 给出柔度上界，A3 排除跳齿分支，A4 给出残差上界；三角不等式与 `c_h|δθ|` 项给出下一步误差的界，单调外近似保证该界包含于 `E_i(t)`。宽度界由定义 627 直接得到。∎
推论：**TEC 的可靠性不依赖对回差的精确辨识，只依赖“上界 `L_cert` + 刚度下界 `K_min` + 无跳齿”**；辨识误差只影响包络宽度与活性，不影响包含性。

**引理 132（区间正运动学的包含与半径）**
若 `Θ` 为关节盒，`f` 在 `Θ` 上 C¹，`L_f=sup_{θ∈Θ}||J(θ)||_2`，则 `f(Θ)⊆X`（区间算术），且对任意 `θ∈Θ`，
```
||f(θ) − f(θ_c)||_2 ≤ L_f ||θ − θ_c||_2 ,
```
因此 `r_K ≤ L_f · ||δθ||_2`。
证明：中值定理 `f(θ)−f(θ_c)=∫_0^1 J(θ_c+s(θ−θ_c))(θ−θ_c)ds`，取算子范数并放大。区间算术的包含性由 `f` 的表达式对四则运算与 `sin/cos` 的区间单调性得到。∎
推论：**前向传播的放大因子是 `σ_max`，不是 `κ`**；`κ` 的危险来自逆映射所需的关节行程，故 KCC 必须同时保留两者。

**引理 133（奇异位形的逆映射放大下界）**
对任意期望笛卡尔位移 `d`，最小范数关节解 `δθ=J^+d` 满足
```
||d||_2/σ_max(J) ≤ ||δθ||_2 ≤ ||d||_2/σ_min(J) ,
```
且当 `d` 对齐 `J` 的最小奇异向量时，上界取等号。因此 `σ_min→0` 时，单位任务位移所需关节位移无界，任何与关节行程成比例的传动误差都被 `κ=σ_max/σ_min` 放大。
证明：对 `J` 作 SVD `J=UΣV^T`，则 `J^+=VΣ^+U^T`，`||J^+||_2=1/σ_min`，`||J||_2=σ_max`；由算子范数定义得上下界，构造 `d=u_min` 得等号。∎
推论：**近奇异时不能靠“更精确的 IK”消除放大**；可选动作只有缩小 `d`、改变冗余解、或拒绝。

**引理 134（传动—运动学预算）**
设每关节误差满足
```
|e_i| ≤ L_i + |τ_i|/K_i + c_{h,i}|δθ_i| + ε_i^cal + ε_i^temp ,
```
`δθ` 为执行任务步 `d` 的关节位移，`δθ=J^+d+null`。在 A1–A4 与定义 631–632 下，
```
||Δx||_2 ≤ σ_max^+(Θ)(L_cert + τ_max/K_min + ε_cal + ε_temp)
          + c_h κ^+(Θ) ||d||_2 + ε_model
        = B_TK(d) .
```
证明：`Δx=f(θ+δθ+e)−f(θ+δθ) ≈ J e`，故 `||Δx||≤σ_max^+||e||`。由 `||e||≤W+c_h||δθ||`、`W=L_cert+τ_max/K_min+ε_cal+ε_temp` 以及引理 133 的 `||δθ||≤||d||/σ_min^-`，得
`||Δx||≤σ_max^+W + c_hσ_max^+||d||/σ_min^- = σ_max^+W + c_hκ^+||d||`，再加模型误差。∎
推论：**绝对回差项由 `σ_max` 放大，换向/相对项由 `κ` 放大**；两者必须分开预算，不能用“平均回差”合并。

**引理 135（NTR 的中立性与单调收益）**
NTR 只在零空间内移动，故 `f(q*)=f(q_ref)=x_d`，不改变末端任务集。若 `σ_min(J(q*)) ≥ σ_min(J(q_ref))` 且 `J_h(q*) ≤ J_h(q_ref)`，则对同一 `d` 有 `B_TK(q*;d) ≤ B_TK(q_ref;d)`；授权集只可能在 `Acc_v15` 内扩大，绝不会超出 `Acc_v15`。
证明：`Q(x_d)` 的约束保证末端等式；`B_TK` 对 `κ^+` 与 `c_h` 项单调，`σ_min` 增大使 `κ^+` 减小，`J_h` 减小使换向项不增；TKA 仍以 `Acc_v15` 为硬边界。∎
推论：**NTR 是“在已证集合内重新分配预算”，不是新增权限**；这也解释了为什么它失效时可以安全退回名义冗余解。

**引理 136（HWS 漂移塌缩的安全性）**
若 HWS 在 `\hat L_t>L_cert`、`\hat K_t<K_min` 或 `Δφ_t>δ_r` 时切换到 `collapsed`，且 `collapsed` 只执行 `Fallback∪a_ask`、`reduced` 只执行 `d≤d_max` 且 `v≤v_max`，则物理违规概率不高于 v15 的对应回退；活动性损失满足
```
P(无可执行认证动作) ≤ P(drift) + P(model violation) + P(calibration miss) .
```
证明：`collapsed` 动作由物理构造保证安全（停/柔顺/询问），不依赖 A1–A4；`reduced` 通过缩小 `d` 使 `B_TK(d)` 落入任务余量；A1–A4 失效时定义 628 的 TEC 不再被引用。∎
推论：**漂移不是用更大的 `L` 去赌，而是用降速/回退买重校准时间**。

**引理 137（与 v15 的包含关系）**
对任意状态 `x`，`Acc_v16(x) ⊆ Acc_v15(x)`，故 `Exec_v16 ⊆ Exec_v15`。
证明：定义 633 先取 `a∈Acc_v15`，再施加 KCC 有效性与预算不等式；NTR 只选 `q∈f^{-1}(x_d)`；HWS 只收缩模式；TEC 只提供区间，不新增动作。所有新约束均为合取项。∎
推论：**v16 的所有新模块只能收紧，不能新增授权**；任一模块失效时沿 v15 退化链回收。

**引理 138（块共形校准的覆盖）**
在 β-混合、块长 `m`、块数 `n_b` 的校准序列下，TEC 的块共形分位满足
```
P(e_{T+1} ∈ E_{T+1}) ≥ 1 − α − β_m − sqrt( log(1/δ) / (2 n_b) ) .
```
证明：块内近似独立 + 共形分位 + 混合系数；对块分数取 Hoeffding 界并合并。∎
推论：**时间相关与换向样本必须按块校准**；普通 i.i.d. 共形会低估回差尾部，尤其在频繁换向的数据上。

**引理 139（授权—速度—余量的收缩）**
在引理 134 下，若任务安全余量为 `M`，则任何满足 `m_task≥B_TK(d)+U_d` 的认证步长满足
```
||d||_2 ≤ ( M − U_d − σ_max^+(Θ) W ) / ( c_h κ^+(Θ) ) ,
```
其中 `W=L_cert+τ_max/K_min+ε_cal+ε_temp`。因此 `κ^+→∞` 或 `σ_max^+W→M` 时 `d→0`；不存在“零回差假设 + 全速 + 近奇异全授权”的策略。
证明：直接解定义 632 的不等式；下界由引理 133 的 SVD 构造给出。∎
推论：**必须显式交换速度、奇异回避、传动保守性三者**；这给 E674/E675 的预注册指标。

**引理 140（组合退化等价）**
若 TEC/KCC/NTR/HWS 任一失效并按第 3 节注入中立元，则 v16 路径分别退化为 v15 的 nominal-FK、名义 Jacobian、名义冗余解、静态传动界；四者全失效时严格退化为 v15，再沿 v15→…→v6 回收。
证明：逐项检查定义。失效模块不再作为 TKA 的合取项；其余模块保持原约束；v15 的 SCD/DSD/DCA/EDC 与时限路径原样保留。∎
推论：**v16 是可拔插的物理可信层，不是对 v15 的重写**。

## 7. 已知风险与失效模式

1. **传动模型类失配**：真实谐波减速器的滞回未必是理想 play 算子；负载相关刚度、油膜、齿面磨损会使 `L` 与 `K` 随状态变化。缓解：A1–A4 显式化、HWS 在线膨胀、块共形尾部校准、保守 `L_cert`、失效即塌缩。

2. **跳齿/ratcheting**：A3 失效时输出角会发生突跳，任何连续包络都不再可靠。缓解：相位跳变检测、力矩突变监测、机械限位/扭矩限制、跳齿即 `collapsed`。

3. **磨损/温升导致 `L` 超界**：长时运行后回差增大，旧 TEC 变窄。缓解：HWS CUSUM、定期准静态标定、`L_cert` 随磨损单调膨胀、超过 `L_max` 禁止 v16 接触授权。

4. **奇异放大与方向性**：`σ_min` 在小盒上的下界可能过保守或过松；任务方向若恰好对齐最小奇异向量，预算急剧变大。缓解：Weyl + Lipschitz 界、方向性预算、缩步、零空间重解、拒绝。

5. **区间运动学过度保守**：区间算术在长链/大盒上可能爆炸，导致 `ρ_auth` 塌缩。缓解：子区间分解、Taylor 模型、局部盒收缩、NTR 减小盒宽、预注册活性下限。

6. **校准样本缺少换向/高力矩**：普通共形会低估滞回尾部。缓解：块共形、主动换向探针、对抗力矩样本、EVT 尾部分位、HWS 监督。

7. **运动学模型误差**：连杆长度、基座位姿、工具坐标系误差不在 TEC 内。缓解：`ε_model` 显式预算、在线手眼/基座标定、任务余量扣除、跨平台重标。

8. **NTR 非凸与解切换**：零空间优化可能陷入局部解，切换本身引入新的换向。缓解：限制切换频率、切换前后预算检查、多起点/热启动、失败退回名义解。

9. **WCET 与实时性**：SVD、区间 FK、NTR 迭代可能超时。缓解：n≤7 的闭式/预计算、NTR 仅在冗余帧、watchdog、降级跳过 NTR、硬件在环压力测试。

10. **误差叠加/双重计数**：v15 的 `U_d`、`ρ_cov`、`τ` 与 v16 的 `B_TK` 可能同向低估或重复扣除。缓解：统一加法预算（引理 134）、保守合取、禁止用 v16 抵消 v15 余量、联合压力测试 E689。

11. **多关节相关性**：逐关节包络忽略同时换向/力矩耦合，可能低估联合误差。缓解：联合包络/协方差上界、关节组换向检测、最坏情形枚举、保守膨胀。

12. **外部接触与柔顺**：任务接触力、工件柔顺、夹爪变形不在纯运动学模型内。缓解：力/位混合证书、接触模型不确定集、`m_task` 预留接触余量、v15 接触证书合取。

## 8. 本轮最大风险

**一句话**：TEC 的可靠性依赖“回差有界、刚度有下界、不发生跳齿”这一模型类假设；一旦磨损、温升、冲击或润滑变化使实际回差超出认证界，而近奇异位形又把这一微小超界放大 `κ` 倍，系统就会在“每一步都通过包络、每个区间都包含名义轨迹”的表象下执行一个物理上已越界的动作——即**证书自洽、模型失配、却被奇异放大成真实危险的安全决定**。
