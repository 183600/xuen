# 第 47 轮（承接第 46 轮 v23；本轮灵感：位姿估计 × 开源生态） · OSS-Pose-Cert：供应链可审计、许可感知、可复现的开源位姿证书生态（五层架构 v11）

> 承接第 46 轮 v23 Memory-Safety-Voice。v23 把记忆检索、语音指令、安全绑定并入 v10 能量-上下文-深度框架，但仍隐含假设 H5：位姿估计器 φ 及其共形校准来自单一、同源、可审计的代码与权重版本，坐标系、许可证、训练分布一致。真实 UniBot 的位姿栈是拼装出来的开源生态：检测用 YOLO/SAM，位姿用 FoundationPose/Gen6D/ORB-SLAM3/VINS-Fusion，深度用不同厂商 SDK，ROS 2 节点由不同团队维护，许可证从 Apache-2.0 到 GPL-3.0 混杂。任一依赖升级、坐标系约定变化、权重被替换或社区贡献被投毒，都会让已签发的姿态证书在“看起来仍有效”的情况下静默失效。两个灵感词精确命中 H5：**位姿估计**给出可组合的估计器委员会与跨实现分歧；**开源生态**给出 SBOM、许可传播与联邦校准的治理结构。耦合出新问题：**如何让姿态证书不仅覆盖几何不确定性，还覆盖供应链不确定性（成分指纹、版本漂移、许可合规、众包校准投毒），并保证任一成分变更时证书 fail-closed 而非静默失效**。

## 0. 直觉与动机

**灵感 1（位姿估计 → 估计器委员会与“分歧即不确定性”）**
直觉：与其相信单一黑箱，不如让多个开源估计器同时投票。定义委员会 Φ={φ_i}，各自输出 SE(3) 变换 T_i；用几何中位数得到 T̄，用委员会离散度 D_t 与一致性比 ρ_t 作为“分布外/退化”的在线信号。但分歧不是万能：若所有估计器共享同一个错误先验（例如同一训练集偏差），低分歧会伪装成高置信，因此分歧必须与 SBOM 指纹、校准护照一起条件化，而不能单独当作置信度。

**灵感 2（开源生态 → 供应链 SBOM 与指纹绑定证书）**
直觉：开源栈的每次 git pull 都可能换掉证书的地基。为每个组件记录指纹 F_i=H(权重哈希, 代码哈希, 坐标系约定, 校准护照, 许可证)，把证书 P_t 与部署时 SBOM 摘要绑定。若运行时指纹与签发时不一致，证书立即降级为“未校准”并要求重校准或保守盒，而不是继续沿用旧半径。

**灵感 3（开源生态 → 联邦校准、可验证凭证与许可合规）**
直觉：社区能贡献大量长尾场景与校准结果，但也会带来投毒和 GPL 污染。用可验证凭证（VC）标注贡献来源与数据护照，用鲁棒加权分位数做联邦共形校准，使恶意贡献质量占比 ≤ ε 时覆盖保证仍成立；部署前用许可闭包分析判断 SBOM 是否与产品分发模式兼容，不合规则自动切换到许可兼容的备选估计器。

**耦合升级**：在 v10 四层之上新增 **供应链信任层（Supply-Chain Trust Layer, SCTL）**。五层 v11：L0 根信任（姿态租约 ℓ_p、能量租约 ℓ_e、**SBOM 指纹租约 ℓ_s**），L1 几何层（估计器委员会 + 跨实现坐标系归一），L2 上下文层（上下文预测驱动委员会成员选择），L3 安全层（CAR 守卫加入指纹/许可/凭证检查），L4 数据层（DCL 采集护照带许可与 VC，联邦校准回灌）。

## 1. 形式化定义（增量：定义 59–63）

**定义 59（开源位姿组件与指纹）**
组件 φ_i=(w_i, h_i, κ_i, l_i, c_i)，其中 w_i 为权重哈希、h_i 为代码哈希、κ_i 为坐标系约定（如 REP-103 / OpenCV / OpenGL）、l_i 为许可证、c_i 为校准护照。组件指纹
F_i=H(w_i‖h_i‖κ_i‖c_i‖l_i)。
SBOM 摘要 F(Φ)=H(sorted{F_i})。**指纹租约** ℓ_s=(F(Φ), τ_s, ε_recal)。

**定义 60（委员会共识与分歧条件半径）**
委员会输出 {T_i}，T̄=GeoMedian_SE3({T_i})。离散度
D_t = max_i d_SE3(T_i, T̄)，一致性比
ρ_t = (1/|Φ|)Σ_i 1[d_SE3(T_i,T̄) ≤ δ]。
条件半径 r_t = r_base(ω_t,m_t) + L_φ·D_t + L_s·(1-ρ_t)。
**分歧条件 soundness**：P(X_t∈P_t | ω_t,m_t,ℓ_s 有效) ≥ 1-α_p。

**定义 61（供应链绑定证书）**
P_t^s=(T̄_t, r_t, F_t, ℓ_p, ℓ_e, ℓ_s, lic_ok)。
有效性判据 Valid(P_t^s)= [F_t=F(Φ_deploy)] ∧ [age(ℓ_s)≤τ_s] ∧ lic_ok ∧ [exchangeability_test(Φ)≥1-α_s]。
任一不满足 → 证书降级为 conservative box 或 fail-closed。

**定义 62（联邦共形校准与投毒鲁棒性）**
贡献 z_j=(score_j, label_j, vc_j)，权重 w_j=w(vc_j, F_j)。加权经验分位数
q̂_{1-α} = inf{q : Σ_{j: score_j≤q} w_j / Σ_j w_j ≥ 1-α}。
设恶意贡献质量占比 ≤ ε，采用截尾权重 w_j←min(w_j, cap) 与 Byzantine 过滤后，覆盖满足
P(Y∈C) ≥ 1-α-ε/(1-ε)。

**定义 63（许可感知部署谓词）**
许可闭包 LicClosure(Φ)=⋃_{i} transitive_licenses(φ_i)。部署模式 d∈{内部, SaaS, 分发}。LicenseGuard(Φ,d)=true iff 所有许可证与 d 兼容（如 GPL 组件不得进入闭源分发闭包）。不兼容 → 替换为许可兼容备选 φ_i' 或阻断发布。

## 2. 三大新增产出与既有 IP 升级

**IP-69 OSS-SBOM（Pose Supply-Chain SBOM & Fingerprint Ledger）**
- 组件清单：模型/权重/代码/依赖/许可证/坐标系约定
- 指纹账本：每次签发证书绑定 SBOM 摘要与组件哈希
- 漂移检测：运行时指纹比对，版本/权重/约定变化触发 ℓ_s 失效

**IP-70 POSE-COMMITTEE（Cross-Implementation Consensus Estimator）**
- 委员会管理：按上下文与能量预算选择 k 个估计器
- 几何中位数 + 分歧度量 D_t/ρ_t
- 坐标系归一：REP-103 / OpenCV / OpenGL 约定转换与自检
- 分歧条件半径注入 PSE

**IP-71 FED-CALIB（Verifiable Federated Conformal Calibration）**
- 可验证凭证 VC 绑定贡献来源/数据护照/许可证
- 鲁棒加权分位数 + 截尾权重抗投毒
- 校准结果回灌 DCL，版本化存证

**IP-72 LICENSE-GUARD（License-Aware Deployment Gate）**
- 传递闭包许可分析
- 部署模式兼容性判定
- 不兼容时的备选估计器切换与证书重签

**既有 IP 升级**
IP-60 PSE：半径 r_t 加入 D_t、ρ_t、指纹有效期
IP-61 DCL：采集护照增加许可证与 VC 字段
IP-62 CCA：新增版本漂移注入、坐标系错配、联邦投毒、许可污染红队
IP-51 CAR：守卫加入 Valid(P_t^s)（指纹/许可/凭证）
IP-63 ECPS：委员会成员数受能量租约约束
IP-45 总线：新增 sbom-fingerprint / committee-disagreement / calibration-vc / license-status 话题

## 3. 算法骨架

SCTL 每签发周期：
1. 读 Φ_deploy、F(Φ)、ℓ_s、ℓ_e、ℓ_p
2. 按上下文 c_t 与能量预算选委员会子集 Φ_k
3. 收集 {T_i}，坐标归一，计算 T̄、D_t、ρ_t
4. 校验 F_t=F(Φ_deploy)、age(ℓ_s)、lic_ok、exchangeability
5. 计算 r_t 并签发 P_t^s；不满足则降级/fail-closed
6. 将失败样本与指纹事件回灌 DCL/FED-CALIB
CAR 用 P_t^s 与 B(v_t,P_t) 联合守卫。

## 4. 本轮最大风险

**一句话**：开源供应链的指纹绑定会给人“可审计”的错觉，但指纹只能证明成分未变、不能证明成分正确；若社区校准数据被投毒或某估计器在长尾场景系统性错误且与其他成员共享同一偏差，委员会低分歧会签发过窄证书，导致姿态证书在真实分布外场景静默失效。

## 2. 关键算法 伪代码

### IP-69 OSS-SBOM 指纹账本
```
def component_fingerprint(phi):
    payload = b"".join([phi.w_hash, phi.code_hash,
                        canon(phi.coord_convention),
                        phi.calib_passport, canon(phi.license)])
    return sha256(payload)

def sbom_digest(phi_set):
    fps = sorted(component_fingerprint(p) for p in phi_set)
    return sha256("".join(fps).encode())

def check_supply_chain(deployed, cert, tau_s):
    if sbom_digest(deployed) != cert.F_t:
        return False, 'fingerprint_drift'
    if age(cert.lease_s) > tau_s:
        return False, 'lease_expired'
    if not license_guard(deployed, cert.deploy_mode):
        return False, 'license_violation'
    return True, 'ok'
```

### IP-70 POSE-COMMITTEE 共识
```
def geo_median_SE3(transforms, iters=20):
    T = transforms[0]
    for _ in range(iters):
        inv = [np.linalg.inv(T) @ Ti for Ti in transforms]
        dT = mean_se3_log(inv)          # Lie 代数平均更新
        T = T @ exp_se3(dT)
    return T

def committee_consensus(phi_subset, obs, omega_t, r_base,
                        L_phi, L_s, delta):
    Ts = []
    for phi in phi_subset:
        obs_i = normalize_coords(obs, phi.coord_convention)
        T = phi.estimate(obs_i)
        Ts.append(denormalize_coords(T, phi.coord_convention))
    T_bar = geo_median_SE3(Ts)
    devs = [se3_distance(Ti, T_bar) for Ti in Ts]
    D_t = max(devs)
    rho_t = sum(d <= delta for d in devs) / len(devs)
    r_t = r_base(omega_t) + L_phi * D_t + L_s * (1 - rho_t)
    return T_bar, r_t, D_t, rho_t
```

### IP-71 FED-CALIB 联邦校准
```
def weighted_quantile(scores, weights, alpha):
    order = argsort(scores)
    s, w = scores[order], weights[order]
    cw = cumsum(w) / sum(w)
    idx = searchsorted(cw, 1 - alpha)
    return s[min(idx, len(s) - 1)]

def robust_fed_calib(contribs, alpha, eps, cap):
    kept = []
    for z in contribs:
        if not verify_credential(z.vc):
            continue
        if not license_ok(z.vc.license):
            continue
        w = min(trust_weight(z.vc, z.F), cap)   # 截尾权重
        kept.append((z.score, w))
    scores = [s for s, _ in kept]
    weights = [w for _, w in kept]
    # 预留 eps 质量给投毒，取更保守分位
    return weighted_quantile(scores, weights, alpha + eps)
```

### IP-72 LICENSE-GUARD 许可守卫
```
def license_closure(phi_set):
    return union(transitive_licenses(p) for p in phi_set)

def license_guard(phi_set, deploy_mode):
    for lic in license_closure(phi_set):
        if not compatible(lic, deploy_mode):
            return False
    return True

def select_compatible_committee(candidates, deploy_mode, k, utility):
    feasible = [p for p in candidates
                if license_guard([p], deploy_mode)]
    return top_k(feasible, k, key=utility)
```

def issue_supply_chain_cert(c_t, omega_t, B_t, deployed,
                            cert_prev, calib, tau_s):
    if not energy_lease_valid(cert_prev.lease_e, t + Delta, E_min):

        if not ok:

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SBOM 指纹 | O(|Φ|) 哈希 | O(|Φ|) | 指纹一致 ⇒ 成分未被替换 |
| 委员会共识 | O(k·T_est + k·iters) | O(k) | 交换性检验通过 ⇒ 覆盖成立 |
| FED-CALIB | O(n log n) | O(n) | 恶意质量 ≤ ε ⇒ 覆盖 ≥ 1-α-ε/(1-ε) |
| LICENSE-GUARD | O(|V|+|E|) | O(|V|) | 闭包兼容 ⇒ 分发合规 |
| 全局签发 | O(|Φ| + k·T_est) | O(|Φ|) | 三重绑定任一失效 ⇒ fail-closed |

正确性定理：若 (i) 指纹 F_t 等于部署 SBOM 摘要且 ℓ_s 未过期，(ii) 许可守卫通过，(iii) 委员会交换性检验在水平 α_s 通过，(iv) 恶意校准质量占比 ≤ ε，则签发的 P_t^s 满足
P(X_t ∈ P_t^s) ≥ 1-α_p-ε/(1-ε)，
且任一成分漂移会触发 fail-closed 而非静默复用旧证书。注意该定理只保证“成分未变 + 校准有效”，不保证“成分本身正确”，后者需独立真值审计。

## 4. 实验设计 E115–E120

| 实验 | 指标 | 门槛 |
|---|---|---|
| E115 SBOM 漂移检出 | 版本/权重/坐标约定变更注入的检出率、误报率 | 检出 ≥ 99%；误报 ≤ 1% |
| E116 委员会分歧校准 | D_t/ρ_t 与真实误差的 Spearman、长尾覆盖率 | ρ ≥ 0.7；覆盖率 ≥ 1-α_p |
| E117 坐标系错配 | OpenCV/REP-103/OpenGL 混用识别率 | 识别率 ≥ 99.5% |
| E118 联邦校准投毒 | ε∈{0,5%,10%,20%} 下覆盖率下降 | 下降 ≤ ε/(1-ε)+2% |
| E119 许可守卫 | GPL 闭源分发阻断率、误阻断率 | 阻断 100%；误阻断 ≤ 2% |
| E120 100h 端到端 | 供应链事件下静默失效数、重校准恢复时间、任务成功率 | 静默失效 0 起；恢复 ≤ 5min；成功率 ≥ 97% |

回退策略：E115 检出 < 95% → 强制离线固定指纹并禁用热更新；E116 相关性 < 0.5 → 委员会降为单估计器保守盒；E118 覆盖率下降超界 → 关闭联邦校准，回退本地校准；E119 误阻断 > 5% → 转人工许可审查队列。

## 6. 本轮最大风险

**一句话**：供应链指纹与许可守卫会制造“已审计”的安全感，但指纹只能证明成分未被替换、许可只能证明可分发，二者都不能证明估计器在该场景正确；若委员会成员共享同一训练偏差或联邦校准被高信誉投毒，低分歧将签发过窄证书，使姿态证书在长尾场景静默失效——因此必须把指纹证据、行为证据（独立真值/OOD）与保守半径三者联合，任何单一证据都不足以放行。
