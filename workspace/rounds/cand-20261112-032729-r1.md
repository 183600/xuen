# 第 59 轮（承接第 58 轮「KG-SFT-UX」IP-139~144；灵感循环第 1 轮；本轮灵感：「检索增强生成」×「演示数据」）

> 第 58 轮把安全论证的中心推到"结构化记忆"——KG 同时驱动检索、OOD、微调、证据合成与心智预测，代价是共模故障：KG 的系统性结构错误会让所有机制一起失效。它的风险自陈留下三个未解口子，也正是本轮两个灵感的入口：**(a)** KG 是"被整理过的结论"，一旦抽取/归类出错，错误会以结构化形式获得权威，而原始证据已被压缩，难以逐条对账；**(b)** 第 58 轮的适应靠 SFT-KG 改权重，微调会把一次性证据固化进参数，事后证伪只能回滚版本，不能回滚"已经学进去的偏见"；**(c)** 系统仍缺少"没见过时如何得体地说不知道"的机制——OOD 门能拒绝摊销先验，但解释与建议仍可能用参数记忆补全，产生"看似有据"的幻觉。
>
> 本轮两个灵感各给一条"外置记忆"的路，但都必须严格限定认识论角色：**检索增强生成**把记忆从"参数/图"换成"带溯源的原始案例库 + 推理时检索"，用归因（citation-or-abstain）对抗幻觉、用可信/不可信分账对抗投毒；它让系统"查得到"，但检索本身不是证据——检索到的东西只能按它原本的来源入账，检索命中不能给旧证据"升权"。**演示数据**把"专家怎么做过"作为可检索的行为先验，用上下文示范替代改权重（不微调），但示范是"行为"不是"真理"，且天然只记录成功案例（幸存者偏差）；因此示范只能提出候选/收窄搜索/生成解释，必须经反事实验证，永远不能进入不可逆接触的必要证据集。核心命题由"结构化记忆守护下的安全自适应"升级为 **"检索可溯源、示范可反证、生成可拒答的证据承诺"**。

核心矛盾：
- **H32（检索召回 vs 幻觉/支持缺口）**：检索器越依赖稠密相似度，越容易把"语义相近但物理不同"的案例召回；真正救命的稀有反例往往相似度低、排不进 top-k。而一旦允许模型"用自己的记忆补全"，支持缺口就被流畅的幻觉填满——最危险的输出恰恰看起来最有据。
- **H33（示范可信 vs 幸存者偏差/行为-真值缺口）**：示范只展示"做成了的那次"，看不到失败的反事实；"专家这样做过"不等于"这样做安全"。若把示范当证据，系统会系统性高估罕见风险下的安全性。
- **H34（外置记忆 vs 新的单点）**：RAG 与示范库若都从同一语料/同一专家来，只是把 KG 的单点换成"语料+检索器"的新单点；共模失效没有消失，只是换了位置。必须让记忆的失败只导致"拒答/加宽/真实探针"，而不是"更自信"。

## 0. 直觉与动机

**灵感 1（RAG → 从"记住结论"到"检索原始案例 + 归因"）**
直觉：第 58 轮的 KG 是"已经嚼过的知识"——实体、边、权重。嚼过的知识方便，但一旦嚼错（把相似表面并错、把早期橡皮章操作者的熟悉度写成高权重），错误就以"结构化"的姿态获得权威，而原始证据已经被压缩掉，无法逐条对账。RAG 换一种记忆观：**不存结论，存案例**。每个案例是一张带溯源的卡片：(区域上下文, 观测, 采取的动作, 事后结果, 来源, 验证状态, 签名)。决策时按当前上下文检索 top-k，让推断"看着案例说话"，并强制归因：每条承重结论必须能指到具体卡片，指不到就删掉；删掉后结论不成立就**拒答并去探**。检索的作用被严格限定为**提候选、找反例、做解释**，不是"给证据升权"：一张旧卡片仍然只是它原来的证据类（真实探针/仿真/示范/人报），检索命中不改变它的权重。

**灵感 2（RAG 投毒 → 检索也要走隔离）**
直觉：能被检索的东西就能被塞进来。语料里混入一条"该材质干燥、可直接通过"的伪造案例，若检索器把它排进 top-k，生成器就会言之凿凿地引用它。防御不是"更相信检索器"，而是**分账 + 单调**：语料分可信/不可信；不可信卡片只能**加宽**后验或提出候选，永远不能收窄、不能充当必要证据；来源信誉按事后证伪回溯降级；top-k 加多样性约束，防止单一簇/单一来源刷屏；检索、归因、投毒事件全部入审计日志。这样投毒成功最多让你"多探一次"，不能让你"少探一次"。

**灵感 3（演示数据 → 用上下文示范替代微调，但示范只提候选）**
直觉：第 58 轮的 SFT-KG 用微调把新证据写进适配器，效率高但不可逆：一次坏标注可能被固化进权重，回滚只能回版本。演示数据提供另一条适应路径：**不改权重，改上下文**——检索相似示范，作为 few-shot 上下文喂给策略/元推断，让它"照着做过的人试一次"。优点是即插即用、可即时撤回（撤掉示范即可），缺点是示范是**行为**不是**真值**：它告诉你"有人这么做过并成功了"，不告诉你"这样做在别的条件下也安全"。因此示范只许三类用途：提候选策略/步态、收窄搜索、生成解释；不许提升授权、不许减少佐证、不许进入不可逆必要证据集。

**灵感 4（幸存者偏差 → 反事实示范验证）**
直觉：示范库天然是"幸存者名单"——失败的操作不会被录成示范，于是"示范里从没出过事"是选择偏差，不是安全性。本轮给每条示范做**反事实体检**：在示范上下文附近的扰动分布里，用第 58 轮的影子仿真与共形残差估计"如果条件稍微变坏，这条示范会不会违反约束"，取风险上界；上界超阈值就判示范不可用；扰动落在声明支持域外则直接判"无法认证"。再按"被录成示范的概率"做逆倾向重加权，报告有效样本量。核心是：**示范只能被反证，不能被证明**——反事实不过 ⇒ 撤下；反事实过了 ⇒ 也只是候选，不是安全证书。

**灵感 5（合流 → 七类证据门 + "检索不是证据" + 三方对账）**
直觉：第 58 轮已有六类证据门（EV-probe*/visit/margin/xmodal/human/ft/ux）。本轮新增唯一一类 **EV-demo**（仅 L0.5/L1、仅候选/收窄、outcome-verified 且反事实过），并立一条硬规则：**不存在 EV-ret**——检索本身不是证据类，检索到的卡片按原来源入账。再补一个三方对账器 RDX：物理证据 E、检索案例 R、可用示范 D。一致只允许 L1 候选加速与解释；分歧则加宽并按溯源定位离群源；无支持且无可用示范则显式 "unknown"，只许真实探针，禁止生成式补全。安全纵深从"多一个模型"变成"多一层认识论隔离"：候选通道与认证通道单向连通——候选只能让动作更保守或触发探针，认证永不依赖候选。

## 1. 形式化定义（增量：定义 145–150）

**定义 145（检索增强证据记忆 RGEM）** 证据语料 𝓔=𝓔_t ⊔ 𝓔_u，卡片 c_i=(z_i,o_i,a_i,y_i,φ_i,src_i,ver_i,t_i,sig_i)：z 区域上下文、o 观测、a 采取动作、y 事后结果、φ 溯源链、src∈{probe,visit,sim,demo,human}、ver∈{verified,unverified,falsified}、t 时间、sig 签名。混合检索器 R(q)=TopK_div(Dense(q)∪Sparse(q)∪Graph(q))，多样性约束为单源/单簇占比 ≤p_max。**召回契约**：对标注查询集，关键支持（含稀有反例）落入 top-k 的概率 ≥1−δ_ret；**支持缺口** n_ret(q)>θ_ret 或 has_support(q)=0 ⇒ 返回 ⊥，禁止生成承重结论。硬规则：检索不是证据类；每张卡片只按 src_i 的原证据类入账，检索命中不改变 src/ver/权重。不可信语料 𝓔_u 的卡片只能加宽或提候选。

**定义 146（检索归因与投毒防护 RAF）** 归因 Att:claim→2^𝓔，支持度 sup(c)=Σ_{c'∈Att(c)} conf(c')·1[src(c')∈𝓔_t]。忠实度 F=承重且被支持 claim 数 / 承重 claim 总数。**生成门**：F<1−ε_attr 或存在无支持的承重 claim ⇒ 删去该 claim；若删除后结论不成立 ⇒ 拒答（abstain）并转真实探针，不得用参数记忆补全。**投毒防护**：源信誉 ρ_src 按事后证伪乘性降级、按证实有界恢复；签名校验；top-k 多样性；若可信与不可信来源冲突 ⇒ 加宽并标记，不采信不可信方。投毒攻击模型 ≤ε_poison，且被投毒卡片不得收窄后验。

**定义 147（示范证据模型 DEMO）** 示范 d=(z_d,τ_d,op_d,y_d,φ_d)，τ_d 状态-动作轨迹，op_d 演示者，y_d 结果。质量 q_d=calibrated(outcome_verified, ρ_op, coverage_of_failure_modes)∈[0,1]。示范只许三类用途：(U1) 提候选策略/步态；(U2) 收窄搜索（不得收窄后验，只收窄动作集）；(U3) 生成解释（仍受 RAF 归因门约束）。**上下文适应**：示范作为 few-shot 上下文注入，不更新任何权重（与 IP-140 的 SFT-KG 相对）。EV-demo：仅 L0.5/L1、仅 U1/U2、outcome-verified 且 CDV 通过；不得提升授权、不得减少佐证、不得进入不可逆必要证据集。

**定义 148（反事实示范验证 CDV）** 观测示范 D_obs 条件于未失败（幸存者偏差）。对 d 定义扰动分布 P_pert(·|z_d) 与声明支持域 𝒮_pert；反事实风险 CF(d)=E_{θ~P_pert}[1[violation|π_d,θ]]。认证：d 可用 ⇔ outcome_verified(d) ∧ z_d∈𝒮_pert ∧ UCB_β(CF(d))≤δ_demo；z_d∉𝒮_pert ⇒ 判"无法认证"（不是"安全"）。用逆倾向重加权 w_d∝1/π_d 校正选择偏差并报告有效样本量 ESS。**只可反证**：反事实超界 ⇒ 撤销 EV-demo 并降 ρ_op；反事实通过 ⇒ 仅恢复候选资格，不产生安全证书。

**定义 149（检索-示范-证据三方对账 RDX）** 三源：物理证据 E（真实探针/到访/裕度）、检索案例 R、可用示范 D。对账：
(R1) 一致 ⇒ 仅允许 L1 候选加速与解释，不进入必要集；
(R2) 分歧 D_RDE(r)=TV(b_E,b_R)+TV(b_E,b_D)>θ_D ⇒ 加宽后验，按溯源/源信誉定位离群源并降权；
(R3) 无支持 R=⊥ 且无可用 D ⇒ 显式 unknown，只许真实探针，禁止生成式补全；
(R4) 硬界：R/D 永不收窄低于 E 的证据；不可信 R 只加宽；D 不提升 auth、不减佐证。

**定义 150（七类证据门与证书 J_p+++）** 证据类={EV-probe*,EV-visit,EV-margin,EV-xmodal(限 L1),EV-human,EV-ft,EV-ux,EV-demo(限 L0.5/L1、候选/收窄、outcome-verified+CDV)}；**不存在 EV-ret**。不可逆接触必要证据集={EV-probe*∨EV-margin}∪佐证，**EV-demo/EV-xmodal/EV-ft/EV-ux 均不得进入**。证书 J_p+++=(J_p++, retrieval_log, attribution_log, support_gap_registry, poison_log, demo_log, cf_verify_log, rde_reconcile_log)，继承 J_p++ 全检。

## 2. 关键算法伪代码（完整版见产物区）

```python
def rag_ground(q, corpus, gate):                 # IP-145/146: 检索→归因→拒答
    cand = hybrid_topk(q, corpus.E_t, corpus.E_u, k, p_max)
    if no_support(cand, q) or n_ret(q) > gate.theta_ret:
        return Abstain(support_gap=True)         # 无支持即拒答，绝不补全
    claims = generate_claims(q, cand)
    kept = [c for c in claims if sup(c, cand) >= gate.theta_prov]
    if any(c.load_bearing and c not in kept for c in claims):
        return Abstain(unsupported_load_bearing=True)
    return GroundedAnswer(kept, citations=Att(kept))

def demo_admit(d, sim, gate):                    # IP-147/148: 示范只提候选
    if d.src != 'demo' or not outcome_verified(d): return None
    if d.z not in gate.S_pert: return None        # 支持外=无法认证
    cf = counterfactual_risk(d, sim, P_pert=gate.P_pert)
    if ucb(cf, gate.beta) > gate.delta_demo:      # 反事实不过=撤销
        gate.revoke_demo(d); return None
    return Candidate(d, use={'U1','U2','U3'})      # 候选，不是证书
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| RGEM | O(log N + k·d)/查询 | O(\|𝓔\|) 增量 | 召回契约、支持缺口检测、溯源诚实 |
| RAF | O(\|claims\|·\|Att\|) | O(\|𝓔_t\|) | 引用或拒答、不可信只加宽、投毒上界 |
| DEMO | O(k·d)/查询 | O(\|D\|) | 仅 U1–U3、不更新权重、不提升授权 |
| CDV | O(N_cf·T_sim)/示范（离线） | O(N_cf) | 反事实上界、支持域诚实、只可反证 |
| RDX | O(\|ℳ\|·d_b) | O(\|V\|) | 一致不收窄、分歧加宽、无支持拒答 |
| PCX++++ | O(\|CP\|·(k_p+k_c+k_ft+k_ux+k_ret+k_demo)·(C_VOI+d)) | O(\|V\|+\|σ\|+\|𝓔\|) | 七类门硬禁令、候选/认证单向 |

**正确性定理（Retrieval-Grounded Demonstration Soundness, RGDS 概要）**：在 A41–A45 上加 (A46) RGEM：召回契约、支持缺口检测、溯源诚实、检索不改变证据类；(A47) RAF：忠实度门、拒答优先、不可信只加宽、投毒上界；(A48) DEMO：示范仅 U1–U3、不更新权重、不提升授权；(A49) CDV：反事实风险上界、支持域诚实、幸存者偏差重加权、只可反证；(A50) RDX/证据门：三方对账单调、无 EV-ret、R/D 不入不可逆必要集。则：
(i) ID 路径承诺失效率 ≤ 第 58 轮界 + δ_ret·1[支持缺口漏检] + ε_attr·1[承重 claim] + ε_poison·1[不可信命中] + δ_demo·1[EV-demo] + δ_cdv·1[反事实漏检]；
(ii) **单向性**：检索/示范的失败只经"拒答/加宽/真实探针/更保守动作"影响系统；命中只经"候选/解释"影响，永不提升授权或替代必要证据；
(iii) 终止性：PCE++++ 在 k_p+k_c+k_ft+k_ux+k_ret+k_demo 内终止；检索与反事实验证均有预算上界。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 检索召回盲区/稀有反例漏检 | 高 | 混合检索 + 支持缺口显式化 + 无支持即拒答 + 真实探针兜底 |
| 生成幻觉/洗权（检索被当证据） | 高 | 引用或拒答 + 不存在 EV-ret + 原来源入账 + 忠实度门 |
| 语料投毒/来源信誉被养 | 高 | 可信/不可信分账 + 不可信只加宽 + 签名 + 多样性 + 事后证伪回溯 |
| 示范幸存者偏差/行为≠真值 | 高 | 反事实体检 + 支持域外不认证 + 只可反证 + 永不进入必要集 |
| 检索/示范成为新单点 | 中 | 三方对账 + 失败只导致拒答/加宽 + 与真实证据单调隔离 |
| 过度拒答拖慢任务 | 中 | 拒答预算 + VOI 在保守约束内优化 + 候选加速仅限 L1 |

## 6. 本轮最大风险

**一句话**：本轮把安全论证的锚点从"结构化记忆"换成了"可检索的案例与示范"，风险也从"图的结构性错误"变成"检索的分布性盲区 + 示范的幸存者偏差"——若检索器系统性漏掉关键反例、示范又只含成功案例，系统会以"有据可查"的姿态自信地重复历史成功路径；必须以"检索不是证据、示范只提候选、无支持即拒答、反事实不过即失效"四条硬规则守住。

# 第 59 轮产物 · 创新点清单 v35：RAG-Demo（检索增强证据记忆×归因生成×示范反事实验证×三方对账，RGEM×RAF×DEMO×CDV×RDX×PCX++++）

> 承接第 58 轮 IP-139~144（KGMM/SFT-KG/UXSE/KGES/ACC/PCX++）与第 57 轮 IP-133~138（MFSL/XMC/PTM/MXI/FSE/PCE+）。本轮把部署前提从「结构化记忆守护下的安全自适应」升级为 **「检索可溯源、示范可反证、生成可拒答的证据承诺」**：记忆从"被整理的结论"退回"带溯源的原始案例"，生成从"自由补全"收紧为"引用或拒答"，适应从"改权重"换成"改上下文"，示范从"专家做过"降格为"可被反事实推翻的候选"。第 58 轮「知识图谱也要走隔离」在本轮推广为 **「检索也要走隔离——检索只提候选，证据按原来源入账；示范也要走隔离——示范只提候选，永不进入不可逆必要集」**。
> IP 编号：IP-145~IP-150（共 6 个），其中 IP-145~148 为新增，IP-149/150 为融合升级（升级 IP-142/143/144）。

**一句话原则**：**检索只提候选，探针才作证；示范只提候选，反事实才证伪；生成只许引用，无据必须拒答。** 候选通道（检索/示范/生成）与认证通道（真实探针/裕度）单向连通：候选只能让动作更保守或触发探针，认证永不依赖候选。

### IP-145 RGEM（检索增强证据记忆）

```python
class RetrievalGroundedEvidenceMemory:
    def __init__(self, theta_ret, p_max=0.4, k=8):
        self.E_t = CaseStore(trusted=True)      # 真实探针/到访/已验证人报
        self.E_u = CaseStore(trusted=False)     # 仿真/未验证人报/外部导入
        self.retriever = HybridRetriever(dense=..., sparse=..., graph=...)
        self.gap = SupportGapRegistry()
        self.theta_ret, self.p_max, self.k = theta_ret, p_max, k

    def retrieve(self, q):
        pool = (self.retriever.topk(q, self.E_t, self.k)
                + self.retriever.topk(q, self.E_u, self.k))
        cand = diversify(pool, p_max=self.p_max)
        if self.retriever.n_ret(q) > self.theta_ret or not self.has_support(q, cand):
            self.gap.record(q, reason='support_gap')
            return None                          # ⊥：禁止生成承重结论
        return cand

    def ingest(self, card, contact_cert):
        """仅证据门通过的接触可写入；检索层永不改变证据类。"""
        if not contact_cert.ok or not verify_signature(card):
            return
        if card.src in TRUSTED_SRC and card.ver == 'verified':
            self.E_t.add(card)
        else:
            self.E_u.add(card)                   # 不可信：只能加宽/提候选

    def falsify_retract(self, card_id, verdict):
        """复用第 58 轮事后证伪：回溯标记卡片，信誉降级。"""
        card = self.E_t.pop(card_id, None) or self.E_u.pop(card_id, None)
        if card and verdict.falsifies(card.src):
            card.ver = 'falsified'
            self.E_u.add(card)
            self.update_reputation(card.src, verdict)
```

### IP-146 RAF（检索归因与投毒防护）

```python
def ground_generate(q, cand, corpus, gate):
    claims = generator.claims(q, cand)
    kept, dropped = [], []
    for c in claims:
        support = [card for card in Att(c, cand)
                   if card.src in corpus.trusted_src
                   and card.conf >= gate.theta_prov]
        (kept if support else dropped).append((c, support))
    if any(c.load_bearing for c, _ in dropped):
        return Abstain('unsupported_load_bearing', dropped)  # 无据即拒答
    if len(kept) / max(1, len(claims)) < 1 - gate.eps_attr:
        return Abstain('low_faithfulness', dropped)
    return GroundedAnswer(kept)

def fuse_retrieval_candidate(b_E, cand, gate):
    """仅用于候选/VOI；认证信念始终是 b_E。"""
    trusted = [c for c in cand if c.src in TRUSTED_SRC]
    untrusted = [c for c in cand if c.src not in TRUSTED_SRC]
    b_prop = b_E
    if trusted:
        b_prop = mixture(b_prop, fuse(trusted),
                         min(sum(c.conf for c in trusted), gate.w_cand_max))
    if untrusted:
        b_prop = widen(b_prop, gate.w_u)         # 不可信只加宽，绝不收窄
    return b_prop

def update_reputation(src, verdict, rho):
    if verdict.falsifies(src):
        rho[src] = max(RHO_MIN, rho[src] * GAMMA_DOWN)   # 证伪快降
    elif verdict.confirms(src):
        rho[src] = min(1.0, rho[src] + GAMMA_UP)         # 证实慢升
```

class DemonstrationStore:
    def __init__(self, cdv, gate):
        self.demos, self.cdv, self.gate = [], cdv, gate

    def admit(self, d):
        if not outcome_verified(d):
            return None
        if d.z not in self.gate.S_pert:
            return None                          # 支持外：无法认证，不是安全

            return None

    def propose(self, q, k=4):
        return [c for c in (self.admit(d) for d in self.retrieve(q, k)) if c]

### IP-148 CDV（反事实示范验证）

```python
def counterfactual_risk(d, sim, P_pert, beta, N=256):
    fails = [sim.violates(d.pi, theta) for theta in P_pert.sample(d.z, N)]
    return clopper_pearson_upper(sum(fails), N, beta)

class CounterfactualVerifier:
    def __init__(self, sim, gate):
        self.sim, self.gate = sim, gate

    def pass_(self, d):
        if d.z not in self.gate.S_pert:
            return False
        return (counterfactual_risk(d, self.sim, self.gate.P_pert,
                                    self.gate.beta)
                <= self.gate.delta_demo)

    def reweight(self, demos):
        w = [1.0 / max(d.propensity, 1e-6) for d in demos]
        ess = (sum(w) ** 2) / sum(x ** 2 for x in w)
        return w, ess
```

### IP-149 RDX（检索-示范-证据三方对账）

```python
def reconcile_rde(b_E, R, D, gate):
    """b_E 是唯一认证信念；R/D 只能加宽或提候选。"""
    if R is None and not D:
        return b_E, 'unknown'                    # 只许真实探针
    b_R = fuse(R) if R else None
    b_D = fuse(D) if D else None
    div = (tv(b_E, b_R) if b_R else 0.0) + (tv(b_E, b_D) if b_D else 0.0)
    if div > gate.theta_D:
        outlier = locate_outlier(b_E, b_R, b_D, R, D)
        downgrade(outlier)                       # 按溯源/信誉降离群源
        return widen(b_E, div), 'reconciled_widen'
    return b_E, 'consistent_candidate_only'      # 一致也不收窄
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| RGEM | O(log N + k·d)/查询；入库 O(1) | O(\|𝓔\|) 增量 | 召回契约、支持缺口检测、溯源诚实、检索不改证据类 |
| RAF | O(\|claims\|·\|Att\|)/生成 | O(\|𝓔_t\|) | 引用或拒答、不可信只加宽、投毒上界 ε_poison |
| DEMO | O(k·d)/查询；上下文注入 O(k) | O(\|D\|) | 仅 U1–U3、不更新权重、不提升授权、不减佐证 |
| CDV | O(N_cf·T_sim)/示范（离线） | O(N_cf) | 反事实上界、支持域诚实、只可反证、ESS 报告 |
| RDX | O(\|ℳ\|·d_b)/区域 | O(\|V\|) | 一致不收窄、分歧加宽、无支持显式 unknown |
| PCX++++ | O(\|CP\|·(k_p+k_c+k_ft+k_ux+k_ret+k_demo)·(C_VOI+d)+\|CP\|·A\*) | O(\|V\|+\|σ\|+\|𝓔\|) | 七类门硬禁令、候选/认证单向、六预算终止 |

**正确性定理（Retrieval-Grounded Demonstration Soundness, RGDS）**
假设 A22–A45（第 53–58 轮）成立；**(A46)** RGEM：召回契约 P(关键支持∈R(q))≥1−δ_ret、支持缺口检测漏检 ≤δ_gap、卡片溯源诚实、检索命中不改变 src/ver/权重；**(A47)** RAF：忠实度门 F≥1−ε_attr 或拒答、不可信卡片只加宽、投毒成功 ≤ε_poison 且不得收窄；**(A48)** DEMO：示范仅用于 U1–U3、上下文适应不更新权重、EV-demo 不提升授权/不减佐证；**(A49)** CDV：CF 上界诚实、𝒮_pert 声明诚实、支持外不认证、幸存者偏差逆倾向重加权、反事实只可反证；**(A50)** RDX/证据门：三方对账单调、无 EV-ret、R/D 不入不可逆必要集。则：

1. **认证不依赖候选**：任意承诺的认证证据集只由 {EV-probe*, EV-visit, EV-margin, EV-human, EV-xmodal(限 L1), EV-ft, EV-ux} 构成，检索/示范只能改变候选集、VOI 或解释，不能改变认证结果；因此检索/示范的分布性错误不会直接转化为错误承诺。
2. **失败单向性**：检索失败 ⇒ 支持缺口/拒答/加宽/真实探针（效率损失）；示范失败 ⇒ 撤销候选（效率损失）；二者都不产生"更自信/更少探"的正向错误。只有"支持缺口漏检"与"反事实漏检"两项会进入安全界，且均被显式计入部署界。
3. **校准保守性**：ACC 校准集只收真实残差；检索/仿真残差不得压低带宽（`acc_with_retrieval`），故 coverage 不低于第 58 轮。
4. **终止性**：PCE++++ 在 k_p+k_c+k_ft+k_ux+k_ret+k_demo 内终止；检索与反事实验证均有预算上界，支持缺口不会触发无限重试。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                   + δ_ft·1[回滚窗口] + δ_kg·1[检索失败] + δ_ux·1[μ_mis>θ_mis])
         − δ_gap·1[支持缺口漏检] − ε_attr·1[承重 claim]
         − ε_poison·1[不可信命中] − δ_demo·1[EV-demo]
         − δ_cdv·1[反事实漏检]
         − P(𝒢 结构性错误未检出) − P(护盾回退失败) − P(τ_int 超时 ∧ 安全停失效)
```

关键：**RGEM 把"记忆"从结论降回案例**，让错误可对账；**RAF 把"生成"从自由补全收紧为引用或拒答**，让幻觉不能承重；**DEMO/CDV 把"示范"从专家权威降格为可反证候选**，让幸存者偏差不能变成安全证书；**RDX 把"候选"与"认证"单向隔离**，让外置记忆的失败只损失效率、不损失安全。

## 4. 实验设计 E182–E186

| 实验 | 指标 | 目标 |
|---|---|---|
| E182 检索召回与支持缺口 | 稀有反例 recall@k（注入 5% 关键反例）；支持缺口检出率/误报率；拒答率；与第 58 轮 KG 检索对比 | recall≥95%；检出≥90%、误报≤2%；拒答 5%~15%；recall↑≥15% |
| E183 归因忠实与拒答 | 承重无支持 claim 率；幻觉率；拒答正确率；引用精确率 | 0；↓≥90%；≥95%；≥95% |
| E184 检索投毒 | 投毒命中率；不可信卡片收窄次数；源信誉恢复时延；多样性约束命中 | ≤1%；0；≤2 次证伪；≥90% 拦截单簇刷屏 |
| E185 示范反事实与幸存者偏差 | 伪成功示范检出率；支持外示范接受数；ESS 估计误差；示范候选的探针节省 | ≥90%；0；≤10%；探针数↓≥20% |
| E186 端到端 | 季度漂移场地 vs 第 58 轮：成功率/探针时间/首访承诺时延/标注利用率/拒答率/错误承诺率 | +8%/−25%/−20%/+20%/≤5%/−60% |

**实验要点**：
- E182 的"稀有反例"由人工注入（如"看起来干燥的透明冰面"），专门检验稠密检索的盲区；同时报告 top-k 中反例排名分布，证明支持缺口不是靠运气。
- E183 用"删除检索证据后模型是否仍给出同一承重结论"检验洗权；正确行为是拒答，而不是用参数记忆硬答。
- E184 在可信语料中注入伪造卡片，检查不可信分区是否只加宽、是否出现任何一次"收窄"；并验证信誉恢复不会因一次证实而瞬间洗白。
- E185 构造"只录成功、失败被隐藏"的示范集，检验 CDV 能否在扰动下发现伪成功；ESS 用来量化"看起来很多、其实很少"的示范。
- E186 重点看"拒答率 ≤5%"——安全机制不能把任务拖死；拒答应集中在真正的高风险检查点。

## 6. 本轮最大风险

**一句话**：本轮把安全论证的锚点从"结构化记忆"换成了"可检索的案例与示范"，风险也从"图的结构性错误"变成"检索的分布性盲区 + 示范的幸存者偏差"——若检索器系统性漏掉关键反例、示范又只含成功案例，系统会以"有据可查"的姿态自信地重复历史成功路径；必须以"检索不是证据、示范只提候选、无支持即拒答、反事实不过即失效"四条硬规则守住。
