# 第 68 轮（承接第 67 轮「SimRAS 仿真增强风险闭环」IP-233~242；灵感循环第 1 轮（新循环）；本轮灵感：「多轮对话」×「三维感知」）

> 前三轮（VISTA→RAS→SimRAS）一直在给「故障」建模：几何故障、情绪故障、未来故障。但它们共享一个从未被检验的**语义前提**——任务与环境是给定的，指称是唯一的，视角是固定的。真实人机协作里，人说的是「把那个挪到这边、轻一点、不是这个」，充满省略、指代、视角依赖与中途修订。
>
> 本轮命题：
>
> **把「对话轮次」当作作用在「三维场景图信念」上的主动实验：一句话 = 一条约束，一次追问 = 一次信息增益最优的观测，一次执行 = 一张可验证的指称证书。**
>
> 命名 **D3C（Dialogue-grounded 3D Adaptive Closure，对话-三维联合自适应闭环）**。它不是「LLM + 点云」的拼接，而是把 VISTA 的「故障可归因」、RAS 的「意图可协商」、SimRAS 的「未来可预演」统一到一个**语言-几何联合信念**上：对话负责消歧意图，三维感知负责验证指称，闭环只在「指称被证书锁死」时才执行。

## 0. 直觉与动机

**灵感 1（多轮对话 → 对话是「主动感知」，不是「指令解析」）**
直觉：现有 embodied LLM 把每句话独立解析成动作，像是把多轮对话拍平成单轮分类。但多轮对话的真正价值是**消歧**：第一轮「那个杯子」不明确，第二轮「不是这个，左边那个」才收敛。也就是说，对话轮次不是冗余，而是**对同一三维假设的一次次条件化**。既然如此，系统就不该被动等待澄清，而应像主动学习一样**主动选择下一个问题**。

**灵感 2（三维感知 → 指称必须有几何锚点）**
直觉：语言里的指称天然是「绑定」问题：`"杯子" → 世界坐标里的哪一条 track？`。仅靠文本嵌入无法区分桌上两个一样的杯子；一旦物体移动、遮挡或换了视角，纯语言共指就会漂移。三维感知提供**持久 track ID + 6DoF 位姿轨迹**，让「那个杯子」跨轮绑定到同一物理实体。这把对话状态跟踪（DST）从「文本槽位」升级为「三维场景图节点」。

**灵感 3（真正的交点：视角依赖的指示词）**
直觉：「左/右/前/后/近」是**相对观察者**的。人说「放左边」，指的是**人自己的左边**，不是相机坐标的 x 负方向。机器人若用相机系去解，会在人转身后系统性出错。于是必须联合估计**说话人 6DoF 位姿 ξ**，把指示词语义落在 ξ 的坐标系里。当 ξ 不确定时，「左边」本身就是一个**歧义假设**——它恰可由一句追问（「您的左边还是我的左边？」）或一次感知动作（转头看说话人）来消解。

**灵感 4（三脉络合流：主动实验 = 问 / 看 / 做）**
直觉：D3C 把机器人的认知动作空间扩成三类——`ask`（问人）、`obs`（重新看/换视角）、`act`（执行）。三者都在降低同一个联合信念的熵，只是成本不同。于是「要不要再问一句」变成一个可计算的最优停止问题：`IG(q)/cost(q) > ν` 才问，否则直接看或直接做。这也解释了为什么「问太多」和「不问就做」都不对——它们只是在信息增益与打扰成本之间取了不同的点。

**灵感 5（D3C 对前三轮的升级点）**
- **VISTA 的「几何故障」** → 增加**语义故障**：指称错误、谓词误判、视角错配；
- **RAS 的「情绪探针」** → 泛化为**对话探针**：追问是比情绪探针更直接的信息获取；
- **SimRAS 的「世界模型」** → 增加 `dialog_head`：预测下一轮用户约束与信念更新，离线用**用户模拟器**扩充 `D_sim^dlg`；
- **C-RAS / C-RAS-WM 的认证前缀** → 增加 `k_ref`：没有指称证书就不执行；
- **J 证书** → 增加 `referent_hash / frame_hash / dialogue_hash`，使「我理解的是哪个物体、哪个视角、依据哪几句话」可审计。

## 1. 形式化定义（增量：定义 266–285）

- **定义 266（D3C 总览）**：D3C = (DGU, SGB, APX, GRC, C-D3C, DRB, DWM)。定位：把 VISTA/RAS/SimRAS 的「物理-情绪-未来」闭环升级为「语言-几何」闭环。不变式：DGU/SGB/APX/证书构建只在语义流；实时流只做 track 更新、证书布尔判定、前缀早停，零学习写操作。
- **定义 267（类型化空间约束）**：第 t 轮话语 `u_t` 经 DGU 解析为约束集 `C_t = {c_i}`，`c_i = (type, M_i, φ_i, ξ_i, w_i)`，`type ∈ {REF, REL, ACT, REV, ANS}`（指称/空间关系/动作/修订/回答），`M_i` 为提及集，`φ_i` 为可判定谓词，`ξ_i` 为谓词所用坐标系，`w_i` 为置信权重。
- **定义 268（三维场景图）**：`G_t = (V_t, E_t, A_t)`。节点 `v=(id, o, T_v, S_v, F_v)`：持久 track ID、语义类别、世界系 6DoF 位姿、形状/占用、可供性。边 `E_t` 为空间关系（含距离/朝向/支撑）。`id` 跨轮持久，是共指的几何锚。
- **定义 269（说话人坐标系与指示词落地）**：说话人位姿 `ξ_t ∈ SE(3)`，后验 `B_t^ξ`，不确定度 `Σ_ξ`。指示谓词在说话人系落地：如「X 在 Y 左边」⇔ `⟨R_ξ e_left, p_X − p_Y⟩ > 0`。当 `Σ_ξ` 大时，同一话语诱导**谓词假设集**而非单值。
- **定义 270（语言-几何联合信念）**：`B_t(G, ξ, u | D_{1:t}, O_{1:t}) ∝ P_0(G, ξ, u) · ∏_{i≤t} P(O_i | G, ξ) · P(C_i | G, ξ, u)`。近似分解为 `B_t^G · B_t^ξ · B_t^u`，保留 REF 与 ξ 的耦合项（指示词依赖）。
- **定义 271（指称绑定 / 数据关联）**：绑定 `a: M → V`，联合得分 `s(m, v) = α·sim_emb(m, v) + β·sim_spatial(m, v) + γ·(1 − H_track(v))`。绑定后验 `P(a(m)=v | B_t) ∝ s(m,v)·B_t^G(v)`。
- **定义 272（指称歧义度）**：`H_ref(t) = H(a | B_t)`，`conf_ref(t) = max_v P(a=v | B_t)`。歧义 ⇔ `H_ref > τ_H` 或 `conf_ref < 1 − δ_ref`。
- **定义 273（认知动作空间）**：`A_epi = A_ask ∪ A_obs ∪ A_act`。`A_ask = {yes/no(φ), which(φ, Cand), frame(term), confirm(v)}`（受限问句文法，答案空间有界、可直接转成约束）；`A_obs` 为换视角/靠近/重扫；`A_act` 为执行动作块。
- **定义 274（期望信息增益）**：`IG(a) = H(B_t) − E_{r∼P(r|a,B_t)}[H(B_{t+1}(r))]`，用场景图粒子近似。成本 `cost(a) = c_turn + c_lat(a) + c_annoy(a)`。
- **定义 275（最优提问与停止）**：`a* = argmax_{a∈A_epi} IG(a)/cost(a)`；仅当 `IG(a*)/cost(a*) > ν` 且 `H_ref > τ_H` 时执行 `a*`，否则执行 `A_act`。`ν` 为信息价值阈值，`ν↑` 则少问、`ν↓` 则多问。
- **定义 276（指称证书 GRC）**：`GRC_t ⇔ (1) conf_ref ≥ 1−δ_ref`（或集合承诺 + 安全回退）；`(2) P(φ 为真 | B_t) ≥ 1−δ_pred`；`(3) KL(B_t^ξ ‖ B_t^{ξ,prior}) ≤ τ_ξ`（或视角已被问句消解）；`(4) consistent(B_t, K_t)`（不与已提交轮次矛盾）。
- **定义 277（认证前缀 C-D3C）**：`k_ref = max{k : ∀s≤k, GRC_{t+s}}`；`k* = min(k_VISTA, k_emo, k_wm, k_ref, m)`。
- **定义 278（可废止修订与承诺缓冲）**：修订算子 `∘` 满足 AGM：`B_t ∘ c = argmin_{B'} d(B', B_t) s.t. B' ⊨ c`。承诺缓冲 `K_t` 记录已执行但未越过不可逆边界的块；新约束若使某承诺的后验跌破 `τ_retract`，则回退到最近不可逆边界。
- **定义 279（对话一致性）**：轮序列一致 ⇔ 不存在已提交提及被绑定到互不相容的 track；矛盾检测 `contradict(c, K_t)` 返回最小冲突支撑集，供修订使用。
- **定义 280（对话世界模型 DWM）**：`DWM_θ = (Enc, dyn_head, dialog_head)`。`dialog_head(B_t, a_t) → P(ΔB_{t+1}), P(u_{t+1} | B_t, a_t)`。用于离线估计 `IG`、预测可能的修订、热启动信念。
- **定义 281（用户模拟器与对话数据集）**：SimEngine-Dlg 在 SimEngine 上叠加**空间歧义用户模型**（省略、指代、视角混用、随机修订），生成 `D_sim^dlg = {(G, ξ, D_{1:T}, O_{1:T})}`，分布匹配目标 `TV(P_sim^dlg ‖ P_real^dlg) < 0.1`。
- **定义 282（语义故障假设）**：在 `ℋ` 上新增 `H_ref`（指称错）、`H_pred`（谓词误判）、`H_frame`（视角错配）、`H_rev`（未吸收修订）；与几何/情绪/未来故障组成 `ℋ_D3C`。
- **定义 283（AIC-D3C 干扰集）**：`ℰ_D3C = ℰ_SimRAS × ℰ_lang × ℰ_geom`，`ℰ_lang = {歧义、指代漂移、恶意误导、方言/省略}`，`ℰ_geom = {遮挡、重复物体、动态移动、视角突变}`。
- **定义 284（J_D3C 证书）**：`J_D3C = (J_SimRAS, referent_hash, frame_hash, dialogue_hash, grc_flag, k_ref)`。Valid ⇔ `Valid(J_SimRAS) ∧ grc_flag ∧ dialogue_hash ≠ ∅`。
- **定义 285（D3C 在线不变式）**：实时环路只含 track 更新、SGB 增量更新、GRC 布尔判定、C-D3C 前缀计算；DGU/DWM/APX 的搜索在语义流异步完成；任何 `GRC=False` 的块都不得越过不可逆边界。

## 2. 关键算法骨架

```python
# DGU：把话语解析成类型化约束
class DialogueGroundingUnit:
    def parse(self, utterance, G, xi):
        mentions = extract_mentions(utterance)
        constraints = []
        for m in mentions:
            cands = self.scene_graph.lookup(m.lemma, G)       # 候选 track
            frame = self.resolve_frame(m, xi)                  # speaker/robot/world
            pred  = self.predicate(m, frame)                   # left_of, near, ...
            constraints.append(Constraint('REF', {m}, pred, frame, 1.0))
        for rel in extract_relations(utterance):
            constraints.append(Constraint('REL', rel.mentions, rel.pred,
                                          self.resolve_frame(rel, xi), 1.0))
        return constraints


# SGB：语言-几何联合信念
class SceneGraphBelief:
    def update(self, constraints, obs):
        self.G = self.tracker.update(self.G, obs)              # 3D 观测
        self.xi = self.speaker_estimator.update(obs)           # 说话人位姿
        for c in constraints:
            self._apply(c)                                     # 贝叶斯条件化
        return self

    def binding_posterior(self, mention):
        scores = {v.id: self._score(mention, v) for v in self.G.nodes}
        return normalize(scores)

    def entropy_ref(self, mention):
        p = self.binding_posterior(mention).values()
        return -sum(q * math.log(q + 1e-9) for q in p)


# APX：问 / 看 / 做
class ActiveProber:
    def select(self, B, budget, nu=0.1):
        cands = []
        for q in self.question_grammar.enumerate(B):           # 受限问句
            cands.append(('ask', q, self.ig(q, B) / self.cost(q)))
        for o in self.observation_actions(B):                  # 换视角/靠近
            cands.append(('obs', o, self.ig(o, B) / self.cost(o)))
        kind, action, score = max(cands, key=lambda z: z[2])
        if score > nu and B.entropy_ref() > self.tau_H:
            return kind, action
        return 'act', None


# GRC：指称证书
class GroundedReferenceCertificate:
    def check(self, B, K):
        ok_ref   = B.conf_ref >= 1 - self.delta_ref
        ok_pred  = B.predicate_truth() >= 1 - self.delta_pred
        ok_frame = kl_div(B.xi, B.xi_prior) <= self.tau_xi or B.frame_resolved
        ok_cons  = consistent(B, K)
        return ok_ref and ok_pred and ok_frame and ok_cons


# DRB：可废止修订
class DefeasibleRevisionBuffer:
    def commit(self, c, block, irreversible):
        self.K.append((c, block, irreversible))

    def revise(self, c, B):
        conflicts = [k for k in self.K if contradict(c, k[0])]
        if not conflicts:
            return B
        support = minimal_conflict_set(conflicts)
        for c_old, block, irr in support:
            if not irr:
                self.K.remove((c_old, block, irr))
                B = retract(B, c_old)                          # AGM 修订
        return B


# DWM：对话世界模型（在线轻量推理）
class DialogueWorldModel:
    def predict(self, B_t, a_t):
        z = self.enc(B_t)
        return {'delta_belief': self.dyn(z, a_t),
                'next_utterance': self.dialog_head(z, a_t)}


# D3C 闭环
def D3C_round(M, obs, utterance):
    # 1) 三维观测 + 说话人估计
    B = M.sgb.update([], obs)
    # 2) 话语 -> 约束 -> 联合信念
    C = M.dgu.parse(utterance, B.G, B.xi)
    B = M.sgb.update(C, obs)
    # 3) 修订（若与承诺缓冲矛盾）
    B = M.drb.revise(C, B)

    # 4) 证书不成立 -> 主动问/看
    while not M.grc.check(B, M.drb.K):
        kind, action = M.apx.select(B, budget=M.budget)
        if kind == 'ask':
            return {'need_answer': action}                     # 结束本轮，等用户回答
        elif kind == 'obs':
            obs = M.execute_observation(action)
            B = M.sgb.update([], obs)
        else:
            break                                              # 信息已尽，转安全回退

    # 5) 认证前缀
    A = M.vista.ach.propose(B.G, H=M.vista.H)
    k_ref = M.grc.certified_prefix(A, B, M.drb.K)
    k_star = min(M.vista.m, M.er.max_m_emotion, M.wm.k_wm,
                 k_ref)
    # 6) 执行 + 承诺
    block = A[:k_star]
    tau_cmd = M.vista.pi_sigma.prefix_dispatch(block)
    M.drb.commit(C, block, irreversible=M.is_irreversible(block))
    # 7) 异步：DWM 预测下一轮、写证书
    M.dwm.predict(B, block)
    M.cert.log(J_D3C(B, k_star))
    return {'executed': block, 'k_star': k_star}
```

## 3. 推导

**引理 13（持久绑定的抗漂移性）** 设单轮文本-几何绑定错误率为 `ε_txt`，track 重识别错误率为 `ε_id`。采用持久 track ID 时，跨 `T` 轮共指错误率 `≤ ε_id + ε_txt`，与 `T` 无关；若每轮独立重解析，则错误率为 `1 − (1−ε_txt)^T → 1`。故长对话下持久绑定把共指错误从「随轮数累积」降为「常数级」。

**引理 14（信息增益的自适应次模性）** 在给定潜场景图后各轮回答条件独立时，`IG` 对问句集合是自适应次模的。由 Golovin–Krause 定理，贪心策略达到最优期望熵下降的 `(1−1/e)` 近似。故 APX 的 `argmax IG/cost` 不是启发式，而是有近似保证的。

**引理 15（修订的可逆代价上界）** 每次修订最多回退到最近不可逆边界，回退块数 `≤ 自上次不可逆边界以来提交的块数`。若用户只做**单调细化**（不推翻已提交指称），则 `K_t` 单调增长、零回退。故「先执行可逆块、不可逆动作留到最后」可把修订代价压到 `O(1)`。

**定理 14（指称执行安全性）** 若 `GRC_t = True`，则执行错误指称的概率 `P(wrong ref) ≤ δ_ref + δ_pred + δ_ξ + δ_cons`；且 C-D3C 在任何 `GRC=False` 的步上执行概率为 0。证明：对四条证书条件做联合界，`k_ref` 的构造保证逐块检查。

**定理 15（对话终止性与信息效率）** 设单问最小信息增益 `IG_min > 0`、初始指称熵 `H_0`、阈值 `τ_H`。贪心提问在至多 `⌈(H_0−τ_H)/IG_min⌉` 轮内使 `H_ref < τ_H`（概率 ≥ 1−δ）；期望轮数不超过固定「每轮都问」策略的 `(H_0−τ_H)/(IG_min·cost)` 倍。故主动提问以可证的方式优于穷举澄清。

**定理 16（Sim2Real 对话迁移界）** 设 `TV(P_sim^dlg ‖ P_real^dlg) ≤ δ_dlg`。则 DWM 在线信念预测误差 `ε_B ≤ ε_B^sim + C·δ_dlg`，`C` 依赖 `dialog_head` 的 Lipschitz 常数。因此证书阈值须保守膨胀：`δ_ref^real = δ_ref + C·δ_dlg`，否则离线标定的证书在真实分布下会**过度自信**。

**定理 17（修订-证书相容性）** 若 `B_t` 满足 `GRC` 且新约束 `c` 不矛盾于 `K_t`，则 `B_t ∘ c` 仍满足 `GRC` 的前三条（指称/谓词/视角单调收紧）；第四条由 `consistent` 直接保证。即「一致修订不会破坏已认证的指称」，只有矛盾修订才触发回退。

## 6. 本轮最大风险

**一句话**：D3C 的全部安全性押在一个假设上——**人的语言约束可以被可靠地锚定到三维 track，且人给出的澄清是充分且诚实的**；一旦场景里存在大量对称/重复物体、说话人视角持续漂移、或用户刻意误导，指称后验就可能「高置信地错」，而 GRC 会把这种错误**认证为可执行**，使闭环以最高置信度执行错误指称——这比「不确定所以不动」危险得多。

**次级风险与缓解**：
1. **过度提问**：ν 过低会打扰用户，反而降低回答质量 → 用 `IG/cost` 阈值 + 每任务提问预算；
2. **证书过度自信**：离线标定的 `δ_ref` 在 Sim2Real 下失效 → 用定理 16 膨胀阈值，并保留集合承诺回退；
3. **修订风暴**：用户频繁改口导致不断回退 → 只允许可逆块先执行，不可逆动作放最后（引理 15）；
4. **多说话人混淆**：需声纹/视线/位姿联合消歧 → 归属不确定时强制 `frame/confirm` 追问；
5. **实时算力**：SGB + APX 在嵌入式平台吃紧 → DGU/APX 异步、量化 DWM、场景图增量更新。

## 2. 形式化定义（完整版）

**定义 266（D3C 总览）** D3C 是把 VISTA/RAS/SimRAS 的「物理-情绪-未来」闭环升级为「语言-几何」闭环：
```
D3C = (DGU, SGB, APX, GRC, C-D3C, DRB, DWM)
```
不变式：DGU/SGB/APX/证书构建只在语义流；实时流只做 track 更新、SGB 增量更新、GRC 布尔判定、C-D3C 前缀早停，零学习写操作。

**定义 267（类型化空间约束）** 第 t 轮话语 `u_t` 经 DGU 解析为
```
C_t = {c_i},  c_i = (type, M_i, φ_i, ξ_i, w_i)
```
其中 `type ∈ {REF, REL, ACT, REV, ANS}`，`M_i` 为提及集，`φ_i` 为可判定谓词（`left_of, near, on, behind, same_object…`），`ξ_i` 为谓词所用坐标系（speaker / robot / world），`w_i` 为置信权重。

**定义 268（三维场景图）** `G_t = (V_t, E_t, A_t)`。节点 `v = (id, o, T_v, S_v, F_v)`：持久 track ID、语义类别、世界系 6DoF 位姿、形状/占用、可供性；边 `E_t` 编码空间关系；`A_t` 为属性。`id` 跨轮持久，是共指的几何锚。

**定义 269（说话人坐标系与指示词落地）** 说话人位姿 `ξ_t ∈ SE(3)`，后验 `B_t^ξ`，不确定度 `Σ_ξ`。指示谓词在说话人系落地：
```
"X 在 Y 左边" ⇔ ⟨R_ξ e_left, p_X − p_Y⟩ > 0
```
当 `Σ_ξ` 大时，同一话语诱导谓词假设集 `{φ^ξ}` 而非单值。

**定义 270（语言-几何联合信念）**
```
B_t(G, ξ, u | D_{1:t}, O_{1:t}) ∝ P_0(G, ξ, u)
    · ∏_{i≤t} P(O_i | G, ξ) · P(C_i | G, ξ, u)
```
近似分解为 `B_t^G · B_t^ξ · B_t^u`，并保留 REF 与 ξ 的耦合项（指示词依赖视角）。

**定义 271（指称绑定 / 数据关联）** 绑定 `a: M → V`，联合得分
```
s(m, v) = α·sim_emb(m, v) + β·sim_spatial(m, v) + γ·(1 − H_track(v))
P(a(m)=v | B_t) ∝ s(m, v) · B_t^G(v)
```

**定义 272（指称歧义度）**
```
H_ref(t) = H(a | B_t),   conf_ref(t) = max_v P(a=v | B_t)
歧义 ⇔ H_ref > τ_H  或  conf_ref < 1 − δ_ref
```

**定义 273（认知动作空间）**
```
A_epi = A_ask ∪ A_obs ∪ A_act
A_ask = {yes/no(φ), which(φ, Cand), frame(term), confirm(v)}
```
受限问句文法保证答案空间有界、可直接转成约束；`A_obs` 为换视角/靠近/重扫；`A_act` 为执行动作块。

**定义 274（期望信息增益与成本）**
```
IG(a) = H(B_t) − E_{r∼P(r|a,B_t)}[H(B_{t+1}(r))]
cost(a) = c_turn + c_lat(a) + c_annoy(a)
```
`IG` 用场景图粒子近似，`c_annoy` 为打扰成本。

**定义 275（最优提问与停止）**
```
a* = argmax_{a∈A_epi} IG(a)/cost(a)
仅当 IG(a*)/cost(a*) > ν 且 H_ref > τ_H 时执行 a*，否则执行 A_act
```
`ν` 为信息价值阈值：`ν↑` 少问，`ν↓` 多问。

**定义 276（指称证书 GRC）**
```
GRC_t ⇔ (1) conf_ref ≥ 1 − δ_ref（或集合承诺 + 安全回退）
      ∧ (2) P(φ 为真 | B_t) ≥ 1 − δ_pred
      ∧ (3) KL(B_t^ξ ‖ B_t^{ξ,prior}) ≤ τ_ξ（或视角已由问句消解）
      ∧ (4) consistent(B_t, K_t)
```

**定义 277（C-D3C 认证前缀）**
```
k_ref = max{k : ∀s≤k, GRC_{t+s}}
k*    = min(k_VISTA, k_emo, k_wm, k_ref, m)
```

**定义 278（可废止修订与承诺缓冲）** 修订算子 `∘` 满足 AGM：
```
B_t ∘ c = argmin_{B'} d(B', B_t)  s.t.  B' ⊨ c
```
承诺缓冲 `K_t` 记录已执行但未越过不可逆边界的块；新约束若使某承诺后验跌破 `τ_retract`，回退到最近不可逆边界。

**定义 279（对话一致性）** 轮序列一致 ⇔ 不存在已提交提及被绑定到互不相容的 track；`contradict(c, K_t)` 返回最小冲突支撑集，供修订使用。

```
dialog_head(B_t, a_t) → P(ΔB_{t+1}), P(u_{t+1} | B_t, a_t)
```

```python
# IP-243 DGU：话语 -> 类型化约束
class DialogueGroundingUnit:
    def parse(self, utterance, G, xi):
        constraints = []
        for m in extract_mentions(utterance):
            cands = self.scene_graph.lookup(m.lemma, G)       # 候选 track
            frame = self.resolve_frame(m, xi)                  # speaker/robot/world
            pred  = self.predicate(m, frame)                   # left_of, near, ...
            constraints.append(Constraint('REF', {m}, pred, frame, 1.0))
        for rel in extract_relations(utterance):
            constraints.append(Constraint('REL', rel.mentions, rel.pred,
                                          self.resolve_frame(rel, xi), 1.0))
        return constraints

    def resolve_frame(self, item, xi):
        if item.explicit_frame:            # "你的左边"
            return item.explicit_frame
        return 'speaker' if xi.confidence > 0.8 else 'ambiguous'


# IP-244 SGB：语言-几何联合信念
class SceneGraphBelief:
    def update(self, constraints, obs):
        self.G  = self.tracker.update(self.G, obs)             # 3D 观测
        self.xi = self.speaker_estimator.update(obs)           # 说话人位姿
        for c in constraints:
            self._apply(c)                                     # 贝叶斯条件化
        return self

    def binding_posterior(self, mention):
        scores = {v.id: self._score(mention, v) for v in self.G.nodes}
        return normalize(scores)

    def entropy_ref(self, mention):
        p = self.binding_posterior(mention).values()
        return -sum(q * math.log(q + 1e-9) for q in p)

    def _score(self, m, v):
        return (self.alpha * sim_emb(m, v) +
                self.beta  * sim_spatial(m, v) +
                self.gamma * (1 - self.H_track[v.id]))


# IP-245 APX：问 / 看 / 做
class ActiveProber:
    def __init__(self, grammar, tau_H=0.3, nu=0.1):
        self.grammar, self.tau_H, self.nu = grammar, tau_H, nu

    def select(self, B, budget):
        cands = []
        for q in self.grammar.enumerate(B):                    # 受限问句
            cands.append(('ask', q, self.ig(q, B) / self.cost(q)))
        for o in self.observation_actions(B):                  # 换视角/靠近
            cands.append(('obs', o, self.ig(o, B) / self.cost(o)))
        kind, action, score = max(cands, key=lambda z: z[2])
        if score > self.nu and B.entropy_ref() > self.tau_H:
            return kind, action
        return 'act', None

    def ig(self, action, B):
        samples = B.sample_scene_graphs(n=64)
        h0 = entropy(samples)
        h1 = sum(B.answer_likelihood(action, s) *
                 entropy(B.condition(action, s).sample_scene_graphs(64))
                 for s in samples) / len(samples)
        return h0 - h1

    def cost(self, action):
        return self.c_turn + self.c_lat[action.kind] + self.c_annoy[action.kind]


# IP-246 GRC：指称证书
class GroundedReferenceCertificate:
    def __init__(self, delta_ref=0.05, delta_pred=0.05, tau_xi=0.2):
        self.delta_ref, self.delta_pred, self.tau_xi = delta_ref, delta_pred, tau_xi

    def check(self, B, K):
        ok_ref   = B.conf_ref >= 1 - self.delta_ref
        ok_pred  = B.predicate_truth() >= 1 - self.delta_pred
        ok_frame = (kl_div(B.xi, B.xi_prior) <= self.tau_xi
                    or B.frame_resolved)
        ok_cons  = consistent(B, K)
        return ok_ref and ok_pred and ok_frame and ok_cons

    def certified_prefix(self, A, B, K):
        k = 0
        for i, a in enumerate(A):
            B_i = B.rollout(a)                                 # 预测该步后信念
            if not self.check(B_i, K):
                break
            k = i + 1
        return k


# IP-248 DRB：可废止修订
class DefeasibleRevisionBuffer:
    def __init__(self, tau_retract=0.2):
        self.K, self.tau_retract = [], tau_retract

    def commit(self, c, block, irreversible):
        self.K.append((c, block, irreversible))

    def revise(self, c, B):
        conflicts = [k for k in self.K if contradict(c, k[0])]
        if not conflicts:
            return B
        support = minimal_conflict_set(conflicts)
        for c_old, block, irr in support:
            if not irr:
                self.K.remove((c_old, block, irr))
                B = retract(B, c_old)                          # AGM 修订
        return B

    B = M.sgb.update([], obs)

    # 2) 话语 -> 约束 -> 联合信念
    C = M.dgu.parse(utterance, B.G, B.xi)
    B = M.sgb.update(C, obs)

    # 3) 修订（若与承诺缓冲矛盾）
    B = M.drb.revise(C, B)

    # 4) 证书不成立 -> 主动问/看
    while not M.grc.check(B, M.drb.K):
        kind, action = M.apx.select(B, budget=M.budget)
        if kind == 'ask':
            return {'need_answer': action}                     # 结束本轮，等用户回答
        elif kind == 'obs':
            obs = M.execute_observation(action)
            B = M.sgb.update([], obs)
        else:
            break                                              # 信息已尽 -> 安全回退

    # 5) 认证前缀
    A = M.vista.ach.propose(B.G, H=M.vista.H)
    k_ref = M.grc.certified_prefix(A, B, M.drb.K)
    k_star = min(M.vista.m, M.er.max_m_emotion, M.wm.k_wm, k_ref)

    # 6) 执行 + 承诺
    block = A[:k_star]
    tau_cmd = M.vista.pi_sigma.prefix_dispatch(block)
    M.drb.commit(C, block, irreversible=M.is_irreversible(block))

    # 7) 异步：DWM 预测下一轮、写证书
    M.dwm.predict(B, block)
    M.cert.log(J_D3C(B, k_star))
    return {'executed': block, 'k_star': k_star}
```

## 4. 推导

**引理 13（持久绑定的抗漂移性）** 设单轮文本-几何绑定错误率为 `ε_txt`，track 重识别错误率为 `ε_id`。采用持久 track ID 时，跨 `T` 轮共指错误率 `≤ ε_id + ε_txt`，与 `T` 无关；若每轮独立重解析，则错误率为 `1 − (1−ε_txt)^T → 1`。故长对话下持久绑定把共指错误从「随轮数累积」降为「常数级」。

**引理 14（信息增益的自适应次模性）** 给定潜场景图后各轮回答条件独立时，`IG` 对问句集合是自适应次模的。由 Golovin–Krause 定理，贪心策略达到最优期望熵下降的 `(1−1/e)` 近似。故 APX 的 `argmax IG/cost` 有近似保证。

**引理 15（修订的可逆代价上界）** 每次修订最多回退到最近不可逆边界，回退块数 `≤ 自上次不可逆边界以来提交的块数`。若用户只做单调细化，则 `K_t` 单调增长、零回退。故「可逆块先执行、不可逆动作留最后」可把修订代价压到 `O(1)`。

**定理 14（指称执行安全性）** 若 `GRC_t = True`，则执行错误指称的概率
```
P(wrong ref) ≤ δ_ref + δ_pred + δ_ξ + δ_cons
```
且 C-D3C 在任何 `GRC=False` 的步上执行概率为 0。证明：对四条证书条件做联合界；`k_ref` 的构造保证逐块检查。

**定理 15（对话终止性与信息效率）** 设单问最小信息增益 `IG_min > 0`、初始指称熵 `H_0`、阈值 `τ_H`。贪心提问在至多 `⌈(H_0−τ_H)/IG_min⌉` 轮内使 `H_ref < τ_H`（概率 ≥ 1−δ）；期望轮数不超过固定「每轮都问」策略的 `(H_0−τ_H)/(IG_min·cost)` 倍。

**定理 16（Sim2Real 对话迁移界）** 设 `TV(P_sim^dlg ‖ P_real^dlg) ≤ δ_dlg`。则 DWM 在线信念预测误差
```
ε_B ≤ ε_B^sim + C·δ_dlg
```
`C` 依赖 `dialog_head` 的 Lipschitz 常数。故证书阈值须保守膨胀：`δ_ref^real = δ_ref + C·δ_dlg`，否则离线标定的证书在真实分布下会过度自信。

**定理 17（修订-证书相容性）** 若 `B_t` 满足 `GRC` 且新约束 `c` 不矛盾于 `K_t`，则 `B_t ∘ c` 仍满足 `GRC` 的前三条（指称/谓词/视角单调收紧）；第四条由 `consistent` 直接保证。即一致修订不破坏已认证指称，只有矛盾修订才触发回退。

## 7. 本轮最大风险

**一句话**：D3C 的全部安全性押在一个假设上——**人的语言约束可以被可靠地锚定到三维 track，且人给出的澄清是充分且诚实的**；一旦场景里存在大量对称/重复物体、说话人视角持续漂移、或用户刻意误导，指称后验就可能「高置信地错」，而 GRC 会把这种错误**认证为可执行**，使闭环以最高置信度执行错误指称——这比「不确定所以不动」危险得多。
