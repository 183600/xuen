# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「创新点」×「主动交互」）

> 第 57 轮把安全的赌注从"模型置信"换到"证据质量"，再用元少样本、跨模态对账、个性化信任把证据质量做成可校准、可对账、可演化；但它的风险自陈留下三个更隐蔽的经济学空白：**(a)** 人的注意力被当作免费且即取即用的资源——系统只在自身算到"该问"时才问，从不为"此刻问是否值得""这个人此刻能否被打扰""早一点问会不会更好"付费，而 L2 同意通道的本金恰恰是信任；**(b)** 系统从不度量"创新"——它无法区分一条新观测是真正的新事实，还是同一已知事实的第五次重复（第 57 轮自己已指出"同一模态重复五遍只是把同一个错误问五遍"），于是"创新点清单"只能靠人肉书写，而非由系统自证；**(c)** 主动行为缺少预算与地板——更主动可能意味着更多打扰、更快耗尽信任，而信任恰是 L2 同意通道的本金。本轮两个灵感各补一刀：**主动交互**把"问"从反应式升级为**注意力经济下的主动决策**（探、报、释三种模式 + 安全地板），**创新点**把"新颖"变成**可签发、可证伪、反冗余的新颖性证书**；二者合流为"会算注意力账、能自证创新"的主动交互。核心命题由"证据说可信"升级为 **"值得打扰、且能证明学到了新东西的证据说可信"**。

核心矛盾：
- **H29（主动 vs 注意力）**：主动交互只有在"更早/更省/更被理解"时才有价值，但每次打扰都消耗有限、共享、恢复缓慢的注意力与信任；问得太早是噪音，问得太勤是狼来了——过度主动会侵蚀它最需要的 L2 同意通道，于是"更主动"可经信任折旧反转为"更不安全"。
- **H30（创新 vs 冗余/噪声）**：没有新颖性度量，系统分不清"新事实"与"重复观测"；奖励新颖又会 Goodhart——系统可能追逐"意外但错误"的观测。创新必须同时满足非冗余、可归因、事后证实，否则只是假设或噪声。
- **H31（假设空间 vs 未知未知）**：主动问题只能从假设集中挑；不在假设集里的现象永远问不到。主动若不配开放世界预留与惊喜审计，只会把盲区问得更精致。

## 0. 直觉与动机

**灵感 1（创新点 → 新颖性证书与双钥验证）**
直觉：科研里"创新点"的最低标准是"相对已有工作不冗余 ∧ 可归因 ∧ 可复现"。给机器人同一把尺子：一条观测的新颖度，等于"用新地图预测它比旧地图好多少"（压缩增益/MDL），重复已知事实的新颖度≈0，所以再问一遍赚不到创新分——主动交互天然反冗余。但新颖≠创新：只有被事后实测或独立通道证实（第一把钥匙）且相对基线先验仍有增益（第二把钥匙）的观测才签发证书，未证实的新颖只进"假设池"；复测即消失的新颖记为噪声并联动降权其来源。创新点 = 一组非冗余、已验证、可归因的证书簇。

**灵感 2（主动交互 → 注意力经济账本）**
直觉：人的注意力像一块电池：每个操作者有一块可耗尽的预算，打扰要花电，误报会让电池容量永久缩水一点（信任侵蚀）。主动交互不是"能问就问"，而是"值不值得打扰"：净价值 = 信息价值 + 安全增益 − 打扰成本 − 探针成本 − 信任折旧；预算越低、可打扰度越低，开口门槛越高。关键护栏是**安全地板**：L2 同意与"不问就会击穿 δ_f"的交互不受预算约束、必发——省电永远不能省出事故。

**灵感 3（主动交互 → 预期式简报/预同意）**
直觉：最好的主动交互不是临场问"可以吗"，而是在低压力窗口把即将到来的决定预先讲清楚：走这条路 30 秒后可能要在冰坡做 L2 决策，有三种选择、各自代价与默认。等到真正的 L2 时刻，人已理解，只需点头/否决——τ_int 更短、决策质量更高、压力更低。但**简报不是同意**：它不改变任何授权状态、可撤回、会过期，现场仍须确认。它只是把"理解"这部分成本提前摊销到人空闲的时候。

**灵感 4（问题组合 → 决策相关信息增益 + 开放世界预留）**
直觉：主动提问不该按"好奇心"排序，而该按"能改变哪个决定、降低多少风险"排序；同时必须留一小块预算给不属于任何现有假设的问题（开放世界预留），并定期做"惊喜审计"（请人指出地图哪里最可能错）。否则主动只是把已有的盲区问得更精致——假设集之外的现象永远问不到。

**灵感 5（合流 → PCE++：探-诺-演-问；问只改时机与对象，不改判据）**
直觉：主动通道绝不绕过证据门：人的回答进入系统时仍按 EV-human 带误差模型与佐证要求入账，预简报不产生任何证据类；主动只改变证据获取的时间、对象与表达，不改变承诺的判据。于是"更主动"可以更早、更省、更被理解，但不能更敢赌。证书 J_q 记录每次主动交互的净价值、是否被证实、是否冗余、注意力账本与安全地板触发——让"我们创新在哪"变成可审计的日志。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（注意力经济账本 AEL）** 操作者 o 在时刻 t 的注意力状态 a_o(t)=(b_o,κ_o,h_o^fa,R_o)：b_o∈[0,B_max] 可耗尽预算（按休息/冷却速率 r 恢复），κ_o∈(0,1] 可打扰度（由行走/搬运/会议等上下文估计），h_o^fa∈[0,1] 历史误报率，R_o 安全储备标记。打扰成本 C_int(o,t)=c_0/κ_o(t)+λ_fa·h_o^fa(t)+λ_s·1[会话压力>τ_s]。预算动态 b_o(t+1)=min(B_max,b_o(t)−spend+recover(Δt))；安全交互只记 R_o、不扣 b_o（安全地板）。h_o^fa 由"主动交互后被证伪/被判无价值"的比率更新，形成信任折旧。

**定义 140（主动交互决策 PAI）** 候选交互 q（探针/提问/简报/警告）在时刻 t 对操作者 o 的净价值 NV(q,t,o)=VOI_元悲观(q)+ΔR_safety(q)−C_int(o,t)−c_probe(q)−λ_trust·Δh^fa(q)。分级：q 为**强制**（mandatory）当且仅当属 L2 同意、或不做会使 P_fail>δ_f；强制交互无视 b_o 必发并记安全地板日志。否则为**自由裁量**（discretionary）：发 ⇔ NV(q,t,o)≥θ_speak(b_o,κ_o)，θ_speak 随 b_o↓、κ_o↓、h^fa↑ 单调上升。自由裁量按 NV/C_int（每单位注意力净价值）降序，每会话打扰数 ≤N_max(b_o)。

**定义 141（预期式简报 PAB）** 对窗口 W 内可能触发的 L2 决策 c 生成简报 Exp_c（内容五元组沿用 MXI，明确不含同意语义），在低压力窗口 t_b（κ_o(t_b)≥κ_brief 且 NV>θ_brief）投递；理解增益 U_gain 由事后同意正确率与 τ_int 度量，记入 preconsent_log。硬约束：简报≠同意（不解除任何 L2）、可撤回、过期失效（T_brief）、被"预授权"的决策仍须现场确认。

**定义 142（新颖性证书 NC）** 对观测/断言 c，旧地图 𝓜_old、新地图 𝓜_new、基线先验 𝓜_0：新颖增益 G_nov(c)=[log p_{𝓜_old}(o_c)−log p_{𝓜_new}(o_c)]_+−DL(c)；相对先验的创新增益 G_inn(c)=[log p_{𝓜_0}(o_c)−log p_{𝓜_new}(o_c)]_+−DL(c)。冗余判定：G_nov(c)≤θ_red 或 c 可由 𝓜_old 在 ε_red 内推出 ⇒ redundant，不产生创新点、其主动交互也不获新颖加分。**双钥验证**：仅当 (i) 事后实测或独立通道证实 validated 且 (ii) G_inn≥θ_nov 时签发 N_c=(c_id,G_inn,validated,attribution,seed,t)。未证实者入假设池；复测消失者记 spurious 并联动降低来源可靠性 ρ。创新点 = 非冗余、已验证、可归因证书的簇。

**定义 143（问题组合 QP）** 竞争假设集 ℋ={h_1,…,h_n,h_⊥}；候选问题 q 对决策分区 π∈{承诺,绕行,降档,L2} 的期望信息增益 IG(q)=H(π|𝓜)−E_a[H(π|𝓜,a)]，决策相关价值 V_dec(q)=IG(q)·E[后果严重度|π]。组合按 V_dec/C_int 排序；**开放世界预留** ε_ow·b_o 仅用于 h_⊥ 类探索问题与惊喜审计，不得被利用型问题挪用；OOD 残差与惊喜审计触发 ℋ 增广（新假设进入下一轮组合）。

**定义 144（主动-新颖证书 J_q 与 PCE++ 算子）** PCE++ 在每个检查点给 PCE+ 加"问"分支：①元推断/跨模态对账（继承 133/134）；②问：存在强制交互则必发，否则在问题组合中按 NV/C_int 选自由裁量交互，受 AEL 预算与 N_max 约束；③若窗口 W 内有 L2 且处低压力窗口，则调度 PAB；④**证据代入**：任何人类回答/简报反馈按 EV-human 误差模型入账，不得直接充当 EV-probe/EV-xmodal，承诺仍须过 FSE；⑤**新颖记账**：每次交互后计算 G_nov，冗余则审计标记，证实且增益足够则签发 N_c。J_q=(attention_log, ask_log, preconsent_log, novelty_log, safety_floor_log, J_p)，继承 J_p 全检；安全地板日志须证明"没有任何强制交互因预算被抑制"。

## 2. 关键算法伪代码（完整版见产物区）

```python
def proactive_interaction(q, o, t, M, A):            # IP-139/140
    if is_L2(q) or skip_fail_prob(q, M) > delta_f:   # 安全地板
        A.safety_floor.log(q, o, t); return execute(q), A
    nv = voi_meta_pessimistic(q, M) + delta_R_safety(q) \
         - interrupt_cost(o, t) - probe_cost(q) - trust_dep(q)
    if A.b[o] <= 0 or nv < theta_speak(A.b[o], A.kappa[o]):
        return silence(q), A                         # 不打扰也是一种动作
    A.spend(o, interrupt_cost(o, t)); return execute(q), A

def novelty_certificate(c, M_old, M_new, M0, verdict, audit):   # IP-142
    g = max(0, logp(M_old, c.obs) - logp(M_new, c.obs)) - dl(c)
    if g <= theta_red or derivable(M_old, c, eps=eps_red):
        audit.mark_redundant(c); return None         # 重复不出创新点
    if not verdict.validated and not independent_confirm(c):
        audit.hypothesis_pool.add(c); return None    # 未证实只是假设
    g0 = max(0, logp(M0, c.obs) - logp(M_new, c.obs)) - dl(c)
    return Cert(c.id, g0, validated=True, seed=c.seed, t=now) if g0 >= theta_nov else None
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| AEL | O(1)/更新 | O(\|O\|) | 预算/打扰度估计误差 ≤ε_attn、信任折旧单调 |
| PAI | O(\|Q\|)/检查点 | O(\|Q\|) | 安全地板完备、自由裁量受预算硬约束 |
| PAB | O(\|W\|)/窗口 | O(\|Exp\|) | 简报≠同意、过期失效、可撤回 |
| NC | O(d_φ+\|𝓜\|)/断言 | O(\|C\|) | 双钥验证、冗余/噪声不签发 |
| QP | O(\|ℋ\|·\|Q\|)/组合 | O(\|ℋ\|+\|Q\|) | 决策相关排序、预留不可挪用 |
| PCE++ | O(\|CP\|·(\|Q\|log\|Q\|+k_p+k_c)) | O(\|V\|+\|σ\|+\|Q\|) | 问不改判据、k_p+k_c+k_ask 终止 |

**正确性定理（PANS，Proactive Attention-Novelty Soundness 概要）**：在 A33–A40 上新增 (A41) AEL 诚实：b_o/κ_o/h^fa 的估计误差 ≤ε_attn；(A42) 安全地板：强制交互永不被预算抑制、日志完备；(A43) 证书健全：签发者已验证且非冗余，DL 诚实，验证假发现率 ≤α_nov；(A44) 主动通道不越权：人类/简报输入只经 EV-human 误差模型入账，不得顶替 EV-probe/EV-xmodal，承诺仍须过 FSE。则：(i) **安全不退化**：主动只改变证据获取的时机/对象/表达，强制交互必发，故 P_fail(PCE++) ≤ P_fail(PCE+) + ε_attn；下降来自"更早拿到证据"，不存在升险路径；(ii) **注意力有界**：每会话自由裁量打扰 ≤N_max，误报率 ≤θ_fa，信任折旧受控；(iii) **创新健全**：每个创新点满足 G_inn≥θ_nov、冗余 ≤θ_red、FDR ≤α_nov，重复观测不产生创新点；(iv) **终止性**：问题组合有限且每会话去重，预算单调下降，PCE++ 在 k_probes+k_cons+k_ask 内终止于 {承诺,绕行,L2 协商,安全停}。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 可打扰度/预算估错 → 该问不问或过度打扰 | 高 | κ 保守估计 + 不确定时默认强制分类 + 回退"仅安全交互" |
| 安全地板被绕过（自由裁量误分类为强制或反之） | 高 | 形式化分级 + 不确定即判强制 + safety_floor_log 独立审计 |
| 新颖性被 Goodhart（追新逐怪） | 高 | 双钥验证 + FDR 控制 + spurious 联动降 ρ + 只认事后证实 |
| 假设空间隧道视野 | 中高 | 开放世界预留（不可挪用）+ 惊喜审计 + OOD 触发假设增广 |
| 预简报被误当同意 | 中 | 无状态变更 + 显式语义 + 过期 + 现场重申 + UI 误读率监控 |

## 6. 本轮最大风险

**一句话**：本轮把主动交互变成"注意力经济下的值得打扰"决策，最大风险从"坏先验普遍"变成**"沉默的乐观"**——当预算耗尽、且新颖性又被当作值得开口的门槛时，系统会为了省注意力和刷新颖度而抑制本该问的安全性问题（或把预简报误当已同意）；必须以不可被预算抑制的安全地板、新颖性双钥验证（事后证实才算）与"简报≠同意"的硬语义三重护栏，保证"不打扰"永远不能退化成"不安全"。

# 第 58 轮产物 · 创新点清单 v34：Proactive-Attention-Novelty（主动注意力经济×预期式简报×新颖性证书，AEL×PAI×PAB×NC×QP×PCE++）

## 2. 关键算法伪代码

### IP-139 AEL（注意力经济账本）

```python
def attention_step(A, o, t, dt, outcome=None):
    a = A.state[o]
    a.b = min(A.B_MAX, a.b + A.recover(dt))           # 休息/冷却恢复
    if outcome is not None:                            # 上次主动交互的后果
        if outcome.falsified or outcome.judged_useless:
            a.h_fa = min(1.0, a.h_fa + eta_fa)         # 信任折旧
        elif outcome.valuable:
            a.h_fa = max(0.0, a.h_fa - eta_fa)         # 缓慢修复
    a.kappa = clamp(A.context_interruptibility(o, t), eps, 1.0)
    A.state[o] = a
    return A

def interrupt_cost(A, o, t):
    a = A.state[o]
    return A.c0 / a.kappa + A.lam_fa * a.h_fa + A.lam_s * int(A.pressure[o] > A.tau_s)
```

### IP-140 PAI（主动交互决策：安全地板 + speak/silent）

```python
def proactive_interaction(q, o, t, M, A):
    mandatory = is_L2(q) or (skip_fail_prob(q, M) > delta_f)
    if mandatory:                                      # 安全地板：无视预算
        A.safety_floor_log.append((q.id, o, t))
        return execute(q), A                           # 必发
    nv = (voi_meta_pessimistic(q, M) + delta_R_safety(q)
          - interrupt_cost(A, o, t) - probe_cost(q) - A.lam_trust * dl_trust(q))
    if A.state[o].b <= 0 or nv < theta_speak(A.state[o].b, A.state[o].kappa):
        A.ask_log.append(('silent', q.id, o, t, nv))
        return silence(q), A                           # 不打扰也是动作
    if A.discretionary_count[o][session()] >= A.N_max(A.state[o].b):
        return silence(q), A                           # 打扰配额
    A.spend(o, interrupt_cost(A, o, t))
    A.ask_log.append(('ask', q.id, o, t, nv))
    return execute(q), A
```

### IP-142 NC（新颖性证书：双钥验证 + 反冗余 + 反噪声）

```python
def novelty_certificate(c, M_old, M_new, M0, verdict, audit):
    g = max(0.0, logp(M_old, c.obs) - logp(M_new, c.obs)) - dl(c)
    if g <= theta_red or derivable(M_old, c, eps=eps_red):
        audit.mark_redundant(c)                         # 重复观测不产生创新点
        return None, audit
    if not verdict.validated and not independent_confirm(c):
        audit.hypothesis_pool.add(c)                    # 第一把钥匙：证实
        return None, audit
    g0 = max(0.0, logp(M0, c.obs) - logp(M_new, c.obs)) - dl(c)
    if g0 < theta_nov:                                  # 第二把钥匙：相对先验有增益
        return None, audit
    cert = Cert(c.id, g0, validated=True, attribution=c.mechanism,
                seed=c.seed, t=now)
    audit.certs.append(cert)
    return cert, audit

def on_retest_spurious(c, audit, M):

    rho_down(M, c.source_modality, gamma_down)          # 联动第 57 轮 R3
```

### IP-143 QP（问题组合：决策相关 + 开放世界预留）

```python
def question_portfolio(M, H, o, t, A):
    cands = decision_relevant_questions(H, M)           # 每个 q 只针对决策分区 π
    exploit = []
    explore = []
    for q in cands:
        score = V_dec(q, M) / (interrupt_cost(A, o, t) + probe_cost(q) + EPS)
        (explore if is_open_world(q) else exploit).append((score, q))
    exploit.sort(reverse=True); explore.sort(reverse=True)
    reserve = A.state[o].b * A.epsilon_ow              # 开放世界预算不可挪用
    return exploit, explore, reserve

def surprise_audit(M, o, t, A):                         # 定期请人指出地图最可能错处
    q = make_question("此处地图最可能哪里错？", target=argmax_epistemic_uncertainty(M))
```

```python
def probe_commit_evolve_plus_plus(x0, M, task, budget, consent, personas, A):
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| AEL | O(1)/更新 | O(\|O\|) | 预算/打扰度误差 ≤ε_attn、信任折旧单调（A41） |
| PAI | O(\|Q\|)/检查点 | O(\|Q\|) | 安全地板完备、自由裁量受预算与 N_max 硬约束（A42） |
| PAB | O(\|W\|)/窗口 | O(\|Exp\|) | 简报≠同意、过期失效、可撤回（A42/A44） |
| NC | O(d_φ+\|𝓜\|)/断言 | O(\|C\|) | 双钥验证、冗余/噪声不签发、FDR ≤α_nov（A43） |
| QP | O(\|ℋ\|·\|Q\|)/组合 | O(\|ℋ\|+\|Q\|) | 决策相关排序、开放世界预留不可挪用 |
| PCE++ | O(\|CP\|·(\|Q\|log\|Q\|+k_p+k_c)) | O(\|V\|+\|σ\|+\|Q\|) | 问不改判据、k_p+k_c+k_ask 终止（A44） |

**正确性定理（Proactive Attention-Novelty Soundness, PANS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** AEL 诚实：b_o/κ_o/h^fa 估计误差 ≤ε_attn，恢复与折旧单调；**(A42)** 安全地板：强制交互永不因预算被抑制，safety_floor_log 完备；**(A43)** 证书健全：签发者已验证且非冗余，DL 诚实，验证假发现率 ≤α_nov；**(A44)** 主动不越权：人类/简报输入仅经 EV-human 误差模型入账，不得顶替 EV-probe/EV-xmodal，承诺仍须过 FSE；预简报不改变任何授权状态。则：

1. **安全不退化**：主动交互只改变证据获取的时机/对象/表达，决策判据与证据门不变；强制交互必发，故
   `P_fail(PCE++) ≤ P_fail(PCE+) + ε_attn`，且其中下降项来自"更早拿到同质量证据"；不存在升险路径。
2. **注意力有界**：每会话自由裁量打扰 ≤N_max(b_o)，误报率 ≤θ_fa（高概率），累计信任折旧受控；安全地板不计入预算，故"省注意力"不能抑制安全交互。
3. **创新健全**：每个创新点满足 G_inn≥θ_nov、冗余 ≤θ_red、FDR ≤α_nov；同一事实的重复观测 G_nov≈0 不产生创新点，复测消失者记 spurious 并降权来源。
4. **终止性**：问题组合有限且每会话去重，预算单调下降，PCE++ 在 k_probes+k_cons+k_ask 内终止于 {承诺, 绕行, L2 协商, 安全停}。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])
             − ε_attn − P(误报耗尽信任 ∧ L2 仍被强制触发) − P(预简报被误读为同意)
```

关键：**主动只改"何时/问谁/怎么问"，不改"能不能赌"**（安全地板 + 证据门不变）；**注意力是资源不是借口**（预算有账、地板免单）；**创新=已验证的新颖性**（双钥验证把"重复"与"噪声"挡在创新点之外）。三个新机制全部经"更早的证据 / 更被理解的同意 / 更可审计的新知"三条通道起作用，仍不产生升险路径。

## 6. 本轮最大风险

**一句话**：本轮把主动交互变成"注意力经济下的值得打扰"决策，最大风险从"坏先验普遍"变为**"沉默的乐观"**——当预算耗尽、且新颖性又被当作值得开口的门槛时，系统会为了省注意力、刷新颖度而抑制本该问的安全性问题（或把预简报误当已同意）；必须以不可被预算抑制的安全地板、新颖性双钥验证（事后证实才算）与"简报≠同意"的硬语义三重护栏，保证"不打扰"永远不能退化成"不安全"。
