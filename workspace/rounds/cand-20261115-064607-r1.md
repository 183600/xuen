# 第 4 轮（研究线累计；灵感循环第 1 轮；本轮灵感：「视觉语言动作模型」×「世界模型」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。VLA 与世界模型各沿一条轴升级 InstructGauge，且任一环节不可用都必须能一键退回；二者都是增强项，不是依赖项。

## 0. 直觉与动机

**灵感 1（VLA → 把「端到端策略」降级为「可供性提议分布」）**
直觉：VLA 最诱人的地方是「看到即会做」，但在带证书的计量系统里，最危险的使用方式恰恰是把它当执行器。VLA 真正稀缺的能力是**跨物体、跨任务的操纵先验**：它能在没见过的场景里提出「抓这里、推那里、从那个视角看」的候选，而不是给出可认证的物理量。因此正确接口不是 `VLA→动作`，而是 `VLA→带支持集的候选集`：候选必须依次通过能力闭包、具身适配器与安全盾三重过滤，才允许进入规划；VLA 不能写状态、不能定阈值、不能充当证据。直觉上，VLA 是「见多识广的实习生」，负责提想法；签发证书的必须是独立回执。

**灵感 2（世界模型 → 把「预测未来」降级为「有认证视界的反事实实验选择器」）**
直觉：世界模型的价值不在于替代现实，而在于**在花掉真实探测预算之前，先在想象里做实验**：哪个探针信息量最大、哪个动作会撞、哪条假设最值得证伪。但想象会复合误差、会被规划器「奖励黑客」、会与真实观测脱节。故世界模型只能用于**排序与选实验**，不能用于**认证状态**；其可信范围必须由「认证想象视界」`H_cert` 显式给出，并随预测-实测差距动态收缩。直觉上，世界模型是「沙盘」，不是「法庭」。

**灵感 3（两者耦合 → 最危险的是「自洽的幻觉」，不是各自出错）**
直觉：VLA 提议 X，世界模型 rollout 后说「X 会成功」，二者一致——但若它们共享视觉编码器、预训练数据与归纳偏置，这种一致只是**同一个错误被数了两遍**。更糟的是：规划器会主动挑选「在想象中信息量最大」的探针，于是想象越乐观，越可能选到物理上无信息、甚至破坏性的动作。解法不是禁用任一组件，而是三根结构支柱：**角色分离**（提议 / 想象 / 裁决三权分立）、**认证视界**（想象只在被实测校准过的时域内参与排序）、**共模证据折扣**（VLA 与 WM 的一致不作独立证据，必要时强制第三路物理回执），再叠加**想象写屏障**（想象态永不写回观测态）与**模型版本化证书**（换模型即失效旧证书）。

## 1. 研究问题（本轮要回答什么）

- **Q1（VLA 的安全性）**：能否把 VLA 限制为「只提议、不裁决」的候选生成器，使提示注入、越界动作与具身不匹配都无法穿透到执行器？
- **Q2（WM 的可证伪性）**：世界模型的想象在什么时域内、以什么置信水平可信？如何把「预测-实测差距」变成在线可测、可触发的断路器，而不是离线指标？
- **Q3（耦合的共模失效）**：当 VLA 与 WM 共享编码器/数据时，「二者一致」何时不是证据？怎样用共模折扣、独立回执与分歧驱动探测，把自洽幻觉压回可界风险？

## 2. 三条设计原则（雏形，正式化见产物区定义 448–463）

**P1 角色分离与非干涉（Propose–Imagine–Adjudicate）**
VLA 只产生候选，WM 只对候选做反事实 rollout，二者都不能写入观测状态、校准阈值或安全谓词。证据只能来自真实回执。形式化方向：给数据打 `Obs / Hyp / Claim` 三类标签，禁止任何 `Hyp→Obs`、`Hyp→q_s`、`Hyp→safety` 的信息流；想象态带 TTL，过期即不可读。这给出「想象不会自我确认」的类型级保证。

**P2 认证想象视界（Certified Imagination Horizon）**
想象只在 `H_cert(ε,α)` 步内参与排序，`H_cert` 由真实 rollout 的 h 步预测误差分位数在线校准；一旦预测-实测差距越界，`H_cert` 折半、重新锚定，直至关闭 WM。分块长度被 `K ≤ min(K_MAX(ι), H_cert)` 夹住——**想象能看多远，块才敢走多远**。

**P3 共模独立见证（Common-Mode Independent Witness）**
VLA 与 WM 的一致只在二者误差不相关时才算两条证据。用共享校准集估计共模相关 `ρ_CM` 与有效证据数 `n_eff = n/(1+(n−1)ρ_CM)`；当 `n_eff` 不足且涉及安全攸关主张时，强制引入不同物理原理的第三路回执。共模底噪 `ρ_0` 以下，增加同源模型无济于事。

## 3. 与基线的接口（如何退化）

- VLA 支持集为空 / 具身残差超界 / 适配器不可用 ⇒ 退回 ToolGauge 解析提议集（等价于 InstructGauge 默认 `ι₀`）；
- WM 不可用 / `H_cert < 1` / IRG 报警 / 算力不足 ⇒ 关闭想象，`K` 退回 `K_MAX(ι)`，CVC 仍用解析漂移界；
- 共模折扣后 `n_eff < n_min` 且无独立回执 ⇒ 拒绝安全攸关主张，降级为单源 + 更保守阈值，或直接退回 ToolGauge；
- 模型版本与证书不匹配 ⇒ 禁止执行并重规划；
- InstructGauge 失效 ⇒ ToolGauge；ToolGauge 失效 ⇒ LeanGauge；LeanGauge 失效 ⇒ MODGAUGE 原样。VLA 与 WM 都是增强项，不是依赖项（引理 59/61/63/65）。

## 4. 预期贡献

1. 一个「VLA 只提议、WM 只想象、回执才裁决」的三权分立口径，把两模型的注入面压到可类型检查的范围内；
2. 两个可证伪的定量工具：**认证想象视界**（把 WM 从信念降级为有时域保证的实验选择器）与**共模证据折扣**（把「模型一致」从证据降级为假设）；
3. **想象写屏障**与**模型版本化证书**，阻断「想象→状态→更乐观的想象」的自确认回路，并防止「A 模型出证、B 模型执行」；
4. 一条完整可证伪路径：E457–E472 覆盖提议安全、视界覆盖、共模陷阱、分歧探索、写屏障、版本热替换与 50Hz 时序保全。

## 5. 本轮最大风险

**一句话**：VLA 与世界模型共享编码器、数据与归纳偏置时，二者「一致」可能只是同一个错误被计数两次；系统若把这种共模幻觉误当独立证据，就会在认证视界内做出自信且难以撤回的探测决策。

## 2. 形式化定义（要点）

**定义 448（VLA 提议 oracle 与支持集）** `π_V(·|o,ℓ;θ_V)` 为 `A_V` 上的提议分布；`Supp_τ = {a : p_{π_V}(a|o,ℓ) ≥ τ}`（或 top-m）。提议证书 `PropCert = (hash(θ_V), hash(o), hash(ι), {(a_i, score_i)}, mass(Supp_τ))`。可采纳提议 `A_prop = Supp_τ ∩ A_adm(ι) ∩ E_emb^{-1}(M_phys)`；若 `A_prop = ∅` 输出 ⊥。关键性质：`A_prop ⊆ A_adm`——VLA 只能**选子集**，不能扩可行域。

**定义 449（具身适配器与残差包线）** `E_emb: A_V → A_R` 完成归一化、尺度映射与 IK 可行性检查；要求 `‖E_emb(a) − a*‖ ≤ r_emb` 且 `mag(E_emb(a)) ⊆ M_phys`。任一 IK 不可行、关节/力矩饱和或残差超界 ⇒ 拒绝该提议。`r_emb` 按具身标定，跨具身时按 `Def 446` 触发重新校准。

**定义 450（世界模型与想象态）** `f_W: Z × A × Z_ε → Z`，解码 `D: Z → S`；rollout 产生 `ŝ_{t+h} = D(z_{t+h})` 与 `Σ_{t+h}`。每个想象态携带 provenance `prov = (h_W, hash(o_anchor), t_anchor, h)` 与 TTL `τ_W`。**类型约束**：`ŝ ∈ S_hyp`，`S_hyp ∩ S_obs = ∅`；想象态不是观测态，不得参与计量数值路径。

**定义 451（认证想象视界）** 给定误差容差 `ε` 与水平 `α`，
`H_cert(ε,α) = max { h : q^{(h)}_{1−α} ≤ ε }`，
其中 `q^{(h)}_{1−α}` 为真实 rollout 上 h 步预测误差 `‖ŝ_t(h) − s_{t+h}‖` 的经验 `1−α` 分位。若误差满足仿射递推 `e_{h+1} ≤ L e_h + b`，则 `e_h ≤ L^h ε_0 + b(L^h−1)/(L−1)`，闭式解为 `H_cert^{aff} = max{h : L^h(ε_0 + b/(L−1)) − b/(L−1) ≤ ε}`（`L>1`；`L=1` 时 `H_cert = ⌊(ε−ε_0)/b⌋`）。分布漂移下用自适应共形（ACI）在线修正，`H_cert` 对 `ε, α, b` 单调不增。

**定义 452（IRG 想象-实测差距监控）** 当真实观测到达时计算 `gap_t(h) = ‖ŝ_t(h) − s_{t+h}‖`，维护触发比例 `Q_t = (1−γ)Q_{t−1} + γ·1[gap_t > η_W]`。若 `Q_t > q_W` 或观测分位超过校准分位 `γ_W` 倍，则执行：`H_cert ← ⌊H_cert/2⌋`，用最新观测重锚定 `z_t`，丢弃全部未消费想象；若 `H_cert < 1` 则关闭 WM。该断路器与 ToolGauge P-Quarantine 共用告警通道。

**定义 453（共模相关与有效证据）** 在共享校准集上计算归一化误差的相关系数 `ρ_CM = corr(e_V, e_W)`；有效独立见证数 `n_eff = n / (1 + (n−1)ρ_CM)`（Kish 设计效应）。安全攸关主张要求 `n_eff ≥ n_min`，否则必须引入不同物理原理的独立回执 `r_ind`。**共模底噪**：若共同失效概率 `ρ_0 ≥ δ`，则增加同族源无法把 `P(all fail)` 降到 `ρ_0` 以下，只有换通道有效。

**定义 454（虚拟探针资格）** 候选 `ξ = (a_{1:h}, checkpoint set)`；想象信息增益 `Î(ξ)` 由 WM 后验给出，真实代价 `c(ξ)`。`Qual(ξ)` 当且仅当 `h ≤ H_cert`、`ξ ⊆ A_adm`、`Î(ξ) − λc(ξ) ≥ m_0`，且存在可证伪回执（某个可能观测会缩小假设集）。资格只说明「值得在现实里做」，**不产生任何证据**。

**定义 455（信念证伪探针与分歧）** `Δ_epi(ξ) = TV(π_V(·|ξ), p_W(·|ξ))`（或 JS 散度）。选择
`ξ* = argmax_{ξ∈Qual} [ Δ_epi(ξ) + β·Î(ξ) ]`。
解释：由三角不等式 `Δ_epi ≤ TV(p_V,p*) + TV(p*,p_W) ≤ 2·max(TV(p_V,p*), TV(p*,p_W))`，故 `Δ_epi` 至少认证「有一个模型错了 ≥ Δ_epi/2」，真实探针可据此证伪。若在宣称新颖的区域出现 `Δ_epi≈0`，标记「可疑共识」（共享先验），强制独立通道复核。

**定义 456（想象写屏障 / 非干涉）** 数据标签 `Obs`（回执）、`Hyp`（隐状态/想象）、`Claim`（语言/VLA 主张）。允许流：`Obs→Claim`、`Obs→Hyp`（重锚定）、`Hyp→ranking`；**禁止流**：`Hyp→Obs`、`Hyp→q_s`、`Hyp→safety predicate`、`Hyp→threshold`。由类型化接口 + 运行时 provenance 检查共同实施；过期的 `Hyp` 不可读。该不变量保证「想象→状态→更乐观的想象」的自确认回路不存在。

**定义 457（耦合块长）** `K ≤ min( K_MAX(ι), H_cert(ε,α), K_ver, ⌊(B_left − c_verify)/c̄⌋ )`。其中 `K_ver` 为模型版本有效窗口：若块执行期间模型版本变化，块失效。跨不可逆动作仍强制 `K=1` 并独立交叉验证（继承定义 445）。**CVC 的 `drift` 只允许由真实回执或解析界计算，禁止直接使用 `ŝ`**；WM 只参与候选排序。

**定义 458（可供性-回执绑定）** 可供性主张 `κ = (region, affordance, confidence)` 必须绑定物理回执 `r`（接触、分割、力/力矩、独立视角等）；无法绑定的 `κ` 从规划与语言输出中**剥离**（`bind_aff` 为纯投影，继承定义 441 的 NCB 纪律）。

**定义 459（模型版本化证书与热替换屏障）** 任何证书携带版本三元组 `(h_V, h_W, h_E)`。执行门要求 `hash(executor) = (h_V,h_W,h_E)`，否则拒绝并重规划。模型热替换只允许发生在 `q_quiesce⁺`：无在途块、无待处理不可逆动作、无将被消费的想象；在途 rollout 一律丢弃。替换即失效所有旧版本证书与分层校准。**A 模型出证、B 模型执行**在类型上不可能。

**定义 460（想象算力与任意时间预算）** `c_imag(h,m) = α_0 + α_1 m h`。仅当 `c_imag ≤ slack_async` 时准入；到截止期就返回 best-so-far（anytime），并令 `h ≤ h_done`。若 `slack_async < c_min`，本拍关闭 WM，绝不阻塞 50Hz 控制路径。

**定义 461（六级修复证书 RepairCert″）** `RepairCert″(s) = (ι, PropCert, ImagTrace, C, ChunkCert, receipts, claims, version triple, CM audit)`。人类审计沿「指令→提议→想象→块→回执→主张」六级证据链复现一次修复；想象段显式标注为假设而非观测。

**定义 462（退化模式自动机）** `Mode ∈ {Vista, NoWM, NoVLA, ModelFree, Lean, MODGAUGE}`。迁移：`Vista→NoWM` 当 `H_cert<1`、IRG 触发或算力不足；`→NoVLA` 当支持集空/适配器拒绝；`→ModelFree` 当 `n_eff<n_min` 且无独立回执，或 VLA/WM 同时不可用；`→Lean` 当 ToolGauge 契约失败；`→MODGAUGE` 当数值路径失败。迁移带迟滞，安全谓词在各模式间保持不变，能力单调不增。

**定义 463（虚拟-真实增益校准）** 真实信息增益 `gain_real(ξ)` 由回执计算，`gain_pred(ξ)` 由 WM 给出；`g(ξ) = gain_real − gain_pred`。按指令/场景层做共形校准，要求 `P(g(ξ) ≥ −δ) ≥ 1−α`；否则放大该探针的代价或收缩 `H_cert`。该定义专门防止「只在想象中信息量大」的乐观探针。

## 4. 推导

**引理 59（提议过滤不扩权）** 若 `A_prop = Supp_τ ∩ A_adm(ι) ∩ E_emb^{-1}(M_phys)`，则 `A_prop ⊆ A_adm(ι) ⊆ A_ToolGauge`。VLA 只能选择子集，不能新增工具、物理量或越界幅值；任何越权候选在能力闭包/适配器/安全盾处被拒。
*证明*：集合交运算不增集；`A_adm` 由能力闭包与安全盾定义；`E_emb^{-1}(M_phys)` 只保留物理包线内动作。提示注入至多改变候选排序，不改变可行域。

**引理 60（认证视界的覆盖与单调性）** 在给定工况内可交换、且 h 步误差满足仿射递推 `e_{h+1} ≤ L e_h + b` 时，对每个 `h ≤ H_cert(ε,α)` 有 `P(e_h ≤ ε) ≥ 1−α`；对 `H_cert` 个视界同时成立需把水平改为 `α/H_cert`（union bound），或使用联合共形。`H_cert` 对 `ε` 与 `b` 单调不增；`L<1` 时稳态误差上界为 `b/(1−L)`，若该值 `>ε` 则无论多短都不可信，必须关闭 WM。
*证明*：分位数定义直接给出单视界覆盖；仿射递推展开得 `e_h ≤ L^h ε_0 + b(L^h−1)/(L−1)`；解不等式得闭式 `H_cert^{aff}`；对 `b` 求导为负，故单调。

**引理 61（回执裁决的块安全）** 若 WM 只参与候选排序、CVC 的 `drift` 与前置检查只使用真实回执或解析界、且 `K ≤ min(H_cert, K_MAX, K_ver)`，则执行块满足与 InstructGauge 引理 52 相同的不变量 `Inv`。WM 的误差只影响「选哪个安全计划」，不影响「计划是否安全」。
*证明*：执行路径上的每一步都由回执型 CVC 在应用前复核；`Hyp` 不进入安全谓词（定义 456）；跨不可逆动作仍由定义 445 强制 `K=1`。故安全性对 WM 的预测质量不敏感；`H_cert` 只限制计划视野，不替代安全检查。

**引理 62（共模证据界）** 将模型失效分解为共同原因 `C`（概率 `ρ_0`）与独立部分。若共同原因发生则所有同族源同时失效，则 `P(all n sources fail) ≥ ρ_0`，且 `P(all fail) ≤ ρ_0 + (1−ρ_0) q_max^n`。因此当 `ρ_0 > δ` 时，增加同族源不能把全失效概率降到 `δ` 以下；只有引入不同物理原理的第三路回执才能。`n_eff` 是该折扣的一阶近似。
*证明*：全概率公式 + union bound；下界由共同原因事件直接给出；`n_eff` 由 Kish 设计效应定义。

**引理 63（想象非干涉）** 若信息流类型系统禁止 `Hyp→Obs`、`Hyp→q_s`、`Hyp→safety`、`Hyp→threshold`，且 TTL 过期不可读，则观测状态过程与所有证书谓词只依赖于 `Obs`；关闭 WM 不改变任何安全保证，只改变候选排序。
*证明*：对执行步归纳。初始观测态只含 `Obs`；每步写状态只能经 `Apply_obs`（定义 456 的 `commit_state`）；证书谓词按定义 435/451 只读回执与解析界。非干涉（Denning 风格）保证 `Hyp` 不影响 `Obs` 的可观察行为；TTL 排除陈旧读。

**引理 64（分歧即误差下界与探索价值）** 对任意真实预测 `p*`，`Δ_epi = TV(p_V,p_W) ≤ TV(p_V,p*) + TV(p*,p_W) ≤ 2·max(TV(p_V,p*), TV(p*,p_W))`，故至少一个模型与真值的 TV 距离 `≥ Δ_epi/2`。因此观察到分歧就**认证了一个可被真实探针证伪的误差**；对二值结果，区分两个预测的期望信息增益 `≥ h_2((1−Δ_epi)/2)`（`h_2` 为二元熵）。
*证明*：三角不等式给出下界；信息增益由二分查询的熵下界（Fano 型论证）给出。该引理把「模型分歧」从启发式升级为有下界保证的主动学习信号。

**引理 65（版本化证书等价）** 若热替换只在 `q_quiesce⁺` 发生、执行门校验版本三元组、且替换即失效旧证书，则不存在任何块在混合版本下执行；在未涉及子图上，执行与 InstructGauge 逐指令等价（再回到引理 57 / 49 / 44），新增的 `PropCert/ImagTrace` 仍是纯投影或只影响排序。
*证明*：版本门使 `hash(executor) ≠ hash(cert)` 时拒绝；静默点保证无在途块与无待消费想象；对未变子图，控制流与 InstructGauge 相同；新增字段不进入数值路径。归纳即得。

**引理 66（想象摊销与 50Hz 保全）** 想象完全异步且任意时间；控制路径新增工作仅为 `O(1)` 的版本/来源/TTL 门检查与缓存排序，最坏新增 `<0.2ms`。总决策代价 `c_d/K + c_verify + c_gate`，当 `K ≥ c_d/(slack_async − c_gate)` 时摊销收益为正；松弛不足则 `K=1` 或关闭 WM，继承引理 58/50。
*证明*：代价分解；截止期到达即返回 best-so-far，不阻塞主循环；`K` 下界由正收益条件解出；退化路径的复杂度回到 InstructGauge/ToolGauge。

## 8. 本轮最大风险

**一句话**：`VLA-P` 与 `WM-R` 若共享编码器、预训练数据与归纳偏置，二者的「一致」会退化为共模幻觉的放大器——`CHC` 只保证想象在时域上不越界，`CMED` 只折扣可观测的相关性，真正未被观测的共模失效仍可能让系统在认证视界内自信地执行一次物理上错误、且不可逆的探测；因此最大风险在「模型族同源」这一不可见假设，而非单个模型的精度。
