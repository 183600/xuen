# 第 41 轮 · v18：成功率知识图谱（SR-KG）× 校准的不确定性 —— 从「技能点估计」到「关系化-校准的得分工程」（四层架构 v6）

> 承接第 40 轮 v17（热预算治理 × 步数感知规划 × 学习-TO，Δ 资源平面）。本轮灵感词「知识图谱 / 成功率」。乍看是两件不相干的事：一个是符号结构，一个是排行榜上的一个数字。但联网核实后它们指向 v17 同一个未被正视的软肋——**v17 把「p_s（技能成功率）」当成一张可以查表得到、且彼此独立的静态先验**（定义 27 的 `Π p_s`），而官方评分是「32 任务 × 5 泛化场景」上的**平均成功率 + 步骤分**（F67）。在真机 episode 极其稀缺、且演示数据只含成功样本（F68）的现实下，逐格点估计的成功率既噪声极大、又系统性偏乐观。**v18 的主轴因此是：成功率不是一个数，而是一个分层、相关、可校准、可向未见物品迁移的「信念场」；知识图谱是承载它的最自然结构。** 新增横切层 **Σ 成功率平面（成功信念账本）**，与 v17 的 Δ 资源平面正交：Δ 管「代价」，Σ 管「对成功的信念」。

## 0. 联网核实（先事实后推理；检索口径 2026-11-10，来源见产物区 §5）

- **事实 F67（官方挑战页，https://unibot.unitree.com/challenges.html，2026-11-10）**：UniBot-V1 为 32 项真机桌面任务（抓取/放置/双手协调），数据集 32,000 演示、169 小时；页面明确有「得分点（满分 100）Scoring Steps」；排行榜按**平均成功率 + 步骤分**综合排序，Leaderboard/Runs 当前均「即将发布 Coming Soon」。→ 评分函数同时含成功率与步数，二者不可偏废。
- **事实 F68（数据集公开性，2026-11-10）**：挑战页链接 HuggingFace 集合 `unitreerobotics/unibot-v1-challenge-dataset`；第三方数据索引（Kinetic Blocks, kineticblocks.com）称约 **33,276 episodes / ~169h / ~811GB / LeRobot v3.0(AV1) / 每任务一 repo / G1+Dex1 / 头戴双目+双腕 640×480@30fps / Apache-2.0**。但 v17 记录的 HF 数据集 API 曾返回 401（A33）。→ 登记 **A40**：以「官方集合页面为准、逐 repo 抽检可达性」核实，不假定全部公开。**关键统计事实：演示是遥操作成功轨迹，天然缺少失败标签。**
- **事实 F69（Unitree 首席科学家 Yuchen Xiao, ITU 演讲，2026-10-17）**：官方把「具身智能的 ChatGPT 时刻」定义为 **「80% success rate on 80% unseen tasks」**；UnifoLM-WLA-1.0 覆盖 64 项桌面/全身任务，ER-1 宣称 7 项 SOTA。→ 官方自己的北极星就是「未见任务上的成功率」——正是知识图谱最擅长的属性级迁移场景。
- **事实 F70（Harness VLA，arXiv 2607.08448，2026-07/09）**：把冻结 VLA 当作**可重试的接触丰富原语**，与少量解析原语组合；从执行轨迹、全局成功规则与**失败模型**中学习原语的「工作范围（operating range）」，不微调即把预训练 VLA 推离其轨迹分布。LIBERO-Pro +38.6pp、RoboCasa365 +25.4pp、RoboTwin C2R 58.4%。→ **强先例：policy 之外的显式成功/失败知识能显著抬高成功率。**
- **事实 F71（Skill-Graph 装配，arXiv 2603.12649，2026-03）**：技能图 `G=(V,L)`；用执行日志训练技能评估器 `E`，估计「特定环境下技能成功似然」；**失败概率感知规划**在高失败步插入感知探测，低风险步跳过监控；算法选择建模为 contextual bandit。→ **最接近本轮的先例**，但限于单一装配域，无校准保证、无属性级未见物品迁移、未与步骤分/榜单耦合。
- **事实 F72（VLAConf，arXiv 2605.29605，2026-05/08）**：在冻结 VLA 表征上做两阶段「任务成功置信度」——step-conditioned Coin-Flip 网络给未校准分数，低容量校准器映射到成功概率；LIBERO 在线估计占优，用于选择性专家接管。→ **校准成功概率的先例**，但仍是 policy 内表征，不含关系结构。
- **事实 F73（共形预测/风险控制谱系，2026）**：CaPTURe（arXiv 2608.09166）用共形预测校准接触不确定性，紧公差插入成功率最多 +30pp；UPS（arXiv 2602.22474, RSS 2026）用共形校准 VLM 验证器 + 策略组合，歧义场景 +30%；ReconVLA（2604.16677）把共形预测施加到动作 token 与状态空间；ICRA 2026 有工作用共形校准世界模型不确定性做双臂失败检测。→ **共形校准在真机上确实能转化为成功率**，但普遍违反 exchangeability（场景/机器/光照漂移），需分层（Mondrian）/加权 CP。
- **事实 F74（roboKG，RA-L 2022, Kwak 等）**：机器人操作知识图谱含 1,524 实体 / 10 关系 / 4,588 三元组，用 KG 嵌入预测抓取部件、夹爪类型与抓取力。→ **KG→操作因子的先例**，但不预测成功率、无校准、无在线更新。
- **事实 F75（GRAFT，CVPR 2026）**：图式部件对应做 affordance 迁移，零样本泛化到未见物体类别（部分级对齐 + 点级匹配）。→ **属性/部件图迁移**的直接证据。
- **事实 F76（属性抓取，T-RO 2024；GCNGrasp, PMLR 2021）**：属性表示在未知物体上 >81% 抓取成功率；语义 KG 让 GCNGrasp 在 held-out 上约 +12%。→ **关系/属性先验确实把样本效率转化为成功率。**
- **事实 F77（RoboDojo，arXiv 2607.04434）**：统一 sim-real 基准上，最强模型精度任务成功率仅 **12.00%**、score 18.32；整体榜与精度榜排名不一致。→ 精度/尾部是主要瓶颈，支持风险敏感而非均值最优。
- **事实 F78（R2S-Eval，arXiv 2609.03276）**：二值成功率「信息量有限」，需结合行为质量/偏好；重复真机评测本身有排名不稳定性。→ **成功率是含噪的、依赖评测分布的统计量**，不是策略的固有属性。
- **事实 F79（缺口，本轮定位）**：以上分别做了「KG→操作因子」（F74）、「技能图→失败概率规划」（F71）、「VLA→校准置信」（F72）、「共形→成功率」（F73）、「属性→未见物体」（F75/F76）。**无人把「类型化成功知识图谱 + 分层共形校准的成功后验 + 相关感知的风险敏感规划 + 面向榜单/步骤分的数据飞轮」统一到 32 任务通才基准上**；也无人把「演示只有成功、episode 极稀缺」当作一等统计约束来设计估计器。这就是 v18 的生态位。

## 1. 研究者直觉（先直觉与动机，后形式化）

**直觉 1（成功率是「借力」问题，不是「测量」问题）**。v17 想给每个 `(技能, 场景)` 估一个 `p_s`。但 32 任务 × 5 场景 × 每格几次 episode，逐格估计的方差大到无法指导决策；更糟的是演示只含成功（F68），观测到的成功率会系统偏乐观。人类研究者不会逐格测——他会说「圆柱体适合吸盘、易滑材质要避免顶抓、大件要双手」，然后**用属性把已测的经验借给没测的组合**。这正是知识图谱的统计学本质：**带类型的部分池化（partial pooling）**。图不是画给人看的，它是「让稀疏标签互相借力」的索引结构。在硬件预算固定的比赛里，这是唯一能同时降低估计方差与数据需求的手段。

**直觉 2（成功率是分布，不是标量；榜单是分布的泛函）**。排行榜 = 32 任务 × 5 场景上的平均成功率 + 步骤分（F67）。优化点估计会犯两类错：(a) 高方差估计器在某些格子上过度乐观，执行时连续失败；(b) 平均会掩盖「一个场景塌方」——例如人为干扰场景成功率 10%，会直接拖垮总分。因此正确目标不是 `E[p]`，而是**分层下界的组合 + 最弱场景保护**：`maximize mean_s p_s^LCB s.t. min_s p_s^LCB ≥ p_min`。这把「成功率」从标量升级为**风险敏感的组合优化**。RoboDojo（F77）显示均值榜与精度榜排名不一致，进一步说明单一均值会误导。

**直觉 3（5 类泛化场景 = 5 个分布分层，校准必须分层）**。位置/干扰物/背景/未见物品/人为干扰，本质是协变量/标签漂移。全局共形校准在漂移下会失效（F73 自己也承认违反 exchangeability）。正确做法是 **Mondrian（分层）共形 + 场景特征加权**：对每个场景桶单独校准，并让「运行中观测到的场景特征」对校准集加权。这样输出的不是「模型自信」，而是**在目标评测分布下有覆盖保证的成功区间**。这是 v18 相对 F70/F71 的硬增量——它们有成功模型，但没有覆盖保证。

**直觉 4（未见物品是知识图谱的主场，也是官方北极星）**。F69 明说官方目标是「80% 成功率 × 80% 未见任务」；F75/F76 证明属性/部件图能把已见经验迁到未见类别。所以 SR-KG 必须把**属性节点**（形状/材质/尺寸/质量/affordance）作为一等公民，而不是只建「物体类别→技能」的查找表。未见物体进来时，IP-36 场景图把它实例化到属性节点，SR-KG 直接用属性近邻给出成功先验与不确定度。这是任何 flat 表格做不到的。

**直觉 5（先例已经证明「显式成功模型」有效，本轮做的是补上它的统计地基）**。Harness VLA（F70）靠成功规则 + 失败模型 +38.6pp；Skill-Graph（F71）靠失败概率感知规划；VLAConf（F72）证明成功置信可校准。这些是强信号：**方向对**。但它们各自缺一块：(F70) 无形式化不确定度、(F71) 单域无迁移无校准、(F72) 无关系结构。v18 不发明新方向，而是把这几块拼成一个**可证明覆盖、可迁移、可在线更新**的整体，并明确回答「在只有成功演示 + 少量真机 episode 时，成功率该怎么估」。这是最像真正研究的一步。

**直觉 6（顺手修掉 v17 的一个具体 bug：独立同分布假设）**。v17 的 `E_score = Π p_s` 隐含「各子技能成功条件独立」。真实操作里失败高度相关：抓歪了，放置大概率也歪。用因子图/隐执行质量 `z` 建相关结构，能让「预计成功率」不再系统性偏离实测。这条不需要新硬件，纯建模修正，却可能直接改变规划选择——是我最想先用离线数据验证的一条。

**直觉 7（本轮已经跑了一个小实验，结论既支持又警示）**。我在 `exp/r41_srkg/` 跑了合成机制验证（5 seeds，非基准证据）：在「每格 1–10 条 episode、仅部分格子被尝试」的稀缺设定下，图正则多任务成功模型相对 flat 计数把成功率 MAE 降低 20%–33%、**决策后悔降低约 29%–50%**，未见物体上尤其明显（n=1 后悔 0.140→0.090，n=5 0.104→0.055）。但**拉普拉斯近似的 90% 下界实际覆盖率只有 0.77–0.86，低于名义 0.90**——模型在误设下过度自信。这恰好证明：**关系化估计是有效的，但必须外挂共形重校准**，不能只靠贝叶斯后验。这条负面结果直接塑造了本轮的 IP-52 设计。

## 2. 形式化直觉（严格版见产物区 §3）

**定义 29（Σ 成功率平面）**：`Σ-Ledger = {P̂_s(·), U_s(·), Cov_s, F_s(·)}`，即技能成功后验、不确定度、每场景校准覆盖率、失败模式分布。它与 v17 的 `Δ-Ledger={H_gpu,Ĥ_motor,S_used,L_p99}` 正交：Δ 决定「付多少物理成本」，Σ 决定「信多少成功概率」。规划的目标函数同时吃两个账本。

**定义 30（SR-KG，类型化成功知识图谱）**：异质图 `G_S=(V,E,A)`，`V=V_obj ∪ V_attr ∪ V_task ∪ V_skill ∪ V_scene ∪ V_fail`；`E=E_hasAttr ∪ E_partOf ∪ E_pre ∪ E_effect ∪ E_sim ∪ E_failExec`。每个「技能×上下文」携带隐成功率 logit `θ_v`；`E_sim` 边携带迁移系数 `κ_uv`。IP-36 的场景图负责每 episode 实例化 `V_obj/V_attr`；SR-KG 负责「成功」这一随机变量及其关系。

**定义 31（图正则分层成功后验）**：`θ=μ+ε`，`ε~N(0,(λI+τL_G)^{-1})`，`L_G` 为 `E_sim/E_pre` 的拉普拉斯；观测 `y_i~Bernoulli(σ(φ(x_i)^Tθ_{skill}))`。MAP + 拉普拉斯后验给出部分池化：未见属性组合从邻居借力。**小实验教训：此近似后验会过度自信，需共形层兜底。**

**定义 32（分层共形风险控制）**：对每个场景桶 `s`，用分裂共形 + 加权（协变量漂移）重校准非一致性分数，输出 `p_s^LCB/p_s^UCB`，并令失败风险 `P(E[1−success]≤α)≥1−δ`。验收标准不是「后验看起来对」，而是「held-out 场景上的实际覆盖率 ≥ 1−α」。

**定义 33（相关感知的风险敏感 E_score）**：用因子图（隐执行质量 `z`）替代 v17 的独立乘积，得到 `P_LCB(success|π)`；规划目标 `E_score_risk(π)=g(N_π)·P_LCB − λ·P_UCB(fail)`，并加最弱场景保护 `min_s p_s^LCB≥p_min`。步数分 `g(N)` 仍按 v17 双口径鲁棒。

**定义 34（成功前沿 / 数据获取价值）**：对候选数据/微调动作 `a`，`AV(a)=E_post[ΔU|do(a)]/cost(a)`，用后验信息增益 × 效用敏感度近似。用它把稀缺的真机预算投向「最影响榜单的失败边」，形成成功率驱动的数据飞轮。

## 3. 关键决断

1. **成功率升格为一个平面**：Σ 平面与 v17 Δ 平面正交，所有「选技能/换策略/采数据」决策都读 Σ 账本，而非查静态表。
2. **图是估计器不是装饰**：SR-KG 的唯一硬指标是「降低成功率估计误差与决策后悔、提高未见物品迁移」，用 `exp/r41_srkg` 的合成压测 + E73 离线回放证明，而非画得好看。
3. **校准优先于自信**：点估计已经有效（MAE −20~33%），但下界覆盖率不足（0.77–0.86），所以**共形重校准是 P0 而非可选**；没有覆盖保证的成功率不许进风险敏感规划。
4. **修独立假设**：用因子图相关结构替换 `Π p_s`，这是纯建模修正，先离线验证再上真机。
5. **修剪继续**：跨本体预训练（单 G1 平台）、全形式鲁棒证书、课程蒸馏进一步降 P2，把复杂度预算让给 Σ 平面（规则 51）。

## 4. 本轮最大风险（一句话）

**若演示只有成功样本、真机 episode 又极少，SR-KG 的成功标签本身稀疏且有偏；图正则会把一条错误边（例如「圆柱→吸盘」在易滑材质上失效）放大成整簇属性上的系统性负迁移，而拉普拉斯后验已实测过度自信（覆盖率 0.77–0.86）——于是「关系化成功率」可能变成一个又自信又错的信念场，规划器会认真地优化一个幻觉中的成功曲面；必须以分层共形覆盖率、held-out 场景/物体检验与 flat 计数兜底三重守门，任一不过即退回 v17 的点估计规划。**

# 第 41 轮产物 · 创新点清单 v18：成功率知识图谱（SR-KG）× 校准不确定性（「Σ 成功率平面」横切层，四层架构 v6）

> 承接 v17（第 40 轮：热预算治理 × 步数感知规划 × 学习-TO，Δ 资源平面）。本轮灵感词「知识图谱 / 成功率」经联网核实（口径 2026-11-10）后收敛到一个 v17 未处理的软肋：v17 把技能成功率当作**静态、独立、可查表**的先验（IP-49 的 `Π p_s`），而官方评分是 32 任务 × 5 泛化场景上的平均成功率 + 步骤分（F67），且演示数据只有成功轨迹（F68）。v18 新增 **横切层 Σ 成功率平面** 与 **2 项核心 IP（IP-52 SR-KG 成功率知识图谱 / IP-53 SUCCESS-FRONTIER 成功率驱动数据飞轮）**，重构 **IP-49 风险敏感规划** 与 **IP-24/28v2 证据流**，并继续修剪 3 项非得分型设计。主轴：**把「成功率」从一个数字升级为一个分层、相关、可校准、可迁移的信念场；知识图谱是它的统计骨架。**

## 0. 结论

- **Σ 成功率平面（本轮总纲）**：`Σ-Ledger={P̂_s, U_s, Cov_s, F_s}`（成功后验 / 不确定度 / 每场景校准覆盖率 / 失败模式分布），与 v17 `Δ-Ledger={H_gpu, Ĥ_motor, S_used, L_p99}` 正交——Δ 管代价、Σ 管信念，二者共同进入规划目标。
- **IP-52 SR-KG（P0 新增，横切）**：类型化异质成功知识图谱（物体/属性/任务/技能/场景/失败模式），图正则分层贝叶斯部分池化 + **分层（Mondrian/加权）共形风险控制**，输出带覆盖保证的 `p_s^LCB/UCB`；在线吸收 episode 证据；与 IP-36 场景图共享属性节点。

- **修剪（规则 51）**：IP-42 跨本体运动 → P2（单 G1 平台，不承重）；IP-46 全形式鲁棒证书 → P2（收缩性已够，覆盖率改由 Σ 平面给）；IP-44 渐进课程蒸馏 → P2（边际得分低）。

### 3.2 IP-52 SR-KG（成功率知识图谱，完整设计）

**IP 卡片（六字段）**
- **动机**：F67 评分 = 平均成功率 + 步骤分；F68/A41 演示只有成功、真机 episode 稀缺；F70/F71/F72 证明显式成功/失败模型能显著抬升成功率；F73 证明共形校准能转化为成功率；F69 官方北极星是「未见任务成功率」；F75/F76 证明属性/关系迁移对未见物体有效。→ 需要一个能**借力、校准、迁移、在线更新**的成功率估计中枢。
- **与现有方案差异**：F71 有技能图+失败概率但单域、无覆盖保证、无属性迁移；F72 有校准但无关系结构；F74 有 KG 但不估成功率；F75/F76 有属性迁移但不做风险敏感规划与榜单耦合。**无人把四者统一，也无人以「仅成功演示」为一等约束做估计器设计。**
- **技术可行性**：图规模小（物体×属性×技能×场景 ~10³ 节点）；图正则 MAP 用梯度/共轭梯度毫秒级；拉普拉斯协方差按技能块求逆（≤12 维/块）；共形层是排序+分位数，O(n log n)；与 IP-36 共享节点，零额外感知成本。
- **所需资源**：数据=演示（成功，用于初始化属性边）+ 自采/仿真失败（IP-35 失败注入，A41）+ 评测 episode 在线证据；算力≈0（CPU）；接口=观测中的物体/属性、语言指令、episode 边界（`reset()`）。
- **落地步骤**：① 从演示抽取任务/技能/物体属性三元组初始化图；② IP-35 注入失败标签补 A41；③ 图正则 MAP + 拉普拉斯方差；④ 分层共形重校准（按 5 场景 + 任务簇）；⑤ 在线更新与漂移检测；⑥ E73–E74 验收。
- **风险**：错误边负迁移（→ 覆盖检验 + 边剪枝 + flat 兜底）；共形 exchangeability 被破坏（→ Mondrian + 加权 CP）；成功标签偏乐观（→ 失败注入 + 先验收缩 + 校准）。

**符号表**

| 符号 | 含义 | 来源/取值 |
|---|---|---|
| `G_S=(V,E,A)` | 类型化成功知识图谱 | VI 类节点 / VI 类边，见定义 30 |
| `θ_v` | 节点 v 的成功 logit | 图正则分层后验 |
| `φ(x)` | 物体属性 + 场景的实例化特征 | 与 IP-36 属性节点对齐 |
| `L_G` | 图拉普拉斯（E_sim/E_pre） | 迁移强度 |
| `τ, λ` | 图/岭正则强度 | E73 交叉验证 |
| `p^LCB_s, p^UCB_s` | 分层共形下/上界 | 覆盖率 ≥ 1−α |
| `Cov_s` | 场景桶 s 的实际覆盖率 | 验收指标 |
| `F_s` | 场景 s 的失败模式分布 | 失败节点聚合 |

**算法（离线建图 → 在线推断）**
```
# 离线：初始化 + 校准
1. 演示解析：每任务切技能段 → (task, skill, object, attrs, scene) 成功边（全 y=1，偏乐观）
2. IP-35 失败注入：MuJoCo 变物体/材质/位姿/干扰 → 生成 y=0 失败样本，补 A41
3. 图正则 MAP：θ* = argmin Σ_i [ -log σ(φ_i^T θ_{skill(i)}) + ... ]
                         + (λ/2)||θ||² + (τ/2)Σ_{(u,v)∈E_sim} κ_uv||θ_u-θ_v||²
   拉普拉斯后验 Σ_post ≈ (X^T S X + λI + τL_G)^{-1}
4. 分层共形：对每个 scene 桶 s，用 held-out 轨迹算非一致性分数 r_i=1-σ(φ_i^Tθ)
   加权（按场景特征核）取分位数 q_s；p^LCB=σ(φ^Tθ - q_s)
5. 验收：held-out 场景/物体上 Cov_s ≥ 1-α，否则强化正则/退回 flat

# 在线：每个 episode 后
6. 观测 y=(success?)、步数 N、场景特征；更新该 (skill,obj,scene) 证据计数
7. 漂移检测：若最近窗口覆盖率 < 1-α-ε → 触发共形集重加权 + 边剪枝候选
8. 输出给 IP-49：p^LCB / p^UCB / 相关结构（因子图）/ 失败模式
```

**正确性论证**
- **P51（部分池化的方差缩减）**：在图拉普拉斯先验下，节点后验方差 `Var(θ_v)` 小于同数据的 MLE 方差，缩减量随邻接度 `deg(v)` 单调增；故稀疏桶借力后估计误差下降（实验：MAE −20~33%）。
- **P52（覆盖保证）**：在桶内 exchangeable 假设下，分裂共形满足 `Pr(p_true ≥ p^LCB) ≥ 1−α`；加权 CP 把该保证推广到有界协变量漂移（重要性权重有界）。
- **P53（迁移不劣化条件）**：若错误边的负迁移损失小于借力带来的方差收益，则图模型期望后悔 ≤ flat；实验未见物体上 n=1/5 后悔降 ~36%/47%，但 held-out 覆盖率不足说明该条件需要共形层强制。

**已知风险**：错误边放大（→ 覆盖检验 + 边剪枝 + flat 兜底）；成功率标签偏乐观（→ 失败注入 + 收缩）；漂移下共形失效（→ Mondrian/加权 + 在线重估）。

### 3.3 IP-49 重构：相关感知、风险敏感、榜单对齐的规划

**核心修正**：v17 `E_score=Π p_s·g(N)−λP(fail)` 假设子技能独立。真实操作中失败强相关。引入隐执行质量 `z`（如抓取稳定性）构造因子图：
```
P(success | π, e) = Σ_z P(z|e) Π_s P(y_s | z, context_s)
```
输出两个量：`P_lower`（条件独立乘积 + LCB，保守下界）与 `P_struct`（因子图 + 校准），规划取 `min(P_lower, P_struct)` 作 `P_LCB`。
```
E_score_risk(π) = g(N_π) · P_LCB(success|π) − λ · P_UCB(fail|π)
s.t.  min_{s∈scenes} p_s^LCB(plan) ≥ p_min          # 最弱场景保护
```
- **步骤分鲁棒**：`g(N)` 仍按 `1/N` 与分段两口径取 `min`（A34）。
- **重规划触发**：IP-24 失败信号 ∨ Σ 覆盖率下降 ∨ Δ 平面 CRITICAL ∨ 证书违约。
- **失败记忆升级**：`M_f[(obj,s,site,fail_sig)] → 策略升级`，并把该证据回写 SR-KG（同一物体同一技能失败率上调，触发换抓取点/推-抓/双手/换工具）。
- **正确性**：P54（风险单调性）`E_score_risk` 对 `P_LCB` 单调增、对 `P_UCB(fail)` 单调减；P55（最弱场景保护）显式约束把「平均最优但某场景塌方」解排除；P56（相关修正）当子技能正相关时 `P_struct ≥ Π p_s`，减少过度悲观导致的无效 retreat（省步）。

### 3.4 IP-53 SUCCESS-FRONTIER（成功率驱动的数据飞轮）

- **动机**：真机预算极稀缺；SR-KG 给出「哪里不确定且影响大」的地图，据此主动取数/微调，而不是被动等评测。
- **形式化**：`AV(a) = IG(a) · |∂U/∂p_{a}| / cost(a)`，`IG(a)` 为对 `a` 观测的后验互信息（近似用预测熵减），`U` 为榜单效用（平均成功率 + 步骤分 − 场景方差惩罚）。选 top-k 执行（采集/仿真放大/小步 LoRA）。
- **落地**：先做「仿真放大」（IP-35 失败注入）+「真机少量验证」，避免直接在评测机上探索；输出下一轮数据配方。
- **风险**：信息增益估计偏差；成本模型失真；→ 以 E76 的「预算-成功率兑换曲线」验收，失败则退化为均匀采样。

### 3.6 运行期伪代码（v18 增量）

```python
# ===== 离线：建图 + 共形校准（IP-52/35）=====
def build_srkg(demos, sim_failures):
    G = typed_graph()                      # obj/attr/task/skill/scene/fail
    G.add_success_edges(parse_demos(demos))# 演示仅 y=1（A41）
    G.add_failure_edges(inject_failures(sim_failures))  # IP-35 补失败
    theta, cov = graph_regularized_map(G, lam, tau)     # 图正则 + 拉普拉斯
    q = {s: weighted_conformal_quantile(G, theta, scene=s, alpha=0.1)
         for s in SCENES}                  # 分层共形
    assert all(coverage_ok(G, theta, s, q[s], alpha=0.1) for s in SCENES)  # E73 门
    return G, theta, cov, q

# ===== 运行期：Σ 平面证据 + 规划 =====
def act_v18(obs, state):
    # 1. IP-36 场景图实例化 → 属性/物体节点
    scene = semantic_map(obs)              # 含 attrs
    # 2. IP-52：查询成功后验（带覆盖保证）
    p_lcb, p_ucb, corr = srkg_query(state.G, state.theta, state.q,
                                    scene, skill_candidates)
    # 3. IP-49：风险敏感规划（相关感知 + 最弱场景保护）
    plan = risk_score_planner(obs.language, scene, p_lcb, p_ucb, corr,
                              delta=state.knobs, min_scene_p=0.15)
    # 4. 中层 → TO → 流式执行（继承 v17）
    traj = hybrid_to(plan, stream_policy_head(plan.skill, obs))
    chunk = traj.next_chunk(state.knobs.T_a_eff)
    if not guard.cbf_check(chunk): chunk = resample_or_fallback(state)
    # 5. 证据回写（IR-24/28v2 + IP-30 校准弱标签）
    y = observe_outcome(obs, chunk)
    if y is not None:
        state.G.update(plan.skill, scene, y)
        state.q = online_conformal_update(state.q, plan.scene, y)
    if failure_monitor(obs) > TAU:
        state.plan = replan_with_failure_memory(state)
    return adapt(chunk, control_space=state.control_space)
```

## 6. 清单迭代规则（继承 27–51 + 本轮新增 52–55）

- 继承规则 27–51（通道诚实/映射验证/SLO/fail-safe/灵感-现实校验/单模型合规/步骤分双解释/稠密监督/方法论遗产/元数据重照亮/语言口径分离/摊销/验证器分级/灵感词落地/层级联合规划/跨本体/流式/蒸馏/服务化/证书化/组合代数/热预算/期望得分/学习-TO/修剪优先）。
- **52（新增）：成功率信念场原则**——成功率不是标量而是分层、相关、可校准、可迁移的分布；Σ 账本（后验/不确定度/覆盖率/失败模式）为全架构一等资源；关系结构（属性/任务/技能/场景/失败）是降低估计方差与数据需求的手段。
- **53（新增）：覆盖优先于自信原则**——任何进入风险敏感规划的成功概率必须带分布无关覆盖保证（分层共形/风险控制）；后验点估计与置信区间分离；覆盖率实测不达标即禁用 LCB，退回保守点估计 + 安全裕度。
- **54（新增）：相关感知得分原则**——禁止默认子技能独立；用因子图/隐执行质量建模失败相关，规划取条件独立下界与结构估计的较小者，避免过度悲观或过度乐观。
- **55（新增）：成功率驱动飞轮原则**——数据/微调预算按「后验信息增益 × 榜单效用敏感度 / 成本」分配；先仿真放大再真机验证；每轮必须报告「预算-成功率兑换曲线」或明确说明未测。

**本轮最大风险一句话**：仅成功演示 + episode 稀缺 → 成功率标签稀疏有偏，图正则会放大错误边并已实测过度自信（覆盖率 0.77–0.86），「关系化成功率」可能变成又自信又错的信念场；以分层共形覆盖、held-out 物体/场景、flat 兜底三重守门，任一不过退回 v17 点估计规划。

**当前最值得押注**：**IP-52 SR-KG 的「图正则部分池化 + 分层共形校准」组合**——它同时被三条独立证据支持（F70 显式成功模型 +38.6pp、F71 失败概率规划、F73 共形校准 +30pp），并已被本轮 pilot 证实「关系化估计确实降低 MAE 20–33%、决策后悔 29–50%、未见物体最显著」，而唯一未过门项的覆盖率缺口（0.77–0.86）恰好由设计中的共形层直接修补——这是一个**已有正收益、且失败模式已知且有解**的高确定性押注；其余两线（IP-53 数据飞轮、IP-49 相关规划）都围绕它的输出运转。
