研究循环 · 新灵感三元组第 1 轮；本轮灵感：「轻量化结构」×「数据配比」

> **基线**：v23 产出 MetricVoiceGauge-NCD-HUTDH-v23（IP-436–439；其上承 v22 的 HDL/ACSC/DCSC、v21 的 SDC/CAC/DCL/GIC、v20 的 PCA/CTS/CFC/HPC）。
> 本轮纪律：**轻量化是函数空间的有界扰动、数据配比是测度空间的有界扰动，两者必须在同一张 conformal 证书里被显式吸收**。不推倒 v23：CESC/FSVC/IPAM/HPC-E+ 与更早各层全部保留。本轮只做一件事：在 v23 的云边少样本证书之上加一层"压缩-配比"层，把"模型怎么变小、校准数据怎么配"从工程细节升级为**可审计、可继承、可联合优化**的证书变量，并顺手封堵 v23 的最大风险（`T_switch` 窗口内覆盖与版本共振崩塌）。

## 0. 直觉与动机

**灵感 1（轻量化结构 → 压缩即证据膨胀，证书可"搭桥"继承）**
直觉：v23 的 DCSC 在稠密模型上标定了 conformal 分位数，但边缘端真正跑的是剪枝/量化/蒸馏后的轻量模型——**校准分布与部署模型不是同一个对象**，直接沿用稠密分位数并不成立。但轻量化并非"必须从零重新标定"：压缩是函数空间里的一次**有界扰动**。若能证明 `sup_x |s_L(x) − s_D(x)| ≤ Δ_comp`，则稠密证书只要把分位数**膨胀** Δ_comp 就对新模型仍然有效（三角不等式直接搬运覆盖保证）。更深一层：**结构本身携带可计算的界**——剪枝后的稀疏支撑、量化的离散网格、蒸馏的 Lipschitz 常数，都能给出比"黑盒重标定"更紧、且可在 50Hz 内 O(1) 查询的 Δ_comp。反直觉点：**轻量化的正确姿势不是"换模型重认证"，而是"把稠密证书按结构感知的界平移"**；而且证书自己也得轻——一张带逐检测 merkle 证明的证书若撑爆控制环预算，比不签更危险。

**灵感 2（数据配比 → 覆盖的绑定约束是配比而非数据量）**
直觉：v23 的 conformal 覆盖是**边缘覆盖**——在校准集整体分布上平均成立。但"缺席幻觉"恰恰是**分组失败**：儿童/轮椅/蹲姿/逆光这些子群在校准集里占比极低，边缘覆盖 99% 可以掩盖某个子群 60% 的失败。数据配比 π 是**校准测度**本身，它决定每个子群拿到多少样本、因而决定分组覆盖能否成立。核心创新：**双账本配比 (Dual-Mix Ledger)**——把"训练配比 `π_train`"（决定分数分布/精度，因而决定活性）与"校准配比 `π_cal`"（决定可交换性，因而决定覆盖有效性）**分开记账**；用 **Mondrian 分组 conformal** 给出逐群 ≥1-α 保证，用**加权 conformal** 校正部署配比与校准配比的错配。反直觉点：**在校准预算固定时，多加多数群样本对最差群覆盖毫无帮助——配比，而不是总量，才是覆盖的绑定约束**。

**灵感 3（两者统一 → 函数扰动 × 测度扰动 的对偶）**
直觉：轻量化是**函数空间**的扰动（`f_D → f_L`），数据配比是**测度空间**的扰动（`P_cal → P_dep`）。两者看似无关，但在 conformal 里是同一个量：**都表现为同一个分位数的膨胀/重加权**。于是可以联合设计：在"逐群覆盖 ≥1-α ∧ 证书预算 ≤ B"的约束下，选择压缩配置 `θ_c` 与校准配比 `π_cal`，最大化活性——压缩越狠 → `Δ_comp` 越大 → `ε̂` 越大 → 活性越低，但延迟越低；配比越准 → 分组 `ε̂` 越紧 → 活性越高。反直觉点：**压缩与配比不是两个独立旋钮，而是一条 Pareto 前沿上的联合选择**；且这条前沿可离线求解、在线 O(1) 查表。

**三者如何统一**
统一为 v23 之上的 **"压缩-配比证书层"**：LCSC 回答"轻量模型的证书从哪来"（有界继承），MCCC 回答"逐群覆盖凭什么成立"（配比声明 + Mondrian/加权 conformal），CCB 回答"证书本身是否付得起"（预算可行），CMCO 回答"`θ_c` 与 `π` 怎么联合选"（Pareto 离线求解）。共享状态 `ζ_v24 = ζ_ce ∪ (θ_c, Δ_comp, π_train, π_cal, {q̂_g}, B_cert)`。统一准入门 **HPC-L = HPC-E+ ∧ LCSC ∧ MCCC ∧ CCB**：任一缺失 → 回退 v23 的稠密模型 + 边缘 conformal（即 v23 行为）。故 `Exec_v24 ⊆ Exec_v23`。

## 1. 研究问题（轮次升级版）

- **Q12（压缩继承的紧界）**：如何标定 `Δ_comp` 使 `CertBox_L = inflate(CertBox_D, Δ_comp)` 以 ≥1-δ 概率包含真物？剪枝（稀疏支撑）/量化（离散网格）/蒸馏（Lipschitz）三类压缩的界能否统一为"函数空间扰动范数"，并在不牺牲紧性的前提下 O(1) 查询？结构感知界与"差异集上 conformal 上分位"如何取更紧者且不破坏覆盖？

- **Q13（分组覆盖的样本复杂度）**：在总校准预算 n 与分组表 G 下，逐群覆盖 `P(s ≤ q̂_g | G=g) ≥ 1-α_g` 需要 `n_g ≥ ?`（关于 α_g、δ、群内可分性）？同时覆盖所有群是取 Bonferroni `α_g=α/|G|` 还是 max-quantile 更省样本？样本不足的群如何**保守占用**（q̂_g=+∞）而不误发缺席证书？

## 2. 设计原则（在 P41–P42 基础上新增 P43–P46）

**P43 轻量化即证据膨胀律（Compression-as-Inflation）**
设 `s_D, s_L` 分别为稠密/轻量模型在同一非一致性评分上的取值，若 `sup_x |s_L(x) − s_D(x)| ≤ Δ_comp`，则 `ε̂_L = ε̂_D + Δ_comp`，且 `CertBox_L = inflate(CertBox_D, Δ_comp)`。`Δ_comp` 取结构感知确定性界与差异集 conformal 上分位的**更紧者**；结构界不可用或失配即回退稠密模型（等价 v23）。轻量化只允许**增大**误差界、只允许**收缩**执行集：`Exec_v24 ⊆ Exec_v23`。

**P44 配比即覆盖声明律（Mix-as-Coverage-Declaration）**
校准测度必须**显式声明并版本化**：`π_cal` 决定分组样本 `n_g=π_cal(g)·n` 与逐群分位数 `q̂_g`；`π_train` 单独记账（只影响分数分布/活性，不影响覆盖有效性）。覆盖目标为**逐群** `P(s ≤ q̂_g | G=g) ≥ 1-α_g`（同时覆盖取 Bonferroni `α_g=α/|G|` 或 max-quantile）。部署配比错配用加权 conformal 校正（密度比有界 `W_max`）；`W_max` 未知、群样本不足或群未声明 → 该群 `q̂_g=+∞`（保守占用），**绝不签发缺席证书**。

**P45 证书预算可行律（Certificate Budget Viability）**
证书的生成延迟与体积是**被认证量**：`B_cert=(B_lat,B_size)`。控制路径只提交 merkle 根（O(1)），逐检测证明离线展开；若生成将超预算，则**渐进降级**为更粗（更保守）的证书，绝不误期。证书预算不可行 ⇒ 降级而非冒险：`Exec` 只收缩、不扩张。

**P46 压缩-配比联合优化律（Compression–Mix Co-Design）**
离线在 `(θ_c, π_cal)` 上解 `max 活性(ε̂(θ_c,π_cal)) s.t. ∀g 覆盖_g(π_cal) ≥ 1-α_g ∧ 延迟(θ_c) ≤ B_lat ∧ 体积 ≤ B_size`，得 Pareto 前沿表；在线仅 O(1) 查表。任一约束不可满足 → 回退 `(稠密模型, 均匀配比, 最大 ε̂)`，即 v23 保守行为。故 `Exec_v24 = Exec_v23 ∩ Fil_lw ∩ Fil_mix ∩ Fil_budget ⊆ Exec_v23`。

## 3. 与基线的接口（如何退化）

- LCSC 失效（无法认证 `Δ_comp`）⇒ 部署稠密模型 ⇒ 等价 v23 的 DCSC（更慢但覆盖不变）；
- MCCC 失效（分组样本不足 / 配比未知 / 群未声明）⇒ 该群保守占用，缺席证书拒发 ⇒ 比 v23 更保守；
- CCB 失效（证书超预算）⇒ 降级为 merkle 根级粗证书 ⇒ 可审计性降级、安全性不降；
- CMCO 无可行解 ⇒ 回退 `(稠密, 均匀, 最大 ε̂)` ⇒ 等价 v23；
- CFC-L 分层计票无法满足 ⇒ 退回 CFC+++ 的 v23 计票行为 ⇒ 等价 v23；
- 全部失效 ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`（引理 169）。
- **安全继承**：压缩只增误差界、配比只收紧逐群覆盖、预算只降级不扩张、联合优化只在可行域内选点；任意失效都向更保守方向退化。

## 4. 预期贡献

1. **压缩继承证书**：首次把"稠密证书 → 轻量模型"的迁移形式化为有界函数扰动下的分位数膨胀，给出结构感知（稀疏/量化/Lipschitz）的紧 `Δ_comp`，免去边缘端从零重认证；
2. **双账本配比**：首次显式区分"训练配比决定活性、校准配比决定覆盖有效性"，把数据配比从训练细节升级为可审计证书变量；
3. **逐群覆盖**：用 Mondrian + 加权 conformal 把"缺席幻觉"从边缘 99% 升级为**逐子群 ≥1-α**，并给出群样本复杂度与未知群保守占用；
4. **证书预算**：把证书自身的延迟/体积纳入认证，给出 merkle 批量提交 + 离线展开 + 渐进降级，调和可审计与实时；
5. **压缩-配比联合优化**：给出离线 Pareto 前沿 + 在线 O(1) 查表，使"压缩多狠 / 数据怎么配"成为同一约束优化问题；
6. **封堵 v23 最大风险**：把 `T_switch` 窗口的覆盖崩塌纳入 CCB/LCSC/MCCC 三证，切换前先验 `Δ_comp` 与逐群覆盖，失败即回滚，`Exec_v24 ⊆ Exec_v23` 闭环。

## 5. 本轮最大风险

**一句话**：逐群覆盖与压缩继承都是**条件于已声明结构**的保证——`Δ_comp` 条件于已知压缩配置、逐群覆盖条件于**列全的分组表 G**；若云端下发的是一条未声明的压缩路径，或部署中出现一个不在 G 里的"未知未知群"（罕见体型/姿态/光照），证书会形式有效而事实失效，机器人将"合规地、可审计地"把一张覆盖空洞的证书当成安全证据——即**结构盲区与配比盲区的联合幻觉**。

## 1. 关键算法骨架（在 IP-436–439 骨架上扩展）

```python
# ============================================================
# IP-440 Lightweight Compression Semantic Certificate (LCSC)
# ============================================================
@dataclass
class CompressionConfig:
    prune_ratio: float
    quant_bits: int
    distill_T: float
    version: int

class LightweightCompressionCertificate:
    def __init__(self, alpha: float = 0.01, delta: float = 0.001):
        self.alpha = alpha
        self.delta = delta
        self.Delta_comp: float = float("inf")
        self.certified: bool = False

    def structural_bound(self, f_D, f_L, cfg: CompressionConfig,
                         act_bound: float) -> float:
        """结构感知确定性界：量化 + 剪枝 + 蒸馏 的三角分解"""
        # 量化：输出扰动 ≤ Lipschitz * 量化步长
        step = 2.0 ** (-cfg.quant_bits)
        lip = estimate_lipschitz(f_L)               # 谱范数估计，离线一次
        b_quant = lip * step
        # 剪枝：被剪权重范数 × 激活界
        b_prune = sum(w.norm().item() for w in pruned_weights(f_L)) * act_bound
        # 蒸馏：直接取教师-学生输出差的训练期最大残差（已知上界）
        b_distill = get_distill_residual_bound(cfg)
        return b_quant + b_prune + b_distill

    def discrepancy_quantile(self, f_D, f_L, D_disc) -> float:
        """差异集上的 (1-delta) 上分位：|s_L - s_D| 的经验上界"""
        diffs = sorted(abs(score(f_L, x) - score(f_D, x)) for x in D_disc)
        idx = min(len(diffs) - 1,
                  math.ceil((len(diffs) + 1) * (1 - self.delta)) - 1)
        return diffs[idx]

    def certify(self, f_D, f_L, cfg, D_disc, act_bound) -> bool:
        b_struct = self.structural_bound(f_D, f_L, cfg, act_bound)
        b_emp = self.discrepancy_quantile(f_D, f_L, D_disc)
        # 两个都是有效上界，取更紧者仍是有效上界
        self.Delta_comp = min(b_struct, b_emp)
        self.certified = math.isfinite(self.Delta_comp)
        return self.certified

    def inflate(self, cert_D) -> "CertBox":
        """稠密证书按 Δ_comp 膨胀：覆盖保证被搬运到轻量模型"""
        if not self.certified:
            raise RuntimeError("Δ_comp 未认证，禁止签发轻量证书")
        return cert_D.inflate(self.Delta_comp)


# ============================================================
# IP-441 Mix-Calibrated Conformal Certificate (MCCC)
# ============================================================
class MixCalibratedConformalCertificate:
    def __init__(self, groups: list[str], alpha: float = 0.01):
        self.groups = groups
        self.alpha = alpha
        self.pi_train: dict = {}
        self.pi_cal: dict = {}
        self.qhat: dict = {g: float("inf") for g in groups}
        self.W_max: Optional[float] = None
        self.UNKNOWN = "__unknown__"

    def declare_mix(self, pi_train: dict, pi_cal: dict):
        """双账本：训练配比只影响活性，校准配比决定覆盖有效性"""
        assert set(pi_cal) == set(self.groups)
        self.pi_train, self.pi_cal = dict(pi_train), dict(pi_cal)

    def n_min(self, alpha_g: float) -> int:
        """使群分位数有限所需的最小样本数（split conformal 指标有效）"""
        return int(math.ceil((1 - alpha_g) / alpha_g)) + 1

    def calibrate(self, D_cal: list[tuple[float, str]]):
        """Mondrian 分组标定：逐群分位数；样本不足 → +inf 保守占用"""
        alpha_g = self.alpha / len(self.groups)     # Bonferroni 同时覆盖
        for g in self.groups:
            scores = sorted(s for s, gg in D_cal if gg == g)
            n_g = len(scores)
            if n_g < self.n_min(alpha_g):
                self.qhat[g] = float("inf")         # 该群永久占用，拒发缺席证书
                continue
            idx = math.ceil((n_g + 1) * (1 - alpha_g)) - 1
            self.qhat[g] = scores[min(idx, n_g - 1)]

    def group_of(self, x) -> str:
        g = classify_group(x)
        return g if g in self.qhat else self.UNKNOWN

    def threshold(self, x) -> float:
        """逐群阈值 + 配比错配校正；未知群一律 +inf"""
        g = self.group_of(x)
        if g == self.UNKNOWN:
            return float("inf")
        q = self.qhat[g]
        if not math.isfinite(q):
            return float("inf")
        if self.W_max is None:
            # 密度比未知：无法校正错配 → 保守占用
            return float("inf") if self.pi_cal != self.pi_train else q
        return q   # 有界密度比下加权 conformal 保证由引理 7 给出

    def coverage_g(self, g: str, D_eval) -> float:
        scores = [s for s, gg in D_eval if gg == g]
        if not scores:
            return 0.0
        return sum(s <= self.qhat[g] for s in scores) / len(scores)

    def group_coverage_ok(self, D_eval) -> bool:
        return all(self.coverage_g(g, D_eval) >= 1 - self.alpha
                   for g in self.groups)

# IP-442 Certificate Complexity Budget (CCB)
# ============================================================
class CertificateComplexityBudget:
    TIERS = ("root", "batched", "per_detection")   # 粗 → 细，越细越贵

    def __init__(self, B_lat: float = 0.020, B_size: int = 1 << 20):
        self.B_lat, self.B_size = B_lat, B_size

    def estimate(self, tier: str, n_det: int) -> tuple[float, int]:
        lat = {"root": 0.001, "batched": 0.003, "per_detection": 0.001 * n_det}[tier]
        size = {"root": 64, "batched": 256 * max(1, n_det // 8),
                "per_detection": 512 * n_det}[tier]
        return lat, size

    def select_tier(self, n_det: int) -> str:
        """从最细到最粗，选第一个满足预算的层级；预算不可行则降到 root"""
        for tier in reversed(self.TIERS):
            lat, size = self.estimate(tier, n_det)
            if lat <= self.B_lat and size <= self.B_size:
                return tier
        return "root"   # 永远可行（只提交 merkle 根）

    def emit(self, certs: dict, n_det: int) -> dict:
        tier = self.select_tier(n_det)
        if tier == "root":
            return {"merkle_root": merkle_root(certs), "tier": tier}
        return {"tier": tier, "proofs": certs}


# ============================================================
# IP-443 Compression–Mix Co-Design Optimizer (CMCO)
# ============================================================
class CompressionMixCoDesign:
    def __init__(self, lcsc: LightweightCompressionCertificate,
                 mccc: MixCalibratedConformalCertificate,
                 ccb: CertificateComplexityBudget):
        self.lcsc, self.mccc, self.ccb = lcsc, mccc, ccb
        self.frontier: list = []

    def solve(self, grid_theta, grid_pi, D_cal, D_eval, eps_D: float):
        """离线 Pareto：max 活性 s.t. 逐群覆盖 ∧ 延迟/体积预算"""
        best = None
        for theta in grid_theta:
            for pi in grid_pi:
                self.mccc.declare_mix(pi, pi)
                self.mccc.calibrate(D_cal)
                if not self.mccc.group_coverage_ok(D_eval):
                    continue
                if not self.lcsc.certify(None, None, theta, D_eval, act_bound=1.0):
                    continue
                lat, size = self.ccb.estimate("per_detection", n_det=8)
                if lat > self.ccb.B_lat or size > self.ccb.B_size:
                    continue
                eps = eps_D + self.lcsc.Delta_comp
                liveness = -eps                      # 误差界越小活性越高
                if best is None or liveness > best[2]:
                    best = (theta, pi, liveness, eps)
        self.frontier.append(best)
        return best   # None → 调用方回退 (稠密, 均匀, 最大 ε)

    def lookup(self, context_key) -> tuple:
        """在线 O(1)：按部署上下文查预解好的 (θ_c, π_cal)"""
        return self.frontier_table.get(context_key, None)

# IP-444 HPC-L 统一四证准入门
# ============================================================
@dataclass
class HPCL:
    hpce: "HPCEPlus"
    lcsc: LightweightCompressionCertificate
    mccc: MixCalibratedConformalCertificate
    ccb: CertificateComplexityBudget

    def admits(self, plan, x, v, z, E_res, margin_req, modules, theta_c) -> bool:
        # 1. v23 基础四证（几何∧规范∧负信息∧能量∧差距∧云边∧少样本∧IP）
        if not self.hpce.admits(plan, x, v, z, E_res, margin_req, modules):
            return False
        # 2. 压缩继承
        if not self.lcsc.certified:
            return False
        # 3. 逐群覆盖
        if not math.isfinite(self.mccc.threshold(x)):
            return False
        # 4. 证书预算
        if not self.ccb.select_tier(len(modules)):
            return False
        return True
```

## 3. 正确性论证

### 引理 5（压缩继承的覆盖搬运）
**陈述**：设稠密模型校准集大小 n，`q̂_D` 为第 `⌈(n+1)(1-α)⌉` 小分数；若 `sup_x |s_L(x)−s_D(x)| ≤ Δ_comp` 以 ≥1-δ 成立，则 `P(s_L(X_test) ≤ q̂_D + Δ_comp) ≥ 1-α-δ`。

**证明**：
1. 逐点有 `s_L(x) ≤ s_D(x) + Δ_comp`（三角不等式）。
2. 在事件 `E_α = {s_D(X_test) ≤ q̂_D}` 上，`s_L ≤ q̂_D + Δ_comp`；由 split conformal 交换性，`P(E_α) ≥ 1-α`。
3. 与事件 `E_δ = {Δ_comp ≥ sup|s_L−s_D|}`（`P≥1-δ`）取交，得 `P(s_L ≤ q̂_D+Δ_comp) ≥ 1-α-δ`。
4. `Δ_comp = min(Δ_struct, Δ_emp)` 两者皆为有效上界，取更紧者仍为上界。∎

### 引理 6（Mondrian 逐群覆盖与样本复杂度）
**陈述**：群内可交换下，群 g 用 `n_g` 个样本在水平 `α_g` 标定的 `q̂_g` 满足 `P(s ≤ q̂_g | G=g) ≥ 1-α_g`；取 `α_g=α/|G|` 时 `P(∀g 覆盖) ≥ 1-α`。当 `n_g ≥ ⌈(1-α_g)/α_g⌉+1` 时 `q̂_g` 有限。

**证明**：
1. 群内独立可交换 ⇒ 群内 split conformal 成立，得 `1-α_g` 覆盖。
2. 对 `|G|` 个群用联合界（Bonferroni）⇒ 同时覆盖概率 `≥ 1-Σα_g = 1-α`。
3. 分位数指标 `⌈(n_g+1)(1-α_g)⌉-1 ≤ n_g-1` 当且仅当 `n_g ≥ (1-α_g)/α_g`，否则指标越界 → 取 `+∞`。∎

### 引理 7（配比错配下的加权覆盖）
**陈述**：若密度比 `w(x)=dP_dep/dP_cal ≤ W_max` 且 `W_max` 已知，加权 split conformal 在 `P_dep` 下覆盖 ≥1-α（有限样本下至多扣 `O(1/√n)` 项）；若 `W_max` 未知或 `π_dep` 与 `π_cal` 不可比，则阈值取 `+∞`，覆盖 =1、活性 =0。

**证明**：
1. 加权 conformal 的覆盖保证由加权可交换性（Tibshirani et al. 2019）直接给出；有界密度比保证权重归一化良定义。
2. 未知/无界时无法构造有效加权测度，唯一无条件有效的阈值是 `+∞`（退化为"假设有人"），安全性优先于活性。∎

### 引理 8（压缩-配比层单调退化链）
**陈述**：任意单点/组合失效下，`Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18` 恒成立。

**证明**：
- LCSC 失效 → 部署稠密模型 → 等价 v23 DCSC，`Exec` 回 v23。
- MCCC 失效（某群 `n_g` 不足/配比未知/群未声明）→ 该群 `q̂_g=+∞` → 缺席证书拒发 → 该群视为"有人"，执行集收缩。
- CCB 超预算 → 降到 `root` 层（只提交 merkle 根）→ 证书更粗更保守，执行集不扩张。
- CMCO 无可行解 → 回退 `(稠密, 均匀, 最大 ε̂)` → 等价 v23。
- 各过滤器均为交集运算，失效方向一致向保守，归纳得链式包含。∎

### 定理（HPC-L 四证准入的安全-活性-可审计完备性）
**陈述**：对任意计划 π，`HPCL.admits(π)=True` ⟺ π 同时满足：
(1) v23 的物理/规范/负信息/能量/云边/少样本/IP 全部条件；
(2) 压缩扰动已被 `Δ_comp` 认证且证书按界膨胀；
(3) 该计划所在群的逐群覆盖 ≥1-α_g（未知群视为不满足）；
(4) 证书生成满足 `B_lat`/`B_size` 预算。

**证明**：直接由 `HPCL.admits` 四连言与引理 5–8。必要性：任一条件缺失即拒证，对应压缩/配比/预算三类风险之一未缓解。充分性：四条件全满足 ⇒ 引理 5 给覆盖搬运、引理 6/7 给逐群覆盖、引理 8 给单调链，构成闭环。∎
