# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC/IP-153~160；灵感循环第 7 轮；本轮灵感：「差异化定位」×「通用操作」）

> 第 60 轮实现了「场景→意图→约束→阻抗→执行→EV-exec→场景更新」的认知驱动闭环，但**三个结构性局限**仍在：
> 1. **证据与先验的「绝对性」**：SSM 用绝对场景先验收敛 K_safe，EEIS 用绝对证据校验执行。然而传感器偏置、重力补偿误差、标定漂移、线缆拖拽等**共模误差**会同时污染先验与证据——「场景识别对了、执行仍然系统性偏」，绝对量纲下无法区分「场景真的变了」与「整套系统一起漂了」。
> 2. **专业化的碎片化**：每新增一个场景就新增一个先验 π_scene(z) 与一组约束 C_intent，技能库随场景线性膨胀、冷启动差、跨场景几乎零复用；缺少一个**通用操作基座**作为「安全地板」和「迁移母体」。
> 3. **知识只进不出**：SERC 只做「场景→约束→阻抗」的正向特化，验证过的特化从未回流为通用能力，同类场景反复从零重学，**泛化通道缺失**。
>
> 本轮借用两个跨域原型解决它们：**差分 GPS（差分定位）**消除共模误差；**通用操作/能力基座（通用操作）**提供安全地板与复用母体。

## 0. 直觉与动机

**灵感 1（差异化定位 → 差分定位 DRP, Differential Reference Positioning）**
直觉：差分 GPS 不用「更准的绝对测量」，而是用一座位置已知的**参考站**。设绝对误差 e = e_c + e_s，e_c 为共模（钟差、电离层），e_s 为本地特异误差；对流动站与参考站做差，e_c 精确抵消，只剩 e_s。映射到操作：维护一组**参考锚** a_i=(任务, 位姿, EV_ref_i, 时刻)，当前执行 EV_t 与最近锚做差 Δ = EV_t ⊖ EV_ref。若两执行共享同一共模误差，则 Δ 只反映「场景/对象差异」。关键洞见：**把「绝对合规」改写为「相对参考的差异化定位」——问的不是「现在偏了多少」，而是「相对锚，差异是什么」**。差分量纲天然免疫共模漂移。

**灵感 2（通用操作 → 通用操作基座 GOS, General Operation Substrate）**
直觉：通用操作不是「万能大招」，而是少数**可组合原语**（reach/contact/press/slide/lift/place/retreat）的闭包。对每个原语取「所有场景下安全参数集的**交集**」：K_gen(p)=∩_{z∈Z} K_safe(p,z)。它一定保守，但具有极强的性质：**无论场景识别是否出错，只要执行落在 K_gen 内就安全**。关键洞见：**通用操作是安全地板（safety floor），差异化定位是性能天花板（performance ceiling）**。先守住地板，再谈加高。

**灵感 3（合流 → 通用-差异双轨闭环 GDOL）**
直觉：系统同时跑「通用轨 G」（场景无关、粗但稳）与「差分轨 D」（锚参照、细但需锚且可能失效）。用一条**通用-差异光谱** s∈[0,1] 连续选择操作点：证据强且锚新鲜→s 升（特化），证据弱或锚老化→s 降（回通用）。两轨不是二选一，而是**同一控制律上的两个端点**。

**灵感 4（差异化定位 → 通用-差异光谱 GSS, General-Specific Spectrum）**
直觉：特化与通用是一对 Pareto 权衡——特化提升单场景精度但降低覆盖，通用提升覆盖但降低精度。定义性能-覆盖曲线 Φ(s)=(perf(s), coverage(s)) 与风险项 risk(s)，操作点 s* 由**差分证据强度**与**差分预算**共同决定。这把第 60 轮离散的「场景置信度阈值 0.7 硬切换」升级为**连续、可微、可预算化**的调度。

**灵感 5（通用操作 → 双向迁移 BTO, Bidirectional Transfer Operator）**
直觉：知识应双向流动。**特化 σ**：通用原语 p 在证据门控下叠加场景特异扩张 ΔK(z)；**泛化 γ**：把在 ≥m 个锚点上验证通过的「扩张规则」压缩成新的通用原语/条件扩张规则。注意泛化必须**保守**——它压缩的是「何时允许扩张的规则」，而不是把安全地板 K_gen 改成并集。这样复用提升，地板不动。

**灵感 6（预算 → 差分认知预算 PCE+++++）**
直觉：差分锚的维护、共模检验、升格验证都要算力/样本。第 60 轮 B_cog=(B_scene,B_intent,B_ros,B_exec) 拓展为六维，新增 **B_diff**（锚数量/新鲜度/差分算力/再锚频率）与 **B_gen**（升格验证样本/原语记忆/降格检查）。B_diff 耗尽⇒s→0 纯通用；B_gen 耗尽⇒停止升格、只保留特化。**任何预算耗尽都只降性能，不降安全地板。**

## 1. 形式化定义（增量：定义 161–168）

**定义 161（差分定位 DRP）** 参考锚集 A={a_i}，a_i=(task_i, z_i, pose_i, EV_ref_i, t_i, fresh_i, valid_i)。差分算子 D(EV,EV_ref)=EV⊖EV_ref（力/位/时间戳对齐后逐分量差）。设执行误差可加分解 e=e_c+e_s。**差分残差** r_t = D(EV_t,EV_ref) − E[D(EV,EV_ref)|z=z_ref]，差分定位后验 p(z|r_t) ∝ p(r_t|z)·p(z)。**差分证书** Cert_diff=(r_t, Cov_r, anchor_id, fresh, α)。

**定义 162（通用操作基座 GOS）** 原语集 P={reach, contact, press, slide, lift, place, retreat}，组合闭包 P*。每原语 p 的**通用契约** K_gen(p)=∩_{z∈Z} K_safe(p,z)；组合契约保守合成 K_gen(p1∘p2)⊆K_gen(p1)∩K_gen(p2)。**通用证据** EV_gen 只依赖原语与契约、与场景无关。核心不变式：∀z, K_gen(p)⊆K_safe(p,z)。

**定义 163（通用-差异光谱 GSS）** 光谱参数 s∈[0,1]：s=0 纯通用，s=1 纯差分。性能-覆盖曲线 Φ(s)=(perf(s), coverage(s))，perf 单调↑、coverage 单调↓。操作点 s* = argmax_s [w_p·perf(s)+w_c·coverage(s)−λ·risk(s)]，且 s* 对差分证据强度单调非减、对预算余量单调非增。

**定义 164（双向迁移算子 BTO）** 特化 σ:(p_gen,z)→p_diff(z)，在 K_gen 之上叠加门控扩张 ΔK(z)，须 Cert_diff 通过。泛化 γ:(p_diff(z₁..z_k),V_val)→rule_gen，把「≥m 锚点、residual≤δ_promo、无安全违规」的扩张压缩为**条件扩张规则**并入 P。降格：新锚上 residual 超阈或安全违规⇒撤销该规则并把该场景 s 下调。BTO 只改「规则集合」，**永不把 K_gen 改为并集**。

**定义 165（差分证据 DEV）** EV_diff=(r, Cov_r, anchor, CM_test, SNR_diff)，SNR_diff=‖r‖²/tr(Cov_r)。**共模检验** CM_test：注入已知探针 δ_probe，验证 D(e_c)≈0；不通过则差分不可用、s 强制回 0。差分 ECE 记为 D-ECE。EV_diff 是 EV-exec 的「参照系变换」，可直接喂给第 60 轮 EPIR。

**定义 166（通用-差分闭环 GDOL）** 算子 GDOL(M, task, scene_obs, intent, budgets)：
```
① RAM.select_anchor(task, scene_obs) → a*
② CM_test(a*)：共模假设是否成立？否 ⇒ s=0 走通用轨
③ DRP：r = D(EV_prev, EV_ref[a*])；更新 p(z|r)
④ GSS：s* = select_operating_point(SNR_diff, freshness, B_diff, B_gen)
⑤ if s* 高：K_expand = EEIS.compile_with_diff(r, ...) ∩ hard_cap(K_gen)
   else：K = K_gen
⑥ 复用第 60 轮：SSM 先验 + CIEC 意图锁定 + ERTC 约束
⑦ Execute(general_track ∥ differential_track) → telemetry
⑧ EV_exec ← build_exec_evidence(...)；EV_diff ← DEV(EV_exec, a*)
⑨ EPIR.append(EV_exec)；SIC/XMC+ 更新（第 60 轮）
⑩ BTO：promote/demote(residual, validation)；更新 RAM fresh/valid
⑪ 更新预算；Return (s*, K, EV_diff, Cert_diff, state)
```

**定义 167（参考锚管理 RAM）** 锚新鲜度 fresh=exp(−(t−t_a)/τ_anchor)；选择 a*=argmin cost_anchor s.t. CM_test(a*)=pass ∧ fresh≥θ_f；连续 k 次 CM_test 失败或 fresh<θ_f 则**退休**并触发 re-anchor（执行已知探针重建锚）。锚池大小受 B_diff.anchor_budget 约束，LRU 淘汰但保留至少一个「全局最稳锚」。

**定义 168（差分认知预算 PCE+++++）** B_cog'=(B_scene,B_intent,B_ros,B_exec,B_diff,B_gen)，其中 B_diff=(anchor_budget, reanchor_freq, diff_compute)，B_gen=(promotion_samples, primitive_memory, demotion_checks)。VOI 扩展：
```
voi = VOI_meta_pessimistic − cost_cog − cost_exec − cost_diff(a) − cost_gen(p)
cost_diff = λ_anchor·Maintain(a) + λ_cm·CM_test(a) + λ_dc·‖r‖_0
cost_gen  = λ_promo·Validation(p) + λ_mem·|P|
```
若 B_diff<θ_diff ⇒ s→0 纯通用；若 B_gen<θ_gen ⇒ 停止升格、仅特化；二者均不改变 K_gen 安全地板。

## 2. 关键算法伪代码

### IP-161 DRP（差分定位）
```python
class DifferentialReferencePositioning:
    def __init__(self, anchors, tau_anchor=600.0, alpha=0.01):
        self.anchors = anchors          # id -> Anchor(task, scene, pose, EV_ref, t)
        self.tau_anchor = tau_anchor
        self.alpha = alpha

    def freshness(self, a, now):
        return math.exp(-(now - a.t) / self.tau_anchor)

    def select_anchor(self, task, scene_obs, now):
        cand = [a for a in self.anchors.values()
                if a.task == task and a.valid
                and self.freshness(a, now) >= self.theta_f
                and self.cm_test(a)]
        return min(cand, key=lambda a: scene_distance(a.scene, scene_obs))

    def difference(self, ev, a):
        ev_a = align_time(ev, a.EV_ref)      # 时间戳/位姿对齐
        r = componentwise_sub(ev, a.EV_ref)
        r -= self.delta_prior[a.id]          # 减去参考场景的期望差分
        return Extra(r=r, Cov_r=a.Cov_ref + covariance(ev),
                     anchor=a.id, fresh=self.freshness(a, now=time.time()))

    def cm_test(self, a, probes=None):
        # 注入已知探针，检验共模可加性：D(e_c) 应约等于 0
        resid = [norm(self.difference(p, a).r) for p in (probes or a.probes)]
        return max(resid, default=0.0) <= self.eps_cm
```

### IP-162 GOS（通用操作基座）
```python
class GeneralOperationSubstrate:
    PRIMITIVES = ['reach','contact','press','slide','lift','place','retreat']

    def __init__(self, scene_set):
        self.scene_set = scene_set
        self.K_gen = {p: self._intersect_all_scenes(p) for p in self.PRIMITIVES}

    def _intersect_all_scenes(self, p):
        sets = [K_safe(p, z) for z in self.scene_set]
        return reduce(intersect_envelope, sets)   # ∩：跨场景安全的地板

    def compose(self, p1, p2):
        K = intersect_envelope(self.K_gen[p1], self.K_gen[p2])
        return Primitive(f'{p1}∘{p2}', K, evidence=EV_gen)

    def execute_general(self, p, state):
        assert in_envelope(state.K, self.K_gen[p])  # 地板不变式
        return run_primitive(p, self.K_gen[p], state)
```

### IP-163 GSS（通用-差异光谱）
```python
def select_operating_point(snr_diff, freshness, budget, cfg):
    evidence = sigmoid(cfg.a * snr_diff) * freshness
    cap = 1.0 if budget.B_gen_ok else 0.5      # 无升格预算则不冲到全差分
    s = evidence * cap
    return clip(s, 0.0, 1.0)

def spectrum_decision(s, K_gen, K_expand, hard_cap):
    if s <= cfg.s_low:                 return K_gen
    blend = convex_blend(K_gen, K_expand, s)
    return intersect_envelope(blend, hard_cap(K_gen))   # 绝不越出硬上限
```

### IP-164 BTO（双向迁移）
```python
class BidirectionalTransferOperator:
    def specialize(self, p_gen, z, cert_diff, s):
        if s < self.s_min or not cert_diff.passed(self.alpha):
            return p_gen                              # 证据不足不特化
        dK = scene_expansion(z) * s
        return Primitive(p_gen.name, intersect_envelope(p_gen.K, dK),
                         gate=('diff', cert_diff.anchor))

    def generalize(self, p_diffs, anchors, val_set):
        ok = [p for p in p_diffs
              if self.residual(p, anchors) <= self.delta_promo
              and self.no_violation(p)]
        if len(ok) < self.m_promo:
            return None                               # 样本不足，拒绝升格
        rule = compress_rule(ok)                      # 只压缩「扩张规则」
        assert safe_floor_unchanged(rule, self.K_gen) # 地板不变式
        return rule
```

### IP-165 DEV / IP-166 GDOL（差分证据 + 双轨闭环）
```python
def differential_evidence(ev, anchor, drp):
    d = drp.difference(ev, anchor)
    snr = norm(d.r)**2 / trace(d.Cov_r)
    return ExtraEvidence(r=d.r, Cov_r=d.Cov_r, anchor=anchor.id,
                         CM_test=drp.cm_test(anchor), SNR_diff=snr)

def general_differential_loop(M, task, scene_obs, intent):
    a = M.ram.select_anchor(task, scene_obs)
    if a is None or not M.ram.cm_test(a):
        return general_track(M, task, intent)         # 地板轨
    r = M.drp.difference(M.last_ev, a)
    s = select_operating_point(snr(r), M.ram.freshness(a),
                               M.budget, M.cfg)
    K = spectrum_decision(s, M.gos.K_gen[task],
                          M.eeis.compile_with_diff(r, M.delta_f_req),
                          M.cfg.hard_cap)
    M.ertc.lock_constraints(M.ciec.map(intent))       # 第 60 轮 CIEC
    ev = M.execute_and_build_evidence(K)
    ev_diff = differential_evidence(ev, a, M.drp)
    M.epir.append(ev)                                  # 第 60 轮 EPIR
    M.bto.specialize(M.gos.K_gen[task], scene_obs.scene, ev_diff.cert, s)
    if M.bto.generalize(M.recent_diff_skills(), M.ram.anchors, M.val_set):
        M.budget.B_gen -= 1
    return M, s, ev_diff
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DRP | O(|A|) 锚选择 / O(dim) 差分 | O(|A|·dim) | 共模消除比 CMCR ≥ 3×（SNR 提升），定位误差 ↓≥40% |
| GOS | O(|P|·|Z|) 预编译，O(1) 查询 | O(|P|·dim) | 地板不变式 ∀z: K_gen⊆K_safe(z)，零越界 |
| GSS | O(1) | O(1) | s* 对证据单调、对预算单调；扩张受 hard_cap |
| BTO | O(m) 升格验证 | O(|P|) | 升格精度 ≥95%；泛化不改变安全地板 |
| GDOL | O(闭环) | 复用 | 端到端安全违规 = 0，样本效率 ↑≥50% |

**引理 1（共模消除）** 若 e=e_c+e_s 且两执行共享同一 e_c，则 D 后 e_c 精确抵消；若 e_c 弱相关（相关系数 ρ_c），残余共模 ≤ (1−ρ_c)·‖e_c‖。
**引理 2（安全地板）** 由 K_gen(p)=∩_z K_safe(p,z) 得 ∀z: K_gen⊆K_safe(z)；故任何落在 K_gen 内的执行与场景识别、差分正确性**无关地安全**。
**定理（SGDO 安全特化）** 假设 A66–A70 成立：**(A66)** CM_test 以 ≥1−β 概率正确判定共模可加性；**(A67)** 锚新鲜度门控排除陈旧锚；**(A68)** 硬上限 K_expand⊆hard_cap(K_gen)；**(A69)** BTO 升格仅在 ≥m 锚点、residual≤δ_promo、无违规时发生；**(A70)** GSS 的 s* 单调受预算约束。则：
1. **安全特化**：误扩张（进入真实不安全区）概率 ≤ α+β+P(stale)，且由于 K_gen 地板不变，最坏情形退化为通用轨的安全性。
2. **知识回流**：升格后被压缩的规则使同类场景的特化收敛接触数期望下降 ≥ (1−δ_promo)；泛化不放松地板，故复用增益不牺牲安全性。
3. **预算单调**：B_diff 或 B_gen 耗尽⇒s 单调下降至纯通用，性能退化有界。
4. **差分可信性**：CM_test 失败即 s=0，差分证据不得单独作为扩张依据。

## 5. 本轮最大风险

**一句话**：差分定位的致命假设是「锚与当前执行共享同一共模误差」——一旦锚老化、或共模误差其实是**场景相关**的（共模可加性失效），差分不仅不抵消反而会放大误差，GSS 会据此把安全地板向上扩张，产生「高置信的越界执行」；必须以 CM_test 探针检验、锚新鲜度门控、K_expand 的硬上限（≤κ·K_gen）、以及「泛化只压缩扩张规则、永不重画地板」四重护栏，确保差分永远只能在地板之上谨慎加高，绝不能重画地板。

## 2. 关键算法伪代码

### IP-161 DRP（差分定位）
```python
class DifferentialReferencePositioning:
    def __init__(self, anchors, tau_anchor=600.0, alpha=0.01, eps_cm=1e-2):
        self.anchors, self.tau_anchor = anchors, tau_anchor
        self.alpha, self.eps_cm = alpha, eps_cm

    def freshness(self, a, now):
        return math.exp(-(now - a.t) / self.tau_anchor)

    def select_anchor(self, task, scene_obs, now):
        cand = [a for a in self.anchors.values()
                if a.task == task and a.valid
                and self.freshness(a, now) >= self.theta_f
                and self.cm_test(a)]
        return min(cand, key=lambda a: scene_distance(a.scene, scene_obs))

    def difference(self, ev, a):
        r = componentwise_sub(align_time(ev, a.EV_ref), a.EV_ref)
        r -= self.delta_prior[a.id]          # 减去参考场景的期望差分
        return Diff(r=r, Cov_r=a.Cov_ref + covariance(ev), anchor=a.id,
                    fresh=self.freshness(a, time.time()))

    def cm_test(self, a, probes=None):
        resid = [norm(self.difference(p, a).r) for p in (probes or a.probes)]
        return max(resid, default=0.0) <= self.eps_cm   # 共模可加性检验
```

### IP-162 GOS（通用操作基座）
```python
class GeneralOperationSubstrate:
    PRIMITIVES = ['reach','contact','press','slide','lift','place','retreat']

    def __init__(self, scene_set):
        self.K_gen = {p: self._intersect_all(p, scene_set) for p in self.PRIMITIVES}

    def _intersect_all(self, p, scene_set):
        return reduce(intersect_envelope, [K_safe(p, z) for z in scene_set])

    def compose(self, p1, p2):
        K = intersect_envelope(self.K_gen[p1], self.K_gen[p2])
        return Primitive(f'{p1}∘{p2}', K, evidence=EV_gen)

    def execute_general(self, p, state):
        assert in_envelope(state.K, self.K_gen[p])   # 地板不变式
        return run_primitive(p, self.K_gen[p], state)
```

### IP-163 GSS（通用-差异光谱）
```python
def select_operating_point(snr_diff, freshness, budget, cfg):
    evidence = sigmoid(cfg.a * snr_diff) * freshness
    return clip(evidence * (1.0 if budget.B_gen_ok else 0.5), 0.0, 1.0)

def spectrum_decision(s, K_gen, K_expand, hard_cap):
    if s <= cfg.s_low:
        return K_gen
    return intersect_envelope(convex_blend(K_gen, K_expand, s), hard_cap(K_gen))
```

### IP-164 BTO（双向迁移）
```python
class BidirectionalTransferOperator:
    def specialize(self, p_gen, z, cert_diff, s):
        if s < self.s_min or not cert_diff.passed(self.alpha):
            return p_gen
        return Primitive(p_gen.name,
                         intersect_envelope(p_gen.K, scene_expansion(z) * s),
                         gate=('diff', cert_diff.anchor))

    def generalize(self, p_diffs, anchors, val_set):
        ok = [p for p in p_diffs if self.residual(p, anchors) <= self.delta_promo
              and self.no_violation(p)]
        if len(ok) < self.m_promo:
            return None
        rule = compress_rule(ok)
        assert safe_floor_unchanged(rule, self.K_gen)   # 永不重画地板
        return rule
```

### IP-165 DEV / IP-166 GDOL（差分证据 + 双轨闭环）

def differential_evidence(ev, anchor, drp):
    d = drp.difference(ev, anchor)
    return ExtraEvidence(r=d.r, Cov_r=d.Cov_r, anchor=anchor.id,
                         CM_test=drp.cm_test(anchor),
                         SNR_diff=norm(d.r)**2 / trace(d.Cov_r))

def general_differential_loop(M, task, scene_obs, intent):
    a = M.ram.select_anchor(task, scene_obs)
    if a is None or not M.ram.cm_test(a):
        return general_track(M, task, intent)            # 地板轨
    r = M.drp.difference(M.last_ev, a)
    s = select_operating_point(snr(r), M.ram.freshness(a), M.budget, M.cfg)
    K = spectrum_decision(s, M.gos.K_gen[task],
                          M.eeis.compile_with_diff(r, M.delta_f_req), M.cfg.hard_cap)
    M.ertc.lock_constraints(M.ciec.map(intent))          # 第 60 轮 CIEC
    ev = M.execute_and_build_evidence(K)
    ev_diff = differential_evidence(ev, a, M.drp)
    M.epir.append(ev)                                     # 第 60 轮 EPIR
    M.bto.specialize(M.gos.K_gen[task], scene_obs.scene, ev_diff.cert, s)
    if M.bto.generalize(M.recent_diff_skills(), M.ram.anchors, M.val_set):
        M.budget.B_gen -= 1
    return M, s, ev_diff

class ReferenceAnchorManager:
    def retire(self):
        return [a for a in self.anchors.values()

class DifferentialCognitiveBudget:
    def __init__(self, anchor_budget=8, reanchor_freq=3,
                 promotion_samples=20, primitive_memory=64):
        self.B_diff = DifferentialBudget(anchor_budget, reanchor_freq)

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| DRP | O(|A|) 选锚 / O(dim) 差分 | O(|A|·dim) | CMCR ≥3×；定位误差 ↓≥40% |
| GOS | O(|P|·|Z|) 预编译 / O(1) 查询 | O(|P|·dim) | 地板不变式，零越界 |
| GSS | O(1) | O(1) | s* 单调；扩张受 hard_cap |
| BTO | O(m) 升格验证 | O(|P|) | 升格精度 ≥95%；地板不变 |
| GDOL | O(闭环) | 复用 | 违规 = 0；样本效率 ↑≥50% |

**引理 1（共模消除）** 共享 e_c 精确抵消；弱相关时残余 ≤ (1−ρ_c)‖e_c‖。
**引理 2（安全地板）** ∀z: K_gen⊆K_safe(z)，故 K_gen 内执行与场景识别/差分正确性无关地安全。
**定理（SGDO 安全特化）** 若 A66–A70 成立（CM_test 正确性、锚新鲜度、硬上限、升格验证、预算单调），则：
1. 误扩张概率 ≤ α+β+P(stale)，最坏退化为通用轨安全性；
2. 升格规则使同类场景特化收敛接触数期望下降 ≥(1−δ_promo)，且不放松地板；
3. B_diff/B_gen 耗尽⇒s 单调降至纯通用，性能退化有界；
4. CM_test 失败⇒s=0，差分证据不得单独作为扩张依据。

## 5. 本轮最大风险

**一句话**：差分定位的致命假设是「锚与当前执行共享同一共模误差」——一旦锚老化、或共模误差其实是场景相关的（共模可加性失效），差分不仅不抵消反而会放大误差，GSS 会据此把安全地板向上扩张，产生「高置信的越界执行」；必须以 CM_test 探针检验、锚新鲜度门控、K_expand 的硬上限（≤κ·K_gen）、以及「泛化只压缩扩张规则、永不重画地板」四重护栏，确保差分永远只能在地板之上谨慎加高，绝不能重画地板。
