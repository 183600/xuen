## 1. 直觉与动机（两个灵感的碰撞）

### 灵感 1 · 竞品分析：竞争地形是三层同心圆，白地在最外圈

**直觉**：绝大多数队伍会挤在圆心——下载官方 UnifoLM-WLA-1.0、在 32 任务上微调、再撒一点通用增广，比的是「标称场景能不能做」。圆心之外有两圈几乎无人：中圈是「按泛化轴做定向工程」，外圈是「读透规则的目标对齐 + 可信交付」。竞品的**共享失败模式**（同一基线、同一相机布局、同一 VLM 偏置）是公共软肋——它们可被离线复现、被定向修复；修一个公共软肋，等于同时超过所有同源队伍。

**严谨定义（竞品分层）**：按「主要投入方向」把参赛者划分为 L1–L5，估计各层占比与软肋（见 §2）。定位定理：在榜单只取前若干名、且前沿极低时，**排名收益 ≈ 改进量 × (1 − 该改进被竞品覆盖的比例 κ)**。因此最优投入不是「做最强的通用模型」，而是「在 κ 最低、且可达的格子上做增量」。这把「竞品分析」从叙事变成了一个可估计的量 κ_a。

### 灵感 2 · 痛点分析：分数是按「轴」漏的，不是按「任务」漏的

**直觉**：大家默认痛点是「32 个任务里哪个最弱」，但榜单的计分单元其实是「任务 × 泛化轴」——每个任务固定 5 轴各 2 次。把泛化当一个总开关，就会在「位置/背景」这种人人都会的轴上内卷，却在「人为干扰/未见物品」这种别人放弃的轴上挂零。痛点必须按 (任务, 轴) 格子排序，而不是按任务排序。

**严谨定义（计分分解）**：设 `x_{i,a,r}∈{0,1}` 为任务 i、轴 a、重复 r 的成功指示，`s_i=(1/10)Σ_{a,r}x_{i,a,r}`，则

`S = (1/32)Σ_i s_i = (1/5)Σ_a S_a`，其中 `S_a=(1/32)Σ_i (1/2)Σ_r x_{i,a,r}`。

即**总分就是 5 个轴成功率的算术平均，每轴权重恒为 1/5=20%**（F22）。由此两个推论：①任何轴的边际权重相同，故投入排序只由「可达性 Δp_a / 成本 c_a」和「竞品覆盖 κ_a」决定，与任务强弱无关；②**目标错位痛点**——步骤分只是并列次级键（F20），把「过程分/部分进度」当主攻（前序 I5 的隐含假设）在词典序下边际价值极低，除非已锁定成功率并列。

### 统一：低前沿赛区的「轴预算」博弈

**直觉**：外部最强约 12.8%（F25），本赛榜首 <30%（用户上下文），说明前沿极低、大量任务接近零。此时「把某一轴从 0 打到高成功率」的绝对收益远大于「把已会任务从 80 抬到 90」。竞争的主战场不是平均水平的微调，而是**把别人放弃的整块轴吃下来**。

**严谨上界**：由 F22，若轴 a 从 0→100% 而其余不变，则 `ΔS = 0.2 = +20pp`（理想上界）。对照 12.8% 的外部前沿，**赢下一个白地轴 ≈ 把总分翻倍**。这是本轮的核心量化依据。

**本轮论点（对前序的修正）**：前序循环结论是「中期胜负手在数据引擎」。本轮修正为：**数据引擎（I2）是燃料，轴预算（I10）才是方向盘**；决定名次的是「把燃料加到哪一格」，以及「是否读对了词典序目标」。据此，人为干扰轴（I4 升级）与未见物品轴（I9 升级）成为主攻，步骤分工程（I5）降级为并列对冲。

## 2. 竞品分层与定位

| 层级 | 典型做法 | 估计占比 | 强项 | 软肋（可攻击点） |
|---|---|---|---|---|
| L1 基线微调派 | 微调官方 WLA-1.0，标称数据为主 | ~60% | 上手快、标称尚可 | 5 轴泛化全线弱；共享基线失败模式 |
| L2 增广派 | 视觉/物理随机增广，无考纲校准 | ~25% | 位置/背景轴较好 | 过度随机化；干扰/未见轴仍弱 |
| L3 换模型派 | 引入 π0/GR00T/OpenVLA 等 | ~10% | 模型新 | 放弃官方 110 孪生语料；延迟/算力风险 |
| L4 系统派 | 重 serving、延迟、稳定性 | ~5% | 交付稳 | 策略能力一般，轴覆盖低 |
| L5 规则洞察派 | 读透词典序 + 轴分解，定向攻白地 | **<5%** | 目标对齐、ROI 高 | 需要严格实验纪律 |

**定位结论**：白地 = `L5 的规则对齐` ∩ `L2 的轴级增广` ∩ `L4 的可信交付`。我们不去 L1 的圆心内卷，也不做 L3 的换模型豪赌；我们做「**规则对齐的轴级组合策略**」：用低成本基座守住位置/背景，把机动预算全压在竞品覆盖最低的「人为干扰」与「未见物品」两轴，并以可信交付兜底。

**共享失败模式论证**：L1/L2 同源，故其失败高度相关。只要用官方基线在留出集上做 canary，就能离线聚类出「透明/反光抓取失败、遮挡后丢失、指令歧义、被移动后不重规划」等公共失败簇。修复这些簇的排名收益 ≈ `(1−κ_cluster)·ΔS_cluster`，这正是新增 I11 的依据。

# UniBot-V1 参赛方案 v2.0（第 1 轮 · 竞品/痛点视角）

> 检索日期 2026-11-27；承接 v1.1（F1–F19、I1–I9）。三条硬修正：①榜单是**词典序**，成功率优先、步骤分仅并列次级键（F20）；②每任务 10 次 = 5 轴各 2 次，故**每轴恰好 20%**（F22）；③**单模型硬约束**，禁止按任务混用多模型（F24）。方案只重排与增量，不重置遗产。

## 0. 一页结论（先看这个）

- **计分真相**：`S = (1/5)Σ_a S_a`，五轴等权；步骤分只在成功率并列时起作用。→ 不要把「部分进度」当主攻。
- **低前沿**：外部最强约 12.8%（F25），本赛榜首 <30%。单轴 0→100% 的理想上界是 **+20pp**，足以翻倍。→ 赢下一个别人放弃的轴，胜过把已会任务磨亮。
- **竞品白地**：人为干扰重规划、未见物品检索、规则对齐、可信交付。位置/背景是人人内卷的「必守基座」，不是差异化来源。
- **主押组合**：`I10 轴预算+规则对齐` × `I4' 人为干扰重规划` × `I9 未见物品检索`，用 `I1` 守基座、`I6` 保可信交付。
- **最大风险**：轴可独立处理的假设；若轴强耦合或干扰轴不可学，则组合收益被高估。

## 1. 形式化模型

### 1.1 计分分解（严谨定义）

设任务 `i∈[32]`、轴 `a∈A={pos,dis,bg,un,hum}`、重复 `r∈{1,2}`，成功指示 `x_{i,a,r}∈{0,1}`。

- 单任务成功率：`s_i = (1/10) Σ_{a,r} x_{i,a,r} = (1/5) Σ_a s_{i,a}`，其中 `s_{i,a}=(1/2)Σ_r x_{i,a,r}`
- 总分：`S = (1/32) Σ_i s_i = (1/5) Σ_a S_a`，其中 `S_a=(1/32)Σ_i s_{i,a}`

**结论**：总分是 5 个轴成功率的算术平均；每轴权重恒为 `1/5`。因此任一轴的边际权重相同，投入排序只取决于「可达增量 / 成本」与「竞品覆盖」，与任务强弱无关。

### 1.2 词典序目标与步骤分对冲

榜单排序键为 `Rank = lexicographic(S, T)`，`T=(1/32)Σ_i t_i` 为平均步骤分（F20）。于是：

- 主目标：`max S`。
- 次目标：仅在 `ΔS=0` 时用 `T` 破并列。
- **门控约束（PR7）**：任何步骤分模块只在「不降低 S」时启用；`ΔS<0 ∧ ΔT>0` 一律否决。

这直接否决了「为了过程分牺牲成功率」的做法，也把前序 I5 从主攻降为并列对冲。

### 1.3 轴 ROI、竞品覆盖与组合优化

- 轴可达增量 `Δp_a`，成本 `c_a`（工程+算力+真机）。
- 绝对效率：`ROI_a^abs = (Δp_a/5)/c_a`。
- 排名效率（差异化）：`ROI_a^rank = (Δp_a/5)(1−κ_a)/c_a`，`κ_a∈[0,1]` 为竞品覆盖比例。
- **两桶预算**：先用基座预算 `B0` 把 `pos/bg` 打到与竞品持平（避免被拉开），再把机动预算 `B1` 全给 `argmax ROI^rank`（预期 `hum/un`）。若 `p_a` 边际递减，则按等边际 `Δp_a(1−κ_a)/c_a` 做注水（water-filling）。

**理想上界**：`S_a: 0→1 ⇒ ΔS=0.2`。这是「攻白地」策略的定量理由，也是其风险来源（见 §5）。

### 1.4 单模型约束下的实现（F24）

F24 禁止「任务 A 用模型 1、任务 B 用模型 2」。因此「轴级组合」必须是**同一模型内**的条件化：

- 任务条件：由 `observation.language` 产生任务嵌入，驱动共享主干 + 轻量任务适配（LoRA/Adapter 专家，属同一模型的混合，不实例化多个独立模型）。
- 轴适配：把轴视为训练/推理时的软条件（增广标记、检索先验、重规划状态机），不改模型数量。
- I9 检索索引、I3 关键点伺服是**同一 PolicyService 内的辅助组件**，非第二策略；仍需按 PR2 向组委会书面确认「单模型」边界。

### 2.1 轴级评测与组合调度（I10）

```python
AXES = ["pos", "dis", "bg", "un", "hum"]
W = 1.0 / 5.0

def axis_profile(model, tasks, debug_env, augmentor):
    # 不计分单任务通道（F23）+ 离线增广，估计 p[task][axis]
    P = {}
    for t in tasks:
        for a in AXES:
            p_off = augmentor.estimate(model, t, a)     # 离线代理，免费无限次
            p_real = debug_env.probe(model, t, a, n=2)  # 少量真机校准（不计分）
            P[t, a] = 0.7 * p_off + 0.3 * p_real
    return P

def rank_coverage(P, history):
    # kappa[a]：该轴上竞品预计也做好的比例；有 Runs 视频后用实测回填
    kappa = {a: estimate_competitor_coverage(a, history) for a in AXES}
    return kappa

def allocate(P, kappa, cost, B0, B1):
    base = ["pos", "bg"]                      # 必守基座，防被拉开
    score = lambda a: (delta_p(P, a) * (1 - kappa[a])) / cost[a]
    order = sorted(AXES, key=score, reverse=True)
    discretionary = [a for a in order if a not in base]
    return {"base": base, "base_budget": B0,
            "attack": discretionary, "attack_budget": B1}
```

### 2.2 人为干扰重规划（I4'，主攻）

```python
RECOVER_BUDGET = 0.2 * 180.0   # 从 180s 中预留 ~36s 用于恢复（F21）

def step_with_replanning(obs, st, policy):
    obj_now = localize(obs, st.target_desc)
    moved = pose_dist(obj_now, st.last_obj_pose) > TAU_MOVE
    human = detect_hand(obs) or motion_anomaly(obs)
    if moved or human:
        st.mode = "RECOVER"
        st.target_pose = obj_now          # 重定位：以当前观测为准
        st.t0 = now()
    if st.mode == "RECOVER":
        if now() - st.t0 > RECOVER_BUDGET:
            return safe_stop(obs)         # 超预算：安全停，保住动作可信度
        return policy.replan_from_current(obs, st)   # 从当前态续做，不从头
    return policy.chunk(obs)
```

关键：不是「停持让位」而是「**从当前态续做**」；`replan_from_current` 可复用 I9 检索到的恢复段先验，避免从零探索。

### 2.3 共享失败模式审计（I11，竞品差异化）

```python
def mine_failures(baseline, val_set):
    fails = []
    for ep in val_set:
        if not baseline.succeeds(ep):
            fails.append((ep.task, ep.axis, failure_signature(ep)))
    clusters = cluster(fails, key=lambda f: f[2])   # 视觉/语义失败签名
    def rank_gain(cl):
        # 修复该簇的边际排名收益：竞品覆盖越低、涉及轴权重越大越值
        return (1 - kappa[cl.axis]) * (len(cl) / len(val_set)) * (1/5)
    return sorted(clusters, key=rank_gain, reverse=True)
```

`failure_signature` 示例：透明/反光、薄边、遮挡丢失、指令歧义、被移动未重规划。Runs 页开放后（F26）用竞品视频回填 `kappa` 与簇分布。

### 2.4 未见物品检索（I9，主攻；承 v1.1）

```python
class RetrievalAugmentedPolicy:          # 同一 PolicyService 内的辅助记忆
    def reset(self):
        self.prior = None                # 每 episode 一次（F18 承前）
    def get_action(self, obs):
        if self.prior is None:
            obj = detect(obs, self.lang)  # 开放词汇检测首帧目标
            emb = embed(obj.crop)         # DINOv2/VLM 嵌入
            hit = self.index.search(emb, k=3)   # 110 语料物体-技能库

                self.prior = hit.action_params  # 软先验：开度/接近高度/朝向/技能模式
        return self.vla.chunk(obs, prior=self.prior)
```

## 5. 风险登记与合规

| 风险 | 触发条件 | 缓解 |
|---|---|---|
| 轴强耦合，分解失效（**最大风险**） | E0 显示 `p_{i,a}` 对轴不可分离、交互显著 | 退化为「按任务簇」而非按轴；改用任务簇 ROI 分配 |
| 干扰轴不可学（无力/触觉） | E2 的 `p_hum` 提升 <1.3× | 只保留「检测→安全停」兜底，预算转 I9/干扰物轴 |
| 未见物品检索误命中 | 标称场景 `Δp<0` | 距离阈值门控 + 软先验；超阈退回无先验 |
| 单模型边界（F24） | I9/I3 辅助组件被裁定为多模型 | 降级为训练时辅助监督（I3'）或去掉独立嵌入器，用主干特征 |
| 可信度（F27） | 延迟抖动/动作异常 | 延迟平滑、动作正则、p99 监控；每次提交过 PR4 门禁 |
| 步骤分工程反噬 | 为 T 牺牲 S | PR7 硬门控：`ΔS<0` 一律否决 |
| 得分点未知（F30） | wiki 不可达 | 先用终态成功标签，步骤分只做对冲，不阻塞主链 |

**合规 checklist**：①同一模型完成全部任务（F24）；②评测期不做在线学习/权重更新（I9 仅推理）；③N 端口独立状态（F28）；④动作健康度与延迟稳定（F27）；⑤数据许可内使用并注明来源。
