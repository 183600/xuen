# 第 69 轮（承接第 68 轮「CALM-RAS」IP-243~252；本轮灵感：「多机评测」×「情感计算」）

> 第 68 轮把「标定」升为一等公民，补上了计量层，并在结尾自陈了它的原罪：**单一机器的自标定不可证伪**——若缓变故障恰好落在标定带宽内，COF 会把它当漂移「标好」，系统在「测量越来越准」的假象中失去对慢故障的检出（R68 最大风险）。这个风险无法在单机内解决，因为「解释掉残差」与「消除故障证据」在单机帧内是同一件事。
>
> 本轮两个灵感恰好提供了「单机之外」的坐标系：
> - **多机评测**：评测的可信度不来自单个评测者的自洽，而来自多个独立评测者的**冗余与分歧**。单机可以自圆其说；留一机预测（leave-one-machine-out）的外部残差无法被本机标定吸收——这是 R68 缺失的「伪证者」。
> - **情感计算**：情感不是可直接读出的物理量，而是带误差的**潜构念（latent construct）**；它的可评估量不是「正确率」，而是**信度（reliability / generalizability）**。多机 = 多评分者，正好落进心理测量学的 G 理论框架。
>
> 一句话命题：**把「测量可信度」从单机内省（R68 的自标定）升级为「多机外部证伪 + 心理测量学信度证书」，并让信度本身充当风险自适应闭环的安全门——FAME-RAS（Fleet-level Affective Measurement Evaluation for RAS：多机评测 × 情感计算的风险自适应闭环）。**
>
> 一句话定位：R68 问「我的测量还准吗」，R69 追问「**凭什么相信这句自评**」——只有当多机冗余与信度证书同时背书时，情感通道才被允许放宽安全约束。

## 0. 直觉与动机

**灵感 1（多机评测 → 自洽不是真值，冗余才是）**
直觉：一个人说「我没问题」不构成证据；十个独立观察者里九个不同意，才构成证据。R68 的 COF 本质上是「本机自评」：只要标定参数能把残差解释掉，系统就认为测量变准了。但可解释性不等于正确性——过参数化的标定能吸收任何慢变残差，包括真实故障。多机评测把「自评」换成「他评」：把机 i 从舰队里拿掉，用其余机器对同一交互的共同潜状态去**预测机 i 应该看到什么**，预测残差就是机 i 的外部证伪量。本机能改写自己的标定，却改不了别人对它的预测。这就是把 R68 的「不可证伪」变成「可证伪」。

**灵感 2（情感计算 → 情感是潜构念，不是标签）**
直觉：情感标注的分歧不是纯噪声，而是构念本身的性质——同一张脸，不同评分者、不同文化、不同时刻读出的情感不同。因此「情感模型准确率 92%」是个伪指标；真正该问的是：**在目标人群与部署机队上，这个情感读数的方差里有多少是可泛化的真信号？** G 理论把观测方差分解成人（person）、机（machine）、时机（occasion）及其交互，给出泛化力系数。这就是「这句话有多可信」的量化证书。R68 用 U(ĉ) 表达「传感器准不准」，R69 用 (1−Φ) 表达「情感构念稳不稳」——两者都只允许通向收紧。

**灵感 3（合流 → 三个角色分工）**
- 多机 = 外部证人（falsifier）：LOMO 残差提供不受本机标定污染的故障证据；
- 情感计算 = 待检验构念（construct）：给出信度而非准确率的评估语义；
- RAS = 安全执行器（actuator）：把 Φ 与 LOMO 证据接进 λ / 阈值门控，低信度即收紧。
三者合成 FAME-RAS 六组件：
1. **MVM 多机潜状态模型**：舰队共享 (z_t, e_t)，每机私有标定 c_m 与测量映射 f_m；
2. **LOMO 留一机伪证器**：用 ℳ\{i} 预测机 i，产生外部残差；
3. **FCOF 舰队标定共识滤波**：R68 COF 的正则化升级——标定必须同时解释自身残差与跨机残差，否则判过标定；
4. **GRC 泛化力信度证书**：G 理论方差分解 + Φ 的滚动置信区间；
5. **CMD 共模失效检测**：专门监控「多机一起错」的盲区（分歧下界 + 多样性探针 + canary 人群）；
6. **RAS† 继承核**：CALM-RAS 的 MTM/SSG/CFA/CAC 全部保留，新增多机层作为其外部审计。

**灵感 4（对 R68 最大风险的对症下药）**
R68 原罪是「标定能力越强，缓变故障越隐形」。FAME 的修法是**换一个不被标定污染的观测者**：LOMO 残差在机 i 的标定参数之外计算，机 i 无论如何调 c_i 都不会改变「别人对它的预测」。于是缓变故障在单机残差里可被吸收，却在跨机残差里留下直流分量（引理 17）。第二个修法是**把不确定性反过来当安全阀**：Φ 低（情感不可信 / 人群不匹配）时不允许放宽，λ_floor 抬升（定义 298），延续 R66–R68 的单向纪律。

**灵感 5（诚实的边界：多机一致 ≠ 多机正确）**
多机评测不是免费午餐：若所有机器共享同一个偏差（同构模型、同一训练集、同一人群先验），舰队会「一起错」且互相背书——这是本轮方案的**共模盲区**。因此 FAME 显式引入 CMD：用异构性（不同模态 / 安装 / 模型族）、分歧下界检测（过度一致本身是可疑信号）、外部 canary 人群来估计共模风险；并在定理 17 中给出「任何无外部真值的方案都无法突破共模盲区」的界，把残余风险写进证书 J_FAME 而不是藏起来。

## 1. 形式化定义（增量：定义 293–302）

**定义 293（FAME-RAS 总览）** FAME-RAS = (MVM, LOMO, FCOF, GRC, CMD, RAS†)。不变式继承 CALM-RAS 三不变式，并新增：
(iv) **外部证伪不变式**：任何单机标定更新必须同时通过 LOMO 跨机残差检验，否则视为过标定；
(v) **信度门控不变式**：情感通道的放宽量不得超过 Φ 的置信下界所允许的额度（低信度 ⇒ 只收紧）；
(vi) **共模显式化**：J_FAME 必须携带 common_mode_flag 与 diversity_vec，共模疑似时全局降级（k=0 或 λ=0.8）。

**定义 294（多机观测模型 MVM）** 舰队 ℳ = {1,…,N}。存在共享潜状态 (z_t ∈ ℝ^{d_z}, e_t ∈ Δ^{K_e}) 与每机私有标定 c_m、测量映射 f_m：
x_t^m = f_m(z_t, e_t; c_m) + ε_t^m，ε_t^m ~ 𝒩(0, Σ_m)。
假设 A95（共享构念）：同一交互的 (z_t, e_t) 对所有 m 的真值相同；A96（异构性）：{f_m} 在模态 / 参数化 / 安装几何上充分不同，使堆叠对齐雅可比列满秩（引理 16）。

**定义 295（留一机伪证残差 LOMO）** 对机 i：
(ẑ_t^{(-i)}, ê_t^{(-i)}) = argmax_{z,e} Σ_{m≠i} log p(x_t^m | z, e, ĉ_m)，
r_t^{(-i)} = x_t^i − f_i(ẑ_t^{(-i)}, ê_t^{(-i)}; ĉ_i)。
注意 r_t^{(-i)} 的预测项不含机 i 的观测，因此机 i 的标定不能直接消除它；这是它与 R68 残差 r_t 的本质区别。

**定义 296（舰队标定共识滤波 FCOF）** 扩展定义 286 的 EKF：状态 c_i，观测 (cal_head_i(z_t), r_t, r_t^{(-i)})。更新目标
J(c_i) = ‖r_t − r_cal(δc_i)‖²_{R_cal} + ‖r_t^{(-i)} − r_cal^{fleet}(δc_i)‖²_{R_fleet} + ‖δc_i‖²_{Q_cal^{-1}}。
**过标定判据**：若标定使自身项显著下降而跨机项不降（ΔJ_self < 0 且 ΔJ_fleet ≥ 0），判 over-calibration，记 H_sensor^trans。速率限制器（R68 定义 286）保留，作为反吸收第一道防线；FCOF 是第二道（跨机）防线。

**定义 297（泛化力信度证书 GRC）** 在目标人群 P × 机队 M × 时机 O 上，观测情感评分 X_{pmo} 的 G 理论分解：
X_{pmo} = μ + ν_p + ν_m + ν_o + ν_{pm} + ν_{po} + ν_{mo} + ε_{pmo}。
相对决策误差方差 σ²_δ = (σ²_m + σ²_{pm})/n_m + (σ²_o + σ²_{po} + σ²_{mo,e})/n_o；
泛化力系数 G = σ²_p / (σ²_p + σ²_δ)；
绝对决策（依赖绝对情感阈值，如「是否痛苦」）用可靠度指数 Φ = σ²_p / (σ²_p + σ²_Δ)，σ²_Δ = σ²_δ + σ²_m/n_m + σ²_o/n_o。
**证书信度**：Φ̂ 用自助法（bootstrap over P, O）给出置信下界 Φ_LB，仅 Φ_LB 可用于门控。

**定义 298（信度门控的风险重参数化 FRC）** 继承 R68 定义 284–285，把标定不确定 U 与情感不可靠 (1−Φ) 合并为可信度向量：
λ_floor(Φ, U) = max(0.6, 0.8·1[(1−Φ_LB) > τ_G], 0.8·1[U > τ_cal])；
τ_risk(Φ, U) = τ⁰_risk·(1 − κ_r·U − κ_φ·(1−Φ_LB))；
τ_emo(Φ) = τ⁰_emo·(1 + κ_e·(1−Φ_LB))（信度越低，越难判「无风险」）。
语义：**任何可信度缺口（标定 U 或信度 1−Φ）都只提高保守性，绝不提高放宽量。**

**定义 299（共模失效检测 CMD）** 共模偏差 b_cm 满足：所有机共享同一偏差，LOMO 残差不可见（预测与被预测者同时偏移）。检测量：
- 分歧下界：D_t = mean_{i≠j} d(π^i_t, π^j_t)；若 D_t < δ_min 且交互被判定为「应存在情感多样性」→ 疑似过度一致；
- 多样性探针：舰队异构度 H_fleet（模态数、模型族数、安装几何熵）；
- canary 人群：已知情感的参考被试子集，其 Φ_canary 是外部锚点。
共模风险估计 p̂_cm = g(D_t, H_fleet, Φ_canary)，写入 J_FAME。

**定义 300（AIC-FAME 干扰集）** ℰ_FAME = ℰ_CALM × ℰ_fleet × ℰ_affect；
ℰ_fleet = {机间时钟漂移、共模偏差、舰队分裂、LOMO 泄漏}；
ℰ_affect = {构念漂移（文化 / 个体）、人群偏移、评分者偏差、情感伪装（继承 R66）}。

**定义 301（FAME 证书 J_FAME）** J_FAME = (J_CALM, fleet_hash, {Φ̂, Φ_LB}, lomo_residual_vec, over_cal_flag, common_mode_flag, p̂_cm, diversity_vec, fame_ver)。
Valid ⇔ Valid(J_CALM) ∧ Φ_LB ≥ τ_G^hard（若用情感放宽）∧ ¬over_cal_flag ∧ (common_mode_flag ⇒ 已降级)。

**定义 302（管线）** 离线：多机同一交互采集 → MVM 对齐 → G 研究（P×M×O）估计 Φ → 标定门限 τ_G；在线：每机 LOMO 残差 → FCOF 标定 → GRC 滚动 Φ_LB → FRC 门控 → CMD 周期探针 → J_FAME 签发。

```python
# IP-253 MVM：多机共享潜状态 + 每机私有标定
class MultiMachineLatentModel:
    def __init__(self, shared_encoder, per_machine, d_z=64, K_e=4):
        self.enc, self.fm, self.d_z, self.K_e = shared_encoder, per_machine, d_z, K_e

    def predict(self, m, z, e, c_m):                 # f_m(z,e;c_m)
        return self.fm[m](torch.cat([z, e]), c_m)

    def infer_shared(self, obs_by_m, c_hat, exclude=None):
        used = {m: x for m, x in obs_by_m.items() if m != exclude}
        # 联合优化共享 (z,e)；amortized 初值 + 少量 Gauss-Newton 精修
        z, e = self.enc(used, {m: c_hat[m] for m in used})
        for _ in range(2):                            # 精修，实时可关
            z, e = self._gn_step(z, e, used, c_hat)
        return z, e

    def lomo(self, i, obs_by_m, c_hat):               # IP-254 留一机伪证
        z, e = self.infer_shared(obs_by_m, c_hat, exclude=i)
        return obs_by_m[i] - self.predict(i, z, e, c_hat[i])


# IP-254 LOMO：跨机残差 -> 过标定判别
class LeaveOneMachineOut:
    def residuals(self, obs_by_m, c_hat):
        return {i: self.mvm.lomo(i, obs_by_m, c_hat) for i in obs_by_m}

    def over_calibration(self, dJ_self, dJ_fleet, eps=0.05):
        # 自身残差降了、跨机残差没降 => 标定在"说圆自己"，判真实故障
        return (dJ_self < -eps) and (dJ_fleet >= -eps) and (dJ_self + dJ_fleet < -eps)


# IP-255 FCOF：舰队标定共识（R68 COF + 跨机正则）
class FleetCalibrationObservationFilter:
    def __init__(self, d_c=12, lam_fleet=0.5):
        self.cof = {m: CalibrationObservationFilter(d_c) for m in range(N)}
        self.lam_fleet = lam_fleet

    def step(self, z_cal_by_m, r_by_m, r_lomo_by_m, sigma_stat):
        for m in range(N):
            # 观测 = 本机标定头 + 本机残差 + 跨机残差（定义 296）
            obs = np.concatenate([z_cal_by_m[m], r_by_m[m],
                                  self.lam_fleet * r_lomo_by_m[m]])
            c, U, thr = self.cof[m].step(obs, sigma_stat)
            yield m, c, U, thr


# IP-256 GRC：G 理论方差分解 + bootstrap 置信下界
class GeneralizabilityCertificate:
    def __init__(self, n_boot=200, tau_G=0.8):
        self.n_boot, self.tau_G = n_boot, tau_G

    def estimate(self, X_pmo):                        # X: 人 x 机 x 时机
        var = self.g_theory_anova(X_pmo)              # -> sigma_p^2, sigma_delta^2 ...
        phi = var.sigma_p2 / (var.sigma_p2 + var.sigma_delta_abs2)
        samples = [self._boot_phi(X_pmo) for _ in range(self.n_boot)]
        return phi, np.quantile(samples, 0.05)        # (Phi, Phi_LB)

    def gate(self, phi_lb):
        # 低信度只收紧（定义 298）
        return {'lam_floor': 0.8 if (1 - phi_lb) > (1 - self.tau_G) else 0.6,
                'kappa_phi': max(0.0, 1.0 - phi_lb)}


# IP-257 CMD：共模失效检测
class CommonModeDetector:
    def estimate(self, pis, H_fleet, phi_canary):
        D = np.mean([dist(pis[i], pis[j]) for i in range(N) for j in range(i+1, N)])
        suspicious_unison = D < self.delta_min
        p_cm = self.calibrate(suspicious_unison, H_fleet, phi_canary)
        return p_cm, p_cm > self.tau_cm          # (p_hat, flag)


# IP-262 主闭环：FAME-RAS round（在 CALM-RAS 之上加多机层）
def FAME_RAS_round(fleet, obs_by_m):
    # 1) 各机 MTM 前向（继承 R68）
    z_by_m, o_by_m = {}, {}
    for m, obs in obs_by_m.items():
        z_by_m[m], o_by_m[m] = fleet[m].mtm.forward(obs, fleet[m].a_prev, fleet[m].ctx)

    # 2) LOMO 外部伪证（新增）
    r_lomo = fleet.lomo.residuals(obs_by_m, fleet.c_hat)

    # 3) FCOF 舰队标定共识（新增，替代纯自标定）
    for m, c, U, thr in fleet.fcof.step(
            {m: o_by_m[m]['cal'] for m in obs_by_m},
            {m: residuals(obs_by_m[m], o_by_m[m]) for m in obs_by_m},
            r_lomo, sigma_stat(fleet)):
        fleet.c_hat[m], fleet.U[m], fleet.thr[m] = c, U, thr

    # 4) 过标定判别（新增）：标定是否只在"自圆其说"
    over_cal = fleet.lomo.over_calibration(fleet.dJ_self, fleet.dJ_fleet)
    if over_cal:
        fleet.attribution_hint = 'H_sensor^trans'

    # 5) GRC 信度证书（新增，离线滚动 / 在线增量）
    phi, phi_lb = fleet.grc.estimate(fleet.recent_scores)
    gate = fleet.grc.gate(phi_lb)

    # 6) 继承 RAS 主链（lambda 由标定 U + 信度 Phi 双重下限约束）
    k, lam, joint = fleet.ras_step(z_by_m, o_by_m, r_lomo)
    lam = max(lam, gate['lam_floor'], fleet.thr_lam_floor)

    # 7) CMD 共模探针（周期）
    p_cm, cm_flag = fleet.cmd.estimate(
        {m: o_by_m[m]['pi'] for m in obs_by_m}, fleet.H_fleet, fleet.phi_canary)
    if cm_flag:
        lam, k = max(lam, 0.8), 0          # 疑似"多机一起错" -> 全局降级

    # 8) 证书签发 + 影子提交（继承 CAC）
    fleet.issue_certificate(J_FAME(J_CALM=..., Phi=(phi, phi_lb), lomo=r_lomo,
                                   over_cal=over_cal, cm=(p_cm, cm_flag)))
    return lam, k, joint, gate, cm_flag
```

## 3. 推导

**引理 16（多机可辨识性）** 在 A95–A96 下，设共享潜维 d = d_z + K_e，机 m 观测维 d_x^m。若 (a) 未知量计数满足 Σ_m d_x^m ≥ d + Σ_m d_c^m，且 (b) 堆叠对齐雅可比 J = [∂f_m/∂(z,e,c_m)] 在真值处列满秩，则每机加性故障 b_i 在共享潜规范（gauge）意义下可辨识，且 b_i 在 LOMO 残差空间上的投影非零。直观：留一法切断机 i 对自身预测的贡献，使 b_i 落在「其余机的列空间之外」的可观测子空间。**注**：至少需 3 台异构机；2 台时 gauge 自由度吞掉一个共同平移分量，只能辨识相对差（分不清「i 偏了」还是「j 偏了」）。

**引理 17（慢故障外部检出——把频率盲区降为方向盲区）** R68 中，故障分量 b_i(ω) 在 ω ≤ ω_cal 时被 COF 吸收，单机残差 → 0。FAME 中，LOMO 残差的故障分量为 r^{(-i)}(ω) ≈ b_i(ω) + O(σ_fleet/√(N−1))，不随 c_i 改变（预测集合排除 i）。故对任意 ω（含 ω→0），只要 ‖b_i‖ > τ_det·σ_fleet/√(N−1) 即可检出。相比 R68 的频域盲区 ω ≤ ω_cal，FAME 的盲区收缩到**共模子空间**（所有机同向偏移的方向）。系：R68 引理 13 的反吸收界从「频率盲区」降级为「方向盲区」——缓变故障不再隐形，除非它恰好是舰队共模。

**引理 18（信度-安全单调界）** 在情感门控下，放宽量 Δλ 是 Φ_LB 的单调非减函数，λ_floor 是 Φ_LB 的单调非增函数。设安全违规指示 V 随保守性 λ 增大而下降（∂E[V]/∂λ ≤ 0），则 ∂E[V]/∂Φ_LB ≤ 0。因此存在 Φ* 使 Φ_LB < Φ* ⇒ E[V] ≤ ε：信度门控可给出安全违规的显式上界，而「低信度仍放宽」在定义 298 下不可达。

**定理 16（FAME 端到端一致性）** 在 A87–A96 下，τ_cmd 满足：
1. P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + **α_lomo + α_reliab + α_cm**；
2. 单机慢故障（ω ≤ ω_cal）的检出概率相较 CALM-RAS 提升，盲区由频域收缩为共模方向（引理 17）；
3. Φ_LB 或标定可信度下降 ⇒ λ_floor 抬升、τ_risk 收紧（定义 298），「可信度下降却放宽」不可能发生；
4. 若 common_mode_flag = 1，则 λ ≥ 0.8 且 k = 0，J_FAME 标记 degraded。

**定理 17（共模盲区下界——诚实性定理）** 任何仅依赖舰队内部观测、无外部真值的评估器，在共模偏差 b_cm 下无法区分「真值整体偏移 b_cm」与「共模偏差 b_cm」——二者在舰队内观测分布上可交换（exchangeable）。因此 FAME 的共模可检测概率上界由外部锚决定：P(detect | b_cm) ≤ 1 − (1 − p_ext)^{n_canary}，其中 p_ext 为单 canary 个案暴露共模的概率。**结论：多机评测把「单机不可证伪」缩小为「共模不可证伪」，但不为零——这是原理性残余，必须写进证书而非隐藏。**

**定理 18（信度证书的 PAC 有效性）** 用 n_P 人、n_M 机、n_O 时机的 G 研究，Φ̂ 的偏差 O(1/n)，方差 O(1/(n_P n_M n_O))；以置信下界 Φ_LB 门控时，在置信度 1−δ 下安全约束成立。给出样本量需求：要把 Φ_LB 的标准误压到 0.05 以内，约需 n_P·n_M·n_O ≥ (z_{1−δ}·0.25/0.05)² ≈ 68 个有效观测单元（保守估计），故 N ≥ 3、n_O ≥ 5、n_P ≥ 10 是工程下限。

## 6. 本轮最大风险

**一句话**：FAME 的全部安全性押在「舰队共享可泛化的情感构念（A95）且不存在共模偏差」上——**若情感意义本身具身 / 文化特异（A95 为假），或舰队共享同一训练偏差 / 同一人群先验（共模），多机一致会制造虚假高 Φ、LOMO 全盲，系统在「多机都同意」的集体幻觉下放宽约束**；多机评测只是把「单机不可证伪」缩小为「共模不可证伪」，从未消除它。

**次级风险与缓解**：
1. **可辨识性退化**：异构不足（N=2 或同构机）→ 引理 16 失效 → 强制 ≥ 3 台异构机 + 雅可比秩在线监控，秩不足即降级为单机 CALM 模式；
2. **LOMO 泄漏**：小 N 时「预测者」被故障机污染 → 严格留一 + 鲁棒聚合（中位数）替代均值，并用 E295 验证；
3. **通信 / 同步不可用**：舰队无法实时共享 → 退化为异步 LOMO（用延迟观测）+ 延长 GRC 窗口，并在 J_FAME 标注 staleness；
4. **信度证书本身被过拟合**：Φ 用同一批 G 研究调门限会乐观偏差 → 独立 held-out 人群 + 自助法置信下界 + 预注册门限；
5. **隐私 / 公平**：跨机共享情感潜状态可能泄露个体 → 只共享去标识化潜变量与聚合统计，人群分层 Φ 避免「平均可信」掩盖少数群体不可信。

## 2. 形式化定义（要点版）

**定义 293（总览与三新不变式）** 继承 CALM-RAS 三不变式，新增：(iv) 外部证伪——单机标定须过 LOMO 检验；(v) 信度门控——放宽量受 Φ_LB 限制；(vi) 共模显式化——J_FAME 携带 common_mode_flag，疑似共模即全局降级。

**定义 294（MVM）** `x_t^m = f_m(z_t, e_t; c_m) + ε_t^m`；A95 共享构念（同一交互的 (z,e) 真值跨机相同），A96 异构性（堆叠雅可比满秩）。

**定义 295（LOMO）** `(ẑ^{(-i)}, ê^{(-i)}) = argmax Σ_{m≠i} log p(x^m|z,e,ĉ_m)`，`r^{(-i)} = x^i − f_i(ẑ^{(-i)}, ê^{(-i)}; ĉ_i)`。预测不含机 i，故本机标定不能消除它。

**定义 296（FCOF）** `J(c_i) = ‖r − r_cal(δc_i)‖²_{R_cal} + ‖r^{(-i)} − r_cal^{fleet}(δc_i)‖²_{R_fleet} + ‖δc_i‖²_{Q⁻¹}`；ΔJ_self<0 ∧ ΔJ_fleet≥0 ⇒ 过标定 ⇒ H_sensor^trans。

**定义 297（GRC）** `X_{pmo} = μ + ν_p + ν_m + ν_o + ν_{pm} + ν_{po} + ν_{mo} + ε`；`σ²_δ = (σ²_m+σ²_{pm})/n_m + (σ²_o+σ²_{po}+σ²_{mo,e})/n_o`；`Φ = σ²_p/(σ²_p+σ²_Δ)`；Φ_LB 为 bootstrap 5% 分位。

**定义 298（FRC）** `λ_floor = max(0.6, 0.8·1[(1−Φ_LB)>τ_G], 0.8·1[U>τ_cal])`；`τ_risk = τ⁰(1−κ_r·U−κ_φ·(1−Φ_LB))`；`τ_emo = τ⁰(1+κ_e·(1−Φ_LB))`。可信度缺口只增保守性。

**定义 299（CMD）** `D_t = mean_{i≠j} d(π^i,π^j)`；过度一致（D_t<δ_min 且交互应有多样性）+ 低异构度 + canary Φ 共同估计 `p̂_cm`。

**定义 300（AIC-FAME）** `ℰ_FAME = ℰ_CALM × ℰ_fleet × ℰ_affect`；ℰ_fleet={时钟漂移, 共模, 舰队分裂, LOMO 泄漏}；ℰ_affect={构念漂移, 人群偏移, 评分者偏差, 情感伪装}。

**定义 301（J_FAME）** `J_FAME = (J_CALM, fleet_hash, {Φ̂,Φ_LB}, lomo, over_cal_flag, common_mode_flag, p̂_cm, diversity, fame_ver)`；Valid ⇔ Valid(J_CALM) ∧ Φ_LB≥τ_G^hard ∧ ¬over_cal ∧ (cm_flag ⇒ 已降级)。

**定义 302（管线）** 离线多机对齐 → G 研究估计 Φ 与 τ_G；在线 LOMO → FCOF → GRC → FRC → CMD → J_FAME。

```python
# IP-253 MVM：共享潜状态 + 每机私有标定
class MultiMachineLatentModel:
    def predict(self, m, z, e, c_m):
        return self.fm[m](torch.cat([z, e]), c_m)

    def infer_shared(self, obs_by_m, c_hat, exclude=None):
        used = {m: x for m, x in obs_by_m.items() if m != exclude}
        z, e = self.enc(used, {m: c_hat[m] for m in used})
        for _ in range(2):                      # GN 精修，实时可关
            z, e = self._gn_step(z, e, used, c_hat)
        return z, e

    def lomo(self, i, obs_by_m, c_hat):         # IP-254
        z, e = self.infer_shared(obs_by_m, c_hat, exclude=i)
        return obs_by_m[i] - self.predict(i, z, e, c_hat[i])

# IP-254 LOMO：过标定判别（自圆其说 vs 真标定）
class LeaveOneMachineOut:
    def over_calibration(self, dJ_self, dJ_fleet, eps=0.05):
        return (dJ_self < -eps) and (dJ_fleet >= -eps) and (dJ_self + dJ_fleet < -eps)

# IP-255 FCOF：舰队标定共识（R68 COF + 跨机正则）
class FleetCalibrationObservationFilter:
    def step(self, z_cal_by_m, r_by_m, r_lomo_by_m, sigma_stat):
        for m in range(N):
            obs = np.concatenate([z_cal_by_m[m], r_by_m[m], self.lam_fleet * r_lomo_by_m[m]])
            c, U, thr = self.cof[m].step(obs, sigma_stat)
            yield m, c, U, thr

# IP-256 GRC：G 理论 + bootstrap 下界
class GeneralizabilityCertificate:
    def estimate(self, X_pmo):
        v = self.g_theory_anova(X_pmo)
        phi = v.sigma_p2 / (v.sigma_p2 + v.sigma_delta_abs2)
        lb = np.quantile([self._boot_phi(X_pmo) for _ in range(self.n_boot)], 0.05)
        return phi, lb

    def gate(self, phi_lb):
        return {'lam_floor': 0.8 if (1 - phi_lb) > (1 - self.tau_G) else 0.6,
                'kappa_phi': max(0.0, 1.0 - phi_lb)}

# IP-257 CMD：共模失效检测
class CommonModeDetector:
    def estimate(self, pis, H_fleet, phi_canary):
        D = np.mean([dist(pis[i], pis[j]) for i in range(N) for j in range(i+1, N)])
        p_cm = self.calibrate(D < self.delta_min, H_fleet, phi_canary)
        return p_cm, p_cm > self.tau_cm

    for m, obs in obs_by_m.items():
        z_by_m[m], o_by_m[m] = fleet[m].mtm.forward(obs, fleet[m].a_prev, fleet[m].ctx)

    r_lomo = fleet.lomo.residuals(obs_by_m, fleet.c_hat)          # LOMO 外部伪证
    for m, c, U, thr in fleet.fcof.step(
            {m: o_by_m[m]['cal'] for m in obs_by_m},
            {m: residuals(obs_by_m[m], o_by_m[m]) for m in obs_by_m},
            r_lomo, sigma_stat(fleet)):
        fleet.c_hat[m], fleet.U[m], fleet.thr[m] = c, U, thr

    over_cal = fleet.lomo.over_calibration(fleet.dJ_self, fleet.dJ_fleet)
    if over_cal: fleet.attribution_hint = 'H_sensor^trans'

    phi, phi_lb = fleet.grc.estimate(fleet.recent_scores)
    gate = fleet.grc.gate(phi_lb)

    k, lam, joint = fleet.ras_step(z_by_m, o_by_m, r_lomo)
    lam = max(lam, gate['lam_floor'], fleet.thr_lam_floor)

    p_cm, cm_flag = fleet.cmd.estimate(
        {m: o_by_m[m]['pi'] for m in obs_by_m}, fleet.H_fleet, fleet.phi_canary)
    if cm_flag: lam, k = max(lam, 0.8), 0          # 疑似"多机一起错" -> 全局降级

    fleet.issue_certificate(J_FAME(J_CALM=..., Phi=(phi, phi_lb), lomo=r_lomo,
                                   over_cal=over_cal, cm=(p_cm, cm_flag)))
    return lam, k, joint, gate, cm_flag
```

## 4. 推导

**引理 16（多机可辨识性）** 若 `Σ_m d_x^m ≥ d_z+K_e+Σ_m d_c^m` 且堆叠对齐雅可比列满秩，则每机加性故障 b_i 在共享潜 gauge 下可辨识，且 b_i 在 LOMO 残差空间投影非零；至少需 3 台异构机（2 台存在共同平移的 gauge 歧义）。

**引理 17（慢故障外部检出）** R68 中 ω ≤ ω_cal 的故障被 COF 吸收，单机残差 → 0；FAME 中 `r^{(-i)}(ω) ≈ b_i(ω) + O(σ_fleet/√(N−1))` 不随 c_i 改变。故任意 ω（含 ω→0）只要 `‖b_i‖ > τ_det·σ_fleet/√(N−1)` 即检出。**盲区从「频率 ω ≤ ω_cal」降级为「方向=共模子空间」**——单机反吸收界（R68 引理 13）被外部证人绕过。

**引理 18（信度-安全单调界）** Δλ 对 Φ_LB 单调非减、λ_floor 单调非增；若 ∂E[V]/∂λ ≤ 0，则 ∂E[V]/∂Φ_LB ≤ 0。故存在 Φ* 使 Φ_LB<Φ* ⇒ E[V] ≤ ε；「低信度仍放宽」在定义 298 下不可达。

**定理 16（FAME 端到端一致性）** A87–A96 下：
1. `P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_lomo+α_reliab+α_cm`；
2. 慢故障（ω≤ω_cal）检出概率高于 CALM-RAS，盲区由频域收缩为共模方向（引理 17）；
3. Φ_LB 或标定可信度下降 ⇒ λ_floor 抬升、τ_risk 收紧，绝不放宽；
4. common_mode_flag ⇒ λ≥0.8 ∧ k=0，证书标 degraded。

**定理 17（共模盲区下界）** 无外部真值的舰队内评估，在共模偏差下无法区分「真值偏移」与「共模偏差」（可交换性）；`P(detect|b_cm) ≤ 1−(1−p_ext)^{n_canary}`。多机评测把「单机不可证伪」缩小为「共模不可证伪」，但不为零，残余风险写入 J_FAME。

**定理 18（信度证书 PAC 有效性）** n_P×n_M×n_O G 研究下，Φ̂ 偏差 O(1/n)、方差 O(1/(n_P n_M n_O))；以 Φ_LB 门控在 1−δ 置信下满足安全约束。工程下限：N≥3、n_O≥5、n_P≥10。

## 8. 本轮最大风险

**一句话**：FAME 的全部安全性押在「舰队共享可泛化的情感构念（A95）且不存在共模偏差」上——**若情感意义本身具身/文化特异（A95 为假），或舰队共享同一训练偏差/人群先验（共模），多机一致会制造虚假高 Φ、LOMO 全盲，系统在「多机都同意」的集体幻觉下放宽约束**；多机评测只是把「单机不可证伪」缩小为「共模不可证伪」，从未消除它。

**次级风险与缓解**：异构不足（N=2/同构）→ 强制 ≥3 异构机 + 雅可比秩监控，秩不足降级为单机 CALM；LOMO 泄漏 → 严格留一 + 鲁棒中位数聚合 + E295；通信/同步不可用 → 异步 LOMO + 标注 staleness；Φ 过拟合 → held-out 人群 + bootstrap 下界 + 预注册门限；隐私/公平 → 只共享去标识潜变量与分层 Φ，避免「平均可信」掩盖少数群体不可信。
