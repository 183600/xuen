### 第 7 轮灵感驱动研究记录

**灵感词**：用户需求分析、大语言模型、面部表情识别

**继承关系**：第 6 轮 CADVS-v6（IP-497~IP-500）确立「指令-几何-力学三元凿」框架：GGC 提供抓取几何可达性约束、MCTM 注入空间拓扑图、STM 实现跨模态指令-轨迹映射，七硬门保持 fail-closed 边界。本轮延续「硬门不增」原则，聚焦「**需求-意图-一致性三角桥**」：在保持证书边界不变的前提下，直接从「用户需求分析」出发，设计「需求意图建模器」(DIM)，引入「需求一致性软评分」η_demand，使系统从「被动接受指令」转向「主动推导意图」。

**直觉与动机**：

1. **用户需求 → 从「指令响应」到「意图推导」**。第 6 轮的 STM 负责「语言→查询向量」的映射，但它无法区分「用户真正想要的」与「用户不够清晰说出的」。引入「需求意图建模器」(Demand Intent Model, DIM)：从用户的历史交互记录、当前环境约束、任务目标三方面推断「用户真正的需求目标」ρ_demand。关键洞见是：**行为从「指令驱动」转向「需求驱动」**——只有当推断的需求意图与指令意图高度一致时，才执行STM生成的轨迹；否则，触发「需求导向回退」。

2. **大语言模型 → 从「静态映射」到「动态推理」**。第 6 轮的 STM 采用 CLIP-style 对齐训练，对指令进行向量化。第 7 轮引入「需求推理链」(Demand Reasoning Chain, DRC)：将LLM连接到DIM，使得从「用户说了什么」到「用户可能需要什么」的推理过程可解释、可审计。关键洞见是：**LLM 充当「需求解释器」**——它的推理链被量化为 η_demand，若推理置信度低于阈值，系统自动切换到历史记忆中的「典型需求响应」。

3. **面部表情识别 → 从「情感调制」到「需求态度捕获」**。第 6 轮的 FAMK 调制阈值 γ_i。第 7 轮提出「需求态度捕获」(Demand Affect Capture, DAC)：基于面部表情识别，捕获用户当前的「需求态度」(desire_affect)——如焦虑表情可能意味着「需要快速、稳妥的解决方案」，而放松表情可能意味着「愿意探索创新方案」。关键洞见是：**情感态度调制需求优先级**——DAC 输出的 desire_affect 调节 ρ_demand 的稀疏性和探索度。

**关键洞见**：第 6 轮回答「如何在不新增硬门的前提下，让提议符合物理、空间、意图」；第 7 轮回答「如何从「用户需求」出发，让系统主动推导「正确的行为」，而不是被动接受指令」。七硬门 kc_evidence_forged_v5 记号原样复用；本轮新增的只有：
- IP-501 DIM（需求意图建模器），
- IP-502 DRC（需求推理链，LLM驱动），
- IP-503 DAC（需求态度捕获），
- IP-504 EFA-v7（软评分 η_demand 纳入四软因子链）

**形式化目标（增量）**：

1. **DIM（Demand Intent Model）**：<br>
   - 需求编码器 E_demand: (history, context, env) ⟼ ρ_demand ∈ ℝ^d_demand<br>
   - 损失 L_DIM = ||ρ_demand - ρ_gold||² + β·KL(π_demand || π_prior)<br>
   - 软因子：η_demand = 1 - H(ρ_pred || ρ_demand)，其中 H 为交叉熵<br>
   - 只有当 η_demand > τ_demand 时，STM 输出的指令才被采纳；否则触发「需求导向回退」

2. **DRC（Demand Reasoning Chain）**：<br>
   - LLM 推理链 R = {r_1, r_2, ..., r_n}，其中 r_i 为推理步骤<br>
   - η_demand = 1 - (1/n)·Σ_i H(r_i)，衡量推理链的整体确定性<br>
   - L_DRC = α·链长度惩罚 - η_demand，鼓励简洁且确定的推理

3. **DAC（Demand Affect Capture）**：<br>
   - 表情编码器 E_affect: face ⟼ affect ∈ {-1, 0, +1}（负面/中性/正面）<br>
   - desire_affect 调节 ρ_demand 的探索度：exploration_scale = 1 + κ·affect<br>
   - 软因子：η_affect = 1 + affect/3 ∈ [2/3, 4/3]，调制 STM 检索的广度

4. **EFA-v7（七硬门 + 四软因子链）**：<br>
   - ECS_v7 = ECS_v6 · η_g · η_topo · η_interp · η_cmd · η_demand · η_affect<br>
   - τ_i^v7 = γ_i·τ_i^v6·Π_factor_i，其中 Π_factor_i = ∏_{j=1}^5 η_j ∈ [1, 1+ε]，设计上限仍为 1.3<br>
   - 新增硬门 kc_demand：η_demand ≥ τ_demand，确保「用户需求」被必要检验

5. **形式化定义**：给定指令 L，目标 ρ_target，记忆 M：<br>
   - ρ_demand = DIM(history, context, env)；<br>
   - η_demand = 1 - H(STM(L) || ρ_demand)；<br>
   - 若 η_demand < τ_demand：<br>
     - q_demand = E_demand(ρ_demand)；<br>
     - m_demand = Top-k(Retr_M(q_demand, K=4))；<br>
     - c_demand = (obj, g_emb, θ_fp, task, ŝ_emo, m_demand, ρ_target, t_topo, q_demand)；<br>
     - x_demand = FMPP.propose(c_demand, K=8)；<br>
   - 若 η_demand ≥ τ_demand：<br>
     - 执行第 6 轮的 EFA-v6 流程<br>

**直觉与动机（本轮迭代扩展）**：

1. **碰撞检测 → 从「硬门约束」到「需求驱动碰撞 guard」**：现有七硬门保证 fail-closed，但未在需求导向回退路径中引入几何碰撞检测。关键洞见：**需求推断的轨迹若存在几何碰撞，即便一致性 η_demand 高，也应拒绝或触发安全回退**。引入 η_collision 软因子，基于 GGC 碰撞网格实时评估 x_demand 与环境的碰撞概率。

2. **语义地图 → 从「向量近似」到「结构化语义映射」**：当前 DIM 的 ρ_demand ∈ ℝ^d_demand 仅作为稠密向量，缺乏语义结构化表征。关键洞见：**引入语义地图，将 ρ_demand 投射到任务语义簿，通过 k-NN 检索确保 ρ_demand 与实际可达任务的语义一致性**，从而 η_demand 有了结构化依据而非纯统计近似。

3. **痛点分析 → 从「假设致盲」到「三层防护机制」**：核心风险是用户意图的非线性突变与自我否定。痛点分析指向三层防护：① **Dual-track DIM**（主需求路径 + 备选路径，经一致性投票），② **η_demand 实时可解释性检查**（每一步 η_demand 的变化趋势而非单点阈值），③ **需求演化检测**（连续 3 轮 η_demand 变化率超过阈值时强制回退）。

**关键洞见**：第 7 轮已回答「如何主动推导正确行为」；本轮迭代回答「如何在推导过程中 guards 多维度防止『正确但有风险』的行为」；七硬门依然保持 fail-closed，新增的只有软因子扩展与两层防护机制。

**形式化目标（增量）**：

1. **η_collision（碰撞软因子）**：
   - 基于 GGC 碰撞网格：η_collision = 1 - (碰撞体素计数 / 总体素数) ∈ [0,1]
   - 仅在需求导向回退路径中计算；常规 EFA-v6 流程不受影响

2. **语义地图投射**（Semantic Map Projection，SMP）：
   - S(ρ_demand) = Top-k(Retr_M(q_semantic, K=8))，其中 q_semantic = W·ρ_demand + b 为可学习投影
   - 一致性验证：η_semantic = 1 - (1/k)·Σ_j sim(ρ_demand, ρ_target_j)，sim 为余弦相似度
   - 若 η_semantic < τ_semantic（默认 0.6），触发语义一致性回退

3. **Dual-track DIM**：
   - 主路径：ρ_demand^main = DIM.encode(history, context, env)
   - 备路径：ρ_demand^alt = DIM.encode(history_tail, context, env) 其中 history_tail 为最近 3 条交互
   - 投票：若 sim(ρ_demand^main, ρ_demand^alt) > τ_vote（默认 0.7），则使用主路径；否则使用备路径并标记「需求不稳定」

4. **EFA-v7 增强**：
   - ECS_v7 = ECS_v6 · η_g · η_topo · η_interp · η_cmd · η_demand · η_affect · η_collision
   - 软因子链 Π_factor_i = ∏_{j=1}^7 η_j ∈ [1, 1.3]（已含 η_collision，设计上限 1.3 保持不变，意味着 η_collision 默认置 1 或在常规流程中不计）

5. **形式化定义（增量）**：
   - ρ_demand = DIM(history, context, env)；<br>
   - （主路径）ρ_demand^main = ρ_demand；<br>
   - （备路径）ρ_demand^alt = DIM(history_tail, context, env)；<br>
   - η_semantic = 1 - (1/k)·Σ_j sim(ρ_demand, ρ_target_j)；<br>
   - η_collision = 1 - (collision_voxels / total_voxels)；<br>
   - 若 η_demand < τ_demand  或  η_semantic < τ_semantic  或  η_collision < τ_collision（默认 0.5）：<br>
     - 走需求导向回退，并额外检查 η_collision<br>
   - 若 所有 软因子 ≥ 阈值：<br>
     - 执行 EFA-v6 在线流程 + 软因子链 × η_demand × η_affect × η_collision

**本轮最大风险**：**需求意图的非线性突变与自我否定**：尽管引入 dual-track 与语义地图，但用户意图仍可能在短期内发生非线性突变（如 suddenly switching from「放置到桌子」到「拿走到柜子」），此时 dual-track 可能因历史权重过大而滞后，语义地图的投影投影也可能过旧。这种结构上的捕获难题在维持七硬门 fail-closed 边界时，仍可能导致「正确但时机不当」或「正确但错误目标」的行动。

### 第 8 轮灵感驱动研究记录

**灵感词**：用户测试、轻量化设计

**继承关系**：第 7 轮 CADVS-v7（IP-501~IP-504）以 DIM/DRC/DAC 建立「需求-意图-一致性三角桥」，把系统从「指令响应」推向「意图推导」，但留下两个现实缺口：(a) 阈值 τ_demand=0.7 与各软因子权重全是开发者先验，从未经过真实用户检验；(b) DIM+DRC+DAC 的算力叠加（尤其 DRC 的 LLM 推理链 5~50 ms）使端侧 0.8 ms 预算名存实亡。本轮沿用「硬门不增」原则（相对 v7 不再新增硬门），聚焦「**测试-校准-轻量三角闭环**」：用「用户测试」把 η_demand 从「假设」变成「可统计校准的量」，用「轻量化设计」把需求核心压回端侧，并用「单边影子门」保证轻量化绝不放松 fail-closed 边界。

**直觉与动机**：

1. **用户测试 → 从「离线评测」到「在线保形校准」**。v7 的 τ_demand 是拍的，η_demand 的语义也从未被真实用户校准。引入「用户测试闭环」(User Testing Loop, UTL)：以覆盖度引导采样用户场景，主动挖掘「系统高置信、用户却拒绝」的反例，再用分裂保形预测(split conformal)在校准集上给出 τ̂_demand，使「错误放行率」获得有限样本、分布无关的上界 α。关键洞见：**阈值不是超参数，而是可被用户测试证伪的统计承诺**。

2. **轻量化设计 → 从「堆模块」到「单边预筛」**。引入「影子门预筛器」(Shadow Gate Prefilter, SGP)：小型代理模型 \hat g 只允许输出「提前否决」，绝不允许「提前放行」，即 \hat g(x)=0 ⟹ g(x)=0（单边可靠性）。因此预筛后的执行集与 v7 严格相等，却把昂贵的七硬门全量验证次数降低一个量级。关键洞见：**轻量化的安全做法是「只做减法」——代理只能否决，不能准入**。

3. **用户测试 × 轻量化 → 量化需求核**。把 DIM 与 DRC 蒸馏进一个 INT8 小模型「量化需求核」(Quantized Demand Core, QDC)，在线只跑 QDC，LLM 推理链退居异步审计；用量化误差界 δ 把阈值抬到 τ_demand+δ，保证 \tilde η ≥ τ+δ ⟹ η ≥ τ。关键洞见：**精度损失可以被安全裕度吸收，但不能被忽略**。

**关键洞见**：第 7 轮回答「如何主动推导需求」；第 8 轮回答「如何用用户测试证明推导是对的，以及如何让它在端侧跑得起」。七硬门与 v7 记号原样复用；本轮新增的只有：

- IP-505 UTL（用户测试闭环，覆盖采样 + 反例挖掘 + 保形校准 τ_demand）
- IP-506 SGP（单边影子门预筛，只否决不放行）
- IP-507 QDC（量化需求核，蒸馏 DIM+DRC 为 INT8 小模型）
- IP-508 EFA-v8（轻量装配器，硬门数与 v7 相同，不新增硬门）

**形式化目标（增量）**：

1. **UTL（User Testing Loop）**：<br>
   - 场景采样器 S_cov：以 k-center 覆盖目标在 (task, env, affect) 空间选取测试场景，最大化最小成对距离；<br>
   - 用户标签 a ∈ {0,1}（1=用户认可系统行为），需求分数 s = η_demand；<br>
   - 反例集 N = { s_i : a_i = 0 }；保形阈值 τ̂_demand = Quantile_{⌈(n+1)(1-α)⌉/n}(N)；<br>
   - 保证：在可交换性下，对任一被用户拒绝的新样本，P(η_demand ≥ τ̂_demand) ≤ α；<br>
   - 漂移检测：对 N 的分数分布做滑动 KS 检验，p < p_min 时触发重校准。

2. **SGP（Shadow Gate Prefilter）**：<br>
   - 廉价特征 φ(x) ∈ ℝ^{d_sgp}（几何统计量、拓扑 token、q-embedding 内积、候选间距）；<br>
   - 代理 \hat g_θ(φ(x)) ∈ {0,1}，训练采用非对称损失：<br>
     L_SGP = E[ 1{g(x)=1}·1{\hat g(x)=0} ]·λ_fp + E[ 1{g(x)=0}·1{\hat g(x)=1} ]·λ_fa，且 λ_fp ≫ λ_fa；<br>
   - 单边约束：\hat g 的决策边界由「所有 g(x)=1 的训练样本的代理分数最大值 + δ_s」确定，宁可漏剪，不可错剪；<br>
   - 仅当 \hat g(x)=0 时提前淘汰 x；\hat g(x)=1 的候选仍走完整七硬门。

3. **QDC（Quantized Demand Core）**：<br>
   - 教师 T = (DIM, DRC 集成)，学生 S 为 2 层 MLP / TinyTransformer，参数量 ≤ 2%·|T|；<br>
   - 蒸馏损失 L_QDC = KL(T(·)‖S(·)) + λ·L_task + γ·L_QAT（量化感知训练）；<br>
   - INT8 量化权重/激活；误差界 δ：在域内高概率有 |\tilde η_demand - η_demand| ≤ δ；<br>
   - 在线安全阈值 τ' = τ̂_demand + δ；LLM 仅在异步审计中比对 S 与 T 的分歧，分歧超阈值则回灌 UTL。

4. **EFA-v8（七硬门 + v7 软因子链，无新增硬门）**：<br>
   - ECS_v8 = ECS_v7（软因子链不变，保证评分语义可继承）；<br>
   - 准入分支：\tilde η_demand ≥ τ' 才走 v7 正常流程，否则走 v7 需求导向回退；<br>
   - 预筛：在候选进入 GGC 之前先过 SGP；SGP 只删不加，故固定阈值下执行集不变；<br>
   - 硬门集合与 v7 完全相同，不新增 kc_user（用户测试只校准既有阈值，不扩张证书边界）。

5. **形式化定义**：给定指令 L、目标 ρ_target、记忆 M、用户测试集 D_test：<br>
   - (η_i, a_i)_{i=1..n} = UTL.collect(D_test)；τ̂ = UTL.conformal_threshold(η_{a=0}, α)；<br>
   - \tilde η = QDC(L, history, context, env)；<br>
   - 若 \tilde η < τ' = τ̂ + δ：走 v7 需求导向回退；<br>
   - 否则：c = build_ctx(...)；cands = FMPP.propose(c, K=8)；<br>
   - cands' = { x ∈ cands : SGP(x) = 1 }（SGP=0 提前淘汰）；<br>
   - 对 cands' 走 v7 的 GGC → 六软因子 → VACK → BCK；<br>
   - 输出 ECS_v8 最高且过七硬门的 x。

**本轮最大风险**：**单边预筛的「单边性」只在训练/校准分布内可证**——一旦用户测试揭示的分布漂移超出 SGP 与 QDC 的校准域，\hat g(x)=0 ⟹ g(x)=0 与 |\tilde η-η| ≤ δ 两个前提会同时失效，轻量化省下的算力可能以静默漏检（错误否决或错误放行）为代价，且这种失效在结构上难以及时暴露。

| φ(x) ∈ ℝ^{d_sgp} | SGP 的廉价候选特征，d_sgp=32 |
| \hat g_θ(φ(x)) ∈ {0,1} | 单边影子门，1=允许进入全量验证，0=提前否决 |
| λ_fp, λ_fa | SGP 非对称损失权重，λ_fp ≫ λ_fa |
| δ_s | SGP 单边安全裕度 |
| T, S | QDC 教师 / 学生模型 |
| \tilde η_demand | QDC 输出的量化需求分数 |
| δ | 量化误差界，|\tilde η - η| ≤ δ |
| τ' = τ̂_demand + δ | 在线安全阈值 |
| L_QDC = KL(T‖S) + λ·L_task + γ·L_QAT | 蒸馏+量化感知损失 |
| r_prune | SGP 提前否决比例 |
| η_utest = 1 - FPR_cal | 用户测试校准置信度（仅审计用，不进 ECS） |

## 2. 关键算法骨架

### IP-505 UTL：用户测试闭环 + 保形校准

```python
@dataclass
class UserTestingLoop:
    """UTL：覆盖引导采样 + 反例挖掘 + 保形校准 τ_demand。
    只校准既有阈值，不新增硬门，不改变证书边界。"""
    alpha: float = 0.05
    p_min: float = 0.01
    n_min: int = 200

    def coverage_sample(self, pool: list[Scenario], k: int) -> list[Scenario]:
        """k-center 贪心：最大化所选场景的最小成对距离"""
        chosen = [pool[0]]
        while len(chosen) < k:
            nxt = max((s for s in pool if s not in chosen),
                      key=lambda s: min(self.dist(s, c) for c in chosen))
            chosen.append(nxt)
        return chosen

    def mine_counterexamples(self, scenarios, eta_fn, user_fn) -> list[tuple[float, int]]:
        """挖掘系统高置信、用户却拒绝的反例"""
        out = []
        for sc in scenarios:
            eta = eta_fn(sc)
            a = user_fn(sc)            # 真实用户标签
            out.append((eta, a))
            if eta >= 0.7 and a == 0:  # 高置信反例，重点回灌
                self.hard_negatives.append(sc)
        return out

    def conformal_threshold(self, scores_neg: list[float]) -> float:
        """分裂保形：τ̂ = 拒绝样本分数的 ⌈(n+1)(1-α)⌉ 次序统计量"""
        n = len(scores_neg)
        assert n >= self.n_min
        scores = sorted(scores_neg)
        k = math.ceil((n + 1) * (1 - self.alpha))
        return scores[min(k, n) - 1]

    def drift_check(self, old_neg: list[float], new_neg: list[float]) -> bool:
        """KS 检验：分布漂移则触发重校准"""
        stat, p = scipy.stats.ks_2samp(old_neg, new_neg)
        return p < self.p_min
```

### IP-506 SGP：单边影子门预筛

```python
@dataclass
class ShadowGatePrefilter:
    """SGP：只允许提前否决，绝不允许提前放行。
    可靠性假设（单边）：\hat g(x)=0 ⟹ g(x)=0。
    g(x)=1 表示 x 通过全部七硬门。"""
    net: nn.Module                  # φ(x) -> score
    margin: float = 0.1             # δ_s
    prune_threshold: float = None   # 由训练集正例最大分数 + margin 标定

    def calibrate(self, X_pos: list, phi: Callable) -> None:
        """决策边界取所有 g(x)=1 样本分数的最大值 + margin：宁可漏剪"""
        with torch.no_grad():
            pos_scores = [self.net(phi(x)).item() for x in X_pos]
        self.prune_threshold = max(pos_scores) + self.margin

    def allow(self, x) -> bool:
        """True=进入全量验证；False=提前否决（安全方向）"""
        if self.prune_threshold is None:
            return True  # 未标定则不剪，退化为 v7
        score = self.net(self.phi(x)).item()
        return score >= self.prune_threshold
```

### IP-507 QDC：量化需求核

```python
@dataclass
class QuantizedDemandCore:
    """QDC：把 DIM+DRC 蒸馏为 INT8 小模型，在线计算 \tilde η_demand。"""
    student: nn.Module
    delta: float = 0.05            # 量化误差界 δ
    lambda_task: float = 0.5
    gamma_qat: float = 0.1

    def distill(self, teacher, data) -> None:
        for x, y in data:
            with torch.no_grad():
                t = teacher(x)
            s = self.student(x)
            loss = (kl_div(s.log_softmax(-1), t.softmax(-1))
                    + self.lambda_task * F.mse_loss(s, y)
                    + self.gamma_qat * self.quantization_penalty())
            loss.backward()

    def quantize(self) -> None:
        """INT8 量化感知训练后转静态量化"""
        self.student = torch.quantization.convert(
            torch.quantization.prepare_qat(self.student, inplace=False),
            inplace=False)

    def score(self, L, history, context, env) -> float:
        """在线：\tilde η_demand，< 0.1 ms"""
        return float(self.student(self.encode_inputs(L, history, context, env)))

    def safe_threshold(self, tau_hat: float) -> float:
        """τ' = τ̂ + δ，保证 \tilde η ≥ τ' ⟹ η ≥ τ̂"""
        return tau_hat + self.delta
```

### IP-508 EFA-v8：轻量装配器

```python
@dataclass
class EvidenceForgingAssemblerV8:
    """EFA-v8：硬门数与 v7 相同；SGP 只剪不加，QDC 用安全裕度。"""
    fmpp: FlowMatchingProposalPolicyKernel
    lmem: LongTermMemoryEmbeddingConsolidation
    famk: FacialAffectModulationKernel
    ggc: GraspGeometryCutter
    mctm: MobileChassisTopologyMap
    stm: SemanticTrajectoryMapper
    qdc: QuantizedDemandCore
    sgp: ShadowGatePrefilter
    v7: EvidenceForgingAssemblerV7
    utl: UserTestingLoop
    tau_hat: float = 0.7

    def select(self, L, t_now, context) -> tuple[bool, Trajectory | None, str]:
        affect = self.dac_observe(context)
        eta_affect = self.famk.get_affect_factor(affect)
        tau_safe = self.qdc.safe_threshold(self.tau_hat)

        # 1. 在线量化需求核
        eta_q = self.qdc.score(L, self.lmem.get_history(),
                               context.__dict__, getattr(context, 'env', {}))
        if eta_q < tau_safe:
            return self.v7._demand_guided_fallback(
                self.v7.dim.encode(self.lmem.get_history(), context.__dict__,
                                   getattr(context, 'env', {})),
                t_now, context, affect, eta_affect)

        # 2. 软因子（沿用 v7）
        q_L = self.stm.forward(L)
        eta_cmd = 1.0 - 0.1 * self.stm.information_entropy(q_L, self.lmem.all_embeddings())
        eta_interp = sigmoid(-self._semantic_traj_distance(q_L) / self.stm.temp)
        eta_topo = self.mctm.query(context.pose)
        s_emo = self.famk.observe(context.face, t_now)
        gamma = self.famk.gamma(s_emo)
        m_topk = self.lmem.retrieve_by_semantic(q_L, k=4)
        t_topo = self.mctm.token(context.pose)
        c = build_ctx(context, s_emo, m_topk, t_topo, q_L)
        cands = self.fmpp.propose(c, K=self.fmpp.K)

        # 3. 单边预筛：只剪不加
        cands = [x for x in cands if self.sgp.allow(x)]

        # 4. 全量七硬门（与 v7 相同）
        surv = []
        for x in cands:
            if not self.ggc.filter(x):
                continue
            eta_g = self.ggc.quality_factor(x)
            eta_total = eta_g * eta_topo * eta_interp * eta_cmd * eta_q * eta_affect
            if self._cheap_gates(x, gamma, eta_total):
                surv.append((x, eta_total))
        if not surv:
            return self.v7._demand_guided_fallback(
                self.v7.dim.encode(self.lmem.get_history(), context.__dict__,
                                   getattr(context, 'env', {})),
                t_now, context, affect, eta_affect)

        surv.sort(key=lambda p: p[1], reverse=True)
        finals = []
        for x, _ in surv[:3]:
            vac = self.v7.v6.vack.evaluate(x, context_with(s_emo), t_now)
            if self.v7.v6.vack.kc_val(vac, tau=gamma['val'] * TAU_VAL5):
                if self.v7.v6._bck_preview(x, gamma):
                    finals.append(x)
        if not finals:
            return self.v7._demand_guided_fallback(
                self.v7.dim.encode(self.lmem.get_history(), context.__dict__,
                                   getattr(context, 'env', {})),
                t_now, context, affect, eta_affect)

        best = max(finals, key=lambda x: self._margin(x))
        return True, best, 'FORGED_CGE_V8'
```

### 集成流水线（v7 → v8）

```
离线/慢时域（分钟~小时级）：
  UTL：覆盖采样 200 场景 → 用户标签 → 反例挖掘 → 保形阈值 τ̂（α=0.05）
  QDC：教师(DIM+DRC) → 蒸馏+QAT → INT8 学生 → 估计误差界 δ
  SGP：在候选样本上跑全量门 → 标定 prune_threshold = max(正例分) + δ_s
  联邦下发：τ̂、δ、QDC 权重、SGP 权重 → 站内签名分发

在线准入（目标 < 0.4 ms）：
  QDC.score ──▶ \tilde η ──▶ 与 τ' = τ̂ + δ 比较
  若 \tilde η < τ'：v7 需求导向回退
  否则：FMPP.propose ──▶ SGP 预筛（只剪）──▶ 七硬门全量验证 ──▶ ECS_v7

在线控制环：
  SGP 每候选 ~0.02 ms；QDC ~0.05 ms；被剪候选跳过 GGC/VACK/BCK
  LLM 推理链完全移出在线路径，仅在异步审计中比对 QDC 与教师分歧
```

## 4. 正确性论证（增量更新）

### 定理 13（单边预筛的保序性）

**陈述**：设 g(x)=1 表示候选 x 通过全部七硬门，SGP 满足单边可靠性 \hat g(x)=0 ⟹ g(x)=0。则在固定阈值 τ' 下，先用 SGP 预筛再走全量门，所得执行集与不做预筛时严格相等；全量门期望调用次数降低 r_prune 比例。

**证明**：预筛后保留集合 A' = {x : \hat g(x)=1}。被删除的 x 满足 \hat g(x)=0，由单边可靠性得 g(x)=0，故这些 x 本就不会进入执行集。于是 A'∩{x:g(x)=1} = {x:g(x)=1}，执行集不变。期望调用次数 E[|A'|]/E[|A|] = 1 - r_prune。∎

### 定理 14（量化安全裕度）

**陈述**：若 QDC 在域内满足 |\tilde η(x) - η(x)| ≤ δ，则采用 τ' = τ̂ + δ 时，\tilde η ≥ τ' ⟹ η ≥ τ̂。即量化不会引入相对于全精度阈值的额外错误放行（只会增加安全方向的拒绝）。

**证明**：\tilde η ≥ τ̂ + δ 且 η ≥ \tilde η - δ ≥ τ̂。故全精度下同样通过阈值。反之 \tilde η < τ' 可能对应 η ≥ τ̂（假拒绝），属安全方向。∎

### 定理 15（保形校准的有限样本错误放行控制）

**陈述**：设校准样本 (s_i, a_i) 可交换，N = {s_i : a_i=0}，n=|N|，取 τ̂ 为 N 的 ⌈(n+1)(1-α)⌉ 次序统计量。则对新的被用户拒绝样本，P(s ≥ τ̂ | a=0) ≤ α。

**证明**：对负类样本的分数序列，保形预测的标准次序统计量论证给出 P(s_{new} ≥ 第 ⌈(n+1)(1-α)⌉ 个次序统计量) ≤ α；可交换性保证新负样本与 N 同分布。∎

### 诚实声明

- 定理 13 的成立完全依赖单边可靠性，而该性质只在 SGP 的校准分布内经验成立；分布漂移会使「只剪不加」退化为「可能错剪」。
- 定理 14 的 δ 是经验误差界，边缘样本与量化溢出场景可能突破 δ；需在线监测 QDC 与教师分歧。
- 定理 15 要求可交换性；真实用户测试存在顺序效应、学习效应与非平稳性，会破坏该前提，需漂移检测与重校准。
- 用户测试样本量小、用户群体偏置会直接污染 τ̂ 与 δ 的估计；这是统计保证的边界，不是工程能消除的。

## 5. 实验设计与验证计划（仿真 → 实机 + 用户研究）

### 5.1 实验设计

- **平台**：机械臂 UR10e + 移动底盘 + 语音指令合成器 + 摄像头；端侧 Jetson Orin（验证量化与延迟）。

- **校准协议**：50% 场景作校准集，50% 作测试集；α=0.05；报告经验错误放行率与覆盖率。
- **QDC 训练**：教师 DIM+DRC 在 10k 交互日志上训练；学生 ≤2% 参数；INT8 QAT。
- **SGP 训练**：候选特征 32 维；非对称损失 λ_fp=100, λ_fa=1；在 5k 候选上标定 prune_threshold。
- **对照**：v7-full、v8-full、A21（无 UTL，τ=0.7 固定）、A22（无 SGP）、A23（无 QDC，保留全量 DIM+DRC）、A24（QDC 无 δ 裕度）、A25（SGP 允许双向/对称损失）、A26（无漂移检测）。
- **场景**：
  - (a) 需求模糊：「把东西放到合适的地方」→ QDC 低置信 → 回退；
  - (b) 高置信反例：η=0.9 但用户连续拒绝 → UTL 挖掘并抬高 τ̂；
  - (c) 分布漂移：新用户群体表情/任务分布偏移 → KS 检验触发重校准；
  - (d) 轻量化边界：SGP 误剪率、QDC 边缘样本、量化溢出；
  - (e) 延迟压测：Jetson 上 P99 与内存占用。

## 7. 本轮最大风险（最终确认）

**一句话**：**单边预筛的「单边性」只在训练/校准分布内可证**——一旦用户测试揭示的分布漂移超出 SGP 与 QDC 的校准域，\hat g(x)=0 ⟹ g(x)=0 与 |\tilde η-η| ≤ δ 两个前提会同时失效，轻量化省下的算力可能以静默漏检（错误否决或错误放行）为代价，且这种失效在结构上难以及时暴露。
