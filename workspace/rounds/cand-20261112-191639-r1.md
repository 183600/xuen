# 第 61 轮（承接第 60 轮「场景感知闭环 SGEC」IP-153~160；灵感循环第 7 轮；本轮灵感：「激光雷达」×「场景泛化」）

> 第 60 轮把「场景」从物理障碍升级为阻抗先验 π_scene(K|z)，并用 CIEC/EPIR/SERC 把认知、意图、证据串成闭环。但**三个根本局限**仍暴露：
> 1. **场景识别是「接触后」的**：SSM 的观测只有力/位遥测，而遥测只在接触发生后才存在——机器人必须先「撞上」新场景才能识别它；所谓「场景先验」实为「接触后验」，前置适应名不副实。激光雷达是唯一能在接触前给出**稠密几何**的模态。
> 2. **场景泛化停留在闭集分类**：Z_scene 固定 10 类，`unknown` 只能回退 `π_general`。真实世界的场景是**连续因子组合**（粗糙度×坡度×摩擦×柔顺性×杂乱度），未见场景大多是「已见因子的新组合」，闭集分类器把可泛化问题误当成不可泛化的拒识问题。
> 3. **几何与动力学从不互相证伪**：LiDAR 的几何预测与力遥测的动力学观测若冲突（反光/雨雾/薄布覆盖软面/打滑），第 60 轮的 XMC+ 只融合执行证据，缺少「几何先验」这一独立信息源，也就无法把冲突本身当作安全信号。

## 0. 直觉与动机

**灵感 1（激光雷达 → 接触前几何先验 LGP）**
直觉：人伸手拿杯子前，眼睛已经估算了「这看起来是硬的/滑的/倾斜的」。LiDAR 点云的局部几何——平面度、法向、坡度、粗糙度、可通行性——是**动力学的视觉指纹**：平面光滑≈刚性高，坡度大≈需补偿重力，点云破碎≈柔软/杂乱。关键洞见：**把几何指纹映射成阻抗先验 π_geo(K|P)**，让 K_safe 在接触前就收窄，把第 60 轮的「接触后识别」前移为「接触前泛化」。这不是又一个传感器融合，而是把「感知」提升为「先验生成器」。

**灵感 2（场景泛化 → 场景因子分解 SFD 与组合泛化 CSG）**
直觉：场景不是「桌子/楼梯/湿地」这些标签，而是若干近正交因子的笛卡尔积：f=(粗糙度 ρ, 坡度 θ, 摩擦 μ, 柔顺性 κ, 杂乱度 c)。见过「光滑-高摩擦-平地」和「粗糙-低摩擦-斜坡」后，面对「粗糙-高摩擦-斜坡」这个**从未见过的组合**，人仍能预测其阻抗。关键洞见：**泛化 = 因子空间中的组合插值，而非类别间的最近邻**；因此 K(f) 的可加/低秩结构直接决定泛化误差上界，也把「unknown」从一个类别变成一个可量化的支撑集距离 d(f,S_obs)。

**灵感 3（LiDAR 域偏移 → 几何-动力学一致性 CGC）**
直觉：雨雾、强反光、透明/黑色表面会让 LiDAR 的几何「说谎」，而薄布覆盖的硬桌会让几何「看不出软」。单一模态的自置信是危险的。关键洞见：**让几何预测的动力学签名与接触实测的动力学签名在共享嵌入空间对账**——一致则信任几何先验，冲突则触发额外探针或保守回退。冲突不是噪声，而是**免费的 OOD 信号**：它同时覆盖「LiDAR 域偏移」与「真实场景异常」两类失效。

**灵感 4（三灵感合流 → 主动场景泛化闭环 ASGL）**
直觉：LiDAR 先验缩小假设空间 → 因子分解把「新场景」变成「新组合」→ 保形预测给出有覆盖保证的 K 集合 → 主动选择信息量最大的接触探针来消歧 → 动力学证据回写因子模型。闭环为：**几何先验→因子组合→保形集→主动探针→动力学后验→因子模型更新**，实现「看得见的泛化、证伪得了的先验」。与第 60 轮 SERC 的区别：SERC 是「场景→约束→执行」的顺序闭环，ASGL 在闭环前端插入了**可证伪的几何假设**，并把「探针选择」变成主动决策。

**灵感 5（PCE++++ → 五维认知预算 PCE+++++）**
直觉：LiDAR 引入新的算力/带宽/采样预算 B_lidar（扫描频率、点数、几何算子开销），泛化引入 B_gen（支撑集估计、保形校准、OOD 检测开销）。任一耗尽都必须降级而非硬撑：B_lidar 耗尽⇒回退历史几何先验+接触后模式；B_gen 耗尽⇒放弃泛化、直接使用保形保守集。预算不是限制，而是**泛化野心的安全阀**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（LiDAR 几何先验 LGP）** 几何指纹到阻抗先验的跨模态映射：
- **局部点云块** P_t（半径 r，点数 n），几何特征算子 Φ_geo(P_t) → g_t ∈ R⁵：
  g = (φ_flat, ρ_rough, θ_slope, τ_trav, H_norm)
  其中 φ_flat = λ_min/(λ₀+λ₁+λ₂)（PCA 特征值平面度），ρ_rough = 点到拟合平面残差的标准差，θ_slope = 拟合法向与重力夹角，τ_trav = 最大可跨越台阶高度估计，H_norm = 法向分布熵。
- **几何→阻抗先验**：π_geo(K|P) = N(K; μ_geo(g), Σ_geo(g))，其中 μ_geo(g)=W ψ(g)+b，ψ 为 RBF 特征，W,b 由校准集 D_cal={(P_i, K_i*)} 拟合；Σ_geo(g)=Σ₀+diag(σ_j²(g)) 随 OOD 距离膨胀（见定义 163）。
- **接触前安全域**：K_safe^{geo} = {K : P_geo(K|g) ≥ τ_geo} ∩ K_safe_base，其中 K_safe_base 为第 60 轮 EEIS 的基础安全域。

**定义 162（场景因子分解 SFD）** 场景模型从「类别」改写为「因子」：
- **因子空间** F ⊂ R^d，f=(ρ_rough, θ_slope, μ_fric, κ_comp, c_clutter)。
- **编码/解码**：场景编码器 E_scene：(P_t, telemetry_{1:t}) → f_t；解码器 D_scene：f → π_scene(K|f)。
- **组合结构假设**（可加低秩）：K(f) = Σ_{j=1}^d K_j(f_j) + R(f)，其中 R 为有界交互残差，||R|| ≤ ε_R。
- **经验支撑集**：S_obs = ∪_{已见场景} Conv{f_i}；OOD 距离 d(f,S_obs) = min_{f'∈S_obs} ||f−f'||_Σ（Σ 为因子尺度矩阵）。

**定义 163（组合场景泛化 CSG）** 泛化误差与安全外推：
- 若 K(·) 在 F 上 L-Lipschitz：∀f,f'，||K(f)−K(f')|| ≤ L||f−f'||。
- **泛化误差上界**：R_gen(f_new) ≤ L·d(f_new,S_obs) + ε_R + δ_fit。
- **OOD 判定**：若 d(f_new,S_obs) > d_thresh，则标记 OOD，令 Σ_geo ← Σ_geo + λ_ood·d²·I（协方差膨胀），使 K_safe^{geo} 收缩为保守子集；此时泛化只允许「安全外推」，不允许「自信外推」。
- **关键性质**：d 增大 ⇒ 先验方差增大 ⇒ 安全域收缩 ⇒ 探针信息增益增大，形成「越不确定越主动求证」的自调节。

**定义 164（接触前-后贝叶斯校准 PBC）** 先验-似然-后验：
- 先验 π_geo(K|P)；接触似然 L(τ_contact|K) 由力/位遥测建模（高斯近似）。
- 后验：π_post(K) ∝ π_geo(K|P)^{w_geo} · L(τ_contact|K)，其中信任权重 w_geo = σ(−χ_cgc)·(1−1{d>d_thresh})，σ 为 logistic。
- **序贯更新**：每完成一次接触探针，π_post 作为下一轮先验；若 CGC 冲突，则 w_geo↓，先验退化为宽分布，避免「几何自信污染动力学证据」。

**定义 165（主动场景泛化闭环 ASGL）** 算子 ASGL(M, P_lidar, Δf_req)：
```
① LGP: g ← Φ_geo(P_lidar); π_geo, K_safe^geo ← LGP(g)
② SFD: f ← E_scene(P_lidar, telemetry_hist); d ← dist(f, S_obs)
③ CSG: if d > d_thresh: Σ_geo += λ_ood·d²·I; OOD ← True
④ CGG: C_α(f) ← conformal_set(f, q_{1-α})
⑤ PBC: π_prior ← π_geo^{w_geo} · π_hist
⑥ EEIS.compile_with_geo_prior(π_prior, Δf_req, C_α) → K_safe
⑦ ActiveProbe: p* ← argmax_p VOI(p | π_prior, budget)   # 信息增益 / 代价
⑧ Execute contact probe at p* → telemetry, EV-exec
⑨ CGC: χ ← consistency(geo_signature, dyn_signature); w_geo ← σ(−χ)
⑩ PBC update: π_post ← π_prior^{w_geo} · L(telemetry)
⑪ SFD update: factor model online calibration (bounded step ≤ η)
⑫ Return (f, K_safe, C_α, χ, OOD, EV-exec)
```

**定义 166（保形泛化保证 CGG）** 分布无关的阻抗覆盖：
- **校准集** {(f_i, K_i*)}，非一致性分数 s_i = ||K̂(f_i)−K_i*|| / σ̂(f_i)。
- **分位数** q_{1-α} = ⌈(n+1)(1−α)⌉/n 经验分位数。
- **预测集** C_α(f_new) = {K : ||K−K̂(f_new)||/σ̂(f_new) ≤ q_{1-α}}。
- **覆盖保证**：交换性成立时 P(K*(f_new) ∈ C_α(f_new)) ≥ 1−α。OOD 破坏交换性⇒按密度比加权保形（weighted conformal），权重有界时覆盖下界仍成立；无界或无法估计密度比时，强制使用保守集 C_cons = K_safe_base。

**定义 167（几何-动力学一致性 CGC）** 跨模态对账：
- **几何签名** s_geo = h_geo(g)（由坡度/粗糙度预测的力-位模板）；**动力学签名** s_dyn = h_dyn(τ_contact)。
- **一致性分数** χ = ||s_geo − s_dyn||_E（共享嵌入 E 中的距离）。
- **判定**：χ ≤ τ_cgc ⇒ 几何先验可信；χ > τ_cgc ⇒ 冲突，触发 ① 追加探针（提高信息增益权重）② w_geo 下调 ③ OOD 标记。
- **冲突归因 CGC-Attribution**：用几何可解释维度（坡度/粗糙度/平面度）与动力学异常模式（打滑/软接触/振动）做匹配，区分「LiDAR 域偏移」（几何碎、反光、雨雾）与「真实场景异常」（薄布覆盖硬面、隐藏柔软层）。

**定义 168（五维认知预算 PCE+++++）** B = (B_lidar, B_scene, B_intent, B_ros, B_exec)：
- **B_lidar** = (Scan_rate, Point_budget, Geo_compute_budget)
- **B_gen** = (Support_estimation_cost, Conformal_calibration_cost, OOD_check_cost)
- 其余继承第 60 轮 B_scene/B_intent/B_ros/B_exec。
- **VOI 扩展**：
  ```
  voi_geo(π) = VOI_meta_pessimistic(π) − cost_geo(π) − cost_cog(π) − cost_exec(π)
  cost_geo = λ_lidar·Scan_cost + λ_gen·Gen_cost + λ_probe·Probe_cost
  ```
- **降级链**：B_lidar 耗尽⇒关闭主动扫描，用历史 π_geo；B_gen 耗尽⇒禁用泛化，强制 C_cons；B_scene 耗尽⇒通用先验；B_intent/B_ros/B_exec 沿用第 60 轮策略。降级必须**单调收缩**安全域，不能反向放宽。

### IP-161 LGP（LiDAR 几何先验）

```python
class LiDARGeometryPrior:
    def __init__(self, W, b, Sigma0):
        self.W, self.b, self.Sigma0 = W, b, Sigma0
        self.r = 0.15
    def extract(self, P):
        # P: (n,3) local patch around target contact point
        c = P.mean(axis=0)
        Q = P - c
        lam, V = np.linalg.eigh(Q.T @ Q / max(len(P), 1))
        phi_flat = lam[0] / (lam.sum() + 1e-9)
        normal = V[:, 0]
        rho_rough = np.std(Q @ normal)
        theta_slope = np.arccos(np.clip(abs(normal @ np.array([0, 0, 1])), -1, 1))
        tau_trav = self._step_height(P)
        H_norm = self._normal_entropy(P)
        return np.array([phi_flat, rho_rough, theta_slope, tau_trav, H_norm])
    def prior(self, g):
        psi = self._rbf(g)
        mu = self.W @ psi + self.b
        Sigma = self.Sigma0 + np.diag(self._hetero_var(g))
        return mu, Sigma
    def safe_set(self, mu, Sigma, tau_geo=0.6):
        # Gaussian level set projected onto box constraints
        return {k: (mu[i] - 2 * np.sqrt(Sigma[i, i]),
                    mu[i] + 2 * np.sqrt(Sigma[i, i]))
                for i, k in enumerate(['Kp', 'Kd', 'Fmax'])}
```

### IP-162/163 SFD+CSG（因子分解与组合泛化）

```python
class SceneFactorModel:
    def __init__(self, d=5, eps_R=0.05, L=1.0):
        self.d, self.eps_R, self.L = d, eps_R, L
        self.support = []           # convex-hull vertices per seen factor cluster
        self.factor_decoders = {}   # additive components K_j(.)
    def encode(self, P, telemetry_hist):
        return self.scene_encoder(P, telemetry_hist)   # f in R^d
    def ood_distance(self, f):
        if not self.support:
            return float('inf')
        return min(np.linalg.norm(f - v) for v in self.support)
    def generalize(self, f, d, d_thresh=0.25, lam_ood=2.0):
        K_hat = sum(self.factor_decoders[j](f[j]) for j in range(self.d))
        bound = self.L * d + self.eps_R
        ood = d > d_thresh
        return K_hat, bound, ood
    def online_update(self, f, telemetry, max_step=0.1):
        # bounded-step calibration: never let one anomalous contact rewrite the model
        grad = self._factor_grad(f, telemetry)
        for j in range(self.d):
            self.factor_decoders[j].w += max_step * np.clip(grad[j], -1, 1)
```

### IP-164 PBC（接触前-后贝叶斯校准）

```python
class PreContactBayesCalibrator:
    def __init__(self, kappa=0.5):
        self.kappa = kappa
    def trust_weight(self, chi, ood, tau_cgc=0.3):
        geo_trust = 1.0 / (1.0 + np.exp(self.kappa * (chi - tau_cgc)))
        return 0.0 if ood else geo_trust
    def update(self, mu_prior, cov_prior, mu_lik, cov_lik, w):
        prec_prior = w * np.linalg.inv(cov_prior)
        prec_lik = np.linalg.inv(cov_lik)
        cov_post = np.linalg.inv(prec_prior + prec_lik)
        mu_post = cov_post @ (prec_prior @ mu_prior + prec_lik @ mu_lik)
        return mu_post, cov_post
```

### IP-165 ASGL（主动场景泛化闭环）

```python
def active_scene_generalization_loop(M, P, delta_f_req):
    g = M.lgp.extract(P)
    mu_geo, cov_geo = M.lgp.prior(g)

    f = M.sfm.encode(P, M.telemetry_hist)
    d = M.sfm.ood_distance(f)
    K_hat, bound, ood = M.sfm.generalize(f, d)
    if ood:
        cov_geo = cov_geo + 2.0 * d**2 * np.eye(len(cov_geo))

    C_alpha = M.cgg.conformal_set(f)
    w_geo = M.pbc.trust_weight(M.last_chi, ood)
    mu_prior, cov_prior = M.pbc.update(mu_geo, cov_geo,
                                       *M.hist_gauss(), w_geo)

    K_safe = M.eeis.compile_with_geo_prior(
        mu_prior, cov_prior, C_alpha, delta_f_req)

    p_star = M.probe.argmax_voi(mu_prior, cov_prior, M.budget)
    telemetry, EV_exec = M.exec.execute_probe(p_star, K_safe.best)

    chi, conflict, attribution = M.cgc.score(g, telemetry)
    M.last_chi = chi
    w_geo = M.pbc.trust_weight(chi, ood)
    mu_post, cov_post = M.pbc.update(mu_prior, cov_prior,
                                     *M.contact_gauss(telemetry), w_geo)

    if conflict:
        M.probe.escalate_priority(attribution)
    M.sfm.online_update(f, telemetry, max_step=0.1)
    M.epir.append(EV_exec.__dict__)

    return f, K_safe, C_alpha, chi, ood, mu_post, cov_post
```

### IP-166 CGG（保形泛化保证）

```python
class ConformalGeneralizer:
    def __init__(self, alpha=0.1):
        self.alpha = alpha
        self.scores = []
    def calibrate(self, f_list, K_star_list, K_hat_fn, sigma_fn):
        self.scores = [np.linalg.norm(K_hat_fn(f) - k) / sigma_fn(f)
                       for f, k in zip(f_list, K_star_list)]
    def q(self):
        n = len(self.scores)
        if n == 0:
            return float('inf')
        idx = min(int(np.ceil((n + 1) * (1 - self.alpha))), n) - 1
        return np.sort(self.scores)[max(idx, 0)]
    def conformal_set(self, f, K_hat_fn, sigma_fn):
        return {'center': K_hat_fn(f), 'radius': self.q() * sigma_fn(f)}
```

```python
class GeoDynamicsConsistency:
    def __init__(self, tau_cgc=0.3):
        self.tau_cgc = tau_cgc
    def score(self, g, telemetry):
        s_geo = self.h_geo(g)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| LGP | O(n + d³) / 点云块 | O(n) 点云 + O(d²) 校准 | 几何先验使 K_safe 接触前收缩 ≥ 20% |
| SFD | O(d·m) 编码（m 为因子基） | O(d + \|S_obs\|) | 因子重构误差 ≤ ε_R |
| CSG | O(\|S_obs\|·d) OOD 查询 | O(\|S_obs\|) | 泛化误差 ≤ L·d + ε_R + δ_fit |
| PBC | O(d³) 高斯更新 | O(d²) | 后验一致，权重冲突时单调退化 |
| CGG | O(n log n) 校准 / O(1) 查询 | O(n) | 覆盖 ≥ 1−α（交换性下） |
| CGC | O(d) 打分 | O(d) | 冲突检测 F1 ≥ 0.9 |
| ASGL | O(闭环 + 探针) | 复用 | 未见场景成功率 ≥ 82% |

**正确性定理（ASGL）**：假设 A66–A70 成立：

```python
class LiDARGeometryPrior:
    def __init__(self, W, b, Sigma0):
        self.W, self.b, self.Sigma0 = W, b, Sigma0
        self.r = 0.15
    def extract(self, P):
        c = P.mean(axis=0)
        Q = P - c
        lam, V = np.linalg.eigh(Q.T @ Q / max(len(P), 1))
        phi_flat = lam[0] / (lam.sum() + 1e-9)
        normal = V[:, 0]
        rho_rough = np.std(Q @ normal)
        theta_slope = np.arccos(np.clip(abs(normal @ np.array([0, 0, 1])), -1, 1))
        tau_trav = self._step_height(P)
        H_norm = self._normal_entropy(P)
        return np.array([phi_flat, rho_rough, theta_slope, tau_trav, H_norm])
    def prior(self, g):
        psi = self._rbf(g)
        mu = self.W @ psi + self.b
        Sigma = self.Sigma0 + np.diag(self._hetero_var(g))
        return mu, Sigma
    def safe_set(self, mu, Sigma, tau_geo=0.6):
        return {k: (mu[i] - 2 * np.sqrt(Sigma[i, i]),
                    mu[i] + 2 * np.sqrt(Sigma[i, i]))
                for i, k in enumerate(['Kp', 'Kd', 'Fmax'])}
```

```python
    def __init__(self, d=5, eps_R=0.05, L=1.0):
        self.d, self.eps_R, self.L = d, eps_R, L
        self.support = []
        self.factor_decoders = {}

        return self.scene_encoder(P, telemetry_hist)
    def ood_distance(self, f):
        if not self.support:
            return float('inf')
        return min(np.linalg.norm(f - v) for v in self.support)
    def generalize(self, f, d, d_thresh=0.25, lam_ood=2.0):
        K_hat = sum(self.factor_decoders[j](f[j]) for j in range(self.d))
        bound = self.L * d + self.eps_R
        ood = d > d_thresh
        return K_hat, bound, ood
    def online_update(self, f, telemetry, max_step=0.1):
        grad = self._factor_grad(f, telemetry)
        for j in range(self.d):
            self.factor_decoders[j].w += max_step * np.clip(grad[j], -1, 1)
```

### IP-164 PBC（接触前-后贝叶斯校准）

```python
class PreContactBayesCalibrator:
    def __init__(self, kappa=0.5):
        self.kappa = kappa
    def trust_weight(self, chi, ood, tau_cgc=0.3):
        geo_trust = 1.0 / (1.0 + np.exp(self.kappa * (chi - tau_cgc)))
        return 0.0 if ood else geo_trust
    def update(self, mu_prior, cov_prior, mu_lik, cov_lik, w):
        prec_prior = w * np.linalg.inv(cov_prior)
        prec_lik = np.linalg.inv(cov_lik)
        cov_post = np.linalg.inv(prec_prior + prec_lik)
        mu_post = cov_post @ (prec_prior @ mu_prior + prec_lik @ mu_lik)
        return mu_post, cov_post
```

```python
class ConformalGeneralizer:
    def __init__(self, alpha=0.1):
        self.alpha = alpha
        self.scores = []
    def calibrate(self, f_list, K_star_list, K_hat_fn, sigma_fn):
        self.scores = [np.linalg.norm(K_hat_fn(f) - k) / sigma_fn(f)
                       for f, k in zip(f_list, K_star_list)]
    def q(self):
        n = len(self.scores)
        if n == 0:
            return float('inf')
        idx = min(int(np.ceil((n + 1) * (1 - self.alpha))), n) - 1
        return np.sort(self.scores)[max(idx, 0)]
    def conformal_set(self, f, K_hat_fn, sigma_fn):
        return {'center': K_hat_fn(f), 'radius': self.q() * sigma_fn(f)}
```
