### 第 1 轮灵感驱动研究记录（承接 KTCG v28）

**灵感词**：痛点分析、场景泛化

**直觉与动机**：
前几轮把 KEMPC 一路加码到「九证一体」的 KTCG v28：证书越叠越多、准入越来越严。但这里藏着一个一直没被正面回答的问题——**我们一直在证明「系统在已知常识下安全」，却很少量化「系统到底在哪里疼」**。痛点分析不是再列一张风险表，而是把「疼」变成可测量、可定位、可排序的信号；场景泛化也不是把规则往新场景硬迁移（这正是上一轮 R22 负外部性的根源），而是**用痛点信号反向决定该泛化到哪里**。

核心转向：从「知识驱动的安全扩张」转为「痛点驱动的场景泛化」——

1. **痛点分析**：定义五维痛点向量 p=(p_safe, p_cons, p_consist, p_expl, p_trans)，分别对应安全违规、过度保守、模型失配、解释退化、迁移校准误差。每一维按自己的容差 τ_j 归一化为 p̃_j=p_j/τ_j，再合成标量痛点指数 PI(p)=‖W⊙p̃‖₂。用 Pareto 前沿定位非支配痛点，避免「用总罚分掩盖单点剧痛」——一个 PI 很低的系统，可能在湿滑地面上单点剧痛。

2. **场景泛化**：把场景参数 θ（摩擦系数、坡度、负载、速度、传感噪声）视为可搜索空间，但只允许在「现实流形」Θ_R={θ:R(θ)≤ε_R} 内扰动。R 用经验场景分布的 KDE 负对数密度或马氏距离构造。这直接堵住「生成物理上不存在的对抗场景、刷高泛化分」的漏洞。

3. **痛点定向采样**：用倾斜分布 q_β(θ)∝exp(β·P(θ;π))·1[θ∈Θ_R] 把有限评估预算压到高痛点区，再用重要性权重 w(θ)=p_real(θ)/q_β(θ) 把覆盖估计无偏地还原到真实场景分布。痛点分析负责「指方向」，场景泛化负责「补盲区」，二者形成互为因果的闭环：新场景暴露新痛点，新痛点再驱动下一轮泛化。

4. **泛化证书 SGC**：不再只验证单个场景，而是对场景族给出带置信度的覆盖下界。SGC=(τ,n,δ,Ĉ_τ,ESS,W_max)，其中 ESS 为有效样本量、W_max 为权重上界。PG-KTCG = KTCG ∪ PVM ∪ SGO ∪ SGC，把「点安全」升级为「族安全」。

**关键洞见**：痛点分析与场景泛化不是并列的两件事，而是互为因果的闭环。这把上一轮「盲目迁移导致 μ 膨胀」的风险，替换为「定向补盲但可能过拟合代理指标」的新风险；风险性质从「隐蔽的错误安全」变为「可观测的代理失真」，这是可工程化的进步，但不是免费的午餐。

**形式化目标（增量）**：
1. 定义五维痛点向量 p 与归一化痛点指数 PI(p)=‖W⊙p̃‖₂，p̃_j=p_j/τ_j。
2. 定义现实流形约束 Θ_R={θ:R(θ)≤ε_R} 与 KDE 密度估计 R(θ)=-log p̂(θ)+const。
3. 定义痛点倾斜采样 q_β 与重要性加权覆盖估计 Ĉ_τ，给出无偏性与方差/ESS 分析。
4. 定义泛化证书 SGC 与覆盖下界 Ĉ_τ - W_max·√(log(1/δ)/(2n))。
5. 构造 PG-KTCG，证明其准入蕴含各痛点分量受控（引理 26）与真实场景覆盖下界（定理 29）。
6. 实验：在双足仿真上对比 KTCG v28 的均匀评估，目标在相同置信度下减少约 40% 评估样本、把最坏场景违规率降低约 30%，并显式报告代理失真（合成痛点集与留出真实痛点集的 PI 差）。

**本轮最大风险**：**痛点代理失真（Goodhart 风险）**——PI 是我们能测的代理，不是安全本身；痛点定向采样会把预算集中到「可测的疼」，于是策略可能被优化成「在合成痛点集上不疼」，却对未建模的真实痛点（未知未知）更脆弱。更隐蔽的是，倾斜采样在痛点尾部会产生大方差的重要性权重，使覆盖证书在高痛点区失效，而系统仍显示「已认证」。

### IP-467 Pain Vector Monitor (PVM)

```python
@dataclass
class PainVector:
    p: np.ndarray          # 五维原始痛点
    p_tilde: np.ndarray    # 按容差归一化
    PI: float              # 痛点指数
    pareto: bool = False   # 是否位于 Pareto 前沿

@dataclass
class PainVectorMonitor:
    tau: dict = field(default_factory=lambda: {
        "safe": 0.05, "cons": 0.15, "consist": 0.10,
        "expl": 0.30, "trans": 0.10})
    W: dict = field(default_factory=lambda: {
        "safe": 3.0, "cons": 1.0, "consist": 1.5,
        "expl": 1.0, "trans": 2.0})
    archive: list = field(default_factory=list)   # 历史痛点向量（Pareto 用）

    def compute(self, traj: Tensor, u_traj: Tensor,
                meta: dict) -> PainVector:
        p = np.array([
            self._safety_pain(traj, meta),          # p_safe
            self._conservatism_pain(traj, meta),    # p_cons
            self._consistency_pain(meta),           # p_consist
            self._explanation_pain(meta),           # p_expl
            self._transfer_pain(meta),              # p_trans
        ], dtype=float)
        tau = np.array([self.tau[k] for k in
                        ("safe", "cons", "consist", "expl", "trans")])
        W = np.array([self.W[k] for k in
                      ("safe", "cons", "consist", "expl", "trans")])
        p_tilde = p / np.maximum(tau, 1e-9)
        PI = float(np.linalg.norm(W * p_tilde))
        pv = PainVector(p, p_tilde, PI)
        self.archive.append(pv)
        pv.pareto = self._is_nondominated(pv, self.archive)
        return pv

    def _safety_pain(self, traj: Tensor, meta: dict) -> float:
        viol = float(meta.get("violation_rate", 0.0))
        # 近失：安全裕度亏欠的均值，margin 越小惩罚越大
        margins = meta.get("safety_margins", [1.0])
        deficit = float(np.mean([max(0.0, 0.05 - m) for m in margins]))
        return viol + 2.0 * deficit

    def _conservatism_pain(self, traj: Tensor, meta: dict) -> float:
        prog = float(meta.get("task_progress", 1.0))
        ref = float(meta.get("nominal_progress", 1.0)) + 1e-9
        return max(0.0, 1.0 - prog / ref)

    def _consistency_pain(self, meta: dict) -> float:
        kappa_hat = float(meta.get("kappa_hat", 0.0))
        kappa_ref = float(meta.get("kappa_ref", 1.0)) + 1e-9
        return abs(kappa_hat - kappa_ref) / kappa_ref

    def _explanation_pain(self, meta: dict) -> float:
        # 规则激活分布的归一化熵越低，单一规则主导越严重
        probs = np.asarray(meta.get("rule_activation_probs", [1.0]), float)
        probs = probs / (probs.sum() + 1e-9)
        H = -float(np.sum(probs * np.log(probs + 1e-9)))
        H_max = np.log(max(len(probs), 2))
        return max(0.0, 1.0 - H / H_max)

    def _transfer_pain(self, meta: dict) -> float:
        pairs = meta.get("transfer_pairs", [])  # [(mu_pred, mu_real)]
        if not pairs:
            return 0.0
        return float(np.mean([abs(mu_p - mu_r) for mu_p, mu_r in pairs]))

    @staticmethod
    def _is_nondominated(pv: PainVector, archive: list) -> bool:
        # 五维越小越好；被任一历史点逐维支配则为受支配点
        for other in archive:
            if other is pv:
                continue
            if np.all(other.p <= pv.p) and np.any(other.p < pv.p):
                return False
        return True
```

### IP-468 Scenario Generalization Operator (SGO)

```python
class ScenarioGeneralizationOperator:
    """在现实流形内搜索高痛点场景：CEM + 现实度投影"""

    def __init__(self, theta_lo, theta_hi, realism_model,
                 pop_size=32, n_elite=8, n_iter=20,
                 eps_R=0.5, novelty_weight=0.2):
        self.lo = np.asarray(theta_lo, float)
        self.hi = np.asarray(theta_hi, float)
        self.realism = realism_model        # R(theta) -> float
        self.pop, self.elite = pop_size, n_elite
        self.iters, self.eps_R = n_iter, eps_R
        self.novelty_weight = novelty_weight

    def propose(self, policy, pain_fn, n_return=64) -> list[np.ndarray]:
        mu = (self.lo + self.hi) / 2.0
        sigma = (self.hi - self.lo) / 4.0
        best = []
        for _ in range(self.iters):
            cand = np.clip(
                np.random.randn(self.pop, len(mu)) * sigma + mu,
                self.lo, self.hi)
            # 现实度投影：越界样本向可行域内收缩
            cand = np.array([self._project_realism(c) for c in cand])
            score = np.array([
                pain_fn(policy, c)
                + self.novelty_weight * self._novelty(c, best)
                for c in cand])
            elite = cand[np.argsort(score)[-self.elite:]]
            mu = elite.mean(axis=0)
            sigma = elite.std(axis=0) + 1e-3
            best.extend(elite.tolist())
        best = np.array(best[-n_return:])
        return [c for c in best if self.realism(c) <= self.eps_R]

    def _project_realism(self, theta: np.ndarray) -> np.ndarray:
        t = theta.copy()
        for _ in range(8):
            if self.realism(t) <= self.eps_R:
                return t
            # 向参数中心收缩，保证投影后仍物理可行
            t = 0.5 * t + 0.5 * (self.lo + self.hi) / 2.0
        return t

    @staticmethod
    def _novelty(theta: np.ndarray, archive: list) -> float:
        if not archive:
            return 1.0
        d = np.min(np.linalg.norm(np.asarray(archive) - theta, axis=1))
        return float(np.tanh(d))
```

### IP-469 Pain-Tilted Sampler & Coverage Estimator (PTSCE)

```python
class PainTiltedSampler:
    """痛点倾斜采样 + 重要性加权覆盖估计"""

    def __init__(self, beta=2.0, W_max=50.0):
        self.beta = beta
        self.W_max = W_max

    def sample(self, sgo, policy, pain_fn, n=500, grid_res=64):
        # 离散化场景网格，构造 q_beta ∝ exp(beta*P) 1[Theta_R]
        axes = [np.linspace(lo, hi, grid_res)
                for lo, hi in zip(sgo.lo, sgo.hi)]
        grid = np.stack(np.meshgrid(*axes, indexing="ij"), -1).reshape(-1, len(axes))
        grid = np.array([g for g in grid if sgo.realism(g) <= sgo.eps_R])
        P = np.array([pain_fn(policy, g) for g in grid])
        logits = self.beta * P
        q = np.exp(logits - logits.max())
        q /= q.sum()
        idx = np.random.choice(len(grid), size=min(n, len(grid)),
                               replace=True, p=q)
        return grid[idx], q[idx], grid, q

    def estimate_coverage(self, samples, q_probs, policy, pain_fn,
                          tau, p_real=None, delta=0.05):
        P = np.array([pain_fn(policy, s) for s in samples])
        ind = (P <= tau).astype(float)
        if p_real is None:
            p_real = np.ones(len(samples)) / len(samples)
        w = p_real / np.maximum(q_probs, 1e-12)
        w = np.clip(w, 0.0, self.W_max)
        chat = float(np.mean(w * ind))
        ess = float((w.sum() ** 2) / (np.sum(w ** 2) + 1e-12))
        radius = self.W_max * np.sqrt(np.log(1.0 / delta) / (2.0 * len(samples)))
        return {
            "C_hat": chat,
            "lower": max(0.0, chat - radius),
            "ESS": ess,
            "W_max": float(w.max()),
            "n": len(samples),
            "delta": delta,
        }
```

### IP-470 Scenario Generalization Certificate (SGC)

```python
@dataclass
class ScenarioGeneralizationCertificate:
    tau: float
    n: int
    delta: float
    C_hat: float
    lower_bound: float
    ESS: float
    W_max: float
    coverage_target: float = 0.95
    min_ESS_ratio: float = 0.05   # ESS/n 下限，防止尾部权重塌缩

    def is_valid(self) -> bool:
        if self.ESS < self.min_ESS_ratio * self.n:
            return False           # 权重退化：证书不可信
        return self.lower_bound >= self.coverage_target

    def to_report(self) -> dict:
        return {
            "tau": self.tau, "n": self.n, "delta": self.delta,
            "C_hat": self.C_hat, "lower_bound": self.lower_bound,
            "ESS": self.ESS, "W_max": self.W_max,
            "valid": self.is_valid(),
        }
```

### IP-471 Pain-Guided Knowledge-Transilient MPC (PG-MPC)

```python
@dataclass
class PainGuidedMPC(KnowledgeTransilientMPC):
    """在 KT-MPC 基础上加入痛点反馈：既防违规，也防过度保守"""
    pvm: PainVectorMonitor = None
    lambda_pain: float = 5.0

    def compute_knowledge_penalty(self, x: Tensor, kc_idx: int = None) -> float:
        base = super().compute_knowledge_penalty(x, kc_idx)
        if self.pvm is None:
            return base
        # 用上一控制周期缓存的痛点指数做在线反馈
        PI = float(getattr(self, "_last_PI", 0.0))
        return base + self.lambda_pain * max(0.0, PI - 1.0) ** 2

    def solve(self, x0: Tensor):
        u, kc, dcc, expl = super().solve(x0)
        # 用实际执行轨迹更新痛点缓存，供下一周期使用
        x_traj = self._simulate_trajectory(x0, np.asarray(u)[None, :])
        pv = self.pvm.compute(x_traj, np.asarray(u)[None, :], self._meta)
        self._last_PI = pv.PI
        self._last_pain = pv
        return u, kc, dcc, expl
```

### IP-472 Pain-Guided Cert Gate (PG-KTCG)

```python
@dataclass
class PainGuidedCertificationGate:
    ktcg: KnowledgeTransilientCertificationGate
    pvm: PainVectorMonitor
    sgo: ScenarioGeneralizationOperator
    ptsce: PainTiltedSampler
    sgc: ScenarioGeneralizationCertificate | None = None
    tau: float = 1.0

    def admits(self, robot_plan, sensor_data) -> bool:
        # 1) 原有九证准入（点安全）
        if not self.ktcg.admits(robot_plan, sensor_data):
            return False

        # 2) 当前计划的实际痛点必须受控
        traj = robot_plan.actual_traj
        u_traj = robot_plan.control_seq
        pv = self.pvm.compute(traj, u_traj, sensor_data.get("meta", {}))
        if pv.PI > self.tau:
            return False

        # 3) 场景族泛化证书必须有效（族安全）
        if self.sgc is None or not self.sgc.is_valid():
            return False

        # 4) 若存在 Pareto 非支配的高痛点，强制进入补盲队列
        if any(p.pareto and p.PI > self.tau for p in self.pvm.archive[-64:]):
            self._enqueue_remediation(pv)
            return False
        return True

    def recertify(self, policy, pain_fn, n=500, delta=0.05) -> ScenarioGeneralizationCertificate:
        samples, q_probs, _, _ = self.ptsce.sample(self.sgo, policy, pain_fn, n)
        stats = self.ptsce.estimate_coverage(
            samples, q_probs, policy, pain_fn, self.tau, delta=delta)
        self.sgc = ScenarioGeneralizationCertificate(
            tau=self.tau, n=stats["n"], delta=delta,
            C_hat=stats["C_hat"], lower_bound=stats["lower"],
            ESS=stats["ESS"], W_max=stats["W_max"])
        return self.sgc

    def _enqueue_remediation(self, pv):
        self._remediation_queue = getattr(self, "_remediation_queue", [])
        self._remediation_queue.append(pv)
```

## 3. 复杂度分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| PVM 痛点计算 | O(T + N_rule + N_trans) | O(N_archive) | T≤200, N_rule≤50, N_archive≤64 |
| SGO 场景搜索 | O(I·(P·d + P·R_KDE)) | O(I·P·d) | I=20, P=32, d≤8 |
| PTSCE 倾斜采样 | O(G^d·(C_pain + C_realism)) | O(G^d) | 网格分辨率 G=64，高维需改用 MCMC/切片采样 |
| SGC 覆盖估计 | O(n·(C_pain + C_dyn)) | O(n) | n=500, ESS 需 ≥0.05n |
| PG-MPC 单步 | O(KT-MPC) + O(T) | O(T) | 痛点反馈开销 <5% |
| PG-KTCG 总体 | O(KTCG) + O(n·C_pain) | O(N_archive + n) | 关键路径仍是 KT-MPC 求解 |

**实时性**：PVM 单步 <1ms；SGO/PTSCE/SGC 属于「评估周期」（每 N 个控制周期或触发补盲时）运行，单次 50–200ms，不进入 50Hz 实时控制回路；PG-MPC 的痛点反馈项 <0.2ms。

## 4. 正确性论证（增量更新）

### 引理 26（痛点指数的单维受控性）

**陈述**：若 PI(p)=‖W⊙p̃‖₂ ≤ 1 且所有 W_j ≥ 1，则对任意 j 有 p_j ≤ τ_j。

**证明**：因 p_j ≥ 0、τ_j > 0，故 p̃_j ≥ 0。由 W_j ≥ 1 得 PI² = Σ_k W_k² p̃_k² ≥ W_j² p̃_j² ≥ p̃_j²，即 p̃_j ≤ PI ≤ 1，于是 p_j = τ_j p̃_j ≤ τ_j。∎

**意义**：这条引理保证「总指数达标」不会掩盖「单维爆表」——只要 W_j≥1，任何一维痛点都受各自容差约束。这是对上一轮「用总罚分掩盖单点剧痛」缺陷的直接修补。

### 引理 27（重要性加权覆盖估计的无偏性）

**陈述**：设 θ_i ~ q_β，w(θ)=p_real(θ)/q_β(θ)，则 Ĉ_τ=(1/n)Σ w(θ_i)·1[P(θ_i;π)≤τ] 满足 E_q[Ĉ_τ]=C_τ。

**证明**：E_q[w(θ)·1[P≤τ]] = ∫ q(θ)·(p_real(θ)/q(θ))·1[P≤τ] dθ = ∫ p_real(θ)·1[P≤τ] dθ = C_τ。线性性给出样本均值无偏。∎

**注意**：无偏性依赖 q 在 p_real 支撑上严格正（绝对连续）。若 q_β 在尾部截断，则只在被覆盖的支撑上无偏，这是本轮风险 R26 的来源。

### 引理 28（ESS 与覆盖下界）

**陈述**：设权重截断于 W_max，则对 n 个独立样本，以概率 ≥1-δ 有 C_τ ≥ Ĉ_τ - W_max·√(log(1/δ)/(2n))。

**证明**：令 Z_i=w(θ_i)·1[P≤τ]，由截断知 Z_i∈[0,W_max]。Hoeffding 不等式给出 Pr(|Ĉ_τ-C_τ|≥ε) ≤ 2exp(-2nε²/W_max²)。令右端等于 δ 并取单侧，得 ε=W_max·√(log(1/δ)/(2n))，故 C_τ ≥ Ĉ_τ-ε 以 ≥1-δ 成立。∎

**推论**：当 ESS=(Σw)²/Σw² 过小时，等效样本量 n_eff<ESS，上述界需用 n_eff 代替 n，否则会高估置信度。故 SGC 强制 ESS/n ≥ 0.05。

### 定理 29（PG-KTCG 的场景族覆盖保证）

**陈述**：若 PG-KTCG 在置信度 1-δ 下准入策略 π，且 SGC 有效（lower_bound ≥ coverage_target、ESS/n ≥ 0.05），则在现实流形 Θ_R 上、权重有界假设下，π 满足 PI≤τ 的真实场景覆盖 C_τ ≥ coverage_target。

**证明**：由 SGC.is_valid() 得 lower_bound=Ĉ_τ-ε ≥ coverage_target。由引理 28，以 ≥1-δ 有 C_τ ≥ Ĉ_τ-ε = lower_bound。又由引理 27，Ĉ_τ 是 C_τ 的无偏估计。故 C_τ ≥ coverage_target。再由 PG-KTCG 的准入条件 PI(π)≤τ 与引理 26，各痛点分量均受容差约束。∎

**局限**：该定理把「现实场景分布」建模为 Θ_R 上的已知 p_real；一旦真实部署分布漂移到 Θ_R 之外，保证失效。这正是 R27 的核心。

## 5. 实验设计

**平台**：双足机器人仿真（MuJoCo，Cassie/Atlas 简化模型），控制频率 50Hz，预测时域 N=20。

**场景参数 θ（d=6）**：

| 维度 | 范围 | 现实流形约束 |
|---|---|---|
| 地面摩擦 μ | [0.2, 1.0] | 低摩擦与高坡度组合需联合约束 |
| 坡度 | [0°, 15°] | 坡度>12° 时摩擦不得<0.4 |
| 负载 | [0, 20] kg | 负载与速度负相关 |
| 速度 | [0, 1.5] m/s | 由步态可行性约束 |
| 传感噪声 σ_s | [0, 0.05] | 噪声与速度正相关 |
| 地形粗糙度 | [0, 0.08] m | 粗糙度与坡度弱负相关 |

**对比方法**：
- B1：KTCG v28 + 均匀随机场景评估（n=500）
- B2：KTCG v28 + 纯对抗场景搜索（无现实流形约束）
- B3：KTCG v28 + 规则迁移（CTKTP，无痛点反馈）
- Ours：PG-KTCG（PVM+SGO+PTSCE+SGC）

**指标**：
1. 认证覆盖率 C_τ 与覆盖下界（同置信度 95%）
2. 达到相同下界所需样本数 n
3. 留出真实场景集上的最坏场景违规率与 PI_95 分位
4. 过度保守度 p_cons（任务进度损失）
5. 代理失真 Gap = PI(synthetic pain set) - PI(held-out real pain set)
6. ESS/n 与 W_max（证书可信度诊断）

**预期结果（模拟，待真机/完整仿真验证）**：

| 方法 | n 需求 | 覆盖下界 | 最坏违规率 | p_cons | 代理失真 Gap | ESS/n |
|---|---|---|---|---|---|---|
| B1 均匀 | 500 | 0.91 | 8.2% | 0.18 | 0.07 | 1.00 |
| B2 对抗 | 500 | 0.96 | 5.1% | 0.27 | 0.31 | 0.22 |
| B3 规则迁移 | 500 | 0.88 | 11.4% | 0.15 | 0.12 | 0.71 |
| Ours | 300 | 0.95 | 5.6% | 0.16 | 0.09 | 0.34 |

**结论预期**：痛点定向采样在保持覆盖下界的同时把样本需求从 500 降到约 300（-40%），最坏违规率较均匀评估降低约 30%；但代价是 ESS/n 从 1.00 降到 0.34、Gap 从 0.07 升到 0.09，说明「效率提升」与「代理失真」是一体两面，必须把 ESS 和 Gap 作为一等公民指标而非事后补丁。

**消融**：
- 去掉现实流形约束 → 覆盖虚高、Gap 显著增大（预期 0.31，同 B2）
- 去掉痛点倾斜（β=0）→ 退化为 B1
- 去掉 SGC 的 ESS 门限 → 尾部权重塌缩时仍误报「有效」，复现 R26
- 把 W 设为均匀权重 → 单维爆表被总指数掩盖，验证引理 26 中 W_j≥1 的必要性

|---|---|---|---|---|
| R25 | 痛点维度选取遗漏关键失效模式，导致「测不到的疼」被系统性忽略 | 高 | 1) 痛点维度可插拔注册；2) 用事故日志做后验因子分析补维；3) 保留一个「未知痛点」哨兵维（残差能量） | 真正的未知未知仍无法被现有维度捕获 |
| **R26** | **倾斜采样尾部权重塌缩，使覆盖证书在高痛点区失效却仍显示有效** | **高** | **1) SGC 强制 ESS/n ≥ 0.05 与 W_max 上限；2) 权重截断 + 保守偏差修正；3) 尾部改用分层采样或 MCMC；4) 证书显式报告 ESS 与 W_max** | **极端尾部（如 μ=0.2 且 15° 坡）样本极少，任何有限样本保证都脆弱** |

| R29 | SGO 的 CEM 搜索开销与实时性冲突 | 中 | 1) 评估周期异步化；2) 增量式 CEM 热启动；3) 场景缓存复用 | 高维场景（d>10）搜索退化 |

## 7. 本轮最大风险（最终确认）

**一句话**：**痛点代理失真（Goodhart 风险）**——PI 是我们能测的代理而非安全本身，痛点定向采样会把预算压到「可测的疼」，策略因此可能被优化成「在合成痛点集上不疼」，却在未建模的真实痛点与分布漂移（R27）下更脆弱；更隐蔽的是，倾斜采样在尾部的重要性权重塌缩（R26）会让覆盖证书在高痛点区失效，而系统仍显示「已认证」——这是一种比单纯违规更难察觉的「证书幻觉」。
