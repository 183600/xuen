# 第 58 轮（承接第 57 轮「少样本元推断×跨模态对账×个性化有界信任」IP-133~138；灵感循环第 4 轮；本轮灵感：「创新点挖掘」×「长程任务」）

> 第 57 轮把安全从"模型置信"推进到"少样本可校准、跨模态可对账、个性化有界的证据承诺"：MFSL 用元先验换效率、共形带保底，XMC 以分歧下限拆穿单模态共谋，PTM 把人从常量变成单向有界状态机。但它的全部定理都隐含一个**单步世界观**：每一条 δ_f、每一个证据门、每一次 J_p 都只对一个检查点的一次承诺负责；而真实部署是数小时、数天、上千次承诺的**长程任务**。这暴露三个更深的裂缝：**(a) 单步健全不等于长程健全**——把每步 δ_f=1e−3 用联合界累到 10^4 步，任务级界变成 1，只能靠极端保守换安全，系统因此不可用；反过来若不累积，长程失败率无人负责。风险需要一个**账户**，而不是一个**上界**。**(b) 长程中世界会漂移**——光照、天气、磨损、物体被移动、操作者换班；第 57 轮的证据、元先验与 OOD 门都默认训练分布稳定，证据没有"保质期"，漂移后旧证书仍被当成新鲜证据使用。**(c) 长程会不断遇到训练语料里没有的失效模式**——而第 57 轮的探索只是在**已知参数**上做 VOI，不会发现"原来还存在这一类失败"。同时，本轮另一个灵感「创新点挖掘」迫使研究本身反省：我们已经积累了 138 个 IP、40 条假设，**下一个真正的创新点不在继续加机制，而在找出"承重却最少被检验的假设"**。于是本轮把"研究如何挖创新"与"系统如何跑长程"合成一件事：**把假设当作可被证伪的对象，把发现当作只增不减的义务**。核心命题升级为 **"风险可记账、证据可保质、失效可归因、未知可挖掘的承诺"**。

核心矛盾：
- **H29（长程复合 vs 单步校准）**：单步 δ_f 不能直接相加，联合界在长程下必然真空；任何"任意时有效"的统计账本都要交换性/稳定零假设，而长程恰恰破坏它；且可自适应花费的风险预算本身制造了"先赌高价值步、后补低价值步"的博弈。
- **H30（漂移 vs 证据半衰期）**：证据越老越不可信，但全量再证在长程里成本不可支付；半衰期与漂移时刻都未知，用"已经出事"来估计半衰期已经太晚。
- **H31（挖掘 vs 安全）**：未知失效模式只能靠主动挖掘发现，但挖掘要花探针、会扰动系统、且"找什么"由系统自己决定——既可能漏掉（看不见的未知），也可能自我确认（挖出自己制造的假模式）；而"发现只加约束"会带来义务膨胀，长程里最终被迫剪枝，剪枝就是唯一允许的"减"路径，也是安全侵蚀的入口。
- **H32（归因 vs 因果）**：跨时间追责依赖 provenance 图，但记录不全时回溯会漏污（坏的没被污染）或误污（好的被连坐）；过宽 taint 会冻结系统，过窄 taint 会让坏证据在长程里继续发放证书。

## 0. 直觉与动机

**灵感 1（长程任务 → 风险是账户，不是上界；任意时有效的风险账本）**
直觉：短任务里"这一步失败概率 ≤ δ"是有用的；长任务里真正的问题是"**到目前为止，我已经把多少失败风险花掉了，账户还剩多少**"。联合界相当于每步都按最坏情况冻结额度，长程必然破产；正确做法是像**投资组合**一样管理风险：给任务设一个总预算 α_mission，每一步的允许失败率不是常数 δ_f，而是由**当前累计证据与累计失败**决定的、随时间有效的上界 U_t；只要 U_t 逼近预算就自动收紧（加探针、降档、绕行），远低于预算才允许高价值承诺加速。用**置信序列 / e-process**替代"每步独立 δ_f"，把"这一次不会错"换成"任何时刻看，长期失败率都不超过 α_mission"，且无需事先知道步数。关键护栏是**不可透支的储备金**：总预算的一部分永久锁死，只用于"出事后的补救与再证"，不参与任何效率交易。

**灵感 2（长程任务 → 证据有保质期，再证是义务）**
直觉：一次触探证明的是"**那一刻、那个政策、那个季节**下的地面"。长程里世界会变：白天变夜晚（视觉失重）、干燥变潮湿（摩擦下降）、鞋底磨平、物体被搬走。第 57 轮的证据只带时间戳，却没带"**在什么漂移速度下还能用多久**"。给每类证据一个**半衰期**与**敏感协变量集**，用变化点检测/置信序列在线监测漂移；一旦某个协变量漂移超过阈值，所有支撑域覆盖它的证书立即降级为"待再证"，并在 τ_renew 内安排一次**最小再证**（不是全量重探，只重探对漂移最敏感的那一维）。再证成本计入**证据债**；债务超限的区域不再接受新的高价值承诺——**不是不让做事，而是先把欠的证据还上**。

**灵感 3（长程任务 → 失效要能跨时间归因；证书栈与污染闭包）**
直觉：长程里最危险的不是"这一步错了"，而是"**第 3 步采的信，到第 900 步才被证明是假的，中间 897 步都在用假信发证书**"。第 57 轮已有"事后证伪回溯"，但只回溯降权一个模态；长程需要**沿依赖图传播污染**：每条证书记录它用了哪些证据、哪些子证书、在什么政策锁下；一旦某证据被证伪，取它的**传递闭包**，把所有下游证书标为 provisional，禁止其授权不可逆动作，并按账本退回相应风险额度。过宽会误伤，过窄会漏污，所以需要一个可审计的**最小充分依赖集**和"污染可申诉、但申诉期间一律按保守处理"的单向规则。再往上一层，**子目标之间要有接口契约**：上一个子目标不能把"任务完成了但世界变脆了"的风险甩给下一步；接口只接受落在已证安全集里的后置状态。

**灵感 4（创新点挖掘 → 挖"承重却少被检验"的假设，而不是继续加机制）**
直觉：一个研究纲领最容易陷入的陷阱，是**不断给已经很强的部分再加一层**，而真正的断裂点总在"大家都在用、却没人认真测过"的假设上。把 138 个 IP 与 40 条假设显式建成一张**依赖超图**，给每条假设算三个量：**承重度**（多少定理依赖它）、**覆盖度**（多少实验真的在它上面做过压力测试）、**可证伪度**（能否设计出会杀死它的实验）。于是创新点 = "承重 × 未覆盖 × 可证伪"乘积最大的那些假设的**否定式**：把"世界平稳"否定成"世界会漂移"→ 得到 EHD；把"单步风险可加"否定成"单步风险不可加"→ 得到 LRL。这不是文字游戏，而是把"灵感"变成**可排序、可审计、可复现**的挖掘算子；它还能反过来给本轮的在线机制供料。

**灵感 5（创新点挖掘 × 长程任务 → 在线失效模式挖掘器：发现只加不减）**
直觉：长程最大的价值不是"跑得久"，而是"**见得多的失败**"。人类的创新往往来自 near-miss（差点出事）而不是事故本身；系统也应如此。维护一个**候选失效模式假设库**（来自跨模态分歧、人工纠正、差一点越界、异常探针残差），用**判别性探针/实验**去主动证伪它们（bandit/信息增益），用**独立的探索预算**支付成本（绝不挪用安全储备）。一旦某模式被确认，就编译成一条**新义务**（新的证据类、新的约束、新的监测谓词），并且**只增不减**；新义务要先过影子验证（用历史日志回放，确认它不会误伤正常承诺）才可上线。被反复证伪的假设则**退休**，但退休只针对该假设，不删除它曾产生的义务。这样"创新"在系统里有了一个可运行的定义：**一次能把未知失效转化为可检验义务的发现**。

**灵感 6（合流 → 长程可挖掘证据承诺 LH-PCE 与证书 J_r）**
直觉：把上述机制挂到第 57 轮的 PCX 算子上：每个检查点先看账本（还有没有预算）、再看新鲜度（证据过期没）、再挖一轮失效模式（有没有值得证伪的新假设）、然后才做探询与承诺；承诺后把新证据、新依赖、新债务写回账本与证书栈。所有新机制仍然只经两个安全通道起作用——**信念更准（含强制加宽/降级）**或**动作更保守（降档、加佐证、缩短超时、绕行）**；"挖掘"是唯一会新增义务的通道，但它被限制为**只增不减 + 影子验证 + 独立预算**，因此不构成升险路径。

## 1. 形式化定义（增量：定义 139–145）

**定义 139（长程风险账本 LRL）** 记已执行承诺的失效指示 y_i∈{0,1}，n_t 步累计。用任意时有效的**置信序列**给出失败率 p 的上界 U_t(α_mission)（如 sub-Bernoulli / empirical-Bernstein CS，满足 P(∀t:p_t≤U_t)≥1−α_mission）。承诺 c 的证书给出条件失效上界 δ_c。准入规则：(L1) U_t≤α_mission−α_res（已实现风险未逼近预算）；(L2) δ_c≤δ_disc(t):=ρ_disc·(α_mission−α_res−U_t)，只花可支配额度；(L3) 高价值承诺可在 (L2) 内按价值密度 v_c/δ_c 提高 δ_c，但 δ_c≤δ_max 且不得动用 α_res；(L4) 一旦最近窗口出现失败，下一窗口 δ_disc 自动减半（**失败后自动收紧**），直到 U_t 回落。停止：U_t+min_c δ_c>α_mission−α_res，或连续拒绝≥k_stop ⇒ 再证/绕行/安全停。长程保证是"**任意时刻**失败率上界≤α_mission"，联合界只是 CS 的一个保守特例；账本按证据类/失效类分账并支持污染退回（见 CST）。

**定义 140（证据半衰期与漂移再证 EHD）** 每类证据 e 带敏感协变量集 S_e、半衰期 τ½(e)、采集政策 π_e 与支撑域 supp(e)。在线漂移分数 d_e(t)=max_{x∈S_e} D_t(x)（变化点检测/两样本 MMD/CS 残差）。新鲜度 fresh(e,t)=exp(−Δ_e/τ½(e))·1[d_e(t)≤θ_drift]。若 fresh<f_min 或 d_e>θ_drift，则 e 及其下游证书降级 stale，并生成再证义务 R_e=(最小再探集合 q_e^min, 期限 τ_renew)，其中 q_e^min 只对漂移最敏感的维度做一次最小探针（不是全量重探）。**证据债** b_evid(r)=∫(stale 证据的支持权重)dt；b_evid>b_max ⇒ 禁止该区域新的高价值承诺，先清偿。半衰期用分层生存模型从事后证伪事件估计，带先验且只允许保守方向更新（估计变短可以，变长需更强证据）。

**定义 141（证书栈与污染闭包 CST）** 证书 c 的依赖集 dep(c)⊆E∪Cert，含证据 id、子证书与政策锁 π_lock。证据/证书 x 被证伪或判 stale ⇒ 污染闭包 Taint(x)=μZ.{x}∪{c:dep(c)∩Z≠∅}（最小不动点）。被污染证书标 provisional：不得授权 R2/L2、不得充当 EV-xmodal 佐证、其曾消耗的风险额度退回账本（**账本退回**）但**不自动变为可支配额度**（防止"靠污染退款再赌"）。再证通过则解除污染，解除只能由新的、独立的、覆盖漂移维度的证据触发。依赖图只记录**最小充分依赖集**；误污率与漏污率进入审计。

**定义 142（子目标接口契约 SIC）** 任务分解为 DAG G=(子目标 g, 边 g→g')，每个 g 有证据证书、退出后置条件 Post_g（世界状态的安全集）、接口风险配额 ρ_g（Σρ_g≤α_mission）。边合法 ⇔ Post_g⊆Pre_{g'} 且 g' 的证书不依赖 g 中未结算的探针。**禁止风险转嫁**：Post 只接受"落在已证安全包络内"的状态，不接受"任务成功但世界变脆"的状态；若接口不满足，必须插入**修复子目标**（如把物体放回稳定位姿）或拒绝继续。子目标层风险在接口独立时用和，否则取悲观 max（接口相关性由共享证据检测）。

**定义 143（假设缺口挖掘器 IMM，离线创新算子）** 研究语料表示为超图 G_R=(A∪M∪Θ∪X,E_R)：假设 A、机制 M、定理 Θ、实验 X；边表示 relies_on / depends_on / tests。对假设 a 定义：承重度 κ(a)=依赖 a 的定理数（传递闭包）；覆盖度 γ(a)∈[0,1]=对 a 的 ∀-条件做过 ≥2 个不同 testbed 压力测试的权重占比；可证伪度 φ(a)=存在可执行反例测试的概率估计。挖掘分 S(a)=κ(a)^α·(1−γ(a))^β·φ(a)^χ（α,β,χ>0，取几何平均）。输出候选创新点 I(a)=(¬a, 机制草案, 反例测试, 预期失效模式)。**挖掘纪律**：只采信"否定后能被当前框架的某个假设吸收"的候选；每条新 IP 必须绑定至少一个**可杀死它的实验**，否则视为文字创新、拒收。本轮由它挖出的两个候选"¬平稳→EHD"与"¬单步可加→LRL"即为示例。

**定义 144（在线失效模式挖掘器 FMM）** 假设库 H={h_i}，h_i=(失效模式描述, 预测签名 ŝ_i, 先验 w_i, 判别探针集 Q_i, 状态)。候选生成：跨模态分歧 D(r)>θ_D、人工纠正、近失事件（margin<ε_near）、探针残差异常。选择判别探针 q\*=argmax_q Σ_h w_h·IG(h;y_q)−cost(q)，约束 q 属可逆非破坏集（继承 A34），并计入**独立探索预算** B_expl（与 α_res 严格分离，耗尽即停，不透支）。观测 y_q 后按贝叶斯更新 w_h（log-loss proper scoring）。确认（w_h≥θ_confirm 且存在独立见证 h）⇒ 编译为**义务** o_h（新增证据类/约束/监测谓词），并入 FSE 的 mined_guards；**只增不减**：ΔObligations≥0。上线前**影子验证**：用历史日志回放，要求 o_h 误伤率≤ε_shadow 且无漏检回归，否则退回假设库。反复证伪（w_h≤θ_retire）⇒ 假设退休，但其已产生义务保留。安全不变量：(F1) 挖掘只增约束；(F2) 探索预算与安全储备分离；(F3) 新义务经影子验证才生效；(F4) 确认需独立见证，防自诱导共谋。

**定义 145（长程可挖掘证据承诺算子 LH-PCE 与证书 J_r）** 在 PCX 每检查点前插入三层：①**账本检查**：U_t、α_res 与 b_evid；预算不足 ⇒ 不出证，先再证/降档。②**新鲜度检查**：CP 涉及 stale 证据 ⇒ 执行 q_e^min 最小再证或用保守共形带替代；OOD 与漂移同时发生 ⇒ 视为新分布，禁止 EV-probe\* 摊销。③**挖掘检查**：存在高 IG 且预算允许的判别探针 ⇒ 先挖一轮失效模式，把确认的模式编译为义务。然后执行第 57 轮 PCX/PCE+ 的元推断→对账→承诺；承诺后写回账本（δ_c、U_t 更新、依赖、债务、污染状态）。证书 J_r=(J_p 全量, risk_ledger, provenance_dag, taint_state, drift_state, evidence_debt, subgoal_contracts, mined_guards, exploration_ledger, shadow_log)。任何一次失败或证伪都触发 CST 污染闭包与账本退回，并在下一检查点强制再证。

## 2. 关键算法伪代码（完整版见产物区）

```python
def long_horizon_commit(cp, M, ledger, failmodes, budget):   # IP-139/140/144/145
    if not ledger.allow(budget.min_step):                     # ①账本：预算不足不赌
        return stop_or_reroute(cp, ledger)
    stale = [e for e in M.evidence[cp.region] if not fresh(e, t_now)]
    if stale:                                                 # ②漂移：最小再证
        M, ledger = renew(M, minimal_renewal_probe(stale, cp), ledger)
        if ledger.debt(cp.region) > ledger.b_max:
            return stop_or_reroute(cp, ledger)
    H, guards = mine_failure_modes(failmodes, M, cp, budget)  # ③挖掘：只增义务
    M.fse.extend_guards(guards)
    st, cert = round57_pcx_commit(cp, M, personas, ledger)    # ④第57轮承诺
    if st != 'ok': return st
    ledger.record(cert.delta_c, cert.p_value, y=None)         # 任意时更新 U_t
    M.provenance.record(cert, deps=cert.evidence)             # CST 依赖图
    return commit(cert)

def retro_falsify(x, M, ledger):                              # IP-141
    tainted = taint_closure({x}, M.provenance)
    for c in tainted:
        c.state = 'provisional'                               # 禁 R2/L2、不得佐证
        ledger.refund(c, spendable=False)                     # 退回但冻结
    ledger.debt += sum(weight(c) for c in tainted)
    return M, ledger, tainted
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| LRL | O(1)/承诺；CS O(log n) 更新 | O(H) | 任意时有效、储备不可动（A41） |
| EHD | O(\|S_e\|·d) 检测 | O(\|E\|) | 半衰期只向短估、再证覆盖漂移维（A42） |
| CST | O(\|dep\|) 闭包/事件 | O(\|Cert\|+\|E\|) | 最小充分依赖、污染单向保守（A43） |

(i) **任意时任务健全性**：P(∃t: p_t>α_mission) ≤ α_mission + δ_drift + δ_taint + δ_shadow；
(ii) **坏证据不长寿**：任一被证伪证据 x 的真实下游证书在检测延迟 τ_detect 后一个 τ_taint 内被隔离，期间不得授权 R2/L2；

```python
def risk_ledger_allow(ledger, delta_c):                 # 承诺前准入
    if ledger.U + ledger.alpha_res >= ledger.alpha_mission - ledger.min_step:
        return False, 'budget_exhausted'                # 不赌：先再证/绕行
    delta_disc = ledger.rho_disc * (ledger.alpha_mission
                                    - ledger.alpha_res - ledger.U)
    if delta_c > delta_disc:
        return False, 'discretionary_cap'               # 只花可支配额度
    return True, delta_disc

def risk_ledger_update(ledger, cert, y):                # 承诺后记账
    ledger.record(cert.delta_c, cert.p_value, y)
    ledger.U = confidence_sequence_upper(ledger.ys, alpha=ledger.alpha_mission)
    if y == 'fail':
        ledger.delta_disc *= 0.5                        # L4：失败后自动收紧
    ledger.audit.log(('spend', cert.id, cert.delta_c, ledger.U))
    return ledger

def high_value_spend(cert, ledger):                     # L3：价值密度分配
    if cert.value_density < ledger.theta_vd:
```

```python
def evidence_freshness(e, t, drift):
    d = max(drift.score(x, t) for x in e.sensitive_covariates)
    f = exp(-(t - e.t0) / e.half_life) * (1.0 if d <= drift.theta else 0.0)
```

### IP-141 CST（证书栈与污染闭包）

```python
def taint_closure(seed, prov):
    Z = set(seed)
    frontier = list(seed)
    while frontier:
        x = frontier.pop()
        for c in prov.dependents(x):                    # 最小充分依赖图
            if c not in Z:
                Z.add(c); frontier.append(c)
    for c in Z - set(seed):
        c.state = 'provisional'                          # 禁 R2/L2、不得佐证
    return Z

def retro_falsify(x, M, ledger):
    tainted = taint_closure({x}, M.provenance)
    for c in tainted:
        ledger.refund(c, spendable=False)                # 退回但冻结，防再赌
    ledger.debt += sum(weight(c) for c in tainted)
    M.audit.log(('taint', x.id, sorted(c.id for c in tainted)))
    return M, ledger, tainted

def revalidate(x, M, ledger):                            # 解除污染：需独立且覆盖漂移维
    e = independent_evidence(x, M)
    if e and cover(e, x.sensitive_dims) and not stale(e, t_now):
        x.state = 'valid'; ledger.unfreeze(x)
    return M, ledger
```

```
             − P(账本停止失效) − P(护盾回退失败) − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

关键：**效率与安全解耦**——账本/储备金负责"长期不出大错"，挖掘负责"发现未知"，证据债负责"别用旧信"，而单次承诺仍走第 57 轮证据门；**创新与安全解耦**——挖掘只能增义务、不能动储备、不能单独作证。

## 6. 本轮最大风险

**一句话**：本轮把单步安全换成长期统计承诺，最大风险是"**账本安全而世界已变**"——任意时上界与在线挖掘都默认漂移可检测、零假设在漂移纪元内成立，一旦遇到检测不到的缓慢系统性漂移或对抗性未知，风险账本会用过去的安全记录为未来的失败背书；必须让储备金不可动、半衰期只向短更新、任何无法归因的异常一律触发保守再证，否则"长程安全"只是一种统计幻觉。
