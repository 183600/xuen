# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 2 轮〔新循环〕；本轮灵感：「放置」×「开源软件」）

> 第 60 轮把执行层升级为「认知驱动的场景-执行闭环」：SSM 场景语义建模、CIEC 认知意图约束、EPIR 执行感知隔离区、SERC 场景闭环、SIC 三元校验、CESC 联合决策。但把镜头拉近到机器人最普通、也最不可逆的一个动作——**放置（place / release）**——时，三个更深的结构性空白暴露出来：
> 1. **放置是「控制权的不可逆交接」，却没有任何「发布工程」**：抓取阶段机器人闭环控制物体；一旦松手，控制权交给世界（重力、摩擦、支撑面）。第 59/60 轮的证书 J_exec、SIC 只背书「执行过程」，不背书「**释放后**物体是否稳定」。机器人能说「刚才这一下我做得合规」，却不能说「我敢松手，且松手后 2 秒仍安全」。放置缺少**承诺语义（commitment semantics）**。
> 2. **每一次放置都是一次「没版本、没锁文件、没物料清单」的裸发布**：同一个技能昨天成功、今天失败，常见根因不是代码改了，而是**感知权重、标定文件、夹爪几何、ROS 包、物体质量估计**中某一项悄悄漂移。软件工程用 lockfile / SBOM / 签名 provenance 解决「可复现性」，机器人放置却把「配置漂移」当成玄学。第 60 轮的 EPIR 只保证证据不丢，不保证**同一放置可被复现**。
> 3. **社区/开源式的技能共享在具身领域是「无安全契约的 fork」**：开源软件靠「许可证 + 回归测试 + 供应链审计」让陌生人敢用彼此的代码；机器人技能一旦被 fork，最危险的是有人**悄悄删掉安全限幅**（把 F_max 调大、把 K_p 调硬）而接口仍然兼容。第 60 轮的约束是运行时护栏，无法阻止**发布前**的安全退化。

## 0. 直觉与动机

**灵感 1（放置 → 放置即「发布提交」PRC）**
直觉：软件发布 = 把一个不可变的、内容寻址的、可回滚的制品交给用户；机器人放置 = 把一个不可变的物理状态交给世界。两者都是「**从可控到不可控的交接点**」。因此可以把一次放置建模为一个**放置发布提交（Placement Release Commit, PRC）**：`μ = (任务, 物体几何/质量, 目标位姿, 阻抗 K, 感知权重摘要, 标定摘要, 环境描述, 执行证据, 许可证)`，其地址 `c = H(canonical(μ))`。关键洞见：**放置不该以「时刻」被记录，而应以「哈希」被记录**——相同哈希 = 同类放置，可复现、可去重、可审计、可回滚。

**灵感 2（开源软件 → 物理锁文件与可复现性 RLock）**
直觉：软件 lockfile 把「依赖树」钉死到具体版本与哈希，回答「为什么昨天能跑」。放置也有一条隐藏依赖树：感知模型 → 标定参数 → 控制器配置 → 夹爪模型 → 物体质量估计 → ROS 传输配置。**物理锁文件（RLock）** 把这些依赖连同容差 `(ε_p, ε_f, ε_s)` 一起钉死，并定义「物理可复现」：`Rep = Pr[实际轨迹与名义轨迹在 ε 内一致] ≥ 1−δ`。关键洞见：**可复现性不是「代码没变」，而是「依赖 + 世界状态都在容差内」**。

**灵感 3（开源软件 → 具身物料清单 R-SBOM）**
直觉：开源供应链用 SBOM + 签名证明「这个二进制由这些源码、这些版本、这些构建者产生」。机器人需要 **R-SBOM（Robot Safety Bill of Materials）**：一次放置依赖哪些模型权重、标定文件、驱动固件、夹具几何、环境先验；每项带摘要与信任等级。若某感知 checkpoint 被替换、某标定文件被篡改，**同一接口下行为可能剧变**——R-SBOM 让「放置失败」能追到「哪个物料变了」。关键洞见：**证据链（第 60 轮 EPIR）回答「发生了什么」，物料清单回答「凭什么会这样」。**

**灵感 4（开源软件 → 安全 Copyleft 许可证 SCL）**
直觉：GPL 的「传染性」保证了衍生作品不能闭源；放置技能需要一种 **安全 Copyleft**：任何 fork/merge 出来的派生放置技能，**必须继承**原技能的安全包络 `C_safe`（力限、速度限、阻抗范围、释放判据），且这一继承是**可机器检验**的。关键洞见：**把「不许删安全限幅」从代码评审的约定，升级为许可证层面的类型系统**——派生包要么通过约束蕴含检查，要么被注册表拒绝发布。

**灵感 5（两灵感合流 → 开放放置闭环 OPC 与 PCE+++++）**
直觉：把上述机制串成开源式协作闭环：`观察 → 提交(PRC) → 钉版本(RLock) → 承诺认证(PCC) → 释放 → 记录溯源(PPL) → 注册表共享 → fork/merge → 回归测试`。每个失败事故被**最小化为可重放测试**并回灌注册表，形成「越用越安全」的公共品。配套把第 60 轮四维预算扩为五维 **B_oss = (B_repro, B_prov, B_registry, B_commit, B_exec)**：复现验证、签名/物料、注册表通信、释放尝试、执行预算。**没有预算的开源协作会退化为无审计的信任，没有回归的复用只是幻觉。**

## 1. 形式化定义（增量：定义 161–168）

**定义 161（放置发布提交 PRC）** 放置发布提交是一个不可变三元组 `PRC = (c, μ, sig)`，其中：
- **清单** `μ = (τ, o, g, K, θ_perc, θ_cal, θ_grip, ξ_env, EV, lic)`：任务、物体几何/质量先验、目标位姿、阻抗、感知摘要、标定摘要、夹爪模型摘要、环境描述、执行证据、许可证；
- **内容地址** `c = H(canonical(μ)) ∈ {0,1}^256`，`canonical` 为确定性序列化；
- **ε-等价类**：`μ ≡_ε μ′` 当且仅当 `|p−p′|≤ε_p ∧ |f−f′|≤ε_f ∧ |s−s′|≤ε_s`（位姿、接触力、滑移）；
- **发布语义**：放置的「释放」事件把 `PRC` 写入溯源账本，此后只可**补偿（re-grasp / adjust）**，不可**撤销**。

**定义 162（物理锁文件与可复现性 RLock）** 依赖锁 `L = {(dep_i, ver_i, digest_i, role_i)} ∪ (ε_p, ε_f, ε_s, δ, N_rep)`，覆盖感知权重、标定参数、控制器配置、ROS 包、夹爪几何、质量估计。可复现谓词：
```
Rep(PRC, L) := Pr_{world ~ W}[ d(ξ_actual, ξ_nominal) ≤ ε ] ≥ 1 − δ
```
其中 `ξ` 为放置轨迹与释放后 2s 的物体状态。漂移检测器 `D_drift`：若重放分布与名义分布的 MMD `> τ_drift`，或任一 `digest` 不匹配，则 `Rep := false`，阻断发布并要求重标定。

**定义 163（具身安全物料清单 R-SBOM）** 有向无环图 `G = (V, E, digest, trust, role)`，节点含模型权重、标定文件、驱动固件、夹具几何、环境先验；边为 `uses / derived-from`。证明与检测：
```
Attest(PRC) = Verify(sig_manifest) ∧ ∀v∈V: digest(v)=expected(v) ∧ trust(v) ≥ τ_trust
Compromised(v) ⇒ 所有依赖 v 的 PRC 标红并禁止 release
```
信任等级 `trust ∈ {self, community, verified, certified}`；`trust < τ_trust` 的物料只能用于探索模式，不得进入竞赛正式放置。

**定义 164（安全 Copyleft 许可证 SCL）** 许可证 `ℓ = (header, C_safe^base, inherit)`，其中安全包络
```
C_safe = (K_p 区间, K_d 区间, F_max, v_max, ε_traj, 场景前提 Z, 意图前提 I, 禁止动作)
```
派生算子 `D`：若 `p′ = fork(p)` 或 `p′ = merge(p, q)`，则要求
```
Check(p′) = ∀c∈C_safe(p): sat(p′.manifest ⊨ c) ∧ C_safe(p′) ⊇ C_safe(p)
```
不满足则注册表拒绝发布（`LICENSE_VIOLATION`）。语义：**安全的传染性强于接口的兼容性**。

**定义 165（放置承诺证书 PCC）** 释放前对释放后时域 `[t_r, t_r+T]` 的稳定性与位姿漂移做预测：
```
PCC = (P_stable, E[pose_err], σ_pose, m_commit, T, α, rollback)
P_stable = ∫ 1[stable(ξ_T)] · p(ξ_T | s_r) dξ_T
```
`s_r` 为释放瞬间状态（物体姿态、接触、力、摩擦/质量估计）。释放判据：
```
RELEASE ⇔ P_stable ≥ 1−α ∧ E[pose_err] + κ·σ_pose ≤ ε_p
否则 ROLLBACK ∈ {re_grasp, adjust_pose, lower_force, abort}
```
关键：`ROLLBACK` 不是「撤销已发生的释放」，而是在**尚未释放**前的补偿动作，或释放后检测到失稳时的**再抓取补救**。

**定义 166（fork-merge 代数 FMA）** 对同任务的放置技能 `a, b`，行为差分
```
Δ(a,b) = (ΔK, Δtraj, Δrelease_rule, ΔC_safe)
```
合并 `m = a ⊕ b` 合法当且仅当 `C_safe(a) ∩ C_safe(b) ≠ ∅` 且 `Δ` 无相互抵消项；否则 `MERGE_CONFLICT`。语义版本 `s(PRC) = (major, minor, patch)`：改动 `C_safe` 或释放判据 ⇒ `major`；改动轨迹/阻抗 ⇒ `minor`；仅元数据 ⇒ `patch`。合并必须通过双方回归集 `R(a) ∪ R(b)`。

**定义 167（放置溯源账本与事故→测试 PPL）** 只追加账本
```
L = {(c_t, parent_c, sig, verdict, EV_t)}
```
事故最小化算子 `Min(incident) → t*`：寻找最小参数化放置测试 `t*`，使 `replay(t*)` 以 ≥ `p_fail` 重现失败；`t*` 注入回归集。账本支持「从失败放置反查到依赖版本、标定文件、感知权重」的一键归因。

**定义 168（开放放置闭环 OPC 与 PCE+++++）** 算子 `OPC(M, τ, o, g, δ_f_req)`：
```
① Observe:   s ← sense(τ, o, g)
② Commit:    PRC ← build_release_commit(s, K, θ_perc, θ_cal, θ_grip, ξ_env)
③ Pin:       L ← resolve_lockfile(PRC.deps); if D_drift: re_calibrate()
④ Certify:   PCC ← predict_release_stability(s, L, T=2s)
⑤ Decide:    if PCC.P_stable ≥ 1−α: release else rollback
⑥ Record:    L ← L.append(PRC, parent, sig, verdict, EV)
⑦ Share:     registry.push(PRC) (若 SCL.Check ∧ R-SBOM.Attest)
⑧ Evolve:    t* ← Min(incident); R ← R ∪ {t*}; PRC′ ← patch(PRC)
⑨ Return:    (PRC, L, PCC, verdict, regression_delta)
```
**PCE+++++ 五维预算**：`B_oss = (B_repro, B_prov, B_registry, B_commit, B_exec)`；
```
voi_oss(π) = VOI_meta(π) − cost_repro(π) − cost_prov(π) − cost_commit(π) − cost_exec(π)
```
耗尽策略：`B_repro` 耗尽 ⇒ 提高 α、减少复现次数；`B_prov` 耗尽 ⇒ 仅本地摘要、标记 `unverified` 且禁止上传；`B_registry` 失联 ⇒ 用本地缓存 lockfile，禁止拉取新包；`B_commit` 耗尽 ⇒ 保守放置（更慢、更大裕度）；`B_exec` 耗尽 ⇒ 第 60 轮原有降级。

## 2. 关键算法伪代码

### IP-161 PRC（内容寻址放置提交）

```python
def build_release_commit(s, K, theta_perc, theta_cal, theta_grip, env, license):
    manifest = {
        "task": canonical_task(s.task),
        "object": {"geom_hash": sha256(s.object_mesh), "mass": s.mass_est},
        "goal": s.goal_pose.tolist(),
        "impedance": {"K_p": K.K_p, "K_d": K.K_d, "F_max": K.F_max},
        "perception": digest(theta_perc),
        "calibration": digest(theta_cal),
        "gripper": digest(theta_grip),
        "environment": env.descriptor,
        "license": license.spdx_id,
    }
    c = sha256(canonical_json(manifest)).hexdigest()
    return PRC(c=c, manifest=manifest, sig=sign(c, key=s.identity))
```

### IP-162 RLock（物理锁文件 + 漂移检测）

```python
def resolve_lockfile(deps, budget):
    chosen = {}
    for dep in topological_sort(deps):
        ver = max(v for v in dep.versions
                  if semver_sat(v, dep.constraints) and sbom.trust(v) >= TAU_TRUST
                  and budget.fits(v))
        chosen[dep.name] = (ver, digest(ver), dep.role)
    return Lockfile(chosen, eps=dep.eps, delta=0.01, N_rep=3)

def is_reproducible(prc, lockfile, replays):
    for r in replays:
        if r.digest != lockfile.digest_of(r.dep):
            return False
        if mmd(r.trajectory, prc.nominal_trajectory) > TAU_DRIFT:
            return False
    return quantile([d(r, prc) for r in replays], 0.99) <= lockfile.eps
```

### IP-163 R-SBOM（物料清单校验）

```python
def attest(prc, sbom, tau_trust):
    if not verify(prc.sig, prc.manifest):
        return False
    for node in sbom.closure(prc.deps):
        if node.digest != prc.manifest.digest_of(node.name):
            return False
        if node.trust_level < tau_trust and not prc.explore_mode:
            return False
    return True

def propagate_compromise(sbom, bad_nodes):
    return {c for c in sbom.all_commits if sbom.depends_on(c, bad_nodes)}
```

### IP-164 SCL（安全 Copyleft 检查）

```python
def check_safety_copyleft(child, parent):
    for c in parent.license.C_safe.constraints():
        if not implies(child.manifest, c):
            return Violation(f"derived package weakens {c.name}")
    if not child.license.inherits(parent.license):
        return Violation("missing safety copyleft header")
    return PASS
```

### IP-165 PCC（释放承诺证书与回滚）

```python
def placement_commitment_certificate(s_r, lockfile, horizon=2.0, n=256):
    samples = [rollout(s_r, lockfile, T=horizon) for _ in range(n)]
    p_stable = mean(1.0 if is_stable(x.T) else 0.0 for x in samples)
    pose_err = [norm(x.pose_T - s_r.goal) for x in samples]
    mu, sigma = mean(pose_err), std(pose_err)
    safe = (p_stable >= 1 - ALPHA and mu + KAPPA * sigma <= lockfile.eps_p)
    return PCC(p_stable, mu, sigma, m_commit=1 - ALPHA - p_stable,
               rollback=choose_rollback(s_r) if not safe else None)
```

### IP-166 FMA（行为差分与合并）

```python
def fork_merge(a, b):
    delta = behavior_diff(a, b)
    if not intersects(a.license.C_safe, b.license.C_safe) or delta.has_conflict:
        return MergeConflict(delta)
    child = merge_manifests(a, b)
    if not check_safety_copyleft(child, a) or not check_safety_copyleft(child, b):
        return LicenseViolation(child)
    if not run_regression(child, a.regressions | b.regressions):
        return RegressionFailure(child)
    return child
```

### IP-167 PPL（事故最小化与账本归因）

```python
def minimize_incident(incident):
    t = incident.test_case
    for field in reversed(order_by_importance(t.params)):
        candidate = shrink(t, field)
        if replay(candidate).failed:
            t = candidate
    return t

def attribute(prc, ledger, sbom):
    return trace_diff(prc, parent=ledger.parent_of(prc), sbom=sbom)
```

### IP-168 OPC（开放放置闭环）

```python
def open_placement_loop(M, task, obj, goal, delta_f_req):
    s = sense(task, obj, goal)
    prc = build_release_commit(s, M.K, M.theta_perc, M.theta_cal, M.theta_grip,
                               M.env, M.license)
    lock = resolve_lockfile(prc.deps, M.budget)
    if not is_reproducible(prc, lock, M.replays):
        M.calibrate(); lock = resolve_lockfile(prc.deps, M.budget)
    pcc = placement_commitment_certificate(s, lock)
    if pcc.P_stable >= 1 - M.alpha:
        verdict = execute_release(M, prc, lock)
    else:
        verdict = execute_rollback(M, pcc.rollback)
    M.ledger.append(prc, parent=M.last_prc, verdict=verdict, EV=M.ev_exec)
    if attest(prc, M.sbom, TAU_TRUST) and check_safety_copyleft(prc, M.base):
        M.registry.push(prc)
    if verdict.failed:
        t_star = minimize_incident(verdict)
        M.regressions.add(t_star)
    return M, prc, lock, pcc, verdict
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PRC | O(|μ|) 哈希 | O(|μ|) | 内容寻址抗碰撞；ε-等价类稳定 |
| RLock | O(|deps|·|ver|) 约束求解 | O(|deps|) | 依赖闭包完整、漂移可检测 |
| R-SBOM | O(|V|+|E|) 校验 | O(|V|) | 篡改检测概率 ≥ 1−2^−λ |
| SCL | O(|C_safe|) 蕴含检查 | O(|C_safe|) | 派生包安全包络不弱化 |
| PCC | O(N_rep·T·n) 蒙特卡洛 | O(n·d) | 承诺可靠性受校准误差约束 |
| OPC | O(闭环 + 校验) | 复用 | 释放/回滚决策可审计 |

**正确性定理（OPR, Open Placement Release）**：假设 A66–A70 成立：
**(A66)** `canonical` 单射到 ε-等价类，`H` 抗碰撞；**(A67)** RLock 依赖集闭合，漂移检测对可测漂移可靠；**(A68)** 签名不可伪造、摘要绑定的 R-SBOM 完整；**(A69)** SCL 的约束蕴含检查在清单语言上可靠且完备；**(A70)** PCC 的稳定性预测器已校准（可靠性图误差 ≤ δ_cal）。则：
1. **物理可复现性**：`Rep(PRC,L)=true ⇒ replay` 落在 ε-等价类内，概率 ≥ 1−δ；
2. **承诺可靠性**：`RELEASE ⇒ P(stable) ≥ 1−α−δ_cal`，且任何未达阈值的释放必留 `override` 审计记录；
3. **供应链可靠性**：任一依赖被篡改 ⇒ `Attest=false`，检测概率 ≥ 1−2^−λ，且依赖它的 PRC 全部阻断；
4. **安全继承性**：派生包若弱化 `C_safe`，则 `Check` 失败并被注册表拒绝；不存在「接口兼容但安全退化」的静默通过；
5. **预算安全性**：任一 `B_oss` 耗尽都触发确定的降级策略，且降级本身被记录为 PRC 元数据。

### IP-162 RLock（物理锁文件 + 漂移检测）

```python
def resolve_lockfile(deps, budget):
    chosen = {}
    for dep in topological_sort(deps):
        ver = max(v for v in dep.versions
                  if semver_sat(v, dep.constraints)
                  and sbom.trust(v) >= TAU_TRUST and budget.fits(v))
        chosen[dep.name] = (ver, digest(ver), dep.role)
    return Lockfile(chosen, eps=dep.eps, delta=0.01, N_rep=3)

def is_reproducible(prc, lockfile, replays):
    for r in replays:
        if r.digest != lockfile.digest_of(r.dep):
            return False
        if mmd(r.trajectory, prc.nominal_trajectory) > TAU_DRIFT:
            return False
    return quantile([d(r, prc) for r in replays], 0.99) <= lockfile.eps
```

### IP-165 PCC（释放承诺证书与回滚）

```python
def placement_commitment_certificate(s_r, lockfile, horizon=2.0, n=256):
    samples = [rollout(s_r, lockfile, T=horizon) for _ in range(n)]
    p_stable = mean(1.0 if is_stable(x.T) else 0.0 for x in samples)
    pose_err = [norm(x.pose_T - s_r.goal) for x in samples]
    mu, sigma = mean(pose_err), std(pose_err)
    safe = (p_stable >= 1 - ALPHA and mu + KAPPA * sigma <= lockfile.eps_p)
    return PCC(p_stable, mu, sigma,
               m_commit=1 - ALPHA - p_stable,
               rollback=choose_rollback(s_r) if not safe else None)
```
