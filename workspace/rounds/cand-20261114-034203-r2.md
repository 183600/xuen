# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环第 3 轮；本轮灵感：「最优控制」×「基准测试」）

> R69 把「问」从被动融合升级成主动决策，用一条贪心规则回答「该不该问、问什么」：`g* = argmax_g [VoI(g) − c(g)]`。但它埋了两个更深的洞，恰好各自对应本轮的一个灵感。
>
> **洞 1（贪心 → 需要最优控制）**：R69 的 VoI 是**一步**的信息增益。可「问」从来不是一次套利，而是一笔**带预算的长期投资**——现在问到的信息会改变未来许多步的决策；而注意力/社交信用/时间是有限资源，现在多问一次就少一次未来的问询。真正该比较的不是「这一步熵降多少」，而是「这个信息让未来的代价-to-go 降低多少」，即**期权价值**。R69 的预算上限只是把这种稀缺性粗暴截断，而不是定价。
>
> **洞 2（不可证伪 → 需要基准测试）**：R69 的 E286–E300 度量了 ECE、成功率、AUC，却没有**真值**。系统完全可能降低了自己的熵、却离真相更远（U_epi 降而遗憾没降）；更糟的是模态校准器可能与评测场景共享数据，让「校准良好」成为污染的回声。没有 oracle 与 regret，「问得值不值」不可证伪；没有冻结基准与统计协议，「比 R68 好」可能只是噪声、多重比较或 Goodhart。
>
> 本轮的洞察是：**这两个灵感是同一枚硬币的两面**。最优控制需要**良定义的代价**才能求值，而良定义的代价只能由「知道真值的 oracle 基准」给出；反过来，基准只有配上**最小化该基准遗憾的决策过程**才有意义，否则只是给一个瞎猜打分。R69 优化的是代理（VoI），评测的是另一回事（成功率）——**代理与度量之间没有桥**。R70 要在它们之间架桥。
>
> 核心命题：**把「问不问、问什么」建模为信念状态上的最优控制问题，其目标函数被定义为冻结潜在模态基准上的 oracle 遗憾；并在每次发版时审计「在线目标与基准度量」的一致性（Objective-Metric Consistency, OMC）。** 命名 **ORBIT-RAS**（Optimal-control, Regret-Benchmarked Interactive uncertainty Treatment）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这次求证值不值它的期权价格，且能否在一套知道真值的冻结基准上被证明**」——不确定性第一次从「刹车踏板 / 一句提问」变成「一笔要记账、要审计、要被第三方 oracle 对账的投资」。

## 0. 直觉与动机

**灵感 1（最优控制 → 信念是状态、交互是控制、预算是状态里的钱）**
直觉：把 R69 的 U_epi 想成「我还不确定该走哪条模态」。最优控制不看此刻的模糊，而看**值函数**：从当前信念出发，未来所有决策的最小期望代价。于是「问」是一个控制量，它的收益是「更新信念后值函数的下降」；它的成本是交互代价 + **花掉预算所代表的未来机会**。预算因此不是外挂的阀门，而是状态的一维，带着自己的影子价格 μ——预算越紧，μ 越高，问询门槛越高。这解释了 R69 为什么需要一个拍脑袋的「每单位时间 ≤ 1 次」：它其实是 μ→∞ 的一刀切。最优控制把它变成可定价、可调度、可解释的连续旋钮，而不是一个需要手调的常数。

**灵感 2（基准测试 → 没有 oracle 的「更好」不是更好）**
直觉：消歧的效果只有一个诚实度量——**遗憾**：如果从一开始就知道真实模态（oracle），代价是多少？实际代价减去它就是「因为不确定而多付的钱」。这笔钱可以拆账：噪声造成的（不可约）、选错模态造成的、问得太少造成的、值函数估不准造成的。拆账让基准从「一个分数」变成「一张诊断书」。而要让这个度量不可作弊，必须：真值隐藏、场景冻结、投毒/OOD 套件版本化、统计协议预注册。否则系统会学会在卷子上漂亮、在世界上糟糕——Goodhart。

**灵感 3（对偶 → 最优控制与基准测试互为前提）**
直觉：没有基准的最优控制是在优化一个自造目标（R69 的 VoI 就是自造目标）；没有决策过程的基准只是一个打分器。二者结合才产生本轮主命题：**目标-度量一致性（OMC）**——在线最小化的代理，必须被证明是基准遗憾的有界误差估计；否则任何「基准上更好」都不许盖章。这不是又一层黑箱，而是一条**可审计的桥**。

**灵感 4（严格包含 → R69 是「无预算 × 短视 × 无污染」的角落）**
直觉：把预算影子价格 μ=0（预算无限）、horizon=1（只看一步）、污染与 OMC 都理想化，ORBIT 逐指令退化成 FLUID-RAS；再把 VoI≤成本，就退化成 CALM-RAS。R69 和 R68 都是这个三维参数空间里的边界点。**新层不是并列替换，而是把旧层包进一个可解释的参数族**——这是每轮都要守的姿态。

**灵感 5（新的最大风险：把 oracle 当成神）**
直觉：最优控制 + 基准测试有一个共同的隐藏假设：**oracle 的代价模型与真值标注是对的**。若「真实模态」标错、或 oracle 的成本函数漏掉社会成本/长期代价，ORBIT 会**最优地**收敛到一个能在基准上自证、却在世界中错误的策略。这不是过拟合训练集，而是**目标设定错误（specification error）**：越优化、越自信、越错。所以本轮必须把「oracle 成本模型本身的不确定性 σ_spec」写进证书，并显式声明所有基准结论只在 σ_spec ≤ τ_spec 时成立。

## 1. 形式化定义（增量：定义 310–322）

**定义 310（ORBIT-RAS 总览）** ORBIT-RAS = (LMB, DR, BOC, SSP, RSC, OMC, BCP, GG, RAS-WM††)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **预算作为状态**：交互预算 B_t 是显式状态，B_t ≥ 0 严格成立、禁止透支，预算消耗改变未来可问次数；
(iii) **目标-度量一致性**：在线目标 L̂ 必须是基准 oracle 遗憾 R 的可认证代理，一致性缺口 Γ ≤ τ_omc，否则禁用 BOC；
(iv) **基准隔离**：潜在真值 m* 与隐藏元度量对在线学习不可见；每次发版强制污染审计与 Goodhart 审计。

**定义 311（潜在模态基准 LMB）** 一个冻结、带版本的基准数据集 ℬ = {(episode, m*, J_oracle, suite_tag)}，hash h_LMB。每条情节含：(a) 隐藏潜在模态 m*（多标注者一致性 κ 达标）；(b) oracle 代价 J_oracle = 知道 m* 且可无限交互的最优策略代价；(c) 四个版本化套件：clean / perturbed / poisoned(ℰ_poison) / OOD。学习者永远看不到 m*，m* 只在评分时解封。**训练-评测数据隔离由 h_LMB 与时间戳双向核验。**

**定义 312（分解遗憾 DR）** 策略 π 在情节上的遗憾 Reg(π) = J(π) − J_oracle ≥ 0。在 A99（四类成因可加且正交）下分解为
Reg = Reg_ale + Reg_epi + Reg_budget + Reg_est，
分别对应：不可约噪声底、选错模态、交互不足、值函数/λ 近似误差。分解不是恒等式而是**设计目标**：四项各自可独立测量，用于把「分数」翻译成「哪个模块坏了」。

**定义 313（信念状态最优控制 BOC）** 信念 b_t(k)=P(M=k|h_t)，增广状态 s_t=(x_t,b_t,B_t)，控制 ξ=(a,g)。交互观测模型 p(y|g,o)，预算动力学 B_{t+1}=B_t−c_int(g)。代价 c(ξ,m)=c_task(a,m)+c_int(g)+risk。目标 min E[Σ_t γ^t c]，Bellman：
V(x,b,B) = min_ξ { E_{m∼b}[c_task(a,m)] + c_int(g) + γ E_{o'}[V(x',b',B')] }。
**交互期权价值** OV(g) = E_{y|g}[V(x,b'_y,B−c_int(g))] + 即时项；相对「不交互」的值差即长时程收益。R69 的 MINT 是 H=1 的短视投影。

**定义 314（预算影子价格 SSP）** 对约束 Σ_t c_int(g_t) ≤ B 取 Lagrange 乘子，定义影子价格 μ_t = −∂V/∂B_t ≥ 0，即「多一单位交互预算能换回多少任务价值」。最优规则化为：选 g 当且仅当 EVSI(g) ≥ (1+μ)c_int(g)。μ=0 退化为 R69 的 EVSI ≥ c；μ 可由基准遗憾对预算的斜率直接标定（可测），无需手调。

**定义 315（风险敏感控制 RSC）** 熵风险 J_β = (1/β) log E exp(β C)。风险敏感 Bellman：V_β = min_ξ { c + (1/β) log E exp(β V_β(next)) }。局部高斯近似下 J_β ≈ m + (β/2)σ²，导出风险增益 λ_β ≈ 1 + (β/2)CV² ≥ 1。最终风险缩放 λ = max(λ_β, λ_floor(U_ale + 未消解 U_epi))，且在认证域内取 λ_floor——**风险敏感只在安全域内买效率，绝不把已认证安全换走**。

**定义 316（目标-度量一致性 OMC）** 在线代理 L̂(π)（BOC 实际最小化的量）与基准遗憾 R(π)（我们评分的量）的一致性缺口 Γ(π)=|L̂−R|/scale(R)。OMC 成立 ⇔ 在 LMB 上以 1−δ 置信有 Γ ≤ τ_omc，且每次基准发版重估。Γ 越界 ⇒ 禁用 BOC，退回 FLUID 的「未对齐但不被游戏」目标。注意：我们不宣称 Γ=0，只宣称 **Γ 被测量并被上界约束**。

**定义 317（基准污染与泄漏探测 BCP）** 三个探针：(a) fresh-generation holdout，训练后重新生成同分布情节，gap = bench_score − fresh_score；(b) memorization probe，值/模态模型能否从近似重复输入复述基准专属标签；(c) temporal leakage，基准情节是否经时间戳泄入训练。输出污染率 ρ̂_b 及置信区间；ρ̂_b > τ_c ⇒ 基准结论作废。

**定义 318（Goodhart 防御 GG）** 基准分两层：公开分 S_pub（被优化）与隐藏元度量 S_meta（人类评分任务成功 / 真实机器人代价，永不暴露）。跟踪分歧 D = |S_pub − S_meta|；若 S_pub 上升而 D 持续扩大 ⇒ 奖励劫持告警。GG 禁止为「只在 S_pub 上存在」的增益发证。

**定义 319（统计协议 SP）** 预注册主指标（regret）、最小可检测效应 MDE、随机种子 ≥ 5、配对 bootstrap 10k 置信区间、跨实验族 Holm–Bonferroni 多重比较校正、报效应量而非只报 p 值、设负对照。未过 SP 的结果只能标「探索性」，不得标「确认」。

**定义 320（遗憾一致性证书 J_ORBIT）** J_ORBIT = (J_FLUID, h_LMB, R_point, R_ci, Reg_decomp, Γ_omc, ρ̂_b, D_goodhart, μ̄, λ_β, σ_spec, orbit_ver)。Valid ⇔ Valid(J_FLUID) ∧ OMC 成立 ∧ ρ̂_b ≤ τ_c ∧ SP 满足 ∧ 预算未透支 ∧ σ_spec ≤ τ_spec。

**定义 321（回退阶梯 Fallback Ladder）** ORBIT → FLUID(R69) → CALM(R68)，沿阶梯遗憾单调不增、安全单调不降。触发条件：Γ_omc 越界 / 污染超阈 / 预算耗尽 / 值网络 OOD / RSC 不可行 / σ_spec 超阈。边界处逐指令与旧层相同。

**定义 322（oracle 成本模型审计）** oracle 的 J_oracle 依赖成本模型 c。用留出的人类/真机代价测量对 c 做外部效度审计，报告目标设定不确定性 σ_spec；σ_spec 进入 J_ORBIT。这是本轮把「最大风险」制度化的地方：**oracle 不是神，是另一个要接受审计的假设。**

## 2. 关键算法骨架

```python
# IP-264 LMB：冻结潜在模态基准（真值只在评分时可见）
class LatentModeBenchmark:
    def __init__(self, episodes, oracle, poison_suite, hash_):
        self.episodes = episodes          # 每条含隐藏 m*，在线不可见
        self.oracle   = oracle            # 知道 m*、无限交互的最优策略
        self.poison   = poison_suite      # ℰ_poison 版本化
        self.hash     = hash_             # 冻结指纹，训练/评测隔离

    def score(self, policy):
        rows = []
        for ep in self.episodes:
            J_pi = rollout(policy, ep.obs_visible)         # 不给 m*
            J_or = rollout(self.oracle, ep.with_truth())   # 给 m*
            rows.append(J_pi - J_or)                       # 逐情节 regret
        return rows                                        # 交由 SP 做配对统计

# IP-265 DR：把 regret 拆成四笔账
def decompose_regret(policy, oracle, ep):
    J    = rollout(policy, ep.obs)
    J_or = rollout(oracle, ep.with_truth())
    return dict(
        ale    = J_or - oracle.irreducible(ep),   # 不可约噪声底
        epi    = wrong_mode_cost(policy, ep),     # 选错模态
        budget = oracle.budget_gap(policy, ep),   # 交互不足
        est    = value_approx_gap(policy, ep),    # V / λ 近似
        total  = J - J_or)                         # 诊断映射见引理 21

# IP-266 BOC：信念空间期权价值控制器（替换 MINT 的一步贪心）
class BeliefOptionController:
    def __init__(self, value_head, gamma=0.99):
        self.V, self.gamma = value_head, gamma          # (x,b,B) -> 值函数（摊销）
    def option_value(self, g, x, b, B):
        b_after = self.predict_belief_update(b, g)      # 期望后验
        return self.V(x, b_after, B - c_int(g)) - self.V(x, b, B)
    def choose(self, x, b, B, cands, mu):
        best, best_score = None, 0.0
        for g in cands:                                 # 注视/探针/问句
            evsi  = -self.option_value(g, x, b, B)      # 值下降 = 收益
            score = evsi - c_int(g) - mu * c_int(g)     # IP-267：μ=0 即 R69
            if score > best_score: best, best_score = g, score
        return best                                     # None → 退化 FLUID / CALM

# IP-267 SSP：影子价格 = 值函数对预算的边际
def shadow_price(value_head, x, b, B, eps=1e-3):
    return -(value_head(x, b, B + eps) - value_head(x, b, B)) / eps   # μ ≥ 0

# IP-268 RSC：熵风险导出 λ，R68 floor 只做下界约束
def risk_scaled_dispatch(V_beta, V_nom, beta, lam_floor):
    lam_beta = risk_gain(V_beta, V_nom, beta)    # 局部近似 ≈ 1 + (β/2)·CV²
    return max(lam_beta, lam_floor)              # 安全永不被风险收益换走

# IP-269 OMC：在线代理 vs 基准遗憾的一致性审计（发版级）
def omc_audit(policy, benchmark, delta=0.05):
    L_hat = policy.online_objective_value()      # BOC 实际最小化的量
    R     = benchmark.score(policy)              # 基准遗憾（带 CI）
    Gamma = abs(L_hat - mean(R)) / scale(R)
    return Gamma, ci(R, delta)                   # Γ > τ ⇒ 禁用 BOC、回退 FLUID

# IP-274 ORBIT 主闭环（继承 FLUID，仅在「交互定价」与「证书」处升级）
def ORBIT_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, _ = M.cof.step(...)
    K = M.fmp.gate(z)                                   # 继承 R69 自适应 K
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, K), z)
    b = mode_belief(modes)                              # 信念状态
    # 1) 影子价格：预算越紧，问询越贵
    mu = M.ssp.shadow_price(M.boc.V, o, b, M.budget.B)
    # 2) 用期权价值而非一步 VoI 决定是否交互
    g = (M.boc.choose(o, b, M.budget.B, M.mint.candidates(modes), mu)
         if U_epi > TAU_EPI else None)
    if g is not None:
        ans = M.cia.execute(g)
        b, U_epi = M.cia.update_belief(modes, ans)
        M.budget.spend(g)                               # 预算作为状态扣减
    # 3) 风险敏感 λ，R68 floor 只做下界约束
    lam = M.rsc.risk_scaled_dispatch(...)               # max(λ_β, λ_floor)
    k   = M.c_ras_wm.certified_prefix(...)              # 继承 R69 安全认证
    # 4) 发版级：OMC / 污染 / Goodhart 审计（离线），证书随版本冻结
    M.omc.submit_async(M.budget.log, M.boc.last_evsi)
    return k, lam, select_mode(modes, U_epi, lam)
```

## 3. 推导

**引理 19（期权价值 ≥ 单步 VoI）** 记一步信息收益 VoI₁(g)，有限时域 H 的期权价值 OV_H(g)。当 H≥1、γ>0 且未来策略依赖信念（∂π/∂b ≠ 0）时，OV_H(g) ≥ VoI₁(g)，差值即期权溢价 P_opt = Σ_{t≥1} γ^t E[ΔV_t]，其中 ΔV_t 是「更准信念」对第 t 步值函数的改进。H=1 或 γ=0 时取等。故 R69 的 MINT 是 ORBIT 在 H=1 的短视投影；基准测得的长期遗憾正是 P_opt 的兑现。系：**只看一步 VoI 会系统性低估问询价值**，在长时程任务里表现为「问得太少」。

**引理 20（预算影子价格与交互频率单调性）** 在约束 Σ c_int(g_t) ≤ B 下，最优交互满足：选 g 当且仅当 EVSI(g) ≥ (1+μ)c_int(g)，其中 μ = −∂V/∂B ≥ 0。于是交互频率随 μ 单调不增；μ=0 退化为 R69 的 EVSI ≥ c。系：R69 的「每单位时间 ≤1 次」等价于 μ→∞、给每次交互一个无穷机会成本；ORBIT 把这一刀切替换为连续定价，且 μ 可由「基准遗憾对预算的斜率」直接标定——**R69 的预算常数在此获得了经济学解释，也获得了可测量。**

**引理 21（遗憾分解非负、可诊断）** 在 A99 下 Reg = Reg_ale + Reg_epi + Reg_budget + Reg_est，各项 ≥ 0。诊断映射：Reg_epi 主导 ⇒ 查 AUD/模态校准；Reg_budget 主导 ⇒ μ 过高或预算过低（应多问）；Reg_est 主导 ⇒ 值函数/λ 近似不足（改进模型）；Reg_ale 主导 ⇒ 任务本身噪声大，控制学不到东西（不该拿它做卖点）。这让冻结基准成为**模块级调试器**，而非一个排行榜数字。

**定理 18（ORBIT ⊇ FLUID ⊇ CALM，且基准遗憾单调）** 在 A99–A101 下，同一冻结 LMB 上 R(ORBIT) ≤ R(FLUID) ≤ R(CALM)。退化条件：H=1 或 γ=0 ⇒ ORBIT≡FLUID（引理 19）；B=0 或 μ→∞ ⇒ 不交互，策略与 R69 逐指令相同（引理 20）；VoI ≤ c ⇒ FLUID≡CALM（R69 定理 16）。安全侧：λ=max(λ_β, λ_floor) 且认证前缀不变 ⇒ 沿阶梯安全单调不降（定理 19）。

**定理 19（风险敏感 λ 的安全证书）** 取熵风险 J_β=(1/β)log E e^{βC}。局部高斯近似（代价均值 m、方差 σ²）下 J_β ≈ m+(β/2)σ²，等价于均值-方差准则，导出 λ_β ≈ 1+(β/2)CV² ≥ 1。在安全关键态（认证域或 λ_floor 主导域）max(λ_β,λ_floor)=λ_floor，故 CVaR_α(C) ≤ R68 对应上界——风险敏感只在安全域内买效率，不拿已认证安全换风险收益。

**定理 20（OMC 下「基准更好」的可证明性）** 设一致性缺口 Γ ≤ τ_omc（以 1−δ 置信），且 SP 满足（配对、预注册、MDE=Δ_min）。若 LMB 上测得 R(π_new) 较 R(π_old) 改善 Δ ≥ Δ_min，则新鲜分布上的真实改善 ≥ Δ − τ_omc − w_CI（1−δ 置信），w_CI 为配对置信半宽。逆否：**不做 OMC 审计时，公开基准上的改善不能推出部署改善**（可能全是目标错位或污染）。这是「benchmarked」在本框架中的严格含义。

**引理 22（污染偏差与探测功效）** 若基准有比例 ρ_b 的情节被污染（训练可见或近似重复），单情节遗憾上界 L_max，则基准乐观偏差 ≤ ρ_b·L_max；fresh 生成留出集无偏。配对检验在真实差距 > MDE 时功效 ≥ 1−β。系：BCP 的 fresh-holdout gap 是 ρ_b 的线性估计，可反解污染率并设阈值。

## 6. 本轮最大风险

**一句话**：ORBIT-RAS 把「价值」建立在两个不再受它控制的假设上——冻结基准的**潜在模态真值**与 oracle 的**成本模型**；一旦标注有偏或成本函数漏项（σ_spec 超阈），最优控制会**最优地**把系统推向一个在基准上自证、却在世界中错误的目标（specification error × benchmark overfitting），而且越优化越自信。

**次级风险与缓解**：
1. **目标设定错误（oracle 成本模型有偏）** → 定义 322 外部效度审计 + σ_spec 进证书 + 超阈禁止发证；
2. **基准污染/泄漏** → BCP 三探针 + 冻结 hash + 训练/评测时间戳隔离 + fresh holdout；
3. **Goodhart / 公开分操纵** → 隐藏元度量 S_meta + 分歧告警 + 禁止只凭 S_pub 发证；
4. **值函数近似误差导致期权价值高估** → 引理 21 的 Reg_est 诊断 + 保守下界 + OOD 回退；
5. **预算阴影价格估计不稳** → 缓存平滑 + 硬预算约束兜底（绝不允许 μ 估计错导致透支）；
6. **统计幻觉（多重比较/种子挑选）** → 预注册 + Holm 校正 + 配对 bootstrap + 负对照。

```python
def score(policy, episodes, oracle):
    rows = []
    for ep in episodes:
        J_pi = rollout(policy, ep.obs_visible)       # 不给真值 m*
        J_or = rollout(oracle, ep.with_truth())      # 给 m*

    return rows                                      # 交给 SP 配对统计

    return dict(ale    = J_or - oracle.irreducible(ep),
                epi    = wrong_mode_cost(policy, ep),
                budget = oracle.budget_gap(policy, ep),

def option_value(V, g, x, b, B):
    b_after = predict_belief_update(b, g)
    return V(x, b_after, B - c_int(g)) - V(x, b, B)
```

## 4. 推导

**引理 19（期权价值 ≥ 单步 VoI）** H≥1、γ>0 且未来策略依赖信念时 `OV_H ≥ VoI₁`，差值 = 期权溢价 `P_opt = Σ_{t≥1} γ^t E[ΔV_t]`；H=1 或 γ=0 取等。系：一步贪心系统性低估问询价值，长时程表现为「问得太少」；R69 的 MINT 是 H=1 投影。

**引理 20（预算影子价格）** 约束下最优交互为 `EVSI ≥ (1+μ)c_int`，`μ=−∂V/∂B ≥ 0`；交互频率随 μ 单调不增，μ=0 退化为 R69。系：R69 的「≤1 次/单位时间」= μ→∞ 的硬截断；μ 可由基准遗憾对预算的斜率标定。

**引理 21（遗憾分解可诊断）** A99 下四笔账非负且可加。映射：epi 主导→查 AUD/校准；budget 主导→应多问；est 主导→值函数/λ 不准；ale 主导→任务噪声大、控制无能为力。

**定理 18（ORBIT ⊇ FLUID ⊇ CALM）** 同一 LMB 上 `R(ORBIT) ≤ R(FLUID) ≤ R(CALM)`；H=1/γ=0、B=0/μ→∞、VoI≤c 分别逐指令退化为 FLUID/CALM；λ=max(λ_β,λ_floor) + 认证前缀不变 ⇒ 安全单调不降。

**定理 19（RSC 安全证书）** 局部高斯 `J_β≈m+(β/2)σ²`，`λ_β≈1+(β/2)CV²≥1`；安全关键态 λ_floor 主导，`CVaR_α ≤ R68` 上界——风险敏感只在安全域内买效率。

**定理 20（OMC 下基准优势可证明）** 若 `Γ≤τ_omc` 且 SP 满足，则 LMB 上改善 `Δ≥MDE` ⇒ 新鲜分布真实改善 `≥ Δ−τ_omc−w_CI`（1−δ）。逆否：不做 OMC，公开基准改善不能推出部署改善。

**引理 22（污染偏差）** 污染率 ρ_b、单情节遗憾上界 L_max 时，基准乐观偏差 ≤ ρ_b·L_max；fresh holdout 无偏，配对检验功效 ≥ 1−β（真实差距 > MDE）。BCP 的 fresh gap 是 ρ_b 的线性估计。

## 7. 本轮最大风险

**一句话**：ORBIT-RAS 把「价值」建立在冻结基准的**潜在模态真值**与 oracle 的**成本模型**上；一旦标注有偏或成本函数漏项（σ_spec 超阈），最优控制会**最优地**把系统推向一个在基准上自证、却在世界中错误的目标（specification error × benchmark overfitting）——**越优化、越自信、越错**。

**次级风险与缓解**：目标设定错误（定义 322 外部效度审计 + σ_spec 进证书 + 超阈禁发证）；基准污染/泄漏（BCP 三探针 + hash + 时间戳隔离 + fresh holdout）；Goodhart（隐藏 S_meta + 分歧告警 + 禁止只凭 S_pub 发证）；值函数误差致期权价值高估（Reg_est 诊断 + 保守下界 + OOD 回退）；影子价格不稳（缓存平滑 + 硬预算兜底，绝不透支）；统计幻觉（预注册 + Holm + 配对 bootstrap + 负对照）。
