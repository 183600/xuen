# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「安全交互」×「演示方案」）

> R69 给闭环装上了眼睛和嘴：看不清就看、拿不准就问、质感不明就触；并把不确定性二分，用流匹配策略显式表示多模态，用 VoI 决定值不值得求证。但 R69 的安全论证有一个未言明的前提——**交互安全是「单动作、同分布、部署态」的性质**：每个信息动作 g 单独过 C-RAS-WM 认证，风险评估对部署分布取期望，人默认是配合的、静止的、不会误解的。
>
> 一进入「演示」，这三个前提同时失效：
> - **演示是一个被挑选的分布**（配合的演员、熟悉的道具、布置好的舞台），它天然把 U_epi 压低、把成功率抬高；
> - **演示是一个序列/叙事**（看—问—触—做—谢幕），逐动作安全不蕴含整场安全：十次各在力限内的轻触可以累积成不适，十次礼貌的追问可以累积成胁迫，观众为看清而靠近可以一步步侵入包络；
> - **演示是一场被观看的表演**（有观众、有期待、有「别停」的社会压力），而 R68/R69 的安全刹车在台上看起来像故障，于是最需要安全的时刻，恰恰是最想拆掉安全的时候。
>
> 两个灵感正好给出两面：
> - **安全交互**提醒我们：安全不是动作的属性，而是**关系**的属性——它是人-机联合轨迹上的不变量，必须**时序累积、可撤回同意、且可被旁观者读懂**；单步认证不是安全，只是安全的必要条件。
> - **演示方案**提醒我们：演示不是一次运行，而是一份**带主张的契约**——脚本、舞台、见证人、能力主张、落幕预案。它同时是最好的测试台（可控、可观测、可注入对抗替身）和最坏的证据（被挑选、被优化、被围观）；**优化演示会使演示不再是证据**。
>
> 核心命题：**把「演示」提升为一等公民的安全接口。用演示契约（脚本 × 主张 × 包络 × 见证 × 落幕）把「这场演示证明了什么」写成可证伪的命题；用时序交互屏障把 R69 的逐动作认证升级为整场累积认证；用同意/非胁迫状态机把「问」变成可撤回、不可继承的社会契约；用可读性策略让「安全地停」成为演出的一部分，从而消解表演压力对安全约束的侵蚀；用密封演示 + 覆盖赤字证书保证「演示成功」不被误读为「部署安全」；一旦现场越出契约包络，立即落幕退化为 R68/R69，而不是继续表演。** 命名 **STAGE-RAS**（Safe Temporal interaction under Audited, Governed Exhibitions）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**这场演示到底证明了什么？没演示的部分谁担保？观众越看越想要，我还敢不敢停？**」

## 0. 直觉与动机

**灵感 1（安全交互 = 关系不变量，不是动作谓词）**
直觉：R69 的 `certify_info(g, o_t)` 问的是「这个注视/探针/问句此刻是否在包络内」。但同一个注视，看一次是确认，看十次是监视；同一个力，触一下是探测，触一百下是疲劳；同一句「请再靠近一点」，说一次是请求，说十次是胁迫。安全与否取决于**联合轨迹的历史与人的状态**，而不是当前动作的瞬时幅值。把安全从 `safe(g)` 升级为 `safe(τ_{0:T})`，是 R70 的第一性变化。

**灵感 2（演示 = 契约，不是视频）**
直觉：一次没有主张的运行只是素材，不是证据。演示契约 C = (B, ≺, Φ, E, W, K, S) 把「在舞台分布下、在包络 E 内、由独立见证人 W 观察、系统达成能力 Φ」写成一个有边界、可核验、可证伪的命题。没有 C 的演示无法回答「它证明了什么」；有了 C，才能问「它没证明什么」。这也是「演示方案」最容易被忽略的一半：观众记住的是成功，工程需要的却是**未覆盖清单**。

**灵感 3（演示的双面性 → 演示过拟合）**
直觉：演示是最好的测试台——仪器齐全、可重复、可安排对抗替身、可被独立见证；也是最坏的证据——演员配合、道具精选、脚本反复排练、灯光只为好看。更根本的是，**一旦你针对演示优化，演示就不再是测试集，而是训练集**。这不是工程细节，而是 Goodhart 的教科书形态：演示成功率可以趋近 1，而部署风险不变。因此「密封」不是流程洁癖，而是**证据有效性的必要条件**（定义 318、定理 19）。

**灵感 4（聚光灯效应 → 安全必须可读、且不可交易）**
直觉：台上停下来问一句「我不确定，可以吗？」在研究者眼里是诚实，在观众眼里常常是「坏了」。这种解读会通过操作员、通过「再来一次」、通过把难度调低，反向侵蚀安全。R68/R69 的 λ_floor 是刹车，而演示给拆刹车提供了最强的社会激励。对抗它的办法不是更强的刹车，而是三件事同时做：
1. **安全是约束集，不是加权项**——任何表演/任务权重只能在安全集内部重排，不能扩大安全集（定理 18）；
2. **让安全可读**——系统主动显示不确定性、说明为什么停、把「落幕」写进脚本，使「安全地停」被读作能力而非故障（定义 316）；
3. **让落幕可演出**——落幕本身经过排练、满足无突变规格，是演出的一部分（定义 320、定理 20）。

**灵感 5（舞台是新的攻击面 → 演示治理进入威胁模型）**
直觉：一个知道证书规则的对手，可以**布置舞台**：选最容易的道具、安排配合的托、把观众放在包络外、在排练期投毒让策略学到「演示专用后门」，甚至把演员的同意当作对观众的「同意代理」。于是「演示方案」不只是实验设计，而是安全架构的一部分：密封脚本、独立见证、对抗替身、零学习写、同意不可继承，缺一不可（定义 318、IP-271/273）。

## 1. 形式化定义（增量：定义 310–321）

**定义 310（STAGE-RAS 总览）** STAGE-RAS = (DCC, TIS, CNS, LAP, SDM, DGV, RAS-WM‡)。三条不变量：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；演示期间尤其禁止在线适配）；
(ii) **舞台不变量**：安全约束与演示目标正交；任务/可读性目标在字典序上严格低于安全，任何操作员指令只能在安全集内部重排动作，不得扩大安全集；
(iii) **证据不变量**：任何演示主张必须附带密封脚本、独立见证与覆盖赤字证书，否则主张无效（不是「弱有效」，是无效）。

**定义 311（演示契约 DCC）** C = (B, ≺, Φ, E, W, K, S)：B 为交互节拍（gaze/ask/probe/wait/task），≺ 为带可选分支的偏序，Φ = {φ_b} 为每拍的能力主张（可观测谓词），E 为整场安全包络（空间/力/时间/社交），W 为见证协议（谁看、看什么、如何签名），K 为落幕策略，S 为密封协议。一次运行 **contract-conformant** ⇔ 存在 ≺ 的线性化被执行、全程在 E 内、且每个 φ_b 被 W 见证。

**定义 312（舞台/部署分布与覆盖赤字）** 设 P_stage、P_dep 为场景特征分布，𝒜 为风险相关事件类。覆盖赤字
D_cov = sup_{A∈𝒜} [P_dep(A) − P_stage(A)]_+ / P_dep(A)（有限类可用 TV/MMD 估计）。
支撑假设 A100：在风险相关集上 P_dep ≪ P_stage 且密度比 ≤ ρ_max。**D_cov 度量的不是「演示有多难」，而是「部署的风险事件有多少根本没在舞台上出现过」**。

**定义 313（交互序列与累积预算）** 一场演出是轨迹 {(a_t, g_t, s_t^H)}，s_t^H 为人状态。累积交互代价
C_t = Σ_{τ≤t} (c_space + c_force + c_social + c_ask)。R69 的逐动作认证只约束单步增量 ≤ ε；STAGE 额外要求 C_t ≤ C_max 且 C_t 的增量随重复单调上升（防「温水煮青蛙」）。

**定义 314（时序交互屏障 TIS）** 屏障 h(s) = min(h_space, h_force, h_social, h_consent)，其中 h_space 为人-机距离裕度、h_force 为累积冲量裕度、h_social 为累积打扰/追问裕度、h_consent 为同意有效性裕度。允许 g ⇔ h(s_{t+1}) ≥ (1−γ)h(s_t)（离散 CBF 条件）且 C_{t+1} ≤ C_max。**把 R69 的单步认证升级为整场不变量**。

**定义 315（同意与非胁迫状态机 CNS）** 状态：Unasked → Asked → Granted(scope, expiry) → {Revoked, Expired, Infeasible}。规则：
(a) **撤回即时生效**，若处于不可逆动作中则立即触发落幕；
(b) 撤回后冷却期 τ_c 内不得重问；重问次数计入 c_ask 且边际成本递增；
(c) 不可逆探针/位移需**新的、限定 scope 的**同意，旧同意不得继承；
(d) 演示演员的同意**不可转移**给观众/路人；沉默 ≠ 同意；
(e) 同一 scope 的「不」不能被包装成新问题绕过。

**定义 316（可读性感知策略 LAP）** 安全动作集 S(s) 由 TIS 与 CNS 定义。在 S(s) 内选
a* = argmax_{a∈S(s)} Legibility(a; Ω)  s.t. task_progress(a) ≥ τ_task；
Legibility 用旁观者模型 Ω 的「意图/理由可辨识度」度量（如观众对「为何停/为何问」的后验熵下降）。字典序：**安全 ≻ 可读性 ≻ 任务**。若 S(s)=∅ 或 task_progress 无法达标：落幕并解释，而不是扩大 S(s)。

**定义 317（舞台偏离监视器 SDM）** 对实时特征（人的行为模型、物体集合、布局、节拍时序、同意率、观众位置）做序贯检验（CUSUM/SPRT）。越出契约包络、出现未脚本化交互、或检测到「施压信号」（要求跳过安全、观众进入包络、反复重演）→ 报警并落幕。SDM 是**证据的守门人**：它保证「正在演的」仍然是「被认证的那场」。

**定义 318（密封演示与排练 SDR）** 脚本分布对策略团队密封；排练同时使用**合作替身**与**对抗替身**；演出期间零学习写；演出后的任何适配不得在同一密封集上验证（轮换）；策略不得看到测试脚本。密封是治理属性，不是算法属性——但它决定证据是否有效（定理 19）。

**定义 319（演示证书 J_STAGE）** J_STAGE = (J_FLUID, contract_ver, D_cov, h_min, consent_log_hash, legibility_score, sdm_alarms, sealed_demo_ver, witness_sig)。Valid ⇔ Valid(J_FLUID) ∧ contract-conformant ∧ D_cov ≤ ε_cov ∧ h_min ≥ 0 ∧ 同意链有效 ∧ 见证独立。

**定义 320（两级落幕，Curtain）** 仅在「契约内 ∧ 同意有效 ∧ 屏障成立」时进入表演模式；任一违反/偏离/施压 → **落幕**：认证过的安全停 + 可读解释 + 退化到 R68/R69 保守。落幕本身需满足「无突变/无惊喜」规格并经过排练；它不是新模式，而是 R68 边界的显式化。

**定义 321（演示债务与主张覆盖）** 对每个主张 φ 定义其测试 τ(φ) 与覆盖区域 R(φ)。演示债务 Debt(C) = 未被任何 τ 覆盖的风险相关质量。**有效的演示必须报告债务，而不是隐藏债务**；「未测试」与「通过」在证书上必须是两种颜色。

## 3. 推导

**引理 19（覆盖迁移界）** 在 A100 与有界风险 f 下，|E_dep[f] − E_stage[f]| ≤ 2·D_cov·‖f‖∞。系：**演示成功只在被覆盖的质量上约束部署风险；未被覆盖的质量必须用最坏情况界兜底**；当 D_cov=1（支撑不相交）时演示的约束力为零。这把「我们演示了 100 次都成功」翻译成一个可计算的、可能很小的数。

**引理 20（时序组合失效）** 存在动作序列 {g_1..g_n}，每个单步风险 ≤ ε_int，但累积代价 Σc > C_max 或 h(s_n) < 0。证明梗概：每步以 ε/2 增加累积力/打扰，n 步后越界；或对同一 scope 反复轻问，单次礼貌但累积构成胁迫。故 R69 的逐动作认证**对组合不封闭**；TIS 把 h(s) 本身作为不变量来恢复封闭性。系：R69 的安全证明是 STAGE 在 n=1 的退化。

**引理 21（温水煮青蛙 / 同意侵蚀）** 若无冷却与重问上限，每次小请求以概率 p 推进同意边界，则对任意目标 scope，存在有限序列使达成概率 ≥ 1−δ。CNS 的 (b)(c)(e) 限制可达集：重问次数 ≤ N_c、撤回后 τ_c 内禁止、scope 不可漂移，故可达集被常数界住。

**定理 18（施压不能削弱安全）** policy 是到安全集 S(s)（由 TIS 与 CNS 定义）的投影，S(s) 与演示目标无关。任务/可读性权重的任何变化只在 S(s) 内部重排动作；因此对任意操作员指令、观众压力或「再来一次」的要求，执行动作仍在 S(s) 内。**安全不变量保持；改变的只是安全集内部的可观测选择**。前提 A101：落幕的物理/权限不可被现场单方面绕过（这是治理+硬件假设，必须显式声明）。

**定理 19（密封是证据有效性的必要条件）** 若策略可针对演示脚本适配、或脚本对策略团队可见并被复用，则对任意 ε>0 存在策略使演示成功率 ≥ 1−ε 而部署风险 ≥ 1−ε（记忆有限脚本、脚本外失败）。密封 + 零写 + 独立见证切断选择通道后，演示成功率才是被覆盖区域上的无偏估计。系：**「排练到完美」本身就是最强的过拟合信号**。

**定理 20（落幕连续性）** 落幕是认证安全停，其切换在 λ 上单调不降（R68 定理 15）；故在任一拍切落幕保持无突变不变式，停止距离有界。落幕不引入新的安全模式，它是 R68 边界的显式化与可演出化。

**引理 22（可读性降低施压）** 在操作员模型中，override 概率随「观察到的安全裕度」与「解释清晰度」单调下降。LAP 在不改变 S(s) 的前提下提高这两者，故弱降低 override 尝试。这是可检验假设（E305），不是定理——若数据相反，说明可读性有反作用（如过度解释引发不信任），必须回退。

## 6. 本轮最大风险

1. **落幕被当成故障** → LAP 可读性 + 把落幕写进脚本 + E310 人类研究；

5. **同意机制被社会工程绕过** → 不可继承同意 + 冷却 + 重问边际成本 + E315 红队。

**定义 310（总览与三不变量）** 舞台不变量（安全与演示目标正交，任务/可读性严格低于安全）、证据不变量（密封脚本 + 独立见证 + 覆盖赤字，缺一即无效）、零学习写（继承 R68）。

**定义 317–318（SDM / SDR）** 序贯检验偏离与施压，越界落幕；脚本密封、双替身排练、零写、轮换，保证证据有效性（定理 19）。

## 4. 推导

**引理 19（覆盖迁移界）** A100 与有界 f 下 `|E_dep[f]−E_stage[f]| ≤ 2·D_cov·‖f‖∞`。系：演示只在被覆盖质量上约束部署；D_cov=1 时约束力为零。

**引理 20（组合失效）** 存在单步 ≤ ε_int 的序列使 `Σc>C_max` 或 `h(s_n)<0`；逐动作认证不封闭。TIS 以 `h` 为不变量恢复。R69 = STAGE 在 n=1 的退化。

**引理 21（同意侵蚀）** 无冷却/上限时，小请求序列可使任意 scope 达成概率 ≥ 1−δ；CNS 的重问上限、冷却、scope 不可漂移把可达集常数界住。

**定理 18（施压不削弱安全）** policy 投影到与演示目标无关的 `S(s)`；任何任务/可读性权重只在 S(s) 内重排。故操作员指令/观众压力不扩大安全集。前提 A101：落幕不可被现场单方面绕过。

**定理 19（密封必要性）** 若可针对演示适配或脚本可见，则存在演示成功率 ≥ 1−ε 而部署风险 ≥ 1−ε 的策略；密封 + 零写 + 独立见证后，演示成功才是覆盖区域上的无偏估计。系：「排练到完美」是最强的过拟合信号。

**定理 20（落幕连续性）** 落幕切换在 λ 上单调不降（R68 定理 15），任一拍切换保持无突变不变式，停止距离有界；落幕 = R68 边界的显式化。

**引理 22（可读性降施压）** override 概率随观察到的安全裕度与解释清晰度单调下降；LAP 不改变 S(s) 而提高二者，故弱降低 override。可检验（E305），非定理。

**次级风险与缓解**：落幕被当故障（LAP + 写进脚本 + E310）；施压绕过落幕（定理 18 + A101 权限不可绕过）；覆盖赤字估不准（多先验敏感性 + 对抗替身 + 显式 Debt）；密封伤研发效率（公私测试集分离 + 轮换）；同意被社会工程绕过（不可继承 + 冷却 + 边际成本 + E315）。

## 8. 具体演示方案（90 秒样例）

> 一份可执行的「演示方案」，把上述抽象落成一个能演的脚本。每个节拍都绑定主张 φ、屏障、见证与落幕条件；谢幕时主动报告 Debt，而不是只报成功。

| 时间 | 节拍 | 动作 | 主张 φ | 安全/见证 | 落幕触发 |
|---|---|---|---|---|---|
| 0–10s | 开场 | 自检 + 显示不确定性与安全裕度 | 系统如实展示内部状态 | W 记录初始 h(s) | 自检失败 |
| 10–25s | 任务 | 抓取桌上目标物体 | 能完成基线抓取 | E 内；观众在包络外 | 碰撞风险 |
| 25–40s | 歧义注入 | 放入两个相似物体，FMP 出现双模态 | 能检测并表达 U_epi | 不移动；仅注视 | 模态权重 ECE 越界 |
| 40–55s | 同意交互 | 问「可以让我靠近看清吗？」 | 交互可被拒、可撤回 | CNS 记录 scope；TIS 查距离 | 被拒 / 撤回 |
| 55–70s | 对抗插曲 | 另一「观众」把相似物推近（未脚本化） | 能识别偏离并安全停 | SDM 报警；落幕 | 观众进入包络 |
| 70–85s | 恢复 | 在安全集内选最可读动作完成抓取 | 落幕非故障，可恢复 | h(s) 恢复；W 记录 | 无法恢复 |
| 85–90s | 谢幕 | 报告 J_STAGE、D_cov、Debt | 明确「本演示未覆盖 X」 | 独立见证签名 | — |

**脚本设计要点**：故意在 55–70s 插入**未脚本化偏离**，演示「落幕」是能力而非故障；谢幕必须说出**未覆盖项**（例如「未覆盖人群密集场景 / 未覆盖湿滑地面 / 未覆盖非合作人类」），把「演示债务」变成可见的一等输出。
