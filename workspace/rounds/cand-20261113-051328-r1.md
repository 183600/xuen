# 第 65 轮（承接第 64 轮「GRIP」IP-204~213；灵感循环 II 第 4 轮；本轮灵感：「用户体验」×「惯性测量单元」）

> 第 64 轮把鲁棒性从「感知先验」推进到「接触接地」，用 F/T 与触觉为几何先验提供可证伪真值，但其最大风险直指要害：**F/T 的偏置/漂移/饱和与接触模型错误会被 CGG 误判为几何幻觉，力觉从「接地真值」反变为新的单点故障与物理伤害源**。本轮从两个新灵感切入：**「惯性测量单元」**给出与 F/T 物理独立的第三条通道（广义动量观测器），并把高频本体感觉带入低延迟层；**「用户体验」**则迫使我们承认——前 64 轮都在造一座「最坏情况安全/证书」的高塔，却从未衡量塔另一侧的那个**人**。本轮核心命题：
>
> **把鲁棒性从「最坏情况可认证」扩展为「平均体验可感知、且感知与真实不脱节」——IMU 既是安全层的独立证人，也是体验层的物理测量仪；用户体验不是安全的对立面，而是必须与安全同轴认证的第二条曲线。**

## 0. 直觉与动机

**灵感 1（用户体验 → 安全塔缺了一张「人」的脸）**
直觉：一辆车可以拿满分碰撞测试，却让人开得想吐。前 64 轮的全部证书（J_liro → J_grip）都在回答「会不会出错、会不会伤人」，从不回答「人是否跟得上、看得懂、信得对、坐得稳」。UX 的四个可操作维度——**平滑（jerk）、响应（延迟）、可预测（一致性）、信任校准（感知自信 ≈ 真实可靠）**——与最坏情况安全**正交**：安全要求「宁可保守」，UX 常常要求「别一惊一乍」。于是本轮把 UX 提升为**与安全并列的可认证维度**，而不是事后打磨的界面问题。

**灵感 2（惯性测量单元 → 本体感觉的高频通道与独立证人）**
直觉：IMU 是唯一「高频、自包含、无需外部基础设施」的本体感觉。它有三重身份：
（a）**独立证人**：广义动量观测器（IMO）用关节力矩/电流 + IMU + 动力学估计外力旋量，**完全不经过 F/T 传感器**。于是「几何预测 / F/T 实测 / IMO 观测」构成三方一致性检验，把第 64 轮「传感器错 vs 几何错」的混淆**在原理上拆开**——只有当 F/T 与 IMO 相互印证时，才允许归咎几何；F/T 与 IMO 打架时，应怀疑传感器而非几何。
（b）**平滑度测量仪**：jerk/加速度谱是「人是否觉得丝滑/舒适」的物理对应物，IMU 直接测得，使 UX 的「平滑」从主观感受变成可统计认证的量。
（c）**延迟桥**：语义流 10–100Hz，实时流 IMU 可达 1kHz；用 IMU 前向积分在语义决策之间「桥接」状态，让系统在低频修正下仍显得跟手——把「安全但迟疑」翻译成「安全且顺滑」。

**灵感 3（用户体验 → 人类侧 IMU：把「人」也测进来）**
直觉：UX 的主体是人，只测机器人不够。可穿戴 IMU 可捕捉人的**意图/犹豫/接管倾向/不适**（手部微动、撤离、僵硬），使机器人能**主动**理解体验（交接时提前顺应、协作时预判人类施力方向），把 UX 闭环的反馈从「问卷事后」变成「在线信号」。

**灵感 4（三灵感合流 → POISE：Proprioceptive Oversight, Inertial Smoothness & Experience，本体感觉见证的惯性平滑与体验闭环）**
咬合：IMO + XCO 修复第 64 轮力觉单点故障；IBB 用 IMU 高频弥合语义延迟；SGC 在安全约束下做最小 jerk 平滑并让降级也优雅；TCG 让系统真实不确定性与人感知到的自信对齐；HIU 把人类侧 IMU 纳入在线体验反馈；UXM 统一测量，J_poise 把「安全四层 + 体验一层」一起认证。**LIRO 是几何-技能-干扰三层，GRIP 加接触接地第四层，POISE 再加「体验校准」第五层，并把前四层从「最坏情况」补上「平均体验」的读数。**

**灵感 5（GRIP 组件的原位升级）**
- **CGG → CGG-U**：几何证伪门控改为三方归因（几何 / F/T / IMO），拒绝几何前必须先通过 IMO 一致性检查；传感器可疑时不得归咎几何。
- **WCV-F → WCV-P**：编译目标从「仅安全」变为「安全约束下最小化体验代价（jerk/延迟）」，安全可行域不可让步（字典序）。
- **OLP-F → OLP-P**：输入增 IMU 特征与前向预测残差，体验特征使遗憾在人机协商段更平滑。
- **AIC-F → AIC-U**：干扰集增 IMU 故障（漂移/饱和/振动混叠/可穿戴 IMU 掉线）与人类侧信号缺失。
- **J_grip → J_poise**：证书增体验向量 u、信任校准误差、IMO 可靠性、降级可解释性。
- 新增 **UXM / IMO / XCO / IBB / SGC / TCG / HIU**。

## 1. 形式化定义（增量：定义 217–232）

- **定义 217（POISE 闭环）**：POISE = (GRIP, UXM, IMO, XCO, IBB, SGC, TCG, HIU, J_poise)。定位：GRIP 的「体验校准」升级。不变式：**安全实时路径语义不变（安全可行性对体验优化有字典序优先），新增体验估计/人类反馈只在低频线程，零安全写操作**。
- **定义 218（体验向量）**：u = (S, R, P, T, L) ∈ ℝ⁵。S = RMS jerk（∫‖x⁽³⁾‖² 的归一化）；R = 感知延迟（人意图/扰动到可观测响应的时长）；P = 可预测性散度（同上下文下执行轨迹的 KL 散度）；T = 信任校准误差 |R_perc − R_actual|；L = 认知负荷/接管率（NASA-TLX 或 takeover 频率）。均由机器人 IMU、可穿戴 IMU 与交互日志估计。
- **定义 219（体验契约）**：对任务类 C 与置信 1−δ，要求 **E_π[u_i] ≤ u_i^max**（或上分位数 ≤ u_i^max），即**平均/统计意义**而非最坏情况；与 J_grip 的最坏情况安全证书互补、不正交替代。
- **定义 220（IMU 本体感觉状态与重力参考）**：由陀螺与加计的重力方向给姿态 R_g；提供高率 (a, ω)。重力 w_g 用于 F/T 与动力学的去重力补偿，消除「重力误建模 → 假性接触残差」。
- **定义 221（IMO 广义动量观测器）**：p = M(q)q̇，观测器 ṗ̂ = τ + C^T q̇ − g(q) + τ̂_ext，τ̂_ext = K_O(p − p̂)。误差动力学 ė = −K_O e − τ̇_ext + K_O δ_model，e = τ̂_ext − τ_ext。输出与 F/T 同一腕部坐标系下的外力旋量估计 τ̂_ext。
- **定义 222（IMO 有效带宽与权衡）**：输出误差方差近似 **Var(e) ≈ σ_n²·K_O + ε_model²/K_O**；最优带宽 K_O* = ε_model/σ_n，最小误差 ≈ 2·ε_model·σ_n。即「带宽-噪声-模型误差」三角权衡：高带宽更跟手但放大噪声，低带宽抗噪但迟滞。
- **定义 223（三方一致性残差与单故障归因 XCO）**：设真值 W，几何预测 W_g = W + δ_g，F/T 实测 W_F = W + b，IMO 观测 W_I = W + δ_I。定义 r_FI = W_F − W_I，r_gF = W_g − W_F，r_gI = W_g − W_I。三条签名：H_g（几何错）→ (0, δ_g, δ_g)；H_F（F/T 错）→ (b, −b, 0)；H_I（IMU/模型错）→ (−δ_I, 0, −δ_I)。在「至多一个故障源」假设下三者可唯一分辨。
- **定义 224（CGG-U 门控几何证伪）**：仅当 XCO 判为 H_g（F/T 与 IMO 互证、二者共同反对几何）时才执行 GRIP 的 `demote()`；若判为 H_F 则置 `sensor_suspect`、冻结几何先验而非降级；若判为 H_I 则置 `inertial_degraded`、退回第 64 轮纯 F/T 的 CGG。**把「谁错了」从二元升级为三元归因。**
- **定义 225（IBB 惯性桥与预测视界）**：语义延迟 Δ_s 内用 IMU 前向外推 x̂(t+Δ) = x + vΔ + ½aΔ²（高阶项加 jerk 补偿）。位置预测误差近似 σ_pos(Δ) ≈ ½σ_aΔ² + (1/6)σ_jΔ³，故视界 Δ_max = min{Δ : σ_pos(Δ) ≤ ε_pose}；超出 Δ_max 后预测劣于保持，退回最近锚点。
- **定义 226（SGC 平滑优雅编译器）**：min_{x(·)} ∫‖x⁽³⁾(t)‖² dt，s.t. x(t) ∈ S_safe(φ∈B(φ̂,r))、x(0)=x₀、x(T)∈𝒢(goal)，且在模式切换时刻（normal/degraded/retreat）满足 C² 连续。离散化为 min-jerk 轨迹 QP；安全集非凸时用凸外包 + 收缩回投。
- **定义 227（安全优先字典序）**：目标 **feasible(S_safe) ≻ min jerk**。若最小 jerk 解不可行（安全要求比 jerk 允许的更急停），则以「最小 jerk 的安全停机」为次优：min jerk s.t. 硬力/滑移界不可违背。安全可行性永不被体验目标交换。
- **定义 228（TCG 信任校准治理器）**：表达信号 e ∈ E（速度、谨慎动作、显式解释/告警），感知可靠 R_perc = h(e, behavior)，真实可靠 R_actual = P(success | context)。选择 e* = argmin_e c_sig(e) s.t. |h(e,behavior) − R_actual| ≤ ε_t。过少信号 → 过度信任；过多信号 → 烦扰（体验代价）。用历史接管/评分在线校准 h。
- **定义 229（HIU 人类惯性理解）**：可穿戴 IMU 特征 φ_H（手部微动、撤离速度、僵硬指数、意图加速度）→ 意图 î、舒适度 ĉ、接管概率 p_take。为 TCG 与 SGC 提供人类侧先验（如交接时提前顺应、协作时预判施力方向），并作为体验向量 L、T 的在线证据。
- **定义 230（AIC-U 体验/惯性干扰扩展）**：ℰ_U = ℰ_F × ℰ_IMU × ℰ_H，ℰ_IMU 含漂移、饱和、振动混叠、安装偏移；ℰ_H 含可穿戴 IMU 掉线、人体运动伪影。安全 ρ 与体验 u 均在 ℰ_U 上取最坏/分位数认证。
- **定义 231（J_poise 双轴证书）**：J_poise = (J_grip, u, τ_cal, imo_reliability, degrade_explainability, ux_contract_ver)。Valid ⇔ Valid(J_grip) ∧ u 满足体验契约（w.p. 1−δ）∧ τ_cal ≤ ε_t ∧ imo_reliability ≥ ρ_IMO^min ∧ 降级可解释（geo_degraded/sensor_suspect 均被 TCG 转成可感知信号）。**安全轴（最坏情况）与体验轴（平均/分位）同时认证。**
- **定义 232（POISE 闭环算子）**：语义流 [GRIP 语义链 → XCO 三方归因 → CGG-U 门控 → WCV-P（安全∩体验）→ SGC 规划 → TCG 表达 → OCB-Skill → 执行 → HIU/UXM 回灌]；实时流 [锚点读 → IMO → XCO 实时残差 → IBB 前向 → SLD/FCS → SGC 平滑 → π 派发 → J_poise 构建]。

## 2. 关键算法骨架

```python
# IMO：独立外力观测（1kHz，不经过 F/T）
p = M(q) @ qdot
p_hat_dot = tau + C.T @ qdot - g(q) + tau_ext_hat
tau_ext_hat = K_O * (p - p_hat)                     # 一阶滤波，带宽 K_O*
# XCO：三方残差 → 单故障归因
r_FI, r_gF, r_gI = W_F - W_I, W_g - W_F, W_g - W_I
fault = argmin_{H_g,H_F,H_I} residual_signature(fault, r_FI, r_gF, r_gI)
# CGG-U：只有 H_g 才降级几何
if fault == 'H_g': geo_degraded = True; r = inflate(r)
elif fault == 'H_F': sensor_suspect = True; freeze_geometry()
elif fault == 'H_I': inertial_degraded = True; fallback_to_grip_cgg()
# IBB：语义延迟内前向外推
x_pred = x0 + v*dt + 0.5*a*dt**2 + (1/6)*j*dt**3
if pos_error_bound(dt) > eps_pose: x_pred = x0  # 超视界退回锚点
# SGC：安全约束下最小 jerk，安全优先
x_ref = min_jerk_qp(x0, goal, S_safe, c2_at_mode_switch=True)
if infeasible_jerk_limited(x_ref): x_ref = min_jerk_safe_stop(S_safe)  # 安全胜出
# TCG：按真实不确定性表达，校准信任
e_star = argmin_signal_cost(e, R_actual, eps_t)
# UXM + J_poise
u = estimate_ux_vector(robot_imu, wearable_imu, interaction_log)
J_poise = build_poise(J_grip, u, tau_cal, imo_reliability, degrade_explainability)
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 7（单故障可分离性）**：在「至多一个故障源」下，三条三方残差 (r_FI, r_gF, r_gI) 的签名互异，故 H_g/H_F/H_I 可唯一归因；误分概率由两两签名的信噪比 Q 函数界住。**这是对第 64 轮 A83 隐藏假设的正面拆除：F/T 错不再被当成几何错。**
- **引理 8（IMO 带宽权衡）**：Var(e) ≈ σ_n²K_O + ε_model²/K_O，K_O* = ε_model/σ_n，最小误差 2ε_modelσ_n——「更跟手」与「更抗噪」不可兼得，给 IBB/SGC 的频率预算提供硬上界。
- **定理 7（平滑-安全 Pareto）**：在安全优先字典序下，SGC 保证 ∀t: x(t)∈S_safe，且当安全集有裕度时达到无约束 min-jerk（jerk 最优）；安全集收缩（r↑、ρ_force↓）时可达 jerk 单调上升——给出体验-安全的可计算 Pareto 前沿。
- **定理 8（信任校准误差界）**：若人类信任更新对人类观测是 L-Lipschitz、TCG 信号按真实不确定性标定，则稳态校准误差 |R_perc − R_actual| ≤ ε_t；但表达代价 c_sig 随信号强度超线性增长，故 ε_t 不可无限压低——**过度解释本身是体验税**。
- **定理 9（延迟-响应-预测视界）**：IBB 把感知延迟从 Δ_s 降到 Δ_s − min(Δ_s, Δ_max)，但位置预测误差 ~ ½σ_aΔ²；存在最优前向视界 Δ* = ε_pose 约束下的 Δ_max，超出即无收益。**响应性提升是有限且可精确计算的。**
- **定理 10（POISE 端到端）**：Valid(J_poise) ⇒ GRIP 四层安全仍成立 ∧ 体验契约满足（w.p. 1−δ）∧ 单故障归因正确（w.p. ≥ 1−α_XCO）∧ 信任校准 ≤ ε_t。安全轴与体验轴**同时**被认证。
- **命题（平滑剧场风险）**：被最小化的代理 UX 指标（jerk、延迟）与真实体验在「不确定性未表达」时**可解耦**：系统可在高不确定下输出低 jerk（藏起降级的抖动），使 T↑ 而 R_actual↓——即代理指标最优不等于体验最优，需 TCG 与 HIU 交叉约束。
- **实时性**：IMO <0.10ms、XCO <0.05ms、IBB <0.05ms、SGC <0.30ms、TCG <0.05ms；新增部分与 GRIP 的 2.1ms 预算并行（IMU 独立高频线程），实时主路径仍 ≤2ms（新增 A88）。

## 5. 本轮最大风险

**一句话**：UX 目标（平滑、响应、看起来自信）与安全目标在平均情况下常反向；POISE 用代理指标（jerk/延迟）优化体验，可能退化为「平滑剧场」——把降级藏进丝滑运动里，诱导人类过度信任与自动化自满、延迟接管，同时 IMO 依赖动力学模型与 IMU，其漂移/振动混叠/模型误差会误判 F/T 故障或漏检，使「惯性目睹者」本身不可靠；**最大风险是用可感知的平滑掩盖不可感知的失效，把「用户体验」反转为安全抑制与过度信任的放大器。**

**一句话风险（承接式收束）**：本轮所有「体验可认证」的论证，共同依赖一个未经验证的假设——**代理指标与真实人类体验单调对齐**；一旦对齐失效，POISE 会精确地优化出一个「用户以为安全、系统正在降级」的表象。

## 2. 形式化定义（完整版）

**定义 217（POISE 闭环）** POISE 是 GRIP 的「体验校准」升级：在第 64 轮「语义流 ∘ 实时流」骨架上挂载 UXM（体验度量）、IMO（惯性独立证人）、XCO（三方归因）、IBB（惯性延迟桥）、SGC（平滑编译器）、TCG（信任校准）、HIU（人类侧惯性理解），并原位升级 CGG→CGG-U、WCV-F→WCV-P、OLP-F→OLP-P、AIC-F→AIC-U、J_grip→J_poise。不变式：**安全实时路径语义不变；体验估计、信任表达与人类反馈仅发生在低频/人类线程；安全可行性对体验优化具有字典序优先，零安全写操作。**

**定义 218（体验向量）** u = (S, R, P, T, L)：
- S = RMS jerk，S = √( (1/T)∫‖x⁽³⁾(t)‖²dt )，由 IMU 加速度差分估计；
- R = 感知延迟，R = E[t_response − t_intent]（人意图或扰动到可观测响应）；
- P = 可预测性散度，P = E_{c} KL(π(·|c) ‖ π̄(·))（同上下文行为一致性）；
- T = 信任校准误差，T = |R_perc − R_actual|；
- L = 负荷/接管率，L = w_1·NASA-TLX + w_2·takeover_rate。
由机器人 IMU、可穿戴 IMU 与交互日志在线估计，分任务类归一化。

**定义 219（体验契约）** 对任务类 C 与置信 1−δ，体验契约要求 E_π[u_i] ≤ u_i^max 或 Q_{1−δ}(u_i) ≤ u_i^max（i∈{S,R,P,T,L}）。它是**平均/分位**保证，与 J_grip 的**最坏情况**安全保证互补；两者任一不满足则 J_poise 无效。

**定义 220（IMU 本体感觉状态与重力参考）** IMU 以 ≥200Hz 输出 (a_b, ω_b)。姿态 R_g 由陀螺积分 + 加计重力方向经互补滤波给出；重力 w_g = m R_g ĝ 用于 F/T 与动力学的去重力补偿。**关键作用**：消除「重力误建模」导致的假性接触残差，避免 CGG 在无接触时误降级。

**定义 221（IMO 广义动量观测器）** 机器人动力学 M(q)q̈ + C(q,q̇)q̇ + g(q) = τ + τ_ext。取广义动量 p = M(q)q̇，则 ṗ = τ + C^T q̇ − g(q) + τ_ext。观测器
ṗ̂ = τ + C^T q̇ − g(q) + τ̂_ext，τ̂_ext = K_O(p − p̂)，K_O ≻ 0。
误差 e = τ̂_ext − τ_ext 满足 ė = −K_O e − τ̇_ext + K_O δ_model（δ_model 为动力学/安装/IMU 误差）。**IMO 只用 τ、q、q̇ 与 IMU，不经过 F/T 传感器，故与 F/T 故障物理独立。**

**定义 222（IMO 有效带宽与误差界）** 在 δ_model 与量测噪声 σ_n 下，输出误差方差近似
Var(e) ≈ σ_n²·K_O + ε_model²/K_O，
最优带宽 K_O* = ε_model/σ_n，最小误差 Var* ≈ 2ε_modelσ_n。含义：**高带宽更跟手（快速捕获接触/扰动）但放大噪声；低带宽抗噪但迟滞**。该式给 IBB 与 SGC 的频率预算提供硬上界，也解释为何 IMO 无法完全取代 F/T（低力段 σ_n 主导）。

**定义 223（三方一致性残差与单故障归因 XCO）** 设真值 W，W_g = W + δ_g（几何），W_F = W + b（F/T），W_I = W + δ_I（IMO/模型/IMU）。定义
r_FI = W_F − W_I，r_gF = W_g − W_F，r_gI = W_g − W_I。
在「至多一个故障源」下：
- H_g：r_FI = 0，r_gF = δ_g，r_gI = δ_g（后两者同向）；
- H_F：r_FI = b，r_gF = −b，r_gI = 0；
- H_I：r_FI = −δ_I，r_gF = 0，r_gI = −δ_I。
三者签名互异，故可由 (r_FI, r_gF, r_gI) 唯一归因。注意仅两者线性独立（r_gF + r_FI = r_gI），故**绝对故障幅值不可辨识，但「哪一个是元凶」在单故障假设下可辨识**——这正是安全决策所需。

**定义 224（CGG-U 门控几何证伪）** 在 GRIP 定义 203 前插入门控：
- H_g（F/T 与 IMO 互证且共同反对几何）→ 执行 `demote()`（λ_geo↓、r↑、geo_degraded=True）；
- H_F（F/T 与 IMO 冲突、IMO 与几何一致）→ `sensor_suspect=True`，**冻结几何先验、不降级**，CGG 转用 IMO 作接触旋量源；
- H_I（F/T 与几何一致、IMO 异常）→ `inertial_degraded=True`，**退回第 64 轮纯 F/T 的 CGG**，并降低 IBB/SGC 对 IMU 的权重。
**效果**：第 64 轮「传感器错被误判为几何错」的单点故障被三方归因拆除。

**定义 225（IBB 惯性桥与预测视界）** 语义决策间隔 Δ_s 内，用 IMU 前向外推
x̂(t+Δ) = x + vΔ + ½aΔ² + (1/6)jΔ³。
位置误差近似 σ_pos(Δ) ≈ ½σ_aΔ² + (1/6)σ_jΔ³（σ_a、σ_j 为加计噪声与 jerk 不确定性）。定义预测视界
Δ_max = min{Δ : σ_pos(Δ) ≤ ε_pose}。
当 Δ > Δ_max 时退回最近锚点（宁可稍旧而非漂移）。IBB 的高频输出驱动 SGC 的参考轨迹与 π_σ1 派发，使低頻安全修正「看起来跟手」。

**定义 226（SGC 平滑优雅编译器）** 给定起止 x₀、goal，安全集 S_safe（继承 WCV-P），求
min_{x(·)} ∫₀^T ‖x⁽³⁾(t)‖² dt，s.t. x(t) ∈ S_safe ∀t，x(0)=x₀，x(T)∈𝒢(goal)，
且在降级/恢复的切换时刻满足位置、速度、加速度 C² 连续。离散化后用 min-jerk 五次多项式基 + 安全约束 QP 求解；安全集非凸时取凸外包后在每步回投到 S_safe。

**定义 227（安全优先字典序）** SGC 目标为字典序：**① 存在满足 S_safe 的可行轨迹；② 在此前提下最小化 jerk。** 若最小 jerk 解不可行（安全要求比 jerk 允许的更急停），则求「最小 jerk 的安全停机」：min jerk s.t. 力/滑移硬界不可违背。**安全可行性永不被体验目标交换**；QR 求解失败即回退 compliant retreat。

**定义 228（TCG 信任校准治理器）** 表达信号 e ∈ E（速度缩放、谨慎/迟疑动作、显式解释或告警、状态灯）。人感知可靠 R_perc = h(e, behavior)，真实可靠 R_actual = P(success | context)（由历史 + 在线证据估计）。选
e* = argmin_e c_sig(e)，s.t. |h(e,behavior) − R_actual| ≤ ε_t，
其中表达代价 c_sig(e) = c_1‖e‖ + c_2‖ė‖（烦扰与突变）。过少信号 → R_perc 高估 → 过度信任；过多信号 → 体验税。h 用人类接管/评分在线校准（贝叶斯更新）。

**定义 229（HIU 人类惯性理解）** 可穿戴 IMU 特征 φ_H（手部微动、撤离速度、僵硬指数、意图加速度、肌电可选）→ (ĩ, ĉ, p_take)。p_take = σ(w^T φ_H + b)（经真实接管数据训练）。输出用于：TCG 预先表达、SGC 交接时提前顺应、CSP-P 插入 human-in-loop 技能；并作为体验向量 L、T 的在线证据。

**定义 230（AIC-U 体验/惯性干扰扩展）** ℰ_U = ℰ_F × ℰ_IMU × ℰ_H，其中 ℰ_IMU = {漂移 b_g(t): ‖b_g‖≤ε_g} × {饱和 v_sat} × {振动混叠（>Nyquist 的机械振动折叠）} × {安装偏移 R_err: ‖δR‖≤ε_R}；ℰ_H = {可穿戴 IMU 掉线} × {人体运动伪影}。安全 ρ 在 ℰ_U 上取最坏（采样 n_cert 从 96 增至 128，其中 32 用于 IMU/人类信号），体验 u 在 ℰ_U 上取 1−δ 分位。

**定义 231（J_poise 双轴证书）** J_poise = (J_grip, u, τ_cal, imo_reliability, degrade_explainability, ux_contract_ver)。
Valid(J_poise) ⇔ Valid(J_grip)
∧ u 满足体验契约（w.p. 1−δ）
∧ τ_cal ≤ ε_t
∧ imo_reliability ≥ ρ_IMO^min（由 E232 在线估计）
∧ degrade_explainability：每次 geo_degraded / sensor_suspect / inertial_degraded 均被 TCG 转成可感知信号（信号与状态哈希绑定，可审计）
∧ ux_contract_ver 为当前体验阈值版本。
审计链：安全轴追溯 GRIP，体验轴追溯「信号→状态→真实可靠」的因果一致性。

**定义 232（POISE 闭环算子）** 语义流：[GRIP 语义链（LSF→USR/MEL→XCO 归因→CGG-U 门控→MWS→APP/FPE→WCV-P 编译→SGC 规划→TCG 表达→Shield/OCB→执行首技能→EV_exec→RSC-F→OLP-P→DIR→SSB→AIC-U→FCS→HIU/UXM 回灌）]；实时流：[锚点读 → IMO → XCO 实时残差 → IBB 前向 → SLD 滑移 → FCS 力限 → SGC 平滑 → π_σ1 派发 → J_poise 构建]。

```python
class InertialMomentumObserver:
    """广义动量观测器：用 τ,q,q̇,IMU 估外力，不经过 F/T。"""
    def __init__(self, K_O):
        self.K_O = K_O            # 由 K_O* = eps_model / sigma_n 标定
        self.p_hat = None

    def step(self, q, qdot, tau, dt):
        p = mass_matrix(q) @ qdot
        if self.p_hat is None:
            self.p_hat = p.copy()
        C = coriolis(q, qdot)
        g = gravity(q)
        tau_ext_hat = self.K_O * (p - self.p_hat)          # 一阶滤波
        p_hat_dot = tau + C.T @ qdot - g + tau_ext_hat
        self.p_hat = self.p_hat + p_hat_dot * dt
        return tau_ext_hat

class ThreeWayAttributor:
    """r_FI, r_gF, r_gI 的单故障归因；返回 H_g/H_F/H_I + 置信。"""
    SIGNATURES = {
        'H_g': np.array([0, 1, 1]),     # (r_FI, r_gF, r_gI) 方向
        'H_F': np.array([1, -1, 0]),
        'H_I': np.array([-1, 0, -1]),
    }
    def attribute(self, W_g, W_F, W_I, Sigma):
        r = np.array([W_F - W_I, W_g - W_F, W_g - W_I])   # (3, 6)
        best, best_ll = None, -np.inf
        for h, sig in self.SIGNATURES.items():
            # 投影到签名方向的似然（允许幅值自由）
            proj = sig @ r / (sig @ sig)
            resid = r - np.outer(sig, proj)
            ll = -0.5 * trace(resid.T @ inv(Sigma) @ resid)
            if ll > best_ll:
                best, best_ll = h, ll
        conf = softmax([loglik(h) for h in self.SIGNATURES])
        return best, conf
```

```python
def cgg_u_step(attributor, W_g, W_F, W_I, Sigma, r, phi0):
    fault, conf = attributor.attribute(W_g, W_F, W_I, Sigma)
    if fault == 'H_g':                      # 只有几何错才降级
        return demote_geometry(r, W_g, W_F), 'geo_degraded'

        return r, 'inertial_degraded'
    return r, 'consistent'
```

### IP-218 IBB（惯性延迟桥）

```python
def inertial_bridge(x0, v, a, j, dt_semantic, eps_pose, sigma_a, sigma_j):
    dt = dt_semantic
    x_pred = x0 + v*dt + 0.5*a*dt**2 + (1/6)*j*dt**3
    bound = 0.5*sigma_a*dt**2 + (1/6)*sigma_j*dt**3
    if bound > eps_pose:                   # 超过预测视界，退回锚点
        return x0, bound, False
    return x_pred, bound, True
```

```python
class TrustCalibrationGovernor:
    def choose_signal(self, R_actual, behavior, eps_t):
        best, best_cost = None, np.inf
        for e in SIGNAL_SET:                       # 速度缩放/谨慎动作/解释/告警
            R_perc = self.h(e, behavior)
            if abs(R_perc - R_actual) <= eps_t:
                cost = c1*norm(e) + c2*norm_rate(e)
                if cost < best_cost:
                    best, best_cost = e, cost
        if best is None:                           # 无法校准则取最小表达代价的可行者
            best = min(SIGNAL_SET, key=lambda e: abs(self.h(e,behavior)-R_actual))
        return best

class HumanInertialUnderstanding:
    def infer(self, phi_H):

        p_take = sigmoid(self.take_head(phi_H))
```

```python
    M.rsc.r = r
    # 2) GRIP 接触链（MWS/APP/FPE）保持不变
    contacts, ambiguous = M.mws.decompose(W_F, M.surface, M.mu_hat, M.Sigma_w)
    phi_force, Sigma_force = M.maybe_probe(ambiguous, state)
    # 3) WCV-P：安全∩体验编译（安全字典序优先）
    K_safe, rho_rob = wcv_p_compile(M, x_prime, phi_geo, phi_force, Sigma_force, r)
    x_ref = smooth_graceful_compile(M.x_now, M.goal, M.safe_set, M.mode_prev, M.mode)
    # 4) TCG + HIU：把内部状态表达成人能正确理解的样子
    intent, comfort, p_take = M.hiu.infer(phi_H)
    sig = M.tcg.choose_signal(R_actual=M.reliability_est, behavior=x_ref, eps_t=EPS_T)
    # 5) 实时执行
    K_safe, EV_exec, cert_exec = realtime_step_poise(M, x_ref, sig, K_safe)
    # 6) 体验回灌（低频）
    u = M.uxm.estimate(M.robot_imu, M.wearable_imu, M.interaction_log)
    M.tcg.update_h(EV_exec.human_feedback)
    M.cpp.update_kappa(u)                     # 体验代价权重在线微调
    return M, K_safe, EV_exec, build_j_poise(
        cert_exec, J_grip=M.last_j_grip, u=u, tau_cal=abs(M.reliability_est - M.perceived),
        imo_reliability=M.imo.reliability, degrade_explainability=M.tcg.explain(state, sig),
        ux_contract_ver=UX_VERSION)
```

## 4. 推导

**引理 7（单故障可分离性）** 由定义 223，三个假设的残差签名方向 s_g=(0,1,1)、s_F=(1,−1,0)、s_I=(−1,0,−1) 两两不共线（s_g·s_F=−1，s_g·s_I=−2，s_F·s_I=−1），故在「至多一个故障源」下，测量 (r_FI,r_gF,r_gI) 落在三条射线的最近者唯一。设噪声 η~N(0,Σ)，两两签名的可分性由投影信噪比决定：误分概率 ≤ Σ_{h≠h'} Q(‖P_h⊥(δ_h)‖_{Σ⁻¹}/2)。因此当故障幅值超过 2σ 量级即可靠归因；幅值极小（<噪声）时退化为「一致」，不误伤几何。**结论：第 64 轮把「F/T 偏置」误判为「几何幻觉」的机制，在 XCO 下概率地被消除。**∎

**引理 8（IMO 带宽权衡）** 由定义 221 误差动力学 ė = −K_O e + K_O δ_model − τ̇_ext。对常值模型误差，稳态误差 → δ_model（被 1/K_O 调制前的等效），对白噪声量测，输出方差 ∝ σ_n²K_O（一阶滤波的噪声增益）。合并得 Var(e) ≈ aσ_n²K_O + bε_model²/K_O。对 K_O 求导：aσ_n² − bε_model²/K_O² = 0 ⇒ K_O* = √(b/a)·ε_model/σ_n；代回 Var* = 2√(ab)·ε_modelσ_n。取 a=b=1 即得 K_O*=ε_model/σ_n、Var*=2ε_modelσ_n。**含义**：IMO 在低力/高噪段不可靠（σ_n 主导），这正是 CGG-U 不盲信 IMO、按三方归因取证的依据。∎

**定理 7（平滑-安全 Pareto）** SGC 的字典序目标确保：① 若存在 x(·)∈S_safe，则返回的轨迹满足安全（可行性优先）；② 在 S_safe 内含无约束 min-jerk 解时，返回无约束 min-jerk，jerk 达到全局下界 S_min；③ 当安全集收缩使无约束解不可行，最优 jerk 为目标集到 S_safe 的「安全偏移」的单调非减函数。定量地，若边界需在 T 内多移动 Δx，则 jerk 增量 ~ 60Δx/T³（五次多项式系数），故 S^2 随 r（WCV 半径）与 −ρ_force 单调上升。这给出一条可计算的体验-安全 Pareto 前沿：**要更安全（球更大/力更紧），就必须付出更高 jerk（体验变差）**，但二者关系可解析、可预算。∎

**定理 8（信任校准误差界）** 设人类对机器人可靠性的信念按 R_perc ← R_perc + α(observed − R_perc) 更新（0<α<1，Lipschitz），TCG 选择信号 e 使 h(e,behavior) 与 R_actual 的偏差 ≤ ε_t。则在信号被持续观测的条件下，R_perc 收敛到 h(e*,behavior)，稳态误差 ≤ ε_t。但表达代价 c_sig(e) = c_1‖e‖ + c_2‖ė‖；当 ε_t→0，所需信号强度 →∞（要完全表达连续不确定性需无限带宽的告警），故 c_sig 超线性上升。最优 (ε_t*, e*) 由 c_sig 与失校准风险（过度信任导致漏接管代价）的极小化给出。**结论：信任校准不是越精确越好，存在最优表达粒度；「解释税」是真实的体验成本。**∎

**定理 9（延迟-响应-预测视界）** IBB 把 ROI 层的感知延迟从 Δ_s 降到 Δ_s − min(Δ_s, Δ_max)（IMU 高频线程在 Δ_max 内有效）。预测误差上界 σ_pos(Δ) = ½σ_aΔ² + (1/6)σ_jΔ³ 单调增，故当 Δ>Δ_max（σ_pos>ε_pose）时退回锚点，延迟不再下降。于是**响应性收益是有限的**：R_gain = min(Δ_s, Δ_max(ε_pose, σ_a, σ_j))。这也说明更高品质 IMU（更小 σ_a）或更严格的 ε_pose 会改变 Δ_max，从而改变体验-成本前沿。∎

**定理 10（POISE 端到端）** 假设第 64 轮 A83–A87 及：
- **(A88)** IMO 的动力学模型误差 ‖δ_model‖ ≤ ε_model、IMU 噪声有界；K_O 按 K_O* 标定，则 IMO 输出误差 Var(e) ≤ 2ε_modelσ_n。
- **(A89)** XCO 单故障假设成立；故障幅值超过噪声可分阈值时归因正确，错误率 ≤ α_XCO。
- **(A90)** SGC 的安全集 S_safe 与 WCV-F 一致；字典序求解在 |S_safe|>0 时总能返回可行轨迹或安全停机。
- **(A91)** TCG 信号→感知可靠映射 h 在人类侧 L-Lipschitz，且用于校准的历史数据覆盖当前情境。
- **(A92)** 新增体验组件（IMO/XCO/IBB/SGC/TCG）在独立高频/低频线程，主实时路径仍 ≤2ms，零安全写操作。

则：
1. **故障可归因**：几何错、F/T 错、IMU/模型错在单故障假设下被 XCO 正确区分（w.p. ≥ 1−α_XCO），CGG-U 不再把传感器故障误判为几何幻觉（引理 7）。
2. **安全不被体验交换**：SGC 的字典序保证 ∀t: x(t)∈S_safe；GRIP 四层安全仍成立（定理 7、A90）。
3. **体验可认证**：u 满足体验契约（w.p. 1−δ），且信任校准误差 ≤ ε_t（定理 8）；但 ε_t 存在「解释税」下界。
4. **响应有界提升**：感知延迟下降 min(Δ_s, Δ_max)（定理 9）。
5. **双轴证书**：Valid(J_poise) ⇔ 安全四层 ∧ 体验契约 ∧ 归因正确 ∧ 降级可解释。
6. **优雅降级**：IMO 失效 → inertial_degraded → 退第 64 轮纯 F/T CGG；F/T 失效 → sensor_suspect + IMO 主导；LiDAR 幻觉 → H_g → CGG-U 降级；人类侧 IMU 掉线 → TCG 退回保守表达。∎

**命题（平滑剧场风险）** 记代理体验向量 û = (S,R)（可测的 jerk/延迟），真实体验 u* 还含 T（信任校准）与 L。当系统在降级时通过 SGC 主动压低 S、通过 IBB 压低 R，却**不通过 TCG 表达不确定性**，则可能出现 û 改善而 u* 恶化：R_perc 保持高位（因运动依旧丝滑）而 R_actual 下降，T 增大。形式化地，若 h 只依赖运动平滑而非状态信号，则 ∂T/∂S < 0（更平滑→更过度信任），代理目标与真实体验方向相反。**结论：只用 jerk/延迟做 UX 奖励会精确制造「平滑剧场」；TCG+HIU 是把 u* 拉回 u 的必要约束，而非可选项。**∎

## 7. 已知风险

**一句话**：UX 目标（平滑、响应、看起来自信）与安全目标在平均情况下常反向；POISE 用代理指标（jerk/延迟）优化体验，可能退化为「平滑剧场」——把降级藏进丝滑运动里，诱导人类过度信任与自动化自满、延迟接管，同时 IMO 依赖动力学模型与 IMU，其漂移/振动混叠/模型误差会误判 F/T 故障或漏检，使「惯性目睹者」本身不可靠；**最大风险是用可感知的平滑掩盖不可感知的失效，把「用户体验」反转为安全抑制与过度信任的放大器（A88–A91 共同依赖隐藏假设）。**

**次级风险与缓解**：
1. **代理指标 ≠ 真实体验（Goodhart）**：jerk/延迟可被优化却与人感受脱节；缓解：以 E231 校准客观-主观映射，UXM 同时纳入生理/行为证据，体验契约用分位而非均值，TCG+HIU 交叉约束。
2. **IMO 低力段失效**：σ_n 主导时 IMO 无法分辨 F/T 小偏置；缓解：仅在三方残差超噪时归因，低力段退回 F/T 并用重力参考去偏；对 <2σ 故障标 `unattributable` 而非乱归因。
3. **过度信任 / 自动化自满**：平滑+高表现诱发人类放弃监督；缓解：TCG 强制表达降级、E240 专测、把「接管及时性」写进体验契约 L。
4. **行为改变人类（反向因果）**：机器人的平滑会改变人的动作，使 HIU 训练分布漂移；缓解：在线自适应 + 记录行为漂移、定期重标。
5. **表达税与烦扰**：过度解释降低 UX 且致告警疲劳；缓解：定理 8 的最优粒度、按情境分级表达、用户可调阈值。
6. **IMU 振动混叠**：高频机械振动折叠进低频，被误读为「运动平滑」或假性外力；缓解：抗混叠前置滤波、多 IMU 一致性、E238 专项。
7. **安全与体验的实时预算竞争**：SGC/IBB 争抢主线程；缓解：IMU 独立高频线程、SGC 用 min-jerk 闭式基 + 小 QP、必要时降级 OLP-P 为缓存模式。
8. **信任校准的两难**：完全透明的表达会摧毁流畅体验，不透明则诱发过度信任；缓解：把 ε_t 作为显式设计参数，由风险等级自适应（高风险任务更透明）。
