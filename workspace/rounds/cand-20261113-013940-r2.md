# 第 64 轮（承接第 63 轮「LIRO 几何-技能-干扰联合闭环」IP-193~203；灵感循环 II 第 3 轮；本轮灵感：「消融实验」×「专利布局」）

> 第 63 轮 LIRO 用 LSF 补稠密几何、用 USL/CSP 补技能抽象、用 DIR/AIC 补四类干扰，并把实时路径压进 ≤2ms。但它对自身组件的态度仍是**「先验相信」而非「经验测量」**，由此暴露两个结构性盲点：
> 1. **贡献从未被测量**：ROSE→LIRO 已累积十余个模块（LSF、USL/CSP、DIR、AIC、SSB、OLP-Geo、WCV-Geo、Shield-Skill、OCB-Skill）。每个模块的「有用性」都是构造时假定的，系统没有任何在线机制回答「此刻哪个模块真的在贡献成功/安全？哪个模块在帮倒忙？」。第 63 轮自述的最大风险正是**几何幻觉**：LSF 在 OOD 几何上输出错误却自信的 g，而系统没有任何探针能发现「去掉 LSF 反而更安全」。
> 2. **能力没有布局**：USL 的技能是**事后堆叠**的，模块之间**功能重叠**（多个模块都在修正 φ̂）、**覆盖空白**（长尾任务无人覆盖）都不可见；更没有任何「若某组件被移除/失效，谁兜底」的结构性保证。第 63 轮的降级只写了「LSF 失效→零几何」，但**降级后是否仍然安全、是否仍有覆盖，从未被证明**。
>
> 本轮的两个灵感恰好构成一对**估值—结构**对偶：**「消融实验」= 给每个能力声明估值（value）**，**「专利布局」= 给能力集合定结构（coverage / dependency / defensive）**。二者合流，把「模块堆叠」升级为**可测量、可裁剪、可认证的能力组合**。

## 0. 直觉与动机

**灵感 1（消融实验 → ACA：Ablation-based Contribution Attribution 运行时消融归因）**
直觉：消融实验在论文里通常是一次性的「事后辩护」——删掉某模块看指标掉多少。**关键反转**：把消融从「离线评审工具」变成「在线感知器官」。在语义流里维护一个**反事实重放缓存**（缓存最近若干步的 x'、φ̂、r、τ、θ 与观测），每个语义步用很小的预算**禁用/降级一个模块子集 S 并重放**，得到 v(S) = α·任务进度 + β·安全裕度 ρ − γ·算力代价。用 **Monte Carlo 置换采样估计每个模块的 Shapley 值 φ_i**：φ_i 就是模块 i 对当前场景的**边际贡献**，且满足效率性 Σφ_i = v(M) − v(∅)。
**关键洞见**：消融不只是评价，而是**因果探针**。若某模块 φ_i < 0（去掉它反而更好），它就是**负贡献模块**——第 63 轮最怕的「几何幻觉」会在这里**自动现形**：LSF 幻觉越自信，去掉它后 ρ 与成功率反而上升，φ_LSF 越负。于是「消融实验」从实验章节升级为**安全机制**：**负贡献隔离**。

**灵感 2（专利布局 → CSC：Claim-Scope Coverage 能力声明组合）**
直觉：专利布局不是「专利越多越好」，而是一组有**独立权利要求（核心）/从属权利要求（特化）/防御性公开（兜底）**结构的**声明组合**：每份声明覆盖一片技术空间，声明之间有**覆盖（coverage）**、**重叠（overlap）**、**新颖性（novelty vs prior art）**、**自由实施 FTO（freedom-to-operate）**，以及刻意留出的**空白（white space）**。
**关键映射**：LIRO 的每个模块/技能就是一条**能力声明 c_i**，其 `scope_i` 是它在「任务类型 × 物体 × 几何域 × 干扰域」描述空间 𝒮 上真正适用的区域。于是可以定义组合的**加权覆盖 Cov(P)**、**冗余重叠 O(P)**、**相对 ROSE 基线的新颖度 N(P)** 与**空白 W**。组合优化在算力预算与 FTO（实时性/接口/安全优先级）约束下最大化「覆盖−冗余」。**空白区域 = 该申请的专利还没申请** → 触发定向技能获取（演示/探索），把「USL 覆盖不全」从被动 bug 变成**主动 filing**。防御性公开 = 永久保留的兜底声明（ROSE 基线技能），保证任何裁剪都不至于无能力可用。

**灵感 3（双灵感合流 → CAPO：Contribution-Attributed Portfolio Operations 贡献归因组合操作）**
三者咬合：**消融给出估值的「真金白银」**（φ_i 是实测边际贡献，不是主观权重），**专利布局给出组合的「结构骨架」**（覆盖/依赖/兜底/空白）。闭环：反事实重放 → Shapley 归因 → 更新每条能力声明的 evidence 与 scope → 组合优化（覆盖−冗余，预算/FTO 约束）→ 贡献路由（激活正贡献、隔离负贡献、保留承重集）→ 消融安全认证（任何单模块移除仍安全）→ 空白检测触发新技能 filing → 执行反馈进入重放缓存。**LIRO 是「组件都在」，CAPO 是「知道谁在起作用、谁该被裁、裁了谁兜底、哪里还缺」**。

**灵感 4（LIRO 组件的原位升级）**
- **OCB-Skill → OCB-Portfolio**：臂空间从「USL 模式 × MEL 模式」扩为「**活跃组合子集** × **消融调度** × USL 模式 × MEL 模式」；奖励显式扣除消融开销并加上实测贡献 Σφ_i。
- **AIC → AIC-Ablate**：认证从「干扰鲁棒」扩为**二维证书**：ρ_dir（扰动轴）× ρ_abl（组件移除轴）。任一轴为负则证书无效。
- **SSB → SSB-Claim**：场景签名追加 `claim_cov`（该场景被哪些声明覆盖）与 `white_space` 标记；Mine 优先把「空白场景」提升为新声明候选。
- **USL → USL-Claim**：技能库组织为**声明树**（独立声明=核心原语，从属声明=参数化特化）；新增技能必须声明 `scope` 并通过覆盖增益检验，防止无意义堆叠。
- **DIR → DIR-Attrib**：nuisance 维度用于**分层归因**——φ_i 按干扰域条件化（φ_i | η），避免「平均贡献」掩盖某干扰下的负贡献。
- **OLP-Geo / WCV-Geo / Shield-Skill**：接口不变；Shield-Skill 增加「承重集不可投影掉」的硬约束。

**灵感 5（研究本身的专利布局，元层面）**
本轮产物同时给出一份**权利要求树 + FTO/prior-art 对照**（产物区 §8）：把「运行时消融归因」「负贡献隔离」「覆盖驱动技能生长」「消融安全证书」拆成独立/从属权利要求，并显式标注与 SHAP/leave-one-out、MoE gating、submodular facility location、graceful degradation 等 prior art 的差异，避免把已公开的通用思想当创新点。**专利布局不只是灵感，也是本轮创新的自我审查工具**。

## 1. 形式化定义（增量：定义 201–216）

- **定义 201（CAPO 闭环）**：CAPO = (LIRO, ACA, ABA, CBR, CSC, WSD, AFO, PCC, OCB-P, CRC, J_capo)。定位：LIRO 的「消融归因 × 能力声明组合」元层；**不改变任何物理接口与实时契约**，只决定「哪些组件以何种粒度被激活/隔离，以及组合覆盖是否充分」。
- **定义 202（能力声明 Claim）**：c_i = (id, scope_i, deps_i, fallback_i, cost_i, evidence_i, kind_i)。kind_i ∈ {independent, dependent, defensive}；scope_i ⊆ 𝒮 为可测的场景描述子集（任务族 × 物体类 × 几何域 × 干扰域）；deps_i 为依赖的父声明；fallback_i 为移除 c_i 时的兜底声明；evidence_i 为 ACA 维护的贡献证据（φ_i 的滑动统计）。
- **定义 203（组合覆盖与冗余）**：设部署分布 w(s) 定义在 𝒮 上。加权覆盖 Cov(P) = ∫_𝒮 w(s)·[1 − exp(−Σ_{c_i∈P} 1[s∈scope_i])] ds（对重叠有递减回报，天然惩罚冗余且保持子模性）；冗余 O(P) = Σ_{i<j} ∫ w(s)·1[s∈scope_i∩scope_j] ds（仅诊断用）；空白 W(P) = ∫ w(s)·1[Σ_i 1[s∈scope_i]=0] ds。
- **定义 204（反事实消融算子 Abl）**：Abl(M, S; ξ) = 以缓存语义快照 ξ = (x', φ̂, r, τ, θ, O) 为输入，把模块子集 S 禁用或替换为 fallback，重放 LIRO 语义/首技能展开，输出 (progress, ρ, cost)。重放保真度 δ_replay = sup_{S∈𝒮_abl} |v_replay(S) − v_real(S)|。
- **定义 205（Shapley 贡献归因 ACA）**：价值 v(S) = α·progress(S) + β·ρ(S) − γ·cost(S)。模块 i 的贡献
  φ_i(v) = Σ_{S⊆M\{i}} [|S|!(|M|−|S|−1)!/|M|!]·[v(S∪{i}) − v(S)]。
  用 m_perm 个随机置换的边际均值估计 φ̂_i；效率性 Σφ̂_i = v(M) − v(∅)（在估计误差内成立）。
- **定义 206（消融预算分配 ABA）**：每语义步消融预算 B_abl（默认 8 次重放）。把「下一个消融子集」视为臂，奖励 = 该子集对降低最不确定/最承重模块 φ 估计方差的贡献；用 UCB/连续减半优先消融**高影响 × 高方差**模块（安全关键模块先消融），把预算花在「最可能翻转决策」的消融上。
- **定义 207（贡献路由 CBR）**：给定 φ̂ 与预算 B，求活跃集 A_t = argmax_{A⊆M} Σ_{i∈A} φ̂_i s.t. Σ_{i∈A} cost_i ≤ B，L_t ⊆ A_t（承重集必须在），deps 闭包成立，防御声明恒可用。若 φ̂_i < −ε_neg 且 i ∉ L_t，则**隔离** i（置为 fallback）；若 i ∈ L_t 却 φ̂_i < −ε_neg，触发**承重冲突**并强制保守兜底。
- **定义 208（组合优化 CSC）**：P* = argmax_{P⊆𝒞} Cov(P) + λ_N·N(P) − λ_C·Σ_{i∈P} cost_i，s.t. 预算 ≤ B、FTO 可行、D ⊆ P（防御声明集必须保留）、依赖闭包。N(P) = Σ_{i∈P} (1 − max_{c'∈Prior} sim(scope_i, scope_{c'})) 为相对 prior art 的新颖度（模块化）。Cov 单调子模 ⇒ 贪心 (1−1/e)。
- **定义 209（空白驱动技能获取 WSD）**：若 W(P) 在部署分布下的质量 W_dep = ∫ w(s)·1[空白] ds ≥ δ_ws，则在空白区域采样演示/探索，学习新技能 σ_new 并**申报新声明** c_new（含 scope、依赖、兜底），仅当 Cov(P∪{c_new}) − Cov(P) ≥ δ_cov 才纳入 USL-Claim。
- **定义 210（消融安全 AFO）**：ρ_abl = min_{i∈M} ρ(Abl(M, {i}; ξ))（单模块移除下的最小安全裕度）；承重集 L = {i: v(M) − v(M\{i}) ≥ δ_L}；关键集 K = {i: ρ(Abl(M,{i})) < 0}。要求 K = ∅ 才能认证；否则强制把关键模块的 fallback 纳入防御声明并重新认证。
- **定义 211（贡献证书 J_capo）**：J_capo = (J_liro, φ̂, L, K, Cov, O, W_dep, ρ_abl, δ_replay, portfolio_hash, aba_ver, attribution_budget)。Valid(J_capo) ⇔ Valid(J_liro) ∧ ρ_abl ≥ 0 ∧ K = ∅ ∧ Cov(P) ≥ 1−α_cov ∧ 所有活跃 i 满足 φ̂_i ≥ −ε_neg ∧ δ_replay ≤ δ_max。
- **定义 212（OCB-Portfolio 预算老虎机）**：臂 = {活跃组合子集策略: {full, greedy, load_bearing_only, cached, frozen}} × {消融调度: {none, uniform, aba}} × {USL 模式} × {MEL 模式}，K 聚合为 24。奖励 r_t = progress_t + λ_φ·Σ_{i∈A_t} φ̂_i − κ·(compute_t + c_abl·n_abl) − κ_s·switch_penalty。
- **定义 213（反事实重放缓存 CRC）**：环形缓存最近 K_c 个语义快照 ξ_j；每个快照含 x'_j, φ̂_j, r_j, τ_j, θ_j, O_j 与执行结果。消融只读缓存、不写实时路径；缓存命中率不足时按 staleness 加权降级归因置信度。
- **定义 214（声明树与 FTO）**：声明图 𝒢_c = (𝒞, E_dep ∪ E_conflict)。E_dep 为从属依赖；E_conflict 为互斥（同一 scope 上两个声明给出冲突兜底）。FTO 约束 = 实时预算（Σcost ≤ B_rt）、接口兼容、安全优先级（Shield 不得被声明裁剪）。声明树支持「阻断分析」：移除某声明是否使依赖它的声明失效。
- **定义 215（贡献非平稳与漂移检测）**：φ_i(t) 随场景漂移；维护指数遗忘均值 φ̄_i 与滑动方差，使用 CUSUM/变化点检测判定「贡献制度切换」。漂移后归因窗口重置，动态 Shapley 遗憾按分段平稳界处理。
- **定义 216（负贡献隔离的因果条件）**：若在窗口 [t−W, t] 内 φ̂_i ≤ −ε_neg 且重放保真度 δ_replay ≤ δ_max，则隔离 i 的**可证收益**下界为 W·(ε_neg − 2δ_replay)。该条件把「去掉它更好」从相关性升级为**有误差界的反事实结论**。

## 2. 关键算法骨架（完整伪代码见产物区）

xi = crc.push(x_prime, phi_hat, r, tau, theta, O)

phi_hat, phi_var = aca.attribute(M, xi, budget=B_abl, m_perm=32)

A_t = cbr.route(phi_hat, costs, L_t, B_compute)

rho_abl, K = afo.certify(M, xi, n_abl=B_abl)

J_capo = build_j_capo(J_liro, phi_hat, L_t, K, Cov(P_star), rho_abl, ...)

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 5（Shapley 估计误差）**：对 m_perm 个随机置换，φ̂_i 的估计误差满足 P(|φ̂_i − φ_i| ≥ ε) ≤ 2exp(−2m_perm ε²/Δ_v²)，Δ_v 为 v 的值域；取 m_perm=32、Δ_v=1 时 ε=0.25 的置信度 > 99%。**贡献估计有显式误差条，不是拍脑袋权重**。
- **引理 6（重放保真下的隔离收益）**：若 δ_replay ≤ δ_max 且窗口内 φ_i ≤ −ε_neg，则隔离 i 的真实累积收益 ≥ W·(ε_neg − 2δ_replay)。**「负贡献隔离」可证不劣，且能直接捕获 LSF 几何幻觉**。
- **引理 7（消融安全传递）**：若 J_liro 有效、ρ_abl ≥ 0、且 ρ 对重放误差 Lipschitz（常数 L_ρ），则任何单模块真实失效下系统安全裕度 ≥ ρ_abl − L_ρ·δ_replay。**从「假定不失效」升级为「单点失效可认证」**。
- **定理 4（组合覆盖的贪心近似）**：Cov(P) 在 𝒮 上单调子模，故贪心组合满足 Cov(P_greedy) ≥ (1−1/e)·Cov(P*)。**「专利布局」的覆盖最大化有近似保证，且天然抑制冗余**。
- **定理 5（CAPO 端到端）**：若 J_capo 有效，则系统同时满足：(i) LIRO 的干扰鲁棒性；(ii) 任一单模块失效下安全裕度 ≥ ρ_abl − L_ρδ_replay；(iii) 对部署分布的覆盖 ≥ 1−α_cov；(iv) 活跃模块无负贡献（φ̂_i ≥ −ε_neg）。**四条保证分别对应「扰动、失效、覆盖、贡献」四个正交轴**。
- **命题（消融开销可控）**：消融只在语义流、只读缓存，单步开销 ≈ B_abl × (首技能展开 + margin 评估) < 15ms；实时路径零新增、零学习写操作。**「消融实验」不进入 1–10kHz 控制回路**。

## 5. 本轮最大风险

**一句话**：若反事实重放的分布偏移（下游模块在消融后改变行为、缓存快照过时）使 Shapley 估计**系统性有偏**，则「消融归因」会退化为**「归因幻觉」**——系统可能误隔离真正承重的模块（如把在特定几何域唯一可靠的 LSF 裁掉），或把有害模块误判为无害，最终让「可测量的组合」变成**对当前场景过拟合的、自信错误的裁剪**；这是本轮所有估值—裁剪—认证论证共同依赖的单点假设（δ_replay 与因果无混杂）。

## 2. 形式化定义（完整版）

**定义 201（CAPO 闭环）** CAPO 是 LIRO 的「消融归因 × 能力声明组合」元层：`CAPO = (LIRO, ACA, ABA, CBR, CSC, WSD, AFO, PCC, OCB-P, CRC, J_capo)`。不变式：**所有消融重放、Shapley 估计、组合优化、技能申报、消融安全认证只发生在语义流/低频线程；实时路径（1–10kHz）只读取已确定的活跃集 A_t 与路由表，零新增学习写操作、零消融重放**。CAPO 不改变任何物理接口；它只回答三个问题：此刻谁在贡献（ACA/CBR）、组合是否覆盖部署（CSC/WSD）、裁掉谁还安全（AFO）。

**定义 202（能力声明 Claim）** `c_i = (id, scope_i, deps_i, fallback_i, cost_i, evidence_i, kind_i)`：
- `scope_i ⊆ 𝒮`：可测的场景描述子集。`𝒮 = 任务族 × 物体类 × 几何域 × 干扰域`，每个维度离散化并可计算隶属（如几何域={平面/曲面/透明/镜面/拓扑异常}，干扰域={干净/LiDAR退化/执行器扰动/对抗/OOD}）。
- `deps_i`：父声明集合；从属声明只有在父声明活跃时才可活跃。
- `fallback_i`：移除 c_i 时的兜底声明（通常是 ROSE 基线的 `safe_idle`/保守阻抗/零几何 LSF）。
- `cost_i`：运行/消融代价（算力/时延）。
- `evidence_i`：ACA 维护的贡献证据（φ_i 的指数遗忘均值、方差、最近更新版本）。
- `kind_i`：独立（核心原语，如 USL 的 reach/grasp/push）、从属（特化，如 grasp_soft、grasp_glass）、防御（永久保留的兜底，如 safe_idle、K_BASELINE）。
- 约束：`scope_i` 必须可由场景签名计算；未声明 scope 的模块不得进入组合（防止「黑盒贡献」）。

**定义 203（组合覆盖与冗余）** 设部署分布 w(s) 定义在 𝒮 上（由任务采样先验 + 近期部署直方图混合，w = (1−β)w_prior + βw_recent）。
- 加权覆盖 `Cov(P) = ∫_𝒮 w(s)·[1 − exp(−Σ_{c_i∈P} 1[s∈scope_i])] ds`。选择指数饱和而非硬并集：同一场景被 k 个声明覆盖时边际价值递减，**天然惩罚冗余且保持单调子模**。
- 冗余 `O(P) = Σ_{i<j} ∫ w(s)·1[s∈scope_i∩scope_j] ds`（仅诊断，不直接进目标，避免破坏子模性）。
- 空白 `W(P) = ∫_𝒮 w(s)·1[Σ_i 1[s∈scope_i]=0] ds`。
- 离散近似：从 w 采样 N_cov=512 个场景点，`Cov ≈ (1/N)Σ_j [1−exp(−Σ_i 1[s_j∈scope_i])]`，误差 O(1/√N)。

**定义 204（反事实消融算子 Abl）** `Abl(M, S; ξ) = (progress, ρ, cost)`：以缓存快照 `ξ=(x', φ̂, r, τ, θ, O, result)` 为输入，把模块子集 S 禁用（或替换为 `fallback_i`），重放：
1. 语义决策链（LSF 融合 → MEL 推理 → CSP 规划 → Shield → OCB 选择）；
2. 首技能 π_σ1 展开；
3. 在球 B(φ̂,r) 上评估安全裕度 ρ 与执行损失。
不执行真实运动。`v(S) = α·progress(S) + β·ρ(S) − γ·cost(S)`，默认 α=1.0、β=2.0（安全权重高于进度）、γ=0.1。`δ_replay = sup_{S∈𝒮_abl} |v_replay(S) − v_real(S)|` 由周期性「真实验证批次」估计（每 N_v=200 步抽 5 个快照做真实短程执行）。

**定义 205（Shapley 贡献归因 ACA）** 模块全集 M（|M|≈10）。Shapley 值
`φ_i(v) = Σ_{S⊆M\{i}} [|S|!(|M|−|S|−1)!/|M|!]·[v(S∪{i}) − v(S)]`。
估计器：采样 m_perm=32 个随机置换 π，`φ̂_i = (1/m_perm)Σ_π [v(Pre_i(π)∪{i}) − v(Pre_i(π))]`，其中 Pre_i(π) 为 π 中 i 之前的模块集。同时维护 `φ̄_i = EMA(φ̂_i, λ_forget=0.9)` 与滑动方差 σ²_i。效率性校验：`|Σφ̂_i − (v(M)−v(∅))| ≤ 3·sqrt(Σσ²_i/m_perm)`，否则标记 `attribution_unstable`。

**定义 206（消融预算分配 ABA）** 每语义步预算 B_abl=8 次重放（可动态 4–32）。把候选消融子集视为臂；优先函数
`score(S) = impact(S) · sqrt(var_est(S)) / cost(S)`，
其中 `impact(S)` 为该子集涉及模块的 |φ̄_i| 之和，`var_est(S)` 为当前估计方差。先用连续减半（successive halving）在候选子集上粗筛，再用 UCB 精算 Top-2 子集；安全关键模块（kind=independent 且进入 K 候选）强制纳入首轮消融。预算耗尽即返回当前 φ̂ 与置信区间，**归因可随时中断（anytime）**。

**定义 207（贡献路由 CBR）** 给定 φ̂ 与算力预算 B_compute，解 0-1 背包：
`A_t = argmax_{A⊆M} Σ_{i∈A} φ̄_i`，s.t. `Σ_{i∈A} cost_i ≤ B_compute`、`L_t ⊆ A_t`、`deps` 闭包成立、防御声明恒在。
路由规则：
- `φ̄_i ≥ ε_pos` → 激活（full）；
- `|φ̄_i| < ε_pos` → 按 cost 贪心裁剪（先裁 cost 高且贡献近零者）；
- `φ̄_i ≤ −ε_neg` 且 `i ∉ L_t` → **隔离**（替换为 fallback_i），写入 `quarantine_log`；
- `φ̄_i ≤ −ε_neg` 且 `i ∈ L_t` → **承重冲突**：不静默隔离，强制保守兜底（Shield 最严约束）并标记 `load_bearing_conflict`，交由 OCB-P 降档。
默认 ε_pos=0.02、ε_neg=0.05（归一化价值单位）。背包用「按 φ̄_i/cost_i 排序 + 承重集预置」的贪心，O(|M|log|M|)。

**定义 208（组合优化 CSC）** 能力声明集 𝒞。`P* = argmax_{P⊆𝒞} Cov(P) + λ_N·N(P) − λ_C·Σ_{i∈P}cost_i`，约束：`Σcost ≤ B`、FTO 可行（定义 214）、`D ⊆ P`（防御声明集）、依赖闭包。`N(P) = Σ_{i∈P} n_i`，`n_i = 1 − max_{c'∈Prior} sim(scope_i, scope_{c'})` 为相对 prior art 的新颖度，sim 为 scope 的 Jaccard/描述子相似度。求解：Cov 单调子模、N 模块化、cost 模块化 ⇒ 目标子模；贪心按 `ΔCov_i + λ_N n_i − λ_C cost_i` 选入，直到预算用尽。默认 λ_N=0.1、λ_C=0.05。

**定义 209（空白驱动技能获取 WSD）** 若 `W_dep(P) = ∫ w(s)·1[空白] ds ≥ δ_ws`（δ_ws=0.15），在空白区域：
1. 采样 K_ws=20 个空白场景，生成探索/演示请求；
2. 从演示 + RL 蒸馏学习新技能 σ_new（复用第 63 轮技能蒸馏管线）；
3. **申报新声明** c_new = (scope=空白区域核密度估计, deps=父技能, fallback=最近邻技能, cost, evidence=空)；
4. 覆盖增益检验：若 `Cov(P∪{c_new}) − Cov(P) ≥ δ_cov`（δ_cov=0.01），纳入 USL-Claim；否则只作为 defensive 声明（防止「为创新而创新」的无效堆叠）。
WSD 把「USL 覆盖不全」从被动 bug 转为**主动 filing**，并用覆盖增益做**新颖性门槛**。

**定义 210（消融安全 AFO）** 
- `ρ_abl = min_{i∈M} ρ(Abl(M, {i}; ξ))`：逐个单模块移除，取最小安全裕度；
- 承重集 `L = {i: v(M) − v(M\{i}) ≥ δ_L}`（δ_L=0.05）；
- 关键集 `K = {i: ρ(Abl(M,{i})) < 0}`；
- 若 K ≠ ∅：把 K 中每个模块的 fallback 提升为防御声明并纳入 D，再对「模块 + fallback」联合重认证；若仍 K ≠ ∅，`J_capo` 显式无效并降级为 ROSE 基线。
- 双模块移除作为次级诊断（可选，预算允许时）：`ρ_abl2 = min_{i<j} ρ(Abl(M,{i,j}))`，用于发现「单独移除安全、组合移除危险」的共依赖对。

**定义 211（贡献证书 J_capo）** `J_capo = (J_liro, φ̂, L, K, Cov, O, W_dep, ρ_abl, δ_replay, portfolio_hash, aba_ver, attribution_budget)`。
`Valid(J_capo) ⇔ Valid(J_liro) ∧ ρ_abl ≥ 0 ∧ K = ∅ ∧ Cov(P*) ≥ 1−α_cov ∧ (∀i∈A_t: φ̄_i ≥ −ε_neg) ∧ δ_replay ≤ δ_max`（α_cov=0.05、δ_max=0.05）。
审计链：`aba_ver` 追溯消融预算/采样版本；`portfolio_hash` 追溯活跃声明集；`φ̂` 追溯贡献估计；`δ_replay` 追溯重放保真度。

**定义 212（OCB-Portfolio 预算老虎机）** 臂空间 = `{组合策略: {full, greedy, load_bearing_only, cached, frozen}} × {消融调度: {none, uniform, aba}} × {USL模式: {full_seq, single_skill, cached}} × {MEL模式: {full, distill, cached}}`，K=5×3×3×3=135，聚合为 K=24（每组取代表臂）。
奖励 `r_t = progress_t + λ_φ·Σ_{i∈A_t} φ̄_i − κ·(compute_t + c_abl·n_abl) − κ_s·switch_penalty`，归一化 [0,1]；EXP3 更新。硬规则：消融调度 `none` 时不得声称 φ 新鲜；`frozen` 组合不得进入 `Valid(J_capo)` 的「活跃贡献」断言。

**定义 213（反事实重放缓存 CRC）** 环形缓存容量 K_c=64。每项 `ξ_j = (x'_j, φ̂_j, r_j, τ_j, θ_j, O_j, result_j, t_j)`。消融只读；缓存条目按 staleness `Δ_j = t − t_j` 加权：`w_replay(ξ_j) = exp(−Δ_j/τ_c)`（τ_c=50 步）。命中率 < 50% 时，φ̂ 置信度按 `sqrt(hit_rate)` 缩放，并在 J_capo 标记 `replay_low_coverage`。CRC 保证消融不触碰实时路径，也不产生真实动作。

**定义 214（声明树与 FTO）** 声明图 `𝒢_c = (𝒞, E_dep ∪ E_conflict)`：
- `E_dep`：从属声明 → 父声明；活跃集必须依赖闭包。
- `E_conflict`：同一 scope 上两个声明给出互斥兜底（如「激进阻抗」与「保守兜底」不可同时活跃），冲突边要求至少一侧降级。
- **FTO 约束**：① 实时预算 `Σ_{i∈A_t} cost_i ≤ B_rt`；② 接口兼容（不得要求 LIRO 未提供的信号）；③ 安全优先级（Shield 约束不得被任何声明裁剪）；④ 计算资源许可（继承 PCE+++++ 硬降级）。
- **阻断分析**：移除声明 c_i 是否使依赖它的声明失效？定义 `block(i) = |{j: i ∈ deps_j 且 c_j 无其他父}|`；高阻断声明自动进入防御集 D。
- **新颖度**：`n_i = 1 − max_{c'∈Prior} sim(scope_i, scope_{c'})`；Prior = ROSE/LIRO 已有模块与公开基线。

**定义 215（贡献非平稳与漂移检测）** φ_i(t) 随场景漂移。维护 `φ̄_i(t) = (1−λ)φ̄_i(t−1) + λφ̂_i(t)` 与滑动方差 σ²_i(t)。CUSUM 统计量 `g_i(t) = max(0, g_i(t−1) + (φ̂_i(t) − φ̄_i(t−1)) − ν)`；`g_i(t) > h` 判定贡献制度切换，重置该模块归因窗口并把 `evidence_i` 标记 stale。动态 Shapley 遗憾按分段平稳界 `O(√(T(1+S_T)))` 处理（S_T 为切换次数）。

**定义 216（负贡献隔离的因果条件）** 若在窗口 [t−W, t] 内 `φ̂_i ≤ −ε_neg` 且 `δ_replay ≤ δ_max`，则隔离 i 的**可证收益**下界为 `W·(ε_neg − 2δ_replay)`。证明要点：由重放保真度，真实边际贡献 `v_real(M)−v_real(M\{i}) ≤ v_replay(M)−v_replay(M\{i}) + 2δ_replay`；窗口内 Shapley 边际均值 ≤ −ε_neg ⇒ 每步隔离收益 ≥ ε_neg − 2δ_replay，累加得下界。该条件把「去掉它更好」从相关性升级为**有误差界的反事实结论**。

### IP-212 CRC（反事实重放缓存）

```python
class CounterfactualReplayCache:
    """语义快照环形缓存。消融只读，不写实时路径。"""
    def __init__(self, capacity=64, tau_c=50.0):
        self.buf = collections.deque(maxlen=capacity)
        self.tau_c = tau_c
        self.t = 0

    def push(self, x_prime, phi_hat, r, tau, theta, O, result):
        self.t += 1
        self.buf.append(dict(x=x_prime, phi=phi_hat, r=r, tau=tau,
                             theta=theta, O=O, result=result, t=self.t))

    def sample(self, k, rng=None):
        if not self.buf:
            return []
        rng = rng or np.random
        items = list(self.buf)
        w = np.array([np.exp(-(self.t - it['t']) / self.tau_c) for it in items])
        w = w / w.sum()
        idx = rng.choice(len(items), size=min(k, len(items)), replace=False, p=w)
        return [items[i] for i in idx]

    def hit_rate(self, window=32):
        recent = [it for it in self.buf if self.t - it['t'] <= window]
        return len(recent) / max(1, min(window, self.buf.maxlen))
```

### IP-204 ACA（运行时消融归因）

```python
class AblationContributionAttributor:
    """Monte Carlo 置换 Shapley。只读 CRC，重放语义链，不执行真实动作。"""
    def __init__(self, modules, m_perm=32, alpha=1.0, beta=2.0, gamma=0.1,
                 lambda_forget=0.9, eps_neg=0.05):
        self.modules = list(modules)          # ['lsf','csp','dir','aic','ssb','olp','wcv','shield','ocb']
        self.m_perm, self.alpha, self.beta, self.gamma = m_perm, alpha, beta, gamma
        self.lam, self.eps_neg = lambda_forget, eps_neg
        self.phi_bar = {m: 0.0 for m in self.modules}
        self.phi_var = {m: 1.0 for m in self.modules}

    def value(self, S, xi):
        progress, rho, cost = self._replay(self.modules, set(S), xi)   # 定义 204
        return self.alpha * progress + self.beta * rho - self.gamma * cost

    def _replay(self, modules, disabled, xi):
        # 语义链重放：disabled 中的模块用 fallback 替换
        # 返回 (progress, rho, cost)，不调用真实执行器
        state = replay_semantic_pipeline(modules, disabled, xi)
        return state.progress, state.rho, state.cost

    def attribute(self, xi, budget, rng=None):
        rng = rng or np.random
        phi_samples = {m: [] for m in self.modules}
        n_eval = 0
        for _ in range(self.m_perm):
            if n_eval >= budget:
                break
            perm = list(rng.permutation(self.modules))
            prefix = []
            prev = self.value(prefix, xi)          # v(∅)
            for m in perm:
                cur = self.value(prefix + [m], xi)  # v(S∪{m})
                phi_samples[m].append(cur - prev)
                prev = cur
                prefix.append(m)
                n_eval += 1
                if n_eval >= budget:
                    break
        phi_hat, phi_var = {}, {}
        for m in self.modules:
            if phi_samples[m]:
                phi_hat[m] = float(np.mean(phi_samples[m]))
                phi_var[m] = float(np.var(phi_samples[m]) / len(phi_samples[m]))
            else:
                phi_hat[m], phi_var[m] = self.phi_bar[m], self.phi_var[m]
            self.phi_bar[m] = self.lam * self.phi_bar[m] + (1 - self.lam) * phi_hat[m]
            self.phi_var[m] = self.lam * self.phi_var[m] + (1 - self.lam) * phi_var[m]
        efficiency_gap = abs(sum(phi_hat.values()) -
                             (self.value(self.modules, xi) - self.value([], xi)))
        unstable = efficiency_gap > 3 * np.sqrt(sum(phi_var.values()) + 1e-9)
        return phi_hat, phi_var, unstable, n_eval
```

### IP-205 ABA（消融预算分配）

```python
class AblationBudgetAllocator:
    """连续减半 + UCB：把预算花在高影响×高方差模块上。"""
    def __init__(self, budget=8, n_candidates=16):
        self.budget, self.n_candidates = budget, n_candidates

    def plan(self, phi_bar, phi_var, critical_candidates=()):
        # 候选子集：单模块移除优先（安全语义最直接），其次随机二元子集
        cands = [frozenset([m]) for m in phi_bar]
        cands += [frozenset(rng.sample(list(phi_bar), 2))
                  for _ in range(max(0, self.n_candidates - len(cands)))]
        def score(S):
            impact = sum(abs(phi_bar[m]) for m in S)
            var = sum(phi_var[m] for m in S)
            return impact * np.sqrt(var + 1e-9)
        # 安全关键模块强制首轮
        forced = [frozenset([m]) for m in critical_candidates]
        cands = forced + [c for c in cands if c not in forced]
        # 连续减半：每轮保留 score 前一半，预算按轮分配
        schedule, remaining = [], self.budget
        while cands and remaining > 0:
            cands.sort(key=score, reverse=True)
            keep = cands[:max(1, len(cands) // 2)]
            per = max(1, remaining // max(1, len(keep)))
            schedule += [(c, per) for c in keep]
            remaining -= per * len(keep)
            cands = keep
        return schedule[:self.budget]
```

### IP-206 CBR（贡献路由与负贡献隔离）

```python
class ContributionRouter:
    """0-1 背包 + 承重集保留 + 负贡献隔离。"""
    def __init__(self, eps_pos=0.02, eps_neg=0.05):
        self.eps_pos, self.eps_neg = eps_pos, eps_neg

    def route(self, phi_bar, costs, load_bearing, deps_closure, budget,
              defensive=()):
        active = set(defensive) | set(load_bearing)
        # 依赖闭包
        for m in list(active):
            active |= deps_closure.get(m, set())
        # 候选按 贡献/代价 排序
        cands = [m for m in phi_bar if m not in active and phi_bar[m] > self.eps_pos]
        cands.sort(key=lambda m: phi_bar[m] / max(costs[m], 1e-6), reverse=True)
        used = sum(costs[m] for m in active)
        for m in cands:
            if used + costs[m] <= budget:
                active.add(m)
                used += costs[m]
        # 负贡献隔离
        quarantined = []
        for m in list(active):
            if phi_bar[m] <= -self.eps_neg and m not in load_bearing:
                active.discard(m)
                quarantined.append(m)
            elif phi_bar[m] <= -self.eps_neg and m in load_bearing:
                # 承重冲突：不静默隔离，强制保守兜底
                quarantined.append(('conflict', m))
        return active, quarantined, used
```

### IP-207 CSC（能力声明组合优化）

```python
class ClaimScopePortfolio:
    """子模覆盖 + 新颖度 − 代价；贪心 (1−1/e)。"""
    def __init__(self, lambda_N=0.1, lambda_C=0.05, n_cov=512):
        self.lambda_N, self.lambda_C, self.n_cov = lambda_N, lambda_C, n_cov

    def _cov(self, P, samples, w):
        cover = np.zeros(len(samples))
        for c in P:
            cover += np.array([1.0 if s in c.scope else 0.0 for s in samples])
        return float(np.sum(w * (1.0 - np.exp(-cover))) / np.sum(w))

    def optimize(self, claims, w_deploy, budget, defensive, fto_ok, prior):
        samples = sample_scenarios(w_deploy, self.n_cov)
        w = np.array([w_deploy(s) for s in samples]); w = w / w.sum()
        P, used = set(defensive), sum(c.cost for c in defensive)
        # 依赖闭包
        changed = True
        while changed:
            changed = False
            for c in list(P):
                for d in c.deps:
                    if d not in P and used + d.cost <= budget:
                        P.add(d); used += d.cost; changed = True
        while True:
            best, best_gain = None, 0.0
            for c in claims:
                if c in P or not fto_ok(c) or used + c.cost > budget:
                    continue
                if any(d not in P for d in c.deps):
                    continue
                gain = (self._cov(P | {c}, samples, w) - self._cov(P, samples, w)
                        + self.lambda_N * novelty(c, prior)
                        - self.lambda_C * c.cost)
                if gain > best_gain:
                    best, best_gain = c, gain
            if best is None:
                break
            P.add(best); used += best.cost
        return P, self._cov(P, samples, w), used
```

def ablation_safety_certify(modules, xi, rho_fn, v_fn, delta_L=0.05):
    """单模块移除 → ρ_abl / 承重集 L / 关键集 K。"""
    full_v = v_fn(modules, xi)
    rho_abl, L, K = float('inf'), set(), set()
    for m in modules:

        if rho_m < 0:

        D.add(c.fallback)          # 把兜底提升为防御声明
    return D

class ClaimPatentTree:
    """独立/从属/防御声明树 + 阻断分析 + FTO。"""
    def __init__(self, claims, prior):
        self.claims = {c.id: c for c in claims}
        self.prior = prior
        self.G = self._build_graph()

    def _build_graph(self):
        G = nx.DiGraph()
        for c in self.claims.values():
            G.add_node(c.id, claim=c)
            for d in c.deps:
                G.add_edge(d, c.id, kind='dep')
        for a in self.claims.values():
            for b in self.claims.values():
                if a.id < b.id and conflict(a.scope, b.scope):
                    G.add_edge(a.id, b.id, kind='conflict')
        return G

    def blocking(self, cid):
        return sum(1 for c in self.claims.values()
                   if cid in c.deps and len(c.deps) == 1)

    def novelty(self, cid):
        c = self.claims[cid]
        return 1.0 - max((scope_sim(c.scope, p.scope) for p in self.prior),
                         default=0.0)

    def fto_ok(self, cid, budget, used, rt_contract_ok):
        c = self.claims[cid]
        return (used + c.cost <= budget and rt_contract_ok(c)
                and c.kind != 'dependent' or all(d in self.claims for d in c.deps))

    def blocking_defensive_set(self, threshold=2):
        return {cid for cid in self.claims if self.blocking(cid) >= threshold}

## 4. 推导

**引理 5（Shapley 估计误差）** 设 `φ̂_i` 为 m_perm 个独立随机置换的边际均值，单次边际 `X_i^(π) = v(Pre_i(π)∪{i}) − v(Pre_i(π)) ∈ [−Δ_v, Δ_v]`，Δ_v 为 v 的值域。由 Hoeffding 不等式，
`P(|φ̂_i − E[X_i]| ≥ ε) ≤ 2exp(−2m_perm ε²/Δ_v²)`。
且随机置换边际的期望正是 Shapley 值（置换采样无偏），故 `E[φ̂_i] = φ_i`。取 m_perm=32、Δ_v=1，`P(误差 ≥ 0.25) ≤ 2exp(−4) ≈ 0.037`；用置信区间上界可在归因不稳定时拒绝决策。∎

**引理 6（重放保真下的负贡献隔离收益）** 设窗口 [t−W,t] 内每步 `φ_i(t) ≤ −ε_neg`，且 `δ_replay = sup_S |v_replay(S) − v_real(S)| ≤ δ_max`。对任意 S，
`v_real(S∪{i}) − v_real(S) ≤ v_replay(S∪{i}) − v_replay(S) + 2δ_replay`。
沿置换取期望，`φ_i^real ≤ φ_i^replay + 2δ_replay ≤ −ε_neg + 2δ_replay`。故每步「移除 i」相对「保留 i」的价值增益 ≥ ε_neg − 2δ_replay；W 步累积 ≥ W(ε_neg − 2δ_replay)。当 δ_max < ε_neg/2 时严格为正。∎

**引理 7（消融安全传递）** 设 `ρ(S)` 对价值/状态扰动 Lipschitz（常数 L_ρ），且 `|v_replay(S) − v_real(S)| ≤ δ_replay`。单模块真实失效 i 等价于真实系统在 `M\{i}` 上运行。`ρ_real(M\{i}) ≥ ρ_replay(M\{i}) − L_ρ·δ_replay ≥ ρ_abl − L_ρ·δ_replay`。若 ρ_abl ≥ 0，则真实安全裕度 ≥ −L_ρδ_replay；配合 AIC 的干扰裕度与 δ_max 阈值，可得非负安全裕度。∎

**定理 4（组合覆盖的贪心近似）** `Cov(P) = ∫ w(s)[1−exp(−Σ_i 1[s∈scope_i])]ds` 是覆盖函数的指数饱和版本，逐点单调且边际递减，故 Cov 单调子模；N 与 cost 模块化，目标 `Cov + λ_N N − λ_C cost` 仍单调子模。标准贪心在基数/背包约束下给出 `(1−1/e)` 近似（背包情形为 `(1−1/e)·OPT` 的常数因子近似）。因此 `Cov(P_greedy) ≥ (1−1/e)Cov(P*)`（忽略新颖度/代价项的加性扰动）。∎

**定理 5（CAPO 端到端保证）** 假设 J_capo 有效。则：
1. **扰动鲁棒**：J_liro 有效 ⇒ 四类干扰下 ρ_dir ≥ 0（第 63 轮定理 3）。
2. **单点失效安全**：K=∅ ∧ ρ_abl ≥ 0 ∧ δ_replay ≤ δ_max ⇒ 任一单模块移除后真实裕度 ≥ ρ_abl − L_ρδ_max（引理 7）。
3. **覆盖充分**：Cov(P*) ≥ 1−α_cov ⇒ 部署分布下至少 1−α_cov 质量的场景被至少一个活跃声明覆盖（由 Cov 定义与采样误差）。
4. **无负贡献**：活跃集 A_t 满足 φ̄_i ≥ −ε_neg ⇒ 不存在被证实的「帮倒忙」模块在运行（引理 6 的反向）。
四条保证正交：扰动（AIC）、失效（AFO）、覆盖（CSC）、贡献（CBR）。∎

**命题（消融开销可控）** 单步消融开销 ≈ n_abl × (语义链重放 + margin 评估) ≈ 8 × (0.5–1.5ms) < 15ms，仅语义流；实时路径新增仅一次活跃集查表（O(1)），**不进入 1–10kHz 控制回路，实时契约 ≤ 2ms 不变**。∎

**命题（负贡献隔离捕获几何幻觉）** 设 LSF 在 OOD 几何域产生幻觉 g，使 `progress` 下降或 `ρ` 下降。则由定义 205，`φ_LSF < 0`；若 |φ_LSF| > ε_neg 且 δ_replay 可忽略，由引理 6，隔离 LSF 严格改进价值；系统回退到第 63 轮 ROSE 的零几何路径（LSF fallback），并令 `J_capo` 标记 `geo_quarantined=True`。**第 63 轮的单点假设风险被转化为可检测、可恢复的运行时事件**。∎

**正确性定理（CAPO-Complete）** 假设第 63 轮 A61–A82 及：
- **(A83)** CRC 快照在窗口内可交换；重放保真度 `δ_replay ≤ δ_max < ε_neg/2`。
- **(A84)** 价值 v 有界（Δ_v < ∞），模块数 |M| ≤ 16，Shapley 值良定义。
- **(A85)** Cov 单调子模；部署分布 w 可由采样估计，估计误差 ≤ δ_w。
- **(A86)** 安全裕度 ρ 对重放/状态扰动 Lipschitz，常数 L_ρ < ∞。
- **(A87)** 声明 scope 可测、依赖闭包与冲突边可计算；prior-art 新颖度可估。
- **(A88)** 消融预算 B_abl 与组合预算 B、实时预算 B_rt 均被遵守。
- **(A89)** 贡献非平稳切换次数 S_T 有限；CUSUM 可检出制度切换。

则：
1. **贡献可测量**：`P(|φ̂_i − φ_i| ≥ ε) ≤ 2exp(−2m_perm ε²/Δ_v²)`，且效率性可校验（引理 5）。
2. **负贡献可隔离**：窗口内 φ_i ≤ −ε_neg 且 δ_replay ≤ δ_max ⇒ 隔离累积收益 ≥ W(ε_neg − 2δ_replay)（引理 6、定义 216）。
3. **失效可认证**：K=∅ ∧ ρ_abl ≥ 0 ⇒ 任一单模块失效下真实安全裕度 ≥ ρ_abl − L_ρδ_max（引理 7）。
4. **覆盖可布局**：贪心组合 `Cov(P_greedy) ≥ (1−1/e)Cov(P*)`（定理 4）。
5. **空白可申报**：W_dep ≥ δ_ws 触发技能获取，且仅当覆盖增益 ≥ δ_cov 才纳入（定义 209）。
6. **端到端四轴安全**：Valid(J_capo) ⇒ 扰动鲁棒 ∧ 单点失效安全 ∧ 覆盖充分 ∧ 无负贡献（定理 5）。

## 7. 已知风险

**一句话**：若反事实重放的分布偏移（下游模块在消融后改变行为、缓存快照过时、模块间存在未建模的共依赖）使 Shapley 估计**系统性有偏**，则「消融归因」会退化为**「归因幻觉」**——系统可能误隔离真正承重的模块（如在特定几何域唯一可靠的 LSF），或把有害模块误判为无害，最终让「可测量的组合」变成**对当前场景过拟合的、自信错误的裁剪**；这是本轮所有估值—裁剪—认证论证共同依赖的单点假设（A83/A89）。

**次级风险与缓解**：
1. **Shapley 组合爆炸**：|M| 增大时 2^|M| 不可行 → 置换采样 + 预算 anytime；模块分层（感知层/规划层/安全层）分组归因，组内精确、组间采样。
2. **重放过时/混杂**：缓存快照与真实执行分布偏移 → 周期性真实短程验证批次估计 δ_replay；δ_replay > δ_max 时禁用隔离决策（只观测不裁剪），并提高真实采样频率。
3. **共依赖失效**：单模块移除都安全、组合移除危险 → 预算允许时做双模块移除诊断 ρ_abl2；把高共依赖对写入声明冲突边 E_conflict，禁止同时裁剪。
4. **声明 scope 误设**：scope 过宽虚报覆盖、过窄漏报 → 用场景签名与真实成功/失败在线校准 scope（保形覆盖校准，α_cov=0.05），越界即收缩。
5. **新颖度被「刷分」**：为拿覆盖增益而堆叠无效技能 → δ_cov 门槛 + 真实任务成功率复验 + 覆盖增益必须在留出场景上复现。
6. **组合抖动**：每步重优化导致模块频繁切换 → 切换惩罚 + 组合版本冻结（cached 臂）+ 仅在贡献制度切换（CUSUM）时重优化。
7. **兜底声明陈旧**：防御性 fallback 长期不验证 → 每次 J_capo 认证强制对 D 中声明做一次消融重放；失败即降级并重新 filing。
8. **专利/FTO 判断主观**：prior-art 新颖度依赖检索质量 → 本轮 §8 明确标注为「设计期自我审查」，不进入运行时证书；运行时只用 scope/覆盖/贡献等可测项。

### 8.2 Prior art 与差异化（FTO）

| Prior art | 已有思想 | 本轮差异（可主张的差异化位置） |
|---|---|---|
| SHAP / leave-one-out / 特征消融 | 离线解释模型预测 | 我们把消融用于**运行时模块裁剪与安全隔离**，并与物理安全裕度 ρ、实时契约、证书绑定 |
| Mixture-of-Experts / learned gating | 学习路由器按输入分配专家 | 我们不用学习权重，而用**实测 Shapley 边际贡献**做路由；且显式处理负贡献与承重冲突 |
| Submodular facility location / sensor placement | 静态覆盖最大化 | 我们是**运行时能力声明组合**：scope 在线校准、空白驱动 filing、与 FTO/依赖/冲突边耦合 |
| Graceful degradation / fallback | 预定义降级路径 | 我们给出**单模块移除的可认证安全裕度**（ρ_abl、K、δ_replay 传递），而非「假定兜底安全」 |
| Runtime verification / shielding | 监控运行时属性 | 我们监控的是**组件贡献**（因果轴），与属性监控（AIC/Shield）正交并组合成二维证书 |
| 专利布局/组合管理 | 法律/商业层面的权利要求组合 | 我们把它**形式化为可计算的能力覆盖优化**，并用它反向约束技术路线（新颖度门槛、防御性公开） |

**FTO 结论（设计期）**：通用「Shapley 归因」「MoE 路由」「子模覆盖」「graceful degradation」均属已公开思想，**不应单独作为创新点主张**。可主张的差异化组合是：**运行时反事实消融 → 负贡献隔离 → 单模块失效可认证 → 覆盖驱动的能力申报 → 二维证书**这一整条闭环，且其每个环节都有可测的运行时产物（φ̂、ρ_abl、Cov、δ_replay）作为技术效果证据。

### 8.3 防御性公开（defensive publication）策略

- **公开**：「按消融贡献裁剪模块算力」这一通用机制（防止被他人用宽泛权利要求阻断后续工作）。
- **保留为核心主张**：「负贡献隔离 + 消融安全证书 + 覆盖空白申报」三者的**组合**及其运行时证据链。
- **不作为主张**：Shapley 采样算法本身、UCB/连续减半本身、子模贪心本身（均为教科书方法），只在从属权利要求中作为实现细节。

### 8.4 与赛事目标的对齐

UniBot 评测看**任务成功率**与**步骤分**。CAPO 的直接收益是：① 用实测贡献裁掉无用/有害模块，降低时延与故障面；② 用消融安全保证组件故障时不崩；③ 用空白驱动补长尾任务覆盖。三者都服务于「更高成功率、更少无效步骤」，而「专利布局」在本轮的作用是**防止把通用方法误当创新、并把真正的组合创新收敛到可验证的技术效果上**。
