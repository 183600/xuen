# 第 3 轮迭代（新灵感循环第 1 轮 · 灵感：「面部表情识别」×「视觉-语言-动作模型」）—— 给 VLA 装一张「进度脸」：用微表情 spotting 的骨架捕捉「被撤回」

> 承接 v2（UIP-01′~15）。v2 已经锁定最大得分缺口：`human_*` 的「反向撤回」——规则里白纸黑字，公开数据里一条都没有。但 v2 的检测器是**静态几何裁判**：它只问「这一步现在成立不成立」，不擅长捕捉**短时、低幅、局部**的撤回动作。本轮两个灵感词正好补这个短板：
> - **面部表情识别（FER）**：真正难的不是「识别大笑」，而是**微表情**——持续约 1/25~1/2 秒、强度低、只有部分 Action Unit（AU）参与，且必须按 **onset–apex–offset 的时间区间**去 spotting；单帧分类器几乎必然漏检。这正是「人手快速拧回/拉开/拿走」的结构。
> - **视觉-语言-动作模型（VLA）**：它不该只是「看到当前帧→吐动作块」。它内部的高层特征已经含有任务成败知识（SAFE 等工作已证明），可以**在同一骨干上**长出进度监控头，做「单模型自监控」，既合规又低延迟。
>
> 一句话主线：**把「任务进度」表示成一张由 Progress-Action-Unit（P-AU）组成的脸，用微表情 spotting 的区间检测与类别不平衡技术，在 VLA 内部学会读「进度被撤回」的微事件；检测到就做块边界级的「前置条件恢复」。**

## 0. 先给直觉：三个撤回场景，为什么「静态裁判」会输

- **T19 拉链**：机器人把拉链拉上（该步计分）。人随后快速拉开。下一次 `get_action` 只看到「拉链是开的」。静态谓词能说「这一步没成立」，但**分不清**三种历史：①机器人根本没拉上；②拉上了又被人拉开；③拉链头从没对齐。若撤回发生在**同一个动作块内部**、并在块边界前结束，静态裁判只拿到末态，**丢掉了变化的方向**——而「已得步骤是否被反向消耗」恰恰由方向决定。
- **T14 倒药**：机器人拧开瓶盖（任务前向动作），人把瓶盖拧回去（撤回）。注意两次都是旋转，只方向相反；单帧看不出哪次是谁、哪次是任务本身。只有**时间区间 + 已提交状态 + 空间归因**三者合起来才可判。
- **T12 开锁**：机器人开到一半，人把锁整个拿走。正确反应不是「重做开锁」，而是**止损**。要把「对象消失」与「对象还在但没对齐」分开，需要检测一个**局部的消失事件**，而不是一个谓词翻转。

三者的共同结构是：**末态观测可以完全相同，但成因（自身失败 / 外部撤回 / 对象缺失）不同；真正的判别信号是一段短时、低幅、局部的时间事件**——这正好是微表情 spotting 被设计出来要解决的问题。

**FER 的直觉**：真实情绪会从微表情里漏出来，但微表情太短、太弱、只牵动部分 AU，人眼和单帧模型都抓不住；必须在视频流里**定位区间**（onset→apex→offset），并处理严重的类别不平衡与「被试相关」差异。把「脸」换成「任务进度场」，把「AU」换成「进度动作单元」，把「被试」换成「物体/本体」——结构同构。

**VLA 的直觉**：今天的 VLA 是「看当前帧→出一块动作」，它没有显式的**自身进度轨迹模型**。但 SAFE 已经证明 VLA 的内部特征足以线性读出「任务将成功/失败」。既然监控信号已在骨干里，就不必外挂一个大 VLM；在同一骨干上长一个轻量**进度头 + 微事件 spotting 头**即可——单模型、低延迟、合规。

### 必须纠正的两点（承接上一候选轮 + 本轮独立复核）

1. **v2 的 UIP-13「运行期自适应块长」不合规**：`action_chunk_size = T_a` 在 `metadata` 握手时确定，每次返回形状须为 `(T_a, …)`。本轮所有「反应性」都放在**固定 `T_a` + 块边界检测 + 块内回看**上，不声称毫秒级反应。
2. **FER 不能字面照搬**：`observation` 是 4 路机器人相机（左右高位 + 左右腕），**没有对准人类脸部的相机**；评测者的人为干扰通常只以「手/物体运动」入镜。因此本轮做的是**方法骨架迁移**，不是「识别实验员表情」。字面版（若头相机偶尔拍到人脸就预测干预）因覆盖不稳、隐私与泛化问题，明确不作为主线。

## 2. 为什么不是「伪跨学科」：只迁移四个可检验的机制

| FER 机制 | 迁移到 UniBot 后的严格对应 | 可证伪点 |
|---|---|---|
| **AU 组合性**：复杂表情 = 少数可解释 AU 的组合 | **P-AU**：每个计分步 = 少数「相对几何/接触」单元的单调组合（接近、对齐、接触、夹紧、插入深度、闭合角） | 若 P-AU 在真机上不可观测，则整套退化为黑箱 |
| **微事件区间 spotting**：短、弱、局部，按 onset–apex–offset 定位 | **反转事件**：某已提交子目标的 P-AU 在 <D 秒内显著下降，且只影响少数单元 | 若 `T_a` 大于事件时长且回看太稀，则事件不可见 |
| **类别不平衡 + 弱标签**：微表情样本极少，标签含歧义 | 撤回样本为零；用**标签分布/序数回归**代替二分类，焦点损失 + 事件级采样 + 硬负例（任务自身的合法倒退） | 若硬负例无法与真撤回分开，则误报爆炸 |
| **被试无关泛化**：跨人归一化才能部署 | **物体无关泛化**：P-AU 只用相对几何，不依赖具体物体外观；背景/光照做风格随机化 | 若 P-AU 暗暗依赖了物体类别，未见物体轴上会崩 |

VLA 侧同样只取两点：**单骨干多轻头**（合规、低延迟）与**测试时双向引导**（BID 式重排，不需要第二个模型）。外挂 VLM（AHA/FPC 路线）只作为离线对照，不进在线回路。

## 3. 严谨定义：从「进度脸」到可执行算法

### 3.1 记号

一次 episode 的观测 `o_t = (I_t^{head_l}, I_t^{head_r}, I_t^{wrist_l}, I_t^{wrist_r}, q_t, g_t, l)`，其中 `q_t` 为关节/末端本体状态，`g_t` 为夹爪开合，`l` 为语言指令；**无触觉/力觉**。计分步 `1..N`，权重 `w_k`（来自 `info.json`，合计 100，末步 ≥ 前序步）。

### 3.2 定义 1（Progress-Action-Unit, P-AU）

P-AU 是一个把观测映射到 `[0,1]` 的**方向性进度单元**：

```
a_i(o_t) = σ( φ_i( rel(E_t, O_t) ) ),   i = 1..m
```

`rel` 只允许使用**物体无关**的相对量：末端到目标距离、轴向夹角、接触/邻近、夹爪闭合与物体是否随动、插入相对深度、铰链/盖子开合角、对齐残差等。一个计分步的进度是 P-AU 的单调组合：

```
p_k(o_t) = Comp_k( a_{i_1}(o_t), …, a_{i_r}(o_t) )   # 例：soft-min 的“有序与”
P_t      = Σ_k w_k · p_k(o_t)                        # 整任务进度（0..100）
```

> 直觉：这就是「任务的脸」——`a_i` 是面部肌肉（AU），`p_k` 是表情类别，`P_t` 是整体情绪强度。

### 3.3 定义 2（任务情感向量）

借用 FER 的 valence–arousal，定义任务的两个连续量：

```
valence_t   = P_t ∈ [0,100]          # 进度“好坏”
arousal_t   = || z_t − ĝ(z_{t−1}, a_{t−1}) ||  # 动作解释不了的潜变化（意外程度）
```

`arousal_t` 高而 `valence_t` 下降 = 「被外部改动」的高危签名；任务自身的合法倒退通常 `arousal_t` 低（因为动作块能解释它）。

### 3.4 定义 3（微进度事件, MPE）

一个微进度事件是一个三元区间 `e = (s, τ, e)` 与单元索引 `i`，满足：

```
a_i(o_τ) < a_i(o_s) − Δ                         # 显著下降（低幅事件用相对基线）
0 < e − s < D_max                               # 短时（对应微表情的 <0.5s 量级）
|{ j : a_j(o_τ) < a_j(o_s) − Δ }| ≤ ρ            # 局部（只有少数 P-AU 参与）
commit_k(s) = 1                                 # 只对“已提交”的计分步计事件
```

`τ` 是下降最深点（apex）。第四条**极其关键**：任务自身也有合法的反向动作（拧开瓶盖是 T14 的前向），不能把「运动学上的反向」误当「进度被撤回」；必须是**已提交子目标的状态被反向消耗**。

### 3.5 定义 4（spotting 任务与评测）

模型从（块边界 + 回看）的观测序列输出一组事件区间 `Ê`。沿用 spotting 的评测而非帧分类：

```
Interval-F1@IoU≥0.5
Recall@FAR≤F per minute
Detection latency  L = t_detect − s        # 从事件开始到被检出
Lead time          = t_undo_done − t_detect # 还剩多少时间可用于恢复
```

帧级 accuracy 在正例率 <2% 时没有意义（这是 FER 文献反复强调、也是本任务最容易被自欺的指标）。

### 3.6 定义 5（PAM-VLA：单骨干 + 四个轻头）

共享骨干 `z_t = f_θ(o_{t−W:t})`，其上四个头：

```
h_act : z_t → A_t ∈ R^{T_a × d}      # 动作块（形状必须严格 (T_a,d)）
h_pau : z_t → â_t ∈ [0,1]^m          # P-AU 强度（回归）
h_prog: z_t → p̂_t ∈ Δ^{N×B}           # 每步进度的序数/标签分布
h_spot: z_{t−W:t} → Ê                 # 微事件区间
```

联合训练：

```
L = L_act + λ1·L_AU + λ2·L_prog^{ord} + λ3·L_spot^{focal} + λ4·L_mono
```

`L_mono` 只加在**干净前向示教**上，惩罚 `p_t < p_{t−1}`，给出「时间的箭头」；`L_spot^{focal}` 处理极端不平衡；`L_prog^{ord}` 用序数/标签分布吸收「进度到底 70% 还是 85%」的标注歧义。**全程单骨干、单模型、无外部推理调用。**

### 3.7 定义 6（块边界恢复与双向引导）

在块边界，若 `h_spot` 以高置信度报告「已提交步 k 的 MPE」且归因为外部，则本块的目标从「推进 k」改为「恢复 k 的前置不变集」：

```
G_k = { s : pre_k(s) = 1 }        # 不要求回到示教那一帧，只要求满足前置条件
```

动作块用 BID 式测试时重排：候选 `A^(1..M)` 按

```
score(A) = −backward_coherence(A; 上一块) + α·forward_progress(A; P_t, p̂)
```

选最高者；`T_a` 固定，提前完成用 hold 补齐。这样「恢复」不需要第二个模型，也不会改变接口形状。

## 4. 瓶颈假设（v3）

- **H1（最高杠杆，沿用）**：撤回型人扰被计入步骤分，而公开数据零覆盖；「检测→恢复」是同时救成功率与步骤分的主通道。
- **H2（本轮新增）**：**静态/帧级验证器不够，必须做时间区间 spotting**。同一末态对应多种历史；只有方向+区间+归因能区分「没做过」与「做了又被撤回」。
- **H3**：进度应是**连续的序数/分布量**，不是 done/ongoing 的符号状态；二分类会把「70% 对齐」与「完全没动」混为一谈。
- **H4**：监控器必须**内生于 VLA**（SAFE 式），外挂 VLM 在单模型合规与延迟上双重不利。
- **H5**：`T_a` 在固定后就是「进度脸的帧率」。它同时决定反应性与带宽；**微事件的可见性 = 一个用带宽买的采样定理问题**。
- **H6**：P-AU 的物体无关性是把「未见物体」轴变成同分布的关键；若 P-AU 依赖外观，泛化会先崩在检测而非动作。
- **H7**：误报比漏报更贵——一次错误重做会消耗步数/时限并把可恢复干扰放大为失败；所以判决必须「遮挡不宣布、不确定不重做」。

## 5. 候选与合并 → v3 清单

围绕两个词发散 11 个草案，合并后得到 v3（详见产物区）：

- **新增**：
  - **UIP-16 PAM-VLA**（旗舰）：进度脸 + 微事件 spotting + 单骨干自监控。
  - **UIP-17 PAU-L**：P-AU 自动标注/弱监督标签工厂（用仿真几何真值 + 本体感觉，蒸馏到真机观测）。
  - **UIP-18 MEB**：微事件基准与区间评测协议（Interval-F1、FAR/min、lead time）。
  - **UIP-19 PBG**：进度双向引导的恢复重规划（BID 式，固定 `T_a`）。
  - **UIP-20 TSB**：`T_a` 与 `obs_delta_indices` 的**离线采样预算**联合标定（带宽-时间分辨率）。
- **吸收/改写**：UIP-01′（滚动验证）→ 被 `h_pau/h_prog/h_spot` 吸收；UIP-09′（撤回检测-重做）→ 被 MPE + 恢复目标吸收；UIP-13（自适应块长）→ **纠正**为「离线选 `T_a` + 固定回看」并入 UIP-20。
- **保留并改角色**：UIP-11 GSO→离线几何标注器（给 P-AU 真值）；UIP-12 DRF→**微事件负样本/正样本发生器**（不再是策略主数据）；UIP-02′（计分步安全网）、UIP-05（语言可供性）、UIP-08′（多端口延迟工程）、UIP-14（技能图）、UIP-15（可信度安全阀）继续保留。
- **明确封存**：外挂 VLM 在线监控（AHA/FPC 式）——只做离线对照，不进在线回路。

**与 v2 的一句话差异**：v2 用「手写几何规则 + Gazebo」在外围做裁判；v3 把裁判**收进 VLA 内部**，并从「帧级谓词」升级为「区间级微事件 spotting」。代价是：它把成败押在一个**可证伪的采样假设**上——撤回事件必须在固定 `T_a` 与回看预算下仍然可见。

## 6. 本轮最大风险（一句话）

**若固定 `T_a` 与回看带宽让「进度脸」的采样率低于撤回事件的持续时间，微事件根本不可见，整套方法会退化成静态裁判；而若强行提高检测灵敏度，又会在任务自身的合法倒退、遮挡与未见物体上误报，触发错误重做，把一次可恢复的人扰放大成真正的失败。**

**→ 本轮最值得押注**：**UIP-16 PAM-VLA（进度脸）× UIP-17 PAU-L（标签工厂）× UIP-18 MEB（区间评测）× UIP-19 PBG（块边界恢复）** 组成的「单模型微事件监控闭环」，先用 UIP-20 把 `T_a`/回看预算的可行性边界测出来——它精确对准规则已写明、数据全空白、且**完全落在选手 API 与离线算力之内**的最大得分缺口；若 MEB 显示采样不足，则诚实降级为「低频结构监控」而不是假装能看见。

## 1. 旗舰深潜：UIP-16 · PAM-VLA

### 1.1 机制（三句话）

1. 共享 VLA 骨干 `f_θ` 从（块边界观测 + `obs_delta_indices` 回看帧）提取时序特征；
2. 四个轻头：动作块 `h_act`、P-AU 强度 `h_pau`、每步进度分布 `h_prog`、微事件区间 `h_spot`；
3. 块边界用 `h_spot` 检测「**已提交**子目标被反向消耗」的 MPE，若归因为外部且可恢复，则本块改为恢复该步的**前置不变集**。

### 1.2 为什么它能赢过 v2 的静态裁判

| 末态观测 | v2 静态谓词能说 | PAM-VLA 能说 |
|---|---|---|
| T19 拉链末态=开 | 「本步不成立」 | 「**曾是闭的（已提交），在区间 [s,e] 内被反向拉开**，apex 在 τ」 |
| T14 瓶盖末态=紧 | 「本步不成立」 | 「旋转方向在已提交后反转，且机器人末端不在接触区→外部」 |
| T12 锁消失 | 「目标不存在」 | 「对象消失型 MPE；不可恢复→止损，而非重做」 |

关键不是多一个分类器，而是多了一个**带时间方向的进度坐标系**：它把「谓词」变成「轨迹」，把「是否成立」变成「是否被反向消耗」。

### 1.3 形式化（与想法区定义一致，落地版）

```
P-AU:   a_i(o_t) = σ(φ_i(rel(E_t, O_t)))                  i=1..m, a_i∈[0,1]
进度:   p_k(o_t) = softmin_i∈I_k a_i(o_t)                  每计分步的软“有序与”
总进度: P_t      = Σ_k w_k p_k(o_t) ∈ [0,100]
情感:   valence=P_t, arousal=||z_t − ĝ(z_{t−1}, a_{t−1})||
MPE:    e=(s,τ,e),  a_i(o_τ)<a_i(o_s)−Δ,  e−s<D_max,
        |{j: a_j(o_τ)<a_j(o_s)−Δ}|≤ρ,  commit_k(s)=1
```

`commit_k` 用迟滞提交（连续 `m` 次稳定成立），避免抖动/遮挡导致账本翻转；**撤销只作用于已提交步**，从机制上排除「任务自身还在做的合法倒退」。

### 1.4 训练目标与标签来源

```
L = L_act + λ1·L_AU + λ2·L_prog^{ord} + λ3·L_spot^{focal} + λ4·L_mono
```

| 项 | 监督 | 来源 |
|---|---|---|
| `L_act` | 动作块（示教动作 / 仿真回放） | 32 HF 数据集 + GSO |
| `L_AU` | P-AU 强度回归（软标签） | UIP-17：GSO 几何真值 → 蒸馏；真机用本体弱标签 |
| `L_prog^{ord}` | 每步进度**标签分布**（B 个序数桶） | 计分点切段 + P-AU 组合，允许 ±1 桶歧义 |
| `L_spot^{focal}` | 事件区间（正/负/难负） | UIP-12：脚本化「拧回/翻开/拉开/拿走/挪底座」 |
| `L_mono` | 干净前向示教上的单调性 | 32 HF 数据集（全部前向成功） |

**不做 32 个模型**：P-AU 头、进度头、spotting 头都挂在同一骨干上，任务通过 `observation.language` + 技能图节点条件化。

### 1.5 推理循环（严格尊重固定 `T_a`）

```python
class PAMVLA:
    def __init__(self, backbone, heads, skill_graph, cfg):
        self.f = backbone                     # 单模型共享骨干
        self.h_act, self.h_pau, self.h_prog, self.h_spot = heads
        self.G = skill_graph
        self.T = cfg.T_a                      # 握手期固定，运行期绝不改
        self.W = cfg.lookback                 # obs_delta_indices 选定的回看
        self.delta, self.D_max, self.rho = cfg.event
        self.N = cfg.num_steps
        self.reset()

    def reset(self):
        self.commit = [0] * self.N            # 已提交账本
        self.redo = 0
        self.prev_z = None
        self.prev_a = None

    def get_action(self, obs):
        # ① 共享前向（obs 已含固定回看帧）
        z_seq = self.f(obs)
        z = z_seq[-1]
        # ② 四个轻头
        a_hat = self.h_pau(z_seq)             # P-AU 强度 (m,)
        p_hat = self.h_prog(z_seq)            # 每步进度分布 (N,B)
        events = self.h_spot(z_seq)           # 微事件区间集合
        # ③ 块边界更新账本（只在已提交步上判撤销）
        self._update_ledger(a_hat, p_hat, events, z)
        # ④ 选择本块目标
        if self._needs_recovery(events):
            goal, mode = self._recovery_goal(events)   # 前置不变集 / 止损
        else:
            goal, mode = self.G.knot(self._current_step()), "forward"
        # ⑤ 生成动作块 + BID 式重排 + 严格补齐
        cands = self.h_act.sample(z, goal=goal, mode=mode, M=self.cfg.M)
        A = self._bid_rank(cands, z, goal)             # UIP-19
        return self._pad_hold(A, self.T)               # 必须 (T_a, d)

    def _update_ledger(self, a, p, ev, z):
        for k in range(self.N):
            if any(self._is_event(ev, k) for ev in ev) and self._external(ev, z):
                if self.commit[k] == 1:
                    self.commit[k] = 0                 # 被外部反向消耗
            elif self._stable(a, p, k, m=self.cfg.m):
                self.commit[k] = 1                     # 迟滞提交

    def _needs_recovery(self, ev):
        # 外部 + 已提交 + 可恢复 + 置信度>τh + 重做预算未超
        return (self._last_external_event is not None
                and self.redo < self.cfg.max_redo
                and self._recoverable(self._last_external_event))
```

**接口红线**：`A.shape == (T_a, d)`；不足用 `hold` 补；`reset()` 清空所有 per-port 状态；不在 `get_action` 里做任何外部 API 调用。

### 1.6 可行性 / 资源 / 风险

- **可行性高**：所有头都是小 MLP/轻 Transformer，挂在冻结或轻微微调的骨干上；不增加接口。
- **资源**：1 张推理卡可训离线头；在线瓶颈仍是 4 路 JPEG 传输（UIP-08′）。
- **风险与护栏**：
  - 误报→错误重做：**双门限**（事件后验 + 外部归因）+ 最大重做次数 + 延迟预算（UIP-15）。
  - 无触觉：`contact` P-AU 只能是视觉+本体代理，明确标为弱项。
  - 采样不足：由 UIP-20 先做 go/no-go，不达标就降级为低频结构监控。

## 2. UIP-17 · PAU-L（Progress-Action-Unit Labeler）

### 2.1 机制

把「P-AU 标签」变成可规模化生产的数据管线，分三层：

1. **仿真真值层（GSO）**：在 Gazebo 中重建代表任务，直接读取物体 6D 位姿、铰链角、插入深度、接触对 → 精确 P-AU 与 MPE 区间；
2. **真机弱监督层**：用公开 32 数据集的本体状态（关节、夹爪、末端）自动标注「接近/夹紧/闭合」等可观测单元；对视觉才能判的单元用少量人工种子 + 半监督一致性；
3. **蒸馏层**：让 `h_pau` 从真机 4 路图像 + 本体预测 P-AU，使离线仿真标签迁移到真实观测。

### 2.2 标签类型

- **强度回归**：`a_i ∈ [0,1]`（对应 FER 的 AU 强度，而非 AU 有无）；
- **序数进度分布**：每计分步 B 个桶上的软标签（如 B=5，允许 `[0,0.1,0.7,0.2,0]` 式歧义）；
- **事件区间**：`(onset, apex, offset, unit, cause)`，`cause∈{self_fail, external_undo, occluded, object_missing}`。

### 2.3 类别不平衡与硬负例（本轮关键）

撤回事件在真实流里可能 <1%。仅靠 focal loss 不够，必须**在事件级采样**并构造**难负例**：

| 难负例类型 | 例子 | 为什么难 |
|---|---|---|
| 任务自身合法倒退 | T14 拧开瓶盖、T19 拉上前的对齐回退 | 运动学方向与「撤回」相同 |
| 未提交/进行中的倒退 | 抓取滑落前的微退 | 未提交，不应计撤销 |
| 遮挡导致的伪下降 | 手/物体被挡住，P-AU 假跌 | 视觉缺失而非真实撤销 |
| 未见物体/背景 | 新颜色、新形状、新桌面 | 外观捷径导致的误报 |
| 人手正常经过 | 手入镜但没碰 | 高 arousal 但无进度损失 |

**训练配比建议（工作假设）**：真/仿真撤回 : 合法倒退 : 遮挡/人手经过 : 普通前向 ≈ 1 : 2 : 2 : 5；报告时按事件而非帧计权。

### 2.4 物体无关泛化（对应 FER 的 subject-independent）

- P-AU 的 `rel` 只用相对几何（距离/角度/接触/深度/闭合），默认不吃物体类别；
- 仅在排序/分拣类任务加**语义谓词**（颜色、类别），并单独标记为「外观相关」；
- 训练时做背景/光照/纹理风格随机化，用 **leave-one-object-out** 验证（对应 leave-one-subject-out）。

## 3. UIP-18 · MEB（Micro-Event Benchmark）

### 3.1 数据来源

- **正样本（撤回）**：UIP-12 DRF 脚本化生成——按 `human_*` 文本实例化（拧回、翻开、拉开、拿走、挪底座、拔起插头），随机化时机/速度/轨迹/幅度；
- **真实小样本**：真人脚本撤回（n=5~8），只用于**校准与外部效度**，不作训练主数据；
- **难负例**：见 UIP-17 §2.3；
- **公开数据**：32 套全为前向成功，**零撤回**——这正是本基准的必要性。

### 3.2 指标（禁止用帧准确率自欺）

| 指标 | 定义 | 用途 |
|---|---|---|
| Interval-F1@IoU≥0.5 | 预测区间与真值区间的匹配 F1 | spotting 主指标 |
| Recall@FAR≤F/min | 固定误报率下的召回 | 工程可用性 |
| Detection latency | `t_detect − t_onset`（按块量化） | 反应速度 |
| Lead time | `t_undo_done − t_detect` | **还剩多少时间可恢复** |
| ΔStepScore | 干扰下相对无干扰的步骤分变化 | 下游价值 |
| Visibility curve | 事件时长 `D` vs `T_a` 的检出率曲线 | 采样可行性（go/no-go） |

### 3.3 协议

- **按任务留出**（leave-one-task-out）与**按物体留出**（leave-one-object-out）双划分；
- 报告 `T_a`、回看偏移、相机子集、分辨率，因为这些直接决定可见性；
- 所有真机结论必须区分「脚本撤回」与「自由撤回」，后者单列。

### 3.4 基线

1. 帧级 P-AU 阈值（无时序）；
2. v2 静态几何谓词；
3. 仅动作残差 `arousal` 阈值；
4. 仅人手 OOD；
5. **PAM-VLA（P-AU + spotting + 归因）**。

预期（可证伪）：基线 1/2 在 `lead time` 与 `Interval-F1` 上显著差于 5；若差异不显著，说明「微事件时序」不是瓶颈，本轮核心假设被推翻。

## 4. UIP-19 · PBG（Progress-Bidirectional Guidance）

### 4.1 机制

在固定 `T_a` 下，生成本块的 `M` 个候选动作块（同一动作头的多样本，或轻量抖动），用**进度**做测试时重排：

```
score(A) = − backward_coherence(A; last_committed_ckpt)
           + α · forward_progress(A; P_t, p̂)
           + β · recovery_feasibility(A; G_k)
           − γ · latency_penalty(A)
```

- **后向一致性**：与上一块已执行动作、以及最后已提交的进度检查点对齐（防止抖动/跳变）；
- **前向进度对比**：优先选择「预测进度增量大且不越过未满足前置条件」的块；
- **恢复可行性**：若处于恢复模式，优先把状态拉回 `G_k`（前置不变集），而不是复现人类轨迹；
- **延迟惩罚**：候选数 `M` 与解码开销受 UIP-15 预算约束。

### 4.2 与 BID 的关系

BID 用「后向一致 + 前向对比」缓解 action chunking 的反应性损失；本轮把「前向对比」从**动作似然**换成**任务进度**，把「后向一致」锚定到**已提交进度检查点**。这不引入第二个模型，也不改接口。

### 4.3 何时才允许「重做」

只有同时满足：① `h_spot` 事件后验 > τ_h；② 归因为外部；③ 子目标可恢复（对象仍在、前置可达）；④ 重做次数 < `max_redo`；⑤ 延迟预算允许。否则**宁可继续前向/止损**。这条「五重门」是本轮对「别把可恢复干扰放大成失败」的直接回答。

## 5. UIP-20 · TSB（Temporal Sampling Budget）

### 5.1 问题

`T_a` 与 `obs_delta_indices` 都在 `metadata` 握手时固定，且每多一个回看偏移 = 多一张 JPEG。**进度脸的帧率不是免费的**。FER 的经验是：要看见 0.2~0.5 秒的微表情，帧率必须足够；类比到本任务：

```
事件时长 D ≈ 0.25~1.0 s（脚本可调；真人撤回可能更短）
控制频率 30 Hz ⇒ D ≈ 8~30 步
可检出性要求（经验性）：T_a ≲ D/2，回看需覆盖块内至少 4~8 个采样点
```

### 5.2 离线联合标定

在 `(T_a, 回看偏移集合, 相机子集, image_resize)` 上做网格/贝叶斯优化：

```
max   E[ Interval-F1 ]  +  κ·E[ΔStepScore]
s.t.  平均往返延迟 ≤ L_max,  抖动 ≤ J_max,
      每块传输 ≤ B_max,      返回形状 == (T_a,d)
```

- 回看优先只用**高位相机**（腕相机在遮挡时更抖），当前帧保留四路；
- 用 Visibility curve 给出「在什么 `D` 以下本方法不可用」的诚实边界；
- 若最优配置仍不可见微事件 → **降级**：只做低频结构监控（块级进度），不冒充微事件检测。

### 5.3 为什么这是 go/no-go

它把本轮的核心风险（采样不足）变成**第一个可测的实验**，而不是最后一刻才发现。若 TSB 判定不可行，UIP-16 仍有「块级进度 + 恢复」价值，但不再宣称「微事件 spotting」。

## 7. 关键算法（训练 + 推理，完整可落地）

```python
# ---------- 训练：单骨干 + 四头联合 ----------
def train_step(batch, backbone, h_act, h_pau, h_prog, h_spot, lam):
    obs, lang, a_gt, pau_gt, prog_dist, ev_gt, clean = batch
    z_seq = backbone(obs, lang)                 # 共享前向
    z = z_seq[:, -1]

    L_act  = action_loss(h_act(z), a_gt)
    L_au   = masked_l1(h_pau(z_seq), pau_gt)    # 软/弱标签
    L_prog = ordinal_ce(h_prog(z_seq), prog_dist)
    L_spot = focal_interval_loss(h_spot(z_seq), ev_gt)   # 事件级 + 区间
    L_mono = monotonic_penalty(h_prog(z_seq), clean)     # 仅干净前向
    return L_act + lam.au*L_au + lam.prog*L_prog + lam.spot*L_spot + lam.mono*L_mono

# ---------- 推理：块边界判定 + 前置不变集恢复 ----------
def bid_rank(cands, z, last_ckpt, p_hat, G_k, cfg):
    scored = []
    for A in cands:
        bc = backward_coherence(A, last_ckpt)         # 后向一致
        fp = predicted_progress_gain(A, p_hat)        # 前向进度
        rf = feasibility_to(G_k, A) if G_k else 0.0   # 恢复可行性
        lp = latency_estimate(A)                      # 延迟惩罚
        scored.append((-bc + cfg.alpha*fp + cfg.beta*rf - cfg.gamma*lp, A))
    return max(scored, key=lambda t: t[0])[1]

# ---------- P-AU 计算示例（物体无关的相对几何） ----------
def progress_action_units(obs, proprio, seg, skill):
    E, O = proprio.ee_pose, seg.target_pose          # 末端 / 目标
    au = {
        "approach": exp(-norm(E.p - O.p) / SIGMA),
        "align":    (cos_angle(E.axis, O.axis) + 1) / 2,
        "contact":  visual_contact_proxy(obs, seg),  # 无触觉→视觉代理
        "grasp":    gripper_closure(proprio) * object_follows(obs, seg),
        "insert":   clamp(relative_depth(seg.peg, seg.hole), 0, 1),
        "closure":  1 - normalized_gap(seg.lid, seg.base),
    }
    return {k: au[k] for k in SKILL_UNITS[skill]}     # 由技能图选激活单元
```

```python
# ---------- 微事件区间判定（块边界 + 回看） ----------
def spot_micro_progress_events(A_hist, commit, delta, D_max, rho):
    """
    A_hist: (W, m) 回看窗口内的 P-AU
    返回 [(s, apex, e, unit, cause)]
    """
    events = []
    for i in range(A_hist.shape[1]):
        drop = A_hist[:, i] - A_hist[:, i].min()      # 简化：相对窗口峰值
        if drop.max() > delta:
            apex = int(A_hist[:, i].argmin())
            if window_duration(apex) < D_max:
                active = (drop > delta).sum()
                if active <= rho:                     # 局部性
                    events.append((0, apex, len(A_hist)-1, i, "external_undo"))
    return [e for e in events if any(commit)]
```

## 8. 实验设计 E201–E209

| 实验 | 对照 | 指标 | 目标 / 判据 |
|---|---|---|---|
| **E201** P-AU 质量 | 仿真真值 vs 真机预测；不同物体留出 | 每单元 MAE、序数一致性、跨物体下降 | 跨物体 MAE 不显著恶化（物体无关成立） |
| **E202** spotting | 帧分类 / v2 静态 / 仅残差 / 仅人手 OOD / PAM | Interval-F1、Recall@FAR、latency、lead time | PAM 的 lead time 显著更长；否则核心假设被推翻 |
| **E203** 内部 vs 外挂监控 | SAFE 式内部头 / AHA 式外挂 VLM | 合规性、逐步延迟、F1 | 内部头延迟低一个量级且合规；外挂只做离线对照 |
| **E204** 恢复触发 | 无恢复 / 固定重做 / 五重门 / 五重门+PBG | 步骤分（`S_end` 与 `S_high` 各算）、重做次数、失败放大率 | 五重门显著降低「越救越糟」 |
| **E205** 五轴泛化 | 未见物体/位置/干扰物/背景 | 误报率、成功率、ΔStepScore | P-AU 物体无关 + 风格随机化降低未见物体误报 |
| **E206** 采样预算（go/no-go） | `T_a` × 回看 × 相机子集 × 分辨率 | Visibility curve、延迟/带宽 | 找到可行区；不可行则诚实降级 |
| **E207** PBG 消融 | 去后向 / 去前向进度 / 去恢复项 | 步骤分、动作抖动 | 每项有可测边际 |
| **E208** 端到端 | 6 代表任务（T19/T14/T12/T26/T27/T16） | 成功率、步骤分、区间指标 | 真机锚点；脚本撤回与自由撤回分开报 |
| **E209** 合规审计 | — | 单骨干、无外部调用、`(T_a,d)` 形状、端口隔离 | 全通过 |

> 报告纪律：真机结论一律标注「真实人扰 / 脚本撤回 / 仿真生成」；后两者只用于检测器验证，不得冒充真机结论。

## 10. 合规与风险

- **单模型合规**：共享骨干 + 多个轻头；在线**零外部 API/VLM**；不做 per-task 独立模型；外挂监督只存在于离线实验对照。
- **接口红线**：`T_a` 握手固定；每次返回 `(T_a,d)`；提前完成用 hold 补齐；`reset()` 清空 per-port 状态；不改变 obs 键集合。
- **无触觉/力觉**：`contact`/`insert` 只能做视觉+本体代理，明确列为弱项；不得在报告里当成真实接触真值。
- **仿真到真机**：GSO 只提供 P-AU 几何**结构**真值，不提供像素级成败；必须用真机锚点校准（E208）。
- **误报优先于漏报的取舍**：默认「遮挡不宣布、不确定不重做、对象缺失则止损」，用 UIP-15 兜底。
- **性能开销**：四个轻头 + M 个候选的 BID 重排会增加推理时间；由 UIP-20 与 UIP-15 联合约束，必要时把 M 降到 2~4。

## 11. 本轮最大风险 & 押注

**一句话**：**若固定 `T_a` 与固定回看预算让进度脸的采样率低于撤回事件的持续时间，微事件根本不可见，方法退化为静态裁判；若强行提高灵敏度，又会在任务自身的合法倒退、遮挡与未见物体上误报，触发错误重做，把可恢复的人扰放大成真正的失败。**

**→ 押注**：**UIP-16 PAM-VLA × UIP-17 PAU-L × UIP-18 MEB × UIP-19 PBG** 的「单模型微事件监控闭环」，并让 **UIP-20 TSB 成为第一个实验（go/no-go）**——它精确对准规则已写明、公开数据全空白、且完全落在选手 API 与离线算力之内的最大得分缺口；若采样可行性不成立，则诚实降级为「块级进度 + 前置条件恢复」，绝不假装能看见看不见的事件。
