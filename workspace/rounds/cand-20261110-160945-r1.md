# 第 46 轮（承接第 45 轮 v10 与第 46 轮产物 v23；本轮灵感：知识图谱 × 对比实验） · KG-Cert × Counterfactual Ablation：证书知识图谱驱动的感知调度与可证伪对比审计（五层架构 v11）

> 承接第 45 轮 v10 能量-上下文-深度框架与第 46 轮 v23 记忆-语音-安全闭环。v10 把感知调度变成能量租约约束下的资源分配，v23 把记忆检索与语音指令接入安全队列，但两者共享隐含假设 H5：**从上下文/记忆到“退化层→模态→证书半径”的映射是嵌入空间里的黑箱，既不可审计，也无法外推到从未共现过的退化组合**；同时每轮都在叠加模块（能量租约、深度门控、记忆、语音绑定），却从未用受控实验回答“每个模块的边际安全收益是否真实、是否以牺牲 soundness 为代价”。两个灵感词精确命中 H5：**知识图谱**把隐式映射显式化为带类型、带证据、带校准半径的关系图，使长尾退化组合可组合推理并输出证书推导；**对比实验**把每个新增模块视为处理变量，用预注册的因子消融、配对反事实重放与非劣性检验来归因其因果效应。二者耦合出新问题：**如何让图谱推理给出的模态决策附带可审计的证书证明，并让对比实验反过来判定图谱的每条边是否值得信任**。

## 0. 直觉与动机

**灵感 1（知识图谱 → 把“退化-模态-证书”从黑箱嵌入变成可组合的显式关系）**
直觉：kNN 记忆只是在嵌入空间做插值。若“透明物体”与“快速运动”从未同时出现，记忆库没有邻居，系统就无法预估二者叠加后的姿态退化；但人类会用“透明材料诱导深度空洞、快速运动诱导运动模糊、两者叠加进一步放大半径”这样的结构化知识外推。于是把场景实体、材料、退化层 ω、模态 m、任务 φ、证书 P 建成类型化有向多重图，边上存条件退化系数、交互项与共形校准证据；在线查询时沿路径复合，输出的是“模态 + 证书半径 + 推导链”，而不是一个不可解释的分数。

**灵感 2（对比实验 → 把架构演进从“叠加模块”变成“可证伪的因果归因”）**
直觉：系统已经从 v9 堆到 v23，继续加模块最大的风险不是不够强，而是某层在悄悄侵蚀 soundness 却因缺少对照而无人发现。把每个模块（KG、深度门控、记忆复用、语音绑定、能量租约）当作二元处理变量，在按“退化层 × 电量桶 × 任务精度”分层的匹配样本上做因子消融；用日志配对反事实重放做离线对照，用影子模式做在线对照；主指标是安全违例率，用非劣性边界 δ_safety 与 Holm–Bonferroni 多重比较校正，先证明“不更差”，再谈“更省电/更成功”。

**灵感 3（二者耦合 → 图谱是审计的载体，审计是图谱的校准器）**
直觉：没有图谱，对比实验只能测整块黑箱的输入输出，无法定位是哪条关系错了；没有对比实验，图谱的边只是人工先验，无法判断它是否比 kNN 更可信。因此让图谱每条边携带 provenance 与校准覆盖，对比实验的消融结果回写边权与置信，形成“结构化先验 → 受控检验 → 图谱修正”的闭环。

**架构升级（v11）**：在 v10 四层（根信任层、L1 几何层、L2 上下文层、L3 安全层、L4 采集层）之上增加一个**横切的 KG-Audit 基底**：L0 根信任仍管姿态/能量租约；L1 的半径不再只查表，而由图谱路径推导；L2 的上下文预测以图谱锚点为检索键；L3 的 CAR 守卫额外检查推导链 provenance 与“非劣性证书”；L4 的 DCL 优先补齐图谱中低覆盖/高不确定的边。对比实验作为贯穿所有层的审计协议，而非单独一个模块。

## 1. 形式化定义（增量：定义 59–63）

**定义 59（证书知识图谱 CG-KG）**
证书知识图谱为带标注的类型化有向多重图
G = (V, E, τ, γ, ρ)，
其中节点类型 V = V_scene ∪ V_mat ∪ V_deg ∪ V_mod ∪ V_task ∪ V_cert；边类型 τ(e) ∈ {induces, degrades, mitigates, certifies, requires, coOccurs, conflicts}。每条边 e=(u→v) 带权重 w_e、交互系数 κ_e、证据护照
π_e = (audit_id, n_e, coverage_e, valid_until_e)，
ρ 把节点/边映射到已校准的半径贡献或功耗。图谱的“可审计”指：任一输出决策都能回溯到一条有限路径及其 π_e。

**定义 60（图谱查询与可采纳模态集）**
查询 q = (c_t, φ, B_t)。锚定函数 g 把上下文映射到实体/任务节点集合 A(q)=g(c_t,φ)。在 G 上做受约束 k 跳搜索，得到路径集合 Π_k(q)。对模态 m 定义
M_G(q) = { m ∈ V_mod : ∃ π ∈ Π_k(q), π⊨m, coverage(π) ≥ 1-α_p, P_m·Δ ≤ E(t)-E_min }，
其中 π⊨m 表示路径末端经 certifies 边连到满足任务 φ 的证书节点。查询输出 (m, r_π, Der(q))，Der(q) 是一棵带 provenance 的推导树。

**定义 61（退化组合算子与健全上界）**
对退化层 ω₁, ω₂ 与模态 m，组合半径定义为
r_{ω₁⊕ω₂}(m) = min( r_max, min(r_{ω₁}(m), r_{ω₂}(m)) + κ_{12}·rad(P_t) )，
其中 κ_{12} 是图谱 conflicts/coOccurs 边上的交互系数（κ≥0 表示叠加放大）。对任意路径 π=ω₁⊕…⊕ω_k，要求
r_π(m) ≥ max_{i} r_{ω_i}(m) 且 r_π(m) ≤ Σ_i r_{ω_i}(m)。
**健全性要求**：若路径覆盖不足或存在未校准的交互边，则 r_π 取保守上界 r_max 并把该路径标记为 unverified。

**定义 62（对比实验单元与配对因果效应）**
设分层变量 s=(ω, B_bucket, φ_precision)，处理向量 z∈{0,1}^k 表示 k 个模块的开关，结局
Y = (V_safety, E_consumed, Success)。
配对样本 (i,i') 在 s 上匹配且仅处理不同。模块 j 的平均处理效应
τ_j = E_s[ E[Y_j(z_j=1)-Y_j(z_j=0) | s] ]。
预注册非劣性边界 δ_safety（安全违例率的允许上升上界）与显著性水平 α=0.05。

**定义 63（证书对比审计判据）**
模块 j 被判定为“可保留”，当且仅当同时满足：
(1) 安全违例率配对差的单侧 95% 置信上界 ≤ δ_safety（非劣）；
(2) 能耗或成功率的改善在 Holm–Bonferroni 校正后仍显著；
(3) 引入 j 后 KG 查询覆盖率不低于引入前（不得以降低覆盖换取表面收益）。
否则模块进入回退候选，且其相关图谱边权被降级为 unverified。

## 2. 新增产出与既有 IP 升级

**IP-69 CG-KG Builder（证书知识图谱构建器）**
- 领域本体：Scene/Material/Degradation/Modality/Task/Cert 六类节点与七类边
- 自动抽取：VLM 场景语义 → 实体/材料节点；共形校准结果 → certifies 边半径；日志挖掘 → coOccurs/conflicts 交互系数
- 证据护照：每条边记录 audit_id、样本数、覆盖区间、失效时间；训练/审计集严格隔离
- 图谱版本化与漂移检测：边覆盖跌破阈值即标 unverified

**IP-70 KQG（KG Query Gate，图谱查询门控）**
- 上下文锚定 + 受能量约束的 k 跳搜索，输出带推导树的模态候选
- 路径复合用定义 61 的保守上界；unverified 路径不参与决策，只触发 DCL
- 与 ECPS/MVR 级联：图谱命中则复用推导链，未命中回退实时效用或 fail-closed
- 证明携带：决策包 = (m, r_π, Der(q), provenance)

**IP-71 CAP（Comparative Ablation Protocol，对比消融协议）**
- 预注册：假设、主/次指标、δ_safety、样本量与检验计划在采集前冻结
- 设计：分层配对 + 2^k 因子消融（关键模块）+ 日志反事实重放 + 影子在线对照
- 统计：配对 bootstrap、单侧非劣性、Holm–Bonferroni、序贯 α 消耗
- 回写：消融结果修正图谱边权与置信，失败模块触发回退开关

**既有 IP 升级**
IP-66 MVR：从纯 kNN 升级为“图谱约束检索”，记忆只作为图谱未覆盖时的补充；
IP-63 ECPS：候选集改为 M_G(q)，效用求解前先过图谱门控；
IP-62 CCA：新增图谱边红队、训练/审计泄漏检测、消融实验功效审计；
IP-61 DCL：采集优先级由“图谱边覆盖缺口 × 交互不确定度”驱动；
IP-51 CAR：守卫联合检查推导链 provenance 与“非劣性证书”有效；
IP-45 总线：新增 kg-query / kg-provenance / ablation-arm / cert-derivation 话题。

## 3. 算法骨架

**离线（图谱构建与预注册）**
1. 从标定集、审计集与历史日志抽取实体、退化层、模态与证书关系；
2. 为每条 certifies/degrades 边单独做分层共形校准，写入半径与覆盖；
3. 挖掘共现与冲突，估计交互系数 κ，标注 provenance；
4. 冻结 CAP 的假设、指标、δ_safety 与样本量，登记审计集版本。

**在线（图谱查询与安全决策）**
1. 读 c_t, φ, B_t, ℓ_e，锚定 A(q)；
2. 受能量约束 k 跳搜索，生成 M_G(q) 与推导树；
3. unverified 或覆盖不足 → 标记 risk，交给 ECPS 实时求解或 fail-closed；
4. 对每个可行 m 计能量可行性与期望半径缩减，选 m_t^*；
5. 签发联合证书 J_t=(P_t,ℓ_p,ℓ_e,m_t,Der(q))，CAR 校验 provenance；
6. 记录决策上下文与图谱版本，供后续配对重放。

**审计（对比实验闭环）**
1. 按 s 分层抽取配对日志段，做模块开关的反事实重放；
2. 计算 τ_j 的配对差与单侧置信界，执行非劣性与多重比较校正；
3. 未通过者回退并降级相关边；通过者更新边权与覆盖；
4. 影子模式验证离线结论与在线分布是否一致，防止分布漂移。

## 4. 本轮最大风险

**一句话**：若图谱边的条件半径来自与在线分布不一致的审计集、或对比实验功效不足却把“未检出差异”误判为“非劣”，系统会以可解释的推导链包装一个被高估的可采纳模态集，从而在长尾退化组合上静默放宽姿态证书；因此必须用独立留出的审计集、预注册与非劣性边界、以及 unverified 边的保守回退，来保证图谱外推与消融结论都不越权。

**定义 66（影子反事实重放）**：给定日志段 L_i，开关模块 j 得到两条反事实轨迹 Y_i(1),Y_i(0)；若 |τ_j^{offline}-τ_j^{shadow}| 的置信区间跨 0，则判定离线重放与在线分布一致，可用于图谱回写。

```
def build_cgkg(calib_sets, audit_sets, logs, ontology, alpha_p):
    G = init_graph(ontology)
    for scene in calib_sets:
        for mat, deg in extract_material_degradation(scene):
            add_edge(G, mat, deg, type='induces',
                     w=estimate_induction(scene, mat, deg),
                     prov=passport(scene.audit_id, scene.n))
        for deg, mod in enumerate_degradation_modality(scene):
            r, cov = conformal_radius(scene, deg, mod, alpha_p)
            add_edge(G, deg, mod, type='degrades', r=r,
                     prov=passport(scene.audit_id, scene.n, cov))
    for mod, cert in modality_cert_pairs(G):
        add_edge(G, mod, cert, type='certifies',
                 r=lookup_calibrated_radius(mod, cert),
                 prov=passport('cert-'+mod, n_cert))
    for a, b in cooccurrence_pairs(logs):
        kappa, n_ab = estimate_interaction(logs, a, b)
        add_edge(G, a, b, type='coOccurs', kappa=kappa,
                 prov=passport('cooc-'+a+'-'+b, n_ab))
    return G

def mark_unverified(G, t, alpha_p):
    for e in G.edges:
        if e.prov.coverage < 1-alpha_p or e.prov.valid_until < t or e.kappa is None:
            e.status = 'unverified'
    return G
```

### IP-70 KQG 图谱查询
```
def kq_query(G, c_t, phi, B_t, Delta, E_min, k=4, beam=8, alpha_p=0.05):
    anchors = ground(G, c_t, phi)
    frontier = [(a, [a], 1.0) for a in anchors]
    paths = []
    for hop in range(k):
        nxt = []
        for node, path, cov in frontier:
            for e in G.out_edges(node):
                if not edge_allowed(e, phi):      # 类型/任务约束
                    continue
                new_cov = min(cov, e.prov.coverage)
                score = new_cov / (1.0 + radius_contrib(e))
                nxt.append((e.dst, path+[e], new_cov, score))
        frontier = top_beam(nxt, beam, key=score)
        paths.extend([p for p in frontier if reaches_cert(p, phi)])
    cands = []
    for node, path, cov, _ in paths:
        m = path[-1].modality
        r, verified = compose_radius(path, m, G, rad(P_t), r_max)
        if not energy_feasible(m, B_t, Delta, E_min):
            continue
        if cov < 1-alpha_p or not verified:
            cands.append((m, r_max, Der(path), 'unverified'))
        else:
            cands.append((m, r, Der(path), 'verified'))
    return dedup_best(cands, key=lambda x: (x[3]=='verified', x[1]))
```

### 定义 61 的组合半径
```
def compose_radius(path, m, G, rad_P, r_max):
    r = 0.0
    prev = None
    for e in path:
        if e.type not in ('degrades', 'coOccurs'):
            continue
        r_e = e.r if e.type == 'degrades' else edge_radius(G, e.src, m)
        if prev is None:
            r = r_e
        else:
            kappa = interaction(G, prev, e.src)
            if kappa is None:
                return r_max, False
            r = min(r_max, min(r, r_e) + kappa * rad_P)
        prev = e.src if e.type == 'degrades' else prev
    return r, True
```

### IP-71 CAP 对比消融
```
def cap_ablation(logs, modules, delta_safety=0.005, alpha=0.05, B=10000):
    strata = build_strata(logs)                 # (omega, B_bucket, phi_precision)
    pairs = match_pairs_within_strata(logs, strata)

    safety_diff, energy_diff, success_diff = {}, {}, {}
    for j in modules:
        ds, de, dsu = [], [], []
        for (i, i2) in pairs:
            y1 = counterfactual_replay(i, module_on=j)
            y0 = counterfactual_replay(i2, module_off=j)
            ds.append(y1.V_safety - y0.V_safety)
            de.append(y0.E_consumed - y1.E_consumed)
            dsu.append(y1.Success - y0.Success)
        safety_diff[j] = (mean(ds), boot_ci(ds, B, side='upper', level=0.95))
        energy_diff[j] = (mean(de), boot_ci(de, B, side='lower', level=0.95))
        success_diff[j] = (mean(dsu), boot_ci(dsu, B, side='lower', level=0.95))

    noninferior = {j: safety_diff[j][1] <= delta_safety for j in modules}
    p_energy = {j: paired_perm_p(energy_diff[j][0], B) for j in modules}
    p_success = {j: paired_perm_p(success_diff[j][0], B) for j in modules}
    rejected_e = holm(p_energy, alpha)
    rejected_s = holm(p_success, alpha)

    keep, rollback = set(), set()
    for j in modules:
        if not noninferior[j]:
            rollback.add(j)
        elif j in rejected_e or j in rejected_s:
            keep.add(j)
        else:
            keep.add(j)         # 非劣但收益不显著：保留但标记低收益
    return keep, rollback, {'safety': safety_diff,
                            'energy': energy_diff,
                            'success': success_diff}
```

### 全局决策整合
```
def global_decision_v24(c_t, phi, omega_t, B_t, v_t, G, M, calib, S_phi):
    cands = kq_query(G, c_t, phi, B_t, Delta, E_min)
    if not cands:
        # 图谱未覆盖：回退 v23 记忆/实时求解，但强制保守半径
        return fallback_v23(c_t, omega_t, B_t, v_t, M, calib, S_phi,
                            force_radius='conservative')
    verified = [c for c in cands if c[3] == 'verified']
    pool = verified if verified else cands
    m_t, r_t, der, status = max(pool, key=lambda c: utility(c, c_t, B_t))
    if not provenance_ok(der) or not cap_gate_allows(m_t):
        return 'fail-closed', None, der
    P_t = pose_certify(m_t, radius=r_t)
    if safety_bind(v_t, P_t, omega_t) < theta_safe:
        push(Q_safe, v_t)
        return 'queued', P_t, der
    return 'execute', P_t, der
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CG-KG 构建 | O((N_calib+N_cooc)·d) 离线 | O(|V|+|E|) | 每条边有独立审计护照与校准半径 |
| KQG 查询 | O(k·beam·deg(G)) 每周期 | O(beam·k) | 输出附带推导树；unverified 路径投影为 r_max |
| 组合半径 | O(|π|) | O(1) | 满足 max_i r_{ω_i} ≤ r_π ≤ Σ_i r_{ω_i}，未校准交互取 r_max |
| CAP 消融 | O(|modules|·|pairs|·B) 离线 | O(|pairs|) | 非劣性 + 多重比较校正；配对设计消除分层混杂 |

**正确性定理（图谱门控的保守性）**：若 KQG 返回的每条路径 π 均满足 coverage(π) ≥ 1-α_p 且所有交互边已校准，则按定义 61 复合的 r_π 是真实退化半径的健全上界，即 r_π ≥ r_true；若任一边 unverified，则系统输出 r_max ≥ r_true 或 fail-closed，因此不会因图谱外推产生过窄姿态盒。进一步，若 CAP 判定模块 j 非劣且图谱边覆盖未下降，则启用 j 不会提高安全违例率的上置信界。

**命题（对比实验的可证伪性）**：在预注册的 δ_safety、α 与样本量下，若模块 j 的真实安全违例率增量大于 δ_safety，则配对非劣性检验以不低于 1-β 的功效拒绝“非劣”假设；若功效不足（<0.8）则 CAP 自动将该模块标记为“证据不足”，不得进入 keep 集合。

## 4. 实验设计 E115–E120（以对比实验为主线）

所有实验先在采集前冻结预注册文档（假设、主/次指标、δ_safety、样本量、α 消耗计划），训练集、校准集、审计集、在线日志四者严格隔离；主指标为安全违例率，次指标为任务成功率、单位任务能耗、证书平均宽度、图谱未验证边比例。

| 实验 | 对照设计 | 指标 | 门槛/判定 |
|---|---|---|---|
| E115 图谱覆盖与证书一致率 | 按边分层留出校准，比较预测覆盖率 vs 名义覆盖率 | 覆盖误差、unverified 边比例 | 覆盖误差 ≤ 1pp；unverified ≤ 5% |
| E116 长尾组合外推（核心对比） | KG vs v23 kNN 记忆，在“单层已见、组合未见”的退化对上配对 | 组合层安全违例率、成功率、cert 宽度 | 违例率相对下降 ≥ 30%，且无非劣回退 |
| E117 模块因子消融 2^3 | 对 {KG, 深度门控, 记忆复用} 做全因子，语音绑定单列 2 臂 | 安全违例率配对差 τ_j | 单侧 95% 上界 ≤ δ=0.5pp；Holm 校正 |
| E118 能量-成功交互 | 电量桶 × 退化层分层，比较各臂能耗与成功 | 单位任务能耗、成功率 | 能耗显著下降且成功率非劣 |
| E119 反事实重放一致性 | 离线重放 vs 影子在线 A/B，同一日志段 | τ_j 偏差、CI 覆盖 | 偏差 CI 跨 0；覆盖 ≥ 95% |
| E120 100h 闭环与漂移 | v23 基线 vs v24，月度漂移注入 | 安全违例、回退次数、未验证边增长 | 违例 0 起；回退 ≤ 2 次；未验证边 ≤ 10% |

**样本量与功效**：以 E117 的非劣性检验为主，预估基线违例率 1.0%，δ=0.5pp，单侧 α=0.05、功效 0.8，配对设计下每臂约需 3.2k 个分层匹配段；100h 在线实验作为外部效度验证，不替代预注册功效分析。

**回退策略**：E116 未达 30% → 保留图谱只做解释层，不参与门控；E117 任一模块非劣失败 → 关闭该模块并降级相关边；E119 重放偏差显著 → 冻结图谱回写，只用在线影子结论；E120 未验证边 > 10% → 触发全量重校准并退回 v23 保守路径。

## 6. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 图谱边半径误校准导致过窄证书 | 高 | 独立留出审计集；unverified 投影 r_max；在线覆盖率监控 |
| 训练/审计泄漏使图谱“看起来”很准 | 高 | 证据护照记录 audit_id；泄漏检测红队；隔离四类数据集 |
| 对比实验功效不足误判非劣 | 高 | 预注册样本量与功效；不足则标“证据不足”并禁止 keep |
| 多重比较导致假阳性 | 中 | Holm–Bonferroni + 序贯 α 消耗 |
| 图谱规模膨胀、查询延迟 | 中 | beam 搜索 + 缓存 + 边裁剪；超时回退实时求解 |
| 分布漂移使旧边失效 | 中 | valid_until + 月度重校准 + DCL 定向补采 |

## 7. 本轮最大风险

**一句话**：最大风险是把“图谱可解释”误当成“图谱正确”——若边的半径与交互系数来自有泄漏的审计集，或对比实验把功效不足的“未检出差异”当成非劣，系统就会用一条看似严谨的推导树为过窄的姿态证书背书，在长尾组合退化上静默失效；因此必须坚持四集隔离、预注册非劣性边界、unverified 边保守回退，并让 CAP 对图谱本身也保留“证据不足即拒绝”的权力。
