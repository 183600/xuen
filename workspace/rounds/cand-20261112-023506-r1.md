# 第 58 轮（承接第 57 轮「少样本×多模态×个性化」IP-133~138；新灵感循环第 1 轮；本轮灵感：「演示数据」×「双臂协作」）

> 第 57 轮把安全的赌注从"模型置信"换到"证据承诺"，又用元推断、跨模态对账与个性化信任把证据的质量、模态与人的因素补齐；但它仍默认证据是"自己探出来的"，且默认一次接触只有一个执行者。本轮两个灵感各戳破一个默认：**演示数据**告诉我们，证据可以来自别人——但别人只演示了"走过的那条分支"，没演示的分支不是"安全"，而是"未知"；**双臂协作**告诉我们，证据可以来自两个执行者——但两臂的"一致"可能只是内部力在零空间里互相抵消的自洽，未必是物理正确。于是核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"演示可追溯且阴影可知、双臂可规范对账且单臂可证伪、不可逆接触只认物理证据"**。一句话：**演示给效率，双臂给冗余，两者都不能替代物理证据。**

核心矛盾：
- **H29（演示效率 vs 反事实阴影）**：演示是"压缩过的一条成功轨迹"，它天然省略了失败分支与风险裕度；把"演示过"当成"安全"就是把"未观测"当成"已证伪"。演示越多越省探针，但阴影越大越危险——效率与覆盖方向相反。
- **H30（双臂一致 vs 合作遮蔽）**：两臂对同一物体的力/位姿读数一致，可能来自真实物理一致，也可能来自内部力在抓取映射零空间中的任意抵消；后者会让"两臂都同意"变成一个观测退化下的假共识。
- **H31（出处权威 vs 分布外洗白）**：演示者的能力与声誉会让系统更愿意采信其演示，但专家在分布外同样会错；若出处直接进入安全界，就会发生"权威洗白"——用"谁做的"替代"为什么安全"。

## 0. 直觉与动机

**灵感 1（演示数据 → 带出处、带阴影、可回放的证据）**
直觉：人类学徒不是靠"看过师傅做一遍"就获得安全保证，而是知道师傅在什么条件下做、哪些情况师傅也没试过。把演示当成证据，必须同时记录三件事：**出处**（谁、在什么光照/材质/负载/遥操作模式下采集，演示者能力后验）、**反事实阴影**（每个决策点未执行的备选动作集合）、**可回放性**（把演示放回当前地图 𝓜 里跑一遍，看预测结果与演示结果是否一致）。出处只用来给演示加权、排序探针，**永远不进入安全界**；阴影是"已知的未知"，未观测分支按最大熵处理，绝不当安全；回放偏离超过阈值则撤销该演示的证据资格。

**灵感 2（双臂协作 → 物理规范对账，而非统计独立）**
直觉：第 57 轮的跨模态对账依赖"条件独立"这一统计假设；双臂给出一个更强的物理版本——两臂对同一物体的力必须满足静力学平衡。但这里藏着一个规范自由度：抓取映射 G=[G_1 G_2] 的零空间 N(G) 对应**内部力**，它不改变物体合外力，却可以任意大（在摩擦锥/执行器限内）。因此双臂的"一致"只有在**规范不变**的意义下才是证据：主张 φ 必须在整个规范类 [f]=(f+N(G))∩F 上都成立；若某个局部异常可以被内部力"解释掉"，那它不是安全证据，只是不确定性。更狠的是**合作遮蔽**：一臂的误差可以被另一臂的内部力补偿，使物体层面看起来完全正常；所以双臂证据必须附加**单臂可证伪**条件——每个臂单独也要有能检测该失败模式的手段，否则两臂一致只是观测退化。

**灵感 3（两灵感合流 → 证据门从五类到七类，演示/双臂只做 L1 与提案）**
直觉：第 57 轮证据门 EV-probe/visit/margin/xmodal/human 在本轮再加两类：**EV-demo\***（出处 + 阴影覆盖 + 回放偏离 + 迁移差四项全过，且仅 L0/L1）与 **EV-bimanual**（规范不变残差 + 单臂可证伪 + 物体级见证，且仅 L1）。二者都**不得进入不可逆接触必要证据集**——不可逆接触只认 EV-probe\* 或 EV-margin 加佐证。演示与双臂可以降低"去哪里探、怎么探"的成本，但不能降低"必须探到物理证据"的门槛。

**灵感 4（演示 × 探询 → 演示只提"去哪探"，不证"探过就安全"）**
直觉：演示数据最有价值的用法不是直接承诺，而是**提案分布**：它告诉系统"有经验的执行者会优先探这几个点、会先试这条分支"。把 q_demo(π|r) 接进 VOI 排序，可以显著省探针；但一旦回放偏离或出现 shadow_gap，系统必须对分歧分支补一次**阴影探针**或绕行，而不是"相信演示所以跳过"。演示引导的是注意力，不是安全判定。

**灵感 5（跨轮：数据出处状态机 + 双臂物理台账）**
直觉：第 57 轮把人建模成信任状态机；本轮把**数据也建模成出处状态机**：每条演示有 provenance 状态（可信/仅提案/失效/待回放），随回放、迁移、事后证伪演化；每个双臂区域有**规范台账**（gauge ledger），记录内部力包络、单臂检测度、物体见证误差。二者都进审计、都可被事后证伪回溯，延续第 56~57 轮"一切判定器走隔离"的思想——**演示与双臂策略也要先走影子模式**。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（演示证据模型 DEM）** 演示集 𝒟_demo={(ξ_i,z_i,π_i,o_i)}_{i=1..N}，ξ_i=(s_{i,0:T},a_{i,0:T-1}) 为轨迹，z_i 采集上下文，π_i=(演示者 id, 能力后验 c_i, 遥操作/自主, 光照/材质/负载, 时间) 为出处向量，o_i 为结果。每个决策点 t 的**反事实阴影** S_{i,t}=A_t\{a_{i,t}\}。阴影覆盖 κ_sh(r)=Σ_t w_t·1[S_{i,t} 至少被增强/回放采样]/Σ_t w_t，w_t 为部署相关性权重。迁移差 d_demo(r)=sup_{z∈Z_r}|p̂(z)−p̂_demo(z)|。出处只用于提案加权：w_demo(r)≤w_demo^max，c_i 不进入任何安全界（**反权威洗白**）。未观测分支记 U，P_fail(U) 取最大熵先验，禁止把 U 当安全。d_demo>θ_demo ⇒ 仅提案级。

**定义 140（演示-仿真偏离 DSD）** 将 ξ_i 回放于当前地图 𝓜：ô_i=Sim(ξ_i,𝓜)；偏离 δ_dsd=d(ô_i,o_i)（末端位姿/接触力/终止状态）。δ_dsd>θ_dsd ⇒ 演示隐含动力学与 𝓜 冲突，撤销其对相关区域的证据资格并登记 shadow_conflict。若部署请求的分支落在未采样的 S_{i,t}，输出 **shadow_gap**，只能触发探针或绕行，不能触发承诺。

**定义 141（双臂规范对账 DGR）** 双臂抓取映射 G_1,G_2，G=[G_1 G_2]，实测 f=(f_1,f_2)。分解 f=f^⊕+f^N，f^N∈N(G)（内部力）；规范类 [f]=(f+N(G))∩F，F 为摩擦锥/执行器/接触约束。主张 φ（接触力≤F_abs、位姿稳定、无滑移）**规范支持** ⇔ ∀f'∈[f]∩F: φ(f')。规范不变残差 r_gi=max_{f'∈[f]∩F} viol(φ,f')。EV-bimanual 需 r_gi≤θ_gi ∧ 物体级见证（位姿/运动）误差≤θ_obj ∧ 单臂可证伪（定义 142），且仅 L1，不入不可逆必要集。

**定义 142（合作遮蔽指数与单臂可证伪 CCD）** 对每个失败模式 e，单臂可检测度 d_j(e)=P(检测到 e | 仅臂 j 的传感与局部证据)；合作遮蔽指数 κ_cc(e)=1−min_j d_j(e)（等价于另一臂可补偿的最大比例）。若 κ_cc>θ_cc，双臂一致是**观测退化**而非独立证据，EV-bimanual 失效。内部力不得用于"解释掉"局部接触异常：若异常可由 f^N 在 F 内吸收，则不构成安全证据，只构成不确定性。

**定义 143（演示-双臂证据门 DGE 与证书 J_d）** 证据类 EV-probe\*/visit/margin/xmodal/human/**demo\***/**bimanual**。EV-demo\* ⇔ 出处证书 ∧ κ_sh≥κ_sh^0 ∧ δ_dsd≤θ_dsd ∧ d_demo≤θ_demo ∧ 仅 L0/L1；EV-bimanual ⇔ r_gi≤θ_gi ∧ κ_cc≤θ_cc ∧ 物体见证一致 ∧ 仅 L1。不可逆接触必要证据集={EV-probe\*∨EV-margin}∪佐证，**demo/bimanual/xmodal 一律不得进入**。J_d=(demo_provenance_log, shadow_atlas, replay_div_log, gauge_ledger, concealment_index, single_arm_tests, internal_wrench_envelope, transfer_audit)，继承 J_p 全检。

**定义 144（演示引导探-诺-演 DPC）** 候选探针分布 q_demo(π|r,𝒟_demo) 仅用于 VOI 排序；admissible_probes 仍按非破坏性过滤（A34 继承）；承诺门不变。若 δ_dsd>θ_dsd 或 shadow_gap，强制对分歧分支做一次**阴影探针**或绕行。演示回放先走影子模式，出处/阴影/偏离/迁移四项检查通过后才进入提案池。

## 2. 关键算法伪代码（完整版见产物区）

```python
def demo_grade(D, r, M):                              # IP-139/140
    if demo_transfer(D, r) > theta_demo: return Grade('proposal_only')
    if replay_divergence(D, M) > theta_dsd:
        audit.flag('shadow_conflict', D.id); return Grade('invalid')
    if shadow_coverage(D, r) < kappa_sh0:
        return Grade('proposal_only', gap=True)       # 未观测≠安全
    return Grade('demo_evidence', w=min(w_demo_max, relevance(D, r)))

def gauge_reconcile(f1, f2, G1, G2, F, claim, obj):   # IP-141/142
    G = hstack([G1, G2]); N = null_space(G)
    gauge = (f1, f2) + N                            # 规范类
    r_gi = max(viol(claim, f) for f in clamp(gauge, F))
    k_cc = 1 - min(single_arm_detect(j, claim) for j in (1, 2))
    ok = r_gi <= theta_gi and k_cc <= theta_cc and obj.error <= theta_obj
    return ok, r_gi, k_cc

def demo_gauge_gate(c, grade, gauge_ok):             # IP-143
    if   c.ev == 'EV-demo*':
        ok = grade.kind == 'demo_evidence' and c.level in ('L0', 'L1')
    elif c.ev == 'EV-bimanual':
        ok = gauge_ok and c.level == 'L1'
    else:
        ok = inherited_gate(c)                        # 第 57 轮五类
    if c.irreversible and c.ev in ('EV-demo*', 'EV-bimanual', 'EV-xmodal'):
        return ('reject', 'nonphysical_on_irreversible', c)
    return ('ok', c) if ok else ('reject', 'evidence_insufficient', c)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| DEM | 查询 O(1)；离线 O(N·T) | O(N·T) | 出处不进安全界、U 按最大熵 |
| DSD | O(T·C_sim)/次回放 | O(T) | 偏离检出、shadow_gap 不承诺 |
| DGR | O(d_f^3) 零空间/区域 | O(d_f^2) | 规范不变残差保守、F 保守 |
| CCD | O(\|E\|·\|A\|) | O(\|E\|) | 单臂可检测度诚实、内部力不洗白异常 |
| DGE | O(\|σ\|) | O(\|σ\|) | 无证据类即拒、demo/bimanual 限 L1 |
| DPC | O(\|CP\|·(k_p+k_c)·(C_VOI+d_φ)+N·T) | O(\|V\|+\|σ\|+N·T) | 演示只提案、物理门不变、终止 |

**正确性定理（Provenance-Gauge Physical Soundness, PGPS 概要）**：在 A33–A40 上加 (A41) 演示出处诚实、阴影图对声明覆盖完备，未观测分支按 U 处理；(A42) 回放偏离与迁移差可检出（δ_dsd、d_demo 有界）；(A43) 双臂规范模型诚实：摩擦锥/执行器约束保守、物体见证误差≤θ_obj、内部力包络正确；(A44) 单臂可检测度诚实、κ_cc≤θ_cc。则：(i) EV-demo\* 只影响提案排序与 L1 佐证，不改变不可逆接触的失效界；(ii) EV-bimanual 仅在 L1 贡献 ≤δ_bm，且被规范不变残差与单臂可证伪双重约束；(iii) 不可逆接触失效界仍为第 57 轮物理证据界（demo/bimanual/xmodal 贡献为 0）；(iv) DPC 在 k_probes+k_cons+k_shadow 内终止于 {承诺, 绕行, L2 协商, 安全停}。

## 6. 本轮最大风险

**一句话**：本轮把"谁演示过"与"两臂都同意"分别当成"为什么安全"与"物理上正确"，最大风险是演示的反事实阴影与双臂的内部力规范自由度同时被忽视——系统会在一个自洽但从未被物理证据覆盖的分支上加速承诺；必须以阴影图、未观测即未知、规范不变残差、单臂可证伪与"不可逆接触只认物理证据"五重护栏，把演示和双臂严格限制在提案与 L1 佐证层。

### IP-141 DGR（双臂规范对账）

```python
def gauge_reconcile(f1, f2, G1, G2, F, claim, obj_witness):
    G = hstack([G1, G2])
    N = null_space(G)                     # 内部力方向：不改变物体合外力
    gauge = clamp((f1, f2) + N, F)        # 规范类，内部力可任意（限内）
    r_gi = max(viol(claim, f) for f in gauge)   # 对整类取最坏
    obj_ok = obj_witness.error <= theta_obj
    return r_gi, obj_ok, gauge

def bimanual_evidence(f1, f2, G1, G2, F, claim, obj_witness, level):
    if level != 'L1':
        return None                       # 不可逆接触不可用
    r_gi, obj_ok, gauge = gauge_reconcile(f1, f2, G1, G2, F, claim, obj_witness)
    k_cc = concealment_index(claim)
    if r_gi <= theta_gi and obj_ok and k_cc <= theta_cc:
        return 'EV-bimanual'
    return None
```

### IP-142 CCD（合作遮蔽检测与单臂可证伪）

```python
def concealment_index(claim):
    # 每个失败模式，至少要有一臂能独立检测；否则两臂一致是观测退化
    worst = 0.0
    for e in failure_modes(claim):
        d1 = single_arm_detectability(arm=1, mode=e)
        d2 = single_arm_detectability(arm=2, mode=e)
        worst = max(worst, 1.0 - min(d1, d2))
    return worst

def internal_wrench_absorbed(anomaly, f_N, F):
    # 异常能被内部力在约束内解释掉 ⇒ 不是安全证据，只是不确定性
    return exists(g in N(F), s.t. anomaly + g in F)

def require_single_arm_sufficiency(claim):
    return concealment_index(claim) <= theta_cc
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DEM | 查询 O(1)；离线 O(N·T) | O(N·T) | 出处不进安全界、U 按最大熵（A41） |
| DSD | O(T·C_sim)/次回放 | O(T) | 偏离检出、shadow_gap 不承诺（A42） |
| DGR | O(d_f^3)/区域（可预计算 O(d_f^2)） | O(d_f^2) | 规范不变残差保守、F 保守（A43） |
| CCD | O(\|E\|·\|A\|) | O(\|E\|) | 单臂可检测度诚实、内部力不洗白异常（A44） |
| DGE | O(\|σ\|) | O(\|σ\|) | 无证据类即拒、demo/bimanual 限 L1 |
| DPC | O(\|CP\|·(k_p+k_c+k_s)·(C_VOI+d_φ)+N·T) | O(\|V\|+\|σ\|+N·T) | 演示只提案、物理门不变、k_s 终止 |

**正确性定理（Provenance-Gauge Physical Soundness, PGPS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 演示出处诚实，阴影图对声明覆盖完备，未观测分支按 U 处理；**(A42)** 回放偏离与迁移差可检出（δ_dsd、d_demo 有界）；**(A43)** 双臂规范模型诚实：摩擦锥/执行器约束保守、物体见证误差≤θ_obj、内部力包络正确；**(A44)** 单臂可检测度诚实、κ_cc≤θ_cc。则：

1. **演示不改变安全界**：EV-demo\* 只进入提案排序与 L1 佐证，不可逆接触的失效界不含 δ_demo；未观测分支 U 只触发探针/绕行。
2. **双臂只做 L1 物理佐证**：EV-bimanual 在 L1 贡献 ≤δ_bm，且同时受 r_gi≤θ_gi、κ_cc≤θ_cc、物体见证一致三重约束；不可逆接触贡献为 0。
3. **不可逆接触健全性**：失效界仍为第 57 轮物理证据界
   `P(fail) ≤ δ_f + ε_meta(k) + δ_probe + ε_h(w_max) + δ_ood·α_conf`，demo/bimanual/xmodal 不进入必要证据集。
4. **终止性**：每检查点探针 ≤k_probes，共识探针 ≤k_cons，阴影探针 ≤k_shadow，DPC 在 k_probes+k_cons+k_shadow 内终止于 {承诺, 绕行, L2 协商, 安全停}。

关键：**演示给效率、共形给保底、双臂给冗余、物理给结论**。出处只买"更值得先看"，不买"更敢赌"；规范不变残差把内部力这个不可辨识自由度显式关进不确定性；单臂可证伪把"两臂都同意"从统计巧合升级为可检验的物理冗余。

## 6. 本轮最大风险

**一句话**：本轮把"谁演示过"与"两臂都同意"分别当成"为什么安全"与"物理上正确"，最大风险是演示的反事实阴影与双臂的内部力规范自由度同时被忽视——系统会在一个自洽但从未被物理证据覆盖的分支上加速承诺；必须以阴影图、未观测即未知、规范不变残差、单臂可证伪与"不可逆接触只认物理证据"五重护栏，把演示和双臂严格限制在提案与 L1 佐证层。
