# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「数据增强」×「消融实验」）

> 第 60 轮用 SGEC 打通了「场景→意图→约束→阻抗→执行→EV-exec→场景更新」的闭环，但留下两个**方法论级**裂缝：
> 1. **稀有经验的统计饥饿**：湿滑地面、软障碍、边界意图（「轻触」vs「加紧」）、ROS 高丢包等关键样本在真实数据里极其稀缺，导致 SSM/CIEC 的置信度在「最需要它正确的长尾」上反而最低；而真实执行失败代价高、不可频繁采集，无法靠「多跑几次」补数据。
> 2. **创新的必要性赤字**：IP 编号从 145 涨到 160，组件层层叠加，却没有任何机制回答「删掉这个组件会怎样」。没有消融，就没有证据说明某个模块不是「叙事装饰」；这与本项目「一切结论都要有证据链」的初衷相矛盾。
> 本轮把「数据增强」用于**扩展不可采样的经验**，把「消融实验」从「事后验证手段」上升为**创新准入闸门**——只有通过消融检验的组件才配进入默认流水线。核心不变量：增强只进先验通道、绝不进证据通道；组件只凭必要性证书入场。

## 0. 直觉与动机

**灵感 1（数据增强 → 物理约束生成式增强 PCGA）**
直觉：机器人接触数据的「长尾」不是图像里的语义长尾，而是**接触动力学参数空间的长尾**。与其拍一万张湿滑地面的照片，不如在**物理约束下**生成一万条「符合接触力学」的力-位轨迹：对摩擦系数 μ、接触刚度 k_c、阻尼 c、振动频率 f_v、传感器噪声 σ 做域随机化，再用接触动力学残差 r = ‖M(q)q̈ + C(q,q̇)q̇ + g(q) − JᵀF‖ 把「物理上不可能」的合成样本剔除。关键洞见：**增强的可信度不由生成器决定，而由物理残差 r 决定**。

**灵感 2（数据增强 → 困难负例意图增强 HNIA）**
直觉：意图识别的错误不发生在「慢点 vs 危险」，而发生在**语义邻域**：「轻触」与「加紧」字面上都会出现「用力/接触」；「稳定」与「慢点」都会出现「别动」。这些是**困难负例**。用标签保持的改写（同义句、语序、口语化、否定前缀）扩增正例，用「最小对比对」构造负例：只改一个关键词，标签却相反。关键洞见：**增强的目标不是让模型见得多，而是把决策边界推离危险邻域**。

**灵感 3（数据增强 → 反事实失效轨迹增强 CFEA）**
直觉：真实的「K_safe 选错导致打滑/过冲」是灾难，不能靠真实试错采集。于是**反事实地**扰动执行参数：把第 60 轮真实跑通的 EV-exec 轨迹中的 K_safe、v_max、F_max 做受控偏移，用辨识出的局部动力学模型外推「如果当时选了另一个 K 会怎样」，得到**近失事（near-miss）轨迹**。这些轨迹**不是证据**，只是「失效边界的训练材料」。

**灵感 4（关键洞见：增强只进先验通道，绝不进证据通道 → 溯源门控 APG）**
直觉：本项目的核心资产是 EV-exec 证据链。数据增强可以改变**信念**，但绝不能改变**事实**。因此把样本分成两个通道：
- **学习/先验通道**：接受 REAL 与 AUG，按保真度 f 与物理残差 r 加权；
- **证据通道**：只接受 REAL，AUG 的证据权重恒为 0。
每个样本携带**溯源标签** prov = (type, generator_id, fidelity, physics_residual)。关键洞见：**「增强」与「伪造」只差一个溯源字段**——只要 AUG 能写进 EV-exec，整个证据链就失去意义。

**灵感 5（消融实验 → 消融门控准入 AGA + 因子消融 FAD）**
直觉：每轮都在加组件，但没人删过组件。把消融从「论文里的表格」变成**准入闸门**：新组件 IP-c 只有在「移除它导致某个预注册指标显著退化、且没有安全指标显著退化」时才被接纳，并生成**必要性证书** N_c。进一步用**因子消融设计**同时消融多个组件与多种增强策略，估计主效应 β_i 与交互效应 β_ij，专治「两个组件单独都有用、合在一起却互相抵消」的隐性冗余。

**灵感 6（合流 → 增强-证据闭环 AECL+ 与 A-Budget）**
直觉：PCGA/HNIA/CFEA 扩充先验 → APG 门控 → SERC 执行 → 真实 EV-exec 回流 → 周期性 AGA/FAD 审计 → 淘汰或接纳组件。预算上新增 B_aug（生成/保真校验/合成-真实差距估计）与 B_abl（消融运行次数、统计功效预算、重训练成本），并让 VOI 显式扣除「假准入风险」。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（物理约束生成式增强 PCGA）** 增强算子 A_phys = (G_phys, C_phys, R_phys)：
- **参数域随机化**：θ_aug ~ p(θ)，θ = (μ, k_c, c, f_v, σ, m_load)，支撑集由物理可行域 Θ_phys 限制；
- **生成器**：x_aug = G_phys(z; θ_aug)，z 为种子轨迹（真实或参数化）；
- **物理约束**：样本被接纳当且仅当
  r(x_aug) = ‖M(q)q̈ + C(q,q̇)q̇ + g(q) − JᵀF‖_Λ ≤ r_max，
  且能量约束 0 ≤ ∫F·q̇ dt ≤ E_in(t) 成立；
- **增强先验**：π_scene^aug(K|z) = Σ_{s∈D_aug(z)} w_s · N(K; K_s, Σ_s)，w_s 由定义 164 给出；
- **合成-真实差距**：Δ_s2r(φ) = sup_{φ∈Φ} |E_{D_real}[φ] − E_{D_aug}[φ]|，用于门控与风险上界。

**定义 162（困难负例意图增强 HNIA）** 意图增强三元组 H = (T_pos, T_neg, d_min)：
- **标签保持正例**：T_pos(I) = {t | 语义等价(t, I) ∧ label(t)=I}，含同义改写、语序变换、口语填充；
- **最小对比负例**：T_neg(I) = {t' | t' 与某 t∈T_pos(I) 仅差一个关键词，且 label(t') ≠ I}，例如
  「轻一点」→ 正例 I=light_touch；「重一点」→ 负例 I=tighten；
- **边界间隔**：d_min = min_{t∈T_pos, t'∈T_neg} D_emb(t, t')，增强目标是最大化 d_min 且保持标签一致；
- **危险方向权重**：误判代价非对称，C(light_touch→tighten)、C(stable→speed)、C(slow→danger) 的代价权重为普通方向的 ρ_danger ≥ 5 倍。

**定义 163（反事实失效轨迹增强 CFEA）** 给定真实轨迹 τ_real = {(x_t, u_t)} 与局部动力学模型 f̂：
- **反事实扰动**：τ_cf = f̂(τ_real; δK, δv, δF)，δ 从「安全壳外、失效壳内」的环带采样；
- **近失事标签**：y_cf = 1[M_safe(τ_cf) < 0]，M_safe 由力/位/速度的联合约束定义；
- **可信区**：反事实仅在 f̂ 的置信域 Ω_cf = {δ | Var[f̂(τ;δ)] ≤ σ²_max} 内有效，出域样本丢弃；
- **使用限制**：CFEA 样本只能进入失效边界学习与消融，**不得**进入 EV-exec。

**定义 164（增强溯源门控 APG）** 溯源类型系统 P 与双通道语义：
- **样本**：s = (x, y, prov)，prov(s) = (type ∈ {REAL, AUG}, gen_id, f, r)，f∈[0,1] 保真度，r 物理残差；
- **权重函数**：w(s) = 1 若 type=REAL；w(s) = f · exp(−λ_r · r) 若 type=AUG；
- **通道分离**：
  - 先验通道 D_prior = D_real ∪ {s∈D_aug | f ≥ f_min ∧ r ≤ r_max ∧ Δ_s2r ≤ τ_s2r}；
  - 证据通道 D_ev = {s | type(s)=REAL}，且对任意 s∈D_aug，w_ev(s) ≡ 0；
- **污染率**：C_rate = |{s∈D_ev : type(s)=AUG}| / max(1, |D_ev|)，理想值 C_rate = 0；
- **注入不可能性**：证据写入 API 只接受 type=REAL 且带硬件签名/HMAC 的样本，AUG 无签名路径。

**定义 165（消融门控准入 AGA）** 组件 c 的准入判定 A(c) = (m_c, δ_c, q, S_safe)：
- **预注册**：实验前固定主指标 m_c 与最小效应 δ_c，避免事后挑选指标（p-hacking）；
- **判定规则**：
  A(c) = 1 ⇔ [Δ_{m_c}(remove c) ≥ δ_c 且 p_{m_c} ≤ q/F（BH-FDR）] ∧ [∀s∈S_safe：remove c 不导致显著退化]；
- **必要性证书**：N_c = (m_c, effect_size, CI_95%, p, remove-c 运行配置)，只有 A(c)=1 的组件进入默认流水线；
- **退役规则**：若 A(c)=0 但 c 存在显著负交互（见定义 166），移入「实验池」而非直接删除，保留复现性。

**定义 166（因子消融设计 FAD）** 设组件/策略因子 X_1..X_k ∈ {0,1}（1=保留）：
- **响应模型**：y = β_0 + Σ_i β_i X_i + Σ_{i<j} β_{ij} X_iX_j + ε；
- **设计**：k≤5 用全因子 2^k；k>5 用分辨度 IV 的部分因子设计，保证主效应不与二阶交互混杂；
- **效应解释**：β_i 为主效应；β_{ij} < 0 且显著 ⇒ 组件 i、j 存在**负交互（冗余/冲突）**；
- **抽象泄漏检验**：leak_gap = E_{D_aug}[conf] − E_{D_real}[acc]；若 leak_gap > τ_leak，判定「合成自洽」风险，拒绝相关增强。

**定义 167（增强-证据耦合闭环 AECL+）** 算子 AECL+(M, scene, intent, δ_f_req)：
```
① Collect: D_real ← recent EV-exec（含硬件签名）
② Augment: D_aug ← PCGA(D_real) ∪ HNIA(intent_logs) ∪ CFEA(D_real, f̂)
③ Gate:    D_prior ← APG(D_real, D_aug)；D_ev ← REAL only
④ Update:  π_scene^aug, ϕ_intent^aug ← train(D_prior)
⑤ Execute: (z_scene, K_safe, EV-exec, Cert) ← SERC(M, scene, intent, δ_f_req)
⑥ Evidence: D_ev.append(EV-exec)；APG.assert(type(EV-exec)=REAL)
⑦ Audit:   每 N_audit 次执行运行 AGA/FAD，更新准入集合 A_admit
⑧ Retire:  A_admit 中失效组件移入实验池
⑨ Return:  (z_scene, K_safe, EV-exec, Cert, A_admit, S2R_gap)
```

**定义 168（A-Budget 与 PCE+++++）** B = (B_aug, B_abl, B_cog, B_exec)：
- **B_aug** = (Generation_cost, Fidelity_check_cost, S2R_estimation_cost)
- **B_abl** = (Ablation_runs, Statistical_power, Retrain_cost)
- **VOI 扩展**：
```
voi_aug(π) = VOI_cog(π) + Value_aug(D_prior) − cost_aug − cost_abl − Risk_false_admit
cost_aug   = λ_gen·|D_aug| + λ_fid·|D_aug|·Fidelity_check + λ_s2r·S2R_estimation
cost_abl   = λ_run·|Ablation_runs| + λ_retrain·Retrain
Risk_false_admit = (1 − power)·Cost_bad_component
```
- 若 B_aug < θ_aug：退化为「仅真实数据」训练；若 B_abl < θ_abl：冻结默认流水线，不接纳新组件（保守优先）。

## 2. 关键算法伪代码

### IP-161 PCGA（物理约束生成式增强）

```python
def pcga_augment(seed_traces, n_aug, theta_bounds, dyn_model):
    aug = []
    for _ in range(n_aug):
        theta = sample_uniform(theta_bounds)          # mu, k_c, c, f_v, sigma
        z = random_choice(seed_traces)
        x = G_phys(z, theta)
        r = dyn_model.residual(x)                     # 接触动力学残差
        if r <= R_MAX and dyn_model.energy_ok(x):
            f = fidelity(x, seed_traces)              # 1 - 归一化 MMD，∈[0,1]
            aug.append(Sample(x, prov=('AUG', GEN_ID, f, r)))
    return aug
```

### IP-162 HNIA（困难负例意图增强）

```python
DANGER_PAIRS = {('light_touch', 'tighten'), ('stable', 'speed'), ('slow', 'danger')}

def hnia_augment(intent_logs, embed, min_gap=0.15):
    pos, neg = [], []
    for I, utt in intent_logs:
        for t in paraphrase(utt):                     # 标签保持
            pos.append((t, I))
        for t in minimal_contrast(utt):               # 最小对比负例
            y = label(t)
            if y != I:
                neg.append((t, y))
    keep = []
    for t, y in pos + neg:
        danger = any((y, y2) in DANGER_PAIRS for y2 in DANGER_PAIRS_TARGETS)
        if margin(embed, t) >= min_gap or danger:
            keep.append((t, y, danger))
    return keep
```

### IP-164 APG（溯源门控，双通道）

```python
class ProvenanceGate:
    def __init__(self, f_min, r_max, tau_s2r):
        self.f_min, self.r_max, self.tau_s2r = f_min, r_max, tau_s2r

    def split(self, samples, real_stats):
        prior, evidence = [], []
        for s in samples:
            if s.prov.type == 'REAL':
                prior.append(s); evidence.append(s)
            else:
                ok = (s.prov.f >= self.f_min
                      and s.prov.r <= self.r_max
                      and s2r_gap(s, real_stats) <= self.tau_s2r)
                if ok:
                    prior.append(s)          # 只进先验通道
                # 无论是否接纳，AUG 永不进入 evidence
        return prior, evidence

    def assert_evidence(self, sample):
        assert sample.prov.type == 'REAL'
        assert verify_hmac(sample)           # 硬件签名，AUG 无此路径
```

### IP-165/166 AGA + FAD（消融门控与因子设计）

```python
def ablation_gate(component, metrics, delta_req, alpha=0.05):
    effects = {m: run_ablation(remove=component, metric=m)
               for m in metrics.primary}
    p_adj = benjamini_hochberg([e.p for e in effects.values()], alpha)
    admitted = any(e.delta >= delta_req[m] and p_adj[m] <= alpha
                   for m, e in effects.items())
    safe = all(not e.significant_degradation for e in metrics.safety)
    cert = NecessityCert(component, effects, p_adj, safe)
    return (admitted and safe), cert

def factorial_ablation(factors, response, resolution=4):
    design = fractional_factorial(len(factors), resolution)   # 分辨度 IV
    y = [response(cfg) for cfg in design]
    beta = ols(design, y)        # beta_i 主效应，beta_ij 交互效应
    leak = mean_real_acc - mean_aug_conf
    return beta, leak
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PCGA | O(n_aug·(G_phys + residual)) | O(|D_aug|) | r ≤ r_max 的样本物理可行；Δ_s2r ≤ τ_s2r |
| HNIA | O(|U|·改写 + \|U\|²·D_emb)，ANN 降为近线性 | O(|D_aug|) | 危险方向误判率下降 ≥ 50% |
| CFEA | O(|τ|·f̂) / 轨迹 | O(Ω_cf) | 近失事覆盖提升，真实损伤 = 0 |
| APG | O(|D|) 门控；证据写入 O(1) | O(|D|) | **C_rate = 0**；证据链仅含 REAL |
| AGA | O(R_runs·|metrics|) | O(R_runs) | 假准入 ≤ q（BH-FDR） |
| FAD | O(2^{k−p}) 次运行 | O(2^{k−p}) | 主效应与二阶交互可识别 |
| AECL+ | 复用 SERC + 周期审计 | 复用 | 增强不污染证据；准入集合单调可退役 |

**正确性定理（AEGIS）**：假设 A66–A70 成立。
- **(A66)** PCGA 满足 r ≤ r_max 的样本具备接触动力学可行性；
- **(A67)** 证据写入路径的硬件签名不可伪造，AUG 无签名通道；
- **(A68)** 消融实验达到预设统计功效 1−β，指标已预注册；
- **(A69)** 当 Δ_s2r ≤ τ_s2r 时，augmented prior 与 real prior 的 TV 距离 ≤ ε_aug；
- **(A70)** B_aug、B_abl 单调消耗，任一耗尽触发保守退化。

则：
1. **证据纯净性**：C_rate = 0，EV-exec 不因增强而失真（由 A67 保证）。
2. **增强收益有界性**：Δ_s2r ≤ τ_s2r ⇒ ‖π_aug − π_real‖_TV ≤ ε_aug ⇒ 增强带来的先验偏移有上界，不会出现「合成自洽」压过真实分布（由 A66、A69 保证）。
3. **准入可靠性**：P(假准入) ≤ q；被接纳组件均持有必要性证书 N_c（由 A68 保证）。
4. **预算安全性**：B_aug 耗尽 ⇒ 仅真实数据；B_abl 耗尽 ⇒ 冻结流水线（由 A70 保证）。

**对照设计（关键）**：E192 必须包含**安慰剂增强**（随机噪声增广，样本量与 PCGA 相同）。若 PCGA 相对安慰剂无显著优势，则说明收益只来自「数据量」而非「物理约束」，PCGA 应在 AGA 中被判为不必要。

## 5. 本轮最大风险

**一句话**：若合成-真实差距估计失效且溯源门控被绕过（AUG 混入 EV-exec），系统会陷入「合成自洽」——在合成数据上置信度极高、在真实执行中灾难性失效；而消融若缺乏预注册与统计功效控制，又可能把「偶然显著」误收为「必要组件」，让创新台账继续膨胀。必须用「证据通道只收 REAL + 硬件签名」「安慰剂增强对照」「预注册 + FDR + 功效分析」三道硬护栏，确保增强只改变信念、消融只裁决必要性。

# 第 61 轮产物 · 创新点清单 v1：AEGIS（增强-证据门控完整性体系：物理约束增强 × 困难负例 × 溯源双通道 × 消融准入，PCGA×HNIA×CFEA×APG×AGA×FAD×AECL+×A-Budget）

> 承接第 60 轮 IP-153~160（SSM×CIEC×EPIR×SERC×PCE++++×SIC×CESC×EPIR-Protocol）。本轮回答两个方法论问题：**稀有经验如何扩展**、**组件如何证明必要**。答案是把「数据增强」限制在**先验通道**、把「消融实验」提升为**准入闸门**，并用溯源门控保证「增强只改信念、不改事实」。

## 2. 关键算法伪代码

### IP-161 PCGA（物理约束生成式增强）

```python
def pcga_augment(seed_traces, n_aug, theta_bounds, dyn_model):
    aug = []
    for _ in range(n_aug):
        theta = sample_uniform(theta_bounds)
        z = random_choice(seed_traces)
        x = G_phys(z, theta)
        r = dyn_model.residual(x)
        if r <= R_MAX and dyn_model.energy_ok(x):
            f = fidelity(x, seed_traces)
            aug.append(Sample(x, prov=('AUG', GEN_ID, f, r)))
    return aug
```

### IP-162 HNIA（困难负例意图增强）

```python
DANGER_PAIRS = {('light_touch', 'tighten'), ('stable', 'speed'), ('slow', 'danger')}

def hnia_augment(intent_logs, embed, min_gap=0.15):
    pos, neg = [], []
    for I, utt in intent_logs:
        pos += [(t, I) for t in paraphrase(utt)]
        neg += [(t, label(t)) for t in minimal_contrast(utt) if label(t) != I]
    keep = []
    for t, y in pos + neg:
        danger = any((y, y2) in DANGER_PAIRS for y2 in DANGER_TARGETS)
        if margin(embed, t) >= min_gap or danger:
            keep.append((t, y, danger))
    return keep
```

### IP-164 APG（溯源门控，双通道）

```python
class ProvenanceGate:
    def __init__(self, f_min, r_max, tau_s2r):
        self.f_min, self.r_max, self.tau_s2r = f_min, r_max, tau_s2r

    def split(self, samples, real_stats):
        prior, evidence = [], []
        for s in samples:
            if s.prov.type == 'REAL':
                prior.append(s); evidence.append(s)
            elif (s.prov.f >= self.f_min and s.prov.r <= self.r_max
                  and s2r_gap(s, real_stats) <= self.tau_s2r):
                prior.append(s)              # 仅先验通道
        return prior, evidence              # AUG 永不进入 evidence

    def assert_evidence(self, sample):
        assert sample.prov.type == 'REAL' and verify_hmac(sample)
```

### IP-165/166 AGA + FAD（消融门控与因子设计）

```python
def ablation_gate(component, metrics, delta_req, alpha=0.05):
    effects = {m: run_ablation(remove=component, metric=m)
               for m in metrics.primary}
    p_adj = benjamini_hochberg([e.p for e in effects.values()], alpha)
    admitted = any(e.delta >= delta_req[m] and p_adj[m] <= alpha
                   for m, e in effects.items())
    safe = all(not e.significant_degradation for e in metrics.safety)
    return (admitted and safe), NecessityCert(component, effects, p_adj, safe)

def factorial_ablation(factors, response, resolution=4):
    design = fractional_factorial(len(factors), resolution)   # 分辨度 IV
    y = [response(cfg) for cfg in design]
    beta = ols(design, y)       # beta_i 主效应；beta_ij 交互效应
    return beta, mean_real_acc - mean_aug_conf   # 后者为 leak_gap
```

### IP-167 AECL+（增强-证据耦合闭环）

```python
def augmented_evidence_loop(M, scene, intent, delta_f_req, n_audit):
    D_real = collect_signed_ev_exec(M)
    D_aug = (pcga_augment(D_real, N_AUG, THETA_BOUNDS, M.dyn_model)
             + hnia_augment(M.intent_logs, M.embed)
             + cfea_augment(D_real, M.dyn_model))
    D_prior, D_ev = M.apg.split(D_real + D_aug, real_stats(D_real))
    train_priors(M, D_prior)

    M, z, K, ev, cert = scenario_perception_evolution_loop(
        M, scene, intent, delta_f_req)
    M.apg.assert_evidence(ev)
    D_ev.append(ev)

    if M.step % n_audit == 0:
        M.admit = [c for c in M.candidates if ablation_gate(c, M.metrics, M.delta)[0]]
        M.beta, M.leak = factorial_ablation(M.factors, M.response)
    return M, z, K, ev, cert, M.admit, M.leak
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| PCGA | O(n_aug·(G_phys + residual)) | O(\|D_aug\|) | r ≤ r_max 物理可行 |
| HNIA | 近线性（ANN 检索） | O(\|D_aug\|) | 危险方向误判 ↓ ≥ 50% |
| CFEA | O(\|τ\|·f̂) / 轨迹 | O(Ω_cf) | 真实损伤 = 0 |
| APG | O(\|D\|) 门控 | O(\|D\|) | C_rate = 0 |
| AGA | O(R·\|metrics\|) | O(R) | 假准入 ≤ q |
| FAD | O(2^{k−p}) | O(2^{k−p}) | 主效应/二阶交互可识别 |
| AECL+ | 复用 SERC + 审计 | 复用 | 增强不污染证据 |

**正确性定理（AEGIS）**：若 A66–A70 成立，则
1. 证据纯净性：C_rate = 0（A67 签名注入不可能）。
2. 增强收益有界：Δ_s2r ≤ τ_s2r ⇒ ‖π_aug − π_real‖_TV ≤ ε_aug（A66、A69）。
3. 准入可靠：P(假准入) ≤ q（A68 BH-FDR），且每个被接纳组件持 N_c。
4. 预算安全：B_aug 耗尽 ⇒ 仅真实数据；B_abl 耗尽 ⇒ 冻结流水线（A70）。

## 5. 本轮最大风险

**一句话**：若合成-真实差距估计失效且溯源门控被绕过（AUG 混入 EV-exec），系统会陷入「合成自洽」——在合成数据上置信度极高、在真实执行中灾难性失效；而消融若缺乏预注册与统计功效控制，又可能把「偶然显著」误收为「必要组件」，让创新台账继续膨胀。必须用「证据通道只收 REAL + 硬件签名」「安慰剂增强对照」「预注册 + FDR + 功效分析」三道硬护栏，确保增强只改变信念、消融只裁决必要性。
