# 第 3 轮（承接第 2 轮 ToolGauge；灵感循环第 1 轮；本轮灵感：「社会影响」×「用户体验」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440）。
> 本轮纪律：**在 ToolGauge 之上加两层，而不是推倒重来**——S-Box 管「修复经验如何在机队/操作员之间传播」，
> X-Box 管「修复结论如何被人类正确理解与行动」；6C 骨架、MODGAUGE 五不变式、严格退化链全部保留。
> 同时审计 ToolGauge 的四个结构性盲点：单机假设、来源不可辨、解释只服务审计不服务信任、缺少人的反馈回路。

## 三位一体映射（升级而非重写）

| 灵感词 | ToolGauge 对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| 社会影响（social influence） | 单机 6C；P-Quarantine 只看自己 | **S-Box + Rep-Box**：来源图、独立性折扣、社会影响预算、分级采纳 | 修复经验应在机队/操作员间传播，但相关证据不能当独立共识 |
| 用户体验（user experience） | RepairCert 只服务审计 | **X-Box + H-Cal + IPS-Feedback**：人类信任校准、注意力预算、VoI 门、渐进披露 | 解释不是越多越好；过载、误导、不可行动都是安全问题 |
| 二者耦合 | 无显式模型 | **信任回路 + 反事实社会审计** | 社会证明与用户接受会互相强化，必须在数值路径上把回路增益压到 0 |

**核心命题**：把 ToolGauge 的「单机、无来源、只服务审计」升级为
「**社会证据可控传播 + 人类信任可学校准 + 数值契约路径不变**」：
社会影响只以**信息性社会影响（ISI）**进入数值先验，**规范性社会影响（NSI）永不进入**；
用户体验层只改变披露策略、语言主张与信任线索，**永不改变** `u_s / χ_R / M_ver`；
二者通过信任回路耦合，但回路在数值路径上的增益被设计为 **0**（信誉只由独立真值更新，流行度不是证据）。

**不变式保持声明**：
- MODGAUGE 五不变式全部保留；
- 新增两条**层间**不变式：**ENS**（认知-规范分离，定义 433）与 **XC-一致性**（体验契约，定义 439/441）；
- **严格退化链延长**：TrustGauge 失效（社会层不可用 / 全为 NSI / 独立性审计失败 / 体验契约不可满足）
  ⇒ 退回 ToolGauge 单机 6C ⇒ 再失效退回 LeanGauge ⇒ 再失效退回 MODGAUGE。
  社会层与体验层都是增强项，不是依赖项。

## 0. 直觉与动机

### 语义澄清：「社会影响」的两种读法

中文「社会影响」同时对应两个英文概念，二者都不可回避：

- **social influence（影响）**：同伴、权威、流行度如何改变一个智能体的信念与行为；
- **social impact（后果）**：系统的外部性、公平、责任与对未同意第三方的风险转移。

本方案把前者放进 **S-Box**（社会证据传播），把后者放进 **X-Box 的公平与自主性条款**（定义 446），
二者在「信任回路」处汇合：**社会影响可以传播证据，但不能制造证据；用户体验可以降低认知负担，但不能制造信任。**

### 灵感 1（社会影响 → 修复经验的社会传播与「假共识」）

直觉：ToolGauge 的修复证书是孤岛。现实中，一个机队里的机器人、一个班次里的操作员会互相参考：
A 修过的盲区，B 想直接复用；B 的接受又会成为 C 的社会证明。这能省探测成本，但也会把**相关误差**
当成独立证据——如果 A、B、C 共享同一个预训练先验、同一批传感器或同一个仿真环境，
他们的「共识」只是同一个错误的三个副本。社会心理学的经典区分在这里恰好是解药：
**信息性社会影响（ISI）**是「因为证据而相信」，**规范性社会影响（NSI）**是「因为压力/流行/权威而相信」。
安全关键系统只能让 ISI 进入数值层；NSI 只能进入展示层，且必须标注为非证据性。

工程上，我们把每条修复证书扩展为带**来源闭包（provenance DAG）**的社会信号，
用「共享原因系数」估计证据相关性，用**设计效应** `n_eff = n/(1+(n-1)ρ)` 修正过度计数，
用**社会影响预算** `τ_max < 1` 保证本地证据永远保留多数权重，
再用**社会采纳门（SAG）**把「社会捷径」限制在非安全关键、来源独立、且通过廉价抽检的场景。
社会影响不是「把别人的后验抄过来」，而是「把别人的证据按独立性折算后当作先验」。

### 灵感 2（用户体验 → 把人的注意力与信任当作一等约束）

直觉：ToolGauge 的 RepairCert 是为审计员设计的，不是为班次中的操作员设计的。
把 20 条回执和 KL 数扔给人，会造成三种失败：

1. **过载**：真正重要的异常被淹没在低价值通知里；
2. **误导**：把机器 σ 直接当成人类可理解的置信度；把「3 个同伴也接受」当成证据；
3. **不可行动**：知道有问题，但不知道怎么回滚、找谁负责、如何复核。

用户体验的核心不是「更漂亮的解释」，而是把**注意力、信任、可逆性**当作约束：
只在信息价值超过注意力成本时打断；置信度必须经过独立的**人类校准层（H-Cal）**；
每个主张可下钻到回执；每个动作可回滚；反馈必须做**选择偏差校正**（用户只对系统选择展示的样本给反馈）。
一句话：**机器后验 `σ` 不等于人类置信度 `c`；解释的说服力必须被证据上限夹紧。**

### 灵感 3（耦合 → 信任回路与反事实审计）

直觉：社会影响与用户体验会耦合出一个正反馈回路：
社会证明 → 接受 → 信誉 → 更多社会证明；
解释的自信外观 → 过度信任 → 更少独立核查 → 反馈更偏。
这个回路可以让一个错误修复获得**制度性信任**：它被很多人接受、被很好看的证书解释、又很少有人复核。
因此本方案不是简单「加一个社交推荐」和「加一个解释面板」，而是同时加三样东西：

- **回路切断**：信誉只由独立真值更新（不用接受率）；流行度不进入信任计算（PNE）；
- **归因审计**：记录每次社会影响事件，并在影子模式重放「去掉社会影响」的反事实；
- **公平约束**：分组校准、风险转移检查、操作员自主性（可关闭社会线索、设置信任上限）。

## 1. 形式化定义（增量：定义 432–448）

**定义 432（修复来源图与证据独立性）**
每条修复证书 `c` 扩展来源闭包
`Anc(c) = (agent, model_version, pretrain_episode, sensor_set, environment, parent_certs)^*`，
构成 provenance DAG。定义共享原因系数
`ρ(c,c') = Σ_{a∈Anc(c)∩Anc(c')} ω(a) / min(Σ_{a∈Anc(c)}ω(a), Σ_{a∈Anc(c')}ω(a)) ∈ [0,1]`，
其中 `ω(a)` 是祖先 `a` 的证据质量（有效样本数/信息量）。
`indep_ε(c,c') ⇔ ρ(c,c') ≤ ε_ρ`。`ρ` 是对两条证据误差相关性的保守上界；
部署前用留出数据校准 `ε_ρ`，运行时用来源图在线计算。

**定义 433（社会信号与 ENS 不变式）**
从 `j` 到 `i` 关于盲区 `s` 的社会信号
`m_{j→i}(s) = (q_j(u_s), C_j(s), basis, Anc_j, Rep_j)`，`basis ∈ {ISI, NSI}`。
数值准入：
`adm(m) ⇔ basis=ISI ∧ (∀c∈C_j: valid(c)) ∧ indep_ε(C_j, C_i) ∧ Rep_j ≥ Rep_min ∧ s ∉ SafetyCritical`。
**ENS（认知-规范分离）不变式**：任何数值自然参数更新中不得出现 `basis=NSI` 的项；
NSI 只允许出现在展示层，且必须标注「非证据性」。这是「语言不进入数值通道」的社会版。

**定义 434（锚定社会后验）**
设本地自然参数 `(h_i, Λ_i)`，社会信号的自然参数 `(h_j, Λ_j)`，权重 `w_j`。
先做**精度封顶**：
`Λ_soc = Σ_j w_j Λ_j`，`Λ_soc^eff = Λ_soc · min(1, tr Λ_i / tr Λ_soc)`，
`h_soc^eff = Λ_soc^eff · μ_soc`，其中 `μ_soc = Λ_soc^{-1} Σ_j w_j h_j`。
再取
`Λ_i^+ = (1-τ_i)Λ_i + τ_i Λ_soc^eff`，
`h_i^+ = (1-τ_i)h_i + τ_i h_soc^eff`，
`τ_i = min(τ_max, τ_max·n_eff/(n_eff+κ))`，`τ_max < 1`。
均值是 `μ_i` 与 `μ_soc` 的精度加权凸组合；社会权重（按迹）
`w_soc = τ_i·trΛ_soc^eff / ((1-τ_i)trΛ_i + τ_i·trΛ_soc^eff) ≤ τ_i ≤ τ_max`，
本地证据至少保留 `1-τ_max` 的权重。社会层只产出先验，不直接写契约。

**定义 435（有效样本量与过度计数惩罚）**
`m` 条等精度、两两相关性 `ρ̄` 的独立观测，朴素精度为 `mI`，真实精度为 `mI/(1+(m-1)ρ̄)`；故
`n_eff = m / (1+(m-1)ρ̄)`，`δ = n_eff/m`。社会分量精度乘以 `δ`。
`ρ̄=1` 时 `n_eff=1`（所有副本只算一条证据），`ρ̄=0` 时 `n_eff=m`。
非等精度时用保守 design-effect 上界
`n_eff = (Σ_j√n_j)^2 / (Σ_j n_j + 2Σ_{j<k}ρ_{jk}√(n_j n_k))`。

**定义 436（社会采纳门 SAG，分级）**
- **Tier 0（禁止）**：`s` 为安全关键；或仅有 NSI；或独立性审计失败。
- **Tier 1（仅先验，默认）**：社会后验只能影响 `H_s` 与探测排序，契约写入前仍须本地探测。
- **Tier 2（捷径）**：允许跳过完整本地探测，当且仅当
  (a) `≥2` 条来源独立 ISI；(b) `Rep_j ≥ Rep_hi`；(c) 成对 `ρ ≤ ρ_max`；
  (d) `|μ_soc − μ_loc| ≤ ε_agr`；(e) 廉价 spot-check `|z| ≤ ε_spot`；(f) XC 中的人工授权。
任一条件失败 ⇒ 自动降级到 Tier 1；Tier 只降不升（除重新取证）。
每次 Tier 2 采纳生成**社会采纳证书**，进入账本。

**定义 437（双时标信誉与反 Sybil）**
`Rep_j(t+1) = (1-α_rep)Rep_j(t) + α_rep·g(outcome_j)`，
`outcome_j` 必须是**交叉验证后的真值结果**，不是用户接受率；`α_rep ≪` 后验更新率。
新代理 `Rep_0` 较低；信誉不可转让、不可购买、**不因被引用而上升**（切断 popularity→trust 通道）。
信任权重 `w_{ij} ≤ Rep_j`；部署前在 endorsement/provenance 图上做稠密子图与环检测以发现串谋。

**定义 438（人类信任状态与校准指标）**
`b_h` 为人类对「修复正确」的主观概率；系统给出信任线索 `c ∈ [0,1]`。定义
`ECE_h = E[|c − P(correct|c)|]`；
`OT = E[(b_h − P(correct))^+]`（过度信任）；`UT = E[(P(correct) − b_h)^+]`（信任不足）。
`b_h` 不作可直接观测假设：用预注册的行为诱因（接受/复核选择）与经验证量表估计，并报告测量误差。
**关键**：机器后验 `σ` 不能直接当人类置信度；`c` 必须经过独立的人类校准层 H-Cal。

**定义 439（体验契约 XC）**
`XC = (B_attn, ε_ECE, ε_OT, ε_UT, L_exp, τ_lat, recourse, ε_explore, PNE, equity)`：
- `B_attn`：每操作员每班次的注意力预算；`L_exp`：单次解释复杂度上限；
- `τ_lat`：修复到用户可见状态的时延上限；`recourse`：回滚/否决/降级；
- `ε_explore`：探索配额（保证反馈正性）；`PNE`：popularity-is-not-evidence；
- `equity`：分组校准约束 `max_g OT_g ≤ ε_OT^max`，且社会捷径不得把风险转移给未同意的第三方。
XC 是 IV-Contract / TB-Contract 的体验层细化；失败 ⇒ 保守披露模式，不改变数值行为。

**定义 440（解释的价值-注意力门）**
对候选解释 `e` 与人类决策问题 `(A,U)`：
`VoI(e) = E_{y~p(y|e)}[max_a E[U(a,y)|e]] − max_a E[U(a,y)]`；
`disclose(e) ⇔ VoI(e) − κ(e) ≥ γ_X ∧ B_attn ≥ κ(e)`。
`κ(e)` 是阅读+决策的注意力成本（可用眼动/响应时延标定）。
这是定义 419 增益注 `β` 的体验层类比：`β` 管「这条探测值不值」，`VoI` 管「这次打断值不值」。

**定义 441（渐进披露一致性与可逆闭包）**
披露层级 `ℓ=0..3`：状态+建议动作 / 证书摘要 / 回执 / 回放。
`Claims(0) ⊆ Claims(1) ⊆ …`；每层数值主张必须引用有效回执（继承定义 423）；
任一层不得与另一层矛盾；层 `ℓ` 的每个建议动作必须在 `≤ℓ+1` 层有登记的回滚路径。
**Refinement Consistency** 与 **Recourse Closure** 可机器检查。

**定义 442（选择性反馈与 IPS 校正）**
反馈 `f` 只在被披露的样本上出现，披露策略 `π(e|context)` 造成 MNAR。
用逆倾向加权 `w = min(1/π, w_max)`，
`ECE_h^IPS = Σ w_i|c_i−f_i| / Σ w_i`。
探索配额 `ε_explore` 保证低风险情境下 `π ≥ ε_explore`（正性条件）；
否则校准只在披露支撑集上可识别，支撑集外可任意偏。
**没有探索的 UX 优化会系统性地高估自己的校准度。**

**定义 443（信任回路与回路增益）**
接受度 `A`、信誉 `Rep`、披露 `D` 的耦合：
`g = (∂A/∂Rep)(∂Rep/∂A) + (∂A/∂D)(∂D/∂A)`。
本方案用「信誉只由独立真值更新」令第一项为 0，用 PNE 令第二项中的 popularity 通道为 0；
若部署坚持用接受率更新信誉，或按接受率优化披露，则必须在线监测 `g` 并要求 `g < 1`。

**定义 444（社会影响账本）**
`L_soc` 记录每次影响事件：
`(t, i, j, s, basis, Anc, τ, D_KL(q_i^+‖q_i), outcome, counterfactual)`。
账本只追加、哈希链防篡改，用于归因、事故复盘和 E451。

**定义 445（反事实社会审计）**
对每次修复，在影子模式重放「去掉社会信号」的版本：
`Δ_soc = D_KL(q_with‖q_without)`，`Δ_perf = perf_with − perf_without`。
若 `Δ_soc > κ_KL` 且 `Δ_perf < 0`，或 Tier 2 采纳后 `Δ_perf` 不佳，则标记为「有害社会影响」。
这把「社会影响是否真的有益」变成可证伪的因果问题，而不是默认有益。

**定义 446（社会影响公平约束）**
将「社会影响」的第二种读法（social impact）纳入 XC：
(a) **分组校准**：对所有用户组 `g`，`OT_g ≤ ε_OT^max`；
(b) **风险转移**：Tier 2 社会捷径不得把验证成本转移给未同意的第三方；
(c) **自主性**：操作员可设置信任上限、关闭社会线索、要求原始回执；
(d) **非操纵**：禁止暗模式，禁止以参与度/接受率为优化目标。

**定义 447（TrustGauge S6CX 与退化链）**
`S6CX = S(社会感知) → H → C → E → C → V → U → X(体验)`。
S-Box 只产出社会先验，不直接写契约；X-Box 只读 EC/回执，只写披露策略、claims 与信任线索。
退化：S-Box 不可用/全 NSI/独立性失败 ⇒ ToolGauge 单机；
XC 不可满足 ⇒ 保守披露（原始回执 + 不确定性 + 无社会证明）；
两者都失败 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。数值路径永不依赖 S/X。

**定义 448（继承与归约）**
未重定义记号沿用定义 398–431。令 `G=∅`、`X=∅` ⇒ TrustGauge ≡ ToolGauge。
五不变式全部保留；新增两条层间不变式：ENS（定义 433）与 XC-一致性（定义 439/441）。

## 2. 关键算法骨架

```python
# IP-321 S-Box：来源独立性 + 设计效应校正 + 分级采纳
@dataclass
class SocialSignal:
    src: AgentID
    s: BlindSpot
    q: Gaussian                  # (mu, Sigma) over u_s
    certs: list[RepairCert]
    basis: Literal["ISI", "NSI"]
    anc: ProvenanceDAG

class SBox:
    def __init__(self, rep, prov, tau_max=0.3, eps_rho=0.1):
        self.rep, self.prov = rep, prov
        self.tau_max, self.eps_rho = tau_max, eps_rho

    def admissible(self, m, local):
        return (m.basis == "ISI"
                and all(valid(c) for c in m.certs)
                and self.prov.indep(m.anc, local.anc, self.eps_rho)
                and self.rep[m.src] >= REP_MIN
                and m.s not in SAFETY_CRITICAL)

    def n_eff(self, ms):
        rho = mean_pairwise(self.prov.rho, ms)
        return len(ms) / (1 + (len(ms) - 1) * rho)

    def pool(self, local, ms):
        ms = [m for m in ms if self.admissible(m, local)]
        if not ms:
            return local
        ne  = self.n_eff(ms)
        tau = self.tau_max * ne / (ne + KAPPA_TAU)   # 有效证据越少，社会权重越小
        w   = softmax([log(self.rep[m.src]) + log(info(m.q)) for m in ms])
        Lam_loc = inv(local.Sigma)
        Lam_soc = sum(w_j * inv(m.q.Sigma) for w_j, m in zip(w, ms))
        mu_soc  = solve(Lam_soc, sum(w_j * inv(m.q.Sigma) @ m.q.mu
                                     for w_j, m in zip(w, ms)))
        Lam_eff = Lam_soc * min(1.0, trace(Lam_loc) / trace(Lam_soc))  # 精度封顶
        h_eff   = Lam_eff @ mu_soc
        Lam     = (1 - tau) * Lam_loc + tau * Lam_eff
        h       = (1 - tau) * (Lam_loc @ local.mu) + tau * h_eff
        return Gaussian(Sigma=inv(Lam), mu=inv(Lam) @ h)

    def adopt(self, s, ms, local):
        if s in SAFETY_CRITICAL or not any(m.basis == "ISI" for m in ms):
            return "Tier0"
        ind = independent_subset(ms, self.prov, self.eps_rho)
        if (len(ind) >= 2
            and min(self.rep[m.src] for m in ind) >= REP_HI
            and max_pairwise_rho(ind, self.prov) <= RHO_MAX
            and norm(mean_of(ind) - local.mu) <= EPS_AGR
            and spot_check(s) <= EPS_SPOT
            and self.xc.human_authorized(s)):
            return "Tier2"
        return "Tier1"

class RepBox:

# IP-323 X-Box：VoI 门 + 渐进披露 + PNE
class XBox:
    def cue(self, q, certs):
        c = self.hcal.map(prob_correct(q, certs))      # 人类校准层，不是机器 σ
        return min(c, evidence_cap(certs))             # 不得超出证据上限

    def disclose(self, s, q, certs, human):
        for level in range(4):
            e = explain(s, q, certs, level)
            if self.voi(e, human) - self.cost(e) >= GAMMA_X \
               and self.budget >= self.cost(e):

                return e

    def voi(self, e, human):
        return expected_utility_gain(e, human) - risk_transfer(e)
```

## 3. 推导（引理 51–56）

**引理 51（社会池化的设计效应与过度计数）** 设 `m` 条无偏高斯证据具有共同精度 `I`、两两相关 `ρ`。
朴素池化精度为 `mI`，真实精度为
`I_eff = mI / (1 + (m-1)ρ)`。
故朴素方差被低估 `1+(m-1)ρ` 倍；用 `n_eff = m/(1+(m-1)ρ)` 可恢复校准。
证明：`Var(Σ μ_j) = mσ² + m(m-1)ρσ²`，取均值的倒数即得。`ρ=0.5, m=5` 时方差低估 3 倍，`n_eff=1.67`。

**引理 52（锚定社会更新的偏差界）** 在精度封顶池化（定义 434）下，社会均值权重 `w_soc ≤ τ_i ≤ τ_max`，因此
`|μ_i^+ − μ_true| ≤ (1-w_soc)|b_loc| + w_soc|b_soc| ≤ (1-τ_max)|b_loc| + τ_max|b_soc|`。
若本地无偏而所有社会来源共享同一偏差 `b`，则社会诱发的偏差 `≤ τ_max·|b|`；
`τ_max=0.3` 时，社会偏差最多是同伴偏差的 30%。这条界是「本地证据永远保留多数权重」的数学形式。

**引理 53（社会捷径的安全性）** 若 Tier 2 要求 `k≥2` 条来源独立 ISI，每条错误率 `≤ε_s`，
且 spot-check 的误接受率 `≤δ_spot`，则错误采纳概率
`P_wrong ≤ ε_s^k + δ_spot`。
`k=2, ε_s=0.1, δ_spot=0.02` ⇒ `P_wrong ≤ 0.03`。
若来源相关 `ρ→1`，独立性收益退化为 `ε_s`，因此**独立性审计是 `ε_s^k` 这一指数的许可证**；
没有它，Tier 2 的界不成立。

**引理 54（选择性反馈下的人类校准可识别性）** 设探索配额 `ε_explore>0`，则低风险情境下
披露倾向 `π ≥ ε_explore`，IPS 权重 `w ≤ 1/ε_explore`；对取值有界的校准分数，
`Var(ECE_h^IPS) = O(B²/(n·ε_explore))`，且估计一致。
若 `ε_explore=0`，校准误差只在披露支撑集上可识别，支撑集外可任意偏。
故 UX 优化必须保留一个小比例的**随机披露**，否则「校准」只是对已展示样本的自我赞美。

**引理 55（体验层不破坏数值等价性）** X-Box 只读 EC 与回执，只写披露策略、claims 与人类信任线索，
不写 `u_s`、`χ_R`、`M_ver`；H-Cal 与 IPS 只更新展示层参数。
因此子图数值等价性与 ToolGauge 引理 49/44 相同；XC 失败时保守披露也只改变展示。
证明：数据流分离 + 写集不相交。

**引理 56（信任回路的稳定性）** 令 `a=∂A/∂Rep, b=∂Rep/∂A, c=∂A/∂D, d=∂D/∂A`。
本方案用真值更新信誉 ⇒ `b=0`；用 PNE 切断流行度通道 ⇒ `d=0`（披露不以接受率为目标）。
故数值路径的回路增益 `g=ab+cd=0`。若部署改用接受率更新信誉，则 `g=ab`，
线性化稳定条件为 `|g|<1`；必须在线估计并告警。

## 2. 形式化定义（要点）

**定义 432（来源图与独立性）** 每条证书带来源闭包 `Anc(c)`，构成 provenance DAG。
共享原因系数 `ρ(c,c') = Σ_{a∈Anc∩Anc'}ω(a) / min(Σ_{Anc}ω, Σ_{Anc'}ω)`；
`indep_ε ⇔ ρ≤ε_ρ`。`ρ` 是误差相关性的保守上界，部署前用留出数据校准，运行时在线计算。

**定义 433（社会信号与 ENS 不变式）** `m_{j→i}(s)=(q_j,C_j,basis,Anc_j,Rep_j)`。
数值准入：`basis=ISI ∧ 全部回执有效 ∧ indep_ε(C_j,C_i) ∧ Rep_j≥Rep_min ∧ s∉SafetyCritical`。
**ENS**：任何数值自然参数更新中不得出现 NSI 项；NSI 只允许在展示层并标注「非证据性」。
这是「语言不进入数值通道」的社会版。

**定义 434（锚定社会后验）** 社会分量的精度按本地精度**封顶**：
`Λ_soc^eff = Λ_soc·min(1, trΛ_i/trΛ_soc)`，`Λ_i^+ = (1-τ_i)Λ_i + τ_iΛ_soc^eff`，
`h_i^+ = (1-τ_i)h_i + τ_i h_soc^eff`，`τ_i = min(τ_max, τ_max·n_eff/(n_eff+κ))`。
社会均值权重 `w_soc ≤ τ_i ≤ τ_max`；本地证据至少占 `1-τ_max`。

**定义 435（有效样本量）** `n_eff = m/(1+(m-1)ρ̄)`，`δ=n_eff/m`；`ρ̄=1 ⇒ n_eff=1`，
`ρ̄=0 ⇒ n_eff=m`。非等精度用保守 design-effect 上界。

**定义 436（SAG 分级）** Tier 0：安全关键 / 仅 NSI / 独立性失败 ⇒ 禁止；
Tier 1：默认，社会证据只影响 `H_s` 与探测排序，仍须本地探测；
Tier 2：≥2 条独立 ISI + 高信誉 + 低相关 + 与本地一致 + 廉价 spot-check + 人工授权。
Tier 只降不升；Tier 2 生成社会采纳证书。

**定义 437（Rep-Box）** `Rep_j(t+1)=(1-α_rep)Rep_j(t)+α_rep·g(outcome_j)`，
`outcome_j` 是交叉验证真值，不是接受率；信誉不可转让、不可购买、不因被引用而上升；
`w_{ij}≤Rep_j`；来源/背书图做稠密子图与环检测。

**定义 438（人类信任指标）** `ECE_h=E[|c−P(correct|c)|]`，
`OT=E[(b_h−P(correct))^+]`，`UT=E[(P(correct)−b_h)^+]`。
`b_h` 用预注册行为诱因与经验证量表估计；**机器 σ 不得直接当 `c`**。

**定义 439（体验契约 XC）** `(B_attn, ε_ECE, ε_OT, ε_UT, L_exp, τ_lat, recourse, ε_explore, PNE, equity)`；
失败 ⇒ 保守披露模式，不改变数值行为。
`equity` 要求分组校准 `max_g OT_g ≤ ε_OT^max`，且社会捷径不得把风险转移给未同意的第三方。

**定义 440（VoI 注意力门）** `VoI(e)=E_{y~p(y|e)}[max_a E[U(a,y)|e]]−max_a E[U(a,y)]`；
`disclose(e) ⇔ VoI(e)−κ(e) ≥ γ_X ∧ B_attn ≥ κ(e)`。
这是 ToolGauge 增益注 `β` 的体验层类比：`β` 管探测值不值，`VoI` 管打断值不值。

**定义 441（渐进披露与可逆闭包）** 层级 0..3：状态+动作 / 证书摘要 / 回执 / 回放；
`Claims(0)⊆Claims(1)⊆…`；每层数值主张必须引用有效回执（继承定义 423）；
任一层不得与另一层矛盾；层 `ℓ` 的动作必须在 `≤ℓ+1` 层有登记回滚路径。

**定义 442（IPS 反馈）** 反馈只在被披露样本上出现（MNAR）；`w=min(1/π,w_max)`，
`ECE_h^IPS=Σw_i|c_i−f_i|/Σw_i`；探索配额 `ε_explore>0` 保证 `π≥ε_explore`（正性条件）。
没有探索的 UX 优化会系统性高估自己的校准度。

**定义 443（信任回路）** `g=(∂A/∂Rep)(∂Rep/∂A)+(∂A/∂D)(∂D/∂A)`。
本方案用真值更新信誉令第一项为 0，用 PNE 令第二项中的流行度通道为 0；
若改用接受率更新信誉/优化披露，必须在线监测 `g<1`。

**定义 444（社会影响账本）** 只追加、哈希链防篡改：`(t,i,j,s,basis,Anc,τ,D_KL,outcome,counterfactual)`。

**定义 445（反事实社会审计）** 影子模式重放「去掉社会信号」：
`Δ_soc=D_KL(q_with‖q_without)`，`Δ_perf=perf_with−perf_without`；
`Δ_soc>κ_KL ∧ Δ_perf<0` ⇒ 标记「有害社会影响」。

**定义 446（社会影响公平约束）** 分组校准、风险转移检查、操作员自主性（信任上限/关闭社会线索/原始回执）、
非操纵（禁止暗模式，禁止以参与度或接受率为优化目标）。

**定义 447（S6CX 与退化）** `S → H→C→E→C→V→U → X`；S 只产出先验，X 只读 EC/回执、只写披露与 claims；
S 失效 ⇒ ToolGauge；XC 不可满足 ⇒ 保守披露；两者都失效 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。

**定义 448（归约）** `G=∅, X=∅ ⇒ TrustGauge ≡ ToolGauge`；五不变式保留；
新增 ENS 与 XC-一致性两条层间不变式。

```python
# IP-321 S-Box：来源独立性 + 设计效应校正 + 分级采纳
@dataclass
class SocialSignal:
    src: AgentID
    s: BlindSpot
    q: Gaussian                  # (mu, Sigma) over u_s
    certs: list[RepairCert]
    basis: Literal["ISI", "NSI"]
    anc: ProvenanceDAG

class SBox:
    def __init__(self, rep, prov, tau_max=0.3, eps_rho=0.1):
        self.rep, self.prov = rep, prov
        self.tau_max, self.eps_rho = tau_max, eps_rho

    def admissible(self, m, local):
        return (m.basis == "ISI"
                and all(valid(c) for c in m.certs)
                and self.prov.indep(m.anc, local.anc, self.eps_rho)
                and self.rep[m.src] >= REP_MIN
                and m.s not in SAFETY_CRITICAL)

    def n_eff(self, ms):
        rho = mean_pairwise(self.prov.rho, ms)
        return len(ms) / (1 + (len(ms) - 1) * rho)

    def pool(self, local, ms):
        ms = [m for m in ms if self.admissible(m, local)]
        if not ms:
            return local
        ne  = self.n_eff(ms)
        tau = self.tau_max * ne / (ne + KAPPA_TAU)   # 有效证据越少，社会权重越小
        w   = softmax([log(self.rep[m.src]) + log(info(m.q)) for m in ms])
        Lam_loc = inv(local.Sigma)
        Lam_soc = sum(w_j * inv(m.q.Sigma) for w_j, m in zip(w, ms))
        mu_soc  = solve(Lam_soc, sum(w_j * inv(m.q.Sigma) @ m.q.mu
                                     for w_j, m in zip(w, ms)))
        Lam_eff = Lam_soc * min(1.0, trace(Lam_loc) / trace(Lam_soc))   # 精度封顶
        h_eff   = Lam_eff @ mu_soc
        Lam     = (1 - tau) * Lam_loc + tau * Lam_eff
        h       = (1 - tau) * (Lam_loc @ local.mu) + tau * h_eff
        return Gaussian(Sigma=inv(Lam), mu=inv(Lam) @ h)

    def adopt(self, s, ms, local):
        if s in SAFETY_CRITICAL or not any(m.basis == "ISI" for m in ms):
            return "Tier0"
        ind = independent_subset(ms, self.prov, self.eps_rho)
        if (len(ind) >= 2
            and min(self.rep[m.src] for m in ind) >= REP_HI
            and max_pairwise_rho(ind, self.prov) <= RHO_MAX
            and norm(mean_of(ind) - local.mu) <= EPS_AGR
            and spot_check(s) <= EPS_SPOT
            and self.xc.human_authorized(s)):
            return "Tier2"
        return "Tier1"

# IP-322 Rep-Box：双时标信誉（只用真值，不用接受率）
class RepBox:
    def update(self, agent, outcome_true):
        self.rep[agent] = (1 - ALPHA_REP) * self.rep[agent] + ALPHA_REP * outcome_true
    def sybil_score(self, graph):
        return max_dense_subgraph(graph, min_size=3)   # 串谋/环检测

# IP-323 X-Box：VoI 门 + 渐进披露 + PNE
class XBox:
    def cue(self, q, certs):
        c = self.hcal.map(prob_correct(q, certs))      # 人类校准层，不是机器 σ
        return min(c, evidence_cap(certs))             # 不得超出证据上限
    def disclose(self, s, q, certs, human):
        for level in range(4):
            e = explain(s, q, certs, level)
            if self.voi(e, human) - self.cost(e) >= GAMMA_X \
               and self.budget >= self.cost(e):
                self.budget -= self.cost(e)
                return e
        return self.defer_or_batch(explain(s, q, certs, 0))
    def voi(self, e, human):
        return expected_utility_gain(e, human) - risk_transfer(e)
    def render_social(self, signals):
        # NSI 只允许以「非证据性」标签展示；不得进入 cue 的数值
        return [label_non_evidential(m) for m in signals if m.basis == "NSI"]
```

```python
# IP-326 TrustGauge S6CX
def trustgauge_s6cx(M, s):
    local = M.local_cert(s)
    ms    = M.sbox.ingest(s)                          # S：社会感知
    q_soc = M.sbox.pool(local.q, ms)                  # 社会先验（仅 ISI）
    mode  = M.sbox.adopt(s, ms, local)                # Tier 0/1/2
    H     = M.lbox.hypothesize(s, M.dbox.R[s], prior=q_soc)   # H
    prog  = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s))# C
    receipts = M.tcv.execute(prog, M.env)             # E
    if len(receipts) < n_min(s):
        return stub_and_red(s, "insufficient")
    mu, Sig = M.apcal.calibrate(receipts, H, s)       # C
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
        mu, Sig = M.apcal.calibrate(receipts, ["UNKNOWN"], s)
        if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
            return stub_and_red(s, "cross_failed")    # V 失败 ⇒ 退化
    # 社会证据不能充当独立校验：独立性审计必须独立于社会信号
    if not M.sbox.independence_ok(ms, M.cross_receipt(s)):
        return stub_and_red(s, "social_not_independent")
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s)
    if not contract_regression(new_ec):
        return stub_and_red(s, "regression")
    M.mreg.hot_replace(M.dpe, new_ec)                 # U
    M.dbox.update_from_posterior(s, mu, Sig)
    M.sbox.publish(s, new_ec, receipts, M.prov)       # 发布 ISI 证据
    M.rep.update(M.self_id, truth_or_shadow(new_ec))  # 慢时标，仅真值
    M.xbox.disclose(s, mu, receipts, M.human)         # X
    M.ledger.log_social(s, ms, q_soc, mu, Sig)        # 定义 444
    return True

def trustgauge_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            submit_async(trustgauge_s6cx, M, s)        # 偏离 50Hz 路径
    if M.xbox.budget_exhausted():
        M.xbox.conservative_mode = True               # 只影响展示，不影响数值
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导（引理 51–56）

**引理 51（社会池化的设计效应）** `m` 条共同精度 `I`、两两相关 `ρ` 的无偏高斯证据，
真实池化精度 `I_eff = mI/(1+(m-1)ρ)`；朴素做法把方差低估 `1+(m-1)ρ` 倍。
用 `n_eff=m/(1+(m-1)ρ)` 可恢复校准。
证明：`Var(Σμ_j)=mσ²+m(m-1)ρσ²`，取均值精度的倒数即得。

**引理 52（锚定社会更新的偏差界）** 精度封顶池化下社会均值权重 `w_soc≤τ_i≤τ_max`，故
`|μ_i^+−μ_true| ≤ (1-w_soc)|b_loc|+w_soc|b_soc| ≤ (1-τ_max)|b_loc|+τ_max|b_soc|`。
若本地无偏、社会来源共享偏差 `b`，社会诱发偏差 `≤τ_max|b|`；`τ_max=0.3` ⇒ 最多 30%。

**引理 53（社会捷径安全性）** Tier 2 要求 `k≥2` 条独立 ISI，单源错误率 `≤ε_s`，
spot-check 误接受 `≤δ_spot`，则 `P_wrong ≤ ε_s^k+δ_spot`。
`k=2, ε_s=0.1, δ_spot=0.02` ⇒ `≤0.03`。
若 `ρ→1`，独立性收益退化为 `ε_s`；**独立性审计是 `ε_s^k` 的许可证**。

**引理 54（选择性反馈可识别性）** `ε_explore>0` ⇒ `π≥ε_explore`，IPS 权重 `≤1/ε_explore`；
有界分数下 `Var(ECE_h^IPS)=O(B²/(n·ε_explore))` 且一致。
`ε_explore=0` ⇒ 校准只在披露支撑集上可识别，支撑集外可任意偏。

**引理 55（体验层数值等价）** X-Box/H-Cal/IPS 只读写展示层；
不写 `u_s/χ_R/M_ver` ⇒ 子图数值等价性与 ToolGauge 引理 49/44 相同。
XC 失败时保守披露只改变展示。

**引理 56（信任回路稳定性）** 令 `a=∂A/∂Rep, b=∂Rep/∂A, c=∂A/∂D, d=∂D/∂A`。
真值信誉 ⇒ `b=0`；PNE ⇒ `d=0`；故数值路径 `g=ab+cd=0`。
若改用接受率信誉，则 `g=ab`，稳定条件 `|g|<1`，需在线监测。

## 9. 本轮最大风险（一句话）

社会影响与体验优化会共同制造一个**自封闭的可信度回路**：相关证据被当作独立共识、
经「校准外观」的解释放大、而人类反馈又只在系统选择展示的样本上产生，
最终让一个错误修复获得制度性信任并绕过局部交叉验证——且越是「用户体验好」，这个回路越隐蔽。
