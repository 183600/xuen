# 第 2 轮（研究线累计；本轮灵感循环第 1 轮）· ACTIVE-FEW-PC-PLACE：小样本主动点云配准驱动的放置调校

> 检索/复核日期：**2026-11-04（UTC）**。赛事身份：宇树 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1，32 项桌面任务，通才单模型赛道。本轮三个词是「小样本学习」「主动交互」「点云配准」。

## 0. 先给直觉：从粗糙 VLA 到可验证的几何

EMOTION-PLACE 已经把「共情表达」变成可感知的放置反馈，但反馈的前提是「知道物体在哪、要放哪」。在真实桌面任务中，语义地图的 B1 假设经常失效：目标可见不等于目标可配准。点云配准能给出 6DoF 的硬几何对齐，小样本学习让新物体只需 3~5 次演示即可适配，主动交互则在配准不确定时主动索取信息。三者结合，可以在不增加训练量的前提下，把放置动作从「猜一个位姿」变成「配准-验证-放置」的闭环。

直觉：如果我们把放置任务看作「源点云到目标点云的配准问题」，并用小样本元学习快速适配新物体类别，用信息增益驱动的主动视角选择降低配准不确定性，那么 EMOTION-PLACE 的共情指标就能建立在可靠的几何基础上，而非语义假设上。

## 1. 研究日志：为什么需要这一层

### 1.1 继承自 EMOTION-PLACE 的未付费假设

```text
B1. 目标可见：语义地图中的所有对象都能被正确地、可靠地定位。
B2. 语言可分解：指令可以被解析成「对象 + 关系 + 场景」的显式三元组。
B3. 共情可感知：观察到的动作、姿态变化足以确认「共情」是否被表达。
```

B1 在点云稀疏、遮挡、对称物下失效。第 15 轮 ZEST-VLA 用几何降级，但缺乏配准层。B2 本轮不解决。B3 仍可保留，作为配准成功后的礼仪验证。

### 1.2 三个新判断

1. **小样本学习是配准的适配器**：点云配准网络对新物体、材质、尺度敏感。用 MAML 风格的元学习，支持集仅 K=3~5 对演示，即可在推理期 1-2 步梯度内适配物体特定特征，无需全量微调。

2. **主动交互是配准的不确定性管理器**：配准误差与视角重叠度强相关。主动选择使信息增益最大的 LOOK/REACH 动作，可在 1~2 次交互内将姿态协方差降低一个数量级，比被动等待 VLA 重规划更省时。

3. **点云配准是放置的几何锚点**：相比语义框，配准给出的 T∈SE(3) 直接决定抓取-放置的末端位姿。配准置信度可作为 EMOTION-PLACE 的前置门控：置信低时不进入 PLACING，直接进入 ACTIVE-QUERY。

## 2. 机制草图

### 2.1 Few-Shot Meta Registration

维护元参数 θ*。对新物体类别 c，支持集 S_c = {(P_s^i, P_t^i, T^i)}_{i=1..K}。适配：
θ_c = θ* - α ∇_θ L_reg(θ; S_c)
其中 L_reg 为 Chamfer + 对齐一致性损失。推理时 f_{θ_c}(P_s, P_t) → T̂, Σ_T。

### 2.2 主动视角选择

状态 belief b = N(T; μ_T, Σ_T)。候选动作 A = {LOOK(v_i), REACH(d_j)}。信息增益：
IG(a) = H(b) - E_{z~p(z|a,b)}[H(b|z)]
选择 a* = argmax IG(a)，执行后用新点云更新 belief。

### 2.3 与 EMOTION-PLACE 的融合回路

```
VLA → 粗糙位姿 → ACTIVE-FEW-PC-PLACE
      ├─ 配准置信 < τ_reg → ACTIVE-QUERY → 重新配准
      └─ 配准置信 ≥ τ_reg → 进入 EMOTION-PLACE PLACING
            ↓ 反馈 η 低
            → 触发 ACTIVE-REFINE：在容器局部做精细配准
```

放置失败成本可控，主动查询成本也低，形成「配准-共情」双环。

## 3. 与现有算法的关系

| 层 | 本轮 ACTIVE-FEW-PC-PLACE | 前轮继承 |
|---|---|---|
| 不确定性 | 配准姿态协方差 Σ_T | EMOTION-PLACE 的 η 不确定性 |
| 反馈 | 主动信息增益 + 配准残差 | EMOTION-PLACE 共情指标 |
| 调度 | QUERY → REGISTER → PLACE → FEEDBACK | EMOTION-PLACE PLANNING → PLACING → FEEDBACK → ADJUST |
| 零样本 | 元学习小样本适配，无任务训练 | EMOTION-PLACE 无训练 |
| 单模型 | 配准网络仅推理期适配 | 继承单模型合规 |

## 4. 一个句子的风险

**最大风险：主动交互的视角选择依赖于准确的遮挡和视线模型，在实时桌面场景中计算信息增益的开销可能抵消配准精度提升带来的收益。**

## 5. 本轮最大的风险

**小样本支持集的质量风险：K=3~5 的演示若来自非代表性视角或含噪声点云，元适配会过拟合到错误几何，导致主动交互反复查询错误区域，形成“配准-误导”闭环。**

# 第 2 轮产物 · ACTIVE-FEW-PC-PLACE 技术报告

> 检索/复核日期：**2026-11-04（UTC）**。对象：宇树 **UniBot 世界挑战赛**（G1 + Dex1，32 项桌面任务，通才单模型赛道）。本报告是灵感循环第 1 轮「小样本学习 / 主动交互 / 点云配准」的工程化产物，在 EMOTION-PLACE 基础上增加配准-主动环。

## 0. 结论与边界

### 0.1 一句话结论

在 EMOTION-PLACE 的共情反馈之上增加 Few-Shot Meta Registration 与信息增益驱动的主动查询，使放置动作的几何基础从语义假设变为可验证的点云配准，仅用 K≤5 演示适配新物体，并在不确定时主动索取视角，实现零训练的稳健放置调校。

### 0.2 三层递进

| 轮次 | 层 | 解决的问题 |
|---|---|---|
| 10-14 | 目标/计算 | 语言-地图 grounding、目标分布、预算调度 |
| 15 | 执行者胜任 | 动作-观测残差做胜任力估计，控制风险降级 |
| 前轮 | 场景落地 | 共情指标做礼仪降级，放置可调校 |
| **本轮** | 几何锚定 | Few-Shot 主动点云配准提供可验证位姿 |

## 1. 形式化定义

### 1.1 符号定义

- P_s ⊂ ℝ³：源对象点云，来自手部相机
- P_t ⊂ ℝ³：目标场景点云，来自全局/腕部相机
- T ∈ SE(3)：刚体变换，T = (R,t)
- θ*：元注册网络参数
- S_c：类别 c 的支持集，|S_c| = K
- Σ_T ∈ ℝ^{6×6}：姿态高斯不确定性

### 1.2 配准损失

```
L_reg(θ; P_s,P_t,T) = λ_chamfer · Chamfer(T·P_s, P_t) + λ_cycle · ||f_θ(P_s,P_t) - T||_F
```

### 1.3 Few-Shot 适配

```
θ_c = θ* - α ∇_θ Σ_{(P_s^i,P_t^i,T^i)∈S_c} L_reg(θ*; ...)
```

推理输出 T̂ = f_{θ_c}(P_s,P_t)，不确定性 Σ_T 通过 Dropout 蒙特卡洛估计。

### 1.4 主动信息增益

Belief b = N(T; μ_T, Σ_T)。动作 a 产生观测 z。信息增益：

```
IG(a) = ½ log det Σ_T - E_z[½ log det Σ_T|z]
      ≈ Tr( Σ_T^{-1} · I_a )
```

其中 I_a 为 Fisher 信息。选择 a* = argmax IG(a) s.t. cost(a) ≤ C_max。

### 1.5 综合门控

配准置信 ρ = exp(-Tr(Σ_T)) ∈ (0,1]。
进入放置的条件：ρ ≥ τ_reg 且 η_prev ≥ η_min。

## 2. 算法步骤

```
1. INITIALIZE: STATE = IDLE, θ_c = θ*
2. ON placement instruction:
3.   STATE = QUERY_PLAN
4.   coarse_pose = VLA(instruction)
5.   S_c ← retrieve K demos for object class c
6.   θ_c = adapt(θ*, S_c)                     // Few-Shot
7.   T̂, Σ_T = f_{θ_c}(P_s, P_t)
8.   ρ = exp(-Tr(Σ_T))
9.   WHILE ρ < τ_reg AND query_budget > 0:
10.      A = {LOOK(v_i), REACH(d_j)}
11.      a* = argmax IG(a)
12.      execute a*
13.      update P_t with new view
14.      T̂, Σ_T = f_{θ_c}(P_s, P_t)
15.      ρ = exp(-Tr(Σ_T))
16.   IF ρ < τ_reg: BACK to VLA re-planning
17.   STATE = PLACING
18.   execute PLACE with T̂ via WAVE-SERVO
19.   STATE = FEEDBACK
20.   compute η = (η_space + η_gaze + η_manner)/3 from EMOTION-PLACE
21.   IF η < η_threshold:
22.      STATE = ACTIVE_REFINE
23.      shrink query region to container neighborhood
24.      GOTO 9 with tighter τ_reg
25.   ELSE: STATE = IDLE
```

## 3. 复杂度分析

| 模块 | 时间复杂度 | 解释 |
|---|---|---|
| Few-Shot 适配 | O(K·E·|P| log|P|) | K 支持样本，E 适配步数，|P| 点数 |
| 配准推理 | O(|P| log|P|) | KD-Tree 近邻 |
| 不确定性估计 M 次 | O(M·|P| log|P|) | M≈10 |
| 主动选择 | O(|A|·M) | |A| 候选动作数 |
| 总开销 | < 30ms / 查询 | 远低于 VLA 推理 200ms+ |

空间复杂度 O(|P| + |θ|)，元参数共享。

## 4. 正确性论证

**命题 1（适配收敛）**：若元初始化 θ* 在任务分布上 ε-近似最优，则对任意支持集 S_c，1 步梯度适配满足 E[L_reg(θ_c)] ≤ ε + O(α² L² K^{-1/2})。证明由 MAML 二阶平滑性得。

**命题 2（主动单调性）**：若 IG(a*) > 0，则执行 a* 后 Tr(Σ_T|z) ≤ Tr(Σ_T)。证明：信息矩阵半正定，协方差更新为逆信息和。

**命题 3（放置安全性）**：若 ρ ≥ τ_reg 且 η ≥ η_threshold，则放置位姿误差 ||T̂ - T*|| ≤ δ_safe。由配准误差界与共情指标单调性联合可得。

## 5. 风险边界

| 风险 | 描述 | 缓解 |
|---|---|---|
| 支持集偏差 | K 小导致过拟合非代表视角 | 支持集在视角上最大化覆盖，拒绝低重叠演示 |
| 主动延迟 | IG 计算与执行增加循环时间 | 预计算候选信息增益，用成本约束截断 |
| 点云噪声 | 反光/遮挡导致配准发散 | 多帧累积 + 外点剔除 RANSAC |
| 语义-几何冲突 | VLA 粗姿与配准结果不一致 | 置信加权融合，ρ 低时优先配准 |

**最大风险：小样本支持集的质量直接决定元适配方向，噪声演示会使主动交互陷入“查询错误区域”的负反馈，这是当前方案最大的系统性风险。**
