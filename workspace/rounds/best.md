# 想法区 · 第 10 轮（新循环 · 第 2 轮）：RHD 只用了盒子的一面

**灵感词**：下界分析 / 可扩展性 / 凸优化
**起点**：v1.9「X-DUB/PACE-R*」。38 例 95 节点 / 25 表，deep 236 / 120，held-out 2,332（44 胜 6 平 0 负），hard3#5 38 / 17 表。它的收官风险是一句话：

> RHD 的收益全部来自释放错峰；同步释放的层上 `Min_R = READY`，分支因子回到 d，最坏情况仍是 n!。

本轮不推倒 v1.9。我想把这句话再往前推一格：**先证明「再加一条顺序支配」这条路已经走到头，再说明唯一没被用掉的东西是什么。**

## 一、先堵三条看起来最诱人的路

### 1.1 集合插入会退化成单任务插入

RHD 的证明是「把 i 插进 j 释放之前的空闲前缀」。一个自然的加强是：不插一个任务，插一个集合 S。

**引理（集合插入坍缩）**。设 `S ⊆ Ready\{j}` 非空，且 S 能被完整排进 `[·, est_j)`（每个 i 在 `[est_i, est_j)` 内、用各自资格机器、互不重叠）。令 `i0` 是这个小排程里第一个开始的任务，则

```text
est_{i0} + p_{i0} ≤ est_j .
```

**证明**：`i0` 开始不早于 `est_{i0}`，完成不晚于 `est_j`。∎

也就是说：只要集合插入成立，单任务 RHD 判据就已经成立，j 早被删了。**集合插入这一族没有新东西。**

### 1.2 反向搜索是免费的，但没有收益

问题在时间反演下是自对偶的：`t ↦ h−t` 把释放变成期限、把前驱变成后继，makespan 不变；反转后的 `est` 恰好是原来的 `q`（最长尾）。v1.9 的 RHD 在反转实例上就是「谁不能最后」。

我实测了 38 例 + deep 8 例，把同一个 v1.9 直接跑在反转实例上：

| 集合 | 正向 | 反向 |
|---|---:|---:|
| 38 例 | **95** | 60,872 |
| deep 8 | **236** | 434 |

逐例看，反向从来没有严格更好（deep#1 32=32，#3 47/48，#5 61=61）。**方向对偶不产生收益**，因为我们的 `h = OPT−1` 探针本来就偏向「源少、汇多」的实例；反过来跑等于把容易的一端换成难的一端。

### 1.3 预流 LP 已经被 tier 1.25 包含

「凸优化」最自然的落点是时间索引 LP 的预流松弛：每个任务在自己窗口里可抢占，m 台机器每时隙容量 m，可行性由最大流判定。它看起来比区间能量强。

但它不强。对同质资格，预流可行性正好是 Horn 条件

```text
∀ a<b :  Σ_{i: [est_i, d_i] ⊆ [a,b]} p_i  ≤  m(b−a) ,
```

其中 `d_i = h − q_i`。而 tier 1.25 的 `energy` 对每个临界 (a,b) 算的是强制重叠

```text
mand_i = min(p_i, est_i+p_i−a, b−(d_i−p_i), b−a) ,
```

对 `[est_i,d_i] ⊆ [a,b]` 的任务，`mand_i = p_i`。所以 tier 1.25 的 `tot ≤ cap` 直接蕴含 Horn 条件；异质资格下 `subset` 层做的是同一件事（`E_i ⊆ S` 的任务对 `|S|·L`）。**预流 LP 能拒的状态，tier 1.25 已经拒了。**

这不是说 LP 没用，而是说：**在这台引擎上，凸松弛的「体积」已经被吃干；再搬一个更大的 LP 进来，只会更慢。**

## 二、转折：RHD 只用了盒子的一面

三条路堵死之后，剩下一条很小的缝。

状态 `σ` 给每个任务两个边界：

```text
est_i  ：最早开始（前向最长路）
lst_i  = h − p_i − q_i  ：最晚开始（后向最长路）
```

v1.9 的 RHD 只用 `est`：

```text
v = min_{i∈Ready} (est_i + p_i) ,     K_RHD = { i : est_i < v } .
```

它对偶的那一面从来没用过：

```text
λ = min_{i∈R} lst_i ,     j 若 est_j > λ，则 j 永远不是第一个 .
```

**直觉一句话**：如果某个任务最晚也得在 x 之前开始，那么任何在 x 之后才释放的任务都不可能是第一个。

把两面合起来：

```text
μ(σ) = min( v(σ) − 1 , λ(σ) )
K(σ) = { i ∈ Ready(R) : est_i ≤ μ(σ) } ,   再取 Max_DCD .
```

`μ ≤ v−1`，所以 `K ⊆ K_RHD`：**DHD 是 RHD 的严格细化，节点数只会更少。**

## 三、为什么这算「凸优化」，而不是又一条拍脑袋规则

单个 `est_i` 和 `lst_i` 不是孤立的数：它们是差分约束多面体

```text
P = { s :  s_i ≥ est_i ,   s_j ≥ s_i + p_i (i→j) ,   s_i + p_i + q_i ≤ h }
```

在坐标 i 上的**精确投影**：

- 前向最长路给出 `min_{s∈P} s_i = est_i`；
- 后向最长路给出 `max_{s∈P} s_i = lst_i`。

所以 `[est_i, lst_i]` 是凸多面体 P 的盒子投影，`est` 与 `lst` 是同一个 LP 的两个面。`μ` 又是下面这个两约束 LP 的最优值：

```text
max μ   s.t.  μ ≤ est_i + p_i − 1  (i∈Ready) ,
              μ ≤ h − p_i − q_i    (i∈R) .
```

「凸优化」在本题里的正确位置，不是搬一个巨型 LP 进来（1.3 已证明它被 tier 1.25 包含），而是**把已有的凸松弛用满**：v1.9 用了一个面，本轮用两个面。

## 四、形式化：三条要证的事

1. **可靠性**：任一可行排程里开始最早的任务 `e` 必在 K 中。若 `est_e > λ`，λ 的见证者严格早于 e；若 `est_e ≥ v`，插入引理给出一个更早开始的可行排程，与 e 的最小性矛盾。两条合起来 `est_e ≤ min(v−1, λ) = μ`。
2. **细化性**：`K_DHD ⊆ K_RHD`，因此无截断时搜索树是 v1.9 的子树。
3. **非空性**：`μ ≥ est_min`（因为 `v−1 ≥ est_min` 且 `lst_i ≥ est_i`），所以最小 est 的任务永远保留。

还有一个必须写进规格的前提：**RHD 那一面（`v−1`）依赖 NORM**。若 `est_i < ā_i`，插入引理不成立。所以 `dhd=True` 时强制 `normalize=True`；若只保留 `λ` 一面，则 NORM 可省，但会丢掉 `v−1` 的收益。

## 六、负结果：同步层仍然是恒等

**定理**。若所有 ready 任务的 `est` 都等于 e，则 `μ ≥ e`，于是 `K = Ready`。

证明：`v = e + min p ≥ e+1`；`λ ≥ min_R est_i = e`（因为 `lst_i ≥ est_i`）。∎

所以 RHD 和 DHD 在同步层**同时失效**。本轮没有打破 d 障碍；根层（所有 source 的 est=0）依然没有证书。20% 的 held-out 收益来自「错峰 + 紧」的实例，不来自同步层。

## 七、可扩展性：不是 n 的问题

我本来想用 n=18/20/22 做规模实验。9 个随机实例（每个 n 各 3 个，p∈[3,6]，ep∈{0.2,0.25,0.3}）在 `h=OPT−1` 上**全部 1 节点根闭**。这不是引擎突然变强，而是随机大实例的根下界几乎就是 OPT：硬度不随 n 增长，而随「根下界与 OPT 的差」增长。deep 那 8 例是筛出来的（base ≥ 200 节点），所以它们小而不易。

这给「可扩展性」一个更诚实的定义：**DHD 的代价是 O(n)，且永不增加节点，所以它随 n 免费扩展；但最坏情况的指数性不随 n 改变，也不被本轮的规则改变。**

## 八、一句话最大风险

**DHD 与 RHD 是同一个盒子的两个面：当一层 ready 任务同步释放时两个面同时失效，分支因子仍是 d，最坏情况仍是 n!，hard3#5 的根证书依然没有。**

## 2. 形式定义

### 2.1 NORM 不变式

**定义 1（NORM）**。`σ=(R,A,est)` 是 NORM 的，若

```text
∀i∈R :  est_i ≥ ā_i(A) = min_{k∈E_i} A_k .
```

**作用域**：`v−1` 那一面（即 RHD 的插入引理）需要 `i` 能在 `est_i` 真正开始。若 `est_i < ā_i`，插入会被推迟，引理不成立（v1.9 的 6.1 有最小反例）。只保留 `λ` 一面时不需要 NORM，因为那一面只用 `s_i ≤ lst_i` 和 `s_j ≥ est_j`（`est_j` 是下界，低估只会让规则更保守）。

`dhd=True` 时强制 `normalize=True`。这是正确性要求，不是可调参数。

### 2.2 最晚开始

**定义 2（lst）**。

```text
q_i = max( 0, max_{ i→j, j∈R } ( p_j + q_j ) ) ,
lst_i = h − p_i − q_i .
```

**引理 1（盒子不等式）**。对任一从 σ 出发的可行排程，以及任一 `i∈R`，

```text
est_i ≤ s_i ≤ lst_i .
```

**证明**。左边是 `est` 的定义。右边：i 之后的最长残余链（不含 i）长度是 `q_i`，它必须在 `h` 前完成，所以 `s_i + p_i + q_i ≤ h`。∎

注意 `q_i` 对非 ready 任务也有定义，且引理 1 对非 ready 任务同样成立——这是 λ 可以取在**整个 R** 上而不是只在 Ready 上的原因，也是本轮比「只对 ready 取 λ」更强的地方。

### 2.3 盒子与凸投影

**定义 3（差分约束多面体）**。

```text
P(σ) = { s ∈ R^n :  s_i ≥ est_i  (i∈R) ,
                    s_j ≥ s_i + p_i  (i→j, i,j∈R) ,
                    s_i + p_i + q_i ≤ h  (i∈R) } .
```

**定理 1（盒子是投影）**。

```text
min_{s∈P} s_i = est_i ,      max_{s∈P} s_i = lst_i .
```

**证明**。下界：前向最长路是 P 逐点最小的解，标准差分约束结论。上界：由引理 1 的约束 `s_i ≤ h−p_i−q_i`；还需说明它与前驱约束兼容，即对每条边 i→j，`lst_i ≤ lst_j − p_i`。由 `q_i ≥ p_j + q_j` 得

```text
lst_i = h − p_i − q_i ≤ h − p_i − p_j − q_j = lst_j − p_i .
```

所以 `s_i ≤ lst_i` 与 `s_j ≥ s_i+p_i` 不冲突，取等可达。∎

于是 `[est_i, lst_i]` 是同一个凸多面体在两个方向上的支撑，`est` 与 `lst` 是同一个 LP 的两个面。

**定义 4（盒子 LP）**。

```text
μ* = max μ
     s.t.  μ ≤ est_i + p_i − 1     (i∈Ready)
           μ ≤ h − p_i − q_i       (i∈R)
```

它的最优值就是 `μ = min(v−1, λ)`。这不是一个需要求解的 LP（两族约束各取 min 即可），但它说明了 `μ` 是**盒子松弛的精确最优值**，不是启发式常数。

### 2.4 DHD 分支集

**定义 5（DHD 分支集）**。

```text
μ(σ) = min( v(σ) − 1 , λ(σ) ) ,
K(σ) = Max_D( { i∈Ready(R) : est_i ≤ μ(σ) } ) .
```

`Max_D` 是 v1.8 的 DCD 极大元商。`K` 非空（定理 5）。

### 2.5 与 RHD 的关系

- 若 `λ ≥ v−1`，则 `μ = v−1`，`K = {est < v} = K_RHD`：**逐字回到 v1.9**。
- 若 `λ < v−1`，则 `K ⊊ K_RHD`：DHD 严格更强。
- 所有 ready 的 `est` 相等时，`μ ≥ est_min`，`K = Ready`：**两个面同时失效**（定理 6）。

## 3. 算法

### 3.1 每节点 DHD

```text
DHD(ready, rem, p, est, q, h):
    v   ← min_{i∈ready} (est_i + p_i)        # O(d)
    λ   ← min_{i∈rem}   (h − p_i − q_i)      # O(n)
    μ   ← min(v − 1, λ)
    keep ← [ i∈ready : est_i ≤ μ ]           # O(d)
    return keep                              # 非空，见定理 5
```

### 3.2 接进 PACE-Λ 的搜索

```text
PACE-Λ(σ,h):
  1  if R=∅: return YES([])
  2  if DEAD(σ): return NO
  3  σ←NORM(σ); A*←CANON(A); estt←est|R
  4  exact memo / F_sub / INT                            # v1.7，不变
  5  window 层: energy / clique / subset / HPACK          # v1.7，不变
  6  MINT / PACK-SET / SOP                                # v1.7，不变
  7  if ¬PACK(σ,h): F_pack.insert; return NO(PACK)        # v1.7，不变
  8  q ← tails(R)                                         # v1.2，不变
  9  ready ← DHD(READY(R), R, p, est, q, h)               # 本轮 tier 0.20
 10  K ← DCD(ready)                                       # tier 0.30，v1.8 原样
 11  for i in K:
         for k in machines(i):
             t ← max(A_k,est_i)
             if t+p_i+q_i(R\{i}) > h: continue
             r ← PACE-Λ(child(i,k,t),h)
             if r=YES: return YES([(i,k,t)]+r)
 12  F_sub.insert(estt,A*); return NO(RESOLVE)
```

与 v1.9 的差异只有第 9 步：`v` 换成 `μ = min(v−1, λ)`。`q` 在 `rec` 里已经算过（第 8 步），所以 `λ` 只是多一次 O(n) 扫描。

### 3.3 实现细节

- `dhd_branch_set(ready, p, est, q, rem, h)`：一次 min 求 v，一次扫描 rem 求 λ，一次过滤。
- `dhd=True` 时强制 `normalize=True`（`v−1` 面需要）。
- `dcd_branch_set` 接收 DHD 过滤后的 ready，因此 `dcd_fan_before` 等于 `d_R`。
- 不新增记忆表；DHD 是无状态的每节点过滤。
- 统计沿用 `rhd_calls / rhd_drops / rhd_fan_before / rhd_fan_after`（语义改为「地平线丢弃」）。
- 消融开关：`dhd`（默认 False，v2.0 主配置 True）、`rhd`（v1.9 遗留）。

## 4. 定理与证明

### 4.1 最早任务必在 K 中

**引理 2（DHD 可靠性）**。设 `S` 是从 σ 出发的可行排程中**最早开始时刻最小**的那个，`e` 是 S 中开始最早的任务。则 `e ∈ K(σ)`。

**证明**。

1. **`est_e ≤ λ`**。若 `est_e > λ`，取 `i` 使 `lst_i = λ`。引理 1 给出 `s_i ≤ lst_i = λ < est_e ≤ s_e`，与 e 最早矛盾。
2. **`est_e < v`**。若 `est_e ≥ v`，取 `i* = argmin(est+p)`，则 `est_{i*}+p_{i*} = v ≤ est_e`。由插入引理（4.2，需要 NORM），存在可行排程 S' 使 `i*` 在 `est_{i*}` 开始。于是 S' 的最早开始 `≤ est_{i*} < est_e ≤ s_e`，与 S 的最小性矛盾。
3. 合起来 `est_e ≤ min(v−1, λ) = μ`，即 `e ∈ K`。∎

**注**：第 2 步只用「存在一个更早开始的可行排程」，不需要 S' 与 S 有相同的任务集合——插入引理给的是完整可行排程。

### 4.2 插入引理（v1.9 原样，此处复述）

**引理 3（insertion exchange）**。设 σ 是 NORM 状态，`i,j∈Ready`，`i≠j`，`est_i+p_i ≤ est_j`。若存在可行 S 以 j 为第一个任务，则存在可行 S' 以 i 为第一个任务。

**证明**。S 中所有机器在 `s_j ≥ est_j ≥ est_i+p_i` 之前为空。取 `k*` 使 `A_{k*}=ā_i ≤ est_i`，把 i 插到 `[est_i, est_i+p_i)`，再从原位置删除 i。资格、释放、机器、优先、期限逐项成立；i 更早完成，后继只会更松。∎

### 4.3 细化性

**定理 2（K_DHD ⊆ K_RHD）**。对任意 σ，

```text
K(σ) ⊆ K_RHD(σ) = { i∈Ready : est_i < v(σ) } .
```

**证明**。`μ = min(v−1, λ) ≤ v−1`，所以 `est_i ≤ μ ⇒ est_i < v`。∎

**推论 1（子树）**。无 frontier 截断时，v2.0（DHD+DCD）的搜索树是 v1.9（RHD+DCD）的子树，节点数不超过 v1.9。

### 4.4 与 DCD 可交换

**引理 4（commutation）**。对任意 σ，

```text
Max_D( {est ≤ μ} ) = Max_D(Ready) ∩ {est ≤ μ} .
```

**证明**。

- `⊆`：设 `k` 在左边。`k∈{est≤μ}`。若存在 `d∈Ready` 使 `d≻_D k`，DCD 要求 `est_d ≤ est_k ≤ μ`，故 `d` 也在 `{est≤μ}` 中，与 k 的极大性矛盾。
- `⊇`：设 `k∈Max_D(Ready)∩{est≤μ}`。若 `d` 在 `{est≤μ}` 中支配 k，则 `d∈Ready`，与 k 在 Ready 中极大矛盾。∎

**推论 2**。`K ⊆ Max_D(Ready)`，且 DCD 的输入从 `d` 缩到 `d_μ = |{est≤μ}|`。

### 4.5 完备性

**定理 3（DHD 完备性）**。若存在从 σ 出发的可行排程，则存在 DHD-正规形可行排程；PACE-Λ 只分支 `K(σ)` 是完备的。

**证明**。对 `|R|` 归纳。取引理 2 的 S 与 e，`e∈K`。DFS 第 11 步把 e 放在 `t=max(A_k,est_e) ≤ s_e`，子状态不晚于 S 去掉 e 后的状态；由归纳，子树返回可行排程。若 e 不在 `Max_D(K)`，用 v1.8 的 DCD 换槽在 K 内把 S 换成以某个极大元开头（DCD 链在 K 内良基：等 est 时 D 严格增大，或索引减小）。∎

### 4.6 非空性

**定理 4（K ≠ ∅）**。

```text
μ(σ) ≥ est_min := min_{i∈Ready} est_i .
```

**证明**。

- `v = est_{i*}+p_{i*} ≥ est_min + 1`（`p≥1`），所以 `v−1 ≥ est_min`。
- 对任意 `i∈R`，`lst_i ≥ est_i`（引理 1），所以 `λ = min lst_i ≥ min_{i∈R} est_i`。
- 非 ready 任务的 `est` 是某个未调度前驱的 `est+p`，沿前驱链下降必到 ready 任务，故 `min_{i∈R} est_i = est_min`。
- 因此 `λ ≥ est_min`，`μ ≥ est_min`，取到最小 est 的 ready 任务必在 K 中。∎

### 4.7 同步层恒等

**定理 5（synchronous identity）**。若所有 ready 任务的 `est` 都等于 e，则 `K = Ready`。

**证明**。`v = e + min p ≥ e+1 ⇒ v−1 ≥ e`；`λ ≥ min_R est_i = e`（定理 4 的论证）。所以 `μ ≥ e`，每个 `est_i = e ≤ μ`。∎

**意义**：RHD 与 DHD 在同步层同时失效。这不是实现缺陷，是盒子本身的信息量：当所有任务同时释放时，盒子的两个面都退化成同一个点。

### 4.8 严格更强的紧例

取 `m=1`，`i: est=0, p=5, q=0`，`j: est=3, p=1, q=0`，`h=6`。

```text
v   = min(0+5, 3+1) = 4          → RHD 保留 est<4：{i, j}
λ   = min(6−5, 6−1) = 1          → μ = min(3,1) = 1
K   = {i : est=0 ≤ 1} = {i}      → DHD 删掉 j
```

检查：i 先做 0–5，j 在 5–6，可行；j 先做 3–4，i 在 4–9 > 6，不可行。所以 j 确实不可能第一，RHD 保留了一个死分支。∎

### 4.9 集合插入坍缩

**引理 5**。设 `S ⊆ Ready\{j}` 非空且能被完整排进 `[·, est_j)`（每个 i 在 `[est_i, est_j)` 内、用各自资格机器、互不重叠）。令 `i0` 是其中第一个开始的任务。则 `est_{i0}+p_{i0} ≤ est_j`。

**证明**。`i0` 开始 ≥ `est_{i0}`，完成 ≤ `est_j`。∎

**意义**：集合插入成立 ⇒ RHD 判据已成立。想把 RHD 从「一个任务」推广到「一组任务」，在插入这一族里没有新东西。

## 5. 复杂度

设 `d=|Ready|`、`n=|R|`、`c=|K|`，位集 n 位、字长 `ω=64`。

```text
DHD 每节点:
    v                 O(d)
    λ                 O(n)
    过滤              O(d)
    空间              O(1)（复用 q）

DCD（在 d_μ 个任务上）:
    排序              O(d_μ log d_μ)
    包含测试          O(d_μ·c) 次，每次 O(n/ω)
    最坏              O(d_μ·c·n/ω + d_μ log d_μ)

合计（DHD+DCD）:
    O(n + d_μ·c·n/ω + d_μ log d_μ)  ≤  v1.9 的 DCD 成本
主搜索:
    N(σ) = 1 + Σ_{i∈K} N(σ_i)
    最坏仍为指数；本轮不改变最坏复杂度
```

`q` 在 v1.9 里已经由 `tails(inst,rem)` 算过（Horn 层、`t+p+q` 剪枝都要用），所以 DHD 的增量成本就是一次 `min`、一次过滤；它同时把 DCD 的输入从 `d` 缩到 `d_μ`。

实测：38 例 0.0329→0.0324 s，deep 0.0817→0.0807 s，easy 0.1596→0.1602 s（±3% 噪声内）。没有「空转费」。

## 7. 负结果与陷阱

### 7.1 集合插入坍缩

见 4.9。任何「把一组任务插进空闲前缀」的规则，只要集合里第一个任务能在 `est_j` 前跑完，就已经被单任务 RHD 覆盖。**这一族没有新支配。**

### 7.2 反向搜索：自对偶但不划算

时间反演 `t ↦ h−t` 把实例变成 `pred'=succ, succ'=pred`，`est'=q`，OPT 不变。我把 v1.9 原样跑在反转实例上：

| 集合 | 正向 | 反向 |
|---|---:|---:|
| 38 例 | **95** | 60,872 |
| deep 8 | **236** | 434 |

逐例反向从未严格更好。原因：`h=OPT−1` 的探针本来就偏向「源少汇多」；反向等于把容易端换成难端。**方向对偶本身不产生收益**，它只在源/汇不对称的实例族上才有意义，本轮的基准里没有。

### 7.3 预流 LP 被 tier 1.25 包含

时间索引预流松弛：每个任务在自己窗口 `[est_i, d_i]`（`d_i=h−q_i`）里可抢占，每时隙容量 m。可行性由最大流判定，也等价于 Horn 条件

```text
∀ a<b :  Σ_{i: [est_i,d_i]⊆[a,b]} p_i ≤ m(b−a) .
```

tier 1.25 对每个临界 (a,b) 算强制重叠 `mand_i`；对 `[est_i,d_i]⊆[a,b]` 的任务 `mand_i=p_i`，其余 `mand_i≥0`，所以 `tot = Σ mand_i ≥ Σ_{contained} p_i`。于是 `tot ≤ cap` 蕴含 Horn。异质资格下 `subset` 层对每个 S 做同样的事。**预流 LP 拒不掉 tier 1.25 没拒的状态。** 这是本轮最重要的负结果：想靠「更大的凸松弛」拿收益，在这台引擎上没有空间；剩余差距是**非抢占/析取**的。

### 7.4 同步层仍然无解

定理 5 说明 DHD 在同步层恒等。根层所有 source 的 `est=0`，所以：
- 根证书仍然没有（hard3#5 仍是 31 节点，不是 1 节点根闭）；
- `d` 障碍仍然是 `d`；
- 本轮的 20% 全部来自错峰实例。

### 7.5 PFD（j-first 不可行）不值得做

我考虑过「若强制 j 第一个后预流不可行，则删 j」（not-first 容量规则）。它是对的，但在本引擎里收益至多 1 个节点：j-first 不可行时，子状态会被同一层 tier 1.25 立即拒掉。**父节点的 PFD 与子节点的 bound 是同一个计算**，省不出子树。

### 7.6 一个差点写错的规格

`dhd_branch_set` 的 `μ` 含 `v−1`，所以它继承了 RHD 对 NORM 的依赖。最初只在 `if rhd:` 时强制 `normalize=True`；`dhd=True, rhd=False` 会绕过它。虽然所有实验都在 `normalize` 默认 True 下跑，但发货模块已改成 `if rhd or dhd:`。教训和 v1.9 的 7.1 一样：**规则的证明前提必须写进开关，而不是写在注释里。**

## 9. 已知风险

1. **最坏复杂度没变**：仍是线性扩展计数，指数级。同步释放 + 未来两两不可比 + p 两两不同时 `c=d`；定理 5 证明 DHD 在这一层恒等。
2. **根层盲区**：所有 source 的 `est=0`，`λ ≥ 0`，`v ≥ 1`，所以 `μ ≥ 0`，全部 source 都保留。hard3#5 的根证书依然没有。
3. **收益仍集中在少数实例**：38 例的 1.080× 几乎全部来自 hard3#5（38→31）；deep 的 1.058× 来自 3 个实例；`large_*` 与 easy 逐字不变。
4. **held-out 不是全新样本**：由 v1.8 的生成过程（seed 424242）重放，v2.0 没有在它上面调参，但也不是本轮新采的。
5. **公共期限 h**：DHD 只用公共期限与 `q`；若任务有各自期限，`lst_i` 要换成 `d_i−p_i`，规则仍成立（引理 1 的右边直接用 `d_i`），但引擎里没有这条路径，需重证。
6. **NORM 是 `v−1` 面的硬前提**：`dhd=True` 强制 `normalize=True`；只保留 `λ` 面时 NORM 可省，但会丢掉 `v−1` 的收益。
7. **`est` 必须精确**：证明同时用 `est_i ≥ ā_i`（插入）与 `s_j ≥ est_j`（下界）。高估 `est_j` 会破坏下界方向（规则变得不保守），低估 `est_i` 会破坏插入。任何对 `est` 的调高/调低都要重证。
8. **`q` 的拓扑序假设**：`tails` 依赖任务编号是拓扑序；反转/重编号实例时必须重排（本轮 `rev.py` 用 `n−1−i` 重编号）。
9. **frontier 截断破坏严格子树单调性**：`K⊆K_RHD` 是定理，但 `F_sub` 的 K=48 截断与访问顺序可能让个别实例略增；本轮 9,000 随机 + 全部基准里 0 次节点增加。
10. **没有形式化验证**：9,000 随机 + 111,053 穷举 + 独立暴力（v1.9 的 30,000）是很强的证据，但不是 Coq/Lean；定理 1–5、引理 1–5 是纸面证明。
11. **规模**：n≤16（基准）/ n≤22（规模探针，全部根闭）；m=3；PSPLIB 未测；n≥22 的**紧**实例未系统测试。
12. **预流 LP 的负结果有边界**：它只对「预流 + 区间/资格」这一族成立；非抢占的析取推理、时间索引 IP、以及带 precedence 的 LP 不在覆盖范围内，仍可能有空间。
13. **DHD 的收益依赖「错峰 + 紧」**：easy（松）与同步层（根、单根扇出深度 1）都是恒等；如果下一批基准全是同步释放，收益会退化到 1.0。

---

## 10. 一句话最大风险

**DHD 与 RHD 是同一个盒子的两个面：当一层 ready 任务同步释放时两个面同时失效，分支因子仍是 d，最坏情况仍是 n!，hard3#5 的根证书依然没有。**
