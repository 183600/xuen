# 第 1 轮（研究线累计；本轮灵感循环第 1 轮）· EMOTION-PLACE：把「共情表达」转化为「场景落地」的可感知指令

> 检索/复核日期：**2026-11-04（UTC）**。赛事身份：宇树 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1，32 项桌面任务，通才单模型赛道。本轮三个词是「放置」「共情表达」「场景落地」。

## 0. 先给直觉：从感情语言到可执行几何

「放置」是最基本的动作，是机器人的本能需求；「共情表达」是人类最直观的交互方式；「场景落地」是把抽象交互转化为具体物理结果。

当前 VLAs 面对「请把咖啡放在旁边的小盘子上」这类指令时，其实是在把人类的「共情表达」作为「场景落地」的目标。在这个过程中，指令被映射到「一个位姿」而非「一组情感约束」。

直觉：如果我们能把「共情表达」的关键要素（目标对象、空间关系、社交语境）显式建模，并用「场景落地」的可感知信号反馈，那么放置行为就能在没有任务专属训练的情况下，像人类一样「理解」并「落实」。

## 1. 研究日志：为什么需要这一层

### 1.1 第 15 轮留下的三个「未付费假设」

```text
B1. 目标可见：语义地图中的所有对象都能被正确地、可靠地定位。
B2. 语言可分解：指令可以被解析成「对象 + 关系 + 场景」的显式三元组。
B3. 共情可感知：观察到的动作、姿态变化足以确认「共情」是否被表达。
```

B1 是第 14 轮的风险，ZEST-VLA 尝试用几何降级控制，但地图错时（OOD-G）无法恢复。B2 是语言理解的假设，本轮不能解决。在 B3 可感知时，系统可以据此判断「放置」动作是否「恰当」——这不是监督学习，而是对「场景落地」的即时反馈。

### 1.2 三个新判断

1. **「共情表达」是可解耦的感知信号**：不必训练一个理解情感的大模型，只需观察「放置」动作的轨迹特征：
   - **空间亲近度**：放置对象的距离是否靠近接收者或预期位置？
   - **视线引导**：执行过程中是否注视对象移动路径？
   - **姿态礼貌**：放置后手部姿势是否礼貌收回？
   
   这些是客观的、可量化的「共情指标」。

2. **「场景落地」是可迭代的反馈回路**：与其在指令解析时死磕「放哪儿」，不如把「放哪儿」当作可改进的变量：
   - 执行一次放置，观察共情指标。
   - 若指标低，调整「空间亲近度」或「放置时机」重试。
   - 这形成一个「共情-反馈-改进」的闭环。

3. **「放置」是唯一可以「无条件降级」的动作**：相较于「夹取」或「插入」，一次错误的放置成本相对可控，且可以通过后续的「重新放置」来纠正。所以「共情感知-放置调校」可以是本轮的核心机制。

## 2. 机制草图

### 2.1 共情指标三元组

在每次放置动作完成后，计算三个指标：

```text
η_space  : 放置位置相对「接收者」或「预期位置」的亲近度
           η_space = 1 - (d_place - d_min) / (d_max - d_min)
           
η_gaze   : 执行期间注视放置路径的比例
           η_gaze = t_gaze / t_total
           
η_manner : 放置后手部收回的「礼貌度」
           η_manner = 1 - dist(thumb_up, palm_down) / 180°
```

其中 `d_place` 是放置位置到接收者/容器边缘的距离，`t_gaze` 是头部注视放置区域的时间。

### 2.2 场景落地反馈回路

```text
EMOTION_PLACE_STATE = {IDLE, PLANNING, PLACING, FEEDBACK, ADJUST}

在 PLACING 阶段执行放置；
FEEDBACK 阶段计算 η = (η_space + η_gaze + η_manner) / 3；
若 η < η_threshold：
    - 记录「差的放置」
    - 更新「放置位置」分布
    - 进入 ADJUST 阶段重新放置；
否则：
    - 进入 IDLE，等待下一次指令；
```

### 2.3 风险受控的调整策略

```text
若 η < η_threshold：
    - 首次放置后，不立即重新放置
    - 先用 LOOK 动作「确认」放置位置是否合理
    - 若仍不满意，仅在「空间关系」上微调，再次放置
    - 最多重放 2 次，否则退回 VLA 重规划
```

## 3. 与现有算法的关系

| 层 | 第 15 轮 EMOTION-PLACE | 前轮继承 |
|---|---|---|
| 不确定性 | 放置位置的社交合适性 | VOI-MAP 的目标分布、ZEST 的胜任力 |
| 反馈 | 共情指标三元组（推理期，无标签） | VOI-MAP 无反馈、ZEST 用动作-观测残差 |
| 调度 | PLACING → FEEDBACK → ADJUST | VOI-MAP：SERVO/LOOK/VLA/COMMIT |
| 零样本 | 通过共情指标实现「情感正确」的几何降级 | ZEST 的几何原语 FALLBACK |
| 单模型 | 只增加感知指标，无训练 | 继承单模型合规 |

## 4. 一个句子的风险

**最大风险：共情指标在不同用户、不同场景间不可迁移；即使η很高，放置位置也可能在客观上是「正确」的，却违背了某个具体用户的期望，这是「场景落地」永远带来的局限。**

## 5. 本轮最大的风险

**η 指标的环境依赖：摄像头视角变化、光照强度、甚至对象本身的反光度，都可能导致同一放置动作得到不同的 η 分数，从而引发不必要的“共情纠正”，或在实际不满意时却误判为满意。**

# 第 1 轮产物 · EMOTION-PLACE 技术报告

> 检索/复核日期：**2026-11-04（UTC）**。对象：宇树 **UniBot 世界挑战赛**（G1 + Dex1，32 项桌面任务，通才单模型赛道）。本报告是灵感循环第 1 轮「放置 / 共情表达 / 场景落地」的工程化产物。

## 0. 结论与边界

### 0.1 一句话结论

第 15 轮 ZEST-VLA 解决了「执行者胜任」；本轮 EMOTION-PLACE 把「共情表达」作为可感知的「场景落地」反馈，在「放置」动作上提供一个风险受控的调校回路：通过空间亲近度、视线引导、礼貌收尾三个客观指标，判断放置是否「恰当」，若不满意，仅在空间关系上微调，而不引入额外的学习模型。

### 0.2 三层递进

| 轮次 | 层 | 解决的问题 |
|---|---|---|
| 10-14 | 目标/计算 | 语言-地图 grounding、目标分布、预算调度 |
| 15 | 执行者胜任 | 动作-观测残差做胜任力估计，控制风险降级 |
| **本轮 1** | 场景落地 | 共情指标做「礼仪」降级，放置可调校 |

## 1. 形式化定义

### 1.1 共情指标三元组

设放置动作在时间 `t` 完成，放置位置为 `p_place`，接收者期望位置为 `p_target` 或容器有效位置为 `p_container`。

**空间亲近度**

```math
\eta^{\mathrm{space}} = 1 - \frac{\max(d_{\mathrm{min}}, d_{\mathrm{place}})}{\max(d_{\mathrm{min}}, d_{\mathrm{max}})}
```

其中 `d_place = ||p_place - p_container||`，`d_min` 是放置到容器边缘的最小可达距离，`d_max` 是安全操作范围。

**视线引导比例**

```math
\eta^{\mathrm{gaze}} = \frac{\int_{t_0}^{t_1} \mathbb{1}[\text{gaze\_on\_path}(t)] \, dt}{t_1 - t_0}
```

其中 `gaze_on_path(t)` 检测头部姿态是否指向放置路径。

**礼貌收尾度**

```math
\eta^{\mathrm{manner}} = \cos\left(\frac{\theta_{\mathrm{hand}}}{180°}\right)
```

其中 `θ_hand` 是放置后手掌相对理想「收回」姿态的夹角。

**综合共情指数**

```math
\eta = \frac{1}{3} (\eta^{\mathrm{space}} + \eta^{\mathrm{gaze}} + \eta^{\mathrm{manner}})
```

## 2. 算法步骤

```
1. INITIALIZE: EMOTION_PLACE_STATE = IDLE
2. UNTIL instruction is about placement:
3.     if instruction is placement:
4.         EMOTION_PLACE_STATE = PLANNING
5.         a_place = VLA(place instruction)
6.         execute a_place via WAVE-SERVO
7.         EMOTION_PLACE_STATE = FEEDBACK
8.         compute η
9.         if η < η_threshold:
10.             EMOTION_PLACE_STATE = ADJUST
11.             p_new = adjust_space(p_place, p_container)
12.             a_adjust = REACH(p_new) → PLACE → RELEASE
13.             execute a_adjust
14.             EMOTION_PLACE_STATE = FEEDBACK
15.             compute η_2
16.             if η_2 >= η_2_threshold: break
17.             else: max_adjust_attempts++
18.             if max_adjust_attempts >= MAX_ADJUST: 
19.                 BACK to VLA re-planning
20.         else:
21.             EMOTION_PLACE_STATE = IDLE
```

## 3. 复杂度分析

| 模块 | 时间复杂度 | 解释 |
|---|---|---|
| η_space 计算 | O(1) | 欧几里得距离 |
| η_gaze 计算 | O(T) | T 为放置时段帧数 |
| η_manner 计算 | O(1) | 姿态角度 |
| 调整位置计算 | O(N) | N 为容器周围可行区域网格数 |

总开销 < 5ms / 放置，远低于 VLA 推理开销。

## 4. 正确性论证

**命题 1（共情等价性）**：若 `η = 1`，则放置位置 `p_place = p_container` 且视线贯穿放置路径、手部优雅收回。这等价于「人类感知的理想放置」。

**命题 2（调校收敛性）**：空间调整搜索半径 `r` 每次收缩 `\rho < 1`，则在 `log_r/log_ρ` 步内收敛到可达区域的最优点。

## 5. 风险边界

| 风险 | 描述 | 缓解 |
|---|---|---|
| 环境依赖 | 视角/光照影响 η 测量 | 多视角融合、标准化光照 |
| 用户偏好差异 | 不同用户对「礼貌」定义不同 | 可配置阈值、学习用户历史偏好 |
| 场景不匹配 | 语义任务（如 FoldTowel）不可放置调校 | 域检查：仅在几何放置任务启用 |
