# 第 10 轮 · FACT-VLA：把力控写进接触相位，把比赛写进证据

> 检索/复核日期：2026-10-27（UTC）。赛事身份不变：宇树 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API。本轮三个灵感词是「力控」「比赛策略」「行为克隆」。状态文件上一轮是第 9 轮 R3-VLA（Regroup / Rephrase / Recover）；本轮不推倒它，而是把它降为泛化与恢复骨架，把主火力移到**接触相位**。

## 0. 先给结论：不能测力，就控制“接触相位”

本轮最重要的判断是：**官方 API 只给位置/姿态/夹爪，不给力矩、电流、触觉或力命令；因此“力控”不能实现成力传感器闭环，只能实现成“接触相位的柔顺行为克隆”。**

具体拆成四层，共用一个 checkpoint：

1. **FACTOR**：用夹爪滞止、视觉接触、以及可选的单步响应亏空，构造**无传感器接触/力代理**；不声称得到牛顿值，只要求单调、可校准、低延迟。
2. **CPT（Contact-Phase Training）**：把轨迹切成自由、接近、接触、抓取、搬运、释放六类相位；用软相位标签做接触加权采样、相位条件动作专家、接触段动作噪声、柔顺/抓稳辅助损失、相位边界头。
3. **CAC（Compliance-Aware Control）**：推理时按相位缩动作、低通滤波、在相位边界截断 chunk、剩余动作填保持/回撤安全端点；夹爪“闭合到滞止”，接触异常触发重对齐/回撤。
4. **EGP（Evidence-Gated Portfolio）**：比赛策略不是“押最难的”，而是**先探测、再分配**；用分层贝叶斯把 10 次试验的成功率不确定性写进分配，成功优先，步数分只在平台期做保险。

一句话：**把“力”从不可观测的传感器变量，改写成可观测的接触相位与响应变量；把“比赛”从拍脑袋选题，改写成带证据门的序贯决策。**

## 1. 这轮怎么想：三个灵感词是一条链

### 1.1 力控：先问“观测量是什么”

官方观测只有关节位置/EE 位姿/夹爪，动作是位置目标。没有 torque、current、tactile，也没有 force 指令。于是有三条路：

- **硬做力估计**：从关节残差/电流反推力矩。问题是数据里没有电机电流，关节残差又受目标超前、重力、摩擦、控制器带宽影响；本轮实测发现原始 `action - next_state` 主要反映目标 lookahead，不是外力。
- **加触觉**：HapticVLA 证明触觉训练可以在部署时去掉触觉，但我们的数据没有触觉，推理 API 也不给触觉；没有训练信号，不能凭空造。
- **控制接触相位**：不估计绝对力，只识别“现在是否在接触、接触是否在建立、物体是否在抵抗、抓取是否在滑”。这些可以从夹爪滞止、视觉、动作-响应关系里弱监督得到。

选第三条。它不是“退而求其次”，而是**与 API 契约一致、与数据形态一致、与 BC 的训练目标一致**的唯一务实路线。

### 1.2 比赛策略：先问“排行榜能不能信”

本轮核对到排行榜 JSON 的 `generated_from` 是 `gen_leaderboard.py`，details/runs 页面是占位；29.7% 的 MolmoAct2 不是可复现的真机 SOTA，而是种子数据。更关键的是：把 8 个模型的占位成功率按任务平均后，与我们的接触强度做 Spearman，只有 **-0.04**。也就是说：

- 不能因为某任务“接触强”就认定它难；
- 不能把公开排行当任务难度表；
- 不能把 10 次试验的噪声当模型差异。

所以比赛策略必须是**证据门控的序贯分配**：先花少量 trial 探测，再用后验决定把数据、调试、提交花在哪；成功率先行，步数分只在成功平台期做保险；任何方法开关必须先过预注册门。

### 1.3 行为克隆：先问“数据里哪段被淹没了”

33,276 条成功轨迹里，自由空间和搬运段占绝大多数，真正的接触/插入/抓稳段很短。标准 BC 的采样是按帧均匀或按轨迹均匀，接触段被自由段淹没；而失败恰好集中在接触段。于是：

- 接触段需要**加权采样**，但不能只加权接触，否则自由段回归；
- 接触段需要**相位条件**，否则同一个观测在“接近”和“插入”下应有不同动作尺度；
- chunk 一旦进入接触，开环执行会放大误差，需要**相位边界截断**；
- 成功数据没有失败恢复，需要**接触段动作噪声/扰动**制造“接近失败”的样本。

这三条正好对应本轮的三层训练/运行时设计。

## 2. 五个硬事实

### 2.1 API 是位置接口，不是力接口

官方 README 明确：`metadata`、`get_action`、`reset`；`control_space` 只能是 `"joint"` 或 `"ee"`，二者互斥；观测是关节位置/EE 位姿/夹爪；动作块大小固定。没有 torque/current/tactile/force 字段，也没有力命令通道。**任何“力矩控制/力反馈闭环”的方案都必须先证明接口支持，否则是幻觉。**

### 2.2 数据很大，但没有力标签

32 个 HF 数据集合计 **33,276 episodes / 18,282,246 frames / 169.28h / 30fps / 4 相机**；挑战页写“32,000 episodes / 169h”是取整。特征是关节、EE 位姿、夹爪、图像、语言；**没有 torque/tactile**。所以监督只能来自动作-状态-视觉的弱信号。

### 2.3 接触段分布极不均衡，但夹爪滞止是干净信号

用 32 个任务各第一个 parquet 统计：夹爪“命令闭合但状态未跟上”的负载帧占比从 **3.4% 到 53.5%**，中位数 19.2%。接触强度最高的任务包括 PlugInEthernet、PlugCharger、DisconnectEthernet、SyringeWaterTransfer、StoreEarphones、PackBag、ToolboxStorage、PourOutMedicine、PlacePhotoFrame、StorePaddle、Unlock。这个信号不需要额外传感器，且与“抓取是否建立”直接相关。

### 2.4 原始动作残差不是力，别把它当力

本轮对齐检查发现：动作目标相对状态有 **约 2–3 帧超前**；状态每帧只动约 **1.2 mm**，而 `action - state` 的典型差距约 **18.7 mm**。因此 `a_t - s_{t+1}` 主要是在量“目标超前多少”，不是在量“外界阻力多大”。直接把它当力会得到漂亮但错误的相关性。**结论：保留夹爪滞止；臂部接触用视觉 + 相位 + 可选的 learned response deficit，不把原始残差写成 force。**

### 2.5 排行榜是占位，接触强度不能预测公开成功率

8 个模型 ×32 任务的排行榜由 `gen_leaderboard.py` 生成；details/runs 是占位。接触强度与占位平均成功率的 Spearman 仅 **-0.04**；夹爪负载占比与成功率的 Spearman 约 **-0.24**（弱负相关，且仍受占位数据影响）。所以：

- 接触强 ≠ 一定难；
- 接触弱 ≠ 一定易；
- 选题必须探测，不能从接触强度直接推难度。

## 3. 为什么不是其他路线

| 路线 | 为什么不做 | 本轮替代 |
|---|---|---|
| 力矩/电流闭环 | API 无 torque/current，数据也无 | 夹爪滞止 + 相位柔顺 |
| 触觉传感器 | 推理 API 无触觉，训练数据也无 | HapticVLA 只作旁证，不当前提 |
| 显式力命令 | 动作空间不接受力 | 位置动作缩放/低通/边界截断 |
| 完整世界模型/MPC | 接触动力学难、延迟高、单模型约束 | 单步响应头（可选）+ 运行时规则 |
| RL / 大规模 sim-to-real | 时间、sim gap、真机安全 | 先 BC + 动作噪声，不上 RL |
| DAgger / 人类在线纠正 | 无交互评测、人力贵 | 成功数据 + 合成扰动 |
| 纯 prompt/paraphrase | 上一轮 R3 已覆盖，不解决接触 | 保留 R3，主攻接触 |
| 只按接触强度分配 trial | 与占位成功率几乎无关 | 证据门控 probe + 后验分配 |

## 4. FACT-VLA：四层，一个 checkpoint

### 4.1 FACTOR：无传感器接触/力代理

对每个时刻，构造三个可观测分数：

- **夹爪滞止**：`g_t = max(0, s_t^g - a_t^g)`，归一化到夹爪行程；高值表示“命令闭合但夹爪没走到”，对应物体抵抗/抓取建立。
- **视觉接触**：腕部相机图像经共享视觉编码器得到接触 logit；不作为硬标签，只作为特征。
- **响应亏空（可选）**：在自由空间段训练一个单步前向头 `f_θ(s_t, a_t, z_t) -> Δs_{t+1}`；接触时残差 `e_t = ||Δs_{t+1} - f_θ(·)||` 升高。它只作为辅助证据，训练/推理都挂在同一 checkpoint 上；若延迟或泛化不过门，直接剪掉。
- **接触分数**：`c_t = σ(α g_t + β e_t + γ v_t + δ visual_logit)`；`v_t` 是视觉/夹爪的辅助项。阈值用 200 帧人工标注校准，报告 AUROC/AUPRC/ECE，不报告“牛顿”。

**校准**：在调试槽用电子秤/弹簧秤做 0/2/5/10 N 按压，记录 `g_t/e_t`，拟合单调映射；只报告 Spearman 与单调性，不把 proxy 当计量力。没有调试槽就只做排序，不做绝对值。

### 4.2 CPT：相位化行为克隆

**相位定义（软标签，不硬切）**：

- P0 自由空间/接近；
- P1 预接触对齐；
- P2 接触/插入/力建立；
- P3 抓取/负载；
- P4 搬运；
- P5 释放/回撤。

标签来自 FACTOR 的变点检测 + 夹爪状态 + 动作幅度，人工只抽检 2–3 条/任务。标签有噪声，所以用软概率、标签平滑、熵正则，不做逐帧硬分类。

**训练目标**：

- **接触加权采样**：`w_t = 1 + λ_c * c_t`，按相位分层，限制单相位占比，防止自由段遗忘。
- **相位条件动作专家**：把相位嵌入加到 action expert 的 token/AdaLN；相位头与动作头共享 backbone。
- **相位边界头**：预测“到下一个相位边界还有几步”；训练时用弱标签，推理时用于截断 chunk。
- **接触段动作噪声**：只对 P2/P3 的 flow-matching 端点加最坏情况噪声，训练“被挡一下还能回来”；自由段不加，避免无谓抖动。
- **柔顺损失**：`L_comp = E[1_contact * max(0, ||Δa|| - cap)^2]`，让接触段动作更小、更平滑；cap 按任务/相位自适应，不做全局硬限。
- **抓稳辅助损失**：用 `g_t` 和未来 H 步是否掉物体（可由夹爪状态/视觉弱标签）训练一个“抓稳概率”头；它不直接输出力，只调制夹爪闭合策略。
- **边界一致性**：同一轨迹相邻 chunk 的相位/边界预测做时序一致性，减少 chunk 边界的相位跳变。

**为什么是 BC 而不是 RL**：成功数据充足、失败数据缺失、真机试错昂贵；先把接触段的条件分布学对，再用动作噪声制造“近失败”样本，是成本最低的分布扩展。

### 4.3 CAC：推理端把“柔顺”兑现

- 动作块仍按 API 返回完整长度；我们只执行**可靠前缀**，剩余填保持/小回撤/预放置安全端点。
- 接触相位内：动作增量按 `cap_c` 缩放 + 一阶低通；不是全局减速，只在 P2/P3 生效。
- 夹爪：闭合到滞止；若 `g_t` 低于阈值，继续闭合；若检测到滑移（负载突降/视觉位移），重抓。
- 相位边界：`L* = min(H, argmax boundary)`；边界前执行，边界后不硬闯。
- 异常：接触分数高但末端位移/视觉进度持续为零 K 步，触发小回撤 + 重对齐；不可逆任务只回撤到安全点，不做大范围探索。
- 延迟预算：FACTOR 只用夹爪 + 视觉时 <2 ms；加前向头若 p99 超预算就剪掉。所有开关有 per-task 配置，默认保守。

### 4.4 EGP：比赛策略是序贯证据问题

- **先探测**：按接触强度、双臂/单臂、长程/短程、可逆/不可逆分层，选 10 个任务做 probe；不假设接触强=难。
- **后验**：每个任务成功率 `p_i ~ Beta(α_i, β_i)`，先验用任务族/接触层做分层收缩；步数分 `s_i` 单独建模；记录 trial 成本。
- **分配**：成功优先；`score_i = P(p_i > p_ref) * (1 - risk_i) + λ * E[step_gain_i]/cost_i`；平台期才提高 λ；保留 10% 探索。
- **停止**：后验概率“比基线高 5pp”低于 0.2 就停；同一任务连续 0/10 两次就冻结检查，不追单任务噪声。
- **提交**：保留 known-good checkpoint；先交安全版，再交 probe 版；规则允许时早交；不允许就等证据门。提交次数未知，默认稀缺，不烧提交。

## 5. 与第 9 轮 R3-VLA 的关系：保留、剪枝、加一层

**保留**：

- Regroup：192 个 session 作为免费域标签，session-grouped 验证；防止随机切分泄漏。
- Rephrase：5 条官方复述做 dropout/一致性/留一复述验证；这是便宜的语言鲁棒性。
- Recover：官方人扰备注 → 动作噪声/恢复训练；SURE-BT 作为运行时骨架。
- DGS-32 的三重留出与配对统计。

**剪枝**：

- 不把“力估计”写成“力矩控制”；不假设 F/T、电流、触觉。
- 不把原始关节/EE 残差当力；本轮实测它主要反映目标超前。
- 不做接触强度→难度的直接分配；与占位成功率相关性接近零。
- 不先上完整世界模型/MPC/RL；接触相位的 BC 更便宜。
- 不把 VFCS 的 K=2 当默认；延迟 p99 不过门就退回 K=1。
- 不把 AEH 当万能；若截断在接触段造成更多卡住，就只保留安全端点。

**新增**：

- FACTOR 接触/力代理；
- CPT 相位化 BC；
- CAC 柔顺运行时；
- EGP 证据门控比赛策略；
- DGS-32C：在上一轮评测上加“接触切片”。

## 6. 实验与门控（先写死，避免事后找理由）

| 门 | 问题 | 通过标准 | 失败动作 |
|---|---|---|---|
| G0 | FACTOR 是否识别接触？ | 人工 200 帧 AUROC ≥0.80；夹爪子集 ≥0.85 | 砍掉前向头，只留夹爪+视觉 |
| G1 | 相位化 BC 是否涨接触段？ | 接触切片成功率 +5pp；自由段回归 ≤1pp | 降 λ_c / 去掉柔顺损失 |

## 7. 风险与合规

- **标签噪声**：相位标签是弱监督；用软标签 + 人工抽检 + 消融，不把相位头当真值。
- **过拟合接触**：接触加权可能牺牲自由段；用相位分层和自由段回归门。
- **代理不等于力**：所有对外表述用“contact/force proxy”，不写“测得牛顿”；校准只报排序。
- **单模型合规**：所有头共享同一 checkpoint；前向头是辅助头，不是第二个在线策略；若必须独立模型，直接剪掉。
- **外部数据**：默认 OFF；只用官方 33k；复述增广用规则模板。
- **真机安全**：接触段动作 cap、低通、回撤、不可逆任务白名单；调试槽校准需安全员。
- **排行榜误读**：明确写“占位数据，不作 SOTA 声明”；不用它证明方法有效。

## 8. 一句话押注

**在位置接口、无力传感器的约束下，用夹爪滞止 + 视觉接触 + 可选响应亏空做接触相位弱监督，把接触段的行为克隆、柔顺动作和 chunk 边界截断写进同一个 WLA-1.0-Base checkpoint，再用证据门控的 probe 分配比赛 trial——这是本轮最值得押注、也最能在官方 API 上落地的一条线。**

# 第 10 轮产物区 · FACT-VLA 技术报告（Force-proxy Aware Contact-phase Training for VLA）

> 目标赛事：宇树 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API。检索/复核日期：**2026-10-27（UTC）**。本报告承接第 9 轮 R3-VLA（Regroup / Rephrase / Recover），但主火力转向**接触相位**：不假设有力传感器，不把位置接口伪装成力矩接口，而是用可观测的接触代理把“力控”写进行为克隆与运行时。

## 0. 产物摘要

**核心命题**：官方 API 只有位置/姿态/夹爪，没有 torque/current/tactile/force 通道；因此本轮不实现“力传感器闭环”，而实现**无传感器接触相位控制**：

1. **FACTOR**：夹爪滞止 + 视觉接触 + 可选单步响应亏空，构成接触/力代理；只要求单调、可校准、低延迟，不声称牛顿值。
2. **CPT**：六类接触相位的软标签、接触加权采样、相位条件动作专家、接触段动作噪声、柔顺/抓稳辅助损失、相位边界头。
3. **CAC**：推理时按相位缩动作、低通、边界截断 chunk、尾段填保持/回撤；夹爪闭合到滞止，异常触发重对齐/回撤。
4. **EGP**：证据门控的资源分配与提交策略；先探测，再用分层贝叶斯后验决定训练/调试/提交，不把占位排行榜当难度表。

**一句话**：把不可观测的“力”改写成可观测的“接触相位 + 响应”，把“比赛策略”改写成“带证据门的序贯决策”，全部挂在同一个 WLA-1.0-Base checkpoint 上。

**明确不做**：

- 不做力矩/电流闭环（API 与数据都不支持）；
- 不做触觉输入（推理没有，训练也没有）；
- 不把原始 `action - next_state` 当力（本轮实测其主要是目标超前）；
- 不先上完整世界模型/MPC/RL（成本高、接触动力学难、单模型/延迟约束）；
- 不按接触强度直接分配比赛 trial（与占位成功率几乎不相关）。

## 1. 事实核对（2026-10-27）

### 1.1 赛事与评分

- 赛事：**UniBot 世界挑战赛 / UniBot World Challenge**，G1 + Dex1，32 项真实桌面操作任务，通才单模型赛道；选手自部署策略，官方通过远程真机 API 调用（[S1][S2][S3][S4]）。
- 任务：32 项，覆盖抓取、放置、双手协调、接触-rich 操作（插网线、插充电器、拔网线、针管转移、开锁、倒药、拉拉链等）。
- 评分：每任务 10 次试验；5 个泛化轴各 2 次；主指标为平均成功率；同分时看平均 step score；再同分看更早提交。单任务限时 180 s；单模型。
- 泛化轴：未见物体/位置/背景/干扰物/语言复述等；具体以官方规则为准（[S2][S3]）。
- 提交次数/截止日期：公开规则摘录中未看到明确上限；本报告不假设无限次提交，策略默认“提交稀缺”。

### 1.2 API 契约

官方 Submission Template 明确（[S4]）：

- 策略类只需实现 `metadata`、`get_action(obs)`、`reset()`；由 `PolicyService` 在本机服务，评测端作为客户端调用。
- `metadata` 包含：
  - `control_space`: `"joint"` 或 `"ee"`，二者互斥；
  - `obs_delta_indices`: 声明哪些观测被发送，以及每个 key 的时序堆叠偏移；
  - `image_resize`: 图像缩放；
  - `action_chunk_size`: 固定 chunk 长度，`int >= 1`；
  - `token`: 官方发放的提交 token。
- 观测：
  - 4 路 RGB：`cam_left_high`、`cam_right_high`、`cam_left_wrist`、`cam_right_wrist`，默认 480×640；
  - 左右臂关节 `[7]`；
  - 左右 EE 位姿 `[6]`（xyz + rpy，base frame）；
  - 左右夹爪开合 `[1]`；
  - 下身体 `[15]`；
  - 语言指令 `str`。
- 动作：
  - `control_space="ee"`：左右 EE 目标 + 夹爪；
  - `control_space="joint"`：左右臂关节目标 + 夹爪；
  - 没有 torque/current/tactile/force 输入，也没有力命令输出。
- `obs_delta_indices` 允许我们请求历史帧（例如前 2–4 帧的 EE/夹爪/腕部图像），这对 FACTOR 的响应估计很重要；但会增加带宽/延迟，必须做预算。
- `meta.token` 必须出现在**每一次** `get_action` 返回值里，不只是 `metadata`；评测端每步校验。
- 官方 README §6 提到会记录每步延迟、波动、动作统计规律性，并可能用于结果可信度判断；因此运行时不能为了“更聪明”而引入不可控的延迟尖峰（[S4]）。

### 1.5 动作语义实测：原始残差不是力

本轮抽了 PlugCharger、HangCup、SyringeWaterTransfer、FoldTowel 四条轨迹做 action-state 对齐：

| 任务 | 最佳滞后（帧） | 最佳滞后误差 | 0 滞后误差 | 结论 |
|---|---:|---:|---:|---|
| PlugCharger | 2 | 11.9 mm | 13.2 mm | 目标超前约 2 帧 |
| HangCup | 3 | 11.2 mm | 14.8 mm | 目标超前约 3 帧 |
| SyringeWaterTransfer | 2 | 16.9 mm | 19.3 mm | 目标超前约 2 帧 |
| FoldTowel | 2 | 14.2 mm | 17.0 mm | 目标超前约 2 帧 |

补充统计（PlugCharger 示例）：

- 状态每帧只移动约 **1.2 mm**；
- `action - state` 的典型差距约 **18.7 mm**；
- 即使按最佳滞后对齐，残差仍有 **1.1–1.7 cm**，远大于单帧状态位移。

**解释**：原始 `a_t - s_{t+1}` 主要量的是“目标超前 + 标定/坐标差”，不是“外界阻力”。把它当力会得到好看但虚假的相关性。**臂部接触只能作为弱证据（视觉 + 相位 + 可选 learned response deficit），不能写成 force。** 夹爪滞止是更干净的信号，因为“命令闭合但夹爪没走到”直接对应物体抵抗。

## 2. 数据分析

### 2.1 接触代理定义

本轮用 32 个任务各第一个 parquet 做探索性统计（不是全量训练集统计；全量会更大，但趋势已足够）：

- **夹爪负载/滞止**：
  `g_t = max(0, s_t^g - a_t^g) / (g_max - g_min + ε)`。
  夹爪原始范围约 0.3–4.65；`s_t^g > a_t^g` 表示“夹爪被物体挡住，没走到命令位置”。`load_frac` 是 `g_t > 0.05` 的帧占比（探索脚本用原始差 >0.2，约等于 4.6% 行程）。
- **关节响应残差**：`r_t = ||a_t^arm - s_{t+1}^arm|| / joint_range`；`resid_p95` 是 95 分位；`blocked10` 是 `r_t / step_t > 10` 的帧占比。它受目标超前影响，只作为辅助。
- **接触强度**：`contact_intensity` 是 `load_frac / blocked10 / resid_p95 / bimanual_frac` 四项百分位排名的均值（0–1 复合排序）。它是**分层/探测用的启发式**，不是物理量，也不是难度标签。
- **注意**：这些统计只用于“哪些任务接触段更长/更值得看”，不用于“哪个任务一定难”。

### 2.3 占位成功率与接触代理的相关性

把 8 个模型 ×32 任务的占位成功率按任务平均，再与接触代理做相关：

| 变量 | Pearson | Spearman |
|---|---:|---:|
| contact_intensity | -0.150 | -0.043 |
| load_frac | -0.317 | -0.242 |
| resid_p95 | +0.179 | +0.325 |
| blocked10 | -0.038 | -0.073 |
| bimanual_frac | -0.239 | -0.136 |

**解释**：

- `contact_intensity` 与占位成功率几乎不相关（Spearman -0.04）；“接触强=难”不成立。
- `load_frac` 有弱负相关（-0.24），但占位数据本身不可信，不能据此排难度。
- `resid_p95` 反而正相关（+0.32），进一步说明“原始残差”受任务运动学/目标超前影响，不能当力。
- 占位排行榜最低的任务包括 PlugInEthernet 17.7%、Unlock 20.1%、SpellRobot 21.8%、OrganizeStationery 22.5%、PourOutMedicine 22.7%；有接触重的，也有接触轻的——再次证明不能只看接触。

### 2.4 对方法的直接含义

1. **夹爪滞止**是最可靠的部署信号：只需 `observation.state.*_gripper` 与上一条动作的夹爪命令，零额外模型、零额外带宽。
2. **臂部接触**不能靠原始残差；用腕部视觉 + 相位 + 可选 learned response deficit，且必须过 G0 门。
3. **接触加权**必须有上限和相位分层，否则自由段退化。
4. **比赛分配**必须用 probe 证据，不能用接触强度排序。
5. **评测**必须加“接触切片”，否则平均成功率会把接触段的改进淹没在自由段里。

## 3. 方法

### 3.1 问题形式化

给定观测 `o_t`（多相机 + 关节 + EE + 夹爪 + 语言）与动作块 `a_{t:t+H}`，学习：

```math
\pi_\theta(a_{t:t+H} \mid o_t, l, z_t, b_t)
```

其中 `z_t ∈ {P0..P5}` 是软相位，`b_t` 是到下一个相位边界的剩余步数。训练目标：

```math
\mathcal{L} =
\mathcal{L}_{\text{flow}}
+ \lambda_z \mathcal{L}_{\text{phase}}
+ \lambda_b \mathcal{L}_{\text{boundary}}
+ \lambda_c \mathcal{L}_{\text{contact}}
+ \lambda_{\text{comp}} \mathcal{L}_{\text{comp}}
+ \lambda_g \mathcal{L}_{\text{grasp}}
+ \lambda_r \mathcal{L}_{\text{recover}}
+ \lambda_{\text{reg}} \|\theta\|^2
```

- `L_flow`：WLA action expert 的 flow-matching/回归损失（沿用官方训练框架，[S8][S9]）。
- `L_phase`：软标签交叉熵/焦点损失；标签来自 FACTOR 变点 + 夹爪状态 + 动作幅度。
- `L_boundary`：到边界的剩余步数做 ordinal/分类回归；只在相位切换附近加权。
- `L_contact`：接触分数与弱标签的一致性（可选；若 G0 不过则去掉）。
- `L_comp`：接触段动作增量/平滑惩罚。
- `L_grasp`：抓稳概率辅助二分类（未来 H 步是否保持负载/不掉落）。
- `L_recover`：R3 的动作噪声/恢复一致性（可选）。

### 3.2 FACTOR：无传感器接触/力代理

#### 3.2.1 三个信号

**(a) 夹爪滞止（主信号，部署必开）**

```math
g_t = \frac{\max(0, s_t^g - a_{t-1}^g)}{g_{\max}-g_{\min}+\epsilon}
```

- `s_t^g` 是当前夹爪开合；`a_{t-1}^g` 是上一条下发的夹爪命令。
- 高值 = 命令更闭合但夹爪被物体挡住 = 抓取建立/物体抵抗。
- 需要按夹爪行程归一化；不同任务/左右手分别归一化。
- 阈值 `τ_g` 用夹爪关闭段的分布定（例如 0.05–0.10 行程），加迟滞，避免抖动。

**(b) 视觉接触（辅助，部署可开）**

- 腕部相机 `cam_left_wrist` / `cam_right_wrist` 经共享视觉编码器，输出接触 logit。
- 训练标签不是人工逐帧标，而是用 FACTOR 的弱标签 + 人工抽检做校准；视觉头只作为特征，不单独当真值。
- 作用：区分“夹爪挡住但没接触物体”和“真的接触/插入”；对插网线、插充电器、针管等末端接触很关键。
- 成本：共享编码器，额外算力小；若延迟超预算，只用夹爪。

**(c) 单步响应亏空（可选，研究项）**

- 在自由空间段（`g_t < τ_g` 且视觉接触低）训练一个轻量前向头：
  `f_θ(s_t, a_t, z_t, a_{t-1}) -> Δs_{t+1}`。
- 接触时 `e_t = ||Δs_{t+1} - f_θ(·)||` 升高；这是“动作发了但状态没跟上”的响应亏空。
- 训练集只取自由空间，避免模型把接触动力学也学进去；按任务留出验证，防止泄漏。
- 它是辅助头，不是第二个在线策略；推理时若 p99 超预算或 G0 不过，直接剪掉。
- 不能把它叫“力矩估计”；它是响应异常分数。

#### 3.2.2 融合与校准

```math
c_t = \sigma\left(\alpha g_t + \beta e_t + \gamma v_t + \delta \cdot \text{visual\_logit}_t\right)
```

- `v_t` 是末端速度/动作幅度/夹爪状态的辅助特征（可选）。
- 用 200 帧人工标注（覆盖 8 个任务：4 个高接触 + 4 个低接触）做 Platt scaling；报告 AUROC、AUPRC、ECE。
- 夹爪力校准：调试槽用电子秤/弹簧秤做 0/2/5/10 N 按压，记录 `g_t`；只报告单调性和 Spearman，不把 proxy 当牛顿。
- 臂部响应校准：用已知阻挡位置/弹簧做 0/5/10 mm 阻挡，记录 `e_t`；只做排序。
- **失败回退**：G0 不过 → `c_t = σ(α g_t + δ visual_logit)`；再不过 → 只用夹爪滞止 + 固定相位规则。

#### 3.2.3 相位分割

```text
输入: g_t, c_t, 夹爪状态, 动作幅度, 腕部视觉
1. 对 g_t/c_t 做 EMA + 迟滞（on/off 双阈值）
2. c_t 连续 k_on 帧 > τ_on -> 接触开始；连续 k_off 帧 < τ_off -> 接触结束
3. 夹爪命令闭合且 g_t > τ_g -> P3 抓取/负载
4. 接触结束 + 夹爪闭合 + EE 速度 > τ_v -> P4 搬运
5. 夹爪命令打开 -> P5 释放/回撤
6. 其余 -> P0 自由/接近；接触前对齐 -> P1 预接触
7. 最短相位时长 + 边界平滑，避免 1–2 帧抖动
```

- 软标签：对每个相位输出概率，不硬切；训练时用标签平滑/熵正则。
- 人工只抽检 2–3 条/任务，标“接触开始/结束、抓取建立、释放”四个点；不逐帧标。
- 双臂：左右各一套相位，再加一个“协调状态”（单臂/双臂/交接）；先做简单版，避免状态爆炸。

### 3.3 CPT：相位化行为克隆

#### 3.3.1 接触加权采样

```math
w_t = \frac{1 + \lambda_c c_t}{\left(1 + \lambda_c c_t\right)_{\text{phase-normalized}}}
```

- 先按相位分层，再在层内按 `c_t` 加权；限制单相位在一个 batch 中的最大占比（例如 35%）。
- `λ_c` 从 0.5 起，网格到 2.0；G1 门不过就降。
- 自由段保留至少 40% 采样，防止“只会接触、不会走路”。

#### 3.3.2 相位条件动作专家

- 在 action expert 的 token 前加相位 embedding：`e_z = Embed(z_t)`；或用 AdaLN/FiLM 注入到动作 token。
- 相位头与动作头共享 backbone；相位头输入 pooled visual/language/proprio features + 夹爪历史。
- 相位头输出 6 类 softmax；边界头输出 `b_t` 的离散桶（例如 0,1,2,4,8,16,32 步）。
- 同一观测在 P1 与 P2 下允许不同动作尺度；这不是“多模型”，是同一模型的条件化。

#### 3.3.3 接触段动作噪声

- 只对 P2/P3 的动作端点加 worst-case 噪声：
  `a' = a + δ, ||δ|| ≤ ε_z`；对 K 个噪声样本取最大损失。
- 目标：让策略见过“插偏一点/被挡一下/抓歪一点”，但不把自由段训得抖动。
- 噪声幅度按相位/任务自适应：接触段小步噪声，抓取段夹爪闭合噪声，搬运段不加。
- 与 R3 的 Recover 共用课程：小噪声 → 物体平移 → 撤销 → 遮挡。

#### 3.3.4 柔顺损失

```math
\mathcal{L}_{\text{comp}} =
\mathbb{E}\left[
\mathbb{1}_{z\in\{P2,P3\}}
\left(
\max(0, \|\Delta a_t\| - \text{cap}_z)^2
+ \beta \|\Delta a_t\|^2
\right)
\right]
```

- `Δa_t = a_t - a_{t-1}`；`cap_z` 按相位自适应（P2 最小，P3 次之，P4 放开）。
- 只惩罚接触段的“大跳”，不是全局减速；自由段不受影响。
- 与运行时 CAC 的 cap 对齐，避免训练/推理不一致。

#### 3.3.5 抓稳辅助损失

- 标签：未来 H 步内 `g_t` 是否持续 > τ_g 且视觉物体未滑落；用夹爪状态 + 腕部视觉弱标签。
- 输出：抓稳概率 `q_t`；不直接输出力，只调制夹爪闭合/重抓。
- 训练时与动作头多任务；推理时 `q_t` 低 → 夹爪再闭合/微调，不硬拉。

#### 3.3.6 边界一致性

- 同一轨迹相邻 chunk 的相位/边界预测做时序一致性（KL/平滑）。
- 边界头预测“还有几步到边界”，推理时用于截断；训练时用弱标签 + 相邻 chunk 一致性。
- 这比固定执行整个 chunk 更安全，且不违反 API（API 仍收到完整 chunk，我们只选择执行前缀）。

### 3.4 CAC：推理端柔顺控制

#### 3.4.1 伪代码

```python
def reset(self):
    self.history.clear()
    self.phase_filter.reset()
    self.fail_count = 0
    self.grasp_state = "open"

def get_action(self, obs):
    o = self.preprocess(obs)                 # resize, history stack
    z, b, c = self.heads(o)                  # phase probs, boundary, contact score
    a = self.policy.sample(o, z)             # full action chunk, API length H

    if z[P2] + z[P3] > self.tau_phase or c > self.tau_contact:
        a = cap_delta(a, self.cap[z])        # per-phase delta cap
        a = lowpass(a, self.alpha[z])        # first-order smoothing

    L = min(len(a), b)                       # reliable prefix
    tail = self.safe_tail(obs, z)            # hold / small retreat / pre-place
    a_exec = concat(a[:L], tail)

    if self.grasp_state == "closing" and c < self.tau_grasp:
        a_exec = self.close_gripper_more(a_exec)

    if c > self.tau_force and self.no_progress(obs, K=5):
        a_exec = self.retreat_or_realign(a_exec)

    return a_exec
```

#### 3.4.2 尾段安全端点

- P0/P1：保持当前位姿（hold），不要发零动作；零动作在某些控制器上可能意味着“回零”。共享的 `action.pivot` 也要保持，不能只填双臂/夹爪。
- P2：沿接近方向小幅回撤（例如 2–5 mm），避免继续顶。
- P3：保持夹爪闭合 + 当前位姿；若抓稳概率低，微调闭合。
- P4：保持当前轨迹的最后一个安全点；不要突然停。
- P5：打开夹爪 + 回撤到安全点。

#### 3.4.3 夹爪闭合到滞止

- 夹爪命令逐步闭合；每步看 `g_t` 是否上升。
- `g_t` 低于 τ_grasp 且 `q_t` 低 → 继续闭合/微调；`g_t` 高 → 保持。
- 检测滑移：`g_t` 突降 + 视觉物体位移 → 重抓（先开一点，再闭合）。
- 夹爪力上限用 `g_t` 的 p95 做软限，不硬顶；不可逆任务（提杯、拿瓶）更保守。

#### 3.4.4 异常与回撤

- 接触分数高但末端位移/视觉进度连续 K 步为 0 → 小回撤 + 重对齐；K 默认 5，按任务调。
- 不可逆任务只回撤到最近安全点，不做大范围探索；宁可失败也不甩飞物体。
- 超时前 N 秒进入“保成功”模式：停止探索，保持当前进度/放置。
- 所有阈值有 per-task 配置；默认保守，G5 安全门通过才放宽。

#### 3.4.5 延迟预算

- 夹爪 + 视觉：<2 ms（不含共享编码器）。
- 前向头：<2 ms；若 p99 超预算，剪掉。
- VFCS/K=2：只在关键状态（接触、插入、放置、人扰后）启用；p99 不达标退回 K=1。
- 记录 p50/p95/p99、latency IQR、动作 jerk、离群率；官方 §6 会看这些（[S4]）。
- 官方允许多个端口共享一个模型；不同端口可能并发调用，`reset`/历史/相位滤波器必须按端口隔离，共享后端要线程安全，不能把 episode 状态串线（[S4] §5）。
- 不要为了“更准”在每个 chunk 都跑多次采样；延迟尖峰可能比成功率更伤可信度。

### 3.5 EGP：证据门控的比赛策略

#### 3.5.1 先澄清：官方大概率是 32×10 全量评测

如果官方每次提交都在 32 个任务上跑 10 次，我们不能“选择只跑某几个任务”。因此 EGP 分两种用法：

- **有 per-task 调试/本地真机槽**：用 probe 分配调试 trial；先 10 个分层任务各 1–2 次，再决定把调试/数据/超参预算放哪。
- **只能整包提交**：用同一后验分配**训练/调试/检查点选择**预算，并决定“先交安全版还是 probe 版”；不是跳过任务。

#### 3.5.2 分层贝叶斯

对任务 `i`：

```math
p_i \sim \mathrm{Beta}(\alpha_{0,\text{family}} + n_i^s,\; \beta_{0,\text{family}} + n_i^f)
```

- `family`：接触高/中/低 × 双臂/单臂 × 长程/短程 × 可逆/不可逆。
- 先验 `α_0, β_0` 用任务族的历史成功率/弱先验；没有历史就用弱先验（例如 α=β=1）。
- step score `s_i` 单独用 Normal/Student-t 建模；不要和成功率混成一个分数。
- 风险 `r_i`：不可逆失败/超时/掉落的上界；安全门 G5 单独约束。

#### 3.5.3 分配目标

```math
U_i =
\underbrace{P(p_i > p_{\text{ref}})}_{\text{成功概率}}
- \lambda_r \underbrace{\mathrm{CVaR}_\alpha(\text{loss}_i)}_{\text{尾部风险}}
+ \lambda_s \underbrace{\mathbb{E}[s_i]/s_{\max}}_{\text{步数保险}}
- \lambda_c \underbrace{\text{cost}_i}_{\text{调试/提交成本}}
```

- 成功优先：`λ_r` 先大后小；`λ_s` 只在成功平台期升。
- 保底：至少留一个“已知能成”的任务族/检查点，防止全押接触导致平均分崩。
- 探索：10% 预算给“后验方差最大/最不确定”的任务族。
- 停止：`P(p_i > p_ref + 0.05) < 0.2` 就停；同一任务连续 0/10 两次冻结检查，不追单任务噪声。
- 检查点选择：`mean success - λ * worst-task regret` 或 `mean - λ * std`；用配对 bootstrap，不选单任务尖峰。

#### 3.5.4 提交策略

- 保留 known-good checkpoint；先交安全版（R3-VLA 基线 + 夹爪滞止），再交 FACT-VLA probe 版。
- 规则允许早交就早交；不允许就等 G1–G3 过门。
- 提交次数未知，默认稀缺；不在同一天连烧多个未验证变体。
- 每次提交记录：模型版本、开关、probe 后验、失败任务、延迟；形成可回滚的提交日志。

### 3.6 单模型合规

- 所有头（动作、相位、边界、接触、抓稳）共享同一个 WLA-1.0-Base backbone/checkpoint；不是多个在线模型。
- 前向头是辅助头，不是第二策略；若必须独立部署，直接剪掉。
- VFCS 只是同一模型的多采样，不引入外部模型；K=2 是延迟上限。
- 规则/代码/外部数据默认 OFF；只用官方 33k；复述增广用规则模板。
- 不调用外部 LLM/VLM 做在线推理；语言 canonicalization 用规则/本地模板。

### 4.2 剪枝

| 上一轮/常见做法 | 为什么剪 |
|---|---|
| 力矩/电流估计 | API/数据无 torque/current；不成立 |
| 触觉输入 | 推理无触觉；训练也无 |

### 4.3 统一训练课程

1. **Stage A（基座）**：WLA-1.0-Base + 官方 33k，EE 动作，R3 的 session/paraphrase 采样；不接相位头。
2. **Stage B（相位）**：冻结视觉/语言主干，训练相位/边界/接触辅助头 + 动作头 LoRA；软标签，低学习率。
3. **Stage C（接触加权/柔顺）**：解冻 action expert，开启 `L_comp`、`L_grasp`、接触段噪声；自由段回归监控。
4. **Stage D（运行时）**：CAC 阈值/尾段/夹爪逻辑在调试槽标定；不训练。
5. **Stage E（比赛）**：EGP probe/后验/提交；保留 known-good。

**课程比例**：clean:contact-weighted:noisy ≈ 6:3:1；接触任务可到 5:4:1，但自由段至少 40%。每个 stage 有回滚点；G1/G2 不过就回退。

## 5. DGS-32C：评测协议

### 5.1 切片

在上一轮 DGS-32 的三重留出（session / paraphrase / perturbation）上，加**接触切片**：

| 切片 | 定义 | 目的 |
|---|---|---|
| C-high | contact_intensity ≥0.75 | 接触段改进是否兑现 |
| C-mid | 0.5–0.75 | 中间地带 |
| C-low | <0.5 | 自由段是否退化 |
| C-bi | 双臂任务 | 协调/交接 |
| C-irrev | 不可逆任务（提杯/拿瓶/倒药等） | 安全/尾部风险 |
| C-long | episode 长度 top quartile | 长程漂移 |

每个切片至少 4–6 个任务；切片内按任务配对，不跨切片混算。

### 5.2 指标

- **主**：平均成功率；接触切片成功率；抓取成功率；插入/接触成功率；不可逆任务成功率。
- **次**：step score；time-to-contact；contact duration；slip rate；re-grasp rate；recovery rate；time-to-recovery；timeout。
- **运行时**：p50/p95/p99 latency；latency IQR；action jerk（接触段/全局）；chunk truncation rate；tail hold rate；异常回撤次数。
- **代理质量**：FACTOR AUROC/AUPRC/ECE；夹爪校准 Spearman；false contact rate；missed contact rate。
- **泛化**：held-out session gap；held-out paraphrase gap；held-out perturbation gap；contact slice gap。
- **安全**：不可逆失败率；掉落/碰撞（若有日志）；回撤成功率。

### 5.3 统计

- 320 次试验（32×10）的成功率标准误约 **2.56pp**（按 p=0.5 保守估）；+5pp 需要配对设计/更多重复才有把握。
- Wilson CI；按 task/session 分层的配对 bootstrap；McNemar（同一任务/同一初始条件）；预注册 +5pp。
- 单任务 +10pp 不当真；看切片/任务族；序列检验控制早停。
- 多模型/多检查点比较用配对 bootstrap + Holm/BH 校正；不要只报均值。
- 排行榜占位数据不参与显著性检验。

### 5.4 接触标签验证

- 抽 8 个任务 ×25 帧 = 200 帧，人工标“接触/未接触、抓取/未抓取”；两人标注，算 Cohen's κ。
- FACTOR 在人工标签上算 AUROC/AUPRC/ECE；夹爪子集单独算。
- 若 κ <0.6，先修标注规范，不急着训相位头。
- 力校准只在调试槽做；没有传感器就只报排序，不报牛顿。

## 6. 实验设计

### 6.1 基线与变量

| 编号 | 模型/开关 | 目的 |
|---|---|---|
| B0 | WLA-1.0-Base（EE，官方 33k） | 基座 |
| B1 | B0 + R3（session/paraphrase/recover） | 上一轮基线 |
| B2 | B1 + 相位头/边界头（不加重加权） | 相位条件是否有效 |
| B3 | B2 + 接触加权采样 | 接触段采样是否有效 |
| B4 | B3 + 柔顺/抓稳损失 + 接触噪声 | 训练侧柔顺是否有效 |
| B5 | B4 + CAC（夹爪滞止 + 边界截断 + 尾段） | 运行时是否兑现 |
| B6 | B5 + FACTOR 前向头（可选） | 响应亏空是否加分 |
| B7 | B6 + EGP（probe/检查点选择） | 比赛策略是否加分 |
| B8 | B7 + 关节空间消融 | 控制空间是否影响 |

**控制空间**：主路径保持 **EE**（WLA 原生，部署直接）；关节空间只做消融，不默认切换。原因：WLA 统一动作空间是 EE 相对 SE(3)，换关节空间要改 action head/数据处理，成本和风险都高；而夹爪滞止不需要关节控制。

### 6.2 门控

| 门 | 问题 | 通过标准 | 失败动作 |
|---|---|---|---|
| G0 | FACTOR 是否识别接触？ | 人工 200 帧 AUROC ≥0.80；夹爪子集 ≥0.85 | 砍前向头，只留夹爪+视觉 |
| G1 | 相位化 BC 是否涨接触段？ | C-high 成功率 +5pp；C-low 回归 ≤1pp | 降 λ_c / 去柔顺损失 |
| G2 | CAC 是否安全增益？ | p99 延迟 ≤预算；timeout 不升；jerk 不升 | 只留夹爪滞止，去臂部规则 |
| G3 | 泛化是否不倒退？ | held-out session/paraphrase 不降 >1pp | 限制到高接触任务 |
| G4 | EGP 是否选对？ | probe 后验 top-3 命中 ≥2；+5pp 后验 ≥0.8 | 回退均匀分配 |
| G5 | 安全是否可接受？ | 不可逆失败不升；回撤可触发 | 关接触探索，保守版提交 |

### 6.3 消融

- **信号消融**：只用夹爪 / 夹爪+视觉 / 夹爪+视觉+前向头；看 AUROC 与接触段成功率。
- **采样消融**：无加权 / 全局加权 / 相位分层加权；看 C-high 与 C-low。
- **相位消融**：无相位条件 / 软相位 / 硬相位；看边界抖动与成功率。
- **柔顺消融**：无 `L_comp` / 仅训练 / 训练+CAC；看接触段 jerk 与卡住率。
- **边界消融**：固定 chunk / AEH / 相位边界截断；看 timeout 与接触段成功率。
- **噪声消融**：无噪声 / 自由段噪声 / 接触段噪声；看恢复率与自由段回归。
- **比赛消融**：均匀分配 / 接触强度分配 / EGP；看 probe 后验与最终平均分。

### 6.4 预算与顺序

1. **数据/标签**（1–2 天）：全量 metadata、接触统计、200 帧标注、FACTOR 校准。
2. **B0/B1 复现**（3–5 天）：WLA 微调/评估管线；确认 EE 动作、chunk、延迟。
3. **B2/B3**（3–5 天）：相位头/边界头/接触加权；先小任务集。
4. **B4/B5**（3–5 天）：柔顺损失/CAC；调试槽标定。
5. **B6/B7**（3–5 天）：前向头/EGP；只在 G0–G3 过后。
6. **全量 32 任务**（按算力）：至少 3 个种子/检查点；配对评估。

**算力假设**：WLA-1.0-Base 6B；LoRA/action expert 微调优先；全参微调只在小规模验证后考虑。若单卡不足，先冻结主干 + 训练 action expert/LoRA；相位头很轻。

## 8. 风险、合规与开关

### 8.1 技术风险

- **标签噪声**：相位/FACTOR 都是弱监督；用软标签、人工抽检、AUROC 门控，不把相位头当真值。
- **接触过拟合**：接触加权可能牺牲自由段；用相位分层、自由段回归门、早停。
- **代理漂移**：夹爪滞止阈值随物体/夹爪磨损变化；用 per-task 分位数 + 在线自适应，但设上下限。
- **臂部响应头失败**：目标超前/标定差会让 `e_t` 失真；G0 不过就剪掉，不影响主路径。
- **运行时规则冲突**：缩放/截断/回撤可能互相打架；用优先级：安全回撤 > 夹爪重抓 > 边界截断 > 柔顺缩放。
- **延迟**：多相机 + 历史堆叠 + 前向头可能超预算；默认只用夹爪+视觉，前向头可选。

### 8.2 比赛风险

- **排行榜占位**：不能当 SOTA/难度表；所有结论以本地配对评估为准。
- **提交次数未知**：默认稀缺；先安全版，再 probe 版；保留回滚。
- **任务级噪声**：10 次试验单任务 SE 很大；不因单任务 +10pp 改全局策略。
- **规则变化**：以官方最新规则为准；本报告不假设未写明的提交上限/截止日期。
- **单模型合规**：所有头共享 checkpoint；不引入第二在线模型；外部数据默认 OFF。

## 9. 开放问题

1. 官方是否逐字使用 5 条公开复述？若使用未公开复述，R3 的留一复述验证仍有用，但不能保证覆盖。
2. 官方是否提供 per-task 调试/分任务结果，还是只给整包 32×10？若允许 per-task 调试，EGP 的 probe 分配可直接用；否则只用于训练/检查点选择。
3. 夹爪开合的单位/方向是否左右一致？本轮按“状态-命令差”的绝对值/符号处理；部署前需用 API 观测再确认。
4. 评测时 `obs_delta_indices` 能堆叠多少帧？历史越长，FACTOR 响应估计越好，但带宽/延迟越高。
5. 官方是否记录/惩罚动作抖动、延迟尖峰？README §6 暗示会看；本轮按“会看”设计。
6. 不可逆任务的安全边界/急停策略由谁负责？需要和官方/现场安全员确认。
7. 夹爪力校准能否上调试槽？若不能，FACTOR 只做排序，不做牛顿。
8. 关节空间是否可能比 EE 更适合力代理？本轮判断“成本高、收益不确定”，只做消融；若消融显著再改主路径。
