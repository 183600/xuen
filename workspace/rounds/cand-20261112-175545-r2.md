# 第 62 轮（承接第 61 轮「具身语义进化闭环」ESEC：USR×MEL×DMS×SRT-Dual×PCE+++++；灵感循环第 8 轮；本轮灵感：「示教学习」×「抗干扰」）

> 第 61 轮让系统从「模块拼接」走向「表征对齐」：USR 统一场景/意图/阻抗/证据，MEL 提供零样本物理先验，DMS 接地多轮对话，SRT-Dual 解耦语义与实时时序。但**四个新局限**暴露：
> 1. **会「理解」不会「做」**：MEL 学的是物理属性 φ_phys（摩擦、刚度……），USR 的 intent_emb 表达「要什么」，却**缺少「怎么做」的程序性技能表征**；ZSSG 只保证物理属性推断误差，不保证新任务组合可执行。
> 2. **抗扰是被动的「躲」**：第 61 轮把干扰塞进 U_epistemic/U_aleatoric，靠保守扩展、冻结锚点、预算降级来回避；**没有「辨识—估计—前馈补偿」的主动抗扰闭环**，力尖峰/传感器退化/动态障碍只能让控制变软，牺牲任务精度。
> 3. **大模型是新的攻击面**：对抗视觉 patch、提示注入、传感器欺骗可污染语义锚点；SACP 只能查「语义—控制是否一致」，**不能证明语义表征本身对扰动不变**——C_sem 很高可能只是「一致地被骗」。
> 4. **最稀缺的抗扰先验就在人手里**：人类操作者的柔顺装配、滑移恢复、力控「手感」是最直接的扰动响应样本，第 61 轮却完全依赖仿真 + 域随机化硬扛 sim2real gap。

## 0. 直觉与动机

**灵感 1（示教学习 → 把示教编译成「阻抗技能程序」而不是轨迹）**
直觉：模仿学习最怕「高维动作分布漂移 + 因果混淆」。但本系统的执行接口本来就是低维阻抗参数 K=(K_p, K_d, F_max)，且 ERTC/EEIS 已保证其安全。关键洞见：**不要克隆关节轨迹，而要把人类示教在接触事件处切分，编译成「阻抗技能原语序列」σ=(前置条件, 阻抗轮廓 K(t), 后置条件)**。示教因此变成 USR 中的**可组合程序**，而非一堆难以泛化的轨迹点。人类「捏鸡蛋先软后稳」的手感，被表示为一条 K(t) 轮廓，天然可迁移到不同物体。

**灵感 2（抗干扰 → 不变子空间 ⊕ 敏感子空间，而非一味不变）**
直觉：对抗训练常追求「表征对扰动不变」，但**安全信息恰恰必须对扰动敏感**——滑移、力尖峰、碰撞不能被当作噪声抹掉。关键洞见：把 USR 分解为 `U_inv ⊕ U_sens`。`U_inv` 承载任务语义（物体类别、目标、阶段），用对抗/对比损失训练其**扰动不变性**；`U_sens` 承载接触安全事件，用**敏感性保持损失**放大滑移/碰撞/超限信号。投影头 Π 只吃 `U_inv` 生成名义阻抗，`U_sens` 单独调制安全裕度。这样「抗干扰」不等于「把危险也抗掉」。

**灵感 3（示教 × 抗扰 → 人类恢复示教是抗扰正样本）**
直觉：人类示教里最有价值的不是「正常完成」，而是「出错后怎么救」——打滑时手腕一沉、卡滞时回撤再进。关键洞见：构造**鲁棒示教增广 RDA**，在物理可行方向（力偏置、延迟、遮挡、对抗 patch、提示注入）上增广示教，并用**双教师**（人类示教教师 + 基于 ERTC/CBF 的安全评论家教师）蒸馏学生。示教提供「往哪救」，安全评论家提供「救到哪算安全」。

**灵感 4（三灵感合流 → 示教-抗扰进化闭环 DREC）**
直觉：示教是慢的（离线/低频，技能库 ~0.1–1Hz 更新），抗扰是快的（观测器 ~1kHz），二者必须分层。DREC 设三条流：**示教流**（离线：相位分解→技能程序→写入 DSL）、**语义流**（10–100Hz：MEL+DMS+USR，检索并组合技能程序）、**实时流**（1–10kHz：DADO 前馈 + EEIS 编译 + ERTC 执行 + 安全盾牌）。三流通过 USR 的**技能版本号**与**安全证书**耦合。

**灵感 5（PCE++++++ → 七维认知-抗扰预算）**
直觉：示教与抗扰都要花预算：示教要采样/标注/切分，抗扰要对抗迭代/观测器带宽/不变性容差。扩展 `B_cog7 = B_cog5 ⊕ (B_demo, B_rob)`。B_demo 耗尽 ⇒ 退化为 ZSSG 物理先验 + 规则技能；B_rob 耗尽 ⇒ 关闭学习前馈、加宽保守裕度、退化为 H∞ 鲁棒控制。**任务性能可降，安全不降。**

## 1. 形式化定义（增量：定义 173–184）

**定义 173（示教数据与接触相位分解）** 一条示教 `d = (τ, F, V, L, m)`，其中 τ={(q_t,q̇_t,τ_t)}_{t=1..T} 为关节轨迹，F 为六维力/力矩序列，V 为多视角视觉，L 为操作者语言标注，m 为元数据（操作者、物体、工具）。
- **相位切分器** `S_phase: d → [(t_k, t_{k+1}, c_k, e_k)]`，`c_k ∈ {approach, contact, insert, rotate, release, recover}`，`e_k` 为接触事件（起始/结束/滑移/卡滞/超限）。
- **事件检测**：`e = (t, type, conf)`，由力导数变点检测 + 接触状态机给出：`type = argmax_j [ 1(‖Ḟ_t‖ > θ_F) · p_contact(j|F_t,V_t) ]`。
- **相位契约**：每个相位附带前置/后置 USR 谓词 `(Φ_pre, Φ_post)`，只有谓词成立才允许执行该相位。

**定义 174（阻抗技能原语 ISP）** 技能原语 `σ = (Φ_pre, Φ_post, K_σ(·), Ξ, u_sync)`：
- `K_σ: [0,T_σ] → K_adm` 为**阻抗轮廓**（分段样条），`K_adm = {(K_p,K_d,F_max) | K_p∈[K_p^min,K_p^max], K_d∈[K_d^min,K_d^max], F_max≤F_max^safe}`；
- `Ξ` 为该原语允许的约束集（继承 ERTC 硬约束）；
- `u_sync` 为同步信号（等待接触、等待视觉确认）。
- **组合代数**：顺序 `σ_1 ; σ_2`（后者的 Φ_pre 必须由前者的 Φ_post 蕴含）、并行 `σ_1 ‖ σ_2`（约束取交）、条件 `σ_1 ⋉_φ σ_2`（按 USR 谓词 φ 选择支路）。
- 关键：**动作空间是「原语 + 轮廓参数」，不是原始关节指令**，因此示教到控制的迁移是低维、可解释、可安全投影的。

**定义 175（示教语义库 DSL）** `D_lib = {(z_j, P_j, cov_j, ver_j)}_{j=1..M}`：
- `z_j = E_skill(σ_j) ∈ ℝ^{d_us}` 为技能嵌入，`E_skill` 与 USR 共享 `d_us`；
- `P_j` 为由原语组合而成的**技能程序**（DSL 表达式）；
- `cov_j` 为局部覆盖率（以 `z_j` 为核心的核密度质量）；
- `ver_j` 为技能版本号，供实时流与证书引用。
- **检索算子** `Retrieve(z_scene, z_intent, k) = TopK_j cos(z_j, [z_scene; z_intent])`，返回候选程序集合；覆盖率不足时回退 ZSSG 物理先验。

**定义 176（复合扰动模型）** 扰动 `d = (d_f, d_s, d_c, d_sem, d_dyn)`：
- `d_f`：力/力矩尖峰、负载突变，`‖d_f‖ ≤ Δ_f`；
- `d_s`：传感器噪声、遮挡、触觉漂移，`d_s ~ P_s` 或最坏情形有界；
- `d_c`：通信延迟/抖动/丢包，`d_c ∈ [0, Δ_c]`；
- `d_sem`：对抗视觉 patch、提示注入、语义欺骗，由扰动算子 `A_sem` 生成；
- `d_dyn`：动态障碍/人机共融扰动。
- 每个分量标注 **随机（stochastic）** 或 **对抗（adversarial）**，抗扰目标必须分别给出概率界与最坏界。

**定义 177（扰动不变—敏感子空间分解 DI-USR）** 将第 61 轮 USR 的嵌入空间分解为
```
U = U_inv ⊕ U_sens,   d_us = d_inv + d_sens
E(x) = (E_inv(x), E_sens(x)) ∈ ℝ^{d_inv} × ℝ^{d_sens}
```
- **不变损失**：`ℒ_inv = E_{x,d}[ ‖E_inv(x+d) − E_inv(x)‖² ]`，`d` 取 `d_s, d_sem` 的可实现扰动；
- **敏感保持损失**：`ℒ_sens = −E_{x,d_safe}[ ‖E_sens(x+d_safe) − E_sens(x)‖² ]`，`d_safe` 为安全相关扰动（滑移、碰撞、超限、力尖峰）；
- **解耦损失**：`ℒ_sep = ‖Cov(E_inv, E_sens)‖_F²`（或 HSIC），强制两子空间近似独立；
- **总损失**：`ℒ_DI = ℒ_task + λ_inv ℒ_inv + λ_sens ℒ_sens + λ_sep ℒ_sep`。
- **分解投影**：名义先验 `K_prior = Π_inv(E_inv(x))`；安全裕度 `m_safe = Π_sens(E_sens(x))`，`K_safe ← EEIS.compile(..., K_prior, m_safe)`。**不变通道不接触安全信号，敏感通道不参与名义语义决策**。

**定义 178（示教增强干扰观测器 DADO）** 在实时流中并联一个广义动量观测器与一个示教学习的残差模型：
```
r(t) = K_O(q)·q̇(t) − ∫_0^t [ K_O(q)·q̈ + C(q,q̇)·q̇ + g(q) − τ_cmd ] dτ
d̂_DOB(t) = L_o · r(t)                       # 经典干扰观测器，带宽 ω_o
d̂_learn(t) = g_θ( E_inv(x_t), E_sens(x_t), D_lib 检索上下文 )
d̂(t) = d̂_DOB(t) + d̂_learn(t)               # 前馈补偿量，注入 EEIS 的 delta_f_req
```
- **带宽自适应**：`ω_o = ω_0 · (1 + κ·ℓ)`，ℓ 为定义 182 的扰动等级；示教覆盖率高时提高学习项权重 `w_learn = clip(cov_j, 0, 1)`；
- **稳定性条件**：观测器误差 `e_o = d − d̂` 满足 `‖e_o(t)‖ ≤ e^{−ω_o t}‖e_o(0)‖ + δ_obs/ω_o`；学习项只补偿低频分量，截止频率 `ω_learn < ω_o/3`，避免与观测器争带宽；
- **安全门控**：若 `‖d̂_learn‖ > Δ_f` 或与 `d̂_DOB` 符号相反，则**丢弃学习项**，仅保留 DOB + 保守裕度。

**定义 179（鲁棒示教增广 RDA）** 增广算子 `A: (d, d_pert) → d'`，在物理可行集 `P_pert` 内对示教施加扰动：
- 力偏置 `A_f`、时间伸缩/延迟 `A_c`、视觉遮挡/patch `A_v`、语言改写/注入 `A_l`；
- **课程半径** `ρ_t = ρ_0 + (ρ_max−ρ_0)·min(1, t/T_cur)`，随学生能力提升而扩大；
- **分布鲁棒目标**：`min_θ sup_{Q ∈ B(P_demo, ρ)} E_Q[ℒ_BC(θ)]`，用扰动组上的 group-DRO 近似；
- **物理可行性投影**：`A(d,d_pert) = Proj_{P_pert}(d + d_pert)`，保证增广样本仍满足 ERTC 约束，不制造「不可能示教」。

**定义 180（安全约束模仿学习 SCIL / 双教师蒸馏）** 学生策略 `π_θ` 在技能原语空间上学习：

           + λ_safe · E_s[ max(0, Q_safe(s, π_θ(s)) − b_safe) ] # 安全评论家教师

### IP-183 DSL（示教语义库：相位切分 → 技能程序编译）

```python
class DemonstrationSemanticLibrary:
    def __init__(self, d_us=256, coverage_target=0.85):
        self.d_us = d_us
        self.coverage_target = coverage_target
        self.skills = []                 # [(z_j, P_j, cov_j, ver_j)]
        self.segmenter = ContactPhaseSegmenter()
        self.skill_encoder = SkillEncoder(d_us)
        self.ver = 0

    def compile_demo(self, demo):
        phases = self.segmenter.split(demo)          # 力导数变点 + 接触状态机
        primitives = []
        for (t0, t1, cls, events) in phases:
            K_profile = self._extract_impedance_profile(demo, t0, t1)
            sigma = SkillPrimitive(
                pre=self._usr_precondition(demo, t0),
                post=self._usr_postcondition(demo, t1),
                K=K_profile,
                Xi=self._inherit_ertc_constraints(demo),
                sync=self._detect_sync_signal(events),
                label=cls
            )
            primitives.append(sigma)
        program = self._compose_program(primitives, demo.language)
        z = self.skill_encoder.encode(program)
        return z, program

    def update(self, demo):
        z, program = self.compile_demo(demo)
        cov = self._kernel_density(z)                # 局部覆盖率
        self.ver += 1
        self.skills.append((z, program, cov, self.ver))
        return self.ver

    def retrieve(self, z_scene, z_intent, k=5):
        q = torch.cat([z_scene, z_intent], dim=-1)
        scored = [(cos(z, q), j) for j, (z, _, _, _) in enumerate(self.skills)]
        topk = sorted(scored, reverse=True)[:k]
        return [self.skills[j] for _, j in topk]

    def _extract_impedance_profile(self, demo, t0, t1):
        F = demo.force[t0:t1]
        v = demo.vel[t0:t1]
        Kp = self._hand_stiffness_estimate(F, v)     # 简化：F/位移 的鲁棒回归
        Kd = self._damping_estimate(F, v, Kp)
        Fmax = float(F.norm(dim=-1).max()) * 1.1
        return PiecewiseSpline(Kp, Kd, Fmax, knots=8)

    def _compose_program(self, primitives, language):
        expr = primitives[0]
        for p in primitives[1:]:
            op = parse_operator(language, p)         # ';' / '||' / '⋉_φ'
            expr = compose(expr, p, op)
        return expr
```

### IP-184 DI-USR（扰动不变—敏感子空间分解）

```python
class DisturbanceInvariantUSR:
    def __init__(self, d_us=256, d_inv=192, d_sens=64):
        self.d_inv, self.d_sens = d_inv, d_sens
        self.enc_inv = InvariantEncoder(d_inv)
        self.enc_sens = SensitiveEncoder(d_sens)
        self.proj_inv = ImpedanceProjector(d_inv)
        self.proj_sens = SafetyMarginHead(d_sens)
        self.opt = torch.optim.Adam(
            list(self.enc_inv.parameters()) + list(self.enc_sens.parameters())
            + list(self.proj_inv.parameters()) + list(self.proj_sens.parameters()), lr=1e-4)

    def loss(self, x, d_rand, d_safe, y_task):
        z_inv = self.enc_inv(x)
        z_sens = self.enc_sens(x)
        z_inv_p = self.enc_inv(x + d_rand)           # 随机/对抗语义扰动
        z_sens_p = self.enc_sens(x + d_safe)         # 安全相关扰动

        l_task = task_loss(self.proj_inv(z_inv), y_task)
        l_inv = F.mse_loss(z_inv_p, z_inv)
        l_sens = -F.mse_loss(z_sens_p, z_sens)       # 负号：鼓励敏感
        l_sep = torch.norm(torch.cov(torch.cat([z_inv, z_sens], -1)), p='fro')
        return l_task + 0.5*l_inv + 0.3*l_sens + 0.1*l_sep

    def encode(self, x):
        z_inv = self.enc_inv(x)
        z_sens = self.enc_sens(x)
        K_prior = self.proj_inv(z_inv)
        m_safe = self.proj_sens(z_sens)
        return z_inv, z_sens, K_prior, m_safe

    def invariance_certificate(self, delta):
        return self.enc_inv.lipschitz() * delta       # ‖E_inv(x+d)-E_inv(x)‖ ≤ L·Δ
```

### IP-185 DADO（示教增强干扰观测器）

```python
class DemoAugmentedDisturbanceObserver:
    def __init__(self, robot_model, learn_model, dt=1e-3,
                 omega0=100.0, omega_learn=30.0):
        self.model = robot_model
        self.g_theta = learn_model
        self.dt = dt
        self.omega_o = omega0
        self.omega_learn = omega_learn
        self.r = np.zeros(robot_model.n_joints)
        self.d_hat_prev = np.zeros(robot_model.n_joints)

    def estimate(self, q, qd, tau_cmd, x_inv, x_sens, dialogue_ctx=None, cov=1.0):
        # 1) 广义动量观测器
        qdd = self.model.accel(q, qd, tau_cmd)
        r_dot = self.model.momentum_matrix(q) @ qdd \
                + self.model.coriolis(q, qd) @ qd + self.model.gravity(q) - tau_cmd
        self.r += r_dot * self.dt
        d_dob = self.omega_o * self.r

        # 2) 示教学习残差（仅低频，截止频率 < omega_o/3）
        w_learn = np.clip(cov, 0.0, 1.0)
        d_learn = w_learn * self.g_theta(x_inv, x_sens, dialogue_ctx)

        # 3) 安全门控：方向/幅值异常则丢弃学习项
        if np.linalg.norm(d_learn) > DELTA_F_MAX or np.dot(d_learn, d_dob) < 0:
            d_learn = np.zeros_like(d_learn)

        d_hat = lowpass(d_dob + d_learn, cutoff=self.omega_learn)
        self.d_hat_prev = d_hat
        return d_hat

    def set_bandwidth(self, disturbance_level):
        self.omega_o = OMEGA_0 * (1.0 + KAPPA * disturbance_level)

class SafetyConstrainedImitation:
    def __init__(self, policy, safety_critic, cbf, shield, lam_safe=0.5, lam_cbf=0.3):
        self.policy = policy
        self.q_safe = safety_critic
        self.cbf = cbf
        self.shield = shield
        self.lam_safe, self.lam_cbf = lam_safe, lam_cbf
        self.opt = torch.optim.Adam(policy.parameters(), lr=3e-4)

    def step(self, batch):
        s, sigma_star = batch
        logp = self.policy.log_prob(s, sigma_star)
        l_bc = -logp.mean()

        sigma_hat = self.policy.sample(s)
        l_safe = F.relu(self.q_safe(s, sigma_hat) - SAFE_BUDGET).mean()
        h = self.cbf.h(s)
        h_dot = self.cbf.h_dot(s, sigma_hat)
        l_cbf = F.relu(-h_dot - CBF_ALPHA * h).mean()

        loss = l_bc + self.lam_safe * l_safe + self.lam_cbf * l_cbf
        self.opt.zero_grad(); loss.backward(); self.opt.step()
        return loss.item()

    def act_safe(self, s, J):
        sigma = self.policy.sample(s)
        if not J.valid or J.robust_margin < TAU_MARGIN:
            sigma = self.shield.conservative_action(s)   # 安全评论家覆盖
        return sigma

    def __init__(self, h=0.1, up=0.3, down=0.7, dwell=0.2):

                       + W2*residual/TAU_RES + W3*z_sens_norm, 0.0, 1.0)

            self.mode = 'high'; self.last_switch = now
        elif self.mode == 'high' and l < 0.7 - self.h and now - self.last_switch > self.dwell:

        return [self.skills[j] for _, j in
                sorted(((cos(z, q), j) for j, (z, *_ ) in enumerate(self.skills)),
                       reverse=True)[:k]]

                        + list(self.proj_inv.parameters()) + list(self.proj_sens.parameters()), 1e-4)

    def loss(self, x, d_rand, d_safe, y_task):
        zi, zs = self.enc_inv(x), self.enc_sens(x)
        zi_p, zs_p = self.enc_inv(x + d_rand), self.enc_sens(x + d_safe)
        l_task = task_loss(self.proj_inv(zi), y_task)
        l_inv = F.mse_loss(zi_p, zi)
        l_sens = -F.mse_loss(zs_p, zs)             # 负号：鼓励对安全扰动敏感
        l_sep = torch.norm(torch.cov(torch.cat([zi, zs], -1)), p='fro')
        return l_task + 0.5*l_inv + 0.3*l_sens + 0.1*l_sep

    def encode(self, x):
        zi, zs = self.enc_inv(x), self.enc_sens(x)
        return zi, zs, self.proj_inv(zi), self.proj_sens(zs)

    def invariance_certificate(self, delta):
        return self.enc_inv.lipschitz() * delta
```

class DemoAugmentedDisturbanceObserver:
    def __init__(self, robot, learn_model, dt=1e-3, omega0=100.0, omega_learn=30.0):
        self.robot, self.g_theta, self.dt = robot, learn_model, dt
        self.omega_o, self.omega_learn = omega0, omega_learn
        self.r = np.zeros(robot.n_joints)

    def estimate(self, q, qd, tau_cmd, z_inv, z_sens, cov=1.0):
        qdd = self.robot.accel(q, qd, tau_cmd)
        r_dot = (self.robot.momentum(q) @ qdd
                 + self.robot.coriolis(q, qd) @ qd
                 + self.robot.gravity(q) - tau_cmd)
        self.r += r_dot * self.dt
        d_dob = self.omega_o * self.r
        d_learn = np.clip(cov, 0, 1) * self.g_theta(z_inv, z_sens)
        if np.linalg.norm(d_learn) > DELTA_F_MAX or np.dot(d_learn, d_dob) < 0:
            d_learn = np.zeros_like(d_learn)        # 安全门控：方向/幅值异常丢弃
        return lowpass(d_dob + d_learn, cutoff=self.omega_learn)

    def set_bandwidth(self, level):
        self.omega_o = OMEGA_0 * (1.0 + KAPPA * level)

class SafetyConstrainedImitation:
    def __init__(self, policy, q_safe, cbf, shield):
        self.policy, self.q_safe, self.cbf, self.shield = policy, q_safe, cbf, shield
        self.opt = Adam(policy.parameters(), 3e-4)

    def step(self, s, sigma_star):
        l_bc = -self.policy.log_prob(s, sigma_star).mean()
        sigma_hat = self.policy.sample(s)
        l_safe = F.relu(self.q_safe(s, sigma_hat) - SAFE_BUDGET).mean()
        h, h_dot = self.cbf.h(s), self.cbf.h_dot(s, sigma_hat)
        l_cbf = F.relu(-h_dot - CBF_ALPHA * h).mean()
        loss = l_bc + 0.5*l_safe + 0.3*l_cbf
        self.opt.zero_grad(); loss.backward(); self.opt.step()

    def act_safe(self, s, J):
        sigma = self.policy.sample(s)
        if not J.valid or J.robust_margin < TAU_MARGIN:
            return self.shield.conservative_action(s)   # 盾牌覆盖
        return sigma

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|

**DREC-Complete 定理要点**（A71–A77：示教覆盖、Lipschitz、扰动有界、安全可行、增广覆盖、调度实时、预算单调）：
1. **技能迁移**：`E[ℒ_task] ≤ ε_BC + L·ε_cover + O(√(log(1/δ)/N))`；组合泛化由相位契约 assume-guarantee 保证。
2. **抗扰不变性**：`‖E_inv(x+d)−E_inv(x)‖ ≤ L·Δ`，同时 `U_sens` 保留 ≥ η 的安全扰动能量。
3. **鲁棒安全**：`P(violation) ≤ α + δ_obs/κ_safe`；证书不达标时盾牌强制接管，不劣于纯规则策略。
4. **实时性**：DAS 最坏档实时流 ≤ 1ms；语义流冻结不阻塞实时流。
5. **预算安全**：`B_demo/B_rob` 耗尽只降技能丰富度与补偿能力，ERTC 硬约束与盾牌不降级。
