# 第 68 轮（承接第 67 轮「SimRAS 仿真增强风险闭环」IP-233~242；新灵感循环第 1 轮；本轮灵感：「面部表情识别」×「双足机器人」）

> 第 67 轮 SimRAS 把「离线仿真预训练 + 在线世界模型 + 视觉问答审计」叠到 RAS 之上，解决了「未来风险怎么演化、怎么可解释地审计」。但它仍有两个隐含假设：其一，**「身体」只是被控的黑箱动力学**，世界模型只需预测状态，不需要「读懂」身体的表达；其二，**「表情」只是人类脸上的信号**，与机器人自身的运动无关。
>
> 本轮提出一个结构同构命题：
>
> **双足机器人的全身平衡，本质上是一张「会动的脸」。** 面部表情与双足步态都由「高维、欠驱动、低维流形、时序强相关」的控制系统产生；两者都同时具有「宏观状态」与「短时-低幅-高导数的非自主微事件」——前者是 FACS 的宏观表情，后者是微表情；对应到双足，就是宏观步态风格与失稳前的平衡微调。
>
> 于是本轮把 **FACS 的「动作单元 × 强度 × 时序段落」方法论迁移到双足平衡**，得到 **GaitFACS**；再反向用人类表情驱动「表达诚实性约束下的社会感知步态」。核心不是「让机器人做表情」，而是**用表情识别的方法论去读身体、并约束身体如何被他人读**。

## 0. 直觉与动机

**灵感 1（面部表情识别 → 动作单元语言）**
直觉：人脸表情识别真正有效的表示从来不是「六类情绪」标签，而是 **FACS 动作单元（AU）+ 强度等级（A–E）+ 时序段落（onset/apex/offset）**。微表情研究进一步表明：最有信息量的往往是**短（<200ms）、低幅、高导数、非自主**的微事件，它们先于宏观表情出现。这套「分解—定强—找段落—抓微事件」的方法论，恰恰是双足失稳检测缺失的东西：现有方法只看 ZMP/Capture Point 是否越界，是「宏观表情」，看不到越界前的「微表情」。

**灵感 2（双足机器人 → 欠驱动发散动力学）**
直觉：双足平衡的核心是线性倒立摆（LIPM）的**发散分量 DCM**：`ξ = x + ẋ/ω`，`ω = √(g/z_c)`。没有恢复时 `ξ(t)-p = (ξ_0-p)e^{ωt}`——小的早期偏差会指数放大。这意味着「早看一眼」的杠杆极大：若能在偏差还很小、但导数已经很快时读到它，就能把「事后摔倒」变成「事前一步」。这正是微表情识别「抓 apex 前兆」的动力学对应物。

**灵感 3（结构同构 → 一张映射表）**
直觉：把两套系统逐项对齐，会得到一张惊人的同构表：

| 面部表情识别 | 双足平衡（GaitFACS） | 共享的数学结构 |
|---|---|---|
| 动作单元 AU | 步态动作单元 BAU（躯干/髋/踝/步宽/步频/头稳/臂摆） | 非负、可加的稀疏运动基 |
| AU 强度 A–E | BAU 强度 `a_k(t)∈[0,5]` | 有界强度回归 |
| onset/apex/offset | 触地相位/步态相位/支撑相切换 | 时序段落分割 |
| 微表情（短-低幅-高导数） | 平衡微表情 BME（失稳前微调） | 低幅高导数事件检测 |
| 宏观表情 / 社交面具 | 宏观步态风格 / 表达塑形 | 慢流形上的风格变量 |
| 假笑、表情欺骗 | 「假稳」、过度自信步态 | 表达-真实状态的校准偏差 |
| 表情识别噪声 | 关节/IMU/接触噪声 | 观测不确定性 |

**灵感 4（合流 → GaitFACS 的双闭环）**
直觉：GaitFACS 不是一个检测器，而是**内环读自己、外环读他人**的双闭环：
- **内环（本体表达闭环）**：B-FACS 把本体感知分解为 BAU → BME-Spotter 抓平衡微表情 → BEW 早警 → 在 DCM/MoS 违约之前进入保守步态。它是「身体读自己的身体」。
- **外环（社会表达闭环）**：人类表情识别（复用第 66 轮 RAS 的 ERG）→ 社交风险 `R_social` → 决定「允许向人类展示多少不稳定」（可接受表达强度 `α_exp`）→ SocialMask 只在**稳定零空间**内塑形可见表达。
- **桥（跨域迁移 + 诚实约束）**：CEAT 用面部 AU 编码器给 B-FACS 提供归纳偏置；HonestyCert 约束「表达的自信」不得超过「真实的稳定」，禁止用「假稳」诱导人类靠近。

**灵感 5（为什么必须是双足，而不是轮式）**
直觉：轮式平台天然稳定，不存在「微表情」这一层；双足是**欠驱动、间歇接触、必须主动维持稳定**的系统，才同时具备「慢流形风格 + 快微事件」的双时间尺度结构——这与面部表情的「慢情绪状态 + 快肌肉微动」在动力学上同构。换句话说，**双足是唯一能把「表情」这套方法论物理地长在身体上的机器人形态**。

## 1. 形式化定义（增量：定义 266–290）

- **定义 266（GaitFACS 总览）**：GaitFACS = (B-FACS, CEAT, BME-Spotter, BEW, SEG, SocialMask, HonestyCert, DualFACS, BAL-SimEngine, J_GaitFACS)。定位：把 SimRAS 的「情绪-故障闭环」扩展为「步态表情-平衡-社交」三耦合闭环。不变式：内环只在实时流做 BAU 提取、BME 检测与早警；CEAT 训练、SimEngine、VQA 审计只在语义流/离线。
- **定义 267（步态动作单元 BAU）**：对关节轨迹 `q_{1:T}∈ℝ^{n_q}`、足底接触 `c_{1:T}`、IMU `w_{1:T}`，取名义步态 `q_nom`，用带物理分组约束的非负基 `Φ∈ℝ^{n_q×K}`（K≈7）分解：`q_t - q_nom(t) ≈ Φ a_t + e_t`，`a_t∈ℝ_+^K`。K 个单元对应躯干倾、髋策略、踝策略、步宽、步频、头稳、臂摆。
- **定义 268（B-FACS 强度与时序段落）**：每个 BAU 强度 `a_k(t)` 量化到 A–E 五级（A:[0,1), …, E:[4,5]）；对每个单元做段落分割 `seg_k=(t_on,t_apex,t_off)`，并按步态相位 `φ(t)` 对齐（左右支撑相）。
- **定义 269（平衡微表情 BME）**：BME 是时间区间 `[t_on,t_off]`，长度 `≤200ms`，满足：(i) 低幅 `max_t‖Σ_k a_kφ_k‖ ≤ ε_amp`；(ii) 高导数 `max_t‖ȧ_t‖ ≥ ε_vel`；(iii) 与 DCM 残差 `r_DCM(t)=ξ(t)-ξ_nom(t)` 的局部相关 `≥ρ_min`。即「短、快、小、且与失稳相关」的微调。
- **定义 270（LIPM / DCM / MoS）**：LIPM 下 `ξ=x+ẋ/ω`，`ω=√(g/z_c)`；支撑多边形 `SP_t`；稳定裕度 `MoS(t)=dist(ξ(t), ∂SP_t)`（内部为正），`ρ_bal=min_t MoS(t)`。
- **定义 271（BME 提前量）**：`τ_lead = t_violate - t_detect`，`t_violate=inf{t:MoS(t)<0}`，`t_detect` 为 BME 首次触发时刻。目标 `τ_lead ≥ τ_min`（默认 150ms，约一个恢复步）。
- **定义 272（CEAT 跨域迁移）**：面部时空 AU 编码器 `E_face` 与步态编码器 `E_gait` 共享 `d_z` 维表达流形 `Z`；对齐损失 `L_align = MMD(E_face(AU_face), E_gait(BAU)) + λ_c·Coral(E_face,E_gait)`，再以 `L_BAU` 有监督微调 `E_gait`。
- **定义 273（共享表达流形与样本复杂度）**：若两域共享 `d_z<d_q` 维流形，则 BAU 检测的泛化误差 `ε(N) ≤ ε_0 + C√((d_z+log(1/δ))/N)`，样本效率相对从零训练提升约 `d_q/d_z` 倍。
- **定义 274（BEW 早警融合）**：`P_fall(t)=σ(w_bme·f_bme + w_mos·(1-clip(MoS/ε_mos,0,1)) + w_wm·P_WM(H_fall))`，`f_bme` 为 BME 置信与提前量的归一化组合；`P_fall>τ_warn` 触发保守步态。
- **定义 275（SEG 社交表情网关）**：复用 ERG 得到人类表情 `π_human∈Δ^4`，输出 `social_gate∈{ENGAGE, CAUTIOUS, AVOID}`，并给出社交风险 `R_social`。
- **定义 276（社交风险）**：`R_social = 1 - π_human(neutral) - 0.3·π_human(tense) - 0.8·π_human(fear) - π_human(pain) + ε`，与第 66 轮 `R_emotion` 同构。
- **定义 277（可接受表达强度）**：`α_exp = clip(1 - κ·R_social/(d_h+ε_0), α_min, 1)`，`d_h` 为人机距离。人类越紧张、越近，允许展示的可见不稳定度越低。
- **定义 278（稳定性雅可比与表达零空间）**：`J_c = ∂(ξ̇, MoS)/∂u`；表达零空间 `N = I - J_c^+J_c`，满足 `J_c N = 0`（一阶不改变稳定量）。
- **定义 279（SocialMask 表达塑形）**：`u = u_nom + α_exp·N·u_exp^des`，其中 `u_exp^des` 为期望的表达动作（臂摆、躯干偏航、步频微调）。硬约束 `MoS(t) ≥ ρ_min`、`‖u‖≤u_max`。
- **定义 280（表达置信）**：`c_exp(t) = f_c(BAU_visible(t)) ∈ [0,1]`，即外部观察者从可见步态推断出的「机器人很稳」的置信。
- **定义 281（诚实性散度）**：`s_true(t)=clip(MoS(t)/ε_mos,0,1)`；`D_honesty = E[max(c_exp - s_true - δ_h, 0)] + λ·E[|c_exp - s_true|]`。证书要求 `D_honesty ≤ δ_h`（单边：允许「示弱」，禁止「假稳」）。
- **定义 282（共因故障）**：`E_common_gait` = 「同一物理扰动（地面突变/人群推挤）同时引起人类紧张 `π_human` 与机器人失衡 `BAU`」的联合假设，纳入 DualFACS 的联合后验。
- **定义 283（BAL-SimEngine）**：在 SimRAS 的 DiffPhys 上加入双足 LIPM + 全身 MPC + 足地接触模型；自动标注 BAU/BME；由情绪动力学驱动虚拟人类 `π_human`，用于 CEAT 与阈值标定。
- **定义 284（Dual-FACS 耦合矩阵）**：`M_dual = Cov(π_human, BAU)`，以互信息 `I(π_human;BAU)` 度量「人-机情绪-步态」耦合强度；`I>τ_mi` 判为共因耦合。
- **定义 285（J_GaitFACS 证书）**：`J_GaitFACS=(J_SimRAS, bfacs_hash, bme_lead, mos_margin, honesty_div, social_gate, aic_gait_ver)`。Valid ⇔ `Valid(J_SimRAS) ∧ mos_margin≥ρ_min ∧ bme_lead≥τ_min ∧ honesty_div≤δ_h`。
- **定义 286（BME 主动探针）**：当 `P_fall` 处于「不确定带」`[τ_low,τ_high]` 时，主动施加微扰测试步（如轻点地面/小幅侧移）以放大 BME 信噪比，探针本身受 `MoS≥ρ_min+Δ_probe` 保护。
- **定义 287（形态迁移不变式）**：对不同腿长/自由度/质量分布的机器人，BAU 语义（而非数值）保持不变：存在形态映射 `T:Φ→Φ'` 使 `a'` 的语义标签一致；CEAT 的共享流形应吸收形态差异。
- **定义 288（实时/语义流分离不变式）**：实时流仅含 BAU 提取、BME 检测、BEW、零空间塑形、诚实性快速校验；CEAT 训练、BAL-SimEngine、VQA 审计、审计缓冲全部在语义流/离线，零实时写操作。
- **定义 289（表达通道可观测性）**：存在从表达通道 `u_exp` 到外部可见运动 `y_vis` 的单射（至少局部），否则 `c_exp` 不可辨识，诚实性证书拒绝签发。
- **定义 290（GaitFACS 端到端算子）**：`GaitFACS: (q,c,w,img,d_h) ↦ (u, mode, P_fall, J_GaitFACS)`，满足定义 288 的不变式与定义 285 的有效性约束。

# B-FACS：步态动作单元提取（实时流）
class BFACSExtractor:
    def __init__(self, basis_phi, groups, K=7):
        self.phi, self.groups, self.K = basis_phi, groups, K

    def extract(self, q_hist, contact_hist, imu_hist):
        q_nom = nominal_gait(q_hist, contact_hist)
        dq = q_hist - q_nom
        a = nnls(self.phi, dq.T).T           # 非负强度 [T,K]
        a = phase_align(a, contact_hist)     # 按支撑相对齐
        segs = temporal_segments(a)          # onset/apex/offset
        return {'a': a, 'segs': segs, 'q_nom': q_nom}


# CEAT：FER 动作单元编码器 → B-FACS 的跨域迁移（离线/语义流）
class CrossEmbodimentAUTransfer:
    def __init__(self, face_encoder, gait_encoder, d_z=16):
        self.e_face, self.e_gait, self.d_z = face_encoder, gait_encoder, d_z

    def align_loss(self, au_face, bau_gait):
        zf, zg = self.e_face(au_face), self.e_gait(bau_gait)
        return mmd(zf, zg) + 0.1 * coral(zf, zg)

    def finetune(self, D_face, D_gait, steps=1000):
        for _ in range(steps):
            L = self.align_loss(*sample(D_face)) + bau_sup_loss(self.e_gait, D_gait)
            L.backward()


# BME-Spotter：平衡微表情检测（借微表情 apex spotting）
class BalanceMicroExpressionSpotter:
    def __init__(self, eps_amp=0.15, eps_vel=2.0, rho_min=0.3, max_len=0.2):
        self.eps_amp, self.eps_vel = eps_amp, eps_vel
        self.rho_min, self.max_len = rho_min, max_len

    def spot(self, a_hist, r_dcm_hist, dt):
        vel = gradient(a_hist, dt)
        hits = []
        for t in range(1, len(a_hist)):
            amp = norm(a_hist[t] - a_hist[t - 1])
            if amp <= self.eps_amp and norm(vel[t]) >= self.eps_vel:
                lo = max(0, t - 5)
                if corr(a_hist[lo:t], r_dcm_hist[lo:t]) >= self.rho_min:
                    hits.append((t, 'apex'))
        return merge_segments(hits, max_len=int(self.max_len / dt))


# BEW：平衡早警融合
class BalanceEarlyWarning:
    def __init__(self, w_bme=0.5, w_mos=0.3, w_wm=0.2, tau_warn=0.35):
        self.w_bme, self.w_mos, self.w_wm = w_bme, w_mos, w_wm
        self.tau_warn = tau_warn

    def risk(self, bme, mos, wm_fall_prob):
        f_bme = min(1.0, bme.confidence * bme.lead_time / 0.5)
        p = sigmoid(self.w_bme * f_bme
                    + self.w_mos * (1 - clip(mos / 0.1, 0, 1))
                    + self.w_wm * wm_fall_prob)
        return {'p_fall': p, 'warn': p > self.tau_warn, 'lead': bme.lead_time}


# SEG：人类表情 → 社交风险门（复用 ERG）
class SocialExpressionGateway(EmotionRecognitionGateway):
    def social_gate(self, face_img, distance):
        emo = self.recognize(face_img)
        R_social = emo['risk']
        gate = ('ENGAGE' if distance > 2.0 and R_social < 0.3
                else 'CAUTIOUS' if R_social < 0.6 else 'AVOID')
        return {'pi_human': emo['pi'], 'R_social': R_social,
                'gate': gate, 'distance': distance}


# SocialMask：稳定零空间内的表达塑形
class SocialMaskShaper:
    def __init__(self, stab_jacobian, alpha_min=0.2, kappa=0.8):
        self.Jc, self.alpha_min, self.kappa = stab_jacobian, alpha_min, kappa

    def alpha_exp(self, R_social, distance):
        return clip(1 - self.kappa * R_social / (distance + 0.1), self.alpha_min, 1.0)

    def shape(self, u_nom, u_exp_desired, R_social, distance):
        alpha = self.alpha_exp(R_social, distance)
        N = np.eye(len(u_nom)) - pinv(self.Jc) @ self.Jc   # Jc N = 0
        return u_nom + alpha * (N @ u_exp_desired)


# HonestyCert：单边表达诚实性证书
class HonestyCertificate:
    def __init__(self, delta_h=0.05, lam=0.1):
        self.delta_h, self.lam = delta_h, lam

    def check(self, c_exp_hist, mos_hist, eps_mos=0.08):
        s_true = np.clip(np.array(mos_hist) / eps_mos, 0, 1)
        c_exp = np.array(c_exp_hist)
        over = np.maximum(c_exp - s_true - self.delta_h, 0)
        div = np.mean(over) + self.lam * np.mean(np.abs(c_exp - s_true))
        return {'divergence': div, 'valid': div <= self.delta_h,
                'overconfident_frames': int((over > 0).sum())}


# DualFACS：人-机表情-步态耦合 / 共因故障
class DualFACSCoupling:
    def __init__(self, tau_mi=0.15):
        self.tau_mi = tau_mi

    def couple(self, pi_human_hist, bau_hist):
        mi = mutual_info(pi_human_hist, bau_hist)
        return {'mi': mi, 'common_cause': mi > self.tau_mi}


# 端到端在线闭环
def GaitFACS_round(M, obs):
    q_hist, contact, imu, img, dist = obs

    # 1) 内环：B-FACS + BME + 早警
    bfacs = M.bfacs.extract(q_hist, contact, imu)
    mos = M.lipm.margin_of_stability(q_hist, contact)
    bme = M.bme.spot(bfacs['a'], M.lipm.dcm_residual(q_hist), M.dt)
    wm_fall = M.wm.rollout_fall_prob(M.lipm.state(q_hist), M.horizon)
    bew = M.bew.risk(bme, mos, wm_fall)

    # 2) 外环：人类表情 → 社交门 → 可接受表达强度
    social = M.seg.social_gate(img, dist)
    alpha = M.mask.alpha_exp(social['R_social'], dist)

    # 3) 早警触发 → 保守步态，禁用表达塑形
    if bew['warn']:
        u = M.gait_mpc.recover_step(M.lipm.state(q_hist), mos)
        mode = 'RECOVER'
    else:
        u_nom = M.gait_mpc.nominal(M.lipm.state(q_hist))
        u_exp = M.gait_mpc.expressive_component(social)
        u = M.mask.shape(u_nom, u_exp, social['R_social'], dist)
        mode = 'SOCIAL' if social['gate'] != 'AVOID' else 'CAUTIOUS'

    # 4) 诚实性证书 + 联合证书
    honest = M.honesty.check(M.expressed_confidence(u, bfacs), [mos])
    cert = M.j_gaitfacs.build(M.simras_cert, bfacs, bme, mos, honest, social)
    return {'u': u, 'mode': mode, 'bew': bew, 'social': social,
            'honest': honest, 'cert': cert}

## 3. 推导

**引理 13（BME 提前量的下界）** 设 DCM 残差在检测时刻按 `‖r(t)‖=‖r(t_d)‖e^{λ_b(t-t_d)}` 发散（`λ_b>0` 为局部发散率），BME 在 `‖r‖=ε_bme` 触发，违约在 `‖r‖=ε_bme+ρ_bal` 发生，则 `τ_lead ≥ (1/λ_b)·ln(1+ρ_bal/ε_bme)`。含义：**提前量随剩余裕度增大、随检测阈值与发散率下降而增大**；这解释了为何「低幅高导数」的 BME 比「低幅」的宏观检测更值钱。

**引理 14（CEAT 的样本效率）** 若面域与步态域共享 `d_z` 维流形、各自内在维度为 `d_q`，则从零训练 BAU 检测器所需样本 `N_0=Ω(ε^{-d_q})`，而 CEAT 迁移后 `N_CEAT=Ω(ε^{-d_z})`；当 `d_z≈16, d_q≈34` 时，样本效率约提升一个数量级。

**引理 15（零空间塑形的一阶安全不变性）** 若 `u=u_nom+αN u_exp` 且 `J_cN=0`，则一阶 `Δξ̇=0`、`ΔMoS=0`；二阶偏差 `|ΔMoS| ≤ ½‖αu_exp‖²·Lip(∇J_c)`。故 SocialMask 在 `α→0` 或 `‖u_exp‖` 小时对稳定量近似无影响。

**定理 14（GaitFACS 端到端稳定性与诚实性）** 在 A87–A91、引理 13–15 与 `D_honesty≤δ_h` 下，在线输出满足：
1. `P(fall) ≤ α_chunk + δ_fi + α_bme + α_wm + α_social`；
2. 早警触发时 `mode=RECOVER` 且 `k_ras` 冻结为保守前缀，禁止表达塑形；
3. 外部观察者的感知安全 `E[1-c_exp] ≥ E[1-s_true]-δ_h`，即「假稳」诱导的上限被 `δ_h` 锁死。

**定理 15（Dual-FACS 共因可辨识性）** 若 `π_human` 与 `BAU` 在无共因时条件独立、共因时经 `E_common_gait` 耦合，则联合后验 `P(H_fall,E_common|BAU,π_human)` 在 `I(π_human;BAU)>τ_mi` 时可把「人类紧张导致的操作者犹豫」与「机器人真实失衡」分离，误归因率下降 `exp(-γ·I)`。

**定理 16（形态迁移的语义保持）** 在定义 287 的形态映射存在且 CEAT 流形对齐误差 `≤ε_z` 时，跨形态 BAU 语义一致率 `≥1-ε_z/δ_sem`；超出该范围时证书拒绝签发并要求重标定。

# IP-243 B-FACS：步态动作单元提取（实时流）
class BFACSExtractor:
    def __init__(self, basis_phi, groups, K=7):
        self.phi, self.groups, self.K = basis_phi, groups, K

    def extract(self, q_hist, contact_hist, imu_hist):
        q_nom = nominal_gait(q_hist, contact_hist)
        dq = q_hist - q_nom
        a = nnls(self.phi, dq.T).T           # [T,K] 非负强度
        a = phase_align(a, contact_hist)     # 左右支撑相对齐
        return {'a': a, 'segs': temporal_segments(a), 'q_nom': q_nom}


# IP-244 CEAT：FER 动作单元编码器 → B-FACS 跨域迁移（离线）
class CrossEmbodimentAUTransfer:
    def __init__(self, face_encoder, gait_encoder, d_z=16):
        self.e_face, self.e_gait, self.d_z = face_encoder, gait_encoder, d_z

    def align_loss(self, au_face, bau_gait):
        zf, zg = self.e_face(au_face), self.e_gait(bau_gait)
        return mmd(zf, zg) + 0.1 * coral(zf, zg)

    def finetune(self, D_face, D_gait, steps=1000):
        for _ in range(steps):
            L = self.align_loss(*sample(D_face)) + bau_sup_loss(self.e_gait, D_gait)
            L.backward()


# IP-245 BME-Spotter：平衡微表情检测
class BalanceMicroExpressionSpotter:
    def __init__(self, eps_amp=0.15, eps_vel=2.0, rho_min=0.3, max_len=0.2):
        self.eps_amp, self.eps_vel = eps_amp, eps_vel
        self.rho_min, self.max_len = rho_min, max_len

    def spot(self, a_hist, r_dcm_hist, dt):
        vel = gradient(a_hist, dt)
        hits = []
        for t in range(1, len(a_hist)):
            amp = norm(a_hist[t] - a_hist[t - 1])
            if amp <= self.eps_amp and norm(vel[t]) >= self.eps_vel:
                lo = max(0, t - 5)
                if corr(a_hist[lo:t], r_dcm_hist[lo:t]) >= self.rho_min:
                    hits.append((t, 'apex'))
        return merge_segments(hits, max_len=int(self.max_len / dt))


# IP-246 BEW：平衡早警融合
class BalanceEarlyWarning:
    def __init__(self, w_bme=0.5, w_mos=0.3, w_wm=0.2, tau_warn=0.35):
        self.w_bme, self.w_mos, self.w_wm = w_bme, w_mos, w_wm
        self.tau_warn = tau_warn

    def risk(self, bme, mos, wm_fall_prob):
        f_bme = min(1.0, bme.confidence * bme.lead_time / 0.5)
        p = sigmoid(self.w_bme * f_bme
                    + self.w_mos * (1 - clip(mos / 0.1, 0, 1))
                    + self.w_wm * wm_fall_prob)
        return {'p_fall': p, 'warn': p > self.tau_warn, 'lead': bme.lead_time}


# IP-247 SEG：人类表情 → 社交门
class SocialExpressionGateway(EmotionRecognitionGateway):
    def social_gate(self, face_img, distance):
        emo = self.recognize(face_img)
        R_social = emo['risk']
        gate = ('ENGAGE' if distance > 2.0 and R_social < 0.3
                else 'CAUTIOUS' if R_social < 0.6 else 'AVOID')
        return {'pi_human': emo['pi'], 'R_social': R_social,
                'gate': gate, 'distance': distance}


# IP-248 SocialMask：稳定零空间内的表达塑形
class SocialMaskShaper:
    def __init__(self, stab_jacobian, alpha_min=0.2, kappa=0.8):
        self.Jc, self.alpha_min, self.kappa = stab_jacobian, alpha_min, kappa

    def alpha_exp(self, R_social, distance):
        return clip(1 - self.kappa * R_social / (distance + 0.1), self.alpha_min, 1.0)

    def shape(self, u_nom, u_exp_desired, R_social, distance):
        alpha = self.alpha_exp(R_social, distance)
        N = np.eye(len(u_nom)) - pinv(self.Jc) @ self.Jc   # Jc N = 0
        return u_nom + alpha * (N @ u_exp_desired)


# IP-249 HonestyCert：单边表达诚实性证书
class HonestyCertificate:
    def __init__(self, delta_h=0.05, lam=0.1):
        self.delta_h, self.lam = delta_h, lam

    def check(self, c_exp_hist, mos_hist, eps_mos=0.08):
        s_true = np.clip(np.array(mos_hist) / eps_mos, 0, 1)
        c_exp = np.array(c_exp_hist)
        over = np.maximum(c_exp - s_true - self.delta_h, 0)
        div = np.mean(over) + self.lam * np.mean(np.abs(c_exp - s_true))
        return {'divergence': div, 'valid': div <= self.delta_h,
                'overconfident_frames': int((over > 0).sum())}


# IP-250 DualFACS：人-机耦合 / 共因
class DualFACSCoupling:
    def __init__(self, tau_mi=0.15):
        self.tau_mi = tau_mi

    def couple(self, pi_human_hist, bau_hist):
        mi = mutual_info(pi_human_hist, bau_hist)
        return {'mi': mi, 'common_cause': mi > self.tau_mi}


# IP-252 GaitFACS 在线闭环
def GaitFACS_round(M, obs):
    q_hist, contact, imu, img, dist = obs

    # 1) 内环
    bfacs = M.bfacs.extract(q_hist, contact, imu)
    mos = M.lipm.margin_of_stability(q_hist, contact)
    bme = M.bme.spot(bfacs['a'], M.lipm.dcm_residual(q_hist), M.dt)
    wm_fall = M.wm.rollout_fall_prob(M.lipm.state(q_hist), M.horizon)
    bew = M.bew.risk(bme, mos, wm_fall)

    # 2) 外环
    social = M.seg.social_gate(img, dist)
    alpha = M.mask.alpha_exp(social['R_social'], dist)

    # 3) 早警优先安全
    if bew['warn']:
        u = M.gait_mpc.recover_step(M.lipm.state(q_hist), mos)
        mode = 'RECOVER'
    else:
        u_nom = M.gait_mpc.nominal(M.lipm.state(q_hist))
        u_exp = M.gait_mpc.expressive_component(social)
        u = M.mask.shape(u_nom, u_exp, social['R_social'], dist)
        mode = 'SOCIAL' if social['gate'] != 'AVOID' else 'CAUTIOUS'

    # 4) 证书
    honest = M.honesty.check(M.expressed_confidence(u, bfacs), [mos])
    cert = M.j_gaitfacs.build(M.simras_cert, bfacs, bme, mos, honest, social)
    return {'u': u, 'mode': mode, 'bew': bew, 'social': social,
            'honest': honest, 'cert': cert}

## 4. 推导

**引理 13（BME 提前量下界）** 设 DCM 残差局部按 `‖r(t)‖=‖r(t_d)‖e^{λ_b(t-t_d)}` 发散，BME 在 `ε_bme` 触发、违约在 `ε_bme+ρ_bal` 发生，则
```
τ_lead ≥ (1/λ_b)·ln(1 + ρ_bal/ε_bme)
```
提前量随剩余裕度增大、随检测阈值与发散率下降而增大。

**引理 14（CEAT 样本效率）** 共享 `d_z` 维流形、内在维度 `d_q` 时，从零训练需 `N_0=Ω(ε^{-d_q})`，迁移后 `N_CEAT=Ω(ε^{-d_z})`；`d_z≈16, d_q≈34` 时样本效率约提升一个数量级。

**引理 15（零空间一阶安全不变性）** 若 `u=u_nom+αN u_exp` 且 `J_cN=0`，则一阶 `Δξ̇=0, ΔMoS=0`；二阶 `|ΔMoS| ≤ ½‖αu_exp‖²·Lip(∇J_c)`。

**定理 14（端到端稳定性与诚实性）** 在 A87–A91、引理 13–15 与 `D_honesty≤δ_h` 下：
1. `P(fall) ≤ α_chunk + δ_fi + α_bme + α_wm + α_social`；
2. 早警触发 ⇒ `mode=RECOVER`，冻结保守前缀，禁用表达塑形；
3. `E[1-c_exp] ≥ E[1-s_true]-δ_h`，即「假稳」诱导上限被 `δ_h` 锁死。

**定理 15（Dual-FACS 共因可辨识）** 若 `π_human⊥BAU | 无共因`、共因经 `E_common_gait` 耦合，则 `I(π_human;BAU)>τ_mi` 时可分离「操作者犹豫」与「真实失衡」，误归因率降 `exp(-γI)`。

**定理 16（形态迁移语义保持）** 若定义 287 的 `T` 存在且 CEAT 流形对齐误差 `≤ε_z`，则跨形态 BAU 语义一致率 `≥1-ε_z/δ_sem`；否则证书拒绝签发并要求重标定。

## 8. 本轮最大风险

**一句话**：GaitFACS 的核心赌注是「双足失稳存在类似人脸微表情的『低幅-短时-高导数』前兆」，但真实失稳常由接触冲击、打滑、外力推挤等**高幅-突变**事件主导；一旦该同构不成立，BME 提前量会退化为 0，而 SocialMask 的可见性塑形反而可能在真实失稳时掩盖人类本应看到的警告信号——这是本轮全部理论依赖的核心假设：**平衡前兆的统计形态与面部微表情同构，且「表达塑形」与「安全信号」可以被零空间干净地解耦**。
