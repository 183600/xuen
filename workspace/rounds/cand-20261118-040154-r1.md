# 第 12 轮（新灵感循环第 1 轮；本轮灵感：「模仿学习」×「数据采集」）

> **基线**：第 11 轮 MetricVoiceGauge-NCD-H（定义 554–570；引理 96–103；实验 E589–E606；IP-363–366）。
> 本轮纪律：**证据先于策略、覆盖先于精度、采集即实验设计、证据必须独立**。不推倒 v11：HAS/HCC/HATD/HDT、MetricVoiceGauge 九不变式、NGE/DSL/CC/CWM/CAE/NCP、AC/MW/ID、DA/SPR/Cal 全部保留；三个新组件以**互不相交端口**接入，任一失效注入中立元，严格退回 v11（引理 102/110 升级版），再沿 v11 链退回 v10/v9/v8/v7/v6。本轮只做三件事：把"演示"变成带见证管的技能、把"见证覆盖"变成证书条件、把"数据采集"变成证书驱动且可屏蔽的实验设计。

## 0. 直觉与动机

### 0.1 v11 真正遗漏的两个隐含假设

v11 已经把规范、接触、因果、谐波四类约束接进同一个块级决策闭环，并把执行器柔顺度提升为技能与证书的一等公民。但它的四重证书仍默认两件事：

1. **技能是给定的，且技能的参考轨迹天然可信**。π_h 的 θ_flex_ref、τ_h_ref、K_p、K_d、f_max 要么来自工程手写，要么来自优化器在仿真里搜出来的解。真实机器人上更常见的来源是**人类演示**：遥操作、动觉示教、VR 手柄、视频加关节重定向。模仿学习可以把这些演示变成策略，但行为克隆只对齐"观测→动作"，不保证演示者的**隐含柔顺策略**（在多大力、何时让、遇到接触相变如何退让）被保留；更严重的是，一条演示只在一个很窄的状态管里证明了"这样做曾经可行"，它**没有**证明这个技能在证书定义域内的其它状态也可行。把演示当策略先验、再把策略在证书域上全权认证，等于把"一次成功"外推成"处处安全"。

2. **数据是充分的，且训练数据可以同时充当证书证据**。v11 的 β 余量、HDT 的域随机化分布、HATD 的启发式、CWM 的不变父集，全部由数据校准。但默认的数据采集是被动的：成功演示多、失败与临界样本少；标称工况多、接触相变与近共振边界少；方便采集的物体/操作者/日期多，真正会击穿证书的组合少。更危险的是，同一批数据既训练策略又校准证书，模型可以在训练集上"自证"——**平均误差下降，但证书边界附近的证据并没有增加**。数据越多，系统越自信；而自信的来源可能只是覆盖了容易的区域。

这两个盲点会**互相放大**：演示密集的地方，策略最自信；数据密集的地方，证书最宽松；而接触相变、滑移临界、近共振、热积累这些真正危险的状态，恰恰既缺演示、又缺数据。于是系统会遇到最坏情形——**在最需要证据的地方，拥有最高的置信度**。

### 0.2 灵感 1（模仿学习 → 演示是带见证管的技能约束，不是动作标签）

直觉：人类演示最有价值的部分不是"手在每一帧往哪动"，而是**在特定接触模式下，用多大的阻抗、留多大的力裕度、什么时候主动退让**。同一段倒水动作，专家和新手的手部轨迹可能很像，但专家的柔顺策略让杯子在接触瞬间不晃、不滑、不激振。行为克隆把这种差异平均掉，得到的策略"看起来对"，却在证书最敏感的相变点失去可解释的力/柔顺结构。

核心创新：**演示锚定技能归纳器（Demonstration-Grounded Skill Inducer, DGSI）**。它不把演示压成 obs→a 的回归器，而是：

- 先用接触模式变点检测把演示切成"自由→接触→力控→释放"等模式段，再用 DTW/相位映射对齐不同演示的同一相位；
- 在每一段上做**合规反辨识**：由运动、接触力/力矩、电流与 v11 的谐波模型，反推演示者的等效阻抗 (K_p,K_d)、力参考 f_ref、谐波参考 τ_h_ref 与柔顺裕度；若反辨识多解，则保留**集合值估计**而不是假装有点估计；
- 输出技能 π_h^D = (π_h, W_π, φ, provenance)，其中 **W_π 是见证管（witness tube）**：演示真正支持的状态-模式-相位区域；φ 是相位映射，provenance 是数据来源与切分标签；
- 用 split conformal 在留出的演示/验证轨迹上校准见证管半径，使"部署状态落在管外"的概率有有限样本、分布无关的上界。

关键转身：**演示不是策略的万能先验，而是技能可认证性的局部见证**。技能只在见证管内享受"演示背书"；管外必须回退到 v11 的模型证书（固定 β）或触发采集，而不是把管内的成功外推到管外。这样，"模仿"从复制动作变成**复制可执行的柔顺契约**。

### 0.3 灵感 2（数据采集 → 采集是证书边界的实验设计）

直觉：对安全证书而言，"更多数据"几乎总是错误的提法。真正的问题是：**哪一条数据能缩小证书的松弛量（slack），或能判定当前证书边界到底在安全侧的哪一边？** 在标称区域再采一万条成功轨迹，可能只让平均预测误差从 2% 降到 1.8%，却完全不改变"接触力上界是否会被击穿"这一纸证书；而在滑移临界点附近采一条带标签的近失败轨迹，可能直接把一个危险方向的 β 缩小一半。数据对证书的价值是**高度非均匀**的。

核心创新：**证书驱动主动采集器（Certificate-Driven Active Collector, CDAC）**。它把采集写成带预算的实验设计：

- 定义证书松弛 s(π;x) = 各证书分量中"距上限的归一化最小余量"；定义采集动作的**证书价值** CV(u) = E[松弛上界的下降 | 证据] / κ(u)，或等价的"对松弛符号的互信息 / 成本"；
- 动作集不只是"再演示一次"：请人演示**近失败后的恢复**（反事实/边界见证）、在 HDT 里对参数与状态做定向采样、在真机上执行**通过 v11 四重证书的微小探针**、请求人类标注一次歧义；
- 所有物理探针都套在 v11 的盾里（嵌套盾），采集本身不能成为新的不安全来源；仿真数据只能作为先验，不能冒充独立见证；
- 用自适应子模贪心在预算下选动作，得到 (1−1/e) 型近似保证；当证书价值低于停止阈值时停止，而不是无限采集。

关键转身：**数据采集不是感知预处理，而是证书边界上的主动实验**。它优化的不是平均精度，而是"最坏方向的松弛"。

### 0.4 灵感 3（模仿学习 × 数据采集 → 演示-采集共设计，反自证）

直觉：把前两者直接拼起来，会得到一个更危险的东西：演示训练出的技能，又用同一批演示来证明其覆盖充分；采集器再优先选择"模型已经比较确定"的区域，因为那里标注便宜、成功率高。结果是**自证循环**：策略、覆盖证书、采集策略共享同一套偏差，证书越来越漂亮，真实边界却从未被触碰。

核心创新：**演示-采集共设计闭环（Demonstration–Data Co-Design Loop, DDCL）**，其核心是一条纪律而不是一个新网络：

- **证据独立性**：用于拟合技能/世界模型/参数后验的数据，不能同时作为该组件证书的唯一见证。按轨迹、操作者、物体实例、工况、日期做 provenance 级切分；WCC 维护证据 DAG，检测"训练-认证"重叠。若无法获得独立证据，则证书退化为 v11 的模型证书（保守），而不是用自证数据签发新证书。
- **反事实演示**：不只采集成功演示，还主动请人演示"差一点失败"的恢复过程，或让仿真在边界附近生成带安全标签的对照。成功样本给出可行性的单侧证据，边界样本才给证书提供**方向**。
- **覆盖驱动的采集**：WCC 先找出见证管的"洞"（证书域中距任何见证都很远、且证书灵敏度高的区域），CDAC 再针对洞选动作；新证据回来后被 DGSI/WCC 重新消费，形成"覆盖→洞→采集→覆盖"的飞轮。

关键转身：**不是先模仿再补数据，而是让"哪里不会"决定"模仿什么、采集什么"**。演示提供技能与局部见证，采集负责把见证扩展到证书真正需要的边界。

### 0.5 三者如何统一

把决策写成**见证-覆盖-合规闭环（Witness–Coverage–Compliance Loop, WCCL）**：

```
演示/遥操作/动觉示教 ──► DGSI：模式切分 + 合规反辨识 + 共形见证管
        │                                   │
        │ provenance                        ▼
        ▼                          π_h^D = (π_h, W_π, φ, 来源)
   见证账本 ◄───────────────────────────────┘
        ▲                                   │
        │                                   ▼
        │                        WCC：覆盖证书 Ĉ_w + 独立性审计
        │                        覆盖条件裕度 β(x) / 收缩包络 / 拒绝
        │                                   │
        │             ┌─────────────────────┴──────────────┐
        │             ▼                                    ▼
        │      证书闭合、可执行                    覆盖洞/松弛紧张
        │             │                                    │
        │             ▼                                    ▼
        │      v11 四重证书 + 盾 + 块守卫           CDAC：证书价值最高的
        │             │                          演示/近失败/仿真/安全探针
        │             ▼                                    │
        └────── 执行日志、残差、触觉/力/电流 ──────────────┘
```

共享的见证状态是 **ζ_w = (skill_id, mode, phase, r_hole, β(x), provenance_set, slack)**。它不是又一个世界模型，而是把"这条技能在哪里有证据、证据有多独立、证据值多少钱"变成规划器可查询的一等状态。DGSI 回答"技能从哪来、在哪里被见证"，WCC 回答"证书的定义域是否被证据覆盖、证据是否独立"，CDAC 回答"下一步采什么最值得"。三者共享同一张见证账本，因此不是三个补丁，而是**技能来源-证书覆盖-数据获取**的闭环。

### 0.6 为什么不是这些"显然的解法"

- **不是行为克隆 + 共形预测包装**：对策略输出做共形预测，只给逐点动作区间，不给闭环安全；这里共形化的是**状态-模式-相位空间中的见证覆盖**，并让覆盖半径进入证书裕度。动作区间大不代表闭环安全，见证管空才是真的没有证据。
- **不是 DAgger / 主动模仿学习**：DAgger 沿策略 rollout 请专家标注以提升任务性能；CDAC 沿**证书松弛最紧或符号最不确定**的方向采集，且动作包括仿真、物理探针与近失败演示，目标是缩小证书不确定性而不是平均策略误差。
- **不是域随机化**：DR 随机化的是**参数**（k_h、摩擦、负载），回答"参数漂移下策略是否稳"；WCC 覆盖的是**证据状态**，回答"这条技能在哪些状态下真的被见证过"。参数覆盖与证据覆盖是正交的两件事，v11 只做了前者。
- **不是"多采数据就好"**：引理 109 将给出被动标称采样与边界主动采样的样本复杂度分离；在边界附近，主动一条可能胜过被动成千条。
- **不是用仿真自证**：HDT 是 v11 的预测器与训练场，仿真样本可以扩先验、做课程，但不能作为独立见证签发实机证书；否则 sim-to-real 的结构误差会被"仿真覆盖"掩盖。

## 1. 研究问题（轮次升级版）

- **Q1（演示的可归纳性与合规可辨识性）**：如何从少量、异构、带噪声的人类演示中，稳定地切分接触模式、对齐相位，并反辨识出演示者的隐含阻抗/力/谐波参考？当反辨识多解时，如何用集合值表示并把不确定性传入见证管与证书，而不是塌缩成一个虚假的点估计？
- **Q2（见证覆盖的可证性与度量选择）**：如何定义"证书定义域被见证覆盖"？在高维接触-谐波状态上，如何选一个**与证书灵敏度对齐**的度量，使覆盖半径能直接控制证书误差？共形校准给出的是边缘覆盖还是条件覆盖？如何用分层/局部共形与核心集得到可计算、可审计的覆盖证书？
- **Q3（证书驱动采集的最优性与安全性）**：在人类时间、物理风险、仿真预算约束下，如何选采集动作使证书松弛上界下降最快？证书价值是否自适应子模？物理探针如何嵌套在 v11 盾内，保证采集本身 100% 通过既有证书？何时应停止采集而转向 a_ask/回退？
- **Q4（证据独立性与反自证）**：如何形式化"训练证据"与"认证证据"的独立性？当 provenance 切分不足以消除共享偏差（同一物体、同一工厂、同一操作者习惯）时，证书还剩下什么保证？如何检测并惩罚"采集器只采容易样本"的 Goodhart 行为？
- **Q5（与 v11 的兼容与退化）**：DGSI 产生的新技能如何保证不绕过 HAS/HCC/HATD/HDT 与四重证书？WCC 的覆盖门控会不会把可行集清空？三者全失效时，主闭环是否与 v11 逐位一致？新增离线/异步成本是否仍守住 50Hz 与 p99 ≤22ms？

## 2. 设计原则（在 P16–P18 基础上新增 P19–P22）

**P19 演示即契约律（Demonstration as Contract）**
任何由演示归纳出的技能必须携带 (W_π, φ, provenance)，并显式声明"只在见证管内享受演示背书"。技能的前置/后置条件在管外不得引用演示证据；管外执行必须回退到 v11 的模型证书或触发采集。禁止把行为克隆的平均策略当作演示对全状态域的可行性证明。

**P20 覆盖即证书条件律（Coverage-Conditioned Certification）**
证书 Ĉ 的有效性必须同时满足：(i) v11 的模型/物理/接触/谐波判据；(ii) 在证书定义域上，见证覆盖概率不低于 1−α，且最大见证洞半径不超过 r_max；(iii) 覆盖条件裕度 β(x) = β_model + L_β·r_hole(x) 被使用，而不是全空间固定 β。覆盖不足时，WCC 只能**收缩技能包络或拒绝**，不能靠"加一点保守量"继续签发。

**P21 采集即实验设计律（Collection as Experiment Design）**
每一次数据采集动作都必须有明确的证书价值估计，并在预算下按 CV/κ 选择；采集动作本身必须通过 v11 四重证书（物理探针）或明确标记为非独立先验（仿真）。禁止无目标地"多采一点"，也禁止用采集动作绕过任何既有安全门。

**P22 证据独立律（Evidence Independence）**
用于拟合某组件的证据与其认证证据必须在 provenance 上可分离；若不可分离，则该组件不得以"见证覆盖"名义签发证书，只能退回 v11 的模型证书。证据 DAG 必须可审计、可复现，且仿真与实机、训练与验证、调参与测试的边界要在账本中显式标注。

## 3. 与基线的接口（如何退化）

- **DGSI 失效** ⇒ 注入技能归纳中立元：π_h^D ← v11 的 DSL/π_h 技能，W_π ← 全空间但只允许 v11 固定 β，provenance ← 空；**等价 v11 灵巧路径**。
- **WCC 失效** ⇒ 注入覆盖中立元：Ĉ_w ≡ true，β(x) ≡ β_v11，不做独立性审计；DGSI 只能提交其包络已被 v11 技能覆盖的技能，否则退回 v11 技能集；**等价 v11 证书路径**。
- **CDAC 失效** ⇒ 注入采集中立元：按 v11 的被动课程采集（有演示就收、HDT 均匀 DR、无证书价值评分），DGSI/WCC 仍工作；**等价 v11 数据路径**。
- **DGSI + WCC + CDAC 全失效** ⇒ 完整退回 MetricVoiceGauge-NCD-H v11，再按 v11 链退回 v10/v9/v8/v7/v6；
- **安全继承**：v11 的物理/接触/谐波/规范证书仍是硬门。DGSI 只能**提出**技能，WCC 只能**收缩/拒绝**，CDAC 只能**建议采集**；任何新模块都不能扩张执行集、不能删除 v11 适用证书、不能把非独立证据当见证（引理 111 升级版）。

## 4. 预期贡献

1. **演示锚定技能归纳与见证管**：把模仿学习从"复制动作"改为"归纳带柔顺契约的技能 + 共形见证管"，给出合规反辨识、集合值不确定性与有限样本覆盖，直接补上 v11"技能来源不可审计"的空白；
2. **见证覆盖证书与覆盖条件裕度**：把"数据是否足以支撑证书"变成一等证书条件，用证书灵敏度构造度量、用核心集与分层共形给出可计算覆盖界，覆盖不足时只收缩/拒绝；
3. **证书驱动主动采集与嵌套盾**：把数据采集写成边界实验设计，统一成功演示、近失败反事实、仿真定向采样与安全物理探针，给出自适应子模近似保证与采集安全性；

## 5. 本轮最大风险

**一句话**：演示与采集数据在接触相变、滑移临界与近共振边界上天然稀疏，若见证覆盖用错了任务相关度量、把"看起来相似"当成"见证充分"，系统就会在最需要证据的地方得到最自信的假覆盖——**数据很多、见证很少、证书仍然自洽**。

**定义 571（演示轨迹与溯源 Demonstration Trajectory & Provenance）** 一条演示是带上下文与切分标签的时序轨迹
```
D_i = ( {(x_t, u_t, y_t)}_{t=1}^{T_i}, c_i, p_i, split_i )
```
其中 x_t 含关节/电机编码器、末端位姿、触觉/力/力矩、电流、温度；u_t 为人类输入或重定向后的动作；y_t 为接触模式后验与力/谐波观测量。p_i 记录操作者、物体实例、工厂/批次、日期、环境、传感器型号等 provenance 属性；split_i∈{train,calib,audit,deploy} 记录该轨迹在证据 DAG 中的用途。**同一轨迹不得同时进入拟合集与认证集**，除非显式标记为 reused 并在 WCC 中降权为零。

**定义 572（演示锚定技能与见证管 Demonstration-Grounded Skill & Witness Tube）** 演示锚定技能是
```
π_h^D = ( π_h, φ, W_π, C_π, r_π, D_π, provenance(π_h^D) )
```
其中 π_h 为 v11 HAS；φ 把轨迹时间映射到模式-相位坐标 (m,ρ)∈M×[0,1]；W_π 是演示及其留出验证轨迹在 (x,m,ρ) 空间中的支持集；C_π 是 W_π 的 k-center 核心集；r_π 是核心集半径；D_π 是参与归纳的演示索引。技能的**见证契约**为：
```
x 可享受演示背书  ⇔  (x,m,ρ) ∈ W_π  ⇔  r_hole(x,m,ρ) ≤ r_α
```
其中 r_α 由分层 split conformal 在 calib 轨迹上校准（定义 574）。**管外不享有演示背书**：π_h^D 在管外只有在 v11 固定 β 的模型证书有效时才可执行，否则必须触发 CDAC 或拒绝。

**定义 573（合规反辨识 Compliance-Aware Inverse Identification）** 给定演示段及其模式-相位对齐，反辨识演示者的隐含柔顺参数
```
θ_id = ( K_p, K_d, f_ref, τ_h_ref, θ_flex_ref, 柔顺裕度 κ_c )
```
通过加权约束优化：
```
θ̂_id ∈ argmin_θ  w_a·‖u_t − π_θ(x_t)‖² + w_f·‖F_t − F̂(x_t,u_t;θ)‖²
                  + w_h·‖τ_h,t − τ̂_h(x_t,u_t;θ)‖² + λ·R(θ)
s.t.  θ ∈ Θ_adm（v11 技能参数域）,  谐波/接触动力学可行
```
当 Hessian 条件数超过阈值或存在多个局部极小，输出**集合值估计**
```
Θ_id = { θ : loss(θ) ≤ loss(θ̂_id) + ε_id }
```
并把 Θ_id 的不确定性传播到见证管半径与 β(x)。**禁止在反辨识多解时塌缩为单点估计**；若 Θ_id 的直径超过 δ_id，该段只能在 v11 固定 β 下使用，或由 CDAC 采集带激励的探针来缩小 Θ_id。

**定义 574（见证核心集与覆盖证书 Witness Coreset & Coverage Certificate）** 对技能 π 的见证集 W_π 构造 k-center 核心集 C_π，使
```
r_π = max_{w∈W_π} d_W(w,C_π) ≤ r_core
```
对任意部署状态 x=(x,m,ρ)，定义洞半径
```
r_hole(x) = d_W(x, C_π) + r_π
```
给定部署分布 μ_π（由 HATD/CWM 在技能包络上预测、按模式与相位分层），见证覆盖概率为
```
cov_α(π) = P_{x∼μ_π}[ r_hole(x) ≤ r_α ]
```
其中 r_α 由**分层 split conformal** 在 calib 集上按非一致性分数 r_hole 校准；对有限验证网格 G 上的最大洞，用联合界/DKW 给出置信上界 r_max。证书
```
Ĉ_w = ( cov_LB, r_max, indep_ok, α, δ, hash(G_prov) )
```
有效 ⇔
```
cov_LB ≥ 1−α  ∧  r_max ≤ r_max^allow  ∧  indep_ok = true
```
（若 indep_ok=false，则 Ĉ_w 只能作为"未认证"标记，执行必须退回 v11 固定 β，见 P22/引理 107。）覆盖概率是**部署分布上的边缘覆盖**（按模式/相位分层），不是逐状态条件覆盖；逐状态的最坏情形由 r_max 与 β(x) 共同控制。

**定义 575（覆盖条件裕度 Coverage-Conditioned Margin）** 对每个证书分量 c（接触力、θ_flex、τ_h、滑移裕度、热、规范裕度等），设真实误差场 e_c(x)=|ĉ_c(x)−c(x)| 关于 d_W 满足 L_c-Lipschitz，且在见证点 w 上 e_c(w)≤β_c^model。则对任意 x 使用
```
β_c(x) = β_c^model + L_c · r_hole(x)
β(x)   = ( β_c(x) )_c
```
作为该点的证书余量。L_c 由验证集上的保守上界 L̂_c 给出；若 L̂_c 不可证或超过 L_max，WCC 拒绝签发覆盖证书。**固定 β 被彻底废除**：靠近见证的点用接近模型的余量，远离见证的点自动变保守，而不是全空间使用同一个可能过松或过紧的常数。

**定义 576（证书松弛与证书价值 Certificate Slack & Certificate Value）** 对技能 π 在状态 x 的证书，定义归一化松弛
```
s(π;x) = min_c  ( b_c − ĉ_c(π;x;β(x)) ) / scale_c
```
其中 b_c 为分量上限，scale_c 为该分量的物理量纲。s>0 表示安全余量，s≤0 表示违反。对采集动作 u，设其观测后风险后验从 R_before(x)=P(s<0|证据) 变为 R_after(x,u)，定义证书价值
```
CV(u) = E_{x∼μ_π}[ max(0, R_before(x) − R_after(x,u)) ] / κ(u)
```
或等价的"对 sign(s) 的互信息 / κ(u)"。CDAC 在预算下最大化累计 CV；当 max_u CV(u) < τ_stop 时停止采集。**CV 不是平均预测误差的下降**，而是证书边界风险的下降。

**定义 577（采集动作与嵌套盾 Acquisition Actions & Nested Shield）** 采集动作集
```
U_col = U_demo^+ ∪ U_demo^− ∪ U_sim ∪ U_probe
```
- U_demo^+：请求一次成功演示（标称或指定模式/相位）；
- U_demo^−：请求一次"近失败后的恢复"演示（反事实/边界见证，定义 582）；
- U_sim：在 HDT 中对指定状态/参数做定向采样或重置，标记 independent=false；
- U_probe：在真机上执行微小激励（小幅转动、轻触、受控重抓、谐波安全频带内的力脉冲）。
每个动作带成本 κ(u)=(人类时间, 物理风险, 仿真预算)。**嵌套盾**要求所有物理动作满足
```
Shield_v11(u) = 1  ⇔  u 通过 v11 的物理/接触/谐波/规范证书
```
只有 u∈U_col 且 Shield_v11(u)=1 才进入可执行采集集 U_col^adm。仿真动作可绕过物理盾但必须标记为非独立证据；人类演示请求不直接驱动机器人，故天然安全。

**定义 578（证据独立性与溯源图 Evidence Independence & Provenance DAG）** 设关键 provenance 属性集为 K_crit（操作者、物体实例、批次、日期、环境、传感器等）。两条证据 D,D' 关于 K_crit **独立**，记 D ⊥_ev D'，当且仅当
```
sig_{K_crit}(D) ∩ sig_{K_crit}(D') = ∅
∧ split(D) ≠ split(D')
∧ D 与 D' 在 G_prov 中无祖先-后代关系
```
其中 sig 为属性取值签名。证书的每条见证边 (D_fit→D_cert) 必须满足 D_fit ⊥_ev D_cert；否则该见证权重置零。若 K_crit 不可知，保守取 K_crit=全部属性；若仍无法分离，则 indep_ok=false，覆盖证书不签发，退回 v11 固定 β（引理 107）。

L = { entry_j = (hash_j, trajectory_j, provenance_j, split_j, model_versions_j, use_tags_j) }

**定义 581（覆盖收缩技能契约 Coverage-Contraction Skill Contract）** 给定技能 π 的原始包络 E_π（满足 v11 pre/post 与证书的状态集），WCC 求最大子集

E_π^cov = { x∈E_π : r_hole(x) ≤ r_α  ∧  Ĉ_w valid  ∧  β(x) 使用当前 L̂ }

**定义 582（边界/反事实见证 Boundary & Counterfactual Witness）** 一条边界见证是
```
w = (x, u, ℓ, δ_s, provenance)
```
其中 ℓ∈{safe, near-miss, unsafe}；near-miss 定义为证书松弛 s(π;x)∈(−ε_nm, +ε_nm) 且实际未发生违反；unsafe 为 s<0 或实际违反。δ_s 是松弛的估计区间。边界见证用于：(i) 估计 sign(s) 与局部 L_c；(ii) 缩小 β(x) 的方向性不确定；(iii) 作为 CDAC 的优先采集目标。**边界见证不能在其标签范围之外充当正见证**；一条 near-miss 只能证明"该邻域曾经接近边界"，不能证明"管外安全"。

**定义 583（采集课程与停止规则 Collection Curriculum & Stopping Rule）** 采集课程是满足预算的有限动作序列
```
χ = (u_1,...,u_T),  s.t.  Σ_t κ(u_t) ≤ B = (B_human, B_phys, B_sim),  u_t∈U_col^adm
```
停止规则：当 WCC 对当前技能集的覆盖证书全部有效，且 max_{u∈U_col^adm} CV(u) < τ_stop，或预算耗尽，或风险后验无法在剩余预算内分离时停止。停止后若仍有覆盖洞，则只能收缩包络、a_ask 或退回 v11，不得用"继续执行 + 在线观察"替代采集。

Ĉ_joint = Ĉ_physical ∧ Ĉ_contact ∧ Ĉ_h ∧ Ĉ_w

有效 ⇔ 四者均有效，且 Ĉ_w 的独立性审计通过（或显式退回 v11 固定 β 且不使用演示证据）。当 WCC 中立时，Ĉ_w≡true 且 β(x)≡β_v11，逐项退回 v11 定义 555。

**升级定义 547′（接触证书，v12）** Ĉ_contact 的定义域从"技能包络 E_π"收缩为"覆盖收缩包络 E_π^cov"；在 E_π^cov 外，接触证书只能以 v11 固定 β 签发，且不得引用演示见证。若 E_π^cov 与接触可行集交集为空，则该段不可执行。

**升级定义 548′（接触安全中止，v12）** 中止点 p∈P^c∩P^h 还必须满足：从 p 开始的耗散轨迹要么在见证管内，要么通过 v11 固定 β 的模型证书；否则 HCC 拒绝该中止点。WCC 只能删除中止点，不能新增中止点。

**升级定义 557′（谐波感知分解，v12）** HATD 的每段候选新增覆盖约束
```
seg 的整个状态-模式-相位包络 ⊆ E_π^cov
```
若不存在满足覆盖约束的段，HATD 先尝试细化粒度或收缩包络；仍无解则向 CDAC 发出"覆盖洞"请求；CDAC 不可用时退回 v11 NCP 候选集与固定 β。

**升级定义 531′（软硬约束衔接，v12）** M₀ 硬检查新增四类入口：
```
(a) 在 E_π^cov 外执行且无 v11 固定 β 证书；
(b) 用非独立证据（indep_ok=false）作为唯一见证签发新技能；
(c) 物理探针未通过 v11 四重证书；
(d) 覆盖证书的 r_max 超过 r_max^allow 或 L̂_c 超过 L_max。
```
四者直接进入 M₀ 硬违规。v11 的物理/接触/谐波/规范判据不因新模块存在而放宽。

**升级定义 534‴（多语义中止点，v12）** P_t = P_t^nav ∪ P_t^c ∪ P_t^h 保持不变，但每个中止点在进入集合前须通过 WCC 的覆盖检查（或 v11 固定 β 回退）。块可执行必要条件升级为：当前模式对应的中止点集非空，且每个中止点的见证/回退证书有效。

# IP-367 DemonstrationGroundedSkillInducer
class DemonstrationGroundedSkillInducer:
    def __init__(self, v11_dsl, harmonic_model, alpha, delta, n_core=512, n_min=5):
        self.dsl, self.harmonic = v11_dsl, harmonic_model
        self.alpha, self.delta = alpha, delta
        self.n_core, self.n_min = n_core, n_min

    def induce(self, demos):
        skills = []
        for D in demos:
            # 1) 接触模式切分：对模式后验做变点检测
            segs = self._segment_modes(D)
            # 2) 相位对齐：模式内 DTW + 归一化相位
            for seg in segs:
                phi = self._align_phase(seg, demos)
                # 3) 合规反辨识：集合值 Θ_id，而非单点
                theta_set = self._inverse_compliance(seg, phi)
                if theta_set.diameter > self.delta_id:
                    theta_set = self._tighten_with_prior(theta_set, seg)
                # 4) 构造候选技能（保守端进入 π_h）
                pi_h = self._to_has(seg, phi, theta_set.conservative_end())
                # 5) 见证集 + 核心集
                W = self._witness_set(seg, phi)
                C, r = self._k_center(W, self.n_core)
                if len(W) < self.n_min or not self._physics_consistent(pi_h, W):
                    continue          # 证据不足：不产出技能，交给 v11/CDAC
                skills.append(DemonstrationGroundedSkill(
                    pi_h=pi_h, phi=phi, W=W, coreset=C, r_pi=r,
                    provenance=D.provenance, theta_set=theta_set))
        return skills

    def _segment_modes(self, D):
        # 模式后验上的变点检测（PELT/Bayesian change-point）
        return change_point(D.mode_posterior, penalty=self._penalty(D))

    def _align_phase(self, seg, corpus):
        # 以模式段为锚，DTW 对齐到语料的中位相位；返回 φ:(t,mode)->rho
        return dtw_phase_map(seg, reference=median_phase(corpus))

    def _inverse_compliance(self, seg, phi):
        # 定义 573：加权约束最小二乘 / 集合值估计
        fit = constrained_least_squares(
            residual=self._compliance_residual(seg, phi),
            bounds=self.dsl.parameter_bounds,
            consistency=self.harmonic.feasibility)
        return set_valued_estimate(fit, epsilon=self.epsilon_id)

    def _k_center(self, W, k):
        # 贪婪 k-center：O(|W|k)，返回核心集与半径
        return greedy_k_center(W, k, metric=certificate_metric)

    def _to_has(self, seg, phi, theta):
        # 把反辨识结果写入 v11 HAS 的 θ_flex_ref/τ_h_ref/f_ref/K_p/K_d
        return self.dsl.build_has(seg, phi, theta)

# IP-368 WitnessCoverageCertifier
WitnessReport = namedtuple("WitnessReport",
                           "valid cert r_alpha indep_ok lipschitz_ok")

class WitnessCoverageCertifier:
    def __init__(self, metric, alpha, delta, r_max_allow, L_max, ledger):
        self.metric = metric            # d_W：证书灵敏度加权度量
        self.alpha, self.delta = alpha, delta
        self.r_max_allow, self.L_max = r_max_allow, L_max
        self.ledger = ledger

    def certify(self, skill, deployment_strata):
        # 1) 覆盖半径：核心集 + 分层 conformal 校准
        r_alpha = self._conformal_radius(skill, deployment_strata)   # 定义 574
        # 2) 部署分布上的覆盖下界 + 网格最大洞
        cov_lb = self._coverage_lower_bound(skill, r_alpha, deployment_strata)
        r_max = self._max_hole_on_grid(skill, deployment_strata)
        # 3) 独立性审计：训练/校准 vs 认证
        indep_ok = self.ledger.audit_independence(
            fit_evidence=skill.provenance,
            cert_evidence=self.ledger.evidence_for(skill.id))
        # 4) Lipschitz 常数上界
        L_hat = self._certified_lipschitz(skill)
        valid = (cov_lb >= 1 - self.alpha
                 and r_max <= self.r_max_allow
                 and indep_ok
                 and all(L_hat[c] <= self.L_max for c in L_hat))
        cert = WitnessCert(cov_lb, r_max, indep_ok, r_alpha, L_hat)
        # 始终返回报告：valid=False 时仍保留 r_alpha/L_hat 供包络收缩或回退判断
        return WitnessReport(valid=valid, cert=cert, r_alpha=r_alpha,
                             indep_ok=indep_ok, lipschitz_ok=all(
                                 L_hat[c] <= self.L_max for c in L_hat))

    def conditioned_margin(self, x, cert, model_beta):
        # 定义 575：β(x) = β_model + L_c * r_hole(x)
        r_hole = self._hole_radius(x, cert)
        return {c: model_beta[c] + cert.L_hat[c] * r_hole for c in model_beta}

    def contract_envelope(self, skill, cert):
        # 定义 581：只收缩，不扩张
        E_cov = {x for x in skill.envelope
                 if self._hole_radius(x, cert) <= cert.r_alpha}
        return E_cov if E_cov else None

    def audit_independence(self, skill):
        # 定义 578/580：返回 bool；不一致则覆盖证据权重置零
        return self.ledger.audit_independence(skill.provenance,
                                             self.ledger.evidence_for(skill.id))

# IP-369 CertificateDrivenActiveCollector
class CertificateDrivenActiveCollector:
    def __init__(self, wcc, hdt, shield_v11, budgets, tau_stop):
        self.wcc, self.hdt, self.shield = wcc, hdt, shield_v11
        self.budgets, self.tau_stop = budgets, tau_stop

    def propose(self, skill, cert, posterior):
        # 1) 由覆盖洞/松弛紧张生成候选状态与模式
        holes = self._find_holes(skill, cert)
        # 2) 生成动作：成功演示、近失败演示、仿真定向采样、安全探针
        U = (self._demo_actions(holes)
             + self._near_miss_actions(holes)
             + self._sim_actions(holes, posterior)
             + self._probe_actions(holes, skill))
        # 3) 嵌套盾：物理动作必须通过 v11 四重证书
        U_adm = [u for u in U if u.kind != 'probe' or self.shield(u)]
        return U_adm

    def certificate_value(self, u, skill, cert, posterior):
        # 定义 576：风险下降 / 成本；用后验采样估计
        samples = posterior.sample(n=64)
        r_before = mean([self._risk(skill, cert, x) for x in self._targets(u)])
        r_after = mean([self._risk_after(skill, cert, x, u, s)
                        for s in samples for x in self._targets(u)])
        return max(0.0, r_before - r_after) / u.cost

    def select_and_run(self, skill, cert, posterior, budget):
        # 自适应子模贪心；带成本时按 CV/κ 密度
        chosen, spent = [], 0
        while spent < budget:
            U = self.propose(skill, cert, posterior)
            if not U: break
            u = max(U, key=lambda u: self.certificate_value(u, skill, cert, posterior))
            cv = self.certificate_value(u, skill, cert, posterior)
            if cv < self.tau_stop: break
            self._execute(u)                 # 演示请求/仿真/带盾探针
            self.wcc.ledger.append(u.evidence)  # 见证账本
            chosen.append(u); spent += u.cost
        return chosen

## 4. 推导

**引理 104（共形见证覆盖界）** 设 (A1) 在每个模式-相位分层 s 内，calib 集与部署状态关于非一致性分数 r_hole 可交换；(A2) 核心集 C_π 与 r_π 在 calib 前固定（不窥视 calib）；(A3) 部署分布 μ_π 的各分层可由 HATD/CWM 给出，且分层权重已知。则对一个新的部署状态 x，分层 split conformal 给出
```
P( r_hole(x) > r_{α,s} ) ≤ α + 1/(n_s+1)
```
其中 n_s 为第 s 层 calib 样本数。若对有限验证网格 G 要求一致覆盖，则取
```
P( max_{x∈G} r_hole(x) > r_{α/|G|,s} ) ≤ α
```
（联合界；或用 DKW 不等式得到经验分布与真实分布的一致偏差界）。因此 WCC 的 cov_LB 可由分层 conformal + 网格一致界共同给出。证明：标准 split conformal 的边缘覆盖 + 分层可交换性；有限网格用 union bound。∎

**引理 105（覆盖条件裕度安全性）** 设 (A1) 对每个证书分量 c，误差场 e_c(x)=|ĉ_c(x)−c(x)| 关于 d_W 是 L_c-Lipschitz；(A2) 对所有见证点 w∈W_π，e_c(w)≤β_c^model；(A3) 对执行状态 x，r_hole(x) 是到见证支持的 d_W 距离上界。则
```
e_c(x) ≤ β_c^model + L_c·r_hole(x) = β_c(x)
```
若证书使用 β_c(x) 检查且通过（ĉ_c(x)+β_c(x)≤b_c），则真实 c(x)≤b_c。证明：取最近的见证点 w*，由 Lipschitz 性与 (A3) 得 e_c(x)≤e_c(w*)+L_c d_W(x,w*)≤β_c^model+L_c r_hole(x)。∎

**引理 106（演示锚定技能的闭环性能界）** 设 (A1) 相位对齐误差 ≤ε_φ；(A2) 行为克隆/技能拟合的逐步动作误差 ≤ε_BC；(A3) 合规反辨识的集合值直径 ≤ε_id，且使用保守端；(A4) 闭环轨迹始终留在见证管 W_π 内；(A5) 闭环动力学关于状态与动作是 L_J-Lipschitz。则
```
J(π_h^D) ≥ J(π*) − C_J·(ε_BC + ε_id + ε_φ)
```
其中 C_J 依赖时域、L_J 与代价函数 Lipschitz 常数。**若轨迹离开 W_π，该界不成立**；此时只有 v11 的模型证书或 CDAC 新证据能重新给出保证。证明：逐步扰动传播 + Lipschitz 复合；管外无见证，故不能延拓。∎

**引理 107（独立性缺失下的自证不可能性）** 设训练证据 D_train 固定，证书只能访问 D_train（或与 D_train 同分布的 reused 数据），且模型类足够丰富。则存在两个部署环境 E_0,E_1，它们在 D_train 上产生完全相同的观测，但在部署域某状态 x* 上安全集不同；任何仅依赖 D_train 的证书要么在其中一个环境失效，要么对两者都弃权（真空）。因此，非平凡的覆盖证书必须依赖**独立见证或排除其中一个环境的强先验**。证明：构造两个世界，使 x* 的动力学仅在训练未覆盖的方向不同；由不可区分性，任何 D_train 上的函数无法区分 E_0,E_1。∎

**引理 108（证书驱动采集的近似最优性）** 设 (A1) 每个采集动作的观测在给定证书假设后条件独立；(A2) 证书价值函数 CV(·|已观测) 是单调、自适应子模的；(A3) 动作选择受基数或成本预算约束。则贪心选择（基数预算）取得
```
CV(χ_greedy) ≥ (1 − 1/e)·OPT
```
成本预算下按 CV/κ 密度贪心取得 ≥ (1−1/e)/2·OPT。若 CV 不满足自适应子模（例如用非凹的互信息代理），贪心无理论保证，只能报告经验曲线。证明：自适应子模最大化标准结论（Golovin & Krause, 2011），成本版本用密度贪心。∎

**引理 109（边界采样与被动标称采样的样本复杂度分离）** 设部署分布 μ 在安全边界 B 的 r-壳层上概率为 μ(B_r)。被动 i.i.d. 采样 n 条轨迹命中该壳层的概率不超过 n·μ(B_r)；当 μ(B_r) 随维度 d 指数小时，达到常数命中概率需要 n=Ω(1/μ(B_r))。反之，设 (A1) 边界在 d_b 维光滑流形上；(A2) 可安全执行 1-Lipschitz 的边界搜索探针；(A3) 边界两侧有 margin γ 的标签。则主动边界搜索可用 O((d_b/γ²)·log(1/δ)) 次探针以 1−δ 概率找到一个边界点。故在边界低维、可安全探测的假设下，主动采集对维度的依赖是多项式 d_b，而被动标称采集可能对 d 指数。证明：被动界由壳层概率与 union bound；主动界由光滑流形上的网格/二分搜索与 Hoeffding 置信界。∎

**引理 110（中立元退化等价 v11）** 将定义 579 的三个中立元分别注入 DGSI/WCC/CDAC 端口，则：DGSI 不再产生新技能，WCC 的证书恒真且 β(x)≡β_v11，CDAC 退回 v11 被动课程；主闭环的候选技能集、证书判据、规划评分与调用序列逐位等于 v11。证明：逐端口代入；三端口互不相交，代入后可交换至调度顺序；WCC 中立时 DGSI 只能提交被 v11 包络覆盖的技能，故执行集不增；再由 v11 引理 102 继续退回 v10/v9/v8/v7/v6。∎

**引理 111（六重证书合取安全继承）** v12 执行管线为（六重 = 物理/接触/谐波/见证/规范/因果）
```
物理证书 ∧ 接触证书 ∧ 谐波证书 ∧ 见证覆盖证书 → 规范盾 → 因果评分 → 块守卫
```
DGSI 只能提出候选技能，WCC 只能收缩包络/删除中止点/拒绝，CDAC 只能建议采集动作；三者都不能扩张 v11 的执行集。对 v11 技能子集，Ĉ_w 在 WCC 中立时恒真、在 WCC 激活时最多收缩，故执行集 ⊆ v11 安全集；对 DGSI 新技能，引理 104–106 覆盖见证与覆盖条件，v11 引理 97–101 覆盖谐波/接触/规范/因果。因此不存在绕过任何 v11 适用证书的执行路径，v11 引理 101 的安全继承在 v11 子集上继续成立。∎

**引理 112（预算守恒 v12）** 新增成本上界：DGSI 完全离线/异步，不占决策预算；WCC 在 5Hz 规划路径上使用 \|C_π\|≤512 的核心集，单技能查询 O(\|C_π\|·d_W)，≤0.2ms，独立性审计按计划缓存 O(1)；CDAC 以 ≤1Hz 异步运行，后验采样 64、动作≤32，摊销 ≤4ms 且不进入 50Hz 关键路径；见证账本追加 O(1)。v11 继承路径 ≤11ms。静态 EDF 校验后，决策侧典型 ≤11.5ms、p99 ≤22ms，50Hz 保持。若 WCC 在某个 tick 无法在预算内完成，则**该 tick 自动退回 v11 固定 β**（deadline-aware fallback），而不是丢拍或使用过期覆盖证书。证明：逐项代入复杂度表并做 EDF 校验；回退分支保证最坏执行时间不超过 v11。∎

## 8. 已知风险与失效模式

1. **证书度量错配**：d_W 若按感知相似度而非证书灵敏度构造，会把"看起来像"当成"见证充分"，导致假覆盖。缓解：用证书分量 Lipschitz 常数加权的度量；对 L̂_c 做对抗验证；把模式/相位/力/谐波状态纳入度量；E611/E619 门禁。
2. **共形可交换性被破坏**：操作者、物体、日期、工况漂移使 calib 与部署不可交换，边缘覆盖界失效。缓解：分层/加权共形；在线重校准；检测漂移则收紧 r_α 或退回 v11 固定 β；把不可交换性显式记入账本。
3. **合规反辨识病态**：演示激励不足时 K_p/K_d/f_ref 多解，集合值直径过大。缓解：保留集合值而非点估计；用主动探针/扫频补激励；强先验正则；直径超限则该段只用 v11 固定 β。
4. **provenance 泄漏**：同一物体实例/工厂/操作者习惯导致"独立"切分仍共享偏差；仿真数据被误当独立见证。缓解：保守 K_crit=全属性；外部审计集；仿真只作先验；账本标记 reused/independent=false；E613 对抗泄漏测试。
5. **采集的 Goodhart 行为**：CDAC 只选"容易让证书变漂亮"的样本，忽略真正危险方向。缓解：预注册覆盖度量；独立审计集；对抗/红队采样；对 CV 代理做校准；把"最坏方向"纳入奖励。
6. **物理探针风险与人类疲劳**：探针扰动任务、近失败演示难获得、操作者疲劳导致演示质量下降。缓解：嵌套盾 + 微幅/短时探针；仿真优先；批量请求与界面优化；设置人类预算与休息策略；E617/E618 门禁。
7. **覆盖收缩导致可行集清空**：过保守的 r_max/α/L_max 使所有新技能被拒，系统退回 v11 甚至无解。缓解：分层 α；局部图表收缩而非全局；HATD 细化粒度；覆盖洞触发采集；a_ask 兜底；任务级松弛。
8. **账本/证书实现漏洞**：provenance 记录不全、哈希碰撞、缓存过期、退化分支残留状态，导致 Level-3 不逐位等价 v11。缓解：内容寻址 + 不可变日志；端口冻结接口；CI 做 diff=0 退化测试；证书带模型版本与时间戳；deadline fallback 强制清空覆盖缓存。

## 9. 本轮最大风险

**一句话**：演示与采集数据在接触相变、滑移临界与近共振边界上天然稀疏，若见证覆盖用错了任务相关度量、把"看起来相似"当成"见证充分"，系统就会在最需要证据的地方得到最自信的假覆盖——**数据很多、见证很少、证书仍然自洽**。
