# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC / IP-153~160；灵感循环第 7 轮；本轮灵感：「能耗优化」×「数据配比」）

> 第 60 轮把「执行层→证据层」闭环升级为「认知驱动的场景-执行闭环」：SSM 用场景-阻抗先验提前收窄 K_safe，CIEC 用意图锁定实时约束，EPIR 用序列号+哈希保障 ROS 消息丢失下的证据链，SERC 把三者串成闭环，PCE++++ 引入四维认知预算。但**四个与能量和数据来源有关的根本局限**仍未解决：
> 1. **能量只是隐变量**：第 59~60 轮的能耗仅以 B_exec 中的 thermal_slack / bus_slack 形式间接出现，阻抗编译 EIC/EEIS 只优化「安全 + 轨迹误差」，高 K_d 带来的铜损、发热和电池消耗没有进入目标函数；「安全但费电」的 K 与「省电但临界安全」的 K 无法被显式比较。
> 2. **数据配比完全未受控**：SSM 的场景先验 π_scene(K|z) 与 CIEC 的意图映射 ϕ_intent→constraint 隐含依赖训练数据，但真实执行、仿真、历史回放、人机对话、跨模态迁移五类数据的混合比例 ρ 从未被定义，更没有和采集/传输能耗挂钩；域偏移会让「场景先验」和「意图理解」同时系统性偏置。
> 3. **预算是计数预算而非能量预算**：PCE++++ 的 B_scene/B_intent/B_ros/B_exec 统计的是操作次数、时延、重传次数，而探针、推理、ROS 回传真正消耗的是焦耳；「多探一次」与「多发一条 EV-exec」之间缺少统一的能量通货。
> 4. **证据采集没有能量取舍**：EPIR 的影子副本默认持久化最近 N=100 条 EV-exec 并增量上云，但原始证据、摘要证据、仅哈希证据的传输能耗相差一个数量级；在能量紧张时，如何选择「哪条证据值得花焦耳」尚未定义。

## 0. 直觉与动机

**灵感 1（能耗优化 → 能量语义账本 ESM 与能量-阻抗联合编译 EIC）**
直觉：**能耗不是执行结束后的账单，而是阻抗参数的先验价格**。同一段轨迹下，阻抗控制律 τ = Jᵀ[K_p(x_d−x) + K_d(ẋ_d−ẋ)] + g(q) 中的增益越高，关节力矩越大，铜损 P_cu = Σ_i R_i τ_i²/k_t,i² 随增益近似平方增长；高 K_d 买到的是稳定性和抗扰，付出的却是发热和电池。关键洞见：把能量分解为机械功、铜损、静态损耗、计算、通信、感知、探针七本账，令阻抗编译在「安全集 ∩ 能量集」内求解，并用能量证书 J_energy 让「每焦耳安全裕度」成为可比较、可审计的指标。

**灵感 2（数据配比 → 数据配方 DMR 与配比驱动学习 DML）**
直觉：**数据配比不是训练细节，而是能量-精度的旋钮**。真实执行数据质量最高但采集最贵，仿真数据近乎免费却有域偏移，历史回放几乎零成本但会强化旧偏差，人机对话数据稀疏却直接携带意图监督，跨模态迁移数据居中。把五类来源的配比 ρ = (ρ_real, ρ_sim, ρ_hist, ρ_dialog, ρ_cross) 放在单纯形上，每个来源有「质量 q_i、域偏移 D_i、能量单价 c_i」三属性；配比既决定 SSM/CIEC 的泛化，也直接决定数据采集与传输的能量账单。关键洞见：**配比必须带覆盖下界 ρ_i ≥ ρ_min**，否则优化器会把预算全压到最便宜的来源，造成「省电但场景崩溃」的源坍缩。

**灵感 3（两灵感耦合 → 能量-数据帕累托 EDP）**
直觉：**数据有能量价格，能量有数据价值**。多采一条真实数据、多回传一条原始证据，都能降低场景/意图的不确定性，但都要花焦耳。定义「每焦耳信息价值」η_I = EVOI/E_data：在能量预算 E_max 下选择帕累托前沿上的工作点，等价于令「数据效用对能量的边际替代率」等于能量的影子价格 λ_E。关键洞见：**能量优化不是一味省电，而是在安全/证据完整性硬约束下，用最小焦耳换取最大认知增益**。

**灵感 4（证据形态配比 → 能量高效证据采集 EEAS）**
直觉：**证据不是越多越好，而是每焦耳最优**。原始 EV-exec、摘要 EV-exec、仅哈希+边端影子副本，是三种「证据数据配比」。当 ROS 链路能量紧张时，优先回传「能闭合因果缺口、且降低场景/意图不确定性最大」的证据；把证据选择建模为带能量约束的子模背包，贪心即可获得 (1−1/e) 近似。关键洞见：**证据链完整性可以完全在边端保证，云端只需收到足够重建因果图的摘要**，从而把通信能量压到最低。

**灵感 5（合流 → 能量-数据协同闭环 EDCL 与 PCE+++++）**
直觉：能量账本 ESM 告诉系统「还剩多少焦耳」，数据配方 DMR 在剩余焦耳下决定「学什么、学多少」，配比学习 DML 更新 SSM/CIEC，能量-阻抗编译 EIC 在安全集内选「最省电的 K」，EEAS 在回传时选「最值钱的证据」，EDP 用执行结果更新帕累托前沿。形成闭环：**能量预算 → 数据配方 → 场景/意图质量 → 阻抗选择 → 执行能耗 → 证据回传 → 能量账本**——这就是「以焦耳为通货的认知-执行闭环」。

**灵感 6（联合证书 → J_joint 三维审计）**
直觉：第 59 轮的 J_exec 证明「执行合规」，第 61 轮还需证明「能量合规」和「数据来源合规」。把 J_joint = (J_exec, J_energy, J_data) 作为一次任务的三联证书：J_exec 记录 K_safe/EV-exec，J_energy 记录能量分解与峰值功率，J_data 记录本次学习/证据所用的配比 ρ 及来源哈希。关键洞见：**没有数据来源与能量账本的可审计性，「省电」和「学到了正确东西」都无法被第三方复现**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（能量语义模型 ESM）** 一次执行任务在时域 [0,T] 上的能量账本为
E_total = E_mech + E_cu + E_static + E_comp + E_comm + E_sense + E_probe，
其中：
- **机械功**：E_mech = ∫₀ᵀ Σ_i τ_i(t) q̇_i(t) dt（回馈制动为负，按带符号计入）
- **铜损**：E_cu = ∫₀ᵀ Σ_i (R_i / k_t,i²) τ_i(t)² dt
- **静态/计算/通信/感知/探针**：E_static = ∫ P_static dt，E_comp = ∫ P_comp(u_comp) dt，E_comm = Σ_m (α·bytes_m + β)，E_sense = Σ_s e_sense(s)，E_probe = Σ_p e_probe(p)
- **能量残差**：r_E = E_total − Σ_components；账本有效当且仅当 |r_E|/E_total ≤ ε_E
- **能量证书**：J_energy = (E_total, breakdown, P_peak, ∫T_thermal dt, timestamp, src_hash)，可被 EPIR 与 J_exec 一起审计

**定义 162（数据配方 DMR）** 数据源集合 S = {real, sim, hist, dialog, cross}，配比 ρ ∈ Δ⁴ = {ρ ≥ 0, Σρ_i = 1}，并施加覆盖下界 ρ_i ≥ ρ_min。每个源 i 有三元属性 (q_i, D_i, c_i)：
- **质量** q_i ∈ [0,1]（监督信噪比、标注可靠性）
- **域偏移** D_i = d_MMD(P_i, P_target)（与目标部署分布的 MMD 距离）
- **能量单价** c_i（采集/传输一单位样本的焦耳数）
数据配比效用与数据能量成本为
U(ρ) = Σ_i ρ_i q_i − γ Σ_i ρ_i D_i − η / ESS(ρ)，  C_data(ρ) = Σ_i ρ_i c_i，
其中 ESS(ρ) = 1/Σ_i ρ_i² 为有效样本量，η/ESS 惩罚「配比过度集中」。训练配比记 ρ_learn，证据形态配比记 ρ_evid = (raw, summary, hash)。

**定义 163（能量-数据帕累托 EDP）** 工作点 p = (ρ_learn, K, ρ_evid)。称 p 支配 p'（记 p ≻ p'）当且仅当 U(p) ≥ U(p')、E_total(p) ≤ E_total(p')、Risk(p) ≤ Risk(p') 且至少一项严格。可行集
P_feas = {p | SIC_valid(K), E_total(p) ≤ E_max, P_peak ≤ P_max, chain_completeness(p) ≥ 1−δ_ev}，
能量-数据帕累托前沿 P* = {p ∈ P_feas | ∄ p' ∈ P_feas, p' ≻ p}。
信息能量效率定义为 η_I(p) = EVOI(p) / E_data(p)，其中 EVOI(p) = U(ρ_learn) − U(ρ_0)。工作点选择规则：
```
p* = argmax_{p∈P*} η_I(p)            # 能效优先
     s.t. EVOI(p) ≥ EVOI_req,        # 认知增益下界
          SIC_valid, chain_completeness ≥ 1−δ_ev
```
若存在多个点，选安全裕度最大者；**安全与证据完整性是硬约束，能量只是次级目标**。

**定义 164（能量感知实时契约 E-ERTC）** 能量契约 C_E = (E_remaining, P_peak, P_avg, T_thermal, τ_deadline, reserve_ratio)。任务 a 的准入条件为
E_pred(a) + reserve·E_max ≤ E_remaining ∧ P_pred(a) ≤ P_peak ∧ T_pred(a) ≤ T_thermal。
任务优先级为字典序：**安全关键 > CIEC 意图锁定 > 证据完整性关键 > 能量 > 学习/探针 > 机会任务**；当 E_remaining 低于 reserve 时，系统进入省电模式：关闭非必要探针、降低学习频率、阻抗回退保守解，但**绝不为了省电而突破 K_safe 或释放 CIEC 的意图锁定**。实时可行契约域为 C_rt ∩ C_E。

**定义 165（能量-阻抗联合编译 EIC）** 给定能量配额 e_alloc 与安全集 K_safe、SIC 有效集：
```
K* = argmin_{K ∈ K_safe ∩ K_SIC ∩ K_E} J_EIC(K)
J_EIC(K) = λ_s·Risk(K) + λ_t·TrajErr(K) + λ_e·E_imp(K)/e_alloc
E_imp(K) = E_mech(K) + E_cu(K) + E_static
K_E = {K | E_imp(K) + E_comp(K) ≤ e_alloc}
```
性质：固定轨迹与 K_p 时，E_cu(K_d) 是 K_d 的凸二次函数，故 K_E 在 K_d 方向为凸下水平集；K_p 与 K_d 同时变化时一般非凸，采用投影梯度或帕累托采样求解。编译产物附 J_energy。

**定义 166（配比驱动学习 DML）** 以配比 ρ 训练 SSM/CIEC 的混合经验风险为
L(θ; ρ) = Σ_s w_s · E_{x∼D_s}[ℓ(θ; x)] + Ω(θ)，  w_s = clip(ρ_s / ρ_s⁰, w_min, w_max)，
其中 ρ_s⁰ 为自然采样率，w_s 为重要性权重；裁剪上界控制方差。场景先验的增量更新为
π_scene^{t+1}(K|z) ∝ π_scene^t(K|z) · exp(−Σ_s w_s ℓ_s(K; z))，
意图映射 ϕ_intent→constraint 的校准误差满足（以概率 1−δ）
Gap_mix ≤ Σ_s ρ_s D_s + sqrt(Σ_s ρ_s² σ_s² / (2n)) + sqrt(log(1/δ)/(2n))，
其中 σ_s 为源内损失方差。该界说明：**域偏移项 Σρ_s D_s 是配比必须显式惩罚的根因**。

**定义 167（能量高效证据采集 EEAS）** 证据池 E = {e_j}，每条证据有认知价值 v_j（对场景/意图不确定性的降低 + 对因果缺口 seq_gap 的覆盖）与能量成本 w_j = w_persist + w_transmit(ρ_evid)。选择问题为
```
max_x Σ_j x_j v_j
s.t.  Σ_j x_j w_j ≤ E_evid,  x_j ∈ {0,1}
```
v(·) 对同区域/同时间窗证据具有递减回报，故为子模函数；贪心选择满足 (1−1/e) 近似。证据形态按「价值/焦耳」择优：若 v_raw/w_raw ≥ v_summary/w_summary 则发原始，否则发摘要，最差仅发哈希并保留边端影子副本。因果完整性约束：任何 seq_gap 未闭合时，相关证据的优先级置为 +∞。

**定义 168（能量-数据协同闭环 EDCL 与 PCE+++++）** 五维（扩展为六维）协同预算
B_ed = (B_energy, B_data, B_scene, B_intent, B_ros, B_exec)，
其中 B_energy = (E_remaining, P_peak, thermal_headroom)，B_data = (data_collection_energy, memory, annotation_budget)，其余沿用第 60 轮。闭环算子：
```
① ESM.account(telemetry) → E_breakdown, E_remaining
② E-ERTC.update(E_remaining, P_peak)；若进入省电模式则设置 fallback 标志
③ DMR.optimize(E_remaining, uncertainty) → ρ_learn*, ρ_evid*
④ DML.update(SSM, CIEC; ρ_learn*)（仅在 B_data 未耗尽时）
⑤ EIC.compile(K; e_alloc=E_remaining/tasks_left) → K*, J_energy（安全/意图锁定优先）
⑥ CIEC.lock_intents(); Execute: telemetry ← wait_contact()
⑦ ESM.audit(telemetry) → r_E；E-ERTC.reconcile
⑧ EEAS.select(evidence; E_evid) → EPIR.append/push；附 J_data
⑨ EDP.update(P*, (ρ*, K*, E_total, U, chain_completeness))
⑩ 若 B_energy < θ_E：省电模式；若 B_data < θ_D：只用 hist/sim 且加域偏移护栏；
   若 B_scene/B_intent 耗尽：第 60 轮回退；若 B_ros 异常：本地闭环
⑪ Return: (K*, E_breakdown, EV-exec, J_joint, P*.status)
```
**PCE+++++ VOI 扩展**：
```
voi_ed(π) = VOI_meta_pessimistic(π) − λ_E·E_total(π) − λ_D·C_data(ρ) − λ_R·Risk(π)
```
能量耗尽的降级顺序固定为：探针 → 学习 → 原始证据 → 摘要证据 → 哈希证据；**安全证书 J_exec 与证据链完整性永不被降级**。

### IP-161 ESM（能量语义账本）

```python
class EnergySemanticModel:
    def __init__(self, R, kt, k_mech=1.0):
        self.R, self.kt = R, kt
        self.E = {k: 0.0 for k in
                  ['mech', 'cu', 'static', 'comp', 'comm', 'sense', 'probe']}
        self.P_peak = 0.0
        self.thermal_integral = 0.0

    def accumulate(self, tau, qdot, dt, P_comp=0.0, P_sense=0.0, E_probe=0.0):
        self.E['mech'] += float(np.sum(tau * qdot) * dt)
        self.E['cu'] += float(np.sum(self.R * tau**2 / self.kt**2) * dt)
        self.E['comp'] += P_comp * dt
        self.E['sense'] += P_sense * dt
        self.E['probe'] += E_probe
        P_now = abs(sum(tau * qdot)) + float(np.sum(self.R * tau**2 / self.kt**2))
        self.P_peak = max(self.P_peak, P_now + P_comp + P_sense)

    def account(self, P_static=0.0, E_comm=0.0):
        self.E['static'] += P_static
        self.E['comm'] += E_comm
        E_total = sum(self.E.values())
        residual = 0.0  # 由功率表实测总能量回填后计算
        return E_total, dict(self.E), residual

    def certificate(self, measured_total, src_hash):
        E_total, breakdown, _ = self.account()
        r_E = abs(measured_total - E_total) / max(measured_total, 1e-9)
        assert r_E <= 0.05, 'energy ledger invalid'
        return {'E_total': E_total, 'breakdown': breakdown,
                'P_peak': self.P_peak, 'residual': r_E, 'src_hash': src_hash}
```

### IP-162 EDP（能量-数据配方优化）

```python
class DataRecipeOptimizer:
    def __init__(self, q, D, c, rho_min=0.1, gamma=0.5, eta=0.02):
        self.q, self.D, self.c = np.array(q), np.array(D), np.array(c)
        self.rho_min, self.gamma, self.eta = rho_min, gamma, eta

    def utility(self, rho):
        ess = 1.0 / np.sum(rho ** 2)
        return float(np.sum(rho * (self.q - self.gamma * self.D)) - self.eta / ess)

    def cost(self, rho):
        return float(np.sum(rho * self.c))

    def optimize(self, E_budget, U_req):
        best = None
        n = len(self.q)
        for rho in simplex_grid(n, step=0.02, lower=self.rho_min):
            U, C = self.utility(rho), self.cost(rho)
            if C > E_budget or U < U_req:
                continue
            key = (C, -U)
            if best is None or key < best[0]:
                best = (key, rho.copy(), U, C)
        return None if best is None else {
            'rho': best[1], 'U': best[2], 'C_data': best[3],
            'eta_I': best[2] / max(best[3], 1e-9)}
```

### IP-164/165 E-ERTC 与 EIC（能量契约 + 能量-阻抗编译）

```python
class EnergyAwareERTC:
    PRIORITY = ['safety', 'intent_lock', 'evidence_chain', 'energy',
                'learning', 'opportunistic']

    def __init__(self, E_max, P_peak, T_thermal, reserve_ratio=0.15):
        self.E_remaining, self.P_peak = E_max, P_peak
        self.T_thermal, self.reserve = T_thermal, reserve_ratio
        self.locked = set()

    def admit(self, task):
        if task.priority == 'safety' or task.priority == 'intent_lock':
            return True
        if self.locked and task.priority != 'intent_lock':
            return False
        need = task.E_pred + self.reserve * self.E_remaining
        ok = (need <= self.E_remaining and task.P_pred <= self.P_peak
              and task.T_pred <= self.T_thermal)
        if ok and task.priority not in ('evidence_chain', 'energy'):
            self.E_remaining -= task.E_pred
        return ok

def compile_energy_impedance(eeis, K_safe, e_alloc, lambda_s=1.0,
                             lambda_t=0.2, lambda_e=0.5):
    best = None
    for K in eeis.pareto_candidates(K_safe):
        E_imp = eeis.predict_energy(K)
        if E_imp > e_alloc:
            continue
        J = lambda_s * eeis.risk(K) + lambda_t * eeis.traj_err(K) \
            + lambda_e * E_imp / max(e_alloc, 1e-9)
        if best is None or J < best[0]:
            best = (J, K, E_imp)
    return None if best is None else {'K': best[1], 'J_EIC': best[0],
                                      'E_imp': best[2]}
```

### IP-167 EEAS（能量高效证据采集）

```python
class EnergyEfficientEvidenceAcquisition:
    def __init__(self, E_evid):
        self.E_evid = E_evid

    def value(self, e, covered):
        base = e['uncertainty_gain'] + 10.0 * e['seq_gap_coverage']
        overlap = sum(1 for c in covered if c == e['region'])
        return base / (1.0 + overlap)          # 子模递减回报

    def select(self, pool):
        chosen, covered, spent = [], [], 0.0
        # 因果缺口未闭合的证据先强制入队
        forced = [e for e in pool if e['seq_gap_coverage'] > 0]
        for e in forced:
            chosen.append(e); spent += e['w_raw']; covered.append(e['region'])
        while True:
            cand = [e for e in pool if e not in chosen
                    and spent + self.cost(e) <= self.E_evid]
            if not cand:
                break
            e = max(cand, key=lambda x: self.value(x, covered) / self.cost(x))
            chosen.append(e); spent += self.cost(e); covered.append(e['region'])
        return chosen, spent

    def cost(self, e):
        return min(e['w_raw'], e['w_summary'], e['w_hash'])
```

**正确性定理（EDCL）**：假设
- (A66) 能量账本误差 |r_E|/E_total ≤ ε_E；

- (A70) 证据价值函数子模，EEAS 覆盖所有 seq_gap，链完整性 ≥ 1−δ_ev；

1. **能量可行性**：EIC 输出的 K* 满足 E_imp(K*) ≤ e_alloc + ε_E·E_max，且 K* ∈ K_safe；能量优化不降低安全约束。

### IP-161 ESM（七本能量账）

```python
class EnergySemanticModel:
    KEYS = ['mech', 'cu', 'static', 'comp', 'comm', 'sense', 'probe']

    def __init__(self, R, kt):
        self.R, self.kt = np.asarray(R), np.asarray(kt)
        self.E = {k: 0.0 for k in self.KEYS}
        self.P_peak, self.thermal_integral = 0.0, 0.0

    def accumulate(self, tau, qdot, dt, P_comp=0.0, P_sense=0.0, E_probe=0.0):
        P_mech = float(np.sum(tau * qdot))
        P_cu = float(np.sum(self.R * tau**2 / self.kt**2))
        self.E['mech'] += P_mech * dt
        self.E['cu'] += P_cu * dt
        self.E['comp'] += P_comp * dt
        self.E['sense'] += P_sense * dt
        self.E['probe'] += E_probe
        self.P_peak = max(self.P_peak, abs(P_mech) + P_cu + P_comp + P_sense)

    def certificate(self, measured_total, P_static, E_comm, src_hash):
        self.E['static'] += P_static
        self.E['comm'] += E_comm
        total = sum(self.E.values())
        residual = abs(measured_total - total) / max(measured_total, 1e-9)
        assert residual <= 0.05, 'energy ledger invalid'
        return {'E_total': total, 'breakdown': dict(self.E),
                'P_peak': self.P_peak, 'residual': residual,
                'src_hash': src_hash}
```

### IP-164/165 E-ERTC + EIC（能量契约 + 能量-阻抗编译）

```python
class EnergyAwareERTC:
    ORDER = ['safety', 'intent_lock', 'evidence_chain', 'energy',
             'learning', 'opportunistic']

    def __init__(self, E_max, P_peak, T_thermal, reserve_ratio=0.15):
        self.E_remaining, self.P_peak = E_max, P_peak
        self.T_thermal, self.reserve = T_thermal, reserve_ratio
        self.mode, self.locked = 'normal', set()

    def admit(self, task):
        if task.priority in ('safety', 'intent_lock'):
            return True
        if self.mode == 'power_save' and task.priority not in ('evidence_chain',):
            return False
        ok = (task.E_pred + self.reserve * self.E_remaining <= self.E_remaining
              and task.P_pred <= self.P_peak and task.T_pred <= self.T_thermal)
        if ok:
            self.E_remaining -= task.E_pred
        return ok

def compile_energy_impedance(eeis, K_safe, e_alloc,
                             lambda_s=1.0, lambda_t=0.2, lambda_e=0.5):
    best = None
    for K in eeis.pareto_candidates(K_safe):
        E_imp = eeis.predict_energy(K)
        if E_imp > e_alloc:
            continue
        J = (lambda_s * eeis.risk(K) + lambda_t * eeis.traj_err(K)
             + lambda_e * E_imp / max(e_alloc, 1e-9))
        if best is None or J < best[0]:
            best = (J, K, E_imp)
    return None if best is None else {'K': best[1], 'J_EIC': best[0],
                                      'E_imp': best[2], 'e_alloc': e_alloc}
```

### IP-166 DML（配比驱动学习）

```python
class DataMixtureLearner:
    def __init__(self, sources, rho0, w_min=0.2, w_max=5.0):
        self.sources, self.rho0 = sources, np.asarray(rho0)
        self.w_min, self.w_max = w_min, w_max

    def weights(self, rho):
        return np.clip(rho / self.rho0, self.w_min, self.w_max)

    def update_scene_prior(self, ssm, rho, likelihoods):
        w = self.weights(rho)
        logp = np.log(np.clip(ssm.scene_prior, 1e-12, None))
        logp -= sum(wi * li for wi, li in zip(w, likelihoods))
        ssm.scene_prior = np.exp(logp - logp.max())
        ssm.scene_prior /= ssm.scene_prior.sum()
        return ssm.scene_prior

    def generalization_bound(self, rho, sigma, n, delta):
        domain = float(np.sum(rho * self.sources.domain_gap))
        var = float(np.sqrt(np.sum(rho**2 * np.asarray(sigma)**2) / (2 * n)))
        return domain + var + np.sqrt(np.log(1 / delta) / (2 * n))
```

### IP-167 EEAS（能量高效证据采集）

```python
class EnergyEfficientEvidenceAcquisition:
    def __init__(self, E_evid):
        self.E_evid = E_evid

    def cost(self, e):
        return min(e['w_raw'], e['w_summary'], e['w_hash'])

    def value(self, e, covered):
        base = e['uncertainty_gain'] + 10.0 * e['seq_gap_coverage']
        return base / (1.0 + sum(1 for r in covered if r == e['region']))

    def select(self, pool):
        chosen, covered, spent = [], [], 0.0
        for e in [x for x in pool if x['seq_gap_coverage'] > 0]:
            chosen.append(e); covered.append(e['region'])
            spent += self.cost(e)
        while True:
            cand = [e for e in pool if e not in chosen
                    and spent + self.cost(e) <= self.E_evid]
            if not cand:
                break
            e = max(cand, key=lambda x: self.value(x, covered) / self.cost(x))
            chosen.append(e); covered.append(e['region']); spent += self.cost(e)
        for e in chosen:
            per = {k: e['value'] / max(e[f'w_{k}'], 1e-9)
                   for k in ('raw', 'summary', 'hash')}
            e['form'] = max(per, key=per.get)
        return chosen, spent
```

## 3. 推导与说明性示例

### 3.1 能量-阻抗的二次关系

单关节、阻尼主导、参考轨迹 e(t)=A sin ωt（ė=Aω cos ωt）时，τ ≈ Jᵀ K_d ė = K_d Aω cos ωt，因此
```
E_cu = (R/k_t²) ∫ τ² dt = (R/k_t²) K_d² A² ω² · T/2  ∝  K_d²
```
若 E_cu 占总能耗比例为 s，K_d 下调 30%，则铜损降至 0.49 倍，总能耗降幅为 s·51%。当 s=0.5 时总能耗 −25.5%，恰好覆盖 E194 的 −25% 目标；当 s=0.3 时仅 −15.3%，说明**必须同时优化轨迹/机械功，不能只调 K_d**。这也解释了为什么 EIC 要把 E_mech 与 E_cu 分开记账。

| K_d 缩放 | E_cu 缩放 | s=0.3 时总能耗降幅 | s=0.5 时总能耗降幅 |
|---|---|---|---|
| 1.00 | 1.00 | 0% | 0% |
| 0.90 | 0.81 | 5.7% | 9.5% |
| 0.80 | 0.64 | 10.8% | 18.0% |
| 0.70 | 0.49 | 15.3% | 25.5% |
| 0.60 | 0.36 | 19.2% | 32.0% |

| ESM | O(n_joint)/周期 | O(1) | 残差 ≤ 5%，前 3 能耗源可定位 |
| DMR/EDP | 离线 O(\|Δ⁴\|/δ²)，在线 O(1) | O(\|P*\|) | 覆盖下界保持，工作点非支配 |
| E-ERTC | O(1)/任务 | O(1) | 安全/意图锁定不被能量抢占 |

| DML | O(n·d) | O(d) | Gap ≤ ΣρD + O(1/√n) |
| EEAS | O(\|E\|²) 贪心 | O(\|E\|) | (1−1/e) 近似，seq_gap 全覆盖 |

**正确性定理（EDCL）**：若 A66–A70 成立，则
1. 能量可行性：EIC 的 K* 满足 E_imp(K*) ≤ e_alloc + ε_E·E_max 且 K* ∈ K_safe；
2. 配比泛化性：U(ρ*) ≥ (1−δ_mix)·U*，且源覆盖下界保持；
3. 证据最优性：EEAS 证据价值 ≥ (1−1/e)·OPT，链完整性 ≥ 1−δ_ev；
4. 闭环改进性：在 SIC_valid 与 τ_response 约束不变时，单位成功任务能耗不高于 SGEC 基线。

**证明要点**：由 EIC 可行域投影、E-ERTC 准入不变式、重要性加权泛化界、子模背包贪心定理、以及 EDP 每轮取非支配点并最小化 E_total 直接得到。关键前置条件是 **安全/意图/证据完整性三项硬约束的字典序优先于能量**，否则第 4 条不成立。

## 6. 本轮最大风险

**一句话**：若能量账本低估铜损/热积累，且数据配比低估仿真-真实域偏移，则「能量最优 + 配比最省」的工作点可能同时是「安全临界 + 场景先验偏置」的——省下的每一焦耳都可能以一次未被察觉的 K_safe 越界或系统性误判为代价；必须以「在线能量残差监测 + ρ_min 覆盖下界 + 域偏移估计上界 + 安全/意图锁定字典序优先 + 帕累托前沿人工复核」五重护栏确保能量与数据优化永远服从安全与证据完整性。
