# 第 17 轮（研究线累计；本轮灵感循环第 3 轮）· SKILL-ISAC-ZEST：从「技能学习」「Isaac Sim」「交互设计」出发，在 SCALABLE-ZEST 基础上构建技能感知残差、模拟优先技能学习与人机协同校准

## 0. 先给直觉：为什么 SCALABLE-ZEST 在技能层面仍会遇到瓶颈

第 16 轮的 SCALABLE-ZEST 把残差计算分布式、权重动态化、置信软化。但它仍把 VLA 当作黑盒单策略：`r_b` 是全局聚合，`γ_b` 是节点级单值。62 节点团队赛中出现的问题是：

> **技能学习**：不同任务阶段使用不同技能原语（如 `REACH, PICK, SERVO, INSERT`），残差分布条件于技能。全局 DRAW 把 `r_geo` 在 `REACH` 和 `INSERT` 上的差异抹平，导致 OOD 检测在技能切换点失真。

> **Isaac Sim**：我们缺乏在真实机器人冒险前验证残差阈值的闭环。`q_α` 仍依赖 5 个 ID 任务的实机校准，校准成本高，且无法覆盖稀有 OOD。

> **交互设计**：软置信 `γ'_b` 仍是无监督自适应。操作员在轻微 OOD 下的「感觉不对」无法进入校准流，导致误触发/漏触发的反馈无法闭环。

一句话押注：

> **第 16 轮把胜任力软化为可分布式计算的置信；本轮把置信细化到技能粒度，用 Isaac Sim 做模拟优先的技能残差校准，并用交互设计把人类的稀疏反馈注入贝叶斯校准，形成「技能-模拟-人」的闭环。**

三个可验证创新点：

1. **技能感知残差图 Skill-Residual Graph, SRG**：把 VLA 计划映射到技能序列 `s_t ∈ S`，为每个技能维护独立残差通道 `r_k^s` 与 DRAW 权重 `w_k^s`，使 OOD 检测在技能切换点保持连续。
2. **模拟优先技能自适应 Sim-Prior Skill Adaptation, SPSA**：在 Isaac Sim 中对每个技能生成对抗性扰动 rollout，离线估计技能特定 conformal 分位数 `q_α^s` 与 MAD 归一化基准，实现零实机风险的阈值校准。
3. **交互式置信校准 Interactive Confidence Calibration, ICC**：交互设计 UI 允许操作员在 Isaac Sim 回放中对技能执行给出稀疏赞同/否决 `h_t ∈ {+1,-1}`，通过 Beta-Bernoulli 更新校准 `γ_s` 的先验，降低误切与漏切。

三个词落地：

| 词 | 落地 | 不做什么 |
|---|---|---|
| **技能学习** | SRG 技能分解、技能级 DRAW、技能级 γ_s | 不重新训练 VLA；不引入新控制通路 |
| **Isaac Sim** | SPSA 模拟 rollout、q_α^s 离线校准、技能 rehearsal | 不做全任务仿真重训练；不依赖真实数据回放 |
| **交互设计** | ICC 稀疏人类反馈 UI、贝叶斯后验更新 γ_s | 不要求持续监督；不改变 FALLBACK 几何原语 |

## 1. 研究日志：从 SCALABLE-ZEST 到 SKILL-ISAC-ZEST 的演进

### 1.1 第 16 轮留下的三个假设

```text
A1. 策略单体：残差与置信在策略级聚合，不区分技能。
A2. 实机校准：q_α、MAD 全部来自真实 ID 任务。
A3. 无监督置信：γ'_b 仅靠统计自适应，无人类反馈。
```

A1 导致技能切换时残差突变被误判为 OOD；A2 限制校准覆盖；A3 使软置信无法学习操作员的隐性偏好。

### 1.2 三个新判断

1. **残差可以按技能解耦**。VLA 计划可解析为技能标签 `s_t`（通过计划文本或动作模式聚类）。每个技能有独立的残差统计 `μ_k^s, MAD_k^s`，DRAW 在技能内更新：`w_k^s ∝ exp(-μ_k^s/τ)`。这保留了无标签假设，同时提升条件检测力。

2. **模拟可以提供先验校准**。Isaac Sim 中对每个技能施加 OOD-E/OOD-S 扰动（光照、几何、动力学），生成合成残差分布，用 conformal 方法得到 `q_α^s`。实机数据仅用于在线微调，先验由模拟提供，符合「不训练」合规。

3. **交互可以校准置信偏置**。人类在回放中给出稀疏反馈 `h_t`，视为对 `γ_s` 的观测。采用 Beta-Bernoulli 共轭更新：`α_s ← α_s + 1_{h=+1}`, `β_s ← β_s + 1_{h=-1}`，后验均值 `E[γ_s] = α_s/(α_s+β_s)` 调制软调度阈值。交互设计仅在 Isaac Sim 回放中进行，不占用实机时间。

### 1.3 与第 16 轮关系

| 层 | 第 16 轮 SCALABLE-ZEST | 第 17 轮 SKILL-ISAC-ZEST |
|---|---|---|
| 残差粒度 | 策略级 | 技能级 SRG |
| 校准来源 | 实机 5 任务 | Isaac Sim SPSA + 实机微调 |
| 置信更新 | 纯统计 | 统计 + ICC 贝叶斯人类反馈 |
| 扩展性 | DRS 分布式 | DRS 分布式 + 技能路由 |
| 安全 | 软置信 | 软置信 + 技能级 γ_s 硬下界 |

保留 DRS、DRAW、SCC 核心；升级为技能感知、在模拟中校准、交互校准。

## 2. 直觉深化：技能切换的残差连续性

技能切换点残差自然跳变。若用全局 `q_α`，切换会被误判为惊讶。SRG 的思想是：**把「不确定」锚定在技能内部**。

- 进入技能 `s` 时，加载该技能的 `q_α^s, μ_k^s`；
- 在技能内 DRAW 仅用该技能的历史 `z^{raw}_k` 更新；
- 技能退出时，将该技能的后验 `α_s, β_s` 提交到 DRS，供其他节点共享。

ICC 提供闭环：操作员在 Isaac Sim 中看到技能级 `γ_s` 下降，回放确认是否真实 OOD，稀疏标签修正先验。这样「人类经验」以统计方式注入系统，无需标注。

## 3. 形式化：SKILL-ISAC-ZEST 符号

### 3.1 技能感知残差图 SRG

技能集合 `S = {REACH, PICK, SERVO, INSERT, LOOK}`。节点 `i` 在块 `b` 执行技能 `s_b ∈ S`。

技能条件残差：

```
r_b^s = (r^{tmp}_b, r^{geo}_b, r^{goal}_b, r^{dyn}_b) | s_b = s
```

技能 DRAW 权重：

```
z^{raw}_{k,s} = r_{k,b} / (MAD_{k,s} + ε)
μ_{k,s} ← (1-η) μ_{k,s} + η z^{raw}_{k,s}
w_{k,s} = exp(-μ_{k,s}/τ) / Σ_j exp(-μ_{j,s}/τ)
s_b^s = Σ_k w_{k,s} z^{raw}_{k,s}
```

技能级惊讶：

```
e_{b}^s = 1[ s_b^s > q_α^s ]
γ_{b}^s = 1 - (1/W) Σ_{i=0}^{W-1} e_{b-i}^s
```

### 3.2 模拟优先技能自适应 SPSA

在 Isaac Sim 中对技能 `s` 生成 `M` 条 rollout，扰动参数 `δ ∈ {OOD-E, OOD-S, ID}`。

合成残差集合 `R_s^{sim}`，计算：

```
q_α^s = quantile_{1-α}( { s_b^s | sim })
MAD_{k,s} = median(|z^{raw}_{k,s} - median(z^{raw}_{k,s})|)
```

实机微调：

```
q_α^s ← (1-λ) q_α^{s,sim} + λ q_α^{s,real}
```

`λ=0.2` 控制模拟先验权重。

### 3.3 交互式置信校准 ICC

人类反馈 `h_t ∈ {+1(赞同), -1(否决)}` 在 Isaac Sim 回放中采集。

Beta 先验 `γ_s ~ Beta(α_s, β_s)`。

更新：

```
α_s ← α_s + 1_{h_t=+1}
β_s ← β_s + 1_{h_t=-1}
γ̂_s = α_s / (α_s + β_s)
```

软调度中使用校准置信：

```
γ'_ {b,s} = γ_{b}^s · γ̂_s · (1 - β·H(S_{b,s} - h))
```

## 4. 算法细节

### 4.1 主循环

```
for each block b:
    s_b = skill_parser(A_b)
    r_b = DRS_i(o_{b-1}, o_b, A_{b-1}, A_b, s_b)
    w_{k,s_b} = DRAW_s_b(r_b)
    s_b^s = Σ w_{k,s_b} z^{raw}_{k,s_b}
    e_b = 1[s_b^s > q_α^{s_b}]
    γ_b^s = update_soft_competence(e_b)
    γ'_b = γ_b^s * γ̂_{s_b} * (1 - β H(S_b - h))
    a* = argmax_a P_succ(a|γ'_b) / c_a with skill-adm set
    execute a*
    if in Isaac Sim replay:
        collect h_t from UI, update α_s, β_s
```

### 4.2 DRS 技能路由

DRS 服务按技能分片：每个技能有独立批处理队列，负载 `λ_{i,s} = 1/(τ_i C_i + B_{i,s})`。节点提交时附带 `s_b`，服务返回 `r_b^s, q_α^s, w_{k,s}`。

## 5. 性质、复杂度、正确性

### 5.1 技能级 DRAW 收敛

命题：若技能内 `z^{raw}_{k,s}` 分布稳定，`w_{k,s}` 收敛到 `exp(-E[μ_{k,s}]/τ)/Z`。

证明同第 16 轮，因技能内 Markov。

### 5.2 模拟先验校准一致性

命题：若 Sim-Reality 残差分布 Wasserstein 距离 ≤ ε，则 `|q_α^{s,real} - q_α^{s,sim}| ≤ L ε`，其中 L 为 quantile Lipschitz 常数。

证明由 conformal 分位数连续性。

### 5.3 ICC 不偏性

命题：Beta-Bernoulli 更新在人类反馈无偏时，`E[γ̂_s]` 收敛到真实技能胜任率。

证明 Beta 共轭后验一致性。

复杂度：每块 O(K + |S|) 时间，空间 O(|S| K W)。技能路由不增加网络开销。

## 6. 可验证假设

| 编号 | 假设 | 证伪条件 |
|---|---|---|
| H1 | SRG 使技能切换点误报率下降 ≥30% | 误报率 <20% 降幅 |
| H2 | SPSA 使实机校准数据需求减少 ≥60% | 需 >40% 实机数据 |
| H3 | ICC 使 ID fallback 率再降 20% | ID fallback 未降 |
| H4 | Isaac Sim 技能 rehearsal 时延 <100ms | 时延 ≥100ms |

## 7. 本轮最大的风险

**Sim-Reality Gap 导致技能级阈值偏移：如果 Isaac Sim 的物理/感知模型与真实机器人差异过大，SPSA 生成的 `q_α^s` 会系统性低估/高估真实 OOD，导致技能级 DRAW 在实机上失效，需额外实机微调来补偿。** 这需要通过域随机化和在线 λ 调整来缓解。

# 第 17 轮产物 · SKILL-ISAC-ZEST 技术报告

## 0. 结论：技能感知、模拟校准、交互闭环

SKILL-ISAC-ZEST 在 SCALABLE-ZEST 的分布式残差、动态加权、软置信基础上，引入技能粒度残差、Isaac Sim 模拟优先校准、交互式贝叶斯校准。核心不变：无训练、无标签、不改执行层。

1. **技能感知残差图 SRG**：为每个技能维护独立 DRAW 权重与 conformal 阈值，技能切换点误报下降。
2. **模拟优先技能自适应 SPSA**：Isaac Sim 生成技能扰动 rollout，离线得到 `q_α^s, MAD_{k,s}`，实机仅做微调。
3. **交互式置信校准 ICC**：操作员在 Isaac Sim 回放中稀疏反馈，Beta-Bernoulli 更新技能级先验 `γ̂_s`。

## 1. 形式化符号

- 技能集 `S`, 节点 `i`, 块 `b`, 技能 `s_b ∈ S`
- 技能条件残差 `r_b^s ∈ ℝ^4`, 原始惊讶 `z^{raw}_{k,s}= r_{k,b}/(MAD_{k,s}+ε)`
- 技能 DRAW 均值 `μ_{k,s} ← (1-η)μ_{k,s}+η z^{raw}_{k,s}`, 权重 `w_{k,s}=exp(-μ_{k,s}/τ)/Σ_j exp(-μ_{j,s}/τ)`
- 融合得分 `s_b^s= Σ_k w_{k,s} z^{raw}_{k,s}`, 惊讶指示 `e_b^s=1[s_b^s>q_α^s]`
- 软胜任力 `γ_b^s = max(0,1-(1/W)Σ e_{b-i}^s)`, CUSUM `S_{b,s}`, 校准置信 `γ̂_s = α_s/(α_s+β_s)`
- 最终软置信 `γ'_{b,s}= γ_b^s·γ̂_s·(1-β·H(S_{b,s}-h))`

## 2. 算法步骤

### 2.1 离线模拟校准 SPSA

```
for s in S:
    for p in {ID, OOD-E, OOD-S}:
        rollouts = IsaacSim.rollout(skill=s, perturbation=p, M=200)
        R_s^{sim} = compute_residuals(rollouts)
    q_α^{s,sim}= quantile_{0.9}(s_b^s)
    MAD_{k,s}= median_abs_deviation(z^{raw}_{k,s})
store q_α^{s,sim}, MAD_{k,s}
```

### 2.2 在线执行循环

```
init μ_{k,s}=0, α_s=2, β_s=2, γ̂_s=0.5
for each block b:
    s_b = skill_parser(A_b)
    r_b = DRS_i(o_{b-1},o_b,A_{b-1},A_b,s_b)
    for k in 4: z = r_{k,b}/(MAD_{k,s_b}+1e-6)
    μ_{k,s_b} ← 0.9 μ_{k,s_b}+0.1 z
    w_{k,s_b}= softmax(-μ_{k,s_b}/0.5)
    s_b^s = Σ w_{k,s_b} z
    q = (1-λ) q_α^{s_b,sim}+ λ q_α^{s_b,real}
    e = int(s_b^s > q)
    update surprise window, CUSUM S
    γ_b^s = 1 - mean(window)
    γ' = γ_b^s * γ̂_{s_b} * (1-0.3*H(S>2.5))
    A_adm = {SERVO,LOOK,VLA,COMMIT} if γ'>0.3 else {LOOK,VLA,FALLBACK,HOLD}
    a* = argmax_{a∈A_adm} P_succ(a|γ')/c_a
    execute a*
    if replay mode:
        h = UI_feedback(s_b) # +1/-1
        α_{s_b} += 1_{h=+1}; β_{s_b} += 1_{h=-1}
        γ̂_{s_b}= α/(α+β)
        DRS.broadcast(α,β)
```

### 2.3 DRS 技能路由接口

```
POST /residual/skill
{obs_before, obs_after, plan_before, plan_after, skill_id}
→ {r_tmp,r_geo,r_goal,r_dyn, q_α^s, w_{k,s}, γ̂_s}
```

## 3. 性质与正确性

### 3.1 技能 DRAW 收敛
**命题**：在技能内序列平稳时，`w_{k,s}` 收敛于 `exp(-E[μ_{k,s}]/τ)/Z`。证明与第16轮一致，指数加权平均收敛。

### 3.2 模拟先验界
**命题**：若 Sim-Reality Wasserstein 距离 ≤ ε，则 `|q_α^{s,real}-q_α^{s,sim}| ≤ L ε`。证明由 quantile Lipschitz。

### 3.3 ICC 一致性
**命题**：在人类反馈无偏时，Beta 后验均值 `γ̂_s` 一致收敛于真实技能胜任率。证明 Beta-Bernoulli 共轭一致性。

### 3.4 安全保持
**命题**：SKILL-ISAC-ZEST 动作集 ⊆ ZEST-VLA 动作集，不引入新执行通路。证明 SRG、SPSA、ICC 仅改变决策输入。
