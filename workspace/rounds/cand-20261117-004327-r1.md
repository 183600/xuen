# 第 11 轮（本轮灵感：「LoRA」×「VLA」）
> **基线**：第 10 轮 MetricVoiceGauge-LRC（定义 540–549；引理 87–93；实验 E571–E590）。
> 本轮纪律：**分解信任 + 语义接地 + 跨通道证伪**。两个灵感各治 v10 一处残债——「LoRA」治**模型信任的不可分解性**（v10 只有“整体信 / 整体不信”F̂：信则错误相关，不信则退回过松 L0 造成 K=1 性能债），「VLA」治**任务语境的缺席**（v10 证书只谈几何与力矩，不谈“这一步是否在为指令服务”，故“自信地做错事”无法被检测）。仍以中立元退化保证：语义层失效退回 v10 证书，适配器失效退回冻结主干，主干越界退回 v9 rollout，再沿 v10 七级链退到 v6。

## 0. 直觉与动机

**灵感 1（LoRA → 前向模型的“冻结主干 + 低秩域增量”）**
直觉：v10 把 F̂ 当成一个不可分的整体：要么落在信任域内（信），要么越界（退回 L0）。可 LoRA 的第一性原理不是“省参数”，而是 **任务/域带来的改变是低秩的**：W' = W + BA。搬到前向模型上，域偏移不是一个任意扰动，而是发生在一个 r 维子空间里的“修正”。于是信任也可以分解：冻结主干 F_base 承载跨域不变的动力学（可离线反复验证，误差界 β_base 稳定），低秩适配器 BA 只承载当前域的修正。关键在于三点：
（i）低秩把适配误差的样本复杂度从 O(min(n,m)) 降到 O(r_eff)（定义 552、引理 94）——陌生域只需少量数据就能给适配器一个**可信的**误差界，不必整体重训；
（ii）BA 可**精确摘除**（Detach），摘除即回到 F_base，于是“适配器不可信”不再等于“退回过松 L0”，而是退回一个**有独立界的中间层**——这正好填上 v10 造成 K=1 回退的那道缝；
（iii）多个域的适配器可**线性组合**，组合仍落在低维子空间内，故可在域后验的置信单纯形上取最坏情形，得到“对域误判鲁棒”的混合证书（定义 558、引理 96）。
核心创新：**秩可分离前向模型（Rank-Decomposable Model, RDM）** 与**可摘除适配器（Detachable Adapter, DA）**。

**灵感 2（VLA → 语义格上的任务接地与组合证书）**
直觉：v10 的证书是纯几何-力矩的：间隙够不够、力矩超没超，从不问“这一块动作是否在为当前指令服务”。VLA 的第一性原理不是“更大的端到端模型”，而是 **视觉、语言、动作被投进同一个语义潜空间 z**，于是“动作是否合乎指令”变成一个**可计算的语义残差**，长程任务变成潜空间里的**可组合格**。由此得到三件事：
（i）**语义条件证书**：在 v10 动态证书之外，增加“指令前/后置谓词”与语义残差阈值，得到“既安全又切题”的判定（定义 553/554）；
（ii）**组合证书文法**：长指令 ℓ=ℓ_1∘ℓ_2 的证书由子证书按 assume-guarantee 组合，接口是子任务间的不变式（定义 555、引理 97）——证书第一次能沿任务结构**递归地**构造，而非对整段 rollout 打一个标量分；
（iii）**独立证伪通道**：VLA 与冻结前向模型是**不同模型族**，其语义残差给出与 Δ_dom、与 RankLedger 都**不同源**的偏移信号（定义 556、引理 99）。v10 最大的病是“证书与排序来自同一个可能失配的模型”，VLA 提供了一个真正正交的怀疑者。
核心创新：**语义格接地（Semantic Lattice Grounding, SLG）** 与**三通道证书仲裁（Cross-Channel Arbitration, CCA）**。

**灵感 3（合成：秩分解 × 语义接地 → 分解信任的证书代数）**
直觉：把 LoRA 的“信任可分解”与 VLA 的“任务可分解”叠起来，证书不再是单一标量，而是一个**带类型的证明对象**：C = (C0 安全, C1 动力学可行, C2 语义切题)。三条通道各答不同问题，且尽量来自不同模型族；接受**执行**只看 C0（安全恒定以 L0 为锚），接受**任务进展**才要求 C1∧C2。于是 v10 的“虚假确定性”被拆成两个可分别审计的量：安全上的虚假 = C0 前提被破坏（除非地图/ULP 假设失效，概率为 0）；任务上的虚假 = C1 与 C2 同时错（若独立则概率相乘，见引理 98）。核心创新：**LAVA 证书代数**（Low-rank Adapted, Vision-grounded Action certificates）。

## 1. 研究问题（轮次升级版）

- **Q1（秩-误差的可证界）**：低秩适配器在域样本 n_d 下的误差界能否以有效秩 r_eff（而非 min(n,m)）为主项，并在 r_eff 退化为满秩时连续回到 v10 的全秩界？
- **Q2（可摘除退化的健全性）**：Detach 是否精确可逆、摘除后的证书界是否严格等于冻结主干的独立界 β_base，从而使“摘除”永远不劣于 v10 的 L0 回退（在健全性意义上）？
- **Q3（语义接地作为独立通道）**：语义残差 s 与 Δ_dom、与 RankLedger 的 q_i 相关性有多低？在 common-cause 失配下 s 是否仍能报警？
- **Q4（组合证书的健全性与成本）**：assume-guarantee 组合是否对任意任务分解健全且可结合，接口不变式检查能否压进 5Hz 预算？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 信任分解律（Trust Decomposition）**
前向模型必须写成“冻结主干 + 低秩适配”，任何对模型的信任必须分解为 β_base + β_adapter，且适配器可被精确摘除。禁止对不可分解的黑箱整体赋予信任。

**P17 证据独立律（Evidence Orthogonality）**
安全（C0）、动力学（C1）、语义（C2）三类证据尽量来自不同模型族 / 不同数据源；当 C1 与 C2 同源时，其联合置信不得超过单通道，且必须显式标注“非独立”。独立与否必须由实验（E599）测量，不得默认。

**P18 语义接地律（Semantic Grounding）**
任何被执行的块必须能生成一条与指令谓词对齐、且数值可被 L0 机检的声明；无法接地者只能作为“安全但未知用途”的动作执行，不得计为任务进展。

## 3. 与基线的接口（如何退化）

- 语义层失效（VLA 不可用 / 接地失败 / 语义残差不可算）⇒ 退回 v10 证书（丢 C2，仅 C0∧C1），行为 = v10；
- 适配器失效（τ_d < θ 或秩估计失败）⇒ Detach → F_base；若 β_base 未认证 ⇒ 退回 v9 全秩 rollout；
- 主干越信任域（β_base 失效）⇒ 退回 v9 F̂ rollout（= v10 的 L2）；
- 再往下沿 v10 七级链：LWC 全失效 → v9 AC；RL 失效 → v9 绝对评分；LCC 失效 → v9 运行时 EDF；AC/MW/ID 失效 → v8 → v7 → v6。
（v11 在 v10 顶部新增两级：语义重置、秩摘除；其余逐级同构，故整体退化链是 v10 的健全细化。）

## 4. 预期贡献

1. **秩可分离前向模型**：把域适应误差的样本复杂度从维度降到有效秩，并提供可摘除的中间信任层，缓解 v10 的 K=1 性能债；
2. **语义格证书代数**：证书从标量升为 (C0,C1,C2) 带类型证明，长任务按文法递归组合，接口不变式可机检；
3. **三通道仲裁**：用独立模型族的语义残差证伪，把 v10 的“虚假确定性”从单点风险拆成可审计的任务级误信率；
4. **语言可审计声明**：每个块生成可机检、可人读的声明，形成审计轨迹；
5. E591–E610 覆盖秩-误差、摘除健全、语义接地、组合、跨通道、退化与端到端。

## 5. 本轮最大风险

**一句话**：**“冻结主干 + 低秩适配”只在真实偏移确实落在适配子空间内时才成立——若域偏移含子空间外的主偏差，低秩界会把偏差当方差而给出过紧的假界；而 VLA 语义残差又可能与被测模型同源共错，于是三通道同时失效。低秩把“模型误差”重命名为“看不见的偏差”，语义接地把“相关错误”误当成“独立证据”。**

# 第 11 轮产物 · 创新点清单 v11：**MetricVoiceGauge-LAVA**（Low-rank Adapted, Vision-grounded Action certificates）

## 1. 符号体系增量（定义 550–559）

| 符号 | 含义 |
|---|---|
| F̂ = F_base + Σ_d w_d B_d A_d | 秩可分解前向模型（RDM） |
| B_d ∈ R^{n×r_d}, A_d ∈ R^{r_d×m} | 域 d 的低秩适配器（r_d ≤ r_max ≪ min(n,m)） |
| w_d, W | 域后验权重及其置信单纯形（由 DA-ML 给出） |
| τ_d | 适配器可信度 = 1 − 观测残差 / 预测残差界 |
| r_eff | 有效秩 = rank(Σ_d w_d B_d A_d) |
| β_base, β_adapter | 冻结主干误差界 / 适配器误差界（秩感知） |
| z = E(o,ℓ,a) | VLA 共享视觉-语言-动作潜空间 |
| s(ζ,ℓ,o) | 语义残差（Mahalanobis 距离和） |
| Pre_ℓ, Post_ℓ | 指令 ℓ 的接地前/后置谓词 |
| C = (C0, C1, C2) | 三通道证书（安全 / 动力学 / 语义） |
| ρ_τ | 排行榜 Kendall τ 稳定性（继承 v10 定义 548） |

**新增定义 550（秩可分解前向模型 RDM）** 域 d 的真实动力学记为 F_d，模型分解为
```
F̂(s,a; w) = F_base(s,a) + Σ_{d∈D} w_d · B_d A_d φ(s,a)
```
其中 F_base 冻结（跨域不变），B_d A_d 为秩 r_d 的域修正，φ 为有界特征，w 为域后验（Σw_d=1, w_d≥0）。误差满足
```
‖F̂ − F_d‖∞ ≤ β_base + Σ_d w_d ‖B_d A_d − Δ_d^true‖ + cross,
```
cross 项由 |w_d − w_d^true| 与适配器幅值控制。F_base 单独可认证，故“整体不可信”可分解为“主干可信 + 适配器待证”。

**新增定义 551（可摘除适配器与信任度 DA）** 适配器可信度
```
τ_d = 1 − (观测残差能量) / (β_base + β_adapter) ∈ [0,1],
```
摘除算子 Detach_d(F̂) = F̂ − w_d B_d A_d（O(1)：令 w_d ≡ 0）。可摘除性保证：所有适配器摘除后 F̂ 精确等于 F_base，且其证书界为独立认证的 β_base。秩预算 ρ_m 为模块 m 的适配器最大秩（与 v10 的层级预算 ℬ_m 正交）。

**新增定义 552（秩感知误差界）** 设域 d 有 n_d 个样本、残差次高斯（参数 σ）、适配器为秩 r 岭回归（岭系数 λ），则 w.p. 1−δ
```
‖Δ̂_d − Δ_d^true‖_F ≤ C·σ·√( r_eff · log(1/δ) / n_d ) + λ‖Δ_d^true‖_*.
```
主项以 √r_eff 而非 √min(n,m) 增长；r_eff = min(n,m) 时退化为 v10 的全秩界。这是低秩信任分解的统计依据（引理 94）。

**新增定义 553（语义格与语义残差 SLG）** VLA 编码器 E 把观测、指令、动作投进共享潜空间：
```
z_o = E_vis(o),  z_ℓ = E_lang(ℓ),  z_a = E_act(ζ) ∈ R^p,
s(ζ,ℓ,o) = ‖z_a − z_ℓ‖_{M} + ‖z_o − z_ℓ‖_{M},
```
M 为协方差白化矩阵。指令分解为子任务格 ℓ = ℓ_1 ⊔ … ⊔ ℓ_n，每个节点带前/后置谓词 (Pre_ℓ, Post_ℓ) 与接口状态。

**新增定义 554（语义条件证书）** 块 ζ 的证书有效 ⇔
```
(C0) L0 硬界通过（v10 定义 541，确定性）
(C1) G^(ℓ) ≥ d_safe ∧ E^(ℓ) ≤ τ_eff（v10 定义 540）
(C2) s(ζ,ℓ,o) < τ_sem ∧ Pre_ℓ(s_0) ∧ Post_ℓ(s_K)
```
并发出声明 Claim_ℓ（数值槽由 C0/C1 填入）。C0 只保证安全，C1 保证动力学可达，C2 保证语义切题——三者是**不同命题**，不得压成一个标量。

**新增定义 555（组合证书文法）** 对 ℓ = ℓ_1 ∘ ℓ_2，若存在接口状态 s_1 使
```
Post_{ℓ_1} ⊆ Pre_{ℓ_2}  ∧  s_1 ∈ Pre_{ℓ_2},
Cert(ℓ_1; s_0) 有效  ∧  Cert(ℓ_2; s_1) 有效
```
则 Cert(ℓ_1∘ℓ_2; s_0) 有效，其证书为 (max(s_1,s_2), C0_1∧C0_2, C1_1∧C1_2, C2_1∧C2_2)。组合满足结合律（子任务格可任意重括号）。

**新增定义 556（三通道证书仲裁 CCA）** 三通道尽量来自不同模型族；决策规则：
```
if ¬C0.ok:                       Reject('unsafe')          # 安全不可妥协
elif C1.ok ∧ C2.ok:              Accept(safety, task_conf, claim)
elif ¬C2.ok:                     SafeReplan('semantic')     # 安全但不切题 ⇒ 任务级重规划
else:                            Accept(safety, task_conf↓, claim)  # 仅 C1 失配，降置信
task_conf = conf(C1)·conf(C2)  若 C1 ⟂ C2（E599 认证），否则 min(conf(C1),conf(C2)).
```
**P17 的硬约束**：未测出独立性前，一律按 min 聚合，禁止把同源错误乘成“更可信”。

**新增定义 557（联合退化：语义重置 × 秩摘除）** 在 v10 七级链顶插入两级，构成九级全序：
```
L0s 语义重置：VLA 不可用/接地失败 ⇒ 丢 C2，用 (C0∧C1)
L0r 秩摘除：τ_d<θ 或秩估计失败 ⇒ Detach_d；β_base 未认证 ⇒ 跳 L0r' 用 v9 rollout
L1–L7 同 v10（LWC L2→L0/L1→v9 AC→RL→LCC→v8→v7→v6）
```
每级失败注入 v10/v9 对应中立元；因每级 O(1)，整链 WCET 不超过 v10 的 20ms（引理 100）。

**新增定义 558（混合证书与域鲁棒性）** 域后验仅知到置信单纯形 W（DA-ML 后验的 (1−α) 区域）时，证书取最坏情形：
```
G_mix = min_{w∈W} [ G_base + Σ_d w_d · δG_d ],   E_mix = max_{w∈W} [ ... ],
```
W 为凸多面体，仿射目标的最小值在顶点取得（引理 96），故只需枚举顶点，代价 O(|W|·|D|)。这使证书对**域误判**鲁棒：用错适配器也会被下界捕获。

**新增定义 559（语言可审计声明）** 每块输出结构化声明与确定性机检器：
```
Claim = “未来 K 步：保持间隙 ≥ ĝ（L0），力矩 ≤ ê，朝 ⟨接地目标⟩ 移动；
         置信 p；证据通道 {C0,C1,C2}；适配器域 d、秩 r_eff。”
```
机检器把 Claim 的数值槽与执行日志逐条比对；不一致即触发 FaultCert（继承 v9）。声明进入审计轨迹，可人读、可回放。

## 2. 关键算法骨架

```python
# IP-361/362 RankDecomposableModel：冻结主干 + 可摘除低秩适配
class RankDecomposableModel:
    def __init__(self, base, r_max=4, beta_base=0.01, lam=1e-2, sigma=0.02):
        self.base = base                 # 冻结，跨域不变，离线认证 beta_base
        self.adapters = {}               # domain -> (B: n×r, A: r×m)
        self.r_max, self.beta_base = r_max, beta_base
        self.lam, self.sigma = lam, sigma

    def predict(self, s, a, w):
        y = self.base(s, a)
        for d, (B, A) in self.adapters.items():
            y = y + w.get(d, 0.0) * (B @ (A @ phi(s, a)))
        return y

    def fit_adapter(self, d, data, rank_budget):
        r = min(rank_budget, self.r_max)
        B, A = low_rank_regression(data, r=r, lam=self.lam)   # 低秩岭回归
        self.adapters[d] = (B, A)

    def bound(self, w, n_d, delta=0.05):
        r_eff = effective_rank(self.adapters, w)               # rank(Σ w_d B_d A_d)
        beta_ad = C_CONST * self.sigma * math.sqrt(
            r_eff * math.log(1.0 / delta) / max(n_d, 1))       # 定义 552
        return self.beta_base + beta_ad, r_eff

    def detach(self, d):                # 精确摘除，O(1)，界 = beta_base
        self.adapters.pop(d, None)
        return self.base

    def worst_case_mixture(self, s, a, W_vertices):           # 定义 558 / 引理 96
        return min(self.predict(s, a, w) for w in W_vertices)


# IP-363 SemanticLattice：VLA 共享潜空间 + 语义残差 + 组合文法
class SemanticLattice:
    def __init__(self, enc, tau_sem=0.5):
        self.enc = enc                  # z = E(o,l,a)；与 base 不同族
        self.tau_sem = tau_sem

    def residual(self, obs, instruction, actions):
        z_l = self.enc.lang(instruction)
        return (mahalanobis(self.enc.act(actions), z_l, self.enc.M) +
                mahalanobis(self.enc.vis(obs),   z_l, self.enc.M))

    def certify(self, obs, instruction, actions):
        lat = self.enc.parse(instruction)          # 谓词格 (Pre,Post,子树)
        s = self.residual(obs, instruction, actions)
        ok = (s < self.tau_sem and lat.Pre(obs.state)
              and lat.Post(actions[-1].next_state))
        return Cert2(s=s, ok=ok, lattice=lat)

    def compose(self, c1, c2):                     # 定义 555 / 引理 97
        assert c1.post_implies_pre(c2), "接口不变式不满足"
        return Cert2(s=max(c1.s, c2.s), ok=c1.ok and c2.ok,
                     lattice=compose_lattice(c1.lattice, c2.lattice))


# IP-364/365 CrossChannelArbiter：三通道仲裁 + 可审计声明
class CrossChannelArbiter:
    def __init__(self, delta_rank=0.15, independent=False):
        self.delta_rank, self.independent = delta_rank, independent

    def decide(self, c0, c1, c2, instruction):
        if not c0.ok:
            return Reject('unsafe')                 # 安全以 L0 为锚，不可妥协
        if not c2.ok:
            return SafeReplan('semantic', claim=c0.claim)  # 安全但不切题
        conf1, conf2 = confidence(c1), confidence(c2)
        task_conf = conf1 * conf2 if self.independent else min(conf1, conf2)
        return Accept(safety=True, task_conf=task_conf,
                      claim=ClaimEmitter.render(c0, c1, c2, instruction))
```

## 3. 推导

**引理 94（秩感知误差界与满秩连通）** 在定义 552 的假设下，适配器误差以 √r_eff 为主项；当 r_eff = min(n,m) 时与 v10 的全秩经验界同阶。证明：低秩岭回归可写为 r 维潜坐标上的 m 个标量回归；对每个回归用自归一化矩阵 Bernstein 界，岭偏差由 λ‖Δ‖_* 控制；以 √r 的并集界合并即得。满秩时 r_eff=min(n,m)，退化为 v10 的 β。∎

**引理 95（摘除退化的健全性）** Detach_d 精确移除 w_d B_d A_d，故 Detach_d(F̂)=F_base；F_base 的证书界 β_base 独立于适配器，故摘除后证书**健全**（sound），即使可能更保守。若 τ_d<θ 定义为“观测残差显著超过 β_base+β_adapter”，则摘除不会把系统带入未经认证的区域。证明：Detach 是线性代数的精确消去；β_base 由离线跨域验证给出，不依赖 τ_d。∎（注：健全≠更紧；在适配器确有帮助处可能更保守，但永不高估安全性。）

**引理 96（混合证书的域鲁棒性）** 若 W 为凸多面体且 g(w)=G_base+Σ_d w_d δG_d 仿射，则 min_{w∈W} g(w) 在 W 的某顶点取得，故 G_mix ≤ g(w) ∀w∈W。证明：仿射函数在紧凸多面体上的极值在顶点；枚举顶点即得全局下界。∎ 推论：DA-ML 域后验哪怕落在 W 内任意点，证书仍成立。

**引理 97（组合证书的健全性与结合律）** 若 Cert(ℓ_1;s_0) 与 Cert(ℓ_2;s_1) 有效且接口不变式 Post_{ℓ_1}⊆Pre_{ℓ_2}、s_1∈Pre_{ℓ_2} 成立，则 Cert(ℓ_1∘ℓ_2;s_0) 有效；且 (ℓ_1∘ℓ_2)∘ℓ_3 与 ℓ_1∘(ℓ_2∘ℓ_3) 的证书等价。证明：沿 Pre→Post 链式蕴含；证书各分量为 ∧，满足交换/结合；接口状态函数复合满足结合律。∎

**引理 98（跨通道误信率）** 安全违背需 C0 前提失败（地图/ULP 假设失效），概率 ≤ ε0（通常为 0）；任务级误接受（接受了实际不完成任务的块）概率为：C1⟂C2 时 ≤ p1·p2，正相关时 ≤ min(p1,p2)。故 CCA 在通道独立时**严格**降低任务级虚假确定性（相对 v10 的单标量），在相关时最多等于较好的单通道——这正是 P17 禁止未测独立就相乘的原因。证明：布尔合取的概率界；独立时乘积，正相关时取最小边际。∎

**引理 99（语义残差对分布偏移的单调性）** 若编码器 E 为 L-Lipschitz，协变量偏移以 W_1 度量，则
```
|s(P) − s(Q)| ≤ L·(W_1^vis + W_1^lang) + 2·bias,
```
故 s 是（至多 L 倍变形的）一致偏移探测器，阈值 τ_sem 给出受 L 控制 FPR 的 OOD 检测。因 s 只经 VLA 编码器，它与前向模型的 Δ_dom **不同源**，可作为独立怀疑者。证明：Mahalanobis 距离对分布偏移的 Lipschitz 连续性 + 三角不等式。∎

**引理 100（联合退化的单调性与 WCET）** 新增的语义重置与秩摘除均为 O(1)（标志翻转 / 字典删除），故九级链 WCET ≤ v10 的 20ms；且每个 v11 回退唯一映射到一个 v10 层级，链是全序细化而非新行为。证明：Detach 为 pop O(1)，语义层为布尔标志；映射表逐级给出（L0s/L0r → v10 L1/L2 或 v9 rollout）；其余沿用 v10 引理 91/92。∎

## 8. 本轮最大风险

**一句话**：**“冻结主干 + 低秩适配”只在真实偏移确实落在适配子空间内时才成立——若域偏移含子空间外的主偏差，低秩界会把偏差当方差而给出过紧的假界；而 VLA 语义残差又可能与被测模型同源共错，于是三通道同时失效。低秩把“模型误差”重命名为“看不见的偏差”，语义接地把“相关错误”误当成“独立证据”。**
