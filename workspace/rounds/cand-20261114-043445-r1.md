# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配×主动交互的不确定性二分」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「状态隔离」×「传感器融合」）

> R69 给了不确定性形状（多模态）和消解它的动作（看/问/触），但有一个从未被检查的更强前提：**所有消费者读的是同一个状态**。任务策略、风险缩放、标定器、流似然异常器与安全认证共享同一个 `z_t` 和同一份观测历史。这个「单一状态」正是共模污染的温床：一次投毒的交互回答、一次被标定吸收的缓变故障、一次时间戳错位，会沿共享状态同时改写策略信念、异常基线与安全包络。R69 自己承认「问错比不问更危险」，却仍让「问来的答案」写进一个所有模块都能读的全局后验。
>
> 本轮两个灵感各补一半：
> - **状态隔离**：把状态拆成若干**互不共享可写内存的单元（cell）**，每个单元有自己的状态空间、噪声模型、时间尺度与信任上限；跨单元只能通过**带来源、版本、时间窗与签名的消息总线**通信。故障被限制在舱壁内，标定单元不能再「解释掉」异常单元看到的东西。
> - **传感器融合**：R69 的「k 个正交证据源一致」是口号，不是算法——它默认来源独立、时间对齐、协方差已知。真正的融合要处理**异构延迟、异步采样、未知相关性与重复计数**；否则「融合」会把毒证据洗成高置信共识。
>
> 核心命题：**R69 让不确定性有了形状；R70 要给状态建「隔离舱」——隔离不是不融合，融合不是乱融合。** 每个单元内部做标准融合（因子图/卡尔曼 + 新息门控），跨单元只做**信任格约束下的保守联邦融合（协方差交叉 + 来源重叠折扣）**，并且**低信任单元不得写高信任单元**。这样交互答案最多污染语义/交互舱，永远不能直接把安全舱「说服」。
>
> 命名 **SILO-RAS**（State-Isolated, Latency-aware, Orthogonal-fusion Risk-Adaptive System）。「silo」是故意保留的贬义：为了故障遏制，我们**主动**制造信息孤岛；但用来源与信任格保证孤岛之间只说「可审计的方言」。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**谁有权改写我所相信的状态，改到什么程度为止**」。

## 0. 直觉与动机

**灵感 1（状态隔离 → 共模污染是 R69 未命名的头号漏洞）**
直觉：R69 的每一个巧思都建立在「共享 `z_t`」上：FMP 用 `z` 条件化，AUD 用 `z` 聚类，FMA 用 `z` 算似然，COF 用 `z` 做标定，C-RAS-WM 用 `z` 做认证。共享省算力，却让一次污染同时命中多个消费者。隔离的直觉来自航空 IMA 分区、微内核地址空间、TEE：不是不通信，而是「写入必须过受控接口、读取必须带权限」。当标定只能写自己的舱，它就再也无法把异常舱的残差抹平；当交互答案只能写 I 舱，它就再也无法直接抬高安全舱的置信。R69 的「问错比不问更危险」因此降级为「问错最多让一个可被降权的舱暂时相信」。

**灵感 2（传感器融合 → 证据纪律要从口号变成估计器）**
直觉：R69 的「至少两个正交证据源」没说怎么判正交、怎么合并、怎么处理延迟。经典融合给了工具：状态空间模型、协方差、新息门控、因子图、协方差交叉。但朴素融合有两个反直觉的坑：(a) 相关证据会被重复计数，两个共享同一相机祖先的「独立」通道会让后验方差虚假缩小；(b) 融合顺序会变成攻击面——先污染低信任舱、再让它与高信任舱融合，输出就被「洗白」。所以融合必须**来源感知**：按 provenance 重叠折扣、跨舱用对未知相关保守的 CI，且**信任只能降不能升**，除非有来源不相交的独立佐证。

**灵感 3（两者张力 → 隔离与融合的最优边界是「信任格 + 单向写」）**
直觉：完全隔离，每个舱都饿死；完全融合，共模故障一锅端。真正的设计变量不是「隔不隔」，而是「**谁能写谁**」。我们把它形式化为一个信任偏序格和写权限关系：安全舱处于格顶，可读所有、可否决所有、只被自己写；语义/交互舱处于格底，可读安全舱但只能向自己的舱写；标定舱可下调语义舱的偏差，但不能上调安全舱的置信。信息可以「向下流」，信任不能「向上爬」。这就是本轮的理论骨架。

**灵感 4（延迟异构 → 时间也必须隔离）**
直觉：触觉 1ms、本体 1kHz、视觉 30–100ms、语言 100–1000ms。R69 的「看—问—做」在同一时间轴上排列，但真实系统里慢通道永远在拖快快通道。隔离天然给出**每舱时间尺度与陈旧度上界**：快舱绝不阻塞等慢舱，慢消息要么按过程噪声膨胀后使用，要么过期丢弃。NIS/NEES 门控在这里不是可选项——没有它，一个迟到的视觉帧会在接触瞬间「纠正」掉真正的力反馈。

**灵感 5（新攻击面 → 隔离会制造新的单点：仲裁与来源）**
直觉：一旦有多个舱，就必须有仲裁与来源定义。攻击者不再需要骗过所有传感器，只需 (1) 污染 provenance 让两个舱看起来独立（其实是同一被劫持的时钟/外参），或 (2) 反复向多个低信任舱注入同一假象，再让它们「一致」地推动联邦融合。**隔离不制造独立性，只保留已有的独立性**。所以本轮必须交付：来源图与有效独立度 `k_eff`、非洗白引理、来源不相交佐证，以及「仲裁器自身也要被分区/复核」的纪律。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（SILO-RAS 总览）** SILO-RAS = (SCG, PBUS, IFF, TLF, TCM, PVG, ERM, RAS-WM‡)。五不变式：
(i) **封装**：任一单元 c 的状态 `x_c` 只由 c 写；
(ii) **类型化 IPC**：跨单元信息只经 PBUS 的带模式消息，携带来源、版本、时间窗、签名；
(iii) **信任单调（no-write-up）**：低信任消息不得抬高目标单元信任，除非来源不相交佐证（定义 317）；
(iv) **时间隔离**：快单元不等待慢单元；过期消息按定义 315 丢弃或膨胀；
(v) **纪元一致**：任何跨单元提交/回滚满足定义 318 的 epoch/向量时钟一致性。

**定义 311（状态单元 State Cell）** 单元 `c = (𝒳_c, Q_c, τ_c, h_c, ϑ_c, W_c, π_c)`：状态空间、过程噪声、时间尺度、陈旧上界、信任级别、可写目标集、局部估计器。规范单元集 `𝒞 = {c_S 安全/本体, c_C 标定, c_T 任务/语义, c_A 异常/似然, c_I 交互/歧义}`。每单元独立维护 `(x_c, Σ_c, e_c, v_c)`。

**定义 312（来源总线消息 PBUS）** 消息 `μ = ⟨src, dst, type, payload, t_meas, t_send, e, v, P(μ), sig⟩`，其中 `P(μ) ⊆ 𝒫` 为来源祖先集（原始传感器、标定表、人类回答、模型版本……），`v` 为向量时钟，`e` 为纪元。接收方校验模式、签名、因果性与时间窗；任一失败则丢弃并记审计。

**定义 313（来源图与有效独立度）** 以来源为节点、变换/融合为超边构造 provenance 图 `G_P`。两消息重叠 `ω(μ_i, μ_j) = |P_i ∩ P_j| / min(|P_i|,|P_j|)`。对一组佐证 S，有效独立度 `k_eff(S)` = 最大来源两两不交（或 `ω ≤ δ_P`）子集大小。R69 的「k 个正交源」被精化为 `k_eff`，而非声明的 k。

**定义 314（信任格）** 信任级别 `L = {T0 原始, T1 单源/建议, T2 跨模态佐证, T3 安全认证}`，带偏序 `≼`（`T0≼T1≼T2≼T3`）。单元有信任上限 `ϑ̄_c`。融合/写入后的信任 `ϑ_out ≼ min_i ϑ_i`；仅当 `k_eff ≥ 2` 且来源不相交时允许一级「确证提升」（定义 317）。安全舱 `ϑ̄ = T3` 且只被 `c_S` 自写。

**定义 315（陈旧度与延迟补偿）** 消息年龄 `a = t_now − t_meas`。传播到公共时刻 `t*`：`x(t*) = Φ(a)x`，`Σ(t*) = Φ(a)ΣΦ(a)ᵀ + a²Q_c + a σ_drift² I`。若 `a > h_c`：丢弃。陈旧度门控保证快速环路只消费在有效时间窗内的状态；迟到消息不得回写已提交的快舱状态。

**定义 316（隔离感知融合 IFF）** 单元内：因子图/卡尔曼，新息门控 `χ²_{ν,α}`（NIS/NEES）。跨单元：只接受「可融合投影」`π_{c→c'}(x_c,Σ_c)`（定义 325），用**协方差交叉** `Σ_CI^{-1} = Σ_i w_i Σ_i^{-1}`（对未知相关保守），并在输入协方差上按来源重叠膨胀 `Σ_i ← (1+ω_i)Σ_i`，防止重复计数。禁止跨单元直接拷贝均值。

**定义 317（信任受限联邦 TLF）** 跨单元融合结果写入 `c'` 的规则：若 `ϑ(μ) ≼ ϑ_{c'}` 且无来源不相交佐证，仅以只读建议进入，不修改 `c'` 的可写状态；若 `k_eff(S) ≥ 2` 且 `max pairwise ω ≤ δ_P`，可提升一级。**非洗白不变式**：`trust(out) ≼ min(trust inputs) + 1[k_eff≥2 ∧ ω≤δ_P]`。

**定义 318（纪元与回滚 ERM）** 每单元维护 `e_c` 与向量时钟 `v_c`，消息携带 `(e,v)`；因果过期或纪元不符即拒收。跨单元动作提交为两阶段：prepare（候选状态 + 局部证书）→ commit（依赖单元确认同一纪元）。故障或一致性失败回滚到最近认证检查点；回滚后所有派生消息作废。继承 R68 定理 15 的换装不变式到状态层。

**定义 319（状态隔离契约 SIC）** 一个单元图满足 SIC，当且仅当：(i) 无共享可写内存；(ii) 所有跨边是 PBUS 类型化消息；(iii) 写能力由 `W_c` 显式授予（默认只读）；(iv) 每条消息带时间窗与来源；(v) 提交/回滚纪元一致；(vi) 全消息可审计（哈希入 AuditBuf）。SIC 是「隔离」的可机器检查定义，而不是口号。

**定义 320（融合洗白 Fusion Laundering）** 洗白增益 `LG = ϑ_out − min_i ϑ_i`。攻击者通过把被污染的低信任输入与高信任输入融合，使输出被重新标为高信任。**非洗白引理**（引理 20）给出 `LG ≤ 0` 的充分条件；不满足则拒绝写入高信任舱。

**定义 321（提案-否决 PVG）** `c_T/c_I` 生成候选动作/模态提案；`c_S` 只能在自身认证的动作集 `𝒜_cert` 内**否决或裁剪**，不得被提案「反向授权」。若 `c_S` 陈旧/不可用，回退到最近认证动作（fail-safe），而不是语义提案。形式：`a* = argmax_{a ∈ 𝒜_cert ∩ (proposal or {a_safe})} score`，且 `c_S` 的否决优先于任何语义置信。

**定义 322（跨单元风险合成）** 每单元输出局部证书 `(risk_c, U_c)`。全局风险按**安全主导的 max** 合成：`risk_global = max_c risk_c`（不求和，避免重复计数）；信息侧决策用保守交（信任取 min、协方差取 CI）。这修正了 R69 把不同来源不确定性「加总」的隐患：不可约噪声在 `c_S`，可约歧义在 `c_I`，模态内方差在 `c_T`，三者语义不同且来源可能重叠。

**定义 323（共模故障与来源多样性）** 共模故障 (CMF) 指两个单元共享来源祖先（`ω > 0`）时被同一扰动同时污染。定义单元对有效独立性 `i(c,c') = 1 − ω(c,c')`。SILO 只能**保留**而非**创造**独立性：若传感器套件本身没有来源多样性，隔离不会降低 CMF 风险。来源多样性审计成为证书必填项。

**定义 324（一致性监测 TCM）** 跨单元一致性残差 `r_{cc'} = ‖π_{c→c'}(x_c) − x_{c'}‖²_{(Σ_c+Σ_{c'})}`；超阈值触发**仲裁**（选高信任、冻结低信任、记审计），绝不静默平均。NEES/NIS 在单元内做传感器级门控；TCM 在单元间做「世界观」级门控。

**定义 325（可融合投影）** `π_{c→c'}: 𝒳_c → 𝒳_{c'}` 是显式声明的、带雅可比与不确定度传播的映射（如标定舱的偏置 → 任务舱的物体位姿修正；安全舱的接触集 → 任务舱的可行动作掩码）。未声明投影的跨单元读写一律禁止——这堵住了「隐式全局变量」的共模通道。

**定义 326（信息动作的隔离路由）** R69 的 `g=(gaze,probe,ask)` 的回答只能写入 I 舱（定义 311），经定义 317 佐证后才可经 π 影响 T 舱；**任何人类回答/语言证据不得写 C 或 S**。这把 R69 的交互投毒上界从「全局后验」收窄到「单舱可降权状态」。

**定义 327（证书 J_SILO）** `J_SILO = (J_FLUID, cell_graph_hash, provenance_coverage, k_eff_min, max_laundering_gain, tcm_p95, staleness_p99, epoch_status, rollback_count, silo_ver)`。Valid ⇔ `Valid(J_FLUID)` ∧ SIC 满足 ∧ `max LG ≤ 0` ∧ `k_eff_min ≥ 2`（用于高信任写入）∧ 无过期纪元消息被消费。

**定义 328（退化族与嵌套）** 令 `|𝒞|=1` 且 PBUS 退化为直连、π 为恒等，则 SILO-RAS ≡ FLUID-RAS（R69）；再令 FMP 关闭、`VoI≡0`，则 ≡ CALM-RAS（R68）。隔离参数（单元数、写能力、来源折扣）构成一个连续设计族，R68/R69 是其在「无隔离/单舱」边界上的点。

# IP-264 SCG：规范状态单元图（每单元独立估计器，默认只读边）
CELLS = {
  'S': Cell(state='safety',   rate=1000, horizon=0.05, trust=T3, writable={'S'}),
  'C': Cell(state='calib',    rate=0.1,  horizon=60.0, trust=T2, writable={'C','T'}),
  'T': Cell(state='task',     rate=30,   horizon=0.2,  trust=T2, writable={'T'}),
  'A': Cell(state='anomaly',  rate=30,   horizon=0.2,  trust=T2, writable={'A'}),   # 只读建议
  'I': Cell(state='interact', rate=1,    horizon=5.0,  trust=T1, writable={'I'}),
}

# IP-265 PBUS：带来源/版本/时间窗/签名的消息总线
def publish(src, dst, typ, payload, P, e, v):
    msg = Msg(src, dst, typ, payload, t_meas=payload.t, t_send=now(),
              P=provenance_union(P), e=e[src], v=v, sig=sign(payload))
    bus.send(msg)                       # 单生产者/单消费者，无共享可写内存

def receive(cell, msg):
    if not verify(msg.sig) or not causal(msg.v, cell.v):        return DROP
    if msg.e != cell.e or age(msg) > cell.horizon:              return DROP
    if not cap_ok(msg.src, cell.id, msg.typ):                   return DROP
    return msg

# IP-266 IFF：单元内融合 + 跨单元保守联邦（来源重叠折扣 + CI）
def fuse_within(cell, msgs):
    x, S = cell.prior()
    for m in msgs:
        S = S + age_inflate(m, cell.Q)                   # 定义 315
        r = m.z - H(m.chain) @ x;  S_m = H @ S @ H.T + m.R
        if r @ inv(S_m) @ r > chi2_gate(len(r)): continue  # 新息门控
        x, S = kalman_update(x, S, m.z, H, m.R)
    return x, S

def federate(cell, inputs):                               # input: (x_i,S_i,prov_i)
    for i in inputs:
        w_i = overlap_with_others(i, inputs)              # 定义 313
        S_i_disc = (1.0 + w_i) * i.S                      # 防重复计数
    S_CI = inv(sum(weight_i * inv(S_i_disc) for i in inputs))  # 协方差交叉
    return conservative_mean(inputs, S_CI), S_CI

# IP-267/317 TLF：信任单调写入（低信任不得写高信任）
def trusted_write(dst_cell, src_msg, fused):
    if src_msg.trust > dst_cell.trust and k_eff(fused.prov) < 2:
        dst_cell.advisory_buffer.append(fused); return False   # 只读建议
    if max_pairwise_overlap(fused.prov) > DELTA_P:
        return False                                            # 相关证据不提升
    dst_cell.write(fused)                                       # 允许（≤ 一级提升）
    return True

# IP-268/324 TCM：跨单元一致性仲裁（不静默平均）
def consistency_gate(x, S, cells):
    bad = []
    for (a, b) in cell_edges:
        r = residual(project(a, b, x[a]), x[b], S[a], S[b])
        if r > tau_tcm: bad.append((a, b))
    for a, b in bad:
        hi = a if cells[a].trust >= cells[b].trust else b
        lo = b if hi == a else a
        freeze_and_audit(lo, reason='cross_cell_inconsistent')
    return len(bad) == 0

# IP-270/321 PVG：语义提案 → 安全舱否决/裁剪
def proposal_veto(proposal, safety):
    if safety.stale(): return safety.last_certified           # fail-safe
    admissible = safety.certified_set()
    return best_admissible(proposal, admissible, safety.veto_order)

# IP-271/318 ERM：两阶段提交 + 纪元回滚
def commit(cells, action):
    cand = {c: cells[c].prepare(action) for c in action.deps}
    if not all(cells[c].epoch == cand[c].epoch for c in cand): return rollback()
    for c in cand: cells[c].commit(cand[c])
    return action

# IP-275 SILO-RAS 主闭环（继承 R69，状态流向按信任格）
def SILO_RAS_round(M, obs):
    M.pbus.ingest(obs)                                  # 原始观测 → 各舱按能力订阅
    M.cells['S'].step(fast=True)                        # 1kHz 安全/本体，绝不等慢舱
    M.cells['C'].step(); M.cells['A'].step(); M.cells['T'].step()
    U_ale, U_epi, modes = M.cells['T'].decompose(M.cells['A'].likelihood())
    g = M.mint.choose_interaction(modes, M.cells['I'], M.budget)   # 只在 I 舱核算 VoI
    if g is not None:
        ans = M.cia.execute_isolated(g)                 # 回答只写 I 舱，需佐证
        M.cells['I'].update(ans, evidence=M.pbus.evidence(ans))
    M.tcm.check(M.cells)                                # 跨舱一致性 → 仲裁/冻结
    if not M.cells['S'].fresh():                        # 安全舱陈旧 → 回退
        return M.cells['S'].last_certified, M.cells['S'].last_lambda
    lam = M.efs.risk_scale(M.cells['T'], M.cells['A'], U_ale, U_epi)  # max 合成
    k = M.ras_wm.certified_prefix(M.ach.propose(M.cells['T'].x), M.cells['S'])
    a = M.pvg.proposal_veto(M.select_mode(modes, lam), M.cells['S'])
    M.vqa_s.submit_async(M.pbus.trace(), M.tcm.last(), M.cells['I'].trust())
    return M.erm.commit(M.cells, a), lam
```

## 3. 推导

**引理 19（隔离的故障遏制）** 在 SIC（定义 319）下，单元 c 的 Byzantine 故障只能通过 PBUS 边影响其后继；且由 no-write-up（定义 314/317），高信任后继至多被降权/否决，不能被低信任源授权。故单舱故障对安全决策的影响被限制在其消息权限内；若安全舱自身或其 T3 祖先未故障，则安全证书不变。证明要点：无共享可写内存 ⇒ 因果影响必须经过边；写能力 `W_c` 与信任格给出影响上界。

**引理 20（融合非洗白）** 设输入来源集 `{P_i}`，两两重叠 `ω_ij`，输入信任为 `ϑ_i`。若 `max ω_ij > δ_P` 或 `k_eff < 2`，则 `trusted_write` 拒绝写入高信任舱，`LG ≤ 0`；若 `k_eff ≥ 2` 且 `max ω ≤ δ_P`，则一次确证提升至多一级。由此单源欺骗率 `δ_p` 下，错误高信任采纳率 `≤ δ_p·ρ_eff^{k_eff−1} + ε_σ`，其中 `ρ_eff` 由来源重叠决定。系：R69 的「k 个正交源」恰是 `k_eff = k`、`ω = 0` 的特例；当「正交」只是声明而来源实际重叠时，R69 的界失效，而 SILO 的 `ω` 折扣会把界加回。

**引理 21（延迟补偿误差界）** 年龄 a 的传播误差协方差增量为 `Φ(a)ΣΦ(a)ᵀ − Σ + a²Q + aσ_drift²I`；其 Mahalanobis 期望随 a 线性增长。若 `a > h_c` 则丢弃，故任何被消费的消息满足 `NEES ≤ τ(a)`；快速环路不会消费慢通道的过期状态。系：视觉迟一帧不会在接触瞬间覆盖力反馈，因为二者在不同舱、且过期帧被丢弃而非平均。

**定理 18（SILO 严格包含 R69 与 R68）** 取 `|𝒞|=1`、`π=Id`、PBUS 直连、无来源折扣，SILO 每步退化为 FLUID-RAS；再关闭 FMP/VoI 退化为 CALM-RAS。一般情形下，任何被授权执行的动作必须通过隔离的 `c_S` 与原 C-RAS-WM 认证；低信任跨舱信息不能放宽 `c_S` 的证书（引理 19–20），故安全风险上界不高于 R69，而语义/交互侧获得「局部可纠错 + 故障不扩散」的收益。**安全侧不让步，可靠性侧得到舱壁。**

**定理 19（无阻塞实时性）** 在分区调度下，`c_S` 有独立预算；PBUS 为无锁单生产者/单消费者；慢舱以 latest-value 语义发布且过期即弃。故 `c_S` 的端到端延迟与慢舱负载无关，`P99 ≤ R69 的 P99 + δ_PBUS`。系：K=4 的歧义采样与人类问答不再可能击穿 1kHz 安全环。

**定理 20（一致性 / 无 split-brain）** 若所有跨舱提交满足定义 318 的 epoch/向量时钟两阶段提交，且 TCM 只做「高信任仲裁 + 低信任冻结」而不静默融合，则不存在被提交的动作同时依赖两个互相矛盾的舱状态；检测到不一致时回滚到最近认证快照，且所有派生消息作废。故控制连续、无突变（继承 R68 定理 15），隔离不引入分裂脑。

## 6. 本轮最大风险

**一句话**：SILO 的收益来自「把共模污染挡在舱壁外」，但**信任格、仲裁器与 provenance 定义本身是共享的、可被攻击的**——若攻击者伪造来源/时间戳，或让多个低信任舱「独立地」相信同一假象，隔离不但不防共谋，反而会以「多舱一致」的名义给伪证据盖章；**新的单点不是状态，而是「谁有权定义独立」**。

**次级风险与缓解**：仲裁器自身故障 → 冗余仲裁 + fail-safe 回退（定理 20）；CI 保守度过高导致过度保守 → 自适应 `δ_P` + E311 校准；多舱计算开销 → 分区调度 + E316 Pareto；隔离阻碍信息共享 → 显式可融合投影 π + E315；来源图膨胀 → 来源哈希压缩 + 审计抽样。

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** SILO-RAS = (SCG,PBUS,IFF,TLF,TCM,PVG,ERM,RAS-WM‡)；封装、类型化 IPC、no-write-up、时间隔离、纪元一致。

**定义 311（状态单元）** 五舱各自独立维护 `(x_c,Σ_c,e_c,v_c)`；安全舱 1kHz、标定舱 0.1Hz、任务/异常舱 30Hz、交互舱 1Hz。

**定义 312–313（PBUS 与来源）** 消息带来源/时钟/纪元/时间窗/签名；`ω` 与 `k_eff` 把 R69 的「正交」从声明变成可计算量。

**定义 314（信任格）** `T0≼T1≼T2≼T3`；融合信任 `≼ min` 输入；仅来源不相交 `k_eff≥2` 允许一级提升；安全舱只被自写。

**定义 315（陈旧度）** `Σ(t*)=ΦΣΦᵀ+a²Q+aσ_drift²I`；超 `h_c` 丢弃；迟到消息不回写快舱。

**定义 316（隔离感知融合）** 舱内因子图 + χ² 新息门控；跨舱 CI，输入协方差按 `(1+ω)` 膨胀防重复计数。

**定义 317（信任受限联邦）** 低信任不得写高信任；`k_eff≥2 ∧ ω≤δ_P` 才允许一级确证提升；非洗白不变式。

**定义 318（纪元与回滚）** 两阶段提交；纪元/向量时钟不符即拒收；失败回滚最近认证快照。

**定义 319（状态隔离契约 SIC）** 无共享可写内存、类型化 IPC、能力授予、时间窗、纪元一致、全消息可审计。

**定义 320（融合洗白）** `LG = ϑ_out − min ϑ_i`；不满足非洗白条件即拒绝写高信任舱。

**定义 321（提案-否决）** 语义/交互舱提案，安全舱在 `𝒜_cert` 内否决/裁剪；安全舱陈旧则 fail-safe 回退。

**定义 322（风险合成）** `risk_global = max_c risk_c`（不求和）；信息侧取 min 信任 / CI 协方差。

**定义 323（共模故障）** 共享来源祖先即 `ω>0`；隔离只能保留独立性，不能创造独立性；来源多样性入证书。

**定义 324（一致性监测）** 跨舱残差超阈值 → 高信任仲裁 + 低信任冻结，绝不静默平均。

**定义 325（可融合投影）** 未声明投影的跨舱读写一律禁止，堵住隐式全局变量通道。

**定义 326（交互隔离路由）** 回答只写 I 舱，佐证后才可经 π 影响 T；不得写 C/S。

**定义 327–328（证书与退化族）** `J_SILO` 并入来源/洗白/一致性/回滚；单舱直连无折扣时严格退化为 R69，再退化为 R68。

        if r @ inv(Sm) @ r > chi2_gate(len(r)): continue
        x, S = kalman_update(x, S, m.z, H, m.R)
    return x, S

def federate(inputs):
    for i in inputs: i.S = (1.0 + overlap_with_others(i, inputs)) * i.S
    S_CI = inv(sum(w_i * inv(i.S) for i in inputs))          # 协方差交叉
    return conservative_mean(inputs, S_CI), S_CI

# IP-267 TLF：低信任不得写高信任
def trusted_write(dst, src, fused):
    if src.trust > dst.trust and k_eff(fused.prov) < 2:
        dst.advisory_buffer.append(fused); return False
    if max_pairwise_overlap(fused.prov) > DELTA_P: return False
    dst.write(fused); return True

# IP-268 TCM：一致性仲裁（不静默平均）
def consistency_gate(x, S, cells):
    for (a, b) in cell_edges:
        if residual(project(a, b, x[a]), x[b], S[a], S[b]) > tau_tcm:
            lo = a if cells[a].trust < cells[b].trust else b
            freeze_and_audit(lo, 'cross_cell_inconsistent')

# IP-270 PVG：提案-否决 + fail-safe
def proposal_veto(proposal, safety):
    if safety.stale(): return safety.last_certified
    return best_admissible(proposal, safety.certified_set(), safety.veto_order)

# IP-271 ERM：两阶段提交 / 纪元回滚
def commit(cells, action):
    cand = {c: cells[c].prepare(action) for c in action.deps}
    if not all(cells[c].epoch == cand[c].epoch for c in cand): return rollback()
    for c in cand: cells[c].commit(cand[c])
    return action

# IP-275 主闭环：观测分舱 → 隔离融合 → 交互只写 I → 仲裁 → 提案-否决 → 提交
def SILO_RAS_round(M, obs):
    M.pbus.ingest(obs)
    M.cells['S'].step(fast=True)                     # 1kHz，绝不等慢舱
    M.cells['C'].step(); M.cells['A'].step(); M.cells['T'].step()
    U_ale, U_epi, modes = M.cells['T'].decompose(M.cells['A'].likelihood())
    g = M.mint.choose_interaction(modes, M.cells['I'], M.budget)
    if g:
        M.cells['I'].update(M.cia.execute_isolated(g), M.pbus.evidence(g))
    M.tcm.check(M.cells)
    if not M.cells['S'].fresh():
        return M.cells['S'].last_certified, M.cells['S'].last_lambda
    lam = M.efs.risk_scale(M.cells['T'], M.cells['A'], U_ale, U_epi)
    k   = M.ras_wm.certified_prefix(M.ach.propose(M.cells['T'].x), M.cells['S'])
    a   = M.pvg.proposal_veto(select_mode(modes, lam), M.cells['S'])
    M.vqa_s.submit_async(M.pbus.trace(), M.tcm.last(), M.cells['I'].trust())
    return M.erm.commit(M.cells, a), lam
```

## 4. 推导

**引理 19（隔离的故障遏制）** SIC 下单元故障只能经 PBUS 边传播；no-write-up 使高信任后继至多被降权/否决，不能被低信任源授权。故单舱 Byzantine 故障对安全决策的影响被限制在其消息权限内；安全舱自身未故障时证书不变。

**引理 20（融合非洗白）** 输入来源两两重叠 `ω_ij`、输入信任 `ϑ_i`。若 `max ω > δ_P` 或 `k_eff<2`，拒绝写高信任舱，`LG≤0`；若 `k_eff≥2 ∧ max ω≤δ_P`，最多提升一级。单源欺骗率 `δ_p` 下错误高信任采纳率 `≤ δ_p·ρ_eff^{k_eff−1}+ε_σ`。系：R69 的「k 正交源」是 `k_eff=k, ω=0` 的特例；声明正交但来源重叠时 R69 的界失效，SILO 的 `ω` 折扣把界加回。

**引理 21（延迟补偿误差界）** 年龄 `a` 的协方差增量 `ΦΣΦᵀ−Σ+a²Q+aσ_drift²I`，Mahalanobis 期望随 `a` 线性增长；`a>h_c` 丢弃 ⇒ 被消费消息满足 `NEES≤τ(a)`，快环不消费慢舱过期状态。

**定理 18（SILO 严格包含 R69/R68）** `|𝒞|=1`、π=Id、直连、无折扣 ⇒ 每步退化为 FLUID-RAS；再关 FMP/VoI ⇒ CALM-RAS。一般情形动作必须通过隔离 `c_S` 与原 C-RAS-WM；低信任信息不能放宽 `c_S` 证书（引理 19–20），故安全风险上界不高于 R69，语义/交互侧获得「局部可纠错 + 故障不扩散」。

**定理 19（无阻塞实时性）** 分区调度给 `c_S` 独立预算；PBUS 无锁单生产/单消费；慢舱 latest-value 且过期即弃 ⇒ `c_S` 延迟与慢舱负载无关，`P99 ≤ R69 P99 + δ_PBUS`；K=4 采样与人类问答不再击穿 1kHz 安全环。

**定理 20（一致性 / 无 split-brain）** epoch/向量时钟两阶段提交 + TCM「高信任仲裁 + 低信任冻结」⇒ 不存在提交动作同时依赖互相矛盾的舱状态；不一致时回滚最近认证快照、派生消息作废；控制连续无突变（继承 R68 定理 15）。

## 7. 本轮最大风险

**一句话**：SILO 的收益来自「把共模污染挡在舱壁外」，但**信任格、仲裁器与 provenance 定义本身是共享的、可被攻击的**——若攻击者伪造来源/时间戳，或让多个低信任舱「独立地」相信同一假象，隔离不但不防共谋，反而会以「多舱一致」的名义给伪证据盖章；**新的单点不是状态，而是「谁有权定义独立」**。

**次级风险与缓解**：仲裁器自身故障 → 冗余仲裁 + fail-safe 回退（定理 20）；CI 过度保守 → 自适应 `δ_P` + E311；多舱开销 → 分区调度 + E316；隔离阻碍共享 → 显式可融合投影 π + E315；来源图膨胀 → 哈希压缩 + 抽样审计。
