# 第 66 轮（承接第 65 轮「VISTA 故障可归因闭环」IP-214~223；灵感循环第 3 轮；本轮灵感：「开源软件」×「微调」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险一针见血：**归因能力依赖「故障属于有限假设集、且视觉与几何的失效相互独立」；真实故障常是未知类型的组合，且透明/镜面/对抗 patch 会让视觉与几何共享同一个分布外失效源，FIR 会把未知复合故障强行塞进最近假设、只膨胀错误的球——系统因「已经归因」反而更自信地继续执行。** 本轮不再往封闭假设集里塞更多假设，而是换一个来自软件工程的提问方式：**一个由成千上万开源依赖组成的系统，凭什么敢上线？它并不证明「没有 bug」，而是让每个 bug 都可定位到版本、可复现、可回滚、可由公告与补丁演化。** 本轮把这条思路移植到机器人安全栈，并用「微调」补上能力演化这一维。核心命题是：
>
> **把「可归因」升级为「可定位、可复现、可分叉、可回滚的安全演化」：用开源软件的物料清单 / 语义版本 / 溯源二分 / 可复现构建，把故障归因从「在封闭假设集里选一个」变成「在版本化组件图里定位到节点，或诚实地隔离」；用携带证书的低秩微调与安全零空间合并，把能力更新从「可能悄悄擦除安全的黑箱」变成「默认不降低安全裕度、可合并、可回滚的受控变更」。**

## 0. 直觉与动机

**先给一个贯穿全文的例子。** 一台机器人用开源 VLA 底座 + 本队 LoRA 适配器 + 共享视觉编码器 + 接触模型 + 标定表。某天它在抓取时力残差突然变大。VISTA 会问：这是几何幻觉、F/T 偏置、接触模型错、视觉错，还是策略 OOD？但真相可能是：**上游视觉编码器换了一个 commit，而这个 commit 同时被几何先验和视觉策略依赖**——VISTA 的独立性假设从一开始就不成立。FOSSIL 会问三个不同的问题：(i) 这个故障能不能被定位到 SBOM 里的某个具体版本节点？(ii) 如果定位不到，能否诚实地隔离而不是强行归因？(iii) 修复能否以一次「带证书的发布」进入系统，而不是在线偷偷改参数？

**灵感 1（开源软件 → 不追求「无 bug」，而追求「可定位、可复现、可回滚」）**
直觉：开源生态并不假装自己无 bug。它用 SBOM 声明依赖、用 semver 声明兼容性、用 lockfile 钉住版本、用 CVE/安全公告把未知漏洞变成可追踪对象、用 `git bisect` 把回归定位到 commit、用可复现构建让第三方能重放证据、用 CI 把修复挡在合并之前。这套机制的精髓不是「正确性证明」，而是**把不可知的故障转化为可操作的版本/证据/回滚问题**。映射到机器人：VISTA 的有限假设集是「封闭世界」；真实世界的未知故障更像一个**未申报的依赖**。与其把它硬塞进最近的假设，不如让它变成一个**带公告编号的 issue**，在隔离中等待分诊。

**灵感 2（开源软件 → 安全是 fork / merge / CI，而不是一次性证明）**
直觉：多机器人、多团队会 fork 同一套栈、各自微调、再合并贡献。安全不能是「出厂时证明一次」，而必须是**合并门**：两个适配器能不能合并，取决于它们的「安全契约」是否兼容（类似 license 兼容性），取决于合并后的回归测试与安全裕度是否仍过门。于是引入**安全语义版本**与**追加式回归注册表**：patch 只刷新证据，minor 可加能力但契约不变，major 一旦改契约就必须全链路重认证；回滚就是把 lockfile 切回上一个已认证版本。

**灵感 3（微调 → 能力获取与安全擦除是同一枚硬币）**
直觉：LoRA / adapter / 参数高效微调是当代机器人获取能力的主要方式：底座开源、数据自采、单卡可训。但微调也是**安全被悄悄擦除**的主要方式：灾难性遗忘、目标分布漂移、奖励黑客、投毒数据，都可能让一个「在 demo 上更强」的适配器在安全临界点上更差。FOSSIL 的立场不是「禁止微调」，而是**让微调携带证书**：冻结安全核、只在低秩子空间适配、在安全回放集上约束函数漂移、用追加式回归门决定是否发布。

**灵感 4（合流 → FOSSIL：Forkable Open-Source Safety with Incremental Learning）**
闭环：SBOM/安全物料清单（组件版本 DAG + 契约 + 哈希 + 来源）→ SSV 安全语义版本 → CFA 携带证书的微调适配器 → SRR 安全回归注册表/发布门 → MSC 安全零空间合并 → 部署为 lockfile → 运行时 VISTA 证据采集 → PBL 溯源二分定位 → CGM 共同祖先共因边缘化 → 定位失败则 QAR 隔离/公告 → 离线分诊 → 新补丁/新版本 → 回到 SRR。**VISTA 解决「哪一层坏了」，FOSSIL 解决「这个判断凭什么可复现、可回滚、可被下游安全地 fork」。**

**灵感 5（VISTA 组件的原位升级）**
- **FIR → PBL**：有限假设后验 → 反事实版本重放 + 依赖层二分的组件定位。
- **固定 ℋ → QAR**：假设集不再离线写死；未知故障先隔离、发公告，分诊后才长成新假设。
- **RSC-V → RSC-S**：不再只分 r_geo/r_force/r_model，而是按组件版本 r_v 与共享祖先 r_u 定向膨胀，并用相关协方差聚合。
- **AFA → AFT**：探针目标从「故障假设互信息」升级为「组件版本可辨识性信息增益」。
- **CSC → CSC-S**：认证前缀绑定当前 lockfile/adapter 版本，任何版本切换即失效。
- **AIC-V → AIC-S**：干扰集增供应链攻击（投毒适配器、篡改标定、依赖混淆、SBOM 过期）。
- **OLP → 离线受控微调**：实时流零学习写进一步收紧为「运行中 artifact 不可变，学习只经发布」。
- **J_vista → J_fossil**：证书增 SBOM/lockfile 哈希、适配器证书、合并证书、来源链、公告集、重放哈希。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（FOSSIL 闭环）**：FOSSIL = (VISTA, SBM, SSV, CFA, SRR, MSC, PBL, CGM, QAR, RER/SCA, J_fossil)。定位：VISTA 的「可定位 + 可复现 + 可演化」升级。不变式：**运行中的每个组件都是已签名、版本化、锁定的 artifact；实时流零学习写；一切学习只经「分支→回归→合并→发布」的离线受控流程。**
- **定义 234（SBM 安全物料清单）**：有向无环图 S=(V,E,{C_v},{h_v},{ver_v},{prov_v})；v 为组件（几何先验、接触模型、视觉编码器、策略底座、适配器、标定表、似然模型、数据切片），边为依赖；C_v 为安全契约（前置/后置条件、运行包络 O_v、安全裕度 ρ_v、失效模式）；h_v 内容哈希；prov_v 来源。部署锁 L 钉住版本+哈希+证书。共享祖先 u∈Anc(v_i)∩Anc(v_j) 是**共因载体**。
- **定义 235（安全契约与安全语义版本 SSV）**：C_v=(Pre_v,Post_v,O_v,ρ_v,Fail_v)。patch=契约与包络不变、仅刷新证据；minor=契约不变、能力/包络扩展但需新证据；major=任何契约、包络、安全裕度或共享祖先变更 → 全链路重认证 + 下游 rebase。安全兼容 C_u ⪯ C_v 表示 v 至少承担 u 的全部安全义务。
- **定义 236（携带证书的微调适配器 CFA）**：冻结安全核 θ0，微调只在低秩子空间 Δθ=BA（rank r≪d）进行；目标 L_CFA=L_task(D_ft)+λ_t‖Δθ‖²+λ_s R_safe(θ0+Δθ;Z_safe)+λ_r L_replay(D_replay)。证书 J_ft=(hash(D_ft),r,δ_FT,Δρ_min,regression,J_prov)。
- **定义 237（函数漂移与安全遗忘界）**：δ_FT=sup_{z∈Z_ref}‖f_{θ0+Δ}(z)−f_{θ0}(z)‖；若安全裕度对函数输出 L-Lipschitz，则 ρ_ft(z)≥ρ_0(z)−Lδ_FT。安全遗忘 F_safe=max(0,ρ_0−ρ_ft)。
- **定义 238（安全回归注册表 SRR）**：追加式测试集 T={(z_i,φ_i)}；发布门 G=∧_i φ_i(θ0+Δ;z_i) ∧ δ_FT≤ε_FT ∧ 哈希/签名匹配 ∧ 无未决安全公告冲突。测试只增不减；删除测试需 major 版本 + 人工批准。
- **定义 239（安全零空间合并 MSC）**：J_s=∂ρ/∂θ|_{Z_safe}，安全零空间 N_s=ker J_s；Δ_m=P_{N_s}(Δ1+Δ2)。一阶安全变化为零，故合并对安全裕度的影响是二阶小量；残余用 L-Lipschitz 界兜底。
- **定义 240（反事实版本重放与溯源二分 PBL）**：给定运行时证据 e、SBOM S、锁 L，对节点 v 用其上一个已认证版本 v^- 做反事实重放，得 e^-_v；契约违反分数 s_v=D(e,e^-_v)−D(e,e_null)。沿依赖层做子集二分，单故障时 O(log|V|) 次重放定位。
- **定义 241（溯源可辨识性）**：线性化 e=Σ_v S_v θ_v+ε；J_prov 为 {S_v} 的块 Gram；κ_prov=λ_min(J_prov^TΣ^-1J_prov)/λ_max。κ_prov>0 时单故障定位误差 ≤exp(−nκ_prov/2)。若两个组件共享祖先或影响向量共线，J_prov 奇异 → 不可定位到叶节点，必须定位到**割**或隔离。
- **定义 242（共同祖先共因边缘化 CGM）**：Σ_e=Σ_indep+Σ_{u∈A}α_u b_u b_u^T。在叶假设之外增祖先假设 H_u，后验按 H_u 边缘化；α_u>τ_cc 时把不确定性膨胀到共享子树并触发 QAR，而不是假装独立。
- **定义 243（未知故障隔离与安全公告 QAR）**：PBL 不可定位时进入 quarantine（safe_idle/柔顺撤退/最小安全策略），冻结 lockfile，生成公告 adv=hash(e,S)，离线复现、分诊、补丁、加回归、升版本；**只有发布后新假设才进入 ℋ**，在线绝不强行归类。
- **定义 244（可复现证据重放 RER 与供应链证明 SCA）**：RER 由证据包（种子、传感日志、模型/代码/标定哈希）确定性重放计算图，得证书哈希 H(J)；SCA 对每个 artifact 验签并沿来源链核验。信任级 τ_v∈{upstream,local,experimental}；experimental 不得进安全关键路径。
- **定义 245（供应链攻击认证 AIC-S）**：ℰ_S 含投毒微调数据、后门适配器、篡改标定、依赖混淆、SBOM 过期/不完整、重放/时序错位；ρ_dir 在 ℰ_S 上重算，J_dir 增 sbom_hash、lockfile_hash、provenance_chain、advisory_set。
- **定义 246（RSC-S / WCV-S）**：按组件版本维护 r_v，按共享祖先维护 r_u；相关聚合 r_corr²=Σ_v r_v²+2Σ_uΣ_{i<j∈desc(u)}α_u r_i r_j；只膨胀被定位子树。搜索域增锁约束 𝕃：只允许 lockfile 中已签名且信任级足够的组件。
- **定义 247（J_fossil）**：J_fossil=(J_vista,sbom_hash,lockfile_hash,release_semver,adapter_cert,merge_cert,provenance_chain,advisory_set,replay_hash,cgm_corr,srr_ver,sca_ver)。Valid ⇔ Valid(J_vista) ∧ SBOM 完整且已签名 ∧ 发布过 SRR ∧ 适配器漂移≤ε_FT ∧ (已定位∨已隔离) ∧ 重放哈希可复现 ∧ 安全关键节点无未决公告 ∧ semver 可接受。
- **定义 248（FOSSIL 闭环算子）**：语义/离线流 [证据账本→SBM/lockfile→PBL/CGM→(未知则 QAR→离线分诊)→CFA 补丁微调→SRR→MSC→SSV 发布→SCA 签名→重部署→VISTA 运行时]；实时流 [锁定 artifact 执行→VISTA 证据采集→CSC-S 前缀→早停→证据账本追加]。

## 2. 关键算法骨架

def FOSSIL_release(theta0, D_ft, sbom, Z_safe, reg):
    adapter, J_ft = CFA.fit(theta0, D_ft, Z_safe, rank=8)      # 冻结安全核 + 低秩适配
    if not reg.gate(sbom, adapter, J_ft):                       # SRR：追加式回归
        return None, 'regression_blocked'
    semver = SSV.bump(sbom, adapter, J_ft)                      # 契约不变→minor/patch
    L_new = sbom.lock(adapter, J_ft, semver)
    SCA.sign(L_new)
    return L_new, 'released'

def FOSSIL_runtime(M, obs):
    e = M.vista.capture(obs)                                    # 实时：只采证，不学习
    if not M.csc_s.monitor(e).abort:
        return M.pinned_artifact.step(obs)                      # 锁定 artifact 执行
    v, conf, status = PBL.localize(e, M.sbom, M.lock, M.replay) # 语义流：溯源二分
    if status != 'localized':
        u = CGM.shared_ancestor(e, M.sbom)                      # 共因？
        if u is not None:
            M.rsc_s.inflate_subtree(u, M.cgm.alpha(u))
        pi_safe, adv = QAR.quarantine(e, M.sbom, M.lock)        # 诚实隔离，不强行归因
        return pi_safe.step(obs), adv
    M.rsc_s.inflate_component(v)                                # 只膨胀被定位的组件
    return M.pinned_artifact.step_safe(obs), v
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（CFA 的安全保持）**：若 Z_safe⊆Z_ref 且 ρ 对函数输出 L-Lipschitz，则对任意 z∈Z_safe，ρ_ft(z)≥ρ_0(z)−Lδ_FT；发布门取 ε_FT≤(ρ_min−ρ_req)/L 即保证参考集上的裕度不破。**注意：这是参考集上的界；跨分布需 conformal 与 OOD 门，不能外推。**
- **引理 10（溯源可辨识与二分代价）**：单故障下，留一版本重放的残差下降在真实节点唯一最大，间隙 ≥cκ_prov θ_min²；沿依赖层二分 O(log|V|) 次重放即可定位。若多故障/共享祖先导致 S_v 共线，最大不唯一 → 判 composite，转 CGM/QAR（这正是 VISTA 风险的出口）。
- **引理 11（共因协方差不被低估）**：Σ_e ⪰ Σ_indep（半正定序）；只用独立协方差会低估尾部、使证书覆盖率 <1−α；CGM 对已声明祖先做边缘化可恢复覆盖率。**未声明祖先 = 不可恢复，落为 A94 风险。**
- **定理 9（FOSSIL 端到端）**：在 A94–A99 下，Valid(J_fossil) ⇒ 每个部署 artifact 已锁定/签名/版本化；每次能力变化都是漂移有界、回归通过的适配器；每次故障要么定位到声明节点、要么隔离，绝不强行归因；共享祖先共因被 CGM 处理；未知故障只经离线分诊和发布长成新假设；任意时刻可回滚到上一个已认证 lockfile。
- **定理 10（安全单调性与可复现发布）**：发布序列在固定参考集上的最小安全裕度非减（每次发布强制 m_t≥m_{t−1} 且测试只增）；相同证据包+lockfile ⇒ 相同证书哈希，故第三方可重放、审计、fork。能力不保证单调，维护 Pareto 前沿；跨分布无保证 → OOD 门/隔离。
- **命题（局部重认证的代价）**：全栈重认证 O(|V|)；定位到叶节点后只需 O(log|V|) 次重放 + O(1) 重认证，定位到祖先则重认证其子树 O(|subtree(u)|)。相比 VISTA 的全球膨胀，FOSSIL 只膨胀/重认证被定位子树。
- **实时性**：adapter 前向 O(rd)（r≪d，目标 <0.1ms）；PBL/CGM/SRR/MSC/CFA 全在离线/语义流；实时流仍只做证据采集、CSC-S 早停与定版执行，零学习写，目标仍 ≤2.5ms（继承 A93）。

## 5. 本轮最大风险

**一句话**：FOSSIL 的全部保证都建立在「SBOM 完整且诚实、证据可复现、安全参考集与真实部署分布可交换」这三个前提上；而在真实开源生态里，未声明的共享依赖/数据、被投毒的适配器、过期的参考集恰恰是常态，于是一份在参考集上完美通过的发布证书，可能只是在为一条从未被审计过的供应链签名——**系统会把「证书已签」误当成「供应链已审」，这比 VISTA 的归因错误更危险，因为它把错误固化成了可复现、可分发、可被下游 fork 的「官方版本」。**

# 第 66 轮产物 · 创新点清单 v5：FOSSIL（Forkable Open-Source Safety with Incremental Learning：安全物料清单 × 安全语义版本 × 携带证书的微调适配器 × 安全回归发布门 × 零空间合并 × 溯源二分 × 共因边缘化 × 隔离公告 × 可复现证据）

> 承接第 65 轮 IP-214~223（VISTA：VPG×ACH×FIR×VCV×VSP/AFA×CSC×RSC-V×WCV-V×CSP-V×AIC-V×J_vista）。第 65 轮把几何先验变成「可证伪」，再把可证伪升级为「可归因」；其最大风险是**在封闭假设集内强行归因**，且视觉与几何可能共享同一个 OOD 失效源。本轮不再增加假设，而是把安全从「一次性的因果诊断」升级为「开源软件式的供应链治理」：SBOM 让依赖与共因显式，semver 让变更可兼容，lockfile 让部署可回滚，bisect 让故障可定位，可复现构建让证据可审计；「微调」则被改造成携带证书的受控变更，而不是安全擦除的黑箱。核心是 **「定位不成就隔离，合并必须先过门，能力更新不得偷偷降安全」**。
>
> IP 编号：IP-224~IP-233（共 10 个），全部为 VISTA/GRIP 组件的原位升级或挂载式新增。

## 2. 形式化定义（完整版）

**定义 233（FOSSIL 闭环）** FOSSIL 是 VISTA 的「可定位 + 可复现 + 可演化」升级：在 VISTA 的「语义流 ∘ 实时流」骨架上挂载 SBM（安全物料清单）、SSV（安全语义版本）、CFA（携带证书的微调适配器）、SRR（安全回归注册表）、MSC（安全零空间合并）、PBL（溯源二分定位）、CGM（共同祖先共因边缘化）、QAR（隔离与公告）、RER/SCA（可复现证据与供应链证明），并原位升级 FIR→PBL、RSC-V→RSC-S、AFA→AFT、CSC→CSC-S、AIC-V→AIC-S、J_vista→J_fossil。不变式：**运行中的每个组件都是已签名、版本化、锁定的 artifact；所有学习发生在离线的「分支→回归→合并→发布」流程；实时流零学习写，只执行锁定 artifact 并采集证据。**

**定义 234（SBM 安全物料清单）** 安全物料清单是有向无环图
S=(V,E,{C_v},{h_v},{ver_v},{prov_v})，
其中 V = V_geo ∪ V_contact ∪ V_vis ∪ V_policy ∪ V_adapter ∪ V_calib ∪ V_lik ∪ V_data；边 (u,v)∈E 表示 v 依赖 u。每个节点携带：安全契约 C_v；内容哈希 h_v=H(artifact bytes ⊕ config ⊕ seed)；语义版本 ver_v；来源 prov_v=(origin repo, commit, license, signer, parent versions)。部署锁为
L={(v, ver_v, h_v, sig_v, τ_v) : v∈V}。
记 Anc(v) 为 v 的传递依赖集；共享祖先集 A={u : u∈Anc(v_i)∩Anc(v_j)，v_i≠v_j}。**SBOM 完整性（A94）**：所有运行时可到达的组件与数据切片都必须在 V 中有声明节点；未声明的共享数据/模型即供应链违规。

**定义 235（安全契约与安全语义版本 SSV）** 契约 C_v=(Pre_v, Post_v, O_v, ρ_v, Fail_v)，其中 ρ_v:Z→ℝ 为标量安全裕度（力/滑移/几何裕度的最小值）。称 C_u ⪯ C_v（v 至少和 u 一样安全）当且仅当
∀z∈O_u∩O_v：ρ_v(z) ≥ ρ_u(z)，且 Post_v ⇒ Post_u。
语义版本规则：
- **patch**：C_v、O_v、Anc(v) 均不变，仅刷新证据/实现；需要重新过 SRR，但不需要下游 rebase；
- **minor**：C_v 不变，O_v 或能力扩展；需要新证据与新增回归，但不需要全链路重认证；
- **major**：Pre_v/Post_v/O_v/ρ_v 或 Anc(v) 任一变化；需要全链路重认证、下游 lockfile rebase 与人工批准。
发布可接受性：patch/minor 需 C_old ⪯ C_new；major 必须显式重认证所有受影响的子树。

**定义 236（携带证书的微调适配器 CFA）** 把参数分为安全核与可适配部分 θ=(θ_safe, θ_adapt)，冻结 θ_safe，只在低秩子空间更新
Δθ = B A，B∈ℝ^{d×r}，A∈ℝ^{r×k}，r≪d。
微调目标
L_CFA = L_task(D_ft) + λ_t‖Δθ‖² + λ_s R_safe(θ0+Δθ; Z_safe) + λ_r L_replay(D_replay)，
其中 R_safe=Σ_{z∈Z_safe} max(0, ρ_req−ρ(z;θ0+Δθ))²，D_replay 为历史安全临界样本回放。适配器证书
J_ft=(hash(D_ft), r, δ_FT, Δρ_min, regression vector, provenance)。
**适配器身份** I_ft=H(θ0.hash, A, B, D_ft.hash, config)：任何字节变化都会改变身份，从而必须重新签名与发布。

**定义 237（函数漂移与安全遗忘界）** 定义
δ_FT = sup_{z∈Z_ref}‖f_{θ0+Δ}(z) − f_{θ0}(z)‖。
若安全裕度 ρ 对函数输出满足 L-Lipschitz，则对 z∈Z_safe
ρ_ft(z) ≥ ρ_0(z) − L·δ_FT。
令安全遗忘 F_safe=max(0, ρ_0−ρ_ft)，能力增益 ΔCap 为目标任务上的成功率提升。发布采用 **Pareto 可接受性**：若 F_safe>β_safe，则必须走 major 版本 + 人工批准；否则在 (ΔCap, −F_safe) 前沿上选择，不允许多个 minor 版本累积出未申报的安全退化。

**定义 238（安全回归注册表 SRR）** 回归测试集 T={(z_i, φ_i)}，φ_i 为可判定的安全性质（力限、滑移界、禁触区、几何裕度、接触稳定性等）。发布门
G(S, Δ) = ∧_i φ_i(θ0+Δ; z_i) ∧ (δ_FT≤ε_FT) ∧ (hash/signature 匹配) ∧ (安全关键节点无未决公告冲突) ∧ (semver 可接受)。
T 是**追加式**的：新故障必须新增测试；删除测试需 major 版本 + 人工批准。发布后还可进入 **canary**：在少量机器人/子任务上部署，监测证据流；若 CUSUM 检测到安全裕度回归则自动回滚到上一个 lockfile。

**定义 239（安全零空间合并 MSC）** 设安全临界 Jacobian J_s=∂ρ/∂θ|_{Z_safe}（在安全参考点上堆叠）。定义岭稳定的安全零空间投影
P = I − J_sᵀ(J_s J_sᵀ + λI)⁻¹J_s。
两个适配器的合并为 Δ_m=P(Δ1+Δ2)。若 J_sΔ_m=0，则安全裕度的一阶变化为零，余项为二阶：
|ρ(θ0+Δ_m)−ρ(θ0)| ≤ ½L_H‖Δ_m‖² + o(‖Δ_m‖²)。
若岭项导致一阶残差 ε_m=‖J_sΔ_m‖，则
ρ ≥ ρ_0 − L·ε_m − ½L_H‖Δ_m‖²。
**合并证书** J_merge=(ε_m, 二阶界, 两适配器身份, 冲突契约, 回归结果)。若两适配器的安全包络/契约冲突，合并视为 major 变更，必须全链路重认证。

**定义 240（反事实版本重放与溯源二分 PBL）** 给定运行时证据 e（VISTA 阶段签名 ρ 及证据账本）、SBOM S、锁 L。对任意节点子集 X⊆V，定义反事实重放：把 X 中节点替换为上一个已认证版本（或名义版本），在同一条记录输入上确定性重执行计算图（RER），得到 e^-_X；定义残差
R(X)=D(e, e^-_X)，D 为 Σ_e 下的马氏距离。
单故障定位分数
s_v = R(∅) − R({v})。
**二分定位**：在 DAG 的平衡割 (X,Y) 上比较 R(X) 与 R(Y)，把包含真实故障的一侧保留为新的 V，重复；单故障、影响可加且非共线时 O(log|V|) 次重放即可定位到节点。若 max_v s_v<τ_prov，或前两名差距<τ_gap，则判 `composite_or_unknown`，进入 CGM/QAR。

**定义 241（溯源可辨识性）** 线性化证据
e = Σ_{v∈V} S_v θ_v + ε，ε∼N(0,Σ)，
其中 θ_v 为组件 v 的契约偏差幅度，S_v 为其影响矩阵。令块设计 S=[S_1,…,S_n]，溯源 Fisher
J_prov = SᵀΣ⁻¹S（按块分块）。
若所有对角块 S_vᵀΣ⁻¹S_v≻0，且块间交叉项不造成稀疏恢复歧义，则单故障可辨识；可辨识裕度
κ_prov = λ_min(J_prov) / λ_max(J_prov)（在归一化块 Gram 上定义）。
Laplace 近似下，单故障定位错误率 ≤ exp(−n·κ_prov/2)。
**关键退化**：若 v_i、v_j 共享祖先 u，则 S_{v_i}、S_{v_j} 都含共同的 b_u 方向，J_prov 秩亏；此时正确的估计量是祖先偏差 θ_u，而不是两个叶节点的独立偏差。这正是 VISTA 独立性假设失效的形式化版本。

**定义 242（共同祖先共因边缘化 CGM）** 把证据模型扩展为
e = Σ_v S_v θ_v + Σ_{u∈A} b_u ψ_u + ε，
其中 ψ_u 为共享祖先 u 的偏差，b_u 为其影响向量。离线用故障注入或图重叠估计
α_u = ‖b_u‖² / σ²（或等级相关系数）。
相关证据协方差
Σ_e = Σ_indep + Σ_{u∈A} α_u b_u b_uᵀ ⪰ Σ_indep。
在叶假设之外增加祖先假设 H_u；后验
P(H_u|e) ∝ p(e|H_u)P(H_u)，
并按 H_u 对叶后验边缘化。若 α_u>τ_cc，则：(i) 不把后代节点当独立故障；(ii) 把不确定性膨胀到共享子树 r_u；(iii) 若 u 是已声明的 upstream 组件，升级为上游 issue 并 pin 回上一版本；(iv) 若 u 未声明，判供应链违规，触发 QAR + SCA 审计。

**定义 243（未知故障隔离与安全公告 QAR）** 当 PBL 返回 `composite_or_unknown` 时，进入隔离态 Q：
1. 冻结当前 lockfile L，禁止任何在线参数写入；
2. 切换到**最小安全策略** π_safe（safe_idle / 柔顺撤退 / 有界保持），其证书只依赖最近一次 known-good lockfile L_good 中未被怀疑的组件；
3. 生成安全公告 adv=H(e,S,L,timestamp)，保存证据包；
4. 离线分诊流水线：RER 复现 → PBL 定位 → 根因分析 → 补丁/新适配器 → 新增回归测试（追加进 T）→ semver 升版 → SRR 发布门 → SCA 签名 → 新 lockfile；
5. **只有发布之后**，新故障假设才进入 ℋ 与 SBOM；在线阶段绝不把未知故障强行归入旧假设。
若怀疑集覆盖所有可用组件，则落入 Lockout + 人类接管（吸收安全态）。

**定义 244（可复现证据重放 RER 与供应链证明 SCA）** 证据包
B=(sensor logs, actions, timestamps, seeds, RNG states, model hashes, calibration, code commit, environment)。
RER(B,L) 确定性执行语义/离线流水线并返回证书 J；可复现性要求
(B≡B′) ∧ (L≡L′) ⇒ H(J)=H(J′)。
对非确定性硬件，记录所有非确定输入，用区间/容差重放，证书显式记录容差。SCA 对每个 artifact 验证签名 sig_v 与来源链 origin→…→deployment，并检查：哈希不符、依赖混淆（同名不同源）、SBOM 过期、签名吊销、未声明的共享数据。信任级 τ_v：upstream（上游认证）、local（本队认证）、experimental（实验；不得进入安全关键路径）。

**定义 245（供应链攻击认证 AIC-S）** 干扰集
ℰ_S = ℰ_V × ℰ_ft × ℰ_supply，
ℰ_ft 含投毒示范、后门触发器、恶意 LoRA、秩/合并漏洞；ℰ_supply 含篡改标定/似然、依赖混淆、伪造/过期 SBOM、签名吊销、证据账本重放。ρ_dir 在 ℰ_S 上重算，J_dir 增 sbom_hash、lockfile_hash、provenance_chain、advisory_set。**认证不要求检出所有攻击；它要求被污染的 artifact 无法以安全关键身份通过 SCA/SRR 并进入 lockfile。**

**定义 246（RSC-S / WCV-S）** 维护组件版本半径 r_v 与共享祖先半径 r_u。PBL 定位到 v 时只膨胀 r_v 并只重认证 subtree(v)；CGM 定位到 u 时膨胀 r_u 并联合膨胀所有后代。相关聚合半径
r_corr² = Σ_{v∈V_safe} r_v² + 2Σ_{u∈A}Σ_{i<j∈desc(u)} α_u r_i r_j，
替代 VISTA 的 r=√(r_geo²+r_force²+r_model²)（后者隐含三者独立）。搜索域
B(φ̂,r_corr) ∩ 𝒢(g) ∩ K(μ̂) ∩ ℱ(f_lim) ∩ 𝒱 ∩ 𝕃，
其中 𝕃 只允许 lockfile 中已签名且信任级足够的组件。

**定义 247（J_fossil）** 
J_fossil=(J_vista, sbom_hash, lockfile_hash, release_semver, adapter_cert, merge_cert, provenance_chain, advisory_set, replay_hash, cgm_corr, srr_ver, sca_ver)。
验证规则：
Valid(J_fossil) ⇔
Valid(J_vista)
∧ SBOM 完整且全部签名可验
∧ 发布已通过 SRR（含追加式回归）
∧ 适配器漂移 δ_FT≤ε_FT 且 J_ft 身份与部署一致
∧ （故障已定位 ∨ 已进入 QAR 隔离）
∧ RER 重放哈希可复现
∧ 安全关键节点无未决公告冲突
∧ semver 可接受 ∧ 供应链证明有效。
审计链新增：为何部署这个版本（release_semver）、为何相信这个适配器（adapter_cert）、为何合并（merge_cert）、故障定位到谁或为何隔离（PBL/QAR）、证据能否重放（replay_hash）。

**定义 248（FOSSIL 闭环算子）** 语义/离线流：
[证据账本 → SBM/lockfile → PBL/CGM 定位 → (未知则 QAR 隔离 → 离线分诊) → CFA 补丁微调 → SRR 发布门 → MSC 合并 → SSV 发布 → SCA 签名 → 重部署 → VISTA 运行时]。
实时流：

### IP-224/225 SBM + SSV（物料清单与语义版本）

class SafetyBOM:
    def __init__(self, nodes, edges, contracts, hashes, versions, provenance):
        self.V, self.E = nodes, edges
        self.C, self.h, self.ver, self.prov = contracts, hashes, versions, provenance
        self.anc = transitive_closure(nodes, edges)

    def shared_ancestors(self):
        return {u for u in self.V if sum(u in self.anc[v] for v in self.V) >= 2}

    def lock(self, artifact_map, cert_map, semver_map):
        return {v: {'ver': semver_map[v], 'hash': H(artifact_map[v]),
                    'sig': sign(artifact_map[v]), 'cert': cert_map[v],
                    'trust': self.prov[v].trust}
                for v in self.V}

    def bump(self, changed, delta):
        if delta.major or (self.anc[changed] & self.shared_ancestors()):
            return bump_major(changed)
        if delta.minor:
            return bump_minor(changed)
        return bump_patch(changed)
```

### IP-226 CFA（携带证书的微调适配器）

```python
class CertifiedFineTune:
    def fit(self, theta0, D_ft, Z_safe, D_replay, rank=8,
            eps_FT=1e-3, rho_min=0.2, lam=(1.0, 1.0, 1.0)):
        theta0.freeze_safety_core()
        A, B = init_low_rank(rank)
        for step in range(T):
            delta = B @ A
            loss = task_loss(theta0 + delta, D_ft)
            loss += lam[0] * (delta.norm() ** 2)
            loss += lam[1] * safety_penalty(theta0 + delta, Z_safe, rho_min)
            loss += lam[2] * replay_loss(theta0 + delta, D_replay)
            update(A, B)
        delta_FT = max_norm_drift(theta0, theta0 + B @ A, Z_ref)
        margin = min_margin(theta0 + B @ A, Z_safe)
        J_ft = {'r': rank, 'delta_FT': delta_FT, 'margin': margin,
                'regression': evaluate_regressions(theta0 + B @ A),
                'identity': H((theta0.hash, A, B, D_ft.hash)),
                'provenance': provenance(D_ft)}
        return Adapter(theta0, B @ A), J_ft
```

class SafetyRegressionRegistry:
    def __init__(self, tests):
        self.tests = list(tests)

    def gate(self, sbom, adapter, J_ft):
        if not sbom.verify_lock_and_signatures():
            return False
        if J_ft['delta_FT'] > EPS_FT or J_ft['margin'] < RHO_REQ:

    def add_test(self, z, phi):

### IP-228 MSC（安全零空间合并）

```python
def merge_safety(d1, d2, J_s, L_H, L, lam=1e-6):
    G = J_s @ J_s.T + lam * np.eye(J_s.shape[0])
    P = np.eye(J_s.shape[1]) - J_s.T @ np.linalg.solve(G, J_s)
    dm = P @ (d1 + d2)
    eps_first = float(np.linalg.norm(J_s @ dm))
    bound = 0.5 * L_H * float(np.linalg.norm(dm) ** 2) + L * eps_first
    return dm, {'eps_first': eps_first, 'delta_margin_bound': bound,
                'identity': H((d1, d2, J_s, lam))}
```

### IP-229 PBL（溯源二分定位）

```python
class ProvenanceBisection:
    def localize(self, e, sbom, lock, replay):
        V = set(sbom.V)
        while len(V) > 1:
            X, Y = balanced_cut(V, sbom.E)          # 依赖图上的平衡割
            rX = replay.residual(e, replace=X, sbom=sbom, lock=lock)
            rY = replay.residual(e, replace=Y, sbom=sbom, lock=lock)
            V = X if rX < rY else Y
        v = next(iter(V))
        conf = replay.reduction(e, {v}, sbom, lock)
        if conf < TAU_PROV:
            return None, conf, 'composite_or_unknown'
        return v, conf, 'localized'
```

### IP-230 CGM（共同祖先共因边缘化）

```python
class CommonCauseMarginalizer:
    def marginalize(self, e, sbom, post_leaf):
        A = sbom.shared_ancestors()
        post_anc, alpha = {}, {}
        for u in A:
            alpha[u] = estimate_alpha(e, u, sbom)   # 由注入/图重叠估计
            if alpha[u] > TAU_CC:
                post_anc[u] = ancestor_likelihood(e, u)
        if not post_anc:
            return post_leaf, None, alpha
        u_star = max(post_anc, key=post_anc.get)
        post = marginalize_leaf(post_leaf, post_anc, sbom)
        return post, u_star, alpha
```

### 4.1 开源机制与机器人安全的严格对应

| 开源软件机制 | 机器人安全对应 | 组件 | 可证伪预测 |
|---|---|---|---|
| SBOM | 组件/数据版本 DAG + 安全契约 | SBM | 移除/隐瞒共享依赖会显著降低定位率与证书覆盖率 |
| semver | 契约兼容与重认证等级 | SSV | 违反 semver 的变更会通过 SRR 造成可测的安全回归 |

### 4.2 引理 9（CFA 的安全保持）

设安全裕度 ρ(z;f) 对函数输出满足 L-Lipschitz：|ρ(z;f)−ρ(z;g)|≤L‖f(z)−g(z)‖。令 δ_FT=sup_{z∈Z_ref}‖f_{θ0+Δ}(z)−f_{θ0}(z)‖，且 Z_safe⊆Z_ref。则对任意 z∈Z_safe，
ρ(z;θ0+Δ) ≥ ρ(z;θ0) − L‖f_{θ0+Δ}(z)−f_{θ0}(z)‖ ≥ ρ_0(z) − Lδ_FT。
若发布门要求 δ_FT ≤ ε_FT=(ρ_min−ρ_req)/L，则 ρ(z;θ0+Δ)≥ρ_req。∎

**边界说明**：该界只在 Z_ref 上成立；若部署分布偏离 Z_ref，Lipschitz 界不能外推。因此 CFA 必须与 OOD 门/conformal 尾界配合，跨分布时退回 QAR。这是本轮不隐藏的假设（A95）。

### 4.3 引理 10（溯源可辨识与二分代价）

线性模型 e=Σ_v S_vθ_v+ε，ε∼N(0,Σ)。设真实故障只在 v*，幅度 ‖θ_{v*}‖≥θ_min。反事实替换集合 X 后的残差为
R(X)=‖Σ^{-1/2}(e−Σ_{v∉X}S_vθ_v)‖²。
则 R({v*})=‖Σ^{-1/2}ε‖² 最小；对任意不含 v* 的 X，
R(X)−R({v*}) = ‖Σ^{-1/2}S_{v*}θ_{v*}‖² ≥ λ_min(S_{v*}ᵀΣ^{-1}S_{v*})θ_min² ≥ cκ_provθ_min²。
故留一版本残差下降在 v* 唯一最大，间隙 ≥cκ_provθ_min²。

二分：在平衡割 (X,Y) 上，替换含 v* 的一侧会移除故障项，残差更小；替换另一侧残差仍高。因此每层比较 2 次重放即可把候选集减半，总重放次数 O(log|V|)。当 S_{v_i}、S_{v_j} 共线（共享祖先/多故障）时，上式间隙为 0，最大不唯一 → 必须判 `composite_or_unknown`，转 CGM/QAR。∎

### 4.4 引理 11（共因协方差不被低估）

由 Σ_e=Σ_indep+Σ_{u∈A}α_u b_ub_uᵀ 且 α_u≥0，有 Σ_e−Σ_indep 半正定，故 Σ_e⪰Σ_indep。对任意方向 w，wᵀΣ_ew≥wᵀΣ_indepw，真实尾部分位数不低于独立假设下的分位数。若证书用 Σ_indep 标定阈值 t，则真实越界概率大于名义 α，覆盖率 <1−α。CGM 用完整的 Σ_e（对已声明祖先）做 CVaR 与边缘化，可恢复名义覆盖率；若存在未声明祖先，则 Σ_e 本身错设，任何证书都无法保证——这正是 A94/最大风险的来源。∎

### 4.5 定理 9（FOSSIL 端到端）

在 A94–A99 下（A94 SBOM 完整；A95 参考集覆盖与 OOD 门；A96 重放确定性/容差；A97 安全裕度 Lipschitz；A98 单故障可辨识或隔离；A99 发布门与签名不可绕过），若 Valid(J_fossil) 成立，则：
1. **部署可审计**：每个运行中的 artifact 都有版本、哈希、签名、来源链，且在 lockfile 中锁定；
2. **能力更新受控**：每次能力变化都来自 CFA，满足 δ_FT≤ε_FT、安全回归通过、适配器身份与部署一致；
3. **故障不强行归因**：每次运行时故障要么被 PBL 定位到已声明组件版本，要么进入 QAR 隔离；不存在「未知故障被塞进最近假设」的路径；
4. **共因被显式处理**：已声明的共享祖先由 CGM 边缘化，后代不被当作独立证据；未声明共享祖先触发供应链违规与隔离；
5. **开放世界安全生长**：未知故障只经离线分诊、新增回归、semver 发布后才进入 ℋ 与 SBOM，在线假设集不增长；
6. **可回滚**：任意时刻保留上一个已认证 lockfile，回滚不依赖重新训练；
7. **可复现**：相同证据包与 lockfile 产生相同证书哈希，第三方可重放、审计、fork。
∎

### 4.6 定理 10（安全单调性与可复现发布）

设发布序列 R_1,…,R_T 均通过 SRR。定义固定安全参考集 Z_safe 上的最小裕度 m_t=min_{z∈Z_safe}ρ(z;θ_t)。SRR 要求每次发布 m_t≥m_{t−1}，且测试集只增不减；因此可行安全约束集合随 t 单调收缩，归纳得 m_1≤m_2≤…≤m_T。即**固定参考集上的安全裕度非减**。

可复现性：RER 是确定性函数（或记录全部非确定输入并给出容差），故 (B,L) 相同 ⇒ H(J) 相同；证书可被任何第三方独立重算。能力不保证单调（任务间存在 trade-off），只能维护 (ΔCap, −F_safe) 的 Pareto 前沿；若新分布超出 Z_ref，则无安全单调性保证，必须走 OOD 门与 QAR。∎

### 4.7 命题（局部重认证有界过度保守）

全栈重认证代价 C_full=O(|V|·C_cert)。PBL 定位到节点 v 后，只需重认证 subtree(v) 并在 subtree(v) 的祖先路径上重新聚合半径，代价
C_loc(v) = O(log|V|·C_replay + |subtree(v)|·C_cert)。
若 v 是叶节点，C_loc=O(log|V|·C_replay+C_cert)≪C_full；若 v 是根附近祖先，退化为全栈重认证，但这正对应真实的共因大范围失效。相比 VISTA 对任意拒绝都膨胀单一 r，FOSSIL 只膨胀被定位子树，体积膨胀从 κ^{d_φ} 降为 Σ_{v∈subtree} κ^{d_v}，对叶故障近似 O(1) 个组件的膨胀。∎

### 4.8 实时性说明

CFA 前向只增加低秩矩阵乘 O(rd)，r 取 4–16，目标 <0.1ms；PBL/CGM/SRR/MSC/CFA 训练与离线分诊全部在语义流/离线线程。实时流仍只做 VISTA 证据采集（视觉 ROI <0.2ms、阶段判定 <0.05ms）、CSC-S 早停（<0.02ms）与定版 artifact 派发；目标 ≤2.5ms（继承 A93），且**实时流零学习写**被进一步收紧为 **artifact 不可变**。

| E252 | 能力 +15~30%，裕度降 <2% | 裕度降 >5%：CFA 信任域/安全回放不足 |

| E254 | 单故障定位 ≥90%，强行归因 ≤5% | 定位 ≤70%：溯源图/影响矩阵不可辨识 |

| E256 | 隔离 100%，违规 0，分诊 ≤48h | 出现任何强行归因或越界：QAR 触发条件太松 |
| E257 | 哈希一致 100%，篡改检出 ≥99% | 一致 <90%：重放不确定性未建模 |
| E258 | 攻击检出 ≥95%，实验件 0 | 检出 <80%：SCA 信任根不足 |
| E259 | 成功率 +20%，安全违规 0 | 不优于 VISTA：供应链层无净收益 |
| E260 | 回滚 ≤2s，无死锁，链一致 | 回滚 >10s 或链不一致：lockfile/证书设计失效 |

## 8. 已知风险

**一句话**：FOSSIL 的全部保证都建立在「SBOM 完整且诚实、证据可复现、安全参考集与真实部署分布可交换」这三个前提上；而在真实开源生态里，未声明的共享依赖/数据、被投毒的适配器、过期的参考集恰恰是常态，于是一份在参考集上完美通过的发布证书，可能只是在为一条从未被审计过的供应链签名——**系统会把「证书已签」误当成「供应链已审」，这比 VISTA 的归因错误更危险，因为它把错误固化成了可复现、可分发、可被下游 fork 的「官方版本」。**

**次级风险与缓解**：
1. **SBOM 不完整/不诚实**：未声明的共享数据或上游 commit 是最危险的共因；缓解：把 SBOM 完整性作为发布硬门（A94），运行时对未声明依赖做来源审计，发现即隔离；但无法证明「没有未声明依赖」。
2. **可复现性与硬件非确定性**：真机传感器/时序/RNG 难以逐位复现；缓解：记录全部非确定输入、用容差与区间重放，证书显式声明容差；对不可重放的部分降级为「统计可复现」而非「逐位可复现」。
3. **参考集与部署分布失配**：δ_FT 只在 Z_ref 上有意义；缓解：OOD 检测 + conformal 尾界 + canary；跨分布时禁用「安全单调性」外推，直接走 QAR。
4. **溯源二分在多大故障/深 DAG 下退化**：多故障、共线影响、非线性接触会让二分误判；缓解：先做单故障检测（残差间隙），不满足即判 composite；对大 DAG 用依赖层限制搜索。
5. **共同祖先系数 α_u 难估**：α_u 依赖注入覆盖与图重叠，未注入的祖先可能被低估；缓解：把 α_u 视为证据而非真值，保守取上界；未声明祖先直接判供应链违规。
6. **微调漂移界的局部性**：Lipschitz/一阶界在强非线性安全临界点（接触切换、滑移）可能失效；缓解：把安全回放集覆盖到这些临界点，使用分段 Lipschitz 与二阶项；仍失效则拒绝发布。
7. **QAR 过度保守影响活性**：频繁隔离会让机器人「什么都不做」；缓解：最小安全策略 + 人类接管 + 分诊 SLA；把隔离时间作为与安全性并列的指标（E256/E260）。
8. **供应链信任根与密钥管理**：SCA 的安全性取决于签名根；根被攻破则整条链失效；缓解：硬件根/多方签名/离线根，定期轮换；把「根被攻破」列为不可完全消除的残余风险。
9. **零空间合并可能过度限制能力**：J_s 的零空间可能很小，导致合并后两个任务都学不好；缓解：允许带残差的软投影，并用二阶界 + SRR 决定是否接受；若残差过大则退化为顺序发布而非合并。
10. **认证只保证「污染件不能进安全关键路径」，不保证检出所有攻击**：这是设计边界而非缺陷；必须与运行时 VISTA、监控和人类接管叠加，不能把证书当绝对安全证明。
