# 第 43 轮（新循环第 3 轮） · 从「飞轮」到「闭环」：证书生命周期的可镇定控制与 Sim-in-the-Loop 回路认证（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉导致证书静默失效」。但更根本的问题在于：v19 所谓「飞轮」其实只是一条**单向流水线**——漂移触发 → Sim 重跑 → KB 更新 → 边缘热更新，全程没有误差信号、没有反馈增益、没有延迟补偿、没有稳定性判据，更没有「放松」动作。它把控制论里最容易出事的环节（正反馈 + 饱和 + 死区时间）当成了理所当然。本轮灵感词「闭环控制」正是要补上这一课：把证书生命周期显式建模为一个**离散时间反馈系统**，给出回路增益、镇定条件、抗积分饱和、延迟补偿与回路 Lyapunov 证明；灵感词「Isaac Sim」则从「验证证书」升级为「验证回路本身」——用 Sim-in-the-Loop（SIL）把整条「监控→触发→重跑→入库→热更新」放进仿真里跑阶跃/斜坡/脉冲漂移，测调节时间、超调、极限环，产出**回路证书**（meta-certificate）。一句话：v19 让证书「能进化」，v20 要证明证书系统「进化得稳定、不振荡、不越权收紧」。

## 0. 直觉与动机

**灵感 1（闭环控制 → 把「飞轮」拆成被控对象 / 误差 / 控制器 / 执行器）**：v19 的漂移触发只做了「检测到就收紧」，这是一个**纯比例、单向、无参考**的开环动作。真实的证书闭环至少要有四个部件：(1) **被控对象** = 部署环境 + 证书参数 → 观测到的真实边际与可用性；(2) **双通道误差** = 安全误差 `s_t = max(0, θ_t − m_min,t)`（正向：证书比真实安全界还松，危险）与可用性误差 `e_t = r − a_t`（反向：证书过紧，宏观上表现为 Nominal 占比掉到目标 r 以下）；(3) **控制器** = 前馈（RAG 检索模板/经验增益）+ 反馈（漂移触发修正），带增益调度与速率限幅；(4) **执行器** = 阈值、KB 模板、L0 表、学生网络权重的**双向**更新（既能收紧也能**释放**）。直觉上，证书系统像空调：只有「制冷」没有「制热」且没有温度计反馈，房间只会越来越冷，直到把机器人冻进 SafeStop——这正是第 41 轮「可用性崩塌」在 v19 里的新变体：**保守性棘轮（ratchet）**。

**灵感 2（闭环控制 → 承认「保守性会积分饱和」，必须发许可证才能放松）**：v19 的合并规则全是单向单调的（守卫取合取、阈值取 max、L_m 取 max、T_hold 取 min），每轮更新只会更保守。反馈系统里这叫**积分饱和（windup）**：执行器长期顶在上限，积分项越积越大，一旦条件允许也回不来。因此本轮引入**保守性账本**（双记账：每次收紧记一笔「负债」，每次带证据的放松记一笔「偿还」）与**双向释放算子**：只有在新证据 `E_t`（实机标定 + 仿真回归 + 形式化重证）足以重新导出 soundness 时，才允许把阈值/KB 模板**定向放松**，且放松幅度受速率与安全下界约束。没有释放通道的闭环，本质上是一个单边饱和系统，稳定性和可用性不可兼得。

**灵感 3（Isaac Sim → 不只验证证书，而是验证「回路」）**：v19 用 Isaac Sim 跑单条证书的压力测试；本轮把**整个闭环控制器**放进环里：Isaac Sim 扮演「可编程的现实」，按脚本注入阶跃漂移（+0.5σ 摩擦骤降）、斜坡漂移（缓慢老化）、脉冲扰动（突发遮挡/丢包），让「监控器→触发→Sim 重跑→CKB 入库→ECR 热更新」真实地跑起来，测四个控制指标：**调节时间（settling）、超调（overshoot）、稳态误差、极限环（limit cycle）**。这产出的是「回路证书」：不仅保证每条边安全，还保证证书系统在漂移下**收敛而非自激**。同时用真实日志回放做 HIL（hardware-in-the-loop），让仿真里的延迟、抖动、量化误差都进入回路。

**耦合升级**：v19 的 `Sim→RAG→Edge→Sim` 是「数据飞轮」；v20 在其上加一层「控制飞轮」：误差计算 → 2-DOF 控制 → 双向执行 → SIL 回路认证 → 增益再整定。两层飞轮正交：数据飞轮负责「看得更准」，控制飞轮负责「改得更稳」。二者共享同一套 Isaac Sim 场景与 CKB 版本号，回路证书随 KB 版本一起签发、一起回滚。

## 1. 形式化定义（增量：定义 38–43）

**定义 38（证书闭环系统与双通道误差）**：证书闭环状态 `x_t = (θ_t, C_t, KB_t, w_t)`（阈值向量、证书模板、知识库、学生网络权重），外生漂移 `d_t`（环境分布偏移），控制 `u_t = (Δθ_t, C_patch, KB_update, w_update)`。观测：可用性 `a_t = P_{D_real}(m ≥ θ_t)`，最坏边际 `m_min,t`。双通道误差：安全误差 `s_t = max(0, θ_t − m_min,t)`（应恒为 0），可用性误差 `e_t = r − a_t`（r 为目标 Nominal 占比，如 0.8）。闭环动力学：`x_{t+1} = U(x_t, e_t, s_t, d_t)`。

**定义 39（回路增益与小增益镇定定理）**：设被控对象灵敏度 `G_p = |∂a/∂θ| = φ(z_θ)/σ`（z_θ 为标准分位，φ 为标准正态密度），控制器增益 `G_u = |∂θ/∂e|`（由比例增益 g 决定）。**回路增益** `L = G_u · G_p`。若更新算子 `U` 在 sup 范数下是 γ-Lipschitz 且 `γ ≤ L < 1`，则由 Banach 不动点定理，`x_t` 以几何速率 `L^t` 收敛到唯一证书平衡点 `x*`；局部稳定性等价于 `L < 1`，且**相位裕度**由 `(1−L)` 给出下界。该结论要求被控对象单调（`∂a/∂θ < 0`，成立）且控制器在平衡点邻域线性时不变。

**定义 40（保守性账本与双向释放算子）**：账本 `D_t = Σ_τ (tighten_τ) − Σ_τ (release_τ)`，其中 `tighten` 记录每次阈值上抬、模板合取、L_m 上修带来的「保守性负债」；`release` 记录带证据的放松。**释放算子** `R_ε(C, E_t)`：仅当证据强度 `E_t ≥ E_min`（实机标定样本量 + 仿真回归通过率 + 形式化重证成功）且放松后证书仍在**安全下界** `θ ≥ μ̂ − kσ` 内（k 为安全裕度系数，单位 σ）时执行；单次释放幅度 `|Δθ| ≤ ρ`。命题：在单调被控对象上，若 `k ≥ z_r = Φ^{-1}(1−r)`，则存在同时满足「安全下界」与「目标可用性」的可行平衡点；否则闭环不可行，控制器必然饱和在下界且 `a < r`。

**定义 41（仿真延迟与 Smith 预测补偿）**：Sim 重跑存在死区时间 `T_sim`（含排队与并行度抖动）。用漂移速度 `v_t = (S_t − S_{t−1})/Δt`（S_t 为定义 36 的分布偏移统计量）与一阶模型预测 `Ŝ_{t+T_sim}`，在更新时使用预测值而非滞后观测；**延迟裕度** `T_m = T_sim + jitter_max` 必须小于控制器的时间常数 `τ_c`，否则回路进入振荡区。若预测误差有界 `|Ŝ − S| ≤ ε_pred`，则补偿后等效回路增益上界放大 `(1 + ε_pred/|S|)`，需相应下调 `G_u`。

**定义 42（证书可观测性与可控性指数）**：以特征投影 `Π(x)`（边际、L_m、regime 序列）为输出，构造可观测性 Gramian `O_T = Σ_t Φ_t^T Π^T Π Φ_t`；可观测性指数 `o_c = λ_min(O_T)/λ_max(O_T)`。并非所有保守性都可由漂移监测观测到（如模板合并引入的静态保守量对漂移不敏感），需**主动探针**（定期在安全区做激励性标定）提升 `o_c`。可控性指数 `c_c`：证书参数中对 `a_t` 有显著影响的子空间占比；无可控影响的参数应移出控制向量，避免无效动作与预算浪费。

**定义 43（回路 Lyapunov 函数与回路证书）**：`V_t = α·s_t² + β·e_t² + γ·D_t²`（α,β,γ>0）。**回路证书** = `(L < 1, T_m < τ_c, ΔV_t < 0 ∀t, 可行平衡点存在)` 四元组，由 SIL 在场景集 `{阶跃, 斜坡, 脉冲}` 上实测并附带置信区间。回路证书与第 42 轮的单点证书**解耦签发**：单点证书管「这一刻安全」，回路证书管「这套更新机制安全」。

## 2. 产出设计（增量 IP-57/58/59 + 升级 IP-51/52/54/55/56/45/49）

### 2.1 IP-57 LOOP-CERT-CONTROLLER（证书回路控制器 LCC）
1. **双自由度结构**：前馈项取 CKB 检索模板的「经验增益」（相似任务的 θ 初值），反馈项为可用性误差的比例-限幅控制 `Δθ = clip(g·e_t·σ√(2π) + v_t·Δt, −ρ, ρ)`；安全误差 `s_t>0` 时以更高优先级强制收紧。
2. **抗积分饱和**：当 `θ` 触及安全下界或速率限幅时，冻结前馈/积分累加，仅保留瞬时比例项；离开饱和后按 `T_anti−windup` 缓慢恢复。
3. **双向执行器**：收紧（默认）与释放（IP-59 证据门控）统一走一个速率受限的投影算子，保证任何时刻证书仍 sound。
4. **增益调度**：按 `L_hat` 在线估计调整 g，目标 `L_hat ≤ 0.7`（保留 30% 裕度）；漂移剧烈时降增益、漂移平缓时升增益。
5. **可行性守卫**：每轮检查定义 40 的可行条件 `k ≥ z_r`，不可行立即上报「能力改进」而非继续收紧（避免无解地推向 SafeStop）。

### 2.2 IP-58 SIM-IN-THE-LOOP CERTIFIER（回路认证器 SIL-Cert）
1. **可编程现实**：Isaac Sim 侧按脚本产生三类漂移（阶跃/斜坡/脉冲）与三类故障（执行器卡滞、传感器漂移、通信延迟），并记录「真值边际」作为被控对象输出。
2. **整环回放**：把 IP-57 控制器、IP-56 ECR 运行时、IP-55 CKB 检索、IP-54 SCV 重跑全部接入同一时钟；延迟、量化、丢帧按实测分布注入。
3. **四指标判定**：阶跃响应（调节时间、超调）、斜坡跟踪（稳态误差）、脉冲恢复（恢复时间）、长时驻留（极限环检测，用相图/自相关判定）。
4. **延迟扫描与裕度验证**：将 `T_sim` 从 0.5× 扫到 3×，找到振荡边界，据此设定 `T_m` 与降增益策略。
5. **HIL 回放**：用真实机器人日志在仿真里重放，闭合「仿真—实机」差；回放通过才允许把回路证书下发到实机。

### 2.3 IP-59 CONSERVATISM-LEDGER（保守性账本 CLedger）
1. **双记账**：每次证书变更记录 `(cause, Δconservatism, evidence, KB_version, git_commit)`；`D_t` 为累计净值，设硬上限 `D_max`。
2. **释放证据包**：实机标定 ≥ N_e 条 + 仿真回归通过率 ≥ p_e + 形式化重证成功，三者全满足才签释放许可。
3. **棘轮检测**：若连续 `M` 轮 `D_t` 单调上升且 `a_t` 单调下降，判定「棘轮告警」，强制进入释放审计或回滚到已验证版本。
4. **审计与追溯**：账本随回路证书一起版本化，支持按 KB/git/硬件版本三维回滚。

## 3. 四层架构 v8

```
L1: TRI-FUSE(INT8) + IP-49 LIO → 度量语义图 C_ms + 漂移界 B_t + m_lo 置信区间
L2: CTC + VLM + IP-35 仲裁 → R_φ(w) + 几何残差证书 → CKB 指纹 (φ, ψ)
L3: IP-51 CAR(双向速率受限阈值) ← IP-56 ECR(L0查表 + INT8监控 + 偏移遥测)
    ← IP-57 LCC(2-DOF + 抗饱和 + 增益调度 + 可行性守卫)
    → IP-47 乘积模板组合 → IP-39 规划(CBF margin) → IP-45 总线(回路遥测 e_t/s_t/L_hat/D_t)
    → IP-48 流匹配 + IP-43 韵律 → IP-53 CMC(看门狗=INT8)
L4: IP-55 CKB(检索 + 模板回收) ← IP-54 SCV(SIL 场景 + 延迟注入)
    → IP-58 SIL-Cert(回路认证: 阶跃/斜坡/脉冲 + HIL 回放)
    → IP-59 CLedger(双记账 + 释放门控) → RCA 签发双证书(单点证书 + 回路证书) → 契约热更新
运行期: L0(5μs) + INT8(100μs) + 偏移监控 → LCC 误差计算 → 双向执行 → 回路遥测
        → (每 T_loop) SIL 回路回归 → 回路证书续签/回滚
```

**关键结构变化**：v19 的箭头是单向的；v8 把「误差计算 → 控制器 → 双向执行 → 回路认证」闭合回 L3，并将「放松」提升为一等公民。

## 4. 实验设计（E87–E94 硬门槛，承接 E79–E86）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E87 回路阶跃响应 | 调节时间、超调、稳态可用性误差 | 阶跃后 < 15 轮回到 ±5pp；超调 < 10%；稳态误差 < 5pp |
| E88 回路增益与稳定性 | 在线 `L_hat`、极限环检测 | `L_hat < 0.7`；100 次漂移无持续极限环 |
| E89 保守性棘轮 | 账本 `D_t` 上界、可用性单调退化检测 | `D_t ≤ D_max`；无连续 M 轮棘轮告警 |
| E90 延迟裕度 | `T_sim` 扫描至 3× 时的振荡边界、Smith 补偿效果 | 2× 延迟下无振荡；超调下降 ≥ 40% |
| E91 SIL 回路认证 | 100 个脚本化漂移场景的通过率 | ≥ 95% 场景收敛；0 次不安全 |
| E92 释放正确性 | 释放后真实违例率、可用性恢复 | 10k 状态 0 违例；恢复 ≥ 10pp |
| E93 可观测/可控性 | 不可观测保守量占比、探针恢复率 | 不可观测 < 20%；探针后恢复 ≥ 80% |
| E94 长时平衡 | 200 小时或 500 轮：可用性平稳性、账本、安全 | 0 不安全；可用性 ≥ 75% 且无趋势性下降 |

回退：E88 回路增益无法压到 1 以下 → 退化为「单边收紧 + 人工释放」，即回到 v19 但显式标注为开环；E87/E91 出现极限环 → 关闭自动释放，锁定 KB 版本并转人工标定；E90 延迟不可控 → 降低 `T_loop`、把 Sim 重跑改为异步批处理；E92 释放违例 → 立即回滚并冻结释放通道。

## 5. 本轮最大风险

**一句话**：v20 把单向飞轮改造成带反馈的闭环，最大新风险是**回路自激**——保守性棘轮、Sim 重跑死区时间与过高更新增益叠加，会让证书在「过紧→SafeStop」与「过松→静默违例」之间形成极限环，且这种振荡在可用性指标上可能伪装成正常波动；因此 E87/E88（阶跃响应、回路增益）与 E92（释放 soundness）必须作为红线实验，任一不达标即降级为开环并锁定版本。

# 第 43 轮产物 · 创新点清单 v20：证书回路可镇定控制（LCC × SIL-Cert × CLedger）× 双向释放（四层架构 v8）

> 承接第 42 轮产物 v19。本轮**增量插入** IP-57/58/59，并升级 IP-51/52/54/55/56/45/49；不推倒任何既有层级。核心是把 v19 的「数据飞轮」升级为「数据飞轮 + 控制飞轮」双环：数据飞轮让证书看得更准，控制飞轮让证书更新得稳、可释放、有回路证明。

## 0. 核心 IP 设计

| 编号 | 名称 | 类型 | 关键改进 |

## 2. 关键算法（伪代码）

### IP-57 LCC：证书回路控制步
```
def loop_control_step(x, obs, KB, cfg):
    theta, C, KBv, w = x
    a_t, m_min = obs.availability, obs.margin_min
    s = max(0.0, theta - m_min)          # 安全误差
    e = cfg.r - a_t                      # 可用性误差(>0 表示可用性不足)
    S_t = obs.drift_stat                 # 定义36 分布偏移

    # --- 1. 前馈：CKB 经验增益 ---
    ff = KB.experience_gain(obs.phi, obs.psi)           # Δθ_ff
    # --- 2. 反馈：可用性误差 -> 阈值增量（负号：放松以提升可用性）---
    fb = cfg.g * e * cfg.sigma * sqrt(2*pi)
    # --- 3. Smith 延迟补偿：用漂移速度预测 T_sim 后的偏移 ---
    S_pred = S_t + obs.drift_velocity * cfg.T_sim
    fb += cfg.k_smith * (S_pred - S_t)

    dtheta = ff + fb
    # --- 4. 安全误差优先：强制收紧 ---
    if s > 0:
        dtheta = max(dtheta, cfg.k_safe * s)

    # --- 5. 速率限幅 + 双向投影（抗积分饱和）---
    dtheta = clip(dtheta, -cfg.rho, +cfg.rho)
    theta_new = theta + dtheta
    lo = obs.mu_hat - cfg.k_sigma * cfg.sigma
    saturated = (theta_new <= lo) or (abs(dtheta) >= cfg.rho - 1e-9)
    if theta_new < lo:
        theta_new = lo                                  # 安全下界硬约束
    # 饱和时冻结前馈/积分累加，离开饱和后缓慢恢复
    cfg.integral = 0.0 if saturated else cfg.integral + ff

    # --- 6. 可行性守卫：k >= z_r 才存在双目标平衡点 ---
    feasible = cfg.k_sigma >= norm_ppf(1 - cfg.r)
    if not feasible:
        return escalate_capability_improvement(x, reason='infeasible_equilibrium')

    return x.with_theta(theta_new), {'e':e,'s':s,'L_hat':estimate_gain(obs),
                                     'saturated':saturated,'feasible':feasible}
```

### IP-59 CLedger：保守性账本与释放
```
def ledger_apply(ledger, action, evidence, config):
    if action.type == 'tighten':
        ledger.D += action.delta
        ledger.append(cause=action.cause, delta=+action.delta,
                      evidence=evidence, kb=action.kb_version)
    elif action.type == 'release':
        # 证据三合一：实机标定 + 仿真回归 + 形式化重证
        ok = (evidence.n_real >= config.N_e
              and evidence.sim_pass >= config.p_e
              and evidence.formal_reproved)
        if not ok:
            return 'REJECT_RELEASE'
        # 安全下界 + 单次幅度约束
        if action.theta_new < action.mu_hat - config.k_sigma*config.sigma:
            return 'REJECT_SAFETY'
        if abs(action.delta) > config.rho:
            return 'REJECT_RATE'
        ledger.D -= abs(action.delta)
        ledger.append(cause='release', delta=-abs(action.delta),
                      evidence=evidence, kb=action.kb_version)
    if ledger.D > config.D_max:
        return 'RATCHET_ALARM'          # 触发释放审计/回滚
    return 'OK'

def ratchet_detect(ledger, avail_hist, M=5):
    # 连续 M 轮 D 单调上升且 a 单调下降 -> 棘轮
    return (all(ledger.D_hist[-i] > ledger.D_hist[-i-1] for i in range(1,M))
            and all(avail_hist[-i] < avail_hist[-i-1] for i in range(1,M)))
```

### IP-58 SIL-Cert：整环仿真与回路证书
```
def sil_loop_certify(controller, runtime, KB, SCV, scenarios, T_sim_grid):
    certs = []
    for sc in scenarios:                       # 阶跃/斜坡/脉冲/组合
        sim = IsaacLoopRig(SCV.scene(sc), delay=sc.T_sim,
                           drop=sc.drop_rate, quant=runtime.quant)
        av, theta, ledger = [], [], CLedger()
        for t in range(sc.T):
            truth = sim.step_reality()          # 真值分布/边际
            obs   = runtime.observe(truth)      # 含延迟/量化/丢帧
            x, info = loop_control_step(controller.state, obs, KB, controller.cfg)
            action = controller.actuate(x, info)
            if action.type == 'release':
                ledger_apply(ledger, action, controller.evidence, controller.cfg)
            sim.apply(action)
            av.append(obs.availability); theta.append(x.theta)
        # 四指标
        certs.append({
          'scenario': sc.name,
          'settling': settling_time(av, controller.cfg.r),
          'overshoot': max(0, max(av) - controller.cfg.r),
          'steady_err': abs(mean(av[-20:]) - controller.cfg.r),
          'limit_cycle': detect_limit_cycle(theta),   # 相图/自相关
          'D_max': ledger.max(),
          'unsafe': sim.unsafe_count,
        })
    # 延迟扫描：找振荡边界
    boundary = scan_delay_boundary(controller, T_sim_grid)
    loop_cert = {
      'L_hat': estimate_loop_gain(certs),
      'T_margin': boundary.stable_T_max,
      'lyapunov_ok': all(c['steady_err'] < 0.05 for c in certs),
      'feasible': controller.cfg.k_sigma >= norm_ppf(1-controller.cfg.r),
      'scenarios': certs,
    }
    return loop_cert if validate_loop_cert(loop_cert) else 'REJECT'
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性保证 |
|---|---|---|---|
| IP-57 LCC 控制步 | O(1) + O(log N) 查表 | O(1) | L<1 且可行 ⇒ 收缩到唯一平衡点（Banach） |
| IP-57 Smith 补偿 | O(1) | O(1) | 预测误差有界 ⇒ 等效增益上界放大已知，可降增益抵消 |
| IP-58 SIL 回路认证 | O(|Scen|·T·T_sim) 可并行 | 场景日志 O(T) | 场景覆盖 ≥1−δ ⇒ 回路证书置信 1−δ |
| IP-58 延迟扫描 | O(|T_grid|·|Scen|·T) | O(1) | 找到振荡边界 ⇒ T_m 取边界 0.7×，留裕度 |
| IP-59 账本更新 | O(1) 摊还 | O(#updates) | 释放三合一证据 + 安全下界 ⇒ 释放后仍 sound |
| IP-59 棘轮检测 | O(M) | O(M) | 连续单调 ⇒ 高置信棘轮告警（可证伪） |
| IP-51 双向守卫 | O(|E|) | 同 L0 | 释放受安全下界约束 ⇒ 守卫始终 ⊇ 真实安全集 |
| IP-52 LCS v2 | 同 v19 + O(1) | 同 v19 | 控制努力饱和时降档 ⇒ 不产生越权动作 |

**命题（闭环可行性）**：平衡点存在的充要条件为 `k ≥ z_r`，其中 `k` 是安全裕度（σ 单位），`z_r = Φ^{-1}(1−r)`。证明：平衡时 `θ* = μ − z_r σ`；安全下界为 `μ − kσ`；要求 `θ* ≥ μ − kσ` 即 `k ≥ z_r`。∎ 推论：若环境本身不安全（k<z_r），任何控制增益都无法同时满足安全与目标可用性，必须改进**能力**（提高 μ）或降低 r。

## 5. 干跑数值实验（合成数据，非实机）

为验证「棘轮 vs 闭环」是否真实存在，按定义 38–40 搭了一个最小离散时间仿真：240 轮，每轮从 `N(μ_t, σ²)` 采 4000 个状态估可用性，`σ=0.30`；每 40 轮阶跃 `μ−=0.25`，第 120 轮脉冲 `μ−=0.40`，叠加 `N(0,0.01)` 随机游走与观测噪声。策略 A = v19 式只收紧（检测到漂移即 `θ←θ+κS`，κ=0.06）；策略 B = 本轮 LCC（g=0.35，速率 ρ=0.04，安全下界 `μ−2.5σ`，前馈漂移速度，抗饱和）。

| 指标 | 策略 A（棘轮，v19） | 策略 B（闭环，v20） |
|---|---|---|
| 末段可用性（最后 20 轮均值） | 0.000 | **0.802** |
| 全程最低可用性 | 0.000 | 0.102 |
| 账本最大净值 D_t | 13.56 | **0.615** |
| 阶跃后调节到 ±5pp | 不收敛 | **8 轮** |
| 阶跃超调 | — | 4.7pp |
| 脉冲后 20 轮平均可用性 | 0.000 | 0.492（恢复中） |

**解读**：(1) 只收紧策略在持续漂移下可用性单调归零，账本无界增长，实证了「保守性棘轮」是本架构的真实失效模式；(2) 闭环策略把账本压到 0.615（约 22× 改善）、末段可用性稳定在目标 0.80 附近，阶跃 8 轮收敛；(3) 解析回路增益 `L = G_u·G_p = (0.35·0.3·√(2π))·(φ(0.8416)/0.3) = 0.263·0.933 ≈ 0.246 < 1`，与实测快速收敛一致，说明小增益判据可作为设计前置条件。**注意**：这是合成数据的机理验证，不替代 E87–E92 的 Isaac Sim / 实机实验。

## 7. 本轮最大风险

**一句话**：v20 把单向飞轮改造成带反馈的闭环，最大新风险是**回路自激**——保守性棘轮、Sim 重跑死区时间与过高更新增益叠加，会让证书在「过紧→SafeStop」与「过松→静默违例」之间形成极限环，且这种振荡在可用性指标上可能伪装成正常波动；因此 E87/E88（阶跃响应、回路增益）与 E92（释放 soundness）必须作为红线实验，任一不达标即降级为开环并锁定版本。
