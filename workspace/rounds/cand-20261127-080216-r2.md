### 第 2 轮灵感驱动研究记录

**灵感词**：预测性维护、自主导航

**直觉与动机**：
前两轮的证书链（HPC-E+ → USMC v24 → SRC-USC v25）本质上都是「点态 / 快照」验证：对给定时刻 t 的计划 π 检查一组布尔谓词。但真实部署中证书既会「过期」，也会「出界」：
- **预测性维护**告诉我们，结构疲劳、电池老化、密封磨损会让 E_max、σ_yield、λ_buck、B_d 等证书参数随健康状态 h(t) 单调退化，今天的证书明天可能不再成立；
- **自主导航**告诉我们，机器人要在未知 / 拒止环境中移动，定位漂移、可通行性变化、通信遮挡会让同一张证书在空间上「并非处处成立」，A 点有效的证书搬到 B 点可能失效。

核心洞见：**证书不是布尔值，而是时空流形上的一个「截面」（section）——它携带有效期 TTL（由剩余使用寿命 RUL 的下置信界决定）和有效域 D（由导航可达域与定位不确定性决定）；准入从「谓词是否为真」升级为「在计划的时空轨迹上是否处处有定义、未过期且裕度非负」。预测性维护提供时间轴（证书会老化），自主导航提供空间轴（证书需输运），二者合成证书的「时空有效期」概念。**

**形式化目标**：
1. 定义预测性健康证书（PHC）：退化状态 h(t)、RUL 下界 T_rul^lo 满足 ℙ(T_rul ≥ τ) ≥ 1-δ_h，健康感知参数包络 θ_lo(h) ≤ θ(h(t)) ≤ θ_hi(h)，θ ∈ {E_max, γ_s, λ_buck, B_d, α, β, δ_dyn}
2. 定义自主导航证书（ANC）：定位误差 conformal 椭球 ℙ(e ∈ ℰ(Σ_loc(t))) ≥ 1-δ_loc、可通行性 τ_trav(x) ≥ τ_min、GNSS 拒止漂移界 ‖e(t)‖ ≤ c·t + b、路径可行性与探索覆盖
3. 定义时空有效期证书（STVC）：证书 C = (φ, TTL, D)，φ 为 v25 基础谓词束，TTL = t0 + T_rul^lo − ε_renew，D 为时空有效域；准入 = ∀(x,t)∈Traj(Π): C 在 (x,t) 有定义 ∧ t ≤ TTL ∧ φ 成立
4. 构建预测-导航统一准入门（PN-USC v26）：v25 七证 ∪ PHC ∪ ANC ∪ STVC 十证一体，Exec_v26 ⊆ Exec_v25
5. 定义「主动降级」：PHC 预测任务期内将失效时，门不直接拒证，而是收缩到降级安全子集 Exec_v26^↓（限速 / 缩短时域 / 保守裕度），保证执行期内无证书静默过期
6. 证明退化-导航耦合下「执行期内无证书过期」安全性与单调退化链保持性

```python
# ============================================================
# IP-448 Prognostic Health Certificate (PHC) — 预测性健康证书
# ============================================================
@dataclass
class PrognosticHealthCertificate:
    """退化状态 + RUL 下置信界 + 健康感知参数包络 + TTL"""
    health_state: 'HealthState'          # h(t) 当前后验估计
    degradation_model: 'DegradationModel'  # ḣ = f_d(h,u,w)，可含 Wiener/Paris-law
    rul_predictor: 'RULPredictor'        # 分位数 / conformal RUL 预测器
    delta_h: float = 0.05                # RUL 风险水平
    horizon: float = 3600.0              # 预测时域 (s)
    eps_renew: float = 60.0              # 再认证延迟预留 (s)
    param_map: dict = None               # θ_name -> callable(h) -> (lo, hi)

    def predict_rul_lower(self) -> float:
        """T_rul^lo：满足 ℙ(T_rul ≥ T_rul^lo) ≥ 1-δ_h"""
        return self.rul_predictor.lower_quantile(self.health_state, 1.0 - self.delta_h)

    def ttl(self, t0: float) -> float:
        return t0 + self.predict_rul_lower() - self.eps_renew

    def parameter_envelope(self, theta_name: str, h) -> tuple:
        return self.param_map[theta_name](h)  # (lo, hi)

    def verify_over_horizon(self, mission_time: float, base_predicates: dict) -> bool:
        """RUL 覆盖任务期 + 沿退化轨迹逐点校验参数包络仍满足基础谓词"""
        # (1) 寿命覆盖：TTL 必须晚于任务结束
        if self.ttl(0.0) < mission_time:
            return False
        # (2) 参数包络：沿预测退化轨迹 h(t) 逐点检查
        N = max(2, int(mission_time / self.horizon * 64))
        for t in torch.linspace(0.0, mission_time, N):
            h_t = self.degradation_model.rollout(self.health_state, t)
            for theta, pred in base_predicates.items():
                lo, hi = self.parameter_envelope(theta, h_t)
                if not pred(lo, hi):     # 谓词需对包络端点均成立
                    return False
        return True

    def margin_ratio(self, t: float) -> float:
        """距失效的剩余裕度比：<1 表示需再认证 / 主动降级"""
        rul = self.predict_rul_lower() - t
        return rul / max(self.eps_renew, 1e-9)


# ============================================================
# IP-449 Autonomous Navigation Certificate (ANC) — 自主导航证书
# ============================================================
@dataclass
class AutonomousNavigationCertificate:
    """定位 conformal 椭球 + 可通行性 + 拒止漂移界 + 路径/覆盖"""
    loc_cov: Tensor                      # [T,3,3] 位置协方差 Σ_loc(t)
    delta_loc: float = 0.01              # 定位风险水平
    traversability: 'TraversabilityField' = None
    tau_min: float = 0.5                 # 可通行性下界
    drift_c: float = 0.01                # GNSS 拒止漂移系数 (m/s)
    drift_b: float = 0.05                # 漂移偏置界 (m)
    path: Tensor = None                  # [T,3] 计划路径
    mapped_domain: 'SpatialMap' = None   # D_nav

    def loc_radius(self, t: int) -> float:
        """conformal 椭球半径：chi2 分位数 × 最大特征值开方"""
        lam = torch.linalg.eigvalsh(self.loc_cov[t]).max().clamp(min=0)
        return float(torch.sqrt(lam) * math.sqrt(chi2.ppf(1 - self.delta_loc, 3)))

    def verify_localization(self) -> bool:
        """∀t: ℙ(e(t)∈ℰ(Σ_loc(t))) ≥ 1-δ_loc"""
        if self.loc_cov is None:
            return False
        return all(torch.isfinite(self.loc_cov[t]).all() for t in range(len(self.loc_cov)))

    def verify_traversability(self) -> bool:
        for x in self.path:
            if self.traversability.query(x) < self.tau_min:
                return False
        return True

    def drift_bound(self, t_end: float) -> float:
        """GNSS 拒止漂移上界 ‖e(t)‖ ≤ c·t + b"""
        return self.drift_c * t_end + self.drift_b

    def verify_drift_within_domain(self, t_end: float) -> bool:
        """漂移不得把机器人推出已建图/可通行域"""
        return self.drift_bound(t_end) <= self.mapped_domain.distance_to_boundary(self.path[-1])

    def verify_path_feasible(self, obstacles, inflation: float) -> bool:
        clearance = min_clearance(self.path, obstacles)
        return clearance > inflation + max(self.loc_radius(t) for t in range(len(self.path)))

    def verify_coverage(self, goal) -> bool:
        return self.mapped_domain.covers(goal, margin=self.loc_radius(len(self.path) - 1))

    def verify_all(self, obstacles, inflation: float, goal) -> bool:
        return (self.verify_localization() and self.verify_traversability()
                and self.verify_drift_within_domain(len(self.path) - 1)
                and self.verify_path_feasible(obstacles, inflation)
                and self.verify_coverage(goal))


# ============================================================
# IP-450 Spatiotemporal Validity Certificate (STVC) — 时空有效期证书
# ============================================================
@dataclass
class SpatiotemporalValidityCertificate:
    """证书即截面 C=(φ,TTL,D)：联合检查定义域、有效期、裕度与输运"""
    base_bundle: 'SemanticReconfigCoordUnifiedCertificate'  # v25 七证
    phc: PrognosticHealthCertificate
    anc: AutonomousNavigationCertificate
    domain: 'SpatiotemporalDomain' = None   # D ⊂ SE(3)×ℝ

    def admits(self, plan: 'MultiRobotPlan') -> bool:
        ttl = self.phc.ttl(plan.t0)
        for (x, t) in plan.trajectory_samples():
            # (i) 时空有效域：D 必须覆盖 (x,t)
            if not self.domain.contains(x, t):
                return False
            # (ii) 未过期：任何采样时刻不得越过 TTL
            if t > ttl:
                return False
            # (iii) 导航裕度非负：定位半径 + 漂移 < 计划安全裕度
            if self.anc.loc_radius(t) + self.anc.drift_bound(t) > plan.margin(x, t):
                return False
            # (iv) 健康感知基础谓词：h(t) 下的 v25 证书仍成立
            h_t = self.phc.degradation_model.rollout(self.phc.health_state, t)
            if not self.base_bundle.admits_with_health(plan, h_t):
                return False
        return True

    def transport_ok(self, x_from, x_to, t) -> bool:
        """证书输运：D 在路径上连通，且定位误差小于域内裕度"""
        return (self.domain.connected(x_from, x_to)
                and self.anc.loc_radius(t) < self.domain.margin(x_to, t))

    def needs_recert(self, t: float) -> bool:
        """再认证触发：参数逼近包络边界 / 定位不确定超阈 / 进入未建图区"""
        return (self.phc.margin_ratio(t) < 1.0
                or self.anc.loc_radius(int(t)) > 3.0 * self.anc.delta_loc
                or not self.domain.mapped(self.anc.current_pose))


# ============================================================
# IP-451 PN-USC 预测-导航统一准入门 v26
# ============================================================
@dataclass
class PrognosticNavigationUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'  # v25 七证
    phc: PrognosticHealthCertificate
    anc: AutonomousNavigationCertificate
    stvc: SpatiotemporalValidityCertificate

    def admits(self, multi_plan: 'MultiRobotPlan', sensor_data: dict) -> tuple[bool, dict]:
        # 1) v25 七证（语义/重构/协同）
        if not self.src_usc.admits(multi_plan, sensor_data):
            return False, {'stage': 'v25', 'reason': 'SRC_USC_reject'}

        # 2) PHC：任务期健康覆盖；不满足时主动降级而非直接拒证
        base_preds = self._health_aware_predicates(multi_plan)
        if not self.phc.verify_over_horizon(multi_plan.mission_time, base_preds):
            return self._active_degrade(multi_plan, sensor_data, base_preds)

        # 3) ANC：导航域与定位/可通行/漂移
        if not self.anc.verify_all(multi_plan.obstacles, multi_plan.inflation, multi_plan.goal):
            return False, {'stage': 'ANC', 'reason': 'navigation_infeasible'}

        # 4) STVC：时空截面
        if not self.stvc.admits(multi_plan):
            return False, {'stage': 'STVC', 'reason': 'certificate_out_of_domain_or_expired'}

        return True, {'degraded': False, 'ttl': self.phc.ttl(multi_plan.t0),
                      'loc_radius': self.anc.loc_radius(len(self.anc.path) - 1)}

    def _active_degrade(self, plan, sensor_data, base_preds) -> tuple[bool, dict]:
        """预测到任务期内失效：收缩到 Exec_v26^↓，直到 PHC 覆盖为止"""
        for factor in (0.8, 0.6, 0.4, 0.2):
            plan_d = plan.scale_speed(factor).shorten_horizon(factor)
            if self.phc.verify_over_horizon(plan_d.mission_time, base_preds):
                return True, {'degraded': True, 'factor': factor,
                              'mode': 'reduced_speed_short_horizon',
                              'ttl': self.phc.ttl(plan_d.t0)}
        return False, {'degraded': False, 'reason': 'PHC_uncoverable_even_at_min_speed'}

    def _health_aware_predicates(self, plan) -> dict:
        """把 v25 基础证书参数映射为对健康包络的谓词"""
        return {
            'E_max':   lambda lo, hi: hi <= plan.E_budget,
            'gamma_s': lambda lo, hi: lo >= plan.gamma_s_min,
            'lambda_buck': lambda lo, hi: lo >= plan.lambda_buck_min,
            'B_d':     lambda lo, hi: lo >= plan.B_d_min,
            'delta_dyn': lambda lo, hi: hi <= plan.delta_dyn_max,
        }


# ============================================================
# 端到端流水线：v26 在 v25 基础上加入健康-导航-时空层
# ============================================================
class PrognosticNavigationPipeline:
    def __init__(self, config: dict):
        self.v25 = config['v25_pipeline']
        self.pn_usc = PrognosticNavigationUnifiedCertificate(
            src_usc=config['src_usc'],
            phc=PrognosticHealthCertificate(
                health_state=config['health_state'],
                degradation_model=config['degradation_model'],
                rul_predictor=config['rul_predictor'],
                delta_h=config['delta_h'],
                eps_renew=config['eps_renew'],
                param_map=config['param_map'],
            ),
            anc=AutonomousNavigationCertificate(
                loc_cov=config['loc_cov'],
                delta_loc=config['delta_loc'],
                traversability=config['traversability'],
                tau_min=config['tau_min'],
                drift_c=config['drift_c'],
                drift_b=config['drift_b'],
                path=config['path'],
                mapped_domain=config['mapped_domain'],
            ),
            stvc=SpatiotemporalValidityCertificate(
                base_bundle=config['src_usc'],
                phc=config['phc'],
                anc=config['anc'],
                domain=config['spacetime_domain'],
            ),
        )
        self.ipam.register_module("phc", ["IP-448"],
            ["rul_conformal_lower", "health_parameter_envelope", "certificate_ttl", "active_degradation"])
        self.ipam.register_module("anc", ["IP-449"],
            ["localization_conformal", "traversability_certificate", "gnss_denied_drift", "coverage"])
        self.ipam.register_module("stvc", ["IP-450"],
            ["spacetime_section", "certificate_transport", "recertification_trigger"])
        self.ipam.register_module("pn_usc", ["IP-451"],
            ["decuple_certificate_gate", "active_degradation_monotone_chain"])

    def step(self, multi_sensor_data: dict) -> tuple[bool, dict]:
        # 1) v25 端到端（语义/重构/协同）
        ok25, info25 = self.v25.step(multi_sensor_data)
        if not ok25:
            return False, {'stage': 'v25', 'details': info25}
        # 2) 更新健康后验与 RUL
        self.pn_usc.phc.health_state = self._update_health(multi_sensor_data)
        # 3) 更新定位协方差/可通行场/建图域
        self.pn_usc.anc.loc_cov = self._propagate_loc_cov(multi_sensor_data)
        self.pn_usc.anc.mapped_domain = self._update_map(multi_sensor_data)
        # 4) 再认证触发检查
        recert = self.pn_usc.stvc.needs_recert(multi_sensor_data['t'])
        # 5) PN-USC 十证准入（含主动降级）
        multi_plan = self.v25._plan_from_consensus(multi_sensor_data)
        admitted, info = self.pn_usc.admits(multi_plan, multi_sensor_data)
        info['needs_recert'] = recert
        return admitted, info

    def _update_health(self, data) -> 'HealthState':
        return data['health_observer'].update(data['current'], data['temperature'], data['load'])

    def _propagate_loc_cov(self, data) -> Tensor:
        # 里程计 + 地标观测的 EKF 协方差传播；拒止时按 c,b 膨胀
        return data['localizer'].propagate(data['odom'], data['landmarks'], data['gnss_available'])

    def _update_map(self, data) -> 'SpatialMap':
        return data['mapper'].fuse(data['lidar'], data['camera'])
```

## 2. 复杂度分析（增量）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |

## 3. 正确性论证（增量）

### 引理 13（PHC 的 RUL-包络双保证）
**陈述**：`PHC.verify_over_horizon(T_m, φ) = True` ⟹ (1) ℙ(T_rul ≥ T_m) ≥ 1-δ_h；(2) 对 ∀t∈[0,T_m]，健康感知参数 θ(h(t)) 落在包络内且 φ 成立。

**证明**：
1. `predict_rul_lower` 返回 1−δ_h 分位数下界，由 conformal 分位数回归的边际覆盖保证（Romano et al. 2019），故 ℙ(T_rul ≥ T_rul^lo) ≥ 1−δ_h；`ttl(0)=T_rul^lo−ε_renew ≥ T_m` 蕴含 RUL 覆盖任务期。
2. 对退化轨迹 h(t) 逐点计算 [θ_lo,θ_hi]，谓词对包络两端均成立，则真实 θ(h(t)) 亦成立（单调性 / 区间包含）。
3. 二者分别保证「寿命足够」与「寿命内参数达标」，缺一即可能执行期静默过期。∎

### 引理 14（ANC 的定位-可通行-漂移三重保证）
**陈述**：`ANC.verify_all(...) = True` ⟹ (1) ℙ(e(t)∈ℰ(Σ_loc(t))) ≥ 1-δ_loc；(2) ∀x∈path: τ_trav(x) ≥ τ_min；(3) GNSS 拒止漂移 ‖e(t)‖ ≤ c·t+b 且不越出建图域。

**证明**：
1. conformal 椭球半径由 χ²₃(1−δ_loc) 与协方差最大特征值给出，覆盖误差概率 ≥ 1−δ_loc。
2. 可通行性场逐点查询，τ_trav 低于阈值即拒证，保证路径物理可通过。
3. 漂移上界 c·t+b 为里程计误差的保守线性界；`verify_drift_within_domain` 要求漂移半径小于到建图域边界距离，避免「证书在域外失效」。∎

### 引理 15（STVC 的时空截面与输运一致性）
**陈述**：`STVC.admits(Π) = True` ⟺ 对 Traj(Π) 每个采样 (x,t)：(i) (x,t)∈D；(ii) t≤TTL；(iii) loc_radius(t)+drift(t)≤margin(x,t)；(iv) h(t) 下 v25 七证成立。

**证明**：直接由 `admits` 的四条连言逐采样检查得到。输运 `transport_ok` 要求 D 沿路径连通且定位误差小于域内裕度；由三角不等式，若两端均在 D 内且误差小于裕度，则中间路径不越界，证书可连续输运。∎

### 引理 16（主动降级的安全性：执行期内无证书静默过期）
**陈述**：若 `_active_degrade` 返回 `(True, {factor})`，则降级计划 Π^↓ 在执行期内满足 PHC 覆盖，且 Exec_v26^↓ ⊆ Exec_v25 ⊆ … ⊆ Exec_v18。

**证明**：
1. 降级通过 `scale_speed`/`shorten_horizon` 缩短任务期 T_m^↓ 并降低负载 u，退化模型给出更平缓的 h(t)，使 T_rul^lo−ε_renew ≥ T_m^↓ 可满足；找到首个 factor 即返回，保证覆盖。
2. Π^↓ 仍通过 v25 七证（未修改语义/重构/协同谓词，仅收缩速度与时域），故属于 Exec_v25；主动降级只收缩不扩张，故单调链保持。
3. 若所有 factor 均不可覆盖，则拒证而非放行，避免「带病执行」。∎

### 定理（PN-USC 十证 + 时空有效性完备性）
**陈述**：对任意多机计划 Π，`PN-USC.admits(Π) = True` ⟺ Π 同时满足 v25 的 (1)–(10) 十条，且 (11) PHC 健康-寿命双保证、(12) ANC 导航三重保证、(13) STVC 时空截面与输运一致；否则要么拒证，要么落入显式标注的降级子集 Exec_v26^↓。

**证明**：必要性由 `admits` 的阶段连言直接给出；充分性由引理 13–16 保证：健康层保证「寿命内参数达标」，导航层保证「可达域内定位/可通行」，时空层保证「整条轨迹不越界、不过期」，降级层保证「不满足时只收缩不放行」。四层合成即从单机物理到群体智能、再到时间维与空间维的完整闭环。∎

## 6. 本轮最大风险（最终确认）

**一句话**：**PHC 的 RUL 下界在全新失效模式/工况漂移下被高估、ANC 的 GNSS 拒止漂移界在特征贫乏环境中被低估、STVC 的时空有效域在未建图边界被外推——三者叠加会让证书 TTL 与有效域同时「乐观外推」，使 PN-USC 在证书已实际过期或已出界时仍判定有效，从而击穿「执行期内无证书静默过期」这一 v26 的核心承诺。**
