# 第 15 轮（新灵感循环第 1 轮；本轮灵感：「抓取位姿估计」×「伦理与合规」）

> **基线**：第 14 轮 MetricVoiceGauge-NCD-HUTDH（定义 595–606；引理 113–124；实验 E647–E660）。
> 本轮纪律：**认证抓取包络 + 非补偿性伦理准入 + 最小披露审计见证**。不推倒 v14：v13 的 AIO/CPD/DDL/RTCR、v14 的 HBR/UCCI/PAA、v12 的 USG/TGC/BAA/GAGP/UC、v11 的 HAS/HCC/HATD/HDT、v10 的 NGE/DSL/CC/CWM/CAE/NCP、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 与九不变式全部保留。三个新组件——GPC（抓取位姿证书，含对称商共形与多峰聚合）、ECA（伦理合规准入，含默认拒绝与规范不确定性锥）、ACW（审计见证，含最小披露与可逆性窗口）——一律以**中立元**接入，失效即严格退回 v14（引理 130），再沿 v14→v13 退化链退回更低版本。本轮只做三件事：把"抓取位姿"从单点估计改写为**带对称商与多峰覆盖的认证包络**、把"伦理合规"从加权软约束改写为**不可补偿的三值准入门**、把二者合成一个**只收缩不扩张**的执行集 `Exec_v15 = Exec_v14 ∩ G_α ∩ Adm_E`。

## 0. 直觉与动机

**灵感 1（抓取位姿估计 → 认证抓取包络而非单点位姿）**
直觉：传统抓取位姿估计输出"最优的 6-DoF 位姿"，再让规划器围绕它工作。这在安全关键场景里是错位的抽象：网络真正拥有的不是"一个位姿"，而是一个**多峰、带对称歧义、且成功与否只由接触边界决定**的分布。取 argmax 会系统性忽略两种致命情形——(i) 物体有对称群（圆柱、方块、杯子），"位姿误差"在以物体对称群取商的度量下很小，但在 SE(3) 欧氏坐标下巨大；(ii) 两个模态的分数几乎相同（正抓/反抓、左倾/右倾），平均或 top-1 都会在接触边界上赌错。核心创新：**认证抓取包络（Certified Grasp Envelope, CGE）+ 对称商共形（Symmetry-Quotient Conformal, SQC）+ 多峰聚合证书（Multimodal Aggregation Certificate, MAC）**。CGE 不输出位姿，而输出一个**被证书验证的位姿集合** `G_α(x,o)`：集合内每个位姿都带力闭合、碰撞余量、可达性与成功下界；SQC 在对称群商空间上做共形校准，使覆盖保证对"等价位姿"成立而不是对欧氏坐标成立；MAC 按模态分别校准，并对**未校准模态显式弃权**——弃权只会触发 `a_ask`，绝不把"不知道"当成"安全"或"不安全"。关键反直觉点：**当歧义高时，正确动作不是选更可能的那个，而是求所有可信模态认证集的交集；交集为空就上交人类。**

**灵感 2（伦理与合规 → 不可补偿的准入门，而不是又一个代价项）**
直觉：v14 把安全、迁移、蒸馏、时间都做成预算，这让伦理合规极易被误接入——把"隐私成本""违规罚分"加进目标函数，然后用更多任务收益去"买"一次违规。这在工程上优雅，在规范上灾难：**伦理约束不是货币，不能被其他项冲抵**。但伦理也有自己的不确定性：感知可能把"违禁物"识别成"普通物"，规则可能有版本歧义，同意令牌可能过期或超范围。核心创新：**伦理合规准入（Ethical Compliance Admission, ECA）+ 默认拒绝门（Default-Negative Gate, DNG）+ 规范不确定性锥（Normative Uncertainty Cone, NUC）+ 同意/范围令牌（Consent & Scope Token, CST）**。ECA 输出三值 `allow / ask / deny`，且是**合取过滤器**而非加权项：任何违规都不能被更高的安全余量、任务价值或用户偏好抵消。DNG 规定"无法证明允许即拒绝或上交"。NUC 把"这条规则是否适用于当前情形"的不确定性显式化：只有当**置信集内每一种分类都允许**时才放行，等价于规范层面的保守扩张。CST 把同意做成带主体、目的、范围、期限、可撤回的令牌，动作所需的权限必须被**当前仍有效的令牌**覆盖。

**灵感 3（抓取×伦理 → 联合包络、最小披露见证与可逆性）**
直觉：抓取是机器人最"物理"的动作，也最容易越界：抓错对象、抓取未授权的人体部位、把摄像头对准隐私区域、把可识别的图像长期留存。伦理若只停留在"放行/拒绝"，仍无法回答事后"为什么允许"。于是需要把抓取证书与伦理门**合成一个联合包络**，并为每次执行生成**最小披露的审计见证**：只记录证书哈希、规则版本、决策承诺与签名，不记录原始图像或可识别特征；监管者可在不接触隐私数据的前提下验证"该决定确实由该规则集与该证书推出"。同时引入**可逆性/可撤回窗口（Retractability Window, RET）**：不可逆或不可撤回的抓取（易碎品、人体接触、不可释放夹持）必须升级为更高等级的同意或人类监督。核心创新：**伦理—抓取联合包络（Ethical-Grasp Envelope, EGE）+ 最小披露见证（Minimal-Disclosure Witness, MDW）+ 可逆性窗口（RET）**。三者把"抓得对"和"抓得该"合成同一个可证对象，并让 `Exec_v15⊆Exec_v14` 成为结构性事实而非事后检查。

**三者如何统一**
统一为 **v14 实现层之上的规范—物理联合准入层**：v14 回答"在毫秒预算内能安全实现多少"，v15 回答"这些可实现的抓取里，哪些在规范上被允许、且能被审计与撤回"。GPC 把位姿分布压成带覆盖保证的集合；ECA 把规范判断压成不可补偿的三值门；ACW 把两者压成可验证、可撤回、最小披露的见证。共享状态 `ζ_eg = (G_α, A_g, Ê, consent, R, W, rule_ver)`。**GPC 回答"哪些位姿抓得住"，ECA 回答"哪些抓取抓得该"，ACW 回答"凭什么、能不能撤回、事后如何证明"**。三者共享同一个"只收缩"语义：位姿证书只能排除位姿，伦理门只能排除动作，见证只能记录而不能授权。

## 1. 研究问题（轮次升级版）

- **Q1（抓取包络的可证覆盖）**：如何在 SE(3) 的对称商与多峰分布上定义单侧覆盖，使"认证集不包含真实不可行位姿"（安全性）与"不漏掉可行位姿"（活动性）同时可控？接触成功是伯努利而非连续误差，如何以成功下界而非位姿误差作为证书对象？模式稀疏或未校准时如何弃权而不误判？
- **Q2（伦理门的非补偿与不确定性）**：如何形式化"不可补偿"，使其在优化、路由、蒸馏、降级的每一步都不可绕过？规范不确定性锥如何构造与校准？感知分类错误如何传导到准入而不产生"错误地允许"？用户偏好 `α_user` 与伦理门冲突时谁优先？
- **Q3（审计与可逆性）**：最小披露见证如何同时满足隐私与可验证？哈希链/承诺如何抵抗事后篡改与重放？可逆性窗口如何与 v14 的 `P^rt`、中止点与时限语义衔接而不产生"已执行才判断不可逆"的缝隙？
- **Q4（兼容与活性）**：ECA 是否会把系统压成"永远 ask"从而被用户关闭（伦理层被绕过）？GPC 与 v14 的 TGC/DGC 概率证书误差是否会相加？三者全失效能否严格退回 v14？新增开销能否守住 50Hz/p99≤22ms？

## 2. 设计原则（在 P22–P24 基础上新增 P25–P27）

**P25 抓取认证保守律（Grasp Certification Conservatism）**
CGE 只输出被证书验证的位姿，认证集必须是真实可行集**单侧子集**；对称用商度量，多峰必须模态条件化；未校准模态一律弃权并请求 `a_ask`，禁止把弃权当拒绝或放行；高歧义时只能用所有可信模态认证集的交集，交集为空即上交人类。任何"取 top-1 更省事"的捷径都不被允许。

**P26 伦理不可补偿律（Ethics is Non-Compensatory）**
伦理是合取过滤器而不是加权项：`Adm_E(a)=allow` 当且仅当规范置信集内每一种分类都允许、且有效同意令牌覆盖该动作。任何违规不得被安全余量、任务价值、用户偏好或蒸馏加速冲抵；不确定性一律落到 `ask` 或 `deny`，不落到 `allow`。伦理门只能缩小执行集。

**P27 审计最小披露与可逆优先律（Minimal-Disclosure Audit & Retractability First）**
每个被执行决定必须携带 MDW：只含承诺/哈希/规则版本/签名，不含原始敏感数据；不可逆动作必须满足 RET 或升级同意等级；撤回/吊销立即生效，且排队中的旧见证不得绕过吊销。见证用于事后问责，绝不用于放行。

## 3. 与基线的接口（如何退化）

- GPC 失效 ⇒ 退回单点位姿 + v14 物理/抓取证书，无对称商、无多峰聚合，**等价 v14 抓取路径**；
- ECA 失效 ⇒ `Adm_E≡allow`（仅记录元指标 `η_E` 供审计），**等价 v14 执行集**；
- ACW 失效 ⇒ 不生成见证、不做可逆性升级，**等价 v14 执行（无审计）**；
- GPC+ECA+ACW 全失效 ⇒ MetricVoiceGauge-NCD-HUTDH v14，再沿 v14 退化链退回 v13/v12/…/v6；
- **安全继承**：GPC 只排除位姿，ECA 只排除动作，ACW 只记录不授权；三端口互不相交，均不能新增授权或放宽任何阈值；`Exec_v15⊆Exec_v14` 由引理 128 保证。

## 4. 预期贡献

1. **认证抓取包络**：把抓取位姿估计从单点回归改写为带对称商覆盖、多峰聚合与显式弃权的认证集合，填补"抓取不确定性不可证"的空白；
2. **非补偿性伦理准入**：把伦理合规从可交易代价改写为默认拒绝的三值合取门，并给出规范不确定性下的保守性保证；
3. **最小披露审计与可逆性**：把"为什么允许"做成隐私友好、可验证、可撤回的见证，使问责与隐私不再互斥；
4. **规范层—物理层联合收缩**：用 `Exec_v15=Exec_v14∩G_α∩Adm_E` 把加速、抓取与伦理解耦，E661–E676 覆盖对称覆盖、多峰弃权、非补偿红队、同意撤销、审计完整性与端到端。

## 5. 本轮最大风险

**一句话**：各层证书各自成立——位姿在对称商内被覆盖、物理余量非负、伦理门返回 `allow`、审计链完整——但它们共享同一个可能出错的感知与规则来源；当分布漂移或对抗样本同时污染对象分类与适用规则时，系统会输出一个形式完全合规、可审计、可撤回、却抓错对象或越过同意边界的抓取，即**"合规清洗"下的实质错误**（ laundered compliance）。

**定义 607（抓取位姿与对称商 Grab Pose & Symmetry Quotient）**
抓取位姿 `g=(R,t)∈SE(3)`；物体对称群 `Sym(o)⊆SE(3)` 为保持物体几何与语义不变的刚体变换子群（有限群或紧群）。对 `g,g'` 定义对称商度量
```
d_Sym(g,g') = inf_{s∈Sym(o)} d_SE3(g, s·g') ,
```
其中 `d_SE3` 为 SE(3) 上双不变度量。称 `g` 与 `s·g` 为**等价位姿**。抓取证书的一切覆盖/误差结论都在 `d_Sym` 下陈述，而非在欧氏坐标下陈述。

**定义 608（认证抓取包络 Certified Grasp Envelope, CGE）**
设 `m_g(x,o,g)` 为可行性余量，`τ_g` 为单侧共形阈值。定义
```
G_α(x,o) = { g∈SE(3) : m_g(x,o,g) ≥ τ_g } .
```
证书对象不是位姿误差，而是**抓取成功/可行性的单侧下界**。要求 soundness：
```
P( G_α(x,o) ⊆ G_true(x,o) ) ≥ 1−α_g ,
```
其中 `G_true` 为满足力闭合、无碰撞、可达、成功概率 ≥p_min 的真实位姿集。活动性（不误排除可行位姿）单列为 `P(g*∈G_α | g*∈G_true)` 指标，不参与安全性断言。若 `G_α=∅`，唯一合法结论是 `a_ask/fallback`，**不得回退到未认证 top-1**。

**定义 609（对称商共形 Symmetry-Quotient Conformal, SQC）**
校准集按模态 `k` 分组，对每个 `(x,o,g)` 记录非一致性分数
```
E_i = d_Sym(g_i, Ĝ(x_i,o_i))    或    E_i = m_true(x_i,o_i,g_i) − m_g(x_i,o_i,g_i) ,
```
取有限样本修正的 `⌈(1−α_k)(n_k+1)⌉` 阶次序统计量 `q_{α_k}`（对可行性余量做单侧修正）。若 `n_k < n_min` 或该模态不在校准支撑内，则标记 `unknown`。SQC 的作用是把"对称等价"折叠掉，使同一覆盖预算不被分散到多个等价坐标上。

**定义 610（多峰聚合证书 Multimodal Aggregation Certificate, MAC）**
设位姿预测给出 `K` 个模态及后验 `{p_k}_{k=1..K}`。对每个模态，若 `k` 已校准，令 `G_{α,k} = {g∈mode_k : m_{g,k}(x,o,g) ≥ τ_{g,k}}`；否则 `G_{α,k}=∅` 且记 `k∈U`（未校准）。定义
```
G_α = ⋃_{k∉U} G_{α,k} ,      abstain = 1[ U≠∅ 或 A_g>A_max 或 Δ_sep<δ_sep ] ,
```
其中 `Δ_sep=p_(1)−p_(2)`。`abstain=1` 时只允许 `a_ask` 或定义 611 的交集动作，**不得从 `G_α` 直接放行**。任一未校准模态只能导致"更保守"，不能导致"更宽松"。

**定义 611（抓取歧义度与歧义交集 Grasp Ambiguity & Intersection）**
```
A_g(x) = 1 − max_k p_k ,        K_plaus(x) = { k : p_k ≥ p_max − δ_p } .
```
当 `abstain=1` 但 `K_plaus` 已知时，允许执行**交集抓取**
```
G_∩(x,o) = ⋂_{k∈K_plaus} G_{α,k} ,
```
即一个在所有可信模态下都被认证的位姿。若 `G_∩=∅`，唯一合法动作是 `a_ask`。语义：**歧义不是猜测的许可证**。

**定义 612（伦理合规准入 Ethical Compliance Admission, ECA）**
规则集 `R_E = {r_1,…,r_m}`，每条规则对 `(x,o,a)` 给出 `{allow,ask,deny}`。定义合取门
```
Adm_E(x,o,a) = deny   若 ∃r: verdict_r=deny
             = ask    若 ¬∃r: deny，且 (∃r: verdict_r=ask 或 ∃r 不确定)
             = allow  当且仅当 ∀r: verdict_r=allow
```
DNG（默认拒绝）规定：规则缺失、规则版本不可验证、分类不可判定、同意不可验证，一律落入 `ask/deny`，**永不落入 `allow`**。ECA 不以任何标量代价进入目标函数；它只在执行集上做交集 `Exec←Exec∩{a:Adm_E=allow}`。

**定义 613（规范不确定性锥 Normative Uncertainty Cone, NUC）**
设分类器输出置信集 `Ê(x)⊆C`，满足 `P(c*(x)∈Ê(x)) ≥ 1−β`。对规则 `r` 的鲁棒求值定义为
```
verdict_r = allow  若 ∀c∈Ê(x): r(c,o,a)=allow
          = deny   若 ∀c∈Ê(x): r(c,o,a)=deny
          = ask    其他（Ê 内存在分歧）
```
于是 `allow` 只在**规范置信集内每一种分类都允许**时出现。这是 deontic conservatism：对"规则是否适用"的不确定性取最保守侧，与 v13 的"保守起点 anytime"、v14 的"漂移安全塌缩"同构。

**定义 614（同意与范围令牌 Consent & Scope Token, CST）**
令牌 `τ_c = (holder, purpose, scope, target, expiry, max_uses, revocable, nonce, sig)`。动作 `a` 需要权限 `req(a)`。定义
```
consent_ok(a) = ∃τ_c : holder 有效 ∧ purpose 匹配 ∧ req(a)⊆scope(τ_c)
                ∧ target 匹配 ∧ now≤expiry ∧ used<max_uses
                ∧ τ_c∉RevokedList ∧ sig 验证通过 .
```
吊销/到期/超范围立即生效；排队中携带旧令牌的动作必须在执行前重新验证，不得以"决策时有效"绕过。

**定义 615（最小披露审计见证 Minimal-Disclosure Witness, MDW）**
对每个执行决定生成
```
W = ( Commit_s(x), Commit_s(G_α), MerkleRoot(cert_hashes), policy_hash,
      decision, W_prev_hash, timestamp, nonce, sig_engine ) ,
```
其中 `Commit_s(·)` 为带盐承诺，`s` 为一次性盐。仅当审计需要选择性披露时提供对应明文与盐。验证者检查哈希链连续性、`policy_hash` 与已登记规则版本一致、`decision = f(承诺值, 证书根, 规则版本)`。**见证不参与授权**，只用于事后问责；`W` 不存原始图像、点云或可识别特征。

**定义 616（可逆性窗口 Retractability Window, RET）**
动作 `a` 在窗口 `τ` 内**τ-可逆**，若存在释放/回撤/松爪策略 `ρ_rel` 使
```
P( 在 τ 内安全释放 ∨ 安全退回可接受状态 ) ≥ 1−γ .
```
否则称 `a` 为 τ-不可逆。τ-不可逆动作要求 `consent_level(a) ≥ L_irr` 且 `R(a,τ)=1`；不满足则 `Adm_E` 强制至少 `ask`。RET 与 v14 的 `P^rt`、中止点、`B_time` 合取：**不可逆性不能靠"事后中止"补偿**。

**定义 617（伦理—抓取联合包络 EGE 与 v15 执行集）**
```
Exec_v15(x,o) = { a : a∈Exec_v14(x)
                    ∧ a = execute(g), g∈G_α(x,o)（或 g∈G_∩）
                    ∧ Adm_E(x,o,a)=allow
                    ∧ consent_ok(a)
                    ∧ ( R(a,τ)=1 ∨ consent_level(a)≥L_irr )
                    ∧ W 已生成且链有效 } .
```
注意 `Adm_E=ask` 时动作只能转为 `a_ask`，不能转成 `allow`；`G_α`/`Adm_E` 只能做交集。于是 `Exec_v15⊆Exec_v14` 是定义层面的结构性事实。

# IP-392/393/394 GPC + SQC + MAC：认证抓取包络
class GraspPoseCertifier:
    def __init__(self, margin_fn, tau_g, sym_group, n_min, A_max, delta_sep, delta_p):
        self.margin_fn = margin_fn          # (x,o,g) -> 可行性余量
        self.tau_g = tau_g                  # 单侧共形阈值（按模态）
        self.Sym = sym_group                # 物体对称群
        self.n_min, self.A_max = n_min, A_max
        self.delta_sep, self.delta_p = delta_sep, delta_p

    def d_sym(self, g, gp):
        return min(d_se3(g, compose(s, gp)) for s in self.Sym)   # 对称商度量

    def certify(self, x, o, modes):
        # modes: [(p_k, hypotheses_k, calibrated_k)]
        G_alpha, U = {}, set()
        for k, (p_k, hyps, calib) in enumerate(modes):
            if not calib:
                U.add(k); continue
            G_alpha[k] = [g for g in hyps
                          if self.margin_fn(x, o, g) >= self.tau_g[k]]
        A_g = 1.0 - max(p_k for p_k, _, _ in modes)
        p_sorted = sorted((p_k for p_k, _, _ in modes), reverse=True)
        delta_sep = (p_sorted[0] - p_sorted[1]) if len(p_sorted) > 1 else 1.0
        abstain = bool(U) or A_g > self.A_max or delta_sep < self.delta_sep
        if abstain:
            K_plaus = [k for k, (p_k, _, _) in enumerate(modes)
                       if p_k >= p_sorted[0] - self.delta_p and k not in U]
            G_cap = intersect_all(G_alpha[k] for k in K_plaus)
            return G_cap, A_g, True        # 空集 => 调用方必须 a_ask
        return union_all(G_alpha.values()), A_g, False


# IP-395/396/397 ECA + NUC + CST：非补偿伦理门
class EthicalComplianceAdmission:
    def __init__(self, rules, classifier, confidence_set_fn, consent_store):
        self.rules = rules
        self.classifier = classifier
        self.Conf = confidence_set_fn
        self.consent = consent_store

    def verdict_rule(self, r, C_hat, o, a):
        verdicts = {r(c, o, a) for c in C_hat}
        if verdicts == {"allow"}: return "allow"
        if verdicts == {"deny"}:  return "deny"
        return "ask"                     # Ê 内分歧 => 保守

    def admit(self, x, o, a):
        C_hat = self.Conf(x)             # 置信集 Ê(x), P(c*∈Ê)>=1-beta
        vs = [self.verdict_rule(r, C_hat, o, a) for r in self.rules]
        if "deny" in vs:
            return "deny"
        if "ask" in vs:
            return "ask"
        if not self.consent.consent_ok(a):   # 范围/目的/期限/吊销
            return "ask"
        return "allow"


# IP-398/399 ACW + RET：最小披露见证与可逆性
class AuditComplianceWitness:
    def __init__(self, ledger, signer, release_policy):
        self.ledger, self.signer, self.release = ledger, signer, release_policy

    def retractable(self, a, tau):
        return self.release.success_prob(a, tau) >= 1.0 - self.release.gamma

    def seal(self, x, G_alpha, certs, policy_hash, decision):
        W = {
            "h_x": commit(salt(), x),                 # 不存原始图像/点云
            "h_g": commit(salt(), G_alpha),
            "certs": merkle_root([hash_cert(c) for c in certs]),
            "policy": policy_hash,
            "decision": decision,
            "prev": self.ledger.head_hash(),
            "ts": now(), "nonce": fresh_nonce(),
        }
        W["sig"] = self.signer.sign(W)
        self.ledger.append(W)
        return W

## 4. 推导

**引理 125（对称商共形的覆盖守恒）** 设 `Sym(o)` 为紧对称群，校准样本按模态内可交换，非一致性分数在商度量 `d_Sym` 下计算，阈值取 `⌈(1−α_k)(n_k+1)⌉` 阶次序统计量。则对同分布新样本
```
P( d_Sym(g*, G_α) ≤ q_{α_k} ) ≥ 1−α_k ,
```
且对可行性的单侧修正版本有 `P(G_α⊆G_true) ≥ 1−α_g`。反之，若在欧氏坐标上直接做共形，对称物体可构造分布使覆盖趋于 0。证明：商映射 `π:SE(3)→Sym(o)\SE(3)` 为可测且交换性在 `π` 下保持，故标准分裂共形在商空间成立；欧氏反例取 `Sym={e,s}` 且真实位姿以 1/2 概率落在 `g0`、`s·g0`，两者欧氏距离大而商距离为 0，任何小于该距离的欧氏球只能覆盖其一。∎ 推论：**对称不是噪声，不能被更多数据平均掉，必须在度量层面折叠**。

**引理 126（多峰覆盖与弃权安全）** 若每个已校准模态满足引理 125 且 `n_k≥n_min`，则
```
P( g*∉G_α ∧ abstain=0 ) ≤ Σ_{k∉U} α_k + P( mode(g*)∉K_plaus ) .
```
未校准模态 `U≠∅` 时 `abstain=1`，动作只能走 `a_ask`/交集路径，不会由未验证模态放行。证明：`{g*∉G_α}` 蕴含 `g*` 所属模态未覆盖或不在 `G_α`，对已校准模态用并集界；`abstain` 的定义保证 `U≠∅` 时直接排除直接放行。∎ 推论：**弃权把"不知道"转成"问人"，而不是转成"安全"或"不安全"**。

**引理 127（歧义交集安全与误差合成）** 若对 `k∈K_plaus` 有 `P(G_{α,k}⊆G_true,k) ≥ 1−α_k`，则任意 `g∈G_∩=⋂_{k∈K_plaus}G_{α,k}` 满足所有可信模态的可行性，概率至少 `1−Σ_{k∈K_plaus}α_k`。若 `G_∩=∅`，系统只能 `a_ask`。再与 v14 的 TGC/DGC 合成时，联合安全界为 `1−α_g−Σ_kα_k−α_gap−α_dis`。证明：交集的每个元素属于每个 `G_{α,k}`，逐模态用 soundness 并对失败事件取并集界；与 v14 证书取交集不增加误放行，只增加漏放行。∎ 推论：**歧义越大，交集越小、越安全、活动性越低；活动性损失可预算但不可忽略**。

**引理 128（伦理门的非补偿性与子集保持）** `Exec_v15⊆Exec_v14`，且对任意效用函数 `J`、任意安全余量 `m`、任意 `α_user`，若 `Adm_E(x,o,a)≠allow`，则 `a∉Exec_v15`，与 `J` 和 `m` 无关。证明：`Exec_v15` 按定义对 `Exec_v14`、`G_α`、`Adm_E=allow`、`consent_ok`、`R∨升级` 取交集；目标函数只在交集内排序，不参与交集成员资格；`α_user` 只能改 `θ_{S,user}` 与同集合内排序。∎ 推论：**伦理不可被"买通"，因为它根本不在可交易的坐标里**。

**引理 129（规范不确定性下的保守性）** 设 `P(c*∈Ê(x))≥1−β`，`verdict_r` 按定义 613 的鲁棒规则求值。则
```
P( Adm_E=allow ∧ 实际违规 ) ≤ β .
```
证明：若 `Adm_E=allow`，则对每条 `r` 有 `∀c∈Ê(x): r(c,o,a)=allow`；若实际违规即 `r(c*,o,a)=deny`，则必有 `c*∉Ê(x)`，其概率 ≤β。∎ 推论：**分类器越不确定，`Ê` 越大，`allow` 越难出现——不确定性被转成假拒绝/上交，而不是假接受**。

**引理 130（中立元退化等价 v14）** 将定义 618 的八个中立元分别注入 GPC/SQC/MAC/ECA/NUC/CST/ACW/RET 端口，则抓取证书退化为 v14 单点路径、伦理门退化为 `allow`、审计退化为无、可逆性退化为不升级；主闭环调用序列与 v14 逐位一致，再沿 v14 链退回 v13/…/v6。证明：逐端口代入定义 618，并用定义 607–620 的边界条件核对；八端口互不相交且中立元不改变 v14 任何证书检查。∎

**引理 131（见证完整性、最小披露与吊销）** 设哈希与承诺满足抗碰撞与隐藏性。则：(i) 任何对 `W` 中记录的修改都会破坏哈希链或签名，验证失败；(ii) 验证者从 `W` 与选择性披露中只能得到被披露字段，不能恢复 `x` 的其余内容；(iii) 若令牌在执行前被吊销，则 `consent_ok(a)=0`，动作不可执行，即使其见证在吊销前已生成。证明：(i) 哈希链归纳 + 签名不可伪造；(ii) 承诺隐藏性 + 选择性披露只打开指定字段；(iii) `consent_ok` 在执行前重新查询 `RevokedList`，定义 614 与定义 617 的合取强制 `allow` 失败。∎ 推论：**审计与隐私可以同时成立，但代价是验证需要承诺方案而非明文**。

**引理 132（预算守恒 v15）** 新增在线成本上界：GPC/SQC/MAC 查表与阈值比较 `O(K+|G_α|)` ≤0.4ms；ECA 规则求值 `O(|R_E|·|Ê|)` ≤0.05ms（规则数受限时）；CST 查询 `O(1)` ≤0.02ms；MDW 哈希+签名 ≤0.05ms；RET 查表 ≤0.02ms。总决策 p99 仍 ≤22ms，50Hz 保持；离线共形校准与规则审计不在关键路径。证明：逐项代入复杂度表并做静态 EDF 校验 `ΣŴ_m≤B_dec`；`B_safe` 与 `B_audit` 硬预留保证时间不被签名称谓意外耗尽。∎

## 8. 已知风险与失效模式

1. **对称群估计错误**：若 `Sym(o)` 被低估，SQC 会把等价位姿当不同位姿，覆盖重新失效；若被高估，可能把不同抓取误判为等价。缓解：几何+语义双通道估计、对称群保守化（宁可高估后人工确认）、部署前对称压力测试。

2. **模态聚类失败**：多峰被合并成一个模态会掩盖歧义，MAC 与交集都失效。缓解：多假设输出、聚类稳定性检查、`Δ_sep` 触发弃权、模态数上限触发 `a_ask`。

3. **弃权导致活动性塌缩**：`n_min`/`A_max` 过严会频繁 `a_ask`，用户体验下降后可能有人试图关闭伦理层。缓解：把假拒绝计入预算、优先补采高频场景、提供"为什么 ask"的可解释见证、绝不提供全局关闭开关。

4. **规范不确定性锥过宽**：`Ê` 越宽越安全但越常 `ask`；分类器校准差时可能永远无法 `allow`。缓解：校准分类器、缩小类别空间、分层规则（先粗后细）、对高风险类别保留宽锥。

5. **规则集本身错误或过期**：门只能执行给定规则，无法判断规则是否正当。缓解：规则版本化 + `policy_hash` 审计、外部合规审查、规则变更需重新预注册、保留"规则未知即 deny"。

6. **同意令牌的语义漂移**：`scope`/`purpose` 在长周期任务中可能被重新解释，导致"范围合法但意图不符"。缓解：最小范围、短期限、显式目的绑定、执行前复述确认、可撤回。

7. **见证隐私副作用**：承诺虽隐藏内容，但元数据（时间、频率、对象类别）仍可能泄露。缓解：最小化元数据、盐随机化、批量/差分隐私、访问控制与保留期限。

8. **审计链可用性单点**：`W` 生成失败或签名服务不可用会阻塞执行，反而促使绕过。缓解：本地预置密钥、签名失败即降级为"记录待签"并禁止高风险动作、链故障触发最低档。

9. **可逆性误判**：`R(a,τ)` 的成功率估计在真实接触下可能过于乐观，导致本应升级的动作被直接执行。缓解：保守下界、接触仿真+硬件在环、不可逆类别白名单硬编码为需升级。

10. **伦理门被"合规清洗"**：各层证书都成立，但共享的感知/分类/规则来源被污染，形成形式合规而实质错误。缓解：独立真值锚定、跨源交叉验证、对抗审计、把"分类来源不确定性"纳入 NUC、高风险场景强制人类确认。

11. **伦理门与用户偏好冲突**：用户可能试图用 `α_user` 或任务价值绕过门。缓解：`reconcile_preference` 结构上禁止抬升 `ask/deny`、冲突时记录并上报、`η_α`/`η_E` 元指标留痕。

## 9. 本轮最大风险

**一句话**：位姿证书、物理余量、伦理门与审计链各自都成立，但它们共享同一套可能出错的感知、分类与规则来源；当分布漂移或对抗样本同时污染这三者时，系统会输出一个对称商认证、物理安全、伦理 `allow`、审计完整、可撤回——却抓错对象或越过同意边界的抓取，即**被"合规清洗"的实质错误**。
