# 第 4 轮（灵感驱动研究循环；本轮灵感：「数据增强」×「平衡控制」）

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v21+IP-425–430（SDC/CAC/DCL/GIC/HPC+/CFC+ 语义-合规层；其上承 v20 联邦感知证书 PCA/CTS/CFC/HPC/CFCtrl、v19 DCM/OGCC/CCV/DRS/OGC、v17 CLP/S2C/HCG/PSV/APS/AMC）。
> 本轮纪律：**增强是"威胁模型的可构造轨道"而非"更多训练数据"；平衡是"安全动作的动态可行核"而非"又一条静态约束"**。不推倒 v21：SDC/CAC/DCL/GIC/HPC+/CFC+ 全部保留，v20/v19/v17 全部保留。本轮只做一件事：**把 v21 的"静态快照证书"升级为"轨道可证伪 + 动力学可行"的证书体系，并正面封堵 v21 最大风险——κ_c 静态经验假设导致的"合规缺席幻觉"**。

## 0. 直觉与动机

**灵感 1（数据增强 → 召回不是常数，而是可构造、可分层、可证伪的"外观轨道"性质）**
直觉：v21 把召回率 κ_c 当成一个全局常数（"这套检测器平均能检出 95% 的人"），而最大风险恰恰是"平均"掩盖了系统性漏检：儿童、轮椅、蹲姿、逆光下的老人。数据增强的第一反应是"多合成这些样本去训练"——但这在安全上是一个**不可证的承诺**：训练集变好了，不等于运行时召回有下界。真正可用的转念是：**增强定义了一个"语义保持变换群 G"及其轨道 Orb_G(z)；召回应当是这个轨道上的性质，而不是训练集上的统计**。沿轨道做多视图推理可以提升召回，但轨道视图高度相关（同一张图调亮度不是独立观测），所以提升必须由"视图独立性证书"来支付，否则只算一票。更关键的是反向用法：**用增强去主动构造"漏检见证"**——在轨道内搜索检测器看不见的合成人，一旦找到，就直接拉低召回下界并拒绝签发缺席证书。于是 κ_c 从"拍脑袋的经验常数"变成**被夹逼的区间**：轨道并集（在独立性成立时）给出更高的召回下界，审计见证给出经验召回下界；AbsCert 只用两者中更保守的一端。
严谨定义：设 `Orb_G(z)={g·z:g∈G}`，G 含光照/尺度/视角/姿态/部分遮挡等**不改变"此处有人"真值、只改变可观测性**的变换。定义轨道缺席规则 `Abs_orb(z,Ω)=∧_{g∈G}(区域Ω在 g·z 上零检出)`，它只能降低假缺席（单调更安全）。设单视图分层漏检上界 `δ_s=1-κ_s`、视图有效独立数 `m_eff(ρ_view)`，则轨道并集漏检 `≤ (1-κ_s)^{m_eff}`；若独立性不可证（`m_eff→1`），轨道退化单视图、提升不予兑现。审计集 N 上找到 |W| 个见证，则以单侧置信 `recall ≥ ClopperPearson_lower(1-|W|/N, α)`。取 `κ_lb = min(轨道下界, 审计下界)` 签发 AbsCert。分层标定：κ_c(g) 按人群/视况分层，用**加权 conformal**（密度比 `w(z)=p_target/p_aug`）把合成样本的标定迁移到目标分布，并显式要求支撑重叠。

**灵感 2（平衡控制 → 安全动作集不是"几何空闲"，而是"动力学可行核"；制动能力随平衡裕度变化）**
直觉：v21 的证书只问"会不会碰、该不该做"，默认机器人"想停就停、想拐就拐"。但足式/人形机器人真正的物理约束是：**能不能在失衡前停住**。平衡控制的中心对象是捕获点（capture point）ξ 与支撑多边形 S：ξ 必须被拉回 S 内。于是"安全"不只是碰撞裕度，还要有**平衡裕度 b(x)=dist(ξ,∂S)**。更微妙的是：**制动能力本身依赖平衡状态**——当 ξ 逼近支撑边界时，最大减速度 a_max(ξ) 急剧下降，制动距离 `d_brake(v,ξ)=v²/(2a_max(ξ))` 反而变大。也就是说，"越接近摔倒，越停不下来"——这是一个会自我放大的风险回路。反过来，平衡也带来**能力**：迈步可以扩展有效支撑，使某些静态不可行的避让/停车变得可行。所以平衡既**收缩**（近边界时）又**扩张**（迈步时）安全动作集，必须用可行核（viability kernel）而不是单条约束来刻画。
严谨定义：LIPM 下 `ξ=x+ẋ/ω`，`ω=√(g/h)`。鲁棒平衡裕度 `b_rob(x)=dist(ξ,∂S)-L_b·σ_x-w_bound`。定义静态可行核 `K_static={x:b_rob(x)≥b_min ∧ ∃σ_stop 使轨迹内 b_rob≥b_min 且碰撞自由}` 与迈步可行核 `K_step⊇K_static`（仅在地形/落脚可达性已认证处）。状态相关制动包络 `d_brake(v,x)=v²/(2a_max(x))+v·t_lat`，其中 `a_max(x)` 随 `b_rob` 单调下降。SafeStop 升级为**认证平衡停机 CBS**：优先减速停，其次迈步停，再次受控下蹲；每一步都要求轨迹内碰撞自由且 `b_rob≥b_min`。

**灵感 3（二者如何统一：感知-平衡安全预算是一条恒等式，而不是两个模块）**
直觉：v21 把感知与执行当两条平行链。但物理上它们被一条**刹车距离恒等式**绑死：要在人出现前停住，探测距离必须覆盖"制动距离 + 反应延迟 + 安全裕度"；而制动距离又由平衡裕度决定。于是"看得多远""停得多快""站得多稳"是同一个预算的三个项。任何一项变差，只能**降速或停机**，不能靠另一项"补回来"。增强在这里的作用是给这条恒等式提供**最坏情形的人**（突然窜出的儿童、跌倒的人），平衡给出**最坏情形下的响应能力**（被推/滑移时还能否停住）。两者合成的威胁模型是联合分布 `(外观, 运动, 扰动)`，其轨道由增强定义，其可行响应由平衡可行核定义。
严谨定义：`R_detect(v,x) = d_brake(v,x) + r_safe + r_lat·v`；速度可行当且仅当 `Cov^orb_t ⊇ tube(path(x,v), R_detect(v,x)) ∧ Abs_orb 在该 tube 上有效 ∧ x∈K_static/K_step`。因为 `d_brake` 随 v 增、`a_max` 随 `b_rob` 减，可行速度集是区间 `[0, v*(x,Cov)]`，且 `v*` 对平衡边际与覆盖半径都单调不增。

**三者如何统一**
统一为 **v21 之上的"轨道可证伪 + 动力学可行"层（Orbit-Falsifiable, Dynamically-Viable Certificate System, OFDV）**：AOC/AAA 回答"我凭什么相信在这条外观轨道上能看见/看不见"，BVC/CPB 回答"我凭什么相信这个动作在物理上停得住、站得稳"，CBS 回答"停不下来时如何安全降级"。共享状态扩展为 **ζ_ordv = ζ_sem ∪ (Orb_t, κ_lb, W_t, x, ξ_t, b_rob, K_t, budget_t)**。统一准入门升级为 **HPC++ = (HPC, CC, AbsCert_orb, BVC, budget_ok) 五证一体**：几何 SAFE ∧ 规范允许 ∧ 轨道负信息可靠 ∧ 平衡可行 ∧ 预算自洽。关键守恒点：**平衡只做"在 v21 已认证自由空间内的动态可行性筛选"，迈步不越出 v21 几何域；增强只做"证据替换/证伪"，不放宽任何约束**——故 `Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18` 由构造保持。

## 1. 研究问题（轮次升级版）

- **Q1（轨道召回的可证性）**：G 如何定义才既覆盖真实人体形态（儿童/轮椅/蹲姿/逆光）又不引入大量非语义变换？视图有效独立数 `m_eff` 如何从共漏率估计并给出置信下界？分层 `κ_c(g)` 的加权 conformal 在支撑不足时如何 fail-safe？轨道并集带来的召回提升与假阳性上升如何权衡？

- **Q2（主动证伪与追溯失效）**：AAA 的搜索分布如何覆盖"未知未知"而不只是已列举的稀有类？反事实缺席注入的合成人真实性差距如何量化并计入 `δ_abs`？见证如何追溯性地使已签发证书失效并触发重新验证？审计集与部署分布不一致时，经验下界还有何意义？

- **Q3（平衡可行核的鲁棒性）**：LIPM/质心动力学在滑移、软地面、负载变化下的模型误差如何进入 `b_rob`？迈步可行核的落脚可达性与地形认证如何在线获得？`a_max(x)` 的保守标定如何避免"越怕摔越不敢动"的活性死锁？`K_step` 只恢复不扩张的边界如何严格保证？

- **Q4（耦合预算与时序）**：`R_detect(v,x)` 与 v21 的 `τ_consensus`/APS 新鲜度、DCL 的 `τ_rule` 如何统一成一条时序预算？CBS 的停机时间 `t_CBS` 如何反馈到义务期限？CFC++ 的"模态×轨道"双多样性如何避免把同源增强视图当独立票？10Hz 语义层与 50Hz 控制环如何在平衡约束下协调？

## 2. 设计原则（在 P34–P36 基础上新增 P37–P39）

**P37 轨道可证伪律（Orbit Falsifiability）**
AbsCert 仅在"轨道最坏情形已被 AAA 审计且视图独立性已证"时签发；κ 用审计见证下界与轨道并集下界夹逼，取更保守端；见证出现即拒发并追溯降级依赖该证书的决策。轨道之外的区域一律保守（"未知未知"按有人处理），绝不用"已增强覆盖"替代"已审计"。

**P38 动态可行律（Dynamic Viability）**
任何准入动作须落在 BVC 可行核内：`b_rob(x)≥b_min` 且存在可行停机策略；制动能力 `a_max(x)` 随 `b_rob` 单调下降，故制动距离随平衡边际单调上升。迈步仅在 v21 已认证自由空间与已认证落脚点内使用，且不扩张 v21 几何域；无法认证时退回静态核。失效方向只能是更低速、更小步、更保守。

**P39 感知-平衡预算守恒律（Perception–Balance Budget）**
`v` 可行 ⟺ `Cov^orb_t ⊇ tube(R_detect(v,x))` ∧ `Abs_orb` 在该 tube 上有效 ∧ `x∈K`。任一因子（覆盖、制动、延迟、平衡）变差只能降速/停机，绝不用放宽另一因子来补偿；`t_CBS` 必须计入 DCL 义务期限，停机时间超期即 SafeStop 升级。

## 3. 与基线的接口（如何退化）

- AOC 失效（轨道/标定不可用）⇒ 回退 v21 的全局 `κ_c`（更保守或等价）；
- AAA 失效（审计搜索不可用）⇒ 无见证下界，AbsCert 退回"轨道外一律保守"；
- BVC 失效（动力学模型不可信）⇒ 静态支撑多边形 + 限速 `v_safe_static`（比默认更保守）；
- CPB 失效（预算不可计算）⇒ `v = min(v21_cap, v_balance_static)`；
- CBS 失效（无认证停机）⇒ 受控下蹲 + 全域低速（可审计降级，非静默）；
- 平衡相关全失效 ⇒ 完全回退 v21 几何-规范证书；
- 增强相关全失效 ⇒ 完全回退 v21 的 SDC/CAC 行为；
- **安全继承**：增强只做证据替换/证伪（不放宽约束），平衡只做 v21 域内动态筛选（迈步不越界），CFC++ 只加严仲裁；任意失效都向保守方向退化，故 `Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`（引理 170）。

## 4. 预期贡献

1. **轨道化召回证书**：把召回从"全局常数"重构为"语义保持变换群上的分层性质"，给出见证下界与轨道并集下界的夹逼，并把视图相关性显式计入（不独立则提升不予兑现）；
2. **增强的证伪范式**：AAA 主动搜索漏检见证 + 反事实缺席注入（负对照），把 v21 的 `κ_c` 经验假设变成可被主动打脸、可追溯失效的区间；
3. **平衡条件化可行核**：捕获点鲁棒裕度、状态相关制动包络 `a_max(x)`、静态/迈步双可行核，显式建模"越接近摔倒越停不下来"的风险回路；
4. **感知-平衡安全预算恒等式**：探测距离、制动距离、稳定裕度统一为一条预算，速度可行区间对平衡边际与覆盖半径单调，杜绝"用一项补偿另一项"；
5. **认证平衡停机 CBS**：减速停/迈步停/受控下蹲三级可审计降级，替代 v21 的瞬时 SafeStop；
6. **HPC++ 五证一体与 CFC++ 双多样性**：几何 ∧ 规范 ∧ 轨道负信息 ∧ 平衡可行 ∧ 预算自洽；模态×轨道双多样性封堵同源增强视图伪造共识；`Exec_v22 ⊆ v21` 闭环。

## 5. 本轮最大风险

**一句话**：v22 的两张新证书都只在"模型内的最坏情形"成立——增强群 G 定义了"能被想象的人"，LIPM/质心动力学定义了"能被执行的平衡"；真实危险恰是 G 之外的人体形态与模型之外的接触（滑移、软地、被推），此时系统会带着两份形式完美的证书撞人或摔倒——**"闭世界增强 + 模型内平衡"的双重幻觉**。

        self.strata = strata                    # 分层指派
        self.kappa = kappa_by_stratum           # 每层召回下界 κ_c(g)
        self.indep = independence               # 视图独立性证书（共漏率）
        self.wconformal = weighted_conformal    # 密度比加权 conformal
        self.alpha = alpha

    def orbit_views(self, z):
        return [g.apply(z) for g in self.group.sample_orbit()]

    def issue_absence(self, z, region):
        views = self.orbit_views(z)
        # 1. 轨道缺席：任一视图在 region 检出人 ⇒ 不是缺席
        if any(self.detector.detect_in(v, region) for v in views):
            return None, "DETECTION_IN_ORBIT"
        # 2. 独立性证书：不独立则轨道提升不予兑现（按单视图保守计）
        s = self.strata.assign(region)
        kappa_s = self.kappa[s]
        if self.indep.certified(views, alpha=self.alpha):
            m_eff = self.indep.effective_count(views)
            kappa_orb = 1.0 - (1.0 - kappa_s) ** m_eff
        else:
            kappa_orb = kappa_s                # 保守回退
        # 3. 审计下界（AAA 见证会拉低它）与轨道下界取更保守者
        kappa_audit = self.auditor.kappa_lower(region)   # 见 IP-432
        kappa_lb = min(kappa_orb, kappa_audit)
        if kappa_lb <= 0.0:
            return None, "FALSIFIED_OR_UNSUPPORTED"
        return AbsCertOrb(region=region, kappa=kappa_lb,
                          delta=1.0 - kappa_lb,
                          orbit=self.group.fingerprint,
                          strata=s), "OK"


# IP-432 Adversarial Augmentation Auditor
class AdversarialAugmentationAuditor:
    def __init__(self, detector, generative, threat_model, orbit_cert,
                 audit_n=2000, alpha=0.01):
        self.detector = detector
        self.generative = generative            # 合成/组合增强（含最坏人体）
        self.threat = threat_model
        self.orbit_cert = orbit_cert
        self.N = audit_n
        self.alpha = alpha
        self.witness = {}                       # region -> [witness...]

    def audit(self, region, n=None):
        """在轨道/生成威胁模型内搜索漏检见证（构造召回下界）"""
        N = n or self.N
        samples = self.generative.sample(region, N, threat=self.threat)
        misses = [s for s in samples if self.detector.misses(s, region)]
        self.witness[region] = misses
        # 单侧 (1-α) 召回下界；见证越多，下界越低
        return clopper_pearson_lower(1.0 - len(misses) / N, self.alpha)

    def kappa_lower(self, region):
        return self.witness.get(region, None) and \
            clopper_pearson_lower(
                1.0 - len(self.witness[region]) / self.N, self.alpha)

    def counterfactual_injection(self, cov):
        """负对照：在声称无人的覆盖区注入最坏合成人，检查 Abs_orb 是否误签"""
        injected = self.generative.inject(cov, k=self.threat.k_worst)
        false_abs = [s for s in injected
                     if self.orbit_cert.issue_absence(s, cov)[0] is not None]
        return len(false_abs) / max(1, len(injected))

    def invalidate_dependents(self, region):
        """见证追溯失效：使依赖该 region 缺席证书的决策作废并重新验证"""
        return RetroactiveInvalidation(targets=region,
                                       cause="AAA_WITNESS")


# IP-433 Balance-Conditioned Viability Certificate
class BalanceViabilityCertificate:
    def __init__(self, dyn, support, sigma_x, w_bound, L_b, b_min=0.02,
                 a_floor=0.5):
        self.dyn = dyn
        self.support = support
        self.sigma_x = sigma_x
        self.w_bound = w_bound
        self.L_b = L_b
        self.b_min = b_min
        self.a_floor = a_floor

    def capture_point(self, x):
        return x.pos + x.vel / self.dyn.omega

    def margin(self, x):
        xi = self.capture_point(x)
        return (self.support.signed_distance(xi)
                - self.L_b * self.sigma_x - self.w_bound)

    def max_decel(self, x):
        # 平衡裕度越小，可施加的前向减速度越小（"越怕摔越停不下"）
        m = self.margin(x)
        return self.dyn.a_ref * smoothstep((m - self.b_min) / self.dyn.b_scale)

    def brake_distance(self, v, x):
        a = max(self.max_decel(x), self.a_floor)
        return v * v / (2.0 * a) + v * self.dyn.t_latency

    def in_static_kernel(self, x, horizon):
        return (self.margin(x) >= self.b_min
                and self.exists_stop(x, horizon, stepping=False))

    def in_step_kernel(self, x, horizon):
        # 仅限已认证落脚点与地形；只恢复不扩张（引理 166）
        return self.exists_stop(x, horizon, stepping=True,
                                footholds=self.support.certified_footholds(x))

    def exists_stop(self, x, horizon, stepping, footholds=None):
        return self.dyn.viability_lookup(x, horizon, stepping, footholds)


# IP-434 Coupled Perception–Balance Budget
class CoupledPerceptionBalanceBudget:
    def __init__(self, bvc, r_safe=0.25, r_lat=0.05, v_cap=1.5, dv=0.02, H=1.0):
        self.bvc = bvc
        self.r_safe = r_safe
        self.r_lat = r_lat
        self.v_cap = v_cap
        self.dv = dv
        self.H = H

    def required_range(self, v, x):
        return self.bvc.brake_distance(v, x) + self.r_safe + self.r_lat * v

    def feasible_speed(self, x, cov, abs_orb):
        v = self.v_cap
        while v > 0.0:
            R = self.required_range(v, x)
            tube = self.path_tube(x, v, R)      # 未来路径的 R-管
            dyn_ok = (self.bvc.in_static_kernel(x, self.H)
                      or self.bvc.in_step_kernel(x, self.H))
            if cov.contains(tube) and abs_orb.valid_on(tube) and dyn_ok:
                return v, True
            v -= self.dv                        # 只能降速，不能放宽覆盖/平衡
        return 0.0, False


# IP-435 Certified Balanced SafeStop
class CertifiedBalancedStop:
    def __init__(self, bvc, decel_stop, step_stop, crouch):
        self.bvc = bvc
        self.modes = [decel_stop, step_stop, crouch]   # 三级降级

    def plan(self, x, obstacles):

                   and self.bvc.margin(s) >= self.bvc.b_min for s in traj):

                        certified=False, t_CBS=self.modes[-1].duration)

## 3. 推导

**引理 163（轨道召回夹逼）** 设单视图分层漏检上界 `δ_s=1-κ_s`、视图有效独立数 `m_eff`。若视图条件独立，轨道并集漏检 `≤(1-κ_s)^{m_eff}`，给出召回下界 `1-(1-κ_s)^{m_eff}`；若独立性不可证（`m_eff=1`），该下界退化为 `κ_s`，轨道提升不予兑现。AAA 在审计集 N 上发现 |W| 个见证，给出单侧 `(1-α)` 召回下界 `κ_audit=ClopperPearson_lower(1-|W|/N,α)`。取 `κ_lb=min(轨道下界,κ_audit)` 签发 Abs_orb，则假缺席 `≤1-κ_lb`；见证出现使 `κ_audit` 下降并追溯失效（引理 164）。∎

**引理 164（加权 conformal 的分层覆盖与支撑缺口）** 若密度比 `w(z)=dp_target/dp_aug` 已知且支撑重叠（`w<∞`），加权 conformal 分位数使目标分布覆盖 `≥1-α`；分层条件覆盖要求每层标定支撑非空，否则该层 `κ_c(g):=0` 并退回"按有人处理"。支撑缺口 `δ_support` 显式进入 `δ_abs = 1-κ_lb+δ_support`；反事实注入的合成-真实差距以同一方式计入。∎

**引理 165（平衡裕度鲁棒前向不变与制动单调性）** 若 `b_rob(x_0)≥b_min` 且控制 `u∈K_static`（存在保持 `b_rob≥b_min` 的停机策略），则由比较引理沿闭环 `b_rob≥b_min` 前向不变。由定义 `a_max(x)` 随 `b_rob` 单调不增，故 `d_brake(v,x)=v²/(2a_max)+v·t_lat` 随 `b_rob` 单调不减——"越接近摔倒越停不下来"是模型内生的，而非参数意外。∎

**引理 166（迈步只恢复不扩张）** `K_step` 的落脚点限制在 v21 已认证自由空间 `F_v21` 内且落脚可达性已认证；故任何经 `K_step` 的停机轨迹的几何投影 `⊆F_v21`。平衡筛选仅把"静态动力学模型误判不可行"的状态重新判为可行，不新增 v21 之外的状态。因此 `Fil_dyn` 是 `Exec_v21` 上的筛选器，而非扩张器。∎

**引理 167（感知-平衡预算的可行区间与单调性）** `R_detect(v,x)=d_brake(v,x)+r_safe+r_lat·v` 对 v 严格增（`d_brake` 增、`r_lat·v` 增）。`Cov^orb` 固定时 `{v:Cov^orb⊇tube(R_detect(v,x))}` 是区间 `[0,v_cov]`；平衡可行给出 `[0,v_bal]`（由 `K` 与 `H` 决定）。交集 `[0,min(v_cov,v_bal)]`；且 `v*` 对 `b_rob` 与覆盖半径单调不增。故"降速/停机"是唯一合法的预算重平衡方向。∎

**引理 168（CBS 三级降级的可达性）** 若 `x∈K_static`，减速停可行；若 `x∈K_step\K_static`，迈步停可行；否则受控下蹲使落地冲击最小且保持碰撞自由（下蹲以 `b_min'≤b_min` 与冲击上界 `J_max` 为条件）。任一情形轨迹内碰撞自由；`t_CBS` 由所选模式给出并计入 DCL 期限，超期即 SafeStop 升级。故 SafeStop 不引入新的碰撞或失衡。∎

**引理 169（CFC++ 双多样性抗相关）** 仲裁要求 `#votes≥N-F ∧ |Mod|≥2 ∧ |Orb|≥2`。同相机同轨道不同亮度的视图 `|Orb|=1`，只算一票；同模态不同轨道才计多票。故单模态相关故障（v21 风险）与单轨道相关增强（v22 新风险）都无法伪造共识，落入 CI/保守。∎

**引理 170（v22 整体安全继承）** AOC/AAA 只替换/证伪证据且向保守退化（163、164）；BVC/CPB/CBS 只在 `Exec_v21` 域内做动态筛选且失效向低速/下蹲（165–168）；CFC++ 只加严仲裁（169）；DCL/GIC/SDC/CAC 原样。故 `Exec_v22 = Exec_v21 ∩ Fil_orb ∩ Fil_dyn ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。∎

## 7. 已知风险与失效模式

1. **增强轨道的闭世界性**（最大风险，见第 8 节）：G 之外的形态（新型助行器、极端衣着、多人叠影）既无见证也无下界；"已增强覆盖"被误当"已审计"。缓解：轨道外一律保守、AAA 持续在线、见证追溯失效（E804/E805/E810）。
2. **动力学模型失配**：LIPM/质心模型未覆盖滑移、软地面、负载突变、关节饱和，可行核可能把不可停状态误判为可行。缓解：鲁棒裕度含模型误差界、在线地形/接触估计、失效即静态核限速（E811/E813/E820）。
3. **活性坍缩**：轨道保守 + 预算限速 + 平衡裕度三重叠加，人流密集区速度可能趋零。缓解：轨道并集在有独立性证据时赎回活性、迈步恢复静态不可行状态、监控活性损失（E802/E814/E830）。
4. **AAA 搜索不足导致的假安心**：搜索分布若只覆盖已列举稀有类，则找不到见证≠没有见证。缓解：生成模型多样采样、把"未搜索区域"显式标为未验证并保守处理、报告搜索覆盖率而非仅报告零见证。
5. **合成-真实差距**：生成人体的纹理/动力学不真实，标定与注入结论有偏。缓解：域随机化、真实小样本校准、把差距计入 δ_support（E806）。
6. **视图相关性被低估**：m_eff 估计偏乐观会虚高召回下界。缓解：用单侧保守下界、共漏率压力测试、CFC++ 双多样性（E803/E822）。
7. **平衡-感知耦合的实时性**：可行核与预算求解若侵入控制路径会破坏 12ms 预算。缓解：离线预计算可行核、10Hz 事件化、控制路径只查表（E818）。
8. **隐私与生成滥用**：合成人体与手势涉及生物特征。缓解：原始图像不出设备、生成仅本地、只传证书与几何特征（继承 E794）。

## 8. 本轮最大风险

**一句话**：v22 的两张新证书都只在"模型内的最坏情形"成立——增强群 G 定义了"能被想象的人"，LIPM/质心动力学定义了"能被执行的平衡"；真实危险恰是 G 之外的人体形态与模型之外的接触（滑移、软地、被推），此时系统会带着两份形式完美的证书撞人或摔倒——**"闭世界增强 + 模型内平衡"的双重幻觉**。
