# 第 41 轮 · 双灵感落地 v8：证书见证数据集 × 可认证域随机化 × 证书化迁移桥（四层架构 v6）

> 承接第 40 轮（v17：可认证流匹配执行 × 度量语义几何锚定 × 证书驱动课程引擎，四层架构 v5）。本轮灵感词「数据集、域随机化」恰好指向第 40 轮体系的两个未闭合缺口：证书是**关于分布**的断言，却一直没有交代「在哪个数据分布上测得」；证书是**关于有效性**的承诺，却从未证明「真实世界落在有效区域内」。本轮把数据集升格为证书的**见证物（witness）**，把域随机化升格为证书的**支撑（support）**，并用一个迁移桥把两者缝成「可证 sim-to-real」。

## 0. 直觉与动机

**灵感 1（数据集 → 证书的证词，而非训练燃料）**：第 40 轮的边际 m_i = {λ̂, 1/L̂, ĥ_min, 1/μ̂, ε̂_ode, B̂} 全是从数据上「测」出来的，但报告里只写了点估计。点估计不是证书——它没有有限样本置信、没有覆盖保证、也说不清「换一批数据还成不成立」。把数据集从「训练燃料」改为「证书见证集」后，三件事同时变清晰：a) 每张证书必须附带**覆盖证书**（数据经验分布与目标分布的 DKW 偏差界）与**边际下界**（Bernstein/Clopper–Pearson/conformal 的 (1−δ) LCB），证书才从「经验达标」升级为「分布达标」；b) 数据的价值不再是「多样性」这种模糊词，而是**每单位标注预算能收紧多少证书赤字**，主动采集变成证书赤字的贪婪最小化；c) 数据版本与证书血缘（lineage）双向绑定，证书失效时沿血缘反查具体数据切片，做**精准重采**而不是全量重训。一句话：数据集是证书的证词，没有证词的证书是断言而非证据。

**灵感 2（域随机化 → 证书的不变包络，而非经验增广）**：域随机化通常靠手感：随机化太窄→sim-to-real 失败，太宽→策略过度保守、证书反而立不住。关键反转是——让**证书来定义随机化的合法范围**。证书在域参数 θ（光照、摩擦、质量、时延、传感噪声、纹理）上成立的集合 Θ_cert 就是「不变包络」；随机化分布必须支撑在 Θ_cert 上。更进一步，可由 margin 对 θ 的 Lipschitz 常数反解出**认证随机化半径 ρ\***：在 d_Θ 球内证书必然成立。这与 randomized smoothing 的 certified radius 同构，只是半径落在**域参数空间**而非输入空间。域随机化由此从「数据增广技巧」升格为「证书操作」：改一次随机化范围，就必须重算 ρ\* 与证书松弛预算。

**灵感 3（耦合 → 第 40 轮缺的迁移定理）**：第 40 轮说证书「在 ValidRegion 内成立」，但从没说真实世界是否落在有效区域内。数据集见证集给出**覆盖**（真实分布被随机化支撑覆盖的 Wasserstein 距离可估、可给上界），域随机化给出**不变性**（覆盖范围内证书都成立），于是拼出证书化迁移界：R_real ≤ R_sim + L_ℓ·W₁ + conformal 项。三项分别来自：第 40 轮证书（R_sim 与 L_ℓ）、本轮见证集（W₁ 的上置信估计）、本轮随机化（把 sim 与 real 拉近的支撑）。sim-to-real 从「信仰之跃」变成**可测量、可认证、可回退**的量。

**三者的耦合结构**：见证集回答「凭什么相信这批数据代表现实」，随机化回答「凭什么相信现实被这批数据覆盖」，迁移界回答「凭什么把 sim 上的证书兑现到 real」。数据是证词，随机化是支撑，迁移界是判决。

## 1. 形式化定义

**定义 27（证书见证集 WitnessSet）**：设证书 C 有边际 m = (m₁…m₆) 与阈值 c，数据集 D = {(oᵢ, aᵢ, θᵢ)}（θ 为域参数）。定义
- 边际下界 m_i^LCB(D, δ) = m̂_i(D) − Rad_i(n, δ′)，Rad_i 取各边际合适的集中不等式（λ̂/ĥ_min 用 Bernstein，成功率用 Clopper–Pearson，B̂ 用 conformal 分位），δ′ = δ/6（Bonferroni）；
- 覆盖偏差 ε_cov(n, δ) = √(log(2/δ)/(2n))（DKW，对所有可测集合一致成立）；
- **见证充分性（定理）**：若 ∀i m_i^LCB(D,δ) ≥ c_i 且 ε_cov(n,δ) ≤ ε，则以概率 ≥ 1−δ，证书 C 在目标分布 P 上成立（真实边际超阈值）。这把「经验达标」严格化为「分布达标」。
- **见证质量**：Gap(D,C) = Σᵢ wᵢ·max(0, cᵢ − m_i^LCB)/cᵢ；主动采集最大化单位成本下的 E[ΔGap]。

**定义 28（证书不变包络与认证随机化半径）**：域参数空间 (Θ, d_Θ)，d_Θ 取各维按敏感度加权（Hellinger/归一化欧氏）。设 margin 对 θ 的 Lipschitz 常数为 L_θ（采样估计 + 区间传播取上界），m₀ = min_{x∈ValidRegion} m(x, θ₀)。
- 不变包络 Θ_cert(C) = {θ : minₓ m(x,θ) ≥ c}；
- **认证随机化半径（定理）**：ρ\*(θ₀,C) ≥ (m₀ − c)/L_θ，即在 d_Θ 半径 ρ\* 内的任意随机化都保持证书成立；
- **证书保持随机化**：分布 P_θ 若 supp(P_θ) ⊆ Θ_cert 且松弛预算 slack(P_θ) = E_θ[(c − m(θ))₊] ≤ slack_budget，则称 P_θ 为证书保持的；越界采样仅允许作为「探索」且必须触发 RCA 观察。

**定义 29（证书化迁移界 CertTransfer）**：真实风险 R_real(π)、随机化仿真风险 R_sim(π; P_θ)，风险泛函 ℓ: O→[0,1] 为 L_ℓ-Lipschitz，且**因子化通过证书敏感子空间 S**（ℓ = ℓ̃∘S，S 由 margin 雅可比主方向选出）。
- **迁移定理**：以概率 ≥ 1−δ，
  R_real(π) ≤ R_sim(π;P_θ) + L_ℓ·Ŵ₁(S#P_real, S#P_sim^θ) + L_ℓ·η(n,m,δ)，
  其中 Ŵ₁ 为 push-forward 分布 Wasserstein 的上置信估计，η 为估计误差项（由见证集样本量给出）。
- **严谨边界**：只用 S# 得到的 W₁ 只有在 ℓ 确实因子化于 S 时才是**上界**；否则投影只会给出下界，直接代入会让迁移界**乐观失效**——这是必须由审计项强制拒绝的情形（见风险表）。
- **迁移预算**：RHS ≤ R_budget 时迁移证书生效；否则输出三选一建议（补采数据 / 缩小随机化半径 / 加强 sim 证书），实现可操作回退。

## 2. 三大产出设计

### 2.1 IP-51 WITNESS-DATASET-ENGINE（证书见证数据集引擎）
1. 数据切片即见证单元：每切片产出 {coverage 证书, 各边际 LCB, lineage hash}，注册 DatasetRegistry，与 CertBundle 双向链接。
2. 主动采集：价值 V(x) = E[ΔGap]/cost(x)，用「边际敏感度 × 覆盖缺口（核密度/最近邻不符度）」近似，贪婪次模优化（1−1/e 保证）。
3. 证书失效传播：沿 lineage 反查受影响切片 → 精准重采与增量重认证，避免全量重训。
4. 自动数据卡：datasheet 字段直接由证书字段生成（可审计、可复现）。

### 2.2 IP-52 CERTIFIED-DOMAIN-RANDOMIZATION（可认证域随机化）
1. 参数化域 θ 六维（光照/摩擦/质量/时延/传感噪声/纹理），每维给区间与度量尺度，d_Θ 按敏感度加权。
2. 证书反解包络：采样估计 L_θ → 计算 ρ\* 与 slack；随机化强度在 ρ\* 内（证书保持），越界需显式预算与告警。
3. 课程化随机化：最坏 θ\* = argmax_θ (c − m(θ))（投影梯度/进化），把「最难但仍可证」的参数带作为重点随机化区——与 IP-50 课程带同构，只是轴换成域参数。
4. 随机化即证书操作：每次调范围都重认证；ρ\* 收缩超阈 → RCA 重颁或缩域。

### 2.3 IP-53 CERT-TRANSFER-BRIDGE（证书化迁移桥，双灵感耦合产物）
1. 三项合成：R_sim（第 40 轮证书）+ L_ℓ（证书 L_v/κ 导出）+ Ŵ₁（见证集）。
2. 子空间降维：只在证书敏感子空间 S 上估 W₁，绕开维度灾难；但强制审计 ℓ 的因子化条件（否则拒绝作为上界）。
3. 迁移预算与三选一回退建议（补数据/缩随机化/强证书）。
4. 少量真实配对数据做 conformal 校准，给 W₁ 与风险差分布无关上界。

## 5. 本轮最大风险

**一句话**：整轮都押在「迁移界是否非空洞」上——高维 Wasserstein 估计以 n^{−1/d} 收敛且不集中，Ŵ₁ 会要么大到让迁移界比平凡界 R_real≤1 还松、要么要求比现实可得的真实数据多几个数量级，sim-to-real 的「可认证」就会重演第 39/40 轮警告的「装饰性证书」，须以 E76/E77 为本轮第一守门实验。

## 2. 关键算法

### IP-51 证书见证数据集（伪代码）
```
def witness_certificate(slices, C, delta=0.01):
    n = total_samples(slices)
    eps_cov = sqrt(log(2/delta) / (2*n))              # DKW 覆盖
    lcb = {}
    for i, margin in enumerate(C.margins):            # 6 类边际
        lcb[i] = margin.estimate(slices) - radius(margin, n, delta/6)
    ok = all(lcb[i] >= C.threshold[i] for i) and eps_cov <= C.eps
    return WitnessSet(coverage=eps_cov, lcb=lcb, lineage=hash(slices), ok=ok)

def active_acquire(pool, C, budget):
    while budget > 0:
        x* = argmax_x  E_dGap(x, C) / cost(x)         # 次模贪婪, 1-1/e
        acquire_and_label(x*); budget -= cost(x*)      # 覆盖缺口×边际敏感度
    return reissue_witness(C)
```

### IP-52 可认证域随机化（伪代码）
```
def certified_randomization(C, theta0, domain):
    L_theta = upper_bound_margin_lip(theta0, domain)  # 采样+区间传播
    m0      = min_margin(C, theta0)                   # ValidRegion 内最小
    rho_star = (m0 - C.c) / L_theta                   # 认证半径下界
    theta_band = sample_band(d_Theta, theta0, rho_star)  # 证书保持支撑
    worst = argmax_theta (C.c - min_margin(C, theta))    # 课程化随机化
    if slack(rand_dist(theta_band)) > slack_budget:
        RCA.warn("randomization exceeds certificate slack"); shrink(rho_star)
    return rand_dist(theta_band), rho_star, worst
```

### IP-53 证书化迁移桥（伪代码）
```
def cert_transfer(C, witness, S, real_pairs, delta=0.01):
    assert risk_factorizes_through(S), "拒绝：ℓ 不经 S，投影 W1 只是下界"
    R_sim   = C.risk_estimate()                       # 第 40 轮证书
    L_risk  = C.L_lipschitz                           # L_v/κ 导出
    W1_hat  = wasserstein_upper(S.push(real_pairs),
                                S.push(C.sim_samples), n, delta)  # 子空间
    eta     = estimation_term(len(real_pairs), delta)
    R_ub    = R_sim + L_risk * W1_hat + L_risk * eta
    if R_ub > C.R_budget:
        return advise(["collect_more", "shrink_randomization", "tighten_cert"])
    return TransferCertificate(R_ub, rho_star=C.rho, delta=delta)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 正确性保证 |
|---|---|---|
| 覆盖证书 (DKW) | O(n) | 一致覆盖，P(sup|P_D−P|>ε)≤δ |
| 边际 LCB | O(6·n) | Bernstein/CP/conformal，Bonferroni 联合 ≥1−δ |
| 主动采集 | O(|pool|·d) / 轮，贪婪 1−1/e | 次模近似最优 |
| ρ* 反解 | O(samples·d_θ) | 区间传播：ρ* ≥ (m₀−c)/L_θ（保守下界） |
| 子空间 W₁ | O(n log n·k)，k=|S| 敏感维 | 仅当 ℓ=ℓ̃∘S 时为上界；否则下界（审计拒绝） |
| 迁移界 | O(n) + conformal O(n log n) | 三角不等式 + KR 对偶 + 因子化条件 |
| lineage 反查 | O(1) 哈希 | 失败切片定位，增量重认证 |

| E76 迁移界非空洞 | (RHS−R_sim)/实测 real gap 紧致比 | 比值≤5，RHS≤R_budget 场景≥80% |
| E77 子空间 W₁ | 界宽/方差 vs 全维；因子化审计 | 界宽降≥50%，审计通过率 100% |
| E78 端到端真机 | 真实违约率、迁移成功率 | 违约<0.5%，成功率≥80% |

失败即回退：E76/E77 不达标 → 放弃定量迁移界，回退 v17（纯 sim 证书）；IP-51/52 转离线工具，迁移桥降级为经验 gap 监控。

## 5. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 高维 W₁ 不集中 → 迁移界空洞 | 高 | 只估证书敏感子空间 S；conformal 上置信；E76/E77 第一守门 |
| 子空间 W₁ 被误当上界（乐观失效） | 高 | 强制因子化审计，不通过即拒绝出证；必要时退全维并接受更松界 |
| 域参数未建模 → 真实分布落在 Θ_cert 外 | 高 | ρ* 内采样 + 覆盖缺口监测 + 出包络告警；E69 连带守门 |
| 主动采集分布偏移（只采易证区） | 中 | 覆盖缺口奖励项 + 分层采样配额 |
| 见证集与证书 lineage 漂移失配 | 中 | 双向哈希绑定 + 每次重颁强制回链 |
| ρ* 过保守（L_θ 高估）→ 随机化范围过窄 | 中 | 区间传播精修 + 关键维 LipSDP；E75 报 ρ* 紧致比 |

## 6. 本轮最大风险

**一句话**：整轮成败系于「迁移界是否非空洞」——高维 Wasserstein 以 n^{−1/d} 收敛且不集中，Ŵ₁ 要么大到连平凡界 R_real≤1 都不如、要么要求现实中拿不到的真实数据量，则「可认证 sim-to-real」将沦为装饰性证书，故 E76/E77 为本轮第一守门实验。
