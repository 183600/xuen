# 第 66 轮（承接第 65 轮「VISTA 视觉知情的安全时序归因」IP-214~223；新一轮灵感循环第 1 轮；本轮灵感：「虚实迁移」×「UniBot-V1」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险是：归因依赖有限故障假设集与「视觉/几何失效相互独立」这两个假设；真实故障常是未知类型的组合，透明/镜面/对抗 patch 会让视觉与几何共享同一个分布外失效源，于是 FIR 会把未知复合故障强行归入最近假设、只膨胀错误的球——系统因为「已经归因」而更自信地继续执行。**根因是：VISTA 只能在已经发生的真实世界里取证，无法对「如果 H 为真，世界会怎样」做反事实实验，也没有一个独立世界来打破共因。** 本轮把「第二世界」引入闭环，核心命题是：
>
> **把数字孪生从训练数据源升级为「可证伪的反事实证人」：用虚实迁移生成安全的虚拟探针，用 UniBot-V1 的统一动作/状态接口做「同动作、双世界」配对，用迁移证书把仿真中的安全承诺有条件下放到真实世界；并首次把「现实间隙」本身拆成可归因故障。**

## 0. 直觉与动机

**灵感 1（虚实迁移 → 反事实证据，而不只是数据增广）**
直觉：VISTA 的主动故障归因（AFA）只能从真实物理探针里选，代价是接触、力、甚至压坏易损物；更致命的是，真实世界只能告诉你「发生了什么」，不能告诉你「如果几何幻觉为真，这个世界会怎样」。数字孪生恰好能对每个故障假设做反事实 rollout：在孪生里注入 H_geo/H_force/H_model/H_gap，跑同一组候选探针，看哪种证据最能分开它们。于是探针选择从「真实试错」变成「**虚拟探针拍卖（VPA）**：先在孪生里免费试遍所有探针，再在真实世界只执行信息量/风险比最高的那一两个」。但必须诚实：孪生有现实间隙，越自信的孪生越危险；所以孪生**不是新真值，而是第三位可错证人**，它的证据必须与真实证据配对校验。

**灵感 2（虚实迁移 → 现实间隙本身就是一种故障）**
直觉：VISTA 把「几何/力/模型/视觉/策略」当作故障，却把 sim-to-real gap 当噪声或 domain randomization。可 gap 是有结构的：物理参数错、渲染/光照错、执行器增益/延迟错、接触模型错、具身/动作空间错。这些结构在真实与孪生的配对残差里留下不同签名，完全可以像 H_geo/H_force 一样被归因。把 gap 升格为 **H_gap_phys / H_gap_vis / H_gap_act / H_gap_lat / H_gap_emb** 后，系统第一次能回答「到底是真实世界坏了，还是孪生坏了，还是两者共享了同一个坏假设」。这也是对第 65 轮共因风险的正面对冲。

**灵感 3（UniBot-V1 → 统一动作接口创造「同动作、双世界」的可配对性）**
直觉：没有公共动作坐标，就无法把仿真和真实逐帧对齐：同样的任务，仿真里是关节力矩，真实里是末端增量，残差里混着接口差异，gap 根本估不准。UniBot-V1 的规范把不同具身映射到 **54 维动作 / 60 维状态 / 默认 H=30 的动作块（30fps）**，并支持二指夹爪与多种五指手；UnifoLM-WLA-1.0 又在约 2500 小时真机数据上给出跨桌面与全身任务的先验。于是可以构造 **UAI（UniBot Action Interface）配对缓冲**：同一动作块 a_{t:t+H} 在孪生与真实各 rollout 一次，逐维比较状态/接触/视觉后果，得到干净的 gap 签名。注意：6B 基础模型只在语义流做先验，实时流用蒸馏块策略；基础模型本身也可错，记为 H_foundation，绝不当作真值。

**灵感 4（三灵感合流 → BRIDGE：双向现实间隙识别与数字孪生接地的安全执行闭环）**
直觉：VISTA 是「真实世界内的故障归因」；BRIDGE 是「跨世界的故障归因 + 证书迁移」。闭环为：
**DTG（孪生参数后验/可信集）→ RGI（间隙签名与扩展故障假设）→ VPA（虚拟探针拍卖）→ UAI（同动作双世界配对）→ TCC（迁移证书）→ DTA（真实证据回灌孪生）→ RSC-W（只膨胀被归因的球）→ CSP-W（块级跨世界技能规划）→ AIC-W（跨世界对抗认证）→ J_bridge**。
其中 **sim→real** 的方向是「证书迁移」：只有间隙上界小于安全裕度/李普希茨常数时才下放；**real→sim** 的方向是「孪生校准」：用真实残差更新 θ 后验。两个方向互为约束，缺一不可。

**灵感 5（GRIP/VISTA 组件的原位升级）**
- **VPG → VPG-W**：视觉世界模型在孪生里做反事实 rollout，给 VCV 提供「如果接触斑在这里，孪生会看到什么」的前置对照。
- **ACH → ACH-U**：直接采用 UniBot-V1 的 54/60 维动作/状态与 H=30 块，块间一致性在跨世界配对后计算。
- **FIR → FIR-W**：故障假设集扩为 ℋ⁺ = ℋ ∪ {H_gap_phys, H_gap_vis, H_gap_act, H_gap_lat, H_gap_emb, H_foundation, H_unknown}；未知故障用 SBI 后验预测与开集检验。
- **VCV → VCV-W**：视觉接触验证先在孪生中预演；若孪生与真实都看不到接触，判 `visual_unobservable`，不得否定几何。
- **APP/AFA → VPA**：探针目标从「故障假设互信息」升级为「单位真实风险的迁移感知互信息」，并允许零真实探针回退。
- **CSC → CSC-W**：认证前缀前加一道 **迁移证书**；k* 只在证书可迁移时生效。
- **RSC-V → RSC-W**：不确定球拆为 r_geo / r_force / r_model / r_gap / r_foundation，只膨胀被归因者。
- **WCV-V → WCV-W**：搜索域增孪生可信集 Θ_δ 与迁移半径约束。
- **CSP-V → CSP-W**：技能同时绑定「仿真块签名」与「真实块签名」，两者都通过才入图。
- **AIC-V → AIC-W**：干扰集增物理/渲染/执行器/延迟/具身错配与共因故障；共因下不要求归因正确，只要求拒绝迁移并安全降级。
- **J_vista → J_bridge**：证书增 twin_posterior、transfer_radius、gap_bound、real_probe_budget、unibot_iface_ver、H_unknown_flag。

**与既有路线的区别（为什么不是「sim2real + domain randomization」）**
- 域随机化把 gap 当作要覆盖的分布，追求平均鲁棒；BRIDGE 把 gap 当作要归因的故障，追求「这一次能不能迁移」的可判定性。
- 系统辨识估计 θ，但不回答「证书能不能下放」；TCC 用 Lipschitz + conformal 给出可检查的迁移条件。
- 数字孪生通常用于训练/评测；BRIDGE 把它用作反事实探针生成器与最小真实实验的设计器。
- 基础模型通常被当作策略先验；BRIDGE 把它当作可错假设 H_foundation，不允许它直接产生安全证书。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（BRIDGE 闭环）**：BRIDGE = (VISTA, DTG, RGI, VPA, UAI, TCC, DTA, RSC-W, CSP-W, AIC-W, J_bridge)。定位：VISTA 的「跨世界故障归因 + 安全证书迁移」升级。不变式：**孪生推断、SBI、虚拟探针拍卖、迁移证书只在语义流；实时流只做配对残差采集、认证前缀执行与早停，零学习写操作。**
- **定义 234（数字孪生集合与参数后验）**：世界参数 θ ∈ Θ（质量/摩擦/恢复系数/接触刚度/执行器增益/延迟/相机内外参等）；先验 p(θ)；孪生 T_θ。用真实配对数据 D 通过 SBI/ABC 得后验 p(θ|D)，并取可信集 Θ_δ={θ: p(θ|D)≥δ}；孪生集合 {T_{θ_i}}_{i=1..M} 表示认知不确定度。
- **定义 235（UniBot 跨世界接口 UAI）**：采用 UniBot-V1 规范：动作 a∈ℝ^54、状态 s∈ℝ^60、默认块长 H=30、30fps，带有效性 mask；同一动作块在孪生与真实各执行一次，得配对轨迹 (s^sim_{t:t+H}, s^real_{t:t+H})。UAI 是 gap 估计与迁移证书的公共坐标；基础模型 UnifoLM-WLA-1.0 仅作语义流先验。
- **定义 236（现实间隙签名）**：配对残差 e_gap(t,h)=d_U(s^sim_{t+h}, s^real_{t+h})，按通道分解为物理/视觉/执行器/延迟/具身五类，按接触阶段聚合为 γ∈ℝ^{d_g}。γ 是 H_gap 类的证据；同时定义证书相关间隙 d_cert(θ_sim, θ_real)=‖θ_sim−θ_real‖_{Σ_θ^{-1}}。
- **定义 237（扩展故障假设集）**：ℋ⁺ = {H0, H_geo, H_force, H_model, H_vis, H_policy, H_gap_phys, H_gap_vis, H_gap_act, H_gap_lat, H_gap_emb, H_foundation, H_unknown}。H_unknown 用开集似然/后验预测覆盖；H_foundation 表示基础模型先验错（动作 token 化、具身错配、幻觉）。
- **定义 238（孪生反事实证据）**：对候选探针 a 与后验样本 θ~p(θ|D)，孪生 rollout 得 ρ_sim(a,θ)；其分布 p_sim(ρ|H,a)=∫p(ρ|θ,H,a)p(θ|D)dθ 是 H 的模拟似然。模拟似然只用于**设计探针与排序假设**，不直接当作真实后验。
- **定义 239（虚拟探针拍卖 VPA）**：候选探针集 A={visual_probe, null_test, press, rub, tap, lift, sim_probe}；对每个 a 计算迁移感知互信息
  I_τ(a)=I_sim(ℋ⁺; ρ_real(a)|D)·λ_τ(γ)，
  其中 λ_τ∈[0,1] 由间隙签名 γ 与孪生可信度给出；真实风险 r(a) 由力/形变/停止距离上界给出。选择
  a*=argmax_{a∈A} I_τ(a)/(r(a)+λ_r)，s.t. r(a*)≤B_probe；
  若 I_τ(a*)<δ_vpa 或 B_probe<r_min，则返回 **no_probe**，退化为纯被动观测。真实世界只执行 a*（通常 0–2 次），其余全部在孪生中完成。
- **定义 240（迁移半径与证书迁移）**：设策略 π 的安全裕度 m(π,θ)=min_{s≤k}ρ_safe(s;θ)，关于 θ 在证书度量下 L_m-Lipschitz。定义迁移半径 r_τ=(m(π,θ_sim)−ε)/L_m。若真实参数以 ≥1−α_gap 的概率落在 B(θ_sim,r_τ) 内（由 DTG 可信集/conformal 给出），则仿真证书可迁移；否则拒绝迁移。
- **定义 241（迁移证书 TCC）**：TCC(π,k)=(θ_sim, r_τ, δ_gap, m_sim, m_lb=m_sim−L_m δ_gap, α_gap, UAI_ver)。可迁移 ⇔ δ_gap≤r_τ ⇔ m_lb≥ε；执行时只用 m_lb 作为真实裕度下界，绝不用 m_sim 冒充真实裕度。
- **定义 242（跨世界故障归因 FIR-W）**：证据 = 真实阶段签名 ρ_real ⊕ 间隙签名 γ ⊕ 孪生模拟似然 p_sim；后验 P(H|ρ_real,γ)∝p(ρ_real|H)p(γ|H)P(H)，其中 H∈ℋ⁺。若 max_H P(H|·)≥1−δ_fi 且拟合优度通过，则定向处置；若后验不集中或所有已知 H 的拟合都很差，则判 H_unknown；若 H_gap 占优，则先更新 DTA、暂缓迁移。
- **定义 243（数字孪生在线适配 DTA）**：用真实配对残差按递归贝叶斯/SBI 更新 p(θ|D)；维护间隙变点检测，一旦 γ 的分布漂移超过阈值，立即作废当前 TCC 并重估 r_τ。只在语义流更新，实时流不写。
- **定义 244（RSC-W 归因定向球）**：维护 r_geo、r_force、r_model、r_gap、r_foundation；只膨胀被 FIR-W 归因的那个半径，融合 r=√(r_geo²+r_force²+r_model²+r_gap²+r_foundation²) 进入 WCV-W。H_gap 时只膨胀 r_gap，不误降级正确几何；H_foundation 时只降基础模型权重。
- **定义 245（CSP-W 跨世界技能规划）**：每条块边需 Valid(J_bridge) 且 TCC 可迁移且 k*≥1；技能 σ 同时绑定仿真块签名分布 𝒟_σ^sim 与真实块签名分布 𝒟_σ^real，实际块签名对两者的 Mahalanobis 距离都需 ≤τ_chunk。可插入 `sim_probe`、`real_probe`、`null_test`、`visual_probe` 元技能。
- **定义 246（AIC-W 跨世界对抗认证）**：干扰集 ℰ_W=ℰ_F×ℰ_vis×ℰ_time×ℰ_sim×ℰ_common；ℰ_sim 含物理参数/渲染/执行器增益与延迟/具身错配；ℰ_common 表示孪生与真实共享同一建模偏差。ρ_dir 在 ℰ_W 上重算（n_cert 128→192，其中 64 给跨世界/共因）；**共因下不要求归因正确，只要求判 H_unknown 并拒绝迁移**。
- **定义 247（BRIDGE 证书 J_bridge）**：J_bridge=(J_vista, twin_posterior, transfer_radius, gap_bound, transfer_margin, real_probe_budget, unibot_iface_ver, H_unknown_flag)。Valid(J_bridge) ⇔ Valid(J_vista) ∧ (δ_gap≤r_τ) ∧ (H_unknown 未触发 ∨ 已安全降级) ∧ k*≥1 ∧ UAI 版本一致 ∧ 共因风险已显式标注。
- **定义 248（BRIDGE 闭环算子）**：语义流 [LiDAR→LSF→USR/MEL→VPG-W 反事实前瞻→ACH-U 生成 UniBot 块→阶段切分→VCV-W→UAI 配对→RGI 间隙签名→FIR-W 跨世界归因→VPA 虚拟探针拍卖→DTA 孪生适配→TCC 迁移证书→WCV-W→CSP-W 块规划→CSC-W 认证前缀→AIC-W]；实时流 [锚点读→真实残差采集→阶段判定→TCC 校验→CSC-W 早停→前缀派发→J_bridge 构建]。

## 2. 关键算法骨架

```python
# DTG + RGI：配对残差 → 孪生后验 → 间隙签名（语义流）
D_paired = uai.collect_paired_rollouts(policy, H=30)      # 同动作，双世界
theta_post = dtg.sbi_update(prior, D_paired)              # p(theta | D)
gamma = rgi.gap_signature(D_paired)                       # 物理/视觉/执行/延迟/具身
gap_bound = dtg.conformal_gap_bound(theta_post, alpha_gap)

# VPA：虚拟探针拍卖（语义流选，真实流只执行一次安全探针）
best, best_score = None, -inf
for a in A:
    rho_sim = dtg.rollout_ensemble(theta_post, a, H=30)
    ig = info_gain(hypotheses=H_PLUS, rho_sim=rho_sim, lam=lam_tau(gamma))
    risk = risk_upper(a, theta_post, f_safe)
    if risk <= B_probe and ig / (risk + lam_r) > best_score:
        best, best_score = a, ig / (risk + lam_r)
if best is None or best_score < delta_vpa:
    probe = None                                              # 纯被动观测
else:
    probe = shield.execute_length_one(best)                   # 长度 1 的认证技能
    gamma = rgi.refresh(gamma, probe.real_residual)

# FIR-W + TCC + CSC-W
post = fir_w.attribute(rho_real, gamma, p_sim)                # H in H_PLUS
h_star, ambiguous = argmax(post), post.max() < 1 - delta_fi
if h_star == "H_unknown" or ambiguous:
    return safe_idle_or_compliant_retreat()
if h_star == "H_gap":
    dtg.adapt(probe.real_residual); return re_certify_later()
m_sim = sim_margin(tau, theta_post.mean())
r_tau = max(0.0, (m_sim - eps) / L_m)
tcc = TransferCertificate(m_sim, gap_bound, r_tau, alpha_gap)
k_star = csc_w.certified_prefix(tau.A, post, m, alpha_chunk, tcc)
if not tcc.transferable:
    return fallback_real_only_vista()                        # 不迁移，回到第 65 轮
execute(tau.A[:k_star]); monitor_and_re_attempt()
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（孪生可信集覆盖）**：若配对样本可交换且间隙残差按 split-conformal 校准，则 P[θ_real∈Θ_δ]≥1−α_gap；SBI 后验经 simulation-based calibration 后给名义覆盖。于是 gap_bound 是证书相关距离的分布无关上界。
- **引理 10（迁移证书的可靠性）**：若 m(π,·) 关于 θ 在证书度量下 L_m-Lipschitz，且 d(θ_sim,θ_real)≤δ，则 m(π,θ_real)≥m(π,θ_sim)−L_m δ。故当 m_sim−L_m δ≥0 时仿真证书可迁移；否则必须拒绝。迁移证书只使用下界 m_lb，绝不用 m_sim 冒充真实裕度。
- **引理 11（虚拟探针的风险单调性）**：VPA 的候选集包含全部真实探针与零真实风险的虚拟探针，且真实探针的最终执行仍受 Shield 的力/形变约束。因此 VPA 的真实风险不超过同一风险预算下的真实-only BOED；当孪生无间隙（δ=0）时可把真实探针数降到 0，当间隙增大时 λ_τ→0 自动退回真实-only。**仿真只降低真实试错，不替代真实安全约束。**
- **定理 9（BRIDGE 端到端跨世界安全）**：在 A94–A99 下，Valid(J_bridge) ⇒ 几何/力/模型/间隙被归因（或显式 H_unknown 并安全降级）∧ 只在间隙上界小于迁移半径时下放证书 ∧ 块前缀安全 ∧ 未知/复合故障不被静默接受 ∧ GRIP/VISTA 有效。真实越界概率 ≤ α_chunk+δ_fi+α_vis+α_gap+α_unknown（联合界）。
- **定理 10（迁移感知的真实样本复杂度）**：设 |ℋ⁺|=M，单次真实探针的迁移感知互信息为 I_τ。要把归因错误率压到 ε，所需真实探针数 N_real≤(log M−H(ε))/I_τ；孪生无间隙时 I_τ 可由虚拟探针获得，N_real=0；间隙为 δ_info 时 I_τ≈(1−δ_info)I_sim，故 N_real 只按 1/(1−δ_info) 增长，而真实-only BOED 需 (log M)/I_real。**孪生的价值不是「替代真实」，而是「把真实探针从 O(log M) 压到 O(1)」。**

并取可信集 Θ_δ={θ:p(θ|D)≥δ}。孪生集合 {T_{θ_i}}_{i=1..M} 用后验样本实例化，其离散度表示认知不确定度；任何证书都必须对 Θ_δ 内所有 θ 成立，而不是只对 MAP 孪生成立。

其中 W_g 按通道（末端位姿、关节、接触力、视觉任务观测量）加权。按接触阶段 P={approach,touch,load} 与物理/视觉/执行器/延迟/具身五类分解，聚合成

**定义 239（虚拟探针拍卖 VPA）** 候选探针集

**定义 240（迁移半径与证书迁移）** 设策略 π 的安全裕度

其中 ρ_safe 沿用第 64/65 轮的几何/滑移/力限裕度。设 m 关于 θ 在 d_cert 下 L_m-Lipschitz：

class DigitalTwinGrounding:
    """世界参数后验 + 孪生集合；语义流更新，实时流只读。"""
    def __init__(self, prior, twin_factory, M=16, alpha_gap=0.05):
        self.prior = prior
        self.twin_factory = twin_factory
        self.M = M
        self.alpha_gap = alpha_gap
        self.theta_post = prior.sample(M)       # 初始孪生集合
        self.cal_residuals = []                 # 配对残差，用于 conformal

    def sbi_update(self, paired_rollouts):
        # 用近似贝叶斯/神经后验估计更新 p(theta | D)
        self.theta_post = self._sbi(self.prior, paired_rollouts)
        return self.theta_post

    def conformal_gap_bound(self, theta_post, alpha_gap=None):
        # split-conformal：用留出配对样本的非一致性分数给 d_cert 上界
        a = alpha_gap or self.alpha_gap
        n = len(self.cal_residuals)
        if n == 0:
            return float("inf")                # 无校准数据：拒绝迁移
        k = math.ceil((n + 1) * (1 - a))
        return float(np.sort(self.cal_residuals)[min(k, n) - 1])

    def rollout_ensemble(self, theta_post, action, H=30):
        # 对后验样本并行 rollout，返回 rho_sim 的集合
        return [self.twin_factory(theta).rollout(action, H)
                for theta in theta_post]


class RealityGapIdentifier:
    """配对残差 → 五类间隙签名 gamma。"""
    def gap_signature(self, paired):
        # paired: {"sim": s_sim[H,60], "real": s_real[H,60], "phase": [...]}
        d = self.weighted_residual(paired["sim"], paired["real"])
        gamma = np.array([
            self.aggregate(d, "physics"),
            self.aggregate(d, "visual"),
            self.aggregate(d, "actuator"),
            self.aggregate(d, "latency"),
            self.aggregate(d, "embodiment"),
        ])
        return gamma

    def detect_change(self, gamma_hist, gamma_now, tau=3.0):
        # CUSUM / KL 变点检测；触发 TCC 作废
        return cusum_stat(gamma_hist, gamma_now) > tau

### IP-226 VPA（虚拟探针拍卖）

```python
class VirtualProbeAuction:
    PROBES = ("visual_probe", "null_test", "press", "rub", "tap", "lift")

    def choose(self, theta_post, gamma, hypotheses, f_safe, object_fragile,
               B_probe, delta_vpa=0.05):
        lam_tau = math.exp(-np.linalg.norm(gamma) / TAU_G)
        best, best_score = None, -math.inf
        for a in self.PROBES + ("sim_probe",):
            rho_sim = self.dtg.rollout_ensemble(theta_post, a, H=30)
            # 用后验预测的离散度/互信息近似 I_sim(H+; rho_real(a))
            ig = self.info_gain(hypotheses, rho_sim) * lam_tau
            risk = self.risk_upper(a, theta_post, f_safe)
            if risk > B_probe:
                continue
            score = ig / (risk + LAMBDA_R)
            if score > best_score:
                best, best_score = a, score
        if best is None or best_score < delta_vpa:
            return None, 0.0                       # 纯被动：不碰真实世界
        if object_fragile and best not in ("visual_probe", "null_test"):
            return None, 0.0                       # 易损物：只能零接触探针
        return best, best_score

    def info_gain(self, hypotheses, rho_sim):
        # 用模拟似然 p_sim(rho|H,a) 计算 H 与 rho 的互信息；
        # 高斯近似下 = 0.5*(logdet(Sigma_prior) - E[logdet(Sigma_post)])
        return mutual_information_gaussian(hypotheses, rho_sim)
```

### IP-228 TCC（迁移证书）

```python
class TransferCertificate:
    def __init__(self, L_m, eps=1e-3, alpha_gap=0.05):
        self.L_m = L_m
        self.eps = eps
        self.alpha_gap = alpha_gap

    def build(self, policy, theta_sim, gap_bound, k, uai_ver):
        m_sim = safety_margin(policy, theta_sim, k)       # min_s rho_safe
        r_tau = max(0.0, (m_sim - self.eps) / self.L_m)
        m_lb = m_sim - self.L_m * gap_bound
        transferable = (gap_bound <= r_tau) and (m_lb >= self.eps)
        return {
            "theta_sim": theta_sim,
            "r_tau": r_tau,
            "gap_bound": gap_bound,
            "m_sim": m_sim,
            "m_lb": m_lb,
            "transferable": transferable,
            "alpha_gap": self.alpha_gap,
            "uai_ver": uai_ver,
        }

    def reject_reason(self, tcc):
        if tcc["gap_bound"] > tcc["r_tau"]:
            return "gap_exceeds_transfer_radius"
        if tcc["m_lb"] < self.eps:
            return "insufficient_real_margin"
        return None
```

def BRIDGE_round(M, obs, delta_f_req):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    # ———— 语义流（10–100Hz）————
    M.lsf.update_geometry(P_cloud)

    y_vis = M.f_vis(img, depth, flow)
    phi_hat_geo, *_ = M.mel.infer_by_mode(M.ocb_skill.choose().mel_mode,
                                          V, T, P, L, x_prime)

    paired = M.uai.paired_rollout(x_prime, M.policy, H=30)
    M.dtg.sbi_update(paired)
    gamma = M.rgi.gap_signature(paired)
    if M.rgi.detect_change(M.gamma_hist, gamma):
        M.tcc = None                                    # 间隙漂移：作废证书
    M.gamma_hist.append(gamma)
    gap_bound = M.dtg.conformal_gap_bound(M.dtg.theta_post)

    # 2) VPA：虚拟探针拍卖；真实世界只执行 0–2 次
    probe, ig = M.vpa.choose(M.dtg.theta_post, gamma, M.hypotheses,
                             M.f_safe, M.object_fragile, M.B_probe)

        real_res = M.shield.execute_length_one(probe, M.policy)
        gamma = M.rgi.refresh(gamma, real_res)

    if not ambiguous:

            h_star, M.balls, M.w_vis, M.H, M.dtg)

    # 4) TCC：仿真证书有条件下放

    k_star = min(k_sim, M.m)

                                       phi_hat_geo, M.balls["r_geo"])

        M, delta_f_req, tau, k_star, x_prime, tcc)

    # 6) 语义流更新
    M.dtg.sbi_update(paired + [real_res])
    M.olp.online_step(M.olp.fuse_evidence(x_prime, W_meas, tactile,
                                          y_vis, post, gamma),
                      execution_loss_grad(K_safe, EV_exec, M.balls))
    M.rsc_w.update(EV_exec, W_meas, phi_hat_geo, post, M.balls)
    rho_dir = M.aic_w.certify(tau, x_prime, phi_hat_geo, M.balls, post,
                              M.dtg, gamma, gap_bound)

        cert_exec, J_vista=M.j_vista, twin_posterior=M.dtg.theta_post,

        unibot_iface_ver=UNIBOT_IFACE_VER,
        H_unknown_flag=(h_star == "H_unknown"),
        aic_w_ver=AIC_W_VERSION)

## 4. 推导

**假设 A94–A99（跨世界证书的前提）**
- **A94（孪生校准）**：配对样本可交换，DTG 的 conformal 可信集覆盖 ≥1−α_gap；SBI 后验通过 SBC 检验，否则退回 conformal。
- **A95（Lipschitz 裕度）**：安全裕度 m(π,θ) 在证书度量 d_cert 下局部 L_m-Lipschitz，且 L_m 的估计误差并入 δ_gap。
- **A96（UAI 可配对性）**：UniBot-V1 的 54/60 维动作/状态接口在 sim 与 real 间可对齐，动作块 H=30 的 mask/归一化一致；版本漂移会显式破坏配对并拒绝迁移。
- **A97（独立通道）**：至少一个真实证据通道（力/触觉/外部标定/IMU/本体感觉）不被主导的孪生模型偏差污染；否则共因 gap 不可辨识。
- **A98（语义/实时分离）**：孪生推断、SBI、VPA、TCC、AIC-W 只在语义流；实时流零学习写操作。
- **A99（共因诚实）**：若 A97 不成立或独立通道自身校准失败，BRIDGE 必须把 gap 视为无界并拒绝迁移，只做安全降级。

**引理 9（孪生可信集覆盖）** 设配对校准样本 (θ_i,D_i) 可交换，非一致性分数 s_i=d_cert(θ_i,Θ̂(D_{−i})) 或配对残差 r_i。取 split-conformal 分位数 q=⌈(n+1)(1−α_gap)⌉/n，则对新的真实 θ_real，
P[d_cert(θ_real,Θ̂)≤q]≥1−α_gap。
若用 SBI 后验代替 conformal，则在 simulation-based calibration（SBC）通过时，Θ_δ 具有名义覆盖；否则必须退回 conformal。故 gap_bound 是证书相关距离的分布无关上界（在可交换性下）。∎

**引理 10（迁移证书的可靠性）** 设 m(π,·) 关于 θ 在 d_cert 下 L_m-Lipschitz。若 d_cert(θ_sim,θ_real)≤δ，则
|m(π,θ_sim)−m(π,θ_real)|≤L_m δ，
即 m(π,θ_real)≥m_sim−L_m δ=m_lb。
因此当 m_lb≥ε 时，仿真中成立的「m≥ε」在真实世界仍成立；当 m_lb<ε 时无法保证，必须拒绝迁移。该界是保守的（worst-case direction），但只需 L_m 与 δ 两个可估量。∎

**引理 11（虚拟探针的风险单调性）** VPA 的候选集包含全部真实探针与零真实风险的虚拟探针；真实探针的最终执行仍受 Shield 的力/形变/停止距离约束。设真实-only 策略在风险预算 B 下的可行探针集为 A_real(B)。VPA 选择 a* 时显式要求 r(a*)≤B_probe≤B，因此其真实风险不超过 B；虚拟探针只用于排序与筛选，不直接产生真实风险。故 VPA 不会比同一预算下的真实-only 策略更危险。若孪生无间隙（δ=0），虚拟探针可完全辨识 H，N_real=0；若间隙增大，λ_τ→0，VPA 自动退化为真实-only。**仿真只降低真实试错，不替代真实安全约束。** ∎

**定理 9（BRIDGE 端到端跨世界安全）** 在 A94–A99 下：
1. **间隙可归因**：RGI 的五类签名与 FIR-W 的扩展假设集使 H_gap_* 与 H_geo/H_force/H_model 可分；未知/复合故障由开集拟合优度与后验熵判为 H_unknown，不再被强行归入最近类。
2. **证书可迁移性**：TCC 只使用 m_lb=m_sim−L_m δ_gap；若 δ_gap>r_τ 或 m_lb<ε，则拒绝迁移并回到真实-only VISTA。由引理 9/10，迁移成功时真实裕度 ≥ε 的概率 ≥1−α_gap。
3. **虚拟探针安全**：VPA 的真实探针数 0–2，且每个探针作为长度 1 的认证技能受 Shield 约束；由引理 11，真实风险不超过预算 B_probe。
4. **共因诚实**：若独立第三通道不可用或自身校准失败，H_unknown/common_cause_flag 触发，系统拒绝迁移（A99）；绝不把「孪生与真实一致」当作「两者都正确」。
5. **证书链**：Valid(J_bridge) ⇒ GRIP/VISTA 有效 ∧ 间隙可迁移 ∧ 块前缀安全 ∧ 未知故障已降级；真实越界概率 ≤ α_chunk+δ_fi+α_vis+α_gap+α_unknown（联合界）。
6. **实时性**：孪生推断、SBI、VPA、TCC、AIC-W 全在语义流；实时流只增配对残差采集、TCC 校验与早停，目标 ≤2.8ms（A94 修订契约）。∎

**定理 10（迁移感知的真实样本复杂度）** 设 |ℋ⁺|=M，单次真实探针的迁移感知互信息为 I_τ。由 Fano/序贯信息不等式，要把归因错误率压到 ε，所需真实探针数
N_real≤(log M−H(ε))/I_τ。
当孪生无间隙时，I_τ 可由虚拟探针获得，N_real=0；当间隙为 δ_info 时，I_τ≈(1−δ_info)I_sim，故 N_real 只按 1/(1−δ_info) 增长，而真实-only BOED 需 (log M)/I_real。**孪生的价值不是「替代真实」，而是「把真实探针从 O(log M) 压到 O(1)」。** ∎

**命题（降低过度保守）** 第 65 轮对任何拒绝都把单一 r 膨胀 κ_infl 倍，几何搜索域体积膨胀 κ_infl^{d_φ}。BRIDGE 在 H_gap 时只膨胀 r_gap，r_geo/r_force 不变；若真实故障是 gap 而几何可信，几何搜索域体积仅为总膨胀方案的 1/κ_infl^{d_φ}（几何分量），避免「因仿真不准而误降级真实几何」。反之 H_geo 时 r_gap 不变，保留孪生的前瞻能力。∎

## 7. 合成机制验证（不是 benchmark 证据）

为检查上述机制是否自洽，运行了 `exp/bridge_sim.py`（随机种子 20261113，纯合成生成模型，未拟合真实数据），结果写入 `exp/bridge_results.json`。四组检查分别对应迁移证书、虚拟探针、共因间隙、开集故障。

### 7.1 迁移证书（A）

设定线性裕度 m(θ)=0.70−w·θ，θ_sim 固定，真实 gap 幅度从 0 增至 1.0；配对校准给带噪 gap 估计，split-conformal 给 95% 上界。BRIDGE 只在 m_sim−bound≥0 时迁移；naive 永远迁移。

| gap 上限 δ_max | naive 虚假安全率 | BRIDGE 虚假安全率 | BRIDGE 可迁移率 | BRIDGE 平均真实裕度（迁移样本） |
|---|---|---|---|---|
| 0.0 | 0.00% | 0.00% | 99.95% | 0.300 |
| 0.2 | 0.00% | 0.00% | 98.50% | 0.301 |
| 0.4 | 0.35% | 0.00% | 85.62% | 0.302 |
| 0.6 | 4.30% | 0.00% | 74.82% | 0.300 |
| 0.8 | 8.50% | 0.00% | 65.08% | 0.300 |
| 1.0 | 12.05% | 0.03% | 58.47% | 0.301 |

解读：naive sim2real 的虚假安全率随 gap 单调上升；TCC 将其压到接近 0，同时保留低 gap 下的高可迁移率。代价是高 gap 下可迁移率下降——这是**有意的保守**，不是缺陷。

### 7.2 虚拟探针拍卖（B）

5 个故障假设、7 类探针、3 个间隙水平；sim 证据带与 H_geo 同向的未建模 bias。指标为 500 次试验均值。

| gap | 策略 | 归因准确率 | 真实探针数 | 真实风险 | 最终熵 |
|---|---|---|---|---|---|
| 0.0 | real-only AFA | 0.980 | 2.684 | 1.282 | 0.130 |
| 0.0 | sim-only | 0.996 | 0.000 | 0.000 | 0.020 |
| 0.0 | VPA | 0.996 | 0.112 | 0.056 | 0.036 |
| 0.5 | real-only AFA | 0.966 | 2.714 | 1.217 | 0.137 |
| 0.5 | sim-only | 0.982 | 0.000 | 0.000 | 0.126 |
| 0.5 | VPA | 0.992 | 0.384 | 0.234 | 0.131 |
| 1.0 | real-only AFA | 0.980 | 2.686 | 1.235 | 0.124 |
| 1.0 | sim-only | 0.886 | 0.000 | 0.000 | 0.913 |
| 1.0 | VPA | 0.968 | 1.670 | 1.004 | 0.268 |

解读：gap=0 时 VPA 用 0.112 个真实探针达到 sim-only 的准确率，比 real-only 少约 96% 的真实探针；gap=1.0 时 sim-only 准确率降到 0.886、熵升到 0.913，而 VPA 自动增加真实探针（1.67）并把准确率拉回 0.968，风险仍低于 real-only。**VPA 的关键不是「不用真实探针」，而是「只在孪生不可信时才用」。**

### 7.3 共因间隙（C）

设共享偏差 b_common 同时污染孪生与真实，配对差会抵消它；独立通道以 p=0.95 检出。比较 naive（总是迁移）、paired-only（只用配对差）与 BRIDGE（配对 + 独立通道）。

| b_common | naive 虚假安全率 | paired-only 虚假安全率 | BRIDGE 虚假安全率 | BRIDGE 可迁移率 |
|---|---|---|---|---|
| 0.0 | 0.00% | 0.00% | 0.00% | 99.98% |
| 0.2 | 0.05% | 0.05% | 0.00% | 4.90% |
| 0.4 | 9.68% | 9.65% | 0.45% | 5.50% |
| 0.6 | 100.0% | 100.0% | 4.30% | 4.30% |
| 0.8 | 100.0% | 100.0% | 4.98% | 4.98% |

解读：配对差单独无法识别共因（paired-only 与 naive 几乎相同）；有独立通道时 BRIDGE 把虚假安全率从 100% 压到约 5%。剩余 5% 是独立通道自身的漏检，**这就是 A99 必须显式声明的残余风险**。

### 7.4 开集/复合故障（D）

用未见复合故障（几何+力+模型）测试闭集 VISTA 与开集 BRIDGE（H_unknown 宽先验 + 拟合优度）。

| 指标 | 结果 |
|---|---|
| 未知复合故障检出率 | 99.02% |
| 闭集 VISTA 强行误归因率 | 100.0% |
| 已知故障准确率 | 89.3% |
| 已知故障误判 H_unknown 率 | 0.05% |

解读：闭集归因必然把未知故障塞进最近类；开集 BRIDGE 以极低的已知故障误报代价换到约 99% 的未知检出。实际部署应把 `H_unknown` 与 `safe_idle` 绑定，而不是继续执行。

## 8. 已知风险

**次级风险与缓解**：
1. **共因间隙不可辨识**：配对差会抵消共享偏差；缓解：AIC-W 显式建模 ℰ_common，强制独立通道（外部标定/IMU/本体感觉/已知砝码），不可用时拒绝迁移；共因下只要求 H_unknown + 安全降级。
2. **Lipschitz 常数 L_m 难估且保守**：L_m 过大会导致可迁移率过低；缓解：局部 Lipschitz + 区间算术 + 分区域标定；把 L_m 的不确定度并入 δ_gap；允许按任务切换证书。
3. **SBI/后验校准在髙维失效**：世界参数维度高、配对数据少；缓解：低维任务相关参数化（摩擦/刚度/增益/延迟）、SBI 后用 SBC 检验、失败则退回 conformal 或拒绝迁移。
4. **UniBot-V1 接口/版本漂移**：54/60 维 mask、动作归一化、基础模型版本变化会破坏配对；缓解：接口版本锁定、mask 校验、跨具身回归测试；基础模型只作语义流先验，实时流用蒸馏策略。
5. **基础模型幻觉**：UnifoLM-WLA-1.0 的长视界先验可能错；缓解：H_foundation 归因、r_foundation 膨胀、与孪生/真实配对残差交叉验证；不用基础模型直接产生安全证书。
6. **真实探针仍非零**：易损物可能一次接触都不能承受；缓解：VPA 支持 no_probe、visual_probe/null_test 优先、B_probe 可设 0；此时只做被动观测并降级。
7. **数字孪生构建成本**：高保真孪生需要资产/标定/渲染；缓解：从 UniBot-V1 真机数据与 SimFoundry 类工具构建；先做任务级低维孪生，不追求全场景高保真。
8. **实时预算**：配对 rollout 与 SBI 不能进实时环；缓解：全部语义流，实时流只读缓存的后验与 TCC；孪生集合用 GPU 并行，实时流只做残差采集与校验。
9. **评估偏差**：合成机制检查不是 benchmark；缓解：E241–E250 在 MuJoCo/Isaac 与 UniBot-V1 真机任务上分层验证，报告 sim-real 相关性，避免只报仿真。
10. **安全与伦理**：主动探针仍可能损伤物体；缓解：Shield 硬约束、力/形变上界、易损物零接触策略、人工急停与审计日志。

**本轮最大风险（一句话）**：若孪生与真实共享同一建模偏差（同一接触模型、同一训练分布、同一视觉渲染假设），「虚实对照」会把共因误差当成一致证据，迁移证书会在最需要时给出虚假安全感；而独立第三通道（力/触觉/外部标定）一旦也失效，BRIDGE 就无法仅凭两个世界辨识共因——这是本轮全部迁移保证共同依赖的隐藏假设（A99）。
