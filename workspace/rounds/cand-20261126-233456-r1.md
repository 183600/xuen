灵感驱动研究循环·新灵感二元组第 1 轮；本轮灵感：「手势识别」×「关节空间控制」

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v23 + IP-431–439（云边协同 CESC / 少样本有效 FSVC / 知识产权 IPAM / 四证准入门 HPC-E+；其上承 v22 的分层 PGEV/ACSC/DCSC/CFC++，v21 的语义-规范层 SDC/CAC/DCL/GIC，v20 联邦感知证书，v19 DCM/OGCC/CCV/DRS/OGC，v17 CLP/S2C/HCG/PSV/APS/AMC）。
> 本轮纪律：**手势不是符号标签而是配置空间里的轨迹；安全不是"笛卡尔目标无碰"而是"关节空间可执行"；意图只能调节规范，不能缩小几何不确定性**。不推倒 v23：HDL/ACSC/DCSC/HPC-E/CESC/FSVC/IPAM/HPC-E+ 全部保留。本轮只做一件事：**把"手势意图"与"机械臂关节控制"统一进同一个"人在环配置空间"，新增一层"关节空间可行性 + 人-机相对配置耦合"证书，把 v23 的"几何/规范/能量/云边可行"升级为"执行机构在误差管内可跟踪 ∧ 人-机配置耦合安全"，并封堵 v23 遗留的、更贴近物理的"单帧假许可 / 遮挡幻觉"风险面**。

## 0. 直觉与动机

**灵感 1（手势识别 → 手势是人体上肢配置空间中的轨迹泛函，而非静态类别）**
直觉：v23 的 GIC 把手势当成离散意图（STOP/YIELD/HANDOVER）分类，隐含假设是"一帧图像 → 一个符号"。但任何真实手势都是**手臂在时间上的连续构型轨迹**：交接是手稳定收敛到共享传递点、停止是减速并保持、让位是主动回撤。把"单帧高置信"当作许可，正是 v23 遗留的假许可风险面。若把人体上肢的关节构型 `q_h(t)` 用 conformal 预测集 `Q_h(t)` 估计出来，手势意图就变成轨迹窗口上的泛函 `g = Φ(Q_h(t-w:t))`——它天然要求**时序一致性、收敛性与稳定性**，单帧误读无法单独构成许可。副产品：人体关节构型预测集经正运动学生成**上肢扫掠体 SV_h(t)**，直接成为机器人关节空间里的动态障碍，手势与机器人关节控制第一次共享同一套"构型空间"语言。

**灵感 2（关节空间控制 → 证书必须落在执行机构真正有权限的空间里）**
直觉：v23 的 ACSC 已给臂加了配空间能耗与 `CertBox_arm`，但它仍是"在笛卡尔/任务空间判定无碰、再把能耗附加进去"。真实机械臂的权限边界在**关节空间**：关节限位、速度上限、力矩饱和、奇异位形（`σ_min(J)→0`）。一个笛卡尔上无碰的路径，可能在奇异点附近需要无穷大关节速度才能跟踪，控制器实际会偏离规划轨迹——于是"规划无碰"并不等于"执行无碰"。核心创新：**关节空间可行证书 (JSFC)**——对候选笛卡尔路径 `ξ(t)`，证明存在关节轨迹 `q_r(t) ∈ Q_free`（限位 ∩ 自碰自由 ∩ 奇异裕度）满足 `|q̇|≤v_max`、`|τ|≤τ_max`，且跟踪误差 `‖ξ - FK(q_r)‖ ≤ e_max`。证书从"目标是否无碰"升级为"执行机构能否在误差管内有权限地实现"。

**灵感 3（二者统一 → 人在环配置耦合证书）**
直觉：既然人手势是构型轨迹、机器人安全是关节可行，那么两者应在**相对配置空间**里耦合：机器人的关节空间障碍集 = 静态/自碰 ∪ 人体上肢扫掠体 `SV_h(t)⊕ε_h`；机器人关节轨迹必须在**远离该耦合障碍**的前提下同时满足 JSFC。关键反直觉点：**手势意图只能改写"规范状态"（速度、许可、让位义务），绝不能改写"几何不确定性"**——即使 GTIC 高置信判定 HANDOVER，`SV_h` 也绝不收缩，许可只在 `SV_h` 之外的共享传递点邻域生效。这样"假许可解锁危险接近"在结构上被切断：意图能调节的只是规范过滤器，不能缩小障碍。

**三者如何统一**
新增共享状态 `ζ_cfg = ζ_ce ∪ (Q_h, SV_h, g_traj, q_r, W_jsfc, ρ_rel)`。统一准入门 **HPC-E++ = HPC-E+ ∪ JSFC ∪ RCCC ∪ GTIC**，`Exec_v24 = Exec_v23 ∩ Fil_jsfc ∩ Fil_rccc ∩ Fil_gtic ⊆ Exec_v23`。其中 `Fil_rccc` 保证人-机相对配置裕度 `ρ_rel ≥ 0`，`Fil_gtic` 只允许意图在 JSFC 可行集**内部**调节规范。

## 2. 设计原则（在 P34–P42 基础上新增 P43–P45）

**P43 关节空间可行律（Joint-Space Feasibility）**
任何进入执行的笛卡尔计划 `ξ(t)` 必须附带 JSFC 见证：存在 `q_r(t)` 使 `q_r(t) ∈ Q_free = [q_min,q_max] ∩ SelfFree ∩ {σ_min(J(q_r)) ≥ σ_thr}`，`|q̇_r| ≤ v_max`，`|τ_r| ≤ τ_max`，且 `sup_t‖ξ(t) - FK(q_r(t))‖ ≤ e_max`。JSFC 不可满足 ⇒ 计划被拒，按**降权序列**（降速 → 关节空间避奇异解 → SafeStop）退化；不得仅凭笛卡尔无碰放行。故 `Exec_v24 ⊆ Exec_v23`。

**P44 人在环配置耦合律（Human-in-loop Configuration Coupling）**
人体上肢构型预测集 `Q_h(t)` 经正运动学生成扫掠体 `SV_h(t) = ⋃_{q_h∈Q_h} FK_h(q_h) ⊕ ε_h`；机器人关节空间障碍集必须包含 `SV_h(t)`，且 `SV_h` 对不确定性**单调**（`Q_h` 变大 ⇒ `SV_h` 只增）。**意图/许可只能改写规范过滤器，不得缩小 `SV_h` 或 `ε_h`**。相对配置裕度 `RCCC: min_t dist(FK_r(q_r(t)), SV_h(t)) ≥ d_safe(t)`，`d_safe` 随人-机相对速度只增不减。

**P45 意图不越可行律（Intent Cannot Exceed Feasibility）**
手势轨迹意图 `g = Φ(Q_h(t-w:t))` 仅能：(a) 触发 STOP/让位义务（低门槛、fail-safe）；(b) 在 JSFC 可行集**内部**调节许可/速度上限；(c) **绝不**把 JSFC 不可行或 RCCC 违反的运动变为可行。GTIC 许可需：窗口内轨迹收敛稳定 ∧ 置信 1-α ∧ 目标区 AbsCert 有效 ∧ ≥2 模态佐证 ∧ 滞回；`TTL_g` 过期回落最严默认。

## 3. 与基线的接口（如何退化）

- HAJSE 失效（姿态估计器故障）⇒ `Q_h` 退化为"人体上肢可达任意构型"的**最大扫掠体** ⇒ 比 v23 更保守；
- GTIC 失效 ⇒ 无许可解锁，义务/急停回落 v23 GIC 静态默认 ⇒ 子集；
- JSFC 失效（IK/力矩模型不可信）⇒ 退回 v23 的笛卡尔 `CertBox_arm` + 静态关节限位保守解 ⇒ `Exec_v24 ⊆ Exec_v23`；
- RCCC 失效 ⇒ 以人体最大可达包络（不依赖实时姿态）作障碍 ⇒ 更保守；
- CESC/FSVC/IPAM（v23 四证）失效 ⇒ 完全退回 v23 ⇒ `Exec_v24 ⊆ Exec_v23`；
- 全部失效 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`。
- **安全继承方向**：HAJSE 只增 `Q_h`（遮挡只膨胀）、SV_h 只增、JSFC 只拒不放、GTIC 只在可行集内解锁、RCCC 只加裕度；任意失效都向更保守退化。

## 4. 预期贡献

1. **手势即配置轨迹**：把手势从静态分类升级为 conformal 构型预测集上的轨迹泛函，从结构上消除单帧假许可；
2. **人体扫掠体耦合**：人体上肢不确定性第一次以构型空间障碍形式进入机械臂关节控制，并证明意图不能缩小该障碍；
3. **关节空间可行证书**：把"几何无碰"升级为"执行机构在误差管内可跟踪"，给出 JSFC 见证与降权退化序列；
4. **意图-可行性交**：给出许可在可行集内的形式化与 chatter 抑制（滞回 + TTL）；
5. **五证一体 HPC-E++**：`Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18` 单调退化链闭环。

## 5. 本轮最大风险

**一句话**：`Q_h` 的 conformal 覆盖依赖交换性，而人体自遮挡/机器人遮挡恰是**非随机、系统性的**缺失机制——被遮挡的肢体可能落在预测集之外，使 `SV_h` 系统性欠膨胀，机器人将在关节空间里"确信"那条手臂不在某处，而它恰恰在那里：即"被遮挡肢体的幽灵"。

# ============================================================
# IP-440 Human Arm Joint-Space Estimator (HAJSE)
# ============================================================
@dataclass
class ConformalSet:
    center: np.ndarray          # 名义关节构型 q_hat ∈ R^{d_h}
    radius: np.ndarray          # 逐关节 conformal 半径
    occlusion: np.ndarray       # 关节级遮挡掩码 occ
    t: float

class HumanArmEstimator:
    def __init__(self, pose_net, alpha=0.01, kappa=0.5):
        self.pose_net = pose_net
        self.alpha = alpha
        self.kappa = kappa
        self.D_calib = []       # (score, residual) 滑动窗口
        self.q_hat_alpha = {}   # 分数分位数

    def inflate_for_occlusion(self, radius, occ):
        # 关键：只膨胀不收缩；被遮挡关节的半径按 kappa 单调放大
        return radius * (1.0 + self.kappa * occ)

    def predict_set(self, frame) -> ConformalSet:
        phi = self.pose_net.feature(frame)
        q_hat = self.pose_net.joints(phi)                 # 名义构型
        s = self.pose_net.score(phi)                      # 非一致性分数
        r = self.q_hat_alpha.get(s, self.q_hat_alpha_max) # conformal 半径
        occ = self.pose_net.occlusion_mask(frame)         # 遮挡掩码
        r = self.inflate_for_occlusion(r, occ)            # 单调膨胀
        return ConformalSet(q_hat, r, occ, time.now())

    def update_calibration(self, q_hat, q_true, occ):
        # HJCE (IP-447)：per-user 少量样本刷新分位数；遮挡样本不计入收缩
        s = self.pose_net.score_from_q(q_hat)
        self.D_calib.append((s, np.abs(q_hat - q_true)))
        if len(self.D_calib) > 5000:
            self.D_calib.pop(0)
        self.q_hat_alpha = conformal_quantiles(self.D_calib, self.alpha)

# IP-441 Gesture Trajectory Intent Certificate (GTIC)
# ============================================================
class GestureTrajectoryIntent:
    def __init__(self, window=10, w_min=5, ttl=0.5,
                 h_low=0.55, h_high=0.75, alpha=0.01):
        self.window, self.w_min, self.ttl = window, w_min, ttl
        self.h_low, self.h_high, self.alpha = h_low, h_high, alpha
        self.last_intent, self.last_t = "NONE", 0.0

    def _stable(self, Qs):
        # 相邻帧构型中心漂移小于阈值，且无关节半径突增
        return all(dist(Qs[i].center, Qs[i+1].center) < d_stab
                   for i in range(len(Qs)-1))

    def _converges(self, Qs):
        # 手部末端向共享传递点收敛，速度递减
        return (dist(FK_h(Qs[-1].center), p_transfer) < d_transfer
                and speed(Qs[-1]) < speed(Qs[0]))

    def _retreats(self, Qs):
        return all(dist(FK_h(Qs[i].center), p_transfer) >
                   dist(FK_h(Qs[i-1].center), p_transfer)
                   for i in range(1, len(Qs)))

    def infer(self, Qs) -> str:
        # STOP：低门槛 fail-safe，任一窗口满足即触发
        if self._is_stop(Qs):
            return self._commit("STOP")
        if len(Qs) < self.w_min or not self._stable(Qs):
            return self._commit("NONE")
        if self._converges(Qs) and self._confidence(Qs) >= 1 - self.alpha:
            return self._commit_hysteretic("HANDOVER")
        if self._retreats(Qs):
            return self._commit("YIELD")
        return self._commit("NONE")

    def _commit_hysteretic(self, intent):
        # 滞回：许可需连续超过 h_high，撤销降到 h_low 以下
        if intent == "HANDOVER" and self._ratio("HANDOVER") >= self.h_high:
            return self._commit("HANDOVER")
        if self.last_intent == "HANDOVER" and self._ratio("HANDOVER") >= self.h_low:
            return self._commit("HANDOVER")
        return self._commit("NONE")

    def _commit(self, intent):
        self.last_intent, self.last_t = intent, time.now()
        return intent

    def get(self):
        # TTL：过期回落最严默认
        if time.now() - self.last_t > self.ttl:
            return "NONE"
        return self.last_intent

# IP-442 Joint-Space Feasibility Certificate (JSFC)
# ============================================================
@dataclass
class JSFCWitness:
    q_traj: np.ndarray      # 关节轨迹
    tau_traj: np.ndarray    # 关节力矩
    sigma_min: float        # 全程最小奇异值

class JointSpaceFeasibility:
    def __init__(self, robot, sigma_thr=0.05, v_max=1.0,
                 tau_max=50.0, e_max=0.01, dt=0.02):
        self.robot, self.sigma_thr = robot, sigma_thr
        self.v_max, self.tau_max = v_max, tau_max
        self.e_max, self.dt = e_max, dt

    def certify(self, xi_traj, q_r0) -> Optional[JSFCWitness]:
        # 以关节空间跟踪候选解（多初值 + 热启动）避免 IK 局部最优误判
        best = None
        for seed in self._seeds(q_r0):
            q_traj = self._track(xi_traj, seed)   # 关节空间跟踪
            if q_traj is None:
                continue
            w = self._check(q_traj, xi_traj)
            if w is not None:
                return w
            best = best or w
        return best

    def _check(self, q_traj, xi_traj):
        sig_min = np.inf
        for k, q in enumerate(q_traj):
            if not self.robot.in_limits(q):            return None
            if self.robot.self_collision(q):           return None
            if np.linalg.svd(self.robot.jacobian(q))[1][-1] < self.sigma_thr:
                return None
            qd = (q_traj[k] - q_traj[k-1]) / self.dt if k > 0 else 0
            if np.max(np.abs(qd)) > self.v_max:        return None
            tau = self.robot.inverse_dynamics(q, qd, 0)
            if np.max(np.abs(tau)) > self.tau_max:     return None
            sig_min = min(sig_min, np.linalg.svd(self.robot.jacobian(q))[1][-1])
        if max(dist(xi_traj[k], self.robot.fk(q_traj[k]))
               for k in range(len(q_traj))) > self.e_max:
            return None
        return JSFCWitness(q_traj, tau_traj, sig_min)


# ============================================================
# IP-444 Joint-Space Authority Governor (JSAG)
# ============================================================
class JointSpaceAuthorityGovernor:
    def degrade(self, plan, reason):
        # 降权序列：先降速，再切关节空间避奇异解，最后 SafeStop
        yield self._slow(plan, factor=0.5)
        alt = self._joint_avoid_singularity(plan)
        if alt is not None:
            yield alt
        yield self._safe_stop(plan)


# ============================================================
# IP-443 Relative Configuration Coupling Certificate (RCCC)
# ============================================================
class RelativeConfigCoupling:
    def __init__(self, eps_h=0.02, eps_disc=0.01, d0=0.3, kv=0.2):
        self.eps_h, self.eps_disc, self.d0, self.kv = eps_h, eps_disc, d0, kv

    def swept_volume(self, Q_h: ConformalSet) -> Occupancy:
        # 保守外近似：对 Q_h 采样 + 包围盒膨胀；半径只增
        pts = [FK_h(q) for q in sample_box(Q_h.center, Q_h.radius, n=64)]
        hull = convex_hull(pts)
        return hull.inflate(self.eps_h + self.eps_disc)   # 只膨胀

    def margin(self, q_r_traj, SV_h, v_rel_traj) -> float:
        return min(dist(FK_r(q_r_traj[k]), SV_h) - (self.d0 + self.kv * v_rel_traj[k])
                   for k in range(len(q_r_traj)))


# ============================================================
# IP-445 Coupled Intent-Feasibility Gate (CIFG)
# ============================================================
class CoupledIntentFeasibilityGate:
    def compatible(self, g, plan, w_jsfc) -> bool:
        # 意图只能改规范/速度，不能把不可行变可行；许可仅在 JSFC 可行集内部
        if g == "STOP":
            return plan.is_stop()                 # STOP 永远兼容（触发停机）
        if g == "HANDOVER":
            # 许可：仍需 JSFC 见证 + 目标区 AbsCert + 传递点在 SV_h 外
            return (w_jsfc is not None
                    and plan.target_area.abs_cert_valid
                    and dist(plan.p_transfer, plan.SV_h) >= plan.d_safe)
        if g == "YIELD":
            return plan.yield_state_reachable(w_jsfc)
        return True                               # NONE：保持 v23 默认规范


# ============================================================
# IP-446 HPC-E++ 统一五证准入门
# ============================================================
@dataclass
class HPCEPlusPlus:
    hpc_e_plus: 'HPCEPlus'      # v23 四证：几何∧规范∧负信息∧能量∧云边∧少样本∧IP
    jsfc: JointSpaceFeasibility
    rccc: RelativeConfigCoupling
    gtic: GestureTrajectoryIntent
    cifg: CoupledIntentFeasibilityGate

    def admits(self, plan, x, v, z, E_res, margin_req, modules, Q_h, v_rel) -> bool:
        # 1. v23 四证基础
        if not self.hpc_e_plus.admits(plan, x, v, z, E_res, margin_req, modules):
            return False
        # 2. 关节空间可行性（见证存在）
        w = self.jsfc.certify(plan.xi, plan.q_r0)
        if w is None:
            return False
        # 3. 人-机相对配置耦合（人体扫掠体进障碍集）
        SV = self.rccc.swept_volume(Q_h)
        if self.rccc.margin(w.q_traj, SV, v_rel) < 0:
            return False
        # 4. 手势轨迹意图 + 意图不越可行
        g = self.gtic.get()
        if not self.cifg.compatible(g, plan, w):
            return False
        return True


# ============================================================
# 端到端：感知 → 人体配置 → 意图 → 关节可行 → 耦合 → 准入
# ============================================================
class HumanInLoopConfigPipeline:
    def __init__(self, config):
        self.hajse = HumanArmEstimator(config['pose_net'])
        self.gtic = GestureTrajectoryIntent()
        self.jsfc = JointSpaceFeasibility(config['robot'])
        self.rccc = RelativeConfigCoupling()
        self.jsag = JointSpaceAuthorityGovernor()
        self.cifg = CoupledIntentFeasibilityGate()
        self.gate = HPCEPlusPlus(config['hpc_e_plus'], self.jsfc,
                                 self.rccc, self.gtic, self.cifg)
        self.window = []

    def step(self, sensor_data, plan, cloud_update=None) -> tuple[bool, dict]:
        # 人体构型预测集（10–20Hz 足够：人手运动慢于机器人）
        Q_h = self.hajse.predict_set(sensor_data['human_frame'])
        self.window = (self.window + [Q_h])[-self.gtic.window:]
        g = self.gtic.infer(self.window)

        admitted = self.gate.admits(
            plan, sensor_data['x'], sensor_data['v'], sensor_data['z'],
            sensor_data['E_res'], sensor_data['margin_req'],
            sensor_data['modules'], Q_h, sensor_data['v_rel'])

        if not admitted:
            # 降权而非直接停机：JSAG 逐级尝试
            for alt in self.jsag.degrade(plan, "gate_reject"):
                if self.gate.admits(alt, sensor_data['x'], sensor_data['v'],
                                    sensor_data['z'], sensor_data['E_res'],
                                    sensor_data['margin_req'],
                                    sensor_data['modules'], Q_h,
                                    sensor_data['v_rel']):
                    return True, {'plan': alt, 'intent': g, 'degraded': True}
            return False, {'plan': None, 'intent': g, 'degraded': True}
        return True, {'plan': plan, 'intent': g, 'degraded': False}

## 3. 正确性论证

### 引理 1（JSFC 的误差管包含与执行集单调）
**陈述**：若 `JSFC(ξ)` 成立，则实际执行轨迹 `ξ_act` 满足 `sup_t dist(ξ_act(t), ξ(t)) ≤ e_max` 且 `q_r(t) ∈ Q_free`；JSFC 拒绝只会移除计划，故 `Exec_v24 ⊆ Exec_v23`。

**证明**：
1. JSFC 见证给出 `q_r(t) ∈ Q_free` 与 `sup‖ξ-FK(q_r)‖≤e_max`，即存在可实现该笛卡尔路径的关节轨迹；
2. 控制器跟踪误差由 `e_max` 界定（跟踪控制器设计保证），故 `ξ_act` 落在以 `ξ` 为轴的 `e_max` 管内；
3. 见证要求 `q_r ∈ Q_free`，故限位/自碰/奇异裕度在执行中均成立；
4. JSFC 是 `Exec_v23` 之上的附加连言过滤，拒绝只会收缩执行集，故 `Exec_v24 ⊆ Exec_v23`。
∎

### 引理 2（扫掠体单调膨胀 ⇒ 无假自由空间）
**陈述**：`SV_h` 对 `Q_h` 与遮挡掩码单调不减；GTIC 的任何意图都不能使 `SV_h` 收缩，故意图不能制造假自由空间。

**证明**：
1. `inflate_for_occlusion(r, occ) = r·(1+κ·occ) ≥ r`，遮挡只增半径；
2. `swept_volume` 对 `Q_h` 采样后取凸包并膨胀 `ε_h+ε_disc`，`Q_h` 增大或采样加密只会使外近似不减；
3. P44 规定意图只改规范过滤器，`SV_h` 的构造不读取 `g_traj`，故 `∂SV_h/∂g = 0`；
4. 因此 `SV_h` 不因 HANDOVER 等意图而收缩，假自由空间不可能由意图产生。
∎

### 引理 3（时序一致性抑制单帧假许可）
**陈述**：在 GTIC 的窗口稳定性 + 滞回 + TTL 下，单帧误读产生许可的概率为 0；许可的假阳率上界为 `α × P(窗口内稳定误读)`。

**证明**：
1. 许可需 `len(Qs) ≥ w_min` 且 `_stable(Qs)`，单帧不满足窗口长度；
2. 许可需 `_converges` 与置信 `≥1-α`，且滞回要求连续超过 `h_high` 才上锁、降到 `h_low` 以下才撤销；
3. `TTL_g` 使过期许可自动回落最严默认，阻断陈旧许可；
4. 故单帧误读无法构成许可，残余假许可需整窗稳定误读，概率被 `α` 与稳定性门槛联合压制。
∎

### 引理 4（人在环配置层的单调退化链）
**陈述**：任意单点/组合失效下，`Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`。

**证明**：
- HAJSE 失效 ⇒ `Q_h` 取最大可达集 ⇒ `SV_h` 最大 ⇒ RCCC 最严 ⇒ 子集；
- GTIC 失效 ⇒ 无许可，回落 v23 GIC 静态默认 ⇒ 子集；
- JSFC 失效 ⇒ 退回 v23 笛卡尔 `CertBox_arm` + 静态限位 ⇒ 子集；
- RCCC 失效 ⇒ 用人体最大可达包络作障碍 ⇒ 子集；
- v23 四证失效 ⇒ 完全退回 v23 ⇒ 子集；
- 组合失效取交，单调性保持。
∎

### 定理（HPC-E++ 五证准入门的安全-合规-可行-耦合-意图完备性）
**陈述**：对任意计划 `π`，`HPCEPlusPlus.admits(π) = True` ⟺ `π` 同时满足：
(1) v23 四证（物理接地/云边一致/少样本覆盖/IP 保护）；
(2) 关节空间可行（存在 `q_r∈Q_free` 的误差管见证）；
(3) 人-机相对配置耦合安全（`ρ_rel ≥ 0`，`SV_h` 已计入障碍）；
(4) 手势意图不越可行（许可仅在 JSFC 可行集内部，STOP 优先）。

**证明**：直接由 `HPCEPlusPlus.admits` 的四个连言条件与引理 1–4 可得。必要性：任一条件缺失即拒证，对应几何/云边/执行机构/耦合/意图五类风险之一未缓解。充分性：四条件全满足，由引理 1 保证跟踪误差管与关节可行，引理 2 保证无意图制造的假自由空间，引理 3 保证无单帧假许可，引理 4 保证单调退化，构成完整闭环。
∎
