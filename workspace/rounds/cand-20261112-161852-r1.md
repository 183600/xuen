# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC / IP-153~160；灵感循环第 7 轮；本轮灵感：「虚实迁移」×「安全交互」）

> 第 60 轮把「执行层→证据层」升级为「认知驱动的场景-执行闭环」：SSM 用场景→阻抗先验提前收窄 K_safe，CIEC 用意图→约束锁定实时预算，EPIR 用 seq+hash 保障 ROS 丢包下的证据链，SERC 串起闭环，PCE++++ 引入四维认知预算。但**三个与「仿真」和「人」有关的根本局限**仍未解决：
> 1. **场景先验的虚实错位**：π_scene(K|z) 只在真实遥测上在线更新，而部署前的 K_safe 由仿真/离线数据预编译。仿真接触模型（刚性接触、理想摩擦锥、零延迟）与真实的系统性偏差会让「仿真中收敛」的 K_safe 在真实世界越界，却没有任何**迁移差距的量化与担保**。
> 2. **意图锁定的安全裸奔**：CIEC 用固定规则把意图映射为约束并立即锁死 ERTC，但意图可能是分布外、模糊甚至对抗的；规则映射无法保证锁定后的系统在人类不可控输入 u_h 下仍停留在安全集内，缺少**交互安全护盾**与可验证的安全证书。
> 3. **证据链是单向的**：EPIR 只做「边→云」回传，数字孪生/仿真器并不消费 EV-exec 去修正自身参数，虚实之间只有「仿真→现实」的策略下发，没有「现实→仿真」的系统辨识回流，迁移差距始终是开环的。

## 0. 直觉与动机

**灵感 1（虚实迁移 → 域随机化阻抗先验 DRIP）**
直觉：仿真最大的价值不是「复现一个真实世界」，而是「可控地制造一族真实世界的可能版本」。把质量 m、静/动摩擦 μ_s/μ_k、接触阻尼 c、传感-通信延迟 τ、噪声 σ_n 当作随机化域 θ~Θ_dom，每个 θ 在仿真里收敛出一个 K*_safe(θ,z)。迁移时不要用均值，而要用**最坏情况包络**（CVaR）：只要现实 θ* 落在域内，包络就覆盖它。关键洞见：**迁移安全不是「平均性能」，而是「对域内最坏情形的可证覆盖」**——均值先验会让多数场景变好、少数场景变灾难性。

**灵感 2（安全交互 → 交互安全过滤器 ISF）**
直觉：人不是环境的一部分，而是持续注入系统的不可控扰动 u_h。安全交互不能靠「预测人」，而要靠「无论人做什么，机器人都有安全动作」。用控制障碍函数（CBF）定义安全集 S_safe（力上限、速度上限、人机距离、关节/力矩限制），意图只修改标称控制 u_nom，**永远不能修改 S_safe**；ISF 用 QP 求最小修正，QP 不可行就退回柔顺/冻结/后撤。关键洞见：**意图可以提议约束，但不能废除安全集**——这正是「认知先行」与「安全兜底」的边界。

**灵感 3（现实→仿真回流 → 数字孪生标定 DTC）**
直觉：每一次真实接触都是一枚「接触指纹」EV-exec（力-位-时序列）。把它回灌仿真做贝叶斯系统辨识，更新 θ_sim 的后验；接触残差 r=||F_real−F_sim(θ)|| 既是标定信号，也是迁移差距的探针。关键洞见：**仿真先验的可信度应当是时变的**：当残差持续偏大，就应主动降低对仿真先验的权重，而不是继续相信一张「过期的地图」。

**灵感 4（三灵感合流 → 虚实安全迁移闭环 VSTC）**
直觉：闭环 = 域随机化采样 → 迁移先验 → EEIS 编译 → 真实执行（ISF 护盾）→ EV-exec/交互记录 → 迁移差距估计 →（安全且可信才）回流 DTC → 更新 θ_sim → 再采样。关键：**在迁移与回流之间加一道「安全闸门」**，不让一次灾难性执行污染孪生标定，也不让过期的仿真先验覆盖真实安全。

**灵感 5（预算 → PCE+++++ / 迁移安全预算 B_vt）**
直觉：迁移不是免费的：域采样与验证、CBF-QP 求解、孪生标定都要算力/时间。新增 B_dr、B_safe、B_twin；耗尽时的降级必须仍是安全的：B_dr 耗尽→用已覆盖的最坏包络；B_safe 耗尽→直接进入物理柔顺/停止模态；B_twin 耗尽→冻结仿真先验、只用真实在线辨识。关键洞见：**安全预算的降级顺序不能按「性能」排，而必须按「危险度」排**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（域随机化阻抗先验 DRIP）** DRIP = (Θ_dom, K*_{θ,z}, π_s2r, α, ℓ)。其中：
- **域参数**：θ = (m, μ_s, μ_k, c, τ, σ_n, b_f) ~ Θ_dom，b_f 为未建模接触偏置
- **仿真安全集**：K*_{θ,z} = EEIS.compile(sim(θ), z) 为在仿真参数 θ、场景 z 下收敛的可行阻抗集
- **风险函数**：ℓ(K,θ;z) = max_t [ (F_t/F_max − 1)_+ + (v_t/v_max − 1)_+ + λ_s·slip_t + λ_e·|e_t|/e_max ] ≥ 0，仅在越界时为正
- **最坏情况包络**：K_safe^s2r(z;α) = { K : CVaR_α[ℓ(K,θ;z) | θ~Θ_dom] ≤ δ_safe }，即对域内最坏 α 分位的条件风险仍安全
- **迁移先验**：π_s2r(K|z) = Σ_θ w(θ)·κ(K − K*_{θ,z})，权重 w(θ) 由 DTC 后验给出（现实证据越支持 θ，该仿真实例权重越高）
- **覆盖度**：ρ_cov = P_{θ~Θ_dom}[θ 落在真实参数 θ* 的 ρ-邻域]，作为 TSC 的先验条件

**定义 162（交互安全过滤器 ISF）** ISF = (S_safe, {h_i}, QP, Γ_fb)。系统 ẋ = f(x) + g(x)u_r + g_h(x)u_h，其中 u_r 为机器人控制、u_h 为人类输入：
- **安全集**：S_safe = { x : h_i(x) ≥ 0, i=1..m }，h_i 覆盖接触力、末端速度、人机距离、关节/力矩、工作空间
- **意图不变性**：C_intent 只作用于标称控制 u_nom = π_imp(x; K_safe, C_intent)，**S_safe 与 C_intent 无关**
- **安全 QP**：
  ```
  u* = argmin_u ||u − u_nom||²_W
       s.t. L_f h_i + L_g h_i·u + L_{g_h} h_i·u_h + α_i(h_i) ≥ 0,  ∀i
            u ∈ U,  F_contact(u) ≤ F_max
  ```
- **兜底**：若可行域为空，Γ_fb 依次尝试 compliant→freeze→retreat，且每一模态都需保持 h_i ≥ 0
- **干预代价**：I_isf = ||u* − u_nom||_W；安全裕度 s = min_i h_i(x)

**定义 163（数字孪生标定 DTC）** DTC = (θ_sim, p(θ), L(θ;E), r_contact, c_twin)。其中：
- **贝叶斯更新**：p(θ|E_1:t) ∝ p(E_t|θ)·p(θ|E_1:t−1)，E_t 为第 t 条 EV-exec
- **接触残差**：r_t(θ) = ||F_t^real − F_t^sim(θ)||²_{Σ⁻¹}，用于粒子/变分后验重加权
- **孪生置信**：c_twin = exp(−λ_r·r̄_t)·1[H(p(θ|E_1:t)) ≤ H_max]，r̄_t 为加权平均残差，H 为后验熵
- **失配触发**：当 c_twin < τ_twin 或 r̄_t 连续 K 个周期上升，判定「仿真失配」，冻结仿真先验并转入真实在线辨识

**定义 164（虚实迁移差距 VTG）** 迁移差距估计量
```
Ĝ_vt = W_1(π̂_s2r, π̂_real) + λ_g·r̄_contact
```
其中 π̂_s2r 为 DRIP 的加权样本分布，π̂_real 为真实 EV-exec 反演得到的 K 估计分布，W_1 为一维 Wasserstein 距离。可分解为 **模型差距 G_model + 参数差距 G_param + 观测差距 G_obs**。**迁移有效条件**：Ĝ_vt ≤ ε_vt 且 c_twin ≥ τ_twin。

**定义 165（迁移安全证书 TSC）** TSC = (K_safe, z, V_env, ρ_vt, δ_dom, ε_gap, c_twin, expiry, src_hash)。有效性判定：
```
TSC.valid ⇔ K_safe ∈ K_safe^s2r(z;α)          # CVaR 风险覆盖
           ∧ Ĝ_vt ≤ ε_gap                       # 迁移差距可接受
           ∧ c_twin ≥ τ_twin                    # 孪生可信
           ∧ now ≤ expiry                       # 未过期
           ∧ (运行时) x ∈ S_safe                # ISF 持续维持
```
任一条件失效即**运行时撤销证书**并触发重编译/回退，证书不可「先发后不管」。

**定义 166（虚实安全迁移闭环 VSTC）** 算子 VSTC(M, scene, intent, delta_f_req)：
```
① DTC: 若存在待标定 EV-exec，更新 p(θ|E)、c_twin、r̄
② DRIP: 采样 Θ_dom → {K*_{θ,z}} → CVaR 包络 K_safe^s2r(z;α)
③ EEIS: K_safe ← compile_with_transfer_prior(K_safe^s2r, π_scene, δ_f_req)
④ CIEC: C_intent ← ϕ_intent→constraint(intent)      # 只改 u_nom，不改 S_safe
⑤ ISF: u* ← safety_filter(x, u_nom(K_safe, C_intent), u_h)；不可行→Γ_fb
⑥ Execute: telemetry ← wait_contact(); EV-exec ← build_exec_evidence(...)
⑦ EPIR: append(EV-exec); sync(); 因果-seq-hash 校验
⑧ VTG: Ĝ_vt ← estimate_gap({K*_{θ,z}}, K_real, w(DTC))
⑨ TSC: issue_or_revoke(K_safe, Ĝ_vt, c_twin, x)
⑩ 安全闸门: if Ĝ_vt ≤ ε_gap ∧ c_twin ≥ τ_twin ∧ x∈S_safe:
                pending_evidence.append(EV-exec)
            else: quarantine(EV-exec); recompile_or_retreat()
⑪ Return: (K_safe, u*, EV-exec, TSC, Ĝ_vt, c_twin)
```

**定义 167（迁移安全预算 B_vt 与 PCE+++++）** B_vt = (B_dr, B_safe, B_twin, B_scene, B_intent, B_exec)。其中新增：
- **B_dr** = (Domain_sample_budget, CVaR_eval_budget, Envelope_cert_budget)
- **B_safe** = (CBF_QP_budget, Human_model_budget, Fallback_budget)
- **B_twin** = (SysID_particle_budget, Gap_estimate_budget, Posterior_update_budget)
- **PCE+++++ VOI**：
```
voi_vt(π) = VOI_meta_pessimistic(π) − cost_vt(π) − cost_cog(π) − cost_exec(π)
cost_vt = λ_dr·DomainCost(π) + λ_safe·QPCost(π) + λ_twin·SysIDCost(π)
```
**降级优先级（按危险度而非性能）**：B_safe 耗尽⇒立即 compliant/stop；B_twin 耗尽⇒冻结 π_s2r、仅用真实在线辨识；B_dr 耗尽⇒只用已认证的最坏包络；B_scene/B_intent/B_exec 耗尽⇒沿用第 60 轮策略。

**定义 168（信任-安全耦合模型 TSM）** 交互安全状态 IS = (s, t)，s 为安全裕度、t∈[0,1] 为人类校准信任：
- **信任更新**：t_{k+1} = clip(t_k + η₁(1 − e_pred) − η₂·I_isf, 0, 1)，e_pred 为意图/行为预测误差，I_isf 为护盾干预强度
- **安全交互域**：S_int = { (s,t) : s ≥ s_min ∧ t ∈ [t_min, t_max] }
- **失配告警**：若 s < s_min ∧ t > t_max → `over_trust_danger`（人类过度放权），需主动降速/解释；若 t < t_min → `trust_miscalibrated`，需透明化与辅助接管
- **关键洞见**：安全交互不只是物理力限，还包括**信任校准**——过度信任与物理越界同样危险

### IP-161 DRIP（域随机化阻抗先验）

```python
class DomainRandomizedImpedancePrior:
    def __init__(self, domain, eeis, alpha=0.1, delta_safe=0.0):
        self.domain, self.eeis = domain, eeis
        self.alpha, self.delta_safe = alpha, delta_safe

    def compile_envelope(self, scene, delta_f_req, n_samples=256):
        samples = []
        for theta in self.domain.sample(n_samples):
            sim_env = self.eeis.make_sim_env(theta)
            K_star = self.eeis.compile_in_sim(sim_env, scene, delta_f_req)
            risk = self._risk(K_star, sim_env, scene)
            samples.append((theta, K_star, risk))
        risks = np.array([r for _, _, r in samples])
        thr = np.quantile(risks, 1 - self.alpha)
        worst = [s for s in samples if s[2] >= thr]
        K_env = intersect_boxes([s[1] for s in worst])
        return K_env, samples

    def transfer_prior(self, samples, weights):
        # weights = DTC posterior over domain parameters
        return WeightedKernelDensity(
            centers=[K for _, K, _ in samples],
            weights=weights,
            bandwidth=self._silverman(samples))

    def _risk(self, K, env, scene):
        traj = env.rollout(K, scene)
        force_v = np.maximum(traj.F / env.F_max - 1, 0)
        speed_v = np.maximum(traj.v / env.v_max - 1, 0)
        slip = np.sum(traj.slip_mask) / max(1, len(traj))
        return float(np.max(force_v) + np.max(speed_v) + 0.5 * slip)
```

### IP-162 ISF（交互安全过滤器）

```python
class InteractionSafetyFilter:
    def __init__(self, barriers, W, u_bounds, fallback):
        self.barriers, self.W = barriers, W
        self.u_min, self.u_max = u_bounds
        self.fallback = fallback

    def filter(self, x, u_nom, u_h):
        A, b = [], []
        for h in self.barriers:
            Lf, Lg, Lgh = h.lie_derivatives(x)
            # CBF: Lf h + Lg h * u + Lgh h * u_h + alpha(h) >= 0
            A.append(-(Lg + 1e-9))
            b.append(Lf + Lgh * u_h + self.alpha(h.value(x)))
        sol = solve_qp(H=self.W, f=-self.W @ u_nom,
                       A=np.vstack(A), b=np.array(b),
                       lb=self.u_min, ub=self.u_max)
        if sol is None:
            return self.fallback.select(x, u_h), {"intervened": True, "fallback": True}
        return sol.x, {"intervened": np.linalg.norm(sol.x - u_nom) > 1e-3,
                       "fallback": False}
```

### IP-163 DTC（数字孪生标定）

```python
class DigitalTwinCalibrator:
    def __init__(self, simulator, theta_prior, sigma, tau_twin=0.6):
        self.sim, self.sigma, self.tau_twin = simulator, sigma, tau_twin
        self.particles = theta_prior.sample(512)
        self.log_w = np.zeros(len(self.particles))
        self.c_twin, self.r_bar = 1.0, 0.0

    def update(self, ev_exec):
        risks = np.zeros(len(self.particles))
        for i, th in enumerate(self.particles):
            F_sim = self.sim.rollout(th, ev_exec.action_seq)
            risks[i] = np.sum(((ev_exec.force - F_sim) / self.sigma) ** 2)
        self.log_w += -0.5 * risks
        self.log_w -= logsumexp(self.log_w)
        w = np.exp(self.log_w)
        self.r_bar = float(w @ risks)
        entropy = -np.sum(w * np.log(w + 1e-12))
        self.c_twin = float(np.exp(-self.r_bar) * (entropy <= self.H_max))
        return self.c_twin, self.r_bar

    def weights(self):
        return np.exp(self.log_w - logsumexp(self.log_w))

    def mismatched(self):
        return self.c_twin < self.tau_twin
```

### IP-164/165 VTG 与 TSC（迁移差距 + 安全证书）

```python
def estimate_transfer_gap(sim_samples, real_K_hist, weights):
    p_sim = WeightedEmpirical([K for _, K, _ in sim_samples], weights)
    p_real = Empirical(real_K_hist)
    return wasserstein_1d(p_sim, p_real) + LAMBDA_G * mean_contact_residual()

def issue_or_revoke(K_safe, env, gap, twin_conf, runtime_safe, cfg):
    valid = (env.contains(K_safe)
             and gap <= cfg.eps_gap
             and twin_conf >= cfg.tau_twin
             and runtime_safe
             and now() <= cfg.expiry)
    cert = TransferSafetyCertificate(K_safe=K_safe, gap=gap,
                                     twin_conf=twin_conf, valid=valid,
                                     expiry=now() + cfg.ttl)
    if not valid:
        cert.revoke_reason = ("gap" if gap > cfg.eps_gap else
                              "twin" if twin_conf < cfg.tau_twin else
                              "runtime" if not runtime_safe else "expired")
    return cert
```

### IP-166 VSTC（虚实安全迁移闭环）

```python
def virtual_sim_safe_transfer_loop(M, scene, intent, delta_f_req):
    if M.pending_evidence:
        c_twin, r_bar = M.dtc.update(M.pending_evidence)
        M.pending_evidence.clear()

    K_env, samples = M.drip.compile_envelope(scene, delta_f_req)
    K_safe = M.eeis.compile_with_transfer_prior(K_env, M.scene_prior, delta_f_req)

    C_intent = M.intent_ctrl.map_intent(intent)          # 只影响 u_nom
    x = M.state()
    u_nom = M.impedance_ctrl(x, K_safe, C_intent)
    u_star, isf_info = M.isf.filter(x, u_nom, M.human_input())
    M.apply(u_star)

    ev = M.wait_contact(); EV_exec = build_exec_evidence(ev, u_star)
    msg = M.epir.append(EV_exec)

    gap = estimate_transfer_gap(samples, M.real_K_history, M.dtc.weights())
    tsc = issue_or_revoke(K_safe, K_env, gap, M.dtc.c_twin,
                          runtime_safe=(min_barrier(M.state()) >= 0), cfg=M.cfg)

    if isf_info["fallback"] or not tsc.valid:
        M.quarantine(EV_exec)                            # 灾难证据不污染孪生
        M.recompile_or_retreat()
    else:
        M.pending_evidence.append(EV_exec)               # 安全证据才回流 DTC

    return K_safe, u_star, EV_exec, tsc, gap, M.dtc.c_twin
```

### IP-167/168 PCE+++++ 与 TSM（预算 + 信任）

```python
class TransferSafetyBudget:
    def __init__(self, dr, safe, twin, cog):
        self.B = {"dr": dr, "safe": safe, "twin": twin, "cog": cog}

    def degrade(self):
        if self.B["safe"] <= 0:  return "compliant_stop"      # 最高危险度
        if self.B["twin"] <= 0:  return "freeze_sim_prior"
        if self.B["dr"] <= 0:    return "certified_envelope_only"
        if self.B["cog"] <= 0:   return "scene_intent_degrade"
        return "normal"

def update_trust(t, pred_err, intervention, eta1=0.1, eta2=0.2):
    return float(np.clip(t + eta1 * (1 - pred_err) - eta2 * intervention, 0, 1))

def interaction_state(margin, trust, cfg):
    if margin < cfg.s_min and trust > cfg.t_max: return "over_trust_danger"
    if trust < cfg.t_min:                        return "trust_miscalibrated"
    return "safe_interaction" if margin >= cfg.s_min else "assist_needed"
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DRIP | O(N_dom·C_compile) 离线 / O(N_dom) 在线 | O(N_dom) | CVaR 包络覆盖域内最坏 α 分位 |
| ISF | O(m³) 每周期 QP（m 为 barrier 数） | O(m²) | S_safe 前向不变；不可行必触发兜底 |
| DTC | O(N_p·T_rollout) 每证据 | O(N_p) | 后验随持续激励收敛；失配可检测 |
| VTG | O(N log N)（一维 Wasserstein 排序） | O(N) | Ĝ_vt 依概率收敛到真实差距 |
| TSC | O(1) 校验 | O(1) | 五条件同时满足才有效 |
| VSTC | O(闭环) | 复用 | 安全证据才回流；危险证据隔离 |

**正确性定理（VSTS，Virtual-Transfer Safety）**：
假设 A66–A72 成立：**(A66)** 域覆盖：真实 θ* 以概率 ≥1−β 落在 Θ_dom 的 α-支撑内，且 W₁(Θ_dom, θ*) ≤ ρ_dom；**(A67)** CVaR 证书：∀K∈K_safe^s2r，CVaR_α[ℓ(K,θ)] ≤ δ_safe；**(A68)** 模型误差有界：真实-仿真的 CBF 模型误差 e_m ≤ ē_m，采用鲁棒 CBF 的 class-κ 收紧；**(A69)** 人类输入有界且兜底存在：u_h ∈ H（力/速度有界），Γ_fb 各模态保持 S_safe 不变；**(A70)** 后验一致性：持续激励下 p(θ|E) 收敛，模型类正确时 c_twin→1，失配时 c_twin 下降；**(A71)** 差距估计集中：样本数 N→∞ 时 Ĝ_vt→G_vt；**(A72)** 预算单调且降级安全。

则：
1. **迁移安全**：若 Ĝ_vt ≤ ε_gap、c_twin ≥ τ_twin 且 TSC 有效，则真实执行以概率 ≥1−α−β 保持在 S_safe 内。
2. **交互安全**：对任意 u_h∈H，ISF 保证 S_safe 前向不变；QP 不可行时 Γ_fb 仍保证 h_i ≥ 0。
3. **失配可检测**：若真实动力学越出 Θ_dom 支撑，则 r̄_t 上升、c_twin 跌破 τ_twin 且 Ĝ_vt 超阈，TSC 在危险部署前被撤销。
4. **证据可信回流**：只有通过安全闸门的 EV-exec 才进入 DTC，灾难性样本被隔离，孪生标定不被污染。
5. **预算安全**：任一 B_vt 耗尽均触发对应安全降级，且 B_safe 优先级最高。

### IP-161 DRIP（域随机化阻抗先验）

```python
class DomainRandomizedImpedancePrior:
    def __init__(self, domain, eeis, alpha=0.1, delta_safe=0.0):
        self.domain, self.eeis = domain, eeis
        self.alpha, self.delta_safe = alpha, delta_safe

    def compile_envelope(self, scene, delta_f_req, n_samples=256):
        samples = []
        for theta in self.domain.sample(n_samples):
            sim_env = self.eeis.make_sim_env(theta)
            K_star = self.eeis.compile_in_sim(sim_env, scene, delta_f_req)
            risk = self._risk(K_star, sim_env, scene)
            samples.append((theta, K_star, risk))
        risks = np.array([r for _, _, r in samples])
        thr = np.quantile(risks, 1 - self.alpha)
        worst = [s for s in samples if s[2] >= thr]
        K_env = intersect_boxes([s[1] for s in worst])
        return K_env, samples

    def transfer_prior(self, samples, weights):
        return WeightedKernelDensity(
            centers=[K for _, K, _ in samples],
            weights=weights, bandwidth=self._silverman(samples))

    def _risk(self, K, env, scene):
        traj = env.rollout(K, scene)
        force_v = np.maximum(traj.F / env.F_max - 1, 0)
        speed_v = np.maximum(traj.v / env.v_max - 1, 0)
        slip = np.sum(traj.slip_mask) / max(1, len(traj))
        return float(np.max(force_v) + np.max(speed_v) + 0.5 * slip)
```

### IP-162 ISF（交互安全过滤器）

```python
class InteractionSafetyFilter:
    def __init__(self, barriers, W, u_bounds, fallback):
        self.barriers, self.W = barriers, W
        self.u_min, self.u_max = u_bounds
        self.fallback = fallback

    def filter(self, x, u_nom, u_h):
        A, b = [], []
        for h in self.barriers:
            Lf, Lg, Lgh = h.lie_derivatives(x)
            A.append(-(Lg + 1e-9))
            b.append(Lf + Lgh * u_h + self.alpha(h.value(x)))
        sol = solve_qp(H=self.W, f=-self.W @ u_nom,
                       A=np.vstack(A), b=np.array(b),
                       lb=self.u_min, ub=self.u_max)
        if sol is None:
            return self.fallback.select(x, u_h), {"intervened": True, "fallback": True}
        return sol.x, {"intervened": np.linalg.norm(sol.x - u_nom) > 1e-3,
                       "fallback": False}
```

**意图不变性**：`C_intent` 只进入 `u_nom`，`S_safe` 与 `{h_i}` 不随意图改变；因此 CIEC 的「认知先行」永远不能把系统推出安全集。

### IP-163 DTC（数字孪生标定）

```python
class DigitalTwinCalibrator:
    def __init__(self, simulator, theta_prior, sigma, tau_twin=0.6):
        self.sim, self.sigma, self.tau_twin = simulator, sigma, tau_twin
        self.particles = theta_prior.sample(512)
        self.log_w = np.zeros(len(self.particles))
        self.c_twin, self.r_bar = 1.0, 0.0

    def update(self, ev_exec):
        risks = np.zeros(len(self.particles))
        for i, th in enumerate(self.particles):
            F_sim = self.sim.rollout(th, ev_exec.action_seq)
            risks[i] = np.sum(((ev_exec.force - F_sim) / self.sigma) ** 2)
        self.log_w += -0.5 * risks
        self.log_w -= logsumexp(self.log_w)
        w = np.exp(self.log_w)
        self.r_bar = float(w @ risks)
        entropy = -np.sum(w * np.log(w + 1e-12))
        self.c_twin = float(np.exp(-self.r_bar) * (entropy <= self.H_max))
        return self.c_twin, self.r_bar

    def weights(self):
        return np.exp(self.log_w - logsumexp(self.log_w))

    def mismatched(self):
        return self.c_twin < self.tau_twin
```

```python
def issue_or_revoke(K_safe, env, gap, twin_conf, runtime_safe, cfg):

             and gap <= cfg.eps_gap

             and runtime_safe
```

```python
def virtual_sim_safe_transfer_loop(M, scene, intent, delta_f_req):
```
