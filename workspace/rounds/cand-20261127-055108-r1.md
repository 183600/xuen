### 第 2 轮灵感驱动研究记录（v26 扩展，接续 v25）

**灵感词**：自然语言指令、用户测试

**直觉与动机**：
现有 SRC-USC（v25）已把机器人从「单机物理」到「群体智能」的七类证书闭环，但整条证书链的输入端仍默认「任务规格 φ 已经给定、正确、且等于人类意图」。真实部署中，任务首先以自然语言出现（如「把红色杯子放到桌上，别碰到显示器」），而最终「对不对、好不好用」由用户裁定。受「自然语言指令」启发：自然语言到形式化规格（STL/LTL）的翻译本身必须携带 conformal 覆盖证书，歧义必须被显式度量、必要时澄清，指称必须接地到 v25 的语义实体。受「用户测试」启发：用户是最终验收者，其任务成功率、信任校准、可用性与接管行为应给出分布无关的有限样本统计下界证书。核心洞见：**自然语言是任务证书的「源」，用户测试是任务证书的「汇」；v25 证明了「执行得对」，v26 要证明「执行的是用户真正想要的，且用户认可」。**

**形式化目标**：
1. 定义自然语言指令证书（NLIC）：conformal 规格覆盖 ℙ(φ*∈C(ℓ))≥1-α_nl；歧义直径 diam(C(ℓ))≤ε_amb 或经澄清对话收敛；指称接地覆盖 ℙ(e*∈G(m))≥1-α_g；执行对「全部可能解释」鲁棒 min_{φ∈C(ℓ)} ρ_φ(π)≥ρ_min。
2. 定义用户测试证书（UTC）：总体任务成功率 Clopper–Pearson 下界 p_L≥1-α_u（置信度 1-δ）；信任校准误差与过度信任率受控；SUS 单侧下界；接管率 ≤γ_u 且每次接管安全回退。
3. 定义部署级证书有效期：UTC 是「许可」而非「每步检查」，在人群/任务分布漂移或有效期届满时失效并触发复测。
4. 构建九证准入门 NLU-USC：Exec_v26 = Exec_v25 ∩ Fil_nl ∩ Fil_user ⊆ Exec_v25。
5. 证明「语义误解 / 用户不接受」两条新退化路径不破坏单调退化链。

**一句话风险**：conformal 覆盖依赖「指令与用户可交换」，一旦遇到组合新颖或对抗性自然语言、且用户测试样本有偏，证书会「覆盖错误的规格」——形式上门通过，语义上却在执行用户从未要求的事。

```python
# ============================================================
# IP-448 Natural Language Instruction Certificate (NLIC) — 自然语言指令证书
# ============================================================
@dataclass
class NaturalLanguageInstructionCertificate:
    """规格覆盖 + 歧义控制 + 指称接地 + 全解释鲁棒 四重证书"""
    instruction: str
    parser: 'ConformalSpecParser'
    alpha_nl: float = 0.05
    eps_amb: float = 0.10          # 规格空间歧义直径容差
    alpha_g: float = 0.05
    rho_min: float = 0.0           # STL 鲁棒度下界
    max_clarify_rounds: int = 3
    spec_metric: 'SpecMetric' = None

    # ---------- 离线：conformal 校准（部署前一次性） ----------
    def calibrate(self, calib_pairs: list[tuple[str, 'Spec']]) -> 'ConformalSpecParser':
        """calib_pairs = [(ℓ_i, φ*_i)]，非一致性分数 s(ℓ,φ)=1-sim(φ,φ*)，
        取 ⌈(n+1)(1-α_nl)⌉/n 分位数 q̂，得 C(ℓ)={φ: s(ℓ,φ)≤q̂}"""
        self.parser.fit(calib_pairs, alpha=self.alpha_nl)
        return self.parser

    def verify_spec_coverage(self, holdout: list[tuple[str, 'Spec']]) -> bool:
        """留出集经验覆盖 ≥ 1-α_nl，且 CP 二项下界 ≥ 1-α_nl（防小样本侥幸）"""
        hits = sum(phi_star in self.parser.predict_set(ell) for ell, phi_star in holdout)
        return clopper_pearson_lower(hits, len(holdout), self.alpha_nl) >= 1 - self.alpha_nl

    # ---------- 在线：每条指令四重验证 ----------
    def verify_grounding(self, mentions: list['Mention'],
                         entities: list['SemanticEntity']) -> bool:
        """∀m: e*_m ∈ G(m)，G(m) 由 SMC 实体 + 开放词汇嵌入检索生成"""
        for m in mentions:
            G = self.parser.ground(m, entities)          # ⊆ ℰ
            if m.gt_entity is not None and m.gt_entity not in G:
                return False
            if m.gt_entity is None and len(G) == 0:      # 无法接地即拒
                return False
        return True

    def ambiguity_diameter(self, C: set['Spec']) -> float:
        """diam(C) = max_{φ,ψ∈C} d_Φ(φ,ψ)，|C| 通常 ≤5，直接两两计算"""
        return max((self.spec_metric.d(a, b) for a in C for b in C), default=0.0)

    def verify_ambiguity(self, C: set['Spec'],
                         dialogue: Optional['ClarificationDialogue'] = None) -> bool:
        """diam(C) ≤ ε_amb，否则必须澄清且直径单调收缩至阈值内"""
        if self.ambiguity_diameter(C) <= self.eps_amb:
            return True
        if dialogue is None:
            return False
        prev = self.ambiguity_diameter(C)
        for _ in range(self.max_clarify_rounds):
            C, question = dialogue.next(C)               # 主动提问消歧
            cur = self.ambiguity_diameter(C)
            if cur > prev * 1.05:                        # 澄清不得放大歧义
                return False
            if cur <= self.eps_amb:
                return True
            prev = cur
        return False                                     # 未收敛 → 拒证（转人工）

    def verify_plan_robustness(self, plan: 'Trajectory', C: set['Spec']) -> bool:
        """全解释鲁棒：对 C 中每个可能解释都满足 ρ_φ(π) ≥ ρ_min"""
        if not C:
            return False
        return min(stl_robustness(plan, phi) for phi in C) >= self.rho_min

    def verify_all(self, plan: 'Trajectory', mentions, entities,
                   dialogue=None) -> bool:
        C = self.parser.predict_set(self.instruction)
        return (bool(C)
                and self.verify_grounding(mentions, entities)
                and self.verify_ambiguity(C, dialogue)
                and self.verify_plan_robustness(plan, C))


# ============================================================
# IP-449 User Testing Certificate (UTC) — 用户测试证书
# ============================================================
@dataclass
class UserTestingCertificate:
    """任务成功率 + 信任校准 + 可用性 + 接管行为；部署级许可，非每步检查"""
    n_users: int
    successes: int
    delta: float = 0.05            # 置信水平：置信度 1-δ
    alpha_u: float = 0.10          # 可接受失败率
    trust_scores: list[float] = field(default_factory=list)
    reliability: list[float] = field(default_factory=list)
    sus_scores: list[float] = field(default_factory=list)
    interventions: int = 0
    gamma_u: float = 0.05
    eps_trust: float = 0.15
    sus_min: float = 68.0
    T_valid: float = 30.0          # 有效期（天）
    drift_score: float = 0.0       # 指令/用户分布漂移检测量
    drift_max: float = 0.20

    def cp_lower(self) -> float:
        """Clopper–Pearson 单侧下界：Beta(δ; k, n-k+1) 分位数"""
        if self.successes <= 0:
            return 0.0
        from scipy.stats import beta
        return float(beta.ppf(self.delta, self.successes,
                              self.n_users - self.successes + 1))

    def verify_task_success(self) -> bool:
        return self.cp_lower() >= 1 - self.alpha_u

    def verify_trust_calibration(self) -> bool:
        """平均校准误差 ≤ ε_trust，且过度信任（trust>rel，危险方向）占比受限"""
        if not self.trust_scores:
            return False
        err = sum(abs(t - r) for t, r in
                  zip(self.trust_scores, self.reliability)) / len(self.trust_scores)
        over = sum(max(0.0, t - r) for t, r in
                   zip(self.trust_scores, self.reliability)) / len(self.trust_scores)
        return err <= self.eps_trust and over <= self.eps_trust / 2

    def verify_usability(self) -> bool:
        """SUS 单侧 t 下界 ≥ sus_min"""
        return one_sided_t_lower(self.sus_scores, self.delta) >= self.sus_min

    def verify_interventions(self) -> bool:
        """接管率 ≤ γ_u；且每次接管都被 v25 安全回退吸收（由 admits 保证）"""
        return self.n_users > 0 and self.interventions / self.n_users <= self.gamma_u

    def verify_validity(self) -> bool:
        return self.drift_score <= self.drift_max

    def verify_all(self) -> bool:
        return (self.verify_task_success()
                and self.verify_trust_calibration()
                and self.verify_usability()
                and self.verify_interventions()
                and self.verify_validity())

    @staticmethod
    def min_sample_size(alpha_u: float, delta: float, expected_fail: int = 0) -> int:
        """零失败场景下保证 p_L≥1-α_u 所需 n：δ^(1/n) ≤ 1-α_u → n≥lnδ/ln(1-α_u)"""
        import math
        if expected_fail == 0:
            return math.ceil(math.log(delta) / math.log(1 - alpha_u))
        return math.ceil((expected_fail + 1) / alpha_u)  # 粗略下界，精确用 CP 反解


# ============================================================
# IP-450 NLU-USC 自然语言-用户统一准入门（九证一体）
# ============================================================
@dataclass
class NaturalLanguageUserUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'   # v25 七证
    nlic: NaturalLanguageInstructionCertificate
    utc: UserTestingCertificate
    utc_issued_at: float = 0.0

    def admits(self, plan: 'Trajectory', nl_input: 'NLInput',
               now: float, **src_args) -> bool:
        # 1. v25 七证（结构/力控/轻量/语义/重构/协同）
        if not self.src_usc.admits(**src_args):
            return False
        # 2. NLIC 每条指令在线验证（覆盖/歧义/接地/全解释鲁棒）
        if not self.nlic.verify_all(
                plan, nl_input.mentions, nl_input.entities, nl_input.dialogue):
            return False
        # 3. UTC 部署级许可：有效期 + 分布未漂移 + 统计下界
        if now - self.utc_issued_at > self.utc.T_valid:
            return False
        if not self.utc.verify_all():
            return False
        return True

# 端到端流水线：v25 多机环 + 语言/用户前置门
# ============================================================
class LanguageUserGatedPipeline:
    def __init__(self, config: dict):
        self.nlu_usc = NaturalLanguageUserUnifiedCertificate(
            src_usc=config['src_usc'],
            nlic=NaturalLanguageInstructionCertificate(
                instruction="", parser=config['parser'],
                alpha_nl=config['alpha_nl'], eps_amb=config['eps_amb'],
                alpha_g=config['alpha_g'], rho_min=config['rho_min'],
                spec_metric=config['spec_metric']),
            utc=config['utc'],
            utc_issued_at=config['utc_issued_at'])
        self.ipam.register_module("nlic", ["IP-448"],
            ["conformal_spec_coverage", "ambiguity_diameter",
             "referential_grounding", "all_interpretation_robustness"])
        self.ipam.register_module("utc", ["IP-449"],
            ["clopper_pearson_success", "trust_calibration",
             "sus_lower_bound", "intervention_rate", "deployment_validity"])
        self.ipam.register_module("nlu_usc", ["IP-450"],
            ["nine_certificate_gate", "language_user_monotonic_chain"])

    def step(self, nl_input: 'NLInput', multi_sensor_data: dict,
             now: float, cloud_update=None) -> tuple[bool, dict]:
        # 0. 解析指令 → 预测规格集 C(ℓ)（歧义未决则先澄清，不进入执行）
        self.nlu_usc.nlic.instruction = nl_input.text
        C = self.nlu_usc.nlic.parser.predict_set(nl_input.text)
        if self.nlu_usc.nlic.ambiguity_diameter(C) > self.nlu_usc.nlic.eps_amb:
            return False, {'stage': 'clarification_required',
                           'candidates': C, 'question': nl_input.clarify_question}

        # 1. v25 七证多机环（并行）
        plan = multi_sensor_data['plan']
        admitted = self.nlu_usc.admits(
            plan, nl_input, now,
            multi_plan=multi_sensor_data['multi_plan'],
            sensor_data=multi_sensor_data,
            gt_entities=multi_sensor_data.get('gt_entities'),
            queries=multi_sensor_data.get('queries'),
            retrieved=multi_sensor_data.get('retrieved'))

        return admitted, {
            'spec_set': C,
            'spec_coverage_ok': self.nlu_usc.nlic.verify_spec_coverage(
                multi_sensor_data['nl_holdout']),
            'grounding_ok': self.nlu_usc.nlic.verify_grounding(
                nl_input.mentions, nl_input.entities),
            'ambiguity_ok': self.nlu_usc.nlic.verify_ambiguity(
                C, nl_input.dialogue),
            'robustness_ok': self.nlu_usc.nlic.verify_plan_robustness(plan, C),
            'user': {
                'task_success_lb': self.nlu_usc.utc.cp_lower(),
                'trust_ok': self.nlu_usc.utc.verify_trust_calibration(),
                'usability_ok': self.nlu_usc.utc.verify_usability(),
                'intervention_ok': self.nlu_usc.utc.verify_interventions(),
                'validity_ok': self.nlu_usc.utc.verify_validity(),
            }
        }


# ---------------- 辅助函数 ----------------
def stl_robustness(plan: 'Trajectory', phi: 'Spec') -> float:
    """STL 鲁棒度：min over 时间窗，负值表示违反（生产用 stlpy/RTAMT）"""
    return phi.robustness(plan)

def clopper_pearson_lower(k: int, n: int, delta: float) -> float:
    if n <= 0 or k <= 0:
        return 0.0
    from scipy.stats import beta
    return float(beta.ppf(delta, k, n - k + 1))

def one_sided_t_lower(xs: list[float], delta: float) -> float:
    import math
    from scipy.stats import t
    n = len(xs)
    if n < 2:
        return float('-inf')
    m = sum(xs) / n
    s = math.sqrt(sum((x - m) ** 2 for x in xs) / (n - 1))
    return m - float(t.ppf(1 - delta, n - 1)) * s / math.sqrt(n)
```

## 2. 复杂度分析（增量）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |

**部署级/在线分离**：NLIC 覆盖校准与 UTC 全部统计检验为**离线/部署级**（O(n) 一次性，秒级），在线仅执行固定阈值比较与鲁棒度计算；因此 20ms 多机控制环不被污染，语言门的额外开销只落在「新指令到达」的规划频率（≤2Hz）。

## 3. 正确性论证（增量）

### 引理 13（NLIC 的覆盖-歧义-接地-鲁棒四重保证）
**陈述**：设指令-规格对 (ℓ, φ*) 与校准集可交换。若 `NLIC.verify_all(...)=True`，则
(1) 以概率 ≥1-α_nl 有 φ*∈C(ℓ)（conformal 边际覆盖）；
(2) 执行时歧义直径 diam(C(ℓ))≤ε_amb，或经至多 R 轮澄清后单调收缩至阈值内；
(3) 所有指称以概率 ≥1-α_g 接地到真实语义实体；
(4) 计划 π 满足 min_{φ∈C(ℓ)}ρ_φ(π)≥ρ_min。

**证明**：
1. 由 split-conformal 的交换性假设与分位数构造，ℙ(φ*∈C(ℓ))≥1-α_nl（Vovk et al. 2005）；`verify_spec_coverage` 用留出集 CP 下界复核，防止小样本经验覆盖虚高。
2. `verify_ambiguity` 显式检查直径，且澄清每轮要求 `cur ≤ prev·1.05` 并最终 ≤ε_amb，否则拒证转人工；这排除了「无限澄清」与「越澄清越模糊」。
3. 指称接地复用 v25 SMC 的语义实体与开放词汇检索，`verify_grounding` 逐 mention 检查 e*∈G(m)，其覆盖由 α_g 的 conformal 校准保证。
4. 关键一步：鲁棒度对 C 取**最小值**（全解释鲁棒），故即使 φ* 只是 C 中之一，只要 (1) 成立，ρ_{φ*}(π) ≥ min_{φ∈C}ρ_φ(π) ≥ ρ_min，即计划对真实意图亦鲁棒。
∎

### 引理 14（UTC 的分布无关有限样本保证）
**陈述**：若 n 个用户为总体 U 的 i.i.d. 样本、任务成功为 Bernoulli(p)，则
(1) `verify_task_success` 为真 ⟹ 以置信度 1-δ 有 p≥1-α_u；
(2) 零失败时所需样本量 n≥lnδ/ln(1-α_u)（如 α_u=0.1, δ=0.05 ⟹ n≥29）；
(3) 信任校准、SUS 下界、接管率均为相应统计量的单侧下界/上界，控制 I 类错误 ≤δ。

**证明**：
1. Clopper–Pearson 下界 p_L=Beta_{δ}(k, n-k+1) 是精确的保守下界，覆盖概率 ≥1-δ，不依赖正态近似。
2. 令 k=0，则 p_L>0 当且仅当 (1-α_u)^n≤δ，取对数即得 n≥lnδ/ln(1-α_u)。
3. `one_sided_t_lower` 为 SUS 均值的单侧 t 下界；`verify_trust_calibration` 同时惩罚平均误差与过度信任方向（automation bias 的危险侧）；`verify_interventions` 为比例上界。各项独立检验用 Bonferroni 将 δ 分摊即可保持族错误率 ≤δ。
∎

### 引理 15（九证单调退化链延伸）
**陈述**：任意单点/组合失效下，`Exec_v26 ⊆ Exec_v25 ⊆ ... ⊆ Exec_v18` 恒成立。

**证明**：在引理 12 基础上增加两条路径：
- 语义误解/规格未覆盖/歧义未收敛/接地失败 → `NLIC.verify_all=false` → `NLU-USC` 拒证 → 退回 `Exec_v25`：仅执行「已形式化且人工确认」的旧任务集，自然语言入口关闭，物理/语义/协同安全不受影响。
- 用户不接受/信任失准/可用性不达标/接管率超限/UTC 过期或漂移 → `UTC.verify_all=false` → `NLU-USC` 拒证 → 退回 `Exec_v25`：系统降级为「专家监督模式」，用户测试重新校准后方可再开语言门。
- 组合失效取交集，`Exec_v26` 只减不增，单调性保持。
∎

### 定理（NLU-USC 九证准入门的安全-合规-可部署-可保护-结构-语义-重构-协同-语言-用户完备性）
**陈述**：对任意计划 π 与指令 ℓ，`NLU-USC.admits(π,ℓ)=True` ⟹ π 同时满足 v25 的十项条件（物理安全、版本一致、适应覆盖、专利保护、结构/力控/轻量、语义/重构/协同）**以及** (11) 语言规格覆盖、歧义受控、指称接地、全解释鲁棒；(12) 用户总体成功率、信任校准、可用性、接管率、部署有效性达标。反向（必要性）在交换性与 i.i.d. 假设成立时以概率 ≥1-(α_nl+α_g+α_u) 成立。

**证明**：`admits` 为 v25 十条件与 NLIC/UTC 的连言；充分性由引理 13–15 直接得到。必要性依赖统计假设：若某条件实际不成立而检验通过，则违反对应引理的覆盖/置信保证，其概率被 α_nl、α_g、α_u、δ 控制；假设被破坏（分布漂移）时必要性不成立——这正是风险 R16/R17 的来源。
∎

## 6. 本轮最大风险（最终确认）

**一句话**：**NLIC 的 conformal 规格覆盖在组合新颖/对抗性自然语言下失去交换性、UTC 的统计下界只对抽样用户总体成立且可被测试过拟合，「全解释鲁棒」又把九证门压向空集——三者叠加时，系统可能以「已认证」的姿态执行一个形式合法却语义错误的计划，即证书覆盖了错误的规格；这比 v25 的任何物理失效都更隐蔽，因为它骗过的是「意图」而非「执行」。**
