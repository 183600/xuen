# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「状态机」×「多模态交互」）

> 第 57 轮把"证据说可信"推进到参数层：元先验可摊销、模态可对账、人可单向有界地赢得信任。但它仍把每一次接触看成**一次独立的布尔判断**——"这个接触安全吗？"——并用证据门在检查点上逐点放行。它默认了两件未被检验的事：**(a)** 系统没有需要跨检查点保持、审计和恢复的**交互状态**（模式、同意、证据版本、指代对象）；只要每个点都过门，轨迹自然安全。**(b)** 多模态被理解为"对同一个表面信念的融合"，而不是"人机之间异步、异构、带指代的通道"。真实交互里，"好"可能指向另一件事，"同意"可能在状态已迁移后才到达，一个旧版本的确认可以授权一个全新的动作。于是留下两个新盲点：**(a) 状态盲区**——证据都合格，但系统处在错误的交互模式里（驾驶舱经典的 mode confusion）；坏的不是某一步，而是整条轨迹。**(b) 指代/时序错位**——多通道表决看似一致，实则说的是不同对象、不同版本；一致性是假的，共因是真的。本轮两个灵感合流为一条更完整的命题：**承诺不是一个判断，而是一次受守卫的状态迁移；交互安全不是点安全，而是轨迹不变量；多模态交互不是投票，而是带版本与指代绑定的同步**。核心命题由"证据说可信"升级为 **"状态可认证、指代可绑定、同步可证明的交互说可信"**。

核心矛盾：
- **H29（不变量 vs 活性）**：把安全写成状态不变量后，最省事的实现是"永不进入执行态"——不变量完美保持，系统彻底无用。安全不变式必须与"在可容许条件下有界前进"同时成立，否则认证的只是一个死系统。
- **H30（同步屏障 vs 实时控制）**：多模态确认需要等各通道对齐到同一状态版本，但控制回路有硬截止期；等，可能错过时机；不等，可能拿旧状态授权新动作。屏障窗口必须只覆盖不可逆迁移，且能被安全监视器抢占。
- **H31（冗余 vs 独立）**：通道越多不等于证据越多。同一条语音被转写两次、点头与"好"同源于一次社交顺从，都是共因；多数表决会把一个错误放大成"法定人数"。而且安全是不对称的：负证据应一票否决，正证据才需要法定人数与物理通道。
- **H32（显式状态机 vs 开放世界）**：显式拓扑可验证，却可能遗漏真实世界的模式；default-deny 会死锁，随手加一条"逃生迁移"又会变成无守卫后门。运行时不变量监视只能证明"没有离开模型"，不能证明"模型覆盖世界"。

## 0. 直觉与动机

**灵感 1（状态机 → 承诺是一次迁移，安全是轨迹不变量）**
直觉：第 57 轮像在每个路口设一个安检门；本轮改成给整条线路画一张**认证状态图**。系统不再回答"能不能接触"，而是回答"当前处在哪个状态、哪些迁移此刻合法、迁移后是否仍满足不变量"。好处有三：其一，把散落在各检查点的条件（物理包络、证据类、同意、操作者授权、预算）统一成**迁移守卫**，安全从"每个点都碰巧对"变成"每条轨迹都可归纳"；其二，把驾驶舱式的 **mode confusion** 显式建模——人和机器对"现在是什么模式"可以有分歧，而这本身就是需要监视的不变量；其三，恢复有了合法路径：不靠临时补丁，而靠一条显式的、需要重新认证的 Recover 迁移。关键设计是**拓扑固定并离线认证，只有守卫阈值可经隔离区更新**——绝不让系统"学会"一条绕过安全的新边。

**灵感 2（多模态交互 → 带版本与指代的绑定，而不是多数表决）**
直觉：多模态交互的真正难点不是"信息不够"，而是"信息对不上"：语音说"可以"，手势指的是另一块地面，目光还停在上一帧，旧版本的确认在状态迁移后才到。于是每个通道发言都携带 **(状态号, 版本号, 指代对象, 命题, 时戳, 通道可靠性/错误模型)**；只有绑定到**当前状态、当前版本、当前指代**的原子才被计入。由此得到三条不对称规则：**负证据一票否决**（任一高可靠通道报告不安全即阻断），**正证据需法定人数 + 独立性 + 至少一个物理通道**（纯语言永远不能单独授权），**版本一漂移即作废**。特别地，同意被设计成一次**比较交换（CAS）**：只有对当前 `(state_id, ver, action_id)` 的同意才生效，状态一升级，旧同意自动失效——这直接堵死"旧授权授权新动作"。

**灵感 3（合流 → 认证交互状态机 + 多模态状态绑定 + 同步屏障）**
直觉：把灵感 1 的状态图与灵感 2 的绑定原子接起来，就得到本轮主轴 **CISM**：迁移守卫里多一项 `g_bind`（绑定谓词），不可逆迁移前多一道 **SLB 同步屏障**（在 τ_sync 内把关键通道对齐到同一版本并完成绑定），运行时多一个 **RIM 不变量监视器**（任何不变量破坏、守卫不可判定、未建模事件都触发故障迁移到 SafeStop，而不是被静默忽略）。状态机负责"哪些事合法"，绑定负责"大家说的是不是同一件事"，屏障负责"新旧状态不会串台"。

**灵感 4（与第 57 轮接口 → 证据门降级为守卫，跨模态升级为交互绑定）**
直觉：第 57 轮的 FSE 证据门不再是独立函数，而是 `g_ev`；XMC 的物理表面分账只在 `g_ev` 内部继续负责"表面信念"，而 MSB 负责"交互状态/指代"——两者正交复合：物理上一致不等于交互上指同一对象，反之亦然。PTM 的操作者 `auth` 继续作为 `g_human` 的输入；MXI 的解释内容增加"当前状态/版本/哪些迁移被哪条守卫挡住"，并与 SLB 共用版本戳，避免"解释的是旧状态、执行的是新状态"。

**灵感 5（PCE⋆ → 从"要不要承诺"变成"走哪条迁移"）**
直觉：第 57 轮的 PCE+ 在检查点问"能否承诺"；本轮改为在状态图上枚举**当前可执行迁移集** `E(s)`，用 VOI 在迁移间做选择，对不可逆迁移先预取（pre-arm）通道原子以隐藏屏障时延，再执行 entry/exit 动作并交给 RIM。若 `E(s)=∅`，不是"拒绝"了事，而是进入显式的 Recover 分支：补探针 → 重新协商同意 → 绕行 → SafeStop，每一步都是迁移而非特判。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（认证交互状态机 CISM）** 交互状态机 ℐ=(S,s₀,→,G,I,Σ,Act,h)：S 为状态集（基本态 B={Idle,Observe,Probe,Reconcile,Propose,AwaitConsent,Commit,Execute,Monitor,Recover,SafeStop}，并含执行/证据/同意/交互四个正交区域，全局态 s=(s_exec,s_ev,s_cons,s_int)∈∏S_i）；→⊆S×S 为迁移；迁移 t=(s,g,a,s′) 的守卫 `g_t = g_phys ∧ g_ev ∧ g_cons ∧ g_bind ∧ g_human ∧ g_budget`，动作 a∈Act 含 entry/exit；I:S→2^Pred 为状态不变量；h=Hash(→) 为拓扑指纹。**承诺即迁移**：进入 Commit/Execute 是一次迁移事件，而非布尔谓词。安全定义：轨迹 σ=s₀s₁… 可容许 ⇔ ∀i Inv(s_i) ∧ 每次迁移执行时守卫为真；不可逆迁移集 →_irr 还须过 SLB。**拓扑不可变约束**：只允许阈值/证据参数经隔离区（第 57 轮"判定器走隔离"）更新，`h` 变更必须重新离线认证（可达性 + 不变量归纳 + 无未守卫的 →_irr）。

**定义 140（多模态状态绑定 MSB）** 通道集 C=C_phys∪C_human∪C_lang（视觉/触探/本体/声学；语音/手势/触摸/目光/按钮；文本），通道原子 `α=(c,sid,ver,ref,φ,t,ρ_c,ε_c)`。绑定谓词 `bind(α,s) ⇔ sid=s.id ∧ ver=s.ver ∧ ref∈Ref(s) ∧ t∈[now−τ_stale(c),now] ∧ ¬stale(ver)`。命题 φ 的支持集/反对集 `A_φ={α: bind ∧ φ_α=φ}`。**不对称法定人数**：(V) 若 ∃α∈A_{¬φ} 且 ρ_c≥ρ_veto 且绑定有效 ⇒ φ 被否决（负证据一票否决）；(P) φ 可被采信 ⇔ |A_φ|≥q(φ) ∧ div(A_φ)≥d(φ) ∧ A_φ∩C_phys≠∅（正证据需人数、独立性、物理通道）；(C) A_φ 与 A_{¬φ} 同时非空 ⇒ 进入 Reconcile（不是多数表决）。div 按物理来源的独立类计数（同一句话的 ASR 与文本、点头与"好"若同源只算一类）。

**定义 141（同步屏障 SLB）** 对 t∈→_irr，屏障 B_t=(C_crit,τ_sync,q,d)：①**预取**（迁移被 VOI 预判时提前广播状态版本并收集原子）；②**版本钉扎**：在 [t₀,t₀+τ_sync] 内冻结 `s.ver`（安全故障迁移优先级更高，可随时抢占）；③**成功条件**：所有 c∈C_crit 在窗口内提交 bind 有效原子 ∧ 按 MSB 达成 φ ∧ 窗口内版本未漂移；④**失败处理**：可恢复则强制迁移到 Reconcile，否则迁移到 SafeStop，**绝不迁移到 Commit/Execute**。屏障失败与超时本质上等价于"没有取得对当前版本的同意"。

**定义 142（运行时状态不变量监视 RIM）** 不变量集 `I={I_env(物理包络), I_ev(证据充分), I_cons(同意 CAS 有效), I_bind(指代/版本一致), I_budget, I_lease}`。监视器在每控制拍与每个事件 e 上求值：`fault ⇔ ¬Inv(s) ∨ ¬decidable(g_t) ∨ (e 未被任何启用迁移消费)`。**无静默态**：任一故障触发全域故障迁移 `𝔣:S→SafeStop` 并锁存，记入 fault_log；守卫不可判定一律按假处理（default-deny），但必须登记为 fault 而非"静默拒绝"，以便在 Recover 中显式处理。`I_cons` 的同意采用 CAS：`valid_consent(action,s) ⇔ consent.action=action ∧ consent.sid=s.id ∧ consent.ver=s.ver`。

**定义 143（状态可读解释与命令落地 SGI）** 人对系统的信念态为 Ĩ_h，**模式混淆度** `Mconf=TV(P_h(s|state), δ_{s})`（人以为的当前状态与真实状态之差）。解释内容 `Exp_s=(s.id,s.ver, 进入原因(守卫+证据), 当前阻塞守卫, 允许迁移集 E(s) 及各自代价, 什么输入会改变状态, 违反的约束与建议)`；渲染模态按第 57 轮 MXI 个性化，但**版本戳与 SLB 共用**：解释送达时若 `s.ver` 已变，必须标记过期并重渲染。**命令落地**：任意多模态命令 m 先解析为"提议迁移" `π(m)`；接受 ⇔ `π(m)∈→ ∧ g_{π(m)} 可满足 ∧ bind ∧ valid_consent`，否则拒绝并返回 Exp_s。**可读性** `L=P(人正确预测下一状态)`，作为被度量与优化的对象。

**定义 144（PCE⋆ 与状态证书 J_s）** 每个控制拍：①取 `E(s)={t: g_t 可判定且为真}`；②若 `E(s)=∅` → Recover 分支（补探针/重协商/绕行/SafeStop）；③否则在 E(s) 上选 `argmax_t[VOI(t|s)−cost(t)]`，不可逆迁移先预取再执行 SLB；④执行 entry/exit 动作，迁移 `s←s′`，交由 RIM 持续监视。终止性：单拍迁移数有限，Probe/Reconcile 受 `k_probes+k_cons` 约束，Recover 无进展即 SafeStop。状态证书 `J_s=(h, state_trace, guard_evals, invariant_checks, binding_records, consent_CAS, barrier_records, fault_log, explanation_log, ver)`，继承第 57 轮 J_p 全部检查。

## 2. 关键算法伪代码（完整版见产物区）

```python
def cism_step(s, e, M, persona, budget):            # IP-139/140/141/142 合流
    if fault(s, e):                                  # RIM：无静默态
        return fault_transition(s, e)                # 锁存 → SafeStop/Recover
    E = [t for t in transitions(s) if decidable(t.g) and eval_guard(t.g, s, M, persona)]
    if not E:
        return recover_or_stop(s, M, budget)         # 显式 Recover 迁移
    t = argmax(E, key=lambda t: voi(t, s) - cost(t))
    if t in irreversible:
        s2, ok = sync_barrier(t, s, M)               # SLB：版本钉扎 + 绑定
        if not ok:
            return transition(s, Reconcile if recoverable(s) else SafeStop)
    s2 = run_actions(t, s)                           # entry/exit
    return transition(s2, t.dst)

def bind_and_quorum(rho, atoms, s, phi):             # MSB：不对称法定人数
    A  = [a for a in atoms if bind(a, s) and a.phi == phi]
    N  = [a for a in atoms if bind(a, s) and a.phi == not phi]
    if any(a.rho >= rho.veto for a in N): return ('veto', N)      # 负证据一票否决
    if len(A) >= q(phi) and diversity(A) >= d(phi) and has_phys(A):
        return ('accept', A)
    if A and N: return ('reconcile', (A, N))
    return ('insufficient', A)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| CISM | O(|→|) 每拍（查表 O(1)） | O(|S|+|→|) 静态 | 拓扑指纹、→_irr 全守卫、离线归纳 |
| MSB | O(|C|·d_α) 每事件 | O(|C|) | 绑定谓词完备、通道错误模型诚实、独立性类正确 |
| SLB | O(|C_crit|·τ_sync/Δt) | O(|C_crit|) | 版本钉扎、故障迁移可抢占、窗口有界 |
| RIM | O(|I|) 每拍 | O(1) | 无静默态、守卫可判定、故障锁存 |
| SGI | O(1)+O(|E(s)|) | O(|Exp|) | 解释版本戳、命令只经迁移落地 |
| PCE⋆ | O(|S|·|→|·(C_VOI+d_α)) | O(|V|+|σ|) | E(s) 枚举完备、Recover 有界、终止 |

**正确性定理（状态-绑定交互健全性 SBIS 概要）**：在 A33–A40 上加 **(A41)** 拓扑健全：离线认证覆盖所有可达态与不变量，→_irr 无未守卫边，拓扑变更必重认证；**(A42)** 绑定与通道错误模型诚实，独立性类不虚报；**(A43)** 屏障时序正确（版本钉扎、τ_sync 有界、故障可抢占）；**(A44)** 监视器完备（无静默态、守卫可判定）；**(A45)** 命令仅经迁移落地且解释版本一致。则：(i) **不变量保持**：任何可执行轨迹恒满足 I；(ii) **不可逆迁移健全**：P(无有效证据/同意/屏障却进入 Execute_irr) ≤ δ_ev+δ_cons+δ_bind+δ_barrier；(iii) **陈旧性隔离**：版本漂移或指代错配的原子不可能进入 →_irr 的守卫（由绑定 + 版本钉扎保证）；(iv) **无静默态 + 有界活性**：在可容许条件下有界前进，否则有界到达 SafeStop；(v) **命令健全**：任何被接受的人机命令对应一条真实迁移，任何未建模命令被显式拒绝。

## 6. 本轮最大风险

**一句话**：状态机给出的是"模型内"的归纳保证——若拓扑与守卫本身遗漏了真实世界的模式，不变量监视只会一遍遍证明"我们从未离开模型"，而 default-deny 要么把系统锁死、要么被一条临时逃生迁移变成无守卫后门；同时多模态法定人数可能被共因通道（同一句话/同一传感器/同一次社交顺从）满足，于是屏障认证的是"大家都同意"，而不是"大家同意的是对的"——认证状态机与绑定法定人数都必须以拓扑重认证、独立性审计和负证据否决为前提，否则只是把不安全从"点"搬到了"轨迹"。

### IP-139 CISM（认证交互状态机）

```python
IRREV = {('Commit', 'Execute_irr'), ('Execute', 'Recover_high_risk'), ...}
STATES = ['Idle','Observe','Probe','Reconcile','Propose','AwaitConsent',
          'Commit','Execute','Monitor','Recover','SafeStop']

def enabled_transitions(s, M, persona):
    E = []
    for t in TRANS[s.id]:                          # 静态拓扑查表 O(1)
        if not decidable(t.guard, s, M):           # 守卫必须可判定
            register_pending(t); continue          # 不静默，登记待定
        if eval_guard(t.guard, s, M, persona):     # 六项合取
            E.append(t)
    return E

def cism_step(s, e, M, persona, budget):
    if rim_fault(s, e, M):                         # IP-142：故障可抢占一切
        return fault_transition(s, e)              # 锁存 → SafeStop / Recover
    E = enabled_transitions(s, M, persona)
    if not E:
        return recover_or_stop(s, M, budget)       # 显式 Recover 迁移，非特判
    t = argmax(E, key=lambda t: voi(t, s) - cost(t))
    if (s.id, t.dst) in IRREV:
        s, ok = sync_barrier(t, s, M)              # IP-141
        if not ok:
            return transition(s, 'Reconcile' if recoverable(s) else 'SafeStop')
    s = run_actions(t, s)                          # entry/exit；迁移后 ver += 1
    return transition(s, t.dst)
```

### IP-140 MSB（多模态状态绑定与不对称法定人数）

```python
def channel_atom(c, s, ref, phi, payload, err):
    return Atom(c=c, sid=s.id, ver=s.ver, ref=ref, phi=phi,
                t=now(), rho=RHO[c], eps=ERR[c])

def bind(atom, s):
    return (atom.sid == s.id
            and atom.ver == s.ver                  # 版本必须当前
            and atom.ref in Ref(s)                 # 指代必须当前对象
            and now() - atom.t <= TAU_STALE[atom.c])

def quorum(atoms, s, phi, cfg):
    A = [a for a in atoms if bind(a, s) and a.phi == phi]
    N = [a for a in atoms if bind(a, s) and a.phi == neg(phi)]
    if any(a.rho >= cfg.rho_veto for a in N):       # (V) 负证据一票否决
        return ('veto', N)
    if (len(A) >= cfg.q[phi] and div(A) >= cfg.d[phi]
            and any(a.c in C_PHYS for a in A)):     # (P) 人数+独立+物理通道
        return ('accept', A)
    if A and N:                                     # (C) 冲突不做多数表决
        return ('reconcile', (A, N))
    return ('insufficient', A)

def div(atoms):                                     # 独立性类，而非通道数
    return len({origin_class(a.c) for a in atoms})  # ASR+文本同源 → 一类
```

### IP-141 SLB（同步屏障）

```python
def sync_barrier(t, s, M):
    ver0 = s.ver
    s.pin = True                                    # 版本钉扎
    atoms = prearmed_atoms(s)                       # 预取（VOI 已预判时）
    atoms += broadcast_and_collect(t.critical_channels, s, tau_sync=TAU_SYNC)
    ok = (now() <= t.t0 + TAU_SYNC
          and s.ver == ver0                          # 窗口内版本未漂移
          and quorum(atoms, s, t.phi, barrier_cfg)[0] == 'accept')
    s.pin = False
    if not ok:
        M.audit.log(('barrier_fail', t, now(), ver0, s.ver))
        return s, False                             # 绝不进入 Commit/Execute
    return s, True

def prearm_barrier(s, E, M):                        # 在非关键路径提前广播
    for t in E:
        if (s.id, t.dst) in IRREV and t.anticipated:
            broadcast_version_and_ref(s); collect_async(t.critical_channels)
```

### IP-142 RIM（运行时状态不变量监视）

```python
def rim_fault(s, e, M):
    if any(not inv(s) for inv in INVARIANTS):       # I_env/I_ev/I_cons/I_bind/...
        return Fault('invariant', which_inv(s))
    E = enabled_transitions(s, M, persona=None)
    if not any(consumes(t, e) for t in E):
        return Fault('unhandled_event', e)          # 无静默态
    if any(not decidable(t.guard, s, M) for t in TRANS[s.id]):
        return Fault('undecidable_guard', e)        # 不可判定 ≠ 静默忽略
    return None

def valid_consent(action, s):                       # 同意 = 对状态版本做 CAS
    c = CONSENT[action]
    return c is not None and c.sid == s.id and c.ver == s.ver

def fault_transition(s, e):                         # 全域、锁存、可审计
    s.fault = e; s.latched = True
    return transition(s, 'SafeStop' if not recoverable(s) else 'Recover')
```

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CISM | O(\|→\|) 每拍；查表 O(1) | O(\|S\|+\|→\|) 静态 | 拓扑指纹、→_irr 全守卫、离线归纳（A41） |
| MSB | O(\|C\|·d_α) 每事件 | O(\|C\|) | 绑定完备、错误模型诚实、独立性类正确（A42） |
| SLB | O(\|C_crit\|·τ_sync/Δt) | O(\|C_crit\|) | 版本钉扎、故障抢占、窗口有界（A43） |
| RIM | O(\|I\|) 每拍 | O(1) | 无静默态、守卫可判定、故障锁存（A44） |
| SGI | O(1)+O(\|E(s)\|) | O(\|Exp\|) | 解释版本戳、命令只经迁移（A45） |
| PCE⋆ | O(\|S\|·\|→\|·(C_VOI+d_α)) | O(\|V\|+\|σ\|) | E(s) 完备、Recover 有界、终止 |

**正确性定理（State-Binding Interaction Soundness, SBIS）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；**(A41)** 拓扑健全：离线认证覆盖所有可达态与不变量，→_irr 无未守卫边，拓扑变更必须重认证并更新 h；**(A42)** 绑定与通道错误模型诚实，独立性类不虚报；**(A43)** 屏障时序正确：版本钉扎有效、τ_sync 有界、故障迁移可抢占；**(A44)** 监视器完备：无静默态、守卫可判定、故障锁存；**(A45)** 命令仅经迁移落地且解释版本一致。则：

1. **不变量保持**：任何可执行轨迹 σ 恒满足 `∀i Inv(s_i)`；状态迁移不会把系统带入不满足 I 的态（guard 含 `Inv(s′)` 检查）。
2. **不可逆迁移健全**：`P(进入 Execute_irr 却无有效证据/同意/屏障) ≤ δ_ev + δ_cons + δ_bind + δ_barrier`。
3. **陈旧性隔离**：任何进入 →_irr 守卫的通道原子必满足 `bind`；窗口内 `ver` 被钉扎，故版本漂移与指代错配的原子不能授权不可逆动作；贡献 ≤ δ_bind。
4. **无静默态与有界活性**：任何不变量破坏、未建模事件或不可判定守卫都触发锁存故障迁移；在可容许条件 A_prog（存在守卫可满足的启用迁移且在预算内）下，系统有界前进，否则有界到达 SafeStop。
5. **命令健全**：任何被接受的人机命令对应一条真实迁移；任何未建模/陈旧/指代错配的命令被显式拒绝并返回状态化解释。

**部署界**（对不可逆迁移取联合界）：

```
P_safe ≥ 1 − Σ_{t∈→_irr} (δ_ev + δ_cons + δ_bind + δ_barrier + δ_inv)
             − P(拓扑覆盖失配) − P(共因假法定人数) − P(监视器漏检) − P(解释/命令错位)
```

其中 `P(拓扑覆盖失配)` 由离线可达性认证与部署期拓扑指纹监视约束，`P(共因假法定人数)` 由独立性类 + 物理通道强制 + 负证据否决约束。关键：**状态机把"某一步错了"变成"轨迹不变量被破坏"**；**绑定把"大家说的不一致"与"大家说的是同一件事"分开**；**CAS 同意把同意钉到状态版本**；**同步屏障把异步通道的旧状态隔离在迁移之外**；四者串起来，才使"交互安全"成为可归纳、可审计、可恢复的性质。

云边协议 CEB++ → **CEB+++**：云端可下发**守卫阈值**（θ、q、d、ρ_veto、τ_sync）与通道可靠性/错误模型的增量更新，但**不得远程修改拓扑**；任何拓扑变更（新增状态/迁移）必须线下重新认证并签发新的拓扑指纹 h，边端只在 h 与认证记录匹配时接受新拓扑。所有更新先在影子模式运行（不变量零破坏 ∧ 故障检出率不降 ∧ 假法定人数率不升）后才接管；边端回传 binding/barrier/fault/解释日志，作为独立性审计、共因分析与拓扑补盲依据。第 57 轮"一切判定器走隔离"在本轮收紧为"**一切拓扑变更走离线重认证**"。

## 7. 本轮最大风险

**一句话**：状态机给出的是"模型内"的归纳保证——若拓扑与守卫本身遗漏了真实世界的模式，不变量监视只会一遍遍证明"我们从未离开模型"，而 default-deny 要么把系统锁死、要么被一条临时逃生迁移变成无守卫后门；同时多模态法定人数可能被共因通道（同一句话/同一传感器/同一次社交顺从）满足，于是屏障认证的是"大家都同意"，而不是"大家同意的是对的"——认证状态机与绑定法定人数都必须以拓扑重认证、独立性审计和负证据否决为前提，否则只是把不安全从"点"搬到了"轨迹"。
