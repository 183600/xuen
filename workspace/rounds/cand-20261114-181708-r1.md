# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~302；灵感循环第 1 轮；本轮灵感：「技能学习」×「交互设计」）

> R73 把「证据」做成了可组合、可审计、可热替换的契约，并用 IP-302 的因果证据图（ECG）与形态无关契约（MIC）收尾。但它把两样东西留在了契约之外：
> - **技能不在类型系统里**：ACH 产出的动作前缀被 certified_prefix 临时裁剪，技能本身没有契约、没有能力域、没有证书。学习（模仿 / RL / 在线微调）一旦发生，实现就在连续变化——而 R73 引理 35 的热替换定理要求「同契约 + 证书有效」，**学习恰恰是证书会失效的那种替换**。证书要么被假装永真（自欺），要么学习被禁止（放弃适应性），二者都不可接受。
> - **人类不在计量系统里**：人类目前只是 IRL 的意图观测源和 R71 的安全否决。但人类反馈是有偏、有噪、会疲劳、会漂移的**仪器**；把「人类说停」当成无条件安全真值，与把深度不确定度当成场景几何不确定度是**同型错误**。交互界面决定了你测到什么，交互设计因此首先是**测量设计**。
> - **组合不免费**：两个各自 95% 可靠的技能串起来不是 95%；A 的退出分布与 B 的进入分布不重合时，离线学到的 B 会在缝合处被分布位移击穿（offline-RL 的 stitching gap），这不是"不确定度相加"能表达的。R73 的组合代数记不确定度，不记**能力域与边界缝隙**。
>
> 本轮两个灵感正好补两块：
> - **技能学习** → **SCS（Skill Contract System）+ SCA（Skill Composition Algebra）+ CLG（Certified Learning Gate）**：技能 =（技能契约 SC，策略 π，证书 cert）；SC 显式声明能力域 K、校准能力下界 κ⁻、**学习通道 λ_L**、进入/退出分布、可逆性等级与回退技能。组合算子 SEQ/OPT/REC 给出「能力不可免费组合」引理与边界缝隙界；学习更新必须过漂移门，证书按 O(ε·H) **优雅退化且可回滚**。
> - **交互设计** → **IXM（Interaction-as-Metrology）+ CLP（Certificate Lifecycle Protocol）**：把示范 / 纠正 / 成对偏好 / 标量评分 / 语言指令 / 否决 / 延迟决策看成不同**仪器**，各有偏差-方差-成本；查询按单位人类成本的期望信息增益（EIG/C）选择；人类否决权按**校准后的人类能力**加权（能力外的人类输入只进偏好后验，不进安全否决）；证书有生命周期，漂移触发重教，教不动则退化到回退技能。
>
> 核心命题：**不再只问「证据能否组合」，而问「被学出来的能力能否携带证书、并在与人的交互中被持续保真？」** 把 R73 的计量契约代数推进为 **SKILLGAUGE-RAS**（Certified SKILL learning with Interaction-calibrated teaching and GAUGE audits）——**能力契约与教学计量**。

## 0. 直觉与动机

**灵感 1（技能学习 → 技能是带能力域的假设，学习是证书会失效的替换）**
直觉：一个学出来的抓取技能不是一段策略代码，而是「在某个状态分布上、由某次训练过程支撑的一个假设」。它在训练分布内可靠，走出分布不只是"误差变大"，而是**没有任何校准保证**。所以技能必须像传感器一样携带契约：能力域 K、合格能力估计 κ、进入/退出分布、可逆性等级、回退技能。更关键：R73 的热替换定理假设「同契约替换、证书仍有效」；但技能学习是在**同一模块内部**连续改变实现，证书正是会失效的那种东西。不能禁止学习（那等于放弃适应性），也不能假装证书永真（那是自欺），只能让学习走一条**有漂移预算、有影子验证、可回滚**的门。组合层面还有隐痛：A 的退出分布与 B 的进入分布不重合时，离线学到的 B 在缝合处会被分布位移击穿——这不是不确定度相加能表达的，需要显式的**边界缝隙预算**。

**灵感 2（交互设计 → 界面是仪器，人类反馈有校准曲线）**
直觉：同一个问题，用标量评分问、用成对比较问、让人类示范、让人类纠正，得到的不是同一种测量。标量评分压缩且受锚点影响；成对比较稳定但昂贵；示范信息量大但混入教师自身技能与习惯；纠正局部高价值但被动；语言指令组合性强但歧义；否决是二元安全信号，但人类会疲劳、会误判、会在能力外自信。交互设计因此是**测量设计**：选仪器、定查询、做校准、算单位成本的信息增益。人类否决也不能无条件当真值：在人类能力域内它是高权重的安全证据，在能力域外它只是偏好证据。否则系统会把"人类说停"误读成"确实不安全"——与把深度方差误读成场景几何方差同型。

**灵感 3（两灵感的交汇 → 教学闭环是一个会自我确证的认识论回路）**
直觉：机器人根据能力缺口提问 → 人类回答 → 机器人更新技能 → 新技能决定下一次提问。危险在于：**机器人问出的分布，正是它用来验证自己的分布**。教到会考（teaching to the test）不再只是数据泄漏，而是闭环结构性偏差。因此交互产生的分布位移必须被显式建模，校准必须**以查询策略为条件**（query-conditional coverage），并保留一条机器人永远不查询的隐藏保持集。

**定位**：R73 的 MODGAUGE 是 R74 在「零学习 + 零交互 + 满能力域」处的严格特例。本轮的创新不在模仿学习、偏好学习、conformal、safe RL 任何单项——这些都已成熟——而在**把"能力"与"教学"同时纳入计量契约**：能力域可审计、学习有漂移门、人类输入是校准仪器、否决权按能力加权、证书有生命周期，且组合定理在能力与边界层面继续成立。

## 1. 形式化定义（增量：定义 383–395）

**定义 383（SKILLGAUGE-RAS 总览）** SKILLGAUGE-RAS = (SCS, SCA, CLG, IXM, CLP, CPB†, MODGAUGE-RAS†)。六不变式：
(i) **技能契约完整性**：任何可学技能必须实例化 SC（定义 384），无契约者不入 SkillLibrary、不参与组合；
(ii) **能力单调性**：组合不得虚增能力（引理 38），SEQ 的能力下界随组件数与边界缝隙单调不增；
(iii) **学习门闭合**：任何策略更新在进入执行前必须通过 CLG（定义 390），漂移证书 ρ ≤ ε，且保留回滚检查点；
(iv) **交互校准**：每个人类输入通道必须有校准仪器模型（定义 388）；未校准通道只能作为偏好证据，不能作为安全证据；
(v) **否决权校准**：人类否决权按校准能力下界加权（定义 389）；安全否决非补偿；
(vi) **严格退化**：学习通道恒等 + 交互通道空 + 能力域全空间 ⇒ 逐指令等于 MODGAUGE（定理 30）；失效只退化到回退技能，安全侧只增不减。

**定义 384（技能契约 SC）** SC = (G, Pre, Post, K, κ⁻, λ_L, ι_I, R_rev, ∂_in/∂_out, fallback, cert_ref, W)：
- G：目标规范（时序逻辑 / 任务谓词）；Pre/Post：前/后置条件；
- K ⊆ X：**能力域**（声明支撑集）；κ⁻: X → [0,1]：**校准能力下界**（conformal 下界，而非点估计的自信度）；
- λ_L: Δπ ↦ (ρ, X_valid)：**学习通道**——部署期更新如何改变策略，以及更新在哪些状态上仍被认证覆盖（R73 χ_R 的行为对应物）；
- ι_I：**交互通道**——消费/请求哪些人类仪器，及其成本模型；
- R_rev ∈ {reversible, conditionally reversible, irreversible}：可逆性等级，决定 SEQ 的安全边际与 REC 的必要性；
- ∂_in/∂_out：进入/退出分布；fallback：能力外或门失败时的保守技能；cert_ref：SEAL-Skill 引用；W：时序/内存预算。

**定义 385（技能模块与技能库）** Skill = (SC, π, cert)，cert =（SEAL-Skill 报告，conformal 覆盖，能力地图 κ⁻，漂移日志，RTA 片段，版本哈希）。SkillLibrary 是带进入/退出分布标注的技能 DAG；选择器只能用 κ⁻ 而非 κ 的点估计。

**定义 386（SCA 技能组合代数）** 在 CCA（SER/PAR/VETO）之上增加：
- **SEQ-SKILL（A ; B）**：要求 Post_A ⇒ Pre_B（在边界分布上），δ_b(A,B) ≤ δ_max，K = K_A ∩ K_B ∩ 边界支撑；能力按引理 38 扣减；失败路由到 fallback；
- **OPT-SKILL（A ▷ B）**：按 κ⁻ × 期望进展选择；**选择器本身必须认证**（禁止在 K 外乐观选择）；
- **REC-SKILL（A ↺ R）**：R 必须在 A 的失败集上被认证；R_rev 决定安全边际；
- **PAR-SKILL / VETO-SKILL**：继承 CCA，额外校验资源预算 W 与不可逆动作的否决优先级。

**定义 387（边界缝合缝隙 δ_b）** δ_b(A,B) = sup_{φ∈Φ} |E_{P_A^exit}[φ] − E_{P_B^entry}[φ]|，其中 Φ 为校准特征族（等价于一定条件下的 TV/MMD）；契约要求 δ_b ≤ δ_max。它量化 offline-RL 的 stitching gap，是 SEQ 组合的唯一新增风险源。

**定义 388（交互仪器模型 IXM）** 对交互类型 u ∈ {示范, 纠正, 成对偏好, 标量评分, 语言指令, 否决, 延迟}，人类观测 f ~ p_h(f | s, u, θ_teacher, UI)。分量：u_amb（指令歧义）、u_demo（示教者技能/噪声）、u_attn（注意/疲劳）、u_drift（偏好漂移）、u_bias（界面锚定/拟人偏差）。在 SEAL-Human 上校准：可靠性图、ECE、覆盖率。信息增益 IG(u,s) = H(belief) − E_f[H(belief | f)]；成本 c_h(u,s)（时间 + 注意 + 信任）。查询选择 u* = argmax IG/c，s.t. 人类负担预算。

**定义 389（校准否决权）** w⁻(s) = 人类否决在 s 正确率的**校准下界**（来自 SEAL-Human 能力地图）。有效否决 = robot_safety_veto ∨ (human_veto ∧ w⁻(s) ≥ τ_h)。若 w⁻ < τ_h，人类输入进入**偏好后验**（只改任务目标），不进入安全否决；若人类否决落在其能力域外，触发解释/延迟请求而非自动停机（避免在危险态因误停造成二次风险）。在其权限内非补偿。

**定义 390（认证学习门 CLG）** 对候选更新 Δπ：①**影子**：在 SEAL-Skill、回放与隐藏保持集上评估，计算漂移证书 ρ(Δπ)（访问状态上的 KL + 能力下界变化 + 罕见安全态探测）；②**门控**：若 ρ ≤ ε_drift、影子安全违例为 0、κ⁻ 在 K 上不降、交互成本不升，则仅在 X_valid 上激活；③**晋升**：全量证书刷新 + 版本钉住；否则拒绝并回滚到上一检查点。**没有第四条通道**。

**定义 391（证书生命周期 CLP）** 证书带有效期/新鲜度，由环境漂移、策略漂移、人类仪器漂移三类检测器共同驱动。续期触发：漂移告警、κ⁻ < κ_min、交互校准 ECE > τ_h、SEAL 过期。续期通过 IXM 查询 + 重教；若在人类负担预算内无法续期，则**显式退化**到 fallback，禁止"证书沉默过期"。**可维护性条件**：单位时间环境漂移 < 单位时间可认证学习容量，否则不存在非平凡认证技能（定理 33）。

**定义 392（技能威胁面）** 示范投毒（后门示教）、奖励黑客（规范博弈）、教到会考（SEAL 过拟合）、人类疲劳攻击、偏好漂移操纵、能力域伪装、边界利用（在 B 的进入支撑外进入 B）。防线：影子门 + 隐藏保持集 + 单源不定案（继承 E356/E357）+ 边界审计 + 否决校准。

**定义 393（主张预算）** 活跃主张总数 ≤ 5；新增主张必须**退役或折叠**一条旧主张，或通过"可分离性审计"（独立消融 + 非冗余效应量）。这是一条防止创新点无限膨胀的元纪律——R71–R73 已有三主张，本轮最多新增两条。

**定义 394（技能证书代数 J_SKILL）** J_SKILL = ⊗_i J(skill_i) ⊗ J_SCA(SkillDAG) ⊗ J_CLG(学习日志) ⊗ J_IXM(交互校准) ⊗ J_comp。Valid(J_SKILL) ⇒ Valid(J_MOD)（R73 为其特例）。

**定义 395（形态无关技能契约 MIC-Skill）** SC 不依赖关节数/手指数/传感器阵列，只依赖目标类型、能力域谓词、学习通道结构与交互通道结构；换形态只需新实现 + 模块级重认证。这把 R73 的 MIC 从证据层延伸到技能层。

## 2. 关键算法骨架

```python
@dataclass(frozen=True)
class SkillContract:                      # 定义 384
    goal: GoalSpec; pre: Predicate; post: Predicate
    K: CompetenceRegion                   # 能力域
    kappa_lcb: Callable[[State], float]   # 校准能力下界 κ⁻（不是点估计）
    lam_L: LearningChannel                # Δπ ↦ (ρ, X_valid)
    iota_I: InteractionChannel            # 仪器类型 + 成本模型
    reversibility: str                    # reversible / conditional / irreversible
    entry_dist: Dist; exit_dist: Dist
    fallback: SkillRef; cert_ref: str; wcet_us: float

@dataclass
class Skill:
    sc: SkillContract; pi: Policy; cert: SkillCert

def seq(a: Skill, b: Skill) -> Skill:      # 定义 386 / 引理 38
    assert implies_on(a.sc.post, b.sc.pre, a.sc.exit_dist)
    d = boundary_gap(a.sc.exit_dist, b.sc.entry_dist)   # 定义 387
    assert d <= DELTA_MAX
    lo = 1.0 - a.cert.alpha - b.cert.alpha - d          # 能力不可免费组合
    return Skill(SC_SEQ(a.sc, b.sc), SeqPolicy(a.pi, b.pi),
                 CertSeq(alpha_lo=lo, boundary=d, fallback=first_fallback(a, b)))

def learning_gate(skill: Skill, delta_pi, replay, seal, hidden) -> GateResult:
    rho = drift_certificate(skill.pi, delta_pi, replay)  # 访问态 KL + 罕见安全态
    if rho > EPS_DRIFT: return REJECT
    sh = evaluate(apply(skill.pi, delta_pi), seal, hidden)  # 影子，不执行
    if sh.safety_violations > 0: return REJECT
    if sh.kappa_lcb < skill.cert.kappa_lcb - TOL: return REJECT
    if sh.interaction_cost > skill.sc.iota_I.budget: return REJECT
    return GATED(apply(skill.pi, delta_pi), rho,
                 valid_region=skill.sc.lam_L(delta_pi).X_valid,
                 rollback=checkpoint(skill))

def choose_query(belief, instruments, human_budget, teacher):
    best = None
    for u, s in candidate_queries(belief):
        ig = mutual_information(belief, u, s)            # EIG
        c  = instruments[u].cost(s, teacher)             # 人类成本
        if c <= human_budget.left and (best is None or ig / c > best.score):
            best = Query(u, s, ig / c)
    return best

def calibrated_veto(s, human_veto, robot_veto, calib):
    w = calib.human_competence_lcb(s)                     # 定义 389
    safety = robot_veto or (human_veto and w >= TAU_H)
    preference = human_veto and w < TAU_H                 # 只改目标，不改安全
    return safety, preference

# IP-308 SKILLGAUGE 主闭环（复用 R73 三域；新增技能/学习/交互三条契约化支路）
def SKILLGAUGE_round(M, obs, audio, tac_frame, depth_img, human):
    d_ev = M.dpe.update(depth_img, rgb, M.cam_state, M.motion, M.peers)  # R73 DPEM†
    d_ev = d_ev if d_ev.valid else stub(M.dpe)
    t_ev = M.dmem.update(tac_frame, M.last_action)

    # === 计量域：先选技能，再决定是否交互/学习 ===
    if M.clock.due_metric():
        b_t = M.bse.step_full(..., d_ev=d_ev, t_ev=t_ev)
        sk = M.lib.select(b_t, M.goal,
                          require=lambda s: s.sc.kappa_lcb(b_t) >= KAPPA_MIN)
        if sk is None:                                   # 能力外 → 保守回退
            return M.fallback.act(b_t)
        if M.clp.needs_renewal(sk, b_t):                 # 证书将过期
            q = choose_query(M.belief, M.instruments, M.human_budget, human)
            f = M.ui.ask(q); M.belief.update(f, q.u); M.clp.log(q, f)
            sk = M.lib.retrain_if_needed(sk, M.belief)
        if M.learner.has_update(sk):
            g = learning_gate(sk, M.learner.delta(sk), M.replay, M.seal, M.hidden)
            if g.ok: M.lib.replace(g.skill)              # 保留 rollback checkpoint
        veto, pref = calibrated_veto(b_t, human.veto, M.safety.veto(b_t), M.calib)
        if veto: return M.fallback.act(b_t)
        M.goal = M.goal.with_preference(pref)
        g_act = M.ervoi.choose(b_t, ..., sk=sk)          # R72 ERVOI†，技能内选动作
        M.snapshot.write(b_t, sk, g_act, M.belief)
        M.mreg.audit(); M.clp.audit_drift()

    # === 控制域：只读快照（继承 R73/R72）===
    snap = M.snapshot.read_latest()
    lam = embodied_risk_scale(snap.U_ale, snap.U_epi, snap.H_z, snap.skill.kappa, M.risk_params)
    A = snap.skill.propose(snap, lam); k = M.c_ras_wm.certified_prefix(A, lam)
    M.ctrl_out.publish(k, lam)
    return k, lam, J_SKILL(M.lib, M.clg_log, M.ixm_calib, M.mreg)
```

## 3. 推导

**引理 38（能力不可免费组合）** 设 A 在 K_A 上以成功率 ≥ 1−α_A 达成 Post_A，B 在其进入支撑上成功率 ≥ 1−α_B，边界 TV 距离 δ_b。则 SEQ(A;B) 的成功率 ≥ 1 − α_A − α_B − δ_b。证：A 失败概率 ≤ α_A；条件于 A 成功，B 在 A 的退出分布上的成功率与在自身进入支撑上相差不超过 δ_b（TV 对有界事件的作用），再由并集界。系：**组合只会扣减认证能力，不会凭空增加**；`κ⁻_{A;B} ≤ min(κ⁻_A, κ⁻_B)` 的上界形式成立，OPT 只能在已认证集合内取 max。这是"能力代数"与"不确定度代数"的关键区别。

**引理 39（交互查询的近最优性）** 若 IG(u,s) 关于查询集单调次模、成本可加，则预算下贪心 EIG/C 达到基数约束的 (1−1/e)、背包约束的 (1−1/√e) 近似（Nemhauser–Wolsey–Fisher；Khuller–Moss–Naor）。人类反馈在「给定潜变量后各观测条件独立」（如 Bradley–Terry 独立成对比较）时互信息次模；若反馈相关，次模性失效，退化为自适应间隙界。系：**"问什么"可以被优化，而不是凭经验设计问卷**。

**引理 40（漂移门的优雅退化）** 折扣 γ∈(0,1)、奖励有界 R_max。若 KL(π′‖π) ≤ ε 于访问分布，则 |J(π′)−J(π)| ≤ (2R_max/(1−γ)²)·√(ε/2)（性能差异引理 + Pinsker）。有限时域有同型 H 因子。系：**学习更新对安全界的影响随 ε 连续趋零**；因此可把 ρ 作为门控量，使"学习"与"证书"不再互斥，而是**证书按已知速率退化**。

**引理 41（否决校准的保守性）** 设 w⁻(s) 是 P(人类否决正确 | s) 的有效下界。则使用校准否决后的漏放（不安全继续）概率 ≤ min(1−p_robot, 1−w⁻)；若把能力外否决降级为偏好，则可避免"错误停机"在危险态造成的二次风险。系：**既不盲信人类，也不盲信机器人——否决权是可校准的量**，过/欠依赖可被目标函数显式权衡。

**引理 42（查询条件覆盖）** 在交互闭环中，若查询策略 π_q 依赖于在线信念，则人类反馈样本不满足全局可交换性；但给定查询类型与状态分层后仍可交换，故 query-conditional conformal 覆盖 ≥ 1−α 成立，而全局 conformal 覆盖率会低于名义值。系：**"问出来的数据"不能当"自然分布的数据"用**；这是教学闭环的结构性偏差，不是实现 bug。

**定理 30（严格包含）** 令 λ_L = 恒等（无学习）、ι_I = 空（无交互）、K = X、fallback = stub，则 SKILLGAUGE 的每一轮与 MODGAUGE（R73）逐指令相等；再退化等于 R72/R71/R68。安全单调不减。

**定理 31（技能证书有效性 ⇒ 系统安全）** Valid(J_SKILL) ⇒ 每个技能 cert 有效 ∧ SCA 校验通过（前后置蕴含、δ_b ≤ δ_max、资源预算、选择器认证）∧ CLG 日志闭合（每次部署更新 ρ ≤ ε 且影子通过）∧ IXM 校准（ECE ≤ τ、覆盖 ≥ 1−α、否决校准有效）⇒ 系统执行风险 ≤ ε_skill（相对能力估计与人类仪器的表达力）。**证明重量落在「能力域在分布外仍有效」与「人类仪器在查询诱导漂移下仍校准」上。**

**定理 32（证书保持学习 + 回滚）** 若 ρ(Δπ) ≤ ε，则安全界退化 ≤ g(ε) 且 g(0)=0（引理 40）；由于 CLG 保留上一有效证书与检查点，回滚可恢复更新前的界。故学习最坏情形 = 不学习，而不会静默使证书失效。**注意**：这是对"安全界"而非"真实风险"的陈述，界的松紧由 SEAL 与能力模型决定。

**定理 33（可维护性边界 / 教学循环终止）** 设单位时间环境漂移为 D，单位查询的信息容量为 C_q、成本为 c_q、人类预算为 B。维持 κ⁻ ≥ κ_min 所需的单位时间查询成本 ≥ D / (C_q·(κ_target−κ_min))；若该成本超过 B，则不存在非平凡认证技能，CLP 必然在有限步内退化到 fallback。于是教学循环要么在预算内有限续期，要么**显式失败**——不存在"永远差一点就好"的无限教学。

## 6. 本轮最大风险

**一句话**：SKILLGAUGE 的核心假设是「能力域可声明、人类仪器可校准」，但技能的能力估计与交互校准本身都在**由系统自己选择的分布**上训练和验证——查询策略会把数据分布推向系统自信的区域，人类示范会把教师自身的技能偏差注入证书，于是系统可能在一个**自我确证的闭环**里产出一张形式完备、覆盖率达标、却无法迁移到自然分布的技能证书；此时审计日志会证明「每次学习都过了漂移门、每次交互都过了校准」，而证书认证的是一个它自己构造出来的世界。

次级风险与缓解：
1. **能力域不可表示（开放世界）** → 显式 fallback 比例作为一等指标；K 外一律保守，宁可用得少不可错得自信。
2. **KL 漂移证书看不见罕见安全失败**（KL 对大偏差不敏感） → 漂移证书叠加 worst-case/对抗探测与隐藏安全态回放，门控取最大违反。
3. **查询条件覆盖仍被系统性偏差击穿** → 永久不查询的隐藏保持集 + 外部环境漂移探针 + 预注册再校准（SEAL-Human v2）。
4. **人类偏好漂移与疲劳** → 仪器模型含 u_drift/u_attn 分量；否决权用下界而非均值；人类负担作为硬预算。
5. **不可逆技能误用** → R_rev=irreversible 的技能强制更高安全边际 + 人类显式确认 + 更强 VETO 优先级。
6. **技能库组合爆炸** → 继承 R73 结构上限（|V_M|≤24、深度≤4）并新增 |SkillLibrary|≤64、SEQ 深度≤3。
7. **主张膨胀** → 定义 393 主张预算：活跃主张 ≤5，新主张必须退役旧主张或通过可分离性审计；C4/C5 若不能独立消融则折叠进 C1/C2。

**定义 389（校准否决权）** 有效否决 = robot_veto ∨ (human_veto ∧ w⁻ ≥ τ_h)；能力外否决降级为偏好证据，避免危险态误停的二次风险；权限内非补偿。

**定义 390（CLG）** 影子 → 门控（仅 X_valid）→ 晋升/拒绝/回滚；无第四条通道；漂移证书 ρ 是唯一放行量。

**定义 391（CLP）** 证书保鲜；三类漂移检测；续期或显式退化；可维护性条件（漂移率 < 可认证学习容量），否则无平凡认证技能。

**定义 392（技能威胁面）** 示范投毒 / 奖励黑客 / 教到会考 / 疲劳攻击 / 偏好漂移操纵 / 能力域伪装 / 边界利用；防线：影子门 + 隐藏保持集 + 单源不定案 + 边界审计 + 否决校准。

**定义 393（主张预算）** 活跃主张 ≤5；新主张须退役旧主张或通过可分离性审计。防止"创新点通胀"。

**定义 394（J_SKILL）** Valid(J_SKILL) ⇒ Valid(J_MOD)（R73 特例）；组合校验增加能力域交非空、δ_b 预算、CLG 日志闭合、IXM 校准有效。

**定义 395（MIC-Skill）** 形态无关技能契约：只依赖目标类型、能力域谓词、学习通道与交互通道结构；换形态 = 新实现 + 模块级重认证。

## 3. 关键算法伪代码

```python
@dataclass(frozen=True)
class SkillContract:                      # 定义 384
    goal: GoalSpec; pre: Predicate; post: Predicate
    K: CompetenceRegion
    kappa_lcb: Callable[[State], float]   # κ⁻：校准下界
    lam_L: LearningChannel                # Δπ ↦ (ρ, X_valid)
    iota_I: InteractionChannel            # 仪器 + 成本
    reversibility: str
    entry_dist: Dist; exit_dist: Dist
    fallback: SkillRef; cert_ref: str; wcet_us: float

@dataclass
class Skill:
    sc: SkillContract; pi: Policy; cert: SkillCert

def seq(a: Skill, b: Skill) -> Skill:      # 引理 38
    assert implies_on(a.sc.post, b.sc.pre, a.sc.exit_dist)
    d = boundary_gap(a.sc.exit_dist, b.sc.entry_dist)
    assert d <= DELTA_MAX
    lo = 1.0 - a.cert.alpha - b.cert.alpha - d
    return Skill(SC_SEQ(a.sc, b.sc), SeqPolicy(a.pi, b.pi),
                 CertSeq(alpha_lo=lo, boundary=d, fallback=first_fallback(a, b)))

def learning_gate(skill, delta_pi, replay, seal, hidden):   # 定义 390
    rho = drift_certificate(skill.pi, delta_pi, replay)
    if rho > EPS_DRIFT: return REJECT
    sh = evaluate(apply(skill.pi, delta_pi), seal, hidden)  # 影子：不执行
    if sh.safety_violations > 0: return REJECT
    if sh.kappa_lcb < skill.cert.kappa_lcb - TOL: return REJECT
    if sh.interaction_cost > skill.sc.iota_I.budget: return REJECT
    return GATED(apply(skill.pi, delta_pi), rho,
                 valid_region=skill.sc.lam_L(delta_pi).X_valid,
                 rollback=checkpoint(skill))               # 定理 32

def choose_query(belief, instruments, human_budget, teacher):  # 引理 39
    best = None
    for u, s in candidate_queries(belief):
        ig = mutual_information(belief, u, s)
        c  = instruments[u].cost(s, teacher)
        if c <= human_budget.left and (best is None or ig / c > best.score):
            best = Query(u, s, ig / c)
    return best

def calibrated_veto(s, human_veto, robot_veto, calib):         # 定义 389
    w = calib.human_competence_lcb(s)
    safety = robot_veto or (human_veto and w >= TAU_H)
    preference = human_veto and w < TAU_H
    return safety, preference

def SKILLGAUGE_round(M, obs, audio, tac_frame, depth_img, human):
    d_ev = M.dpe.update(depth_img, rgb, M.cam_state, M.motion, M.peers)
    d_ev = d_ev if d_ev.valid else stub(M.dpe)                 # R73
    t_ev = M.dmem.update(tac_frame, M.last_action)

    if M.clock.due_metric():
        b_t = M.bse.step_full(..., d_ev=d_ev, t_ev=t_ev)
        sk = M.lib.select(b_t, M.goal,
                          require=lambda s: s.sc.kappa_lcb(b_t) >= KAPPA_MIN)
        if sk is None:                                         # 能力外 → 回退
            return M.fallback.act(b_t)
        if M.clp.needs_renewal(sk, b_t):                       # 证书将过期
            q = choose_query(M.belief, M.instruments, M.human_budget, human)
            f = M.ui.ask(q); M.belief.update(f, q.u); M.clp.log(q, f)
            sk = M.lib.retrain_if_needed(sk, M.belief)
        if M.learner.has_update(sk):
            g = learning_gate(sk, M.learner.delta(sk), M.replay, M.seal, M.hidden)
            if g.ok: M.lib.replace(g.skill)                    # 保留 checkpoint
        veto, pref = calibrated_veto(b_t, human.veto, M.safety.veto(b_t), M.calib)
        if veto: return M.fallback.act(b_t)
        M.goal = M.goal.with_preference(pref)
        g_act = M.ervoi.choose(b_t, ..., sk=sk)                # R72 ERVOI†
        M.snapshot.write(b_t, sk, g_act, M.belief)
        M.mreg.audit(); M.clp.audit_drift()

    snap = M.snapshot.read_latest()
    lam = embodied_risk_scale(snap.U_ale, snap.U_epi, snap.H_z, snap.skill.kappa, M.risk_params)
    A = snap.skill.propose(snap, lam); k = M.c_ras_wm.certified_prefix(A, lam)
    M.ctrl_out.publish(k, lam)
    return k, lam, J_SKILL(M.lib, M.clg_log, M.ixm_calib, M.mreg)
```

## 4. 推导

**引理 38（能力不可免费组合）** SEQ(A;B) 成功率 ≥ 1 − α_A − α_B − δ_b（并集界 + TV 对边界事件的作用）。系：`κ⁻_{A;B}` 不高于组件下界的单调组合；组合只扣减认证能力。**这是能力代数区别于不确定度代数的核心。**

**引理 39（交互查询近最优性）** IG 单调次模且成本可加时，贪心 EIG/C 达 (1−1/e)（基数）/ (1−1/√e)（背包）近似；人类反馈在条件独立观测下互信息次模，相关反馈退化为自适应间隙界。系：**问卷设计可被优化**。

**引理 40（漂移门优雅退化）** KL(π′‖π) ≤ ε ⇒ |J′−J| ≤ (2R_max/(1−γ)²)·√(ε/2)（性能差异引理 + Pinsker）。系：**学习与证书不再互斥，证书按已知速率退化**。

**引理 41（否决校准保守性）** w⁻ 为正确率下界 ⇒ 漏放概率 ≤ min(1−p_robot, 1−w⁻)；能力外否决降级为偏好可避免危险态误停的二次风险。系：**否决权是可校准的量，不是无条件真值**。

**引理 42（查询条件覆盖）** 查询策略依赖在线信念时全局可交换性失效；按查询类型/状态分层后仍可交换，故 query-conditional conformal 覆盖 ≥1−α，全局覆盖低于名义值。系：**"问出来的数据"不能当自然分布数据用**。

**定理 30（严格包含）** λ_L=恒等、ι_I=空、K=X、fallback=stub ⇒ 逐指令等于 MODGAUGE，再退化等于 R72/R71/R68；安全单调不减。

**定理 31（技能证书 ⇒ 系统安全）** Valid(J_SKILL) ⇒ 技能 cert 有效 ∧ SCA 校验通过 ∧ CLG 日志闭合 ∧ IXM 校准 ⇒ 执行风险 ≤ ε_skill。**证明重量落在能力域与人类仪器在分布外的表达力。**

**定理 32（证书保持学习 + 回滚）** ρ ≤ ε ⇒ 安全界退化 ≤ g(ε), g(0)=0；回滚恢复更新前界；学习最坏情形 = 不学习，不会静默失效。注意这是对"安全界"而非"真实风险"的陈述。

**定理 33（可维护性边界）** 维持 κ⁻ ≥ κ_min 所需查询成本 ≥ D/(C_q·(κ_target−κ_min))；超预算则不存在非平凡认证技能，CLP 有限步内退化到 fallback——不存在无限期"差一点就好"的教学。

## 7. 本轮最大风险

**一句话**：SKILLGAUGE 假设「能力域可声明、人类仪器可校准」，但能力估计与交互校准都在**系统自己选择的分布**上训练和验证——查询策略把数据推向系统自信区，教师偏差注入证书，于是系统可能在一个自我确证的闭环里产出形式完备、覆盖率达标、却无法迁移的证书；审计日志证明「每次学习都过漂移门、每次交互都过校准」，而它认证的只是自己构造出来的世界。

次级风险与缓解：
1. **开放世界能力域不可表示** → fallback 比例升为一等指标；K 外宁可保守。
2. **KL 漂移看不见罕见安全失败** → 叠加 worst-case/对抗探测 + 隐藏安全态回放，取最大违反。
3. **查询条件覆盖仍被系统性偏差击穿** → 永久不查询的隐藏保持集 + 外部漂移探针 + SEAL-Human v2 再校准。
4. **偏好漂移与疲劳** → 仪器模型含 u_drift/u_attn；否决用下界；人类负担硬预算。
5. **不可逆技能误用** → 更高安全边际 + 显式人类确认 + 更强 VETO 优先级。
6. **技能库组合爆炸** → 继承 R73 结构上限，新增 |SkillLibrary|≤64、SEQ 深度≤3。
7. **主张通胀** → 主张预算（活跃 ≤5）；C4/C5 不能独立消融则折叠进 C1/C2。
