## 0. 直觉与动机

**灵感 1（用户测试 → 证书参数是可被证伪、可被预注册的统计假设，而不是永恒常数）**
直觉：v22 的每一个门槛——α、δ、κ_c、τ_rule、q_low/q_high、E_margin——都诞生于实验室与设计师直觉。但"证书说安全"与"用户感到安全 / 确实安全"之间隔着整整一个**统计推断问题**：证书是对**部署人群**的承诺，而用户测试只给一个**有限、自选、会适应机器人**的样本。核心创新：**用户证据回路 (User-Test Evidence Loop, UTEL)**——把每条证书声明编译为可检验假设（"假许可率 ≤ α"、"任务成功率 ≥ 1-β"、"N 小时内零跌倒"），用**预注册 + anytime-valid 置信序列**做带提前停止的序贯检验，用**分层/对抗采样**强制覆盖检测器最弱的人体形态层；任何阈值变更都必须变成**新的 merkle 承诺版本**，而非运行时热调参。关键反直觉点：**用户测试最危险的产物不是"证书被推翻"，而是"证书被指标绑架"**——为提升满意度而悄悄放松门槛是一种 Goodhart 式的规范漂移，所以 UTEL 必须被隔离在运行时安全链之外，只能"生产需重新认证的新版本"，永远不能"当场放宽门槛"。副产品：**反事实用户测试 (CUT)** 用日志做 off-policy 评估，让新阈值在"零新增暴露"下先被筛一遍，ESS 不足即拒绝推断。

**灵感 2（平衡控制 → 从"能量够不够"到"能不能被恢复"，且人是耦合动力学的一部分）**
直觉：v22 的 EVC 只保证"电还够、能制动"，却不保证"不会翻"。足式/轮足机器人可以在能量充足时因捕获点越界而摔倒。平衡控制的核心不是姿态，而是**可恢复性**：捕获点/DCM `ξ = x + ẋ/ω₀` 是否落在支撑域可达的捕获区域内、接触力是否在摩擦锥内、最坏情况下一次落脚恢复的能耗 `E_bal_recover` 是否仍留在储备账户里。核心创新 1：**平衡可行证书 (Balance Viability Certificate, BVC)**，把人形共享区里早已挂在违反项里的"平衡裕度 <0"正式形式化为一个鲁棒受控不变集 `Ω_bal`，并让 `E_bal_recover` 进入储备不变量。核心创新 2（真正反直觉）：**人不是平衡问题的边界条件，而是耦合振子**。机器人一次"安全"的恢复性迈步会惊动人，人的本能后仰/闪避又反过来改变机器人周围的可行域与人距——于是"对机器人安全的恢复"可能"对人危险"。因此需要**耦合平衡证书 (Coupled Balance Certificate, CBC)**：联合捕获点 `ξ_c = ξ_r + λ_c·ξ_h`，耦合增益 `λ_c` 与人体容忍加速度 `a_tol` 都由用户测试标定。最尖锐的张力：**DCL 的"见人即停 / 勿侵入"义务可能动力学上不可行**——某些形态必须迈步才能不摔倒，而唯一可行落脚点可能落在人的个人空间内。这就是**跌倒-侵入两难**，必须由显式的、预授权的、可审计的仲裁参数 `w_fi` 处理，而 `w_fi` 本身是一个只有用户与伦理委员会能回答的规范问题。

**两者如何统一**
统一为一个**三时间尺度的证据-控制架构**：内环（50Hz）控制 + O(1) 证书查询；中环（每回合/每次部署）运行 PGEV/能量/平衡的运行时认证；外环（每次用户试验/每次发版）是 UTEL，它**只**产出被 pre-registration 与 SCC 约束的新证书版本 `θ'`，再让 `θ'` 重新走一遍内环/中环的同一道门。共享状态扩展为 **`ζ_user = ζ_pgev ∪ (Ω_bal, λ_c, a_tol, θ_thresh, H_trail, Ev_t, w_fi)`**。统一准入门 **HPC-B = (HPC-E, BVC, CBC)**：几何/规范/能量 ∧ 可恢复平衡 ∧ 人机耦合可接受，任一缺失即向 v22→v21→v20 保守退化。

## 2. 设计原则（在 P37–P42 基础上新增 P43–P46）

**P43 证据回路隔离律（Evidence-Loop Isolation）**
直觉：能改善安全的证据，如果放在运行时链里，也会被用来"改善指标"从而削弱安全。形式化：UTEL 只能读取日志、产生**新版本** `θ'`，并与 `θ` 一起落 merkle 承诺；运行时门只接受**当前已认证版本**，禁止热改。每个版本内安全继承成立（见产物区命题）；版本间演化必须重走 `HPC-E ∧ BVC ∧ CBC` 全套门。故"用户测试"不进入控制路径，只进入**发版流程**。

**P44 平衡可恢复律（Balance Recoverability）**
直觉：安全不是"站得稳"，而是"无论被怎么推，都存在一次能耗得起的恢复"。形式化：存在鲁棒受控不变集 `Ω_bal ⊆ K_bal`，`K_bal = {s : dist(ξ, Cap(P_supp)) ≤ margin_bal ∧ w_contact ∈ FCC ∧ E_res ≥ E_fallback + E_arm + E_bal_recover + E_margin}`；计划 π 必须使全轨迹留在 `Ω_bal`。`Ω_bal` 对不确定性 `u ∈ U` 与现实的差距 `d_gap` 复用 RGC 的证伪机制；无法证明留在 `Ω_bal` 时退回静态人距上限（更保守）。

**P45 耦合平衡律（Coupled Balance）**
直觉：机器人恢复动作是人的扰动源，人是机器人可行域的扰动源。形式化：联合捕获点 `ξ_c = ξ_r + λ_c·ξ_h`，要求 `ξ_c` 在联合捕获区域、且恢复动作诱发的加速度 `|a_r| ≤ a_tol`（避免惊扰导致人失稳）。`λ_c`、`a_tol` 只由用户测试标定并带 TTL；标定过期或分布外（OOD）即回落到"人视为不可预测扰动"的最保守耦合，此时共享区停机而非冒险。

**P46 跌倒-侵入仲裁律（Fall–Intrusion Arbitration）**
直觉：规范说"停"，动力学说"必须迈"。形式化：当 `DCL` 的 `F/O` 与 `BVC` 同时不可满足时，仲裁器在**预授权边界**内放行"最小侵入的恢复步"，目标 `min(a_r, dist_to_human)` 的加权 `w_fi`；每次仲裁写审计事件、恢复后强制 SafeStop 并重认证。`w_fi` 是规范参数，由用户测试/伦理委员会设定，运行时只可**收紧**不可放宽。故 `Exec_v23 = Exec_v22 ∩ Fil_balance ∩ Fil_coupled ∩ (HPC-B admissible) ⊆ Exec_v22`。

## 3. 与基线的接口（如何退化）

- BVC 失效（平衡核不可证）⇒ 退回 v22 的静态人距上限 + 共享区限速 ⇒ 比 v22 更保守；
- CBC 失效（耦合标定过期/OOD）⇒ 把人当不可预测扰动、共享区停机 ⇒ 子集；
- UTEL 失效（试验数据不足/ESS 不足）⇒ 沿用上一已认证版本 `θ`、不产生新版本 ⇒ 等价 v22；
- SCC 触发（Goodhart 漂移）⇒ 吊销当前版本、回滚到上一个未漂移版本 ⇒ 更保守；
- FIA 无预授权 ⇒ 拒绝恢复步、接受受控跌倒（并记录）⇒ 保守方向不变；
- 全部失效 ⇒ 完全回退 v22 ⇒ `Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20`（引理 163）。
- **安全继承**：BVC 只加受控不变集约束，CBC 只加联合约束，FIA 只在预授权内放宽且事后 SafeStop，UTEL 只产出新版本；任意失效都向更保守方向退化。

## 4. 预期贡献

1. **用户证据回路**：首次把证书常数变成"预注册 + anytime-valid 序贯检验 + 分层对抗采样"的实证对象，并给出"版本内单调、版本间受控演化"的安全继承纪律；
2. **反事实用户测试**：用 off-policy（IS/DR + ESS 守门）在零新增暴露下预筛阈值变体，避免拿真人做阈值搜索；
3. **规范一致性证书**：用独立审计测度监测"代理指标—潜在安全"的解耦，显式防御 Goodhart 式规范漂移；
4. **平衡可行证书**：把 DCM/捕获点、摩擦锥与恢复能耗并入统一储备不变量，给出"可恢复性"而非"姿态"的证书；
5. **耦合平衡证书**：把人体作为耦合振子纳入证书，给出联合捕获点 + 容忍加速度的可审计条件；
6. **跌倒-侵入仲裁**：首次正面承认"规范要求停、动力学要求迈"的真实两难，并给出预授权、可审计、只会收紧的化解机制；
7. **HPC-B 三证一体**：`(HPC-E, BVC, CBC)` 统一准入门，闭环 `Exec_v23 ⊆ Exec_v22`。

## 5. 本轮最大风险

**一句话**：整轮的可靠性最终押在两个**外生样本**上——用户测试样本与耦合增益 `λ_c` 的标定样本——若它们系统性遗漏最脆弱人群（儿童、轮椅、认知障碍、强逆光），那么证书会在**形式完备**的同时，把一个"对测试者友好、对未测试者危险"的策略认证为安全；最大的失败不是摔倒，而是**用看似严谨的用户证据，把偏见洗成了合规**。

# IP-437 Balance Viability Certificate
class BalanceViabilityCertificate:
    def __init__(self, omega0, supp_poly, fcc, margin_bal, eps_gap):
        self.omega0 = omega0          # √(g/z_com)，可随 CoM 高度更新
        self.P_supp = supp_poly       # 支撑多面体
        self.FCC = fcc                # 摩擦锥
        self.margin_bal = margin_bal
        self.eps_gap = eps_gap        # 现实差距 d_gap 内的鲁棒膨胀

    def dcm(self, x, xdot):
        return x + xdot / self.omega0

    def in_kernel(self, s):
        xi = self.dcm(s.x, s.xdot)
        return (
            self._dist_to_capture_region(xi) <= self.margin_bal - self.eps_gap
            and self._wrench_in_fcc(s.contact_wrench, self.FCC)
            and s.E_res >= (s.E_fallback + s.E_arm
                            + s.E_bal_recover + s.E_margin)
        )

    def robust_invariant(self, plan, U, delta):
        """Ω_bal 验证：对所有 u ∈ U 的 rollout，轨迹留在 K_bal 的概率 ≥1-δ。
        找不到见证 ≠ 已证明：见证集为空时只能退回更保守的静态人距上限。"""
        witnesses = self._falsify(plan, U)      # 复用 RGC 的反例搜索
        if witnesses:
            return False, witnesses
        return self._interval_bound(plan, U) >= 1 - delta, []

# IP-438 Coupled Balance Certificate
class CoupledBalanceCertificate:
    def __init__(self, bvc, lam_c, a_tol, ttl):
        self.bvc, self.lam_c, self.a_tol = bvc, lam_c, a_tol
        self.ttl = ttl

    def joint_capture_point(self, s_r, s_h):
        return (self.bvc.dcm(s_r.x, s_r.xdot)
                + self.lam_c * self.bvc.dcm(s_h.x, s_h.xdot))

    def joint_viable(self, s_r, s_h, now):
        if now - self.lam_c.ts > self.ttl:          # 标定过期 → 最保守
            return False, "COUPLING_STALE"
        if self._is_ood(s_h):                        # 分布外人体 → 最保守
            return False, "HUMAN_OOD"
        # 1) 机器人可恢复  2) 恢复加速度不惊扰人  3) 联合捕获点不越界
        return (
            self.bvc.in_kernel(s_r)
            and abs(s_r.a_recover) <= self.a_tol
            and self._dist_to_joint_capture(self.joint_capture_point(s_r, s_h))
                <= self.bvc.margin_bal
        ), "OK"

# IP-436 User-Test Evidence Loop（隔离在运行时链之外）
class UserTestEvidenceLoop:
    def __init__(self, theta, alpha_ut, beta_ut, strata):
        self.theta = theta
        self.commit = merkle_commit(theta)   # 预注册：开跑前冻结阈值
        self.alpha_ut, self.beta_ut = alpha_ut, beta_ut
        self.strata = strata                 # 强制覆盖最弱人体形态层

    def monitor(self, stream):
        """anytime-valid 置信序列：任意时刻停止仍保持名义水平（免 p-hacking）。"""
        for event in stream:
            self.Ev_t = self._confidence_sequence_update(event)
            if self._violates_lower_bound(self.Ev_t, self.alpha_ut):
                return "REJECTED"            # 假许可率超界
            if self._sufficiently_powered(self.Ev_t, self.strata):
                return "PASSED"

    def propose_version(self, theta_new):
        """只能生成需重新认证的新版本；绝不在运行时热改阈值。"""
        return CertVersion(theta=theta_new,
                           merkle=merkle_commit(theta_new),
                           requires_recert=True)

# IP-439 Counterfactual User Tester（零新增暴露的阈值预筛）
class CounterfactualUserTester:
    def off_policy_eval(self, logs, target_policy, min_ess=200):
        w = [target_policy.prob(a, s) / log.behavior_prob(a, s)
             for (s, a, log) in logs]
        ess = (sum(w) ** 2) / sum(wi ** 2 for wi in w)
        if ess < min_ess:                    # 支撑重叠不足 → 诚实拒绝
            return None, "INSUFFICIENT_OVERLAP"
        return doubly_robust_estimate(logs, w), "OK"

# IP-440 Specification-Consistency Certificate（防 Goodhart）
class SpecificationConsistencyCertificate:
    def test_decoupling(self, proxy_series, audit_series):
        """代理指标（满意度/完成时间/近失）与独立审计安全（独立伤害/近失复核）
        的关联若因优化而解耦超过界，顺序变点检验触发吊销当前证书版本。"""
        return not self._change_point_detected(proxy_series, audit_series)

# IP-441 Fall–Intrusion Arbitrator
class FallIntrusionArbitrator:
    def resolve(self, dcl_feasible, balance_feasible, w_fi):
        if dcl_feasible or balance_feasible:
            return "NO_CONFLICT"
        # 义务不可满足且跌倒不可避免：仅在预授权范围内放行最小侵入恢复步
        step = self._min_intrusion_recovery(weight=w_fi)
        if not self._within_preauthorization(step):
            return "CONTROLLED_FALL"         # 无预授权 → 接受受控跌倒并记录
        self.audit.record(step)              # 全链可审计
        return "RECOVER_THEN_SAFESTOP"

# IP-442 HPC-B 统一准入门
@dataclass
class HPCB:
    hpce: HPCE
    bvc: BalanceViabilityCertificate
    cbc: CoupledBalanceCertificate

    def admits(self, plan, s_r, s_h, now, U, delta):
        hpce_ok = self.hpce.admits(plan)     # 几何∧规范∧能量（v22 原门）
        bal_ok, _ = self.bvc.robust_invariant(plan, U, delta)
        cpl_ok, _ = self.cbc.joint_viable(s_r, s_h, now)
        return hpce_ok and bal_ok and cpl_ok

## 2. 安全继承命题与"版本间非单调"警示

**命题 163（版本内单调继承）**：对固定证书版本 `θ`，
`Exec_v23(θ) = Exec_v22(θ) ∩ Fil_balance(θ) ∩ Fil_coupled(θ) ∩ HPC-B ⊆ Exec_v22(θ)`。
*证明*：`Fil_balance` 是鲁棒受控不变集的交集过滤，`Fil_coupled` 是联合捕获点/容忍加速度带来的附加不等式，FIA 仅在预授权内放宽且事后 SafeStop，HPC-B 是多重合取门；交集只会删计划不会增计划；`E_bal_recover ≥ 0` 只会抬高储备下界。∎

**警示（版本间非单调）**：UTEL 可发布放宽阈值的 `θ'`，此时 `Exec_v23(θ')` 可能 **⊋** `Exec_v23(θ)`。因此安全继承**只在版本内成立**；跨版本必须经 pre-registration + SCC + 全套重认证，且禁止运行时热改 `θ`。这是把"用户测试"隔离在运行时安全链之外的根本原因。
