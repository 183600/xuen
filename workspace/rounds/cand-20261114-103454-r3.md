# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS 具身计量审计」IP-287~294；灵感循环第 3 轮；本轮灵感：「语言指令」×「模型蒸馏」）

> R72 把 GAUGE 从「认知层」下沉到「具身层」：REG 实时执行图、IRL 意图识别、DMEM 灵巧接触计量、EREFLEX 三层反作用、ERVOI、S2R-UQ、三域分离，回答了「我的测量链在实时调度、意图模糊、灵巧接触下还能否兑现风险界」。但 R72 仍有两处结构性盲点：
> - **语言指令视角**：R72 只把语言当作 **意图证据** `y_intent=(speech, gesture, gaze, context)` 与情感韵律，从未把一句指令当作 **可执行、可验证、可审计的规格**。「把螺丝拧到刚好不晃」「把红块放蓝盒左边、别碰倒杯子」里包含指代、量词、比较级、隐式安全约束、可验证的成功谓词、以及**欠定**成分。把整句压成粗粒度 `z`，丢掉了几乎全部信息与可验证性。更关键：**指令本身是一次测量**（测得「人想要什么任务」），其仪器是「人的表达 + 机器人解析器 + 指代落地 + 说话人可信度 ψ」，因此必须像 R72 的 `u_tac` 一样被**四分量审计**。
> - **模型蒸馏视角**：R72 的全栈（完整 BSE、意图网、触觉网、联合后验）在 1kHz 控制域与 50Hz 计量域都**装不下**。自然要做蒸馏。但标准蒸馏只保**平均输出**，不保**尾部、校准、弃权区域**。学生可能训练集 99% 准确、OOD 却**高置信地错**，而老师本会说「我不知道」。正确的框架是计量学的：**蒸馏 = 用廉价现场仪器替换已校准的参考标准**。信任现场仪器不是因为它平均吻合，而是因为它有**可追溯校准链、声明有效域、以及域外不用它**。
>
> 本轮两个灵感 + 一个统一：
> - **语言指令（ILM / ICC）**：把自然语言编译为**指令契约 κ**（grounded symbols、前置/后置条件、安全不变量、欠定集 Ω、追溯链 τ、四分量不确定度 `u_instr`）；「是否遵循指令」从口头声明变成**可运行时判定的谓词**；欠定/不可行时发起**澄清或安全拒绝**（一个 VoI 为正的动作）。
> - **模型蒸馏（CPD / TAD）**：**保证书蒸馏**——学生必须继承老师的（i）校准、（ii）弃权区域包含性 `R_S ⊇ R_T`、（iii）带**蒸馏残差 `u_dist`** 的证书；控制域跑学生，残差代理超阈或有界域外即**有界 deferral** 给老师，deferral 期间执行**已认证 safe-hold**，绝不阻塞控制环。
> - **统一（TFER）**：sim→real（S2R-UQ）、teacher→student（CPD）、language→contract（ILM）是**同一个数学对象**——带残差、有效域、追溯链与回退源的**有损翻译**。安全不靠「相信翻译无损」，而靠**组合残差预算 + 回退到源**。
>
> 核心命题：**R72 问「我的测量链能否兑现风险界？」；R73 再问「我的测量链所遵循的那句话，是我以为的那句话吗？而我用来理解它的那个小模型，还配得上那张证书吗？」** —— 把 EMBODIED 升级为 **LINGUA-GAUGE-RAS**（Language-instruction-grounded, dIstillation-certified, Non-degenerate, Guaranteed-under-transfer, Unified-audit GAUGE for RAS）——**可翻译性审计闭环**。一句话读法：**每一次翻译都要留证；证不住，就退回原文。**

## 0. 直觉与动机

**灵感 1（语言指令 → 指令是有损、组合、可验证的「欲望测量」，不是意图标签）**
直觉：人说「把左边那个拿给我」时，`z=拿取` 只是这句话最表层的一小部分。真正驱动执行、也真正能被追责的是：**指代落到哪个物体**（「那个」= 红杯还是蓝杯？）、**成功谓词**（拿到手 / 放到够得着 / 只是指向）、**比较级与量词**（「快一点」「都」「刚好不晃」）、**隐式安全约束**（「小心别碰倒」）、以及**欠定集**（要不要盖盖子？）。这句自然语言是「人想要的 task」经过**人的表达（有损编码）**再经过**机器人的解析与落地（有损解码）**得到的一次**测量**。既然 R72 坚持任何进入风险缩放的数字都必须有「构造 / 估计器 / 不确定度 / 有效域 / 追溯链 / 反指标」，那么**指令进入规划前也必须过同一套审计**。把 ℓ 编译成**指令契约 κ**，让「是否遵循」成为运行时判定的谓词，是从「猜意图」到「守契约」的跃迁。

**灵感 2（模型蒸馏 → 蒸馏是仪器替换，必须替换的是「证书」而非「输出」）**
直觉：R72 的完整栈有两套模型同时跑：计量域的大 BSE/意图网、感知域的触觉网。控制域 1ms 内只放得下一个**小模型**。蒸馏看起来是压缩问题，实则是**测量仪器替换问题**：老师是「参考标准」，学生是「现场仪器」。计量学从不因为现场仪器「平均读数接近标准」就信任它；它要求现场仪器有**可追溯校准链**、**声明的扩展不确定度**、**明确的有效量程**，并且**量程外读数一律作废**。映射到这里：学生必须继承老师的**校准**（ECE 不劣化）、**弃权区域**（老师弃权的输入学生也必须弃权：`R_S ⊇ R_T`）、以及一张带**蒸馏残差 `u_dist`** 的证书；域外或残差超预算时，学生**必须 deferral 给老师**，而不是硬答。

**灵感 3（统一 → 三种「翻译」同构，安全 = 对回退封闭）**
直觉：把三件事并排看：
- `T_s2r`：仿真参数 θ_sim → 实机参数 θ_real（R72 的 S2R-UQ，残差 Δ）；
- `T_dist`：老师策略/后验 π_T → 学生 π_S（本轮 CPD，残差 u_dist）；
- `T_ground`：自然语言 ℓ → 可执行契约 κ（本轮 ILM，残差 u_instr）。
三者的数学形状完全一样：一个映射 `T: X→Y`，配一个**残差界 u**、一个**有效域 D**、一条**追溯链 τ**、以及一个**回退源 fallback**（当 x∉D 或 u 超预算时，不做翻译，直接用未翻译的源）。组合两个翻译时，误差不是相加这么简单：若 `T2` 对输入是 Lipschitz 常数 `L_2`，则 `u(T2∘T1) ≤ u(T2) + L_2·u(T1)`。于是得到本轮最想立的命题：**只要每个翻译都带「可验证残差 + 有效域 + 回退」，那么把任何一层换成更便宜的翻译，系统的安全包络都不会变小；换翻译只能改变效率，不能挖穿安全。** 这把 R72「安全侧只增不减」从「退化链」升级为「翻译代数」。

**灵感 4（两个新的反作用：指令修订 L2′ 与 deferral 抖动）**
直觉：R72 的反作用阶梯是 ψ（情感）/ z（意图）/ c（接触）。本轮新增两类**发生在「翻译层」的反作用**：
- **指令修订反作用 L2′**：机器人**澄清**（「您是要红杯还是蓝杯？」）会改变人后续的措辞与指令；机器人**静默猜测**则可能让人以后说得更含糊（因为「反正它会猜」）。这是比 R72 的意图漂移（z 漂移）更上游的**规格漂移**（κ 漂移）。
- **deferral 反作用 L4**：学生频繁 deferral → 老师负载上升 → 老师延迟上升 → deferral 等待变长 → 控制域更多 safe-hold → 任务变慢 → 人更烦躁（ψ 下降）→ 指令更急更含糊（L2′）→ 更多 deferral。这是一条**跨翻译层的坏循环**，必须纳入统一反作用预算。
于是 R72 的三层预算扩展为**五层**：ψ / z / c / κ / deferral，且五层共享 `B_reflex_total`。

**灵感 5（与 R72 的接口：同一 λ、同一证书、同一退化链）**
直觉：不新建平行体系。`u_instr` 与 `u_dist` 直接进 R72 定义 360 的**同一个风险缩放分母与 λ_floor**；指令契约哈希、学生证书链、翻译残差链直接进 `J_EMB` 的**同一个证书**；失效时沿 R72 定义 364 的**同一条退化链**逐指令回退。**R73 不是 R72 的旁支，而是它的「输入侧（语言）」与「实现侧（蒸馏）」的闭合。**

## 1. 形式化定义（增量：定义 366–386）

**定义 366（LINGUA-GAUGE-RAS 总览）** LINGUA-GAUGE-RAS = (ILM, ICC, ICM, CPD, TAD, TFER, EMBODIED-GAUGE-RAS†)。六不变式：
(i) **指令契约完整性**：任何进入规划的指令都必须先编译为 κ，且 κ 携带（grounded symbols、pre/post、I_safe、Ω、追溯链 τ、四分量 `u_instr`）；**未经审计的自然语言不得直接到达 ACH 规划器**；
(ii) **学生证书完整性**：任何在控制域/计量域运行的学生 S 都必须携带 `J_S = J_T ⊕ (u_dist, D_dist, τ_dist)`；**S 的输出不得在 `D_dist` 之外被使用**；
(iii) **deferral 活性**：控制环绝不阻塞等待老师；deferral 由 `D_def` 界定时限，超时即进入已认证 safe-hold（R68 类）；
(iv) **翻译残差预算**：组合翻译链的累计残差 ≤ `B_transfer`；超预算即回退到该链的源（更慢但持证）；
(v) **五层反作用预算**：`c^ψ + c^z + c^c + c^κ + c^def ≤ B_reflex_total`；
(vi) **严格逐指令退化链**：ILM 失效 ⇒ 澄清/拒绝，否则退 R72；CPD 失效 ⇒ deferral 老师，否则退 R72；TFER 超预算 ⇒ 只回退出错那一层。三者全失效 ⇒ R68。

**定义 367（指令契约 κ）** κ = (Σ, R, Φ_pre, Φ_post, I_safe, Ω, τ, u)：
- `Σ`：落地符号集（物体 o_i 及其位姿分布 b(o_i)、区域、关系）；每个符号携带 grounding 不确定度；
- `R`：指代消解映射（deixis / anaphora → Σ），是一个关于候选落地的分布 r；
- `Φ_pre, Φ_post`：前置 / 后置条件谓词（Σ 上的时序逻辑，如 `◇_{≤H} holds(o,box)`）；
- `I_safe`：安全不变量（always 子句，如 `□ ¬collide ∧ □ ¬drop`）；
- `Ω`：欠定集（自由参数 / 开放选择，如「要不要盖盖子」）；
- `τ`：追溯链（utterance → parse forest → grounding → 可达性检查）；
- `u = (u_sem, u_ground, u_scope, u_comply)`（见定义 368）。
只有 `u_instr` 在预算内、且 `Φ_post` 可达性非空、且 `I_safe` 与场景无硬冲突的 κ 才允许进入规划。**不可执行不是错误，是可被检测并拒绝的状态。**

**定义 368（指令计量 ILM：四分量）** 与 R72 的 `u_tac` 结构对偶：
- `u_sem`：语义解析歧义（parse forest 上的熵 / top-k 契约间期望差异）；
- `u_ground`：指代落地不确定度（`E_{b(o)}[d(o,o*)]`，含物体位姿与指代双重不确定）；
- `u_scope`：量词/比较级/模糊词的边界不确定度（把「快一点」「刚好」「都」建模为分级满足区间，取区间宽度）；
- `u_comply`：运行时合规监视器自身的判定不确定度（能否在传感器精度内**验证** `Φ_post`）。
`u_instr² = u_sem² + u_ground² + u_scope² + u_comply²`（四机制独立，近似正交；遗漏 `u_comply` 会把「无法验证」误当成「已验证为真」）。**每项独立追溯链 `τ_instr_i`。**

**定义 369（指令契约编译器 ICC）** 管线：
`ℓ → parse forest P → 按语境/ψ 先验剪枝 → grounding（对 b_t(s) 做指代消解）→ 候选契约 {κ_j}`
`→ 后验 b(κ) ∝ p(ℓ|κ)·p(κ|context)·p(scene|grounding) → 可达性检查（Φ_post）∧ 不变量一致性（I_safe）→ (κ*, b(κ), u_instr, feasible, Ω)`。
若 `feasible=⊥` 或 `u_instr` 超阈或 `Ω` 过大 ⇒ **输出澄清查询或安全拒绝**（定义 372），而不是硬规划。

**定义 370（指令合规监视器 ICM）** 每个控制拍，在 `b_t` 与 κ 下估计
`p_comply = Pr[ ◇_{≤H} Φ_post ∧ □ I_safe | b_t, κ ]`，
以及 `u_comply`。若 `p_comply < τ_comply` 或 `I_safe` 风险超预算 ⇒ 中止 / 进入 safe-hold，并记录失败模式。**「我遵循了指令」从此是一条带证书的运行时谓词，不是一句口头声明。**

**定义 371（语言引导风险缩放 L-RISK）** 在 R72 定义 360 上扩展：
`λ = max( risk_scale(U_ale, U_epi, H[b_t(z)], u_tac, u_instr.total(), u_dist),
          λ_floor(U_ale + U_epi + H[b_t(z)] + u_tac.total() + u_instr.total() + u_dist) )`。
**指令越含糊、落地越不确定、合规越难验证、学生越不可信，λ 越高，动作越慢越软。** 这是 R72「意图不确定度是物理安全分母」的语言层推广：**语义不确定度也是物理安全分母。**

**定义 372（指令澄清作为 VoI 动作）** 在 R72 ERVOI 上增加指令信息增益与澄清成本：
`VoI^L(g) = VoI^E(g) + IG_κ(g) − c_ask^instr(g) − c_reflex^κ(g) − c_reflex^def(g)`，
其中 `IG_κ(g) = H[b(κ)] − E_y[H[b(κ')]]`。**安全拒绝（不做、解释原因）始终是一个可用动作，且有界遗憾**：`Regret(refuse) ≤ ε_refuse`。**「问一句」和「什么都不做」都是合法的一等动作，而不是失败。**

**定义 373（保证书蒸馏 CPD：Certificate-Preserving Distillation）** 给定老师 T 及其在 `D_T` 上有效的证书 `J_T`，学生 S 由 T 蒸馏得到。CPD 要求：
(i) **校准迁移**：在 `D_T` 上 `|ECE_S − ECE_T| ≤ ε_cal`（或以 hold-out 认证集做保守再校准，保证不劣化）；
(ii) **弃权包含**：`R_S ⊇ R_T`（老师弃权的输入，学生必须弃权），通过在审计集上对学生弃权阈值做**支配性校准**并以集中不等式给出高概率保证；
(iii) **残差有界**：在 `D_T` 上 `E[d(S(x),T(x))] ≤ ε_agree`，且给出高概率**尾部**界（非仅均值）。
则 `J_S = J_T ⊕ (u_dist, D_dist, τ_dist)`，`D_dist ⊆ D_T`，**S 只允许在 `D_dist` 上运行**。`τ_dist`：学生哈希 → 训练/审计集 ID → 老师哈希 → 老师证书。**这就是计量学的校准层级：学生可追溯至老师，老师可追溯至（仿真/实机）参考。**

**定义 374（蒸馏残差分解 u_dist）** 与 `u_tac` 对偶：
`u_dist² = u_agree² + u_cal² + u_tail² + u_ood²`，
- `u_agree`：平均输出/动作分歧（KL 或动作距离）；
- `u_cal`：校准迁移误差（ECE 差）；
- `u_tail`：**尾部/分位差异**（标准蒸馏忽略的部分；需分位数审计而非训练损失）；
- `u_ood`：域边界残差，进一步分解为 `u_ood = √(u_ood^state² + u_ood^lang²)`——**状态域外**（新场景）与**语言域外**（新指令措辞）。**语言条件策略的有效域必须同时是「状态 × 语言」的子集。**
遗漏任一分量 ⇒ 学生「平均对、尾部错、越界更自信」，正是 R72 警告过的「信息增益虚高、风险缩放失效」的蒸馏版本。

**定义 375（两层随时可弃权 TAD）** 控制域跑学生 S（快）。定义**残差代理** `δ_S(x) ∈ [0,1]`（集成方差 / OOD 分 / 校准后的残差估计）。当 `δ_S(x) > τ_def` 或 `x ∉ D_dist` ⇒ 触发 deferral：控制域在 `D_def` ms 内执行**已认证 safe-hold**（R68 类有界保持），计量域异步调用老师 T；若 T 在 `D_def` 内返回则用 T 的持证输出，否则继续 safe-hold 并请求人工/指令澄清。**控制环永不阻塞（活性）；safe-hold 恒持证（安全性）。deferral 率是一等指标。**

**定义 376（翻译残差代数 TFER）** 翻译 `T = (src, dst, u_T, D_T, τ_T, fallback)`。复合：
`u(T2∘T1) ≤ u_T2 + L_T2 · u_T1`，`D(T2∘T1) = D_T1 ∩ T1^{-1}(D_T2)`，`fallback(T2∘T1) = fallback(T1) 若 T2 失败`。
**安全不变式**：对任意组合链，若在可达状态/指令分布上累计残差 ≤ `B_transfer`，则使用翻译模块；否则回退到该链的源模块（持证但更慢/更弱）。`T_s2r`（R72）、`T_dist`（CPD）、`T_ground`（ILM）**皆是其实例**。

**定义 377（翻译复合证书 J_LDG）** `J_LDG = (J_EMB, κ_hash, J_S, u_instr, u_dist, transfer_chain_hash, deferral_policy_hash, lng_ver)`。Valid ⇔ `J_EMB` 有效 ∧ κ 在预算内 ∧ S 运行于 `D_dist` ∧ 累计翻译残差 ≤ `B_transfer` ∧ deferral 活性已证。

**定义 378（威胁模型 AIC-LDG）** `ℰ_LDG = ℰ_EMB × ℰ_lang × ℰ_dist`：
- `ℰ_lang`：指令注入 / 场景文字 prompt 注入、对抗性指代歧义（精心构造的「那个」使落地翻转）、指令漂移、借语言操纵 ψ、自相矛盾子句、**语义 OOD 但语言表面在分布内**的恶意指令；
- `ℰ_dist`：老师投毒、学生后门、审计集污染、校准集投毒、**域边界探测**（把输入推到 `D_dist` 外以触发/规避 deferral）。
**关键**：老师不因「大」而成为信任根；证书链可以在**审计集**这一环被投毒。

**定义 379（R73 严格退化链）** 扩展定义 364：
- 全失效 ⇒ R68（纯视觉/本体开环）；
- ILM 失效（无法落地/不可行）⇒ 澄清/拒绝，否则固定契约先验 + R72；
- CPD 失效（S 出域或 `u_dist` 超预算）⇒ deferral 老师，否则 R72（无学生）；
- TFER 超预算 ⇒ **只回退出错的那一层翻译**，其余层照常；
- 全有效 ⇒ LINGUA-GAUGE-RAS 完整形态。
**安全侧只增不减：任何退化都保留 R68 硬安全包络与 λ_floor。**

**定义 380（指令修订反作用 L2′）** `κ_{t+1} ~ p(κ' | κ_t, a_t^robot, g_t^ask, ψ_t)`；成本
`c_reflex^κ = D_KL(b(κ_t) ‖ b(κ_{t+1})) + λ_κ·𝟙[κ_{t+1} ∉ K_safe]`。
机器人**静默猜测**（不问）与**过度澄清**（问太碎）都会推高 `c_reflex^κ`：前者让规格漂移累积，后者透支人的耐心。**澄清的时机与粒度本身需要 VoI 论证。**

**定义 381（deferral 反作用 L4）** `λ_def` 随 deferral 率与等待时长上升；成本
`c_reflex^def = λ_def·(deferral_rate) + μ_def·E[wait_time] + ν_def·𝟙[ψ_{t+1} ∉ Ψ_safe]`。
**deferral 不是免费的**：它把「学生的不确定」转化为「系统的延迟」，并可能经 ψ（L1）与指令（L2′）反馈成更大负载。五层预算必须合算。

**定义 382（翻译残差监控 TRM）** 部署期/在线持续估计各翻译层的实际残差，与证书声明值比对；若实际残差 > 声明残差 × (1+ρ) 连续超阈 ⇒ 判定该层证书**已失效**（domain drift / 投毒），立即回退该层源并冻结相关指标。**这是 R72 运行时监控器 RTM 在翻译层的对偶：证书不是签一次就永久有效，必须被在线证伪。**

**定义 383（语言/蒸馏联合审计集 SEAL-LD）** 密封、隐藏、分层的审计集：跨文化/跨语言指令、方言/口音/省略句、对抗指代、以及蒸馏的**状态 OOD / 语言 OOD / 尾部分位**分层样本。离线评估 `u_instr`、`u_dist` 的覆盖率与校准；在线只看见「通过位」。**审计集的代表性是整条信任链的隐含根——必须被显式声明其覆盖范围。**

**定义 384（指令合规的不可伪造性）** 合规证书必须由**控制域/计量域的可信监视器**产生，且包含 `(κ_hash, p_comply, u_comply, 观测证据哈希, 监视器版本)`；**学生模型（LLM/VLA）不得自证合规**（学生只能建议，不能签发合规证书）。**「自己说自己做到了」不是证据。**

**定义 385（有效域的多重交集）** 部署模块的有效域取多重交集：
`D_deploy = D_EMB ∩ D_dist^{(state×lang)} ∩ D_T ∩ D_ground`。
任一为空 ⇒ 该模块该指令下不可用，回退。**有效域不是装饰，是「能不能用」的硬门。**

**定义 386（R73 证书的自反性边界）** `J_LDG` 只保证「相对于被声明且被审计的翻译残差模型」的安全；**证书的效力上界 = 审计集覆盖范围 × 残差模型正确性**。任何超出该覆盖的使用都**不在证书效力内**。**这是防止「证书递归自证」的显式边界条款。**

# IP-295 ILM：指令计量四分量（计量域，软实时）
def instruction_metrology(parse_forest, grounding_dist, comply_monitor):
    u_sem    = entropy(parse_forest)                      # 语义解析歧义
    u_ground = expected_grounding_error(grounding_dist)   # 指代落地误差
    u_scope  = scope_interval_width(parse_forest)          # 量词/比较级模糊
    u_comply = comply_monitor.uncertainty()                # 合规判定不确定度
    return sqrt(u_sem**2 + u_ground**2 + u_scope**2 + u_comply**2)

# IP-296 ICC：语言 -> 指令契约 κ（计量域，事件触发）
class InstructionContractCompiler:
    def compile(self, utterance, b_scene, psi):
        P = self.parser.parse(utterance)                  # parse forest
        P = self.prune(P, context=self.ctx, credibility=psi)
        K = []
        for p in P.topk(4):
            g  = self.ground(p, b_scene)                  # 指代消解 -> Σ
            k  = Contract(Σ=g.symbols, R=g.ref_map,
                          pre=p.pre, post=p.post, inv=p.safety,
                          Omega=p.open_set)
            feas = self.reachability(k.post, b_scene) and \
                   self.invariant_consistent(k.inv, b_scene)
            K.append((k, feas))
        bK = self.posterior(P, K, b_scene)                # b(κ)
        k_star = argmax(bK)
        u = instruction_metrology(P, self.grounding_dist, self.comply)
        feasible = any(f for _, f in K)
        if (not feasible) or u > TAU_INSTR or len(k_star.Omega) > TAU_OMEGA:
            return ClarifyOrRefuse(k_star, bK, u, reason=...)   # 定义 372
        return AuditedContract(kappa=k_star, b=bK, u_instr=u, feasible=True,
                               tau=self.tchain(utterance, P, K))

# IP-297 ICM：合规监视器（计量域，写入快照）
def compliance_tick(b_t, kappa, H=2.0):
    # 时序逻辑概率估计：◇_{≤H} Φ_post ∧ □ I_safe
    p_post  = prob_eventually(b_t, kappa.post, H)
    p_safe  = prob_always(b_t, kappa.inv)
    p_comply = p_post * p_safe
    u_comply = monitor_uncertainty(b_t, kappa)
    if p_comply < TAU_COMPLY or risk(kappa.inv, b_t) > RISK_BUDGET:
        return Compliance(abort=True, safe_hold=True)
    return Compliance(abort=False, p_comply=p_comply, u_comply=u_comply)

# IP-298 CPD：保证书蒸馏（离线；在线只读证书）
def certificate_preserving_distill(teacher, student, audit_set, J_T, D_T):
    student.fit_offline(teacher, audit_set)               # 输出+弃权分数双蒸馏
    # (i) 校准迁移（保守再校准）
    student.recalibrate(audit_set.calibration, target=teacher.ece)
    # (ii) 弃权区域包含：支配性阈值校准
    student.set_reject_threshold(
        dominance_calibrate(student.reject_scores(audit_set),
                            teacher.reject_scores(audit_set),
                            delta=1e-3))                   # R_S ⊇ R_T
    # (iii) 残差有界（含尾部！）
    u_agree = mean_divergence(student, teacher, audit_set)
    u_cal   = abs(student.ece - teacher.ece)
    u_tail  = quantile_divergence(student, teacher, audit_set, q=0.999)
    u_ood   = ood_boundary_residual(student, audit_set,
                                    state_split=True, lang_split=True)
    u_dist  = sqrt(u_agree**2 + u_cal**2 + u_tail**2 + u_ood**2)
    J_S = J_T.append(u_dist=u_dist, D_dist=min(D_T, audit_set.domain),
                     tau_dist=trace(student, audit_set, teacher, J_T))
    return student, J_S

# IP-299 TAD：两层随时可弃权（控制域 <0.02ms 决策）
def control_with_deferral(x,  S, proxy, J_S, safe_hold, teacher_ch):
    delta = proxy(x)                     # 残差代理（集成方差/OOD/校准残差）
    if delta <= TAU_DEF and J_S.in_domain(x):
        y, cert = S(x), J_S.short_cert(x)          # 学生持证输出
        return y, cert, "student"
    # Deferral：绝不阻塞，先守 safe-hold
    safe_hold.engage(deadline=D_DEF)               # R68 类已认证保持
    if teacher_ch.ready():                          # 异步老师已回
        y, cert = teacher_ch.take()                 # 老师持证输出
        safe_hold.release()
        return y, cert, "teacher"
    return None, J_S.hold_cert(), "safe_hold"       # 超时继续守

# IP-300 L-RISK：语言+蒸馏纳入风险缩放（控制域，硬实时）
def lingua_risk_scale(U_ale, U_epi, H_z, u_tac, u_instr, u_dist, p):
    denom = U_ale + U_epi + H_z + u_tac.total() + u_instr.total() + u_dist
    return max(p.lam_base * (1 + denom / p.lam_scale),
               p.lam_floor * (1 + denom))

# IP-301 TFER：翻译残差代数 + 组合预算
def compose_transfer(T1, T2, B_transfer):
    u = T2.u + T2.L * T1.u                       # Lipschitz 复合上界
    D = T1.D & preimage(T2.D, T1)                 # 有效域交集
    chain = T1.chain + [T2.id]
    if u <= B_transfer:
        return Translated(T2(T1), u=u, D=D, chain=chain)
    return T1.fallback()                          # 超预算 -> 退回源

# IP-302 TRM：翻译残差在线证伪（计量域）
def transfer_residual_monitor(declared_u, realized_buf):
    realized = quantile(realized_buf, 0.999)
    if realized > declared_u * (1 + RHO):
        return CertStatus.invalidated(trigger="domain_drift_or_poison")
    return CertStatus.valid()

# IP-303 LINGUA 主闭环（在 R72 三域上叠加指令层）
def LINGUA_GAUGE_RAS_round(M, obs, audio, tac_frame, utterance):
    # 控制域：学生 + deferral + 语言风险分母
    snap = M.snapshot.read_latest()
    kappa = snap.kappa if snap.kappa else M.last_kappa
    u_instr, u_dist = snap.u_instr, M.J_S.u_dist
    lam = M.lingua_risk_scale(snap.U_ale, snap.U_epi, snap.H_z,
                              snap.tac_ev.u_tac if snap.tac_ev else 0.0,
                              u_instr, u_dist, M.risk_params)
    y_ctrl, cert, src = control_with_deferral(
        obs, M.student, M.proxy, M.J_S, M.safe_hold, M.teacher_ch)
    if src == "safe_hold":
        M.mode = "R68"; return None, lam, M.J_LDG()
    # 计量域：编译指令 + 合规 + 残差证伪
    if M.clock.due_metric():
        kappa_new, bK, u_instr_new = M.icc.compile(utterance, M.b_t, M.psi_hat)
        if isinstance(kappa_new, ClarifyOrRefuse):
            g = M.ervoi.choose_language(M.b_t, M.psi_hat, kappa_new, M.budget)
            if g: M.cia.execute(g)                      # 澄清/解释
            M.mode = "R72"
        else:
            M.last_kappa = kappa_new
        M.icm.update(M.b_t, M.last_kappa)
        M.trm.update(M.J_S.declared_u, M.realized_residual_buf)
        if M.trm.invalidated(): M.J_S = M.J_S.invalidate(); M.mode = "defer_only"
        M.snapshot.write(b_t=M.b_t, kappa=M.last_kappa, u_instr=u_instr_new, ...)
    # 感知域：情绪/触觉/意图观测（同 R72）
    M.aura.update(audio); M.dmem.update(tac_frame, M.last_action)
    return y_ctrl, lam, M.J_LDG()

## 3. 推导

**引理 33（指令契约的组合性）** 设 κ 是若干子句的合取，第 i 个子句的合规监视器对状态是 Lipschitz 常数 `L_i`、不确定度 `u_i`。则整体合规不确定度 `u_comply(κ) ≤ Σ_i L_i·u_i`。证明：合取的概率与 Lipschitz 监视器复合，沿每个子句的扰动用三角不等式累加。系：**「逐子句留证」不是工程洁癖，是让长指令的审计可组合、可定位、可回退的必要条件。**

**引理 34（校准迁移 ⇒ 保守风险缩放）** 若 `ECE_S ≤ ECE_T + ε_cal` 且 `R_S ⊇ R_T`（均在 `D_dist` 上），则对任意 `x∈D_dist`，用「学生 + `u_dist`」得到的 `λ` 不小于用老师得到的 `λ`（当其余项相同）。证明：`u_dist ≥ u_cal ≥ 0` 单调抬高 `λ`；弃权包含确保学生不在老师会弃权处行动。系：**把老师换成学生，只要进 `u_dist` 且守弃权包含，安全侧就只增不减。**

**引理 35（蒸馏残差的尾部支配）** 存在老师 T 与学生 S 使训练集平均分歧 → 0，但在 0.1% 尾部（如罕见接触/罕见指令）分歧为 Θ(1)。证明：构造两个在训练支撑上几乎相同、仅在尾部支撑上相反的分布；KL 均值被尾部测度压小，而分位差不下压。系：**`u_tail` 必须由分位数审计测量，不能由训练损失推断；这是「标准蒸馏」与「保证书蒸馏」的分水岭。**

**引理 36（deferral 活性与有界 safe-hold）** 若 safe-hold 已认证（R68 类）且 `D_def` 有限，则无论老师响应多慢，控制环都能在 `δ_ctrl` 内完成每拍；deferral 不会造成 deadline miss。证明：deferral 分支的第一步是进入有界 safe-hold，不等待；老师返回仅作为可选升级。系：**「等老师」永远不会出现在控制关键路径上。**

**引理 37（翻译代数的安全性单调）** 对任意组合链 `T2∘T1`，若每层带残差界与回退源，则部署系统的安全包络 `S_deploy` 满足 `S_deploy ⊇ S_source`；加入翻译只会收缩状态与提高效率，不会扩大不安全集。证明：当 `x∈D` 且残差 ≤ 预算时用翻译，否则回退到源；两步的安全性均不弱于源（翻译支路有 `u` 抬高 λ，回退支路等于源）。系：**「换便宜翻译」是效率决策，不是安全决策——这正是为什么可以放心蒸馏。**

**定理 27（指令契约可靠性 ⇒ 合规可验证）** 若 κ 经 ICC 审计（`u_instr` 在预算内、可行）且 ICM 在每个控制拍监视，则「指令是否被遵循」是一个运行时**可判定谓词**，其判定误差 ≤ `u_comply`；不存在「系统声称遵循而实际未遵循且未被检出」的静默失败（在监视器有效域内）。**证明重量**：落在 ICM 的传感器可观测性与 `Φ_post` 可验证性上。

**定理 28（保证书蒸馏 ⇒ 安全迁移）** 若 CPD（定义 373）成立，且学生在 `D_dist` 内运行、deferral 策略满足定义 375，则对老师成立的风险界 `ε_T` 对部署学生成立到 `ε_T + L·u_dist`（`L` 为任务风险对输出的 Lipschitz 常数）；且 deferral 触发处的风险不超过老师直接控制的风险。**这是 R72 定理 24 的蒸馏对偶。**

**定理 29（翻译不伤安全 / 回退封闭）** 对由 `T_s2r, T_dist, T_ground` 任意组合且带 `B_transfer` 与回退的系统，其物理执行风险满足
`Risk_deploy ≤ min_over_fallbacks( Risk_source_chain ) + Σ u_i`，
且当所有翻译触发回退时 `Risk_deploy = Risk_source`。**因此「更便宜的翻译」不会挖穿安全包络，只会牺牲效率。** 这把 R72 的「安全单调不减」从退化链推广为**翻译代数**。

**定理 30（严格包含与五层预算有限停止）** 在 A111–A115（ICC 审计有效、CPD 三条件成立、ILM 四分量可测、TFER 残差有界、五层反作用 Lipschitz）下：LINGUA 在退化条件下逐指令等于 EMBODIED/R72/R71/R68（定义 379）；且五层边际成本均有正下界、边际信息增益随交互次数非增，故 ERVOI+澄清联合策略存在有限停止 `n*`。**安全单调不减，效率仅在「指令可落地、学生持证、翻译在预算内」时获益。**

## 6. 本轮最大风险

**一句话**：R73 把安全从「相信一张具身证书」进一步转移到「相信**三层有损翻译各自的残差界**」——但 `T_ground`（语言→契约）、`T_dist`（老师→学生）、`T_s2r`（仿真→实机）的残差**分别**在某审计集上被认证为小，而它们在**真实闭环的联合工作点**上从未被联合观测；一旦审计集本身有偏或被投毒（语言的跨文化分布、蒸馏的尾部与语言 OOD、实机的重尾残差），残差界会系统性偏小，而回退链最终信任的「源/老师/审计集」这个**信任锚点本身可能就是错的**——于是系统会拿着一摞**互相引用、层层盖章、却共同建立在同一个未经证实的审计集上**的证书，把含糊的「差不多」执行成确定的碰撞，事后审计只能看到「每一层翻译当时都在其声明的有效域内、每一份残差都小于预算」，这就是**「对一个错误的对象做了完美的可追溯翻译」**，是比 R72「自信地错可执行性」更深一层的**信任递归风险**。

次级风险与缓解：
1. **联合工作点未被观测** → 增加**翻译联合审计**：不只分层评估，另设「组合工作点」隐藏测试集，直接测量端到端残差；分层残差之和作为**下界**而非估计。
2. **审计集污染/有偏** → `SEAL-LD` 分文化/分语言/分尾部分层 + 审计集哈希与覆盖范围**显式写入证书**；审计集变更即证书失效；引入第三方/对抗性审计。
3. **语言 OOD 表面在分布内** → 语义 OOD 检测（不是词面 OOD）+ 指令注入红队 + 契约不变量硬校验（可疑指令先过 I_safe 一致性再落地）。
4. **学生尾部高置信** → CPD 强制尾部/分位审计（引理 35）+ 弃权包含支配性校准 + 在线 TRM 证伪旧证书。
5. **deferral 坏循环（L4×L1×L2′）** → 五层联合预算与保守上界；deferral 率设硬上限，超限即降级到 R72（不依赖老师）。
6. **澄清过度/不足** → 用 VoI^L 统一裁决「问/猜/拒绝」，安全拒绝始终可用且有界遗憾。
7. **复杂度与证书爆炸** → 设模块上限（|𝒵|≤8、|𝒞|≤5、|𝒦_clause|≤16、翻译链长 ≤3）；每层一条可复算残差证明；复杂度纳入审计指标。

## 2. 形式化定义（要点版）

**定义 366（总览与六不变式）** 指令契约完整性、学生证书完整性、deferral 活性、翻译残差预算、五层反作用预算、严格退化链。**未经审计的语言不得进规划；学生不得在 `D_dist` 外用；控制环绝不阻塞。**

**定义 367（指令契约 κ）** grounded symbols Σ + 指代映射 R + 前/后置 Φ_pre/Φ_post + 安全不变量 I_safe + 欠定集 Ω + 追溯 τ + 四分量 u。**只有 `u_instr` 在预算内、Φ_post 可达、I_safe 无硬冲突的 κ 才可进规划。**

**定义 368（指令计量 ILM）** `u_sem`（解析歧义）、`u_ground`（指代落地）、`u_scope`（量词/比较级模糊）、`u_comply`（合规判定不确定）；四机制独立近似正交，`u_instr²=Σ`。**遗漏 `u_comply` ⇒ 把「无法验证」误当「已验证为真」。**

**定义 369（契约编译器 ICC）** `ℓ→P→剪枝→grounding→{κ_j}→b(κ)∝p(ℓ|κ)p(κ|ctx)p(scene|ground)→可达性∧不变量检查→(κ*,b,u_instr,feasible,Ω)`。不可行/超阈 ⇒ 澄清/拒绝。

**定义 370（合规监视器 ICM）** 每拍估计 `p_comply` 与 `u_comply`；超阈 ⇒ 中止/safe-hold。**「我遵循了」是带证书的谓词。**

**定义 373（CPD）** 三条件（校准迁移 / 弃权包含 / 残差有界含尾部），`J_S=J_T⊕(u_dist,D_dist,τ_dist)`，只允许在 `D_dist` 运行。**计量学校准层级：学生→老师→参考。**

**定义 374（u_dist 四分量）** `u_agree`（平均分歧）、`u_cal`（校准迁移）、`u_tail`（尾部分位）、`u_ood`（状态域外 ⊕ 语言域外）。**语言条件策略的有效域是「状态 × 语言」的子集。**

**定义 375（TAD）** 残差代理 `δ_S>τ_def` 或出域 ⇒ 有界 deferral；`D_def` 内 safe-hold；老师异步返回可升级。**活性 + 安全双保证。**

**定义 376（TFER）** 复合残差与有效域；超 `B_transfer` 回退源。**S2R-UQ / CPD / ILM 皆实例。**

**定义 377（J_LDG）** `Valid ⇔ J_EMB 有效 ∧ κ 在预算 ∧ S∈D_dist ∧ 累计残差≤B_transfer ∧ deferral 活性已证`。

**定义 378（威胁模型 AIC-LDG）** `ℰ_LDG=ℰ_EMB×ℰ_lang×ℰ_dist`：指令注入/对抗指代/语义 OOD/自相矛盾子句；老师投毒/学生后门/审计集污染/域边界探测。**老师不因大而是信任根；审计集可被投毒。**

**定义 379（严格退化链）** 全失效→R68；ILM 失效→澄清/拒绝或 R72；CPD 失效→deferral 老师或 R72；TFER 超预算→只回退出错层；全有效→完整形态。**安全侧只增不减。**

**定义 380（指令修订反作用 L2′）** `κ'~p(κ'|κ,a_robot,g_ask,ψ)`；成本 = KL + λ_κ·𝟙[κ'∉K_safe]。**静默猜测与过度澄清都推高成本。**

**定义 381（deferral 反作用 L4）** `c_reflex^def = λ_def·rate + μ_def·wait + ν_def·𝟙[ψ'∉Ψ_safe]`。**deferral 经 ψ 与指令反馈成坏循环，须五层合算。**

**定义 382（TRM）** 在线残差证伪：实际残差 > 声明×(1+ρ) 连续超阈 ⇒ 该层证书失效、回退、冻结指标。

**定义 383（SEAL-LD）** 密封分层审计集：跨文化/方言/对抗指代/尾部分位/语言 OOD；离线评估覆盖率与校准；在线只看通过位。

**定义 384（合规不可伪造）** 合规证书只能由可信监视器签发，含 `(κ_hash,p_comply,u_comply,证据哈希,版本)`；**学生/LLM/VLA 不得自证合规。**

**定义 385（多重有效域）** `D_deploy=D_EMB∩D_dist^{(state×lang)}∩D_T∩D_ground`；任一为空 ⇒ 该指令下该模块不可用。

**定义 386（证书自反性边界）** 证书效力上界 = 审计覆盖 × 残差模型正确性；超覆盖使用不在效力内。**防「证书递归自证」。**

# IP-295 ILM：指令计量四分量（计量域，软实时）
def instruction_metrology(parse_forest, grounding_dist, comply_monitor):
    u_sem    = entropy(parse_forest)
    u_ground = expected_grounding_error(grounding_dist)
    u_scope  = scope_interval_width(parse_forest)
    u_comply = comply_monitor.uncertainty()
    return sqrt(u_sem**2 + u_ground**2 + u_scope**2 + u_comply**2)

# IP-296 ICC：语言 -> 指令契约 κ（计量域，事件触发）
class InstructionContractCompiler:
    def compile(self, utterance, b_scene, psi):
        P = self.prune(self.parser.parse(utterance), self.ctx, psi)
        K = []
        for p in P.topk(4):
            g = self.ground(p, b_scene)                 # 指代消解 -> Σ
            k = Contract(Σ=g.symbols, R=g.ref_map,
                         pre=p.pre, post=p.post, inv=p.safety,
                         Omega=p.open_set)
            feas = self.reachability(k.post, b_scene) and \
                   self.invariant_consistent(k.inv, b_scene)
            K.append((k, feas))
        bK = self.posterior(P, K, b_scene)
        k_star = argmax(bK)
        u = instruction_metrology(P, self.grounding_dist, self.comply)
        if (not any(f for _, f in K)) or u > TAU_INSTR \
           or len(k_star.Omega) > TAU_OMEGA:
            return ClarifyOrRefuse(k_star, bK, u, reason=...)
        return AuditedContract(kappa=k_star, b=bK, u_instr=u, feasible=True,
                               tau=self.tchain(utterance, P, K))

# IP-297 ICM：合规监视器（计量域，写快照）
def compliance_tick(b_t, kappa, H=2.0):
    p_post   = prob_eventually(b_t, kappa.post, H)      # ◇_{≤H} Φ_post
    p_safe   = prob_always(b_t, kappa.inv)              # □ I_safe
    p_comply = p_post * p_safe
    u_comply = monitor_uncertainty(b_t, kappa)
    if p_comply < TAU_COMPLY or risk(kappa.inv, b_t) > RISK_BUDGET:
        return Compliance(abort=True, safe_hold=True)
    return Compliance(abort=False, p_comply=p_comply, u_comply=u_comply)

# IP-298 CPD：保证书蒸馏（离线；在线只读证书）
def certificate_preserving_distill(teacher, student, audit_set, J_T, D_T):
    student.fit_offline(teacher, audit_set)             # 输出 + 弃权分数双蒸馏
    student.recalibrate(audit_set.calibration, target=teacher.ece)   # (i)
    student.set_reject_threshold(                        # (ii) R_S ⊇ R_T
        dominance_calibrate(student.reject_scores(audit_set),
                            teacher.reject_scores(audit_set), delta=1e-3))
    u_agree = mean_divergence(student, teacher, audit_set)           # (iii)
    u_cal   = abs(student.ece - teacher.ece)
    u_tail  = quantile_divergence(student, teacher, audit_set, q=0.999)
    u_ood   = ood_boundary_residual(student, audit_set,
                                    state_split=True, lang_split=True)
    u_dist  = sqrt(u_agree**2 + u_cal**2 + u_tail**2 + u_ood**2)
    return student, J_T.append(
        u_dist=u_dist, D_dist=min(D_T, audit_set.domain),
        tau_dist=trace(student, audit_set, teacher, J_T))

# IP-299 TAD：两层随时弃权（控制域 <0.02ms 决策）
def control_with_deferral(x, S, proxy, J_S, safe_hold, teacher_ch):
    delta = proxy(x)
    if delta <= TAU_DEF and J_S.in_domain(x):
        return S(x), J_S.short_cert(x), "student"
    safe_hold.engage(deadline=D_DEF)                    # 绝不阻塞，先守
    if teacher_ch.ready():
        y, cert = teacher_ch.take()
        safe_hold.release()
        return y, cert, "teacher"
    return None, J_S.hold_cert(), "safe_hold"

# IP-300 L-RISK：语言 + 蒸馏纳入风险缩放（控制域，硬实时）
def lingua_risk_scale(U_ale, U_epi, H_z, u_tac, u_instr, u_dist, p):
    denom = U_ale + U_epi + H_z + u_tac.total() + u_instr.total() + u_dist
    return max(p.lam_base * (1 + denom / p.lam_scale),
               p.lam_floor * (1 + denom))

# IP-301 TFER：翻译残差代数 + 组合预算
def compose_transfer(T1, T2, B_transfer):
    u = T2.u + T2.L * T1.u                              # Lipschitz 复合
    D = T1.D & preimage(T2.D, T1)
    chain = T1.chain + [T2.id]
    if u <= B_transfer:
        return Translated(T2(T1), u=u, D=D, chain=chain)
    return T1.fallback()                                # 超预算 -> 退回源

# IP-302 TRM：翻译残差在线证伪（计量域）
def transfer_residual_monitor(declared_u, realized_buf):
    realized = quantile(realized_buf, 0.999)
    if realized > declared_u * (1 + RHO):
        return CertStatus.invalidated(trigger="domain_drift_or_poison")
    return CertStatus.valid()

# IP-303 LINGUA 主闭环（叠加在 R72 三域上）
def LINGUA_GAUGE_RAS_round(M, obs, audio, tac_frame, utterance):
    # ===== 控制域 (1kHz, 硬实时) =====
    snap = M.snapshot.read_latest()
    kappa = snap.kappa if snap.kappa else M.last_kappa
    lam = M.lingua_risk_scale(
        snap.U_ale, snap.U_epi, snap.H_z,
        snap.tac_ev.u_tac if snap.tac_ev else 0.0,
        snap.u_instr, M.J_S.u_dist, M.risk_params)
    y_ctrl, cert, src = control_with_deferral(
        obs, M.student, M.proxy, M.J_S, M.safe_hold, M.teacher_ch)
    if src == "safe_hold":
        M.mode = "R68"; return None, lam, M.J_LDG()

    # ===== 计量域 (50Hz, 软实时) =====
    if M.clock.due_metric():
        kappa_new, bK, u_instr = M.icc.compile(utterance, M.b_t, M.psi_hat)
        if isinstance(kappa_new, ClarifyOrRefuse):
            g = M.ervoi.choose_language(M.b_t, M.psi_hat, kappa_new, M.budget)
            if g: M.cia.execute(g)                       # 澄清/解释/安全拒绝
            M.mode = "R72"
        else:
            M.last_kappa = kappa_new
        M.icm.update(M.b_t, M.last_kappa)
        M.trm.update(M.J_S.declared_u, M.realized_residual_buf)
        if M.trm.invalidated():
            M.J_S = M.J_S.invalidate(); M.mode = "defer_only"
        M.snapshot.write(b_t=M.b_t, kappa=M.last_kappa,
                         u_instr=u_instr, ...)

    # ===== 感知域 (异步, Best-effort) =====
    M.aura.update(audio)
    M.dmem.update(tac_frame, M.last_action)
    return y_ctrl, lam, M.J_LDG()

## 4. 推导

**引理 33（指令契约组合性）** 合取契约的合规不确定度 `u_comply(κ) ≤ Σ_i L_i·u_i`（各子句监视器 Lipschitz 常数为 `L_i`）。系：逐子句留证使长指令可组合、可定位、可逐句回退。

**引理 34（校准迁移 ⇒ 保守风险缩放）** 若 `ECE_S ≤ ECE_T + ε_cal` 且 `R_S ⊇ R_T`（均在 `D_dist`），则「学生 + `u_dist`」的 λ 不小于「老师」的 λ（其余项相同）。系：**换学生只增安全。**

**引理 35（蒸馏残差尾部支配）** 存在 T/S 使训练平均分歧 → 0，但 0.1% 尾部分歧为 Θ(1)。系：**`u_tail` 必须分位审计，不能由训练损失推断——这是保证书蒸馏与标准蒸馏的分水岭。**

**引理 36（deferral 活性与有界 safe-hold）** safe-hold 已认证且 `D_def` 有限 ⇒ 每拍仍满足 `δ_ctrl`，deferral 不造成 deadline miss。系：**「等老师」永不在控制关键路径上。**

**引理 37（翻译代数安全性单调）** 每层带残差界与回退 ⇒ `S_deploy ⊇ S_source`；加翻译只收缩状态、提高效率，不扩大不安全集。系：**换便宜翻译是效率决策，不是安全决策。**

**定理 27（指令契约可靠性 ⇒ 合规可验证）** κ 经 ICC 审计且 ICM 每拍监视 ⇒ 「是否遵循」是运行时**可判定谓词**，误差 ≤ `u_comply`；在监视器有效域内不存在「声称遵循而实际未遵循且未检出」的静默失败。**证明重量在 ICM 可观测性与 Φ_post 可验证性。**

**定理 28（保证书蒸馏 ⇒ 安全迁移）** CPD 成立且 `S∈D_dist`、deferral 合规则：老师的风险界 `ε_T` 对学生成立到 `ε_T + L·u_dist`；deferral 触发处风险 ≤ 老师直控风险。**R72 定理 24 的蒸馏对偶。**

**定理 29（翻译不伤安全 / 回退封闭）** 任意带 `B_transfer` 与回退的翻译组合：`Risk_deploy ≤ min_over_fallbacks(Risk_source_chain) + Σ u_i`；全回退时 `Risk_deploy = Risk_source`。**「更便宜的翻译」不会挖穿安全包络。**

**定理 30（严格包含与五层预算有限停止）** 在 A111–A115 下：LINGUA 在退化条件下逐指令等于 EMBODIED/R72/R71/R68；五层边际成本有正下界、边际信息增益随交互非增 ⇒ ERVOI+澄清联合策略存在有限停止 `n*`。**安全单调不减，效率仅在「指令可落地、学生持证、翻译在预算内」时获益。**

## 8. 本轮最大风险

**一句话**：R73 把安全从「相信一张具身证书」进一步转移到「相信**三层有损翻译各自的残差界**」——`T_ground`（语言→契约）、`T_dist`（老师→学生）、`T_s2r`（仿真→实机）的残差**分别**在某个审计集上被认证为小，但它们在**真实闭环的联合工作点**上从未被联合观测；一旦审计集本身有偏或被投毒（语言的跨文化分布、蒸馏的尾部与语言 OOD、实机的重尾残差），残差界会系统性偏小，而回退链最终信任的「源 / 老师 / 审计集」这个**信任锚点本身可能就是错的**——于是系统会拿着一摞**互相引用、层层盖章、却共同建立在同一个未经证实的审计集上**的证书，把含糊的「差不多」执行成确定的碰撞；事后审计只能看到「每一层翻译当时都在其声明的有效域内、每一份残差都小于预算」。这就是**「对一个错误的对象做了完美的可追溯翻译」**，比 R72「自信地错可执行性」更深一层的**信任递归风险**。

次级风险与缓解：
1. **联合工作点未被观测** → 增加**翻译联合审计**：除分层评估外，另设「组合工作点」隐藏测试集直接测量端到端残差；分层残差之和作为**下界**而非估计。
2. **审计集污染/有偏** → `SEAL-LD` 分文化/分语言/分尾部分层 + 审计集哈希与覆盖范围**显式写入证书**；审计集变更即证书失效；引入第三方/对抗性审计。
3. **语言表面在分布内但语义 OOD** → 语义 OOD 检测（非词面 OOD）+ 指令注入红队 + 契约不变量硬校验（可疑指令先过 I_safe 一致性再落地）。
4. **学生尾部高置信** → CPD 强制尾部/分位审计（引理 35）+ 弃权包含支配性校准 + 在线 TRM 证伪旧证书。
5. **deferral 坏循环（L4×L1×L2′）** → 五层联合预算与保守上界；deferral 率设硬上限，超限即降级到 R72（不依赖老师）。
6. **澄清过度/不足** → 用 `VoI^L` 统一裁决「问 / 猜 / 拒绝」，安全拒绝始终可用且有界遗憾。
7. **复杂度与证书爆炸** → 模块上限（|𝒵|≤8、|𝒞|≤5、|𝒦_clause|≤16、翻译链长 ≤3）；每层一条可复算残差证明；复杂度纳入审计指标。
