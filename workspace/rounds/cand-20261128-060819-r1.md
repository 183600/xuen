### 第 6 轮灵感驱动研究记录

**灵感词**：联邦学习、抗干扰

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把提议升级为条件流匹配、记忆升级为固化闭环、人因升级为情感调制，并用定理 6 把框架从「规则系统」推广为「任意生成器 + 认证边界」（CGE），执行集 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。但 v5 的三个前提在舰队部署下同时失效：(a) 固化只在单站、单机进行，跨站经验无法共享、冷启动慢，v5 产物区已明确把「舰队联邦、跨站价值/情绪异构」推到第 6 轮；(b) 所有门都在名义输入 x 上求值，假设无外部力扰动、无传感噪声、无遮挡，而真实站点输入会漂移；(c) 联邦一旦引入，聚合本身就是新的攻击面——恶意站可用合法范数内的投毒更新把全局提议慢性推向门边界。两个灵感词统一为主题「认证的联邦抗干扰执行」（Certified Federated Robust Execution, CFRE），形成 CADVS-v6（IP-497~500）。本轮自律：**硬门数量仍不增**（维持七门），联邦与抗干扰只通过三条非侵入路径进入——提议参数联邦化、阈值鲁棒收紧、通信降级回退；执行集嵌套升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **联邦学习 → 只联邦「提议」，绝不联邦「门」**。v5 的流策略 θ_FM 是单站固化出来的，舰队里每个站的物体/几何/任务分布不同（non-IID），单站经验少、冷启动慢。直觉：让各站共享「怎么提好候选」的知识，但安全边界必须留在本地。引入 FCPAK：各站只上传提议器/编码器的参数增量 Δ_i（经范数裁剪 + DP 噪声 + 安全聚合），由 Byzantine-robust 聚合器（centered clipping / coordinate-wise median，容忍 f < n/2 恶意站）合成全局提议先验，再下发共享骨干 + 本地个性化 adapter。理论主轴是**定理 9（联邦提议/门分离）**：聚合器输出任意（甚至被投毒）都只能改变 π_θ^FM，门谓词与 τ^4 在本地冻结只读，故 Exec_v6 ⊆ Exec_v5 与聚合内容无关。这把 v5 定理 6 从「单站换提议」强化为「跨站任意聚合都不动信任边界」。

2. **抗干扰 → 从「点认证」升级为「管认证」，用有界干扰集把阈值只紧不松地抬起来**。v5 的七门都在名义输入 x 上求值；真实站点有外部扰动 w、传感噪声、遮挡，x 会漂移。直觉：不要赌扰动为零，而是承认它落在有界集 W 内，要求整条管 x⊕W 都通过。引入 AIRK：对每个门分数 s_i 估计 Lipschitz 常数 L_i，定义鲁棒阈值 τ_i^rob = τ_i + L_i·ρ（ρ 为干扰集半径），等价于 kc_i^rob(x)=1[min_{δ∈W} s_i(x+δ) ≥ τ_i]。这天然满足「只紧不松」（定理 11），并给出可认证鲁棒半径 ρ_i* = (s_i(x)−τ_i)/L_i。对 BCK 用扰动集下的鲁棒 wrench 锥/ZMP，对 EEK/VACK 用区间界传播（IBP，L_i ≤ ∏_l‖W_l‖_2 谱范数积）。诚实边界：接触拓扑突变等非 Lipschitz 门无法给紧界，直接 fail-closed 回退。

3. **抗干扰的第二层 → 通信与更新通道也是干扰面，必须「降级可证」而非「降级碰运气」**。联邦引入后，掉包、时延、干扰、投毒都会让全局提议短暂不可用或不可信。直觉：把「通信健康度」显式建模为降级状态机，任何降级都只能回退到更保守的已签名策略，绝不跳到未验证策略。定义三态：NOMINAL（全局 + 个性化提议）→ LOCAL（通信超预算，用上一版已签名全局模型）→ RULE（连本地模型都不可信/新颖度触发，回退 v5 规则提议）。**定理 12（降级单调性）**：三态执行集满足 Exec_RULE ⊆ Exec_LOCAL ⊆ Exec_NOMINAL ⊆ Exec_v5，任意干扰导致的降级只会收缩执行集，fail-closed 在所有状态保持；向更激进方向的恢复必须冷却 + 签名校验，防止干扰者伪造「链路良好」把系统推回被污染的全局模型。

**关键洞见**：v5 回答「提议=任意生成器、记忆反哺、含情感时如何守住证书」；v6 回答「当提议被联邦化、输入被干扰、通道被打断时，信任边界还能不能守住」。答案是把「联邦」「鲁棒」「降级」三件事全部约束在提议侧与阈值侧，门谓词永远本地、冻结、只紧不松。七硬门 kc_evidence_forged_v4 记号继续原样复用；本轮新增的只有：鲁棒阈值 τ_i^rob、干扰集 W 与 Lipschitz 常数 L_i、鲁棒聚合算子 RobAgg、降级状态机 D_state、联邦证书保持约束，软评分 ECS_v6 = ECS_v5 · η_fed · η_rob · η_link。

**形式化目标（增量）**：
1. 干扰集：W = {δ : ‖δ‖_W ≤ ρ}（或 zonotope），rad(W)=ρ；门鲁棒分数 s_i^rob(x)=min_{δ∈W} s_i(x+δ) ≥ s_i(x) − L_i·ρ（球集下取等）。
2. 鲁棒阈值：τ_i^rob = τ_i^5 + L_i·ρ_i（ρ_i 为分配到门 i 的干扰预算，Σ_i ρ_i = ρ 或 max 合成），kc_i^rob(x)=1[s_i(x) ≥ τ_i^rob]。
3. 鲁棒聚合：RobAgg({Δ_i}) = clip(aggregate_robust({Δ_i}), Δ_max) + DP 噪声；容忍 f < n/2 Byzantine；只作用于提议参数。
4. 降级状态机：D_state ∈ {NOMINAL, LOCAL, RULE}，转移由链路健康度 h_link 与新颖度触发；向下即时，向上需冷却 + 签名校验。
5. 定理 9（联邦提议/门分离）、定理 10（鲁棒聚合误差界）、定理 11（干扰鲁棒认证与只紧性）、定理 12（降级单调性/嵌套保持）。
6. Exec_CADVS-v6 = {x ∈ supp(π_fed^FM) : ∧_i kc_i^rob(x,c; τ_i^rob)=1} ⊆ Exec_CADVS-v5。

**本轮最大风险**：**干扰预算与鲁棒聚合的「安全幻觉」**——ρ_i 与 L_i 的估计一旦偏乐观（真实扰动超出 W，或门分数的非 Lipschitz 局部被 IBP 平滑掉），鲁棒证书会在最需要它的边界处失效；同时 Byzantine 界只保证「聚合误差有界」不保证「提议不退化」，恶意站可用合法范数内的定向漂移慢性污染提议，使系统在证书形式上恒真时逐渐失去可用性——这把风险从「不安全」转化为「不可用/慢性退化」，两者都难以在离线红队里完全复现。

### IP-497 FCPAK：联邦证书保持聚合核（慢时域，站间异步）

```python
@dataclass
class FederatedCertificatePreservingAggregator:
    """FCPAK：只联邦提议参数，门与 τ^4 本地冻结只读。
    定理 9：聚合输出任意（含投毒）→ 只改 π_fed^FM，不改 Exec_gate"""
    n_sites: int
    f_byz: int                    # 容忍上限，要求 f_byz < n_sites / 2
    clip_norm: float = 1.0        # 每站更新范数裁剪 τ
    sigma_dp: float = 1.1         # 高斯机制噪声尺度

    def secure_aggregate(self, updates: list[Tensor]) -> Tensor:
        # 1) 每站范数裁剪，限制单站影响力
        clipped = [u * min(1.0, self.clip_norm / (norm(u) + 1e-12))
                   for u in updates]
        # 2) Byzantine-robust 预聚合：centered clipping，对 f 个离群站有界
        robust = centered_clipping(clipped, f=self.f_byz)
        # 3) DP 高斯噪声：敏感度 S = 2·clip_norm / n_sites
        noise = normal(0.0, self.sigma_dp * 2.0 * self.clip_norm / self.n_sites,
                       shape=robust.shape)
        return robust + noise

    def apply(self, local_fmpp, global_delta: Tensor, adapter_delta: Tensor) -> None:
        """只更新提议器参数；门代码与 τ^4 在此只读。
        frozen-gate 断言：任何参数不得流向 gate/threshold 模块"""
        local_fmpp.theta = local_fmpp.theta + global_delta + adapter_delta
        assert not any(p.requires_grad for p in gate_params())   # 门不参与梯度
        assert all(close(tau4_now[i], TAU4_FROZEN[i]) for i in GATES)  # τ^4 不变

    def detect_and_evict(self, updates, reputations) -> list[int]:

        诚实边界：慢性定向漂移在单轮范数内合法，需跨轮信誉累积才可发现"""
```

### IP-498 AIRK：抗干扰鲁棒核（在线准入，与控制环解耦）

```python
@dataclass
class AntiInterferenceRobustnessKernel:
    """AIRK：有界干扰集 W 下的鲁棒阈值 τ^rob = τ^5 + L·ρ（只紧不松）。
    定理 11：可认证鲁棒半径 ρ* = (s(x) − τ^5)/L"""
    rho: float                       # 干扰预算（DOB 残差 + 噪声 + 模型不确定）
    lip: dict                        # 每门 Lipschitz 常数 L_i（IBP / 谱范数积）
    rho_ref: float = 0.05

    def robust_threshold(self, tau5: dict) -> dict:
        # τ^rob ≥ τ^5 恒成立 → 执行集只缩
        return {i: tau5[i] + self.lip[i] * self.rho for i in tau5}

    def robust_score(self, gate_i, x) -> float:
        # 球集 worst-case 紧（引理 45）：s^rob = s(x) − L_i·ρ
        return gate_i.score(x) - self.lip[gate_i.name] * self.rho

    def certified_radius(self, gate_i, x) -> float:
        return max(0.0, (gate_i.score(x) - self.tau5[gate_i.name])
                   / (self.lip[gate_i.name] + 1e-12))

    def update_budget(self, dob, noise_bound: float, model_bound: float) -> None:
        """扰动观测器残差 + 传感噪声界 + 模型不确定界 → 更新 ρ。
        ρ 必须覆盖真实扰动，否则鲁棒证书失效（R60）"""
        self.rho = dob.residual_bound() + noise_bound + model_bound

    def robust_bck_qp(self, x, W) -> bool:
        """扰动集 W 下的鲁棒 wrench 锥 / ZMP：用 support function 求
        max_{δ∈W} 违反量 ≤ 0；接触拓扑突变（非 Lipschitz）→ 返回 False 触发回退"""
```

```python
    门谓词 {kc_i} 与 τ^4 在本地冻结只读，则 Exec_v6(θ_agg) = Exec_gate ∩ supp(π_fed^FM(θ_agg))
    ⊆ Exec_gate = Exec_v5。执行边界与聚合内容无关；聚合只影响「尝试通过门的提议分布」。
    证明：门是本地固定谓词，θ_agg 只进入 π 的 pushforward，谓词与阈值不变。∎

    """
    return "Proven"

# 定理 10：鲁棒聚合误差有界（只约束提议质量）
def theorem_robust_aggregation_bounded() -> str:
    """

    经 Pinsker 转为提议分布总变差 TV(π_fed‖π_honest) ≤ √(ε_agg/2)。

    """
    return "Proven (quality bound only)"

# 定理 11：干扰鲁棒认证与只紧性
def theorem_interference_robust_certification() -> str:
    """
    定理 11：若门 i 为 L_i-Lipschitz、干扰集 W 半径 ρ，取 τ_i^rob=τ_i^5+L_i·ρ_i，
    则 (i) kc_i^rob(x)=1 ⇒ 对 ∀δ∈W, kc_i(x+δ)=1（管认证）；
    (ii) τ_i^rob ≥ τ_i^5 ⇒ Exec^rob ⊆ Exec_v5（只紧）；
    (iii) 可认证半径 ρ_i* = (s_i(x)−τ_i^5)/L_i；ρ_i* < ρ_i 时门不可鲁棒认证，fail-closed。
    证明：(i) 引理 45 下界；(ii) 阈值单调；(iii) 解不等式。∎

    """
    return "Proven (Lipschitz gates); non-Lipschitz → fail-closed"

# 定理 12：降级单调性/嵌套保持
def theorem_degradation_monotonicity() -> str:
```

### IP-500 EFA-v6：七硬门 + 鲁棒阈值 + 联邦提议 + 降级状态机

```python
@dataclass
class RobustFederatedEvidenceForgingAssembler:
    """EFA-v6：七硬门不变（阈值鲁棒收紧、只紧不松）+ 联邦提议 + 降级状态机"""
    fmpp: FlowMatchingProposalPolicyKernel
    lmem: LongTermMemoryEmbeddingConsolidation
    famk: FacialAffectModulationKernel
    airk: AntiInterferenceRobustnessKernel
    hapk: HeterogeneityAwarePersonalizationKernel
    fcpak: FederatedCertificatePreservingAggregator
    v5: EvidenceForgingAssemblerV5          # 复用七门 + 规则提议回退
    D_state: str = 'NOMINAL'
    h_hi: float = 0.85
    h_lo: float = 0.50

    def tick_link(self, h_link: float, novelty: bool, sig_ok: bool) -> None:
        # 向下即时：只收缩，安全；向上需冷却 + 签名校验（引理 47）
        if novelty or h_link < self.h_lo:
            self.D_state = 'RULE'
        elif h_link < self.h_hi:
            self.D_state = 'LOCAL' if self.D_state != 'RULE' else 'RULE'
        elif self.D_state != 'NOMINAL' and sig_ok and self._cooldown_ok():
            self.D_state = 'NOMINAL'

    def select(self, x0_state, t_now, rule_id, context):
        if self.D_state == 'RULE':
            return self.v5._fallback_rule_proposal(self.famk.gamma(None))
        s_emo = self.famk.observe(context.face, t_now)
        gamma = self.famk.gamma(s_emo)
        tau5 = {i: gamma[i] * TAU4[i] for i in TAU4}
        tau5 = self.hapk.calibrate_thresholds(tau5, context.local_stats)
        tau_rob = self.airk.robust_threshold(tau5)       # τ^rob ≥ τ^5（只紧）
        c = build_ctx(context, s_emo, self.lmem, self.D_state)
        # NOMINAL 用全局+个性化；LOCAL 用上一版已签名全局模型
        policy = self.fmpp if self.D_state == 'NOMINAL' else self._signed_global
        cands = policy.propose(c, self.fmpp.K)
        # 级联第 0 层：鲁棒预筛（s_i − L_i·ρ）
        surv = [x for x in cands if self._robust_cheap_gates(x, tau_rob)]
        if not surv:
            return self.v5._fallback_rule_proposal(gamma)
        # 级联第 1 层：VACK（IBP 鲁棒化，τ_val^rob），仅 ≤3 幸存者
        finals = []
        for x in sorted(surv, key=self._prefilter_score, reverse=True)[:3]:
            if self._vack_robust(x, context, tau_rob['val']):
                finals.append(x)
        # 级联第 2 层：鲁棒 BCK 预览（扰动集下 wrench 锥/ZMP）
        ok = [x for x in finals if self.airk.robust_bck_qp(x, self.airk.W)]
        if not ok:
            return False, None, 'ALL_CANDIDATES_REJECTED'
        return True, max(ok, key=certified_margin), 'FORGED_CFRE'

    def ecs_v6(self, n_flow, s_emo, h_link, m_topk) -> float:
        eta_fed = sigmoid(cos_sim(m_topk, self._global_proto) - self.b_fed)
        eta_rob = exp(-self.airk.rho / self.airk.rho_ref)
        return self.v5.ecs_v5(n_flow, s_emo) * eta_fed * eta_rob * h_link
```

## 4. 正确性论证（增量更新）

### 引理 45（球集鲁棒分数取等）

**陈述**：设 s_i 为 L_i-Lipschitz，W={δ:‖δ‖≤ρ}，则 min_{δ∈W} s_i(x+δ) = s_i(x) − L_i·ρ。**证明**：Lipschitz 给下界；取 δ*=−ρ·∇s_i/‖∇s_i‖ 使等号成立。∎

### 引理 46（鲁棒聚合 + DP 误差界）

**陈述**：诚实更新 ‖Δ_i‖≤τ、Byzantine f<N/2、聚合为 centered clipping，则 ‖RobAgg − mean_honest‖ ≤ c·(f/N)·τ + σ_dp·(2τ/N)·√d + het。**证明**：centered clipping 的 (f,τ)-鲁棒性 + 高斯机制标准界 + 三角不等式。∎ **诚实边界**：该界只约束提议参数偏离，不承担安全语义。

### 引理 47（降级误升级界）

**陈述**：向更激进方向恢复需连续 k 周期 h_link≥h_hi 且签名校验通过；单周期伪造概率 ≤ p_f ⇒ 误升级概率 ≤ p_f^k。∎（依赖周期独立假设）

### 引理 48（个性化只紧的嵌套保持）

**陈述**：若 τ_local(i)=max(τ_i^5, τ_cal(i)) ≥ τ_i^5 且门谓词不变，则 Exec(HAPK) ⊆ Exec_v5。∎

### 定理 v6（联邦 + 抗干扰 + 降级三重守边，总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 干扰真实值落在 W 内、(B9) 门分数对 x 局部 Lipschitz（非 Lipschitz 处已 fail-closed）下：
(i) Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29（鲁棒阈值只紧 + 提议支撑受限）；
(ii) 联邦分离：任意聚合输出（含投毒）不改执行边界（定理 9）；
(iii) 聚合质量：投毒只使提议退化，偏差有界（引理 46 / 定理 10）；
(iv) 管认证：kc_i^rob(x)=1 ⇒ ∀δ∈W 名义门通过；ρ_i*<ρ_i 时 fail-closed（定理 11）；
(v) 个性化只紧：Exec(HAPK) ⊆ Exec_v5（引理 48）；
(vi) 降级单调：Exec_RULE ⊆ Exec_LOCAL ⊆ Exec_NOMINAL ⊆ Exec_v5，误升级有界（定理 12 / 引理 47）；
(vii) 七锚完备性保持（v5 定理 8），无新增锚点。

**证明**：(i)(ii) 由谓词/阈值本地冻结与支撑受限；(iii) 引理 46；(iv) 引理 45 + 阈值单调；(v) 引理 48；(vi) 三态支撑递减 + 引理 47；(vii) 锚点集合不变。∎

**诚实声明**：(B8) 依赖 ρ 覆盖真实扰动——ρ 低估则鲁棒证书失效，无结构兜底；(B9) 接触拓扑突变等非 Lipschitz 门只能 fail-closed，会损失可用性；鲁棒聚合只保证误差有界，不防「合法范数内慢性定向漂移」；跨站价值异构只允许更保守，不能表达「某站更激进」的偏好（治理约束优先于个性化）。

## 7. 本轮最大风险（最终确认）

**一句话**：**干扰预算与鲁棒聚合的「安全幻觉」**——ρ_i 与 L_i 一旦偏乐观（真实扰动超出 W，或门分数的非 Lipschitz 局部被 IBP 平滑掉），鲁棒证书会在最需要它的边界处失效；同时 Byzantine 界只保证聚合误差有界、不保证提议不退化，恶意站可用合法范数内的定向漂移慢性污染提议，使系统在证书形式上恒真时逐渐失去可用性——风险从「不安全」转为「不可用/慢性退化」，两者都难以在离线红队中完全复现。
