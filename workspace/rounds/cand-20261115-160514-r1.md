# 第 8 轮（新灵感循环第 1 轮；本轮灵感：「数据规模」×「指令泛化」）

> **基线**：第 7 轮 MetricVoiceGauge-OTL-GC-ER（定义 493–529；引理 73–76；实验 E513–E525）。
> 本轮纪律：**泛化是负债，不是能力；数据规模是抵押品，不是燃料**。v8 只把“数据规模”折算成“覆盖证据”：任何指令泛化只有在覆盖账本（Coverage Ledger）上留有 ≥ k_min 份见证时才允许执行；无见证者一律降级为骨架或澄清。任一 v8 模块不可用 ⇒ 单跳退回 v7。

## 0. 直觉与动机

**灵感 1（数据规模 → 从“训练燃料”到“认证抵押品”）**
直觉：在感知/语言任务里，“数据越多越好”几乎是信仰。但在安全关键具身系统里，数据规模真正买到的不是“更强的模型”，而是**“更大范围内、以更高置信度说‘这条指令我能正确接地’”的资格**。模型参数变多只改变“平均表现”，而认证关心的是“这一次、这条组合、有没有证据”。因此我们拒绝把数据规模直接折算成参数/准确率，而把它折算成一个可消耗、可审计的量：**每一份校准样本，只能为它实际覆盖的那些语义依赖（槽位、关系、动作原语）签发见证**。数据规模由此从“燃料”变成“抵押品”——它决定系统今天被允许泛化到多远，而不是模型上限有多高。

**灵感 2（指令泛化 → 从“能力上限”到“未偿负债”）**
直觉：语音指令是组合性的（“把**红色**积木放进**蓝色**盒子，然后**抓取**扳手”）。泛化能力来自组合，而组合空间会爆炸。最危险的失败不是“听不懂而停下”，而是**模型对从未见过的组合给出高置信度的错误接地**——这就是“幻觉泛化”。所以泛化不是越多越好的“能力”，而是一笔**未偿负债（semantic liability）**：每向外推一步，就多欠一份尚未被证据覆盖的风险。安全系统的任务不是消除负债，而是**让负债始终低于可接受的抵押额度**。

**交叉直觉（覆盖账本：用数据规模给泛化上信用额度）**
把两个灵感拧在一起，得到 **MetricVoiceGauge-SCIG（Scale-Certified Instruction Generalization，规模校准的指令泛化）**。它把“数据规模 → 泛化”的隐含假设显式化为一个账本：
- **借方**：每次执行一条泛化指令，都消耗“覆盖信用”；
- **贷方**：每份校准/示教数据，为其依赖图上的节点与边记入见证；
- **风控**：用分布无关的共形预测给出接地预测集 `C_α(ℓ)`；只要预测集不是单点、或依赖图上存在“见证不足”的边，就**不允许签发泛化证书**，而退化为安全骨架或主动请求澄清。

关键洞察：**在分布漂移下，共形覆盖会悄悄失效**。所以覆盖率不能只看“名义 α”，必须用**组合依赖图上的未见质量**去近似漂移，并把它变成可执行的降级判据。数据规模的另一重作用随之显现：它不仅要“覆盖高频指令”，还要通过**主动补账**优先买下长尾高风险组合——把数据花在账本最薄的边上。

## 1. 研究问题（轮次升级版）

- **Q1（规模→证书）**：如何把数据规模 `n` 严格折算为分布无关的语义覆盖证书——即给定校准集，对任意新指令输出预测集 `C_α(ℓ)`，使 `P(ι* ∈ C_α(ℓ)) ≥ 1−α`，并让证书宽度 `r_α(n)` 随 `n` 有可预注册的收缩律？
- **Q2（组合覆盖与漂移）**：如何在受控指令语法上计算“依赖图覆盖度”`ρ(ℓ)`，使其 ① 能捕捉“词都认识、组合没见过”的 OOD 组合；② 当部署分布偏离校准时，用未见质量给共形覆盖打上“已失效”的告示，而不是继续自信执行？
- **Q3（门控与补账）**：如何把覆盖边界变成运行时门控（执行 / 骨架 / 澄清），并把被拒绝的指令转化为**主动补账**请求，使数据规模的增长与长尾泛化需求形成闭环，同时保证 v8 对系统可行集只做“交（收紧）”？

## 2. 设计原则（在 P7–P9 基础上升级为 P10–P12）

**P10 语义覆盖证书（Semantic Coverage Certificate, SCC）**
指令到指令规格的接地映射记为 `g_θ: L → I`，真值记为 `g*(ℓ)`。在校准集 `D_n = {(ℓ_k, ι*_k)}_{k=1}^n`（独立同分布于部署分布 `P`）上计算非一致性分数 `s(ℓ, ι) = d(g_θ(ℓ), ι)`。取
```
q̂ = ⌈(n+1)(1−α)⌉-th smallest of { s(ℓ_k, ι*_k) }
C_α(ℓ) = { ι ∈ I : s(ℓ, ι) ≤ q̂ }
```
则对与校准集可交换的新样本，`P(g*(ℓ) ∈ C_α(ℓ)) ≥ 1−α`。证书不是“模型很确定”，而是“**在这一置信水平下，可能正确的接地都在这个集合里**”。若 `⌈(n+1)(1−α)⌉ > n`，则证书不可签发（数据规模不足以支撑该 α）。

**P11 组合覆盖账本（Compositional Coverage Ledger, CCL）**
把受控指令语言写成产生式图 `G = (V, E)`：`V` 是语义槽（对象/颜色/关系/动作/修饰），`E` 是组合边。每条指令 `ℓ` 由解析器导出依赖集 `dep(ℓ) ⊆ V ∪ E`。账本按校准样本记账：
```
cov_n(x) = #{ k : x ∈ dep(ℓ_k) },     x ∈ V ∪ E
ρ(ℓ)     = min_{x ∈ dep(ℓ)} min(1, cov_n(x) / k_min)
```
`k_min` 为预注册见证门槛（例如 3）。`ρ(ℓ)=1` 当且仅当 `ℓ` 的**整条依赖路径**都被至少 `k_min` 份真实样本见证。这样，“认识每个词”不等于“见过这种组合”：只要有一条边见证不足，`ρ<1`。

**P12 泛化门控与主动补账（Coverage-Gated Execution + Active Accrual, CGA）**
运行时三态门控：
```
GATE(ℓ) =
  EXECUTE   若 |C_α(ℓ)| = 1 且 ρ(ℓ) = 1 且 Λ(ℓ) ≤ L_cap
  SCAFFOLD  若 |C_α(ℓ)| > 1 且 ∃ ι_s ∈ C_α(ℓ) ∩ I_scaffold，ρ(dep(ℓ_s)) = 1
  CLARIFY   其它
```
其中 `Λ(ℓ)` 为语义负债（定义 536），`I_scaffold` 是预先认证的安全动作骨架族（只执行动作骨架、推迟具体参数）。`EXECUTE` 是唯一会签发“泛化证书”的路径。被 `CLARIFY` 的指令不丢弃，而进入补账队列，其价值按
```
ν(x) = f(x) · w(x) · (1 − cov_n(x)/k_min)
```
排序（`f` 为部署频率、`w` 为风险权重），贪心选择下一份示教数据；覆盖函数次模 ⇒ 贪心有 `1−1/e` 近似保证。数据规模因此只“长在账本最薄、风险最高的边上”。

## 3. 与基线的接口（如何退化）

- **SCC / CCL / CGA 任一不可用**（模块缺失、超时、校准集为空、`q̂=∞`）⇒ 完全旁路 v8，逐字运行 v7；
- **证书不可签发或 `ρ(ℓ) < 1`** ⇒ 不执行该指令的“泛化版本”，退到 `SCAFFOLD`（安全骨架）或 `CLARIFY`（固定 `ι₀` 并请求澄清）——这比 v7 **更保守**，属于合法精化；
- **v7 的 OTL / GCT / ER 失效** ⇒ 按 v7 声明退回 v6；
- **单向性**：v8 任何结论都不能扩大 v7 已认证的 `M₀/M₁` 可行集；`EXECUTE` 必须同时通过 v7 的硬约束检查，因此 `SCIG ⊆ v7`。

## 4. 预期贡献

1. **语义覆盖证书 SCC**：把“数据规模”从训练燃料改写成分布无关的接地预测集与覆盖半径，给出 `1−α` 覆盖保证与 `n` 依赖的证书收缩律；
2. **组合覆盖账本 CCL**：在受控语法依赖图上度量“词认识但组合没见过”的 OOD，用未见质量近似分布漂移，弥补共形覆盖在 shift 下的静默失效；
3. **泛化门控 CGA**：把泛化从“总是尽量执行”改为“有见证才执行”，三态（执行/骨架/澄清）只收紧可行集，并给出“无免费泛化”（置信度不能替代覆盖）的判据；
4. **主动补账**：把拒绝执行的指令转化为数据采集需求，使数据规模与长尾泛化形成闭环（次模贪心，`1−1/e`）；
5. 完整的 **规模-覆盖-泛化** 三部闭环：E526–E545 覆盖共形校验、覆盖半径规模律、组合 OOD、门控安全、主动补账与实时性。

## 5. 本轮最大风险

**一句话**：整套框架把“泛化资格”押在“校准集与部署可交换（exchangeable）”这一前提上——一旦指令分布发生真实漂移（新物体、新操作员、新句式），共形覆盖的名义 `1−α` 会静默失真，而未见证质量只是漂移的代理指标；最危险的情形是系统凭一份**看似完整、实则过期的覆盖账本**，对真正 OOD 的指令给出单点高置信预测并 `EXECUTE`，即“用一张过期的保单去承保一次从未被承保的风险”。

## 2. 形式化定义（要点）

**定义 530（指令接地与真值）** 接地映射 `g_θ: L → I` 输出类型化指令规格；真值 `g*(ℓ)` 由标注/示教给出。接地距离 `d: I×I → [0,∞)` 在动作原语、目标对象、空间参数、抓取几何四个分量上加权求和，要求 `d(ι,ι)=0` 且满足三角不等式。

**定义 531（共形接地预测集 SCC）** 给定校准集 `D_n` 与失效预算 `α`：
```
k_α   = ⌈(n+1)(1−α)⌉
q̂_α   = 第 k_α 小的 { s(ℓ_k, ι*_k) }        （若 k_α > n，则 q̂_α = +∞）
C_α(ℓ)= { ι ∈ I : s(ℓ, ι) ≤ q̂_α }
```
**若 `q̂_α = +∞`，视为“数据规模不足以签发证书”**，`C_α` 不定义（门控必走 `CLARIFY`）。

**定义 532（覆盖半径与数据规模律）** `r_α(ℓ;n) = diam(C_α(ℓ))`。在参数化平滑接地模型下，`E[r_α(n)] = Θ(n^{-1/2})`；在 `d` 维 Hölder-`β_s` 光滑非参数模型下 `E[r_α(n)] = O(n^{-β_s/(2β_s+d)})`。据此定义**反向规模需求**：
```
n_need(ε) = min{ n : E[r_α(n)] ≤ ε }
```
即“要把证书宽度压到 `ε`，至少需要多少份数据”。

**定义 533（组合依赖图 CDG）** 受控语法 `G=(V,E)`，解析器 `dep: L → 2^{V∪E}`。依赖图满足：`dep(ℓ)` 覆盖 `ℓ` 的每个词法槽与每次槽间组合；`ℓ` 用到的组合边必须同时在 `dep(ℓ)` 中。

**定义 534（覆盖账本与覆盖度 CL）** 账本维护见证计数 `cov_n(x)`，仅由**已核验的真实样本**（校准集或用户澄清/示教）记账，禁止由模型自预测记账：
```
cov_n(x) = #{ k : x ∈ dep(ℓ_k) }
ρ(ℓ)     = min_{x∈dep(ℓ)} min(1, cov_n(x)/k_min)
μ(ℓ)     = 1 − ρ(ℓ)
```
`ρ(ℓ)=1` 表示 `ℓ` 的整条依赖路径均已被充分见证。

**定义 535（泛化门控 GG）** 对候选接地集 `Cand(ℓ)`：
```
S = C_α(ℓ) ∩ Cand(ℓ)
GATE(ℓ) =
  EXECUTE   若 S = {ι̂}（单点） ∧ ρ(ℓ) = 1 ∧ Λ(ℓ) ≤ L_cap
  SCAFFOLD  若 ∃ ι_s ∈ S ∩ I_scaffold ∧ ρ(dep(ℓ_s)) = 1
  CLARIFY   其它
```
`EXECUTE` 输出 `ι̂` 并签发证书 `(ℓ, ι̂, q̂_α, ρ(ℓ), n)`；`SCAFFOLD` 只执行已认证骨架 `ι_s`（推迟未见证参数）；`CLARIFY` 请求一次示教/确认，并以 v7 的保守默认 `ι₀` 临时兜底。`SCAFFOLD/CLARIFY` 一律不签发泛化证书。

**定义 536（语义负债 SDM）** 执行 `ℓ` 的预期损失上界：
```
Λ(ℓ) = L_wrong · α + L_ood · μ(ℓ)
```
第一项是共形失效率对应的损失，第二项是未见组合的漂移/OOD 损失。认证余额 `B(ℓ)=L_cap−Λ(ℓ)`，`B≥0` 是 `EXECUTE` 的必要条件。数据规模 `n↑` 使 `q̂_α↓`、`ρ↑`，故 `Λ` 单调下降——这形式化了“数据规模作为抵押品”。

**定义 537（补账价值与主动策略 AAP）** 对未被见证的依赖元素 `x`：
```
ν(x) = f(x) · w(x) · (1 − cov_n(x)/k_min)
```
其中 `f(x)` 为部署频率、`w(x)` 为风险权重。补账策略每次选择 `argmax_{x∈未覆盖} ν(x)` 对应的指令请求示教；得到核验样本后同时更新 `D_n` 与账本，再重算 `q̂_α`。

**定义 538（规模-泛化闭环不变式 SCL）** 
```
Φ_SCIG = ( SCC, CDG, CL, GG, SDM, AAP )
不变式：EXECUTE(ℓ) ⇒ |C_α(ℓ)|=1 ∧ ρ(ℓ)=1 ∧ Λ(ℓ)≤L_cap ∧ 动作 ∈ Feas_v7(M₀)
```
即：**没有单点共形证书、没有完整覆盖账本、或动作越出 v7 硬约束，都不得执行泛化指令**。数据规模在此只通过 `n`（共形）与 `cov_n`（账本）进入，永不通过“模型参数规模”直接授权泛化。

## 3. 关键算法骨架

```python
import math
from collections import defaultdict

# IP-351 ConformalGrounding：数据规模 -> 覆盖证书
class ConformalGrounder:
    def __init__(self, grounder, alpha=0.05):
        self.g, self.alpha = grounder, alpha
        self.qhat = None

    def calibrate(self, D_cal):
        """D_cal: [(ell, iota_star)]，其长度 n 即数据规模"""
        scores = sorted(self.g.score(l, i) for l, i in D_cal)
        n = len(scores)
        k = math.ceil((n + 1) * (1 - self.alpha))
        if k > n:
            self.qhat = math.inf          # 规模不足，不签发证书
        else:
            self.qhat = scores[k - 1]

    def certificate(self, ell, candidates):
        if self.qhat is None or math.isinf(self.qhat):
            return None                   # 定义 531：证书不可签发
        S = [i for i in candidates if self.g.score(ell, i) <= self.qhat]
        return S

    def radius(self, ell, candidates):
        S = self.certificate(ell, candidates)
        if S is None or len(S) < 2:
            return 0.0
        return max(self.g.dist(a, b) for a in S for b in S)


# IP-352/353 CompositionalDependencyGraph + CoverageLedger
class CoverageLedger:
    def __init__(self, grammar, k_min=3):
        self.G, self.k_min = grammar, k_min
        self.count = defaultdict(int)

    def credit(self, ell):
        """只由已核验样本记账（定义 534）"""
        for x in self.G.dep(ell):
            self.count[x] += 1

    def rho(self, ell):
        dep = self.G.dep(ell)
        if not dep:
            return 0.0
        return min(min(1.0, self.count[x] / self.k_min) for x in dep)

    def uncovered(self, ell):
        return [x for x in self.G.dep(ell) if self.count[x] < self.k_min]

    def unobserved_mass(self, ell):
        return 1.0 - self.rho(ell)


# IP-356 SemanticDebtMeter
class SemanticDebtMeter:
    def __init__(self, L_wrong, L_ood, L_cap, alpha):
        self.L_wrong, self.L_ood, self.L_cap, self.alpha = \
            L_wrong, L_ood, L_cap, alpha

    def liability(self, ledger, ell):
        return self.L_wrong * self.alpha + self.L_ood * ledger.unobserved_mass(ell)

    def balance(self, ledger, ell):
        return self.L_cap - self.liability(ledger, ell)


# IP-354 GeneralizationGate：覆盖门控
class GeneralizationGate:
    def __init__(self, conformal, ledger, debt, I_scaffold, default_iota):
        self.scc, self.ledger, self.debt = conformal, ledger, debt
        self.I_scaffold, self.default_iota = I_scaffold, default_iota

    def decide(self, ell, candidates):
        S = self.scc.certificate(ell, candidates)
        if S is None:                                   # 数据规模不足
            return "CLARIFY", self.default_iota
        lam = self.debt.liability(self.ledger, ell)
        if len(S) == 1 and self.ledger.rho(ell) >= 1.0 and lam <= self.debt.L_cap:
            return "EXECUTE", S[0]
        safe = [i for i in S if i in self.I_scaffold]
        if safe and self.ledger.rho(safe[0]) >= 1.0:
            return "SCAFFOLD", safe[0]
        return "CLARIFY", self.default_iota


# IP-355 ActiveAccrualPlanner：主动补账
class ActiveAccrualPlanner:
    def __init__(self, ledger):
        self.ledger = ledger

    def value(self, ell, freq, risk):
        return sum(freq.get(x, 1.0) * risk.get(x, 1.0) *
                   (1.0 - min(1.0, self.ledger.count[x] / self.ledger.k_min))
                   for x in self.ledger.uncovered(ell))

    def select(self, unresolved, freq, risk):
        """次模贪心：每次买下风险加权未见质量最大的依赖（定义 537）"""
        return max(unresolved, key=lambda e: self.value(e, freq, risk))


# IP-357 ScaleCertifiedLoop：规模-泛化主闭环（关键片段）
def scig_step(v7, ell, candidates, gate, planner, freq, risk):
    decision, iota = gate.decide(ell, candidates)

    if decision == "EXECUTE":
        plan = v7.step(iota)                       # 仍受 v7 硬约束 M₀ 约束
        cert = ("EXECUTE", ell, iota, gate.scc.qhat, gate.ledger.rho(ell))
        return plan, cert

    if decision == "SCAFFOLD":
        plan = v7.step(iota)                       # 只执行已认证骨架，不签发证书
        return plan, ("SCAFFOLD", ell, iota, None, gate.ledger.rho(ell))

    # CLARIFY：临时用保守默认，同时把该指令登记为补账目标
    target = planner.select([ell], freq, risk)
    return v7.step(gate.default_iota), ("CLARIFY", ell, None, target)


def on_demonstration(gate, planner, ell, iota_star):
    """用户澄清/示教返回后：数据规模 n↑，账本记账，然后重算证书"""
    gate.scc.cal.append((ell, iota_star))
    gate.scc.calibrate(gate.scc.cal)
    gate.ledger.credit(ell)
    return gate.scc.qhat, gate.ledger.rho(ell)
```

## 4. 推导

**引理 77（无免费泛化：置信度 ≠ 覆盖）** 设接地器的置信度 `conf(ℓ)` 仅是输入特征与参数的连续函数，不引用任何外部见证。则存在指令 `ℓ*` 满足 `dep(ℓ*) ∩ (∪_k dep(ℓ_k)) = ∅`（依赖组合从未被见证），使 `conf(ℓ*)` 可任意接近 1，而真实接地误差 `d(g_θ(ℓ*), g*(ℓ*))` 无上界。证明：平滑外推在训练支撑外不提供误差界；构造 `ℓ*` 仅由训练中未共现的槽位组合构成，模型输出由其邻近特征的插值决定，可通过选择邻近特征使插值任意偏离真值，而置信度仍高。故“模型很确定”不能替代“覆盖证据”，必须外置覆盖证书。

**引理 78（共形覆盖有效性）** 若 `(ℓ, g*(ℓ))` 与 `D_n` 独立同分布（可交换），`s` 为任意非一致性分数，则按定义 531 构造的 `C_α(ℓ)` 满足
```
P( g*(ℓ) ∈ C_α(ℓ) ) ≥ 1 − α,
```
且该界与 `g_θ`、`P` 的形式无关。证明：标准 split conformal 排序统计论证——`n+1` 个分数可交换，新样本分数排在前 `k_α` 小的概率至少 `k_α/(n+1) ≥ 1−α`。

**引理 79（分布漂移下的覆盖缺口）** 若部署分布 `Q` 与校准分布 `P` 的总变差距离 `TV(P,Q) ≤ ε`，则对 `ℓ ~ Q`：
```
P( g*(ℓ) ∈ C_α(ℓ) ) ≥ 1 − α − ε.
```
因此名义 `1−α` 在漂移下会静默失真。覆盖账本的未见质量 `μ(ℓ)` 是 `ε` 的可计算代理：当 `μ(ℓ) > 0` 时，至少有一整条依赖边没有 `k_min` 份校准见证，提示该区域的 `TV` 可能未被约束，必须降级而不能继续 `EXECUTE`。

**引理 80（覆盖半径的规模律）** 对同一嵌套校准序列，`r_α(ℓ;n)` 依概率关于 `n` 非增；在参数化平滑模型下 `E[r_α(n)] = Θ(n^{-1/2})`，在 `d` 维 Hölder-`β_s` 光滑非参数模型下 `E[r_α(n)] = O(n^{-β_s/(2β_s+d)})`。推论：`n_need(ε)` 给出“把证书宽度压到 `ε` 所需的最小数据规模”，这是可预注册、可预算的指标。

**引理 81（门控单调安全）** `GATE` 的三个出口都落在 v7 的 `M₀` 可行集内：`EXECUTE/SCAFFOLD` 调用 `v7.step`（其硬约束与 `SpatialCert` 保证可行），`CLARIFY` 调用 `v7.step(ι₀)`（v7 已认证的保守默认）。门控只把指令从“执行泛化版本”移到“骨架或澄清”，不引入新动作原语，故
```
Feas_SCIG ⊆ Feas_v7，  且 GATE ≠ EXECUTE 时安全裕度不减。
```
即 v8 对可行集只做交，不做并。

**引理 82（退化等价）** 若 SCC 不可用（`q̂=∞`）、或 CDG/CL/GG/SDM/AAP 任一被旁路，则主闭环不含任何 v8 分支，所有指令按 v7 原路径处理，输出与 v7 逐字一致（可做哈希比对）。若再关闭 v7 的 OTL/GCT/ER，则退回 v6。故 v8 是 v7 的可选增强。

**引理 83（补账次模性与近似比）** 覆盖增益
```
F(S) = Σ_{x∈V∪E} w(x) · min(1, cov_S(x)/k_min)
```
是单调、次模的（截断线性计数之和保持次模）。故按 `ν` 的贪心补账达到 `(1−1/e)·OPT`；达到目标覆盖 `c*` 所需示教数最坏为 `k_min·|V∪E|`，且风险加权意义下不劣于随机选样。

**引理 84（实时性）** 单步附加开销：共形查表 `O(|Cand(ℓ)|)`，依赖检查 `O(|dep(ℓ)|)`，门控常数次比较，补账规划 `O(|unresolved|)`；在校准集按 `q̂` 建索引后，`C_α` 查询为 `O(log|D_n| + |Cand|)`。总附加 ≤ 2ms，主闭环 WCET ≤ 24ms，保持 50Hz。

## 8. 本轮最大风险

**一句话**：整套框架把“泛化资格”押在“校准集与部署可交换”这一前提上——一旦指令分布发生真实漂移（新物体、新操作员、新句式），共形覆盖的名义 `1−α` 会静默失真，而未见证质量只是漂移的代理指标；最危险的情形是系统凭一份**看似完整、实则过期的覆盖账本**，对真正 OOD 的指令给出单点高置信预测并 `EXECUTE`，即“用一张过期的保单去承保一次从未被承保的风险”。
