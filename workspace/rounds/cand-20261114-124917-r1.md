# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~302；灵感循环第 4 轮；本轮灵感：「碰撞检测」×「动作分块」）

> R73 把系统安全问题重构为「证据计量的可组合契约」：MMS / EC / CCA / ΣREFLEX / CPB，并在尾部补入 ECG 因果证据图、MIC 形态无关契约与 IP-302 因果证据组合。它回答的是「**同一时刻的多个证据如何被审计、组合、热替换**」。但它留下一个从未被真正触碰的维度：**时间**。
> - **R73 的隐含假设**：证据在「当前这一刻」有效，动作是「下一步」的原子决策。CCA 的三个算子（SER/PAR/VETO）都是**同一时刻**的证据组合；EC 的预算闭合是「输入→输出」的空间预算，不是「现在→未来」的时间预算；stub 的 `u=∞` 也没有时间语义（是这一刻无穷，还是整段无穷？）。
> - **动作分块打破了这个假设**：ACT / Diffusion Policy / VQ-BeT 一类策略一次输出 H 步动作并**开环执行**。机器人不再「每步看一次证据」，而是在一个时间窗内**承诺**一整段轨迹。R73 的证书若只覆盖 t 时刻，就无法证明 [t, t+H] 内任何一刻的安全；一旦块执行中途环境突变，系统既没有新证据、也没有反应窗口。
> - **碰撞检测是时间的试金石**：碰撞本质上是**连续时间**的性质，而几乎所有工程实现都是**离散采样**检查的——路径点稀疏或速度高时会「穿模」(tunneling)。把 R73 的单帧证据直接喂给碰撞检查，会在两个路径点之间给出「全程无碰撞」的**假证书**。碰撞还是**非补偿性否决**的自然原型：距离不够就是不够，不能用其他模态的高置信度把它「平均」掉。
>
> 本轮两个灵感正好补上时间维的两半：
> - **碰撞检测** → **CCC（Continuous Collision Certificate，连续碰撞证书）**：把碰撞检查从「离散采样返回布尔」升级为「连续区间返回带不确定度的距离下界 + 无反穿保证 + 硬否决」。它**消费** DPEM/DMEM 的几何不确定度预算（R73 的预算闭合终于在时空中闭合），输出时间索引的距离下界 `d_lb(t)` 与到碰撞时间的下界 `TTC_lb`。
> - **动作分块** → **TEC（Temporal Evidence Contract，时序证据契约）+ ACB（Action Chunk Binding）+ ECL（Endogenous Certified Length，内生认证块长）**：每个证据契约除空间预算外，声明**认证时域 h**（我的证书在多久内可信）、**时域衰减 δ(Δ)**、**刷新策略**与**承诺语义**；动作块成为一等证据对象；块长不再是超参数，而是由「证书何时失效」**推导**出来的 h*。
>
> 核心命题：**不再问「这一步安全吗」，而问「这份安全证书能覆盖多长的时间窗，以及系统能否只在证书覆盖的窗口内承诺动作？」** 把 MODGAUGE 的空间契约代数扩展为**时空契约代数** → **CAGE-RAS（Certified Action-chunk GauGE for RAS）**：**承诺即证据，时域即预算，碰撞即否决。**

## 0. 直觉与动机

**灵感 1（碰撞检测 → 安全是区间性质，不是采样点性质）**
直觉：碰撞不是「某个离散时刻两个几何体重叠」，而是「连续轨迹上的最小距离降到 0」。采样检查只要在 Δt 内位移超过障碍最小特征厚度，就会漏检（tunneling）。连续碰撞检测（CCD）用**扫掠体 (swept volume)** 或**保守推进 (conservative advancement)** 保证区间内无遗漏。再叠加 R73 的教训：几何本身是不确定的——深度六分量给出障碍边界的 `u_geom`，位姿跟踪有误差 `e_track`。所以碰撞证书的正确形式不是布尔，而是
  **d_lb(t) = d̂(t) − κ_geom·u_geom(t) − e_track(t) ≥ d_safe，∀t∈[0,h]**，
它在不确定度或跟踪误差变大时**自动收紧**。碰撞是**硬否决**（COMP-VETO 的典范）：其它模态再自信也不能补偿「即将碰撞」。而「最小距离随时间的变化率」就是**到碰撞时间 TTC** 的下界——它天然是动作与时间的函数，正好对接 R73 的 `χ_R` 反作用通道。

**灵感 2（动作分块 → 承诺把安全从状态问题变成预测问题）**
直觉：动作分块 = 用一个块（H 步）换取平滑、低频推理、时序一致。代价是**开环承诺**：块执行期间机器人不再重新决策，反应窗口 W = h − ℓ（ℓ 为感知 + 计算 + 执行延迟）。因此：
1. 证书必须覆盖**整段块**，还要覆盖右侧延迟余量 [t, t+h+ℓ]；
2. 块长受三个同时衰减的量约束：距离下界随承诺变短（跟踪误差随时间增长）、障碍预测的 conformal 有效域随时间收缩、遮挡导致的「自由空间」假设随时间变脆；
3. **h\* = sup{ h : d_lb(h) ≥ d_safe ∧ e_track(h) ≤ e_max ∧ obstacle_valid(h) ∧ h−ℓ ≥ W_min }**。块长从超参数变成证书的函数——这就是「内生认证块长」。
这带来一个漂亮的二重性：**块越长效率越高但反应窗口越窄；块越短越安全但推理/抖动成本越高**。CAGE 不选边，它把两端都写成契约，让组合代数在给定风险预算下求 h*。

**灵感 3（时空预算闭合 → R73 的预算终于跨时间守恒）**
直觉：R73 的 EC 说「输入不确定度 ⊆ 输出不确定度」。但那是在一次组合内。分块后证据会**跨块传递**：上一块末尾的位姿误差、未更新的障碍地图、衰减的标定，都是下一块的**输入预算**。若不显式记账，就会发生「时间上的凭空变好」——与 R73 批判的「空间上的凭空变好」同型。所以 TEC 必须声明**时域衰减 δ(h)** 与**陈旧度 staleness**，HCA 的组合规则必须保证：**块序列（串联）的不确定度沿时间单调不减；只有刷新（拿到新证据）时才允许下降**。这把 R73 的「组合单调性」从空间推广到时空，得到**时域组合下界定理**。

**灵感 4（ECG 的时序化 → 承诺因果链）**
直觉：R73 尾部引入 ECG（模块证据的条件依赖图）。分块执行引入一条显式的**承诺因果链**：`块选择 → 计划轨迹 → 预测位姿 → 预测障碍 → 距离下界 → 否决/执行`。这条链上任一边断裂（障碍预测网络失效、深度断链、标定过期），表现不是「u 慢慢变大」，而是「**证书的时域突然失效**」——必须触发**承诺截断**（truncate at last certified time），而不是让不确定度在开环中累积。这把 ECG 从「同一时刻的因果」扩展为「跨越承诺窗口的因果」。

**灵感 5（多假设碰撞 → 否决的合取语义）**
直觉：面对动态障碍，真正要否决的不是「最可能轨迹会碰撞」，而是「存在一条在 conformal 可能集内的轨迹会碰撞」。这是**悲观合取**：安全 ⇔ ∀o(t) ∈ C_α(t)，无碰撞。所以 PAR 融合多源障碍预测时不能取平均/取最优，必须取**可能集的并**再检查最小距离。这与 R73「PAR 仅在一致性审计通过才允许缩窄」互补——碰撞场景的默认方向是**保守扩张**，不是缩窄。

**灵感 6（严格退化与热替换在时间维度仍成立）**
直觉：把 h→单步、CCC→离散布尔、χ_H→平凡，CAGE 应逐指令退化为 R73 MODGAUGE；把承诺→无（每步重规划），退化为 R72/R71。热替换定理必须加强为：同 TEC 替换实现，**不仅空间性质保持，认证时域 h 也保持**。这保证「换一个碰撞检测库 / 换一个动作分块策略」不改变系统级安全证书的**覆盖区间**。

## 1. 形式化定义（增量：定义 383–398）

**定义 383（CAGE-RAS 总览与六不变式）** CAGE-RAS = (TEC, ACB, CCC, HCA, ECL, χ_H, J_TEMP, MODGAUGE-RAS†)。六不变式：
(i) **时序完备性**：每份证据携带认证时域 h 与衰减 δ，无界证书不得进入执行路径；
(ii) **承诺-覆盖**：被执行块的证书必须覆盖 [t0, t0+h+ℓ]（延迟增广），ℓ 为实测延迟；
(iii) **连续无遗漏**：碰撞证书是连续时间的（无反穿），而非端点采样；
(iv) **时域单调性**：未经刷新的组合，u 沿时间非减、h 沿组合非增；
(v) **硬否决**：碰撞否决不可被其它模态补偿；
(vi) **严格退化**：h→单步、CCC→离散、χ_H→id 时逐指令退化为 R73（再退化为 R72/R71/R68）。

**定义 384（时序证据契约 TEC）** TEC = EC ⊕ (h_cert, δ, refresh, κ_stale, commit_sem)：
- `h_cert`：认证时域——无刷新时证据在 [t0, t0+h_cert] 内可信；
- `δ: ℝ≥0 → 𝒰`：时域膨胀函数，距上次刷新 Δ 后不确定度按 δ(Δ) 放大（δ(0)=0，单调非减）；
- `refresh ∈ {time, event, drift}`：刷新触发；
- `κ_stale`：陈旧阈值，超过即自动降级为 h=0 stub；
- `commit_sem ∈ {one-step, chunk, until-event}`：此证据允许支撑多长的承诺。

**定义 385（动作块对象 ACB）** 块 A = (τ=(a₁…a_H), Δt, B_A, cert_A, h_A, t0, ℓ)：
- τ：开环轨迹；B_A：有效基（basin）——从此状态执行 τ 且跟踪误差 ≤ e_max 时仍留在所有模块有效域内的状态集；
- cert_A = (CCC_A, budget_A, τ_trace)；h_A = H·Δt；t0 时间戳；ℓ 实测延迟。
块是**一等证据对象**：有 T_in（当前证据）、T_out（未来状态分布 + 证书），可被 TEMP-SER 组合、被 TEMP-VETO 否决。

**定义 386（连续碰撞证书 CCC）** 给定块轨迹 q(t)、障碍集 O(t)（几何不确定度 u_geom(t) 继承自 DPEM 预算闭合）、跟踪误差界 e_track(t)：
  `d̂(t) = min_{o∈O(t)} dist(q(t), o)`，`d_lb(t) = d̂(t) − κ_geom·u_geom(t) − e_track(t)`。
`CCC_A = {∀t∈[0,h_A+ℓ] : d_lb(t) ≥ d_safe} ∧ {no-tunneling : 逐区间扫掠覆盖 ∨ 最大步长 < 障碍最小特征厚度/2}`。
`TTC_lb = min{ t : d_lb(t) ≤ 0 }`。输出 = (d_lb 的时间函数, TTC_lb, 否决标志, 追溯链)。**预算闭合**：u_geom,out ≥ u_geom,in（碰撞检测第一次真正「花掉」深度/接触预算，而不是各算各的）。

**定义 387（时域组合代数 HCA）** 三算子：
- **TEMP-SER**（块序列 A→B）：`h_out = min(h_A, t_start(B)+h_B)`；跨块预算 `u_in(B) ⊇ δ(t_B−t_A)·u_out(A)`；若间隙 > κ_stale ⇒ B 降为 h=0 stub；拼接瞬态必须被 B 的证书覆盖。
- **TEMP-PAR**（多源碰撞）：几何 CCC ⊕ 深度 CCC ⊕ 近距/触觉，取**可能集并**语义：`d_lb = min_i d_lb_i`，`veto = ∨ veto_i`；仅当一致性审计通过且独立时才允许不增大（默认**保守不缩窄**）。
- **TEMP-VETO**：任一碰撞否决 ⇒ 整块拒绝（非补偿）。
**时域下界**：未刷新路径上 `u_out(t) ≥ u_in(t0)·δ(t−t0) + Σ 传播`，`h_out ≤ min_i h_i − Σ t_switch`。

**定义 388（内生认证块长 ECL）**
`h* = sup{ h ≥ 0 : d_lb(h) ≥ d_safe ∧ e_track(h) ≤ e_max ∧ obstacle_conformal_valid(h) ∧ (h−ℓ) ≥ W_min }`。
因 d_lb 对 h 非增、e_track 对 h 非减，可行集是前缀 [0,h*] ⇒ **h\* 良定义且对风险参数单调**（d_safe↑ ⇒ h\*↓）。内生块长 = ⌊h*/Δt⌋·Δt。

**定义 389（块拼接审计 TCA）** 相邻块 A_k, A_{k+1}：重叠残差 `r = |τ_k(t_switch) − τ_{k+1}(t0)| ≤ C_α`（SEAL 校准的 conformal 集）、状态连续性、切换瞬态被证书覆盖。若 r 越界或下一块未在 t_switch 前就绪 ⇒ **截断到最后认证点**或安全停机。**块边界 (stitch seam) 是新的攻击面。**

**定义 390（时域反作用通道 χ_H / 第五层 L5）** `χ_H: (h, τ) ↦ (Δe_track(h), Δu_obstacle(h), Δocclusion(h))`——承诺长度如何调制跟踪误差累积、障碍预测时域误差与遮挡。进入 ΣREFLEX 作为 L5：`c_reflex^H = E[Δ(u_geom + e_track) | h]`，计入总预算。**χ_H ≠ χ_v**：χ_v 改变「你看哪里」导致的噪声，χ_H 改变「你多久不再看」导致的累积不确定度。

**定义 391（时域威胁面 AIC-COLLISION）** ℰ_collision = {穿模注入（高速/稀疏路径点投毒）、遮挡幻影自由空间、SDF/地图投毒、位姿/跟踪投毒（放大 e_track 制造「假安全」）、动态障碍对抗定时（在反应窗口 W 内出现）、延迟攻击（放大 ℓ）}。防线：连续证书 + 单源不定案 + 悲观 TEMP-PAR + CBF 回退 + 延迟实测监控。

**定义 392（承诺截断与安全回退）** 块中途失效（漂移/陈旧/障碍突现）：在 `t_trunc = 所有证书最后有效时刻` 截断 τ，进入 h=0 的反应模式（单步重规划）或 CBF 安全停机（须在 W 内）。区分 **NoPlan**（t0 即不可证，不启动）与 **Abort**（飞行中失效，截断）。

**定义 393（时域退化链）** h→0 的 stub 语义：证据仅在瞬时有效，强制单步；模块 stub 扩展为 (证据∅, u=∞, D=∅, I⊥=本模态, χ_R 平凡, **h=0**)。降级阶梯 R74→R73→R72→R71→R68 逐指令等价。

**定义 394（J_TEMP 时空组合证书）** `J_TEMP = ⊗_i J(module_i) ⊗ J_HCA(MReg) ⊗ J_ECG(temporal)`。J_HCA 校验：时域交非空、跨块预算经 δ 闭合、拼接审计通过、延迟覆盖 [t,t+h+ℓ]、硬否决完备。Valid(J_TEMP) ⇒ 在 [t0, t0+h+ℓ] 上安全。

**定义 395（延迟增广认证时域）** ℓ = ℓ_sense + ℓ_compute + ℓ_act，**实测而非假设**；认证区间 [t0, t0+h+ℓ]；有效反应窗口 W = h − ℓ；W < W_min 的块不予接受。延迟攻击 = 监测 ℓ 的分布漂移并触发收紧。

**定义 396（无反穿条件）** 若每个相邻路径点区间都做扫掠/保守推进检查，**或**最大位移 < δ_obs（障碍最小特征厚度），则 [t_k, t_{k+1}] 内无遗漏碰撞。结合障碍运动 Lipschitz 上界 v_obs，可得连续轨迹的无反穿保证。

**定义 397（动态障碍悲观合取）** 安全 ⇔ ∀o(t) ∈ C_α(t): d_lb^{(o)}(t) ≥ d_safe。多预测器 PAR 取可能集**并**（最小距离、否决取或），一致性审计只许可「不缩窄」，不许可「取平均变好」。

**定义 398（CAGE 主张 C4–C6 绑定）** C4 连续碰撞证书 ← (CCC, AIC-COLLISION) ← MB4 ← AB4；C5 内生认证块长 ← (TEC, ACB, ECL) ← MB5 ← AB5；C6 时空契约组合 ← (HCA, J_TEMP, TCA) ← MB6 ← AB6。非绑定组件 = 工程附件，不入 MReg、不进正文。

## 2. 关键算法骨架

```python
# IP-303 TEC：时序证据契约（继承 R73 EC）
@dataclass(frozen=True)
class TemporalEvidenceContract(EvidenceContract):
    h_cert: float                       # 无刷新可信时长
    decay: Callable[[float], float]     # δ(Δ)：时域膨胀
    refresh: str                        # 'time' | 'event' | 'drift'
    kappa_stale: float                  # 超过即 h=0 stub
    commit_sem: str                     # 'one-step' | 'chunk' | 'until-event'

# IP-304 ACB：动作块作为一等证据对象
@dataclass
class ActionChunk:
    tau: Tensor; dt: float              # (H, act_dim)
    basin: Predicate                    # B_A
    cert: ChunkCert; h: float; t0: float
    latency: float                      # ℓ 实测

# IP-305 CCC：连续碰撞证书（感知/计量域）
class ContinuousCollisionCertificate:
    def certify(self, tau, obstacles, u_geom, e_track, d_safe, latency):
        intervals = conservative_advance(tau, dt=self.dt, obstacles=obstacles)
        d_lb = []
        for t, seg in intervals:
            d_hat = min_distance(seg, obstacles.at(t))        # 连续距离查询
            d_lb.append((t, d_hat - KAPPA*u_geom[t] - e_track[t]))  # 预算闭合(引理38)
        h_cert = first_time(d_lb, lambda v: v < d_safe)       # 首个跌破 d_safe
        no_tunnel = all(seg.max_disp < obst.thickness/2 for seg in intervals) \
                    or conservative_advance_exact(intervals)
        veto = (h_cert < tau.horizon + latency) or not no_tunnel
        ttc = first_time(d_lb, lambda v: v <= 0.0)
        return ChunkCert(d_lb=d_lb, h=h_cert, ttc=ttc, veto=veto,
                         no_tunnel=no_tunnel, trace=self.tchain.merge(...))

# IP-306 HCA：时域组合代数
def compose_temporal(A, B, op, clock):
    if op == 'TEMP-SER':                     # 块序列：时域取交，预算跨块传播
        gap = B.t0 - (A.t0 + A.h)
        if gap > KAPPA_STALE: return stub_temporal(B)     # 陈旧 → h=0
        u_in = A.cert.budget.u * A.ec.decay(gap)          # 时域膨胀
        return ChunkCert(h=min(A.h, B.h - gap),
                         u=max(u_in, B.cert.budget.u),    # 单调不减
                         veto=A.veto | B.veto)

# IP-307 ECL：内生认证块长（单调 ⇒ 二分）
def endogenous_chunk_length(evidence, risk):

    while hi - lo > risk.eps:

        ok = (collision.lb(h) >= risk.d_safe) and \
             (tracking.err_bound(h) <= risk.e_max) and \

             (h - risk.latency >= risk.W_min)             # 延迟-反应守恒(引理44)

# IP-308 CHRONO-ΣREFLEX：在 R73 通道预算上加 L5 时域层
def chrono_sigmareflex_step(mods, chunk, state, budget):

        states2[i], total = s2, total + c_i
    if budget.spent + total > budget.B: return None, total
    return states2, total
```

## 3. 推导

**引理 38（几何不确定度 → 碰撞裕度）** `d_lb(t)` 对 `u_geom` 与 `e_track` 单调非增；在 DPEM 预算闭合下 `P(d(t) ≥ d_lb(t)) ≥ 1−α`。系：**碰撞检测第一次真正「花掉」了深度/接触预算，而不是各算各的**——这是 R73 预算闭合在时空中的兑现。

**引理 39（无反穿）** 保守推进覆盖每个区间；在位移界满足时 `d_lb(t)` 连续，区间最小值可在区间内取得；仅当步长 < 障碍特征厚度时端点采样才充分。系：**tunneling 是采样频率与速度的函数，不是碰撞检测器返回的布尔值**。

**引理 40（h\* 存在性与前缀性）** d_lb 对 h 非增、e_track 对 h 非减 ⇒ 可行 h 集合是区间 [0,h\*]；h\* 对 d_safe 单调递减、对速度包络单调递减。系：**块长可证地随风险预算单调**，而不是拍脑袋调参。

**引理 41（时域组合下界）** TEMP-SER 经 k 块：`u_out(t) ≥ u_in(t0)·δ(t−t0) + Σ 传播`，`h_out ≤ min_i h_i − Σ t_switch`；无刷新则不确定度不下降。系：**时空版「不存在凭空变好」**。

**引理 42（拼接安全）** 若重叠残差 ∈ C_α 且下一块证书覆盖切换瞬态，则拼接执行安全；否则必须截断。系：**块边界 stitch seam 是新的攻击面**。

**引理 43（内生块长支配固定块长）** 任意固定 H 且 H·Δt ≤ h\*(risk) 的策略都是 ECL 的可行解；ECL 额外利用 h\* > H·Δt 的场景，并在 h\* < H·Δt 时拒绝。单调证书下 ECL 的可行安全集 ⊇ 固定 H 集。系：**固定块长要么浪费安全裕度、要么违反它，二者不可兼得**。

**引理 44（延迟-反应守恒）** W = h − ℓ；对突发障碍的安全要求 W ≥ W_min（CBF 停稳时间）。故增大 h 必须同时提高感知/计算速度或降低速度。系：**分块效率的上限由延迟决定，而不是由策略网络决定**。

**定理 30（CAGE 严格包含 MODGAUGE）** 令 h=Δt、ℓ=0、CCC=离散且步长满足引理 39、χ_H=id，则 CAGE 逐指令等于 R73 MODGAUGE；再令承诺→每步重规划，退化为 R72/R71/R68。**安全单调不减。**

**定理 31（J_TEMP 有效性 ⇒ 区间安全）** Valid(J_TEMP) ⇒ 对 [t0, t0+h+ℓ] 内每个 t，碰撞风险 ≤ ε（相对于几何预算校准与动态障碍 conformal 覆盖）。**证明重量落在「障碍预测的 conformal 覆盖在分布外是否成立」与「e_track 上界是否真实」上。**

**定理 32（无反穿 + 延迟 ⇒ 承诺块安全）** 在障碍运动 Lipschitz（v_obs ≤ V）、保守推进、延迟增广时域与无反穿条件下，承诺块内无遗漏碰撞。系：**开环承诺的安全性可由证书而非反应速度保证——前提是预测不失效**。

**定理 33（时域零级联）** 任一模块失效 ⇒ h=0 stub ⇒ 截断该块 ⇒ 进入反应模式；其它模块证书除时域交收缩外不受影响，无级联。

## 6. 本轮最大风险

**一句话**：CAGE 把碰撞安全从「状态属性」变成了「**预测属性**」——块执行那一刻的证书只对「它所相信的未来」有效；如果动态障碍的运动超出 conformal 预测集、或跟踪误差上界 e_track 在接触/负载变化下被低估，那么一块在 t0「所有证书有效、所有否决通过、审计日志合规」的承诺，会在开环执行中途静默失效，而机器人已经没有反应窗口 W = h − ℓ 去补救——系统会用一份时间上正确、预算上闭合、拼接上无缝的证书，**自信地承诺一段它其实无法保证的未来**。

次级风险与缓解：
1. **块过长导致反应窗口消失** → ECL 硬约束 W ≥ W_min；看门狗强制截断；长块只在静态、可预测场景放行。
2. **障碍预测分布外** → 悲观合取（定义 397）+ 可能集并 + 在线 conformal 漂移检测 + 突发障碍必触发 CBF。
3. **e_track 上界失真（负载/接触/温漂）** → e_track 由本体 + 接触预算联合给上界，而非模型自报；超界即截断。
4. **拼接缝攻击** → TCA + 切换瞬态证书覆盖 + 残差 conformal 审计；缝处不允许「跳变借道」。
5. **延迟攻击/测量失真** → ℓ 实测分布监控，漂移即收紧 h\* 并降级为单步。
6. **连续碰撞计算开销** → 层次包围盒 + 保守推进剪枝 + 近场才启用精确扫掠；预算超限即降级为保守上界（u↑、h↓）。
7. **时域预算记账腐化** → TEC 版本化 + SEAL-Contract 审计集 + 跨块 δ 可复算；任何未记账跨块传递视为断链。
8. **MB4–MB6 过拟合** → 密封保持集 SEAL-MB + 预注册指标 + 三方复现（承接 E385 协议）。

| `c_reflex^H = E[Δ(u_geom+e_track) | h]` | 承诺累积反作用成本 |
| `ℰ_collision` | 时域威胁面：穿模注入 / 遮挡幻影 / 地图投毒 / 跟踪投毒 / 障碍定时 / 延迟攻击 |
| `J_TEMP = ⊗_i J(module_i) ⊗ J_HCA ⊗ J_ECG(temporal)` | 时空组合证书 |
| `stub† = (∅, u=∞, D=∅, I⊥=本模态, χ_R=id, h=0)` | 时域降级语义 |
| `CertCost_T = Σ(SEAL+conformal) + 组合校验 + 时域 δ 复算` | 时空认证成本度量 |

## 2. 形式化定义（要点版）

**定义 383（CAGE 总览与六不变式）** (i) 时序完备性（无界证书禁入执行）；(ii) 承诺-覆盖（证书覆盖 [t0,t0+h+ℓ]）；(iii) 连续无遗漏（无反穿）；(iv) 时域单调性（未刷新则 u 非减、h 非增）；(v) 碰撞硬否决（非补偿）；(vi) 严格退化（h→单步、CCC→离散、χ_H→id ⇒ R73）。

**定义 384（TEC）** 在 R73 EC 上增加 `h_cert`、`δ(Δ)`（单调非减膨胀）、`refresh ∈ {time,event,drift}`、`κ_stale`、`commit_sem ∈ {one-step,chunk,until-event}`。超过 κ_stale 的证据自动降为 h=0 stub。

**定义 385（ACB）** 块 A=(τ,Δt,B_A,cert_A,h_A,t0,ℓ)；B_A 为「执行 τ 后仍在所有模块有效域内」的状态基；块是证据对象，有 T_in/T_out，可被组合与否决。块内开环，块间可拼接。

**定义 386（CCC）** `d̂(t)=min_o dist(q(t),o)`；`d_lb=d̂−κ·u_geom−e_track`；证书 = 全程 d_lb ≥ d_safe 且无反穿；输出 TTC_lb 与追溯链；预算闭合 u_geom,out ≥ u_geom,in。

**定义 387（HCA）** TEMP-SER：`h_out=min(h_A, t_B+h_B)`，跨块 `u_in(B) ⊇ δ(t_B−t_A)·u_out(A)`，间隙>κ_stale 即 stub，必须覆盖拼接瞬态；TEMP-PAR：多源取可能集并、`d_lb=min`、`veto=∨`，默认不缩窄；TEMP-VETO：任一否决即整体拒绝。

**定义 388（ECL）** 由 `d_lb` 非增、`e_track` 非减 ⇒ 可行集为前缀 [0,h\*]；`h*` 对 d_safe、速度包络单调；块长 = ⌊h*/Δt⌋·Δt。

**定义 389（TCA 拼接审计）** 重叠残差 `r ≤ C_α` + 状态连续 + 切换瞬态被覆盖；失败则截断到最后认证点或安全停机。stitch seam 为攻击面。

**定义 390（χ_H / L5）** 承诺长度调制跟踪误差累积、障碍预测误差与遮挡；`c_reflex^H=E[Δ(u_geom+e_track)|h]` 计入 ΣREFLEX；χ_H 与 χ_v 正交（「多久不再看」vs「看哪里」）。

**定义 391（AIC-COLLISION）** 六类时域威胁；防线：连续证书 + 单源不定案 + 悲观 PAR + CBF 回退 + 延迟实测。

**定义 392（截断与回退）** 中途失效 ⇒ 在最后认证时刻截断 τ ⇒ h=0 单步或 CBF 停机（须在 W 内）；区分 NoPlan 与 Abort。

**定义 393（时域退化链）** stub† 增加 h=0；R74→R73→R72→R71→R68 逐指令等价。

**定义 394（J_TEMP）** `⊗J(module_i) ⊗ J_HCA ⊗ J_ECG`；J_HCA 校验时域交非空、δ 预算闭合、拼接审计、延迟覆盖、硬否决完备；Valid ⇒ [t0,t0+h+ℓ] 安全。

**定义 395（延迟增广）** ℓ=ℓ_sense+ℓ_compute+ℓ_act 实测；W=h−ℓ；W<W_min 拒块；ℓ 漂移即收紧 h\*。

**定义 396（无反穿条件）** 逐区间扫掠/保守推进 ∨ 最大位移 < 障碍最小特征厚度；结合 v_obs Lipschitz 得连续无反穿。

**定义 397（动态障碍悲观合取）** 安全 ⇔ ∀o∈C_α: d_lb^{(o)}≥d_safe；PAR 取可能集并，审计只许不缩窄。

**定义 398（主张 C4–C6 绑定）** C4←(CCC,AIC-COLLISION)←MB4←AB4←(漏检率,误减速,TTC 误差)；C5←(TEC,ACB,ECL)←MB5←AB5←(成功率,碰撞率,吞吐)；C6←(HCA,J_TEMP,TCA)←MB6←AB6←(区间安全,拼接失败,热替换等价)。非绑定=工程附件。

```python
# IP-303 TEC：时序证据契约（继承 R73 EC）
@dataclass(frozen=True)
class TemporalEvidenceContract(EvidenceContract):
    h_cert: float                       # 无刷新可信时长
    decay: Callable[[float], float]     # δ(Δ)：时域膨胀
    refresh: str                        # 'time' | 'event' | 'drift'
    kappa_stale: float                  # 超过即 h=0 stub
    commit_sem: str                     # 'one-step' | 'chunk' | 'until-event'

# IP-304 ACB：动作块作为一等证据对象
@dataclass
class ActionChunk:
    tau: Tensor; dt: float              # (H, act_dim)
    basin: Predicate                    # B_A
    cert: ChunkCert; h: float; t0: float
    latency: float                      # ℓ 实测

# IP-305 CCC：连续碰撞证书
class ContinuousCollisionCertificate:
    def certify(self, tau, obstacles, u_geom, e_track, d_safe, latency):
        intervals = conservative_advance(tau, dt=self.dt, obstacles=obstacles)
        d_lb = []
        for t, seg in intervals:
            d_hat = min_distance(seg, obstacles.at(t))             # 连续距离查询
            d_lb.append((t, d_hat - KAPPA*u_geom[t] - e_track[t])) # 预算闭合(引理38)
        h_cert = first_time(d_lb, lambda v: v < d_safe)            # 首个跌破 d_safe
        no_tunnel = all(seg.max_disp < obst.thickness/2 for seg in intervals) \
                    or conservative_advance_exact(intervals)
        veto = (h_cert < tau.horizon + latency) or not no_tunnel
        ttc = first_time(d_lb, lambda v: v <= 0.0)
        return ChunkCert(d_lb=d_lb, h=h_cert, ttc=ttc, veto=veto,
                         no_tunnel=no_tunnel, trace=self.tchain.merge(...))

# IP-306 HCA：时域组合代数
def compose_temporal(A, B, op, clock):
    if op == 'TEMP-SER':                     # 块序列：时域取交，预算跨块传播
        gap = B.t0 - (A.t0 + A.h)
        if gap > KAPPA_STALE: return stub_temporal(B)      # 陈旧 → h=0
        u_in = A.cert.budget.u * A.ec.decay(gap)           # 时域膨胀
        return ChunkCert(h=min(A.h, B.h - gap),
                         u=max(u_in, B.cert.budget.u),     # 单调不减
                         veto=A.veto | B.veto)
    if op == 'TEMP-PAR':                     # 多源碰撞：悲观合取，可能集并
        return ChunkCert(d_lb=elementwise_min(A.d_lb, B.d_lb),
                         veto=A.veto or B.veto)            # 默认不缩窄
    if op == 'TEMP-VETO':                    # 硬否决，非补偿
        return ChunkCert(veto=A.veto or B.veto)

# IP-307 ECL：内生认证块长（单调 ⇒ 二分）
def endogenous_chunk_length(evidence, risk):
    lo, hi = 0.0, risk.h_max
    while hi - lo > risk.eps:
        h = 0.5*(lo + hi)
        ok = (collision.lb(h) >= risk.d_safe) and \
             (tracking.err_bound(h) <= risk.e_max) and \
             obstacle.conformal_valid(h) and \
             (h - risk.latency >= risk.W_min)              # 延迟-反应守恒(引理44)
        lo, hi = (h, hi) if ok else (lo, h)
    return math.floor(lo / DT) * DT

# IP-308 CHRONO-ΣREFLEX：R73 通道预算 + L5 时域层
def chrono_sigmareflex_step(mods, chunk, state, budget):
    total, states2 = 0.0, {}
    for i, m in mods.items():
        chi   = m.ec.chi_R(chunk.actions)          # R73 空间反作用通道
        chi_H = m.ec.chi_H(chunk.h, chunk.tau)     # L5 时域反作用通道
        c_i, s2 = m.reflex_cost(state[i], chi, chi_H)
        c_i += m.temporal_cost(state[i], chi_H)    # 承诺累积成本
        if s2 not in m.safe_set: return None, total
        states2[i], total = s2, total + c_i
    if budget.spent + total > budget.B: return None, total
    return states2, total

# IP-309 CAGE 主闭环（MODGAUGE 上增加承诺层与截断层）
def CAGE_round(M, obs, audio, tac_frame, depth_img):
    d_ev = M.dpe.update(...); t_ev = M.dmem.update(...)
    b_t  = M.bse.step_full(..., d_ev=d_ev, t_ev=t_ev)
    # === 承诺层（计量域）：证书生于块，不生于单步 ===
    h_star = endogenous_chunk_length(M.evidences(b_t), M.risk)     # IP-307
    A = M.policy.propose_chunk(b_t, h=h_star)                      # 动作块
    A.cert = M.ccc.certify(A.tau, M.obstacles, u_geom=M.dpe.u_geom,
                           e_track=M.track.err_bound, d_safe=M.risk.d_safe,
                           latency=M.rtm.latency)                  # IP-305
    if A.cert.veto:                                                # 硬否决
        A = M.policy.propose_chunk(b_t, h=max(DT, h_star/2))       # 缩短承诺
        A.cert = M.ccc.certify(...)
        if A.cert.veto: A = safe_stop(M, within=M.rtm.latency)     # 回退
    s2, cost = chrono_sigmareflex_step(M.mods, A, M.state, M.budget)  # IP-308
    if s2 is None: A, s2 = safe_stop(M, within=M.rtm.latency), M.state
    if not M.tca.audit(M.last_chunk, A):                           # 拼接审计(定义389)
        A = M.tca.truncate(M.last_chunk)
    M.last_chunk, M.state = A, s2
    # === 执行层（控制域）：开环执行块 + 看门狗截断 ===
    k = M.exec.commit(A)                                           # 承诺执行
    if M.watchdog.stale_or_surprise():                             # 中途失效
        k = M.exec.truncate_to_last_certified()                    # 定义392
    return k, J_TEMP(M.mreg, M.last_chunk)                          # 定义394
```

## 4. 推导

**引理 38（几何不确定度 → 碰撞裕度）** `d_lb` 对 `u_geom`、`e_track` 单调非增；DPEM 预算闭合下 `P(d ≥ d_lb) ≥ 1−α`。系：**碰撞检测真正花掉了深度/接触预算，R73 预算闭合在时空中兑现。**

**引理 39（无反穿）** 保守推进覆盖每区间；位移界满足时 d_lb 连续，区间最小值可达；端点采样仅当步长 < 障碍特征厚度时充分。系：**tunneling 是采样率与速度的函数。**

**引理 40（h\* 存在性/前缀性/单调性）** d_lb 对 h 非增、e_track 对 h 非减 ⇒ 可行集 = [0,h\*]；h\* 对 d_safe 与速度包络单调递减。系：**块长随风险预算可证单调。**

**引理 41（时域组合下界）** TEMP-SER 经 k 块：`u_out ≥ u_in·δ + Σ 传播`，`h_out ≤ min_i h_i − Σ t_switch`；无刷新不下降。系：**时空版「不存在凭空变好」。**

**引理 42（拼接安全）** 残差 ∈ C_α 且切换瞬态被覆盖 ⇒ 拼接安全；否则截断。系：**stitch seam 是新攻击面。**

**引理 43（ECL 支配固定块长）** 固定 H·Δt ≤ h\* 的策略均是 ECL 可行解；ECL 额外利用 h\* > H·Δt，并在 h\* < H·Δt 时拒绝；可行安全集 ⊇ 固定 H 集。系：**固定块长要么浪费裕度、要么违反它。**

**引理 44（延迟-反应守恒）** W=h−ℓ 必须 ≥ W_min（CBF 停稳时间），否则增大 h 无安全意义。系：**分块效率上限由延迟决定。**

**定理 30（CAGE 严格包含 MODGAUGE）** h=Δt、ℓ=0、CCC=离散且步长合规、χ_H=id ⇒ 逐指令等于 R73；承诺→每步重规划 ⇒ 退化 R72/R71/R68。**安全单调不减。**

**定理 31（J_TEMP 有效性 ⇒ 区间安全）** Valid(J_TEMP) ⇒ ∀t∈[t0,t0+h+ℓ] 碰撞风险 ≤ ε（相对几何预算校准与动态障碍 conformal 覆盖）。**证明重量落在障碍预测的分布外覆盖与 e_track 上界真实性上。**

**定理 32（无反穿 + 延迟 ⇒ 承诺块安全）** 障碍 Lipschitz（v_obs ≤ V）+ 保守推进 + 延迟增广 + 无反穿 ⇒ 承诺块无遗漏碰撞。

**定理 33（时域零级联）** 模块失效 ⇒ h=0 stub ⇒ 截断 ⇒ 反应模式；其它模块仅受时域交收缩影响，无级联。

## 7. 本轮最大风险

**一句话**：CAGE 把碰撞安全从「状态属性」变成了「**预测属性**」——块执行那一刻的证书只对「它所相信的未来」有效；如果动态障碍运动超出 conformal 预测集、或跟踪误差上界 e_track 在接触/负载变化下被低估，那么一块在 t0「所有证书有效、所有否决通过、审计日志合规」的承诺，会在开环执行中途静默失效，而机器人已经没有反应窗口 W = h − ℓ 去补救——系统会用一份时间上正确、预算上闭合、拼接上无缝的证书，**自信地承诺一段它其实无法保证的未来**。

次级风险与缓解：
1. **块过长导致反应窗口消失** → ECL 硬约束 W ≥ W_min + 看门狗强制截断；长块只在静态可预测场景放行。
2. **障碍预测分布外** → 悲观合取（定义 397）+ 可能集并 + 在线 conformal 漂移检测 + 突发障碍必触发 CBF。
3. **e_track 上界失真（负载/接触/温漂）** → 由本体 + 接触预算联合给上界，不采信模型自报；超界即截断。
4. **拼接缝攻击** → TCA + 切换瞬态证书覆盖 + 残差 conformal 审计；缝处禁止「跳变借道」。
5. **延迟攻击/测量失真** → ℓ 实测分布监控，漂移即收紧 h\* 并降级单步。
