# 第 44 轮（新循环第 4 轮） · Latency-Sound × Novelty-Ledger：把「推理延迟」升格为证书的有效性条件，把「论文创新点」降格为可证伪账本（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 用证书租约 ℓ=(m,τ,λ,κ) 处理了并发下的「陈旧边际」，但它仍压着两个未言明的单点假设：**(H5) 证书时间戳 τ 就是测量时刻，推理管线被默认为「即时且准时」**——真实链路里 τ 是传感器曝光时刻，证书要到 τ+L_e2e 才可用，而 L_e2e 含排队、批处理、抢占与长尾；v20 的衰减项只算了「物理状态会变」，却没算「推理本身把这截时间吃掉了」，于是尾部延迟一长，守卫就用上「看似新鲜、实则已过使用期」的边际，静默不 sound。**(H6) 创新点的价值被当作既定**——43 轮堆出 59 个 IP，但「相对谁新、在等延迟下是否还赢、去掉哪个机制增益就消失」从未形式化；很多所谓提升可能只是「偷偷多花算力/延迟」的假创新。本轮灵感词「推理延迟」「论文创新点」精确命中这两个假设：**推理延迟**把延迟从性能指标升格为**证书有效性的一个维度**，并逼出一个真正的理论问题——证书紧度随算力上升、新鲜度随延迟下降，这是一场赛跑，存在**最优停止时刻**；**论文创新点**把叙事降格为**可证伪账本**，用「等延迟基线」审计每个增益，把「多花延迟换来的分数」记为**创新负债**而非创新点。二者耦合处（延迟-效用前沿 × 等延迟审计）是本轮真正的新问题：**只有先回答「等延迟下是否仍赢」，前沿上的每个点才有资格被称为创新。**

## 0. 直觉与动机

**灵感 1（推理延迟 → 证书是一场「紧度 vs 新鲜度」的赛跑）**：直觉上，给模型更多时间，它会把边际下界算得更紧（m ↑）；但结论也更旧，物理状态已经多走了 λ·c（可用性 ↓）。所以真正能用于守卫的不是 m，而是**可用边际 U(c) = m(c) − λ·c**：第一项奖励算力，第二项惩罚延迟。若 m 随计算时间 c 单调、凹（收益递减），则 U 单峰，最优停止点满足 **m'(c*) = λ**——多算一毫秒买来的紧度增益，恰好等于它多付的陈旧代价。三种区域：λ 大（高速、高风险）时 c*→0，应尽快用粗糙界；m' 大（慢动态、强不确定）时 c* 很大，值得等精细界；中间区才需要复杂调度。一句话：**延迟不是要消灭的开销，而是要解出来的最优停止时刻。**

**灵感 2（论文创新点 → 「等延迟基线」与「创新负债」）**：直觉上，审稿人最狠的一问是「你是不是只是多花了算力？」于是把每个创新点写成可证伪条目 N_i=(主张, 定理/实验, 基线, 消融, 反例)，并规定**所有比较必须在等端到端延迟下进行**（matched-latency baseline）。若某机制在等延迟下增益消失，它只是「用延迟买分数」，记为**创新负债**，不得计入创新点。真正的创新点必须同时满足：等延迟下仍赢（效应显著）、去掉该机制增益显著下降（必要性）、存在可执行反例（可证伪）。这把「创新点」从形容词变成**可计算、可审计、可否证**的三元组。

**灵感 3（耦合 → 延迟-效用前沿 LUF 是唯一值得画的主图）**：延迟-效用前沿 LUF = { (p99 延迟, 任务效用, 灾难风险) 可达点 } 的 Pareto 面。v20 的证书体系本质是在**固定延迟**下换安全；本轮的延迟感知调度让**延迟本身成为策略变量**，从而**外扩**这条前沿。论文的主图不再是「我们有多少 IP」，而是「在同一延迟预算下，我们的可行前沿比基线外扩多少」。而 LUF 上每个声称外扩的点，都必须先过等延迟审计——否则只是把 x 轴往右推。

**耦合升级**：LSC（延迟 sound 证书）把双时间戳与延迟预算显式化；LAS（延迟感知调度）把 EDF 的 deadline 直接由边际导出，并保证「错过即降级」；LUF（前沿基准）用等延迟扫描画出可证伪曲线；NLA（创新账本审计器）把每个 IP 映射到一条能被消融/反例击倒的主张。四层架构由此由 v8 的「个性化 + 并发证书层」升级为 v9 的「个性化 + 并发 + **延迟 sound 层** + **创新审计层**」。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（双时间戳延迟 sound 证书）**：证书 c=(I, m̂, τ_obs, τ_cert, τ_use, λ, θ)。m̂ 为基于 τ_obs 观测算出的边际下界，τ_cert 为证书可用时刻，τ_use 为被守卫消费时刻；端到端延迟 **L_e2e = τ_use − τ_obs**。**延迟预算** D(θ) = (m̂ − θ)/λ，即「边际衰减到阈值前还允许走多久」。**sound 条件**：(i) m̂ 在 τ_obs 处是有效下界；(ii) L_e2e ≤ D(θ)。满足时可用边际 m_eff = m̂ − λ·L_e2e ≥ θ。**注**：v20 的租约只在「τ 就是消费时刻」的隐含假设下等价于此；它既没有把推理链路计入 L_e2e，也没有把「何时停止计算」当成决策。**推论**：v20 在 p99 延迟超过 D(θ) 的尾部事件上会静默不 sound，而这类事件恰好被平均延迟指标掩盖。

**定义 45（anytime 证书改进曲线与可用边际）**：对固定观测，令 m(c) 为在「观测年龄 = c」内能拿到的最好证书下界（c 含排队 + 计算）。假设 (i) m 单调不减；(ii) m 凹；(iii) m(c) ≤ m* 有界。则**可用边际** U(c)=m(c)−λc。**最优停止定理**：U 为凹函数，c*(λ)=argmax U 满足：若 m'(0) ≤ λ，则 c*=0（衰减主导，立即出粗糙界）；否则 c* 为 m'(c*)=λ 的唯一内点（紧度主导，值得等）。**几何解释**：c* 是曲线 m(c) 上斜率等于衰减率 λ 的切点。**注**：这条定理把「延迟优化」从工程调参变成一次一维凹优化，且对任意 anytime 推理器成立。

**定义 46（边际导出 deadline 与单调降级）**：作业 j 的 deadline D_j(θ_j) = max{c : m_j(c) ≥ θ_j + λ_j c}，即「结果仍有用的最晚年龄」。调度用 EDF，按 D_j 排序。**准入控制**：若作业的 WCET > D_j，则不启动该作业（而非启动后超期）。**单调降级**：任何未在 D_j 前完成的作业，其结论作废；运行时必须改用上一条仍有效下界 m_prev 的衰减值，或更保守回退 m_fbk ≤ m_prev − λ(now−τ_prev)。**定理（无过期进入守卫）**：若每个进入守卫的证书都满足 L_e2e ≤ D(θ)，则守卫 sound；EDF + 准入（拒绝 WCET>D 的作业）保证「过期证书永不进入守卫」。**注**：这把 v20 的 HI/LO 模式从「砍任务」升级为「砍不满足 deadline 的任务」。

**定义 47（延迟-效用前沿与等延迟增益）**：对工作负载 W 与配置 π，LUF(W) = Pareto{ (L_p99(π), U_task(π), R_cat(π)) }。记面积指标 AUF = ∫U_task dL。**等延迟增益** ΔU(L) = U_{π_LSC}(L) − U_{π_base}(L)，要求在置信区间下 ΔU(L)>0。**外扩判据**：AUF_LSC ≥ AUF_base 且存在一段延迟区间使 ΔU>0 且 R_cat 不增。**注**：若只在「平均延迟」上比较，LSC 可以靠拖着长尾不报而虚赢；因此 LUF 必须用 p99/p999 与最大延迟两条轴同时画。

**定义 48（可证伪创新点账本）**：每个创新点 N_i=(claim_i, evidence_i, baseline_i, ablation_i, falsifier_i, effect_i)。**创新判据**：(a) 等延迟效应显著；(b) 消融使效应显著下降（必要性）；(c) falsifier_i 可被自动执行并可能击倒 claim_i。**创新负债** debt_i=max(0, effect_unmatched_i − effect_matched_i)；**负债率** = Σdebt_i / Σeffect_unmatched_i。**红线**：负债率 <10%，否则该轮创新点整体不成立。**注**：baseline 必须是「同等延迟预算下可运行的 anytime 版本」，不能是「关掉 anytime 的稻草人」。

**定义 49（尾部延迟的 hard/soft 双轨）**：hard 轨用静态 WCET 或保守上界 C_max 签发，保证 L_e2e ≤ C_max；soft 轨用共形尾部界给 P(L_e2e > D) ≤ δ，仅用于 availability 调优。**双轨契约**：安全关键守卫只接受 hard 轨证书；soft 轨若超界，只能触发降级或 v20 式串行安全路径。**命题（无 WCET 时的诚实降级）**：若平台无法给出 C_max，则任何声称的「延迟 sound」都是概率性的，必须在运行时显式携带 δ 并禁止进入 hard 守卫。

## 2. 四大新增产出与既有 IP 升级

### 2.1 IP-60 LATENCY-SOUND-ANYTIME-CERT（延迟 sound 证书 LSC）
1. **双时间戳**：结论携带 (τ_obs, τ_cert, τ_use) 与 λ、θ；守卫读的是 m_eff 而非 m̂。
2. **改进曲线校准**：按状态单元离线/在线拟合 m(c) 的单调凹包络（保守包络，不用点估计）。
3. **最优停止**：解 m'(c*)=λ（闭式或二分），输出建议计算预算；边界情形 c*=0。
4. **过期检测**：L_e2e > D(θ) 立即作废并单调降级，绝不把过期结论送进守卫。
5. **hard/soft 双轨**：WCET 轨与共形尾部轨分离，安全守卫只吃 hard 轨。

### 2.2 IP-61 LATENCY-AWARE-CERT-SCHEDULER（延迟感知调度器 LAS）
1. **deadline 直接由边际导出**：D_j(θ_j)=max{c: m_j(c) ≥ θ_j+λ_j c}，不拍脑袋设 ms 预算。
2. **EDF + 准入控制**：WCET>D_j 的作业不启动；过载时优先保 D 小且 κ 高的作业。
3. **尾延迟隔离**：批处理/投机分支不得与安全作业共享尾延迟；HI 模式禁批处理。
4. **与 v20 混合关键级合并**：HI 模式 = 只保留满足 deadline 的 safety/geometry 作业，硬隔离安全预算。
5. **降级可审计**：每次降级记录 (cause, stale_age, fallback_m)，供 E99/E102 审计。

### 2.3 IP-62 LATENCY-UTILITY-FRONTIER（延迟-效用前沿基准 LUF）
1. **延迟注入**：0–500ms 可编程注入（含抖动与长尾），覆盖排队/抢占/批处理三种来源。
2. **等延迟扫描**：固定延迟预算，扫描各配置，画 AUF 与 ΔU(L)。
3. **匹配基线**：base 与 LSC 在同一延迟、同一算力上限下比较；base 也允许 early-exit。
4. **风险同轴**：每次点都记录 R_cat 与最坏延迟，拒绝「牺牲风险换效用」的伪外扩。

### 2.4 IP-63 NOVELTY-LEDGER-AUDITOR（创新账本审计器 NLA）
1. **claim 编译**：把每个 IP 的一句话卖点编译成可测不等式 + 基线 + 消融 + falsifier。
2. **等延迟审计**：自动跑 matched-latency 对比，计算 debt_i 与负债率。
3. **消融矩阵**：逐个关闭机制，检验必要性；效应在消融后不降的 claim 降级为「工程优化」。
4. **可复现包**：claim→脚本→数据→CI，保证审稿人能一键击倒或复现。
5. **论文定位表**：三档主张（定理级 / 系统级 / 经验级）分别给出最近相关工作与差异点。

## 5. 本轮最大风险

**一句话**：m(c) 的「单调凹 + 平稳」与 WCET 在真实边缘端都可能不成立（缓存、动态批处理、温漂会让曲线非凹、尾部不可控），此时最优停止点会算错；而等延迟审计又可能一次性把大部分既有 IP 判为创新负债——因此 E96（曲线校准）与 E98（等延迟审计）必须设为红线，并永久保留 v20 的「固定短租约 + 串行监控」作为永不失 sound 的底线。

# 第 44 轮产物 · 创新点清单 v21：Latency-Sound × Novelty-Ledger（LSC × LAS × LUF × NLA）× 可证伪的延迟-安全闭环（四层架构 v9）

## 1. 符号体系（增量：定义 44–49 符号）

| 符号 | 含义 | 定义 |
|---|---|---|
| τ_obs, τ_cert, τ_use | 观测/可用/消费时刻 | 证书双时间戳；L_e2e=τ_use−τ_obs |
| D(θ) | 延迟预算 | (m̂−θ)/λ，边际衰减到阈值前的最大允许年龄 |
| m(c) | anytime 改进曲线 | 观测年龄 c 内可得的最好下界；单调、凹、有界 |
| U(c)=m(c)−λc | 可用边际 | 真正可用于守卫的量；凹函数 |
| c* | 最优停止时刻 | 若 m'(0)≤λ 则 0，否则 m'(c*)=λ |
| D_j(θ_j) | 作业 deadline | max{c: m_j(c) ≥ θ_j+λ_j c} |
| LUF / AUF | 延迟-效用前沿 / 面积 | Pareto{(L_p99,U_task,R_cat)}，AUF=∫U_task dL |
| ΔU(L) | 等延迟增益 | U_LSC(L)−U_base(L) |
| N_i | 创新点条目 | (claim,evidence,baseline,ablation,falsifier,effect) |
| debt_i / 负债率 | 创新负债 | max(0,effect_unmatched−effect_matched)；Σdebt/Σeffect_unmatched |
| C_max | 认证延迟上界 | WCET 或保守上界；hard 轨才可进安全守卫 |

## 2. 关键算法（伪代码）

### IP-60 LSC：任意时间曲线、可用边际与最优停止
```
def anytime_lower_bound(x_obs, budget_c):           # 复用 v20 L0/L1
    b = cert_lookup(x_obs)                          # 或 INT8 监控，随时间加深
    return b.m_lo                                   # 保证随 c 单调（取包络 max）

def fit_envelope(samples):                          # 离线/在线校准
    # samples: [(c, m)]，拟合单调凹包络 m(c)，保守取逐点上界
    return concave_monotone_envelope(samples)

def usable_margin(m_curve, c, lam):
    return m_curve(c) - lam * c                     # 定义 45

def optimal_stop(m_curve, lam, c_max):
    if slope(m_curve, 0) <= lam:                    # 衰减主导
        return 0
    lo, hi = 0.0, c_max                             # 凹 => 三分/二分
    while hi - lo > EPS:
        mid = (lo + hi) / 2
        if slope(m_curve, mid) > lam: lo = mid
        else: hi = mid
    return (lo + hi) / 2                            # m'(c*)=lambda

def latency_sound_margin(x_obs, t_use, lam, theta, c_max):
    age = t_use - x_obs.tau_obs                     # 真实端到端年龄
    c_star = optimal_stop(m_curve_of(x_obs), lam, c_max)
    m = anytime_lower_bound(x_obs, c_star)
    m_eff = m - lam * age
    if age > (m - theta) / lam:                     # 超 D(theta)
        return None, Downgrade(age, m)              # 绝不返回过期结论
    return m_eff, None

def hard_soft_cert(x_obs, wcet, delta, theta, lam):
    hard = latency_sound_margin(x_obs, now()+wcet, lam, theta, wcet)
    if hard is not CERT_OK:
        return None, FALLBACK_SERIAL            # 安全守卫只吃 hard 轨
    soft_delta = conformal_tail_latency(x_obs, delta)
    return hard, soft_delta
```

### IP-61 LAS：边际导出 deadline、准入与单调降级
```
def job_deadline(m_curve, theta, lam):
    # max c s.t. m(c) - lam*c >= theta，即 U(c) >= theta
    return argmax_age(m_curve, lambda c: usable_margin(m_curve,c,lam) >= theta)

def schedule(jobs, overload):
    for j in jobs:
        j.D = job_deadline(j.m_curve, j.theta, j.lam)
    if overload:                                    # HI 模式：只删不增
        jobs = [j for j in jobs if j.kappa >= K_GEOMETRY]
        jobs = [j for j in jobs if j.wcet <= j.D]   # 准入：不可行不启动
        reserve_budget(SAFETY_MONITOR, B_safe)
        disable_batching()                          # 尾延迟隔离
    return edf(jobs)                                # 按 D 排序 + RTA 校验

def on_job_finish(j, t):
    if t - j.tau_obs > j.D:                         # 超期
        return downgrade(j.m_prev, j.tau_prev, t)   # 单调降级
    return j.m_lo - j.lam * (t - j.tau_obs)          # m_eff

def downgrade(m_prev, tau_prev, t, lam):
    # 用上一条仍有效下界的衰减值；无有效则回退串行安全路径
    m_fbk = m_prev - lam * (t - tau_prev)
    return m_fbk if m_fbk >= THETA_MIN else SERIAL_PATH
```

### IP-62 LUF / IP-63 NLA：前沿扫描与等延迟审计
```
def luf_sweep(configs, latencies, episodes):
    points = []
    for cfg in configs:
        for L in latencies:                         # 等延迟预算
            run = simulate(cfg, inject_latency=L, episodes=episodes)
            points.append((run.p99_latency, run.utility, run.cat_risk, cfg))
    return pareto(points)                           # 三维 Pareto 面

def matched_latency_effect(claim, L):
    base = run_baseline(claim.baseline, latency=L, budget=claim.budget)
    ours = run_method(claim.method,     latency=L, budget=claim.budget)
    return paired_diff(ours.score, base.score, claim.effect_metric)

def audit_claim(claim):
    eff_matched = min over L of matched_latency_effect(claim, L)
    eff_unmatched = claim.reported_effect            # 原始（非等延迟）效应
    debt = max(0.0, eff_unmatched - eff_matched)     # 定义 48
    abl = run_ablation(claim.mechanism)               # 去掉机制的效应
    necessary = (eff_matched - abl.effect) >= ABL_EPS
    falsified = not exec_falsifier(claim.falsifier)  # falsifier 应能击倒
    return ClaimResult(claim, eff_matched, debt,
                       necessary, falsified,
                       novel=(eff_matched > 0 and necessary and not falsified))

def novelty_debt_ratio(results):
    return sum(r.debt for r in results) / max(sum(r.claim.reported_effect for r in results), EPS)
```

### IP-51/52/56 升级：m_eff 守卫与 hard 轨 deadline
```
def car_guard_v2(e, x, cert, persona, lease, t):
    theta = cert.alpha_e[e] * cert.theta_sim[e]
    m_eff, dg = latency_sound_margin(x, t, lease.lam, theta, lease.c_max)
    if dg is not None:                              # 超期 => 降级，不用 m
        return guard_with(downgrade_margin(dg, e), theta)
    m_cap = persona_cap[e](persona)
    return min(m_eff, m_cap) >= theta

def certify_light_v4(x, guards, persona, budget_us, kappa):
    c_star = optimal_stop(m_curve_of(x), lam_of(x), budget_us)
    b = anytime_lower_bound(x, c_star)
    lease = Lease(m=b.m_lo, tau_obs=x.tau_obs, tau_cert=now(),
                  lam=lam_of(x), kappa=kappa, c_max=wcet_of(x))
    if not guards_undecided(b):                      # 仍在 D 内
        if now() - x.tau_obs <= (b.m_lo - theta)/lease.lam:
            return b, lease, -1
    return downgrade_monotone(b), lease, T0_STATUS    # T0 尽力，但 hard 轨把关
```

## 4. 实验设计（E95–E102，硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E95 延迟 soundness | 0–500ms 注入下过期证书进入守卫；p999 尾部静默失效；检出时延 | 0；0；<1 个控制周期 |
| E96 anytime 曲线校准 | m(c) 凹包络拟合误差；c* 与网格搜索效用差；20 个状态单元一致率 | R²≥0.95；<3%；≥95% |
| E97 前沿外扩 | AUF 相对 latency-agnostic；p99 处效用增益；灾难风险 | ≥+15%；≥+5pp；不高于基线 |
| E98 等延迟审计 | matched-latency 仍成立 claim 比例；创新负债率；消融必要性 | ≥80%；<10%；≥70% |
| E99 deadline 调度 | deadline 错过率；过载下过期使用；HI 模式降级正确性 | <1%；0；100% |
| E100 实机延迟 | 动态障碍 + 0/100/200ms 注入违例；任务成功率 | 0；≥无延迟基线的 90% |
| E101 可复现性 | 3 条 headline claim 干净环境复现；CI 重叠 | 全部复现；重叠 |
| E102 端到端消融 | 去 LSC 前沿收缩；去 LAS 效用损失；去 NLA 债务检出 | ≥10%；≥10%；可检出 |

回退：E95 任一过期进入守卫 → 关闭 anytime，退回 v20 固定短租约 + 串行监控；E96 曲线非凹/不可校准 → 只用固定保守预算，不做最优停止；E97 无外扩 → 承认延迟感知无系统收益，只保留理论贡献；E98 负债率超标 → 砍掉被判负债的 IP，只保留定理与消融后仍成立的机制；E99 deadline 不可行 → 提高 λ 保守度、缩短预算、HI 模式只保 safety；E101 不可复现 → 该 claim 降级为「初步观察」，不得写入论文。

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| m(c) 在真实边缘端非凹/非平稳（缓存、动态批、温漂），最优停止失效 | 高 | E96 红线；拟合单调凹**保守包络**而非点估计；按状态单元分层；失配即回退固定预算 |
| WCET 高估使 deadline 不可行，可用性崩塌 | 高 | E99 红线；hard/soft 双轨；HI 模式先砍个性化/投机；无法给 WCET 时显式 δ 并禁入 hard 守卫 |
| 批处理提升吞吐但放大尾延迟，安全作业被拖过 D | 中-高 | HI 模式禁批处理；安全作业独立队列；按请求 deadline 而非批 deadline 调度 |
| 等延迟基线不公平（base 无 anytime / 算力更少），制造假创新 | 高 | E98 红线；base 同延迟同算力且允许 early-exit；公开脚本与数据；CI 复现 |
| 审计把大部分既有 IP 判为创新负债，影响论文故事 | 中-高 | 提前接受「剪枝」；把负债率本身作为方法贡献；只保留定理 + 消融后仍成立的机制 |
| 延迟注入仿真与真机差距，导致前沿图过于乐观 | 中 | E100 真机校准；注入覆盖排队/抢占/批处理三源；报告最坏延迟而非仅 p99 |
| τ_obs 本身有传感器延迟且不可观测，L_e2e 被低估 | 中-高 | 硬件时间戳 + 曝光时刻校准；把传感器延迟计入 C_max；E95 专门注入 |
| LUF 用平均延迟画图掩盖长尾，出现「假外扩」 | 中 | 主图强制 p99/p999/最大延迟三轴；AUF 用上包络而非平均 |

## 6. 本轮最大风险

**一句话**：m(c) 的「单调凹 + 平稳」与 WCET 在真实边缘端都可能不成立（缓存、动态批处理、温漂会让曲线非凹、尾部不可控），此时最优停止点会算错；而等延迟审计又可能一次性把大部分既有 IP 判为创新负债——因此 E96（曲线校准）与 E98（等延迟审计）必须设为红线，并永久保留 v20 的「固定短租约 + 串行监控」作为永不失 sound 的底线。
