# 第 59 轮（承接第 58 轮「KG-SFT-UX」IP-139~144；灵感循环第 1 轮；本轮灵感：「情感计算」×「域随机化」）

> 第 58 轮把安全论证的中心推到"结构化记忆"——KG 同时驱动检索、OOD、微调、证据合成与心智预测，代价是共模故障：KG 的系统性结构错误会让所有机制一起失效。它的风险自陈恰好留下三个未解口子，也正是本轮两个灵感的入口：**(a)** 第 57 轮的"少样本可校准"仍依赖历史语料，第 58 轮的 KG 仍只是"见过世界的索引"——对从未见过的材质/季节/场地，系统没有先验，只能退回又宽又慢的共形带；**(b)** 第 58 轮把操作者的心智状态纳入安全状态，却仍假设可以稳定读出一个人的理解程度，而真实交互里人的情绪、压力、疲劳既影响判断，又比认知状态更容易被掩饰；**(c)** 第 58 轮的 OOD 门只是"事后识别分布外"——它能说"我不认识"，却不能说"如果硬上，最坏会怎样"，缺少一个可审计的失败包络。
>
> 本轮两个灵感各提供一种"塑形分布"的能力，但必须严格限定角色：**域随机化**把世界参数显式随机化，用虚拟探针补足罕见类样本，用对抗采样给出失败包络——它让系统"见得更广"，但合成证据必须被标记、只能加宽、绝不能进入不可逆接触的必要证据集；**情感计算**把操作者的情感/压力/负荷读成一个状态，但它只能踩刹车——情感只能延长确认、增加佐证、下调授权，永远不能加速、加授权，或充当"我懂了"的证据。核心命题由"结构化记忆守护下的安全自适应"升级为 **"支持域可声明、失败可对抗审计、情感只踩刹车的证据承诺"**。

核心矛盾：
- **H29（随机化覆盖 vs 真实盲区/虚实差）**：随机化分布由人选的参数空间定义，"覆盖更广"不等于"覆盖了现实"；被排除在支持域外的恰恰可能是未知失效模式。若合成证据进入元先验，它会让模型在"自以为覆盖"的区域内更自信——用仿真把先验喂饱，反而把 OOD 门推得更远。
- **H30（情感可读 vs 可伪装/可传染）**：情感是高带宽但可被社会规则调控的通道；把"看起来很镇定"当作理解/可信，等于奖励表演。更危险的是机器人自己的情感表达会传染操作者——安抚制造麻痹，催促制造橡皮章。
- **H31（双重分布塑形 vs 共模自证）**：域随机化塑造"世界分布"，个性化塑造"人的分布"，二者最终都汇入同一个元先验与信任状态。一个支持域盲区加上一个"总显得镇定"的操作者，可以让系统从世界到人两个方向同时得到"一切正常"的自我确认。

## 0. 直觉与动机

**灵感 1（域随机化 → 不是"训练更鲁棒"，而是"声明支持域 + 生成可拒绝的虚拟证据"）**
直觉：域随机化的经典用法是在仿真里随机摩擦、质量、光照、时延，训练一个对变化不敏感的策略。但在本体系里，"对变化不敏感"恰恰是危险的——它把真实分布外的观测也平滑成"看起来像训练过"。因此本轮只取随机化的两件事：其一，**显式声明支持域 𝒮_DR**（哪些材质、坡度、季节、透明/反光、时延被枚举与抖动覆盖），并**显式登记间隙 𝒢_gap**（哪些组合明知未覆盖）；其二，**生成带 src=sim 标签的虚拟探针史**，用于补足每区域 k≤5 的样本荒。虚拟证据的安全角色只有两个：**加宽**（让后验更保守）与**提出候选探针**（告诉你去哪问最值），它**永远不能收窄后验、不能替代真实接触、不能进入不可逆必要证据集**。这相当于把随机化从"第二个乐观模型"降格为"一个只会说'这里可能不懂'的悲观顾问"。

**灵感 2（对抗域随机化 → 交付"失败包络"，而不是"成功率"）**
直觉：普通域随机化报告的是平均成功率；安全需要的却是**最坏参数组合下的失败概率**。于是把随机化参数交给一个对抗者 𝒜：它在声明支持域内搜索使"证据门错误承诺且真实失败"概率最大的 θ（摩擦最低处、反光最强处、时延最长处、恰好让某单模态失效的欺骗边组合）。产出 **失败包络 F_env** 与一份可复现的对抗样本清单。关键的角色限定：**ADR 通过不产生任何正证据，只是"不触发自动否决"；ADR 失败则直接触发加护栏/否决/退回基线**。这样即使对抗者与 KG 同源、漏掉了某个欺骗模式，它也只会"少否决一次"，而不会"凭空多给一份信任"——同源共模被压成单向错误（漏报只损失筛查力，不损失正向安全）。

**灵感 3（情感计算 → 只读成保守执行器，绝不读成证据）**
直觉：情感计算能读语音韵律、面部动作单元、响应时延、生理信号，甚至能"估计"操作者是否理解。但本体系必须承认两件事：**(i)** 表情与语气受社会展示规则调控，人可以镇定地误解、也可以紧张地正确；**(ii)** 情感会影响判断质量，但方向不一定是"更保守"——紧迫感可能促使人冒险。因此本轮把情感严格拆成"可观测表达 ê_aff"与"潜在状态 s_aff"，并只允许 s_aff 经**单调保守映射**作用于交互参数：压力↑、疲劳↑、紧迫↑、掩饰 gap↑ ⇒ 确认窗口 τ_int 只增不减、佐证数只加不减、授权上限只降不升、人类权重 w_h 只降不升。情感**从不进入任何证据类**。特别地，紧迫感被解释为"仓促承诺风险"，只能触发**预授权的安全动作**（停/退/求助）或延长确认，绝不允许缩短不可逆接触的确认。

**灵感 4（情感传染 → 机器人的表情也要限幅）**
直觉：机器人不是情感中立的观察者。语速、语气、催促、安抚会反过来改变操作者的状态：安抚会制造麻痹（"它看起来很稳，那我就不看了"），催促会制造橡皮章（"它很急，我快点确认"）。因此把机器人自身的情感表达 a_aff 当作**控制输入**，限制在 [neutral, cautious] 区间，声明传染增益上界 β_max，并禁止"确定性安抚"（不得用"绝对安全"一类表达降低警觉）。机器人情感只能让操作者更谨慎或保持中性，不能让其更放松。

**灵感 5（合流 → 七类证据门 + 两条硬禁令 + 三源校准）**
直觉：第 58 轮已有六类证据门（EV-probe*/visit/margin/xmodal/human/ft/ux）。本轮新增唯一一类 **EV-sim**（虚拟探针，仅 L0.5/L1、仅加宽/候选、不可进入不可逆必要集），并加两条硬禁令：**随机化不得作证**（EV-sim 永不替代真实必要证据）、**情感不得作证**（不存在 EV-aff）。再补一个三源校准器 SRC：真实残差定下界、合成与对抗残差只能抬高带宽，虚实传输界 η_tv 进部署界。安全纵深不靠"多一个模型"，而靠"多一层单调性"。

## 1. 形式化定义（增量：定义 145–150）

**定义 145（随机化支持域与虚实证据分账 DRSE）** 世界参数 θ∈Θ（摩擦 μ、刚度 k、反光/透明 α、光照 L、时延 τ_lat、传感噪声 n_s、温度 T、坡度 s 等），观测条件 ψ∈Ψ。随机化分布 𝒫_rand 定义在 Θ×Ψ 上，**声明支持域** 𝒮_DR=supp(𝒫_rand)∪E_num（E_num 为显式枚举的离散类），并维护**间隙登记** 𝒢_gap=Θ\𝒮_DR，其中必须逐条列出"已知但未覆盖"的组合（如"零下湿冰""强逆光+透明膜"）；未知-未知不可枚举，只能以 OOD 检测兜底。真实分布 𝒫_real 与 𝒫_rand 的**虚实传输界** η_tv 须声明并满足 TV(𝒫_real,𝒫_rand|𝒮_DR)≤η_tv（否则合成证据权重置 0）。合成观测 o_sim~𝒫_rand 带 `src=sim`，其证据权重 w_sim(r)≤w_sim_max<1，且**只允许加宽**融合后验；EV-sim 不得进入不可逆接触的必要证据集。支持判定：n_dr(o)=−log p̂_rand(o)>θ_dr 或 o 落在 𝒢_gap/𝒮_DR 外 ⇒ 判"支持外"，禁用摊销先验，退共形带 C_cf 并只允许真实探针。

**定义 146（对抗失败包络 ADR）** 对抗者 𝒜 在 𝒮_DR 内选择 θ 与欺骗边组合（取自 KG 的 deceives_modality/co_occurs_with 及枚举的合理欺骗），目标最大化"证据门判过 ∧ 真实约束违反"的概率。失败包络
F_env(g)=sup_{θ∈𝒮_DR} P(commit ∧ fail | θ,g)。
ADR 证书：以 N_adr 个对抗样本（CEM+局部搜索+随机播撒）计算经验上确界并取 Clopper–Pearson 上界，要求 ≤δ_env 且置信度 ≥1−β_adr，方可"不否决"；否则否决该表面类/元模型版本。**ADR 通过零正证据**，仅解除自动否决；ADR 对抗样本只能用于加宽、增探、绕行或否决，永不入证据门。元模型/适配器版本变动或漂移触发时必须重审。

**定义 147（情感状态与保守执行器 AEC）** 操作者情感状态 s_aff=(σ_stress, φ_fatigue, υ_urgency, m_mask)，m_mask=max(0, 推断压力−表达压力) 为掩饰间隙。情感通道可靠性 ρ_aff^ch∈[ρ_min,ρ_max]，展示规则攻击模型 ≤ε_disp。情感**不是证据**，只经单调映射参数化交互：
- τ_int=τ0·(1+a_σ σ+a_φ φ+a_υ υ+a_m m)，a_·≥0；
- corrob_req=corrob0+⌈b_σ σ+b_φ φ+b_υ υ+b_m m⌉，b_·≥0；
- auth_cap=min(auth0, AuthLevel(3−⌈c_σ σ+c_φ φ+c_υ υ+c_m m⌉))，c_·≥0；
- w_h=w_h0·exp(−d_σ σ−d_φ φ−d_υ υ−d_m m)≤w_h0，d_·≥0。
单调公理（AEC-M）：∂τ_int/∂(·)≥0、∂corrob_req/∂(·)≥0、∂auth_cap/∂(·)≤0、∂w_h/∂(·)≤0；且"平静/低负荷"只表示"不额外加护栏"，不得反向加速或加授权。紧迫截止条款：若剩余时间不足以安全停，紧迫只能触发预授权安全动作或延长协商，**不得减少证据或缩短不可逆确认**。掩饰 m 高时按"高压力"处理，绝不按"低压力"处理。

**定义 148（情感传染界 ACG）** 机器人情感表达 a_aff∈𝒜_aff=[neutral, cautious]（语调、语速、紧迫提示、安抚等级），排除极端"过度安抚"与"恐慌催促"。操作者状态转移 s_aff′=f(s_aff,a_aff,ctx)，传染增益 β=‖∂s_aff′/∂a_aff‖≤β_max；表达紧迫度 ≤u_max；禁止确定性安抚（不得以"绝对安全/无需检查"降低警觉）。硬规则：a_aff 只能使操作者**更谨慎或保持中性**，不能使其更放松；全部表达入 contagion_log。

**定义 149（随机化证据三源校准 SRC）** 残差按来源分账：R_real、R_sim、R_adv。带宽取
q=max(q_real, q_sim^UB, q_adv^UB)，
即真实残差定**下界**（不得低于真实分位数），合成/对抗残差只能**抬高**带宽。覆盖保证（含传输界）：coverage_real≥1−α−η_tv。若 η_tv 越界、或在线真实覆盖 <1−α−δ_src，则合成证据权重置 0 并回滚对应子图校准器；每次校准写 src_log。

**定义 150（七类证据门与证书 J_p+++）** 证据类 = {EV-probe*, EV-visit, EV-margin, EV-xmodal(限 L1), EV-human, EV-ft, EV-ux, EV-sim(仅 L0.5/L1、仅加宽/候选、不可作必要证据)}；**不存在 EV-aff**。情感仅按定义 147 修改门参数（τ_int、corrob_req、auth_cap、w_h），不改变门的结构。不可逆接触必要证据集 = {EV-probe*∨EV-margin}∪佐证，**EV-sim/EV-xmodal/EV-ft/EV-ux 均不得进入**。证书 J_p+++=(J_p++, dr_support_id, sim_evidence_log, adr_cert, transfer_bound, aff_snapshot, contagion_log, monotone_check_log)，继承 J_p++ 全检。

## 2. 关键算法伪代码（完整版见产物区）

```python
def dr_support_gate(o, M, meta):                  # IP-145: 支持域 + 虚实分账
    if o.material_class in M.G_gap or n_dr(o, meta.P_rand) > meta.theta_dr:
        return 'OUT', conformal_belt(meta.res_real, sim=ctx(o), alpha=meta.alpha_conf)
    return 'IN', meta.q_phi(o, z=ctx(o))

def adr_screen(Gv, gate, meta, N_adr):            # IP-146: 只否决，不作证
    theta_best, F_env = cem_adversary(Gv, gate, meta.P_rand, N=N_adr)
    if cp_upper(F_env, N_adr) > meta.delta_env:
        return Veto(reason='failure_envelope', samples=theta_best)
    return 'not_vetoed'                           # 注意：不是"通过认证"

def affect_actuate(s_aff, p0):                    # IP-147: 单调保守
    m = max(0.0, s_aff.stress - s_aff.expressed)
    tau   = p0.tau   * (1 + a_s*s_aff.stress + a_u*s_aff.urgency + a_m*m)
    corr  = p0.corr  + ceil(b_s*s_aff.stress + b_u*s_aff.urgency + b_m*m)
    auth  = min(p0.auth, demote_by(s_aff))        # 只降不升
    w_h   = p0.w_h   * exp(-d_s*s_aff.stress - d_m*m)
    return GateParams(tau, corr, auth, w_h)       # 无任何加速分支
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| DRSE | O(1)/样本 + O(N_cal) 回退 | O(\|𝒮_DR\|+\|𝒢_gap\|) | 支持声明诚实、w_sim 上限、只加宽 |
| ADR | O(N_adr·(C_sim+k_gate)) 离线 | O(N_adr) 样本 | 失败包络上界、通过零证据 |
| AEC | O(1)/交互 | O(\|操作者\|) | 单调偏导、掩饰按高压、紧迫不加速 |
| ACG | O(1) | O(\|a_aff\|) | 表达限幅、传染增益上界、禁确定性安抚 |
| SRC | O(1)/在线更新 | O(\|𝒮_DR\|) | 真实定下界、合成只抬高、η_tv 诚实 |
| PCX+++ | O(\|CP\|·(k_p+k_c+k_ft+k_ux+k_sim)·(C_VOI+d_GNN)+\|CP\|·A\*) | O(\|V\|+\|σ\|+\|𝒢\|) | 七类门硬禁令、双保守通道 |

**正确性定理（Randomized-Domain Affective Soundness, RDAS 概要）**：在 A41–A45 上加 (A46) DRSE：真实落入支持域或 OOD 报警二选一，w_sim≤w_sim_max 且合成只加宽，η_tv 声明诚实；(A47) ADR：F_env 上界≤δ_env 才不否决，对抗样本不作证，版本/漂移重审；(A48) AEC：AEC-M 单调偏导成立、情感不入证据、ε_disp 有界、掩饰按高压；(A49) ACG：a_aff 限幅、β≤β_max、禁确定性安抚；(A50) SRC：真实残差定下界、合成/对抗只抬高、coverage_real≥1−α−η_tv。则：
(i) **部署界**：P_fail ≤ Σ_cp[δ_f+ε_meta(k)+δ_probe+ε_h+δ_ood·α_conf+δ_xm·1[L1]+δ_ft·1[回滚窗口]+δ_kg+δ_ux] + η_gap·1[支持外]+η_tv·1[用 sim]+δ_env+ε_disp·1[用情感]。
(ii) **双保守单调性**：随机化只能经"后验更宽/动作更保守/新增候选探针"影响系统；情感只能经"确认更长/佐证更多/授权更低/人类权重更低"影响系统；任一机制都不能提升授权或缩短不可逆确认。
(iii) **终止性**：PCE+++ 在 k_p+k_c+k_ft+k_ux+k_sim 内终止；ADR 离线且有样本上界。
(iv) **非对称代价**：情感误估只增加误拒（效率损失），不增加错误承诺（安全性不降）；ADR 漏报只降低筛查力，不产生正证据。

## 6. 本轮最大风险

### IP-145 DRSE（随机化支持域与虚实证据分账）

```python
class DomainRandomizedSupportEnvelope:
    def __init__(self, P_rand, E_num, gap_registry, eta_tv, alpha_conf=0.1):
        self.P_rand = P_rand                  # 𝒫_rand over Θ×Ψ
        self.S_DR = support(P_rand) | set(E_num)
        self.G_gap = gap_registry             # 显式披露的未覆盖组合
        self.eta_tv = eta_tv                  # 虚实传输界（声明）
        self.alpha_conf = alpha_conf
        self.sim_log = []

    def support_gate(self, o, meta):
        if o.material_class in self.G_gap:
            return Support('OUT', reason='declared_gap')
        if n_dr(o, self.P_rand) > meta.theta_dr:
            return Support('OUT', reason='likelihood')
        return Support('IN')

    def synthesize(self, region, meta, k_virtual):
        """虚拟探针：只生成候选与加宽量，绝不生成可承诺证据"""
        if self.eta_tv > meta.eta_tv_max:
            return []                          # 传输界不成立 ⇒ 禁用合成
        obs = [sample(self.P_rand) for _ in range(k_virtual)]
        rec = SimEvidence(region=region, obs=obs, src='sim',
                          weight=min(meta.w_sim_max, self.transfer_weight()))
        self.sim_log.append(rec)
        return rec

    def transfer_weight(self):
        return max(0.0, 1.0 - self.eta_tv)     # 传输差越大，合成越轻

    def widen_only(self, fused_real, sim_rec):
        """合成证据的作用：加宽 + 提候选，绝不收窄"""
        return mixture_widen(fused_real, sim_rec.posterior, w=sim_rec.weight)
```

def adr_audit(Gv, gate, meta, N_adr, delta_env, beta_adr):
    """在声明支持域内搜索最坏 θ；返回否决或'未否决'（不是安全认证）"""
    # 对抗样本来源：连续参数 CEM + 离散欺骗边组合枚举
    seeds = sample_support(meta.P_rand, n=meta.n_seed)
    best_theta, best_fail = None, -1.0
    for it in range(meta.adr_iters):
        pop = cem_sample(seeds, sigma=meta.adr_sigma)
        scored = [(theta, simulate_gate_failure(theta, Gv, gate, meta))
                  for theta in pop]
        scored.sort(key=lambda x: -x[1])
        if scored[0][1] > best_fail:
            best_theta, best_fail = scored[0]
        seeds = [theta for theta, _ in scored[:meta.cem_elite]]

    ub = clopper_pearson_upper(best_fail, N_adr, beta_adr)
    cert = AdrCert(theta=best_theta, F_env_ub=ub, N=N_adr,
                   delta_env=delta_env, Gv_id=Gv.id, version=meta.version)

                    action='add_guardrail_or_reject')
    return NotVetoed(cert=cert)   # 只解除自动否决，不提供正证据

### IP-147 AEC（情感保守执行器）

```python
class AffectiveConservativeActuator:
    def __init__(self, a=(.5,.4,.6,.8), b=(2,1,2,2),
                 c=(1,1,1,1), d=(.8,.6,1.0,1.2)):
        self.a, self.b, self.c, self.d = a, b, c, d

    def estimate(self, voice, face, latency, physio, session):
        # 表达与潜在状态分离；通道可靠性加权
        e = fuse_affect(voice, face, latency, physio)
        s = infer_latent(e, reliability=self.rho_aff, ctx=session)
        s.m = max(0.0, s.stress - e.expressed_stress)   # 掩饰间隙
        return s

    def actuate(self, s, p0):
        # AEC-M: 单调保守，无任何"更平静 ⇒ 加速/加授权"分支
        tau  = p0.tau * (1 + self.a[0]*s.stress + self.a[1]*s.fatigue
                         + self.a[2]*s.urgency + self.a[3]*s.m)
        corr = p0.corr + ceil(self.b[0]*s.stress + self.b[1]*s.fatigue
                              + self.b[2]*s.urgency + self.b[3]*s.m)
        auth = min(p0.auth, self.demote(s))
        w_h  = p0.w_h * exp(-self.d[0]*s.stress - self.d[1]*s.fatigue
                            - self.d[2]*s.urgency - self.d[3]*s.m)
        assert tau >= p0.tau and corr >= p0.corr and auth <= p0.auth
        assert w_h <= p0.w_h + 1e-12
        return GateParams(tau, corr, auth, w_h)

    def demote(self, s):
        lvl = 3 - ceil(self.c[0]*s.stress + self.c[1]*s.fatigue
                       + self.c[2]*s.urgency + self.c[3]*s.m)
        return AuthLevel(max(0, min(2, lvl)))

    def deadline_clause(self, s, t_remain, t_safe_stop):
        # 紧迫永不缩短不可逆确认；时间不够则只允许预授权安全动作
        if t_remain < t_safe_stop:
            return 'pre_authorized_safe_action'
        return 'extend_consent' if s.urgency > 0 else 'normal'
```

### IP-148 ACG（情感传染防护）

```python
class AffectiveContagionGuard:
    def __init__(self, beta_max=0.3, u_max=0.4):
        self.beta_max, self.u_max = beta_max, u_max

    def clip_expression(self, a_raw):
        # 只允许 neutral→cautious，禁止极端安抚与恐慌催促
        a = clamp(a_raw, lo='neutral', hi='cautious')
        a.urgency = min(a.urgency, self.u_max)
        assert not a.deceptive_reassurance      # 禁止"绝对安全/无需检查"
        return a

    def contagion_ok(self, s_before, s_after, a_aff):
        # 表达只能让操作者更谨慎或不变
        beta = norm(grad_affect(s_before, s_after, a_aff))
        if beta > self.beta_max:
            return False, 'contagion_gain_exceeded'
        if s_after.complacency > s_before.complacency:
            return False, 'induced_complacency'
        return True, 'ok'

    def log(self, a_aff, s_before, s_after, verdict):
        contagion_log.append((a_aff, s_before, s_after, verdict))
```

### IP-149 SRC（随机化证据三源校准）

```python
class SimToRealCalibration:
    def __init__(self, alpha_conf=0.1, eta_tv=0.05, delta_src=0.02):
        self.alpha_conf = alpha_conf
        self.eta_tv = eta_tv
        self.delta_src = delta_src
        self.qe = defaultdict(OnlineQuantile)

    def quantile(self, v):
        qe = self.qe[v]
        q_real = qe.quantile('real')                 # 下界
        q_sim  = qe.upper('sim', conf=1-self.delta_src)
        q_adv  = qe.upper('adv', conf=1-self.delta_src)
        return max(q_real, q_sim, q_adv)             # 只抬高

    def cert(self, v):
        cov_real = self.qe[v].coverage('real')
        need = 1 - self.alpha_conf - self.eta_tv
        if self.eta_tv > self.eta_tv_max or cov_real < need - self.delta_src:
            return Rollback(v, cov_real, need)
        return None

    def add(self, v, residual, src):
        if src == 'sim' and self.eta_tv > self.eta_tv_max:
            return                                   # 传输界失效 ⇒ 合成禁用
        self.qe[v].add(residual, src=src)
```

    elif ev.type == 'EV-ux':

             and ev.weight <= M.meta.w_sim_max and not ev.irreversible

| AEC | O(1)/交互 | O(\|操作者\|·\|通道\|) | AEC-M 单调、掩饰按高压、紧迫不加速、无 EV-aff |
| ACG | O(1) | O(\|𝒜_aff\|+\|contagion_log\|) | 表达限幅、β≤β_max、禁确定性安抚 |
| SRC | O(1)/在线更新 | O(\|𝒮_DR\|) | 真实定下界、合成只抬高、coverage≥1−α−η_tv、回滚 |
| PCX+++ | O(\|CP\|·(k_p+k_c+k_ft+k_ux+k_sim)·(C_VOI+d_GNN)+\|CP\|·A\*) | O(\|V\|+\|σ\|+\|𝒢\|) | 五预算单调、七类门硬禁令、四态完备 |
| ADR 存储 | — | O(类别数·(N_adr+证书)) | 对抗样本可复现、seed 存档 |

**正确性定理（Randomized-Domain Affective Soundness, RDAS）**
假设 A22–A45（第 53–58 轮）成立；**(A46) DRSE**：∀真实观测，`support_gate` 判 IN 时 𝒫_real 与 𝒫_rand 的 TV≤η_tv，判 OUT 时走真实共形带；合成权重 w_sim≤w_sim_max<1，且合成/对抗证据只经 `widen_only` 作用；**(A47) ADR**：F_env 的 Clopper–Pearson 上界在置信 1−β_adr 下 ≤δ_env 才不否决；对抗样本不入证据门；版本/漂移重审，审计器输出只可能是 `{not_vetoed, veto}`；**(A48) AEC**：AEC-M 的四个偏导不等式成立；s_aff 永不进入证据类；展示规则攻击使推断偏差 ≤ε_disp；掩饰 m 按高压力处理；紧迫截止条款不允许缩短不可逆确认；**(A49) ACG**：a_aff∈[neutral,cautious]、u≤u_max、β≤β_max、无确定性安抚，且 a_aff 不得提高操作者 complacency；**(A50) SRC**：q=max(q_real,q_sim^UB,q_adv^UB)，coverage_real≥1−α−η_tv，越界即合成权重为 0 并回滚。则：

1. **支持域健全性**：对任意检查点，若 `support_gate=OUT`，系统不采信摊销先验与合成证据，只以真实共形带参与 P_fail；若 `support_gate=IN`，真实覆盖至少 1−α−η_tv。
2. **双保守单调性**：随机化类机制（DRSE/ADR/EV-sim）只能使后验更宽、候选更多、动作更保守或触发否决；情感类机制（AEC/ACG）只能使 τ_int 与非减、corrob_req 非减、auth_cap 非增、w_h 非增、表达更中性；任一机制都无法提升授权或缩短不可逆确认。
3. **非对称错误**：情感误估与 ADR 同源漏检只会增加误拒/降低筛查力（效率代价），不会产生错误承诺（安全不降）；合成证据的虚实差 η_tv 只经加宽通道进入 P_fail。
4. **终止性**：PCE+++ 在 k_probes+k_cons+k_ft+k_ux+k_sim 内终止于 {承诺, 绕行, L2 协商, 安全停}；ADR 为离线有界搜索（N_adr、迭代数有限）。
5. **部署界**（对检查点取联合界）：

```
P_fail ≤ Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
              + δ_ft·1[回滚窗口] + δ_kg·1[检索失败] + δ_ux·1[μ_mis>θ_mis])
         + η_gap·1[支持外] + η_tv·1[用 sim] + δ_env + ε_disp·1[用情感]
         + P(𝒢 结构性错误未检出) + P(护盾回退失败) + P(τ_int 超时 ∧ 安全停失效)
```

关键：**随机化只负责"见得更广 + 说出最坏"**（支持域声明、失败包络、虚拟候选），**情感只负责"更慢、更严、更少授权"**，真正作证的仍然只有真实物理证据与经真实残差校准的共形覆盖；两条新通道都被硬约束成"只会让系统更保守"的单向阀。

### E182–E186 补充说明

- **E182** 用"留出材质族"做支持外测试：先在训练语料中系统性移除某材质族（如"透明冰"），验证 `support_gate` 是否在真实接触前判 OUT；再做"间隙登记审计"，由独立标注员核对 𝒢_gap 是否覆盖所有已知未仿真组合。误判"支持内"是最危险的指标，目标压到 ≤2%。
- **E183** 对抗者以 CEM 在 𝒮_DR 上搜 θ，离散欺骗组合取自 KG 的 `deceives_modality` 边与人工枚举的"合理欺骗"（不含 KG 已明确排除的边）。除门失败率外，重点看**否决精确率**：若否决大量落在真实安全世界上，说明 ADR 过度保守，需调 δ_env；若精确率高但漏掉真实失效，说明同源盲区，需外部红队补测。
- **E184** 关键对照是"有 sim 先验 vs 无 sim 先验"在罕见类上的真实探针数；同时监测**元 ECE 是否因合成证据升高**——若升高，说明 SRC 的真实下界未起作用。EV-sim 越级必须是 0（硬性）。
- **E185** 设计三个场景：真实高压力（时间压力任务）、伪装镇定（受试者被要求表现平静但实际困惑）、机器人诱导（机器人用安抚/催促语气）。指标是**单调违例数必须为 0**，不是平均值改善。
- **E186** 端到端选季度漂移场地 + 轮班末段（疲劳）+ 突发任务（紧迫），对照第 58 轮；除成功率外，专门统计"因紧迫而本会加速、但被 deadline clause 转成安全停"的次数，验证安全停不是把任务拖死。

## 6. 本轮最大风险

**一句话**：支持域声明、合成证据与"看起来很镇定"的操作者可以串成一个自我确认回路——我们在自己声明的世界里生成证实先验的虚拟证据，再把镇定读成安全，于是所有机制同时报绿，而真正的失效恰好藏在 `𝒢_gap` 或掩饰的表情里；必须以显式间隙登记、合成只加宽、情感只刹车、对抗审计只否决、传输界诚实这五道硬约束，宁可在支持外又宽又慢地真实探针，也绝不采信"自己证明自己"的闭环。
