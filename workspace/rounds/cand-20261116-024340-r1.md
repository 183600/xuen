# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「视觉编码器」×「智能体」）

> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> **本轮纪律**：**证书化视觉证据 + 受契约约束的智能体**。两个灵感分别治理 v9 的两种债：**感知债**（几何证据只回答"多远"，不回答"是什么/能否抓/能否通过"，语义判断靠硬编码）与**任务债**（长程任务分解靠人手写状态机，不可扩展）。纪律不变：新组件全部是**可选增强**，任一失效注入中立元、逐位退回 v9；视觉编码器与智能体都**不得直接驱动执行器**。

## 0. 直觉与动机

### 灵感 1：视觉编码器 → 证书化视觉证据（Certified Visual Evidence, VME）
直觉：深度/SLAM 给的是几何，视觉编码器给的是语义与可供性（这是地毯还是台阶？能抓吗？能压过去吗？）。但把 ViT/DINO/CLIP 特征直接喂策略是危险的：特征不可解释、错误不保守、OOD 时"自信地错"。所以本轮不把编码器当"更强的感知"，而把它当**会弃权的证人**：
- **双头编码器**：一个头产任务特征；另一个头产**逐通道指标估计 + 保形区间**（视觉间隙、可通行性、抓取可供性、语义危险）；
- **三把锁**：Mondrian 分层保形标定（分布无关的分层边际覆盖）、潜在空间 OOD p 值（信任门）、**注意力证据覆盖**（"你到底看没看那块危险区域"）；
- **一条无损纪律**：视觉证据只能**加法增补** v9 几何证据；缺席 ⇒ 中立元 ⇒ 退回 v9。

核心创新：**VisCertEncoder（VME）**——把"语义感知"从不可解释的隐向量，变成带覆盖率、覆盖域、来源与弃权语义的**可审计证据通道**。

### 灵感 2：智能体 → 受类型契约约束的智能体（Contracted Agency, AG）
直觉：LLM 智能体擅长把"把桌上的杯子收进洗碗机"拆成步骤，但它的输出是自然语言，不能直接驱动 50Hz 控制，也不能信任它"不乱来"。所以本轮不把智能体当控制器，而把它当**证书编译器**：
- **0.5Hz 低频**：目标 → **意图 DAG**，节点只能取封闭工具注册表 R 中**带类型契约**的原语；
- 自然语言谓词经**接地文法 Γ** 编译为指标层级上的可判定谓词，编译不了就拒绝（no-op）；
- 执行前由**意图准入盾**在控制频率复核 Pre、证据来源与 M₀ 不变式；
- **记忆分层**：已证事实账本 vs 自由文本猜想，后者永不升级为事实。

核心创新：**AgentCompiler（AG）**——安全性**不依赖 LLM 正确**：LLM 可以胡说，但类型系统 + 盾保证它越不出 v9 可达行为集。配套 **CrossModalEvidenceBroker（CEB）** 做几何↔视觉三角验证与证据溯源。

### 灵感 1×2 的交叉点（为什么必须一起做）
单独做 VME，智能体会读到没有溯源与覆盖标注的"裸感知"；单独做 AG，它只能在几何证据上做任务分解，无法使用语义可供性。二者交汇处才是本轮真正的研究对象：**智能体的每一条事实都必须来自带证书的证据，每一条证据都必须能定位到看它的那块像素**。CEB 就是这个交点的执行者。

## 1. 研究问题（轮次升级版）

- **Q1（证书化视觉证据）**：分布偏移下，Mondrian 保形区间的覆盖如何随场景分层退化？注意力证据覆盖能否把"看错地方"从不可检测错误变成可检测弃权？保守界半格的加法融合如何保证 VME 缺席时逐位等价 v9？
- **Q2（智能体安全边界）**：类型化工具契约 + 接地文法 + 意图盾，能否保证任意（含对抗/幻觉）LLM 输出经编译后仍落在 v9 行为集的仿真细化内？Γ 的完备性（能接多少任务）与保守性（零不安全接受）如何权衡？
- **Q3（相关失效）**：VME 与 AG 共享视觉前端与语言先验，交叉模态一致性检查在何种独立性假设下 sound？共享传感器下如何避免"自洽的错"？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 证据可选律（Certified-Evidence Optionality, VME）**
视觉证据只能通过带中立元 v_VME^⊥ 的保守界融合算子 ⊕_V 增补 v9 几何证据，不得替换基线通道。VME 失效（信任门关 / 超时 / 覆盖不足 / 交叉模态不一致 / 编码器版本未标定）⇒ 全通道注入 v_VME^⊥，逐位等价 v9。

**P14 智能体不直接执行律（No-Direct-Actuation, AG）**
AG 只产生意图 DAG，节点属于封闭注册表 R；自然语言谓词必须在接地文法 Γ 内可判定，否则拒绝为 no-op；任何节点执行前必须过意图准入盾；AG 不得新增原语、不得修改契约、不得写执行器或账本。

**P15 证据溯源律（Provenance-Before-Belief, PL）**
智能体只能把具备有效证书的账本条目当作事实（来源编码器版本、标定 id、时间戳、信任分、覆盖、证书类型、TTL）。自由文本记忆永不进入已证状态；过期/未证条目在决策中视为不存在。

## 3. 与基线的接口（如何退化）

- VME 失效 ⇒ v_VME^⊥，v9 几何证据路径（引理 88，逐位）；
- AG 失效（LLM 超时 / 解析失败 / 接地失败 / 意图被盾全拒）⇒ no-op 意图，v9 反应式分块策略；
- CEB 失效 ⇒ VME 与 AG 同时关闭 ⇒ v9；
- PL 失效 ⇒ AG 只读当前周期已证状态、禁用长期记忆（"无记忆 AG"）；若仍不可用则关闭 AG；
- 再往下沿用 v9 五级链：AC→MW→ID→DA/SPR/Cal→v7→v6；
- 全部失效 ⇒ MetricVoiceGauge-OTL-GC-ER v7，再退回 v6。

## 4. 预期贡献

1. **证书化视觉证据**框架：分层保形 + 潜在 OOD 信任门 + 注意力证据覆盖 + 保守界半格加法融合，使语义感知可弃权、可审计、可逐位回退；
2. **受契约智能体**框架：类型化工具 + 接地文法 + 意图准入盾 + 溯源账本，使 LLM 可任意出错而系统安全性可证；
3. **交叉模态三角验证**：用几何证据独立校验视觉证据，给出 sound 的不一致报警与显式的可检测边界；
4. **相关失效的诚实刻画**：明确共享前端下 soundness 假设失效的条件，并把它变成可测量、可预注册的实验对象（E575）；
5. **预算-安全-长程三闭环**：低频 VME/AG 摊销后决策预算不破 20ms，E571–E590 覆盖覆盖率先验、弃权、三角验证、对抗幻觉、长程任务与退化矩阵。

## 5. 本轮最大风险

**一句话**：VME 与 AG 共享同一视觉前端与同一语言先验，它们的错误是相关的——当场景同时骗过表征与语义接地时，交叉模态一致性检查也会一起失效，此时安全盾验证的只是"被污染证据内部的自洽"，而非与真实世界的一致性。

## 1. 符号体系增量（定义 540–550）

| Admit(v) | 意图准入盾谓词（定义 549） |
| δ_j, β_g, β_v | 交叉模态差异与两模态误差上界（定义 550） |

**新增定义 540（视觉证据张量 EvidenceTensor）** VME 单帧输出：
```
E_t = { (μ̂_j, [l_j, u_j], cov_j, src, cal_id) }_{j∈J}
```
其中 μ̂_j 为通道点估计，[l_j,u_j] 为保形区间，cov_j 为支持域上的注意力证据覆盖，src 为编码器版本哈希，cal_id 为标定集 id。E_t 是**只读证据**，不含任何动作语义。

**新增定义 541（Mondrian 分层保形指标头）** 预处理把场景分为层 s ∈ S（室内/室外 × 光照/天气）。层 s 的校准集上定义归一化非一致性分数 s_i = |y_i − μ̂_i| / σ̂_i，取
```
q_s = 第 ⌈(n_s+1)(1−α_s)⌉ 个次序统计量（若 > n_s 则 q_s = +∞，即弃权）
[l_j, u_j] = [μ̂_j − q_s σ̂_j, μ̂_j + q_s σ̂_j]
```
在层内可交换假设下，P(y ∈ [l_j,u_j]) ≥ 1−α_s。q_s=+∞ 时该通道直接弃权而非放大区间。

**新增定义 542（潜在信任检验 LatentTrust）** 取主干池化特征 z_t，用校准集的 kNN 距离 d_t = ‖z_t − z_(k)‖（或 class-conditional Gaussian 的 Mahalanobis 距离）。保形 p 值
```
p_t = (1 + #{i ≤ n_cal : d_i ≥ d_t}) / (n_cal + 1)
```
信任门开 ⇔ p_t ≥ α_out。注意：这是**边际** OOD 检验，不是逐样本保证；其失效正是本轮风险的来源。

**新增定义 543（证据覆盖 EvidenceCoverage）** 对通道 j 声明其结论所依赖的支持域 R_j（例如语义危险通道的 hazard 扇区）。令 a_p 为主干在 patch p 上的归一化注意力质量，则
```
cov_j = Σ_{p : p ∩ R_j ≠ ∅} a_p / |{p : p ∩ R_j ≠ ∅}|
```
要求 cov_j ≥ c_min。**语义**：证书只在被证据覆盖的 R_j 上有效；未覆盖则通道弃权（返回 ⊥）。这把"看错地方"从静默错误变成显式弃权。

**新增定义 544（保守界半格与中立视觉元 ConservativeBoundLattice）** 每通道按方向 o_j 只取**安全侧保守界**：
```
o_j = ≥ :  b_j = l_j,  ⊕_V = min,  v_j^⊥ = +∞
o_j = ≤ :  b_j = u_j,  ⊕_V = max,  v_j^⊥ = −∞
融合：b_j^fused = b_j^v9 ⊕_V b_j^VME = min(b_j^v9, b_j^VME)（或 max）
```
因 min(x,+∞)=x、max(x,−∞)=x，故 b_j ⊕_V v_j^⊥ = b_j（恒等元）。融合只会让保守界更保守（≥ 类更小、≤ 类更大），不会因单个模态出错而放宽安全边界。v_VME^⊥ ≜ 全通道 v_j^⊥。

**新增定义 545（意图 DAG IntentDAG）** AG 单次低频输出 G_t = (V, E, ρ)：节点 v ∈ V 是工具注册表 R 的实例，边 (u→v) ∈ E 表示 u 的 Post 必须先于 v 的 Pre，ρ 把节点映射到子目标。G_t 不含连续控制量、不含时间戳级别的轨迹；轨迹仍由 v9 的 AC/反应式策略生成。

**新增定义 546（类型化工具契约 TypedToolContract）** 每个原语 r ∈ R 声明
```
τ_r = (Pre_r, Post_r, Eff_r, Cost_r, Risk_r, Cert_r)
```
Pre/Post 是 Γ 上的可判定谓词；Eff 为对已证状态的效果；Cost/Risk 为时间/风险预算；Cert_r ⊆ J 为执行前必须具备的证据通道与证书类型（如 SpatialCert、AC 块证书）。**注册表 R 封闭且静态版本化**；AG 不能新增 r。

**新增定义 547（接地文法 Γ）** Γ 是受限一阶谓词语言：
```
φ ::= c_j ⋈ θ | certified(E, j) | ¬φ | φ∧φ | φ∨φ | ◇_{≤T}φ | □_{≤T}φ
```
c_j 为指标通道值，θ 取自有限标定阈值网格，⋈ ∈ {<,≤,=,≥,>}。接地函数 g: NL → Γ ∪ {⊥} 由 LLM 产生候选，但由**独立、可审计的 parser/typechecker** 判定是否属于 Γ；不在 Γ 内一律 ⊥（no-op）。因此 g 的正确性不参与 soundness 证明，只有 typechecker 的 soundness 参与。

**新增定义 548（证据溯源账本 ProvenanceLedger）** 每条事实
```
e = (b, src, t, cal_id, trust, cov, cert, ttl)
```
为已证事实 ⇔ cert 有效 ∧ t − t_e ≤ ttl ∧ trust ≥ α_out ∧ cov ≥ c_min ∧ src = 当前注册编码器版本。AG 可读事实集 Facts(t) ⊆ L 仅含已证事实；**自由文本记忆 M_free 与 L 物理隔离，且 M_free 没有写入 L 的接口**。

**新增定义 549（意图准入盾 IntentShield）** 节点 v 在激活时刻准入：
```
Admit(v) ⇔ v.r ∈ R
          ∧ holds(Pre_{v.r}, S_cert(t))            # 已证状态
          ∧ Cert_{v.r} ⊆ TrustedEvidence(t)         # 证据在账本中且已证
          ∧ M0_preserved(G_t, v, S_cert(t))         # v9 硬检查 + AC 证书
```
任一不满足 ⇒ 拒绝该节点（不执行、不降级为"更激进的替代"）；整张 DAG 不可救则报 AG 失效并回退 v9。

**新增定义 550（交叉模态差异与三角验证 CrossModalTriangulation）** 对同时具备几何与视觉估计的通道 j：
```
δ_j = |μ̂_j^g − μ̂_j^v|
alarm_j ⇔ δ_j > β_g,j + β_v,j
```
alarm_j 时该通道注入 v_j^⊥（不信任视觉）。**soundness**：alarm ⇒ 至少一个模态误差超出其标定界；**不完备**：两模态同时以相关方式出错时 δ_j 可以很小。

## 2. 形式化定义（要点与升级）

**定义 493（六层指标层级）** 继承 v8：M=(M₀,M₁,M₂,M₃,M_dom,M_SLAM) 不变；VME 证据经 CEB 融合后只进入 M₁/M₂/M₃ 的输入端口，**M₀ 仍只由几何/物理检查驱动**。
**定义 496（软证书，v10）** 继承 v9，新增证据条件：δ_trigger 追加 `∧ (∀j: cov_j ≥ c_min) ∧ ¬alarm`；即视觉证据覆盖不足或三角验证报警时，软证书不得放行。
**定义 521（DA-OTL）** 继承；阈值 τᵢ(t) 可读取 VME 融合后的保守界，但读取路径必须经 CEB 的已证事实接口。

# IP-357 VisCertEncoder：证书化视觉编码器（VME）
CHANNELS = ('clr_v', 'trav', 'grasp', 'sem_haz')
ORIENT = {'clr_v': '>=', 'trav': '>=', 'grasp': '>=', 'sem_haz': '<='}

class VisCertEncoder:
    def __init__(self, backbone, metric_head, conformal, trust, cache,
                 alpha_out=0.05, c_min=0.6, frame_budget_ms=20):
        self.backbone, self.head = backbone, metric_head      # 冻结，无梯度
        self.conformal, self.trust = conformal, trust
        self.cache, self.alpha_out, self.c_min = cache, alpha_out, c_min
        self.frame_budget_ms = frame_budget_ms

    def evidence(self, obs, t):
        if self._over_budget(t):                 # 超时 -> 弃权
            return None                          # => v_VME^⊥
        tokens = self.cache.get(obs.keyframe_id) # 关键帧特征缓存
        if tokens is None:
            tokens = self.backbone(obs.rgb)      # 5Hz 关键帧
            self.cache.put(obs.keyframe_id, tokens, ttl=30)
        p_ood = self.trust.pvalue(tokens.z)      # 定义 542
        if p_ood < self.alpha_out:
            return None                          # 信任门关 -> v_VME^⊥
        mu, sigma = self.head(tokens)            # 逐通道点估计/尺度
        out = {}
        for j in CHANNELS:
            lo, hi = self.conformal.interval(      # 定义 541，按层 s
                mu[j], sigma[j], obs.scene_stratum)
            if lo == -inf:                     # q_s=+∞ -> 该通道弃权
                continue
            cov = self._coverage(tokens, obs.support_region(j))  # 定义 543
            if cov < self.c_min:
                continue                         # 覆盖不足 -> 该通道 ⊥
            out[j] = Evidence(j, mu[j], lo, hi, cov,
                              src=self.version, cal=self.conformal.cal_id)
        return out or None


# IP-359 CrossModalEvidenceBroker：保守界融合 + 三角验证 + 溯源
class EvidenceBroker:
    def __init__(self, beta_g, beta_v, alpha_out, c_min):
        self.beta_g, self.beta_v = beta_g, beta_v
        self.alpha_out, self.c_min = alpha_out, c_min
        self.ledger = ProvenanceLedger()

    def fuse(self, v9_bounds, ev):
        """v9_bounds: 每通道已是保守界；ev=None => 中立元。"""
        fused = dict(v9_bounds)
        if ev is None:                                   # VME 缺席
            return fused
        for j, e in ev.items():
            b = e.lo if ORIENT[j] == '>=' else e.hi     # 安全侧保守界
            fused[j] = (min(fused[j], b) if ORIENT[j] == '>='
                        else max(fused[j], b))           # 定义 544
        return fused

    def triangulate(self, geo_mu, vis_ev):
        alarm = set()
        if vis_ev is None:
            return alarm
        for j, e in vis_ev.items():
            if j in geo_mu and abs(geo_mu[j] - e.mu) > \
                    self.beta_g[j] + self.beta_v[j]:     # 定义 550
                alarm.add(j)
        return alarm

    def commit(self, ev, t):
        if ev is None:
            return
        for j, e in ev.items():
            self.ledger.append(Fact(j, e.mu, src=e.src, t=t,
                                    cal_id=e.cal, trust=e.p_ood,
                                    cov=e.cov, cert='VME'))
        self.ledger.expire(t)

    def read_facts(self, t):
        return [f for f in self.ledger.active(t)
                if f.trust >= self.alpha_out and f.cov >= self.c_min]


# IP-358 AgentCompiler：类型化意图编译 + 意图准入盾
class AgentCompiler:
    def __init__(self, llm, registry, grounder, typechecker, llm_timeout_s=2.0):
        self.llm, self.R = llm, registry          # R 封闭、版本化
        self.grounder, self.tc = grounder, typechecker
        self.llm_timeout_s = llm_timeout_s

    def compile(self, goal, broker, t):
        facts = broker.read_facts(t)              # 只喂已证事实（P15）
        raw = self.llm.invoke(self._prompt(goal, facts),
                              timeout=self.llm_timeout_s)
        dag = parse_intent_dag(raw)               # JSON schema 解析
        if dag is None:
            return NoOp()
        for v in dag.nodes:
            if v.r not in self.R:                 # 封闭世界
                return NoOp()
            tau = self.R[v.r]
            phi = self.grounder.to_gamma(v.predicate)   # NL -> Γ
            if phi is None or not self.tc.in_gamma(phi):
                return NoOp()                     # 接地失败 -> no-op
            v.Pre, v.Post, v.Cert = tau.Pre, tau.Post, tau.Cert
        if not self.tc.dag_well_typed(dag, self.R, GAMMA):
            return NoOp()
        return dag

    def shield(self, node, S_cert, trusted_evidence):
        tau = self.R[node.r]
        return (holds(tau.Pre, S_cert)
                and tau.Cert <= trusted_evidence      # 定义 549
                and m0_preserved(node, S_cert)         # v9 硬检查
                and ac_cert_valid(S_cert))

## 4. 推导

**引理 87（分层保形覆盖与支持域限制）** 设校准集与测试样本在场景层 s 内可交换，非一致性分数 s_i=|y_i−μ̂_i|/σ̂_i，q_s 为第 ⌈(n_s+1)(1−α_s)⌉ 个次序统计量。则层 s 的新样本满足 P(y ∈ [μ̂−q_sσ̂, μ̂+q_sσ̂]) ≥ 1−α_s。若 q_s=+∞、cov_j<c_min 或支持域外，通道返回 ⊥ 而不给出区间。故 VME 的 soundness 是**定义域受限**的：区间保证只对 certified support R_j 成立，域外不声称。证明：split conformal 的分位数论证 + 定义域限制；注意这是层内边际覆盖，不是逐样本条件覆盖。∎

**引理 88（中立视觉等价）** 对每通道 j，b_j ⊕_V v_j^⊥ = b_j（min(x,+∞)=x，max(x,−∞)=x）。VME 缺席/信任门关/覆盖不足/三角报警时，所有相关通道注入 v_j^⊥，融合结果 b^fused 与 v9 的保守界逐位相同；CEB 的账本记录不改变数值通道。因此系统可观测指标状态与 v9 逐位等价。∎

**引理 89（智能体迹包含 / 封闭世界安全）** 设 (a) 所有 DAG 节点取自静态封闭注册表 R 且契约已离线验证；(b) 每个执行节点在激活时通过意图盾（Pre 在已证状态成立、Cert 证据齐备、M₀ 不变式保持）；(c) 不在 Γ 内的谓词一律 no-op；(d) AG 无执行器写权限。则任意执行轨迹 τ_AG 都是某条 v9 兼容原语轨迹的仿真细化：对节点执行次数归纳，每个节点对应一个 v9 原语，盾保证其前置条件，边保证顺序，故 AG 只能**在 v9 可达行为集内选择子目标**，不能扩张动作集。安全性归约为静态契约验证 + 运行时盾，与 LLM 输出正确性无关。∎

**引理 90（意图 DAG 时序可靠性）** 若对每条边 (u→v) 有 Post_u ⇒ Pre_v（在已证状态上），且任一源-汇路径的累计 Cost ≤ 预算、节点截止期满足 EDF 可行性，则按拓扑序执行保持所有契约后置条件与 M₀ 不变式。节点内部的连续安全由 v9 的 AC 中块守卫负责；AG 的重规划只发生在节点边界，不破坏块内局部性。∎

**引理 91（交叉模态三角验证：sound 但不完备）** 若 δ_j = |μ̂_j^g − μ̂_j^v| > β_g,j + β_v,j，则不可能同时有 |μ̂_j^g − y_j| ≤ β_g,j 与 |μ̂_j^v − y_j| ≤ β_v,j（三角不等式），故 alarm 蕴含"至少一个模态超出其标定误差界"，报警是 sound 的。但报警不能定位是哪一方错，且当两模态误差高度相关（共享前端/共享相机）时 δ_j 可保持很小，检测功效趋于 0：不存在仅凭 δ_j 的完备检测器。故保守响应固定为"不信任视觉、注入 v_j^⊥"，即退回几何证据。∎

**引理 92（溯源阻断自噬污染）** 由于 Facts(t) 仅由证书有效、TTL 未过、信任与覆盖达标的账本条目构成，且自由文本记忆 M_free 无写入 L 的接口，任一幻觉信念都不可能在同一或后续周期被升级为"已证事实"。故 AG 的事实状态是已证观测历史的函数，其误差不会通过自我引用被放大；ttl 进一步把陈旧事实的影响限制在固定窗口内。∎

**引理 93（v10 退化格与逐位回退）** 令 F ⊆ {VME, AG, CEB, PL} 为失效集合。由引理 88，VME∈F 时指标通道逐位退回 v9；AG∈F 时意图为 no-op，子目标退回 v9 反应式；CEB∈F 时前两者同时关闭；PL∈F 时禁用长期记忆，无记忆仍不可用则关闭 AG。任一 F 下系统行为都落在 v9 行为集内；再与 v9 引理 83 的五级链复合，得到完整退化格，最坏退回 v6。∎

**命题 94（AG 的"LLM 不可信"安全性）** 由引理 89，AG 的安全性证明不包含"LLM 输出正确"这一前提；LLM 仅作为 Γ 候选生成器，其任意（含对抗）输出必须通过独立的 parser/typechecker 与盾。因此对 LLM 的对抗提示攻击只能影响"选哪个合法子目标"，不能造成越权执行。∎
