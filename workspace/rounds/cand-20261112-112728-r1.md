# 第 58 轮（承接第 57 轮「少样本元推断×跨模态对账×个性化信任」IP-133~138；灵感循环第 1 轮；本轮灵感：「闭环控制」×「数据集构建」）

> 第 57 轮把安全的赌注从"模型置信"移到"证据质量"，再用 MFSL/XMC/PTM 让少样本、跨模态、个性化下的证据更可校准；但它默认了两件事：**(a)** 元训练语料 𝒟_meta 是**外生、静态、已经在那里**的，仿佛数据先于策略存在；**(b)** 五层安全门是一串**开环串联的关卡**，各自过线即总安全。闭环控制会立刻反问：**这份数据集是谁、在什么策略下、为什么只在这些区域采集的？** 答案恰恰是"由上一版策略自己采的"——而策略只会去它认为"该决断"或"可安全探"的格子，于是语料系统性缺失的，正是"自信地错误"和"不敢去碰"的那些格子。数据集构建因此不是一次离线工作，而是**被控制器内生驱动的闭环**：策略决定采样，采样决定元模型，元模型又决定策略。本轮把两条灵感合成一条主线：**(i)** 闭环辨识需要**外源激励**（persistent excitation）——没有在上下文空间上的持续激励，数据只是控制器已经相信的世界的倒影，模型不可辨识；**(ii)** 数据集构建必须**可声明**——每个上下文格子的覆盖、倾向（propensity）与"不可达证据洞"都要进证书，**覆盖不足则弃权**。于是安全不再是一串可逐关满足的门，而是认知状态上的**控制不变集**（E-CBF）；学习不再是"有数据就更新"，而是双时间尺度上**带独立审计流的门控**；个性化不再是"人越可信越放松"，而是带**抗积分饱和**与**挑战注入**的人在环闭环。核心命题由"少样本可校准…的证据承诺"升级为 **"闭环可辨识、覆盖可声明、不可达即弃权的证据承诺"**。

核心矛盾：

- **H33（闭环 vs 可辨识）**：控制器自己生产数据会掩盖被控对象；无外源激励时"模型—策略—数据"回路不可辨识，模型只是策略的镜子。而激励要花预算、占节拍，且只能在安全动作上做。
- **H34（覆盖 vs 可达）**：最需要被验证的高风险格子，恰恰最不能被安全探测；覆盖契约只能在"安全可探流形"上满足，"认证盲区"是结构性的，不是采样量问题。
- **H35（双时间尺度稳定）**：快环（每检查点探-诺）与慢环（元更新）耦合；环路增益 ≥1 时元模型与策略可能共演化成自证气泡或极限环——"学得越多越自信"未必是收敛。
- **H36（解释 vs 警觉）**：解释与自动化降低操作者负荷，也诱导自满（automation bias）；人这条通道在被最依赖时最脆弱，必须持续注入挑战信号才能保持其可靠性可辨识。

## 0. 直觉与动机

**灵感 1（闭环控制 → 数据采集本身是受控过程）**
直觉：监督学习假设数据分布 p(z) 固定且与学习器无关。机器人不是这样：它按策略 π 决定去哪、探哪、信谁、何时让人确认；一条观测能否进入语料，取决于验证倾向 p^v(z)=P(verify at z|π)。这就是**闭环辨识**——被控对象（世界）与控制器（策略+元模型）被反馈连在一起。控制论的老结论直接适用：**反馈回路中的数据不足以辨识开环对象，除非叠加外源激励**。所以探索配额不是可选的工程技巧，而是可辨识性的必要条件：它相当于系统辨识中的 dither / 持续激励信号，把"策略的镜子"剪开一道缝。

**灵感 2（数据集构建 → 倾向、覆盖、不可达洞）**
直觉：既然采样由策略决定，就必须记录**倾向** p^v(z)，否则语料是 MNAR（missing-not-at-random）：缺的正是"自信不探"的格子，而缺失本身与被估量相关。还要区分两种缺失：**(a) 有覆盖但样本少**——可用 IPS/双重稳健重加权与共形加宽修正；**(b) 支持为零、且任何安全动作都无法制造支持**——IPS 无定义，任何重加权都是幻觉，只能登记为**不可达证据洞**并弃权。数据集不是一堆样本，而是一张**带倾向账与覆盖账的证明** J_d。

**灵感 3（合流 → 认知控制不变集）**
直觉：第 57 轮的"元校准→OOD→共形→对账→证据门→授权"是六道串联关卡；串联门可以各自刚好过线、合起来却整体漂出安全带（每关 90% 就是 0.9⁶）。把它重写成单一**认知安全集** S_e={校准裕度≥0 ∧ 覆盖裕度≥0 ∧ 分歧≤θ_D ∧ OOD 距离≥0 ∧ 语料新鲜度≥0}，并要求每个动作在最坏一步预测下仍把屏障函数 h_e 保持在非负——这就是离散时间**控制屏障函数**（CBF）。不变集不会被"逐关刚好过线"钻空子。

**灵感 4（双时间尺度 → 慢环门控 + 独立审计流）**
直觉：快环每检查点更新，慢环每次部署/云端更新。若"有数据就学"，策略与数据互为因果，可能自证（loop gain≥1）。处方：慢更新必须通过**独立审计流** 𝒜（一个固定探索策略采集、不受当前策略影响的少量外源样本）与收缩/增益检验；否则冻结元更新、加大探索配额。𝒜 就是闭环辨识里的工具变量/外源激励，它把回路剪开，让"模型是否真的更准"可被检验，而不是被模型自己的采样决策确认。

**灵感 5（人在环 → 抗积分饱和 + 挑战注入）**
直觉：把解释频率当控制输入看：解释越多越清楚 → 人响应越快，但自满越高 → 橡皮章风险越大。授权是带积分器的控制器，会积分饱和（windup）——操作者"表现严谨攒授权"、再一次性滥用。处方：降级即时、升级限速、**抗饱和**（触到全局硬界即停止积分，不许"攒着未来放开"）、会话衰减。同时，人对系统的可靠性只有在被**持续激励**时才可辨识：需要低频、低风险的**挑战注入**（偶尔要求独立复核 / 故意保留部分解释），代价是注意力，收益是人的失效率不退化、可被发现。

**灵感 6（合流 → 证据门六类、PCE 加星）**
直觉：**EV-coverage** 新增且仅限 L1 与路由决策（覆盖证书 + 倾向校正校准），绝不进入不可逆接触的必要证据集；EV-probe* 增加"倾向加权校准"与支持审计；EV-human 的激活/佐证由 HCL 控制器的 auth 参数化。承诺必须过 E-CBF；探针预算显式分成 k_probes（VOI 导向）与 k_explore（覆盖导向）；慢环由 DLC 门控。击穿安全需要：闭环不可辨识 ∧ 覆盖洞恰落在风险集 ∧ E-CBF 一步界失效 ∧ 独立审计流也被污染 ∧ 人退化——纵深从"五层证据"变成"结构（不可达洞）+ 闭环（外源激励）+ 人（持续激励）"三重。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（闭环证据动力学 CLED）** 状态 x_t=(b_t,𝒟_t,π_t,θ_i)，动作 a_t∼π_t(·|b_t)，观测 o_t∼P(·|z,a_t)。语料只收录**被验证事件** 𝒟_t={(z_i,o_i,p^v_i)}_{i≤t}；已承诺但未验证的结果记为**右删失**（censored）。元模型 q_t=Learn(𝒟_t)，信念 b_{t+1}=U(b_t,o_t,q_t)，策略 π_{t+1}=Π(b_{t+1},q_t)。闭环算子 Φ:(b,𝒟,π)→(b',𝒟',π')，局部环路增益 L=sup_z‖∂π/∂q‖·‖∂𝒟/∂π‖·‖∂q/∂𝒟‖。

**定义 140（反馈可辨识与倾向校正 IDP）** 验证倾向 p^v_t(z)=P(verify at z|π_t)。无外源激励时 p^v 内生，存在**不可辨识集** U={z:p^v(z)=0}。倾向校正校准：ECE^IPS=∑_i w_i·ℓ(q(z_i),o_i)/∑w_i，w_i=min(w_max,1/p^v(z_i))；双重稳健版本同时用结果回归。可辨识条件（PE）：存在外源策略 π^e 使 inf_{z∈Z_decl} p^v(z)≥p_min>0。支持审计 supp(𝒟)={z:p^v(z)>0}；U 上**只加宽不收窄**，任何"重加权后的自信"均非法。

**定义 141（覆盖-或-弃权契约 CAA 与数据集证书 J_d）** 上下文划分 Z=⊔Z_j（材质簇×坡度×季节）。覆盖 c_j=加权验证次数，覆盖赤字 g_j=max(0,c_min−c_j)。契约：任何将被**承诺**的格子 z∈Z_j，要么 c_j≥c_min ∧ z∉U（可声明覆盖），要么该承诺只可取保守默认（弃权/绕行/降档/L2）。安全探索配额：每批探针至少 ε 比例分配给覆盖赤字最大的格子，且仅限 L1 非破坏性动作，预算 k_explore 计入终止界。数据集证书 J_d=(coverage_map, propensity_model/w_max, censoring_report, U 与不可达洞清单, exploration_ledger, loop_gain_history, audit_stream_stats, drift/staleness)。

**定义 142（认知控制屏障 E-CBF）** 认知安全集 S_e={x:h_e(x)≥0}，h_e=min{h_cal,h_cov,h_div,h_ood,h_fresh}，各分量按声明界归一（如 h_cal=1−ECE_k/ε_max、h_cov=c_j/c_min−1、h_div=1−D/θ_D、h_ood=d_ood/θ_ood−1、h_fresh=1−age/T_stale）。对动作 a∈{probe,commit,gait,authorize}，要求离散 CBF 条件 h_e(x_{t+1}) ≥ (1−γ)·h_e(x_t) 在**最坏一步预测**（由 Lipschitz 界 L_h 与动作影响界给出）下成立；无可行动作则扩探询预算，仍无则安全停/L2。承诺可行 ⇔ ∃a：CBF 条件 ∧ R≤δ_f ∧ 证据门同时成立。

**定义 143（双时间尺度闭环稳定 DLC）** 慢环 q_{t+1}=MetaUpdate(q_t,𝒟_t) 仅当通过：(i) 影子模式回归（ECE 不劣化 ∧ OOD 检出不降 ∧ 覆盖不降）；(ii) **独立审计流** 𝒜（固定 π^e 采集，与部署流统计独立）上误差不增；(iii) 收缩/增益检验（L̂<1 或更新为压缩映射 ‖q_{t+1}−q*‖≤κ‖q_t−q*‖,κ<1）。任一不过 ⇒ 冻结元更新并把 k_explore 提升；连续 N_f 次失败 ⇒ 退回第 57 轮手工先验路径并告警。气泡判据：若 dist(𝒟,𝒜)↑ 同时模型自信↑，判**自证气泡**，强制剪回路。

**定义 144（人在环闭环控制 HCL）** 操作者状态 s_o=(cal,vig,auth,cmp)，新增自满度 cmp。解释控制量 u_E（频率/模态/详细度）↑ ⇒ 响应时延↓ 但 cmp↑：dcmp/dt=α·u_E+β·success−γ_decay·cmp，橡皮章风险随 cmp 单调升。授权为带积分器控制器：升级限速 Δ_auth/T、降级即时、**抗积分饱和**（触全局硬界即停止积分）、会话衰减。**挑战注入**：以频率 ρ_pe 注入低风险独立复核/解释保留，维持人对系统的持续激励（PE），否则人的失效率不可辨识且会退化。τ_int、corrob*、w_h 仍由 auth 参数化，全局硬界与决策规则本体不动。

## 2. 关键算法伪代码（完整版见产物区）

```python
def loop_step(x, r, a, o, meta):                   # IP-139: 闭环一步
    pv = verify_propensity(x.pi, r)                # p^v(z|π)
    if a == 'probe':    x.D.append((r, o, pv))     # 只有验证事件入语料
    elif a == 'commit': x.censored += 1            # 右删失，不入语料
    if pv == 0:         x.meta.U.add(r)            # 不可达证据洞
    x.pi = policy(belief_update(x.b, o, meta.q), x.q)
    x.loop_gain = estimate_gain(x, independent=x.audit)
    return x

def ecbf_admit(x, a, L_h):                         # IP-142: 认知不变集
    h = epistemic_barrier(x)                       # min(h_cal,h_cov,h_div,h_ood,h_fresh)
    if h < 0 or h - L_h*worst_step_cost(x, a) < (1-GAMMA)*h:
        return False
    return True

def coverage_or_abstain(z, cell, Jd, level):       # IP-141: 覆盖不足即弃权
    if cell in Jd.U or Jd.coverage[cell] < C_MIN:
        return 'abstain' if level == 'irreversible' else 'conservative_default'
    return 'licensed'

def slow_loop_gate(q_new, q_old, D, audit):        # IP-143: 剪开回路
    if regression(q_new, q_old, audit.shadow) > 0: return freeze(q_old, True)
    if err_on(audit.stream, q_new) > err_on(audit.stream, q_old):
        return freeze(q_old, True)                 # 独立流不认账
    if estimate_gain(D, audit.stream) >= 1:        return freeze(q_old, True)
    return accept(q_new)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| CLED | O(1)/步 + O(H) 增益估计 | O(\|𝒟\|) | 倾向与删失如实记录 |
| IDP | O(\|𝒟\|)/慢环 | O(\|𝒟\|) | p_min>0 才可辨识，U 只加宽 |
| CAA | O(\|Z\|) 覆盖账 | O(\|Z\|) | 覆盖不足即弃权、不可逆禁赌 |
| E-CBF | O(1)/动作 | O(1) | 最坏一步界 L_h 诚实（A43） |
| DLC | O(\|𝒜\|)/慢环 | O(\|𝒜\|) | 独立审计流真的独立（A46） |
| HCL | O(1)/事件 | O(\|操作者\|) | 限速、抗饱和、PE≥ρ_pe |

**正确性定理（Closed-Loop Grounded Soundness, CLGS 概要）**：在 A33–A40 上加 (A41) 闭环记录诚实（每条证据带 p^v、承诺结果标删失、倾向模型可复核）；(A42) PE/覆盖（安全探索配额被遵守，或 U 与不可达洞被显式登记）；(A43) E-CBF 最坏一步界诚实；(A44) 慢环只采纳过影子回归+独立流+增益检验的更新；(A45) HCL 限速/抗饱和/降级即时且挑战注入≥ρ_pe；(A46) 审计流 𝒜 与部署流统计独立。则：(i) **支持健全性**——U 上任何承诺要么弃权要么只取共形最坏值，ECE^IPS 仅在重叠域一致，不存在靠重加权"修"出的虚假精度；(ii) **闭环不变性**——h_e≥0 沿轨迹不变，串联门不会在反馈下"逐关过线却整体漂出"；(iii) **自证排除**——L̂<1 或门控拒绝所有增益≥1 的更新，q_t 有界，𝒟–𝒜 分布漂移持续增大即触发冻结+增探；(iv) **人在环非退化**——授权与自满有界，人在挑战注入下失效率可辨识；(v) **终止性**——每检查点探针 ≤k_probes（其中覆盖探索 ≤k_explore）、共识 ≤k_cons。

## 6. 本轮最大风险

**一句话**：本轮把安全寄托在"覆盖可声明、不可达即弃权"上，但覆盖契约只能在**安全可探流形**上被满足——最危险、最该被验证的风险格子恰恰是不可达证据洞，系统对它们唯一健全的动作是弃权；而弃权直接损失活性，一旦工程上为了完成任务把弃权改成"按共形最坏值赌一把"，闭环就会重新退化为一个证书漂亮、却恰在最需要它的地方失效的系统。

### IP-139 CLED（闭环证据动力学与删失账）

```python
def loop_step(x, r, a, o, meta):
    pv = verify_propensity(x.pi, r)               # p^v(z|π)，由可复核倾向模型给出
    if a == 'probe':
        x.D.append((r, o, pv)); x.cover.add(r)
    elif a == 'commit':
        x.censored += 1                           # 右删失：结果不进语料
    if pv <= 0.0:
        x.meta.U.add(r)                           # 不可达证据洞
    if a == 'probe':
        x.b = belief_update(x.b, o, meta.q)
    x.pi = policy(x.b, x.q)
    x.loop_gain = estimate_gain(x, independent=x.audit)
    return x

def estimate_gain(x, independent):
    # L ≈ ‖∂π/∂q‖·‖∂𝒟/∂π‖·‖∂q/∂𝒟‖，用独立流做外源，避免自相关
    return norm(policy_sensitivity(x)) * norm(sampling_sensitivity(x)) \
           * norm(learning_sensitivity(x, independent))
```

### IP-142 E-CBF（认知控制屏障）

```python
def epistemic_barrier(x):
    h_cal   = 1.0 - x.ece / EPS_META_MAX
    h_cov   = x.coverage[cell_of(x.r)] / C_MIN - 1.0
    h_div   = 1.0 - x.D / THETA_D
    h_ood   = x.ood_distance / THETA_OOD
    h_fresh = 1.0 - x.staleness / T_STALE
    return min(h_cal, h_cov, h_div, h_ood, h_fresh)

def ecbf_admit(x, a, L_h):
    h = epistemic_barrier(x)
    if h < 0.0:
        return False
    h_next_wc = h - L_h * worst_step_cost(x, a)   # 最坏一步预测（A43）
    return h_next_wc >= (1.0 - GAMMA) * h

def commit_if_ecbf(x, sigma, g, gate):
    candidates = [('probe', best_probe(x)), ('commit', commit(sigma, g)), ('reroute', reroute(x))]
    for kind, a in candidates:
        if a is None: continue
        if ecbf_admit(x, a, L_h) and gate(kind, a) == 'ok':
            return kind, a
    return 'extend_or_stop', no_admissible_action(x)   # 扩探→安全停/L2
```

```python
def slow_loop_gate(q_new, q_old, D, audit):
    if regression(q_new, q_old, audit.shadow) > 0:      # (i) 影子回归
        return freeze(q_old, boost_explore=True)
    if err_on(audit.stream, q_new) > err_on(audit.stream, q_old):

        return freeze(q_old, boost_explore=True)        # (iii) 增益/收缩

def bubble_detect(D, A, q):
```

### IP-138→PCE++（双预算探-诺-演 + 覆盖探索 + E-CBF + 慢环门控）

```python
def pce_closed_loop(x0, M, task, budget, audit, personas):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        # ① 覆盖导向的外源探索（与 VOI 探针分开记账）
        for q in safe_exploration_quota(cells_of(cp), M.Jd, budget):
            if budget.k_explore <= 0: break
            M = loop_step(M, cp.region, 'probe', execute_probe(q, cap=F_abs), meta)[0]
            budget.k_explore -= 1
        inf = meta_few_shot_infer(M, cp.region, M.obs[cp.region], meta, audit)
        M.b[cp.region] = inf.post if inf.cls == 'ID' else worst_in(inf.belt)
        sigma = foothold_schedule(x0, cp, M); R = schedule_risk(sigma, M)
        while select_gait(R) == 'halt' and budget.k_probes > 0:
            cands = admissible_probes(cp, M, F_abs)
            if not cands: break
            q = argmax(cands, key=lambda q: voi_meta_pessimistic(q, M, inf)
                                         + LAMBDA_COV * coverage_value(q, M.Jd) - cost(q))
            if voi_meta_pessimistic(q, M, inf) < theta_voi: break
            M = loop_step(M, cp.region, 'probe', execute_probe(q, cap=F_abs), meta)[0]
            if M.D[cp.region] > theta_D and 'consensus' not in cp.done:
                p2 = most_disagreeing_modality_probe(M, cp.region)
                M = loop_step(M, cp.region, 'probe', execute_probe(p2, cap=F_abs), meta)[0]
                cp.done.add('consensus')
            sigma = reselect_footholds(x0, cp, M); R = schedule_risk(sigma, M)
            budget.k_probes -= 1
        g = select_gait(R)
        lv = contact_level(cp)
        kind, a = commit_if_ecbf(M, sigma, g, lambda k, act: evidence_gate(k, act, M, personas, ood_reg))
        if kind == 'commit':
            M.Jd = dataset_certificate_jd(M, audit)
            sched.append(a); log.append(tag_evidence(M, a)); continue
        if coverage_or_abstain(cp.region, M.Jd, lv) == 'abstain':
            return reroute_or_stop(cp, M, sigma, R, consent)      # 覆盖不足即弃权
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt': route = alt; continue
        return negotiate_or_stop(cp, M, sigma, R, consent,
                                 tau_int=tau_int(personas.active.auth))
    return sched, log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CLED | O(1)/步 + O(H) 增益 | O(\|𝒟\|) | 倾向/删失如实、U 显式（A41） |
| IDP | O(\|𝒟\|)/慢环 | O(\|𝒟\|) | 重叠域一致、U 只加宽（A42） |
| CAA | O(\|Z\|) 覆盖账 | O(\|Z\|) | 覆盖不足即弃权、不可逆禁赌 |
| E-CBF | O(1)/动作 | O(1) | 最坏一步界 L_h 诚实（A43） |
| DLC | O(\|𝒜\|)/慢环 | O(\|𝒜\|) | 审计流统计独立（A46） |
| HCL | O(1)/事件 | O(\|操作者\|) | 限速/抗饱和/降级即时/PE（A45） |
| PCE++ | O(\|CP\|·(k_p+k_e+k_c)·(C_VOI+d_φ)) | O(\|V\|+\|σ\|) | 双预算终止、四态+弃权完备 |

**正确性定理（Closed-Loop Grounded Soundness, CLGS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 闭环记录诚实：𝒟 中每条带 p^v，承诺结果标为右删失，倾向模型可复核；**(A42)** PE/覆盖：安全探索配额被遵守，或不可辨识集 U 与不可达洞被显式登记，可声明域上 p^v≥p_min>0；**(A43)** E-CBF 最坏一步界诚实：h_e 的 Lipschitz 常数 L_h 与动作影响界可复核；**(A44)** 慢环只采纳通过影子回归+独立流+增益/收缩检验的更新；**(A45)** HCL 授权限速、抗积分饱和、降级即时，挑战注入频率 ≥ρ_pe；**(A46)** 审计流 𝒜 与部署流统计独立（由固定外源策略 π^e 采集）。则：

1. **支持健全性**：在 U 上，任何承诺要么弃权，要么只以共形带最坏值进入 P_fail；ECE^IPS 仅在重叠域与真值一致，不存在靠重加权"修"出的虚假精度。可声明域上的承诺失效率 ≤ δ_f+ε_meta(k)+δ_probe+ε_h(w_max)+δ_xm·1[L1]。
2. **闭环不变性**：若 A42–A43 成立，则 h_e(x_t)≥0 沿轨迹不变，E-CBF 保证认知状态不越出 S_e；串联证据门"逐关刚好过线、整体漂出"的漏洞被消除。
3. **自证气泡排除**：若 L̂<1 或门控拒绝所有增益≥1 的更新（A44），则 q_t 有界；若 dist(𝒟,𝒜) 持续增大且模型自信上升，bubble_detect 触发冻结+增探，系统不会滑入"越学越自信的错误不动点"。
4. **人在环非退化**：A45 下授权与自满有界，人在挑战注入下失效率可辨识（人侧 PE），橡皮章不会因解释变好而静默扩散。
5. **终止性**：每检查点探针 ≤k_probes+k_explore、共识 ≤k_cons，PCE++ 终止于 {承诺, 弃权, 绕行, L2 协商, 安全停}。
6. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1] + δ_loop)
             − P(𝒜 非独立) − P(E-CBF 一步界失效) − P(HCL 饱和 ∧ 未弃权)
             − P(不可达洞被误判为可声明)
```

关键：**未覆盖格只允许弃权，其失效贡献为 0，代价是活性（liveness）而非安全**；若策略拒绝弃权而改按共形最坏值下注，则必须显式计入 δ_worst——**把"活性换安全"的选择变成必须声明的账，而不是悄悄发生的默认**。

## 4. 本轮可行性验证：闭环玩具实验（实跑数字）

用 40 格一维地形（真实强度 μ(z)=1.0+1.2z，负载阈值 L=1.6，真实安全边界 z*=0.5），策略只探"预测裕度最接近 0"的 3 个格子（不确定性导向），每轮 400 次探针，16 轮，比较覆盖探索配额 ε：

| 配额 ε | 终局信念误差 | 错误承诺率（committed ∧ 真不安全） | 语料覆盖格占比 |
|---|---|---|---|
| 0.00 | 0.214 | **50.0%** | 50% |
| 0.10 | 0.030 | 2.5% | 97% |
| 0.25 | 0.009 | **0.0%** | 100% |

关键现象：ε=0 时策略永远只探"高端/边界附近"，那些先验乐观但真实不安全的低端格子**因自信而从不被探**，于是错误承诺率 16 轮**恒定在 50%**、信念误差停在 0.214——这是一个自证不动点，而不是暂时欠采样；语料内校准可以"看起来很好"，因为差的格子根本不在语料里。10% 的覆盖配额即可把错误承诺率压到 2.5%，25% 压到 0。

静态支持审计（真实μ=1.0+1.2z，倾向仅在 z∈[0.55,1.0] 非零）：语料密集区局部误差 0.001–0.002，而全体真实误差 0.009、支持空洞占 55%（空洞内平均误差 0.101）；加入均匀外源配额后支持空洞 55%→0%，全体误差 0.009→0.001–0.002。这直接印证 **IPS 无重叠则无定义**：不把"洞"补上或声明，任何重加权都只会把误差算得更漂亮，不会让模型更准。

## 7. 本轮最大风险

**一句话**：本轮把安全寄托在"覆盖可声明、不可达即弃权"上，但覆盖契约只能在**安全可探流形**上被满足——最危险、最该被验证的风险格子恰恰是不可达证据洞，系统对它们唯一健全的动作是弃权；而弃权直接损失活性，一旦工程上为了完成任务把弃权改成"按共形最坏值赌一把"，闭环就会重新退化为一个证书漂亮、却恰在最需要它的地方失效的系统。
