### 第 1 轮灵感驱动研究记录

**灵感词**：长期记忆、力矩传感

**直觉与动机**：
前序框架（HPC-E+ → USMC → SRC-USC，v18–v25）已把机器人系统刻画为「感知-合规-能量-结构-语义-重构-协同」的证书链，但它本质上是**情景式（episodic）**的：每步验证当前计划，验证完即丢弃，既不跨任务积累，也无法察觉一个曾经有效的证书在物理世界缓慢漂移后已悄然失效（负载变化、关节摩擦上升、结构疲劳、接触环境老化）。受「长期记忆」启发，证书应升级为**可持久、可溯源、可巩固、可遗忘、可再验证**的记忆对象；受「力矩传感」启发，力矩传感器是机器人-世界交互的**直接物理探针**，可作为证书的「物理锚点」——在线时复核动力学模型、检测接触事件，离线时对记忆条目做再接地（re-grounding）。核心洞见：**没有物理锚点的记忆是幻觉，没有记忆的力矩是失忆**；力矩见证的长期记忆把证书链从无状态过滤器变为可自我纠错的终身可验证系统。

**形式化目标**：
1. 定义长期记忆证书（LTM）：持久、内容寻址、带溯源 DAG 与衰减状态 v_k(t) 的记忆库 M，支持存/取/巩固/遗忘/再验证，并以「内容哈希幂等 + 父记忆存在」保证记忆图无环可审计。
2. 定义力矩传感证书（TSC）：残差 r(t)=τ_m−τ_p 的模型保真、接触事件签名、外力包络、参数可辨识（持续激励）四重证书，给出外力估计的 Lipschitz 误差界。
3. 定义力矩见证的记忆再接地（TWMR）：记忆条目 m 在时刻 t 有效 ⟺ 其扭矩见证在当前动力学下残差 ≤ δ_mem，即「记忆新鲜度」是可物理复核的谓词，而非时间猜测。
4. 定义力矩见证巩固与遗忘（TWCF）：仅当扭矩再接地通过才允许巩固（离线回放）；衰减+效用驱动的分层巩固与安全关键记忆钉扎（pinned），防止灾难性遗忘抹掉合规记忆。
5. 构建统一记忆-力矩准入门（MTG-USC）：Exec_v26 = Exec_v25 ∩ Fil_mem ∩ Fil_torque ⊆ Exec_v25，并证明记忆陈旧/力矩异常/巩固投毒下的单调退化链保持性。

## 1. 关键算法骨架（在 SRC-USC 骨架上扩展）

```python
# ============================================================
# IP-448 Long-Term Memory Certificate (LTM) — 长期记忆证书
# ============================================================
@dataclass
class TorqueWitness:
    """力矩见证：一次可复核、可防篡改的物理接地记录"""
    t: float
    tau_meas: Tensor              # [n] 实测关节力矩
    q: Tensor; qd: Tensor; qdd: Tensor   # [n]
    tau_pred: Tensor              # [n] 模型预测
    residual: Tensor              # [n] r = tau_meas - tau_pred
    contact_flag: bool
    sensor_ids: list[str]         # 冗余传感器集合（用于偏差交叉校验）
    hash: str                     # hash(payload || t || sensor_ids)


@dataclass
class MemoryItem:
    key: str                      # 内容寻址键 = hash(payload)
    kind: str                     # 'episodic' | 'semantic' | 'procedural'
    payload: dict                 # 证书 / 技能 / 语义地图
    provenance: list[str]         # 父记忆键列表（DAG 边）
    witness: TorqueWitness        # 物理锚点
    t_store: float
    utility: float = 0.0          # 检索收益估计（任务奖励-风险-能量）
    hits: int = 0
    pinned: bool = False          # 安全关键记忆：禁止遗忘
    lam: float = 1e-4             # 衰减率（巩固后减半）

    def validity(self, t: float) -> float:
        return math.exp(-self.lam * (t - self.t_store)) * (
            1.0 + math.log1p(self.hits) * 0.1)


@dataclass
class LongTermMemoryCertificate:
    """持久 + 溯源 + 衰减 + 力矩再接地的长期记忆证书"""
    items: dict[str, MemoryItem] = field(default_factory=dict)
    delta_mem: float = 0.5        # 再接地残差容差 (Nm)
    v_min: float = 0.05           # 存活阈值
    quarantine_buf: dict[str, MemoryItem] = field(default_factory=dict)

    # ---------- 存：只接收可被力矩再接地的记忆 ----------
    def store_item(self, m: MemoryItem, tsc: 'TorqueSensingCertificate',
                   model: 'RobotModel', t: float) -> bool:
        if m.key != content_hash(m.payload):
            return False                     # 内容寻址一致性
        if m.key in self.items:
            return True                      # 幂等（已存在）
        if any(p not in self.items for p in m.provenance):
            return False                     # 溯源完整性：父记忆必须存在或为根
        if not self.revalidate(m, tsc, model, t):
            self.quarantine_buf[m.key] = m   # 无法接地 → 隔离待审，不入库
            return False
        self.items[m.key] = m
        return True

    # ---------- 再接地：记忆新鲜度的可物理复核谓词 ----------
    def revalidate(self, m: MemoryItem, tsc: 'TorqueSensingCertificate',
                   model: 'RobotModel', t: float) -> bool:
        w = m.witness
        r = tsc.residual(w.tau_meas, w.q, w.qd, w.qdd, model)
        return bool(r.abs().max() <= self.delta_mem)

    # ---------- 取：新鲜度过滤 + 力矩过滤 ----------
    def retrieve(self, query: Tensor, t: float, k: int = 5,
                 tsc: 'TorqueSensingCertificate' = None,
                 model: 'RobotModel' = None) -> list[MemoryItem]:
        cand = sorted(self.items.values(),
                      key=lambda m: self.validity(t) + m.utility, reverse=True)
        out = []
        for m in cand:
            if tsc is not None and not self.revalidate(m, tsc, model, t):
                continue                     # 陈旧记忆不返回
            if m.pinned or m.validity(t) >= self.v_min:
                m.hits += 1
                out.append(m)
            if len(out) >= k:
                break
        return out

    # ---------- 巩固：离线回放，仅对力矩一致的高效用记忆晋升 ----------
    def consolidate(self, tsc: 'TorqueSensingCertificate',
                    model: 'RobotModel', t: float) -> int:
        promoted = 0
        for m in list(self.items.values()):
            if m.hits >= 3 and not m.pinned and self.revalidate(m, tsc, model, t):
                m.kind = 'semantic' if m.kind == 'episodic' else 'procedural'
                m.lam *= 0.5                 # 巩固 → 衰减更慢（类睡眠巩固）
                m.pinned = m.utility >= 0.9  # 高价值晋升为不可遗忘
                promoted += 1
        return promoted

    # ---------- 遗忘：衰减驱逐，钉扎记忆豁免 ----------
    def forget(self, t: float) -> int:
        evicted = [k for k, m in self.items.items()
                   if not m.pinned and m.validity(t) < self.v_min]
        for k in evicted:
            del self.items[k]
        return len(evicted)


# ============================================================
# IP-449 Torque-Sensing Certificate (TSC) — 力矩传感证书
# ============================================================
@dataclass
class TorqueSensingCertificate:
    """模型保真 + 接触签名 + 外力包络 + 可辨识性 四重保证"""
    n_joints: int
    delta_tau: float = 0.5        # 残差噪声带 (Nm)，由传感器标定
    contact_threshold: float = 1.0
    F_max: float = 200.0          # 外力包络上界 (N)
    sigma_exc: float = 1e-2       # 持续激励下界

    def residual(self, tau_meas: Tensor, q: Tensor, qd: Tensor, qdd: Tensor,
                 model: 'RobotModel', F_ext: Tensor = None) -> Tensor:
        tau_pred = model.rnea(q, qd, qdd)
        if F_ext is not None:
            tau_pred = tau_pred + model.jacobian(q).T @ F_ext
        return tau_meas - tau_pred

    def verify_model_fidelity(self, witnesses: list[TorqueWitness]) -> bool:
        """‖r(t)‖∞ ≤ δ_τ：动力学模型在见证窗口内可信"""
        return all(bool(w.residual.abs().max() <= self.delta_tau)
                   for w in witnesses)

    def verify_contact_signature(self, w: TorqueWitness) -> bool:
        """接触事件签名：残差超噪声带 ⟺ contact_flag，且方向与末端力一致"""
        detected = bool((w.residual.abs() > self.contact_threshold).any())
        return detected == w.contact_flag

    def estimate_external_force(self, w: TorqueWitness,
                                model: 'RobotModel') -> Tensor:
        """F̂_ext = (Jᵀ)⁺ r；其误差 ≤ ‖(Jᵀ)⁺‖·δ_τ（Lipschitz 界）"""
        J = model.jacobian(w.q)
        return torch.linalg.pinv(J.T) @ w.residual

    def verify_force_envelope(self, witnesses: list[TorqueWitness],
                              model: 'RobotModel') -> bool:
        return all(bool(torch.norm(self.estimate_external_force(w, model)) <= self.F_max)
                   for w in witnesses)

    def verify_identifiability(self, regressor_stack: Tensor) -> bool:
        """持续激励：σ_min(Φ) ≥ σ_exc，否则参数估计不可证"""
        return bool(torch.linalg.svdvals(regressor_stack).min() >= self.sigma_exc)

    def verify_all(self, witnesses: list[TorqueWitness], model: 'RobotModel',
                   regressor_stack: Tensor) -> bool:
        return (self.verify_model_fidelity(witnesses) and
                all(self.verify_contact_signature(w) for w in witnesses) and
                self.verify_force_envelope(witnesses, model) and
                self.verify_identifiability(regressor_stack))


# ============================================================
# IP-451 MTG-USC 记忆-力矩统一准入门（v26）
# ============================================================
@dataclass
class MemoryTorqueGroundedUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'   # v25 七证
    ltm: LongTermMemoryCertificate
    tsc: TorqueSensingCertificate

    def admits(self, multi_plan, sensor_data: dict,
               model: 'RobotModel', t: float) -> bool:
        # 1. v25 七证（USMC + SMC + RMC + MCC，复用）
        if not self.src_usc.admits(
                multi_plan, sensor_data,
                gt_entities=sensor_data.get('gt_entities'),
                queries=sensor_data.get('queries'),
                retrieved=sensor_data.get('retrieved')):
            return False

        # 2. 力矩证书：模型保真 + 接触签名 + 外力包络 + 可辨识
        if not self.tsc.verify_all(
                sensor_data['torque_witnesses'], model,
                sensor_data['regressor_stack']):
            return False

        # 3. 记忆证书：计划所依赖的每条记忆必须当前可再接地且未过期
        for key in multi_plan.memory_refs:
            m = self.ltm.items.get(key)
            if m is None:
                return False
            if not self.ltm.revalidate(m, self.tsc, model, t):
                return False                 # 记忆陈旧（物理漂移）
            if not m.pinned and m.validity(t) < self.ltm.v_min:
                return False                 # 已过存活阈值
        return True

# ============================================================
class LifelongMemoryTorquePipeline:
    def __init__(self, config: dict):
        self.mtg = MemoryTorqueGroundedUnifiedCertificate(

            ltm=LongTermMemoryCertificate(
                delta_mem=config['delta_mem'], v_min=config['v_min']),

                delta_tau=config['delta_tau'],
                contact_threshold=config['contact_threshold'],
                F_max=config['F_max'],
                sigma_exc=config['sigma_exc']),
        )
        self.ipam.register_module("ltm", ["IP-448"],
            ["content_addressed_memory", "provenance_dag", "torque_regrounding", "decay_forgetting"])
        self.ipam.register_module("tsc", ["IP-449"],
            ["model_fidelity", "contact_signature", "force_envelope", "identifiability"])
        self.ipam.register_module("twcf", ["IP-450"],
            ["torque_witnessed_consolidation", "pinned_safety_memory", "layered_forgetting"])
        self.ipam.register_module("mtg_usc", ["IP-451"],
            ["twelve_certificate_gate", "memory_torque_monotonic_chain"])

    def step(self, multi_sensor_data: dict, model, t: float,
             cloud_update=None) -> tuple[bool, dict]:
        # 1-11. v25 七证流水线（略，复用）
        admitted_v25, info = self._v25_step(multi_sensor_data, cloud_update)

        # 12. 力矩见证构造与 TSC 校验
        witnesses = self._build_witnesses(multi_sensor_data, model)
        torque_ok = self.mtg.tsc.verify_all(
            witnesses, model, multi_sensor_data['regressor_stack'])

        # 13. 记忆再接地：用当前力矩见证复核计划依赖的记忆
        memory_ok = True
        for key in multi_sensor_data.get('plan_memory_refs', []):
            m = self.mtg.ltm.items.get(key)
            if m is None or not self.mtg.ltm.revalidate(
                    m, self.mtg.tsc, model, t):
                memory_ok = False
                break

        # 14. 在线存新记忆（仅通过再接地者）+ 周期巩固/遗忘
        for m in self._extract_memory_candidates(multi_sensor_data, witnesses):
            self.mtg.ltm.store_item(m, self.mtg.tsc, model, t)
        if int(t) % self.config['consolidate_period'] == 0:
            self.mtg.ltm.consolidate(self.mtg.tsc, model, t)
            self.mtg.ltm.forget(t)

        # 15. MTG-USC 十二证准入
        admitted = admitted_v25 and torque_ok and memory_ok
        return admitted, {
            **info,
            'torque': {
                'model_fidelity_ok': self.mtg.tsc.verify_model_fidelity(witnesses),
                'contact_signature_ok': all(
                    self.mtg.tsc.verify_contact_signature(w) for w in witnesses),
                'force_envelope_ok': self.mtg.tsc.verify_force_envelope(witnesses, model),
                'identifiability_ok': self.mtg.tsc.verify_identifiability(
                    multi_sensor_data['regressor_stack']),
            },
            'memory': {
                'size': len(self.mtg.ltm.items),
                'quarantined': len(self.mtg.ltm.quarantine_buf),
                'memory_ok': memory_ok,
            },
        }


def content_hash(payload: dict) -> str:
    """内容寻址：规范化序列化后哈希（防篡改 + 幂等）"""
    blob = json.dumps(payload, sort_keys=True, default=str).encode('utf-8')
    return hashlib.sha256(blob).hexdigest()
```

## 3. 正确性论证（增量）

### 引理 13（力矩传感证书的保真-接触-包络-可辨识四重保证）
**陈述**：`TSC.verify_all(witnesses, model, Φ) = True` ⟺ 在见证窗口内同时满足：
(1) 模型保真：‖τ_m−τ_p‖∞ ≤ δ_τ，
(2) 接触签名：残差超噪声带 ⟺ contact_flag，且方向与末端力一致，
(3) 外力包络：‖(Jᵀ)⁺r‖ ≤ F_max，
(4) 参数可辨识：σ_min(Φ) ≥ σ_exc。

**证明**：
1. `verify_model_fidelity` 逐见证比较残差与标定噪声带 δ_τ，δ_τ 由传感器噪声（SEA 弹性体应变片 + 冗余关节力矩传感器）离线标定的 6σ 给出，保证无接触时零误报。
2. `verify_contact_signature` 检查残差超阈与接触标志的等价性；方向一致性由 `estimate_external_force` 的最小范数解与接触法向的点积符号判定，排除「力矩突变但非接触」的伪事件。
3. `verify_force_envelope` 的误差界由伪逆 Lipschitz 性给出：‖F̂−F*‖ ≤ ‖(Jᵀ)⁺‖·‖r‖∞ ≤ ‖(Jᵀ)⁺‖·δ_τ，故 F_max 设为接触任务许用力的 (1−‖(Jᵀ)⁺‖δ_τ/F_max) 保守缩放。
4. `verify_identifiability` 由最小二乘参数估计的唯一性条件（持续激励）给出：σ_min(Φ)≥σ_exc ⇒ 参数协方差有界，惯性/负载参数可证；否则降级为固定参数保守模型。
∎

### 引理 14（长期记忆证书的存-取-溯源可靠性）
**陈述**：`LTM` 中任一可被 `retrieve` 返回的非钉扎记忆 m，在返回时刻 t 满足：(a) 力矩再接地通过（r≤δ_mem），(b) 溯源 DAG 无环且父记忆存在，(c) 新鲜度 v_m(t)≥v_min。隔离区（quarantine_buf）中的记忆永不返回。

**证明**：
1. `store_item` 在入库前调用 `revalidate`，失败者仅进 `quarantine_buf`，故 `items` 中记忆入库时均已接地；`retrieve` 再次对候选调用 `revalidate`，排除入库后因物理漂移而失效者。
2. 内容寻址键 key=hash(payload) 且入库检查 `m.key==content_hash(payload)`，同一内容幂等；`provenance` 要求所有父键已在 `items` 中，由于父必须先于子入库，溯源图按入库时间拓扑有序 ⇒ 无环。
3. `retrieve` 对非钉扎记忆强制 `validity(t)≥v_min`，否则跳过；钉扎记忆（合规/急停）豁免衰减以保证安全记忆不被遗忘。
∎

### 引理 15（力矩见证巩固与遗忘的 Exec 保序性）
**陈述**：`TWCF.consolidate/forget` 不会扩大任何计划的准入集合，也不会把未通过再接地的记忆晋升为可检索记忆；钉扎记忆永不被驱逐。

**证明**：
1. `consolidate` 只修改已入库（已接地）记忆的 kind/lam/pinned，不新增 key、不改变 `MTG-USC.admits` 的连言结构；提升 pinned 仅使该记忆更难被遗忘，不会使原本被拒的计划变为通过（准入仍需 `revalidate`）。
2. `forget` 仅删除 `not pinned and validity<v_min` 者；删除记忆只会使依赖它的计划因 `memory_refs` 缺失而被拒，故 Exec 单调不增。
3. 钉扎记忆由 `not m.pinned` 短路保护，`forget` 与 `consolidate` 均不驱逐，满足安全记忆持久性。
∎

### 引理 16（v26 记忆-力矩单调退化链）
**陈述**：任意单点/组合失效下，`Exec_v26 ⊆ Exec_v25 ⊆ … ⊆ Exec_v18` 恒成立。

**证明**：`MTG-USC.admits = v25.admits ∧ TSC.verify_all ∧ memory_refs 再接地`，是 v25 的合取强化，故集合必然收缩。三条退化路径：
- 记忆陈旧/物理漂移（再接地失败）→ `memory_refs` 检查拒证 → 退回 `Exec_v25`：丢弃记忆依赖的任务级规划，改用当前感知的几何重规划（记忆不参与决策），保留 v25 全部安全。
- 力矩异常/传感器漂移/可辨识性丧失 → `TSC.verify_all=false` → 退回 `Exec_v25` 并切换「无力矩反馈的保守模式」（降速、降力、增大安全裕度），禁止依赖力矩的接触任务。
- 巩固投毒/记忆污染（隔离区命中或溯源断裂）→ 该记忆不入库/不返回 → 相关计划拒证 → 退回 `Exec_v25`，并以钉扎记忆与审计日志做离线复核。
- 组合失效取交集，单调性由合取保持。
∎

### 定理（MTG-USC 十二证准入门的安全-合规-可部署-可保护-结构-语义-重构-协同-力矩-记忆完备性）
**陈述**：对任意多机计划 Π={π_1..π_N}，`MTG-USC.admits(Π)=True` ⟺ Π 同时满足：
(1)–(10) v25 的十项条件（物理接地安全、云边一致、conformal 覆盖、专利保护、结构、力控、轻量化、语义、重构、协同），
(11) 力矩四重保证（模型保真 ∧ 接触签名 ∧ 外力包络 ∧ 可辨识），
(12) 记忆三重保证（计划引用的每条记忆可再接地 ∧ 新鲜度达标 ∧ 溯源完整）。

**证明**：必要性由 `admits` 的十二个连言条件直接给出，任一缺失即拒证。充分性由引理 4/8/12（v25 单调链与统计覆盖）、引理 13–15（力矩与记忆的可靠性、保序性）与引理 16（v26 单调退化）共同保证：十二条件全满足时，系统在「物理-语义-群体」之上再叠加「时间（记忆）-接触（力矩）」两维闭环，构成从瞬时安全到终身可验证的完整链条。
∎
