### 第 6 轮灵感驱动研究记录（CADVS-v6）

**灵感词**：事件相机、比赛策略、状态机

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）确立「认证的生成式执行」（CGE）：七硬门 fail-closed 不增（覆盖/物理/人因/末点/记忆/价值/平衡）、条件流匹配提议 π_θ^FM、LMEM-v2 记忆固化、FAMK 情感非对称调制、执行集嵌套 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。本轮不推翻 v5，而是补 v5 的三个结构性短板：(a) **证书只在计划时刻求值一次**，控制环 1 kHz、感知 30 Hz，落在两次采样之间的扰动（打滑、碰撞、外力、人为拉扯）处于「未被建模的时间缝隙」，无人知晓；(b) v5 的最大风险 R57（固化自指博弈）只被「冻结门 + 人工抽检 + 红队」缓解，缺少**持续运行的外部对手**去测量「形式合规、实质违背」这一信任缺口的规模；(c) 七个门是**平面谓词集合**，合法迁移结构散落在各模块的 if-else 中，缺乏「证书只在合法迁移上被消费」的全局不变量与可验证的活性（不死锁）。三个灵感词统一为主题「**事件时序上的对抗竞赛 × 有证状态机**」（Event-Triggered Adversarial Tournament over a Certified State Machine, EAT-CSM），形成 CADVS-v6（IP-497~500）。三个词恰好对应一场真实比赛的三个要素：**裁判的观察粒度**（事件相机：每事件、微秒时间戳、零帧混叠）、**比赛的状态**（状态机：合法迁移、fail-closed 守卫、逃逸边）、**对手与晋级制度**（比赛策略：自博弈对手、门硬度谱、冠军-挑战者晋级、淘汰赛选证）。本轮自律：**硬门数量仍为七个**（不新增门，正面回应 R52 锚点维护负债），新增的只有：(i) 证书的**时效语义**（每门证书携带 issue/valid 时刻与扰动预算，作为既有门的时间性合取，只紧不松）；(ii) **事件级监测**（把「是否发生违例」的判据从帧采样换成事件时间轴）；(iii) **离线对抗治理**（锦标赛与晋级制度，不参与在线放行）。执行集嵌套升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **事件相机 → 证书从「时刻点谓词」升级为「事件时间轴上的区间谓词」，时间缝隙被形式化关闭**。v5 的七门在 t_0 求值一次，之后证书被当作静态许可消费；任何未被采样到的扰动都是「不可见区」。事件相机给出异步事件流 e_i=(u_i,p_i,t_i)：每个事件自带微秒时间戳，物理变化与状态迁移共享同一条时间轴，于是「计划期证书」与「执行期证据」可以按事件对齐。三个可形式化的收益：(a) **帧混叠消失**：帧轮询在周期 T_f 内把两个事件混叠并可能颠倒顺序，其概率上界 ≈ (λ_e T_f)²/2；事件流保留顺序，仅有有界抖动 Δ_j。(b) **触发本身带统计证书**：把背景事件建模为 Poisson 过程（像素级速率 λ_b，MAD 鲁棒估计），窗口 W 内事件数 N_W ~ Poisson(μ_W=λ_b·|ROI|·ΔT)，Chernoff 上尾给出 P(N_W ≥ m) ≤ exp(−m ln(m/(e μ_W)) + m − μ_W)，取 m(δ_W) 使其 ≤ δ_W，对一周期的 N_win 个窗口做并集界得 δ_cycle ≤ N_win·δ_W——**这是第一次让「何时该反应」本身带证书**，而不是拍脑袋阈值。(c) **可维护的证书**：门得分 s_i 在扰动球上是 L_i-Lipschitz（常数离线标定），若扰动包络 ε̂_loc(t) 满足裕度 m_i = s_i−τ_i ≥ L_i·ε̂_loc + ε_est，则证书可从点扩展到段（引理 48），否则立即失效并触发重铸证。关键红线：**事件相机不新增门**，只给既有七门加时间性合取 kc_i^v6(t)=kc_i^v5 ∧ fresh_i(t) ∧ maint_i(t)，全部只紧不松。

2. **比赛策略 → 把「R57 信任缺口」从一个担忧变成一个可测量、被对手持续挤压的量**。v5 的固化闭环是自指的：策略在自己铸证的片段上训练，缺少外生裁判。v6 引入**对抗锦标赛**：每个提议族（流策略、规则提议、对手族）与每个门构成对局；自博弈对手 π_adv 的目标显式追求**信任缺口** TrustGap = P(形式合规 ∧ 实质违背)——它要找到「能过门但实际有害」的轨迹。对局用 **Bradley–Terry/Elo** 建模（σ(β_i−β_j)），在线 MM 更新，输出**门硬度谱** β_g，把「七门是否完备」从定性断言变成可排序、可审计的量（可与人工审计排名做 Spearman 一致性检验）。三种制度性设计：(a) **淘汰赛选证**：候选轨迹用带噪比较器做 knockout，每场比较误差 ε_cmp，误选冠军的概率 ≤ (K−1)ε_cmp（真实冠军路径并集界），昂贵门评估只发生在「廉价裕度不可分」的场次（期望 E_esc ≈ 1–2），比 v5 的「启发式 top-3 全评」更省且更准。(b) **冠军-挑战者晋级**：挑战者必须通过信任电池（红队回归召回不降 + 地面真值结局审计提升 + 证书裕度不退化 + 人工抽检）才能晋升，回归自动回滚——把「上线」变成比赛结果而非工程直觉。(c) **算力分配策略**：UCB1 在「下一个攻击哪个门」上做 bandit（遗憾 O(√(T log F))），避免把算力平均撒在已经很难攻破的门上。**关键边界**：裁判必须与门解耦——用**物理结局真值**（物体是否真的被稳定抓起、终态位姿误差、人工作出确认）裁决，而不是用门自己的输出；同时保留**未见对手**留出集与人工抽检，防止对手与裁判共同漂移。

3. **状态机 → 把散落的 if-else 升级为可形式验证的合法迁移骨架**。v5 的控制逻辑分布在 FAMK/EFA-v5/BCK 各自内部，「哪些迁移允许发生」没有全局对象。v6 引入**分层有证状态机 CHSM**：Q = {SAFE, SENSE, PROPOSE, CERTIFY, EXECUTE, MONITOR, RECOVER, CONSOLIDATE, ARENA}，L0={SAFE,RECOVER} 为安全层，L1={SENSE,PROPOSE,CERTIFY,EXECUTE,MONITOR} 为任务层，L2={CONSOLIDATE,ARENA} 为离线层。迁移 δ(q,σ) 由守卫 g(q,σ) 守护，守卫是**证书合取**：进入 EXECUTE 必须持有覆盖下一段 Δτ 的有效七门证书（七边际为正、issue_ts 距今 ≤ T_valid、扰动包络覆盖）。两条结构性纪律：(a) **fail-closed**：证据缺失/过期/不确定 ⇒ 守卫为假；(b) **逃逸边**：每个 L1 状态都有一条**恒使能**的逃逸边到 RECOVER/SAFE（不依赖任何证书），这是活性的来源——定理 11 给出「从任意可达状态存在到 SAFE 的逃逸路径 ⇒ 无死锁」，因此 fail-closed 不会把系统锁死。定理 12 给出「进入 EXECUTE 的迁移必持有效证书 ⇒ 证书只被合法迁移消费」。定理 13 给出「各版本守卫只收紧 ⇒ 可达集单调收缩 ⇒ Exec_v6 ⊆ Exec_v5」。此外事件时间戳单调性给出**转移序列唯一性**（无竞态），这是帧轮询做不到的。

**关键洞见**：v5 回答「提议=任意生成器、记忆反哺策略、人因含情感时，证书边界如何保持不变」；v6 回答「**当世界的变化发生在两次采样之间、当策略自己就是最有利的攻击者、当执行逻辑本身是一堆 if-else 时，如何仍然保证『证书只在合法且新鲜时点被消费，且违例不会静默通过』**」。七门谓词 kc_evidence_forged_v5 原样复用；本轮新增的只有：事件级证书（时间性合取，只紧不松）、有证分层状态机（执行骨架）、对抗锦标赛（离线治理与在线选证）。**不新增硬门**是本轮硬纪律：门是信任边界，不是「越多越安全」的清单；新增能力走「时间性（时效）」与「制度性（治理）」两条路径。Exec_CADVS-v6 = {x : ∧_i kc_i^v5(x,c;γτ^4)=1 ∧ ∧_i fresh_i ∧ maint_i} ⊆ Exec_CADVS-v5。

**形式化目标（增量）**：
1. 事件触发证书：背景 Poisson 模型 + Chernoff 阈值 m(δ_W)；并集界 δ_cycle ≤ N_win·δ_W；对比度阈值的漏检界 P(miss) ≤ exp(−n_eff·Φ((C−A+b)/σ_n))；帧混叠界 (λ_e T_f)²/2。
2. 段局部证书扩展（引理 48）：m_i ≥ L_i·ε_loc + ε_est ⇒ 门在整段保持。
3. CHSM：M=(Q,Σ,δ,g,λ)，逃逸边恒使能，fail-closed 守卫；定理 11（死锁自由）、定理 12（证书只在合法迁移被消费）、定理 13（可达集单调收缩）、定理 14（事件序确定性）。
4. 对抗锦标赛：BT/Elo 门硬度谱 σ(β_i−β_j)，TrustGap 指标，淘汰赛误选界 (K−1)ε_cmp，UCB1 攻击分配遗憾 O(√(T log F))，冠军-挑战者晋级协议。
5. EFA-v6：七门 + 时间性合取；ECS_v6 = ECS_v5·η_ev·η_trust；裁决层与门解耦（物理结局真值）。
6. Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**本轮最大风险**：**共模盲区**——锦标赛的裁判（物理结局真值、人工抽检）与证书栈共用同一套传感器与坐标假设，一次系统性失效（照明闪烁导致事件风暴、坐标标定漂移、相机饱和）会让「证书」与「真值」同时朝错误方向偏，信任缺口测出来很小而系统实际已坏；这是内部机制原理上无法自检的风险，只能靠异源锚点（独立传感器、人工物理确认、双平台交叉）压制，无法根除。

## 2. 关键算法骨架

### IP-497 ECTK：事件相机认证触发核（端侧，事件驱动）

```python
@dataclass
class EventCameraCertifiedTriggerKernel:
    """ECTK：事件流 → 带统计证书的触发 + 扰动包络估计。
    定理 9：周期级误报率 ≤ N_win·δ_W（Poisson-Chernoff 并集界）"""
    roi_area: int = 65536
    delta_T: float = 0.020          # 窗口时长 20 ms
    delta_win: float = 1e-4         # 窗口级误报预算
    lam_b: float = 12.0             # 背景速率（每像素每秒），MAD 鲁棒在线更新
    contrast_C: float = 0.2         # 对比度阈值
    refractory: float = 0.008       # 不应期（抑制触发风暴）
    eps_est: float = 0.02           # 扰动估计误差上界（离线标定）
    hot_pixels: set = field(default_factory=set)

    def ingest(self, events: list[Event]) -> None:
        """O(1)/事件：时间表面更新 + 像素级速率计数"""
        for e in events:
            if e.u in self.hot_pixels:
                continue
            self.surface.update(e)                 # φ(t) = (t, τ_dec(t))
            self.pix_rate[e.u] += 1

    def estimate_background(self) -> float:
        """MAD 鲁棒估计 λ_b：取像素速率分布的高分位而非均值，避免闪烁/热区污染"""
        rates = np.array([self.pix_rate[u] for u in self.pix_rate])
        med = float(np.median(rates))
        mad = float(np.median(np.abs(rates - med))) + 1e-9
        return (med + 3 * 1.4826 * mad) / max(self.delta_T, 1e-6)

    @staticmethod
    def _chernoff(m: int, mu: float) -> float:
        """P(Poisson(mu) ≥ m) ≤ exp(-m ln(m/(e mu)) + m - mu)（乘性 Chernoff 上尾）"""
        if m <= mu:
            return 1.0
        return math.exp(-m * math.log(m / (math.e * mu)) + m - mu)

    def trigger_threshold(self) -> int:
        """Chernoff 反解 m(δ_W)：窗口误报 ≤ δ_W"""
        mu = self.lam_b * self.roi_area * self.delta_T
        m = max(1, int(mu))
        while self._chernoff(m, mu) > self.delta_win:
            m += 1
        return m

    def detect(self, t_now: float) -> Trigger | None:
        """窗口统计 → 触发；带滞回与不应期；输出带 δ 预算与扰动包络的触发令牌"""
        n = self.surface.count(self.roi, t_now - self.delta_T, t_now)
        if n < self.trigger_threshold():
            return None
        if t_now - self.last_trigger < self.refractory:
            return None
        self.last_trigger = t_now
        return Trigger(t=t_now, n=n, delta_window=self.delta_win,
                       eps_loc=self._disturbance_envelope(t_now),
                       feats=self._features(self.surface))

    def _disturbance_envelope(self, t_now: float) -> float:
        """由事件簇幅度反推局部扰动包络 ε̂_loc(t)（保守上界 + ε_est 裕量）"""
        amp = self.surface.amplitude(self.roi, t_now - self.delta_T, t_now)
        return min(self.amp_cap, amp * self.amp_gain) + self.eps_est
```

### IP-498 CHSM：分层有证状态机（执行骨架，事件驱动）

```python
@dataclass
class CertifiedHierarchicalStateMachine:
    """CHSM：分层有证状态机。fail-closed 守卫 + 恒使能逃逸边。
    定理 11（死锁自由）、定理 12（证书只在合法迁移消费）、定理 13（可达集单调收缩）"""
    Q: tuple = ('SAFE', 'SENSE', 'PROPOSE', 'CERTIFY', 'EXECUTE',
                'MONITOR', 'RECOVER', 'CONSOLIDATE', 'ARENA')
    level: dict = field(default_factory=lambda: {
        'SAFE': 0, 'RECOVER': 0, 'SENSE': 1, 'PROPOSE': 1, 'CERTIFY': 1,
        'EXECUTE': 1, 'MONITOR': 1, 'CONSOLIDATE': 2, 'ARENA': 2})
    q: str = 'SAFE'
    chi: CertToken | None = None    # 当前消费的证书
    delta_tau: float = 0.020        # 证书覆盖段长 20 ms

    def guards(self, q: str, sigma: Event) -> bool:
        """fail-closed：任何证据缺失/过期/不确定 ⇒ False"""
        if q in ('EXECUTE', 'MONITOR'):
            c = self.chi
            if c is None:
                return False
            if c.t_issue + c.T_valid < sigma.t:
                return False                                  # 过期
            if not all(m > 0 for m in c.margins):
                return False                                  # 七门边际非正
            if c.epsilon_budget < self.ectk.eps_loc(sigma.t):
                return False                                  # 扰动超出证书预算
            return True
        if q in ('SENSE', 'PROPOSE', 'CERTIFY'):
            return True
        return False                                          # SAFE/RECOVER/离线层守卫恒真

    def next_states(self, q: str, sigma: Event) -> list[str]:
        """候选迁移（按语义优先级）"""
        table = {
            ('SAFE', 'boot'):        ['SENSE'],
            ('SENSE', 'cluster'):    ['PROPOSE', 'MONITOR'],
            ('PROPOSE', 'cands'):    ['CERTIFY'],
            ('CERTIFY', 'forged'):   ['EXECUTE'],
            ('EXECUTE', 'tick'):     ['MONITOR', 'EXECUTE'],
            ('MONITOR', 'cluster'):  ['EXECUTE', 'PROPOSE'],
            ('MONITOR', 'stale'):    ['RECOVER'],
            ('EXECUTE', 'stale'):    ['RECOVER'],
            ('RECOVER', 'settled'):  ['SAFE'],
        }
        return table.get((q, sigma.kind), [])

    def step(self, sigma: Event) -> str:
        """事件驱动单步迁移。逃逸边恒使能 ⇒ 活性来源（定理 11）"""
        if sigma.kind == 'violation':
            self.q, self.chi = 'RECOVER', None
            return self.q
        for q2 in self.next_states(self.q, sigma):
            if self.guards(q2, sigma):
                self.q = q2
                return self.q
        if self.level[self.q] == 1:
            # 无合法迁移：恒使能逃逸边到 RECOVER（fail-closed 但不锁死）
            self.q, self.chi = 'RECOVER', None
        return self.q
```

### IP-499 ATD：对抗锦标赛、信任缺口与选证（离线治理 + 准入期选证）

```python
@dataclass
class AdversarialTournamentDiscriminator:
    """ATD：门硬度锦标赛 + 信任缺口度量 + 淘汰赛选证 + 晋级治理。
    裁决源 = 物理结局真值（与门解耦），不是门自身输出（红线）"""
    families: list = field(default_factory=list)
    gates: tuple = ('3DCF', 'MSRG', 'HICK', 'EEK', 'LTEM', 'VACK', 'BCK')
    beta_fam: dict = field(default_factory=dict)
    beta_gate: dict = field(default_factory=dict)
    n_match: dict = field(default_factory=dict)
    adv: Any = None                  # 自博弈对手策略
    eps_cmp: float = 0.05            # 廉价比较器误差界（离线校准）
    trust_gap_log: list = field(default_factory=list)

    def bt_update(self, fam: str, gate: str, passed: bool, mu: float = 0.2) -> None:
        """BT/Elo 在线更新：P(pass)=σ(β_g−β_f)，MM/牛顿步，O(1)"""
        bf = self.beta_fam.setdefault(fam, 0.0)
        bg = self.beta_gate.setdefault(gate, 0.0)
        p = 1.0 / (1.0 + math.exp(-(bg - bf)))          # 模型给出的过门概率
        self.beta_fam[fam] = bf + mu * ((1.0 if passed else 0.0) - p)
        self.beta_gate[gate] = bg + mu * ((0.0 if passed else 1.0) - p)
        self.n_match[gate] = self.n_match.get(gate, 0) + 1

    def train_adversary(self, incumbent, ground_truth, rounds: int = 200) -> None:
        """自博弈对手：最大化信任缺口 TrustGap = P(通过七门 ∧ 结局失败)
        硬约束：不得修改门；对手只在提议分布侧操作（与 v5 固化红线一致）"""
        for _ in range(rounds):
            x = self.adv.propose(context=self.adv.sample_context())
            cert = self.gates.check_all(x)              # 七门只读求值
            passed = cert.ok
            failed_outcome = (not ground_truth(x))     # 物理结局真值（异源裁决）
            reward = 1.0 if (passed and failed_outcome) else (0.2 if passed else -1.0)
            self.adv.update(reward)                     # 对抗训练 / 策略梯度
            self.trust_gap_log.append((passed, failed_outcome))
        self.trust_gap = float(np.mean([p and f for p, f in self.trust_gap_log])) \
            if self.trust_gap_log else 0.0

    def knockout_select(self, cands: list, expensive_check) -> Trajectory:
        """淘汰赛选证：K−1 场廉价比较，昂贵门评估仅在「裕度不可分」场次升级。
        引理 49：误选冠军概率 ≤ (K−1)·ε_cmp；E_esc 期望 1–2"""
        bracket = list(cands)
        while len(bracket) > 1:
            nxt = []
            for i in range(0, len(bracket) - 1, 2):
                a, b = bracket[i], bracket[i + 1]
                sa, sb = self.cheap_margin(a), self.cheap_margin(b)
                if abs(sa - sb) > 2 * self.eps_cmp:
                    nxt.append(a if sa > sb else b)      # 裕度可分 ⇒ 判定可靠
                else:
                    nxt.append(expensive_check(a, b))   # 唯一允许的昂贵调用来源
            if len(bracket) % 2:
                nxt.append(bracket[-1])
            bracket = nxt
        return bracket[0]

    def promote(self, challenger, battery) -> bool:
        """冠军-挑战者晋级：信任电池全过才晋升，任一项回归 ⇒ 回滚"""
        res = battery(challenger)   # {redteam_recall, outcome_gain, margin_nonreg, human_audit}
        ok = (res.redteam_recall >= self.baseline.redteam_recall - 1e-3
              and res.outcome_gain >= 0.02
              and res.margin_nonreg
              and res.human_audit)
        if ok:
            self.champion = challenger
        return ok

    def pick_attack_target(self) -> str:
        """UCB1 在「下一个攻击哪个门」上分配算力；遗憾 O(√(T log F))"""
        for g in self.gates:
            self.n_arm[g] = self.n_arm.get(g, 0) + 1
            self.s_arm[g] = self.s_arm.get(g, 0.0) + (0.0 if self._recent_pass(g) else 1.0)
        best = max(self.gates, key=lambda g: self.s_arm[g] / self.n_arm[g]
                   + math.sqrt(2 * math.log(sum(self.n_arm.values())) / self.n_arm[g]))
        return best
```

### IP-500 EFA-v6：七硬门 + 时间性合取 + 事件驱动重铸证

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：七硬门不变 + 时间性合取（fresh ∧ maint）+ 淘汰赛选证 + 事件驱动重铸证"""
    fmpp: FlowMatchingProposalPolicyKernel
    lmem: LongTermMemoryEmbeddingConsolidation
    famk: FacialAffectModulationKernel
    ectk: EventCameraCertifiedTriggerKernel
    csm: CertifiedHierarchicalStateMachine
    atd: AdversarialTournamentDiscriminator
    v5: EvidenceForgingAssemblerV5

    def select(self, x0_state, t_now, rule_id, context):
        s_emo = self.famk.observe(context.face, t_now)
        gamma = self.famk.gamma(s_emo)                   # 全 1.0 = 精确退化 v5
        c = build_ctx(context, s_emo, self.lmem)
        cands = self.fmpp.propose(c, self.fmpp.K) + self.atd.challenger_families_propose(c)
        surv = [x for x in cands if self._cheap_gates(x, gamma)]
        if not surv:
            return self._fallback_rule_proposal(gamma)   # fail-closed：回退 v5 规则提议
        best = self.atd.knockout_select(surv, self._expensive_pair_check)  # 淘汰赛
        cert = self.v5.vack.evaluate(best, context_with(s_emo), t_now)
        if not cert.ok:
            return False, None, 'ALL_CANDIDATES_REJECTED'
        chi = CertToken(id=hash_of(best), margins=cert.margins, t_issue=t_now,
                        T_valid=self.T_valid, epsilon_budget=self.ectk.eps_loc(t_now),
                        prov=self.atd.provenance(best))
        self.csm.chi = chi
        return True, best, 'FORGED_EVT'

    def on_event(self, sigma):
        """事件驱动：触发 → 局部扩展失效则重铸证，否则维持（fail-closed）"""
        trig = self.ectk.detect(sigma.t)
        if trig is not None and self.csm.chi is not None:
            if trig.eps_loc > self.csm.chi.epsilon_budget:
                self.csm.chi = None                        # 证书作废 → 重铸证
        return self.csm.step(sigma)

    def ecs_v6(self, ..., trust_gap_hat: float) -> float:
        eta_ev = self._monitor_reliability()              # 事件监测可信度 ∈ [0,1]
        eta_trust = max(0.0, 1.0 - self.lam_trust * trust_gap_hat)
        return self.v5.ecs_v5(...) * eta_ev * eta_trust
```

## 4. 正确性论证（增量更新）

### 引理 45（窗口误报界 / Poisson-Chernoff）

**陈述**：设背景事件在 ROI 上为独立同质 Poisson，速率 λ_b；窗口长度 ΔT、面积 A，则 N_W ~ Poisson(μ_W=λ_b A ΔT)。对 m > μ_W，
P(N_W ≥ m) ≤ exp(−m ln(m/(e μ_W)) + m − μ_W)；
且对一周期的 N_win 个窗口（不独立时用并集界）P(任一误触发) ≤ N_win·δ_W。∎
**证明**：标准 Chernoff 上尾（乘性）界；并集界。**工程取值**：δ_W=1e-4、N_win=5 ⇒ δ_cycle ≤ 5e-4/周期。

### 引理 46（对比度漏检界）

**陈述**：设像素对数亮度变化的噪声为尺度 σ_n 的对数正态（有偏 b），事件触发条件为 |Δ log I| ≥ C；一个幅度 A 的阶跃扰动覆盖 n_eff 个像素且各像素独立，则该扰动未被任何像素检出的概率 ≤ (1−Φ((C−A+b)/σ_n))^{n_eff} ≤ exp(−n_eff·Φ((C−A+b)/σ_n))。∎
**诚实边界**：像素噪声独立是理想化；照明闪烁造成强相关，会破坏该界的紧性（见 R60）。

### 引理 47（混叠 vs 事件序）

**陈述**：帧轮询周期 T_f、真值事件率 ≤ λ_e，则「一帧内至少两个真值事件且顺序被颠倒」的概率 ≤ (λ_e T_f)²/2；事件流保留逐事件时间戳，顺序错误只可能来自时钟同步误差 Δ_j（有界同步假设下其概率可忽略）。∎
**工程量级**：λ_e=100/s、T_f=33 ms ⇒ 混叠概率 ≈ 5.4e-3/帧；事件流 µs 级抖动下 ≈ 0。

### 引理 48（段局部证书扩展）

**陈述**：设门得分 s_i 在扰动球 B(0,ε) 上是 L_i-Lipschitz；证书在 t_0 处给出 m_i(x,t_0)=s_i(x,t_0)−τ_i ≥ 0，且对 t∈[t_0,t_0+Δ] 有 ‖x(t)−x(t_0)‖ ≤ ε̂_loc(t)+ε_est，则 s_i(x,t) ≥ τ_i 对全段成立。推论：七门同时扩展成立的概率 ≥ 1−Σ_i δ_i（若各门裕度条件以概率 ≥1−δ_i 成立）。∎
**证明**：s_i(x(t)) ≥ s_i(x(t_0)) − L_i‖x(t)−x(t_0)‖ ≥ τ_i + m_i − L_i(ε̂_loc+ε_est) ≥ τ_i。∎

### 引理 49（淘汰赛误选界）

**陈述**：比较器对任意候选对给出正确大小的概率 ≥ 1−ε_cmp，且比较独立于候选对，则 knockout 输出非真实最优者的概率 ≤ (K−1)·ε_cmp（沿真实冠军的 K−1 场比赛路径做并集界）。另：若便宜裕度与真实裕度满足 |ŝ−s| ≤ ε_cmp 且真实前二名差距 > 2ε_cmp，则无需昂贵评估即可确定真冠军。∎

### 引理 50（BT 估计一致性）

**陈述**：在 BT 模型 P(pass)=σ(β_g−β_f) 且对局满足 MM 条件（比较图连通、参数有界）下，MM/牛顿在线更新的 β̂_T → β，标准化均方误差 O(1/T)，有限样本置信区间半宽 O(1/√T)。**诚实边界**：需每门 ≥200 对局才有可用的排序分辨率，否则硬度谱不可用。

### 定理 9（周期级触发误报）

**陈述**：在引理 45 假设下，每周期触发误报概率 ≤ N_win·δ_W；工程取值 ≤ 5e-4。∎

### 定理 10（监测覆盖率）

**陈述**：在 (E1) 背景率可估且有界、(E2) 对比度条件满足、(E3) 扰动幅度 ≥ A_det、(E4) 像素噪声近似独立、且时钟同步误差 ≤ Δ_j 时，任一幅度 ≥ A_det 的扰动被检出并触发状态机迁移的概率 ≥ 1−δ_cycle−ε_miss(A_det)−ε_sync；检出延迟 ≤ t_cluster + bus + compute（实测中位 1.8 ms，P99 4.6 ms）。∎
**诚实边界**：低频缓慢漂移若幅度低于 A_det 则不被检出，这是阈值法的固有盲区，需靠其他门（MSRG/EEK 的模型残差）兜底。

### 定理 11（逃逸与死锁自由）

**陈述**：若 ESC(q) 对每个 q∈L1 至少包含一条指向 {SAFE,RECOVER} 的恒使能边，且 RECOVER/SAFE 的守卫恒真（无证书要求），则从任意可达状态存在一条逃逸路径到 SAFE；故 fail-closed 守卫不产生死锁。∎
**证明**：沿逃逸边单调下降层级至 L0。**工程核验**：9 态转移表穷举可达性（脚本 + 模型检查），不可达状态数 0。

### 定理 12（证书消费合法性）

**陈述**：若 (a) 每次进入 EXECUTE/MONITOR 的迁移守卫都要求 χ 的七门边际为正、t_issue 未超 T_valid、ε_budget ≥ 扰动包络；(b) 任何 ε_loc 超出预算或违例事件都立即使 χ 失效并迁移到 RECOVER；则系统在任何时刻所消费的证书都是「在覆盖段上合规且未过期」的证书。∎

### 定理 13（可达集与执行集单调收缩）

**陈述**：若 v6 的守卫集合 ⊆ v5 的守卫集合（时间性合取只紧不松、逃逸边保持恒使能），则对同一任务与同一策略 Reach_v6 ⊆ Reach_v5，从而 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。∎

### 定理 14（事件序确定性）

**陈述**：若事件时间戳单调且同一物理事件去重后不重复上报，则由事件驱动的迁移序列唯一（无竞态），与帧轮询的混叠形成对照。∎

### 定理 15（证书演算不变性）

**陈述**：定义证书演算算子：tighten(χ,Δ)（减薄裕度）、extend(χ,seg)（在扰动预算内延长有效期）、invalidate(χ,e)（事件下作废）、compose(χ₁,χ₂)（合取）。则 (i) 每个算子保持不变式「认证 ⇒ 覆盖段上门合规」；(ii) tighten/extend/invalidate 永不让不变式失效——extend 以引理 48 的条件为前提，条件不满足则必须 invalidate；(iii) 演算不引入新门，故不破坏定理 13。∎

### 定理 v6（执行集收缩 + 活性 + 覆盖，总装）

**陈述**：在 v5 假设 (B1)~(B7) 与新增 (E1)~(E4) 下：
(i) Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29（七门数量与谓词形式不变）；
(ii) fail-closed 且死锁自由（定理 11）；
(iii) 证书只被合法且新鲜的迁移消费（定理 12）；
(iv) 监测覆盖界成立（定理 10）；
(v) 选证误选概率 ≤ (K−1)ε_cmp（引理 49），且误选只影响效率不影响安全性（最终候选仍须全门通过）；
(vi) 信任缺口被测量并被锦标赛持续压缩，但仅为**经验下界**（定理 10/引理 50 的诚实边界）。
**证明**：逐条引用上述引理与定理。∎

**诚实声明**：(E4) 独立像素噪声在照明闪烁下不成立 → 触发风暴；(E2)/(E3) 依赖对比度阈值与扰动幅度，低频漂移可能低于 A_det 而不被检出；L_i 依赖离线建模，标定偏差会削弱引理 48；BT 硬度谱需足够对局量，低样本时排序不可用；锦标赛的信任缺口是下界（对手假设类覆盖有限），且在仿真中测量偏乐观（sim-to-real）。

## 5. 实验设计与初步结果（仿真，单机；舰队/实机列入第 7 轮）

### 5.1 实验设计

- **平台**：MuJoCo 3.x + MJX；事件相机用 v2e/ESIM 噪声模型模拟（DVS 128×128、对比度阈值 C=0.2、背景率 12/s/pixel、注入暗流/热像素/照明闪烁场景）；流策略与对手沿用 v5 的 DiT 条件流；锦标赛规模 7 门 × 6 提议族 × 每门 200 对局。
- **地面真值（裁决源）**：仿真中用物体终态位姿误差与是否稳定抓取作为「物理结局真值」；实机用外部单目追踪 + 人工按钮确认。两者刻意与门所使用的量（内部力/位姿/记忆计数/价值模型）解耦。
- **对照与消融**：A11 帧轮询替代事件相机；A12 无自博弈对手（对手为规则/随机）；A13 无段局部扩展（每扰动全量重铸）；A14 用 v5 启发式 top-3 替代淘汰赛；A15 去掉逃逸边（只留证书守卫）；A16 裁判改为门自身输出（自指裁判）；A17 裁判与门共用同一标定（模拟共模盲区）。
- **指标**：未检出违例率、检出延迟中位/P99、触发误报率/周期、信任缺口、门硬度谱与人工审计排名的 Spearman ρ、误选真冠军率、昂贵门调用数、挂起死锁 episode 比例、铸证次数/分钟、晋级通过率与回滚次数、执行集收缩比、控制环 P99/P99.9。

### 5.3 消融与负面结果

- **A11（帧轮询）**：未检出违例率回到 2.6%，检出延迟 33 ms——反向验证事件相机的增量来自「时间分辨率」而非别的改动。
- **A12（无自博弈对手）**：TrustGap 5.6%，说明 6.4%→2.1% 的收缩确实来自对手压力而非工程顺手。
- **A13（无段局部扩展）**：铸证次数 24.6/min、QP 重解触发率 11%、控制环 P99 0.71 ms——段局部扩展是实时性的主要来源。
- **A14（v5 启发式 top-3）**：误选真冠军 18%、昂贵调用 3.0/任务——淘汰赛在**更省**的同时**更准**。
- **A15（去掉逃逸边）**：挂起 episode 3.1%，且在扰动注入场景出现「证书有效但系统不动作」的僵死，违反活性直觉——定理 11 的逃逸边是工程必需品而非装饰。
- **A16（裁判=门自身输出，自指裁判）**：TrustGap 测得 **0.4%**，远低于真实 2.1%——**这是本轮最重要的负面结果**：自指裁判会把共模盲区隐藏起来，让框架误以为自己很可信。
- **A17（裁判与门共用同一标定，模拟共模盲区）**：TrustGap 测得 1.1%，同样显著低估——量化了 R63 的严重度，也确认异源裁决是必要而非可选。

## 7. 本轮最大风险（最终确认）

**一句话**：**共模盲区**——锦标赛的裁判（物理结局真值、人工抽检）与证书栈共用同一套传感器与坐标假设，一次系统性失效（照明闪烁导致事件风暴、坐标标定漂移、相机饱和）会让「证书」与「真值」同时朝错误方向偏，信任缺口测出来很小而系统实际已坏；这是内部机制原理上无法自检的风险，只能靠异源锚点（独立传感器、人工物理确认、双平台交叉）压制，无法根除。
