# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；本轮灵感：「低延迟推理」×「任务分解」）

> R69 给闭环装上了一张会提问的嘴，却默认**时间是免费的**：`VoI(g) − c(g)` 是一笔静态经济账，只算「问一次值不值」，不算「在下一个控制截止期之前来不来得及问」。可 R69 的每一项收益都要用毫秒支付——K 采样、DTW 聚类、VoI 枚举、冻结 LLM 解码问句、Hutchinson 回放——而这些毫秒与控制器的硬截止期直接竞争。更糟的是，R69 把整条管线当成一个**单体**：贵的那一段一旦超时，系统不是「少知道一点」，而是**错过截止期**——这是安全性失败，不是效率损失。R69 甚至明写「K=4 歧义路径允许一次性预算超支」，这在软实时里是免责声明，在硬实时里是定时炸弹。
>
> 本轮两个灵感正好各补一刀：
> - **任务分解**说：一个决策不是一次前向，而是一张**带截止期的子决策 DAG**——感知、歧义估计、模态假设、交互、认证、下发各有不同的时限与价值；而且大量 epistemic 歧义**并不改变动作**（绕左/绕右通过认证后同样安全），根本不必消解。
> - **低延迟推理**说：每个子决策都可以是 **anytime / 可中断 / 可降保真** 的，能在「剩余 slack」内做多少算多少，做完多少用多少，绝不为了一步到位的确定性而牺牲准时。
>
> 核心命题：**把 R69 的单体闭环分解成一张截止期标注的任务 DAG；硬截止期只由一条 R68-safe 的「安全脊线」承担，所有 epistemic 细化都降级为可选、可中断、可投机、按「每毫秒计算价值」调度的枝叶；到点没算完的一律丢弃，且永不半提交。** 命名 **LADDER-RAS**（Latency-Aware Decomposed Decision & Epistemic Refinement）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**在下一个截止时刻之前，我能算到哪一步、又该果断放弃哪一步**」。

## 0. 直觉与动机

**灵感 1（低延迟推理 → 延迟是预算，不是成本标量）**
直觉：R69 把交互成本 `c(g)` 压成一个数，但真实系统里真正会杀人的约束是**截止期**，不是平均成本。平均 3ms、P99 12ms 的管线，在平均意义上「划算」，在每 100 帧一次的超时里就是事故。低延迟推理的正确姿态不是「把每一步都做快一点」，而是承认**计算可以被随时打断**：每个子任务都有一条 `质量–延迟` 曲线，先产出可用但粗糙的结果，再在剩余时间里逐级精化；时间一到，交付当前最好的可用结果。这把「快或准」的二选一，改写成「在预算内买到多少确定性」的连续优化。

**灵感 2（任务分解 → 按决策相关性拆，而不是按网络层拆）**
直觉：常见的「任务分解」是把策略拆成感知头、预测头、规划头，各自加速；但这仍是**计算视角**的分解。本轮更关键的是**决策视角**的分解：把「当前该做什么」展开成一棵决策树，内部节点是子问题（是哪个物体？对方意图是什么？抓把手还是抓杯沿？），叶子是经过认证的动作。许多子问题在叶子处**汇合到同一个安全动作**——此时无论答案是什么，动作都不变。这样的歧义叫**决策无关歧义**，消解它是在花钱买一个不改变行为的答案。任务分解的第一性价值，是**先把不会影响动作的枝剪掉，再谈怎么算得快**。

**灵感 3（slack 是唯一通用货币 → VoI 升级为 VoC）**
直觉：`slack = 截止期 − 安全脊线的 p99 延迟`。所有 refine 节点共享这一笔预算。一个细化节点值不值得跑，不取决于它的绝对信息量，而取决于它**在截止前完成的概率 × 每毫秒带来的风险下降**（value of computation, VoC）。这直接解释了 R68 与 R69 的关系：R68 是 `slack = 0`（没有时间问，只能收紧）；R69 是 `slack = ∞`（总来得及问，故只看 VoI）。LADDER 不是又加一层，而是在**延迟预算这条轴上把两者连成了一条退化谱**。

**灵感 4（投机执行 → 用预测换延迟，但不能有物理副作用）**
直觉：等观测到了再算就晚了；可以在预测的未来 `ô_{t+Δ}` 上**提前并行**算昂贵的消歧分支，等真实观测到达再做一次廉价校验：对得上就提交，对不上就丢弃。但必须区分两类动作：**计算可以投机并回滚，物理信息动作（注视/探针/问句）不能**——发出去的目光收不回来，说出口的话也收不回来。所以投机只允许发生在「准备」阶段，物理交互必须走两阶段 prepare→commit，绝不允许半次注视、半句提问。

**灵感 5（分解的反面 → 新失效模式是「标签错误」与「延迟撒谎」）**
直觉：LADDER 的安全性不再只押在模型上，而押在两个新前提上：(a) **安全脊线 / 可细化节点**的类型划分是对的；(b) **延迟预测**不会系统性乐观。一旦把某个安全关键子任务误标成「可丢弃的细化」，截止压力会精确地在最紧的时刻丢掉唯一不能丢的一步；一旦 p99 预测偏低，slack 就是一个谎言，调度器会自信地排进一个根本跑不完的计划。于是本轮必须交付：节点类型的静态安全闭包、单向保守的延迟校准、「宁可少算、不可错算」的降级阶梯，以及对这些新失效模式的审计与干扰集。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（LADDER-RAS 总览）** LADDER-RAS = (DTD, SCS, AIR, SPEC, ADT, FLB, DCC, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **安全脊线不可调度掉**：任何调度方案必须包含完整 SafeSpine，脊线节点不得降保真、不得丢弃、不得投机；
(iii) **截止期硬约束**：执行任何动作前，SafeSpine 必须已在截止期前完成；否则进入 hold-safe，不执行依赖细化的动作；
(iv) **原子提交**：细化结果只有在通过认证后一次性提交；未完成、已超时或投机过期的节点不得以任何比例写入动作。

**定义 311（截止期标注任务 DAG，DTD）** `G = (V, E, d, ℓ, τ, lf)`。节点 `v ∈ V` 是一个子决策（trunk、mode_head、FMP 采样、轨迹聚类、VoI 枚举、问句解码、CIA、FMA、C-RAS-WM 认证、prefix dispatch 等）；`E` 为数据/顺序依赖；`d(v) ∈ {spine, refine}` 为节点类型；`ℓ(v) ∈ {0,…,L_v}` 为保真档位；`τ(v, ℓ)` 为对应 p99 延迟；`lf(v)` 为最晚完成时刻。`τ(v)` 默认取 p99，所有调度只用 p99 而非均值，保证结论不依赖「平均情况」。

**定义 312（安全脊线 SafeSpine 与 slack）** SafeSpine `S* ⊂ V` 是覆盖「感知→认证→下发」所有路径的最小脊线割，且只含 `spine` 节点；其输出与 R68 的 `λ_floor` 收缩 + C-RAS-WM 认证前缀逐指令一致。`slack = D − τ_p99(S*)`，`D` 为控制截止期。若 `slack < 0` ⇒ 进入 **hold-safe**（R68 最保守 + 限速/停车），不执行任何需要细化的动作。slack 是本文唯一的时间货币。

**定义 313（anytime 节点与保真档位）** 每个节点有质量–延迟剖面 `Q_v(ℓ, τ)`，档位嵌套 `ℓ=0` 最粗、`ℓ=L_v` 最细，`Q_v` 对 `ℓ` 单调不减、对 `τ` 单调不增。FMP 的档位为 `ℓ = (K, N_step, early_exit_layer)`：`K∈{1,2,4}`、`N_step∈{1,2}`、速度网按层提前退出。关键约束：**认证只用区间/最坏情形包络，不用当前保真档位的点估计**，否则降保真会偷偷降安全。

**定义 314（计算价值 VoC，替代 R69 的 VoI）** 在状态 `s` 与已选调度 `σ` 下，
`VoC(v,ℓ | s,σ) = E[ΔR_risk(v,ℓ) | s] · P(τ(v,ℓ) + switch ≤ lf(v) | σ) / (τ(v,ℓ) + switch)`，
即「每毫秒的期望风险下降」，并乘以**赶得上截止期**的概率。`E[ΔR_risk]` 由当前模态后验与 ADT 的叶子风险给出。R69 的 `VoI(g) − c(g)` 是本式在 `P=1`、`τ` 被忽略、且只考虑交互节点时的特例。

**定义 315（slack 调度问题 SCS）** 选调度 `σ = {(v,ℓ)}` 最大化 `Σ_{(v,ℓ)∈σ} VoC(v,ℓ)`，约束：`Σ τ ≤ slack`、满足偏序 `E`、`S* ⊂ σ` 且脊线档位固定。这是带先序约束的背包型子模最大化。求解用「拓扑可行的边际 VoC/毫秒贪心」：每轮在可启动节点中取收益密度最高者，直到 slack 耗尽；`VoC` 单调子模时，基数约束下贪心 ≥ `(1−1/e)OPT`，一般背包下 ≥ `1/2 OPT`（标准结论）；实测报告与离线 oracle 的间隙。

**定义 316（动作相关决策树 ADT）** 把当前 `K` 个模态展开成一棵决策树：内部节点是子问题 `q`（物体身份 / 意图 / 可供性 / 接触点），每个内部节点的分支是该子问题的候选答案，叶子是经 `λ_floor` 与 C-RAS-WM 认证的动作。ADT 与 FMP 模态一一对应：模态是「整条轨迹的先验」，ADT 是「这条轨迹依赖哪些离散选择」的显式拆解。

**定义 317（决策无关歧义与剪枝）** 若某内部节点 `q` 的所有子树叶子在认证后产生**相同的最优安全动作与相同的风险上界**（在给定 `λ_floor` 下按字典序比较，允许配置等价），则称 `q` 为决策无关，剪掉该子树并把对应 `U_epi` 记为 0。定义决策相关性 `ρ(q) = max_{a,a'} |R(a) − R(a')| / R_scale`；仅当 `ρ(q) ≤ δ_act` 时剪枝。剪枝是**对目标函数无损**（引理 19），不是近似。

**定义 318（投机执行与租约 SPEC）** 在预测未来 `ô_{t+Δ}` 上提前计算 refine 分支，每个投机结果带租约 `(valid_until, pred_hash, ε_spec)`。真实观测 `o_{t+Δ}` 到达后，若 `‖o − ô‖ ≤ ε_spec` 且哈希一致则**提交**，否则**丢弃**（回滚代价为 0，因为纯计算无副作用）。物理信息动作 `g` **禁止投机**：只能 prepare 候选并认证，等真实观测到达后才可 commit。

**定义 319（两阶段原子提交 / 无半交互）** 信息动作走 `prepare(g*) → certify(g*) → commit(g*)`。若截止期在 prepare 与 commit 之间到达，任务被放弃，不得执行任何部分动作（不转半圈、不半句提问、不半程探针）。提交日志 `commit_log_hash` 记录每次交互的唯一原子性证据。

**定义 320（保真感知 FMP / 蒸馏一步流）** 默认执行 1-step 一致性蒸馏的速度网；当 `slack` 增大时依次升到 2-step、`K=2/4`。蒸馏只用于**生成候选**，认证仍用全保真区间包络；因此「用快模型生成、用慢边界认证」把低延迟与安全解耦。

**定义 321（延迟校准与单向保守 LPM）** 延迟预测器 `τ̂_p99` 由硬件计数器 + DAG 路径长 + 当前频率给出；在线监控 `|τ̂ − τ_actual|`。若校准误差超 `τ_lat`，**只允许把 slack 调小（悲观重估），永不允许调大**，即 `slack_used = min(slack_measured, slack_predicted) − margin`。延迟预测不允许乐观偏差。

**定义 322（降级阶梯 D0–D5）** `D0` 全保真；`D1` 丢弃可选 refine（按 VoC 从低到高）；`D2` 丢弃交互、保留诊断；`D3` 退回 R69→R68 纯保守；`D4` hold-safe（限速/停车）；`D5` 紧急停机。要求 **单调性**：沿 D0→D5，`λ` 单调不降、脊线不变、每级只减「算」不减「防」。降级由截止期余量、ECE、FMA 异常三者联合触发，而不是单一阈值。

**定义 323（证书 J_LADDER）** `J_LADDER = (J_FLUID, slack_used, spine_latency_p99, refinement_completion_ratio, dropped_nodes, speculation_hit_rate, speculation_waste, latency_calib_err, degradation_level, commit_log_hash, ladder_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ SafeSpine 按时完成 ∧ 降级级别与实测一致 ∧ 无半交互 ∧ 延迟校准误差 ≤ τ_lat`。

**定义 324（时序参与式审计 VQAuditor-T）** 在 VQAuditor-I 基础上审计「时间决策」：被丢弃的 refine 节点事后是否被证明是决策相关的（后悔值）、投机是否系统性过期、延迟预测是否系统性乐观、降级是否触发过晚。结论回灌 `AuditBuf`，更新下一轮的 VoC 先验与延迟余量。

**定义 325（延迟-投机干扰集 AIC-LADDER）** `ℰ_LADDER = ℰ_FLUID × ℰ_deadline × ℰ_spec`。`ℰ_deadline`：用高歧义/OOD 输入诱发昂贵路径、制造计算 DoS 以饿死安全脊线；`ℰ_spec`：构造让预测未来「看起来对」的对抗观测，骗取投机提交。新增攻击面：**攻击者不必骗过感知，只需骗过调度器**（让系统自己把安全时间花光）。

**定义 326（谱系包含：延迟预算单形）** LADDER 在 `slack=0 ∧ refine=∅` 时逐指令等于 R68；在 `slack=∞ ∧ 全保真 ∧ 无 ADT 剪枝` 时等价于 R69；一般情形是两者的连续插值。故 R68 与 R69 是延迟预算单形的两个顶点，LADDER 是内部点——**不是并列替代，而是在同一安全约束下的时间维度泛化**。

```python
# IP-264 DTD：截止期标注任务 DAG（节点类型静态检查，安全闭包）
class TaskDAG:
    def __init__(self, nodes, edges, deadline):
        self.V, self.E, self.D = nodes, edges, deadline
        self.spine = self._min_cut(kind='spine')          # 安全脊线，静态锁定
        self._assert_safety_closure()                     # spine 的每项前驱仍是 spine

    def p99(self, subset, fidelity):
        return longest_path_p99(subset, self.E, fidelity) # 只信 p99，不信均值

# IP-265 SCS：slack 调度（先剪决策无关枝，再按 VoC/ms 贪心）
def schedule(dag, belief, D):
    spine_t = dag.p99(dag.spine, fidelity='fixed')
    if spine_t > D:
        return HOLD_SAFE, 0.0                         # 来不及保安全 → 不细化
    slack = min(D - spine_t - LAT_MARGIN, measured_slack())
    cand = [v for v in dag.V
            if v.kind == 'refine' and decision_relevant(v, belief)]
    plan, used = [], 0.0
    while cand:
        feasible = [v for v in cand if used + tau(v, level(v)) <= slack
                    and precedence_ok(v, plan)]
        if not feasible: break
        v = max(feasible, key=lambda u: VoC(u, belief) / tau(u, level(u)))
        lvl = best_level_under(v, slack - used)       # anytime：能细则细
        plan.append((v, lvl)); used += tau(v, lvl)
        cand.remove(v)
    return plan, slack - used

# IP-268 ADT：动作相关分解与无损剪枝
def prune_action_irrelevant(modes, lambda_floor):
    tree = build_decision_tree(modes)                 # 子问题：身份/意图/可供性
    for q in postorder(tree):
        leaves = certified_leaves(q, lambda_floor)
        if max_risk(leaves) - min_risk(leaves) <= DELTA_ACT:
            mark_irrelevant(q)                        # 该歧义不影响动作
    return tree, relevant_modes(tree)

# IP-267 SPEC + IP-266 AIR：投机细化与 anytime 执行
def speculative_refine(node, o_hat, lease):
    result = node.run(o_hat, fidelity=lease.level)    # 纯计算，可回滚
    return Tagged(result, valid_until=lease.valid_until, pred_hash=hash(o_hat))

def commit_or_drop(tagged, o_real):
    if match(o_real, tagged.pred_hash) and now() <= tagged.valid_until:
        return tagged.result                          # 提交
    return None                                       # 丢弃，零副作用

    # 6) 证书 + 时序审计（记录丢弃后悔值与延迟校准）
    M.vqa_t.submit_async(plan, U_epi_eff, M.lat_calib, M.commit_log)
    return k, lam, M.select_mode(modes, U_epi_eff), J_LADDER(...)
```

## 3. 推导

**引理 19（决策无关剪枝无损）** 设内部节点 `q` 的所有叶子在给定 `λ_floor` 与 C-RAS-WM 认证下产生风险上界差 `≤ δ_act` 的动作集。剪掉 `q` 后，调度器不再为其分配任何计算，所选动作与风险上界不变（至多差 `δ_act`）。故「不改变动作的歧义」可以从 `U_epi` 中移除而不损失安全性——这是把「信息」与「有用信息」分开的关键一步。

**引理 20（VoC 子模与贪心界）** 若细化节点的边际风险下降随已选集合增大而递减（校准良好的后验下通常成立），则 `VoC` 是单调子模函数。此时定义 315 的密度贪心在基数约束下给出 `≥(1−1/e)OPT`，在带权 slack 约束下给出 `≥1/2 OPT`；先序约束只减少可选项，不破坏单调性。系：**调度不需要精确最优，贪心已足够接近，且失败模式是「少赚」而非「不安全」**。

**引理 21（anytime 单调性）** 在模态后验校准（A99）下，向已完成的证据集加入任一合法 refine 结果，Bayes 风险不增；因此「多做一步不会更差，少做一步只是少赚」。结合 `λ_floor` 的下界，停止计算不会突破 R68 的安全包络。注意反向不成立：未校准的后验可能让「多做一步」更差，故 MCG（R69 定义 306）在 LADDER 中升级为**调度准入条件**：ECE 越界 ⇒ 只允许 spine，禁止 refine 投机。

**引理 22（投机收益与浪费上界）** 投机命中率 `p_hit`、单次投机成本 `τ_s`、产生的延迟节省 `Δ`。当 `p_hit · Δ > (1−p_hit) · τ_s` 时投机有正期望；期望浪费计算 `≤ (1−p_hit) · Σ τ_s`，且浪费只消耗 slack，不影响脊线或安全。系：**投机是纯效率工具，永远不该被赋予安全职责**。

**定理 18（延迟预算谱系包含）** 在 A95–A99 下，`slack=0 ∧ refine=∅` 时 LADDER 与 R68 逐指令相同；`slack=∞ ∧ 全保真 ∧ 无剪枝` 时与 R69 等价；任一中间配置的期望风险 `≤` 同状态下的 R68，且 `≤` 同状态下的 R69。故 LADDER 是二者在延迟预算轴上的严格泛化，安全侧沿整条轴不退让。

**定理 19（截止期安全与无半提交）** 若 SafeSpine 在 `D` 前完成，则最终执行的动作属于 R68 认证集，且与哪些 refine 被丢弃、哪些投机被拒绝无关；两阶段原子提交保证不存在部分执行的物理信息动作；降级阶梯 `D0→D5` 使 `λ` 单调不降、安全包络单调收紧。故 **deadline miss 只会退化为更保守的 R68/hold-safe，不会退化为不安全动作**。

## 6. 本轮最大风险

**一句话**：LADDER 的安全性从「模型可信」转移到了「**节点类型划分可信 + 延迟预测可信**」——一旦把安全关键子任务误标为可丢弃的 refine，或 `p99` 预测系统性乐观，调度器就会在最紧的截止时刻**精确地丢掉唯一不能丢的那一步**；此时系统不是变慢，而是**准时地做错**。

```python
# IP-264 DTD：截止期标注任务 DAG（脊线静态锁定）
class TaskDAG:
    def __init__(self, nodes, edges, deadline):
        self.V, self.E, self.D = nodes, edges, deadline
        self.spine = self._min_cut(kind='spine')
        self._assert_safety_closure()        # spine 的所有前驱仍须为 spine

# IP-265 SCS：先剪决策无关枝，再按 VoC/ms 拓扑贪心
def schedule(dag, belief, D):
    t_spine = dag.p99(dag.spine, fidelity='fixed')
    if t_spine > D:
        return HOLD_SAFE, 0.0
    slack = min(D - t_spine - LAT_MARGIN, measured_slack())
    cand = [v for v in dag.V if v.kind == 'refine' and decision_relevant(v, belief)]
    plan, used = [], 0.0
    while cand:
        feas = [v for v in cand if used + tau(v, level(v)) <= slack
                and precedence_ok(v, plan)]
        if not feas: break
        v = max(feas, key=lambda u: VoC(u, belief) / tau(u, level(u)))
        lvl = best_level_under(v, slack - used)
        plan.append((v, lvl)); used += tau(v, lvl); cand.remove(v)
    return plan, slack - used

# IP-268 ADT：动作相关分解 + 无损剪枝
def prune_action_irrelevant(modes, lambda_floor):
    tree = build_decision_tree(modes)
    for q in postorder(tree):
        leaves = certified_leaves(q, lambda_floor)
        if max_risk(leaves) - min_risk(leaves) <= DELTA_ACT:
            mark_irrelevant(q)            # 该歧义不改变认证动作
    return tree, relevant_modes(tree)

# IP-267 SPEC：投机 + 租约校验（纯计算可回滚）
def commit_or_drop(tagged, o_real):
    if match(o_real, tagged.pred_hash) and now() <= tagged.valid_until:
        return tagged.result
    return None                           # 丢弃，零副作用

# IP-275 LADDER 主闭环（继承 R69，插入时间层）
def LADDER_RAS_round(M, obs):
    z, o = M.mtm.forward(obs)
    c, U_cal, _ = M.cof.step(o)
    plan, leftover = M.scs.schedule(M.dag, M.belief, M.deadline)
    base = M.r68_baseline(o, c, U_cal)             # 定义 312：R68-safe 脊线
    if base.latency_p99 > M.deadline:
        return M.degrade(HOLD_SAFE, base)          # D4
    for (v, lvl) in plan:                          # 只用 slack 做 refine
        if deadline_reached(M.deadline):
            M.audit.drop_remaining(plan, v); break
        if v.is_speculative: M.spec.submit(v, predicted_future(o), lvl)
        else:                v.advance(lvl)        # anytime：拿当前最好
    U_ale, U_epi, modes = M.merge_spine_and_refine(base, M.spec.commits())
    _, relevant = M.adt.prune_action_irrelevant(modes, M.lambda_floor)
    U_epi_eff = U_epi if relevant else 0.0         # 决策无关歧义免费
    g = None
    if U_epi_eff > TAU_EPI and M.scs.has_slack(plan):
        g = M.mint.prepare_and_certify(relevant, o)   # 物理交互：只 prepare
        if g and deadline_ok_before(commit_time(g)):
            g = M.mint.commit(g)                      # 唯一不可投机处
    lam = max(M.efs.risk_scale(...),
              lam_floor(U_ale + (0.0 if g else U_epi_eff)))
    k = M.c_ras_wm.certified_prefix(base.action, ..., wm_preds)
    M.vqa_t.submit_async(plan, U_epi_eff, M.lat_calib, M.commit_log)
    return k, lam, M.select_mode(modes, U_epi_eff), J_LADDER(...)
```

## 4. 推导

**引理 19（决策无关剪枝无损）** 若内部节点 `q` 的所有叶子在给定 `λ_floor` 与 C-RAS-WM 认证下风险上界差 `≤ δ_act`，则剪掉 `q` 不改变所选动作与风险上界（至多差 `δ_act`）。故不改变动作的歧义可从 `U_epi` 移除而不损失安全性——把「信息」与「有用信息」分开。

**引理 20（VoC 子模与贪心界）** 若边际风险下降随已选集合递减，则 `VoC` 单调子模；密度贪心在基数约束下 `≥(1−1/e)OPT`、带权 slack 约束下 `≥1/2 OPT`；先序约束只减少可选项、不破坏单调性。系：调度失败模式是「少赚」，不是「不安全」。

**引理 21（anytime 单调性）** 校准后验（A99）下，加入合法 refine 证据使 Bayes 风险不增；停止计算不会突破 `λ_floor`。反向不成立：未校准后验可能「多做更差」，故 MCG 升级为调度准入条件——ECE 越界只许 spine，禁止 refine 投机。

**引理 22（投机收益与浪费上界）** 命中率 `p_hit`、成本 `τ_s`、节省 `Δ`；`p_hit·Δ > (1−p_hit)·τ_s` 时投机正期望，期望浪费 `≤(1−p_hit)·Στ_s`，且只消耗 slack。系：投机是纯效率工具，永不承担安全职责。

**定理 18（延迟预算谱系包含）** A95–A99 下，`slack=0∧refine=∅` 与 R68 逐指令相同；`slack=∞∧全保真∧无剪枝` 与 R69 等价；中间配置期望风险 `≤` 同状态 R68 且 `≤` 同状态 R69。LADDER 是二者在延迟预算轴上的严格泛化。

**定理 19（截止期安全与无半提交）** 若 `S*` 在 `D` 前完成，最终动作属于 R68 认证集，与哪些 refine 被丢弃/投机被拒无关；两阶段原子提交排除部分物理交互；`D0→D5` 使 `λ` 单调不降。故 deadline miss 只退化为更保守的 R68/hold-safe，不会退化为不安全动作。

## 7. 本轮最大风险

**一句话**：LADDER 的安全性从「模型可信」转移到了「**节点类型划分可信 + 延迟预测可信**」——一旦把安全关键子任务误标为可丢弃的 refine，或 `p99` 预测系统性乐观，调度器就会在最紧的截止时刻**精确地丢掉唯一不能丢的那一步**；此时系统不是变慢，而是**准时地做错**。

**次级风险与缓解**：脊线被误分类（DTD 静态类型 + 安全闭包 + 定理 19 的 `S*` 不可调度掉）；延迟预测乐观（LPM 单向悲观 + E308 零乐观偏差门）；计算 DoS 饿死脊线（脊线先算、refine 后算 + E310）；投机投毒（租约/哈希 + 禁止物理投机 + E314）；决策相关性误剪（`δ_act` 保守 + 剪枝后悔值审计，定理 19 兜底）；降级过晚（`D0–D5` 单调阶梯 + 联合触发 + E306）。
