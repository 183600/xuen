# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「开源生态」×「在线学习」）

> R69 教会系统「看、问、触」，并用一条纪律把「问」纳入认证：aleatoric 收紧、epistemic 去问、单次回答不得单独定案。但它有两个从未写进证书的前提：
> (a) **闭环里所有零件都是「我们的」**——同一训练管线、同一份标定数据、同一个冻结版本；
> (b) **这一版就是永远**——实时流零学习写，系统不会从自己问出来的证据里变好，也不会变坏。
>
> 开源生态让 (a) 失效：真实部署是「冻结基座 + 社区适配器 + 第三方标定包 + 外部流头 + 别人的 LLM 解码器」拼起来的。每块都可能被上游静默更新、许可各异、可热插拔、也可被投毒。在线学习让 (b) 失效：一旦放开学习，系统会从交互中改变自己，于是漂移、遗忘、以及「自己选择问谁」造成的选择偏差一起回来。
>
> 本轮两个灵感正好合成一个新问题：
> - **开源生态**把信任对象从「模型」迁移到「**组合 + 出处 + 版本**」：证书不再是模型名字的函数，而是整张物料清单 Merkle 根的函数；同时给出解药（可复现工件、公开探针、社区审计、CVE 式吊销）。
> - **在线学习**把「出厂快照」变成「**一条非平稳的证据流**」：逐次测试的「每次都过」不等于「整条轨迹都过」；真正的敌人是沸蛙式漂移，而工具必须给出时间一致（anytime-valid）的保证。
>
> 核心命题：**R70 不再问「这一句回答可不可信」，而问「我此刻信任的这套拼装，还是上一轮认证过的那套吗；我从交互中学到的东西，是在认证域内改进，还是把它悄悄推了出去」。把认证从一次性快照升级为跨上游、跨版本、跨时间可续签的契约：出处账本 + 组合风险代数 + anytime-valid 在线监控 + 受控提交门 + 主动学习倾向性下限。** 命名 **GRAFT-RAS**（Gated Re-certification for Assembled and Fine-Tuned systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我信任的这整套东西，还是我以为的那一整套吗；而它正在学的东西，会不会把我带出证书**」——认证不是一次性盖章，而是一张必须随每个零件、每个版本、每个夜晚续签的通行证。

## 0. 直觉与动机

**灵感 1（开源生态 → 证书属于组合与出处，而不属于模型）**
直觉：R69 的 J_FLUID 像一张「给模型拍的照片」。开源生态里系统是「活的拼装」：今天换个量化流头，明天上游修个 bug，后天社区标定包升个版本。照片立刻过期，而没人会为每次换零件重拍整张照片。正确的对象是**物料清单（BOM）的 Merkle 根**：证书绑定「哪些哈希、以什么依赖关系、在什么版本下组合」，任何一片叶子变化都会改变根，从而自动作废下游声明。这把「信任一个名字」变成「信任一张可核对、可复现、可吊销的图」。

**灵感 2（在线学习 → 单步通过不等于全程通过）**
直觉：R69 的每个交互决策都「通过了认证」，就像沸水里的青蛙每一秒都觉得「温度还能忍」。逐次假设检验在无限序列上必然遭遇多次第一类错误（多重比较 / 偷看偏差），而缓慢的、每次都合规的更新可以累积成一次越界。在线学习给了正确的数学：**e-process / 测试鞅**给出时间一致的错误率控制；**累积安全预算（认证债务）**让「今天欠一点、明天还一点」显式记账，而不是悄悄透支。

**灵感 3（组合不是相加 → grafts 之间有免疫排斥）**
直觉：R69 默认「各层独立」，但上游适配器与本地标定器、流头与 LLM 解码器之间存在**干涉**：单独看每件都合格，合在一起可能出现新的模态、放大某个低密度区、或让标定层的残差假设失效。这就是移植的「排斥反应」。所以必须对**组合**做探针（graft-union probes），并把干涉项写进风险上界；未能认证干涉的组合，按最坏情况处理而不是按零处理。

**灵感 4（学习会自我实现 → 选择性求证制造选择偏差）**
直觉：R69 只在「它已经疑惑」的地方提问，因此它收集的数据不是世界分布，而是「疑惑分布」。用这些数据在线更新，会让模型越来越擅长回答自己爱问的问题，却对从不发问的区域越来越盲。更隐蔽的是 Goodhart：如果学习目标最终由监控器代理，学习者会学会让监控器满意，而不是让系统更安全。因此学习必须带**倾向性下限**（每个动作都有非零被探索概率）、**逆倾向加权**、**回放锚点**，并且只允许改效率层，安全层冻结。

**灵感 5（双时间尺度 → 实时不写、慢环提交、原子换装）**
直觉：R69 的铁律「实时流零学习写」不能被牺牲。在线学习不等于在线改控制策略。正确的结构是**双缓冲**：实时控制只读一份签名冻结快照；学习在影子缓冲持续进行；提交必须过门（CUG）并原子换装；出错则回滚到上一个已认证快照。这样既保住 R69 的实时不变式，又让系统真的能从交互流里变好。

**灵感 6（社区是证据，也是新的投毒面）**
直觉：开源生态同时提供「免费的审计」与「免费的共谋」。公开探针、第三方复现、CVE 吊销是极有价值的证据；但一个被收买的审计者、一组互相背书的 sybil 账户、一个看起来独立实则同源的 fork，会让「k 个独立证据源」退化成「k 个同一张嘴」。所以 R69 的正交性纪律必须升级为**出处加权的独立性**：同源不算独立，未声明来源不算独立。

**灵感 7（不可免费传播的证书 → 接口兼容不等于安全兼容）**
直觉：开源世界最容易犯的错，是把「API 没变」当成「行为没变」。但安全证书约束的是**行为分布与风险包络**，不是函数签名。一个「只是重构」的提交、一次「只换量化」的升级，都可能改变模态几何或低密度区。因此证书必须绑定内容哈希；fork 只有在差分效应可认证时才能继承证书，否则一律重认证。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（GRAFT-RAS 总览与四不变式）** GRAFT-RAS = (FMP, AUD, MINT, CIA, FMA, BOML, CAR, AOM, CSB, CUG, IAL, REV, CAL, RBG, RAS-WM†)。四不变式：
(i) **实时零学习写**（继承 R69 定义 293-i）：控制路径只读签名冻结快照 φ；
(ii) **出处绑定**：每个可执行工件是 BOML 的一个签名节点，证书绑定 Merkle 根 r_BOM；
(iii) **组合风险预算**：端到端风险 ≤ Σ 组件预算 + 经认证的干涉项，未认证干涉按最坏情况计；
(iv) **时间一致安全**：对任意长的版本序列，任一被提交版本越界的概率 ≤ α（anytime-valid）。

**定义 311（出处账本 BOML）** 节点 v = (h, ver, lic, sig_up, man_train, man_eval, revoke)，其中 h 为内容哈希、sig_up 为上游签名、man_* 为可复现清单。边 e = (u→v, kind) 表示组合/依赖/派生（微调、量化、蒸馏、fork）。账本是有向无环图；r_BOM = Merkle(G)。证书 C 只对 r_BOM 有效。

**定义 312（可执行快照与双缓冲）** 时刻 t 的控制策略 φ_t 是一份不可变快照，取自某个已认证 r_BOM。学习器只写影子快照 φ̃；提交 u 是 (φ_t → φ̃) 的原子换装。不变式：一个执行回合内 r_BOM 与所有节点哈希不变。

**定义 313（组合风险代数 CAR）** 对组合 φ，设组件 i 的认证扰动预算 ε_i、其到输出的下游 Lipschitz 增益 L_i、组件对 (i,j) 的认证干涉上界 I_ij：
R(φ) ≤ Σ_i L_i ε_i + Σ_{i<j} I_ij + R_shared。
单节点、无干涉时 I=0，退化为 R69 的单一证书。I_ij 不能假设为 0；未做 graft-union 探针时取最坏界 I_ij ≤ min(L_i ε_i, L_j ε_j)（保守）。

**定义 314（证书不可免费传播）** 设 fork φ' 相对 φ 的差分 Δ。C(φ) 可传播到 φ' 仅当存在认证的差分效应 cert(Δ) 满足 cert(Δ) ≤ δ_transfer，且 Δ 不触及安全相关子集（定义 322）。否则必须对 φ' 的 BOM 根重新认证。「接口兼容 ≠ 安全兼容」。

**定义 315（变更事件与脏集传播）** 任一节点的 h/ver/lic/revoke 变化触发变更事件；其下游闭包 D(v) 全部标脏。脏集非空时，实时路径继续跑旧快照，但禁止提交新快照，直到 CUG 通过。

**定义 316（在线监控 AOM / e-process）** 观测安全残差流 Z_1, Z_2, …（如组合残差、越界指示、校准误差）。零假设 H0: E[Z] ≤ ρ。构造有界测试鞅（e-process）
W_t = Π_{s≤t} (1 + λ_s (Z_s − ρ))，λ_s ∈ [0, 1/(1+ρ)]。
当 W_t ≥ 1/α 时拒绝 H0。由可选停时定理：在 H0 下 P(sup_t W_t ≥ 1/α) ≤ α。该保证**不假设独立同分布**，对非平稳流仍然时间一致，代价是功效依赖信噪比。

**定义 317（累积安全预算 / 认证债务 CSB）** 每个提交 u_k 记入债务 d_k ≥ 0（由 CAR 的上界增量、回放退化、漂移估计决定）。累积债务 D_t = Σ_{k≤t} d_k 必须满足 D_t + R(φ_t) ≤ B_safe。债务可由「干净的在线运行」按 AOM 的财富增长偿还（还款率 η）。沸蛙式漂移被显式记账：单步可过，累积不可无限。

**定义 318（分布漂移与有效样本量）** 设新数据分布 q、参考分布 p，密度比 w(x)=q(x)/p(x)。ESS = (Σ w_i)² / Σ w_i²。仅当 ESS ≥ n_min 且 w 的尾指数有界时，在线更新才被允许；否则裁剪 w 并计入偏差项，或拒绝更新。这条门是「支持失配」的硬闸，防止在从未见过的区域外推。

**定义 319（主动学习与倾向性下限 IAL）** 交互/查询策略的倾向性 π(g|s) ≥ π_min > 0（每个被考虑的信息动作都有非零探索概率）。学习估计使用逆倾向加权（IPW）：
θ̂ = argmin Σ_i (1/π(g_i|s_i)) ℓ(θ; s_i, g_i, y_i)。
只有效率层参数可更新（定义 322）；倾向性低于 π_min 的动作不得进入训练集，除非仅作未加权诊断。

**定义 320（交互诱导的分布偏移界）** 由于状态访问分布依赖策略，定义有效样本量 ESS_π 与重要性权重上界 W_max。认证的效率改进 ΔJ 满足
ΔJ ≤ c·√(Var_IPW / ESS_π) + c'·log(W_max)/n，
且当 ESS_π < n_min 或 W_max > W_cap 时 ΔJ 认证为 0（不得声称改进）。这把「主动学习一定更好」降级为「在支持覆盖下、可被证书承认的更好」。

**定义 321（社区与第三方证据 CAL）** 证据项 e 带出处 p(e) 与独立性签名 ind(e)。组合规则：同一出处/同一上游/同一被问者在相关图内只算一个独立源；sybil 与共谋由出处图的连通分量与相关惩罚处理。e-process 的 λ 按独立源数缩放，相关源不增加证据。

**定义 322（安全层冻结与受控遗忘）** 参数/组件分为安全相关子集 S（标定映射、模态几何、风险缩放、认证阈值）与效率子集 E（解码风格、任务偏好、非安全先验）。在线学习只更新 E；S 的任何变更走完整 CUG + 重新认证。回放锚点 A = 规范探针 ∪ 旧交互缓冲；遗忘风险 Forget = max_{a∈A} |J_new(a) − J_old(a)|；Forget > τ_forget 则拒绝提交。

**定义 323（吊销与回滚 REV）** 吊销列表是签名的 (h, reason, ts) 集合；命中后：标脏 v 及其下游、作废绑定到受影响 r_BOM 的证书、回滚到最近一个不含 v 的已认证快照、写不可变事件日志。回滚是原子的，控制连续（继承 R69 定理 17）。

**定义 324（受控更新门 CUG）** 提交 u 通过当且仅当：
(a) 出处校验（签名、哈希、许可、非吊销）；
(b) CAR 上界 R(φ̃) ≤ B_safe − D_t；
(c) 规范探针 + 投毒/幻影探针回放不退化；
(d) 漂移门（定义 318）通过；
(e) AOM 的非劣检验通过（新快照不低于旧快照的安全界）；
(f) CSB 可记账。任一失败即拒绝，实时路径不变。

**定义 325（证书 J_GRAFT）** J_GRAFT = (J_FLUID, bom_root, version_vector, car_bound, aom_wealth, cumulative_debt, ess, propensity_floor_ok, revocation_status, graft_ver)。Valid ⇔ Valid(J_FLUID) ∧ 出处可验 ∧ CAR ≤ B_safe − D_t ∧ AOM 未报警 ∧ 无吊销 ∧ 快照与 BOM 根一致。

**定义 326（退化边界）** 当 BOML 只有一个签名节点、无更新、IAL 关闭、π_min 不适用时，GRAFT 的每一步与 R69 逐指令相同。R69 = GRAFT 的「静态单体」边界；安全侧不做任何让步。

**定义 327（监控的独立第二意见）** 为防止学习者 Goodhart 化监控器，AOM 的代理残差必须与一个**不参与学习**的外部探针（例如固定规范场景的独立传感器/人工抽检）做周期一致性检查；二者散度超过阈值即冻结学习并报警。

**定义 328（版本向量与校准纪元）** 每个组件带校准纪元 e_i（版本向量）。跨组件融合仅在纪元兼容（同一标定窗口或已认证的纪元映射）时成立；纪元不一致的组合按未认证处理。这把 R68 的「标定窗口」从单组件推广到组合。

# IP-264 BOML：出处账本、签名与脏集传播
class ProvenanceLedger:
    def add(self, node): self.G.add_node(node.h, **node.fields); return self.root()
    def root(self): return merkle_root(self.G)
    def dirty_closure(self, v): return descendants(self.G, v) | {v}
    def verify(self, snapshot):
        return (all(self.G.nodes[n].valid() for n in snapshot.nodes)
                and snapshot.root == self.root()
                and not revoke.hit(snapshot.nodes))

# IP-265 CAR：组合风险代数 + graft-union 探针
def composition_bound(phi, probes):
    base   = sum(L[i] * eps[i] for i in phi.nodes)
    interf = 0.0
    for i, j in combinations(phi.nodes, 2):
        if (i, j) in probes.certified:
            interf += probes.I[(i, j)]                  # 实测干涉上界
        else:
            interf += min(L[i] * eps[i], L[j] * eps[j])  # 未认证 → 最坏
    return base + interf + phi.R_shared

# IP-266 AOM：anytime-valid e-process（不假设 iid）
class AnytimeMonitor:
    def __init__(self, rho, alpha): self.rho, self.alpha, self.W = rho, alpha, 1.0
    def observe(self, z, lam):
        self.W *= 1.0 + lam * (z - self.rho)
        return self.W >= 1.0 / self.alpha      # 时间一致拒绝，无偷看惩罚

# IP-268 CUG：受控提交门（慢环；原子换装）
def commit(snapshot, shadow, u, M):
    if not M.bom.verify(shadow):                        return reject("provenance")
    if M.car.bound(shadow, M.probes) > M.B_safe - M.csb.debt:
        return reject("risk")
    if not M.replay.noninferior(shadow, M.anchors):     return reject("replay")
    if not M.drift.gate(u.data):                        return reject("support")
    if not M.aom.noninferiority(shadow, snapshot):      return reject("online")
    if not M.csb.charge(M.car.inc(shadow, snapshot)):   return reject("debt")
    M.swap_atomic(shadow)                               # 此刻起实时路径读新快照
    return accept

# IP-269 IAL：带倾向性下限的主动学习（只更新效率层 E）
def learn(shadow, batch):
    keep = [x for x in batch if x.propensity >= PI_MIN]
    w    = [1.0 / x.propensity for x in keep]           # IPW
    if ess(w) < N_MIN: return shadow                    # 支持不足 → 不学
    grad = sum(wi * grad_eff(x) for wi, x in zip(w, keep))
    shadow.update_efficiency_layer(grad)                # 安全层 S 冻结
    return shadow

# IP-270 REV：吊销 → 脏集 → 作废证书 → 原子回滚
def on_revocation(hit, M):
    dirty = M.bom.dirty_closure(hit)
    M.certs.invalidate(lambda c: touches(c.bom_root, dirty))
    M.rollback_to(M.last_clean_snapshot(exclude=dirty))
    M.event_log.append_immutable(hit, dirty)

# IP-274 实时路径：与 R69 逐指令相同，只多版本戳与残差旁路
def GRAFT_round(M, obs):
    phi = M.snapshot                     # 签名冻结快照
    out = FLUID_RAS_round(phi, obs)      # R69 主闭环，零改动
    M.aom.observe(out.residual, phi.lam) # 只写监控流，不写策略
    M.ial.log(out.g, out.answer, out.propensity)  # 只写影子缓冲
    return out                           # 控制路径无学习写

## 3. 推导

**引理 19（证书的出处不可传递）** 对任意 fork/升级 Δ，若 Δ 触及安全相关子集或 cert(Δ) > δ_transfer，则 C(φ) 不能传播到 φ'，必须重认证。证明要点：证书只约束 r_BOM 的叶子与组合关系，Δ 改变叶子/边即改变被约束对象；「同名 / 接口兼容」不构成实测等价。系：**开源生态里「我的上游和你的一样」不是安全论证，只有哈希相同才是**。

**引理 20（组合干涉的次可加性与最坏界）** R(φ) ≤ Σ L_i ε_i + Σ I_ij + R_shared；若未对 (i,j) 做 graft-union 探针，则 I_ij 可取到 min(L_i ε_i, L_j ε_j)（存在使两组件误差同向叠加的输入）。故「单件都合格」不蕴含「组合合格」，且干涉项不能靠相加各件的独立证书得到。

**定理 18（GRAFT 严格包含 R69）** 在定义 326 的静态单体边界，GRAFT 与 R69 每步逐指令相同；一般情形下，GRAFT 只在「提升效率或更新组件」时放宽，且每次放宽都被 CAR/CSB/AOM 三重约束包住，故任意状态期望风险 ≤ R69（安全侧不让步），效率改进仅在认证域内兑现。R69 = GRAFT 的零更新、单节点退化。

**定理 19（anytime-valid 无沸蛙定理）** 设每个提交版本 φ_k 的安全残差在 H0 下满足 E[Z]≤ρ，AOM 用有界测试鞅 W_t 且累积债务满足 D_t + R(φ_t) ≤ B_safe。则对任意停时 τ（可依赖历史），P(∃k≤τ: R(φ_k) > B_safe) ≤ α。对照：逐次水平 α 的固定样本检验在长度 T 的流上族错误率 ≤ αT，随 T 线性膨胀。故「每步都过」必须升级为「整条序列都过」。

**定理 20（主动学习的安全改进界）** 在倾向性下限 π_min、安全层冻结、漂移门与回放锚点下，认证的效率改进满足定义 320 的 IPW 界；安全包络 R(φ) 不因效率层更新而增大。若 ESS_π < n_min 或 W_max > W_cap，则认证改进为 0，CUG 拒绝提交。系：**主动学习不是「问得越多越好」，而是「在被支持覆盖的区域里，按已知倾向性可被记账地变好」**。

**定理 21（吊销-回滚一致性与连续控制）** 吊销命中后，回滚到不含该节点的最近已认证快照，其 BOM 根与证书链可验证；换装是原子的，回滚前后控制指令在安全包络内连续（继承 R69 定理 17 与 R68 定理 15）。故供应链事件不会把系统留在「半新半旧」的未认证状态。

**引理 21（Goodhart 反馈的不可自证）** 若学习目标与监控器共享同一代理残差，存在一个策略序列使代理残差单调下降而真实风险上升（学习器可对代理过拟合）。因此必须引入定义 327 的不参与学习的外部探针；仅靠自监控的在线学习不构成安全论证。

## 6. 本轮最大风险

**一句话**：GRAFT-RAS 把「认证的连续性」本身当成了新的可信根——**若出处签名可被伪造、上游共谋、组合风险上界的干涉项被系统性低估、或在线监控在对抗性非平稳流中被慢慢喂成盲区，系统就会在「每一步都通过」的假象下被连续走出认证域**；此时证书仍在、日志仍绿，而安全已经悄悄失效。

**次级风险与缓解**：
1. **e-process 在强非平稳/低信噪比下功效不足** → 分层监控（按组件/场景）+ 外部探针 + 债务上限触发硬回滚；
2. **Goodhart / 学习器适应监控器** → 定义 327 独立第二意见 + 安全层冻结 + 定期红队探针；
3. **社区证据的 sybil / 共谋** → 出处图独立性加权 + 相关惩罚 + 许可与签名门槛；
4. **慢环提交延迟错过漂移窗口** → 实时只读旧快照、canary 快照、紧急吊销优先于常规提交；
5. **回放锚点带来隐私与存储成本** → 锚点摘要化/去标识化，只保留统计量与本轮证书所需最小证据。

# IP-264 BOML：出处账本与脏集传播
class ProvenanceLedger:
    def root(self): return merkle_root(self.G)
    def dirty_closure(self, v): return descendants(self.G, v) | {v}
    def verify(self, snap):
        return (all(self.G.nodes[n].valid() for n in snap.nodes)
                and snap.root == self.root() and not revoke.hit(snap.nodes))

# IP-265 CAR：组合风险上界
def composition_bound(phi, probes):
    base = sum(L[i]*eps[i] for i in phi.nodes)
    interf = 0.0
    for i, j in combinations(phi.nodes, 2):
        interf += probes.I[(i, j)] if (i, j) in probes.certified \
                  else min(L[i]*eps[i], L[j]*eps[j])      # 未认证 → 最坏
    return base + interf + phi.R_shared

# IP-266 AOM：anytime-valid e-process
class AnytimeMonitor:
    def observe(self, z, lam):
        self.W *= 1.0 + lam*(z - self.rho)
        return self.W >= 1.0/self.alpha                   # 时间一致，不依赖 iid

# IP-268 CUG：受控提交（慢环，原子换装）
def commit(snapshot, shadow, u, M):
    if not M.bom.verify(shadow):                       return reject("provenance")
    if M.car.bound(shadow, M.probes) > M.B_safe - M.csb.debt: return reject("risk")
    if not M.replay.noninferior(shadow, M.anchors):    return reject("replay")
    if not M.drift.gate(u.data):                       return reject("support")
    if not M.aom.noninferiority(shadow, snapshot):     return reject("online")
    if not M.csb.charge(M.car.inc(shadow, snapshot)):  return reject("debt")
    M.swap_atomic(shadow); return accept

# IP-269 IAL：倾向性下限 + IPW，只更新效率层
def learn(shadow, batch):
    keep = [x for x in batch if x.propensity >= PI_MIN]
    w    = [1.0/x.propensity for x in keep]
    if ess(w) < N_MIN: return shadow                  # 支持不足 → 不学
    shadow.update_efficiency_layer(
        sum(wi*grad_eff(x) for wi, x in zip(w, keep)))  # 安全层 S 冻结
    return shadow

# IP-270 REV：吊销 → 标脏 → 作废证书 → 回滚
def on_revocation(hit, M):
    dirty = M.bom.dirty_closure(hit)
    M.certs.invalidate(lambda c: touches(c.bom_root, dirty))
    M.rollback_to(M.last_clean_snapshot(exclude=dirty))
    M.event_log.append_immutable(hit, dirty)

# IP-274 实时路径：与 R69 逐指令相同，仅多版本戳与残差旁路
def GRAFT_round(M, obs):

    out = FLUID_RAS_round(phi, obs)                  # R69 主闭环，零改动
    M.aom.observe(out.residual, phi.lam)             # 旁路：只写监控流
    M.ial.log(out.g, out.answer, out.propensity)     # 旁路：只写影子缓冲
    return out                                       # 控制路径无学习写

## 4. 推导

**引理 19（证书的出处不可传递）** 证书只约束 `r_BOM` 的叶子与组合关系；差分 Δ 改变叶子/边即改变被约束对象。「同名/接口兼容」不构成实测等价。故若 Δ 触及安全相关子集或 `cert(Δ)>δ_transfer`，必须重认证。系：开源生态里「我的上游和你的一样」不是安全论证，只有哈希相同才是。

**引理 20（组合干涉的次可加性与最坏界）** `R(φ)≤ΣL_iε_i+ΣI_ij+R_shared`；未做 graft-union 探针时 `I_ij` 可取到 `min(L_iε_i,L_jε_j)`（存在使两组件误差同向叠加的输入）。故「单件都合格」不蕴含「组合合格」，干涉项不能由各件独立证书相加得到。

**定理 18（GRAFT 严格包含 R69）** 在单节点、零更新、关闭 IAL 的静态单体边界，GRAFT 与 R69 每步逐指令相同；一般情形下每次放宽都被 CAR/CSB/AOM 三重约束包住，故任意状态期望风险 ≤ R69（安全不让步），效率改进仅在认证域内兑现。

**定理 19（anytime-valid 无沸蛙定理）** AOM 用有界测试鞅且 `D_t+R(φ_t)≤B_safe`，则对任意停时 τ，`P(∃k≤τ: R(φ_k)>B_safe)≤α`。对照：逐次水平 α 的固定样本检验在长度 T 的流上族错误率 ≤ αT，随 T 线性膨胀。故「每步都过」必须升级为「整条序列都过」。

**定理 20（主动学习的安全改进界）** 倾向性下限、安全层冻结、漂移门与回放锚点下，认证效率改进满足 IPW 界；安全包络不因效率层更新而增大。若 `ESS_π<n_min` 或 `W_max>W_cap`，认证改进为 0，CUG 拒绝提交。系：主动学习不是「问得越多越好」，而是「在被支持覆盖的区域里，按已知倾向性可被记账地变好」。

**定理 21（吊销-回滚一致性与连续控制）** 吊销命中后回滚到不含该节点的最近已认证快照，BOM 根与证书链可验证；换装原子，回滚前后控制指令在安全包络内连续。故供应链事件不会把系统留在「半新半旧」的未认证状态。

**引理 21（Goodhart 反馈的不可自证）** 若学习目标与监控器共享同一代理残差，存在策略序列使代理残差单调下降而真实风险上升。因此必须有定义 327 的不参与学习的外部探针；仅靠自监控的在线学习不构成安全论证。

## 7. 本轮最大风险

**一句话**：GRAFT-RAS 把「认证的连续性」本身当成了新的可信根——**若出处签名可被伪造、上游共谋、组合风险上界的干涉项被系统性低估、或在线监控在对抗性非平稳流中被慢慢喂成盲区，系统就会在「每一步都通过」的假象下被连续走出认证域**；此时证书仍在、日志仍绿，而安全已经悄悄失效。

**次级风险与缓解**：e-process 在强非平稳/低信噪比下功效不足（分层监控 + 外部探针 + 债务上限硬回滚）；Goodhart / 学习器适应监控器（独立第二意见 + 安全层冻结 + 红队探针）；社区证据 sybil/共谋（出处图独立性加权 + 相关惩罚 + 签名门槛）；慢环提交错过漂移窗口（旧快照兜底 + canary + 吊销优先）；回放锚点隐私与存储（摘要化/去标识化，仅留最小证据）。
