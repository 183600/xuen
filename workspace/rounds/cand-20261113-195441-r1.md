# 第 69 轮（承接第 68 轮「CALM-RAS 标定感知风险自适应闭环」IP-243~252；灵感循环第 1 轮；本轮灵感：「嵌入式系统」×「跨任务泛化」）

> 第 68 轮把「标定」升级为在线潜变量，用速率限制挡住快变故障，用 canary 挡住坏适配器；但它的自陈风险已经指出一个更深的循环论证：**标定是否可信，仍然由被标定的那套测量来验证**。当慢故障与漂移同频、同签名时，COF 会把它「标好」，CFA 会把 H_cal 后验推高，CAC 的金标集若未覆盖该模式便放行——系统越会标定，慢故障越隐形。
>
> 本轮两个灵感给出两个「外部裁判」，而且恰好互补：
>
> - **嵌入式系统**：可信不是软件承诺，而是**写权限 + 物理参照 + 确定性执行**。把标定状态放进硬件隔离域，让学习模型只能「提案」不能「落笔」；用带隙基准、晶振/PPS、标准质量/力矩、已知电阻等**不经过学习通路的参照**做探针。
> - **跨任务泛化**：真漂移是**共享潜变量**，修正它应当让所有任务（包括未参与拟合的留出任务）都变好；慢故障是**局部/传感器特定**的，强行塞进标定只会让拟合任务变好。于是「泛化性」本身成为可证伪的计量判据；而任务多样性把 R68 的时间频率可分性升级为**任务空间可分性**。
>
> 核心命题：
>
> **XGM-RAS（Cross-task Generalized Metrology RAS）：用跨任务留出泛化做「内部裁判」，用硬件锚定探针做「外部裁判」，用嵌入式认证内核做「唯一仲裁者」；可辨识则标定，不可辨识则拒答并退入计量安全运行域——绝不让标定吸收不确定性。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我的标定凭什么可信、它能泛化到没见过的任务吗**」。

## 0. 直觉与动机

**灵感 1（嵌入式系统 → 标定的真值必须来自学习通路之外）**
直觉：R68 的 CAC 五关、双缓冲原子换装，本质上是把「学习写操作」关进软件围栏。但软件围栏挡不住一个有写权限的模型，也挡不住「模型和验证集一起漂移」。嵌入式平台给了三样软件给不了的东西：**硬件隔离的写权限**（MPU/TrustZone/独立安全核）、**物理可溯源的参照**（带隙电压、晶振/PPS、标准质量、已知力矩、已知电阻）、**确定性的时间与预算**（WCET、看门狗、A/B 双 bank）。因此应该把「谁有权写标定」从算法问题变成硬件问题：MTM/COF 只能产生带签名的 `Δc` 提案，唯一能写 `c, Σ` 的是 ECK；标定真值优先来自 HEP 的物理参照，而不是来自被标定的网络自己。

**灵感 2（跨任务泛化 → 漂移是共享的，故障是局部的；泛化性就是真伪判据）**
直觉：一个真实的标定误差是**共享潜变量**：它同时污染情绪、故障、世界模型、质量等多个任务；把它改正，应该让所有任务都变好，包括从未参与拟合的留出任务。一个慢故障则是**局部/传感器特定**的：把它硬塞进标定，只会让用于拟合的标定任务变好，留出任务不改善甚至变差。于是得到一个可证伪的判据：**能跨任务泛化的修正是漂移，不能泛化的修正是故障**。更进一步，任务多样性本身就是可辨识性来源：一个方向对单个任务可能不可见，但对另一个任务可见；把所有任务的敏感度拼起来，漂移/故障签名矩阵的零空间会缩小——这是 R68「频率可分」的任务空间版本。

**灵感 3（两个裁判 + 硬件仲裁 → 打破自证循环）**
把两者合流：HEP 是**外部裁判**（物理参照，不经过学习通路），CTGC 是**内部裁判**（未参与拟合的任务/探针），ECK 是**仲裁者**（硬件隔离、签名、原子提交）。三者都不是拟合目标本身，所以标定不再自证。判决不是二值的，而是三值：`CAL / FAULT / UNKNOWN`。当可辨识性不足或证据冲突时，系统必须**拒答**，进入计量安全运行域（MSR），而不是把不确定性吸收进 `c`。

**灵感 4（三值判决 → 不确定性不是一个标量，而要落到运行域）**
R68 在高不确定时统一抬高 `λ`、收缩 `k`，这是把动作空间沿一个标量方向压扁。本轮改为结构化降级：L0 正常；L1 冻结标定、禁用新适配器、保守 `λ`；L2 只运行对不可辨识方向不敏感的任务/动作（停、保持、回撤、慢速搬运），使用硬件锚定的控制模式；L3 安全停机。升级必须同时满足「新鲜探针 + CTGC 通过 + ECK 认证」，降级可以自动且单调。**拒答不是失败，而是可审计的安全状态。**

**灵感 5（对 R66–R68 风险的收编）**
- R66「情绪被欺骗 → 误放宽」：情绪任务现在也是 CTGC 的留出任务；若标定修正不能同时改善行为上下文中的情绪一致性，则判为局部故障；U 高时 MSR L≥1，`λ ≥ 0.8` 纪律保留。
- R67「WM/VQA 黑箱前瞻误放宽」：WM 是天然留出任务；标定修正若不能改善 WM 的下一步预测，说明它只拟合了标定段；CGC 在影子流里无标签地提前发现「任务梯度打架」。
- R68「慢故障被标定吸收」：核心目标。同频慢故障不再靠频率分离，而靠任务空间 off-span 分量 `κ_met` 与 CTGC 的留出泛化分离；不可辨识时明确拒答。
- R68「CAC 软件承诺」：升级为 ECK 硬件写权限 + 计量认证 `M_att`，适配器提交增加留出任务回归与标定红线检查。

## 1. 形式化定义（增量：定义 293–308）

**定义 293（XGM-RAS 总览）** `XGM-RAS = (CALM-RAS†, TIA, HEP, CTGC, CGC, MSA, ECK, TGR)`。继承 R68 的 MTM / SSG / COF / CFA / CAC / RAS-WM†。三条不变式升级：
(i) **标定写权限分离**：MTM/COF 只能产生 `Δc` 提案；唯一能写 `c, Σ` 的是 ECK，学习模块不能直接写安全内存、不能 DMA 到安全域；
(ii) **无可辨识性即不吸收**：`Δc` 只有在 TIA 判为可辨识且 CTGC 通过时才能作为 `H_cal` 提交；否则判 `H_fault` 或 `H_unknown`（拒答）；
(iii) **实时预算不变式**：HEP 与 CTGC 只在 slack 中运行并有 WCET 上界；任何超时、认证失败或看门狗触发都冻结 `c` 并进入 MSR，控制环仍保持 R68 的 `< 2.6 ms`。

**定义 294（任务族与防泄漏切分）** 任务族 `𝒯 = 𝒯_fit ⊔ 𝒯_ho ⊔ 𝒯_safe`，另有硬件探针集 `𝒫`。`𝒯_fit`（标定任务、静态段）用于估计 `Δc`；`𝒯_ho`（emo/fault/wm/qual/控制子任务）只用于 CTGC，绝不参与 `Δc` 的拟合；`𝒯_safe`（安全关键任务）永不进入任何梯度或自适应，只做监控。训练/验证必须满足：拟合集与留出集无样本、无时间窗、无传感器子集重叠；留出任务必须使用不同的模态组合或不同的时间片段。此定义显式禁止「用同一段数据既拟合又验收」的自证陷阱。

**定义 295（任务诱导敏感度与可辨识谱）** 对任务 `τ`，记损失 `ℓ_τ(c)`，敏感度 `J_τ = ∂ℓ_τ/∂c`（或残差雅可比）。任务诱导 Fisher 信息：
`F_𝒯(c) = Σ_{τ∈𝒯} J_τᵀ Ω_τ J_τ`，`Ω_τ` 为任务噪声精度。特征分解 `F_𝒯 = V Λ Vᵀ`，有效秩 `r_id = (Σλ_i)² / Σλ_i²`，方向可辨识度 `ρ_id(v) = vᵀF_𝒯v / vᵀv`，不可辨识子空间 `N_𝒯 = span{v : ρ_id(v) < ε_id}`。`r_id` 称为**任务空间孔径**：任务越多样，孔径越大，`N_𝒯` 越小。

**定义 296（漂移/故障签名与计量可分离指数）** 慢漂移 `c` 与慢故障 `f` 在任务/探针上的残差签名为 `s_d = J δ`、`s_f = K f`，其中 `J = [J_τ]`、`K = [K_τ]` 为堆叠雅可比。令 `P_J` 为 `Ω` 加权到 `range(J)` 的投影，定义
`κ_met = min_{‖f‖=1} ‖(I − P_J) K f‖_Ω`。
`κ_met ≈ 0` 表示慢故障与漂移**计量混叠**（R68 的盲区）；`κ_met ≥ κ_min` 时两者可由任务空间 off-span 分量分离，高斯噪声下的检测错误指数至少为 `κ_met²/(2σ²)`。关键点：`κ_met` 是**任务空间**量，与故障的时间频率无关。

**定义 297（硬件嵌入式探针 HEP）** 探针 `p = (u_p, y_p, r_p, J_p)`：已知激励 `u_p`、测得响应 `y_p`、硬件参照 `r_p`（带隙基准、晶振/PPS、标准质量/力矩、已知电阻/电流）、解析签名 `J_p`。探针集 `𝒫 = 𝒫_bias ⊔ 𝒫_gain ⊔ 𝒫_clock ⊔ 𝒫_thermal ⊔ 𝒫_elec`，分别覆盖零偏、增益、时间同步、热漂移、供电/电流。约束：
(a) 探针动作必须属于**探针安全集**（力/力矩/速度/工作空间/剂量上限，可逆，不造成人/物风险）；
(b) 参照必须可溯源，并有独立的漂移监控；
(c) 参照信号不经过学习 trunk。HEP 的价值不在「更准」，而在「**不由被标定对象定义真值**」。

**定义 298（跨任务泛化证书 CTGC）** 对候选 `Δc`，在冻结评测集上定义逐任务改善 `I_τ(Δc) = ℓ_τ(c) − ℓ_τ(c+Δc)`。令
`G_fit = Σ_{τ∈𝒯_fit} w_τ I_τ`，
`G_ho = Σ_{τ∈𝒯_ho} w_τ I_τ + Σ_{p∈𝒫} w_p I_p`，
`ρ_tr = G_ho / max(G_fit, ε_g)`，
`NT = Σ_τ max(0, −I_τ)`。
判决规则：
- `CAL`：`G_fit ≥ τ_g`、`ρ_tr ≥ ρ_min`、`NT ≤ δ_nt`、`max_τ(−I_τ) ≤ δ_deg`，且所有探针一致；
- `FAULT`：`G_fit ≥ τ_g` 且（`ρ_tr < ρ_min` 或 `NT > δ_nt` 或探针拒绝）；
- `UNKNOWN`：`G_fit < τ_g`，或探针 SNR `< τ_snr`，或证据持续冲突。
阈值 `(τ_g, ρ_min)` 在已知漂移/故障的计量集 `D_met` 上做共形校准，控制「静默吸收」风险 `≤ δ_abs`。一句话：**漂移必须处处变好；故障只允许局部变好。**

**定义 299（跨任务梯度相干性 CGC）** 在冻结 batch 上取 `g_τ = ∇_c ℓ_τ(c)`。相干性 `C_ct = (1/(M(M−1)))Σ_{τ≠τ'} cos(g_τ, g_τ')`，离散度 `D_ct = 1 − ‖Σ_τ g_τ‖ / Σ_τ‖g_τ‖`。取 `Σ_τ g_τ g_τᵀ` 的 top-r 特征子空间为相干子空间 `P_coh`。提案分解为 `Δc_coh = P_coh Δc` 与 `Δc_perp`；`Δc_perp` 是任务特定（故障）证据。CGC 无标签、可在影子流计算，作为 CTGC 的提前预警和探针调度的先验。

**定义 300（计量三值判决 MSA）** `V_met ∈ {CAL, FAULT, UNKNOWN}`：
- `CAL`：`κ_met ≥ κ_min` 且 CTGC=`CAL` 且 `ρ_id(Δc) ≥ ε_id`；
- `FAULT`：`κ_met ≥ κ_min` 且（CTGC=`FAULT` 或探针似然比 `LR ≥ τ_lr`）；
- `UNKNOWN`：`κ_met < κ_min`（混叠），或 CTGC=`UNKNOWN`，或探针 SNR 不足，或 ECK 超时。
`UNKNOWN` 时冻结 `c`（禁止写），令 `U = ∞`、`λ_floor = 0.8`，进入 MSR；只有在探针安全集内且「信息增益/风险」超过阈值时才允许安排主动探针。**宁可拒答，不可假确定。**

**定义 301（计量安全运行域 MSR）** 四级运行域：
- L0 正常：`CAL` 且 `U < τ_cal`，全功能；
- L1 标定冻结：禁用新适配器与在线标定写入，保守 `λ`，任务集不变；
- L2 不变量任务域：只运行对 `N_𝒯` 不敏感的任务/动作（停、保持、回撤、慢速搬运），使用硬件锚定控制模式，`k` 前缀收缩；
- L3 安全停机。
降级自动且单调（UNKNOWN / FAULT / 超时 / 认证失败）；升级必须同时满足「新鲜探针 + CTGC=`CAL` + ECK 认证」。这把 R68 的标量收缩升级为**结构化、可审计的降级**。

**定义 302（嵌入式认证内核 ECK）** 硬件隔离的安全域（独立安全核 / 锁步 MCU / TrustZone）。职责：
(a) 安全内存保存 `c, Σ`、证书、单调计数器；MTM 无写权限、无 DMA 通道；
(b) 邮箱只接收带 nonce、CRC、速率限制的 `Δc` 提案；
(c) 时间触发调度：控制（最高）> 安全监控 > 探针（slack，WCET `B_p`）> 影子训练（可抢占，尽力而为）；
(d) A/B 双 bank、单调版本号、安全启动、远程认证 quote，提交/回滚原子；
(e) 看门狗：心跳丢失或证书无效 → 硬件复位到最近有效 `c` 并进入 MSR L2；
(f) 产出计量认证 `M_att = Sign_ECK(hash(c, Σ, probe results, CTGC, CGC, version))`。

**定义 303（量化区间 EKF QIE）** 定点区间 EKF：状态与协方差存为向外取整的区间 `[x_lo, x_hi]`，predict/update 全程区间算术；`U_int = tr(Σ_hi)`。保证：真实 `c ∈ [c]`、`Σ_true ⪯ Σ_hi`，故 `U_int ≥ U_true`。有限字长带来的额外保守性在时域 `T` 上为 `O(T·d_c·2^{−b})`；选择位宽 `b` 使保守性 `≤ ε_q` 且满足 WCET。**量化不能制造虚假置信。**

**定义 304（任务泛化路由器 TGR）** 任务嵌入 `e_τ`，训练任务流形 `M_𝒯`，泛化半径 `r_gen`，泛化裕度 `m_gen(e_τ) = dist(e_τ, M_𝒯)/r_gen`。若 `m_gen > 1`（未见任务/未见组合），禁用学习标定与适配器，退回不变量策略，记入 `ℰ_xfer`。对组合任务检查任务算术兼容性 `e_{τ1+τ2} ≈ e_{τ1} ⊕ e_{τ2}`；不兼容则直接进入 MSR L2。

**定义 305（J_XGM 证书）** `J_XGM = (J_CALM, task_split_hash, F_𝒯 spectrum/r_id, κ_met, probe_set_hash, probe residuals/SNR, CTGC(G_fit, G_ho, ρ_tr, NT), CGC(C_ct, D_ct), V_met, MSR level, M_att, WCET slack, xgm_ver)`。
`Valid(J_XGM) ⇔ Valid(J_CALM) ∧ ECK attestation valid ∧ V_met/MSR 一致 ∧ 探针可溯源 ∧ 标定红线未越界`。证书可回放、不可抵赖；任何自适应提交必须携带它。

**定义 306（干扰集 AIC-XGM）** `ℰ_XGM = ℰ_CALM × ℰ_id × ℰ_emb × ℰ_xfer × ℰ_abs`：
- `ℰ_id`：混叠故障（`κ_met ≈ 0`）、探针伪造、参照漂移、主动探针偏置估计；
- `ℰ_emb`：故障注入、时钟/电压毛刺、DMA/内存攻击、超时、flash 损坏、认证重放；
- `ℰ_xfer`：负迁移、未见任务组合、任务路由错误、留出集泄漏；
- `ℰ_abs`：拒答 DoS、CAL/UNKNOWN 振荡、探针调度饥饿。
每个干扰都要求一个可观测签名与一个对应实验。

**定义 307（XGM 管线）** 离线：预训练 MTM；标定 HEP 参照；构造含已知漂移/故障的 `D_met`；共形校准 CTGC 阈值；完成 WCET 分析。在线：
控制 tick 内 MTM 前向 + COF 只产生提案；每 `T_p` 在 slack 运行 HEP；每 `T_cgc` 影子计算 CGC；每 `T_ctgc` 计算 CTGC；TIA 低频运行；ECK 判决/签名/提交；MSA 决定 MSR 级别。适配器提交在 R68 CAC 五关之上增加「留出任务回归」与「计量认证」两关。

**定义 308（跨任务泛化半径）** 对任务分布 `P_𝒯` 与留一任务误差 `ε_loto(τ)`，定义 `r_gen = sup{ρ : max_τ ε_loto(τ) ≤ ε_gen}`。`r_gen` 由离线留一任务交叉验证估计，并写入 `J_XGM`；TGR 的 `m_gen` 以此为尺度。跨任务泛化不是无限承诺，它有可度量的**适用半径**。

**假设 A95–A100**：A95 任务多样性（`J_τ` 张成漂移空间，故障签名存在 off-span 分量或可被探针补足）；A96 探针可溯源且参照漂移独立可监控；A97 CTGC 留出样本足够、损失有界、可共形校准；A98 区间算术向外取整、定点误差有界；A99 ECK 隔离成立（攻击者无物理/硬件级能力）；A100 探针与 CTGC 的 WCET 在 slack 预算内，超时必触发 fail-safe。

## 2. 关键算法骨架

```python
# IP-253 TIA：任务诱导可辨识性
class TaskInducedIdentifiability:
    def analyze(self, J, K, Omega, eps_id=1e-3):
        F = sum(J[t].T @ Omega[t] @ J[t] for t in J)
        lam = np.linalg.eigvalsh(F)
        r_id = (lam.sum() ** 2) / (np.sum(lam ** 2) + 1e-12)
        # Ω 加权投影到 range(J)，再取故障签名的 off-span 最小奇异值
        W = block_diag(Omega)
        Jw, Kw = sqrtm(W) @ vstack(J), sqrtm(W) @ vstack(K)
        P = Jw @ np.linalg.pinv(Jw)
        kappa = svd(Kw - P @ Kw, compute_uv=False)[-1]
        return {'r_id': r_id, 'kappa_met': kappa,
                'identifiable': kappa >= eps_id,
                'null_space': null_space(F, eps_id)}

# IP-255/256 CTGC + CGC：跨任务泛化证书
class CrossTaskGeneralizationCertificate:
    def evaluate(self, delta_c):
        I_fit = self.task_improvements(self.fit_tasks, delta_c)
        I_ho = self.task_improvements(self.ho_tasks, delta_c)
        I_pr = self.probe_improvements(delta_c)
        G_fit, G_ho = self.agg(I_fit), self.agg(I_ho) + self.agg(I_pr)
        rho = G_ho / max(G_fit, self.eps_g)
        NT = sum(max(0.0, -i) for i in I_fit + I_ho)
        verdict = ('CAL' if G_fit >= self.tau_g and rho >= self.rho_min
                   and NT <= self.delta_nt else
                   'FAULT' if G_fit >= self.tau_g else 'UNKNOWN')
        return verdict, {'G_fit': G_fit, 'G_ho': G_ho, 'rho_tr': rho, 'NT': NT}

    def gradient_coherence(self, grads):
        u = [g / (np.linalg.norm(g) + 1e-12) for g in grads]
        C = np.mean([np.dot(u[i], u[j]) for i in range(len(u))
                     for j in range(i + 1, len(u))])
        return C, 1.0 - np.linalg.norm(np.sum(u, axis=0)) / len(u)
```

## 3. 推导

**引理 16（任务多样性可辨识界）** 堆叠残差 `r = Jδ + Kf + ε`。若 `Kf ∈ range(J)` 对所有 `f` 成立，则存在 `δ'` 使 `Jδ' = Jδ + Kf`，两个假设的观测分布完全相同，任何估计器都不可分——这正是 R68 的混叠盲区，对应 `κ_met = 0`。反之若 `κ_met > 0`，则 `(I−P_J)r` 在故障下的均值范数至少 `κ_met‖f‖`；高斯噪声下，用该投影残差的卡方检验，检测错误指数为 `κ_met²‖f‖²/(2σ²)`。任务多样性通过扩大 `range(J)` 的维数缩小 `N_𝒯`：新增一个与前序任务敏感度不共线的任务/探针，会严格减小零空间；若故障签名在任一任务/探针上有 off-span 分量，则 `κ_met > 0`。系：**可辨识性来自任务空间秩，而不是标定时长或时间频率**；这解释了为什么 R68 的速率限制对同频慢故障无效。

**引理 17（CTGC 静默吸收界）** 在 `H_cal` 下，真漂移修正对每个任务的期望改善非负；在局部 `H_fault` 下，拟合任务改善 `E[I_fit] > 0`，但留出任务 `E[I_ho] ≤ 0`。令 `Δ = ρ_min E[I_fit] − E[I_ho] > 0`，改善量有界于 `[−B, B]`。由 Hoeffding，`P(G_ho ≥ ρ_min G_fit | H_fault) ≤ exp(−2N_ho Δ² / B²)`，故取 `N_ho ≥ (B²/2Δ²)ln(1/δ)` 即可把静默吸收压到 `δ`；在 `D_met` 上做共形校准可去掉分布假设。对照 R68：没有留出集时 `N_ho = 0`，该界退化为 1，即**同频慢故障必然被吸收**。系：CTGC 的检验力随「留出任务与拟合任务的条件独立性」增长；若留出任务与拟合任务共享同一故障源，则 `E[I_ho]` 也被抬高，检验失效——这是共模故障边界的来源。

**引理 18（量化区间健全性与实时预算）** 向外取整的区间 EKF 满足归纳不变式：若 `c_t ∈ [c_t]`、`Σ_t ⪯ Σ_t^hi`，则 predict/update 后仍成立，故 `U_int = tr(Σ_hi) ≥ U_true`；每步额外保守性不超过 `O(d_c·2^{−b})`，时域 `T` 内累加为 `O(T·d_c·2^{−b})`。若 HEP+CTGC 的 WCET 之和 `≤` 控制环 slack，则时间触发调度下控制 deadline 错过数为 0；超时路径进入看门狗并冻结 `c`。系：定点实现不会产生「虚假低不确定度」，只会更保守；保守性可被 `ε_q` 预算约束。

**定理 16（XGM 端到端计量安全）** 在 A87–A100 下，对任意慢故障：
1. 若 `κ_met ≥ κ_min`（可辨识），则 `P(静默吸收) ≤ δ_abs + δ_probe`，与故障频率无关；
2. 若 `κ_met < κ_min`（混叠），则 `V_met = UNKNOWN` 的概率 `≥ 1 − δ_det`，系统冻结 `c`、`λ ≥ 0.8`、进入 MSR L≥1——这是**显式拒答**，不是静默吸收；
3. 因此 R68 的 `α_cal` 被替换为 `α_cal^XGM ≤ max(δ_abs + δ_probe, δ_det)`，对带内慢故障也成立；
4. 快故障检出保持 R68 的引理 13 不变（COF 仍速率受限，CTGC 是附加证据，不改变快变残差通道）；
5. 若故障是共模的（`K` 在所有任务/探针上均落在 `range(J)`），则 `κ_met = 0`，系统只能拒答或误判；安全性不再由 CTGC 保证，而由 TIA 的 `κ_met` 估计质量与探针参照的独立性保证。

**定理 17（嵌入式认证与活性）** 在 A99–A100 下：
1. 学习模型绕过 ECK 直接写 `c` 的成功概率 `≤ ε_hw`（硬件隔离/无 DMA/签名校验）；
2. 提交与回滚在 A/B 双 bank 上原子，任意时刻读到的要么是旧版本、要么是新版本，不会出现混合状态；
3. 探针/CTGC 超时或认证失败时，看门狗在 `B_wd` 内把系统置入 MSR L2，控制环 deadline 错过数为 0；
4. 主动探针受安全集与剂量约束，单次探针造成的力/位移/热剂量有上界，故探针不会引入未认证的物理风险。

## 6. 预实验（代理仿真，非真机）

为验证引理 16/17 的机制，先用线性高斯代理模型做最小实验（`exp/xgm_sim.py`，5000 次 Monte Carlo，`d_c=4, d_f=2`，5 个拟合任务 + 5 个留出任务，σ=0.2，seed=20261113）：

**（a）任务空间可辨识性（对应引理 16）**

| `κ_met` | 0.000 | 0.214 | 0.334 | 0.997 |
|---|---|---|---|---|
| 5% FPR 下检出率 | 5.8% | 13.2% | 59.1% | 97.5% |

`κ_met ≈ 0` 时检出率等于误报率，验证「同频不可辨识」；off-span 分量增大后检出率单调上升。说明任务多样性确实是把「时间频率不可分」转成「任务空间可分」的杠杆。

**（b）CTGC 与共模耦合（对应引理 17 与其系）**

| 共模耦合 γ | CTGC 静默吸收（5% 误拒） | AUC | CGC AUC |
|---|---|---|---|
| 0.0（局部故障） | 0.26% | 0.999 | 0.748 |
| 0.3 | 20.6% | 0.853 | 0.679 |
| 0.6 | 62.8% | 0.569 | 0.608 |
| 1.0（完全共模） | 100% | 0.411 | 0.507 |

局部慢故障（R68 的盲区）被 CTGC 几乎完全拦下；但随着故障在留出任务上的共模耦合增强，CTGC 的判别力单调坍塌，完全共模时甚至会把故障当成漂移（AUC < 0.5，静默吸收 100%）。注意：在完整 XGM 中，完全共模对应 `κ_met = 0`，TIA 应判 `UNKNOWN` 并拒答；表中 γ=1 是「绕过 TIA、仅用 CTGC」的反事实消融，用来说明为什么 TIA 与探针参照的独立性是必不可少的，而不是可选的。CGC 在局部故障下有一定预警力（AUC 0.748），但在共模下同样失效——这与引理 17 的系一致。

**（c）结论**：代理仿真支持两个判断——(i) 任务空间 off-span 分量是慢故障可辨识的充分杠杆；(ii) 跨任务泛化不是万能钥匙，它的失效边界正是「故障在所有任务/探针上共模」。下一步必须用 E286–E300 在真实多任务/嵌入式平台上验证，尤其是 E295 的共模故障压力测试。

## 7. 本轮最大风险

**一句话**：XGM-RAS 把 R68 的「同频混淆」转化为「任务空间可辨识性」问题，但 `κ_met` 的估计本身依赖任务与探针的独立性——**若慢故障是共模的（同一供电基准漂移、同一温漂、同一批传感器老化同时污染所有任务与硬件参照），则故障签名落入漂移子空间、`κ_met ≈ 0`；此时若 TIA 因参照通道也被污染而把不可辨识误判为可辨识，CTGC 会看到「处处变好」，系统就会把共模故障认证成全局标定——参照系与被测对象共享同一个故障源时，泛化性无法自救。**

**次级风险与缓解**：
1. **留出集泄漏/任务相关性**：共享 trunk 与共享传感器使 `𝒯_fit` 与 `𝒯_ho` 不独立 → 按传感器子集/时间窗/模态组合做严格切分，训练时禁止跨切分梯度，定期做泄漏审计；
2. **TIA 的 `J/K` 估计误差**：在线估计的 `κ_met` 可能把接近零的混叠误判为可辨识 → 对 `κ_met` 做置信下界（bootstrap/区间），低置信时默认 `UNKNOWN`；
3. **探针物理风险与开销**：主动探针可能改变场景或造成磨损 → 探针安全集、剂量预算、信息增益/风险门控、可逆优先；
4. **嵌入式资源与量化保守性**：HEP/CTGC 挤占 slack、定点区间导致过度拒答 → WCET 分析、探针 duty cycle 上限、`ε_q` 预算、必要时降采样；
5. **ECK 供应链与物理攻击**：安全启动/认证依赖硬件根信任 → 出厂密钥、远程认证、A/B 回滚、物理篡改检测；
6. **拒答 DoS/振荡**：攻击者制造持续 UNKNOWN → 拒答预算、升级路径、人工接管、MSR 驻留时间下限。

## 2. 形式化定义（要点版）

**定义 293（总览与三不变式）** 标定写权限分离（只有 ECK 能写 `c,Σ`）；无可辨识性即不吸收（TIA+CTGC 双门控，否则拒答）；实时预算不变式（HEP/CTGC 在 slack 运行，超时冻结 `c` 并进入 MSR，控制环仍 `<2.6ms`）。

**定义 294（任务族与防泄漏切分）** `𝒯_fit` 只用于估计 `Δc`；`𝒯_ho` 只用于 CTGC；`𝒯_safe` 永不参与自适应。拟合/留出无样本、时间窗、传感器子集重叠，显式禁止「同一段数据既拟合又验收」。

**定义 295（任务诱导 Fisher 与可辨识谱）** `F_𝒯 = Σ J_τᵀ Ω_τ J_τ`；`r_id` 为有效秩，`ρ_id(v)` 为方向可辨识度，`N_𝒯` 为不可辨识子空间。任务越多样，孔径越大，零空间越小。

**定义 296（计量可分离指数）** `κ_met = min_{‖f‖=1}‖(I−P_J)Kf‖_Ω`。`κ_met=0` ⇔ 慢故障与漂移在任务/探针签名上混叠；`κ_met>0` 时检测错误指数 `≥ κ_met²/(2σ²)`；这是**任务空间**量，与时间频率无关。

**定义 297（HEP）** 探针 `(u_p,y_p,r_p,J_p)`，参照为带隙/晶振-PPS/标准质量/力矩/电阻；必须满足探针安全集、剂量上限、参照可溯源且不经过学习 trunk。

**定义 298（CTGC）** `I_τ = ℓ_τ(c) − ℓ_τ(c+Δc)`；`G_fit/G_ho`；`ρ_tr`；`NT`。`CAL` 需 `G_fit≥τ_g ∧ ρ_tr≥ρ_min ∧ NT≤δ_nt ∧ 逐任务退化≤δ_deg`；`FAULT` 为拟合好但留出差；`UNKNOWN` 为证据不足。阈值在 `D_met` 上共形校准。判据：**漂移处处变好，故障只局部变好**。

**定义 299（CGC）** `g_τ=∇_cℓ_τ`；`C_ct` 为梯度相干，`D_ct` 为离散度；`P_coh` 为 top-r 相干子空间；`Δc_perp` 作为任务特定故障证据。无标签、影子流运行。

**定义 300（MSA 三值判决）** `CAL`：`κ_met≥κ_min ∧ CTGC=CAL ∧ ρ_id(Δc)≥ε_id`；`FAULT`：`κ_met≥κ_min ∧ (CTGC=FAULT ∨ LR≥τ_lr)`；`UNKNOWN`：混叠 / 证据冲突 / SNR 不足 / ECK 超时。`UNKNOWN` ⇒ 冻结 `c`、`U=∞`、`λ_floor=0.8`、MSR L≥1。

**定义 301（MSR）** L0 正常；L1 冻结标定/禁新适配器/保守 `λ`；L2 仅不变量任务与硬件锚定控制（停/保持/回撤/慢搬运）；L3 安全停机。自动单调降级，升级需「新鲜探针 + CTGC=CAL + ECK 认证」。

**定义 302（ECK）** 硬件隔离安全域；唯一写权限；nonce+CRC+速率限制邮箱；时间触发调度（控制 > 安全监控 > 探针 > 影子训练）；A/B 双 bank + 单调版本 + 安全启动 + 认证 quote；看门狗 fail-safe；签名 `M_att`。

**定义 303（QIE）** 定点区间 EKF，向外取整；保证 `c_true∈[c]`、`Σ_true⪯Σ_hi`，故 `U_int≥U_true`；额外保守性 `O(T·d_c·2^{−b})`，受 `ε_q` 预算约束。

**定义 304（TGR）** 任务嵌入 `e_τ`、流形 `M_𝒯`、泛化半径 `r_gen`、裕度 `m_gen`；`m_gen>1` ⇒ 禁用学习标定/适配器，退回不变量策略，记 `ℰ_xfer`；组合任务检查任务算术兼容性。

**定义 305（J_XGM）** 在 `J_CALM` 上增加任务切分哈希、`F_𝒯/r_id`、`κ_met`、探针残差/SNR、CTGC/CGC、`V_met`/MSR、`M_att`、WCET。`Valid ⇔ Valid(J_CALM) ∧ ECK 认证 ∧ 判决/运行域一致 ∧ 探针可溯源 ∧ 红线未越界`。

**定义 306（AIC-XGM）** `ℰ_XGM = ℰ_CALM × ℰ_id × ℰ_emb × ℰ_xfer × ℰ_abs`：混叠/探针伪造、嵌入式故障注入/毛刺/DMA、负迁移/OOD 任务、拒答 DoS/振荡。

**定义 307（管线）** 离线：预训练 MTM → 标定 HEP 参照 → 构造 `D_met` → 共形校准 CTGC → WCET 分析。在线：每个控制 tick 只产生 `Δc` 提案；slack 中跑 HEP；影子流算 CGC/CTGC；TIA 低频；ECK 判决/签名/提交；MSA 决定 MSR。CAC 五关之上增加「留出任务回归 + 计量认证」两关。

**定义 308（泛化半径）** `r_gen = sup{ρ : max_τ ε_loto(τ) ≤ ε_gen}`，由留一任务交叉验证估计并写入 `J_XGM`；TGR 的 `m_gen` 以此为尺度。跨任务泛化有可度量的适用边界。

**假设 A95–A100**：任务多样性 / 探针可溯源 / CTGC 可共形校准 / 区间算术健全 / ECK 隔离成立 / WCET 在 slack 预算内且超时 fail-safe。

```python
# IP-253 TIA：任务空间可辨识性
class TaskInducedIdentifiability:
    def analyze(self, J, K, Omega, eps_id=1e-3):
        F = sum(J[t].T @ Omega[t] @ J[t] for t in J)
        lam = np.linalg.eigvalsh(F)
        r_id = (lam.sum() ** 2) / (np.sum(lam ** 2) + 1e-12)
        Jw, Kw = whiten(stack(J), Omega), whiten(stack(K), Omega)
        P = Jw @ np.linalg.pinv(Jw)
        kappa = np.linalg.svd(Kw - P @ Kw, compute_uv=False)[-1]
        return {'r_id': r_id, 'kappa_met': kappa,
                'identifiable': kappa >= eps_id, 'null_space': null(F, eps_id)}

# IP-254 HEP：物理参照探针
class HardwareEmbeddedProbes:
    def run(self, slack, risk, dose_left):
        cand = [p for p in self.probes if p.safe() and p.dose <= dose_left]
        chosen = sorted(cand, key=lambda p: p.info_gain / (p.risk + 1e-6))[:self.B_max]
        res = [p.excite_and_measure() for p in chosen]     # 不经过 MTM trunk
        return {'residuals': [r.y - r.ref for r in res],
                'snr': [r.snr for r in res],
                'safe': all(r.within_limits for r in res),
                'lr': self.likelihood_ratio(res)}

# IP-255/256 CTGC + CGC：跨任务泛化证书
class CrossTaskGeneralizationCertificate:
    def evaluate(self, delta_c):
        I_fit = self.task_improvements(self.fit_tasks, delta_c)
        I_ho = self.task_improvements(self.ho_tasks, delta_c)
        I_pr = self.probe_improvements(delta_c)
        G_fit, G_ho = self.agg(I_fit), self.agg(I_ho) + self.agg(I_pr)
        rho = G_ho / max(G_fit, self.eps_g)
        NT = sum(max(0.0, -i) for i in I_fit + I_ho)
        if G_fit >= self.tau_g and rho >= self.rho_min and NT <= self.delta_nt:
            verdict = 'CAL'
        elif G_fit >= self.tau_g:
            verdict = 'FAULT'
        else:
            verdict = 'UNKNOWN'
        return verdict, {'G_fit': G_fit, 'G_ho': G_ho, 'rho_tr': rho, 'NT': NT}

    def gradient_coherence(self, grads):
        u = [g / (np.linalg.norm(g) + 1e-12) for g in grads]
        C = np.mean([np.dot(u[i], u[j]) for i in range(len(u))
                     for j in range(i + 1, len(u))])
        return C, 1.0 - np.linalg.norm(np.sum(u, axis=0)) / len(u)

# IP-257 MSA + MSR：三值判决与结构化降级
class MetrologicalSafeAbstention:
    def decide(self, tia, ctgc, probes, U):
        if not tia.identifiable or ctgc == 'UNKNOWN' or probes.snr < self.tau_snr:
            return 'UNKNOWN', self.level(U, worst=True)
        if ctgc == 'FAULT' or probes.lr >= self.tau_lr:
            return 'FAULT', self.level(U, worst=True)
        return 'CAL', 0

# IP-258/259 ECK + QIE：唯一写权限与区间健全性
class EmbeddedCertificationKernel:
    def commit(self, delta_c, cert, qie):
        if not self.rate_limit_ok(delta_c): return 'REJECT'
        if not self.red_lines_ok(delta_c): return 'REJECT'    # 5% FS / 2° / 20ms
        if cert.V_met != 'CAL' or not self.verify(cert): return 'REJECT'
        c_int, S_int = qie.apply_interval(delta_c)             # 向外取整
        self.secure_write_ab(c_int, S_int, self.sign(cert))   # A/B 原子换装
        return 'PASS'

# IP-260 TGR：未见任务组合护栏
def task_router(e_tau, manifold, r_gen):
    return 'INVARIANT' if manifold.distance(e_tau) / r_gen > 1.0 else 'LEARNED'

# IP-262 主闭环
def XGM_round(M, obs):
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)
    r = residuals(x_prime, o, M.wm_residual_cache)
    c_prop, U, thr = M.cof.propose(o['cal'], r, sigma_stat(M))      # 仅提案
    probes = M.hep.run(M.slack(), risk=U, dose_left=M.dose_left)
    tia = M.tia.analyze(M.J_hat, M.K_hat, M.Omega)
    verdict, ctgc = M.ctgc.evaluate(c_prop)
    C_ct, D_ct = M.ctgc.gradient_coherence(M.shadow_grads())
    V_met, level = M.msa.decide(tia, verdict, probes, U)
    if V_met == 'CAL':
        M.eck.commit(c_prop, M.cert(V_met, tia, ctgc, probes, C_ct), M.qie)
    else:
        M.msr.enter(level)
    wm_preds = M.mtm.rollout(z, M.ach.propose_actions(x_prime, 5))
    joint = M.cfa(r, o['pi'], M.eck.read_state(), M.eck.U())
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime), joint, M.m_ras)
    lam = max(M.efs.risk_scale(joint), thr['lam_floor'], M.msr.lambda_floor(level))
    return k, lam, V_met, level, (tia['kappa_met'], ctgc['rho_tr'], C_ct)
```

## 4. 推导

**引理 16（任务多样性可辨识界）** `r=Jδ+Kf+ε`。若 `Kf∈range(J)` 对所有 `f`，则存在 `δ'` 使 `Jδ'=Jδ+Kf`，两假设观测分布相同 → `κ_met=0`，不可辨识（R68 盲区）。若 `κ_met>0`，`(I−P_J)r` 在故障下均值范数 `≥κ_met‖f‖`，高斯下检测错误指数 `κ_met²‖f‖²/(2σ²)`。新增不共线任务/探针严格缩小零空间；故障签名有 off-span 分量则 `κ_met>0`。**可辨识性来自任务空间秩，而非时间频率。**

**引理 17（CTGC 静默吸收界）** `H_cal` 下各任务期望改善非负；局部 `H_fault` 下 `E[I_fit]>0` 但 `E[I_ho]≤0`。令 `Δ=ρ_min E[I_fit]−E[I_ho]>0`，改善有界 `[−B,B]`，Hoeffding：`P(G_ho≥ρ_minG_fit|H_fault) ≤ exp(−2N_hoΔ²/B²)`。故 `N_ho≥(B²/2Δ²)ln(1/δ)` 可把静默吸收压到 `δ`；`D_met` 上共形校准可去分布假设。R68 无留出集（`N_ho=0`）时界退化为 1，**同频慢故障必然被吸收**。系：留出与拟合共享故障源时检验失效——共模故障边界。

**引理 18（量化区间健全性与实时预算）** 向外取整区间 EKF 保持 `c_t∈[c_t]`、`Σ_t⪯Σ_t^hi`，故 `U_int≥U_true`；每步额外保守性 `O(d_c·2^{−b})`，时域累加 `O(T·d_c·2^{−b})`。若 HEP+CTGC 的 WCET 和 `≤` slack，则控制 deadline 错过数为 0；超时经看门狗冻结 `c`。**定点只会更保守，不会虚假置信。**

**定理 16（XGM 端到端计量安全）** A87–A100 下：
1. `κ_met≥κ_min` ⇒ `P(静默吸收)≤δ_abs+δ_probe`，与故障频率无关；
2. `κ_met<κ_min` ⇒ `V_met=UNKNOWN` 概率 `≥1−δ_det`，冻结 `c`、`λ≥0.8`、MSR L≥1（显式拒答）；
3. `α_cal^XGM≤max(δ_abs+δ_probe, δ_det)`，对带内慢故障成立；
4. 快故障检出保持引理 13（COF 速率限制不变，CTGC 为附加证据）；
5. 共模故障（`K` 全落在 `range(J)`）⇒ `κ_met=0`，安全性转由 TIA 的 `κ_met` 估计质量与探针参照独立性保证。

**定理 17（嵌入式认证与活性）** A99–A100 下：学习模型绕过 ECK 写 `c` 的成功率 `≤ε_hw`；A/B 双 bank 保证提交/回滚原子，无混合状态；探针/CTGC 超时或认证失败时看门狗在 `B_wd` 内置 MSR L2，控制 deadline 零错过；主动探针受安全集与剂量约束，不引入未认证物理风险。

| E297 24h/7day 老化马拉松 | 长时程慢故障 | 零静默吸收，误拒答 ≤ 5%，成功率降 ≤ 3% |
| E298 消融 | 各组件贡献 | 去 TIA/HEP/CTGC/CGC/ECK/QIE 分别退化 |
| E299 嵌入式部署 | MCU/NPU 延迟/内存/功耗 | 实时预算、安全域内存、功耗达标 |
| E300 端到端验收 | 1000 次局部/共模慢故障注入 | 零静默吸收；拒答可解释；成功率不降 |

## 7. 预实验（代理仿真）

`exp/xgm_sim.py`：线性高斯代理，5000 次 Monte Carlo，`d_c=4, d_f=2`，5 拟合任务 + 5 留出任务，σ=0.2，seed=20261113。

**（a）任务空间可辨识性**

| `κ_met` | 0.000 | 0.214 | 0.334 | 0.997 |
|---|---|---|---|---|
| 5% FPR 下检出率 | 5.8% | 13.2% | 59.1% | 97.5% |

`κ_met≈0` 时检出 = 误报，验证同频不可辨识；off-span 增大后检出单调升。

**（b）CTGC 与共模耦合**

| 共模耦合 γ | CTGC 静默吸收（5% 误拒） | AUC | CGC AUC |
|---|---|---|---|
| 0.0（局部） | 0.26% | 0.999 | 0.748 |
| 0.3 | 20.6% | 0.853 | 0.679 |
| 0.6 | 62.8% | 0.569 | 0.608 |
| 1.0（完全共模） | 100% | 0.411 | 0.507 |

局部慢故障（R68 盲区）几乎被完全拦下；共模耦合增强时 CTGC 判别力单调坍塌，γ=1 时会把故障当漂移。完整 XGM 中 γ=1 对应 `κ_met=0`，TIA 应判 `UNKNOWN` 并拒答；表中 γ=1 是「绕过 TIA、仅用 CTGC」的反事实消融，说明 TIA 与探针参照独立性不可省。CGC 在局部故障下有预警力，在共模下同样失效，与引理 17 的系一致。

## 8. 本轮最大风险

**一句话**：XGM-RAS 把 R68 的「同频混淆」转化为「任务空间可辨识性」问题，但 `κ_met` 的估计本身依赖任务与探针的独立性——**若慢故障是共模的（同一供电基准漂移、同一温漂、同一批传感器老化同时污染所有任务与硬件参照），故障签名落入漂移子空间、`κ_met≈0`；此时若 TIA 因参照通道也被污染而把不可辨识误判为可辨识，CTGC 会看到「处处变好」，系统就会把共模故障认证成全局标定——参照系与被测对象共享同一个故障源时，泛化性无法自救。**

**次级风险与缓解**：留出集泄漏/任务相关性（按传感器子集/时间窗/模态严格切分 + 泄漏审计）；TIA 的 `J/K` 估计误差（`κ_met` 置信下界，低置信默认 UNKNOWN）；探针物理风险/开销（安全集 + 剂量预算 + 信息增益/风险门控）；嵌入式资源/量化保守性（WCET 分析 + duty cycle 上限 + `ε_q` 预算）；ECK 供应链/物理攻击（安全启动 + 远程认证 + A/B 回滚 + 篡改检测）；拒答 DoS/振荡（拒答预算 + 升级路径 + 人工接管 + 驻留时间下限）。
