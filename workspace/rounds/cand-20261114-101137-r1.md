# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「多轮对话」×「三维感知」）

> R69 让系统学会了「问」，但只在**单轮、短视、无空间地基**的意义上问：一次注视/一次探针/一句问话，随即决策。它自陈的最大风险是「问错比不问更危险」——因为模态分布若不可信，主动交互会把「诚实的不知道」变成「被证实的错误」。
>
> 本轮两个灵感正好补上 R69 的两个盲点：
> - **多轮对话**把「问一次」升级为**序贯实验设计**：问题会改变下一问，互补信息可以叠加，但也会带来指代歧义、错误预设、跨轮谄媚与煤气灯、以及误差跨轮累积；
> - **三维感知**给语言提供**可检验的地基**：持久语义场景图让「那个 / 后面那个 / 之前看到的同一个」变成场景图上的指代后验；Next-Best-View 把「被遮挡」这种 epistemic 不确定变成可执行的视角动作。
>
> 核心命题：**把消歧从「一次信息动作」升级为「扎根 3D 场景记忆的多轮对话」；但对话主张默认不是证据，任何跨轮信念更新都必须带出处、时效与独立性折扣；多轮只在信息互补时严格优于单轮，一旦冗余/被污染/空间标定失效，就单调退化回 R69 的单轮，再退化回 R68 的纯保守。** 命名 **SPIRE-RAS**（Spatial Persistent-memory Interactive Resolution Engine）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**这个『那个』到底是哪个、我上次看到它时它在哪、我是不是被一轮轮话术带偏了**」——多轮对话不是把同一句话问三遍，而是让每一问都锚在同一个三维世界上。

## 0. 直觉与动机

**灵感 1（多轮对话 → 消歧是序贯实验，不是一次抽签）**
直觉：R69 的 MINT 每一轮独立地算 `argmax_g[VoI(g)−c(g)]`，这是**短视**的。真实消歧常常是「先问大类，再问细节」「先看全景，再凑近遮挡处」「先确认是不是同一物体，再问它去哪了」。第一问的价值往往不在它自己降低多少熵，而在于**它把第二问变成可问的**。这在信息论上就是条件熵的**次模性**：互补信息的联合增益大于各自增益之和；而冗余信息的联合增益会被「重复计数」吃掉。于是多轮策略要回答三个 R69 没回答的问题：**(a) 问几轮？(b) 先问哪个？(c) 什么时候必须停？**

**灵感 2（三维感知 → 语言需要指代地基，否则可以被牵着走）**
直觉：R69 的问句 `q = Decode_LLM(g_ask)` 没有任何「指代」约束，模型完全可以生成一句语法正确、却指向虚空的问话（「它现在还在原来那里吗？」——哪个它？哪里？）。三维感知给出三样东西：**(i) 物体恒存**（被遮挡后仍以衰减置信度存在，可被再次观测复活）、**(ii) 空间关系**（前后/左右/支撑/包含，可把「后面那个」解析成场景图上的候选集）、**(iii) 视角可控**（Next-Best-View 能主动挪动/转动去消除遮挡，这是比「凝视」更强的物理信息动作）。但反过来，3D 记忆也会**过期、重影、被重复计数或被注入伪造节点**——地基本身可能是烂的。

**灵感 3（回音室 → 多轮最危险的新故障）**
直觉：单轮时，R69 还能说「我问了一次，但我用 k 个正交证据源交叉验证」。多轮时，系统会不自觉地把**自己上一轮说过的话**、以及**自己场景记忆里由那句话写进去的节点**，当成下一轮的支持证据。于是形成闭环：`对话主张 → 写入记忆 → 下一轮引用记忆 → 强化主张`。这不是学习，是**自我催眠**。因此本轮必须把「出处（provenance）」提升为一等公民，并定义**回音室判据**：若一个信念的支持图完全落在「对话主张来源」的子图里，则它不可辨识，必须要求外部锚点或直接保守。

**灵感 4（对 R69 的姿态 → 新层必须是旧层的严格退化）**
直觉：R69 的「单轮 + 无 3D 地基 + 无跨轮」应当恰好是 SPIRE 在 `H=1, no-SMS, no-NBV` 边界上的退化；R68 又是 R69 在「永不交互」边界上的退化。这样三层不是并列的三个黑箱，而是一条**嵌套的保守梯队**：多轮失败 → 单轮 → 不交互。安全侧永远只增不减，效率侧才拿 resolution bonus。

**灵感 5（新动作 = 新攻击面 → 多轮威胁模型）**
直觉：会「多轮问」之后，攻击者不必一次骗成，可以**慢慢推**：先问一个含错误预设的问题（「你刚才为什么把红杯子挪走了？」——它根本没动），再看系统是否接受预设；再反复重申一个假事实（「你上次说是蓝色」）制造煤气灯；或利用 3D 侧信道（伪造遮挡、重放旧视角、注入幽灵节点）让系统「亲眼看到」假证据。**多轮把单点欺骗变成渐进式共识劫持**。所以除主动交互认证外，还要有**错误预设拒答权**与**跨轮矛盾显式化**。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（SPIRE-RAS 总览）** SPIRE-RAS = (SMS, DST, MDP, NBV, SRG, CSPD, TVC, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **对话主张默认非证据**：人类回答、LLM 问句、历史对话默认只提供似然，不得单独改变已接地的场景图信念，除非有独立来源交叉支撑；
(iii) **出处与时效**：场景图每个节点、每条对话主张都带 `(source_class, timestamp, ttl, independence_id)`；过期自动降权，重复来源不重复计数；
(iv) **预算与单调退避**：每轮信息动作 ≤ 1 次、总交互轮数 ≤ H、物理位移 ≤ ε_g，且信息动作必须过 C-RAS-WM 认证；任一失败 ⇒ U_epi 未消解并**单调退化**到 R69/R68。

**定义 311（持久空间语义场景图 SMS）** `G_t = (V_t, E_t)`。节点 `v = (id, c_v, μ_v, Σ_v, occ_v, vis_v, prov_v, ttl_v, t_first, t_last)`：类后验 `c_v`、位姿均值/协方差、占据概率、可见性、出处、存活期。边 `e` 编码空间关系（左/右/前/后/上/下/支撑/包含）与共现。**物体恒存**：`v` 在被遮挡期间保留，置信度按 `exp(−Δt/τ_v)` 衰减；仅当出现**独立**观测时才刷新 `t_last` 并重置衰减。

**定义 312（多轮对话状态 DST）** `d_t = (ι_t, ρ_t, C_t, Q_t, X_t, t)`：意图后验 `ι_t`、场景图上的**指代后验** `ρ_t ∈ Δ(V_t)`、共同基础（已承诺且有出处的事实）`C_t`、未决问题集 `Q_t`、**跨轮矛盾集** `X_t`、轮次 `t`。约束：`C_t` 只吸收出处类别 ≥「独立来源」的接地事实；人类主张 `∈ C_t` 需标注信任上限 `τ_h`。

**定义 313（空间指代接地 SRG）** 指代表达 `e`（指示词、定指描述、空间关系、时序回指「之前那个」）映射为 `p(v | e, G_t, d_t)`。解析失败或 `max_v p < τ_ref` 或 top-2 后验间距 `< δ_ref` ⇒ **指代歧义**，不得默认取 argmax。**错误预设检测**：若 `e` 预设了一个在 `G_t` 中高置信不存在的节点/事实，标记 `presupposition_violation`，系统有权**拒答并要求重新表述**（拒答是合法动作，不是失败）。

**定义 314（多轮对话 POMDP 与策略）** 状态 `s = (world, G, intent, trust_state)`；动作空间 `𝒜_+ = 𝒜_task × 𝒜_info^H`，`𝒜_info = {gaze, probe, ask, viewpoint ν}`；观测模型含人类回答的**信任通道**（可信度上限、可能撒谎）。策略 `π(d_t)` 在时域 `H` 上最大化
`E[Σ_{t=0}^{H} γ^t (r_task − c_info − c_social)]`，s.t. 定义 310 的安全约束。默认 `H=1`（即 R69），仅当互补性估计超阈值才升 `H∈{3,5}`。

**定义 315（跨轮 VoI 与停止规则）** `VoI_H(g_{1:H}) = H(M | d_t) − E_{y_{1:H}}[H(M | d_t, y_{1:H})]`。逐轮贪心选 `g_t* = argmax_g [VoI(g | d_{t-1}) − c(g)]`；停止条件：边际 `VoI < c`、或触发矛盾 `X_t ≠ ∅`、或出处折扣后 `n_eff < n_min`、或预算耗尽。补充定义**互补性秩** `r_comp`：若 `r_comp = 1`（来源冗余），则强制 `H=1`，多轮无益。

**定义 316（3D 主动感知 NBV）** 视角动作 `ν ∈ SE(3)`（离散候选或连续）。信息增益 `IG(ν) = H(occ, ρ) − E_{o~p(·|ν)}[H(occ, ρ | o)]`，净收益 `IG(ν) − λ_m·‖ν‖_SE(3)`。`ν*` 必须经 C-RAS-WM‡ 认证：无碰撞、时间窗不超、移动不破坏当前任务安全包络。NBV 是「看/触」在三维上的严格推广，R69 的 gaze 是 `ν` 的旋转子集。

**定义 317（出处与时效 TVC）** 每条证据 `e` 带 `κ(e) ∈ {self_sensor, independent_sensor, human_claim, prior_memory, model_hallucination}` 与独立性标识 `indep_id`。定义**有效证据数** `n_eff = (Σ_i w_i)² / Σ_i w_i²`，其中 `w_i` 由 `κ` 与相关性 `ρ_ij` 折扣得到。记忆时效：`w_ttl = exp(−(t − t_last)/τ_v)`。**同一来源重复 100 次不增加 n_eff**。

**定义 318（多轮投毒与谄媚防御 CSPD）** 防御四类跨轮攻击：(a) **预设注入**（在问句里夹带假事实）；(b) **重复强化**（反复重申使系统把它当常识）；(c) **煤气灯**（否认系统已接地的事实，制造自我怀疑）；(d) **渐进推移**（每轮只推一点点，绕过单轮阈值）。规则：`κ = human_claim` 的证据进入贝叶斯时受信任上限 `τ_h` 约束，且**「与历史对话一致」本身不计为证据**；矛盾必须写入 `X_t` 并可在下一轮显式追问，而不是被静默平均掉。

**定义 319（3D 空间校准门 S-MCG）** 扩展 R69 的 MCG 到三维：对位姿、占据、指代后验分别计算 `ECE_spatial`、`ECE_ref`（含遮挡分层）。若 `ECE_spatial > τ_3d` 或 `ECE_ref > τ_ref_ece` ⇒ 禁用 NBV/SRG，退回 R69 的非空间单轮消歧；再失败退回 R68。对应「空间表征坍缩」的下游门。

**定义 320（对话审计 VQAuditor-D）** 审计对象新增：问句是否**诱导**、是否夹带预设、是否单源采纳、指代是否被正确接地、跨轮是否出现矛盾被平滑、`n_eff` 是否被重复来源虚增、NBV 是否安全。结论回灌 AuditBuf，成为下一轮 MINT/MDP 的先验成本。

**定义 321（AIC-SPIRE 干扰集）** `ℰ_SPIRE = ℰ_FLUID × ℰ_dialogue × ℰ_3d × ℰ_echo`：
`ℰ_dialogue = {poison_answer, false_presupposition, gaslight, sycophancy_drift, social_engineering}`；
`ℰ_3d = {ghost_object, occlusion_attack, viewpoint_replay, stale_map, adversarial_texture}`；
`ℰ_echo = {memory_dialogue_loop, self_citation, provenance_laundering}`。

**定义 322（证书 J_SPIRE）** `J_SPIRE = (J_FLUID, ECE_spatial, ECE_ref, H_ref_before, H_ref_after, turn_count, contradiction_log_hash, provenance_histogram, n_eff, nbv_log_hash, spire_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ ECE_spatial ≤ τ_3d ∧ 预设未越权 ∧ 出处非循环 ∧ 预算未越界`。

**定义 323（三级保守退避）** 若多轮在预算内消解且证据非循环：`λ = λ_floor(U_ale)`（resolution bonus）；若多轮失败/被投毒/`X_t≠∅`/`n_eff<n_min`：退回 R69 单轮，仍用 `λ_floor(U_ale + U_epi)`；若单轮也不可信/`ECE` 越界/`slow_fault_suspect`：退回 R68 最保守。**任何一级失败，λ 单调不降**。

**定义 324（出处折扣贝叶斯）** `p(M | y_1..y_k) ∝ p(M) · Π_i (p(y_i|M)/p(y_i))^{w_i}`，`w_i` 为独立性权重，`n_eff` 如定义 317；且后验置信度**封顶**于 `1 − ε_trust`（当仅有 `human_claim` 支持时封顶于 `τ_h`）。这修正了 R69「k 个正交源」是**假设**而非保证的漏洞。

**定义 325（对话承诺与提问安全）** 承诺 `C_t` 必须可审计、可追溯、可撤回；问句本身要过安全过滤：不得泄露敏感信息、不得诱导危险动作、不得把「拒答」堵死。**拒答一个含错误预设的问题，是正确行为而非交互失败**。

**定义 326（记忆—对话回音室判据）** 构造支持图：节点为信念，边为「支持」关系，边带出处。若某信念的支撑子图**完全**落在 `κ ∈ {human_claim, prior_memory}` 且无 `independent_sensor` 锚点，则判为**循环支持**，该信念不可辨识，禁止据此定案。静态近似可用信念—记忆互信息 `I(belief; 自身历史发言) / H(belief)` 监测。

**定义 327（多轮预算与自适应时域）** 默认 `H=1`；`r_comp` 与 `mode_head` 共同决定是否升 `H=3/5`。每升一档需同时满足：互补性高、空间校准通过、当前无矛盾、剩余任务时窗足够。保证 P99 实时预算，多轮路径允许一次性预算超支。

# IP-264 SMS：持久空间语义场景图（带出处/时效/物体恒存）
class SpatialMemory:
    def update(self, obs, prov, t):
        for det in obs.detections:                       # 含位姿/协方差/可见性
            v = self.associate(det)                      # 数据关联，避免重影
            if v is None:
                self.add_node(det, prov, t)
            elif prov.independent_of(v.prov):            # 仅独立观测才刷新
                self.fuse(v, det, prov, t)               # 融合位姿/类别/占据
                v.t_last = t
            # 被遮挡不删除：置信度按 exp(-Δt/tau) 衰减（物体恒存）
        self.decay_and_expire(t)                         # TTL 过期降权/归档

# IP-265 DST：多轮对话状态（只吸收已接地事实）
def dialogue_step(d, answer, graph, t):
    rho = srg.ground(answer.referents, graph, d)         # 指代后验
    if answer.has_presupposition and not graph.supports(answer.presupposition):
        d.X.add(('presupposition', answer.presupposition, t))   # 不采纳预设
    else:
        d = bayes_update_provenance(d, answer, weight=trust(answer))  # IP-269
    d.Q = update_open_questions(d, rho)
    return d

# IP-266 MDP：跨轮 VoI 策略（次模贪心 + 停止规则，H=1 即 R69）
def choose_dialogue_action(d, graph, budget):
    if d.X: return None                                  # 有矛盾 → 先澄清/保守
    if complementarity_rank(graph, d) <= 1:              # 来源冗余 → 不升多轮
        return one_turn_voi(d, graph, budget)            # 退化 R69
    best = None
    for g in info_candidates(graph, d):                  # gaze/probe/ask/NBV
        if not budget.allow(g) or not c_ras_wm.certify(g, graph): continue
        score = conditional_voi(g, d) - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None     # 边际无利 → 停

# IP-267 NBV：三维视角信息增益（满足安全包络）
def next_best_view(graph, d):
    cands = viewpoint_candidates(graph.occluded_regions)
    return max(cands, key=lambda v: ig_occupancy(v, graph, d) - move_cost(v)
               if c_ras_wm.certify_view(v) else -inf)

# IP-268 SRG：空间指代接地（拒答错误预设）
def ground_ref(expr, graph, d):
    rho = referent_posterior(expr, graph, d)             # 指示/定指/关系/回指
    if expr.presupposes and not graph.supports(expr.presupposes):
        return RefResult(rho, violation='presupposition')  # 可拒答
    if top2_gap(rho) < DELTA_REF:
        return RefResult(rho, ambiguous=True)            # 指代歧义 → 追问/保守
    return RefResult(rho)

# IP-269 CSPD+TVC：出处折扣更新（重复来源不重复计数，回音室拦截）
def bayes_update_provenance(d, evidence, weight):
    if provenance_cycle(d.belief, evidence, d.history):  # 定义 326
        d.X.add(('circular_support', evidence.id, d.t))
        return d                                         # 不成案
    w = independence_weights(evidence, d.history)        # 含 rho_ij 折扣
    n_eff = effective_count(w)
    if evidence.kind == 'human_claim':
        weight = min(weight, TAU_H)                      # 信任上限
    return posterior_update(d, evidence, weight, n_eff)

def SPIRE_round(M, obs):

        resolved = M.dst.decided(d)
    # 3) 似然第二意见（R69 继承）+ 回音室判据
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o, o_cal)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    circular = M.tvc.has_cycle(d.belief)
    # 4) 三级退避
    if not resolved or d.X or circular:
        return R69_round(M, o)                            # 回单轮
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale))    # 仅用 aleatoric
    mode = select_mode_from_ref(ref, d, lam)
    k = M.c_ras_wm.certified_prefix(mode.a, ..., wm_preds)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_d.submit_async(d, ref, a_hat, circular)         # 对话审计
    return k, lam, mode, (U_ale, d)
```

## 3. 推导

**引理 19（多轮 VoI 的次模性与贪心上界）** 证据集上的信息增益 `V(S) = H(M) − H(M | Y_S)` 是单调次模的。因此对 `|S| ≤ H` 的序贯问题，逐轮贪心达到最优的 `1 − 1/e`。系 1：**多轮只在互补性秩 `r_comp > 1` 时严格优于单轮**；若来源冗余（`r_comp=1`），贪心第一轮即饱和，`H=1` 最优——这正是 R69。系 2：停止规则 `边际 VoI < c` 不会损失超过 `1/e` 的最优性，且保证交互次数有界。

**引理 20（出处折扣与重复来源上界）** 若 `k` 条主张共享同一来源（相关性 `ρ`），朴素贝叶斯把置信度膨胀到约 `1 − (1−δ)^k`，但有效证据数满足 `n_eff = k / (1 + (k−1)ρ) ≤ 1/ρ`（`k→∞`）。故**重复来源永远无法把置信度推过由 `ρ` 决定的平台**；`ρ→1` 时 `n_eff→1`，多轮重申完全无信息。系：R69 的「k 个正交源」若未验证独立性，其安全保证 `δ_p·ρ^{k−1}` 是**乐观上界**；本轮以 `n_eff` 与信任上限 `τ_h` 将其修正为可检验量。

**定理 18（SPIRE 严格包含 R69/FLOID 与 R68）** 在 A95–A99 下，SPIRE 的期望风险 ≤ R69 ≤ R68；且当 `H=1`、`SMS` 不启用、`NBV` 不启用、无指代歧义、`n_eff ≥ n_min` 时，SPIRE **逐指令等价于 R69**；当进一步 `VoI ≤ c` 或 `ECE` 越界时逐指令等价于 R68。故 R69/R68 分别是 SPIRE 在「单轮」与「不交互」边界上的退化——安全侧不做任何让步，效率侧获得多轮 resolution bonus。

**引理 21（3D 指代可辨识性）** 设场景图候选的指代后验 top-2 间距为 `δ_ref`、候选可分性由空间分离与可见性决定。若 `δ_ref` 低于噪声底（遮挡/重影/标定误差），则**任何**预算内的问句或视角动作都无法把错误指代概率降到阈值以下；此时继续追问只会放大自信而非信息。故 `top2_gap < δ_ref ⇒ 必须退避/拒答`，而非强行接地。

**引理 22（回音室与循环支持不可辨识）** 若信念 `b` 的支撑子图全部来自 `{human_claim, prior_memory}` 且无 `independent_sensor` 锚点，则对 `b` 的后验更新不满足可辨识性：存在两个不同的世界状态产生完全相同的观测—对话联合分布。此时「与历史一致」不是证据，只是**自洽**；必须引入外部锚点或退回保守。这是定义 326 的理论依据，也是 R69「单次交互不得定案」在多轮上的严格推广。

**定理 19（多轮无漂移、无突变）** 在定义 317/324/325 下：(a) 仅有 `human_claim` 时后验置信度被 `τ_h` 封顶，重复与渐进推移不能突破；(b) 矛盾写入 `X_t` 并触发停止，信念不会被静默平均；(c) 任一级失败时 `λ` 单调不降地退化为 R69→R68，且提交/换装不变式（R68 定理 15）保持。故多轮交互**不引入控制突变**，只改变模态/指代选择。

## 6. 本轮最大风险

**一句话**：SPIRE 把「对话」和「3D 记忆」接在一起，就制造了一个**自证闭环**——系统上一轮的话可以写进场景图，下一轮又被当作支持自己的证据，误差于是跨轮复利、越问越确信；**若出处、时效与独立性折扣失效，多轮对话会把 R69 的「问错一次」升级为「用一串自洽的谎话把自己说服」——循环自证，比单点问错更危险**。

**次级风险与缓解**：
1. **3D 记忆重影/过期/被投毒** → 出处 + TTL + 独立观测才刷新（定义 311/317）+ ℰ_3d 对抗训练；
2. **指代接地错误被语言放大** → 指代后验 + top-2 间距门 + 拒答权（定义 313/325、引理 21）；
3. **跨轮谄媚/煤气灯** → 信任上限 `τ_h` + 矛盾显式化 + 「历史一致不算证据」（定义 318/324、定理 19）；
4. **多轮实时预算击穿** → 互补性秩门控 `H=1 默认` + 自适应时域（定义 315/327）；
5. **空间表征坍缩** → S-MCG 校准门，`ECE_spatial` 越界即禁用 NBV/SRG、退回 R69（定义 319）。

# IP-264 SMS：持久空间语义场景图（物体恒存 + 出处 + 时效）
class SpatialMemory:
    def update(self, obs, prov, t):
        for det in obs.detections:
            v = self.associate(det)                       # 数据关联，抑制重影
            if v is None: self.add_node(det, prov, t)
            elif prov.independent_of(v.prov):             # 仅独立观测刷新
                self.fuse(v, det, prov, t); v.t_last = t
        self.decay_and_expire(t)                          # 遮挡不删，按 TTL 衰减

# IP-265 DST：多轮状态（只吸收已接地事实；预设不采纳）
def dialogue_step(d, answer, graph, t):
    rho = srg.ground(answer.referents, graph, d)
    if answer.presupposes and not graph.supports(answer.presupposes):
        d.X.add(('presupposition', answer.presupposes, t))
    else:
        d = bayes_update_provenance(d, answer, trust(answer))   # IP-269
    d.Q = update_open_questions(d, rho); return d

# IP-266 MDP：跨轮 VoI（次模贪心 + 停止；H=1 即 R69）
def choose_dialogue_action(d, graph, budget):
    if d.X: return None                               # 矛盾 → 澄清/保守
    if complementarity_rank(graph, d) <= 1:
        return one_turn_voi(d, graph, budget)         # 退化 R69
    best = None
    for g in info_candidates(graph, d):
        if not budget.allow(g) or not c_ras_wm.certify(g, graph): continue
        score = conditional_voi(g, d) - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None  # 边际无利 → 停

# IP-267 NBV：三维视角信息增益

    cands = viewpoint_candidates(graph.occluded_regions)
    return max((v for v in cands if c_ras_wm.certify_view(v)),
               key=lambda v: ig_occupancy(v, graph, d) - move_cost(v), default=None)

    if expr.presupposes and not graph.supports(expr.presupposes):
        return RefResult(rho, violation='presupposition')
    if top2_gap(rho) < DELTA_REF: return RefResult(rho, ambiguous=True)
    return RefResult(rho)

# IP-269 CSPD+TVC：出处折扣（重复来源不重复计数；回音室拦截）
def bayes_update_provenance(d, evidence, weight):
    if provenance_cycle(d.belief, evidence, d.history):   # 定义 326
        d.X.add(('circular_support', evidence.id, d.t)); return d
    w = independence_weights(evidence, d.history)         # rho 折扣
    n_eff = effective_count(w)
    if evidence.kind == 'human_claim': weight = min(weight, TAU_H)
    return posterior_update(d, evidence, weight, n_eff)

# IP-274 主闭环（R69 + 三级退避）
def SPIRE_round(M, obs):
    M.sms.update(obs, obs.provenance, M.t)
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    if not M.s_mcg.ok(o): return R69_round(M, o)          # 空间校准失败 → 退化
    ref = M.srg.ground(obs.referent_expr, M.sms.graph, M.dst.state)
    if ref.violation: M.dst.reject_presupposition(ref)
    H = 1 if M.r_comp.rank(M.dst.state) <= 1 else 3
    resolved = False
    for _ in range(H):
        g = M.mdp.choose_dialogue_action(M.dst.state, M.sms.graph, M.budget)
        if g is None: break
        M.dst.step(M.dst.state, M.cia.execute(g), M.sms.graph, M.t)
        if M.dst.state.X: break
        resolved = M.dst.decided(M.dst.state)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o, o_cal)
    circular = M.tvc.has_cycle(M.dst.state.belief)
    if not resolved or M.dst.state.X or circular: return R69_round(M, o)
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale))    # 仅 aleatoric
    mode = select_mode_from_ref(ref, M.dst.state, lam)
    k = M.c_ras_wm.certified_prefix(mode.a, ..., wm_preds)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_d.submit_async(M.dst.state, ref, a_hat, circular)
    return k, lam, mode, (U_ale, M.dst.state)
```

## 4. 推导

**引理 19（多轮 VoI 次模性）** `V(S)=H(M)−H(M|Y_S)` 单调次模 ⇒ 序贯贪心达到最优 `1−1/e`；`r_comp=1`（冗余）时第一轮即饱和，`H=1` 最优 = R69。停止规则不损超过 `1/e`，且交互次数有界。

**引理 20（出处折扣上界）** 同源 `k` 条主张（相关 `ρ`）满足 `n_eff=k/(1+(k−1)ρ) ≤ 1/ρ`。故重复来源无法越过由 `ρ` 决定的置信平台；`ρ→1` 时多轮重申零信息。修正 R69「k 正交源」的乐观假设为可检验的 `n_eff`。

**引理 21（3D 指代可辨识性）** 若 top-2 后验间距低于噪声底（遮挡/重影/标定误差），任何预算内问句或视角都无法把错误指代率降到阈值下；继续追问只放大自信。故 `top2_gap<δ_ref ⇒ 退避/拒答`。

**引理 22（回音室不可辨识）** 支撑子图全在 `{human_claim, prior_memory}` 且无独立传感器锚点 ⇒ 存在不同世界产生相同观测—对话分布；「与历史一致」只是自洽，不是证据，必须外部锚点或保守。

**定理 18（SPIRE 严格包含 R69/R68）** A95–A99 下期望风险 SPIRE ≤ R69 ≤ R68；`H=1 / 无 SMS / 无 NBV / 无指代歧义 / n_eff≥n_min` 时逐指令等价 R69；再满足 `VoI≤c` 或 `ECE` 越界时逐指令等价 R68。安全不让步，效率获多轮 resolution bonus。

**定理 19（多轮无漂移、无突变）** (a) 仅 `human_claim` 时置信被 `τ_h` 封顶，重复/渐进推移不能突破；(b) 矛盾入 `X_t` 并停止，不被静默平均；(c) 任一级失败 `λ` 单调不降地退化 R69→R68，提交/换装不变式保持 ⇒ 控制连续。

## 7. 本轮最大风险

**一句话**：SPIRE 把对话与 3D 记忆接在一起就造出**自证闭环**——上一轮的话写进场景图，下一轮又被当成支持自己的证据，误差跨轮复利、越问越确信；**若出处、时效与独立性折扣失效，多轮对话会把 R69 的「问错一次」升级为「用一串自洽的谎话把自己说服」——循环自证，比单点问错更危险**。

**次级风险与缓解**：3D 记忆重影/过期/投毒（出处 + TTL + 独立观测刷新 + ℰ_3d）；指代错误被语言放大（指代后验 + top-2 间距门 + 拒答权，引理 21）；跨轮谄媚/煤气灯（`τ_h` + 矛盾显式化 + 历史一致不算证据，定理 19）；多轮实时预算击穿（互补性秩门控 + 自适应 H）；空间表征坍缩（S-MCG 越界即禁用 NBV/SRG、退 R69/R68）。
