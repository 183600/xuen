# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「深度学习」×「长程任务」）

> R69 把不确定性一分为二，并用「流匹配多模态策略 + 主动多模态交互」去消解 epistemic 部分。它问出「我该向谁求证、还能问什么」，这是巨大的进步。但 R69 的 VoI 是**短视**的：它在单个决策点比较「现在问」与「现在不问」，隐含假设每一步的歧义彼此独立、每个歧义都同样紧急、每次交互的收益都只作用于当前步。长程任务把这三个假设同时打破：
> - 一次模态误判会改变后续观测分布，错误**复利**，不是线性相加；
> - 有些歧义会在未来被免费观测消解，现在问是浪费；有些歧义必须先穿过不可逆的门，问晚了就没用；
> - R69 的 λ_floor 每步收紧，T 步后可能累积成「胆怯税」，让系统因为过度保守而无法完成任务。
>
> 同时，R69 自陈的最大风险——流模型模态分布不可信、追问幻影、把误导回答盖章为「已验证」——恰好可以在长程任务里被部分治愈：**事件结束后的延迟标签**（最终哪个模态为真、哪次交互真正有益）是离线再校准 MCG 与 VoI 的天然监督。深度学习在这里的正确用法不是「实时在线学习」，而是「异步、隔离、可回滚的离线整合」，从而不破坏 R69 的实时零写不变式。
>
> 核心命题：**把「瞬时消歧」升级为「带保质期的消歧」——用信息半衰期 τ_info 与不可逆指数 I 决定何时问，用非短视 VoI 衡量跨期价值，用跨期风险预算替代每步保守，用延迟标签离线再校准修复 R69 的模态失准，用时序模态一致性拦截幻影。** 命名 **EPOCH-RAS**（Epistemic-Persistence, Option-value, Credit-assignment, Horizon-aware Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「该向谁求证、还能问什么」，R70 问「**这个问题还值得现在问吗，还是让未来替我回答、把预算留给不可逆的那一步**」——不确定性不只能被问出来，也能被等待、被押后、在长程里复利。

## 0. 直觉与动机

**灵感 1（长程任务 → 误差是复利，不是加法）**
直觉：单步 95% 正确的策略，100 步连乘只剩 0.6%。R69 的 U_epi 是瞬时量，它把每一步的歧义当成独立事件；但长程任务里，第 t 步选错模态会改变后续观测分布，把「一次误判」变成「永久进入错误分支」。所以不确定性的代价不是 Σ U_t，而是随**剩余影响质量** κ_t 指数放大。必须把 κ_t 显式化，否则系统会把预算平摊到无关紧要的早期小歧义上，却在真正决定命运的岔口没预算。

**灵感 2（信息半衰期 → 有些问题不用问）**
直觉：人不会为每一个小歧义停下来问；有些歧义下一秒就自己清楚了（走过去就看见了，等一秒信号就稳定了）。若未来观测在到达不可逆分叉之前会以很高概率消解歧义，那么现在交互是浪费预算；反之若先要穿过一扇不可逆的门（抓取、签署、注射、变道），就必须在门前问清。VoI 必须乘以「歧义是否会在门前自然消解」——这就是**信息半衰期** τ_info。

**灵感 3（不可逆性 → 现在问 vs 以后问）**
直觉：长程任务的关键不是总时长，而是「不可逆动作」的位置。可逆区间里可以边做边看（defer），不可逆点前必须 resolve。定义 τ_info（信息半衰期）与 T_commit（不可逆时刻），交互时机 t* ≈ T_commit − τ_info：太早问会过时，太晚问来不及。这把 R69 的「要不要问」升级为「**什么时候问**」。

**灵感 4（风险预算 → R69 的每步保守会累积成胆怯税）**
直觉：R69 每步都用 λ_floor 压低速度，单步看很安全，T 步后可能什么都做不完（保守性雪崩 / timidity tax）。长程安全不是「每步最保守」，而是「把有限的风险预算花在不可逆处」：在可逆处允许 resolution credit 让渡，在不可逆处用最硬的地板。关键是硬下限仍在：**任何关于不可逆性的不确定 → I^ub=1 → 逐项退回 R69**，R69 不被削弱。

**灵感 5（深度学习 → 离线整合，而不是实时学习）**
直觉：R69 最大的病是模态分布不可信；长程任务正好提供「延迟标签」——事件结束后回看，哪个模态是真的、那次交互值不值，都有答案。用这些延迟标签离线再校准 MCG/VoI，是对 R69 风险的正面治疗。但必须异步、隔离、可回滚，绝不能在实时环路里写（继承零学习写操作）；否则把「校准」变成「漂移/投毒/遗忘」的新入口。

**灵感 6（深模型是双刃 → 新黑箱必须被旧下界锁住）**
直觉：非短视 VoI 需要一个学出来的长程价值/批评家，但它本身可能过度乐观，从而把「等一等」合理化。安全姿势：VCR 只允许在「校准通过且其给出的 VoI ≥ 短视 VoI 下界」时启用；任何不确定 → 回落到 R69 短视 VoI + 硬地板。这样长程层是 R69 的严格扩展，不是替代。**深模型只准改善效率，不准改善（放松）安全。**

## 1. 形式化定义（增量：定义 310–325）

**定义 310（EPOCH-RAS 总览与四不变式）** EPOCH-RAS = (HUT, NVOI, IRS, VCR, TMC, DLR, RCA, RAS-WM†)。四不变式：
(i) **实时零学习写操作**（继承定义 276-i / 293-i）：所有参数更新只发生在离线/异步通道；
(ii) **硬安全地板**：∀t，λ_t ≥ λ_floor(U_ale + I_t^ub·U_epi^unres)，其中 I_t^ub 是不可逆指数的**保守上界**；当 I_t^ub=1 时逐项等于 R69；
(iii) **跨期预算**：总交互次数 ≤ B_H、总位移 ≤ E_g、社交成本 ≤ C_H，由 token bucket 发放，禁止透支未来；
(iv) **延期权可撤销 + 到期强制决策**：任何 defer 必须携带最迟决策时刻 T_commit^ub 与失败退路；证据表明 T_commit 不可信时 I^ub←1，立即退回 R69。

**定义 311（长程增广过程）** 离散 H 步、折扣 γ∈[0,1)。信念 b_t 定义在潜在模态/世界状态上；增广动作 ξ_t=(a_t,g_t)（继承定义 294）；转移 P(o_{t+1}|b_t,ξ_t)。潜在模态 M_t 同时影响转移与回报。策略 π_θ(ξ_{t:t+H}|o_t) 由 R69 的 FMP 给出。

**定义 312（影响质量与误差复利）** 对 t 处的模态决策，定义其**剩余影响质量**
κ_t = Σ_{k=t}^{min(t+H,T)} γ^{k−t}·P(∂J/∂M_t ≠ 0 at k | h_t)，
即该决策在折扣意义下仍然相关的概率质量。独立近似下，每步模态错误概率 p 使成功率 S(t) ≈ ∏_{k=t}^{t+H}(1−p_k) ≈ (1−p)^{H−t}。κ_t 越大，同一处歧义越值钱；这解释了为什么 R69 的「平摊式」VoI 在长程上会错配预算。

**定义 313（信息半衰期）** τ_info(t) = min{τ ≥ 0 : E_{o_{t:t+τ}}[H(M_t|o_{t:t+τ})] ≤ ½·H(M_t|o_t)}；若不存在则 τ_info=∞。它度量「不问也能自己清楚」的时间尺度。实际用 HUT/VCR 的集成预测 + 保形区间给出保守上界 τ_info^ub。

**定义 314（不可逆指数与不可逆时刻）** 给定当前歧义下的两个候选模态 {m_i,m_j}，
I_t = 1 − E[V_recover(b_{t+1}^{m_wrong})] / E[V_recover(b_{t+1}^{m_right})] ∈ [0,1]，
其中 V_recover 是在剩余预算内回到正确分支的最优值。I_t=0 表示选错可无损恢复；I_t=1 表示选错即锁死。T_commit = min{t' ≥ t : I_{t'} ≥ I_crit} 是必须在此之前定案的**不可逆时刻**。I_t^ub 由集成/保形给出保守上界；不可信时取 1。

**定义 315（认知债务与胆怯税）** 认知债务 D_epi(t) = Σ_{k=t}^{min(t+H,T)} γ^{k−t}·κ_k·U_epi(k)（只计未消解部分），是 R69 瞬时 U_epi 的跨期积分；D_ale 类似但只走 λ 硬地板。胆怯税 TT(t) = Σ_{k=t}^{t+H}[c(λ_k) − c(λ_hard,k)]，度量因过度保守而损失的可行进度。R69 的 TT 随 H 线性增长，这正是长程任务里「越安全越做不完」的来源。

**定义 316（非短视 VoI，NVOI）** 设 V* 为长程最优值，b_t^g 为执行信息动作 g 后的后验：
VoI_H(g|b_t) = E[V*(b_t^g) − V*(b_t)] = IG(g) + OV(g) − Risk(g)。
IG 是 R69 的即时信息增益；OV 是**期权价值**（未来决策因更准的信念而改善，与 κ_t 同阶）；Risk 是信息动作自身风险与错误回答的风险溢价。押后价值定义为
VoI_def(t) = E_{o_{t+1}}[V*(b_{t+1})] − V*(b_t)（不交互、只等自然观测）。
当 τ_info 小且 T_commit 远时，VoI_def 大而 VoI_H(g) 小，应 defer；反之必须 now。

**定义 317（跨期风险预算）** 给定轨迹级风险约束 P(∃k∈[t,t+H]: failure_k) ≤ ε_H，按影响质量分配每步预算 ε_k = ε_H·κ_k / Σ_j κ_j，再反解 λ_k = Λ(ε_k)。最终
λ_t = max( λ_floor(U_ale + I_t^ub·U_epi^unres),  λ_alloc(t) )。
R69 是「ε_H = H·ε_step 且 I^ub≡1」的特例；EPOCH 只允许在 I^ub<1 处把**尚未被锁死**的那部分 epistemic 地板让渡给未来，硬地板 λ_floor 永不消失。

**定义 318（IRS 决策规则）** 每步在三个候选策略中选择：
- **now**：g* = argmax_g [VoI_H(g) − c(g)]，要求 VoI_H−c ≥ 0、g 过 C-RAS-WM 认证、TMC 通过；
- **defer**：要求 I_t^ub < I_crit 且 T_commit^ub − t > τ_info^ub + margin；登记 deadline 与失败退路；到期仍未消解则强制 now/保守；
- **conservative / abort**：不交互，λ=λ_floor(U_ale+U_epi)（即 R69），或交人。
取 argmax{J_now, J_defer, J_cons}（对应期望值）。若 defer 的后悔上界 > 0 或 T_commit 不可信，则**禁止 defer**。

**定义 319（VCR：分布式价值/VoI 批评家）** VCR 由离线数据训练，输出回报分位数 {Q_τ}、VoI 估计与不确定度。三门控：
(a) **校准门**：分位覆盖 ≥ 1−α 且 ECE ≤ τ_vcr；
(b) **悲观门**：收益取下分位、风险取上分位（禁止乐观方向）；
(c) **下界门**：VoI_VCR ≥ VoI_myopic（短视下界），否则截断到短视值。
任一门不过 ⇒ VCR 关闭，EPOCH 退化为 FLUID-RAS 的短视决策。VCR 只影响期权价值，不影响安全地板。

**定义 320（TMC：时序模态一致性）** 对候选模态 m，在窗口 W 上定义持久度 ρ_m = (1/W)Σ_i 1[nearest_mode(ξ_{t−i}) = m]，扰动稳定度 s_m = P_{δ~Δ}(采样 perturb(o_t,δ) 后 m 仍出现)，TMC(m) = ρ_m·s_m。若 TMC(m) < τ_tmc：判为幻影/瞬态，**不得作为交互对象、不得驱动 MINT**；其质量并入 U_ale 或丢弃。真实模态在时间上持续、在扰动下稳定；幻觉模态反之。

**定义 321（DLR：延迟标签离线再校准）** 事件结束或经过 τ_label 后获得延迟标签 y（真实模态、真实结果、事后可验证的交互收益）。DLR 在隔离区用 y 更新 mode_head/MCG 与 VCR：
- **标签准入**：k 源一致 + 审计 + 防投毒（ℰ_poison，定义 304）；
- **更新方式**：版本化快照 + canary + 可回滚；
- **漂移门**：若新 ECE > 旧 ECE + τ_drift，拒绝更新；
- **实时零写**：更新永不在控制环路内发生，只在下一个 episode 边界原子换装。
这把 R69 的「模态分布可信吗」从一次性假设，变成可被延迟标签持续检验的假设。

**定义 322（RCA：回顾性交互信用分配）** 对每次交互 g 计算事后信用
C(g) = E[Y | g 执行] − E[Y | g 不执行]（用日志数据 + 双稳健/逆概率加权估计），并与当时的 VoI 预测比较得校准残差 e_voi。RCA 更新 MINT 的成本先验与 DLR 的标签权重；e_voi 系统性为正（当时高估）则提高 τ_voi，反之降低。RCA 只用于离线，不参与实时控制。

**定义 323（AIC-EPOCH）** ℰ_EPOCH = ℰ_FLUID × ℰ_horizon，其中
ℰ_horizon = { 延期内 Trap（无限等待/错过 T_commit）、交互疲劳攻击（诱使系统频繁提问耗预算与社会信任）、延迟标签投毒（污染 DLR）、长程 reward hacking（用 defer 刷分）、不可逆性误估、VCR 乐观偏差 }。

**定义 324（证书 J_EPOCH）** J_EPOCH = (J_FLUID, B_H_used, defer_count, defer_regret, I_coverage, tau_info_error, TMC_false_query, DLR_drift, VCR_coverage, rca_bias, epoch_ver)。Valid ⇔ Valid(J_FLUID) ∧ 预算未越界 ∧ 所有 defer 均满足定义 318 的可撤销条件 ∧ VCR 启用时三门全过 ∧ DLR 未越漂移门。

**定义 325（分层 EPOCH 流水线）** 长 H 时不做 O(H) 全展开：用学到的子目标分解 ψ 把 [t,t+H] 切成 L 段，每段维护局部 HUT，跨段只传 (D_epi, I^ub, T_commit) 三个充分统计量；分层误差以 γ^{段长} 衰减。复杂度从 O(H) 降到 O(L)。

```python
# IP-264 HUT：长程不确定性传播（分层，O(L) 而非 O(H)）
def propagate(subgoals, kappa, gamma):
    D_epi = 0.0
    for seg in subgoals:
        D_epi += (gamma ** seg.offset) * kappa(seg) * expected_U_epi(seg)
    return D_epi

# IP-265 NVOI：即时增益 + 期权价值 − 风险；并计算押后价值
def nvoi(g, b, t, vcr, myopic_voi):
    ig   = entropy(b) - expected_entropy(b, g)          # R69 的短视 VoI
    if vcr is None or not vcr.gate_open():               # 三门不过 → 只用短视
        return ig - cost(g), None
    ov   = max(0.0, vcr.option_value(b, g))              # 期权价值，非负
    risk = vcr.risk_upper(b, g)                          # 上分位，悲观
    val  = max(myopic_voi, ig + ov - risk) - cost(g)     # 下界门：不低于短视
    return val, vcr.defer_value(b, t)                    # 押后价值

# IP-266 IRS：现在问 / 押后 / 保守（定义 318）
def decide(b, t, budget, hut, vcr, myopic_voi):
    I_ub     = hut.irreversibility_upper(b)              # 不可信 → 1.0
    tau_ub   = hut.info_half_life_upper(b)
    T_commit = hut.time_to_commitment_upper(b)
    best_g, J_now = best_information_action(b, vcr, myopic_voi)
    J_defer = None
    can_defer = (I_ub < I_CRIT and (T_commit - t) > tau_ub + MARGIN
                 and budget.can_reserve_until(T_commit))
    if can_defer:
        J_defer = vcr.defer_value(b, t) if vcr and vcr.gate_open() else None
    if best_g and J_now is not None and J_now > 0 and c_ras_wm.certify_info(best_g, b):
        if J_defer is None or J_now >= J_defer:
            return ('interact', best_g)
    if J_defer is not None and J_defer > 0:
        return ('defer', T_commit)                       # 登记 deadline
    return ('conservative', None)                        # 退回 R69

# IP-268 TMC：时间持久性 + 扰动稳定性，拦截幻影模态
def temporal_mode_consistency(mode_track, window, perturb):
    rho    = match_ratio(mode_track[-window:])
    stable = perturbation_stability(mode_track[-window:], perturb)
    return rho * stable                                  # < TAU_TMC ⇒ 不可追问

# IP-269 DLR：延迟标签离线再校准（实时零写 + 隔离 + 可回滚）
def delayed_recalibrate(buffer, quarantine, snapshot):
    labels = quarantine.verified(buffer)                 # k 源一致 + 审计
    if len(labels) < N_MIN: return snapshot
    cand = recalibrate(snapshot.mode_head, snapshot.vcr, labels)
    if cand.ece > snapshot.ece + DRIFT_TAU:              # 漂移门
        rollback(snapshot); return snapshot
    canary_deploy(cand, zero_realtime_write=True)        # episode 边界原子换装
    return cand

# IP-273 主闭环（继承 R69，插入「何时问」这一层）
def EPOCH_RAS_round(M, obs, t):
    z, o = M.mtm.forward(obs); c, U_cal, _ = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    modes = M.fmp.decompose(M.fmp.sample(o, K))
    U_ale, U_epi = M.aud.split(modes)
    # 1) 幻影过滤：不持续、不稳定的模态不得成为交互对象
    M.tmc.update(o)
    modes = [m for m in modes if M.tmc.score(m) >= TAU_TMC]
    # 2) 长程量：影响质量 / 不可逆上界 / 信息半衰期 / 到期时刻
    kappa    = M.hut.influence_mass(t, M.vista.H)
    I_ub     = M.hut.irreversibility_upper(o)            # 不可信 → 1.0
    tau_ub   = M.hut.info_half_life_upper(o)
    T_commit = M.hut.time_to_commitment_upper(o)
    myopic   = M.mint.short_voi(modes, o)                # R69 短视下界
    vcr      = M.vcr if M.vcr.gate_open() else None
    # 3) 现在问 / 押后 / 保守（R69 边界）
    action, arg = M.irs.decide(o, t, M.budget, M.hut, vcr, myopic)
    g = None
    if action == 'interact':
        g = arg
        U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    elif action == 'defer':
        M.defer.register(deadline=arg, fallback='conservative')
    # 4) 跨期风险预算 + 硬地板；I_ub=1 时完全回到 R69
    lam = max(M.risk_budget.alloc(t, kappa),
              lam_floor(U_ale + I_ub * U_epi))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    if action == 'conservative' or not M.hut.certified():
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(...))   # R69 最保守
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_epoch.submit_async(action, g, I_ub, tau_ub, T_commit, myopic)
    return k, lam, mode, (U_ale, U_epi, action)
```

## 3. 推导

**引理 19（误差复利与交互时机）** 设每步模态错误概率 p（独立近似），在 t 处消歧把 p 降为 p'。剩余 H−t 步的成功率从 (1−p)^{H−t} 升到 (1−p')^{H−t}，相对增益 ≈ (H−t)(p−p')（小 p 展开）。故**早期交互的边际价值随剩余影响质量 κ_t 增长**；但若 τ_info < T_commit−t，未来观测会免费完成同样的降 p，则现在交互的净增益为 0，最优是 defer。系：最优交互时刻 t* ≈ max(t, T_commit − τ_info)，即「在不可逆之门前一个信息半衰期处问」。

**引理 20（延期的安全条件与后悔上界）** 若 I_t^ub < I_crit 且 T_commit^ub − t > τ_info^ub + margin，则 defer 的期望后悔 ≤ ε_H·P(估计失效) + c_wait；一旦任一上界失效（T_commit 提前、τ_info 变大、I 升到 1），立即强制 now/保守，后悔不累积。反之，若 T_commit 不可信而仍 defer，后悔可无界——这正是定义 318 禁止的情形。

**引理 21（TMC 幻影过滤）** 设真模态在窗口内持久概率 ≥ ρ_T，幻影模态持久概率 ≤ ρ_H < ρ_T，则用阈值 τ_tmc∈(ρ_H,ρ_T) 的 TMC 过滤，把幻影送进交互的概率 ≤ exp(−W·D(ρ_H‖ρ_T))。系：R69 的「追问幻影」风险随观测窗口长度指数下降，代价只是少量延迟。

**引理 22（延迟标签校准）** 在平稳性下，用 N 个延迟标签做再校准，期望 ECE 以 O(√(log(1/δ)/N)) 下降；在总变差预算 Δ 的慢漂移下，跟踪误差 ≤ O(√Δ) + O(√(log(1/δ)/N))。系：DLR 的漂移门必须随 Δ 自适应，否则「校准」会追着噪声跑。

**定理 18（R69 的严格包含与安全不退化）** 在 A99（I^ub 是有效上界、VCR 三门通过或关闭、TMC 只删幻影）下，EPOCH 的期望风险 ≤ FLUID-RAS + ε_gate；且当 H=1、I^ub≡1、VCR 关闭、defer 禁用时，两者**逐指令相同**。要点：λ_t ≥ λ_floor(U_ale+I^ub U_epi) ≥ 当 I^ub=1 时恰为 R69 地板；VCR 只增加期权价值且被短视下界截断；TMC 只减少错误交互。

**定理 19（长程安全与无突变）** EPOCH 的交互/押后只改变「模态选择」与「何时选择」，不改变安全包络；跨期风险预算满足轨迹级 chance constraint；λ_t 关于 U 与 I 连续，defer→now 的切换有 margin 与 deadline 双保险；提交/换装不变式（R69 定理 15）保持 ⇒ 控制连续、无突变；任何门失败都单调退化到 R69。

## 6. 本轮最大风险

**一句话**：EPOCH 把「现在要不要问」交给了两个学出来的时间量——信息半衰期 τ_info 与不可逆指数 I；如果它们系统性乐观（低估 τ_info、低估 I 的滞后效应），系统就会把该问的问题押后到一个已经来不及的不可逆门前，而长程的误差复利会把这一次「等一等」放大成整条轨迹的失败——**R69 的危险是「问错」，R70 的危险是「该问而不问，且用学到的理由说服自己不必问」**。

**次级风险与缓解**：
1. **延期内 Trap**（无限等待/错过 T_commit）→ 硬 deadline + 到期强制 now + 引理 20 后悔上界；
2. **延迟标签投毒**（污染 DLR）→ 标签准入 + k 源一致 + 漂移门 + 可回滚快照（定义 321）；
3. **VCR 乐观偏差** → 悲观门 + 短视下界门 + 校准门，三门全过才启用（定义 319）；
4. **非平稳漂移** → 漂移门自适应 + 回滚 + 定理 18 退化保证；
5. **TMC 误删稀有真模态** → 阈值保守 + 稀有模态保留通道 + E305 专项审计；
6. **胆怯税与冒险税的两难** → 跨期风险预算显式化（定义 317），并用 E299 类 Pareto 实验标定 ε_H。

## 3. 关键算法伪代码

```python
# IP-264 HUT：长程不确定性传播（分层）
def propagate(subgoals, kappa, gamma):
    D = 0.0
    for seg in subgoals:                       # L 段，非 H 步展开
        D += (gamma ** seg.offset) * kappa(seg) * expected_U_epi(seg)
    return D

# IP-265 NVOI：即时增益 + 期权价值 − 风险；并算押后价值
def nvoi(g, b, t, vcr, myopic_voi):
    ig = entropy(b) - expected_entropy(b, g)              # R69 短视 VoI
    if vcr is None or not vcr.gate_open(): return ig - cost(g), None
    ov   = max(0.0, vcr.option_value(b, g))               # 期权价值 ≥ 0
    risk = vcr.risk_upper(b, g)                           # 上分位，悲观
    val  = max(myopic_voi, ig + ov - risk) - cost(g)      # 下界门
    return val, vcr.defer_value(b, t)

# IP-266 IRS：现在问 / 押后 / 保守
def decide(b, t, budget, hut, vcr, myopic_voi):
    I_ub     = hut.irreversibility_upper(b)               # 不可信 → 1.0
    tau_ub   = hut.info_half_life_upper(b)
    T_commit = hut.time_to_commitment_upper(b)
    g, J_now = best_information_action(b, vcr, myopic_voi)
    can_defer = (I_ub < I_CRIT and (T_commit - t) > tau_ub + MARGIN
                 and budget.can_reserve_until(T_commit))
    J_def = vcr.defer_value(b, t) if (can_defer and vcr and vcr.gate_open()) else None
    if g and J_now is not None and J_now > 0 and c_ras_wm.certify_info(g, b):
        if J_def is None or J_now >= J_def: return ('interact', g)
    if J_def is not None and J_def > 0: return ('defer', T_commit)
    return ('conservative', None)                         # 退回 R69

# IP-268 TMC：持久度 × 扰动稳定度，拦截幻影
def temporal_mode_consistency(track, window, perturb):
    return match_ratio(track[-window:]) * perturbation_stability(track[-window:], perturb)

# IP-269 DLR：延迟标签离线再校准（隔离 + 漂移门 + 可回滚）
def delayed_recalibrate(buffer, quarantine, snap):
    labels = quarantine.verified(buffer)                  # k 源一致 + 审计
    if len(labels) < N_MIN: return snap
    cand = recalibrate(snap.mode_head, snap.vcr, labels)
    if cand.ece > snap.ece + DRIFT_TAU: rollback(snap); return snap
    canary_deploy(cand, zero_realtime_write=True)         # episode 边界原子换装
    return cand

# IP-273 主闭环（继承 R69，插入「何时问」层）
def EPOCH_RAS_round(M, obs, t):

    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    modes = M.fmp.decompose(M.fmp.sample(o, K))
    U_ale, U_epi = M.aud.split(modes)
    M.tmc.update(o); modes = [m for m in modes if M.tmc.score(m) >= TAU_TMC]
    kappa    = M.hut.influence_mass(t, M.vista.H)
    I_ub     = M.hut.irreversibility_upper(o)             # 不可信 → 1.0
    tau_ub   = M.hut.info_half_life_upper(o)
    T_commit = M.hut.time_to_commitment_upper(o)
    myopic   = M.mint.short_voi(modes, o)                 # R69 短视下界
    vcr      = M.vcr if M.vcr.gate_open() else None
    action, arg = M.irs.decide(o, t, M.budget, M.hut, vcr, myopic)
    g = None
    if action == 'interact':
        g = arg; U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    elif action == 'defer':
        M.defer.register(deadline=arg, fallback='conservative')
    lam = max(M.risk_budget.alloc(t, kappa),
              lam_floor(U_ale + I_ub * U_epi))            # I_ub=1 ⇒ R69 地板
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    if action == 'conservative' or not M.hut.certified():
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(...))  # R69 最保守
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_epoch.submit_async(action, g, I_ub, tau_ub, T_commit, myopic)
    return k, lam, mode, (U_ale, U_epi, action)
```

## 4. 推导

**引理 19（误差复利与交互时机）** 每步模态错误 p、在 t 处消歧降到 p'，剩余 H−t 步成功率从 `(1−p)^{H−t}` 升到 `(1−p')^{H−t}`，相对增益 ≈ `(H−t)(p−p')`。故 VoI 随剩余影响质量 κ_t 增长；但若 τ_info < T_commit−t，未来观测免费完成同样的降 p，现在交互净增益为 0 —— 最优时刻 `t* ≈ max(t, T_commit − τ_info)`。

**引理 20（延期安全与后悔上界）** 若 `I^ub<I_crit` 且 `T_commit^ub−t > τ_info^ub+margin`，defer 后悔 ≤ `ε_H·P(估计失效)+c_wait`；任一上界失效立即强制 now/保守，后悔不累积；T_commit 不可信仍 defer 则后悔可无界（定义 318 禁止）。

**引理 21（TMC 幻影过滤）** 真模态持久 ≥ ρ_T、幻影 ≤ ρ_H<ρ_T，则阈值过滤下幻影被送入交互的概率 ≤ `exp(−W·D(ρ_H‖ρ_T))`——R69 的「追问幻影」风险随窗口指数下降。

**引理 22（延迟标签校准）** 平稳时 ECE 以 `O(√(log(1/δ)/N))` 下降；总变差 Δ 的慢漂移下跟踪误差 ≤ `O(√Δ)+O(√(log(1/δ)/N))`。系：漂移门须随 Δ 自适应。

**定理 18（R69 严格包含与安全不退化）** A99（I^ub 有效上界、VCR 三门通过或关闭、TMC 只删幻影）下，EPOCH 期望风险 ≤ FLUID-RAS + ε_gate；且 H=1、I^ub≡1、VCR 关闭、defer 禁用时**逐指令相同**。因为 λ_t ≥ λ_floor(U_ale+I^ub U_epi)（I^ub=1 即 R69 地板），VCR 只加期权价值且被短视下界截断，TMC 只减少错误交互。

**定理 19（长程安全与无突变）** 交互/押后只改变「模态选择」与「何时选择」，不改安全包络；跨期预算满足轨迹 chance constraint；λ_t 关于 U、I 连续；defer→now 有 margin+deadline 双保险；提交/换装不变式（R69 定理 15）保持 ⇒ 控制连续、无突变；任一门失败单调退化到 R69。

## 7. 本轮最大风险

**一句话**：EPOCH 把「现在要不要问」交给了两个学出来的时间量——信息半衰期 τ_info 与不可逆指数 I；如果它们系统性乐观（低估 τ_info、低估 I 的滞后效应），系统就会把该问的问题押后到一个已经来不及的不可逆门前，而长程的误差复利会把这一次「等一等」放大成整条轨迹的失败——**R69 的危险是「问错」，R70 的危险是「该问而不问，且用学到的理由说服自己不必问」**。

**次级风险与缓解**：延期内 Trap（硬 deadline + 到期强制 + 引理 20）；延迟标签投毒（标签准入 + k 源一致 + 漂移门 + 可回滚，定义 321）；VCR 乐观偏差（悲观门 + 短视下界门 + 校准门，定义 319）；非平稳漂移（漂移门自适应 + 回滚 + 定理 18 退化）；TMC 误删稀有真模态（保守阈值 + 稀有通道 + E305 审计）；胆怯税与冒险税的两难（跨期风险预算显式化 + Pareto 标定 ε_H）。
