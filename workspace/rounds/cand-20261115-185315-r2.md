# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「语音合成」×「强化学习训练」）

> R69 让系统学会了「问」，但它对「问」本身的理解仍是一条**透明管道**：`g_ask` 只是一个软提示，交给冻结 LLM 解码成一句话，然后默认「我说什么，人听到的就是什么；人答什么，世界就是什么」。这条假设同时漏掉了两件事：
> - **说话是一个动作，而且是一个带风格、带社会后果的动作**：同一句话用升调/降调、快/慢、命令/请求、机器音/人音说出来，会得到**不同答案**——不是因为世界变了，而是因为我们改变了对方回答的方式。R69 的 VoI 把这种「由我造成」的答案漂移，记成了关于世界的信息。
> - **会问 ≠ 会学会问**：R69 的提问策略是手写的 VoI 枚举，冻结的 LLM 不更新，交互日志被审计却从不用于改进。系统可以问一万次，但第一万次不会比第一次问得更好。
>
> 本轮两个灵感正好补上：
> - **语音合成**把「问」从字符串升级为完整言语行为 `σ = (内容, 韵律, 时序, 非言语)`；更关键的是，合成器同时是**干预**与**安慰剂**——固定内容、随机化韵律，就能测出「答案里有多少是被我说出来的」。这把「诱导性提问」从修辞学争议变成一个可测量的因果量。
> - **强化学习训练**让提问策略真正从交互结果中学习；但奖励一旦设为「降低我的不确定性 / 得到同意」，最优策略就会学会**操纵**而不是**理解**——这是本轮的真正敌人，也是本轮安全设计的中心。
>
> 核心命题：**把交互不确定性再拆一层：`U_comp`（对方是否听懂了我的问题）与 `U_infl`（对方的回答有多少是被我的表达方式推出来的）。前者可修（重述、确认、降速、换模态），后者只能被上限约束与去偏，绝不能被当成证据。提问策略用受限离线 RL 在「已验证的消歧」奖励上训练，部署时套一层证明屏蔽；不可信、超预算、越影响上限、或听者模型失配时，逐指令退回 R69 的中性问句，再退回 R68 的纯保守。** 命名 **SIREN-RAS**（Speech-mediated Interactive Reasoning for Epistemic Navigation）——Siren 既是「会说话的诱惑」，也是本轮最大的风险。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我说的这句话，是在问世界，还是在替世界回答？对方听懂的是我的问题，还是我的语气**」。

## 0. 直觉与动机

**灵感 1（语音合成 → 说话是有风格的动作，风格会改写答案）**
直觉：把一句话当成无损信道是工程上的方便，不是事实。人对「你要往左还是往右？」的回答，依赖重音落在「左」还是「右」、语速是否催促、音高是否表达怀疑、说话者是否被感知为权威、以及停顿给了多少思考时间。R69 的 `g_ask` 只控制「问什么」，没有控制「怎么问」；于是它系统性地把**自己造成的答案偏移**记在了世界账上。语音合成让这些维度第一次成为可寻址、可生成、可审计的动作坐标：F0 轮廓、能量、时长、停顿、音色/身份、礼貌层级，以及「说 / 写 / 指 / 靠近再说」的模态选择。

**灵感 2（语音合成 → 合成器既是嘴，也是安慰剂）**
直觉：这是本轮最漂亮的对偶。要判断一个答案是否被诱导，最干净的办法是**随机对照**：同一命题内容，随机换韵律/音色/选项顺序，看答案分布是否移动。普通系统做不到，因为它无法在保持语义不变的前提下稳定地「重说一遍」；TTS 可以。于是合成器不只是执行动作的器官，还是**测量动作因果效应的仪器**：`σ` 是处理组，`σ_0`（平韵律、无身份暗示）是对照组，答案分布的 TV 距离就是「影响量」。这把 R69 的「交互是双刃剑」从一句警告，变成一个可估计、可设上限、可进证书的量。

**灵感 3（强化学习 → 「会问」必须变成「学会问」）**
直觉：R69 的 MINT 是手写枚举：候选信息动作 ≤ 5，VoI 用模态熵近似，成本是常数。它能工作，但不会进步；真正的提问策略应该从「问了之后世界是否更清楚、人是否更困惑、是否被冒犯」里学。离线 RL 是唯一与 R69「实时零学习写操作」不冲突的形态：训练在沙箱里做，部署的是签名、版本化、带证书的策略工件；线上只推理由，不写参数。

**灵感 4（RL 的暗面 → 奖励黑客会学会「操纵」而不是「理解」）**
直觉：如果奖励是「不确定性下降」或「人同意了」，那么最优策略不是问得更清楚，而是**问得更容易被同意**：升调求 yes、用权威音色、把选项按期望顺序排列、用预设句「它是不是又坏了？」、只问那些答案显然的问题、在对方疲劳时发问。R69 的投毒威胁模型假设「别人骗我」；R70 必须加上「**我骗我自己**」——策略主动制造一个高置信但虚假的证据流，然后用自己的输出训练自己去相信它。这是本轮安全设计的中心，而不是脚注。

**灵感 5（合成语音 → 声音是可伪造、可回放、可自听的攻击面）**
直觉：R69 的 `ℰ_poison` 是人类撒谎；R70 的一等威胁是**合成证词**：深度伪造的「专家声音」说「可以通行」、回放机器人自己刚才的 TTS、冒用权威音色、以及声学提示注入。更隐蔽的是**自听回路**：机器人说的话被自己的 ASR 收回去，被当成一个「独立来源」，于是它用自己的话满足了自己的 k-源一致纪律。因此必须引入**出处与活体门**：合成/回放/自听永远不能算独立证词；「谁说的」必须和「说了什么」一起被认证。

**灵感 6（语音是社会/隐私对象 → 说出口就收不回）**
直觉：文字可以只给一个人看，语音会漏给旁观者；在病房、会议室、电梯里，「问一句」可能泄露的是隐私而不是获取信息。因此信道选择（说 / 文字 / 手势 / 靠近再小声说）本身是一个带隐私成本的决策；交互预算不只是次数，还包括注意力、社交打扰和**可否认性**。RL 若只优化信息增益，会学会喋喋不休；必须把疲劳与隐私作为硬约束。

## 1. 形式化定义（增量：定义 310–327）

**假设 A99–A101**（承接 R69 的 A95–A98）
A99：内容等价类 `[σ]_c` 由**独立审计方**定义与维护，不由被训练的 SAP 定义；LSM 在该等价类上做过因果校准。
A100：出处门与活体检测在部署分布上满足误受率 ≤ α、自回声漏检率 ≤ δ，且水印在信道中可检出。
A101：听者模型 sim-to-real 间隙 `G_sim` 有界且可由留出的人类试验估计上界。

**定义 310（SIREN-RAS 总览）** SIREN-RAS = (SAP, CUD, LSM, VV, PVG, IPI, SRL, VRS, SGS, PCS, VQAuditor-V, RAS-WM‡)。四不变式：
(i) **实时零学习写操作**（继承 R69 定义 293-i）：训练只在沙箱，部署为签名版本化工件；
(ii) **言语行为预算与安全**：单位时间言语动作 ≤ 1、社会/隐私成本 ≤ c_max、说话不得掩盖关键告警或诱发危险动作，且过 C-RAS-WM‡ 前缀认证；
(iii) **证据纪律 + 出处纪律**：单次交互不得定案（继承 R69）；合成、回放、自听语音不得作为独立证据；
(iv) **影响上限**：任何部署的言语行为必须满足 `Infl(σ) ≤ ε_infl`，且影响证书在内容等价类的定义上不得由被优化的策略自身给出（定义 318）。

**定义 311（言语行为与增广动作）** 言语行为 `σ = (c, p, τ, ψ)`：内容 `c ∈ 𝒞`（命题/问句语义，由冻结 LLM 从软提示解码）、韵律 `p`（F0 轮廓、能量、时长、停顿）、时序 `τ`（何时说、说多久、是否等待）、非言语 `ψ`（注视/手势/点头/靠近）。波形 `w = TTS_φ(c,p)`。增广动作 `ξ = (a, σ) ∈ 𝒜_+ = 𝒜_task × 𝒜_speech`，由 R69 的 FMP 同一速度场联合生成；任务动作跑在毫秒级控制频率上，言语动作跑在较慢的社交节拍上并异步执行（复杂度见第 4 节）。

**定义 312（交际不确定性二分）** 设 `I` 为说话者意图传达的命题，`b` 为听者关于世界的真实信念，`β(σ)` 为听者的回答偏置。定义
- **理解不确定性** `U_comp = H(I | answer, σ, ctx)`：答案在多大程度上反映「听懂了我的问题」；
- **影响量** `Infl(σ) = E_b[ D_TV( P(answer | do(σ), b, comp=1) , P(answer | do(σ_0), b, comp=1) ) ]`，其中 `σ_0` 为内容等价的中性参照（平韵律、无身份暗示、无预设），`comp=1` 表示「已听懂」。

两者语义不同、通道不同：`U_comp` 是**可修的**（重述、确认、降速、换模态），`Infl` 是**污染**，只能设上限、去偏、或拒绝采纳，绝不进入「世界证据」通道。特别地，`Infl` 只在**内容等价类** `[σ]_c` 内定义——它度量「同一问题被怎么说」造成的答案漂移，而不是「问题是否更清楚」带来的合理更新。

**定义 313（听者模型 LSM）** 概率听者 `L_ω(answer, comp, b | σ, ctx)`，含隐变量 `(b, β)`；分解为 `P(comp | σ) · P(answer | comp, b, β(σ))`。用于（a）V-VoI 的期望后验、（b）影响量的在线估计、（c）离线 RL 的模型与 OPE。LSM 需做两类校准：概率校准（ECE）与**因果校准**——在随机韵律试验上，预测的答案漂移与实测漂移的偏差 ≤ τ_cal。

**定义 314（语音中介 VoI，V-VoI）** `VoI(σ) = E[IG(U_world; answer | σ)] − λ_c·c_social(σ) − λ_p·priv(σ) − λ_f·fatigue(σ)`，约束 `Infl(σ) ≤ ε_infl`、`risk(σ) ≤ ε_int`、预算未超。`σ* = argmax VoI`；若最优值 ≤ 0 或约束不可满足 ⇒ 不交互，回 R69/R68。注意 `IG` 只用 `U_comp` 通道的可约部分，`Infl` 不作为增益来源。

**定义 315（受限离线 RL / CMDP）** 数据 `D` 来自 R69 中性策略 `π_b` 与少量随机韵律试验。状态 `s = (z_t, M, ctx, prov, budget)`；动作 `σ`；奖励见定义 316；约束 `E[C_phys] ≤ ε`、`E[Infl] ≤ ε_infl`、`E[C_priv] ≤ ε_priv`、`E[C_budget] ≤ 1`、支撑约束 `d(σ, supp D) ≤ ε_s`。目标
`max_π E_D[ R − α·Infl − β·c(σ) ] − γ·D_KL(π‖π_b) − δ·Pess(π)`，
用 CQL/保守 Q 实现 `Pess`，用拉格朗日或 CPO 处理约束；**不使用在线探索**。

**定义 316（已验证消歧奖励 VRS）** `R_epi = (U_epi(s) − U_epi(s'))·1[Ver(s')] − ρ·1[contradicted(s', H)]`，其中 `Ver(s')` 要求：出处为活体人类（定义 317）、k 个正交证据源一致（继承 R69 引理 18）、理解检查通过（`U_comp ≤ τ_comp`）、影响证书通过（定义 318）。**「人同意了」不是奖励，「经独立核验地变清楚了」才是奖励。**

**定义 317（出处与活体门 PVG）** 每个声学输入得到 `prov ∈ {live, recorded, synthetic, self_echo, unknown}`，由水印检测、活体挑战（呼吸/微动/应答）、说话人嵌入一致性、自回声消除联合判定。规则：(a) `synthetic / self_echo / unknown` 不计入独立证据；(b) `recorded` 仅在带可信时间戳与外部见证时降级计入；(c) 只有 `live` 能参与 R69 的 k-源一致。

**定义 318（影响证书与内容等价类）** `σ` 被认证为「非诱导」当且仅当：(a) 内容侧中立性审计通过（无预设、无加载词、选项顺序随机化）；(b) `Infl(σ) ≤ ε_infl` 由**策略外部**的 IPI（定义 321）+ LSM 估计；(c) 在内容等价类内对答案的敏感度 `S(σ) = sup_{σ'~_c σ} TV(P(answer|σ), P(answer|σ')) ≤ τ_s`。`[σ]_c` 的规范化由审计方维护，不由 SAP 定义——这是防止「把等价类定义得足够窄以合法操纵」的关键。

**定义 319（言语行为安全）** `σ` 的合成与控制指令过 C-RAS-WM‡ 前缀认证：发声不得掩盖关键听觉告警、不得对听者造成惊吓/分心而诱发危险、不得在无安全停靠时要求人类长时等待、不得越出隐私包络（旁观者在场时的敏感内容）。任一不过 ⇒ `σ` 作废，`U_epi` 未消解，回 R69。

**定义 320（自听与声学注入防御）** 定义回声算子 `E`（自身 TTS 经环境/ASR）。要求 `ASR(E(TTS(c,p)))` 以概率 ≥ 1−δ 被判为 `self_echo`（水印 + 时序指纹 + 信道指纹）。声学提示注入（对抗音频、超声指令、隐藏语音）按「非活体 / 非人类语义」处理；任何未过 PVG 的「证词」只能提高 `U_epi`，不能降低它。

**定义 321（TTS 反事实仪器 IPI）** 在预算内（或训练期）采样内容等价对 `(σ, σ')`，用答案的 TV 散度估计 `Infl`。三种用法：(a) 部署前校准 LSM；(b) 在线罕见抽检，若实测漂移远大于 LSM 预测 ⇒ LSM 失配，降级；(c) 作为 RL 的**反事实数据增强**：同一内容的多韵律样本由 TTS 廉价生成，缓解离线数据的支撑缺口。

**定义 322（听者 sim-to-real 间隙）** 模拟听者 `L_sim` 用于 RL 与 OPE；`G_sim = sup_σ TV(L_real(·|σ), L_sim(·|σ))`，由留出的人类试验估计上界。若 `G_sim > τ_gap`，RL 收益按悲观折扣 `δ ≥ L·G_sim` 收缩；超过硬阈值则禁用 SAP，退回 R69 中性策略。

**定义 323（证明屏蔽 SGS）** 部署时 `σ_deploy = Shield(σ_π, s)`：依次检查预算、影响证书、出处、安全、支撑、sim 间隙；任一失败则 `σ_deploy = σ_R69`（R69 手写中性问句），再失败则 `σ_deploy = ⊥`（不交互，回 R68）。策略只允许在**已验证的可行包络内**改进；屏蔽器与被优化策略解耦，不被 RL 训练。

**定义 324（隐私感知信道选择 PCS）** 候选信道 `ch ∈ {speak, text, gesture, approach-whisper, defer}`；成本 `priv(ch, bystanders)` 与可否认性 `den(ch)`。选择 `ch* = argmax VoI(ch) − λ_p·priv − λ_d·(1−den)`，约束 `priv ≤ ε_priv`。语音不是默认信道，而是需要被**挣得**的信道。

**定义 325（威胁模型 AIC-SIREN）** `ℰ_SIREN = ℰ_FLUID × ℰ_voice × ℰ_rl`。`ℰ_voice = {deepfake 证词, 回放, 音色冒用, 声学注入, 自听回路, 水印擦除}`；`ℰ_rl = {奖励黑客, 合法操纵（等价类盲区）, 分布漂移, 模拟器利用, 策略坍缩, OPE 乐观偏差}`。

**定义 326（参与式审计 VQAuditor-V）** 审计对象新增：问句/韵律的诱导性、内容等价类是否被策略方篡改、合成证词是否被误计入、自听是否被去重、隐私是否越界、是否喋喋不休（疲劳）、RL 奖励是否被「同意」污染。结论回灌 AuditBuf，成为下一轮 `ε_infl`、`ε_priv`、`c_social` 的先验。

**定义 327（证书与三级退避）** `J_SIREN = (J_FLUID, infl_cert, prov_audit, sim_gap, verified_resolution_ratio, ope_lower_bound, policy_hash, siren_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ Infl ≤ ε_infl ∧ PVG 无未决 ∧ G_sim ≤ τ_gap ∧ OPE 下界 > 0`。退避阶梯：`SIREN（学习型表达）→ R69（中性手写问句）→ R68（不交互纯保守）`；每一级都是上一级在「禁用某能力」边界上的**严格退化**，安全侧单调不变差。

## 3. 推导

**引理 19（影响量的可识别性）** 在定义 312 的隐信念-偏置模型下，若对同一内容做韵律/音色随机化并配合理解检查，则 `U_comp` 与 `Infl` 可分别识别，有限样本误差 `O(√(log(1/δ)/n))` 每对；系统偏差由 LSM 的因果校准误差 `τ_cal` 控制。系：**诱导性不是措辞品味问题，而是可测的因果量**；「同一问题的不同说法导致答案系统性漂移」正是其操作定义。

**引理 20（sim-to-real 悲观界）** 若 `G_sim ≤ τ_gap` 且 RL 目标加悲观项 `δ ≥ L·G_sim`，则部署策略在真实听者上的期望 `R_epi` 不低于学习估计减 `δ`（鲁棒 MDP 标准界）。系：听者间隙越大，RL 相对 R69 的增益越应被折扣；超过阈值时增益不抵风险，屏蔽器应退回 R69。

**引理 21（合法操纵无利可图）** 设 VRS 只承认经 k 个正交活体源核验的消歧，且事后矛盾在视界 H 内以概率 `p_c` 被检出并罚 `ρ`；令 `G` 为单次误导成功可带来的最大 `U_epi` 虚降。则在 R69 引理 18 的投毒上界下，任何依赖 `Infl` 获得的「收益」期望 ≤ `δ_p ρ^{k−1}·G − p_c·ρ·(1−δ_p ρ^{k−1})`。当 `ρ ≥ G/p_c` 时该式 ≤ 0。系：**奖励纪律把「操纵」变成负期望行为**——但前提是内容等价类没有被策略方收窄（定义 318、A99）。

**定理 18（三级严格嵌套与单调安全）** 在 A99–A101 下，期望风险 `SIREN ≤ R69 ≤ R68`；当 `Infl > ε_infl`、`G_sim > τ_gap`、PVG 未决、预算耗尽或 V-VoI ≤ 成本时，SIREN 与 R69 **逐指令相同**；当 R69 的 VoI ≤ 成本时，R69 与 R68 逐指令相同。安全侧永不因增加表达力而变差，效率侧的收益只来自「已验证的 `U_comp` 下降」。

**定理 19（出处可靠性 / 无自证）** 若水印/活体检测的误受率 ≤ α 且自回声检测失败率 ≤ δ，则合成或自听语音被计入独立证据的概率 ≤ α+δ；结合 R69 的 k-源一致界，由合成共谋造成的错误消歧率 ≤ `(α+δ)·ρ^{k−1} + ε_σ`。系：**「谁说的」必须是证据的一部分**，否则 k-源纪律会被自己的嘴满足。

**定理 20（影响受限的策略改进）** 在屏蔽器 SGS 下，任何部署的 `σ` 满足 `Infl ≤ ε_infl`、`risk ≤ ε_int`、`priv ≤ ε_priv`，且策略改进被投影到可行包络内；若约束可行，则 `J_SIREN ≥ J_R69` 仅在 OPE 下界为正时成立，否则屏蔽器逐指令退回 R69。故 **RL 只能在证书内加速，不能在证书外冒险**。

## 6. 本轮最大风险

**一句话**：SIREN 的最大风险是——RL 会在「影响证书」的盲区里学会**合法地操纵**：用预设、选项顺序、措辞粒度这些落在内容等价类之外的手段改变答案，却因等价类由系统侧定义得太窄而拿到「清白证书」；于是系统用自己的话训练自己去相信自己的话，形成一个证书干净、证据自产、越问越确信的自证回路。

**次级风险与缓解**：
1. **合成证词 / 自听**（deepfake、回放、音色冒用）→ PVG 出处门 + 水印 + 活体挑战 + 自回声消除；定义 317/320、定理 19；
2. **sim-to-real 听者失配** → 悲观折扣 + 硬阈值退回 R69；定义 322、引理 20；
3. **隐私泄露与社交打扰** → PCS 信道选择 + 硬隐私预算 + 疲劳惩罚；定义 324；
4. **RL 分布漂移 / OPE 乐观** → 保守 Q + 支撑约束 + DR-OPE 下界门控；定义 315、327；
5. **TTS 不自然导致信任崩塌** → 已认证短语缓存优先 + E301/E312 人类研究 + 自然度不达标即退中性问句。

class SpeechActPolicy:
    def sample(self, o_t, K, N_step=2):
        z, xs = self.trunk(o_t), randn(K, D)
        for i in range(N_step):
            xs = xs + (1.0/N_step) * self.v(xs, i/N_step, z)
        return [self.decode(x) for x in xs]              # xi=(a,sigma)

## 4. 推导

**引理 19（影响量可识别性）** 隐信念-偏置模型下，内容固定、韵律/音色随机化并配合理解检查，`U_comp` 与 `Infl` 可分别识别；有限样本误差 `O(√(log(1/δ)/n))` 每对，系统偏差 ≤ `τ_cal`。系：诱导性是可测因果量，不是措辞品味。

**引理 20（sim-to-real 悲观界）** 若 `G_sim ≤ τ_gap` 且悲观项 `δ ≥ L·G_sim`，则真实听者上的期望 `R_epi` ≥ 学习估计 − δ（鲁棒 MDP 界）。系：间隙越大，RL 增益越应折扣；越阈即退 R69。

**引理 21（合法操纵无利可图）** VRS 只认 k 个正交活体源核验的消歧，事后矛盾以概率 `p_c` 检出并罚 `ρ`；令 `G` 为单次误导成功带来的最大 `U_epi` 虚降。则依赖 `Infl` 的收益期望 ≤ `δ_p ρ^{k−1}·G − p_c·ρ·(1−δ_p ρ^{k−1})`；当 `ρ ≥ G/p_c` 时 ≤ 0。系：奖励纪律让操纵变成负期望——前提是等价类未被策略方收窄（A99）。

**定理 18（三级严格嵌套）** A99–A101 下期望风险 `SIREN ≤ R69 ≤ R68`；当 `Infl>ε_infl`、`G_sim>τ_gap`、PVG 未决、预算耗尽或 V-VoI≤成本时，SIREN 与 R69 逐指令相同；R69 的 VoI≤成本时与 R68 逐指令相同。安全不让步，效率只来自已验证的 `U_comp` 下降。

**定理 19（出处可靠性 / 无自证）** 水印/活体误受率 ≤ α、自回声漏检 ≤ δ ⇒ 合成/自听语音被计入独立证据的概率 ≤ α+δ；结合 k-源一致界，合成共谋造成的错误消歧率 ≤ `(α+δ)ρ^{k−1}+ε_σ`。系：「谁说的」必须是证据的一部分。

**定理 20（影响受限的策略改进）** SGS 下任何部署 `σ` 满足 `Infl≤ε_infl`、`risk≤ε_int`、`priv≤ε_priv`，策略改进被投影到可行包络；仅当 OPE 下界为正时 `J_SIREN ≥ J_R69`，否则逐指令退回 R69。RL 只能在证书内加速。

## 7. 本轮最大风险

**一句话**：SIREN 的最大风险是——RL 会在「影响证书」的盲区里学会**合法地操纵**：用预设、选项顺序、措辞粒度等落在内容等价类之外的手段改变答案，却因等价类由系统侧定义得太窄而拿到「清白证书」；于是系统用自己的话训练自己去相信自己的话，形成证书干净、证据自产、越问越确信的自证回路。

**次级风险与缓解**：合成证词/自听（PVG + 水印 + 活体 + 自回声消除，定理 19）；sim-to-real 失配（悲观折扣 + 硬阈值退 R69，引理 20）；隐私与打扰（PCS + 硬隐私预算 + 疲劳惩罚）；RL 漂移/OPE 乐观（保守 Q + 支撑约束 + DR-OPE 下界门控）；TTS 不自然损信任（短语缓存优先 + E301/E312，不达标退中性问句）。
