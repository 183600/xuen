# 第 67 轮（承接第 66 轮「RAS 情绪驱动闭环」IP-224~233；灵感循环第 4 轮；本轮灵感：「放置」×「语义分割」）

> 第 66 轮 RAS 把「被动故障响应闭环」升级为「主动意图感知闭环」，但它仍把一个关键量当作免费输入：**安全区域本身**。RAS 会问「谁该控制、控制多少」，会缩放力限与几何容差，却默认「哪里可以放」是一个已经算好的几何自由空间。真实操作里，绝大多数致命放置错误不是碰撞，而是**语义错位**：杯子放在桌沿、刀具落进走道、清洁剂放进餐具篮、手伸进正在沸腾的锅上方。度量自由空间是必要条件，远不是充分条件。
>
> 语义分割恰好提供了逐像素的区域含义，但**分割概率图不是证书**：它在类别边界上系统性含糊，在透明物体、液体、反光、未知纹理上会「自信地错」。放置则把语义与度量动作姿态绑定在一起，是检验「语义是否可信」的最锋利探针。
>
> 本轮核心命题：
>
> **把「意图闭环」升级为「语义放置闭环」：SPACE（Semantic Placement-Aware Certified Execution）——把语义分割当作一等故障源，把放置看作语义适宜场上的受约束搜索，并让每一个候选放置携带一张证书；该证书只有在分割裕度、几何稳定裕度、里程-语义一致性与 RAS 风险缩放同时成立时才有效。**
>
> SPACE 问的不是「谁控制、控制多少」，而是：「**把它放在哪里既合语义、又几何稳定，并且能从像素出发给出证明？**」它把「放置」从一个自由空间点，升级为一个**带证书的语义槽位（certified semantic slot）**。

## 0. 直觉与动机

**灵感 1（放置 → 从 free-space 选点，到 semantic-slot 选择）**
直觉：经典放置规划在 SE(3) 里采自由位姿，靠碰撞检测剔除。但桌面重排的失败模式很少是「穿模」，更多是「放对了空间、放错了类别」——把易碎品放到悬空边缘、把湿垃圾放到纸盒上、把工具放进食品区。几何自由空间因此是**必要但不充分**的。
语义分割把场景变成一张区域标签格：台面、容器内部、地面、行人、易碎、液体、禁放、未知。放置于是变成「在语义槽位集合里选一个」：支撑面槽 `P_support`、容器槽 `P_container`、禁放槽 `P_forbidden`。槽位是**语义与度量的联合对象**，不是像素标签，也不是纯几何体。

**灵感 2（语义分割 → 它不是标签图，而是「边界 + 后验」两个场）**
直觉：把 `argmax` 标签图直接喂给规划器，等于把最危险的信息（边界不确定性、后验置信度）丢掉了。SPACE 只接受两个场：
- 逐像素类别后验 `s_t(u) ∈ Δ^C`，及其 top-1 标签 `ℓ_t(u)`、top-2 裕度 `m_t(u) = s_(1) - s_(2)`；
- 逐像素到最近类别边界的距离场 `δ_t(u)`。
关键洞察是：**分割误差是沿边界空间相关的**。同样面积的两个放置足迹，一个深入区域内部、一个横跨边界，语义风险可以差一个数量级。因此放置必须「边界感知」，而不是「面积感知」。

**灵感 3（放置 × 语义分割 → 最小式放置适宜场 PSF）**
直觉：一个放置只有在其**最弱约束**成立时才安全。用「加权求和」打分会把「支撑极好、但悬在禁放区上方」的位姿算成高分，这正好是最危险的错。SPACE 采用**最小式聚合**：
`Φ_o(p) = min_{g∈G} φ_g(o,p)`，`G = {支撑, 稳定, 容纳, 间隙, 可达, 语义-度量一致}`。
`φ_g = 1` 表示理想，`φ_g = 0` 表示恰在约束边界，`φ_g < 0` 表示已违反。最小式给出一个保守、可证伪的谓词：`Φ_o(p) ≥ ε_Φ` 当且仅当全部约束同时成立。语义风险 `R_seg` 作为与 `Φ` 正交的第二根轴单独认证，以便后续归因区分「几何没放稳」和「语义看错了」。

**灵感 4（故障归因 → 放置失败的五种来源）**
直觉：一次放置失败（滑移、倾倒、穿透、擦碰、最终位姿偏离）可能是：
- `H_seg`：语义标错（把玻璃盖当成台面）；
- `H_bound`：边界/遮挡导致足印跨类；
- `H_depth`：深度/标定误差让像素距离失真；
- `H_afford`：适宜模型错（该物体其实不能叠放）；
- `H_dyn`：场景在规划与执行之间变了（有人把杯子推走）。
这些故障**高度混淆**：透明物体引发的「稳定性失败」看起来是物理问题，实则是语义+深度共因。SFA（Semantic Fault Attribution）把放置残差与分割裕度一起放进签名，并显式建模共因潜变量 `Z`（透明、反光、可变形、被遮挡、对抗纹理）。区分「我分割错了」与「我物理模型错了」决定了下一步是**再去看一眼（PAP）**还是**重新规划几何**——这是 RAS 的「故障可归因」在语义-度量界面的自然延伸。

**灵感 5（主动闭环 → 先看再放，放前验证，不确定就拒绝）**
直觉：当 `R_seg(p*)` 偏高时，SPACE 不赌，而是执行**放置感知主动感知 PAP**：在候选视角/微探针中选一个，使「足印标签」的期望信息增益/成本最大；只有语义裕度达标才提交。若探针预算耗尽仍不达标，退化为**已知安全回退**（放入标定过的安全箱 / 交还人类 / 保持悬停），绝不「先放了再说」。这与 RAS 的 `face_unobservable ⇒ λ_risk ≥ 0.8` 完全同构，只是在语义层重述为：**语义不可观测 ⇒ 拒绝在不确定区域放置**。

**灵感 6（与 VISTA/RAS 的三元接口）**
直觉：VISTA 管「怎么动、坏了哪一层」，RAS 管「该不该动、动多少」，SPACE 补上「**放在哪里**」。三者构成一个闭环三元组：
`是否该动 (RAS) × 哪里能放 (SPACE) × 怎么动 (VISTA)`。
退化链必须单调：完整 SPACE → RAS + 安全箱 → VISTA 保持。信息越少，证书越保守，但**永远不允许在无效证书下执行放置**。

## 1. 形式化定义（增量：定义 245–262）

- **定义 245（SPACE 总览）** `SPACE = (SEG, SAF, PSF, SPC, SFA, PAP, SPS, SBF)`，分别为语义证据网关、语义适宜场、放置适宜场、语义放置证书、语义故障归因、放置感知主动感知、放置闭环状态机、安全回退。不变式：分割后验、PSF、证书、归因只在语义流；实时流只允许足印 ROI 变换、裕度查表、失败早停，零学习写操作。
- **定义 246（语义后验与边界场）** 分割器 `f_seg` 把 RGB-D 观测 `(I_t, D_t)` 映射为逐像素后验 `s_t : Ω → Δ^C`。记 `ℓ_t(u)=argmax_c s_t(u)`，top-2 裕度 `m_t(u)=s_(1)(u)-s_(2)(u) ∈ [0,1]`，边界距离 `δ_t(u)=dist(u, ∂ℓ_t)`（像素）。
- **定义 247（放置查询与槽位）** 放置查询 `p=(x, R, o)`，其中 `o` 为物体类别、`(x,R) ∈ SE(3)`。槽位集 `P = P_support ∪ P_container ∪ P_forbidden`。每个槽位带允许标签集 `A_o`（物体 `o` 可接触的语义类别）。
- **定义 248（足印语义风险）** 物体在 `p` 处的足印 `F_o(p)=π_p(o) ⊆ Ω`。定义
  `u_m = 1 - min_{u∈F} m_t(u)`，`u_δ = exp(-δ_min/δ0)`，`δ_min = min_{u∈F} δ_t(u)`，
  `comp = 1[∀u∈F: ℓ_t(u) ∈ A_o]`，
  `R_seg(o,p) = 1 - (1-u_m)(1-u_δ)·comp ∈ [0,1]`。
  一旦足印触到不允许类别，`R_seg=1`；裕度越大、离边界越远，风险越低。
- **定义 249（最小式放置适宜场 PSF）** 对几何/物理约束 `G={support, stability, containment, clearance, reach, metric}`，定义归一化裕度 `φ_g(o,p) ∈ (-∞,1]`（`<0` 表示违反）。放置适宜场
  `Φ_o(p) = min_{g∈G} φ_g(o,p)`；可行集 `P_adm = {p : Φ_o(p) ≥ ε_Φ ∧ R_seg(o,p) ≤ τ_seg}`。
- **定义 250（关键几何裕度）**
  `φ_support = d(contact_o(p), ∂R_support)/r_o`（接触点集到支撑区域边界的带符号距离）；
  `φ_stability = (r_sup - d(CoM⊥, ∂P_sup))/r_o`（质心投影到支撑多边形边界的余量）；
  `φ_containment = min_{v∈∂o} d(v, ∂R_container)/r_o`；
  `φ_clearance = (d_min - r_o)/r_o`（足印到禁放区/动态障碍的最小距离）；
  `φ_reach = (d_max - d_ee)/d_max`（末端可达余量）。
- **定义 251（语义-度量一致性裕度）** `φ_metric = 1 - |d_metric(u) - d_pixel→metric(u)|/d0` 在边界邻域上取最小值；用于捕获深度与分割边界不一致（透明/反光/斜面）。
- **定义 252（语义放置证书 SPC）**
  `J_SPC = (J_RAS, p*, Φ_o(p*), R_seg(o,p*), support_set, label_hash, seg_version, active_views, spc_ver)`。
  `Valid(J_SPC) ⇔ Valid(J_RAS) ∧ Φ_o(p*) ≥ ε_Φ ∧ R_seg(o,p*) ≤ τ_seg ∧ φ_metric(p*) ≥ ε_metric`。
- **定义 253（语义故障假设集）** `H_SPC = H_RAS ∪ {H_seg, H_bound, H_depth, H_afford, H_dyn, H_ok}`。语义签名 `σ_t = (r_place, R_seg, m-profile, δ-profile, depth_residual, seg_version_drift)`。
- **定义 254（放置残差）** `r_place = (‖p_final - p*‖, slip, topple, penetration, near_miss)`，即最终位姿偏差、滑移距离、倾倒角、穿透深度、最小擦碰余量。
- **定义 255（SFA 联合归因）** 引入共因潜变量 `Z ∈ {透明, 反光, 可变形, 被遮挡, 对抗纹理, 无}`：
  `P(H, Z | σ, ρ) ∝ p(σ | H, Z) · p(ρ | H, Z) · P(H) · P(Z)`。
  当 `Z` 不可直接观测时，用透明/液体/可变形检测器或主动探针给 `P(Z)` 一个可更新的先验，避免把共因误拆成两个独立故障。
- **定义 256（放置感知主动感知 PAP）** 候选视角/微动作集 `V`，下一次观测选择
  `v* = argmax_{v∈V} I(L_{F_o(p)}; y_v | s_t, D_t) / E_cost(v)`，
  且该视角运动必须通过 RAS 的运动证书。停止条件：`R_seg ≤ τ_seg` 或 PAP 预算 `B_pap` 耗尽。
- **定义 257（语义认证前缀 C-SPC）** 沿接近-放置轨迹切成动作块 `A_1..A_m`。语义前缀
  `k_seg = max{k : ∀s≤k, max_{u∈F_o(A_s)} R_seg ≤ τ_seg}`，
  `k*SPC = min(k_RAS, k_seg, m_seg)`。靠近过程也认证，因为物体在接近时可能扫过禁放区。
- **定义 258（放置闭环状态机 SPS）**
  `感知 → 分割 → SAF/PSF → 提槽 → 认证 → (必要时) PAP → 受护接近/放置 → 观测残差 → SFA → 更新/回退`。
- **定义 259（安全回退 SBF）** 若无可行 `p*`，回退集 `F = {hold, safe_bin, handover}`，按期望风险取 `argmin`。**禁止在无效证书下执行放置**；`safe_bin` 必须是标定过的、语义已知的容器。
- **定义 260（退化链与单调性）** 记证书序 `SPACE ≻ RAS+safe_bin ≻ VISTA_hold`。若 `R_seg ≡ 0`，SPACE 退化为 RAS 风险缩放下的度量放置；若语义不可观测，SPACE 退化为安全箱回退；沿退化链，允许行为集单调收缩。
- **定义 261（语义适宜场 SAF）** `SAF_t(o) = {(u, ℓ_t(u), m_t(u), δ_t(u), D_t(u)) : u∈Ω}`，是 PSF、SFA、PAP 共享的只读证据表；证书用 `label_hash` 与 `seg_version` 绑定，防止执行期被静默改写。
- **定义 262（放置效用与目标）** `U_o(p)` 为任务效用（如美观、可达、后续可抓取）。SPACE 目标：
  `max_p U_o(p) s.t. Valid(J_SPC(p))`；失败时最小化 `E[risk | F]`。

## 2. 关键算法骨架

class SemanticPlacementGateway:
    def __init__(self, tau_seg=0.25, eps_phi=0.10, delta0=8.0, eps_metric=0.2):
        self.tau_seg, self.eps_phi = tau_seg, eps_phi
        self.delta0, self.eps_metric = delta0, eps_metric

    def observe(self, rgb, depth):
        s = segment(rgb)                         # (C,H,W) 后验
        top2 = s.topk(2, dim=0).values
        l = top2.new_tensor(s.argmax(0))         # (H,W) 标签
        m = top2[0] - top2[1]                    # top-2 裕度
        delta = boundary_distance(l)             # 到最近类边界像素距离
        return {'s': s, 'l': l, 'm': m, 'delta': delta,
                'metric': depth_to_metric(depth), 'version': version_hash(s)}


class PlacementSuitabilityField:
    def semantic_risk(self, seg, footprint, A_o):
        ys, xs = footprint.nonzero(as_tuple=True)
        if ys.numel() == 0:
            return 1.0
        u_m = 1.0 - float(seg['m'][ys, xs].min())
        d_min = float(seg['delta'][ys, xs].min())
        u_d = math.exp(-d_min / self.delta0)
        compatible = all(int(c) in A_o for c in seg['l'][ys, xs])
        if not compatible:
            return 1.0
        return 1.0 - (1.0 - u_m) * (1.0 - u_d)

    def phi(self, o, p, seg):
        d_sup = signed_dist(contact_points(o, p), support_boundary(seg, o))
        phi_support = d_sup / r_o(o)
        phi_stability = (r_support(o, p, seg) - d_com(o, p)) / r_o(o)
        phi_contain = min_vertex_dist(o, p, container_interior(seg, o)) / r_o(o)
        phi_clear = (min_clearance(o, p, seg) - r_o(o)) / r_o(o)
        phi_reach = (d_max - end_effector_dist(p)) / d_max
        phi_metric = metric_consistency(seg, footprint(o, p), o)
        return min(phi_support, phi_stability, phi_contain,
                   phi_clear, phi_reach, phi_metric)

    def best(self, o, candidates, seg, A_o):
        best = None
        for p in candidates:
            F = footprint(o, p)
            R = self.semantic_risk(seg, F, A_o)
            if R > self.tau_seg:
                continue
            phi = self.phi(o, p, seg)
            if phi < self.eps_phi or metric_consistency(seg, F, o) < self.eps_metric:
                continue
            key = (task_utility(o, p), -R)
            if best is None or key > best[0]:
                best = (key, p, phi, R)
        return None if best is None else best[1:]


class SemanticFaultAttribution:
    H = ['H_seg', 'H_bound', 'H_depth', 'H_afford', 'H_dyn', 'H_ok']
    def posterior(self, sigma, rho):
        post = {}
        for h in self.H:
            post[h] = self.p_sigma[h](sigma) * self.p_rho[h](rho) * self.prior[h]
        return normalize(post)


class PlacementAwarePerception:
    def next_view(self, seg, footprint, views, ras):
        best, best_gain = None, 0.0
        for v in views:
            if not ras.certifies_motion(v):
                continue
            gain = mutual_information(footprint, v, seg) / view_cost(v)
            if gain > best_gain:
                best, best_gain = v, gain
        return best


def SPACE_round(M, obs, o, goal):
    rgb, depth = obs
    seg = M.seg_gateway.observe(rgb, depth)
    cands = M.slots.propose(seg, o, goal)
    p_star, phi, R = M.psf.best(o, cands, seg, M.A[o])

    views = 0
    while (p_star is None or R > M.tau_seg) and views < M.max_views:
        v = M.pap.next_view(seg, footprint(o, p_star), M.view_set, M.ras)
        if v is None:
            break
        rgb, depth = M.move_and_capture(v)      # 运动由 RAS 认证
        seg = M.seg_gateway.observe(rgb, depth)
        cands = M.slots.propose(seg, o, goal)
        p_star, phi, R = M.psf.best(o, cands, seg, M.A[o])
        views += 1

    if p_star is None or R > M.tau_seg:
        return M.sbf.choose(o, seg), None, {'reason': 'no_certified_slot'}

    A = M.vista.ach.propose_approach(p_star)
    k_ras = M.csc_ras.certified_prefix(A)
    k_seg = M.csc_seg.certified_prefix(A, seg, o, M.tau_seg)
    k = min(k_ras, k_seg, M.m_seg)

    J = M.spc.build(p_star, phi, R, seg, k, views)
    if not M.spc.valid(J):
        return M.sbf.choose(o, seg), J, {'reason': 'invalid_certificate'}

    outcome = M.execute_guarded(A[:k], p_star)
    sigma = M.placement_residual(outcome, p_star)
    post = M.sfa.posterior(sigma, M.vista.fir.signature(M.vista.residual_log))
    return p_star, (outcome, J), post

## 3. 推导

**引理 11（边界跨越界）** 设真实类边界相对分割边界的偏差服从零均值、标准差 `σ_b` 的扰动（沿法向近似独立）。若足印到最近边界的距离 `δ_min`，则足印跨入错误类别的概率 `≤ exp(-δ_min²/(2σ_b²))`。因此取 `δ0 = σ_b√(2 ln(1/β))` 可把边界误置概率压到 `β` 以下；这正是 `u_δ=exp(-δ_min/δ0)` 的函数形式来源。
*证明要点*：单边高斯尾界 + 足印内最危险点（离边界最近处）支配整体跨越事件。

**引理 12（top-2 裕度校准）** 若分割器在部署分布上校准，即 `P(error | m) ≤ exp(-c·m²)`，则 `u_m = 1 - min_F m` 是足印内「至少一个像素判错」概率的一个上界族；`R_seg` 因此是足印级误置概率的保守代理，且随 `m` 单调不增。

**引理 13（最小式保守性）** 若每个 `φ_g` 都是对应约束的可靠下界（`φ_g ≥ 0 ⇒ 约束成立`），则 `Φ = min_g φ_g ≥ ε_Φ > 0 ⇒ 所有约束同时成立`。最小式是「最弱环节」聚合，具有幂等性与保序性；任何加权和都可能用强约束补偿弱约束，因此不满足该保守性，不能用于证书谓词。

**定理 11（SPC 端到端可靠性）** 在 (i) 分割后验校准、足印级误判概率 `≤ δ_seg`；(ii) 各几何裕度为可靠下界；(iii) `Valid(J_RAS)`；(iv) `φ_metric ≥ ε_metric` 下，执行 `A[:k*SPC]` 后的放置发生语义/物理违约的概率满足
`P(violation) ≤ δ_seg + α_chunk + δ_fi + δ_metric`。
*证明要点*：对足印像素做并集界得到 `δ_seg`；`k_RAS` 覆盖物理违约 `α_chunk+δ_fi`；`φ_metric` 把深度导致的边界错位限制在 `δ_metric`；三者事件取并集即得。

**定理 12（语义故障可辨识性）** 设语义签名 `σ` 对各故障源的雅可比 `J_σ(H)` 在工作点列满秩，且共因 `Z` 被条件化（可观测，或由 PAP 探针把 `P(Z)` 集中到单点）。则 `H_SPC` 的后验在给定先验下可辨识，且 `κ_SPC ≥ min(κ_fi, κ_seg)`——语义维度不会降低 VISTA 原有的故障可辨识度；共因校正只会收紧混淆项。

**定理 13（安全退化 / 不劣于）** 若 `R_seg > τ_seg` 或 PAP 预算耗尽，SPACE 进入回退 `F`，且**从不执行无效证书的放置**。在此条件下
`P(violation | SPACE) ≤ P(violation | RAS_hold) + δ_fallback`，
其中 `δ_fallback` 只来自回退动作（安全箱/交接）自身的残余风险。特别地，退化链上任一保守层都不会比「贸然放置」更危险。

**定理 14（主动感知的信息单调性）** 在分割器校准、视角似然无偏、期望信息增益关于候选视角次模的假设下，贪心 PAP 的每步期望 `R_seg` 单调不增，且达到 `(1-1/e)` 的近似最优信息增益；主动感知最多增加成本，不会在期望意义上让证书变差。

class SemanticEvidenceGateway:
    def observe(self, rgb, depth):
        s = segment(rgb)                    # (C,H,W)
        top2 = s.topk(2, dim=0).values
        l = s.argmax(0)
        m = top2[0] - top2[1]
        delta = boundary_distance(l)
        return {'s': s, 'l': l, 'm': m, 'delta': delta,
                'metric': depth_to_metric(depth), 'version': version_hash(s)}


class PlacementSuitabilityField:
    def semantic_risk(self, seg, F, A_o):
        ys, xs = F.nonzero(as_tuple=True)
        if ys.numel() == 0:
            return 1.0
        u_m = 1.0 - float(seg['m'][ys, xs].min())
        u_d = math.exp(-float(seg['delta'][ys, xs].min()) / self.delta0)
        if not all(int(c) in A_o for c in seg['l'][ys, xs]):
            return 1.0
        return 1.0 - (1.0 - u_m) * (1.0 - u_d)

    def phi(self, o, p, seg):
        return min(
            signed_dist(contact_points(o, p), support_boundary(seg, o)) / r_o(o),
            (r_support(o, p, seg) - d_com(o, p)) / r_o(o),
            min_vertex_dist(o, p, container_interior(seg, o)) / r_o(o),
            (min_clearance(o, p, seg) - r_o(o)) / r_o(o),
            (d_max - end_effector_dist(p)) / d_max,
            metric_consistency(seg, footprint(o, p), o),
        )

    def best(self, o, cands, seg, A_o):
        best = None
        for p in cands:
            F = footprint(o, p)
            R = self.semantic_risk(seg, F, A_o)
            if R > self.tau_seg:
                continue
            phi = self.phi(o, p, seg)
            if phi < self.eps_phi or metric_consistency(seg, F, o) < self.eps_metric:
                continue
            key = (task_utility(o, p), -R)
            if best is None or key > best[0]:
                best = (key, p, phi, R)
        return None if best is None else best[1:]


class SemanticFaultAttribution:
    H = ['H_seg', 'H_bound', 'H_depth', 'H_afford', 'H_dyn', 'H_ok']
    def posterior(self, sigma, rho):
        post = {h: self.p_sigma[h](sigma) * self.p_rho[h](rho) * self.prior[h]
                for h in self.H}
        return normalize(post)


class PlacementAwarePerception:
    def next_view(self, seg, F, views, ras):
        best, best_gain = None, 0.0
        for v in views:
            if not ras.certifies_motion(v):
                continue
            gain = mutual_information(F, v, seg) / view_cost(v)
            if gain > best_gain:
                best, best_gain = v, gain
        return best


def SPACE_round(M, obs, o, goal):
    rgb, depth = obs
    seg = M.seg.observe(rgb, depth)
    p_star, phi, R = M.psf.best(o, M.slots.propose(seg, o, goal), seg, M.A[o])

    views = 0
    while (p_star is None or R > M.tau_seg) and views < M.max_views:
        v = M.pap.next_view(seg, footprint(o, p_star), M.view_set, M.ras)
        if v is None:
            break
        rgb, depth = M.move_and_capture(v)          # RAS 认证的运动
        seg = M.seg.observe(rgb, depth)
        p_star, phi, R = M.psf.best(o, M.slots.propose(seg, o, goal), seg, M.A[o])
        views += 1

    if p_star is None or R > M.tau_seg:
        return M.sbf.choose(o, seg), None, {'reason': 'no_certified_slot'}

    A = M.vista.ach.propose_approach(p_star)
    k = min(M.csc_ras.certified_prefix(A),
            M.csc_spc.certified_prefix(A, seg, o, M.tau_seg),
            M.m_seg)
    J = M.spc.build(p_star, phi, R, seg, k, views)
    if not M.spc.valid(J):
        return M.sbf.choose(o, seg), J, {'reason': 'invalid_certificate'}

    outcome = M.execute_guarded(A[:k], p_star)
    post = M.sfa.posterior(M.placement_residual(outcome, p_star),
                           M.vista.fir.signature(M.vista.residual_log))
    return p_star, (outcome, J), post

## 4. 推导

**引理 11（边界跨越界）** 若真实边界相对分割边界的法向偏差服从 `N(0,σ_b²)`，则 `P(足印跨类) ≤ exp(-δ_min²/(2σ_b²))`。取 `δ0=σ_b√(2ln(1/β))` 使误置概率 `≤β`，解释了 `u_δ=exp(-δ_min/δ0)` 的形式。

**引理 12（裕度校准）** 若 `P(error|m) ≤ exp(-c m²)`，则 `u_m=1-min_F m` 给出足印「至少一像素判错」概率的保守上界，`R_seg` 随 `m` 单调不增。

**引理 13（最小式保守性）** 若所有 `φ_g` 为可靠下界，则 `Φ≥ε_Φ>0 ⇒ 全约束成立`；最小式具幂等、保序，不容许强约束补偿弱约束。

**定理 11（SPC 端到端可靠性）** 在分割校准、几何裕度可靠、`Valid(J_RAS)`、`φ_metric≥ε_metric` 下：
```
P(violation) ≤ δ_seg + α_chunk + δ_fi + δ_metric
```
*证明要点*：足印像素并集界 + `k_RAS` 的物理保证 + 度量一致项的深度界，三者取并。

**定理 12（语义故障可辨识性）** 若 `σ` 对故障源的雅可比列满秩且 `Z` 被条件化，则 `H_SPC` 后验可辨识，`κ_SPC ≥ min(κ_fi,κ_seg)`；共因校正只收紧混淆项。

**定理 13（安全退化）** 当 `R_seg>τ_seg` 或 PAP 预算耗尽，SPACE 进入 `F` 且从不执行无效证书放置：
```
P(violation|SPACE) ≤ P(violation|RAS_hold) + δ_fallback
```

**定理 14（PAP 信息单调性）** 在校准、视角似然无偏、增益次模下，贪心 PAP 每步期望 `R_seg` 单调不增，信息增益达 `(1-1/e)` 近似最优。

## 6. 本轮最大风险

**一句话**：SPACE 的所有证书都依赖「分割裕度 `m` 与边界距离 `δ` 在部署分布上仍然校准」；而透明、液体、反光、未知纹理与对抗图案会让分割器**自信地错**，使 `R_seg` 系统性低估真实语义误差，从而把「语义上不允许的放置」认证为合法——这是被证书亲手放行的误置。

**次级风险与缓解**：
1. **分布漂移**：用 conformal risk control 在线监控足印级覆盖率；一旦覆盖率跌破名义值，自动上调 `τ_seg` 或强制 `safe_bin`；
2. **共因混淆**：CAS 显式检测透明/液体/可变形；检测到 `Z ≠ 无` 时冻结语义证书，改走探针或回退；
3. **边界模糊**：对 `δ_min < δ0` 的足迹禁止提交，即使 `R_seg` 因 `comp=1` 显得很低；
4. **主动感知成本**：PAP 只在 `R_seg ∈ (τ_seg, τ_seg+Δ]` 区间触发，避免为已确定/已失败的情形浪费视角；
5. **实时算力**：足印 ROI 变形 + 轻量分割头（MobileNetV3/DeepLab-lite）优先，全图分割走慢路径异步更新。
