# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「商业模式」×「多机器人协作」）

> 第 60 轮把单机执行闭环升级为「场景→意图→约束→阻抗→执行→证据」的认知驱动闭环（SSM×CIEC×EPIR×SERC×PCE++++）。但仍有三个结构性缺口：
> 1. **单机本体论**：SSM/CIEC/SERC 全部以单机器人 r 为中心。多机器人共搬时，阻抗不是各自私有的属性，而是耦合后的系统属性 K_Σ = Φ(K_1,...,K_M)；单机 K_safe 的并集/交集不能直接保证耦合安全。
> 2. **证据无价值语义**：J_exec/EV-exec 只能证明「做了什么」，不能证明「谁欠谁、SLA 是否达成、责任如何分摊」。商业模式（RaaS 按次计费、SLA 罚金、责任险）无法挂接到证据上，结算靠人工、争议靠扯皮。
> 3. **激励与安全的错位（Goodhart 风险）**：若按任务完成量计费，执行层有动机压缩安全裕度、少报接触力、延迟上报失败；证据层再严谨，也会被「选择性上报」腐化。

## 0. 直觉与动机

**灵感 1（商业模式 → 可验证执行契约 VEC）**
直觉：商业模式本质上是「一组关于未来的承诺 + 违约的代价」。RaaS 按次计费承诺「完成一次搬运收一次钱」，SLA 承诺「延迟超过 τ 赔 X」，责任险承诺「碰撞由责任方承担」。这些承诺若不能从执行证据中机械判定，就只能靠事后人工对账。关键洞见：**把商业合同编译成关于 EV-exec 的时序逻辑义务**——「在 t₁–t₂ 内保持接触力 ≤ F_max」是可判定的 MTL 公式，不是散文；一旦可判定，付款、罚金、责任分摊都能由证据自动结算，且「无证据不结算」。

**灵感 2（多机器人协作 → 跨机器人证据账本 CREL）**
直觉：单机 J_exec 是「自证」，多机协作需要「互证」。共搬时，r_i 说「我在 t 时刻施加了 F_i」，r_j 说「我感知到合力 F_Σ」——两条证据必须因果对齐，否则责任无法归属。ROS 2/DDS 是异步多播，消息可能乱序、丢失、甚至被恶意节点伪造。关键洞见：**证据不能只存本地影子副本，要进入一个带因果边与签名链的跨机账本**；账本不追求「全局时钟」，只追求「happens-before 可复现」——这恰好对应物理协作中的「谁先让、谁后动」。

**灵感 3（商业模式 × 多机器人 → 协作阻抗议价 CIB）**
直觉：两个机器人刚性抓住同一张桌子时，阻抗不是各自的私有参数，而是耦合后的系统参数。更麻烦的是：谁承担更多刚度、谁承担更多风险，本质是**经济分配问题**。若合同里 r_i 的责任份额 λ_i = 0.8，它就该被要求提供更大的安全裕度（更硬的 K）或支付更高的价格。关键洞见：**把阻抗选择从「单机优化」变成「带责任权重的多边议价」**——在耦合可行域内寻找各机器人可接受、且责任与风险匹配的 K_Σ。

**灵感 4（合流 → 价值-安全对账 VSR / 机制设计）**
直觉：商业激励与安全目标天然错位。按任务量计费 ⇒ 压缩安全裕度；按证据付费 ⇒ 选择性上报；按责任分摊 ⇒ 互相甩锅。关键洞见：**用机制设计把「安全」设为不可交易的硬约束（dominant constraint），把「价值」设为仅在安全可行域内优化的软目标**。付款函数必须满足安全支配性（硬违规即零付款）、安全单调性（违规越重付款越低）与激励相容性（如实上报是占优策略）。

**灵感 5（预算 → PCE+++++ 五维）**
直觉：经济层不是免费的：结算、托管、仲裁、跨机共识都吃算力/带宽/时延。把 B_econ、B_collab 并入预算，并规定**经济降级不得放松安全约束**——最坏情况是「先干活、后结算」，绝不是「为了结算而降低 K_floor」。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（可验证执行契约 VEC）** C = (P, O, E_s, Σ, D, δ)。其中：
- **契约方** P = {p_1,...,p_M}（机器人运营方、任务委托方、保险方）
- **义务集** O = {o_k}：每个 o_k 为过去时度量时序逻辑公式 past-MTL，原子命题取自证据谓词，例如
  - `□[t1,t2] (contact_force ≤ F_max)`（接触力上限）
  - `◇[t1,t2] grasp_holds ∧ □[t1,t2] slip = 0`（抓持稳定）
  - `handover_done → (src_release ≺ dst_grasp)`（交接先后，≺ 为 happens-before）
- **证据模式** E_s：每个原子命题映射到所需 EV-exec 字段 (robot_id, seq, ts, payload_hash, sig)
- **结算函数** Σ: (V_final, O_eval) → (payment, penalty)
- **争议规则** D；**可靠性界** δ
- **可执行性判定**：contract_executable(C) ⇔ ∀o_k∈O，存在监视器 M_k 使 |M_k(E) − truth| ≤ δ。不可执行的义务（无法从证据判定）拒绝签署，避免「不可证伪的 SLA」。

**定义 162（跨机器人证据账本 CREL）** L = (V, E_h, E_c, F)。其中：
- **记录** v = (rid, robot_id, seq, ts, payload_hash, sig, prev_hash, causal_refs)
- **哈希边** E_h：v.prev_hash 指向同一机器人的前序记录；causal_refs 指向 happens-before 的其他机器人记录
- **因果边** E_c：由消息发送/接收建立，构成偏序（不依赖全局时钟）
- **终结性** F：v 为 final ⇔ 收到 q = ⌈(M+f+1)/2⌉ 个不同机器人的后续引用（或 quorum 证书），且其所有因果祖先已 final
- **安全性**：同一机器人对同一 seq 不得产生两条不同 final 记录（equivocation 检测）
- **对账语义**：只有 final 记录可参与结算；未 final 的记录一律视为「证据不足」

**定义 163（协作阻抗议价 CIB）** CIB = (Φ, {K_safe^i}, λ, c, u, τ_bargain)。其中：
- **耦合映射** Φ: K_1×...×K_M → K_Σ 单调连续；各向同性刚性共抓近似为 K_Σ^{-1} = Σ_i K_i^{-1}（导纳可加）
- **耦合可行域** K_collab = { Φ(K_1,...,K_M) | ∀i: K_i ∈ K_safe^i(场景, 意图), SIC_valid }
- **责任份额** λ = (λ_1,...,λ_M)，Σλ_i = 1，由 VEC 的义务与责任条款给出
- **单机成本** c_i(K_i; K_Σ) = λ_i·Risk(K_Σ) + ρ_i·Effort(K_i)，ρ_i 为经济价格
- **议价**：交替出价使 u_i = −c_i + payment_i 最大化；若 K_collab = ∅ 或超过 τ_bargain，降级为 leader-follower 刚性模式

**定义 164（价值-安全对账 VSR）** 付款函数 P: (E, C) → ℝ，必须同时满足：
- **VSR-1 安全支配**：若 ¬Safe(K, execution)，则 P = 0 且 penalty ≥ 0，与任务成败无关
- **VSR-2 安全单调**：P 关于违规幅度单调不增；硬违规不可用付款补偿
- **VSR-3 激励相容**：存在审计概率 α 与罚金系数 κ，使 α·κ·penalty ≥ gain(misreport) 时，如实上报为占优策略
- **VSR-4 裕度地板**：K_floor ⊆ K_safe 为不可协商项，任何商业条款不得下移
- **结算**：Σ_C(e) = base·1[O_task] − penalty(violations)，托管 escrow；证据不足 ⇒ DEFER（疑罪从无，不结算）

**定义 165（五维协同预算 B_mec / PCE+++++）** B_mec = (B_cog, B_econ, B_collab)。其中：
- **B_econ** = (Settlement_latency, Escrow_depth, Arbitration_compute)
- **B_collab** = (Sync_bandwidth, Consensus_rounds, Coupling_tolerance)
- **扩展 VOI**：
```
voi_mec(π) = voi_cog(π) − cost_econ(π) − cost_collab(π)
cost_econ    = λ_settle·Settlement_cost + λ_arb·Arbitration_cost
cost_collab  = λ_cons·Consensus_rounds + λ_sync·Sync_bytes
```
- **降级规则**：B_econ 耗尽 ⇒ 延迟结算/离线对账（安全不回退）；B_collab 耗尽 ⇒ leader-follower；B_cog 耗尽 ⇒ 沿用第 60 轮降级链。

**定义 166（协作归因与信誉 CARM）** 归因 a: Evidence DAG → Δ^M（机器人上的单纯形）：
- **反事实价值** v(S) = 1 ⇔ 只有联盟 S 存在时足以避免失败 f（基于耦合模型的因果反事实）
- **归因** a_i = Shapley_i(v)（精确 O(2^M)，近似 O(M·|E|·samples)）
- **信誉更新** R_i ← clip(R_i + η·(1 − a_i) − η'·a_i, 0, 1)，用于未来协作对象选择与保证金定价
- 作用：抑制搭便车与道德风险，使「分摊责任」有可复现的算法依据

**定义 167（拜占庭证据韧性 BER）** 设 M ≥ 3f+1：
- **交叉签名**：每次交接 handover 由 src 与 dst 双签，形成跨机因果边
- **证据法定数**：quorum q = ⌈(M+f+1)/2⌉
- **分裂检测**：若同一 (robot_id, seq) 出现两条不同 payload_hash 的签名记录，立即标记 equivocation 并冻结该机器人结算
- **安全性**：≤ f 个拜占庭机器人时，结算可靠性不低于非拜占庭情形（见 A67）

**定义 168（多机经济-契约闭环 MECCL）** 算子 MECCL(M, task, β)：
```
① Scene/Intent: 复用第 60 轮 SSM/CIEC 得到 z_scene 与 C_intent
② Contract: VEC.compile(β, z_scene, C_intent) → C；若不可执行则拒绝签约
③ Bargain: K_Σ ← CIB.bargain(K_collab, λ)
④ Dispatch: 各机分发 K_i 与 ERTC 锁定约束（含 K_floor）
⑤ Execute: 多机耦合执行，交叉签名记录 EV-exec
⑥ Ledger: CREL.append(·)；等待 final
⑦ Settle: VSR.settle(C, L_final) → (payment, penalty)
⑧ Attribute: CARM.attribute(L_final, failure) → a
⑨ Update: R_i 与 λ 依据归因更新，写入下一轮契约
⑩ Return: (K_Σ, L_final, settlement, a, R)
```

## 2. 关键算法伪代码

### IP-161 VEC（可验证执行契约）

```python
class VerifiableExecutionContract:
    def __init__(self, parties, obligations, evidence_schema, settlement_fn, delta=1e-3):
        self.parties = parties
        self.obligations = obligations          # {name: past-MTL formula}
        self.schema = evidence_schema
        self.settle = settlement_fn
        self.delta = delta
        self.compiled = {k: compile_past_mtl(v) for k, v in obligations.items()}

    def executable(self):
        # 不可从证据判定的义务 = 不可证伪的 SLA，必须拒签
        return all(mon.evidence_bound() <= self.delta
                   for mon in self.compiled.values())

    def check(self, ledger_view):
        return {k: mon.evaluate(ledger_view) for k, mon in self.compiled.items()}

    def settle_from_evidence(self, ledger_view):
        res = self.check(ledger_view)
        if any(v == 'UNKNOWN' for v in res.values()):
            return Settlement(payment=0.0, state='DEFER')   # 证据不足，不结算
        return self.settle(res, ledger_view)
```

### IP-162 CREL（跨机器人证据账本）

```python
class CrossRobotEvidenceLedger:
    def __init__(self, robot_id, M, f):
        self.robot_id = robot_id
        self.M, self.f = M, f
        self.records = {}
        self.head = {r: None for r in range(M)}
        self.finalized = set()

    def append(self, ev_exec, causal_refs=()):
        seq = self._next_seq(self.robot_id)
        rec = EvidenceRecord(
            robot_id=self.robot_id, seq=seq, ts=time.time(),
            payload_hash=sha256(canonical_json(ev_exec)),
            prev_hash=self.head[self.robot_id],
            causal_refs=tuple(self.records[r].rid for r in causal_refs),
            sig=sign(self.robot_id, canon(ev_exec)),
        )
        self.records[rec.rid] = rec
        self.head[self.robot_id] = rec.rid
        return rec

    def finalize(self, rec):
        q = math.ceil((self.M + self.f + 1) / 2)
        if self._acks(rec) >= q and self._ancestors_final(rec):
            self.finalized.add(rec.rid)
            return True
        return False

    def detect_equivocation(self):
        seen = {}
        for r in self.records.values():
            key = (r.robot_id, r.seq)
            if key in seen and seen[key].payload_hash != r.payload_hash:
                return key
            seen[key] = r
        return None
```

### IP-163 CIB（协作阻抗议价）

```python
class CollaborativeImpedanceBargain:
    def __init__(self, robots, coupling_map, liability, deadline=1.0):
        self.robots = robots
        self.Phi = coupling_map
        self.lam = liability            # sum(lam)=1
        self.deadline = deadline

    def feasible_set(self):
        # 各 K_safe^i 为 EEIS 给出的凸集；Phi 单调连续
        return intersect_projected(self.Phi, [r.K_safe for r in self.robots])

    def bargain(self, K_collab):
        if not K_collab:
            return None                       # 无耦合可行解
        offers = {r.id: r.preferred_K(K_collab) for r in self.robots}
        t = 0.0
        while t < self.deadline:
            proposal = self._liability_weighted_median(offers, self.lam)
            if all(self._acceptable(r, proposal) for r in self.robots):
                return proposal               # 一致点：责任与风险匹配
            offers = self._counter_offers(offers, proposal)
            t += self._round_cost()
        return None                           # 超时 → leader-follower 降级
```

### IP-164 VSR（价值-安全对账）

```python
def value_safety_settlement(contract, ledger_view, enforcement):
    violations = detect_hard_violations(ledger_view)   # 来自 J_exec / EV-exec
    if violations:
        # VSR-1：安全支配——任务再成功也不付款，且罚金与违规幅度单调相关
        return Settlement(payment=0.0,
                          penalty=enforcement.penalty(violations),
                          reason='SAFETY_DOMINANCE')
    result = contract.check(ledger_view)
    if any(v == 'UNKNOWN' for v in result.values()):
        return Settlement(payment=0.0, state='DEFER')  # VSR-3：不奖励可疑证据
    return Settlement(payment=contract.settle(result), penalty=0.0, reason='OK')
```

### IP-165 PCE+++++（五维协同预算）

```python
class MechBudget:
    def __init__(self, settle_latency=0.2, escrow_depth=32, arb_ops=50,
                 sync_bw=1_000_000, consensus_rounds=3):
        self.B_settle, self.B_escrow, self.B_arb = settle_latency, escrow_depth, arb_ops
        self.B_sync, self.B_cons = sync_bw, consensus_rounds
        self.used_settle = self.used_escrow = self.used_arb = 0
        self.used_sync = self.used_cons = 0

    def econ_mode(self):
        if self.used_settle > self.B_settle or self.used_escrow > self.B_escrow:
            return 'deferred_settlement'      # 安全不回退，仅结算延后
        return 'normal'

    def collab_mode(self):
        if self.used_sync > self.B_sync or self.used_cons > self.B_cons:
            return 'leader_follower'          # 物理协作降级
        return 'coupled'
```

### IP-166 CARM（协作归因）

```python
def counterfactual_attribution(ledger_view, failure, M, samples=256):
    def v(S):
        # 若仅联盟 S 的机器人存在即可避免 failure，则 v(S)=1
        return 1.0 if replay_without(ledger_view, failure, keep=S) else 0.0
    return monte_carlo_shapley(v, M, samples)   # O(M·|E|·samples)

def update_reputation(R, attribution, eta=0.05, eta_prime=0.10):
    return clip(R + eta * (1 - attribution) - eta_prime * attribution, 0.0, 1.0)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| VEC | O(\|O\|·\|E\|) 编译，O(1) 增量判定 | O(\|O\|) | 义务判定 δ-可靠；不可判定义务拒签 |
| CREL | 追加 O(1)，终结 O(log M) | O(N+M) | 因果完备；≤f Byzantine 抗抵赖 |
| CIB | O(M·d·N_round) | O(M·d) | 凸可行域内收敛；责任权重保序 |
| VSR | O(\|E\|) | O(1) | 安全支配 + 安全单调 + 激励相容 |
| CARM | O(M·\|E\|·samples) | O(M) | Shapley 近似误差 ≤ ε |

**假设 A66–A70**：**(A66)** VEC：past-MTL 监视器对证据可靠，判定误差 ≤ δ。**(A67)** CREL：部分同步网络下，因果投递与 quorum 终结可实现；拜占庭节点 ≤ f，且 M ≥ 3f+1。**(A68)** CIB：各 K_safe^i 为凸集，Φ 单调连续（各向同性时近似仿射），故 K_collab 可判定且议价有限轮收敛。**(A69)** VSR：审计概率 α 与罚金系数 κ 满足 α·κ·penalty ≥ gain(misreport)；K_floor 由 ERTC 强制，契约层不可写。**(A70)** PCE+++++：B_econ/B_collab/B_cog 单调消耗，耗尽只触发性能降级，不放松安全约束。

**正确性定理（MECCL）**：若 A66–A70 成立，则
1. **结算可复现**：任何被结算的义务均可在 L_final 上复现，误结算率 ≤ δ + Pr[Byzantine > f]。
2. **耦合安全**：若 K_collab ≠ ∅ 且 CIB 在 τ_bargain 内收敛，则产出的 K_Σ ∈ K_collab，且 ∀i: K_i ∈ K_safe^i（含 K_floor）。
3. **激励相容**：VSR 下策略性上报的期望收益 ≤ 如实上报；硬安全违规付款恒为 0，且罚金随违规幅度单调不减。
4. **降级安全**：任一 B_mec 耗尽只降性能（延迟结算/leader-follower），安全约束与 K_floor 不被修改。

### IP-161 VEC（可验证执行契约）

```python
class VerifiableExecutionContract:
    def __init__(self, parties, obligations, evidence_schema, settlement_fn, delta=1e-3):
        self.parties = parties
        self.obligations = obligations          # {name: past-MTL formula}
        self.schema = evidence_schema
        self.settle = settlement_fn
        self.delta = delta
        self.compiled = {k: compile_past_mtl(v) for k, v in obligations.items()}

    def executable(self):
        return all(mon.evidence_bound() <= self.delta
                   for mon in self.compiled.values())

    def check(self, ledger_view):
        return {k: mon.evaluate(ledger_view) for k, mon in self.compiled.items()}

    def settle_from_evidence(self, ledger_view):
        res = self.check(ledger_view)
        if any(v == 'UNKNOWN' for v in res.values()):
            return Settlement(payment=0.0, state='DEFER')
        return self.settle(res, ledger_view)
```

### IP-162 CREL（跨机器人证据账本）

```python
class CrossRobotEvidenceLedger:
    def __init__(self, robot_id, M, f):
        self.robot_id = robot_id
        self.M, self.f = M, f
        self.records, self.finalized = {}, set()
        self.head = {r: None for r in range(M)}

    def append(self, ev_exec, causal_refs=()):
        seq = self._next_seq(self.robot_id)
        rec = EvidenceRecord(
            robot_id=self.robot_id, seq=seq, ts=time.time(),
            payload_hash=sha256(canonical_json(ev_exec)),
            prev_hash=self.head[self.robot_id],
            causal_refs=tuple(self.records[r].rid for r in causal_refs),
            sig=sign(self.robot_id, canon(ev_exec)),
        )
        self.records[rec.rid] = rec
        self.head[self.robot_id] = rec.rid
        return rec

    def finalize(self, rec):
        q = math.ceil((self.M + self.f + 1) / 2)
        if self._acks(rec) >= q and self._ancestors_final(rec):
            self.finalized.add(rec.rid)
            return True
        return False

    def detect_equivocation(self):
        seen = {}
        for r in self.records.values():
            key = (r.robot_id, r.seq)
            if key in seen and seen[key].payload_hash != r.payload_hash:
                return key
            seen[key] = r
        return None
```

### IP-163 CIB（协作阻抗议价）

```python
class CollaborativeImpedanceBargain:
    def __init__(self, robots, coupling_map, liability, deadline=1.0):
        self.robots, self.Phi = robots, coupling_map
        self.lam, self.deadline = liability, deadline

    def feasible_set(self):
        return intersect_projected(self.Phi, [r.K_safe for r in self.robots])

    def bargain(self, K_collab):
        if not K_collab:
            return None
        offers = {r.id: r.preferred_K(K_collab) for r in self.robots}
        t = 0.0
        while t < self.deadline:
            proposal = self._liability_weighted_median(offers, self.lam)
            if all(self._acceptable(r, proposal) for r in self.robots):
                return proposal
            offers = self._counter_offers(offers, proposal)
            t += self._round_cost()
        return None
```
