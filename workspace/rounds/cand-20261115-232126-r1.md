# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「灵巧手」×「抓取规划」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**接触证书 + 反射分层 + 技能图**。v9 的全部证书都长在自由空间（间隙、能耗、域偏移）；一旦手指闭合，主要矛盾从"别撞"变成"别滑"，而滑移是毫秒级、不可逆、由摩擦锥而非距离决定。因此本轮不把灵巧手当"换一个末端执行器"，而当作**新增一个安全域：接触空间**；新模块全部可选中立元，失效即严格退回 v9。

## 0. 直觉与动机

**灵感 1（灵巧手 → 触觉反射层与协同降维）**
直觉：灵巧手的价值不是多几个关节，而是能在接触中"感知—反应"。人手抓鸡蛋时并不每 20ms 重规划一次，而是脊髓级反射在 ~1kHz 维持握力与防滑，大脑只负责"抓哪里、做什么"。核心创新：**触觉反射层（TactileReflexLayer, TRL）**——1kHz 运行、独立于 50Hz 决策环的硬实时反射，只允许在**反射包络 R(g)** 内调节指力；R(g) 由抓取证书推出，故反射"救急但不越权"。同时用**姿态协同** q=Sz+e 把 16 自由度压到 3–6 维规划，并给出协同截断误差对力封闭裕度的显式下界。

**灵感 2（抓取规划 → 力封闭证书与任务化排序）**
直觉：抓取规划的传统输出是一个位姿，但"位姿可信"不等于"抓得住"。严谨的接口应输出**带证书的抓取假设** g=(x*,R*,z,C,τ_g,π_g)，证书包含力封闭裕度、摩擦锥裕度、ε-度量和力矩裕度，且必须计入位姿/摩擦/协同三类误差。核心创新：**抓取证书（GraspCert, GCert）**，把 v9 的"块证书"从自由空间推广到接触空间；并让抓取规划按**任务可得性** π_g 排序（要倒水就抓杯柄，要递给人就抓可交接面），而非只按几何稳定性。

**灵感 3（两灵感交汇 → 抓取-分块持久不变式与灵巧技能图）**
直觉：v9 的动作块是"开环执行 K 步 + 廉价守卫"，但抓取期间物体可能相对手指微滑，块内必须保证"抓取仍成立"。核心创新：把块证书扩成**抓取-分块持久不变式**：预测块内接触 wrench 轨迹始终在摩擦锥内留裕度，否则在块内插入**再抓取检查点** r_k ∈ P_t；并定义**灵巧技能图（DSG）**给 v8 PrimitiveGraph 增加手内旋转/倒手/再抓取节点，每条边携带"后置证书⇒前置条件"的传递义务。

## 1. 研究问题（轮次升级版）

- **Q1（接触证书可靠性）**：在物体位姿误差 ε_x、摩擦估计误差 ε_μ、协同截断误差 ε_s 同时存在时，如何给出力封闭裕度的可计算下界，使"证书通过"以 ≥1−δ 的概率蕴含真实力封闭？三类误差的 Lipschitz 折减是否足够紧？
- **Q2（反射-规划共存）**：1kHz 反射与 50Hz/5Hz 规划构成混合系统，如何用反射包络与优先级格保证反射既不越权（不破坏证书）、也不与规划器形成极限环/抖振？"包络预留 δ_r + 抗积分饱和"能否给出有界振幅保证？
- **Q3（接触域退化）**：如何把"灵巧手不可用/触觉失效/技能图缺失"编码为中立元，使系统严格退回 v9 的开环抓取与逐步执行，而非降级为无证书的盲目抓取？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P16）

**P13 接触证书律（Contact-Certificate Law, GCert）**
任何抓取执行前必须持有有效力封闭证书；证书值随位姿/摩擦/协同误差按 Lipschitz 下界折减；折减后低于阈值即拒绝该抓取，而非"先抓再说"。

**P14 反射包络律（Reflex-Envelope Law, TRL）**
反射层只能在证书导出的凸包络 R(g) 内动作，且除 M₀ 硬检查外拥有点抢占权；反射不得改变证书，只能消费证书的剩余裕度（并预留 δ_r 给规划纠正）。

**P15 抓取-分块持久律（Grasp-Chunk Persistence）**
块内每一预测步都必须满足抓取持久不变式；不满足则缩短 K_eff 或插入再抓取检查点；滑移风险高时 K_eff≡1，使每次抓取决策都可被最新触觉修正。

**P16 技能证书传递律（Skill-Certificate Transport）**
技能图上的每次迁移必须携带并检查证书：源技能的后置证书强度 ≥ 目标技能前置条件所需强度，否则迁移被拒绝（等价于"不安全的技能切换不发生"）。

## 3. 与基线的接口（如何退化）

**接触层减法链（v10 → v9）：**
- TRL 失效 ⇒ 常力握持（v9 开环抓取），证书仍在但无防滑反射；
- DSG 失效 ⇒ 退化为单一 pick-and-place 技能（等价 v9 无手内操作）；
- GCert 失效/超时 ⇒ 只允许 v9 已支持的几何预抓取，拒绝新抓取（中立元=不抓）；
- DGP 失效 ⇒ 沿用上一有效抓取假设 g，超时则安全放置/释放；
- 接触层整体失效 ⇒ 完整退回 v9 MetricVoiceGauge-ACMD，再按 v9 五级链退回 v8/v7/v6；
- 摩擦估计失效 ⇒ 用证书的保守下界 μ_min（最坏表面），牺牲成功率换安全。

**继承 v9 的五级链**：AC 证书失效 ⇒ K_eff←1；MW 失效 ⇒ v8 手写网关；ID 失效 ⇒ 全模块常开；DA/SPR/Cal 失效 ⇒ 中立元注入（Δ_dom≡0 / risk_SLAM≡0 / sensor_weight≡1）；全失效 ⇒ v7 → v6。

## 4. 预期贡献

1. **接触空间证书**：把 v9 的自由空间证书扩展到力封闭/摩擦锥，并给出位姿-摩擦-协同三类误差的显式裕度折减（引理 87）；
2. **硬实时触觉反射层**：证书导出凸包络 + 优先级格，证明反射保力封闭且与规划器有界共存、无大振幅极限环（引理 88–89）；
3. **抓取-分块持久不变式与再抓取检查点**：把"块内安全"从避障推广到"不掉落"（引理 90）；
4. **灵巧技能图与证书传递**：为高自由度手内操作提供可组合、可退化、可验证的技能编排（引理 91）；
5. **三域统一退化**：自由空间（v9）+ 接触空间（v10）两层证书共用同一中立元代数，v10→v9→v8→v7→v6 严格等价（引理 92）；
6. E571–E590 覆盖证书标定、摩擦敏感性、反射时延、滑移抑制、协同压缩、技能切换、退化等价与端到端抓取任务。

## 5. 本轮最大风险

**一句话**：抓取证书的可靠性最终压在摩擦系数估计上，而滑移恰恰是摩擦估计失效的**事后**信号——1kHz 反射能救一次打滑，却不能修正证书已错的 μ 假设，于是"反射越灵敏，越可能掩盖证书的系统性偏差"，形成"越滑越信、越信越快滑"的错觉。

## 2. 形式化定义

**定义 540（灵巧手与姿态协同 Dexterous Hand & Synergy）** 灵巧手 H = (n_q, FK, T, τ_max)：n_q 个关节（典型 16，5 指）、指尖前向运动学 FK、触觉阵列 T_i ∈ R^{a×b}（典型 5×8/指尖）、关节力矩上限 τ_max。姿态协同基 S ∈ R^{n_q×k}（k≪n_q，典型 k=4），预成型姿态：
```
q(z) = S z + q_0 + e,   ‖e‖ ≤ ε_s
```
ε_s 为协同截断误差上界（E573 标定）。假设 FK 在关节空间关于 q 的 Lipschitz 常数为 L_fk，则接触点位移满足 ‖δp‖ ≤ L_fk(‖S Δz‖ + ‖e‖)。

**定义 541（抓取假设 GraspHypothesis）** g = (x*, R*, z, C, τ_g, π_g, v_appr)：
- x* ∈ R³、R* ∈ SO(3)：物体坐标系下的抓取中心与接近姿态；
- z ∈ R^k：协同系数，决定预成型 q(z)；
- C = {(i, p_i, n_i)}：接触集，p_i 为指尖接触点、n_i 为物体表面外法向；
- τ_g ∈ R^{n_q}：额定指力/力矩剖面；
- π_g ∈ [0,1]：任务可得性先验（由下游任务与物体部位决定，E582 标定）；
- v_appr：接近方向，含预抓取间隙与退出通道。

**定义 542（抓取证书 GraspCertificate）** 对抓取假设 g 与摩擦估计 μ̂：
```
m_μ  = min_{i∈C} ( μ̂_i f_{n,i} − ‖f_{t,i}‖ ) / ( μ̂_i f_{n,i} + ε₀ )        # 摩擦锥裕度 ∈ (−∞,1]
W_i  = { w_i(f) : f ∈ FC_i(μ̂_i), ‖f‖ ≤ 1 }                                 # 单位接触 wrench 集
ε_g  = max{ r : B_r(0) ⊆ conv( ⋃_{i∈C} W_i ) }                             # ε-度量
γ_fc = ε_g / w_ref                                                         # 归一化力封闭裕度
m_τ  = min_i ( 1 − |τ_{g,i}| / τ_{max,i} )                                 # 力矩裕度
GCert(g) = (γ_fc, m_μ, m_τ, ε_g)
```
证书**名义有效** ⇔ γ_fc ≥ γ_min ∧ m_μ ≥ m_μ^min ∧ m_τ ≥ m_τ^min ∧ ε_g ≥ ε_min。其中 FC_i 为手指 i 的摩擦锥（库仑锥，半角 arctan μ̂_i），w_ref 为参考 wrench 尺度。

**定义 543（证书可靠性：三类误差折减 Certified Lower Bound）** 设 γ_fc、m_μ、m_τ 关于物体位姿 x、摩擦 μ、协同误差 e 均 Lipschitz，常数分别为 (L_γx,L_γμ,L_γs) 等。给定位姿误差界 ε_x、摩擦估计误差界 ε_μ、协同截断 ε_s，定义保守证书：
```
Ḡ(g) = ( γ_fc − L_γx ε_x − L_γμ ε_μ − L_γs ε_s,
         m_μ  − L_μx ε_x − L_μμ ε_μ − L_μs ε_s,
         m_τ  − L_τx ε_x − L_τμ ε_μ − L_τs ε_s,
         ε_g  − L_εx ε_x )
```
**证书可靠** ⇔ Ḡ 的每一项仍 ≥ 对应阈值。P13 要求：只有 Ḡ 可靠才允许执行；GCert(g) 名义通过但 Ḡ 不通过 ⇒ 视为拒绝。位姿误差 ε_x 由 v8 SpatialCert/SPR 的物体位姿不确定度给出；ε_μ 由摩擦估计器给出；ε_s 由 E573 标定。

**定义 544（触觉反射层 TactileReflexLayer, TRL）** 以 f_r = 1kHz 独立运行（硬件定时器/ISR，不被 50Hz 环阻塞）。滑移统计量：
```
s_t^slip = [ ‖ḟ_t‖ > v₁ ] ∨ [ E_{50–200Hz}(f_t) > v₂ ] ∨ [ d(f_t/f_n)/dt < −v₃ ]
p_slip   = σ( a₁‖ḟ_t‖ + a₂E_vib − a₃(f_n/f_t − μ̂) + b )
```
反射律 π_r：当 p_slip ≥ τ_slip 时，沿证书允许方向增大法向力/收拢手指；否则维持。输出经反射包络投影与抗积分饱和（泄漏积分、速率限幅）。TRL 只读取 GCert/Ḡ，不写入证书。

**定义 545（反射包络 ReflexEnvelope）**
```
R(g) = { Δτ :  f_{n,i}(τ_g+Δτ) ≤ f_n^max,  ∀i
               m_μ,i(τ_g+Δτ) ≥ Ḡ.m_μ^min + δ_r,  ∀i
               |τ_g+Δτ| ≤ τ_max,
               |Δτ| ≤ Δτ_max }
```
在接触线性化下，摩擦锥为二阶锥、f_n 关于 τ 线性，故 R(g) 是凸集 ⇒ 欧氏投影唯一。δ_r>0 为**规划预留裕度**：反射最多消费到 Ḡ.m_μ − δ_r，给 5Hz 规划留纠正空间。

**定义 546（抓取-分块持久不变式 GraspChunkPersistence）** 对动作块 ζ = (a^{1:K}, Ĉ, P) 与抓取 g，要求 ∀k≤K：
```
w_k = predicted_wrench( g, a^{1:k}, object_pose_k ) ∈ FC( C_k ; μ̂ )
m_μ(w_k) ≥ Ḡ.m_μ^min + β_g,   γ_fc(w_k) ≥ γ_min,   ‖Δx_k‖ ≤ ε_x + k·δ_x
```
其中 β_g 为块内滑移余量，δ_x 为块内位姿漂移率上界。任一 k 不满足 ⇒ 在该 k 处插入再抓取检查点，或收缩 K_eff。**证书有效** ⇔ 空间分量（v9 Ĉ）与接触分量（上式）同时成立；这就是升级后的定义 533。

**定义 547（再抓取检查点 RegraspPoint）** r ∈ {1..K} 为再抓取点，当且仅当在第 r 步末满足二者之一：
(a) 当前 g 的 Ḡ 仍可靠（可继续）；或
(b) 存在已认证的 g' 使得迁移证书 ψ_{g→g'} 成立（后置裕度 ≥ g' 前置需求）。
与中止点不同：中止点是"停下来"，再抓取点是"换一种抓法继续任务"。P_t 升格为 P_t^abort ∪ P_t^regrasp，中块守卫按优先级选择 regrasp > abort > continue。

**定义 548（灵巧技能图 DexterousSkillGraph, DSG）** G_d = (V, E)：
```
V = {reach, pre-grasp, close, lift, transport, in-hand-rotate, regrasp, place, release}
E ⊆ V×V,  e=(u→v) 携带 (ψ_e^-, ψ_e^+, cert_obligation)
```
ψ_e^- 为迁移前置（如"物体已在手中且 Ḡ 可靠"），ψ_e^+ 为后置（如"旋转 θ 后仍力封闭"）。**证书传递义务**：执行 e 后必须保证 post(e) 的证书强度 ≥ 下一个技能 pre(v) 所需强度，否则拒绝该边。DSG 是 v8 PrimitiveGraph 的严格超图（保留原节点与边）。

**定义 549（接触安全优先级格 Contact Priority Lattice）** 预占关系 ≺ 为全序：
```
M₀ 硬检查  ≺  TRL 滑移反射  ≺  GCert 再抓取  ≺  SpatialCert 避障
          ≺  AC 中块守卫  ≺  ER/任务/情感调制
```
左侧可抢占右侧；TRL 只能在 R(g) 内抢占，不能违反 M₀ 与力矩上限。该全序无环，故抢占不会自锁。

**定义 550（接触层中立元表 GraspNeutralTable）**

| 模块 | 失效注入 v^⊥ | 等价 v9 模式 |
|---|---|---|
| TRL | Δτ ≡ 0（常力） | v9 开环抓取（无防滑反射） |
| DSG | 单原子技能 pick-place | v9 PrimitiveGraph，抓取为原子 |
| GCert | 拒绝新抓取（⊥ = 不抓） | v9 几何预抓取路径 |
| DGP | 保持上一 g；过期则释放 | v9 无灵巧规划 |
| 摩擦估计 | μ̂ ← μ_min（保守下界） | v9 固定摩擦假设 |
| 接触层整体 | 全部上述中立元 | v9 ACMD |

**升级定义 496（软证书，v10）** δ_trigger 增加接触条件：
```
δ_trigger = {σ<τ_safe ∧ γ_grasp valid ∧ Δ_dom<τ_dom ∧ risk_SLAM<τ_SLAM
             ∧ Ĉ_t valid ∧ Ḡ(g) reliable ∧ p_slip<τ_slip}
```
七条件同尺度触发 M₀ 硬检查；滑移与证书失效同样立即进入接触层处置，无"块内软通过、块末硬失"空洞。

**升级定义 531（软硬约束衔接）** M₀ 判据增加接触入口：中块滑移/证书失效 ⇒ 立即切换最近再抓取点或安全释放，不等块边界。

**升级定义 539（有效块长门控）**
```
K_eff(t) = 1                                          若 U_t 不成立或 p_slip ≥ τ_slip 或 Ḡ 近乎失效
         = max(1, ⌊K_max·(1 − min(1, Δ_dom/τ_dom))·ρ_grasp⌋)   否则
ρ_grasp = clip( Ḡ.m_μ / (m_μ^min + β_g), 0, 1 )
```

抓取越"悬"（接触裕度越薄），块越短；极薄时 K_eff=1，每次抓取动作都被最新触觉修正。这是 P15 的直接实现。

```python
# IP-358 GraspCertifier：抓取证书（定义 542–543）
@dataclass
class GraspCert:
    gamma_fc: float; m_mu: float; m_tau: float; eps_g: float
    unc: tuple                      # (eps_x, eps_mu, eps_s)

class GraspCertifier:
    def __init__(self, thresholds, lipschitz):
        self.th, self.L = thresholds, lipschitz

    def raw_margins(self, g, obj, mu_hat):
        contacts = g.C
        m_mu = min((mu_hat[i]*f_n - f_t) / (mu_hat[i]*f_n + 1e-9)
                   for i, f_n, f_t in contacts)
        W = [unit_wrench_set(i, mu_hat[i]) for i in range(len(contacts))]
        eps_g = largest_ball_in_convex_hull(W)       # ε-度量
        gamma_fc = eps_g / self.th.w_ref
        m_tau = min(1 - abs(t)/self.th.tau_max for t in g.tau_g)
        return GraspCert(gamma_fc, m_mu, m_tau, eps_g, unc=None)

    def certified_bound(self, raw, unc):
        ex, em, es = unc                        # 定义 543
        L = self.L
        return GraspCert(
            raw.gamma_fc - L.gx*ex - L.gmu*em - L.gs*es,
            raw.m_mu    - L.mx*ex - L.mmu*em - L.ms*es,
            raw.m_tau   - L.tx*ex - L.tmu*em - L.ts*es,
            raw.eps_g   - L.ex*ex, unc)

    def reliable(self, c):
        return (c.gamma_fc >= self.th.gamma_min
                and c.m_mu  >= self.th.mu_min
                and c.m_tau >= self.th.tau_min
                and c.eps_g >= self.th.eps_min)


# IP-357 DexterousGraspPlanner：协同空间采样 + 任务化排序
class DexterousGraspPlanner:
    def __init__(self, sampler, synergy, certifier, n_cand=256):
        self.sampler, self.S, self.cert, self.n = sampler, synergy, certifier, n_cand

    def plan(self, obj, task_ctx, mu_hat, unc):
        best = None
        for z, x_star, R_star in self.sampler.sample(obj, self.S, self.n):
            q = self.S @ z + self.S0                 # 定义 540
            C = self.fk_contacts(q, x_star, R_star)
            g = GraspHypothesis(x_star, R_star, z, C,
                                tau_profile(C, task_ctx), task_prior(obj, C))
            raw = self.cert.raw_margins(g, obj, mu_hat)
            c = self.cert.certified_bound(raw, unc)
            if not self.cert.reliable(c):            # P13：不可靠即拒绝
                continue
            score = (W_STAB*c.gamma_fc + W_TASK*g.pi_g
                     - W_SLIP*slip_risk(g, task_ctx))
            if best is None or score > best.score:
                best = ScoredGrasp(g.with_cert(c), score)
        return best or None                          # None ⇒ GCert 中立元（不抓）


# IP-359 TactileReflexLayer：1kHz 硬实时反射（定义 544–545）
class TactileReflexLayer:
    def __init__(self, tau_slip=0.7, delta_r=0.1, rate_limit=0.2, leak=0.05):
        self.tau_slip, self.delta_r = tau_slip, delta_r
        self.rate_limit, self.leak, self.integral = rate_limit, leak, 0.0

    def tick(self, g, tau_cmd, contact):
        p = self.detect_slip(contact)                # 定义 544 统计量
        self.integral = (1 - self.leak)*self.integral + p
        desired = self.reflex_law(p, contact, g, tau_cmd, self.integral)
        dtau = desired - tau_cmd
        dtau = project_onto(self.envelope(g, contact, tau_cmd), dtau)
        dtau = clip(dtau, -self.rate_limit, self.rate_limit)   # 抗饱和
        return tau_cmd + dtau

    def envelope(self, g, contact, tau):
        return ConvexSet([                         # 定义 545
            lambda d: contact.fn(tau+d) <= F_N_MAX,
            lambda d: contact.mu_margin(tau+d) >= g.cert.m_mu - self.delta_r,
            lambda d: abs(tau+d) <= TAU_MAX,
            lambda d: abs(d) <= DTAU_MAX,
        ])


# IP-360 DexterousSkillGraph：带证书传递的技能编排（定义 548，P16）
class DexterousSkillGraph:
    def __init__(self, nodes, edges):
        self.V, self.E = nodes, edges

    def transition_ok(self, e, cert_src, state):
        return (e.pre(state) and
                cert_strength(cert_src) >= e.pre_strength and
                cert_strength(e.post_cert(state)) >= e.pre_strength)

    def plan(self, start, goal, cert0, state):
        # 证书约束下的最短路；不可行边直接删除
        frontier, dist, prev = [start], {start: 0.0}, {}
        while frontier:
            u = min(frontier, key=dist.get); frontier.remove(u)
            for e in self.E.get(u, []):
                if not self.transition_ok(e, cert0, state):
                    continue
                v, w = e.v, e.cost
                if dist.get(v, INF) > dist[u] + w:
                    dist[v], prev[v] = dist[u] + w, u
                    frontier.append(v)
        return reconstruct(prev, start, goal)
```

## 4. 推导

**引理 87（三类误差下的证书折减）** 设 γ_fc、m_μ、m_τ 关于位姿 x、摩擦 μ、协同误差 e 均 Lipschitz，常数如定义 543。则对任意真实 (x,μ,e) 满足 ‖Δx‖≤ε_x、|Δμ|≤ε_μ、‖e‖≤ε_s：
```
γ_fc^true ≥ γ_fc − L_γx ε_x − L_γμ ε_μ − L_γs ε_s = Ḡ.γ_fc
```
m_μ、m_τ、ε_g 同理。证明：由 Lipschitz 性与三角不等式，
|γ_fc(x+Δx, μ+Δμ, e) − γ_fc(x,μ,0)| ≤ L_γx‖Δx‖ + L_γμ|Δμ| + L_γs‖e‖ ≤ 折减量；取最坏方向即得下界。∎
**推论**：若 Ḡ 各项 ≥ 阈值，则真实抓取满足力封闭、摩擦锥与力矩约束（以定义域内的 Lipschitz 界为前提）。

**引理 88（反射包络保力封闭且不越权）** 设 Ḡ(g) 可靠，τ ∈ 名义可行域，Δτ ∈ R(g)。则 (i) 施加 τ+Δτ 后摩擦锥裕度 ≥ Ḡ.m_μ^min + δ_r > m_μ^min；(ii) 关节力矩不超 τ_max；(iii) 反射不改变 Ḡ，故不改变后续规划所依赖的证书。证明：(i)(ii) 直接由 R(g) 的逐项约束；(iii) TRL 的输出写回指力而非证书存储，且定义 544 规定只读。∎

**引理 89（反射-规划有界共存，无大振幅极限环）** 在接触线性化与准静态假设下，若 (a) 优先级格 549 无环，(b) 包络预留 δ_r>0，(c) 反射积分带泄漏 λ>0 且速率限幅，(d) 规划器仅于块边界（≥200ms）更新目标，则混合系统无 Zeno，且接触力进入并停留在区间 [f_floor, f_ceil]，区间宽度 ≤ Δτ_max；任何振荡振幅 ≤ δ_r/λ，故不存在大振幅极限环。证明思路：定义 V=(f−f*)²；两次规划更新之间目标 f* 固定，反射在 R(g) 内单调逼近 f_floor，泄漏项使积分不累积；规划更新把 f* 移动不超过 δ_r，故 V 在每个更新周期内下降，除滑移重触发外无能量注入。∎
**限定**：该结论依赖线性化接触模型；强非线性/多接触耦合下的严格性由 E576 经验检验，不声称无条件成立。

**引理 90（抓取-分块组合安全）** 若块 ζ 的空间证书（v9 引理 82）与抓取持久不变式（定义 546）同时成立，则块内执行要么始终保持力封闭（m_μ ≥ m_μ^min），要么在某个 k*≤K 命中再抓取点 r_{k*} 并执行已认证 g'。故掉落概率满足：
```
P(drop) ≤ P(Ḡ 不可靠) + P(滑移未被 TRL 检出 | 滑移发生)
        ≤ P(ε_x 超界) + P(ε_μ 超界) + P(ε_s 超界) + (1 − recall_TRL)
```
证明：定义 546 保证预测轨迹在摩擦锥内留 β_g；若真实偏差超出预测（因 ε 估计失效），则由定义 547 的检查点与 549 的抢占顺序，系统必在最近 r 处切换到已认证 g' 或安全释放；两种失败源分别对应证书不可靠与反射漏检，取并集界。∎

**引理 91（技能图证书传递）** 对 DSG 上任一路径 v₀→v₁→…→v_m，若初始证书可靠且每条边 e_i 满足 post(v_{i-1}) 的证书强度 ≥ pre(v_i) 所需强度，则所有技能在其前置条件内执行，安全不变式沿路径保持。证明：对路径长度归纳。基例为初始证书；归纳步由 P16 的传递义务与 Ψ_e 的定义直接得到。∎

**引理 92（接触层中立元退化到 v9）** 对定义 550 每一行注入 v^⊥，系统可观测行为与 v9 对应模式逐位一致：TRL 失效 ⇒ Δτ≡0，即 v9 无反射开环抓取；DSG 失效 ⇒ 单原子 pick-place，即 v9 把抓取视为原子的 PrimitiveGraph；GCert 失效 ⇒ 不做新抓取，仅 v9 几何路径；DGP 失效 ⇒ 保持/释放，v9 无灵巧规划；摩擦估计失效 ⇒ μ̂=μ_min，即 v9 的固定摩擦假设。接触层整体失效则完全回到 v9 ACMD。结合引理 83（v9→v8）与 v8 严格退化链，得 v10→v9→v8→v7→v6 的严格等价链。∎

## 8. 本轮最大风险

**一句话**：抓取证书的可靠性最终压在摩擦系数估计上，而滑移恰恰是摩擦估计失效的**事后**信号——1kHz 反射能救一次打滑，却不能修正证书已错的 μ 假设，于是"反射越灵敏，越可能掩盖证书的系统性偏差"，形成"越滑越信、越信越快滑"的错觉。
