# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 7 轮；本轮灵感：「位姿估计」×「步骤分」）

> 第 60 轮把执行层升级为「认知驱动的场景-执行闭环」：SSM 场景语义先验、CIEC 意图约束锁定、EPIR 因果隔离、SERC 闭环、PCE++++ 认知预算。但它把两件事当成了「免费且确定」的：**坐标系**与**成功判据**。
> 1. **几何锚点缺失**：所有阻抗 `K_safe`、场景先验 `π_scene(K|z)`、意图约束 `C_intent` 都必须表达在某个任务坐标系 `T` 中，而 `T` 由物体/末端位姿 `ξ` 决定。第 60 轮从未建模 `ξ` 及其不确定性 `Σ_ξ`——**同一个 `K_safe` 在错误位姿下会产生完全不同的接触力**。位姿估计误差是第 60 轮所有安全证书共同的「隐藏变量」，却从未进入证书。
> 2. **步骤分不可证**：第 60 轮的闭环目标仍是探针的二元成败（`D⁺`/ECE）。但真实赛题（UniBot 等）按**步骤分/部分分**评分：抓取、抬升、放入、按钮按下各占权重。当前系统既没有稠密进度信号，也无法把「已完成多少」变成可核验证据；预算 `B_cog` 只能押注整任务，失败即全损，且无法防「分数幻觉」。
> 3. **位姿跳变与场景变化不可分**：SSM 从遥测判断场景切换，但**位姿漂移/重定位跳变**与**真实场景变化**在力/位置遥测上几乎同形。第 60 轮会把一次位姿失效误判为「换场景」，切到错误先验——这正是第 60 轮自陈最大风险的物理来源。

## 0. 直觉与动机

**灵感 1（位姿估计 → 位姿接地安全 PGT / PIG）**
直觉：阻抗不是「真实的力」，而是「K 乘以位移」。位移是相对的，必须有一个位姿锚点。**若位姿估计的不确定度是 5 mm，那么超过某个刚度的 K 在统计上一定会顶穿力限**。所以位姿不确定性不是感知层的内部事务，它直接给执行层的刚度设了一个**上限**：

```
K ≤ F_tol / (Δx_nom + J_max · r_pose(Σ_ξ))
```

这给出一条新原则：**「高刚度特权」必须由「高置信位姿」购买**。位姿不够准，就只能变柔，或先主动重测位姿——而不是自欺欺人地照用标称 K。

**灵感 2（步骤分 → 位姿支撑步骤证书 PBSC）**
直觉：比赛里的步骤分最怕两件事——**多报**（没做到却说做到）与**漏报**（做到了没证据）。位姿恰好是判据：一个子目标（如「物体到达槽内」「末端到预抓取位姿」）本质是位姿空间中的流形 `M_i` 加容差 `ε_i`。是否完成就是一个**统计检验**：

```
(ξ̂ ⊖ ξ*)ᵀ (Σ_ξ + ε²I)⁻¹ (ξ̂ ⊖ ξ*) ≤ χ²_{d,1-α}
```

于是步骤分不再是自报，而是**由位姿见证 + EPIR 证据链签发的证书**；假阳性率 `α` 可标定。这直接防止「分数幻觉」。

**灵感 3（两者合流 → 位姿是执行证据与步骤分的共同货币）**
直觉：第 60 轮的 EV-exec 是「力/位置/时间」的流水，步骤分是「任务完成度」。位姿是唯一能同时翻译两者的量：把 EV-exec 的接触点投到物体坐标系，就是几何进度；把子目标流形投到世界坐标系，就是评分判据。**以位姿为共同货币，把执行证据兑换成可核验的步骤分**——这是本轮的核心命题。

**灵感 4（位姿-场景消歧 PDS）**
直觉：位姿失效与场景变化都会让遥测「跳」，但指纹可分：场景变化时**配准内点率仍高、位姿轨迹连续**，只是力特征改变；位姿失效时**内点率骤降、位姿新息与协方差暴涨**，力特征可能连续。用二元似然比分开二者：判为位姿失效 ⇒ 冻结场景先验、触发重定位；判为场景变化 ⇒ 才更新 SSM。这把第 60 轮「先失败后回退」的误判路径提前切断。

**灵感 5（PCE+++++ → 位姿/步骤分预算）**
直觉：位姿估计要算力（关键帧率、配准迭代、重定位），步骤分核验也要算力（稳定性窗口、去认证）。纳入预算后：`B_pose` 不足 ⇒ 保守固定坐标系 + 加位姿不确定性地板；`B_score` 不足 ⇒ 只记二元证书、放弃细粒度部分分；任一预算耗尽都触发对应安全策略，且**永远不为追分牺牲执行安全**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（位姿接地任务坐标系 PGT）** 位姿模型 `Γ_pose = (ξ, Σ_ξ, T, g)`。其中：
- **位姿与协方差**：`ξ ∈ SE(3)` 为物体/工具/末端锚点位姿，估计 `ξ̂`，局部协方差 `Σ_ξ ∈ R^{6×6}`（平移块 `Σ_p`、旋转块 `Σ_r`）。
- **任务坐标系**：`T(ξ) = exp(ξ^) · T_0`，阻抗 `K ∈ SPD(d)` 表达在 `T` 中（d=3 平移，或 6 全身）。
- **接地映射**：`g_{W←T(ξ)}` 把任务坐标投到世界坐标；接触位移对位姿的雅可比 `J_ξ = ∂(世界接触位移)/∂ξ`，工作域内 `||J_ξ|| ≤ J_max`。
- **位姿半径**：`r_pose(Σ_ξ) = sqrt(λ_max(Σ_p)) · χ_{3,1-α}`（3σ 椭球半径；稳健场景可用 `r_pose = 3·sqrt(tr(Σ_p)/3) + r_floor`）。
- **位姿条件安全集**：

```
K_safe^pose(ξ̂, Σ_ξ) = { K ∈ K_safe^scene :
    ||K|| · ( ||Δx_nom|| + J_max · r_pose(Σ_ξ) ) + F_noise ≤ F_tol }
```

位姿越不确定，允许的刚度上限越低。注意 `K_safe^pose ⊆ K_safe^scene ⊆ K_safe_base`：**位姿不确定性只会收窄安全集，从不会放宽它**。

**定义 162（位姿不确定性阻抗护栏 PIG）** 给定任务最低刚度 `K_min^task`（保证跟踪误差 ≤ ε_track 所需）与位姿条件上限 `K_max^pose = F_tol / (||Δx_nom|| + J_max·r_pose + F_noise/||K||)`：
- **可行区间**：`I_K = [K_min^task, K_max^pose]`。
- **护栏**：`PIG(K, Σ_ξ)`：若 `I_K = ∅` 返回 `POSE_SAFETY_INFEASIBLE`；若 `K > K_max^pose` 返回 `clamp(K_max^pose)`；否则返回 `K`。
- **不可行恢复**：当 `I_K = ∅`，不强行降刚度（降到任务下限以下会跟踪失败），而是选主动感知动作

```
a* = argmax_{a ∈ {move_camera, tactile_probe, regrasp, relocalize}}
       ΔE[λ_max(Σ_ξ) | a] / cost(a)
```

先降低位姿不确定性，再重编译阻抗。这把「位姿不安全」从**隐性失败**变成**显式、可规划的动作**。

**定义 163（位姿支撑步骤证书 PBSC）** 任务分解为子目标 DAG `G_S = (S, ≺)`，子目标 `s_i = (M_i, ε_i, w_i)`：
- `M_i ⊂ SE(3)` 为完成流形（如物体位姿落在目标槽的面内位姿 + 朝向锥），`ε_i` 为容差，`w_i ≥ 0` 为该步权重（`Σ w_i = 1` 或总分为 100）。
- **位姿见证**：`W_i = (ξ̂_i, Σ_i, t_i, seq_i, hash_i)`，其中 `seq_i/hash_i` 来自 EPIR，保证证据链完整。
- **认证谓词**：

```
certified(s_i) ⇔ d_i² = (ξ̂_i ⊖ ξ*_i)ᵀ (Σ_i + ε_i²I)⁻¹ (ξ̂_i ⊖ ξ*_i) ≤ χ²_{d,1-α}
                 ∧ pred(i) 已 final-bank ∧ seq_i 连续
```

- **步骤分**：二值认证下 `s_i = w_i` 当且仅当 `certified`；细粒度模式取 `s_i = w_i · clip(1 - d_i²/(ε_i²·χ²), 0, 1)`，但只有 `certified` 的那部分才能进最终账本。
- **证书**：`C_i = (i, W_i, d_i², α, evidence_seq_range, signer)`。
- **可靠性**：若 `Σ_i` 已标定，则 `P(certified(s_i) | s_i 未真正完成) ≤ α`——这就是「分数不是自报，是可核验的位姿证书」。

**定义 164（部分分规划器 PCP）** 给定 `G_S`、每步期望代价 `c_i`（时间/能量/`B_cog`）、成功概率 `p_i`（随 `Σ_ξ` 降低而升高）、权重 `w_i`：
- **目标**：

```
max_π E[ Σ_i w_i · 1[certified(s_i)] ]   s.t.  Σ_i c_i(π) ≤ B_total,  依赖 ≺ 满足
```

- **信用密度**：`ρ_i = (p_i · w_i) / c_i`；贪心按 `ρ_i` 选可执行步。
- **结构**：带优先约束的随机背包是 NP-hard；链/串并联 DAG 用 `O(|S|·B)` DP 精确解；一般 DAG 用贪心（对背包松弛有 2-近似）并以 DP 为小规模 oracle。
- **与第 60 轮的区别**：整任务不可行时不再直接 `DEGRADE_EXEC`，而是返回**最大信用的子目标集合**（部分分前缀），把「失败」变成「拿到能拿的分」。

**定义 165（位姿-场景变化消歧器 PDS）** 证据向量 `e = (ρ_reg, ν_pose, D_f, r_lc)`：配准内点率、归一化位姿新息 `ν_pose = ||ξ̂_t ⊖ ξ̂_{t⁻}||²_{Σ}`、力特征散度、回环残差。两假设：
- `H_scene`：真实场景变化（`ρ_reg` 高、`ν_pose` 小、`D_f` 大）。
- `H_pose`：位姿失效/漂移/重定位（`ρ_reg` 低、`ν_pose` 大、`Σ_ξ` 膨胀、`D_f` 可连续）。
- **判决**：

```
Λ(e) = log p(e|H_scene) - log p(e|H_pose)
Λ > τ_s  ⇒ H_scene：更新 SSM 的 κ_scene 与 π_scene
Λ < τ_p  ⇒ H_pose ：冻结 π_scene，膨胀 Σ_ξ 地板，触发重定位/重观测
τ_p ≤ Λ ≤ τ_s ⇒ 继续采样（SPRT，直到置信或超时）
```

- **意义**：第 60 轮的 SIC「场景置信度」从此改为**在 `H_scene` 下才更新**；`H_pose` 下的位姿跳变不再污染场景先验。

**定义 166（部分分银行 PCB）** 账本分两层：
- **暂定账 `B_tent`**：刚认证、仍在稳定性窗口 `Δt_stab` 内的步骤。
- **终账 `B_final`**：通过 `Δt_stab` 无矛盾证据的步骤，`S_t = Σ_{i∈B_final} w_i`。
- **去认证**：若后续证据与已终账步骤矛盾（如「已放入」后物体位姿离开流形且持续），签发 `C_i^revoke`，把 `i` 从终账移出并记录审计链。默认只允许对 `B_tent` 回退，终账回退需显式撤销证书。
- **退化策略**：预算耗尽或 `POSE_SAFETY_INFEASIBLE` 时，策略**停在当前最大已验证信用**并返回 `(S_t, {C_i})`，绝不为了追分执行不安全动作。

**定义 167（几何接地步骤分闭环 GSEL）** 算子 `GSEL(M, task, budget)`：

```
① PCP:  plan ← pcp.select(G_S, budget)                    # 按信用密度排序子目标
② for s_i in plan:
③   PGT:  ξ̂_i, Σ_i ← pose_estimator.estimate(s_i.target)   # 位姿 + 协方差
④   PIG:  K_i ← pig.guard(K, Σ_i)
⑤         if K_i = POSE_SAFETY_INFEASIBLE:
⑥             a* ← pig.recovery_action(Σ_i); execute(a*); continue
⑦   CLEP+: K_safe ← EEIS.compile(delta_f_req, fused, ξ_exec, Z_env, K_i)
⑧   Dispatch → Execute → EV-exec
⑨   PBSC: C_i ← pbsc.certify(s_i, ξ̂_i, Σ_i, EV_exec)
⑩   PDS:  if pds.classify(evidence) = H_pose: freeze_scene(); relocalize()
⑪         if pds.classify(evidence) = H_scene: SSM.update(κ_scene, π_scene)
⑫   PCB:  if C_i.certified: bank_tentative(C_i); after Δt_stab: bank_final(C_i)
⑬   budget.consume(B_pose, B_score, B_exec)
⑭       if any_budget_exhausted: return pcb.report(), DEGRADE_RULE
⑮ return pcb.report()  # (S_t, final certificates, decertification log)
```

**定义 168（位姿-步骤分预算 PCE+++++）** `B_geo = (B_pose, B_score, B_scene, B_intent, B_ros, B_exec)`：
- `B_pose = (Keyframe_rate, Registration_budget, Relocalization_budget, Σ_floor)`
- `B_score = (Certification_checks, Stability_window, Decertification_budget)`
- 其余沿用第 60 轮。VOI 扩展：

```
voi_geo(π) = VOI_meta_pessimistic(π) - cost_cog(π) - cost_pose(π) - cost_score(π)
cost_pose  = λ_pose·Registration_cost + λ_reloc·Relocalization_cost
cost_score = λ_cert·Certification_cost + λ_stab·Stability_window_cost
```

降级：`B_pose < θ_pose` ⇒ `Σ_floor` 抬升、固定保守坐标系；`B_score < θ_score` ⇒ 只记二元证书；`B_scene/B_intent/B_ros/B_exec` 耗尽沿用第 60 轮策略。

## 2. 关键算法伪代码

### IP-161/162 PGT + PIG（位姿接地与阻抗护栏）

```python
class PoseGroundedImpedance:
    def __init__(self, F_tol, J_max, alpha=0.95, r_floor=1e-3):
        self.F_tol = F_tol
        self.J_max = J_max
        self.chi3 = chi2.ppf(alpha, df=3)
        self.r_floor = r_floor

    def pose_radius(self, cov_p):
        r = math.sqrt(max(np.linalg.eigvalsh(cov_p)[-1], 0.0)) * self.chi3
        return max(r, self.r_floor)

    def k_max_pose(self, dx_nom, cov_p, f_noise=0.0):
        r = self.pose_radius(cov_p)
        return self.F_tol / (abs(dx_nom) + self.J_max * r + 1e-9) - f_noise

    def guard(self, K, K_min_task, dx_nom, cov_p):
        k_max = self.k_max_pose(dx_nom, cov_p)
        if K_min_task > k_max:
            return None, {'feasible': False, 'K_max': k_max, 'K_min': K_min_task}
        return min(K, k_max), {'feasible': True, 'K_max': k_max, 'K_min': K_min_task}
```

> 数值示例（标量平移，`F_tol=30 N`、`Δx_nom=2 mm`、`J_max=1.2`）：当 `r_pose=5 mm` 时 `K_max≈3750 N/m`，任务需 `K_min=3000`，可行；当重定位失败使 `r_pose` 涨到 `8 mm` 时 `K_max≈2591 N/m < 3000`，**可行区间为空**——此时正确动作是重测位姿，而不是偷偷用 3000。

### IP-163 PBSC（位姿支撑步骤证书）

```python
class PoseBackedStepCertifier:
    def __init__(self, alpha=0.05):
        self.alpha = alpha

    def certify(self, step, xi_hat, cov, ev_seq):
        r = xi_hat.boxminus(step.xi_star)
        S = cov + (step.eps ** 2) * np.eye(len(r))
        d2 = float(r.T @ np.linalg.pinv(S) @ r)
        thr = chi2.ppf(1.0 - self.alpha, df=len(r))
        ok = (d2 <= thr) and ev_seq.continuous and step.predecessors_final
        score = step.w if ok else 0.0
        return {
            'step': step.id, 'certified': ok, 'd2': d2, 'threshold': thr,
            'score': score, 'xi': xi_hat, 'cov': cov, 'seq': ev_seq,
        }
```

### IP-164 PCP（部分分规划）

```python
def plan_partial_credit(subgoals, budget):
    best = {0.0: (0.0, [])}
    for s in topo_order(subgoals):
        nxt = dict(best)
        for used, (val, chosen) in best.items():
            if s.predecessors_final and used + s.cost <= budget:
                cand = used + s.cost
                nval = val + s.p_success * s.weight
                if cand not in nxt or nval > nxt[cand][0]:
                    nxt[cand] = (nval, chosen + [s.id])
        best = nxt
    return max(best.values(), key=lambda x: x[0])[1]
```

一般 DAG 用 `ρ_i = p_i·w_i/c_i` 贪心；小规模用上式 DP 作 oracle。

### IP-165 PDS（位姿-场景消歧）

```python
def disambiguate(evidence, tau_s, tau_p):
    ll_scene = logpdf_scene(evidence)
    ll_pose = logpdf_pose(evidence)
    lam = ll_scene - ll_pose
    if lam > tau_s:
        return 'H_scene'
    if lam < tau_p:
        return 'H_pose'
    return 'HOLD'
```

### IP-166/167 PCB + GSEL（账本与闭环）

```python
class PartialCreditBank:
    def __init__(self, dt_stab):
        self.dt_stab = dt_stab
        self.tentative = {}
        self.final = {}
        self.revoked = []

    def bank_tentative(self, cert, now):
        self.tentative[cert['step']] = (cert, now)

    def settle(self, now, contradiction):
        for sid, (cert, t0) in list(self.tentative.items()):
            if now - t0 >= self.dt_stab and sid not in contradiction:
                self.final[sid] = cert
                del self.tentative[sid]

    def report(self):
        return sum(c['score'] for c in self.final.values())
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PGT | O(1) 变换复合 / O(K) 位姿图关键帧 | O(K + 6) | 位姿安全集只收窄不放宽 |
| PIG | O(d³) 特征分解 / O(d) 逐轴 | O(1) | `K ∈ K_safe^pose ⇒ P(力超限) ≤ α` |
| PBSC | O(d²) 马氏距离 | O(d²) | 假阳性率 ≤ α（协方差已标定） |
| PCP | O(\|S\|·B) DP / O(\|S\|log\|S\|) 贪心 | O(\|S\|·B) | 链精确；一般 DAG 贪心 2-近似 |
| PDS | O(1)/证据 | O(1) | 可分条件下判决误差随间隔指数下降 |
| PCB | O(\|S\|·Δt) 结算 | O(\|S\|) | 终账单调不减（除显式撤销） |

**正确性定理（GEOSCORE）**：假设 `A66–A70` 成立：
- **(A66) 位姿标定**：估计器一致，`Σ_ξ` 与真实误差匹配（χ² 一致性检验通过），误差落在 `r_pose` 内概率 ≥ `1-α`。
- **(A67) 雅可比有界**：工作域内 `||J_ξ|| ≤ J_max`。
- **(A68) 流形良定**：子目标流形与容差 `(M_i, ε_i)` 明确，认证谓词假阳性 ≤ `α`。
- **(A69) 权重单调**：`w_i ≥ 0`，终账只增不减（除显式撤销）。
- **(A70) 预算单调**：`B_pose/B_score` 单调消耗，耗尽即触发对应降级。

则：
1. **位姿鲁棒力安全**：若 `K ∈ K_safe^pose(ξ̂,Σ_ξ)` 且 `A66/A67` 成立，则 `P(||F|| ≤ F_tol) ≥ 1-α`。
2. **步骤分可靠性**：任一 final-bank 步骤为真完成的概率 ≥ `1-α`；报告分不高于真实分（高概率）。
3. **单调不回退**：`S_t` 沿 final 账单调不减；撤销只作用于有显式 `C_i^revoke` 的步骤。
4. **消歧正确性**：当 `H_scene` 与 `H_pose` 的 `Λ` 间隔 `Δ > 0`，SPRT 的平均判决样本数与错误率随 `Δ` 指数下降。
5. **预算安全**：任一 `B_geo` 分量耗尽 ⇒ 触发对应安全策略，且策略永不降低执行安全下界。

## 2. 核心推导与关键算法

### 2.1 位姿不确定性 → 刚度上界（IP-161/162）

阻抗控制中接触力 `F = K·Δx`。真实位移由「名义位移 + 位姿误差诱导位移」组成：

```
Δx_true = Δx_nom + J_ξ · δξ + noise,     ||δξ|| ≤ r_pose(Σ_ξ)  (以 1-α 概率)
⇒ ||F|| ≤ ||K||·( ||Δx_nom|| + J_max·r_pose(Σ_ξ) ) + F_noise
```

要保证 `||F|| ≤ F_tol`（以 `1-α` 概率），充要条件是

```
||K|| ≤ K_max^pose = (F_tol - F_noise) / ( ||Δx_nom|| + J_max·r_pose(Σ_ξ) )
```

同时任务跟踪要求 `||K|| ≥ K_min^task`。于是：

```
可行 ⇔ K_min^task ≤ K_max^pose
```

**数值示例**（标量平移，`F_tol=30 N`、`F_noise=0`、`Δx_nom=2 mm`、`J_max=1.2`）：

| 位姿半径 `r_pose` | `K_max^pose` | 任务需 `K_min=3000` | 结论 |
|---:|---:|---:|---|
| 2 mm | ≈ 6818 N/m | 可行 | 可用标称刚度 |
| 5 mm | ≈ 3750 N/m | 可行 | 仍有余量 |
| 8 mm | ≈ 2591 N/m | **不可行** | 必须重测位姿，不能偷偷用 3000 |

这条式子是本轮最硬的结论：**位姿不确定度直接买入/剥夺执行层的刚度特权**。

### 2.2 步骤分 = 位姿流形上的统计认证（IP-163）

子目标完成 = 位姿估计落在目标流形容差内，且证据链连续：

```
certified(s_i) ⇔ (ξ̂_i ⊖ ξ*_i)ᵀ (Σ_i + ε_i²I)⁻¹ (ξ̂_i ⊖ ξ*_i) ≤ χ²_{d,1-α}
                 ∧ pred(i)∈B_final ∧ EPIR.seq_continuous
```

- `Σ_i` 已标定时，假阳性（未完成却认证）≤ `α`。
- 证书 `C_i` 绑定 `(W_i, d_i², α, seq_range, signer)`，可被第三方重放核验。
- 细粒度部分分只在 `certified` 前提下按 `d_i²` 打折；**未认证的进度不得进入终账**。

### 2.3 部分分规划（IP-164）

```
max_π E[ Σ_i w_i·1[certified(s_i)] ]  s.t. Σ_i c_i ≤ B_total, ≺ 满足
```

- 信用密度 `ρ_i = p_i w_i / c_i`，贪心优先做「便宜、稳、分高」的步骤。
- 链/串并联 DAG：`O(|S|·B)` DP 精确。
- 一般 DAG：带优先约束的随机背包，NP-hard；贪心对背包松弛 2-近似，小规模用 DP oracle 对拍。

### 2.4 位姿失效 vs 场景变化（IP-165）

```
Λ(e) = log p(e|H_scene) - log p(e|H_pose)
H_scene: 内点率高、位姿新息小、力特征变
H_pose : 内点率低、位姿新息大、协方差膨胀
Λ>τ_s ⇒ 更新 SSM；Λ<τ_p ⇒ 冻结 SSM + 重定位；否则 SPRT 继续采样
```

这直接消解第 60 轮把「位姿跳变」误认为「场景切换」的路径。

### 2.5 部分分银行（IP-166）

```
B_tent --(Δt_stab 无矛盾)--> B_final      # 默认只对暂定账回退
B_final --(显式矛盾证据)--> 撤销 + C_i^revoke  # 留审计链
S_t = Σ_{i∈B_final} w_i                  # 单调不减（除显式撤销）
```

## 3. 关键算法伪代码

### IP-161/162 PGT + PIG

```python
class PoseGroundedImpedance:
    def __init__(self, F_tol, J_max, alpha=0.95, r_floor=1e-3):
        self.F_tol, self.J_max = F_tol, J_max
        self.chi3 = chi2.ppf(alpha, df=3)
        self.r_floor = r_floor

    def pose_radius(self, cov_p):
        r = math.sqrt(max(np.linalg.eigvalsh(cov_p)[-1], 0.0)) * self.chi3
        return max(r, self.r_floor)

    def guard(self, K, K_min_task, dx_nom, cov_p, f_noise=0.0):
        r = self.pose_radius(cov_p)
        k_max = (self.F_tol - f_noise) / (abs(dx_nom) + self.J_max * r + 1e-9)
        if K_min_task > k_max:
            return None, {'feasible': False, 'K_max': k_max, 'K_min': K_min_task}
        return min(K, k_max), {'feasible': True, 'K_max': k_max, 'K_min': K_min_task}
```

### IP-163 PBSC

```python
def certify_step(step, xi_hat, cov, ev_seq, alpha=0.05):
    r = xi_hat.boxminus(step.xi_star)
    S = cov + (step.eps ** 2) * np.eye(len(r))
    d2 = float(r.T @ np.linalg.pinv(S) @ r)
    thr = chi2.ppf(1 - alpha, df=len(r))
    ok = bool(d2 <= thr and ev_seq.continuous and step.predecessors_final)
    return {'step': step.id, 'certified': ok, 'd2': d2, 'threshold': thr,
            'score': step.w if ok else 0.0, 'xi': xi_hat, 'cov': cov, 'seq': ev_seq}
```

### IP-164 PCP（链/小规模精确 DP）

```python
def plan_partial_credit(subgoals, budget):
    best = {0.0: (0.0, [])}
    for s in topo_order(subgoals):
        nxt = dict(best)
        for used, (val, chosen) in best.items():
            if s.predecessors_final and used + s.cost <= budget:
                cand = used + s.cost
                nval = val + s.p_success * s.weight
                if cand not in nxt or nval > nxt[cand][0]:
                    nxt[cand] = (nval, chosen + [s.id])
        best = nxt
    return max(best.values(), key=lambda x: x[0])[1]
```

### IP-165 PDS

```python
def disambiguate(evidence, tau_s, tau_p):
    lam = logpdf_scene(evidence) - logpdf_pose(evidence)
    if lam > tau_s:
        return 'H_scene'
    if lam < tau_p:
        return 'H_pose'
    return 'HOLD'
```

### IP-166/167 PCB + GSEL

```python
def gsel_loop(M, task, budget):
    bank = PartialCreditBank(dt_stab=M.dt_stab)
    plan = plan_partial_credit(task.subgoals, budget.remaining())
    for s in plan:
        xi_hat, cov = M.pose.estimate(s.target)
        K, info = M.pig.guard(M.K, s.K_min, M.dx_nom, cov.P)
        if K is None:
            M.execute(M.pig.recovery_action(cov))
            continue
        K_safe = M.eeis.compile(M.delta_f_req, M.fused, M.xi_exec, M.Z_env, K)
        ev = M.execute_clep(K_safe)
        cert = certify_step(s, xi_hat, cov, ev.seq)
        h = disambiguate(ev.evidence, M.tau_s, M.tau_p)
        if h == 'H_pose':
            M.freeze_scene(); M.relocalize()
        elif h == 'H_scene':
            M.scene_model.update(M.telem_force, M.telem_pos)
        if cert['certified']:
            bank.bank_tentative(cert, ev.t)
        bank.settle(ev.t, contradiction=M.check_contradiction())
        budget.consume(M)
        if budget.exhausted():
            return bank.report(), budget.degrade_rule()
    bank.settle(M.now(), contradiction=M.check_contradiction())
    return bank.report(), bank.final
```

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| PGT | O(1) 变换 / O(K) 关键帧 | O(K+6) | `K_safe^pose ⊆ K_safe^scene`（只收窄） |
| PIG | O(d³) 特征分解 | O(1) | 认证条件下 `P(力超限) ≤ α` |
| PBSC | O(d²) 马氏距离 | O(d²) | 假阳性 ≤ α（协方差标定） |
| PCP | O(\|S\|·B) DP / O(\|S\|log\|S\|) 贪心 | O(\|S\|·B) | 链精确；一般 DAG 2-近似 |
| PDS | O(1) | O(1) | 可分间隔越大，SPRT 错误率指数下降 |
| PCB | O(\|S\|·Δt) | O(\|S\|) | 终账单调不减（除显式撤销） |

**正确性定理（GEOSCORE）**：若 `A66–A70` 成立（位姿标定、雅可比有界、流形良定、权重单调、预算单调），则：
1. **力安全**：`K ∈ K_safe^pose ⇒ P(||F||≤F_tol) ≥ 1-α`。
2. **得分可靠**：final-bank 步骤为真完成的概率 ≥ `1-α`；报告分不高于真实分（高概率）。
3. **单调不回退**：`S_t` 沿 final 账单调不减。
4. **消歧**：`H_scene/H_pose` 可分时，判决错误率随间隔指数下降。
5. **预算安全**：任一 `B_geo` 分量耗尽 ⇒ 对应降级，且不降低安全下界。

**退化关系（消融对照）**：

```
去掉 PGT/PIG（固定标称 K）        → 逐字回到第 60 轮，位姿噪声下力超限暴露
去掉 PBSC（自报步骤分）            → 分数幻觉，假阳性不可控
PBSC 用欧氏距离替代马氏距离        → 忽略协方差各向异性，假阳性升高
PCP 只做整任务（all-or-nothing）   → 低预算下步骤分显著下降
去掉 PDS（SSM 直接吃位姿跳变）     → 误切场景率回到第 60 轮水平
PCB 取消稳定性窗口（立即终账）     → 假进度直接入账，去认证率上升
```
