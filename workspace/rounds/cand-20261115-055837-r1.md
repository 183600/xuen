# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「成功率」×「竞赛策略」）

> R69 把不确定性拆成 aleatoric 与 epistemic，用「流匹配多模态策略 + 主动交互」去消解后者：系统终于会问「我该向谁求证」。但它仍是一个**单局、单步风险**的世界观——每一步都在问「这一动作风险多大」，却从不问「**我这一整场能赢吗、我到底在为哪个分数去赢**」。R69 的成功是「每一步都不出错」的局部最优；竞赛的成功是「在有限次机会、有限对手、明确排名规则下拿到名次」的全局最优。这两者之间隔着一整个**统计层**。
>
> 本轮两个灵感正好补上这一层：
> - **成功率**不是一个数字，而是一个**带置信区间的随机变量**：它由有限次、可截尾（超时即失败）、且分布可能漂移的试验估计而来。把点估计当真理，是 R68「标定吸收」在统计层的翻版——**分数也会骗人**。
> - **竞赛策略**的核心不是「期望收益最大」，而是「**在排名/名次规则下，用有限次尝试、面对会读你策略的对手，风险最优**」：领先要守、落后要搏；策略要随机以免被针对；每一局都要为「整场」服务，而不是为「这一步」服务。
>
> 核心命题：**把 R69 的「每步风险最小化」升级为「整场成功率-排名风险组合优化」，并让 R69 的交互消歧成为这个更大 VoI 问题在「元层无利可图」时逐指令退化的边界。** 命名 **ARENA-RAS**（Adversarial Rank-aware Estimation of success with Nested Attempts）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我在优化的分数，是否就是我想赢的那场比赛**」——从「不做错」到「赢得对」。

## 0. 直觉与动机

**灵感 1（成功率 → 它是一个分布对象，不是标量）**
直觉：排行榜上写「成功率 92%」，读起来像一个确定事实；但它是「n 次试验里成功了 k 次」的**估计**。n 小、任务难、有超时截尾、测试集还可能和训练集重叠——同一个 92% 背后可以是「稳如老狗」也可以是「运气好 + 刷题」。R69 已经教我们不信单一传感器残差；本轮要把同样的怀疑投向**自己的战绩**：成功率必须带**置信下界**与**分布鲁棒半径**，否则「我很强」只是自证。
严谨地说：把「一局成功」建成随机变量 S∈{0,1}，成功率 p(π;𝒟,Ω)=E_{τ~𝒟,ω~Ω}[S]。可见量只有有限样本与截尾时间。估计器输出的是 LCB（下置信界）而非点估计，且对任务分布漂移取最坏情形（DRO）。

**灵感 2（竞赛策略 → 它优化的是顺序统计量，不是期望）**
直觉：单人任务里「期望收益最大」就够了；竞赛里你拿第几名取决于**别人**的分数，是一个**顺序统计量**问题。领先 1 分时，稳妥拿 0.5 分比 50% 概率拿 3 分更值；落后 10 分且只剩一局时，稳稳拿 0.5 分是必输，必须去搏 3 分。也就是说，**风险偏好本身应由记分牌状态决定**：领先→风险规避（守），落后→风险寻求（搏）。这不是拍脑袋，而是排名收益函数在阈值两侧的凹凸性决定的。
严谨地说：名次 R=1+Σ_i 1[X_i>X]，目标 max P(R≤r*) 或 max E[U_rank(X)]，其中 U_rank 是阈值 t_{r*}（场地第 r* 名的分数）附近的 S 形函数；均值-方差（乃至二阶随机占优/凸序）分析给出「何时加方差有益」的判据。

**灵感 3（有限尝试 → 探索从「免费」变成「稀缺预算」）**
直觉：R69 的交互预算约束的是**每一步**的信息动作；竞赛的预算约束的是**整场只有 A 次尝试**。一次尝试既可能是「拿分」，也可能是「弄清对手/场地/自己到底行不行」。于是分配问题变成**预算化 bandit**：把有限的局花在「稳拿胜场」还是「消除关键不确定性」上。成功率的不确定性越大，单次尝试的**信息价值**越高——这与 R69 的 VoI 是同一个算子，只是作用在「能力/场地信念」而非「动作模态」上。
严谨地说：在尝试预算 A 下最大化 P(总胜场 ≥ w*)，等价于对任务类做带终局约束的 best-arm/Thompson 分配；每局的边际价值 = 边际胜率 + 信息增益。

**灵感 4（对手会读你 → 可预测性本身是漏洞）**
直觉：如果对手能从你的历史推断你下一步必走保守路线，他就会针对你。竞赛策略因此需要**受控随机化**：在安全且已认证的策略集上做混合，让对手无法低代价预测。但随机化有代价（平均收益下降）且危险（越出安全包络），所以必须给「不可预测性」标价：隐藏带来的收益要能补偿效用损失，且随机化的支撑集永远落在认证集内。
严谨地说：max H(μ) s.t. E[u]≥u_0, KL(μ‖μ_ref)≤κ, supp(μ)⊆Σ_cert；Pinsker 给出对手可获得的推断优势上界 √(κ/2)，即「隐藏预算」是有限且可审计的。

**灵感 5（成功率会被刷高 → Goodhart 是 R68 反吸收引理的竞赛版）**
直觉：R68 最怕「缓变故障被标定吸收」，因为通道在自己测自己；竞赛最怕「**分数被刷高而任务没做成**」——仿真漏洞、评测集泄漏、奖励黑客、只练可见题。二者的结构完全相同：**一个只用自己选择分数的系统，无法审计自己是不是在优化错的东西**。R69 的「被证实的错误」在 R70 升级为「**被刷高的成功**」：更系统、更自我强化、更难事后发现。
严谨地说：若「真实能力提升」与「分数泄漏/过拟合」在选择分布 𝒟_select 上诱导相同的分数律，则任何只依赖 𝒟_select 的检验功效为 0（风险 ≥ 1/2）；必须引入与 𝒟_select 不相交的留出通道 + 行为签名，才可能识别。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（ARENA-RAS 总览）** ARENA-RAS = (SRE, RRA, RCM, MAV, ABM, GGC, SLD, CSC, CCS, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **安全支配序**（定义 320）：物理安全 ≻ 合法性 ≻ 任务成功 ≻ 排名收益 ≻ 风格/隐藏；竞赛层只能对**已通过 R69 C-RAS-WM 认证**的动作重新排序，绝不扩大安全包络；
(iii) **统计诚实**：成功率以分布鲁棒 LCB 进入决策，禁止把点估计当期望；ECE/覆盖率越界即退回 R69 纯保守；
(iv) **分数-任务一致性**：所有排名决策必须同时报告留出集 LCB 与行为签名，单靠选择集分数不得定案。

**定义 311（成功率的随机过程，含截尾与竞争风险）** 一局由任务 τ~𝒟、场地/对手 ω~Ω、策略 π 决定。成功指示 S=1[任务在 T_max 内完成 ∧ 全部硬约束满足]。观测为 (S_i, c_i, t_i)：c_i=1 表示超时/中止（右截尾）。真实成功率 p(π;𝒟,Ω)=E[S]。超时与主动失败作为**竞争风险**处理（Aalen–Johansen），不能把截尾当成功或失败。

**定义 312（SRE：分布鲁棒成功率下界）** 经验成功率 p̂=k/n。在 1-Lipschitz 损失下有
p_L = max{0, p̂ − ρ_DRO − √(log(1/δ)/(2n))}，
其中 ρ_DRO 为任务/场地分布的 W₁ 半径（A100）。小样本时用 Clopper–Pearson 精确下界替代正态近似；有截尾时用 Kaplan–Meier/Aalen–Johansen 的 log–log 下界。**p_L 是本轮所有「能不能打」判断的唯一合法输入**，而非 p̂。

**定义 313（排名收益与顺序统计阈值）** 场地 N 个对手分数 {X_i}，我方 X。名次 R=1+Σ_i 1[X_i>X]。排名收益 U_rank(X)=P(R≤r*)。设 t_{r*}=场地的第 r* 高分（顺序统计量）。用平滑 S 形代理 U^σ_rank（logistic，宽度 σ）保证可微（A99）：它在 t_{r*} 下方凸、上方凹。

**定义 314（RRA：排名感知风险偏好）** 状态 s_c=(X, {X_i}, 剩余尝试 a, 名次目标 r*)。定义风险偏好 θ(s_c)∈[θ_min,θ_max]，决策目标
max_μ E_μ[X] − θ(s_c)·CVaR_α(−X)（或等价地 max E[U^σ_rank]），
并令 θ 随「落后幅度 × 尝试紧迫度」单调下降：领先→θ 大（守，压方差）；落后且机会将尽→θ 小甚至为负（搏，抬方差）。切换点由引理 20 给出。

**定义 315（RCM：场地模型与 minimax 后悔）** 场地模型是对手混合策略分布 𝒫_field。我方混合 μ∈Δ(Σ_cert)。定义最坏情形后悔
Reg(μ)=max_{σ∈Σ_field}[ max_{μ'} u(μ',σ) − u(μ,σ) ]。
用在线镜像下降/EXP3 在 T 局上求 μ，使平均后悔 ≤ D√(log|Σ|/T)；每步结果投影回 Σ_cert（已认证策略集）。

**定义 316（CSC：受控策略隐藏）** 在认证集上求
μ* = argmax_μ H(μ) s.t. E_μ[u] ≥ u_0，KL(μ‖μ_ref) ≤ κ，supp(μ)⊆Σ_cert。
κ 为**隐藏预算**；对手由历史反推我方策略的推断优势被 Pinsker 界 √(κ/2) 限制。隐藏不得以降低安全裕度为代价（定义 320）。

**定义 317（MAV：两级 value-of-information）** 元层动作 𝒜_meta = {信任当前能力/场地模型、花一局试探、向裁判/人类求证、切换策略、保留尝试}。元层信念 B=(能力信念, 场地信念)。VoI_meta(m)=H(B)−E_{y~p(·|m)}[H(B|y)]，选择 argmax[VoI_meta−c_meta]。对象层 VoI 即 R69 的 MINT（作用于动作模态）。两级可分解（引理 21）。

**定义 318（ABM：尝试预算下的分配）** 尝试预算 A、需胜场 w*。把任务类 i 的后验胜率记为 Beta 后验；目标是 max P(Σ_i W_i ≥ w*)。每类尝试的边际价值 = P(该局决定总胜场跨过 w*) 的增量 + 对能力后验的期望信息增益；按价值贪心/Thompson 分配，并保留一个「探测局」以防能力模型整体失准。

**定义 319（GGC：Goodhart 与泄漏守护）** 记选择集 LCB 为 p_L^{sel}，留出集（与选择/调参不相交，哈希登记）LCB 为 p_L^{hold}。泄漏/过拟合判据：p_L^{sel} − p_L^{hold} > τ_leak，或行为签名检测到奖励黑客/仿真漏洞利用/评测集命中。任一触发 ⇒ **禁止据分数采取激进策略**，退回 R69 纯保守，并把该局标为「不计入能力证据」。

**定义 320（SLD：安全支配序）** 决策按字典序比较：(物理安全裕度 ≥ ε_safe) ≻ (合法性/规则约束) ≻ (任务成功) ≻ (排名收益) ≻ (隐藏/风格)。「搏」只能在字典序前三项不变的前提下提高方差；任何会降低物理安全裕度的动作被硬约束直接剔除，不参与排序。CSC 的随机化支撑集 ⊆ Σ_cert。

**定义 321（CCS：竞赛证书 J_ARENA）** J_ARENA = (J_FLUID, p_L^{sel}, p_L^{hold}, ρ_DRO, n_eff, P(R≤r*), regret_upper, attempt_ledger, field_model_hash, heldout_hash, goodhart_flag, strategy_entropy, arena_ver)。Valid ⇔ Valid(J_FLUID) ∧ p_L^{hold} ≥ p_min ∧ goodhart_flag=false ∧ 尝试预算未越界 ∧ SLD 未被违反 ∧ 隐藏预算 κ 未越界。

**定义 322（VQAuditor-C2：竞赛审计）** 审计对象新增：是否用选择集分数冒充真实能力、是否单源采纳排行榜、策略切换是否有据、隐藏是否越预算、是否在对手模型失配时仍强行「搏」。结论回灌 GGC 与 RCM 先验。

**定义 323（AIC-ARENA 威胁模型）** ℰ_ARENA = ℰ_FLUID × ℰ_compete，ℰ_compete = {沙袋（故意示弱换让分/签位）、对手合谋、任务/评测泄漏、裁判/奖励黑客、可预测性被针对、排行榜投毒}。对抗训练与红队须覆盖「策略层」而非仅「动作层」。

**定义 324（严格包含与退化边界）** 当场地为单点（无对手）、尝试预算 A=1、评分=纯成功率、无分布漂移时：排名项为常数、元层 VoI≤0、θ≡0、μ=δ_{π} ⇒ ARENA 逐指令退化为 FLUID；再令交互 VoI≤成本 ⇒ 退化为 R68。**安全侧永不弱于 R69/R68**（定理 18）。

**定义 325（非平稳场地与记分牌耦合）** 对手会学习、场地会漂移。用变点检测 + 滑动窗口重估 𝒫_field；检测到漂移即重置后悔累积并重算 p_L。记分牌状态 X 与对手分数随时间变化，RRA 每局重算 θ，不做跨局硬编码。

**定义 326（比赛状态机与局间不变量）** 局间允许离线重训/校准（非实时流），但必须满足：重置后安全包络不缩小、证书可重放、隐藏预算清零、尝试账本持久化。禁止在局内做学习写操作（继承 R68 定义 276-i）。

## 2. 关键算法骨架

```python
# IP-264 SRE：成功率的下置信界（截尾 + 分布鲁棒）
def success_lcb(episodes, delta, dro_radius):
    # episodes: (success, censored, time, task_id)
    if any_censored(episodes):
        p_hat = aalen_johansen_rmst(episodes)          # 竞争风险 / 超时
    else:
        p_hat = clopper_pearson_lower(episodes, delta)
    return max(0.0, p_hat - dro_radius - hoeffding_slack(len(episodes), delta))

# IP-265 RRA：排名感知风险偏好（领先守、落后搏）
def risk_appetite(score, field, attempts_left, r_star):
    gap   = order_stat(field, r_star) - score          # >0 落后
    press = 1.0 / max(attempts_left, 1)
    theta = clip(k_gap * gap - k_press * press, theta_min, theta_max)
    return theta                                        # θ↓ = 更敢搏

# IP-266 RCM + IP-271 CSC：minimax 后悔 + 受控隐藏
def compete(field_model, certified, theta, kappa):
    regret = lambda mu: max_br_regret(field_model, mu, certified)
    mu = online_mirror_descent(regret, iters=T)         # O(sqrt(T)) 平均后悔
    mu = safety_project(mu, certified)                  # 只投影到已认证集
    mu = max_entropy_with_kl(mu, kappa)                 # KL 预算内提高不可预测性
    return mu, regret_upper(mu)

# IP-267 MAV：两级 VoI（元层 vs R69 对象层）
def meta_voi(belief_cap, belief_field, meta_actions, cost):
    best = None
    for m in meta_actions:                              # 信任/试探/问裁判/换策略/留机会
        voi = entropy(belief_cap, belief_field) - expected_entropy(m)
        s   = voi - cost(m)
        if best is None or s > best.score: best = (m, s)
    return best if best and best.score > 0 else None    # ≤0 → 退化为 R69 单层

# IP-268 ABM：尝试预算分配（存胜场 vs 消歧能力）
def allocate_attempts(task_classes, budget, need_wins, belief_cap):
    posterior = [thompson_posterior(c) for c in task_classes]
    return greedy_until(budget,
        value=lambda c: dP_reach_need(posterior, c, need_wins)
                        + beta * info_gain(belief_cap, c))

# IP-269 GGC：Goodhart / 泄漏守护
def goodhart_guard(p_sel, p_hold, behavior_sig):
    leak   = p_sel - p_hold
    gaming = gaming_detector(behavior_sig)               # 奖励黑客/仿真漏洞/评测命中
    return (leak > TAU_LEAK) or gaming

# IP-274 主闭环（继承 FLUID-RAS：竞赛层只重排已认证动作，不扩包络）
def ARENA_RAS_trial(M, task_class, scoreboard):
    p_l = M.sre.success_lcb(M.episode_log, M.delta, M.dro_radius)
    if M.ggc.goodhart_guard(M.p_sel, M.p_hold, M.behavior_sig):
        return M.fluid.run_conservative(task_class)     # 退回 R69/R68，拒绝刷分
    theta = M.rra.risk_appetite(scoreboard.our, scoreboard.field,
                                M.attempts_left, M.r_star)
    mu, regret = M.rcm.compete(M.field_model, M.certified, theta, M.kappa)
    meta = M.mav.meta_voi(M.belief_cap, M.belief_field, M.meta_actions, M.cost)
    if meta is None:                                    # 元层无利可图 → 纯 R69
        return M.fluid.run(task_class, theta=0.0)
    # 元层动作同样走 R69 认证与证据纪律；只做选择，不越过安全包络
    plan = M.fluid.run(task_class, strategy=sample(mu), theta=theta)
    M.ccs.log(p_l, mu, regret, meta, M.attempts_left)
    M.vqa_c2.submit_async(scoreboard, mu, meta)
    return plan
```

## 3. 推导

**引理 19（成功率 LCB 的分布鲁棒覆盖）** 设每局独立、S 为 1-Lipschitz 的 0-1 损失，W₁-DRO 半径 ρ，样本量 n。则定义 312 的 p_L 满足 P(p_true ≥ p_L) ≥ 1−δ。
证明要点：Hoeffding 给 |p̂−p_true| ≤ √(log(1/δ)/(2n))（以概率 1−δ）；Kantorovich–Rubinstein 给 |E_Q[S]−E_{𝒟}[S]| ≤ ρ·Lip(S)=ρ。两者相减即得。小样本用 Clopper–Pearson 精确覆盖率；截尾用 Aalen–Johansen 的方差估计替代。**系**：n 越小、ρ 越大，p_L 越低、策略越保守——「机会很少」于是自动转化为「别乱赌」，无需另设规则。

**引理 20（均值-方差与排名阈值：何时该搏）** 设排名收益取平滑 S 形 U^σ_rank（A99），其在阈值 t_{r*} 下方凸、上方凹。若我方分数分布 G 是 F 的均值保持扩张（mean-preserving spread），则：当 X 的均值低于 t_{r*}（落后）时 E_G[U^σ_rank] ≥ E_F[U^σ_rank]；当均值高于 t_{r*}（领先）时不等号反向。
证明要点：凸函数在凸序下单调（E[φ(X)] 随 spread 增大），凹函数反向；S 形代理在阈值两侧分别凸/凹。**系**：RRA 的 θ 切换点正好是「期望分数 = 场次第 r* 名分数」，即引理给出的零交叉；这为「领先守、落后搏」提供了可证明的开关，而不是经验规则。

**引理 21（两级 VoI 的严格嵌套）** 把信念分成对象层 B_obj（动作模态，R69）与元层 B_meta（能力/场地）。由互信息链式法则，
I(B_obj,B_meta; Y | do(m)) = I(B_obj;Y|do(m)) + I(B_meta;Y|B_obj,do(m))。
因此总 VoI 可分解为对象层 VoI 与元层 VoI；当元层最优增益 ≤ 其成本时，最优计划就是只在对象层做 R69 的 MINT。**故 R69 是 ARENA 在「元层无利可图」边界上的精确退化**，而非被替换的旧模块。

**引理 22（分数不能自审：Goodhart 的不可内生化）** 设两个假设 H_true（真实能力提升）与 H_game（分数泄漏/过拟合）在选择分布 𝒟_select 上诱导相同的分数律。则任何仅依赖 𝒟_select 的检验，其两类错误风险之和 ≥ 1。故 GGC 必须有**与 𝒟_select 不相交**的留出通道（D(𝒟_hold‖𝒟_select)>0）或独立行为签名；若二者分布相同，则不存在有功效的检测。
这是 R68「标定吸收」引理在统计层的镜像：**一个只用自己的分数做选择的系统，无法察觉自己在优化错的东西**。它不是工程缺陷，而是信息论下界；因此 R70 把「留出集哈希 + 行为签名」写成证书的强制字段（定义 321），而不是可选建议。

**定理 18（ARENA 严格包含 FLUID/R68，且安全侧不让步）** 在 A99–A100 与定义 320 下：(i) ARENA 每步执行的动作必属于 R69 认证集，竞赛层只做重排，故任意状态的风险 ≤ R69 的同状态风险上界；(ii) 当场地单点、A=1、纯成功率评分、无漂移时，排名项为常数、元层 VoI≤0、θ=0、μ=δ，ARENA 与 FLUID 逐指令相同；再令交互 VoI≤成本则与 R68 相同。**系**：安全侧永不弱化，效率侧多出「守/搏」与「隐藏」两个自由度，但都被硬约束和预算封顶。

**定理 19（无后悔与隐藏预算）** 在 T 局上以在线镜像下降求混合策略，平均后悔 ≤ D√(log|Σ|/T)，即随局数趋于 0；受控隐藏以 KL 预算 κ 约束时，对手从历史反推我方策略的推断优势 ≤ √(κ/2)（Pinsker），且平均效用损失 ≤ ε_hide。若检测到场地漂移（定义 325），重置后悔累积，界在漂移后窗口内重新成立。**系**：不可预测性是被明码标价的资源，不会偷偷用安全或长期收益去换。

## 6. 本轮最大风险

**一句话**：ARENA-RAS 的全部竞赛收益押在「**选择分数 ≈ 任务价值**」与「**场地模型足够真**」这两个前提上——一旦分数可被刷高、评测集泄漏或对手模型严重失配，它会以统计上高度自信的姿态去优化一个**幻影目标**；R69 的「被证实的错误」至此升级为「**被刷高的成功**」：系统赢了排行榜、输了任务，而且引理 22 说明这种偏差**无法仅靠自己的分数审计出来**——**赢错，比不赢更危险**。

**次级风险与缓解**：
1. **Goodhart / 评测泄漏** → GGC 强制留出集哈希 + 行为签名 + 定义 321 证书门控；检测到即退回 R69 纯保守；
2. **沙袋/合谋/排行榜投毒** → ℰ_compete 对抗训练 + RCM minimax 后悔 + VQAuditor-C2；
3. **「搏」越出安全包络** → SLD 字典序硬约束，搏只在已认证集合内提高方差（定理 18）；
4. **隐藏随机化反噬**（探索到坏策略）→ KL 隐藏预算 κ + 支撑集 ⊆ Σ_cert + 定理 19 的效用损失上界；
5. **场地非平稳导致模型过期** → 变点检测 + 滑动窗口重估 + 后悔重置（定义 325）；
6. **小样本 + 截尾把成功率估飘** → 分布鲁棒 LCB、竞争风险模型、以及「尝试少则自动更保守」的引理 19 系。

```python
def success_lcb(episodes, delta, dro_radius):
    p_hat = (aalen_johansen_rmst(episodes) if any_censored(episodes)
             else clopper_pearson_lower(episodes, delta))
    return max(0.0, p_hat - dro_radius - hoeffding_slack(len(episodes), delta))

    return clip(k_gap * gap - k_press * press, theta_min, theta_max)

    best = None
    for m in meta_actions:
        s = entropy(belief_cap, belief_field) - expected_entropy(m) - cost(m)
        if best is None or s > best.score: best = (m, s)
    return best if best and best.score > 0 else None

# IP-268 ABM：尝试预算分配
def allocate_attempts(classes, budget, need_wins, belief_cap):
    post = [thompson_posterior(c) for c in classes]
    return greedy_until(budget, value=lambda c: dP_reach_need(post, c, need_wins)
                                             + beta * info_gain(belief_cap, c))

# IP-269 GGC：Goodhart / 泄漏守护
def goodhart_guard(p_sel, p_hold, sig):
    return (p_sel - p_hold > TAU_LEAK) or gaming_detector(sig)

# IP-274 主闭环（继承 FLUID-RAS；竞赛层只重排已认证动作）
def ARENA_RAS_trial(M, task_class, scoreboard):
    p_l = M.sre.success_lcb(M.episode_log, M.delta, M.dro_radius)
    if M.ggc.goodhart_guard(M.p_sel, M.p_hold, M.behavior_sig):
        return M.fluid.run_conservative(task_class)          # 退 R69/R68
    theta = M.rra.risk_appetite(scoreboard.our, scoreboard.field,
                                M.attempts_left, M.r_star)
    mu, regret = M.rcm.compete(M.field_model, M.certified, theta, M.kappa)
    meta = M.mav.meta_voi(M.belief_cap, M.belief_field, M.meta_actions, M.cost)
    if meta is None:
        return M.fluid.run(task_class, theta=0.0)            # 元层无利可图 → 纯 R69
    plan = M.fluid.run(task_class, strategy=sample(mu), theta=theta)
    M.ccs.log(p_l, mu, regret, meta, M.attempts_left)
    M.vqa_c2.submit_async(scoreboard, mu, meta)
    return plan
```

## 4. 推导

**引理 19（成功率 LCB 的分布鲁棒覆盖）** 独立试验、S 为 1-Lipschitz 0-1 损失、W₁ 半径 ρ、样本 n，则 `P(p_true ≥ p_L) ≥ 1−δ`。证明：Hoeffding + Kantorovich–Rubinstein 相减。系：n↓ / ρ↑ ⇒ p_L↓ ⇒ 自动更保守，「机会少」无需另设规则。

**引理 20（均值-方差与排名阈值）** 排名收益用平滑 S 形 `U^σ_rank`（阈值下凸、上凹）。若分数分布 G 是 F 的均值保持扩张，则落后（均值<t_{r*}）时 spread 提高期望排名收益，领先（均值>t_{r*}）时反向。系：RRA 的 θ 切换点 = 期望分数与 `t_{r*}` 的零交叉——「领先守、落后搏」可证明而非拍脑袋。

**引理 21（两级 VoI 严格嵌套）** 由互信息链式法则 `I(B_obj,B_meta;Y|do(m)) = I(B_obj;Y|do(m)) + I(B_meta;Y|B_obj,do(m))`，总 VoI 可分解；元层最优增益 ≤ 成本时，最优计划即 R69 的 MINT。故 R69 是 ARENA 在「元层无利可图」边界上的精确退化。

**引理 22（分数不能自审：Goodhart 不可内生化）** 若 H_true（真实能力）与 H_game（泄漏/过拟合）在选择分布上诱导相同分数律，则任何仅依赖选择集的检验两类错误和 ≥ 1。故必须有**不相交留出集**或独立行为签名；分布相同则检测无功效。这是 R68「标定吸收」引理在统计层的镜像，也解释为何定义 321 把留出集哈希写成强制字段。

**定理 18（ARENA 严格包含 FLUID/R68，安全不让步）** 每步执行动作 ∈ R69 认证集，竞赛层只重排 ⇒ 任意状态风险 ≤ R69 上界；单点场地 + A=1 + 纯成功率 + 无漂移 ⇒ 排名项常数、VoI_meta≤0、θ=0、μ=δ ⇒ 与 FLUID 逐指令相同；再令交互 VoI≤成本 ⇒ 与 R68 相同。

**定理 19（无后悔与隐藏预算）** OMD/EXP3 平均后悔 ≤ D√(log|Σ|/T)；KL 预算 κ 下对手推断优势 ≤ √(κ/2)（Pinsker），效用损失 ≤ ε_hide；检测到漂移则重置后悔累积，界在漂移后窗口内重新成立。不可预测性是被明码标价的资源。

## 7. 本轮最大风险

**一句话**：ARENA-RAS 的全部收益押在「**选择分数 ≈ 任务价值**」与「**场地模型足够真**」上——一旦分数可被刷高、评测泄漏或对手模型严重失配，它会以统计上高度自信的姿态优化一个**幻影目标**；R69 的「被证实的错误」升级为「**被刷高的成功**」：赢排行榜、输任务，而引理 22 证明这种偏差**无法只靠自己的分数审计出来**——**赢错，比不赢更危险**。

**次级风险与缓解**：Goodhart/泄漏（GGC 留出集哈希 + 行为签名 + 证书门控，触发即退 R69）；沙袋/合谋/榜投毒（ℰ_compete 对抗 + minimax 后悔 + VQAuditor-C2）；「搏」越界（SLD 字典序硬约束，定理 18）；隐藏反噬（KL 预算 κ + 支撑集 ⊆ Σ_cert + 定理 19）；场地非平稳（变点检测 + 后悔重置）；小样本/截尾（DRO LCB + 竞争风险 + 引理 19 系自动更保守）。
