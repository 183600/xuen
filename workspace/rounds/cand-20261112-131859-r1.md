# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC / IP-153~160；灵感循环第 7 轮；本轮灵感：「场景落地」×「视觉问答」）

> 第 60 轮用 SSM×CIEC×EPIR×SERC×PCE++++ 把「场景语义→意图→约束→阻抗→执行→证据」闭了起来，但它把「场景」当成了一个**在实验室里预定义好的封闭标签集** `Z_scene`，并默认视觉理解是免费且可信的。真实「场景落地」精确打在这两个未言明的前提上：
> 1. **封闭集 vs 开放世界**：`Z_scene` 只有 10 个类。部署现场会出现反光桌面、透明杯、湿痕、新桌布、异形包装——它们不属于任何一类，却必须给出阻抗先验。闭集把「没见过」压成 `unknown`，回退通用先验，等于放弃前置适应。
> 2. **VQA 的自信错觉**：视觉问答能回答开放世界问题（「这表面湿吗」「杯柄可抓吗」），但它在分布漂移下会**更自信地错**。把答案文本直接写进 `π_scene`，等于把幻觉编译成阻抗约束，且没有任何覆盖率保证。
> 3. **「问了」不等于「落地了」**：部署验收要回答「这个场地、这个标定版本、这套问题策略，是否真的能保证安全」。第 60 轮只有 SIC 自评置信度，没有**现场落地证书**，也没有把「问」与「摸」放进同一张成本表决策。

## 0. 直觉与动机

**灵感 1（场景落地 → 开放集属性接地 OGSM）**
直觉：场景不是「类别」，而是「属性的联合」。桌面 = (材质=木质, 湿度=干, 坡度≈0, 变形=低, 可抓=平面)；湿滑地面 = (材质=瓷砖, 湿度=湿, 坡度=0, 变形=低, 可抓=平面)。关键洞见：**部署中遇到的新场景，本质是已知属性的新组合，而不是未知类别**。把场景识别从「闭集分类」改写为「m 个原子属性的答案集」，开放集泛化就来自属性分解，而不是类别枚举。`Z_scene` 从「枚举表」降级为「属性先验的缓存」。

**灵感 2（视觉问答 → 带覆盖保证的答案集 ACI-VQA）**
直觉：VQA 不该给单一答案，而应给**集合**（「湿或微湿」「可能是杯柄，也可能是杯沿」）。用共形预测把「答案集」变成有覆盖率 `1-α` 的对象；再做部署自适应（ACI）：用接触后的 `EV-exec` 作为延迟标签，在线调 `α_t`，使长期错误率收敛到 `α`，**即使视觉分布漂移、即使交换性不成立**。关键洞见：不是让 VQA 更准，而是让**「它错的时候，我们知道它可能错，并据此放宽 K 或放弃执行」**——把不可审计的准确率换成可审计的覆盖率。

**灵感 3（合流 → 答案集→阻抗区间 ASI）**
直觉：若真实属性 `y` 落在答案集的笛卡尔积里，则任意 `K ∈ ∩_{y∈ΠS_i} K_safe(y)` 都是安全的。于是「答案集的宽度」严格对应「安全阻抗区间的宽度」：答得越窄，K 可用域越宽；答得越宽，K 越保守；交集为空则拒绝下发。关键洞见：**存在一个包含单调（反单调）的映射，把语言层面的不确定性无损失地接到控制层面的安全裕度上**——这是把 VQA 接进 SGEC 的数学接口。

**灵感 4（场景落地 × 视觉问答 → 问-触价值决策 ABT）**
直觉：部署预算有限：问一次 VQA 有 token/时延/热成本，摸一次有接触风险与节拍损失。定义 `VOI_ask` 与 `VOI_probe` 并比较；只有问的边际收益 ≥ 摸的边际收益时才问，否则直接接触探测。关键洞见：**「先问后触」不是无条件先问，而是「问与摸在同一货币下竞价」**；`K_safe(S)=∅` 时强制探测（安全储备不可挪用），答案集够窄时主动闭嘴直接执行。

**灵感 5（合流 → 落地接地证书 GCC + PCE+++++）**
直觉：把「这个场地是否落地成功」做成可审计证书：站点 id、标定版本、`α_t` 轨迹、经验覆盖率、漂移统计、每次 K 区间与探针日志。验收判据是「经验联合覆盖 ≥ 1-α-δ 且零次未认证下发」。PCE+++++ 在 B_scene/B_intent/B_ros/B_exec 之外新增 **B_ask（查询/token 预算）、B_cal（标定/调试轮次）、B_probe（接触探针预算）**，并规定：**经济降级可以少问，但绝不能把未认证的 K 下发**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（开放集接地场景模型 OGSM）** 场景模型 `Γ_open = (A, 𝒜, S, g_attr, π_open)`。其中：
- **属性集** `A = {a_1,...,a_m}`，`m` 为影响阻抗的原子属性数（材质、湿度、坡度、变形、几何可抓性等）；
- **属性域** `𝒜_i`（类别型为有限集，连续型为有界区间）；
- **属性答案集** `S_i(x) ⊆ 𝒜_i`：视觉输入 `x` 经 VQA 得到的第 i 个属性的候选集合；
- **场景-属性先验** `π_open(K | y)`，`y = (y_1,...,y_m) ∈ Π_i 𝒜_i`；第 60 轮的 `π_scene(K|z)` 作为 `π_open` 的一个闭集特例（当属性域被离散成类时退化为原表）；
- **属性生成器** `g_attr: (task, uncertainty) → Q_attr`：只生成与当前阻抗不确定性相关的属性问题，而不是开放闲聊。

**定义 162（部署自适应共形答案集 ACI-VQA）** 五元组 `C = (s, D_cal, q̂, α_t, γ)`。其中：
- **非一致性分数** `s_i(x,a) ∈ ℝ`：VQA 对「属性 i 取 a」的打分（如 1 − softmax 概率、或 logit margin）；
- **标定集** `D_cal`：站点调试期采集的 `(x, ŷ)` 对，`ŷ` 来自接触探针；
- **答案集** `S_i(x) = {a ∈ 𝒜_i : s_i(x,a) ≤ q̂_i(1-α_{i,t})}`，`q̂_i` 为 `D_cal` 上分数的经验分位数；
- **Bonferroni 拆分**：`α_i* = α/m`，使联合覆盖 `P(∀i: y_i ∈ S_i) ≥ 1-α`；
- **ACI 更新**（延迟标签到达时）：`α_{i,t+1} = Π_{[0,1]}( α_{i,t} + γ (α_i* − err_{i,t}) )`，`err_{i,t} = 1{y_i,t ∉ S_i,t}`；
- **延迟标签**：`ŷ_i,t` 由 `EV-exec` 反演（滑移→湿；力响应斜率→刚度），探针误差有界 `P(ŷ_i,t ≠ y_i,t) ≤ ε_p`。

**定义 163（答案集→阻抗区间编译器 ASI）** 映射 `ASI: (Π_i S_i) → 2^{𝒦}`：
```
K_safe(S) = ( ∩_{y ∈ Π_i S_i} K_safe(y) ) ∩ K_safe_base
```
- **包含反单调引理**：若 `S ⊆ S'`（逐属性包含），则 `K_safe(S') ⊆ K_safe(S)`；
- **可执行性**：`K_safe(S) = ∅` 时**禁止**下发任何 K，只能问、摸或降级；
- **顶点求值**：若每个 `K_safe(y)` 的上下界对属性单调（假设 A66），只需在属性域的超立方体顶点上求值，`O(2^m)` 而非 `O(Π|S_i|)`。

**定义 164（问-触价值决策 ABT）** 动作集 `Act = {ask(q), probe, commit(K), degrade}`，决策规则：
```
K0 = ASI(S)
VOI_ask(q)  = E[U(ASI(S_q))] − U(K0) − c_ask(q) − λ_cal·1{需重标定}
VOI_probe   = E[U(ASI(ŷ))] − U(K0) − c_probe − λ_r·R_probe
策略：
  if K0 = ∅:               强制 probe（安全储备 R_probe ≥ 1 不可挪用）
  elif max_q VOI_ask(q) ≥ VOI_probe and ≥ 0:  ask(argmax)
  elif VOI_probe > max(0, max_q VOI_ask(q)):   probe
  else:                     commit(argmax_{K∈K0} U(K))
```
其中 `U(K)` 为在安全区间内可取的最佳跟踪/能耗效用（可由第 60 轮 PCE 的 `voi` 退化得到），`S_q` 为提问 q 后的预测答案集。

**定义 165（落地接地证书 GCC）** `J_land = (site_id, D_cal版本, α_t轨迹, 经验联合覆盖, 漂移统计, 下发日志, 探针日志, verdict)`。验收谓词：
```
LANDED       ⇔  empirical_coverage ≥ 1 − α − δ_cal
                ∧ unsafe_dispatch = 0
                ∧ empty_set_rate ≤ ρ_max
                ∧ (shift_stat ≤ τ_shift ∨ α已按漂移膨胀)
CONDITIONAL  ⇔  仅覆盖或 empty_set_rate 之一略越界
REJECTED     ⇔  unsafe_dispatch > 0 或 覆盖 < 1 − α − 2δ_cal
```
GCC 是「场景落地」的可审计凭证：没有 GCC 的 K，等价于第 60 轮没有 `J_exec` 的执行。

**定义 166（问答-场景-执行闭环 QV-SERC）** 算子 `QV-SERC(M, task, intent, delta_f_req)`：
```
① 观测 x；ShiftDetect(emb_t, D_cal) → 漂移标志
② OGSM: 由任务与不确定性生成属性问题集 Q_attr；当前答案集 S
③ ABT: 计算 K0 = ASI(S)；若 K0=∅ 或 VOI_probe 占优 → probe/ask 循环
④ ACI-VQA: 取答案集 S_i(x)，按 Bonferroni 保证联合覆盖
⑤ ASI: K_safe(S) → 区间；与第 60 轮 K_safe^scene 求交
⑥ EEIS: compile(K_safe(S), delta_f_req, D⁺)
⑦ Dispatch: 仅当 K_safe(S) ≠ ∅ 且 J_land 有效时下发
⑧ Execute: 接触 → telemetry → EV-exec
⑨ 延迟标签 ŷ 入 ACI 更新；GCC 追加一条记录
⑩ XMC++: D⁺ ← xmodal_fuse_plus(...)；回到 ①
```
**安全优先级**：物理探针 > 人类澄清回答 > VQA 答案（按接地强度递减）；任何高优先级证据都能收窄 `S`，但只有物理探针能改变 `D_cal`。

**定义 167（PCE+++++ 六维落地预算）** `B_land = (B_ask, B_cal, B_probe, B_scene, B_intent, B_exec)`：
- `B_ask`：每 episode 的查询数与视觉 token 上限；
- `B_cal`：每站点的标定 episode 上限（决定 GCC 的初始 `D_cal` 大小）；
- `B_probe`：允许的接触探针次数，含风险储备 `R_probe`；
- 规则：`B_ask` 耗尽 → 只用已有 `S` 或直接 probe；`B_cal` 耗尽 → GCC 标记 `CONDITIONAL`，K 区间强制向 `K_safe_base` 收；`B_probe` 触及 `R_probe` → 禁止任何 `K ∉ K_safe_base` 的下发。

**定义 168（双向澄清对话 BCD）** 两条语言通道：
- **机器人→人**：当 `ASI(S)=∅` 且探针不可行时，生成最小澄清问题（「这块布下面有硬物吗？」），答案作为弱证据并入 `S`，但**不得单独用于放宽 K**；
- **人→机器人**：回答「你为何选这个刚度」时必须返回 GCC 证据链（问题、答案集、覆盖版本、K 区间、探针），即语言解释必须可回溯到证书，禁止自由发挥。

### IP-161 OGSM（开放集属性接地）

```python
class OpenSetGroundedSceneModel:
    def __init__(self, m_attrs=5):
        self.attrs = ['material', 'wetness', 'slope', 'deform', 'grasp']
        self.domains = {
            'material': ['wood', 'metal', 'glass', 'fabric', 'tile', 'unknown'],
            'wetness':  [0.0, 0.25, 0.5, 0.75, 1.0],
            'slope':    [-0.3, -0.1, 0.0, 0.1, 0.3],
            'deform':   [0.0, 0.5, 1.0],
            'grasp':    ['flat', 'handle', 'edge', 'none'],
        }
        self.answer_sets = {a: set(self.domains[a]) for a in self.attrs}  # 初始最保守
        self.attr_prior  = self._init_priors()

    def refine(self, attr, answer_set):
        self.answer_sets[attr] = self.answer_sets[attr] & set(answer_set)

    def scene_prior(self, K_grid):
        ys = list(itertools.product(*[sorted(self.answer_sets[a]) for a in self.attrs]))
        dens = np.mean([self.attr_prior.pdf(y, K_grid) for y in ys], axis=0)
        return dens / dens.sum()
```

### IP-162 ACI-VQA（部署自适应共形答案集）

```python
class AdaptiveConformalVQA:
    def __init__(self, alpha=0.1, m_attrs=5, gamma=0.01):
        self.alpha_star = alpha / m_attrs        # Bonferroni
        self.alpha_t = {a: self.alpha_star for a in range(m_attrs)}
        self.gamma = gamma
        self.cal_scores = {a: [] for a in range(m_attrs)}

    def answer_set(self, attr_id, x, scorer, domain):
        if not self.cal_scores[attr_id]:
            return set(domain)                    # 冷启动：最保守
        qhat = np.quantile(self.cal_scores[attr_id], 1 - self.alpha_t[attr_id])
        return {a for a in domain if scorer(x, a) <= qhat}

    def update(self, attr_id, y_hat, S_t):
        err = 0.0 if y_hat in S_t else 1.0
        a = self.alpha_t[attr_id] + self.gamma * (self.alpha_star - err)
        self.alpha_t[attr_id] = float(np.clip(a, 1e-4, 1.0))
        self.cal_scores[attr_id].append(err)      # 简化的在线分位维护
```

### IP-163 ASI（答案集→阻抗区间）

```python
def answerset_to_impedance(answer_sets, ksafe_of, ksafe_base, monotone=True):
    attrs = list(answer_sets)
    if monotone:
        corners = itertools.product(*[
            (min(answer_sets[a]), max(answer_sets[a])) for a in attrs
        ])
        intervals = [ksafe_of(dict(zip(attrs, c))) for c in corners]
    else:
        intervals = [ksafe_of(dict(zip(attrs, y)))
                     for y in itertools.product(*[answer_sets[a] for a in attrs])]
    lo = max(iv.lo for iv in intervals)
    hi = min(iv.hi for iv in intervals)
    lo, hi = max(lo, ksafe_base.lo), min(hi, ksafe_base.hi)
    return KInterval(lo, hi) if lo <= hi else KInterval.empty()
```

### IP-164 ABT（问-触价值决策）

```python
def ask_before_touch(S, utility, questions, budget, probe_model):
    K0 = answerset_to_impedance(S, probe_model.ksafe_of, probe_model.base)
    if K0.empty:
        return ('probe', None)                      # 安全储备不可挪用
    best_q, best_ask = None, -np.inf
    for q in questions:
        if budget.B_ask <= 0:
            break
        S_q = probe_model.predict_refinement(S, q)
        gain = np.mean([utility(answerset_to_impedance(s, probe_model.ksafe_of,
                                                        probe_model.base))
                        for s in S_q]) - utility(K0)
        voia = gain - budget.c_ask(q)
        if voia > best_ask:
            best_q, best_ask = q, voia
    voip = np.mean([utility(answerset_to_impedance(
                        probe_model.predict_probe(S), probe_model.ksafe_of,
                        probe_model.base))]) - utility(K0) \
           - budget.c_probe - budget.lambda_r * probe_model.R_probe
    if best_ask >= voip and best_ask >= 0:
        return ('ask', best_q)
    if voip > max(0.0, best_ask):
        return ('probe', None)
    return ('commit', K0)
```

### IP-165 GCC（落地接地证书）

```python
class GroundingCommissioningCertificate:
    def __init__(self, site_id, cal_version):
        self.site_id, self.cal_version = site_id, cal_version
        self.records = []           # (t, S, K_interval, probe_label, alpha_t, shift)

    def append(self, S, K_iv, y_hat, alpha_t, shift_stat):
        self.records.append(dict(t=len(self.records), S=S, K=K_iv,
                                 y=y_hat, alpha=alpha_t, shift=shift_stat))

    def verdict(self, alpha, delta_cal=0.03, rho_max=0.35):
        cov = np.mean([r['y'] in r['S'] for r in self.records])
        unsafe = sum(1 for r in self.records if r['K'].dispatched and r['K'].empty)
        empty = np.mean([r['K'].empty for r in self.records])
        if unsafe > 0 or cov < 1 - alpha - 2 * delta_cal:
            return 'REJECTED'
        if cov >= 1 - alpha - delta_cal and empty <= rho_max:
            return 'LANDED'
        return 'CONDITIONAL'
```

### IP-166 QV-SERC（问答-场景-执行闭环）

```python
def qv_serc(M, task, intent, delta_f_req):
    x = M.perceive()
    shift = M.shift_detector.score(x, M.gcc.cal_embeddings)
    if shift > M.tau_shift:
        M.aci.inflate_alpha(beta=0.02)            # 漂移 → 答案集变大
    S = M.ogsm.answer_sets
    action, q = ask_before_touch(S, M.utility, M.g_attr(task), M.budget, M.probe_model)
    while action in ('ask', 'probe') and M.budget.ok(action, q):
        if action == 'ask':
            S = M.aci.refine(S, x, q)
        else:
            y_hat, ev = M.contact_probe()
            S = M.aci.refine_with_probe(S, y_hat)
            M.aci.update_all(y_hat, S)
        action, q = ask_before_touch(S, M.utility, M.g_attr(task), M.budget, M.probe_model)
    K_iv = answerset_to_impedance(S, M.probe_model.ksafe_of, M.ksafe_base)
    if K_iv.empty:
        return M, 'DEGRADE_EXEC'
    K = M.eeis.compile(K_iv, delta_f_req, M.D_plus)
    dispatch_impedance_params(K.best, cert=M.eeis.cert, land=M.gcc.verdict(M.alpha))
    M, fused, D_plus, EV = closed_loop_exec_probe(M, M.current_cp, delta_f_req, M.budget)
    M.gcc.append(S, K_iv, EV.y_hat, M.aci.alpha_t, shift)
    M.D_plus = D_plus
    return M, 'OK'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| OGSM | O(m) 属性合并/周期 | O(Σ|𝒜_i|) | 属性分解不丢失类别信息；闭集为其特例 |
| ACI-VQA | O(1) 更新 / O(|𝒜_i|) 构造 | O(|D_cal|) | 长期平均覆盖 ≥ 1-α-ε_p（无需交换性） |
| ASI | O(2^m)（单调）/ O(Π|S_i|)（一般） | O(1) | 包含反单调：S 越小 K 域越大；空集禁止下发 |
| ABT | O(|Q|·2^m) | O(|Q|) | 强制探针保护空集；次模下 (1-1/e) 近似 |
| GCC | O(1) 追加 / O(N) 验收 | O(N) | unsafe_dispatch=0 为一票否决 |
| QV-SERC | O(闭环 + 问触循环) | 复用 | 覆盖率与执行安全解耦可审计 |

**正确性定理（VQ-LAND）**：
假设 A66–A71 成立：**(A66)** 每个 `K_safe(y)` 的上下界对属性单调；**(A67)** ACI 的长期平均误差 `(1/T)Σ err_t ≤ α + o(1)`（无交换性要求）；**(A68)** 探针标签误差 `≤ ε_p`；**(A69)** 漂移检测漏报率 `≤ δ_shift`，且漏报时 `α` 已被动膨胀；**(A70)** 预算单调消耗且安全储备 `R_probe` 不可挪用；**(A71)** 只下发 `K ∈ K_safe(S)` 且 `K_safe(S) ≠ ∅`。

则：
1. **落地安全性**：若 `y_t ∈ Π_i S_i,t`，则下发 `K_t ∈ K_safe(S_t) ⊆ K_safe(y_t)`，故安全；故部署期平均不安全率 `≤ α + ε_p + δ_shift`。
2. **紧致性**：当站点回到分布内且 `α_t → α*`，答案集收缩，`K_safe(S)` 宽度趋近 `K_safe(y)` 宽度，探针数严格少于 always-probe。
3. **空集安全**：`K_safe(S)=∅` 时强制 probe/degrade，杜绝「用幻觉 K 执行」。
4. **可审计性**：GCC 的 `unsafe_dispatch = 0` 是验收的一票否决项，任何 VQA 改进都不能绕过它。

### IP-161 OGSM（开放集属性接地）

```python
class OpenSetGroundedSceneModel:
    def __init__(self, m_attrs=5):
        self.attrs = ['material', 'wetness', 'slope', 'deform', 'grasp']
        self.domains = {
            'material': ['wood', 'metal', 'glass', 'fabric', 'tile', 'unknown'],
            'wetness':  [0.0, 0.25, 0.5, 0.75, 1.0],
            'slope':    [-0.3, -0.1, 0.0, 0.1, 0.3],
            'deform':   [0.0, 0.5, 1.0],
            'grasp':    ['flat', 'handle', 'edge', 'none'],
        }
        self.answer_sets = {a: set(self.domains[a]) for a in self.attrs}
        self.attr_prior  = self._init_priors()

    def refine(self, attr, answer_set):
        self.answer_sets[attr] = self.answer_sets[attr] & set(answer_set)

    def scene_prior(self, K_grid):
        ys = list(itertools.product(*[sorted(self.answer_sets[a]) for a in self.attrs]))
        dens = np.mean([self.attr_prior.pdf(y, K_grid) for y in ys], axis=0)
        return dens / dens.sum()
```

### IP-162 ACI-VQA（部署自适应共形答案集）

```python
class AdaptiveConformalVQA:
    def __init__(self, alpha=0.1, m_attrs=5, gamma=0.01):
        self.alpha_star = alpha / m_attrs          # Bonferroni 联合覆盖
        self.alpha_t = {a: self.alpha_star for a in range(m_attrs)}
        self.gamma = gamma
        self.cal_scores = {a: [] for a in range(m_attrs)}

    def answer_set(self, attr_id, x, scorer, domain):
        if not self.cal_scores[attr_id]:
            return set(domain)                     # 冷启动：最保守
        qhat = np.quantile(self.cal_scores[attr_id], 1 - self.alpha_t[attr_id])
        return {a for a in domain if scorer(x, a) <= qhat}

    def update(self, attr_id, y_hat, S_t):
        err = 0.0 if y_hat in S_t else 1.0
        a = self.alpha_t[attr_id] + self.gamma * (self.alpha_star - err)
        self.alpha_t[attr_id] = float(np.clip(a, 1e-4, 1.0))
        self.cal_scores[attr_id].append(err)

    def inflate_alpha(self, beta=0.02):
        for a in self.alpha_t:
            self.alpha_t[a] = float(np.clip(self.alpha_t[a] - beta, 1e-4, 1.0))
```

### IP-163 ASI（答案集→阻抗区间）

```python
def answerset_to_impedance(answer_sets, ksafe_of, ksafe_base, monotone=True):
    attrs = list(answer_sets)
    if monotone:
        corners = itertools.product(*[
            (min(answer_sets[a]), max(answer_sets[a])) for a in attrs
        ])
        intervals = [ksafe_of(dict(zip(attrs, c))) for c in corners]
    else:
        intervals = [ksafe_of(dict(zip(attrs, y)))
                     for y in itertools.product(*[answer_sets[a] for a in attrs])]
    lo = max(iv.lo for iv in intervals)
    hi = min(iv.hi for iv in intervals)
    lo, hi = max(lo, ksafe_base.lo), min(hi, ksafe_base.hi)
    return KInterval(lo, hi) if lo <= hi else KInterval.empty()
```

### IP-164 ABT（问-触价值决策）

```python
def ask_before_touch(S, utility, questions, budget, probe_model):
    K0 = answerset_to_impedance(S, probe_model.ksafe_of, probe_model.base)
    if K0.empty:
        return ('probe', None)                     # 安全储备 R_probe 不可挪用
    best_q, best_ask = None, -np.inf
    for q in questions:
        if budget.B_ask <= 0:
            break
        S_q = probe_model.predict_refinement(S, q)
        gain = np.mean([utility(answerset_to_impedance(s, probe_model.ksafe_of,
                                                        probe_model.base))
                        for s in S_q]) - utility(K0)
        voia = gain - budget.c_ask(q)
        if voia > best_ask:
            best_q, best_ask = q, voia
    voip = np.mean([utility(answerset_to_impedance(
                        probe_model.predict_probe(S), probe_model.ksafe_of,
                        probe_model.base))]) - utility(K0) \
           - budget.c_probe - budget.lambda_r * probe_model.R_probe
    if best_ask >= voip and best_ask >= 0:
        return ('ask', best_q)
    if voip > max(0.0, best_ask):
        return ('probe', None)
    return ('commit', K0)
```

### IP-165 GCC（落地接地证书）

```python
class GroundingCommissioningCertificate:
    def __init__(self, site_id, cal_version):
        self.site_id, self.cal_version = site_id, cal_version
        self.records = []          # (t, S, K_interval, probe_label, alpha_t, shift)

    def append(self, S, K_iv, y_hat, alpha_t, shift_stat):
        self.records.append(dict(t=len(self.records), S=S, K=K_iv,
                                 y=y_hat, alpha=alpha_t, shift=shift_stat))

    def verdict(self, alpha, delta_cal=0.03, rho_max=0.35):
        cov = np.mean([r['y'] in r['S'] for r in self.records])
        unsafe = sum(1 for r in self.records if r['K'].dispatched and r['K'].empty)
        empty = np.mean([r['K'].empty for r in self.records])
        if unsafe > 0 or cov < 1 - alpha - 2 * delta_cal:
            return 'REJECTED'
        if cov >= 1 - alpha - delta_cal and empty <= rho_max:
            return 'LANDED'
        return 'CONDITIONAL'
```

```python
class LandingBudget:
    def __init__(self, ask=20, cal=10, probe=5, exec_budget=None):
        self.B_ask, self.B_cal, self.B_probe = ask, cal, probe
        self.R_probe = 1                     # 安全储备，不可挪用
        self.B_exec = exec_budget or ExecBudget()
        self.ops_ask = self.ops_cal = self.ops_probe = 0

    def ok(self, action, q):
        if action == 'ask':
            return self.ops_ask < self.B_ask
        if action == 'probe':
            return self.ops_probe < self.B_probe - self.R_probe
        return True

    def can_relax_K(self):
        return self.ops_probe < self.B_probe - self.R_probe

    def degrade_action(self):
        if self.ops_ask >= self.B_ask:
            return 'commit_or_probe'
        if self.ops_cal >= self.B_cal:
            return 'shrink_to_base'
        return 'normal'
```
