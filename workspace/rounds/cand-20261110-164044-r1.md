# 第 44 轮（灵感循环第 1 轮，承接第 43 轮 v20） · Language-Cert × Grounding-Cert：把「机器人」的「多语言支持」从翻译特性升格为可证伪的语义证书层（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形仅边际覆盖 + 多用户契约空集」，但整条证书链仍压着一个从未被写进证明义务的假设：**语义层输出默认「语言无关且接地正确」**。所有下游几何证书、CBF、监控器都只对「目标语义 φ」负责，却没有任何一条证明「φ 就是这位用户用这种语言真正想要的东西」。对一台真实机器人而言，这不是翻译质量问题，而是 **soundness 空洞**：翻错一句话不会让证书失效，只会让证书**对错误目标保持完全 sound**——这是 v20 的 all-checker 都检不出的「可认证地做错事」。本轮灵感词「机器人」「多语言支持」精确命中它：**机器人**把语言从字符串拉回物理接地（目标物、空间关系、接触部位），**多语言支持**则把否定、量词、空间框架、称谓→动作映射、语码转换变成证书必须显式携带的条件。核心命题：**语言不是预处理，而是证书的前置条件；多语言支持不是把 n 种语言翻成 1 种，而是把语言覆盖做成可审计的安全面**。于是本轮新增 **语言条件化语义证书 + 解释证明 + 跨语言共形解释集 + 接地见证（verify-then-act）+ 跨语言证书迁移 + 语言覆盖账本**，把「会说多国语言」升级为「对每种语言都说得清自己凭什么安全」。

## 0. 直觉与动机

**灵感 1（机器人 → 语言必须落到物理，翻译只是中介）**：在 UniBot 这类桌面操作场景里，「把左边那个红杯子递给我」同时包含**指代**（哪个杯子）、**空间框架**（观察者左还是杯子左）、**属性**（红到什么程度算红）、**动作后果**（递=抓取+移动+释放，接触力多大）。不同语言把这些信息切分得不一样：有的语言量词强制区分「杯/个/只」，有的语言方位词以绝对方位为主，有的语言否定会与量词作用域纠缠。只做「中→英→抓取」的枢轴翻译，会把「不要拿左边那个」翻成「拿左边那个」这类极性错误。因此**语义证书必须带语言与接地的来源证明**，而且机器人应能在动手前用一次「看一眼/碰一下/问一句」把歧义消掉。直觉：**先接地，再执行；能看见就不猜，猜就必须证明覆盖**。

**灵感 2（多语言支持 → 语言相对性是新的 soundness 空洞）**：v20 的语义层一直把「同一条指令的不同语言版本」当作同分布样本。现实恰恰相反：英语数据多、校准充分，低资源语言样本少、方言/俚语漂移快，导致**语言分层后每层的覆盖完全不同**。更危险的是「翻对了字面、翻错了意图」：礼貌等级、模糊限制语（「差不多」「稍微」）、否定辖域在翻译后可能丢失，而下游证书对丢失后的语义仍然 sound。直觉上的修法不是「换更大的模型」，而是把语义输出拆成 **(保守语义证书, 解释证明 A, 跨语言解释集 I_ℓ^α)** 三元组：证书只对解释集里所有可能的解释都安全的动作放行；解释证明写清用了哪种语言、哪套接地表、哪批校准数据、覆盖多少；解释集之外一律走澄清或安全停机。这样**多语言不是增加能力，而是增加一条必须被证明的维度**。

**灵感 3（耦合 → 语言是人格与并发的隐藏维度）**：v20 已有「人格契约」与「并发证书」。语言恰好同时穿过两者：人格里有语言偏好/熟练度/是否语码转换，多用户并发时两个人可能用不同语言同时说话。若把 A 用户的中文指令错误归因给 B 用户，就会用错人格契约与语言覆盖档位——这不是识别错误，而是**契约归因错误**，其后果与 v20 的「证书撕裂读」同构。于是需要把 **(说话人, 语言, epoch)** 做成和证书租约一样的原子快照：一旦换人或换语言，所有由旧归因导出的证书立即失效。直觉：**语言不是全局变量，而是每个 utterance 的带 epoch 的绑定**。

**耦合升级**：LCSem（语言条件化语义证书）把每个语义结论变成「带解释证明的、对解释集求交后的」保守证书；XLCT（跨语言证书迁移）用证书模板/接地表分离 + 接地分歧上界，决定哪些语言可以复用证书、哪些必须重接地；LCLD（语言覆盖账本）把每种语言的可信度做成可降级的三档契约；MAR（多语言归因运行时）把说话人-语言绑定纳入 v20 的租约/epoch 机制。四层架构由 v20 的「人格 + 并发证书」升级为 v9 的「语言信任边界 + 可证伪接地 + 人格/并发证书」。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（语言条件化语义证书与解释证明）**：设语言集合 L，语言 ℓ∈L 的话语 u∈U_ℓ，上下文 ctx。语义层 S_ℓ: U_ℓ×Ctx → (c_sem, A)，其中 c_sem=(Ĝ, C_cons, ρ) 为目标、硬约束与执行策略；**解释证明** A=(model_id, version, ℓ, grounding_table_id, calib_set_id, cov_ℓ, ambiguity_set, parser_provenance, ts)。称语义层在 ℓ 上 **((ℓ,α)-sound)**，若
  P_{u∼D_ℓ}[ exec(c_sem) ⊨_ε intent(u) ] ≥ 1−α，
其中 ⊨_ε 表示在容差 ε 内满足用户真实意图。**信任闸门** Gate(c_sem,A,action) 为真，当且仅当 A.model∈CertSet(ℓ)、cov_ℓ≥1−α、且 action 的不可逆级不超过 tier(ℓ) 的许可；**没有 A 的 c_sem 不得进入规划**。这把 v20 的每条下游证书都变成「A-gated」。

**定义 45（跨语言解释集、保守解释与接地见证）**：对解释 π 定义非一致性分数 s_ℓ(u,π)；用按语言分层的 Mondrian 校准取分位 q_ℓ=Quantile({s_ℓ(u_i,π_i^true)}_{i∈calib_ℓ}, 1−α)，得**解释集** I_ℓ^α(u)={π: s_ℓ(u,π)≤q_ℓ}，在层内可交换性下满足 P(intent(u)∈I_ℓ^α(u))≥1−α。**保守解释** c_cons=⋂_{π∈I_ℓ^α} c(π)：动作必须对所有合理理解都可接受，故按构造 sound（动作集只收缩）。当 c_cons 不可行时，定义**接地见证** W={w_1..w_m} 为一组可执行的感知/交互谓词（颜色、左右、把手、指认），其取值把 I_ℓ^α 划分为若干剩余类。**分离性**：若存在 W 使剩余解释类对「执行 a / 不执行 a」判断一致，则称 W 分离了 a。**命题（verify-then-act）**：若 W 分离 a 且 W 的测量本身在认证感知包络内，则执行 a 在 I_ℓ^α|_W 上 sound，无需再问人。**澄清算子** Q 在「问人 / 主动感知 / 减速慢行」中选择，最大化单位代价的「不安全解释质量」下降，并受 deadline 约束。

**定义 46（跨语言证书迁移）**：把证书拆为**语言无关模板** C 与**语言相关接地表** G_ℓ（物体命名、空间框架、否定极性、量词辖域）。迁移算子 T_{ℓ←ℓ0}: c_{ℓ0}=(C,θ_{ℓ0}) → c_ℓ=(C,θ_ℓ)。称迁移在 ℓ 上**可证**，当且仅当
  (i) 目标解释集不弱于源：I_ℓ^α ⊆ T^{-1}(I_{ℓ0}^α)；
  (ii) 目标层校准有效：cov_ℓ ≥ 1−α；
  (iii) 接地分歧有界：d(G_ℓ,G_{ℓ0}) ≤ d_max(ℓ,ℓ0)，
其中 d 由探针集上的命名/框架/极性差异度量，并把 λ_d·d 计入 s_ℓ。**迁移命题**：若 (i)–(iii) 成立，则 c_ℓ 的可行动作集 ⊆ c_{ℓ0} 的可行动作集，故迁移不新增违例。**负迁移告警**：语言类型学接近不等于接地接近（同源词假朋友、否定极性反转），必须用探针集实测 d，禁止按语系先验批准迁移。

**定义 47（语言覆盖账本与降级契约）**：每种语言 ℓ 维护账本 ledger(ℓ)=(n_ℓ, cov_ℓ, ambig_ℓ, clarify_success_ℓ, mistrans_ℓ, drift_ℓ, last_cal)。**三档**：**certified**（n_ℓ≥n_min ∧ cov_ℓ≥1−α ∧ drift_ℓ≤δ）；**probation**（样本或覆盖不足）；**unsupported**（未校准或漂移超限）。**降级契约**：certified 放开全部动作；probation 只允许可逆/低力动作，不可逆动作必须确认或通过接地见证；unsupported 禁止不可逆动作，只能逐动作确认或安全停机。**禁止静默枢轴**：任何安全关键约束不得经「ℓ→枢轴语言→接地」中转（枢轴会抹掉否定/模态），枢轴仅允许用于非安全闲聊。账本降级立即生效，升级必须重新校准/重接地后按流程恢复。

**定义 48（说话人-语言归因与语言租约）**：多用户场景中每条话语绑定 (speaker s, language ℓ_s, epoch E)。**归因快照**在一个 epoch 内原子一致；任何说话人切换、语言切换或重叠语音判定都 E←E+1。**语言租约** ℓ_lease=(s,ℓ,δ_attrib,E,τ,λ)，所有由其导出的语义/几何证书必须携带同一 E。**非干扰**：ASR/MT 任务的 guarantee 是「不得改写 (s,ℓ,utterance_id) 绑定」，语义任务 rely 在该绑定上；一旦 epoch 前进，旧绑定导出的证书全部失效。**归因一致性命题**：若绑定无撕裂读且 epoch 在切换时单调递增，则不存在用「旧语言证书」为新语言话语授权的执行。

**定义 49（语言感知证书自动机）**：扩展 IP-51 CAR 的状态为 LanguageMode∈{Certified(ℓ), Probation(ℓ), Unsupported}，守卫改为
  m ← min(m_lookup, m_lease, m_persona, m_lang)，
其中 m_lang 由语言档位与 A 的有效性导出；动作还须过 Gate(A) 且不可逆级 ≤ tier(ℓ).permits。**转移**：换人/换语言 → epoch++ → 失效重颁；任何语言事故立即降档；升档只经账本重认证。**合成命题**：由于语言层只做收缩（迁移只在定义 46 条件下才可能放宽，且仍受 A-gate 与 C_global 约束），v20 的 CBF/租约/RG 不变式在加入 m_lang 后仍成立；新增的只是「不可证语言不得执行不可逆动作」这一条更保守的约束。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 LANGUAGE-CERTIFIED SEMANTICS（语言条件化语义证书引擎 LCSem）
1. **语义证书 + 解释证明**：每个语义结论输出 (c_sem, A)，A 记录语言、模型版本、接地表、校准集、覆盖率、歧义集与解析来源；无 A 不进规划。
2. **语言分层共形解释集**：按 ℓ（可再按方言/领域分层）维护非一致性分数分布，输出 I_ℓ^α；覆盖不足自动收缩。
3. **保守解释与接地见证**：优先对解释集求交得 c_cons；不可行时选择「问人/看/碰/减速」的见证方案，verify-then-act。
4. **信任闸门**：把 A 的有效性、语言档位与动作不可逆级绑定，形成 L2.5 语言信任边界。

### 2.2 IP-61 CROSS-LINGUAL CERTIFICATE TRANSFER（跨语言证书迁移 XLCT）
1. **模板/接地分离**：证书模板语言无关，语言差异集中在接地表 G_ℓ；迁移只改参数与接地，不改证书结构。
2. **迁移有效性判据**：定义 46 的 (i)–(iii) 三条同时成立才放行；否则返回「需重接地」。
3. **负迁移探测**：探针集覆盖命名、空间框架、否定极性、量词辖域、礼貌→动作；d 超界即阻断并记事故。
4. **迁移预算**：按语言对维护已证迁移图与等价类，优先复用低成本且 d 小的源语言。

### 2.3 IP-62 LANGUAGE COVERAGE LEDGER（语言覆盖账本与降级契约 LCLD）
1. **账本字段与采集**：在线记录样本数、条件覆盖、歧义率、澄清成功率、误译事故、漂移、上次校准。
2. **三档降级契约**：certified/probation/unsupported 对应不同的动作不可逆级与确认要求。
3. **禁止静默枢轴**：在编译期/运行时禁止把安全关键约束经枢轴语言中转，只允许闲聊枢轴。
4. **语言事故回灌**：把低资源语言、方言、语码转换反例写回 CKB 与课程引擎。

### 2.4 IP-63 MULTILINGUAL ATTRIBUTION RUNTIME（多语言归因运行时 MAR）
1. **说话人-语言绑定**：diarization + 语言识别输出 (s,ℓ,δ_attrib)，共享一个 epoch 快照。
2. **语言租约**：把 v20 的租约扩展为带 (s,ℓ,E) 的语言租约；换人/换语言即 epoch++ 并使旧证书失效。
3. **撕裂读检测**：快照前后 epoch 不一致则重试或单调降级，禁止用半新半旧的绑定。
4. **多用户澄清队列**：澄清请求按说话人与语言排队，避免澄清风暴与人格串扰。

L3: IP-51 CAR(LanguageMode/AttestationEpoch) ← IP-58 CCR(语言租约 + 归因快照)
    → IP-53 CMC(语言分层监控器: 确认粒度/力上限) → IP-39 规划(CBF margin=min(...,m_lang))
    → IP-45 总线(language/attestation/epoch 审计) → IP-47 组合代数(语言接口契约)

    + IP-59 ICV(跨语言对抗 + 枢轴注入) + IP-54 SCV(多语言多用户仿真)
    → IP-50 语言课程 → IP-44 蒸馏 → RCA 重颁(language-conditioned) → 证书热更新

        换人/换语言 → epoch++ → 旧证书原子失效 → 重新语义/接地
```

## 6. 本轮最大风险

**一句话**：所有语言层都只能保证「相对于某个解释集 sound」，而跨语言共形仍是层内边际覆盖、迁移可能把「类型学接近」误当「接地接近」、枢轴翻译可能抹掉否定——最危险的不是听不懂，而是系统用一份**解释证明齐全、下游全部可认证、却对错误语义保持 sound** 的证书去做不可逆动作；因此 E96（条件覆盖）、E97（迁移）、E101（跨语言对抗）必须设为红线，未认证语言默认「不可逆动作先确认/先见证，否则安全停机」，绝不允许静默枢轴。

### IP-60 LCSem：解释证明、保守解释与接地见证
```
def certified_semantics(u, ctx, action):
    lang, conf = language_id(u)
    A = Attestation(model=SEM_MODEL, version=SEM_VER, lang=lang,
                    grounding=G[lang].id, calib=CALIB[lang].id,
                    cov=ledger.cov(lang), ts=monotonic_now())
    # 1) 语言档位闸门：未认证语言不允许不可逆动作
    if not ledger.permits(lang, action.irreversibility):
        return ClarifyOrSafeStop(reason="lang_tier")
    # 2) 按语言分层的共形解释集
    I = conformal_interpretations(u, lang, alpha)
    if not I:
        return ClarifyOrSafeStop(reason="empty_interp")
    # 3) 保守解释：对解释集求交，安全但可能不可行
    c_cons = intersect_over(I)
    if feasible(c_cons, action):
        return A_gated(c_cons, A)                 # 仍需过 Gate
    # 4) 不可行 -> 选接地见证（看/碰/指认），verify-then-act
    W = select_witness(I, action, budget=deadline_left())
    if W is None:
        return dialogue_clarify(u, I, lang, A)    # 用用户语言提问
    I2 = evaluate_witness(W, I)                   # 感知/交互结果分裂解释集
    if safe_compatible(I2, action):
        A = A.with_evidence(W)                    # 证明里记录见证
        return A_gated(intersect_over(I2), A)
    return dialogue_clarify(u, I2, lang, A)

def language_gate(c_sem, A, action, ledger):
    tier = ledger.tier(A.lang)
    ok_model  = A.model in CERT_SET[A.lang]
    ok_cov    = A.cov >= 1 - alpha
    ok_action = action.irreversibility <= tier.permits
    return ok_model and ok_cov and ok_action

def select_witness(I, action, budget):
    # 选择信息增益/代价比最高、且在感知包络内可执行的见证
    best = None
    for W in candidate_witnesses(I, action):
        if not observable_safe(W, budget):       # 遮挡/危险接近直接剔除
            continue
        gain = unsafe_mass(I) - unsafe_mass(evaluate_witness(W, I))
        if best is None or gain / cost(W) > best.gain / best.cost:
            best = Witness(W, gain, cost(W))
    return best.W if best and best.gain > gain_min else None
```

### IP-61 XLCT：跨语言证书迁移与负迁移探测
```
def cross_lingual_transfer(c_src, l_src, l_dst, probe_set):
    # 证书模板语言无关；只迁移参数与接地，不迁移结果合法性
    d = grounding_divergence(G[l_src], G[l_dst], probe_set)
    if d > d_max(l_src, l_dst):
        return TransferResult(ok=False, reason="grounding_divergence")
    if not coverage_ok(l_dst, alpha):
        return TransferResult(ok=False, reason="coverage")
    c_dst = instantiate(C_template, transfer_params(c_src.theta, d))
    # (i) 目标解释集不弱于源：I_l^alpha ⊆ T^{-1}(I_l0^alpha)
    if not subset(interpretations(l_dst), transferred(interpretations(l_src))):
        return TransferResult(ok=False, reason="interpretation_not_subset")
    # 迁移可证：目标动作集 ⊆ 源动作集
    assert acts(c_dst) <= acts(c_src)
    return TransferResult(ok=True, cert=c_dst, d=d)

def negative_transfer_probe(l_src, l_dst):
    # 命名、空间框架、否定极性、量词辖域、礼貌->动作 五类探针
    cases = probe_set(l_src, l_dst)
    fails = [c for c in cases
             if polarity(c) != polarity(translate(c, l_src, l_dst))
             or spatial_frame(c) != spatial_frame(translate(c, l_src, l_dst))]
    return len(fails) / len(cases)          # 失败率超阈值即阻断迁移

def transfer_graph_plan(l_target, certs):
    # 在已证迁移图上找接地分歧最小、路径最短的源语言
    return dijkstra(graph=certified_transfer_edges(), source=l_target,
                    weight=lambda e: e.d)
```

### IP-62 LCLD：语言账本、档位与降级契约
```
def update_ledger(lang, outcome):
    e = ledger[lang]
    e.n += 1
    e.cov = online_coverage(e, outcome)
    e.ambig = running_ambiguity(e, outcome.interp_size)
    e.clarify_success = running_success(e, outcome.clarified)
    e.mistrans += int(outcome.mistranslation)
    e.drift = drift_detect(e, outcome)
    e.last_cal = e.last_cal or outcome.calibrated_at
    # 降级立即生效；升级必须重校准后按流程恢复
    e.tier = demote(e) if (e.cov < 1-alpha or e.drift > delta) else e.tier

def permits(ledger, lang, irreversibility):
    tier = ledger[lang].tier
    if tier == CERTIFIED:   return True
    if tier == PROBATION:   return irreversibility <= REVERSIBLE
    return False                          # unsupported：禁止不可逆

def no_silent_pivot(constraint, path):
    # 安全关键约束不得经过枢轴语言中转
    if constraint.safety_critical and any(h.lang is not constraint.lang
                                          for h in path[:-1]):
        raise PolicyViolation("silent_pivot_forbidden")
    return True

def clarify_or_safestop(u, reason, lang, ledger):
    if ledger[lang].tier == CERTIFIED and reason in ("empty_interp",):
        return dialogue_clarify(u, lang)          # 先问，不直接停
    return SafeStop(reason=reason, speak_in=lang)  # 用用户语言说明原因

### IP-63 MAR：归因快照、语言租约与撕裂检测
```
def attribution_epoch(utterances):
    E = epoch_now()
    bind = {}
    for u in utterances:
        s, l, conf = diarize_and_identify(u, E)
        bind[u.id] = Binding(speaker=s, lang=l, epoch=E, conf=conf)
    return Snapshot(bind=bind, epoch=E)

def on_speaker_or_language_switch(snapshot, new_binding):
    if new_binding.speaker != snapshot.speaker or \
       new_binding.lang != snapshot.lang:
        snapshot.epoch += 1
        invalidate_all_leases(lambda lease: lease.epoch < snapshot.epoch)
    return snapshot

def language_lease(binding, lam):
    return Lease(speaker=binding.speaker, lang=binding.lang,
                 delta=binding.conf, epoch=binding.epoch,
                 tau=monotonic_now(), lam=lam)

def snapshot_read(state):
    e1 = state.epoch; snap = state.value; e2 = state.epoch
    if e1 != e2:
        return downgrade_snapshot(state)   # 禁止半新半旧绑定
    return snap

def car_guard_lang(e, x, cert, persona, lease, lang_lease, ledger, t):
    theta = cert.alpha_e[e] * cert.theta_sim[e]
    m = min(cert.m_lo[e],
            lease.m - lease.lam * (t - lease.tau),
            persona_cap[e](persona),
            lang_cap[e](ledger, lang_lease))
    same_epoch = (lease.epoch == lang_lease.epoch)
    return (m >= theta) and lease_valid(lease, theta, t) and \
           same_epoch and language_gate(cert.sem, cert.attest, cert.action, ledger)
```

| E97 跨语言迁移 soundness | 负迁移静默放行；迁移后违例；较全量重校覆盖差；重接地成本降幅 | 0；0 起；≤2pp；≥3x |
| E98 语言覆盖降级 | unsupported 不可逆无确认执行；静默枢轴违规；澄清成功率；安全停机时延 | 0；0；≥95%；<2s |

| E100 多用户多语言并发 | 3 用户 3 语言不可行率；澄清风暴/死锁；安全停机率；人格串扰 | <10%；0；<5%；0 |
| E101 跨语言对抗鲁棒性 | 否定辖域/量词/空间框架/假朋友/枢轴注入违例；攻击检出率；假朋友检出率 | 0；≥95%；≥95% |
| E102 长时程语言漂移 | 100h 不安全事件；新俚语/方言漂移检出；账本状态正确率；语言事故回灌率 | 0 起；≥95%；100%；100% |

回退：E96 覆盖失效 → 该语言降 probation/unsupported 并强制确认/见证；E97 迁移不可靠 → 关闭迁移、逐语言重接地；E98 降级过严 → 增加澄清/操作员接管通道，但不放宽档位；E99 归因不稳 → 单一活跃说话人仲裁并暂停多用户；E100 澄清风暴 → 排队 + 操作员仲裁；E101 对抗失败 → 该语言对禁用迁移并重校准；任何红线失败 → 熔断回退 v20（单语言语义、无迁移、纯收缩）。

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 语言分层共形仍是层内边际覆盖，方言/俚语子群被平均掉，扩张被欺骗 | 高 | E96 红线；按方言/领域二次分层；在线漂移检测；覆盖不足即降档，绝不静默扩张 |
| 保守解释求交过紧，低资源语言几乎不可用（可用性崩塌复发） | 高 | E98 红线；接地见证优先于澄清；澄清 UX 与操作员接管；档位升级流程与样本主动采集 |
| 跨语言迁移「类型学接近≠接地接近」，假朋友/否定极性反转被静默放行 | 高 | E97/E101 红线；探针实测 d；迁移需 (i)–(iii) 三证；负迁移即阻断并记事故 |
| 枢轴翻译抹掉否定/模态，形成「字面正确、语义反向」 | 高 | 编译期/运行时禁止安全关键约束走枢轴；枢轴仅闲聊；极性探针回归纳入 CI |
| 多用户重叠语音导致说话人-语言归因错误，用错人格/语言档位 | 中-高 | E99 红线；epoch 原子快照；重叠即降级/仲裁；单一活跃说话人兜底 |
| 接地见证不可观测或成本过高（遮挡、危险接近、语义不可区分） | 中 | 见证可行性预检；不可行则澄清；见证预算计入 deadline；见证失败计数触发停机 |
| 多语言评测集泄漏/不真实，离线覆盖好、在线崩 | 中 | 真人多语言试运行；语言事故回灌；按真实用户语言分布重校准；保留 held-out 方言集 |
| 语言档位与人格契约交叉导致确认粒度过高（每步都问） | 中 | 确认合并/批量确认；仅不可逆动作强制确认；操作员模式兜底 |
| 证明 A 被伪造或版本回滚，用旧的高覆盖模型冒充认证模型 | 中 | A 由硬件/安全启动签名；model/grounding/calib 三元组哈希绑定；E95 红队验证 |

## 6. 本轮最大风险

**一句话**：所有语言层都只能保证「相对于某个解释集 sound」，而跨语言共形仍是层内边际覆盖、迁移可能把「类型学接近」误当「接地接近」、枢轴翻译可能抹掉否定——最危险的不是听不懂，而是系统用一份**解释证明齐全、下游全部可认证、却对错误语义保持 sound** 的证书去做不可逆动作；因此 E96（条件覆盖）、E97（迁移）、E101（跨语言对抗）必须设为红线，未认证语言默认「不可逆动作先确认/先见证，否则安全停机」，绝不允许静默枢轴。
