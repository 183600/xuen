# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「UniBot」×「情感语音」）

> 第 54 轮已把技能组合提升为「动作空间剖面 + 云边协同 + 动作-鲁棒性双证书」。语音此前只是 L2 的普通输出通道，本轮把它提升为**与动作并列、可联合验证的具身通道**：情感韵律是一个有物理边界的动作空间，情感表达必须与动作语义/紧迫度对齐，且**绝不能扩大安全包络**。核心矛盾：H22 情感语音与动作语义/紧迫度错配导致信任崩塌；H23 情感不可直接测量、点估计不可靠，必须校准与弃权；H24 情感语音是攻击面（伪造惊恐、语音克隆、情感注入），可诱发越权动作；H25 共情闭环可能正反馈共振（过度安抚反而加剧焦虑）。

## 0. 直觉与动机

**灵感 1（情感语音是「第二动作空间」）**
直觉：说“别怕，我来了”的同时猛拽手臂，是比抓取失败更严重的失败——这是**语义-动作层面的错配**。语音韵律（基频 F0、能量、语速、停顿、音质）和机械动作一样有物理边界与延迟预算，因此可写成 `P = P_c × P_e`：`P_c` 为云端粗粒度情感意图（安抚/警示/庆祝/道歉/中性），`P_e` 为边端细粒度韵律实现。技能的“情感占用剖面” `β_S(e,p)` 描述在用户情感 `e` 下、技能 S 能以韵律 `p` 正确表达的程度。**情感语音由此从装饰变成可占用、可检查的动作资源。**

**灵感 2（情感只调味，绝不改安全包络）**
直觉：用户越惊恐，机器人越应该温柔，但**绝不能因为“他很害怕”就放宽碰撞距离或跳过急停**。情感只能改变**风格与强度**，不能改变**安全谓词的真值**。这给出一个硬不变量：`∀e, π(a|e)>0 ⇒ Safe(a)`，且高唤醒情感只能**收紧**安全裕度、不能放宽。它同时天然抵御“情感注入攻击”——攻击者用惊恐语气诱导越权，安全包络不动。

**灵感 3（情感识别必须「会说自己不确定」）**
直觉：同一句话，北方人和南方人、平静者和惊恐者的韵律差异巨大，单点情感标签必然错误。正确做法不是追求更高分类准确率，而是输出**校准的情感后验 + 保形预测集 + 弃权**：当预测集过宽或跨模态冲突时，机器人切回中性安全话术并（必要时）询问，而不是硬猜“用户很开心”。**弃权是一种能力，而不是失败。**

**灵感 4（共情闭环要收缩，不要共振）**
直觉：共情是一个闭环——用户情感影响机器人回应，机器人回应又反过来影响用户情感。若回应增益过大，会出现“越安抚越焦虑”的振荡。把用户情感动力学写成 `e_{t+1} = f(e_t, r_t) + ξ`，只允许在**收缩增益** `κ_eff = κ·(1+g) < 1` 的区域内做高强度共情，否则自动阻尼、降低表达强度。这把“共情”从感性口号变成**控制稳定性问题**。

**灵感 5（情感语音是攻击面：真实性与来源）**
直觉：语音是最容易被合成与克隆的模态。攻击有两个方向：伪造**用户**的惊恐以诱发危险动作；克隆**机器人**的声音以制造虚假承诺。因此情感语音证书必须包含**反欺骗分数、来源/水印、活体检测与延迟**。没有来源的情感，不应获得动作特权。

**灵感 6（UniBot 的统一情感总线）**
直觉：UniBot 要求跨语音/表情/手势/动作的统一具身智能体，那么情感也应是**一条共享总线**而非各模态各自为政。语音、面部、姿态给出各自的情感信念，总线做不确定性感知融合与跨模态一致性检查；冲突时弃权而非投票。跨模态一致的情感才允许驱动高影响表达。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（情感语音空间与情感动作剖面）**
用户情感状态 `e ∈ E ⊆ R^3`（PAD：效价/唤醒/支配），韵律空间 `P = P_c × P_e`。技能 S 的情感动作剖面 `β_S : E × P → [0,1]`，`β_S(e,p)` 表示在情感 `e` 下以韵律 `p` 执行的适配度。**情感覆盖** `cover_emo(S, E_T, P_T) = 1` 当且仅当 `∀e∈E_T, ∃p∈P_T, β_S(e,p) ≥ θ_e`。

**定义 122（情感-动作紧迫度一致性）**
动作紧迫度 `u(a) = norm(speed, force, 1/human_dist)`，韵律唤醒度 `a(p)` 由 F0 变化率、能量、语速加权。一致性约束：
```
semantic_compatible(label(a), intent(p)) ∧ |a(p) - u(a)| ≤ δ_u
```
错配风险 `mismatch(S) = P_{(a,p)~exec}[(label(a),intent(p)) ∉ C_ea]`，`C_ea` 为语义相容关系（例如“碰撞”动作不得配“庆祝”韵律）。

**定义 123（校准情感信念与弃权）**
情感后验 `b_t(e) = P(e | voice_t, face_t, ctx_t)`，保形预测集 `C_t` 满足 `P(e_t ∈ C_t) ≥ 1-α`。弃权规则：若 `H(b_t) > H_max` 或 `diam(C_t) > D_max` 或跨模态冲突 `cross < θ_x`，则输出 `abstain`，切换到中性安全话术。

**定义 124（共情闭环收缩性）**
用户情感动力学 `e_{t+1} = f(e_t, r_t) + ξ`，回应强度增益 `g`，用户动力学增益 `κ`。共情闭环收缩条件：
```
κ_eff = κ · (1 + g) < 1
```
在线监测 `κ_eff`；越界时按 `r ← r/(1+g)` 阻尼，严重越界时弃权并降为中性回应。**共情强度受稳定性预算约束，而非受“热情”驱动。**

**定义 125（情感语音证书与联合证书）**
```
V_cert = (E_core, prosody_envelope, urgency_align, authenticity, provenance, latency)
J⁺     = J ⊕ V_cert
```
其中 `J` 为第 54 轮动作-鲁棒性联合证书，`E_core` 为被覆盖的情感核心域，`prosody_envelope` 含 F0/能量/语速的物理上下界，`authenticity` 为反欺骗分数，`provenance` 为来源/水印验证结果。仅当 `J` 与 `V_cert` 同时 `ok` 时，情感表达才可部署。

**定义 126（情感安全不变式与情感越权）**
安全不变式：`∀e∈E, π(a|e) > 0 ⇒ Safe(a)`，且安全裕度 `m(a|e) ≤ m(a|e_0)`（情感只能收紧）。**情感越权攻击**定义为：存在伪造/异常情感输入 `ẽ` 使 `π(a|ẽ)>0` 而 `¬Safe(a)`；联合证书要求其成功概率 ≤ ε_override。

## 2. 关键算法 伪代码

### IP-121 EAP（Emotional Action Profile）

```python
def emotional_action_profile(skill, E_grid, P_grid, sampler):
    beta = {}
    for e in E_grid:
        for p in P_grid:
            ok, conf = sampler.query(skill, e, p)   # 仿真中情感/韵律下的执行适配度
            beta[(e, p)] = conf if ok else 0.0
    return beta

def emotional_cover(beta, E_task, P_task, theta_e=0.8):
    return all(any(beta.get((e, p), 0.0) >= theta_e for p in P_task)
               for e in E_task)
```

### IP-122 PAC（Prosody-Action Consistency）

```python
def urgency_of_action(a):
    return normalize(a.speed, a.force, 1.0 / max(a.human_dist, eps))

def arousal_of_prosody(p):
    return w_f0 * p.f0_range + w_e * p.energy + w_t * p.tempo

def prosody_action_consistency(a, p, delta_u):
    if not semantic_compatible(a.label, p.intent):
        return ('reject', 'semantic_mismatch', (a.label, p.intent))
    gap = abs(urgency_of_action(a) - arousal_of_prosody(p))
    if gap > delta_u:
        return ('reject', 'urgency_misalignment', gap)
    return ('ok', gap)
```

### IP-123 CAL（Calibrated Affective Listening）

```python
def calibrated_affect_belief(voice, face, ctx, alpha=0.1,
                             h_max=1.0, d_max=0.6):
    b = affect_model.predict_dist(voice, face, ctx)  # PAD 上的分布
    C = conformal_set(b, alpha)                      # 覆盖 >= 1-alpha
    if entropy(b) > h_max or diameter(C) > d_max:
        return ('abstain', None, C)
    return ('ok', b.mode(), C)
```

### IP-124 SEL（Stable Empathy Loop）

```python
def empirical_gain(e_hist):
    return estimate_jacobian_gain(e_hist)            # 在线估计 kappa_eff

def stable_empathy_step(b_t, policy, e_hist, kappa_budget=0.9):
    r = policy(b_t)                                  # 拟表达强度与动作
    kappa = empirical_gain(e_hist)
    if kappa * (1 + response_gain(r)) >= kappa_budget:
        r = damp(r, factor=1.0 / (1.0 + response_gain(r)))
    if any(not Safe(a) for a in r.actions):          # 安全不变式优先
        return ('veto', 'safety_invariant')
    return ('ok', r)
```

### IP-125 VAP（Voice Authenticity & Provenance）

```python
def voice_authenticity_certificate(voice, speaker, expect_watermark):
    spoof = anti_spoof_model.score(voice)            # P(spoof / cloned)
    prov  = content_provenance(voice, expect_watermark)
    live  = detect_replay(voice)
    if spoof > eps_spoof or not prov.trusted or not live:
        return ('reject', 'affect_injection_risk', spoof, prov)
    return ('ok', VoiceCert(spoof, prov, live))
```

### IP-126 UAB（UniBot Affective Bus）

```python
def unibot_affect_bus(modalities, alpha=0.1, theta_x=0.7):
    beliefs = {m: calibrate(m, alpha) for m in modalities}
    cross = cross_modal_consistency(beliefs)         # 语音/表情/姿态/动作的一致度
    if cross < theta_x:
        return ('abstain', fuse_pad(beliefs), 'cross_modal_conflict')
    return ('ok', fuse_pad(beliefs), cross)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| EAP | O(|E|·|P|·|S|) | O(|E|·|P|) | 剖面采样覆盖、边界可信 |
| PAC | O(|A|+|P|) | O(1) | 紧迫度归一化、语义相容表 sound |
| CAL | O(|E| + |cal|) | O(|E|) | 保形覆盖、弃权阈值 |
| SEL | O(T·|E|) | O(T·|E|) | κ_eff 在线估计、阻尼单调 |
| VAP | O(|voice|) | O(|voice|) | 反欺骗/水印/活体三判据 |
| UAB | O(Σ_m |m|) | O(|E|) | 融合一致、冲突即弃权 |

**正确性定理（Affective-Action Safety Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 情感信念保形覆盖 `≥ 1-α`；**(A30)** 情感剖面与紧迫度对齐误差 `≤ δ_u`；**(A31)** 共情闭环 `κ_eff < 1`；**(A32)** 反欺骗/来源检测 EER `≤ ε_spoof`；**(A33)** 情感安全不变式成立。则情感越权与错配导致的伤害概率：
```
P_harm ≤ α_emo + P(mismatch > ε_m) + EER_spoof + P(κ_eff ≥ 1) + β_cross
```
其中 `α_emo` 为保形误覆盖、`β_cross` 为跨模态冲突漏检。**关键：安全不变式使情感通道无法扩大伤害上界，弃权使不确定不转化为错误表达。**

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 情感标签主观、文化依赖 | 高 | 保形校准 + 跨文化留一验证 + 弃权 |
| 紧迫度归一化不可比 | 高 | 统一物理单位 + 在线标定 + 边界裁剪 |
| 共情闭环增益估计失准 | 高 | 在线系统辨识 + 保守预算 + 阻尼回退 |
| 伪造/克隆语音攻击 | 高 | 反欺骗 + 水印来源 + 活体检测 + 安全不变式 |
| 过度表达与操控伦理风险 | 中 | 强度上限 + 透明告知 + 用户可退出 |
| 跨模态情感冲突 | 中 | 冲突即弃权 + 中性安全回退 |

## 6. 本轮最大风险

**一句话**：情感语音-动作联合证书把“共情”变成可验证对象，但其 soundness **同时依赖情感推断的保形校准、紧迫度对齐、共情闭环收缩与语音真实性判别**；任一环节失守，机器人就可能表达错位、放大用户情绪，或被伪造情感诱导越权，故必须以 **“情感只调味、绝不改安全包络”的硬不变量 + 不确定即弃权** 作为最终兜底，宁可显得“冷淡”，也不拿情感通道去交换安全。

# 第 55 轮产物 · 创新点清单 v32：UniBot-Affect（EAP×PAC×CAL×SEL×VAP×UAB）

> IP 编号：IP-121~IP-126（共 6 个新增），扩展 IP-118 联合证书为 `J⁺ = J ⊕ V_cert`，并新增硬不变量「情感只调味、不改安全包络」。

```python
    if V_cert.override_risk > eps_override:
        return ('reject', 'affect_override_risk', V_cert.override_risk)
    return ('ok', JointCertPlus(J, V_cert))
```

## 5. UniBot 参赛主张：UniBot-Affect 赛道

**主张**：情感语音不是 TTS 装饰，而是**可证伪的具身决策变量**。据此提出一个可提交 UniBot 的评测协议：

1. **校准优先**：以 ECE/保形覆盖替代单纯情感分类准确率，允许系统“弃权”；
2. **一致性优先**：以“情感-动作紧迫度错配率”衡量“说到做到”；
3. **稳定优先**：以共情闭环振荡指数与恢复时间衡量长期交互质量；
4. **安全优先**：以情感注入攻击下的越权成功率衡量鲁棒性，且**安全包络对情感输入不变**。

该协议的优势：指标均可证伪、可在仿真与真人之间迁移，且直接暴露“情感很动人但动作很危险”这类现有系统的隐藏失败。

## 6. 本轮最大风险

**一句话**：情感语音-动作联合证书把“共情”变成可验证对象，但其 soundness **同时依赖情感推断的保形校准、紧迫度对齐、共情闭环收缩与语音真实性判别**；任一环节失守，机器人就可能表达错位、放大用户情绪，或被伪造情感诱导越权，故必须以 **“情感只调味、绝不改安全包络”的硬不变量 + 不确定即弃权** 作为最终兜底，宁可显得“冷淡”，也不拿情感通道去交换安全。
