## 0. 直觉与动机

**灵感 1（力觉传感是唯一的双向物理通道）**
直觉：视觉与表情是「只读」的：机器人看见人，人却看不见机器人在「看」。力觉不同——机器人推人一把，人也推机器人一把；Newton 第三定律使**感知与表达共享同一个物理端口**。因此力觉让「共情」第一次可以成为动词：不只是识别你的不适，而是用柔顺、停顿、回让、轻拍，把「我理解你」写回你身上。这是 RAS/SimRAS 的视觉链路在物理上做不到的。

**灵感 2（共情表达 ≠ 情绪识别，它是一个必须被认证的动作）**
直觉：前几轮最多做到「我紧张，所以机器人变保守」。这是单向共情。真正的共情表达会产生动作：松手、让步、轻拍、引导。动作就有代价、有风险、有副作用。于是共情本身必须进入安全证书——不是「识别得准」就够，而是「表达得安全」。这把「情感计算」从感知问题改写为**带约束的控制问题**。

**灵感 3（力觉是情感的生理锚点，天然抗表情欺骗）**
直觉：假笑可以排练，惊跳反射不能。握力骤增、皮肤电导、回撤延迟 <120ms 是生理泄漏，受能量守恒与反射弧时延约束，比像素更难伪造。上一轮最大风险是「表情欺骗使系统误判情绪安全、过度放宽容差」。力觉给出物理锚点：视觉说「没事」但力觉说「惊跳」，则应信力觉。**情感从「被观测」变成「被物理见证」。**

**灵感 4（共情表达有预算，存在情感-任务 Pareto 前沿）**
直觉：无限共情 = 什么都不做。机器人若一感知到紧张就停下，任务永远完不成。所以共情不是越大越好，而是受「共情预算」约束：表达消耗预算，共振（被理解）回补预算。存在一条**认证共情半径** `r_emp`，在安全与任务约束下最大化「被感知的共情」。这把情感交互与经济学的「稀缺资源分配」接上了。

**灵感 5（合流 → HEL：Haptic Empathic Loop）**
把 SimRAS 的「未来风险闭环」升级为「力觉共情表达闭环」：
1. **FEG Force-Emotion Gateway**：1kHz 力/触觉 → 任务条件残差 → 五类情感代理；
2. **TAR Tactile-Affective Resonance**：面部情绪 `π` 与力觉情感 `a` 的跨模态共振与生理泄漏检测；
3. **AES Affective-Expressive Synthesis**：在共情预算下选择表达动作（软化/让步/停顿/保持/轻拍/引导）；
4. **EEC Empathic-Expressive Controller**：阻抗控制实现表达，能量罐保证无源性；
5. **HEC Haptic Empathy Certificate**：认证前缀同时通过力安全包络、被动性、共情预算；
6. **HER Haptic Empathic Regulation**：把人的压力代理与任务误差一起做协同调节。

**灵感 6（与前序组件的接口）**
- RAS 的 `ERG` 情绪概率 `π` 不再是唯一情感证据，而是与 FEG 的 `a` 做 TAR 融合；
- SimRAS 的 `WM` 滚动预测新增「表达-反应」头：预测 `e_t → a_{t+1}` 的共情响应；
- `ℋ` 从「故障-情绪」扩为「故障-情感-表达」三元假设，显式建模 `X`（表达过度/不足/误判）；

## 1. 形式化定义（增量：定义 266–285）

- **定义 266（HEL 总览）**：`HEL = (FEG, TAR, AES, EEC, HEC, HER)`。定位：SimRAS 的「未来风险闭环」升级为「力觉共情表达闭环」。不变式：1kHz 实时环只跑 FEG + EEC + HEC 早停；TAR/AES/HER 在语义流（10~50Hz）；零学习写操作。
- **定义 267（力觉观测量）**：`φ_t = (F_n, F_t, τ, ẋ, s, spec) ∈ ℝ^{d_φ}`，其中法向力、切向力、力矩、速度、滑移指标、力谱（0–500Hz）。
- **定义 268（力觉-情感代理）**：`a_t = g_φ(φ_t^aff) ∈ Δ^5`，类别 `A = {calm, guarded, startled, struggling, trusting}`；`φ_t^aff = φ_t - D_task(u_t)` 为扣除任务动力学后的情感残差。
- **定义 269（跨模态共情共振）**：`ρ_t = 1 - JS(π_t^{proj} || a_t) ∈ [0,1]`，`π^{proj}` 为将视觉四类情绪投影到五类情感空间的分布。`ρ_t ≥ τ_ρ` 称「共振成立」。
- **定义 270（情感物理锚点 APA）**：融合后验 `P(affect | π, a) ∝ π^{w_π} · a^{w_φ}`，`w_φ = σ(face_quality, ρ_t)`，`w_π = 1 - w_φ`。当 `π(neutral) 高 ∧ a(startled) 高 ∧ leakage=True` 时判 `H_affect_spoof`。
- **定义 271（共情表达动作空间）**：`E = {soften(K), yield(D), pause(Δt), hold, pat(f, A), guide(v)}`，每个动作参数化为阻抗元组 `e = (K, D, F_max, f_pat, A_pat)`。
- **定义 272（共情表达合成）**：`e*_t = argmax_{e∈E} [E[EmpathyPerceived(e)] - λ_task·TaskCost(e) - λ_safe·Risk(e)]`，且须通过预算与力包络门控。
- **定义 273（共情预算）**：`B_emp(t) = clip(B_0 + ∫_0^t (η·ρ_s - c_e·1[e_s≠∅]) ds, B_min, B_max)`。共振回补、表达消耗，防止「共情刷屏」与过度让步。
- **定义 274（力觉共情阻抗控制）**：`F_cmd = K(t)(x_d - x) + D(t)(ẋ_d - ẋ) + F_ff`，其中 `K(t) = K_0(1 - κ_s·ρ_t)`、`D(t) = D_0(1 + κ_d·ρ_t)`；表达通过调节阻抗而非施加蛮力实现。
- **定义 275（共情能量罐与被动性）**：`E_tank(t) = E_0 + ∫_0^t (P_in - P_out) ds`，要求 `E_tank ≥ 0`。主动表达（如 pat）只能从罐中支取，禁止净注入能量。
- **定义 276（共情-故障联合假设）**：`ℋ_HEL = ℋ_RAS × A × X`，`X = {X0 正常表达, X1 表达过度, X2 表达不足, X3 表达误判}`。机器人自己的表达也是故障源。
- **定义 277（共情认证前缀）**：`k*HEL = min(k_VISTA, k_emo, k_wm, k_emp, m)`，`k_emp = max{k : ∀s≤k, |F_cmd(s)| ≤ F_safe(s) ∧ E_tank(s) ≥ 0 ∧ X0 占优}`。
- **定义 278（J_HEL 证书）**：`J_HEL = (J_SimRAS, ρ_t, E_tank, expr_hash, emp_budget, force_signature, hel_ver)`。Valid ⇔ `Valid(J_SimRAS) ∧ E_tank ≥ 0 ∧ ρ_t ≥ τ_ρ ∧ |F_cmd| ≤ F_safe`。
- **定义 279（情感-任务 Pareto 与认证共情半径）**：`P = {(TaskPerf, EmpathyPerceived)}`；`r_emp = max{δ : ∃π, Empathy ≥ δ ∧ Task ≥ 1-ε ∧ Safe}`。
- **定义 280（HER 共情调节）**：`u_t = argmin_{u} E[Stress_{t+H} + λ_task·TaskErr + λ_safe·Risk]`，`Stress` 由 `a_t` 与生理泄漏共同估计。
- **定义 281（力觉欺骗/泄漏检测）**：`leakage = [t_reaction < 120ms] ∧ [ΔK_grip > τ_K] ∧ [E_sig 的阶跃特征]`；仅当视觉与力觉矛盾且泄漏成立时，判定 `H_affect_spoof`。
- **定义 282（AIC-HEL 干扰集）**：`ℰ_HEL = ℰ_SimRAS × ℰ_force × ℰ_emp`，`ℰ_force = {量化噪声, 温漂, 接触瞬态, 滑移误判, 工具重力}`，`ℰ_emp = {过度共情, 共情疲劳, 表达误解}`。

- **定义 284（共情闭环的因果闭合）**：分别估计 `TE(e→a)` 与 `TE(a→e)`；若二者均 `> τ_TE` 称「闭环共情」，否则标 `open_loop_empathy`，其表达不计入 `r_emp`。

```python
# FEG：力觉-情绪网关（1kHz）
class ForceEmotionGateway:
    def __init__(self, fs=1000, tau_startle=0.12):
        self.fs, self.tau_startle = fs, tau_startle

    def sense(self, force_buf, tactile_buf, task_ctx):
        phi = extract_force_features(force_buf, tactile_buf)   # Fn,Ft,tau,xdot,slip,spec
        phi_aff = phi - task_dynamics.predict(task_ctx)        # 任务条件残差
        a = affect_classifier(phi_aff)                         # in Delta^5
        leakage = (startle_latency(phi_aff) < self.tau_startle
                   and grip_stiffness_jump(phi_aff) > TAU_K)
        return {'phi': phi, 'phi_aff': phi_aff, 'a': a, 'leakage': leakage}


# TAR：触觉-情感共振 + 物理锚点融合
class TactileAffectiveResonance:
    def __init__(self, tau_rho=0.6):
        self.tau_rho = tau_rho

    def fuse(self, pi_face, a_force, face_quality):
        pi_proj = project_to_affect_space(pi_face)             # Delta^4 -> Delta^5
        rho = 1.0 - jensen_shannon(pi_proj, a_force)
        w_phi = sigmoid(face_quality, rho)                     # 视觉差 -> 重信力觉
        post = normalize(pow(pi_proj, 1 - w_phi) * pow(a_force, w_phi))
        spoof = (pi_face[NEUTRAL] > 0.7 and a_force[STARTLED] > 0.6
                 and leakage_flag(a_force))
        return {'affect': post, 'rho': rho, 'spoof': spoof}


# AES：共情表达合成（10~50Hz）
class AffectiveExpressiveSynthesis:
    def select(self, affect, rho, task_ctx, budget, joint_post):
        best, best_score = None, 0.0
        for e in EXPRESSIONS:                                  # soften/yield/pause/hold/pat/guide
            benefit = expected_empathy(e, affect, rho)
            cost = task_cost(e, task_ctx)
            risk = expressive_risk(e, joint_post)
            score = benefit - LAMBDA_TASK * cost - LAMBDA_SAFE * risk
            if budget.can_afford(e) and score > best_score:
                best, best_score = e, score
        return best


# EEC：共情表达控制器（1kHz，含能量罐）
class EmpathicExpressiveController:
    def __init__(self, K0=200.0, D0=20.0, E0=5.0):
        self.K0, self.D0, self.E_tank = K0, D0, E0

    def step(self, x, xd, xdd, e, dt, F_safe):
        K = self.K0 * (1 - e.kappa_s * e.rho)
        D = self.D0 * (1 + e.kappa_d * e.rho)
        F = K * (xd - x) + D * (xdd - xd) + e.F_ff
        F = clip(F, -F_safe, F_safe)
        p = float(F @ xd)
        self.E_tank -= p * dt                                   # 注入为正时支取
        if self.E_tank < 0:
            F = passive_project(F, xd)                          # 投影回耗散域
            self.E_tank = 0.0
        return F


# HEC：共情认证前缀
class HapticEmpathyCertificate:
    def certified_prefix_hel(self, A, joint_post, wm_preds, e, E_tank):
        k_sim = self.simras_prefix(A, joint_post, wm_preds)
        k_emp = 0
        for i in range(min(k_sim, len(A))):
            if self.force_envelope_ok(A[i], e) and E_tank >= 0.0:
                k_emp = i + 1
            else:
                break
        return min(k_sim, k_emp, self.m_hel)


# HEL：在线实时环
def HEL_round(M, obs, force_obs, task_ctx):
    # 1) SimRAS 前向（视觉 + 世界模型）
    face_gate = M.erg_wm.recognize(obs.img, obs.x, M.act_seq)
    A = M.vista.ach.propose(obs.x, H=M.vista.H)
    wm_preds = M.wm.rollout(obs.x, M.act_seq, k=min(5, len(A)))

    # 2) FEG：力觉情感代理
    f = M.feg.sense(force_obs.buf, force_obs.tactile, task_ctx)

    # 3) TAR：跨模态共振与欺骗校正
    tar = M.tar.fuse(face_gate['pi'], f['a'], face_gate['face_quality'])
    if tar['spoof']:
        face_gate['gate'] = 'HIGH_RISK'          # 生理泄漏优先于表情
        M.fas.raise_hypothesis('H_affect_spoof')

    # 4) EFS：故障-情感-表达联合后验（扩展 H）
    joint_post = M.efs_hel.synthesize(rho=M.vista.fir.signature(),
                                      face_gate=face_gate, affect=tar['affect'])

    # 5) AES：共情表达选择（受预算门控）
    e = M.aes.select(tar['affect'], tar['rho'], task_ctx,

    # 6) HEC：共情认证前缀

    F_cmd = M.eec.step(obs.x, obs.xd, obs.xdd, e, obs.dt, M.F_safe)
```

## 3. 推导

**引理 13（共情表达的被动性保证）** 取储能函数 `V = ½ẋᵀMẋ + ½ΔxᵀKΔx + E_tank`。在定义 274 的阻抗律与定义 275 的能量罐投影下，`V̇ = -ẋᵀDẋ + Ṗ_active ≤ 0`（当无主动 pat 时严格耗散）。于是人-机耦合端口满足无源性：`∫_0^T F_cmd·ẋ dt ≤ E_0`。故对任意有界人类输入，`|F_cmd|` 有界且不超过 `F_safe`。这第一次让「共情表达」而不是「共情识别」具备可证明的物理安全界。

**引理 14（力觉锚点抑制表情欺骗）** 设表情欺骗成功需同时满足「视觉不可疑」与「力觉无泄漏」。在给定状态条件下二者近似独立，若力觉泄漏检测的漏报率为 `δ_φ`、视觉欺骗先验为 `ε_π`，则 AND 规则下 `P(欺骗通过) ≤ ε_π·δ_φ`；若 `δ_φ ≤ 0.1`，欺骗成功率相对纯视觉下降一个数量级（`≥10×`）。这就是「生理见证」相对像素证据的硬优势。

**引理 15（共情预算有界，不过度表达）** 由定义 273，`Ḃ = ηρ - c_e·1[e≠∅] ≤ η_max - c_e·duty`。当 `ηρ ≤ c_e` 时 `B` 单调下降并被 `B_min` 截断，故长期表达占空比 `duty ≤ η_max/c_e`。结合定义 272 的 `benefit > cost` 门控，系统不会陷入「共情刷屏」，也不会因持续让步而冻结任务。

**定理 14（HEL 端到端安全-共情一致性）** 在 SimRAS 定理 11、引理 13~15 与共情认证前缀定义下，HEL 输出满足：
1. `P(harm) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_force`；
2. `E_tank ≥ 0 ⇒ ∀t, |F_actual(t)| ≤ F_safe(t)`（表达永不越过力包络）；
3. 当 `ρ_t ≥ τ_ρ` 且 `B_emp ≥ B_min` 时，存在表达策略使 `EmpathyPerceived ≥ r_emp`，且 `TaskPerf ≥ 1-ε`；
4. `spoof=True ⇒ λ_risk` 不因表情「安全」而放宽（回退到力觉主导的保守分支）。

**定理 15（任务-情感可辨识性）** 记任务动力学的建模误差为 `ε_d`，`∂φ_aff/∂a` 的最小奇异值为 `σ_min`，条件数为 `κ_J`。则情感代理估计误差 `||â - a*|| ≤ (κ_J/σ_min)·ε_d + ε_cls`。**推论**：在接触丰富且激励充分的阶段（抓取、插入、协作搬运）可辨识性最好；在自由空间或恒定接触阶段，`φ_aff` 退化，必须回退到视觉或主动探针。这意味着「力觉共情」只在接触阶段可信。

**定理 16（共情-故障解耦）** 若每个表达动作 `e` 在证书中登记了名义力签名 `F_e`，则残差 `r = F - F_e`。当 `||r|| > τ_r` 时归因给故障而非表达；混淆概率 `P(confuse) ≤ P(||F_e - F̂_e|| > τ_r/2) + P(genuine_fault < τ_r/2)`。因此「机器人因共情让步」与「机器人因故障失控」第一次在力签名层面可分——这是防止共情被误判为故障、以及故障被共情掩盖的关键。

## 6. 本轮最大风险

**一句话**：HEL 把「共情表达」与「任务执行」放进同一个力觉端口，而这一端口同时承载接触动力学、人的生理反应与机器人自己的表达——一旦任务诱导的力尖峰被误读为情感、或共情让步被误读为故障/失稳，系统就会在「表达理解」与「保持安全」之间产生不可判定的耦合，最坏情况下**因过度共情而主动削弱安全裕度**；这是本轮全部理论依赖的核心假设：**力觉信号中情感分量可从任务动力学中可靠分离，且基于无源性的表达certification足以覆盖人-机接触的不确定性**。

**次级风险与缓解**：
1. **任务-情感混淆**：用任务条件残差 + 接触阶段可辨识性门控；不可辨识时回退视觉/探针；
2. **过度共情导致任务冻结**：共情预算 + Pareto 半径硬约束；
3. **共情-故障误判**：每个表达动作登记名义力签名，残差归因（定理 16）；
4. **柔顺/摩擦的 Sim2Real 差距**：离线域随机化 + 在线能量罐兜底，宁可少表达不可越界；
5. **伦理与操控感**：表达可关闭、可审计、需知情同意，避免「情感操控」。

## 2. 形式化定义（完整版）

**定义 266（HEL 总览）** HEL 是 SimRAS 的「未来风险闭环」升级为「力觉共情表达闭环」：
```
HEL = (FEG, TAR, AES, EEC, HEC, HER)
```
不变式：1kHz 实时环只含 FEG、EEC、HEC 早停；TAR/AES/HER 在语义流（10~50Hz）；零学习写操作；表达动作必须通过「力包络 + 无源性 + 共情预算」三重认证。

**定义 267（力觉观测量）** 力/触觉传感器在 1kHz 输出
```
φ_t = (F_n, F_t, τ, ẋ, s, spec) ∈ ℝ^{d_φ}
```
其中 `s ∈ [0,1]` 为滑移指标，`spec` 为 0–500Hz 力谱（用于惊跳/震颤等高频生理特征）。

**定义 268（力觉-情感代理）** 先做任务条件残差
```
φ_t^aff = φ_t - D_task(u_t)
```
再由 `g_φ: ℝ^{d_φ} → Δ^5` 输出 `a_t`，类别 `A = {calm, guarded, startled, struggling, trusting}`。`D_task` 由任务动力学模型（含工具重力、期望接触力）给出。

**定义 269（跨模态共情共振）** 将视觉四类 `π_t ∈ Δ^4` 投影到五类空间得 `π_t^{proj}`，
```
ρ_t = 1 - JS(π_t^{proj} || a_t) ∈ [0,1]
```
`ρ_t ≥ τ_ρ` 称共振成立；`ρ_t < τ_ρ` 只能进入「观察」而不能进入「表达」。

**定义 270（情感物理锚点 APA）** 融合后验
```
P(affect | π, a) ∝ π^{w_π} · a^{w_φ},
w_φ = σ(face_quality, ρ_t),  w_π = 1 - w_φ
```
当 `π(neutral) > 0.7 ∧ a(startled) > 0.6 ∧ leakage=True` 时判 `H_affect_spoof`，并强制走保守分支。

**定义 271（共情表达动作空间）**
```
E = {soften(K), yield(D), pause(Δt), hold, pat(f, A), guide(v)}
```
其中 `soften` 降低刚度、`yield` 降低阻尼/让位、`pause` 暂停推进、`hold` 保持当前接触、`pat` 主动轻拍（消耗能量罐）、`guide` 以低力引导。

**定义 272（共情表达合成）**
```
e*_t = argmax_{e∈E} [ E[EmpathyPerceived(e)] - λ_task·TaskCost(e) - λ_safe·Risk(e) ]
s.t.  budget.can_afford(e) ∧ force_envelope_ok(e) ∧ (ρ_t ≥ τ_ρ)
```

**定义 273（共情预算）**
```
B_emp(t) = clip( B_0 + ∫_0^t (η·ρ_s - c_e·1[e_s≠∅] - c_p·1[e_s=pat]) ds, B_min, B_max )
```
共振回补、表达消耗；`pat` 额外消耗，防止「共情刷屏」。

**定义 274（力觉共情阻抗控制）**
```
F_cmd = K(t)(x_d - x) + D(t)(ẋ_d - ẋ) + F_ff
K(t) = K_0(1 - κ_s·ρ_t),  D(t) = D_0(1 + κ_d·ρ_t)
```
表达通过调节阻抗实现，而非直接施加更大/更小的蛮力。

**定义 275（共情能量罐与被动性）**
```
E_tank(t) = E_0 + ∫_0^t (P_in - P_out) ds ≥ 0
```
主动表达（pat）只能从罐中支取；若 `E_tank` 将为负，则将 `F_cmd` 投影回耗散域。

**定义 276（共情-故障联合假设）**
```
ℋ_HEL = ℋ_RAS × A × X,  X = {X0 正常表达, X1 表达过度, X2 表达不足, X3 表达误判}
```
机器人自身的表达被视为潜在故障源，与几何/传感器/模型故障同层归因。

**定义 277（共情认证前缀）**
```
k*HEL = min(k_VISTA, k_emo, k_wm, k_emp, m)
k_emp = max{k : ∀s≤k, |F_cmd(s)| ≤ F_safe(s) ∧ E_tank(s) ≥ 0 ∧ P(X0|post) ≥ 1-τ_X}
```

**定义 278（J_HEL 证书）**
```
J_HEL = (J_SimRAS, ρ_t, E_tank, expr_hash, emp_budget, force_signature, hel_ver)
Valid ⇔ Valid(J_SimRAS) ∧ E_tank ≥ 0 ∧ ρ_t ≥ τ_ρ ∧ |F_cmd| ≤ F_safe
```

**定义 279（情感-任务 Pareto 与认证共情半径）**
```
P = {(TaskPerf(policy), EmpathyPerceived(policy)) : policy feasible}
r_emp = max{δ : ∃policy, Empathy ≥ δ ∧ Task ≥ 1-ε ∧ Safe}
```

**定义 280（HER 共情调节）**
```
u_t = argmin_u E[ Stress_{t+H} + λ_task·TaskErr + λ_safe·Risk ]
```
`Stress` 由 `a_t` 与生理泄漏联合估计；在慢环（10Hz）求解，输出给 AES/EEC。

**定义 281（力觉欺骗/泄漏检测）**
```
leakage = [t_reaction < 120ms] ∧ [ΔK_grip > τ_K] ∧ [E_sig 阶跃特征]
```
仅当视觉与力觉矛盾且泄漏成立时判 `H_affect_spoof`；避免把正常用力误判为惊跳。

**定义 282（AIC-HEL 干扰集）**
```
ℰ_HEL = ℰ_SimRAS × ℰ_force × ℰ_emp
ℰ_force = {量化噪声, 温漂, 接触瞬态, 滑移误判, 工具重力}
ℰ_emp   = {过度共情, 共情疲劳, 表达误解}
```

**定义 283（实时不变式）** 力采样 1kHz；FEG <0.2ms；EEC 1kHz、<0.05ms；HEC 早停 <0.1ms；TAR/AES 10~50Hz；任何学习/审计写操作不得进入控制周期。

**定义 284（共情闭环的因果闭合）**
```
closed_loop = [TE(e→a) > τ_TE] ∧ [TE(a→e) > τ_TE]
```
否则标 `open_loop_empathy`，其表达不计入 `r_emp`（避免把「单方面表演」当成共情）。

```
ExprTrace = {(t, e_t, params, ρ_t, E_tank, r_emp)}
```

进入证书哈希链，支持事后归因「这次让步是共情还是故障」。

```python
class EmpathicExpressiveController:
    def __init__(self, K0=200.0, D0=20.0, E0=5.0):
        self.K0, self.D0, self.E_tank = K0, D0, E0

    def step(self, x, xd, xdd, e, dt, F_safe):
        K = self.K0 * (1 - e.kappa_s * e.rho)
        D = self.D0 * (1 + e.kappa_d * e.rho)
        F = K*(xd - x) + D*(xdd - xd) + e.F_ff

        self.E_tank -= p * dt
        if self.E_tank < 0:
            F = passive_project(F, xd)
            self.E_tank = 0.0
        return F


class HapticEmpathyCertificate:

                    and E_tank >= 0.0 and p_x0 >= 1 - self.tau_X):

            else:
```

```
V̇ = -ẋᵀDẋ + Ṗ_active ≤ 0
```
（无主动 pat 时严格耗散）。故人-机耦合端口满足无源性 `∫_0^T F_cmd·ẋ dt ≤ E_0`；对任意有界人类输入，`|F_cmd|` 有界且不超过 `F_safe`。这是「表达」而非「识别」第一次具备可证明的物理安全界。

**引理 14（力觉锚点抑制表情欺骗）** 设欺骗通过需「视觉不可疑 ∧ 力觉无泄漏」。在给定状态下二者近似独立，视觉欺骗先验 `ε_π`、力觉泄漏漏报 `δ_φ`，则 AND 规则下
```
P(欺骗通过) ≤ ε_π · δ_φ
```
当 `δ_φ ≤ 0.1` 时相对纯视觉下降至少一个数量级。

**引理 15（共情预算有界）** 由定义 273，
```
Ḃ = ηρ - c_e·1[e≠∅] - c_p·1[e=pat] ≤ η_max - c_e·duty
```
当 `ηρ ≤ c_e` 时 `B` 单调下降并被 `B_min` 截断，故 `duty ≤ η_max/c_e`；结合定义 272 的 `benefit > cost` 门控，系统不会「共情刷屏」或长期冻结任务。

**定理 14（HEL 端到端安全-共情一致性）** 在 SimRAS 定理 11、引理 13~15 与定义 277 下：
1. `P(harm) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_force`；
2. `E_tank ≥ 0 ⇒ ∀t, |F_actual(t)| ≤ F_safe(t)`；
3. `ρ_t ≥ τ_ρ ∧ B_emp ≥ B_min ⇒ ∃policy: EmpathyPerceived ≥ r_emp ∧ TaskPerf ≥ 1-ε`；
4. `spoof=True ⇒ λ_risk` 不回退到「表情安全」分支，改用力觉主导的保守分支。

**定理 15（任务-情感可辨识性）** 设任务动力学建模误差 `ε_d`，`∂φ_aff/∂a` 最小奇异值 `σ_min`，条件数 `κ_J`，则
```
||â - a*|| ≤ (κ_J/σ_min)·ε_d + ε_cls
```
**推论**：仅在接触丰富且激励充分的阶段（抓取、插入、协作搬运）可辨识性成立；自由空间或恒定接触阶段 `φ_aff` 退化，必须回退视觉或主动探针。

**定理 16（共情-故障解耦）** 每个表达动作登记名义力签名 `F_e`，残差 `r = F - F_e`。当 `||r|| > τ_r` 归因故障；混淆概率
```
P(confuse) ≤ P(||F_e - F̂_e|| > τ_r/2) + P(genuine_fault < τ_r/2)
```
因此「因共情让步」与「因故障失控」第一次在力签名层面可分。

## 8. 本轮最大风险

**一句话**：HEL 把「共情表达」与「任务执行」放进同一个力觉端口，而这一端口同时承载接触动力学、人的生理反应与机器人自己的表达——一旦任务诱导的力尖峰被误读为情感、或共情让步被误读为故障/失稳，系统就会在「表达理解」与「保持安全」之间产生不可判定的耦合，最坏情况下**因过度共情而主动削弱安全裕度**；这是本轮全部理论依赖的核心假设：**力觉信号中情感分量可从任务动力学中可靠分离，且基于无源性的表达认证足以覆盖人-机接触的不确定性**。
