# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS 具身计量审计×实时执行图」IP-287~294；灵感循环第 3 轮；本轮灵感：「数据配比」×「流匹配策略」）

> R72 的审计链覆盖了「推理时测量」，但有两个未审计的端点：
> - **上游端点：数据配比**。所有测量链、所有先验、所有校准，最终由训练数据的**混合比例 w** 决定。R72 审计「证据可不可信」，却不审计「证据是从哪种世界配比里学来的」。配比是**证据的证据（meta-evidence）**，也是最容易被 Goodhart 的旋钮：调 w 就能在验证集上刷低 ECE，却让最差来源的校准崩掉。
> - **下游端点：生成输运**。R72 把策略当给定黑箱。但流匹配策略不是「一次前向」，而是**一段 ODE 输运**：coupling、步数、solver、guidance、条件嵌入共同决定终端分布。审计只看到输出 a，看不到**a 是被哪股速度场、哪条轨迹、哪份数据输运出来的**。输运误差与配比偏差在终端叠加，却不在任何证书里。
>
> 本轮两个灵感正好补两端：
> - **数据配比**：把配比升级为**可审计的测度**——每个来源携带 (有效样本量, 覆盖, 污染, 漂移, 校准, 追溯链)，定义**有效配比** w^eff 与**配比杠杆**；放弃「平均配比」的补偿式思维，改为**逐来源非补偿性审计**。
> - **流匹配策略**：把策略升级为**可溯源的受控输运**——证明混合流的速度场恰是**责任加权平均** v_t^w = Σ r_i v_t^i，于是「这条动作来自哪些数据」可由**责任沿轨迹积分**得到；并把 solver 误差、混合认知不确定度、配比偏差统一进风险缩放。
>
> 核心命题：**把计量审计链从「推理时的证据」向两端延伸——上游到数据配比（谁教会了它），下游到生成输运（它凭什么生成这个动作）——形成 AUDITED-MIXTURE-FLOW（AMF：配比可审计 × 流可溯源 × 风险可引导 × 反作用可预算的生成式证据闭环）。** 且必须承认：**配比本身会反作用**——部署策略选择数据、合成数据回流配比，会形成 L4 配比反作用（模型坍缩/回声室），必须纳入统一反作用预算。

## 0. 直觉与动机

**灵感 1（数据配比 → 配比是上游先验，不是训练超参）**
直觉：w 看起来只是 DataLoader 的采样概率，但它等价于一个**关于「世界由哪些子分布组成」的先验**。w 大 ⇒ 该来源在低密度区也有速度场支撑；w 小 ⇒ 该来源在混合中被其他来源的似然淹没（**少数源坍缩**）。R72 在推理时把 U_epi 当「模型没见过」，但 U_epi 的**可控源头正是 w**。所以「配比」不是调参，而是**epistemic 不确定度的预算分配**。

**灵感 2（流匹配 → 策略是一次受控输运，不是一次函数调用）**
直觉：流匹配学速度场 v_θ(x,t)，从噪声 x_0 积分到动作 x_1。它天然提供三样审计抓手：(i) **轨迹**（可检查中间态是否进入危险区）；(ii) **速度场**（可检查局部方向是否被污染源主导）；(iii) **输运代价**（OT coupling 越小，离散化误差越小）。把策略看成「输运一个分布」，就能问 R72 问不出的问题：**这次生成把哪个分布输运过来了？输运得稳不稳？**

**灵感 3（配比×流的精确耦合 → 混合速度场 = 责任加权平均）**
直觉：这是本轮最关键的一条数学事实。若每个来源 i 有自己的概率路径 p_t^i 与速度场 u_t^i，混合分布 p_t^w = Σ w_i p_t^i 的速度场不是简单平均，而是
**v_t^w(x) = Σ_i r_i(x,t) u_t^i(x)，r_i = w_i p_t^i(x) / p_t^w(x)。**
r_i 是「在 (x,t) 处，这个样本有多大概率来自源 i」。于是**一次 w 的调整、一个来源的缺失，都会被 r 自动翻译成速度场的局部改写**。这既是配比影响策略的机制，也是流溯源的数学基础。

**灵感 4（配比审计 → 从轨迹反推数据来源，追溯链在生成侧闭环）**
直觉：既然 v^w 是责任加权平均，那么沿生成轨迹积分 r_i，就得到这条动作的**来源贡献谱** ρ_i。这让 R71 的 TCHAIN（数据追溯链）第一次能延伸到**生成物**：不是「数据集里有这帧」，而是「这条轨迹有 63% 由仿真源、31% 由遥操作源、6% 由合成源输运而来」。若某条危险轨迹的 ρ 高度集中在已审计失败的来源上，就能**逐轨迹否决**。

**灵感 5（风险感知流引导 → 把 λ 接进 ODE，而不是只接在动作后）**
直觉：R72 的 λ 只在「生成完之后」缩放/裁剪动作，是**事后刹车**。流匹配允许**事中导航**：在速度场上加一个风险势的负梯度 v^λ = v^w − λ∇Φ，让输运过程本身绕开高风险区域。λ 直接来自 E-RISK 的 λ_floor，于是「不确定度越大 ⇒ 引导越强 ⇒ 终端风险越低」变成一条可推导的性质，而不是一句口号。

**灵感 6（L4 配比反作用 → 模型坍缩是反作用阶梯的第四层）**
直觉：R72 有 ψ(L1)/z(L2)/c(L3) 三层反作用。现在加一层：**策略生成 → 被采集成新数据 → 改变 w → 改变策略**。若合成/自采集数据占比无约束增长，少数真实源被淹没，w 缓慢漂移到「模型自说自话」的不动点——这就是**生成式模型坍缩**。必须给真实源一个**锚定下界 w_real ≥ w_anchor**，并把配比漂移成本 c_reflex^w 纳入 B_reflex_total。

## 1. 形式化定义（增量：定义 366–380）

**定义 366（AMF 总览与五不变式）** AMF = (MIX-METRO, AMF-CFM, FLOW-TRACE, UQ-FLOW, R-FG, EREFLEX†)，五不变式：
(i) **配比可审计**：每个来源 i ∈ I 携带六元组 + (N_i^eff, κ_i, c_i, δ_i, w_i)，有效配比 w^eff 由污染/去重/漂移校正后重归一化；
(ii) **流可溯源**：生成轨迹必须携带来源贡献谱 ρ 与速度分解 v^w = Σ r_i u^i 的可复算哈希；
(iii) **不确定度三分解**：U² = U_within² + U_between² + U_solver²，三者同权进入 λ；
(iv) **非补偿性配比否决**：任一来源审计失败 ⇒ w_i^eff = 0 或整批拒用，不得用其他来源「补量」；
(v) **严格逐指令退化**：配比审计失效 ⇒ 固定 w + R72；流溯源失效 ⇒ 只保留终端动作 + R72；引导失效 ⇒ λ 退回事后缩放；全失效 ⇒ R68/R72 硬安全包络。

**定义 367（数据配比测度与有效配比）** 来源集 I，原始配比 w ∈ Δ^{|I|−1}，混合测度 μ_w = Σ_i w_i μ_i。来源 i 的污染率 c_i、去重率 d_i、漂移质量 δ_i 给定后，
w^eff_i = w_i (1 − c_i)(1 − d_i)(1 − δ_i) / Σ_j w_j (1 − c_j)(1 − d_j)(1 − δ_j)。
**审计对象是 w^eff，不是 w**——原始配比可以很好看，有效配比可能已经塌向污染源。

**定义 368（配比计量六元组 MIX-METRO）** 每个来源 i 的配比指标
m_i = (φ_i, m̂_i, u_i, D_i, τ_i, I⊥_i) ⊕ (N_i^eff, κ_i, c_i, δ_i, w_i^eff)，
其中 φ_i 为该来源到目标分布的构造映射，m̂_i 为校准后的经验测度，u_i 为测度不确定度，D_i 为有效域，τ_i 为来源追溯链，I⊥_i 为「该来源不可被其他来源代理」的反指标（反 Goodhart），N_i^eff 为有效样本量，κ_i 为覆盖半径，c_i 为污染率，δ_i 为协变量漂移。**缺任一项，该来源不得进入混合。**

**定义 369（混合流匹配与责任分解 AMF-CFM）** 来源 i 的概率路径 p_t^i 满足连续性方程 ∂_t p_t^i + ∇·(p_t^i u_t^i) = 0，p_0^i = p_0（同一噪声基）。混合路径 p_t^w = Σ_i w_i p_t^i，则其速度场
v_t^w(x) = Σ_i r_i(x,t) u_t^i(x),   r_i(x,t) = w_i p_t^i(x) / p_t^w(x),   Σ_i r_i = 1。
训练目标为责任加权条件流匹配：
L(w) = E_{t, i∼w, x_1∼p_1^i, x_t|x_1} [ ‖ v_θ(x_t, t, e_i) − u_t^i(x_t|x_1) ‖² ]，
其中 e_i 为来源嵌入（provenance token）。**流策略 σ = (coupling, solver, N_steps, guidance, e)** 是显式策略变量。

**定义 370（配比杠杆、输运误差与流策略审计）**
- **配比杠杆**：∂v_t^w/∂w_i = (p_t^i/p_t^w)(u_t^i − v_t^w)。它度量「把 w_i 改一点，速度场在哪变」；杠杆大的来源是**高风险/高价值来源**。
- **输运误差**：若部署目标分布 q 的速度场为 v^q，同一噪声起点下 ‖x_1^w − x_1^q‖ ≤ ((e^{LT}−1)/L) · sup_t ‖v_t^w − v_t^q‖（L 为 v 的 Lipschitz 常数）。
- **流策略指标**：transport cost（OT coupling）、solver 局部/全局误差（Euler O(h)、高阶 O(h^p)）、guidance distortion、mode coverage、steps 的 Pareto 前沿。**σ 与 w 一样，必须进证书。**

**定义 371（流策略不确定度三分解 UQ-FLOW）** 设动作 A、来源 S∈I、P(S=i)=w_i^eff、A|S=i ∼ p^i，则
**U_within² = E_{i∼w}[Var_{p^i}(A)]**（源内：含 aleatoric 与传感器），
**U_between² = Var_{i∼w}(E_{p^i}[A])**（源间：配比诱导的认知不确定度），
**U_solver² = Var(输运离散化误差)**（步数/耦合/solver 诱导）。
总不确定度 **U² = U_within² + U_between² + U_solver²**（全方差定律 + 独立输运误差）。**三者同权进入 E-RISK 的 λ，不允许「solver 误差可忽略」的先验假设。**

**定义 372（轨迹级流溯源 FLOW-TRACE）** 对生成轨迹 {x_t}_{t∈[0,1]}，定义来源贡献谱
ρ_i(x_0) = (1/T) ∫_0^T r_i(x_t, t) dt,   Σ_i ρ_i = 1。
ρ 是**这条动作的来源责任分布**；轨迹证书附 (ρ, 最大责任源 i* = argmax ρ_i, 责任熵 H(ρ), 各源 τ_i 哈希)。**当 ρ_{i*} 指向已审计失败的来源、且 H(ρ) 低（高置信归因）时，该轨迹可被逐条否决。**

**定义 373（混合校准缺口 MCG）** 设源 i 的校准误差 ECE_i，混合策略的校准误差 ECE(p^w)。
MCG = ECE(p^w) − Σ_i w_i^eff ECE_i。
MCG > 0 表示**混合本身制造了新的校准误差**（来源间分布重叠导致责任模糊、边界样本被错误归属）。**MCG 是配比审计的独立否决指标：MCG 超阈 ⇒ 不允许用「加权平均校准」为混合背书。**

**定义 374（风险感知流引导 R-FG）** 设风险势 Φ: 𝒳 → ℝ_+（对轨迹前缀的风险上界，可由 R72 的 λ 与障碍距离构造，L_Φ-Lipschitz）。引导速度场
v_t^λ(x) = v_t^w(x) − λ ∇_x Φ(x),   λ = λ_{E-RISK}(U_ale, U_epi, H_z, u_tac)（R72 定义 360）。
**λ 由多重不确定度驱动，故引导强度随「配比不确定 + 接触不确定 + 意图不确定」单调增**；当 λ ≥ λ_floor 时，即使 base 速度场指向高风险区，终端分布也被 Gibbs 倾斜 p_λ ∝ p^w exp(−λΦ)。

**定义 375（配比-风险联合优化 MIX-DRO）** 双层鲁棒问题：
w* = argmin_{w∈Δ, 审计可行} max_{q∈𝒬_ε(w)} E_q[Risk(π_{w,σ})] + β·MCG(w) + γ·U_solver(σ)
s.t. ∀i 审计通过(w_i^eff)，w_real ≥ w_anchor，|σ| ≤ 复杂度上限，
其中 𝒬_ε(w) 为以 p^w 为中心、半径 ε 的分布鲁棒球（ε 由 U_between 给出）。**内层训练流策略，外层在审计约束下用指数梯度/镜像下降更新 w。**

**定义 376（AMF-IVG 门控）** 在 R72 E-IVG 基础上新增：
- 配比：任一源审计失败（c_i > τ_c、ECE_i > τ_ece、κ_i < τ_κ、I⊥_i 失效）、MCG > τ_mcg、w_real < w_anchor；
- 流：solver 误差 > τ_solver、transport cost 超预算、guidance distortion > τ_gd、mode coverage < τ_cov；
- 溯源：H(ρ) > τ_Hρ（归因太糊）或 ρ_{i*} 指向失效源。
任一触发 ⇒ 对应模块降级（配比 → 固定 w；流 → 固定 σ_min + 终端裁剪；溯源 → 只保留动作）。

**定义 377（AMF 证书 J_AMF）** J_AMF = (J_EMB, mix_hash(w^eff, {m_i}), flow_trace_hash(ρ), uq_decomp_hash, mcg, solver_budget, dro_dual, amf_ver)。
Valid ⇔ Valid(J_EMB) ∧ 全源审计通过 ∧ 流溯源可复算 ∧ UQ 三分解自洽 ∧ MCG ≤ τ_mcg ∧ 引导 λ 记录完整。

**定义 378（威胁模型 AIC-AMF）** ℰ_AMF = ℰ_EMB × ℰ_mix × ℰ_flow：
ℰ_mix = {配比投毒（高污染源伪装低污染）、去重规避、漂移源静默混入、Goodhart 配比（刷验证 ECE 牺牲最差源）、合成数据回声室}；
ℰ_flow = {coupling 后门、solver 步数隐写（用步数编码触发）、guidance 反向利用（把风险势当奖励）、责任分解规避（把污染源特征混入干净源）}。

**定义 379（严格退化链）**
- 配比审计失效 ⇒ w = w_exp（经验固定配比）+ R72；
- 流溯源失效 ⇒ 仅用终端动作 + R72 事后 λ 缩放；
- 引导失效 ⇒ λ 退回事后缩放（R72 原语义）；
- 全失效 ⇒ R72 / R68。
**安全侧只增不减：AMF 每一步都保留 R72 的 λ_floor 与 R68 硬安全包络。**

**定义 380（配比反作用 L4 与真实源锚定）** 配比反作用动力学
w_{t+1} = Mix(w_t, D_{t+1}^{robot}, D_{t+1}^{synth}),  c_reflex^w = D_KL(w_{t+1} ‖ w_t) + λ_w·𝟙[w_real < w_anchor]，
纳入统一预算 Σ(c^ψ + c^z + c^c + c^w) ≤ B_reflex_total。**w_real ≥ w_anchor 是防模型坍缩的非补偿性硬约束。**

```python
# IP-295 MIX-METRO：配比计量审计（离线/部署期，输出 w_eff 与门控）
class MixtureMetrology:
    def audit(self, sources, w):
        for i, src in sources.items():
            c_i  = src.contamination_estimate()      # 独立金标/交叉一致性
            d_i  = src.dedup_ratio()
            dlt  = src.covariate_shift(target=src.target_ref)
            ece  = src.calibration_ece()
            kappa = src.coverage_radius()
            if (c_i > TAU_C or ece > TAU_ECE or kappa < TAU_K
                or not src.tchain.valid() or not src.I_perp.valid()):
                src.fail("audit")                    # 非补偿性：该源直接出局
        w_eff = normalize({i: w[i]*(1-s.c_i)*(1-s.d_i)*(1-s.delta)
                           for i, s in sources.items() if s.audited})
        mcg = mixture_calibration_gap(sources, w_eff)   # 定义 373
        return MixtureState(w_eff=w_eff, mcg=mcg,
                            gate=(mcg <= TAU_MCG and w_eff.real >= W_ANCHOR))

# IP-296 AMF-CFM：责任加权条件流匹配 + 来源嵌入
def amf_train_step(batch, w_eff, model):
    i, x1 = batch.source, batch.x1
    x0    = sample_noise(x1.shape)
    t     = rand_uniform()
    xt    = flow_interp(x0, x1, t)                  # coupling: OT 或 independent
    ut    = flow_velocity(x0, x1, t)                # 条件速度 u_t^i
    e_i   = source_embedding(i)                     # provenance token
    pred  = model(xt, t, e_i)
    # 责任加权：w_eff 直接写进采样/损失权重
    loss  = (w_eff[i] * ((pred - ut) ** 2).mean(1)).sum() / w_eff[i].sum()
    return loss                                     # 反传更新 v_θ

# IP-297 FLOW-TRACE：沿 ODE 积分责任，输出轨迹级来源谱
def flow_trace(model, x0, T=1.0, N=32):
    xt, rho = x0, zeros(n_sources)
    for k in range(N):
        t  = k / N * T
        # 责任 r_i 由各源密度头/来源嵌入路由给出（或 mixture-of-experts 路由）
        r  = model.responsibilities(xt, t)          # Σ r = 1
        rho += r / N
        v  = model.velocity(xt, t)                  # = Σ r_i u_i（若训练一致）
        xt = xt + (T / N) * v                       # Euler / RK4
    return xt, rho, entropy(rho), argmax(rho)

# IP-298 UQ-FLOW：三分解不确定度 -> 进 λ
def uq_flow(model, x0, sources, w_eff, sigma):
    # 源内：逐源采样方差；源间：源条件均值的加权方差；solver：多步数差
    within  = sum(w_eff[i] * var_source(model, i, x0) for i in sources)
    means   = [mean_source(model, i, x0) for i in sources]
    between = weighted_var(means, w_eff)
    solver  = var([integrate(model, x0, steps=s) for s in sigma.step_grid])
    return UQDecomp(within=within, between=between, solver=solver,
                    total=sqrt(within + between + solver))

# IP-299 MIX-DRO：审计约束下的配比鲁棒优化（指数梯度 + 可行投影）
def mix_dro_update(w, grad_risk, mcg_grad, sources, lr):
    w = w * exp(-lr * (grad_risk + BETA * mcg_grad))
    w = project_simplex(w)
    w = enforce_audit(w, sources)           # 失败源置 0
    w = enforce_anchor(w, W_ANCHOR)         # w_real >= W_ANCHOR（非补偿）
    return normalize(w)

# IP-300 R-FG：风险感知流引导（λ 来自 E-RISK）
def risk_guided_flow(model, x0, lam, phi, T=1.0, N=32):
    xt = x0
    for k in range(N):
        t = k / N * T
        v = model.velocity(xt, t)
        g = grad_x(phi, xt)                 # 风险势梯度（障碍/速度/力上界）
        xt = xt + (T / N) * (v - lam * g)   # 事中导航：不做事后裁剪
    return xt

# IP-301 AMF 主闭环（配比审计 -> 生成 -> 溯源 -> 门控 -> 证书）
def AMF_round(M, obs, w_raw, target):
    # 1) 配比审计（离线/低频）
    mix = M.mixmetro.audit(M.sources, w_raw)
    if not mix.gate:
        M.mode = "R72_FIXED_MIX"             # 退化：固定经验配比
        return M.r72_round(obs)
    # 2) 流策略生成（流匹配 ODE）
    x0  = M.encoder(obs, M.intent_ctx)       # 条件 = 观测 + R72 意图/接触上下文
    uq  = M.uqflow.decompose(x0, M.sources, mix.w_eff, M.sigma)
    lam = M.e_risk.scale(uq.total, M.u_ale, M.u_epi, M.H_z, M.u_tac)
    a1  = M.rfg.generate(x0, lam, M.risk_potential)
    rho = M.trace.attribute(x0)              # 轨迹来源谱
    # 3) 溯源门控 + 证书
    if rho.entropy > TAU_HRHO and not rho.argmax_is_trusted(M.sources):
        M.mode = "TERMINAL_ONLY"             # 退化：只用动作 + R72 事后 λ
        a1 = M.e_risk.post_scale(a1, lam)
    return a1, J_AMF(M, mix, uq, rho, lam)
```

## 3. 推导

**引理 33（混合速度场的责任分解精确性）** 设各源路径 p_t^i 满足连续性方程且共享 p_0。则混合路径 p_t^w = Σ_i w_i p_t^i 满足
∂_t p_t^w + ∇·(p_t^w v_t^w) = 0,  v_t^w = Σ_i r_i u_t^i,  r_i = w_i p_t^i / p_t^w。
证明：∂_t p^w = Σ w_i ∂_t p^i = −Σ w_i ∇·(p^i u^i) = −∇·(Σ w_i p^i u^i) = −∇·(p^w Σ (w_i p^i/p^w) u^i)。∎
系：**配比对策略的作用不是「换个采样器」，而是精确地改写速度场的责任路由；流溯源也因此有严格的概率解释。**

**引理 34（配比杠杆与输运稳定性）** (i) ∂v_t^w/∂w_i = (p_t^i/p_t^w)(u_t^i − v_t^w)；(ii) 对两个配比 w, w' 与同一初始噪声，
‖x_1^w − x_1^{w'}‖ ≤ ((e^{LT}−1)/L) · sup_t ‖v_t^w − v_t^{w'}‖ ≤ ((e^{LT}−1)/L) · Σ_i |w_i − w'_i| · sup_t‖u^i − v^w‖。
证明：(i) 由定义 369 直接求偏导；(ii) 对 δ_t = x_t^w − x_t^{w'} 用 Grönwall：d‖δ_t‖/dt ≤ L‖δ_t‖ + ‖Δv_t‖。∎
系：**配比的一个小扰动会被 e^{LT} 放大——流匹配的步数越多/速度场越陡，配比误差越危险；杠杆大的源必须单独审计。**

**引理 35（不确定度三分解的完备性）** 在定义 371 的混合模型下，
Var(A) = E_{S∼w}[Var(A|S)] + Var_{S∼w}(E[A|S]) = U_within² + U_between²。
叠加独立输运误差 U_solver² 后，U² = U_within² + U_between² + U_solver² 为总方差的上界（若 solver 误差与源相关则用协方差项修正）。证明：全方差定律 + 方差的可加性（独立时）。∎
系：**R72 只把 U_epi 当「模型没见过」，AMF 把它拆成「源内噪声」与「源间配比差异」；后者可被 w 直接控制，前者不能——这决定了配比优化该动哪一部分。**

**引理 36（轨迹溯源的一致性、不可伪装性与忠实性条件）** (i) 由 Σ r_i = 1 得 Σ ρ_i = 1，ρ 是概率向量；(ii) 若模型速度场严格等于定义 369 的混合速度场，则 ρ 是「轨迹在源上的占用测度」，且当终端源支撑不相交（可分离）时，x_1 ∈ supp p_1^i ⇒ ρ_i → 1；(iii) **忠实性条件**：v_θ 必须可写成「共享基 + 来源条件残差」的线性/路由结构，否则神经网络的**特征叠加（superposition）**会使 ρ 只具**名义归因**意义，不保证反事实忠实。
证明：(i)(ii) 由 r 的定义与可分离支撑直接得到；(iii) 为反例构造：两层 MLP 可在不改变输出的情况下重参数化源嵌入，使 r 任意但 v 不变。∎
系：**FLOW-TRACE 的证书必须声明「名义归因」还是「忠实归因」，并在架构上强制路由（mixture-of-experts / 加性源头）才可升级为忠实归因。**

**引理 37（配比的非补偿性审计与安全单调）** 设源 i 审计失败，其风险下界为 R_i^bad > 0，且其余源风险非负。则对任意 w_i > 0，
R(w) ≥ w_i^eff · R_i^bad；令 w_i^eff = 0 得 R(w') ≤ R(w)，且任何提高干净源权重的补偿都无法抵消 w_i^eff R_i^bad 这一项。
证明：风险对源可加且非负，污染源贡献下界独立于其他源权重。∎
系：**「多加点干净数据把脏数据稀释掉」在安全上不成立——这是 R71 非补偿性否决在配比层的再现。**

**引理 38（风险引导的终端风险下降）** 设 Φ 光滑、L_Φ-Lipschitz，沿 v^λ = v^w − λ∇Φ 有
dΦ/dt = ⟨∇Φ, v^w⟩ − λ‖∇Φ‖²。
若未引导漂移有界 ⟨∇Φ, v^w⟩ ≤ B，则 Φ(x_T) ≤ Φ(x_0) + BT − λ∫_0^T ‖∇Φ‖² dt。故当 λ > B / ‖∇Φ‖²（引导项压过漂移）时终端风险严格下降；且 λ 越大、Φ 越陡，下降越多。
证明：链式法则 + 积分。∎
系：**λ_floor 从「事后缩放系数」升级为「事中导航强度」；不确定性越大，ODE 越被风险势拽向安全区。**

**定理 27（AMF 严格包含与风险单调）** 在 A111–A116（配比测度可审计、流速度可分解、UQ 三分解有界、非补偿审计可行、引导 Lipschitz、反作用预算收敛）下：AMF 在退化条件下逐指令等于 R72/R71/R68（定义 379）；对任意有效执行，其风险界 ≤ R72 风险界。**安全单调不减，生成质量收益仅在「配比可信、流可溯源、引导有效」时兑现。**

**定理 28（AMF 证书 ⇒ 配比/输运/校准安全）** 若一次生成通过 J_AMF，则 (i) 全源审计通过 ⇒ 无已知污染源进入混合；(ii) w^eff 与 ρ 可复算 ⇒ 配比与轨迹来源不可静默篡改；(iii) UQ 三分解自洽且进入 λ ⇒ 源内/源间/solver 不确定度都被风险缩放看到；(iv) MCG ≤ τ_mcg ⇒ 混合没有制造超阈校准误差；(v) J_EMB 有效 ⇒ 具身层安全成立。综上，**配比—输运—执行三层风险 ≤ ε_amf（相对审计模型）**。

**定理 29（MIX-DRO 的可行性保持与收敛）** 在凸风险损失与凸审计约束下，指数梯度 + 单纯形投影 + 失败源置零 + 锚定投影的迭代保持可行域不变；对固定内层策略，外部权重以 O(1/√T) 收敛到约束 minimax 点。**非补偿审计约束不破坏收敛性，只收缩可行域。**

## 6. 本轮最大风险

**一句话**：AMF 把安全从「相信推理时的计量证书」进一步转移到「相信 **配比审计能识别所有污染/漂移源**、相信 **神经速度场的来源分解是忠实的而非名义的**、相信 **混合校准缺口 MCG 能捕获配比自身制造的偏差**」——**如果污染源通过特征叠加把自身伪装进干净源的速度场（责任分解只给出好看的 nominal ρ，反事实归因完全错误），或者 MIX-DRO 在验证集上刷低 MCG 却把最差来源的校准推到分布外，或者 L4 配比反作用在长时程把 w_real 压到锚定边界以下、模型缓慢坍缩成自说自话的不动点——系统会拿着一份「配比已审计、流已溯源、证书已盖章」的生成策略，在真机上生成一条来源谱看起来 99% 干净、实际上 99% 来自被污染源的动作，事后审计发现「每条轨迹的 ρ 都合法、每个源的 ECE 都在阈值内、每轮 MCG 都通过」，这就是**生成式层面的「自信地错自己的来源与输运」**。** 而且它比 R72 更隐蔽：R72 至少错在「测量」，AMF 可能错在「对测量的来源撒了谎」。

次级风险与缓解：
1. **责任分解不忠实** → 强制**可分解架构**（共享基 + 加性来源头 / mixture-of-experts + 路由稀疏约束），并在证书里区分 `nominal` / `faithful` 两级归因；定期用**反事实源替换测试**（把源 i 换成 i′，看 ρ 与输出是否同步变）验证忠实性。
2. **配比审计漏源/漂移** → 来源卡片带**在线漂移探测器**（MMD/能量分数）+ **密封污染金标集**；源污染率 c_i 用区间而非点估计，取上界进 w^eff。
3. **MCG 被 Goodhart** → MCG 与被审计的最差源 ECE 联合门控；**禁止用加权平均校准为混合背书**；验证集按源分层，报告最差源而非平均。
4. **L4 模型坍缩** → 真实源锚定 w_real ≥ w_anchor 作为**非补偿硬约束**；合成数据设**可追溯配额**与「新颖性/一致性」双门；监控 w 的熵与真实源占比。
5. **引导把分布推离数据支撑** → 引导只在**可信域 D** 内生效，超出即退回事后 λ 缩放；监控 guidance distortion 与 mode coverage。
6. **证书开销/实时性** → 配比审计离线、流溯源与 UQ 在感知域异步、控制域只读快照（继承 R72 三域分离），证书异步组装。
7. **复杂度爆炸** → 模块上限：|I|≤32、|sources in trace|≤8、N_steps≤64、每源一条可复算证明；复杂度纳入审计指标。

## 2. 形式化定义（要点版）

**定义 366（AMF 总览与五不变式）** 见想法区。核心：配比可审计、流可溯源、不确定度三分解、非补偿配比否决、严格退化链。

**定义 367（数据配比测度与有效配比）** μ_w = Σ w_i μ_i；w^eff 由污染 c、去重 d、漂移 δ 校正后重归一化。**审计对象是 w^eff 而非 w**；原始配比好看不代表有效配比没塌向污染源。

**定义 368（配比计量六元组 MIX-METRO）** m_i = (φ_i,m̂_i,u_i,D_i,τ_i,I⊥_i)⊕(N_i^eff,κ_i,c_i,δ_i,w_i^eff)。六元组承 R71 定义 332；I⊥ 是「源不可被代理」的反 Goodhart 指标。**缺项即不得入混合。**

**定义 369（混合流匹配与责任分解 AMF-CFM）** 各源路径共享 p_0，p_t^w=Σ w_i p_t^i，则 v_t^w=Σ r_i u_t^i，r_i=w_i p_t^i/p_t^w，Σr=1。训练目标为责任加权 CFM：L(w)=E_{t,i∼w,x_1∼p_1^i,x_t|x_1}‖v_θ(x_t,t,e_i)−u_t^i‖²。流策略 σ 为显式变量。

**定义 370（配比杠杆、输运误差与流策略审计）** ∂v/∂w_i=(p^i/p^w)(u^i−v^w)；输运误差 ‖x_1^w−x_1^q‖ ≤ ((e^{LT}−1)/L)sup‖v^w−v^q‖；σ 的 transport cost / solver 误差 / guidance distortion / mode coverage 全部进证书。

**定义 371（流策略不确定度三分解 UQ-FLOW）** U_within²=E_w[Var(A|S)]（源内噪声），U_between²=Var_w(E[A|S])（配比诱导的认知不确定），U_solver²=Var(输运离散化)。**U²=三者之和，同权进 λ。**

**定义 372（轨迹级流溯源 FLOW-TRACE）** ρ_i=(1/T)∫r_i(x_t,t)dt，Σρ=1。轨迹证书附 (ρ,i*=argmaxρ,H(ρ),{τ_i})。**ρ_{i*} 指向失效源且 H(ρ) 低 ⇒ 逐轨迹否决。**

**定义 373（混合校准缺口 MCG）** MCG=ECE(p^w)−Σw_i^eff ECE_i。**MCG>0 表示混合本身制造校准误差；MCG 超阈不得用加权平均校准背书。**

**定义 374（风险感知流引导 R-FG）** v_t^λ=v_t^w−λ∇Φ，λ=λ_{E-RISK}(U_ale,U_epi,H_z,u_tac)。**λ 随配比/接触/意图不确定度单调增；λ≥λ_floor 时终端分布 Gibbs 倾斜 p_λ∝p^w exp(−λΦ)。**

**定义 375（配比-风险联合优化 MIX-DRO）** w*=argmin_{w∈Δ,审计可行} max_{q∈𝒬_ε(w)} E_q[Risk(π_{w,σ})]+β·MCG(w)+γ·U_solver(σ)，s.t. 全源审计通过、w_real≥w_anchor、|σ|≤上限。内层训策略，外层审计约束指数梯度。

**定义 376（AMF-IVG 门控）** 新增失效：任一源审计失败 / MCG>τ / w_real<w_anchor；solver 误差 / guidance distortion / mode coverage 超阈；H(ρ)>τ 或 ρ 指向失效源。任一触发 ⇒ 对应模块降级。

**定义 377（AMF 证书 J_AMF）** Valid ⇔ J_EMB 有效 ∧ 全源审计通过 ∧ 流溯源可复算 ∧ UQ 三分解自洽 ∧ MCG≤τ ∧ 引导 λ 记录完整。

**定义 378（威胁模型 AIC-AMF）** ℰ_AMF=ℰ_EMB×ℰ_mix×ℰ_flow。ℰ_mix：配比投毒、去重规避、漂移混入、Goodhart 配比、合成回声室。ℰ_flow：coupling 后门、步数隐写、guidance 反向利用、责任分解规避。

**定义 379（严格退化链）** 配比审计失效⇒w=w_exp+R72；流溯源失效⇒终端动作+R72 事后 λ；引导失效⇒λ 退回事后缩放；全失效⇒R72/R68。**安全侧只增不减。**

**定义 380（配比反作用 L4 与真实源锚定）** w_{t+1}=Mix(w_t,D_robot,D_synth)；c_reflex^w=KL(w_{t+1}‖w_t)+λ_w·𝟙[w_real<w_anchor]；纳入 Σ(c^ψ+c^z+c^c+c^w)≤B_reflex_total。**w_real≥w_anchor 是非补偿硬约束。**

## 3. 关键算法伪代码

```python
# IP-295 MIX-METRO：配比计量审计
class MixtureMetrology:
    def audit(self, sources, w):
        for i, s in sources.items():
            c_i, d_i, delta = s.contamination(), s.dedup_ratio(), s.shift()
            ece, kappa      = s.calibration_ece(), s.coverage_radius()
            if (c_i > TAU_C or ece > TAU_ECE or kappa < TAU_K
                or not s.tchain.valid() or not s.I_perp.valid()):
                s.fail("audit")                      # 非补偿：直接出局
        w_eff = normalize({i: w[i] * (1-s.c_i) * (1-s.d_i) * (1-s.delta)
                           for i, s in sources.items() if s.audited})
        mcg = mixture_calibration_gap(sources, w_eff)     # 定义 373
        return MixtureState(
            w_eff=w_eff, mcg=mcg,
            gate=(mcg <= TAU_MCG and w_eff.real >= W_ANCHOR))

# IP-296 AMF-CFM：责任加权条件流匹配 + 来源嵌入
def amf_train_step(batch, w_eff, model):
    i, x1 = batch.source, batch.x1
    x0    = sample_noise(x1.shape)
    t     = rand_uniform()
    xt    = flow_interp(x0, x1, t)              # OT 或 independent coupling
    ut    = flow_velocity(x0, x1, t)            # 条件速度 u_t^i
    e_i   = source_embedding(i)                 # provenance token
    pred  = model(xt, t, e_i)
    loss  = (w_eff[i] * ((pred - ut) ** 2).mean(1)).sum() / w_eff[i].sum()
    return loss                                 # 反传更新 v_θ

# IP-297 FLOW-TRACE：沿 ODE 积分责任，输出轨迹级来源谱
def flow_trace(model, x0, T=1.0, N=32):
    xt, rho = x0, zeros(model.n_sources)
    for k in range(N):
        t   = k / N * T
        r   = model.responsibilities(xt, t)     # Σ r = 1（路由头）
        rho = rho + r / N
        v   = model.velocity(xt, t)             # = Σ r_i u_i（训练一致时）
        xt  = xt + (T / N) * v                  # Euler / RK4
    return xt, rho, entropy(rho), argmax(rho)

# IP-298 UQ-FLOW：三分解不确定度 -> 进 λ
def uq_flow(model, x0, sources, w_eff, sigma):
    within  = sum(w_eff[i] * var_source(model, i, x0) for i in sources)
    means   = [mean_source(model, i, x0) for i in sources]
    between = weighted_var(means, w_eff)        # 全方差定律的源间项
    solver  = var([integrate(model, x0, steps=s) for s in sigma.step_grid])
    return UQDecomp(within=within, between=between, solver=solver,
                    total=sqrt(within + between + solver))

# IP-299 MIX-DRO：审计约束下的配比鲁棒优化
def mix_dro_update(w, grad_risk, mcg_grad, sources, lr):
    w = w * exp(-lr * (grad_risk + BETA * mcg_grad))
    w = project_simplex(w)
    w = enforce_audit(w, sources)               # 失败源置 0（非补偿）
    w = enforce_anchor(w, W_ANCHOR)             # w_real >= W_ANCHOR（防坍缩）
    return normalize(w)

# IP-300 R-FG：风险感知流引导（λ 来自 E-RISK）
def risk_guided_flow(model, x0, lam, phi, T=1.0, N=32):
    xt = x0
    for k in range(N):
        t  = k / N * T
        v  = model.velocity(xt, t)
        g  = grad_x(phi, xt)                    # 风险势梯度（障碍/速度/力上界）
        xt = xt + (T / N) * (v - lam * g)       # 事中导航，不做事后裁剪
    return xt

# IP-301 MIX-REFLEX：L4 配比反作用 + 真实源锚定
def mix_reflex_step(w, d_robot, d_synth, budget, anchor):
    w2 = mix(w, d_robot, d_synth)
    cost_w = kl_div(w, w2) + LAM_W * (w2.real < anchor)
    if w2.real < anchor or budget.spent + cost_w > budget.B:
        return w, None                           # 拒绝配比更新（锚定/预算）
    return w2, cost_w

# IP-302 AMF 主闭环
def AMF_round(M, obs, w_raw):
    # 1) 配比审计（离线/低频，输出 w_eff 与门控）
    mix = M.mixmetro.audit(M.sources, w_raw)
    if not mix.gate:
        M.mode = "R72_FIXED_MIX"
        return M.r72_round(obs)                  # 退化：固定经验配比
    # 2) 流策略生成（流匹配 ODE，感知/计量域异步）
    x0  = M.encoder(obs, M.intent_ctx)           # 条件含 R72 意图/接触上下文
    uq  = M.uqflow.decompose(x0, M.sources, mix.w_eff, M.sigma)
    lam = M.e_risk.scale(uq.total, M.u_ale, M.u_epi, M.H_z, M.u_tac)
    a1  = M.rfg.generate(x0, lam, M.risk_potential)
    rho = M.trace.attribute(x0)                  # 轨迹来源谱
    # 3) 溯源门控 + 异步证书
    if rho.entropy > TAU_HRHO and not rho.argmax_is_trusted(M.sources):
        M.mode = "TERMINAL_ONLY"
        a1 = M.e_risk.post_scale(a1, lam)        # 退化：终端动作 + 事后 λ
    return a1, J_AMF(M, mix, uq, rho, lam)       # 证书异步组装
```

## 4. 推导

**引理 33（混合速度场的责任分解精确性）** 各源路径 p_t^i 满足连续性方程且共享 p_0 ⇒ 混合路径 p_t^w=Σ w_i p_t^i 满足 ∂_t p_t^w+∇·(p_t^w v_t^w)=0，v_t^w=Σ r_i u_t^i，r_i=w_i p_t^i/p_t^w。
证明：∂_t p^w=Σw_i∂_t p^i=−Σw_i∇·(p^i u^i)=−∇·(Σw_i p^i u^i)=−∇·(p^w Σ(w_i p^i/p^w)u^i)。∎
系：**配比精确改写速度场的责任路由；流溯源因此有严格概率解释。**

**引理 34（配比杠杆与输运稳定性）** (i) ∂v_t^w/∂w_i=(p_t^i/p_t^w)(u_t^i−v_t^w)；(ii) 同一初始噪声下
‖x_1^w−x_1^{w'}‖ ≤ ((e^{LT}−1)/L)·sup_t‖v_t^w−v_t^{w'}‖ ≤ ((e^{LT}−1)/L)·Σ_i|w_i−w'_i|·sup_t‖u^i−v^w‖。
证明：(i) 直接求偏导；(ii) 对 δ_t 用 Grönwall：d‖δ_t‖/dt ≤ L‖δ_t‖+‖Δv_t‖。∎
系：**配比扰动被 e^{LT} 放大——步数越多/场越陡，配比误差越危险；高杠杆源必须单独审计。**

**引理 35（不确定度三分解的完备性）** Var(A)=E_w[Var(A|S)]+Var_w(E[A|S])=U_within²+U_between²；叠加独立输运误差 U_solver² 得总方差（源相关时补协方差项）。证明：全方差定律。∎
系：**R72 的 U_epi 被拆成「源内噪声」与「源间配比差异」；后者可被 w 控制，前者不能。**

**引理 36（轨迹溯源的一致性、不可伪装性与忠实性条件）** (i) Σr=1 ⇒ Σρ=1；(ii) 若 v_θ 严格等于混合速度场，则 ρ 是轨迹的源占用测度，源支撑可分离时 x_1∈supp p_1^i ⇒ ρ_i→1；(iii) **忠实性条件**：v_θ 必须可写成共享基 + 来源条件残差的路由结构，否则特征叠加使 ρ 仅名义归因。
证明：(i)(ii) 直接；(iii) 反例：两层 MLP 在输出不变下重参数化源嵌入，使 r 任意。∎
系：**证书必须区分 nominal/faithful 归因；只有强制路由架构才可升级为忠实归因。**

**引理 37（配比的非补偿性审计与安全单调）** 源 i 失败且 R_i^bad>0，其余源风险非负 ⇒ R(w)≥w_i^eff·R_i^bad；令 w_i^eff=0 得 R(w')≤R(w)，且提高干净源权重无法抵消该项。∎
系：**「加干净数据稀释脏数据」在安全上不成立——R71 非补偿否决在配比层的再现。**

**引理 38（风险引导的终端风险下降）** Φ 光滑，沿 v^λ=v^w−λ∇Φ 有 dΦ/dt=⟨∇Φ,v^w⟩−λ‖∇Φ‖²。若 ⟨∇Φ,v^w⟩≤B，则 Φ(x_T)≤Φ(x_0)+BT−λ∫‖∇Φ‖²dt；λ>B/‖∇Φ‖² 时终端风险严格下降。证明：链式法则+积分。∎
系：**λ_floor 从「事后缩放」升级为「事中导航」；不确定度越大，ODE 越被拽向安全区。**

**定理 27（AMF 严格包含与风险单调）** 在 A111–A116 下，AMF 退化时逐指令等于 R72/R71/R68；有效执行的风险界 ≤ R72 风险界。**安全单调不减，生成质量收益仅在配比可信、流可溯源、引导有效时兑现。**

**定理 28（AMF 证书 ⇒ 配比/输运/校准安全）** 通过 J_AMF ⇒ (i) 无已知污染源入混合；(ii) w_eff 与 ρ 可复算、不可静默篡改；(iii) UQ 三分解自洽且进 λ；(iv) MCG≤τ 表示混合未制造超阈校准误差；(v) J_EMB 有效 ⇒ 具身层安全。综上配比—输运—执行三层风险 ≤ ε_amf。**证明重量落在「审计能识别所有污染/漂移源」与「速度场来源分解忠实」上。**

**定理 29（MIX-DRO 的可行性保持与收敛）** 凸风险与凸审计约束下，指数梯度 + 单纯形投影 + 失败源置零 + 锚定投影保持可行域；固定内层策略时外部权重以 O(1/√T) 收敛到约束 minimax 点。**非补偿审计只收缩可行域，不破坏收敛。**

## 7. 本轮最大风险

**一句话**：AMF 把安全从「相信推理时的计量证书」进一步转移到「相信 **配比审计能识别所有污染/漂移源**、相信 **神经速度场的来源分解是忠实的而非名义的**、相信 **混合校准缺口 MCG 能捕获配比自身制造的偏差**」——**如果污染源通过特征叠加把自身伪装进干净源的速度场（责任分解只给出好看的 nominal ρ，反事实归因完全错误），或者 MIX-DRO 在验证集上刷低 MCG 却把最差来源的校准推到分布外，或者 L4 配比反作用在长时程把 w_real 压到锚定边界以下、模型缓慢坍缩成自说自话的不动点——系统会拿着一份「配比已审计、流已溯源、证书已盖章」的生成策略，在真机上生成一条来源谱看起来 99% 干净、实际上 99% 来自被污染源的动作，事后审计发现「每条轨迹的 ρ 都合法、每个源的 ECE 都在阈值内、每轮 MCG 都通过」，这就是**生成式层面的「自信地错自己的来源与输运」**。** 它比 R72 更隐蔽：R72 至少错在「测量」，AMF 可能错在「对测量的来源撒了谎」。

次级风险与缓解：
1. **责任分解不忠实** → 强制可分解架构（共享基 + 加性来源头 / MoE + 路由稀疏约束）；证书区分 nominal/faithful；用**反事实源替换测试**验证 ρ 与输出同步变。
2. **配比审计漏源/漂移** → 在线漂移探测（MMD/能量分数）+ 密封污染金标集；c_i 取区间上界进 w_eff。
3. **MCG 被 Goodhart** → MCG 与最差源 ECE 联合门控；按源分层报告最差值，禁止加权平均背书。
4. **L4 模型坍缩** → w_real≥w_anchor 非补偿硬约束；合成数据可追溯配额 + 新颖性/一致性双门；监控 w 熵与真实源占比。
5. **引导把分布推离数据支撑** → 引导只在可信域 D 内生效，越界退回事后 λ 缩放；监控 guidance distortion 与 mode coverage。
6. **证书开销/实时性** → 配比审计离线、溯源与 UQ 感知域异步、控制域只读快照（继承 R72 三域分离），证书异步组装。
7. **复杂度爆炸** → 模块上限 |I|≤32、trace 源 ≤8、N_steps≤64；每源一条可复算证明；复杂度纳入审计指标。
