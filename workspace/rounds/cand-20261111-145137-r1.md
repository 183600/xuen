# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「SLAM」×「碰撞避免」）

> 第 54 轮把技能组合提升为“动作-鲁棒性双证书”，但所有证书都默认地图与位姿近似真值。本轮把 **SLAM 漂移、退化、地图陈旧与动态障碍** 显式引入碰撞避免证书。核心矛盾：**H22**：碰撞避免的几何前提（地图 + 位姿）本身是 SLAM 的估计量且有误差，用点估计做安全边距会在漂移处系统性越界；**H23**：为避障而执行的动作（贴墙、急转、倒退、进入未知区）恰恰可能破坏可定位性，形成“越躲越漂、越漂越躲”的感知-安全耦合回路。

## 0. 直觉与动机

**灵感 1（SLAM 不是地图供应商，而是带漂移的证书签发者）**
直觉：传统流水线是 `SLAM → 地图 → 规划 → 避障`，碰撞检查用点估计间隙 `d̂(x,O)`。但真实间隙 `d*` 与估计之间存在误差：`d* = d̂ − ε`，`ε` 随位姿协方差、地图稀疏度、动态遮挡而变。安全边距不应手调，而应是 **校准后的下界**：只有 `d̂ − ε(δ) ≥ r + b_safe` 才签发碰撞证书。`ε(δ)` 由 conformal 校准从非一致性分数分布中取分位数，给出有限样本覆盖保证。这样，“安全”从几何事实变成一条 **可审计的统计契约**。

**灵感 2（可定位性是有方向的动作属性）**
直觉：走廊里沿墙方向漂移不一定危险，朝墙方向漂移致命；旋转扫描时角向可观测、平移可能退化。因此不应要求“全程非退化”，而应要求 **安全关键方向可观测**：令 `H(x)=JᵀΩJ` 为 SLAM 法方程 Hessian，`λ_u(x)=uᵀH(x)u / uᵀu`，只对改变间隙的方向 `u∈U_safe(x)` 要求 `λ_u ≥ λ_min`。把 `λ_S(a)` 作为第二动作剖面，与第 54 轮 `α_S(a)` 并列。这样，避障动作第一次被要求“不许把自己变瞎”。

**灵感 3（云边地图契约：全局地图是承诺，不是真值）**
直觉：云端全局地图 `M_c` 一致但可能陈旧；边端局部地图 `M_e` 新鲜但局部。若直接把 `M_c` 下发给边端做避障，动态障碍已被烘进地图或位置已漂移，云端的安全证书在边端失效。需要 **地图交接契约** `C_map=(M_c,t_c,T_ec,δ_m,λ_overlap,Δ_stale)`：只有在重叠区漂移 `δ_m ≤ δ_m^max`、方向可定位性足够、陈旧度 `Δ_stale ≤ τ_map` 且动态掩膜已扣除时才接受；否则边端触发重定位，而不是“带病使用”。这是第 54 轮 `γ_ce` 在 **地图通道** 上的对偶。

**灵感 4（动态障碍不是地图噪声，而是带预测不确定性的风险场）**
直觉：行人、叉车、其他机器人不能当静态占据写进 SLAM 地图，否则地图被污染、避障过度保守甚至死锁。应将静态占据 `O_static` 与动态轨迹 `O_dyn(t)` 分离，对动态体用预测分布给出碰撞概率 `R_dyn(π)=P(∃t≤H: collision)`，并以机会约束 `R_dyn(π) ≤ δ_d` 签发证书。安全不再是“距离 > r”，而是“碰撞概率 < δ”。

**灵感 5（证书修复：主动 SLAM 是安全动作，不是额外开销）**
直觉：当联合证书因可定位性不足或动态风险过高而失败时，不应直接拒停或硬闯；可插入信息增益动作（减速、环视、回环、请求云端子图、等待人群通过）。把它建模为 **证书修复算子** `Rep`：在风险预算内最大化单位时间期望信息增益，使 `ε` 收缩到可签发。这把安全从静态边距变为可调度的预算，代价是时间与任务延迟。

**灵感 6（感知-安全耦合回路与金字塔扩展）**
直觉：膨胀 `ε↑ → 速度↓ → 单位距离信息↑ → ε↓` 是负反馈；但也可能 `ε↑ → 更激进绕行 → 进入更差特征区 → ε↑` 是正反馈。需要显式监测耦合增益并加阻尼。在第 54 轮动作协同层 `𝔸` 之上叠加 **感知安全层 `𝕊`**：`𝕊0` 动力学安全（CBF），`𝕊1` 位姿-地图不确定性，`𝕊2` 方向可定位性，`𝕊3` 动态风险，`𝕊4` 云边地图契约。跨层证书必须 **单调包含**：外层声明的安全集不得大于内层能保证的安全集。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（SLAM 信念）**
SLAM 信念 `b_t = (μ_t, Σ_t, M_t, H_t)`：`μ_t ∈ SE(3)` 为位姿均值，`Σ_t` 为位姿协方差，`M_t` 为带占据概率与观测计数的地图（栅格/子图），`H_t` 为最近窗口内的法方程信息矩阵。真值位姿与地图记为 `(x_t*, M*)`。

**定义 122（校准间隙下界）**
由 `b` 计算间隙估计 `d̂(x,O)`。在校准集 `{(d̂_i,d*_i)}` 上定义非一致性分数 `s_i = d̂_i − d*_i`（正值表示估计偏乐观）。取
```
ε_δ = s_(⌈(n+1)(1−δ)⌉)        （若索引 > n，则 ε_δ = +∞，拒绝签发）
```
则在可交换性假设下，对新样本有 `P(d* ≥ d̂ − ε_δ) ≥ 1 − δ`。在线分布漂移下改用 ACI：
```
α_{t+1} = α_t + γ(δ − err_t),   ε_t = Quantile_{1−α_t}(scores)
```
长期平均误覆盖收敛到 `δ`。

**定义 123（地图条件碰撞证书）**
轨迹 `π` 的膨胀最小间隙 `m_ε(π) = min_t [ d̂(μ_t,M_t) − ε_δ(t) ]`。
```
C_col(π,b) = 1  ⇔  m_ε(π) ≥ r + b_safe
```
其中 `r` 为机器人外接半径，`b_safe` 为不可动安全缓冲。该证书 **只对静态占据** 负责。

**定义 124（方向可定位性证书）**
给定 `H(x)=JᵀΩJ`，安全关键方向集
```
U_safe(x) = { u ∈ T_xSE(3) : |⟨u, ∇_x d̂(x)⟩| ≥ c_safe }
```
窗口累计方向裕度 `λ_u^W(x) = uᵀH_W u / (uᵀD u)`，`D` 为量纲归一化矩阵，`H_W = Σ_{t∈W} H_t`。
```
C_loc(π) = 1  ⇔  ∀t, ∀u∈U_safe(x_t):  λ_u^W(x_t) ≥ λ_min
```
这是 **方向性** 条件：允许沿等距方向退化，但禁止朝向/远离障碍方向的退化。

**定义 125（动态碰撞风险）**
对动态体 `j` 的轨迹预测 `p(x_j^{t+1} | history)`，联合风险
```
R_dyn(π) = 1 − E[ Π_{t≤H} 1( robot_t ∩ ⋃_j O_j(t) = ∅ ) ]
C_dyn(π) = 1  ⇔  R_dyn(π) ≤ δ_d
```

**定义 126（云边地图契约）**
```
C_map = (M_c, t_c, T_ec, δ_m, λ_overlap, Δ_stale)
```
其中 `T_ec` 为云-边相对变换，`δ_m` 为重叠区（扣除动态掩膜后）的占据/几何不一致度（如 95 分位），`λ_overlap` 为重叠区的方向可定位裕度，`Δ_stale = now − t_c`。契约有效当且仅当
```
δ_m ≤ δ_m^max  ∧  λ_overlap ≥ λ_min  ∧  Δ_stale ≤ τ_map  ∧  动态掩膜已扣除
```
否则触发 `Reloc`（重定位）或 `request_submap`，不得直接用 `M_c` 签发碰撞证书。

**定义 127（SLAM-碰撞联合证书）**
```
J_sc = (ρ, A_cert, b, λ_min(π), R_dyn(π), δ_m, evidence)
```
其中 `ρ, A_cert` 承接第 54 轮。可部署条件：
```
dom_J = in  ∧  C_col(π,b)  ∧  C_loc(π)  ∧  C_dyn(π)  ∧  C_map valid
```
`evidence` 至少包含：校准集规模与分位数、退化方向特征谱、动态预测轨迹集合、地图交接残差与时间戳。

**定义 128（证书修复算子）**
给定修复动作库 `𝒜_rep = {slow, rotate, loop_closure, request_submap, wait}`，
```
Rep(C, budget) = a* = argmax_{a∈𝒜_rep} EI(a)/T(a)
                 s.t. Risk(a) ≤ δ_rep  ∧  Cost(a) ≤ budget
```
其中 `EI(a)` 为期望信息增益（位姿/地图熵下降或 `ε` 的期望收缩）。修复成功当 `ε_{t+1} ≤ (1−η)ε_t + w_t`（`η>0`）；否则 `fail-safe` 停车并请求人工接管。

## 2. 关键算法伪代码

### IP-121 MCF（Map-Conditioned Field）

```python
def lower_bound_clearance(traj, b, calib, delta):
    m = +inf
    for t, x in enumerate(traj.poses):
        d_hat = distance_to_occupied(x, b.M)
        eps = calib.quantile(delta)          # 或 ACI 在线分位数
        m = min(m, d_hat - eps)
    return m

def collide_cert(traj, b, calib, r, b_safe, delta):
    return lower_bound_clearance(traj, b, calib, delta) >= r + b_safe
```

### IP-122 LOC（Directional Localizability Certificate）

```python
def safety_directions(x, grad_d, c_safe):
    U = []
    for u in tangent_basis(x):
        if abs(dot(u, grad_d(x))) >= c_safe:
            U.append(u)
    return U

def localizability_cert(traj, b, lam_min, c_safe):
    for t, x in enumerate(traj.poses):
        H = accumulated_info(b.H, window=W)   # H_W
        for u in safety_directions(x, grad_clearance, c_safe):
            lam = quad(u, H) / quad(u, b.D)
            if lam < lam_min:
                return False, (t, x, u, lam)  # 见证退化方向
    return True, None
```

### IP-123 MCH（Map Consistency Handoff）

```python
def map_handoff(M_c, t_c, M_e, T_ec, delta_m_max, lam_min, tau_map):
    if now() - t_c > tau_map:
        return ('relocalize', 'stale', now() - t_c)
    O = overlap(M_c, T_ec, M_e) - dynamic_mask(M_e)
    delta_m = discrepancy_quantile(M_c, M_e, O, T_ec, q=0.95)
    lam_ov = min_directional_localizability(M_e, O)
    if delta_m <= delta_m_max and lam_ov >= lam_min:
        return ('accept', fuse(M_c, M_e, O, T_ec), delta_m, lam_ov)
    return ('relocalize', delta_m, lam_ov)
```

### IP-124 DCC（Dynamic Collision Certificate）

```python
def dynamic_risk(traj, tracks, H, N=512):
    hits = 0
    for _ in range(N):
        scene = sample_futures(tracks, H)
        if any(collide(traj[t], scene[t]) for t in range(H)):
            hits += 1
    return hits / N

def dynamic_cert(traj, tracks, H, delta_d, N=512):
    return dynamic_risk(traj, tracks, H, N) <= delta_d
```

### IP-125 JSC（Joint SLAM-Collision Certificate）

```python
def joint_slam_cert(skill_seq, b, calib, tracks, contract, cfg):
    J = joint_certificate(skill_seq, cfg.gamma_ce, cfg.delta_a_budget, cfg.rho_min)  # 第54轮
    if J.status != 'ok':
        return J
    plan = J.plan
    if not collide_cert(plan, b, calib, cfg.r, cfg.b_safe, cfg.delta):
        return ('reject', 'clearance', lower_bound_clearance(plan, b, calib, cfg.delta))
    ok, deg = localizability_cert(plan, b, cfg.lam_min, cfg.c_safe)
    if not ok:
        return ('reject', 'degenerate', deg)
    r_dyn = dynamic_risk(plan, tracks, cfg.H)
    if r_dyn > cfg.delta_d:
        return ('reject', 'dynamic', r_dyn)
    if contract.status != 'accept':
        return ('reject', 'map_contract', contract)
    return ('ok', JointSlamCert(J, b, deg, r_dyn, contract))
```

### IP-126 APR（Active Perception Repair）

```python
def repair(C_fail, budget, risk_budget):
    scored = sorted(ACTION_LIB, key=lambda a: EI(a) / T(a), reverse=True)
    for a in scored:
        if Risk(a, C_fail.b) <= risk_budget and Cost(a) <= budget:
            return ('repair', a)
    return ('fail_safe', 'stop_and_handoff')
```

def coupling_monitor(eps_hist, speed_hist, lam_hist):

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| MCF | O(|π|·|M|)（有 ESDF 时 O(|π|)） | O(|π|+|M|) | 校准覆盖、分数可交换 |
| LOC | O(|π|·(|U|·dim + dim³/窗口)) | O(dim²) | H 与 SLAM 后端一致、方向集完备 |
| MCH | O(|O| + |M_c| + |M_e|) | O(|O|) | 动态掩膜正确、漂移度量 conservative |
| DCC | O(N·H·J) | O(H·J) | 预测集合覆盖真值（或误差有界） |
| JSC | O(各组件之和 + 第54轮 J) | O(|A|+|M|) | 五条件合取、证书不可拆分 |
| APR | O(|𝒜_rep|) | O(|𝒜_rep|) | EI 估计单调、风险上界 sound |
| PSM | O(window) | O(window) | 增益估计不滞后于控制周期 |

**正确性定理（Perception-Conditioned Collision Safety）**
假设第 54 轮 (A22)–(A28) 成立，并新增：
**(A29)** 校准样本可交换或 ACI 平均覆盖成立；
**(A30)** 地图/位姿误差被 `ε_δ` 下界支配，`d̂` 对位姿 1-Lipschitz；
**(A31)** 方向可定位门保证安全关键方向信息累计 `λ_u^W ≥ λ_min`，从而窗口内位姿误差增长有界；
**(A32)** 动态预测的碰撞集合以概率 `1−δ_pred` 覆盖真实未来；
**(A33)** 地图契约满足 `δ_m ≤ δ_m^max` 且 `Δ_stale ≤ τ_map`；
**(A34)** 修复算子在预算内满足收缩 `ε_{t+1} ≤ (1−η)ε_t + w_t`，否则 fail-safe。

则对任一经 `J_sc` 认证的轨迹，
```
P( ∃t 发生碰撞 ∧ J_sc 有效 )
  ≤ δ_p + δ_m + δ_pred + β_E + P(repair timeout)
```
其中 `δ_p` 为 conformal/ACI 误覆盖，`β_E` 为执行误差。证明用并集界：碰撞发生当且仅当至少一条不确定性下界被突破；`C_col` 保证静态间隙下界，`C_loc` 保证位姿误差不沿安全关键方向失控增长，`C_dyn` 保证动态风险，`C_map` 保证地图前提未陈旧。注意该定理是 **no-false-safety** 型，不保证 liveness；保守可能导致停车，需由修复算子与任务层处理。

## 6. 本轮最大风险

**一句话**：SLAM 条件的碰撞证书把“安全”从几何距离升级为“校准后的统计下界 + 方向可定位 + 地图契约 + 动态风险”的四重合取，但其 soundness **全部押在校准分布可交换、地图交接真实、动态预测覆盖真值这三件事上**；一旦环境漂移使 conformal 覆盖失效、或边端接受了陈旧/投毒的云端地图，证书会变成比“没有证书”更危险的 **false safety**——它会主动关闭保守兜底。故必须把 **OOD 检测 + 地图契约否决 + fail-safe 停车** 作为不可绕过的元护栏，宁可频繁不签发，也绝不签发一个无法被在线覆盖检验的证书。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（MCF×LOC×MCH×DCC×JSC×APR×PSM）· SLAM-Safe

> 承接第 54 轮产物 v31。本轮在“动作-鲁棒性双证书”之上，增加 **SLAM 条件化** 的碰撞安全体系：
> - **MCF（Map-Conditioned Field）**：用 conformal/ACI 校准把位姿-地图误差膨胀成间隙下界；
> - **LOC（Directional Localizability Certificate）**：只对“改变间隙的安全关键方向”要求可观测；
> - **MCH（Map Consistency Handoff）**：云端地图交接契约，拒绝陈旧/漂移/未去动态的全局图；
> - **DCC（Dynamic Collision Certificate）**：静态占据与动态轨迹分离，机会约束碰撞风险；
> - **JSC（Joint SLAM-Collision Certificate）**：五条件合取的联合证书；
> - **APR（Active Perception Repair）**：把主动 SLAM 作为证书修复动作；
> - **PSM（Perception-Safety Monitor）**：监测“越躲越漂”的耦合正反馈并阻尼。
>
> IP 编号：IP-121~IP-127（共 7 个新增），并升级 IP-116/117/118/119/120 以携带 SLAM 信念与感知安全证据。状态：设计稿 + 可运行伪代码 + 解析推演 + 预注册实验门槛；**未做真实机器人实测**，故不报伪造数字。

## 0. 版本关系与本轮增量

v31 的资产全部保留：`TRO/RXC/RCO/REX/RTA/TRC/RUR` 鲁棒性谱与 `Explain`，`ACS/SCOM/CEC/AEC/AAL/JTC` 动作-协同层。本轮只增加“感知前提”这一层，并把第 54 轮的证书全部 **降级为条件证书**：它们不再对“地图真值”负责，而只对“给定 SLAM 信念 `b` 下的条件安全”负责。

本轮七项增量：

1. **MCF**：把 `d̂ ≥ r+b_safe` 改成 `d̂ − ε_δ ≥ r+b_safe`；`ε_δ` 由 split conformal 或 ACI 给出，而不是手调固定膨胀。
2. **LOC**：把可定位性从“全局最小特征值”改为“安全关键方向上的累计信息下界”，允许沿等距方向退化。
3. **MCH**：给云端地图加时间戳、漂移、动态掩膜与可定位性四道闸门；不满足则重定位或请求新子图。
4. **DCC**：动态障碍不写入静态地图；用预测分布 + 机会约束替代固定距离膨胀。
5. **JSC**：`J_sc = (ρ, A_cert, b, λ_min, R_dyn, δ_m, evidence)`；五条件合取，任一失败即拒签。
6. **APR**：拒签不等于停死；在风险预算内选择信息增益动作修复证书，修复失败才 fail-safe。
7. **PSM**：显式估计 `∂ε/∂λ` 的符号与增益，检测“避障导致退化、退化导致更激进避障”的正反馈。

退化关系：

```text
ε_δ → 0, λ_min → 0, δ_m → 0, 忽略动态        → 逐字回到 v31（动作-鲁棒性双证书）
只保留 MCF                                    → conformal 安全滤波器
只保留 LOC                                    → 可定位性感知的 SLAM 导航
只保留 MCH                                    → 云边地图一致性交接
只保留 DCC                                    → 动态机会约束避障
MCF+LOC+MCH+DCC 但无 APR/PSM                  → 保守但可能死锁的“纯证书”版本
```

### IP-121 MCF

```python
def conformal_quantile(scores, delta):
    n = len(scores)
    k = ceil((n + 1) * (1 - delta))
    if k > n:
        return float('inf')          # 样本不足，拒签
    return sorted(scores)[k - 1]

def lower_bound_clearance(traj, b, calib, delta):
    eps = conformal_quantile(calib.scores, delta)   # 或 ACI 在线值
    return min(distance_to_occupied(x, b.M) - eps for x in traj.poses)

def collide_cert(traj, b, calib, r, b_safe, delta):
    return lower_bound_clearance(traj, b, calib, delta) >= r + b_safe
```

```python
def aci_update(alpha, delta, err_t, gamma):
    alpha = alpha + gamma * (delta - err_t)
    return min(max(alpha, 1e-6), 1 - 1e-6)
```

### IP-122 LOC

```python
def safety_directions(x, grad_d, c_safe):
    return [u for u in tangent_basis(x) if abs(dot(u, grad_d(x))) >= c_safe]

def localizability_cert(traj, b, lam_min, c_safe, W):
    for t, x in enumerate(traj.poses):
        H = sum(b.H[s] for s in window(t, W))
        for u in safety_directions(x, b.grad_clearance, c_safe):
            lam = quad(u, H) / quad(u, b.D)
            if lam < lam_min:
                return False, (t, x, u, lam)
    return True, None
```

def map_handoff(M_c, t_c, M_e, T_ec, cfg):
    if now() - t_c > cfg.tau_map:
        return ('relocalize', 'stale')
    O = overlap(M_c, T_ec, M_e) - dynamic_mask(M_e)

### IP-124 DCC

```python
def dynamic_risk(traj, tracks, H, N=512):
    hits = 0
    for _ in range(N):
        scene = sample_futures(tracks, H)
        if any(collide(traj[t], scene[t]) for t in range(H)):
            hits += 1
    return hits / N

def dynamic_cert(traj, tracks, H, delta_d, N=512):
    return dynamic_risk(traj, tracks, H, N) <= delta_d
```

### IP-125 JSC

```python
def joint_slam_cert(skill_seq, b, calib, tracks, contract, cfg):
    J = joint_certificate(skill_seq, cfg.gamma_ce, cfg.delta_a_budget, cfg.rho_min)
    if J.status != 'ok':
        return J
    plan = J.plan
    if not collide_cert(plan, b, calib, cfg.r, cfg.b_safe, cfg.delta):
        return ('reject', 'clearance', lower_bound_clearance(plan, b, calib, cfg.delta))
    ok, deg = localizability_cert(plan, b, cfg.lam_min, cfg.c_safe, cfg.W)
    if not ok:
        return ('reject', 'degenerate', deg)
    r_dyn = dynamic_risk(plan, tracks, cfg.H, cfg.N)
    if r_dyn > cfg.delta_d:
        return ('reject', 'dynamic', r_dyn)
    if contract.status != 'accept':
        return ('reject', 'map_contract', contract)
    return ('ok', JointSlamCert(J, b, deg, r_dyn, contract, evidence=collect()))
```

## 5. 解析推演：安全预算账本与一个算例

### 5.1 间隙账本

把安全条件展开成一张可审计的账本：

```
d̂  =  r  +  b_safe  +  ε_δ  +  slack
     (机器人半径) (不可动缓冲) (校准膨胀) (剩余裕度)
```

`slack < 0` 即拒签；`slack` 就是“这条轨迹有多接近证书边界”。这比单一“安全/不安全”标签更有用：它直接告诉修复算子该缩小 `ε`（多感知）还是增大 `d̂`（绕远/减速）。

### 5.2 finite-sample 覆盖

对 `n` 个可交换校准分数 `s_i=d̂_i−d*_i`，取 `k=⌈(n+1)(1−δ)⌉`。若 `k≤n`，则
```
P( s_{n+1} ≤ s_(k) ) ≥ k/(n+1) ≥ 1−δ
⇒ P( d*_{n+1} ≥ d̂_{n+1} − s_(k) ) ≥ 1−δ
```
若 `k>n`，样本不足以支撑 `1−δ`，直接返回 `+∞` 并拒签。这一条把“校准集太小却仍敢签发”这种常见工程隐患显式堵死。

### 5.3 算例（纯算术，非实测）

设 `r=0.30 m`，`b_safe=0.05 m`，故要求 `d̂−ε_δ ≥ 0.35 m`。

| 场景 | `d̂` | `ε_δ` | 下界 | `slack` | 结论 |
|---|---:|---:|---:|---:|---|
| 开阔大厅 | 1.20 | 0.04 | 1.16 | +0.81 | 签发，且可加速 |
| 标准走廊 | 0.42 | 0.06 | 0.36 | +0.01 | 签发但贴边，禁止加速 |
| 走廊 + 漂移 | 0.42 | 0.09 | 0.33 | −0.02 | 拒签；需 `ε≤0.07` 或 `d̂≥0.44` |
| 人群前方 | 0.80 | 0.05 | 0.75 | +0.40 | 静态通过，但 `R_dyn=0.08>δ_d` → 拒签，等待/绕行 |

该表说明：**MCF 不是“更保守”，而是把保守量放在可解释的位置**；拒签时能明确指出是感知预算不足还是动态风险超限。

### 5.4 方向 LOC 的反例与正例

- 反例（应拒签）：走廊宽 0.9 m，机器人朝墙横移，横向 Hessian 特征值 0.02 < λ_min=0.1，`∇d̂` 与横向对齐 → `u∈U_safe` 且 `λ_u` 低 → 拒签。
- 正例（不应误拒）：同一走廊沿墙前进，沿墙方向特征值 0.02 但 `∇d̂` 与沿墙方向近似正交 → 该方向不在 `U_safe` → 不因它拒签。

这正是“方向性”相对“全局最小特征值”的收益：避免把无害退化当成危险退化。

### 5.5 云边地图陈旧性的量级

若云端地图 `Δ_stale=10 s`，行人在边端以 1.2 m/s 移动，则位置漂移约 12 m；若该行人被烘进 `M_c` 的静态占据，边端会得到完全错误的安全边界。故 `τ_map` 必须与最快动态体的速度、地图更新频率联合设定，而不是拍一个常数；动态掩膜是硬前提。

## 6. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MCF | O(|π|·|M|)（ESDF 下 O(|π|)） | O(|π|+|M|) | 覆盖 ≥1−δ；样本不足即拒签 |
| LOC | O(|π|·(|U|·dim+dim³/W)) | O(dim²) | H 与后端一致；安全方向集完备 |
| MCH | O(|O|+|M_c|+|M_e|) | O(|O|) | 漂移度量 conservative；动态掩膜正确 |
| DCC | O(N·H·J) | O(H·J) | 可达集包络 sound；采样仅作估计 |
| JSC | O(MCF+LOC+MCH+DCC+J) | O(|A|+|M|) | 五条件合取，不可拆分 |
| APR | O(|𝒜_rep|) | O(|𝒜_rep|) | 风险上界 sound；EI 单调 |
| PSM | O(window) | O(window) | 增益估计周期 ≤ 控制周期 |

**定理（Perception-Conditioned Collision Safety）**
在 (A22)–(A28) 之上增加 (A29)–(A34)（见想法区）。对任一经 `J_sc` 认证的轨迹：
```
P(∃t 碰撞 ∧ J_sc 有效)
  ≤ δ_p + δ_m + δ_pred + β_E + P(repair timeout)
```
证明骨架：碰撞意味着至少一个下界被突破。若静态真值间隙 `<r`，则由 `C_col` 与 conformal 覆盖，该事件概率 `≤δ_p+δ_m`；若因位姿沿安全方向漂移导致突破，则由 `C_loc` 的 `λ_u^W≥λ_min` 给出窗口内误差增长上界，超出即不在认证域；若因动态体，则 `C_dyn` 限制其概率 `≤δ_pred`；若因地图前提失效，则 `C_map` 应已拒绝，漏检概率计入 `δ_m`；执行误差计入 `β_E`；修复超时计入最后一项。并集界给出结论。

**边界声明**：该定理不保证 liveness，也不覆盖“校准集与部署分布完全无重叠”的情形；后者由 OOD 检测与 ACI 作为元护栏处理，超出则停止而非降级签发。

## 7. 实验设计 E162–E168（预注册门槛）

**基线**：B1 点估计 ESDF + 固定膨胀；B2 协方差膨胀（用 `Σ` 但不校准）；B3 v31 双证书 + 固定安全边距；Ours 完整 MCF+LOC+MCH+DCC+JSC+APR+PSM。
**平台**：仿真（Habitat/Gazebo + 动态行人 + 可控退化纹理）先做，再上真机小规模；每场景 ≥ 200 episodes，报告均值与 95% CI。

| 实验 | 对照 | 指标 | 预注册目标 |
|---|---|---|---|
| E162 校准覆盖 | B1/B2 | 覆盖率误差、ECE、可靠性图 | 覆盖率 ∈ [1−δ−0.02, 1−δ+0.01]，ECE ≤ 0.03 |
| E163 认证碰撞 | B1/B3 | 每 km 碰撞、近失、假安全率 | 碰撞 ≤ 1e−3/km，近失 −50%，假安全 ≤ 1e−3 |
| E164 退化走廊 | Ours−LOC | 碰撞率、误拒率 | 碰撞 −80%，误拒 ≤ 10% |
| E165 地图交接 | 直接下发 `M_c` | 陈旧图假接受、重定位成功率/延迟 | 假接受 ≤ 1%，成功 ≥ 95%，P95 ≤ 2 s |
| E166 动态人群 | B1+恒速预测 | 风险违约、死锁、完成时间 | 违约 ≤ δ_d+0.01，死锁 ≤ 5%，时间 +≤ 15% |
| E167 主动修复 | 无修复直接停 | 修复成功率、时间开销、失败安全性 | 成功 ≥ 85%，开销 ≤ 20%，失败 100% fail-safe |
| E168 红队 | — | 镜子/玻璃、绑架、投毒、遮挡 | 300 ms 内证书失效，认证碰撞 = 0 |

**消融与曲线**：分别关闭 MCF/LOC/MCH/DCC/APR/PSM；主报告不是单一成功率，而是“**证书签发率 vs 假安全率**”的 Pareto 前沿——因为任何安全机制都能靠“永不签发”获得 0 碰撞，必须同时约束可用性。

**可复现性**：固定随机种子集；校准/测试按环境与动态密度分组；所有拒签必须记录见证（`ε`, `λ_u`, `R_dyn`, `δ_m`），便于审计与 `Explain` 回放。

## 9. 对 UniBot 的落地含义

- **安全证书可解释**：机器人不是“莫名停下”，而是给出 `ε_δ/λ_u/R_dyn/δ_m` 中哪一项超预算；
- **云边协同有契约**：云端地图只在时间戳、漂移、可定位性三关通过后才被边端接受，避免“云图过期害死边端”；
- **人群场景可生存**：动态风险用机会约束而非硬距离，减少 freezing robot 问题；修复动作库提供“先环视再通过”的可用策略；
- **可证伪**：所有目标都是可测的（覆盖率、假安全率、死锁率、重定位延迟），红队场景可复现。

## 10. 本轮最大风险

**一句话**：SLAM 条件的碰撞证书把“安全”升级为“校准统计下界 + 方向可定位 + 地图契约 + 动态风险”的四重合取，但其 soundness **全部押在校准分布可交换、地图交接真实、动态预测覆盖真值这三件事上**；一旦环境漂移使 conformal 覆盖失效、或边端接受了陈旧/投毒的云端地图，证书会变成比“没有证书”更危险的 **false safety**——它会主动关闭保守兜底。故必须把 **OOD 检测 + 地图契约否决 + fail-safe 停车** 作为不可绕过的元护栏，宁可频繁不签发，也绝不签发一个无法被在线覆盖检验的证书。
