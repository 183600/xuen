# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 2 轮；本轮灵感：「任务分解」×「通信延迟」）

> 第 57 轮把"证据说可信"推到了少样本、跨模态、个性化三重纵深，但它默认了两个从未被检验的前提：**(a) 承诺发生在一个不分解的、单一的检查点上**——决策者把整条长程任务当成一次赌注，证据只按"区域"挂账，没有"这段子任务的输出是否足以成为下一段子任务的输入"这一层；**(b) 证据、同意、信任状态都是瞬时且全局一致的**——一张探针图、一次人类"可以"、一个授权级，默认在到达的那一刻就永远成立。真实部署里，任务被分解给多段技能甚至多台机器人，消息要经过网络，证据是"关于过去的断言"，而承诺是"关于现在的赌注"。本轮两个灵感各补一刀：**任务分解**把承诺单位从"检查点"改成"带假设-保证契约的子任务边界"，让证据可作用域化、可组合、可局部追责，并把"还差什么证据"显式记成**接口证据债务**；**通信延迟**把时间变成一等对手——证据带 TTL 与时效核、同意降级为可撤销的**租约**、分布式信任只做**保守 min 合并**（分裂只能少授权、永不超授权）、是否通信本身用**延迟折现 VOI** 决策。核心命题由"少样本可校准、跨模态可对账、个性化有界"升级为 **"契约可组合、证据可过期、授权不可被时延通胀"的分布式证据承诺**。

核心矛盾：
- **H29（分解 vs 组合健全性）**：局部安全 ≠ 全局安全。分解把一次不可逆赌注拆成若干"局部可证"的子赌注，但子任务间的**耦合不变量 I**（采样改变返程表面、导航改变热环境、多机共享同一区域）往往没有证据；接口假设 A_j 若强于上游保证 G_i，组合就在"胶水"处漏。分得越细，接口越多，泄漏面越大；分得越粗，又退回单点过度自信。
- **H30（时延 vs 时效证据）**：证据是"关于过去的断言"，承诺是"关于现在的赌注"。第 57 轮默认证据/同意瞬时有效；通信延迟下，到达的证据可能已过期、同意的持有者可能已失权、信任状态可能在两个副本间分裂。把陈旧证据当新鲜、把过期租约当有效、把分裂授权当合并授权，是三条全新的升险通道。
- **H31（通信 vs 自主）**：通信既是降低不确定性的手段，也是新的延迟源与故障源。等云端元模型、等人确认、等同伴对账都要花时间；在 τ_safe 之外等到的答案价值为负。通信预算与安全停之间的取舍不能靠"总是问一下"，否则系统会在最需要果断时被自己的礼貌拖死。

## 0. 直觉与动机

**灵感 1（任务分解 → 契约式证据与接口债务）**
直觉：一条长程任务不是"一次下注"，而是一串接力。把"去冰塘取样并返回"拆成 导航→接近→探针→取样→返程，每一棒都有**进入条件**（假设 A_i：路面被上游证明足够干、区域被证明非薄冰）与**交付承诺**（保证 G_i：本段结束时共享状态满足某约束）。安全不来自"每段都自信"，而来自**契约可组合**：上一棒的 G_i 必须蕴含下一棒的 A_j，所有局部保证再加**耦合不变量 I** 必须蕴含任务级目标 G_root。分解还带来一个被忽视的资产——**作用域**：取样段的证据不该被返程段无偿借用（取样已经改变了表面）。当必须在保证未建立时穿越边界，不许假装没有风险，而是记一笔**接口证据债务**：欠什么、何时还、由谁还、到期未还就降档/绕行/停。分解的价值是让"我们到底还欠什么"从隐性直觉变成可审计账本。

**灵感 2（通信延迟 → 时效证据、同意租约、保守合并）**
直觉：网络里的每一条消息都是"过去的明信片"。收到"该区域已探明"时，要先问三件事：它是何时写的（t_make）？还新鲜吗（TTL/时效核）？它说的模型版本还是我现在用的版本吗（ver_e）？第 57 轮把同意当成一张永久通行证；在时延世界里，同意应是一张**租约**——有作用域、有持有者、有到期时间、有防重放 nonce、有 fencing token，撤销即时生效，续租要重新往返，且可用窗要扣掉 RTT 与时钟漂移。信任状态也不再是一个全局变量：边缘与云端各有一份，分区时可能分裂；正确的合并方向不是"取最大"，而是**保守 min**——`cal/vig/auth` 全取各副本最小值，降级急切广播，升级要 quorum + 全副本 ack。于是分裂只会让系统更保守，绝不会让它更敢赌。最后，既然通信要花时间，是否通信本身就是决策：用**延迟折现 VOI**——只有当答案大概率在截止前到达、且到达时仍有价值，才值得问。

**灵感 3（合流 → 承诺单位 = 带时间的契约边界）**
直觉：第 57 轮的承诺单位是"检查点"，本轮改成"**契约边界 × 承诺时刻**"。一次承诺合法，需要同时满足：上游保证在边界时刻仍成立（分解维度）、所需证据在 t_commit 仍新鲜且作用域正确（时效维度）、同意租约在 t_commit 仍有效且持有者未失权（授权维度）、没有未清的入边债务（完整性维度）。四者任一失败都只通向更保守的出口，不构成升险路径。

**灵感 4（证据门 FSE → FSE+：新鲜度、作用域、债务三谓词）**
直觉：第 57 轮的五类证据门回答"证据够不够强"；本轮再加三个谓词：**Fresh(e,t_c)**（在承诺时刻仍新鲜）、**Scope(e,T_i)**（作用域匹配，不跨子任务无偿借用）、**NoDebt(∂T_i)**（入边无未清债务）。证据类本身不新增"更强"的类，而是给所有类加一个时间与作用域上的"有效性封印"——一条再强的证据，过期或越界都只能算线索，不能算承诺依据。

**灵感 5（PCE+ → D-PCE：耦合监视器 + 延迟折现通信）**
直觉：探-诺-演循环外面再套一层"分解-契约"层；每个边界先跑耦合监视器，检查共享状态是否仍满足 I（取样后表面变了 ⇒ 下游契约失效 ⇒ 重新分解或重规划）。缺证据时先算延迟折现 VOI，够得着截止才发通信，够不着就直接走本地保守默认。通信预算与探针预算并列，成为有限资源。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（任务分解契约 TDC）** 分解 𝒟=(𝒯,≺,𝒮,I)。𝒯={T_i}_{i=1..n}，每个子任务带契约 C_i=(A_i,G_i,E_i)：A_i 为进入假设（对共享接口变量 X_i⊆𝒮 的约束），G_i 为退出保证，E_i 为作用域限定在 T_i 的证据子证书（J_p 的 scope 切片）。≺ 为 DAG 偏序；𝒮 为共享状态（区域图 𝓜、耦合变量）；I 为对 𝒮 的耦合不变量。**健全性三条件**：(i) ∀(i→j)∈≺，G_i∧I ⊨ A_j；(ii) ∧_i G_i∧I ⊨ G_root；(iii) ∀i，E_i 仅引用 T_i 可达区域与证据类，跨作用域复用必须显式 re-scope 并重验新鲜度。粒度选择为 min_𝒟 [Coordination(𝒟)+LeakageRisk(𝒟)] s.t. (i)-(iii) 与预算，其中 LeakageRisk 度量未被 I 覆盖的耦合变量数，接口数 |∂𝒟| 进入复杂度。

**定义 140（接口证据债务 IED）** 当必须在 G_i 未建立时穿越边界，记债务 d=(obl 待证命题, deadline τ_d, discharge 所需证据类与作用域, owner, cover)。约束：①债务显式且加权有界 Σ_i w(d_i)≤D_max（w 随接触不可逆程度递增）；②覆盖关系 cover 严格强于原证据门，只有更强证据类能覆盖债务；③不可逆接触（L2）前所有入边债务必须清零；L1 允许 cover 临时覆盖，但 τ_d 到期未清即强制降档/绕行/安全停；④债务随承诺写入证书 J_p，不得静默丢弃。

**定义 141（时效证据 TE）** 证据 e=(payload,t_make,t_recv,ttl_e,ver_e,nonce_e,scope_e)。在承诺时刻 t_c 的有效置信 conf_{t_c}(e)=conf(e)·g_age(t_c−t_make;λ_e)·1[t_c≤t_make+ttl_e]·1[ver_e∈𝒱_pin(t_c)]·1[scope_e∋(T_i,r)]，其中 g_age 为声明单调不增的时效核，𝒱_pin(t_c) 为决策开始时钉住、且承诺时刻仍被允许的模型版本集。承诺判定在 t_c 执行而非 t_recv；陈旧漏检概率 ≤δ_age 由 ttl 与 g_age 的诚实声明保证。未通过 Fresh 谓词的证据只能作"待验证线索"，不得计入必要证据集。

**定义 142（同意租约 CL）** 租约 c=(scope,holder,t_grant,L,nonce,fence)。有效 ⇔ t_grant≤t_c≤t_grant+L ∧ nonce 未被消费 ∧ fence=fence_latest(scope) ∧ holder 在 t_c 仍持有该 scope 的授权（取 DTC 合并后值）。续租须一次新往返，τ_int^eff=τ_int+RTT̂+skeŵ（租约可用窗相应收缩）；撤销即时生效（eager revoke）。重放（旧 nonce）、过期、旧 fence、失权 holder 一律拒绝，拒绝即保守默认。授权只参数化佐证数、w_h 与 τ_int，决策规则本体不因租约而变。

**定义 143（分布式保守信任合并 DTC）** 每副本 v 持 s_o^v=(cal_o^v,vig_o^v,auth_o^v)。合并算子 ⊔ 保守：cal^⊔=min_v cal^v，vig^⊔=min_v vig^v，auth^⊔=min_v auth^v；降级即时广播并带向量时钟，升级需 quorum 令牌或单写者租约且在所有副本 ack 后生效。性质：任意分区/乱序/延迟下 auth^⊔≤min_v auth_real^v，即"分裂只会少授权、永不超授权"；代价是可用性（可能暂时过保守），需以会话域与重连同步回收。

**定义 144（延迟折现 VOI 与通信安全预算 LVOI）** 通信动作 κ（问人/同伴对账/取元模型）有成本 c_κ、截止 d_κ、到达时间分布 A_κ（由 RTT 估计）。VOI_L(κ)=E_{A_κ}[VOI(κ)·1[A_κ≤d_κ]·g_age(d_κ−A_κ)]−c_κ−λ_lat·Var[A_κ]。通信规则：仅当 VOI_L(κ)≥θ_voi ∧ RTT̂+3σ̂≤τ_safe(level) 才发起；否则走本地保守默认（hold/降档/安全停）。通信预算 C_comm 与探针预算并列进入 D-PCE。

## 2. 关键算法伪代码（完整版见产物区）

```python
def decompose_and_contract(task, M, risk):          # IP-139
    D = propose_decomposition(task)
    for T in D.nodes:
        D.C[T] = infer_contract(T, M, risk)          # (A,G,scope)
    for (i, j) in D.edges:
        if not entails(D.C[i].G and D.I, D.C[j].A):
            D = refine(D, edge=(i, j))               # 加细或加耦合探针
    return D if entails(all_G(D) and D.I, task.G_root) else None

def fresh(e, t_c, pinned_ver):                       # IP-141
    return (t_c <= e.t_make + e.ttl and e.ver in pinned_ver
            and not e.nonce_used)

def lease_valid(c, t_c, trust):                      # IP-142
    return (c.t_grant <= t_c <= c.t_grant + c.L
            and not consumed(c.nonce)
            and c.fence == fence_latest(c.scope)
            and auth_of(c.holder, trust) >= required(c.scope))

def merge_trust(replicas):                           # IP-143
    return State(cal=min(r.cal for r in replicas),
                 vig=min(r.vig for r in replicas),
                 auth=min(r.auth for r in replicas))

def dpce(x0, task, M, budget, consent, personas):    # IP-144
    D = decompose_and_contract(task, M, risk)
    if D is None: return safe_hold('decomposition_unsound')
    pinned = model_version_now()
    for b in D.topological_boundaries():
        if coupling_violated(D.I, M, b):             # 胶水监视器
            D = refine_or_replan(D, b); continue
        k = choose_comm_action(b, D, M)
        if k and lvoi(k, M, b) >= theta_voi \
           and rtt_hat(k) + 3 * sigma_hat(k) <= tau_safe(b.level):
            send(k); budget.spend_comm(k)
        ok = evidence_gate_plus(core_contact(b), now(), D, ledger, personas, ood)
        if ok and lease_valid(consent[b], now(), merge_trust(trust_replicas)):
            commit(b); ledger.settle(b)
        else:
            return negotiate_or_stop(b, M, consent, personas)
    return schedule
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| TDC | O(\|𝒯\|·\|∂𝒟\|)；蕴含检查最坏 O(\|𝒯\|²) | O(\|𝒯\|+\|∂𝒟\|) | 契约健全（A41）、粒度泄漏审计 |
| IED | O(\|∂𝒟\|) 账本更新 | O(\|∂𝒟\|) | 债务有界、到期强制保守 |
| FSE+ | O(\|σ\|+\|e\|)/边界 | O(\|σ\|) | Fresh/Scope/NoDebt 三谓词 |
| CL | O(1) 校验；O(1) 续租 | O(\|租约\|) | nonce/fence 唯一、撤销即时 |
| DTC | O(\|replicas\|) 合并；O(n²) gossip 最坏 | O(\|操作者\|·\|replicas\|) | 保守 min、分裂不超授权 |
| D-PCE | O(\|𝒯\|·\|CP\|·(k_p+k_c)·(C_VOI+d_φ)+\|∂𝒟\|) | O(\|V\|+\|σ\|+\|𝒯\|) | LVOI 硬门、债务清零、终止 |

**正确性定理（Composable Timely Distributed Soundness, CTDS）**：在 A33–A40 上新增 **(A41)** 契约健全与耦合监视：G_i∧I⊨A_j、根保证成立、耦合漏检 ≤δ_cpl；**(A42)** 时效诚实：ttl/g_age 声明诚实、时钟漂移有界、陈旧漏检 ≤δ_age；**(A43)** 租约与合并诚实：nonce/fence 唯一、DTC 保守、授权超发概率为 0、重放必拒；**(A44)** 时延可估：RTT 估计覆盖真实到达概率 ≥1−δ_rtt、τ_safe 声明诚实。则：(i) 分解承诺失效率 ≤Σ_i(第 57 轮子任务界)+δ_cpl+δ_age+δ_lease+δ_rtt，未清债务贡献为 0（直接拒绝）；(ii) 若 A41 成立，局部健全 ⇒ 对 G_root 全局健全，分解只在接口处新增 δ_cpl 而不改变原有证据界；(iii) 交互单调性：TE 只降 conf、CL 只缩有效期、DTC 只取 min、LVOI 只减通信，四者均无升险通道；(iv) D-PCE 在 |𝒯| 个边界、每边界有限通信与有界债务 deadline 内终止于 {承诺, 绕行, 重新分解, L2 协商, 安全停}。

## 6. 本轮最大风险

### IP-139 TDC（任务分解契约：假设-保证 + 耦合不变量）

```python
def propose_decomposition(task):
    return DAG([nav, approach, probe, sample, return_], deps=task.plan)

def infer_contract(T, M, risk):
    A = required_preconditions(T, M)          # 进入时对共享状态的假设
    G = guaranteed_postconditions(T, M, risk) # 退出时承诺的保证
    return Contract(A=A, G=G, scope=reachable_regions(T))

def decompose_and_contract(task, M, risk):
    D = propose_decomposition(task)
    for T in D.nodes:
        D.C[T] = infer_contract(T, M, risk)
    for (i, j) in D.edges:
        if not entails(D.C[i].G and D.I, D.C[j].A):
            D = refine(D, edge=(i, j))        # 加细子任务或插入耦合探针
    if not entails(all_G(D) and D.I, task.G_root):
        return None                           # 分解不健全，拒绝承诺
    if interface_count(D) > budget.max_iface:
        return None                           # 粒度过细，协调开销失控
    return D
```

def open_debt(boundary, level, ledger):

             deadline=now() + tau_d(boundary),
             discharge=boundary.required_evidence,
             owner=boundary.owner, cover=boundary.cover_class)

       and scope_ok(e, d.owner):

def fresh(e, t_c, pinned_ver):
    return (t_c <= e.t_make + e.ttl
            and e.ver in pinned_ver
            and not nonce_used(e.nonce))

def scope_ok(e, task_scope):

def evidence_gate_plus(c, t_c, D, ledger, persona, ood_reg):

### IP-142 CL（同意租约：防重放、防过期、防失权）

def grant_lease(scope, holder, L, t_grant):

def lease_valid(c, t_c, trust):
    return (c.t_grant <= t_c <= c.t_grant + c.L
            and not consumed(c.nonce)
            and c.fence == fence_latest(c.scope)
            and auth_of(c.holder, trust) >= required(c.scope))

def renew_lease(c, rtt_hat, skew_hat):
    if c.t_grant + c.L - (rtt_hat + skew_hat) <= now():
        return reject('lease_expired_before_roundtrip')
    c.L = max(0.0, c.L - (rtt_hat + skew_hat))     # 可用窗扣时延
    c.t_grant, c.nonce = now(), fresh_nonce()

def lvoi(k, M, b):
    dist = rtt_estimate(k.peer)
    val = expectation(dist, lambda a: voi(k, M, b) * (a <= k.deadline)
                      * g_age(k.deadline - a, lam=k.lam))

def dpce(x0, task, M, budget, consent, personas):

| 组件 | 时间 | 空间 | 正确性保证 |

**正确性定理（Composable Timely Distributed Soundness, CTDS）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；**(A41)** 契约健全与耦合监视：∀(i→j)，G_i∧I⊨A_j，∧_iG_i∧I⊨G_root，耦合监视器漏检 ≤δ_cpl；**(A42)** 时效诚实：ttl/g_age 声明诚实、时钟漂移有界、陈旧漏检 ≤δ_age；**(A43)** 租约与合并诚实：nonce/fence 唯一、DTC 保守、授权超发概率 0、重放必拒、撤销即时；**(A44)** 时延可估：RTT 估计覆盖真实到达概率 ≥1−δ_rtt、τ_safe 声明诚实。则：

1. **分解承诺健全性**：P(fail) ≤ Σ_i(第 57 轮子任务界) + δ_cpl + δ_age + δ_lease + δ_rtt；任何未清债务使该边界承诺被直接拒绝，贡献为 0。
2. **组合性**：若 A41 成立，每个子任务的局部健全性经 G_i∧I⊨A_j 传递，蕴含 G_root 全局健全；分解只在接口处新增 δ_cpl，不改变原有证据类强度界。
3. **交互单调性（强化）**：TE 只降低置信、CL 只缩短有效期、DTC 只取 min 授权、LVOI 只减少通信、债务只增不减至偿还——五者均无升险路径；时延/分区只会让系统更保守。
4. **终止性**：D-PCE 在 |𝒯| 个拓扑边界、每边界有限通信（C_comm 约束）与有界债务 deadline 内终止于 {承诺, 绕行, 重新分解, L2 协商, 安全停}。
5. **部署界**（对检查点与接口边界取联合界）：

```
P_safe ≥ 1 − Σ_cp Σ_i (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])
             − Σ_b (δ_cpl + δ_age + δ_lease + δ_rtt)
             − P(𝓜 陈旧未检出) − P(耦合监视器漏检) − P(护盾回退失败)
```

关键：**分解给结构、契约给责任、债务给诚实**（局部自证不再等于全局自证，欠账必须显式且到期即保守）；**时效给证据封条、租约给同意封条、保守合并给授权封条**（时间不能把"过去的同意"洗成"现在的授权"）；**LVOI 把"是否通信"也变成一次有截止的安全决策**。四个新机制全部经"证据更弱/更旧/更窄、授权更小、通信更少"的保守通道起作用。

## 6. 本轮最大风险

**一句话**：本轮把风险从"坏先验普遍"赶到了**接口与时间缝**——任务分解让每一段子任务都能局部自证正确，但真正决定生死的耦合不变量 I 与跨边界共享状态往往没有证据，而通信延迟又让每段"看到"的是陈旧世界，于是每段都拿着过期地图交接一个此刻已不成立的保证；换言之，分而治之没有消除赌注，只是把赌注藏进了胶水与时延里，必须以耦合监视器、接口债务、时效证据与保守信任合并四重护栏，宁可停在一个"局部都保守、全局可审计"的慢解，也不接受"每段都对、合起来错"的漂亮分解。
