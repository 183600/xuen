（灵感驱动研究循环·新灵感组合第 1 轮；本轮灵感：「竞品分析」×「应用落地」）

> **基线**：第 2 轮产出 MetricVoiceGauge-NCD-HUTDH-v23 + IP-431–439（云边同步 CESC / 少样本 FSVC / IP 认证 IPAM / 四证 HPC-E+）。其上承 v22 分层 PGEV（HDL/ACSC/DCSC/CFC++）、v21 语义-规范层（SDC/CAC/DCL/GIC）、v20 联邦感知证书与 v19/v17 全链。
> **本轮纪律**：前二十三轮的全部证明都是"相对于自身"的——`Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18`，却从未回答"凭什么是你、凭什么现在能上场"。竞品分析提供**外部参照类与可证伪的比较命题**；应用落地提供**从实验台到现场的成熟度阶梯与成本约束**。不推倒 v23：IP-431–439 全部保留；本轮只加一层"外部效度 + 运营就绪"的落地层，把"自洽的证书"升级为"可被外部基准证伪、可被现场证据逐步解锁"的证书。

## 0. 直觉与动机

**灵感 1（竞品分析 → 外部效度、参照类与可证伪的比较优势）**
直觉：v23 造了一台越来越精密的"自证机器"，但它最大的竞争对手从来不是另一套证书体系，而是**现状基线**——一台 SICK 安全激光雷达 + ISO 3691-4 认证的简单堆栈。如果 v24 不能在人机共享场景里，用可审计的统计证据说明自己**在同等风险下活性更高、或在同等活性下风险更低、且部署成本不爆炸**，那么再优雅的证明也只是学术自娱。竞品分析在此不是市场动作，而是一种**认识论工具**：它强制引入**参照类 (reference class)** 与**共享场景分布**，把"我们更好"从修辞变成**配对差分假设检验**；它同时暴露"哪些是入场券（table stakes）、哪些是差异化（differentiator）"，防止把工程必备能力误当成创新卖点。反直觉点：**竞品分析的首要产物不是"优势清单"，而是"证伪清单"**——先写下在什么场景下我们应当输给基线，再去测；测不出来，才配谈优势。

严谨定义（参照类差分证书 RCDC）：给定参照类 `R = {b_0, b_1, …, b_m}`（`b_0` = 现状认证基线，`b_1…` = 端到端学习+运行时监控、纯几何证书等替代架构，挑战者 = v24），共享配对场景分布 `D_eval = {(ξ_i, seed_i)}`，指标向量 `m(π, ξ) = (collision, near_miss, intervention, throughput, TCO)`。对每个安全性指标定义配对差分 `Δ_i = m_challenger(ξ_i) − m_baseline(ξ_i)`，用**e-过程/检验鞅** `E_t = ∏_{i≤t}(1 + λ_i Δ_i)`（`Δ_i` 有界、`λ_i` 可预测）构造证据；当 `E_t ≥ 1/α` 时拒绝 `H_0: challenger 不优于 baseline`（Ville 不等式保证任意时刻第一类错误 ≤ α）。**比较优势命题** `Claim(c)` 仅在 (i) 参照类显式声明、(ii) 配对同种子、(iii) 效应量 + e-值达阈、(iv) Pareto 非支配（任一维度不得显著劣化）四条同时满足时才可签发。

**灵感 2（应用落地 → 成熟度阶梯与"挣得"的 ODD 扩张）**
直觉：v23 的每一条证明都在**收缩**执行集，这在实验台上是美德，在现场却是死因：一个永远只敢在空场地慢速爬行的机器人，安全证书再完备也会被客户退货。落地的本质是**在受控、可撤销、由现场证据"挣得"的前提下，逐步扩大运行设计域 (ODD)**——先影子回放，再有人盯守，再限速限区，最后才放开到已认证包络。关键张力：**扩张是概率性的、可停止的、随时可撤销的；但扩张的终点永远不得超过 v23 已认证的包络**。这要求现场证据的统计工具必须支持**连续监控 + 可选停止**，否则"多跑几天看看"会系统性地抬高假阳性解锁率。反直觉点：**落地安全不是单调收缩，而是"有证据才解锁、一有异常就瞬时回缩"的非对称棘轮**——扩张慢如蜗牛、回缩快如断闸。

严谨定义（部署成熟度阶梯 DML / 部署就绪证书 DRC）：成熟度 `ℓ ∈ {L0, L1, L2, L3, L4}` 对应已解锁 ODD 序列 `∅ ⊂ ODD_0 ⊆ ODD_1 ⊆ … ⊆ ODD_4 ⊆ ODD_cert`，`ODD_cert` 为 v23 证书覆盖的包络。第 `k` 级门控 `Gate_k: E_{1..t} → {pass, fail}` 基于**随时有效置信序列 (anytime-valid confidence sequence)** 对现场指标（碰撞/近失/人工接管/越界事件）做监控；`ODD_unlocked(t) = ODD_{ℓ(t)}`，`ℓ(t)` 仅在门控连续通过且无异常时上升，任何异常事件使 `ℓ(t) ← L_{max(0,ℓ−1)}` 或直接回 L0（分级回缩）。**部署就绪谓词** `DeployReady(π, ℓ) ≜ ODD(π) ⊆ ODD_ℓ ∧ TCO(π) ≤ B_tco ∧ 所有 Claim 有 RCDC 背书`。

**二者如何统一**
统一为 **v23 证书栈之上的"外部效度-运营就绪"层**：RCDC 回答"凭什么说我们比现状更好、好在哪、边界在哪"，DRC 回答"凭什么现在可以把它放到这个场地、以这个速度、在这个区域跑"。共享状态扩展为 `ζ_dep = ζ_ce ∪ (R, D_eval, E_t, ℓ, ODD_ℓ, TCO, claims, fel)`。统一准入门 **HPC-E++ = HPC-E+ ∧ DRC ∧ TDB**：只有"v23 全部证书通过 ∧ 当前成熟度已解锁该 ODD ∧ 成本在预算内"才执行；RCDC 不直接过滤计划，而是**给 DRC 的每次升级背书**——没有可证伪的比较证据，成熟度阶梯不许往上爬。故 `Exec_v24 = Exec_v23 ∩ Fil_drc ∩ Fil_tco ⊆ Exec_v23`，单调链继续成立。

## 1. 研究问题（轮次升级版）

## 2. 设计原则（在 P34–P42 基础上新增 P43–P45）

**P43 竞品差分可证伪律（Competitive Differential Falsifiability）**
任何"优于参照类"的断言都必须是一次**预先注册的配对假设检验**：显式声明参照类 `R`、共享场景分布 `D_eval`、指标向量 `m` 与效应量；用 e-过程在任意时刻拒绝 `H_0` 时第一类错误 ≤ α；且必须满足 Pareto 非支配。**未通过 RCDC 的断言不得写入对外证书，也不得作为成熟度升级的依据**。RCDC 只影响"可主张什么"与"能否升级"，绝不直接放宽执行集——避免"为了赢基准而放行"。

**P44 落地成熟度棘轮律（Deployment Maturity Ratchet）**
`ODD_unlocked(t) = ODD_{ℓ(t)} ⊆ ODD_cert` 恒成立；`ℓ(t)` 上升需连续通过随时有效门控且无异常事件，下降可瞬时发生（异常/越界/接管率超标）。**扩张与回缩不对称**：`τ_up ≫ τ_down`（升慢降快），回缩带滞回 `h` 防振荡。任何一级解锁都携带可审计证据哈希并写入 merkle 账本；`Exec_v24 = Exec_v23 ∩ Fil_drc`，故安全单调性不被"落地"破坏。

**P45 成本显式与 Pareto 律（Deployment Cost Explicitness）**
证书必须携带**可部署性向量** `d(π) = (capex, opex, integration_person_days, bandwidth, latency_p99, memory)`；`TCO(π) = Σ d_i` 必须 ≤ 预算 `B_tco`，且相对参照类的 Pareto 前沿不得被支配。**成本不是软约束**：超预算的计划与超 ODD 的计划一样被 `Fil_tco` 拒绝。目的：让"多加一层证书"的工程代价显式化，防止证书体系无限膨胀直至不可部署。

## 3. 与基线的接口（如何退化）

- RCDC 失效（无参照类/评测不可信）⇒ 禁止任何对外优势主张与成熟度升级，但内部安全证书照常签发 ⇒ 停留在当前 `ℓ`，`Exec_v24` 不扩大；
- DRC 失效（现场证据流中断/门控崩溃）⇒ 瞬时回缩到 `L0`（影子模式），仅保留 `ODD_0` ⇒ 比 v23 更保守；
- TDB 失效（成本模型不可信）⇒ 采用最保守默认预算（只允许已验证的低成本配置）⇒ 子集；
- RCDC 与 DRC 均正常但无任何优势证据 ⇒ 允许部署但不允许"升级解锁"⇒ 保守但可上线；
- 全部落地层失效 ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18`；
- **安全继承**：RCDC 只约束主张、DRC 只收缩 ODD、TDB 只做预算过滤；三者失效均向更保守方向退化，故单调链恒成立。

## 4. 预期贡献

1. **外部效度的形式化**：首次把"竞品分析"从市场修辞升级为可证伪的配对差分证书（RCDC + e-过程 + Pareto 非支配），给整套证书体系一个**外部参照系**；
2. **落地成熟度棘轮**：把"从实验台到现场"形式化为带随时有效证据、可撤销、非对称的 ODD 解锁阶梯（DML/DRC），解决"越证越保守、越保守越不可部署"的活性悖论；
3. **成本即证书**：把 TCO 与集成成本纳入证书与 Pareto 判定（P45/TDB），首次让"证书税"显式可见，给出证书复杂度的经济学刹车；
4. **反 Goodhart 设计**：预注册 + 留出分布 + e-过程可选停止，使"刷基准"在结构上无法伪造优势；
5. **落地安全单调性**：证明 `Exec_v24 = Exec_v23 ∩ Fil_drc ∩ Fil_tco ⊆ Exec_v23`，把"能落地"与"更安全"统一到同一条单调链；
6. **HPC-E++ 五证一体**：HPC-E+ ∪ RCDC ∪ DRC ∪ TDB 统一准入门，形成"安全-合规-可部署-可保护-可竞争"的闭环。

## 5. 本轮最大风险

**一句话**：竞品基准与成熟度阶梯都可能被"指标优化"绑架——一旦把"通过基准 / 到达 L4"当成目标而非手段，系统就会用统计显著性包装一个在真实长尾中从未被覆盖的部署，证书体系退化为**可审计的合规剧场**。

## 1. 关键算法骨架（在 IP-431–439 骨架上扩展）

```python
# ============================================================
# IP-440 Reference-Class Differential Certificate (RCDC)
# ============================================================
@dataclass
class Claim:
    metric: str                  # "collision" / "near_miss" / "throughput" ...
    direction: int               # +1 越大越好（吞吐），-1 越小越好（碰撞）
    delta_hat: float             # 平均配对差分
    e_value: float               # 当前 e-过程值
    pareto_ok: bool
    reference_set_id: str
    eval_hash: bytes             # D_eval 的 merkle 根（预注册）

class ReferenceClassDifferentialCertificate:
    def __init__(self, baselines: dict[str, Callable], alpha: float = 0.01):
        self.R = baselines
        self.alpha = alpha
        self.D_eval: list[tuple[Scenario, int]] = []
        self.e_proc: dict[str, float] = defaultdict(lambda: 1.0)
        self.deltas: dict[str, list[float]] = defaultdict(list)
        self._frozen_eval_hash: bytes | None = None

    def preregister(self, scenarios: list[tuple[Scenario, int]]):
        """预注册评测集：冻结后不可再改，防止事后挑选场景"""
        self.D_eval = scenarios
        self._frozen_eval_hash = merkle_root([s.hash() for s, _ in scenarios])

    def paired_eval(self, challenger: Callable):
        """同种子、同初始状态配对评测；逐指标累积 e-过程"""
        assert self._frozen_eval_hash is not None, "must preregister D_eval"
        for metric, direction in [("collision", -1), ("near_miss", -1),
                                   ("throughput", +1)]:
            self.e_proc[metric] = 1.0
        for xi, seed in self.D_eval:
            m_ch = run_episode(challenger, xi, seed)
            for b_name, b_policy in self.R.items():
                m_b = run_episode(b_policy, xi, seed)   # 缓存：同 ξ/seed 只算一次
                for metric, direction in [("collision", -1), ("near_miss", -1),
                                           ("throughput", +1)]:
                    delta = direction * (m_ch[metric] - m_b[metric])
                    self.deltas[metric].append(delta)
                    lam = self._predictable_bet(self.deltas[metric])  # ∈(0,1/bound)
                    self.e_proc[metric] *= (1.0 + lam * delta)

    def _predictable_bet(self, deltas: list[float]) -> float:
        """可预测投注：仅用 t-1 前信息，保证 E_t 为检验鞅"""
        n = len(deltas)
        if n == 0:
            return 0.0
        mu = sum(deltas) / n
        return max(0.0, min(0.9 / 1.0, 0.5 * mu))  # 简化：Δ 有界于 [-1,1]

    def claims(self) -> dict[str, Claim]:
        out = {}
        for metric in self.e_proc:
            c = Claim(
                metric=metric,
                direction=1 if metric == "throughput" else -1,
                delta_hat=float(np.mean(self.deltas[metric])),
                e_value=self.e_proc[metric],
                pareto_ok=self._pareto_nondominated(metric),
                reference_set_id="R-v24",
                eval_hash=self._frozen_eval_hash,
            )
            out[metric] = c
        return out

    def claim_valid(self, c: Claim) -> bool:
        """可证伪优势：e-值达阈 ∧ 效应量为正 ∧ Pareto 非支配 ∧ 预注册"""
        return (c.e_value >= 1.0 / self.alpha
                and c.direction * c.delta_hat > 0
                and c.pareto_ok
                and c.eval_hash == self._frozen_eval_hash)

    def _pareto_nondominated(self, metric: str) -> bool:
        """挑战者在 (safety, liveness, TCO) 上不被任一基线严格支配"""
        ch = self._aggregate(metric)
        for b in self.R:
            if strictly_dominates(b, ch):
                return False
        return True

# IP-441 Capability Conformance Matrix (CCM)
# ============================================================
class CapabilityConformanceMatrix:
    """入场券 vs 差异化；一致性等级 L0 无 / L1 文档 / L2 测试 / L3 认证"""
    def __init__(self):
        self.rows: dict[str, dict] = {}

    def add(self, capability: str, kind: str, level: int, evidence: str):
        assert kind in ("table_stake", "differentiator")
        self.rows[capability] = dict(kind=kind, level=level, evidence=evidence)

    def deployable(self, required_levels: dict[str, int]) -> bool:
        for cap, need in required_levels.items():
            if self.rows.get(cap, {}).get("level", -1) < need:
                return False
        return True

    def differentiators(self) -> list[str]:
        return [c for c, r in self.rows.items() if r["kind"] == "differentiator"]


# ============================================================
# IP-443 Field Evidence Ledger (FEL) — 随时有效置信序列 + 偏差检测
# ============================================================
class FieldEvidenceLedger:
    def __init__(self, alpha: float = 0.05, n0: int = 30):
        self.alpha = alpha
        self.n0 = n0
        self.streams: dict[str, list[float]] = defaultdict(list)
        self.bias_hist: list[float] = []

    def observe(self, metric: str, value: float, context: dict):
        self.streams[metric].append(value)
        self.bias_hist.append(self._tv_bias(context))

    def confidence_sequence(self, metric: str) -> tuple[float, float]:
        """Hoeffding-style anytime-valid CS（Waudby-Smith & Ramdas 2021）：
        P(∀t: μ ∈ CS_t) ≥ 1-α，支持连续监控与可选停止"""
        x = np.asarray(self.streams[metric], dtype=float)
        n = len(x)
        if n < self.n0:
            return (0.0, 1.0)                    # 证据不足 → 最宽区间
        mu = x.mean()
        # 简化：随时间加宽的 log-log 半径（任意时刻同时覆盖）
        radius = np.sqrt(np.log(np.log(max(n, 3)) + 1.0) / n) * 2.0
        radius += np.sqrt(np.log(2.0 / self.alpha) / (2.0 * n))
        return (max(0.0, mu - radius), min(1.0, mu + radius))

    def sampling_bias(self) -> float:
        """场地/时段/人群分布相对预注册分布的 TV 距离（滑动窗口）"""
        if len(self.bias_hist) < self.n0:
            return 0.0
        return float(np.mean(self.bias_hist[-self.n0:]))

    def _tv_bias(self, context: dict) -> float:
        # 与预注册 context 分布比较，返回 TV 距离（实现略）
        return context.get("tv_distance", 0.0)


# ============================================================
# IP-442 Deployment Maturity Ladder (DML / DRC)
# ============================================================
class DeploymentMaturityLadder:
    LEVELS = ["L0", "L1", "L2", "L3", "L4"]

    def __init__(self, fel: FieldEvidenceLedger, odd_levels: dict[str, "ODD"],
                 tau_up: float = 3600.0, tau_down: float = 1.0, hyst: float = 0.1):
        self.fel = fel
        self.odd_levels = odd_levels
        self.tau_up = tau_up
        self.tau_down = tau_down
        self.hyst = hyst
        self.level = 0
        self.pass_since: float | None = None
        self.last_anomaly: float = -1e9

    def odd(self) -> "ODD":
        return self.odd_levels[self.LEVELS[self.level]]

    def tick(self, now: float, anomaly: bool):
        # 回缩：瞬时、可跨级（异常 / 接管率超标 / 抽样偏差过大）
        if anomaly or self.fel.sampling_bias() > self.hyst:
            self.level = max(0, self.level - (2 if anomaly else 1))
            self.pass_since = None
            self.last_anomaly = now
            return

        # 升级：连续通过门控 ≥ τ_up，且离上次异常 ≥ τ_up
        if self.level >= len(self.LEVELS) - 1:
            return
        if self._gate_pass(self.LEVELS[self.level]):
            if self.pass_since is None:
                self.pass_since = now
            if now - self.pass_since >= self.tau_up and now - self.last_anomaly >= self.tau_up:
                self.level += 1
                self.pass_since = None
        else:
            self.pass_since = None

    def _gate_pass(self, level: str) -> bool:
        """随时有效门控：碰撞/近失上界、接管率上界、ODD 覆盖下界"""
        lo_c, hi_c = self.fel.confidence_sequence("collision")
        lo_i, hi_i = self.fel.confidence_sequence("intervention")
        budget = GATE_BUDGET[level]
        return (hi_c <= budget["collision"]
                and hi_i <= budget["intervention"]
                and self.fel.sampling_bias() <= budget["bias"])

    def deploy_ready(self, plan, tco: float, budget: float, claims: dict) -> bool:
        return (plan.odd ⊆ self.odd()
                and tco <= budget
                and all(claim_valid(c) for c in claims.values()))


# ============================================================
# IP-444 TCO / Deployability Budget (TDB)
# ============================================================
@dataclass
class DeployabilityVector:
    capex: float          # 硬件/传感器/算力
    opex: float           # 能耗/云带宽/维护
    integration_person_days: float
    bandwidth_mbps: float
    latency_p99_ms: float
    memory_mb: float

class TCOBudget:
    def __init__(self, weights: dict[str, float], budget: float):
        self.w = weights
        self.budget = budget

    def tco(self, d: DeployabilityVector) -> float:
        return (self.w["capex"] * d.capex + self.w["opex"] * d.opex
                + self.w["ipd"] * d.integration_person_days
                + self.w["bw"] * d.bandwidth_mbps
                + self.w["lat"] * d.latency_p99_ms
                + self.w["mem"] * d.memory_mb)

    def within_budget(self, d: DeployabilityVector) -> bool:
        return self.tco(d) <= self.budget

    def certificate_tax(self, d_with_cert: DeployabilityVector,
                        d_without_cert: DeployabilityVector) -> float:
        """证书税：为维护证书体系付出的额外 TCO 占比"""
        base = self.tco(d_without_cert)
        return (self.tco(d_with_cert) - base) / max(base, 1e-9)


# ============================================================
# IP-445 HPC-E++ 统一五证准入门
# ============================================================
@dataclass
class HPCEPlusPlus:
    hpc_e_plus: 'HPCEPlus'          # v23 四证（安全/合规/云边/少样本/IP）
    rcdc: ReferenceClassDifferentialCertificate
    dml: DeploymentMaturityLadder
    tdb: TCOBudget
    ccm: CapabilityConformanceMatrix

    def admits(self, plan, x, v, z, E_res, margin_req, modules,
               deploy_vec: DeployabilityVector,
               required_caps: dict[str, int]) -> tuple[bool, dict]:
        # 1. v23 基础（安全/合规/云边/少样本/IP）
        if not self.hpc_e_plus.admits(plan, x, v, z, E_res, margin_req, modules):
            return False, {"reason": "HPC-E+ rejected"}

        # 2. 部署成熟度 + ODD 门控
        if plan.odd ⊄ self.dml.odd():
            return False, {"reason": "ODD not unlocked", "level": self.dml.level}

        # 3. 成本预算
        if not self.tdb.within_budget(deploy_vec):
            return False, {"reason": "TCO over budget",
                           "tco": self.tdb.tco(deploy_vec)}

        # 4. 能力一致性（入场券）
        if not self.ccm.deployable(required_caps):
            return False, {"reason": "capability conformance missing"}

        # 5. 比较优势主张（仅影响对外证书与升级，不影响单步安全）
        claims = self.rcdc.claims()
        if not all(self.rcdc.claim_valid(c) for c in claims.values()):
            return True, {"warn": "deployable but no validated advantage claim",
                          "level": self.dml.level}

        return True, {"level": self.dml.level,
                      "tco": self.tdb.tco(deploy_vec),
                      "claims": claims}
```

## 2. 复杂度分析

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| RCDC 配对评测 | O(\|D_eval\|·\|R\|·T_ep) 离线 | O(\|D_eval\|·\|R\|) | n=10⁴ 场景，\|R\|≤5 |

| FEL 置信序列 | O(1) 增量 / O(window) 偏差 | O(\|streams\|·n) | n₀=30, α=0.05 |
| DML 门控 | O(\|metrics\|) / tick | O(1) | τ_up=1h, τ_down≈1s |

## 3. 正确性论证

### 引理 5（落地层的安全单调性）
**陈述**：对任意时刻 t，`Exec_v24(t) = Exec_v23 ∩ Fil_drc(t) ∩ Fil_tco ⊆ Exec_v23`。
**证明**：
1. `Fil_drc` 只接受 `ODD(π) ⊆ ODD_{ℓ(t)}`，而 `ODD_{ℓ} ⊆ ODD_cert`（DML 定义），`ODD_cert` 由 v23 证书给出；
2. `Fil_tco` 只做预算过滤，不增设计划；
3. RCDC 不进入执行过滤（仅在 `admits` 末尾产生告警，不影响返回 `True` 的集合），故不扩大执行集；
4. 因此任何被 v24 准入的计划必被 v23 准入，单调链保持。∎

### 引理 6（随时有效证据的门控有效性）
**陈述**：若 DML 的门控使用 anytime-valid 置信序列，则在任意可选停止策略下，`P(对某 t 误判指标越界 | 真实指标在界内) ≤ α`。
**证明**：
1. 置信序列满足 `P(∀t: μ ∈ CS_t) ≥ 1−α`（Ville / 检验鞅构造，Waudby-Smith & Ramdas 2021）；
2. 门控只在 `CS_t` 的上界越过预算时判 fail；若真实 μ 在预算内，则误判仅当 `μ ∉ CS_t`，其概率 ≤ α（对所有 t 同时）；
3. 连续监控/可选停止不改变该界，因为界是对整条路径一致成立的。∎

### 引理 7（比较优势命题的可证伪性）
**陈述**：若 `claim_valid(c) = True`，则"挑战者优于参照类"的断言在显著性 α 下成立，且不是基准过拟合的产物（在预注册留出分布上）。
**证明**：
1. `e_value ≥ 1/α` 由 Ville 不等式给出 `P(误报优势) ≤ α`；
2. `eval_hash == _frozen_eval_hash` 保证评测集预注册、未事后挑选；
3. `pareto_ok` 排除"单指标刷分、其余维度劣化"的伪优势；
4. `direction·delta_hat > 0` 排除"统计显著但方向相反"的退化。∎

### 定理（HPC-E++ 五证准入门的安全-合规-可部署-可保护-可竞争完备性）
**陈述**：`HPCEPlusPlus.admits(π) = True` ⟺ π 同时满足：(1) v23 全部安全/合规/云边/少样本/IP 条件；(2) ODD 在当前成熟度内；(3) TCO 在预算内；(4) 能力一致性达标。若需对外主张优势，还需 (5) RCDC 可证伪优势成立。
**证明**：直接由 `admits` 的连言结构与引理 5–7 可得；条件 (5) 只影响对外证书与升级资格，不进入执行集，故不破坏 (1)–(4) 的单调性。∎
