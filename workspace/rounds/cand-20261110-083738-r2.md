# 第 43 轮（新循环第 3 轮） · 证书随形：可重构机构上的「技能证书迁移代数」与形态感知技能学习（四层架构 v8）

> 承接第 42 轮 v19（Sim-Cert-RAG 飞轮：SCV × CKB × ECR）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉」导致证书静默失效。本轮灵感词「技能学习」「可重构机构」把问题从「同一台机器、同一套技能、证书如何进化」推进到**「机器本身会变形、技能会增生」时证书如何跟着走**。核心直觉：v19 的证书都隐含假设「被控对象 f 与控制技能 π 固定」；一旦机构可重构，f 变成 f_m（m 为构型），技能变成可学习、可组合的原子 a，**证书必须从「点」升级为「沿两条轴的族」：时间轴（技能串联）与形态轴（构型重构）**。技能学习提供「可携证书的原子」，可重构机构提供「迁移证书的态射」；二者合成一个**证书范畴**：对象是 (技能, 构型) 上的证书，态射是技能组合与构型重构，soundness 由迁移界的 Lipschitz/ISS 不等式保证。合起来是：**证书随形（Certificates Follow Form）**。

## 0. 直觉与动机

**灵感 1（技能学习 → 从「整机策略认证」到「技能原子 + 组合代数」）**：v19 的 CAR/LCS 把安全证书绑在「一条完整策略」上，策略一改就得重证，冷启动成本高。技能学习的直觉是把策略拆成**可复用的技能原子** a=(π_a, 前置 P_a, 后置 Q_a, 不变式 I_a, 障碍函数 B_a, 收缩率 κ_a, 有效域 D_a)。每个原子自带**契约**，两个原子若能「后置⊆前置 + 不变式相容 + 接口变量对齐」就能组合成 a;b，组合证书由子证书保守合成（B 取 min、κ 取 min、D 取交）。这把第 41/42 轮的 CEGAR 从「每次从零合成整机证书」变成「只在接口差集上做契约检查」。更深一层：技能学习不只产生 π，还可以**产生证书**——用可微 CBF / 学习型障碍函数从示教与仿真中学 B_a，但必须让 B_a 通过 v19 的 CMC 区间电路做 sound 化包装：学习只负责「猜形状」，证书负责「兜底界」。

**灵感 2（可重构机构 → 证书的「协变」而不是「重算」）**：可重构机构（模块化自重构、变拓扑机械臂、变形机构）让动力学 f_m、控制权限 U_m、观测模型 h_m 都随构型 m 变化。v19 的证书在换构型后直接失效，若每次重算，则重构的灵活性被认证成本吃掉。直觉是引入**重构算子**与**证书迁移映射**：若构型 A→B 之间存在状态传输映射 ρ_{A→B} 与模型失配 δ_{A→B}(x)=‖f_B(ρ(x))−Dρ·f_A(x)‖，则把 A 上的障碍函数 B_A 拉回（pullback）到 B，得到**带 δ 带的鲁棒障碍函数**：B_B(ρ(x)) ≥ B_A(x) 且 dB_B/dt ≤ −α(B_B)+L_B·δ，于是只要 B_B ≥ α^{-1}(L_B δ)，迁移后仍安全。这就是把 v19 的 Sim-to-Real 迁移界 α_e 推广为**构型间迁移界 β_{A→B}**。离散拓扑变化（对接、拆解、模块换位）时 ρ 不是微分同胚，连续不等式失效——这正是最危险、也最有研究价值之处：必须引入**重构瞬态证书**（morphing transient certificate），在「旧证书已失效、新证书未生效」的夹缝里给出有限时间安全的第三条保证。

**灵感 3（耦合 → 证书范畴 + 形态随机化）**：把两条轴摆在一起，证书是 (φ 任务, ψ 环境, m 构型, a 技能) 四维空间上的**纤维丛**，技能组合与构型重构都是保 soundness 的态射。由此派生出两个新能力：(1) **证书感知技能学习**——训练技能时不仅最大化任务回报，还最大化「迁移后最差边际」，即形态随机化（morphological domain randomization, MDR），让学到的技能天然**可携**（portable）；(2) **联合形态-技能规划**——任务来了，不只问「用哪个技能」，还问「把机器重构成哪种形态能让这串技能都可证」，把重构当作提高可证性的主动手段，而非被动适配。v19 的 CKB 顺势升级为按 (φ, ψ, m) 索引，迁移证书可热启动复用。

**一句话直觉**：技能学习让证书「可拆可组」，可重构机构让证书「可搬可迁移」，两者相乘得到一张**能随形态流动的技能安全网**。

## 1. 形式化定义（增量：定义 38–44）

**定义 38（技能原子与技能证书）**：技能原子 a = (π_a, P_a, Q_a, I_a, B_a, κ_a, D_a)，其中 π_a 闭环策略，P_a/Q_a 前置/后置条件集，I_a 不变式集，B_a: D_a→ℝ 障碍/能量函数，κ_a>0 认证收缩率，D_a 有效域。称 a 在 D_a 上**已证**，若 ∀x_0∈D_a∩P_a，闭环轨迹满足 x_t∈I_a、B_a(x_t)≥0 且 dB_a/dt ≤ −κ_a B_a（前向不变 + 指数稳定），并在有限时 T_a 内到达 Q_a。技能证书 C_a=(B_a, κ_a, D_a, T_a)。

**定义 39（技能证书的时序组合）**：a;b 可组合当且仅当 Q_a⊆P_b、I_a∩I_b≠∅、接口变量对齐（读写契约一致）。组合证书 C_{a;b}=(min(B_a,B_b), min(κ_a,κ_b), D_a∩D_b, T_a+T_b)，仅在接口差集 Δ_{ab}:=(I_a∩I_b)^c 上跑 CEGAR 补全。**命题**：若 Δ_{ab} 补全 sound，则 C_{a;b} sound（保守合成 + 差集补全，不引入新假设）。

**定义 40（可重构机构族与重构算子）**：构型空间 M，每个 m∈M 给出状态空间 X_m、动力学 f_m、控制权限 U_m、观测 h_m。连续重构算子 R: m→m' 附带状态传输 ρ_{m→m'}: X_m→X_{m'} 与模型失配
δ_{m→m'}(x)=‖f_{m'}(ρ(x))−Dρ_{m→m'}·f_m(x)‖ + ‖h_{m'}∘ρ − h_m‖，
**重构距离** d_M(m,m')=sup_x δ_{m→m'}(x)。离散拓扑变化（对接/拆解）记为 m⊳m'，此时 ρ 非微分同胚、d_M 无定义，改由**接口契约**刻画（见定义 44）。

**定义 41（证书迁移与重构修正系数 β）**：连续重构下把 C 拉回至 m'：C'=ρ^*C，B'(ρ(x))=B(x)。鲁棒障碍函数不等式 dB'/dt ≤ −κ B' + L_B·δ 给出**迁移边际退化** m'(ρ(x)) ≥ m(x) − L_B·δ_{m→m'}·T_horizon。定义 β_{m→m'} = 1 + L_B·d_M·T_horizon / max(ε,κ)，实机阈值 θ'=β·θ。**定理（迁移 soundness）**：若 β_{m→m'}·θ 不超过 κ 裕度且 δ 上界 sound，则迁移证书在 m' 上 sound；否则证书标记 `TransportedUnsafe` 并拒绝激活。

**定义 42（形态-技能证书适用包络与可携半径）**：技能 a 的可证构型集 M_a={m∈M : C_a 迁移至 m 仍 sound}，适用包络 E_a={(m, D_a^{(m)})}。**可携半径** r_a = max_{m∈M_a} d_M(m, m_a^0)，m_a^0 为技能原始认证构型。MDR 的目标即最大化 min_{m∈M} margin 并扩大 |M_a|。

**定义 43（证书感知技能学习 / 形态随机化）**：技能学习目标 J(π)=E_{任务}[R] − λ·P_fail(C_π) s.t. min_{m∼p_M} margin_{π,m} ≥ 0。**形态随机化（MDR）**：m∼p(M) 采样构型参与训练，等价于对动力学参数的分布鲁棒优化。**证书成功率** CS(π)=P_{m∼p_M}[π 在 m 上可证]；学习目标 max_π min_m margin_{π,m}，产出 (π, {C_{π,m}})。

**定义 44（重构瞬态证书与三相语义）**：对离散重构 m⊳m'，定义接口状态 Y=I_{m→m'}（两构型共享的可观测接口量），瞬态证书 C_trans=(I_trans, B_trans, T_m) 满足：∀y_0∈I_trans∩P_trans，在 [0,T_m] 内 B_trans(y_t)≥0，且 T_m 内到达 ρ^{-1}(D_{m'}) 的入口集。**三相证书语义**：(i) 重构前——旧证书 C_m；(ii) 重构中——瞬态证书 C_trans（专用安全集，必要时 SafeStop 是它的合法后置）；(iii) 重构后——新证书 C_{m'} 激活，带迟滞阈值防抖。**定理**：若 C_m、C_trans、C_{m'} 三相均 sound 且接口契约 Y 对齐，则整段重构安全。

## 2. 四大产出设计（增量 IP-57/58/59 + 升级 IP-55/51/52/47/49/50/54/56）

### 2.1 IP-57 CERTIFICATE-CARRYING SKILL LIBRARY（CCSL 证书随行技能库）
1. **技能原子化**：把既有策略拆为 a=(π_a, 契约, C_a)；契约用类型化端口（输入状态/输出状态/资源）描述，便于组合检查。
2. **组合代数**：链式组合 a;b 用定义 39 合成；并行组合 a∥b 用「资源共享 + 干扰项」处理（共享执行器、共享状态估计），生成乘积证书。
3. **接口差集 CEGAR**：只在 Δ_{ab}（后置⊄前置、不变式冲突区）跑补全，其余直接复用。
4. **证书版本锁**：策略每次更新生成新 hash，旧证书自动失效并触发增量再证，防「学习漂移」绕过证书。

### 2.2 IP-58 RECONFIG-CERT-TRANSPORT（RCT 重构证书迁移）
1. **连续迁移**：计算 ρ 与 d_M，按定义 41 得 β，输出 `TransportedCertificate`（含 β、退化带、有效期）。
2. **离散拓扑变化**：抽取接口状态 Y、生成接口契约、合成瞬态证书 C_trans（鲁棒 CBF / 有限时间可达集）。
3. **迁移收缩**：多次迁移 β 会连乘，做 **β 预算管理**——β_total=∏β_i 超阈值即拒绝再迁移或触发再证，避免误差爆炸。
4. **迁移溯源**：每张迁移证书记 (源构型、目标构型、ρ hash、δ 上界、β、时间戳)，供 CKB 索引与审计。

### 2.3 IP-59 MORPHO-SKILL-LEARNER（MSL 形态感知技能学习）
1. **MDR 训练环**：构型采样器 p(M)（连续参数 + 离散拓扑），每轮对采样构型做证书压力测试，把最差边际回传为损失。
2. **可微证书代理**：B_a 用可微参数化（神经 CBF），学习后再经 CMC 区间电路 sound 化；学习只提供形状先验，认证仍走形式化。
3. **便携性正则**：L_port=Σ_m max(0, θ − margin_m)，显式奖励「迁移后仍安全」。
4. **技能-形态共设计**：允许学习器同时提出「建议构型序列」，把重构当作动作空间的一部分（见 2.4）。

## 5. 本轮最大风险

**一句话**：迁移界 β 会随重构次数**连乘膨胀**，而离散拓扑切换点恰是 Lipschitz/ISS 假设失效的奇点——一旦 β_total 被低估或瞬态证书在切换瞬间误判可行，证书会「带着合法外衣」穿过一次拓扑跳变而失效；因此 E88（迁移界）与 E89（瞬态）必须设为红线，任一不达标即禁止该重构边。

## 2. 关键算法（伪代码）

### IP-57 CCSL：技能组合与契约检查
```
def compose_skills(a, b, budget_cegar=60s):
    # 1. 契约链式检查
    assert subset(a.Q, b.P),          "postcondition of a must imply precondition of b"
    assert compatible(a.ports, b.ports), "interface variables must align"
    inter = a.I & b.I
    # 2. 保守合成证书
    C = Certificate(
        P=a.P, Q=b.Q, I=inter,
        B=lambda x: min(a.B(x), b.B(x)),   # barrier 取 min（更保守）
        kappa=min(a.kappa, b.kappa),
        D=a.D & b.D,
        T=a.T + b.T
    )
    # 3. 只在接口差集上补全
    Delta = (a.I & b.I).complement_within(a.D & b.D)
    if not empty(Delta):
        C = cegar_refine(C, Delta, budget=budget_cegar)
    C.cert_hash = hash_policy(a.pi) + hash_policy(b.pi)
    return C

def compose_parallel(a, b):
    # 并行/共享资源：引入干扰项，证书取乘积并加干扰裕度
    G = interference_set(a, b)          # 共享执行器/状态估计冲突
    C = Certificate(
        I=a.I & b.I,
        B=lambda x: min(a.B(x), b.B(x)) - worst_interference(G, x),
        kappa=min(a.kappa, b.kappa) - lip_interference(G),
        D=a.D & b.D
    )
    return C
```

### IP-58 RCT：证书迁移、瞬态合成与 β 预算
```
def transport_certificate(C, m_from, m_to, rho, T_horizon, beta_budget):
    if is_discrete_topology_change(m_from, m_to):
        return discrete_transport(C, m_from, m_to)
    # 连续重构：鲁棒 CBF pullback
    delta = sup_x model_discrepancy(m_from, m_to, rho, x)   # d_M
    L_B   = lipschitz_constant(C.B)
    beta  = 1.0 + L_B * delta * T_horizon / max(1e-6, C.kappa)
    if beta_budget * beta > BETA_MAX:                       # 连乘爆炸保护
        return TransportResult(status='REJECT', reason='beta_budget_exceeded')
    C_to = pullback(C, rho)
    C_to.kappa = C.kappa - L_B * delta * T_horizon
    C_to.valid = (C_to.kappa > 0)
    C_to.beta  = beta
    C_to.status = 'OK' if C_to.valid else 'TransportedUnsafe'
    return C_to

def discrete_transport(C_from, m_from, m_to):
    # 离散拓扑变化：抽接口状态 -> 接口契约 -> 合成瞬态证书
    Y = interface_state(m_from, m_to)          # 共享接口可观测量
    contract = extract_contract(C_from, Y)     # 旧证书在接口上的投影
    C_trans = synthesize_transient_cert(
        I_trans=safe_interface_set(m_from, m_to, contract),
        target=preimage_valid(C_to=None, rho=None, m_to=m_to),
        T_m_max=2.0
    )
    if not C_trans.feasible:
        return TransportResult(status='REJECT', reason='transient_infeasible')
    return TransportResult(status='TRANSIENT', C_trans=C_trans, contract=contract)

def synthesize_transient_cert(I_trans, target, T_m_max):
    # 在接口安全集上合成有限时间障碍函数，负责 T_m 内到达目标入口集
    B_trans = synth_robust_cbf(I_trans, target, horizon=T_m_max)
    T_m     = max_reach_time(B_trans)
    return TransientCert(I_trans=I_trans, B=B_trans, T_m=T_m,
                         feasible=(B_trans is not None and T_m <= T_m_max))
```

### IP-59 MSL：形态随机化技能学习
```
def learn_morphology_robust_skill(task, M, p_M, iters=1e5):
    pi = init_policy(task)
    for it in range(iters):
        m_batch = sample_configs(p_M, M, k=16)
        loss = 0.0
        worst_margin = +inf
        for m in m_batch:
            C_m = certify(pi, m)                 # 走 CMC 区间电路 sound 化
            margin_min = min_barrier_margin(pi, m)
            worst_margin = min(worst_margin, margin_min)
            loss += task_loss(pi, m) \
                    + lambda_cert * max(0.0, theta - margin_min)   # L_cert
            loss += lambda_port * max(0.0, theta - transported_margin(C_m, m))
        pi = update(pi, loss)                    # 学习只猜证书形状
    return pi, {m: certify(pi, m) for m in sample_configs(p_M, M, k=256)}
```

def car_step(x, m, cert_slots, plan):
    if plan.current_mode == 'Morphing':
        status, margin = check_transient(cert_slots.transient, x)
        if not status: return SafeStop(reason='transient_violation')
        return continue_morphing()
    # 正常：使用（可能迁移来的）证书
    C = cert_slots.active(m)
    if C.status != 'OK':
        return SafeStop(reason='certificate_transported_unsafe')
    theta_real = C.beta * C.theta
    return guard(x, C, theta_real)

def certify_light_v3(x, m, guards, budget_us=200):
    # T-2: 迁移证书查表（零重证）
    C = cert_slot_table.lookup(m)
    if C and C.status == 'OK':
        b = C.margin_at(x); U = undecided(b, guards)
        if not U: return b, -2
    # T-1: L0 查表
    b = cert_lookup_L0(x, m); U = undecided(b, guards)
    if not U: return b, -1
    # T0: L1 INT8 监控
    return downgrade_monotone(b), 0

### IP-47 升级：技能×构型双轴联合规划
```
def plan_certified(phi, M, skill_lib, reconfig_cost):
    # 节点=(构型m, 抽象状态s)，边=执行技能 或 重构
    open_set = priority_queue(); open_set.push((0.0, (m0, s0)))
    best = {}
    while open_set:
        cost, (m, s) = open_set.pop()
        if goal_reached(phi, s): return reconstruct_path()
        for a in skill_lib.applicable(s, m):
            s2 = a.apply(s)
            if a.cert.valid_on(m) and subset(s, a.P):
                open_set.push((cost + a.cost, (m, s2)))
        for m2 in M.neighbors(m):
            tr = transport_certificate(active_cert(m), m, m2, rho(m, m2), T_h)
            if tr.status in ('OK', 'TRANSIENT'):
                open_set.push((cost + reconfig_cost(m, m2), (m2, s)))
    return None
```

## 4. 实验设计（E87–E94，硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E87 技能组合 soundness | 组合证书在随机采样初始条件的违例率；接口差集召回 | 0 违例；差集召回 ≥99% |
| E88 证书迁移界实测 | 迁移后实机边际 ≥ β·θ 比例；β 保守度 | ≥95%；β 不过估 >2x 真实退化 |
| E89 重构瞬态安全 | 重构全程不安全事件；瞬态证书可行率；T_m | 0 起；≥98%；T_m<2s |

| E91 联合规划 | 认证任务成功率；规划时间；重构次数 | ≥90%；<60s；≤3 次 |
| E92 迁移热启动 | 迁移证书复用率 vs 重证；重证时间下降 | 复用 ≥70%；降 ≥10x |
| E93 长时程重构鲁棒性 | 100h 反复重构：不安全事件、可用性、β_total 增长 | 0 起；Nominal≥80%；β_total<1.5 |

回退：E88 迁移界失效 → 关闭连续迁移，退回逐构型重证；E89 瞬态不可行 → 重构全程 SafeStop，把重构降级为离线停机操作；E90 CS 不达标 → 缩小 M 到可证子集，禁止跨子集重构；E93 β 爆炸 → 强制周期性全量重证替代连乘迁移。

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| β 连乘膨胀：多次重构后 β_total 指数增长，可用性或 soundness 双崩 | 高 | E93 β_total<1.5 红线；β 预算管理超阈即拒绝迁移或触发全量重证 |
| 拓扑切换奇点：离散重构时 ρ 非微分同胚，连续界失效 | 高 | E89 红线；接口契约 + 瞬态证书 + 重构期间 SafeStop 兜底；瞬态不可行即禁该重构边 |
| 技能学习漂移：在线更新策略使旧证书失效却被继续使用 | 高 | 证书版本锁 + 策略 hash 校验；漂移即触发增量再证或回滚策略 |
| 接口差集被低估：组合只在标称接口检查，漏掉耦合扰动 | 中 | 差集召回 ≥99% 门槛；并行组合计入干扰裕度 |
| 形态空间组合爆炸：M 巨大，CKB 冷启动稀疏 | 中 | 分层构型抽象 + 相似构型证书外推（β 界内）；仅在有界子集开放重构 |
| 可微 CBF 学习不 sound：神经障碍函数只在采样点成立 | 中 | CMC 区间电路 sound 化包装；全量验证集零违例才放行 |
| 瞬态证书保守过度：T_m 超时导致频繁 SafeStop | 中 | 瞬态安全集与目标入口集协同设计；T_m 预算 + 迟滞防抖 |

## 6. 本轮最大风险

**一句话**：迁移界 β 会随重构次数**连乘膨胀**，而离散拓扑切换点恰是 Lipschitz/ISS 假设失效的奇点——一旦 β_total 被低估或瞬态证书在切换瞬间误判可行，证书会「带着合法外衣」穿过一次拓扑跳变而失效；因此 E88（迁移界）与 E89（瞬态）必须设为红线，任一不达标即禁止该重构边。
