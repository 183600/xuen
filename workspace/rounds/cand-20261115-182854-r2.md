# 第 9 轮（灵感循环第 9 轮；本轮灵感：「手势识别」×「视觉语言动作模型」）
> **基线**：第 8 轮 MetricVoiceGauge-DA-SPR-Cal v8（定义 493–531；引理 77–81；实验 E531–E550）。
> **本轮纪律**：手势识别与 VLA **都不进入硬约束主环**。二者只贡献「提议 + 不确定性」，由证书层裁决；任一模块缺失必须逐级退化回 v8，且不得改变 M₀ 的语义。

## 0. 直觉与动机

**灵感 1（手势识别 → 指称接地与安全旁路）**
直觉：现有系统的「意图入口」几乎只有语音文本。但人说话时大量使用指示词——「把**那个**拿给我」「放**这里**」。语言本身不携带指称对象，真正消歧的是手。手势识别因此有两个正交价值：
1. **指称接地（deictic grounding）**：指向射线 + 3D 场景图，把「那个」绑定到具体物体，补上语音缺失的一阶信息；
2. **安全旁路（safety override）**：张开手掌/举手是跨文化的高优先级「停」信号，应能以低延迟直接落到 M₀，而不经过长链路语义解析。
直觉上的关键判断是：手势的**误识别**很常见，所以它绝不能成为「允许做什么」的依据，只能成为「禁止做什么」的依据之一——禁止是安全单调的，允许不是。

**灵感 2（视觉语言动作模型 → 动作提议器，而非决策者）**
直觉：VLA（如 RT-2 / OpenVLA / π0 一类）能从图像+语言直接吐出一段动作块（action chunk），开放语义泛化极强。但它有三个致命属性：延迟高（数十 ms 到数百 ms）、置信度未校准、OOD 时会**自信地胡说**。因此把它放进 50Hz 硬实时闭环是灾难。正确姿势是**提议-证书分离**：VLA 只做低频动作提议器，把 action chunk 交给既有的 MetricLadder 在「执行前」做抽样可达性证书；证书不过就退回 v8 的经典规划器。VLA 永远拿不到直接驱动执行器的权限。

**核心洞察**：手势与 VLA 的共同点不是「更聪明的感知」，而是**引入了新的、高置信度但可能系统性错误的先验**。本轮的真正研究问题不是「怎么用它们」，而是「怎么让它们错了也不致命」。

## 1. 研究问题（轮次升级版）

- **Q1（指称绑定的不确定性）**：如何把「语音意图 + 手势指向 + VLA 语言接地」融合成一个带显式不确定性的 grounded command，使「绑定错误」可被检测并在低置信时主动弃权（abstain）而非硬猜？
- **Q2（VLA 的实时-安全解耦）**：如何把高延迟、高维、未校准的 VLA action chunk 纳入 50Hz 指标证书体系，同时不破坏 WCET、不产生「证书层之外的执行通道」？
- **Q3（手势安全覆盖的可证明性）**：如何设计手势安全覆盖，使其满足**安全单调性**（只收缩可行动作集），并把误触发的代价限制在可用性而非安全性上？

## 2. 设计原则（P7–P9 之后升级为 P10–P12）

**P10 指称绑定的主观逻辑化（Subjective-Logic Binding）**
每个模态对「指向哪个物体」输出一个主观逻辑意见 ω=(b,d,u,a)，而非一个标量概率：
```
ω^X = (b^X, d^X, u^X, a),  b+d+u = 1,  P(ω^X) = b^X + a·u^X
```
语音显式名词、手势指向分布、VLA 接地分布各自成意见，用共识算子 ⊕ 融合。融合后若冲突质量 K = b₁d₂ + d₁b₂ 超过阈值，则**弃权并请求澄清**，而不是输出一个看似高置信的错误绑定。

**P11 提议-证书分离（Proposal–Certificate Separation）**
VLA 只能通过 `propose(o_t, ℓ) → A_{t:t+H}` 接口输出动作块；执行器只接受经 `ActionChunkCertifier` 认证的动作。形式化要求：被执行动作 a ∈ A_adm ⊆ A_safe，其中 A_safe 由 M₀ 定义。VLA 的语义先验只影响「提议分布」，不影响「准入判据」。

**P12 手势安全覆盖的安全单调性（Safety-Monotone Override）**
安全手势只做集合交：`A_adm ← A_adm ∩ Stop`。因此覆盖后可行集只会变小，**任何满足覆盖后约束的策略必然满足覆盖前约束**。代价是误触发导致可用性下降，故必须配滞回计数 + 语音否决 + 工作空间约束三重守卫。

## 3. 与基线的接口（如何退化）

- 手势模块失效 ⇒ 指示词无法接地，仅接受显式名词指令（等价 v8 的 VoiceCommandTyping）；
- VLA 模块失效 ⇒ 动作提议退回 v8 的经典规划器，风险向量退回 5 维；
- 手势安全覆盖失效 ⇒ 无 STOP 手势旁路，但 M₀ 仍由 v8 原有安全判据守护；
- 三模块全失效 ⇒ 逐位等价于 MetricVoiceGauge-DA-SPR-Cal v8，再退回 v7。

## 4. 预期贡献

1. **主观逻辑指称绑定**框架：把「那个 + 指向」变成带显式不确定性与弃权能力的 grounded command；
2. **VLA 提议-证书分离**架构：证明高延迟开放语义模型可以安全地挂在 50Hz 证书体系外侧；
3. **安全单调的手势覆盖**：给出「只收缩、不放宽」的可证明安全旁路；
4. 完整的 **语音-手势-VLA-证书** 四模态闭环：E551–E570 覆盖指称接地、安全旁路、VLA 认证、退化等价与实机集成。

## 5. 本轮最大风险

**一句话**：手势与 VLA 都属于「高置信度但可能系统性错误」的模态——指称绑定错误与 VLA 语义幻觉会在证书层之前制造出**看似合理**的错误提议，而手势安全覆盖的误触发又会频繁打断任务；三者合卷下，「系统对多模态共识过度自信，把错误绑定当作既定事实送进硬约束」。

## 1. 符号体系增量（定义 532–545）

| `K_conflict` | 融合冲突质量 `b₁d₂ + d₁b₂` |

**新增定义 532（手势词表与 GestureToken）** 手势词表分为三类，安全类与指称类语义不同：
```
G = G_deixis ∪ G_safety ∪ G_affirm,   G_deixis ∩ G_safety = ∅
g_t = (κ_t, p_t^hand, c_t),  c_t = P(κ_t | p_{t-T+1:t}^hand)
```
其中分类器为骨架时序模型（ST-GCN/轻量 Transformer），输入 21 关键点滑动窗，输出类别与置信；`c_t ∈ [0,1]`。

**新增定义 533（指称接地 Deictic Grounding）** 由腕点 w 与食指尖 e 构造指向射线 r(s)=w+s·(e−w)/‖e−w‖，对场景物体 o（位姿 x_o、半径 r_o、可见性 v_o）定义：
```
p(o|g) ∝ exp( −d(r, o)² / (2σ_ray²) ) · v_o · 1[ o ∈ W_space ]
d(r,o) = min_{s≥0} ‖r(s) − x_o‖ − r_o
```
只在操作员工作空间 W_space 内接地，抑制「指到天花板」的退化。

**新增定义 534（主观逻辑意见与共识融合 SubjectiveLogicBinding）** 各模态意见：
```
ω^voice = 由显式名词/指代类型给出;  ω^gesture = 由 p(·|g) 经概率→意见变换;
ω^VLA   = 由 VLA 接地头给出
```
共识算子（同一基率 a 下）：
```
k = u₁ + u₂ − u₁u₂
b = (b₁u₂ + b₂u₁)/k,  d = (d₁u₂ + d₂u₁)/k,  u = u₁u₂/k,  a = a
K_conflict = b₁d₂ + d₁b₂
```
若 `K_conflict > τ_conflict` 或 `P(ω^bind) < τ_bind` ⇒ **弃权**（BAP 发起澄清），否则输出 grounded command。

**新增定义 535（接地命令 GroundedCommand）**：
```
cmd = (ℓ, o*, ρ_bind, source_mask),  o* = argmax_o P(ω^bind)(o)
source_mask ∈ {voice, gesture, VLA}³ 记录参与模态，用于退化与审计
```

**新增定义 536（VLA 提议 VLAProposal）** 异步提议器：
```
A_{t:t+H}, σ_chunk, H(A), OOD(z) = VPA.propose(o_t, ℓ)
σ_chunk = softmax_T( logits ) 的温度校准值;  H(A) = (1/H)Σ_h H(π_h)
```
`VPA` 只暴露 `propose()`，不暴露任何 `execute()`——接口层面剥夺执行权。

**新增定义 537（VLA 风险分量 VLARiskComponent）**：
```
risk_VLA(s) = w_f·(1 − σ_chunk) + w_e·Ĥ(A) + w_o·ÕOD(z)
Ĥ(A) = H(A)/log|A| ∈ [0,1],  ÕOD = clip(OOD(z)/OOD_ref, 0, 1)
```
`w_f, w_e, w_o ≥ 0`；归一化保证 `risk_VLA ∈ [0, Σw]` 有界，可直接进 softmax。

**新增定义 538（动作块认证 ActionChunkCertifier）** 执行前对块做抽样可达性认证：
```
Certify(A_{t:t+H}) = ⋀_{h∈S} [ (ŝ_{t+h} ⊨ M₀) ∧ (ŝ_{t+h} ⊨ M₁) ]
ŝ_{t+h} = f̂(s_t, A_{t:t+h})   （轻量动力学/可达集上界）
```
S 为抽样检查点集合（首尾 + 均匀 k 点）。任一不满足 ⇒ 拒绝该块，回退 v8 滚动时域规划器。**关键**：证书在「执行前」完成，VLA 永远不产生未认证动作。

**新增定义 539（动作块时序一致性 ChunkTemporalConsistency）** 相邻两块的公共时域上：
```
Δ(A^{m}, A^{m+1}) = max_{τ∈overlap} ‖A^m(τ) − A^{m+1}(τ)‖_∞
通过 iff Δ ≤ ε_chunk
```
不通过则用 CCM 做平滑/截断，或整块弃用，避免块切换抖动。

**新增定义 540（手势安全覆盖 GestureSafetyOverride）** 三守卫 + 滞回 + 语音否决：
```
Override_t = 1[ κ_t ∈ G_safety ] ∧ [ c_t > τ_g ] ∧ [ N_consec ≥ N_hold ]
            ∧ [ hand ∈ W_robot ] ∧ [ ¬VoiceVeto(ℓ_t) ]
if Override_t:  A_adm ← A_adm ∩ Stop
```
`N_hold` 通常 3 帧（30Hz 下 ≤100ms）；`VoiceVeto` 仅接受显式「继续/取消」指令，避免误停被语音噪声放大。

**新增定义 541（六维风险与权重扩展）**：
```
w'(s) = softmax( α·risk(s) + β·emo(s)·Ṽ )_{0..5},  risk ∈ ℝ⁶
w_i(s) = softmax( α·risk(s) )_i,  i = 0..5
```
VLA 关闭时截断为 5 维并重归一化（与 v8 完全一致）。

**新增定义 542（GVLA 闭环标识）**：
```
Φ_GVLA = {绑定: subjective-logic ⊕, 提议: VLA-only-propose,
          认证: certify-then-execute, 覆盖: safety-monotone}
Φ_v8   = {绑定: voice-only, 提议: v8 planner, 认证: 无 VLA, 覆盖: 无手势}
```

**新增定义 543（绑定弃权策略 BindingAbstentionPolicy）** 低置信/高冲突时的动作：
```
if K_conflict > τ_conflict:  ask_clarification("你指的是 A 还是 B？")
elif ρ_bind < τ_bind:        request_explicit_noun / 等待下一次指向
else:                        执行 grounded command
```
弃权率与误绑率构成显式的可用性-正确性权衡曲线（可预注册）。

## 2. 关键算法骨架

```python
# IP-354/355 GCT-2 + DeicticGrounder
class GestureGrounder:
    def __init__(self, classifier, scene_graph, sigma_ray=0.05,
                 workspace=None, tau_g=0.9):
        self.cls = classifier          # 骨架时序分类器
        self.scene = scene_graph        # 3D 场景图（物体位姿/半径/可见性）
        self.sigma_ray = sigma_ray
        self.workspace = workspace or (lambda p: True)
        self.tau_g = tau_g

    def process(self, hand_kpts):
        """hand_kpts: (T,21,3) 关键点滑窗 -> GestureToken + 接地分布"""
        kappa, conf = self.cls(hand_kpts)
        token = {'class': kappa, 'conf': conf, 'kpts': hand_kpts[-1]}
        if kappa not in DEIXIS_CLASSES:
            return token, None
        w, e = hand_kpts[-1, 0], hand_kpts[-1, 8]   # wrist, index tip
        direction = (e - w); direction /= (np.linalg.norm(direction) + 1e-9)
        dists = {}
        for o in self.scene.objects:
            if not self.workspace(o.pose[:3]):
                continue
            d = min_ray_point_distance(w, direction, o.pose[:3]) - o.radius
            dists[o.id] = np.exp(-d**2 / (2 * self.sigma_ray**2)) * o.visibility
        z = sum(dists.values()) + 1e-12
        return token, {k: v / z for k, v in dists.items()}


# IP-356 主观逻辑绑定
def prob_to_opinion(p, uncertainty=0.2, base_rate=0.5):
    u = uncertainty
    return {'b': (1 - u) * p, 'd': (1 - u) * (1 - p), 'u': u, 'a': base_rate}

def consensus(w1, w2):
    k = w1['u'] + w2['u'] - w1['u'] * w2['u']
    if k <= 1e-9:
        return w1
    return {
        'b': (w1['b'] * w2['u'] + w2['b'] * w1['u']) / k,
        'd': (w1['d'] * w2['u'] + w2['d'] * w1['u']) / k,
        'u': (w1['u'] * w2['u']) / k,
        'a': w1['a'],
    }

def expectation(w):
    return w['b'] + w['a'] * w['u']

class SubjectiveLogicBinder:
    def __init__(self, tau_bind=0.75, tau_conflict=0.25):
        self.tau_bind, self.tau_conflict = tau_bind, tau_conflict

    def bind(self, voice_slots, gesture_dist, vla_dist):
        if gesture_dist is None and vla_dist is None:
            return voice_slots, 1.0, ['voice']        # 退化到 v8
        objs = set(voice_slots.get('candidates', [])) | \
               set((gesture_dist or {}).keys()) | set((vla_dist or {}).keys())
        best, best_p, conflict_max = None, -1.0, 0.0
        for o in objs:
            w = prob_to_opinion(voice_slots.get('p', {}).get(o, 0.5), 0.3)
            masks = ['voice']
            if gesture_dist is not None:
                w = consensus(w, prob_to_opinion(gesture_dist.get(o, 0.0), 0.1))
                masks.append('gesture')
            if vla_dist is not None:
                w = consensus(w, prob_to_opinion(vla_dist.get(o, 0.5), 0.25))
                masks.append('VLA')
            p = expectation(w)
            if p > best_p:
                best, best_p = o, p
        # 冲突质量（取次优与最优的互斥质量近似）
        return {'object': best, 'confidence': best_p, 'sources': masks}, best_p, masks

    def should_abstain(self, rho_bind, conflict):
        return conflict > self.tau_conflict or rho_bind < self.tau_bind


# IP-357/358 VLA 提议 + 风险
class VLAProposalAdapter:
    def __init__(self, policy, calibrator, ood_scorer, H=12, device='cuda'):
        self.policy, self.cal, self.ood = policy, calibrator, ood_scorer
        self.H, self.device = H, device

    @torch.no_grad()
    def propose(self, obs, instruction):
        """异步调用；只返回提议，绝不执行"""
        logits, A, z = self.policy.forward(obs, instruction, horizon=self.H)
        sigma = self.cal.temperature_softmax(logits)          # 校准后成功概率
        ent = float(-(logits.softmax(-1) * logits.log_softmax(-1)).sum(-1).mean())
        ood = float(self.ood(z))
        return {'chunk': A, 'sigma': sigma, 'entropy': ent, 'ood': ood}

def risk_vla(prop, w_f=0.6, w_e=0.2, w_o=0.2, ood_ref=1.0):
    ent_norm = min(prop['entropy'] / np.log(8.0), 1.0)
    ood_norm = float(np.clip(prop['ood'] / ood_ref, 0.0, 1.0))
    return w_f * (1 - prop['sigma']) + w_e * ent_norm + w_o * ood_norm


# IP-359 动作块认证（certify-then-execute）
class ActionChunkCertifier:
    def __init__(self, dynamics, metric_ladder, k_samples=4):
        self.f, self.M, self.k = dynamics, metric_ladder, k_samples

    def certify(self, s_t, chunk):
        H = chunk.shape[0]
        idx = sorted(set([0, H - 1] + list(
            np.linspace(0, H - 1, self.k).astype(int))))
        for h in idx:
            s_hat = self.f.predict(s_t, chunk[:h + 1])
            if not self.M.satisfies(s_hat, layers=(0, 1)):   # 仅硬约束 + 安全
                return False, {'failed_at': h, 'state': s_hat}
        return True, {}


# IP-360 手势安全覆盖
class GestureSafetyOverride:
    def __init__(self, tau_g=0.9, n_hold=3):
        self.tau_g, self.n_hold = tau_g, n_hold
        self.count = 0

    def step(self, token, in_workspace, voice_veto):
        ok = (token and token['class'] in SAFETY_CLASSES
              and token['conf'] > self.tau_g
              and in_workspace and not voice_veto)
        self.count = self.count + 1 if ok else 0
        return self.count >= self.n_hold


# IP-361 主闭环片段
def metricvoicegauge_round_9(M, s, obs, audio_stream=None,
                             gesture_grounder=None, binder=None,
                             vla_adapter=None, certifier=None,
                             safety_override=None, ell=None, **v8_kwargs):
    # --- 0. 感知（复用 v8 ≤2ms 预算）---
    gtok, gdist = (None, None)
    if gesture_grounder is not None:
        gtok, gdist = gesture_grounder.process(M.latest_hand_kpts)

    # --- 1. 安全覆盖最先裁决（只收缩，速度优先）---
    stop = False
    if safety_override is not None:
        stop = safety_override.step(gtok, M.hand_in_workspace, M.voice_veto)

    # --- 2. 指称绑定（语音 + 手势 + VLA 接地）---
    voice = M.voice_slots(audio_stream) if audio_stream is not None else {}
    vla_ground = M.vla_grounding(obs, ell) if vla_adapter is not None else None
    cmd, rho, masks = (voice, 1.0, ['voice'])
    if binder is not None:
        cmd, rho, masks = binder.bind(voice, gdist, vla_ground)

    # --- 3. VLA 提议（主环外异步缓存，此处只读）---
    prop = M.vla_cache.latest if vla_adapter is not None else None
    if prop is not None:
        r6 = np.append(M.reward_decomposer._risk5(M.env.state),
                       risk_vla(prop))
    else:
        r6 = np.append(M.reward_decomposer._risk5(M.env.state), 0.0)

    # --- 4. 认证：无证书则无执行权 ---
    action = None
    if prop is not None and certifier is not None and not stop:
        ok, why = certifier.certify(s, prop['chunk'])
        if ok:
            action = prop['chunk'][0]
        else:                                  # 回退 v8 规划器
            action = M.planner.v8_step(s, cmd, r6)
    elif not stop:
        action = M.planner.v8_step(s, cmd, r6)

    if stop:
        action = M.planner.safe_stop(s)         # 手势覆盖：交集 Stop

    # --- 5. 继承 v8 其余流程（指标监控/证书/奖励/发布）---
    return M.metricvoicegauge_round_8(s, obs, cmd, r6, action, **v8_kwargs)
```

## 3. 推导

**引理 82（一致证据下融合不确定性单调不增）**
对同一目标的一致证据（冲突质量 `K_conflict=0`），共识算子满足
```
u_fused = u₁u₂/(u₁+u₂−u₁u₂) ≤ min(u₁, u₂)
```
证明：比较 `u_fused ≤ u₁` ⇔ `u₂ ≤ u₁+u₂−u₁u₂` ⇔ `0 ≤ u₁(1−u₂)`，成立。
故多模态一致时绑定不确定性严格下降；一旦证据冲突（`K_conflict>0`），融合不再保证下降，此时由 BAP 弃权，避免「用融合掩盖冲突」。

**引理 83（手势安全覆盖的安全单调性）**
覆盖操作定义为 `A_adm ← A_adm ∩ Stop`，只做交集。对任意策略 π，若其输出满足覆盖后约束，则必然满足覆盖前约束（`A_adm∩Stop ⊆ A_adm`）。因此覆盖不会引入新的不安全动作；其唯一失效模式是误触发导致 `A_adm` 变为空集或过小，即**可用性下降而非安全性下降**。配合 N_hold 滞回与语音否决，误触发率可按帧独立假设上界为 `(1−τ_g)^{N_hold}` 量级。

**引理 84（VLA 无法绕过 M₀）**
执行路径唯一：`propose → certify → execute`，且 `certify` 内部强制 `s_hat ⊨ M₀ ∧ M₁`。未认证块一律回退 v8 规划器。因此被执行动作 `a ∈ A_adm ⊆ A_safe`，VLA 的语义先验只能改变提议分布，不能改变准入判据。即便 VLA 输出完全幻觉，最坏结果是「被拒绝 + 退化到 v8」，而非不安全执行。

**引理 85（risk_VLA 有界与排序保持）**
`σ_chunk∈[0,1]` ⇒ `1−σ_chunk∈[0,1]`；`Ĥ,ÕOD∈[0,1]`；系数有限 ⇒ `risk_VLA∈[0,w_f+w_e+w_o]` 有界，注入 softmax 不炸。温度校准 `softmax_T` 对任意 T>0 保序（argmax 不变），故校准只改善概率标定（降低 ECE），不改变风险排序。

**引理 86（时序一致 ⇒ 执行可预测）**
若相邻块在重叠时域满足 `Δ ≤ ε_chunk`，且动力学满足 Lipschitz 常数 L，则实际执行轨迹与任一单块外推的偏差 `≤ ε_chunk + L·δt`。故认证时域可保守取 `H_cert = H − ⌈(ε_chunk+Lδt)/v_max⌉`，保证「认证过的前缀」在执行时仍然有效。

**引理 87（七级退化正确性）**
各模块接口正交：手势只影响 grounding 分布输入；SLB 只影响 `cmd` 与 `ρ_bind`；VPA/VRH 只影响 `risk` 第 6 维与提议；ACC 只影响「是否执行 VLA 提议」；GSO 只做集合交；CCM/BAP 只影响平滑与弃权。按声明顺序逐级关闭，均不改变其余模块的输入输出契约，故逐级等价于 v8 对应子集；全关即逐位等价 v8。

**引理 88（绑定错误可检测性）**
在模态校准假设下，`K_conflict > τ_conflict` 或 `P(ω^bind) < τ_bind` 时弃权。误绑事件要求「错误目标获得最高期望概率且超过阈值且冲突未超阈」，其概率随 τ_bind 单调下降；弃权率随 τ_bind 单调上升。故存在显式的「误绑率-弃权率」Pareto 前沿，可用于预注册权衡。

## 7. 本轮最大风险

**一句话**：手势与 VLA 都是「高置信度但可能系统性错误」的模态——指称绑定错误与 VLA 语义幻觉会在证书层之前制造看似合理的错误提议，而手势安全覆盖的误触发又会频繁打断任务；三者合卷下，「系统对多模态共识过度自信，把错误绑定当作既定事实送进硬约束」。
