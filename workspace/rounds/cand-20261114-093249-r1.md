# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS」IP-287~294；本轮灵感：「研究空白」×「实时控制」）

> R72 把 GAUGE 从「认知层」下沉为「具身层」：REG 实时执行图、IRL 意图、DMEM 灵巧接触、EREFLEX 三层反作用、S2R-UQ，回答「我的测量链在实时调度、意图模糊、灵巧接触下还能兑现风险界吗」。但 R72 的实时性是**静态的、以数据溯源为中心的**，留下了五个真研究空白：
> - **空白 1（溯源 ≠ 完备）**：`J_EMB` 只证明「数据从哪来」（TCHAIN）与「调度契约哈希匹配」，**不证明「消费该数据的那次计算是否算完」**。被 deadline 截断的粒子滤波、提前退出的 anytime 网络、只跑一半的优化器，其输出仍可携带完整 TCHAIN 与匹配的 REG 哈希——**证书「有效」，语义「残缺」**。
> - **空白 2（WCET 不可静态界定）**：`WCET(θ_nom)+L_T·u_real` 对**数据相关执行时间**（分支、早退、迭代次数、缓存、自适应粒子数）不成立；静态 RTA 的前提在「会学习的系统」上本身失效。
> - **空白 3（任务集不确定 + 事件触发）**：ERVOI 是事件触发，但经典可调度性理论假设**固定周期任务集 + 已知 WCET**；任务集随交互增长、自触发、变精度的系统没有现成 (m,K)/混合关键性可调度性保证。
> - **空白 4（计算与感知预算割裂）**：R72 只把计算当成本（WCET），没把它当**可分配的证据资源**——「多算一拍」与「多问一句」是同一枚硬币两面，却分属 DAES 与 ERVOI，无联合最优。
> - **空白 5（混合关键性模式颤振）**：R72 三域是「优先级分层」，不是**混合关键性 LO/HI**；模式切换的**颤振（thrashing）**会吃掉全部时间余量。
>
> 本轮核心命题：**不再只问「我的数据从哪来、调度契约匹配吗」，而问「在 deadline 到达的那一刻，我手上的这个结果，究竟是『算到哪、算到哪都可信』的哪个完备级别？」**
> 提出 **CERT-GAUGE-RAS**（**C**omputation-aware, **E**pistemic, **R**eal-**T**ime certified GAUGE）——**计算感知的实时计量审计闭环**：以 **AEO 渐进证据算子**、**TVD 时耦有效域**、**u_comp 计算陈旧不确定度**、**WHRT 弱硬实时契约**、**DAES 期限感知计量调度**、**EMCP 认知模式切换协议** 六大构件，填补「溯源–完备性缺口」。

## 0. 直觉与动机

**灵感 1（研究空白 → 真正的缺口在「证书的语义」，不在「算子的精度」）**
直觉：一篇实时控制论文最容易做的改进是「把 WCET 测得更准、把优先级排得更好」。但真正的空白是：**「数据可信」与「结果算完」是两件正交的事**。R72 的 `J_EMB` 把二者混为一谈——它审计了数据的来源链，却没有审计**计算本身的完备性**。设想一个被抢占的粒子滤波：重采样只做了一半，输出仍是「合法」的后验，TCHAIN 仍完整，因为数据确实来自合法传感器；但它的分布已经偏离了「算到底」的分布。**审源不审算，等于只验了食材没验火候。** 这是 relative-to-deadline 的语义空白，不是精度空白。

**灵感 2（实时控制 → 学习型组件的 WCET 是「数据相关」而非「参数相关」）**
直觉：R72 用 `WCET(θ_nom)+L_T·u_real` 把**参数不确定度**折进时序余量，这很漂亮，但只覆盖了「参数变」。真正的杀手是**输入变**：一个带早退的 Transformer、一个按残差自适应增减粒子数的滤波、一个迭代次数依赖条件数的优化器——同一组参数，输入不同，执行时间能差一个数量级。**对开放输入集，这种最坏执行时间不可判定。** 所以正确姿态不是「算一个更保守的 WCET」（那会逼死控制环），而是承认**「在任意时刻被切断，都必须给出一个此刻仍可证明的结果」**——这正是 anytime 算法的语义，把它从「优化技巧」升格为**实时正确性的定义**。

**灵感 3（计算即计量 → 预算分配就是证据质量分配）**
直觉：在 R72 里，「再算一拍估计」和「再问人一句」是两个互不相干的旋钮。但站在 deadline 前，它们是**同一种资源（实时预算）的两种花费**，换来的是**同一种货币（风险下降）**。于是问题变成：给定每拍预算 B，如何把「精化级别 j」分配给 BSE / IRL / DMEM / 规划，使**经认证的风险下降最大**？这正是**边际计算价值（Marginal Value of Computation, MVC）**。把「何时停」从 R72 的 VoI（值不值得问）扩展成 **VoC（值不值得算）**，二者共用同一个预算账本，才叫「实时控制」而不是「实时调度 + 控制」。

**灵感 4（三层反作用之外，还有「计算反作用」）**
直觉：R72 有三层反作用 ψ / z / c。本轮引入**第四层——计算反作用（computation reflexivity）**：**你算得越久，结果越可信，但 control 用的越旧**；你为省时间算得越浅，`u_comp` 越大，λ 越高，动作越保守，又反过来让你有更多时间算。这不是 bug，是一个**闭环**：`u_comp` 同时是「计算预算的函数」和「风险缩放的自变量」。把它显式建模，才不会出现「为了安全而算太多，反而超时用了最不安全的结果」的悖论。

**灵感 5（研究空白地图：把五个空白对应到六个构件）**

| 缺口 | 既有理论 | 缺什么 | 本轮构件 |
|---|---|---|---|
| G1 溯源–完备性缺口 | TCHAIN / 证书审计（R71–R72） | 计算完备性未被证书覆盖 | AEO 渐进链 + TVD 完备位 |
| G2 数据相关 WCET | 静态 RTA / WCET 分析 | 输入相关执行时间不可静态界定 | anytime + WHRT (m,K) |
| G3 动态任务集可调度性 | 固定任务集 RM/EDF | 事件触发/自触发的 (m,K) 保证 | WHRT 账本 + 运行时分位 RTA |
| G4 算 vs 问的统一预算 | VoI（R71）/ WCET | 计算与感知预算无联合优化 | DAES + MVC（VoC） |
| G5 模式颤振 | 混合关键性（Vestal） | 认知任务在 LO/HI 间的滞回切换 | EMCP 防颤振协议 |

## 1. 形式化定义（增量：定义 366–377）

**定义 366（CERT-GAUGE-RAS 总览）** CERT-GAUGE-RAS = (REG†, AEO, TVD, WHRT, DAES, EMCP, GAUGE-RAS‡)。六不变式：
(i) **计算完备性优先**：任何被消费的证据必须携带「达成级别 j」及其独立证书，`provenance ∧ completeness(j) ∧ age ≤ age_max(j)` 缺一不可；
(ii) **任意中断安全（anytime interrupt safety）**：渐进链的**任意前缀**都是合法证据，中断点即交付点；
(iii) **弱硬实时契约**：控制任务满足 (m,K)-firm（任意 K 个周期内 miss ≤ m）并带 LO/HI 关键性模式；
(iv) **计算陈旧入险**：`u_comp` 作为独立不确定度分量进入 λ_floor 与认证前缀；
(v) **模式无颤振**：EMCP 带滞回与驻留时间，任意窗口内模式切换次数有界；
(vi) **严格退化链**：CERT 在固定 j=J 时逐指令退化为 EMBODIED，再退化为 R71、R68。

**定义 367（渐进证据算子 AEO）** AEO: (x, budget) → 链 `⟨E^(0), E^(1), …, E^(J)⟩`。每一级 `E^(j)` 独立携带 R71 六元组 `(φ, m, u^(j), D^(j), τ, I⊥)` **加** 计算元数据 `(j, spend_j, wcet_bound_j, complete_j, h_j)`，并满足：
- **认证单调性（A111）**：`u^(0) ≥ u^(1) ≥ … ≥ u^(J)`，且每级证书独立可验；
- **前缀合法性**：对任意 `j' < J`，`E^(j')` 在该级有效域 `D^(j')` 内是**有效证据**；
- **非单调算子必须包络**：若原始 anytime 算子不满足 A111，则用**下界包络** `ū^(j) = min_{k≥j} u_raw^(k)` 重写，否则拒绝进链。
`J=1` 时 AEO 退化为 R72 的原子证据。

**定义 368（时耦有效域 TVD）** 有效域加时间维：`D_t = D_spatial × D_temporal`，`D_temporal = [t − age_max(j), t]`。证据 `E^(j)` **可被消费**当且仅当
`prov_valid(E) ∧ complete_j ∧ (age = now − t_E) ≤ age_max(j)`。
定义**时间余量** `μ_t = age_max(j) − age`；`μ_t < 0` 即「时间上失效」，其严重度**高于**空间失效（因为空间失效可查询，时间失效不可追回）。

**定义 369（计算陈旧不确定度 u_comp）**
`u_comp² = u_level² + u_age² + u_var²`，其中
- `u_level(j) ≥ sup_{x∈D^(j)} ‖b^(j)(x) − b^(J)(x)‖`（截断偏差上界，由区间算术 / 神经网络验证器 CROWN/IBP 或收缩率 `Lρ^{J−j}` 给出）；
- `u_age` 为 `age` 窗口内后验漂移上界（由动力学 Lipschitz 给出）；
- `u_var` 为**时间维不确定度**：执行时间分布的尾部导致「本该到 j* 却只到 j」的概率加权损失（EVT 极值 / 分布鲁棒 DRO 上界）。
`u_comp` 与 R72 的 `U_ale, U_epi, H[b(z)], u_tac` **同权**进入风险分母。

**定义 370（弱硬实时控制契约 WHRT）** 控制任务 τ_c 带**双重契约**：
- **(m,K)-firm**：任意连续 K 周期内 deadline miss ≤ m（`m/K` 为允许的 miss 率）；
- **混合关键性 LO/HI**：`WCET_c^LO ≤ WCET_c^HI`，LO 模式用乐观界、HI 模式用悲观界；模式由 EMCP 驱动。
- **可调度性**：离线用响应时间分析 + 典型最坏情况分析（TWCA, p=0.999）联合验证；在线维护 **WHRT 账本**（滑窗 miss 计数）。
性质：只要账本未越界，`age` 的累积被 (m,K) 限住（见引理 37），从而 `u_age` 有界。

**定义 371（期限感知计量调度 DAES）** 每计量周期解一个**预算化风险下降**问题：
`max_{j_1..j_T} Σ_i ΔR_i(j_i; b_t)  s.t.  Σ_i cost_i(j_i) ≤ B,  WHRT 账本可行,  j_i ∈ {0..J_i}`
其中 `ΔR_i(j)` 是模块 i 从级别 `j−1` 精化到 `j` 带来的**经认证风险下降**。定义**边际计算价值** `MVC_i(j) = ΔR_i(j) / Δt_i(j)`。
- 在 **A114（风险下降对 j 次模 / 递减回报）** 下，按 MVC 降序的**前缀约束贪婪**达到 `(1−1/e)` 近似；
- 若不满足 A114，退化为**带证书的分支定界**（预算小、T·J 小可承受）。

**定义 372（计算感知风险缩放）**
`λ = max( risk_scale(U_ale, U_epi, H[b(z)], u_tac, u_comp),
          λ_floor(U_ale + U_epi + H[b(z)] + u_tac + u_comp.total()) )`。
关键：`u_comp` 同时是**预算的函数**（算得浅→大）与 **λ 的自变量**（大→软化→省时间），构成**计算反作用闭环**（第 L4 层反作用）。

**定义 373（认知模式切换协议 EMCP）** 状态机 LO/HI：
- LO→HI：`risk > enter_hi`（立即，安全侧）；
- HI→LO：仅当 `risk < exit_lo` 且**持续驻留** `≥ H` 且 `H ≥ K·period`；
- 单调关键性：HI 模式下**只允许升关键性、不允许降任务**。
性质：滞回 `enter_hi > exit_lo` + 驻留 `H` ⇒ 任意窗口 `W` 内切换次数 `≤ ⌊W/H⌋ + 1`，无 Zeno / 无颤振（引理 36）。

**定义 374（分离命题：溯源–完备性缺口）** 称系统存在**溯源–完备性缺口**，若存在一次执行使 `Valid(J_EMB)` 成立（TCHAIN 完整、REG 哈希匹配、E-IVG 全过），但被消费证据的截断偏差 `> ε_emb`，从而使实际风险界被击穿。**定理 27 证明该缺口在数据相关计算下必然存在**，且仅靠 R72 的溯源证书不可闭合。

**定义 375（CERT 证书 J_CERT）**
`J_CERT = (J_EMB, anytime_chain_hashes, completeness_vector, u_comp, whrt_ledger, mode_trace, dynamic_rta_proof, mvc_ledger, cert_ver)`。
`Valid(J_CERT) ⇔ Valid(J_EMB) ∧ 每条链哈希匹配 ∧ completeness_vector 与消费位一致 ∧ u_comp 已传播至 λ_floor ∧ (m,K) 账本未越界 ∧ EMCP 轨迹合法 ∧ 动态 RTA 证明有效`。

**定义 376（威胁模型 AIC-CERT）** `ℰ_CERT = ℰ_EMB × ℰ_time × ℰ_comp`：
- `ℰ_time = {deadline 攻击（用难输入诱导集中 miss）、时间侧信道、TWCA 分位投毒、模式颤振诱导}`；
- `ℰ_comp = {渐进链伪装（早级看起来收紧实则收敛到错模式）、完备位伪造、精化饥饿（DAES 永久剥夺关键任务）、非单调算子注入、u_level 上界投毒}`。

**定义 377（严格退化包含链）**
- 固定 `J=1`（原子证据）⇒ **EMBODIED（R72）**；
- 再关闭 REG† 动态部分、固定先验意图 ⇒ **R71**；
- 全失效 ⇒ **R68**。
且 `risk_CERT ≤ risk_EMBODIED ≤ risk_R71 ≤ risk_R68`（同有效域下，安全侧只增不减）。

```python
# IP-295 AEO：渐进证据算子（每级独立可证；非单调必须包络）
class AnytimeEvidenceOperator:
    def __init__(self, refiners, verifier):
        self.refiners, self.verifier = refiners, verifier
    def run(self, x, budget):
        E, chain, j = self.refiners[0](x), [], 0
        while True:
            cert = self.verifier.certify(E, level=j, spend=budget.spent())   # 六元组+计算元数据
            chain.append(CertifiedLevel(j, E, cert))
            if j == budget.max_level or budget.exhausted(): break
            if not budget.allow_next(self.wcet_bound(j + 1)): break          # 保守级间 WCET 界
            E = self.refiners[j + 1](E); j += 1
        chain = monotone_envelope(chain)     # A111 不满足 -> 下界包络 ū^(j)=min_{k≥j} u_raw^(k)
        return AnytimeEvidence(chain=chain, achieved=j, ts=now())            # 任意前缀合法

# IP-296/297 TVD + u_comp：时间维准入与计算陈旧不确定度
def tvd_admit(ev, now, age_max_fn):
    j   = ev.achieved
    age = now - ev.ts
    ok  = ev.chain[j].cert.valid and age <= age_max_fn(j)      # provenance ∧ completeness ∧ age
    mu_t = age_max_fn(j) - age                                 # 时间余量
    u_level = ev.chain[j].cert.truncation_bound                # CROWN/IBP 或 Lρ^{J-j}
    u_age   = drift_bound(age)                                 # 动力学 Lipschitz
    u_var   = timing_loss_tail(ev.chain[j].meta)               # EVT/DRO 尾部截断损失
    return ok, mu_t, sqrt(u_level**2 + u_age**2 + u_var**2)

# IP-298 WHRT：弱硬实时契约（离线验证）+ 在线账本
def whrt_offline_check(tasks, m, K, wcet_lo, wcet_hi):
    return (rta_with_mk(tasks, m, K)                          # (m,K)-firm 响应时间
            and twca(tasks, p=0.999)                          # 典型最坏情况
            and all(wcet_lo[t] <= wcet_hi[t] for t in tasks))

# IP-299/300 DAES + MVC：把计算预算当证据资源分配（前缀约束贪婪）
def daes_allocate(tasks, budget, risk_state):
    alloc = {i: 0 for i in tasks}
    heap  = [(-mvc(i, 1, risk_state), i, 1) for i in tasks]; heapify(heap)
    spent = 0
    while heap:
        negv, i, j = heappop(heap)
        c = cost(i, j)
        if -negv <= 0 or spent + c > budget: break            # 无正收益或超预算
        if not whrt_mk_ok(alloc, i, j): continue              # 保持 (m,K) 可行
        alloc[i] = j; spent += c
        if j < max_level(i):
            heappush(heap, (-mvc(i, j + 1, risk_state), i, j + 1))
    return alloc, spent                                       # A114 次模 => (1-1/e)

# IP-301 EMCP：混合关键性模式切换（滞回 + 驻留 + 单调关键性）
class EpistemicModeController:
    def __init__(self, enter_hi, exit_lo, hold):
        self.enter_hi, self.exit_lo, self.hold = enter_hi, exit_lo, hold
        self.mode, self.low_since = 'LO', None
    def step(self, risk, t):
        if self.mode == 'LO' and risk > self.enter_hi:
            self.mode, self.low_since = 'HI', None             # 立即升关键性（安全侧）
        elif self.mode == 'HI':
            if risk < self.exit_lo:
                if self.low_since is None: self.low_since = t
                elif t - self.low_since >= self.hold: self.mode = 'LO'
            else: self.low_since = None
        return self.mode

    # === 感知域（Best-effort；低级别证据即可用）===
    psi, ev_a = M.aura.anytime(audio, budget=M.percept_budget)
    tac_ev    = M.dmem.anytime(tac,   budget=M.percept_budget)
    M.mode    = M.emcp.step(M.risk.current(), M.clock.now())
    return k, lam, make_J_CERT(M)
```

## 3. 推导

**引理 33（任意中断安全）** 设 AEO 满足 A111 认证单调性与前缀合法性。则对任意抢占点 `j`，`E^(j)` 是有效证据且其界 `u^(j) ≥ u^(J)`。证明：链构造保证每级独立证书；单调性保证前缀不比终级更紧。系：**R72 的原子证据只是 `J=1` 的退化链；anytime 不是优化，是实时正确性的定义。**

**引理 34（u_comp 上界截断偏差）** 在 A112（截断偏差可被区间包络/收缩率界定）下，用级别 `j` 与终级 `J` 的后验偏差满足 `‖b^(j) − b^(J)‖ ≤ u_level(j)`；叠加年龄漂移 `≤ u_age`、时间尾损失 `≥ u_var`，得总陈旧偏差 `≤ u_comp`。系：**忽略 u_comp ⇒ 当 `j ≪ J` 时风险被系统性低估，且这种低估在 TCHAIN 上完全不可见**——正是定义 374 的缺口。

**引理 35（DAES 的近似比与 WHRT 保持）** 在 A114（风险下降对级别次模）与 A115（零精化时 WHRT 可行）下，DAES 的前缀约束贪婪取得 `≥ (1−1/e)` 的最优风险下降，且每个被接受的分配都保持 (m,K) 可行。证明：预算化次模最大化 + `whrt_mk_ok` 作为不变量维持。系：**「算出更安全的结果」这件事本身有可证明的性价比上界，不是调参。**

**引理 36（EMCP 无颤振）** 滞回 `enter_hi > exit_lo` 加驻留 `H`，任意长度 `W` 的窗口内模式切换次数 `≤ ⌊W/H⌋ + 1`，故无 Zeno、无颤振。证明：两次 LO→HI 之间必经历完整驻留。系：**混合关键性最臭名昭著的模式颤振，在认知任务上被驻留时间消掉。**

**引理 37（WHRT ⇒ 累积陈旧有界）** 若 (m,K)-firm 成立，则任 K 窗口内至多 `m` 次 miss，每次 miss 至多使 `age` 增加一个 `period`，故 `age` 的累积上界为 `m·period`，进而 `u_age` 有界。系：**弱硬实时不是「放松安全」，而是「把 miss 预算换成可证明的陈旧上界」——比假装硬实时更诚实。**

**定理 27（分离定理：溯源–完备性缺口不可由溯源证书闭合）** 存在系统与对手，使 `Valid(J_EMB)` 成立而消费证据的截断偏差 `> ε_emb`，风险界被击穿。构造：取任一非退化 anytime 估计器（如自适应粒子滤波）；对手输入保持 (i) 数据源合法（TCHAIN 不变）、(ii) 各级空间指标 `∈ D^(j)`、(iii) 强制早抢占，则 `J_EMB` 无法区分「算到 J」与「算到 j」。∎ 系：**必须把 `completeness`、`TVD`、`u_comp` 提升为证书一等公民（定义 375），否则 R72 会「盖章通过」一次语义残缺的执行。**

**定理 28（严格包含与风险单调）** 在 A111–A116 下，CERT 在 `J=1` 时逐指令等于 EMBODIED（定义 377），再退化为 R71、R68；且对任意有效执行，`risk_CERT ≤ risk_EMBODIED`。证明：λ 只多了一个非负项 `u_comp`，认证前缀的可行集只收窄不扩张。**安全侧只增不减，效率只在「算得完、算得对、算得及时」时获益。**

**定理 29（J_CERT 有效 ⇒ 风险界 + 弱硬实时保证）** 若 `Valid(J_CERT)`，则：(i) 每条被消费证据满足 `provenance ∧ completeness ∧ age`（TVD）；(ii) WHRT 账本显示任意 K 窗口 miss `≤ m`，模式轨迹满足 EMCP；(iii) `u_comp` 已传播到 λ_floor 与认证前缀；(iv) `J_EMB` 有效。综合得控制风险 `≤ ε_cert`，且 deadline miss 率 `≤ m/K`。**证明的重量全部压在「AEO 链真被验证过」「u_comp 真上界了偏差」「模式轨迹未被伪造」上。**

**定理 30（DAES 相对计算最优的差距有界）** 在 A114/A115 下，DAES 的风险下降 `≥ (1−1/e)·OPT_compute`，从而相对均匀分配把 `ε_cert` 至少改善同一比例。**证明依赖 A114；次模性是必须实测验证的假设，不是公理（见 E373）。**

## 6. 本轮最大风险

**一句话**：CERT-GAUGE-RAS 把安全从「相信溯源证书」转移到「相信 **anytime 链的认证单调性在分布外仍成立**、相信 **u_comp 真的上界了截断偏差与时间重尾**、相信 **DAES 的精化分配没有饿死那个真正关键的任务**」——**如果某个神经 anytime 算子只是「看起来单调」（各级下界收紧，却一致收敛到错误模式），或者执行时间的重尾超出 EVT/DRO 的覆盖，或者 (m,K) 的 miss 恰好集中在最难输入上导致 `age` 与 `u_level` 同时失控，那么系统会拿着一份「溯源齐全、完备级别达标、弱硬实时账本全绿、模式无颤振」的 `J_CERT`，在真机上语义错误地动作，而事后审计发现「所有完备位当时都为真、所有账本当时都没越界」——这是比 R72 更隐蔽的「自信地错自己的可执行性」，因为它错在「计算已完备」这个最不该被怀疑的地方。**

次级风险与缓解：
1. **渐进链伪装 / 非单调** → 强制**下界包络 + 终级交叉校验**（E367/E386）；链哈希进 J_CERT，篡改即断链降级。
2. **u_comp 低估（重尾/多峰）** → **EVT + DRO 双上界取最大**，分位数 99.9%，部署前注入极端负载压测（E368/E387）。
3. **DAES 精化饥饿** → 每任务设**公平下限 j_min**（关键安全任务不可被剥夺），并把「最低完备级别」写入 WHRT 约束（E372）。
4. **miss 集中化攻击** → (m,K) 账本 + **滑窗抖动监控**，miss 的空间聚集度超阈即触发 HI 模式并冻结攻击面。
5. **模式颤振** → EMCP 滞回 + 驻留 `H≥K·period`；A/B 实测切换次数（E371）。
6. **次模性不成立** → 违例任务退化为带证书分支定界（E373/E374）。
7. **复杂度爆炸** → 模块上限 `|tasks|≤12, J≤8, |Z|≤8, |C|≤5`，DAES 只在计量域运行，控制域只读 O(1) 快照。

---

**当前方案最大风险一句话**：真正的危险不是算不完，而是系统会**误以为「算完了」**——`J_CERT` 里的完备位与弱硬实时账本全绿，却掩盖了「收敛到错模式、尾部分布未覆盖、关键任务被饿死」的语义失败。

## 2. 形式化定义（要点版）

**定义 366（CERT-GAUGE-RAS 总览与六不变式）** 见想法区。核心：计算完备性优先、任意中断安全、弱硬实时契约、计算陈旧入险、模式无颤振、严格退化链。

**定义 367（AEO 渐进证据算子）** 每级 `E^(j)` 独立携带 R71 六元组 + `(j, spend_j, wcet_bound_j, complete_j, h_j)`；A111 认证单调性 `u^(0)≥…≥u^(J)`；非单调算子用下界包络 `ū^(j)=min_{k≥j}u_raw^(k)`；`J=1` 退化为 R72 原子证据。**中断点即交付点。**

**定义 369（u_comp）** `u_comp²=u_level²+u_age²+u_var²`；`u_level` 由区间算术/神经网络验证器（CROWN/IBP）或收缩率 `Lρ^{J−j}` 给出；`u_age` 由动力学 Lipschitz；`u_var` 由 EVT/DRO 时间尾。**与 U_ale/U_epi/H_z/u_tac 同权进 λ 分母。**

**定义 370（WHRT）** (m,K)-firm + LO/HI；离线 RTA+TWCA(p=0.999)，在线滑窗 miss 账本。**弱硬实时 ⇒ 累积陈旧有界（引理 37）。**

**定义 371（DAES）** `max Σ ΔR_i(j_i) s.t. Σcost≤B, WHRT 可行, j_i∈{0..J_i}`。A114 次模 ⇒ 前缀贪婪 (1−1/e)；否则带证书分支定界。**计算预算即证据资源。**

**定义 372（计算感知风险缩放）** `λ=max(risk_scale(U_ale,U_epi,H_z,u_tac,u_comp), λ_floor(…+u_comp))`。`u_comp` 既是预算函数又是 λ 自变量 ⇒ **L4 计算反作用闭环**。

**定义 373（EMCP）** LO→HI 立即（安全侧）；HI→LO 需 `risk<exit_lo` 且驻留 `≥H≥K·period`；HI 下只升不降关键性。**任意窗口切换 ≤⌊W/H⌋+1，无颤振。**

**定义 374（分离命题：溯源–完备性缺口）** 存在执行使 `Valid(J_EMB)` 而截断偏差 `>ε_emb`。定理 27 证明其必然存在且溯源证书不可闭合。

**定义 375（J_CERT）** `Valid ⇔ J_EMB 有效 ∧ 链哈希匹配 ∧ 完备位与消费一致 ∧ u_comp 已入 λ_floor ∧ (m,K) 未越界 ∧ EMCP 轨迹合法 ∧ 动态 RTA 有效`。

**定义 376（AIC-CERT 威胁模型）** `ℰ_time={deadline 攻击、时间侧信道、TWCA 分位投毒、颤振诱导}`；`ℰ_comp={渐进链伪装、完备位伪造、精化饥饿、非单调算子注入、u_level 上界投毒}`。

**定义 377（严格退化包含链）** `J=1 ⇒ EMBODIED ⇒ R71 ⇒ R68`；`risk_CERT ≤ risk_EMBODIED ≤ risk_R71 ≤ risk_R68`。

```python
# IP-295 AEO：渐进证据算子（每级独立可证；非单调必须包络）
class AnytimeEvidenceOperator:
    def __init__(self, refiners, verifier):
        self.refiners, self.verifier = refiners, verifier
    def run(self, x, budget):
        E, chain, j = self.refiners[0](x), [], 0
        while True:
            cert = self.verifier.certify(E, level=j, spend=budget.spent())   # 六元组+计算元数据
            chain.append(CertifiedLevel(j, E, cert))
            if j == budget.max_level or budget.exhausted(): break
            if not budget.allow_next(self.wcet_bound(j + 1)): break          # 保守级间 WCET 界
            E = self.refiners[j + 1](E); j += 1
        chain = monotone_envelope(chain)     # A111 不满足 -> 下界包络 ū^(j)=min_{k≥j} u_raw^(k)
        return AnytimeEvidence(chain=chain, achieved=j, ts=now())            # 任意前缀合法

# IP-296/297 TVD + u_comp：时间维准入与计算陈旧不确定度
def tvd_admit(ev, now, age_max_fn):
    j   = ev.achieved
    age = now - ev.ts
    ok  = ev.chain[j].cert.valid and age <= age_max_fn(j)      # provenance ∧ completeness ∧ age
    mu_t = age_max_fn(j) - age                                 # 时间余量
    u_level = ev.chain[j].cert.truncation_bound                # CROWN/IBP 或 Lρ^{J-j}
    u_age   = drift_bound(age)                                 # 动力学 Lipschitz
    u_var   = timing_loss_tail(ev.chain[j].meta)               # EVT/DRO 尾部截断损失
    return ok, mu_t, math.sqrt(u_level**2 + u_age**2 + u_var**2)

# IP-298 WHRT：弱硬实时契约（离线验证）+ 在线账本
def whrt_offline_check(tasks, m, K, wcet_lo, wcet_hi):
    return (rta_with_mk(tasks, m, K)                          # (m,K)-firm 响应时间
            and twca(tasks, p=0.999)                          # 典型最坏情况分析
            and all(wcet_lo[t] <= wcet_hi[t] for t in tasks)) # LO/HI 单调

class WHRTLedger:
    def __init__(self, m, K):
        self.m, self.K, self.hist = m, K, deque(maxlen=K)
    def record(self, met: bool):
        self.hist.append(0 if met else 1)
        return sum(self.hist) <= self.m                     # false => 触发 HI / 降级
    def stale_bound(self, period): return self.m * period   # 引理 37

# IP-299/300 DAES + MVC：把计算预算当证据资源分配（前缀约束贪婪）
def mvc(i, j, risk_state):
    return risk_state.delta_R(i, j) / max(risk_state.delta_t(i, j), EPS)

def daes_allocate(tasks, budget, risk_state, whrt):
    alloc = {i: 0 for i in tasks}
    heap  = [(-mvc(i, 1, risk_state), i, 1) for i in tasks]; heapify(heap)
    spent = 0
    while heap:
        negv, i, j = heappop(heap)
        c = risk_state.delta_t(i, j)
        if -negv <= 0 or spent + c > budget: break            # 无正收益或超预算
        if not whrt.mk_ok(alloc, i, j): continue              # 保持 (m,K) 可行
        alloc[i] = j; spent += c
        if j < max_level(i):
            heappush(heap, (-mvc(i, j + 1, risk_state), i, j + 1))
    return alloc, spent                                       # A114 次模 => (1-1/e)

# IP-301 EMCP：混合关键性模式切换（滞回 + 驻留 + 单调关键性）
class EpistemicModeController:
    def __init__(self, enter_hi, exit_lo, hold):
        self.enter_hi, self.exit_lo, self.hold = enter_hi, exit_lo, hold
        self.mode, self.low_since, self.trace = 'LO', None, []
    def step(self, risk, t):
        if self.mode == 'LO' and risk > self.enter_hi:
            self.mode, self.low_since = 'HI', None             # 立即升关键性（安全侧）
        elif self.mode == 'HI':
            if risk < self.exit_lo:
                if self.low_since is None: self.low_since = t
                elif t - self.low_since >= self.hold: self.mode = 'LO'
            else: self.low_since = None
        self.trace.append((t, self.mode)); return self.mode

# IP-302/303 J_CERT + CERT 主闭环（控制域只读；任何截断都交出一个合法前缀）
def make_J_CERT(M):
    return Cert(J_EMB=M.j_emb,
                anytime_chain=[h(ev.chain) for ev in M.evidence],
                completeness=M.achieved_vector,               # 每条证据实际级别 j
                u_comp=M.u_comp, whrt_ledger=M.whrt.ledger,
                mode_trace=M.emcp.trace, dynamic_rta=M.rta_dyn.proof,
                mvc_ledger=M.daes.ledger, ver=CERT_VER)

def CERT_GAUGE_round(M, obs, audio, tac):
    # ========== 控制域（硬实时，只读时耦快照）==========
    snap = M.snapshot.read_latest()
    ok, mu_t, u_comp = tvd_admit(snap.evidence, M.clock.now(), M.age_max)
    if not ok:
        M.mode = M.emcp.step(risk=INF, t=M.clock.now()); lam = M.risk.lam_floor_max()
    else:
        lam = computation_aware_risk(snap, u_comp)            # u_comp 入 λ_floor
    A = M.ach.propose_ctrl(...)
    k = M.certified_prefix(A, lam, mu_t, snap.level)          # 认证前缀依赖「已达级别」
    M.ctrl_out.publish(k, lam)
    if not M.whrt.record(deadline_met=M.clock.met()):         # (m,K) 账本越界
        M.mode = 'HI'; M.risk.escalate()
    # ========== 计量域（软实时，可抢占；DAES 分配下一拍）==========
    if M.clock.due_metric():
        alloc, spent = M.daes.allocate(M.tasks, M.budget(), M.risk_state(snap), M.whrt)
        for i, j in alloc.items(): M.modules[i].refine_to(j) # 前缀精化，可随时中断
        M.snapshot.write(M.collect(), M.u_comp(), M.emcp.mode)
    # ========== 感知域（Best-effort；低级别证据即可用）==========
    psi, ev_a = M.aura.anytime(audio, budget=M.percept_budget)
    tac_ev    = M.dmem.anytime(tac,   budget=M.percept_budget)
    M.mode    = M.emcp.step(M.risk.current(), M.clock.now())
    return k, lam, make_J_CERT(M)
```

## 4. 推导

**引理 33（任意中断安全）** AEO 满足 A111 与前缀合法性 ⇒ 任意抢占点 `j` 的 `E^(j)` 是有效证据且 `u^(j)≥u^(J)`。系：**R72 原子证据只是 `J=1` 的退化链；anytime 是实时正确性的定义，不是优化。**

**引理 34（u_comp 上界截断偏差）** A112 下 `‖b^(j)−b^(J)‖≤u_level(j)`；叠加 `u_age`、`u_var` 得总陈旧偏差 `≤u_comp`。系：**忽略 u_comp 时，`j≪J` 的风险低估在 TCHAIN 上完全不可见。**

**引理 35（DAES 近似比与 WHRT 保持）** A114/A115 下，前缀贪婪取得 `≥(1−1/e)` 最优风险下降，且每次接受分配保持 (m,K) 可行。

**引理 36（EMCP 无颤振）** 滞回 + 驻留 `H` ⇒ 任意 `W` 内切换 `≤⌊W/H⌋+1`，无 Zeno。

**引理 37（WHRT ⇒ 累积陈旧有界）** (m,K) 成立 ⇒ 任 K 窗口 `age` 累积 `≤m·period`，`u_age` 有界。系：**弱硬实时把 miss 预算换成可证明的陈旧上界，比假装硬实时更诚实。**

**定理 27（分离定理）** 存在系统与对手使 `Valid(J_EMB)` 成立而截断偏差 `>ε_emb`，风险界被击穿。构造取非退化 anytime 估计器 + 合法数据源 + 空间指标在域内 + 强制早抢占。∎ 系：**completeness/TVD/u_comp 必须是证书一等公民，否则 R72 会盖章通过语义残缺的执行。**

**定理 28（严格包含与风险单调）** `J=1` 时 CERT 逐指令等于 EMBODIED，再退化为 R71、R68；`risk_CERT≤risk_EMBODIED`。证明：λ 只多非负 `u_comp`，认证前缀可行集只收窄。

**定理 29（J_CERT 有效 ⇒ 风险界 + 弱硬实时保证）** `Valid(J_CERT)` ⇒ TVD 全过、`(m,K)` 未越界、EMCP 轨迹合法、`u_comp` 已进 λ、`J_EMB` 有效 ⇒ 控制风险 `≤ε_cert` 且 miss 率 `≤m/K`。**重量在「链被真验证」「u_comp 真上界」「轨迹未伪造」。**

**定理 30（DAES 相对计算最优差距有界）** A114/A115 下 DAES 风险下降 `≥(1−1/e)·OPT_compute`，相对均匀分配把 `ε_cert` 至少改善同比例。**依赖 A114，必须实测（E373）。**

## 7. 本轮最大风险

**一句话**：CERT-GAUGE-RAS 把安全从「相信溯源证书」转移到「相信 **anytime 链的认证单调性在分布外仍成立**、相信 **u_comp 真的上界了截断偏差与时间重尾**、相信 **DAES 的精化分配没有饿死那个真正关键的任务**」——**如果某个神经 anytime 算子只是「看起来单调」（各级下界收紧，却一致收敛到错误模式），或者执行时间的重尾超出 EVT/DRO 的覆盖，或者 (m,K) 的 miss 恰好集中在最难输入上导致 `age` 与 `u_level` 同时失控，那么系统会拿着一份「溯源齐全、完备级别达标、弱硬实时账本全绿、模式无颤振」的 `J_CERT`，在真机上语义错误地动作，而事后审计发现「所有完备位当时都为真、所有账本当时都没越界」——这是比 R72 更隐蔽的「自信地错自己的可执行性」，因为它错在「计算已完备」这个最不该被怀疑的地方。**

次级风险与缓解：
1. **渐进链伪装 / 非单调** → 下界包络 + 终级交叉校验（E367/E386）；链哈希进 J_CERT，篡改即断链降级。
2. **u_comp 低估（重尾/多峰）** → EVT + DRO 双上界取最大，分位数 99.9%，部署前极端负载压测（E368/E387）。
3. **DAES 精化饥饿** → 每任务公平下限 `j_min`，关键安全任务不可被剥夺，最低完备级别写入 WHRT（E372）。
4. **miss 集中化攻击** → (m,K) 账本 + 滑窗抖动监控，miss 空间聚集度超阈即触发 HI 并冻结攻击面（E369）。
5. **模式颤振** → EMCP 滞回 + 驻留 `H≥K·period`，A/B 实测切换次数（E371）。
6. **次模性不成立** → 违例任务退化为带证书分支定界（E373/E374）。
7. **复杂度爆炸** → `|tasks|≤12, J≤8, |Z|≤8, |C|≤5`；DAES 只在计量域，控制域只读 O(1) 快照。

---

**当前方案最大风险一句话**：真正的危险不是算不完，而是系统会**误以为「算完了」**——`J_CERT` 的完备位与弱硬实时账本全绿，却掩盖「收敛到错模式、尾部分布未覆盖、关键任务被饿死」的语义失败。
