# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；新灵感循环第 1 轮；本轮灵感：「抓取规划」×「具身智能大模型」）

> 第 54 轮解决的是“技能在动作空间里能不能拼、云端计划的动作边端接不接得住”。本轮把镜头推到动作空间最稠密、最物理的一小块——**抓取**。核心矛盾：H22：具身大模型（VLA）给出的是**语义可抓**（语言/可供性条件下合理的 6D 抓取分布），而部署成功取决于**物理可抓**（接触力封闭裕度）；两者存在系统性错位，语义越自信，越可能落在力封闭盲区。H23：抓取规划不是选一个抓取，而是选一条**接触模式转移序列**；单帧抓取证书在“松手换姿”时会失效。

## 0. 直觉与动机

**灵感 1（抓取不是“点动作”，而是“接触流形上的驻留”）**
直觉：第 54 轮把技能写成动作空间占用 `α_S(a)`，但抓取成败几乎不取决于末端是否到达某个 6D 位姿，而取决于指面与物体之间那一小片接触是否始终落在摩擦锥内。同一个位姿，接触点差 2mm、法向偏 5°，力封闭裕度可能由正变负。因此动作剖面必须从“可达/不可达”升级为 **接触模式剖面**：技能在 `(接触构型, 接触模式)` 上的驻留程度。接触模式 `M={stick, slip, roll, detach}` 才是抓取的第一性状态变量，`α_S` 只是它在运动学上的边缘投影。
严谨化：定义 121。

**灵感 2（VLA 给“语义可抓”，边端要“物理可抓”）**
直觉：具身大模型擅长回答“抓把手、从侧面、用包裹式”，输出的是语言/可供性条件下的抓取分布 `π_VLA(g|o,l)`。但它是从海量图文与演示中学到的 **相关性先验**，没有显式约束力封闭。于是出现系统性错位：语义上最合理的抓取，可能恰好落在薄壁、低摩擦、重心偏移的力封闭盲区。解法不是“让大模型更准”，而是引入 **语义→接触落地算子 Γ**，把提议投影到已认证的接触流形上，并为每个抓取出具物理裕度证书。语义分数与物理裕度必须 **同时** 进入决策，缺一不可。
严谨化：定义 122、123。

**灵感 3（抓取规划是接触模式序列，不是单帧抓取）**
直觉：真实抓取常常需要“先推、再夹、再重抓”。单帧抓取证书再漂亮，若两个抓取之间必须经过一次“松手换姿”，而该转移会短暂离开无跌落管，序列仍然失败。因此抓取规划应写成 **接触模式转移图** 上的路径问题：边权不是 Jaccard 相似度，而是转移全过程中力封闭裕度的最小值与接触模式合法性。
严谨化：定义 124。

**灵感 4（语义-接触对齐误差 → 可度量的“大模型幻觉”）**
直觉：VLA 的“语义可抓”与接触流形的“物理可抓”之间的差距，本身应是一个可测量、可回传的量 `δ_sc`。它由几何投影距离（最近的已认证抓取有多远）与本体覆盖缺口（语义标签有多少没有接触模式实现）两部分组成。`δ_sc` 大的物体/指令，就是大模型的高风险区；把 `δ_sc` 作为云端提议的先验门控，比笼统地说“大模型不可靠”更可操作。
严谨化：定义 125。

**灵感 5（云边分工：语义在高处，接触在低处）**
直觉：云端 VLA 负责开放词汇语义提议与任务分解，边端负责接触落地、力封闭校验与重抓取规划；反向通道不再只回传“失败了”，而是回传 **接触级解释**（哪个接触点滑移、摩擦系数低估多少、哪次模式转移非法），云端据此重写可供性提示并重采样。这把第 54 轮的 `γ_ce`（粗→细）升级为 `γ_vc`（语义→接触），也让第 53 轮的 Explain 获得接触物理语义。
严谨化：定义 126。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（接触模式动作空间与接触剖面）**
设物体 `O`、手 `H`。接触构型 `c = {(p_i, n_i, f_i)}_{i=1..k} ∈ C`，其中 `p_i ∈ ∂O` 为接触点，`n_i` 为指向物体内部的单位法向，`f_i = |f_t,i|/|f_n,i| ∈ [0, μ_i]` 为归一化切向载荷。接触模式集合 `M = {stick, slip, roll, detach}`。技能 `S` 的 **接触模式剖面** `κ_S : C × M → [0,1]`，满足 `Σ_{m∈M} κ_S(c,m) ≤ 1`。抓取动作 `a=(R,t,q_h)` 经正运动学诱导接触集 `c(a)`。**接触有效** 定为：
```
contact_valid(a) ⇔ κ_S(c(a), stick) ≥ θ_k ∧ κ_S(c(a), detach) ≤ θ_d
```
并定义动作剖面 `α_S(a) := 1[contact_valid(a)]`。即 `α_S` 是 `κ_S` 的边缘投影，抓取的“可行”不再由几何到达判定，而由接触模式驻留判定。

**定义 122（语义抓取提议）**
VLA 在视觉 `o`、语言指令 `l`、上下文 `χ` 下输出抓取分布 `π_VLA(g | o,l,χ)`，`g=(R,t,q_h)`。定义语义分数 `s_sem(g) = log π_VLA(g|o,l,χ) - log Z`，**语义抓取流形** `S_l = { g : s_sem(g) ≥ θ_sem }`。云端只返回 top-k 提议 `G_VLA = TopK_{g∈S_l} s_sem(g)`。关键：`S_l` 是语义流形，不必然与任何物理解集相交。

**定义 123（抓取证书）**
对抓取 `g`、接触集 `c(g)`、外部扳手集 `W_ext`、估计摩擦系数 `μ̂`，定义三个物理裕度：
- 摩擦裕度 `ε_f(g) = min_i ( μ̂_i - f_t,i/f_n,i )`；
- 扳手裕度 `ε_w(g) = max{ ε : ε·𝔹 ⊂ GWS(c(g)) }`，`𝔹` 为单位扳手球，`GWS` 为接触原始扳手按摩擦锥缩放后的凸包（`ε_w>0` 等价于力封闭）；
- 接触裕度 `ε_c(g) = min_i dist(p_i, ∂(∂O))/diag(O)`，惩罚边缘/薄壁接触。
**抓取证书** `𝔾(g) = (g, c(g), ε_f, ε_w, ε_c, ρ_contact, E)`，其中 `ρ_contact` 为第 53 轮鲁棒性谱在接触维度（摩擦、位姿、质量、柔顺）上的限制，`E` 为仿真接触轨迹与真实滑移日志。`g` **已认证** 当且仅当
```
ε_f ≥ ε_f^min ∧ ε_w ≥ ε_w^min ∧ ε_c ≥ ε_c^min ∧ ρ_contact(d) ≥ ρ_min(d) ∀d
```

**定义 124（重抓取转移与无跌落不变量）**
从 `g_i` 到 `g_j` 的转移由连续接触轨迹 `c(t), t∈[0,1]` 实现。称转移 **可采纳** 当且仅当：
1. 模式转移在图 `M` 的状态机上合法（如 `stick→roll` 合法，`stick→detach` 仅在重抓取瞬间允许）；
2. **无跌落不变量**：`∀t, ε_w(c(t)) ≥ ε_w^min` 且物体位移 `‖x(t)-x(0)‖ ≤ δ_drop`。
定义接触兼容性 `compat_g(g_i,g_j) = min_t ε_w(c(t)) / ε_w^min`，转移成本 `c_regrasp = ∫_0^1 (‖τ(t)‖ + λ_m·1[mode jump](t)) dt`。第 54 轮的 `compat`（动作集 Jaccard）在此被 `compat_g` 取代：**组合可行性 = 接触能连续保持，而非动作集重叠**。

**定义 125（语义-接触对齐误差）**
```
δ_sc(o,l) = δ_geo + λ·δ_onto
δ_geo  = E_{g~π_VLA}[ d_SE3( g, Π_C(g) ) ]
δ_onto = 1 - |L_contact| / |L_sem|
```
`Π_C(g)` 为 `g` 到已认证接触集 `C_cert` 的最近投影；`L_sem` 为语义可供性标签集，`L_contact` 为其中存在接触模式实现的标签。`δ_geo` 度量“语义抓取离物理可行有多远”，`δ_onto` 度量“语义本体有多少没有被接触本体覆盖”。

**定义 126（语义-物理双证书与云边接触契约）**
双证书 `𝔻 = (s_sem, 𝔾, δ_sc, γ_vc, Explain_contact)`：
- `s_sem` 语义分数；`𝔾` 抓取证书；
- `γ_vc : S_l → C` 语义→接触落地映射（把 6D 抓取提议映射为接触构型）；
- `δ_sc` 对齐误差；
- `Explain_contact`：接触级反向解释，输出 `(接触点索引, 失败模式, 摩擦缺口 μ_i-μ̂_i, 建议的重提议约束)`。
云边接触契约 `C_vc = (P_sem, P_contact, γ_vc, δ_sc, Loop_contact)`：云端产生语义计划 `P_sem`，边端产生接触计划 `P_contact`；部署条件为
```
𝔻 certified ∧ δ_sc ≤ Θ_sc ∧ J(P_contact) ∈ dom_J
```
其中 `J` 为第 54 轮动作-鲁棒性联合证书，但需追加接触维度裕度。

## 2. 关键算法 伪代码

### IP-121 CMP（Contact-Mode Profiling）

```python
def contact_mode_profile(skill, obj, hand, C_space, modes, sim, n_contact=512):
    kappa = {}
    for c in sample_contacts(C_space, obj, hand, n=n_contact, stratified=True):
        trace = sim.contact_trace(skill, obj, hand, c)
        for m in modes:
            kappa[(c, m)] = occupancy(trace, m) * contact_stability(trace, m)
    return kappa

def contact_valid(kappa, g, fk, theta_k=0.9, theta_d=0.05):
    c = fk.induced_contacts(g)
    return kappa.get((c, 'stick'), 0.0) >= theta_k and \
           kappa.get((c, 'detach'), 0.0) <= theta_d
```

### IP-122 SGP（Semantic Grasp Proposal）

```python
def vla_propose(obj, instruction, ctx, k=32, theta_sem=-2.0):
    raw = vlm.sample_grasps(obj.rgbd, instruction, ctx, n=k * 4)
    cand = [g for g in raw if g.logprob >= theta_sem]
    cand.sort(key=lambda g: g.logprob, reverse=True)
    return cand[:k]                     # 语义流形 S_l 的 top-k
```

### IP-123 GCX（Grasp Certificate）

```python
def grasp_certificate(g, obj, hand, mu_hat, W_ext, rho_min, thresholds):
    c = contact_set(g, obj, hand)
    if len(c) < 2: return Reject('no_contact', c)
    eps_f = min(mu_hat[i] - slip_ratio(c[i]) for i in range(len(c)))
    eps_w = wrench_margin(c, W_ext)          # 内接于 GWS 的最大球半径
    eps_c = min(dist_to_boundary(p, obj) for p in points(c)) / obj.diag
    if eps_f < thresholds.f or eps_w < thresholds.w or eps_c < thresholds.c:
        return Reject('margin_violation', (eps_f, eps_w, eps_c))
    rho = contact_robustness(g, dims=['friction', 'pose', 'mass', 'compliance'])
    if min(rho.values()) < rho_min:
        return Reject('robustness_fail', rho)
    return Ok(Cert(g, c, eps_f, eps_w, eps_c, rho))
```

### IP-124 RGC（Regrasp Composition Graph）

```python
def build_regrasp_graph(proposals, obj, hand, transition_policy, thresholds):
    G = nx.DiGraph()
    valid = [(g, cert) for g in proposals
             for cert in [grasp_certificate(g, obj, hand, ...)]
             if isinstance(cert, Ok)]
    for g, cert in valid:
        G.add_node(g.id, cert=cert)
    for (gi, _), (gj, _) in itertools.permutations(valid, 2):
        traj = transition_policy.plan_contact_transition(gi, gj, obj, hand)
        if traj is None or not mode_transition_legal(traj): continue
        if not no_drop_invariant(traj, eps_w_min=thresholds.w): continue
        G.add_edge(gi.id, gj.id,
                   cost=regrasp_cost(traj),
                   compat=min_eps_w(traj) / thresholds.w,
                   margin=min_margin(traj))
    return G
```

### IP-125 CEG（Contact-Edge Governance）

```python
def contact_grounded_plan(task, G_regrasp, gamma_vc, mu_hat, thresholds):
    proposals = vla_propose(task.obj, task.instruction, task.ctx)
    grounded = []
    for g in proposals:
        cert = grasp_certificate(g, task.obj, task.hand, mu_hat, task.W_ext, ...)
        if isinstance(cert, Ok):
            grounded.append((g, cert))
    if not grounded:
        return Reject('semantic_physical_gap', explain_gap(proposals, task))
    start = task.initial_contact
    goal  = task.goal_contact
    path  = a_star(G_regrasp, start=start, goal=goal,
                   edge_filter=lambda e: e['margin'] >= thresholds.w)
    if path is None:
        exp = explain_contact_failure(G_regrasp, start, goal)
        return Reject('no_contact_path', exp)   # 回传云端重提议
    return Ok(path, duplex_certificate(path, gamma_vc, delta_sc(task)))
```

### IP-126 DGC（Duplex Grasp Certificate）

```python
def duplex_certificate(path, gamma_vc, delta_sc, theta_sc, J):
    certs = [G_regrasp.nodes[g]['cert'] for g in path]
    eps_w_seq = compose_margin_sequence(certs)     # 含重抓取恢复项
    if eps_w_seq < 0: return Reject('sequence_margin_fail')
    if delta_sc > theta_sc: return Reject('semantic_contact_misalign', delta_sc)
    if not in_domain(J, certs): return Reject('joint_domain_mismatch')
    evidence = collect_contact_traces(path) + collect_vla_logits(path)
    return Ok(DuplexCert(path, certs, eps_w_seq, delta_sc, gamma_vc, evidence))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CMP | `O(|C|·|M|·T_sim)` | `O(|C|·|M|)` | 分层采样覆盖、模式判定阈值 sound |
| SGP | `O(k·T_vla)` | `O(k)` | 语义流形 top-k 召回 |
| GCX | `O(k·|c|·LP(GWS))` | `O(|c|·|W_ext|)` | 裕度估计下界、摩擦标定 |
| RGC | `O(V²·T_traj)` | `O(V²)` | 无跌落不变量、模式状态机 |
| CEG | `O(k·T_gcx + V log V + E)` | `O(V+E)` | `γ_vc` Lipschitz、Explain 闭环 |
| DGC | `O(|path|·|c| + |𝔇_ρ|)` | `O(|path|·|c|)` | 序列裕度组合 sound、`δ_sc` 预算 |

**正确性定理（Contact-Grounded Grasp Composition Soundness）**
承接第 53/54 轮假设；新增 **(A29)** 接触模型与摩擦估计在标定域内误差 `|μ̂-μ| ≤ Δμ`；**(A30)** VLA 提议在认证接触集上的召回率 `≥ r0`；**(A31)** 落地映射 `γ_vc` 在 `S_l` 上 Lipschitz 常数 `L<1`；**(A32)** 重抓取转移规划在接触管内完备。则
```
P_success ≥ 1 - P(|μ̂-μ| > Δμ) - P(ε_w^est < 0 | ε_w^true ≥ 0)
            - P(δ_sc > Θ_sc) - P(no admissible regrasp) - β_E
```
关键：**证书的 soundness 首先取决于摩擦估计的 soundness**；语义只在 `δ_sc` 门控内贡献召回，物理裕度才是零阶约束。

| 风险 | 等级 | 缓解 |

## 6. 本轮最大风险

**一句话**：把抓取从“运动学可达”推进到“接触模式驻留 + 语义-物理双证书”，理论上是把大模型的相关性先验钉在力封闭流形上的正确方向，但整套 soundness **首先押注在摩擦系数与接触模型的在线标定精度上**——一旦 `μ̂` 在薄壁/软体/油污表面系统性高估，证书会把“即将滑落”判成“已认证”，语义分数越高反而越危险，因此必须以 **保守摩擦下界 + 接触反例绊线 + 物理否决优先于语义** 作为不可协商的前置护栏。

# 第 55 轮产物 · 创新点清单 v32：GraspGround-VLA（CMP×SGP×GCX×RGC×SCA×DGC）

> 承接第 54 轮产物 v31。本轮在“动作空间剖面 + 技能组合 + 云边协同”之上，补上动作空间里最物理、最容易暴露大模型幻觉的一段——**抓取接触**。核心增量：
> - **CMP（Contact-Mode Profiling）**：把动作剖面 `α_S` 细化为接触模式剖面 `κ_S`；
> - **SGP（Semantic Grasp Proposal）**：把 VLA 的语义抓取分布显式建模为 `π_VLA(g|o,l)`；
> - **GCX（Grasp Certificate）**：摩擦/扳手/接触三裕度 + 接触鲁棒性谱的物理证书 `𝔾`；
> - **RGC（Regrasp Composition Graph）**：以“无跌落不变量”替代 Jaccard 兼容性的重抓取转移图；
> - **SCA（Semantic-Contact Alignment）**：可度量、可回传的语义-接触对齐误差 `δ_sc`；
> - **DGC（Duplex Grasp Certificate）**：语义分数 + 物理证书的联合部署判据与云边接触闭环。
>
> IP 编号：IP-121~IP-126（共 6 个新增）；升级 IP-115（α→κ）、IP-116（compat→compat_g）、IP-117（γ_ce→γ_vc）。

## 2. 关键算法 伪代码

### IP-121 CMP

```python
def contact_mode_profile(skill, obj, hand, C_space, modes, sim, n_contact=512):
    kappa = {}
    for c in sample_contacts(C_space, obj, hand, n=n_contact, stratified=True):
        trace = sim.contact_trace(skill, obj, hand, c)
        for m in modes:
            kappa[(c, m)] = occupancy(trace, m) * contact_stability(trace, m)
    return kappa

def contact_valid(kappa, g, fk, theta_k=0.9, theta_d=0.05):
    c = fk.induced_contacts(g)
    return kappa.get((c, 'stick'), 0.0) >= theta_k and \
           kappa.get((c, 'detach'), 0.0) <= theta_d
```

### IP-122 SGP

```python
def vla_propose(obj, instruction, ctx, k=32, theta_sem=-2.0):
    raw = vlm.sample_grasps(obj.rgbd, instruction, ctx, n=k * 4)
    cand = [g for g in raw if g.logprob >= theta_sem]
    cand.sort(key=lambda g: g.logprob, reverse=True)
    return cand[:k]
```

### IP-123 GCX

```python
def grasp_certificate(g, obj, hand, mu_hat, W_ext, rho_min, thresholds):
    c = contact_set(g, obj, hand)
    if len(c) < 2: return Reject('no_contact', c)
    eps_f = min(mu_hat[i] - slip_ratio(c[i]) for i in range(len(c)))
    eps_w = wrench_margin(c, W_ext)          # GWS 内接球半径，>0 即力封闭
    eps_c = min(dist_to_boundary(p, obj) for p in points(c)) / obj.diag
    if eps_f < thresholds.f or eps_w < thresholds.w or eps_c < thresholds.c:
        return Reject('margin_violation', (eps_f, eps_w, eps_c))
    rho = contact_robustness(g, dims=['friction', 'pose', 'mass', 'compliance'])
    if min(rho.values()) < rho_min:
        return Reject('robustness_fail', rho)
    return Ok(Cert(g, c, eps_f, eps_w, eps_c, rho))
```

### IP-124 RGC

```python
def build_regrasp_graph(proposals, obj, hand, transition_policy, thresholds):
    G = nx.DiGraph()
    valid = [(g, cert) for g in proposals
             for cert in [grasp_certificate(g, obj, hand, ...)]
             if isinstance(cert, Ok)]
    for g, cert in valid:
        G.add_node(g.id, cert=cert)
    for (gi, _), (gj, _) in itertools.permutations(valid, 2):
        traj = transition_policy.plan_contact_transition(gi, gj, obj, hand)
        if traj is None or not mode_transition_legal(traj): continue
        if not no_drop_invariant(traj, eps_w_min=thresholds.w): continue
        G.add_edge(gi.id, gj.id,
                   cost=regrasp_cost(traj),
                   compat=min_eps_w(traj) / thresholds.w,
                   margin=min_margin(traj))
    return G
```

### IP-125 SCA（语义-接触对齐）

```python
def semantic_contact_alignment(proposals, C_cert, labels_sem, labels_contact):
    delta_geo = mean(dist_se3(g, nearest(g, C_cert)) for g in proposals)
    delta_onto = 1.0 - len(labels_contact) / max(1, len(labels_sem))
    return delta_geo + LAMBDA * delta_onto

def sca_gate(delta_sc, theta_sc):
    return delta_sc <= theta_sc
```

### IP-126 DGC + CEG（云边接触闭环）

```python
def contact_grounded_plan(task, G_regrasp, gamma_vc, mu_hat, thresholds):
    proposals = vla_propose(task.obj, task.instruction, task.ctx)
    grounded = [(g, cert) for g in proposals
                for cert in [grasp_certificate(g, task.obj, task.hand,
                                               mu_hat, task.W_ext, ...)]
                if isinstance(cert, Ok)]
    if not grounded:
        return Reject('semantic_physical_gap',
                      explain_gap(proposals, task))   # 回传云端
    path = a_star(G_regrasp, start=task.initial_contact, goal=task.goal_contact,
                  edge_filter=lambda e: e['margin'] >= thresholds.w)
    if path is None:
        return Reject('no_contact_path',
                      explain_contact_failure(G_regrasp, task))
    return Ok(path, duplex_certificate(path, gamma_vc,
                                       semantic_contact_alignment(
                                           proposals, task.C_cert,
                                           task.labels_sem, task.labels_contact),
                                       J=task.joint_cert))

def duplex_certificate(path, gamma_vc, delta_sc, J, theta_sc):
    certs = [G_regrasp.nodes[g]['cert'] for g in path]
    eps_w_seq = compose_margin_sequence(certs)   # 含重抓取恢复项
    if eps_w_seq < 0: return Reject('sequence_margin_fail')
    if delta_sc > theta_sc: return Reject('semantic_contact_misalign', delta_sc)
    if not in_domain(J, certs): return Reject('joint_domain_mismatch')
    evidence = collect_contact_traces(path) + collect_vla_logits(path)
    return Ok(DuplexCert(path, certs, eps_w_seq, delta_sc, gamma_vc, evidence))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CMP | `O(|C|·|M|·T_sim)` | `O(|C|·|M|)` | 分层采样覆盖 ≥ 95%，模式判定 sound |
| SGP | `O(k·T_vla)` | `O(k)` | 语义流形 top-k 召回 ≥ r0 |
| GCX | `O(k·|c|·LP(GWS))` | `O(|c|·|W_ext|)` | 裕度下界 sound，摩擦标定域内 |
| RGC | `O(V²·T_traj)` | `O(V²)` | 无跌落不变量、模式状态机完备 |
| SCA | `O(k·|C_cert|)` | `O(k)` | `δ_geo` 投影距离可计算、本体覆盖可枚举 |
| DGC/CEG | `O(k·T_gcx + V log V + E + |path|·|c|)` | `O(V+E+|path|·|c|)` | 序列裕度组合 sound、`γ_vc` Lipschitz、Explain 闭环收敛 |

**正确性定理（Contact-Grounded Grasp Composition Soundness）**
承接第 53/54 轮 (A22)–(A28)；新增 **(A29)** 标定域内摩擦估计误差 `|μ̂-μ| ≤ Δμ`；**(A30)** VLA 在认证接触集上召回 `≥ r0`；**(A31)** `γ_vc` 在 `S_l` 上 Lipschitz `L<1`；**(A32)** 重抓取转移规划在接触管内完备。则
```
P_success ≥ 1 - P(|μ̂-μ| > Δμ) - P(ε_w^est < 0 | ε_w^true ≥ 0)
            - P(δ_sc > Θ_sc) - P(no admissible regrasp) - β_E
```
要点：**语义分数只决定召回，物理裕度决定 soundness**；`δ_sc` 是二者的显式桥接量，而非事后解释。

## 6. 本轮最大风险

**一句话**：抓取接触层把“语义可抓”钉到“物理可抓”的力封闭流形上，方向正确且可证伪，但整套 soundness **首要押注在摩擦系数与接触模型的在线标定精度**——一旦 `μ̂` 在薄壁、软体或油污表面系统性高估，证书会把“即将滑落”判成“已认证”，语义分数越高越危险；因此必须把 **保守摩擦下界证书 + 接触反例绊线 + 物理否决优先于语义** 设为不可协商的部署前置条件。
