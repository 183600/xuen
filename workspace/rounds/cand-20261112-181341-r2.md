# 第 62 轮（承接第 61 轮「具身语义进化闭环」ESEC；灵感循环第 8 轮；本轮灵感：「因果推理」×「热管理」）

> 第 61 轮构建了 ESEC：USR 统一语义表征、MEL 多模态具身大模型、DMS 多轮对话管理、SRT-Dual 语义-实时双流、PCE+++++ 六维预算，把「语义先行」接入实时控制。但**四个深层局限**在本轮暴露：
> 1. **MEL 的相关性捷径**：MEL 的物理属性推断是在观测数据上拟合 `P(φ_phys | V,T,P,L)`，训练分布中「温度/材质/表面状态」高度混杂，模型会学到 `高温 ⇒ 软`、`反光 ⇒ 低摩擦`等**伪因果**；它无法回答 `do(K_p←0.7K_p)` 的反事实效应，因而「零样本泛化」在分布外是脆弱的。
> 2. **热状态的系统性缺席**：第 61 轮把 `φ_phys` 当作静态参数，但接触摩擦与执行器铜损持续生热，`μ(Θ)、k(Θ)、η(Θ)、σ(Θ)` 随温度漂移；长时间作业会出现「控制器参数没变、被控对象已经变了」的**热漂移失稳**。
> 3. **异常归因是相关式的**：EFGP 用「滑移 ⇒ 降 K_p」「振动 ⇒ 升 K_d」的规则，把**伴随现象**当作**致因**；滑移可能来自热软化、法向力不足、表面污染或磨损，错误干预会放大故障。
> 4. **时间尺度还缺一层**：语义流 10–100Hz、实时流 1–10kHz 之外，热过程是 0.01–1Hz 的慢变量；把热塞进任何一条现有流都会破坏其契约，需要**三时间尺度**与显式的热安全降载协议。

## 0. 直觉与动机

**灵感 1（因果推理 → 因果场景模型 CSM）**
直觉：把 MEL 从「拟合联合分布」改成「拟合结构因果模型」。变量分为外生（材质 M、表面污染 C、环境温度 Θ_amb、磨损 W）与内生（温度 Θ、摩擦 μ、刚度 k、阻尼 η、脆性 σ、法向力 F_n、切向速度 v、滑移 s、振动 a_vib、接触力 F_t）。结构方程不是黑箱，而是**物理先验约束的神经符号混合式**：`μ = f_μ(M, C, Θ, W, F_n) + ε`。关键洞见：MEL 的物理属性头不再是 `φ_phys`，而是**因果后验** `P(φ, G | obs)`；控制决策必须经过 `do(K)` 的反事实查询，而不是直接回归。

**灵感 2（热管理 → 热-物理耦合模型 TPM）**
直觉：热是「慢状态、强耦合、不可逆」。建立集总热模型 `C_th·Θ̇ = Q_gen − Q_diss`，其中 `Q_gen = η_loss·F_t·v + I²R`（接触摩擦 + 电机铜损），`Q_diss = hA(Θ−Θ_amb)`；材料属性随温度漂移 `μ(Θ)=μ_0(1−α_μ(Θ−Θ_0))`。关键洞见：**热不是环境噪声，而是控制约束的一等公民**——阻抗调度必须预测 `t_lim`（到达热限的时间）并在热包络内降载，而不是等到温度报警。

**灵感 3（因果 × 热 → 因果根因诊断 CRD）**
直觉：异常发生后，问题不是「哪个信号超阈值」，而是「如果我把它改回去，异常会不会消失」。用反事实必要性 `N_i = P(Y_{do(X_i=x_i^ref)}=0 | Y=1)` 与充分性 `S_i = P(Y_{do(X_i=x_i^obs)}=1 | Y=0)` 对候选因子排序；对不可识别的因子（存在未观测混杂）**拒绝下结论**。关键洞见：**诊断的诚实性优先于诊断的果断性**——不可识别时必须请求澄清或转入硬保守，而不是猜一个最可能的规则。

**灵感 4（因果-热 → 三时间尺度架构 TCT + 热约束阻抗调度 TIS）**
直觉：增加第三条**因果-热流**（0.1–10Hz）：更新 SCM 后验、做反事实诊断、用热感知 MPC 生成 `K_thermal`。三流通过三类锚点（语义锚点 / 热锚点 / 反事实锚点）耦合。关键洞见：**安全降载是单调的**——热锚点过期时只能按 `γ(Δt)` 逐级降低刚度/提高阻尼/收紧力上限，任何升载必须等待新鲜热锚点与因果证书。

**灵感 5（干预式自学习 → 干预证据缓冲 IEB）**
直觉：运行时每次下发的 `K` 都是一次 `do(K=k)`，因此 `(K, context, outcome)` 是**干预样本**，而非被动观测。把干预日志（含倾向性、版本号、热状态）写入 IEB，SCM 可用它在线校正因果效应，并检测「规则干预无效」的因果反证。关键洞见：**执行即实验**——但必须带倾向性与安全边界，否则会把安全兜底误学成因果效应。

**灵感 6（PCE++++++ → 八维认知-因果-热预算）**
直觉：第 61 轮 `B_cog5` 需补 `B_causal`（反事实采样、因果发现、干预试验）与 `B_thermal`（热观测器、热 MPC、热裕度）。预算耗尽时因果推理降级为「冻结图 + 规则保守」，热预算耗尽时切换「常值最坏情况降载」，二者都**不允许以安全换算力**。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（因果场景模型 CSM）** `CSM = (V, U, F, P(U), G)`。其中：
- **外生变量** `U = (M, C, Θ_amb, W, ε)`：材质、表面污染、环境温度、磨损、噪声
- **内生变量** `V = (Θ, μ, k, η, σ, F_n, v, F_t, s, a_vib, y)`：温度、摩擦、刚度、阻尼、脆性、法向力、切向速度、接触力、滑移、振动、任务结果
- **结构方程** `F = {f_v}`，物理先验约束：
  ```
  Θ_{t+1} = Θ_t + Δt/C_th · [η_loss·F_t·v + I²R − hA(Θ_t − Θ_amb)] + ε_Θ
  μ        = μ_0(M,C) · (1 − α_μ(Θ−Θ_0)) · (1 − β_W·W) + ε_μ
  s        = 1[ F_t > μ·F_n ]  （或 P(s=1) = σ(κ(F_t − μF_n))）
  a_vib    = g(K_p, K_d, μ, v, F_n) + ε_a
  y        = h(φ_phys(Θ), K, F_n, v, C) + ε_y
  ```
- **因果图** `G=(V,E)`：边方向由物理先验固定（`Θ→μ→s`、`K→a_vib`、`F_n→F_t`），禁止数据驱动反向边
- **干预**：`do(X=x)` 删除 X 的入边并固定其值；`P(y | do(X=x)) = Σ_z P(y | X=x, Z=z)P(z)`，`Z` 为满足后门准则的调整集
- **反事实**：三步法（abduction → action → prediction）计算 `Y_{X=x'}(u)`，并给出可识别性区间 `[Y^-, Y^+]`
- **可识别性余量**：`id_margin = 1 − TV(P_obs(Z), P_target(Z)) − ε_positivity`，低于阈值即判「不可识别」

**定义 174（热-物理耦合模型 TPM）** `TPM = (Θ, C_th, hA, Q_gen, Q_diss, φ(Θ), Env_th)`。其中：
- **温度相关属性**：
  ```
  μ(Θ) = μ_0·(1 − α_μ(Θ−Θ_0)),   k(Θ) = k_0·(1 − α_k(Θ−Θ_0))
  η(Θ) = η_0·(1 + α_η(Θ−Θ_0)),   σ(Θ) = σ_0·(1 + α_σ(Θ−Θ_0))
  ```
- **集总热动力学**：`C_th·Θ̇ = Q_gen − Q_diss`，`Q_gen = η_loss·F_t·v + I²R`，`Q_diss = hA(Θ−Θ_amb) + ε_rad(Θ⁴−Θ_amb⁴)`
- **热状态观测器**：EKF `x_th=(Θ, R_th, C_th)`，由接触力、速度、电流、温度传感器联合估计，协方差 `Σ_th`
- **热时间常数**：`τ_th = C_th/(hA)`；**到达热限时间**：`t_lim = τ_th·ln((Θ_max−Θ_ss)/(Θ_max−Θ_t))`（`Θ_ss` 为稳态温升）
- **热剂量**：`D_th = ∫(Θ−Θ_ref)⁺ dt`，材料疲劳/润滑退化与 `D_th` 单调相关
- **热安全包络**：`Env_th = {Θ ≤ Θ_max, D_th ≤ D_max, t_lim ≥ H_safe, |Θ̇| ≤ Θ̇_max}`

**定义 175（因果根因诊断 CRD）** 对异常 `y∈{slip, vibration, force_exceed, thermal_alarm}` 与上下文 `z`：
- **反事实归因向量**：对每个候选因子 `X_i ∈ {K_p, K_d, F_n, v, μ(Θ), C, W}`
  ```
  A_i = E[Y | do(X_i = x_i^obs), z] − E[Y | do(X_i = x_i^ref), z]
  N_i = P(Y_{do(X_i=x_i^ref)} = 0 | Y = 1, z)       # 必要性
  S_i = P(Y_{do(X_i=x_i^obs)} = 1 | Y = 0, z)       # 充分性
  ```
- **因果 Shapley 分解**：在 G 的祖先子图上对 `A_i` 做 Shapley 分摊，保证归因可加且对称
- **可识别性门控**：若 `id_margin < τ_id` 或 `max_i |[Y^-,Y^+]| > ε_cf`，诊断标记 `UNIDENTIFIABLE`，**禁止自动干预**
- **干预选择**：`a* = argmax_{a∈A_safe} E[ΔP(y) | do(a)] − λ_cost·cost(a)`，且要求 `N_{a} ≥ τ_N` 才允许自动执行

**定义 176（热约束阻抗调度 TIS）** 慢时间尺度 MPC：
```
min_{u_{0:H-1}} Σ_{k=0}^{H-1} [ ‖e_track,k‖²_Q + λ_Θ·(Θ_{t+k}−Θ_ref)² + λ_D·D_th,k
                              + λ_safe·risk(K_{t+k}, Θ_{t+k}) ]
s.t.  Θ_{t+k+1} = Θ_{t+k} + Δt/C_th·[Q_gen(K_{t+k}, Θ_{t+k}) − Q_diss(Θ_{t+k})]
      Θ_{t+k} ≤ Θ_max,  D_th,k ≤ D_max,  t_lim ≥ H_safe
      K_{t+k} ∈ K_feasible(Θ_{t+k}),  ‖u_{k+1}−u_k‖ ≤ ΔK_max   # 平滑约束
```
- 求解：热模型一维、约束箱式，采用**序列凸近似 + 内点法**，或短时域 `H≤20` 的 iLQR
- 输出与语义先验融合：`K_prior^ct = λ_th·K_thermal + (1−λ_th)·Π(anchor_sem)`，`λ_th` 随 `U_thermal` 升高而增大
- **降载算子** `Derate(K, γ)`：`K_p←γK_p, K_d←K_d/γ, F_max←γF_max`，`γ∈[γ_min,1]` 单调不增

**定义 177（三时间尺度架构 TCT）** 三条异步流水线：
- **因果-热流** `f_ct ≈ 0.1–10Hz`：CSM 后验更新 → CRD 诊断 → TIS 求解 → 提交热锚点/反事实锚点
- **语义流** `f_sem ≈ 10–100Hz`：MEL（以 `φ(Θ)` 与因果后验为条件）→ DMS（消费诊断）→ USR 提交语义锚点
- **实时流** `f_rt ≈ 1–10kHz`：读取三类锚点 → EEIS 编译 → ERTC 派发 → 构建 EV-exec（含热信号）→ IEB
- **优先级**：`热安全 ≻ 因果可信 ≻ 语义忠实 ≻ 跟踪性能`
- **过期语义**：语义锚点过期 → 保守扩展（继承第 61 轮）；**过期热锚点** → 强制 `Derate` 单调降载，禁止任何升载

**定义 178（因果-热锚点与一致性协议 CTA/CTP）** 
```
CTA = (Θ_t, Θ̇_t, φ(Θ)_t, D_th, t_lim, U_thermal,
       causal_graph_version, edge_posterior, id_margin,
       cf_bounds, diagnosis_id, version=(epoch, counter), timestamp, checksum)
```
- **写入**：CAS 原子写，`version` 为 64 位 `(epoch, counter)` 单调递增
- **读取**：检查 `now − timestamp < τ_fresh_th`；`id_margin < τ_id` 的锚点标记 `non_interventional`
- **一致性规则**：`K_t` 必须同时满足 `J_ct` 与热包络；任一不满足即 `Derate` 直到满足
- **回滚**：连续 3 次热包络预测违约 ⇒ 冻结 SCM 干预，退回「规则 + 最坏情况降载」

**定义 179（八维认知-因果-热预算 PCE++++++）** `B_cog8 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_causal, B_thermal)`：

- `B_thermal = (observer_ops, mpc_horizon, mpc_iters, thermal_margin, derate_rate_limit)`

- **降级**：`B_causal` 耗尽 ⇒ 冻结图、关闭反事实、仅用规则保守；`B_thermal` 耗尽 ⇒ 固定 `γ=γ_min` 最坏情况降载；**二者降级都不得放宽热包络**

关键：执行证据既是**语义对账依据**，也是**干预样本**，反哺 CSM 在线的因果效应校正。

**定义 182（因果域随机化与迁移 CDR）** 将 sim2real 视为因果迁移：
```
P_real(Y | do(K)) = ∫ P_sim(Y | do(K), φ) · P_real(φ) dφ
```
- **因果不变性假设**：机制 `P(Y | do(K), Pa(Y))` 跨域不变，只有外生分布 `P(φ)` 变化
- **域随机化**：只随机化**因果机制参数**（`μ_0, α_μ, C_th, hA, η_loss`），不随机化伪相关（如「材质颜色 ↔ 摩擦」的虚假映射）
- **迁移界**：若支撑重叠且机制稳定，`|P_real − P_sim^reweight| ≤ δ_mech + TV(P_real(φ), P_sim(φ))`
- **反捷径正则**：训练时对与 `K` 无因果路径的特征做对抗去偏，惩罚 `I(feature; 材质颜色)` 中与任务无关的部分

**定义 183（干预证据缓冲 IEB）** `IEB = {(K_t, z_t, EV_t, π_t, Θ_t, ver_t)}_{t=1..N}`：
- `π_t` 为实际执行策略的倾向性（含降载/回退标记），保证干预样本可加权
- **加权因果更新**：`P(Y|do(K)) ≈ Σ_t w_t·1[K_t≈K]·Y_t`，`w_t = 1/π_t`，并做有效样本量裁剪 `ESS ≥ N_min`
- **反证检测**：若某规则干预 `a` 在 `ESS≥N_min` 下 `E[ΔY|do(a)] < 0`，标记该规则失效，触发 CRD 复核

**定义 184（因果风险感知对话策略 CRTP）** DMS 的动作选择增加因果门槛：
- 可自动执行的约束必须来自 `id_margin ≥ τ_id` 且 `N_necessary ≥ τ_N` 的诊断
- 若诊断 `UNIDENTIFIABLE`，动作限定为 `{ask_clarify, wait, derate_conservative}`，禁止 `propose_constraint`
- 对话奖励增加因果项：`R += λ_cf·(1 − cf_bound_width) − λ_wrong·1[intervention_on_unidentifiable]`

### IP-183 CSM（因果场景模型）

```python
class CausalSceneModel:
    def __init__(self, graph_prior, physical_equations, d_latent=64):
        self.G = graph_prior              # 物理先验 DAG，禁止数据驱动反向边
        self.F = physical_equations       # 结构方程（神经符号混合）
        self.posterior = {}               # 外生变量的后验
        self.intervention_log = IEB()

    def update_observational(self, obs, thermal_sensors, dt):
        # 贝叶斯更新外生变量（材质/污染/磨损/热参数）
        self.posterior = self._bayes_update(self.posterior, obs, thermal_sensors, dt)
        return self.posterior

    def update_interventional(self, ieb):
        # 用 do(K) 干预样本做加权因果校正
        ess = ieb.effective_sample_size()
        if ess >= N_MIN:
            self.F = self._weighted_causal_update(self.F, ieb, weights=1/ieb.propensity)
        return self.F

    def do_query(self, target, intervention, context, n_samples=256):
        # P(target | do(X=x), context)，后门调整
        Z = self._backdoor_set(target, intervention.var)
        if not self._positivity_ok(Z):
            return None, 0.0           # 不可识别
        vals = [self._sample_and_propagate(intervention, Z, context) for _ in range(n_samples)]
        lo, hi = np.percentile(vals, [5, 95])
        id_margin = 1 - self._tv(self.posterior[Z], context.target_Z)
        return float(np.mean(vals)), id_margin

    def counterfactual(self, observed, intervention, target):
        # abduction → action → prediction
        u = self._abduct(observed)                 # 反推外生噪声
        cf = self._propagate(self._set_intervention(intervention), u)
        return cf[target], self._bound_width(cf)

    def counterfactual_attribution(self, y_event, context, candidates):
        out = {}
        for Xi in candidates:
            a_i = self.do_query(y_event, Do(Xi, Xi.obs), context)[0]
            a_ref = self.do_query(y_event, Do(Xi, Xi.ref), context)[0]
            n_i = self._p_no_event_given_do_ref(y_event, Xi, context)
            s_i = self._p_event_given_do_obs(y_event, Xi, context)
            out[Xi] = dict(A=a_i - a_ref, N=n_i, S=s_i)
        return out
```

### IP-184 TPM（热-物理耦合模型）

```python
class ThermoPhysicalModel:
    def __init__(self, C_th, hA, alpha=(a_mu, a_k, a_eta, a_sigma),
                 theta_max=80.0, d_max=1e6, dt=0.01):
        self.C_th, self.hA = C_th, hA
        self.alpha = alpha
        self.theta_max, self.D_max, self.dt = theta_max, d_max, dt
        self.ekf = ThermalEKF(state_dim=3)   # (Theta, R_th, C_th)

    def predict(self, theta, F_t, v, current, theta_amb):
        Q_gen = self.eta_loss * F_t * v + current**2 * self.R
        Q_diss = self.hA * (theta - theta_amb)
        return theta + self.dt / self.C_th * (Q_gen - Q_diss)

    def update(self, theta_meas, F_t, v, current, theta_amb):
        theta_pred = self.predict(self.ekf.x[0], F_t, v, current, theta_amb)
        self.ekf.predict(theta_pred)
        self.ekf.update(theta_meas)
        return self.ekf.x[0], self.ekf.P[0, 0]

    def physical_properties(self, theta):
        mu0, k0, eta0, sig0 = self.phi0
        d = theta - self.theta0
        return dict(mu=mu0*(1-self.alpha[0]*d), k=k0*(1-self.alpha[1]*d),
                    eta=eta0*(1+self.alpha[2]*d), sigma=sig0*(1+self.alpha[3]*d))

    def time_to_limit(self, theta, theta_ss):
        tau = self.C_th / self.hA
        if theta_ss <= theta:
            return float('inf')
        return tau * np.log((self.theta_max - theta_ss) / (self.theta_max - theta))

    def thermal_margin(self, theta):
        return (self.theta_max - theta) / self.theta_max

    def envelope_ok(self, theta, dose, t_lim, H_safe):
        return (theta <= self.theta_max and dose <= self.D_max
                and t_lim >= H_safe)
```

```python
class CausalRootCauseDiagnosis:
    def __init__(self, csm, tau_id=0.6, tau_N=0.7, eps_cf=0.15):
        self.csm, self.tau_id, self.tau_N, self.eps_cf = csm, tau_id, tau_N, eps_cf

    def diagnose(self, ev_exec, context):
        y = ev_exec.anomaly_type
        if y is None:
            return Diagnosis(type='none', identifiable=True)
        cands = self._candidates(y)              # 由 G 的祖先集生成
        attrib = self.csm.counterfactual_attribution(y, context, cands)
        shap = self._causal_shapley(attrib, self.csm.G)
        best = max(shap, key=lambda k: shap[k])
        id_margin = min(self.csm.do_query(y, Do(Xi, Xi.obs), context)[1] for Xi in cands)
        cf_width = max(self.csm.counterfactual(ev_exec.obs, Do(Xi, Xi.ref), y)[1]
                       for Xi in cands)
        if id_margin < self.tau_id or cf_width > self.eps_cf:
            return Diagnosis(type='UNIDENTIFIABLE', best=best,
                             id_margin=id_margin, cf_width=cf_width,
                             allowed_actions=['ask_clarify', 'wait', 'derate_conservative'])
        n_best = attrib[best]['N']
        return Diagnosis(type=y, cause=best, N=n_best, id_margin=id_margin,
                         cf_width=cf_width, attributable=shap,
                         auto_intervene=(n_best >= self.tau_N))
```

### IP-186 TIS（热约束阻抗调度）

```python
class ThermalImpedanceScheduler:
    def __init__(self, tpm, horizon=15, dt=0.2, gamma_min=0.5):
        self.tpm, self.H, self.dt, self.gamma_min = tpm, horizon, dt, gamma_min

    def solve(self, theta, dose, K_ref, theta_amb, F_t, v, current):
        # 序列凸近似；变量为各步 derate 因子 gamma_k
        g = np.ones(self.H)
        for _ in range(self.max_iters):
            g = self._convex_step(g, theta, dose, K_ref, theta_amb, F_t, v, current)
            if self._converged(g): break
        gamma = min(g[0], 1.0)
        K_th = self._derate(K_ref, max(gamma, self.gamma_min))
        return K_th, gamma

    def _convex_step(self, g, theta, dose, K_ref, theta_amb, F_t, v, current):
        # 目标：跟踪 + 热惩罚 + 平滑；约束：热包络线性化
        A, b = self._linearize_thermal(g, theta, theta_amb, F_t, v, current)
        return solve_qp(H=self._Q, f=self._f(g, K_ref), A=A, b=b, bounds=(self.gamma_min, 1.0))

    def _derate(self, K, gamma):
        K2 = dict(K)
        K2['K_p'] *= gamma
        K2['K_d'] /= gamma
        K2['F_max'] *= gamma
        return K2
```

| 组件 | 时间 | 空间 | 正确性保证 |

**正确性定理（CTEL-Complete）**：
假设 A61–A70 及 **(A71)** CSM 在给定 `G` 下满足后门可识别性与 positivity；未观测混杂的敏感度 `Γ ≤ Γ_max`。**(A72)** TPM 的 `C_th, hA, α` 位于已知紧区间，EKF 误差协方差一致有界；热模型在包络内 Lipschitz。**(A73)** CRD 的反事实查询使用与观测一致的外生后验；不可识别判定是保守的（不会把不可识别误判为可识别）。**(A74)** TIS 的 MPC 在每个采样点递归可行，且 `Derate` 单调不增。**(A75)** IEB 的倾向性已知且 `ESS ≥ N_min`，干预样本支撑覆盖目标 `K`。**(A76)** 实时流对热锚点的读取是原子的，`version=(epoch,counter)` 64 位不回绕。**(A77)** DMS 的 CRTP 在 `UNIDENTIFIABLE` 状态下严格禁用自动约束提案。

则：
1. **因果可信性**：可识别条件下，`|ĈATE − CATE| ≤ ε_cate`；不可识别条件下，系统输出区间并拒绝自动干预，误干预率 ≤ δ_wrong。
2. **热安全**：在 A72–A74 下，任意时刻 `Θ ≤ Θ_max`、`D_th ≤ D_max`，且 `t_lim ≥ H_safe`；热锚点过期时 `K` 单调降载，不产生升载跳变。
3. **归因正确性**：若真实致因 `X*` 可识别且 `N_{X*} ≥ τ_N`，CRD 以概率 ≥ 1−δ 将其排在首位；错误规则在 `ESS≥N_min` 后被 IEB 反证并停用。
4. **三流实时性**：实时流周期抖动 ≤ 0.2ms，不依赖 CT/语义流时序；热过期降载只增加安全裕度。
5. **迁移可信性**：CDR 下 `P_real(Y|do(K))` 与重加权 sim 分布的 TV 距离 ≤ δ_mech + TV(P(φ))。
6. **预算安全性**：`B_causal`/`B_thermal` 耗尽只触发「冻结因果 + 最坏情况降载」，绝不放宽热包络或绕过 `J_ct`。

### IP-183 CSM（因果场景模型）

```python
class CausalSceneModel:
    """物理先验 DAG + 神经符号结构方程 + 干预式在线校正。"""

    def __init__(self, graph_prior, physical_equations, d_latent=64,
                 tau_id=0.6, eps_cf=0.15, n_cf=256):
        self.G = graph_prior
        self.F = physical_equations
        self.posterior = {}
        self.tau_id, self.eps_cf, self.n_cf = tau_id, eps_cf, n_cf
        self.version = (0, 0)

    def _backdoor_set(self, target, cause):
        # G 中去除 cause 出边后，阻断 target 与 cause 的全部后门路径
        return self._minimal_separator(target, cause, remove_out_edges_of=cause)

    def _positivity_ok(self, Z):
        return all(self.posterior[z].min_prob >= 1e-3 for z in Z)

    def update_observational(self, obs, thermal_sensors, dt):
        self.posterior = self._bayes_update(self.posterior, obs, thermal_sensors, dt)
        self.version = (self.version[0], self.version[1] + 1)
        return self.posterior

    def update_interventional(self, ieb, n_min=30):
        ess = ieb.effective_sample_size()
        if ess < n_min:
            return self.F, False
        w = 1.0 / np.clip(ieb.propensity, 1e-6, 1.0)
        self.F = self._weighted_causal_update(self.F, ieb, w)
        self.version = (self.version[0] + 1, 0)
        return self.F, True

    def do_query(self, target, intervention, context):
        Z = self._backdoor_set(target, intervention.var)
        if not self._positivity_ok(Z):
            return None, 0.0
        samples = np.array([
            self._sample_and_propagate(intervention, Z, context)
            for _ in range(self.n_cf)
        ])
        lo, hi = np.percentile(samples, [5, 95])
        id_margin = 1.0 - self._tv(self.posterior[Z], context.target_Z) - self._positivity_penalty(Z)
        return float(samples.mean()), float(np.clip(id_margin, 0, 1)), (lo, hi)

    def counterfactual(self, observed, intervention, target):
        u = self._abduct(observed)
        cf = self._propagate(self._set_intervention(intervention), u)
        width = self._cf_bound_width(cf, target)
        return cf[target], width

    def counterfactual_attribution(self, y, context, candidates):
        out = {}
        for Xi in candidates:
            a_obs = self.do_query(y, Do(Xi, Xi.obs), context)
            a_ref = self.do_query(y, Do(Xi, Xi.ref), context)
            if a_obs[0] is None or a_ref[0] is None:
                out[Xi] = dict(A=None, N=None, S=None, identifiable=False)
                continue
            n_i = self._prob_no_event(Do(Xi, Xi.ref), context, y)
            s_i = self._prob_event(Do(Xi, Xi.obs), context, y)
            out[Xi] = dict(A=a_obs[0] - a_ref[0], N=n_i, S=s_i,
                           identifiable=(a_obs[1] >= self.tau_id))
        return out

    def sensitivity(self, Gamma_max=2.0):
        # 未观测混杂敏感度：E-value 风格，返回使结论翻转的最小 Gamma
        return self._e_value(self.posterior, self.G, Gamma_max)
```

### IP-184 TPM（热-物理耦合模型）

```python
class ThermoPhysicalModel:
    def __init__(self, C_th, hA, eta_loss, R, phi0, theta0,
                 alpha, theta_max=80.0, d_max=1e6, dt=0.01):
        self.C_th, self.hA, self.eta_loss, self.R = C_th, hA, eta_loss, R
        self.phi0, self.theta0, self.alpha = phi0, theta0, alpha
        self.theta_max, self.D_max, self.dt = theta_max, d_max, dt
        self.ekf = ThermalEKF(dim=3)          # (Theta, R_th, C_th)
        self.dose = 0.0

    def step(self, theta, F_t, v, current, theta_amb):
        Q_gen = self.eta_loss * F_t * v + current**2 * self.R
        Q_diss = self.hA * (theta - theta_amb)
        theta_next = theta + self.dt / self.C_th * (Q_gen - Q_diss)
        self.dose += max(theta_next - self.theta0, 0.0) * self.dt
        return theta_next

    def observe(self, theta_meas, F_t, v, current, theta_amb):
        pred = self.step(self.ekf.x[0], F_t, v, current, theta_amb)
        self.ekf.predict(pred, self.dt)
        self.ekf.update(theta_meas)
        return self.ekf.x[0], float(self.ekf.P[0, 0])

    def properties(self, theta):
        mu0, k0, eta0, sig0 = self.phi0
        d = theta - self.theta0
        a_mu, a_k, a_eta, a_sig = self.alpha
        return dict(mu=mu0*(1-a_mu*d), k=k0*(1-a_k*d),
                    eta=eta0*(1+a_eta*d), sigma=sig0*(1+a_sig*d))

    def time_to_limit(self, theta, theta_ss):
        tau = self.C_th / self.hA
        if theta_ss >= self.theta_max:
            return 0.0
        if theta_ss <= theta:
            return float('inf')
        return tau * np.log((self.theta_max - theta_ss) / (self.theta_max - theta))

    def envelope(self, theta, t_lim, H_safe, margin=0.1):
        theta_lim = self.theta_max * (1 - margin)
        return dict(ok=(theta <= theta_lim and self.dose <= self.D_max and t_lim >= H_safe),
                    thermal_margin=(theta_lim - theta) / self.theta_max,
                    t_lim=t_lim, dose=self.dose)
```

```python
class CausalRootCauseDiagnosis:
    def __init__(self, csm, tau_id=0.6, tau_N=0.7, eps_cf=0.15):
        self.csm, self.tau_id, self.tau_N, self.eps_cf = csm, tau_id, tau_N, eps_cf

    def diagnose(self, ev_exec, context):
        y = ev_exec.anomaly_type
        if y is None:
            return Diagnosis(kind='none', identifiable=True, auto_intervene=False)

        candidates = self._ancestors_of(y, self.csm.G)
        attrib = self.csm.counterfactual_attribution(y, context, candidates)
        id_margin = min((v['identifiable'] * 1.0) for v in attrib.values()) if attrib else 0.0
        cf_width = max((self.csm.counterfactual(ev_exec.obs, Do(X, X.ref), y)[1]
                        for X in candidates), default=0.0)

        if id_margin < self.tau_id or cf_width > self.eps_cf:
            return Diagnosis(kind='UNIDENTIFIABLE', id_margin=id_margin,
                             cf_width=cf_width,
                             allowed=['ask_clarify', 'wait', 'derate_conservative'],
                             auto_intervene=False)

        shap = self._causal_shapley(attrib)
        best = max(shap, key=shap.get)
        n_best = attrib[best]['N'] or 0.0
        return Diagnosis(kind=y, cause=best, attributable=shap,
                         id_margin=id_margin, cf_width=cf_width, N=n_best,
                         auto_intervene=(n_best >= self.tau_N))
```

### IP-186 TIS（热约束阻抗调度）

```python
class ThermalImpedanceScheduler:
    def __init__(self, tpm, horizon=15, dt=0.2, gamma_min=0.5, max_iters=8):
        self.tpm, self.H, self.dt = tpm, horizon, dt
        self.gamma_min, self.max_iters = gamma_min, max_iters

    def solve(self, theta, K_ref, theta_amb, F_t, v, current, H_safe):
        g = np.ones(self.H)
        for _ in range(self.max_iters):
            A, b = self._linearize_thermal(g, theta, theta_amb, F_t, v, current)
            g_new = self._solve_qp(g, A, b, K_ref)
            if np.max(np.abs(g_new - g)) < 1e-3:
                g = g_new
                break
            g = g_new
        gamma = float(np.clip(g[0], self.gamma_min, 1.0))
        K_th = self._derate(K_ref, gamma)
        theta_pred = self._rollout(theta, gamma, theta_amb, F_t, v, current)
        t_lim = self.tpm.time_to_limit(theta, theta_pred[-1])
        return K_th, gamma, t_lim

    def _linearize_thermal(self, g, theta, theta_amb, F_t, v, current):
        # Q_gen 与 gamma 近似线性：F ~ gamma、v ~ const；据此给出每步温度上界
        rows, rhs = [], []
        rows.append(np.ones(self.H)); rhs.append((self.tpm.theta_max * 0.9 - theta) / self.dt)
        return np.array(rows), np.array(rhs)

    def _solve_qp(self, g, A, b, K_ref):
        # 变量 g∈[gamma_min,1]^H；目标：跟踪 + 热惩罚 + 平滑
        H = self.H
        Q = np.eye(H) * 1.0 + 0.5 * (np.eye(H) - np.eye(H, k=1)) @ (np.eye(H) - np.eye(H, k=1)).T
        f = -0.3 * np.ones(H)
        return solve_box_qp(Q, f, A, b, lb=self.gamma_min, ub=1.0)

    def _derate(self, K, gamma):
        K2 = dict(K)
        K2['K_p'] = K['K_p'] * gamma
        K2['K_d'] = K['K_d'] / max(gamma, 1e-6)
        K2['F_max'] = K['F_max'] * gamma
        return K2
```

### IP-187 TCT（三时间尺度闭环）

```python
class CausalThermalTriFlow:
    def __init__(self, csm, tpm, crd, tis, mel, dms, usr, eeis, ertc, budget):
        self.csm, self.tpm, self.crd, self.tis = csm, tpm, crd, tis
        self.mel, self.dms, self.usr = mel, dms, usr
        self.eeis, self.ertc, self.budget = eeis, ertc, budget
        self.last_thermal_anchor = None

    def ct_step(self, obs, thermal):
        if not self.budget.can_causal():
            return self._conservative_ct(obs, thermal)
        self.csm.update_observational(obs, thermal.sensors, dt=0.1)
        self.csm.update_interventional(obs.ieb)
        diagnosis = self.crd.diagnose(thermal.ev_exec, obs.context)
        K_th, gamma, t_lim = self.tis.solve(
            thermal.theta, thermal.K_ref, thermal.theta_amb,
            thermal.F_t, thermal.v, thermal.current, H_safe=10.0)
        anchor = self.usr.commit_thermal_anchor(
            theta=thermal.theta, phi=self.tpm.properties(thermal.theta),
            dose=self.tpm.dose, t_lim=t_lim, diagnosis=diagnosis,
            K_thermal=K_th, graph_version=self.csm.version,
            id_margin=diagnosis.id_margin)
        self.last_thermal_anchor = anchor
        return anchor

    def semantic_step(self, obs, diagnosis):
        phi = self.tpm.properties(self.last_thermal_anchor.theta)
        z_scene, pi, U = self.mel.infer(obs.V, obs.T, obs.P, obs.L, phi, diagnosis)
        a = self.dms.step(U, diagnosis)      # CRTP 门控
        self.usr.commit_semantic_anchor(z_scene, self.usr.intent_encoder(self.dms.b_intent), phi, U)
        return a

    def realtime_step(self, obs, thermal):
        anchor = self.usr.read_thermal_anchor()
        if anchor is not None and anchor.fresh and anchor.id_margin >= TAU_ID:
            K_prior = anchor.K_thermal
        else:
            age = 0.0 if anchor is None else (time.time() - anchor.timestamp)
            gamma = max(self.budget.gamma_min, 1.0 - 0.05 * age)   # 只降不升
            K_prior = Derate(self.last_thermal_anchor.K_thermal, gamma)
        K_safe = self.eeis.compile(obs.delta_f, obs.fused, obs.xi_exec, obs.Z_env,
                                   K_prior, self.tpm.properties(thermal.theta))
        K_safe = self._clamp_thermal(K_safe, thermal.theta)
        cert = self.ertc.dispatch(K_safe)
        ev = build_evidence(thermal.signals, cert)
        self.csm.intervention_log.push(K_safe, obs.context, ev,
                                       propensity=self.ertc.last_propensity,
                                       theta=thermal.theta)
        return K_safe, ev, cert

    def _clamp_thermal(self, K, theta):
        env = self.tpm.envelope(theta, self.tpm.time_to_limit(theta, theta), H_safe=10.0)
        if not env['ok']:
            gamma = max(self.budget.gamma_min, 1.0 - env['thermal_margin'])
            return self.tis._derate(K, gamma)
        return K
```

### IP-188 PCE++++++（八维预算）

```python
class CausalThermalBudget:
    def __init__(self, base, cf_samples=256, boot=32, discovery_ops=10,
                 trials=20, mpc_iters=8, gamma_min=0.5):
        self.base = base
        self.B_cf, self.B_boot = cf_samples, boot
        self.B_disc, self.B_trial = discovery_ops, trials
        self.B_mpc, self.gamma_min = mpc_iters, gamma_min
        self.used = dict(cf=0, boot=0, disc=0, trial=0, mpc=0)
        self.causal_frozen = False
        self.thermal_worst = False

    def can_causal(self):
        return not self.causal_frozen and self.used['cf'] < self.B_cf * 10

    def can_thermal(self):
        return not self.thermal_worst and self.used['mpc'] < self.B_mpc * 100

    def degrade(self, id_margin):
        if self.used['cf'] >= self.B_cf * 10 or id_margin < 0.3:
            self.causal_frozen = True
        if self.used['mpc'] >= self.B_mpc * 10:
            self.thermal_worst = True
        return dict(causal_frozen=self.causal_frozen,
                    thermal_worst=self.thermal_worst,
                    gamma=(self.gamma_min if self.thermal_worst else 1.0))

    def voi_cog8(self, action):
        base_voi = self.base.voi_meta_pessimistic(action)
        cost = self.base.cost_exec(action)
        cost += 0.3 * (self.used['cf'] / (self.B_cf * 10))
        cost += 0.1 * (self.used['mpc'] / (self.B_mpc * 100))
        cost += 0.2 * action.id_margin_need
        return base_voi - cost
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CSM | 观测更新 O(S·|V|)；do-query O(N_cf·|V|)；反事实 O(N_cf·|V|) | O(|V|²+N_cf) | 后门可识别时 `|ĈATE−CATE|≤ε_cate`；否则输出区间并拒绝干预 |
| TPM | 预测 O(1)；H 步 rollout O(H) | O(1) | 温度估计误差有界；热包络预测保守 |
| CRD | O(|Cand|·N_cf·|V|) | O(|Cand|·N_cf) | 可识别时 Top-1 校准；不可识别硬拒绝 |
| TIS | O(max_iters·H³)（箱式 QP） | O(H) | 递归可行；`γ` 单调不增 |
| TCT | 三流异步，实时流独立 | 锚点 ~10MB | 实时抖动 ≤0.2ms；过期只降不升 |
| PCE++++++ | O(1) | O(1) | 降级不放宽热包络、不绕过 `J_ct` |

**正确性定理（CTEL-Complete）**：
假设 A61–A70 及 **(A71)** CSM 的 `G` 满足后门可识别性与 positivity；未观测混杂敏感度 `Γ ≤ Γ_max`。**(A72)** TPM 参数位于已知紧区间，EKF 一致有界；包络内热模型 Lipschitz。**(A73)** CRD 的不可识别判定保守。**(A74)** TIS MPC 递归可行且 `Derate` 单调。**(A75)** IEB 倾向性已知、`ESS ≥ N_min`、支撑覆盖目标 K。**(A76)** 热锚点读取原子、`version=(epoch,counter)` 64 位不回绕。**(A77)** CRTP 在 `UNIDENTIFIABLE` 下禁用自动约束提案。

则：
1. **因果可信性**：可识别时 `|ĈATE−CATE|≤ε_cate`；不可识别时误干预率 ≤ δ_wrong。
2. **热安全**：任意时刻 `Θ≤Θ_max`、`D_th≤D_max`、`t_lim≥H_safe`；热锚点过期时 K 单调降载。
3. **归因正确性**：可识别且 `N_{X*}≥τ_N` 时，CRD 以概率 ≥1−δ 将真因排首位；IEB 可反证并停用失效规则。
4. **三流实时性**：实时流抖动 ≤0.2ms，不依赖 CT/语义流。
5. **迁移可信性**：`TV(P_real(Y|do(K)), P_sim^reweight) ≤ δ_mech + TV(P_real(φ),P_sim(φ))`。
6. **预算安全性**：`B_causal`/`B_thermal` 耗尽仅触发「冻结因果 + 最坏情况降载」，不放宽热包络。
