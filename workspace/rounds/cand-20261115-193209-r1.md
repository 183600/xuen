# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互不确定性二分闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「容错控制」×「人形机器人」）

> R69 做了一件很漂亮的事：把不确定性拆成 aleatoric / epistemic，并让系统第一次「开口问」。但它有一个从未言明、也从未被检验的前提——**被问的世界是稳定的，提问的身体是完好的**。λ_floor 缩放的是「已选动作」的风险，VoI 支配的是「信息动作」的收益，二者都默认：执行器还有效、传感器还诚实、我仍然是训练时那具身体。
>
> 人形机器人恰恰活在这个前提失效的地方。它会抓起重物（负载突变）、会磨损、会磕碰、会被抱住、会在湿滑地面丢接触、会单腿/单臂失效——**但它的高自由度、多接触点、欠驱动结构又使它在身体部分失效后仍有能力继续工作**。这正是容错控制（FTC）的全部主题：用冗余换生存。而 R69 把这份冗余当成免费的，全部花在了「问」上。
>
> 本轮的核心命题：**在 R69 的两轴不确定性（aleatoric / epistemic）之外，加入第三轴——结构性不确定 U_struct（我的身体/动作空间还成立吗）；把「问」升级为「先自诊、再重构、最后才问」，并让人形机器人的物理冗余成为容错与交互共同争夺的稀缺预算。** 命名 **SOMA-RAS**（Self-model & Online Morphology-aware Active fault-tolerant Risk-Adaptive System：自模型 × 全身控制分配的人形机器人主动容错闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的身体还是我以为的那具身体吗？我还能做什么？**」——不确定性不只是一种要消解的歧义，也可能是一次必须被容忍、被重构、被优雅降级的结构改变。

## 0. 直觉与动机

**灵感 1（人形机器人 = 冗余的富矿；FTC = 把冗余变成生存）**
直觉：人形机器人有几十个自由度、两只手、两条腿，以及「身体可以靠、可以坐、可以跪、可以扶」的环境接触。这种冗余在正常情况下是「多余的」，在故障时就是「救命钱」。容错控制的核心不是「故障后停机」，而是**控制分配（control allocation）**：把仍然有效的执行器/接触点重新分配去满足一个优先级列表（别摔倒 > 别自碰撞 > 完成任务 > 做交互），从而在部分失效下继续工作。R69 从没用过这份冗余——它只有「收紧 λ」这一种降级方式。

**灵感 2（第三轴：结构性不确定）**
直觉：R69 的 U_ale 是「同一个动作里的噪声」，U_epi 是「该选哪个动作」；但还有第三种，也是人形机器人最致命的——**「动作空间本身是否还成立」**。一条腿锁死、一个关节失去效力、一个力传感器偏置，改变的不是「选哪个动作」，而是「哪些动作还可行」。R69 的 FMA 只能给出一个怀疑分 a_score；R70 要把它升级成**带隔离的故障假设集 Φ + 每个假设对应的可容许动作集 A_adm(φ)**。这带来一个关键判别：**暂时的歧义去问（epistemic），持续的结构改变去重构（structural）**。对着一个死掉的执行器反复「问」是徒劳；对一个只是有歧义的任务过度「重构」是浪费。

**灵感 3（诊断也是一种信息动作，但它和任务消歧抢同一份预算，而且有优先级）**
直觉：自诊断可以通过「主动自检」完成——命令一个小幅运动，看本体感觉是否跟上（这正是 FTC 的 built-in test）。这天然就是 R69 定义的信息动作，只是它要消解的目标从「任务模态 M」变成「故障假设 φ」。于是 MINT 的 VoI 从一元变二元：VoI(M) + VoI(φ)。但二者不是并列的：**在身体模型不可信时，任何任务消歧都可能建立在错误的身体上**，所以「先验身、后问题」——身体有效性优先。同时要防另一个极端：过度诊断（假警）会诱发不必要的降级，本身也会致险。

**灵感 4（错诊比不诊更危险——R69「问错比不问更危险」的同构）**
直觉：FTC 最古老也最疼的教训是**误隔离（misattribution）**：位置传感器偏置和执行器偏置在残差空间里常常不可分；把一个健康肢体误判为故障而关掉它，比不诊断更容易摔倒。更狡猾的是**隐蔽故障（stealthy / masked fault）**：它刻意表现得像健康模型，让自模型残差保持在阈值内。因此 SOMA 绝不能把安全押在 φ̂ 上：必须有**永远在线的被动安全层**（反射/平衡/力矩限幅），主动诊断与重构只在模型有效性门通过后接管，且只用于「提升性能与生存率」，不用于「保证基本安全」。

**灵感 5（人形机器人特有：预期形态变化 vs 故障；环境接触与受控跌倒）**
直觉：人形机器人经常**主动改变自己的「形态」**——搬起箱子（负载）、拿起工具、被人抱住。这些会让自模型残差瞬间变大，但它们不是故障；若误诊就会「搬个箱子被判成执行器坏死」。所以故障先验必须以「意图」为条件（我是否命令了抓取）。另两点是人形独有：其一，**环境本身就是备用执行器**（扶栏、坐下、跪撑、靠墙），所以降级不只是「降低性能」，还可以是「换接触模式」；其二，**受控跌倒 + 起身**是合法的降级模式，而不是失败——关键是把「可恢复的失衡」和「结构故障」分开。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（SOMA-RAS 总览与分层不变式）** SOMA-RAS = (SMM, FDI-S, RMS, FT-WBC, DEG, SCP, FDIR-B, AFDI, MVC, FRM, RAS-WM‡)。三不变式：
(i) **被动安全常驻**：低层反射/平衡/限幅控制器永远在线，其安全性不依赖 φ̂（诊断错误不得导致失稳）；
(ii) **主动层单调退化**：诊断/重构只在 MVC（定义 320）通过时接管，且降级方向单调（D0→D1→D2→D3），任何不确定都只能往更保守方向移动；
(iii) **实时流零学习写操作 + 预算硬约束**：继承 R68 定义 276-i 与 R69 定义 293，新增诊断与重构的算力/时延预算。

**定义 311（自模型与效仿残差）** 自模型 S_ψ: (ξ_{t−1}, q_t) ↦ ŷ_t 预测本体感觉响应（关节位置/速度/力矩、接触力旋量）。效仿残差 r_self(t) = y_t − ŷ_t。用效仿副本（efference copy）把「我命令的」从「世界施加的」中分离，是人形机器人解析冗余的基础。

**定义 312（故障假设集与结构化残差）** φ ∈ Φ = {φ_0=nominal, φ_i^sens（传感器偏置/漂移）, φ_j^act,κ（执行器有效性损失 LOE，κ_j∈[0,1]）, φ_j^lock（关节锁死）, φ_c^contact（接触丢失）, φ^payload（负载变化，含有意/无意）, φ^power（功率/温升降额）}。结构化残差 r = (r_1,…,r_n) 由奇偶空间/解析冗余生成；故障签名矩阵 S_{ij}=∂r_i/∂φ_j。**可隔离性**：φ_a, φ_b 可隔离 ⇔ 其签名列不同；否则并入歧义组 G。

**定义 313（故障后验与结构性不确定）** p(φ | r_self, o, u_intent) ∝ p(r_self|φ) p(φ|u_intent)，其中 u_intent 含「是否命令了抓取/工具」以区分**预期形态变化**与故障。结构性不确定 U_struct = Σ_φ p(φ)·C(φ)，C(φ) 为该故障的后果严重度（失稳/不可恢复性），或等价地用后果加权熵。U_struct 与 U_ale/U_epi 语义正交，不做简单相加（继承定义 297 的分通道原则）。

**定义 314（冗余裕度与可容许动作集）** 故障修正后的有效性矩阵 B_φ = B diag(κ(φ))，可用接触集 C(φ)。定义冗余裕度 ρ(s,φ) = 在硬安全约束（质心/CoP 落在支撑多边形、摩擦锥、力矩/速度限、非穿透）下的最大可行松弛。可容许动作集 A_adm(φ,s) = { ξ : 存在分配使 ρ(s,φ) ≥ 0 }。ρ≥0 为可行边界；ρ<0 必须升级降级层级。

**定义 315（容错全身控制分配 FT-WBC）** 决策变量 τ=[τ_joint, f_contact]。字典序优先级：P0 硬安全（平衡/非穿透/限幅）> P1 自碰撞与姿态 > P2 任务 > P3 交互。在 B_φ 与 C(φ) 下解分层 QP，低优先级用松弛变量。它是容错在物理上的「执行器」：故障改变的是 B_φ，而不是策略的全部重训。

**定义 316（降级层级与接触模式）** D0 正常；D1 任务降额（降速/降力，保留全部任务）；D2 换接触模式（坐下/跪撑/扶靠/靠墙，用任务换稳定）；D3 受控跌倒 + 起身/求助。每级有经认证的包络 E_i(φ)。接触模式的切换需要**经认证的过渡机动**（先建立新接触、再释放旧接触），不能靠凸混合。

**定义 317（自条件策略 SCP）** 复用 R69 的流匹配策略，把条件从 o 扩为 (o, ŝ_self, φ̂, D_i)：π_θ(ξ | o, ŝ_self, φ̂, D_i)，输出限制在 A_adm(φ̂,s) ∩ E_{D_i}。当 φ̂=φ_0 且 D=D0 时，SCP 逐指令退化为 FLUID-RAS（定义 293）。

**定义 318（冗余预算与交互储备 FDIR-B）** 把全身控制权威分解为四份：任务 / 平衡 / **容错储备** / 交互。约束：选择信息动作 g 后必须满足 ρ(s,φ̂) ≥ ρ_min(h(φ̂))，h 为随残差趋势上升的故障风险。交互只有在不侵蚀储备时才被允许；故障风险越高，储备越厚、交互越少。这把 R69 的 MINT 预算与 FTC 的冗余耦合起来。

**定义 319（交互式主动诊断 AFDI）** 自检动作 g_test（小幅受控运动/接触探询/注视）产生观测 y，VoI_fault(g)=I(φ; y|g)。与 R69 MINT 联合，但**字典序优先**：若 U_struct > τ_s，预算先给故障隔离，任务消歧推迟（在错误身体上消歧无意义）。**证据纪律继承**：自检结论必须与第二条独立通道（电流 vs 位置 vs 接触）一致，否则不得重构——这是对假警/隐蔽故障的防线。

**定义 320（模型有效性门控认证 MVC）** C-RAS-WM 的后缀认证必须在 M_{φ̂} 下进行（故障修正的动力学）。证书有效当且仅当：(a) φ̂ 处于单点或一致歧义组；(b) 该模型下 WM 预测误差 < τ_wm；(c) 自模型残差通过平稳性/一致性检验。若 WM 与自模型互相矛盾 ⇒ 证书作废 ⇒ 强制升至 D2 保守。**用陈旧身体模型做认证，是 R68「用陈旧标定做认证」的容错版。**

**定义 321（无扰重构）** 同一接触模式内，控制按 τ(t) = (1−β)τ_{D_i} + β τ_{D_{i+1}}，β 在 Δt_blend 内单调升到 1。因硬安全约束集为凸、两端点均可行，任意凸组合仍可行 ⇒ 力矩不跳变、约束不破坏。跨接触模式（如 D1→D2）走认证过渡边，而非混合；接触模式构成一张带认证边的有向图。

**定义 322（跌倒与恢复管理 FRM）** 区分**可恢复失衡**（瞬态，交给被动反射）与**结构故障**（持续，交给主动层）。触发 D3 时规划**最小伤害跌倒**（护头、降低质心冲击），随后在 φ̂ 下认证「能否起身」；若起身不可行（如手臂+腿同时失效），则**求助**——这是合法的恢复交互动作。恢复就绪度 R(φ) 离线预计算。

**定义 323（证书 J_SOMA）** J_SOMA = (J_FLUID, φ̂, ambiguity_group, ρ_min, D_i, model_validity, blend_hash, recovery_readiness)。Valid ⇔ Valid(J_FLUID) ∧ MVC 通过 ∧ ρ ≥ ρ_min ∧ 未用歧义组中的 φ 为 D0/D1 辩护 ∧ 被动安全层在线。

**定义 324（威胁模型 AIC-SOMA）** ℰ_SOMA = ℰ_FLUID × ℰ_fault × ℰ_fdi。ℰ_fault = 故障注入、隐蔽/掩蔽故障（伪装成健康模型）、传感器欺骗（伪装成执行器故障以诱发错误降级）；ℰ_fdi = 假警、误隔离、歧义组利用。与 R69 的 ℰ_poison 联乘。

## 2. 关键算法骨架

```python
# IP-264 SMM：自模型监测（效仿副本残差）
class SelfModelMonitor:
    def __init__(self, S): self.S = S
    def residual(self, cmd, y_proprio, q):
        y_hat = self.S(cmd, q)                     # 预测本体感觉响应
        return y_proprio - y_hat                   # r_self

# IP-265 FDI-S：结构化残差 + 签名隔离（歧义组按最坏情形处理）
def diagnose(r_self, Phi, u_intent):
    post = {phi: likelihood(r_self, phi) * prior(phi, u_intent) for phi in Phi}
    post = normalize(post)
    G    = ambiguity_group(post)                   # 签名相同的故障并组
    return post, G                                 # G 内取最坏 φ 做重构

# IP-266/267 RMS + FT-WBC：冗余裕度与优先分配
def admissible_and_allocate(s, phi, task, interaction):
    B_phi, C_phi = modified_effectiveness(phi), contact_set(phi)
    feas, slack   = hierarchical_qp(s, B_phi, C_phi,
                                    priorities=[HARD_SAFETY, SELF_COLL,
                                                task, interaction])
    rho = feasible_slack(slack)                    # ρ(s,φ)
    return rho, (feas if rho >= 0 else None)

# IP-268 DEG：降级层级（D0→D1→D2→D3；接触模式切换走认证边）
def degrade_level(rho, U_struct, D_cur, phi_hat):
    if rho >= rho_min_nominal(phi_hat): return bump_blend(D0)
    if rho >= rho_min_derated(phi_hat): return bump_blend(D1)   # 任务降额
    if exists_certified_contact_mode(phi_hat): return transition(D2)  # 坐/跪/扶
    return controlled_fall_plan(D3)                # 最小伤害跌倒 + 恢复

# IP-271 AFDI：交互式主动诊断（破传感器/执行器混淆）+ 证据一致性
def active_fdi(M, r_self, phi_post, budget):
    if entropy(phi_post) < TAU_S: return None      # 已够确定，不折腾
    g = argmax_g [ I(phi; y | g) - cost(g) ]       # 自检动作
    if budget_reserve_ok(g) and c_ras_wm.certify_info(g): return g
    return None

# IP-276 主闭环（继承 FLUID-RAS，仅在「身体模型」处插入 SOMA 层）
def SOMA_RAS_round(M, obs):
    y = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)   # R68/R69 原路
    r_self = M.smm.residual(M.last_cmd, y.proprio, y.q)       # ① 自模型残差
    phi_post, G = M.fdi.diagnose(r_self, M.Phi, M.u_intent)   # ② 隔离
    # ③ 身体有效性优先：先诊断，后任务消歧（R69 被推迟）
    if U_struct(phi_post) > TAU_S:
        g_test = M.afdi.active_fdi(M, r_self, phi_post, M.budget)
        if g_test: phi_post = M.fdi.update(M.cia.execute(g_test), phi_post)
    phi_hat = safe_representative(phi_post, G)                # 歧义组取最坏
    rho, feas = M.wbc.admissible_and_allocate(M.state, phi_hat, M.task, M.g)
    if feas is None: M.deg.force_next_level()                 # ④ 降级
    # ⑤ 只有在储备允许时才允许 R69 的交互
    g = None
    if rho - M.fdir.reserve_cost(g) >= M.fdir.rho_min(M.hazard):
        g = M.mint.choose_interaction(M.modes, M.o, M.budget)
    # ⑥ 自条件策略 + 模型有效性门控认证
    xi  = M.scp.sample(M.o, M.z, M.last_action, phi_hat, M.deg.level)
    ok  = M.mvc.certify(phi_hat, M.wm_preds) and rho >= M.fdir.rho_min(M.hazard)
    lam = M.efs.risk_scale(...) if ok else 1.0                # 认证失败 → 最保守
    tau = M.wbc.allocate(xi.a, phi_hat) * lam
    M.vqa_f.submit_async(phi_post, M.deg.level, r_self, ok)
    return tau, phi_hat, M.deg.level, (rho, U_struct(phi_post))
```

## 3. 推导

**引理 19（可隔离性与歧义组的最坏情形安全）** 若 φ_a、φ_b 签名相同，则任何仅基于 r 的判别器都无法区分它们；此时唯一安全的重构必须对 G 中所有 φ 同时可行，即 A_adm(G,s) = ∩_{φ∈G} A_adm(φ,s)。系：**不可隔离的故障 = 「结构性 aleatoric」**，只能保守；可隔离的故障才是「结构性 epistemic」，可主动重构/自检消解。这为 R69 的二分类补上第三类的边界。

**引理 20（优雅降级界）** 在 LOE κ_j ≥ κ_min 且存在冗余执行器时，FT-WBC 保持 P0 硬安全可行；任务空间加速度误差满足 ‖a_task − a_task^des‖ ≤ c·(1−κ_min)·‖τ‖，其中 c 由 J_task 与 B_φ 的条件数决定。故性能随 κ 连续退化，而非灾难性失效。系：**冗余裕度 ρ 是「故障可容忍度」的度量**，ρ 单调下降预示失稳。

**引理 21（主动自检破解传感器/执行器混淆）** 被动残差 r ≈ J δ_act + δ_sens 在 J 的列空间方向不可分（秩亏）。自检动作 g_test 沿与 J 的零空间正交的激励方向产生附加响应，使组合签名满秩，从而恢复可隔离性：I(φ; y|g_test) > I(φ; y|∅)。系：R69 的信息动作在 FTC 下获得第二用途——**既是任务消歧，也是故障隔离**；但它消耗的正是容错储备。

**定理 18（SOMA 严格包含 FLUID 与 R68）** 当 Φ={φ_0}、ρ≥0、D=D0、U_struct ≤ τ_s 时，SOMA 逐指令等价于 FLUID-RAS；进一步当 VoI(g*)≤c(g*) 时等价于 R68。安全侧永不更弱（被动层 + MVC 门控）；而 FLUID 无 U_struct，对「动作空间改变」只能盲目收紧，故 SOMA 是严格泛化。

**定理 19（无扰重构与约束保持）** 同接触模式下，因硬约束集为凸且两端点可行，任意凸混合可行 ⇒ 力矩与约束连续（继承 R69 定理 17）；跨接触模式走认证过渡边 ⇒ 有界 jerk、无突变。故容错的存在不引入控制不连续。

**定理 20（储备约束的健全性与单调性）** 若选择任何交互 g 后都满足 ρ ≥ ρ_min(h)，则交互不会把容错能力压到认证裕度以下；且 ρ_min 随故障风险 h 单调不减，故交互频率随 h 单调不增。系：R69 的「想问就问」被替换为「先买保险再问」——储备是交互的预算上限。

**引理 22（模型有效性门控的误隔离上界）** 若真故障 φ* 落在歧义组 G 内，且所选降级对 G 中所有 φ 可行，则安全保持；若 φ̂ 落在 G 外（误隔离），MVC 的 WM–自模型一致性检验在残差信噪比 ≥ SNR_0 时以概率 ≥ 1−β 检出并强制退回 D2。故误隔离的伤害被被动层与门控共同限界。

## 6. 本轮最大风险

**一句话**：SOMA-RAS 的全部收益押在「故障后验 φ̂ / 歧义组 G 是对的」这一前提上——**一个隐蔽故障可以伪装成健康自模型，一次误隔离可以把健康肢体关掉、或把控制分配给已经失效的执行器**；于是主动容错会把一个「可恢复的部分故障」升级成「自信的跌倒」——**错诊，比不诊更危险**。而如果为了安全把冗余储备留得太多，又会饿死 R69 的交互消歧（liveness 反噬）。

**次级风险与缓解**：
1. **传感器/执行器混淆** → 主动自检（引理 21）+ 第二条独立通道一致纪律；
2. **假警/欺骗诱发错误降级** → 意图条件先验（定义 313）+ 证据纪律 + 被动层兜底；
3. **隐蔽/掩蔽故障** → MVC 门控 + WM–自模型一致性检验（引理 22）；
4. **接触模式切换瞬态** → 认证过渡边 + 有界 jerk（定理 19）；
5. **储备饿死交互** → 显式 Pareto 调档（E309），安全优先但保留最小交互率；
6. **实时预算** → 被动层 1kHz 常驻、主动层降频与事件触发，故障路径允许一次预算超支但 P0 不断档。

## 2. 形式化定义（要点版）

**定义 310（总览与分层不变式）** SOMA-RAS 三不变式：(i) 被动安全层常驻、安全性不依赖 φ̂；(ii) 主动层只在 MVC 通过后接管，降级方向单调 D0→D1→D2→D3；(iii) 实时流零学习写操作 + 诊断/重构预算硬约束。

**定义 311–312（自模型与故障隔离）** `r_self = y − S_ψ(ξ_{t−1}, q_t)`；故障集 Φ 含传感器偏置、执行器 LOE `κ_j`、关节锁死、接触丢失、负载变化、功率降额；结构化残差 + 签名矩阵 `S_{ij}`；签名相同者并入歧义组 `G`。

**定义 313（结构性不确定）** `p(φ|r_self,o,u_intent)`，以意图 `u_intent`（是否命令抓取）区分**有意形态变化**与故障；`U_struct = Σ p(φ)C(φ)`，与 U_ale/U_epi 正交分通道。

## 3. 关键算法伪代码

```python
# IP-264 SMM：自模型监测（效仿副本残差）
class SelfModelMonitor:
    def residual(self, cmd, y_proprio, q):
        return y_proprio - self.S(cmd, q)          # r_self

# IP-265 FDI-S：结构化残差 + 签名隔离（歧义组按最坏情形处理）
def diagnose(r_self, Phi, u_intent):
    post = normalize({phi: likelihood(r_self, phi) * prior(phi, u_intent)
                      for phi in Phi})
    return post, ambiguity_group(post)             # G 内取最坏 φ

# IP-266/267 RMS + FT-WBC：冗余裕度与字典序分配
def admissible_and_allocate(s, phi, task, interaction):
    B_phi, C_phi = modified_effectiveness(phi), contact_set(phi)
    feas, slack = hierarchical_qp(s, B_phi, C_phi,
                                  priorities=[HARD_SAFETY, SELF_COLL,
                                              task, interaction])
    rho = feasible_slack(slack)
    return rho, (feas if rho >= 0 else None)

# IP-268 DEG：降级层级（接触模式切换走认证边）
def degrade_level(rho, U_struct, D_cur, phi_hat):
    if rho >= rho_min_nominal(phi_hat): return bump_blend(D0)
    if rho >= rho_min_derated(phi_hat): return bump_blend(D1)
    if exists_certified_contact_mode(phi_hat): return transition(D2)
    return controlled_fall_plan(D3)

# IP-271 AFDI：交互式主动诊断（破传感器/执行器混淆）
def active_fdi(r_self, phi_post, budget):
    if entropy(phi_post) < TAU_S: return None
    g = argmax_g [ I(phi; y | g) - cost(g) ]
    return g if budget_reserve_ok(g) and c_ras_wm.certify_info(g) else None

# IP-276 主闭环（继承 FLUID-RAS，仅在「身体模型」处插入 SOMA 层）
def SOMA_RAS_round(M, obs):
    y = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    r_self = M.smm.residual(M.last_cmd, y.proprio, y.q)        # ① 自模型残差
    phi_post, G = M.fdi.diagnose(r_self, M.Phi, M.u_intent)    # ② 隔离
    if U_struct(phi_post) > TAU_S:                             # ③ 身体优先
        g_test = M.afdi.active_fdi(r_self, phi_post, M.budget)
        if g_test: phi_post = M.fdi.update(M.cia.execute(g_test), phi_post)
    phi_hat = safe_representative(phi_post, G)                 # 歧义组取最坏
    rho, feas = M.wbc.admissible_and_allocate(M.state, phi_hat, M.task, M.g)
    if feas is None: M.deg.force_next_level()                  # ④ 降级
    g = None
    if rho - M.fdir.reserve_cost(g) >= M.fdir.rho_min(M.hazard):   # ⑤ 储备门
        g = M.mint.choose_interaction(M.modes, M.o, M.budget)
    xi = M.scp.sample(M.o, M.z, M.last_action, phi_hat, M.deg.level)
    ok = M.mvc.certify(phi_hat, M.wm_preds) and rho >= M.fdir.rho_min(M.hazard)
    lam = M.efs.risk_scale(...) if ok else 1.0                 # ⑥ 门控认证
    tau = M.wbc.allocate(xi.a, phi_hat) * lam
    M.vqa_f.submit_async(phi_post, M.deg.level, r_self, ok)
    return tau, phi_hat, M.deg.level, (rho, U_struct(phi_post))
```

## 4. 推导

**引理 19（可隔离性与歧义组最坏情形安全）** 签名相同者不可区分，安全重构须对 `G` 中所有 φ 同时可行：`A_adm(G,s)=∩_{φ∈G}A_adm(φ,s)`。系：**不可隔离故障 = 结构性 aleatoric（只能保守）；可隔离故障 = 结构性 epistemic（可重构/自检）**——为 R69 的二分类补第三类边界。

**引理 20（优雅降级界）** `κ_j ≥ κ_min` 且存在冗余时，FT-WBC 保持 P0 可行；任务加速度误差 `≤ c(1−κ_min)‖τ‖`，c 由 `J_task, B_φ` 条件数决定。系：`ρ` 是故障可容忍度，单调下降预示失稳。

**引理 21（主动自检破解混淆）** 被动残差 `r≈Jδ_act+δ_sens` 在 J 列空间方向秩亏；自检沿正交激励方向使组合签名满秩，`I(φ;y|g_test) > I(φ;y|∅)`。系：R69 信息动作在 FTC 下获得第二用途（任务消歧 + 故障隔离），但消耗的正是容错储备。

**定理 18（SOMA 严格包含 FLUID 与 R68）** `Φ={φ_0}`、`ρ≥0`、`D0`、`U_struct≤τ_s` 时逐指令等价 FLUID；进一步 `VoI≤c` 时等价 R68。安全不更弱（被动层 + MVC）；FLUID 无 U_struct，对动作空间改变只能盲目收紧 ⇒ SOMA 严格泛化。

**定理 19（无扰重构与约束保持）** 同接触模式下凸可行集 ⇒ 凸混合可行 ⇒ 力矩/约束连续（继承 R69 定理 17）；跨模式走认证过渡边 ⇒ 有界 jerk、无突变。

**定理 20（储备约束健全性与单调性）** 任意交互后 `ρ≥ρ_min(h)` ⇒ 容错能力不低于认证裕度；`ρ_min` 随风险 h 单调不减 ⇒ 交互频率随 h 单调不增。系：把 R69 的「想问就问」改为「先买保险再问」。

**引理 22（误隔离上界）** 真故障在 `G` 内且降级对 `G` 全员可行 ⇒ 安全保持；φ̂ 落在 `G` 外时，MVC 的 WM–自模型一致性检验在 `SNR ≥ SNR_0` 下以概率 `≥1−β` 检出并强制退回 D2 ⇒ 误隔离伤害被被动层与门控共同限界。

## 8. 本轮最大风险

**一句话**：SOMA-RAS 的全部收益押在「故障后验 φ̂ / 歧义组 G 是对的」这一前提上——**一个隐蔽故障可以伪装成健康自模型，一次误隔离可以把健康肢体关掉、或把控制分配给已经失效的执行器**；于是主动容错会把一个「可恢复的部分故障」升级成「自信的跌倒」——**错诊，比不诊更危险**；而若为安全把冗余储备留得太多，又会饿死 R69 的交互消歧（liveness 反噬）。

**次级风险与缓解**：传感器/执行器混淆（主动自检 + 第二通道一致）；假警/欺骗诱发错误降级（意图条件先验 + 证据纪律 + 被动层兜底）；隐蔽/掩蔽故障（MVC 门控 + WM–自模型一致性）；接触模式切换瞬态（认证过渡边 + 有界 jerk）；储备饿死交互（E309 显式 Pareto 调档，安全优先但保留最小交互率）；实时预算（被动层 1kHz 常驻、主动层降频与事件触发，故障路径允许一次超支但 P0 不断档）。
