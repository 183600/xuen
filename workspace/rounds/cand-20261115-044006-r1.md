# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「物体泛化」×「真实世界泛化」）

> R69 让系统学会「问」：把不确定性拆成 aleatoric/epistemic，用看/问/触去消解可约的那一半，并用流似然给标定层做第二意见。但 R69 的整套推理都建立在一个未经检验的前提上——**「当前这个物体、这个世界，是我训练时认识的那一类」**。一旦前提失效，R69 不会变得「不确定」，反而可能**非常确信地做错**：流匹配在有限数据上会从最近的已知物体插值出一条平滑、低熵、看似自洽的轨迹；模态分解于是报告 H_mode≈0，VoI 判定「无需交互」，系统自信地抓向一个它根本没见过的物体。
>
> 两个灵感正好指向这个前提的两条裂缝：
> - **物体泛化**：陌生物体不是「一个新标签」，而是**已知属性的新组合**。功效（affordance）往往是属性的函数，而非物体身份的查表。所以泛化的单位是**因子**，不是动作模态；R69 的 U_epi 度量「选哪个动作」，却测不出「我是否认错了物体的某个属性」。
> - **真实世界泛化**：从仿真到现实、光照/背景/传感器/摩擦/质量/本体的偏移，会让任何密度型信号（含 R69 的流似然）一起抬高。但**观测变了 ≠ 决策该变**；用密度替代不变性，会把「无害的分布漂移」误判成「危险」，也会把「密度内但决策已失真」的偏移完全漏掉。真正的泛化保证是**决策不变性**，不是表征相似度。
>
> 核心命题：**在 R69 的「动作模态」层之外，再加两层不确定性——物体因子支持层与世界决策不变层——并让三层按「世界 → 物体 → 动作」级联处置；只有高层被判定有效，低层的 VoI 才有意义。** 命名 **TERRA-RAS**（Tiered Epistemic Resolution for Real-world Adaptation）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这个物体、这个世界，还是我以为的那个吗**」——泛化不是训练结束后自动获得的属性，而是一张必须持续用「支持度 + 不变性」续费的证书。

## 0. 直觉与动机

**灵感 1（物体泛化 → 泛化不是「动作歧义」，是「我认错物体了吗」）**
直觉：R69 的 U_epi 只度量策略在动作空间里的多峰性。但把花瓶当杯子时，策略完全可能只有一个模态——「握杯身、往嘴里送」——歧义为零而错误极大。**低熵不等于正确；模态一致的同义词是「从同一个错误表征里一致地外推」。** 物体泛化的真正风险落在表征上，而不在动作上：未见过的材质（滑）、未见过的质心（偏）、未见过的关节（会动）、未见过的大小（抓不住）。因此需要一层**物体因子支持**：先把物体分解成可干预的属性因子 ψ=(形状, 材质, 关节, 质心, 尺度…)；只要每个因子都落在训练支持内，即使物体身份全新，功效也能按因子可加/可 Lipschitz 地泛化；反之，任意因子越界，动作层的「选模态」就是在给一个错误前提做精算。

**灵感 2（物体泛化 → 新颖性有两种，处置相反）**
直觉：同为「物不确定」，有两种本质不同的情形。**(a) 支持内功效歧义**：杯子可以从把手抓，也可以从杯口抓——两个模态都合法，看/问即可消解，这仍是 R69 的地盘。**(b) 因子支持外新颖性**：从没见过这种表面，它到底滑不滑？这不是「选哪个模态」，而是**支持集为空**——没有任何模态是可靠的，必须用探针去「测出」一个属性，或直接保守。把 (b) 误当 (a)，就是 R69 最危险的失效模式：拿一个不存在的后验去算 VoI。

**灵感 3（真实世界泛化 → 泛化不是「密度」，是「决策不变性」）**
直觉：R69 的流似然在真实世界偏移下会全线抬高——换了灯、换了桌面、换了相机，都会让「训练分布外的观测」得到低似然。若把低似然直接当危险，系统会对**完全无害的域偏移**过度保守、过度追问，utility 崩塌。反过来，一个在训练密度内、但动力学已变的场景（同款桌面但摩擦不同），密度信号完全看不出。正确的判据应是一个**决策充分统计量** T(o)：最优动作只通过 T 依赖 o。只要 p(T) 在偏移下稳定，决策就该稳定；若不稳定，才是决策相关的世界偏移。密度是「像不像训练集」，不变性是「决策会不会变」——泛化要的是后者。

**灵感 4（三层不确定性 → R69 是「无泛化偏移」的边界情形）**
直觉：把不确定性写成三分量 U=(U_mode, U_obj, U_world)。它们不是并列相加，而是**有包含关系**：世界层失效时，物体因子估计与动作后验都不可信（U_world≈∞ ⇒ U_obj/U_mode 无定义）；物体因子越界时，动作模态的 VoI 无意义（在错误前提上做选择）。因此处置必须是**级联/优先级**而不是加权求和：先判世界是否仍是这个世界，再判物体因子是否在支持内，最后才轮到 R69 的「看/问/触」。当 U_obj=U_world=0 时，TERRA 逐指令退化为 R69——R69 成为「无泛化偏移」边界。

**灵感 5（交互升级 → 从「问动作」到「探因子」）**
直觉：R69 的信息动作 g=(注视, 探针, 问句) 是通用的、面向动作模态的。物体泛化要求信息动作**面向属性因子**：转一转看是否有关节（形状/关节）、戳一下看屈服（材质/刚性）、抬一下看力矩（质心/质量）、捏一下看回弹（柔顺）。目标是最大化与**因子**的互信息 IG(ψ_f; y|g_f)，而不是与动作模态的互信息。这带来一个新约束：探针会改变物体状态（可能把物体推下桌、造成不可逆形变），所以必须加**非破坏性**约束 state-change ≤ ε_state——这是 R69 的「信息动作安全」没有覆盖的。

**灵感 6（对偶通道 → 把 R69 的 Δa 拆成物体项与世界项）**
直觉：R69 的 FMA 用一个标量 Δa=|a_score(o)−a_score(o_cal)| 当「标定不可吸收的第二意见」。但在真实世界偏移下，这个标量把两种东西混在一起：**物体新奇**与**上下文新奇**。于是同一盏灯变暗，既可能触发「缓变故障」误报（实际无害），也可能掩盖真正的物体异常。把流似然条件化分解 p_θ(ξ|ψ̂,ĉ)，得到 a_score≈a_obj+a_ctx+a_cross，再分别看 Δa_obj 与 Δa_ctx：Δa_ctx↑ 而 Δa_obj≈0 ⇒ 无害域偏移，不该过度保守；Δa_obj↑ ⇒ 物体层问题，该探因子。这是对 R69 最脆弱处（标量二意见不可分辨来源）的直接修补。

**灵感 7（泛化认证本身会被骗 → 新的威胁模型）**
直觉：一旦「支持度/不变性」变成放行依据，它就成了新的攻击面。对抗性物体可以用一个 patch 把新颖物体的因子表征伪装成支持内（伪支持）；训练里的捷径特征（纹理与材质的虚假相关）会让支持测试在因果上失效；「每个因子都见过、但组合从未见过」的组合爆炸会让逐因子支持全部通过而联合支持为空；而良性 OOD（新背景、新光照）会被过度保守，形成 utility 侧的「假阳性代价」。所以 TERRA 必须交付：**因果化（可干预）支持测试、联合支持（copula）检验、对抗裕度、以及「宁可不发证也不发假证」的证书纪律**。

**灵感 8（对 R69「k 源一致」的直接影响）**
直觉：R69 的证据纪律要求「k 个正交证据源一致」。但在物体/世界偏移下，多个证据源可能**共享同一个错误前提**（都用同一个被捷径污染的物体编码器），于是「一致」只是在重复同一个偏差。TERRA 要求证据的**正交性追到因子层**：不同证据必须约束不同因子、或在不同上下文 c 下采集，否则不计入 k。这与 R69 的「血缘正交」互补：R70 补的是**表征/上下文正交**。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（TERRA-RAS 总览）** TERRA-RAS = (TUC, FAD, OSG, WCG, H-VoI, APX, CFL, CGT, TTC, AIC-TERRA, J_TERRA, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **层级优先**：世界层未判定有效前，不得用物体/动作层结论驱动交互；物体层未判定有效前，不得用动作层 VoI 驱动交互；
(iii) **认证口径**：任何「可泛化」的主张必须同时携带支持裕度与不变性裕度，缺一即视为未认证；
(iv) **R69 包含**：当两层门均通过时，TERRA 逐指令等于 R69（定义 326）。

**定义 311（因子化物体表征 FAD）** 物体观测 o_obj 经编码器 E_obj 得到可干预属性因子 ψ = (ψ_shape, ψ_material, ψ_articulation, ψ_mass, ψ_scale) ∈ Ψ = Π_f Ψ_f。因子是**因果干预靶点**（定义 324），不是任意潜维：每个 ψ_f 对应一组可实施的干预（转/戳/抬/捏），且功效预测器 F(ψ) 对每个因子 Lipschitz（A100）。

**定义 312（逐因子支持与新颖度 OSG）** 对因子 f 用校准集得到共形分数 s_f(o)；新颖度 δ_f = 1 − p_f，其中 p_f = (1 + #{cal: s ≥ s_f})/(n+1)。支持集 S_f = {δ_f ≤ τ_f}。物体层不确定性 U_obj = Σ_f w_f · φ(δ_f)，φ 单调增、φ(τ_f)=0。可约/不可约据此再分：δ_f ≤ τ_f 下的功效多峰仍属 R69 的 U_epi；δ_f > τ_f 属「支持外」，不可用选模态消解。

**定义 313（世界上下文与决策充分统计量 WCG）** 世界上下文 c（光照、背景、传感器、摩擦、质量、本体）；决策充分统计量 T=h(o)，满足 π*(a|o)=π*(a|T(o))（A99）。世界偏移为 p(c)≠p_train(c)。不变性裕度 I_w = sup_A |P(T∈A|c) − P(T∈A|c_ref)|（总变差），决策翻转上界 flip_upper 由 I_w 与风险映射的 Lipschitz 常数给出。

**定义 314（三层不确定性 TUC）** U_world = flip_upper（或风险加权的不变性违反量）；U_obj 如定义 312；U_mode = H_mode·g(Δ_min)（继承 R69 定义 297）。优先级：U_world>τ_w ⇒ 物体/动作层结论作废；U_obj>τ_o ⇒ U_mode 的 VoI 作废。三者分别进入不同通道，不做标量加和。

**定义 315（层级信息价值 H-VoI）** 对层 k∈{world, obj, mode} 与候选处置 r，定义 VoI_k(r)=E[risk(π|o) − risk(π|o,y)]。选择 (k*,r*)=argmax_{k,r}[VoI_k(r)−c_k(r)]，**受优先级约束**：若更高层未判定有效，则低层 VoI 置为 −∞。若无利可图 ⇒ 不交互，进入对应层兜底（定义 320）。这给出「先修世界、再探物体、最后问动作」的级联，而非并行枚举。

**定义 316（属性探针 APX）** 探针 g_f∈𝒜_probe 定向作用于因子 f：旋转/平移（形状、关节）、戳（材质、刚性）、抬/称（质心、质量）、挤/捏（柔顺）。目标 g_f* = argmax_g IG(ψ_f; y|g) − c(g)，s.t. **非破坏性** state-change(g) ≤ ε_state、C-RAS-WM‡ 认证、预算未超。探针失败/超时 ⇒ 该因子保持未消解。

**定义 317（上下文因子化流似然 CFL）** 以 (ψ̂,ĉ) 条件化分解流似然：a_score(ξ|o) ≈ a_obj(ξ|ψ̂) + a_ctx(ξ|ĉ) + a_cross。定义 Δa_obj = |a_obj(o) − a_obj(o_ref)|、Δa_ctx = |a_ctx(o) − a_ctx(o_ref)|。判据：Δa_ctx↑ ∧ Δa_obj≈0 ⇒ 无害域偏移；Δa_obj↑ ⇒ 物体层问题；两者同升且 r_res↓ ⇒ 延续 R69 的缓变故障疑。

**定义 318（组合泛化证书 CGT）** 设功效预测 F 对各因子 Lipschitz 常数 L_f，新组合 ψ* 的逐因子最近邻距离 δ_f，联合支持裕度 δ_joint（定义 325）。组合误差上界 |F(ψ*)−F(ψ_NN)| ≤ Σ_f L_f δ_f + ε_joint；证书仅在 ∀f: δ_f≤τ_f 且 δ_joint≤τ_joint 时有效，否则记为「无证书」。ε_joint 度量「因子都见过但组合没见过」的额外间隙。

**定义 319（迁移信任证书 TTC）** TTC = (I_w, flip_upper, ref_contexts, n_ref)。用于世界层：flip_upper≤τ_flip ⇒ 世界不变、允许进入物体层；否则世界层兜底。证书由多上下文参考集计算，并记录参考覆盖度，避免在「只在单一上下文校准过」时给出虚假信任。

**定义 320（分层保守兜底）** 三层各有兜底，且**只收紧不放松**：(a) 世界未解 ⇒ 全局保守：继承 R68 λ_floor、拒绝主动交互、按需请求接管/重标定；(b) 物体未解 ⇒ 物体保守：限速、限力、避开依赖未知因子的功效（如对未知材质不做高摩擦假设），但允许不触及该因子的任务动作；(c) 动作未解 ⇒ R69 的 λ_floor(U_ale+U_epi)。任一层兜底都不得使安全包络弱于 R68。

**定义 321（泛化证书 J_TERRA）** J_TERRA = (J_FLUID, {δ_f}, δ_joint, I_w, flip_upper, Δa_obj, Δa_ctx, tier_decisions, probe_log_hash, gen_ver)。Valid ⇔ Valid(J_FLUID) ∧ 支持与不变性裕度达标 ∧ 层级纪律满足 ∧ 非破坏性探针约束满足。**证书纪律**：任一必需裕度缺失或不可信 ⇒ 判为无效，绝不以「看起来对」补签。

**定义 322（泛化威胁模型 AIC-TERRA）** ℰ_TERRA = ℰ_FLUID × ℰ_gen，ℰ_gen = {伪支持 adversarial object、捷径特征 spurious shortcut、组合爆炸 compositional explosion、良性偏移过度保守 benign-shift over-conservatism、仿真-现实残差 sim-to-real residual、因子纠缠 factor entanglement}。每个威胁对应一条证书检查。

**定义 323（层级预算账本 TLG）** 交互预算按层分配：世界层处置最稀有但最贵，物体层探针居中，动作层问句最便宜。采用注水式（water-filling）分配，账本记录各层消耗与「饥饿」状态；高层长期未获预算 ⇒ 提升其在下一轮的先验权重，但不得突破总预算与安全约束。

**定义 324（因果化支持测试）** 支持测试不能只看密度，要看**干预一致性**：对因子 f 的估计应在对其它因子做已知干预（数据增广或机器人自身动作）时保持稳定；若不稳定，则该估计被捷径污染，δ_f 打折（视为更不可信）而非更可信。形式化：causal_support_f = δ_f + ρ·instability_f，ρ>0。

**定义 325（联合支持 copula 检验）** 记各因子经验分布 F_f，联合新颖度 δ_joint = max_f δ_f + λ·(−log C(F_1(δ_1),…,F_d(δ_d)))，其中 C 为校准集上的 copula 密度。单项都低但 copula 密度极低 ⇒ 组合从未见过，δ_joint 抬高，阻止「逐因子全通过却组合失效」。

**定义 326（R69 退化边界）** 当 U_world≤τ_w 且 U_obj≤τ_o（两层门通过）时，TERRA 的采样、VoI、λ、证书均与 R69 相同（同一 K、同一预算、同一随机源），且 J_TERRA 包含 J_FLUID。故 R69 = TERRA 在「物体/世界均在支持内」边界上的严格退化。

```python
# IP-264 TUC：三层不确定性（廉价优先，昂贵后置）
def tiered_uncertainty(o, policy, obj_model, ctx_model):
    psi, delta = obj_model.factorize_and_score(o)      # 逐因子新颖度
    U_obj  = sum(w[f] * phi(delta[f]) for f in FACTORS)
    T      = ctx_model.decision_sufficient(o)          # A99 的 T(o)
    I_w, flip = ctx_model.invariance_margin(T)         # 世界不变性裕度
    U_world = flip
    z      = policy.trunk(o)
    K      = 1 if policy.mode_head(z) < TAU_MODE else 4
    modes  = policy.sample(o, K)
    U_mode = entropy(mode_weights(modes)) * sep_factor(modes)
    return psi, delta, (U_mode, U_obj, U_world), modes

# IP-268 H-VoI：层级优先，不满足优先级则低层无定义
def tiered_voi(state, budget):
    tiers = [('world', world_candidates(state)),     # 重标定/降级/接管
             ('obj',   probe_candidates(state)),     # 转/戳/抬/捏
             ('mode',  ask_candidates(state))]       # R69 的看/问
    for tier, cands in tiers:
        if not tier_valid(tier, state):              # 高层未判定 ⇒ 低层作废
            continue
        best = max((c for c in cands if budget.allow(c)),
                   key=lambda c: voi(c) - cost(c), default=None)
        if best is not None and voi(best) - cost(best) > 0:
            return tier, best
    return None, None

# IP-269 APX：面向最不确定的因子做探针，非破坏性
def attribute_probe(psi, delta, o, budget):
    f = argmax(delta, key=lambda k: delta[k])        # 最可疑的因子
    g = argmax(probes_for(f), key=lambda g: IG_f(psi[f], g) - cost(g))
    if not c_ras_wm.certify_probe(g, o):             # 运动学/力/位包络
        return psi, delta
    if not non_destructive(g, o, eps_state):         # 非破坏性约束
        return psi, delta
    y = execute(g)
    psi[f], delta[f] = obj_model.update(f, y)
    return psi, delta

# IP-270 CFL：把 R69 的标量 Δa 分解为物体项/上下文项
def factorized_flow_anomaly(policy, xi, o, o_ref, psi_hat, c_hat):
    a_obj = policy.log_likelihood(xi, o, cond=('obj', psi_hat))
    a_ctx = policy.log_likelihood(xi, o, cond=('ctx', c_hat))
    return abs(a_obj - policy.log_likelihood(xi, o_ref, cond=('obj', psi_hat))), \
           abs(a_ctx - policy.log_likelihood(xi, o_ref, cond=('ctx', c_hat)))

# IP-276 主闭环：世界 → 物体 → 动作 的级联
def TERRA_RAS_round(M, obs):
    psi, delta, (U_mode, U_obj, U_world), modes = M.tuc.tiered(obs)
    # tier 0：世界是否还是这个世界
    if U_world > TAU_W:
        return M.tuc.world_fallback(obs)             # R68 全局保守 + 请求接管
    # tier 1：物体因子是否在支持内（含联合支持）
    if U_obj > TAU_O or joint_novelty(delta) > TAU_JOINT:
        tier, g = M.hvoi.select(obs, M.budget)       # 只允许 world/obj 层
        if tier == 'obj' and g is not None:
            psi, delta = M.apx.execute(g, psi, delta)
            U_obj = recompute_obju(delta)
        if U_obj > TAU_O or joint_novelty(delta) > TAU_JOINT:
            return M.tuc.object_conservative(modes, psi)  # 限速/限力/避开新功效
    # tier 2：R69 内环（动作模态级）
    d_obj, d_ctx = M.cfl.flow_anomaly(M.fmp, M.last_action, obs, M.o_ref, psi, M.c_hat)
    # R69 的 Δa 由 (d_obj + d_ctx) 取代；语义更细
    U_epi = U_mode * sep_factor(modes)
    g = (M.mint.choose_interaction(modes, obs, M.budget)
         if U_epi > TAU_EPI else None)
    if g is not None:
        U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    U_floor = U_ale(modes) + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., M.wm_preds)
    mode = select_mode(modes, U_epi, lam)
    M.vqa_i.submit_async(g, U_epi, d_obj, d_ctx)
    return k, lam, mode, (U_obj, U_epi, U_world)
```

## 3. 推导

**引理 19（R69 在物体偏移下的 confident-but-wrong）** 存在物体偏移使 H_mode→0、Δ_min≥3σ_in（R69 判为「不歧义、可执行」），而期望功效误差有正下界。构造：训练集只含「杯形且刚体」的物体；测试物体为同外形但软质/低摩擦，功效预测器从最近的杯形样本外推，所有流模态收敛到同一轨迹（杯身抓取）。此时 U_mode≈0，但执行滑脱概率→1。故 **U_mode 不是风险在物体偏移下的单调代理**；R69 的 VoI 会因「不歧义」而不交互，恰好在最该求证时沉默。

**引理 20（因子化支持泛化界）** 在 A100（F 对各因子 L_f-Lipschitz）且联合支持成立时，新组合 ψ* 相对最近邻 ψ_NN 的功效误差 ≤ Σ_f L_f δ_f + ε_joint；若存在 δ_f>τ_f 或 δ_joint>τ_joint，则上界失效（记为无证书，定义 318）。系：**可约性来自「因子在支持内」，不来自「物体身份相似」**；这解释了为什么实例级/类别级 OOD 检测会漏掉「熟悉的零件、陌生的组合」。

**引理 21（无害偏移与决策相关偏移的可分性）** 在 A99 下，若 p(T) 在偏移下不变，则决策分布在风险 Lipschitz 意义下变化 ≤ L·TV(p(T),p_ref(T))=0；而流似然 a_score 可在 p(T) 不变时任意抬高。因此**仅凭密度/似然不能判别决策相关性**；CFL 的 Δa_ctx 可吸收无害偏移、Δa_obj 保留物体相关分量，使无害偏移下的假保守率 ≤α（校准后），同时不牺牲物体异常的检出。这是对 R69 FMA 标量二意见的可辨识性修复。

**引理 22（级联 H-VoI 的占优性）** 在 A100–A101（下层处置的价值在高层未判定有效时为零，且风险对层间误差单调）下，带优先级约束的顺序 VoI 选择不少于任何同等预算的并行分配；证明用交换论证：把一个低层处置的预算换给一个能判定高层有效的处置，期望风险不增。系：**预算应优先买「让后面所有估计变可信」的那一层**，而非平均撒在动作层。

**定理 18（TERRA 严格包含 R69）** 在 A95–A101 下：当 U_world≤τ_w 且 U_obj≤τ_o 时，TERRA 与 R69 逐指令相同（定义 326）；当任一门失败时，TERRA 进入对应层的保守兜底，其风险不超过 R68 安全包络，而 R69 可能因引理 19 的 confident-but-wrong 超出该包络。故对任意状态，TERRA 的期望风险 ≤ R69，且安全侧不做让步。

**定理 19（探针安全与无突变）** 属性探针经受 C-RAS-WM‡ 认证且满足非破坏性约束后，物理风险 ≤ ε_probe、状态改变 ≤ ε_state；探针只改变「因子估计」，不改变安全包络；探针失败/超时/被伪支持欺骗时，λ 单调不降地退化为物体保守；提交/换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变。

**定理 20（证书可靠性 / 反「泛化剧场」）** 若 J_TERRA 判 Valid，则要么两层裕度真实达标，要么已走对应层兜底；当对抗/捷径/组合威胁的强度超过证书裕度（定义 322 的检查失败）时，J_TERRA 判为**无效**而非 Valid。即：证书体系在裕度被击穿时不产生假阳性认证——但该保证**以因子化与不变性统计量本身正确为前提**（见第 6 节最大风险）。

## 6. 本轮最大风险

**一句话**：TERRA 的全部保证都押在「因子分解是对的、且存在可用作门控的决策充分不变统计量」这一前提上——**若真实功效依赖某个不在 ψ 里的因子（整体形状、接触构型、任务语义），或捷径特征本身在上下文间恰好不变，那么支持门与不变性门就会恰好给那些泛化本该防住的物体/世界盖上「已认证」的章，级联还会把有限的探针预算花在错误的层上**；这是一种比 R69 更危险的失效——R69 至少是「诚实的不知道」，而 TERRA 会产出**泛化剧场**（generalization theater），用已知因子的支持度为未知物体背书。

**次级风险与缓解**：
1. **因子分解不完备 / 因子纠缠** → 定义 311/324 的干预一致性检验 + 残差因子通道；裕度不足即判无证书；
2. **伪支持与对抗物体** → 定义 322 的对抗裕度 + 引理 20 的联合支持（copula）+ 证书纪律（宁可不发证）；
3. **良性偏移被过度保守** → 定义 317 的 Δa_ctx/Δa_obj 分解 + E305 假保守预算，禁止用密度替代不变性；
4. **组合爆炸漏检** → 定义 325 联合支持 + E302；
5. **探针破坏物体/越界** → 定义 316 非破坏性约束 + C-RAS-WM‡ 认证 + 定理 19；
6. **真实世界无可穷尽支持** → 承认证书是外推：只在「不变性裕度 + 支持裕度」双达标时放行，否则退回 R68 保守，绝不声称全局泛化。

**定义 325（联合支持 copula）** `δ_joint = max_f δ_f + λ·(−log C(F_1(δ_1),…,F_d(δ_d)))`；逐因子通过但组合未见过 ⇒ δ_joint 抬高。

**定义 326（R69 退化边界）** `U_world≤τ_w ∧ U_obj≤τ_o` ⇒ 采样/VoI/λ/证书与 R69 相同，且 J_TERRA ⊇ J_FLUID；R69 = TERRA 的「无泛化偏移」边界。

```python
# IP-264 TUC：三层不确定性（廉价优先）
def tiered_uncertainty(o, policy, obj_model, ctx_model):
    psi, delta = obj_model.factorize_and_score(o)
    U_obj = sum(w[f]*phi(delta[f]) for f in FACTORS)
    T = ctx_model.decision_sufficient(o)                 # A99
    I_w, flip = ctx_model.invariance_margin(T)
    z = policy.trunk(o)
    K = 1 if policy.mode_head(z) < TAU_MODE else 4
    modes = policy.sample(o, K)
    U_mode = entropy(mode_weights(modes)) * sep_factor(modes)
    return psi, delta, (U_mode, U_obj, flip), modes

# IP-268 H-VoI：层级优先（高层未判定 ⇒ 低层 −∞）
def tiered_voi(state, budget):
    for tier, cands in [('world', world_candidates(state)),
                        ('obj',   probe_candidates(state)),
                        ('mode',  ask_candidates(state))]:
        if not tier_valid(tier, state):                  # 优先级约束
            continue
        best = max((c for c in cands if budget.allow(c)),
                   key=lambda c: voi(c)-cost(c), default=None)
        if best is not None and voi(best)-cost(best) > 0:
            return tier, best
    return None, None

# IP-269 APX：定向最可疑因子，非破坏性
def attribute_probe(psi, delta, o):
    f = argmax(delta, key=lambda k: delta[k])
    g = argmax(probes_for(f), key=lambda g: IG_f(psi[f], g)-cost(g))
    if not c_ras_wm.certify_probe(g, o): return psi, delta
    if not non_destructive(g, o, eps_state): return psi, delta
    psi[f], delta[f] = obj_model.update(f, execute(g))
    return psi, delta

# IP-270 CFL：标量 Δa 分解为物体/上下文两项
def factorized_flow_anomaly(policy, xi, o, o_ref, psi, c):
    a_obj = policy.log_likelihood(xi, o, cond=('obj', psi))
    a_ctx = policy.log_likelihood(xi, o, cond=('ctx', c))
    return (abs(a_obj-policy.log_likelihood(xi, o_ref, cond=('obj', psi))),
            abs(a_ctx-policy.log_likelihood(xi, o_ref, cond=('ctx', c))))

# IP-276 主闭环：世界 → 物体 → 动作
def TERRA_RAS_round(M, obs):
    psi, delta, (U_mode, U_obj, U_world), modes = M.tuc.tiered(obs)
    if U_world > TAU_W:                                   # tier 0
        return M.tuc.world_fallback(obs)                  # R68 全局保守 + 接管
    if U_obj > TAU_O or joint_novelty(delta) > TAU_JOINT: # tier 1
        tier, g = M.hvoi.select(obs, M.budget)
        if tier == 'obj' and g is not None:
            psi, delta = M.apx.execute(g, psi, delta)
            U_obj = recompute_obju(delta)
        if U_obj > TAU_O or joint_novelty(delta) > TAU_JOINT:
            return M.tuc.object_conservative(modes, psi)  # 限速/限力/避开新功效
    d_obj, d_ctx = M.cfl.flow_anomaly(M.fmp, M.last_action, obs, M.o_ref, psi, M.c_hat)
    U_epi = U_mode * sep_factor(modes)                    # tier 2：R69 内环
    g = (M.mint.choose_interaction(modes, obs, M.budget) if U_epi > TAU_EPI else None)
    if g is not None:
        U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    U_floor = U_ale(modes) + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., M.wm_preds)
    mode = select_mode(modes, U_epi, lam)
    M.vqa_i.submit_async(g, U_epi, d_obj, d_ctx)
    return k, lam, mode, (U_obj, U_epi, U_world)
```

## 4. 推导

**引理 19（R69 在物体偏移下的 confident-but-wrong）** 存在物体偏移使 U_mode≈0（H_mode→0、Δ_min≥3σ_in）而期望功效误差有正下界。构造：训练仅含「杯形刚体」，测试为同形软质/低摩擦物体；流模态一致收敛到杯身抓取。故 U_mode 不是风险在物体偏移下的单调代理，R69 的 VoI 恰在最该求证时沉默。

**引理 20（因子化支持泛化界）** A100 下，新组合 ψ* 的功效误差 ≤ Σ_f L_f δ_f + ε_joint，仅当 ∀f δ_f≤τ_f 且 δ_joint≤τ_joint；否则上界失效（无证书）。系：可约性来自「因子在支持内」，而非「物体身份相似」——实例/类别 OOD 会漏掉「熟悉的零件、陌生的组合」。

**引理 21（无害偏移与决策相关偏移可分）** A99 下若 p(T) 不变，则决策分布变化 ≤ L·TV=0；而 a_score 可在 p(T) 不变时任意抬高。故仅凭密度/似然不可判决策相关性；CFL 的 Δa_ctx 吸收无害偏移、Δa_obj 保留物体分量，使假保守率 ≤α 且不牺牲异常检出。

**引理 22（级联 H-VoI 占优）** A100–A101 下，带优先级约束的顺序 VoI 不少于同等预算的并行分配（交换论证：把低层预算换给能判定高层有效性者，期望风险不增）。系：预算优先买「让后续估计变可信」的那一层。

**定理 18（TERRA 严格包含 R69）** A95–A101 下：两层门通过时逐指令等于 R69；任一门失败时进入分层保守兜底，风险不超过 R68 安全包络，而 R69 可能因引理 19 超出该包络。故任意状态 TERRA 期望风险 ≤ R69，安全侧不让步。

**定理 19（探针安全与无突变）** 探针经 C-RAS-WM‡ 认证且非破坏 ⇒ 物理风险 ≤ε_probe、state-change ≤ε_state；只改因子估计不改安全包络；失败/超时/伪支持 ⇒ λ 单调不降退化为物体保守；换装不变式（R68 定理 15）保持 ⇒ 控制连续无突变。

**定理 20（证书可靠性 / 反泛化剧场）** J_TERRA 判 Valid ⇒ 要么两层裕度真实达标，要么已走对应层兜底；当对抗/捷径/组合威胁超过证书裕度（定义 322 检查失败）时判**无效**而非 Valid。故证书体系不在裕度被击穿时产生假阳性认证——但该保证以「因子化正确、存在可用决策充分不变统计量」为前提（见第 7 节）。

## 7. 本轮最大风险

**一句话**：TERRA 的全部保证押在「因子分解正确、且存在可用作门控的决策充分不变统计量」这一前提上——**若真实功效依赖某个不在 ψ 里的因子（整体形状、接触构型、任务语义），或捷径特征在上下文间恰好不变，那么支持门与不变性门就会恰好给泛化本该防住的物体/世界盖上「已认证」的章，级联还会把探针预算花在错误的层上**；这比 R69 更危险——R69 至少是「诚实的不知道」，而 TERRA 会产出**泛化剧场**，用已知因子的支持度为未知物体背书。

**次级风险与缓解**：因子分解不完备/纠缠（定义 311/324 干预一致性 + 残差因子通道，裕度不足判无证书）；伪支持/对抗物体（定义 322 对抗裕度 + 定义 325 联合支持 + 证书纪律）；良性偏移过度保守（定义 317 Δa_obj/Δa_ctx 分解 + E305）；组合爆炸漏检（定义 325 + E302）；探针破坏/越界（定义 316 非破坏性 + C-RAS-WM‡ + 定理 19）；真实世界支持不可穷尽（只在不变量+支持双达标时放行，否则退 R68 保守，绝不声称全局泛化）。
