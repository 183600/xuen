# 第 61 轮（承接第 60 轮 SGEC IP-153~160；灵感循环第 7 轮；本轮灵感：「论文创新点」×「力控」）

> 复盘：第 59~60 轮把系统堆成「执行接地 → 场景-认知闭环」三层（BUQ/ERTC/EEIS/CLEP/XMC/PCE+++/SSM/CIEC/EPIR/SERC），但**创新点正在通胀**：缩写数量线性增长，「这篇论文到底主张什么」却越来越模糊。第 61 轮做一次**归约（reduction）**：用「论文创新点」逼问"在一条已被接受的评估轴上，可证伪的增量是什么"；用「力控」指定唯一承载增量的物理战场——**接触力控制**。

## 0. 直觉与动机

**灵感 1（论文创新点 → 创新点不是缩写，而是"评估轴上的可证伪增量"）**
直觉：审稿人不会为"又加了一个模块"买单，只会为"在一条已被接受的轴（稳定性/精度/代价/适用域）上，你比 SOTA 多走了可测量、且能被实验打败的一步"买单。于是把创新点写成四元组 N=(G, M, E, ΔP)：缺口 G、机制 M、证据 E、相对先验增量 ΔP。关键判据：**若 ΔP 无法被基线实验区分，则 M 再精巧也等于 0**。由此引出"创新点序"：两个方案若在合理基线下不可区分，则在论文意义上等价。

**灵感 2（力控 → 力控的硬核三难）**
直觉：力控真正难的不是"调 K/B"，而是三件事：
(a) **接触瞬态冲击**：自由空间→接触的刚度跳变，力尖峰 F_peak 决定安全；
(b) **刚度不确定下的耦合稳定**：环境刚度 K_e 可能跨一个数量级，K_r 选大则失稳、选小则跟踪差；
(c) **饱和/摩擦下的力跟踪**：执行器饱和破坏线性假设，摩擦带来死区。
第 59~60 轮的 BUQ（在线辨识不确定）、ERTC（契约化实时约束）、EEIS（阻抗编译）、J_exec（执行证书）恰好一一对位这三难——**这正是被缩写淹没的创新点**。

**灵感 3（合流 → 唯一主定理：契约可证明力控 CPFC）**
直觉：不要再报"8 个新模块"。把全部基础设施压到**一个可证伪主定理**上：
> **CPFC 主定理（待证）**：若环境刚度被 BUQ 约束在 K̂_e=[k_min,k_max]，ERTC 契约 C_rt 强制 (B_r, x_max, F_safe, T_s)，EEIS 在 C_rt 内编译 (K_r,B_r)，则接触闭环对所有 K_e∈K̂_e 鲁棒无源（μ>0），稳态力跟踪误差
> ε_F = F_d · max_{k_e∈K̂_e} K_r|k_e−k_0| / (k_0(K_r+k_e))，
> 且该界**紧**（最坏 K_e 取等）、**可消融**（去掉 BUQ/ERTC/J_exec 任一，界严格变坏）。
一句话创新点：**把力控从"参数整定"提升为"可编译、可证明、可消融的契约"**。其余模块退居"支撑该定理的基础设施"，不再是独立创新点。

**灵感 4（从"堆叠"到"归约" → 创新点归约算子 Reduce）**
直觉：给 60 轮的每个模块贴一个"存在理由"：(T) 收紧主定理的界；(W) 拓宽适用域（刚性→柔性、准静态→动态）；(C) 降低证据成本（算力/时延/通信）；(N) 都不是→降级为工程细节或删除。Reduce 的输出是一张**创新点依赖图**，保证每个保留模块都能回答"删了你，哪条实验会变差"。

**灵感 5（可证伪 → 力控证伪台 + 基线不可区分性检验）**
直觉：论文必须有一个"主张为假就必然失败"的最小实验。设计**力控证伪台 Falsification Bench**：同一任务、同一扰动序列下比较 (i) 经典阻抗、(ii) 自适应阻抗、(iii) 学习式变阻抗、(iv) CPFC。若 (i)~(iii) 任一在没有 ERTC/J_exec 的情况下也达到相同 μ 与 ε_F，则 CPFC 的 ΔP 被证伪。**证伪台先于理论**：先设计能打败自己的实验，再决定定理怎么写。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（创新点四元组与创新点序）** N=(G,M,E,ΔP)，E=(metric, baseline set, threshold, CI)。定义不可区分关系：N₁ ≡_B N₂ 当且仅当在基线集 B 上 E₁、E₂ 无法以给定置信度分离。定义优势序：N₁ ≻ N₂ 当 N₁ 至少一条轴上严格更优且在其余轴上不劣。**只有 ≻ 非空的 N 才可写入论文贡献列表。**

**定义 162（接触耦合模型与鲁棒无源裕度）** 机器人阻抗 Z_r(s)=M_r s+B_r+K_r/s；环境 Z_e(s)=K_e+B_e s。闭环鲁棒无源当且仅当对 ∀K_e∈K̂_e、∀ω：Re[Z_r(jω)+Z_e(jω)]≥0。采样数据下的充分条件取
B_r ≥ B_min(M_r,K_r,k_max,T_s) = 2√(M_r)·max(ζ_min√K_r, √k_max) + k_max·T_s/2，
定义无源裕度 μ = (B_r − B_min)/B_min，μ>0 为可行。

**定义 163（契约可证明力控 CPFC）** 编译器 CERT：(Ξ, C_rt, δ_f) → (K_r*, B_r*, ε_F, μ, J_cpfc)，其中 Ξ 为 BUQ 输出的不确定集，C_rt=(B_max,x_max,F_safe,T_s)，δ_f 为力跟踪需求。J_cpfc 为机器可检的执行证书，包含 (Ξ,C_rt,K_r*,B_r*,ε_F,μ, 证据哈希)。要求三条性质：**可靠性**（证书通过 ⇒ 主定理前提成立）、**紧性**、**可消融性**。

**定义 164（紧性 Tightness）** 若 ε_F 的界无法被任何合法 (K_r,B_r) 在不违反 C_rt 的前提下进一步收紧，且存在 K_e*∈K̂_e 与轨迹使 |F−F_d|=ε_F，则称该界紧。紧性缺口 gap_tight = |ε_F^certified − ε_F^achieved|。

**定义 165（创新点归约算子 Reduce）** Reduce:(模块集, 证伪台) → 依赖图 D。规则：m 若无法归入 {TIGHTEN,WIDEN,CHEAPEN} 或消融后主定理不变坏，则标记 DEMOTE。D 中每条边 m→claim 标注它收紧的是 ε_F 还是提高的是 μ。

**定义 166（力控证伪台 Falsification Bench）** B_f=(任务族, 扰动序列, 基线集, 判别度量 d, 阈值 τ_d)。判别度量取 d=(μ, ε_F, F_peak, T_settle)。**CPFC 被判据存活**当且仅当对每个基线 b∈B_f：b 无法同时满足 μ_b≥μ_cpfc ∧ ε_F,b≤ε_F,cpfc ∧ F_peak,b≤F_peak,cpfc（除非 b 使用了被消融模块）。

**定义 167（消融必要性）** 模块 m 必要，当且仅当移除 m 后，证伪台上 ε_F 增大 > ρ_ε 或 μ 降到 ≤0 或 F_peak 增大 > ρ_F；否则 m 为工程细节（DEMOTE）。

**定义 168（论文证据台账 Evidence Ledger）** 行 L=(claim_id, metric, baseline, effect_size, CI, artifact_hash, grade)。grade A：可复现且在证伪台存活；B：仅仿真；C：仅单例。**贡献列表只允许引用 grade A/B。**

### IP-162 鲁棒无源界

```python
def robust_passivity(M_r, K_r, B_r, k_max, Ts, zeta_min=0.7):
    B_min = 2*np.sqrt(M_r)*max(zeta_min*np.sqrt(K_r), np.sqrt(k_max)) \
            + k_max*Ts/2.0
    mu = (B_r - B_min) / B_min
    return mu, B_min
```

### IP-163 CPFC 证书编译器

```python
def cpfc_certify(xi, C_rt, delta_f, force_model):
    K_hat = xi.env_stiffness_interval          # [k_min, k_max], 来自 BUQ
    k0 = xi.nominal_k
    best = None
    for K_r in grid(C_rt.K_min, C_rt.K_max):
        B_r = max(C_rt.B_min,
                  2*sqrt(M_r)*max(ZETA_MIN*sqrt(K_r), sqrt(K_hat.hi))
                  + K_hat.hi*C_rt.Ts/2)
        if B_r > C_rt.B_max:
            continue
        mu, _ = robust_passivity(M_r, K_r, B_r, K_hat.hi, C_rt.Ts)
        if mu <= 0 or penetration(K_r, k0, delta_f) > C_rt.x_max:
            continue
        if impact_peak(K_r, B_r, K_hat) > C_rt.F_safe:
            continue
        eps_F = max(force_model.err(K_r, k, k0, delta_f)
                    for k in (K_hat.lo, K_hat.hi))
        cand = Cert(K_r, B_r, mu, eps_F)
        if best is None or cand.eps_F < best.eps_F:
            best = cand
    if best is None:
        return INFEASIBLE               # 触发 ERTC 降级
    best.tight = tightness_gap(best, K_hat, force_model) <= TAU_TIGHT
    return best
```

### IP-164 紧性探针

```python
def tightness_gap(cert, K_hat, force_model):
    worst = max((K_hat.lo, K_hat.hi),
                key=lambda k: force_model.err(cert.K_r, k, K_hat.nom,
                                              cert.delta_f))
    return abs(force_model.err(cert.K_r, worst, K_hat.nom, cert.delta_f)
               - cert.eps_F)
```

### IP-165 证伪与消融

```python
def falsify(cert, bench):
    for b in bench.baselines:                   # 经典/自适应/学习阻抗
        if (b.mu >= cert.mu and b.eps_F <= cert.eps_F
                and b.F_peak <= cert.F_peak and not b.uses_ablated_module):
            return FALSIFIED(b)                 # 基线不可区分 => ΔP = 0
    for m in cert.support_modules:              # BUQ / ERTC / J_exec
        d_eps, d_mu = ablation_necessity(m, bench)
        if d_eps <= RHO_EPS and d_mu <= 0:
            return MODULE_UNNECESSARY(m)
    return SURVIVES
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| Reduce (IP-161) | O(\|M\|·\|B\|) | O(\|M\|) | 每个保留模块有非空消融证据 |
| Passivity (IP-162) | O(1) | O(1) | B≥B_min ⇒ 鲁棒无源（充分） |
| CPFC Cert (IP-163) | O(G·\|K̂_e\|) | O(1) | 证书通过 ⇒ 主定理前提 |
| Tightness (IP-164) | O(\|K̂_e\|) | O(1) | 端点取极值（静态误差单调） |
| Falsify (IP-165) | O(\|B_f\|·\|support\|) | O(\|B_f\|) | 存活 ⇒ ΔP 未被基线抹平 |

**静态力误差推导（用于 ε_F）**：线性接触下，机器人弹簧 F=K_r(x_r−x)、环境 F=K_e x，平衡得 F(k_e)=K_r k_e x_r/(K_r+k_e)。按名义 k_0 选 x_r 使 F(k_0)=F_d，则
F(k_e)/F_d = k_e(K_r+k_0)/(k_0(K_r+k_e))，
故相对误差
e(k_e) = K_r|k_e−k_0| / (k_0(K_r+k_e))，
ε_F = F_d · max_{k_e∈{k_min,k_max}} e(k_e)。因 e 对 k_e 在区间端点取极值，界可精确计算且在最坏 K_e 处取等（**紧**）。

**命题 CPFC（证明骨架）**：
1. *鲁棒无源*：B_r≥B_min 使阻尼比 ζ≥ζ_min 且覆盖采样保持相位滞后，由无源性定理闭环 L2 稳定。
2. *跟踪界*：由上面静态推导，∀K_e∈K̂_e 有 |F−F_d|≤ε_F。
3. *紧性*：e(k_e) 在端点取极值，最坏 K_e 取等；无合法 K_r 更优（否则 ε_F 非最小）。
4. *可消融*：
   - 去 BUQ ⇒ K̂_e 退化为单点或过宽：过宽使 ε_F↑ 且可能 μ≤0；单点使最坏情形失配 ⇒ F_peak↑。
   - 去 ERTC ⇒ B_r、x_max、F_safe 无强制 ⇒ 存在 K_e 使 μ≤0 或穿透超限。
   - 去 J_exec ⇒ 证书不可检 ⇒ 可靠性前提不可验证（证据降为 C）。
5. *张力（论文卖点）*：K_r↓ 使 e(k_e)↓ 但穿透 x_r↑、扰动抑制↓；K_r↑ 使 e(k_e)↑ 且冲击↑。CPFC 编译的正是**同时满足 μ>0、x_r≤x_max、F_peak≤F_safe 的最小 ε_F 点**——这是"可证明的折中"，而非经验调参。

```python
def cpfc_certify(xi, C_rt, delta_f, force_model):
    K_hat, k0 = xi.env_stiffness_interval, xi.nominal_k
    best = None
    for K_r in grid(C_rt.K_min, C_rt.K_max):
        B_r = max(C_rt.B_min,
                  2*sqrt(M_r)*max(ZETA_MIN*sqrt(K_r), sqrt(K_hat.hi))
                  + K_hat.hi*C_rt.Ts/2)
        if B_r > C_rt.B_max:
            continue
        mu, _ = robust_passivity(M_r, K_r, B_r, K_hat.hi, C_rt.Ts)
        if mu <= 0:                                    continue
        if penetration(K_r, k0, delta_f) > C_rt.x_max: continue
        if impact_peak(K_r, B_r, K_hat) > C_rt.F_safe: continue
        eps_F = max(force_model.err(K_r, k, k0, delta_f)
                    for k in (K_hat.lo, K_hat.hi))
        if best is None or eps_F < best.eps_F:
            best = Cert(K_r, B_r, mu, eps_F, delta_f)
    if best is None:
        return INFEASIBLE                              # 触发 ERTC 降级
    best.tight = tightness_gap(best, K_hat, force_model) <= TAU_TIGHT
    return best

def tightness_gap(cert, K_hat, fm):
    worst = max((K_hat.lo, K_hat.hi),
                key=lambda k: fm.err(cert.K_r, k, K_hat.nom, cert.delta_f))
    return abs(fm.err(cert.K_r, worst, K_hat.nom, cert.delta_f)
               - cert.eps_F)

def falsify(cert, bench):
    for b in bench.baselines:
        if (b.mu >= cert.mu and b.eps_F <= cert.eps_F
                and b.F_peak <= cert.F_peak and not b.uses_ablated_module):
            return FALSIFIED(b)                        # ΔP = 0
    for m in cert.support_modules:                     # BUQ/ERTC/J_exec
        d_eps, d_mu = ablation_necessity(m, bench)
        if d_eps <= RHO_EPS and d_mu <= 0:
            return MODULE_UNNECESSARY(m)
    return SURVIVES
```

## 4. 正确性（主定理与证明骨架）

**命题 CPFC**：若 CERT 返回可行证书，则 ∀K_e∈K̂_e：闭环鲁棒无源（μ>0），且
ε_F = F_d·max_{k_e∈{k_min,k_max}} K_r|k_e−k_0|/(k_0(K_r+k_e))
是紧的力跟踪上界。

*证明骨架*：
1. 无源：B_r≥B_min ⇒ 阻尼比 ζ≥ζ_min 且覆盖采样保持滞后，由无源性定理得 L2 稳定。
2. 误差：线性平衡 F(k_e)=K_r k_e x_r/(K_r+k_e)，按 k_0 标定 x_r ⇒ e(k_e)=K_r|k_e−k_0|/(k_0(K_r+k_e))；e 在区间端点取极值。
3. 紧：无合法 K_r 更优；最坏 K_e 取等。
4. 消融：去 BUQ ⇒ K̂_e 过宽（μ≤0）或过窄（失配 F_peak↑）；去 ERTC ⇒ B_r/x_max/F_safe 失约束；去 J_exec ⇒ 证书不可检，证据降 C。
5. 折中卖点：K_r↓⇒跟踪好但穿透/扰动抑制差；K_r↑⇒冲击/失配误差大；CPFC = 在 μ>0、x_r≤x_max、F_peak≤F_safe 下最小化 ε_F 的**可证明折中点**。

| 组件 | 时间 | 空间 | 保证 |
|---|---|---|---|
| Reduce | O(\|M\|·\|B\|) | O(\|M\|) | 保留模块均有消融证据 |
| Passivity | O(1) | O(1) | B≥B_min ⇒ 鲁棒无源（充分） |
| CPFC Cert | O(G·\|K̂_e\|) | O(1) | 证书通过 ⇒ 主定理前提 |
| Tightness | O(\|K̂_e\|) | O(1) | 端点极值 ⇒ 界紧 |
| Falsify | O(\|B_f\|·\|support\|) | O(\|B_f\|) | 存活 ⇒ ΔP 未被抹平 |

## 6. 本轮最大风险

**一句话**：若证伪台上经典/自适应阻抗在**不使用 ERTC/J_exec** 的情况下已达到相近的 μ 与 ε_F，则 CPFC 的创新点会被"基线不可区分性"直接抹平——本轮最大的风险不是定理证不出来，而是**定理即使证明了也可能不新**。
