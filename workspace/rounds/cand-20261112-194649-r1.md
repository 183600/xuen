# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 1 轮；本轮灵感：「创新点」×「灵巧操作」）

> 第 60 轮用 SSM×CIEC×EPIR×SERC×PCE++++ 把「认知先行」接到了「执行安全」上，但仍把机器人抽象成**单末端 6-DoF 阻抗 K_safe**。一旦任务换成灵巧操作（多指手、接触丰富、手内重定向），这个抽象在三处泄漏：
> 1. **阻抗没有接触分辨率**：K_safe 是一个 6×6 笛卡尔刚度，而灵巧手的关键变量是**每根手指的接触力、接触刚度及其在摩擦锥内的分配**。用一个 K_safe 概括一个抓取，等于把「抓取矩阵 G、摩擦锥、力封闭裕度」全部丢掉——力封闭可行性无法被“安全”证书覆盖。
> 2. **场景语义是静态标签，接触拓扑是动态状态**：SSM 的场景 z 在一次任务内基本不变，但灵巧操作的核心恰恰是**接触模式的连续切换**（接近→接触→粘着→滑移→再抓取→放置）。第 60 轮没有「接触状态机」，无法表达“此刻是否已失去力封闭”。
> 3. **证据链证明“执行合规”，既不证明“操作灵巧”，更不证明“创新点成立”**：EV-exec / J_exec 只说明没违反约束；它对“这个方案相对基线到底新在哪、新多少、是不是只是运气”没有给出一张可检验的证书。于是“创新点”停留在叙事层。
>
> 本轮把「灵巧操作」当作创新点的**试金石**，并把「创新点」本身形式化为**可证伪对象**：一个创新点不是一个名词，而是一条带必要性、充分性、可复现性的统计断言。

## 0. 直觉与动机

**灵感 1（灵巧操作 → 抓取阻抗张量 GIT）**
直觉：给灵巧手下发“一个刚度”是错的，应该下发“一束手指的接触刚度 + 一个摩擦锥内的力分配”。把物体期望力旋量 w_des 通过抓取矩阵 G 分配到各接触点，再用摩擦锥保证不滑；物体等效刚度不是 K_safe，而是 `K_o = (G K_c^{-1} G^T)^{-1}`。关键洞见：**灵巧 = 可调的接触阻抗张量，而不是末端刚度**；灵巧裕度 ρ_dex（摩擦锥贴边程度）才是比 K_safe 更本质的安全量。

**灵感 2（灵巧操作 → 接触模式编排 CMO）**
直觉：灵巧操作是一条“接触拓扑轨迹”，而不是一条“关节轨迹”。凡是“抓稳”都是一段不变式：只要物体被支撑，就要求 ρ_dex ≥ ρ_min。把接触模式建成混合自动机，用触觉特征（法向力 f_n、切向比 r_t、相对切向速度 v_t）做迁移守卫，禁止非法迁移（如“未断开就进入自由”）。关键洞见：**接触模式本身就是一等公民，应像场景一样被规划、被校验**。

**灵感 3（创新点 → 创新点证书 NaC）**
直觉：竞赛里的“创新点”常是形容词；可辩护的创新点应是“机制 π 让能力 C 相对基线 B 提升至少 δ，且该提升在 α 水平显著、去掉 π 后消失（必要性）、把 π 单独加回后重现（充分性）、在多个种子上可复现”。关键洞见：**创新点 = 一个通过必要性+充分性检验的因果效应**，而不是一个新缩写。

**灵感 4（灵巧操作 × 创新点 → 灵巧创新闭环 DICL）**
直觉：把 GIT 当被检验机制 π，把 CMO 当执行编排，把 DEX-Cert 当能力度量 C，把 NaC 当证伪器，就得到“场景→抓取可达→接触模式→逐指阻抗→触觉执行→灵巧证书→创新证书”的闭环。关键洞见：**每一次灵巧操作都同时产出一张“我做成了”和一张“我为什么新”的证书**。

**灵感 5（PCE++++ → 灵巧预算 PCE+++++）**
直觉：灵巧是**带宽昂贵的**——触觉频率、逐指控制频率、接触切换次数、手内重定向时间都是稀缺资源。把认知预算扩成 B_dex；一旦 B_dex 耗尽，不是“继续硬做灵巧”，而是**优雅降级为包络/功率抓取**：牺牲 ρ_dex 的精细度，换取 ρ ≥ ρ_min 的稳定支撑。关键洞见：**灵巧的降级必须保持力封闭，而不是保持任务**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（抓取阻抗张量 GIT）** 灵巧手 m 指、第 i 指接触维数 q_i（点接触=3），总接触力 f∈R^q，抓取矩阵 G∈R^{6×q}。GIT 为六元组
`GIT = (G, {FC_i}, K_c, K_o, ρ_dex, S_slip)`，其中：
- **力平衡**：`G f = w_ext + w_des`（w_ext 为外力旋量，w_des 为物体期望力旋量）
- **摩擦锥**：`FC_i = {f_i : f_{n,i} ≥ f_min, ||f_{t,i}|| ≤ μ_i f_{n,i}}`
- **接触刚度**：`K_c = blkdiag(K_1,…,K_m)`，`K_i ∈ S^3_{++}`（每指 3-DoF 接触刚度）
- **物体等效刚度**：`K_o = (G K_c^{-1} G^T)^{-1}`（接触柔顺经抓取映射串联到物体）
- **灵巧裕度**：`ρ_dex(f) = min_i (μ_i f_{n,i} − ||f_{t,i}||) / (μ_i f_{n,i})`
- **滑移指示**：`S_slip = 1[∃i : ||f_{t,i}|| ≥ (1−ε_slip) μ_i f_{n,i}]`
- **可行性**：`GIT 可行 ⇔ ∃f : Gf = w_ext+w_des ∧ f_i∈FC_i ∧ K_o ⪰ K_min ∧ ρ_dex(f) ≥ ρ_min`。这是一个**二阶锥规划（SOCP）可行性问题**；最大裕度 `ρ* = max{ρ : 上述约束把 μ_i 换成 (1−ρ)μ_i 后仍可行}`，用对 ρ 的二分 + SOC 可行性求解得到。

**定义 162（接触模式编排 CMO）** 混合自动机 `CMO = (S, →, Guard, Inv, Forbid)`：
- **状态集**：`S = {free, approach, contact, stick, slip, break, regrasp, place}`
- **触觉观测量**：`o_t = (f_n, f_t, v_t, contact_flag, shear_rate)`
- **守卫 Guard**：`stick→slip` 当 `r_t := ||f_t||/(μ f_n) ≥ 1−ε_slip`；`slip→stick` 当 `v_t < v_stick ∧ r_t < 1−2ε_slip`；`contact→break` 当 `f_n < f_min`；`stick→regrasp` 当 `ρ_dex < ρ_regrasp`。
- **不变式 Inv(s)**：`s ∉ {free} ⇒ ρ_dex ≥ ρ_min`。
- **禁止集**：`Forbid = {(stick→free), (slip→place), (break→stick)}`（未经 approach/contact 不得直接跨越）。
- **计划算子**：`Plan(git, s_goal) = argmin_{σ} |σ|`，s.t. 沿路径每步满足 `Guard ∧ Inv`（在有限状态图上做 Dijkstra）。

**定义 163（灵巧能力证书 DEX-Cert）** 对一次灵巧轨迹 τ：
```
J_dex(τ) = w_s·S_task + w_c·ρ̄_dex + w_m·m_manip + w_r·(1−S̄_slip) − w_e·Ē_energy − w_t·T̄_time
```
其中 S_task∈{0,1} 任务成功；ρ̄_dex 为轨迹上最小摩擦裕度的时间均值；`m_manip = sqrt(det(J J^T))` 为归一化可操作度；S̄_slip 为滑移时间占比；T̄_time 为完成时间。
- **证书**：`Cert_dex = (J_dex, Var(J_dex), N_trials, seed_set)`，并给出单侧置信下界 `LCB_{1−α}(J_dex)`。
- **达标**：`DEX-Cert 达标 ⇔ LCB_{1−α}(J_dex) ≥ θ_dex ∧ 所有 trial 满足 Inv`。

**定义 164（创新点证书 NaC）** 一个创新点 `ν = (π, C, J, B, δ, α, E)`：
- π 为被检验机制（本文即“GIT+CMO 相对单 K_safe”）；C 为能力主张；J 为度量（本文取 J_dex）；B 为基线（第 60 轮 SERC）；δ>0 为**预注册**效应阈值；α 为显著性水平；E≥30 为配对数。
- **配对差**：`ΔJ_e = J_e(B+π) − J_e(B)`。
- **必要性（ablation）**：`ΔJ_nec = E[J(B) − J(B⊖π)] ≥ δ`（拿掉机制后性能必须掉下来）。
- **充分性（add-back）**：`ΔJ_suf = E[J(B+π) − J(B)] ≥ δ`（只把机制加回基线必须能重现提升）。
- **统计有效性**：`LCB_{1−α}(ΔJ) ≥ δ`（BCa bootstrap 单侧下界）。
- **可复现性**：`∀s∈seed_set（|seed_set|≥2）` 结论成立，且在 ≥3 个场景切分上方向一致。
- **认证**：`ν ∈ N_cert ⇔ 必要性 ∧ 充分性 ∧ 统计有效 ∧ 可复现`。
- **创新点半衰期**：`T_½(ν) = min{t : ∃B'(t), ΔJ(B'(t), ν) < δ}`，用于量化“创新点保鲜期”。

**定义 165（灵巧创新闭环 DICL）** 算子 `DICL(M, scene, task, w_des)`：
```
① z      ← SSM.update(telemetry)
② u      ← Affordance.select(z, task)              # 场景先验给出候选抓取
③ git    ← GIT.solve(G(u), w_des, μ̂, K_c)           # SOCP 求 ρ* 与逐指力
④ if not git.feasible: return DEGRADE_POWER_GRASP
⑤ σ      ← CMO.Plan(git, task.contact_goal)
⑥ for s in σ:
       CMO.transition(s, Guard=o_t)
       τ_c ← GIT.contact_torque(git, s)             # 逐指力矩
       o_t ← execute(τ_c)                           # 返回触觉/位姿
       if SCE.precursor(o_t) > θ_slip: git ← REGRASP(...); goto ⑤
⑦ EV-dex ← build_dex_evidence(git, σ, o_t)
⑧ Cert_dex ← DEX-Cert.evaluate(EV-dex)
⑨ ν      ← NaC.certify(π=(GIT,CMO), J=J_dex, B=round60)
⑩ EPIR.append(EV-dex)                               # 复用第 60 轮证据链
⑪ return (Cert_dex, ν, EV-dex)
```

**定义 166（灵巧预算 B_dex 与 PCE+++++）** `B_dex = (B_tac, B_finger, B_mode, B_reorient)`：
- `B_tac = (f_tac, N_ch, latency_max)`：触觉采样率 × 通道数预算
- `B_finger = (rate_1,…,rate_m)`：逐指控制频率预算
- `B_mode = (switches/s, settle_time)`：接触模式切换预算
- `B_reorient = (Δθ_max, T_max)`：手内重定向能力预算
- **成本**：`cost_dex(π) = λ_tac·(f_tac/f_tac^max) + λ_f·Σ(rate_i/rate_i^max) + λ_m·switches + λ_r·T_reorient`
- **降级**：若 `B_dex < θ_dex`，降级为**功率抓取**（全指包络、`ρ_min^power > ρ_min`、放弃手内重定向），保持力封闭但放弃灵巧；若 B_tac 异常，退化为“力/位混合 + 保守 ρ_min”。
- **耦合**：B_dex 的消耗不得挤占第 60 轮 B_exec 的安全松弛（`B_dex` 与 `B_scene/B_intent/B_ros/B_exec` 单调耦合，取 min 的剩余安全余量）。

**定义 167（滑移前兆因果估计 SCE）** 前兆信号
`σ_slip(t) = d||f_t||/dt − c·(μ f_n − ||f_t||) + κ·v_t`。
若 `σ_slip(t−k:t) > θ_slip` 连续 k 拍，则预测在时域 `τ_slip = min{Δ : v̂_t(t+Δ) ≥ v_stick}` 内发生滑移。SCE 输出 `(P_slip, τ_slip)`；当 `τ_slip < 2·Δt_ctrl` 触发 REGRASP。**因果约束**：只能用 t 及之前的触觉，禁止使用未来帧（避免离线标签泄漏）。
- **可辨识条件**：若滑移前 `d||f_t||/dt > c·(μ f_n−||f_t||)` 且 `v_t` 单调增，则存在 `τ_slip > 0` 满足触发条件（前兆领先于实际滑移）。

**定义 168（创新点-任务对齐 ITA）** UniBot 评分 `S = Σ_j ω_j·cap_j − λ_risk·Risk`，cap_j 为竞赛能力项。对每个认证创新点 ν∈N_cert，定义**风险调整边际得分**
```
ΔS(ν) = (∂S/∂J_dex)·ΔJ(ν) − λ_risk·Var(J(ν)) − cost(ν)
```
选择 `ν* = argmax_{ν∈N_cert, Risk≤ρ_max} ΔS(ν)/cost(ν)`。**创新点不是越多越好，而是在证书有效前提下、单位成本风险调整得分最高的那一个。**

## 2. 关键算法伪代码

### IP-161 GIT（抓取阻抗张量，SOCP 求最大灵巧裕度）

```python
class GraspImpedanceTensor:
    def __init__(self, G, mu, f_min=1.0, rho_min=0.15, eps_slip=0.05):
        self.G, self.mu, self.f_min = G, mu, f_min
        self.rho_min, self.eps_slip = rho_min, eps_slip

    def solve(self, w_des, w_ext, K_c, rho_tol=1e-3):
        w = w_des + w_ext
        lo, hi, f_best = 0.0, 0.95, None
        while hi - lo > rho_tol:
            rho = 0.5 * (lo + hi)
            f = self._socp_feasible(w, rho)      # ||f_t,i|| <= (1-rho)*mu_i*f_n,i
            if f is not None:
                lo, f_best = rho, f
            else:
                hi = rho
        if f_best is None:
            return GIT(feasible=False)
        K_o = np.linalg.inv(self.G @ np.linalg.inv(K_c) @ self.G.T)
        slip = any(np.linalg.norm(self._ft(f_best, i)) >=
                   (1 - self.eps_slip) * self.mu[i] * self._fn(f_best, i)
                   for i in range(len(self.mu)))
        return GIT(self.G, f=f_best, K_o=K_o, rho_dex=lo, S_slip=slip, feasible=True)

    def _socp_feasible(self, w, rho):
        # SOCP: min 0 s.t. G f = w, f_n >= f_min, ||f_t,i|| <= (1-rho)mu_i f_n,i
        return solve_socp(self.G, w, self.mu * (1 - rho), self.f_min)
```

### IP-162 CMO（接触模式编排）

```python
class ContactModeOrchestrator:
    S = ['free','approach','contact','stick','slip','break','regrasp','place']
    FORBID = {('stick','free'), ('slip','place'), ('break','stick')}

    def guard(self, s, o):
        r_t = np.linalg.norm(o.f_t) / max(o.mu * o.f_n, 1e-9)
        if s == 'stick'   and r_t >= 1 - o.eps_slip:                 return 'slip'
        if s == 'slip'    and o.v_t < o.v_stick and r_t < 1 - 2*o.eps_slip: return 'stick'
        if s == 'contact' and o.f_n < o.f_min:                       return 'break'
        if s == 'stick'   and o.rho_dex < o.rho_regrasp:             return 'regrasp'
        return s

    def transition(self, s, o):
        s2 = self.guard(s, o)
        if (s, s2) in self.FORBID:
            raise IllegalContactTransition(f"{s}->{s2}")
        if s2 != 'free' and o.rho_dex < o.rho_min:
            raise InvariantViolation("force closure lost")
        return s2

    def plan(self, git, s_goal):
        return dijkstra(self.S, start=git.contact_state, goal=s_goal,
                        step=lambda s: self._admissible(s, git))
```

### IP-163 / IP-164 DEX-Cert 与 NaC（双证书）

```python
class DexterityCertificate:
    def evaluate(self, ev_dex, alpha=0.05):
        J = np.array([e.J_dex for e in ev_dex.trials])
        return Cert(J.mean(), J.var(), len(J), ev_dex.seeds,
                    lcb=bca_lower_bound(J, alpha))

class NoveltyCertificate:
    def certify(self, J, J_base, J_wo_pi, delta, alpha=0.05, seeds=None):
        d   = np.array(J) - np.array(J_base)
        lcb = bca_lower_bound(d, alpha)
        nec = np.mean(np.array(J_base) - np.array(J_wo_pi)) >= delta
        suf = np.mean(d) >= delta
        rep = all(self._seed_passes(s, delta, alpha) for s in (seeds or []))
        return NoveltyVerdict(valid=(lcb >= delta and nec and suf and rep),
                              lcb=lcb, necessity=nec, sufficiency=suf, reproducible=rep)
```

### IP-165 DICL（灵巧创新闭环，含滑移回退）

```python
def dexterous_innovation_loop(M, scene, task, w_des):
    z = M.ssm.update(M.telem_force, M.telem_pos)
    u = M.affordance.select(z, task)
    git = M.git.solve(w_des, M.w_ext, M.K_c)
    if not git.feasible:
        return degrade_power_grasp(M, task)
    plan = M.cmo.plan(git, task.contact_goal)
    for s in plan:
        M.cmo.transition(s, M.tactile)
        o_t = execute(M.git.contact_torque(git, s))
        p_slip, tau_slip = M.sce.precursor(o_t)
        if tau_slip < 2 * M.dt_ctrl:
            git = M.regrasp(git, o_t)
            plan = M.cmo.plan(git, task.contact_goal)
            break
    ev = build_dex_evidence(git, plan, M.log)
    cert_dex = M.dex_cert.evaluate(ev)
    nu = M.nac.certify(ev.J_dex, M.baseline_J, M.ablation_J, delta=M.delta)
    M.epir.append(ev.as_dict())
    return cert_dex, nu, ev
```

### IP-167 SCE（滑移前兆因果估计）

```python
class SlipCausalEstimator:
    def __init__(self, c=0.8, kappa=2.0, k=3, theta=0.15):
        self.c, self.kappa, self.k, self.theta = c, kappa, k, theta
        self.win = deque(maxlen=k + 1)

    def precursor(self, o):
        ft_norm = np.linalg.norm(o.f_t)
        dft = 0.0 if not self.win else (ft_norm - self.win[-1]) / o.dt
        sigma = dft - self.c * (o.mu * o.f_n - ft_norm) + self.kappa * o.v_t
        self.win.append(ft_norm)
        hot = len(self.win) >= self.k and all(w > self.theta for w in self.win[-self.k:])
        tau = self._predict_horizon(o) if hot else np.inf   # 只用历史，严格因果
        return (1.0 if hot else 0.0), tau
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| GIT | O(log(1/ρ_tol)·SOCP)，SOCP≈O((mq)^3) | O(q²) | SOCP 精确：可行则力平衡+摩擦锥成立，ρ* 为最大裕度 |
| CMO | 计划 O(\|S\|²)，迁移 O(1) | O(\|S\|+\|E\|) | Inv 强制 ρ_dex ≥ ρ_min；Forbid 拒绝非法迁移 |
| DEX-Cert | O(E·T) | O(E) | LCB 在 1−α 下覆盖真实均值 |
| NaC | O(E·B_boot) | O(E) | 必要性+充分性+LCB ⇒ 非偶然效应；假认证率 ≤ α |
| DICL | O(\|σ\|·T_ctrl) | 复用第 60 轮 | 每步接触模式有界；滑移前兆可回退 |
| SCE | O(k) / 周期 | O(k) | 严格因果；前兆领先条件可辨识 |

**正确性定理（DICE，Dexterous Innovation Certificate Engine）**：

2. **接触安全**：CMO 不变式保证被支撑物体始终 `ρ_dex ≥ ρ_min`，不出现“未断开即自由”的非法迁移。
3. **灵巧可度量**：DEX-Cert 的 `LCB_{1−α}(J_dex) ≥ θ_dex` 是可检验的灵巧主张，而非形容词。
4. **创新可证伪**：NaC 认证 `ν` ⇒ 必要性、充分性、统计有效、可复现同时成立，故 ΔJ 的因果归因成立且假认证率 ≤ α。

6. **选择最优**：ITA 在 N_cert 内按风险调整边际得分选 `ν*`，避免“创新点堆砌”挤占风险预算。

### IP-161 GIT（抓取阻抗张量，SOCP 二分求 ρ*）

```python
class GraspImpedanceTensor:
    def solve(self, w_des, w_ext, K_c, rho_tol=1e-3):
        w = w_des + w_ext
        lo, hi, f_best = 0.0, 0.95, None
        while hi - lo > rho_tol:
            rho = 0.5 * (lo + hi)
            f = self._socp_feasible(w, rho)      # ||f_t,i|| <= (1-rho)*mu_i*f_n,i
            if f is not None: lo, f_best = rho, f
            else:             hi = rho
        if f_best is None:
            return GIT(feasible=False)
        K_o = np.linalg.inv(self.G @ np.linalg.inv(K_c) @ self.G.T)
        return GIT(self.G, f=f_best, K_o=K_o, rho_dex=lo, feasible=True)
```

### IP-162 CMO（接触模式编排）

```python
class ContactModeOrchestrator:
    S = ['free','approach','contact','stick','slip','break','regrasp','place']
    FORBID = {('stick','free'), ('slip','place'), ('break','stick')}

    def guard(self, s, o):
        r_t = np.linalg.norm(o.f_t) / max(o.mu * o.f_n, 1e-9)
        if s == 'stick'   and r_t >= 1 - o.eps_slip:                       return 'slip'
        if s == 'slip'    and o.v_t < o.v_stick and r_t < 1-2*o.eps_slip:  return 'stick'
        if s == 'contact' and o.f_n < o.f_min:                             return 'break'
        if s == 'stick'   and o.rho_dex < o.rho_regrasp:                   return 'regrasp'
        return s

    def transition(self, s, o):
        s2 = self.guard(s, o)
        assert (s, s2) not in self.FORBID, "illegal contact transition"
        assert s2 == 'free' or o.rho_dex >= o.rho_min, "force closure lost"
        return s2
```

class NoveltyCertificate:
    def certify(self, J, J_base, J_wo_pi, delta, alpha=0.05, seeds=None):
        d   = np.array(J) - np.array(J_base)
        lcb = bca_lower_bound(d, alpha)                       # 单侧下界
        nec = np.mean(np.array(J_base) - np.array(J_wo_pi)) >= delta
        suf = np.mean(d) >= delta
        rep = all(self._seed_passes(s, delta, alpha) for s in (seeds or []))
        return NoveltyVerdict(valid=(lcb >= delta and nec and suf and rep),
                              lcb=lcb, necessity=nec, sufficiency=suf, reproducible=rep)

    def precursor(self, o):
        ft = np.linalg.norm(o.f_t)
        dft = 0.0 if not self.win else (ft - self.win[-1]) / o.dt

def select_innovation(n_cert, score_grad, risk_budget=0.2):
