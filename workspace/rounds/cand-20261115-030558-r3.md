# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「域随机化」×「大语言模型」）

> R69 把「看 / 问 / 触」变成了消歧动作，却默认了一个东西不动：**世界模型本身**。它的 aleatoric / epistemic 二分回答的是「在同一个世界里，我该选哪个动作模态」；它从未问过「我是否还站在那个世界里」。域随机化把这个默认项翻上台面：训练时世界本就是从 p_φ(θ) 采样的一族，**支撑 supp(p_φ) 才是全部保证的真实疆域**——支撑之内，随机化是鲁棒性；支撑之外，随机化是一句自信的谎。大语言模型则给出另一半——它能从语言、常识与场景描述里提出「还有哪些世界可能出现」：雨天地面更滑、纸箱比金属箱轻、老人转身更慢、礼貌规范会改变人的让行；它也能提出「墙纸颜色不该影响擦拭轨迹」这类语义不变式。但它同样会一本正经地提出物理上不存在的世界，并把一句「肯定没事」当成证据。
>
> 核心命题：**把「世界」显式化为一族可随机化、可认证、可后验的世界 θ；认证支撑 S_cert 是安全与性能保证的唯一疆域；LLM 只负责提出长尾假设与相关结构，物理与数据负责删假设；当后验逼近 / 越出支撑边界时，系统必须承认「不是动作不确定，而是世界假设错了」，把动作级消歧让位于世界级辨识或模型无关安全。** 命名 **REALM-RAS**（Randomized-Environment support with Active Language-grounded Model-mismatch awareness）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我脚下的这个世界，还在我以为的那一族世界里吗；我的保证，到底覆盖到哪里为止**」。

## 0. 直觉与动机

**灵感 1（域随机化 → 世界是一族，支撑即保证）**
直觉：DR 不是「让模型见多识广」这么轻。它把真实世界当成 p_φ(θ) 的一个样本，于是策略真正被优化的是「在支撑里任意 θ 都不坏」。这句话反过来读更锋利：**保证只在支撑里成立**。支撑是合同的适用范围，不是装饰。R69 的 FLUID 其实偷偷假设了 |Θ|=1——一个固定世界里的多模态动作；一旦真实 θ 落在支撑外，流策略仍会吐出漂亮的多个模态、权重仍会归一化、VoI 仍会算出正数，但这一切都可能是在错误世界里自洽。**在错误的世界里，越精确的消歧越危险。**

**灵感 2（DR 的沉默假设 → 支撑缺口与「看起来正常」的错）**
直觉：DR 最危险的失败不是训练不充分，而是**支撑缺口**：真实世界在支撑外，却和支撑内某个世界在观测上几乎不可分。此时没有任何集成成员「觉得不对」，OOD 分数不响，系统会继续用 R69 的口吻说话。这比「测不准」更致命：测不准至少会触发 λ_floor；世界错配却可能一路绿灯。所以本轮的第一原则不是「更准地估不确定性」，而是「**先确认不确定性的坐标系还在不在**」。

**灵感 3（大语言模型 → 世界的语义先验，而不是概率神谕）**
直觉：手工 DR 的两个死穴是**维度独立采样**与**长尾想不全**。前者把本应相关的参数（下雨、湿滑、低照度、行人撑伞）拆成独立均匀分布，采样点绝大多数落在物理上不可能的组合里；后者让「刚拖过的地」「透明饮料洒了一地」「纸箱里有半瓶水」这类真正要命的长尾永远进不了随机化表。LLM 恰好擅长这两件事：它能把一句「厨房刚拖过地」展开成一组相关参数区间，能把「医院走廊」与「慢速、避让、低声」联起来，还能提出可证伪的检查（「若地面真的湿，小制动力下轮速与车速应出现滑移差」）。但 LLM 不知道物理定律的边界，也不知道自己的置信度——**它只能提议世界，不能给世界盖章**。

**灵感 4（R69 的盲点 → 不确定性是分层的，VoI 只在模型内有效）**
直觉：R69 的 MINT 在「动作模态 M」上算 VoI：问一句能减少多少模态熵。但 VoI 是**条件于世界模型**的量。若世界模型错了，减少的是「错误世界里的模态熵」——系统会越来越自信地走向一个不存在的正确答案。信息论上这是链式法则：`I((M,Θ); y) = I(Θ; y) + E_θ[I(M; y|θ)]`。R69 只优化第二项，且默认 Θ 已知。**世界级信息没解决之前，动作级信息可能一文不值，甚至为负**（把错误世界确认得更牢）。这是 R69「问错比不问更危险」的上一层版本：**在世界错的时候问，是在给错误的世界做背书**。

**灵感 5（安全的不对称 → LLM 只能加假设，不能减假设）**
直觉：如果允许语言 / LLM 收紧支撑（「用户说地面是干的，那就把湿滑世界删掉」），一句提示注入或一次谄媚就能让系统把安全余量删掉——这正是 R68 / R69 最怕的「自信地错」。于是本轮采用一条强不对称纪律：**语义先验只能增加世界假设（扩大支撑、增加候选、重加权），删除世界假设必须同时通过物理可行性认证与数据证据**。好处是：LLM 的幻觉在安全侧变得「免费」——最坏结果是过度保守、多问几次；它无法把系统推向过度自信。代价是效率：长尾假设会拖慢收敛，必须靠离线后验聚焦的 DR 预算来消化。

**灵感 6（DR 的三种老毛病 → 捷径、平均化、不可辨识）**
直觉：DR 不是银弹。①**捷径学习**：策略可能抓住随机化里的伪线索（墙纸颜色、特定纹理、渲染器瑕疵），在真机上失效；LLM 可以提出「哪些参数应当无关」的语义不变式，用反事实随机化做定向审计。②**保守平均**：支撑越宽，最坏情形保证越松、标称性能越差；这给出一条「覆盖-保证前沿」，DR 预算应花在后验高概率且决策敏感的方向，而不是均匀铺开。③**不可辨识**：很多 θ 产生同一观测，再问也分不开；此时正确做法不是继续交互，而是对后验做风险敏感聚合（CVaR），承认「这题不可解」而不是假装解开。

**灵感 7（严格包含的底线 → 单点世界必须逐指令退回 R69）**
直觉：这是本系列的硬约束。REALM 在 Θ={θ0}、LLM 不提议、世界辨识关闭时，必须**逐指令等于 FLUID（R69）**；禁止交互时等于 CALM（R68）。支撑扩张与门控只能是「在旧层外面加一层世界层」，不能偷偷改掉旧层的动作级逻辑；否则每加一层就多一个独立需要信任的黑箱。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（REALM-RAS 总览与五不变式）** REALM-RAS = (WSP, LSP, SGC, WID, H-VoI, WRP, INV, FLUID-RAS†)。五不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i、R68 定义 276-i）：测试时不更新策略权重或世界参数，DR 自适应只发生在离线；
(ii) **支撑即保证**：一切安全 / 性能保证只在认证支撑 S_cert 内成立；越界必须显式声明 OOD 并退化，绝不允许「在支撑外沿用支撑内的 λ 语言」；
(iii) **语义单调加假设**：语言 / LLM 只能增加世界假设（扩大支撑或重加权），删除假设必须由物理可行性认证与数据证据共同完成；
(iv) **世界优先门控**：U_world 未受控时，不得用动作模态的后验 VoI 驱动交互或执行；世界级不确定性优先于动作级；
(v) **严格包含**：`Θ={θ0} ∧ 无 LSP ∧ 无 WID` ⇒ 逐指令等于 FLUID（R69）；禁止交互 ⇒ 等于 CALM（R68）。

**定义 311（随机化世界空间与参数分区）** 世界参数 `θ = (θ_dyn, θ_sen, θ_sem, θ_task) ∈ Θ ⊆ ℝ^{d_θ}`：θ_dyn 为质量 / 摩擦 / 阻尼 / 延迟等动力学参数；θ_sen 为噪声 / 偏置 / 标定 / 分辨率；θ_sem 为人的意图、社交规范、物体可供性、光照语义；θ_task 为任务上下文。每个 θ 诱导一个世界模型 M_θ（预测动力学、观测与人的响应）。LLM 还可提出**相关性分区**：`θ = (θ_rel, θ_nui)`，其中 θ_nui 是「按理不该影响任务」的冗余参数；该分区只是假设，由 INV（定义 322）用反事实检验。

**定义 312（基础 DR 先验、认证支撑、语义外缘、支撑裕度）** 训练期基础先验 p_φ(θ)；语言条件语义先验 q_ψ(θ|ℓ)（ℓ 为指令 / 场景描述 / 人答）。有效先验 `p_eff(θ) ∝ p_φ(θ)·q_ψ(θ|ℓ)`。**认证支撑** `S_cert ⊆ Θ` 是同时满足「物理可行 Φ」「可实例化 I」「安全包络 E」「数据验证 D」的世界集合；**语义外缘** `R_sem = supp(q_ψ) \ S_cert` 是 LLM 提出但未认证的假设，**只能驱动离线采集，不能驱动控制**。支撑裕度 `d_S(θ) = inf_{θ'∈∂S_cert} d_θ(θ,θ')`，其中 d_θ 为参数空间度量（归一化后）。支撑覆盖率 `Cov(S_cert)` 由 held-out 世界族与现场日志估计。**「支撑即保证」：一切定理都形如 `θ* ∈ S_cert ⇒ ...`。**

**定义 313（LLM 场景提议器 LSP）** `LSP: (ℓ, c, τ, memory) → {C_i}`，其中场景卡 `C_i = (P_i, [a_i,b_i], Σ_i, r_i, O_i, F_i)`：参数组、区间 / 相关结构、理由、可区分观测量、可证伪实验。LSP 还可输出两类次级提案：①**相关结构**（雨 ⇒ 湿滑 ∧ 低照度 ∧ 撑伞行人，给出联合分布而非独立盒）；②**语义不变式**（「墙纸颜色不影响擦拭」）。每张卡带 `provenance_hash` 与自评置信，但**置信不是安全概率**；LSP 的输出一律是假设，不是控制指令，也不是先验的最终裁决。

**定义 314（支撑认证门 SGC 与单调加假设）** 对提案 C_i 依次检查：物理可行 `Φ(θ)`（量纲、守恒、限位）、可实例化 `I(θ)`（渲染 / 参数化模型能生成）、安全包络 `E(θ)`（该世界族下模型无关安全约束仍有解）、数据验证 `D(θ)`（held-out 或现场证据不否证）。通过者进入 `S_cert` 并升版；不通过者进入 `R_sem`。**单调加假设**：控制时的 LLM 提案只能 `S_cert ← S_cert ∪ ·` 或对已有成员重加权；任何删除 `S_cert ← S_cert \ ·` 必须附带物理 / 数据证书 `E_phys`，否则拒绝。SGC 是「语义提议」与「安全权威」之间的唯一闸门。

**定义 315（世界集成、后验与支撑统计）** 世界集成 `{θ_i, w_i}_{i=1}^{N_w}`，权重由 p_eff 初始化，再以预测似然递推更新：`w_i ∝ w_i · p(o_t | M_{θ_i}, o_{<t})`。世界不确定性拆为 `U_world = U_world^id + U_world^irr`：前者是可被辨识动作降低的部分（后验可分离），后者是不可辨识的残余（多个 θ 观测等价）。**世界失配统计**：以密度比 / 恰当评分构造 e-value `e_t = p_{θ̂_t}(o_t|o_{<t}) / p_ref(o_t|o_{<t})`，在 `θ*∈S_cert` 零假设下 `E[e_t] ≤ 1`；由 Ville 不等式，`P(sup_t e_t ≥ 1/α) ≤ α`，给出任意时刻有效的 OOD 报警。四元异常签名见定义 328。

**定义 316（三元不确定性分解）** `U = (U_ale, U_epi, U_world)`：`U_ale` 为同一世界内的不可约噪声（条件于 θ）；`U_epi` 为同一世界内的动作模态歧义（R69 定义 297，**条件于 θ**）；`U_world` 为世界假设本身的不确定 / 错配。三者语义不同、**不做简单加和**，按层级处置：世界层 → 动作层 → 噪声层。R69 的 `(U_ale,U_epi)` 是本轮在 θ 上取点质量（`U_world=0`）的截面。

**定义 317（分层 VoI 与世界辨识动作）** 世界辨识动作 `g_w ∈ 𝒜_info` 指「执行一个安全的观测 / 探针 / 提问，使世界后验更集中」，例如低速小制动力探针区分干 / 湿地面、换一个视角区分透明容器是否为空。链式法则给出精确分解：
`I((M,Θ); y | o) = I(Θ; y | o) + E_{θ~p(θ|o)}[ I(M; y | o, θ) ]`。
定义 `H-VoI(g) = I(Θ; y|g,o) + E_θ[I(M; y|g,o,θ)] − c(g)`。**门控**：若 `U_world^id > τ_w` 且动作决策对 θ 敏感（模态排序随 θ 改变），先选 `g_w`；仅当世界后验在 S_cert 内充分集中、`d_S ≥ m` 时，才允许 R69 的动作模态交互。R69 的 MINT 是 `Θ` 已知、上式第一项为 0 的退化。

**定义 318（支撑三区门 IN / RIM / OUT）** 依据后验质量、支撑裕度与 e-value 划分：
- **IN**：`P(θ∈S_cert|o) ≥ 1−α`、`e_t < 1/α`、`d_S(θ̂) ≥ m` ⇒ 正常 REALM：用世界条件化的 R69，可获 resolution bonus；
- **RIM**：后验靠近边界、`e_t` 升高或 `d_S < m` ⇒ **禁用动作模态 VoI 与 resolution bonus**，只允许安全的世界辨识动作或 R68 兜底；未在预算内辨识 ⇒ 保持 RIM；
- **OUT**：后验落在支撑外或 e-value 越过阈值 ⇒ 只保留模型无关安全；安全停车 / 向人求助 / 降速；显式 OOD 声明，禁止任何学习写。
转移单调：IN→RIM→OUT 可即时发生；OUT→IN 必须经再认证（定义 324），不能「因为看起来没事了」就跳回。

**定义 319（世界鲁棒策略 WRP）** 对每个 `θ_i`，用 R69 的模态分解与风险缩放得到候选 `(m, λ_i)`；在世界后验上做风险敏感聚合：
`ξ* = argmin_{ξ} CVaR_β[ R(θ, ξ) ]`（β 为尾部水平），或对后验高密度集取最坏情形。
当后验退化为点质量时，WRP 逐指令等于 R69 的 `select_mode`；当 `U_world^irr` 大时，WRP 给出**不假装辨识**的鲁棒动作，并把代价写进证书。

**定义 320（支撑条件化的保守退避）** 只有同时满足「IN 区 + U_epi 已消解」才发放 R69 的 resolution bonus：`λ = λ_floor(U_ale)`；否则
`λ = λ_floor( U_ale + U_epi^{unres} + f(U_world) )`，
其中 `f` 单调不减、`f(0)=0`、`f ≥ 0`，把世界残余不确定性视同 aleatoric 兜底。由此：世界不受控时，λ **不小于** R69；世界受控且消解成功时，才可能低于 R69（获得效率收益）。安全侧永不让步。

**定义 321（覆盖-保证前沿与后验聚焦离线 DR）** 对支撑 `S`，定义覆盖率 `Cov(S)=P(θ*∈S)` 与最坏情形保证 `Risk*(S)=min_π sup_{θ∈S} R(θ,π)`。若 `S1 ⊆ S2`，则 `Cov(S2) ≥ Cov(S1)` 而 `Risk*(S2) ≥ Risk*(S1)`，标称性能一般也随支撑变宽而下降——**扩大支撑买到覆盖，付出保证变松 / 性能下降的代价**。**DFR（Distribution-Focused Randomization）** 是离线预算分配：把随机化 / 采集预算花在 `后验质量 × 决策敏感度 × LLM 可实例化` 最高的方向，并在前沿上选点；它只在离线运行，遵守定义 310-i。

**定义 322（不变式 / 捷径审计 INV）** 对 `θ = (θ_rel, θ_nui)` 分区，定义冗余敏感度
`S_nui = E_{o, θ_nui, θ_nui'}[ D( π(·|o,θ_nui), π(·|o,θ_nui') ) ]`
（D 为行为 / 轨迹散度）。`S_nui` 高 ⇒ 策略在利用 DR 伪线索（捷径），或 LLM 的「无关」判断错了。INV 用反事实随机化做定向审计，并把结论回灌 LSP 与 DFR。它补的是 R69 完全没有的一类失败：**在支撑之内、却在因果上依赖了错误的参数**.

**定义 323（语言即证据与单调加假设契约）** 任何文本 `e_ℓ`（指令、图像描述、人的回答）都是带来源的证据 `(content, source, t, hash, version)`，**不是命令**；它可增加假设、可在 S_cert 内重加权，但**不能在无物理 / 数据证书时收紧 S_cert 或删除世界假设**。这条契约把提示注入、谄媚、单句「没事」的攻击面限制在「更保守」一侧。它与 R69 的「单次交互不得单独定案」同构，但作用在**世界支撑**而非动作模态上。

**定义 324（支撑扩张协议）** 触发 RIM / OUT 后，扩张只能经由：(a) 模型无关安全包络内的安全探索；或 (b) 人机在环确认；随后 (c) SGC 认证 + 数据验证 + `J_REALM` 重签。禁止实时权重写；每次扩张是带版本号的显式事件，旧支撑与新支撑的差集与理由进入审计。这样杜绝「支撑蔓延」（support creep）——不能靠一次次「顺手放宽」把安全边界悄悄挪走。

**定义 325（威胁模型 ℰ_REALM）** `ℰ_REALM = ℰ_FLUID × ℰ_support × ℰ_llm`。
ℰ_support：支撑缺口、错误认证、被污染的 DR 先验、仿真器伪影、参数共模漂移；
ℰ_llm：幻觉出物理不可能世界、提示注入 / 谄媚使支撑被非法收紧、语义接地错误、LLM 的语义盲区（想不出真实长尾）、对抗性场景描述。
继承 ℰ_FLUID 的投毒 / 模态坍缩 / ODE 发散。

**定义 326（证书 J_REALM）** `J_REALM = (J_FLUID, support_version, Cov(S_cert), d_S_min, U_world, e_t_max, regime∈{IN,RIM,OUT}, llm_proposal_hash, cert_ids, S_nui, realm_ver)`。
`Valid ⇔ Valid(J_FLUID) ∧ regime 判定有据 ∧ 单调加假设契约未被违反 ∧ (IN ⇒ Cov≥1−α ∧ e<1/α ∧ d_S≥m) ∧ (OUT ⇒ OOD 声明 ∧ 仅模型无关安全) ∧ 任何支撑扩张都有再认证`.

**定义 327（参与式审计 VQAuditor-W）** 审计对象新增世界层决策：哪些 LLM 提案被认证 / 被拒、是否出现「文本收紧支撑」的尝试、OOD 是否及时声明、扩张是否再认证、世界辨识动作是否安全且确实有信息量、WRP 是否在不可辨识时过度自信。结论回灌 LSP 与 DFR，形成离线改进闭环。

**定义 328（世界条件化 FMA 与四元异常签名）** 把 R69 的 `a_score(ξ|o)` 升级为世界条件化 `a_score(ξ|o,θ)`；四元签名 `(r_res, Δa, U_world, d_S)` 分离四类问题：传感器漂移（r_res↑）、被标定吸收的缓变故障（r_res↓, Δa↑）、世界错配（U_world↑, d_S↓，Δa 可升）、不可辨识（U_world↑、d_S 正常、e_t 不报警、所有 θ 都「说得通」）。R69 的 (r_res, Δa) 是 θ≡θ0 的切片。

def certify(prop, wsp):

    if not instantiable(prop):                            return 'rim'

# IP-267 WID：世界后验、支撑裕度与 anytime-valid OOD
def update_worlds(worlds, obs, alpha):
    for w in worlds:
        w.loglik = w.model.predictive_loglik(obs)
    worlds.normalize()
    U_world = entropy(worlds.w) + dispersion(worlds.theta)
    d_S     = min(worlds.margin(theta) for theta in worlds.support())
    e_t     = worlds.best_density(obs) / worlds.ref_density(obs)   # E[e]≤1 under H0
    regime  = ('OUT' if ville_alarm(worlds.e_process, alpha)
               else 'RIM' if e_t > 1/alpha or d_S < M_MIN
               else 'IN')
    return U_world, d_S, e_t, regime

# IP-268 H-VoI：先世界、后动作
def hierarchical_voi(worlds, modes_by_world, candidates, budget):
    best = None
    for g in candidates:
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        voi_w = mutual_info_world(worlds, g)                    # I(Θ; y|g)
        voi_a = mean(mutual_info_modes(worlds[w], g) for w in worlds)  # E[I(M;y|g,θ)]
        score = voi_w + voi_a - cost(g)
        if best is None or score > best.score: best = (g, score, voi_w)
    return best

    return cvar_select(cand, worlds.w, beta)   # 点质量 ⇒ R69 select_mode

# IP-275 主闭环
def REALM_round(M, obs, language):

             else M.wsp.R_sem.add(c))              # 失配绝不进控制

## 3. 推导

**假设 A99–A103**：
A99（支撑覆盖）真实 θ* 落在 S_cert 内的概率 ≥ 1−α，覆盖率由 held-out 世界族与现场日志校准；
A100（世界损失 Lipschitz）风险 `R(θ,ξ)` 在 d_θ 下关于 θ 为 L_θ-Lipschitz，故用 θ̂ 代替 θ* 的额外后悔 ≤ L_θ·d_θ(θ*,θ̂)；
A101（集成校准 / e-value 有效）世界后验在支撑内校准，密度比 e-value 在 H0 下 `E[e]≤1`；
A102（可实例化与单调加假设）被认证的提案均可实例化且物理可行，文本无法在无证书时收缩 S_cert；
A103（不可辨识可检出）若 `U_world^id` 在预算内无法降到 τ_w，则后验在参数空间保持正分散，CVaR 聚合的后悔有界（见定理 20）。

**引理 19（世界优先的 VoI 分解与门控）** 对任意观测 o 与信息动作 g，链式法则给出
`I((M,Θ); y|o) = I(Θ; y|o) + E_{θ~p(θ|o)}[I(M; y|o,θ)]`。
在 A100 下，若动作模态的排序随 θ 改变，则在错误 θ̂ 下选出的模态 m̂ 相对真实最优模态的后悔 ≤ `L_θ·d_θ(θ*,θ̂) + regret_action`；而 R69 的动作级 VoI 只降低第二项、对第一项无能为力。故当 `L_θ·diam_p(Θ) > max_g E[I(M;y|g,o,θ)]`（世界诱导的后悔超过任何动作级信息增益）时，世界优先门控的期望后悔严格小于动作优先。**系：R69 是 `Θ={θ0}`、第一项为 0 的边界；「先问世界，再问动作」不是风格，是链式法则的直接推论。**

**引理 20（支撑边界处的保证失效与 e-value 检测）** 若 `θ* ∉ S_cert`，则 DR 的一切保证（包括 R69 的流似然与 λ_floor 校准）都不再有覆盖意义；此时 e-value 在 H0 下由 Ville 保证误报 `≤ α`，检测功效由 `θ*` 与 S_cert 上混合预测之间的 f-散度决定。若该散度低于可由有限样本分辨的阈值（**支撑盲区**：θ* 与某个 θ∈S_cert 观测等价），则任何统计检验都无法可靠报警。**系：世界错配的检测极限由支撑的几何决定，而不是由样本量决定；这既是 REALM 的动机，也是它的天花板。**

**引理 21（语言单调加假设的安全性）** 在 A102 下，若文本 / LLM 只能增加假设或在 S_cert 内重加权，则认证安全集随时间为单调不增（除非发生带证书的显式扩张）：`S_safe(t+1) ⊆ S_safe(t)`。因此任意（含对抗性）文本与 LLM 幻觉只能导致**过度保守、交互预算浪费或性能下降**，不能导致「支撑被非法收紧 → 过度自信」。**系：幻觉在安全侧是免费的，在效率侧是收费的；这正是我们愿意让 LLM 提议长尾的原因。**

**引理 22（覆盖-保证前沿）** 若 `S1 ⊆ S2`，则 `Cov(S2) ≥ Cov(S1)`，但 `Risk*(S2) = min_π sup_{θ∈S2} R(θ,π) ≥ Risk*(S1)`，标称性能 `J(S2) ≤ J(S1)`（一般情形）。故不存在「又覆盖又不变怂」的免费午餐；DFR 的最优点在 `Cov` 与 `Risk*`（以及标称性能）的前沿上，按后验质量 × 决策敏感度分配预算，而不是均匀扩大盒式支撑。**系：LLM 提出的长尾不是越多越好；每加一个世界都在给保证上紧一圈。**

**定理 18（REALM 严格包含 FLUID / CALM）** 在 A99–A103 下，当 `Θ={θ0}`、LSP 关闭、WID 关闭（`U_world=0, d_S=∞`）时，SGC 恒等、H-VoI 退化为 R69 MINT、WRP 退化为 `select_mode`、定义 320 退化为 R69 定义 307，故 REALM **逐指令等于 FLUID**；禁止交互时逐指令等于 CALM。对 `θ*∈S_cert`，REALM 的额外门控只会收缩安全集 / 抬高 λ，故安全风险 ≤ R69；对 `θ*∉S_cert`，R69 的保证本已失效，而 REALM 显式声明 OOD 并退到模型无关安全。**安全侧弱占优，效率侧只在世界受控时兑现 resolution bonus。**

**定理 19（世界级安全门，本轮核心）** 在 RIM / OUT 区，动作模态 VoI 与 resolution bonus 被禁用，`λ ≥ λ_floor(U_ale + U_epi + f(U_world)) ≥` R69 同状态下的 λ；只允许模型无关安全动作与安全的世界辨识动作。因此**任何由错误世界诱导出的动作模态，都不能驱动交互或执行**；支撑扩张必须再认证（定义 324），故「支撑蔓延」不能悄悄扩大已认证安全集。**系：R69「问错比不问更危险」在 REALM 中被降级为「世界没确认前，问只亏效率，不亏安全」——前提是门控真的先于动作层。**

**定理 20（不可辨识时的后悔界）** 在 A100 / A103 下，若后验保持分散（`U_world^irr > 0`），WRP 的 CVaR 聚合满足
`E[R(θ*, ξ*_CVaR)] ≤ (1−β)^{-1} · L_θ · E_{p}[d_θ(θ, θ_med)] + ε_mode`，
其中 θ_med 为后验中位世界，ε_mode 为动作级残余。若后验集中，则 `E[d]→0`，退化为 R69 的模态选择。**系：不可辨识不是「再问一问」能解决的；正确回应是风险敏感地承认它，并把代价写进 J_REALM。**

## 6. 本轮最大风险

**一句话**：REALM 的全部保证都押在「认证支撑真的覆盖了部署世界」这一前提上——若真实世界落在支撑之外、却恰好与支撑内某个世界**观测等价**（LLM 想不出的长尾、DR 从未随机到的方向、或认证时被仿真器伪影骗过），e-value 不会报警、世界后验也不会分散，系统会在一个错误的世界里自信地执行 R69 的消歧逻辑；**检测不到的世界错配，比测不准更致命——因为它连「我错了」的机会都没有。**

**次级风险与缓解**：
1. **支撑盲区不可检测**（引理 20 的极限）→ 显式「未知保留区」+ 保守默认 + 定期人机在环再认证 + 永不宣称支撑外覆盖；
2. **LLM 幻觉 / 提示注入**→ 单调加假设契约（定义 323）+ SGC 物理认证 + 文本只能导致更保守（引理 21）+ E303/E312；
3. **世界集成拖垮实时预算** → 默认 N_w=1，仅异常触发扩到 ≤4 锚点；LLM 全离线 / 低频；E314 / 复杂度表；
4. **过度保守导致系统「不敢动」**（支撑太宽 / 长尾太多）→ 覆盖-保证前沿选点（定义 321）+ DFR 后验聚焦 + E308/E311；
5. **捷径学习被 DR 掩盖** → INV 语义不变式 + 反事实随机化 + E309；
6. **不可辨识被误当成可辨识** → CVaR 聚合（定义 319）+ 定理 20 + 证书里显式记录 `U_world^irr`。

# 第 70 轮产物 · 创新点清单 v1：REALM-RAS（Randomized-Environment support with Active Language-grounded Model-mismatch awareness：域随机化世界支撑 × 大语言模型语义先验的模型错配感知闭环；WSP×LSP×SGC×WID×H-VoI×WRP×INV×DFR×RAS-WM†）

> 承接第 69 轮 IP-253~263（FLUID-RAS）。R69 把「看 / 问 / 触」变成消歧动作，但把**世界模型本身**当成固定背景：它的 aleatoric / epistemic 二分只回答「同一个世界里该选哪个动作模态」，从未问「我是否还在那个世界里」。**域随机化**把这个默认项翻上台面——世界本是一族 `θ ~ p_φ(θ)`，**认证支撑 `S_cert` 才是全部保证的真实疆域**；支撑内随机化是鲁棒性，支撑外随机化是自信的谎。**大语言模型**提供另一半：它能从语言与常识提出相关结构与长尾世界（雨天湿滑、纸箱轻、老人慢、礼貌规范改变让行），也会幻觉出物理上不存在的世界。
>
> 核心命题：**把世界显式化为一族可随机化、可认证、可后验的 θ；LLM 只加假设，物理与数据删假设；世界后验逼近 / 越出支撑边界时，承认「不是动作不确定，而是世界假设错了」，用世界级辨识或模型无关安全取代动作级消歧。** 命名 **REALM-RAS**。
>
> 一句话定位：R69 问「我该向谁求证」，R70 问「**我脚下的世界还在我以为的那一族里吗；我的保证覆盖到哪里为止**」。IP 编号：IP-264~IP-275（共 12 个）；理论姿态为「R69 是本轮在 `Θ={θ0}`、无 LSP、无 WID 边界上的严格退化，R68 是『禁止交互』边界」。

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** 实时零学习写；**支撑即保证**（一切保证形如 `θ*∈S_cert ⇒ ...`）；**语义单调加假设**（LLM / 文本只能加、不能删）；**世界优先门控**（U_world 未受控时禁用动作级 VoI）；**严格包含**（`Θ={θ0} ∧ 无 LSP ∧ 无 WID` ⇒ R69；禁止交互 ⇒ R68）。

**定义 311–312（世界空间 / 支撑）** `θ=(θ_dyn,θ_sen,θ_sem,θ_task)`；世界模型 `M_θ`；`S_cert` 由「物理可行 Φ + 可实例化 I + 安全包络 E + 数据验证 D」定义；`R_sem = supp(q_ψ)\S_cert` 只能驱动离线采集；`d_S(θ)=inf_{θ'∈∂S_cert} d_θ(θ,θ')`。

**定义 313–314（LSP / SGC）** 场景卡 `C=(P,[a,b],Σ,r,O,F)`：参数、区间 / 相关结构、理由、可区分观测、可证伪实验；每卡带 provenance。SGC 四关认证；控制时只允许 `S_cert ← S_cert ∪ ·` 或重加权，删除必须带物理 / 数据证书 `E_phys`。**语义只提议，物理与数据盖章。**

**定义 315（WID）** 世界后验 `w_i ∝ w_i·p(o_t|M_{θ_i})`；`U_world` 拆为可辨识 / 不可辨识；e-value `e_t = p_{θ̂}(o_t|o_{<t}) / p_ref`，Ville 保证 `P(sup e_t ≥ 1/α) ≤ α`。

**定义 316（三元分解）** `U_ale`（世界内噪声）、`U_epi`（世界内动作模态歧义）、`U_world`（世界假设不确定 / 错配）；分通道、按层级处置，不做简单加和。

**定义 317（H-VoI）** 链式法则 `I((M,Θ);y|o) = I(Θ;y|o) + E_θ[I(M;y|o,θ)]`；`U_world^id > τ_w` 且决策对 θ 敏感 ⇒ 先选 `g_w`；世界集中后才允许 R69 动作模态交互。

**定义 318（三区门）** IN：后验质量 ≥1−α、`e_t<1/α`、`d_S≥m` ⇒ 正常 R69；RIM：近边界 / e 升高 / `d_S<m` ⇒ 禁动作级 VoI 与 bonus，只允许安全世界辨识或 R68 兜底；OUT：支撑外 / e 越阈 ⇒ 仅模型无关安全、OOD 声明、禁学习写。OUT→IN 必须再认证。

**定义 319–320（WRP / 退避）** 对每个 θ 得 `(m,λ_i)`，后验做 `argmin CVaR_β`；点质量时等于 R69。仅当「IN + U_epi 已消解」发 resolution bonus；否则 `λ=λ_floor(U_ale+U_epi^{unres}+f(U_world))`，世界不受控时 λ 不小于 R69。

**定义 321–322（覆盖前沿 / INV）** `S1⊆S2 ⇒ Cov↑` 但 `Risk*↑`、标称性能↓；DFR 在前沿上按后验 × 决策敏感度分配离线预算。`S_nui` 度量策略对冗余参数的依赖，抓 DR 捷径与仿真器伪影。

**定义 323–324（语言证据 / 扩张协议）** 文本是带 provenance 的证据，不是命令；无物理 / 数据证书不得收紧 `S_cert`。扩张只能经安全探索 / 人机在环 + SGC + 数据验证 + 证书重签；禁止实时权重写，杜绝支撑蔓延。

**定义 325–328（威胁 / 证书 / 审计 / 四元签名）** `ℰ_REALM=ℰ_FLUID×ℰ_support×ℰ_llm`；J_REALM 增支撑版本 / 覆盖率 / 裕度 / U_world / e-value / regime / 提案哈希 / S_nui；VQAuditor-W 审世界层决策；把 R69 的 `a_score(ξ|o)` 升级为 `a_score(ξ|o,θ)`，用 `(r_res, Δa, U_world, d_S)` 分离漂移 / 缓变故障 / 世界错配 / 不可辨识。

## 3. 关键算法伪代码

```python
# IP-264/265：世界支撑 + LLM 场景提议（LLM 只提假设）
class WorldSupport:
    def __init__(self, theta0, dr_prior, m=0.1, alpha=0.05):
        self.S_cert = {theta0}      # 保证的唯一疆域
        self.R_sem  = set()         # 未认证语义外缘
        self.m, self.alpha = m, alpha

def llm_propose(llm, language, caption, task, memory):
    return llm.structured_generate(SCENARIO_CARD, build(language, caption, task, memory))

# IP-266：SGC 四关 + 单调加假设
def certify(prop, wsp):
    ok = (physically_feasible(prop) and instantiable(prop)
          and safety_envelope_has_solution(prop) and data_does_not_refute(prop))
    if not ok: return 'rim'                     # 进 R_sem，不进控制
    wsp.S_cert = wsp.S_cert | prop.theta_range  # 只加
    return 'certified'

def may_shrink(world, evidence):
    return has_physical_and_data_certificate(evidence)   # 文本/LLM 默认 False

# IP-267：世界后验 + 支撑裕度 + anytime OOD
def update_worlds(worlds, obs, alpha):
    for w in worlds: w.loglik = w.model.predictive_loglik(obs)
    worlds.normalize()
    U_world = entropy(worlds.w) + dispersion(worlds.theta)
    d_S     = min(worlds.margin(t) for t in worlds.support())
    e_t     = worlds.best_density(obs) / worlds.ref_density(obs)
    regime  = ('OUT' if ville_alarm(worlds.e_process, alpha)
               else 'RIM' if (e_t > 1/alpha or d_S < M_MIN) else 'IN')
    return U_world, d_S, e_t, regime

# IP-268：先世界、后动作
def h_voi(worlds, modes_by_world, candidates):
    best = None
    for g in candidates:
        if not safe(g): continue
        score = (mutual_info_world(worlds, g)                    # I(Θ;y|g)
                 + mean(mutual_info_modes(worlds[w], g) for w in worlds)  # E[I(M;y|g,θ)]
                 - cost(g))
        if best is None or score > best.score: best = (g, score)
    return best

# IP-269：不可辨识时的 CVaR 聚合
def world_robust_select(worlds, obs, lam_floor, beta):
    cand = []
    for w in worlds.supported():
        lam = max(r69_risk_scale(w, obs), lam_floor)
        cand += [(w.theta, m, lam) for m in r69_decompose(w, obs)]
    return cvar_select(cand, worlds.w, beta)     # 点质量 ⇒ R69 select_mode

# IP-275：主闭环
def REALM_round(M, obs, language):
    if M.tick % T_LSP == 0:                      # 语义层：低频、非硬实时
        for c in llm_propose(M.llm, language, M.caption(obs), M.task, M.memory):
            (M.wsp.S_cert.add(c) if certify(c, M.wsp) == 'certified' else None)
    U_world, d_S, e_t, regime = update_worlds(M.wid.worlds, obs, M.alpha)
    if regime == 'OUT':                          # 只保留模型无关安全
        return M.safe_stop_or_ask(), 'OUT', M.cert(OOD=True)
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.mode_head)
    if regime == 'IN':
        g = (h_voi(M.wid.worlds, modes, M.info_candidates) if U_world > TAU_W
             else M.mint.choose_interaction(modes, o, M.budget) if U_epi > TAU_EPI else None)
        if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
        bonus = (U_epi < TAU_EPI and U_world < TAU_W)
    else:                                        # RIM：禁动作级 VoI
        g, bonus = h_voi(M.wid.worlds, modes, M.info_candidates), False
    U_floor = U_ale + (0.0 if bonus else U_epi) + M.f(U_world)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    mode = world_robust_select(M.wid.worlds, modes, lam, M.beta)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o, o_cal, theta=mode.theta)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if slow or regime != 'IN': lam = max(lam, 0.8); k = min(k, k_cal_shrink(...))
    M.vqa_w.submit(g, regime, U_world, d_S, e_t, M.wsp.version, a_hat)
    return k, lam, mode, (U_ale, U_epi, U_world, regime)
```

## 4. 推导

**假设 A99–A103**：A99 支撑覆盖 `P(θ*∈S_cert)≥1−α`；A100 风险关于 θ 为 `L_θ`-Lipschitz；A101 世界后验校准、e-value 在 H0 下 `E[e]≤1`；A102 认证提案可实例化、文本不能无证书收缩支撑；A103 不可辨识时后验保持正分散。

**引理 19（世界优先的 VoI 分解与门控）** 链式法则
`I((M,Θ);y|o) = I(Θ;y|o) + E_{θ}[I(M;y|o,θ)]`。
在 A100 下，错误 θ̂ 选模态的后悔 ≤ `L_θ·d_θ(θ*,θ̂) + regret_action`；R69 的动作级 VoI 只降低第二项。当 `L_θ·diam_p(Θ) > max_g E[I(M;y|g,o,θ)]` 时，世界优先门控严格优于动作优先。系：R69 是 `Θ={θ0}` 的边界。

**引理 20（支撑边界与 e-value）** `θ*∉S_cert` ⇒ DR 保证失效；Ville 保证误报 ≤ α；检测功效由 `θ*` 与 S_cert 混合预测的 f-散度决定。若二者观测等价（**支撑盲区**），任何有限样本检验都无法报警。系：检测极限由支撑几何而非样本量决定。

**引理 21（语言单调加假设的安全性）** 在 A102 下，任意文本 / LLM 只能加假设或在 S_cert 内重加权，故 `S_safe(t+1)⊆S_safe(t)`（除带证书扩张）。幻觉 / 提示注入只能导致过度保守与预算浪费，不能导致过度自信。系：**幻觉在安全侧免费，在效率侧收费。**

**引理 22（覆盖-保证前沿）** `S1⊆S2 ⇒ Cov(S2)≥Cov(S1)`，但 `Risk*(S2)≥Risk*(S1)`、标称性能一般下降。无免费午餐；DFR 在 `Cov` 与 `Risk*` 前沿上按后验 × 决策敏感度分配预算，而非均匀扩大盒式支撑。

**定理 18（REALM 严格包含 FLUID / CALM）** 在 A99–A103 下，`Θ={θ0}`、LSP / WID 关闭时，SGC 恒等、H-VoI→R69 MINT、WRP→`select_mode`、定义 320→R69 定义 307，故**逐指令等于 R69**；禁止交互时等于 R68。`θ*∈S_cert` 时 REALM 只收缩安全集 / 抬高 λ，安全风险 ≤ R69；`θ*∉S_cert` 时 R69 保证本已失效，REALM 显式 OOD 并退到模型无关安全。

**定理 19（世界级安全门）** RIM / OUT 区禁用动作模态 VoI 与 resolution bonus，`λ ≥ λ_floor(U_ale+U_epi+f(U_world))`，只允许模型无关安全动作与安全世界辨识动作；错误世界诱导的模态不能驱动交互或执行；支撑扩张必须再认证，故无支撑蔓延。系：R69「问错比不问更危险」被降级为「世界没确认前，问只亏效率不亏安全」。

**定理 20（不可辨识后悔界）** 在 A100 / A103 下，WRP 的 CVaR 聚合满足
`E[R(θ*,ξ*_CVaR)] ≤ (1−β)^{-1}·L_θ·E_p[d_θ(θ,θ_med)] + ε_mode`；
后验集中时 `E[d]→0`，退化为 R69 模态选择。系：不可辨识不是多问几次能解决的；应风险敏感地承认并记入 J_REALM。

## 7. 本轮最大风险

**一句话**：REALM 的全部保证都押在「认证支撑真的覆盖了部署世界」上——若真实世界落在支撑之外、却与支撑内某个世界**观测等价**（LLM 想不出的长尾、DR 从未随机到的方向、或认证被仿真器伪影骗过），e-value 不报警、后验不分散，系统会在错误世界里自信地执行 R69 的消歧逻辑；**检测不到的世界错配，比测不准更致命——它连「我错了」的机会都没有。**

**次级风险与缓解**：支撑盲区不可检测（引理 20）→ 显式未知保留区 + 保守默认 + 定期人机在环再认证，永不宣称支撑外覆盖；LLM 幻觉 / 提示注入 → 单调加假设契约 + SGC 物理认证 + 仅导致更保守（引理 21）+ E303/E312；实时预算 → N_w=1 默认 + 异常触发 ≤4 锚点 + LLM 全离线；过度保守 → 覆盖-保证前沿选点 + DFR + E308/E311；捷径学习 → INV 语义不变式 + 反事实随机化 + E309；不可辨识误判 → CVaR + 定理 20 + 证书记录 `U_world^irr`。
