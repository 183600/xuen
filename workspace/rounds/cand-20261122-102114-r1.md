# 第 1 轮（本轮灵感：「可用性评估」×「多机评测」）

> **基线**：上一轮产出 MetricVoiceGauge-NCD-HUTDH-v20 + IP-420–424（感知层完整方案）。
> 本轮纪律：**可用性是可证伪的约束、评测是可审计的证书、跨机泛化是可迁移的信任**。不推倒 v20：v20 的 PCA / CTS / CFC / HPC / CFCtrl 与 v19 / v17 全部保留。本轮只做一件事：把"这套证书到底好不好用、换台机器还成不成立"从**事后统计**提升为**一层可计算、可审计、可回退的证书**。

## 0. 直觉与动机

**灵感 1（可用性评估 → 可用性不是指标，而是证书的第二个坐标轴）**
直觉：v17–v20 的所有努力都在把证书"压紧"（更少假阳性、更小盲区）。但一个把整个动作空间都判成 UNSAFE 的证书，安全上是完美的、可用性上是灾难的。传统评测把"成功率 / 碰撞率 / 耗时"当排行榜数字，事后统计、与证书本身脱钩，于是"安全"和"好用"永远是两套互不相干的叙事。核心创新：**可用性感知证书 (Usability-Aware Certificate, UAC)**。证书不再只是一个布尔判定，而是 `UC = (verdict, utility, attribution, diagnosis, cost)`：在 SAFE 的每个 θ 上附带"这一步能推进多少任务"的**效用**、保守性来自哪个约束的**归因**、失败时能定位到哪个模块的**诊断线索**。关键反直觉点：**保守性不是免费的，也不是越多越安全**——真正的目标不是"最小碰撞域"，而是**可用性前沿 (Usability Frontier)** 上"单位保守性换来的任务效用"最大的那个点。

**灵感 2（多机评测 → 评测不是排行榜，而是一张可审计的证书）**
直觉：单机评测把"证书在 demo 机器上安全"误当成"证书安全"。不同机器人有不同的传感器套件、自由度、算力、动力学；同一张 HPC 在一台机器上 SAFE，换一台就可能因为标定 / 执行误差而 UNSAFE。传统 benchmark 只报均值，不报分层、不报统计功效、不报数据泄漏，于是"在 3 台机器上跑通"被当成"在所有机器上安全"。核心创新：**多机评测协议 (Multi-Machine Evaluation Protocol, MMEP)** 与 **评测证书 (Evaluation Certificate, EvalCert)**。评测按**具身分层 (Embodiment Stratification)** 采样，强制**预算对齐**与**种子固定**，并输出一张证书：它声明自己的任务分布、分层权重、统计功效、泄漏审计与负对照结果。关键反直觉点：**评测本身必须先被证明有效，才有资格证明系统有效**——一张没有功效分析与负对照的评测报告，只是"看起来漂亮"的数字。

**灵感 3（两者统一 → 评测格与有界回退）**
直觉：可用性评估回答"证书值不值得用"，多机评测回答"证书在哪些机器上值得信"。二者统一为 **评测格 (Evaluation Lattice)**：`ζ_eval = (uac_profile, embodiment_strata, eval_cert, invariance_witness, mode_eval)`。UAC 给出每个具身上的可用性剖面；MMEP 把剖面按具身分层聚合；EvalCert 给聚合结果盖章；**评测不变性 (Evaluation Invariance)** 决定这份结论能否迁移到新具身。关键反直觉点：**评测的信任不能无限回退**——"谁来评测评测"必须有界，最终锚定在**物理真值根 (Physical Ground-Truth Root)**（动作捕捉 / 力传感 / 人工复核），回退层数 ≤ 2，超过即拒绝而非默认信任。

**严谨定义（把上面的直觉钉死）**
- 证书 `Cert(θ) ∈ {SAFE, UNSAFE, UNKNOWN}` 沿用 v20 HPC；**安全判定函数不可被本轮修改**。
- 可用性剖面 `UAC_n(θ) = (utility_n(θ), attr_n(θ), diag_n(θ), cost_n(θ))`，其中 `attr_n(θ) = argmin_{m∈{CCV,PCA,CTS,CFC}} slack_m(θ)/slack_m^0` 为最紧约束（binding module），`diag_n(θ)` 为归因分布的熵（越小越可诊断）。
- 可用性前沿 `UF = { (conservatism(k), E[utility|k]) : k ∈ K_adm, CollisionRate(k) ≤ ε }`，只保留 Pareto 非支配点；`k = (margin_col, γ_threshold, ρ_scale, τ_consensus)` 为保守性旋钮。
- 评测证书 `EvalCert = (hash(D_task), SeedSet, S, {n_s}, power, LeakAudit, NegCtrl, hash(code), MerkleRoot)`；缺项即降级为假设。
- 评测不变性见证 `Inv(C)`：断言 `C` 在分层 `S` 上**符号一致**、合并置信区间不含 0、且每层碰撞率 ≤ ε；`Inv(C)=1` 才允许跨机迁移。

## 1. 研究问题（轮次升级版）

- **Q1（可用性证书的可计算性）**：如何把"这一步有多有用"从任务层安全地投影到证书层，而不让效用估计反过来污染安全判定？可用性前沿如何被高效逼近（无需扫全参数网格）？

- **Q2（归因与可诊断性）**：当证书保守或失败时，如何唯一地归因到 PCA / CTS / CFC / CCV 中的某个模块？归因不确定性如何量化，并进入 margin 而不制造新的盲区？

- **Q3（多机评测的公平性与统计功效）**：如何按具身分层，使不同机器人的样本量、任务难度、算力预算可比？在小样本（N ≤ 10 机器人、每机少量回合）下如何保证 Type I / II 误差可控？

- **Q4（评测不变性与跨机安全迁移）**：什么样的结论可以跨具身迁移？评测不变性如何被"见证 (witness)"而非断言？不满足不变性时如何无痛回退到 v20？

- **Q5（评测本身的可审计性）**：EvalCert 如何防止数据泄漏、选择性报告与 p-hacking？"评测的评测"如何有界终止在物理真值根，而不是无限套娃？

## 2. 设计原则（在 P31–P33 基础上新增 P34–P36）

**P34 可用性-安全分离律（Usability–Safety Separation）**
效用估计只允许在**已判定 SAFE 的子域**上排序，绝不参与 SAFE / UNSAFE 判定：`safe(θ) ⟺ v20_cert(θ)=SAFE`，`UC(θ).utility = f_task(θ)` 仅当 `safe(θ)`。`utility` 是证书的**只读标注**，任何反向影响安全的路径都被结构性切断。**效用不能扩张动作集合。**

**P35 评测证书律（Evaluation Certification）**
任何"更好"的断言必须附带 `EvalCert`，含任务分布哈希、种子集、分层、每层样本量、功效分析、泄漏审计、负对照、代码哈希与 Merkle 根；缺任一项的断言降级为**假设**，不得进入结论区。**没有证书的"更好"只是意见。**

**P36 有界回退律（Bounded Regress）**
评测信任链深度 ≤ 2（系统 → 评测 → 物理真值根）；超过深度或物理真值不可得时，**默认拒绝该评测结论**并回退 v20，而不是默认信任。**不可证伪的评测比没有评测更危险。**

## 3. 与基线的接口（如何退化）

- UAC 失效（效用 / 归因不可计算）⇒ 证书退化为 v20 HPC 的纯布尔判定 ⇒ 等价 v20；
- UFO 失效（前沿不可解 / 超时）⇒ 取 v20 原 margin ⇒ 等价 v20；
- MMEP / EvalCert 失效（评测不可信）⇒ 不采纳任何"更好"结论，只保留 v20 保守证书 ⇒ 等价 v20；
- EIT 失效（不变性不可判定）⇒ 禁止跨机迁移，逐机重测 ⇒ 等价 v20 的逐机部署；
- DT 失效（归因歧义）⇒ 返回 `AMBIGUOUS` 并升级人工 / 真值根，不自动调参；
- 全失效 ⇒ 完全回退 v20；`Exec_v21 ⊆ Exec_v20`。

## 4. 预期贡献

1. **可用性证书**：首次把"可用性"写成证书的第二坐标轴，给出可用性前沿的分离式优化，使"安全"与"好用"在同一对象内可比较、可证伪；
2. **可审计评测**：首次让评测本身成为证书，给出多机分层、功效分析、泄漏审计与负对照的完整协议；
3. **评测不变性**：给出跨机安全迁移的"见证"机制与有界回退，把"换台机器还能不能信"从经验变成可计算判据；
4. **归因诊断**：给出基于 Merkle proof + 反事实消融的模块级归因，使保守 / 失败可被定位而非被掩盖；
5. **端到端闭环**：安全（v20）→ 好用（UAC/UFO）→ 可换机（MMEP/EIT）三层叠加，保持 `Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。

## 5. 本轮最大风险

**一句话**：可用性前沿的效用信号来自**任务分布代理**，若评测任务分布与实际部署分布错配（长尾任务 / 长尾具身被分层采样系统性漏掉），系统会在"评测证书全绿"的情况下，为**未被评测覆盖的长尾具身**放行一个高效用但实际不安全的证书——即"评测集偏置下的可用性幻觉"。

# IP-425 Usability Certificate Compiler
class UsabilityCertificateCompiler:
    def __init__(self, hpc, task_model, module_slacks):
        self.hpc = hpc                    # v20 分层感知证书
        self.task = task_model            # 只读任务效用模型
        self.slacks = module_slacks       # m -> slack(θ) 可微/可采样函数

    def compile(self, node, obj, thetas):
        """把 v20 证书编译成 UC 剖面；绝不修改 SAFE/UNSAFE 判定。"""
        profile = {}
        for theta in thetas:
            verdict = self.hpc.cert(node, obj, theta)   # v20 判定，只读
            if verdict != "SAFE":
                profile[theta] = UAC(verdict=verdict,
                                     utility=None,       # 非 SAFE 无定义
                                     attribution=None,
                                     diagnosis=None,
                                     cost=self.hpc.query_cost())
                continue

            # 1. 效用只读标注（P34：不回流到安全判定）
            utility = self.task.expected_progress(theta)

            # 2. 归因：最紧约束 + 归因熵
            norm = {m: self.slacks[m](theta) / self.slacks[m].scale
                    for m in ("CCV", "PCA", "CTS", "CFC")}
            attr = min(norm, key=norm.get)
            dist = softmax_normalize(-np.array(list(norm.values())))
            diag = float(entropy(dist))       # 越小越可诊断

            # 3. 反事实影子价格：放松单模块 δ 是否能转为 SAFE
            shadow = {}
            for m in ("CCV", "PCA", "CTS", "CFC"):
                shadow[m] = self.counterfactual_relax(node, obj, theta, m,
                                                      delta=0.02)
            profile[theta] = UAC(verdict="SAFE", utility=utility,
                                 attribution=(attr, shadow), diagnosis=diag,
                                 cost=self.hpc.query_cost())
        return UsabilityProfile(profile=profile)

    def counterfactual_relax(self, node, obj, theta, module, delta):
        """仅用于估计保守性影子价格，结果不回写安全判定。"""
        relaxed = self.hpc.with_knob(module, delta)
        return 1.0 if relaxed.cert(node, obj, theta) == "SAFE" else 0.0


# IP-426 Usability Frontier Optimizer
class UsabilityFrontierOptimizer:
    def __init__(self, ucc, safety_filter, epsilon=0.0, margin_min=0.01):
        self.ucc = ucc
        self.safety = safety_filter       # 直接复用 v20 CCV
        self.eps = epsilon
        self.margin_min = margin_min

    def admissible(self, k):
        """容许域：旋钮不得低于 v20 安全下界。"""
        return (k.margin_col >= self.margin_min
                and k.gamma_threshold >= 0.85
                and k.rho_scale <= 1.0
                and k.tau_consensus <= 2.0)

    def frontier(self, task_stream, budget):
        """约束贝叶斯优化逼近 Pareto 前沿；所有候选先过安全过滤。"""
        points = []
        for k in self.propose(task_stream, budget):
            if not self.admissible(k):
                continue
            # 安全过滤：任何候选计划都必须逐点通过 v20 CCV
            if not self.safety.all_safe(task_stream, k):
                continue
            util = np.mean([self.ucc.compile_one(k, x) for x in task_stream])
            coll = self.safety.empirical_collision_rate(task_stream, k)
            if self.ucb_upper(coll) <= self.eps:      # 高置信上界
                points.append((self.conservatism(k), util, k))
        return pareto_nondominated(points)

    def select(self, frontier, utility_floor):
        """在效用不低于 floor 的前沿点中选保守度最低者。"""
        feasible = [p for p in frontier if p[1] >= utility_floor]
        return min(feasible, key=lambda p: p[0]) if feasible else None


# IP-427 Multi-Machine Evaluation Harness
class MultiMachineEvaluationHarness:
    def __init__(self, strata, seeds, alpha=0.05, power=0.8, mde=0.15):
        self.strata = strata          # list[Embodiment]
        self.seeds = seeds
        self.alpha = alpha
        self.power = power
        self.mde = mde

    def run(self, systems, task_dist, budget_per_stratum):
        """配对、分层、预算对齐地评测多个系统。"""
        results = {}
        for s in self.strata:
            # 每层固定回合数与种子；不同系统共享同一任务流
            n = self.sample_size(power=self.power, alpha=self.alpha, mde=self.mde)
            n = min(n, budget_per_stratum)
            paired = []
            for seed in self.seeds[:n]:
                task = task_dist.sample(stratum=s, seed=seed)
                row = {}
                for name, sys in systems.items():
                    row[name] = sys.episode(task, embodiment=s, seed=seed)
                paired.append(row)
            results[s.id] = paired
        return results

    def pooled_effect(self, results, baseline, treatment):
        """分层加权合并效应量 + 配对 bootstrap CI。"""
        effects, weights = [], []
        for sid, rows in results.items():
            d = [r[treatment].success - r[baseline].success for r in rows]
            effects.append(np.mean(d))
            weights.append(len(d))
        effects, weights = np.array(effects), np.array(weights)
        pooled = float(np.sum(effects * weights) / np.sum(weights))
        ci = paired_bootstrap_ci(results, baseline, treatment,
                                 n_boot=10000, alpha=self.alpha)
        return pooled, ci

    def negative_controls(self, systems):
        """负对照：必须被检出的退化系统。"""
        checks = {
            "disabled_collision": systems["broken_no_collision"],
            "label_shuffle": systems["shuffled_labels"],
        }
        return {name: self.detect_regression(sys) for name, sys in checks.items()}


# IP-428 Evaluation Certificate Auditor
class EvaluationCertificateAuditor:
    def __init__(self, preregistration):
        self.prereg = preregistration

    def audit(self, report, results):
        cert = EvalCert(
            task_hash=hash(report.task_dist),
            seeds=report.seeds,
            strata=report.strata,
            n_per_stratum={s: len(r) for s, r in results.items()},
            power=report.power,
            leak_audit=self.leakage_audit(report),
            neg_ctrl=report.negative_controls,
            code_hash=report.code_hash,
            merkle_root=report.merkle_root,
        )
        checks = {
            "prereg_match": self.matches_prereg(report),
            "all_strata_reported": set(report.strata) == set(results),
            "no_optional_stopping": self.no_optional_stopping(report),
            "power_ok": cert.power >= self.prereg.power,
            "no_leakage": cert.leak_audit["passed"],
            "neg_ctrl_behaved": all(cert.neg_ctrl.values()),
            "merkle_ok": verify_merkle(cert.merkle_root, report.proofs),
        }
        cert.valid = all(checks.values())
        cert.checks = checks
        return cert

    def leakage_audit(self, report):
        """训练/评测分离、时间切分、任务分布独立性。"""
        return {
            "temporal_split": report.eval_start > report.train_end,
            "task_disjoint": report.eval_tasks.isdisjoint(report.train_tasks),
            "seed_disjoint": report.eval_seeds.isdisjoint(report.train_seeds),
            "passed": (report.eval_start > report.train_end
                       and report.eval_tasks.isdisjoint(report.train_tasks)

# IP-429 Evaluation-Invariance Transfer
class EvaluationInvarianceTransfer:
    def __init__(self, delta_inv=0.25, epsilon=0.0, lipschitz=1.0):
        self.delta_inv = delta_inv
        self.eps = epsilon
        self.L = lipschitz

    def witness(self, claim, results, cert):
        """生成 Inv(C)：符号一致 + 合并 CI 不含 0 + 每层碰撞率达标。"""
        if not cert.valid:
            return InvarianceWitness(valid=False, reason="EVALCERT_INVALID")
        signs = {s: np.sign(claim.effect[s]) for s in results}
        consistent = len(set(signs.values())) == 1 and 0 not in signs.values()
        ci_excludes_zero = claim.ci[0] > 0 or claim.ci[1] < 0
        safe_each = all(claim.collision_rate[s] <= self.eps for s in results)
        return InvarianceWitness(
            valid=consistent and ci_excludes_zero and safe_each,
            signs=signs, ci=claim.ci, per_stratum_safe=safe_each,
        )

    def transfer(self, claim, witness, new_embodiment, strata):
        """新具身落在支撑域内才允许迁移，风险上界 ≤ ε + δ_inv·L。"""
        if not witness.valid:
            return None, "FALLBACK_V20"
        d = min(embodiment_distance(new_embodiment, s) for s in strata)
        if d > self.delta_inv:
            return None, "OUT_OF_SUPPORT"
        risk_bound = self.eps + d * self.L
        if risk_bound > self.eps:
            return None, "RISK_BOUND_EXCEEDED"
        return claim.effect_pooled, "TRANSFER_OK"


# IP-430 Diagnosis Traceback
class DiagnosisTraceback:
    def __init__(self, max_ablations=6, entropy_threshold=0.5):
        self.k = max_ablations
        self.H_thr = entropy_threshold

    def diagnose(self, hpc, node, obj, theta):
        """基于 Merkle proof 定位模块；消融次数有界。"""
        modules = ("CCV", "PCA", "CTS", "CFC")
        base = hpc.cert(node, obj, theta)
        impact = {}
        for m in modules[:self.k]:
            ablated = hpc.without_module(m, proof=hpc.merkle_proof(theta))
            impact[m] = self.verdict_distance(base, ablated.cert(node, obj, theta))
        total = sum(impact.values()) or 1.0
        dist = {m: v / total for m, v in impact.items()}
        H = float(entropy(np.array(list(dist.values()))))
        ranked = sorted(impact, key=impact.get, reverse=True)
        if H > self.H_thr:
            return DiagnosisCertificate(status="AMBIGUOUS", entropy=H,
                                        ranked=ranked, escalate=True)
        return DiagnosisCertificate(status="RESOLVED", top=ranked[0],
                                    confidence=1.0 - H, ranked=ranked,
                                    escalate=False)

## 3. 推导

**引理 157（可用性不扩张安全域）** UCC 仅在 `Cert_v20(θ)=SAFE` 上定义 `utility` 与 `attr`，且 P34 切断效用对安全判定的任何反向路径。故 `UC` 能授权的动作集合恒等于 v20 的 SAFE 集合，`Exec_v21 ⊆ Exec_v20`。∎

**引理 158（可用性前沿的安全性）** UFO 的候选旋钮先经 `admissible(k)`（`margin_col ≥ margin_min`、`γ ≥ 0.85`、`ρ_scale ≤ 1`、`τ ≤ TTL`）过滤，再经 v20 CCV 逐点安全过滤；前沿点只在通过过滤的候选上取 Pareto 支配。故 `UF ⊆ v20 安全域`，且前沿点不产生新的碰撞授权。∎

**引理 159（EvalCert 的统计有效性）** 在预注册 `α`、功效 `1-β`、配对设计与负对照齐备的条件下，ECA 的 `valid=1` 保证：错误拒绝原假设的概率 ≤ α，且 `disabled_collision` / `label_shuffle` 负对照必须被检出。若任一检查失败，`valid=0`，断言降级为假设（P35），不进入结论。∎

**引理 160（评测不变性 ⇒ 跨机迁移风险有界）** 若 `Inv(C)=1` 且新具身到已评测分层支撑集的距离 `d ≤ δ_inv`，则迁移风险满足 `risk ≤ ε + d·L`（`L` 为碰撞率对具身特征的 Lipschitz 常数）。当 `d·L ≤ ε - ε = 0` 或经校准后 `risk ≤ ε` 时允许迁移；否则返回 `FALLBACK_V20`。故迁移只在有界风险内发生。∎

**引理 161（归因可追溯性）** 若 Merkle proof 完整且 DT 的消融覆盖全部模块，则模块责任分布唯一确定；归因熵 `H ≤ H_thr` 时给出唯一 top 模块，`H > H_thr` 时返回 `AMBIGUOUS` 并升级，绝不伪造确定性。∎

**引理 162（v21 整体安全继承）** 在同一几何快照、同一机器人集合下，`Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。证明：UCC 只标注不授权（引理 157），UFO 只在前沿安全子集内选点（引理 158），EvalCert 只决定"结论是否可信"而非"动作是否安全"（引理 159），EIT 越界即回退 v20（引理 160），DT 只读不写。五者叠加只产生子集。∎

## 7. 已知风险与失效模式

1. **效用代理错配（Goodhart）**：`utility` 是任务推进的代理，若代理与真实任务价值偏离，UFO 会把证书推到"指标好看但任务无意义"的前沿点。缓解：多目标效用、人工偏好校准、效用审计。
2. **长尾具身盲区**：分层采样可能系统性漏掉稀有具身（特殊传感器 / 极端动力学），使 `Inv(C)` 在支撑域内成立却在长尾失效。缓解：主动长尾采样、OOD 检测、保守 `δ_inv`、默认回退。
3. **小样本功效不足**：N ≤ 10 且每机回合少时，合并估计的 CI 过宽，`Inv(C)` 可能因功效不足而误判。缓解：配对设计、分层借力、贝叶斯先验、预注册 MDE。
4. **评测泄漏 / 选择性报告**：任务、种子或时间切分不当会制造虚假提升；只报显著层是隐蔽的 p-hacking。缓解：ECA 强制全层报告、负对照、预注册与 Merkle 审计。
5. **归因歧义**：模块耦合（PCA 与 CTS 同时收紧）会让 DT 的消融相互抵消，产生高熵。缓解：联合消融、Shapley 近似、`AMBIGUOUS` 升级而非猜测。
6. **真值根不可靠**：`dt_root` 依赖动捕 / 力传感 / 人工复核，其自身有噪声与标定漂移；若真值根偏，整个评测证书被"正确地"锚在错误上。缓解：多源真值交叉、标定周期、真值不确定性传播。
7. **跨机特征空间假设**：EIT 用 `embodiment_distance` 判断支撑域，若特征空间不能反映真实动力学差异，距离会失真。缓解：学习具身嵌入、对抗验证、逐机重测兜底。
8. **评估开销挤压实时性**：UAC 编译与 DT 消融若进入控制环，会破坏 50Hz 预算。缓解：离线/异步编译、只读缓存、控制路径只查预编译 UC。

## 8. 本轮最大风险

**一句话**：可用性前沿与评测证书都建立在**任务分布与具身分层的采样支撑集**上；一旦长尾任务或长尾具身被系统性漏采，系统会在"分层全绿、功效达标、负对照通过"的完美评测下，把**未被支撑集覆盖的真实部署**误判为可迁移安全域——即"评测证书越完整，越可能为评测之外的失败背书"的**支撑集幻觉**。
