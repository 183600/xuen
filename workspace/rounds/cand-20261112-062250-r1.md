# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感驱动研究循环第 1 轮（新循环）；本轮灵感：「关节驱动」×「用户共创」）

> 第 59 轮把证据承诺一路钉到执行层物理：BUQ 在线辨识电机不确定性、ERTC 契约化嵌入式实时性、EEIS 把 δ_f 编译成阻抗参数与安全证书、CLEP 让执行实测回流证据层。但它仍默认了两个更深的前提：**其一，关节是理想力矩源**——电机转矩经刚性传动无损地变成关节转矩，末端阻抗参数可以被精确执行；**其二，安全目标是单主体定义的**——δ_f、ε_traj、F_max 由工程师一次性给定，用户只是「需求提出者/操作者」，不参与安全边界的共同作者化。**关节驱动**恰好击穿第一个前提：真实关节含谐波减速器迟滞、串联弹性（SEA/VSA）储能、背隙、腱绳蠕变、摩擦与热致刚度漂移，`τ_joint` 对 `τ_motor` 的映射是**非线性、有记忆、非唯一可逆**的两端口；更关键的是**弹性储能可以在毫秒级释放为冲击力**，使第 59 轮「瞬时力限幅」在能量意义上不再充分。**用户共创**恰好击穿第二个前提：用户通过演示、纠正、偏好表达、技能编排共同作者化机器人行为，安全与「好」不再由单一主体定义；但共创同时带来**偏好漂移、硬地板侵蚀、责任稀释**三类风险。本轮核心命题：**「把关节从『理想力矩源』还原为『含弹性储能/迟滞/背隙的两端口物理契约』；把用户从『需求提出者』升级为『硬安全地板内的共同作者』；并用一条不可越权的单向安全律钉死——关节模型只能修正执行证据、用户共创只能收紧约束或在地板内重塑目标，二者都绝不能放松硬安全边界。」**

核心矛盾：
- **H32（关节抽象泄漏·弹性储能与迟滞非可逆）**：第 59 轮 EEIS 在末端空间给出 `F_max, K_p, K_d` 证书，默认这些参数能被关节精确执行。实则：谐波传动迟滞使同一电机转矩对应一段关节转矩区间；SEA 的 `½K_sea·Δθ²` 储能在接触瞬间释放，峰值接触力由**能量**而非**瞬时力矩**决定；背隙在换向时产生力突跳；编码器偏心与力矩传感器串扰使力矩估计有偏。若继续用「末端瞬时力限幅 + 刚性逆动力学」，系统会在「电流/力矩都未超限」的情况下打出超限冲击——**证书在电机侧成立、在接触侧失效**。
- **H33（用户共创·安全定义的多主体性与地板漂移）**：共创意味着用户参与定义目标、软风险容忍与行为风格。但若直接把用户偏好当作安全约束的放宽依据，`δ_f` 会被逐步「谈判」到危险区；反过来，若安全完全不可协商、用户任何偏好都被拒绝，机器人将退化为不可用的「安全摆设」。真正需要的是**双包络分离**：不可协商的硬地板 `S_hard`（治理给定）与用户共创的软包络 `S_soft(θ_co)`（偏好给定），并证明 `S_soft ⊆ S_hard` 恒成立、投影算子 `Π_co` 永不出界。
- **H34（共创归属·责任稀释与证据越权）**：当行为由用户演示 + 机器人泛化共同产生，失败后责任归属不清；更危险的是用「用户说可以」冒充物理证据，去替代力/接触/跨模态佐证。必须建立**归属账本**与**非对称证据律**：用户偏好/演示是「目标与结构」的来源，**不是独立的物理观测**，不能进入 `EV-xmodal/EV-human` 佐证集；用户作者的技能被机器人自主执行时，执行责任仍由执行证据链承担。

## 0. 直觉与动机

**灵感 1（关节驱动 → 关节驱动建模与储能安全 JAM）**
直觉：关节不是「理想力矩源」，而是**带记忆、带储能、带间隙的两端口元件**。电机端口 `(τ_m, θ_m)` 与关节端口 `(τ_j, q)` 之间由三重非线性连接：迟滞 `H_γ[·]`（Prandtl–Ishlinskii 算子，谐波/腱绳/摩擦共同贡献）、背隙 `B_{b_g}(·)`、串联弹性 `K_sea(θ_m/N − q) + b_sea(θ̇_m/N − q̇)`。于是「给定期望关节力矩，反解电机电流」不是单值映射，而是一个**区间/椭球**：`T_m^{-1}(τ_j^des) = {τ_m | τ_j^des ∈ G(τ_m, ξ_joint)}`。关键洞见不在迟滞本身，而在**能量**：`E_sea = ½K_sea(θ_m/N − q)²` 是可在接触瞬间释放的势能，峰值接触力近似 `F_pk ≈ sqrt(2 K_env E_release)`（能量法），因此第 59 轮「瞬时 `F ≤ F_max`」必须升级为「**可释放能量 `E_release ≤ E_safe(δ_f, K_env)`**」。把 `ξ_joint=(K_sea,b_sea,迟滞参数,背隙,摩擦,编码器偏心,力矩传感器偏置/增益,热漂移)` 纳入在线辨识，输出**关节级结构化似然修正**与**能量上界**，供 EEIS 做证书提升。

**灵感 2（关节驱动 → 关节物理契约与证书提升 JPC）**
直觉：末端证书与关节可行性之间存在**语义鸿沟**。EEIS 输出的是末端阻抗 `(K_p,K_d,F_max,ω_traj)`，而执行器受限于关节转矩上限、关节速度、SEA 储能上限、传动迟滞界、热降额与奇异位形。把末端证书「抬升」到关节空间：`K_q = Jᵀ K_p J + (∂Jᵀ/∂q)F`（含几何刚度项），`τ_j = Jᵀ F`，并要求 `σ_min(J) ≥ σ_min^req`（远离奇异）、`‖τ_j‖_∞ ≤ τ_j_max`、`E_sea^req ≤ E_sea_max`、`K_q` 落在传动可实现刚度区间。定义**提升裕度** `m_lift = min{...}`；`m_lift ≤ 0` 即 `CERT_LIFT_FAIL`，必须降级（更软阻抗/换位形/停），而不是「假设它能执行」。这把第 59 轮 `K_safe=∅ ⇒ 降级` 从「末端无解」扩展到「**末端有解但关节执行不了**」。

**灵感 3（用户共创 → 双包络与安全投影 CCE）**
直觉：安全不能由单一主体定义，但也不能由任意主体随意放宽。采用**双包络**：硬地板 `S_hard={π | Risk(π) ≤ ε_hard}` 由治理与法规给定、**对用户不可协商**；软包络 `S_soft(θ_co)={π | U_user(π;θ_co) ≥ u_min, Risk(π) ≤ ρ_soft(θ_co)}` 由用户偏好 `θ_co` 塑形，且**按构造**满足 `ρ_soft(θ_co) ≤ ε_hard`。用户共创发生在硬地板**之内**：`π* = argmax_{π ∈ S_hard} U_user(π;θ_co)`（投影/约束优化），因此「共创」改变的是**在地板内如何去、多快、多柔顺、多主动**，而不是地板本身。更进一步，用户共创不仅是「调偏好」，还包括**编写技能**：引入**安全类型化技能语法**——每个原语带效果类型（改变哪个区域、施多少力、储多少能量），用户编排的技能必须通过类型检查（前置条件蕴含后置条件、累计效果不越契约），不安全技能在部署前被拒绝。偏好用 Bradley–Terry/GP 从演示与纠正学习，并用**共形偏好集** `Θ_co`（覆盖率 `1−α_co`）显式表示「用户偏好本身也不确定」。

**灵感 4（用户共创 → 共权仲裁与归属账本 SAL/APL）**
直觉：共创必须落到「谁在何时有最终决定权」。定义共享权限 `α_auth ∈ [0,1]`，仲裁规则分三层：用户指令**出硬地板** ⇒ 机器人必须拒绝并给出「最小违规证书」与安全替代；用户在**软包络外但地板内** ⇒ 升级请求确认（不静默执行）；用户在**软包络内** ⇒ 可把权限交给用户/融合策略。安全不变性由**投影算子**保证：`π_sa = Π_{S_hard}((1−α)π_robot + απ_user)`，对任意 `α` 都不出界。归属方面，行为由多源数据共同塑造（用户演示、用户纠正、机器人自采、先验、云端），用影响函数/Shapley 近似得到**溯源向量** `w_prov`，失败时可定位最小责任子集并回滚重认证；同时设**反责任洗白律**：若用户作者的技能被机器人自主执行，`w_robot` 不得低于 `w_min`，执行责任仍由 `EV-exec` 承担。

**灵感 5（五者合流 → 共创-关节闭环 JCAL 与共创预算 COB）**
直觉：JAM 回答「关节到底做了什么、存了多少能量」，JPC 回答「末端证书能不能在关节上兑现」，CCE 回答「用户在地板内想要什么」，SAL 回答「此刻谁说了算」，APL 回答「这个行为是谁的作品」；再叠加第 59 轮的 CLEP/ERTC/BUQ/EEIS，形成**共创-关节闭环 JCAL**：辨识关节 → 提升并校验契约 → 取偏好共形集 → 共权仲裁 → 硬地板内软优化 → 下发带证书的关节阻抗 → 执行并收集关节遥测与用户反馈 → 更新归属与预算 → 回流证据层。新增**共创预算 `B_co`**（用户注意力、演示次数、确认时延、信任裕度）：向用户提问/求确认本身有成本，只有当 `voi_co = E[ΔU_user] − cost_attention − cost_latency > θ_co` 时才打扰用户；五预算 `B_probe/B_ft/B_ux/B_exec/B_co` 硬隔离、互不挪用。

## 1. 形式化定义（增量：定义 153–161）

**定义 153（关节两端口驱动模型 JAM）** 关节驱动状态
```
ξ_joint = (K_sea, b_sea, {r_l, w_l}_{l=1..L_PI}, b_g, c_v, c_c, e_x, e_y, τ_bias, τ_gain, c_creep, T_j)
```
其中 `{r_l,w_l}` 为广义 Prandtl–Ishlinskii 迟滞算子的阈值/权重，`b_g` 为背隙宽度，`(e_x,e_y)` 为编码器偏心，`(τ_bias,τ_gain)` 为力矩传感器偏置/增益，`c_creep` 为弹性体蠕变，`T_j` 为关节温度。两端口前向模型（`N` 为减速比，`H_γ` 为迟滞算子，`B_{b_g}` 为背隙算子）：
```
τ_m   = K_t i_q
τ_j   = H_γ[ K_sea (θ_m/N − q) ] + b_sea (θ̇_m/N − q̇)
        + B_{b_g}(q) + c_v q̇ + c_c sign(q̇) + c_creep q
E_sea = ½ K_sea (θ_m/N − q)²
τ_s   = τ_gain τ_j + τ_bias + v_s        (力矩传感器)
```
辨识器 `UKF_joint` 以 `(q, θ_m, i_q, τ_s, T_j)` 为观测、`ξ_joint` 为状态（慢漂移过程模型），满足收敛契约 `‖ξ_joint−ξ_true‖_P⁻¹ ≤ χ²_dof(1−α_j)`。定义**逆映射歧义度** `Amb(τ_j^des)=diam{τ_m | τ_j^des ∈ G(τ_m,ξ_joint)}` 与**可释放能量上界**
```
E_release = E_sea + ½ b_sea (Δθ̇)² + E_kin^eff
```
对最大环境刚度 `K_env_max`，峰值接触力满足 `F_pk ≤ sqrt(2 K_env_max E_release)`（能量法）。JAM 输出关节级结构化似然修正 `L_joint(obs|τ_j, ξ_joint)` 与 `(Amb, E_release)`。OOD：`ξ_joint` 落出置信椭球或 `Amb` 超过阈值 ⇒ `JOINT_OOD`，触发共形保底带与关节降级。

**定义 154（关节物理契约与证书提升 JPC）** 关节契约
```
C_joint = (τ_j_max, F_pk_max, E_sea_max, q_min, q_max, q̇_max,
           Δ_hys_max, b_g_max, K_sea∈[K_sea_min,K_sea_max], thermal_derate, σ_min^req)
```
运行时监视器 `M_joint` 周期采样关节转矩、储能、迟滞、背隙、温度、雅可比条件数。给定末端证书 `Cert_eeis=(K_p,K_d,F_max,ω_traj,...)` 与位形 `q`，**证书提升**：
```
K_q = Jᵀ(q) K_p J(q) + (∂Jᵀ/∂q)(q) F_max      # 含几何刚度
τ_j = Jᵀ(q) F_max
E_sea^req = ½ F_max² / K_env_est
m_lift = min{ τ_j_max − ‖τ_j‖_∞,
              E_sea_max − E_sea^req,
              (σ_min(J) − σ_min^req) · κ_J,
              K_sea_max − λ_max(K_q),
              F_pk_max − sqrt(2 K_env_max E_release) }
```
`m_lift > 0` 且 `Amb`、迟滞、背隙均守界才输出 `Cert_joint = (K_q, τ_j, F_pk, E_sea, m_lift, Amb, hys, b_g, version, q_hash)`；否则 `CERT_LIFT_FAIL`，必须 `DEGRADE_JOINT`（更软阻抗/换位形/减速/停）。提升的**音性**要求：`m_lift>0 ⇒ 关节约束全部满足`；**完备性**要求：`m_lift≤0 ⇒ 存在至少一项不可兑现`。

**定义 155（用户共创双包络与安全投影 CCE）** 用户偏好状态 `θ_co ∈ Θ`（速度、柔顺度、自主度、接触容忍、可接受风险姿态等），由演示 `D_demo` 与纠正 `D_corr` 经 Bradley–Terry/GP 偏好模型学习，并给出共形偏好集 `Θ_co={θ | s_pref(θ) ≤ r̂_co}`（覆盖率 `≥1−α_co`）。硬地板与软包络：
```
S_hard      = {π | Risk(π) ≤ ε_hard}                    # 治理给定，用户不可协商
S_soft(θ)   = {π | U_user(π;θ) ≥ u_min(θ), Risk(π) ≤ ρ_soft(θ)}
ρ_soft(θ)  ≤ ε_hard  (按构造),  S_soft(θ) ⊆ S_hard, ∀θ∈Θ_co
```
共创投影 `Π_co(θ) = argmax_{π∈S_hard} U_user(π;θ)`。**安全类型化技能语法** `G`：每个原语 `p` 带效果类型 `Eff(p)=(ΔR, ΔF, ΔE, ΔT)`（区域、力、储能、时长效果）；用户编排技能 `σ=p_1;…;p_n` 必须通过类型检查 `Γ ⊢ σ : Safe`，即前置条件 `Pre(p_i)` 被前序效果蕴含、累计 `ΣEff` 不越 `C_joint` 与 `S_hard`。未通过者拒绝部署，并给出反例轨迹（类型错误最小证书）。

**定义 156（共权仲裁 SAL）** 共享权限 `α_auth ∈ [0,1]`，机器人策略 `π_r`、用户策略 `π_u`、用户偏好模型 `U_user`。仲裁结果
```
π_sa = Π_{S_hard}( (1−α_auth) π_r + α_auth π_u )
```
仲裁分级规则：
```
if π_u ∉ S_hard:                 REFUSE + MinimalViolationCert + safe_alt
elif π_u ∉ S_soft(θ_co):         ESCALATE（请求确认，不静默执行）
else:                            FOLLOW / BLEND（α 生效，仍过 M_joint 运行时守界）
```
共权切换有界时延 `τ_ho ≤ T_ho_max`；切换期间执行「保持+降速+增柔顺」安全接管。`α_auth` 由信任标定更新但**不得**改变 `S_hard`：`α_auth` 只影响 `S_hard` 内如何混合，不影响地板本身（安全不变性）。

**定义 157（归属-溯源账本 APL）** 数据源集合 `S={user_demo, user_corr, robot_self, prior, cloud}`。对行为级结果泛函 `φ`（成功/风险/跟踪误差），源 `s` 的归属用 Shapley 值近似：
```
w_s = Shapley_s(φ; D) ≈ Σ_{i∈D_s} −∇_θ L(z_i,θ)ᵀ H_θ⁻¹ ∇_θ φ
w_prov = normalize(w_s, s∈S) ∈ Δ^{|S|−1}
```
账本条目 `ℓ=(behavior_id, w_prov, evidence_refs, consent_token, α_auth, timestamp, prev_hash)` 哈希链式不可篡改。**反责任洗白律**：任一由机器人自主执行的行为，`w_robot ≥ w_min`；用户作者技能被执行时，失败仍须由 `EV-exec/Cert_joint` 链承担执行责任。失败归因：`s* = argmax_s w_s`，回滚最小责任子集 `S_resp`（源级/技能级），经第 59 轮 CEB++++ 隔离区影子复核后方可重新上线。

**定义 158（共创预算 B_co 与 PCE++++）** `B_co=(attention_left, demo_left, ratification_time_left, trust_margin)`。向用户提问/求确认的价值：
```
voi_co(a) = E[ΔU_user | query a] − λ_attn·attention(a) − λ_lat·latency(a) − λ_trust·trust_cost(a)
```
仅当 `voi_co > θ_co` 且 `B_co.viable()` 时打扰用户；注意力耗尽 ⇒ 采用保守默认（降速、增柔顺、减少主动探询）并记账。五预算 `B_probe/B_ft/B_ux/B_exec/B_co` 单调消耗、硬隔离、不可挪用；任一耗尽 ⇒ 保守降级（缩小动作集/带保护轻触/绕行/协商/停）。

**定义 159（关节-共创联合编译 JCC）** 两阶段编译：
```
Hard:  K_joint^safe = { K_q | m_lift(K_q; Cert_eeis, C_joint, q) > 0
                              ∧ Risk(K_q) ≤ ε_hard ∧ E_release ≤ E_sea_max }
       if K_joint^safe = ∅: return DEGRADE_JOINT
Soft:  π* = argmax_{π ∈ K_joint^safe ∩ S_soft(Θ_co)} U_user(π;θ_co)
       if π* = ∅: return NEGOTIATE_OR_STOP（请求放宽软偏好/降档，不得放宽硬地板）
```
输出 `Cert_jc=(Cert_eeis, Cert_joint, θ_co, Θ_co, w_prov, α_auth, consent_state, E_release, m_lift, version, hash)`。

**定义 160（共创约束对账 XMC+++ 与单向安全律）** 共创不是独立观测模态，而是**约束/目标模态**。定义共创意见分歧（只统计保守方向）
```
D_co(r) = Σ_a w_a · 1[ δ_user(a)=unsafe ∧ δ_fused(a)=safe ] · margin_gap(a)
D+++    = D++ + w_co·D_co
```

### IP-152 JAM（关节两端口建模与储能安全）

```python
class JointActuationModel:
    def __init__(self, joint_spec, N, alpha_j=0.01):
        self.N = N
        self.spec = joint_spec
        self.ukf = UKF(state_dim=13, obs_dim=5)  # ξ_joint
        self.ripple_pi = PrandtlIshlinskii(n_thresholds=5)
        self.alpha_j = alpha_j

    def two_port_forward(self, xi, theta_m, q, dtheta_m, dq, i_q):
        K_sea, b_sea, *pi_params, b_g, c_v, c_c, e_x, e_y, tau_b, tau_g, c_cr, T_j = xi
        x = theta_m / self.N - q
        dx = dtheta_m / self.N - dq
        tau_j = self.ripple_pi.apply(K_sea * x, pi_params) + b_sea * dx
        tau_j += backlash(q, b_g) + c_v * dq + c_c * np.sign(dq) + c_cr * q
        E_sea = 0.5 * K_sea * x**2
        tau_s = tau_g * tau_j + tau_b
        return tau_j, E_sea, tau_s

    def torque_sensor_bias_corrected(self, tau_s, xi):
        tau_b, tau_g = xi[9], xi[10]
        return (tau_s - tau_b) / tau_g

    def update(self, telemetry):
        q, theta_m, i_q, tau_s, T_j, dtheta_m, dq = telemetry
        def h(xi):
            tau_j, E_sea, tau_s_pred = self.two_port_forward(
                xi, theta_m, q, dtheta_m, dq, i_q)
            enc_q = q + xi[6] * np.cos(q) + xi[7] * np.sin(q)  # 偏心
            return np.array([enc_q, theta_m, i_q, tau_s_pred, T_j])
        self.ukf.update(np.array([q, theta_m, i_q, tau_s, T_j]), h=h)

    def inverse_torque_set(self, tau_des, xi, tol=1e-3):
        # 迟滞/背隙导致非唯一：区间采样
        lo, hi = -np.inf, np.inf
        for tau_m in np.linspace(-self.spec.tau_m_max, self.spec.tau_m_max, 4097):
            tau_j, _, _ = self.two_port_forward(xi, *self.state_from_torque(tau_m))
            if abs(tau_j - tau_des) <= tol:
                lo, hi = min(lo, tau_m), max(hi, tau_m)
        return lo, hi, (hi - lo if np.isfinite(hi - lo) else np.inf)

    def energy_release_bound(self, xi, xi_prev, dt, K_env_max):
        E_sea = self.two_port_forward(xi, *self.last_state)[1]
        E_dyn = 0.5 * xi[1] * ((self.dtheta_m_prev / self.N - self.dq_prev)**2)
        E_kin = 0.5 * self.spec.effective_inertia * self.dq_prev**2
        E_release = E_sea + E_dyn + E_kin
        F_pk_ub = np.sqrt(2 * K_env_max * E_release)
        return E_release, F_pk_ub

    def is_ood(self):
        return self.ukf.mahalanobis() > chi2.ppf(1 - self.alpha_j, df=13)
```

class JointContractLifter:
    def __init__(self, contract, motor_params):
        self.C = contract
        self.motor = motor_params

    def lift(self, cert_eeis, xi_joint, q, env_stiffness_est):
        J = self.jacobian(q)
        dJ = self.jacobian_derivative(q)
        K_q = J.T @ np.diag([cert_eeis.K_p]*3) @ J + dJ.T @ (cert_eeis.F_max * np.ones(3))
        tau_j = J.T @ np.array([cert_eeis.F_max, cert_eeis.F_max, cert_eeis.F_max])
        E_sea_req = 0.5 * cert_eeis.F_max**2 / max(env_stiffness_est, 1.0)

        sigma_min = np.linalg.svd(J, compute_uv=False).min()
        K_env_max = self.env_stiffness_upper(env_stiffness_est)
        E_release, F_pk_ub = self.joint_model.energy_release_bound(
            xi_joint, self.joint_model.last_xi, dt=0.001, K_env_max=K_env_max)

        m_lift = min(
            self.C.tau_j_max - np.abs(tau_j).max(),
            self.C.E_sea_max - E_sea_req,
            (sigma_min - self.C.sigma_min_req) * self.kappa_J,
            self.C.K_sea_range[1] - np.linalg.eigvalsh(K_q).max(),
            self.C.F_pk_max - F_pk_ub,
        )
        if m_lift <= 0:
            return None, LiftFailure(m_lift, tau_j, E_sea_req, F_pk_ub, sigma_min)

        cert_joint = JointCertificate(
            K_q=K_q, tau_j=tau_j, F_pk=F_pk_ub, E_sea=E_sea_req, m_lift=m_lift,
            ambiguity=self.joint_model.inverse_torque_set(tau_j.max(), xi_joint)[2],
            hys=self.estimate_hysteresis(xi_joint), backlash=self.estimate_backlash(xi_joint),
            q_hash=hash(q.tobytes()), version=self.version)
        return cert_joint, None

### IP-154 CCE（共创双包络与安全投影）

```python
class CoCreativeEnvelope:
    def __init__(self, epsilon_hard, alpha_co=0.05):
        self.eps_hard = epsilon_hard
        self.alpha_co = alpha_co
        self.r_hat_co = None  # 共形阈值

    def fit_preference(self, D_demo, D_corr):
        # Bradley-Terry / GP 偏好模型：p(θ_co | D)
        self.pref_model = BradleyTerryGP().fit(D_demo, D_corr)
        return self.pref_model

    def conformal_pref_set(self, D_calib):
        scores = [self.pref_model.nonconformity(theta) for theta in D_calib]
        self.r_hat_co = np.quantile(scores, 1 - self.alpha_co)
        return self.r_hat_co

    def soft_envelope(self, theta):
        rho_soft = min(self.pref_model.risk_tolerance(theta), self.eps_hard)
        return SoftEnvelope(u_min=self.pref_model.u_min(theta), rho_soft=rho_soft)

    def project(self, theta, candidate_policies, risk_fn, utility_fn):
        feasible = [p for p in candidate_policies
                    if risk_fn(p) <= self.eps_hard
                    and utility_fn(p, theta) >= self.soft_envelope(theta).u_min]
        if not feasible:
            return None, "SOFT_INFEASIBLE"
        return max(feasible, key=lambda p: utility_fn(p, theta)), None

    def typecheck_skill(self, skill, grammar, joint_contract):
        effects = (0.0, 0.0, 0.0, 0.0)  # ΔR, ΔF, ΔE, ΔT
        for prim in skill.primitives:
            if not grammar.has(prim):
                return False, TypeError("unknown_primitive", prim)
            if not implies(skill.pre, prim.pre):
                return False, TypeError("precondition_violation", prim)
            effects = add_effects(effects, prim.effects)
        if exceeds(effects, joint_contract):
            return False, TypeError("contract_overflow", effects)
        return True, None
```

def arbitrate_shared_authority(pi_r, pi_u, theta_co, S_hard, S_soft, alpha_auth):

def update_authority(alpha_auth, trust_estimate, risk_margin, dt):
    # 信任标定：仅在有充分安全裕度时逐步授权，撤销授权更快
    target = clip(trust_estimate, 0.0, 1.0)
    rate_up, rate_down = 0.05, 1.0
    rate = rate_up if target > alpha_auth else rate_down
    return clip(alpha_auth + rate * (target - alpha_auth) * dt, 0.0, 1.0)

class AttributionLedger:
    def __init__(self, w_min=0.1):
        self.w_min = w_min
        self.chain = []
        self.prev_hash = "genesis"

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| JAM | UKF O(d³), d=13 ≈ 2.2k flops/周期；反解区间采样 O(N_sample) | O(d²) | 辨识收敛契约、`Amb`/`E_release` 上界诚实、OOD 漏检 ≤δ_j_ood |
| JPC | O(提升) = O(3³ + 采样) / 位形 | O(1) | 提升音性 `m_lift>0 ⇒ 全约束满足`；完备性 `m_lift≤0 ⇒ 不可兑现` |
| CCE | 偏好拟合 O(N_demo·d_θ²)；投影 O(\|Π\|·d) | O(N_demo + \|Θ_co\|) | `S_soft(θ)⊆S_hard`、投影不出界、技能类型检查可靠 |

**正确性定理（Co-Authored Safety Soundness, CASS）**
假设 A51–A55（第 59 轮）成立；**(A56)** JAM：`UKF_joint` 在 `N_j` 次接触后满足 `‖ξ_joint−ξ_true‖_P⁻¹ ≤ χ²_dof(1−α_j)`；迟滞/背隙/储能上界模型诚实包含真实行为；OOD 漏检率 ≤δ_j_ood。**(A57)** JPC：证书提升音且完备；`m_lift>0 ⇒ τ_j、E_sea、σ_min、K_q、F_pk 全满足契约`；`m_lift≤0 ⇒ 至少一项不可兑现`。**(A58)** CCE：偏好模型与共形集 `Θ_co` 覆盖率 `≥1−α_co`；`U_user` 为真实用户偏好的诚实估计；`ρ_soft(θ)≤ε_hard` 按构造成立；技能类型系统可靠（通过 ⇒ 累计效果不越契约）。**(A59)** SAL：投影算子 `Π_{S_hard}` 精确；仲裁分级规则穷尽；切换时延 ≤T_ho_max；`M_joint` 运行时监视器权威。**(A60)** APL/COB：影响函数归属为 Shapley 值的 `O(1/√|D|)` 近似；`w_robot≥w_min`；五预算单调消耗、互不挪用。则：

1. **关节-能量安全**：任意承诺时刻，`‖τ_j‖_∞ ≤ τ_j_max`、`F_pk ≤ F_pk_max`、`E_release ≤ E_sea_max`、`q/q̇` 守界；`m_lift≤0` 或 `JOINT_OOD` ⇒ 强制 `DEGRADE_JOINT`，不得下发原证书。
2. **共创安全不变性**：对任意用户 `θ_co∈Θ_co`、任意共享权限 `α_auth∈[0,1]`、任意用户指令，`π_sa∈S_hard`，故 `Risk(π_sa) ≤ ε_hard`；用户偏好只能在地板内改变目标，`∂ε_hard/∂θ_co = 0`。
3. **非对称证据律**：关节模型只能通过 `L_joint` 修正证据、用户共创只能通过 `U_user`/软包络/技能结构影响行为；二者均不能增大 `F_max/δ_force`、不能降低 `ε_hard`、不能替代 `EV-exec/EV-xmodal` 物理佐证；违反即拒绝并留证。
4. **归属有界与可回滚**：失败事件按 `w_prov` 可定位最小责任子集 `S_resp`，回滚后须经隔离区复核；`w_robot≥w_min` 防责任洗白。
5. **终止性**：JCAL 在 `k_probes+k_cons+k_ft+k_ux+k_exec+k_co` 内终止于 `{承诺(带 Cert_jc), 绕行, 降档, L2 协商, 安全停, 关节降级停, 共创拒绝, 技能类型错误}`。

```python
class JointActuationModel:
    def __init__(self, joint_spec, N, alpha_j=0.01):
        self.N, self.spec = N, joint_spec
        self.ukf = UKF(state_dim=13, obs_dim=5)      # ξ_joint
        self.pi = PrandtlIshlinskii(n_thresholds=5)
        self.alpha_j = alpha_j

    def forward(self, xi, theta_m, q, dtheta_m, dq, i_q):
        K_sea, b_sea, *pi_params, b_g, c_v, c_c, e_x, e_y, tau_b, tau_g, c_cr, T_j = xi
        x = theta_m / self.N - q
        dx = dtheta_m / self.N - dq
        tau_j = self.pi.apply(K_sea * x, pi_params) + b_sea * dx
        tau_j += backlash(q, b_g) + c_v * dq + c_c * np.sign(dq) + c_cr * q
        return tau_j, 0.5 * K_sea * x**2, tau_g * tau_j + tau_b

    def update(self, q, theta_m, i_q, tau_s, T_j, dtheta_m, dq):
        def h(xi):
            tau_j, _, tau_s_pred = self.forward(xi, theta_m, q, dtheta_m, dq, i_q)
            enc_q = q + xi[6] * np.cos(q) + xi[7] * np.sin(q)      # 编码器偏心
            return np.array([enc_q, theta_m, i_q, tau_s_pred, T_j])
        self.ukf.update(np.array([q, theta_m, i_q, tau_s, T_j]), h=h)

    def inverse_torque_set(self, tau_des, xi, n=4097, tol=1e-3):
        lo, hi = np.inf, -np.inf
        for tau_m in np.linspace(-self.spec.tau_m_max, self.spec.tau_m_max, n):
            thighs = self.torque_from_motor(tau_m, xi)
            if abs(thighs - tau_des) <= tol:
                lo, hi = min(lo, tau_m), max(hi, tau_m)
        return lo, hi, (hi - lo if np.isfinite(hi - lo) else np.inf)

    def energy_release_bound(self, xi, K_env_max):
        _, E_sea, _ = self.forward(xi, *self.last_state)
        E_dyn = 0.5 * xi[1] * (self.dtheta_m_prev / self.N - self.dq_prev)**2
        E_kin = 0.5 * self.spec.effective_inertia * self.dq_prev**2
        E_release = E_sea + E_dyn + E_kin
        return E_release, np.sqrt(2 * K_env_max * E_release)

    def is_ood(self):
        return self.ukf.mahalanobis() > chi2.ppf(1 - self.alpha_j, df=13)

    def lift(self, cert_eeis, xi_joint, q, env_stiffness_est):

        F = np.array([cert_eeis.F_max] * 3)

class CoCreativeEnvelope:
    def __init__(self, epsilon_hard, alpha_co=0.05):
        self.eps_hard, self.alpha_co = epsilon_hard, alpha_co
        self.r_hat_co = None

    def fit_preference(self, D_demo, D_corr):
        return BradleyTerryGP().fit(D_demo, D_corr)

    def conformal_pref_set(self, D_calib):
        scores = [self.model.nonconformity(theta) for theta in D_calib]
        self.r_hat_co = np.quantile(scores, 1 - self.alpha_co)
        return self.r_hat_co

    def soft_envelope(self, theta):
        return SoftEnvelope(
            u_min=self.model.u_min(theta),
            rho_soft=min(self.model.risk_tolerance(theta), self.eps_hard))

    def project(self, theta, policies, risk_fn, utility_fn):
        soft = self.soft_envelope(theta)
        feasible = [p for p in policies
                    if risk_fn(p) <= self.eps_hard
                    and utility_fn(p, theta) >= soft.u_min]
        return (max(feasible, key=lambda p: utility_fn(p, theta)), None) \
            if feasible else (None, "SOFT_INFEASIBLE")

    def typecheck_skill(self, skill, grammar, joint_contract):
        if not grammar.well_typed(skill):
            return False, TypeError("grammar", skill)
        acc = zero_effects()
        for prim in skill.primitives:
            if not implies(skill.pre, prim.pre):
                return False, TypeError("precondition", prim)
            acc = add_effects(acc, prim.effects)
        if exceeds(acc, joint_contract):
            return False, TypeError("contract_overflow", acc)
        return True, None
```

    def __init__(self, attention=20, demo=10, ratify_time=30.0, trust_margin=1.0):
        self.attention_left, self.demo_left = attention, demo
        self.ratify_time_left, self.trust_margin = ratify_time, trust_margin

        return dU - (LAMBDA_ATTN * attention_cost + LAMBDA_LAT * latency
                     + LAMBDA_TRUST * trust_cost)

    def should_query(self, dU, attention_cost, latency, trust_cost, theta_co):
        if self.frozen or self.attention_left <= 0:
            return False
        return self.voi_co(dU, attention_cost, latency, trust_cost) > theta_co

    def viable(self):
        return (not self.frozen and self.attention_left > 0
                and self.demo_left >= 0 and self.ratify_time_left > 0)
