# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「数据规模」×「机器人操作系统」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**数据尺度证书化 + ROS 原生契约 + 联邦标定**。两个灵感合治 v9 的单一命门：v9 的信任域 `U_t` 由 `Δ_dom`（20 帧滑窗）事后判定，而域跳变时刻恰是前向模型误差最大时刻——**诊断与危险同相**。本轮把"偏移检测"从**时间域的事后报警**改写为**数据支撑域的先验预检**：证书宽度本身就是偏移计；任一新增环节失效仍须注入中立元、逐位退回 v9/v8，不得行为漂移。

## 0. 直觉与动机

**灵感 1（数据规模 → 支撑度即信任）**
直觉：v9 问"最近的观测像不像训练分布"，这是时间序列统计；更稳的问法是"我**即将执行**的这条块，前向模型在它附近**有没有足够的数据**"。数据规模给了这把尺子：局部有效样本量 `n_eff` 越大，共形（conformal）残差分位的证书越窄、越可信；`n_eff` 跌破 `⌈1/α⌉−1` 时分位根本不存在，证书自动不可用。于是**不再需要等 20 帧去"检测"偏移**——块一进入无数据支撑区，预检当场失败，`K_eff` 立即塌到 1。核心创新：**数据尺度共形证书（DataScaleConformalCertifier, DSC）**：`β(x)` 由局部加权共形分位给出，宽度随数据规模以 `O(n_eff^{-1/2})` 收缩；并用自适应共形（ACI）在漂移下维持长期覆盖率。衍生闭环：守卫认证过的安全执行块回流进回放缓冲（**数据飞轮**），数据规模自增、证书自紧——预算-安全-数据三环闭合。

**灵感 2（机器人操作系统 → 契约即 QoS 与生命周期）**
直觉：v9 的契约中间件仍是"进程内对象"，集成债没还完。ROS 2 已把"时限、存活、持久化、并发"做成一等公民：DDS 的 `DEADLINE`/`LIVELINESS`/`HISTORY`/`DURABILITY` 与 lifecycle 节点。核心创新：**ROS 原生契约图（ROSNativeContractGraph, RNC）**：契约 `κ_m` 编译为 QoS profile，`DEADLINE_MISSED` 回调即注入中立元，ID 的 active/dormant/frozen 直接映射 lifecycle 的 active/inactive/finalized。退化从"配置表"进一步落地为**标准中间件语义**，可由节点图自省做运行期验证；QoS 历史深度还给出一个数据尺度条件：`depth ≥ ⌈rate·D_m⌉+1`，否则证书陈旧。

**灵感 1×2（合成 → 联邦数据尺度）**
直觉：单机数据规模有限，多机可"凑数据规模"——但不能直接倒原始数据。核心创新：**联邦标定交换（FederatedCalibrationExchange, FCE）**：各节点只发布**残差速写（sketch）+ 计数**，聚合端用 MMD 两样本检验判断残差分布是否可交换；可交换才并入同一 Mondrian 单元抬高 `n_eff`，否则各守本地。**交换性检验是安全闸**：宁可 `n_eff` 小、证书宽，不可错池化、假置信。

## 1. 研究问题（轮次升级版）

- **Q1（数据尺度证书）**：在局部（Mondrian 单元/加权邻域）可交换假设下，共形证书能否以 `n_eff` 为唯一门控量，给出有限样本覆盖 `≥1−α`，并使"无数据支撑 ⇒ 无证书 ⇒ K_eff=1"零滞后成立？时间相关与重复样本造成的 `n_eff` 虚胀如何剔除？
- **Q2（ROS 原生退化）**：把 v9 的契约中间件下沉为 DDS QoS + lifecycle，能否使 `DEADLINE_MISSED` 注入与 v9 超时注入在数值与时限上逐位等价，且节点图自省可验证？
- **Q3（联邦标定安全）**：仅当 MMD 检验不拒绝可交换时池化残差，能否保证联合覆盖不低于本地覆盖，从而"多机数据规模"永不降低安全性？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 数据尺度证书律（Data-Scale Conformal Certificate, DSC）**
信任域改为**数据支撑域** `U_t^data = {n_eff(x_t) ≥ n_min(α)}`，在**块生成时**对候选块 `a^{1:K}` 逐点预检，先于执行。证书余量 `β(x)` 取局部加权共形分位；`n_eff < n_min(α)=⌈1/α⌉−1` 或交换性被拒 ⇒ `β=+∞` ⇒ 证书无效 ⇒ `K_eff=1`。ACI 在线调节 `α_t` 以在漂移下守住长期覆盖率。**检测由"事后 20 帧"变为"先验 0 帧"**。

**P14 ROS 原生契约律（ROS-Native Contract, RNC）**
每模块契约编译为 ROS 2 QoS：`D_m↔DEADLINE`、存活租约 `↔LIVELINESS`、`history depth ≥ ⌈rate·D_m⌉+1`、关键状态 `TRANSIENT_LOCAL`。`DEADLINE_MISSED`/`LIVELINESS_CHANGED` 回调注入中立元 `v_m^⊥`（发布到 `/m/fail`）。ID 状态机映射 lifecycle：active↔active、dormant↔inactive、frozen↔finalized。代码可达性不删（继承 P12）。

**P15 联邦标定交换律（Federated Calibration Exchange, FCE）**
跨节点只交换 `(cell_id, residual_sketch, n)`，不交换原始数据；聚合端做 MMD 两样本检验，`p>p₀` 判可交换并池化提升 `n_eff`，否则保留本地。池化后的证书覆盖率不得低于各本地证书的覆盖率（引理 90）。

## 3. 与基线的接口（如何退化）

- DSC 失效（`n_eff<n_min` / 交换性拒绝 / 共形分位不可得）⇒ `β←β_max`（v9 E554 标定值或更宽）⇒ `K_eff←1`，逐步执行，等价 v9 Level-1；
- RNC 失效（DDS 不可用 / 节点图退化）⇒ 退回 v9 进程内契约中间件（引理 83 路径），等价 v9 集成方式；
- FCE 失效（无交换性或聚合端失联）⇒ 仅用本地共形；本地 `n_eff<n_min` 时再落 DSC Level-1，等价 v9 固定 `β`；
- ID/归因门控失效 ⇒ 全模块 active、固定调度，等价 v9/v8 全模块常开；
- v9 的 AC/MW/ID 任一失效 ⇒ 按 v9 五级链退回；v8 的 DA/SPR/Cal 任一失效 ⇒ 中立元（Δ_dom≡0 / risk_SLAM≡0 / weight≡1），等价 v7；
- 全部失效 ⇒ 完整退回 MetricVoiceGauge-OTL-GC-ER v7，再退回 v6。

## 4. 预期贡献

1. **数据尺度共形证书**：把前向模型的信任从"近期像不像训练集"升级为"即将执行的块有没有数据支撑"，用 `n_eff` 单一门控量统一"证书有效/失效/块长"，使域跳变的检测延迟从 ≥20 帧降到 ≤1 块（先验预检）。
2. **ROS 原生契约图**：退化链下沉为标准 DDS QoS + lifecycle 语义，`DEADLINE_MISSED` 注入与 v9 超时注入逐位等价；节点图自省把集成正确性变成可运行期验证的性质。
3. **联邦数据尺度**：残差速写 + MMD 交换性闸门，多机"凑数据规模"而不牺牲安全性，给出池化不劣于本地的形式保证。
4. **数据飞轮 + 置信门控蒸馏**：安全执行块回流提升 `n_eff`、收紧 β、反哺更长块；ID 的休眠仅在归因置信上界低于阈值且样本量足够时触发，避免小样本误休眠。
5. 实验 E571–E590 覆盖共形覆盖率、尺度律、零滞后检测、QoS 注入、联邦交换、飞轮长跑与端到端。

## 5. 本轮最大风险

**一句话**：共形证书的有限样本有效性以「局部邻域内可交换」为前提，而回放数据的时间相关、重复样本与度量盲区会**虚增 `n_eff`、在最需要保守处把 β 收窄**——"数据规模"可被相关性伪造，证书在最陌生处反而最自信。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-DSC-ROS**（Data-Scale Conformal Certificates · ROS-Native Contracts）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮灵感：「数据规模」×「机器人操作系统」
> **继承纪律**：MetricVoiceGauge 九不变式（CVC-闭环、SpatialCert、RT-CVC、FaultCert、PrimitiveGraph、严格退化链、OTL、GCT、ER）与 v8 的 DA-ML/SPR/Cal、v9 的 AC/MW/ID 全部保留。新组件一律为**可选增强**：任一环节不可用 ⇒ 注入中立元并严格退回 v9/v8 对应级（引理 89），不得行为漂移。**本轮核心命题**：证书的宽度就是域偏移计——信任不再由 `Δ_dom` 事后判定，而由**数据支撑度**在执行前判定。

## 1. 符号体系增量（定义 540–550）

| 符号 | 含义 |
|---|---|
| `D` / `D_cal` | 回放缓冲 / 标定子集（split conformal 的 calibration 部分） |
| `x = (s, a^{1:K})` | 待认证查询：状态 + 候选块 |
| `w_i(x)` | 局部权重：核权重或协变量偏移下的密度比 `p_test(x_i)/p_cal(x_i)` |
| `n_eff(x)` | 数据尺度有效样本量（Kish ESS，定义 540） |
| `n_min(α) = ⌈1/α⌉−1` | 共形分位存在所需的最小局部样本量（定义 541） |
| `β(x)` | 局部加权共形残差分位，证书余量（定义 541） |
| `U_t^data` | 数据支撑域：`{n_eff(x_t) ≥ n_min(α_t)}`（定义 542） |
| `α_t` | ACI 自适应误覆盖率（定义 543） |
| `Q_m` | 模块 `m` 的 QoS profile：`(D_m, lease_m, depth_m, rel_m, dur_m)`（定义 544） |
| `ℓ_m ∈ {active,inactive,finalized}` | ROS lifecycle 状态，映射 ID 的 active/dormant/frozen（定义 545） |
| `P_fed` | 联邦标定池 `{(cell_id, sketch, n)}`（定义 546） |
| `T_fly` | 数据飞轮周期（每 2000 控制周期回流并重标定，定义 547） |
| `n_eff^robust` | 去重/去相关修正后的有效样本量（定义 549） |

**新增定义 540（数据尺度有效样本量 Data-Scale ESS）** 对标定集 `D_cal` 与查询 `x`，取局部权重 `w_i(x)=K_h(x,x_i)`（核带宽 `h`，或协变量偏移下的似然比），定义 Kish 有效样本量
```
n_eff(x) = (Σ_i w_i(x))² / Σ_i w_i(x)²
```
`n_eff ≤ N_cal`，等号当且仅当权重均一。它同时是"局部数据规模"与"加权后实际信息量"的严格度量：重复/高相关样本因权重塌缩而**不增加** `n_eff`。

**新增定义 541（局部共形证书 LocalConformalCertificate）** 按 Mondrian 划分单元（如 `(Δ_dom 分箱, risk_SLAM 分箱, 任务相位)`），单元内取加权残差 `R_i = |g_true(s_i,a_i) − F̂_g(s_i,a_i)|`。若 `n_eff(x) ≥ n_min(α)`，取加权残差的第 `⌈(n_eff+1)(1−α)⌉` 个分位为 `β(x)`；否则 `β(x)=+∞`。证书有效性：
```
Cert_x valid ⇔ β(x) < ∞ ∧ (min_k F̂_clearance(s,a^{1:k}) − β(x)) ≥ d_safe
             ∧ (max_k F̂_effort(s,a^{1:k}) + β(x)) ≤ τ_eff
```
`β(x)` 随 `n_eff` 增大而单调不增；`n_eff→n_min` 时 `β→∞`（分位逼近最大残差）。**这就是"数据规模即信任"的代数形式**。

**新增定义 542（数据支撑域与零滞后门控 Data-Scale Trust Domain）** 块生成时对**候选块**逐点评估
```
U_t^data = { min_{k≤K} n_eff(s_t, a^{1:k}) ≥ n_min(α_t) ∧ ACI 覆盖检验通过 }
K_eff(t) = 1                                  若 U_t^data 不成立 ∨ U_t^model 不成立（v9 定义 539）
         = max(1, ⌊K_max·(1 − Δ_dom/τ_dom)⌋)   否则
```
关键：`U_t^data` 在**执行前**评估候选块的数据支撑，命中域跳变时"看到即将驶入无支撑区"，故检测延迟 ≤1 块；`U_t^model`（v9 的 `Δ_dom/risk_SLAM`）降级为**第二道交叉校验**，二者取交集只增安全性、不引入回归。

**新增定义 543（自适应共形 ACI）** 在线调节覆盖率目标：
```
α_{t+1} = clip( α_t + γ(α* − 1[R_t > β_t]), α_min, α_max )
```
`1[R_t>β_t]` 为超界指示；`γ` 步长。标准 ACI 保证漂移下长期误覆盖率 `→ α*`；本系统取 `α*=0.05`，`α_min=0.01, α_max=0.20`。ACI 只调**目标**，不调数据，故不破坏定义 541 的有限样本有效性（在局部可交换时段内）。

**新增定义 544（ROS 原生契约 QoS）** 契约 `κ_m` 编译为 ROS 2 QoS profile
```
Q_m = ( DEADLINE=D_m, LIVELINESS=2·D_m, HISTORY=depth_m=⌈rate_m·D_m⌉+1,
        RELIABILITY=RELIABLE, DURABILITY=TRANSIENT_LOCAL（关键态）/VOLATILE（可弃态） )
```
任一端检测 `DEADLINE_MISSED`/`LIVELINESS_CHANGED` 即在 reader 侧发布 `v_m^⊥` 到 `/m/fail`（`TRANSIENT_LOCAL` 供晚加入者补齐）。`HISTORY` 深度条件保证不因队列过浅而读到陈旧证书：`depth_m ≥ ⌈rate_m·D_m⌉+1`。

**新增定义 545（生命周期映射 LifecycleMapping）** 蒸馏状态机与 ROS 2 lifecycle 对齐：
```
ID active  ↔ lifecycle active      （计算 + 发布）
ID dormant ↔ lifecycle inactive    （不计算，仍可被 configure/activate；等价 v^⊥）
ID frozen  ↔ lifecycle finalized   （仅离线证据 → configure 解冻）
```
迁移通过 `ChangeState` 服务受控，可被节点图自省审计；`P12` 的"不删码"体现为 inactive/finalized 节点**仍在图中、代码可达**。

**新增定义 546（联邦标定池 FederatedCalibrationPool）** 各节点发布 `(cell_id, sketch, n)`，`sketch` 为残差分位速写（如 t-digest / KLL，`O(1)` 量级误差可控）。聚合端对同一单元的跨节点残差做 MMD（RBF 核）两样本检验：
```
exchangeable(node A, node B | cell) ⇔ p_value(MMD(R_A, R_B)) > p₀   （p₀=0.01）
pool(cell) 仅当所有入池节点两两可交换
```
池化后 `n_eff^pooled = (Σ n_i)² / Σ n_i²`（若速写提供权重）或 `Σ n_i`（等权）。**安全闸**：不可交换即不池化，退回本地证书。

**新增定义 547（数据飞轮 DataFlywheel）** 每 `T_fly=2000` 周期，将**通过 50Hz 守卫且无中止**的执行块连同真实残差回流进 `D`，并重算各 Mondrian 单元覆盖；若漂移统计量超阈则增量重训 `F̂` 并重标定 `β`。飞轮使"安全执行 → 数据规模↑ → 证书↓ → 更长块 → 更多执行"形成正反馈，但受预检预算与污染防护约束（定义 549）。

**新增定义 548（归因置信门控 AttributionConfidenceGate）** 消融归因 `c_m` 由 `n_abl` 个回合估计，取 Bernstein 置信上界
```
ε(n_abl) = sqrt(2·σ̂²·ln(2/δ)/n_abl) + 3·ln(2/δ)/n_abl
休眠条件：UCB_m = c_m + ε(n_abl) < τ_off ∧ n_abl ≥ n_min(0.1)
```
小数据规模（`ε` 大）时任何模块都睡不着 → 保守；大数据规模时才允许休眠。`frozen` 另需 `H_frz=20` 回合持续满足。这把 `P12` 的"选择资格"从固定谓词升级为**样本量感知的统计判据**。

**新增定义 549（数据污染鲁棒性 Data-Poisoning Robustness）** 重复/对抗样本可虚增 `n_eff`。以 `ε`-球去重得到 `N_unique`，并做截尾残差分位：
```
n_eff^robust = min(n_eff, N_unique),   R_trim = 去掉最大 5% 残差后重算
β(x) = 基于 n_eff^robust 的 (1−α) 分位且用 R_trim 复核
```
若重复率估计 `> 30%`，强制 `U_t^data=false`（宁可 K=1）。

**新增定义 550（预检计算预算 Preflight Budget）** DSC 预检只在 5Hz 块生成执行：HNSW 近似 kNN（`O(log N)`）取局部集 + 加权分位（`O(n_eff log n_eff)`），预算 `≤1.2ms`；摊销到 50Hz 为 `0.12ms/cycle`。50Hz 守卫仅比对实时残差是否落出预计算 `β` 带（`O(1)`，`≤0.3ms` 不变）。

## 2. 形式化定义（要点与升级）

**定义 493（六层指标层级）** 继承 v8/v9：`M=(M₀,M₁,M₂,M₃,M_dom,M_SLAM)` 不变。
**定义 495/524（MetaWeight/情感，5 维）** 继承不变。

# IP-357 DataScaleConformalCertifier：数据尺度共形证书
class DataScaleConformalCertifier:
    def __init__(self, F_hat, index, cells, alpha=0.05, gamma=0.01,
                 alpha_star=0.05, beta_max=0.20, d_safe=0.15):
        self.F, self.index = F_hat, index          # HNSW 索引 over (s,a) 嵌入
        self.cells, self.alpha = cells, alpha      # Mondrian 单元 -> 残差样本
        self.gamma, self.alpha_star, self.beta_max = gamma, alpha_star, beta_max
        self.d_safe = d_safe

    def n_min(self, alpha):
        return math.ceil(1.0 / alpha) - 1           # 定义 541

    def local_residuals(self, x):
        nbrs = self.index.search(x, k=min(self.index.size, 4096))
        w = [self._kernel(x, xi) for xi, _ in nbrs]  # 核或密度比权重
        sw2 = sum(wi * wi for wi in w)
        n_eff = (sum(w) ** 2) / sw2 if sw2 > 0 else 0.0
        return w, n_eff

    def beta(self, x):
        w, n_eff = self.local_residuals(x)
        cell = self.cells.key(x)
        cal = self.cells.residuals(cell)
        # 污染鲁棒：去重 ESS + 截尾残差（定义 549）
        n_eff_r = min(n_eff, self.cells.unique_count(cell, radius=1e-3))
        if n_eff_r < self.n_min(self.alpha):
            return math.inf, n_eff_r             # 无证书 → K_eff=1
        q = weighted_quantile(trim_top(cal, 0.05), w,
                              level=math.ceil((n_eff_r + 1) * (1 - self.alpha)))
        return min(q, self.beta_max), n_eff_r

    def preflight(self, state, cand, K):
        """块生成时对候选块逐点预检；定义 542 的数据支撑域。"""
        for k in range(1, K + 1):
            b, n_eff = self.beta((state, cand[:k]))
            if not math.isfinite(b):
                return False, math.inf, n_eff
        g_min = min(self.F.clearance(state, cand[:k]) for k in range(1, K + 1)) - b
        e_max = max(self.F.effort(state, cand[:k]) for k in range(1, K + 1)) + b
        ok = (g_min >= self.d_safe) and (e_max <= state.tau_eff)
        return ok, b, n_eff

    def update_aci(self, residual_gt, beta_used):
        err = 1.0 if residual_gt > beta_used else 0.0
        self.alpha = clip(self.alpha + self.gamma * (self.alpha_star - err),
                          self.alpha_min, self.alpha_max)

# IP-359 FederatedCalibrationExchange：联邦标定
class FederatedCalibrationExchange:
    def __init__(self, p0=0.01, cell_key=None):
        self.p0, self.key = p0, cell_key
        self.pool = defaultdict(list)               # cell -> [(sketch, n, node)]

    def offer(self, node, cell, sketch, n):
        self.pool[cell].append((sketch, n, node))

    def aggregate(self, cell):
        entries = self.pool[cell]
        for a in range(len(entries)):
            for b in range(a + 1, len(entries)):
                if mmd_pvalue(entries[a][0], entries[b][0]) <= self.p0:
                    return None                     # 不可交换 → 不池化
        return PooledSketch(entries)                # 可交换 → 提升 n_eff


# IP-360 ScaleAwareDistiller：尺度感知蒸馏（ID 升级）
class ScaleAwareDistiller:
    def __init__(self, mw, tau_off=0.01, delta=0.05):
        self.mw, self.tau_off, self.delta = mw, tau_off, delta

    def ucb(self, c, sigma, n):
        eps = math.sqrt(2 * sigma**2 * math.log(2 / self.delta) / n) \
              + 3 * math.log(2 / self.delta) / n       # Bernstein（定义 548）
        return c + eps

    def maybe_sleep(self, m, c, sigma, n_abl):
        if n_abl < math.ceil(1 / 0.1) - 1:
            return False                                # 样本不足 → 保守
        if self.ucb(c, sigma, n_abl) < self.tau_off:
            self.mw.set_dormant(m)                      # lifecycle → inactive
            return True
        return False

## 4. 推导

**引理 87（共形有效性与数据尺度门控）** 设查询 `x` 所属 Mondrian 单元内残差可交换、`n_eff(x) ≥ n_min(α)=⌈1/α⌉−1`，则定义 541 的 `β(x)` 满足 `P(R ≤ β(x)) ≥ 1−α`；且 `β(x)` 关于 `n_eff` 单调不增，`n_eff < n_min` 时无有限 `β`。证明：加权 split-conformal 的覆盖定理给出 `P(R_{n+1} ≤ q̂) ≥ 1−α`，其中 `q̂` 取第 `⌈(n_eff+1)(1−α)⌉` 个加权次序统计量；该次序统计量存在 ⇔ `⌈(n_eff+1)(1−α)⌉ ≤ n_eff` ⇔ `n_eff ≥ ⌈1/α⌉−1`。次序统计量随样本增而减小（同分布），故单调。∎

**引理 88（零滞后预检 / 消除 Δ_dom 滞后）** 若候选块 `a^{1:K}` 的某前缀落入数据无支撑区（局部 `n_eff<n_min` 或残差超 `β`），定义 542 在**块生成时刻**即令 `U_t^data=false`，故 `K_eff=1`、不执行该块；而 v9 的 `Δ_dom` 需偏移后 `W=20` 帧方能报警。故对"执行前已存在于候选块内"的偏移，DSC 检测延迟 ≤1 个块周期（20ms×K 内），v9 ≥ `W·Δt=400ms`。证明：`U_t^data` 对候选块逐点求值（定义 542 的 `min_k`），其值只依赖 `x_t` 与 `a^{1:K}`、不依赖后续观测，故在生成时确定；`Δ_dom` 定义在最近 `W` 帧观测上，需累积偏移后样本。∎（**注意**：该结论以"F̂ 的嵌入/度量能分辨该偏移"为前提，见风险。）

**引理 89（ROS 契约与 v9 逐位等价）** 对每个模块，`DEADLINE_MISSED` 触发的 `v_m^⊥` 注入在数值上等于 v9 `ContractMiddleware` 超时注入的 `fail_value`，在时限上同周期内完成（DDS 回调与进程内 guard 同周期）；`lifecycle inactive` 的行为等价 v9 `dormant`（跳过计算、输出 `v^⊥`）。故 RNC 的任一级退化与 v9 对应级可观测输出逐位一致。证明：映射表 `Q_m↔κ_m`、`inactive↔dormant`、`finalized↔frozen` 为双射且 `fail_value` 引用同一常量；QoS 的 `DEADLINE` 与 `Ŵ_m` 均按 `D_m` 校验。∎

**引理 90（联邦标定不劣于本地）** 若 MMD 检验未拒绝，则池化残差与本地残差可交换，池化共形覆盖 `≥1−α` 且 `n_eff^pooled ≥ max_i n_eff^i`，故 `β^pooled ≤ min_i β^i`（引理 87 单调性），覆盖不低于本地；若检验拒绝，定义 546 不池化，各节点退回本地证书，覆盖与本地相同。故联邦化在期望意义上**只会收紧证书、不会降低覆盖**。证明：可交换时残差同分布，合并样本的次序统计量覆盖保持；拒绝时走本地分支。检验第一类错误 `≤p₀`，对应"错误池化"概率受控。∎

**引理 91（置信门控 / 小样本不误休眠）** 归因 `c_m` 的 Bernstein 上界 `UCB_m` 满足 `P(c_m^true > UCB_m) ≤ δ`；仅当 `UCB_m<τ_off` 才休眠，故 `P(误休眠) ≤ δ`。且 `ε(n_abl)` 关于 `n_abl` 递减，休眠速率随数据规模单调不增地保守。证明：Bernstein 不等式直接给出；`ε` 的 `1/√n` 项与 `1/n` 项均递减。∎

**引理 92（预检预算守恒）** DSC 预检在 5Hz 执行，单次 `≤1.2ms`，摊销 `≤0.12ms/cycle`；50Hz 守卫仅做 `O(1)` 残差比对，`≤0.3ms`；RNC 的 QoS 回调为 DDS 原生事件（`O(1)`）。故决策侧 `≤ v9` 预算，p99 `≤20ms`，50Hz 保持。证明：由定义 550 的预算分配与 HNSW `O(log N)` 查询；联邦聚合仅在 `T_fly` 触发、离线式摊销。∎

## 8. 本轮最大风险

**一句话**：共形证书的有限样本有效性以「局部邻域内可交换」为前提，而回放数据的时间相关、重复样本与度量盲区会**虚增 `n_eff`、在最需要保守处把 β 收窄**——"数据规模"可被相关性伪造，证书在最陌生处反而最自信。
