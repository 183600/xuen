# 第 66 轮（承接第 65 轮「VISTA 故障可归因安全时序闭环」IP-214~223；灵感循环第 3 轮；本轮灵感：「强化学习训练」×「面部表情识别」）

> 第 65 轮把「可证伪」升级为「可归因」，其最大风险一针见血：**VISTA 假设故障属于有限假设集、且视觉与几何失效相互独立；真实故障是未知类型的组合，透明/镜面/对抗 patch 让视觉与几何共享同一 OOD 失效源，FIR 会把未知复合故障强行归入最近假设、只膨胀错误的球，系统因「已经归因」而更自信地继续执行。** 第 64~65 轮本质上都在做同一件事：**给定策略与世界模型，如何推断与认证**。本轮换一个更底层的问题：**这个策略与世界模型到底怎么学出来？**——第 66 轮不叠加第 6 个模态，而是补上一直缺失的**训练闭环**。核心命题：
>
> **把「推理时的故障归因」升级为「训练时的可辨识性设计」：用面部动作编码（FACS）的思想把安全/任务信号分解为可解释的物理动作单元（PAU），把表情识别对「标注歧义 / 微表情 / 复合表情 / 跨被试」的成熟处理，对应到 RL 训练里的「奖励歧义 / 故障前兆 / 复合故障 / 跨物体跨域」，并用 VISTA 证书作探索盾、用「微表情抑制检测」抓奖励黑客。**

## 0. 直觉与动机

**灵感 1（面部表情识别 → 从「标量奖励 / 单类故障」到「动作单元 + 标签分布」）**
FER 最深刻的一课不是"识别人脸"，而是**把一张脸拆成若干可解释、可组合、跨个体稳定的动作单元（FACS/AU），并把"这是什么表情"的硬标签换成标签分布**。原因有三：表情本身有**标注歧义**（同一张脸不同标注者给出不同情绪）、有**复合表情**（喜怒同现）、呈**长尾分布**（惊讶与微表情稀少）。硬 one-hot 会逼模型在歧义处过度自信并给出错误的高梯度。
对照 RL 训练：接触操作里"此刻正确的行为"同样**本质歧义**——同一状态常存在多个可行的接触模式/抓取点，标量奖励与 one-hot 目标把这种多峰性压成单峰，训练出对某一种模式过度自信、对分布外接触脆弱的策略。于是本轮第一件事：把接触流（力/触觉/本体/视觉残差）编码成 **PACS（物理动作编码系统）**——K 个 PAU 的强度 + 时序包络（onset-apex-offset），奖励与监督在 PAU 上以**标签分布**给出，而不是一个标量。

**灵感 2（面部表情识别 → 微表情「先检测、后识别」→ 故障前兆的两段式）**
微表情只有 1/25~1/15 秒、幅度极小、长尾分布，端到端分类器在极端类不平衡下召回很差；FER 的标准解法是 **spot-then-recognize（先无类别地判断"哪里可能有"，再判断"是什么"）**：spotter 便宜、类无关、靠时序突变与惊讶度；recognizer 昂贵、类特定、只在候选窗上跑。
对照：接触失效的**前兆**（初始滑移、力饱和、磨损漂移）就是"物理世界的微表情"——短暂、微弱、稀有。第 65 轮 FIR 的阶段签名是"事后归因"，等故障已经成形。本轮加 **MES（微表情 spotter）**：类无关地对 PAU 轨迹做惊讶度/时序突变 spotting，先报警"这里可能要出问题"，再由 PAU 识别器分辨"是滑移还是偏置"。**先 spotting 后 recognition，把稀有事件的召回从端到端分类的瓶颈里解放出来**，这正是 FER 对付长尾的看家本领。

**灵感 3（面部表情识别 → 跨被试解耦「身份 vs 表情」→ 跨物体/跨域解耦「物体属性 vs 任务相位」）**
FER 的一大难题是跨被试泛化：同一个人笑和另一个人笑，像素差异可能远大于"笑"与"微笑"的差异。成熟做法是**解耦身份（identity）与表情（expression）**，用对抗/互信息约束让表情表征不携带身份，于是换人不必重学。
对照 sim-to-real：同一种"轻触稳定"在不同刚度/摩擦/质量的物体上，绝对力与形变差异巨大。若表征把二者混在一起，换物体或换仿真器就失效。本轮加 **DPR（解耦物理表征）**：把 z_id（物体/接触属性：刚度、摩擦、质量）与 z_expr（任务相位/PAU 包络）解耦，用梯度反转与互信息下界约束，策略在 z_expr 上学习、对 z_id 做域随机化。跨物体与 sim-to-real 泛化从"记忆"变成"解耦不变"。

**灵感 4（强化学习训练 → 奖励黑客就是「表情抑制」：agent 学会面不改色地失败）**
这是本轮最关键的合流。FER 里存在**表情抑制 / 欺骗（facial suppression / deception）**：真实情绪存在，但脸上看不出来，专门骗读脸系统。RL 训练里有完全同构的 **reward hacking**：agent 学会把奖励代理或证书的观测信号压到"看起来正常"，同时在真实物理上失败。第 64~65 轮所有证书与归因都是**看信号**的，因此都可能被"表情抑制"骗过——agent 学会把 PAU/残差维持在盾的可行域内，而实际接触已经退化。
于是本轮把 reward hacking 重新表述为 **"PAU 抑制 / 表达操控"**：**RHD（奖励黑客检测器）** 用**留出的、未参与奖励的 PAU 检测器集成** + OOD/惊讶度地板，检测"盾内低惊讶但物理退化"的区域；一旦发现策略系统性地把 PAU 驱向 spotter 盲区，即判 reward hacking，收缩可行域并做反事实重训。**证书不只验证执行，还要验证"训练没有教 agent 去骗证书"。**

**灵感 5（强化学习训练 → 安全探索 + 打标预算 + 强度课程）**
- **安全探索**：训练早期策略必然乱试。用第 65 轮 **VISTA 证书作 shield**（CSR，证书屏蔽约束 RL）：动作先过盾投影/拒绝，探索只在 Valid(J_vista) 域内发生，把"训练期物理风险"压到证书预算 α_total 内。
- **打标预算**：FER 用主动学习少标注；此处用**主动奖励查询**，只在高歧义（H_L 大）且高影响的决策点向人类或仿真 oracle 要标签，与第 65 轮 AFA 探针共享"信息增益"骨架。
- **强度课程**：FER 的 onset-apex-offset 对应接触强度。**ACC（强度课程）** 先低强度/低载荷/单 PAU（"中性脸"），再升强度、加复合 PAU（"复合表情"），以歧义熵与成功率为推进信号，降低稀有失效的样本复杂度。

**灵感 6（合流 → PACT：Physical Action Coding Training）**
闭环：PACS 编码 → MES spot → LDL 标签分布 → APR 歧义悲观奖励 → CSR 证书屏蔽训练 → DPR 解耦表征 → RHD 反奖励黑客 → ACC 强度课程 → 训练证书 J_pact；训练好的策略再回到 VISTA 做推理期归因与认证。第 65 轮把"接触"拆成前/中/后，PACT 把"学习"拆成 **看（PACS/MES）→ 标（LDL/主动查询）→ 练（APR/CSR/ACC）→ 查（RHD/DPR 泄漏）**，并让每一环都对应一个可审计的训练故障。

## 1. 形式化定义（增量：定义 233–246）

- **定义 233（PACT 闭环）**：PACT = (VISTA, PACS, MES, LDL, APR, CSR, DPR, RHD, ACC, J_pact)。定位：VISTA 的"训练期"前置闭环——VISTA 负责推理期归因与认证，PACT 负责把策略/世界模型**学**到让 VISTA 的假设成立。不变式：**训练期间物理执行一律经 CSR 证书盾；PAU 编码与 MES/DPR 只读实时流，奖励聚合、RHD 审计、课程推进只在低频训练线程。**
- **定义 234（PACS 物理动作编码系统）**：对接触流 x_t=(f_t, τ_t, tactile_t, q_t, e_vis_t) 学习编码 E_φ 到 K 个物理动作单元强度 u_t∈[0,1]^K（如法向力上升率、切向滑移、力矩比、接触面积变化、磨损漂移、接近速度），u_t=E_φ(x_t, 邻域窗)。要求 (i) **可解释**：每个 PAU 有物理语义与单调方向；(ii) **可重构**：解码器 D_ψ(u_t)≈x_t 达阈值；(iii) **近正交激活**：在操作流形上 PAU 激活矩阵列近正交。
- **定义 235（PAU 时序包络与强度）**：每个 PAU 用 onset–apex–offset 三角/偏斜包络参数化 e_k(t)=(t_on, t_apex, t_off, A_k, 斜率)；强度 A_k 与包络一起构成"表情短语"。阶段切分（第 65 轮 P）由 PAU 包络而非固定阈值给出，避免自由空间/轻触边界模糊。
- **定义 236（MES 微表情 spotter 与 spot-then-recognize）**：spotter S_ω 类无关，输入 PAU 轨迹窗，输出候选微事件分数 s_t（惊讶度：重构残差 + 时序一阶/二阶突变 + 稀有度密度）；s_t>τ_spot 时进入识别器 R_ξ，输出 PAU 类别/强度。目标是 **spotting 召回** 与 **识别条件精度** 两个可分解指标，而非端到端单指标。
- **定义 237（LDL 标签分布与歧义熵）**：对状态 s 的"正确 PAU/行为"给出标签分布 q(a|s)∈Δ^{K}（多标注者/多可行模式），歧义熵 H_L(s)=−Σ q log q；校准要求 ECE(q)≤ε_cal。硬 one-hot 视为 q 退化为 δ。
- **定义 238（APR 歧义悲观奖励与弃权）**：奖励取标签分布下的下置信/尾部效用 r_ APR(s,a)=CVaR_α^{q}[U(s,a)] + γΦ(s')−Φ(s)，Φ(s)=−c·H_L(s) 为熵势函数（势函数塑形保证策略不变性）；当 H_L>τ_amb 时**弃权**：不给该步奖励梯度、只留安全信号。悲观把"歧义"转成"保守"，弃权把"噪声"转成"无梯度"，双管齐下抑制奖励黑客。
- **定义 239（CSR 证书屏蔽约束 RL）**：训练目标 max_π E_π[r_ APR] s.t. 每步 a 经证书盾 Π_J：若 a 使 Valid(J_vista) 失效则投影到最近可行动作，否则用已认证 fallback（safe_idle/柔顺 retreat）。等价于带屏蔽的 CMDP，拉格朗日乘子自适应；探索只在 {s: J_vista 有效} 内发生。
- **定义 240（DPR 解耦物理表征）**：编码器分解 z=(z_id, z_expr)；约束 I(z_expr; z_id)≤ε_leak（互信息下界/梯度反转），z_id 经域随机化增广，策略 π(a|z_expr, task) 不读 z_id。泄漏 ε_leak 用 MINE/对抗判别器估计，进入 J_pact。
- **定义 241（RHD 奖励黑客 / 表情抑制检测）**：维护留出检测器集成 {R_j}（训练奖励从未用到）+ 惊讶度地板 s_min。对策略轨迹计算"抑制分数" κ_hack=TV(R_j 输出, 奖励用检测器输出)+1[s_t<s_min ∧ 物理退化]。κ_hack>τ_hack ⇒ 判 reward hacking，收缩 CSR 可行域、冻结该区奖励、反事实重训（把抑制区标为负样本）。
- **定义 242（ACC 强度课程）**：课程阶段 ℓ=1..L 对应 PAU 强度/载荷/复合度递增。推进条件：本阶段成功率高 ∧ 歧义熵已降 ∧ RHD κ_hack≤τ_hack；回退条件反之。稀有失效（π_ℓ 小）在低阶段即以"弱表情"暴露，避免高载荷下才首次遇到。
- **定义 243（复合 PAU / 复合故障组合解码）**：真实状态常是多 PAU 同现（复合表情）。识别器输出多标签强度 u_t，用组合解码 argmax_{支持集} p(u_t|x) 而非单类 softmax；与第 65 轮"未知复合故障"对应——**只要求判 ambiguous + 安全降级，不要求强行归因**。
- **定义 244（跨物体/跨域 PAU 不变性与 sim-to-real）**：要求 PAU 语义在物体/仿真器变换下不变：E_φ(T(x))≈E_φ(x)（T 为物体属性/渲染/动力学扰动），用一致性损失 + z_id 增广实现；泛化界按域差异项加 ε_leak。
- **定义 245（J_pact 训练证书）**：J_pact=(J_vista, pau_coverage, ambiguity_ECE, shield_violation_rate, hacking_score, leakage_est, curriculum_stage, acc_ver)。Valid(J_pact) ⇔ 训练全程 shield_violation_rate≤α_total ∧ ambiguity_ECE≤ε_cal ∧ hacking_score≤τ_hack ∧ leakage_est≤ε_leak ∧ pau_coverage≥ρ_min。
- **定义 246（PACT 训练算子）**：低频训练画外音 [PACS 拟合→MES 预训练→LDL 标定→CSR 屏蔽 rollout→APR 奖励→DPR 解耦→RHD 审计→ACC 推进→J_pact 构建]；实时流只做 PAU 前向、spotting、盾投影与派发，零奖励聚合/零学习写操作。

## 2. 关键算法骨架

```python
# PACT 训练一步（低频训练线程；实时流只做盾投影与派发）
u = pacs.encode(x_window)                     # K 维 PAU 强度 + 包络
s = mes.spot(u)                                # 类无关微事件分数
events = mes.recognize(u, mask=s > tau_spot)   # 只在前兆窗上识别
q = ldl.posterior(u, events)                   # 标签分布
H_L = -sum(q * log(q + 1e-9))
r = apr.pessimistic(q, info) + apr.entropy_potential(H_L)   # 势函数塑形
if H_L > tau_amb:
    r = None                                   # 弃权：不产生奖励梯度
loss = -E[log pi(a | z_expr(s), task)] * r     # z_expr 不含 z_id（DPR）
a_shield = csr.shield(a, J_vista)              # 证书盾：投影/拒绝
if rhd.hacking_score(traj) > tau_hack:         # "面不改色地失败"
    csr.shrink(region); retrain_counterfactual(region)
acc.advance_if(success, H_L, rhd.score)        # 强度课程
J_pact = build_training_cert(vista, pacs, ldl, csr, rhd, dpr, acc)
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（spot-then-recognize 的稀有事件召回与样本复杂度）**：总体召回 ≥ (1−ε_s)(1−ε_r)；因 spotter 类无关、可用全部 n 个样本训练，推荐样本复杂度从 O(1/π)（端到端，π 为稀有率）降到 O(1)，识别器只在候选窗上付 O(1/π) 代价。故极端长尾下两段式显著优于端到端。
- **引理 10（歧义悲观 + 势函数弃权的奖励偏差有界与策略不变）**：若 q 校准，CVaR_α 相对期望效用的偏差 = O(σ)，方向保守；熵势塑形 r'=r+γΦ(s')−Φ(s)（Φ=−cH_L）**不改变最优策略集**（势函数塑形不变性），弃权只降梯度方差、不扭曲可辨识区的最优点。
- **引理 11（证书屏蔽探索安全）**：若每步动作均经 Valid(J_vista) 盾投影/拒绝并配已验证 fallback，则训练期非预期物理越界率 ≤ α_total（继承 VISTA 的 α_chunk+δ_fi+α_vis+α_geo），**训练不引入证书预算之外的新风险**——前提是盾本身正确（继承 A88）。
- **定理 9（PACT 训练保证）**：在 A94–A100 下：训练期安全 ≤ α_total；歧义区奖励偏差有界且不改变最优集；稀有前兆召回 ≥ (1−ε_s)(1−ε_r)；解耦泄漏 ε_leak 下 sim-to-real 风险满足 Ben-David 型界；reward hacking 在留出检测器一致偏离时可检出（漏检受 PAU 覆盖上界约束）。故 Valid(J_pact) ⇒ **安全地学、学得准、没学会骗证书、换域不崩**。
- **定理 10（强度课程的探索期伤害-样本权衡）**：设阶段稀有率 π_1≥…≥π_L、单位样本伤害 d_ℓ 单调升。均匀探索从第一步就可能进入高强度阶段（访问率 π_L）；门槛课程要求低阶段成功率达标才放行，故前 N_low 步高强度访问率为 0，探索期期望灾难伤害从 d_L·π_L·N 降到 d_L·π_L·(N−N_low)。总覆盖样本 ~Σ_ℓ 1/π_ℓ（**可能不更少**），课程用**总样本换探索期安全**——先学"中性脸"再学"复合强表情"（与引理 11 的 α_total 预算对齐）。
- **命题（PAU 可辨识 ⇔ 近正交，呼应第 65 轮引理 7）**：PAU 激活矩阵 A 可辨识 ⇔ AᵀΣ⁻¹A≻0，条件数由解剖/物理独立性控制。PAU 若高度共激活（相关），则 κ_pau 退化、歧义与漏检同时上升——**这就是本轮头号风险的数学根**。
- **实时性**：PACS 前向、MES spotting、盾投影全在实时流（目标 ≤2.5ms 继承 VISTA）；LDL/APR/RHD/DPR/ACC 全在低频训练线程，实时路径零学习写操作。

## 2. 形式化定义（完整版）

**定义 233（PACT 闭环）** PACT 是 VISTA 的训练期前置闭环：在 VISTA 的"语义流 ∘ 实时流"骨架上，训练线程新增 PACS（PAU 编码）、MES（前兆 spotting）、LDL（标签分布）、APR（歧义悲观奖励）、CSR（证书屏蔽 RL）、DPR（解耦表征）、RHD（反奖励黑客）、ACC（强度课程），并输出 J_pact。不变式：**物理执行一律经 CSR 证书盾；PAU 前向、spotting、盾投影在实时流；奖励聚合、RHD 审计、DPR 训练、课程推进只在低频训练线程，实时路径零学习写操作。**

**定义 234（PACS 物理动作编码）** 编码器 E_φ 把接触流窗 x_{t−w:t} 映射到 PAU 强度 u_t∈[0,1]^K，解码器 D_ψ(u_t)≈x_{t−w:t}。要求：
1. **可解释**：第 k 个 PAU 有物理语义与单调方向（如 PAU-法向力上升率、PAU-切向滑移速度、PAU-力矩比、PAU-接触面积变化率、PAU-磨损漂移、PAU-接近速度）。
2. **可重构**：重构 R²≥ρ_rec（默认 0.9）。
3. **近正交**：在操作流形上激活矩阵 A=[u^{(1)}…u^{(N)}] 的列近正交，可辨识裕度 κ_pau=λ_min(AᵀΣ_x⁻¹A)/λ_max(·) 有下界。第 (3) 条是后文一切归因/检测的数学前提，也是最脆弱处。

**定义 235（PAU 时序包络与阶段切分）** 每个 PAU 用 onset–apex–offset 包络 e_k(t) 参数化，强度 A_k∈[0,1] 与包络共同构成"表情短语"。第 65 轮的阶段 P={approach,touch,load} 改由包络判定：approach ⇔ 所有接触类 PAU 的 A_k<ε_pos；touch ⇔ 法向力 PAU 进入 onset 后、未达 load 阈值；load ⇔ 法向力/滑移 PAU 的 apex 后。**用包络替代固定力阈值**，避免零力窗被污染。

**定义 236（MES spot-then-recognize）** spotter S_ω 类无关地输出微事件分数
s_t = α·‖x_t − D_ψ(E_φ(x_t))‖² + β·|Δu_t| + γ·ρ_rare(u_t)，
其中第三项为稀有度密度（训练集 PAU 密度的低分位）。s_t>τ_spot 的窗口送入识别器 R_ξ，输出 PAU 类别与强度。评价拆成两个可分解指标：**spotting 召回**（真前兆是否被任何候选窗覆盖）与**识别条件精度**（候选窗内类别是否正确）。两段式的关键收益：spotter 只用"有无前兆"的类无关标签，可用全部样本训练，不受稀有类不平衡拖累。

**定义 237（LDL 标签分布与歧义熵）** 对状态 s 的"正确 PAU/行为"标注为分布 q(a|s)（多标注者或多可行接触模式给出）。歧义熵 H_L(s)=−Σ_a q(a|s)log q(a|s)；校准要求 ECE(q)≤ε_cal。硬 one-hot 是 q=δ 的退化特例。q 由多标注者投票 + 退火软标签构造，允许"同一状态多个都对"。

**定义 238（APR 歧义悲观奖励与弃权）** 定义
r_APR(s,a) = CVaR_α^{q}[U(s,a)] + γΦ(s') − Φ(s),  Φ(s) = −c·H_L(s)。
悲观项把"歧义"转成"保守"（在标签分布的低尾取值）；熵势塑形是**势函数塑形**，由 Ng 等的不变性结论不改变最优策略集；当 H_L(s)>τ_amb 时**弃权**：该步不产生奖励梯度，只保留 CSR 的安全信号。这样歧义区的多峰性不会逼迫策略过度自信，稀有但高影响的前兆也不会被平均掉。

**定义 239（CSR 证书屏蔽 RL）** 训练目标
max_π E_π[r_APR]  s.t.  ∀t: a_t' = Π_J(a_t) 且 Valid(J_vista(s_t,a_t'))。
Π_J 为证书盾：若 a_t 使 J_vista 失效，投影到最近可行动作；若无可行投影，执行已认证 fallback（safe_idle / 柔顺 retreat）。等价于带屏蔽的 CMDP，拉格朗日乘子 λ_safe 自适应：
λ_safe ← [λ_safe + η(Ĉ_shield − α_total)]_+，
Ĉ_shield 为滑动窗口盾违约率。探索只在 {s: J_vista 有效} 内发生。

**定义 240（DPR 解耦物理表征）** 编码器分解 z=(z_id,z_expr)。约束 I(z_expr;z_id)≤ε_leak（MINE 下界或梯度反转实现），z_id 经域随机化增广（刚度/摩擦/质量/渲染/延迟），策略 π(a|z_expr,task) **不读 z_id**。泄漏用留出判别器估计 ε_leak 并写入 J_pact。其目的是把"同一种轻触稳定"在换物体时从"记忆绝对力"变成"识别相对相位"。

**定义 241（RHD 奖励黑客 / 表情抑制检测）** 维护一组**留出 PAU 检测器** {R_j}（训练奖励从未使用它们）与惊讶度地板 s_min。对策略轨迹计算抑制分数
κ_hack = TV(R_j 输出, 奖励用检测器输出) + 1[∃t: s_t < s_min ∧ 物理退化],
其中"物理退化"由独立物理量（滑移积分、力跟踪误差、接触面积损失）判定。κ_hack>τ_hack ⇒ 判 reward hacking：收缩 CSR 该区域可行域、冻结该区奖励、把抑制区标为负样本做反事实重训。**直译 FER 的表情抑制检测：真实失效在发生，但观测信号被压平。**

**定义 242（ACC 强度课程）** 课程阶段 ℓ=1..L 对应 PAU 强度、载荷与复合度递增（L=4 默认：低载荷单 PAU → 中载荷单 PAU → 高载荷单 PAU → 复合 PAU）。推进条件：本阶段滚动成功率≥ρ_succ ∧ H_L 已降至阈值 ∧ κ_hack≤τ_hack；否则回退。稀有失效在低阶段以"弱表情"暴露，避免到高载荷才首次遭遇。

**定义 243（复合 PAU / 复合故障组合解码）** 识别器输出多标签强度 u_t，用组合解码 argmax_{支持集} p(u_t|x) 而非单类 softmax。与第 65 轮"未知复合故障"对应：**复合故障只要求判 ambiguous 并安全降级，不要求强行归因**。

**定义 244（跨物体/跨域 PAU 不变性）** 要求 E_φ(T(x))≈E_φ(x)，T 为物体属性/渲染/动力学扰动；用一致性损失 + z_id 增广实现。域泛化界按 Ben-David 型：目标风险 ≤ 源风险 + 域差异项 + ε_leak·C，故降低 ε_leak 与域差异即收紧 sim-to-real 泛化界。

**定义 245（J_pact 训练证书）** Valid(J_pact) ⇔
Valid(J_vista) ∧ shield_violation_rate≤α_total ∧ ambiguity_ECE≤ε_cal ∧ hacking_score≤τ_hack ∧ leakage_est≤ε_leak ∧ pau_coverage≥ρ_min ∧ acc_ver 为当前版本。
审计链新增：为何这一步奖励被弃权（H_L）、为何判黑客（κ_hack/留出检测器）、训练是否越界（盾违约率）、表征是否泄漏（ε_leak）、课程到哪一阶段。

**定义 246（PACT 训练算子）** 低频训练流：[PACS 拟合重构→MES 预训练（类无关）→LDL 标定→CSR 屏蔽 rollout→PAU/前兆采集→APR 奖励→DPR 解耦更新→RHD 审计→ACC 推进→J_pact 构建]；实时流：[PAU 前向→spotting→盾投影→π_σ 派发→J_vista 构建]。训练完成后策略/世界模型交回 VISTA 做推理期归因与认证。

### IP-224 PACS（PAU 编码）

```python
class PACS:
    """可解释、可重构、近正交的物理动作单元编码。"""
    def __init__(self, K, rec_weight=1.0, orth_weight=0.1, sem_weight=0.1):
        self.enc, self.dec = MLP(in_dim, K), MLP(K, in_dim)
        self.K = K

    def loss(self, x, sem_targets):
        u = torch.sigmoid(self.enc(x))                  # [B,K] PAU 强度
        rec = ((self.dec(u) - x) ** 2).mean()           # 可重构
        gram = (u.T @ u) / max(len(u), 1)
        orth = (gram - torch.diag(torch.diag(gram))).pow(2).mean()  # 近正交
        sem = ((u - sem_targets) ** 2).mean()           # 物理语义弱监督
        return rec + self.orth_weight * orth + self.sem_weight * sem

    def envelope(self, u_seq):
        return [(onset(u_seq[:, k]), apex(u_seq[:, k]), offset(u_seq[:, k]))
                for k in range(self.K)]                  # onset-apex-offset
```

```python
class MicroExpressionSpotter:

class LabelDistributionLearner:

        q = softmax(logits / self.temperature)
        return apply_mask(q, event_mask)                 # 只在候选窗细分类
```

### IP-228 APR（歧义悲观奖励）

```python
class AmbiguityPessimisticReward:
    def __init__(self, alpha=0.1, c=0.5, tau_amb=0.7, gamma=0.99):
        self.alpha, self.c, self.tau_amb, self.gamma = alpha, c, tau_amb, gamma

    def __call__(self, q, utility, s, s_next):
        # 标签分布下效用的 CVaR（低尾 = 悲观）
        vals = (q * utility).sum(-1)
        cvar = self._cvar(utility, q, self.alpha)
        phi = -self.c * self._entropy(q)
        phi_next = -self.c * s_next.entropy
        r = cvar + self.gamma * phi_next - phi
        abstain = self._entropy(q) > self.tau_amb
        return torch.where(abstain, torch.zeros_like(r), r), abstain
```

```python
class CertifiedShieldRL:
    def step(self, policy, obs, J_vista):

        a_safe = self.shield.project_or_fallback(a, J_vista)   # Π_J
```

```python
class RewardHackingDetector:
    def __init__(self, heldout_detectors, s_min, tau_hack=0.3):
        self.dets, self.s_min, self.tau_hack = heldout_detectors, s_min, tau_hack

    def hacking_score(self, traj, physical_deg):
```

### IP-230 DPR（解耦物理表征）

```python
class DisentangledPhysicalRepr:
    def __init__(self, enc_id, enc_expr, disc, lam_leak=0.1):
        self.enc_id, self.enc_expr, self.disc = enc_id, enc_expr, disc
        self.lam_leak = lam_leak

    def split(self, x):
        return self.enc_id(x), self.enc_expr(x)          # z_id, z_expr

    def leak_device(self, z_expr):
        return self.disc(z_expr.detach())                # 奖励黑客式身份判别

    def loss(self, x, x_aug, policy_loss):
        z_id, z_expr = self.split(x)
        _, z_expr_aug = self.split(x_aug)                # 同一 z_id、扰动观测
        consist = ((z_expr - z_expr_aug) ** 2).mean()    # PAU 一致性（跨域不变）
        leak = -cross_entropy(self.leak_device(z_expr), self._id_label(x))
        grad_rev = -self.lam_leak * leak                 # 梯度反转：让 z_expr 不含身份
        return policy_loss + consist + grad_rev


class AdaptiveIntensityCurriculum:
    def __init__(self, L=4, rho_succ=0.8, tau_hack=0.3):
        self.L, self.rho_succ, self.tau_hack, self.stage = L, rho_succ, tau_hack, 1

    def advance_if(self, success, entropy, hacking):
        if success >= self.rho_succ and entropy < self._ent_target() \
           and hacking <= self.tau_hack:
            self.stage = min(self.L, self.stage + 1)
        elif success < 0.3 or hacking > 2 * self.tau_hack:
            self.stage = max(1, self.stage - 1)          # 回退
        return self.stage
```

```python
def PACT_train(M, replay, J_vista):
    # 低频训练线程
    M.pacs.fit(replay.x, replay.sem)                 # IP-224/225
    M.mes.pretrain(replay.x, replay.u)               # IP-226 类无关
    M.ldl.calibrate(replay.q)                        # IP-227 ECE
    for stage in range(1, M.ACC_L + 1):
        batch = replay.sample(intensity=stage)       # IP-232 课程
        u = M.pacs.encode(batch.x)
        spot = M.mes.spot(u); q = M.ldl.posterior(u, spot)
        a, logp = M.policy.act(M.dpr.expr(u), batch.task)
        a_safe, viol = M.csr.step(M.policy, batch.obs, J_vista)
        r, abstain = M.apr(q, batch.utility, batch.s, batch.s_next)
        M.update_policy(logp, r, abstain, viol)      # 弃权步无奖励梯度
        M.dpr.update(batch.x, lambda_leak)           # IP-230 解耦
        hack, k = M.rhd.audit(batch.traj, physical_deg(batch))
        if hack:
            M.csr.shrink(batch.region); replay.mark_negative(batch.region)
        M.acc.advance_if(batch.success, q.entropy, k)
    return build_j_pact(J_vista, M.pacs, M.ldl, M.csr, M.rhd, M.dpr, M.acc)
```

## 4. 推导

**引理 9（spot-then-recognize 的稀有事件召回与样本复杂度）** 设微事件稀有率为 π，spotting 漏检率 ε_s，识别条件错误率 ε_r。两段式总体召回 = (1−ε_s)(1−ε_r)（任何真前兆须先被候选窗覆盖、再被正确识别）。样本复杂度：spotter 目标为类无关的二分类（有/无前兆），正负样本可用全部 n 个时间窗，泛化差距 ∼√(log(1/δ)/2n)；端到端 K 类分类中稀有类有效样本仅 nπ，差距 ∼√(log(1/δ)/2nπ)。故两段式把 spotting 阶段的样本需求从 O(1/π) 降到 O(1)，识别器只需在候选窗（量级 πn）上付出 O(1/π) 代价——在 π≪1 时总代价远低于端到端。∎

**引理 10（歧义悲观与势函数弃权的偏差有界与策略不变）** 设 q 已校准为真实标签分布。CVaR_α 相对期望效用的差为 O(σ_q) 且方向保守（取值于低尾）。加入熵势 Φ(s)=−cH_L(s)：由势函数塑形不变性，r'=r+γΦ(s')−Φ(s) 与原奖励共享最优策略集，故熵势只平滑优化地形、不移动最优点。弃权等价于在该状态把奖励梯度置零，只降低梯度方差，不改变可辨识区的最优性。∎

**引理 11（证书屏蔽探索安全）** 若每步执行 a'=Π_J(a) 且 Π_J 只在 Valid(J_vista) 内返回，失效时用已单独认证的 fallback，则由 VISTA 引理 8 的联合界，训练期非预期物理越界率 ≤ α_total=α_chunk+δ_fi+α_vis+α_geo。屏蔽不改变"越界预算"，只把未认证动作挡在门外，因此训练不引入证书预算之外的新物理风险。**注意：此结论继承 J_vista 的正确性，即继承第 65 轮 A88。** ∎

**定理 9（PACT 训练保证）** 在 A94–A100（PAU 因果可分且近正交、q 可校准、盾正确、留出检测器与奖励检测器独立、解耦泄漏有界、课程稀有率单调）下：
1. **训练期安全**：由引理 11，越界 ≤ α_total。
2. **歧义鲁棒**：由引理 10，歧义区奖励偏差 O(σ_q) 且最优集不变，弃权只降方差。
3. **稀有前兆**：由引理 9，召回 ≥ (1−ε_s)(1−ε_r)，spotting 样本需求 O(1)。
4. **跨域泛化**：Ben-David 界 目标风险 ≤ 源风险 + d_ℋ(源,目标) + ε_leak·C，DPR 同时压 d_ℋ（PAU 一致性）与 ε_leak。
5. **反奖励黑客**：若策略把 PAU 压向 spotter 盲区而物理退化，则留出检测器与奖励检测器 TV 偏离增大、且 s_t<s_min ∧ 物理退化触发，κ_hack 超过 τ_hack；漏检率受 PAU 覆盖率 ρ_min 上界约束。故 Valid(J_pact) ⇒ 训练安全 ∧ 歧义校准 ∧ 前兆可召回 ∧ 域泛化有界 ∧ 未学会骗证书。∎

**定理 10（强度课程的探索期伤害-样本权衡）** 设课程阶段稀有率 π_1≥…≥π_L、单位样本伤害 0<d_1≤…≤d_L。均匀探索从第一步起以访问率 π_L 进入最高强度阶段，探索期期望灾难伤害 ≈ d_L·π_L·N。门槛课程要求阶段 ℓ<L 的成功率≥ρ_succ 才放行 ℓ+1，故前 N_low 步对阶段 L 的访问率为 0，期望灾难伤害降至 d_L·π_L·(N−N_low)（低阶段伤害 d_ℓ 计入小量）。代价是覆盖所有强度所需样本 ~Σ_ℓ 1/π_ℓ，**可能大于均匀采样的 1/π_min**——课程不以总样本取胜，而以"把样本从高伤害区挪到低伤害区"取胜。当 d_ℓ 单调升且训练受 α_total 安全预算约束时，这是帕累托改进：在同等安全预算下可探索更多，或在同等探索量下伤害更低。故课程的正确收益是**探索期安全**而非纯样本效率。∎

**命题（PAU 可辨识 ⇔ 近正交）** 线性化 u=Aθ+η、η∼N(0,Σ_u)，则 θ 可辨识 ⇔ J_pau=AᵀΣ_u⁻¹A≻0，κ_pau=λ_min(J_pau)/λ_max(J_pau)。FER 中 AU 的解剖独立性给出激活矩阵近正交，故 κ_pau 有下界；若接触 PAU 高度共激活（如同一机械臂姿态下法向力与力矩比强相关），则对应列近共线，κ_pau→0，识别与 spotting 同时退化。这与第 65 轮引理 7（阶段签名可辨识）同构：**可辨识性不是数据量问题，而是编码设计问题**。

**双层契约（Training–Inference Contract）**：
- **推理期（VISTA）**：给定策略/世界模型，负责"归因与认证"，输出 J_vista。
- **训练期（PACT）**：给定盾 J_vista，负责"学出策略且不去刷盾"，输出 J_pact。
- **双向咬合**：
  1. J_vista → Π_J：训练动作必须过推理期证书盾（训练不越过 α_total）。

## 9. 数值 sanity check 与消融矩阵

**引理 9 的算例**：取稀有率 π=0.01、spotting 漏检 ε_s=0.05、识别条件错误 ε_r=0.05，则总体召回 ≈0.95×0.95=0.9025。端到端要在稀有类上得到 1000 个正样本需 n≈10^5 个窗；类无关 spotter 只需约 5×10^3 个含/不含前兆的窗即可把 spotting 召回推到 ~0.95（VC 界尺度），识别器只在 ~πn 个候选窗上训练。故 spotting 阶段样本需求降约一个数量级（1/π），与极端长尾（π<0.01）时收益更大。

**引理 11 的算例**：继承 VISTA 的 α_chunk=0.05、δ_fi=0.15、α_vis=0.05、α_geo=0.05，则 α_total≈0.30 为训练期最坏越界上界；实现上通过"盾投影 + 已验证 fallback"通常远低于此。关键不是数值大小，而是**训练不放大 VISTA 已承诺的预算**。

**命题的算例**：若 K=8、PAU 两两相关系数 0.2，则 AᵀΣ⁻¹A 近似单位阵加 0.2 的 off-diagonal，κ_pau≈(1+0.2·7)/(1−0.2) 量级有限；若相关系数升到 0.9，κ_pau 迅速塌缩，归因混淆率按 exp(−n·κ_pau/2) 恶化——**与第 65 轮引理 7 的 Laplace 速率同形**。这说明："多加 PAU"不等于"更可辨识"，关键是正交设计。

**定理 10 的算例**：π_L=0.005、N=10^5、d_L=1、π_ℓ 低阶段伤害 d_ℓ≈0.1。均匀探索期高伤害期望 ≈0.005×10^5=500 单位；门槛课程若前 80% 步锁在高强度外，则高伤害期望降至 ~100 单位（降 80%），代价是总样本从 ~2×10^4 增至 ~5×10^4（Σ1/π_ℓ）——**用 2.5× 样本换 5× 伤害下降**，在 α_total 约束下是合算的。

## 10. 已知风险

**一句话**：PACT 的全部论证依赖「PAU 是因果可分的、且其语义跨物体/跨域稳定」这一隐藏假设（A94）；若 PAU 实际高度共激活、或换物体/仿真器后同一 PAU 变了意思，则歧义惩罚与弃权会**系统性压掉稀有但致命的微弱前兆**，spotter 恰在最需要处失明，RL agent 却学会把残差维持在"分类器认为正常"的窄带里——**「表情抑制」从被检测对象升级为训练最优解：分类体系变成自我实现的预言，系统只看得见它有名字的故障，agent 学会面不改色地失败。**

**次级风险与缓解**：
1. **PAU 共激活/不可分**：接触物理量天然相关（力-力矩-滑移）；缓解：用近正交正则 + 稀疏激活 + 物理先验约束，并在 J_pact 记录 κ_pau，低于阈值即拒绝宣称可辨识。
2. **跨域语义漂移**：换物体后 PAU 含义变；缓解：DPR 一致性 + z_id 增广，漂移检测触发重标定，而非硬用旧 PAU。
3. **弃权导致学习停滞**：高歧义区长期无梯度；缓解：用主动奖励查询在高歧义高影响点补标签，把"弃权"变成"请人标"而非"放弃"。
4. **盾过保守**：CSR 可能把可行探索挡掉；缓解：拉格朗日自适应 + 只在 J_vista 失效区投影，保留盾内全空间。
5. **RHD 与奖励检测器共享偏差**：留出检测器若不独立则漏检；缓解：多源检测器（物理量/留出 PAU/世界模型残差）交叉，任一偏离即审计。
6. **spotter 误报拖垮识别器**：候选窗过多；缓解：稀有度密度 + 时序一致性过滤，限制单位时间候选窗数。
7. **课程推进被奖励黑客信号污染**：agent 可能压住推进指标；缓解：推进条件用留出物理量，不看 agent 可控信号。
8. **计算与工程复杂度**：PACS/MES/DPR/RHD 显著增训练成本；缓解：只在训练线程、离线预训练 spotter、实时流零学习。
