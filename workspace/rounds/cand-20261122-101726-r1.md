# 第 3 轮（新灵感循环第 3 轮；本轮灵感：「轮足机器人」×「记忆检索」）

> **基线**：第 2 轮产出 MetricVoiceGauge-NCD-HUTDH-v20+IP-420–424。本轮纪律：**形态是证书的维度、记忆是证明的索引、切换是带守卫的迁移**。不推倒 v20：CLP/S2C/HCG/PSV/APS/AMC（v17）、DCM/OGCC/CCV/DRS/OGC（v19）、PCA/CTS/CFC/HPC/CFCtrl（v20）全部保留。本轮只做一件事：把轮足机器人的**接触模式切换**与**情节记忆检索**，以“只检索证明、不复用结论”的方式，安全地注入 v20 的证书体系。

## 0. 直觉与动机

**灵感 1（轮足机器人 → 证书要随接触模式“换参考系”，不是换阈值）**
直觉：轮足机器人在同一时刻可能以轮接地、足端接地或轮足混合支撑；轮式的碰撞域近似一个滚动圆柱体，足式的碰撞域取决于落足点与摆动腿包络。二者不是同一参数空间里“大小不同”的两个域，而是**接触签名不同**的两套几何。v20 的 `ColDom_fed` 默认了一个固定接触模式，一旦模式切换，证书的参考系就变了。核心创新：**形态-接触证书 (Morpho-Contact Certificate, MCC)**，把碰撞证书从 `Θ_n^col(o)` 升级为 `Θ_n^col(o, m)`，其中 `m` 为接触模式，证书绑定**接触签名** `κ(n,m) = (接触点集、法锥、摩擦锥、支撑多边形、等效惯量)`。关键反直觉点：**模式切换不是在两张证书之间插值，而是在一张证书内部切换参考系**——只有接触签名可连续迁移的公共子域，才允许跨模式复用；否则必须重建证书。

**灵感 2（记忆检索 → 检索“证明”，而不是检索“结论”）**
直觉：最朴素的做法是把历史“这里安全”的结论直接拿来用，但这很危险：结论依赖当时的接触模式、地形、物体几何与标定，任何一项漂移都会让结论失效。核心创新：**情节证书记忆 (Episodic Certificate Memory, ECM)**。记忆库存的不是 SAFE 标签，而是**证书证明对象** `c = (上下文签名 x, 证书骨架, 证明义务 obligations, 局部见证样本, 版本, 时间)`。检索按上下文相似度返回候选**证明骨架**；再由**检索门控复验 (Retrieval-Gated Revalidation, RGR)** 在当前上下文重放证明义务，只有重放通过才把候选域接回当前证书。关键反直觉点：**记忆的价值不是省掉验证，而是把“在全参数空间搜索证明”缩小为“在检索到的证明骨架附近重放”**——检索只改变搜索起点，不改变接受判据。

**灵感 3（轮足 × 记忆 → 混合步态的“守卫记忆”）**
直觉：轮足的步态切换是离散事件序列，历史切换经验（哪种地形从轮式切足式、切换时的速度/姿态窗口）很有价值，但这些经验以“轨迹片段”存在，不能直接当证书。核心创新：**混合步态证书自动机 (Hybrid Gait Certificate Automaton, HGCA)**，把模式切换建模为带守卫的混合自动机：每个模式有不变量 `Inv_m`，每条切换边有守卫 `G_{m→m'}` 与**瞬态管道证书** `T_{m→m'}`。记忆库检索的是**历史守卫与瞬态管道的证明骨架**，在当前接触签名下复验后，才允许扩展当前守卫。关键反直觉点：**轮足的“熟练”不是记住了成功的动作，而是记住了哪些守卫曾经被证明过**。

**三者如何统一**
统一为 **v20 感知证书体系之上的形态-记忆层**：v20 回答“给定几何与分布式感知，θ 是否安全”；v21 回答“在给定接触模式 m 与历史证明记忆下，θ 是否仍安全，以及能否安全切到 m′”。MCC 是形态维度，HGCA 是切换维度，ECM/RGR/FIC 是记忆维度。共享状态 `ζ_hyb = (mode, contact_signature, memory_index, retrieved_proofs, discrepancy, τ_mode, mode_chain)`。统一接口：**MCC ∧ HGCA ∧ ECM(检索命中) ∧ RGR(复验通过) ∧ FIC(新鲜且无冲突) 全部成立，CCV 窄相位才在该子域返回 SAFE；否则回退 v20**。

## 1. 研究问题（轮次升级版）

- **Q1（形态-接触证书的保守性）**：如何定义接触签名 `κ(n,m)` 与模式条件碰撞域 `Θ_n^col(o,m)`，使模式切换时证书的保守性可证？接触签名漂移（打滑、悬空、软地面下陷）如何量化并转成 `margin_contact`？证书在 `‖κ−κ̂‖ ≤ δ_κ` 之外如何安全降级？

- **Q2（记忆的证明表示）**：证书如何表示成可机械重放的证明对象（证明义务 + 见证集 + 覆盖证书），使检索到的记忆可被独立复验？上下文签名 `x` 如何设计，使相似检索召回高、误召回低？

- **Q3（检索门控）**：上下文差异 `Δ(x,x_i)` 与证明重放条件如何共同保证“移植后仍安全”？阈值 `δ_gate` 如何随 v20 的 `ρ_max`、`margin_col` 自适应？当检索命中的是“部分证明”时，如何只接回被证明覆盖的子域？

- **Q4（混合步态时序）**：轮/足/混合切换的瞬态（腾空、单支撑、轮足交替）如何在 50Hz 控制环内被 HGCA 的不变量 + 守卫覆盖？记忆检索延迟（含 v20 CFC 共识延迟）与模式切换时序如何协调？检索未完成时如何维持 v20 的安全执行？

## 2. 设计原则（在 P31–P33 基础上新增 P34–P37）

**P34 形态条件证书律（Morpho-Conditioned Certificate）**
证书以 `(o, m, κ)` 为索引。只有当实测接触签名 `κ_now` 满足 `d_κ(κ_now, κ_cert) ≤ δ_κ` 时证书有效；否则证书降级为“仅该接触签名下的保守子域”。模式切换必须额外通过**瞬态管道证书** `T_{m→m'}`：切换期间 50Hz 采样轨迹必须整体落在 `Inv_m ∩ Inv_{m'} ∩ SafeSet` 内。**模式条件证书只能收缩参数域，不能扩张**。

**P35 记忆证明律（Proof-Not-Verdict）**
ECM 只存**证明对象**，不存 SAFE 结论；检索返回证明骨架；RGR 必须重放全部证明义务；记忆命中**不能绕过** CCV/PCA 的局部验证。故记忆只能改变“先验/搜索起点”，不能改变“接受判据”。形式化：`Accepted_v21(θ) ⇒ Accepted_v20(θ)` 对任意记忆内容成立。

**P36 混合步态安全律（Hybrid Gait Safety）**
HGCA 的每个模式有不变量 `Inv_m ⊆ Θ_n^col(o,m) ∩ Balance_m`；每条切换边有守卫 `G_{m→m'} ⊆ Inv_m ∩ Inv_{m'}` 与瞬态管道 `T_{m→m'}`；执行计划必须在自动机接受语言内，且瞬态管道覆盖切换期间全部采样点。**守卫只能从“已验证的公共子域”中取，禁止从记忆结论直接生成守卫**。

**P37 遗忘保守律（Conservative Forgetting）**
记忆有 TTL 与版本号；过期或版本不匹配的记忆不得参与 RGR。同一键出现冲突证明时，安全域取**保守交**、危险域取**保守并**；若冲突无法消解（同时存在 SAFE 与 UNSAFE 证明），该键降级为 `UNKNOWN` 并排除。**遗忘是安全机制，不是性能妥协**。

## 3. 与基线的接口（如何退化）

- MCC 失效/接触签名未知 ⇒ 固定为 v20 的单一接触假设 ⇒ 等价 v20（更保守）；
- HGCA 失效/模式不可判定 ⇒ 锁定当前模式、禁止切换 ⇒ 等价 v20；
- ECM 无命中/检索超时 ⇒ 走 v20 的全量证书构建 ⇒ 等价 v20；
- RGR 复验失败/`Δ > δ_gate` ⇒ 丢弃候选、回退全量构建 ⇒ 等价 v20；
- FIC 冲突/过期/版本不匹配 ⇒ 该记忆不可用 ⇒ 等价无记忆（v20）；
- 全失效 ⇒ 完全回退 v20；**安全继承**：MCC 收缩域、HGCA 限守卫、ECM/RGR 只接回子域、FIC 只删不增，故 `Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19`，由引理 162 保证。

## 4. 预期贡献

1. **形态-接触证书**：首次把轮足接触模式作为碰撞证书的显式维度，给出模式条件碰撞域、接触签名鲁棒界与跨模式公共子域；
2. **情节证书记忆**：提出“检索证明而非结论”的记忆范式，把经验复用改造为证明复用，填补“记忆加速”与“证书安全”之间的鸿沟；
3. **混合步态证书自动机**：把轮足切换的瞬态纳入带守卫的可验证自动机，使“切换过程”本身可证明安全；
4. **检索门控复验与遗忘保守律**：使记忆召回率提升不以安全为代价，给出可机械审计的移植与遗忘规则；
5. **v21 形态-记忆层**：`Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19`，闭环“形态切换 → 记忆加速 → 碰撞安全”。

## 5. 本轮最大风险

**一句话**：ECM/RGR 的安全性依赖“上下文相似 ⇒ 证明可移植”的**连续性假设**；若地形/接触的微小变化引起碰撞谓词的**非连续跳变**（薄冰突然破裂、轮子陷入软土、足端踩塌薄壳），则 `Δ` 很小但证明已失效，检索会以“高相似度”把错误证明移植进来——即**记忆的连续性幻觉**。

# IP-425 Morpho-Contact Certificate
@dataclass(frozen=True)
class ContactSignature:
    contacts: tuple          # 接触点 / 轮接地弧采样
    normal_cone: tuple
    friction_cone: tuple
    support_polygon: Polygon
    inertia_eff: np.ndarray

    def distance(self, other, w=(1.0, 0.5, 0.5, 0.5, 0.3)):
        return (w[0] * hausdorff(self.contacts, other.contacts)
                + w[1] * cone_angle(self.normal_cone, other.normal_cone)
                + w[2] * cone_angle(self.friction_cone, other.friction_cone)
                + w[3] * poly_dist(self.support_polygon, other.support_polygon)
                + w[4] * rel_fro(self.inertia_eff, other.inertia_eff))


class MorphoContactCertificate:
    def __init__(self, ccv, delta_kappa=0.05, lip_kappa=2.0, margin_contact=0.005):
        self.ccv = ccv
        self.delta_kappa = delta_kappa
        self.lip_kappa = lip_kappa          # L_c 的上界估计
        self.margin_contact = margin_contact

    def certify(self, node, obj, mode):
        kappa = extract_contact_signature(node, obj, mode)
        # 1. 取模式条件碰撞域（v20 CCV 增加 mode 参数）
        dom = self.ccv.query_mode_conditioned(node, obj, mode)
        # 2. 按接触不确定性保守收缩：L_c * δ_κ + margin_contact
        shrink = self.lip_kappa * self.delta_kappa + self.margin_contact
        dom_safe = dom.shrink(shrink)
        return ModeCertificate(mode=mode, kappa=kappa, domain=dom_safe,
                               margin=shrink, t=now())

    def valid_under(self, cert, kappa_now):
        return cert.kappa.distance(kappa_now) <= self.delta_kappa

    def common_subdomain(self, cert_a, cert_b):
        """跨模式可迁移的公共子域（模式切换复用）"""
        common = cert_a.domain.intersect(cert_b.domain)
        if common.is_empty() or common.volume() < common.margin():
            return None
        return common.shrink(cert_a.margin + cert_b.margin)

    def degrade(self, cert):
        """签名漂移超界：降级为 UNKNOWN，交由 v20 全量重建"""
        return None


# IP-426 Hybrid Gait Certificate Automaton
class HybridGaitCertificateAutomaton:
    def __init__(self, mcc, ccv, balance, sample_hz=50):
        self.mcc = mcc
        self.ccv = ccv
        self.balance = balance
        self.sample_hz = sample_hz

    def invariant(self, mode, cert):
        return cert.domain.intersect(self.balance.set(mode))

    def guard(self, src, dst, cert_src, cert_dst):
        # 守卫只能来自两张已验证证书的公共子域
        return self.mcc.common_subdomain(cert_src, cert_dst)

    def transition_certificate(self, src, dst, plan, cert_src, cert_dst):
        guard = self.guard(src, dst, cert_src, cert_dst)
        if guard is None:
            return None, "NO_COMMON_GUARD"
        tube = reachable_tube(plan, src, dst, hz=self.sample_hz)
        # 瞬态管道必须整体落在 守卫 ∩ 两种模式不变量 ∩ 当前安全集
        must = guard.intersect(self.invariant(src, cert_src)) \
                    .intersect(self.invariant(dst, cert_dst))
        if not tube.subset_of(must):
            return None, "TUBE_ESCAPES_GUARD"
        if not tube.subset_of(self.ccv.safe_set()):
            return None, "TUBE_UNSAFE"
        return TransitionCertificate(src, dst, guard, tube, t=now()), "OK"

    def accepts(self, mode_sequence, plan, certs):
        cur = mode_sequence[0]
        for nxt in mode_sequence[1:]:
            tc, st = self.transition_certificate(cur, nxt, plan, certs[cur], certs[nxt])
            if st != "OK":
                return False, st
            cur = nxt
        return True, "OK"

@dataclass
class CertificateProof:
    context: ContextSignature
    skeleton: object            # 证书骨架（域形状 + 参数化）
    obligations: list           # O：边界约束（可重放）
    witnesses: list             # W：支撑义务的采样

    version: int
    t_created: float
    ttl: float

class EpisodicCertificateMemory:
    def __init__(self, dim, n_tables=8, n_hashes=4):
        self.index = LSHIndex(dim, n_tables, n_hashes)   # 内容寻址
        self.store = {}

    def insert(self, proof):
        key = proof_id(proof)
        self.store[key] = proof
        self.index.add(key, embed(proof.context))

    def retrieve(self, ctx, k=5, rho_ret=0.8):
        cands = self.index.query(embed(ctx), k=k)
        scored = [(self.context_similarity(ctx, self.store[c].context), c) for c in cands]
        scored = [(s, c) for s, c in scored if s >= rho_ret]
        scored.sort(reverse=True)
        return [self.store[c] for _, c in scored]

    def context_similarity(self, a, b):
        # 接触签名 + 地形 + 物体谱系 + 参数域重叠 + 传感器置信度
        return (0.30 * (1.0 - tanh(a.kappa.distance(b.kappa)))
                + 0.20 * terrain_sim(a.terrain, b.terrain)
                + 0.20 * spectrum_sim(a.spectrum, b.spectrum)     # 复用 v20 CTS

# IP-428 Retrieval-Gated Revalidation
class RetrievalGatedRevalidation:
    def __init__(self, ccv, mcc, delta_gate0=0.10, cover_eps=0.01):
        self.ccv = ccv
        self.mcc = mcc
        self.delta_gate0 = delta_gate0
        self.cover_eps = cover_eps

    def adaptive_delta_gate(self, rho_max, margin_col):
        # 感知风险越高、margin 越小，门越严
        return self.delta_gate0 * (1.0 - rho_max) * (1.0 + margin_col)

    def transplant(self, proof, ctx_now, node, obj, mode):
        # 1. 上下文门控
        delta = context_discrepancy(proof.context, ctx_now)
        gate = self.adaptive_delta_gate(ctx_now.rho_max, ctx_now.margin_col)
        if delta > gate:
            return None, "CONTEXT_SHIFT"
        # 2. 接触签名门控
        if not self.mcc.valid_under(proof.mode_cert, ctx_now.kappa):
            return None, "KAPPA_DRIFT"
        # 3. 只接回被证明覆盖的子域（绝不超过当前模式域）
        cand = proof.domain.intersect(self.ccv.query_mode_conditioned(node, obj, mode))
        # 4. 证明义务重放（必须全部通过）
        for ob in proof.obligations:
            if not self.replay(ob, node, obj, mode):
                return None, "OBLIGATION_FAIL"
        # 5. 覆盖证书：义务须 ε-覆盖候选域边界
        if not self.covers_boundary(proof, cand, eps=self.cover_eps):
            return None, "INSUFFICIENT_COVERAGE"
        return cand, "OK"

    def replay(self, obligation, node, obj, mode):
        verdict = self.ccv.check(obligation.sample, node, obj, mode)
        return verdict == "SAFE" and self.ccv.margin(obligation.sample) >= obligation.margin

    def covers_boundary(self, proof, cand, eps):
        return boundary_coverage(proof.witnesses, cand) <= eps


# IP-429 Memory Interference & Forgetting Controller
class MemoryInterferenceForgettingController:
    def __init__(self, version_table, default_ttl=600.0):
        self.version_table = version_table
        self.default_ttl = default_ttl

    def admit(self, proof, now):
        if now - proof.t_created > min(proof.ttl, self.default_ttl):
            return False, "EXPIRED"
        if proof.version < self.version_table.current(proof_key(proof)):
            return False, "STALE_VERSION"
        return True, "OK"

    def resolve_conflicts(self, proofs):
        """同键多证明：安全域保守交，危险域保守并；混合冲突降级 UNKNOWN"""
        safe = [p for p in proofs if p.label == "SAFE"]
        unsafe = [p for p in proofs if p.label == "UNSAFE"]
        if safe and unsafe:
            return None, "UNKNOWN"          # 冲突未消解，排除
        if unsafe:
            return union(unsafe), "UNSAFE"  # 危险域保守并
        dom = intersect_all([p.domain for p in safe])
        return dom, "SAFE"

class ContactScheduleFreshnessIntegrator:

        self.aps = aps
        self.cfc_freshness = cfc_freshness
        self.ttl_mode = ttl_mode
        self.ttl_retrieval = ttl_retrieval

    def gate(self, mode_cert, transition_cert, proof, now):

## 3. 推导

**引理 157（接触签名鲁棒性）** 设碰撞谓词对接触签名满足 `L_c`-Lipschitz，即 `d_κ(κ,κ') ≤ δ ⇒ |col(θ,κ) − col(θ,κ')| ≤ L_c·δ`。MCC 将证书域收缩 `L_c·δ_κ + margin_contact` 后，若 `d_κ(κ_now,κ_cert) ≤ δ_κ`，则 `cert.domain ⊆ Θ_n^col(o,m)|_{κ_now}`。故模式条件证书在签名漂移内仍保守。∎ 推论：**证书只收缩，不扩张**。

**引理 158（模式切换守卫保守性）** HGCA 仅在 `T_{m→m'} ⊆ Inv_m ∩ Inv_{m'} ∩ SafeSet` 时接受切换。瞬态管道的 50Hz 采样覆盖切换全过程，且守卫取自两张已验证证书的公共子域。故切换期间任意采样点均满足两种模式的不变量与零碰撞，`mode_sequence` 的整条轨迹安全。∎

**引理 159（证明重放可靠性）** 设候选域边界 `∂Cand` 被证明义务的见证集 `W` 以 `ε` 覆盖，碰撞谓词对 θ 满足 `L_θ`-Lipschitz，且每个义务在当前上下文重放时以 `L_θ·ε` 的余量通过。则 `Cand ⊆ Θ_n^col(o,m)`。证明：任取 `θ ∈ Cand`，存在 `w ∈ W` 使 `‖θ−w‖ ≤ ε`；重放给出 `w` 安全且余量 `≥ L_θ·ε`，由 Lipschitz 得 `θ` 安全。∎ 推论：**义务覆盖不足时 RGR 必须拒绝**（`INSUFFICIENT_COVERAGE`）。

**引理 160（检索门控保守性）** RGR 的候选域 `Cand = proof.domain ∩ Θ_n^col(o,m)_now`，故 `Cand ⊆ Θ_n^col(o,m)_now`。记忆命中只能接回当前模式域的子集，不能越过 v20 的 CCV/PCA 边界。因此任意记忆内容下 `Accepted_v21 ⇒ Accepted_v20`。∎

**引理 161（遗忘与冲突保守性）** FIC 排除过期与版本不匹配的证明；冲突证明按安全域取交、危险域取并，混合冲突降级 UNKNOWN 并排除。三类操作都只能删除候选或收缩域，不能新增授权。故记忆治理不破坏 `Exec_v21 ⊆ Exec_v20`。∎

**引理 162（v21 整体安全继承）** 同一几何快照、同一接触签名、同一机器人集合下，`Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。证明：MCC 收缩域、HGCA 限制守卫、ECM 只检索、RGR 只接回子域、FIC 只删不增、CSFI 只触发回退，六者叠加只产生子集。∎

**命题 163（记忆加速的边界）** 令 `S_full` 为 v20 全量证书构建的搜索空间，`S_ret` 为检索证明骨架附近的搜索空间。若检索召回率 `r`、误召回率 `f`，则期望加速比 `≤ |S_full| / (r·|S_ret| + (1−r)·|S_full|)`，且该加速**不以安全为代价**（引理 159–161）。∎ 说明：记忆只在证明空间做剪枝。

## 7. 已知风险与失效模式

1. **记忆的连续性幻觉**：RGR 假设“上下文相似 ⇒ 证明可移植”。在非连续接触（薄冰破裂、软土塌陷、足端踩空）下，`Δ` 很小但碰撞谓词跳变，导致错误移植。缓解：非连续性检测器（接触力/滑移突变）、局部重采样、`δ_gate` 随不确定性收紧、检测到跳变即全量回退。

2. **接触签名估计误差**：轮足接触点/法锥/摩擦锥由状态估计得到，打滑与悬空会造成 `κ` 偏差被低估，使 `valid_under` 误判为有效。缓解：多传感器融合（IMU/关节力矩/视觉）、在线滑移估计、`L_c` 在线标定。

3. **证明义务覆盖不足**：若 `W` 只覆盖边界的一部分，重放通过仍可能漏掉未覆盖区域。缓解：显式覆盖证书 + `ε` 上界校验（引理 159 的 `INSUFFICIENT_COVERAGE` 分支）、自适应加密采样。

4. **记忆投毒/来源伪造**：跨机器人共享证明时，恶意证明可能被检索命中。缓解：来源签名与版本链、复用 v20 CFC 拜占庭过滤、RGR 本地重放作为最后防线。

5. **LSH 假阴性**：相似上下文未召回，导致活性损失（不是安全问题）。缓解：多表 + 精确回退、召回率监控、冷启动全量构建。

6. **模式爆炸与状态空间**：轮/足/混合 × 地形 × 物体组合过多，证书与守卫数量膨胀。缓解：模式抽象、证书骨架共享、按需生成。

7. **检索/切换时序与 50Hz 冲突**：检索或瞬态管道计算超时，导致控制环降频。缓解：检索旁路化、预计算守卫、CSFI 超时回退 v20。

8. **版本漂移与一致性**：多机器人记忆版本不一致，旧证明被误用。缓解：单调版本号、强一致版本表、拒绝降级。

## 8. 本轮最大风险

**一句话**：ECM/RGR 的安全性依赖“上下文相似 ⇒ 证明可移植”的连续性假设；若地形/接触的微小变化引起碰撞谓词的**非连续跳变**（薄冰突然破裂、轮子陷入软土、足端踩塌薄壳），则 `Δ` 很小但证明已失效，检索会以“高相似度”把错误证明移植进来——即**记忆的连续性幻觉**。
