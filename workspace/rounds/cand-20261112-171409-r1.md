# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「多机协同」×「碰撞避免」）

> 第 60 轮的 SGEC 把单机器人的「场景→意图→约束→阻抗→执行→证据」闭环打通了，但它的三个隐含假设在多机场景下同时失效：
> 1. **阻抗空间的单机可分解假设**：EEIS 把 K_safe 当作单机独立编译的安全集，SIC 三元校验也只用本机的 scene_conf/K_certainty。多机共享工作空间时，两台机器的阻抗通过共享对象/共享接触面**物理耦合**——各自独立编译出的 K_safe 在联合空间里可能根本不可行。双机共搬一个箱子时，「各承担一半载荷」的独立假设在力学上是错的。
> 2. **「碰撞避免」与「接触执行」的目标冲突**：经典避障（CBF/速度障碍）隐式假设机器人是**不接触的质点**，安全集是「距离 ≥ d_safe」。但接触式操作机器人恰恰**需要接触**：若把避障直接叠加，任何正常接触都会被判为碰撞并触发假阳性急停（false stop），把 SGEC 的「执行接地」变成「执行瘫痪」。
> 3. **证据链的全局时钟假设**：第 60 轮 EPIR 依赖单机单调 seq_id 与可比较 timestamp。多机 ROS2/DDS 各节点是**独立时钟、独立序列**的，「谁先谁后」无法用单机 seq 表达；若强行融合，会把并发事件误判为因果事件，破坏 J_exec 的可审计性。

## 0. 直觉与动机

**灵感 1（多机协同 → 联合阻抗可行域 JSIC）**
直觉：两台机器人不是「两个独立的安全集」，而是「一个联合约束系统」。想象双机共抬一张桌子：机器 A 的刚度 K_A 越低，桌子越会把负载甩给 B；A 认为「我只需承担 G/2」的独立假设在物理上是错的。关键洞见：**把多机的安全从「笛卡尔积 K_safe^A × K_safe^B」升级为「带耦合约束的联合集合 K_joint」**——耦合项 C_ij(K_i,K_j) 显式刻画共享载荷/共享接触面的力学传递，联合可行性成为一等的安全判据。

**灵感 2（碰撞避免 → 接触感知避障 CACA）**
直觉：碰撞与执行性接触的区别不在「是否接触」，而在「**接触是否有意图证书且落在允许的接触流形上**」。因此安全屏障不应是标量距离 d_safe，而应是**意图条件化屏障** h^CACA：当且仅当本机持有有效的接触意图证书、且接近方向落在接触锥（contact cone）内时，屏障边界才从 d_safe 松弛到 d_contact_min；否则维持硬边界。关键洞见：**避障要「认得出该碰的碰」**——把 EV-exec 意图证据变成放行接触的许可证。

**灵感 3（多机证据 → 向量时钟分布式证书 DVEC）**
直觉：没有全局时钟，就不能问「绝对谁先」；只能问「**因果上谁依赖谁**」。向量时钟 V_i ∈ N^M 恰好刻画这种偏序：m → m' 当且仅当 V(m) 逐分量 ≤ V(m')。多机证据链要的不是「合并所有日志」，而是「**一个因果一致的全局切（consistent cut）**」——类似 Chandy-Lamport 快照：每台机器在一致切内贡献一段 EV-exec，联合证书 J_exec^multi 只在该切上验证哈希链。关键洞见：**证据的完整性 = 因果一致性，而非时间戳顺序**。

**灵感 4（三灵感合流 → 多机认证闭环 MACL）**
直觉：JSIC 决定「联合阻抗是否可行」；CACA 决定「哪些接触可以放行」；DVEC 决定「联合证据是否可审计」。把它们串成闭环：**场景→联合意图→协商约束→联合阻抗→接触感知执行→分布式证据→联合信念更新**。执行不是「各干各的」，而是「在联合可行域内、在意图许可的接触上、留下因果一致的证据」。

**灵感 5（PCE++++ → 多机预算 PCE+++++）**
直觉：多机新增三类不可忽视的开销——通信 B_comm（带宽/消息率/时延）、协商 B_coord（RCC 迭代轮数）、安全裕度 B_safety（可接受的保守度与假阳性急停率）。**通信越少，安全裕度必须越大**：δ_safe = g(B_comm 赤字)，形成「通信-安全」守恒。若 B_comm 耗尽⇒LSF 局部安全包络；若 B_coord 耗尽⇒固定右行/优先级；若 B_safety 耗尽⇒全局保守减速。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（联合场景-阻抗-置信度 JSIC）** 设智能体集合 A={a_1,...,a_M}，联合阻抗 K=(K_1,...,K_M)，K_i∈R^d。定义：
- **耦合算子**：C_ij(K_i,K_j) = ‖T_ij K_i − T_ji K_j‖_{Σ_ij}，T_ij 为共享对象载荷传递矩阵。对刚性共搬对象 Δx_i=Δx_j=Δx，由 F_i+F_j=G 得 (K_i+K_j)Δx=G，即等效刚度 K_eff = K_i+K_j。
- **联合安全集**：K_joint = {K | ∀i: K_i∈K_safe_i^scene ∧ ∀i<j: C_ij(K_i,K_j) ≤ c_ij^max ∧ Feasible(F_i+F_j=G)}。
- **JSIC 判定**：JSIC_valid ⇔ K_joint ≠ ∅ ∧ (∀i: scene_conf_i ≥ τ_scene) ∧ (∀i<j: d_ij ≥ d_safe)。
- **联合置信度**：γ_joint = (min_i γ_i)·exp(−max_{i<j} C_ij/c_ij^max)。

**定义 162（接触感知碰撞避免 CACA）** 对机对 (i,j)：
- 有符号距离 d_ij(x)，硬安全距离 d_safe，允许接触距离 d_contact_min < d_safe，接触流形 M_contact ⊂ ∂R_i × ∂R_j。
- **接触意图证书** φ_contact(i,j,t) = 1[ K_i^intent 匹配 M_contact 法向 ∧ EV-exec 在窗内 ∧ JSIC_valid ∧ u_i·n_ij ≥ cos θ_cone ]，n_ij 为 j→i 单位法向，u_i 为接近方向，θ_cone 为接触锥半角。
- **意图条件化屏障**：h_ij^CACA(x,t) = d_ij(x) − d_safe + (d_safe − d_contact_min)·φ_contact(i,j,t)。
- **安全不变性约束（CBF）**：ḣ_ij^CACA + α(h_ij^CACA) ≥ 0，α 为 class-K 函数；仅在 φ_contact=1 时屏障松弛，否则退化为硬约束 d_ij ≥ d_safe。

**定义 163（向量时钟分布式执行证书 DVEC）** 每机维护 V_i∈N^M：
- 本地事件：V_i[i]+=1，附 V(e)=V_i；接收消息 m：V_i ← max(V_i,V(m))，再 V_i[i]+=1。
- **因果序**：m→m' ⇔ V(m) ≤ V(m') 且 V(m)≠V(m')；否则并发（incomparable）。
- **一致切**：事件集 C 满足 e'∈C ∧ e→e' ⇒ e∈C；等价于边界向量 F∈N^M，各机只贡献 V[i]≤F[i] 的段。
- **联合证书**：J_exec^multi=(seg_1,...,seg_M,F,{hash_i})，有效 ⇔ ∀i 哈希链验证通过 ∧ 所有 seg_i 落在同一一致切 F 内。
- **并发冲突**：若两机并发事件声明同一资源，按确定性优先级 π=min(H(id_i‖id_j)) 裁决，否则标记 CONFLICT 触发重规划。

**定义 164（互惠约束协同 RCC）** 协商机制 (J_i, λ, ρ)：
- 目标：min Σ_i J_i(K_i,K_{−i}) s.t. ∀i<j C_ij(K_i,K_j) ≤ c_ij^max。
- **对偶分解**：各机 min_{K_i} J_i + Σ_j λ_ij C_ij；价格更新 λ_ij ← max(0, λ_ij + η(C_ij − c_ij^max))。
- **右行权**：ρ(i,j)=argmax_{k∈{i,j}} (p_k + u_k)，p 为任务优先级、u 为紧迫度；平局用 H(id_i‖id_j) 的奇偶做严格全序。
- **让行**：若 ρ(j,i)=j，则 i 的 d_safe^i ← d_safe^i + κ_yield。
- 严格全序保证无死锁；对偶收敛给出 K_joint 的可行点。

**定义 165（多机预算 PCE+++++）** B_multi=(B_comm,B_coord,B_safety,B_scene,B_intent,B_ros,B_exec)：
- B_comm=(msg_rate,bw,latency)，B_coord=(negotiation_rounds,coupling_compute)，B_safety=(margin_budget,false_stop_budget)。
- **通信-安全守恒**：δ_safe = g(max(0, B_comm^req − B_comm))，B_comm 越紧，d_safe^eff = d_safe + δ_safe 越大。
- VOI：voi_multi(π)=VOI_meta_pess − cost_cog − cost_exec − cost_comm − cost_coord − cost_safety。
- 降级：B_comm 耗尽⇒LSF；B_coord 耗尽⇒固定右行；B_safety 耗尽⇒全局保守减速。

**定义 166（多机认证闭环 MACL）** 算子 MACL(M, A, intents, δ_f^req)：
```
① SSM_i: 各机场景更新 → z_i
② CIEC_joint: 联合意图对齐，冲突按 π 裁决
③ RCC: 协商 K_joint（对偶分解）
④ JSIC: 校验 K_joint ≠ ∅ 且 d_ij ≥ d_safe
⑤ CACA: 按 φ_contact 施加意图条件化屏障
⑥ Execute: 接触式执行，生成 EV-exec_i
⑦ DVEC: 一致切快照 → J_exec^multi
⑧ 更新联合信念 γ_joint；Return (K_joint, J_exec^multi, CSD)
```

**定义 167（接触-安全判别器 CSD）** 判别函数 g_csd:(d_ij, f_contact, φ_contact, EV-exec) → {INTENDED, COLLISION, UNCERTAIN}：
- INTENDED ⇔ φ_contact=1 ∧ f∈[0,F_tol] ∧ 接触点在 M_contact 内 ∧ 力-位移刚度与 K_i 一致。
- COLLISION ⇔ f>F_max ∨ 接触点在接触锥外 ∨ φ_contact=0。
- 其余为 UNCERTAIN ⇒ 保守急停 + 人工确认；要求 P(误判 COLLISION|INTENDED) ≤ ε_fs。

**定义 168（局部安全回退 LSF）** 通信中断或 B_comm 耗尽时：
- 各机以最后已知状态与加速度界 a_max 计算邻居**前向可达集** R_j(t+Δ)。
- 局部屏障 h_ij^LSF = dist(x_i, R_j) − d_safe^LSF，d_safe^LSF ≥ d_safe。
- 保证：若所有机执行 LSF，则 ∀t 无碰撞，与协同是否收敛无关。

### IP-161 JSIC（联合阻抗可行域）

```python
class JointSceneImpedanceCertainty:
    def __init__(self, agents, coupling):
        self.A = agents
        self.C = coupling
        self.c_max = coupling.c_max

    def joint_feasible(self, K_agent, scenes, poses):
        for i in self.A:
            if not self._sic_valid(i, K_agent[i], scenes[i]):
                return False, None
        for i in self.A:
            for j in self.A:
                if i < j and self.C[i][j](K_agent[i], K_agent[j]) > self.c_max[i][j]:
                    return False, None
        K_joint = self._project(self._scene_box(scenes), K_agent)
        if K_joint is None:
            return False, None
        worst = max(self.C[i][j](K_agent[i], K_agent[j]) / self.c_max[i][j]
                    for i in self.A for j in self.A if i < j)
        gamma = min(self._gamma[i] for i in self.A) * np.exp(-worst)
        return True, (K_joint, gamma)
```

### IP-162 CACA（接触感知避障）

```python
class ContactAwareCollisionAvoidance:
    def __init__(self, d_safe, d_contact_min, cone_deg=20):
        self.d_safe = d_safe
        self.d_contact_min = d_contact_min
        self.cos_cone = np.cos(np.deg2rad(cone_deg))

    def barrier(self, i, j, x_i, x_j, u_i, n_ij, ev_exec, jsic_valid):
        d = signed_distance(x_i, x_j)
        phi = (jsic_valid
               and contact_certificate(i, j, ev_exec)
               and float(np.dot(u_i, n_ij)) >= self.cos_cone)
        h = d - self.d_safe + (self.d_safe - self.d_contact_min) * float(phi)
        return h, phi

    def safe_control(self, u_nom, barriers, alpha):
        return solve_qp_barrier(u_nom, barriers, alpha)
```

### IP-163 DVEC（向量时钟分布式证书）

class VectorClock:
    def __init__(self, m, idx):
        self.V = np.zeros(m, dtype=int)
        self.idx = idx

    def tick(self):
        self.V[self.idx] += 1
        return self.V.copy()

    def recv(self, Vm):
        self.V = np.maximum(self.V, Vm)
        self.V[self.idx] += 1

def causal(Va, Vb):
    return bool(np.all(Va <= Vb) and np.any(Va < Vb))

class DistributedSnapshot:
    def __init__(self, agents, channels):
        self.A, self.ch = agents, channels

    def snapshot(self, trigger):
        for c in self.ch:
            c.send_marker()
        segs = {i: self.A[i].ev_exec_since_last_marker() for i in self.A}
        F = np.max([s.frontier for s in segs.values()], axis=0)
        return self._consistent_cut(segs, F)

    def joint_certificate(self, segs, F):
        for seg in segs.values():
            if not verify_hash_chain(seg) or not all(seg.frontier <= F):
                return None
        return JExecMulti(segs, F, [s.head_hash for s in segs.values()])

### IP-164 RCC（互惠约束协同）

```python
class ReciprocalConstraintCoordination:
    def __init__(self, agents, coupling, eta=0.1, rounds=20):
        self.A, self.C = agents, coupling
        self.eta, self.rounds = eta, rounds
        self.lam = {(i, j): 0.0 for i in agents for j in agents if i < j}

    def negotiate(self, K_init):
        K = K_init.copy()
        for _ in range(self.rounds):
            for i in self.A:
                K[i] = self.A[i].best_response(K, self.lam)
            for (i, j), l in self.lam.items():
                viol = self.C[i][j](K[i], K[j]) - self.c_max[i][j]
                self.lam[(i, j)] = max(0.0, l + self.eta * viol)
            if self._converged(K):
                break
        return K, self.lam

    def right_of_way(self, i, j, p, u):
        si, sj = p[i] + u[i], p[j] + u[j]
        if si != sj:
            return i if si > sj else j
        return i if hash((min(i, j), max(i, j))) % 2 == 0 else j
```

### IP-166 MACL（多机认证闭环）

```python
def multi_agent_certified_loop(M, A, intents, delta_f_req):
    scenes = [M[i].scene_model.update(M[i].telem) for i in A]
    intents = resolve_joint_intents(intents, A, priority=M.priority)
    K_joint, lam = M.rcc.negotiate([M[i].K_safe for i in A])
    ok, res = M.jsic.joint_feasible(K_joint, scenes, M.poses)
    if not ok:
        K_joint, gamma = M.jsic.conservative_fallback(scenes), 0.0
    else:
        K_joint, gamma = res

    if M.budget.comm_exhausted():
        return M.lsf.local_loop(A, K_joint)

    for i in A:
        M[i].caca.enforce(K_joint[i], M[i].ev_exec)

    EV = {i: M[i].execute(K_joint[i], delta_f_req) for i in A}
    segs, F = M.dvec.snapshot(trigger=A)
    J_multi = M.dvec.joint_certificate(segs, F)
    M.gamma_joint = gamma * np.exp(-M.csd.conflict_rate())
    return M, K_joint, J_multi, M.gamma_joint
```

### IP-167 CSD（接触-安全判别）

```python
class ContactSafetyDiscriminator:
    def __init__(self, F_max, F_tol, eps_fs=0.01):
        self.F_max, self.F_tol, self.eps_fs = F_max, F_tol, eps_fs

    def classify(self, d_ij, f, phi_contact, in_manifold, ev_exec):
        if f > self.F_max or not in_manifold or not phi_contact:
            return "COLLISION"
        if phi_contact and 0 <= f <= self.F_tol and self._stiffness_consistent(ev_exec):
            return "INTENDED"
        return "UNCERTAIN"
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| JSIC | O(M²d) / 周期 | O(Md) | 联合可行率 ≥ 95%，耦合过载率下降 ≥ 70% |
| CACA | O(M²) 屏障 + QP | O(M²) | 意图内接触放行率 ≥ 98%，非意图碰撞 = 0（仿真） |
| DVEC | O(M) 消息开销 / 事件 | O(M·窗口) | 一致切完整性 ≥ 99.9% |
| RCC | O(R·M²d) | O(M²) | 收敛轮数 ≤ 10，死锁率 = 0 |
| CSD | O(1) / 接触事件 | O(1) | P(误判 COLLISION) ≤ ε_fs |
| LSF | O(M) 可达集 | O(M) | 通信中断下 ∀t 无碰撞 |

**正确性定理（MACL）**：
假设 A66–A70 成立；**(A66)** 耦合算子 C_ij 满足 Lipschitz 且对偶问题严格凸，RCC 收敛到 K_joint 的可行点。**(A67)** 接触意图证书 φ_contact 是可靠的：M_contact 与法向匹配可验证，故 h^CACA 是增广安全集的合法 CBF。**(A68)** DVEC 快照产生因果一致切，哈希链抗碰撞。**(A69)** CSD 误判上界 P(COLLISION|INTENDED) ≤ ε_fs。**(A70)** LSF 前向可达集是邻居真实可达集的过近似。

则：
1. **联合可行性**：JSIC_valid ⇒ K_joint 执行不产生耦合过载（F_i+F_j=G 恒满足）。
2. **接触感知安全**：φ_contact=1 的正常接触不被拦截；φ_contact=0 时 CBF 不变性保证 d_ij ≥ d_safe。
3. **证据可审计**：J_exec^multi 在一致切上验证，跨机因果序保持、并发冲突不误判为因果。
4. **优雅降级**：B_comm 耗尽时 LSF 与协同是否收敛无关地保证无碰撞。
5. **假阳性界**：全局急停率 ≤ ε_fs。

## 5. 本轮最大风险

**一句话**：CACA 的「松弛屏障」与 CSD 的「判为意图接触」依赖**同一个**接触意图证书 φ_contact，一旦该证书被误估或伪造，两层彼此独立的防线会因共享同一信任根而**相关失效**——屏障被放宽的同时判别器又放行，真实的破坏性碰撞得以穿过；必须以「力-位移刚度独立校验 + 不可松弛的硬屏障兜底 + 人工否决通道」三重冗余，确保接触证书永不成为单点失效。

> 承接第 60 轮 IP-153~160（场景感知闭环 SGEC：SSM×CIEC×EPIR×SERC×PCE++++）。本轮把「单机场景-执行闭环」升级为 **「多机认证协同闭环」**：联合场景-阻抗-置信度 JSIC 让多机的安全从「独立安全集之积」变为「带耦合约束的联合可行域」；接触感知碰撞避免 CACA 用意图证书把「该碰的碰」与「不该碰的碰撞」区分开，避免假阳性急停；向量时钟分布式证书 DVEC 在无全局时钟的 ROS2/DDS 下用因果一致切重建联合证据；互惠约束协同 RCC 用对偶分解达成无死锁的联合阻抗协商；PCE+++++ 扩展通信/协商/安全裕度预算。实现 **「联合可行、认得出该碰的碰、证据因果可审计、断联可安全回退」**。

## 2. 关键算法伪代码

### IP-161 JSIC（联合阻抗可行域）

```python
class JointSceneImpedanceCertainty:
    def __init__(self, agents, coupling):
        self.A = agents
        self.C = coupling
        self.c_max = coupling.c_max

    def joint_feasible(self, K_agent, scenes, poses):
        for i in self.A:
            if not self._sic_valid(i, K_agent[i], scenes[i]):
                return False, None
        for i in self.A:
            for j in self.A:
                if i < j and self.C[i][j](K_agent[i], K_agent[j]) > self.c_max[i][j]:
                    return False, None
        K_joint = self._project(self._scene_box(scenes), K_agent)
        if K_joint is None:
            return False, None
        worst = max(self.C[i][j](K_agent[i], K_agent[j]) / self.c_max[i][j]
                    for i in self.A for j in self.A if i < j)
        gamma = min(self._gamma[i] for i in self.A) * np.exp(-worst)
        return True, (K_joint, gamma)
```

### IP-162 CACA（接触感知避障）

```python
class ContactAwareCollisionAvoidance:
    def __init__(self, d_safe, d_contact_min, cone_deg=20):
        self.d_safe = d_safe
        self.d_contact_min = d_contact_min
        self.cos_cone = np.cos(np.deg2rad(cone_deg))

    def barrier(self, i, j, x_i, x_j, u_i, n_ij, ev_exec, jsic_valid):
        d = signed_distance(x_i, x_j)
        phi = (jsic_valid
               and contact_certificate(i, j, ev_exec)
               and float(np.dot(u_i, n_ij)) >= self.cos_cone)
        h = d - self.d_safe + (self.d_safe - self.d_contact_min) * float(phi)
        return h, phi

    def safe_control(self, u_nom, barriers, alpha):
        return solve_qp_barrier(u_nom, barriers, alpha)
```

### IP-163 DVEC（向量时钟分布式证书）

```python
class VectorClock:
    def __init__(self, m, idx):
        self.V = np.zeros(m, dtype=int)
        self.idx = idx

    def tick(self):
        self.V[self.idx] += 1
        return self.V.copy()

    def recv(self, Vm):
        self.V = np.maximum(self.V, Vm)
        self.V[self.idx] += 1

def causal(Va, Vb):
    return bool(np.all(Va <= Vb) and np.any(Va < Vb))

class DistributedSnapshot:
    def __init__(self, agents, channels):
        self.A, self.ch = agents, channels

    def snapshot(self, trigger):
        for c in self.ch:
            c.send_marker()
        segs = {i: self.A[i].ev_exec_since_last_marker() for i in self.A}
        F = np.max([s.frontier for s in segs.values()], axis=0)
        return self._consistent_cut(segs, F)

    def joint_certificate(self, segs, F):
        for seg in segs.values():
            if not verify_hash_chain(seg) or not all(seg.frontier <= F):
                return None
        return JExecMulti(segs, F, [s.head_hash for s in segs.values()])
```

### IP-164 RCC（互惠约束协同）

```python
class ReciprocalConstraintCoordination:
    def __init__(self, agents, coupling, eta=0.1, rounds=20):
        self.A, self.C = agents, coupling
        self.eta, self.rounds = eta, rounds
        self.lam = {(i, j): 0.0 for i in agents for j in agents if i < j}

    def negotiate(self, K_init):
        K = K_init.copy()
        for _ in range(self.rounds):
            for i in self.A:
                K[i] = self.A[i].best_response(K, self.lam)
            for (i, j), l in self.lam.items():
                viol = self.C[i][j](K[i], K[j]) - self.c_max[i][j]
                self.lam[(i, j)] = max(0.0, l + self.eta * viol)
            if self._converged(K):
                break
        return K, self.lam

    def right_of_way(self, i, j, p, u):
        si, sj = p[i] + u[i], p[j] + u[j]
        if si != sj:
            return i if si > sj else j
        return i if hash((min(i, j), max(i, j))) % 2 == 0 else j
```

### IP-166 MACL（多机认证闭环）

```python
def multi_agent_certified_loop(M, A, intents, delta_f_req):
    scenes = [M[i].scene_model.update(M[i].telem) for i in A]
    intents = resolve_joint_intents(intents, A, priority=M.priority)
    K_joint, lam = M.rcc.negotiate([M[i].K_safe for i in A])
    ok, res = M.jsic.joint_feasible(K_joint, scenes, M.poses)
    if not ok:
        K_joint, gamma = M.jsic.conservative_fallback(scenes), 0.0
    else:
        K_joint, gamma = res

    if M.budget.comm_exhausted():
        return M.lsf.local_loop(A, K_joint)

    for i in A:
        M[i].caca.enforce(K_joint[i], M[i].ev_exec)

    EV = {i: M[i].execute(K_joint[i], delta_f_req) for i in A}
    segs, F = M.dvec.snapshot(trigger=A)
    J_multi = M.dvec.joint_certificate(segs, F)
    M.gamma_joint = gamma * np.exp(-M.csd.conflict_rate())
    return M, K_joint, J_multi, M.gamma_joint
```

### IP-167 CSD（接触-安全判别）

```python
class ContactSafetyDiscriminator:
    def __init__(self, F_max, F_tol, eps_fs=0.01):
        self.F_max, self.F_tol, self.eps_fs = F_max, F_tol, eps_fs

    def classify(self, d_ij, f, phi_contact, in_manifold, ev_exec):
        if f > self.F_max or not in_manifold or not phi_contact:
            return "COLLISION"
        if phi_contact and 0 <= f <= self.F_tol and self._stiffness_consistent(ev_exec):
            return "INTENDED"
        return "UNCERTAIN"
```

### IP-168 LSF（局部安全回退）

```python
class LocalSafetyFallback:
    def __init__(self, a_max, d_safe_lsf, horizon=0.5):
        self.a_max, self.d_safe_lsf, self.horizon = a_max, d_safe_lsf, horizon

    def reachable_set(self, x_j, v_j):
        R = x_j + v_j * self.horizon + 0.5 * self.a_max * self.horizon ** 2
        return R

    def local_barrier(self, x_i, neighbors):
        return min(dist(x_i, self.reachable_set(n.x, n.v)) for n in neighbors) - self.d_safe_lsf

    def local_loop(self, A, K_joint):
        for i in A:
            A[i].caca.d_safe = self.d_safe_lsf
            A[i].execute(K_joint[i], local_only=True)
        return A, K_joint, None, 0.0
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| JSIC | O(M²d) / 周期 | O(Md) | 联合可行率 ≥ 95%，耦合过载率 ↓≥70% |
| CACA | O(M²) 屏障 + QP | O(M²) | 意图内接触放行 ≥ 98%，非意图碰撞 = 0（仿真） |
| DVEC | O(M) / 事件；快照 O(M·|seg|) | O(M·窗口) | 一致切完整性 ≥ 99.9% |
| RCC | O(R·M²d) | O(M²) | 收敛 ≤ 10 轮，死锁 = 0 |
| CSD | O(1) / 接触事件 | O(1) | P(误判 COLLISION|INTENDED) ≤ ε_fs |
| LSF | O(M) / 周期 | O(M) | 断联下 ∀t 无碰撞 |

**正确性定理（MACL）**：
若 A66–A70 成立（A66 RCC 对偶收敛；A67 φ_contact 可靠 ⇒ h^CACA 为合法 CBF；A68 DVEC 一致切+抗碰撞哈希；A69 CSD 误判界 ε_fs；A70 LSF 可达集过近似），则：
1. **联合可行性**：JSIC_valid ⇒ K_joint 执行满足 F_i+F_j=G，无耦合过载。
2. **接触感知安全**：φ_contact=1 的正常接触被放行；φ_contact=0 时 CBF 不变性保证 d_ij ≥ d_safe。
3. **证据可审计**：J_exec^multi 在一致切 F 上验证，跨机因果序保持、并发不被误判为因果。
4. **优雅降级**：B_comm 耗尽时 LSF 与协同是否收敛无关地保证无碰撞。
5. **假阳性界**：全局假阳性急停率 ≤ ε_fs。

## 5. 本轮最大风险

**一句话**：CACA 的「松弛屏障」与 CSD 的「判为意图接触」依赖**同一个**接触意图证书 φ_contact，一旦该证书被误估或伪造，两层彼此独立的防线会因共享同一信任根而**相关失效**——屏障被放宽的同时判别器又放行，真实的破坏性碰撞得以穿过；必须以「力-位移刚度独立校验 + 不可松弛的硬屏障兜底 + 人工否决通道」三重冗余，确保接触证书永不成为单点失效。
