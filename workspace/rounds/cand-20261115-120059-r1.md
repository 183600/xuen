# 第 1 轮（新灵感循环；基线：第 5 轮 InstructGauge-RTDI v5）

> **基线**：第 5 轮 InstructGauge-RTDI（IP-334–339；定义 468–492；引理 63–68；实验 E473–E492）。此前 WR / InstructGauge v3 / ToolGauge / LeanGauge / MODGAUGE 全部继承。
> 本轮灵感：「可扩展性」×「机器人」。
> 本轮纪律：**从“单机安全”升级为“群体可扩展安全”，但任何新增组件都必须可退化为单机 RTDI**。这里的“可扩展”不是把系统做大，而是回答：在什么结构条件下，验证与协调成本可以随规模线性/亚线性增长；超过该条件，系统必须显式降级，而不是假装仍然可扩展。

## 0. 直觉与动机

### 灵感 1：可扩展性不是“更大的中央大脑”，而是“更小的耦合面”

直觉：单机 RTDI 的证书是“一个机器人、一段时间、一个空间管”的原子证明。把 N 个机器人放在一起，最自然的做法是中央规划器统一验证所有机器人的所有动作；但这会同时产生三笔坏账：

- **计算**：碰撞/证书检查是全对的 `O(N²)`；
- **通信**：每个机器人都要把完整状态送到中心，带宽 `O(N)`；
- **失效**：中心一挂，全队失明。

真正的可扩展性来自**局部性**：如果机器人只在空间上邻近时才相互影响，那么只要维持交互图稀疏，每个机器人就只需要和常数个邻居交换**有界大小的证书**，验证成本由“N”变成“每个机器人的局部交互度”。

严谨地说，可扩展性有三维：

1. **N 维（机队规模）**：验证/通信成本对 N 的增长阶；
2. **|M| 维（地图/场景规模）**：空间证书更新的增量成本，理想为 `O(log |M|)`；
3. **|Π| 维（技能库规模）**：新增原语时，是否需要回归验证所有旧任务。

单机方案在这三维上都是“全量重算”，所以机队一扩大就退化。本轮要把证书变成**可组合的一等对象**，让规模只进入证书的“索引/聚合”层，而不进入每个机器人的执行层。

### 灵感 2：机器人 = 带连续动力学、间歇通信、时钟偏差的分布式系统

直觉：传统分布式系统可以假设消息最终到达、状态可重放；机器人不行。邻居的位姿在 100ms 后已经过期，而“过期”在物理上意味着**不确定性膨胀**。因此，可扩展安全不能只检查“当前证书是否冲突”，还必须检查“在证书陈旧窗口内，真实占用是否仍不冲突”。

这给出本轮的核心安全条件：**用可达集膨胀把时间不确定性换成空间保守性**。证书带有效期 `H`；在 `δ ≤ H` 内使用邻居证书时，把它的占用管按 `v_max δ + ½ a_max δ²` 膨胀；膨胀后仍不相交才允许并行。超过 `H` 就停止/重规划，而不是“相信最后一次消息”。

### 灵感 3：耦合——可扩展性的单位必须是“证书”，不是“机器人”

直觉：如果以机器人为单位扩展，N 个机器人就是 N 份完整的 RTDI 栈，协调层还要做 N² 次两两检查；这是把单机复杂度乘了 N²。以**证书**为单位则不同：证书有区域、有有效期、有前后条件，可以像 separation logic 的资源一样并行组合（不相交资源）或顺序组合（后条件蕴含前条件）。规模扩大时，我们扩的是证书的数量和空间索引，而不是每个证书的验证逻辑。

但证书代数有一个硬边界：并行组合只在**占用不相交**时可交换；一旦资源重叠，就退化为顺序/优先级，不能再并行。这直接推出本轮的“可扩展包线”：**可扩展性等价于维持交互图的稀疏性**；密度超过阈值时，任何成对证书方法都不可避免地趋向 `O(N²)`，此时正确做法是显式降级（预留/优先级/减速/停），而不是宣称仍然可扩展。

## 1. 研究问题

- **Q1（组合安全）**：能否把单机 CVC/SpatialCert 提升为一个可靠的证书代数，使 `c₁ ⊗ c₂` 的局部证明足以推出全局安全？
- **Q2（规模阶）**：在交互图稀疏度 `λ` 下，验证与通信成本对 `N`、`|M|`、`|Π|` 的真实增长阶是什么？下界在哪里？
- **Q3（异构校准）**：跨机器人共享校准数据会破坏可交换性，如何在不牺牲覆盖率的条件下获得规模收益？
- **Q4（退化）**：当通信、地图、时钟、证书任一失效时，系统如何逐级退回单机 RTDI 而不产生“伪安全”？

## 2. 设计原则（雏形，正式化见产物区定义 493–504）

**P1 局部优先（Local-first）**
全局安全主张 = 局部证书的合取 + 邻接兼容性证明；不存在全局锁，也不存在必须串行化的全局验证步骤。

**P2 证书代数（Certificate Algebra）**
并行 `⊗`（不相交资源，可交换）与顺序 `;`（后条件⇒前条件，可结合）两种组合子；组合保持可靠性。并行失败时不是“报错”，而是转为顺序/优先级。

**P3 有界陈旧（Bounded Staleness）**
证书带有效期；陈旧窗口内用可达集膨胀，膨胀后不相交才并行；超过有效期就停止/重规划。

**P4 空间摘要（Spatial Digest）**
八叉树 + Merkle 哈希做区域索引与增量失效，更新 `O(log |M|)`；摘要证明完整性，不证明安全性，安全性仍由证书语义负责。

**P5 异构分层校准（Group Conformal）**
按机器人类型/指令层分组校准，样本不足回退全局阈值；明确“共享数据”与“覆盖率”的交换。

**P6 显式退化（Graceful Degradation）**
`N=1`、无共享地图、无通信、无校准样本分别有明确的退化路径，且退化链可逐级验证。

## 3. 与基线的接口（如何退化）

- `N=1` ⇒ 证书代数退化为单证书，等价 RTDI；
- 无证书交换 ⇒ 各机器人独立 RTDI + 局部急停；
- 无共享空间摘要 ⇒ 用本体感知局部证书，等价单机 SpatialCert；
- 无通信/超时 ⇒ 只信自己证书，邻居按“最大膨胀”视为移动障碍物；
- 分组校准样本不足 ⇒ 回退全局共形阈值（v3 行为）；
- 任一增强抛异常 ⇒ 关闭该增强，保留 RTDI。

## 4. 预期贡献

1. 一个可组合的时空证书代数，把“全局安全”降为“局部证明 + 邻接兼容”；
2. 一个带增量空间摘要与有界陈旧膨胀的群体执行器，给出 `O(N log N + K)` 的验证上界与 `Ω(N²)` 的稠密下界；
3. 一个异构分组共形校准口径，量化“共享数据”与“覆盖率”的交换；
4. 一条可证伪的规模包线：用交互图渗流阈值预测性能拐点，E493–E512 覆盖规模、密度、陈旧、异构、故障与退化。

## 5. 本轮最大风险

**一句话**：本方案把可扩展性押在“交互图稀疏 + 证书及时”上；一旦密度或通信延迟越过渗流/陈旧阈值，局部证书可以各自可靠却共同导致**活锁或容量坍塌**——系统看起来仍然“安全”（没撞），但已经不再“可扩展”（走不动），而这类失败比碰撞更难被现有安全指标发现。

## 2. 形式化定义（要点）

**定义 493（机队任务与能力剖面 FleetTaskModel）**
机器人 `r` 的能力剖面与任务定义为：
```
κ_r = (T_r, m_r, ρ_r, S_r, WCET_r),   T_r ⊆ T₀
τ   = (γ_τ, ψ_τ, D_τ, req_τ, F_τ)
Admissible(r, τ) ⇔ req_τ ⊆ κ_r ∧ u(κ_r, τ) ≤ D_τ − t_now
A: Task ⇀ Robot,   |A⁻¹(r)| ≤ cap_r,   ∀τ: Admissible(A(τ), τ)
```
其中 `u` 为任务在机器人上的最坏执行时间估计。能力剖面是**类型层**约束：分配只改变“谁做”，不改变“能做什么”。

**定义 494（时空证书 SpatialCert）**
证书是带时空区域与有效期的一等证明对象：
```
c = (id, r, R_c, O_c, pre_c, post_c, H_c, h_c, dep_c)
R_c = R_c^space × [t_c^0, t_c^1]
O_c: [t_c^0, t_c^1] → 2^{R³}
h_c = H(id, r, R_c, O_c, pre_c, post_c, H_c, dep_c)
```
可靠性：`Sound(c, x_r)` 当且仅当
```
∀t ∈ [t_c^0, t_c^1]: x_r(t) ∈ O_c(t)
∧ pre_c 在 t_c^0 成立
∧ post_c 在 t_c^1 成立
∧ ∀d ∈ dep_c: Sound(d, x_{robot(d)})
```
证书不是“日志”，而是**可被独立检查的局部定理**。

**定义 495（证书代数 CertAlgebra）**
并行组合与顺序组合：
```
c₁ ⊗ c₂ 有定义 ⇔ [t₁⁰,t₁¹] ∩ [t₂⁰,t₂¹] ≠ ∅
             ∧ ∀t ∈ 交集: O₁(t) ∩ O₂(t) = ∅
c₁ ⊗ c₂ = (新id, {r₁,r₂}, R₁∪R₂, O₁∪O₂,
           pre₁∧pre₂, post₁∧post₂,
           min(H₁,H₂), H(h₁,h₂), dep₁∪dep₂)

c₁ ; c₂ 有定义 ⇔ t₁¹ ≤ t₂⁰ ∧ (post₁ ⇒ pre₂)
c₁ ; c₂ = (新id, {r₁,r₂}, R₁∪R₂,
           O₁ 在 [t₁⁰,t₁¹] 上取 O₁、在 (t₁¹,t₂¹] 上取 O₂,
           pre₁, post₂, min(H₁,H₂), H(h₁,h₂), dep₁∪dep₂)
```
并行单位元 `ε=(∅,∅,true,true,∞)`；并行在兼容集合上构成**部分交换幺半群**（交换性要求无优先级/无时序依赖），顺序构成**范畴**（结合、有单位）。资源不相交是交换性的物理前提，不是实现细节。

**定义 496（空间摘要 SpatialDigest）**
```
D_M = (V_octree, E_child, h_node, leaves)
h_node = H(h_left, h_right, bbox(node))
update(D_M, c): 插入叶节点并按路径重算哈希   → O(log |M|)
query(D_M, R): 返回与 R 相交的叶证书集合     → O(log |M| + k)
```
摘要提供**完整性**（证书未被篡改、区域索引一致），不提供**安全性**；安全性由定义 494/495 的语义承担。二者必须分离，否则会把“哈希一致”误当成“物理安全”。

**定义 497（有界陈旧 StaleGuard）**
设证书在 `t_r` 生成，当前 `t`，陈旧量 `δ = t − t_r`。定义可达集半径与可用性：
```
ρ(δ) = e_state + v_max·δ + ½·a_max·δ²
inflate(O, ρ)(t) = O(t) ⊕ Ball(ρ)            // Minkowski 和
Usable(c, δ) ⇔ δ ≤ H_c
SafePair(c_i, c_j, δ_i, δ_j) ⇔
    inflate(O_i, ρ(δ_i)) ∩ inflate(O_j, ρ(δ_j)) = ∅
    ∨ priority(i, j)                           // 低优先级让行
```
若 `¬Usable` 或 `¬SafePair`，低优先级机器人必须重规划/减速/停，而不是继续消费过期证书。注意膨胀必须**双方都做**：碰撞是两个位置不确定性的叠加。

**定义 498（分组共形校准 FleetConformal）**
分组 `g = (robot_type, instruction_stratum)`。对组 `g` 的非一致性分数 `S_g`，用加权分位数：
```
w_i = 1/n_g (i ∈ g),   w_0 = β (pooled prior)
q_g = WeightedQuantile_{1−α}(S_g ∪ S_pool, w)
C_g(x) = {y : s(x,y) ≤ q_g}
```
覆盖语义：
- 若 `n_g ≥ n_min` 且组内可交换，则 `P(Y ∈ C_g) ≥ 1−α`；
- 若样本不足回退池化，则保守界为 `P(Y ∈ C_g) ≥ 1−α−TV(P_g, P_pool)`，并显式记录回退事件。
这把“跨机器人共享数据”从无条件假设改成**可量化的分布偏移代价**。

**定义 499（证书 DAG 与机队安全账本 CertLedger）**
```
Ledger = (Certs, ComposeEdges, root_hash)
commit(c): 更新从叶到根的 Merkle 路径   → O(log N)
verify(c): 检查 c 到根的路径与依赖闭包   → O(log N + |dep_c|)
Φ_fleet = ⋀_{r∈R} Φ_r ∧ ⋀_{(i,j)∈E_int} Compat(c_i, c_j)
```
全局主张不是一个巨型证明，而是“局部证书 + 邻接兼容边”的合取；任意审计者可只下载相关路径验证，不必重放全队。

**定义 500（规模包线与渗流阈值 ScaleEnvelope）**
```
χ = N·A_robot / A_arena
ρ = 2(r_occ + v_max·H)
λ = N·πρ² / A_arena
G_int = (R, {{i,j} : inflate(O_i, ρ) ∩ inflate(O_j, ρ) ≠ ∅})
```
定义可扩展包线 `S = {χ ≤ χ_c}`，其中 `χ_c` 由交互图的渗流阈值 `λ_c` 标定（随机几何图近似下 `λ_c ≈ 1`，实际由实验 E494 校准）。`χ ≤ χ_c` 时 `K = O(N)`；`χ > χ_c` 时 `K` 趋向 `O(N²)`，成对证书方法失效。

**定义 501（类型化分布式分配 TypedMarketAlloc）**
```
bid_i(τ) = utility(τ) − cost_i(τ)
cost_i(τ) = α·WCET_i(τ) + β·travel_i(τ) + γ·capability_mismatch(i,τ)
```
CBBA/拍卖迭代至收敛；收敛轮数不超过通信图直径 `diam(G_comm)`。分配结果必须通过定义 493 的 `Admissible` 检查；不通过则任务退回未分配池，由局部重规划处理。

**定义 502（退化格 DegradationLattice）**
```
L4: 全空间摘要 + 证书 DAG（连通、低延迟）
L3: 配对陈旧证书（通信间歇、无共享地图）
L2: 仅本地证书（无邻居证书）
L1: 独立 RTDI（N=1 或全队失联）
L0: 安全停（证书过期且无法重规划）
```
切换谓词：`comm_timeout ⇒ L3`，`digest_unavailable ⇒ L2`，`N=1 ∨ no_peer ⇒ L1`，`¬Usable ∧ ¬can_replan ⇒ L0`。降级只允许逐级向下，恢复需连续 `k` 个周期验证，避免抖动。

**定义 503（机队安全主张 FleetSafetyClaim）**
```
Φ_fleet(t) = ⋀_{r∈R} Sound(c_r(t), x_r) ∧ ⋀_{(i,j)∈E_int} SafePair(c_i,c_j,δ_i,δ_j)
```
该主张是**时变的**：每个控制周期重新求值；证书提交只是把已验证的局部主张固化到账本，不改变其语义。

**定义 504（异构指数 HeterogeneityIndex）**
```
H = 1 − (2/(N(N−1))) · Σ_{i<j} |T_i ∩ T_j| / |T_i ∪ T_j|
```
`H=0` 表示能力完全同构；`H→1` 表示能力几乎不相交。异构指数进入引理 73 的规模律：共享原语越少，迁移先验越弱，成功率的规模斜率越差。

# IP-341 证书代数：并行/顺序组合
class Certificate:
    def __init__(self, cid, robot, region, occupancy, pre, post,
                 horizon, deps):
        self.id, self.robot = cid, robot
        self.region, self.occupancy = region, occupancy
        self.pre, self.post = pre, post
        self.horizon, self.deps = horizon, deps
        self.hash = self._digest()

    def _digest(self):
        return H(self.id, self.robot, self.region, self.occupancy,
                 self.pre, self.post, self.horizon, self.deps)

class CertAlgebra:
    def parallel(self, c1, c2):
        overlap = c1.region.time.intersect(c2.region.time)
        if overlap.is_empty():
            raise Incompatible("no time overlap")
        for t in overlap.samples():
            if c1.occupancy.at(t).intersects(c2.occupancy.at(t)):
                raise Incompatible("occupancy overlap", pair=(c1.id, c2.id))
        return Certificate(
            cid=new_id(), robot={c1.robot, c2.robot},
            region=c1.region.union(c2.region),
            occupancy=UnionOccupancy(c1.occupancy, c2.occupancy),
            pre=c1.pre & c2.pre, post=c1.post & c2.post,
            horizon=min(c1.horizon, c2.horizon),
            deps=c1.deps | c2.deps)

    def sequential(self, c1, c2):
        if c1.region.time.end > c2.region.time.start:
            raise Incompatible("time order violated")
        if not implies(c1.post, c2.pre):
            raise Incompatible("postcondition does not imply precondition")
        return Certificate(
            cid=new_id(), robot={c1.robot, c2.robot},
            region=c1.region.union(c2.region),
            occupancy=SequencedOccupancy(c1.occupancy, c2.occupancy),
            pre=c1.pre, post=c2.post,
            horizon=min(c1.horizon, c2.horizon),
            deps=c1.deps | c2.deps)

# IP-342 空间摘要：八叉树 + Merkle 哈希，增量失效
class SpatialDigest:
    def __init__(self, arena_bbox, max_depth=10):
        self.root = OctreeNode(arena_bbox, depth=0, max_depth=max_depth)
        self.cert_index = {}

    def update(self, cert):
        self.root.insert(cert)                    # O(log |M|)
        self.cert_index[cert.id] = cert
        self._rehash_path(cert.region)            # O(log |M|)

    def remove(self, cert):
        self.root.remove(cert.id)
        self.cert_index.pop(cert.id, None)
        self._rehash_path(cert.region)

    def query_overlap(self, region):
        # 只返回与 region 相交的叶证书；未相交子树被整枝剪掉
        return self.root.query(region)

    def root_hash(self):
        return self.root.hash

# IP-343 有界陈旧：把时间误差换成空间保守
class StaleGuard:
    def __init__(self, e_state, v_max, a_max):
        self.e_state, self.v_max, self.a_max = e_state, v_max, a_max

    def reachable_radius(self, delta):
        return self.e_state + self.v_max * delta + 0.5 * self.a_max * delta**2

    def inflate(self, cert, delta):
        if delta > cert.horizon:
            raise StaleCertificate(cert.id, delta, cert.horizon)
        rho = self.reachable_radius(delta)
        return cert.occupancy.minkowski_ball(rho)

    def safe_pair(self, ci, di, cj, dj, priority):
        oi = self.inflate(ci, di)
        oj = self.inflate(cj, dj)
        overlap = oi.intersect(oj)
        if overlap.is_empty():
            return True
        # 物理资源重叠：并行不可用，只能由优先级决定让行
        return priority(ci.robot, cj.robot)

# IP-344 分组共形校准：异构机器人不共享可交换性
class FleetConformal:
    def __init__(self, alpha, n_min, beta=1.0):
        self.alpha, self.n_min, self.beta = alpha, n_min, beta
        self.group_scores = {}
        self.pooled_scores = []

    def calibrate(self, scores_by_group):
        self.group_scores = scores_by_group
        self.pooled_scores = [s for g in scores_by_group.values() for s in g]
        self.quantiles = {}
        for g, scores in scores_by_group.items():
            if len(scores) >= self.n_min:
                self.quantiles[g] = weighted_quantile(
                    scores + self.pooled_scores,
                    weights=[1.0/len(scores)]*len(scores) + [self.beta/len(self.pooled_scores)]*len(self.pooled_scores),
                    q=1 - self.alpha)
            else:
                self.quantiles[g] = weighted_quantile(
                    self.pooled_scores,
                    weights=[1.0/len(self.pooled_scores)]*len(self.pooled_scores),
                    q=1 - self.alpha)
                self.quantiles[g] = (self.quantiles[g], "pooled_fallback")

    def predict(self, group, score):
        q = self.quantiles.get(group, self.quantiles.get("__global__"))
        return score <= (q[0] if isinstance(q, tuple) else q)

# IP-345 类型化分布式分配：能力约束 + 通信图直径收敛
class TypedMarketAllocator:
    def allocate(self, tasks, robots, comm_graph, max_rounds=None):
        max_rounds = max_rounds or diameter(comm_graph) + 1
        bundles = {r.id: [] for r in robots}
        for _ in range(max_rounds):
            changed = False
            for r in robots:
                candidates = [t for t in tasks
                              if Admissible(r, t) and t not in assigned(tasks)]
                best = max(candidates, key=lambda t: r.bid(t), default=None)
                if best and r.bid(best) > current_winner_bid(best):
                    bundles[r.id].append(best)
                    assign(best, r)
                    changed = True
            broadcast_bids(robots, comm_graph)
            if not changed:
                break
        return bundles

# IP-346 主闭环：局部 RTDI + 证书 + 邻域兼容 + 证书 DAG
def fleetgauge_scale_round(M, robots, tasks, ell=None):
    # 1. 类型化分配：只决定“谁做”，不扩大能力
    bundles = M.alloc.allocate(tasks, robots, M.comm_graph)
    certs = {}

    for r in robots:
        if not bundles[r.id]:
            continue
        # 2. 每台机器人本地跑 RTDI，生成候选块与证书
        C_r, spatial_cert, claims = M.rtdi[r.id].plan_and_certify(
            r, bundles[r.id], ell)
        c_r = M.algebra.make_certificate(r, C_r, spatial_cert)
        certs[r.id] = c_r

        # 3. 只把证书发布到空间摘要（有界大小，不含原始感知流）
        M.digest.update(c_r)

    # 4. 只在交互图上做邻域兼容检查，不做全对检查
    conflicts = []
    for (i, j) in M.interaction_graph(certs):
        ci, cj = certs[i], certs[j]
        di = M.clock.age(ci)
        dj = M.clock.age(cj)
        if not M.stale_guard.safe_pair(ci, di, cj, dj, M.priority):
            conflicts.append((i, j))

    # 5. 冲突消解：低优先级让行，最多 R 轮；仍冲突则降级
    for _ in range(M.max_resolve_rounds):
        if not conflicts:
            break
        loser = {M.priority.lower(i, j) for (i, j) in conflicts}
        for rid in loser:
            C_r = M.rtdi[rid].replan_local(certs[rid], reason="conflict")
            certs[rid] = M.algebra.make_certificate(robots[rid], C_r, None)
            M.digest.update(certs[rid])
        conflicts = M.recheck_conflicts(certs)

    if conflicts:
        # 6. 无法在包线内消解：显式降级，而不是继续“安全地”堵死
        return M.degrade(level="L2", reason="dense_conflict")

    # 7. 并行执行；每台机器人仍受 RTDT 的 CVC + 诊断恢复约束
    results = []
    for r in robots:
        results.append(M.rtdi[r.id].execute(certs[r.id]))

    # 8. 提交证书 DAG；只更新变化路径
    for c in certs.values():
        M.ledger.commit(c)

    return results, M.ledger.root_hash()

# IP-346 退化入口
def degrade(level, reason):
    if level == "L2":
        return IndependentRTDI(all_robots)       # 无邻居证书
    if level == "L1":
        return RTDI_single_or_stop()             # N=1 或全队失联
    if level == "L0":
        return SafeStop()                        # 证书过期且无法重规划

## 4. 推导

**引理 69（证书代数可靠性）**
若 `Sound(c₁, x₁)`、`Sound(c₂, x₂)`，且 `c₁ ⊗ c₂` 有定义，则 `Sound(c₁⊗c₂, x₁‖x₂)`；若 `Sound(c₁,x₁)`、`Sound(c₂,x₂)` 且 `c₁ ; c₂` 有定义，则 `Sound(c₁;c₂, x₁·x₂)`。
证明：并行情形对时间做归纳。任一 `t` 落在交集中时，`x₁(t)∈O₁(t)`、`x₂(t)∈O₂(t)`，且 `O₁(t)∩O₂(t)=∅`，故联合轨迹落在 `O₁∪O₂` 中且两机器人不共享物理点；前后条件由合取保持。顺序情形由时间不重叠与 `post₁⇒pre₂` 直接拼接；依赖闭包按定义 494 递归可靠。注意：并行交换性要求无优先级偏序，否则只能作为“兼容集合上的部分交换”。

**引理 70（验证局部性与通信上界）**
设交互图最大度 `Δ`、边数 `K`、空间摘要查询 `O(log |M| + k)`，则每轮验证成本 `O(N log N + K)`；每台机器人每轮发送/接收证书 `O(Δ)`，总消息 `O(NΔ)`。
证明：每台机器人只查询自身证书区域，摘要返回相交证书数 `k_r`，`Σ_r k_r = 2K`；邻域构建 `O(N log N)`；窄相位只检查 `K` 条边。任何不在 `E_int` 中的机器人对，其膨胀占用已不相交，无需检查。若 `K=O(N)`（有界密度），总成本 `O(N log N)`。

**引理 71（有界陈旧安全）**
假设真实轨迹满足 `|x_r(t)−x_r(t_r)| ≤ v_max δ + ½ a_max δ²`，状态估计误差 `≤ e_state`，且 `δ ≤ H_c`。则 `x_r(t) ∈ inflate(O_c(t), ρ(δ))`。若对所有重叠时刻有 `inflate(O_i,ρ(δ_i)) ∩ inflate(O_j,ρ(δ_j)) = ∅`，则两机器人无碰撞。
证明：由中值定理与加速度上界，位置偏差被可达集球包住；状态估计误差与运动偏差相加得到 `ρ(δ)`；Minkowski 膨胀是真实占用的超集。超集不相交 ⇒ 真实占用不相交。若 `a_max` 被遥测违背，证书前提失效，`StaleGuard` 必须拒绝该证书，不能继续使用。

**引理 72（分组共形覆盖）**
若组 `g` 内样本可交换且 `n_g ≥ n_min`，则 `P(Y ∈ C_g) ≥ 1−α`；若回退到池化分布，则 `P(Y ∈ C_g) ≥ 1−α−TV(P_g, P_pool)`。
证明：组内情形是标准分割共形（split conformal）的加权版本；池化情形把组分布与池化分布的全变差作为覆盖损失的三角不等式上界。有限样本下再用 `1/(n_g+1)` 做保守修正。该界是保守的，但把“异构”从口头假设变成可检验的量。

**引理 73（规模律与渗流拐点）**
在 Poisson 空间近似下，期望交互度 `λ = Nπρ²/A_arena`，`E[K] = Nλ/2`，验证成本 `C(N) = Θ(N log N + Nλ)`。
- 若竞技场随 N 扩张且密度固定，`λ=O(1)`，`C=Θ(N log N)`；
- 若竞技场固定，`λ=Θ(N)`，`C=Θ(N²)`；
- 交互图在 `λ` 越过随机几何图渗流阈值 `λ_c` 时出现巨连通分量，冲突与重规划级联，完成率出现拐点。
证明（前两条）：代入 `E[K]` 即得；第三条是随机几何图的标准渗流现象，`λ_c` 由 E494 数值标定。该引理是**近似规模律**，用于预测拐点而非给出严格常数。

**引理 74（稠密下界）**
若 `G_int` 为完全图（所有膨胀证书两两相交），则任何仅依赖成对证书的验证纪律必须检查 `Ω(N²)` 对，才能区分“存在冲突”与“不存在冲突”；因此固定高密度下不存在成对证书的亚二次可扩展方案。
证明：构造一组证书，其冲突只体现在某一对特定的占用交集上，且所有单证书的局部摘要相同。若不检查该对，验证者无法区分冲突与非冲突；对抗性下界要求逐对检查。推论：可扩展性必须靠“维持稀疏”或“改变抽象”（预留、优先级、分批、停），而不是更快的两两检查。

## 8. 本轮最大风险

**一句话**：本方案把可扩展性押在“交互图稀疏 + 证书及时”上；一旦密度或通信延迟越过渗流/陈旧阈值，局部证书可以各自可靠却共同导致**活锁或容量坍塌**——机器人没有相撞，但队伍走不动，而“安全指标全绿”会掩盖“可扩展性已经失败”这一真正的事故模式。
