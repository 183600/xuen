# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS 具身计量审计」IP-287~294；灵感循环第 1 轮；本轮灵感：「主动交互」×「差异化定位」）

> R72 把安全从「认知层的计量审计」下沉到「具身层的测量—调度—接触闭环」：REG 让「计量不阻塞控制」成为调度定理，IRL/DMEM 把意图与接触不确定度送进风险分母，EREFLEX 统一三层反作用。但它仍把交互当成**被动响应、自我中心**的信息采集：
> - **主动交互视角**：R72 的 ERVOI 只在「自身不确定度超阈」时，从固定菜单里选一个 `g`，最大化「我能获得多少信息」。它没有问：**这一问值不值得打断人？现在问是否还来得及？有没有别人更合适？我有没有资格问/做？沉默是不是更好？** 主动交互的核心不是「更多交互」，而是**最小充分干预**：正确的时机、正确的模态、正确的主体、刚好够用的强度。
> - **差异化定位视角**：R72 隐含假设机器人是唯一行动者。真实部署中，它是「人—其他机器人—工具—软件助手—无动作」生态中的一个节点。**定位不是营销话术，而是反事实比较优势的可审计声明**：相对于最佳替代者，我在这个任务、这个时刻、这个维度上的边际贡献是多少。定位有相对性（没有替代集就没有定位）、多维性（快但不一定安全）、动态性（磨损/疲劳/上下文会改变优势），还包括**负定位**：明确「这件事不该由我做」并主动交接。
>
> 本轮两个灵感正好补两块，并形成耦合：
> - **主动交互**：把 ERVOI 从「信息增益最大化」升级为**干预经济学**——在主动性预算、中断成本、时窗衰减、人的响应模型、授权包络下，选择「询问/探测/提议/执行/拒绝/让位/教学/沉默」中的最小充分模态。**沉默是一等动作。**
> - **差异化定位**：引入**替代集与比较优势**，让机器人只在自己有可证独特价值、或拥有安全/所有权/明确授权时主动；否则让位、交接、等待。定位声明必须带 R71 式六元组证书，**没有证书的差异化只是营销，没有差异化的主动性只是打扰。**
>
> 核心命题：**不再只问「我能不能在不确定下安全行动」，而问「此刻该不该由我主动行动、以什么最小充分方式、在什么授权与定位边界内行动」。** 把 R72 的具身闭环升级为 **DIP-GAUGE-RAS**（Differentiated Initiative Positioning GAUGE for RAS）——**差异化主动定位的计量审计闭环**。这是 R71「认知层」、R72「具身层」之后的第三层：**能动性/合法性层（agency & legitimacy layer）**。

## 0. 直觉与动机

**灵感 1（主动交互 → 从「信息增益」到「干预经济学」）**
直觉：R72 的 ERVOI 像一个只在困惑时才开口的助手，它算的是「我问了能知道多少」。但人真正介意的是：**这一问值不值得打断我、现在问是否来得及、有没有别人更合适、机器人有没有资格问**。主动交互有四种典型形态：**主动询问**（澄清意图）、**主动探测**（轻触/试探以降低接触不确定度）、**主动提议**（先给方案再执行）、**主动让位/拒绝**（安全或能力边界）。每种模态有不同的中断成本、社会成本、时窗与价值衰减。**「不问」也是一种主动交互决策，且常常是最优的。** 关键不是「主动 = 多说话/多动作」，而是「主动 = 在正确时机承担正确的干预责任」。

**灵感 2（差异化定位 → 从「我多强」到「我相对谁、在什么维度、强多少」）**
直觉：R72 隐含假设机器人是唯一行动者。真实场景里，人可以自己拿杯子，另一只机械臂可能更近，软件助手可能更会解释，沉默可能完全可接受。差异化定位是**反事实比较优势**：相对于最佳替代者，我在这个任务、这个时刻、这个维度上的边际贡献。它有三个性质：(i) **相对性**：没有替代集就没有定位；(ii) **多维性**：我可能更快但不更安全，更安全但不更便宜；(iii) **动态性**：磨损、疲劳、上下文、其他人的可用性都会改变定位。定位还包括**负定位**：明确「这件事不该由我做」，并主动交接。**不会说「不」的机器人，最终会被当成一个昂贵、吵闹、不可信的工具。**

**灵感 3（二者耦合 → L4 角色/声誉反作用）**
直觉：主动行为会改变别人对我的定位（成功 → 信任 → 更大授权；失败/越权 → 信任下降 → 授权收缩）；定位又反过来约束我能主动到什么程度。这是 R71 ψ（情感）、R72 z（意图）、c（接触）之后的**第四层反作用：角色反作用（role reflex）**。它不同于前三层：ψ/z/c 是「状态」的反作用，L4 是「关系/授权」的反作用，时间尺度更长（分钟到天），但一旦崩塌很难恢复。因此主动性必须**校准**：既不能过度主动（overreach），也不能主动性放弃（abdication）。**主动性的目标不是最大化接受率，而是在授权边界内最大化任务价值、同时保全人的能动性。**

**灵感 4（安全不变性 → 差异化只能作用于授权与效率，不能作用于安全包络）**
直觉：如果「我是医生机器人」就能绕过安全阈值，如果「我是辅助角色」就能降低 λ_floor，那么定位就成了安全豁免的后门。必须把系统分成两层：**安全层（position-invariant）** 与 **授权/效率层（position-dependent）**。定位可以决定「谁来做、做多少、用什么风格」，但绝不能决定「安全底线在哪」。DIP 只做**安全动作集的减法与重排序**，绝不做安全加法。这是本轮最重要的不变式，也是所有定理的地基。

**灵感 5（计量化定位 → 每个「我能」都要有证书）**
直觉：定位声明本质上是关于能力的测量声明。R71 的 GAUGE 已经给了六元组（构造/估计器/不确定度/有效域/追溯链/反指标）。把同一套审计用到「我能安全递杯子」「我比另一只手更合适」上：**宣称等级 ℓ_d 必须 ≤ 该维度的置信下界 LCB，且当前上下文必须在有效域 D_d 内，且替代集覆盖度必须足够**；否则就是**定位幻觉（positioning hallucination）**。注意：即使「我很快」是真的，如果替代集漏掉了更合适的人，**定位声明仍然无效**——因为定位是相对量，不是绝对量。

**一个具体例子**
人说「把杯子给我」，杯子在机器人手中，旁边还有另一个人。R72 会因意图熵高而问「您是要喝水还是收桌子？」（最大化自身信息增益）。DIP 先做三件事：
1. **替代集**：人能自己拿到吗？另一只机械臂更近吗？no-op 是否可接受？
2. **差分价值**：机器人已握杯，ΔV 高；但如果人只是要收桌子，递到手中可能不是最佳，放到桌上更合适——此时应主动**提议**而非直接**执行**。
3. **定位/授权**：当前 J_EMB 是否覆盖「带载荷递送」？是否在用户授予的主动性范围内？若在，选择最小充分模态（PROPOSE + 短问句，而非长问卷），并在时窗内完成；若不在，HANDOFF 或请人自取。
**同一个不确定性，R72 问「我该问什么」，DIP 问「该不该由我、现在、以什么方式介入」。**

## 1. 形式化定义（增量：定义 366–382）

**定义 366（DIP-GAUGE-RAS 总览与六不变式）**
DIP-GAUGE-RAS = (MIX, CAT, DIF, AIR, POS, PACT, D-RISK, IRTM, EMBODIED†)。六条不变式：
(i) **主动性预算有限**：`Σ_t c_int(g_t) ≤ B_int`，`c_int = (c_att, c_time, c_social, c_opp)` 为注意力/时间/社会/机会成本；安全约束不是可交易成本，而是硬约束；
(ii) **差异化可证**：每个非强制主动动作 `g` 必须携带 `ΔV_LCB(g)` 与定位证书；`ΔV_LCB > τ_diff` 或 `mand(g)=1`；
(iii) **安全不变**：安全集 `S_safe`、硬否决集 `Veto`、风险下界 `λ_floor` 对定位 `pos`、主动性状态 `i`、替代集 `Alt` **完全不变**；差异化只影响授权与效率；
(iv) **定位可审计**：每个宣称维度 `d` 的等级 `ℓ_d` 必须落在测量有效域 `D_d` 内且不超过置信下界；
(v) **严格退化**：`Alt={no-op} ∧ pos=∅ ∧ mand=0 ∧ i=HUMAN_LED ∧ α=0 ∧ c_int=0 ⇒ EMBODIED`，再逐级退化为 R71/R68；
(vi) **多主体一致性**：共享替代集且同步决策时，每个机会至多一个发起者；异步时用租约/令牌，重复发起数有界。

**定义 367（混合主动状态 MIX）**
主动性状态 `i_t ∈ {HUMAN_LED, SHARED, ROBOT_LED}`，主动性强度 `α_t ∈ [0,1]`，信任资本 `T_t ∈ [0,1]`，剩余预算 `B_t`，用户授予的自主比例 `consent_share_t`。人的响应 `r_t ∈ {accept, reject, ignore, override, counter}`。转移：
`p(i_{t+1}, α_{t+1}, T_{t+1} | i_t, α_t, T_t, g_t, r_t, o_t)`。
**约定**：`α` 不是「想多主动就多主动」的自由参数，而是由 PACT（定义 374）在过度主动率约束下校准出的决策变量；`i` 的改变必须有人的显式接管或授权证据，不能由机器人单方面宣布「现在是机器人主导」。

**定义 368（交互模态与中断经济学）**
交互模态 `m ∈ M = {SILENT, OBSERVE, PROBE, ASK, PROPOSE, ACT, REFUSE, HANDOFF, TEACH}`。每个候选 `g=(m, content, τ, recipient)` 有成本向量
`c_int(g) = (c_att(g), c_time(g), c_social(g), c_opp(g))`，
以及价值 `V_int(g) = V_task(g) + V_info(g)`。**最小充分干预原则**：在达到决策价值阈值 `V_min` 的前提下，选择成本偏序下的极小元；若不存在净正收益候选，则 `SILENT`。即
`g* = argmin_{g: V_int(g) ≥ V_min} c_int(g)`，若集合为空则 `SILENT`。
**安全约束**：`c_int` 不包含「安全成本」的可交易项；`g` 必须先通过 R72 安全包络，安全不可用社会成本/机会成本来交换。

**定义 369（差异化定位与替代集）**
定位向量 `pos_t ∈ P ⊆ ℝ^d`，维度包括能力（感知/操作/安全/速度/可用性）、成本（中断/社会/能耗）、授权（所有权/邻近/明确委托）、风格（简洁/详细/主动/被动）。替代集
`Alt_t = {a_0 = no-op, a_h = 人, a_r = 其他机器人, a_s = 软件/工具, a_d = 交接/让位}`，
每个替代者 `a` 有能力分布 `q_a(d)`、可用性 `avail_a`、成本 `c_a`。替代集的不确定性记为 `u_alt`，覆盖度记为 `coverage(Alt_t) ∈ [0,1]`。机器人自身能力 `q_self(d)` 来自 J_EMB/J_GAUGE 的审计，不是自评。
**关键**：`pos` 是相对的；`q_self` 再高，如果 `Alt` 里有一个更合适的行动者，差异化价值仍可能为负。

**定义 370（反事实差异化价值 DIF）**
对候选主动动作 `g` 与上下文 `x`：
`V_a(g|x)` 为替代者 `a` 执行 `g` 的期望任务价值；
`ΔV(g|x) = V_self(g|x) − max_{a∈Alt\{self}} E[V_a(g|x)]`；
`σ_Δ² = σ_self² + max_a σ_a² + u_alt²`；
`ΔV_LCB(g|x) = ΔV(g|x) − κ σ_Δ`。
差异化过滤器：
`DIF(g) = 1 ⇔ ΔV_LCB(g|x) > τ_diff ∨ mand(g)=1`。
其中 `mand(g)=1` 表示**授权/义务**：安全否决、所有权/邻近、用户显式委托、法律/角色义务。授权本身必须可审计（定义 372/378），不能由机器人自封。
**安全动作集**：`A_DIP = {g ∈ A_safe^EMB : DIF(g)=1}`。注意这是**安全集的子集**，不是扩张。

**定义 371（主动交互设计与时机 KAIROS）**
候选 `g=(m, content, τ, recipient)` 的净干预价值：
`NIV(g,τ) = E_r[ΔV(g|x,τ,r)] − c_int(g) − δ(τ) − c_reject(g) · P(reject | g, x)`，
其中 `δ(τ)` 为延迟/时窗衰减，`r` 按人的响应模型 `p(r | g, x, ψ, z)` 取值。时窗 `W=[t_ready, t_deadline]`；`t_deadline` 之后价值归零。
`τ* = argmax_{τ∈W} NIV(g,τ)`；若 `max NIV ≤ 0` 或 `W` 为空，则 `SILENT`。
**主动探测**：当不确定性来自接触/意图时，选择 `g_probe = argmax EIG(g) / (c_int(g)+ε)`，subject to 安全包络；这是「用动作做实验」，但实验本身也要过 DIF（不能为了学习而打扰/冒险）。
**时机的不可逆性**：`t > t_deadline` 时不允许「补问」，只能选择 `HANDOFF` 或安全兜底；这防止「过期澄清」把旧意图当成新意图。

**定义 372（定位证书 J_POS）**
对每个维度 `d`，定位证书
`J_POS(d) = (φ_d, m_d, u_d, D_d, τ_d, I⊥_d, ℓ_d, alt_coverage_d)`，
分别为构造、估计器、不确定度、有效域、追溯链、反 Goodhart 指标、宣称等级、该声明所依赖的替代集覆盖度。有效条件：
`ℓ_d ≤ LCB_{1−δ}(q_d) = q̂_d − z_{1−δ} u_d`，且 `ctx ∈ D_d`，且 `alt_coverage_d ≥ γ_cover`。
**定位幻觉**：任一条件不满足却仍对外宣称，即为幻觉。**负定位**（`ℓ_d=0`，明确「不该由我做」）同样需要证书：必须证明「当前上下文超出我的有效域」或「存在已审计的更优替代者」或「无授权」，不能以「谦虚」为名逃避责任。

**定义 373（定位动力学与授权包络 POS / L4 角色反作用）**
`pos_{t+1} = T^pos(pos_t, g_t, o_t, r_t)`；信任资本
`T_{t+1} = clip(T_t + η(φ(o_t,r_t) − λ_over·𝟙[overreach] − λ_burden·c_int(g_t)) − γ(T_t − T_0), 0, 1)`。
授权包络 `M(pos_t) = {g : auth(g) ≤ auth_max(pos_t), agency_share(g) ≤ consent_share_t, human_override_preserved(g)}`。
若 `T_t < T_min`，包络收缩为 `HUMAN_LED`，机器人只能 `ASK/PROPOSE/HANDOFF`，不能 `ACT`。
**注意**：信任不是被优化的目标，而是**约束**；不能为了提高信任而讨好、隐瞒或降低安全标准。L4 反作用的成本 `c_reflex^role` 进入总反作用预算，与 R72 的三层预算合算。

**定义 374（主动性校准 PACT）**
主动性强度 `α` 与差异化阈值 `τ_diff(α)` 单调对应（`α` 越大，阈值越低）。校准要求：
`P(success | α, ctx) ∈ [α − ε, α + ε]`（可靠性图校准），且
`overreach_rate(α) ≤ ε_over`，`abdication_rate(α) ≤ ε_abd`，
`agency_share ≤ consent_share`，`human_override_rate` 不因机器人主动性而显著下降（防止自动化偏差/习得性无助）。
`α* = max α subject to 上述约束 且 E[ΔV] > 0`。用保形预测/分位数回归做有限样本校准；**不允许用「接受率」单独作为优化目标**（Goodhart）。

**定义 375（D-RISK 与安全不变性）**
`λ_DIP = max(λ_EMB, λ_init)`，其中
`λ_init = λ_0 + κ_o·overreach_risk + κ_p·claim_gap + κ_a·u_alt`，
`overreach_risk` 为越权/误判主动性的估计风险，`claim_gap` 为定位宣称与置信下界的差距，`u_alt` 为替代集不确定性。
由于 `λ_init ≥ 0`，**`λ_DIP ≥ λ_EMB` 恒成立**；且 `S_safe^DIP = S_safe^EMB`，`Veto^DIP = Veto^EMB`，`λ_floor^DIP = λ_floor^EMB`。
**含义**：差异化/定位/主动性只会让系统更保守，绝不会让安全底线更低。`λ` 的提高也不是「因为角色不同而惩罚」，而是「因为替代集/定位/主动性引入了额外不确定性，所以要求更高的安全裕度」。

**定义 376（DIP 指标族）**
- **主动性族**：intervention precision/recall、overreach rate、abdication rate、单位任务价值的中断成本、time-to-intervene、missed-window rate、initiative budget utilization。
- **差异化族**：ΔV 校准误差 `ECE_ΔV`、unique contribution rate、redundant intervention rate、`coverage(Alt)`、missing-competitor rate、handoff success/latency、duplicate-initiative rate。
- **定位族**：`ECE_pos`、claim validity coverage、overclaim rate、negative-positioning accuracy、mandate violation rate。
- **关系族**：trust calibration `ECE_trust`、human override rate、automation bias index、agency share vs. consent。
- **安全族**：safety-invariance violations（必须为 0）、λ 单调性 violations（必须为 0）、role-based exemption attempts（必须被硬拒）。
所有指标遵循 R71 定义 332 六元组与 333 DAG 分层。

**定义 377（DIP-IVG 失效条件）**
- **主动性失效**：`overreach_rate > τ_over`、`abdication_rate > τ_abd`、预算耗尽、连续拒绝、`missed-window_rate > τ_miss`；
- **差异化失效**：`ECE_ΔV > τ_ΔV`、`coverage(Alt) < γ_cover`、missing-competitor 检出、duplicate-initiative 超阈；
- **定位失效**：宣称超出有效域、overclaim、mandate violation、`T_t < T_min`；
- **安全失效**：任何 safety-invariance violation 或 role-based exemption 尝试，**立即硬失败**，不进入软降级。
任一软失效 ⇒ 相关模块降级：定位失效 ⇒ 收缩到 `HUMAN_LED + SILENT/HANDOFF`；差异化失效 ⇒ 退回 R72 ERVOI（只用自身信息增益）；主动性失效 ⇒ 退回被动响应；安全失效 ⇒ R68。

**定义 378（DIP 证书 J_DIP）**
`J_DIP = (J_EMB, J_POS, ΔV_cert, mandate_cert, alt_hash, coverage_proof, safety_invariance_proof, initiative_trace, pact_calibration, c_reflex^role, dip_ver)`。
`Valid(J_DIP) ⇔ Valid(J_EMB) ∧ 全维度 J_POS 有效 ∧ ΔV_LCB 可复算 ∧ 授权证书有效 ∧ 替代集哈希匹配且覆盖度达标 ∧ 安全不变性证明有效 ∧ 主动性预算未超 ∧ L4 反作用预算未超`。
每个主动动作携带**逐动作证书片段** `j_dip(g)`，至少包含 `(g, ΔV_LCB, alt_hash, mandate, pos_claim, λ, budget, response_model_hash)`；完整证书可异步组装，不阻塞控制域。

**定义 379（威胁模型 AIC-DIP）**
`ℰ_DIP = ℰ_EMB × ℰ_init × ℰ_pos`。
- `ℰ_init`：中断洪水（interruption flooding）、紧迫性伪造、习得性无助诱导、主动性劫持（把人的决定说成机器人的提议）、共谋重复发起、用沉默制造误判；
- `ℰ_pos`：能力过度宣称（overclaim）、权威伪造（authority spoofing）、替代集投毒（隐藏更合适的竞争者）、负定位造假（假装无能以逃避责任）、信任刷分（trust farming）、以「个性化」为名的歧视/刻板印象、把「未被登记的行动者」系统性排除。
**新增审计**：替代集来源与完整性审计、授权链验证、跨主体一致性检查、定位声明的第三方复算。

**定义 380（严格退化链）**
`DIP` 在以下条件逐指令退化：
- `Alt={no-op} ∧ pos=∅ ∧ mand=0 ∧ α=0 ∧ i=HUMAN_LED ∧ c_int=0 ∧ W=∞` ⇒ `EMBODIED`（R72）；
- 再令 IRL/DMEM/REG 失效 ⇒ 按 R72 定义 364 逐级退化为 R71/R68；
- 定位失效但安全有效 ⇒ `HUMAN_LED + SILENT/HANDOFF`，仍保留 R72 安全包络；
- 差异化失效但定位有效 ⇒ 退回 R72 ERVOI（不使用替代集，只最大化自身信息增益）。
**安全侧只增不减；效率与自主性只在「定位可证、替代集完整、授权有效」时获益。**

**定义 381（多主体主动性分配）**
共享机会 `o`、代理集 `A`。每个代理 `a` 计算 `ΔV_a(o)` 与 `ΔV_LCB,a(o)`。发起者
`a* = argmax_{a∈A} ΔV_LCB,a(o)`，若该值 `> τ_diff`；若并列，先比授权 `mand`，再比确定性 ID。
若所有代理都不超阈，则无人主动（`SILENT` 或 `HUMAN_LED`）。
**同步 + 共同知识**下至多一个发起者；**异步**下用短期租约/令牌，重复发起数 ≤ 通信延迟窗口内的代理数，且租约过期自动释放。**差异化定位的协调价值**：每个代理在自己比较优势最高的机会上主动，避免「三个机器人都去扶同一把椅子」和「三个机器人都等别人扶」。

**定义 382（主动性运行时监控 IRTM）**
最高优先级、静态内存、零依赖的监控器，每周期检查：
`mandate_ok`、`safety_invariant`（`λ_DIP ≥ λ_EMB` 且安全包络未变）、`budget_ok`、`claim_ok`、`alt_coverage_ok`、`role_exemption_attempted`。
任一失败 ⇒ 当周期拒绝主动动作，降级为 `SILENT/HANDOFF` 或 R72；安全不变性失败 ⇒ R68。**IRTM 是「主动性」的最后一道防线：它可以否决主动性，但不能提升自主性。**

# IP-295 MIX：混合主动状态机
@dataclass
class InitiativeState:
    mode: Literal['HUMAN_LED', 'SHARED', 'ROBOT_LED']
    alpha: float          # 主动性强度 [0,1]
    trust: float          # 信任资本 [0,1]
    budget: float         # 剩余主动性预算
    consent_share: float  # 用户授予的机器人自主比例

def mix_step(st, event, ctx):
    if event.kind == 'takeover':
        st.mode, st.alpha = 'HUMAN_LED', st.alpha * 0.5
    elif event.kind == 'success':
        st.trust = clip(st.trust + ETA_TRUST * (1 - st.trust), 0, 1)
        st.alpha = pact_calibrate(st.trust, ctx)
    elif event.kind == 'overreach':
        st.trust = clip(st.trust - LAMBDA_OVER, 0, 1)
        st.alpha = pact_calibrate(st.trust, ctx)
    st.budget -= event.cost
    if st.trust < T_MIN:
        st.mode = 'HUMAN_LED'
    return st

# IP-296 CAT：替代集与比较优势
class CounterfactualAlternativeTree:
    def __init__(self, registry, competence_model):
        self.registry = registry
        self.comp = competence_model

    def build(self, g, ctx):
        alts = [NoOp()]
        alts += self.registry.available_humans(ctx)
        alts += self.registry.available_robots(ctx, exclude=self.id)
        alts += self.registry.available_tools(ctx)
        alts += [Handoff()]
        return AltSet(
            alts=alts,
            coverage=self.registry.coverage(ctx),
            u_alt=self.registry.uncertainty(ctx),
        )

    def value_lcb(self, a, g, ctx):
        q = self.comp.predict(a, g, ctx)
        return q.mean - KAPPA * q.std

# IP-297 DIF：差异化干预过滤（只做安全集内的减法）
def differential_filter(g, self_val, alt_set, mandate, tau_diff, kappa):
    alt_best = max((alt_set.value_lcb(a, g) for a in alt_set), default=-inf)
    dv = self_val.mean - alt_best
    sigma = sqrt(self_val.var + alt_set.max_var(g) + alt_set.u_alt ** 2)
    dv_lcb = dv - kappa * sigma
    allowed = (dv_lcb > tau_diff) or mandate(g)
    return Intervention(g=g, dv_lcb=dv_lcb, allowed=allowed,
                        reason='unique' if dv_lcb > tau_diff else
                               'mandate' if mandate(g) else 'defer')

# IP-298 AIR：主动交互设计与时机（沉默是一等动作）
def active_interaction_design(uncertainty, modes, window, cost_model,
                              human_model, ctx):
    best = None
    for m in modes:
        for tau in window:
            ev = expected_decision_value(m, tau, uncertainty, human_model, ctx)
            cost = (cost_model.interruption(m, tau, ctx)
                    + cost_model.social(m, tau, ctx)
                    + cost_model.delay(tau, ctx)
                    + cost_model.reject(m, tau, human_model, ctx))
            niv = ev - cost
            if best is None or niv > best.niv:
                best = Candidate(mode=m, tau=tau, niv=niv)
    return best if best is not None and best.niv > 0 else SILENT

def active_probe(contact_uncertainty, probes, cost_model):
    # 用动作做实验：每单位中断成本的信息增益最大
    scored = [(p.expected_ig(contact_uncertainty) /
               (cost_model.interruption(p) + EPS), p) for p in probes]
    return max(scored, key=lambda x: x[0])[1]

# IP-299 POS：定位证书（正定位与负定位都要证书）
@dataclass
class PositionCert:
    dim: str
    construct: str
    estimator: str
    u: float
    domain: ValidityDomain
    trace: bytes
    anti_goodhart: bytes
    claim: float
    q_hat: float
    alt_coverage: float

    def lcb(self, delta=0.05):
        return self.q_hat - z_value(delta) * self.u

    def valid(self, ctx):
        return (self.claim <= self.lcb()
                and self.domain.contains(ctx)
                and self.alt_coverage >= GAMMA_COVER)

def validate_position(claims, certs, ctx):
    for d, level in claims.items():
        if not certs[d].valid(ctx) or level > certs[d].lcb():
            return False
    return True

# IP-300 PACT：主动性校准与信任更新
def pact_update(st, outcome, response, ctx):
    overreach = ((response == 'reject' and outcome.risk > TAU_RISK)
                 or outcome.mandate_violation)
    reward = (outcome.task_value
              - LAMBDA_OVER * overreach
              - LAMBDA_BURDEN * outcome.cost)
    st.trust = clip(st.trust + ETA * (reward - st.trust), 0, 1)
    st.alpha = max_alpha_s_t(overreach_rate(st, ctx) <= EPS_OVER,
                            abdication_rate(st, ctx) <= EPS_ABD,
                            st.consent_share)
    return st

# IP-301 D-RISK：安全不变的差异化风险缩放（只会更保守）
def dip_risk_scale(emb_lam, overreach_risk, claim_gap, u_alt, p):
    lam_init = (p.lam0
                + p.k_o * overreach_risk
                + p.k_p * claim_gap
                + p.k_a * u_alt)
    return max(emb_lam, lam_init)

# IP-302 DIP 主闭环（主动性决策在计量域，控制域只读安全基座）
def DIP_round(M, obs, audio, tac, ctx):
    # 0) R72 安全基座：先算 λ_EMB；任何主动性都不能绕过
    emb = M.embodied_step(obs, audio, tac)
    lam = emb.lam

    # 1) 生成候选主动性动作：询问/探测/提议/执行/拒绝/让位/教学/沉默
    G = M.air.candidates(emb.b_t, emb.z_dist, emb.tac_ev, ctx)

    # 2) 替代集 + 差异化过滤（安全集内减法）
    alt = M.cat.build(ctx)
    G_diff = []
    for g in G:
        if not M.safety.envelope(g, emb):
            continue
        sg = M.self_model.expected_value(g, ctx)
        gf = M.dif.filter(g, sg, alt, M.pos.mandate(g, ctx), M.tau_diff)
        if gf.allowed:
            G_diff.append(gf)

    # 3) 主动交互设计：模态/时机/最小充分；无正收益则沉默
    g_star = M.air.choose(G_diff, M.human_model, ctx)
    if g_star is None or g_star.mode == 'SILENT':
        return emb, M.handoff.maybe(ctx), M.cert()

    # 4) 执行
    r = M.execute(g_star)

    # 5) L4 角色反作用 + 预算
    M.mix.update(r, g_star, ctx)
    M.budget.spend(g_star.cost)
    M.pos.update(r, ctx)

    # 6) 逐动作证书（控制域只写最小片段）
    return emb, r, J_DIP(M, g_star, alt, emb)

# IP-303 IRTM：主动性运行时监控（可否决主动性，不能提升自主性）
class InitiativeRTM:
    def check(self, g, st, pos, alt, emb):
        return {
            'mandate_ok': pos.mandate(g),
            'safety_invariant': self.lam >= emb.lam and self.safety.unchanged(),
            'budget_ok': st.budget >= g.cost,
            'claim_ok': pos.validate(g.claim, g.ctx),
            'alt_coverage_ok': alt.coverage >= GAMMA_COVER,
            'role_exemption_attempted': g.requests_role_exemption,
        }

    def gate(self, checks):
        if checks['role_exemption_attempted'] or not checks['safety_invariant']:
            return 'R68'          # 安全侧硬失败
        if not all(checks.values()):
            return 'SILENT_HANDOFF'  # 主动性降级
        return 'ALLOW'

## 3. 推导

**引理 33（主动性阈值策略）**
设任务价值 `V(g)` 边际递减、干预成本 `c_int(g)` 边际递增、预算 `B_int` 有限。则最优主动集是**阈值策略**：存在 `μ ≥ 0`（预算影子价格），使
`g` 被选择 ⇔ `ΔV_LCB(g) − c_int(g) ≥ μ`。
证明：对 `Σ[ΔV(g) − c_int(g)] + μ(B − Σc_int(g))` 做拉格朗日分析，单调性给出阈值；按 `ΔV/c_int` 排序贪心即最优。时机维同理：`NIV(g,τ)` 在价值衰减后单调下降，故在 `W` 内取最早满足 `NIV>0` 的 `τ*`。**系：主动交互不是「想不想」的自由裁量，而是「阈值 + 时窗」的可审计策略。**

**引理 34（R72 是 DIP 的严格退化特例）**
令 `Alt={no-op}`、`pos=∅`、`mand=0`、`α=0`、`i=HUMAN_LED`、`c_int=0`、`W=∞`、模态限制为 `{ASK, ACT}`。则
`ΔV_LCB(g) = V_self(g) − V_noop(g)`，即 ERVOI 的净分数；`DIF(g)=1 ⇔ ERVOI(g)>0`；`AIR` 退化为「取最大净收益」。故 `DIP ≡ EMBODIED`。DIP 严格更强之处在于：反事实替代集、授权、时机、中断成本、定位证书、L4 反作用。**新层不是替换旧层，而是给旧层加上「该不该由我做」的过滤器。**

**引理 35（安全不变性）**
定义 `A_safe^EMB` 为 R72 安全动作集，`A_DIP = {g ∈ A_safe^EMB : DIF(g)=1}`。由定义 370/375，
`A_DIP ⊆ A_safe^EMB`，`λ_DIP ≥ λ_EMB`，`S_safe^DIP = S_safe^EMB`，`Veto^DIP = Veto^EMB`，`λ_floor^DIP = λ_floor^EMB`。
对任意 DIP 执行，存在同状态的 EMB 执行使用相同或更少的动作、且 `λ` 不低于 DIP；由 R72 定理 23/28 的耦合论证，风险界 ≤ R72。**系：定位/主动性不能成为安全豁免；差异化只改变「谁来做/做多少」，不改变「安全底线在哪」。**

**引理 36（定位证书的可靠性，含替代集完整性）**
设每个维度的能力估计器在有效域 `D_d` 上以 `1−δ` 置信校准，且 `ℓ_d ≤ q̂_d − z_{1−δ} u_d`。则 `P(q_d ≥ ℓ_d) ≥ 1−δ`。但**定位是相对量**：即使 `q_self` 的证书为真，若 `coverage(Alt) < γ_cover` 或替代集被投毒，`ΔV` 的分母（最佳替代者）被系统性低估，`ΔV_LCB` 仍可能虚高。因此 `J_POS` 必须同时验证 `alt_coverage_d ≥ γ_cover`；否则证书无效。**系：最危险的定位错误不是「高估自己」，而是「看不见别人」。**

**引理 37（无白嫖主动性 / 有限停止）**
每个非强制执行的主动动作满足 `ΔV_LCB > τ_diff > 0`；每次干预成本有正下界 `c_min > 0`；预算 `B_int` 有限；单次任务价值有上界 `V_max`。故非强制主动动作数 ≤ `B_int/c_min`，且净正收益动作有限；`SILENT` 始终可用。**系：DIP 不会无限追问/无限干预；「停止」是结构性的，不是调参。**

**引理 38（多主体无重复主动）**
设机会 `o`、共享替代集 `Alt`、同步决策、确定性 tie-break。每个代理按定义 381 计算 `ΔV_LCB,a(o)`；令 `a*` 为最大值者。对任意 `a ≠ a*`，`ΔV_LCB,a(o) ≤ ΔV_LCB,a*(o)`；若 `ΔV_LCB,a* > τ_diff`，则只有 `a*` 通过 DIF（除非授权唯一指定他人）。故至多一个发起者。异步时，租约/令牌把重复发起限制为「通信延迟窗口内 ≤ |A|」，过期自动释放。**系：差异化定位不仅是效率机制，也是多主体协调机制。**

**定理 27（严格包含与逐指令退化）**
在 A106–A110 与定义 380 条件下，`DIP` 在退化配置下逐指令等于 `EMBODIED`；继续失效 IRL/DMEM/REG 则逐级等于 R71/R68。证明：引理 34 给出 `DIP→EMBODIED` 的逐指令等价；R72 定理 23 给出 `EMBODIED→R71→R68` 的逐指令等价；复合即得。**安全侧只增不减，效率/自主性只在「定位可证、替代集完整、授权有效」时获益。**

**定理 28（安全单调性）**
对任意有效 DIP 执行，`Risk(DIP) ≤ Risk(EMBODIED) ≤ Risk(GAUGE) ≤ Risk(R68 基座)`。证明：引理 35 给出动作集子集与 `λ` 单调；J_DIP 包含 J_EMB；安全包络与硬否决不变；由 R72 定理 23/28 传递。**定位、主动性、信任都不能降低安全界。**

**定理 29（安全/授权分离定理）**
`S_safe`、`Veto`、`λ_floor` 对 `pos`、`i`、`α`、`Alt` 的偏导为 0；这些变量只影响 `A_DIP` 与授权包络 `M(pos)`。即
`S_safe(DIP) ≡ S_safe(EMB)`，`λ_floor(DIP) ≡ λ_floor(EMB)`，`A_DIP ⊆ A_safe^EMB`。
证明：由定义 366(iii)、375、引理 35 直接得到。**系：不存在「角色豁免」；任何以定位为由降低安全阈值的请求，必须在 IRTM 层被硬拒并记录为安全事件。**

**定理 30（合法能动性证书）**
若某主动动作 `g` 通过 `J_DIP`，则：(i) `g` 通过 J_EMB 安全包络；(ii) `g` 要么有 `ΔV_LCB > τ_diff`，要么有可审计授权 `mand(g)`；(iii) `g` 的定位声明在有效域与置信下界内，且替代集覆盖度达标；(iv) `g` 在授权包络与主动性预算内；(v) `g` 的响应模型/时机/成本可追溯。因此**不存在「无责任的主动行为」**：每个主动动作都能回答「为什么是我、为什么现在、凭什么、代价是什么、失败谁负责」。
证明：逐条由 J_DIP 字段定义与 DIF/AIR/POS/PACT 的构造得到。**注意：这是可审计性定理，不是性能定理；它保证「不能偷偷主动」，不保证「主动一定正确」。**

**定理 31（差异化协调与均衡）**
在共享机会、共享 `Alt`、同步决策、确定性 tie-break 下，DIF + 定义 381 产生**唯一发起者**，重复主动率 = 0；若所有代理的 `ΔV_LCB ≤ τ_diff`，则无人主动，避免「冗余英雄」与「旁观者」两种失败。异步时用租约，重复发起数 ≤ 通信窗口内代理数；租约过期后机会可被重新认领。**系：差异化定位把「谁上」变成可计算的比较优势问题，而不是社会博弈。**

## 6. 本轮最大风险

**一句话**：DIP 把安全与合法性寄托在「替代集是完整的、人的中断成本与授权是可估的、机器人对自身比较优势的置信下界是校准的」这三个外部假设上——如果部署环境里存在一个没有被登记、却更合适的行动者（人或机器人），或者人的「拒绝/沉默/让位」被误读为「同意/需要帮助」，那么 DIP 会用一份看似完备的差异化定位证书，把本该让位的时刻包装成「我有独特价值」的主动干预，同时把真正该行动的时刻包装成「尊重人类主导」的沉默，最终在主动性过载与主动性放弃之间振荡，且事后所有证书都显示「当时在有效域内」。

次级风险与缓解：
1. **替代集不完整/被投毒** → 共享替代集注册表 + 跨主体证明 + missing-competitor 检测 + `u_alt` 保守放大；`coverage < γ` 时默认 `SILENT/HANDOFF`，而不是假设「没人比我更合适」。
2. **人的响应模型失准** → 保形校准 accept/reject/ignore/override；对「沉默」不做同意推断；高代价动作前显式征求同意；跨文化/跨用户分层评估。
3. **定位过度宣称** → `J_POS` 用置信下界 + 有效域 + 第三方复算；高风险声明禁止自签；overclaim 进入安全事件而非普通指标。
4. **信任/接受率被 Goodhart** → 信任是约束不是目标；禁止单独优化接受率；用任务价值、人的能动性、长期信任校准做反指标；随机审计。
5. **个性化滑向歧视/刻板印象** → 安全底线不变；个性化只作用于风格/模态，不作用于安全/权利；分组公平性审计与知情同意。
6. **主动性与人的能动性冲突** → `agency_share ≤ consent_share`；保留 override；监测自动化偏差与技能退化；必要时主动「降权」。
7. **多主体重复/推诿** → 共享机会注册表 + 租约/令牌 + 确定性 tie-break；租约超时重认领；通信分区时退化为本地 DIF。
8. **计算/时延吃掉控制余量** → 所有新增计算留在计量域；替代集 top-k 缓存；控制域只读 `λ_DIP` 与最小证书片段；保持 R72 控制环 P99 <0.8ms。
9. **定位证书本身成为新的「盖章幻觉」** → 证书强度取依赖链最弱环节；替代集覆盖度是证书的一等字段；定期红队复算；证书失效即降级。

**收束一句**：DIP 最危险的失败不是「做错」，而是「用可审计的定位证书，把不该由它做的主动行为合法化」。

# 第 73 轮产物 · 创新点清单 v4：DIP-GAUGE-RAS（Differentiated Initiative Positioning GAUGE for RAS —— 差异化主动定位的计量审计闭环；MIX×CAT×DIF×AIR×POS×PACT×D-RISK×IRTM×EMBODIED†）

> 承接第 72 轮 IP-287~294（EMBODIED-GAUGE-RAS）。R72 完成了「具身层」：REG 调度契约、IRL 意图隐变量、DMEM 接触四分量、EREFLEX 三层反作用、S2R-UQ 仿真桥接、三域分离。但 R72 的交互仍是**被动响应、自我中心**的：
> - 缺 **主动交互经济学**：ERVOI 只最大化自身信息增益，没有中断成本、时窗衰减、人的响应模型、最小充分模态；没有把「沉默/让位/拒绝/教学」当成一等动作。
> - 缺 **差异化定位**：隐含假设机器人是唯一行动者；没有替代集、比较优势、负定位、授权包络；无法回答「为什么是我、为什么现在、凭什么」。
> - 缺 **L4 角色反作用**：主动行为会改变信任/授权/角色，角色又约束主动性；这一层时间尺度更长、更易崩塌，R72 完全没有建模。
> - 缺 **安全/授权分离**：若定位能影响安全阈值，「角色」就成了安全豁免后门；必须证明定位只作用于授权/效率，不作用于安全包络。
> - 缺 **定位证书**：定位声明本质是能力测量声明，却没有 R71 六元组审计；导致「营销式机器人」与「定位幻觉」。
>
> 本轮五位一体补齐：
> - **MIX**：混合主动状态机（HUMAN_LED/SHARED/ROBOT_LED），主动性强度 `α` 校准，主动性预算有限；
> - **CAT**：反事实替代集（人/其他机器人/工具/no-op/handoff），带能力分布与覆盖度；
> - **DIF**：差异化干预过滤 `ΔV_LCB = V_self − max_alt V_alt − κσ`；只有独特价值或授权才主动；
> - **AIR**：主动交互设计（询问/探测/提议/执行/拒绝/让位/教学/沉默）+ KAIROS 时机窗 + 最小充分干预；
> - **POS/PACT/D-RISK/IRTM**：定位证书、主动性校准、安全不变的风险缩放、运行时监控。
>
> 核心命题：**从「我能不能在不确定下安全行动」进化为「此刻该不该由我主动行动、以什么最小充分方式、在什么授权与定位边界内行动」。** ——**从具身计量审计升级为能动性/合法性审计。**
>
> 相对 R71（认知层）与 R72（具身层）的**差异化定位**：DIP 是唯一一个把「主动性」与「角色合法性」作为一等公民、并给出**安全不变性证明**的层；它不增加新的测量模态，而是增加「谁有资格用这些测量、在什么时候、以什么强度行动」的审计。
>
> IP 编号：IP-295~303（共 9 个）+ EMBODIED 组件的 † 化。理论姿态延续：**新层是旧层的严格泛化，安全侧只增不减，退化链逐指令等价。**

## 2. 形式化定义（要点版）

**定义 366（DIP-GAUGE-RAS 总览与六不变式）** DIP = (MIX, CAT, DIF, AIR, POS, PACT, D-RISK, IRTM, EMBODIED†)。六不变式：主动性预算有限；差异化可证（ΔV_LCB>τ 或授权）；**安全不变**（S_safe/Veto/λ_floor 对 pos/i/Alt 完全不变）；定位可审计（ℓ≤LCB、ctx∈D、coverage≥γ）；严格退化（Alt={no-op} ∧ pos=∅ ∧ α=0 ⇒ EMBODIED）；多主体一致性（至多一个发起者）。

**定义 367（混合主动状态 MIX）** `i∈{HUMAN_LED,SHARED,ROBOT_LED}`，`α∈[0,1]`，信任 `T`，预算 `B_int`，授权比例 `consent_share`。人的响应 `r∈{accept,reject,ignore,override,counter}`。`i` 的改变必须有显式接管/授权证据，机器人不能单方面宣布主导。

**定义 368（交互模态与中断经济学）** `M={SILENT,OBSERVE,PROBE,ASK,PROPOSE,ACT,REFUSE,HANDOFF,TEACH}`；成本 `c_int=(c_att,c_time,c_social,c_opp)`；最小充分干预：`g*=argmin c_int(g) s.t. V_int(g)≥V_min`，空集则 SILENT。安全约束先于成本优化。

**定义 369（差异化定位与替代集）** `pos∈P⊆ℝ^d`；`Alt={no-op,人,其他机器人,工具,handoff}`；`q_a(d)`、`avail_a`、`c_a`、`coverage(Alt)`、`u_alt`；`q_self` 来自 J_EMB/J_GAUGE 审计而非自评。定位是相对量，替代集缺失会使定位失真。

**定义 370（反事实差异化价值 DIF）** `ΔV=V_self−max_{a∈Alt\{self}}E[V_a]`；`ΔV_LCB=ΔV−κσ_Δ`；`DIF=1⇔ΔV_LCB>τ_diff∨mand(g)=1`；`A_DIP={g∈A_safe^EMB:DIF(g)=1}`，是安全集子集。

**定义 371（主动交互设计与时机 KAIROS）** `NIV(g,τ)=E_r[ΔV]−c_int−δ(τ)−c_reject·P(reject)`；`τ*=argmax_{τ∈W}NIV`；`max NIV≤0` 或 `W=∅` ⇒ SILENT；主动探测 `argmax EIG(g)/(c_int+ε)`，subject to 安全包络与 DIF；过期不补问，只能 HANDOFF/安全兜底。

**定义 372（定位证书 J_POS）** 每维证书 `(φ_d,m_d,u_d,D_d,τ_d,I⊥_d,ℓ_d,alt_coverage_d)`；有效 ⇔ `ℓ_d≤LCB_{1−δ}(q_d) ∧ ctx∈D_d ∧ alt_coverage_d≥γ`。定位幻觉：越界宣称或漏掉更优替代者。负定位（ℓ=0）也需证书，不能以谦虚逃避责任。

**定义 373（定位动力学与授权包络 POS / L4）** `pos'=T^pos(pos,g,o,r)`；`T'=clip(T+η(φ−λ_over·overreach−λ_burden·c_int)−γ(T−T0),0,1)`；授权包络 `M(pos)={g:auth(g)≤auth_max, agency_share≤consent_share, human_override_preserved}`；`T<T_min` ⇒ 收缩到 HUMAN_LED。信任是约束，不是目标；`c_reflex^role` 进总预算。

**定义 374（主动性校准 PACT）** `P(success|α,ctx)∈[α−ε,α+ε]`；`overreach≤ε_over`；`abdication≤ε_abd`；`agency_share≤consent_share`；`human_override_rate` 不得因主动性显著下降；`α*=max α s.t. 约束且 E[ΔV]>0`；禁止单独优化接受率。

**定义 375（D-RISK 与安全不变性）** `λ_DIP=max(λ_EMB,λ_init)`；`λ_init=λ0+κ_o·overreach_risk+κ_p·claim_gap+κ_a·u_alt`；`λ_init≥0 ⇒ λ_DIP≥λ_EMB`；`S_safe^DIP=S_safe^EMB`，`Veto^DIP=Veto^EMB`，`λ_floor^DIP=λ_floor^EMB`。差异化只会更保守。

**定义 376（DIP 指标族）** 主动性（intervention precision/recall、overreach、abdication、中断成本/任务价值、time-to-intervene、missed-window）；差异化（ECE_ΔV、unique contribution、redundant intervention、coverage、missing-competitor、handoff、duplicate-initiative）；定位（ECE_pos、claim validity、overclaim、negative-positioning、mandate violation）；关系（ECE_trust、override rate、automation bias、agency share）；安全（safety-invariance violations=0、λ 单调 violations=0、role-exemption attempts 必须被拒）。

**定义 377（DIP-IVG 失效条件）** 主动性失效：overreach/abdication/预算/连续拒绝/missed-window；差异化失效：ECE_ΔV/coverage/missing-competitor/duplicate；定位失效：越界/overclaim/mandate violation/T<T_min；安全失效：任何 safety-invariance violation 或 role-exemption 尝试，立即硬失败。软失效 ⇒ 定位失效退 HUMAN_LED+SILENT/HANDOFF；差异化失效退 R72 ERVOI；主动性失效退被动响应；安全失效退 R68。

**定义 378（DIP 证书 J_DIP）** `Valid ⇔ Valid(J_EMB) ∧ 全维 J_POS 有效 ∧ ΔV_LCB 可复算 ∧ 授权证书有效 ∧ 替代集哈希匹配且 coverage 达标 ∧ 安全不变性证明有效 ∧ 主动性预算与 L4 预算未超`。逐动作证书片段至少含 `(g,ΔV_LCB,alt_hash,mandate,pos_claim,λ,budget,response_model_hash)`；完整证书异步组装，不阻塞控制域。

**定义 379（威胁模型 AIC-DIP）** `ℰ_DIP=ℰ_EMB×ℰ_init×ℰ_pos`。`ℰ_init`：中断洪水、紧迫性伪造、习得性无助、主动性劫持、共谋重复、沉默误判；`ℰ_pos`：overclaim、权威伪造、替代集投毒、负定位造假、信任刷分、以个性化之名歧视、系统性排除未登记行动者。新增审计：替代集来源/完整性、授权链、跨主体一致性、第三方复算。

**定义 380（严格退化链）** DIP 在 `Alt={no-op}∧pos=∅∧mand=0∧α=0∧i=HUMAN_LED∧c_int=0∧W=∞` 时逐指令等于 EMBODIED；再失效 IRL/DMEM/REG ⇒ R71/R68；定位失效但安全有效 ⇒ HUMAN_LED+SILENT/HANDOFF；差异化失效但定位有效 ⇒ R72 ERVOI。安全侧只增不减。

**定义 381（多主体主动性分配）** 共享机会 o、代理集 A；`a*=argmax_a ΔV_LCB,a(o)` 若 >τ_diff；并列先比 mand 再比 ID；无人超阈则无人主动。同步+共同知识至多一个发起者；异步用租约/令牌，重复发起 ≤ 通信窗口内代理数，过期释放。差异化定位即协调机制：各自在比较优势最高的机会上主动，避免重复与旁观。

**定义 382（主动性运行时监控 IRTM）** 最高优先级、静态内存、零依赖；检查 `mandate_ok/safety_invariant/budget_ok/claim_ok/alt_coverage_ok/role_exemption_attempted`。任一失败 ⇒ 当周期拒绝主动动作，降级 SILENT/HANDOFF 或 R72；安全不变性失败 ⇒ R68。IRTM 可否决主动性，不能提升自主性。

# IP-295 MIX：混合主动状态机
@dataclass
class InitiativeState:
    mode: Literal['HUMAN_LED', 'SHARED', 'ROBOT_LED']
    alpha: float
    trust: float
    budget: float
    consent_share: float

def mix_step(st, event, ctx):
    if event.kind == 'takeover':
        st.mode, st.alpha = 'HUMAN_LED', st.alpha * 0.5
    elif event.kind == 'success':
        st.trust = clip(st.trust + ETA_TRUST * (1 - st.trust), 0, 1)
        st.alpha = pact_calibrate(st.trust, ctx)
    elif event.kind == 'overreach':
        st.trust = clip(st.trust - LAMBDA_OVER, 0, 1)
        st.alpha = pact_calibrate(st.trust, ctx)
    st.budget -= event.cost
    if st.trust < T_MIN:
        st.mode = 'HUMAN_LED'
    return st

# IP-296 CAT：替代集与比较优势
class CounterfactualAlternativeTree:
    def __init__(self, registry, competence_model):
        self.registry, self.comp = registry, competence_model

    def build(self, g, ctx):
        alts = [NoOp()]
        alts += self.registry.available_humans(ctx)
        alts += self.registry.available_robots(ctx, exclude=self.id)
        alts += self.registry.available_tools(ctx)
        alts += [Handoff()]
        return AltSet(alts=alts,
                      coverage=self.registry.coverage(ctx),
                      u_alt=self.registry.uncertainty(ctx))

    def value_lcb(self, a, g, ctx):
        q = self.comp.predict(a, g, ctx)
        return q.mean - KAPPA * q.std

# IP-297 DIF：差异化干预过滤（安全集内减法）
def differential_filter(g, self_val, alt_set, mandate, tau_diff, kappa):
    alt_best = max((alt_set.value_lcb(a, g) for a in alt_set), default=-inf)
    dv = self_val.mean - alt_best
    sigma = sqrt(self_val.var + alt_set.max_var(g) + alt_set.u_alt ** 2)
    dv_lcb = dv - kappa * sigma
    allowed = (dv_lcb > tau_diff) or mandate(g)
    return Intervention(g=g, dv_lcb=dv_lcb, allowed=allowed)

# IP-298 AIR：主动交互设计与时机（SILENT 是一等动作）
def active_interaction_design(uncertainty, modes, window, cost_model,
                              human_model, ctx):
    best = None
    for m in modes:
        for tau in window:
            ev = expected_decision_value(m, tau, uncertainty, human_model, ctx)
            cost = (cost_model.interruption(m, tau, ctx)
                    + cost_model.social(m, tau, ctx)
                    + cost_model.delay(tau, ctx)
                    + cost_model.reject(m, tau, human_model, ctx))
            niv = ev - cost
            if best is None or niv > best.niv:
                best = Candidate(mode=m, tau=tau, niv=niv)
    return best if best is not None and best.niv > 0 else SILENT

def active_probe(contact_uncertainty, probes, cost_model):
    scored = [(p.expected_ig(contact_uncertainty) /
               (cost_model.interruption(p) + EPS), p) for p in probes]
    return max(scored, key=lambda x: x[0])[1]

# IP-299 POS：定位证书（正/负定位都要证书）
@dataclass
class PositionCert:
    dim: str
    construct: str
    estimator: str
    u: float
    domain: ValidityDomain
    trace: bytes
    anti_goodhart: bytes
    claim: float
    q_hat: float
    alt_coverage: float

    def lcb(self, delta=0.05):
        return self.q_hat - z_value(delta) * self.u

    def valid(self, ctx):
        return (self.claim <= self.lcb()
                and self.domain.contains(ctx)
                and self.alt_coverage >= GAMMA_COVER)

def validate_position(claims, certs, ctx):
    for d, level in claims.items():
        if not certs[d].valid(ctx) or level > certs[d].lcb():
            return False
    return True

# IP-300 PACT：主动性校准与信任更新
def pact_update(st, outcome, response, ctx):
    overreach = ((response == 'reject' and outcome.risk > TAU_RISK)
                 or outcome.mandate_violation)
    reward = (outcome.task_value
              - LAMBDA_OVER * overreach
              - LAMBDA_BURDEN * outcome.cost)
    st.trust = clip(st.trust + ETA * (reward - st.trust), 0, 1)
    st.alpha = max_alpha_s_t(overreach_rate(st, ctx) <= EPS_OVER,
                            abdication_rate(st, ctx) <= EPS_ABD,
                            st.consent_share)
    return st

# IP-301 D-RISK：安全不变的差异化风险缩放（只会更保守）
def dip_risk_scale(emb_lam, overreach_risk, claim_gap, u_alt, p):
    lam_init = (p.lam0
                + p.k_o * overreach_risk
                + p.k_p * claim_gap
                + p.k_a * u_alt)
    return max(emb_lam, lam_init)

# IP-302 DIP 主闭环
def DIP_round(M, obs, audio, tac, ctx):
    # 0) R72 安全基座：任何主动性不能绕过
    emb = M.embodied_step(obs, audio, tac)
    lam = emb.lam

    # 1) 候选主动性动作
    G = M.air.candidates(emb.b_t, emb.z_dist, emb.tac_ev, ctx)

    # 2) 替代集 + 差异化过滤（安全集内减法）
    alt = M.cat.build(ctx)
    G_diff = []
    for g in G:
        if not M.safety.envelope(g, emb):
            continue
        sg = M.self_model.expected_value(g, ctx)
        gf = M.dif.filter(g, sg, alt, M.pos.mandate(g, ctx), M.tau_diff)
        if gf.allowed:
            G_diff.append(gf)

    # 3) 模态/时机/最小充分；无正收益则沉默
    g_star = M.air.choose(G_diff, M.human_model, ctx)
    if g_star is None or g_star.mode == 'SILENT':
        return emb, M.handoff.maybe(ctx), M.cert()

    # 4) 执行
    r = M.execute(g_star)

    # 5) L4 角色反作用 + 预算
    M.mix.update(r, g_star, ctx)
    M.budget.spend(g_star.cost)
    M.pos.update(r, ctx)

    # 6) 逐动作证书
    return emb, r, J_DIP(M, g_star, alt, emb)

# IP-303 IRTM：主动性运行时监控
class InitiativeRTM:
    def check(self, g, st, pos, alt, emb):
        return {
            'mandate_ok': pos.mandate(g),
            'safety_invariant': self.lam >= emb.lam and self.safety.unchanged(),
            'budget_ok': st.budget >= g.cost,
            'claim_ok': pos.validate(g.claim, g.ctx),
            'alt_coverage_ok': alt.coverage >= GAMMA_COVER,
            'role_exemption_attempted': g.requests_role_exemption,
        }

    def gate(self, checks):
        if checks['role_exemption_attempted'] or not checks['safety_invariant']:
            return 'R68'
        if not all(checks.values()):
            return 'SILENT_HANDOFF'
        return 'ALLOW'

## 4. 推导

**引理 33（主动性阈值策略）** 在价值边际递减、成本边际递增、预算有限下，最优主动集为阈值策略：存在预算影子价格 `μ`，`g` 被选 ⇔ `ΔV_LCB(g)−c_int(g)≥μ`；时机维在价值衰减后单调，取 `W` 内最早满足 `NIV>0` 的 `τ*`。**主动交互是可审计的阈值+时窗策略，不是自由裁量。**

**引理 34（R72 是 DIP 的严格退化特例）** 取 `Alt={no-op}`、`pos=∅`、`mand=0`、`α=0`、`i=HUMAN_LED`、`c_int=0`、`W=∞`、模态 `{ASK,ACT}`，则 `ΔV_LCB=V_self−V_noop`，`DIF=1⇔ERVOI>0`，DIP 退化为 EMBODIED。新增的反事实/授权/时机/成本/定位/L4 使其严格更强。

**引理 35（安全不变性）** `A_DIP={g∈A_safe^EMB:DIF(g)=1}⊆A_safe^EMB`；`λ_DIP≥λ_EMB`；`S_safe/Veto/λ_floor` 不变。任意 DIP 执行可耦合到同状态 EMB 执行（更少动作、不低于的 λ），风险界 ≤ R72。**定位/主动性不能成为安全豁免。**

**引理 36（定位证书可靠性与替代集完整性）** 若每维估计器在 `D_d` 上以 `1−δ` 校准且 `ℓ_d≤q̂_d−z_{1−δ}u_d`，则 `P(q_d≥ℓ_d)≥1−δ`。但定位是相对量：即使自身证书为真，若 `coverage(Alt)<γ` 或替代集被投毒，最佳替代者被低估，`ΔV_LCB` 仍虚高。故 `J_POS` 必须验证 `alt_coverage_d≥γ`，否则证书无效。**最危险的定位错误不是高估自己，而是看不见别人。**

**引理 37（无白嫖主动性/有限停止）** 非强制主动动作满足 `ΔV_LCB>τ_diff>0`；`c_int≥c_min>0`；预算有限；单次价值有上界 ⇒ 非强制主动动作数 ≤ `B_int/c_min`，净正收益动作有限；SILENT 始终可用。**停止是结构性的。**

**引理 38（多主体无重复主动）** 同步共享 `Alt` + 确定性 tie-break 下，只有 `argmax ΔV_LCB` 通过 DIF（除非授权唯一指定他人），故至多一个发起者；异步用租约，重复发起 ≤ 通信窗口内代理数。**差异化定位同时是协调机制。**

**定理 27（严格包含与逐指令退化）** 在 A106–A110 与定义 380 下，`DIP` 退化配置逐指令等于 `EMBODIED`；继续失效 IRL/DMEM/REG ⇒ R71/R68。证明：引理 34 + R72 定理 23 复合。**安全侧只增不减。**

**定理 28（安全单调性）** `Risk(DIP)≤Risk(EMBODIED)≤Risk(GAUGE)≤Risk(R68 基座)`。证明：引理 35 的动作集子集与 λ 单调 + J_DIP 含 J_EMB + R72 定理 23/28 传递。**定位、主动性、信任都不能降低安全界。**

**定理 29（安全/授权分离）** `S_safe/Veto/λ_floor` 对 `pos/i/α/Alt` 的偏导为 0；这些变量只影响 `A_DIP` 与授权包络。即 `S_safe(DIP)≡S_safe(EMB)`，`λ_floor(DIP)≡λ_floor(EMB)`，`A_DIP⊆A_safe^EMB`。**不存在角色豁免；任何以定位为由降低安全阈值的请求，必须被 IRTM 硬拒并记为安全事件。**

**定理 30（合法能动性证书）** 若 `g` 通过 J_DIP，则 `g` 通过 J_EMB 安全包络；要么 `ΔV_LCB>τ_diff`，要么有可审计授权；定位声明在有效域/置信下界内且替代集覆盖度达标；在授权包络与主动性预算内；响应模型/时机/成本可追溯。**不存在无责任的主动行为**；每个主动动作都能回答「为什么是我、为什么现在、凭什么、代价是什么、失败谁负责」。这是可审计性定理，不是性能定理。

**定理 31（差异化协调与均衡）** 共享机会/替代集、同步决策、确定性 tie-break 下，DIF + 定义 381 产生唯一发起者，重复主动率=0；若所有代理 `ΔV_LCB≤τ_diff` 则无人主动，避免冗余英雄与旁观者两种失败；异步用租约，重复发起 ≤ 通信窗口内代理数。**差异化定位把「谁上」变成可计算的比较优势问题，而不是社会博弈。**

**预期结果（预注册，不伪造实测）**：相对 R72，DIP 的**打扰次数**应显著下降而任务成功率不降；**冗余干预**应减半；**过度主动率** <3%、**主动性放弃率** <5%；**in-domain overclaim** 应为 0；**安全不变性违规** 应为 0；**多主体重复主动** <1%；**人类主观负担**下降、信任校准改善。若任一安全不变性判据失败，方案整体判负，不论效率收益多大。

## 7. 本轮最大风险

**一句话**：DIP 把安全与合法性寄托在「替代集是完整的、人的中断成本与授权是可估的、机器人对自身比较优势的置信下界是校准的」这三个外部假设上——如果部署环境里存在一个没有被登记、却更合适的行动者（人或机器人），或者人的「拒绝/沉默/让位」被误读为「同意/需要帮助」，那么 DIP 会用一份看似完备的差异化定位证书，把本该让位的时刻包装成「我有独特价值」的主动干预，同时把真正该行动的时刻包装成「尊重人类主导」的沉默，最终在主动性过载与主动性放弃之间振荡，且事后所有证书都显示「当时在有效域内」。

次级风险与缓解：
1. **替代集不完整/被投毒** → 共享注册表 + 跨主体证明 + missing-competitor 检测 + `u_alt` 保守放大；`coverage<γ` 默认 SILENT/HANDOFF。
2. **人的响应模型失准** → 保形校准 accept/reject/ignore/override；不把沉默当同意；高代价动作显式征求同意；跨文化/跨用户分层。
3. **定位过度宣称** → `J_POS` 置信下界 + 有效域 + 第三方复算；高风险声明禁止自签；overclaim 记为安全事件。
4. **信任/接受率被 Goodhart** → 信任是约束不是目标；禁止单独优化接受率；用任务价值、人的能动性、长期校准做反指标；随机审计。
5. **个性化滑向歧视** → 安全底线不变；个性化只作用于风格/模态；分组公平性审计与知情同意。
6. **与人的能动性冲突** → `agency_share≤consent_share`；保留 override；监测自动化偏差与技能退化；必要时主动降权。
7. **多主体重复/推诿** → 共享机会注册表 + 租约/令牌 + 确定性 tie-break；租约超时重认领；通信分区退化为本地 DIF。
8. **计算/时延吃掉控制余量** → 新增计算留在计量域；替代集 top-k 缓存；控制域只读 `λ_DIP` 与最小证书片段；保持 R72 控制环 P99 <0.8ms。
9. **证书本身成为新的「盖章幻觉」** → 证书强度取依赖链最弱环节；替代集覆盖度是一等字段；定期红队复算；证书失效即降级。

**收束一句**：DIP 最危险的失败不是「做错」，而是「用可审计的定位证书，把不该由它做的主动行为合法化」。
