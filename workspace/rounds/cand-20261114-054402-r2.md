# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态不确定性二分闭环」IP-253~263；本轮灵感：「电池管理」×「群体智能」）

> R66–R69 一路给同一个「不变的身体」加智能：R66 决定谁控制，R67 预测未来，R68 校准测量，R69 主动求证。这四层都默默假设了同一组东西——**执行器能力恒定、安全包络时不变、证据源彼此独立**。本轮两个灵感恰好把这三条假设逐一击穿：
>
> - **电池管理**说：身体会衰老。SoH（容量衰减、内阻上升、功率能力收缩）不可直接观测、路径依赖、单调退化；只有施加**激励**才能辨识它，而激励本身**不可逆地消耗寿命**。于是「求知」第一次有了不可撤销的代价——**为了知道还能活多久，必须先花掉一点寿命**。
> - **群体智能**说：第二意见来自同伴。但 swarm 既可能是集体智慧，也可能是**共谋的错觉**（共模漂移 / Byzantine 少数）。「多少人同意」远不如「这些人的失效有多独立」重要。
>
> 核心命题：**把 R69 的「不确定性管理 + 主动求证」升级为「会衰老、靠同伴互证、能量可共享的代谢闭环」：安全包络、风险缩放、交互预算全部变成健康状态的函数（只会更保守）；探询的收益用不可逆损伤折价；群体证据按「有效独立源数 k_eff」而非人头数采信；能量流即风险流。** 命名 **PULSE-RAS**（Probe-budgeted Uncertainty-aware Lifecycle & Swarm Estimation）。
>
> 一句话定位：R66「谁控制」→ R67「未来怎样」→ R68「测量还准吗」→ R69「该向谁求证」→ R70「**我的身体还剩多少、值不值得为知道它而消耗它、谁的话可信**」。不确定性不只是刹车踏板，也不只是一句提问——它还是**体检的剂量**与**同伴的独立性**。

## 0. 直觉与动机

**灵感 1（电池管理 → 安全包络是正在收缩的存量，不是常数）**
直觉：R68/R69 把 λ_floor、交互预算、C-RAS-WM 的功率上界都当成了时不变约束。但电池的健康状态决定了「同一个动作现在是否还安全」：内阻 R 随老化上升，同样的电流会产生更大的压降与发热，内阻翻倍后一个原本在包络内的加速动作可能直接触发欠压/过温保护。更根本的是，**安全性随寿命单调收紧**——昨天能做的长前缀，今天可能因为可用功率不足而在执行途中失效。因此不能只在「当前动作」上收紧，而要让**整个安全包络随健康后验下界一起折旧**。这把 R68 的「测量准不准」推进为「**身体还撑不撑得住这套测量与控制**」。

**灵感 2（电池管理 → 可辨识性必须用激励购买，而激励加速衰老）**
直觉：SoH 不是一个能直接读出的数。要估计容量衰减/内阻增长，必须让电流「足够丰富」地激励，使不同健康参数在响应上可分（persistent excitation）。被动恒功率巡航下，容量与偏置、内阻与温度效应会退化（FIM 接近奇异），估计器给出的点估计**看起来收敛，实则不可辨识，且置信区间系统性过窄**——它会在不报警的情况下把安全包络高估。这和 R69 的 epistemic 同构，但更残酷：R69 的「问一次」付出的是可恢复的社交/物理成本；PULSE 的「探一次」付出的是**不可逆的寿命**。于是 VoI 必须被损伤算子折价：`VoI_D = VoI − κ_D·ΔD − c`。由此得到一个**体检悖论**：探得太少，健康不可辨识，包络被高估（危险）；探得太多，探针本身把寿命耗尽（也危险）——中间必有内点最优频率。

**灵感 3（群体智能 → 第二意见来自同伴，但共识可能是集体错觉）**
直觉：单体自检永远无法分辨「我真健康」与「我的标定层把我骗了」（R68/R69 的剩余风险）。群体能提供外部见证：同伴观测同一环境、共享时段，可交叉验证健康与感知。但 swarm 有两个反面：**(a) 共模漂移**——所有同伴用同款传感器、同款标定、同一环境，会一起错；**(b) Byzantine 少数**——小比例被污染或撒谎的同伴可以把共识拽偏。关键量不是「多少票」，而是**失效相关矩阵的有效独立源数 `k_eff`**。R69 的「k 个正交证据源」必须升级为「**相关性感知的法定人数**」：只有去相关后的 `k_eff ≥ k_min` 且两两失效相关 `ρ ≤ ρ_max` 时，共识才被采信；否则退回单源纪律、再退回 R69。

**灵感 4（电池 × 群体 → 能量是可共享、总量守恒且持续退化的资源；安全从单体变网络）**
直觉：当群体可以交换能量（系留充电、无线传能、换电），一个体的健康会影响另一个体的能力，「谁该花掉边际那焦耳」就变成**分布式风险分配**：能量应流向「最能降低全局风险」的节点，而不是「最会喊饿」的节点。安全包络也从单体不变式升级为**网络不变式**：任意子集的联合功率需求不得超过该子集的联合（折旧后）能力，且任何节点的调度都不得把它压到关键储备以下。这是 PULSE 的「代谢」层——**能量流 = 风险流**。

**灵感 5（严格包含 → R69 是「不老、独居、不探测」的边界）**
直觉：理论姿态必须与前几轮一致——新层是旧层的**严格泛化**，不是并列替代。若健康恒定（dD=0）、禁止激励、群体大小为 1、不交换能量，PULSE 必须逐指令退化为 R69（再无交互时退化为 R68）。这样 R68/R69 不是被推翻，而是被包含在「静态身体」的边界上，安全侧永不因新增层而让步。这也是本轮对 R68「标定吸收缓变故障」的正面回应：标定层能吸收**瞬时残差**，但吸收不了「同款设备群体里健康分布的尾部偏移」——时间维度与群体维度是两个标定层够不着的自由度。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（PULSE-RAS 总览）** PULSE-RAS = (PHS, IDE, SWC, EMR, LPR, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i、R69 定义 293-i）；
(ii) **损伤预算硬约束**：累积激励损伤 `D_used ≤ D_max`；任何可能触发未建模退化区（如析锂窗口、过温窗口）的探针一律禁止；健康状态**禁止只报点估计**，必须携带区间，且包络认证只用区间下界；
(iii) **相关性感知证据纪律**：群体共识仅在 `k_eff ≥ k_min` 且 `max ρ_ij ≤ ρ_max` 时采信，否则视为单源并套用 R69 纪律；
(iv) **能量守恒与网络安全**：任意子集联合功率 ≤ 其折旧后联合能力；任何调度不得使节点低于关键储备。

**定义 311（隐藏健康状态与路径依赖退化）** 健康状态 `h_t = (C_t, R_t, T_t, D_t)`：容量、内阻、热历史、累积损伤。动力学 `h_{t+1} = h_t + ∫ a(I_τ, T_τ, DoD_τ, ξ_τ) dτ + w_t`，其中 `a` 对损伤分量单调、非负、不可逆（`D` 只增不减）；`C = C_0(1−βD)`，`R = R_0(1+γD)`。`h` 不能直接测量，只能经端电压/电流/温度间接观测；退化**路径依赖**（Ah 吞吐、C-rate、DoD、温度共同决定）。

**定义 312（能力包络折旧）** 认证安全集 `𝒮_t = 𝒮(h_t)`，其中功率上界 `P_max(h)`、能量储备 `E_reserve(h)` 均随 `h` 退化。折旧因子 `δ_t = P_max(h_t)/P_max(h_0) ≤ 1`。关键性质：`t' ≥ t ⇒ 𝒮(h_t) ⊆ 𝒮(h_{t'})`（**包络非扩张**）。任何认证都必须用健康下界：`𝒮_cert = 𝒮(h⁻) ⊆ 𝒮(h_true)`（"健康侧保守"，与 R68 的 λ_floor 同构）。

**定义 313（激励条件可辨识性）** 健康参数 `θ(h)` 在输入电流轨迹 `u` 下可辨识当且仅当 Fisher 信息矩阵 `F(u)=Σ_t J_tᵀΣ^{-1}J_t`（`J_t=∂ŷ_t/∂θ`）满足 `λ_min(F(u)) ≥ λ_id`。定义可辨识裕度 `κ_id(u)=λ_min(F(u))`。被动恒功率巡航对某些参数（容量—偏置、内阻—温度）存在退化方向，`κ_id→0`，此时点估计不可认证。

**定义 314（损伤算子与损伤折价 VoI）** 激励 `g`（脉冲/阶跃/局部深放电）造成不可逆损伤增量 `ΔD(g)=∫a(·)`。定义有效信息价值 `VoI_D(g) = I(θ; y_g) − κ_D·ΔD(g) − c(g)`，其中 `κ_D` 把"损伤换算为等效风险"（例如以损失寿命焦耳计）。选择 `g* = argmax VoI_D`，s.t. 损伤预算未超、热裕度 ≥ τ_th、不落入未建模退化区、且 `g` 通过 C-RAS-WM 的探针认证。若 `VoI_D ≤ 0`：不探测，保持区间健康后验并沿用 R69 保守路径。

**定义 315（健康后验与区间保证）** 维护健康状态的后验/区间 `[h⁻, h⁺]`（粒子滤波或区间观测器）。报告点估计而无区间视为违规（不变式 ii）。包络认证只用 `h⁻`；群体融合也必须在区间层面做保守交/并（乐观融合被禁止）。这是 R68「反吸收」思想在"身体"上的落地：宁可低估健康，不可高估。

**定义 316（群体见证图与失效相关矩阵）** 见证图 `G_w=(V,E_w)`，边表示两体可在同时段/同环境比较。由共享协变量与联合残差估计两两失效相关 `ρ_ij`，得相关矩阵 `R`；有效独立源数 `k_eff = (Σ_i λ_i)² / Σ_i λ_i²`（`λ_i` 为 `R` 的特征值；独立时 `k_eff=n`，完全共模时 `k_eff=1`）。

**定义 317（相关性感知法定人数 SWC）** 共识被采信当且仅当：(a) `k_eff ≥ k_min`；(b) `max_{i≠j} ρ_ij ≤ ρ_max`；(c) 用鲁棒聚合（截尾中位数）而非均值。任一不满足 ⇒ 降级为"单源"，套用 R69 定义 293-iii 的 k 源一致纪律；再不足则 U_epi 保持未消解、走 R69 兜底。**共模漂移使 `k_eff` 塌缩到 1，冗余的表决随即失效。**

**定义 318（能量代谢网络与风险路由 EMR）** 有向能量转移图，节点 `i` 具折旧能力 `P_i^max(h_i⁻)` 与关键储备 `E_i^crit`。路由 `π` 分配 `x_{ij} ≥ 0`，按效率 `η` 传输：节点 `j` 实得 `η x_{ij}`。网络联合安全：
`∀S⊆V: Σ_{i∈S} P_i(t) + Σ_{i∈S,j∉S}(1−η)x_{ij} ≤ Σ_{i∈S} P_i^max(h_i⁻) + Σ_{j∉S} η x_{ji}`。
在满足上式与储备约束下，选择使**期望全局风险**最小的路由（风险权重由 LPR 给出）。**能量流即风险流**。

**定义 319（寿命感知风险传播 LPR）** 所有 R68/R69 旋钮变为健康条件化：
- 风险缩放 `λ_t = clip(λ_base + (1−δ_t)·Λ_max, λ_floor, 1)`（能力越低，floor 越高，绝不因引入新层而更冒险）；
- 交互/探测预算 `B_t = B_0·δ_t`（身体越差，越没资格为求知而消耗）；
- 认证前缀长度 `k_t = min(k_{R69}, k_max(h⁻))`（可用功率下降 → 可执行的安全前缀缩短）。
三者均对 `h⁻` 单调：`h⁻` 越低越保守。

**定义 320（两/三时间尺度调度）** 快环（ms）：完整继承 R69，不变；代谢环（s–min）：运行 PHS/IDE/EMR，是**唯一**可写健康状态的地方；生命周期环（小时/循环）：更新包络与 λ 调度。快环只读取慢环下发的健康下界与调度，保证实时性不被健康估计击穿。

**定义 321（证书 J_PULSE）** `J_PULSE = (J_FLUID, h_interval, δ_t, k_eff, ρ_max, D_used, routing_hash, κ_id, pulse_ver)`。Valid ⇔ `Valid(J_FLUID)` ∧ 区间已认证 ∧ k_eff/ρ 门通过（或已降级为单源纪律）∧ 损伤预算未越界 ∧ 网络联合安全成立。

**定义 322（生命周期审计与威胁模型 AIC-LIFE）** 新增攻击面：虚报健康（装健康骗能量）、能量虹吸（恶意路由）、共谋健康通胀（全体一致声称健康）、诱使他人过度探测（探针攻击）、传感器老化伪装成真故障。并入干扰集：`ℰ_PULSE = ℰ_FLUID × ℰ_age × ℰ_swarm × ℰ_energy`（退化未建模 / Byzantine 与共谋 / 路由劫持）。VQAuditor-L 审计探测决策与健康融合，结论回灌损伤预算先验与 `k_min/ρ_max` 门限。

**定义 323（严格退化 / canonical rollback）** 若 `h` 恒定（`dD=0`）、禁激励（IDE 关闭）、`N=1`（无群体）、无能量转移（EMR 关闭），则 PULSE 逐指令输出 R69 的动作；R69 在「永不交互」时再逐指令退化为 R68。故 `PULSE ⊃ R69 ⊃ R68`，安全侧严格不弱于旧层。

**定义 324（可辨识性—损伤 Pareto 前沿）** 在健康状况空间上，可达前沿刻画「健康估计方差 ↔ 累积损伤」的权衡：`Frontier = { (Var(ĥ), D_used) : (IDE, LPR) 可行 }`。最优体检节奏取前沿拐点（边际信息增益 = 边际损伤风险）；寿命越接近终点，拐点越偏向「少探、保守」。

```python
# IP-264 PHS：隐藏健康状态估计（路径依赖 + 区间保证）
class HealthStateEstimator:
    def step(self, I, V, T, dt):
        self.h = self.h + aging_model.increment(I, T, self.dod, dt)  # 不可逆，D 单调
        self.belief = self.filter.update(V, I, T, self.h)            # 粒子/区间观测器
        lo, hi = self.belief.interval(0.99)
        return HealthInterval(lo, hi)                                # 只下发区间，不报点

# IP-265 IDE：可辨识性 + 损伤折价的探测规划（体检悖论的内点解）
def plan_excitation(belief, budget, thermal, c_ras_wm):
    best = None
    for g in probe_candidates(belief):                 # 脉冲 / 阶跃 / 局部深放电
        kappa = fisher_identifiability(g, belief)      # 可辨识性增益 κ_id
        dD    = damage_model(g, belief)                # 不可逆损伤增量
        if budget.used + dD > budget.dmax:          continue
        if thermal.margin(g) < thermal.tau:         continue
        if not c_ras_wm.certify_probe(g):           continue   # 探针也过安全认证
        score = voi_health(belief, kappa) - KAPPA_D * dD - cost(g)
        if best is None or score > best.score: best = (g, score, dD)
    return best if best and best.score > 0 else None  # 无利可图 -> 不探，走 R69

# IP-266 SWC：相关性感知群体共识（按 k_eff 而非人头数）
def swarm_consensus(own_health, witnesses, rho_mat):
    k_eff = (sum(eig(rho_mat))**2) / sum(e**2 for e in eig(rho_mat))
    if k_eff >= K_MIN and max_pairwise(rho_mat) <= RHO_MAX:
        return robust_aggregate([own_health] + witnesses, method='trimmed_median')
    return None                                        # 共模/共谋疑 -> 单源纪律 -> R69

# IP-267 EMR：能量代谢与风险路由（能量流 = 风险流）
def route_energy(nodes, h_intervals, risk_weights):
    caps    = {i: power_cap(nodes[i], h_intervals[i].lo) for i in nodes}  # 用下界
    reserves= {i: nodes[i].critical_reserve for i in nodes}
    return min_cost_flow(risk_weights, caps, reserves, capacity_loss=ETA)

# IP-273 主闭环（快环完全继承 R69；慢环写健康、调旋钮）
def PULSE_round(M, obs):
    # --- 快环：R69 原样，不改 ---
    k69, lam69, mode, U = M.fluid_round(obs)
    # --- 代谢环（decimated，s–min）---
    if M.metabolic_loop.due():
        h = M.phs.step(obs.I, obs.V, obs.T, M.metabolic_loop.dt)
        g = M.ide.plan_excitation(h, M.damage_budget, M.thermal, M.c_ras_wm)
        if g is not None: M.execute_probe(g)                 # 计入不可逆损伤
        peer = M.swc.consensus(h, M.witnesses, M.rho_mat)
        h    = M.fuse(h, peer) if peer else h                # 保守区间融合
        delta= capability_depreciation(h)                    # 包络折旧 δ_t
        routing = M.emr.route_energy(M.nodes, M.h_intervals, M.risk_weights)
        M.lpr.update(delta, routing)                         # 更新 λ / 预算 / k_max
        # --- 生命周期环（小时/循环）---
        if M.lifecycle_loop.due():
            M.envelope.shrink_to(h.lo)                       # 用下界收缩安全集
    # --- 快环只读取慢环下发的健康条件化旋钮 ---
    lam = M.lpr.apply(lam69)                                 # 只会更保守
    k   = min(k69, M.lpr.k_max(h))                           # 能力收缩 -> 前缀缩短
    return k, lam, mode, h
```

## 3. 推导

**假设** A99（退化动力学在受保护区内光滑、单调；未建模退化模式只发生在受保护区外）、A100（设计激励下健康参数在有限区间内可辨识）、A101（两两失效相关可由共享协变量有界估计）、A102（传能效率 `η` 有界已知）、A103（热失控前兆在 ≥ τ_warn 的反应时窗外可观测）、A104（Byzantine 比例 `< f_max` 且鲁棒聚合可用）。

**引理 19（被动不可辨识性 → 静默过度自信）** 若输入持续非激励（`κ_id(u) < λ_id`），则至少一个健康参数不可辨识：存在 `θ ≠ θ'` 使输出轨迹同分布而 `h` 不同。于是任何仅基于点估计的包络认证存在非零概率高估安全集（`𝒮_cert ⊄ 𝒮(h_true)`）。故"不探测"不是中性选择，而是**系统性地把不确定性藏进置信区间**。系：用区间下界 `h⁻` 认证可恢复可靠性，代价是保守。

**引理 20（损伤折价 VoI 的内点最优 / 体检悖论）** 设信息增益 `VoI(probing)` 对激励强度先增后饱和（凹），累积损伤对强度凸增，则 `VoI_D` 在预算内存在内点最大。过探（`D_used → D_max`）与不探（`κ_id→0`）都提高期望风险；最优探测节奏 `T*` 随退化率上升、随安全权重上升而**变稀疏**。系：体检频率本身是一个可证明的安全参数，不是经验调参。

**引理 21（相关性感知 Byzantine 上界）** 设有 `n` 个见证、至多 `f` 个 Byzantine、鲁棒聚合。独立噪声项可按 `~1/k_eff` 被冗余抵消，但共模偏差 `b_common` 不随 `n` 缩小；当 `ρ→1`（`k_eff→1`）时聚合误差下界被 `b_common` 占优，冗余完全不改善。故**未去相关的表决是幻觉式冗余**；`k_eff` 是唯一的有效冗余度量。

**定理 18（PULSE 严格包含 R69/R68）** 在 A99–A104 下，PULSE 的任意状态期望风险 ≤ R69；且当 `h` 恒定、IDE 关闭、`N=1`、EMR 关闭时两者**逐指令相同**，此时 `δ_t=1`、`λ_t=λ_base`、`k_t=k_{R69}`。R69 再在 `VoI−c≤0` 时退化为 R68。安全侧不做任何让步，效率侧的额外收益来自"更准的健康下界 → 更紧但仍可靠的包络"。

**定理 19（网络安全不变式）** 在定义 318 的联合约束与关键储备约束下，任意风险路由保持：每个节点运行在 `𝒮(h_i⁻)` 内、任意子集联合功率不超其折旧联合能力、无节点被抽干至储备以下。证明要点：约束对子集取并/交保持不变式；`η<1` 使绕行只会更紧，故最优路由不会破坏安全边界。

**定理 20（生命周期单调退化 / 优雅降级）** 因 `𝒮_t` 非扩张、`δ_t` 非增、`λ_t` 非减、`k_t` 非增，PULSE 的保守度沿寿命单调上升、能力单调下降，控制连续无突变；唯一潜在"安全悬崖"是热失控触发区，被定义 310-ii 的"禁入未建模退化区"与 A103 的预警窗显式隔开。系：系统可以"优雅地变弱"，但不允许"优雅地越过悬崖"。

## 6. 本轮最大风险

**一句话**：PULSE-RAS 的全部安全保证都押在「退化动力学 `a(·)` 与被保护区刻画是准确的」这一前提上——**若探针本身触发了一个模型不知道的退化模式（例如大电流脉冲诱发析锂），系统就会为了获得可辨识性而亲手制造一种它无法表征的故障；更糟的是，若全体同伴执行同一套同步探测策略，这种故障会在群体中同步发生、并被去相关后的"一致"见证盖章为"健康"——体检的副作用被集体共识合法化**。探得太少会静默高估健康，探得太多会制造模型外的病且被群体背书，这正是 PULSE 最深的脆弱点。

**次级风险与缓解**：
1. **共模漂移/共谋** → `k_eff/ρ` 门控 + 鲁棒聚合 + 群体异构化（不同传感/标定）+ E305/E306；
2. **能量路由被劫持** → 守恒与储备硬约束 + 审计 + E307/E315；
3. **热失控安全悬崖** → 保护区禁入 + 预警窗假设 A103 + E311；
4. **健康估计漂移导致包络高估** → 只用 `h⁻` 认证 + 区间覆盖率校准 + E301/E304；
5. **慢环击穿实时性** → 两/三时间尺度解耦，快环零改动，慢环异步（定义 320）。

## 3. 关键算法伪代码

```python
# IP-264 PHS：隐藏健康状态（路径依赖 + 区间）
class HealthStateEstimator:
    def step(self, I, V, T, dt):
        self.h = self.h + aging_model.increment(I, T, self.dod, dt)   # D 单调不可逆
        self.belief = self.filter.update(V, I, T, self.h)
        return self.belief.interval(0.99)                              # 只下发 h⁻/h⁺

# IP-265 IDE：可辨识性 + 损伤折价的探测（体检悖论内点解）
def plan_excitation(belief, budget, thermal, c_ras_wm):
    best = None
    for g in probe_candidates(belief):
        kappa, dD = fisher_gain(g, belief), damage_model(g, belief)
        if budget.used + dD > budget.dmax or thermal.margin(g) < thermal.tau: continue
        if not c_ras_wm.certify_probe(g): continue          # 探针也过安全认证
        score = voi_health(belief, kappa) - KAPPA_D*dD - cost(g)
        if best is None or score > best.score: best = (g, score, dD)
    return best if best and best.score > 0 else None        # 无利可图 -> 不探

# IP-266 SWC：相关性感知共识（按 k_eff 而非人头数）
def swarm_consensus(own, witnesses, rho_mat):
    lam   = eigvalsh(rho_mat)
    k_eff = lam.sum()**2 / (lam**2).sum()
    if k_eff >= K_MIN and max_pairwise(rho_mat) <= RHO_MAX:
        return robust_aggregate([own] + witnesses, method='trimmed_median')
    return None                                             # 共模/共谋 -> 单源 -> R69

# IP-267 EMR：能量风险路由（能量流 = 风险流）
def route_energy(nodes, h_intervals, risk_weights):
    caps = {i: power_cap(nodes[i], h_intervals[i].lo) for i in nodes}   # 用下界
    return min_cost_flow(risk_weights, caps, nodes.reserve, loss=ETA)

# IP-273 PULSE：快环继承 R69，慢环写健康并调旋钮
def PULSE_round(M, obs):
    k69, lam69, mode, U = M.fluid_round(obs)                # 快环：零改动
    if M.metabolic_loop.due():
        h = M.phs.step(obs.I, obs.V, obs.T, M.metabolic_loop.dt)
        g = M.ide.plan_excitation(h, M.damage_budget, M.thermal, M.c_ras_wm)
        if g: M.execute_probe(g)                            # 记入不可逆损伤
        peer = M.swc.consensus(h, M.witnesses, M.rho_mat)
        h    = M.fuse(h, peer) if peer else h               # 保守区间融合
        delta= capability_depreciation(h)                   # δ_t
        route= M.emr.route_energy(M.nodes, M.h_intervals, M.risk_weights)
        M.lpr.update(delta, route)                          # λ / B / k_max 调度
        if M.lifecycle_loop.due(): M.envelope.shrink_to(h.lo)
    lam = M.lpr.apply(lam69)                                # 只会更保守
    k   = min(k69, M.lpr.k_max(h))                          # 能力收缩 -> 前缀缩短
    return k, lam, mode, h
```

## 4. 推导

**假设** A99（退化在受保护区内光滑单调；未建模模式只在区外）、A100（设计激励下参数有限区间可辨识）、A101（失效相关可由共享协变量有界估计）、A102（`η` 有界已知）、A103（热前兆在 ≥τ_warn 可观测）、A104（Byzantine 比例 `<f_max` 且鲁棒聚合可用）。

**引理 19（被动不可辨识性 → 静默过度自信）** `κ_id(u)<λ_id` 时至少一个健康参数不可辨识（存在同输出不同 `h`），故点估计认证以非零概率高估安全集；不探测不是中性，而是把不确定性藏进置信区间。用 `h⁻` 认证可恢复可靠性，代价是保守。

**引理 20（损伤折价 VoI 的内点最优 / 体检悖论）** 信息增益对激励强度凹、累积损伤凸，则 `VoI_D` 在预算内存在内点最大；过探（`D_used→D_max`）与不探（`κ_id→0`）都抬高期望风险；最优节奏 `T*` 随退化率与安全权重上升而变稀疏。体检频率是可证明的安全参数。

**引理 21（相关性感知 Byzantine 上界）** `n` 见证、`f` 恶意、鲁棒聚合：独立噪声项按 `~1/k_eff` 被抵消，但共模偏差 `b_common` 不随 `n` 缩小；`ρ→1`（`k_eff→1`）时误差下界被 `b_common` 占优。未去相关的表决是幻觉式冗余，`k_eff` 是唯一有效冗余度量。

**定理 18（严格包含 R69/R68）** A99–A104 下 PULSE 任意状态期望风险 ≤ R69；当 `h` 恒定、IDE 关闭、`N=1`、EMR 关闭时逐指令相同（`δ_t=1, λ_t=λ_base, k_t=k_{R69}`），R69 再在 `VoI−c≤0` 时退化为 R68。安全不让步，效率收益来自"更准的健康下界 → 更紧但仍可靠的包络"。

**定理 19（网络安全不变式）** 定义 318 的联合约束与储备约束下，任意风险路由保证每节点运行于 `𝒮(h_i⁻)`、任意子集联合功率不超折旧联合能力、无节点被抽干至储备以下；`η<1` 使绕行只会更紧，最优路由不破坏安全边界。

**定理 20（生命周期单调退化 / 优雅降级）** `𝒮_t` 非扩张、`δ_t` 非增、`λ_t` 非减、`k_t` 非增 ⇒ 保守度沿寿命单调上升、能力单调下降、控制连续无突变；唯一潜在安全悬崖是热失控触发区，被"禁入未建模退化区 + A103 预警窗"显式隔开。可优雅地变弱，但不允许优雅地越过悬崖。

## 7. 本轮最大风险

**一句话**：PULSE-RAS 的全部安全保证押在「退化动力学 `a(·)` 与被保护区刻画准确」这一前提上——**若探针触发模型外的退化模式（如大电流脉冲诱发析锂），系统就会为获得可辨识性而亲手制造一种它无法表征的故障；若全体同伴又执行同一套同步探测策略，该故障会在群体中同步发生，并被去相关后的"一致"见证盖章为"健康"——体检的副作用被集体共识合法化**。探得太少会静默高估健康，探得太多会制造模型外的病且被群体背书，这是 PULSE 最深的脆弱点。

**次级风险与缓解**：共模漂移/共谋（`k_eff/ρ` 门控 + 鲁棒聚合 + 群体异构化 + E305/E306）；能量路由被劫持（守恒与储备硬约束 + 审计 + E307/E315）；热失控安全悬崖（保护区禁入 + A103 预警窗 + E311）；健康估计漂移致包络高估（只用 `h⁻` + 区间校准 + E301/E304）；慢环击穿实时性（两/三时间尺度解耦，快环零改动 + 定义 320）。
