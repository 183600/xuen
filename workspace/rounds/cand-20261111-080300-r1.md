# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「动作分块」×「大语言模型」）

> 第 54 轮已建立动作空间剖面 α_S、技能组合图 G_S、云边动作映射 γ_ce 与动作-鲁棒性联合证书 J，形成 v31。本轮把时间粒度与语义规划引入：**动作分块（action chunking）** 让执行单元从单步动作 a 变成时间块 c=(a_{t:t+H},H,φ)，**大语言模型（LLM）** 让组合从图搜索上升为语义程序提议。核心矛盾：H22：第 54 轮的兼容性在动作集合上定义，单步看兼容的技能，在块边界处可能状态/速度/相位不连续，组合在“块接缝”处系统性失效；H23：LLM 能提出语义连贯的分块程序，但语义合理性 ≠ 动作可落地性，LLM 幻觉会在动作空间与时间边界上同时显现，而现有证书体系无法拒收“看起来对”的分块计划。

## 0. 直觉与动机

**灵感 1（动作分块 → 把技能从动作集合扩展为时域块原语）**
直觉：技能不只在动作空间 A 上占用 α_S，还以固定/自适应长度 H 输出一整段轨迹。真实执行失败常不在块内，而在块与块之间：上一块末状态与下一块首状态对不上、速度突变、相位跳变。因此组合的第一性对象应从“技能节点”变为“块节点”，鲁棒性也应在块级定义：`ρ_chunk` 覆盖块内扰动与块间切换两类来源。

**灵感 2（块边界 → 组合的新失效面）**
直觉：定义**边界证书** `B(c_i,c_j)=(Δs,Δv,Δφ,A_b,ρ_b)`：位置/速度/相位偏差、边界动作交集、边界鲁棒性。只有当 `Δs≤δ_s ∧ Δv≤δ_v ∧ Δφ≤δ_φ ∧ A_b≠∅ ∧ ρ_b≥ρ_min`，两个块才可拼接。第 54 轮的兼容性 `compat(A_i,A_j)` 只是 `A_b≠∅` 的特例；真正的组合风险在 `Δs,Δv,Δφ`。可用 ACT 式 overlap blending（`ω` 帧重叠 + 时间集成）缓解，但必须把 blending 后的证书重新验证，**绝不能用平滑掩盖断点**。

**灵感 3（LLM 作为块程序提议者 → “LLM 提议，证书裁决”）**
直觉：让 LLM 在受约束的**块 DSL 文法** `L(G_C)` 上生成类型安全的块程序 `P_LLM=⟨c_1,…,c_k; pre/post⟩`，而不是直接输出底层动作。LLM 负责语义分解（“先抓取、再对齐、后插入”），证书负责物理裁决。任何块必须通过 ACC 的块剖面覆盖与 CBC 的边界证书才能进入计划；未通过者视为**幻觉块** `h(c)=1`，进入有界修复环。这把 LLM 的语义先验与第 54 轮的可验证组合真正接上，且“幻觉”被定义为**可判定证书失败**，而非主观判断。

**灵感 4（有界修复环 → 用反向解释驱动 LLM 重写分块）**
直觉：第 53–54 轮的 Explain 能给出失败根因（哪个维度、哪个动作、哪个边界）。把它作为结构化反馈回灌 LLM：`P_{k+1}=LLM(P_k, Explain(fail))`，并限制迭代 `N_max` 与接受阈值。修复不是自由重写，而是受 **块级局部编辑算子** R 约束（改 H、换等价块、插入过渡块、调整相位），保证每次修复单调不降证书得分；否则拒绝并回退到第 54 轮的图搜索候选。

**灵感 5（自适应时域 → 分块长度本身就是决策变量）**
直觉：H 太短 → 重规划频繁、观测陈旧、误差累积路径多；H 太长 → 块内漂移大、边界难对齐、LLM 语义与底层脱节。定义可容许时域 `H*(T)`：在鲁棒性谱 ρ、边端延迟 τ_e、LLM 推理延迟 τ_LLM 约束下最大化期望成功率。LLM 给出任务阶段的**语义先验 H_prior**，证书给出**物理上界 H_max**；实际 `H=min(H_prior,H_max,⌊budget/τ⌋)`，并由块级证书回写校正。

**灵感 6（时域金字塔 → 在 𝕃/𝔸 之上叠加块层 ℂ）**
直觉：`ℂ_0` 物理控制周期，`ℂ_1` 块原语，`ℂ_2` 块程序，`ℂ_3` LLM 任务分解。跨层传递证书必须同时携带 `(ρ, A_cert, B, H, evidence)`，形成**动作-边界-鲁棒性三证书**，LLM 只能在 `ℂ_2/ℂ_3` 提议，`ℂ_0/ℂ_1` 的可行性由证书否决。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（动作块与块剖面）**
动作块 `c=(a_{t:t+H}, H, φ)`，`H∈[H_min,H_max]` 为时域长度，`φ∈Φ` 为相位标签。技能 S 的块剖面 `β_S : A × [0,H] → [0,1]`，`β_S(a,τ)` 表示块内第 τ 步在动作 a 上的占用度，并附边界状态 `(s_in,s_out)`。**块覆盖** `cover_chunk(c,A_T)=1` 当且仅当 `∀τ∈[0,H], β_S(·,τ)` 覆盖 `A_T(τ)` 且 `‖s_out - s_T(H)‖ ≤ δ_s`。

**定义 122（块边界兼容性与边界证书）**
两块的边界证书 `B(c_i,c_j) = (Δs, Δv, Δφ, A_b, ρ_b, ω)`：
- `Δs=‖s_out(c_i)-s_in(c_j)‖`，`Δv=‖v_out(c_i)-v_in(c_j)‖`，`Δφ=dist(φ_i,φ_j)`；
- `A_b = A(c_i)∩A(c_j)` 为边界动作交集；
- `ρ_b = min_d ρ_chunk(d; c_i→c_j)` 为边界切换鲁棒性；
- `ω` 为 overlap blending 窗口长度。
**边界可行** 当且仅当 `Δs≤δ_s ∧ Δv≤δ_v ∧ Δφ≤δ_φ ∧ A_b≠∅ ∧ ρ_b≥ρ_min ∧ ω≤ω_max`。若使用 blending，则须以 blending 后轨迹重新计算证书，记 `B^ω`。

**定义 123（块组合图）**
块组合图 `G_C=(V_C,E_C)`，`V_C` 为可用块实例，`E_C={(c_i,c_j) | B(c_i,c_j) 可行}`。每条边附带 **块组合证书** `C_chunk=(B, ρ_chunk, A_cert, H, evidence)`；路径证书取逐边证书的交并与最弱鲁棒性。

**定义 124（LLM 块程序与接地）**
块 DSL 文法 `G_C` 规定块类型、参数域、前后置条件与边界接口。LLM 输出 `P_LLM ∈ L(G_C)`，经**接地函数** `ground(P_LLM)` 映射为块实例序列。块 c 接地成功当且仅当 `cover_chunk(c,A_T)=1` 且其所有相邻边界证书可行。**幻觉块** `h(c)=1 ⇔ ¬grounded(c)`；程序幻觉率 `H(P)=|{c:h(c)=1}|/|P|`。计划只有在 `H(P)=0` 且全路径 `C_chunk` sound 时才可部署。

**定义 125（有界提议-验证-修复环）**
修复环 `R_loop = (P_0, Verify, Repair, N_max, ε)`：`P_0=LLM(T,G_C)`，每轮用 ACC/CBC/AEC 验证并生成 Explain；若不通过且 `k<N_max`，执行受约束编辑 `P_{k+1}=Repair(P_k,Explain_k)`，其中 Repair 只允许 {调 H, 替换同类块, 插入过渡块, 调相位}，且要求证书得分 `score(P_{k+1})≥score(P_k)-ε`。只有在固定点 `Verify(P*)=ok` 时才签发证书，否则回退到第 54 轮图搜索。

**定义 126（可容许时域）**
可容许时域 `H*(T)=argmax_{H∈[H_min,H_max]} J(H)`，`J(H)=P_success(H) - λ_r·τ_replan(H) - λ_o·τ_stale(H) - λ_l·τ_LLM(H)`，且受边端约束 `H·τ_step ≤ τ_e` 与证书约束 `max_τ ρ_chunk(τ;H) ≥ ρ_min`。LLM 提供 `H_prior`，物理与延迟约束给出 `H_max`，最终 `H = min(H_prior, H_max, H*(T))`。

## 2. 关键算法 伪代码

### IP-121 ACC（Action Chunk Characterization）

```python
def chunk_profile(skill, A, H, sampler):
    beta, boundaries = {}, {}
    for tau in range(H):
        for a in A:
            feas, conf = sampler.query(skill, a, tau)
            beta[(a,tau)] = conf if feas else 0.0
    boundaries['s_in']  = sampler.state_at(skill, 0)
    boundaries['s_out'] = sampler.state_at(skill, H-1)
    boundaries['v_in']  = sampler.velocity_at(skill, 0)
    boundaries['v_out'] = sampler.velocity_at(skill, H-1)
    return ChunkProfile(beta, boundaries, H)

def cover_chunk(profile, A_T, delta_s, theta_cov=0.8):
    inside = all(profile.beta.get((a,t),0.0) >= theta_cov
                 for t,A_t in enumerate(A_T) for a in A_t)
    reach  = norm(profile.boundaries['s_out'] - A_T[-1].goal) <= delta_s
    return inside and reach
```

### IP-122 CBC（Chunk Boundary Certificate）

```python
def boundary_certificate(ci, cj, delta, omega_max):
    ds = norm(ci.s_out - cj.s_in)
    dv = norm(ci.v_out - cj.v_in)
    dphi = phase_distance(ci.phi, cj.phi)
    A_b = action_intersection(ci.A, cj.A)
    if omega := choose_blend(ci, cj):
        ci, cj = blend(ci, cj, omega)   # 必须重算以下量
        ds, dv = recompute_boundary(ci, cj)
        A_b = action_intersection(ci.A, cj.A)
    rho_b = min(robustness_spectrum(ci, 'intra'),
                robustness_spectrum(cj, 'intra'),
                robustness_spectrum((ci,cj), 'switch'))
    ok = (ds<=delta.s and dv<=delta.v and dphi<=delta.phi
          and len(A_b)>0 and min(rho_b.values())>=delta.rho_min
          and (omega is None or omega<=omega_max))
    return ('ok' if ok else 'reject',
            BoundaryCert(ds, dv, dphi, A_b, rho_b, omega))
```

### IP-123 CCC（Chunk Composition Graph）

```python
def build_chunk_graph(chunks, delta, theta_a):
    G = nx.DiGraph()
    for ci in chunks:
        for cj in chunks:
            if ci.id == cj.id: continue
            status, B = boundary_certificate(ci, cj, delta, omega_max)
            if status == 'ok' and jaccard(ci.A, cj.A) >= theta_a:
                G.add_edge(ci.id, cj.id, cert=ChunkCert(B, ci.H, ci.A_cert))
    return G
```

### IP-124 LCG（LLM Chunk Grounding）

```python
def ground_llm_program(P_llm, skill_lib, delta):
    program = parse_typed(P_llm, grammar=G_C)
    grounded = []
    for node in program.chunks:
        c = instantiate(node, skill_lib, H=node.H)
        if not cover_chunk(c.profile, node.A_T, delta.s):
            return ('hallucination', c, 'coverage_fail')
        grounded.append(c)
    for ci, cj in zip(grounded, grounded[1:]):
        status, B = boundary_certificate(ci, cj, delta, omega_max)
        if status != 'ok':
            return ('hallucination', (ci,cj), 'boundary_fail', B)
    return ('ok', grounded)
```

### IP-125 LRP（LLM Repair Loop）

```python
def propose_verify_repair(task, llm, skill_lib, N_max=3, eps=0.05):
    P = llm.propose(task, grammar=G_C, prior=skill_lib.signatures)
    best, best_score = None, -inf
    for k in range(N_max+1):
        status, payload = ground_llm_program(P, skill_lib, delta)
        score = certificate_score(payload)
        if score > best_score:
            best, best_score = P, score
        if status == 'ok':
            return ('ok', P, k)
        explain = build_explain(payload)
        P_next = llm.repair(P, explain, edit_ops={H, swap, bridge, phase})
        if certificate_score(P_next) < best_score - eps:
            break
        P = P_next
    return ('fallback_graph_search', best, explain)
```

### IP-126 AHC（Adaptive Horizon Controller）

```python
def choose_horizon(task, rho, tau_e, tau_llm, H_prior):
    candidates = [H for H in range(H_min, H_max+1) if H*tau_step <= tau_e]
    scored = []
    for H in candidates:
        p_succ = predict_success(task, H, rho)
        latency = tau_llm(H) + tau_replan(H) + tau_stale(H)
        scored.append((p_succ - lambda_r*tau_replan(H)
                       - lambda_o*tau_stale(H) - lambda_l*tau_llm(H), H))
    H_phys = max(scored, key=lambda x: x[0])[1] if scored else H_min
    return min(H_prior, H_phys), scored
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| ACC | O(|A|·H_max·|S|) | O(|A|·H_max) | 块内采样覆盖、边界状态可测 |
| CBC | O(|A| + |𝔇_ρ|) | O(|A|+|𝔇_ρ|) | Δs/Δv/Δφ 阈值 sound、blending 后重算 |
| CCC | O(|C|²·(|A|+|𝔇_ρ|)) | O(|C|²) | 边界证书传递、路径取最弱 |
| LCG | O(|P|·|A|·H_max + |P|·|𝔇_ρ|) | O(|P|·|A|) | 接地完备、幻觉可判定 |
| LRP | O(N_max·(|P|·|A|+|P|·|𝔇_ρ|)) | O(|P|) | 编辑单调、修复有界 |
| AHC | O((H_max-H_min)·T_pred) | O(H_max) | 延迟模型可信、约束闭合 |

**正确性定理（Chunk-Grounded LLM Composition Soundness）**
承接第 54 轮 (A22)–(A28)；新增假设：
**(A29)** 块剖面 `β_S` 由结构化仿真校准，`cover_chunk` 可判定且采样覆盖 ≥ 95%；
**(A30)** 边界证书阈值 `(δ_s,δ_v,δ_φ,ρ_min)` sound，且 blending 后证书 `B^ω` 不被平滑掩盖；
**(A31)** Repair 算子只做证书不降序的局部编辑，修复环在 `N_max` 内到固定点或以回退终止；
**(A32)** LLM 在文法 `G_C` 上的提议以概率 `p_cov` 覆盖至少一个可行程序（否则依赖回退）。
则对已验证分块程序 `P*`（`H(P*)=0` 且全路径 `C_chunk` sound）：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
             - P(β_S miscalibrated) - P(Δs/Δv/Δφ 超界)
             - (1-p_cov)·P(回退失败)
```
关键：**块级覆盖先验**、**边界证书可判定**、**LLM 只在接地后获得信任**。

**消融**：去掉 CBC、去掉 LRP 回退、去掉 AHC、LLM 直接输出底层动作，分别量化边界失效、幻觉漏检、时域失配与语义-物理断层。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| LLM 语义合理但边界不可拼接 | 高 | CBC 硬否决 + 接地后才计分 + 回退图搜索 |
| 块剖面采样不足导致虚假覆盖 | 高 | 主动采样 + 边界附近加密 + 红队块注入 |
| blending 掩盖真实断点 | 高 | blending 后强制重算 B^ω + 真实机复验 |
| 修复环震荡/无限重写 | 中 | 编辑单调性 + N_max + 证书得分回退 |
| 长 H 导致块内漂移累积 | 高 | AHC 物理上界 + 块内 TRO/REX 在线校验 |
| LLM 延迟破坏实时性 | 中 | 异步预提议 + 缓存块程序 + 边端只做验证 |

## 6. 本轮最大风险

**一句话**：把动作分块与 LLM 引入后，组合从“动作兼容”升级为“块级接地 + 边界证书 + 语义提议”的三层信任链，但其 soundness **同时依赖块剖面的完备采样、边界证书在 blending 后仍然 sound、以及 LLM 提议对可行程序的可达性**；最危险的是**语义合理性伪装成物理可行性**——LLM 生成的分块程序在语言层高度连贯，却在块接缝处以微小 Δs/Δv 持续性错位，而平滑与仿真又会把这种错位抹平，因此必须以 **边界证书硬否决 + blending 后重验 + 真实机断点探针** 三重护栏，宁可回退到第 54 轮的保守图搜索，也不让“读起来很对”的分块计划通过部署闸门。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-ChunkLLM（ACC×CBC×CCC×LCG×LRP×AHC）

> 承接第 54 轮产物 v31。本轮在动作空间剖面 + 技能组合图 + 云边协同之上，增加 **动作分块、块边界证书、LLM 块程序提议与有界修复** 三条主线：
> - **ACC（Action Chunk Characterization）**：把技能占用从单步动作扩展为时域块剖面 `β_S`；

## 2. 关键算法 伪代码

### IP-121 ACC

```python
def chunk_profile(skill, A, H, sampler):
    beta, b = {}, {}
    for tau in range(H):
        for a in A:
            feas, conf = sampler.query(skill, a, tau)
            beta[(a,tau)] = conf if feas else 0.0
    b['s_in'], b['s_out'] = sampler.state_at(skill, 0), sampler.state_at(skill, H-1)
    b['v_in'], b['v_out'] = sampler.velocity_at(skill, 0), sampler.velocity_at(skill, H-1)
    return ChunkProfile(beta, b, H)

def cover_chunk(profile, A_T, delta_s, theta_cov=0.8):
    inside = all(profile.beta.get((a,t),0.0) >= theta_cov
                 for t,A_t in enumerate(A_T) for a in A_t)
    return inside and norm(profile.b['s_out'] - A_T[-1].goal) <= delta_s
```

### IP-122 CBC

```python
def boundary_certificate(ci, cj, delta, omega_max):
    ds = norm(ci.s_out - cj.s_in)
    dv = norm(ci.v_out - cj.v_in)
    dphi = phase_distance(ci.phi, cj.phi)
    A_b = action_intersection(ci.A, cj.A)
    omega = choose_blend(ci, cj)
    if omega:
        ci, cj = blend(ci, cj, omega)     # 平滑后必须重算，禁止沿用原证书
        ds, dv = recompute_boundary(ci, cj)
        A_b = action_intersection(ci.A, cj.A)
    rho_b = min(robustness_spectrum(ci,'intra'),
                robustness_spectrum(cj,'intra'),
                robustness_spectrum((ci,cj),'switch'))
    ok = (ds<=delta.s and dv<=delta.v and dphi<=delta.phi
          and A_b and min(rho_b.values())>=delta.rho_min
          and (omega is None or omega<=omega_max))
    return ('ok' if ok else 'reject',
            BoundaryCert(ds,dv,dphi,A_b,rho_b,omega))
```

### IP-123 CCC

```python
def build_chunk_graph(chunks, delta, theta_a, omega_max):
    G = nx.DiGraph()
    for ci in chunks:
        for cj in chunks:
            if ci.id == cj.id: continue
            status, B = boundary_certificate(ci, cj, delta, omega_max)
            if status == 'ok' and jaccard(ci.A, cj.A) >= theta_a:
                G.add_edge(ci.id, cj.id,
                           cert=ChunkCert(B, ci.H, ci.A_cert))
    return G
```

### IP-124 LCG

```python
def ground_llm_program(P_llm, skill_lib, delta):
    program = parse_typed(P_llm, grammar=G_C)
    grounded = []
    for node in program.chunks:
        c = instantiate(node, skill_lib, H=node.H)
        if not cover_chunk(c.profile, node.A_T, delta.s):
            return ('hallucination', c, 'coverage_fail')
        grounded.append(c)
    for ci, cj in zip(grounded, grounded[1:]):
        status, B = boundary_certificate(ci, cj, delta, omega_max)
        if status != 'ok':
            return ('hallucination', (ci,cj), 'boundary_fail', B)
    return ('ok', grounded)
```

### IP-125 LRP

```python
def propose_verify_repair(task, llm, skill_lib, N_max=3, eps=0.05):
    P = llm.propose(task, grammar=G_C, prior=skill_lib.signatures)
    best, best_score = None, -inf
    for k in range(N_max+1):
        status, payload = ground_llm_program(P, skill_lib, delta)
        score = certificate_score(payload)
        if score > best_score:
            best, best_score = P, score
        if status == 'ok':
            return ('ok', P, k)
        explain = build_explain(payload)
        P_next = llm.repair(P, explain, edit_ops={H, swap, bridge, phase})
        if certificate_score(P_next) < best_score - eps:
            break
        P = P_next
    return ('fallback_graph_search', best, explain)
```

### IP-126 AHC

```python
def choose_horizon(task, rho, tau_e, tau_llm, H_prior):
    candidates = [H for H in range(H_min, H_max+1) if H*tau_step <= tau_e]
    scored = []
    for H in candidates:
        p_succ = predict_success(task, H, rho)
        J = (p_succ - lambda_r*tau_replan(H)
             - lambda_o*tau_stale(H) - lambda_l*tau_llm(H))
        scored.append((J, H))
    H_phys = max(scored, key=lambda x: x[0])[1] if scored else H_min
    return min(H_prior, H_phys), scored
```

```python
def chunk_transfer_certify(J_source, G_C_target, phi, delta_a_budget, delta_rho_budget):
    P = recompile_chunks(J_source, G_C_target, phi)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ACC | O(|A|·H_max·|S|) | O(|A|·H_max) | 块内采样覆盖 ≥ 95%，边界状态可测 |
| CBC | O(|A|+|𝔇_ρ|) | O(|A|+|𝔇_ρ|) | Δs/Δv/Δφ 阈值 sound，`B^ω` 重算 |
| CCC | O(|C|²·(|A|+|𝔇_ρ|)) | O(|C|²) | 边界证书传递，路径取最弱鲁棒性 |
| LCG | O(|P|·|A|·H_max+|P|·|𝔇_ρ|) | O(|P|·|A|) | 接地完备，幻觉可判定 |
| LRP | O(N_max·(|P|·|A|+|P|·|𝔇_ρ|)) | O(|P|) | 编辑单调，`N_max` 有界 |
| AHC | O((H_max-H_min)·T_pred) | O(H_max) | 延迟模型可信，约束闭合 |

**正确性定理（Chunk-Grounded LLM Composition Soundness）**
承接第 54 轮 (A22)–(A28)；新增：
**(A29)** `β_S` 由结构化仿真校准，`cover_chunk` 可判定且采样覆盖 ≥ 95%；
**(A30)** `(δ_s,δ_v,δ_φ,ρ_min)` sound，blending 后 `B^ω` 不被平滑掩盖；
**(A31)** Repair 仅做证书不降序的局部编辑，修复环在 `N_max` 内到固定点或回退；
**(A32)** LLM 在 `G_C` 上以概率 `p_cov` 覆盖至少一个可行程序，否则依赖图搜索回退。
则对已验证 `P*`（`H(P*)=0` 且全路径 `C_chunk` sound）：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
             - P(β_S miscalibrated) - P(Δs/Δv/Δφ 超界)
             - (1-p_cov)·P(回退失败)
```
关键：**块级覆盖先验**、**边界证书可判定**、**LLM 仅在接地后获得信任**。

## 6. 本轮最大风险

**一句话**：动作分块与 LLM 把组合升级为“块级接地 + 边界证书 + 语义提议”的三层信任链，但其 soundness **同时依赖块剖面的完备采样、边界证书在 blending 后仍 sound、以及 LLM 提议对可行程序的可达性**；最危险的是**语义合理性伪装成物理可行性**——LLM 的块程序在语言层连贯，却在块接缝处以微小 Δs/Δv 持续错位，而平滑与仿真会把错位抹平，故必须以 **边界证书硬否决 + blending 后重验 + 真机断点探针** 三重护栏，宁可回退到第 54 轮的保守图搜索，也不放行“读起来很对”的分块计划。
