# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「最小可行产品」×「主动交互」）

> 第 54 轮把技能组合升级为“动作-鲁棒性双证书”，但代价是证书体系持续膨胀：L0–L6 六层、二十余个字段、六个新 IP。本轮用 **最小可行产品（MVP）** 做一次强制“减法”，用 **主动交互** 把第 54 轮最脆弱的假设——“动作剖面完备采样”——替换为“按需取证”。核心矛盾：**H22：完备证书 ≠ 可部署产品，绝大多数证书字段在真实决策中是不起作用的惰性字段，而“最小化”会误删只在长尾起作用的保命字段；H23：第 54 轮 soundness 依赖 α_S 的完备采样，但完备采样在开放动作空间不可行，唯一可行的替代是把“预标定完备性”换成“决策边际触发的主动询问”。**

## 0. 直觉与动机

**灵感 1（证书的最小化：从“证明一切”到“只证明会改变决策的东西”）**
直觉：一张证书不是越全越好，而是**恰好覆盖会翻转部署决策的那几个量**。若两个任务在某个字段上不同、但部署决策相同，则该字段对产品是惰性的。MVP 的第一性问题是：**给定决策函数，证书字段集合的最小充分子集是什么？** 这把前 54 轮的“加证书”改造成“证书压缩/剪枝”，并用“决策一致率”而非“字段完整性”作为正确性口径。

**灵感 2（主动交互 = 用交互预算兑换证据，替代离线完备采样）**
直觉：第 54 轮要求 `α_S` 在全动作空间 `A` 上完备采样才能判定 `cover(S,A_T)`。但机器人真正需要的不是“全部动作的剖面”，而是“**当前任务附近、决策边际很薄的那一小片动作**”的剖面。于是让机器人**主动交互**：当决策边际 `μ(T)` 低于阈值时，主动向人示教、向云端请求重剖分、或主动澄清约束；当交互成本高于信息价值时，主动降级/弃权。这把“完备预标定”换成“**按需、预算受限的证据获取**”。

**灵感 3（主动交互是一种新的一等动作：元动作空间 M）**
直觉：前 54 轮的动作空间只有物理动作 `A = A_c × A_e`。主动交互引入与物理动作**正交但抢占同一时间预算**的元动作集合 `M = {ask_demo, ask_clarify, ask_reprofile, ask_assist, safe_stop}`。机器人每一步的选择不只是“执行哪个技能”，而是“执行 / 询问 / 弃权”三选一，且询问会消耗本可用于执行的时间。这让“主动性”成为可度量、可预算、可优化的对象，而不是产品口号。

**灵感 4（MVP 边界 = 最小可部署包络，边界外“主动示弱”）**
直觉：存在一个任务区域 `E_MVP`，在其中最小证书足以支撑部署；区域之外，产品不应硬撑，而应**主动示弱**（询问或安全停机）。产品的诚实边界 `E_MVP` 本身就是卖点：可预测的失败胜过不可预测的“看起来能跑”。这直接对抗第 54 轮的负迁移风险。

**灵感 5（反向“砍枝”：为 UniBot 选出一条真正可交付的最小技术栈）**
直觉：既然目标是“参加 UniBot 的创新点”，就必须回答“哪 3–5 个 IP 能在真机上闭环演示”。本轮把前 54 轮的资产显式分为 **保命核心（必留） / 增益（可留） / 演示负担（砍掉或降级为附录）**，给出一个可在一台真实机器人上跑通的 MVP 技术栈，而非继续堆层。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（证书决策投影与决策充分性）**
沿用第 54 轮联合证书 `J = (ρ, A_cert, γ_ce, δ_a, evidence, …)`。对任务 `T` 定义部署决策 `dec(J,T) ∈ {execute, ask, abstain}`。投影 `π` 从 `J` 选出字段子集，称 `π` 在分布 `𝒟` 上 **ε-决策充分**，当且仅当
```
Pr_{T~𝒟}[ dec(π(J),T) ≠ dec(J,T) ] ≤ ε
```
即丢掉被投影字段后，决策几乎不变。

**定义 122（最小可行证书 MVC）**
`MVC(J) = π*(J)`，其中
```
π* = argmin_π |π(J)|
     s.t.  π 在 𝒟 上 ε-决策充分
           ∧ C_req ⊆ π(J)          （保命字段硬约束，永不可删）
```
`C_req` 至少包含：安全/碰撞相关字段、`ρ` 的致命维度、`A_core` 覆盖、`δ_a` 预算。**注意：最小化必须在硬约束内做，否则“最小”会退化为“最危险”。**

**定义 123（决策边际 μ）**
任务 `T` 在各活跃约束上的归一化松弛取最小：
```
μ(T) = min{
  min_d (ρ(d) − ρ_min(d)) / (1 − ρ_min(d)),
  (Θ_a − δ_a) / Θ_a,
  (compat − θ_a) / (1 − θ_a),
  (cover − θ_cov) / (1 − θ_cov)
}
```
`μ(T)` 越小，部署决策越接近翻转边界，越不可信。

**定义 124（主动交互元动作空间 M 与交互预算）**
```
M = { ask_demo, ask_clarify, ask_reprofile, ask_assist, safe_stop }
```
每个元动作 `m` 有交互成本 `c(m)`（人类时间/延迟）与成功收益。系统受预算 `B`（如 60 秒人类交互/任务，或 ≤ 2 次询问/任务）约束。

**定义 125（信息价值触发 VOI）**
对一次查询 `q`，令 `Δdec(q)` 为其带来的期望决策改进（用边际扩张或成功概率提升度量），则
```
VOI(q) = Δdec(q) − λ·c(q)
```
主动触发条件：`μ(T) < μ_0 ∧ argmax_{q∈M} VOI(q) > 0`；否则执行或弃权。

**定义 126（最小可行产品边界 / 最小可部署包络）**
```
E_MVP(ε,B) = { T : 用 MVC 单独决策的成功率 ≥ 1−ε，且期望询问次数 ≤ B }
```
“最小可行产品”形式化为四元组 `P_MVP = (MVC, E_MVP, π_ask, SLM)`，其中 `π_ask` 为预算化主动策略，`SLM` 为影子闭环（见 IP-125）。**产品 = 证书 + 边界 + 主动策略 + 最小闭环**，而不是一份更长的证书。

## 2. 关键算法 伪代码

### IP-121 MVC（Minimal Viable Certificate：硬约束下的后向消元）

```python
def minimize_certificate(Js, dec_fn, eps, required_fields, delta=0.05):
    # Js: 校准任务集上的全字段证书；dec_fn: 以全证书为金标准
    keep = set(required_fields)
    active = [f for f in Js[0].fields if f not in keep]
    full_dec = [dec_fn(J) for J in Js]
    # 后向消元：每次尝试删一个“删掉后与金标准分歧最小”的字段
    while active:
        worst = None
        for f in active:
            trial = [x for x in active if x != f]
            agree = mean(dec_fn(project(J, keep | set(trial))) == d
                         for J, d in zip(Js, full_dec))
            if agree >= 1 - eps:          # 仍 ε-充分
                if worst is None or agree > worst[1]:
                    worst = (f, agree)
        if worst is None:
            break                          # 再删任何一个都会破坏充分性
        active.remove(worst[0])
    return keep | set(active)
```

```python
def cert_risk_bound(n, eps, delta):
    # PAC 形式的决策充分性上界（Hoeffding）
    return eps + sqrt(log(1/delta) / (2*n))
```

### IP-122 PIT（Proactive Interaction Trigger：边际 + VOI 双门控）

```python
def decision_margin(J, thresholds):
    slacks = [rho_slack(J, d, thresholds) for d in J.rho]
    slacks += [delta_slack(J), compat_slack(J), cover_slack(J)]
    return min(slacks)

def proactive_step(J, T, mu0, B_left, voi_model):
    mu = decision_margin(J, thresholds)
    if mu >= mu0:
        return ('execute', None)           # 边际充足，直接执行
    best, best_v = None, 0.0
    for m in M:                            # ask_demo / ask_clarify / ...
        if voi_model.cost(m) > B_left: continue
        v = voi_model.expected_gain(J, T, m) - voi_model.lam * voi_model.cost(m)
        if v > best_v:
            best, best_v = m, v
    if best is not None:
        return ('ask', best)               # 主动取证
    return ('abstain', 'safe_stop')        # 主动示弱
```

### IP-123 VOQ（Value-of-Information Query：预算化信息采集）

```python
def budgeted_query(T, voi_model, B):
    spent, log = 0.0, []
    while spent < B:
        J = current_certificate(T)
        if decision_margin(J, thresholds) >= mu0:
            break
        m = argmax_{m in M} (expected_gain(J, T, m) - lam*cost(m))
        if expected_gain(J, T, m) <= lam*cost(m):
            break
        J = apply_query(J, m)              # 示教/澄清/云端重剖分后更新证书
        spent += cost(m); log.append((m, J))
    return J, spent, log
```

### IP-124 MDE（Minimum Deployable Envelope：校准得到“敢部署”的区域）

```python
def compute_envelope(calib_tasks, mvc, success_fn, eps, alpha=0.05):
    # 用 split-conformal 估计条件成功率下界
    scores = [(mu(T), success_fn(mvc, T)) for T in calib_tasks]
    # 单调假设：μ 越大成功率越高；取 (1-alpha) 下置信边界
    c_hat = conformal_lower_bound(scores, alpha)
    return lambda T: c_hat(mu(T)) >= 1 - eps   # E_MVP 判定器
```

### IP-125 SLM（Shadow-Loop MVP：影子闭环，先“陪跑”再“接管”）

```python
def shadow_loop(mvp, full_cert, robot, human, tasks):
    log = []
    for T in tasks:
        d_mvp = mvp.decide(T)              # 最小证书决策
        d_ref = full_cert.decide(T)        # 全证书/人类金标准
        if d_mvp == 'execute':
            traj = robot.shadow_execute(T) # 不真正改变世界，影子执行
            ok = full_cert.verify(traj)    # 全证书校验
        else:
            ok = (d_mvp == d_ref)
        log.append((T, d_mvp, d_ref, ok))
        if not ok:
            mvp.update_from_discrepancy(T, d_ref)
    return report(log)                     # 决策一致率、触发率、接管就绪度
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| MVC | O(\|F\|²·\|𝒟_cal\|) | O(\|F\|·\|𝒟_cal\|) | 硬约束保命字段、PAC 充分性 |
| PIT | O(\|𝔇_ρ\|+\|M\|) | O(1) | μ 单调代理、VOI 校准 |
| VOQ | O(B/c_min · \|M\|) | O(\|M\|) | 预算闭合、贪心次模近似 |
| MDE | O(\|𝒟_cal\| log \|𝒟_cal\|) | O(\|𝒟_cal\|) | conformal 覆盖率、μ 单调 |
| SLM | O(\|𝒟_shadow\|·(C_exec+C_verify)) | O(\|𝒟_shadow\|) | 影子无副作用、分歧可回灌 |

**正确性定理（MVP Decision-Sufficiency & Proactive Safety）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** `MVC` 在分布 `𝒟` 上以 `1−δ` 概率 ε-决策充分；**(A30)** `μ(T)` 是成功率的单调代理（μ 越大越安全），且 conformal 下界有效；**(A31)** 主动询问失败概率 ≤ `β_ask`，且预算 `B` 按定义 126 闭合。
则对 `T ∈ E_MVP`：
```
P_success(MVP) ≥ 1 − ε − β_ask − β_tail
```
对 `T ∉ E_MVP`：系统要么以 ≤ B 次询问把任务拉回 `E_MVP`，要么以概率 1 弃权（主动示弱），**不产生“无证书的静默执行”**：
```
P(silent_unsafe_execute) = 0
```
关键：**最小化被硬约束保护，主动交互被预算与 VOI 双重门控，包络外强制询问/弃权。**

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| MVC 删掉长尾保命字段 | 高 | 硬约束 `C_req` + 长尾红队 + conformal 风险控制 |

## 6. 本轮最大风险

**一句话**：最小可行证书的“最小”只能相对于**已访问分布**来度量，而被删掉的字段恰恰可能是只在罕见长尾上救命的字段——若 `MVC` 只在常见任务上验证充分，产品就会在最需要它的长尾处最脆弱，因此必须以 **保命字段硬约束 + conformal 长尾风险控制 + 包络外强制主动示弱** 三道闸门，坚决不允许“最小”滑向“最危险”。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-MVP（MVC×PIT×VOQ×MDE×SLM）

> 承接第 54 轮产物 v31（GroundEdge-GenSim+++，IP-115~120）。本轮不再是“加层”，而是一次 **产品化收敛**：把动作-鲁棒性双证书压缩为 **决策充分的最小可行证书**，并用 **主动交互** 替代“完备离线采样”。新增五个算子：

> - **SLM（Shadow-Loop MVP）**：影子闭环，先陪跑后接管的最小产品回路。
>
> IP 编号：IP-121~IP-125（共 5 个新增），并对 IP-107/112/118 做“减法适配”。本轮明确输出**可交付的最小技术栈**，其余前序 IP 降级为增益/附录。

### IP-123 VOQ（Value-of-Information Query）

```python
def budgeted_query(T, voi_model, B):
    spent, log = 0.0, []
    while spent < B:
        J = current_certificate(T)
        if decision_margin(J, thresholds) >= mu0:
            break
        m = argmax_M(expected_gain(J, T, m) - lam * cost(m))
        if expected_gain(J, T, m) <= lam * cost(m):
            break
        J = apply_query(J, m)
        spent += cost(m); log.append((m, J))
    return J, spent, log
```

### IP-124 MDE（Minimum Deployable Envelope）

```python
def compute_envelope(calib_tasks, mvc, success_fn, eps, alpha=0.05):
    scores = sorted((mu(T), success_fn(mvc, T)) for T in calib_tasks)
    c_hat = conformal_lower_bound(scores, alpha)   # (1-alpha) 条件成功率下界
    return lambda T: c_hat(mu(T)) >= 1 - eps
```

### IP-125 SLM（Shadow-Loop MVP）

```python
def shadow_loop(mvp, full_cert, robot, tasks):
    log = []
    for T in tasks:
        d_mvp = mvp.decide(T)
        if d_mvp == 'execute':
            traj = robot.shadow_execute(T)         # 不动真世界
            ok = full_cert.verify(traj)
        else:
            ok = (d_mvp == full_cert.decide(T))
        log.append((T, d_mvp, ok))
        if not ok:
            mvp.update_from_discrepancy(T, full_cert.decide(T))
    return report(log)                             # 一致率 / 触发率 / 接管就绪度
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MVC | O(\|F\|²·\|𝒟_cal\|) | O(\|F\|·\|𝒟_cal\|) | 硬约束保命 + PAC 充分性上界 |
| PIT | O(\|𝔇_ρ\|+\|M\|) | O(1) | μ 单调代理、VOI 校准 |
| VOQ | O((B/c_min)·\|M\|) | O(\|M\|) | 贪心次模近似、预算闭合 |
| MDE | O(\|𝒟_cal\| log\|𝒟_cal\|) | O(\|𝒟_cal\|) | conformal 覆盖率 `≥1−α` |
| SLM | O(\|𝒟_shadow\|·(C_exec+C_verify)) | O(\|𝒟_shadow\|) | 影子零副作用、分歧可回灌 |

**正确性定理（MVP Decision-Sufficiency & Proactive Safety）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** `MVC` 在 `𝒟` 上以 `1−δ` 概率 ε-决策充分；**(A30)** `μ(T)` 为成功率的单调代理且 conformal 下界有效；**(A31)** 询问失败率 ≤ `β_ask` 且预算 `B` 闭合。则
```
T ∈ E_MVP:   P_success(MVP) ≥ 1 − ε − β_ask − β_tail
T ∉ E_MVP:   P(silent_unsafe_execute) = 0      （必然询问或弃权）
```
三条护栏缺一不可：**最小化受硬约束保护、主动交互受 VOI 与预算双重门控、包络外强制示弱。**

## 6. 本轮最大风险

**一句话**：最小可行证书的“最小”只能相对于**已访问分布**度量，被删掉的字段恰恰可能只在罕见长尾上救命——若 `MVC` 仅在常见任务上验证充分，产品将在最需要它的长尾处最脆弱；必须以 **保命字段硬约束 `C_req` + conformal 长尾风险控制 + `E_MVP` 外强制主动示弱** 三道闸门，严禁“最小”滑向“最危险”。
