# 第 44 轮（新循环第 4 轮） · Instruct-Cert × Sim-Cert：把「自然语言指令」的歧义与「Isaac Sim」的仿真信任边界纳入可验证证书闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形只保边际覆盖 + 多用户契约求交为空」，但它仍压着两个未言明的单点假设：**(H3) 自然语言指令被当作无歧义的规格**——L2 的 VLM 把一句话编译成一个目标，随后所有证书都在为这个「已选定的解释」背书，却从未证明这个解释就是用户的意思；**(H4) Isaac Sim 被当作可信的现实替身**——仿真里零违例被默认为实机安全，却从未给出「仿真结果在什么参数域内有效、跨出该域误差多大」的证书。本轮灵感词「自然语言指令」「Isaac Sim」精确命中这两点：**自然语言指令**迫使我们承认「语言是规格的压缩包，不是规格本身」，把解释集 G、硬/软约束分离、澄清动作提升为证书链的一等公民；**Isaac Sim**迫使我们把仿真从「数据工厂」改造成「带校准证书的测量仪器」，每条仿真结论必须携带场景哈希、参数包络 E 与 sim-to-real 转移误差。二者耦合处是本轮真正的新问题：语言决定仿真里被检验的是哪个任务，仿真决定语言解释在物理上是否成立——两个不确定性相乘，且任一侧被投毒（指令注入 / 场景投毒）都能制造出「看起来已认证」的假证书。

## 0. 直觉与动机

**灵感 1（自然语言指令 → 规格不是一句话，而是一个可展开的假设集）**：直觉上，「把红色盒子放到桌子左边，别碰倒杯子」至少包含四层不确定：红是哪一种红（颜色阈值/光照）、桌子左边是观察者左还是桌子自身左、盒子指哪一个、以及「别碰倒杯子」是硬禁止还是随口提醒。v20 的流水线会先选一个解析，再为它生成几何证书；问题在于——**证书证明的是「系统以为的任务」，不是「用户说出的任务」**。于是把语言编译成**解释集 G(I)**：每个解释 g 带硬约束 φ_g（安全/禁止/时序必须，必须在**所有**一致解释下成立）、软目标 ψ_g（任务意图，可在高置信解释下优化）、未定参数 ρ_g 与置信权重 p_g。安全用全称量词（∀g），任务完成用存在/加权量词（∃g 或按 p_g 期望），这两类量词**绝不能混用**；把「别碰倒杯子」当软目标，正是语言层最典型的静默不安全。缩小 G 有两条路：主动**澄清**（唯一能无损缩小且不引入猜测的方式），或等待更多上下文。一句话：**语言欠定，安全取全称，意图取置信，澄清是唯一免费的收缩。**

**灵感 2（Isaac Sim → 仿真不是现实的替身，而是一台必须校准的仪器）**：直觉上，一把秤在 0–40°C 内准确，超出就要重新标定；仿真同理。Isaac Sim 里的光照、摩擦、质量、驱动延迟、传感器噪声、资产网格都是参数 θ_sim。仿真证书只在**参数包络 E** 内有效；离开 E，结论不再 sound。更进一步，sim-to-real 有系统偏差，必须用实机校准数据给出**转移误差界 ε_transfer**，并把安全边际按 m_real ≥ m_sim − L_m·(ε_sim+ε_transfer) 膨胀。每条仿真证书要携带：场景哈希 H_scene、参数 θ_sim、包络 E、见证轨迹 witness、覆盖报告 U_cov。**能被重放、能被审计、出了包络自动作废**，才配叫仿真证书。同时把 Isaac Sim 从被动验证器升级为**主动对抗器**：用 LLM + 域随机化生成歧义指令与最坏场景，但生成器本身不可信，反例必须先通过确定性重放与独立检查器才允许进入知识库。一句话：**仿真结论带「有效期」，跨出包络即失效；反例带「来源」，不可重放即拒绝。**

**灵感 3（耦合 → 语言是程序，仿真是编译器，两者都可被投毒）**：语言侧的威胁是**指令注入/权威混淆**——一句来自非授权来源的话（路人、网页、被篡改的语音）若被当成操作员指令，就能合法地把安全约束改写成「别管那个杯子」。仿真侧的威胁是**场景/参数投毒**——对抗者构造一个「在 E 内怎么走都安全」的错误场景，让证书在错误世界里成立。二者叠加时，一个被投毒的语言解释加一个被投毒的仿真场景，可以联合伪造出全链路「零违例」。因此必须引入**指令权威格**（签名操作员 > 操作员 > 已登记用户 > 环境文本/第三方 > 仿真合成）与**反例准入证明**（确定性重放 + 独立检查 + 签名验证，三重独立）。一句话：**证书的可靠性 = min(语言解释的覆盖, 仿真包络的有效性, 来源的可信度)。**

**耦合升级**：ISC（指令规格编译器）把一句话编译成解释集 + 硬/软约束 + 澄清计划；CSB（可认证仿真桥）把 Isaac Sim 输出变成带包络、转移误差与见证的证书；ISAV（指令-仿真对抗验证器）同时 fuzz 语言与场景，做注入/投毒/歧义炸弹压力测试。四层架构由 v8 的「人格契约层 + 并发证书层」升级为 v9 的「仿真-检索-边缘飞轮 + 人格契约层 + 并发证书层 + 指令规格层 + 仿真信任层」。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（指令解释集与硬/软约束分离）**：给定指令 I 与上下文 c，解释集 G(I,c) = {g=(φ_g, ψ_g, ρ_g, p_g, auth_g)}。φ_g 为硬约束（安全、禁止、时序必须），ψ_g 为软目标（偏好、效率、风格），ρ_g 为未定参数取值，p_g 为校准后的解释权重，auth_g 为签发该解释所依据的权威来源。**一致解释集** G_hard(I) = {g∈G : φ_g 与全局安全域相容}（不做概率裁剪）；**任务解释集** G_α(I) = 权重累积覆盖 ≥ α 的最小解释子集。**命题（两类量词）**：安全谓词必须对 ∀g∈G_hard 成立；任务完成只需对 G_α 中的解释可达。用 G_α 背书安全，会把禁止项当低概率偏好，产生静默不安全。

**定义 45（指令鲁棒证书与单调性）**：策略 π 的指令鲁棒证书 C_I = C_safe ∩ C_live，其中
C_safe = {π : ∀g∈G_hard(I), ∀θ∈E, 沿 π 的所有可达状态满足 φ_g}，
C_live = {π : ∃g∈G_α(I), 在 φ_g 下达成 ψ_g 且不越出 C_global}。
**单调性命题**：若 G'_hard ⊆ G_hard 且 E'⊆E，则 C_safe(G',E') ⊇ C_safe(G,E)；若 G'_α ⊆ G_α，则 C_live(G'_α) ⊆ C_live(G_α)。**推论**：澄清（缩小 G_hard）与加严仿真包络（缩小 E）对安全性免费、但损失可用性；扩展解释集或放宽 E 必须重新取证，绝不能默认。

**定义 46（澄清作为主动集合收缩与 VOI 判据）**：问题 q 把解释集划分为 {G_1..G_k}，其**信息价值** VOI(q) = E_{j}[ max_{π} U(π|G_j) ] − max_{π} U(π|G)，其中 U 含安全裕度与任务收益。**澄清规则**：仅当 VOI(q) > c_ask（交互成本 + 延迟税）且安全在划分上确实分叉时才提问；否则执行 **maximin 解释** g* = argmax_g min_{θ∈E} margin(π_g, θ)。**命题**：不澄清时的 maximin 执行仍保证 C_safe；澄清后 G_hard 单调收缩，故 soundness 不降、可用性不降。

**定义 47（Isaac Sim 有效性证书与 sim-to-real 转移界）**：仿真证书 S=(H_scene, θ_sim, E, ε_sim, U_cov, w)。在 θ_sim∈E 下，仿真谓词 m_sim(θ) 满足认证残差 ε_sim（由物理参数界与数值积分界给出）；U_cov 为场景/参数覆盖报告；w 为可重放见证轨迹。**有效性语义**：θ_sim∉E 时 S 立即作废。**转移界**：用实机校准对 Δ(s)=m_real(s)−m_sim(s) 做（按场景/构型分层的）共形校准，给出 P(|Δ|≤ε_transfer)≥1−β；**转移守卫**：m_real ≥ m_sim − L_m·(ε_sim+ε_transfer) ≥ θ。**命题**：若包络有效且转移界覆盖成立，则仿真证书在实机以 ≥1−β 概率 sound；β 不可被吞掉，必须在安全论证里显式出现。

**定义 48（语言-仿真联合认证与量词次序）**：联合可采纳集 A(I) = {π : π∈C_safe(G_hard,E) ∧ π∈C_live(G_α) ∧ 仿真证书有效 ∧ 转移守卫通过}。**定理（联合可靠性）**：若 (i) G_hard 覆盖真实意图的硬约束部分；(ii) 真实 θ∈E；(iii) 转移界以 1−β 成立；则 π∈A(I) ⇒ 实机不违反任何硬约束，且以 ≥1−β 概率满足其选中的软目标。**否定命题（量词次序错误）**：若把硬约束塞进 G_α 做概率裁剪，则存在 α 与 β 同时失效的灾难场景——安全不再是全称命题，认证随样本量增长仍可能系统性漏掉被裁掉的解释。

**定义 49（对抗指令/场景的来源格与反例准入）**：来源格 L: simulator-synth < external-text < registered-user < operator < signed-operator。安全相关子句只能由 ≥registered-user 且带签名者改写；低来源文本只能贡献软偏好。**反例准入**：候选反例 (I, scene, θ, witness) 进入 CKB 当且仅当（a）witness 在 H_scene、θ_sim 下确定性重放成功，（b）独立检查器复核违例，（c）来源签名可验证；否则只存为「未证实线索」。**命题（投毒抗性）**：单点投毒若要进入 CKB，必须同时伪造场景哈希、重放见证与签名，三者独立，故攻击成本从「一条坏样本」提升为「一次可验证的仿真共谋」。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 INSTRUCTION-SPEC-COMPILER（指令规格编译器 ISC）
1. **解释集编译**：ASR/NLU/VLM → 多解析解释集 G（含否定、量词辖域、指代、空间参照系、省略），显式区分硬约束 φ 与软目标 ψ；未定参数 ρ 标注默认值与影响域。
2. **权威与注入过滤**：按来源格 L 校验每个安全相关子句的签发主体；低来源文本降级为软偏好；检测「忽略以上规则」类注入并隔离。
3. **澄清规划**：构建歧义图，按 VOI 选问题；安全分叉必澄清或 maximin，禁止静默选解析。
4. **约束编译**：把 φ/ψ 编译为守卫谓词、CBF 约束与 STL 时序公式，输出带解释标签的证书请求。

### 2.2 IP-61 CERTIFYING-SIM-BRIDGE（可认证仿真桥 CSB）
1. **有效性包络**：为每个仿真任务声明 θ_sim 与 E（摩擦、质量、延迟、噪声、资产版本）；越界自动作废。
2. **场景/参数哈希与见证账本**：证书携带 H_scene、θ_sim、witness，支持确定性重放与差异审计。
3. **sim-to-real 转移校准**：分层共形校准 Δ，输出 ε_transfer 与覆盖报告；β 显式进入安全裕度。
4. **主动仿真实验**：在 Isaac Sim 内做域随机化与参数扫掠，生成带包络的证书；对包络边缘做敏感性分析并回灌课程。

### 2.3 IP-62 INSTRUCTION-SIM-ADVERSARIAL-VALIDATOR（指令-仿真对抗验证器 ISAV）
1. **歧义炸弹生成**：否定/辖域/指代/多语言/省略句，构造「安全随解析分叉」的指令集。
2. **注入与权威攻击**：环境文本注入、语音冒充、跨来源拼接、权限提升链。
3. **场景/参数投毒**：生成在错误 E 内恒安全的场景，检验包络与转移校准能否拒绝。
4. **反例准入与重放审计**：确定性重放 + 独立检查 + 签名验证；产出可进 CKB 的纯净反例与拒收原因统计。

## 3. 四层架构 v9

```
L1: TRI-FUSE(INT8) + IP-49 LIO → C_ms + B_t + L_m(经验分位)
    实机校准数据 → sim-to-real 转移校准(CSB)；状态/人意图估计
L2: ASR/NLU + VLM + IP-35 仲裁 → 解释集 G(I) + 硬/软约束 + 权威校验
    歧义图 → IP-60 ISC(澄清规划, VOI) → 分支池(b 候选, 并发投机)
L3: IP-51 CAR(InstructionMode + SimEnvelope + 租约) ← IP-58 CCR
    → IP-47 解释/包络兼容组合 → IP-39 规划(CBF margin 减转移膨胀)
    → IP-45 总线(解释/权威/场景哈希/包络/见证) → IP-48 认证流匹配 + IP-43 澄清话术
    → IP-53 CMC(解释×包络参数化监控器, 最高关键级)
L4: IP-60 ISC(解释集 + 权威 + 澄清) + IP-61 CSB(包络 + 见证 + 转移校准)
    ← IP-62 ISAV(歧义/注入/投毒 + 重放审计) + IP-54 SCV(Isaac Sim 对抗场景)
    → IP-44 蒸馏 + IP-50 课程(歧义/注入/包络) → RCA 重颁(解释×包络条件) → 热更新
运行期：语言→解释集→澄清或 maximin→Isaac Sim 带包络认证→转移守卫→执行→监控
        安全分叉→澄清；包络越界→重仿真/重校准或保守回退；反例→重放审计→CKB
```

## 4. 实验设计（E95–E102 硬门槛，承接 E87–E94）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E95 指令解释覆盖 | 硬约束解释覆盖率（否定/辖域/指代/参照系）；漏解率 | ≥99.5%；<0.5% |
| E96 硬/软约束分离 | 把禁止项误当软目标的比例；歧义下不安全执行 | 0；0 起 |
| E97 澄清 VOI | 安全相关澄清率；无效提问率；任务时延增量 | ≥95%；<10%；<15% |
| E98 仿真包络/转移 | 越界证书拒绝率；转移界覆盖；实机安全违例 | 100%；≥1−β(β=0.05)；0 起 |
| E99 注入/权威 | 注入成功率；越权改写安全子句；合法指令误拒率 | 0；0；<5% |
| E100 场景投毒/反例准入 | 投毒场景误纳率；见证重放一致率；签名校验漏检 | 0；100%；0 |
| E101 长时程语言条件 | 100h 不安全事件；解释漂移检出；包络漂移检出 | 0 起；≥95%；≥95% |
| E102 Isaac 重放与吞吐 | 见证重放确定性；场景哈希差异检出；认证吞吐 | 100%；100%；≥50 task/s |

回退：E95/E96 不达标 → 关闭多解析，改为逐字单解释 + 所有歧义必澄清（牺牲效率保安全）；E97 无效提问过高 → 提高 VOI 阈值并批量澄清；E98 转移覆盖失效 → 禁止仿真外推，仅用实机校准包络并激进缩小 E；E99 失败 → 只接受签名操作员指令，外部文本全部降为软偏好；E100 失败 → 反例不自动入库，转人工复核；任何红线失败 → 全链路熔断回退 v20。

**可证伪预测**：若 H3/H4 成立，则 v20 在「否定 + 空间参照系 + 包络外参数」组合场景下的实机违例应显著高于零；且违例样本中「证书在系统所选解释下成立」的比例应接近 100%——即证书没错，错的是解释与包络。该预测可用 E95/E98 的失败模式直接检验。

## 5. 本轮最大风险

## 2. 关键算法（伪代码）

### IP-60 ISC：解释集编译、权威校验与澄清规划
```
def compile_instruction(utt, ctx, global_safety):
    parses = nlu_multi_parse(utt, ctx)      # 否定/辖域/指代/参照系/省略
    G = [Grounding(phi=hard(g), psi=soft(g), rho=params(g),
                   p=calibrate_weight(g), auth=provenance(g))
         for g in parses]
    # 安全子句必须来自 >=registered-user；低来源仅可贡献软偏好
    G = [g if authorize(g.auth, need='safety') else downgrade_to_soft(g)
         for g in G]
    G_hard = [g for g in G if compatible(g.phi, global_safety)]   # 不做概率裁剪
    G_soft = top_credible(G, alpha)                               # 仅用于任务意图
    return InstructionSet(G_hard, G_soft, ambiguity_graph(G_hard),
                          injections=detect_injection(utt))

def plan_instruction_robust(ins, E):
    if safety_splits(ins.G_hard):                 # 不同解释的安全域分叉
        q = argmax_q VOI(q, ins.G_hard)
        if VOI(q, ins.G_hard) > c_ask:
            return Clarify(q, fallback=maximin_plan(ins, E))
        return maximin_plan(ins, E)               # 不猜，取最坏情形最优
    return robust_plan(ins.G_hard, E)             # ∀g∈G_hard, ∀θ∈E
```

### IP-61 CSB：仿真证书、包络与转移守卫
```
def certify_in_sim(task, scene, theta, E, witness):
    assert theta in E                              # 包络外不允许签发
    m_sim, eps_sim = simulate_margin(scene, theta, task, witness)
    U = coverage_report(scene, E)                  # 场景/参数覆盖报告
    return SimCert(H_scene=hash(scene), theta=theta, E=E,
                   m=m_sim, eps_sim=eps_sim, U_cov=U, witness=witness)

def calibrate_transfer(real_log, sim_log, beta):
    # 分层共形：按场景类型/构型分层，避免边际覆盖被场景混合欺骗
    return {stratum: conformal_quantile(real_log[s]-sim_log[s], 1-beta)
            for stratum, s in stratify(real_log)}

def sim_to_real_guard(cert, x_real, eps_transfer, L_m, theta_req):
    theta_hat = estimate_sim_params(x_real)
    if not cert.E.contains(theta_hat):
        return INVALID                             # 包络外：作废，重仿真/保守回退
    m_real_lb = cert.m - L_m * (cert.eps_sim + eps_transfer)
    return m_real_lb >= theta_req
```

### IP-62 ISAV + 联合运行时：反例准入与端到端选择
```
def admit_counterexample(ce, ckb):
    if not deterministic_replay(ce):   return REJECT, 'replay'
    if not independent_checker(ce):    return REJECT, 'check'
    if not verify_signature(ce):       return REJECT, 'auth'
    ckb.add(ce.with_provenance())                  # 三重独立通过才入库
    return ADMIT, 'ok'

def step(utt, ctx, x_real, E, eps_transfer):
    ins  = compile_instruction(utt, ctx, GLOBAL_SAFETY)
    plan = plan_instruction_robust(ins, E)
    if isinstance(plan, Clarify):
        return speak(plan.q)                       # IP-43 澄清话术/韵律
    candidates = parallel_plan(plan)               # 复用 IP-58 投机并行
    valid = []
    for beta in candidates:
        cert = certify_in_sim(beta.task, beta.scene, beta.theta, E, beta.witness)
        if (sim_to_real_guard(cert, x_real, eps_transfer, L_m, beta.theta_req)
            and certify_branch(beta) in C_safe(ins.G_hard, E)):
            valid.append((beta, cert))
    if not valid:
        return negotiate_or_safestop()             # 空集绝不静默放行
    return max(valid, key=lambda bc: score(bc[0]))
```
