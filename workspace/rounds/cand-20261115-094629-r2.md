# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「模型蒸馏」×「云边协同」）

> R69 问出「我该向谁求证、还能问什么」，用流匹配把歧义变成有形状的多个模态，用 VoI 把「问」变成动作，并用动作似然补 R68 的计量洞。但它默认了一件从未写进证书的事：**这个会多采样、会算似然、会规划交互的大模型，究竟跑在哪里？** 真实终端上跑得动的是 FLUID-RAS 的**蒸馏学生**；老师（大流模型、完整审计、大上下文）在云上。于是 R69 的两条命脉——模态分布可信、U_epi 可估——在交给边端之前，先经过了一次**有损压缩**。
>
> 本轮两个灵感正好接上：
> - **模型蒸馏**告诉我们：蒸馏不是复制，是**对分布做有损压缩**。保真度优化默认优先保住均值/成功率，压掉的往往正是尾部模态与校准——也就是 R69 赖以触发交互、兑换 resolution bonus 的那个信号；
> - **云边协同**告诉我们：老师不是神，而是一个**有延迟、要带宽、可能过时/被篡改/会泄露隐私**的远端。向它求助本身就是一个新的、昂贵的、异步的信息动作，而且它和 R69 的「看/问/触」一样，必须排队、认证、审计。
>
> 核心命题：**把 R69 的两分不确定性扩成三分 U = U_ale + U_epi + U_dist。U_dist 是「我这个缩小版自己」的模型侧不确定性：它既不是世界噪声，也不是世界歧义，只能靠更好的蒸馏或向云求证来降。交互动作空间从「看/问/触」扩成一条保真度阶梯（边端先验 → 局部传感 → 云端老师 → 人类专家），用「截止期约束下的 VoI」逐级升级；安全锚仍在边端本地认证（云提议、边认证），R69 的 resolution bonus 从此需要一张蒸馏证书才能兑换。** 命名 **CASCADE-RAS**（Cloud-edge Asymmetric Student-teacher Certified Adaptive Distillation Escalation）。

## 0. 直觉与动机

**灵感 1（模型蒸馏 → 蒸馏是对分布的有损压缩，先被压掉的常是尾部与校准）**
直觉：R69 的整个安全论证挂在一句话上——「流模型吐出的模态权重是可信的」。但边端跑不动那个大模型，只能跑蒸馏学生。常规蒸馏的损失是对**动作/均值**的回归或对获胜模态的模仿，这恰恰是**最不需要保真**的部分：决定安全的是「少数派模态还在不在」「权重有没有被压平」「学生是不是比老师更自信」。一次为成功率优化的蒸馏，会把多峰压成单峰、把尾部的 0.05 权重压成 1e-4、把老师在罕见场景的犹豫抹成学生的斩钉截铁。于是 R69 的 U_epi 被**系统性低估**：系统越「蒸馏成功」，越不会去交互，越会在最需要第二意见的罕见歧义上自信地复读老师的系统性错误。这不是蒸馏的 bug，是**优化目标与安全目标错配**。
更关键的是，这里多出一种 R69 没有的不确定性：**U_dist（蒸馏间隙）**。它不是「世界有噪声」（U_ale），也不是「世界有歧义」（U_epi），而是「我这个缩小版和老师差多少」——一种**模型侧的 epistemic**：可通过更大容量、更好蒸馏、或直接问云来降低。把它塞进 R69 的任何一格都会语义错位，必须单列一维。

**灵感 2（云边协同 → 老师是一个有延迟、要带宽、可能撒谎的远端）**
直觉：既然 U_dist 的最终仲裁者在云上，那么「问云」就该是一个正式的信息动作。但它与 R69 的「看/问/触」有本质区别：**它是异步的、有截止期、有字节和隐私成本、而且回答可能过期**。R69 的 MINT 可以假设「做了信息动作，观测立刻变好」；云查询不能。等云回包时，车可能已经过了岔口。所以云查询的价值不是经典 VoI，而是**截止期约束下的 VoI**：只有歧义的时标长于往返延迟时，问云才划算；碰撞级的快歧义必须由边端局部阶梯在截止期内解决。这给出一条干净的分工：**快 epistemic 用边，慢 epistemic 用云**。
同时，「云」不是一个权威，而是一个**不可信输入源**：缓存会过期、链路会重放/篡改、老师版本会漂移、甚至会泄露上调的原始观测。因此权威必须分级：**认知权威可临时借给云，安全权威永远留在边**——云提议，边认证。

**灵感 3（两者相乘 → 保真度阶梯，R69 的交互只是第二级）**
直觉：把 R69 的局部信息动作与云查询放到同一个坐标轴上，会看到一条按「成本—延迟—可降不确定性」排序的阶梯：r_0 边端先验（免费、永远在线）→ r_1 局部看/问/触（毫秒级、受物理/社交预算约束）→ r_2 云端老师（百毫秒级、受带宽/隐私约束）→ r_3 人类专家/离线复核（分钟级、受人力约束）。R69 的 MINT 只是这条阶梯上取「一级」的特例。正确的调度不是对每一级都算 argmax，而是**最便宜且够用**：从低到高，选第一个能使后验熵（在截止期内）降到目标以下的级；一级都不够用，就走保守兜底。这既是硬实时下的 satisficing，也天然把「先问便宜的，再问贵的」变成纪律。

**灵感 4（安全与审计 → 蒸馏会引入一类看不见的失效）**
直觉：蒸馏带来了两种常规监控看不见的坏法。其一是**蒸馏投毒/后门**：被污染的老师或数据可以种一个只在罕见状态触发的行为，学生在训练分布上完全校准，gap 估计器也在同一分布上训练，天然看不见这个盲区。其二是**共谋式一致**：学生和老师来自同一训练血统，它们「意见一致」不是正确性的证据，只是相关性的证据。因此 R69 的「k 个正交证据源一致」必须显式要求至少一个**非蒸馏来源**（第二老师版本、物理残差、人类抽检）；同时按比例抽取「影子查询」做交叉验证，才能把 sys 系统性偏差从「高置信」里拆出来。

**灵感 5（理论姿态 → R69 是「零间隙、零带宽」的边界，但这次是安全侧的无回退）**
直觉：CASCADE 必须再次严格包含 R69，否则每加一层就多一个要独立信任的黑箱。包含关系很干净：令学生=老师（蒸馏间隙 ĝ=0）、云预算 B=0，CASCADE 逐指令退化为 FLUID-RAS。不同的是，本轮不能像 R69 那样宣称「效率白拿」——当 ĝ>0 且没有云时，CASCADE 通过膨胀 U_epi **主动变得比 R69 更保守**。这是诚实的理论姿态：**安全侧永不回退，效率侧的 bonus 现在必须用一张蒸馏证书来兑换**。换句话说，R69 的乐观是 CASCADE 在「证书永远有效」边界上的特例。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（CASCADE-RAS 总览）** CASCADE-RAS = (UPD, GAP, ESC, LDL, TSM, SSA, CEG, RAS-WM‡)。三不变式：
(i) **实时环零学习写操作**（继承 R69 定义 293-i）；
(ii) **云提议、边认证**：任何来自老师/云的候选动作只是证据，必须通过本地 C-RAS-WM‡ 前缀认证后才可执行，远端不得直接写执行器；
(iii) **证书兑换**：R69 的 resolution bonus 只有在蒸馏证书（间隙上界、ECE、影子自审、版本兼容）有效时才可兑换；否则按膨胀后的 epistemic 保守，安全侧不弱于 R69。

**定义 311（师生对与权威分级）** 老师 π_T：云侧大流策略，容量 Θ_T、延迟 L_T、上行带宽 B_T、版本 v_T；学生 π_S：边侧蒸馏策略，容量 Θ_S ≪ Θ_T，负责实时采样与控制。权威分两级：**安全权威恒在边**（RAS-WM‡ 认证）；**认知权威可临时在云**（老师后验/建议只作为证据源之一，需与本地证据一致）。

**定义 312（三分不确定性）** U = (U_ale, U_epi, U_dist)。U_ale 为传感器/执行噪声（不可约）；U_epi 为世界歧义（R69 定义 297，可由局部交互或云查询降低）；U_dist 为蒸馏近似误差（模型侧 epistemic：关于「学生与老师差多少」，可由容量↑、蒸馏质量↑或向云求证降低，与世界的噪声/歧义正交）。三者语义不同，不直接相加，各走不同通道（定义 322）。

**定义 313（不确定性保持蒸馏 UPD）** 蒸馏目标不是 argmax，而是 mixture：
L_UPD = L_flow + λ_m L_mode + λ_c L_cal + λ_s L_shield，
其中 L_flow 在老师 ODE 轨迹上匹配学生速度场（分布匹配，而非只匹配获胜模态）；L_mode 匹配模态权重/熵（防模态坍缩与权重压平）；L_cal 对齐模态校准（温度/ECE）；L_shield 要求学生认证安全裕度不弱于老师。四项缺一：只留 L_flow 就是「会复读、不会犹豫」的学生。

**定义 314（蒸馏间隙与认证上界 GAP）** gap(o) = D(π_T(·|o), π_S(·|o))，D 取 2-Wasserstein 或 KL。认证上界 ĝ 由 held-out probe 集 + 共形分位给出：P(gap ≤ ĝ) ≥ 1−α。定义 epistemic 膨胀
U_epi^inf = U_epi^S + κ·ĝ，κ ≥ c_H（引理 19）。
ĝ 是「学生自评」之外的第二意见：学生可以自称很确定，但 ĝ 由独立探针集给出，不随学生的自信改变。

**定义 315（升级动作空间）** 在 R69 的 𝒜_info 上增云查询 g_cloud = (q, δ, b)：q 为查询载荷（压缩潜变量或指定问题），δ 为截止期，b 为带宽/隐私预算。g_cloud 是**异步动作**：发出后不阻塞控制环，回包携带发送与老师时间戳。总动作 ξ = (a, g_local, g_cloud)。

**定义 316（截止期约束 VoI）**
VoI_δ(g) = P(τ≤δ)·E_{y~p(·|g,o)}[H(M|o)−H(M|o,y)] + (1−P(τ≤δ))·γ·VoI_deferred(g)，
其中 τ 为往返延迟，γ∈(0,1) 为延迟折扣。选择 g* = argmax[VoI_δ − c_comm − c_lat − c_priv]，s.t. 预算未超；若 max ≤ 0 则不升级。P(τ≤δ) 由链路延迟分布给出，不假设恒定。

**定义 317（保真度阶梯 LDL）** 有序级 r_0（边端先验，成本 0）、r_1（局部看/问/触，即 R69 的 𝒜_info）、r_2（云端老师）、r_3（人类专家/离线复核）。每级有 (cost_r, latency_r, reduction_r)，成本与保真度单调增。调度规则：从 r_0 起，选**第一个**使期望后验熵在截止期内 ≤ τ_H 的级；全不达标 ⇒ 不升级、走保守兜底。

**定义 318（异步与陈旧 TSM）** 回包年龄 a = now − t_teacher；有效熵 H_eff = H + ρ(a)，ρ 随链路抖动与场景漂移单调增。只有 H_eff < H_pre（合并前）时允许并入，且并入不得降低 λ；否则丢弃。**陈旧回包不得兑换 resolution bonus。**

**定义 319（影子自审 SSA）** 按比例 p_shadow 抽取升级请求，用**非蒸馏来源**（第二老师版本、物理残差、人类抽检）交叉验证；统计 gap 估计偏差、后门触发率与系统性偏差。SSA 结果回灌 ĝ 与 λ；SSA 不通过 ⇒ 冻结 bonus。

**定义 320（云边威胁模型 AIC-CASCADE）** ℰ_CASCADE = ℰ_FLUID × ℰ_dist × ℰ_link × ℰ_stale × ℰ_priv。ℰ_dist：蒸馏投毒/后门、老师漂移；ℰ_link：篡改/重放/延迟注入/拜占庭；ℰ_stale：过期缓存；ℰ_priv：升级载荷泄露隐私。云侧与链路输入一律不可信。

**定义 321（云提议边认证 CEG）** 老师输出建议 a_T 后，本地先投影到认证前缀：a_exec = Proj_{C-RAS-WM‡}(a_T)。不可投影则拒绝并标记。老师不得直接驱动执行器；学生也不得把老师的似然当作安全证据。安全锚只在边。

**定义 322（证书门控的 resolution bonus）** bonus 可用 ⇔ ĝ ≤ τ_gap ∧ ECE_S ≤ τ_ece ∧ SSA_pass ∧ 版本兼容（定义 326）。可用时 λ = λ_floor(U_ale)（R69 的 bonus）；不可用/超时/被污染时 λ = λ_floor(U_ale + U_epi^inf + U_dist) ≥ R69 在同条件下的 λ_floor(U_ale + U_epi)。R69 恰为 (ĝ=0, B=0, π_S=π_T) 边界。

**定义 323（证书 J_CASCADE）** J_CASCADE = (J_FLUID, teacher_ver, student_ver, ĝ_p95, ECE_S, U_dist_p95, escalation_log_hash, staleness_p95, link_integrity, SSA_pass_rate, cascade_ver)。Valid ⇔ Valid(J_FLUID) ∧ 蒸馏证书有效 ∧ 链路完整 ∧ 无未处置的陈旧覆盖。

**定义 324（舰队带宽竞争 FBA）** n 个边端共享一条上行链路。每个升级请求报 (VoI_δ, deadline, size)。按 VoI 密度（每字节每毫秒的期望熵降）出价，二价拍卖分配；在互相独立、单参数估值下真实报价是弱占优，且最大化总 VoI。单机预算为 n=1 的特例。

**定义 325（共形模态校准门 MCG†）** 不直接信学生的模态权重：构造模态预测集 S_α(o) 使 P(M* ∈ S_α) ≥ 1−α（共形/risk-controlling）。若 ECE_S > τ_ece 或覆盖率不达标 ⇒ 禁用 VoI 决策、退回保守。它与 R69 的 MCG 兼容但更严：给的是**覆盖保证**，而不只是平均校准。

**定义 326（版本偏斜与刷新）** 老师版本 v_T 与学生训练所用版本 v_T^S 不一致即版本偏斜 skew = 1{v_T ≠ v_T^S}。skew=1 时 ĝ 上浮、bonus 冻结，直到学生增量蒸馏完成；刷新采用回放 + EWC 防灾难遗忘，并保留旧版影子用于 SSA。

```python
# IP-264 UPD：不确定性保持蒸馏（分布 + 模态 + 校准 + 安全盾）
class UncertaintyPreservingDistill:
    def loss(self, o, v_T, v_S, modes_T, modes_S):
        L_flow = mse(v_S(x_s, s, z_S), v_T(x_s, s, z_T).detach())      # 轨迹/分布匹配
        L_mode = w2(mode_dist(modes_S), mode_dist(modes_T).detach())   # 模态结构，不许坍缩
        L_cal  = abs(ece(modes_S, o) - ece(modes_T, o).detach())       # 校准对齐
        L_safe = relu(margin_T(o) - margin_S(o)).mean()                # 学生安全裕度只许更严
        return L_flow + lm*L_mode + lc*L_cal + ls*L_safe

# IP-265 GAP：蒸馏间隙的认证上界（held-out probe + conformal）
def certify_gap(student, teacher, probes, alpha=0.1):
    gaps = [dist(student.dist(o), teacher.dist(o)) for o in probes]
    return conformal_quantile(gaps, alpha)        # ĝ：P(gap <= ĝ) >= 1-alpha

def inflate(U_epi_S, g_hat, kappa):
    return U_epi_S + kappa * g_hat                # 补回学生的乐观

# IP-266 ESC：截止期约束下的云查询价值
def escalation_value(modes, w, deadline, link):
    tau  = link.predict_latency()                 # 上行 + 计算 + 下行
    imm  = link.p_arrive_before(tau, deadline)    # 当前决策窗口内可用概率
    voi  = imm * expected_entropy_drop(w, 'cloud')
    voi += (1 - imm) * GAMMA * deferred_value(modes, tau - deadline)
    return voi - bandwidth_cost(modes) - privacy_cost(modes)

# IP-267 LDL：最便宜且够用的保真度阶梯
def choose_rung(modes, w, deadline, target_H, budget):
    for rung in [EDGE_PRIOR, LOCAL_SENSE, CLOUD, HUMAN]:     # 成本递增
        if not budget.allow(rung) or not c_ras_wm.certify_rung(rung): continue
        if expected_posterior_entropy(modes, w, rung, deadline) <= target_H:
            return rung
    return CONSERVATIVE_ONLY                                  # 都不够用 → R69 兜底

# IP-270 CEG：云提议、边认证
def cloud_propose_edge_dispose(advice, o, wm_preds):
    a = advice.action
    if not c_ras_wm.certify_prefix(a, wm_preds):
        a = project_to_certified(a, o)             # 投影或拒绝
    return a

# IP-276 主闭环（继承 R69 FLUID-RAS，插入蒸馏层与阶梯）
def CASCADE_round(M, obs):
    z_S, o = M.student.trunk(obs)
    U_ale, U_epi_S, modes = M.student.aud(z_S, o)          # R69 的分解，用学生做
    g_hat  = M.gap.lookup(o)                               # 认证过的间隙上界
    U_epi  = M.urd.inflate(U_epi_S, g_hat)                 # 不信任学生的乐观
    # 1) 保真度阶梯：先在边端解决；快歧义绝不排队等云
    rung = M.ldl.choose_rung(modes, U_epi, M.deadline, M.target_H, M.budget)
    if rung == LOCAL_SENSE:
        ans = M.mint.execute(M.mint.choose_interaction(modes, U_epi))
        U_epi = M.cia.update_belief(U_epi, ans)
    elif rung == CLOUD:
        M.link.send_async(M.esc.build_query(modes, o), M.deadline)   # 只影响未来/慢时标
    elif rung == CONSERVATIVE_ONLY:
        pass
    # 2) 异步回包：按年龄决定并入还是丢弃；陈旧答案不得降 λ
    U_epi = M.tsm.merge_or_discard(U_epi, M.link.pending(), now=M.now)
    # 3) 证书决定能否兑换 resolution bonus
    cert = M.jcert.cascade(M.j_fluid, g_hat, M.student.ece,
                           M.ssa.pass_rate, M.version_pair)
    U_floor = U_ale + (U_epi if not cert.bonus_ok else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    # 4) 云建议只是证据：本地认证后才可执行
    A = M.ceg.dispose(M.link.latest_advice(), o, M.wm_preds)
    k = M.c_ras_wm.certified_prefix(A, M.wm_preds)
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_d.submit_async(rung, g_hat, U_epi, cert)
    return k, lam, mode, (U_ale, U_epi)
```

## 3. 推导

**引理 19（蒸馏间隙的静默放松界）** 设模态分布支撑有界、熵在 2-Wasserstein 度量下满足 |H(μ)−H(ν)| ≤ c_H·W_2(μ,ν)。若 W_2(π_S, π_T) ≤ ĝ，则 |H_S(M|o) − H_T(M|o)| ≤ c_H·ĝ。因此学生自报的 U_epi^S 可比老师真实值少 c_H·ĝ；若直接拿它去算 λ，会相对 R69 的安全水位把 λ 压低最多 ∝ c_H·ĝ——这就是 **silent loosening（静默放松）**：蒸馏越激进，系统越安全地「看起来」确定。取 κ ≥ c_H 的膨胀 U_epi^inf = U_epi^S + κ·ĝ 可恢复单侧安全。系：ĝ→0 时回到 R69；ĝ 越大，膨胀必须越大，bonus 越难兑换。

**引理 20（截止期 VoI 与快慢认知分工）** 对截止期为 δ 的决策，若往返延迟 τ ≥ δ，即时 VoI = 0，只剩 γ^{τ−δ} 的延迟价值。因此云升级只对时标 T_epi ≥ τ 的**慢 epistemic**有正收益；对**快 epistemic**（碰撞、抓取窗口）必须在 δ 内由局部阶梯解决。系：把 U_epi 按歧义时标再分为 fast/slow，fast 只许 r_0/r_1，slow 才许 r_2/r_3——从结构上杜绝「等云时撞上」。

**引理 21（陈旧失效）** 设回包年龄 a，链路抖动与场景漂移使有效熵 H_eff = H + ρ(a)，ρ 单调增。若 H_eff ≥ H_pre，则并包不降低后验熵，应丢弃；只有 H_eff < H_pre 时才允许并入，且 λ 不升。系：陈旧回包不能兑换 bonus，防止「用旧答案消解新歧义」。

**定理 18（CASCADE 对 R69 无安全回退且严格包含）** 在 A99–A101 下：(i) 只要 bonus 未获证书，λ_CASCADE ≥ λ_R69（同观测、同标定）；(ii) 当 π_S = π_T（ĝ=0）且云预算 B=0，CASCADE 与 R69 逐指令相同；(iii) 证书有效且升级在截止期内降低 U_epi 时，期望风险 ≤ R69，效率获得 resolution bonus。故 R69 是 CASCADE 在 (ĝ=0, B=0) 的边界：安全不让步，效率 bonus 需证书兑换。

**定理 19（阶梯 satisficing 最优）** 在 A100（阶梯嵌套、成本随保真度单调增、增量 VoI 递减/超模）下，给定硬熵目标 τ_H 与截止期，「最便宜且达标的级」在所有可行级分配中成本最优。系：舰队共享上行时，按 VoI 密度的二价拍卖最大化总 VoI（定义 324）；单机预算为 n=1 的特例。

## 6. 本轮最大风险

**一句话**：CASCADE 会把「蒸馏成功」变成「自我沉默」——蒸馏损失天然奖励学生与老师一致、且压掉尾部与校准，于是学生越像老师越自信，R69 的 U_epi 被系统性低估，系统越不会升级到云，恰恰在最需要第二意见的罕见歧义上以高置信复读老师的系统性错误；而用来发现这一点的 gap 估计器又与蒸馏共享同一分布，天然看不见这个盲区——**越省带宽，越自信地错**。

**次级风险与缓解**：
1. **静默放松**（膨胀不足 → λ 被压低）→ 引理 19 单侧膨胀 + 证书门控（定义 314、322）；
2. **蒸馏投毒/后门** → 非蒸馏来源的 SSA 影子自审 + ℰ_dist 对抗训练 + 旧版影子对照（定义 319、320）；
3. **云侧越权/拜占庭** → 「云提议、边认证」+ 本地投影 + 链路完整性（定义 321、323）；
4. **等云等出事故** → 快/慢 epistemic 分工 + 硬截止期 + 阶梯 satisficing（引理 20、定义 317）；
5. **陈旧答案消解新歧义** → 年龄惩罚 ρ(a) 与「陈旧不得降 λ」（引理 21、定义 318）；
6. **版本偏斜与灾难遗忘** → 版本配对、bonus 冻结、回放 + EWC 刷新（定义 326、E312）。

```python
# IP-264 UPD：不确定性保持蒸馏（四项联合，防坍缩/防压平/防过自信）
def upd_loss(o, v_T, v_S, modes_T, modes_S):
    L_flow = mse(v_S(x_s, s, z_S), v_T(x_s, s, z_T).detach())     # 分布匹配
    L_mode = w2(mode_dist(modes_S), mode_dist(modes_T).detach())  # 模态结构
    L_cal  = abs(ece(modes_S, o) - ece(modes_T, o).detach())      # 校准
    L_safe = relu(margin_T(o) - margin_S(o)).mean()               # 安全盾只许更严
    return L_flow + lm*L_mode + lc*L_cal + ls*L_safe

# IP-265 GAP：间隙上界 + 膨胀（堵静默放松）
def certify_and_inflate(U_epi_S, probes, student, teacher, kappa, alpha=0.1):
    g_hat = conformal_quantile([dist(student.dist(o), teacher.dist(o))
                                for o in probes], alpha)
    return U_epi_S + kappa * g_hat, g_hat                          # 引理 19

# IP-267 LDL：最便宜且够用；快歧义绝不等云
def choose_rung(modes, w, deadline, target_H, budget):
    for rung in [EDGE_PRIOR, LOCAL_SENSE, CLOUD, HUMAN]:
        if not budget.allow(rung) or not c_ras_wm.certify_rung(rung): continue
        if expected_posterior_entropy(modes, w, rung, deadline) <= target_H:
            return rung
    return CONSERVATIVE_ONLY

# IP-268 TSM：陈旧回包只许丢弃，不许降 λ
def merge_or_discard(U_epi, pending, now):
    for msg in pending:
        H_eff = msg.H + rho(now - msg.teacher_ts)
        if H_eff < entropy_of(U_epi):                 # 只在仍能降熵时并入
            U_epi = bayes_merge(U_epi, msg)
        # 否则丢弃：陈旧不得兑换 bonus
    return U_epi

# IP-270 CEG：云提议、边认证
def dispose(advice, o, wm_preds):
    a = advice.action
    return (a if c_ras_wm.certify_prefix(a, wm_preds)
            else project_to_certified(a, o))          # 越权即投影/拒绝

# IP-276 主闭环（继承 R69 FLUID-RAS）
def CASCADE_round(M, obs):

    U_ale, U_epi_S, modes = M.student.aud(z_S, o)

    elif rung == CLOUD:

    U_epi = M.tsm.merge_or_discard(U_epi, M.link.pending(), M.now)
    cert  = M.jcert.cascade(M.j_fluid, g_hat, M.student.ece,
                            M.ssa.pass_rate, M.version_pair)
```

## 4. 推导

**引理 19（静默放松界）** 若 `W_2(π_S,π_T) ≤ ĝ` 且熵在 W_2 下 `c_H`-Lipschitz，则 `|H_S − H_T| ≤ c_H·ĝ`。直接用 `U_epi^S` 会把 λ 相对 R69 压低最多 `∝c_H·ĝ`——蒸馏越激进越「看起来确定」。取 `κ ≥ c_H` 的膨胀可恢复单侧安全；`ĝ→0` 回到 R69。

**引理 20（截止期 VoI 与快慢分工）** 若 `τ ≥ δ`，即时 VoI = 0，只剩 `γ^{τ−δ}` 延迟项。云升级只对时标 `≥τ` 的慢 epistemic 有正收益；快 epistemic 必须由 r_0/r_1 在 δ 内解决。系：fast 只许边、slow 才许云。

**引理 21（陈旧失效）** `H_eff = H + ρ(a)`，ρ 单调增。若 `H_eff ≥ H_pre`，并包不降熵，应丢弃；陈旧回包不得降低 λ、不得兑换 bonus。

**定理 18（对 R69 无安全回退且严格包含）** 在 A99–A101 下：bonus 未获证书时 `λ_CASCADE ≥ λ_R69`；`π_S=π_T`（ĝ=0）且 `B=0` 时两者逐指令相同；证书有效且升级在截止期内降 U_epi 时，期望风险 ≤ R69 且效率获 bonus。R69 = (ĝ=0, B=0) 边界。

**定理 19（阶梯 satisficing 最优）** 在 A100（嵌套、成本单调增、增量 VoI 递减/超模）下，给定 τ_H 与截止期，「最便宜且达标」成本最优；系：VoI 密度二价拍卖最大化舰队总 VoI，单机预算为 n=1 特例。

## 7. 本轮最大风险

**一句话**：CASCADE 会把「蒸馏成功」变成「自我沉默」——蒸馏奖励学生与老师一致、压掉尾部与校准，于是学生越像老师越自信，R69 的 U_epi 被系统性低估，系统越不会升级到云，恰在最需要第二意见的罕见歧义上以高置信复读老师的系统性错误；而发现这一点的 gap 估计器又与蒸馏共享同一分布，天然看不见这个盲区——**越省带宽，越自信地错**。

**次级风险与缓解**：膨胀不足/静默放松（引理 19 + 证书门控）；蒸馏投毒/后门（非蒸馏来源 SSA + 旧版影子 + ℰ_dist 对抗）；云侧越权/拜占庭（云提议边认证 + 本地投影）；等云等出事故（快慢分工 + 硬截止期 + satisficing）；陈旧答案消解新歧义（ρ(a) + 陈旧不得降 λ）；版本偏斜/灾难遗忘（bonus 冻结 + 回放/EWC）。
