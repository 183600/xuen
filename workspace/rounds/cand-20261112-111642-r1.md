# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 1 轮；本轮灵感：「主动交互」×「数据质量」）

> 第 60 轮的 SGEC 让系统第一次具备「场景先验→意图约束→执行→证据」的前馈能力：SSM 把场景变成阻抗先验、CIEC 把意图锁成实时约束、EPIR 用序号+哈希保证 EV-exec 不丢不乱序、SERC 把四者串成闭环。但它暴露了**三个更深的局限**：
> 1. **认知仍是被动的**：SSM 等观测、CIEC 等意图、CLEP 等接触。系统从不「开口问」——当 `scene_conf < 0.7` 或意图映射有歧义时，它只能回退通用先验或猜，而不是**主动索取一条能最快消除不确定性的信息**。这使「认知先行」在信息不足时退化为「保守等待」。
> 2. **证据被当成等质量**：EPIR 只校验 `seq_id + hash`（**完整性 integrity**），却把每一条 EV-exec 当作同等可信地喂给 XMC+。而真实数据是有**质量差异**的：传感器噪声、时间陈旧、样本残缺、跨源冲突、来源偏见。把「完整但错误」的数据与「新鲜且正确」的数据等权融合，等于让低质量数据稀释甚至污染场景/阻抗信念。
> 3. **主动交互本身有代价且会改变数据**：向人提问不是免费的（注意力、打扰、安全），更危险的是**问题会塑造答案**——「地面很滑，对吧？」得到的「对」是低独立性的数据。主动交互若不受约束，会制造出「质量看似高、其实被诱导」的数据，形成自我确认的回音室。

## 0. 直觉与动机

**灵感 1（主动交互 = 用提问买信息 → PIQ 主动信息询问）**
直觉：人机协作里，机器人不该只是「听懂再执行」，而应像一个好助手：不确定时**主动问一句**、看不清时**主动换个视角**、学不会时**主动请求示范**。把「问什么、问谁、何时问、问几次」形式化为一个**信息获取动作空间** A_pro；每种询问都是一次「用人类注意力换不确定性下降」的交易。关键洞见：**主动交互的触发条件不是「不确定」，而是「这条信息的边际价值 > 打扰它的代价」**——否则机器人会变成复读机式的追问者。

**灵感 2（数据质量是信息的单位价值 → DQG 数据质量门）**
直觉：数据不是「有/无」，而是「多好」。一条 EV-exec 的质量至少包含**准确**（测量置信）、**时效**（越旧越不可信，按半衰期指数衰减）、**完整**（样本是否缺项）、**一致**（与其它来源是否矛盾）、**来源可信**（该人类/传感器历史是否靠谱），以及常被忽略却致命的**独立**（是否被引导性问题污染）。用六维质量向量 Q(e) 打分，按**木桶原则**（最弱维度定级）过门：accept / downweight / reject。关键洞见：**质量门不是事后清洗，而是信念更新的准入控制**——低质量证据根本不允许进入 `belief`。

**灵感 3（两者通过 VOI 耦合 → 主动-质量闭环 AIQ）**
直觉：主动交互是「买信息」，数据质量是「买入信息的成色」，二者天然由**信息价值 VOI**统一：
`VOI_pro(q) = 预期不确定性下降 × 预期回答质量 − 打扰成本 − 安全风险 − 时延成本`。
只有当 `VOI_pro(q) > θ_voi` 才值得开口；回答进来后先过数据质量门，再按质量加权更新信念。关键洞见：**提问策略与质量评估必须联合优化**——问一个高质量来源的好问题，胜过问十个低质量来源的坏问题。

**灵感 4（预测性主动 → AIP 预见性意图）**
直觉：第 60 轮的 CIEC 是「意图到达后再锁约束」，仍有 τ_response 时延。真正的主动交互是**在意图说出口之前就预判**：从任务阶段、场景、历史交互预测未来 horizon 内的意图分布；若某意图概率高且「预置成本」低，就提前做**可撤销的影子锁定（shadow lock）**，等真实意图到达再转正或撤销。关键洞见：**主动不是抢跑，而是「预置 + 可撤销」**——预测错误必须能在 τ_deadline 内无损撤回。

**灵感 5（交互疲劳与耐心预算）**
直觉：人会烦。主动交互的价值必须受**人类耐心预算 B_human** 约束：单位任务的询问次数、注意力额度、疲劳速率。预算耗尽时机器人必须**自解**（回退保守先验/安全保持），而不是继续骚扰。这把「主动」从「想不想问」变成「配不配问」。

**灵感 6（PCE+++++ → 六维认知-社交-质量预算）**
直觉：在第 60 轮 B_cog=(B_scene,B_intent,B_ros,B_exec) 上增加 `B_human`（注意力/耐心）与 `B_dq`（质量审计、来源核验、交叉取证额度）。任一耗尽即触发对应安全策略：B_scene 空→通用场景先验；B_intent 空→默认约束；B_ros 异常→本地闭环；B_human 空→禁止询问、自解；B_dq 空→拒绝低可信来源、只用本地高可信证据；B_exec 空→原有降级。

## 1. 形式化定义（增量：定义 161–170）

**定义 161（主动交互动作空间 A_pro）** 一次主动交互 `a = (q_type, q_target, q_content, δ_deadline, expected_quality)`，其中：
- **询问类型** `q_type ∈ {CLARIFY_INTENT, CONFIRM_SCENE, REQUEST_DEMO, REQUEST_VIEWPOINT, ASK_PREFERENCE, SAFE_HOLD}`
- **询问对象** `q_target ∈ {human_operator, remote_supervisor, self_reprobe, peer_robot}`
- **内容约束** `q_content` 必须来自**非诱导模板集** `T_nl`（禁止预设答案的 yes/no 引导句，见定义 170）
- **期望质量** `expected_quality = E[Q(resp) | q_type, q_target, ctx]`
- **截止** `δ_deadline`：超过则视为「无回答」，按未获取处理。

**定义 162（不确定性场 U）** `U = (U_scene, U_intent, U_exec)`：
- `U_scene = H(π_scene)`（场景后验熵）
- `U_intent = H(p_I)`（意图后验熵）或映射歧义度 `ambiguity(ϕ_intent→constraint)`
- `U_exec = tr(Cov[K])`（阻抗估计的迹协方差）或第 60 轮 `D⁺`
- 归一化：`Ũ_i = U_i / U_i^max`，便于跨量纲比较。

**定义 163（数据质量向量 Q(e)）** 对证据 `e`：
`Q(e) = (q_acc, q_time, q_comp, q_cons, q_prov, q_ind) ∈ [0,1]^6`
- `q_acc` 测量置信；`q_time = 2^{-(t_now - t_e)/h}`（半衰期 h）；`q_comp` 完整度；`q_cons` 跨源一致度；`q_prov = E[Beta(α_s,β_s)]` 来源历史可信；`q_ind = 1 - leading_bias` 非诱导性。
- **聚合质量（木桶下界）**：`Q_min(e) = min_i q_i`，`Q_prod(e) = (Π_i q_i)^{1/6}`；门控用 `Q_min`，加权融合用 `Q_prod`（或混合 `Q_eff = λ·Q_min + (1-λ)·Q_prod`）。

**定义 164（来源可信 Beta 后验）** `T_s = Beta(α_s, β_s)`，`E[T_s] = α_s/(α_s+β_s)`。当证据被后续执行的 EV-exec 证实/证伪时：`α_s += 1`（正确）或 `β_s += 1`（错误）。用于识别「总是说错的人/传感器」。

**定义 165（质量门与质量加权融合 Q-XMC）** 门控函数
```
gate(e) = accept      if Q_min(e) ≥ τ_accept
          downweight  if τ_reject ≤ Q_min(e) < τ_accept
          reject      if Q_min(e) < τ_reject
```
信念更新：`belief' = Σ_{e: gate≠reject} w_e·e / Σ w_e`，其中 `w_e = Q_prod(e)`（accept）或 `0.5·Q_prod(e)`（downweight）；**reject 的证据权重严格为 0**。这替换了第 60 轮 XMC+ 的等权/置信加权融合。

**定义 166（主动信息价值 VOI_pro）**
```
VOI_pro(q) = Ĝ(q) · Q̂(q) − λ_h·C_attn(q) − λ_r·R_act(q) − λ_t·L(q)
```
- `Ĝ(q) = E_{resp}[H(belief) − H(belief|resp)]`：预期不确定性下降（信息增益）
- `Q̂(q) = expected_quality(q)`：预期回答质量（定义 161）
- `C_attn`：注意力/打扰成本；`R_act`：主动动作的安全风险（如换视角的碰撞风险）；`L`：时延成本
- **询问判据**：`q* = argmax_q VOI_pro(q)`，且仅当 `VOI_pro(q*) > θ_voi` 执行；否则沉默并自解。

**定义 167（人类耐心预算 B_human）** `B_human = (A_units, ρ_fatigue, n_max)`：注意力额度、疲劳速率、单任务询问上限。每次询问扣 `cost_attn(q)`；`remaining < 0` 或 `queries_this_task ≥ n_max` 时进入 **SELF_RESOLVE** 模式，禁止一切 `q_target=human_*` 的动作。

**定义 168（主动-质量闭环 AIQ）** 算子 `AIQ(M, task, ctx)`：
```
① U ← M.uncertainty.measure()
② q ← PIA.decide(U, ctx, M.belief)            # 无 q 则为 None（沉默）
③ if q ≠ None:
     resp ← interact(q)                          # 询问人/重采/换视角
     M.human_budget.consume(q)
     (dec, Q) ← M.dqg.gate(resp)
     if dec ≠ reject: M.belief ← quality_weighted_fuse(M.belief, resp, Q)
④ I_pred ← AIP.predict(ctx.window, horizon=2s)  # 预见性意图
   if max(I_pred) > θ_ant: M.ertc.shadow_lock(argmax I_pred)
⑤ M, fused, D⁺, EV, cert ← SERC(M, scene, intent, δ_f_req)   # 第 60 轮闭环
⑥ J_aiq ← build_aiq_certificate(U_before=U, U_after=measure(), q, Q, cert)
⑦ return M, J_aiq
```

**定义 169（预见性意图 AIP）** `AIP: context_window → p_I(·|ctx)` 预测未来 horizon 内意图分布。影子锁定：若 `p_max > θ_ant`，对 `I* = argmax p_I` 预置约束 `C_pre = ϕ(I*)`，标记 `revocable=true`、`expire=τ_deadline`；真实意图到达时若一致则转正（commit），否则在 `τ_deadline` 内无损撤销（rollback）。**影子锁定不消耗执行预算，但占用锁优先级。**

**定义 170（非诱导查询模板与主动交互证书 J_aiq）** 
- **非诱导约束**：`q_content ∈ T_nl`，且 `leading_bias(q) = 0`；`T_nl` 要求开放式中性表述（「你希望多轻？」而非「是不是要很轻？」）。
- **证书** `J_aiq = (U_before, U_after, q_used, Q_used, interaction_cost, voi_realized, safe_hold)`，作为第 60 轮 J_exec 的**认知-质量补充**，可被审计：若 `U_after > U_before`（越问越乱）则标注 `UNINFORMATIVE_QUERY` 并回滚该证据。

### IP-161 PIQ（主动信息询问）

```python
class UncertaintyField:
    def __init__(self, scene_model, intent_belief, exec_cov):
        self.scene_model, self.intent_belief, self.exec_cov = scene_model, intent_belief, exec_cov
    def measure(self):
        def H(p):
            p = np.clip(np.asarray(p, float), 1e-9, 1.0); return float(-(p*np.log(p)).sum())
        U_scene = H(self.scene_model.scene_prior)
        U_intent = H(self.intent_belief.posterior)
        U_exec = float(np.trace(self.exec_cov))
        return np.array([U_scene, U_intent, U_exec])

class ProactiveInteractionAgent:
    QUERY_TYPES = ['CLARIFY_INTENT', 'CONFIRM_SCENE', 'REQUEST_DEMO',
                   'REQUEST_VIEWPOINT', 'ASK_PREFERENCE']
    def __init__(self, human_budget, theta_voi=0.15, n_max=3):
        self.budget, self.theta_voi, self.n_max = human_budget, theta_voi, n_max
        self.queries_this_task = 0

    def decide(self, U, ctx, belief):
        if self.budget.remaining <= 0 or self.queries_this_task >= self.n_max:
            return None                      # SELF_RESOLVE：禁止打扰人
        best, best_v = None, -1e9
        for q in self._candidates(U, ctx):
            v = self._voi(q, U, belief)
            if v > best_v: best, best_v = q, v
        return best if best_v > self.theta_voi else None

    def _voi(self, q, U, belief):
        gain  = self._expected_entropy_reduction(q, U, belief)   # Ĝ(q)
        q_exp = self._expected_quality(q)                        # Q̂(q)
        return (gain * q_exp
                - self.lam_h * self._attention_cost(q)
                - self.lam_r * self._risk(q)
                - self.lam_t * q.latency)

    def _candidates(self, U, ctx):
        cands = []
        if U[1] > 0.5: cands.append(self._make('CLARIFY_INTENT', 'human_operator'))
        if U[0] > 0.6: cands += [self._make('CONFIRM_SCENE', 'human_operator'),
                                 self._make('REQUEST_VIEWPOINT', 'self_reprobe')]
        if U[2] > 0.7: cands.append(self._make('REQUEST_DEMO', 'human_operator'))
        return cands
```

### IP-162 DQG（数据质量门）

```python
class DataQualityGate:
    def __init__(self, tau_accept=0.6, tau_reject=0.3, halflife=30.0):
        self.tau_accept, self.tau_reject, self.halflife = tau_accept, tau_reject, halflife
        self.trust = defaultdict(lambda: Beta(1.0, 1.0))   # 来源 -> Beta

    def score(self, e, now):
        q_acc  = float(e.get('confidence', 0.5))
        q_time = 0.5 ** ((now - e['timestamp']) / self.halflife)
        q_comp = float(e.get('completeness', 1.0))
        q_cons = self._cross_source_consistency(e)         # 与其它源矛盾则下降
        q_prov = self.trust[e['source']].mean()
        q_ind  = 1.0 - float(e.get('leading_bias', 0.0))
        return dict(acc=q_acc, time=q_time, comp=q_comp,
                    cons=q_cons, prov=q_prov, ind=q_ind)

    def gate(self, e, now):
        Q = self.score(e, now)
        q_min = min(Q.values())                             # 木桶原则
        if q_min >= self.tau_accept: return 'accept', Q
        if q_min <  self.tau_reject: return 'reject', Q
        return 'downweight', Q

    def update_trust(self, source, was_correct):
        if was_correct: self.trust[source].alpha += 1
        else:           self.trust[source].beta  += 1

    def _cross_source_consistency(self, e):
        peers = self.recent_by_region(e['region'])
        if not peers: return 1.0
        d = np.median([abs(e['value'] - p['value']) for p in peers])
        return float(np.exp(-d))                            # 分歧大→一致度低
```

### IP-163 Q-XMC（质量加权跨模态共识）

```python
def quality_weighted_fuse(belief, evidences, dqg, now):
    num = den = 0.0
    for e in evidences:                                     # 跨模态证据
        dec, Q = dqg.gate(e, now)
        if dec == 'reject':
            continue                                        # 低质量证据绝不入信念
        q_eff = float(np.prod(list(Q.values())) ** (1/len(Q)))  # 几何均值
        w = q_eff if dec == 'accept' else 0.5 * q_eff
        num += w * e['value']; den += w
    return (num / den) if den > 0 else belief
```

### IP-164 AIQ（主动-质量闭环）

```python
def active_information_quality_loop(M, task, ctx):
    U_before = M.uncertainty.measure()
    q = M.pia.decide(U_before, ctx, M.belief)
    Q_used, dec = None, None
    if q is not None:
        resp = interact(q)                                  # 主动询问/重采/换视角
        M.human_budget.consume(q)
        dec, Q_used = M.dqg.gate(resp, now=time.time())
        if dec != 'reject':
            M.belief = quality_weighted_fuse(M.belief, [resp], M.dqg, time.time())
        M.pending_trust.append((resp['source'], resp['seq_id']))  # 待事后核验

    I_pred = M.aip.predict(ctx.window, horizon=2.0)         # 预见性意图
    if max(I_pred.values()) > M.theta_ant:
        M.ertc.shadow_lock(argmax(I_pred))

    M, fused, D_plus, EV, cert = scenario_perception_evolution_loop(
        M, task.scene, task.intent, task.delta_f_req)       # 第 60 轮 SERC 闭环

    U_after = M.uncertainty.measure()
    J_aiq = build_aiq_certificate(U_before, U_after, q, Q_used, dec, cert)
    if J_aiq['flag'] == 'UNINFORMATIVE_QUERY':
        M.rollback_last_evidence()
    return M, J_aiq

def build_aiq_certificate(U_b, U_a, q, Q, dec, cert):
    gain = float(np.linalg.norm(U_b - U_a))
    flag = 'UNINFORMATIVE_QUERY' if (q is not None and gain <= 0) else 'OK'
    return dict(U_before=U_b.tolist(), U_after=U_a.tolist(),
                q_used=q, Q_used=Q, q_decision=dec,
                interaction_cost=q.cost if q else 0.0,
                voi_realized=gain, flag=flag, exec_cert=cert)
```

### IP-165 PCE+++++（六维认知-社交-质量预算）

```python
class CognitiveSocialBudget:
    def __init__(self, scene_ops, intent_ops, ros_retry, exec_budget,
                 attention_units, dq_audits, fatigue_rate=0.05):
        self.B_scene, self.B_intent, self.B_ros, self.B_exec = scene_ops, intent_ops, ros_retry, exec_budget
        self.B_human = dict(units=attention_units, fatigue=fatigue_rate)
        self.B_dq = dict(audits=dq_audits)

    def query_allowed(self):
        return self.B_human['units'] > 0

    def consume(self, q):
        self.B_human['units'] -= q.cost
        if q.target.startswith('human'):
            self.B_dq['audits'] -= 1                    # 每次问人消耗一次审计额度

    def policy(self):
        if self.B_human['units'] <= 0: return 'SELF_RESOLVE'
        if self.B_dq['audits'] <= 0:   return 'TRUSTED_SOURCES_ONLY'
        if self.B_scene <= 0:          return 'GENERIC_SCENE_PRIOR'
        if self.B_ros <= 0:            return 'LOCAL_LOOP_ONLY'
        return 'NORMAL'
```

## 3. 复杂度与正确性（概要）

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PIQ（不确定性场+VOI） | O(N + \|A_pro\|·N) | O(N) | 贪心 VOI 停止，≤ n_max 次询问 |
| DQG（六维质量门） | O(1) + O(k) 跨源一致 | O(k + \|sources\|) | 木桶下界保守，reject 权重严格为 0 |
| Q-XMC | O(m) 证据融合 | O(m) | 低质量证据影响有界 ≤ τ_Q |
| AIQ | O(闭环 + 询问) | 复用 SERC | 证书可审计，越问越乱则回滚 |
| AIP（影子锁定） | O(\|I\|) | O(1) | τ_deadline 内可撤销，不占执行预算 |

**正确性定理（AIQ）**：设 A66–A72 成立——(A66) 质量门 `Q_min` 是证据可靠度的保守下界；(A67) VOI 估计误差 ≤ ε_voi；(A68) 来源 Beta 后验收敛；(A69) 耐心预算刻画人类容忍度；(A70) 影子锁定在 τ_deadline 内可无损撤销；(A71) reject 证据永不进入信念；(A72) 非诱导模板 `leading_bias=0`。则：
1. **质量单调性**：同等证据集下，Q-XMC 的后验误差不高于等权融合（正权重凸组合的方差收缩）。
2. **主动停止性**：贪心 VOI 在 ≤ n_max 步内停止，且 `E[H(belief_{t+1})] ≤ E[H(belief_t)]`（当 VOI>θ 时严格下降）。
3. **抗污染有界性**：任一被 reject 的单一证据对信念的影响为 0；被 downweight 的影响 ≤ 0.5·Q_prod。

```python
class UncertaintyField:
    def __init__(self, scene_model, intent_belief, exec_cov):
        self.scene_model, self.intent_belief, self.exec_cov = scene_model, intent_belief, exec_cov
    def measure(self):
        def H(p):
            p = np.clip(np.asarray(p, float), 1e-9, 1.0); return float(-(p*np.log(p)).sum())
        return np.array([H(self.scene_model.scene_prior),
                         H(self.intent_belief.posterior),
                         float(np.trace(self.exec_cov))])

class ProactiveInteractionAgent:
    QUERY_TYPES = ['CLARIFY_INTENT', 'CONFIRM_SCENE', 'REQUEST_DEMO',
                   'REQUEST_VIEWPOINT', 'ASK_PREFERENCE']
    def __init__(self, human_budget, theta_voi=0.15, n_max=3):
        self.budget, self.theta_voi, self.n_max = human_budget, theta_voi, n_max
        self.queries_this_task = 0

    def decide(self, U, ctx, belief):
        if self.budget.remaining <= 0 or self.queries_this_task >= self.n_max:
            return None                                  # SELF_RESOLVE
        best, best_v = None, -1e9
        for q in self._candidates(U, ctx):
            v = self._voi(q, U, belief)
            if v > best_v: best, best_v = q, v
        return best if best_v > self.theta_voi else None

    def _voi(self, q, U, belief):
        gain  = self._expected_entropy_reduction(q, U, belief)   # Ĝ(q)
        q_exp = self._expected_quality(q)                        # Q̂(q)
        return (gain * q_exp
                - self.lam_h * self._attention_cost(q)
                - self.lam_r * self._risk(q)
                - self.lam_t * q.latency)

    def _candidates(self, U, ctx):
        cands = []
        if U[1] > 0.5: cands.append(self._make('CLARIFY_INTENT', 'human_operator'))
        if U[0] > 0.6: cands += [self._make('CONFIRM_SCENE', 'human_operator'),
                                 self._make('REQUEST_VIEWPOINT', 'self_reprobe')]
        if U[2] > 0.7: cands.append(self._make('REQUEST_DEMO', 'human_operator'))
        return cands
```

### IP-162 DQG（数据质量门）

```python
class DataQualityGate:
    def __init__(self, tau_accept=0.6, tau_reject=0.3, halflife=30.0):
        self.tau_accept, self.tau_reject, self.halflife = tau_accept, tau_reject, halflife
        self.trust = defaultdict(lambda: Beta(1.0, 1.0))

    def score(self, e, now):
        return dict(
            acc  = float(e.get('confidence', 0.5)),
            time = 0.5 ** ((now - e['timestamp']) / self.halflife),
            comp = float(e.get('completeness', 1.0)),
            cons = self._cross_source_consistency(e),
            prov = self.trust[e['source']].mean(),
            ind  = 1.0 - float(e.get('leading_bias', 0.0)))

    def gate(self, e, now):
        Q = self.score(e, now)
        q_min = min(Q.values())                            # 木桶原则
        if q_min >= self.tau_accept: return 'accept', Q
        if q_min <  self.tau_reject: return 'reject', Q
        return 'downweight', Q

    def update_trust(self, source, was_correct):
        if was_correct: self.trust[source].alpha += 1
        else:           self.trust[source].beta  += 1

    def _cross_source_consistency(self, e):
        peers = self.recent_by_region(e['region'])
        if not peers: return 1.0
        d = np.median([abs(e['value'] - p['value']) for p in peers])
        return float(np.exp(-d))
```

```python
def quality_weighted_fuse(belief, evidences, dqg, now):
    num = den = 0.0
    for e in evidences:
        dec, Q = dqg.gate(e, now)
        if dec == 'reject':
            continue                                       # 低质量证据绝不入信念
        q_eff = float(np.prod(list(Q.values())) ** (1 / len(Q)))
        w = q_eff if dec == 'accept' else 0.5 * q_eff
        num += w * e['value']; den += w
    return (num / den) if den > 0 else belief
```

```python
def anticipatory_lock(ertc, predictor, window, theta_ant, tau_deadline):
    p = predictor.predict(window)
    if max(p.values()) <= theta_ant:
        return None
    I_star = max(p, key=p.get)
    ertc.shadow_lock(I_star, revocable=True, expire=tau_deadline)
    return I_star

def on_intent_arrival(ertc, predictor, intent):

        if ertc.shadow_intent == intent:
            ertc.commit_shadow_lock()                      # 预测正确：转正
        else:
            ertc.rollback_shadow_lock()                    # 预测错误：无损撤销
```
