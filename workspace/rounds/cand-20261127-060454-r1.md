### 第 1 轮灵感驱动研究记录（v26）

**灵感词**：检索增强生成、场景理解

**直觉与动机**：
前序框架 SRC-USC v25 已把感知-合规-能量-结构-语义-重构-协同七证熔于一炉，但其语义建图证书（SMC）只证明「看见了什么」，并未证明「为何这样做」——决策所依赖的世界知识与任务规范来自参数记忆或离线语料，缺乏可追溯、可复核、可追责的证据链。受「检索增强生成」启发：把机器人决策改写为「查询→检索→接地→生成」的可审计管道，检索到的每条证据都必须携带来源签名、时效戳、文本蕴含下界与场景锚定证书；受「场景理解」启发：场景不再是扁平对象列表，而是带空间关系、可供性、遮挡与自由空间的结构化场景图 𝒢=(𝒪,ℰ)，其完备性、几何一致性与可供性可执行性均需可证。核心洞见：**RAG 为决策提供可追溯的「外部记忆证据」，场景理解为证据提供「物理落地锚点」，二者互为校验——检索无场景则悬空，场景无检索则短视**。据此把「语义正确」升级为「证据可追溯 + 场景可落地 + 跨模态不矛盾」三位一体。

**形式化目标**：
1. 定义检索增强接地证书（RAGC）：对查询 q 与任务谓词 φ，Top-K 检索覆盖 ℙ(∃d∈R_K(q): d⊨φ)≥1-α_r；每条生成断言 c_j 的支撑集 Supp(c_j)⊆D×𝒮 非空；文本蕴含忠实度 NLI(d,c_j)≥τ 且无支撑断言比例 ≤δ_h；证据时效 age(d)≤T_stale 或显式标记过期。
2. 定义场景理解证书（SUC）：场景图 𝒢 的 conformal 对象召回 ℙ(Recall≥1-α_s)；空间关系与度量几何一致（d_H、关系方向容差）；可供性谓词 Aff(o,a)⇒几何/物理可执行；遮挡与自由空间完备性。
3. 定义检索-场景一致性证书（RSC）：文本证据与场景图之间的跨模态蕴含/矛盾检测，矛盾率 ≤δ_con，指代消解须落到具体场景实体。
4. 构建检索-场景统一准入门（RSUC v26）：SRC-USC ∪ RAGC ∪ SUC ∪ RSC，Exec_v26 ⊆ Exec_v25。
5. 证明检索投毒/场景漂移/跨模态矛盾三重退化路径下，单调退化链仍严格保持。

**本轮最大风险**：检索语料的签名信任根一旦被污染或提示注入伪装成高相关证据，RAGC 的「覆盖-忠实-时效」三重校验会被高 NLI 分数的对抗文本整体绕过，使机器人在场景锚点看似成立的情况下执行被投毒的任务规范——即「证据链完整但证据本身是假的」。

# ============================================================
# IP-448 Retrieval-Augmented Grounding Certificate (RAGC)
# ============================================================
@dataclass
class RetrievalAugmentedGroundingCertificate:
    """检索覆盖 + 证据签名/时效 + 断言接地 + NLI 忠实度"""
    corpus: 'KnowledgeCorpus'
    retriever: 'DenseRetriever'
    trusted_keys: set[str] = field(default_factory=set)  # 语料发布者信任根
    alpha_r: float = 0.05
    tau_nli: float = 0.80
    delta_h: float = 0.01
    T_stale: float = 30 * 24 * 3600.0
    K: int = 8

    def verify_provenance(self, docs: list['Doc']) -> bool:
        """每条证据签名可验证且发布者在信任根内（防投毒/提示注入）"""
        for d in docs:
            if not verify_signature(d.content_hash, d.signature, d.publisher_key):
                return False
            if d.publisher_key not in self.trusted_keys:
                return False
        return True

    def verify_retrieval_coverage(self, query: str, phi: 'TaskPredicate',
                                  calibrator: 'ConformalCalibrator') -> bool:
        """ℙ(∃d∈R_K(q): d⊨φ) ≥ 1-α_r，阈值经离线 query 级 conformal 校准"""
        docs = self.retriever.topk(query, self.K)
        if not docs or not any(phi.satisfied_by(d) for d in docs):
            return False
        # 非一致性分数 s(q)=1-max_d score(d,φ)，用校准分位数给边际覆盖保证
        s = 1.0 - max(phi.score(d) for d in docs)
        return s <= calibrator.quantile(1 - self.alpha_r)

    def verify_grounding(self, claims: list['Claim'],
                         scene_graph: 'SceneGraph') -> bool:
        """每条断言须同时有文本支撑与场景锚点，缺一即拒"""
        for c in claims:
            text_ok = any(d in self.retriever.last_retrieved for d in c.support_docs)
            scene_ok = all(scene_graph.has_entity(e) for e in c.scene_anchors)
            if not c.support_docs or not c.scene_anchors or not (text_ok and scene_ok):
                return False
        return True

    def verify_faithfulness(self, claims: list['Claim']) -> bool:
        """无支撑断言率 ≤ δ_h，且支撑文档对断言蕴含 ≥ τ"""
        if not claims:
            return True
        unsupported = 0
        for c in claims:
            best = max((nli_entailment(d.text, c.text) for d in c.support_docs),
                       default=0.0)
            if best < self.tau_nli:
                unsupported += 1
        return unsupported / len(claims) <= self.delta_h

    def verify_freshness(self, docs: list['Doc'], now: float) -> bool:
        """证据未过期，或过期证据被显式标记且不被用于关键断言"""
        for d in docs:
            if now - d.timestamp > self.T_stale and not d.stale_flagged:
                return False
        return True

    def verify_all(self, query, phi, claims, scene_graph, docs, calibrator,
                   now) -> bool:
        return (self.verify_provenance(docs)
                and self.verify_retrieval_coverage(query, phi, calibrator)
                and self.verify_grounding(claims, scene_graph)
                and self.verify_faithfulness(claims)
                and self.verify_freshness(docs, now))

# IP-449 Scene Understanding Certificate (SUC)
# ============================================================
@dataclass
class SceneUnderstandingCertificate:
    """场景图完备性 + 几何一致 + 空间关系 + 可供性 + 遮挡/自由空间"""
    scene_graph: 'SceneGraph'          # 𝒢 = (𝒪, ℰ)
    alpha_s: float = 0.05
    eps_geo: float = 0.03              # 多视角重投影/几何容差 (m)
    delta_rel: float = 0.05            # 空间关系方向/距离容差
    occlusion_margin: float = 0.02

    def verify_object_recall(self, gt: Optional['SceneGraph'] = None,
                             calibrator: Optional['ConformalCalibrator'] = None) -> bool:
        """conformal 对象召回：ℙ(Recall ≥ 1-α_s)；无 GT 时用多视角一致性"""
        if gt is not None:
            matched = sum(1 for o in gt.objects
                          if self.scene_graph.match(o, tol=self.eps_geo))
            recall = matched / max(1, len(gt.objects))
            return recall >= 1 - self.alpha_s
        return self._multi_view_recall_check(calibrator)

    def verify_geometric_consistency(self, views: list['View']) -> bool:
        """同一对象多视角几何重投影误差 ≤ ε_geo"""
        for o in self.scene_graph.objects:
            for v in views:
                if v.sees(o):
                    if reprojection_error(o, v) > self.eps_geo:
                        return False
        return True

    def verify_spatial_relations(self) -> bool:
        """关系谓词须与度量几何一致：on⇒接触面法向/高度，inside⇒包含，
        left-of⇒投影方向，near⇒距离阈值"""
        for (oi, r, oj) in self.scene_graph.relations:
            if not metric_consistent(oi, r, oj, self.scene_graph,
                                     tol=self.delta_rel):
                return False
        return True

    def verify_affordance_grounding(self) -> bool:
        """Aff(o,a) 必须由几何+物理谓词支撑（可承重/可抓取/可通行）"""
        for o, a in self.scene_graph.affordances:
            if not (geometry_supports(o, a) and physics_feasible(o, a)):
                return False
        return True

    def verify_occlusion_and_free_space(self, sensor: 'DepthSensor') -> bool:
        """遮挡区与自由空间不矛盾：ℱ 内不得有已观测占用；
        被遮挡区不得被断言为空（保守标记 unknown）"""
        for p in sensor.observed_points:
            if in_free_space(self.scene_graph, p):
                return False
        for o in self.scene_graph.objects:
            if self.scene_graph.is_in_occluded_region(o) and o.claimed_visible:
                if not self._visible_with_margin(o, sensor):
                    return False
        return True

    def verify_all(self, gt=None, calibrator=None, views=None, sensor=None) -> bool:
        ok = self.verify_object_recall(gt, calibrator)
        ok = ok and (views is None or self.verify_geometric_consistency(views))
        ok = ok and self.verify_spatial_relations()
        ok = ok and self.verify_affordance_grounding()
        ok = ok and (sensor is None or self.verify_occlusion_and_free_space(sensor))
        return ok

    def _multi_view_recall_check(self, calibrator) -> bool:
        # 以多视角新增对象边际增长率估计未观测召回上界
        return calibrator is not None and calibrator.recall_bound(self.scene_graph) >= 1 - self.alpha_s

    def _visible_with_margin(self, o, sensor) -> bool:
        return sensor.visible_fraction(o) >= 1.0 - self.occlusion_margin


# ============================================================
# IP-450 Retrieval-Scene Consistency Certificate (RSC)
# ============================================================
@dataclass
class RetrievalSceneConsistencyCertificate:
    """文本证据 ↔ 场景图的跨模态蕴含/矛盾/指代/空间谓词互证"""
    delta_con: float = 0.02
    tau_ground: float = 0.75

    def verify_cross_modal_entailment(self, claims: list['Claim'],
                                      scene_graph: 'SceneGraph') -> bool:
        """每条文本断言投影到场景事实后不得矛盾"""
        contradictions = 0
        for c in claims:
            facts = scene_graph.facts_for(c.scene_anchors)
            if nli_contradiction(c.text, facts) >= self.tau_ground:
                contradictions += 1
        return contradictions / max(1, len(claims)) <= self.delta_con

    def verify_referential_grounding(self, claims: list['Claim'],
                                     scene_graph: 'SceneGraph') -> bool:
        """所有指代（"它/那个/左侧的"）解析到唯一且存在的场景实体"""
        for c in claims:
            for ref in c.references:
                resolved = scene_graph.resolve(ref)
                if resolved is None or not scene_graph.has_entity(resolved):
                    return False
        return True

    def verify_spatial_text_consistency(self, docs: list['Doc'],
                                        scene_graph: 'SceneGraph') -> bool:
        """文本空间谓词（on/inside/left-of）与度量几何互证"""
        for d in docs:
            for (a, rel, b) in d.spatial_claims:
                oa, ob = scene_graph.resolve(a), scene_graph.resolve(b)
                if oa is None or ob is None:
                    return False
                if not metric_consistent(oa, rel, ob, scene_graph,
                                         tol=self.delta_rel):
                    return False
        return True

    def verify_all(self, claims, scene_graph, docs) -> bool:
        return (self.verify_cross_modal_entailment(claims, scene_graph)
                and self.verify_referential_grounding(claims, scene_graph)
                and self.verify_spatial_text_consistency(docs, scene_graph))


# ============================================================
# IP-451 RSUC — 检索-场景统一准入门 v26
# ============================================================
@dataclass
class RetrievalSceneUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'   # v25 七证
    ragc: RetrievalAugmentedGroundingCertificate
    suc: SceneUnderstandingCertificate
    rsc: RetrievalSceneConsistencyCertificate

    def admits(self, plan: 'MultiRobotPlan', sensor_data: dict) -> bool:
        # 1. 继承 v25 七证（单机 USMC + 语义/重构/协同）
        if not self.src_usc.admits(
            plan.multi_plan, sensor_data,
            gt_entities=sensor_data.get('gt_entities'),
            queries=sensor_data.get('queries'),
            retrieved=sensor_data.get('retrieved')):
            return False
        # 2. 检索增强接地证书
        ragc_ok = self.ragc.verify_all(
            query=sensor_data['query'], phi=sensor_data['task_predicate'],
            claims=plan.claims, scene_graph=self.suc.scene_graph,
            docs=self.ragc.retriever.last_retrieved,
            calibrator=sensor_data['retrieval_calibrator'],
            now=sensor_data['now'])
        if not ragc_ok:
            return False
        # 3. 场景理解证书
        if not self.suc.verify_all(
            gt=sensor_data.get('gt_scene'),
            calibrator=sensor_data.get('scene_calibrator'),
            views=sensor_data.get('views'),
            sensor=sensor_data.get('depth_sensor')):
            return False
        # 4. 检索-场景跨模态一致性证书
        if not self.rsc.verify_all(plan.claims, self.suc.scene_graph,
                                   self.ragc.retriever.last_retrieved):
            return False
        return True


# ============================================================
# 扩展：多机流水线挂接 RSUC（第 12 步起）
# ============================================================
class RetrievalScenePipeline:
    def __init__(self, config: dict):
        self.rsuc = RetrievalSceneUnifiedCertificate(
            src_usc=config['src_usc'],
            ragc=RetrievalAugmentedGroundingCertificate(
                corpus=config['corpus'], retriever=config['retriever'],
                trusted_keys=config['trusted_keys'],
                alpha_r=config['alpha_r'], tau_nli=config['tau_nli'],
                delta_h=config['delta_h'], T_stale=config['T_stale'],
                K=config['K']),
            suc=SceneUnderstandingCertificate(
                scene_graph=config['scene_graph'],
                alpha_s=config['alpha_s'], eps_geo=config['eps_geo'],
                delta_rel=config['delta_rel']),
            rsc=RetrievalSceneConsistencyCertificate(
                delta_con=config['delta_con'], tau_ground=config['tau_ground']))
        self.ipam.register_module("ragc", ["IP-448"],
            ["retrieval_coverage", "provenance", "grounding", "faithfulness", "freshness"])
        self.ipam.register_module("suc", ["IP-449"],
            ["object_recall", "geo_consistency", "spatial_relations",
             "affordance_grounding", "occlusion_free_space"])
        self.ipam.register_module("rsc", ["IP-450"],
            ["cross_modal_entailment", "referential_grounding", "spatial_text_consistency"])
        self.ipam.register_module("rsuc", ["IP-451"],
            ["eleven_certificate_gate", "retrieval_scene_monotonic_chain"])

    def step(self, multi_sensor_data: dict, cloud_update=None) -> tuple[bool, dict]:
        # 1-11. 继承 SRC-USC v25（七证准入）
        admitted25, info25 = self.rsuc.src_usc.admits_with_info(
            multi_sensor_data, cloud_update)
        if not admitted25:
            return False, {'layer': 'SRC-USC_v25', 'details': info25}

        # 12. 查询构造与检索（可审计）
        query = self._build_query(multi_sensor_data)
        docs = self.rsuc.ragc.retriever.topk(query, self.rsuc.ragc.K)

        # 13. 场景图增量更新（对象/关系/可供性/自由空间）
        self.rsuc.suc.scene_graph = self._update_scene_graph(multi_sensor_data)

        # 14. 生成决策断言并接地（每断言附文本证据+场景锚点）
        plan = self._plan_from_evidence(query, docs, self.rsuc.suc.scene_graph)

        # 15. RSUC 十一证准入
        admitted = self.rsuc.admits(plan, multi_sensor_data)
        return admitted, {
            'plan': plan if admitted else None,
            'retrieval': {
                'provenance_ok': self.rsuc.ragc.verify_provenance(docs),
                'coverage_ok': self.rsuc.ragc.verify_retrieval_coverage(
                    query, multi_sensor_data['task_predicate'],
                    multi_sensor_data['retrieval_calibrator']),
                'grounding_ok': self.rsuc.ragc.verify_grounding(
                    plan.claims, self.rsuc.suc.scene_graph),
                'faithfulness_ok': self.rsuc.ragc.verify_faithfulness(plan.claims),
                'freshness_ok': self.rsuc.ragc.verify_freshness(
                    docs, multi_sensor_data['now']),
            },
            'scene': {
                'recall_ok': self.rsuc.suc.verify_object_recall(
                    multi_sensor_data.get('gt_scene'),
                    multi_sensor_data.get('scene_calibrator')),
                'relations_ok': self.rsuc.suc.verify_spatial_relations(),
                'affordance_ok': self.rsuc.suc.verify_affordance_grounding(),
                'occlusion_ok': self.rsuc.suc.verify_occlusion_and_free_space(
                    multi_sensor_data['depth_sensor']),
            },
            'xmodal': {
                'entailment_ok': self.rsuc.rsc.verify_cross_modal_entailment(
                    plan.claims, self.rsuc.suc.scene_graph),
                'referential_ok': self.rsuc.rsc.verify_referential_grounding(
                    plan.claims, self.rsuc.suc.scene_graph),
                'spatial_text_ok': self.rsuc.rsc.verify_spatial_text_consistency(
                    docs, self.rsuc.suc.scene_graph),
            }
        }

    def _build_query(self, d: dict) -> str:
        return d['task_instruction'] + " | scene:" + d['scene_summary']

    def _update_scene_graph(self, d: dict) -> 'SceneGraph':
        g = self.rsuc.suc.scene_graph
        g.integrate(d['objects'], d['relations'], d['affordances'],
                    d['free_space'], d['occluded_regions'])
        return g

    def _plan_from_evidence(self, query, docs, scene_graph) -> 'MultiRobotPlan':
        claims = self.llm_generate(query, docs)
        for c in claims:
            c.support_docs = self._attribute(c, docs)       # 引用溯源
            c.scene_anchors = scene_graph.resolve_mentions(c.text)  # 场景锚定

## 3. 正确性论证（增量）

### 引理 13（检索增强接地证书的覆盖-溯源-忠实三重保证）
**陈述**：`RAGC.verify_all(...) = True` ⟺ 决策证据同时满足：
(1) 检索覆盖：ℙ(∃d∈R_K(q): d⊨φ)≥1-α_r，
(2) 溯源可信：每条证据签名可验证、发布者在信任根内、未过期，
(3) 接地忠实：每条断言有文本支撑与场景锚点，且无支撑断言率 ≤δ_h。

**证明**：
1. 覆盖性由 query 级 conformal 校准保证边际覆盖（Vovk et al. 2005），非一致性分数 s(q)=1-max_d score(d,φ) 的校准分位数给出有限样本保证。
2. `verify_provenance` 校验内容哈希与发布者签名，将「语料真实性」归约为密码学假设；`verify_freshness` 把时效性显式化，过期证据不得进入关键断言。
3. `verify_grounding` 要求 Supp(c_j) 在文本侧（引用溯源）与场景侧（实体锚定）同时非空；`verify_faithfulness` 用 NLI 下界约束断言被证据蕴含，杜绝「无中生有」。
4. 三条件分别对应「查得到、查得真、用得对」，任一缺失即证据链断裂。
∎

### 引理 14（场景理解证书的召回-几何-关系-可供性-完备五重保证）
**陈述**：`SUC.verify_all(...) = True` ⟺ 场景图同时满足：
(1) conformal 对象召回 ≥1-α_s，
(2) 多视角几何一致（重投影 ≤ε_geo），
(3) 空间关系与度量几何一致，
(4) 可供性由几何与物理谓词支撑，
(5) 遮挡区与自由空间不矛盾。

**证明**：
1. 有 GT 时直接统计召回；无 GT 时用多视角边际新增率估计未观测召回上界，conformal 校准给出 1-α_s 保证。
2. 重投影一致性约束对象位姿/几何与观测自洽，排除「幽灵对象」。
3. 关系谓词（on/inside/left-of/near/occludes）逐一与度量事实核对，避免语义标签与几何脱节。
4. 可供性 `Aff(o,a)` 必须同时通过几何可行性（夹持宽度/接触面积/净空）与物理可行性（质量/摩擦/稳定性），把「看起来能抓」升级为「证书保证能抓」。
5. 自由空间内不得有已观测占用，被遮挡区不得被断言为空——把「看不见」保守编码为 unknown，防止幻觉式补全。
∎

### 引理 15（检索-场景跨模态一致性）
**陈述**：`RSC.verify_all(...) = True` ⟹ 文本证据与场景图之间不存在超过 δ_con 的矛盾，所有指代均落到唯一真实实体，文本空间谓词与度量几何互证。

**证明**：
1. `verify_cross_modal_entailment` 将每条断言投影为场景事实并计算矛盾概率，矛盾率上界 δ_con 由离线校准确定。
2. `verify_referential_grounding` 要求指代解析唯一且实体存在，排除悬空指代（"那个东西"指不到）。
3. `verify_spatial_text_consistency` 对文本空间谓词与几何事实做双向核对，防止「文档说在桌上、几何说悬空」。
4. 三者共同保证：检索来的知识确实描述了当前场景，而非另一个相似场景。
∎

### 引理 16（十一证单调退化链）
**陈述**：任意单点/组合失效下，`Exec_v26 ⊆ Exec_v25 ⊆ … ⊆ Exec_v18` 恒成立。

**证明**：在引理 12 基础上增加三条退化路径：
- 检索投毒/覆盖失效/证据过期 → `RAGC.verify_all=false` → `RSUC` 拒证 → 退回 `Exec_v25`（禁用外部知识依赖，降级为纯场景驱动/参数记忆的保守策略）。
- 场景漂移/几何失配/可供性不成立/遮挡矛盾 → `SUC.verify_all=false` → `RSUC` 拒证 → 退回 `Exec_v25`（冻结语义任务级操作，降级为几何避障与已证安全动作）。
- 跨模态矛盾/指代悬空/空间谓词不符 → `RSC.verify_all=false` → `RSUC` 拒证 → 退回 `Exec_v25`（丢弃冲突证据，仅保留双模态一致子集）。
- 组合失效取交集，交集的子集关系保持单调。
∎

### 定理（RSUC 十一证准入门完备性）
**陈述**：对任意计划 Π，`RSUC.admits(Π)=True` ⟺ Π 同时满足 v25 的十项条件，且额外满足：
(11) 检索覆盖、溯源可信、接地忠实、证据新鲜，
(12) 场景召回、几何一致、关系正确、可供性可执行、遮挡完备，
(13) 跨模态不矛盾、指代接地、文本空间谓词与几何互证。

**证明**：由 `RSUC.admits` 的连言结构与引理 1–12（v25）及引理 13–15 直接可得。必要性：任一条件缺失即拒证，对应检索/场景/跨模态三类风险之一未被缓解。充分性：全条件满足时，由引理 16 保证执行集单调链与退化安全，构成从「证据可追溯」到「物理可落地」再到「跨模态自洽」的闭环。
∎

## 6. 本轮最大风险（最终确认）

**一句话**：**RAGC 的信任根与 NLI 忠实度共同假设「合法来源 + 语义蕴含即安全」，但对抗性提示注入可以在签名合法的语料中植入语义上「蕴含」却行为上危险的任务规范，同时 SUC 的场景锚点仅校验实体存在而不校验规范适配性——于是十一证可能在证据链、场景链、跨模态链全部「形式通过」的情况下放行一条被投毒的高层指令，使「证据可追溯」沦为「可追溯地做错事」。**
