# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「鲁棒性」×「泛化能力」）

> 第 54 轮完成了「动作空间剖面 α_S → 技能组合图 G_S → 云边联合证书 J」的闭环。本轮追问一个被默认掉的前提：**所有 ρ 与 J 的 soundness 都只在标定过的偏移族内成立**。核心矛盾：H22：鲁棒性是「固定任务、向内加压」的纵向深度，泛化是「固定压力、向外换任务」的横向宽度，二者不可加，把深度当宽度会在域外产生「自信的错误证书」；H23：云端有广而浅的泛化先验，边端有窄而深的鲁棒证书，二者之间存在显式的覆盖率缺口，必须由运行时新颖性门把它逼出来，而不是用离线平均指标掩盖。

## 0. 直觉与动机

**灵感 1（二维能力面 → 从标量 ρ 到面上的区域）**
直觉：一个技能的真实能力不是一个数，而是 `(ε, δ)` 平面上的一块区域。`ε` 是环境扰动强度（鲁棒轴），`δ` 是任务/环境相对标定分布的新颖度（泛化轴）。于是成功面 `S(ε,δ)`、最坏鲁棒面 `ρ(ε,δ)` 取代第 53–54 轮的单一谱。证书不再是平面上的一个点，而是**有效域内的一个带置信带的子区域**。这一步把「鲁棒 or 泛化」的二选一，变成「在哪个 (ε,δ) 上、以多大把握、保证什么」。

**灵感 2（证书有效性域 → 把「保证的适用范围」变成一等公民）**
直觉：任何证书 `C` 都有一个隐含的 `dom(C) ⊆ 𝔖`。过去它被吞进假设里，现在必须显式写出：`V = {(ε,δ) : 标定覆盖率 ≥ 1-α ∧ 经验支撑 ≥ κ}`。只有 `(ε,δ) ∈ V` 时证书才 sound；域外一律 **abstain / escalate**。这等价于给系统一个「我不知道」的合法输出，而不是被迫给出一个域外仍然看似精确的数字。

**灵感 3（新颖性门 → 把泛化检测从离线指标变成在线闸门）**
直觉：泛化能力的失效通常不是渐变，而是「突然掉出有效域」。因此在边端部署一个新颖性评分 `n(x) = d_Ψ(δ_x, P_calib)`：`n ≤ τ_n` 才允许本地出证，否则升级到云端（云端有更广的先验，但更慢）。用序贯检验控制「误发证书率」`P(certify | x∉V) ≤ γ`，把泛化风险变成可预算的运行时约束。

**灵感 4（鲁棒-泛化权衡前沿 → 不强行标量化）**
直觉：过度正则化会提高 `ε` 方向的鲁棒深度，却可能压缩 `δ` 方向的可用宽度（过拟合到扰动族）。二者构成 Pareto 前沿 `𝔉 = {(ρ*, G*)}`。正确做法不是发明一个权重把两轴压成一个数，而是先给出前沿，再按任务的风险预算在前沿上选工作点，并明确「本工作点放弃哪一段泛化」。

**灵感 5（可迁移鲁棒性 + 云边分工 → 让鲁棒性能跨任务族传递）**
直觉：单任务鲁棒不等于任务族鲁棒。定义可迁移鲁棒性 `TRB(Π) = inf_{τ∼P_family} ε*(δ_τ)`，即在整个任务族上的最坏鲁棒边界。云边分工由此清晰：云端负责「广而浅」的泛化先验与 `TRB` 估计，边端负责「窄而深」的本地鲁棒证书与 `V` 的在线守门；反向解释信道从第 54 轮的「重剖分」升级为「域外告警 + 有效性域重标定」。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（偏移空间与二维能力面）**
偏移空间 `𝔖 = Φ × Ψ`：`Φ` 为环境扰动，以度量 `d_Φ` 给出半径 `ε`；`Ψ` 为任务分布族，新颖度 `δ = d_Ψ(P_task, P_calib)`（Wasserstein 或 MMD）。
- 成功面：`S(ε,δ) = Pr_{φ∼B_ε(φ0), τ∼N_δ}[success]`；
- 最坏鲁棒面：`ρ(ε,δ) = inf_{φ∈B_ε(φ0)} Pr_{τ∼N_δ}[success | φ]`。
技能的能力是平面上的区域 `R_S = {(ε,δ) : S(ε,δ) ≥ g_min}`，而非标量。

**定义 122（鲁棒边界与泛化边界）**
```
ε*(δ) = sup{ ε : ρ(ε,δ) ≥ ρ_min }         # 给定新颖度下的鲁棒深度
δ*(ε) = sup{ δ : S(ε,δ) ≥ g_min }          # 给定扰动下的泛化宽度
```
`ε*(·)` 与 `δ*(·)` 一般非单调：存在「鲁棒越深、泛化越窄」的权衡段，该段即灵感 4 的 Pareto 前沿。

**定义 123（证书有效性域 CVD）**
证书 `C` 的有效性域
```
V_C = { (ε,δ) ∈ 𝔖 : cov_α(ε,δ) ≥ 1-α ∧ support_n(ε,δ) ≥ κ }
```
其中 `cov_α` 为标定覆盖率下界，`support_n` 为经验支撑密度。证书语义升级为 **域内断言、域外弃权**：
```
dom(C) = V_C,   sound(C) 仅对 (ε,δ) ∈ V_C 成立
```
域外输出 `abstain` 或 `escalate`，不得输出精确的 ρ 数值。

**定义 124（鲁棒-泛化缺口与可迁移鲁棒性）**
- 泛化诱发的鲁棒侵蚀：`gap_RG(δ) = ρ(0,0) - ρ(0,δ)`；
- 可迁移鲁棒性：`TRB(Π) = inf_{τ∼P_family} ε*(δ_τ)`，`Π` 为策略族。
若 `TRB(Π) ≥ ε_0`，称该鲁棒性对任务族 `P_family` **可迁移**。

**定义 125（新颖性门 NGATE）**
边端新颖性评分 `n(x) = d_Ψ(δ_x, P_calib)`。闸门
```
gate(x) = certify   若 n(x) ≤ τ_n
        = escalate  若 n(x) > τ_n
```
序贯检验须满足误发预算：`P(gate=certify | x ∉ V_C) ≤ γ`。

**定义 126（泛化-鲁棒联合证书 GRJ）**
```
GRJ = (ρ, G, V_C, n, γ_ce, evidence)
```
部署条件：
```
(ε,δ) ∈ V_C ∧ n(x) ≤ τ_n ∧ ρ ≥ ρ_min ∧ G ≥ g_min
```
任一不满足则 escalate 至云端；云端回复新的 `P_c` 与重标定的 `V_C`。GRJ 是第 54 轮 `J = (ρ, A_cert, γ_ce, δ_a)` 在泛化维度上的严格扩展：`J` 只回答「动作对不对齐」，GRJ 还要回答「这个保证在不在有效域内」。

## 2. 关键算法 伪代码

### IP-121 GRP（Generalization-Robustness Profiling）

```python
def profile_capability(skill, grid_eps, grid_delta, sampler, n_strata):
    surface, robust = {}, {}
    for eps in grid_eps:
        for delta in grid_delta:
            trials = stratified_sample(grid_eps, grid_delta, n_strata)
            S = mean([sampler.success(skill, e, d) for (e, d) in trials])
            R = min([sampler.worst_case(skill, e, d) for (e, d) in trials])
            surface[(eps, delta)] = S
            robust[(eps, delta)] = R
    return surface, robust

def boundaries(surface, robust, rho_min, g_min):
    eps_star = {d: max([e for (e, dd) in robust if dd == d and robust[(e, dd)] >= rho_min],
                       default=0) for d in {dd for (_, dd) in robust}}
    delta_star = {e: max([d for (ee, d) in surface if ee == e and surface[(ee, d)] >= g_min],
                         default=0) for e in {ee for (ee, _) in surface}}
    return eps_star, delta_star
```

### IP-122 CVD（Certificate Validity Domain）

```python
def build_validity_domain(calib_scores, shift_grid, alpha=0.1, kappa=0.05):
    # split-conformal 覆盖率下界 + 经验支撑约束
    q = conformal_quantile(calib_scores, 1 - alpha)
    V = set()
    for (eps, delta) in shift_grid:
        cov = lower_coverage(calib_scores, eps, delta, q)
        sup = support_density(calib_scores, eps, delta)
        if cov >= 1 - alpha and sup >= kappa:
            V.add((eps, delta))
    return V, q

def certify(C, eps, delta, V):
    if (eps, delta) not in V:
        return ('abstain', 'outside_validity_domain')
    return ('ok', C.rho_at(eps, delta))
```

### IP-123 NGATE（Novelty Gate）

```python
def novelty_gate(x, P_calib, tau_n, gamma, state):
    n = distance(x, P_calib)                 # MMD / 马氏距离
    e = e_value(state, n, tau_n)             # 序贯 e-value
    if n <= tau_n:
        state.update('in', e)
        return ('certify', n)
    state.update('out', e)
    if e >= 1 / gamma:                       # 误发预算触发
        return ('escalate', n)
    return ('escalate', n)
```

### IP-124 GRT（Generalization-Robustness Tradeoff）

```python
def pareto_frontier(policy_family, eps_probe, delta_probe, rho_min, g_min):
    F = []
    for pi in policy_family:
        rho_pi = robust_at(pi, eps_probe, delta_probe)
        G_pi = gen_at(pi, delta_probe)
        F.append((rho_pi, G_pi, pi))
    F = non_dominated(F)                     # 不标量化，保留双目标
    knee = max(F, key=lambda t: t[0] * t[1]) # 仅作默认工作点候选
    return F, knee
```

### IP-125 TRB（Transferable Robustness Bound）

```python
def transferable_robustness(policies, task_family, rho_min, alpha=0.05):
    bounds = []
    for tau in task_family.sample():
        eps_tau = eps_star_estimate(policies, tau, rho_min)
        rad = uniform_convergence_radius(n=len(tau.calib), delta=tau.novelty, alpha=alpha)
        bounds.append(max(0.0, eps_tau - rad))
    return min(bounds)                       # 任务族最坏鲁棒下界
```

### IP-126 GRJ（Generalization-Robustness Joint Certificate）

```python
def grj_certificate(skill, eps, delta, x, V_C, P_calib, rho_min, g_min, gamma_ce):
    if (eps, delta) not in V_C:
        return ('escalate', 'outside_V', reprofile_request(eps, delta))
    gate, n = novelty_gate(x, P_calib, tau_n=tau_n_of(skill), gamma=0.03, state=state)
    if gate != 'certify':
        return ('escalate', 'novelty', n)
    rho = skill.rho_at(eps, delta)
    G = skill.gen_at(eps, delta)
    if rho < rho_min or G < g_min:
        return ('reject', 'capability_fail', rho, G)
    return ('ok', GRJ(rho=rho, G=G, V_C=V_C, n=n, gamma_ce=gamma_ce,
                      evidence=collect_evidence(skill, eps, delta)))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| GRP | O(|Φ|·|Ψ|·n_strata·T_sim) | O(|Φ|·|Ψ|) | 分层采样覆盖、边界置信带 |
| CVD | O(|𝔖|·N_calib) | O(N_calib) | 可交换性、覆盖率下界 sound |
| NGATE | O(d·|P_calib|) 或 O(1) 近似 | O(d) | 误发率 ≤ γ、序贯有效性 |
| GRT | O(|Π|·T_eval + |Π|²) | O(|Π|) | 非支配筛选正确、前沿不塌缩 |
| TRB | O(|P_family|·|Π|·T_eval) | O(|P_family|) | 任务族 Lipschitz / 一致收敛 |
| GRJ | O(|𝔖| + d·N_calib) | O(|𝔖|+N_calib) | 域内出证、域外弃权语义闭合 |

**正确性定理（Generalization-Aware Certificate Soundness）**
在第 54 轮 (A22)–(A28) 基础上追加：**(A29)** 有效域 `V_C` 内的标定样本可交换，split-conformal 覆盖成立；**(A30)** 新颖性门满足误发预算 `P(certify | x∉V_C) ≤ γ`；**(A31)** 任务族上存在一致收敛半径 `rad(n,δ,α)`（或 Lipschitz 传递界）；**(A32)** 云端升级往返延迟 ≤ τ_g。
则：
```
若 (ε,δ) ∈ V_C:   P(success) ≥ 1 - Σ_d(1-ρ_min(d)) - α - γ
若 (ε,δ) ∉ V_C:   无鲁棒性保证；仅当 (A31) 成立时 G ≤ Ĝ_n + rad(n,δ,α)
```
**关键**：证书必须**条件于域成员关系**。把域外样本按域内公式报数，是 soundness 失效的唯一主因。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 有效域 `V_C` 离线估偏 | 高 | 在线覆盖率监控 + 滚动重标定 + 弃权契约 |
| 新颖性探测器存在 OOD 盲区 | 高 | 红队对抗探测 + 多探测器投票 + 保守 τ_n |
| 鲁棒-泛化前沿不单调、难辨识 | 中 | 双侧探针 + 前沿置信带 + 不强行标量化 |
| 升级风暴 / 云端延迟 | 中 | hysteresis + 本地缓存 + 分级升级预算 |
| 把域内鲁棒误报为泛化 | 高 | 双轴分栏报告 + 域成员硬门 + 审计日志 |

## 6. 本轮最大风险

**一句话**：把「证书有效性域」当成可以离线一次估准的静态盒子，而它其实随部署流形持续漂移、新颖性探测器还存在盲区；一旦把域外的鲁棒性深度读成泛化宽度，系统就会在最需要保证的地方给出最自信的错误证书，故必须以 **在线覆盖率监控 + 域外强制弃权 + 云边分级升级** 作为不可关闭的硬约束，宁可频繁说「我不知道」，也不让有效性域变成一块遮羞布。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim+++G（GRP×CVD×NGATE×GRT×TRB×GRJ）

> 承接第 54 轮产物 v31。本轮在「动作-鲁棒双证书」之上，增加 **泛化维度** 与 **证书有效性域**，把鲁棒性从「指定偏移族内的深度」与泛化能力从「跨分布族的宽度」显式分离：
> - **GRP（Generalization-Robustness Profiling）**：`(ε,δ)` 二维能力面与边界；
> - **CVD（Certificate Validity Domain）**：证书有效域 `V_C`，域内断言、域外弃权；
> - **NGATE（Novelty Gate）**：运行时新颖性闸门，控制误发证书率；
> - **GRT（Generalization-Robustness Tradeoff）**：不标量化的 Pareto 前沿搜索；
> - **TRB（Transferable Robustness Bound）**：跨任务族的可迁移鲁棒下界；
> - **GRJ（Generalization-Robustness Joint Certificate）**：`(ρ,G,V_C,n,γ_ce,evidence)` 联合出证与分级升级。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-118/120 以纳入有效性域与泛化门。


```python
def transferable_robustness(policies, task_family, rho_min, alpha=0.05):
    bounds = []
    for tau in task_family.sample():
        eps_tau = eps_star_estimate(policies, tau, rho_min)
        rad = uniform_convergence_radius(n=len(tau.calib), delta=tau.novelty, alpha=alpha)
        bounds.append(max(0.0, eps_tau - rad))
    return min(bounds)
```

### IP-126 GRJ

```python
def grj_certificate(skill, eps, delta, x, V_C, P_calib, rho_min, g_min, gamma_ce):
    if (eps, delta) not in V_C:
        return ('escalate', 'outside_V', reprofile_request(eps, delta))
    gate, n = novelty_gate(x, P_calib, tau_n=tau_n_of(skill), gamma=0.03, state=state)
    if gate != 'certify':
        return ('escalate', 'novelty', n)
    rho, G = skill.rho_at(eps, delta), skill.gen_at(eps, delta)
    if rho < rho_min or G < g_min:
        return ('reject', 'capability_fail', rho, G)
    return ('ok', GRJ(rho, G, V_C, n, gamma_ce, collect_evidence(skill, eps, delta)))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| GRP | O(|Φ|·|Ψ|·n_strata·T_sim) | O(|Φ|·|Ψ|) | 分层采样覆盖、边界置信带 |
| CVD | O(|𝔖|·N_calib) | O(N_calib) | 可交换性、覆盖率下界 sound |
| NGATE | O(d·|P_calib|) | O(d) | 误发率 ≤ γ |
| GRT | O(|Π|·T_eval + |Π|²) | O(|Π|) | 非支配筛选正确、前沿不塌缩 |
| TRB | O(|P_family|·|Π|·T_eval) | O(|P_family|) | 任务族 Lipschitz / 一致收敛 |
| GRJ | O(|𝔖|+d·N_calib) | O(|𝔖|+N_calib) | 域内出证、域外弃权闭合 |

**正确性定理（Generalization-Aware Certificate Soundness）**
假设第 54 轮 (A22)–(A28) 成立；追加 **(A29)** `V_C` 内标定样本可交换、split-conformal 覆盖成立；**(A30)** 新颖性门误发预算 `P(certify|x∉V_C) ≤ γ`；**(A31)** 任务族存在一致收敛半径 `rad(n,δ,α)`；**(A32)** 云端升级往返 ≤ τ_g。则
```
(ε,δ) ∈ V_C:  P(success) ≥ 1 - Σ_d(1-ρ_min(d)) - α - γ
(ε,δ) ∉ V_C:  无鲁棒保证；仅 (A31) 下 G ≤ Ĝ_n + rad(n,δ,α)
```
关键：**证书语义必须条件于域成员关系；域外按域内公式报数即 soundness 失效**。

## 5. 本轮最大风险

**一句话**：把「证书有效性域」当成可以离线一次估准的静态盒子，而它随部署流形持续漂移、新颖性探测器还存在盲区；一旦把域外的鲁棒性深度读成泛化宽度，系统就会在最需要保证的地方给出最自信的错误证书，故必须以 **在线覆盖率监控 + 域外强制弃权 + 云边分级升级** 作为不可关闭的硬约束，宁可频繁说「我不知道」，也不让有效性域变成一块遮羞布。
