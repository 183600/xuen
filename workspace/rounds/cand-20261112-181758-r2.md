# 第 61 轮（承接第 60 轮 SGEC「场景感知闭环」IP-153~160；本轮灵感：「力觉传感」×「差异化定位」）

> 第 60 轮的 SGEC 把「场景→意图→约束→阻抗→执行→EV-exec→场景更新」闭了起来，但它的力觉接口仍是被高度压缩的**标量力**，由此暴露三个结构性盲点：
> 1. **力觉语义坍缩**：EV-exec 与 SSM 只消费少数法向/切向力标量，丢失接触斑的**空间分布与时变微动**。湿滑地面与粗糙桌面可以给出几乎相同的法向力均值，却在接触形貌、剪切分布、微振动频谱上截然不同——第 60 轮的最大风险（湿滑误判为粗糙）本质是**标量力不足以区分接触力学**。
> 2. **定位基准缺失**：阻抗 K_safe 是末端绝对坐标下的参数，而接触任务真正关心的是**相对物体/接触面的位姿**。场景先验能告诉我们「这是湿滑地面」，却不能告诉我们「触点落在物体边缘还是中心」，导致边缘接触、翻滚、局部滑移无法被前置约束。
> 3. **证据不可差分审计**：EPIR 持久化的是标量力与其哈希，无法回答「这条滑移证据来自哪片触觉区域、在什么标定版本下测得」。一旦触觉阵列增益漂移或饱和，证据链仍然"完整"，但语义已经失真。

## 0. 直觉与动机

**灵感 1（力觉传感 → 触觉场表示 TFR 与差分触觉签名 DTS）**

直觉：标量力像「一只耳朵听交响乐」，只能听到总音量；触觉阵列则是「一整支麦克风阵列」，能听到接触的音色。把接触写成时空场 `T_t(x)`（x 为 taxel 坐标，t 为时间），则：
- 接触斑质心 `c_t` 告诉我们「压在哪里」；
- 压强二阶矩告诉我们「软还是硬、平还是斜」；
- 切向位移率场 `s_t(x)` 告诉我们「哪里先滑」；
- 高频振动能量 `E_HF` 告诉我们「粗糙、湿滑还是即将滑移」。

关键洞见不在于「多装一个传感器」，而在于**用差分而非绝对值做判据**：绝对力阈值随物体重量、场景、装配增益漂移，永远需要重新标定；而 `∂T/∂t`、`∇_x T`、`∇²_x T` 对共模的增益与偏置天然不敏感——这与差分放大器抑制共模噪声是同一个原理。于是，**「差分」把接触状态从「绝对力道德」转成「相对形态学」**，使阈值可以跨场景迁移。

第二洞见：**滑移是可提前预判的**。宏观滑移前，接触边缘先出现微滑（incipient slip），在触觉场上表现为高频抖动能量上升、切向/法向比 `r_τ=||f_t||/f_n` 逼近摩擦上限。把 `(E_HF, r_τ, 局部滑移场)` 组成接触状态机，可在宏观滑移前一个控制周期内触发约束——这正是第 60 轮 CIEC「认知先行」在物理层的对应物：**物理先行**。

**灵感 2（差异化定位 → 双重语义：差分定位 + 研究差异化）**

直觉：这个词有两层，且两层都真实可用。
- **差分定位（differential positioning）**：触觉场不是「全局定位」，而是**相对接触面的定位**。由接触质心、压力矩与剪切方向，可以估计末端相对物体/接触帧的局部位姿 `ξ_t ∈ SE(3)`；不可观测方向（如点接触绕法向旋转）必须显式标记为「定位退化」，而不是假装知道。这为阻抗参数提供**接触帧基准**，把「绝对坐标下的 K_safe」升级为「接触帧下的 K_safe」。
- **研究差异化（differentiated positioning）**：把「差异化」从口号变成可测量量。定义相对标量力的**差异化增益** `G_diff = I(S; z) − I(f_n; z)`：只有当差分触觉签名对场景的互信息严格高于标量力时，新增触觉通道才配得上它的成本。若 `G_diff ≤ 0`，本轮方案在该场景上就是「昂贵的冗余」，应被预算机制自动裁掉。

第三层（工程定位）也顺手成立：本方案不替换阻抗控制，而是给阻抗参数**提供可审计的触觉接地**；不与视觉伺服竞争全局位姿，而补足遮挡下的接触相对微定位。

**灵感 3（两灵感合流 → 差分触觉认知闭环 DTCL）**

直觉：把第 60 轮的 SSM 从「力标量→场景」升级为「触觉场→差分签名→场景」，把 CRP 补成「触觉场→接触帧」，再用接触状态机 σ_t 在 CIEC 之前加一道**物理约束闸门**：
`场景先验 → 触觉差异化鉴别（确认/否定场景） → 接触状态（滑移/冲击/边缘） → 接触帧定位（是否退化） → 阻抗约束 → 执行 → 触觉证据胶囊 → 场景/标准更新`。
其核心不是再加一层模块，而是把第 60 轮「场景置信度」拆成**可证伪的两个量**：场景是否分得开（TSDD 的 D_diff）与触点是否定得准（CRP 的可观测秩 ρ_t）。两者任一不成立，就退回保守阻抗，而不是让「高置信度错误」继续传播。

**灵感 4（PCE+++++ → 触觉预算与降级阶梯）**

直觉：触觉阵列的带宽、taxel 数、标定漂移都是有限资源。把 `B_tac=(采样率, taxel 数, 端到端时延, 标定置信度)` 纳入预算：全量 DTS+CRP → 降采样 DTS（放弃 CRP）→ 标量力+滑移标志 → 第 60 轮保守回退。关键是**降级顺序按可观测性排序**：先牺牲空间分辨率，最后才牺牲滑移检测，因为滑移是安全临界量。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（触觉场表示 TFR）** 触觉观测为时空张量场
`T_t : X × [0,T] → R^3,  T_t(x) = (p_n(x), p_s(x), p_τ(x))`
其中 `X ⊂ R^2` 为 taxel 坐标网格，`p_n` 为法向压强，`(p_s,p_τ)` 为两个切向分量。由场导出：
- **接触斑**：`Ω_t = {x ∈ X | ||T_t(x)|| > τ_noise}`，面积 `A_t = |Ω_t|`；
- **接触质心**：`c_t = (∫_{Ω_t} x·w_t(x) dx)/(∫_{Ω_t} w_t(x) dx)`，`w_t(x)=||T_t(x)||`；
- **压力矩**：`M_t^{(k)} = ∫_{Ω_t} (x − c_t)^{⊗k} w_t(x) dx, k=1,2`；
- **合力**：`f_n(t)=∫ p_n`，`f_t(t)=∫(p_s,p_τ)`；
- **滑移场**：`s_t(x)=∂_t u_t(x)`，`u_t` 为 taxel 切向位移估计；
- **饱和率**：`sat_t = |{x | |T_t(x)| ≥ T_max}| / |X|`。

**定义 162（差分触觉签名 DTS）** 先在无接触期估计逐 taxel 基线 `b̂_t(x)`（EWMA 高通的慢分量），令 `T̃_t = T_t − b̂_t`。定义
`S_t = D[T̃_t] = (N_t, G_t, H_t, E_t)`，
其中
- `N_t(x) = ∂_t T̃_t(x) / (||T̃_t||_1 + ε)`（归一化时间差分）；
- `G_t(x) = ∇_x T̃_t(x) / (||T̃_t||_1 + ε)`（归一化空间梯度）；
- `H_t(x) = ∇²_x T̃_t(x) / (||T̃_t||_1 + ε)`（归一化空间曲率）；
- `E_t = Σ_{f∈[f_lo,f_hi]} |F{T̃_t}(f)|²`（高频带能量，捕捉微滑/粗糙度）。

**命题 161.1（共模不变性）** 若 `T' = aT + b`，`a>0` 且 `b(x)` 在每个时间窗内为常数（或经 `b̂_t` 高通移除），则 `D[T'] = D[T]`（忽略 ε 与饱和截断）。即 DTS 对传感器整体增益与偏置不敏感；但**逐 taxel 增益不一致**与**饱和**会破坏该不变性，必须由标定矩阵与 `sat_t` 显式建模。
**命题 161.2（滑移前置性）** 在 stick-slip 微振假设下，`E_t` 与 `r_τ` 的联合越界早于宏观切向位移超过 `d_slip`，故存在 `t_P < t_G` 使预滑状态可提前一个控制周期被检测。

**定义 163（接触状态机 CSM）** 状态 `σ_t ∈ {Free, Stick, PreSlip, GrossSlip, Impact, Edge}`，迁移由差分签名与滞回计时决定：
```
Free      → Stick     : A_t ≥ A_min ∧ f_n ≥ f_n_min
Stick     → PreSlip   : (E_HF ≥ θ_HF) ∨ (r_τ ≥ μ_s − δ_μ)
Stick     → Impact    : max_x |N_t(x)| ≥ θ_imp
Stick     → Edge      : ||ċ_t|| ≥ v_edge
PreSlip   → GrossSlip : ∫_{t_P}^{t} ||s_t|| dt ≥ d_slip ∨ r_τ ≥ μ_k
PreSlip   → Stick     : E_HF < θ_HF − h_E ∧ r_τ < μ_s − δ_μ − h_μ（滞回）
GrossSlip → Stick     : ||s_t|| < v_stick 持续 τ_dwell
Impact    → Stick     : ||N_t|| < θ_imp − h_I 持续 τ_dwell
```
其中 `μ_s, μ_k` 为静/动摩擦系数估计，`h_*` 为滞回带宽，`τ_dwell` 为防抖驻留时间。CSM 的输出不是「力」，而是**物理事件**，供 CIEC 与证据层消费。

**定义 164（接触相对定位 CRP）** 给定物体局部模型 `M_o`（SDF + 摩擦锥），以触觉场拟合末端相对接触帧位姿 `ξ_t=(R_t,p_t) ∈ SE(3)`：
```
ξ_t* = argmin_ξ  Σ_{x∈Ω_t} ||T_t(x) − Φ(x; ξ, M_o, f_int)||²_Σ
                 + λ_dyn ||ξ − ξ_{t−1}||²
                 s.t.  ξ ∈ Ξ_contact(M_o)
```
`Φ` 为接触力学正演（例如半空间弹性接触 + 库仑摩擦），`f_int` 为内部力。可观测性由雅可比 `J_t = ∂Φ/∂ξ` 决定：可观测子空间为 `range(J_t^T)`，可观测秩 `ρ_t = rank(J_t)`，定位置信度 `γ_pos = σ_min(J_t)`（最小奇异值）。点接触一般至多 3 个可观测方向（切平面两向 + 法向距离）；面接触视模型可达 5 个；**绕接触法向的旋转通常不可观测**，必须由视觉/本体先验破缺，或显式标记 `ξ_t` 的退化子空间 `ker(J_t)`。无物体模型时退化为触觉里程计，仅相对位移可观测。
**定位退化判据**：`CRP_valid = (ρ_t ≥ ρ_min) ∧ (γ_pos ≥ γ_min) ∧ (sat_t ≤ θ_sat)`。

**定义 165（触觉场景差异化鉴别 TSDD）** 对场景 `z, z'`，定义差分可分辨度
`D_diff(z,z') = KL(P(S|z) || P(S|z'))`，
以及相对标量力的**差异化增益**
`G_diff = I(S; z) − I(f_n; z)`。
场景集 `Z` 称 **DTS-可鉴别**，若 `min_{z≠z'} D_diff(z,z') ≥ D_min`。此时由 Fano 不等式，场景分类错误率下界由 `I(S;Z)` 控制；若 `G_diff ≤ 0`，说明在该场景对上差分触觉不提供超越标量力的信息，应被预算裁剪。典型例子：湿滑地面与粗糙桌面的 `P(f_n|z)` 高度重叠，但前者 `E_HF` 低而滑移场连续、后者 `E_HF` 高而滑移场近零，故 `D_diff` 大、`G_diff>0`——这正面对第 60 轮的最大风险。

**定义 166（触觉证据胶囊 TEC）** 扩展 EV-exec 为
`EV_tac = (t, seq_id, H(EV_exec), c_t, A_t, f_n, f_t, S_t, σ_t, ρ_t, γ_pos, sat_t, calib_ver, frame_digest)`
其中 `H(·)` 为内容哈希，`calib_ver` 为标定版本，`frame_digest` 为接触帧/标定矩阵摘要。EPIR 校验规则扩展为：`calib_ver` 不匹配或 `sat_t > θ_sat` 时，胶囊标记为 **differential-invalid**，只能作为标量证据使用，不得参与 DTS/CRP 结论。如此，证据不仅「有没有丢」，还可被审计「差分结论是否仍然成立」。

**定义 167（触觉预算 PCE+++++）** `B_tac = (f_s, n_taxel, L_tac, γ_calib)` 分别为采样率、启用 taxel 数、端到端时延、标定置信度。扩展 VOI：
```
voi_tac(π) = VOI_meta_pessimistic(π) − cost_cog(π) − cost_exec(π) − cost_tac(π)
cost_tac = λ_f·f_s/f_max + λ_n·n_taxel/n_max + λ_L·max(0,L_tac−L_max) + λ_c·(1−γ_calib)
```
降级阶梯（按可观测性排序，先牺牲空间分辨率、最后牺牲滑移）：
```
L0: 全量 DTS + CRP
L1: 降采样 DTS（n_taxel↓，关闭 H_t）+ 低秩 CRP
L2: 标量力 + E_HF 滑移标志（仅 CSM 的安全子集）
L3: 第 60 轮保守阻抗回退（无触觉结论）
```
触发条件：`f_s` 或带宽不足→L1；`γ_pos < γ_min` 或 `ρ_t < ρ_min`→关闭 CRP、保留 DTS；`sat_t > θ_sat` 或 `γ_calib < γ_calib,min`→L2；`B_tac` 耗尽→L3。

**定义 168（差分触觉认知闭环 DTCL）** 算子 `DTCL(M, scene, intent, δ_f_req)`：
```
① TFR:        T_t ← read_tactile_array(); c_t,A_t,f_n,f_t,Ω_t
② DTS:        S_t ← differential_signature(T_t, b̂_t)
③ TSDD:       z_t, D_diff, G_diff ← tactile_scene_differentiate(S_t, Z)
④ CSM:        σ_t ← contact_state_machine(S_t, f_n, f_t)
⑤ CRP:        ξ_t, ρ_t, γ_pos ← contact_relative_position(T_t, M_o)
⑥ SIC+:       SIC_valid ← SIC(第60轮) ∧ (D_diff ≥ D_min) ∧ (G_diff>0) ∧ CRP_valid
⑦ CIEC+:      C_intent ← ϕ_intent(intent); φ_tac(σ_t); ERTC.lock(C_intent ∪ C_tac)
⑧ EEIS+:      K_safe ← compile_with_scene_prior(π_scene(K|z_t), δ_f_req, C_tac)
⑨ Execute:    telemetry, T_t+1 ← wait_contact()
⑩ TEC+EPIR:   EV_tac ← build_tactile_capsule(...); S_shadow.append(EV_tac); S_sync.push()
⑪ Update:     b̂_t ← update_baseline(T_t); π_scene, scene_conf ← update(TSDD, EV_tac)
⑫ Return:     (z_t, σ_t, ξ_t, K_safe, EV_tac, SIC_valid, budget.level)
```
触觉约束闸门 `φ_tac` 定义为对阻抗的**有向修正**（不是替代）：
```
φ_tac(Stick)      : ΔK = 0
φ_tac(PreSlip)    : K_p↓, K_d↑, v_max↓, F_max↓; 沿 −f_t 方向施加预紧
φ_tac(GrossSlip)  : 退出/回撤，F_max↓，禁止加力
φ_tac(Impact)     : K_p↓↓, 阻尼↑，进入柔顺吸收
φ_tac(Edge)       : 降法向力，调整姿态以增大接触面积
```
当 `SIC_valid=false` 时，`φ_tac` 只允许「收紧」不允许「放松」：安全方向单调，防止错误场景先验放宽约束。

## 2. 关键算法伪代码

### IP-161 TFR / DTS（触觉场与差分签名）

```python
class TactileDifferentialSignature:
    def __init__(self, taxel_shape, eps=1e-6, f_band=(40.0, 200.0), dt=0.01):
        self.shape = taxel_shape
        self.eps = eps
        self.f_band = f_band
        self.dt = dt
        self.baseline = np.zeros(taxel_shape + (3,))
        self.beta = 0.001
        self.prev = None
        self.prev_u = None

    def update(self, T):                      # T: [H,W,3], 无接触时更新基线
        if np.linalg.norm(T) < self.noise_floor:
            self.baseline = (1 - self.beta) * self.baseline + self.beta * T
        Tt = T - self.baseline
        N = (Tt - self.prev) / (self.dt * (np.abs(Tt).sum() + self.eps)) if self.prev is not None else np.zeros_like(Tt)
        G = np.gradient(Tt, axis=(0, 1)) / (np.abs(Tt).sum() + self.eps)
        H = np.gradient(np.gradient(Tt, axis=0), axis=0) / (np.abs(Tt).sum() + self.eps)
        E = self._band_energy(Tt, self.f_band)
        self.prev = Tt
        return {'N': N, 'G': G, 'H': H, 'E_hf': E,
                'contact_mask': np.linalg.norm(T, axis=-1) > self.noise_floor,
                'sat_ratio': float((np.linalg.norm(T, axis=-1) >= self.T_max).mean())}
```

### IP-162 CSM（接触状态机）

```python
class ContactStateMachine:
    STATES = ['Free', 'Stick', 'PreSlip', 'GrossSlip', 'Impact', 'Edge']

    def __init__(self, mu_s=0.6, mu_k=0.45, theta_hf=0.3, d_slip=2e-3):
        self.sigma = 'Free'
        self.mu_s, self.mu_k = mu_s, mu_k
        self.theta_hf, self.d_slip = theta_hf, d_slip
        self.slip_acc = 0.0
        self.dwell = 0.0

    def step(self, feat, f_n, f_t, c_dot, dt):
        E, r_tau = feat['E_hf'], np.linalg.norm(f_t) / (f_n + 1e-9)
        slip_step = np.linalg.norm(feat['slip_field']) * dt
        s = self.sigma
        if s == 'Free' and feat['area'] >= A_min and f_n >= F_MIN:
            s = 'Stick'
        elif s == 'Stick':
            if np.max(np.abs(feat['N'])) >= THETA_IMP: s = 'Impact'
            elif np.linalg.norm(c_dot) >= V_EDGE:      s = 'Edge'
            elif E >= self.theta_hf or r_tau >= self.mu_s - DELTA:
                s = 'PreSlip'; self.slip_acc = 0.0
        elif s == 'PreSlip':
            self.slip_acc += slip_step
            if self.slip_acc >= self.d_slip or r_tau >= self.mu_k:
                s = 'GrossSlip'
            elif E < self.theta_hf - H_E and r_tau < self.mu_s - DELTA - H_MU:
                self.dwell += dt
                if self.dwell >= TAU_DWELL: s = 'Stick'; self.dwell = 0.0
        elif s == 'GrossSlip' and slip_step / dt < V_STICK:
            self.dwell += dt
            if self.dwell >= TAU_DWELL: s = 'Stick'; self.dwell = 0.0
        elif s == 'Impact' and np.max(np.abs(feat['N'])) < THETA_IMP - H_I:
            self.dwell += dt
            if self.dwell >= TAU_DWELL: s = 'Stick'; self.dwell = 0.0
        self.sigma = s
        return s, r_tau
```

### IP-163 CRP（接触相对定位与可观测性）

```python
class ContactRelativePositioner:
    def __init__(self, object_model, rho_min=2, gamma_min=0.05):
        self.model = object_model
        self.rho_min, self.gamma_min = rho_min, gamma_min
        self.xi = np.eye(4)

    def estimate(self, T, contact_mask, xi_prior):
        residual = lambda xi: self._tactile_residual(T, contact_mask, xi)
        J = jacobian(residual, xi_prior)                 # 数值/解析雅可比
        U, S, Vt = np.linalg.svd(J, full_matrices=False)
        rho = int((S > SIGMA_EPS).sum())
        gamma = float(S[rho - 1]) if rho > 0 else 0.0
        xi_hat = self._map_solve(residual, xi_prior, self.model.contact_sdf)
        valid = (rho >= self.rho_min) and (gamma >= self.gamma_min) and \
                (self._sat_ok(T))
        degenerate_dirs = Vt[rho:]                          # 不可观测子空间
        return xi_hat, rho, gamma, valid, degenerate_dirs
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TFR/DTS | O(N_taxel) / 帧 | O(N_taxel) | 共模不变性（命题 161.1）；滑移前置（命题 161.2） |
| CSM | O(1) 状态迁移 | O(1) | 滞回防抖；预滑→宏观滑移不漏报（在 stick-slip 假设下） |
| CRP | O(k·N_taxel)（k 为迭代数） | O(ξ + J) | 可观测秩 ρ_t 与退化子空间显式化；σ_min ≥ γ_min |
| TSDD | O(K·N_scene) | O(N_scene·M_gmm) | DTS-可鉴别时分类错误受 Fano 下界约束 |
| TEC/EPIR | O(1) 追加 | O(window) | calib/sat 版本校验；差分结论可审计 |
| DTCL | O(闭环) | 复用 | 安全方向单调：SIC 无效时只收紧不放松 |

**正确性定理（DTC，Differential Tactile Cognition）**：假设 A66–A72 成立。
- **(A66) DTS 共模假设**：`T' = aT + b`，`a>0`，`b` 在窗内空间常数或经 `b̂_t` 高通移除；非均匀增益由标定矩阵 `C(x)` 补偿，饱和率 `sat_t ≤ θ_sat`。
- **(A67) 微滑可观测假设**：在摩擦锥边缘存在高频微振，`E_HF` 在宏观滑移前越过 `θ_HF`（stick-slip 模型成立）。
- **(A68) 接触力学模型假设**：`Φ(x;ξ,M_o,f_int)` 在有界模型误差 `ε_Φ` 内成立；接触帧标定误差有界。
- **(A69) 可观测性假设**：`ρ_t ≥ ρ_min`，`γ_pos ≥ γ_min`；退化方向由视觉/本体先验或保守策略覆盖。
- **(A70) 场景可鉴别假设**：`min_{z≠z'} D_diff(z,z') ≥ D_min` 且 `G_diff>0`。
- **(A71) 证据完整性假设**：EPIR 的 seq/hash/calib 校验完备，`differential-invalid` 胶囊不参与差分结论。
- **(A72) 预算假设**：`B_tac` 单调消耗，降级阶梯按可观测性排序。

则：
1. **场景鉴别正确性**：若 A66、A70 成立，则湿滑/粗糙等标量力混淆场景的 DTS 后验可分，`P(ẑ≠z) ≤ ε_scene`，且 `G_diff>0` 说明增益非冗余。
2. **滑移前置性**：若 A67 成立，则 CSM 在 `t_P < t_G` 进入 PreSlip，约束闸门至少提前一个控制周期生效。
3. **接触定位可靠性**：若 A68、A69 成立，则 `CRP_valid=true` 时 `||ξ̂−ξ|| ≤ ε_pos(γ_pos)`；`CRP_valid=false` 时系统显式降级而非静默置信。
4. **安全单调性**：当 `SIC_valid=false` 时 `φ_tac_safe_only` 只允许收紧约束，故 `K_safe^{t+1} ⊆ K_safe^{t}`，不会因误判放宽安全域。
5. **证据可审计性**：若 A71 成立，则任何 `differential-invalid` 证据都被降级为标量证据，不会被用于场景/定位结论。

```python
class TactileDifferentialSignature:
    def __init__(self, shape, eps=1e-6, dt=0.01, f_band=(40, 200)):
        self.shape, self.eps, self.dt = shape, eps, dt
        self.f_band = f_band
        self.baseline = np.zeros(shape + (3,))
        self.beta, self.prev, self.noise_floor = 1e-3, None, 0.02

    def update(self, T):
        if np.linalg.norm(T) < self.noise_floor:
            self.baseline = (1-self.beta)*self.baseline + self.beta*T
        Tt = T - self.baseline
        denom = np.abs(Tt).sum() + self.eps
        N = ((Tt - self.prev)/(self.dt*denom)) if self.prev is not None \
            else np.zeros_like(Tt)
        G = np.gradient(Tt, axis=(0, 1)) / denom
        H = np.gradient(np.gradient(Tt, axis=0), axis=0) / denom
        E = self._band_energy(Tt, self.f_band)
        self.prev = Tt
        return {'S': {'N': N, 'G': G, 'H': H, 'E_hf': E},
                'contact_mask': np.linalg.norm(T, axis=-1) > self.noise_floor,
                'sat_ratio': float((np.linalg.norm(T, axis=-1) >= self.T_max).mean())}
```

class ContactStateMachine:
    def step(self, feat, f_n, f_t, c_dot, dt):
        E, r_tau = feat['E_hf'], np.linalg.norm(f_t)/(f_n + 1e-9)
        slip = np.linalg.norm(feat['slip_field'])*dt
        s = self.sigma
        if s == 'Free' and feat['area'] >= A_MIN and f_n >= F_MIN:
            s = 'Stick'
        elif s == 'Stick':
            if np.max(np.abs(feat['N'])) >= THETA_IMP: s = 'Impact'
            elif np.linalg.norm(c_dot) >= V_EDGE:      s = 'Edge'
            elif E >= self.theta_hf or r_tau >= self.mu_s - DELTA:
                s, self.slip_acc = 'PreSlip', 0.0
        elif s == 'PreSlip':
            self.slip_acc += slip
            if self.slip_acc >= self.d_slip or r_tau >= self.mu_k:
                s = 'GrossSlip'

        elif s == 'Impact' and np.max(np.abs(feat['N'])) < THETA_IMP - H_I:

| 经典阻抗/导纳控制 | 标量力误差驱动 K 调整 | K 由差分触觉证据接地，且接触帧相对化 | `G_diff>0`；边缘/滑移失败率下降 |
| 绝对力阈值滑移检测 | 固定 `f_t/f_n` 阈值 | DTS 共模抑制 + 六态 CSM + 预滑前置 | 跨物体阈值迁移误差 ≤10%；提前 ≥1 周期 |
| 视觉/触觉伺服 | 全局位姿为主，接触精度受遮挡 | 触觉接触帧微定位，显式退化子空间 | `ρ_t/γ_pos` 可观测；1mm 级接触定位 |
| 第 60 轮 SGEC | 标量力→场景先验 | 触觉场→DTS→TSDD，拆分为「场景可分」与「触点可定」 | 湿滑误判 −60%；证据可审计率 ≥99% |

> 定位陈述：**不是「再加一个触觉传感器」，而是把触觉变成可证伪的差分证据层**——用共模抑制把阈值从场景标定中解放出来，用可观测性把「接触定位」从自信猜测变成带退化标记的估计，用 `G_diff` 把「差异化」从叙事变成可裁剪的预算判据。

## 5. 实验设计 E192–E197

| 实验 | 指标 | 目标 |
|---|---|---|
| E192 DTS 不变性 | 增益/偏置扰动漂移；跨物体阈值迁移 | ≤5%；≤10% |
| E193 TSDD | 湿滑/粗糙/软垫分类；`G_diff`；vs 标量力 | ≥92%；`G_diff>0`；+15% |
| E194 CRP | 位姿误差；`ρ_t/γ_pos`；退化检出 | ≤1mm；≥95% |
| E195 CSM | 预滑提前量；漏报/误报 | ≥1 周期；≤1%/≤3% |
| E196 端到端 | vs 第 60 轮：误判、边缘失败、可审计率 | −60%；−40%；≥99% |
| E197 消融/预算 | DTS/CSM/CRP/TEC 贡献；L0–L3 代价 | DTS+CSM 为主；L2 保安全 |

## 6. 本轮最大风险

**一句话**：若触觉阵列发生逐 taxel 增益漂移或饱和，DTS 的共模不变性被破坏，系统可能以「高置信度」把湿滑读成粗糙、把退化定位读成精确接触帧；因此必须以「逐 taxel 标定矩阵 + `sat_t` 门控 + `G_diff` 非冗余校验 + `CRP_valid` 可观测秩检查 + SIC 无效时只收紧不放松」五重护栏，确保差分触觉从不是「更自信的猜测」而是「可证伪的接地」。
