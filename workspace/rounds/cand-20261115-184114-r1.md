# 第 1 轮（新循环；技术基线 v8；本轮灵感：「UniBot」×「异常检测」）

> **基线**：第 8 轮 MetricVoiceGauge-DA-SPR-Cal v8（定义 493–540；引理 77–81；实验 E531–E550）。
> **本轮纪律**：两个灵感不是并列拼装，而是互相成就——UniBot 提供跨本体共享潜空间作为"公共度量尺"，异常检测在该潜空间上做**分布无关的可校准判决**；任一模块失效仍走严格退化链，最终可退回 v8。

## 0. 直觉与动机（先直觉，再严谨）

**灵感 1（UniBot）→ 统一潜空间是"公共度量尺"**
直觉：把 UniBot 想成一个见过大量机器人、任务与指令的"通用具身大脑"，它把视觉、语言、本体状态压进同一个潜空间 Z。v8 的域偏移用独立 ResNet 特征，与动作、语言不共享坐标系；而 UniBot 潜空间天然跨任务、跨本体对齐。于是"异常"可以定义得极朴素：**此刻的潜向量离见过的正常流形有多远**。域偏移是"整体漂移"，异常是"局部离群"，两者成为同一把尺子上的两个刻度。
严谨化：令 ψ_θ: O×L→Z 为冻结的 UniBot 编码器，z_t = ψ_θ(o_t, ℓ_t)。在 Z 上定义非一致性分数 a(z)（kNN 距离），用参考正常集 Z_cal 做保形校准得到 p 值。**异常 ⇔ p ≤ α**，而 α 即误报率上界。这把 v8 里"凭经验收紧"改成"有统计契约的收紧"。

**灵感 2（异常检测）→ 从"多一个风险分"升级为"可证明有界的退化闸门"**
直觉：v8 的最大痛点是感知抖动导致阈值反复收紧→"退化风暴"。异常检测若只当第 6 个风险维度，治标不治本；真正的价值是用**保形 p 值做闸门**：只有在 p ≤ α（统计显著）时才允许 OTL 追加收紧项。没有显著证据的"可疑"，不许触发退化。
严谨化：门控 g(s)=1[p(s)≤α]，把 v8 的 Δ_dom 项升级为 κᵢΔ_dom + μᵢ·g·(1−p)。由保形性质，正常状态下 E[g]≤α，故**单位时间的虚假退化次数期望 ≤ αT**（再加迟滞修正）。这是本轮最硬的贡献：把 v8 的风险从"经验担忧"变成"可计算上界"。

**灵感 3（两者相乘）→ 类型化异常与差异化分诊**
直觉：UniBot 的动作头还能预测下一步动作。于是异常天然分成四型——**感知异常**（潜空间离群）、**语义异常**（新物体/新场景）、**行为异常**（人或其他智能体越界）、**策略异常**（UniBot 预测动作与执行/指令动作残差过大）。四型不是同一个报警，而是四条不同的恢复路径：重标定、减速询问、让行停车、保守重规划。**异常检测不是"响铃"，而是"分诊"。**
严谨化：定义类型化非一致性向量 a(s)=(a_sen,a_sem,a_beh,a_pol)，每型独立保形校准得 p_j；分诊映射 T: j→(层, 恢复动作)，且所有恢复动作仍须通过 M₀ 硬约束。

## 1. 研究问题

- **Q1（统一表征是否划算）**：UniBot 潜空间能否同时服务域偏移估计 Δ_dom 与异常检测，并在 ≤3ms 感知预算内完成，且不破坏 v8 的 50Hz WCET？
- **Q2（误报能否被证明有界）**：如何用保形预测把"何时收紧阈值"变成带 FPR 上界的判决，使虚假退化频率 ≤ αT，同时保持对真实异常的检测功效（power）？
- **Q3（类型化恢复是否无空洞）**：四类异常如何各自落到正确的指标层与恢复动作，且异常触发的任何恢复计划都不绕过 M₀ 硬约束、不产生"软通过硬失"？

## 2. 设计原则（P10–P12，承接 P7–P9）

**P10 统一潜空间基底（UniBot Latent Substrate, ULS）**
用冻结 UniBot 编码器统一 v8 的 φ（域）与新增异常的度量空间，跨本体用逐本体仿射归一化对齐：
```
z_t = ψ_θ(o_t, ℓ_t),   z̃_t = A_e (z_t − b_e) / s_e
```
A_e、b_e、s_e 由该本体少量正常轨迹估计；目的是让异常阈值可跨本体迁移，而非每台机器重标。

**P11 保形异常判决（Conformal Anomaly Verdict, CAV）**
以 kNN 非一致性分数 + 保形 p 值取代固定阈值：
```
a(z) = (1/k) Σ_{i=1}^k ||z − z_(i)||²,   p(z) = (1 + #{r∈Z_cal : a(r) ≥ a(z)}) / (|Z_cal|+1)
```
异常当且仅当 p ≤ α。**α 是误报率上界，不是经验阈值**；参考集仅用通过 M₀ 的正常状态维护，防止异常污染参考集。

**P12 类型化异常分诊（Typed Anomaly Triage, TAT）**
四型异常各自校准、各自映射到层与恢复：

| 类型 | 非一致性来源 | 落入层 | 恢复动作 |
|---|---|---|---|
| 感知异常 | z 在 Z 上的 kNN 离群 | M_anom→M₀ | 触发 Calib-FI 重标定/降权 |
| 语义异常 | 新物体/新场景潜类别 | M_dom,M_anom | 减速 + 语音询问 + 提高安全权重 |
| 行为异常 | 人/智能体轨迹越界 | M₁,M_anom | 让行/停车 |
| 策略异常 | ‖π_uni(z) − a_cmd‖ 残差大 | M₂,M_anom | 保守重规划 |

## 3. 与基线接口（如何退化）

- UniBot 不可用 ⇒ 退回 v8 的 ResNet φ + Mahalanobis 异常分（无保形校准），功能保留但失 FPR 保证；
- 保形校准集缺失/污染 ⇒ α 退化为固定阈值 τ_anom（失保证、保功能）；
- 异常检测整体失效 ⇒ a(s)≡0、g≡1、M_anom 关闭，七层退六层，**严格等价 v8**；
- UniBot 与异常检测同时失效 ⇒ 完整退回 MetricVoiceGauge-DA-SPR-Cal v8，再退回 v7/v6。

## 4. 预期贡献

1. **统一潜空间度量**：把域偏移（整体漂移）与异常（局部离群）统一到 UniBot 潜空间的一把尺子上；
2. **可证明有界的退化闸门**：保形 p 值门控使虚假退化频率 ≤ αT，直接针对 v8 的"退化风暴"风险；
3. **类型化异常分诊**：四型异常→四层→四种恢复，且全部经 M₀ 硬约束过滤；
4. **跨本体迁移**：逐本体仿射归一化让异常阈值可在新本体上零样本迁移；
5. 完整实验 **E551–E570** 覆盖检测功效、误报校准、类型分诊、跨本体、复合压力与退化等价。

## 5. 本轮最大风险

**一句话**：保形预测只保证误报率上界，**不保证检测功效**——若 UniBot 潜空间发生表征坍缩或与真实异常方向错位，系统会"统计上完美守约地漏报"关键异常，而跨本体的仿射归一化还可能把这种漏报系统性放大到新机器人上。

**新增定义 541（UniBot 统一编码 UnifiedLatent）**
```
z_t = ψ_θ(o_t, ℓ_t) = normalize( MLP( Enc_vis(o_t) ⊕ Enc_state(q_t) ⊕ TextEnc(ℓ_t) ) )
```
ψ_θ 冻结（可选 LoRA 适配），d=512；ℓ_t 为语音指令经 TextEnc 的嵌入。z_t 同时供：① v8 域偏移 Δ_dom 的特征输入（替代 ResNet）；② 异常 kNN 度量；③ π_uni 动作预测。

**新增定义 542（逐本体归一化 PerEmbodimentNormalization）**
```
z̃_t = A_e (z_t − b_e) / s_e ,   A_e^⊤ A_e = I
```
A_e,b_e,s_e 由本体 e 的 M 条正常轨迹（M=50）估计：b_e 为均值，s_e 为逐维尺度，A_e 为对齐参考本体协方差主轴的正交变换。目的：让同一 α 在新本体上仍近似有效。

**新增定义 543（kNN 非一致性分数 kNNNonconformity）**
```
a_j(z) = (1/k) Σ_{i=1}^{k} || z̃ − z̃_(i) ||²₂ ,   z̃_(i) 为 Z_ref^(j) 中第 i 近邻
```
k=10；四型各维护独立参考集 Z_ref^(j)。

**新增定义 544（保形 p 值 ConformalPValue）**
```
p_j(z) = ( 1 + #{ r ∈ Z_cal^(j) : a_j(r) ≥ a_j(z) } ) / ( |Z_cal^(j)| + 1 )
```
仅用通过 M₀ 的正常状态填充 Z_cal^(j)（定义 554 的卫生维护）。

**新增定义 545（异常判决与严重度 AnomalyVerdict）**
```
anomalous_j(z) ⇔ p_j(z) ≤ α ,    sev_j(z) = 1 − p_j(z) ∈ [0,1)
```

**新增定义 546（类型化异常向量 TypedAnomalyVector）**
```
a(s) = (a_sen, a_sem, a_beh, a_pol)
a_sen：z̃ 对 Z_ref^(sen) 的 kNN 离群（感知/新场景）
a_sem：潜类别相对参考语义簇的最近簇距离
a_beh：场景中动作者轨迹对可行域边界的侵入量经潜空间编码
a_pol：|| π_uni(z̃) − a_cmd ||² / (||a_cmd||² + ε)
```

**新增定义 547（异常风险分量 AnomalyRiskComponent）**
```
risk_ANOM(s) = Σ_{j∈{sen,sem,beh,pol}} γ_j · g_j · sev_j ,   γ_j ≥ 0
```
有界：0 ≤ risk_ANOM ≤ Σγ_j。默认 γ=(0.25,0.30,0.25,0.20)。

**新增定义 548（六维风险向量 SixDimRisk）**
```
risk(s) ∈ ℝ⁶ = [risk_SEN, risk_SEM, risk_EFF, risk_PERF, risk_SLAM, risk_ANOM]
```

**新增定义 549（异常门控阈值调节 CAG-OTL）**
```
τᵢ(t) = clip( τᵢ(0) + η·θ(t) + κᵢ·Δ_dom(t) + μᵢ·g_anom(t)·sev_anom(t), ε_min,i, ε_max,i )
g_anom(t) = 1[ min_j p_j(z_t) ≤ α ],   sev_anom(t) = max_j (1 − p_j(z_t))
μᵢ ≥ 0（定义 559 单调约束）
```

**新增定义 550（七层指标闭合 SevenLayerMetricLadder）**
```
M = (M₀, M₁, M₂, M₃, M_dom, M_SLAM, M_anom)
M_anom 监控：min_j p_j(z_t) > α（正常）且 risk_ANOM < τ_anom；违背 ⇒ 经 δ_anom 触发 M₀。
```

**新增定义 551（策略异常残差 PolicyAnomalyResidual）**
```
a_pol(s) = || π_uni(z̃) − a_cmd ||²_{Σ_π} / ( ||a_cmd||²_{Σ_π} + ε )
```
Σ_π 为 π_uni 的动作不确定度协方差；同时把 a_pol 注入 M₂（效能）作为"指令-策略一致性"判据。

**新增定义 552（分诊映射 TriageMap）**
```
T(sen) = (M_anom→M₀, CalibFI_isolate)        # 重标定/降权
T(sem) = (M_dom, M_anom→M₀, SlowAndAsk)      # 减速+语音询问+提高安全权重
T(beh) = (M₁, M_anom→M₀, YieldOrStop)        # 让行/停车
T(pol) = (M₂, M_anom→M₀, ConservativeReplan) # 保守重规划
```

**新增定义 553（异常感知软证书 AnomalyAwareSoftCert）**
```
δ_trigger = { σ < τ_safe ∧ γ_grasp valid ∧ Δ_dom < τ_dom
              ∧ risk_SLAM < τ_SLAM ∧ min_j p_j > α }
```
任一条件为假 ⇒ 直接进入 M₀ 硬约束检查。

**新增定义 554（参考集卫生维护 ReferenceSetHygiene）**
```
Z_cal ← ReservoirSample( { s : s 通过 M₀ ∧ p_j(s) > α } )   # 只收正常且非异常样本
if p_j(s) ≤ α: Z_cal 不更新   # 防止异常污染参考集
```
周期性重估 α 的经验分位（滑动 |Z_cal| 的 (1−α) 分位）以对抗概念漂移。

**新增定义 555（迟滞与持续性 Hysteresis）**
```
模式切换到"异常"需连续 m 次 p_j ≤ α（m=3）；恢复"正常"需连续 n 次 p_j > α（n=5）。
```
用于抑制单帧抖动引发的模式翻覆（flapping），与定义 549 的门控叠加。

**新增定义 556（退化链标识 DegradationIdentity）**
```
Φ_UniAD = { z=ψ_θ(o,ℓ),  risk 6-dim+ANOM,  M 7-layer,  τᵢ gated by conformal p }
Φ_v8    = { z=ResNet φ,   risk 5-dim,       M 6-layer,  τᵢ = DA-OTL }
Φ_UniAD | (CAV off) = Φ_v8   # 定义 549 中 g≡0, risk_ANOM≡0, M_anom 关闭
```

**新增定义 557（跨本体迁移阈值 ThresholdTransfer）**
```
τ_anom^(e) = Quantile_{1−α}( { a_j(z̃) : z ∈ Z_cal^(e) } )
```
当本体 e 无标定集时，用参考本体分位经 A_e 映射后直接迁移。

**新增定义 558（异常恢复动作集 RecoveryActionSet）**
```
R = { CalibFI_isolate, SlowAndAsk, YieldOrStop, ConservativeReplan }
每个 r∈R 生成的动作候选仍须通过 M₀ 硬约束（定义 550）方可执行。
```

**新增定义 559（门控单调约束 GateMonotonicity）**
```
μᵢ ≥ 0,  κᵢ ≥ 0,  g∈{0,1},  sev∈[0,1]  ⇒  τᵢ 的异常项只增不减
```
确保异常只会"收紧"阈值，绝不会错误地"放宽"安全约束。

**新增定义 560（主闭环集成契约 IntegrationContract）**


## 2. 形式化定义（要点速览）

- 定义 541–545：UniBot 编码 → 归一化 → kNN 分数 → 保形 p 值 → 判决；

```python
import numpy as np

class UniBotLatentSubstrate:
    """IP-355：统一潜空间基底（冻结编码器 + 逐本体归一化）"""
    def __init__(self, encoder, dim=512, normalizer=None):
        self.encoder = encoder            # ψ_θ，冻结
        self.dim = dim
        self.normalizer = normalizer      # (A_e, b_e, s_e) 或 None

    def encode(self, obs, lang_emb):
        with _no_grad():
            z = self.encoder(obs, lang_emb)      # (d,)
        return self._normalize(z) if self.normalizer else z

    def _normalize(self, z):
        A, b, s = self.normalizer
        return A @ (z - b) / np.maximum(s, 1e-6)


class ConformalAnomalyVerdict:
    """IP-356：kNN 非一致性 + 保形 p 值，四型独立校准"""
    TYPES = ("sen", "sem", "beh", "pol")

    def __init__(self, k=10, alpha=0.05, m=3, n=5):
        self.k = k
        self.alpha = alpha
        self.m, self.n = m, n
        self.Z_ref = {t: [] for t in self.TYPES}   # 参考流形
        self.Z_cal = {t: [] for t in self.TYPES}   # 保形校准集
        self.hist = {t: [] for t in self.TYPES}
        self.mode = {t: "normal" for t in self.TYPES}

    def _knn_score(self, t, z):
        ref = np.asarray(self.Z_ref[t])
        if len(ref) == 0:
            return 0.0
        d = np.sum((ref - z) ** 2, axis=1)
        k = min(self.k, len(d))
        return float(np.mean(np.partition(d, k - 1)[:k]))

    def _p_value(self, t, score):
        cal = np.asarray(self.Z_cal[t])
        if len(cal) == 0:
            return 1.0
        scores = np.array([self._knn_score(t, r) for r in cal])
        return (1.0 + np.sum(scores >= score)) / (len(cal) + 1.0)

    def evaluate(self, z, a_pol=None):
        out = {}
        for t in self.TYPES:
            a = a_pol if (t == "pol" and a_pol is not None) else self._knn_score(t, z)
            p = self._p_value(t, a) if t != "pol" else self._p_value(t, a)
            self.hist[t].append(p)
            self.hist[t] = self.hist[t][-(self.m + self.n):]
            self._update_mode(t, p)
            out[t] = {"a": a, "p": p, "g": int(p <= self.alpha),
                      "sev": 1.0 - p, "mode": self.mode[t]}
        return out

    def _update_mode(self, t, p):
        tail = self.hist[t]
        if self.mode[t] == "normal" and len(tail) >= self.m \
                and all(x <= self.alpha for x in tail[-self.m:]):
            self.mode[t] = "anomalous"
        elif self.mode[t] == "anomalous" and len(tail) >= self.n \
                and all(x > self.alpha for x in tail[-self.n:]):
            self.mode[t] = "normal"

    def risk_component(self, verdict, gamma):
        return sum(gamma[t] * verdict[t]["g"] * verdict[t]["sev"] for t in self.TYPES)


class AnomalyGatedThresholdLadder:
    """IP-358：v8 DA-OTL + 异常门控项 μᵢ·g·sev"""
    def __init__(self, initial, eta=0.05, N=5, kappa=None, mu=None,
                 eps_min=None, eps_max=None):
        self.base = dict(initial)
        self.tau = dict(initial)
        self.eta, self.N = eta, N
        self.kappa = kappa or {i: 0.5 for i in range(7)}
        self.mu = mu or {i: 0.2 for i in range(7)}
        self.eps_min = eps_min or {i: -np.inf for i in range(7)}
        self.eps_max = eps_max or {i: np.inf for i in range(7)}
        self.hist = {i: [] for i in range(7)}
        self.delta_dom = 0.0
        self.g_anom, self.sev_anom = 0, 0.0

    def set_domain_shift(self, d):
        self.delta_dom = d

    def set_anomaly(self, g, sev):
        self.g_anom, self.sev_anom = g, sev

    def update(self, layer, satisfied):
        h = self.hist[layer]
        h.append(1 if satisfied else 0)
        if len(h) > self.N:
            h.pop(0)
        if len(h) < 2:
            return self.tau[layer]
        trend = h[-1] - h[-2]
        adj = self.eta * (-1 if trend < 0 else 1)
        dom = self.kappa[layer] * self.delta_dom
        anom = self.mu[layer] * self.g_anom * self.sev_anom   # μ≥0 ⇒ 只收紧
        self.tau[layer] = float(np.clip(
            self.tau[layer] + adj + dom + anom,
            self.eps_min[layer], self.eps_max[layer]))
        return self.tau[layer]


class AnomalyRecoveryDispatcher:
    """IP-362：四型 → (层, 恢复动作)，全部经 M₀ 过滤"""
    MAP = {
        "sen": ("M_anom→M₀", "CalibFI_isolate"),
        "sem": ("M_dom,M_anom→M₀", "SlowAndAsk"),
        "beh": ("M₁,M_anom→M₀", "YieldOrStop"),
        "pol": ("M₂,M_anom→M₀", "ConservativeReplan"),
    }

    def dispatch(self, verdict, metric_ladder):
        actions = []
        for t, v in verdict.items():
            if v["mode"] == "anomalous":
                target, action = self.MAP[t]
                # 所有恢复动作候选必须过 M₀ 硬约束
                if metric_ladder.check_hard_constraint_safe(action):
                    actions.append((t, target, action))
                else:
                    actions.append((t, target, "M₀-blocked"))
        return actions


def metricvoicegauge_round_9(M, s, obs, lang_emb, audio_stream=None,
                             uls=None, cav=None, dispatcher=None,
                             cag_otl=None, gamma=None):
    """MetricVoiceGauge-UniAD 主闭环：感知 ≤3ms + 决策 ≤20ms = ≤23ms @50Hz"""
    gamma = gamma or {"sen": .25, "sem": .30, "beh": .25, "pol": .20}

    # 0. 感知侧（≤3ms）：UniBot 编码 + 四型异常判决
    if uls is not None and cav is not None:
        z = uls.encode(obs, lang_emb)                       # ~1.5ms
        a_pol = M.policy_head.residual(z, M.cmd) if hasattr(M, "policy_head") else None
        verdict = cav.evaluate(z, a_pol)                    # ~0.8ms
        risk_anom = cav.risk_component(verdict, gamma)      # ~0.1ms
        g_anom = int(any(v["g"] for v in verdict.values()))
        sev_anom = max((v["sev"] for v in verdict.values()), default=0.0)
    else:
        verdict, risk_anom, g_anom, sev_anom = {}, 0.0, 0, 0.0

    # 1. 域偏移（复用 UniBot 潜空间，退回 v8 ResNet 时仍可用）
    delta_dom = M.domain_adapter.compute_domain_shift() if M.domain_adapter else 0.0

    # 2. 门控阈值调节（v8 DA-OTL + 异常项）
    if cag_otl is not None:
        cag_otl.set_domain_shift(delta_dom)
        cag_otl.set_anomaly(g_anom, sev_anom)
        for layer in range(7):
            cag_otl.update(layer, M.metric_ladder.layer_satisfied(layer))
        tau = cag_otl.tau
    else:
        tau = M.metric_ladder.thresholds

    # 3. 六维风险向量（v8 5 维 + risk_ANOM）
    base5 = M.reward_decomposer.risk_vector(M.env.state, M.slam_risk)
    risk6 = np.array([*base5, risk_anom])
    w = M.meta_weight.softmax6(risk6)

    # 4. 分诊恢复（仅异常模式触发；全部过 M₀）
    actions = dispatcher.dispatch(verdict, M.metric_ladder) if dispatcher else []

    # 5. 继承 v8 主流程：规划 → 指标监控(7层, tau) → SpatialCert/FaultCert
    #    → 软硬约束(p_anom>α 且旧条件) → 奖励(w) → 证书发布
    return M.metricvoicegauge_round_8(
        M, s, obs, audio_stream, taut=tau, risk6=risk6, w=w, triage=actions)
```

## 4. 推导

**引理 82（保形误报率上界）**
设正常状态与校准集 Z_cal^(j) 可交换（exchangeable），非一致性分数为 a_j。则对正常 s_t：
```
P( p_j(z_t) ≤ α ) ≤ α
```
证明：标准保形（split conformal）结论——p 值在正常样本上一致分布于 {1/(n+1),…,1}，故 P(p≤α)=⌊α(n+1)⌋/(n+1) ≤ α。推论：单次判决的虚假异常率 ≤ α；这是定义 544 的直接结果，**与分数分布、维度无关**。

**引理 83（虚假退化频率上界）**
在引理 82 与迟滞（定义 555，m-of-n）下，单位时间 T 内由异常门控引起的虚假阈值收紧次数期望满足
```
E[#false tightenings] ≤ α·T / m + O(1)
```
证明：无条件时每步虚假门控概率 ≤ α；m 连击要求把单步事件降为长度 m 的游程，其期望启动频率 ≤ α^m 的游程近似；保守上界取 α/m·T。因此 **v8 中"经验上可能任意频繁"的退化风暴被 α 显式压住**，α 越小越稳（代价是功效下降，见最大风险）。

**引理 84（稀疏异常互补性）**
令窗口均值偏移 Δ_dom = ‖μ_W − μ_ref‖²，单个异常点相对参考流形的距离为 D。若异常只占窗口比例 β，则 Δ_dom ≤ β·D 量级；当 β < 1/W 时可能 Δ_dom < τ_dom（整体漂移被稀释）。而 kNN 分数 a_j(z) 是**逐样本局部统计**，不受稀释，只要 D 超过 Z_cal 的 (1−α) 分位即有 p_j ≤ α。故存在异常满足
```
Δ_dom < τ_dom  ∧  p_anom ≤ α
```
即"均值漂移漏检、kNN 检出"。结论：M_dom 与 M_anom 互补，不可互相替代。

**引理 85（退化正确性）**
关闭 CAV（a≡0、p≡1、g≡0、sev≡0）⇒ 定义 547 risk_ANOM≡0；定义 549 的异常项 μᵢ·g·sev≡0，CAG-OTL 退化为 v8 的 DA-OTL；定义 548 六维退五维；定义 550 七层退六层；定义 553 去掉 p 条件。逐项与 v8 定义 529/527/493/496 相同，故 Φ_UniAD|(CAV off) = Φ_v8。**各增强接口正交，无级联副作用。**

**引理 86（跨本体 FPR 连续性）**
设本体 e 归一化后的潜分布与参考分布 Wasserstein-1 距离为 δ_e，kNN 分数分布在阈值 τ_anom 附近的密度下界为 c>0。则迁移阈值在本体 e 上的真实 FPR 满足
```
| FPR_e − α | ≤ C·δ_e ,   C = C(α, c, k)
```
证明：Wasserstein-1 连续性控制分位数的偏移；分数分布越平坦（c 小）界越松。**该引理是"条件性"的：δ_e 大或 c 小时跨本体迁移不可靠**——这正是最大风险的形式化来源。

**引理 87（无安全空洞与单调性）**
定义 559 保证 μᵢ,κᵢ≥0、g∈{0,1}、sev∈[0,1]，故定义 549 的异常项非负，τᵢ 只可能被收紧、绝不放松；定义 558 要求每个恢复动作候选先过 M₀ 硬约束，定义 552 每条分诊路径都标注 `→M₀`。因此"异常被处理"与"安全被保证"不脱节：任一异常触发的恢复计划若违反 M₀ 则被阻断（`M₀-blocked`），不存在"软通过硬失"。
