# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS 具身计量审计×意图×接触×实时执行」IP-287~294；灵感循环第 3 轮；本轮灵感：「仿真训练」×「创新点挖掘」）

> R72 把 GAUGE 从「认知层」下沉为「具身系统」：REG 调度契约、联合后验 b_t(s,z)、灵巧手接触四分量、三层反作用预算、S2R-UQ 参数桥接，最后用 J_EMB 盖章。但 R72 有一个没被正视的事实：**它的全部不变式与阈值都是人手设定的**——τ_ece_intent、τ_Hc、τ_slip、B_reflex_total、λ_floor、WCET 余量、|N_REG|≤20……没有一个是由数据「训练」或「证伪」出来的。它们只是「研究者先验 + 有限测试」。R72 自己承认最大风险正是：证书可能**自信地错自己的可执行性**。
>
> 本轮两个灵感正好补这口气：
> - **仿真训练（Simulation Training）**：仿真是唯一能拿到**不确定度真值**（s\*, z\*, c\*, 接触力真值、真实 WCET、真实滑移时刻）并**大规模注入故障/分布外/对抗**的地方。但——**朴素地用仿真训练审计器，会制造「模拟器共适应」（simulator co-adaptation）**：审计器学到的是模拟器自己的误差模型，而不是世界的误差模型；证书于是变成**自我实现的预言**。所以「用仿真训练」不是免费的午餐，必须给出**特权信息隔离、单侧覆盖目标、留出模拟器族、模拟差异预算**的严格协议。
> - **创新点挖掘（Innovation Mining）**：R72 的六层结构是人「想」出来的。创新点可以被形式化为**「不变式的反例」**：在压力空间中搜索能够**最小地违反** A106–A110（RTA 通过、意图校准、接触可测、反作用 Lipschitz、S2R 残差有界）的**见证（witness）**，见证要么**收紧阈值**，要么**编译成一条新不变式/新层**。这把「灵感」变成**可搜索、可复现、可证伪**的过程。但必须防止**对「创新」本身 Goodhart**（为凑数发明 trivial 层），因此定义**负载性（load-bearing）**：一个新层只有满足「移除它会让留出见证集上的认证风险界严格变大」，才算一个真创新点。
>
> 核心命题：**不再问「我的证书在测试集上成立吗」，而问「我的证书的成立边界，是否已被一个对抗性的仿真训练与证伪挖掘过程主动搜索过，并留下可审计的覆盖账本？」** —— 把 R72 的「具身计量审计」升级为 **FORGE-GAUGE-RAS**（**F**alsification-**O**riented **R**ed-team **G**ap-mining **E**ngine for GAUGE-RAS，证伪驱动 × 红队生成 × 缺口挖掘的**审计训练闭环**）。

## 0. 直觉与动机

**灵感 1（仿真训练 → 仿真不是「更便宜的实机」，而是「唯一能看见真值的反事实实验室」）**
直觉：实机上你永远不知道「真实的意图是什么」「真实接触力是多少」「如果不开这一枪真实 WCET 是多少」。只有仿真能给你**特权神谕（privileged oracle）**：s\*、z\*、c\*、真实接触几何、真实滑移时刻、真实最坏执行时间。这意味着，仿真里可以**监督审计器去逼近真值的不确定度**——这是实机做不到的。
但危险也在这里：如果审计器只在**一个**模拟器里训练，它会把「这个模拟器的误差结构」当成「世界的误差结构」。于是**模拟器里没建模的物理，恰好也是审计器不会报警的物理**——审计器与模拟器「共谋」，证书自我盖章。这不只是 sim2real gap 的旧问题，而是 **sim2real gap 作用在「审计器本身」上**：R72 只担心策略过拟合仿真，本轮要担心**审计器过拟合仿真**。直觉结论：**仿真训练的正确目标不是「让审计器更准」，而是「让审计器在留出的模拟器族上仍然保守」——要单侧覆盖（upper-bound），不要对称校准（ECE）。**

**灵感 2（创新点挖掘 → 创新点 = 「不变式的最小反例」）**
直觉：人类研究者的「灵感」往往是「我在某次实验里看到一个反常，于是加了一层」。这个过程的本质是：**发现一个当前假设的违反者，然后把它固化成新的假设约束**。既然如此，它可以被自动化：维护压力算子库（保真度降级、传感器漂移、接触模式切换、意图分布外、调度风暴、对抗注入），用质量-多样性搜索（MAP-Elites/novelty）去找**最小的**违反见证；每个见证或收紧一个阈值，或编译成一条新不变式。**「创新点挖掘」于是 = 对假设空间做定向证伪搜索 + 见证到约束的编译。**
但要警惕：如果以「挖到的创新点数量」为优化目标，引擎会大量产出**平凡层**（比如把一个阈值从 0.08 调到 0.079 也算一层）——这是**对创新本身 Goodhart**。所以创新点必须**负载（load-bearing）**：在**留出见证集**上，移除它会让认证风险界严格变差；否则不计入。

**灵感 3（二者的化学反应 → 仿真训练提供真值，创新挖掘消费反例；但共享同一个「表达力天花板」）**
直觉：仿真训练给创新挖掘提供**真值标注的失败案例**（否则你不知道这一枪打偏是估计错还是审计错）；创新挖掘给仿真训练提供**课程**（专挑审计器最弱、且最像真实失效的角落去练）。二者形成闭环：**训练 → 挖掘 → 编译 → 再训练**。
但闭环有一个致命的结构性风险：**「挖不到反例」≠「没有反例」**。如果模拟器族表达不了某种真实失效（比如某种从未被建模的文化手势、某种 DDS 中断风暴），那么红队再强也挖不到，覆盖账本会显示「已覆盖」，而真实世界恰好从那个缺口漏进去。**证书永远只能相对于「声明的 (模拟器族 Π, 红队预算 R, 压力算子库 F, 覆盖度 κ)」成立**——这一条必须写进证书语义，而不是藏在脚注里。

**灵感 4（与 R72 的关系 → 不是加第 7 层，而是给前 6 层配「训练与证伪的元层」）**
直觉：R72 的 REG/IRL/DMEM/EREFLEX/ERVOI/S2R-UQ 是**对象层**；FORGE 是**元层**：它不直接控制机器人，而是**训练、证伪、并审计对象层的阈值与假设**。因此 FORGE 的退化必须极其保守：**元层失效时，对象层退回 R72 的手设阈值（而不是无限信任训练产物）**；这保证了「训练出问题」不会反向污染已经验证过的安全包络。

## 1. 形式化定义（增量：定义 366–378）

**定义 366（FORGE-GAUGE-RAS 总览）** FORGE-GAUGE-RAS = (STG, PUL, OCR, RTP, FME, I2C, GAUGE-RAS†)。六不变式：
(i) **特权隔离**：特权神谕只进训练，**可部署估计器永远看不到 (s\*, z\*, c\*, τ\*)**；泄漏必须被审计（定义 368）；
(ii) **单侧覆盖优先**：所有安全相关风险计以**单侧上界覆盖**（tail coverage）为目标，**不以 ECE 为目标**；ECE 低不等于尾部安全（定义 369）；
(iii) **模拟器族留出**：训练用 Π_train，验证用**不相交**的 Π_heldout；证书必须携带模拟差异预算 d̂ 与置信半径（定义 374）；
(iv) **红队不可认证**：任何红队策略能击穿的 (context, policy) 一律不得进入认证集；认证是**对策略类**的，不是对单条轨迹（定义 370）；
(v) **反例可编译且负载**：每个见证要么收紧阈值，要么编译成新不变式；创新点只在**留出见证集上负载**时计数（定义 372）；
(vi) **声明式保证**：J_FORGE 的语义是**条件保证** `Safe | (Π, R_budget, F, κ, d̂)`，声明本身进入审计（定义 377–378）。

**定义 367（仿真训练场 STG 与特权神谕）** STG = (Π, G, F, O, Λ)：
- Π = {π_1,…,π_M} 为**异构模拟器族**（不同引擎/不同保真度/不同域随机化参数），划分为 Π_train ⊔ Π_heldout；
- G: 场景 → (s\*, z\*, c\*, F_contact\*, t_slip\*, τ\*_wcet) 为**特权神谕**，只在训练与评估时可用；
- F 为压力算子库，每个 f ∈ F: 场景 → 场景'（保真度降级、噪声注入、接触切换、意图分布外、调度风暴、对抗注入）；
- O 为**可部署观测模型**（非特权），o = O(s, z, c) + noise；
- Λ 为训练课程调度器。
**关键**：G 在部署时物理上不可得（不接线、不旁路），PUL 必须保证 f_θ(o) 不依赖 G。

**定义 368（特权不确定性学习 PUL 与泄漏审计）** 审计器/风险计 f_θ: o → (û, m̂) 在训练期用特权标签 u\* 监督，经蒸馏得到可部署版本。定义**特权差距** G_priv = E_{real}[u\*(x) − û(x)]，要求**单侧保守**：P(u\* > û + ε) ≤ α_priv（宁可高估不确定度，不可低估）。**泄漏审计**：以互信息/金丝雀探针 I(o; G | û) ≤ ε_leak 与「删除特权通道后性能不降」双判据验证隔离；任一越界 ⇒ 该风险计不可用于认证。

**定义 369（单侧覆盖风险计 OCR）** 对每个安全相关指标 m（如 u_tac、H[b_t(z)]、WCET），风险计输出**上预测界** I_m(o) = [0, U_m(o)]，标称覆盖率 1−α。定义：
- **边际覆盖** C_marg = P(u_true ≤ U_m(o))；
- **风险条件覆盖** C_cond = inf_{高险层 g} P(u_true ≤ U_m(o) | g)（Mondrian/group-conformal）；
- **尾部风险** R_α = E[(u_true − U_m(o))_+]。
认证要求**单侧** C_cond ≥ 1−α 且 R_α ≤ ε_tail。**明令禁止**用 ECE 作为安全风险计的训练目标：ECE 可在「平均很准、尾部系统性低估」时接近 0，而安全恰恰死在尾部。

**定义 370（红队策略与不可认证性）** 红队策略 π_red 在预算 R_budget 内最大化「**已认证但实际不安全**」（Certified-But-Unsafe, CBU）：
J_red(π_red) = E[ 𝟙(certified) · 𝟙(unsafe) · severity ]，s.t. cost(π_red) ≤ R_budget。
认证器 C 对**策略类** Π_reach 给出认证集 S_cert(ε) = { (π, ctx) : sup_{π_red∈R_budget} CBU(π,ctx) ≤ ε }。
**性质**：R_budget 越大 ⇒ S_cert 越小（单调收缩）；**若 π_red 只能攻击部署策略本身，则证书只对该策略有效，对「以后可能被训练出的策略」无效**——因此红队必须对**可达策略类**取上确界。

**定义 371（证伪挖掘引擎 FME 与质量-多样性档案）** 压力空间 Σ = ∏_{f∈F} domain(f)。FME 维护档案 𝒜（MAP-Elites/novelty），键为**失效原型**（RTA miss / 意图高置信错 / 滑移漏检 / 四分量低估 / 反作用预算穿透 / 模拟差异超界），格内保存**最小见证** w = (scenario, f-composition, invariant_id, margin, minimality)。搜索目标：
max_w [ violation(w) + η·novelty(w) − ζ·|f-composition| ]，
其中 **1-最小性**：对 w 的任一压力算子做 delta-debugging 删除后 violation 不再成立。搜索同时受**种子多样性**与**留出模拟器**约束（防止在 Π_train 上过拟合出伪见证）。

**定义 372（不变式→约束编译器 I2C 与负载性账本）** I2C: witness → constraint。按失效原型映射：
- RTA miss → 收紧 δ 或改用 WCET(θ_nom)+L_T·u_real^max 的保守界（引理 32）；
- 意图高置信错 → 收紧 τ_ece_intent / 提高 ι_intent 惩罚 / 扩充 SEAL-Intent；
- 接触分量低估 → 增加分量估计或抬高 u_tac 先验；
- 反作用穿透 → 收紧 B_reflex_total 或改联合上界（R72 风险 4）；
- 模拟差异超界 → 增加 Π_heldout 成员或抬高 d̂。
**负载性（load-bearing）**：新约束/新层 ℓ 计入创新点，当且仅当在**留出见证集 W_held** 上
∃ w: risk_bound(GAUGE \ ℓ, w) − risk_bound(GAUGE ∪ ℓ, w) ≥ Δ_min > 0。
**创新产出** = #{ℓ 负载} / #{ℓ 挖出}；**创新复杂度代价** = 新增参数/阈值/节点的审计负担。**禁止**以「挖出数量」为目标函数。

**定义 373（假设覆盖度与未覆盖区风险界）** 假设空间 𝒜 = {A106,…,A110 及其量化参数}。覆盖度 κ = μ(𝒜 中被至少一个非平凡见证触及的区域) / μ(𝒜)。**未覆盖区不能当作安全**：设风险界对假设参数 Lipschitz 常数 L_R，未覆盖区直径 diam(𝒜\𝒜_cov)，则
R_total ≤ κ·R_cov + (1−κ)·(R_cov + L_R·diam(𝒜\𝒜_cov)) = R_cov + (1−κ)·L_R·diam。
**认证门槛**：κ ≥ κ_min 且 (1−κ)·L_R·diam ≤ ε_unk（未知-未知预算）。

**定义 374（模拟差异预算 SDB 与迁移界）** 对 π ∈ Π，定义差异 d(π) = sup_{w∈W_held} |R_real(w) − R_π(w)|（由少量实机锚点 + 分位数回归估计 d̂ 与置信半径 ρ）。**迁移证书**：
R_real ≤ R_π + d̂ + ρ，且须 d̂ + ρ ≤ ε_cert，否则**禁止把 π 上调的保证迁移到实机**。
**留出规则**：d̂ 必须在 π ∉ Π_train 上估计；对 Π_train 内估计的 d̂ 一律加**共适应惩罚**（定义 375）。

**定义 375（两时间尺度对抗训练与非共谋）** 认证器 C_φ 与红队 R_ψ 交替优化：
min_φ max_ψ [ L_cert(φ; ψ) + λ·CoAdapt(φ, π_deploy) ]，ψ 每 K 步更新、φ 每 1 步更新（两时间尺度），且部署策略 π_deploy 的训练**stop-gradient 于 C_φ**。
**共适应差距** CoAdapt = E_{π_deploy}[CBU] − E_{π_red∪π_deploy 外的对抗策略}[CBU]；若 CoAdapt > ε_co，说明策略学到的是「骗过当前认证器」而非「真安全」，证书作废。

**定义 376（创新挖掘的有限停止与重开）** 设第 n 次挖掘的负载产出收益 Δ_n、探测成本 c_n > 0。当 Δ_{n+1} ≤ c_{n+1} 且覆盖增量 Δκ_{n+1} ≤ ε_κ 时停止。**非平稳重开**：若 Π_heldout 或红队预算发生变化，覆盖账本失效，挖掘**重开**（不继承旧 κ）。

**定义 377（仿真训练证书 J_FORGE）** J_FORGE = (J_EMB, priv_isolation_proof, coverage_report{每指标}, sdb{π,d̂,ρ}, redteam_score{sup CBU}, witness_archive_hash, κ, loadbearing_ledger, declaration)。Valid ⇔ Valid(J_EMB) ∧ 特权隔离通过 ∧ 每指标 C_cond ≥ 1−α ∧ d̂+ρ ≤ ε_cert ∧ sup CBU ≤ ε_cbu ∧ κ ≥ κ_min ∧ 未知-未知预算达标 ∧ 声明哈希匹配。

**定义 378（威胁模型 AIC-FORGE）** ℰ_FORGE = ℰ_EMB × ℰ_sim × ℰ_red × ℰ_mine：
ℰ_sim = {模拟器后门/投毒、保真度虚标、Π_heldout 泄漏、差异 d̂ 伪造}；
ℰ_red = {红队奖励黑客（只挑易例）、共谋（与部署策略共享种子）、对覆盖账本做投毒}；
ℰ_mine = {压力算子库不全导致「假覆盖」、最小见证不可复现、I2C 编译出平凡层刷负载性}；
ℰ_meta = {声明 (Π,R,F,κ) 本身被篡改，把「相对保证」包装成「绝对保证」}。

```python
# IP-295 STG：仿真训练场 + 特权神谕（训练期专用，部署期物理不可达）
@dataclass
class Privileged:
    s_star: State; z_star: Intent; c_star: ContactMode
    contact_force: Array; t_slip: float; wcet_true: float

class SimTrainingGround:
    def __init__(self, sim_family, stress_ops, obs_model, curriculum):
        self.Pi = sim_family                 # 训/验已切分 Pi_train / Pi_heldout
        self.F, self.O, self.cur = stress_ops, obs_model, curriculum
    def rollout(self, pi_id, stress_seq):
        scen = self.sample_scene(pi_id)
        for f in stress_seq: scen = self.F[f](scen)      # 压力算子组合
        traj, priv = self.Pi[pi_id].run(scen)            # priv = 特权神谕
        obs = self.O(traj)                               # 可部署观测
        return obs, priv

# IP-296 PUL：特权不确定性学习 + 泄漏审计（训练期）
class PrivilegedUncertaintyLearner:
    def fit(self, dataset):                 # dataset: (obs, u_star) from G
        # 单侧损失：惩罚低估（u_hat < u_star），容忍高估
        loss = lambda u_hat, u_star: softplus(u_star - u_hat) ** 2
        return train(self.net, dataset, loss)
    def audit_leakage(self, obs, priv):
        mi = mutual_info_estimate(obs, priv, self.net)
        canary = canary_probe(self.net, priv)          # 删通道后性能是否塌
        return mi <= EPS_LEAK and not canary.collapses

# IP-297 OCR：单侧覆盖风险计（组条件 conformal，训练期校准）
class OneSidedCoverageMeter:
    def calibrate(self, calib_set):         # (o, u_true, group) 来自 Pi_heldout
        self.q = {}
        for g in calib_set.groups:          # Mondrian：按高险层分组
            resid = [u_true - self.upper(o) for o,u_true,_ in calib_set if g]
            self.q[g] = quantile(resid, 1 - ALPHA)     # 单侧上界
    def upper(self, o):
        g = self.stratum(o)
        return self.raw(o) + self.q[g]       # 保证尾部覆盖，而非 ECE
    def report(self):
        return coverage(self, groups='mondrian'), tail_risk(self)

# IP-298 RTP：红队策略（最大化「已认证但实际不安全」）
class RedTeamPolicy:
    def objective(self, certified, unsafe, severity):
        return (certified * unsafe * severity).mean()   # CBU rate + 严重度
    def step(self, env, budget):
        # 在 R_budget 内搜索能穿过认证器、且真实出事的策略
        adv = self.optimize(self.objective, env, max_cost=budget)
        return adv, self.sup_cbu(adv)                    # 取上确界，不取平均

# IP-299 FME：证伪挖掘引擎（质量-多样性 + 1-最小见证）
class FalsificationMiningEngine:
    def __init__(self, archive, stress_ops, sim_train, sim_heldout):
        self.A, self.F = archive, stress_ops
    def mine(self, invariant_suite, budget):
        found = []
        while budget.remaining():
            w = self.sample_stress(self.F, seed_diverse=True)
            if not self.F.valid_on(w, self.sim_heldout):  # 拒伪见证
                continue
            viol = invariant_suite.violation(w)           # 距违反多远
            if viol <= 0: continue
            w = self.minimize_1minimal(w, invariant_suite) # delta-debugging
            if self.A.add(w):                              # 新失效原型或更小
                found.append(w)
        return found
    def minimize_1minimal(self, w, inv):
        for f in reversed(w.stress_seq):
            w2 = w.without(f)
            if inv.violation(w2) > 0: w = w2              # 删掉仍违反 => 更小
        return w

# IP-300 I2C：不变式→约束编译 + 负载性账本
class InvariantToConstraintCompiler:
    MAP = {'rta_miss':'tighten_delta_or_wcet_bound',
           'intent_overconfident':'tighten_tau_ece_or_iota',
           'contact_underestimate':'add_component_or_raise_prior',
           'reflex_breach':'tighten_B_or_joint_upper',
           'sdb_exceed':'enlarge_heldout_family'}
    def compile(self, witness):
        return refine_invariants(self.MAP[witness.kind], witness)
    def is_load_bearing(self, layer, heldout_witnesses, g_guard):
        delta = max(risk_bound(g_guard, w) - risk_bound(add(g_guard, layer), w)
                    for w in heldout_witnesses)
        return delta >= DELTA_MIN

# IP-301 ACB：假设覆盖度 + 未知-未知预算
def assumption_coverage(archive, assumption_space):
    cov = union_of_touched(archive, assumption_space)
    kappa = measure(cov) / measure(assumption_space)
    unk = (1 - kappa) * L_R * diameter(assumption_space - cov)
    return kappa, unk            # 认证须 kappa>=K_MIN and unk<=EPS_UNK

# IP-302 SDB：模拟差异预算 + 迁移界
def sim_discrepancy(pi, heldout_witnesses, real_anchors):
    d = max(abs(risk_real(w) - risk_pi(pi, w))
            for w in heldout_witnesses if w in real_anchors)
    d_hat = quantile_regression(d, q=0.99)
    rho = conformal_radius(real_anchors)
    return d_hat, rho            # 须 d_hat+rho <= EPS_CERT 才可迁移

# IP-303 FORGE 主循环：两时间尺度对抗训练 + 挖掘 + 编译
def FORGE_round(STG, C, R, FME, I2C, budget):
    # (1) 训练：PUL/OCR 用特权标签，仅在 Pi_train
    obs, priv = STG.sample_batch(Pi='train')

    assert C.pul.audit_leakage(obs, priv)
    # (2) 红队：最大化 CBU（不只看部署策略，看策略类）
    adv, sup_cbu = R.step(STG.env(Pi='heldout'), R_budget=budget.red)
    # (3) 挖掘：找最小反例，拒绝伪见证
    witnesses = FME.mine(C.invariants, budget.mine)
    # (4) 编译：负载性检验（留出见证集，不看训练见证）
    for w in witnesses:
        layer = I2C.compile(w)
        if I2C.is_load_bearing(layer, heldout_witnesses, C.invariants):
            C.invariants = add(C.invariants, layer)
            C.ledger.record(layer, w, delta=...)
    # (5) 覆盖与迁移：不达标就不盖章
    kappa, unk = assumption_coverage(FME.A, C.assumption_space)
    d_hat, rho = sim_discrepancy(Pi='heldout', heldout_witnesses, C.real_anchors)
    if sup_cbu > EPS_CBU or kappa < K_MIN or unk > EPS_UNK or d_hat+rho > EPS_CERT:
        return J_FORGE(C, valid=False, reason=...)   # 拒绝，不降级为「相信训练」
    return J_FORGE(C, valid=True, declaration=(STG.Pi, budget.red, FME.F, kappa))

# IP-304 FORGE 部署主闭环（元层只训练/审计，不直接控制）
```

## 3. 推导

**引理 33（ECE→尾部安全不成立；单侧覆盖才是安全语义）** 存在一族风险计 {f_n} 使 ECE(f_n) → 0，而其高险层覆盖率 C_cond → 0。证明思路：令 f_n 在 99% 的样本上略高估、在 1% 的高险样本上严重低估；平均校准误差被 99% 的样本摊薄到 0，而安全损失全部集中在被低估的尾部。系：**R72 用 ECE_intent/ECE_aff 作为 veto 指标是不完备的；安全相关指标必须用单侧/条件覆盖与尾部 CVaR。**

**引理 34（特权泄漏 ⇒ 部署端系统性过度自信）** 若 I(o; G | û) > ε_leak，则存在依赖特权信息的 û 在部署分布上满足 E[u\* − û] > 0（低估），从而 λ 被低估。证明：由 Fano/数据处理不等式，若 û 携带 G 的信息，则它必然对 G 所刻画的真实误差结构有偏；移除 G 后其误差转为有向低估。系：**「仿真里很准」可能是特权泄漏，而不是可部署的校准。**

**引理 35（红队预算 ⇒ 认证集单调收缩）** 若 R_budget' ⊇ R_budget，则 S_cert(ε; R_budget') ⊆ S_cert(ε; R_budget)。证明：上确界在更大集合上取，CBU 只增不减。系：**认证集的大小本身就是红队强度的函数；任何不提红队预算的「安全率」都不可比。**

**引理 36（负载性创新 ⇒ 风险界严格下降，但复杂度可上升）** 若 ℓ 负载，则存在留出见证 w 使 risk_bound(GAUGE∪ℓ, w) ≤ risk_bound(GAUGE, w) − Δ_min；但 |params| 增加可能抬高审计成本与 WCET 余量。因此创新点在 (风险界, 复杂度) 平面上形成 **Pareto 前沿**，选点须显式声明。系：**创新不是越多越好，是 Pareto 上的移动。**

**引理 37（覆盖度不足 ⇒ 风险界不可收缩）** 由定义 373，只要 (1−κ)·L_R·diam > ε_unk，就存在未覆盖假设上的最坏执行使 R_total > ε_unk，无论已覆盖区多好。证明：未覆盖区风险由 Lipschitz 界接管，与 κ 无关。系：**「我们挖到很多反例」不等于「余下区域安全」——覆盖账本必须带未覆盖上界。**

**引理 38（模拟差异预算 ⇒ 迁移证书的有效性）** 若 d̂+ρ ≤ ε_cert 且 d̂ 在 Π_heldout 上估计，则 R_real ≤ R_π + ε_cert 以置信度 1−δ 成立。证明：由定义 374 与 conformal 半径的有限样本覆盖。系：**没有实机锚点的「仿真安全率」不能迁移；有锚点也必须声明置信度。**

**引理 39（两时间尺度 ⇒ 非共谋的局部稳定）** 在定义 375 下，若红队每 K 步、认证器每 1 步更新且部署策略对认证器 stop-gradient，则部署策略的一阶最优性条件不含「欺骗认证器」方向，共适应差距 CoAdapt 在局部不增。证明：对 φ 的梯度不回流到 π_deploy，故 π_deploy 只优化真实任务+真实风险代理，而非认证器边界。系：**共谋是可以通过训练协议（而非事后审计）结构性避免的。**

**定理 27（FORGE 是 R72 的严格元层泛化）** 取 F=∅（无压力算子）、κ=1（覆盖全假设空间）、R_budget=0（无红队）、Π_heldout=Π_train、d̂=0，则 J_FORGE ≡ J_EMB，FORGE 主循环退化为 R72 的手设阈值路径，且**不引入任何新的控制行为**。**证明**：各新增模块在退化参数下为空操作，阈值表回退到 R72 缺省。**安全侧只增不减：FORGE 只在元层增加审计，不改写对象层的安全包络。**

**定理 28（红队鲁棒证书 ⇒ 部署安全，条件于策略类）** 若 sup_{π_red∈R_budget} CBU ≤ ε_cbu 且部署策略 π_deploy ∈ Π_reach 被红队覆盖，则 P(certified ∧ unsafe) ≤ ε_cbu + ε_gap(Π_reach, R_budget)，其中 ε_gap 是「红队未覆盖的可达策略」造成的间隙。**证明**：直接由定义 370 与全概率公式。系：**证书的安全性=红队覆盖面×认证器鲁棒性，二者缺一不可；这也是本框架必须公开声明 R_budget 的原因。**

**定理 29（无一揽子保证：证书只能相对于声明成立，且存在不可挖失效）** 对任意有限模拟器族 Π、有限压力算子库 F、有限红队预算 R_budget，存在一个真实世界失效模式 w† 使 w† ∉ span(Π,F,R_budget)（不可表达/不可达）。因此不存在基于 (Π,F,R_budget) 的**绝对**安全证书；J_FORGE 只能是**相对证书** `Safe | (Π,R,F,κ,d̂)`。**证明**：构造 w† 需要 Π 未建模的物理或 F 未包含的算子，其存在性由「有限族 ∪ 有限算子 ≠ 真实世界全体」保证（对角线/表达力论证）。系：**诚实的结论不是「我们证明了安全」，而是「我们证明了在声明的对手与表达力下未找到反例，并给出了未覆盖区上界」——这把 R72 的「自信地错」显式降级为「已知边界的相对保证」。**

**定理 30（负载性计数 ⇒ 对创新 Goodhart 免疫）** 若创新点只按定义 372 的负载性计数，且风险界在留出见证集上被独立评估，则任何最大化负载创新数目的策略都不能通过「加入平凡层」降低认证风险界（平凡层非负载，不计分），故优化负载创新数**不会**恶化留出见证上的安全界；它最多在复杂度轴上付出代价（引理 36）。**证明**：非负载层对留出见证的风险界差 < Δ_min，删除它不改变认证；负载层才改变。**系：把「创新产出」定义为负载性，是把 Goodhart 从目标函数里结构性移除，而不是靠评审人拍脑袋。**

## 6. 本轮最大风险

**一句话**：FORGE-GAUGE-RAS 把 R72 的「自信地错自己的可执行性」换成了更隐蔽的「**自信地错自己的表达力**」——它用仿真训练出审计器、用红队挖出反例、用覆盖账本宣称「已搜索」，但**「没挖到反例」永远不等于「没有反例」**：如果模拟器族 Π 表达不了某种真实物理（未建模的接触磨损、DDS 中断风暴、跨文化意图），压力算子库 F 里没有对应算子，红队预算 R 又只在 Π 的壳内搜索，那么 FME 会在「可表达世界的全集」里勤勤恳恳地挖，覆盖账本 κ 逼近 1，J_FORGE 带着「单侧覆盖达标、差异预算达标、红队上确界达标」的完整签名盖章放行，而真实失效恰好从那个**谁都没建模的维度**穿过——事后审计会显示「所有挖到的反例都已编译、所有覆盖都达标、所有声明都匹配」，这就是**元层面的「在错误的假设空间里证明了正确性」**，比 R72 的「自信地错」更难被发现，因为这次连「证伪过程」本身都成了信任对象。

次级风险与缓解：
1. **模拟器族表达力不足** → 维护**跨引擎异构族**（MuJoCo/Isaac/自研刚柔耦合），并引入**真实锚点最小集**；对「Π 未覆盖的真实失效」强制标记为 known-unknown，禁止计入 κ。
2. **红队只在壳内搜（共谋）** → 红队必须跨 Π_heldout 训练，并保留**一支不参与训练的黑箱红队**做最终检验（类似 holdout evaluator）。
3. **覆盖度 κ 被 Goodhart** → κ 不是优化目标，是**报告量**；认证只看「未覆盖区上界 + 负载性账本」，且两者由独立代码路径计算。
4. **对创新本身 Goodhart** → 负载性定义要求留出见证集与风险界**独立复算**；平凡层不计分；复杂度的 Pareto 代价显式记录（引理 36、定理 30）。
5. **特权泄漏** → 部署镜像物理断开神谕通道，泄漏审计（MI/金丝雀）不通过即整份 J_FORGE 作废。
6. **模拟差异 d̂ 被投毒** → d̂ 的实机锚点用**密封集 SEAL-Real** 离线评估，在线只看通过位；差异模型用分位数回归取 99.9% 分位。
7. **元层复杂到没人能审** → 强制**声明最小化**：J_FORGE 必须把 (Π,R,F,κ,d̂) 压成人类可读的一页；不可读即视为不可认证。

> - **阈值全是手设的**：τ_ece_intent、τ_Hc、τ_slip、B_reflex_total、λ_floor、WCET 余量、|N_REG|≤20 都是「研究者先验 + 有限测试」，没有一条由数据训练或证伪而来；
> - **校准用错了目标**：R72 用 ECE 作为意图/情感 veto，但 ECE 可在尾部系统性低估时仍接近 0——**安全死尾部，而 ECE 看不见尾部**；
> - **没有「仿真训练」协议**：仿真是唯一能拿到不确定度真值并大规模注入故障的地方，但朴素训练会让审计器**过拟合模拟器的误差模型**，证书变成自我实现的预言；
> - **没有「创新点挖掘」方法**：R72 的六层是人想出来的，缺乏「发现假设违反者 → 编译成新不变式」的可复现过程，也没有防止**对创新本身 Goodhart** 的机制。
>
> 本轮补齐一个**元层**（不改对象层控制行为，只训练/证伪/审计对象层的阈值与假设）：
> - **STG**：异构模拟器族 + 特权神谕（s\*,z\*,c\*,接触真值,真实 WCET）+ 压力算子库；
> - **PUL**：用特权标签训练不确定度，蒸馏到可部署估计器，并做**特权泄漏审计**；
> - **OCR**：把安全风险计的训练目标从「对称校准 ECE」改为**单侧/条件覆盖 + 尾部 CVaR**；
> - **RTP**：红队策略最大化「已认证但实际不安全」（CBU），认证对**策略类**取上确界；
> - **FME**：在压力空间做质量-多样性搜索，产出**1-最小见证**，拒绝在训练模拟器上过拟合出的伪见证；
> - **I2C + 负载性账本**：见证编译成不变式/层，只有**移除它会严格抬高留出见证上的认证风险界**的层才算创新点；
> - **ACB + SDB**：覆盖度 κ 必须带**未覆盖区 Lipschitz 上界**；模拟差异 d̂ 必须带**置信半径**，否则禁止把仿真保证迁移到实机。
>
> 核心命题：**从「我的证书在测试集上成立吗」进化为「我的证书的成立边界，是否已被对抗性仿真训练与证伪挖掘主动搜索过，并留下可审计的覆盖账本？」** ——**审计训练闭环**。
>
> IP 编号：IP-295~304（共 10 个）+ GAUGE-RAS 组件的元层 † 化。理论姿态延续：**新层是旧层的严格元层泛化，安全侧只增不减，退化时退回 R72 手设阈值。**

## 2. 形式化定义（要点版）

**定义 366（FORGE 总览与六不变式）** 见想法区。核心：特权隔离、单侧覆盖优先、模拟器族留出、红队不可认证、反例可编译且负载、声明式保证。

**定义 367（STG）** 异构模拟器族 Π_train/Π_heldout；特权神谕 G 只在训练与评估可用；压力算子库 F；可部署观测 O。**部署镜像物理断开 G 通道。**

**定义 368（PUL 与泄漏审计）** 特权标签监督 + 蒸馏；单侧保守损失 `softplus(u*−û)²`；泄漏审计 `I(o;G|û) ≤ ε_leak` 且删通道后性能不塌。任一越界 ⇒ 风险计不可认证。

**定义 369（OCR）** 上预测界 `I_m(o)=[0,U_m(o)]`；要求组条件单侧覆盖 `C_cond ≥ 1−α` 且尾部风险 `R_α ≤ ε_tail`。**ECE 不作安全风险计的训练目标**（引理 33）。

**定义 370（RTP 与不可认证性）** 红队最大化 CBU；认证集 `S_cert(ε;R_budget) = {(π,ctx): sup CBU ≤ ε}`；R_budget 越大 S_cert 越小（引理 35）；红队必须覆盖可达策略类，不能只攻击部署策略（定理 28）。

**定义 371（FME 与质量-多样性档案）** 压力空间 Σ 上最大化 `violation + η·novelty − ζ·|f-composition|`；档案 𝒜 按失效原型分格存 1-最小见证；在 Π_heldout 上验证，拒绝伪见证。

**定义 372（I2C 与负载性账本）** 见证→约束映射（RTA/意图/接触/反作用/差异五类）；层 ℓ 负载 ⇔ ∃留出见证 w: `risk_bound(GAUGE\ℓ,w) − risk_bound(GAUGE∪ℓ,w) ≥ Δ_min`。**创新产出 = 负载数/挖出数**；禁止以挖出数量为目标。

**定义 373（ACB 与未知-未知预算）** `R_total ≤ R_cov + (1−κ)·L_R·diam(𝒜\𝒜_cov)`；认证须 `κ ≥ κ_min` 且未覆盖上界 ≤ ε_unk。**覆盖不全不能当作安全。**

**定义 374（SDB 与迁移界）** 留出族差异 `d̂` + `ρ`；`R_real ≤ R_π + d̂ + ρ`，且 `d̂+ρ ≤ ε_cert` 才允许迁移；Π_train 内估计的 d̂ 加共适应惩罚。

**定义 375（两时间尺度非共谋）** `min_φ max_ψ [L_cert + λ·CoAdapt]`；红队每 K 步、认证器每步更新；部署策略对认证器 stop-gradient；`CoAdapt > ε_co ⇒ 证书作废`。

**定义 376（有限停止与非平稳重开）** 负载收益 ≤ 成本且覆盖增益 ≤ ε_κ 时停止；Π_heldout 或 R_budget 变化 ⇒ 旧 κ 失效、挖掘重开。

**定义 377（J_FORGE）** Valid ⇔ J_EMB 有效 ∧ 特权隔离通过 ∧ 每指标 C_cond ≥ 1−α ∧ d̂+ρ ≤ ε_cert ∧ sup CBU ≤ ε_cbu ∧ κ ≥ κ_min ∧ 未知-未知预算达标 ∧ 声明哈希匹配。

**定义 378（威胁模型 AIC-FORGE）** ℰ_FORGE = ℰ_EMB × ℰ_sim × ℰ_red × ℰ_mine × ℰ_meta：模拟器后门/保真度虚标/留出泄漏、红队奖励黑客/共谋/账本投毒、算子库不全致假覆盖/最小见证不可复现/平凡层刷负载、声明被篡改包装成绝对保证。

```python
# IP-295 STG：仿真训练场 + 特权神谕（训练期专用，部署期物理不可达）
@dataclass
class Privileged:
    s_star: State; z_star: Intent; c_star: ContactMode
    contact_force: Array; t_slip: float; wcet_true: float

class SimTrainingGround:
    def __init__(self, sim_family, stress_ops, obs_model, curriculum):
        self.Pi = sim_family                 # 已切分 Pi_train / Pi_heldout
        self.F, self.O, self.cur = stress_ops, obs_model, curriculum
    def rollout(self, pi_id, stress_seq):
        scen = self.sample_scene(pi_id)
        for f in stress_seq: scen = self.F[f](scen)
        traj, priv = self.Pi[pi_id].run(scen)      # priv = 特权神谕
        return self.O(traj), priv                    # 可部署观测 / 特权标签

# IP-296 PUL：特权不确定性学习 + 泄漏审计
class PrivilegedUncertaintyLearner:
    def fit(self, dataset):                 # dataset: (obs, u_star) from G
        loss = lambda u_hat, u_star: softplus(u_star - u_hat) ** 2   # 单侧：罚低估
        return train(self.net, dataset, loss)
    def audit_leakage(self, obs, priv):
        mi = mutual_info_estimate(obs, priv, self.net)
        canary = canary_probe(self.net, priv)
        return mi <= EPS_LEAK and not canary.collapses

# IP-297 OCR：单侧覆盖风险计（Mondrian conformal）
class OneSidedCoverageMeter:
    def calibrate(self, calib_set):         # (o, u_true, group) 来自 Pi_heldout
        self.q = {}
        for g in calib_set.groups:
            resid = [u_true - self.upper_raw(o) for o,u_true,gg in calib_set if gg==g]
            self.q[g] = quantile(resid, 1 - ALPHA)     # 组条件单侧上界
    def upper(self, o):
        return self.upper_raw(o) + self.q[self.stratum(o)]
    def report(self):
        return coverage(self, groups='mondrian'), tail_risk(self)   # C_cond, R_alpha

# IP-298 RTP：红队策略（最大化 CBU）
class RedTeamPolicy:
    def objective(self, certified, unsafe, severity):
        return (certified * unsafe * severity).mean()
    def step(self, env, budget):
        adv = self.optimize(self.objective, env, max_cost=budget)
        return adv, self.sup_cbu(adv)        # 取上确界，不取平均

# IP-299 FME：证伪挖掘（质量-多样性 + 1-最小见证）
class FalsificationMiningEngine:
    def __init__(self, archive, stress_ops, sim_train, sim_heldout):
        self.A, self.F = archive, stress_ops
    def mine(self, invariant_suite, budget):
        found = []
        while budget.remaining():
            w = self.sample_stress(self.F, seed_diverse=True)
            if not self.F.valid_on(w, self.sim_heldout):   # 拒伪见证
                continue
            if invariant_suite.violation(w) <= 0: continue
            w = self.minimize_1minimal(w, invariant_suite)  # delta-debugging
            if self.A.add(w): found.append(w)
        return found
    def minimize_1minimal(self, w, inv):
        for f in reversed(w.stress_seq):
            w2 = w.without(f)
            if inv.violation(w2) > 0: w = w2               # 删掉仍违反 => 更小
        return w

# IP-300 I2C：不变式→约束编译 + 负载性检验
class InvariantToConstraintCompiler:
    MAP = {'rta_miss':'tighten_delta_or_wcet_bound',
           'intent_overconfident':'tighten_tau_ece_or_iota',
           'contact_underestimate':'add_component_or_raise_prior',
           'reflex_breach':'tighten_B_or_joint_upper',
           'sdb_exceed':'enlarge_heldout_family'}
    def compile(self, witness):
        return refine_invariants(self.MAP[witness.kind], witness)
    def is_load_bearing(self, layer, heldout_witnesses, g_guard):
        delta = max(risk_bound(g_guard, w) - risk_bound(add(g_guard, layer), w)
                    for w in heldout_witnesses)
        return delta >= DELTA_MIN

# IP-301 ACB：覆盖度 + 未覆盖区 Lipschitz 上界
def assumption_coverage(archive, assumption_space):
    cov = union_of_touched(archive, assumption_space)
    kappa = measure(cov) / measure(assumption_space)
    unk = (1 - kappa) * L_R * diameter(assumption_space - cov)
    return kappa, unk            # 认证须 kappa>=K_MIN and unk<=EPS_UNK

# IP-302 SDB：模拟差异预算 + 迁移界
def sim_discrepancy(pi, heldout_witnesses, real_anchors):
    d = max(abs(risk_real(w) - risk_pi(pi, w))
            for w in heldout_witnesses if w in real_anchors)
    d_hat = quantile_regression(d, q=0.99)
    rho = conformal_radius(real_anchors)
    return d_hat, rho            # 须 d_hat+rho <= EPS_CERT

# IP-303 FORGE 主循环：两时间尺度对抗训练 + 挖掘 + 编译
def FORGE_round(STG, C, R, FME, I2C, budget):
    obs, priv = STG.sample_batch(Pi='train')
    C.update_risk_meters(PUL.fit(obs, priv), OCR.calibrate(obs, priv))
    assert C.pul.audit_leakage(obs, priv)
    adv, sup_cbu = R.step(STG.env(Pi='heldout'), R_budget=budget.red)
    witnesses = FME.mine(C.invariants, budget.mine)
    for w in witnesses:
        layer = I2C.compile(w)
        if I2C.is_load_bearing(layer, heldout_witnesses, C.invariants):
            C.invariants = add(C.invariants, layer)
            C.ledger.record(layer, w, delta=...)
    kappa, unk = assumption_coverage(FME.A, C.assumption_space)
    d_hat, rho = sim_discrepancy(Pi='heldout', heldout_witnesses, C.real_anchors)
    if sup_cbu > EPS_CBU or kappa < K_MIN or unk > EPS_UNK or d_hat+rho > EPS_CERT:
        return J_FORGE(C, valid=False, reason=...)
    return J_FORGE(C, valid=True, declaration=(STG.Pi, budget.red, FME.F, kappa))

# IP-304 FORGE 部署主闭环（元层只训练/审计，不直接控制）
def FORGE_DEPLOY_round(M, obs, audio, tac_frame):
    k, lam, j_emb = EMBODIED_GAUGE_RAS_round(M, obs, audio, tac_frame)  # R72 对象层
    if not M.j_forge.valid or M.meta.mode != 'FORGE':
        M.thresholds = M.r72_defaults          # 元层失效 ⇒ 退回手设阈值
    elif M.coverage_monitor.c_cond() < 1 - ALPHA:
        M.meta.mode = 'DEGRADED'; M.thresholds = M.r72_defaults
    return k, lam, j_emb, M.j_forge.shape()
```

## 4. 推导

**引理 33（ECE ⇏ 尾部安全）** 存在风险计族使 ECE → 0 而高险层覆盖 → 0。系：R72 用 ECE 当 veto 不完备；安全指标须用单侧/条件覆盖与尾部 CVaR。**（对应 IP-297）**

**引理 34（特权泄漏 ⇒ 部署端系统低估）** 若 `I(o;G|û) > ε_leak`，则存在依赖 G 的 û 在部署分布上 `E[u*−û] > 0`，λ 被低估。系：「仿真里很准」可能是泄漏，不是可部署校准。**（对应 IP-296）**

**引理 35（R_budget ⇒ 认证集单调收缩）** `R_budget' ⊇ R_budget ⇒ S_cert(ε;R_budget') ⊆ S_cert(ε;R_budget)`。系：不声明红队预算的「安全率」不可比。**（对应 IP-298）**

**引理 36（负载创新 ⇒ 风险严格下降但复杂度可升）** 负载层使留出见证风险界下降 ≥Δ_min；但新增参数抬高审计成本与 WCET 余量 ⇒ 创新点落在 (风险界, 复杂度) Pareto 前沿。**（对应 IP-300）**

**引理 37（覆盖不足 ⇒ 风险界不可收缩）** 只要 `(1−κ)·L_R·diam > ε_unk`，就存在未覆盖假设上的最坏执行使 `R_total > ε_unk`。系：「挖到很多反例」≠「余下安全」。**（对应 IP-301）**

**引理 38（差异预算 ⇒ 迁移证书有效）** 若 `d̂+ρ ≤ ε_cert` 且 d̂ 在 Π_heldout 上估计，则 `R_real ≤ R_π + ε_cert`（置信 1−δ）。系：无实机锚点的「仿真安全率」不能迁移。**（对应 IP-302）**

**引理 39（两时间尺度 ⇒ 非共谋局部稳定）** 红队每 K 步、认证器每步更新且部署策略对认证器 stop-gradient，则部署策略一阶条件不含「欺骗认证器」方向，CoAdapt 局部不增。系：共谋可用训练协议结构性避免。**（对应 IP-303）**

**定理 27（FORGE 是 R72 的严格元层泛化）** 取 F=∅、κ=1、R_budget=0、Π_heldout=Π_train、d̂=0，则 J_FORGE ≡ J_EMB，主循环退化为 R72 手设阈值，**不引入任何新控制行为**。安全侧只增不减。

**定理 28（红队鲁棒证书 ⇒ 部署安全，条件于策略类）** 若 `sup CBU ≤ ε_cbu` 且 π_deploy ∈ Π_reach 被红队覆盖，则 `P(certified ∧ unsafe) ≤ ε_cbu + ε_gap(Π_reach, R_budget)`。系：安全性 = 红队覆盖面 × 认证器鲁棒性。

**定理 29（无一揽子保证，存在不可挖失效）** 对任意有限 Π、F、R_budget，存在真实失效 w† 不可表达/不可达，故不存在绝对安全证书；J_FORGE 只能是**相对证书** `Safe | (Π,R,F,κ,d̂)`。**证明**：有限族 ∪ 有限算子 ≠ 真实世界全体（表达力/对角线论证）。系：**把 R72 的「自信地错」显式降级为「已知边界的相对保证」——这是本轮最重要的诚实性结论。**

**定理 30（负载性计数 ⇒ 对创新 Goodhart 免疫）** 若创新点只按负载性计数、且风险界在留出见证集上独立评估，则任何最大化负载创新数的策略都无法用平凡层降低认证风险界；优化负载数不会恶化留出安全界，最多付出复杂度代价（引理 36）。**证明**：非负载层对留出见证的风险界差 <Δ_min，删除它不改变认证。

## 7. 本轮最大风险

**一句话**：FORGE-GAUGE-RAS 把 R72 的「自信地错自己的可执行性」换成了更隐蔽的「**自信地错自己的表达力**」——它用仿真训练出审计器、用红队挖出反例、用覆盖账本宣称「已搜索」，但**「没挖到反例」永远不等于「没有反例」**：如果模拟器族 Π 表达不了某种真实物理（未建模的接触磨损、DDS 中断风暴、跨文化意图），压力算子库 F 里没有对应算子，红队预算 R 又只在 Π 的壳内搜索，那么 FME 会在「可表达世界的全集」里勤勤恳恳地挖，覆盖账本 κ 逼近 1，J_FORGE 带着「单侧覆盖达标、差异预算达标、红队上确界达标」的完整签名盖章放行，而真实失效恰好从那个**谁都没建模的维度**穿过——事后审计会显示「所有挖到的反例都已编译、所有覆盖都达标、所有声明都匹配」，这就是**元层面的「在错误的假设空间里证明了正确性」**，比 R72 的「自信地错」更难被发现，因为这次连「证伪过程」本身都成了信任对象。

次级风险与缓解：
1. **模拟器族表达力不足** → 跨引擎异构族（MuJoCo/Isaac/自研刚柔耦合）+ 真实锚点最小集；Π 未覆盖失效强制标为 known-unknown，禁止计入 κ。
2. **红队壳内共谋** → 红队跨 Π_heldout 训练，并保留一支不参与训练的黑箱红队做最终检验。
3. **κ 被 Goodhart** → κ 只报告不优化；认证只看「未覆盖区上界 + 负载账本」，两者由独立代码路径计算。
4. **对创新本身 Goodhart** → 负载性要求留出见证与风险界独立复算；平凡层不计分；复杂度 Pareto 代价显式记录（引理 36、定理 30）。
5. **特权泄漏** → 部署镜像物理断开神谕通道；MI/金丝雀不通过即整份 J_FORGE 作废。
6. **d̂ 被投毒** → 实机锚点走密封集 SEAL-Real；差异模型取 99.9% 分位。
7. **元层复杂到没人能审** → J_FORGE 必须把 (Π,R,F,κ,d̂) 压成人类可读一页；不可读即视为不可认证。
