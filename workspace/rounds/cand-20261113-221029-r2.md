# 第 69 轮（承接第 68 轮「CALM-RAS 标定感知风险自适应闭环」IP-243~252；灵感循环新循环第 2 轮；本轮灵感：「预训练」×「场景理解」）

> 第 68 轮把「标定」升级为在线潜变量 c_t，用自监督与单模型多任务把「测量是否可信」纳入闭环，却自陈了一个结构性风险：**标定能力越强，缓变故障越隐形**。根因不是某个阈值没调好，而是**计量闭环是自我确认的（self-confirming）**：标定器 COF、归因器 CFA、伪标签生成器 SSG 全部在同一个自适应回路里共同漂移，没有任何**独立于该回路**的参照来裁决「这条缓变残差到底是漂移还是故障」。三者可以串通出一个自洽却错误的世界故事，而没有任何一方有动机拆穿它。
>
> 本轮两个灵感恰好补上这块缺失的「独立参照」：**预训练**的独特价值不是权重初始化，而是**在部署前见过带特权标签（已知标定、已知故障）、跨场景的数据**——把它冻结，就得到一个在线回路永远无法同化的外部观测者；**场景理解**给出语义接地，把「透明物体、软体形变、镜面反光本来就该产生的残差」先解释掉，使剩下的残差才进入漂移/故障判别。
>
> 核心命题：**用一个冻结的场景语义先验作独立参照，把残差分解为「场景应有的 / 标定漂移 / 真实故障」三分量，再让预训练的漂移/故障流形判别器充当不可收买的第二意见——PRISM-RAS（Pretrained Reference for Independent Scene Metrology：预训练参考系 · 独立场景计量）。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**判定我测量准不准的那个判据，本身可信吗**」——给自我确认的计量闭环装上一个不可被它同化的「异见者」。

## 0. 直觉与动机

**灵感 1（预训练 → 从「权重初始化」到「不可篡改的参考系」）**
直觉：R68 把预训练当作 CALM-RAS 的暖启动（定义 290：离线自监督预训练 trunk），这是把预训练的价值用窄了。预训练真正不可替代之处在于它**在部署前见过带特权的、跨场景的、含已知标定与已知故障的数据**——在线回路永远拿不到这种特权信息，因为它只有一条无法回放的现实轨迹。若把预训练产物冻结成一个只读观测器，它就拥有在线自适应模型永远不可能拥有的东西：**独立性**。自我确认的克星不是更强的模型，而是一个**不会和你说同一套谎话**的模型。因此本轮「预训练」不是初始化，而是**宪法（constitution）**：它定义「什么叫漂移、什么叫故障、什么场景本来会产生什么残差」，允许在线系统引用，却不允许它修改。

**灵感 2（场景理解 → 残差并不等价，先让语义解释掉「本该如此」的部分）**
直觉：R68 的残差五元组把所有跨模态不一致一视同仁。但工程上大量「不一致」是场景物理本来就决定的：透明物体让深度失效、软体让力-位移滞后、镜面让视觉噪声暴涨、遮挡让视觉-触觉几何短暂错位。把这些**场景可解释残差**和**真异常残差**混在一起，等于给慢变故障提供了一片天然的噪声海。场景理解（scene graph：刚性/反光/形变/透明/材质/光照）给出残差的条件先验 r̄_scene(G_t) 与 Σ_scene(G_t)：先减掉「本该如此」，剩下的 r_⊥ 才值得归因。这就是「棱镜」——一道复合残差被语义分解成谱线，故障那条谱线不再淹没在场景噪声里。

**灵感 3（预训练 × 场景理解 → 反事实解耦，学到三个可分离的因子）**
直觉：要判别「漂移 vs 故障」，光有场景先验不够，还得知道两者各自「长什么样」。若预训练数据显式包含同一场景下的已知标定变化与已知故障注入，就能用**反事实交换**训练解耦表征：交换两段同场景数据的标定状态 → 标定因子必须按已知变换改变而场景因子不动；交换场景 → 场景因子变、标定因子不动；注入故障 → 只有故障因子变。由此得到因子化世界先验 z = (z_scene, z_cal, z_fault, z_res) 和两条冻结参考流形 M_cal、M_fault。在线只需问：这条慢变残差轨迹离哪条流形更近？这是独立于在线自适应的第二意见。

**灵感 4（三灵感合流 → PRISM-RAS 六组件）**
1. **FSP Frozen Scene-Semantic Prior**：冻结的场景解析 + 残差条件先验（r̄_scene, Σ_scene）+ 场景新颖度 ν + 冻结的漂移/故障参考流形；
2. **SRD Semantic Residual Decomposition**：r = r_scene(G) + r_cal(c) + r_fault + ε，场景项由冻结先验**预测**而非在线拟合——这是反自我确认的关键；
3. **PMD Pretrained Manifold Discriminator**：在 M_cal / M_fault 上对慢变残差做独立判别，提供标定带宽之外的证据；
4. **SCN Scene-Novelty Gate**：分布外场景 → 关闭语义解释、只收紧不放宽；
5. **SCC Scene-Conditioned Counterfactual Canary**：用冻结故障流形在**当前场景**上生成开放式金丝雀，补 R68 固定金标集的覆盖漏洞；
6. **FAA Frozen-Anchor Auditing + CALM-RAS†**：参考系独立性不变式与证书化；MTM/SSG/COF/CFA/CAC/RAS-WM 全部继承，只是观测输入改为语义去偏残差 r_⊥，CAC 增为六关。

**灵感 5（对 R68 风险的对症下药）**
- R68 最大风险「慢变故障被标定吸收」：PMD 在标定带宽**之外**给出独立判别（引理 16），SCC 补金标覆盖（引理 18）；
- R68「CAC 金标集未覆盖该故障模式」：金丝雀从固定集升级为**场景条件生成式**，覆盖随采样数指数上升；
- R68「标定吸收故障」与「伪标签自毒」：残差先经语义去偏再进 COF，伪标签不再来自会自洽漂移的单一回路；
- R68 遗留「标定红线悖论」：FSP 把物理先验（刚性、形变、透明度）写进冻结参照，红线参数不再只依赖出厂计量；
- 新增风险「场景误解把真故障解释掉」：SCN 门控 + 横截性假设 A95 + 解释量几何上界（引理 17），并规定语义解释**只在分布内且高置信**时生效。

## 1. 形式化定义（增量：定义 293–308）

**定义 293（PRISM-RAS 总览）** PRISM-RAS = (FSP, SRD, PMD, SCN, SCC, FAA, CALM-RAS†)。四条不变式：
(i) **参考系独立性**：FSP 参数 θ_F 在线零更新、零梯度（∂L_online/∂θ_F ≡ 0），版本哈希 h_F 钉入证书；在线回路只能**引用**判据，不能**修改**判据；
(ii) **语义解释单向保守**：场景语义仅在 ν_t ≤ τ_scene 且关键属性置信时被允许解释残差；分布外一律 r_scene := 0；
(iii) **三分残差横截**：r_scene、r_cal、r_fault 所在子空间两两横截（A95），语义解释量受几何上界约束（引理 17）；
(iv) 继承 CALM-RAS 三不变式（实时流零学习写、标定安全红线、标定速率受限）。

**定义 294（冻结场景语义先验 FSP）** FSP = (Φ_parse, Φ_sig)，输出
G_t = Φ_parse(obs_t) = (objects, α)，α = (rigidity, reflectance, deformability, transparency, material, lighting)；
r̄_scene(G_t) = E_F[r | G_t]，Σ_scene(G_t) = Cov_F[r | G_t]，ν_t = 场景新颖度（定义 297）；
以及两条冻结参考流形 M_cal、M_fault（由 D_pre 中特权标签构造，定义 296）。
离线训练集 D_pre 含**特权监督**（已知 c、已知故障注入、跨场景、跨本体），在线冻结。FSP 是「宪法」，不是「另一份在线权重」；distill 出的轻量 scene_head 只用于实时特征，不改写 FSP 判据。

**定义 295（语义残差分解 SRD）** 对 R68 的残差五元组 r_t：
r_t = r_scene(G_t) + r_cal(c_t) + r_fault + ε_t，
其中 r_scene := gate(ν_t)·r̄_scene(G_t)（**先验预测，非在线拟合**），gate = 1[ν_t ≤ τ_scene] ∧ 1[c_attr ≥ τ_attr]；
r_⊥ := r_t − r_scene；r_cal 由 COF 在 r_⊥ 上估计（R68 COF 的观测从 r_t 换成 r_⊥）；r_fault := (I − P_c) r_⊥，P_c 为标定子空间投影。
语义：**先让场景解释，再让标定解释，剩下的才归因故障**。r_scene 由冻结先验给定，故在线回路无法通过自适应放大「场景解释」来吞掉故障。

**定义 296（预训练流形判别器 PMD）** 冻结先验给出两条参考流形：M_cal（已知漂移轨迹集）、M_fault（已知故障轨迹集），均在 D_pre 上用特权标签构造，且带场景标签。对在线慢变残差窗口 R_{t−T:t}：
d_cal = dist_F(R, M_cal)，d_fault = dist_F(R, M_fault)，
p_fault^{PMD} = σ((d_cal − d_fault)/τ_m)，其中 dist_F 为冻结表征中的 k-近邻/马氏距离。
这是 R68 标定带宽**之外**的独立证据：**慢变不再等于可吸收**。场景条件版本 dist_F(·|G_t) 用于排除场景诱导的相似性。

**定义 297（场景新颖度与语义门控 SCN）** ν_t = Mahalanobis(z_scene(G_t); D_pre)（或密度比 log p_pre/(p_pre+p_alt)）。语义门控：
gate_t = 1[ν_t ≤ τ_scene] ∧ 1[min_i c_attr,i ≥ τ_attr]；U_scene := max(0, ν_t − τ_scene)。
ν_t > τ_scene ⇒ r_scene := 0（禁止解释）、λ_floor 抬升、所有阈值只收紧。另设**方差膨胀上限**：若 λ_max(Σ_scene) > Σ_cap，则禁用解释（防「场景多样」成为万能挡箭牌）。

**定义 298（反事实解耦预训练 CDP）** z = (z_scene, z_cal, z_fault, z_res)。预训练目标：
L_pre = L_rec + λ_s L_scene_sup + λ_c L_swap^cal + λ_f L_swap^fault + λ_i L_inv + λ_d L_dis，
其中 swap 指从同场景、不同标定/不同故障的两段数据交换对应因子标签，要求：
swap c ⇒ z_cal 按已知变换变化且 z_scene 不变；swap G ⇒ z_scene 变且 z_cal 不变；inject fault ⇒ 仅 z_fault 变。
L_dis 为因子间互信息下界（CLUB/Fisher），配合因子维数约束保证可辨识性（A96）。

**定义 299（场景条件反事实金丝雀 SCC）** 给定当前 G_t 与 ĉ_t，FSP 从 M_fault 条件采样 N_c 条慢变故障轨迹：
r_canary^{(i)} = r̄_scene(G_t) + r_cal(ĉ_t) + r_fault^{(i)}，r_fault^{(i)} ~ M_fault(·|G_t)。
候选适配器 M_θ′ 上线前，若其标定头把 r_canary 的故障分量「修」进 r_cal（吸收比 ρ_abs = ‖Δr_cal‖/‖r_fault^{(i)}‖ > 0.5），一票否决。金丝雀从固定集升级为**开放式、场景条件生成式**：故障模式由冻结流形在当前场景实例化，而非人工枚举。

**定义 300（参考系独立性审计 FAA 与证书）** J_PRISM = (J_CALM, h_F, ν_t, (E_s,E_c,E_f), (d_cal,d_fault), G_hash, scene_conf, prism_ver)，
其中 (E_s,E_c,E_f) 为三分量能量占比。Valid ⇔ Valid(J_CALM) ∧ h_F 匹配 ∧ [ν_t ≤ τ_scene ∨ 保守标志] ∧ ‖ε‖ ≤ ε_max ∧ SCC 通过。
FAA 审计：在线日志中不存在对 θ_F 的写；FSP 训练分布与部署分布的场景重叠率须在允许区间，否则视为**弱独立**并整体降级为 R68 保守模式。

**定义 301（风险一致性扩展）** 在 R68 的 λ_floor 上加入场景与判别不一致：
λ_floor = max(0.6, 0.8·1[U_cal > τ_cal ∨ ν_t > τ_scene ∨ |d_cal − d_fault| < τ_amb])，
其中 τ_amb 为判别模糊带。**允许的放宽**仅当：ν ≤ τ_scene ∧ ‖ε‖ 小 ∧ p_fault^{PMD} < τ_p ∧ SCC 通过，且放宽后 λ 不低于 R68 基线。即「棱镜」能给出**有原则的放宽**，但永不低于旧基线；场景语义只能解释噪声，不能解释掉安全余量。

**定义 302（场景语义的特征注入）** 实时 scene_head 输出 G_t 的紧凑嵌入，注入 MTM 的 ctx 与 VQAuditor-S 的审计上下文；FSP 全模型异步运行（≈1–2 Hz），其输出缓存供 SRD/PMD/SCC 使用。语义特征只进「解释」与「审计」通路，不改写故障先验的硬约束。

**定义 303（管线）** 离线：D_pre（含特权标定/故障/场景标签）上反事实解耦预训练 FSP → 冻结并哈希 → 蒸馏 scene_head → 构造 M_cal/M_fault → 校准 τ_scene、τ_amb、τ_m。在线：CALM-RAS† 循环内残差先经 SRD 去场景偏，再 COF/CFA；PMD/SCN/SCC 作为只读观测器并行；CAC 升级为六关（R68 五关 + SCC）。

**定义 304（VQAuditor-S）** 升级 R68 的 VQAuditor-C：审计对象增加「语义解释是否合理」——对每个被 r_scene 解释掉的残差，追问「该场景属性是否真的蕴涵此残差？」；审计结论回灌 AuditBuf 并作为 FSP 漂移的早期告警（若解释频繁被推翻，说明 D_pre 支持集跟不上部署）。

**定义 305（AIC-PRISM 干扰集）** ℰ_PRISM = ℰ_CALM × ℰ_scene × ℰ_pre × ℰ_ref；ℰ_scene = {场景误解析、OOD 场景、语义幻觉}；ℰ_pre = {预训练-部署偏移、特权标签泄漏、解耦失败}；ℰ_ref = {弱独立、参照被篡改、哈希失配}。

**定义 306（同源 vs 异源的双重检验）** R68 的同源一致性（引理 15）用于「快变漂移」的高灵敏检出；PMD 的异源流形判别用于「慢变故障」的独立复核。二者一快一慢、一同源一异源，构成正交证据：同源提灵敏，异源反自证。

**定义 307（解释预算）** 每 T_explain 窗口内，语义解释累计能量占比 ≤ β_sem（如 0.4）。超预算即冻结解释并告警——防止「长期、缓慢地把故障解释成场景」这种**慢速解释漂移**（R68 慢变故障的新变种）。

**定义 308（J_PRISM 的不可上诉性声明）** 证书显式记录独立参照版本与置信边界；当 FAA 判定弱独立或 SCN 报 OOD，证书降级为「条件有效」，系统只能执行保守分支。**独立性是授权使用语义解释的必要条件，不是充分条件。**

## 2. 关键算法骨架

```python
# IP-253 FSP：冻结场景语义先验（只读，无梯度）
class FrozenScenePrior:
    def __init__(self, ckpt_hash):
        self.theta = load_frozen(ckpt_hash)
        self.h_F = ckpt_hash
        self.M_cal, self.M_fault = None, None          # 离线构造的参考流形

    @torch.no_grad()
    def observe(self, obs):
        G = self.parse_scene(obs)                       # scene graph + attrs α
        r_mean, r_cov = self.residual_prior(G)          # r̄_scene, Σ_scene
        nu = self.novelty(G)                            # 场景新颖度
        return G, r_mean, r_cov, nu


# IP-254/256 SRD + SCN：先语义去偏，再交给标定
def semantic_residual_decomposition(r, G, r_mean, r_cov, nu, attr_conf):
    gate = (nu <= TAU_SCENE) and (min(attr_conf) >= TAU_ATTR) \
           and (max_eig(r_cov) <= SIGMA_CAP)            # 方差膨胀上限
    r_scene = r_mean if gate else zeros_like(r)         # 先验预测，非在线拟合
    r_perp  = r - r_scene                               # 待归因残差 r_⊥
    return r_perp, r_scene, gate


# IP-255 PMD：冻结流形上的独立判别
class ManifoldDiscriminator:
    def score(self, window_R, G):
        d_cal   = self.dist(window_R, self.M_cal, cond=G)
        d_fault = self.dist(window_R, self.M_fault, cond=G)
        p_fault = sigmoid((d_cal - d_fault) / self.tau_m)
        return p_fault, d_cal, d_fault


# IP-257 SCC：场景条件反事实金丝雀
class SceneCounterfactualCanary:
    def generate(self, G, c_hat, fsp, n_c=32):
        return [fsp.r_mean(G) + cal_model(c_hat) + fsp.sample_fault(G)
                for _ in range(n_c)]

    def veto(self, shadow, canaries):
        return any(shadow.cal_head.absorption_ratio(rf) > 0.5 for rf in canaries)


# IP-262 PRISM 主闭环：在 R68 上插入只读观测器，不改实时写路径
def PRISM_round(M, obs):
    G, r_mean, r_cov, nu = M.fsp.observe(obs)                    # 冻结先验
    x_prime = M.lsf.fuse(M.usr.fuse(*obs[:4]))
    z, o = M.mtm.forward(obs_pack, M.a_prev, ctx=scene_ctx(G))   # R68 MTM
    r = residuals(x_prime, o, M.wm_residual_cache)

    r_perp, r_scene, gate = semantic_residual_decomposition(     # 1) 语义去偏
        r, G, r_mean, r_cov, nu, attr_conf(G))
    c, U, thr = M.cof.step(o['cal'], r_perp, sigma_stat(M))      # 2) 标定（观测 r_⊥）
    p_pmd, d_cal, d_fault = M.pmd.score(                          # 3) 独立判别
        M.residual_window(r_perp), G)

    rho = M.fir_signature(z, M.residual_log)
    joint = M.cfa(r_perp, o['pi'], c, U, p_pmd)                   # 4) 先标定后归因 + PMD

    A = M.ach.propose(x_prime, H=M.vista.H)
    wm_preds = M.mtm.rollout(z, M.ach.propose_actions(x_prime, 5))
    k = M.c_ras_wm.certified_prefix(A, joint, min(M.vista.m, M.m_emo),
                                    M.alpha_chunk, wm_preds)
    if U > TAU_CAL or nu > TAU_SCENE: k = min(k, k_cal_shrink(A, U, nu))

    lam = M.efs.risk_scale(joint)
    lam = max(lam, thr['lam_floor'],                              # 5) 只收紧的纪律
              0.8 if (U > TAU_CAL or nu > TAU_SCENE
                      or abs(d_cal - d_fault) < TAU_AMB) else 0.6)
    if gate and p_pmd < TAU_P and M.scc.passed:
        lam = max(lam, LAMBDA_BASELINE)                           # 有原则的放宽，不破基线

    tau = emotion_response_shaping_wm(
        M.pi_sigma.prefix_dispatch(A[:k]) * lam, joint, wm_preds)
    M.vqa_s.submit_async(wm_preds, {'G': G, 'nu': nu, 'explain': (r_scene, gate)})
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit,
                       canaries=M.scc.generate(G, c, M.fsp))      # 6) 六关 + 生成式金丝雀
    return k, lam, joint, (c, U, nu, p_pmd)
```

## 3. 推导

**引理 16（独立参照的反自证界）** 设 A = COF 把慢变故障吸收为漂移，q = P(A | fault) 为 R68 的吸收率。PRISM 增加 PMD 事件 F（判为故障）。由参考系独立性（θ_F 冻结、D_pre 与在线自适应独立）与 h_F 钉死，F 在给定真实成因下与在线自适应条件独立；且 PMD 只**抬高**故障先验、从不压低。故吸收需 A ∧ ¬F：
P(absorb | fault) ≤ q·(1 − s_PMD)，
其中 s_PMD = P(F | fault) 对 fault ∈ supp(M_fault) 成立。取 s_PMD ≥ 0.9 ⇒ 慢变故障误吸收 ≤ 0.1·q——**在完全不动 R68 标定带宽的前提下，误吸收降一个数量级**。

**引理 17（语义误解释的几何上界）** 由横截性 A95，故障流形的切空间与场景可解释子空间的最大主角 θ_max 有界。r_scene 被约束落在场景子空间内（冻结先验预测 + 方差膨胀上限），故其对故障方向的投影满足 ‖P_s r_f‖² ≤ sin²θ_max·‖r_f‖²。因此被语义解释掉的故障能量占比 ≤ gate·sin²θ_max。取 θ_max ≤ 20° ⇒ ≤ 11.7%；且当 ν > τ_scene 时 gate = 0，解释量为零。关键：**该上界不随在线自适应增长**，因为 r̄_scene 是冻结的、不是拟合出来的——这与 R68 中「可被 COF 逐步放大的标定解释」形成本质区别。

**引理 18（生成式金丝雀覆盖）** 设某慢变故障模式落在 M_fault 的支持集内，其邻域 B_η 的采样测度为 μ(B_η)。SCC 从 M_fault(·|G_t) 独立采样 N_c 条金丝雀，则该模式**完全未被覆盖**的概率 ≤ (1 − μ(B_η))^{N_c} ≤ exp(−N_c·μ(B_η))。因此 R68 的固定金标集覆盖漏洞，被指数级采样覆盖所替代，剩余风险仅为「故障模式落在 supp(M_fault) 之外」：P(uncovered) ≤ P(fault ∉ supp M_fault) + exp(−N_c μ)。取 N_c = 32 且 μ 适中时第二项可忽略。

**定理 16（PRISM-RAS 端到端风险一致性）** 在 A87–A96 下，继承定理 14 全部结论并加强：
1. P(慢变故障被误判为漂移) ≤ (1 − s_PMD)(1 − r_SCC)·q_CALM + sin²θ_max·gate + P(fault ∉ supp M_fault)；
2. ν_t > τ_scene ⇒ r_scene := 0 ∧ λ_floor 抬升 ∧ k 收缩——**场景不确定也永远只导向收紧**；
3. 语义解释仅在分布内、方差有界、属性高置信、PMD 不反对、SCC 通过时才可能使 λ 触及基线，且**永不低于 R68 基线**；
4. 预训练-部署偏移使 s_PMD 下降时，FAA 的场景重叠率审计触发整体降级为 R68 保守模式（有界退化，而非静默失效）。

**定理 17（参考系独立性 ⇒ 自证概率乘积界）** 若 FSP 冻结且其 D_pre 与在线自适应机制独立，则自证事件 S = {COF 吸收 ∧ PMD 未报} 的概率满足 P(S) ≤ q(1−s_PMD)；而若参照系也在线共适应（如允许 FSP 微调），两者误差相关，最坏退化到 P(S) ≈ min(q, 1−s_ref) ≈ q。故**独立性把「取小」变成「取乘」**：这正是冻结作为安全机制的理论依据，而非工程保守主义。

## 6. 本轮最大风险

**一句话**：PRISM-RAS 把安全性押在「冻结的场景/故障先验在部署环境依然正确」上——一旦部署场景或故障模式落在 D_pre 支持集之外，这个**不可在线修改**的参照系就会变成**不可上诉的错误法官**：它要么把真实故障当作「场景本该有的残差」解释掉（语义幻觉），要么把正常漂移永久判为故障；而恰恰是它的独立性（禁止在线学习）使任何在线证据都无法纠正它——**独立性既是让自证闭环失效的解药，也是让参照系错误无法被申诉的枷锁**。

**次级风险与缓解**：
1. **场景误解析**：分割/属性错误导致 r_scene 吞掉故障 → SCN 属性置信门控 + 解释预算（定义 307）+ VQAuditor-S 复核 + E297 对抗测试；
2. **预训练-部署偏移**：FSP 场景重叠率低 → FAA 弱独立判定 + 整体降级 R68 保守模式 + 证书标「条件有效」；
3. **解耦失败**：因子不可辨识使 SRD/PMD 失真 → A96 可辨识性假设 + swap 不变性测试（E293）+ 失败即禁用语义解释；
4. **生成式金丝雀失真**：M_fault 采样的故障不真实 → 流形一致性校验 + 人工审计抽样 + 与真实注入混合；
5. **计算与内存**：FSP 全模型 1.2GB → 冻结 + INT8 + 异步低帧率 + 蒸馏头实时化 + 边缘端按需加载；
6. **参照系篡改/哈希失配**：h_F 钉入证书 + 只读挂载 + 启动期完整性校验，失配即拒绝使用语义解释。

```python
class FrozenScenePrior:
    def __init__(self, ckpt_hash):
        self.theta = load_frozen(ckpt_hash); self.h_F = ckpt_hash
        self.M_cal, self.M_fault = load_manifolds(ckpt_hash)
    @torch.no_grad()
    def observe(self, obs):

# IP-254/256 SRD + SCN
def semantic_residual_decomposition(r, G, r_mean, r_cov, nu, attr_conf):
    gate = (nu <= TAU_SCENE) and (min(attr_conf) >= TAU_ATTR) \
           and (max_eig(r_cov) <= SIGMA_CAP)
    r_scene = r_mean if gate else zeros_like(r)      # 先验预测，非拟合
    return r - r_scene, r_scene, gate                # r_⊥, r_scene, gate

    def score(self, window_R, G):

        d_fault = self.dist(window_R, self.M_fault, cond=G)
        return sigmoid((d_cal - d_fault)/self.tau_m), d_cal, d_fault

                for _ in range(n_c)]
    def veto(self, shadow, canaries):
        return any(shadow.cal_head.absorption_ratio(rf) > 0.5 for rf in canaries)

    r_perp, r_scene, gate = semantic_residual_decomposition(
        r, G, r_mean, r_cov, nu, attr_conf(G))                   # 语义去偏
    c, U, thr = M.cof.step(o['cal'], r_perp, sigma_stat(M))      # 标定观测 r_⊥
    p_pmd, d_cal, d_fault = M.pmd.score(M.residual_window(r_perp), G)
    joint = M.cfa(r_perp, o['pi'], c, U, p_pmd)                  # 独立第二意见
    k = M.c_ras_wm.certified_prefix(A, joint, m_ras, M.alpha_chunk, wm_preds)
    if U > TAU_CAL or nu > TAU_SCENE: k = min(k, k_cal_shrink(A, U, nu))
    lam = max(M.efs.risk_scale(joint), thr['lam_floor'],
              0.8 if (U > TAU_CAL or nu > TAU_SCENE
                      or abs(d_cal-d_fault) < TAU_AMB) else 0.6)
    if gate and p_pmd < TAU_P and M.scc.passed: lam = max(lam, LAMBDA_BASELINE)
    M.vqa_s.submit_async(wm_preds, {'G': G, 'nu': nu, 'explain': (r_scene, gate)})
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit,
                       canaries=M.scc.generate(G, c, M.fsp))
    return k, lam, joint, (c, U, nu, p_pmd)
```

## 4. 推导

**引理 16（反自证界）** 参考系独立 ⇒ PMD 与在线自适应条件独立，且只抬高故障先验；慢故障吸收 ≤ q·(1−s_PMD)。s_PMD ≥ 0.9 ⇒ 误吸收 ≤ 0.1·q（相对 CALM-RAS 降一个数量级），且不改动标定带宽。

**引理 17（语义误解释几何上界）** 横截性 A95 + 冻结预测 ⇒ 被语义解释掉的故障能量 ≤ gate·sin²θ_max。θ_max=20° ⇒ ≤ 11.7%；OOD 时 gate=0。该上界**不随在线自适应增长**（r̄_scene 冻结），与 R68 可被逐步放大的标定解释形成本质区别。

**引理 18（生成式金丝雀覆盖）** N_c 条场景条件采样完全漏掉故障模式邻域 B_η 的概率 ≤ exp(−N_c·μ(B_η))；剩余风险为故障落在 supp(M_fault) 之外。固定金标漏洞被指数级覆盖替代。

**定理 16（端到端风险一致性）** 慢故障误判 ≤ (1−s_PMD)(1−r_SCC)q + sin²θ_max·gate + P(fault∉supp M_fault)；场景不确定只收紧；语义放宽永不低于 R68 基线；预训练偏移触发 FAA 整体降级（有界退化）。

**定理 17（独立性 ⇒ 自证乘积界）** 冻结且独立 ⇒ 自证事件概率 ≤ q(1−s_PMD)（乘积）；若允许参照共同适应则退化为 ≈ q（取小）。独立性把「取小」变成「取乘」，是冻结作为安全机制的理论依据。

## 7. 本轮最大风险

**一句话**：PRISM-RAS 把安全性押在「冻结的场景/故障先验在部署环境依然正确」上——一旦部署场景或故障模式落在 D_pre 支持集之外，这个**不可在线修改**的参照系就会成为**不可上诉的错误法官**：它要么把真实故障当作「场景本该有的残差」解释掉（语义幻觉），要么把正常漂移永久判为故障；而恰恰是它的独立性（禁止在线学习）使任何在线证据都无法纠正它——**独立性既是让自证闭环失效的解药，也是让参照系错误无法被申诉的枷锁**。

**次级风险与缓解**：场景误解析（SCN 属性门控 + 解释预算 + VQAuditor-S + E297）；预训练-部署偏移（FAA 场景重叠率 + 整体降级 R68 保守模式 + 证书标条件有效）；解耦失败（A96 + swap 测试，失败即禁用解释）；金丝雀失真（流形一致性校验 + 人工抽样 + 混合真实注入）；计算内存（冻结 INT8 + 异步低帧率 + 蒸馏头实时化 + 边缘按需加载）；参照篡改（h_F 钉入证书 + 只读挂载 + 启动完整性校验，失配即拒绝解释）。
