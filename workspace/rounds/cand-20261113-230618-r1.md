# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「机器人竞赛」×「机器人基础模型」）

> R69 问出「我该向谁求证」，把不确定性拆成 aleatoric 与 epistemic，用流匹配多模态策略给出歧义的形状，再用看/问/触主动消解。但它有一组从未被审视的前提：世界是**非策略性的**（会诚实回答，至少不会反过来利用你的提问），交互是**私密的**（问一次只花自己的预算），目标是**求真**（把任务做对），先验是**我独有的**（别人拿不到我的策略）。
>
> 「机器人竞赛」一次性打破这四个前提：对手会**适应并针对你**，公共信道让每一次注视、每一次提问都成为**情报**，记分牌是**序数排名**而不是真值，而且你没有第二次机会。「机器人基础模型」则打破第五个隐含前提：所有参赛者可能共享同一个基础策略——它既是能力来源，也是一个**公开、可被所有人训练针对的共同弱点**。
>
> 核心命题：**竞赛不是「更难的单项任务」，而是一个博弈。R69 的两分不确定性必须升级为四分：aleatoric（噪声）、epistemic-world（可问清的世界歧义）、strategic（对手类型，不能靠问，只能靠对冲）、rule（合法性，必须靠规则证书）。交互的价值也不再恒为正——在对抗与公开信道下，信息会泄露、会反噬；因此把 R69 的 VoI 换成可正可负的博弈 VoI（NVoI），把「选最确定的模态」换成「在安全/合法/不可利用/不泄露的硬约束内选最优混合策略」。**
>
> 命名 **RIVAL-RAS**（Rival-aware Interactive Value-of-information under Adversarial Leakage）。一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**对手是谁、他在怎么利用我，而我这句提问又暴露了什么**」——在竞赛里，不确定性不只是刹车和提问，还是**底牌**。

## 0. 直觉与动机

**灵感 1（机器人竞赛 → 对手是「会回应你的不确定性」）**
直觉：在单机任务里，不确定性是一个被动的事实，你测它、问它、或者绕开它。但竞赛里的不确定性是**活的**：你不知道对手下一步，而对手也在猜你；你越不确定、越犹豫、越频繁试探，对手越容易读出你的策略。更关键的是，对手的「类型」（稳健型 / 激进型 / 欺骗型 / 专克某一招）**无法通过提问消除**——你问他，他只会给你对他有利的答案。R69 的 epistemic 是「世界欠你一个答案」；竞赛里的 strategic 是「对手不欠你任何东西，还在利用你找答案的动作」。因此这部分不确定性不能被「消解」，只能被**对冲**（hedge）：用混合策略把最坏情况的价值抬起来，而不是把某个后验熵降下去。

**灵感 2（机器人基础模型 → 共享先验 = 共同知识 = 公共弱点）**
直觉：机器人基础模型（RFM）让每个参赛队都站在同一个强先验上：同样的技能词表、同样的抓放先验、同样的语言接口、同样的失败模式。这在单队看来是能力，在联赛看来是**单一栽培（monoculture）**：所有人共享的强先验，就是所有人都能预训练针对的公共目标。一个只会在 RFM 均值行为上打补丁的策略，看起来很强，但对「专门研究过这个基础模型」的对手是**高可利用（exploitable）**的。因此本轮必须把「能力」与「不可利用性」分开：RFM 负责提出候选技能与风格（support / prior），**不负责签最终策略**；最终策略是在安全合法集合上做**降低可利用性的混合投影**。

**灵感 3（交互是双刃剑 → 在竞赛里，「问」是一个公开动作，是一个 tell）**
直觉：R69 把注视/探针/问句当成「只花自己预算」的信息动作。但竞赛有观众、有直播、有对手的传感器：你停下来盯着某个物体看三秒，等于告诉对手「这里有我不确定的东西」；你问裁判一个规则问题，等于暴露你准备打擦边球；你反复试同一个动作，等于交出你的策略族。于是**信息价值不再单调**：一个能降低你对世界熵的探询，可能同时把你自己的一部分策略熵送给对手。R69 的 `VoI ≥ 0` 在博弈里是错的；正确的量是**净信息价值 NVoI = 世界信息增益 − 泄露代价 − 成本**，它可以为负。负值时，正确动作是**不问**——哪怕问了能让你更「确定」。

**灵感 4（规则 → 物理安全之外的第二个硬约束，且「合法」不等于「合规精神」）**
直觉：竞赛把「安全」扩展成三层：不伤人（物理）、不犯规（规则）、不被取消资格（解释权）。RFM 从人类演示里学到的行为可能**合法但违反规则精神**：钻空子、利用裁判盲区、把「成功」定义成规则没写禁止的样子。这类行为短期得分、长期被改规则或判罚，是典型的**奖励黑客**。因此规则必须被形式化为可验证的证书（谓词/时序逻辑），并保留一个**规则边界裕度**：不贴着边界开车。规则有歧义时，裁判是**有成本、可能有偏的 oracle**，不是免费真值；对规则的 epistemic 要用「询问裁判 + 裕度」处理，而不是用对手模型猜。

**灵感 5（目标 → 竞赛优化的是序数排名，不是标量真值）**
直觉：R69 优化「任务成功/误差」。竞赛的收益是**排名**：你不需要比真值更准，你只需要比场上其他人好；领先时该收，落后时该搏。期望分数最大 ≠ 夺冠概率最大：在四强决赛里，同样的均值、更大的方差可能显著提高夺冠率（本轮预实验：均值同为 1.0，σ=1.4 的波动型夺冠率 0.320，σ=0.6 的稳健型只有 0.248）。所以 R70 的目标必须是**排名感知（rank-aware）且随当前名次调整风险胃口**的，但**安全/合法/不可利用/不泄露仍是硬约束**，不得被「搏一把」买走。

**灵感 6（与 R69 的关系 → 只加对抗外层，内环安全不让步）**
直觉：RIVAL 不重写 R69 的流匹配策略、aleatoric/epistemic 二分、看/问/触与流似然第二意见；它把 R69 的「合作世界假设」替换为「策略性世界假设」，并在其外加一层**博弈外环**：对手类型建模、联赛、混合策略投影、规则证书。关键工程姿态：**重计算全部发生在 episode 之间/回合之间，绝不进入 2.6ms 实时内环**；内环只保留廉价的对手类型分类、泄露监视、合法性与安全证书。若没有公共信道（泄露=0）、对手非适应（U_strat=0）、规则平凡、联赛单点，则 RIVAL 逐指令退化为 FLUID；FLUID 再按自身边界退化为 R68。得到严格退化链 `R68 ⊂ FLUID-RAS ⊂ RIVAL-RAS`：新层只在「能证明对手存在且信息会泄露」时才打开。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（RIVAL-RAS 总览）** `RIVAL-RAS = (TBM, GVD, ILG, NEP, FMX, RBC, LGE, AED, RAO, VQAuditor-A, RAS-WM‡)`。五不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **安全与合法性双硬约束**：物理安全（RAS-WM）与规则合法（RBC）都不可被分数/排名加权交易；
(iii) **不可利用性下限**：所选策略对联赛最优回应的可利用性 `Expl(σ) ≤ ε_expl`（只在安全合法集合内定义）；
(iv) **信息纪律**：不执行净信息价值 `NVoI ≤ 0` 的交互；公开泄露不超过预算 `B_leak`；单源/单信任域证据不得定案（继承并强化 R69 定义 293-iii）；
(v) **单调退化**：无公共信道、对手非适应、规则平凡、联赛单点时，逐指令退化为 FLUID-RAS（定义 326）。

**定义 311（竞赛模型）** 部分可观测随机博弈 `𝒢 = (𝒮, 𝒜, 𝒜^o, 𝒪, P, r, R, γ)`。我方动作 `a ∈ 𝒜`，对手动作 `a^o ∈ 𝒜^o`，联合观测 `o = (o_self, o_pub)`，其中 `o_pub` 为**双方都能观测的公共信道**。状态转移 `P(s'|s,a,a^o)`，收益 `r(s,a,a^o)`。规则 `R = {φ_j}` 为可判定的谓词或时序逻辑公式，合法性 `Legal(s,a,s') = ∧_j φ_j(s,a,s')`。竞赛通常为有限回合、淘汰制、序数排名。

**定义 312（对手类型与 TBM）** 对手类型 `θ^o ∈ Θ^o` 编码其策略族、能力、欺骗倾向、风险胃口与对 RFM 的依赖程度。维护信念 `b_t(θ^o)`，由公共观测做贝叶斯更新：`b_{t+1} ∝ b_t · p(o_pub,t | θ^o, a_t)`。类型集 `Θ^o` 必须显式包含一个 **novel / out-of-league** 的万能类型（防联赛过拟合，定义 319）。

**定义 313（四元不确定性分解）** 在 R69 的 `(U_ale, U_epi)` 之外新增两项，语义不同、通道不同：
- `U_ale`：传感器/执行噪声，不可约（→ R68 的 λ floor）；
- `U_epi^w`：关于世界、可由感知或合作式交互消除的歧义（→ R69 的 MINT）；
- `U_strat = max_{θ,θ' ∈ supp b} |V^*(b; θ) − V^*(b; θ')|`：对手类型导致博弈价值可能摆动的幅度（**可约但不靠问**，靠比赛/探索与对冲）；
- `U_rule = P(¬Legal | o)` 或规则归属后验熵：动作是否合法/合精神的不确定性（**靠规则证书与裁判询问**处理）。
四项不做简单加和：`U_ale` 进安全缩放；`U_epi^w` 进 NVoI 交互门；`U_strat` 进混合投影 NEP；`U_rule` 进合法性证书与规则裕度。

**定义 314（博弈信息价值 GVD 与净信息价值 NVoI）** 设 `V^*(b)` 为给定信念下博弈的**安全价值（max-min 或 ε-Nash 值）**。信息动作 `g` 的博弈信息价值
`VoI_G(g) = E_{y~p(·|g)}[V^*(b_{g,y})] − V^*(b)`，
它**可以为负**（引理 19）。公开泄露
`Lk(g) = I(A_priv ; o_pub(g))`，其中 `A_priv` 为我方未来混合策略/私有类型。净信息价值
`NVoI(g) = VoI_G(g) − κ·Lk(g) − c(g)`。
仅当 `NVoI(g) > 0` 且泄露预算 `B_leak` 未超、且 `g` 通过安全与合法性证书时才执行；否则不交互，退化为 R69 的保守/直接执行。

**定义 315（信息泄露治理 ILG）** 把每个动作的「公开可观测面」显式建模：`o_pub = h_pub(s, a, g) + ε_pub`。维护泄露账本 `B_leak(t) = Σ_τ I(A_priv,τ ; o_pub,τ)`，并定义**策略指纹** `FP = p(o_pub | σ)`：若对手能以高于阈值 `τ_fp` 的准确率从公开观测反推我方混合策略，则判定「策略已暴露」，强制切换风格/提高混合熵或执行反情报动作（假动作，但必须安全合法）。注意：假动作也是动作，同样受安全/合法/预算约束。

**定义 316（不可利用策略投影 NEP）** 给定 RFM 先验 `π_θ`、安全合法策略集 `Π_safe = {π : 物理安全 ∧ Legal}`，求混合策略
`σ* = argmax_{σ ∈ Δ(Π_safe)} E_{π~σ}[U(π)] − η·D(σ)`，
`s.t. Expl(σ) = max_{π^o} E[U(π^o, σ)] − E[U(σ, σ)] ≤ ε_expl`，`D(σ)` 为熵/风格多样性正则。
RFM 只提供 support 与先验，不直接成为 `σ*`。`η` 与 `ε_expl` 是**风险胃口**的函数（定义 321）：领先时调低 `ε_expl`/提高稳健性，落后时允许更高方差但**永不放松安全与合法性**。

**定义 317（基础模型可利用性审计 FMX）** 因为所有队可能共享同一 RFM，定义共同先验下的「单一栽培风险」
`FMX = E_{π^o ∈ League}[Expl_{π^o}(π_RFM)]`，
并用留出风格集评估 RFM 的**可预测性**（对手能否从行为反推技能调用序列）。`FMX > τ_fmx` ⇒ 禁止直接使用 RFM 的确定性众数行为，必须经 NEP 混合与风格多样化。另设**能力门**：RFM 提出的技能若偏离其训练支撑（OOD / 幻觉技能），不得进入 `Π_safe`，除非有独立技能证书。

**定义 318（规则证书 RBC）** 规则形式化为 `R = {φ_j}`（安全时序逻辑 / 谓词）。合法性证书 `Cert_R(a) = (Legal, margin, rule_id, referee_query?)`，其中
`margin = min_j dist(s,a,s'; ∂φ_j)` 为到规则边界的距离；要求 `margin ≥ m_rule`（不贴边）。规则歧义 `U_rule > τ_rule` 时可向**裁判 oracle** 询问（有成本 `c_ref`，答案可能有偏 `b_ref`），询问结果按证据纪律（定义 320）并入。区分 **违规（illegal）** 与 **取消资格风险（disqualification risk）**：合法但违反规则精神的动作，只有在 `margin ≥ m_spirit` 且审计通过时才允许。

**定义 319（联赛泛化 LGE）** 对手分布不是单点而是联赛 `ℒ = {π^o_1, …, π^o_M}`，并通过 PSRO / 虚拟博弈持续扩充：`ℒ ← ℒ ∪ {BR(σ*)}`。定义联赛遗憾 `Reg_ℒ(σ) = max_{π^o ∈ ℒ} E[U(π^o, σ)] − E[U(σ, σ)]`。类型先验 `b_0` 在联赛上做**分层抽样**并保留至少一个**留出对手族**；`Reg_ℒ` 与留出族表现的系统性背离即为过拟合信号（与 R69 的 FMA 对偶通道同构）。

**定义 320（对抗证据纪律 AED）** R69 的「k 个正交源一致」在对手可共谋时不成立。把证据源按**信任域**划分：同一对手控制的两个通道只算一个源。设 `n` 个信任域、至多 `f` 个被对手控制，采用拜占庭多数：`n ≥ 3f+1` 且需按源置信度加权。形式化：当 `n ≥ 3f+1` 且诚实源正确时，多数决议正确（引理 21）；但诚实源有噪声时，必须用**置信加权多数**而非硬多数，否则噪声可压过拜占庭容错（预实验中 q=0.85、f=2 时硬多数反而劣于 k=2，正是此教训）。裁判/规则 oracle 计入独立信任域，但不得作为唯一源。

**定义 321（排名感知目标 RAO）** 竞赛收益为序数：`U_rank = 1[rank(σ) = 1]` 或 `P(top-k)`。策略选择不优化期望分数，而优化
`max_{σ ∈ Π_safe} E[U_rank(σ)]`，s.t. `Expl(σ) ≤ ε_expl(standing)`；`ε_expl` 与混合熵随当前名次 `standing` 调整：落后→允许更高方差（搏），领先→降低方差（守），但安全/合法/泄露约束不随名次变化。

**定义 322（竞赛安全包络 CSE）** 可行集
`Π_feas = {π : 物理安全 ≥ S_floor ∧ Legal(margin ≥ m_rule) ∧ Expl(π) ≤ ε_expl ∧ B_leak ≤ B_leak,max ∧ 能力门通过}`。
任何不在 `Π_feas` 的候选，无论夺冠概率多高，一律不可选。`Π_feas` 是四条硬约束的交，不是加权和。

**定义 323（参与式审计 VQAuditor-A）** 审计新增：对手模型是否过拟合联赛（留出族表现）、泄露账本是否如实、规则裕度是否被侵蚀、是否把 RFM 的可预测众数行为直接当策略、是否用「落后该搏」为借口放松安全。结论回灌 AuditBuf，成为下一轮 `ε_expl`、`m_rule`、`B_leak` 的先验。

**定义 324（威胁模型 AIC-RIVAL）** `ℰ_RIVAL = ℰ_FLUID × ℰ_opp × ℰ_league × ℰ_rule × ℰ_leak`：
- `ℰ_opp`：自适应对手、欺骗性示弱/示强、诱骗式提问、针对我方交互模式的 baiting；
- `ℰ_league`：联赛投毒、只针对某一风格的过拟合对手、隐藏王牌；
- `ℰ_rule`：规则歧义、裁判偏差、利用漏洞被秋后算账、规则版本切换；
- `ℰ_leak`：从公开动作反推策略（行为指纹）、从探询反推不确定点、旁路观测。

**定义 325（证书 J_RIVAL）** `J_RIVAL = (J_FLUID, expl_est, ε_expl, leak_used, B_leak,max, rule_margin_min, rule_hash, opp_ece, league_regret, fmx, rank_objective, rival_ver)`。Valid ⇔ `Valid(J_FLUID) ∧ Expl ≤ ε_expl ∧ leak_used ≤ B_leak,max ∧ rule_margin_min ≥ m_rule ∧ opp_ece ≤ τ_ece^o ∧ 能力门通过`。

**定义 326（单调退化与严格包含）** 当 `o_pub ≡ ∅`（无公共信道，`Lk≡0`）、`U_strat = 0`（对手非适应或单机）、规则平凡（`Legal ≡ true`）、联赛单点（`ℒ = {π^o_0}`）时，`NVoI = VoI`、`NEP` 退化为恒等、`RBC` 恒真、`RAO` 退化为 R69 的期望成功，故 RIVAL 的选择与 FLUID **逐指令相同**；再叠加 R69 自身的退化条件即得 R68。链 `R68 ⊂ FLUID-RAS ⊂ RIVAL-RAS` 在安全侧恒不弱化。

# IP-264 TBM：对手类型信念（在线只做廉价分类，离线拟合类型集）
def update_type_belief(b, o_pub, my_action, type_lib):
    lik = [type_lib[th].likelihood(o_pub, my_action) for th in type_lib]
    return normalize([b[i] * lik[i] for i in range(len(b))])

# IP-265/266 GVD+ILG：净信息价值 = 博弈增益 − κ·泄露 − 成本（可负）
def net_voi(g, b, sigma_priv, budget):
    if not c_ras_wm.certify_info(g, o_t) or not rbc.certify(g): return -inf
    if not budget.allow(g): return -inf
    voi_g = expected_security_value(b, g) - security_value(b)
    leak  = mutual_info(sigma_priv, public_surface(g))
    return voi_g - KAPPA * leak - cost(g)

def choose_interaction(cands, b, sigma_priv, budget):
    scored = [(g, net_voi(g, b, sigma_priv, budget)) for g in cands]
    g, s = max(scored, key=lambda z: z[1])
    return g if s > 0 else None          # 负 NVoI 时“不问”才是最优

# IP-267 NEP：在安全合法集上求低可利用混合（离线/回合间求解）
def non_exploitable_projection(rfm_prior, Pi_safe, eps_expl, eta, standing):
    support = rfm_prior.top_k(styles=True)          # RFM 只给 support
    sigma = fictitious_play_or_lp(support, Pi_safe)
    while exploitability(sigma) > eps_expl:
        sigma = mix_with_best_response_shield(sigma, league)
    return entropy_regularize(sigma, eta * risk_appetite(standing))

# IP-268 FMX：共享先验的单一栽培审计
def foundation_exploitability(policy_rfm, league, heldout_styles):
    e_in  = mean(exploitability(policy_rfm, opp) for opp in league)
    e_out = mean(exploitability(policy_rfm, opp) for opp in heldout_styles)
    return e_in, e_out          # e_out 高 ⇒ 过拟合联赛 / 可预测众数行为

# IP-269 RBC：规则证书 + 边界裕度 + 裁判询问
def rule_certificate(a, s, rules, m_rule):
    legal = all(phi.eval(s, a) for phi in rules)
    margin = min(distance_to_boundary(s, a, phi) for phi in rules)
    return legal and margin >= m_rule, margin

# IP-270 LGE：联赛与留出对手族（外环，不进实时流）
def expand_league(sigma, league, heldout):
    br = best_response(sigma, league)
    return league + [br], evaluate(sigma, heldout)   # heldout 不参与选择

# IP-271 AED：信任域加权拜占庭证据
def byzantine_evidence(sources, n_domains, f_max):
    assert n_domains >= 3 * f_max + 1
    votes = [s.answer for s in dedup_by_trust_domain(sources)]
    return confidence_weighted_majority(votes)

# IP-272 RAO：排名感知，风险胃口随名次变，但硬约束不变
def rank_aware_select(cands, standing, Pi_feas):
    eps = eps_table[standing]            # 落后允许更高方差
    feasible = [c for c in cands if c in Pi_feas and exploitability(c.sigma) <= eps]
    return argmax(feasible, key=lambda c: P_win(c.sigma, field))

# IP-275 RIVAL 主闭环（R69 内环 + 竞赛外环）
def RIVAL_round(M, obs, match_ctx):
    # --- 外环（回合间已算好）：σ*、联赛、规则版本、ε_expl ---
    # --- 内环：只加廉价对抗层，重计算不进来 ---
    z, o = M.mtm.forward(...)
    c, U_cal, thr = M.cof.step(...)
    b = M.tbm.update(match_ctx.public_obs, M.last_action)
    U_ale, U_epi, modes, _ = M.fluid.decompose(...)     # R69
    a_hat = M.fma.flow_anomaly(...)                      # R69 第二意见

    legal, margin = M.rbc.certificate(M.candidate_a, o, M.rules, M.m_rule)
    if not legal or margin < M.m_rule:
        return M.rbc.safe_fallback(o)                    # 不拿分数换合法
    # 2) 交互：只有在净价值为正且泄露预算内才问
    g = (M.gvd.choose_interaction(M.info_candidates(modes), b, M.sigma_priv, M.budget)
         if (U_epi > TAU_EPI and not M.fluid.slow_fault_suspect) else None)
    if g is not None:
        U_epi = M.fluid.cia.update_belief(modes, M.cia.execute(g))
        M.ilg.charge(g)                                  # 记录泄露账本
    # 3) R69 的安全缩放照旧；strategic/rule 不改 λ 的语义

    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))

    # 4) 在等价安全前缀中按混合策略选风格（NEP 只在安全集内混合）

    # 5) 排名感知的风险胃口只作用于“同等安全”的候选
    if match_ctx.behind: tau = M.rao.rescale_within_safe_set(tau, U_floor)
    M.vqa_a.submit_async(g, b, margin, M.ilg.snapshot())
    return k, lam, style, (U_ale, U_epi), b

## 3. 推导

**引理 19（对抗与公开信道下信息价值可为负）** 在零和博弈中，向对手公开任何关于我方混合策略 `σ` 的信息都不会提高我方安全价值：对手信息集变大 ⇒ `min` 可取到更小 ⇒ `V(σ | 对手额外信息) ≤ V(σ)`。取 2×2 匹配 pennies，均衡值 0；若公开信号以概率 `p` 泄露我方实际动作，对手最优回应使我方每回合期望变为 `−(2p−1)`。而该信号若同时提供世界信息、其独立增益为 `Δ_w`，则 `NVoI = Δ_w − (2p−1)`，当 `p > (1+Δ_w)/2` 时为负。**系**：R69 的 `VoI ≥ 0` 只是「世界非策略且信道私密」的特例；竞赛中必须用 NVoI 门，且「感知/探询越多越好」是错的。

**引理 20（混合降低可利用性，代价有界）** 对有限安全合法策略集 `Π_safe`，若 RFM 原始确定性策略的可利用性为 `E_0`，NEP 在 `η→0` 时返回 `ε_expl`-近似均衡混合 `σ*`，则 `Expl(σ*) ≤ ε_expl`，且相对联赛的期望收益损失不超过 `η·(E_0 − ε_expl)_+ + O(1/√T)`（`T` 为虚拟博弈/PSRO 迭代数）。**系**：不可利用性是**买来的**——用一点联赛平均收益换掉被针对时的巨大损失。本轮预实验（`exp/rival_probe.py`）：6 风格零和博弈中，原始 RFM 众数风格对联赛均值收益 0.356 但可利用性 1.311；均衡混合把可利用性降到 0，代价是联赛均值收益降到 0.236（损失 0.120，约为原始联赛优势的 34%），混合熵 1.78/ln6。**这意味着「稳健」不是免费的，必须把代价写成显式预算，而不是假装没有。**

**引理 21（对抗证据的信任域界）** 设 `n` 个信任域、至多 `f` 个被对手控制、诚实源正确。若 `n ≥ 3f+1`，多数决议正确；R69 的「任取 k=2 一致」在两名被选者均为共谋者时即失败，其错误率至少 `C(f,2)/C(n,2)` 量级。**但噪声会吃掉这个保证**：当诚实源正确率 `q < 1` 时，硬多数可能被独立噪声压垮。预实验（`q=0.99`，`n=3f+1`）：`f=1/2/3` 时 k=2 一致错误率 0.49%/5.12%/6.89%，信任域加权多数为 0.03%/0.10%/0.01%；而在 `q=0.85, f=2` 时硬多数反而 16.8% 劣于 k=2 的 12.9%。**系**：拜占庭容错不是「加人」就够，必须同时满足 `n≥3f+1` 与**置信加权**；裁判也是一个信任域，不是唯一真值。

**引理 22（排名感知与期望分数的分离）** 在 `m` 人淘汰赛中，若策略收益分布均值相同、方差不同，则 `P(rank=1)` 一般不是均值的单调函数：更高方差可提高夺冠概率但降低期望排名稳定性/期望分数。预实验（4 人决赛，均值同为 1.0）：稳健型 `σ=0.6` 夺冠率 0.248，波动型 `σ=1.4` 夺冠率 0.320。**系**：R69 的「期望任务成功」在竞赛中是错误的效用；RAO 必须用序数效用并在安全集内调节风险胃口。注意这**不**授权为了夺冠放松安全/合法——`Π_feas` 是硬约束，方差调节只在 `Π_feas` 内进行。

**定理 18（RIVAL 严格包含 FLUID/R68）** 在定义 310 的不变式与定义 326 的边界条件下，RIVAL 在任意状态的物理安全与规则合法性不弱于 FLUID；且当无公共信道、对手非适应、规则平凡、联赛单点时，RIVAL 与 FLUID 逐指令相同；FLUID 再按 R69 定理 16 退化为 R68。因此 `R68 ⊂ FLUID-RAS ⊂ RIVAL-RAS`，新层不引入新的、需要独立信任的「安全让渡」。

**定理 19（竞赛安全与无突变）** 由于 (a) RBC 与 C-RAS-WM 在动作发出前做硬过滤，(b) NEP 只在 `Π_safe` 内混合，(c) RAO 只在同等安全候选间调方差，(d) 所有重计算（联赛、均衡、FMX）在回合间完成，内环只增加有界时间的类型分类/泄露记账/规则证书，故：物理安全包络不变、合法性保持、控制连续无突变；交互失败/超时/泄露超额时 `λ` 单调不降地退回 R69，再退回 R68。

## 6. 本轮最大风险

**一句话**：RIVAL-RAS 的全部对抗性收益都押在「**联赛与规则的形式化是正确的那场博弈**」这一前提上——如果真实对手在留出族之外（novel type）、或者规则存在未建模的解释/漏洞，那么所谓的 ε-不可利用只是「对这个模型不可利用」，系统会用一套在错误博弈里算出的均衡**自信地走进唯一没被建模的反制**；更糟的是，共享的机器人基础模型让所有队犯同一种可预测的错，于是「算错博弈」比「不算博弈」更危险——**这正是 R69「问错比不问更危险」在竞赛层的镜像：算错，比不算更危险。**

**次级风险与缓解**：
1. **联赛过拟合 / 留出族泄露**：LGE 强制留出族、FMX 审计单一栽培、VQAuditor-A 复核；E313 专测新对手。
2. **规则形式化错误 / 漏洞误用**：RBC 谓词化 + 边界裕度 `m_rule` + 裁判询问 + 规则版本哈希进证书；规则变更即失效重签。
3. **泄露账本低估**：ILG 只保证「对已建模公开面」的界；对策是提高混合熵、假动作（仍受安全合法约束）、以及把 `L_pub` 写成上界而非点估计。
4. **拜占庭噪声压过容错**：AED 要求 `n≥3f+1` **且**置信加权；预实验已给出 `q=0.85, f=2` 的失效反例，必须在证书里显式声明适用条件。
5. **NEP 计算昂贵 / 实时性**：全部放回合间；内环只采样已算好的 `σ*`，并用 `mode/type head` 廉价门控。
6. **把「落后该搏」当作放松安全的借口**：RAO 只在 `Π_feas` 内调方差，CSE（定义 322）四条硬约束不随名次变化，定理 19 兜底。

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** 实时流零学习写操作；物理安全与规则合法双硬约束；不可利用性下限 `Expl(σ) ≤ ε_expl`；不执行 `NVoI ≤ 0` 的交互且 `B_leak` 不超；`R68 ⊂ FLUID ⊂ RIVAL` 单调退化。

**定义 311–312（竞赛模型与 TBM）** POSG + 公共信道 + 规则 `R={φ_j}`；对手类型 `θ^o` 信念由公共观测贝叶斯更新，类型集必须包含 novel/out-of-league 类型以防联赛过拟合。

**定义 313（四元不确定性）** `U_ale` 进 R68 λ floor；`U_epi^w` 进 NVoI 交互门；`U_strat = max_{θ,θ'}|V^*(b;θ) − V^*(b;θ')|` 进 NEP 对冲；`U_rule` 进 RBC 证书与裕度。四项不简单加和。

**定义 314–315（GVD 与 ILG）** `VoI_G(g)=E[V^*(b_{g,y})]−V^*(b)` 可负；`NVoI=VoI_G−κ·I(A_priv;o_pub(g))−c(g)`，仅 `NVoI>0` 且泄露预算内才问。`B_leak(t)=Σ I(A_priv;o_pub)`，策略指纹 `p(o_pub|σ)` 超阈即强制多样化/反情报（反情报动作同样受安全合法约束）。

**定义 316–317（NEP 与 FMX）** `σ*=argmax E[U]−ηD(σ)` s.t. `Expl(σ)≤ε_expl`；RFM 只提供 support。`FMX=E_{π^o∈ℒ}[Expl_{π^o}(π_RFM)]`，超阈禁止直接用确定性众数行为；能力门挡 RFM 幻觉技能。

**定义 318（RBC）** `Cert_R(a)=(Legal, margin, rule_id, referee_query?)`，`margin=min_j dist(·,∂φ_j)`，要求 `margin≥m_rule`；合法但违反规则精神需 `margin≥m_spirit`；规则歧义问裁判（有成本、有偏），按 AED 并入。

**定义 319–320（LGE 与 AED）** 联赛 `ℒ` 用 PSRO/虚拟博弈扩充并保留留出族；`Reg_ℒ(σ)=max_{π^o∈ℒ}E[U(π^o,σ)]−E[U(σ,σ)]`。证据按信任域去重，`n≥3f+1` 且置信加权多数；裁判只算一个信任域。

**定义 321–322（RAO 与 CSE）** 优化序数 `E[U_rank]` 而非期望分数；风险胃口随 standing 变但只在 `Π_feas` 内。`Π_feas = 物理安全 ∧ Legal(margin≥m_rule) ∧ Expl≤ε_expl ∧ B_leak≤B_leak,max ∧ 能力门`，四条硬约束取交、不取加权和。

**定义 323–326（审计/威胁/证书/退化）** VQAuditor-A 审联赛过拟合、泄露、规则裕度、RFM 可预测性、以「搏」放松安全；`ℰ_RIVAL=ℰ_FLUID×ℰ_opp×ℰ_league×ℰ_rule×ℰ_leak`；`J_RIVAL` 并入可利用性/泄露/规则裕度/对手 ECE/联赛遗憾；无公共信道+非适应对手+平凡规则+单点联赛时逐指令退化为 FLUID。

# IP-264 TBM：对手类型信念（在线廉价，离线拟合）
def update_type_belief(b, o_pub, my_action, type_lib):
    lik = [type_lib[th].likelihood(o_pub, my_action) for th in type_lib]
    return normalize([b[i] * lik[i] for i in range(len(b))])

# IP-265/266 GVD+ILG：净信息价值（可负），负则不交互
def net_voi(g, b, sigma_priv, budget):
    if not c_ras_wm.certify_info(g, o_t) or not rbc.certify(g): return -inf
    if not budget.allow(g): return -inf
    voi_g = expected_security_value(b, g) - security_value(b)
    leak  = mutual_info(sigma_priv, public_surface(g))
    return voi_g - KAPPA * leak - cost(g)

def choose_interaction(cands, b, sigma_priv, budget):
    g, s = max(((g, net_voi(g, b, sigma_priv, budget)) for g in cands),
               key=lambda z: z[1])
    return g if s > 0 else None

# IP-267 NEP：安全合法集上的低可利用混合（回合间求解）
def non_exploitable_projection(rfm_prior, Pi_safe, eps_expl, eta, standing):
    support = rfm_prior.top_k(styles=True)            # RFM 只给 support
    sigma = fictitious_play_or_lp(support, Pi_safe)
    while exploitability(sigma) > eps_expl:
        sigma = mix_with_best_response_shield(sigma, league)
    return entropy_regularize(sigma, eta * risk_appetite(standing))

# IP-268 FMX：共享先验的单一栽培审计
def foundation_exploitability(policy_rfm, league, heldout):
    return (mean(exploitability(policy_rfm, o) for o in league),
            mean(exploitability(policy_rfm, o) for o in heldout))

# IP-269 RBC：规则证书 + 裕度 + 裁判
def rule_certificate(a, s, rules, m_rule):
    legal  = all(phi.eval(s, a) for phi in rules)
    margin = min(distance_to_boundary(s, a, phi) for phi in rules)
    return legal and margin >= m_rule, margin

# IP-271 AED：信任域去重 + 置信加权拜占庭多数
def byzantine_evidence(sources, n_domains, f_max):
    assert n_domains >= 3 * f_max + 1
    votes = [s.answer for s in dedup_by_trust_domain(sources)]
    return confidence_weighted_majority(votes)

# IP-272 RAO：排名感知；风险胃口随名次变，硬约束不变
def rank_aware_select(cands, standing, Pi_feas):
    eps = eps_table[standing]
    feasible = [c for c in cands if c in Pi_feas and exploitability(c.sigma) <= eps]
    return argmax(feasible, key=lambda c: P_win(c.sigma, field))

# IP-275 主闭环（R69 内环 + 竞赛外环）
def RIVAL_round(M, obs, match_ctx):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    b = M.tbm.update(match_ctx.public_obs, M.last_action)
    U_ale, U_epi, modes, _ = M.fluid.decompose(...)       # R69
    a_hat = M.fma.flow_anomaly(...)                        # R69 第二意见
    legal, margin = M.rbc.certificate(M.candidate_a, o, M.rules, M.m_rule)
    if not legal or margin < M.m_rule:
        return M.rbc.safe_fallback(o)                      # 不拿分数换合法
    g = (M.gvd.choose_interaction(M.info_candidates(modes), b, M.sigma_priv, M.budget)
         if (U_epi > TAU_EPI and not M.fluid.slow_fault_suspect) else None)
    if g is not None:
        U_epi = M.fluid.cia.update_belief(modes, M.cia.execute(g))
        M.ilg.charge(g)
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    style = M.nep.sample_style(M.sigma, o, standing=match_ctx.standing)
    tau = M.pi_sigma.prefix_dispatch(style.a[:k]) * lam
    if match_ctx.behind: tau = M.rao.rescale_within_safe_set(tau, U_floor)
    M.vqa_a.submit_async(g, b, margin, M.ilg.snapshot())
    return k, lam, style, (U_ale, U_epi), b

## 4. 推导

**引理 19（对抗/公开信道下信息价值可为负）** 零和博弈中公开关于我方混合策略的信息不提高安全价值；2×2 匹配 pennies 均衡值 0，若公开信号以概率 `p` 泄露我方动作，则期望变为 `−(2p−1)`。故 `NVoI = Δ_w − (2p−1)` 可为负。系：R69 的 `VoI≥0` 是非策略、私密信道的特例；竞赛中「多感知/多探询」不一定更好。

**引理 20（混合降可利用性，代价有界）** 有限 `Π_safe` 上，NEP 返回 `ε_expl`-近似均衡混合，`Expl(σ*)≤ε_expl`，相对联赛的期望收益损失有界（`η·(E_0−ε_expl)_+ + O(1/√T)`）。**预实验**（`exp/rival_probe.py`）：6 风格零和博弈，原始 RFM 众数风格联赛均值收益 0.356、可利用性 1.311；均衡混合可利用性 0、联赛均值收益 0.236（损失 0.120，约原始优势的 34%），混合熵 1.78/ln6。稳健不是免费的。

**引理 21（对抗证据信任域界）** `n` 信任域、`f` 被控、诚实源正确时，`n≥3f+1` 的多数决议正确；R69 任取 `k=2` 一致在两人皆共谋时失败。噪声会吃掉保证：预实验 `q=0.99, n=3f+1` 时 `f=1/2/3` 的 k=2 错误率 0.49%/5.12%/6.89%，加权多数 0.03%/0.10%/0.01%；而 `q=0.85,f=2` 时硬多数 16.8% 反劣于 k=2 的 12.9%。系：需 `n≥3f+1` **且**置信加权；裁判只是一个信任域。

**引理 22（排名与期望分数分离）** 均值相同、方差不同时 `P(rank=1)` 一般不随均值单调；4 人决赛预实验（均值均 1.0）稳健 `σ=0.6` 夺冠率 0.248，波动 `σ=1.4` 夺冠率 0.320。系：R69 的期望成功在竞赛中是错误效用；RAO 用序数效用，但只在 `Π_feas` 内调方差。

**定理 18（严格包含）** 在定义 310 不变式与 326 边界下，RIVAL 的物理安全与合法性不弱于 FLUID；无公共信道/非适应/平凡规则/单点联赛时逐指令相同；FLUID 再退化 R68。故 `R68 ⊂ FLUID ⊂ RIVAL`。

**定理 19（竞赛安全与无突变）** RBC+安全证书先于优化；NEP 只在 `Π_safe` 内混合；RAO 只在同等安全候选间调方差；重计算在回合间；内环只加有界时间薄层 ⇒ 安全包络不变、控制连续；交互失败/超时/泄露超额时 `λ` 单调不降退回 R69，再退回 R68。

## 7. 预实验（可复现，非正式实验）

代码 `exp/rival_probe.py`，结果 `exp/rival_probe_results.json`（`PYTHONPATH=.pylibs python exp/rival_probe.py`）。三个 sanity check 支撑三条引理：

1. **可利用性（引理 20）**：6 风格零和博弈，原始 RFM 众数风格可利用性 **1.311**、联赛均值收益 **0.356**；均衡混合可利用性 **0.000**、联赛均值收益 **0.236**、混合熵 **1.78/ln6**。稳健代价 ≈ 0.120（原始联赛优势的 34%），说明必须把稳健当预算显式记账。
2. **拜占庭证据（引理 21）**：诚实正确率 `q=0.99`、`n=3f+1` 时，`f=1/2/3` 的 R69 `k=2` 一致错误率为 **0.49% / 5.12% / 6.89%**，信任域加权多数为 **0.03% / 0.10% / 0.01%**；`q=0.85,f=2` 时硬多数 **16.8%** 反劣于 `k=2` 的 **12.9%** —— 拜占庭容错在噪声下不是免费的，必须 `n≥3f+1` 且置信加权。
3. **排名 vs 分数（引理 22）**：4 人决赛、均值同为 1.0，稳健型（σ=0.6）夺冠率 **0.248**，波动型（σ=1.4）夺冠率 **0.320**。期望分数最优 ≠ 夺冠概率最优，RAO 的序数效用有实证依据。

这些数字仅用于验证公式方向与失效边界，不替代 E301–E315 的正式实验。

## 8. 本轮最大风险

**一句话**：RIVAL-RAS 的全部对抗性收益都押在「**联赛与规则形式化是正确的那场博弈**」这一前提上——若真实对手在留出族之外（novel type）或规则存在未建模的解释/漏洞，所谓的 ε-不可利用只是「对这个模型不可利用」，系统会用一套在错误博弈里算出的均衡**自信地走进唯一没被建模的反制**；共享的机器人基础模型又让所有队犯同一种可预测的错，于是算错博弈比不算博弈更危险——**这是 R69「问错比不问更危险」在竞赛层的镜像：算错，比不算更危险。**

**次级风险与缓解**：联赛过拟合（LGE 留出族 + FMX + VQAuditor-A + E313）；规则形式化错误/漏洞（RBC 谓词化 + `m_rule`/`m_spirit` + 裁判询问 + 规则哈希）；泄露账本低估（ILG 用上界而非点估计 + 提高混合熵 + 安全合法的反情报动作）；拜占庭噪声压过容错（AED 同时要求 `n≥3f+1` 与置信加权，并在证书里声明适用条件）；NEP 计算昂贵（全部回合间，内环只采样 `σ*`）；以「落后该搏」放松安全（CSE 四条硬约束不随名次变化，定理 19 兜底）。
