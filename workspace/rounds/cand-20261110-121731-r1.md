# 第 44 轮（新循环第 4 轮） · Contact-Quality-Cert × Data-Quality-Cert：把「力觉真值」与「数据质量」提升为证书的根信任层（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形仅边际覆盖 + 多用户契约求交可空」。但它仍压着两个未言明的单点假设：**(H1) 传感器是可信神谕**——v20 的租约 ℓ=(m,τ,λ,κ) 只处理「陈旧」，不处理「新鲜但坏掉」：一次刚采到的读数可能已饱和、漂移、串扰或被驱动层伪造，时间新鲜 ≠ 数据可用；**(H2) 数据是干净且可交换的**——共形覆盖、检索式证书、蒸馏校准都默认标定集与 CKB 数据质量合格，而力/触觉数据恰恰有跨会话标定漂移、标签噪声、污染与跨本体失配。本轮灵感词「力觉传感」「数据质量」精确命中这两个假设：**力觉传感**是安全约束最终兑现的物理真值，也是质量最易在关键时刻崩坏的模态（碰撞瞬间、接近力上限时饱和、温漂）；**数据质量**是所有证书的元性质——它决定任何 margin、任何覆盖保证是否还成立。二者耦合处是本轮真正的新问题：**质量不能自证**（质量估计器本身可能被欺骗），于是「谁给数据质量证书背书」变成一个根信任递归。

## 0. 直觉与动机

**灵感 1（力觉传感 → 接触是最后真值，也是质量最脆弱处）**：安全最终要用牛顿来兑现。直觉上我们会把 F/T 传感器当作「真值」，但真实 F/T 是非理想的：标定漂移、迟滞、串扰、饱和、带宽有限。更糟的是一个结构性事实——**质量-负载负相关**：安全最吃紧的区域（大力、接近上限、碰撞）恰好是传感器最不靠谱的区域（饱和、非线性、高动态）。因此「点估计 + 加性噪声」的证书不可靠；必须用**集合隶属**：给定读数 y 与质量 q，真值落在 [y−u₋(q), y+u₊(q)]，只有整个区间都在力上限之下才允许签发接触证书。好消息是接触可被**独立见证**：关节力矩残差 τ−JᵀF、视觉接触检测、冗余 F/T、主动自检，都可用于交叉验证——质量可以被审计，而不必相信传感器自报。

**灵感 2（数据质量 → 证书的根信任不是传感器，而是数据）**：v20 的租约只说「新鲜」，没说「好」。把租约从 (m,τ,λ,κ) 扩为 (m,τ,λ,κ,q)，有效 margin 变成 m_eff = m − λ(t−τ) − u₊(q)：时间衰减只是质量完美时的特例。离线侧更根本：共形覆盖依赖标定集可交换性，检索式证书依赖 CKB 干净，蒸馏依赖标签质量；v20 所说的「边际覆盖风险」本质上是**数据质量风险**。给出质量修正的覆盖界：若标定集含标签噪声 η 与污染 c，则有效覆盖只能保证 ≥ 1−α−η−c；要么把 α 上调，要么用加权/鲁棒共形恢复。数据质量因此不是数据集的一个元数据字段，而是一张可审计的证书。

**灵感 3（耦合 → 「质量不可自证」与根信任递归）**：如果 q 由可能故障的同一个传感器/驱动上报，那么 u(q) 是循环论证——坏传感器报「我很健康」，证书照签，静默失效。因此立一条工程-数学原则：**No self-attestation（质量不得自证）**；q_lo 必须由**独立见证集**背书（跨模态 + 冗余 + 自检），并在故障假设 f 下用 Byzantine 一致性给出下界。这把「数据质量」从软性指标变成可验证谓词，也把 v20 的租约从「时间戳契约」升级为「时间 × 质量双契约」。

**耦合升级**：CQC（接触质量证书器）把力/触觉读数编译为质量条件不确定区间并做独立见证；DQL（数据质量账本）统一在线质量轨迹与离线数据质量证书，修正共形与检索；QFV（质量故障验证器）注入漂移/饱和/欺骗/污染并验证质量坍缩阶梯。四层架构由 v8 的「人格契约层 + 并发证书层」升级为 v9：在其下再插一个**贯穿四层的根信任平面 L_root（数据质量平面）**，让「证书之上还有证书」。

## 1. 形式化定义（增量：定义 44–50）

**定义 44（数据质量状态与质量证书）**：质量状态 q=(q_cal,q_sat,q_snr,q_lat,q_hys,q_xtalk,q_prov)∈Q，分别刻画标定漂移、饱和余量、信噪比、时延、迟滞、串扰、来源完整性。质量证书 Q=(q_lo,E,S,T) 携带分量下界 q_lo、证据 E、作用域 S（传感器/量程/工况）与有效期 T。称 Q **sound**，若在置信 ≥1−β 下 q_lo ≤ q_true（分量序）。**部分序**：q¹ ⪰ q² 当且仅当各分量 ≥。质量不是标量，禁止用单一「置信度」替代多维状态。

**定义 45（质量条件不确定集）**：对真值 y* 的读数 y，定义 U(q)=[y−u₋(q), y+u₊(q)]，并要求按质量分箱（Mondrian by quality bin）校准：∀ 质量箱 b，P(y*∈U(q) | q_lo∈b) ≥ 1−α_q。**单调性**：q¹ ⪰ q² ⟹ U(q¹) ⊆ U(q²)。力维度记 F_true∈[F−u₋,F+u₊]。这使「数据质量差」直接表现为区间变宽，而非被点估计掩盖。

**定义 46（质量感知租约与声性）**：租约 ℓ=(m,τ,λ,κ,q)，有效 margin m_eff(ℓ,t)=m−λ(t−τ)−u₊(q)。用于阈值 θ 的守卫当且仅当 m_eff≥θ 且 Q 经见证且 t≤T。**命题（新鲜且好才可用）**：若 q_lo 下界 sound 且 u₊ 对 q 单调不增，则任何通过守卫的决策，其真实 margin 必 ≥θ。**推论**：v20 租约是 q=1（u₊=0）的特例；只要 u₊(q)>0，「新鲜」不再蕴含「sound」。

**定义 47（独立质量见证与非自证原则）**：见证集 W={w₁..w_k}，每个 w_i 是独立通道上的谓词/监控（冗余 F/T、关节力矩残差 τ−JᵀF、视觉接触、温度、主动自检）。**见证 A(q_lo)** 成立当且仅当在至多 f 个故障见证下仍有一致多数落在容差内。**非自证原则**：产出 y 的通道不得作为 q(y) 的唯一见证。**定理（f-故障下的见证声性）**：若通道数 k>2f、故障见证数 ≤f 且一致集成立，则 q_lo ≤ q_true。

**定义 48（离线数据质量证书与覆盖修正）**：数据集 D 的数据质量证书 DQ=(η,c,δ_cal,d,b,P_hash)：标签噪声上界、污染率、跨会话标定漂移、重复率、类别平衡、来源哈希。**质量修正覆盖命题**：若标定集因污染 c 与标签噪声 η 破坏可交换性，则朴素共形覆盖 ≥1−α 不再成立，只能保证 ≥1−α−η−c；用加权/鲁棒共形可回收至 1−α（代价是区间变宽）。**推论**：v20 的覆盖保证隐含 DQ 的 η=c=0；否则必须显式扣减或重加权。

**定义 49（接触安全证书的复合声性）**：接触证书 C_contact 在 t 时刻 sound，当且仅当 (i) 力区间上界 F+u₊(q) ≤ cap_{global∩persona}；(ii) 质量证书经见证且租约有效；(iii) 接触状态（接触/非接触）估计带安全余量。**定理（复合）**：若定义 45–47 各自 sound，则 C_contact ⟹ 无接触力上限违例（在故障假设 f 内）；且任一前提失效时 C_contact 必须被拒签，而不是用点估计替代。

**定义 50（质量预算与质量坍缩阶梯）**：质量预算 B_q 用于自检、重标定与冗余；**质量坍缩**指 q_lo 低于使 u₊(q) 超过安全 margin 的阈值 q*。降级阶梯：Full → Quality-Hedged（按 u₊(q) 膨胀 margin）→ Fixed-Conservative（假定最坏 q_min）→ Force-Limited/Stop。**契约**：坍缩必须触发阶梯并记录，绝不静默沿用点估计。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 CONTACT-QUALITY-CERTIFIER（接触质量证书器 CQC）
1. **多维质量估计**：标定残差、饱和余量（用原始 AD + 派生量，勿只看滤波值）、SNR、时延上界、迟滞（加载/卸载环）、串扰（多轴）。
2. **质量条件不确定区间**：按质量分箱的 Mondrian 共形，输出 [F−u₋(q),F+u₊(q)]，并保证对 q 的单调性。
3. **独立见证与非自证**：冗余 F/T + 力矩残差 + 视觉接触 + 主动自检，按 f-故障 Byzantine 一致给出 q_lo；产出通道不得作唯一见证。
4. **接触证书复合与坍缩阶梯**：力区间上界 vs persona∩global 力上限；饱和护栏（专门处理质量-负载负相关），坍缩即降级。

### 2.2 IP-61 DATA-QUALITY-LEDGER（数据质量账本 DQL）
1. **在线质量账本**：按传感器/流维护 q(t) 轨迹、见证证据、衰减与作用域，并与 IP-58 租约表合并为「质量感知租约」。
2. **离线数据质量证书**：来源哈希、标签噪声估计（confident learning/交叉验证）、污染检测（OOD/重复/对抗）、跨会话标定漂移、类别平衡。
3. **质量修正的共形与检索**：加权/鲁棒共形、α 保守扣减、CKB 指纹内嵌 DQ 证书哈希，检索时只接受通过质量门槛的条目。
4. **质量预算与审计**：自检/重标定/冗余的资源记账；质量事件的不可抵赖审计日志（谁、何时、凭什么证据背书）。

### 2.3 IP-62 QUALITY-FAULT-VALIDATOR（质量故障验证器 QFV）
1. **故障注入**：漂移、饱和、stuck-at、串扰、时延尖峰、驱动层 Byzantine 伪造；力/触觉专属的冲击与碰撞瞬态。
2. **质量坍缩与阶梯验证**：在仿真里强制 q 坍缩，检验是否按阶梯降级而非静默沿用点估计。
3. **数据污染与标签噪声注入**：向标定集/CKB 注入污染，验证质量修正覆盖界与检测器。
4. **仿真-现实质量差与跨本体**：量化触觉跨会话/跨硬件标定漂移，验证 DQ 证书的迁移性。

## 5. 本轮最大风险

**一句话**：质量证书本身也是被质量污染的数据估计出来的，一旦见证集发生共因故障（同一标定/驱动/负载相关失效），Byzantine 一致会给出虚假的 q_lo，而高动态接触又恰好让视觉与力矩见证同时失效——因此本方案最大风险是「质量坍缩与见证坍缩同相发生」，必须以固定最坏界兜底并把 E97/E101 设为红线。

## 2. 关键算法（伪代码）

### IP-60 CQC：质量证书、条件区间与见证
```
def certify_quality(raw, derived, witness_set, fault_hyp):
    q_dim = {
        'cal':   calibration_residual(raw, derived),
        'sat':   saturation_margin(raw),            # 用原始 AD + 派生量，勿只看滤波值
        'snr':   snr_estimate(raw),
        'lat':   latency_bound(raw),
        'hys':   hysteresis_estimate(load_unload_cycles),
        'xtalk': crosstalk_estimate(multi_axis),
    }
    q_lo = componentwise_lower_bound(q_dim, conf=1 - BETA)
    if not independent_attest(witness_set, q_lo, fault_hyp):   # 非自证
        return QualityCert(q_lo=None, status='UNATTESTED')      # 立即进入降级阶梯
    return QualityCert(q_lo, evidence=witness_set, scope=..., expiry=...)

def quality_conditioned_interval(y, q_lo, alpha_q):
    b = quality_bin(q_lo)                       # 按质量分箱的 Mondrian
    u_minus, u_plus = conformal_quantiles[b](alpha_q)
    return [y - u_minus, y + u_plus]            # 质量差 => 区间必然变宽

def independent_attest(witnesses, q_lo, fault_hyp):
    agreeing = [w for w in witnesses if w.supports(q_lo)]
    # k>2f 且一致多数；产出通道不得作为唯一见证（非自证原则）
    producer_only = all(w.channel == witnesses.producer for w in agreeing)
    return len(agreeing) >= len(witnesses) - fault_hyp.f and not producer_only

def contact_cert_guard(F, q_lo, cap, lease, t):
    F_lo, F_hi = quality_conditioned_interval(F, q_lo, ALPHA_Q)
    m_eff = lease.m - lease.lam * (t - lease.tau) - (F_hi - F)
    ok = (F_hi <= cap) and attest(lease.q) and (m_eff >= cap - F_hi)
    return accept(contact_certificate(F_lo, F_hi, cap)) if ok else reject_and_degrade()
```

### IP-61 DQL：在线账本、数据质量审计与质量修正共形
```
def data_quality_audit(D):
    return DQ(
        eta=estimate_label_noise(D),        # confident learning / 交叉验证
        c=contamination_rate(D),            # OOD / 重复 / 对抗样本
        delta_cal=cross_session_drift(D),   # 触觉跨会话标定漂移
        d=duplicate_rate(D), b=class_balance(D),
        provenance=hash_provenance(D))

def quality_adjusted_conformal(cal_set, DQ, alpha):
    if DQ.eta + DQ.c == 0:
        return standard_conformal(cal_set, alpha)
    alpha_eff = min(1.0, alpha + DQ.eta + DQ.c)      # 保守扣减
    return weighted_conformal(cal_set, reweight_by_provenance=True, alpha=alpha_eff)

def degrade_ladder(q_lo, margin, B_q):
    if q_lo < q_star(margin):                        # 质量坍缩：u_+ 已吃掉安全 margin
        log_quality_collapse(q_lo)
        return 'FIXED_CONSERVATIVE' if B_q > 0 else 'FORCE_LIMITED_OR_STOP'
    return 'QUALITY_HEDGED' if q_lo < q_nominal else 'FULL'

def lease_renew_quality_aware(task, x, q_lo, theta, kappa):
    b = cert_lookup_L0(x)
    lam = L_m * v_max_bound(x)
    u_plus = conformal_quantiles[quality_bin(q_lo)](ALPHA_Q)[1]
    return Lease(m=b.m_lo, tau=monotonic_now(), lam=lam, kappa=kappa, q=q_lo,
                 expiry=monotonic_now() + (b.m_lo - theta - u_plus) / max(lam, eps))
```

### IP-51/52/53 升级：质量感知的守卫与监控

def car_transition_guard(e, x, cert_obj, persona, lease, t):
    theta   = cert_obj.alpha_e[e] * cert_obj.theta_sim[e]
    m_lookup = cert_lookup_L0(x).m_lo[e]
    m_lease  = lease.m - lease.lam * (t - lease.tau)
    m_qual   = u_plus(lease.q, cert_obj.sensor[e])       # 质量膨胀量（取正）
    m_cap    = persona_cap[e](persona) * quality_cap_factor(lease.q)
    return min(m_lookup, m_lease) - m_qual >= theta and lease_valid(lease, theta, t) \
           and min(m_lookup, m_lease) - m_qual <= m_cap

def schedule_with_quality(tasks, overload, quality_collapse):
    if quality_collapse:                       # 质量坍缩优先：先保见证与自检预算
        tasks = [t for t in tasks if t.role in {'safety', 'witness', 'selftest'}]

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 质量证书由被污染的数据估计，形成根信任递归（坏传感器自证健康） | 高 | 非自证原则；k>2f 独立见证；E97 红线；固定最坏界兜底 |
| 见证集共因故障（同标定/同驱动/负载相关）导致虚假一致 | 高 | 见证通道物理/软件解耦；共因故障假设 f 显式建模；E97/E101 红线 |
| 高动态接触时视觉模糊 + 力矩饱和，见证同时失效 | 高 | 冲击瞬态专用见证（主动自检/冗余 F/T）；坍缩阶梯；力限速 |

| 离线数据污染使共形覆盖静默失效 | 高 | DQ 审计；α 保守扣减/加权共形；CKB 只收合格条目；E99 红线 |

## 6. 本轮最大风险

**一句话**：质量证书本身也是被质量污染的数据估计出来的，一旦见证集发生共因故障（同一标定/驱动/负载相关失效），Byzantine 一致会给出虚假的 q_lo，而高动态接触又恰好让视觉与力矩见证同时失效——因此本方案最大风险是「质量坍缩与见证坍缩同相发生」，必须以固定最坏界兜底并把 E97/E101 设为红线。
