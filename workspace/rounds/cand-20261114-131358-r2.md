# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；本轮灵感：「流匹配策略」×「长期记忆」）

> R69 把不确定性一分为二：aleatoric 走 R68 铁律，epistemic 交给「流匹配多模态策略 + 主动多模态交互」。结构很漂亮，但它头顶悬着一个前提——**流模型的模态分布必须可信**。R69 在自陈的最大风险里已经承认：若 rectified flow 幻觉出不存在的模态、或坍缩掉真模态，VoI 就在错误信念上计算，系统会「自信地追问一个幻影」，把「诚实的不知道」升级成「被证实的错误」。
>
> 本轮两个灵感正好切进来：
> - **流匹配策略**：R69 只用了它的「生成」，没有用它更本质的结构性质——连续、可条件化、可被外部锚点拉动而**无需重训**；
> - **长期记忆**：R69 是「逐回合失忆」的——每一轮都从零重推模态、重新校准，上一轮验证过的、证伪过的、失败过的证据全部蒸发。**一个不会记忆的怀疑者，永远无法区分「真模态」与「幻觉」**，因为单次采样里它们长着同一张分布脸。
>
> 核心命题：**给流匹配策略装一个跨回合长时记忆，让「模态可信吗」从一次前向的赌博，变成一个可积累、可复现检验、可追溯的统计判断；并让记忆以「非参数条件化」而非「改权重」的方式参与动作生成——既能学新模态，又不遗忘旧模态。** 命名 **MNEMO-RAS**（Memory-grounded Non-parametric Epistemic Mode Oracle for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我以前见过它吗、那一次我错了吗**」——记忆不是数据库，是怀疑的第二个来源。

## 0. 直觉与动机

**灵感 1（流匹配策略 → 被浪费的结构）**
直觉：R69 把流模型当采样器，K 条轨迹聚类完就丢。但流模型的真正优势在于：输出空间连续、可插值、可被外部锚点拉动。只要把一个被验证过的旧模态原型 ξ̄ 作为引导项塞回速度场，就能在不改一个权重的情况下，让生成分布偏向「我认识的世界」。记忆正该介入这个位置：**记忆不该是一条 if-else 规则，而应是速度场上的一处引力源**。这不是把记忆当查表，而是把记忆当先验几何。

**灵感 2（长期记忆 → 幻觉与真实只能靠时间分开）**
直觉：一次采样分不清「真模态」与「幻觉模态」——它们在单帧里是同一张脸。但时间能分开二者：真模态会**复现**（相似情境下反复出现，并被现实证据确认），幻觉模态是**跨回合近似独立的噪声**，不会复现。R69 最大的漏洞不是算法细节，而是它**没有记忆去观测复现**。长期记忆把「一次前向的置信」升级为「跨回合的复现检验」：一个模态被支持的次数、被确认的语境、被证伪的记录，共同构成可信度 κ。**复现是幻觉的照妖镜。**

**灵感 3（非参数持续适应 → 学新模而不忘旧模）**
直觉：世界会变、任务会冒出新模态。传统做法是重训流模型，代价是灾难性遗忘，也违反 R68「实时零学习写」的不变式。记忆给出第三条路：把新模态作为**情景原型**追加进记忆，推理时用检索到的原型去条件化速度场（in-context conditioning）。于是「学习」发生在记忆里而不是权重里——可回滚、可审计、可遗忘，且旧模态一个都没丢。这是把 continual learning 从「改权重」降维成「改检索」。

**灵感 4（记忆是双刃剑 → 持久污染与自证循环）**
直觉：R69 的交互投毒是一次性的，骗一次就过去了；一旦系统会记忆，一次投毒就被**固化**。更可怕的是自证循环：系统问 → 得到误导答案 → 写进记忆 → 下次用记忆「证明」该模态可信 → 更自信地问 → 收到更多同源假证据。记忆把「一次被骗」变成「永久相信」，还会为后续被骗背书。所以本轮必须同时交付：**写入门控（provenance / 多源 / 复现）、有效性视界（防陈旧）、隔离区（防污染扩散）、新颖性守卫（防只检索旧模态导致坍缩）**。

**灵感 5（记忆的隐私维度 → 记忆里存的是人）**
直觉：跨回合记忆存的往往不是机器状态，而是**人的话、人的表情、人的让步**。技术上是「数据」，伦理上是被记录者。长期记忆必须有隐私预算与同意边界：能不存原文就不存、能本地化就本地化、能过期就过期。这一条不是附加项，而是「记忆系统能否被社会接受」的生死线，也直接反作用于可用样本量：隐私越紧，样本越少，ECE 越难压，系统越须保守。

## 1. 形式化定义（增量：定义 310–323）

**定义 310（MNEMO-RAS 总览）** MNEMO-RAS = (FMP, LTM, MBM, MAG, MCE, PMW, MVP, NCG, RAS-WM†)。五不变式（i–iii 继承 R69，iv–v 新增）：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **交互预算硬约束**（继承 R69 定义 293-ii）；
(iii) **证据纪律**：单次交互/单模态回答不得单独定案，需 ≥ k 个正交证据源一致（继承 R69 定义 293-iii）；
(iv) **记忆不直接生成动作**：LTM 只能通过「重加权模态可信度 κ」与「条件化速度场」影响策略；任何记忆内容都不得绕过 C-RAS-WM 认证，也不得把 λ_floor 压到 R68 下界以下；记忆失效 ⇒ 逐指令退化为 R69；
(v) **只追加、不改写、来源可追**：记忆只 append（含 tombstone 与 challenge 记录），禁止原地改写与静默删除；每条带 provenance 与有效性视界；未验证条目进隔离区 Q，不进语义记忆 S。

**定义 311（长时记忆结构 LTM）** LTM = (E, S, Q, P)。情景记忆 E = {(τ, o_τ, ξ_τ, g_τ, ℰ_τ, verdict_τ, t_τ, prov_τ)}：记录「当时情境—动作—证据集—审计结论—时间—来源链」；语义记忆 S = {ξ̄_k, ctx_k, supp_k, cal_k, h_k}：被多源或复现确认过的模态原型及其语境、支持度、校准统计、有效性视界 h_k；隔离区 Q 存放未验证或受挑战条目；P 为 provenance 有向图（谁由谁派生、谁挑战谁）。

**定义 312（记忆检索 R）** R(q; m) = TopM_{e∈E∪S} [ sim_ctx(q, e) − γ·age(e) + β·veracity(e) − δ·challenge(e) ]，其中 sim_ctx 为情境嵌入相似度，age 为陈旧惩罚，veracity 为来源可信度，challenge 为未决挑战惩罚。检索只读；在实时环外预取，环内仅查缓存。

**定义 313（记忆支撑的模态银行 MBM）** 对 K 个流采样聚类得模态 {m_k}。记忆支撑 supp(m_k) = Σ_{ξ̄∈S} w(ξ̄)·1[W_2(m_k, ξ̄) ≤ Δ_min/2]·decay(age)·veracity，w 为支持计数饱和函数。模态可信度 κ_k = σ(a·supp_k + b·consistency_k − c·challenge_k)。定义已验证集 V = {k : κ_k ≥ τ_κ} 与候选新模态集 N = {k : κ_k < τ_κ}。

**定义 314（复现检验与隔离）** 新模态 m ∈ N 进入隔离区 Q；仅在「连续 ρ 个相似情境复现」且「获得 ≥ k 源一致确认」后晋升进 S。否则到期衰减出队。判别依据：真模态跨回合出现概率 p、且与语境相关；幻觉模态跨回合近似独立（复现率 ≈ 基础采样率 q < p）。这把 R69 的「单次可信」改成「跨回合可证」。

**定义 315（记忆锚定引导 MAG）** 条件速度场 v_θ(x_s, s | o_t, R) = v_θ(x_s, s | o_t) + α·Σ_{k∈R∩V} ŵ_k (ξ̄_k − x_s)·b(s)，其中 b(s) 为时间窗（只在路径中段生效，避免扰动端点），α ≤ α_max 为锚定强度，且受 NCG 约束。梯度不回传、权重不更新；锚点只拉向已验证模态。MAG 产出的 ξ 仍需过 C-RAS-WM 认证，且不得越过 ε_int。

**定义 316（记忆校准估计 MCE）** 用记忆中「预测模态权重 vs 事后确认结果」滚动估计可靠性：ECE_mem = Σ_b (n_b/N)|acc(b) − conf(b)|，conf 为预测权重，acc 为事后由 verdict 确认的频率，按 provenance 加权、按视界截断。MCE 取代 R69 的静态 ECE 去驱动 MCG：ECE_mem > τ_ece ⇒ 关 VoI。记忆同时提供 FMA 的上下文正常基线 a_score 历史，使「行为异常」也可相对记忆判断。

**定义 317（来源保持写入 PMW）** 写入只在实时环外、审计之后发生；条目须带（来源动作 g、证据集 ℰ、审计 verdict、时间、派生链）。晋升进 S 需「≥ k 正交源一致 OR 复现 ρ 次」。禁止原地改；冲突以追加 challenge 表达，由 VQAuditor-M 裁决。删除只允许按隐私/法规以 tombstone 执行（保留哈希证明，不保留内容）。

**定义 318（有效性视界与衰减 MVP）** 每条记忆有视界 h；h 随环境非平稳速率 ν 缩短。检索条目满足 age > h 时只作弱先验（veracity 打折），并触发「用前复验」；复验未过即视为无效，不参与 κ。漂移检测（R68 COF / R69 FMA）抬高 ν ⇒ 全库视界收缩。

**定义 319（新颖性/覆盖守卫 NCG）** 防记忆导致的模态坍缩：监控记忆条件化后的模态熵 H_mode 与已验证模态覆盖 Cov。若 H_mode < H_min 或 Cov 下降，则降低 α 并强制 K↑。目标：**记忆提高精度，但不能以牺牲探索与覆盖为代价**——这是 R69「模态坍缩」在记忆侧的镜像。

**定义 320（记忆投毒威胁模型 ℰ_mem）** ℰ_mem = {情景注入（伪造 episode）、重放攻击（把旧的有效情境当作新证据重放）、provenance 伪造（来源说谎）、sybil 复现（用多个同源假条目制造「复现」）、渐进漂移（每步小偏移把原型推走）}。合并 ℰ_MNEMO = ℰ_FLUID × ℰ_mem。关键：**复现检验可被 sybil 攻击绕过**，故复现必须配「来源多样性」——复现条目须来自不可共谋的来源集合。

**定义 321（回溯审计 VQAuditor-M）** 审计不只审本轮，还能回溯：当新证据与 S 中条目矛盾，追加 challenge 并重算 κ；对「曾被采纳又事后证伪」的条目追溯其是否污染了后续决策（污染传播分析）。结论回灌 PMW 的 veracity 与 MCE。

**定义 322（隐私预算与同意 MPC）** 情景记忆默认只存嵌入摘要/哈希，不存原始人声/人脸；确需原文的条目用 (ε_p, δ_p)-差分隐私或本地加密，累计隐私预算，超预算即触发遗忘（tombstone）。同意撤回优先于一切保留策略。

**定义 323（证书 J_MNEMO）** J_MNEMO = (J_FLUID, supp_coverage, ECE_mem, provenance_completeness, quarantine_ratio, staleness_p95, novelty_margin, privacy_budget_used, memory_log_hash, mnemo_ver)。Valid ⇔ Valid(J_FLUID) ∧ ECE_mem ≤ τ_ece ∧ provenance_completeness ≥ τ_prov ∧ privacy_budget_used ≤ B_p ∧ 隔离区未溢出。

# IP-264/265 LTM + MBM：检索与模态支撑
class LongTermMemory:
    def retrieve(self, o_t, m=8):                      # 环外预取，环内只查缓存
        q = self.ctx_embed(o_t)
        cand = self.ann.search(q, k=4*m)               # 只读
        return sorted(cand, key=lambda e: sim(q, e) - GAMMA*age(e)
                      + BETA*veracity(e) - DELTA*pending_challenge(e))[:m]

    def support(self, mode, hits):                     # 定义 313
        return sum(w(e)*exp(-age(e)/h(e))*veracity(e)
                   for e in hits if W2(mode, e.xi) <= self.delta_min/2)

# IP-266 MAG：记忆锚定引导（不改权重、不反传）
def memory_anchored_sample(v, trunk, o_t, hits, alpha, K, N_step=2):
    z, xs = trunk(o_t), randn(K, D)
    anchors = [(w, e.xi) for e in hits if e.verified for w in [e.weight]]
    for i in range(N_step):
        s = i / N_step
        v_mem = sum(w * (a - xs) * B(s) for w, a in anchors)   # 时间窗 B(s)
        xs = xs + (1.0/N_step) * (v(xs, s, z) + alpha * v_mem)
    return [decode(x) for x in xs]

# IP-267 MCE：记忆校准（替代静态 ECE 驱动 MCG）
def memory_calibration(stats):                          # (conf, acc, prov) 来自记忆
    bins = bucket(stats)
    return sum(n_b/N * abs(acc_b - conf_b) for b in bins)   # provenance 加权

# IP-268/269 PMW + MVP：写入门控（环外、审计后、只追加）
def memory_write(entry, audit, sources, ltm, nu):
    if not audit.valid:                 ltm.quarantine(entry); return
    diverse  = source_diversity(sources) >= K_SRC       # 防 sybil 复现
    recurred = ltm.recurrence(entry) >= RHO
    if diverse or recurred:
        ltm.append_semantic(entry, prov=entry.prov,
                            horizon=validity_horizon(entry, nu))
    else:
        ltm.quarantine(entry)                            # 不晋升，防幻觉固化
    ltm.append_log_hash(entry)                           # 只追加审计链

# IP-275 主闭环（继承 R69，仅在“模态可信度 / 条件化”两处插入记忆）
def MNEMO_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    hits = M.ltm.cached_retrieve(o)                      # 环内零 I/O
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = (M.fmp.sample(o, K) if not hits
               else memory_anchored_sample(M.fmp.v, M.fmp.trunk, o, hits,
                                           M.alpha, K))   # 记忆锚定
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    # 关键新增：用记忆支撑把“幻觉模态”与“真模态”分开
    supp  = [M.ltm.support(m, hits) for m in modes]
    kappa = [sigmoid(a*s + b*cons(m) - c*challenge(m))
             for m, s in zip(modes, supp)]
    V = [k for k in range(len(modes)) if kappa[k] >= TAU_K]   # 已验证
    N = [k for k in range(len(modes)) if kappa[k] <  TAU_K]   # 新模态 → 隔离
    # 记忆校准门：R69 的 MCG 从静态 ECE 换成滚动 ECE_mem
    if memory_calibration(M.ltm.stats) > TAU_ECE:
        return R69_FLUID_round(M, obs)                   # 逐指令退化 R69
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o, o_cal, M.ltm.baseline(o))
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    g = (M.mint.choose_interaction(V, o, M.budget)
         if (U_epi > TAU_EPI and not slow and V) else None)
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    # NCG：记忆锚定若压低熵/覆盖，松开 α 并补采样
    if entropy(modes) < H_MIN or coverage_drop(modes, M.ltm):
        M.alpha = max(0.0, M.alpha - D_ALPHA); K = max(K, 4)
    mode = select_mode(modes, U_epi, lam, kappa)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.pmw.submit_async(g, modes, supp, kappa)            # 环外写入门控
    return k, lam, mode, (U_ale, U_epi, kappa)

## 3. 推导

**引理 19（复现可分辨幻觉）** 设真模态在相似情境下每回合出现概率 p，幻觉模态每回合独立出现概率 q，且 p − q ≥ Δ_p > 0（A99）。经 n 个相似情景，真/幻觉的支持计数分别近似 Bin(n,p) 与 Bin(n,q)。以「出现 ≥ ρ = ⌈nq + c√(nq)⌉ 次」判为真，则幻觉被误判的概率随 n 指数下降（大偏差速率由 KL(Ber(q)‖Ber(ρ/n)) 给出）。系：**R69 的单次模态后验无法区分二者（同一张分布脸），记忆复现使判别力随回合累积——用时间换判别力**；交互（R69）是「主动索取一次证据」，记忆（R70）是「被动积累多次证据」，两者正交、可叠加。

**引理 20（投毒驻留上界）** 在 append-only + 多源复现 + 视界衰减下，单条被投毒条目晋升进 S 的概率 ≤ δ_p^{k}（k 个不可共谋源）或 ≤ c_sybil(ρ)^{-1}（伪造复现需制造 ρ 次跨源、跨视界一致证据，成本随 ρ 与来源多样性上升）；即便晋升，其影响随视界 h 指数衰减，期望驻留期 ≤ h/(1 − r_renew)。渐进漂移每周期位移 ≤ δ_drift，累计超 τ_drift 即触发复验。系：**记忆把「一次性欺骗」转化为「需持续付费维持的欺骗」**——这是 append-only 相对可改写记忆的安全优势，也解释了为何定义 310-v 不可让步。

**引理 21（陈旧与视界）** 设环境以速率 ν 漂移，条目平均年龄 ā。用陈旧先验的额外风险 ≤ L_ctx·ν·ā + ε_stale；若复验成本为 c/h，则最小化 L_ctx·ν·h + c/h 得 h* = √(c / (L_ctx·ν))。系：非平稳时「记太久」与「不记」同样危险；视界必须随漂移检测自适应（定义 318）。

**定理 18（严格容纳链 R68 ⊂ R69 ⊂ R70）** 关闭记忆（hits = ∅、α = 0、MCE 恒通过、不写）⇒ MNEMO 逐指令等于 FLUID；再关闭交互（VoI 恒 ≤ 成本）⇒ 等于 CALM-RAS。故在 A95–A99 下，期望风险 R70 ≤ R69 ≤ R68；当记忆失效/被投毒/陈旧/隐私超预算时，MNEMO 只退化为 R69，绝不弱于 R68 的安全侧。**安全单调性不变，效率增益来自「可信模态不再被误当 aleatoric 收紧」。**

**定理 19（非参数持续适应与不遗忘）** 设新模态集 M_new 概率质量 ε_new、旧模态集 M_old。MAG 只加引导、不删权重：α → 0 时生成分布连续回到 FMP，故旧模态遗忘 → 0；新模态的可表示误差 err_new ≤ err_FMP + c·dist(M_new, R)（检索缺口）。存在 α* 使新模态召回最大而旧模态覆盖 ≥ 1 − η。系：**记忆把 continual learning 的「稳定性—可塑性」权衡从权重空间搬到检索空间**——稳定性由「不删」保证，可塑性由「检索 + 锚定」提供。

**定理 20（隐私—效用前沿）** 在 (ε_p, δ_p)-DP 记忆下，每回合泄漏上界由预算组合给出；可用记忆样本数随 B_p 增大而增多，ECE_mem 随之下降。隐私超预算触发遗忘 ⇒ 样本减少 ⇒ ECE_mem 上升 ⇒ MCG 更易越界 ⇒ 更依赖 R69 兜底。系：**隐私不是纯合规成本，而是「减少可用记忆 → 提高不确定性 → 触发保守」的物理约束**，必须进入 J_MNEMO 与预算优化，而非事后补丁。

## 6. 本轮最大风险

**一句话**：MNEMO-RAS 把「一次判断失误」升级成「写进记忆的永久先验」，而记忆又会条件化策略本身——**一旦被投毒或已陈旧的条目晋升进语义记忆，系统就会自己查自己、自己证明自己，形成跨重启存活的自我强化错误；记忆安全的下界由最弱的那一次写入决定，而不是由最强的审计决定。**

class LongTermMemory:
    def retrieve(self, o_t, m=8):
        q = self.ctx_embed(o_t); cand = self.ann.search(q, k=4*m)
        return sorted(cand, key=lambda e: sim(q,e) - GAMMA*age(e)
                      + BETA*veracity(e) - DELTA*pending_challenge(e))[:m]
    def support(self, mode, hits):
        return sum(w(e)*exp(-age(e)/h(e))*veracity(e)
                   for e in hits if W2(mode, e.xi) <= self.delta_min/2)

# IP-266 MAG：记忆锚定（不改权重、不反传）
def memory_anchored_sample(v, trunk, o_t, hits, alpha, K, N_step=2):
    z, xs = trunk(o_t), randn(K, D)
    anchors = [(e.weight, e.xi) for e in hits if e.verified]
    for i in range(N_step):
        s = i/N_step
        v_mem = sum(w*(a-xs)*B(s) for w, a in anchors)   # 时间窗 B(s)
        xs = xs + (1.0/N_step)*(v(xs, s, z) + alpha*v_mem)
    return [decode(x) for x in xs]

    bins = bucket(stats)

## 4. 推导

**引理 19（复现可分辨幻觉）** 真模态每回合出现概率 p、幻觉模态独立出现概率 q，且 p−q ≥ Δ_p > 0（A99）。经 n 个相似情景，支持计数近似 Bin(n,p)/Bin(n,q)；以「出现 ≥ ρ=⌈nq+c√(nq)⌉ 次」判真，幻觉误判率随 n 由大偏差速率 KL(Ber(q)‖Ber(ρ/n)) 指数下降。系：单次模态后验无法区分二者（同一张脸），记忆复现使判别力随回合累积——**用时间换判别力**；交互（R69，主动索取一次）与记忆（R70，被动积累多次）正交可叠加。

**引理 20（投毒驻留上界）** append-only + 多源复现 + 视界衰减下，单条投毒条目晋升率 ≤ `δ_p^{k}`（k 个不可共谋源）或 ≤ `c_sybil(ρ)^{-1}`；即便晋升，影响随视界指数衰减，期望驻留 ≤ `h/(1−r_renew)`；渐进漂移每周期 ≤ δ_drift，累计超 τ_drift 触发复验。系：**记忆把一次性欺骗变成需持续付费维持的欺骗**——append-only 的安全优势，也是定义 310-v 不可让步的理由。

**引理 21（陈旧与视界）** 环境漂移速率 ν、平均年龄 ā 时，陈旧先验额外风险 ≤ `L_ctx·ν·ā + ε_stale`；复验成本 c/h，最小化 `L_ctx·ν·h + c/h` 得 `h* = √(c/(L_ctx·ν))`。系：非平稳时「记太久」与「不记」同样危险，视界须随漂移自适应。

**定理 18（严格容纳链 R68 ⊂ R69 ⊂ R70）** 关记忆（hits=∅、α=0、MCE 恒过、不写）⇒ 逐指令等于 FLUID；再关交互 ⇒ 等于 CALM-RAS。A95–A99 下 `R70 ≤ R69 ≤ R68`；记忆失效/投毒/陈旧/隐私超预算时只退化到 R69，安全侧不弱于 R68。

**定理 19（非参数持续适应与不遗忘）** MAG 只加引导不删权重，α→0 时生成分布连续回到 FMP ⇒ 旧模态遗忘→0；新模态可表示误差 ≤ `err_FMP + c·dist(M_new, R)`。存在 α* 使新模态召回最大、旧模态覆盖 ≥ 1−η。系：稳定性由「不删」保证，可塑性由「检索+锚定」提供——把稳定性—可塑性权衡从权重空间搬到检索空间。

**定理 20（隐私—效用前沿）** (ε_p,δ_p)-DP 下泄漏上界由预算组合给出；可用样本随 B_p 增大而增多，ECE_mem 下降。超预算遗忘 ⇒ 样本减少 ⇒ ECE_mem 上升 ⇒ MCG 更易越界 ⇒ 更依赖 R69 兜底。系：隐私是「减少记忆 → 提高不确定性 → 触发保守」的物理约束，须进 J_MNEMO 与预算优化。

## 7. 本轮最大风险

**一句话**：MNEMO-RAS 把「一次判断失误」升级成「写进记忆的永久先验」，而记忆又会条件化策略本身——**一旦被投毒或已陈旧的条目晋升进语义记忆，系统就会自己查自己、自己证明自己，形成跨重启存活的自我强化错误；记忆安全的下界由最弱的那一次写入决定，而不是由最强的审计决定。**

**次级风险与缓解**：sybil 复现绕过检验（来源多样性 + 不可共谋源 + 引理 20）；模式坍缩（NCG + α 自适应 + E311）；非平稳陈旧（MVP 视界 + 用前复验 + 引理 21）；隐私超预算（MPC + DP + 定理 20 + E313）；写操作侵入实时环（PMW 全环外 + 只追加 + E307）。
