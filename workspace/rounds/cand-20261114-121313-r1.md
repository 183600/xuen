# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~301；灵感循环第 1 轮；本轮灵感：「预测性维护」×「需求洞察」）

> R73 把证据计量变成可组合契约（MMS/DPEM/CCA/ΣREFLEX/CPB），但它有一个被自己那句风险点破的时间盲区：**所有证书都是某一时刻的快照**。EC 的有效域 D、SEAL 校准报告、conformal 覆盖率、u_calib，全部默认「部署时成立 ⇒ 运行时成立」。于是系统只有两种时间状态：**现在合规** 与 **超阈值后 stub（失败）**。中间那段「正在变坏但还没坏」的历史被完全浪费——而这正是预测性维护的全部领地。
>
> 更尖锐的是：R73 的「契约表达力风险」其实是一个**时间化**的风险。契约不会突然撒谎，它会**缓慢漂移出有效域**（外参热漂、镜头污染、传感器老化、IR 暴露累积、机械磨损），而 R73 只在漂出之后才知道。与此同时，「剩余寿命」这个概念在 R73 里根本无法定义——因为寿命是相对于**失效判据**的，而失效判据是相对于**需求**的。需求若只是一条静态规格 ρ_s，那么「预测」就退化为「对照一条可能过时/过松/过紧的线」。这就是第二个灵感词的入口：**没有需求洞察的预测性维护，是在为一个错误的目标预测寿命。**
>
> 本轮把两件事焊在一起：
> - **预测性维护** → **PROG（Metrological Prognostics）**：把每个模块的退化状态 d_i(t) 与契约失效边界 ∂D_i 显式建模，用**计量残差本身**作状态监测信号（无需新硬件），给出 **RUV（Remaining Useful Validity）** 的首达时分布；用**悲观预测**（可信退化模型集下界）把预测误差转成「寿命变短」而非「安全变差」。
> - **需求洞察** → **RIM（Requirement Insight Model）**：需求 ρ 是不可观测潜变量，有后验 q_t(ρ)；区分**陈述需求 ρ_s**、**显露需求 ρ_r**（从人的纠正/干预反推）与**可信需求集 P_δ**；证据充分性定义为对 P_δ 的**分布鲁棒**满足，而非对单点 ρ_s 的满足。需求也有寿命——**需求腐化（spec rot）**。
>
> 核心命题：**不再问「此刻证据是否充分」，而问「在需求仍可能变化的未来 H 内，证据是否仍将以高概率充分——以及为了让这个『是』成立，现在应当先维护什么、先问清什么？」** 把 R73 的 **MODGAUGE** 升级为 **PRISM-GAUGE-RAS**（Predictive, Requirement-Indexed Survival Metrology with GAUGE audits）：**视界证书 + 需求索引证据 + 计量生存分析**。

## 0. 直觉与动机

**灵感 1（预测性维护 → 计量系统就是它自己的状态监测器）**
直觉：工业 PdM 的经典套路是「加振动/温度传感器 → 学退化 → 预测 RUL」。但在这个系统里，**不需要加传感器**：DPEM 已经每帧输出 u_calib、u_interf、u_material，DMEM 输出接触残差，IRL 输出意图校准误差。这些**计量残差的时间序列本身就是退化过程的观测量**——校准漂移在 u_calib 的慢变趋势里，镜头污染在 u_material/深度残差的基线抬升里，IR 暴露在 u_interf 的累积里，机械磨损在接触残差分布的展宽里。所以 PROG 的输入是 R73 的**副产物**，边际成本极低。第二层直觉：R73 的 stub 是**事后**的（已经越界）；PdM 的价值在于把「越界」变成「预计将越界」，从而在越界前执行**降级阶梯**（收紧 λ_floor、缩小有效域、提高审计率、安排重标定），把一次「失效」换成一次「维护」。第三层、也是最关键的直觉：**预测会撒谎**。一个自信而错误的退化模型会告诉你「还有很久」，于是系统安静地什么都不做——预测性维护在这里不是天然增加安全，而是**把安全押在模型上**。因此必须用悲观预测（对可信模型集取下界）+ 预测-行动分离（预测本身不授权推迟），否则 PdM 是净风险源。

**灵感 2（需求洞察 → 充分性是相对于需求的，需求是潜变量）**
直觉：R73 的 CPB 把「主张 → 证明」绑定了，但**主张从哪来**？ε_mod、τ_v、碰撞率上限、延迟预算——这些阈值被当作给定常数。可现实中它们恰恰是最不确定的东西：用户说的是 ρ_s，用户真正在意的是 ρ_r，而部署场景真正要求的是 ρ*；三者不同。需求洞察的工程化不是「写更好的需求文档」，而是**把需求当作带后验的潜变量，并让安全证书对这个后验鲁棒**。这带来两个反直觉结论：(a) **需求越模糊，需要的证据越多**——模糊不是免费的，它必须在证据预算里付账，否则系统就是拿「我以为你要的」去认证「你其实要的」；(b) **需求可能被机器人自己的行为改写**——如果机器人一直很谨慎，人会逐渐容忍更松的要求，于是显露需求 ρ_r 变松；若系统据此放松证据，就会进入「谨慎 → 需求松弛 → 证据减少 → ……」的正反馈，最终在真实需求没变的情况下自我解除武装。这需要一个**外部锚**（显式确认、监管约束、定期重述），否则无安全保证。

**灵感 3（两词的焊接点 → 需求是寿命的参照系）**
直觉：RUL 在 PdM 里从来不是「还能转多少小时」，而是「相对于失效判据还能转多少小时」。把失效判据换成安全需求，立刻得到：**RUV_i(t; ρ) 是 ρ 的单调不增函数**。需求越严（允许的不确定度越小），失效边界越早到达，RUV 越短；需求后验越宽（模糊），可信需求集 P_δ 里的最严 ρ 决定保守 RUV。于是「维护什么」不再是按模块平均退化排序，而是按 **(需求严格度 × 需求后验质量 × 退化速度 × 失效代价)** 排序——**需求洞察直接决定维护优先级**。这是本轮真正的结构性贡献，而不是两个模块的拼接：**需求是预测的参照系，预测是需求的时间化。**

**灵感 4（视界证书 → 从快照合规到区间保证）**
直觉：R73 的 `Valid(J_MOD) ⇒ risk ≤ ε` 是一个 t 时刻的断言；把它沿时间积分才是 RAS 真正需要的。定义 **视界证书 J_H(t,H)**：在 [t, t+H] 上，以概率 ≥ 1−δ，所有模块契约有效、需求鲁棒充分、组合合法、预算可行。H→0 时严格退化为 J_MOD。这迫使我们同时面对两类不确定性：**退化不确定性**（RUV 分布）与**需求不确定性**（q(ρ)），并且它们**相乘**——两者都自信地错，才会「安静地什么都不做」。这就是要把两者放进同一个证书而不是两个独立模块的原因。

**灵感 5（证据债务 → 迟到与早到的对称性）**
直觉：推迟维护/推迟取证/推迟问清需求，都是**向模型借钱**：今天省下的成本，明天以更高的失败概率或更贵的补救偿还。把它记成 **证据债务 D_e(t)**（所需证据率与实付证据率之差的积分 + 推迟维护的期望补救成本），并约束 D_e ≤ D_max，就得到一个与 R73 ΣREFLEX 预算同构、但作用于**时间轴**的预算。它给出一个漂亮的停止性结论：只要维护的边际收益有正下界、债务利率有正下界，就存在**有限的**最优维护时刻——「一直拖」不是最优。

## 1. 形式化定义（增量：定义 383–400）

**定义 383（PRISM-GAUGE-RAS 总览）** PRISM = (PROG, RIM, RIVH, MES, CRPB, MODGAUGE-RAS†)。六不变式：
(i) **契约时间化**：每个 EC 附退化状态 d_i(t) 与失效边界 ∂D_i，静态 D 升级为时变可行域 D_i(t)；
(ii) **需求索引**：充分性判据以需求后验 q_t(ρ) 为参照，禁止对单点 ρ_s 认证；
(iii) **视界声明**：安全断言是 [t,t+H] 上的概率保证（定义 389），不是 t 时刻快照；
(iv) **预测-行动分离**：RUV 预测不得直接授权推迟维护（定义 397 悲观下界 + MES 显式决策）；
(v) **需求-证明绑定**：CRPB（定义 394），每个 claim 绑定 requirement 与 proof；
(vi) **严格退化链扩展**：预测性降级阶梯（定义 396）先于 stub，安全侧只增不减（定理 32）。

**定义 384（退化状态与计量健康）** 对模块 i，退化状态 d_i(t) ∈ ℝ^{k_i}：d = (δ_cal, c_opt, e_ir, w_mech, …) 对应内/外参漂移、光学污染、IR 暴露累积、机械磨损。随机退化过程
d_i(t+Δ) = d_i(t) + μ_i(d_i)Δ + σ_i(d_i)dW_t + J_t（J_t 为污染/碰撞跳变）。
可观测量 z_i(t) =（u_calib 趋势、u_material 基线漂移、u_interf 累积、接触残差展宽…），全部来自 R73 计量输出（定义 369/370），**零新增硬件**。健康指数 h_i(t) = Φ_i(d_i(t)) ∈ [0,1]，Φ_i 单调不增。

**定义 385（契约失效边界与 RUV）** 需求索引阈值 τ_i(ρ) 把需求 ρ 映到该模块允许的不确定度/误差上限。契约在 t 有效当且仅当
u_i(d_i(t)) ≤ τ_i(ρ) ∧ d_i(t) ∈ D_i^{raw}。
**剩余有效寿命** RUV_i(t; ρ) = inf{τ>0 : u_i(d_i(t+τ)) > τ_i(ρ)}。其预测分布 p(RUV_i | F_t, ℳ) 由退化过程的首次通过时间给出。**关键**：RUV 对 ρ 单调不增（需求越严，寿命越短）。

**定义 386（证据生存函数与风险率）** S_i(τ;t) = P(RUV_i(t) > τ | F_t) = ∫ S_i(τ;t,ℳ) dΠ_t(ℳ)，Π_t 为退化模型后验。风险率 h_i(τ) = −d ln S_i / dτ。计量域以 1 Hz 更新。

**定义 387（需求洞察模型 RIM）** 需求潜变量 ρ ∈ 𝒫（碰撞率上限、延迟、抓取误差、接触力、隐私等，按 claim 分组）。后验
q_t(ρ) ∝ q_0(ρ) · ∏_{s≤t} L(obs_s | ρ)，obs ∈ {显式陈述, 人的纠正/接管, 审计结果, 任务上下文, 监管约束}。
三个对象：**陈述需求** ρ_s（规格/人所说）；**显露需求** ρ_r（由行为反推的后验）；**可信需求集** P_δ(t) = 最高后验密度集，质量 1−δ。
**需求模糊度** A_t = 𝒟(q_t(ρ), δ_{ρ_s})（KL 或 P_δ 与 {ρ_s} 的分离度）；**需求漂移**为 q_t 的上下文条件变化。
**需求索引充分性**：证据 E 对 claim C 是 (q,δ)-充分 ⇔ ∀ρ ∈ P_δ(t): P(risk_C ≤ ρ | E) ≥ 1−α。

**定义 388（需求索引视界 RIVH）** 模块 i 在需求后验 q 下的视界
H_i(t;q) = sup{ H : S_i(H;t) ≥ 1−δ_i ∧ ∀t'∈[t,t+H], D_i(t') ≠ ∅ ∧ (q,δ)-充分 }。
系统视界由 CCA 组合（定义 392、引理 42）：SER 取 min 并扣除组合开销；PAR 仅当跨模态独立性与需求鲁棒性同时通过才可延长，否则取 min。

**定义 389（视界证书 J_H）** J_H(t,H) =（模块证书在 [t,t+H] 有效, RIVH_i ≥ H, (q,δ)-充分性, MReg 组合在视界内合法, 视界内预算可行, 证据债务 D_e ≤ D_max）。Valid(J_H) ⇒ 在 [t,t+H] 上 risk ≤ ε 以概率 ≥ 1−δ_cert。H→0 ⇒ J_H = J_MOD（R73）。

**定义 390（证据债务）** D_e(t) = ∫_t (r_req(s) − r_actual(s))_+ ds + Σ_{推迟的维护 m} γ^{Δt_m} · E[补救成本_m]，r_req 为按需求后验计算的所需证据率。约束 D_e ≤ D_max。利率 γ<1 给出「越拖越贵」。

**定义 391（维护动作与策略 MES）** 动作 a ∈ {do-nothing, recalibrate, replace, re-elicit(问清需求), gather-evidence, tighten-domain, stub}。策略 π(a | d̂, q_t, D_e) 求解
max_π E[ mission utility − maintenance cost − evidence cost ]
s.t. ∀t'∈[t,t+H]: J_H(t',H) 成立。
需求关键度 w_i(t) = E_{ρ∼q_t}[ ∂risk/∂u_i ]（需求越严、后验越集中，权重越大）。

**定义 392（视界组合）** SER(A∘B)：H = min(H_A, H_B) − δ_comp（寿命是最弱环节，串联另加延迟）。PAR(A⊕B)：仅当 (i) R73 跨模态一致性审计通过且 (ii) 退化过程在可信模型集内条件独立 时，H 可取 ≥ min；否则 H = min（禁止「融合延寿」）。VETO：H = min，任一否决 ⇒ H = 0。

**定义 393（需求驱动的维护优先级）** Priority_i = w_i(t) · P(RUV_i < H) · L_fail / Cost_maint。按此分配维护窗口与人工问询预算——把「需求洞察」变成资源分配信号，而非文档。

**定义 394（CRPB：主张-需求-证明绑定）** 在 R73 CPB 上增加需求维：每个 claim C 绑定 (ρ_C, proof, requirement-evidence link, 需求校准报告)。**过度规格**：ρ_s 显著严于 P_δ ⇒ 证据浪费（可安全下调）；**欠规格**：ρ_s 显著松于 P_δ ⇒ 不安全（必须收紧）。CRPB 入图前置校验同时检查「证明确实服务于该需求」与「需求确实是部署需求」。

**定义 395（需求腐化与需求寿命）** 需求自身有寿命：当 A_t = 𝒟(q_t(ρ_r), δ_{ρ_s}) > A_max 或上下文变化使 P_δ 迁移，判定 **spec rot**，触发 re-elicit；在此之前按 P_δ 鲁棒认证。需求视界 H_req(t) = 预测 A 首次越界的时间。

**定义 396（预测性降级阶梯）** L0 全功能 → L1 按预测风险膨胀收紧 λ_floor（λ ← λ·(1+κ·P(RUV<H))）→ L2 收缩有效域到高置信区 → L3 提高审计率/降低自主性 → L4 stub（R73 定义 381）→ L5 系统级 R68。**触发条件全部是「预测将越界」，且必须用悲观 RIVH**；任何一级都不得减少其他模态的保守性。

**定义 397（悲观预测与模型可信集）** 退化模型集 ℳ，后验 Π_t。**悲观视界** H_lb(t) = inf_{ℳ' ∈ ℳ_δ(t)} H(t;ℳ')，ℳ_δ 为模型可信集。设计原则：**模型怀疑 ⇒ 寿命缩短，而非安全放宽**。若 ℳ_δ 含「突然跳变」模型（黑天鹅），H_lb 显著收缩，从而强制更早维护或更早降级。

**定义 398（需求对抗面 AIC-REQ）** 威胁：需求欠规格（人没说清/故意隐瞒）、偏好欺骗、规格投毒、任务分布迁移、**自反馈需求松弛**（机器人谨慎 ⇒ 人放松要求 ⇒ 系统据此减证据）。防线：外部锚（显式确认/监管约束/定期重述）+ 需求后验校准 + 单源不定案（R73 E356/E357 原则）+ 自反馈检测（q(ρ_r) 与 ρ_s 的持续分离 + 行为-需求联合模型）。

**定义 399（PRISM MBench：MB4/MB5）** MB4（预测性维护）：加速退化台（外参热漂、镜头污染、IR 暴露、磨损）× 任务视界，预注册退化曲线与维护成本；MB5（需求洞察）：模糊/演化/欠规格需求场景 + 显式 elicitation 协议。各 ≤3h 单卡可复现，密封保持集 SEAL-MB4/5。

**定义 400（成本度量）** CertCost_H = 模块视界证书生成 + 需求后验校准 + 组合校验；MaintCost = 维护动作 + 停机；EvidenceDebt = D_e。C4/C5 的可证伪形式均以这三者比值表述。

## 2. 关键算法骨架

```python
# IP-302 PROG：计量生存分析（计量域 1Hz，复用 R73 计量残差，零新硬件）
class MetrologicalPrognostics:
    def update(self, mod, metrology_hist):
        z = condition_monitor(metrology_hist)        # u_calib/u_interf/残差趋势
        self.d = self.filter.update(self.d, z)       # 退化状态后验（粒子/卡尔曼）
        self.model_post = self.bma.update(z)         # 退化模型后验 Π_t
        return self.d, self.model_post
    def ruv(self, mod, rho, horizon):
        b = mod.ec.threshold(rho)                    # τ_i(ρ)：需求越严越低
        return [first_passage_survival(self.d, self.model_post, b, t) for t in horizon]
    def pessimistic_horizon(self, mod, q, H):
        return min(self.horizon_for(mod, M, q, H)
                   for M in credible_models(self.model_post))   # 模型怀疑 ⇒ 寿命变短

# IP-303 RIM：需求洞察（事件触发 + 每轮）
class RequirementInsight:
    def update(self, obs, ctx):
        self.q = bayes_update(self.q, obs, ctx)      # 陈述/纠正/审计/约束
        self.P_delta = hpd_set(self.q, self.delta)   # 可信需求集
        self.ambiguity = divergence(self.q, self.rho_s)
        if self.detect_feedback_loop(obs):           # 谨慎→放松 的自反馈
            self.external_anchor_required = True     # 强制 re-elicit / 监管锚
        return self.q, self.P_delta
    def robust_sufficient(self, ev, claim, alpha):
        return all(risk_bound(ev, claim, rho) <= rho
                   for rho in self.P_delta), self.worst_rho()   # 对最严需求都要满足

# IP-304 RIVH + IP-305 MES：视界与需求驱动维护
def viability_horizon(modules, q, H):
    H_i = {i: m.prog.pessimistic_horizon(m, q, H) for i, m in modules.items()}
    return compose_horizons(H_i, modules.mreg)       # SER/PAR/VETO（定义 392）

def maintenance_step(modules, q, D_e, H):
    pr = {i: priority(m, q, H) for i, m in modules.items()}   # w_i·P(RUV<H)·L/C
    a = solve_index_policy(pr, modules, D_e, H)      # Whittle/有限时域 MDP
    if a.kind == 're-elicit': return ask_human(a.rho_axis)    # 需求侧维护
    if a.kind in ('recalibrate', 'replace'): schedule(a)
    return a, D_e + debt_increment(a)

# IP-306 CRPB + IP-307 PRISM 主闭环（复用 R73 三域）
def PRISM_round(M, obs, audio, tac_frame, depth_img):
    # 感知域（100Hz）
    d_ev = M.dpe.update(depth_img, rgb, M.cam_state, M.motion, M.peers)
    q, P_delta = M.rim.update(extract_req_obs(obs, audio), M.ctx)   # 需求后验
    # 计量域（50Hz）
    if M.clock.due_metric():
        for mod in M.mods.values(): M.prog[mod].update(mod, M.metrology_hist[mod])
        H_sys = viability_horizon(M.mods, q, M.H)                   # IP-304
        if not M.cert.horizon_valid(H_sys):                         # 视界证书失效
            a, M.debt = maintenance_step(M.mods, q, M.debt, M.H)    # IP-305
        M.mode = degradation_ladder(M.mods, q)                      # L0..L5（悲观触发）
        b_t = M.bse.step_full(..., d_ev=d_ev, t_ev=M.dmem.update(tac_frame, M.last_action))
        M.snapshot.write(b_t, q, H_sys, M.debt, M.mode)
    # 控制域（1kHz，继承 R73；λ 由视界风险膨胀调制）
    snap = M.snapshot.read_latest()
    lam = embodied_risk_scale(snap.U_ale, snap.U_epi, snap.H_z,
                              max(snap.t_ev.u, snap.d_ev.u), M.risk_params) \
          * (1 + M.kappa * risk_inflation(snap.H_sys, q))
    A = M.ach.propose_ctrl(..., pvop_bias=snap.pvop); k = M.c_ras_wm.certified_prefix(A, lam)
    M.ctrl_out.publish(k, lam); M.cert_ctrl.write(k=k, lam=lam, breaker=M.breaker.status())
    return k, lam, J_H(M, H_sys)                                # 视界证书（定义 389）
```

## 3. 推导

**引理 38（需求索引寿命的单调性）** 若退化过程 d_i(t) a.s. 非降（Gamma 过程）且 u_i(·) 对 d_i 单调，则 RUV_i(t;ρ) 良定义 a.s.，S_i(τ;t) 对 τ 单调不增；且 τ_i(ρ) 对 ρ 单调不增 ⇒ RUV 对 ρ 单调不增。系：**「需求越严，寿命越短」不是口号，是可证的序关系；这也说明脱离需求谈 RUL 无意义。**

**引理 39（悲观预测的安全性：预测误差只花效率）** 若真实退化模型 ℳ* ∈ ℳ_δ(t) 以概率 ≥ 1−δ_m 成立，则 H_lb(t) ≤ H_true(t) 以概率 ≥ 1−δ_m。使用 H_lb 触发的降级阶梯不会晚于真实失效，故预测误差只导致**过早维护/过早降级**（效率损失），不导致安全损失。系：**这是把 PdM 从「风险源」变成「安全增益」的唯一正确姿势。**

**引理 40（需求模糊度 ⇒ 证据预算单调）** 对固定的证据生成机制，P_δ 越宽（A_t 越大），满足 (q,δ)-充分所需的风险上界越严（取 inf over P_δ），故所需证据量单调不减。系：**需求模糊不是免费的——它在证据预算里付账；「大概安全」不能当「安全」认证。**

**引理 41（无免费推迟与有限最优维护时刻）** 若维护的边际收益有正下界 a>0、证据债务利率有正下界 b>0，则推迟 Δ 的净期望成本增量 ≥ (b−a)Δ 在 a<b 时无界；在 a>b 时推迟收益随 Δ 递减且最终被未来失败风险支配 ⇒ 存在有限最优维护时刻 t*_m。系：**「一直拖」不是最优——与 R73 引理 36 的有限停止同构，但作用在时间轴。**

**引理 42（视界组合：最弱环节，无免费延寿）** SER 串联的风险与退化可加 ⇒ H ≥ min 仅在无额外延迟时取等，一般 H < min；PAR 的融合虽可缩小 u，但若两模块共享退化源（同一热场/振动/光源）则其失效时间相关，融合不能延长 H；仅当条件独立且一致性审计通过，H 才可 ≥ min。系：**视界不会因「多传感器」白送——与 R73「组合不产生认知免费午餐」同型。**

**定理 30（PRISM 严格包含 MODGAUGE）** 取 H=0、ρ 退化为单点 ρ_s、ℳ 为单模型、退化过程恒等（μ=σ=J=0），则 PROG 退化为空、RIM 退化为固定阈值、J_H 退化为 J_MOD，PRISM 逐指令等于 R73；再退化等于 R71/R68。**安全单调不减、效率仅在退化模型与需求后验校准时获益。**

**定理 31（视界证书可靠性 ⇒ 区间安全）** 在 A114–A117（退化过程类正确且可信集覆盖真值；需求后验校准；证据率约束与债务界限可执行；CCA 视界组合可靠）下：Valid(J_H(t,H)) ⇒ 在 [t,t+H] 上 risk ≤ ε 以概率 ≥ 1−δ_cert。**证明重量落在「ℳ_δ 覆盖真退化」与「q_t(ρ) 校准」上**——与 R73 定理 28 的重量落在「契约表达力」完全对应，只是从空间移到了时间。**

**定理 32（预测性降级阶梯细化退化链；预测失败时安全回退）** 对任意预测错误（包括突然跳变、模型外失效），以 H=0 回退到 R73 的反应式 stub 规则，安全性质仍成立，仅视界退化为 0。⇒ 预测性降级是反应式降级的**严格细化**；误报（过早降级）只损失效率，漏报（过晚降级）被悲观下界 H_lb + 反应式兜底双重封锁。系：**安全不依赖预测准确，只依赖「悲观 + 兜底」。**

**定理 33（需求洞察的安全收益及其条件）** 若 q_t(ρ) 校准且对 P_δ 做鲁棒充分性检验，则相对「单点 ρ_s 认证」：(i) 当 ρ_s 欠规格（ρ_s 松于真实需求）时安全严格更优；(ii) 当 ρ_s 过规格时不增加安全但可安全下调证据（效率收益）；(iii) 若自反馈需求松弛发生且无外部锚，则 q_t(ρ_r) 可收敛到严格松于真实需求的固定点，此时任何基于 q_t 的证书都失效。系：**需求洞察的安全价值有前提——需求后验必须被外部锚钉住，否则它会自己骗自己。**

## 6. 本轮最大风险

**一句话**：PRISM 用「预测的寿命」和「推断的需求」为「暂不维护、暂不取证」辩护——预测性维护把安全从测量转移到了退化模型，需求洞察把安全从规格转移到了需求后验，于是系统最危险的状态不再是「证据不足」，而是「**模型和需求都很自信地错**」：此时它会以一份完整的视界证书、闭合的预算和漂亮的审计日志，在最该维护的时候安静地什么都不做。

次级风险与缓解：
1. **退化模型族不完备（ℳ_δ 未覆盖真值）** → 强制包含「突然跳变/黑天鹅」模型 + 悲观下界 + 反应式兜底（定理 32）；离线用 E392/E396 检验覆盖。
2. **需求后验不可校准（人的陈述与行为不一致）** → 外部锚（显式确认/监管约束）+ 单源不定案 + E393 校准审计；未校准则退回单点 ρ_s 并显式标注保守性下降。
3. **自反馈需求松弛固定点** → 行为-需求联合模型 + 漂移检测 + 强制周期性重述（定理 33(iii)）；检测到即锁定证据水平不降。
4. **预测的共因失效（多模块共享热/振/光）** → 环境级共因变量独立监测（继承 R73 风险 5）+ 视界组合禁 PAR 延寿（引理 42）。
5. **维护策略近视（Whittle 索引假设不满足）** → 部署期有限时域 MDP 校验 + 索引策略仅作初值 + 安全约束硬投影。
6. **MB4/MB5 过拟合** → 密封保持集 + 预注册 + 三方复现（E405/E406）。
7. **证据债务被「再融资」（拆东墙补西墙）** → D_e 全局不可转移 + 硬上限 D_max + 审计日志逐周期记账。

| `(q,δ)-充分` | ∀ρ∈P_δ: P(risk_C≤ρ\|E)≥1−α（分布鲁棒） |
| `H_i(t;q)=sup{H:S_i(H)≥1−δ ∧ D_i≠∅ ∧ (q,δ)-充分}` | 需求索引视界 RIVH |
| `H_lb(t)=inf_{ℳ'∈ℳ_δ} H(t;ℳ')` | 悲观视界（模型怀疑 ⇒ 寿命缩短） |
| `J_H(t,H)` | 视界证书：[t,t+H] 区间安全，H→0 退化为 J_MOD |
| `D_e(t)=∫(r_req−r_actual)_+ + Σγ^{Δt}E[补救]` | 证据债务（向模型借钱，越拖越贵） |
| `Priority_i = w_i·P(RUV_i<H)·L_fail/Cost_maint` | 需求驱动维护优先级 |
| `w_i(t)=E_{ρ∼q_t}[∂risk/∂u_i]` | 需求关键度（需求越严/越集中越大） |
| `ℰ_req` | 需求对抗面：欠规格/偏好欺骗/规格投毒/任务迁移/自反馈松弛 |
| `MB4 / MB5` | 预测性维护台 / 需求洞察台 |

## 2. 形式化定义（要点版）

**定义 383（PRISM 总览与六不变式）** 契约时间化 / 需求索引 / 视界声明 / 预测-行动分离 / 需求-证明绑定 / 预测性降级阶梯先于 stub。

**定义 384（退化状态与计量健康）** d_i(t) 的随机过程 + 健康指数 Φ_i；观测量 z_i(t) 全部来自 R73 计量输出——**计量系统就是它自己的状态监测器**。

**定义 385（失效边界与 RUV）** 契约有效 ⇔ u_i(d_i(t)) ≤ τ_i(ρ) ∧ d_i ∈ D_raw；RUV 为首达时 inf{τ>0: u_i>τ_i(ρ)}；**RUV 对 ρ 单调不增**。

**定义 386（生存函数与风险率）** S_i(τ;t) 跨模型后验积分；h_i(τ)=−d ln S_i/dτ；1Hz 更新。

**定义 387（需求洞察 RIM）** q_t(ρ) 贝叶斯后验；ρ_s/ρ_r/P_δ；模糊度 A_t；**需求索引充分性** = 对 P_δ 的最严需求仍满足 risk≤ρ。

**定义 388（需求索引视界 RIVH）** H_i(t;q)=sup{H : S_i(H)≥1−δ_i ∧ 域非空 ∧ (q,δ)-充分}；系统视界按 CCA 组合。

**定义 389（视界证书 J_H）** 模块有效 + RIVH≥H + 鲁棒充分 + 组合合法 + 预算可行 + 债务 D_e≤D_max；Valid ⇒ [t,t+H] 上 risk≤ε 以概率 ≥1−δ_cert；H→0 = J_MOD。

**定义 390（证据债务）** 证据率缺口积分 + 推迟维护的贴现补救成本；D_e≤D_max，γ<1。

**定义 391（维护策略 MES）** 动作集含 re-elicit；目标 = 任务效用 − 维护成本 − 证据成本，硬约束 J_H 在视界内成立；w_i=E[∂risk/∂u_i]。

**定义 392（视界组合）** SER：H=min(H_A,H_B)−δ_comp；PAR：仅当一致性审计 + 退化条件独立才可 H≥min，否则 min；VETO：任一否决 ⇒ H=0。

**定义 393（需求驱动优先级）** Priority_i = w_i·P(RUV_i<H)·L_fail/Cost_maint；决定维护窗口与问询预算。

**定义 394（CRPB）** claim ↦ (ρ_C, proof, requirement-evidence link, 需求校准报告)；过度规格浪费、欠规格不安全，双向审计。

**定义 395（需求腐化）** A_t>A_max 或上下文迁移 ⇒ spec rot，触发 re-elicit；H_req = A 首次越界时间。

**定义 396（预测性降级阶梯）** L0→L1 收紧 λ_floor→L2 缩域→L3 提审率→L4 stub→L5 R68；触发用悲观 RIVH；不得降低他模态保守性。

**定义 397（悲观预测）** H_lb = inf over 可信模型集；模型怀疑 ⇒ 寿命缩短（而非安全放宽）；可信集含黑天鹅模型。

**定义 398（需求对抗面 AIC-REQ）** 五类威胁；防线=外部锚 + 需求校准 + 单源不定案 + 自反馈检测。

**定义 399（MB4/MB5）** 加速退化维护台 / 模糊-演化-欠规格需求台；预注册+固定种子+密封保持集，≤3h 单卡。

**定义 400（成本度量）** CertCost_H / MaintCost / EvidenceDebt；C4/C5 以比值给出可证伪形式。

## 3. 关键算法伪代码

```python
# IP-302 PROG：计量生存分析（计量域 1Hz，复用 R73 计量残差，零新硬件）
class MetrologicalPrognostics:
    def update(self, mod, metrology_hist):
        z = condition_monitor(metrology_hist)        # u_calib/u_interf/残差趋势
        self.d = self.filter.update(self.d, z)       # 退化状态后验（粒子/卡尔曼）
        self.model_post = self.bma.update(z)         # 退化模型后验 Π_t
        return self.d, self.model_post
    def ruv(self, mod, rho, horizon):
        b = mod.ec.threshold(rho)                    # τ_i(ρ)：需求越严越低
        return [first_passage_survival(self.d, self.model_post, b, t) for t in horizon]
    def pessimistic_horizon(self, mod, q, H):
        return min(self.horizon_for(mod, M, q, H)
                   for M in credible_models(self.model_post))   # 模型怀疑 ⇒ 寿命变短

# IP-303 RIM：需求洞察（事件触发 + 每轮）
class RequirementInsight:
    def update(self, obs, ctx):
        self.q = bayes_update(self.q, obs, ctx)      # 陈述/纠正/审计/约束
        self.P_delta = hpd_set(self.q, self.delta)   # 可信需求集
        self.ambiguity = divergence(self.q, self.rho_s)
        if self.detect_feedback_loop(obs):           # 谨慎→放松 的自反馈
            self.external_anchor_required = True     # 强制 re-elicit / 监管锚
        return self.q, self.P_delta
    def robust_sufficient(self, ev, claim, alpha):
        return all(risk_bound(ev, claim, rho) <= rho
                   for rho in self.P_delta), self.worst_rho()   # 对最严需求都要满足

# IP-304 RIVH + IP-305 MES：视界与需求驱动维护
def viability_horizon(modules, q, H):
    H_i = {i: m.prog.pessimistic_horizon(m, q, H) for i, m in modules.items()}
    return compose_horizons(H_i, modules.mreg)       # SER/PAR/VETO（定义 392）

def maintenance_step(modules, q, D_e, H):
    pr = {i: priority(m, q, H) for i, m in modules.items()}   # w_i·P(RUV<H)·L/C
    a = solve_index_policy(pr, modules, D_e, H)      # Whittle/有限时域 MDP
    if a.kind == 're-elicit': return ask_human(a.rho_axis)    # 需求侧维护
    if a.kind in ('recalibrate', 'replace'): schedule(a)
    return a, D_e + debt_increment(a)

# IP-306 CRPB + IP-307 PRISM 主闭环（复用 R73 三域）
def PRISM_round(M, obs, audio, tac_frame, depth_img):
    # 感知域（100Hz）
    d_ev = M.dpe.update(depth_img, rgb, M.cam_state, M.motion, M.peers)
    q, P_delta = M.rim.update(extract_req_obs(obs, audio), M.ctx)   # 需求后验
    # 计量域（50Hz）
    if M.clock.due_metric():
        for mod in M.mods.values(): M.prog[mod].update(mod, M.metrology_hist[mod])
        H_sys = viability_horizon(M.mods, q, M.H)                   # IP-304
        if not M.cert.horizon_valid(H_sys):                         # 视界证书失效
            a, M.debt = maintenance_step(M.mods, q, M.debt, M.H)    # IP-305
        M.mode = degradation_ladder(M.mods, q)                      # L0..L5（悲观触发）
        b_t = M.bse.step_full(..., d_ev=d_ev, t_ev=M.dmem.update(tac_frame, M.last_action))
        M.snapshot.write(b_t, q, H_sys, M.debt, M.mode)
    # 控制域（1kHz，继承 R73；λ 由视界风险膨胀调制）
    snap = M.snapshot.read_latest()
    lam = embodied_risk_scale(snap.U_ale, snap.U_epi, snap.H_z,
                              max(snap.t_ev.u, snap.d_ev.u), M.risk_params) \
          * (1 + M.kappa * risk_inflation(snap.H_sys, q))
    A = M.ach.propose_ctrl(..., pvop_bias=snap.pvop); k = M.c_ras_wm.certified_prefix(A, lam)
    M.ctrl_out.publish(k, lam); M.cert_ctrl.write(k=k, lam=lam, breaker=M.breaker.status())
    return k, lam, J_H(M, H_sys)                                # 视界证书（定义 389）
```

## 4. 推导

**引理 38（需求索引寿命单调性）** d_i(t) a.s. 非降且 u_i 对 d_i 单调 ⇒ RUV 良定义、S_i 对 τ 单调不增；τ_i(ρ) 对 ρ 单调不增 ⇒ **RUV 对 ρ 单调不增**。系：脱离需求谈 RUL 无意义。

**引理 39（悲观预测安全性）** ℳ*∈ℳ_δ 以概率 ≥1−δ_m ⇒ H_lb ≤ H_true 以概率 ≥1−δ_m；用 H_lb 触发降级不会晚于真实失效 ⇒ **预测误差只花效率、不花安全**。系：PdM 从风险源变为安全增益的唯一正确姿势。

**引理 40（需求模糊度 ⇒ 证据预算单调）** P_δ 越宽 ⇒ 鲁棒充分性取 inf over P_δ ⇒ 所需证据量单调不减。系：需求模糊不免费，必须在预算里付账。

**引理 41（无免费推迟与有限最优维护）** 维护边际收益正下界 a、债务利率正下界 b ⇒ 推迟的净成本增量可控，存在有限最优维护时刻 t*_m。系：与 R73 引理 36 有限停止同构，作用于时间轴。

**引理 42（视界组合最弱环节）** SER 风险/退化可加 ⇒ 一般 H<min；PAR 若共享退化源（热/振/光）则失效相关，融合不延寿；仅条件独立且一致性审计通过才可 H≥min。系：视界不因多传感器白送。

**定理 30（PRISM 严格包含 MODGAUGE）** H=0、ρ→ρ_s、ℳ 单模型、退化恒等 ⇒ PROG 空、RIM 固定阈值、J_H=J_MOD，逐指令等于 R73；再退化等于 R71/R68。安全单调不减。

**定理 31（视界证书可靠性 ⇒ 区间安全）** 在 A114–A117 下，Valid(J_H(t,H)) ⇒ [t,t+H] 上 risk≤ε 以概率 ≥1−δ_cert。**证明重量落在 ℳ_δ 覆盖真退化与 q_t(ρ) 校准**——对应 R73 定理 28 的「契约表达力」，从空间移到时间。

**定理 32（预测性降级是反应式降级的严格细化；预测失败安全回退）** 任意预测错误下以 H=0 回退 R73 stub，安全仍成立、视界归零；误报只损失效率，漏报被悲观下界 + 反应式兜底双重封锁。系：**安全不依赖预测准确，只依赖悲观 + 兜底。**

**定理 33（需求洞察的安全收益及其条件）** q_t 校准且对 P_δ 鲁棒 ⇒ (i) ρ_s 欠规格时安全严格更优；(ii) ρ_s 过规格时不增安全但可安全减证据；(iii) 若自反馈松弛且无外部锚，q_t(ρ_r) 收敛到松于真实需求的固定点，基于 q_t 的证书全部失效。系：需求后验必须被外部锚钉住。

## 7. 本轮最大风险

**一句话**：PRISM 用「预测的寿命」和「推断的需求」为「暂不维护、暂不取证」辩护——预测性维护把安全从测量转移到了退化模型，需求洞察把安全从规格转移到了需求后验，于是系统最危险的状态不再是「证据不足」，而是「**模型和需求都很自信地错**」：此时它会以一份完整的视界证书、闭合的预算和漂亮的审计日志，在最该维护的时候安静地什么都不做。

次级风险与缓解：
1. **退化模型族不完备** → 强制含黑天鹅模型 + 悲观下界 + 反应式兜底（定理 32）+ E392/E396 覆盖检验。
2. **需求后验不可校准** → 外部锚 + 单源不定案 + E393 校准审计；未校准则退回单点 ρ_s 并标注保守性下降。
3. **自反馈需求松弛固定点** → 行为-需求联合模型 + 漂移检测 + 强制重述（定理 33(iii)），检测即锁定证据水平不降。
4. **退化共因（热/振/光）** → 环境级共因变量独立监测 + 视界组合禁 PAR 延寿（引理 42）。
5. **维护策略近视** → 有限时域 MDP 校验 + 索引策略仅作初值 + 安全约束硬投影。
6. **MB4/MB5 过拟合** → 密封保持集 + 预注册 + 三方复现（E405/E406）。
7. **证据债务「再融资」** → D_e 全局不可转移 + 硬上限 + 逐周期审计记账。
