# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；本轮灵感循环第 1 轮；本轮灵感：「路径规划」×「腕部相机」）

> 第 54 轮已把技能组合推进到动作空间剖面 `α_S` 与云边动作-鲁棒联合证书 `J`，但仍隐含假设“执行时看得见目标”。本轮引入 **腕部相机（eye-in-hand）** 这一随动传感器，把路径规划从“几何/动作可行”扩展为 **可观测性约束下的视-动联合规划**。核心矛盾：**H22** 几何可行 ≠ 视觉可观测（出视场、自遮挡、运动模糊）；**H23** 观测依赖动作、动作又依赖观测，形成动态耦合；**H24** 云端粗路径的可见性假设在边端腕部相机的细粒度观测上失效，需要可传递的可见性证书。

## 0. 直觉与动机

**灵感 1（腕部相机是把路径“看”出来的传感器）**
直觉：传统路径规划只问“走不走得通”，腕部相机却追问“走的过程中看不看得见”。腕部相机随末端运动，近距离、高分辨率，但视场窄、易被末端执行器/工件/自身臂遮挡、快速运动产生模糊。同一条几何无碰路径，可能在某些段“盲走”。因此路径上的每个位姿都应附加一个**可观测性标签**，规划目标从“几何可达”升级为“几何可达 × 视觉可观测”。

**灵感 2（运动模糊给出速度上限 → 轨迹自带速度-清晰度包络）**
直觉：曝光时间 `t_exp` 内相机随末端移动，像点被拉成线段。横向速度越大、深度越近、焦距越长，模糊越重。给定允许模糊 `b_max`，可反解每段的横向速度上限。于是**路径规划自动产生限速曲线**：越靠近目标（深度 `z` 小）越要慢。这是硬约束而非软惩罚，会直接挤压云边协同的时间预算。

**灵感 3（遮挡与视场 → 可见集是路径投下的“影子”）**
直觉：腕部相机能否看见目标，由“相机-目标”视线与视锥共同决定。末端执行器、工件、机械臂自身都可能挡住视线。定义沿路径累积的可见集 `V(τ)`；只有任务关键点始终在 `V(τ)` 内，视觉伺服才有意义。可见集像路径投下的影子，影子必须罩住目标。

**灵感 4（观测-动作耦合 → 主动感知而非被动记录）**
直觉：动作决定视角，视角决定不确定度，不确定度又决定下一步动作。这天然是 POMDP/主动感知问题：局部可以“多看一眼”（next-best-view）以降低位姿不确定性，但会偏离全局路径、增加时间。规划需在**信息增益**与**路径代价**之间折中，而不是把相机当作事后记录器。

**灵感 5（云边视-动闭环 → 把 Explain 从动作失败扩展到感知失败）**
直觉：云端用粗略几何与名义可见性规划全局路径；边端用腕部相机实时估计可见性并在失败前做局部修正；若仍失败，把“哪一段、为什么看不见（出视场 / 遮挡 / 模糊）”作为根因回传，云端重规划。这把第 54 轮的“动作-鲁棒”闭环升级为 **视觉-动作-鲁棒三闭环**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（腕部可观测剖面）**
设任务关键点集 `O`，路径段 `τ:[0,1]→SE(3)`，腕部相机模型 `C=(f,p,t_exp,F,z_min,z_max)`（焦距、像元尺寸、曝光时间、视锥、深度范围）。可观测质量
```
ω(τ,o) = φ_fov(τ,o) · φ_occ(τ,o) · φ_blur(τ,o) · φ_res(τ,o) ∈ [0,1]
```
- `φ_fov ∈ {0,1}`：`o` 是否在视锥 `F` 内；
- `φ_occ ∈ {0,1}`：相机-`o` 视线是否无遮挡；
- `φ_blur = clip(1 - b(τ,o)/b_max, 0, 1)`；
- `φ_res = clip(z_ref/z(τ,o), 0, 1)`，表示近距分辨率增益。
其中模糊 `b(τ,o) = ||v_⊥(τ)||·t_exp·f / (z(τ,o)·p)`，`v_⊥` 为相对目标的横向速度。

**定义 122（视-动联合可行路径）**
路径 `τ` 视-动可行当且仅当
```
τ ∈ Ξ_geo ∩ Ξ_obs ∩ Ξ_dyn
Ξ_obs = { τ | ∀o∈O, ω(τ,o) ≥ θ_obs }
Ξ_dyn = { τ | b(τ,o) ≤ b_max ∀o, 且满足关节/加速度约束 }
```
即几何无碰、全程可观测、速度-清晰度包络内三者同时成立。

**定义 123（可见性证书）**
```
V_cert = (V_core, V_buffer, δ_v, b_max, O_map, S_vis)
```
- `V_core = { o | min_{τ} ω(τ,o) ≥ θ_obs }`：路径上始终可见的核心目标集；
- `V_buffer = { o | min_{τ} ω(τ,o) ≥ θ_obs - δ_v }`：容错带；
- `δ_v`：可见性裕度误差上界；
- `O_map`：遮挡图（保守膨胀后的占据/遮挡体）；
- `S_vis`：可见性采样证据（视点、深度、实测模糊）。
**证书有效** 当且仅当 `V_core ⊇ O_T` 且 `δ_v ≤ Θ_v`。

**定义 124（视-动规划成本）**
```
cost_VAMP(τ) = w_g·L(τ)
             + w_o·(1 - (1/|O|)Σ_o ω(τ,o))
             + w_b·∫ b(τ(s))/b_max ds
             + w_s·∫ ||κ(s)||² ds
             - w_i·IG(τ)
s.t.  τ ∈ Ξ_geo ∩ Ξ_obs ∩ Ξ_dyn
```
`IG(τ)` 为视差带来的信息增益（降低目标位姿/深度不确定性），`κ` 为曲率。前三项分别度量长度、可观测性、模糊，末项奖励主动感知。

**定义 125（云边视-动契约）**
```
C_ve = (P_c, P_e, E_vis, Explain_vis)
```
- `P_c`：云端粗路径与可见性包络 `(V_core^c, b_max^c)`；
- `P_e`：边端细路径，须满足 `V_core^c ⊆ V_core^e` 且 `b_max^e ≤ b_max^c`；
- `E_vis`：可见性对齐误差 `|V_core^c - V_core^e|`；
- `Explain_vis`：感知失败根因映射 `(段索引, cause∈{fov,occlusion,blur}) → ΔP_c`。

**定义 126（视-动-鲁棒联合证书）**
```
JV = (J, V_cert, δ_v, b_env)
```
其中 `J` 为第 54 轮动作-鲁棒联合证书，`b_env` 为速度-清晰度包络（每个深度段的最大允许速度）。**可部署** 当且仅当 `dom_JV(T)=in`、`δ_v ≤ Θ_v`、且 `b_env` 在边端时序预算 `τ_e` 内可满足。

## 2. 关键算法 伪代码

### IP-121 VAP（Visibility-Aware Planner）

```python
def visibility_aware_plan(x_start, O, cam, occ_map, budget):
    tree = Tree(x_start)
    while not budget.exhausted():
        x_rand = sample_se3()
        x_near = tree.nearest(x_rand)
        seg = steer_with_speed_bound(x_near, x_rand, cam, O)
        if seg is None:
            continue
        if not omega_ok(seg, O, cam, occ_map, theta_obs):
            continue
        c = cost_vamp(seg, O, cam, occ_map)
        tree.insert(seg, c)
        if reaches(seg, goal):
            path = extract_path(tree)
            return path, build_visibility_cert(path, O, cam, occ_map)
    return None
```

### IP-122 OCM（Observation Coupling Model）

```python
def blur(seg, cam, o):
    v = max_transverse_speed(seg)
    z = depth(seg, o)
    return v * cam.t_exp * cam.f / (z * cam.pixel_pitch)

def speed_limit(cam, z):
    return cam.b_max * z * cam.pixel_pitch / (cam.f * cam.t_exp)

def omega(seg, o, cam, occ_map):
    if not in_frustum(o, seg.pose, cam):
        return 0.0
    if ray_blocked(seg.pose, o, occ_map):
        return 0.0
    b = blur(seg, cam, o)
    phi_blur = max(0.0, 1.0 - b / cam.b_max)
    phi_res = min(1.0, cam.z_ref / depth(seg, o))
    return phi_blur * phi_res

def steer_with_speed_bound(x0, x1, cam, O):
    seg = interpolate(x0, x1)
    for o in O:
        z = min_depth_on_seg(seg, o)
        if seg.max_speed > speed_limit(cam, z):
            seg = time_scale(seg, speed_limit(cam, z) / seg.max_speed)
    return seg
```

### IP-123 VCC（Visibility Certificate Chain）

```python
def compose_visibility(certs, delta_v_budget):
    V_core = reduce(intersect, [c.V_core for c in certs])
    V_buffer = reduce(intersect, [c.V_buffer for c in certs])
    delta_v = sum(c.delta_v for c in certs)
    b_max = min(c.b_max for c in certs)
    if delta_v > delta_v_budget or not V_core:
        return ('reject', 'visibility_gap', delta_v)
    return ('ok', VCert(V_core, V_buffer, delta_v, b_max,
                         merge_occlusion_maps(certs)))
```

### IP-124 NBVS（Next-Best-View Servoing）

```python
def nbv_servo(x_cur, o, cam, occ_map, global_path, dev_budget):
    best, best_score = None, -inf
    for x in sample_viewpoints(x_cur, radius=cam.nbv_radius):
        dev = path_deviation(x, global_path)
        if dev > dev_budget:
            continue
        if not omega_ok_segment(x_cur, x, o, cam, occ_map, theta_obs):
            continue
        ig = information_gain(x_cur, x, o, cam, occ_map)
        score = ig - lambda_dev * dev
        if score > best_score:
            best, best_score = x, score
    return best
```

### IP-125 CERP（Cloud-Edge Replan on Perception failure）

```python
def perception_replan(P_c, report, G, V_cert):
    if report.cause in ('fov', 'occlusion'):
        V_core = shrink_visible_set(V_cert.V_core, report.segment)
        return cloud_replan(P_c, constraints={'V_core': V_core})

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| VAP | O(N log N·\|O\|·r) | O(N) | 采样覆盖、速度包络不下溢 |
| OCM | O(\|O\|) / 段（射线求交 O(log M)） | O(M) | 相机模型标定、遮挡图保守 |
| VCC | O(k·\|O\|) | O(\|O\|) | 可见集交集保守、δ_v 可加 |
| NBVS | O(M·\|O\|) | O(M) | 视点库覆盖、偏差预算 |
| CERP | O(\|V\| log \|V\| + \|E\|) | O(\|V\|+\|E\|) | 根因可定位、重规划收敛 |

**模糊-速度硬约束推导**
针孔模型下，曝光 `t_exp` 内的像素模糊近似
```
b_px = (v_⊥ · t_exp · f) / (z · p)
```
要求 `b_px ≤ b_max`，得
```
v_⊥ ≤ v_max(z) = b_max · z · p / (f · t_exp)
```
取 `f=4mm, p=2μm, t_exp=5ms, b_max=2px`，则 `v_max(z)=0.2·z m/s`：

| 深度 z (m) | 0.15 | 0.30 | 0.50 | 1.00 |
|---|---|---|---|---|
| 速度上限 (m/s) | 0.030 | 0.060 | 0.100 | 0.200 |

**关键结论**：腕部相机越贴近目标，允许速度越低，近距离作业的轨迹被强制拉长——这正是云端粗规划最容易忽略、边端最容易失败的地方。

**正确性定理（Visibility-Aware Planning Soundness）**
假设第 54 轮 (A22)–(A28) 成立；**(A29)** `ω` 由结构化标定与仿真校准；**(A30)** 遮挡图 `O_map` 对真实遮挡体保守（无假可见）；**(A31)** 模糊模型误差有界、深度估计给出保守下界；**(A32)** Explain 回传与重规划在 `τ_loop` 内收敛。则
```
P(success) ≥ 1 - Σ_k P(ω_k < θ_obs) - P(δ_v > Θ_v)
              - β_E - P(replan 不收敛 | 感知失败)
```
其中求和覆盖路径段。**保守遮挡图 + 深度下界**保证 `V_cert` 不产生“假可见”，这是证书 soundness 的核心。

## 6. 本轮最大风险

**一句话**：可见性证书的最大风险是移动腕部相机下的“静态采样幻觉”——遮挡图与模糊模型若只在离散视点标定，连续轨迹上的自遮挡与深度突变会让 `V_cert` 在段间失效，云端以为可见、边端实际盲走；因此必须以 **保守视线膨胀 + 在线模糊校核 + 感知失败回传** 三重护栏，严格区分“看过”与“看得见”。

def cost_vamp(seg, O, cam, occ_map):
    geo  = seg.length
    obs  = 1 - mean([omega(seg, o, cam, occ_map) for o in O])
    blur = integral(seg, lambda s: blur(s, cam, O) / cam.b_max)
    curv = integral(seg, lambda s: curvature(seg, s) ** 2)
    ig   = information_gain_seg(seg, O, cam)
    return w_g*geo + w_o*obs + w_b*blur + w_s*curv - w_i*ig
```

    V_core   = reduce(intersect, [c.V_core for c in certs])
    V_buffer = reduce(intersect, [c.V_buffer for c in certs])
    delta_v  = sum(c.delta_v for c in certs)
    b_max    = min(c.b_max for c in certs)
    if delta_v > delta_v_budget or not V_core:
        return ('reject', 'visibility_gap', delta_v)
    return ('ok', VCert(V_core, V_buffer, delta_v, b_max,
                         merge_occlusion_maps(certs),
                         merge_evidence(certs)))

### IP-124 NBVS

```python
def nbv_servo(x_cur, o, cam, occ_map, global_path, dev_budget):
    best, best_score = None, -inf
    for x in sample_viewpoints(x_cur, radius=cam.nbv_radius):
        dev = path_deviation(x, global_path)
        if dev > dev_budget:
            continue
        if not omega_ok_segment(x_cur, x, o, cam, occ_map, theta_obs):
            continue
        ig = information_gain(x_cur, x, o, cam, occ_map)
        score = ig - lambda_dev * dev - lambda_t * travel_time(x_cur, x)
        if score > best_score:
            best, best_score = x, score
    return best
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| VAP | O(N log N·\|O\|·r) | O(N) | 采样覆盖 ≥ 95%，速度包络不下溢 |
| OCM | O(\|O\|)（射线 O(log M)） | O(M) | 相机模型标定，遮挡图保守 |
| VCC | O(k·\|O\|) | O(\|O\|) | 可见集交集保守，δ_v 可加 |
| NBVS | O(M·\|O\|) | O(M) | 视点库覆盖，偏差预算闭合 |
| CERP | O(\|V\| log \|V\| + \|E\|) | O(\|V\|+\|E\|) | 根因可定位，重规划收敛 |
| JVC | O(VAP + k·\|O\|) | O(N+\|O\|) | 三证一致，时序预算可满足 |

**速度-清晰度包络（可计算推导）**
```
b_px = v_⊥·t_exp·f / (z·p) ≤ b_max
⇒ v_⊥ ≤ v_max(z) = b_max·z·p / (f·t_exp)
```
取 `f=4mm, p=2μm, t_exp=5ms, b_max=2px`，得 `v_max(z)=0.2z m/s`：

| 深度 z (m) | 0.15 | 0.30 | 0.50 | 1.00 |
|---|---|---|---|---|
| 速度上限 (m/s) | 0.030 | 0.060 | 0.100 | 0.200 |

推论：近距离精作业阶段腕部相机要求更低速度，轨迹时长被强制拉长；云端必须在 `τ_e` 预算中显式预留这段“看得清的代价”。

**正确性定理（Visibility-Aware Planning Soundness）**
假设第 54 轮 (A22)–(A28) 成立；**(A29)** `ω` 经结构化标定/仿真校准；**(A30)** `O_map` 对真实遮挡体保守；**(A31)** 模糊模型误差有界，深度取保守下界；**(A32)** Explain 回传与重规划在 `τ_loop` 内收敛。则
```
P_success ≥ 1 - Σ_k P(ω_k < θ_obs) - P(δ_v > Θ_v)
              - β_E - P(replan 不收敛 | 感知失败)
```
**关键**：可见性证书 soundness 来自“遮挡保守 + 深度下界 + 最坏模糊传播”，任一环节乐观化都会产生假可见。

## 6. 本轮最大风险

**一句话**：可见性证书的最大风险是移动腕部相机下的“静态采样幻觉”——遮挡图与模糊模型若只在离散视点标定，连续轨迹上的自遮挡与深度突变会让 `V_cert` 在段间失效，云端以为可见、边端实际盲走；因此必须以 **保守视线膨胀 + 在线模糊校核 + 感知失败回传** 三重护栏，严格区分“看过”与“看得见”。
