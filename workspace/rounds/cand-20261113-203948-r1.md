# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；本轮灵感：「数据采集」×「Isaac Sim」）

> R69 的 FLUID-RAS 干了一件漂亮事：把「不确定」拆成 aleatoric 与 epistemic，让系统学会「问」。但它留下了一张没有兑现的支票——**MCG（定义 306）要求模态权重是校准的（ECE ≤ τ_ece），却从没回答：这张校准凭证是谁签发的、凭什么信、过期了怎么办**。如果没有数据能识别模态后验，MCG 要么永远失败（FLUID 退化成 R68，效率收益为零），要么在错误的数据上通过（VoI 建立在幻觉模态上，比不交互更危险）。R69 自陈的最大风险——「问错，比不问更危险」——其根因不在交互层，而在**校准层缺少可识别性**。
>
> 本轮两个灵感正好补这块地基：
> - **数据采集**提醒我们：校准不是训练超参，而是一个**因果可识别性问题**——被动日志里你永远看不到「反事实动作」，因此模态后验不可辨识；只有**干预**才能把「歧义」变成有标签的数据。
> - **Isaac Sim** 提供一个可重放、可分支、可固定 nuisance 的**反事实干预机**：同一场景、同一物理、只改潜模态，就能采到成对观测与真值模态标签。但仿真本身也是一个模型——**用它校准策略，等于让模拟器给自己的考卷打分**，必须再用真实锚点做外部审计。
>
> 核心命题：**把 R69 的全局 ECE 门，升级为「地域化 + 可审计 + 失败闭合」的校准凭证系统**——只有同时满足（i）仿真干预可识别、（ii）真实锚点可桥接、（iii）采集无自噬偏差 的**状态区域**，才允许解锁 VoI；其余区域逐指令退回 R68。数据采集本身也升级为一类**带预算、有偏、会自我实现**的决策动作，由 VoI 驱动，并配随机探索底噪与留出审计。
>
> 命名 **CALIBRA-RAS**（Calibrated Interventional Bridge for Region-aware Ambiguity）。一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我凭什么相信自己知道该问谁——我的怀疑本身是在哪个世界里校准的**」——信任不能自签，校准必须过桥。

## 0. 直觉与动机

**灵感 1（数据采集 → 被动数据不可识别，干预数据才可以）**
直觉：R69 想让模态权重可信。但现实中你只有「人最终做了什么」的日志，永远不知道「如果当时他其实想走另一边，会怎么做」——潜模态 M 在观测数据里是不可见的。Isaac Sim 的价值不在于「更多数据」，而在于**可以造出反事实对**：固定场景与扰动，只把潜意图从「绕左」切到「绕右」，得到两条只差模态的轨迹。于是「模态后验」第一次有了可监督标签。这是从 observational 到 interventional 的跃迁，也是校准能否成立的分水岭。

**灵感 2（Isaac Sim → 高保真不是重点，可干预 + 可复现才是）**
直觉：很多人把仿真当「便宜的数据工厂」，比谁更真。但对校准而言，关键属性是四点：可 reset / 可分支（反事实）、可固定 nuisance（去混淆）、可版本化（凭证可追溯）、可对抗（能主动构造边界场景）。Isaac Sim 的 scene graph、Replicator、域随机化、物理参数、传感器噪声模型恰好提供这四点。**高保真只影响 sim-real 差距 δ_T 的大小，可干预才决定校准是否可识别**——前者是精度问题，后者是存在性问题。

**灵感 3（校准要局部化 → 全局 ECE 是统计幻觉）**
直觉：一个机器人在「空旷走廊」里模态很可信，在「人群密集、表情暧昧」处完全不可信；全局 ECE 把两者平均成一个「看起来合格」的数字，却在关键区域放行 VoI。正确做法是把状态空间划成区域，每区一张校准证书；**证书是局部的、带样本量下限、带有效期的**。这把 R69 的 MCG 从「全局开关」升级为「区域通行证」，也让「覆盖率」成为一等公民——系统明确知道自己**在多大比例的状态上被允许怀疑**。

**灵感 4（数据采集本身是行动 → 会自我实现、会 Goodhart）**
直觉：如果让策略自己决定「去哪里采数据」，它一定去自己最困惑的地方；采回来再训练，模型在该处变自信，测得的 ECE 下降——但真实部署分布上的 ECE 可能上升。**你测到的是你自己挑出来的世界**。这就是校准的 Goodhart：主动采集把「校准」变成「自我安慰」。必须引入随机探索底噪、固定分布的留出审计流、以及「采集策略不得选择审计集」的隔离。数据采集因此不是预处理，而是一个需要证据纪律的闭环决策动作。

**灵感 5（信任链 → 三道审计，失败闭合）**
直觉：完整的信任链是 现实 →(锚点)→ 仿真标签 →(桥接)→ 校准 →(模态)→ 流策略 → VoI → 动作。任何一环都不能自证：仿真不能给自己发证，流模型不能给自己的模态打分，采集策略不能给自己的数据盖章。于是本轮交付三样东西：**反事实可识别性**（数据层）、**真实锚桥 + 加权保形**（迁移层）、**反自噬审计 + 失败闭合**（治理层）。任一环断裂，系统只允许退回 R68 的「诚实保守」——**宁可不知道自己不知道，也不能假装知道自己知道**。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（CALIBRA-RAS 总览）** CALIBRA-RAS = (CID, LCM, RAB, CRG, AVO, ACM, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i、R69 定义 293-i）；
(ii) **校准凭证不可自签**：任何模态校准结论必须至少含一个非自生成数据源（仿真干预或真实锚点），且经 RAB 桥接；单一来源不得解锁 VoI；
(iii) **失败闭合（fail-closed）**：证书链任一环缺失、越界或被投毒 ⇒ 该区域退回 R68，且不得用「补采数据」绕过审计。

**定义 311（潜模态与因果目标）** 设结构因果模型 (M, N, O, A)：M ∈ {1..K} 为潜模态（意图/动作分支），N 为 nuisance（场景、光照、人体尺度、传感器噪声），O 为观测，A 为动作。部署目标是因果后验 π(M|O)，而非仅相关后验。假设 **A99**：M 在给定 N 下外生、无未观测混淆、正性 ∀m: p(M=m|N)>0。A99 是全部可识别性论证的前提，且必须在证书里显式声明、可被审计推翻。

**定义 312（反事实干预数据 CID）** 一个数据单元 d = (n, do(M=m), o, ξ*, c, h)，其中 n 固定 nuisance，o 为观测，ξ* 为参考动作块，c 为采集成本，h 为可复现哈希。成对单元 𝒫 = {(d_m, d_m′) : n 相同、仅 m≠m′}。干预在 Isaac Sim 中由场景分支 + 固定随机种子 + 固定物理参数实现，故 p(o|do(M=m), N=n) 可重放。记干预数据集为 D_int；核心要求是**配对差只含模态变量**。

**定义 313（区域划分与局部校准 LCM）** 划分 φ: 𝒪 → ℛ（由 mode_head 嵌入 + 局部敏感哈希，或浅层决策树得到，保证每格可解释、可复现）。区域 r 的局部校准误差 ECE_r = Σ_b (|B_b|/n_r)·|acc(B_b) − conf(B_b)|，并记录可靠图单调性与样本量 n_r。全局 ECE 是 ECE_r 的加权平均——**平均值合格不代表每个区域合格**。

**定义 314（认证区域与覆盖率）** 区域 r 被认证（r ∈ 𝒞）当且仅当：ECE_r ≤ τ_ece、n_r ≥ n_min、桥接差异 δ_T(r) ≤ τ_b、来源哈希校验通过、且反自噬审计通过（定义 318）。覆盖率 cov = P_deploy(𝒞) = Σ_{r∈𝒞} P_deploy(r)。证书只对「认证区域 × 有效期 × 仿真版本」成立。

**定义 315（真实锚桥 RAB）** 小规模真实锚点集 D_real = {(o, m_verified)}，m_verified 来自遥操作真值、专家复核或可验证的任务结果。在区域 r 上估计重要性权重 w_r(o) = dP_real/dP_sim，桥接差异 δ_T(r) = TV(P_real(·|r), P_sim(·|r))（或 MMD / 分类器双样本检验），并要求权重有界、正性成立（A100）。**仿真再高保真也只是降低 δ_T；只有真实锚点能证明 δ_T 小**。锚点是有成本的「现实签名」。

**定义 316（区域校准门 CRG，升级 MCG）** 在状态 s 处，若 φ(s) ∈ 𝒞，允许 MINT 计算 VoI 并执行交互；否则禁用 VoI，逐指令走 R68 纯保守兜底（λ = λ_floor(U_ale + U_epi)）。若 𝒞 = ∅，则全局退化 R68。CRG 把 R69 的「ECE ≤ τ_ece」全局断言替换为「该状态所在区域有未过期的、可审计的证书」。

**定义 317（采集价值 AVoI）** 候选数据单元 d 的采集价值 AVoI(d) = E_{D∪d}[R_deploy(π)] − E_D[R_deploy(π)]，工程近似为
AVoI(d) ≈ leverage(d) × miscalibration(r_d) × bridgeability(r_d) / cost(d)，
三项分别对应「该区域的决策影响多大」「当前有多不准」「桥接后多可信」。选择 d* = argmax_d [AVoI(d) − c(d)]，s.t. 采集预算、真实采集的物理/社会风险 ≤ ε_acq。若 max[AVoI−c] ≤ 0：停止采集（数据饱和）。

**定义 318（反自噬采集纪律 ACM）** 采集策略以概率 1−ε 选择当前最不确定区域、以 ε 均匀随机探索；审计集 D_audit 独立同分布于**固定的部署分布**，其抽样不受采集策略影响（物理隔离）；证书必须报告自噬偏差界 bias_bound(ε, n_audit)。若 ε=0 或审计集被采集分布污染，则校准读数失效——**这正是 Goodhart 的形式化入口**。

**定义 319（加权保形模态集 WCS）** 不直接信模态点权重，输出模态集 C_α(o) ⊆ {1..K}，使 P(M ∈ C_α(o)) ≥ 1−α。用 RAB 权重做加权保形（weighted conformal），在 A100 下给出分布无关覆盖保证；集合大小 |C_α| 本身是决策相关的 epistemic 度量：集合大 ⇒ 不可定案，走 R68。这样即使流模型模态权重有偏，保形覆盖仍可守住一个可证明的下界。

**定义 320（缺口感知回退 DPF）** 若区域未认证、δ_T(r) > τ_b、|C_α| > κ_max、来源哈希失效或证书过期，则强制回退：把未消解 epistemic 视同 aleatoric，λ = λ_floor(U_ale + U_epi)，且交互动作 g 作废。回退是**单调收紧**的，绝不因「再采一点数据」而临时放宽。

**定义 321（数据来源与仿真版本）** 溯源元组 prov = (sim_ver, scene_hash, physics_params, seed, asset_ids, sensor_noise_model, intervention_log_hash)。任何物理参数、资产或版本变更都**使下游证书失效**并触发再校准。证书带 TTL（time-to-live）；过期即撤销。没有溯源的「校准」不是凭证，只是传闻。

**定义 322（仿真投毒与干扰集 ℰ_sim）** 把仿真视为**不可信预言机**：物理偏差、模态标签污染、对抗性场景选择、只演示漂亮场景的「demo 过拟合」、以及锚点被敌手挑选。扩展干扰集 ℰ_CALIBRA = ℰ_FLUID × ℰ_sim × ℰ_incest（自噬）。对抗训练与红队场景生成都以此为目标分布。

**定义 323（证书 J_CALIBRA）** J_CALIBRA = (J_FLUID, region_id, region_coverage, local_ece_max, bridge_discrepancy, avoi_ratio, audit_bias_bound, conformal_coverage, provenance_hash, calibra_ver)。Valid ⇔ Valid(J_FLUID) ∧ 该区域已认证 ∧ 覆盖率满足其 VoI 声明 ∧ 反自噬审计通过 ∧ 溯源未失效。

**定义 324（区域局部包含）** 形式化陈述见定理 18：𝒞 内逐指令等于 FLUID（风险 ≤ R68 且享 resolution bonus），𝒞 外逐指令等于 R68。R69 是「𝒞 = 全域且证书为真」的理想边界；R70 把不可检验的理想条件替换为可检验、可失效、可撤销的证据条件。

**定义 325（非平稳与再校准触发）** 真实锚点流上的漂移监视器持续估计 δ_T(r) 与局部 ECE 的偏移；当 δ_T(r) 或 ECE_r 超过阈值、或保形覆盖率跌破 1−α、或 provenance 变更时，**撤销受影响区域的证书**并触发一轮 AVoI 采集。证书是有寿命的资产，不是一次性成就。

**定义 326（采集-交互对偶）** R69 的 MINT 在推理时「问世界」，R70 的 AVO 在采集时「问仿真/现实」；两者都以 VoI 为目标，但前者改变信念、后者改变模型。组合约束：采集不得直接为某次交互「背书」，交互也不能用未认证区域的数据临时提升置信；二者共享预算账本，**任何一侧的超支都不得由另一侧的事后收益冲抵**。

# IP-264 CID：Isaac Sim 反事实成对干预采样（离线）
def counterfactual_pairs(sim, scene, nuisance, modes, seed):
    sim.reset(scene, nuisance, seed)                  # 固定 N 与物理
    pairs = {}
    for m in modes:
        sim.set_latent_mode(m)                        # do(M=m)
        o, xi = sim.rollout()                         # 可重放观测与参考动作
        pairs[m] = (o, xi, hash(sim.state()))
    return [ (pairs[m], pairs[m2]) for m, m2 in combinations(modes, 2) ]

# IP-265 LCM：区域划分 + 局部校准
def local_calibration(D_int, phi, tau_ece, n_min):
    cells = group_by(D_int, key=lambda d: phi(d.o))
    cert = {}
    for r, data in cells.items():
        ece = expected_calibration_error(data)
        cert[r] = (ece, len(data), reliability_diagram(data))
    return cert

# IP-266 RAB：真实锚点桥接差异
def transfer_discrepancy(D_real, D_sim, phi, r):
    wr = fit_density_ratio(D_sim_cell(r), D_real_cell(r))   # 有界、正性检验
    return tv_distance(weighted(D_sim_cell(r), wr), D_real_cell(r)), wr

# IP-267 CRG：认证区域图（含反自噬与溯源校验）
def certified_region_map(cert, bridge, audit, prov, tau_b):
    C = set()
    for r,(ece,n,_) in cert.items():
        if ece <= TAU_ECE and n >= N_MIN \
           and bridge[r] <= tau_b and audit.passed(r) and prov.valid(r):
            C.add(r)
    return C

# IP-268 AVO：采集价值驱动的数据规划
def choose_acquisition(C, cert, bridge, budget):
    best = None
    for d in candidate_units(C, cert, bridge):        # 未认证/高杠杆/可桥接
        if not budget.allow(d):            continue
        if d.real and risk(d) > EPS_ACQ:   continue
        avoi = leverage(d)*miscalib(cert,d.r)*bridgeable(bridge,d.r)/cost(d)
        if best is None or avoi > best.avoi: best = (d, avoi)
    return best if best and best.avoi > 0 else None   # 数据饱和即停

# IP-269 ACM：反自噬审计（审计集与采集集物理隔离）
def audit_feedback(collector, D_audit, eps):
    if not collector.is_randomized(eps): return FAIL("no exploration floor")
    if collector.overlaps(D_audit):      return FAIL("audit contaminated")
    return bound(eps, n=len(D_audit))                 # ECE_true - ECE_measured 的上界

# IP-270 WCS：加权保形模态集
def conformal_mode_set(o, D_cal, w, alpha):
    scores = [(1 - w_i * posterior_i(o)[m_i], m_i) for m_i, ... in D_cal]
    q = weighted_quantile(scores, 1 - alpha)
    return {m for s, m in scores if s <= q}

# IP-271 CALIBRA-RAS 主闭环（实时部分与 R69 同构，仅插入区域门）
def CALIBRA_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    r = M.phi(o)                                       # O(1) 区域查找
    if r not in M.C or M.cert_expired(r):              # 失败闭合
        return R68_fallback(M, o, U_cal)               # 逐指令退回
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    Cset = M.wcs.conformal_mode_set(o, M.D_cal[r], M.w[r], M.alpha)
    if len(Cset) > KAPPA_MAX:                          # 集合太大 ⇒ 不可定案
        return R68_fallback(M, o, U_cal)
    g = M.mint.choose_interaction(modes, o, M.budget) if U_epi > TAU_EPI else None
    if g is not None:
        ans = M.cia.execute(g); U_epi = M.cia.update_belief(modes, ans)
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(modes, U_epi, lam)
    M.vqa_d.submit(g, r, U_epi, Cset, M.prov)          # 数据审计异步回灌
    return k, lam, mode, (U_ale, U_epi)

def R68_fallback(M, o, U_cal):
    lam = lam_floor(U_cal)                             # 纯保守，无交互
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    return k, lam, None, (U_cal, U_cal)

## 3. 推导

**引理 19（干预可识别性）** 在 A99（M 外生、给定 N 无未观测混淆、正性）下，成对干预满足 p(o|do(M=m),N=n) = p(o|M=m,N=n)，故 π(M|o) ∝ p(o|M,N)p(M) 可由 D_int 一致估计，据此计算的局部 ECE_r 对**仿真可表达的模态**无偏。系：**被动日志只给选择偏置下的 p(o|M, selected)，不能替代干预数据**——这解释了 R69「有大量真实数据却仍校不准」的根因：缺的不是样本量，缺的是反事实。

**引理 20（迁移差异上界）** 设区域 r 上真实与仿真分布的 TV 距离为 δ_T(r)，用锚点估计有界重要性权重 w_r，则加权保形集在部署域的覆盖率缺口 ≤ δ_T(r) + O(√(log(1/α)/n_r))（A100：权重有界、锚点正性）。若 δ_T(r) > τ_b 则证书不可签发。系：**仿真提升的是保真度，锚点提供的是合法性**；没有锚点，δ_T 不可估，证书只能是自签。

**引理 21（反自噬 / Goodhart 界）** 若采集以概率 1−ε 选择当前最不确定区域、以 ε 均匀探索，审计集独立同分布于固定部署分布，则 |ECE_measured − ECE_true| ≤ O(ε) + O(√(log(1/δ)/n_audit)) + selection_bias；若 ε=0 或审计集被采集策略污染，则该差无界且方向为正——**测得越准，实际可能越偏**。系：主动数据采集必须有探索底噪与外部审计，否则它系统性地制造「自信的错误」。

**定理 18（区域局部包含 R68/R69）** 在 A99–A101 下，CALIBRA 在 𝒞 内逐指令等于 FLUID（由定理 16，风险 ≤ R68 且享 resolution bonus）；在 𝒞 外强制走 R68 兜底。故任意状态的期望风险 ≤ R68；当 𝒞 = ∅ 时与 R68 逐指令相同。**R69 是「全域认证且证书为真」的理想边界；R70 把这个不可检验的理想条件，替换为可检验、可失效、可撤销的证据条件。**

**定理 19（采集预算的有限终止与近似最优）** 若 AVoI 关于数据单元近似子模（A102），贪心采集达到 (1−1/e) 的最优风险下降；当所有区域已认证或边际 AVoI ≤ 成本时停止，故数据引擎有限终止。系（数据饱和）：当 sim-real gap 成为主导误差项时，继续采仿真数据只降低仿真 ECE、不降低部署风险——**数据不是越多越好，而是越「可过桥」越好**。

## 6. 本轮最大风险

**一句话**：CALIBRA-RAS 把「该不该信自己的模态」外包给了一个**同样是模型的仿真器**——如果 Isaac Sim 的ambiguity结构与真实世界不同构、或真实锚点恰好落在仿真覆盖良好的「漂亮区域」，桥接就会**签发一张错误的合格证**；而错误的合格证比没有合格证更危险，因为它会解锁 VoI，让系统把 R69 的「诚实的不知道」升级成「有凭证的错误」——**在错的世界里校准，比不校准更危险**。

**次级风险与缓解**：
1. **仿真-真实不同构（δ_T 被低估）** → 锚点留出验证 + 双样本检验 + δ_T 置信上界，越界即撤证；
2. **主动采集的 Goodhart / 自噬** → 定义 318 的 ε 探索底噪 + 物理隔离审计集 + 引理 21 偏差界；
3. **证书陈旧** → 定义 321/325 的 provenance 哈希 + TTL + 漂移触发撤销；
4. **锚点太贵/不可得** → 证书覆盖率诚实下降，非认证区退 R68；论文须报告 coverage-risk 曲线而非单一均值；
5. **仿真投毒/红队场景缺失** → ℰ_sim 对抗训练 + VQAuditor-D 参与式数据审计 + E309 红队。

def counterfactual_pairs(sim, scene, nuisance, modes, seed):
    sim.reset(scene, nuisance, seed)                 # 固定 N 与物理参数
    return [ {m: (sim.do(m).rollout(), hash(sim.state())) for m in modes}
             for _ in [0] ]                           # 同一 N 下多模态分支

def local_calibration(D_int, phi, tau_ece, n_min):

            for r, data in cells.items()}

# IP-266 RAB：真实锚桥
def transfer_discrepancy(D_real, D_sim, phi, r):
    wr = fit_bounded_density_ratio(D_sim_cell(r), D_real_cell(r))
    return tv(weighted(D_sim_cell(r), wr), D_real_cell(r)), wr

# IP-267 CRG：认证区域图（含审计与溯源）

            if ece <= TAU_ECE and n >= N_MIN and bridge[r] <= tau_b
            and audit.passed(r) and prov.valid(r)}

# IP-268 AVO：采集价值规划
def choose_acquisition(C, cert, bridge, budget):

    for d in candidates(C, cert, bridge):             # 未认证、高杠杆、可桥接

        if best is None or avoi > best.avoi: best = (d, avoi)
    return best if best and best.avoi > 0 else None   # 数据饱和即停

def audit_feedback(collector, D_audit, eps):

    if collector.overlaps(D_audit):      return FAIL("audit contaminated")
    return bias_bound(eps, n=len(D_audit))            # |ECE_meas - ECE_true| 上界

# IP-270 WCS：加权保形模态集
def conformal_mode_set(o, D_cal, w, alpha):

    q = weighted_quantile([s for s, _ in scored], 1 - alpha)
    return {m for s, m in scored if s <= q}

    M.vqa_d.submit(g, r, U_epi, Cset, M.prov)         # 数据审计异步回灌

## 4. 推导

**引理 19（干预可识别性）** A99 下 p(o|do(M=m),N=n)=p(o|M=m,N=n)，故 π(M|o) 可由 D_int 一致估计，局部 ECE_r 对仿真可表达模态无偏。系：被动日志只给选择偏置下的 p(o|M,selected)，**缺的不是样本量，是反事实**。

**引理 20（迁移差异上界）** 有界权重 + 正性下，加权保形在部署域的覆盖缺口 ≤ δ_T(r) + O(√(log(1/α)/n_r))；δ_T(r)>τ_b 则证书不可签发。系：**仿真降 δ_T，锚点证 δ_T**；无锚点的证书只能是自签。

**引理 21（反自噬 / Goodhart 界）** ε-随机探索 + 独立审计下，|ECE_meas − ECE_true| ≤ O(ε) + O(√(log(1/δ)/n_audit)) + selection_bias；ε=0 或审计污染时该差无界且偏正。系：主动采集若无探索底噪与外部审计，会系统性制造「自信的错误」。

**定理 18（区域局部包含 R68/R69）** A99–A101 下，𝒞 内逐指令等于 FLUID（由定理 16，风险 ≤ R68 且享 resolution bonus），𝒞 外逐指令等于 R68；故任意状态风险 ≤ R68，𝒞=∅ 时退化为 R68。**R69 是「全域认证且证书为真」的理想边界；R70 把它换成可检验、可失效、可撤销的证据条件。**

**定理 19（采集有限终止与近似最优）** AVoI 近似子模（A102）时贪心达 (1−1/e)；所有区域认证或边际 AVoI≤成本即停。系（数据饱和）：sim-real gap 主导时，再采仿真只降仿真 ECE、不降部署风险。

## 5. 复杂度分析

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CRG 区域查找 | O(1)，< 0.01ms | O(|ℛ|) | 定义 313–316 |
| WCS 保形查表 | O(log K)，< 0.03ms | O(K·n_cal) 离线 | 定义 319；A100 |
| 实时环路总延迟（K=1） | **< 2.7ms**（R69 + ~0.04ms） | — | 定理 18 |
| CID 成对干预（离线） | O(P·rollout) | 数据湖 | 定义 312；引理 19 |
| LCM 局部校准（离线） | O(|ℛ|·n_r) | O(|ℛ|) | 定义 313 |
| RAB 桥接（离线，小锚点） | O(n_real·d) | O(n_real) | 定义 315；引理 20 |
| AVO 采集规划（异步） | O(|cand|·|ℛ|) | O(|ℛ|) | 定义 317；定理 19 |

结论：**数据治理换实时零负担**——实时只多一次 O(1) 区域查找与一次 O(log K) 保形查表。

## 7. 本轮最大风险

**一句话**：CALIBRA-RAS 把「该不该信自己的模态」外包给了一个**同样是模型的仿真器**——若 Isaac Sim 的歧义结构与真实世界不同构、或真实锚点恰好落在仿真覆盖良好的「漂亮区域」，桥接就会**签发一张错误的合格证**；而错误的合格证比没有合格证更危险，因为它会解锁 VoI，把 R69 的「诚实的不知道」升级成「有凭证的错误」——**在错的世界里校准，比不校准更危险**。

**次级风险与缓解**：δ_T 被低估（锚点留出验证 + 双样本检验 + 置信上界，越界撤证）；采集 Goodhart/自噬（ε 探索底噪 + 物理隔离审计集 + 引理 21）；证书陈旧（provenance 哈希 + TTL + 漂移撤销）；锚点太贵（覆盖率诚实下降，报告 coverage-risk 曲线而非单一均值）；仿真投毒/红队缺失（ℰ_sim 对抗训练 + VQAuditor-D + E309）。
