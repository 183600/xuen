# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS」IP-287~294；灵感循环第 1 轮；本轮灵感：「可重构机构」×「平衡控制」）

> R72 把 GAUGE 从「认知层」下沉为「具身层」：REG 实时执行图、IRL 意图隐变量、DMEM 接触计量、EREFLEX 三层反作用、S2R-UQ 参数桥接，并确立了「调度可信、意图可辨、接触可计量」才启用新层的严格退化链。但 R72 仍隐含两个**静态假设**：
> - **本体结构固定**：R72 的 (s, z, c) 全活在一个**固定的状态空间与固定运动学**里——雅可比 J(q)、惯性参数、传感器-机体变换、标定链 τ 在整段任务中不变。**可重构机构**（轮足切换、模块自重构、可锁关节、变形连杆）打破这一点：**状态空间本身随模式 m 改变**，旧坐标系下的状态估计不能直接搬到新坐标系。
> - **风险可补偿**：R72 把安全表达为「风险缩放 λ 抬高 ⇒ 动作软化 ⇒ 风险下降」，本质是**可补偿的**：多花一点保守性就能换回安全。**平衡控制**打破这一点：存在一个硬边界（跌倒/倾覆），越过后任何 λ 都无意义。平衡是**不可补偿的可行性约束**，不是可加的风险项。
>
> 本轮两个灵感正好补两块，并逼出第三个更深的问题：
> - **可重构机构**：把本体升级为**模式流形 ℳ 上的纤维丛**——底空间是模式（拓扑），纤维是该模式的状态空间 𝒮_m；重构是底空间上的路径，需要**规范联络 ∇** 把信念与不确定度从一条纤维平行搬运到另一条纤维。**绕一圈重构回来（m→m'→m）未必回到原点**，这个**和乐（holonomy）**是重构历史的几何记忆，也是一个新的计量对象。
> - **平衡控制**：把安全升级为**权威约束下的可行核（viability kernel）𝒱_m(u)**：不是问「风险多大」，而是问「在剩余控制权威 u 下，是否还存在一条永不离开安全集的轨迹」。重构要**吃掉**平衡控制权威（同一批执行器既维持平衡又驱动变形），于是 𝒱_m 随重构收缩——**重构与平衡在权威预算上直接竞争**。
> - **第三块（本轮真正的新洞见）**：**模式歧义**。若不知道自己是「轮」还是「腿」，就会用错雅可比、错动力学、错可行核；这比单纯「不确定」更危险，因为**错误的模型会给出高置信的错误安全证明**。必须引入**模式鲁棒的安全控制交集**与**非补偿的平衡否决**。
>
> 核心命题：**不再只问「我的测量链在固定本体上可信吗」，而问「当我的本体在变形、且每一步都踩在可行域边缘时，我的测量链还能逐指令兑现风险界吗？」** 把 R72 的 EMBODIED-GAUGE-RAS 再下沉一层，得到 **METAMORPHIC-GAUGE-RAS（M-GAUGE-RAS，变形计量审计闭环）**：**变拓扑 × 平衡可行 × 计量审计 × 证据闭环**。

## 0. 直觉与动机

**灵感 1（可重构机构 → 状态空间在变，测量必须跨坐标系搬运）**
直觉：R72 默认「同一个关节角 q 永远是同一个自由度」。可重构后，同一个物理关节在「臂模式」是肩俯仰、在「腿模式」是髋俯仰；同一个 IMU 读数，在不同连杆拓扑下对应不同的机体速度。**换模式 = 换坐标系图卡（chart）**。若不把旧信念「搬运」到新图卡，BSE 会把「坐标系变了」误读为「世界变了」。更糟：搬运映射（图卡间雅可比）本身带标定误差，**搬运一次就多一份误差**。所以重构不是免费的「切换开关」，而是一次**带不确定度的坐标变换**。

**灵感 2（平衡控制 → 可行域是不可补偿的硬边界，调 λ 救不了）**
直觉：R72 的 λ 是「保守性旋钮」：不确定度大就调高，动作变慢变软。但平衡不是这样：如果质心-捕获点（Capture Point）已经越出支撑多边形能救回的范围，**再保守也救不回来**——你已经没有足够的力矩/落脚点。平衡是**可行性（feasibility）**问题，不是**风险（risk）**问题。用 λ 去表达平衡，会把「必然跌倒」误画成「高风险但可调」。必须把平衡单列为**否决层（veto）**：进入不可行域即硬降级（下蹲/撑地/坐下），不参与 λ 的补偿式计算。

**灵感 3（耦合 → 重构要吃平衡权威，可行核随权威收缩）**
直觉：一台轮足机器人从「轮」变「腿」，需要同一批电机先解锁、再转动、再锁定。这段时间里，**用于维持平衡的力矩被抽走了**。于是「重构」和「平衡」不是两件独立的事，而是**共享一个控制权威预算 u_max = u_bal + u_reconf + u_reserve**。抽去 u_reconf 去变形，留给平衡的 u_bal 就少了，可行核 𝒱_m(u_bal) 就小了。**能不能重构，本身就是个可行性问题**：得证明存在一条重构轨迹，使得每个中间时刻都还在（被收缩后的）可行核里。

**灵感 4（和乐 → 绕一圈重构回不来，这是可测量的几何误差）**
直觉：物理里，向量沿曲面绕一圈平行移动回原点，一般不再指向原方向——差一个**和乐**。机器人也一样：m→m'→m 绕一圈，由于齿轮间隙、编码器零位、连杆柔顺、锁止重复性，回到同一模式时**状态估计和标定不会精确复原**。这个偏差不是「噪声」，而是**路径依赖的系统性几何误差**，随重构历史累积。它必须被**显式计量**：定义**形态规范不变性间隙 ι_morph**，即绕圈后的估计偏离多少；超阈就必须**重标定（重置联络）**。这把 R71 的 gauge 不变性从「隐喻」变成**字面意义上的联络和乐**。

**灵感 5（模式歧义 → 用错雅可比比不知道更危险；保守交集控制）**
直觉：如果模式后验 b_t(m) 在「轮」和「腿」之间各 0.5，而两者在同一关节上要求的安全力矩相反，那么任何「取平均」的控制都可能两边都不安全。正确做法不是「按概率混合动作」，而是求**所有候选模式安全控制集的交集** ∩_m U_m^safe；交集为空则**不能动**，必须先花很小的动作去**辨识模式**（锁止测试、微动一致性检验），或者直接撑地。**错误的模型会自信地给出错误的安全证明**——这是本轮最危险的失效模式。

## 1. 形式化定义（增量：定义 366–381）

**定义 366（METAMORPHIC-GAUGE-RAS 总览）** M-GAUGE-RAS = (REG†, IRL†, DMEM†, RCM, MGB, VBC, VRT, EREFLEX†, S-RISK, J_MG)。六不变式：
(i) **模式计量完整**：模式后验 b_t(m) 与模式条件化标定链 kine_calib_id(m) 缺一不可用；
(ii) **联络可追溯**：每次跨模式信念搬运携带 T_{m→m'} 与 Σ_frame，并写入追溯链；
(iii) **和乐有界**：闭合重构回路后 ι_morph ≤ τ_holo，否则触发重标定或降级；
(iv) **可行域优先**：任何动作与任何重构日程，须在每个中间时刻位于权威约束可行核内；
(v) **平衡非补偿**：平衡否决与 ρ^rob 独立于 λ，不可用保守性「买回」；
(vi) **严格逐指令退化**：任一新层失效退回 R72 / R71 / R68。

**定义 367（重构机构纤维丛与规范联络 MGB）** 纤维丛 π: ℰ_ℳ → ℳ，底空间 ℳ 为模式流形（离散模式 × 连续过渡参数 θ），纤维 𝒮_m 为模式 m 的状态空间。规范联络 ∇ 沿底空间路径 γ: [0,1] → ℳ 给出平行搬运 T_γ: 𝒮_{γ(0)} → 𝒮_{γ(1)}。信念搬运：
b_{m'}(T_γ x) = b_m(x) / |det J_{T_γ}(x)|，
协方差 Σ' = J_T Σ J_Tᵀ + Σ_frame(m→m')，其中 Σ_frame ⪰ 0 为图卡间标定协方差。联络由运动学标定与锁止模型给出，**每次搬运都写入追溯链**。

**定义 368（和乐不确定度与形态规范不变性间隙）** 对闭合重构回路 γ（m→…→m），和乐映射 H_γ = T_γ。和乐不确定度
Σ_holo(γ) = （沿 γ 累积的 Σ_frame） + (H_γ x̂ − x̂)(H_γ x̂ − x̂)ᵀ。
形态规范不变性间隙
ι_morph(γ) = ‖H_γ x̂ − x̂‖ / (‖x̂‖ + ε)。
ι_morph ≤ τ_holo 视为「重构历史可忽略」；否则标记需重标定。**和乐不能由更多同源传感消除**（引理 33），只能由**独立重标定测量**重置。

**定义 369（模式隐变量与模式计量 RCM）** 模式 m ∈ ℳ，模式后验 b_t(m) 由本体感觉、电流特征、锁止传感器、运动学一致性残差在线推断。模式计量证据
e_m = (b_t(m), lock_state, backlash_est, kine_calib_id(m), observability, τ_rcm)，
其中 kine_calib_id(m) 为**模式索引标定链**（每个模式的雅可比/惯性/传感器变换各有独立标定与不确定度），τ_rcm 为模式条件追溯链。**缺少 kine_calib_id 的证据不得进入控制与风险缩放。**

**定义 370（模态动力学与权威约束可行核）** 模式 m 动力学 ẋ = f_m(x) + g_m(x)(u_bal + u_reconf) + w，约束 ‖u_bal‖ + ‖u_reconf‖ + ‖u_reserve‖ ≤ u_max。可行核
𝒱_m(u) = { x : ∃ 控制策略 σ，仅用权威 ≤ u，使 x(t) ∈ X_safe ∀t ≥ 0 }。
平衡裕度 ρ_m(x; u) = signed_dist(x, ∂𝒱_m(u))。**u 越小，𝒱_m(u) 越小（引理 34）。**

**定义 371（鲁棒可行核与不确定度侵蚀）** 给定综合不确定度半径 ε = ε(s, z, c, m, holo) = √(U_ale² + U_epi² + H_z² + u_tac² + H_m² + u_holo²)，鲁棒可行核
𝒱_m^ε(u) = { x : B(x, ε) ⊆ 𝒱_m(u) } = 𝒱_m(u) ⊖ ε（集合侵蚀）。
鲁棒平衡裕度 ρ^rob = ρ_m(x; u) − L_ρ · ε（L_ρ 为 ρ 对 x 的 Lipschitz 常数）。**ρ^rob ≤ 0 ⇒ 在当前不确定度下不可行。**

**定义 372（平衡否决与可行性门控）** 平衡否决谓词
BalVeto(x, m, u, ε) ⇔ ρ^rob_m(x; u, ε) ≤ 0 ∨ ‖u_bal‖ > u_max − ‖u_reconf‖ − ‖u_reserve‖。
BalVeto 为**非补偿硬谓词**：触发即进入安全姿态（brace / sit），**不进入 λ 的补偿式权衡**。这与 R71 的非补偿安全否决同构，但对象从「语义安全」变为「动力学可行性」。

**定义 373（保可行性重构转移 VRT 与混合自动机）** 混合自动机状态 (m, phase, x)，模式不变式 x ∈ 𝒱_m(u_bal)；切换 m→m' 的守卫须在**安全交接集**
𝒢_{m→m'} = 𝒱_m(u_bal^post) ∩ 𝒱_{m'}(u_bal^post) ∩ 𝒳_geom ∩ 𝒳_vel
内触发，且重构有时间预算 deadline τ_reconf。**VRT 规划 = 在模式图 × 状态空间里找一条路径，使每个中间时刻 x(t) ∈ 𝒱_{m(t)}(u_max − ‖u_reconf(t)‖ − ‖u_reserve‖) 且按时完成。** 否则拒绝重构并转入 brace。

**定义 374（形态反作用层 L4 与四层预算）** 在 R72 的 L1(ψ)/L2(z)/L3(c) 之上新增 L4 模式反作用：
c_reflex^m = λ_e·E_reconf + λ_a·∫‖u_reconf‖ dt + λ_h·Δι_morph + λ_d·𝟙[模式抖动 / dwell 违反]。
累计预算 B_reflex_total 四层合算；稳态集新增 M_safe（模式稳定、无抖动、dwell ≥ τ_dwell）。**模式抖动（chattering）本身就是反作用成本**，用最小驻留时间与滞回抑制。

**定义 375（形态鲁棒风险缩放 S-RISK）**
λ = max( risk_scale(U_ale, U_epi, H_z, u_tac, H_m, u_holo),
         λ_floor(Σ) )，
其中 H_m = H[b_t(m)]、u_holo = √tr(Σ_holo)，Σ 为全部软不确定度之和。**同时输出非补偿谓词 BalVeto 与 ModeConflict（定义 376）。λ 只调任务激进性，不制造平衡权威。**

**定义 376（模式冲突与保守交集控制）** 令 M_δ = { m : b_t(m) ≥ δ }。若存在 x 使 ∩_{m∈M_δ} U_m^safe(x) = ∅，则 ModeConflict = 1。此时被控量必须取保守交集（若非空）：
u ∈ ∩_{m∈M_δ} U_m^safe(x)，
为空则**冻结激进动作**，执行模式辨识动作或 brace。**绝不对冲突模式做「按概率混合」的力矩**——混合力矩在两端都可能不安全。

**定义 377（形态反作用 VoI：MRVOI）**
VoI^M(g) = c(ψ)·IG_s + η·IG_z + η_m·IG_m
          − c_reflex^ψ − c_reflex^z − c_reflex^c − c_reflex^m
          − γ·E[ΔH^future] − κ·P_fall(g)。
**非补偿门**：若 P̂_fall(g) > P_fall_max 或 BalVeto 或 ModeConflict（无安全交集），该动作**直接排除**，不看 VoI 多大。IG_m 为模式信息增益（重构/探测可用来辨识模式）。

**定义 378（混合证书 J_MG）** J_MG = (J_EMB, mode_validity, holonomy_bound, viability_cert, reconfig_schedule_cert, authority_ledger, mg_ver)。Valid ⇔ J_EMB 有效 ∧ 模式计量有效 ∧ ι_morph ≤ τ_holo ∧ 每个模式可行核证明有效 ∧ 重构日程在每个中间时刻可行 ∧ 权威账本平衡。

**定义 379（威胁模型 AIC-MG）** ℰ_MG = ℰ_EMB × ℰ_morph × ℰ_bal：
ℰ_morph = { 锁止执行器故障（锁在错误角度）、模式伪装（传感器谎报模式）、齿轮间隙注入、和乐投毒、重构时机攻击（在临界平衡时刻诱导重构）、权威耗尽攻击、对抗性本体感觉导致模式混淆 }；
ℰ_bal = { 临界点推搡、未建模负载偏移、支撑面受力打滑、对抗性质心偏移、可行核模型投毒 }。

**定义 380（严格退化包含链）**
- 全失效 ⇒ R68（纯开环 + 硬安全包络）；
- 仅 RCM / VRT 失效 ⇒ 冻结当前模式 + R72（不重构）；
- 仅 VBC 失效 ⇒ 退化为静态平衡裕度 + R72，并强制保守姿态（不可补偿层失效则收缩自由度）；
- 全有效 ⇒ M-GAUGE-RAS。
**安全单调不减；重构只在「模式可辨、行域可行、和乐有界」时启用。**

**定义 381（权威预算账本与平衡-重构共设计）** 权威账本 A_t 记录每一时刻 u_bal + u_reconf + u_reserve ≤ u_max，reserve 为恢复余量。重构规划必须保证全程 ‖u_reconf‖ 不侵蚀 reserve 之下的平衡最低权威 u_bal^min(m)。**平衡-重构共设计 = 在满足 u_bal^min(m) 的前提下最大化重构速度，或在给定 deadline 下最小化权威占用。**

# IP-295 RCM：模式计量（感知域 100Hz 产出，计量域消费）
@dataclass
class ModeEvidence:
    b_m: Distribution            # b_t(m)
    lock: LockStatus             # 每关节锁止 + 间隙
    kine_calib_id: Dict[int, str]  # 模式索引标定链
    observability: float         # 模式可辨性
    tau: TraceChain

class ReconfigMetrology:
    def update(self, proprio, currents, lock_sensors):
        b_m  = self.mode_filter.step(proprio, currents, lock_sensors)
        lock = self.lock_model.estimate(lock_sensors, currents)
        # 模式一致性：在每个候选模式下计算运动学残差
        resid = {m: self.kine_residual(m, proprio) for m in support(b_m)}
        # 残差本身作为模式证据，并更新可辨性
        return ModeEvidence(b_m, lock, self.calib_ids, observability(resid), self.tchain)

# IP-296 MGB：纤维丛搬运 + 和乐（重构事件触发）
class GaugeBundle:
    def transport(self, est, m_from, m_to):
        T = self.connection(m_from, m_to)          # 图卡映射及其雅可比 J_T
        est2 = T.apply(est)
        est2.cov = T.J @ est.cov @ T.J.T + self.frame_uncertainty(m_from, m_to)
        est2.tau = self.tchain.extend(m_from, m_to, T, est2.cov)
        return est2
    def holonomy(self, loop):                       # loop: [m0, m1, ..., m0]
        H, cov = None, 0
        for a, b in zip(loop[:-1], loop[1:]):
            T = self.connection(a, b)
            H = T if H is None else T.compose(H)
            cov = T.J @ cov @ T.J.T + self.frame_uncertainty(a, b)
        drift = H.apply(self.x_ref) - self.x_ref
        return Holonomy(Sigma=cov + outer(drift, drift), iota=norm(drift)/(norm(self.x_ref)+EPS))
    def gauge_gap(self, est, loop):
        return self.holonomy(loop).iota            # iota_morph

# IP-297 VBC：权威约束可行核 + 鲁棒裕度 + 否决（控制域 <0.05ms）
class BalanceViability:
    def __init__(self, kernel_oracle, eps_model, lipschitz):
        self.V, self.eps, self.L = kernel_oracle, eps_model, lipschitz
    def margin(self, x, m, u_avail):
        return self.V.signed_distance(x, m, u_avail)     # ρ_m(x;u)
    def robust_margin(self, x, m, u_avail, eps):
        return self.margin(x, m, u_avail) - self.L * eps  # ρ^rob
    def veto(self, x, m, u_bal, u_reconf, u_reserve, eps):
        return (self.robust_margin(x, m, u_bal, eps) <= 0.0
                or u_bal > U_MAX - u_reconf - u_reserve)

# IP-298 VRT：保可行重构规划（混合自动机；事件触发，计量域 anytime）
class VRTPlanner:
    def plan(self, x, m_from, m_to, deadline, viab, budget):
        for sched in self.transition_graph.paths(m_from, m_to):   # 按 deadline 剪枝
            ok = True
            for (m_t, theta_t, dur) in sched:
                u_rec = self.reconf_authority(theta_t)
                u_bal = U_MAX - u_rec - budget.reserve
                if not viab.in_kernel(x_t(m_t, theta_t), m_t, u_bal, budget.eps_t):
                    ok = False; break
                if budget.ledger.would_violate(u_rec, dur): ok = False; break
            if ok: return ReconfigSchedule(sched, cert=self.certify(sched))
        return None                                  # 不可行 ⇒ 拒绝重构，转 brace

# IP-299 S-RISK：形态鲁棒风险缩放 + 非补偿谓词（控制域 1kHz）
def structural_balance_risk(U_ale, U_epi, H_z, u_tac, H_m, u_holo, rho_rob, params):
    denom = U_ale + U_epi + H_z + u_tac + H_m + u_holo
    lam = max(params.lam_base * (1 + denom / params.lam_scale),
              params.lam_floor * (1 + denom))
    veto = (rho_rob <= params.rho_min)          # 非补偿：不进 denom，不参与 max
    return lam, veto

# IP-300 模式冲突：保守交集控制（控制域）
def mode_robust_control(x, b_m, delta, safe_sets):
    M_delta = [m for m in b_m.support() if b_m[m] >= delta]
    inter = intersect([safe_sets[m](x) for m in M_delta])
    if inter.is_empty():
        return None, ModeConflict(1)                 # 冻结激进动作 / brace
    return inter.project_conservative(), ModeConflict(0)

def morphological_voi(b_t, psi, z_dist, c_dist, b_m, budget, fmp, bse):

        score = ig_s + ig_z + ig_m - cost_ref - cost_m - GAMMA * expected_future_loss(...)

## 3. 推导

**引理 33（和乐不确定度非负且不可同源消除）** 对任意闭合重构回路 γ，Σ_holo(γ) ⪰ 0，且其均值漂移在无独立重标定测量时以传感器分辨率下界为限，不能由同一组传感器增加采样消除。证明：平行搬运是复合仿射映射，Σ_frame ⪰ 0 故协方差不减；均值漂移源于锁止重复性与齿轮间隙的**系统性偏置**，属偏置而非零均值噪声，增加同源样本只降低方差、不降低偏置。系：**绕圈重构有不可消除的信息代价，必须显式重标定重置，否则 ι_morph 单调累积。**

**引理 34（可行核的权威单调性）** u1 ≤ u2 ⇒ 𝒱_m(u1) ⊆ 𝒱_m(u2)。证明：权威约束集 {σ : ‖σ‖ ≤ u} 随 u 单调扩大，可行策略集单调扩大，可行核单调扩大。系：**重构抽走权威 ⇒ 可行核收缩 ⇒ 重构与平衡在权威上直接竞争；这是「重构危险」的定量根源。**

**引理 35（不确定度侵蚀的单调性 ⇒ 安全单调）** ε1 ≤ ε2 ⇒ 𝒱_m^{ε2}(u) ⊆ 𝒱_m^{ε1}(u)，ρ^rob 关于 ε 非增。证明：集合侵蚀对半径单调；Lipschitz 下界单调。系：**R72 的每一层不确定度（s, z, c）与新层（m, 和乐）都只能收缩安全集，不会膨胀——新增层次在安全侧单调不减。**

**引理 36（平衡不可补偿性）** 存在 x ∉ 𝒱_m(u_max) 使对任意 λ > 0 与任意信息量 I，BalVeto 恒真；即 λ 只在权威内调任务激进性，不能扩张可行核。证明：λ 作用于任务增益/速度，不改变 u_max 与动力学可达集；𝒱_m 仅依赖 (f_m, g_m, u_max, X_safe)。故不可行状态对 λ 不变。系：**用 λ 表达平衡是把硬约束错当软风险；必须用独立否决层。**

**引理 37（保可行重构的复合安全性）** 若 x0 ∈ 𝒱_{m0}(u_max)，每个模式不变式成立、每个切换守卫在安全交接集内触发、且重构日程满足权威约束，则 ∀t: x(t) ∈ X_safe。证明：域内用模式可行性，跨域用交接集交叠，权威约束保证过渡期仍可行；对切换次数归纳。系：**「不变式 + 守卫交叠 + 权威预算」是混合系统安全的充分条件，且可逐模式局部验证。**

**引理 38（重构 deadline 与跌倒下界）** 若在时刻 t 必须完成重构才能维持可行（如腾空/单支撑），而剩余权威不足以在 deadline 前完成，则存在 p_min > 0 使 P(fall) ≥ p_min。系：**重构 deadline 是新的实时约束，必须进入 REG 控制域调度（与 R72 的 RTA 衔接）。**

**定理 27（混合组合安全）** 在 A111–A116 下，若 J_MG 有效，则执行轨迹保持在 ∪_m 𝒱_m 内，无硬安全违规（相对模型）。证明：引理 37 组合 + 定义 372 否决 + 定义 378 证书逐项对应。**证明重量落在「可行核模型正确」「权威模型正确」「和乐可测」三条假设上。**

**定理 28（严格包含与退化等价）** M-GAUGE-RAS 在定义 380 退化条件下逐指令等于 EMBODIED / R71 / R68；且有效执行的风险界 ≤ R72。证明：退化映射逐项对应；新层仅在有效时启用，安全集单调（引理 35）。**新层是旧层的严格泛化。**

**定理 29（形态证书 ⇒ 平衡安全，条件性）** 若 J_MG 通过，则在该证书的有效域内，系统不会跌倒（相对可行核模型）。**注意：这是一个条件性保证——它保证的是「在模型给出的可行核内安全」，而不是「真实物理不跌倒」；两者之差正是本轮最大风险。**

**定理 30（无静默和乐累积）** 若每次闭合重构回路后执行 ι_morph 检验并在超阈时重标定，则该执行序列中任意时刻的和乐漂移 ≤ τ_holo + 残差界，不存在未被证书标记的静默累积。证明：每次闭环后要么重置，要么 ι_morph 进入证书字段并触发降级；故未标记漂移不可能超过阈值。系：**和乐必须作为一等计量对象写入证书，否则它就是不可见的慢性中毒。**

**假设 A111–A116**
- A111 模式集有限且 VRT 图连通（任何目标模式可从当前模式经可行路径到达，或明确不可达）。
- A112 联络 ∇ 光滑，Σ_frame 可标定且上界已知。
- A113 𝒱_m(u) 非空、对 (u, ε) Lipschitz，可在控制域实时查询（barrier / 降维近似）。
- A114 模式可观测：在驻留时间内可用锁止测试/微动把模式歧义降到 δ 以下，或保守交集非空。
- A115 权威模型 u_bal + u_reconf + u_reserve ≤ u_max 正确。
- A116 平衡/可行核名义模型（质心动力学 / LIPM / CBF）在有效域内残差有界。

## 6. 本轮最大风险

**一句话**：M-GAUGE-RAS 把安全从「相信测量链 + 相信调度契约」进一步转移到「相信**可行核模型 𝒱_m 的几何形状**、相信**控制权威账本 u_max = u_bal + u_reconf**、相信**和乐漂移可被独立重标定重置**」——**如果真实的平衡边界比模型更靠内（未建模的连杆柔顺、摩擦、通信延迟、电池电压跌落使执行器实际力矩低于标称），那么机器人会在「证书声称可行」的状态下踩过真实的倾覆边界；如果模式辨识在对抗性本体感觉下给出高置信错误模式，它就会用错雅可比、错可行核，拿着盖章的 J_MG 把「错误模型的安全证明」执行成真机跌倒；如果和乐漂移被误当作零均值噪声、未触发重标定，它会在长时程里静默累积，直到某次绕圈重构后估计偏移到可行核之外——事后审计会发现「所有指标当时都在有效域内、所有证书当时都通过了验证、所有和乐当时都低于阈值」，这就是**变形层面的「自信地错自己的可行性」**：它不是在测量上错了，而是在**「安全集长什么样」这件事本身**上错了。**

次级风险与缓解：
1. **可行核模型偏差（最大风险）** → **在线可行域辨识**：用微小安全探测估计真实边界，维护 `𝒱_m^online` 与名义 `𝒱_m` 的**保守下界**（取交集）并写入证书；模型投毒纳入 ℰ_bal。
2. **权威账本失真（电压/温升/延迟使实际力矩下降）** → **权威的在线计量**：以电流/温度/母线电压估计可用力矩，`u_max` 用分位数下界；账本记录名义与实测偏差，超阈即降级。
3. **模式伪装/混淆** → **跨源一致性**：锁止传感器 + 电流特征 + 运动学残差 + 视觉共同定模式，**单源不定案**；高冲突时强制保守交集或 brace。
4. **和乐被当噪声** → **把 ι_morph 作为一等证书字段**（定理 30），超阈强制重标定；重标定用已知几何/锁止基准作独立测量。
5. **重构 deadline 与 REG 冲突** → 把重构日程纳入 RTA 静态验证；控制域预留 `u_reserve` 与时间余量，deadline 不可达即拒绝重构。
6. **模式抖动（chattering）** → 最小驻留时间 + 滞回 + L4 反作用成本显式惩罚；抖动频次纳入审计。
7. **复杂度爆炸** → 模块化上限：|ℳ|≤8、每模式可行核用低维降维（质心 3D + CPC）近似、|M_δ|≤3、每 veto 一条可复算证明。

## 2. 形式化定义（要点版）

**定义 366（M-GAUGE-RAS 总览与六不变式）** 核心：模式计量完整、联络可追溯、和乐有界、可行域优先、平衡非补偿、严格逐指令退化。

**定义 367（重构纤维丛与规范联络 MGB）** 底 ℳ（模式 × 过渡参数 θ），纤维 𝒮_m；联络 ∇ 给出平行搬运 T_γ；b_{m'}(T_γ x) = b_m(x)/|det J_T(x)|，Σ' = J_T Σ J_Tᵀ + Σ_frame。**每次搬运写入追溯链。**

**定义 368（和乐与形态规范不变性间隙）** 闭合回路 γ：H_γ = T_γ；Σ_holo = 累积 Σ_frame + 均值漂移外积；ι_morph = ‖H_γ x̂ − x̂‖/(‖x̂‖+ε)。**ι_morph ≤ τ_holo 才视为重构历史可忽略；否则强制重标定（引理 33）。**

**定义 369（模式隐变量与模式计量 RCM）** b_t(m) 由本体感觉/电流/锁止/运动学残差推断；e_m 携带模式条件标定链 kine_calib_id(m)。**缺标定链不得进入控制与风险缩放。**

**定义 370（模态动力学与权威约束可行核）** ẋ = f_m(x) + g_m(x)(u_bal + u_reconf) + w，‖u_bal‖+‖u_reconf‖+‖u_reserve‖ ≤ u_max；𝒱_m(u) 为仅用权威 ≤u 的不离 X_safe 的可控集。**u↓ ⇒ 𝒱_m↓（引理 34）。**

**定义 371（鲁棒可行核与不确定度侵蚀）** ε = √(U_ale²+U_epi²+H_z²+u_tac²+H_m²+u_holo²)；𝒱_m^ε = 𝒱_m ⊖ ε；ρ^rob = ρ_m − L_ρ ε。**ρ^rob ≤ 0 ⇒ 当前不确定度下不可行。**

**定义 372（平衡否决与可行性门控）** BalVeto ⇔ ρ^rob ≤ 0 ∨ ‖u_bal‖ > u_max − ‖u_reconf‖ − ‖u_reserve‖。**非补偿硬谓词：触发即 brace/sit，不进入 λ 权衡。**

**定义 373（保可行性重构转移 VRT）** 混合自动机 (m, phase, x)，不变式 x ∈ 𝒱_m(u_bal)；守卫须在 𝒢_{m→m'} 内触发；重构带 deadline τ_reconf。**VRT = 在模式图 × 状态空间找每个中间时刻都可行的路径。**

**定义 374（L4 模式反作用与四层预算）** c_reflex^m 含重构能量/权威占用/和乐增量/抖动惩罚；四层合算 ≤ B_reflex_total；稳态集新增 M_safe（含 dwell ≥ τ_dwell）。**模式抖动本身计成本。**

**定义 375（形态鲁棒风险缩放 S-RISK）** λ = max(risk_scale(U_ale,U_epi,H_z,u_tac,H_m,u_holo), λ_floor(Σ))；同时输出 BalVeto 与 ModeConflict。**λ 只调任务激进性，不制造平衡权威。**

**定义 376（模式冲突与保守交集控制）** M_δ = {m : b_t(m) ≥ δ}；若 ∩_{m∈M_δ} U_m^safe(x) = ∅ 则 ModeConflict=1，否则取交集 u ∈ ∩ U_m^safe。**严禁按概率混合冲突模式的力矩。**

**定义 377（形态反作用 VoI：MRVOI）** VoI^M 含 IG_m 与可行性成本；**非补偿门**：P̂_fall > P_fall_max 或 BalVeto 或 ModeConflict ⇒ 动作直接排除，与 VoI 大小无关。

**定义 378（混合证书 J_MG）** Valid ⇔ J_EMB 有效 ∧ 模式计量有效 ∧ ι_morph ≤ τ_holo ∧ 可行核证明有效 ∧ 重构日程全程可行 ∧ 权威账本平衡。

**定义 379（威胁模型 AIC-MG）** ℰ_MG = ℰ_EMB × ℰ_morph × ℰ_bal。新增：锁止故障、模式伪装、间隙注入、和乐投毒、重构时机攻击、权威耗尽、对抗本体感觉；临界推搡、负载偏移、支撑打滑、可行核模型投毒。

**定义 380（严格退化包含链）** 全失效→R68；RCM/VRT 失效→冻结模式+R72；VBC 失效→静态平衡裕度+R72+保守姿态；全有效→完整形态。**安全单调不减；重构只在「模式可辨、行域可行、和乐有界」时启用。**

**定义 381（权威预算账本与平衡-重构共设计）** A_t 记录 u_bal + u_reconf + u_reserve ≤ u_max；重构规划不得侵蚀 u_bal^min(m)。**在满足平衡最低权威下最大化重构速度，或给定 deadline 下最小化权威占用。**

# IP-295 RCM：模式计量（感知域 100Hz）
@dataclass
class ModeEvidence:
    b_m: Distribution
    lock: LockStatus
    kine_calib_id: Dict[int, str]
    observability: float
    tau: TraceChain

class ReconfigMetrology:
    def update(self, proprio, currents, lock_sensors):
        b_m  = self.mode_filter.step(proprio, currents, lock_sensors)
        lock = self.lock_model.estimate(lock_sensors, currents)
        resid = {m: self.kine_residual(m, proprio) for m in support(b_m)}
        return ModeEvidence(b_m, lock, self.calib_ids, observability(resid), self.tchain)

# IP-296 MGB：纤维丛搬运 + 和乐（重构事件触发）
class GaugeBundle:
    def transport(self, est, m_from, m_to):
        T = self.connection(m_from, m_to)
        est2 = T.apply(est)
        est2.cov = T.J @ est.cov @ T.J.T + self.frame_uncertainty(m_from, m_to)
        est2.tau = self.tchain.extend(m_from, m_to, T, est2.cov)
        return est2
    def holonomy(self, loop):
        H, cov = None, 0
        for a, b in zip(loop[:-1], loop[1:]):
            T = self.connection(a, b)
            H = T if H is None else T.compose(H)
            cov = T.J @ cov @ T.J.T + self.frame_uncertainty(a, b)
        drift = H.apply(self.x_ref) - self.x_ref
        return Holonomy(Sigma=cov + outer(drift, drift),
                        iota=norm(drift) / (norm(self.x_ref) + EPS))

# IP-297 VBC：权威约束可行核 + 鲁棒裕度 + 非补偿否决（控制域 <0.05ms）
class BalanceViability:
    def margin(self, x, m, u_avail):        return self.V.signed_distance(x, m, u_avail)
    def robust_margin(self, x, m, u_avail, eps):
        return self.margin(x, m, u_avail) - self.L * eps        # ρ^rob
    def veto(self, x, m, u_bal, u_reconf, u_reserve, eps):
        return (self.robust_margin(x, m, u_bal, eps) <= 0.0
                or u_bal > U_MAX - u_reconf - u_reserve)

# IP-298 VRT：保可行重构规划（混合自动机，anytime）
class VRTPlanner:
    def plan(self, x, m_from, m_to, deadline, viab, budget):
        for sched in self.transition_graph.paths(m_from, m_to):
            if not self.within_deadline(sched, deadline): continue
            ok = True
            for (m_t, theta_t, dur) in sched:
                u_rec = self.reconf_authority(theta_t)
                u_bal = U_MAX - u_rec - budget.reserve
                if not viab.in_kernel(x_t(m_t, theta_t), m_t, u_bal, budget.eps_t):
                    ok = False; break
                if budget.ledger.would_violate(u_rec, dur): ok = False; break
            if ok: return ReconfigSchedule(sched, cert=self.certify(sched))
        return None                                     # 不可行 ⇒ 拒绝重构 / brace

# IP-300 S-RISK：形态鲁棒风险缩放 + 非补偿谓词（控制域 1kHz）
def structural_balance_risk(U_ale, U_epi, H_z, u_tac, H_m, u_holo, rho_rob, params):
    denom = U_ale + U_epi + H_z + u_tac + H_m + u_holo
    lam = max(params.lam_base * (1 + denom / params.lam_scale),
              params.lam_floor * (1 + denom))
    veto = (rho_rob <= params.rho_min)              # 非补偿：不进 denom
    return lam, veto

# IP-300b 模式鲁棒控制：保守交集
def mode_robust_control(x, b_m, delta, safe_sets):
    M_delta = [m for m in b_m.support() if b_m[m] >= delta]
    inter = intersect([safe_sets[m](x) for m in M_delta])
    if inter.is_empty():
        return None, ModeConflict(1)                # 冻结激进动作 / brace
    return inter.project_conservative(), ModeConflict(0)

# IP-301 MRVOI：具身 + 形态 + 可行性 VoI
def morphological_voi(b_t, psi, z_dist, c_dist, b_m, budget, fmp, bse):
    best = None
    for g in morph_action_candidates(b_t, z_dist, b_m, top_k=3):
        if not budget.allow(g): continue
        rho_rob = budget.viab.robust_margin(budget.x, g.mode, g.u_bal, budget.eps)
        if rho_rob <= RHO_MIN or g.p_fall > P_FALL_MAX: continue      # 非补偿门
        psi2, z2, c2, cost_ref, _ = ereflex_step(psi, z_dist, c_dist, g, ...)
        z2, cost_m = mode_reflex_step(b_m, g, budget)                 # L4
        ig_s = credibility(psi) * (entropy(b_t.marginal_s()) - expected_post_entropy_s(b_t, g, fmp))
        ig_z = ETA * (z_dist.entropy() - z2.entropy())
        ig_m = ETA_M * (b_m.entropy() - budget.predicted_mode_entropy(g))
        score = ig_s + ig_z + ig_m - cost_ref - cost_m - GAMMA * expected_future_loss(...)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

## 4. 推导

**引理 33（和乐非负且不可同源消除）** 对闭合回路 γ，Σ_holo ⪰ 0；无独立重标定时均值漂移以传感器分辨率为下界，不能靠同源增采样消除。证明：搬运为复合仿射映射，Σ_frame ⪰ 0 故协方差不减；漂移源于锁止重复性/间隙的**系统偏置**，增采样只降方差。系：**绕圈重构有不可消除信息代价，必须显式重标定重置。**

**引理 34（可行核权威单调）** u1 ≤ u2 ⇒ 𝒱_m(u1) ⊆ 𝒱_m(u2)。系：**重构抽走权威 ⇒ 可行核收缩 ⇒ 重构与平衡直接竞争。**

**引理 35（侵蚀单调 ⇒ 安全单调）** ε1 ≤ ε2 ⇒ 𝒱_m^{ε2} ⊆ 𝒱_m^{ε1}，ρ^rob 关于 ε 非增。系：**每一层不确定度只收缩安全集，不膨胀——新增层次安全侧单调不减。**

**引理 36（平衡不可补偿）** ∃x ∉ 𝒱_m(u_max) 使任意 λ、任意信息量下 BalVeto 恒真。证明：λ 只调任务增益/速度，不改变 u_max 与可达集；𝒱_m 仅依赖 (f_m, g_m, u_max, X_safe)。系：**用 λ 表达平衡是把硬约束错当软风险。**

**引理 37（保可行重构复合安全）** 若 x0 ∈ 𝒱_{m0}(u_max)、每模式不变式成立、每切换守卫在安全交接集内触发、重构日程满足权威约束，则 ∀t: x(t) ∈ X_safe。对切换次数归纳。

**引理 38（重构 deadline 与跌倒下界）** 若必须完成重构才能维持可行而剩余权威不足，则 P(fall) ≥ p_min > 0。系：**重构 deadline 是进入 REG/RTA 的新实时约束。**

**定理 27（混合组合安全）** 在 A111–A116 下，J_MG 有效 ⇒ 轨迹保持于 ∪_m 𝒱_m，无硬安全违规（相对模型）。**证明重量落在「可行核模型正确 / 权威模型正确 / 和乐可测」三假设上。**

**定理 28（严格包含与退化等价）** M-GAUGE-RAS 在定义 380 下逐指令等于 EMBODIED/R71/R68；有效执行风险界 ≤ R72。新层仅在有效时启用，安全集单调（引理 35）。

**定理 29（形态证书 ⇒ 平衡安全，条件性）** J_MG 通过 ⇒ 证书有效域内不跌倒（相对可行核模型）。**这是条件性保证——它保证「在模型可行核内安全」，而非「真实物理不跌倒」；两者之差即本轮最大风险。**

**定理 30（无静默和乐累积）** 每次闭环后检验 ι_morph 并在超阈时重标定 ⇒ 任意时刻和乐漂移 ≤ τ_holo + 残差界，无未被证书标记的静默累积。系：**和乐必须是一等计量对象，否则是不可见的慢性中毒。**

**假设 A111–A116**：A111 模式集有限且 VRT 图连通；A112 联络光滑、Σ_frame 可标定且上界已知；A113 𝒱_m(u) 非空、对 (u,ε) Lipschitz、可实时查询；A114 模式可观测（驻留期内歧义降到 δ 以下或保守交集非空）；A115 权威模型 u_bal+u_reconf+u_reserve ≤ u_max 正确；A116 平衡/可行核名义模型在有效域内残差有界。

## 7. 本轮最大风险

**一句话**：M-GAUGE-RAS 把安全从「相信测量链 + 相信调度契约」进一步转移到「相信**可行核模型 𝒱_m 的几何形状**、相信**权威账本 u_max = u_bal + u_reconf + u_reserve**、相信**和乐可被独立重标定重置**」——**如果真实平衡边界比模型更靠内（未建模连杆柔顺、摩擦、通信延迟、电压跌落使实际力矩低于标称），机器人就会在「证书声称可行」的状态下踩过真实倾覆边界；若模式辨识在对抗性本体感觉下给出高置信错误模式，它就用错雅可比、错可行核，拿着盖章的 J_MG 把「错误模型的安全证明」执行成真机跌倒；若和乐漂移被当作零均值噪声、未触发重标定，它会在长时程里静默累积，直到某次绕圈重构后估计偏移到可行核之外——事后审计会发现「所有指标当时都在有效域内、所有证书当时都通过了验证、所有和乐当时都低于阈值」，这就是变形层面的「自信地错自己的可行性」：它不是在测量上错了，而是在「安全集长什么样」这件事本身错了。**

次级风险与缓解：
1. **可行核模型偏差（最大）** → **在线可行域辨识**：微小安全探测估真实边界，维护 `𝒱_m^online` 与名义 `𝒱_m` 的保守交集并写入证书；模型投毒纳入 ℰ_bal。
2. **权威账本失真（电压/温升/延迟）** → **权威在线计量**：以电流/温度/母线电压估可用力矩，`u_max` 取分位数下界；账本记录名义-实测偏差，超阈即降级。
3. **模式伪装/混淆** → **跨源一致性**：锁止 + 电流 + 运动学残差 + 视觉共同定模式，单源不定案；高冲突强制保守交集或 brace。
4. **和乐被当噪声** → 把 ι_morph 作为**一等证书字段**（定理 30），超阈强制重标定，用已知几何/锁止基准作独立测量。
5. **重构 deadline 与 REG 冲突** → 把重构日程纳入 RTA 静态验证，控制域预留 `u_reserve` 与时间余量，deadline 不可达即拒绝重构。
6. **模式抖动** → 最小驻留时间 + 滞回 + L4 反作用成本显式惩罚，抖动频次纳入审计。
7. **复杂度爆炸** → 模块化上限：|ℳ|≤8、可行核用低维降维（质心 3D + CPC）近似、|M_δ|≤3、每 veto 一条可复算证明。
