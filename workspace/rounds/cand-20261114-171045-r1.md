# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「双足机器人」×「开源生态」）

> R69 让系统学会了「问」：把不确定性拆成 aleatoric（噪声，收紧）与 epistemic（歧义，去求证），并用看/问/触去消解后者。但 R69 仍默认了四个从未被质询的前提：**一个可信模型、一块固定硬件、一张单点证书、一个中心化维护者**。真实的双足机器人不这样运行。
>
> 双足机器人是**混杂系统**：单支撑、双支撑、摆动、着地冲击，每一相的动力学位形、欠驱动程度、可行域都不同；最危险的不是相内，而是**相与相的接口**——脚在什么状态着地、冲击映射是否把上一相的安全集送进下一相的安全集、接触时序的微小偏差会不会让整条证书失效。
>
> 开源生态是**图**：同一套安全栈会被 fork、被重写、被移植到不同腿长/质量/关节限幅的机器上，被大量不完全可信的贡献者以 PR 的方式持续改动。这里最危险的不是单点漏洞，而是**证书的传播**——上游的「已验证」在下一个 fork 里还算数吗？接口兼容是否等于安全兼容？一个「只是重构」的提交会不会悄悄放宽假设？
>
> 两个灵感指向同一个问题：**一张局部成立的证明，如何经过一次「翻译」后仍然成立？** 在双足里，翻译是着地冲击映射与「模板→整机」的模拟关系；在开源里，翻译是 fork/版本/硬件参数变化下的契约细化。二者可以共用同一个原语：**带模拟关系的假设-保证契约**。
>
> 核心命题：**把安全证书从「单点证明」升级为「可运输对象」：它沿两条图传播——接触模式图（gait automaton）与 fork/依赖图（PBoM DAG）。证书只在两种条件下有效：每一段模式转移都把前一个不变式送进下一个不变式；每一次 fork 都能证明语义变化落在证书依赖锥之外，或重新清偿受影响的义务。** 命名 **FORGE-RAS**（Forkable, Open, Refinement-typed, Gait-certified Ecosystem for Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**这张证书在别人的机器上、在下一个 fork 里，还算数吗**」——安全不再是一个仓库的私有属性，而是生态里可运输、可继承、可审计的公共品。

## 0. 直觉与动机

**灵感 1（双足机器人 → 安全是分模式的，最脆的是模式接口）**
直觉：R68/R69 的安全包络默认连续演化；但双足每迈一步都在「换系统」：单支撑时质心在支撑脚上方的一小片区域内才可控，双支撑时两脚构成不同的约束锥，摆动腿的落点决定了下一步的可控集。着地瞬间的冲击把速度状态经一个非光滑映射打到新相，**这一步才是证书最容易断的地方**。因此不能只维护一个全局安全集，而要维护一组模式索引的不变式 `K_q`，并显式证明「守卫条件内的任何状态，经冲击映射后都落在下一相的 `K_{q'}` 内」。这把「会不会摔倒」从相内跟踪问题，变成**相间证书传播问题**。
形式化：定义 311–313；安全判据是 `K_q` 在相内受控不变 + 守卫可达 + `R_{q→q'}(K_q∩G) ⊆ K_{q'}`。

**灵感 2（开源生态 → 安全是分叉的，证书会随 fork 传播或失真）**
直觉：开源让安全栈获得「许多双眼睛」，但也让**证书脱离其证明语境**：同一个 API 下，上游假设「估计器输出有界延迟」，下游实现却只保证平均延迟；两个各自安全的模块组合起来可能争用同一只脚；一个看似无害的「性能优化」改掉了数值精度，令不变式的边界越界。接口兼容是最容易被误当作安全兼容的东西。要做的是给每个模块配一份**语义绑定**的契约与证明物料清单（PBoM），让 fork 的增量改动只需清偿「证书依赖锥」内的义务，而不是每次全量重证；同时让无法证明的改动**默认不能继承证书**。
形式化：定义 314–320。

**灵感 3（统一原语 → 契约细化就是模拟关系）**
直觉：双足的「模板→整机」是模拟关系：低维模板（LIPM/捕获点）的行为能否被高维整机在某个误差界内复现；fork 的「上游→下游」也是模拟关系：下游在更多/更少的假设下能否提供上游的保证。二者都可写成 `C_up ⊑ C_down`：下游假设不弱于上游、下游保证不弱于上游、且证明可被运输。于是**步态相 = 模块，冲击映射 = 接口适配器，硬件参数盒 = 环境假设**，一套代数同时处理物理与软件。
形式化：定义 314–315、317；引理 19–21。

**灵感 4（开放性的代价 → 证书洗白是新的攻击面）**
直觉：一旦证书能被继承，攻击者就有了新目标：不去攻破证明，而是**让一个不安全的 fork 看起来继承了证明**。手段包括：把放宽假设伪装成重构；用同名/同接口的依赖替换（依赖混淆/抢注）；利用不可重放的构建与固件时序；在基准上过拟合；以及治理捕获（说服唯一维护者合并）。R69 的威胁模型只防「回答撒谎」，没防「证书洗白」。本轮必须给出：语义哈希、依赖锥、对抗差分证伪、阈值治理与可重放构建；否则开源生态会把一个假证书复制得比漏洞还快。
形式化：定义 316、318–322；命题 1、定理 19。

**灵感 5（严格包含 R69 → 新增的都是集成时成本，不是实时成本）**
直觉：当 `|Q|=1`、平台盒退化为单点、PBoM 只有一个节点、fork 差为空、接触时序无偏差时，FORGE-RAS 必须逐指令等价于 R69 FLUID-RAS。所有新增义务都应落在**离线/CI/加载时**：步态核与重定向在离线求解，增量证书在合并前清偿，运行时只多一个 <0.1ms 的模式/守卫监督。任何一项失败都退化为 R69 的纯保守或双足的「安全停/坐地」，安全侧永不让步。
形式化：定理 18、20。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（FORGE-RAS 总览与五不变式）** FORGE-RAS = (HGK, RET, SCC, PBoM, ΔCC, SVS, ADF, SDR, VQAuditor-F, CGP, FLUID-RAS†)。五不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **语义绑定**：运行时加载的每个模块必须通过 PBoM 重算语义哈希，并与证书中记录的一致；
(iii) **组合封闭**：任何多模块/多模式组合必须沿契约细化链验证；未通过者只允许运行 R69 的保守子集；
(iv) **不可单点削弱**：安全关键假设的修改需 CGP 阈值签名与挑战窗口；
(v) **可重放**：证书验证必须确定，或给出可检查的区间界；构建不可重放即视为证书无效。

**定义 311（双足接触模式自动机）** `H = (Q, X, U, f, G, R, D)`。`Q = {ds, ls, rs, rec, stop}`（双支撑、左单支撑、右单支撑、恢复、安全停）；`X = ⊔_{q∈Q} X_q`，`X_q ⊆ ℝ^{n_q}`；`f_q` 为局部 Lipschitz 向量场；`U_q` 为满足力矩/关节/摩擦锥约束的输入集；`G_{q,q'} ⊆ X_q` 为守卫；`R_{q,q'}: G_{q,q'} → X_{q'}` 为着地/切换的冲击映射；`D_q=[τ_q^min,τ_q^max]` 为驻留时间。一个执行是 `(q_0,x(t)) → (q_1,x(t)) → …`，其模式序列与切换时刻构成调度 `Σ=(q_0,τ_0)(q_1,τ_1)…`。

**定义 312（步态相安全核）** 对每个相 `q`，给定集合 `K_q ⊆ X_q ∩ Safe_q` 与控制器 `κ_q`，称 `(K_q,κ_q)` 为相证书，若：
(a) **相内不变**：从任意 `x∈K_q` 出发，闭环流在 `[0,τ]` 内保持于 `K_q`，直到到达守卫或驻留上界；
(b) **守卫可达**：存在 `τ∈D_q` 使轨迹在 `τ` 时刻进入 `G_{q,q'}`；
(c) **冲击闭合**：`R_{q,q'}(K_q ∩ G_{q,q'}) ⊆ K_{q'}`；
(d) `Safe_q` 已编码摩擦锥、CoP/支撑多边形、力矩/关节限幅、自碰撞与地形约束。
若模式序列上每一相都满足 (a)–(d)，称该执行 **hybrid-safe**。注意 (c) 是本定义与 R69 连续包络的本质差别：**证书必须穿过非光滑的着地映射**。

**定义 313（接触时序鲁棒与恢复核）** 名义调度 `Σ` 的 `ε`-邻域 `Σ_ε` 为切换时刻偏差 ≤ `ε`、相序不变的所有调度。对每个相定义恢复核 `K_q^rec` 与安全停集 `S_stop`（静态稳定、力矩可关断、无自碰撞的姿态集），并要求：从 `K_q` 在 `ε` 内可达的任何边界状态出发，监督器能在 `T_rec` 内进入 `K_{q'}` 或 `S_stop`。守卫裕度 `ρ_g(x)=dist(x,∂G)`；当实测模式/时刻越出 `Σ_ε` 或 `ρ_g < ρ_g^min` 时，切换到恢复核。

**定义 314（安全契约与细化）** 契约 `C = (A, G, Φ, h_sem, cone)`：`A` 为环境/上游假设（扰动界、状态集、传感器误差、时序抖动、接触模型误差），`G` 为保证（如 `K_q` 不变、捕获点界、无跌倒），`Φ` 为机器可检查的证明对象（障碍函数、SOS 证书、可达管、重放脚本），`h_sem` 为语义哈希，`cone` 为 `Φ` 实际读取的自由变量集合（证书依赖锥）。称 `C_up ⊑ C_down`（`C_down` 细化 `C_up`，可替换上游）当且仅当：
`A_up ⊆ A_down`，`G_down ⊆ G_up`，且存在可检查的证据运输 `T: Φ_up ↦ Φ_down`。
三条都可机器检查；缺一不可继承。

**定义 315（契约组合与证据运输）** 并行组合 `C_1 ⊗ C_2 = (A_1∩A_2∩I, G_1∩G_2, Φ_1⊗Φ_2, h_sem, cone_1∪cone_2)`，其中 `I` 是接口一致性假设（共享资源、时序、坐标/单位、数值精度）。顺序组合 `C_1 ; C_2` 仅当 `G_1 ⇒ A_2` 时有效，保证为 `G_2`。证据运输 `T` 必须保序：`C_1⊑C_2 ∧ C_2⊑C_3 ⇒ C_1⊑C_3`；组合对 `⊑` 单调。该代数使 DAG 可按拓扑序自底向上检查（定理 20）。

**定义 316（证明物料清单 PBoM）** `PBoM=(V,E,ℓ,h_root)` 为有向无环图。节点 `v=(id, h_sem, C, Φ, recipe, toolchain, sig)`，其中
`h_sem = H( normalized_IR ∥ weights ∥ config ∥ compiler_flags ∥ numeric_mode ∥ firmware_version )`；
边为依赖/接口边；`h_root = H(canonical_serialize(V,E))`。加载时 `Att(PBoM, runtime)` 为真当且仅当：重算的所有 `h_sem` 等于记录值、`runtime.platform ⊆ PBox`、`runtime.toolchain` 可重放且数值模式一致。PBoM 同时充当安全 SBOM：每个依赖都必须给出出处与签名。

**定义 317（平台盒与模板-整机模拟关系）** 平台参数盒 `P=∏_i[p_i^-,p_i^+]`，包含质量、质心高度、连杆长度、力矩上限、摩擦系数、驱动延迟。整机模型 `M_h(p)`，模板 `M_t(θ)`（LIPM/捕获点/质心动力学）。模拟关系 `S_p ⊆ X_h × X_t` 带抽象 `α` 与提升 `lift`，误差 `δ(p)`。若模板核 `K_t` 的签名裕度 `ρ_t = dist(K_t, Unsafe_t)` 满足
`ρ_t > L_S·δ_max + L_p·diam(P) + c_p`，
则提升集 `K_h(P)={x_h | ∃x_t∈K_t, (x_h,x_t)∈S_p}` 对所有 `p∈P` 安全。称 `K_h(P)` 为**重定向证书**；新硬件只需 `p_new⊆P` 且重算的裕度仍为正。

**定义 318（fork 语义差与证书依赖锥）** 设 fork `F` 从上游 `U` 的 PBoM 根 `h_U` 分出。语义差 `Δ = (ΔV, ΔE, Δh_sem, ΔP)`，只记录**语义**变化（IR、权重、配置、依赖、工具链、平台盒），不记录注释/格式。对每个义务 `o`，其证书依赖锥 `cone(o)` 是 `Φ_o` 的数据/控制依赖、区间算术支撑、守卫表达式、时序假设与数值模式所触及的变量集合。称 `Δ` **触及** `o` 当且仅当 `Δ ∩ cone(o) ≠ ∅`。

**定义 319（增量义务与非干涉）** 给定 `F,U`，增量义务集
`Obl(F,U) = { o ∈ Obl(U) : Δ 触及 o } ∪ NewObl(F)`。
若 `Δ ∩ cone(o)=∅`，则 `o` 的真值在 `F` 中不变（引理 21），无需重证；否则 `ΔCC` 必须 (a) 运输证明并局部重查，(b) 全量重解，或 (c) 拒绝。成本 `C_Δ = Σ_{o∈Obl} |cone(o)|`。若所有义务清偿且细化成立，称 `F` **证书可继承**。

**定义 320（安全语义版本 SVS）** 对 `F` 相对 `U` 的契约变化分类：
- **SAFETY-MAJOR（破坏性）**：不满足 `A_U ⊆ A_F` 或 `G_F ⊆ G_U`，即下游不能再安全替换上游；
- **SAFETY-MINOR（兼容增强）**：`A_F ⊇ A_U` 且 `G_F ⊂ G_U`，在同假设下提供更强保证；
- **SAFETY-PATCH（等价）**：`A,G` 等价，仅内部语义/证明更新，证书可局部重放。
分类器必须在合并前给出；任何 MAJOR 变更即使测试全绿也不得默认继承证书。

**定义 321（对抗差分证伪 ADF）** 给定上游 `U` 与 fork `F` 都声明同一契约 `C`，场景分布 `D`。ADF 在所有静态检查均通过的约束下，搜索轨迹 `ζ` 最大化
`J(ζ)=Viol_F(ζ) + λ·|m_F(ζ) − m_U(ζ)| + μ·Coverage(ζ)`，
其中 `Viol` 为违反指示，`m` 为证书裕度（如障碍函数最小值），`Coverage` 鼓励覆盖证书依赖锥内的分支。搜索用 CMA-ES/MAP-Elites 等无梯度方法，优先攻击最小裕度义务。**ADF 是证伪器，不是证明器**：找不到反例不等于证明；对于无法证明非干涉的关键 `Δ`，必须全量重解。

**定义 322（证书洗白与供应链威胁模型 ℰ_FORGE）** `ℰ_FORGE = ℰ_FLUID × ℰ_fork × ℰ_platform × ℰ_supply`，包含：把放宽假设伪装成重构；同名/同接口依赖替换（依赖混淆、抢注）；不可重放构建与固件/时序漂移；基准过拟合与选择性证据；治理捕获（单维护者合并危险改动）；证书复制/重放别的平台盒；仿真-实机接触模型不匹配。信任假设：哈希抗碰撞、至少一个独立诚实审计者、阈值签名不可伪造。

**定义 323（加载时证明与运行时监督）** 启动时计算 `Att(PBoM, runtime)`；失败则不暴露认证包络，进入 `SAFE_DEGRADE`（R69 纯保守）或 `SAFE_STOP`（双足：受控下蹲/坐地/扶停）。运行时监督器估计当前相 `q̂` 与切换时刻 `τ̂`：若 `(q̂,τ̂)∉Σ_ε` 或守卫裕度低于阈值，调用定义 313 的恢复核；恢复核自身必须已获证书。监督不修改策略，不进行学习写操作。

**定义 324（证书 J_FORGE）** `J_FORGE = (J_FLUID, contract_chain, pbom_root, platform_box_proof, hybrid_kernel_proof, adf_report, svs_class, quorum_proof, forge_ver)`。`Valid(J_FORGE)` 当且仅当：
`Valid(J_FLUID)` ∧ 契约链逐级细化 ∧ `Att` 通过 ∧ 运行时平台在盒内 ∧ 步态核 (a)–(d) 成立 ∧ 所有增量义务已清偿 ∧ MAJOR 变更具备 `quorum_proof` ∧ `adf_report` 无未处理反例（反例存在 ⇒ 隔离，不得当作已证明）。

**定义 325（安全公地治理 CGP）** 对每个安全关键假设 `a` 定义关键级 `crit(a)`。修改 `a` 的提案需满足
`Gov(a,Δ) = (|Sigs| ≥ k_{crit}) ∧ (|distinct_orgs(Sigs)| ≥ m_{crit}) ∧ (无未决挑战) ∧ (变更已写入仅追加透明日志)`。
`J_FORGE` 的有效性包含 `Gov`。透明日志用 Merkle 树；fork 携带上游日志头，拒绝无法追溯的假设变更。

**定义 326（运输损失与证书覆盖率）** 对 fork 链 `U→F`，定义
`L_trans = d_H(G_U, G_F) + w_A·d_H(A_U, A_F)`（保证与假设的 Hausdorff 距离），
证书覆盖率 `κ_cov = |已局部清偿义务| / |Obl(F,U)|`，假设债务 `D_A = Σ_a w(a)·1[a 未验证]`。
生态排序以 `(安全性, κ_cov, −D_A, −L_trans)` 为准；低运输损失的 fork 可被优先复用。

## 3. 推导

**引理 19（步态相组合）** 若每个相 `q` 的 `(K_q,κ_q)` 满足定义 312(a)(b)(c)，则从 `K_{q0}` 出发、沿任意满足驻留约束的调度 `Σ` 的执行保持于 `⋃_q K_q`，且在证明时域内不进入 `⋃_q (Safe_q)^c`。证明：对模式序号归纳。相内由 (a) 保持；守卫到达由 (b) 保证；切换瞬间由 (c) 把状态送入下一相核；若守卫/驻留失败，则由定义 313 的监督器接管。**系**：跌倒风险的主要来源被定位到 (c) 的冲击闭合，而不是相内跟踪误差——这把双足安全验证的重点从「整段轨迹」移到「每步的接口」。

**引理 20（重定向可靠性）** 设模板核裕度 `ρ_t`、模拟关系误差上界 `δ_max`、流/抽象 Lipschitz 常数 `L_S`、平台参数敏感度 `L_p`。若 `ρ_t > L_S δ_max + L_p diam(P) + c_p`，则对所有 `p∈P`，提升集 `K_h(P)` 与不安全集不相交。证明：任意整机轨迹经 `S_p` 投影为模板轨迹；误差在 `δ_max` 内传播，参数变化贡献至多 `L_p diam(P)`；由三角不等式，模板到边界的距离始终为正，故整机不会越界。**系**：平台盒越大，所需模板裕度越大；「重定向」不是免费移植，而是用鲁棒裕度购买参数自由度。

**引理 21（非干涉与 fork 继承）** 若 `Δ ∩ cone(o)=∅`，则 `o` 的真值在 `F` 中不变；若 `C_U` 有效、`C_U⊑C_F`、且 `Obl(F,U)` 全部清偿，则 `C_F` 有效。证明：`cone(o)` 包含证明 `Φ_o` 所读取的全部自由变量（含数值模式与工具链）；语义差未触及它们，故存在从 `Φ_o^U` 到 `Φ_o^F` 的恒等运输。其余义务由清偿与细化给出；组合单调性来自定义 315。**注意**：这是相对某个切片/依赖分析的可靠性结论；若分析漏掉隐式依赖（如全局状态、未声明的环境变量、浮点重结合），非干涉前提失效——这正是风险所在。

**引理 22（接触时序鲁棒）** 若实际切换状态 `x` 与名义守卫状态 `x*` 满足 `‖x−x*‖≤ε`，且守卫裕度 `ρ_g > L ε`，则 `R(x)` 落在 `K_{q'}` 的 `L_R ε`-邻域内；若进一步 `ρ_{q'} > L_R ε`，则冲击闭合仍成立；否则恢复核在 `T_rec` 内进入 `S_stop`。证明：冲击映射的局部 Lipschitz 性与守卫裕度定义直接给出。**系**：滑移/早着地/晚着地应被建模为 `ε` 的增大，而不是「未建模扰动」；只要监督器能估计 `ε`，证书可随接触质量自适应收紧。

**命题 1（接口兼容 ≠ 安全兼容）** 存在两个模块 `M_1,M_2`，接口类型与语法契约均匹配、各自在孤立环境安全，但组合后不安全。构造：`M_1` 假设「脚底接触由我独占」，`M_2` 假设「脚底接触由我独占」，二者都通过接口检查；组合后同时下发足端轨迹，违反支撑约束。或：`M_1` 保证「平均延迟有界」，`M_2` 假设「最坏延迟有界」，类型相同而假设不匹配。故开源生态中仅凭 API/类型/单元测试的兼容性认证，**不可能**给出组合安全；必须显式检查假设-保证与共享资源约束。

**定理 18（FORGE 严格包含 FLUID）** 取 `|Q|=1`、无转移、平台盒为单点、PBoM 单节点、`Δ=∅`、`Σ_ε={Σ}`，并令 `Safe_{q}` 等于 R69 的认证安全集、`K_q` 为 R69 的保守包络，则 `J_FORGE` 的有效性与 R69 的 `J_FLUID` 一致，运行时动作逐指令相同；FORGE 的额外运行时开销仅为守护裕度查询 `<0.1ms`（可预编译为椭球/查表）。因此 R69 是 FORGE 在「单模式、单平台、零 fork、零时序偏差」边界上的退化；安全侧不让步，效率侧只在集成阶段增加成本。

**定理 19（证书洗白的残余风险上界）** 在 ℰ_FORGE 下，一次「语义已变但证书看似继承」的合并被接受，必须至少发生以下之一：(a) 依赖锥分析漏掉真实依赖且 ADF 在 `B` 次查询内未发现；(b) 关键级被错误分类或阈值签名被攻破；(c) 语义哈希碰撞/重放。故残余风险
`≤ (1−β_ADF)^B + P_capture + P_hash + P_misclass`，
其中 `β_ADF` 为单次查询发现证书相关差异的概率。**该上界不能降到 0**，因此对于无法证明非干涉的 MAJOR 变更，协议要求全量重解，而不是「ADF 没找到就放行」；ADF 的作用是把沉默的洗白变成显式的反例，不是替代证明。

**定理 20（端到端可靠性与退化等价）** 若 `Valid(J_FORGE)`、运行时平台在盒内、实际调度 `Σ_actual∈Σ_ε`、且每个已加载模块通过 `Att`，则由引理 19–22，执行保持 hybrid-safe；若任一条件失败，监督器在 `T_rec` 内进入恢复核或 `S_stop`，且该退化路径的保守性不弱于 R69（定理 18）。证明：正常路径由契约链与模式核组合给出；失败路径由定义 323 与恢复核证书给出；两条路径的切换是单次、无学习写操作的，故控制连续（继承 R69 定理 17 的换装不变式）。**系**：FORGE 把开放生态引入的风险转化为「可用性/性能下降」，而不是「安全包络扩张」。

## 6. 本轮最大风险

**一句话**：FORGE-RAS 的全部安全性押在「语义哈希 + 依赖锥 + 细化关系真的覆盖了所有安全相关语义」这一前提上——**若存在语义缝隙（编译重排、固件时序、未声明的全局状态、仿真-实机接触模型差异），一个不安全的 fork 就会继承一张看起来合法的证书；在开源生态里，这张被洗白的证书会被复制、移植、引用得比漏洞本身更快**——证书的传播速度，就是风险的传播速度。

**次级风险与缓解**：
1. **形式化不可扩展**（高维双足相核、SOS 爆炸）→ 模板+模拟关系 + 区间算术 + 只对差异参数重证；必要时降级为测试/可达管，证书强度显式标注。
2. **依赖锥漏报**（隐式依赖、数值模式、浮点重结合）→ 把工具链/数值模式纳入 `h_sem` 与 `cone`；对 MAJOR 变更强制全量重解，不依赖非干涉。
3. **治理失败/贡献者摩擦**（开源激励不足，维护者绕过 CI）→ 阈值签名只用于关键假设，普通补丁走快速通道；透明日志与挑战窗口降低捕获收益。
4. **ADF 被当作证明**（没找到反例就放行）→ 定义 321/324 明确 ADF 只做证伪；无法证明非干涉即全量重证。
5. **恢复核自身未认证**（安全停也可能摔）→ 恢复核必须与主核同等级证书；`S_stop` 采用静态稳定姿态并做冲击闭合检查。

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** FORGE-RAS = (HGK, RET, SCC, PBoM, ΔCC, SVS, ADF, SDR, VQAuditor-F, CGP, FLUID-RAS†)；五不变式：实时零学习写；语义绑定；组合封闭；不可单点削弱；可重放。

**定义 311–313（双足模式与恢复）** 模式自动机 `H`；相核 `K_q` 需 (a) 相内受控不变、(b) 守卫可达、(c) `R(K_q∩G)⊆K_{q'}`、(d) `Safe_q` 含摩擦锥/CoP/力矩/关节/地形；`Σ_ε` 内偏差由监督器接管，恢复核在 `T_rec` 内进入下一相或 `S_stop`。

**定义 314–315（契约与组合）** `C=(A,G,Φ,h_sem,cone)`；`C_up⊑C_down ⇔ A_up⊆A_down ∧ G_down⊆G_up ∧ 证据运输`；并行 `⊗` 需接口假设 `I`，顺序 `;` 需 `G_1⇒A_2`；`⊑` 为前序且组合单调（可按 DAG 拓扑序检查）。

**定义 316（PBoM）** 语义哈希绑定的依赖 DAG；`Att` 重算 `h_sem`、检查平台盒与工具链可重放。语义哈希覆盖 IR、权重、配置、编译选项、数值模式与固件版本。

**定义 317（重定向）** 平台盒 `P`、模拟关系 `S_p`、误差 `δ(p)`；若 `ρ_t > L_Sδ_max + L_p·diam(P) + c_p`，则 `K_h(P)` 安全。新硬件只需 `p_new⊆P` 且裕度为正，否则重新求解。

**定义 318–319（fork 增量证书）** 语义差 `Δ`；义务 `o` 的依赖锥 `cone(o)`；`Δ∩cone(o)=∅` 则 `o` 非干涉、无需重证；否则运输/局部重查/全量重解/拒绝。`C_Δ=Σ|cone(o)|`。

**定义 320–321（安全版本与 ADF）** MAJOR 破坏性（`A_U⊄A_F` 或 `G_F⊄G_U`）、MINOR 兼容增强、PATCH 等价；ADF 在静态全绿约束下最大化 `Viol_F + λ|m_F−m_U| + μ·Coverage`；有反例即隔离，无没有反例 ≠ 证明。

**定义 322–323（威胁与监督）** `ℰ_FORGE`：伪装重构、依赖替换/抢注、构建漂移、基准过拟合、治理捕获、平台盒重放、仿真-实机接触失配；加载 `Att` 失败或运行时 `(q̂,τ̂)∉Σ_ε` / 守卫裕度不足 ⇒ 恢复或安全停。

**定义 324–325（证书与治理）** `J_FORGE` 有效性 = `J_FLUID` ∧ 契约链 ∧ `Att` ∧ 平台盒 ∧ 步态核证明 ∧ 增量义务清偿 ∧ MAJOR 阈值签名 ∧ ADF 无未处理反例。`Gov` 要求 k-of-n、m 个独立组织、无未决挑战、仅追加日志。

**定义 326（生态度量）** `L_trans`、`κ_cov`、`D_A`；优先复用低运输损失、高覆盖、低假设债务的 fork。

## 3. 关键算法伪代码

```python
# IP-264 HGK：离线求相核，运行时只查裕度
class HybridGaitKernel:
    def certify(self, H):
        K = {q: solve_controlled_invariant(H.f[q], H.U[q], H.Safe[q]) for q in H.Q}
        for q, q2 in H.transitions:
            assert subset(impact(H.R[q, q2], K[q] & H.G[q, q2]), K[q2])
        return K

    def margin(self, q, x):
        return signed_distance(self.K[q], x)          # < 0.05ms，预编译查找/椭球

# IP-265 RET：模板→整机
def retarget(template_kernel, P_box, sim):
    dmax, L_S, L_p = sim.error_bound(P_box)
    rho_t = template_kernel.signed_margin()
    return RetargetCertificate(P_box, rho_t > L_S*dmax + L_p*diameter(P_box) + C_P)

# IP-266/267 SCC + PBoM
class SafetyContract:
    def refines(self, up):
        return (subset(up.A, self.A) and subset(self.G, up.G)
                and self.transport_witness(up))

def build_pbom(modules):
    for v in modules:
        v.h_sem = H(v.ir, v.weights, v.config, v.flags, v.numeric_mode, v.firmware)
    return PBoM(modules, root=H(canonical(modules)))

def attest(pbom, runtime):
    return (pbom.recompute() == pbom.root
            and runtime.platform in pbom.platform_box
            and reproducible(runtime.toolchain, pbom.recipe))

# IP-268/269/270：fork 增量证书
def fork_certify(fork, upstream, budget):
    delta = semantic_diff(fork, upstream)
    obls  = [o for o in upstream.obligations if delta.hits(o.cone)]
    for o in obls:
        if not discharge(o, fork, delta): return REJECT
    if classify_semver(upstream, fork) == "SAFETY-MAJOR" and not CGP.quorum(fork):
        return REJECT
    report = ADF.search(upstream, fork, budget)
    return CERTIFIED if report.no_open_counterexample else QUARANTINE

# IP-271/276：主闭环（R69 不动，只在模式接口处加监督）
def FORGE_RAS_round(M, obs, runtime):
    if not M.attested:
        return M.safe_stop_or_degrade()
    q_hat, tau_hat = M.gait_monitor.estimate(obs)
    if (q_hat, tau_hat) not in M.schedule.Sigma_eps:
        return M.recovery.recover(obs)
    if M.hgk.margin(q_hat, obs.x) < RHO_G:
        return M.recovery.recover(obs)
    k, lam, mode, U = FLUID_RAS_round(M, obs)
    if not M.hgk.certified(q_hat, mode.a[:k]):
        return M.recovery.recover(obs)
    return k, lam, mode, U
```

## 4. 推导

**引理 19（步态相组合）** 若每相 `(K_q,κ_q)` 满足相内不变、守卫可达、冲击闭合，则从 `K_{q0}` 出发沿任意驻留可行调度的执行保持于 `⋃K_q`，不进入不安全集。证明：对模式序号归纳；相内由不变性，切换由冲击闭合，守卫/驻留失败由监督器接管。系：跌倒风险主要定位在冲击闭合，而非相内跟踪。

**引理 20（重定向可靠性）** 若 `ρ_t > L_Sδ_max + L_p·diam(P) + c_p`，则对所有 `p∈P`，`K_h(P)` 安全。证明：整机轨迹投影到模板，误差由模拟关系与参数敏感度控制，三角不等式保证模板到边界距离始终为正。

**引理 21（非干涉与 fork 继承）** 若 `Δ∩cone(o)=∅`，则 `o` 真值不变；若 `C_U` 有效、`C_U⊑C_F`、且 `Obl(F,U)` 全部清偿，则 `C_F` 有效。注意：依赖锥漏掉隐式依赖/浮点重结合时前提失效。

**引理 22（接触时序鲁棒）** 若实际切换状态距名义守卫 ≤ε 且 `ρ_g>Lε`，则 `R(x)` 落在 `K_{q'}` 的 `L_Rε`-邻域；若 `ρ_{q'}>L_Rε` 冲击闭合仍成立，否则恢复核在 `T_rec` 内到 `S_stop`。系：滑移/早着地/晚着地应建模为 `ε` 的增大。

**命题 1（接口兼容 ≠ 安全兼容）** 存在接口类型匹配、各自孤立安全、组合后不安全的模块对（共享足端独占假设、或平均延迟保证对上最坏延迟假设）。故仅凭 API/类型/单测的兼容性认证不能给出组合安全，必须检查假设-保证与共享资源约束。

**定理 18（FORGE 严格包含 FLUID）** 取 `|Q|=1`、无转移、平台盒单点、PBoM 单节点、`Δ=∅`、`Σ_ε={Σ}`，则 FORGE 与 R69 的证书有效性一致、运行时动作逐指令相同；额外开销仅为 `<0.1ms` 的守卫查询。R69 是 FORGE 在「单模式、单平台、零 fork、零时序偏差」边界的退化。

**定理 19（证书洗白残余上界）** 一次「语义已变但证书看似继承」的合并被接受，需至少发生：依赖锥漏报且 ADF 在 `B` 次内未发现、关键级误分类或阈值签名被攻破、哈希碰撞/重放。故残余风险 `≤(1−β_ADF)^B + P_capture + P_hash + P_misclass`，不能降到 0；无法证明非干涉的 MAJOR 变更必须全量重解。

**定理 20（端到端可靠性与退化等价）** 若 `Valid(J_FORGE)`、平台在盒内、`Σ_actual∈Σ_ε`、所有模块通过 `Att`，则执行 hybrid-safe；任一条件失败则监督器在 `T_rec` 内进入恢复核或 `S_stop`，且保守性不弱于 R69。证明：正常路径由契约链与模式核组合（引理 19–22）；失败路径由定义 323；切换无学习写，控制连续。

## 7. 本轮最大风险

**一句话**：FORGE-RAS 的安全性押在「语义哈希 + 依赖锥 + 细化关系覆盖所有安全相关语义」这一前提上——**若存在语义缝隙（编译重排、固件时序、未声明全局状态、仿真-实机接触差异），不安全的 fork 会继承一张合法的证书；在开源生态里，这张被洗白的证书会被 fork、移植、引用得比漏洞本身更快**——证书的传播速度就是风险的传播速度。

**次级风险与缓解**：形式化不可扩展（模板+模拟关系+区间算术，显式标注证书强度）；依赖锥漏报（工具链/数值模式纳入 `h_sem` 与 `cone`，MAJOR 强制全量重解）；治理失败/贡献摩擦（关键假设才用阈值签名，普通补丁快速通道）；ADF 被误当证明（定义 321/324 明确只证伪）；恢复核自身未认证（恢复核与主核同级证书，`S_stop` 做冲击闭合检查）。
