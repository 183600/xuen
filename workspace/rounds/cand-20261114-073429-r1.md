# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「分布外泛化」×「机器人」）

> R69 把不确定性一分为二，用「主动交互」把可约的 epistemic 歧义问掉。但它把全部效率收益押在一个从未被检验的前提上：**流模型的模态分布可信**。R69 自陈的最大风险正是如此——模态权重未校准时，系统会自信地追问一个幻影。本轮要指出更深一层：**R69 的整套推理都默认「我仍在训练时认识的那个世界里」**。一旦分布偏移（光照、摩擦、负载、关节磨损、人的意图都变了），模态分布、交互收益、流似然、乃至安全包络会同时失去意义。而 R69 用来兜底的「第二意见」恰恰是一条**高维密度**（FMA 的 −log p）——这在分布外泛化里是最著名的陷阱之一：**似然不等于典型性**，一个 flow 完全可以对 OOD 给出比 ID 更高的似然。
>
> 本轮两个灵感正好补上两块缺失：
> - **分布外泛化**给出「分布无关的有限样本保证」这套工具（保形/序贯检验/概念偏移），也逼我们区分「变了但仍可解」与「根本不在支撑里」；
> - **机器人**给出一个统计之外、环境伪造不了的见证通道——**本体**：力矩、接触、能量守恒。要骗过它，必须真的移动身体；同时机器人还能**用动作去检验世界是否还在支撑内**（轻推测摩擦、轻触测刚度）。
>
> 核心命题：**把 R69 的「不确定性」问题升级为「模型有效性」问题。OOD 不是对单个观测的静态判定，而是闭环里的一条过程：随时可检测、单调可回退、把「可解新颖性」与「支撑缺口」分开处置；而兜底证据从「原始似然」换成「典型性 + 保形 p 值 + 本体一致性」三重、分布无关的见证。** 命名 **ARGUS-RAS**（Adaptive Risk-aware Generalization Under Shift）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我还在我认识的世界里吗？我的身体还是那个身体吗？**」——分布外不是一个分数，而是四根轴上的世界与本体的共同漂移。

## 0. 直觉与动机

**灵感 1（分布外泛化 → 机器人把 OOD 变成一条有反馈的过程）**
直觉：在图像分类里，OOD 是「测试分布 ≠ 训练分布」的一个静态事件，测试样本独立同分布。机器人不是这样：它**身处**分布之中，而且它的策略会**改变**数据分布——躲开陌生角落的策略看起来「没有 OOD」，去探索的策略会「制造 OOD」。再加上时间相关、执行器磨损、环境缓慢改变，闭环数据**根本不可交换**。所以机器人 OOD 的第一性原理不是「这个样本像不像训练集」，而是「**我的模型（观测/动力学/本体/意图）在闭环里是否仍然有效，以及我能否在有限时间内知道它失效了**」。这把 OOD 从「检测」升级为「带反馈的序贯过程」，也直接解释为什么 R69 那条静态的 FMA 分数必然会漏判。

**灵感 2（似然盲区 → R69 的兜底证据本身就不可靠）**
直觉：高维密度不度量「在不在支撑上」。flow 把概率质量堆在低维流形附近时，流形外的「怪点」可以拿到比真实样本更高的 log p；更一般地，「典型性」问题说明密度高低与是否 ID 并不同向。R69 的 FMA 用 −log p 当「标定不可吸收的第二意见」，方向是对的，但**尺子错了**：它测的是「这条动作在策略里罕见吗」，而不是「这个世界还在策略的训练支撑里吗」。正确的尺子是**典型性**（相对参考集 log p 的标准化偏离）加上**分布无关的保形 p 值**，而不是原始密度。

**灵感 3（机器人 → 本体是一个环境伪造不了的见证）**
直觉：视觉可以被对抗渲染骗过，世界模型可以被一个「看起来很合理」的错误观测带偏，但**力矩/接触/能量守恒**骗不过：要让本体残差降低，你必须真的把身体动起来。于是有了一条和 R69「标定不可吸收通道」同构、但方向相反的冗余见证：R69 防的是「传感器被标定吸收」，R70 防的是「整个世界被偏移」。两种偏移模式在 (观测 OOD↑, 本体残差↓) 与 (观测 OOD↓, 本体残差↑) 上可分：前者是**世界/传感器变了身体没变**，后者是**身体退化而世界正常**——纯数据驱动的 OOD 检测对这两者恰好双盲。

**灵感 4（机器人 → 用动作检验世界，而不是只观测世界）**
直觉：R69 的信息动作是为了「消解动作模态的歧义」；R70 把同一套 VoI 机制**换了被消解的对象**：从「该选哪个动作」换成「世界是否还在支撑内」。轻推一下测摩擦、轻触一下测刚度、变焦/换曝光测传感器——这些探针的期望信息增益可以显式计算，且必须过和任务动作相同的安全认证与预算。这就是「主动 OOD 验证」：泛化能力的一部分来自**会做实验**，而不只是来自更大的训练集。

**灵感 5（二分 → OOD 也要再二分，否则「泛化」就是「冒险」）**
直觉：R69 把 uncertainty 分成 aleatoric/epistemic；R70 必须把 OOD 也分成两类，否则一遇偏移就只会刹车，泛化收益为零。**可解新颖性**：世界变了，但在支撑附近，存在安全探针能把判断拉回高置信（例如光照变了但几何没变）；**支撑缺口**：无论怎么问、怎么看，都没有可用的参考（例如全新物理地形、执行器损坏）。前者可以在**保形安全集**内探索并拿 resolution bonus；后者只能保守退避。R69 的 MCG/ECE 门控，恰好是「任务轴上的权重校准」这一特例。

**灵感 6（保证 → 从阈值启发式升级为分布无关证书）**
直觉：R69 到处是 TAU_FMA、TAU_EPI、τ_ece 这类手工阈值，它们的误报率没有任何保证。分布外泛化领域已经把这件事做成了定理：保形预测给**有限样本覆盖**，自适应保形（ACI）给**非可交换序列的长期覆盖**，e-process 用 Ville 不等式给**任意时刻误报控制**。把它们接进闭环，OOD 告警就从「调参」变成「有证书的告警」。代价是：保形只在协变量偏移、且标签函数不变时才对**正确的量**有保证；**概念偏移**下证书形式有效、语义空洞（定义 321）——这正是本轮最大的风险所在。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（非平稳闭环 MDP 与分布偏移过程）** 部署环境为时变 MDP 族 {M_t}，M_t = (S, A, P_t, R, γ, Ω, O_t)。分布偏移是一个**过程** ν_t = (ν_t^obs, ν_t^dyn, ν_t^emb, ν_t^task)，分别度量观测核、转移核、本体参数、任务/意图分布相对参考的偏离。关键：闭环数据分布 D_t = D(π, ν_t) 同时依赖策略 π，故 OOD 样本不是独立同分布地抽自 ν_t，而是**由被评估的策略自己生成**——存在**分布反馈**。

**定义 311（四轴偏移分解 SAD）** 对状态 x 给出可解释的偏移向量 ν(x)，四轴各有指定见证统计与参考集：
- **观测轴** obs：P(o|s) 变（光照/雾/传感器退化）；见证 = 表征空间两样本检验 + 重建残差。
- **动力学轴** dyn：P(s'|s,a) 变（摩擦/负载/风）；见证 = 动作条件一步预测残差 + 逆动力学一致性。
- **本体轴** emb：θ_body 变（磨损/标定漂移/执行器退化）；见证 = 力矩/接触/能量残差（定义 315）。
- **任务轴** task：目标/意图分布变；见证 = 目标后验与人类指令一致性。
不同轴走不同兜底策略；非唯一归因时按最保守轴处理（定义 324）。

**定义 312（可解新颖性 vs 支撑缺口 RSD）** 设训练支撑 S_train（表征空间）。对 x ∉ S_train：
- 若存在安全信息动作 g 使 VoI_support(g) = H(1[x∈S_train]) − E_y[H(1[x∈S_train]|y,g)] > c(g)，且 g 过认证，则称 x 为**可解新颖性**（resolvable novelty）；
- 否则称**支撑缺口**（support gap）。
前者允许在保形安全集内探索并获 resolution bonus；后者只能保守。这是 R69 的 ale/epi 二分在「模型有效性」上的镜像：可解性不再关于动作模态，而关于**世界是否还在支撑内**。

**定义 313（典型性分数，替代原始似然 TYP）** 原始流密度 log p_θ(x) 不是 OOD 分数。定义典型性 T(x) = |log p_θ(x) − μ_ref| / σ_ref（μ_ref, σ_ref 为参考集上 log p 的均值/标准差），以及混合分数 s_OOD(x) = (T(x), d_feat(x))，d_feat 为特征空间到参考核心集（core-set）的距离。用典型性而非密度，直接修复 R69 FMA 的似然盲区（引理 19）。

**定义 314（顺序保形检验 SCT）** 给定非一致性分数 s 与参考校准集 {s_i}_{i=1..n}，保形 p 值 p(x) = (1 + #{i : s_i ≥ s(x)}) / (n+1)；当 p(x) < α 时告警。为处理闭环非可交换性，采用**自适应保形推断（ACI）**：维护 α_t，α_{t+1} = α_t + γ(α_target − err_t)，err_t = 1[p_t < α_t]，给出长期覆盖率 ≥ 1−α−O(γ)（引理 20）。告警的**任意时刻误报控制**用 e-process {E_t}，满足 Ville 不等式 P(sup_t E_t ≥ 1/δ) ≤ δ。

**定义 315（本体一致性见证 EOW）** 本体残差 r_emb = (r_τ, r_contact, r_energy)：
- r_τ = ‖τ_meas − τ_model(q, q̇, q̈)‖（力矩一致性）；
- r_contact = 接触模型残差（穿透/滑移/刚度）；
- r_energy = 能量收支不平衡量。
本体一致性 C_emb = 1[r_emb ≤ τ_emb ∧ 可达性 ∧ 能量守恒]。关键分离性：**要伪造 r_emb 必须真的移动身体**，故视觉/世界模型可骗过观测轴，骗不过本体轴（引理 21）。

**定义 316（主动 OOD 验证 AOV）** 信息动作 g 在动力学模型下做假设检验：H0 = 世界仍在支撑内，H1 = 已偏移。选 g* = argmax_g E[KL(p(y|g,H1) ‖ p(y|g,H0))] − c(g)，s.t. risk(g) ≤ ε_int 且 g 过 C-RAS-WM 认证（复用 R69 定义 302 / 定理 17）。典型动作：轻推测摩擦、轻触测接触刚度、变焦/曝光测传感器。每单位时间 ≤ 1 次（继承 R69 交互预算）。

**定义 317（分布反馈校正 WCR）** 闭环参考集须按策略重要性加权：w(a,s) = π_ref(a|s) / π_deploy(a|s)，有效样本数 ESS = (Σw)² / Σw²。ESS < τ_ess ⇒ 参考不可验证，直接判「不可判定 OOD」并保守。这防御幸存者偏差：**会躲开新状态的策略，不能因此「看起来」没有 OOD**。

**定义 318（漂移策略治理 DPG）** 映射 (四轴幅度, 保形告警, 支撑缺口标志, C_emb, ESS) → 保守等级 λ_out：
- 支撑缺口 ∨ 告警 ∨ ¬C_emb ∨ ESS 不足 → λ_out = λ_floor(U_ale + U_epi)（等同 R69 最保守路径）；
- 可解新颖性且认证安全 → 允许在保形安全集 𝒮_conf 内探索，获 resolution bonus；
- 单调性：λ_out 对每个轴幅度、告警严重度非减（定义 323）。

**定义 319（保形安全集与安全探索包络）** 𝒮_conf(x) = {a : 动力学预测的 p95 边界包络内 ∧ 可达 ∧ 动作保形分位数内}。只有 a ∈ 𝒮_conf 才允许带 resolution bonus；离开 𝒮_conf 立即回退。这把「泛化」限制在可认证的探索空间里。

**定义 320（两级时间尺度与零学习写操作）** 实时层（<5ms）只做检测/回退/治理，**禁止任何在线学习写操作**（继承 R66–R69 不变式）；慢速层把 OOD 样本、告警、反事实写入**隔离影子缓冲 ALB**，离线训练/校准后经双重缓冲与证书换装（J_ARGUS）才生效。**检测（retreat）与适应（adapt）严格分离**——这是把「泛化」纳入安全闭环的前提。

**定义 321（协变量偏移 vs 概念偏移）** 协变量偏移：P(x) 变而 P(y|x)（含安全标签函数）不变；概念偏移：P(y|x) 变。保形只在协变量偏移下对**固定标签函数**有覆盖保证；概念偏移下保形覆盖的是过时的标签，证书「形式有效、语义空洞」。定义概念偏移检验：r_concept = 一致性(预测风险标签, 人类/物理复核标签)。r_concept 越界 ⇒ 保形证书降级为「不适用」。

**定义 322（泛化证书 J_ARGUS）** J_ARGUS = (J_FLUID, conformal_coverage_emp, e_process_state, shift_axis_vec, support_gap_flag, ess, C_emb, r_concept, calib_set_hash, argus_ver)。Valid ⇔ Valid(J_FLUID) ∧ 覆盖率在容差内 ∧ 概念偏移检验通过 ∧ ESS 足够 ∧ C_emb ∧ 告警未触发。

**定义 323（偏移单调保守性）** λ_out(ν) 对 ν 的每个分量非减，且对告警指示非减；组合时取 **max 而非平均**（任一处可疑即收紧）。继承 R68「只收紧」铁律，但触发源从单一残差升级为四轴 + 保形证据。

**定义 324（偏移归因的可识别性）** 四轴并非总可分离：观测退化与动力学变化都能抬高一步预测残差。用**干预性**区分——主动改变某轴（AOV 探针），看残差是否随之变化，只有真正由该轴引起的才归因。归因不确定性进入 J_ARGUS；非唯一归因时按最保守轴处理。

**定义 325（ARGUS-RAS 总览）** ARGUS-RAS = (FLUID-RAS, SAD, TYP, SCT, EOW, AOV, RSD, DPG, WCR, ALB)。三不变式：(i) 实时流零学习写操作；(ii) 任一 OOD 证据可疑即单调回退，安全侧永不弱于 R69/R68；(iii) 适应只能经隔离缓冲 + 证书换装，绝不在线改变安全函数。

# IP-264 SAD：四轴偏移分解（复用 R69 trunk 表征）
def decompose_shift(z, o, a_prev, tau_meas, q, qd, qdd, ref):
    nu_obs = two_sample_stat(z, ref.z)                    # 观测轴
    nu_dyn = pred_residual(o, a_prev, ref.dynamics)       # 动力学轴
    nu_emb = embodiment_residual(tau_meas, q, qd, qdd)    # 本体轴（EOW）
    nu_task = intent_consistency(o, ref.intent)           # 任务轴
    return dict(obs=nu_obs, dyn=nu_dyn, emb=nu_emb, task=nu_task)

# IP-265/266 SCT+TYP：典型性 + 保形 p 值 + ACI + e-process
class ConformalOOD:
    def __init__(self, scores_ref, alpha=0.05, gamma=0.01, delta=1e-3):
        self.s_ref, self.alpha_t, self.gamma = scores_ref, alpha, gamma
        self.e, self.delta = 1.0, delta
    def score(self, x, logp, ref_mu, ref_sd):
        return (abs(logp - ref_mu) / ref_sd, d_feat(x, self.s_ref))   # TYP
    def p_value(self, s):
        return (1 + np.sum(self.s_ref >= s)) / (len(self.s_ref) + 1)
    def step(self, s):
        p = self.p_value(s)
        err = float(p < self.alpha_t)
        self.alpha_t += self.gamma * (0.05 - err)            # ACI
        self.e *= (1 + 0.05 * (err - self.delta))            # e-process
        return p, (p < self.alpha_t), (self.e >= 1 / self.delta)

# IP-267 EOW：本体一致性（环境伪造不了）
def embodiment_ok(tau_meas, q, qd, qdd, tau_model, contact, energy):
    r = max(norm(tau_meas - tau_model(q, qd, qdd)),
            contact.residual, abs(energy.balance))
    return r <= TAU_EMB

# IP-269 RSD：可解新颖性 vs 支撑缺口

    if g is not None and voi_support(x, g, ref) > cost(g):
        return 'resolvable'
    return 'gap'

    k = M.c_ras_wm.certified_prefix(A, ..., M.wm_preds)

    if not M.safe_set.contains(a, M.x_prime, M.ref):       # 𝒮_conf
        lam = max(lam, lam_floor(U_ale + U_epi)); exploit = False
    # 5) 审计 + 泛化证书；OOD 样本进隔离影子缓冲（不在线学习）
    if kind != 'in' or alarm:
        M.alb.enqueue(o, nu, kind, a, p)                    # IP-273，离线才用
    M.vqa_i.submit_async(g, nu, kind, p, anytime, C_emb)
    return k, lam, a, J_ARGUS(M, nu, kind, p, ess, C_emb)
```

## 3. 推导

**引理 19（似然盲区 / likelihood blindness）** 存在数据分布与流模型使 E_{x~OOD}[log p_θ(x)] ≥ E_{x~ID}[log p_θ(x)]：当 ID 数据集中在低维流形、而模型把概率质量堆在流形边界/近邻时，流形外的 atypical 点可获得高于 ID 的密度。故密度不度量「是否在支撑上」。系：R69 的 a_score（FMA）不是有效 OOD 检验；其「第二意见」只在**同一参考分布内**有效，跨分布时必须换成典型性 + 保形 p 值（定义 313–314）。

**引理 20（任意时刻与长期覆盖）** 对非可交换序列，ACI 给出长期误覆盖率 (1/T)Σ err_t ≤ α + O(1/(γT))（高概率）；e-process 由 Ville 不等式给 P(∃t : E_t ≥ 1/δ) ≤ δ。故 OOD 告警的误报具有**分布无关的有限样本 / 任意时刻**保证，而非 R69 的阈值启发式。系：告警可以从「调 TAU」变成「设 δ」。

**引理 21（本体见证的分离性）** 若本体参数在名义范围，则 r_emb ≤ 测量噪声；若仅观测/世界模型被偏移（含对抗渲染、传感器欺骗），r_emb 仍名义而 obs-OOD 统计上升；若本体退化（磨损），r_emb 上升而观测 OOD 可能不显著。故 (obs↑, emb↓) 与 (obs↓, emb↑) 是可区分的两种偏移模式，补足纯数据驱动 OOD 检测对「静默退化」与「合理假象」的双盲——这是 R69 反吸收引理（引理 13/17）在**世界侧**的镜像。

**定理 18（ARGUS 严格包含 FLUID 与 R68）** 在无告警、无支撑缺口、ESS 足够、C_emb 成立时，ARGUS 与 FLUID 逐指令相同（于是 R68 是其在「永不交互」边界的退化）；任一 OOD 证据越界时 λ_out ≥ R69 的 λ，故风险 ≤ R69 的保守路径。可解新颖性在 𝒮_conf 内允许探索，严格优于「一律保守」当且仅当 VoI_support > 成本。**安全侧不做任何让步，泛化侧只在获得认证时获益。**

**定理 19（告警误报控制与有限回退）** H0（未偏移）下，e-process 误报率 ≤ δ，ACI 长期误覆盖 ≤ α + o(1)；回退触发是稀有事件，且回退**无状态累积**（λ_out 由当轮证据决定、多轴取 max），故不出现「一次误报永久保守」的棘轮效应。

**定理 20（分布反馈下的不可欺骗性）** 在 WCR 重要性加权与 ESS 门控下，策略通过**避开**新状态使经验 OOD 率下降的幅度被重要性权重偏差界住：|Ê_OOD − E_OOD| ≤ B·√(1 − ESS/n)（B 为核/分数有界常数）。ESS 不足即拒绝结论，因此「躲开 OOD 就报告安全」不被允许——幸存者偏差被显式处理。

**定理 21（检测与适应分离的无突变性）** 实时层无学习写操作，λ_out 只依赖当轮证据与证书 ⇒ 控制连续、无突变；适应经影子缓冲 + 证书换装，换装点受 R68 定理 15 的提交/换装不变式约束 ⇒ 换装也不引入突变。

## 2. 形式化定义（要点版）

**定义 310（非平稳闭环 MDP）** 时变 MDP 族 {M_t}；偏移是过程 ν_t；闭环数据 D_t = D(π, ν_t) 依赖策略本身，存在**分布反馈**，样本不独立同分布。

**定义 311（四轴偏移 SAD）** 观测轴（P(o|s)）/ 动力学轴（P(s'|s,a)）/ 本体轴（θ_body）/ 任务轴（目标/意图），各有指定见证统计与参考集；非唯一归因按最保守轴处理。

**定义 312（可解新颖性 vs 支撑缺口 RSD）** x∉S_train 时，若存在安全探针使 `VoI_support(g) > c(g)` 且过认证，则为**可解新颖性**（可在 𝒮_conf 内探索、获 bonus）；否则为**支撑缺口**（只能保守）。

**定义 313（典型性 TYP）** `T(x)=|log p_θ(x)−μ_ref|/σ_ref`；混合分数 `(T, d_feat)`。密度不度量支撑，故用典型性替代 R69 的原始 −log p。

**定义 314（顺序保形 SCT）** 保形 p 值 `p(x)=(1+#{s_i≥s(x)})/(n+1)`；ACI `α_{t+1}=α_t+γ(α−err_t)` 给非可交换长期覆盖；e-process 由 Ville 给任意时刻误报 `≤δ`。

**定义 315（本体见证 EOW）** `r_emb=(r_τ,r_contact,r_energy)`，`C_emb=1[r_emb≤τ_emb ∧ 可达 ∧ 能量守恒]`；伪造它必须真的移动身体 ⇒ 环境骗不过本体轴。

**定义 316（主动 OOD 验证 AOV）** `g*=argmax E[KL(p(y|g,H1)‖p(y|g,H0))]−c(g)`，过 C-RAS-WM 认证，≤1 次/单位时间；轻推测摩擦、轻触测刚度、变焦测传感器。

**定义 317（分布反馈校正 WCR）** 重要性权重 `w=π_ref/π_deploy`，`ESS=(Σw)²/Σw²`；ESS 不足 ⇒ 不可判定 OOD、保守。防御「躲开 OOD 就报安全」的幸存者偏差。

**定义 318–319（治理 DPG 与保形安全集）** 缺口/告警/¬C_emb/ESS 不足 → `λ_out=λ_floor(U_ale+U_epi)`（R69 最保守）；可解且认证 → 𝒮_conf 内探索 + resolution bonus；离开 𝒮_conf 立即回退。

**定义 320（两级时间尺度）** 实时层只检测/回退/治理，**零学习写操作**（继承 R66–R69）；OOD 样本进隔离影子缓冲 ALB，离线训练/校准后经证书换装生效。检测与适应严格分离。

**定义 321（协变量 vs 概念偏移）** 保形仅在协变量偏移、固定安全标签函数时对**正确的量**有覆盖；概念偏移下覆盖过时标签，证书「形式有效、语义空洞」。用 `r_concept` 检验并降级证书。

**定义 322–323（证书与单调性）** `J_ARGUS=(J_FLUID, coverage, E_t, ν_vec, gap_flag, ESS, C_emb, r_concept, calib_hash, ver)`；`λ_out` 对每轴与告警非减，多轴取 **max**（继承「只收紧」铁律，触发源升级为四轴+保形）。

**定义 324（归因可识别性）** 四轴可能纠缠；用干预性 AOV 探针区分「哪个轴真的变了」，非唯一归因时按最保守轴。

**定义 325（总览三不变式）** ARGUS-RAS 三不变式：实时零学习写操作；任一 OOD 证据可疑即单调回退、安全侧永不弱于 R69/R68；适应只经隔离缓冲 + 证书换装。

    return dict(obs=two_sample_stat(z, ref.z),
                dyn=pred_residual(o, a_prev, ref.dynamics),

class ConformalOOD:
    def score(self, x, logp, ref_mu, ref_sd):
        return (abs(logp - ref_mu) / ref_sd, d_feat(x, self.s_ref))   # TYP
    def p_value(self, s):

    samples = M.fmp.sample(o, 4 if M.fmp.mode_head(z) > TAU_MODE else 1)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    nu    = M.sad.decompose_shift(z, o, M.last_a, M.tau, M.q, M.qd, M.qdd, M.ref)
    p, alarm, anytime = M.sct.step(M.sct.score(o, M.fmp.loglik(o), M.mu, M.sd))
    C_emb = M.eow.ok(M.tau, M.q, M.qd, M.qdd, M.contact, M.energy)
    ess   = M.wcr.effective_size(M.ref, M.policy)
    kind  = M.rsd.classify_novelty(o, M.ref, M.budget)
    g = (M.aov.choose_probe(o, nu, M.budget)
         if (kind == 'resolvable' and not alarm and C_emb) else None)
    if g is not None: kind = M.aov.verify_and_update(g, o, M.ref)
    lam, exploit = M.dpg.govern(nu, alarm or anytime, kind, C_emb, ess,
                                U_ale, U_epi, M.efs, M.last_r_res)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(M.x_prime, M.vista.H), ..., M.wm_preds)
    a = M.pi_sigma.prefix_dispatch(M.select_mode(modes, U_epi, lam).a[:k]) * lam
    if not M.safe_set.contains(a, M.x_prime, M.ref):                 # 𝒮_conf 硬约束
        lam = max(lam, lam_floor(U_ale + U_epi)); exploit = False
    if kind != 'in' or alarm: M.alb.enqueue(o, nu, kind, a, p)       # 离线才学
    M.vqa_i.submit_async(g, nu, kind, p, anytime, C_emb)
    return k, lam, a, J_ARGUS(M, nu, kind, p, ess, C_emb)
```

## 4. 推导

**引理 19（似然盲区）** 存在流模型与分布使 `E_OOD[log p_θ] ≥ E_ID[log p_θ]`；密度不度量是否在支撑上。系：R69 的 `a_score`（FMA）不是有效 OOD 检验，跨分布必须改用典型性 + 保形（定义 313–314）。

**引理 20（任意时刻与长期覆盖）** 非可交换序列下 ACI 给长期误覆盖 `≤α+O(1/(γT))`；e-process 由 Villes 给 `P(∃t:E_t≥1/δ)≤δ`。告警从「调 TAU」变为「设 δ」。

**引理 21（本体见证分离）** 本体名义 ⇒ `r_emb` 有界；仅观测/世界模型偏移 ⇒ `r_emb` 名义而 obs-OOD↑；本体退化 ⇒ `r_emb`↑而 obs-OOD 可能不显著。故 `(obs↑,emb↓)` 与 `(obs↓,emb↑)` 可分，补足纯数据驱动检测对「静默退化」与「合理假象」的双盲——R69 反吸收引理在世界侧的镜像。

**定理 18（严格包含 FLUID 与 R68）** 无告警/无缺口/ESS 足够/C_emb 时，ARGUS 与 FLUID 逐指令相同（R68 为「永不交互」边界退化）；任一 OOD 证据越界时 `λ_out≥λ_R69`，风险不高于 R69 保守路径；可解新颖性在 𝒮_conf 内探索，严格优于一律保守当且仅当 `VoI_support>成本`。安全不让步，泛化凭证书获益。

**定理 19（误报控制与有限回退）** H0 下 e-process 误报 `≤δ`、ACI 长期误覆盖 `≤α+o(1)`；回退无状态累积（当轮证据 + 多轴 max），无「一次误报永久保守」棘轮。

**定理 20（分布反馈不可欺骗）** WCR 重要性加权 + ESS 门控下，策略靠避开新状态压低经验 OOD 率的幅度被 `B·√(1−ESS/n)` 界住；ESS 不足即拒绝结论 ⇒ 幸存者偏差被显式处理。

**定理 21（检测/适应分离无突变）** 实时层无学习写操作、`λ_out` 只依赖当轮证据 ⇒ 控制连续；适应经影子缓冲 + 证书换装、受 R68 定理 15 提交/换装不变式约束 ⇒ 换装无突变。

## 7. 本轮最大风险

**一句话**：ARGUS-RAS 的全部安全保证建立在「参考校准集与部署世界**同标签函数、可重要性加权**」这一前提上——**若偏移是概念偏移（安全标签本身变了）或校准集被污染，保形给出的覆盖是对「过时/错误标签」的覆盖，系统会拿着一份形式完全有效、语义却空洞的证书，在真正危险的新世界里自信地报告「已验证安全」；这比 R69 的「问错」更隐蔽，因为这次连告警都不会响。**

**次级风险与缓解**：保形集污染/投毒（校准集来源审计 + 本体交叉验证 + r_concept 检验）；四轴归因错误（干预性 AOV + 非唯一按最保守轴）；探针本身不安全（复用 R69 定义 302 认证 + 定理 17 + 预算硬约束）；分布反馈使参考失真（WCR + ESS 门控）；实时计算超标（core-set/草图化保形 + 增量 ESS，探针走一次性预算）。
