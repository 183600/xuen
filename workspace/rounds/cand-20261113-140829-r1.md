# 第 66 轮（承接第 65 轮「VISTA 故障可归因四层闭环」IP-214~223；灵感循环新周期第 1 轮；本轮灵感：「抗干扰」×「推理延迟」）

> 第 65 轮用三阶段签名把「几何可证伪」升级为「故障可归因」，其自述的最大风险仍未触及一个更基本的物理事实：**归因发生在慢语义流，执行发生在快实时流**。FIR 要 15 维签名、AFA 要互信息、AIC-V 要 128 次认证，是 10–100Hz 乃至秒级的东西；而控制环 2.5ms 就把动作执行完了。于是 VISTA 的结论到达实时环时往往**已经过期**。第 65 轮的隐式假设是「归因正确 ⇒ 安全」，本轮补上被漏掉的那半句：「**归因正确、且尚未过期 ⇒ 安全**」。本轮不叠加第 6 个模态，而是换一个提问方式：
>
> **把推理延迟当作一种「计算干扰」来抗：安全证书不是快照而是易腐品，安全包络随证书年龄按可达性增长速率膨胀；快环用干扰观测器就地兜底，慢环用 anytime 归因按剩余有效期出证，二者在「时效包络」上交叠交接，永不出现无人负责的盲区。**

## 0. 直觉与动机

**灵感 1（抗干扰 → 不追「谁坏了」，先压「坏消息有多大」）**
直觉：第 65 轮的 FIR 要先分辨是几何幻觉、力偏置还是模型错，再决定膨胀哪个球——这条路依赖**归因正确且及时**。但控制论里有个更便宜的办法：干扰观测器（DOB/ADRC）把**所有未建模效应集中成一个总干扰** d̂，在快环里就地抵消，根本不需要知道"为什么"。抗干扰的本义不是"识别干扰源"，而是"**让闭环对总干扰呈现收缩**"。诚实之处在于：DOB 只能观测到它能观测到的干扰；传感器共模欺骗与不可观测模态会让 d̂ 出现**盲区**，而这正是本轮要显式建模的失效。

**灵感 2（推理延迟 → 证书是易腐品，安全包络随年龄膨胀）**
直觉：一张安全证书不是静态事实，而是一张**有保质期的通行证**。签发时刻 t0 的裕度 ρ0，会随"年龄" a 按安全函数的最坏衰减/可达集增长速度被吃掉。所以真正该问的不是"这个证书对不对"，而是"**它多旧了，过期前安全集缩到多小**"。把可达性管（reachability tube）装进证书，就得到"时效包络"：证书越旧，可信任集必须越保守地**膨胀（dilate）**。DILATE 由此得名——**Delay-Immune Latency-Aware Temporal Envelope（延迟免疫的时效包络）**。

**灵感 3（抗干扰 × 推理延迟 → 二者在控制论里是同一枚硬币）**
直觉：经典结论是，干扰抑制带宽与延迟裕度此消彼长——你把灵敏度函数在低频压得越低（抗干扰越强），相位滞后 e^{-jωτ} 就越早把相位裕度吃光（可容忍的延迟越小），这正是 Bode 灵敏度积分/延迟边际的内容。所以"既想要极快的归因、又想要极强的抗干扰"在物理上不可兼得；本轮不追求两者都最优，而是**显式地站在一条「时效-干扰-归因」前沿上**，并据此决定 k*、算力预算与兜底切换点。

**灵感 4（三灵感合流 → DILATE：快慢双环 + 时效包络 + 无推断兜底）**
闭环：快环（DOB 总干扰抑制 + 鲁棒事件触发 + 时效包络评估）与慢环（VPG/FIR/AFA/CSP-V 的 anytime 版本，出带 t0/τ_max 的时序证书）**时间尺度分离**；慢环结论带年龄进入快环；快环在证书新鲜期执行认证前缀，在临近过期时**提前**切到 passivity 兜底（交叠而非接力，避免盲区）；兜底不依赖任何归因。二者输出合成 J_dilate。

**灵感 5（VISTA/GRIP 组件的原位升级）**
- **CSC → TSC/DLP**：块级证书升级为**时序安全证书**（带签发时刻、有效期、增长率），执行前缀 k* 再被"剩余有效期/步长"截断——"长预测、短执行"升级为"**长预测、新鲜执行**"。
- **FIR/AFA → ANY**：归因与探针变成 **anytime**，任何时刻被打断都返回一个**单调收紧且始终有效**的后验/证书；探针选择从互信息升级为**单位毫秒的信息增益（VoC）**。
- **RSC-V → RSC-G**：球半径除归因定向外，再叠加**年龄增长率**（旧证据只允许收紧、不允许放宽）。
- **WCV-V → WCV-A**：搜索域增**年龄膨胀约束** E(a)，并按后验与年龄双重边缘化取尾部。
- **CSP-V → CSP-W**：块边需满足**弱硬实时契约**（m-of-k 截止期）与 wcet 预算。
- **AIC-V → AIC-D**：干扰集增**延迟抖动/抢占/块重放与传感器共模**，并把"归因正确"降级为"**在时效内安全**"。
- **J_vista → J_dilate**：证书增 `tsc(t0, τ_max, growth)`、`age`、`dob_residual`、`ret_stats`、`fallback_passivity_ver`、`weakly_hard_ver`。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（DILATE 闭环）**：DILATE = (GRIP, VISTA, TSC, AEB, DOB, RET, ANY, PFS, DLP, CAB, AIC-D, J_dilate)。定位：VISTA 的「抗延迟 + 抗干扰」升级。**不变式**：实时流在任何时刻要么持有**未过期的** TSC，要么处于**经过验证的** PFS 兜底；任何时刻都存在一个**不依赖新鲜推断**的安全包络；语义流的一切产物都必须携带 `(t0, τ_max, growth)`。
- **定义 234（时序安全证书 TSC）**：TSC=(x0, K_safe, ρ0, t0, τ_max, g, δ_guard, δ_fb)。ρ0 为签发时安全裕度（继承 VISTA 的 CSC/ρ_safe）；t0 为签发时刻；τ_max 为新鲜期；g 为增长模型（定义 236）；δ_guard 为提前交接保护带；δ_fb 为兜底 passivity 保证。`Valid(TSC,t) ⇔ 0 ≤ t−t0 ≤ τ_max ∧ ρ0 − γ(t−t0) ≥ 0`。
- **定义 235（年龄膨胀包络 AEB）**：以安全函数 h（CBF）表达，定义年龄膨胀算子 D_a 与包络
  E(a) = {x : h(x) ≥ ρ0 − γ(a)}，γ(0)=0，γ 单调不减。
  性质：a1≤a2 ⇒ E(a2) ⊆ E(a1)；a=0 时 E(0) 退化为第 65 轮证书集。**E(a) 保守但永远 sound**；它把"延迟"翻译成"几何上更大的不可信域"。
- **定义 236（干扰-年龄耦合增长率）**：闭环安全函数满足 ISS 型不等式
  ḣ ≥ −α h + β(‖d‖ + ε_dob)，‖d‖≤D，
  其中 α 为残余自然衰减率、β 为干扰增益、ε_dob 为 DOB 残差上界。由比较引理得
  γ(a) = (1−e^{−αa})ρ0 + (β/α)(1−e^{−αa})D̃，D̃ = D+ε_dob。
  若 α→0 取极限 γ(a) = ρ0·0 + βD̃·a（线性吃裕度）。**注意 γ 同时受 α 与 D̃ 控制，这即是「抗干扰」进入「有效期」的通道。**
- **定义 237（时延裕度与有效期）**：定义快环的**时延裕度** τ_dm = sup{τ : 含纯延迟 e^{−jωτ} 的闭环仍前向不变/稳定}。证书有效期
  τ_max = inf{a : γ(a) ≥ ρ0} = (1/α)·ln(1 + α ρ0/(β D̃))（α>0）。
  关键对偶：∂τ_max/∂D̃ < 0——**残余干扰越小，证书越「耐放」**；抗干扰直接购买延迟容忍。
- **定义 238（鲁棒事件触发 RET）**：快环维护残差 r_t（DOB 残差或 h 的下降率），CUSUM 统计量
  S_t = max(0, S_{t−1} + ‖r_t‖ − ν)，
  仅当 S_t>θ 且距上次唤醒 ≥ τ_dwell 时唤醒慢环。ν 取噪声/共模干扰上界，θ 由检测延迟与误报权衡。保证：噪声 ≤ν 时无虚假触发；驻留时间 τ_dwell>0 排除 Zeno；检测延迟 ≤ θ/(ρ_drift−ν)。
- **定义 239（anytime 归因与出证 ANY）**：把 VISTA 的 FIR/AFA/CSP 视为 anytime 算法，返回证书序列
  (ρ0^{(0)} ≥ ρ0^{(1)} ≥ …) 与后验序列，且**每个中断点都给出一个有效上界**；以 τ_deadline 为硬截止，以**单位毫秒的裕度增益** VoC=Δρ0/Δms 调度。被打断时返回"当前最紧的有效证书"，绝不返回半成品。
- **定义 240（无推断兜底 PFS）**：PFS 为 passivity/能量整形控制 u_fb，使闭环关于 (d, h) 耗散，存在存储函数 S 与安全集 Ω_fb，使得 ‖d‖≤D 时对任意 u_fb 有 x(t)∈Ω_fb。**PFS 不需要 fault_posterior、不需要归因，也不读语义流**；它是"不知道原因也能安全"的最后一层。
- **定义 241（延迟感知前缀规划 DLP）**：执行前缀
  k* = min(k*_CSC, ⌊(τ_max − δ_guard − τ_comp)/Δt⌋)，
  其中 τ_comp 为一次重归因的最坏计算时延，Δt 为控制周期。若 k*<1 则进入 **hold/重规划**而非盲执行。这把第 65 轮"短执行"收紧为"**只在证据新鲜期内执行**"。
- **定义 242（计算-年龄预算 CAB）**：在弱硬实时（m-of-k）约束下，把语义算力分配给 {VPG,FIR,AFA,CSP-V,AIC-D}，最小化期望风险
  min E[ risk(age, fault_entropy) ] s.t. 任意 k 个截止期内至少 m 个按时，Σ wcet_i ≤ B。
  调度准则：优先服务"**风险×年龄斜率**"最大的任务（旧且关键者先算）。
- **定义 243（弱硬实时安全契约）**：记截止期序列 D_1,D_2,…。若在任意连续 k 个截止期中至多 m 个 miss，则称 (m,k)-满足。DILATE 的安全结论不要求全满足，只要求 **(m,k)-满足 + PFS 覆盖**：miss 期间由 PFS 兜底，其安全性与 miss 次数无关。
- **定义 244（干扰分类与共模）**：E_D = E_phys × E_sens × E_comp。E_phys 为外力/接触扰动；E_sens 为噪声/偏置/欺骗与**跨模态共模**；**E_comp 为推理延迟**（计算抖动、抢占、块重放、通信延迟）——本轮把它显式列为一种**作用于控制环的干扰**，而不仅是"算得慢"。
- **定义 245（AIC-D 干扰/延迟对抗认证）**：在 E_D 上认证：对抗延迟/抖动、传感器欺骗、最坏扰动与共模。ρ_dir 增延迟/抢占样本（n_cert 128→160，其中 32 给 E_comp），ρ_force 在最坏扰动与最坏共模下取最坏；J_dir 增 `delay_margin_ver`、`age_budget_ver`、`fallback_passivity_ver`。**共模/超界扰动下不要求归因正确，只要求被判 stale 并切 PFS。**
- **定义 246（干涉-延迟-归因前沿）**：给定算力 C 与最坏干扰 D，定义可达三元组 (τ_det, ω_bw, A)（检测延迟、干扰抑制带宽、归因精度）。前沿 𝔉_C,D = Pareto 边界。DILATE 不追求单点最优，而是**在 𝔉 上选点**：τ_det 由 RET/ANY 决定，ω_bw 由 DOB 决定，A 由 FIR/CAB 决定；三者通过 Bode/延迟边际耦合（见命题 2）。
- **定义 247（DILATE 证书 J_dilate）**：J_dilate = (J_vista, tsc=(t0,τ_max,g), age, dob_residual, ret_stats, any_schedule, fallback_passivity_ver, weakly_hard_ver, aic_d_ver)。`Valid(J_dilate,t) ⇔ Valid(J_vista) ∧ Valid(TSC,t) ∧ (FallbackReady ∨ age ≤ τ_max−δ_guard) ∧ (m,k)-满足已审计 ∧ RET 无抖动`。审计链新增：**为何此刻还能信这张证书（age/τ_max）、过期后谁兜底（PFS）、算力为何这样分（CAB）**。
- **定义 248（DILATE 闭环算子）**：语义流 [LiDAR→LSF→USR/MEL→VPG→ACH→阶段切分→VCV→FIR(anytime)→AFA→WCV-A→CSP-W→**TSC 出证**→CSC 前缀→Shield→执行→EV_exec→RSC-G→OLP→DIR→AIC-D]；实时流 [锚点读→**DOB 残差→AEB 评估→RET 判定**→CSC 早停→WCV-A 编译→π_σ 前缀派发→**TSC 年龄检查→PFS 交接**→J_dilate 构建]。不变式：延迟只改变"信任半径"，绝不改变"安全兜底"的存在性。

## 2. 关键算法骨架

```python
# 快环：DOB + 时效包络 + 事件触发（实时，不读语义流）
d_hat = dob.estimate(x, u, dt)                 # 总干扰估计（无需归因）
r = residual(x, u, d_hat)                      # 残差（同时是触发信号）
age = t - tsc.t0
if age > tsc.tau_max - tsc.delta_guard:        # 临近过期 → 提前交叠兜底
    mode = 'FALLBACK_PFS'
elif any_cusum(r) > theta and (t - last_wake) > tau_dwell:
    wake_semantic_stream()                     # 鲁棒事件触发（抗噪声误报）
    mode = 'GUIDED'
if mode == 'GUIDED' and not aeb_valid(tsc, age):
    mode = 'FALLBACK_PFS'                       # 包络已不 sound，绝不盲信

# 慢环：anytime 归因，按 VoC 调度，任何中断点都出有效证书
post, rho0 = fir.anytime(phases, deadline=t+tau_comp, monotone=True)
tsc = TSC(x0=x, K_safe=K, rho0=rho0,
          t0=now(), tau_max=solve_tau_max(rho0, alpha, beta, D_tilde),
          g=growth(alpha, beta, D_tilde), delta_guard=delta_g)

# 前缀：只在新鲜期内执行
k_star = min(csc.certified_prefix(A, post, m, alpha_chunk),
             floor((tsc.tau_max - tsc.delta_guard - tau_comp)/dt))
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（时效包络可靠性）**：若 h 满足 ḣ ≥ −αh + β(‖d‖+ε_dob)、‖d‖≤D，则对年龄 a∈[0,τ_max] 有 h(x(t0+a)) ≥ ρ0 − γ(a)，即真实状态落在 E(a) 内；且 τ_max 有闭式 (1/α)ln(1+αρ0/(βD̃))。于是**延迟不再是一个"未证明的空白"，而是被换算成可计算的保守半径**。
- **引理 10（鲁棒触发的检测-误报-无 Zeno）**：CUSUM 阈值 θ、死区 ν、驻留 τ_dwell 下：噪声≤ν 不误触发；检测延迟 ≤θ/(ρ_drift−ν)；驻留时间保证 Zeno 自由。故"抗干扰"在触发层是可证明的，而非经验调参。
- **定理 9（DILATE 延迟-干扰安全）**：在 A94–A98 下，若 `Valid(J_dilate,t)` 或 PFS 就绪，则执行全程（含延迟抖动与 (m,k) 截止期 miss）满足力/几何/滑移安全。核心是**交接不变式**：τ_max 按 PFS 安全集 Ω_fb 反解（要求 E(τ_max)⊆Ω_fb 且提前 δ_guard 交叠），故 GUIDED→FALLBACK **不存在无人负责的盲区**。
- **定理 10（anytime+DLP 的前沿近优性）**：给定算力与延迟裕度，CAB 的 VoC 贪心在单调收紧假设下达到 𝔉 上 ε-近优点；DLP 的 k*=min(k*_CSC,τ_bud/Δt) 使块承诺的越界概率 ≤α_chunk+δ_fi+α_vis+α_delay。第 65 轮的"长预测、短执行"由此推广为"**长预测、新鲜执行**"。
- **命题 2（Bode 型三难下界）**：对最小相位 LTI 安全环，灵敏度积分 ∫ln|S(jω)|dω=0 且纯延迟使穿越频率 ω_c≲1/τ；故存在常数 c>0 使 τ_det·D_eff ≥ c（同一量级上不可同时任意小）。这给出"抗干扰—抗延迟—归因精度"三者的**不可兼得性**，也解释了为何 DILATE 选择"分环 + 兜底"而非"更快更准的单一环"。
- **实时性**：DOB(<0.1ms)+AEB(<0.02ms)+RET(<0.05ms)+TSC 年龄检查(<0.01ms)+PFS 切换(<0.02ms)，其余同 VISTA，目标仍 ≤2.5ms；语义 anytime 全在低频流，按 CAB 预算调度。

## 5. 本轮最大风险

## 2. 形式化定义（完整版）

**定义 233（DILATE 闭环）** DILATE 是 VISTA 的「抗延迟 + 抗干扰」升级：在 VISTA 的语义流/实时流骨架上挂载 TSC（时序证书）、AEB（年龄膨胀包络）、DOB（干扰观测器）、RET（鲁棒事件触发）、ANY（anytime 归因）、PFS（passivity 兜底）、DLP（延迟感知前缀）、CAB（算力-年龄预算），并原位升级 RSC-V→RSC-G、WCV-V→WCV-A、CSP-V→CSP-W、AIC-V→AIC-D、J_vista→J_dilate。**不变式**：实时流在任意时刻要么持有一张未过期的 TSC，要么处于经过验证的 PFS 兜底；任何时刻都存在一个不依赖新鲜推断的安全包络；语义流的一切产物必须携带 `(t0, τ_max, g)`。**语义流是作者，实时流是只执行"新鲜预印本"的读者，PFS 是不需要读懂论文也能保命的机械保险。**

**定义 234（时序安全证书 TSC）** 记签发时刻 t0、签发裕度 ρ0、块前缀 K_safe。TSC=(x0, K_safe, ρ0, t0, τ_max, g, δ_guard, δ_fb)。其中 g 为增长模型（定义 236），δ_guard 为提前交接保护带（在证书仍有效时就开始交叠），δ_fb 为 PFS 的覆盖保证。定义
`Valid(TSC,t) ⇔ 0 ≤ t−t0 ≤ τ_max ∧ ρ0 − γ(t−t0) ≥ 0`。
与第 65 轮 CSC 的本质差别：CSC 只说"这 k* 步安全"，TSC 说"**这 k* 步在多长时间内仍然安全**"。

**定义 235（年龄膨胀包络 AEB）** 设安全函数 h(x)≥0 刻画安全集。定义年龄膨胀算子 D_a 与包络
E(a) = {x : h(x) ≥ ρ0 − γ(a)}。
性质：(i) γ(0)=0，E(0) 退化为第 65 轮证书集；(ii) γ 单调不减 ⇒ a1≤a2 时 E(a2)⊆E(a1)；(iii) 只要 ρ0−γ(a)≥0，E(a) 对可达状态 sound。AEB 把"我多久没更新了"翻译成"我还敢信多大范围"——**延迟因此不再是论证里的空白，而是一个可计算的保守半径**。WCV-A 的搜索域在此包络内取交集。

**定义 236（干扰-年龄耦合增长率）** 设闭环安全函数满足 ISS 型不等式
ḣ ≥ −αh + β(‖d‖ + ε_dob)，‖d‖≤D，D̃=D+ε_dob。
由比较引理（Gronwall）：
h(x(t0+a)) ≥ e^{−αa}ρ0 − (β/α)(1−e^{−αa})D̃ = ρ0 − γ(a)，
其中 γ(a)=(1−e^{−αa})ρ0 + (β/α)(1−e^{−αa})D̃。
于是 γ(0)=0，γ̇(0)=αρ0+βD̃。**抗干扰（减小 D̃/β）直接减慢 γ 的增长**；控制（增大 α）在瞬态与稳态间有非平凡的权衡。

**定义 237（时延裕度与证书有效期）** 快环含计算/通信纯延迟 τ（E_comp），定义时延裕度
τ_dm = sup{τ : 含 e^{−jωτ} 的闭环仍稳定且前向不变}。
证书有效期由 γ(τ_max)=ρ0 反解：
τ_max = (1/α)·ln(1 + αρ0/(βD̃))（α>0）；α→0 时 τ_max = ρ0/(βD̃)。
**核心对偶**：∂τ_max/∂D̃ = −ρ0/(βD̃²(1+αρ0/(βD̃))) < 0。即**残余干扰越小，证书越耐放；抗干扰就是在购买推理延迟容忍度**。这是本轮两个灵感词的定量桥梁。

**定义 238（鲁棒事件触发 RET）** 快环维护残差 r_t（DOB 残差或 h 的实测下降率超出模型预测的部分），CUSUM
S_t = max(0, S_{t−1} + ‖r_t‖ − ν)，S_0=0。
仅当 S_t>θ 且 t−last_wake≥τ_dwell 时唤醒慢环。取 ν ≥ 噪声/共模干扰上界 ⇒ ‖r_t‖≤ν 时 S_t 不增长、无虚假触发；θ 越大误报越少、检测延迟越大。**抗干扰在触发层是可证的**：噪声抑制（ν）、误报/延迟权衡（θ）、无 Zeno（τ_dwell）。

**定义 239（anytime 归因与出证 ANY）** 把 VISTA 的 FIR/AFA/CSP-V 改造为 anytime 算法：在任意中断时刻 k 返回 `(post_k, ρ0^{(k)}, K_safe^{(k)})`，且满足单调性 `ρ0^{(0)} ≥ ρ0^{(1)} ≥ …`、每个中断点都是**有效上界**（不会因提前中断而给出过紧/过松的错误结论）。调度以 τ_deadline 为硬截止，按 VoC=Δρ0/Δms 优先服务高价值计算。探针选择由第 65 轮的"最大化故障假设互信息"升级为"**最大化单位毫秒的判别信息（VoC-I）**"。

**定义 240（无推断兜底 PFS）** PFS 为 passivity/能量整形控制 u_fb，使闭环关于 (d,h) 耗散：存在存储函数 S 与安全不变集 Ω_fb，使得对任意 ‖d‖≤D 都有 x(t)∈Ω_fb，**且该保证不依赖 fault_posterior、不读语义流、不需要任何归因**。设计条件：Ω_fb ⊇ E(τ_max)（兜底必须覆盖证书过期时的最坏可达状态）；否则必须缩短 τ_max 或收紧 D。PFS 是"不知道原因也能安全"的最后一层。

**定义 241（延迟感知前缀规划 DLP）** 对第 65 轮的认证前缀 k*_CSC，施加时效截断
k* = min(k*_CSC, ⌊(τ_max − δ_guard − τ_comp)/Δt⌋)，
其中 τ_comp 为一次重归因的最坏计算时延，Δt 为控制周期。若 k*<1，则进入 hold/重规划（**绝不盲执行**）。这把"长预测、短执行"收紧为"长预测、**新鲜执行**"：视界 H 可以很长（只用于前瞻与一致性），但执行承诺只能落在证书的新鲜期内。

**定义 242（计算-年龄预算 CAB）** 在弱硬实时约束下，把语义算力分配给任务集 {VPG,FIR,AFA,CSP-V,AIC-D}：
min_{schedule} E[ risk(age_i, H(P(H|ρ))) ]
s.t. ∀k: #{miss in any k deadlines} ≤ m，Σ wcet_i ≤ B。
贪心准则：优先服务"**风险×年龄斜率**"最大者（旧且关键者先算）。这把第 65 轮"全部语义流低频跑"升级为"按风险的算力经济"。

**定义 243（弱硬实时安全契约）** 记截止期序列 D_1,D_2,…。若任意连续 k 个截止期中至多 m 个 miss，称 (m,k)-满足。DILATE 的安全结论**不要求硬实时全满足**，只要求 (m,k)-满足 + PFS 覆盖：miss 期间由 PFS 兜底，其安全性与 miss 次数无关。这是把"实时性"从"必须按时"降级为"**可以偶尔迟到，但不许裸奔**"。

**定义 244（干扰分类与共模）** E_D = E_phys × E_sens × E_comp。E_phys：外力/接触扰动；E_sens：噪声/偏置/欺骗与**跨模态共模**（同一分布外源同时污染视觉与力，承接第 65 轮最大风险）；**E_comp：推理延迟**——计算抖动、抢占、块重放、通信延迟。本轮的关键立场：**推理延迟是作用于控制环的一种干扰，而不是单纯的"算得慢"**；因此它可以、也应当被"抗干扰"的手段处理。

**定义 245（AIC-D 干扰/延迟对抗认证）** 在 E_D 上认证：对抗延迟/抖动、传感器欺骗、最坏扰动与共模。ρ_dir 增 E_comp 样本（n_cert 128→160，其中 32 给延迟/抢占/共模），ρ_force 在最坏扰动与最坏共模下取最坏；J_dir 增 `delay_margin_ver`、`age_budget_ver`、`fallback_passivity_ver`。**共模/超界扰动下不要求归因正确，只要求能被判 stale 并切 PFS**——这是与第 65 轮"必须归因"的根本区别。

**定义 246（干涉-延迟-归因前沿）** 给定算力 C 与最坏干扰 D，定义可达三元组 (τ_det, ω_bw, A)（检测延迟、干扰抑制带宽、归因精度）构成的可行域与 Pareto 前沿 𝔉_{C,D}。DILATE 不追求单点最优，而是**在 𝔉 上选点**：τ_det 由 RET/ANY 决定，ω_bw 由 DOB 决定，A 由 FIR/CAB 决定。三者通过 Bode/延迟边际耦合（命题 2），故"更快、更强、更准"不可同时取得。

**定义 247（DILATE 证书 J_dilate）** J_dilate=(J_vista, tsc=(t0,τ_max,g), age, dob_residual, ret_stats, any_schedule, fallback_passivity_ver, weakly_hard_ver, aic_d_ver)。验证规则：
`Valid(J_dilate,t) ⇔ Valid(J_vista) ∧ Valid(TSC,t) ∧ (FallbackReady ∨ age ≤ τ_max−δ_guard) ∧ (m,k)-满足已审计 ∧ RET 无抖动`。
审计链新增三问：**为何此刻还能信这张证书（age/τ_max）、过期后谁兜底（PFS/Ω_fb）、算力为何这样分（CAB/VoC）**。

**定义 248（DILATE 闭环算子）** 语义流：[LiDAR→LSF→USR/MEL→VPG→ACH→阶段切分→VCV→FIR(anytime)→AFA→WCV-A→CSP-W→**TSC 出证**→CSC 前缀→Shield→执行→EV_exec→RSC-G→OLP→DIR→AIC-D]；实时流：[锚点读→**DOB 残差→AEB 评估→RET 判定**→CSC 早停→WCV-A 编译→π_σ 前缀派发→**TSC 年龄检查→PFS 交接**→J_dilate 构建]。不变式：**延迟只改变"信任半径"，绝不改变"安全兜底"的存在性。**

### IP-224/225/226 实时快环：DOB + AEB + TSC 年龄检查

```python
class RealtimeEnvelope:
    """实时流：只做观测、包络评估与兜底切换，零学习写操作。"""
    def __init__(self, alpha, beta, D, delta_guard=0.2, dt=0.002):
        self.alpha, self.beta, self.D = alpha, beta, D
        self.delta_guard, self.dt = delta_guard, dt
        self.dob = DisturbanceObserver(bandwidth=DOB_BW)
        self.cusum = RobustCUSUM(nu=NU, theta=THETA, dwell=TAU_DWELL)

    def step(self, x, u, tsc, t):
        d_hat = self.dob.update(x, u, self.dt)
        eps = self.dob.residual_bound()
        D_tilde = self.D + eps
        r = self.dob.residual(x, u, d_hat)

        age = t - tsc.t0
        gamma = ((1.0 - np.exp(-self.alpha * age)) * tsc.rho0
                 + (self.beta / max(self.alpha, 1e-6))
                 * (1.0 - np.exp(-self.alpha * age)) * D_tilde)
        aeb_ok = (age <= tsc.tau_max) and (tsc.rho0 - gamma >= 0.0)

        if (not aeb_ok) or (age >= tsc.tau_max - self.delta_guard):
            return 'FALLBACK_PFS', d_hat, eps        # 提前交叠，避免盲区
        if self.cusum.update(r) > self.cusum.theta:
            self.cusum.reset()
            return 'WAKE_SEMANTIC', d_hat, eps
        return 'GUIDED', d_hat, eps
```

### IP-227 鲁棒事件触发（抗干扰的触发层）

```python
class RobustCUSUM:
    def __init__(self, nu, theta, dwell, s_max=1e6):
        self.nu, self.theta, self.dwell = nu, theta, dwell
        self.S, self.last = 0.0, -np.inf

    def update(self, r_norm):
        # 死区 nu 吸收噪声/共模；噪声<=nu 时 S 不增长 -> 无误报
        self.S = min(self.max_s, max(0.0, self.S + float(r_norm) - self.nu))
        return self.S

    def fire(self, t):
        if self.S > self.theta and (t - self.last) >= self.dwell:
            self.last = t
            return True
        return False
```

### IP-228 anytime 归因（任意中断点出有效证书）

```python
class AnytimeAttribution:
    """返回单调收紧的 (post, rho0, K_safe)；每个中断点都 sound。"""
    def run(self, phases, deadline, doc):
        post, rho0, K = self.fir_warm_start(phases)      # 立刻给一个粗但有效的界
        yield post, rho0, K
        while time.time() < deadline and not self.converged(post, doc):
            post, rho0, K = self.fir_refine(phases, post)  # 只会收紧 rho0
            if not doc.monotone_ok(rho0, K):
                break                                     # 拒绝非单调，保留上一有效界
            yield post, rho0, K
```

### IP-229/231 TSC 出证 + 算力-年龄预算

```python
def issue_tsc(x, rho0, alpha, beta, D_tilde, delta_guard):
    if D_tilde <= 0:
        tau_max = np.inf
    else:
        tau_max = (1.0 / alpha) * np.log1p(alpha * rho0 / (beta * D_tilde))
    return TSC(x0=x, rho0=rho0, t0=now(), tau_max=tau_max,
               g=(alpha, beta, D_tilde), delta_guard=delta_guard)


def cab_schedule(tasks, budget, deadlines):
    # 按 风险 * 年龄斜率 / wcet 排序；满足 (m,k)
    tasks = sorted(tasks, key=lambda z: z.risk * z.age_slope / z.wcet, reverse=True)
    plan, used = [], 0.0
    for z in tasks:
        if used + z.wcet <= budget and weakly_hard_ok(plan + [z], deadlines):
            plan.append(z); used += z.wcet
    return plan
```

```python
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    # ———— 实时快环（每 2ms）————
    mode, d_hat, eps = M.envelope.step(M.x, M.u_prev, M.tsc, now())
    if mode == 'FALLBACK_PFS':
        u = M.pfs.control(M.x, d_hat)                 # 无推断兜底
        return M, u, build_j_dilate(M, mode='FALLBACK')
    if mode == 'WAKE_SEMANTIC':
        M.cab.wake(M.fir, M.vpg, M.csp_w)

    # ———— 语义流（anytime，按 CAB 预算）————
    A = M.ach.propose(M.x_prime, H=M.H)               # 长视界仅用于前瞻
    visual = M.vpg.verify_and_predict(M.y_vis, A, M.mws.last_contacts)
    for post, rho0, K_safe in M.fir.anytime(M.phases, M.deadline, M.doc):
        pass                                          # 单调收紧，保留最后有效值
    M.tsc = issue_tsc(M.x, rho0, M.alpha, M.beta, M.D + eps, M.delta_guard)

    # ———— 前缀：只在新鲜期内执行 ————
    k_star = min(M.csc.certified_prefix(A, post, M.m, M.alpha_chunk),
                 int(np.floor((M.tsc.tau_max - M.tsc.delta_guard
                               - M.tau_comp) / M.dt)))
    if k_star < 1:
        return M, M.pfs.hold(M.x), build_j_dilate(M, mode='HOLD')
    for a in A[:k_star]:
        if not aeb_valid(M.tsc, now()):
            break                                     # 实时早停 → 切兜底
        dispatch(a)
    M.rsc_g.update(M.EV_exec, M.tsc, mode)
    M.dir.update(sample_batch_from_history(32))
    M.aic_d.certify(M.tsc, M.EV_exec, M.d_hat)
    return M, K_safe, build_j_dilate(M, mode='GUIDED')
```

## 4. 推导

**引理 9（时效包络可靠性）** 设 h 连续可微，闭环满足 ḣ ≥ −αh + β(‖d‖+ε_dob)，且 ‖d‖≤D。令 D̃=D+ε_dob。由比较引理，对任意 a≥0，
h(x(t0+a)) ≥ e^{−αa}h(x(t0)) − (β/α)(1−e^{−αa})D̃
≥ e^{−αa}ρ0 − (β/α)(1−e^{−αa})D̃
= ρ0 − [(1−e^{−αa})ρ0 + (β/α)(1−e^{−αa})D̃]
= ρ0 − γ(a)。
故 ρ0−γ(a)≥0 时 h≥0，真实状态落在 E(a)={h≥ρ0−γ(a)} 内。令 γ(τ_max)=ρ0 得
ρ0 = (1−e^{−ατ})ρ0 + (β/α)(1−e^{−ατ})D̃
⇒ e^{−ατ} = (β/α)D̃/(ρ0+(β/α)D̃)
⇒ τ_max = (1/α)ln(1 + αρ0/(βD̃))。
且 ∂τ_max/∂D̃ < 0：**抗干扰度（D̃↓）直接延长可信任期**。∎

**引理 10（鲁棒触发的检测-误报-无 Zeno）** CUSUM S_t=max(0,S_{t−1}+‖r_t‖−ν)。若 ‖r_t‖≤ν（纯噪声/共模≤死区），则 S_t 不增，永不越过正阈值 θ ⇒ 无误报。若真实漂移 ‖r_t‖≥ρ_drift>ν，则 S 每步至少增 ρ_drift−ν，从 0 到 θ 需 ≤θ/(ρ_drift−ν) 步 ⇒ 检测延迟有界。驻留时间 τ_dwell>0 使两次触发间隔严格为正 ⇒ 排除 Zeno。∎

**定理 9（DILATE 延迟-干扰安全）** 在 A94–A98 下，对执行全程任意时刻 t，或 `Valid(TSC,t)`（GUIDED），或 PFS 就绪（FALLBACK），且二者在 [t0+τ_max−δ_guard, t0+τ_max] 上**交叠**。分情况：
1. GUIDED：引理 9 保证 h≥ρ0−γ(age)≥0，且 DLP 保证 k*≤⌊(τ_max−δ_guard−τ_comp)/Δt⌋，故整个执行前缀都落在新鲜期内，力/几何/滑移由 VISTA 的 ρ_safe 保证；
2. FALLBACK：PFS 的耗散性只要求 ‖d‖≤D，不读取任何推断，故归因过期/错误/缺失都不影响其安全性；
3. **交接不变式**：由定义 240 的覆盖条件 Ω_fb⊇E(τ_max)，且切换发生在 τ_max−δ_guard（证书仍有效、状态仍在 E(τ_max−δ_guard)⊆Ω_fb），故切换瞬间状态必在 Ω_fb 内；此后 PFS 保持其不变。因此 GUIDED→FALLBACK **不存在无人负责的盲区**；
4. 截止期 miss：由定义 243，miss 期间由 PFS 兜底，其安全性与 miss 次数无关。
综上，`Valid(J_dilate,t)` 或 PFS 就绪 ⇒ 全程安全。∎

**定理 10（anytime+DLP 的前沿近优性）** (i) 设各任务的计算-收益曲线单调凹（更多算力只带来递减的 ρ0 增益），则 CAB 的 VoC 贪心在预算 B 与 (m,k) 约束下达到加权效用最大值的 1−1/e 或 ε-近优（标准可分离凹资源分配结论）；(ii) DLP 的 k* 同时被 CSC 的安全界与新鲜期截断，故块内越界概率 ≤α_chunk+δ_fi+α_vis+α_delay，其中 α_delay 为年龄膨胀超界概率（由引理 9 的确定性界给出，通常为 0）；(iii) 由 (i)(ii)，在算力与延迟裕度固定时，DILATE 的执行安全-吞吐点落在 𝔉_{C,D} 的 ε-邻域。第 65 轮的"长预测、短执行"由此推广为"**长预测、新鲜执行**"。∎

**命题 2（Bode 型三难下界，LTI 下严格、非线性下为猜想）** 考虑最小相位、相对阶≥2 的稳定安全环，灵敏度 S(s)。Bode 灵敏度积分 ∫_0^∞ ln|S(jω)|dω = 0：在某频段压低 |S|（抗干扰）必在另一频段抬高 |S|。加入纯延迟 e^{−jωτ} 后，相位滞后随 ω 线性增长，闭环穿越频率满足 ω_c ≲ π/(2τ) 量级。于是"把干扰抑制带宽 ω_bw 提高到某值"与"把检测延迟 τ_det 降到某值"不能同时任意推进：存在常数 c>0（依赖被控对象与裕度）使
τ_det · D_eff ≥ c。
这解释了为何 DILATE 不去追求"更快更准的单一环"，而选择**分环（快环抗干扰、慢环归因）+ 无推断兜底**：把不可能同时满足的三者，拆成两条各自可行的时间尺度，再用时效包络把二者安全地缝合。∎（非线性、非最小相位情形仅为猜想，需在 E247 中经验检验。）

**命题 3（抗干扰购买延迟容忍）** 由引理 9 的闭式，τ_max 对 D̃ 严格单调递减。若通过 DOB 把有效残余干扰从 D̃ 降到 D̃'=D̃/k，则有效期从 τ_max 增至 (1/α)ln(1+k(e^{ατ_max}−1))，对小 ατ_max 近似放大 k 倍。这给出"**每 6dB 干扰抑制约换取一段可量化的额外延迟容忍**"的工程换算，也是 E242/E247 的核心可证伪预测。∎

## 7. 已知风险

**一句话**：DILATE 的最后一层兜底（PFS）把安全性押在"最坏干扰集 D 与 passivity 假设成立"上；一旦真实接触是非被动的、或传感器共模欺骗让 DOB 残差**完全看不见**干扰，兜底就会在证书过期、最需要它的那一刻**静默失效**——而由于它被设计成"不依赖推断"，归因模块恰恰不会发现它已经失效，于是"无需归因的安全"反而成了比第 65 轮更隐蔽、更不可审计的新单点故障（A94）。

**次级风险与缓解**：
1. **PFS 的 passivity 假设被违反**：非被动接触（如刚性碰撞、储能元件）会让能量整形失效；缓解：在线监测 passivity 余量（存储函数导数），越界即降速/退让；把"非被动"纳入 AIC-D 的最坏集，并在 E246 中**主动暴露**该失效点而非掩盖。
2. **DOB 盲区（共模欺骗）**：d̂ 只能看见可观测的干扰；跨模态共模会让残差同时"看起来很干净"；缓解：引入物理独立通道（IMU/关节电流/本体感觉）做交叉校验；RET 增加"多通道不一致"分支；共模下不要求归因，只要求判 stale 并切 PFS。
3. **时效包络过度保守**：γ(a) 用最坏增长率，长延迟下 E(a) 迅速收缩，导致频繁 hold、吞吐下降；缓解：分段/自适应 γ（用在线估计的 D̃ 而非静态上界）、按风险分级设定 α_risk、允许"可逆任务"用更松的包络。
4. **Bode 三难被误用为绝对律**：命题 2 仅在 LTI 最小相位下严格，非线性/非最小相位可能绕开；缓解：把它当设计直觉与经验检验对象（E247），不作安全性证明的唯一依据。
5. **anytime 单调性难保证**：精度提高通常单调，但数值/近似可能破坏单调；缓解：保留上一有效界、显式校验 `monotone_ok`，非单调即拒绝更新。
6. **CAB 在 miss 风暴下饥饿**：分布漂移时任务集中 defer，语义流排队；缓解：(m,k) 约束 + 优先级老化 + PFS 兜底使其不至于不安全，只损失性能。
7. **时钟/时间戳攻击与不同步**：TSC 的年龄依赖可信时钟；缓解：单调时钟、时间戳签名（承接 AIC 的同步认证）、对时钟跳变做保守重置（age←τ_max）。
8. **实时预算**：DOB+RET+AEB+PFS 逼近 2.5ms；缓解：硬件定时器、DOB 降阶、与 LSF 共享编码、把 anytime 世界模型全部留在语义流。
