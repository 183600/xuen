> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v22+IP-431–435（其上承 v21 语义-规范层 SDC/CAC/DCL/GIC/CFC+、v20 联邦感知证书 PCA/CTS/CFC/HPC/CFCtrl、v19 证书体系与 v17 感知链）。
> 本轮纪律：**不推倒 v22 的任何模块，只补一个被所有前序版本默认忽略的维度——时间**。前序证书都隐含"此刻成立即永久成立"；本轮把每张证书改写为**带有效期与续期义务的租约（lease）**，并把体系自身的版本演进形式化为**可机械复核的路线图合规证书**。核心一句话：**证书是租约，不是地契；续期是必须被证明的事件，绝不能由时间流逝自动发生**。

## 0. 直觉与动机

**灵感 1（技术路线图 → 版本演进本身是一张证书）**
直觉：v18→v19→v20→v21→v22 的每一版都在做"受约束的继任"，但这种继任只活在人的叙述里，没有被形式化。真实的工程路线图有三个要素：**有向的里程碑依赖（DAG，不是列表）**、**进入/退出判据（entry/exit criteria）**、**被显式记录的欠账（deferred work）**。把这三者变成证书，就得到 **认证路线图合规层 (Certification Roadmap Conformance Layer, CRCL)**：路线图 `R = (M, ≺, Dep, D)` 是里程碑 DAG，每个 `m = (capability, entry, exit, deps, debt)`；一次发布 `R_n → R_{n+1}` 只有在携带 **路线图合规证书 (Roadmap Conformance Certificate, RCC)** 时才被准入。RCC 必须机械证明三件事：(i) **单调继任** `Exec_{n+1} ⊆ Exec_n`；(ii) **依赖闭合**（`m` 的所有 `deps` 已在其 exit criteria 上达成）；(iii) **安全债有期限**（每条被推迟的能力记为债务 `b = (item, deadline T_debt, severity)`，要么已偿还，要么在 `T_debt` 内被排期）。关键反直觉点：**安全债不是"欠着就行"的会计科目——它必须复用 DCL 的带期限义务 O-规则**（"存在 ≤T_debt 的前缀进入偿还状态"），于是"路线图合规"与"机器人在此刻合规"在数学上是同一类约束，不需要新模态，`Exec` 的单调继承性原样保住。

**灵感 2（预测性维护 → 证书的物理前提也有 RUL）**
直觉：v22 的 HPC-E 假定标定有效、检测器召回下界 κ_c 成立、执行器包络未降额、传感器新鲜——这些**前提全部在退化**。预测性维护（PdM）的核心不是"坏了再修"，而是用退化模型预测**剩余使用寿命分布 RUL**，在失效**之前**行动。把这一点推进到证书层，就得到 **预测性健康证书 (Prognostic Health Certificate, PHC)**：每个前提 `i` 有健康状态 `h_i(t)` 与退化模型（可含 conformal 校准的预测区间），证书的有效期不是无限，而是 `H_cert = min_i (RUL_i 的 1-β 下界)`——即"所有前提以 ≥1-β 概率同时成立的最长未来时长"。关键反直觉点（也是本轮的支点）：**维护在语义上不是"修机器"，而是"续期证书"**；推迟维护是**向安全资本借债**，这笔债必须进 CRCL 的安全债账本并附带期限。于是 PdM 的调度问题 = 租约续期问题 = 带期限义务问题，与 DCL 完全同构。更妙的是，PHC 让 v22 的 P37 分层降级从"失效后回退"升级为**预测性收缩（predictive contraction）**：在前提失效**之前**就按预测把能量/速度/接近包络收缩，收缩单调、可审计，且**恢复只能由认证的维护事件触发，绝不因时间流逝自动恢复**。

**两者如何统一：证书是租约（Certificates-as-Leases）**
统一为 **证书生命周期层**，两个时间尺度共享一个不变量：
- **宏观（月/年）**：路线图租约——版本 `n` 的证书域不是永久的，下一次继任必须用 RCC 换取；
- **微观（时/日）**：健康租约——每个前提的有效期 `H_cert`、续期义务、预测性收缩。
每张租约 `L = (scope, not_after, renewal_obligation, issuer)`；**执行域只接纳落在全部未过期租约交集中的计划**。共享状态扩展为 `ζ_life = ζ_pgev ∪ (R, b_debt, {h_i, RUL_i}, {L_k}, maint_log)`。统一准入门升级为 **HPC-L = (HPC-E, RCC, PHC-over-horizon)**：几何∧规范∧负信息（HPC+）∧能量可持续（EVC/RGC）∧**路线图合规**∧**健康租约覆盖计划时域**。任一失效 ⇒ 收缩包络（预测性）或退化为 v22 ⇒ `Exec_v23 ⊆ Exec_v22 ⊆ …`。

**为什么这不是叠床架屋**：前序每一层都在"某时刻"判真，时间是唯一没被量化的轴；不补时间，`Exec_{n+1} ⊆ Exec_n` 只在发布瞬间为真，随后因物理退化而**悄悄失效**——这正是 v21 最大风险"合规的缺席幻觉"在时间维上的翻版（宏观叫"纸面续期"，微观叫"逾期未修"）。CRCL+PHC 是把这条隐性时间轴显式化、并把它的失效变成**可审计、可预警、可拒绝**的事件。

## 2. 设计原则（在 P34–P42 基础上新增 P43–P46）

**P43 证书租约律（Certificates-as-Leases）**
每张证书 `C` 携带显式有效期 `[t, t + H_C]` 与续期义务 `Renew_C`（一个带期限 O-规则）。执行准入只受理满足 `horizon(π) ⊆ ⋂_k [t, t+H_{C_k}]` 的计划；**不存在永久证书**。租约到期且未续期 ⇒ 其覆盖域自动向保守方向收缩（不是静默失效），并登记一条逾期债务。续期只能由**可审计事件**（认证维护 / 重新标定 / 重新校准 / 发布新 RCC）触发，时间流逝本身不构成续期。

**P44 路线图合规律（Roadmap Conformance）**
发布 `R_{n+1}` 可准入当且仅当 RCC 成立：`Exec_{n+1} ⊆ Exec_n` ∧ `∀m ∈ frontier(R_{n+1}) : deps(m) 已 exit` ∧ `∀b ∈ Debt : 已偿还 ∨ (deadline(b) ≤ T_debt(b) 且已排期)`。安全债**不得无限滚续**：连续滚续次数 `rollover(b)` 超阈值即把该债务的严重度上调并强制收缩相关能力（"债务降级"，与 P37 的层级降级同构）。RCC 是纯语法可复核谓词，可进 merkle 审计链（复用 v21 规则库版本化）。

**P45 预测性收缩律（Prognostic Contraction）**
若 PHC 在计划时域内预测前提 `i` 的健康低于阈值（`RUL_i` 的 1-β 下界 < `horizon(π)`），则执行包络必须**在失效之前**单调收缩至 `Envelope(h_i)`；收缩是单调的，恢复仅在认证维护事件之后、且分级进行（每次恢复幅度 ≤ 一个认证台阶，需驻留时间）。故 `Exec(t) ⊆ Exec_v22` 对一切 `t` 成立，而非仅在发布瞬间成立。**反直觉点**：预测性收缩把"急停"变成"提前、平滑、可解释的降级"，活性损失是渐进的，且失效可从账本提前数小时预测。

**P46 健康加权共识律（Health-Weighted Federated Consensus）**
一张联邦票只有在"投票节点 PHC 覆盖决策时域"时才被计数；`CFC++` 的仲裁升级为 **HWFC**：`count = Σ_i ω_i·𝟙[vote_i]`，`ω_i = 𝟙[PHC_i ⊇ horizon]`（二值门，而非软权重，避免被系统性乐观的软权重污染）。健康节点不足 `N-F` 或模态数 `<2` ⇒ 保守仲裁（CI）。**反直觉点**：把"过期的自信"整票作废，比给退化节点降权更安全——因为退化往往是**相关的**，软权重会把同源故障洗成"多数"。

## 3. 与基线的接口（如何退化）

- CRCL 失效（路线图判据引擎崩溃）⇒ 冻结在上一张已准入 RCC，禁止新发布、只允许收缩 ⇒ `Exec` 子集；
- PHC 失效（退化模型不可信）⇒ 所有前提按"即将到期"处理，包络取最保守静态值并停止自动续期 ⇒ 比 v22 更保守；
- CLM 失效（租约管理器崩溃）⇒ 进入**最大限制租约模式**（短 TTL + 只缩不放）⇒ 子集；
- HWFC 健康门无法满足（健康节点不足）⇒ 仲裁退回 CFC++ 行为 ⇒ 等价 v22；
- 维护事件无法认证 ⇒ 不续期、不恢复，维持预测性收缩态；
- 全失效 ⇒ 完全回退 v22 ⇒ `Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ … ⊆ Exec_v18`。
- **安全继承**：租约只删不增可达集，预测性收缩只缩不放，RCC 单调继任硬约束，健康门只作废票不作假票 ⇒ 任意失效都向更保守方向退化。

## 4. 预期贡献

1. **证书租约化**：首次把 v18–v22 所有证书从"永久地契"改写为带有效期与续期义务的租约，给出"到期自动保守收缩、续期必须可审计"的统一不变量；
2. **路线图即证书**：把版本演进形式化为可机械复核的 RCC（单调继任 + 依赖闭合 + 安全债有期限），并与 DCL 带期限义务复用同一形式化，无需新模态；
3. **预测性健康证书**：把 PdM 的 RUL 思想推进到证书前提层，给出 `H_cert = min_i RUL_i^(1-β)` 的可校准有效期与预测性收缩协议；
4. **预测性降级**：把 v22 的"失效后回退"升级为"失效前收缩"，急停变为渐进可解释降级，并用认证维护事件做分级恢复；
5. **健康加权共识 HWFC**：以二值健康门作废"过期的自信票"，封堵相关退化被软权重洗成多数的风险；
6. **HPC-L 统一准入门**：`HPC-E ∧ RCC ∧ PHC-over-horizon`，使 `Exec_v23 ⊆ Exec_v22` 对**每个时刻**成立，而不仅在发布瞬间。

## 5. 本轮最大风险

**一句话**：整个体系把"证书还能有效多久"押在 RUL 退化模型与维护记录上——若模型系统性乐观或维护事件被漏记，证书会在账面上自动续期而物理前提早已过期，形成比"缺席幻觉"更隐蔽的**"纸面续期的安全幻觉"**；同时路线图的"安全债滚续"可让 `Exec_{n+1} ⊆ Exec_n` 形式上恒真而实质能力被缓慢掏空。

## 1. 关键算法骨架（在 IP-431–435 骨架上扩展）

```python
from dataclasses import dataclass, field
from typing import Dict, List, Set, Tuple

# ---------- IP-436 路线图合规层 ----------
@dataclass(frozen=True)
class Milestone:
    capability: str
    entry: Set[str]
    exit: Set[str]
    deps: Set[str]
    debt: Tuple[str, int, int] | None  # (item, severity, T_debt)

@dataclass
class Roadmap:
    milestones: Dict[str, Milestone]
    edges: Dict[str, Set[str]]          # ≺：m -> 后继集合
    debt: Dict[str, Tuple[int, int, int]]  # item -> (severity, deadline, rollover)

class RoadmapConformanceCertificate:
    def __init__(self, prev_exec, curr_exec, executed_caps: Set[str]):
        self.prev_exec, self.curr_exec = prev_exec, curr_exec
        self.executed = executed_caps

    def admits(self, roadmap: Roadmap, frontier: Set[str]) -> Tuple[bool, str]:
        # (i) 单调继任：新执行域必须是旧的子集
        if not is_subset(self.curr_exec, self.prev_exec):
            return False, "NON_MONOTONE_SUCCESSOR"
        # (ii) 依赖闭合：前沿里程碑的依赖必须已 exit
        for m in frontier:
            ms = roadmap.milestones[m]
            if not ms.deps.issubset(self.executed):
                return False, f"DEPENDENCY_OPEN:{m}"
        # (iii) 安全债有期限且不得无限滚续
        for item, (sev, deadline, roll) in roadmap.debt.items():
            if roll > MAX_ROLLOVER:                      # 债务降级
                self.curr_exec = contract(self.curr_exec, item)
            if roll > 2 * MAX_ROLLOVER:                  # 硬拒
                return False, f"DEBT_ROLLOVER_EXHAUSTED:{item}"
        return True, "OK"

# ---------- IP-437 预测性健康证书 ----------
class PrognosticHealthCertificate:
    def __init__(self, beta: float = 0.01):
        self.beta = beta
        self.rul_models: Dict[str, object] = {}   # premise -> degradation model
        self.calib: Dict[str, object] = {}        # conformal 校准器（复用 DCSC 的 calib）

    def update(self, premise: str, health: float, maint_events: list):
        self.rul_models[premise].observe(health, maint_events)

    def rul_lower_bound(self, premise: str) -> float:
        # conformal 校准的 1-β 下界：P(RUL_i >= q) >= 1-β
        return self.calib[premise].lower_quantile(self.rul_models[premise], self.beta)

    def horizon(self) -> float:
        # 关键：所有前提的联合有效期；相关性未建模时用 Bonferroni 折减
        per = [self.rul_lower_bound(p) for p in self.rul_models]
        return min(per) if not self._correlated(per) else min(per) / len(per)

    def predictive_envelope(self, base_env):
        # 只缩不放：按最短剩余寿命单调收缩
        H = self.horizon()
        return contract_envelope(base_env, factor=min(1.0, H / H_NOMINAL))

# ---------- IP-438 证书租约管理器 ----------
@dataclass
class Lease:
    scope: str
    not_after: float
    renew: str          # 带期限 O-规则名，指向 maint/re-cert 事件
    issuer: str

class CertificateLeaseManager:
    def __init__(self, phc: PrognosticHealthCertificate, t_min_dwell=5.0, dt_react=1.0):
        self.phc, self.leases, self.maint_log = phc, {}, []
        self.t_min_dwell, self.dt_react = t_min_dwell, dt_react
        self.last_contraction = None

    def tick(self, now: float):
        # 续期只能由认证维护事件触发；时间流逝不构成续期
        for L in self.leases.values():
            if now >= L.not_after - self.dt_react and not self._renewed(L, now):
                self._contract(L.scope)            # 预测性收缩，而非静默失效
                self._log_overdue(L)

    def on_maintenance(self, event):
        if not self._verify_signature(event):
            return                                   # 未认证维护 = 不续期
        self.maint_log.append(event)
        self.phc.update(event.premise, event.health, [event])
        self._renew(event.premise, now=event.t)

    def _renew(self, premise, now):
        L = self.leases[premise]
        L.not_after = now + self.phc.rul_lower_bound(premise)
        # 分级恢复：每次最多 Δ_recover，且需驻留时间
        self._step_recover(premise, max_step=DELTA_RECOVER, dwell=self.t_min_dwell)

@dataclass

class HealthWeightedFederatedConsensus(CertificateFederatedConsensusPlusHierarchical):
    def consensus_round(self, now, horizon):
        results = {}
        for key, votes in self.votes.items():
            # 二值健康门：健康租约不覆盖决策时域的票整票作废
            healthy = {i: v for i, v in votes.items()
                       if self.phc_of[i].horizon() >= horizon and now < self.lease_of[i].not_after}
```

## 2. 关键推导（安全继承，逐时刻版）

**命题 926（租约不增可达集）**：对任意计划 `π`，`π ∈ Fil_lease ⇒ π ∈ Exec_v22`。
*证明*：`Fil_lease` 只含形如 `Valid(L_k,t)` 与 `horizon(π) ≤ H_cert` 的合取条件，其中 `H_cert ≥ 0`、`Valid` 是布尔门；它们不引入任何新的运动/能量/规范许可，只删除不满足者。故 `Fil_lease` 是 `Exec_v22` 上的恒等或收缩算子。∎

**命题 927（逐时刻单调，而非仅发布瞬间）**：若 P45 成立（包络只缩不放、恢复需认证事件且分级），则 `∀t, Exec_v23(t) ⊆ Exec_v22(t)`。
*证明*：由命题 926 得 `Exec_v23(t) ⊆ Exec_v22(t)`，前提是 `Exec_v22(t)` 自身随时间不扩张。P45 的预测性收缩只减 `Envelope(h_i(t))`，而 `h_i` 的恢复仅在 `maint_log` 认证事件后以 `Δ_recover` 台阶进行，且每步仍需 RCC/PHC 复核；故 `Exec_v22(t)` 在无认证事件时单调不增。上述两重收缩复合后仍单调不增。∎

**命题 928（RCC 与 DCL 的义务同构）**：安全债排期谓词 `∃t' ≤ T_debt, state(t') ∈ RepaySet` 与 P35 的带期限义务过滤器 `Θ_O = {plan : ∃t' ≤ τ_rule, state(t') ∈ YieldSet}` 在同构映射 `RewardSet ≅ YieldSet, T_debt ≅ τ_rule` 下等价。
*推论*：路线图合规**不需要**新义务模态；CRCL 直接复用 DCL 的编译与审计链，`Exec` 单调性证明可原样引用引理 162。

**命题 929（HWFC 不弱于 CFC++）**：令 `H` 为健康节点集，`V` 为全部投票节点。HWFC 的计数集 `H ⊆ V`，且健康门 `ω_i ∈ {0,1}` 只删不加。故 `HWFC admissible ⇒ CFC++ admissible`，即 `Exec_v23^HWFC ⊆ Exec_v22^CFC++`。∎

## 3. 实验设计

| 编号 | 假设 | 方法 | 指标 |
|---|---|---|---|
| E1 | RUL 预测区间的 conformal 覆盖真实 | 注入轴承磨损/标定漂移/电池衰减轨迹，`n=2000` 序列，检验 `P(RUL ≥ 下界) ≥ 1-β` | 覆盖率偏离、收缩提前量（小时） |
| E2 | 安全债滚续不会掏空能力 | 随机生成 1000 条发布 DAG，施加"连续滚续"攻击 | `rollover` 超限触发率、能力实质缩减量、误拒率 |
| E3 | 预测性收缩先于失效 | 关闭维护事件注入，对比 v22 回退与 v23 收缩 | 首次碰撞前预警时间、活性损失、振荡次数（应 ≤ T_min_dwell） |
| E4 | HWFC 抗相关退化 | 注入同源传感器退化，使健康节点静默变成"自信但过期" | 误共识率、`CI` 保守率、与 CFC++ 对比 |

**消融**：去掉 PHC（等价 v22 静态假设）→ E3 碰撞预警退化；去掉 RCC → E2 出现能力空转；去掉健康门 → E4 误共识上升。三者应分别复现"缺席幻觉"的时间版三种形态。
