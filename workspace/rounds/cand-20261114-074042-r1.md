# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「数据集」×「演示数据」）

> R69 学会了向外求证：看不清就看、拿不准就问、质感不明就摸。但它仍默默把「不确定性」当成**模型自己报告的属性**——流策略吐出几团模态、mode_head 报一个熵、交互后熵下降，就认为 epistemic 被消解了。这等于相信一个从未被检验的前提：**模型的信念分布，忠实地反映了它被教过的东西**。而 R69 自陈的最大风险恰恰是「模态权重未校准（幻觉出不存在模态、或坍缩掉真模态）」——这不是策略的毛病，是**数据的毛病**。
>
> 本轮把追问的对象从「世界/人」换成「**数据本身**」：
> - **数据集**告诉我们：epistemic 不是网络的自述，而是**演示覆盖（support）/来源独立性/可交换性**的函数；一个动作没被演示过，不等于它危险，也不等于它安全——缺席是歧义的。
> - **演示数据**告诉我们：示范是**策略条件**样本（π_D 的轨迹），不是世界的无偏采样；多峰可能只是几个演示者的**风格差异**，而非任务真的有两解。把风格当歧义去追问，是 R69 还没意识到的浪费与风险。
>
> 核心命题：**把 epistemic 从「模型信念」下放到「数据证据」——用带出处账本（provenance）的演示数据集构造支持密度、演示者分层不确定性、保形（conformal）模态集与决策影响集；只在数据证据充分、支持内、多源一致时才允许 R69 式交互/放行；支持外、单源依赖、漂移或出处可疑时一律退化为 R68 纯保守；主动交互升级为「请示范一小段」，但示范只能进隔离暂存、必须离线整合，绝不能在线自确认。** 命名 **DATUM-RAS**（Demonstration-Anchored, Trust-calibrated Uncertainty Management）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我学到的东西本身可信吗；我该不该、以及如何，去学一个新的示范**」——不确定性不只属于传感器与策略，也属于**数据从哪来、够不够、有没有被教坏**。

## 0. 直觉与动机

**灵感 1（数据集 → epistemic 是数据的属性，不是模型的自述）**
直觉：R69 用 `H_mode·g(Δ_min)` 度量「可约歧义」，但这两个量都从策略采样里算，等于让模型给自己打分。真正的可约性取决于：这个状态/动作区域**被多少条独立演示覆盖过**、这些演示是否来自不同的人/不同环境、留出验证能否复现。换成一个从未见过的状态，流模型照样会吐出若干模态并给出「漂亮的熵」——它不知道自己在分布外，因为 softmax/ODE 不会自动表达无知。数据集视角把 epistemic 变成可查证的对象：**支持（support）、覆盖（coverage）、来源独立性（source independence）、可交换性（exchangeability）**。一句话：**不在支持里的自信，是数据没教过它的自信。**

**灵感 2（演示数据 → 示范是「策略条件」样本，不是「世界」样本）**
直觉：演示轨迹是从演示者策略 π_D 采出来的，不是从「所有可行动作」里均匀采的。于是动作空间里的密度是 `p_D(o,a) = π_D(a|o)·p(o)`，它混淆了两件事：**世界允不允许** 与 **演示者愿不愿做**。一个动作在数据里缺席，可能是危险（演示者回避），也可能只是没必要（演示者从不需要）。这意味着支持必须**非对称使用**：演示的「在场」可以作为可行性/k 源一致的正向证据；演示的「缺席」绝不能反推危险。R69 的 VoI 建立在「模态分布=世界可能性」上，本轮的修正很硬：**支持外不估计 epistemic 的大小，只把它标为「未知」并直接走保守**——因为这题在观测数据下不可识别。

**灵感 3（多演示者 → 多峰的来源可能是风格，不是任务歧义）**
直觉：R69 看到两个动作模态就想去「问清楚」。但如果两个模态来自两位演示者（一个习惯绕左、一个习惯绕右），那它根本不是任务歧义，也不是噪声，而是**演示者风格方差** `U_demo`。把它当 epistemic 去追问，既浪费交互预算，又可能把「偏好」误升级成「安全」问题；更糟的是，若多数演示者恰好有同一个坏习惯，模态权重最高的恰恰是错的。反过来，若同一演示者在匹配状态下仍给出不稳定动作，那才是 `U_ale`；若不同演示者在**去除风格后**仍系统性对立，那才是真 `U_epi^dis`。问题在于：仅凭观测数据，**风格与真歧义在统计上不可辨识**——两者都表现为「来源间方差」。要打破这个混淆，必须做**干预式查询**（让演示者在受控条件下展示反事实），这正是本轮主动示范查询的理论动机。

**灵感 4（数据集是活的 → 漂移、过期、自产生、投毒）**
直觉：R68/R69 的模型一旦训练完就被当成常量；但部署环境会变、夹爪会换、桌面会重铺、任务会迁移——**数据集是对过去世界的快照，支持会过期**。更危险的是闭环会「自己喂自己」：机器人自己的执行若被回灌成演示数据，就会形成回声室（echo chamber），把自己的错误固化成「被演示过的支持」。再加上投毒：一段看起来合理、实则会撞墙的示范，一旦进入数据集，就会污染**所有未来轮次**的 epistemic 估计。R69 的投毒是「问错一次，错一次」；R70 的投毒是「**学错一次，之后每次都错**」——这是复利级的风险，必须用出处账本、暂存隔离、k 源一致、影响集删除来治理。

**灵感 5（主动问数据 → 从「问一句话」升级为「请示范一小段」，且学习必须离线可撤回）**
直觉：R69 的信息动作是看/问/触；语言答案转瞬即逝、难以验证。示范数据则给出更丰富、可复核、可离线审计的监督信号：「这一步该往哪走」「如果这样放会怎样」。但要安全地用它，必须把**数据获取**和**模型更新**彻底解耦：查询得到的示范先进入隔离暂存（staging），在当前轮次只作为**一次证据**参与后验，不写模型；只有离线整合窗口里，经 k 个独立出处一致、通过安全与物理合理性检查、且不与留出验证冲突，才允许进入数据集并原子换装。这条「**在线只读、离线才学**」的纪律，是 R68「零学习写操作」在数据层的严格延伸——**会问的系统，必须先学会不轻信自己学到的东西。**

## 1. 形式化定义（增量：定义 310–326）

**定义 310（DATUM-RAS 总览）** DATUM-RAS = (DPL, SDM, DSC, TDX, CCR, ADQ, DSG, DSA, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）：在线只读冻结的数据快照；
(ii) **出处不可变**：每条演示轨迹携带签名 provenance；无匿名数据；查询示范进入 staging，不进入训练集；
(iii) **支持有界 epistemic**：`U_epi` 只在演示支持内被估计；支持外一律标记为「未知」，走 R68 纯保守，**不允许用模型置信度把它缩小**；
(iv) **数据级证据纪律**：单条新示范/自产生示范不得单独更新已部署模型或建立安全关键模态的支持；整合需 ≥k 个独立 provenance root 一致 + 审计 + 离线窗口。

**定义 311（演示数据集与出处账本 DPL）** 数据集 `D = {(τ_i, p_i)}_{i=1}^N`，`τ_i = (o_{0:T_i}, a_{0:T_i})`。出处 `p_i = (s_i, e_i, t_i, v_i, q_i, ℓ_i, σ_i)`：来源/演示者 `s_i`、载体 `e_i`、时间 `t_i`、环境哈希 `v_i`、质量 `q_i`、谱系 `ℓ_i ∈ {expert, human, teleop, self, correction}`、签名 `σ_i`。按谱系划分 `D = D_exp ⊔ D_hum ⊔ D_self ⊔ Q_stage`。账本只追加、可验证、可追溯；根公钥为信任锚。

**定义 312（支持密度与覆盖 SDM）** 在任务相关投影空间（由任务雅可比/可负担性降维）上定义支持密度 `ρ_D(o,a)`（kNN/KDE，带保形阈值 `ρ_τ`）。观测覆盖 `COV(o) = |{s : 在 o 的局部邻域内至少有一条该来源的演示}|`（独立来源计数）；动作支持 `AS(o) = {a : ρ_D(o,a) ≥ ρ_τ}`。**支持是非对称的**：`a ∈ AS(o)` 是正向证据；`a ∉ AS(o)` 只表示「未观测」，不表示「不可行」。

**定义 313（演示者分层不确定性分解 DSC）** 将 R69 的 `U_epi` 细分为四项：
- `U_ale = E[within-trajectory noise]`：同一来源、匹配状态下的不可约噪声；
- `U_demo`：匹配状态下的**演示者间风格/偏好方差**（非世界 epistemic）；
- `U_epi^sup = h(ρ_D(o))`：支持不匹配（状态/动作落在覆盖外，随距离单调增，支持外取上界 `+∞` 的标记值）；
- `U_epi^dis`：去除风格后的**跨来源任务级分歧**（真歧义）。
有 `U_epi(R69) ≈ U_epi^sup + U_epi^dis`，但 R69 的模态熵里混入了 `U_demo`——这是本轮修正的核心。

**定义 314（演示策略混杂与去偏）** 演示服从 `p_D(o,a) = π_D(a|o)p(o)`。定义策略条件占用偏置 `β_D(a|o) = π_D(a|o)/π_ref(a|o)`（`π_ref` 为任务先验/均匀参照）。支持证据必须按来源独立性加权，且对反事实动作做**重要性校正**；当 `β_D` 不可估（严重混杂）时，只保留「在场正向认证」，并把反事实支持标为不可识别。禁止用「缺席」推「危险」。

**定义 315（决策影响集与有效来源数 TDX）** 对当前状态与候选模态 `m`，用预计算 datamodel/影响函数 `I_i(m,o)` 表示删除演示 `i` 对选择 `m` 的影响。有效独立来源数 `n_eff(o) = (Σ_i I_i)² / Σ_i I_i²`；**单源翻转** `single_dep = [max_i I_i > flip_τ]`。若 `n_eff < n_min` 或 `single_dep`，决策视为数据脆弱，不得单独放行。

**定义 316（保形模态集 CCR）** 以留出演示 `D_cal ⊂ D` 构造非一致性分数 `s(o,a) = 1 − ρ_D(o,a)`（或 `−log p_θ(a|o)`）。对水平 `α`，`C_α(o) = {m : s(m,o) ≤ q_{1−α}(s(D_cal))}`。在可交换性下 `P(M_true ∈ C_α) ≥ 1−α`。**仅当 `|C_α(o)| = 1`** 才签发单模态动作证书；否则 `U_epi` 保持为正。用数据侧保形覆盖**替代** R69 的自报 ECE 门控（定义 306）。

**定义 317（数据集证书与覆盖契约）** `J_data = (D_hash, coverage_map, per-region n_sources, α, ρ_τ, shift_threshold, provenance_root)`。部署证书 `J_RAS` 仅在「当前观测落在 `J_data` 声明支持且 `COV ≥ k_min`、保形集有效」时成立。证书是按区域、按 α 签发的局部契约，不是全局常量。

**定义 318（主动示范查询 ADQ）** 信息动作扩展为 `g_demo = (o_prompt, constraints, H_demo, type)`，`type ∈ {show, correct, prefer}`：`show` 让演示者在指定状态示范正确动作；`correct` 让其在机器人将执行的动作附近给出修正；`prefer` 让其在两个合法模态间表达偏好（用于消解 `U_demo`/`U_epi^dis`）。查询必须过 C-RAS-WM 认证（定义 302）、受交互预算约束。

**定义 319（查询示范的暂存与整合 DSG）** 查询所得 `τ^q` 先进入 `Q_stage`。在线仅作为单次证据参与后验，**不写模型**。离线整合准入条件（全部满足）：
(a) ≥k 个独立 provenance root 一致（或 expert 签名）；
(b) 通过安全包络与物理合理性检查；
(c) 不与留出验证 `D_cal` 冲突，或冲突已升级人工复核；
(d) 出处签名有效、环境哈希匹配。
单条查询示范**永不**单独建立安全关键模态的支持。

**定义 320（自产生数据回声抑制）** 自产生数据 `D_self` 的出处权重 `w_self < 1`，且 `D_self` 不得单独支撑任何安全关键模态的证书。定义回声率 `ECHO(o) = supp_claim(o) ∩ D_self / supp_claim(o)`；若某支持声明只能由 `D_self` 解释，标记为「未验证」，走 R68 保守。

**定义 321（数据集漂移与新鲜度 DSA）** 以两样本检验/分类器估计当前观测流与 `D` 的协变量偏移 `DS`；以时间衰减 `fresh(t_i)` 计新鲜度。若 `DS > τ_shift` 或 `fresh < τ_fresh`，则**无论模型多自信**，一律抬高 `U_epi^sup`（support claims 过期），并触发再示范或保守回退。

**定义 322（数据投毒威胁模型 ℰ_data）** 数据投毒示范、出处伪造/重放、看起来安全实则会撞墙的「奖励黑客」示范、示范中的后门触发器、自产生回声、演示策略分布迁移。合并 `ℰ_DATUM = ℰ_FLUID × ℰ_data`。

**定义 323（数据集审计 VQAuditor-D）** 审计数据级决策：本次动作由哪些演示影响（拓扑）、来源是否可信、支持声明是否有效、查询示范是否被不当整合、自产生数据是否泄漏进支持。结论回灌 `AuditBuf`，成为下一轮数据集策展与查询成本先验。

**定义 324（两级保守退避扩展）** 安全地板项 `U_safe = U_ale + U_epi^sup + (未消解 U_epi^dis)`。`U_demo` **不并入安全地板**（偏好/风格交由 `prefer` 查询或确定性 tie-break 解决），但在无法消解时记录为「偏好未定」。若支持外/漂移/单源依赖/出处可疑/暂存未整合：`λ = λ_floor(U_safe + U_epi^dis 全部未消解项)`，并 `λ ≥ 0.8`；否则 `λ = λ_floor(U_safe)`（resolution bonus）。R68 与 R69 为边界情形。

**定义 325（证书 J_DATUM）** `J_DATUM = (J_FLUID, data_cert_hash, α, n_eff, coverage, shift_stat, staged_queue_hash, provenance_root, datum_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ 观测在认证覆盖内 ∧ C_α 有效 ∧ Q_stage 未整合项不支撑当前动作 ∧ DS ≤ τ_shift`。

**定义 326（在线/离线分离与原子换装）** 在线：只读快照、零学习写、暂存只增不改。离线整合窗口：更新 `D`、重算支持与保形阈值、重算 datamodel、执行出处审计，然后**原子换装**新快照并签发新 `J_data`；失败则回滚。整合期间不改变已下发控制量。

```python
# IP-266 DSC：演示者分层不确定性分解（替换 R69 的 U 标量）
def stratified_decompose(samples, modes, snap, o):
    U_ale  = within_source_noise(snap, o)              # 不可约
    U_demo = between_source_style_variance(snap, o)    # 风格，不是安全
    U_sup  = support_mismatch(snap.sdm, o, samples)    # 支持外 → +inf 标记
    U_dis  = cross_source_disagreement(snap, o, modes) # 任务级真歧义
    return U_ale, U_demo, U_sup, U_dis

# IP-267 TDX：决策影响集与有效来源数
def decision_influence(o, mode, datamodel):
    I = datamodel.influence(o, mode)                   # {i: I_i}，离线预计算
    n_eff = (sum(I.values())**2) / sum(v*v for v in I.values())
    single_dep = max(I.values()) > FLIP_TAU
    return n_eff, single_dep

# IP-268 CCR：保形模态集（替代自报 ECE 门控）
def conformal_mode_set(o, modes, cal_scores, alpha):
    q = quantile(cal_scores, 1 - alpha)
    return {m for m in modes if nonconformity(m, o) <= q}

# IP-269 ADQ：主动示范查询（净 VoI 含持久化折现与投毒成本）
def choose_demo_query(C_alpha, o, budget, shift):
    best = None
    for g in demo_query_candidates(o, C_alpha):        # show / correct / prefer
        if not budget.allow(g): continue
        if not c_ras_wm.certify_info(g, o): continue   # 查询本身也要安全认证
        gain = expected_mode_reduction(C_alpha, g, o)
        cost = physical_social_cost(g) + persist_discount(shift) * \
               p_poison(g) * L_poison                 # 错误会跨轮复利
        voi = gain - cost
        if best is None or voi > best.voi: best = (g, voi)
    return best if best and best.voi > 0 else None    # 无利可图 → R68/R69

# IP-270 DSG：暂存隔离与离线整合
def consolidate(Q_stage, D, k=2):
    for tau in Q_stage:
        srcs = independent_roots(tau, D)               # 独立出处
        if (len(srcs) >= k and audit_ok(tau)
                and safe_envelope_ok(tau) and not conflicts_cal(tau, D)):
            D.add(tau)                                 # 仅在离线窗口
    return D

# IP-271 DSA：数据集漂移与新鲜度
def dataset_shift(snap, live_stream, now):
    ds = two_sample_classifier(snap.D, live_stream)
    fresh = min(recency_decay(p.t, now) for p in snap.provenance)
    return ds, fresh

def DATUM_RAS_round(M, obs):
    snap = M.dataset.snapshot()                        # 冻结快照，原子
    z, o = M.mtm.forward(obs); c, U_cal, _ = M.cof.step(o)
    # 1) R69 多模态采样（廉价门控）
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z)
    # 2) R70 数据证据层：分层 / 影响 / 保形 / 漂移
    U_ale, U_demo, U_sup, U_dis = M.dsc.decompose(samples, modes, snap, o)
    C_alpha = M.ccr.set(o, modes, snap.cal_scores, M.alpha)
    n_eff, single_dep = M.tdx.influence(o, M.last_mode, M.datamodel)
    ds, fresh = M.dsa.shift(snap, M.live, M.now)
    out_of_support = (M.sdm.rho(o, M.last_action) < snap.rho_tau)
    data_unverified = (out_of_support or len(C_alpha) > 1 or single_dep
                       or ds > TAU_SHIFT or fresh < TAU_FRESH
                       or M.has_staged_support_claim(o))
    # 3) 交互：数据可信才允许 R69 看/问/触；否则优先请示范
    g = None
    if not out_of_support and (U_dis > TAU_EPI or U_demo > TAU_DEMO):
        g = M.mint.choose_interaction(modes, o, M.budget)
        if g is None:
            g = M.adq.choose_demo_query(C_alpha, o, M.budget, ds)
    if g is not None:
        r = M.adq.execute(g) if is_demo_query(g) else M.cia.execute(g)
        if is_demo_query(g):
            M.staging.put(r)                          # 只入暂存，不写模型
        U_epi_after = M.cia.update_belief(modes, r)
    else:
        U_epi_after = U_dis
    # 4) 退避：支持外 / 未验证 → R68 纯保守，安全地板不缩
    U_safe = U_ale + U_sup + (U_epi_after if not data_unverified else U_dis)
    lam = max(M.efs.risk_scale(...), lam_floor(U_safe))
    if out_of_support or data_unverified:
        lam = max(lam, 0.8)
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    # 5) 选择：单模态证书优先；否则选保形集内最保守模态
    mode = select_mode(modes, C_alpha, U_epi_after, lam)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 6) 审计 + 证书
    M.vqa_d.submit_async(g, C_alpha, n_eff, ds, out_of_support, M.staging)
    cert = M.j_datum.issue(snap, C_alpha, n_eff, ds, M.staging)
    return k, lam, mode, cert
```

## 3. 推导

**引理 19（支持外不可估计）** 设 `(o,a)` 落在演示分布低密度尾 `ρ_D(o) < ρ_τ`。在仅由 `D` 构成的经验风险最小化框架内，任意估计器对该区域动作价值的 excess risk 下界 ≥ `c·d((o,a), supp D)`（策略密度对条件/动作 Lipschitz，常数有界），且该下界**不能由模型自身置信度收缩**。系：支持外不能「估计」epistemic 的大小，只能「标记未知」并走保守；把 softmax/熵当置信度在支持外无效——这正是定义 310-iii。

**引理 20（风格—歧义不可辨识）** 在匹配状态 `o` 上，若只有观测演示而无干预/偏好标签，则 `U_demo`（演示者风格）与 `U_epi^dis`（任务级真歧义）统计不可辨识：二者都表现为来源间方差。辨识需至少一次干预式查询（在受控条件下让同一/不同演示者展示反事实）。系：R69 把全部模态熵当 epistemic 会**高估可约性**，导致无谓追问；ADQ 的 `show/correct/prefer` 正是为打破该混淆而设计。

**引理 21（保形覆盖与单模态可认证）** 若 `D_cal` 与部署观测可交换，则 `P(M_true ∈ C_α) ≥ 1−α`。当 `|C_α(o)|=1` 时可签发单模态动作证书；否则 `U_epi>0`。系：用数据侧保形覆盖替代 R69 的自报 ECE，把「模型说自己校准了」换成「留出数据证明它有覆盖」。

**引理 22（数据级投毒上界与跨轮复利）** 若来源中至多 `δ_p` 比例被污染，整合需 `k` 个独立 provenance root 一致，则持久错误进入 `D` 的概率 ≤ `δ_p·ρ^{k−1}+ε_σ`（`ρ<1` 为来源欺骗相关）。一旦未经隔离地进入，其影响在 `T` 轮内累积污染量约 `(1−γ^T)/(1−γ)·L_poison`。系：数据级纪律必须比 R69 的单次交互纪律更严，因为**错误会跨轮复利**，且撤回已执行动作不可能。

**定理 18（DATUM 对 FLUID/R68 的严格包含与安全单调）** 在 A99–A101 下：
- 若数据证书 `J_data` 有效、`DS ≤ τ_shift`、`|C_α|=1`、`n_eff ≥ n_min`，则 DATUM 与 FLUID 行为一致（必要时用 ADQ 替代语言问询，收益不减）；
- 若支持外/漂移/单源依赖/出处可疑/暂存未整合，则 DATUM 的风险 ≤ FLUID ≤ R68（更保守），且当 `VoI_eff ≤ 0` 时逐指令退化为 R68。
故安全侧永不弱于 R69/R68；效率侧的 resolution bonus 只在**数据证据充分**时发放。

**定理 19（在线/离线分离与无突变）** 在线只读冻结快照且零学习写；数据集整合与保形/支持重算仅在离线窗口原子换装；暂存数据在整合前不影响任何动作。因此控制连续、无突变（继承 R68 定理 15 / R69 定理 17），且被隔离/撤回的数据不会造成已执行动作的追溯性失效。

**假设**：
- A99（出处独立性）至少 `k_min` 个独立 provenance root，根公钥可信；
- A100（可交换性/加权有效）部署与 `D_cal` 在漂移界内可交换，或加权保形有效；
- A101（Lipschitz 与支持正则）策略密度、支持密度对条件/动作 Lipschitz，`ρ_τ` 非退化。

## 6. 本轮最大风险

**一句话**：DATUM-RAS 的全部安全论证都锚在「出处账本的根公钥可信 + 演示数据未被系统性污染」上——**若根被伪造、或被一串「看起来合理」的示范有组织地教坏，它会把「我不知道」升级成「数据集已认证」，制造跨轮复利、难以撤回的持久性假自信；学错，比问错更难清除。**

**次级风险与缓解**：
1. **高维动作空间支持估计数据饥饿** → 任务相关投影 + 结构化动作分解；支持过粗时宁可保守；
2. **演示策略条件偏差不可完全去偏** → 只用「在场」做正向认证，绝不用「缺席」推危险；把反事实支持标为不可识别（定义 314）；
3. **保形可交换性在非平稳部署下失效** → 加权保形 + 漂移检测（定义 321），保证失效即退回 R68；
4. **查询疲劳/社交成本** → 交互预算 + 非侵入 `prefer` 查询 + E312 用户研究 + E315 Pareto；
5. **自产生数据回声** → provenance 权重、`D_self` 不得单独建立安全支持、仅离线整合（定义 320、319）；
6. **存储/版本/审计开销** → 快照级增量证书、离线整合、datamodel 缓存。

**定义 323–324（审计与退避）** VQAuditor-D 审影响拓扑/来源/自数据泄漏/暂存整合，回灌 AuditBuf；安全地板 `U_safe=U_ale+U_epi^sup+未消解 U_epi^dis`，`U_demo` 不入地板；支持外/漂移/单源/可疑/未整合 ⇒ `λ≥0.8` 且退化 R68。

**定义 325–326（证书与分离）** `J_DATUM=(J_FLUID,data_cert_hash,α,n_eff,coverage,shift_stat,staged_queue_hash,provenance_root,datum_ver)`；在线只读快照、暂存只增；离线重算支持/保形/datamodel 后**原子换装**，失败回滚。

## 4. 推导

**引理 19（支持外不可估计）** `ρ_D(o)<ρ_τ` 时，在仅由 `D` 构成的 ERM 框架内，任意估计器对该区域动作价值的 excess risk 下界 ≥ `c·d((o,a),supp D)`，且不能由模型置信度收缩。系：支持外只能「标记未知」并保守，softmax/熵不能表达分布外无知（定义 310-iii）。

**引理 20（风格—歧义不可辨识）** 匹配状态下只有观测演示时，`U_demo` 与 `U_epi^dis` 都表现为来源间方差，统计不可辨识；需至少一次干预式查询（`show/correct/prefer`）打破混淆。系：R69 把全部模态熵当 epistemic 会高估可约性，导致无谓追问。

**引理 21（保形覆盖与单模态可认证）** `D_cal` 与部署可交换时 `P(M_true∈C_α)≥1−α`；`|C_α|=1` 才可签发单模态证书。系：用数据侧保形覆盖替代自报 ECE，把「模型自称校准」换成「留出数据证明覆盖」。

**引理 22（数据级投毒上界与跨轮复利）** 污染率 `δ_p`、整合需 k 个独立 root 一致（欺骗相关 `ρ<1`）时，持久错误进入 `D` 的概率 ≤ `δ_p·ρ^{k−1}+ε_σ`；未隔离时 T 轮累积污染 ≈ `(1−γ^T)/(1−γ)·L_poison`。系：数据纪律必须严于 R69 单次交互纪律，因为错误跨轮复利且不可追溯撤回。

**定理 18（DATUM 严格包含 FLUID/R68 且安全单调）** A99–A101 下：数据证书有效、`DS≤τ_shift`、`|C_α|=1`、`n_eff≥n_min` 时与 FLUID 行为一致（ADQ 可替代语言问询且收益不减）；支持外/漂移/单源/可疑/未整合时风险 ≤ FLUID ≤ R68，`VoI_eff≤0` 时逐指令退化为 R68。安全侧不让步，效率侧只在数据证据充分时发放 resolution bonus。

**定理 19（在线/离线分离与无突变）** 在线只读冻结快照、零学习写；整合与保形/支持重算仅离线原子换装；暂存整合前不影响动作。故控制连续、无突变（继承 R68 定理 15 / R69 定理 17），被隔离/撤回的数据不造成已执行动作的追溯失效。

**假设**：A99 出处独立且根公钥可信（≥`k_min` 独立 root）；A100 漂移界内可交换或加权保形有效；A101 策略/支持密度 Lipschitz 且 `ρ_τ` 非退化。

## 7. 本轮最大风险

**一句话**：DATUM-RAS 的全部安全论证都锚在「出处账本的根公钥可信 + 演示数据未被系统性污染」上——**若根被伪造、或被一串「看起来合理」的示范有组织地教坏，它会把「我不知道」升级成「数据集已认证」，制造跨轮复利、难以撤回的持久性假自信；学错，比问错更难清除。**

**次级风险与缓解**：高维支持估计数据饥饿（任务投影 + 结构化分解，宁可保守）；演示策略条件偏差不可完全去偏（只用「在场」正向认证，绝不用「缺席」推危险）；保形可交换性在非平稳下失效（加权保形 + 漂移检测，失效即退 R68）；查询疲劳（预算 + 非侵入 `prefer` + E312/E315）；自产生回声（provenance 权重、`D_self` 不单独建立安全支持、仅离线整合）；存储/版本/审计开销（快照级增量证书 + 离线整合）。
