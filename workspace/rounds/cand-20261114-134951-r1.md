# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~302；新灵感循环第 1 轮；本轮灵感：「用户测试」×「三维感知」）

> R73 把证据做成可组合契约（MMS/DPEM/CCA/ΣREFLEX/CPB），附录 IP-302 又用 ECG 补因果、用 MIC 补形态无关。但它留下两个**测量学**而非工程学的前提：
> - **仪器=真相**：每个模块都被默认为「测量它声称测量的东西」。深度模块的 `u_depth` 被当成「场景几何不确定度」；用户测试的满意度被当成「安全/可用性证据」。校准（calibration）只保证「读数与标准一致」，不保证「标准与构念一致」——这是**构念效度（construct validity）**问题，不是加一个方差项能解决的。
> - **跨构念可加**：CCA 允许把不同模态的不确定度做 SER/PAR。但「深度噪声」与「用户信任」不是同一个构念，它们的数值不可通约；对二者取 `max` 或 `fuse` 在类型上是错的，不只是保守/激进的问题。CCA 的「保守并集」只对同构念成立。
>
> 本轮两个灵感正好补这两块：
> - **用户测试** → **HEM（Human Evidence Metrology）**：用户研究是仪器，不是真理。把抽样、评分者、顺序/学习/疲劳、反应性、迁移、需求特征、构念欠代表分解为**七分量**，并显式区分**随机不确定度（信度）**与**系统偏差（效度）**；用户证据只能**否决**，不能单独**认证**物理安全。
> - **三维感知** → **3DCM（3D Construct Metrology）**：三维感知不是「场景 + 噪声」，而是**构念族**（尺度/位姿/形状/占据/可供性）+ **可辨识性**。遮挡、对称、无纹理、透明、非刚性、表示依赖使后验**多峰或集值**；单峰高斯协方差会系统性过度自信。歧义只能由**动作**（视角/接触/主动探测）消解——这正好接上 R73 的 χ_v。
> - **把两者接起来** → **CVA（Construct Validity Algebra）**：用户对「机器人是否看见透明杯」的判断，与深度模块的 `u_material` 是**两个仪器测同一构念**（汇聚效度）；而「用户信任」与「碰撞率」是**不同构念**，只能通过**名义网络中的桥接证书**发生关系。没有桥就**否决**，而不是取 max。
>
> 核心命题：**不再问「证据有多不确定」，而问「证据测量的构念是否就是安全主张所指的构念；跨构念组合是否存在合法的桥；桥本身的不确定度是否被计入」。** 把 R73 的「计量契约代数」升级为 **VALID-GAUGE-RAS**（VALidity-aware Instrumented Layered evidence GAUGE for RAS）——**构念效度感知的具身计量闭环**。

## 0. 直觉与动机

### 灵感 1（用户测试 → 用户研究是仪器，不是真理）

直觉：一次用户测试的输出不是「用户的真实感受」，而是一条**测量链**：
`构念 κ → 操作化 o → 仪器 I → 反应 y → 计分 s`。
这条链上每一环都可能出错，而且错法不同：
- **信度问题**（随机误差，可被平均削弱）：被试抽样、评分者间/内一致性、题目顺序、疲劳与练习、会话时长、语言理解。
- **效度问题**（系统偏差，平均不掉）：操作化只覆盖了构念的一部分（construct under-representation）、题目混入了无关构念（construct-irrelevant variance）、被试在「被观察/被机器人看着」时改变行为（Hawthorne/反应性）、社会赞许与需求特征、实验室任务与部署场景不匹配（生态效度）。
- **不变性问题**（换人群/换机器人/换任务后仪器含义变了）：同一个「信任问卷」在专家与新手、不同文化、不同机器人形态上未必测量同一个构念（测量不变性：configural/metric/scalar invariance）。
- **伦理问题**：知情同意、可撤回、数据最小化、不得隐蔽测量；这些不是附录，而是有效域的一部分——违反即证据作废。

关键认识：**高信度不蕴含高效度**。一个每次都稳定给出 4.7 分的问卷，可以稳定地测错东西。用户测试在机器人安全论证中的常见误用，正是把「统计显著 + 高 α」当成「安全/可用性已被证明」。所以用户证据进入安全闭环的唯一安全姿势是：**它只能收紧（否决），不能放松（认证）**——这既符合单源不定案原则，也避免把昂贵、低 N、易反应性的人类数据变成物理安全界的依据。

### 灵感 2（三维感知 → 几何构念的可辨识性，而非只是噪声）

直觉：三维感知也不是「场景 + 高斯噪声」，而是**构念族** `K_3D = {尺度, 6D 位姿, 形状/拓扑, 占据/自由空间, 可供性, 可见性}`。每个构念有自己的失效结构：
- **统计不确定度**：深度/ LiDAR 测距噪声，可随帧数平均。
- **可辨识性/歧义**：对称物体（杯子绕轴旋转）、重复纹理、透明/镜面、遮挡、单目尺度——后验是**多峰或集值**，不是单峰协方差。对称物体的位姿后验在一个对称群 `G` 的轨道上等概率；任何单峰小协方差都在 KL 意义下系统性过度自信。
- **模型差异**：非刚体、非朗伯表面、动态场景，使观测模型本身错。
- **配准/标定漂移**：外参、时间同步。
- **表示依赖**：Chamfer 距离、占据栅格、位姿误差、法向误差对同一场景给出不同的「误差」——换一个表示，结论可能翻转。
- **尺度**：单目/单帧的绝对尺度不可观测。

关键认识：**歧义不是噪声，不能被平均掉；它只能被动作消解**。走近、换视角、加接触、主动打光——这正是 R73 的视角反作用通道 χ_v 的推广：动作 → 视角/接触 → 可辨识性 → 构念估计 → 动作。于是「三维感知」天然是**动作条件化的可辨识性**，而不仅是动作条件化的噪声。

### 灵感 3（把两者接起来 → 桥接与名义网络）

直觉：用户测试与三维感知不是两个孤立模块，它们可以在**同一构念**上互为仪器：
- 用户报告「你看见那个透明杯了吗？」与深度模块的「材质失效概率」都在测**可见性/场景几何**这一构念——若二者在密封集上收敛，则获得**汇聚效度**；若不收敛，说明至少一个仪器测错了构念。
- 用户「信任」与「碰撞率/误抓率」是**不同构念**。要谈「信任高所以安全」，必须有一条被验证的**桥**：`信任 ← 可解释性/可预测性 → 实际安全` 的名义关系，并在密封集上校准、在目标人群/任务上通过测量不变性。没有桥时，把二者数值组合是**范畴错误**。

这把 R73 附录的 ECG/MIC 正式吸收：ECG 的因果边就是名义网络的**预测关系**；MIC 的形态无关性就是**跨形态测量不变性**。二者从「可选扩展」升为「构念效度的必要条件」。

### 灵感 4（构念效度代数 → 不可通约否决，而非保守放大）

直觉：R73 的 CCA 在跨构念时给出 `max(u_A,u_B)`，并称之为「保守并集」。但若 `A` 测的是深度噪声、`B` 测的是用户信任，`max` 给出的数既不是深度不确定度上界，也不是信任不确定度上界，而是**两个不同单位的数被强行放在同一标尺上**。真正保守的做法不是放大数值，而是**拒绝该主张**：`I⊥ = {INCOMMENSURABLE}`。桥接之后，桥自身的不确定度 `u_β` 必须进入组合（**桥接膨胀**），且桥的有效域要取交。由此得到一条比 CCA 更强的单调性：**不存在「效度洗白」路径**——任何跨构念路径的输出不确定度都不可能低于路径上所有桥的不确定度之和。

## 1. 形式化定义（增量：定义 383–400）

**定义 383（VALID-GAUGE-RAS 总览与六不变式）**
`VALID-GAUGE-RAS = (CVC, HEM, 3DCM, CVA, NNA, HRX, CVB, J_CV, MODGAUGE-RAS†)`。六不变式：
(i) **构念完整性**：任何仪器必须声明目标构念与操作化（定义 384/385），无构念不入图；
(ii) **可通约性**：组合仅在同一构念内，或经有效桥接证书（定义 389）进行；无桥 ⇒ **否决**，不是取 max；
(iii) **效度单调性**：桥接与效度不确定度只能增加下游不确定度、收缩有效域，无「效度洗白」；
(iv) **人类证据单向性**：人类证据可收紧/否决物理主张，但不能单独认证物理安全（定义 399、定理 39）；
(v) **反应性预算**：人类测量负担与反应性成本 `Σ c_H ≤ B_human`，重复测量会改变仪器本身（定义 387）；
(vi) **严格退化**：仪器失效 ⇒ 构念 stub；人类证据失效 ⇒ 仅该主张降级为探索性，安全侧只增不减（定义 395）。

**定义 384（构念与操作化）** 构念 `κ` 是理论中的潜变量（如 trust、perceived safety、usability、workload、situation awareness；或 metric scale、6D pose、occupancy、affordance、visibility）。操作化 `o(κ) = (刺激集, 反应格式, 计分, 聚合)`。仪器 `I = (κ, o, V)`，`V` 为效度证据记录（内容/汇聚/区分/名义/生态/不变性）。**信度只是 `V` 的一个子项，不能代替 `V`。**

**定义 385（构念效度契约 CVC）**
`CVC = (κ, o, V, D_c, τ_c, B, I⊥, W, seal_ref)`：
- `κ`：目标构念（可为构念族的一个分量）；
- `o`：操作化；
- `V`：效度证据（content, convergent, discriminant, nomological, ecological, invariance）；
- `D_c`：构念有效域（人群/任务/会话时长/语言文化/机器人形态）；
- `τ_c`：反应 → 构念估计的聚合函数，携带**偏差界** `b(κ,o)`；
- `B`：桥接证书集合（定义 389）；
- `I⊥`：构念级否决（操作检查失败、非不变、共同方法方差过高、Goodhart 疑似）；
- `W`：被试负担（时间/认知/隐私）；
- `seal_ref`：预注册与密封集引用。

**定义 386（人类证据计量 HEM 与七分量）** 观测 `y_h = (问卷/量表, 行为, 干预/接管, 访谈, 生理)`，`p_human(y_h | κ, θ_p, h)`。不确定度分解：
```
u_human² = u_samp² + u_rater² + u_order² + u_react² + u_transfer² + b_demand² + b_construct²
```
- `u_samp`：被试抽样/选择；`u_rater`：评分者间/内；`u_order`：顺序、学习、疲劳；`u_react`：反应性/Hawthorne；`u_transfer`：人群/任务/生态迁移；
- `b_demand`：需求特征/社会赞许的系统偏差上界；`b_construct`：构念欠代表/无关构念混入的偏差上界。
**前五项是随机误差（信度），后两项是系统偏差（效度）。** 平均只能压前五项，压不掉后两项；因此 `u_human` 不是「越大越保守」，而是「偏差必须显式入账」。
有效域 `D_human = D_c ∩ {同意有效, 未疲劳超阈, 操作检查通过, 语言匹配, 无协议违规}`。否决 `I⊥ = {MANIPULATION_FAIL, NONINVARIANT, STRAIGHTLINING, ENGAGEMENT_COLLAPSE, CONSENT_WITHDRAWN, PROTOCOL_VIOLATION, GOODHART_SUSPECTED}`。

**定义 387（人类反应性通道 HRX / L5）** `χ_H: (a, n_exp, context) → (θ_h, D_human')`，`θ_h = (trust, novelty, fatigue, learning)`。动作与观察历史如何改变仪器状态，进而改变 `u_human` 与有效域。反作用成本
`c_H = w_t·time + w_l·cognitive_load + w_τ·trust_calibration_error + w_p·privacy_risk`；
预算 `Σ_t Σ_j c_H^j ≤ B_human`；稳态集
`H_safe = {fatigue ≤ f_max, load ≤ l_max, |trust − calibrated_trust| ≤ τ_t, consent 成立}`。
任一项越界 ⇒ 该次人类证据被拒绝（非补偿）。**有限停止**见引理 46。

**定义 388（三维构念计量 3DCM 与可观测性证书）** 对 `κ ∈ K_3D`，观测 `y_3d = (深度/点云/多视图/RGB, 位姿先验, 运动)`：
```
u_3D² = u_stat² + u_amb² + u_model² + u_reg² + u_rep² + u_scale²
```
- `u_stat`：测距/匹配统计噪声；`u_amb`：歧义直径（对称轨道、遮挡多峰、重复纹理）；`u_model`：非刚体/非朗伯/动态；`u_reg`：配准/外参/时间同步；`u_rep`：表示依赖（Chamfer/occupancy/pose/normal 的度量差）；`u_scale`：单目尺度不可观测。
**可观测性证书** `O(κ, scene, v) = (G_κ, modes, visibility, ambiguity_diameter, disambiguation_action)`：`G_κ` 为构念的对称/等价群，`modes` 为等价类代表，`visibility` 为可见比例，`disambiguation_action` 为最能降低 `u_amb` 的动作（输出到 χ_v）。
有效域 `D_3D = {visibility ≥ v_min, |G_κ| 在预声明群表内, 材质/非刚性在模型域内}`。歧义超阈 ⇒ **集值证据**或构念 stub；不得用单峰协方差冒充。

**定义 389（桥接证书与不可通约性）** 桥 `β = (κ_A, κ_B, φ, D_β, u_β, V_β)`：
- `φ`：有理论依据的名义关系（方向、符号、机制）；
- `D_β`：桥的有效域（人群/任务/形态/环境）；
- `u_β`：桥的不确定度（含模型差异与校准误差）；
- `V_β`：桥的效度证据（密封桥接集、测量不变性、复现）。
**可通约**：`A ~ B` 当且仅当 `κ_A = κ_B`，或存在有效 `β` 且 `D_β ⊇ D_A ∩ D_B`。否则组合为**不可通约**，输出 `I⊥ = {INCOMMENSURABLE}`，**不是**保守 `max`。

**定义 390（构念效度代数 CVA）** 四种组合：
- **同构念串联 `SER-κ`**：`u_out ≥ u_A + L_B·u_A`，`D_out = D_A ∩ D_B`，追溯合并，否决取并（继承 CCA）；
- **同构念汇聚并联 `PAR-κ`**：两仪器测同一 `κ`，仅在**汇聚审计**（密封集上 conformal 覆盖）通过且**区分审计**（与其他构念不混淆）通过时允许缩窄；否则保守 `max`；
- **桥接组合 `BRIDGE-β`**：`u_out ≥ inflate(u_A, u_β) + b_β`，`D_out = D_A ∩ D_B ∩ D_β`，追溯含 `β` 的证书哈希；方向性必须保留（`κ_A→κ_B` 不可逆用）；
- **否决 `VETO-κ`**：任一仪器失效、非不变、不可通约 ⇒ 整体否决该主张（非补偿）。
**效度单调性（引理 44）**：不存在跨构念路径使输出不确定度低于路径上所有桥的 `u_β` 之和而同时通过审计。

**定义 391（名义网络审计 NNA）** 名义网络 `N = (K, E_n, w)`：节点构念，边为理论预测关系（符号/效应量下界/机制）。审计四项：
- **汇聚效度**：同构念的不同仪器相关 ≥ `ρ_conv`；
- **区分效度**：不同构念的仪器相关 ≤ `ρ_disc`（含 HTMT/共同方法方差检查）；
- **名义效度**：观测到的符号与效应量符合 `E_n`；
- **测量不变性**：跨人群/任务/语言/机器人形态的 configural/metric/scalar invariance 成立（`ΔCFI < ε`，mean 结构不漂移）。
任一项失败 ⇒ 对应桥/仪器否决；相关主张从 confirmatory 降为 exploratory。NNA 正式吸收 R73 附录的 ECG（因果边 = `E_n`）与 MIC（跨形态不变性）。

**定义 392（构念漂移与不变性 TTL）** 构念、仪器、桥都会漂移（人群变化、新奇效应消退、策略被优化、环境变化）。用测量不变性检验 + 桥残差 CUSUM/变点检测监控；`Cert` 带 TTL；失效 ⇒ 重校准或 stub。**效度是有保质期的。**

**定义 393（用户测试预注册、盲法与伦理）** 预注册：假设、构念操作化、样本量与功效、排除标准、分析计划、操作检查、盲法/顺序、不良事件报告、密封保持集。盲法：被试对条件/假设盲，主试对条件盲（可行时），分析者对分组盲。伦理：知情同意、可撤回、数据最小化、匿名化、去简报、IRB/伦理审查；**禁止隐蔽测量**。

**定义 394（构念效度证书 J_CV）**
`J_CV = ⊗_{I} J_CVC(I) ⊗ J_HEM ⊗ J_3D ⊗ J_NNA ⊗ J_bridge ⊗ J_ethics`。
`Valid(J_CV)` 区分 **confirmatory**（可进入安全/能力主张）与 **exploratory**（仅假设生成）。物理安全部分仍由 `J_MOD` 承担；`J_CV` 不替代 `J_MOD`，只约束**构念解释**与**跨构念主张**。

**定义 395（退化链）** 人类仪器失效（操作检查失败/非不变/撤回同意/Goodhart 疑似）⇒ 人类证据 stub（不产生可认证主张；物理安全不受影响）；3D 可辨识性失效 ⇒ 该构念集值证据或 stub；桥失效/过期 ⇒ 跨构念主张否决，同构念主张保留；ECG/MIC/NNA 失效 ⇒ 对应桥降级；物理模块失效 ⇒ 继承 R73 定义 381 的 stub。**安全侧只增不减；主张只降不升。**

**定义 396（复杂度结构上限）** `|K| ≤ 16`、`|I| ≤ 24`、桥接深度 `≤ 2`、`|G_κ|` 在预声明对称群表内、`|E_n| ≤ 64`、每构念仪器 `≤ 6`——全部为部署期与运行时增量可审计的图性质。

**定义 397（MBench-V 构念效度基准）** MB6（用户测试效度：操作检查、汇聚/区分、顺序/学习、反应性、跨人群不变性；`N ≤ 40/cell`，预注册）；MB7（三维构念：对称/遮挡/透明/非刚性/表示依赖；单卡 ≤3h）。每个基准配密封保持集与预注册脚本。

**定义 398（CPB-V 构念效度绑定）** 在 R73 CPB 上增加**效度门**：每个组件必须声明其测量的构念、桥、效度证据与失效模式；新增主张
- **C6（构念有效证据组合）** ← (CVC, HEM, 3DCM, CVA, NNA) ← MB6/MB7 ← AB6/AB7 ←（汇聚/区分相关、测量不变性、桥残差覆盖率、主张膨胀率、人-机一致性、信任校准误差）。
非绑定组件 = 工程附件；人类证据不绑定物理安全主张（只能作为否决/能力证据）。

**定义 399（人类证据单向性与单源不定案）** 人类证据可对物理主张投否决票（如报告伤害、接管、明显不适），但**不得**用于放松 `J_MOD` 的物理安全界；物理安全认证必须由物理证据链独立支撑。形式化：`SafetyBound = f(physical_evidence) ∧ ¬human_veto`，而不是 `f(physical_evidence, human_satisfaction)`。

**定义 400（严格包含目标）** 当 `K` 为单构念、无桥、人类通道关闭、3DCM 退化为 R73 DPEM（单峰高斯、无对称商）时，VALID-GAUGE 逐指令等于 MODGAUGE；再退化等于 R72/R71/R68（定理 36）。**安全单调不减，效度只增加约束。**

# IP-315 NNA：名义网络审计（部署/会话级）
def nomological_audit(instruments, net, data):
    conv = all(corr(i, j) >= net.rho_conv
               for k in net.nodes for i, j in pairs(instruments.of(k)))
    disc = all(corr(i, j) <= net.rho_disc
               for k1 in net.nodes for k2 in net.nodes if k1 != k2
               for i in instruments.of(k1) for j in instruments.of(k2))
    nomo = all(sign(corr(i, j)) == e.sign and abs(corr(i, j)) >= e.min_eff
               for e in net.edges for i in instruments.of(e.src)
               for j in instruments.of(e.dst))
    inv  = all(measurement_invariance(i, data, g)
               for i in instruments.all() for g in net.groups)
    return AuditResult(conv=conv, disc=disc, nomo=nomo, inv=inv,
                       failed={...})   # 任一失败 -> 对应桥/仪器否决

## 3. 推导

**引理 43（信度–效度分离）** 设观测分数 `X = T + E + B`，`Var(E) = σ²/n`（平均可降），`B = b_demand + b_construct` 为系统偏差。则 `n→∞` 时随机不确定度 →0，但 `B` 不变；若操作化欠代表构念，则 `E[T − κ] = b_construct ≠ 0`。因此 `Cronbach's α → 1` 不蕴含 `|B| → 0`。系：**高信度是必要不充分条件；用户测试不能靠「内部一致性好」宣称安全/可用性有效。**

**引理 44（桥接膨胀与效度单调性）** 对任意 `BRIDGE-β` 组合，`u_out ≥ u_A + L·u_A + u_β` 且 `D_out ⊆ D_A ∩ D_β`；`u_β ≥ 0` 且桥不可逆用。故任何跨构念路径的输出不确定度不可能低于路径上所有桥的 `u_β` 之和而同时通过审计。**证明**：由 `inflate` 非负、`D` 取交、桥方向性；对路径归纳。系：**不存在「效度洗白」——不能用一条未校准的桥把用户满意度变成安全证据。**

**引理 45（对称商与可辨识性下界）** 设物体对称群 `G` 作用在位姿空间 `X` 上，似然 `p(y|x)` 满足 `G`-不变性。则后验 `p(x|y)` 是 `G`-等变的，至少含 `|orbit|` 个等价模式；任何单峰高斯近似 `q = N(μ,Σ)` 若 `Σ` 的直径小于轨道直径，则 `KL(p‖q)` 有正下界，且 `q` 对等价位姿赋予可忽略质量。**证明**：由不变性/等变性，轨道上各点后验相等；单峰集中在一点必遗漏其余等概率模式。系：**协方差不是歧义的正确表示；对称物体的位姿必须报告商空间直径与模式，而不是一个被压扁的 Σ。** 动作（χ_v）是唯一能打破对称的合法手段。

**引理 46（人类反应性预算与有限停止）** 对非平凡人类测量，`c_H` 有正下界 `ε_H`（时间/认知/隐私不可为零）；边际信息增益随疲劳/学习饱和而递减（`ΔI(n+1) ≤ ΔI(n)`），且过度测量使 `u_trans` 与 `b_demand` 上升。故存在有限最优测量次数 `n*`，且 `Σ c_H ≤ B_human` 下算法在有限步停止。**证明**：正下界 + 边际收益递减 + 预算单调；与 R71 引理 31/R73 引理 36 同型。系：**用户测试不是越多越好；「多测几轮」会同时耗尽预算并污染仪器。**

**引理 47（不可通约的否决性）** 若 `κ_A ≠ κ_B` 且无有效桥，则不存在单调函数 `f` 使 `f(u_A)` 成为 `κ_B` 的合法不确定度；`max(u_A,u_B)`、`fuse`、加权和均为范畴错误。**证明**：构念不同则风险语义不同；构造两个在 `κ_A` 上同分布、在 `κ_B` 上任意的场景，任何仅依赖 `u_A` 的界无法约束 `κ_B`。系：**CCA 的「保守并集」只在同构念内保守；跨构念时必须否决主张，而不是放大数字。**

**引理 48（不变性漂移可检出）** 若测量在部署域内满足 metric invariance，则桥残差分布稳定；若 scalar invariance 被违反，则残差均值出现位移，变点/CUSUM 在漂移有界时可于有界延迟内检出；未检出期间证书 TTL 提供保守上界。**证明**：标准变点检测 + TTL 的保守性。系：**效度必须在部署中持续审计，不能只在论文里成立一次。**

**定理 36（VALID-GAUGE 严格包含）** 取单构念 `K={κ}`、无桥、人类通道关闭、3DCM 退化为 R73 DPEM（单峰高斯、无对称商、`u_amb=u_rep=u_scale=0`），则 VALID-GAUGE 逐指令等于 MODGAUGE。**证明**：逐定义代入定义 383(vi)、390、395 与 R73 定理 27；退化链继承。系：**新层是旧层的严格泛化；效度约束只增加，不删除旧保证。**

**定理 37（J_CV 有效性 ⇒ 构念有效主张）** 在 A117–A119（构念在部署域内稳定、桥 sound 且方向正确、测量不变性成立）下，`Valid(J_CV)` ⇒ 每个 confirmatory 主张的构念效度（内容/汇聚/区分/名义/不变性）成立；物理安全部分由 `J_MOD` 独立给出，`J_CV` 只保证「该主张确实在谈它声称的构念」。**证明重量落在 A117–A119：效度是理论负载且可废止（defeasible）的，证书不能把「未发现反例」写成「已证明绝对有效」。**

**定理 38（不可通约组合的安全否决）** 若某组合路径包含未桥接的构念跨越，则 `Valid(J_CV)` 失败；系统可选择将该人类/跨构念证据置 stub 并仅用物理证据继续，但**不得**宣称组合后的安全/能力性质。**证明**：引理 47 + 定义 395。系：**不会因为用户满意度高而「证明」碰撞率低。**

**定理 39（人类证据安全无关性）** 若人类证据只用于否决（`SafetyBound = f(physical) ∧ ¬human_veto`）而从不放松物理界，则人类仪器的任何失效（操作检查失败、非不变、撤回同意、Goodhart）都不会使物理风险超过纯物理证据的界；它只会降低能力/舒适度主张的置信度。**证明**：物理界与 `u_human` 无函数依赖；否决只会收缩可行集。系：**用户测试失效是主张问题，不是安全问题——这使 HRI 数据可以进审计而不污染安全认证。**

**定理 40（效度认证的局部性与摊销）** `J_CV` 的校验只依赖仪器证书、桥证书与 NNA 结果，不依赖机队规模或云模型规模；若测量不变性在目标域成立，硬件/实现改变若不影响仪器的不变域，则无需重跑用户研究。`CertCost_CV = O(|I|+|B|) + 一次性效度研究`，可跨机队摊销。**证明**：定义 394 的合取式不含机队/云项；NNA 按仪器与构念做局部检查。系：**构念效度不是每个机器人都重做一遍的奢侈品，而是可复用的契约。**

## 6. 本轮最大风险

**一句话**：VALID-GAUGE 把安全的证明负担从「契约表达力」转移到「**桥接证书与测量不变性**」——如果桥只在受控用户测试的人群/任务/机器人形态内成立，却在部署中失去测量不变性（或因为系统开始优化被测量的构念而发生 Campbell/Goodhart 腐化），那么系统会用一份**预注册、盲法正确、统计显著、效度证书齐全**的用户研究，自信地证明一个它在真实世界**已经不再测量**的构念，而所有审计日志都会显示「每一步都合规」。

次级风险与缓解：
1. **效度是理论负载且可废止的** → 不宣称绝对效度；用对抗性效度测试、密封保持集、独立复现、明确的 «defeasible» 语言；证书写「未发现反例」而非「已证明」。
2. **用户研究昂贵/低 N** → 分层贝叶斯部分池化 + 等价性检验 + 基于模拟的功效分析 + 小样本试点；MB6 预算化。
3. **Goodhart/反应性**（优化测量目标会腐蚀测量）→ 人类证据**只否决不认证**（定理 39）；轮换仪器；NNA 漂移检测；红队试测；`GOODHART_SUSPECTED` 否决。
4. **对称群/歧义爆炸** → 预声明对称群表 + 物体类预计算 + 运行时只验增量；超表即集值/stub。
5. **跨文化/跨形态不变性不可保证** → 局部校准 + 有效域限制 + 不条件下推广；把 MIC 从「形态无关」修正为「跨形态不变性证据」。
6. **构念/桥/多重比较爆炸** → 结构上限（`|K|≤16`、桥深≤2、`|I|≤24`）+ 预注册假设 + FDR 控制。
7. **伦理与隐私** → 知情同意、可撤回、数据最小化、IRB、禁止隐蔽测量；伦理否决为硬否决。
8. **被质疑为「只是心理测量学」** → 定位：创新不在发明效度理论，而在把效度做成**可组合、可审计、受实时约束的证据契约**，尤其是**不可通约否决**与**人类证据安全无关性定理**。

## 2. 形式化定义（要点版）

**定义 383（总览与六不变式）** 构念完整性 / 可通约性（无桥即否决）/ 效度单调性（无洗白）/ 人类证据单向性（只否决不认证）/ 反应性预算 / 严格退化（主张只降不升，安全只增不减）。

**定义 384（构念与操作化）** 构念 `κ` 是理论潜变量；操作化 `o=(刺激,反应,计分,聚合)`；仪器 `I=(κ,o,V)`。**信度只是 `V` 的子项。**

**定义 385（CVC）** 见符号表。核心：**每个仪器必须声明「我测的是哪个构念、在什么人群/任务/形态上有效、我有哪些效度证据、我能往哪些构念架桥」。**

**定义 386（HEM 七分量）** 随机项：抽样、评分者、顺序/学习/疲劳、反应性、迁移；系统项：需求偏差、构念偏差。有效域含操作检查/同意/语言/疲劳；否决含 `MANIPULATION_FAIL/NONINVARIANT/STRAIGHTLINING/CONSENT_WITHDRAWN/GOODHART_SUSPECTED`。

**定义 387（HRX / L5）** `χ_H:(a,n_exp,context)→(θ_h,D_human′)`；`c_H=w_t·time+w_l·load+w_τ·trust_err+w_p·privacy`；`Σc_H≤B_human`；`H_safe` 含疲劳/负荷/信任校准/同意；越界即拒绝（非补偿）。

**定义 388（3DCM 六分量与可观测性）** 六分量见符号表；可观测性证书给出对称群、模式、可见性、歧义直径与消歧动作；有效域含可见比例/群表/材质/非刚性；歧义超阈 ⇒ 集值或 stub，禁止单峰协方差冒充。

**定义 389（桥接与不可通约）** 桥必须有理论关系、密封校准、有效域与 `u_β`；不可通约 ⇒ `I⊥={INCOMMENSURABLE}`，不取 max。

**定义 390（CVA）** `SER-κ` 单调传播；`PAR-κ` 仅在汇聚+区分审计通过时缩窄；`BRIDGE-β` 桥接膨胀且方向性保留；`VETO-κ` 非补偿。**效度单调性：跨构念路径输出不确定度 ≥ 路径上桥不确定度之和。**

**定义 391（NNA）** 四项审计：汇聚（同构念仪器相关 ≥ρ_conv）、区分（异构念相关 ≤ρ_disc，含 HTMT/共同方法方差）、名义（符号/效应量符合 `E_n`）、不变性（configural/metric/scalar，`ΔCFI<ε`）。ECG→`E_n`；MIC→跨形态不变性。

**定义 392（构念漂移与 TTL）** 变点/CUSUM 监控桥残差；证书带 TTL；失效即重校准或 stub。**效度有保质期。**

**定义 393（预注册/盲法/伦理）** 假设、操作化、样本量与功效、排除、分析、操作检查、盲法/顺序、不良事件、密封集；知情同意、可撤回、数据最小化、IRB、禁止隐蔽测量。

**定义 394（J_CV）** 见符号表。`Valid(J_CV)` 分 confirmatory/exploratory；物理安全仍由 `J_MOD` 承担。

**定义 395（退化链）** 人类失效 ⇒ 人类 stub（仅主张降级）；3D 不可辨识 ⇒ 集值/stub；桥失效/过期 ⇒ 跨构念否决；物理模块失效 ⇒ R73 定义 381 stub。安全只增不减。

**定义 396（结构上限）** `|K|≤16`、`|I|≤24`、桥深≤2、`|G_κ|` 在预声明表内、`|E_n|≤64`、每构念仪器≤6。

**定义 397（MBench-V）** MB6 用户测试效度（`N≤40/cell`，预注册）；MB7 三维构念（单卡≤3h）；各配密封集。

**定义 398（CPB-V）** 效度门 + **C6（构念有效证据组合）** ← (CVC,HEM,3DCM,CVA,NNA) ← MB6/MB7 ← AB6/AB7 ←（汇聚/区分相关、不变性、桥残差覆盖率、主张膨胀率、人-机一致性、信任校准误差）。人类证据不绑定物理安全主张。

**定义 399（人类证据单向性）** `SafetyBound = f(physical) ∧ ¬human_veto`；人类证据可否决，不可放松物理界。

**定义 400（严格包含目标）** 单构念/无桥/人类关闭/3DCM 退化为 DPEM ⇒ 等于 MODGAUGE；再退化 ⇒ R72/R71/R68。

# IP-311 CVC + 构念/仪器注册表
@dataclass(frozen=True)
class ConstructValidityContract:
    kappa: Construct                    # 目标构念
    operationalization: Op              # 刺激/反应/计分/聚合
    validity: ValidityRecord            # content/convergent/discriminant/nomological/invariance
    domain: Predicate                   # D_c：人群/任务/时长/语言/形态
    tau_construct: Callable             # 反应 -> 构念估计（带偏差界）
    bridges: FrozenSet[Bridge]          # κ -> 其他构念的桥
    veto_set: FrozenSet[str]            # I⊥
    burden: BurdenBudget                # W：时间/认知/隐私
    seal_ref: str                       # 预注册/密封集

class ValidityRegistry:                 # 构念 DAG + 桥边
    def compose(self, a, b, op):
        if a.kappa == b.kappa:
            return self.same_construct(a, b, op)       # SER-κ / PAR-κ
        beta = self.find_bridge(a.kappa, b.kappa)
        if beta is None or not beta.valid(a.domain & b.domain):
            return VetoVerdict(a.claim_id, 'INCOMMENSURABLE')   # 不是 max
        return self.bridged(a, b, beta, op)

# IP-312 HEM：人类证据计量（会话级）
class HumanEvidenceMetrology:
    def update(self, responses, behavior, protocol, history):
        u_samp  = self.sampling_unc(protocol)
        u_rater = self.rater_unc(responses)
        u_order = self.order_unc(responses, history)
        u_react = self.reactivity_unc(history, behavior)
        u_trans = self.transfer_unc(protocol.population)
        b_dem   = self.demand_bias(responses, protocol.blinding)
        b_con   = self.construct_bias(protocol.operationalization)
        valid = (protocol.manipulation_check.passed
                 and self.invariance.holds(protocol.domain)
                 and not self.response_pathology(responses)
                 and protocol.consent.valid)
        u = math.sqrt(u_samp**2 + u_rater**2 + u_order**2 +
                      u_react**2 + u_trans**2 + b_dem**2 + b_con**2)
        return HumanEvidence(kappa=protocol.kappa, u=u, bias=(b_dem, b_con),
                             breakdown=(u_samp, u_rater, u_order, u_react,
                                        u_trans, b_dem, b_con),
                             valid=valid, tau=self.trace.merge(protocol.trace))

# IP-313 3DCM：三维构念计量（感知域 100Hz）
class Construct3DMetrology:
    def update(self, sensor_ev, obj_hyp, viewpoint):
        st  = self.statistical(sensor_ev)
        amb = self.ambiguity(obj_hyp, viewpoint)
        mod = self.model_discrepancy(obj_hyp)
        reg = self.registration(sensor_ev)
        rep = self.representation(sensor_ev)
        sc  = self.scale(sensor_ev)
        obs = ObservabilityCert(kappa=obj_hyp.kappa, group=amb.group,
                                modes=amb.modes, visibility=viewpoint.visibility,
                                ambiguity_diameter=amb.diameter,
                                disambiguation=self.best_action(amb, viewpoint))
        valid = obs.identifiable(obj_hyp.kappa) and not st.out_of_domain
        return Evidence3D(kappa=obj_hyp.kappa,
                          u=math.sqrt(st.u**2 + amb.u**2 + mod.u**2 +
                                      reg.u**2 + rep.u**2 + sc.u**2),
                          obs=obs, valid=valid,
                          chi_R=amb.disambiguation_channel())  # 接 R73 χ_v

# IP-314 CVA：构念效度代数
def compose_construct(a, b, op, ledger):
    if a.kappa == b.kappa:
        if op == 'PAR':
            if ledger.convergent(a, b) and ledger.discriminant(a, b):
                return fuse_same_construct(a, b)
            return Ev(u=max(a.u, b.u), D=a.D & b.D,
                      veto=a.veto | b.veto | {'PAR_CONVERGENCE_FAIL'})
        return Ev(u=a.u + lipschitz(b, a.u), D=a.D & b.D,
                  tau=a.tau.merge(b.tau), veto=a.veto | b.veto)
    beta = ledger.find_bridge(a.kappa, b.kappa)
    if beta is None or not beta.valid(a.D & b.D):
        return VetoVerdict(a.claim_id, 'INCOMMENSURABLE')   # 范畴错误
    u = inflate(a.u, beta.u) + b.u                          # 桥接膨胀
    return Ev(u=u, D=a.D & b.D & beta.D, tau=beta.trace.merge(a.tau, b.tau),
              veto=a.veto | b.veto | beta.veto | {'BRIDGED': beta.id})

# IP-315 NNA：名义网络审计
def nomological_audit(instruments, net, data):
    conv = all(corr(i, j) >= net.rho_conv
               for k in net.nodes for i, j in pairs(instruments.of(k)))
    disc = all(corr(i, j) <= net.rho_disc
               for k1 in net.nodes for k2 in net.nodes if k1 != k2
               for i in instruments.of(k1) for j in instruments.of(k2))
    nomo = all(sign(corr(i, j)) == e.sign and abs(corr(i, j)) >= e.min_eff
               for e in net.edges for i in instruments.of(e.src)
               for j in instruments.of(e.dst))
    inv  = all(measurement_invariance(i, data, g)
               for i in instruments.all() for g in net.groups)
    return AuditResult(conv=conv, disc=disc, nomo=nomo, inv=inv)

# IP-316 HRX：人类反应性预算（L5）
def human_reflex_step(protocol, a, human_state, budget):
    dtheta, D = protocol.cvc.chi_H(a, human_state.exposure, human_state.context)
    c = (protocol.w_t * dtheta.time + protocol.w_l * dtheta.cognitive_load
         + protocol.w_tau * dtheta.trust_error + protocol.w_p * dtheta.privacy)
    if not protocol.H_safe(human_state, dtheta): return None, c
    if budget.spent + c > budget.B_human: return None, c
    return human_state.step(dtheta), c

# IP-317 CVB + J_CV：效度绑定与构念证书
def validity_certificate(registry, hem, cm3d, nna, ethics):

        nna=nna.cert(), bridges=registry.bridge_certs(),
        ethics=ethics.cert(),
        confirmatory=registry.confirmatory_claims(),
        exploratory=registry.exploratory_claims(),
    )

# IP-318 VALID-GAUGE 主闭环（复用 R73 三域；新增慢速效度域）
def VALID_GAUGE_round(M, obs, audio, tac_frame, sensor_ev, session):
    # 感知域（100Hz）
    e3d = M.cm3d.update(sensor_ev, M.obj_hyp, M.viewpoint)
    if not e3d.valid: e3d = construct_stub(M.cm3d, e3d.kappa)
    d_ev = M.dpe.update(obs.depth, obs.rgb, M.cam_state, M.motion, M.peers)
    if not d_ev.valid: d_ev = stub(M.dpe)
    t_ev = M.dmem.update(tac_frame, M.last_action)
    psi_hat, _ = M.aura.update(audio)

    # 计量域（50Hz）
    if M.clock.due_metric():
        b_t = M.bse.step_full(..., d_ev=d_ev, t_ev=t_ev, e3d=e3d)
        z_dist, _, _ = M.irl.update(M.y_intent_buf, psi_hat, b_t)
        claims = M.cva.compose_claims(e3d, t_ev, b_t, z_dist)  # 无桥 -> 否决
        M.snapshot.write(b_t, z_dist, d_ev, e3d, t_ev, claims, M.state)
        M.mreg.audit()

    # 效度域（会话级/慢速，不在硬实时路径）
    if M.clock.due_validity():
        h_ev = M.hem.update(session.responses, session.behavior,
                            session.protocol, M.history)
        audit = M.nna.audit(M.instruments, session.data)
        if h_ev.valid and audit.passed and M.ethics.valid(session):
            M.validity.commit(h_ev, session.seal)          # confirmatory
        else:
            M.validity.downgrade(h_ev.kappa, 'EXPLORATORY') # 不进安全解释
        s_h, c_h = human_reflex_step(session.protocol, M.last_action,
                                     M.human_state, M.budget)
        if s_h is not None: M.human_state = s_h

    # 控制域（1kHz，只读快照，零分配）
    snap = M.snapshot.read_latest()
    lam = embodied_risk_scale(snap.U_ale, snap.U_epi, snap.H_z,
                              max(snap.t_ev.u, snap.d_ev.u, snap.e3d.u),
                              M.risk_params)                # 物理证据，不含满意度
    A = M.ach.propose_ctrl(..., pvop_bias=snap.pvop)
    k = M.c_ras_wm.certified_prefix(A, lam)
    M.ctrl_out.publish(k, lam)
    return k, lam, J_MOD(M.mreg), J_CV(M.validity)

## 4. 推导

**引理 43（信度–效度分离）** `X=T+E+B`；平均使 `Var(E)→0`，但 `B=b_demand+b_construct` 不变。`α→1` 不蕴含 `|B|→0`。系：**高信度不能替代效度；用户测试不能靠内部一致性宣称安全。**

**引理 44（桥接膨胀与效度单调性）** `BRIDGE-β` 满足 `u_out≥u_A+L·u_A+u_β`、`D_out⊆D_A∩D_β`；桥不可逆用。任何跨构念路径输出不确定度 ≥ 路径上所有 `u_β` 之和。系：**无「效度洗白」。**

**引理 45（对称商下界）** 对称群 `G` 下后验 `G`-等变，至少 `|orbit|` 个等概率模式；直径小于轨道直径的单峰高斯有正 KL 下界并漏掉等价位姿。系：**协方差不是歧义的正确表示；动作是唯一合法消歧手段。**

**引理 46（人类反应性有限停止）** `c_H` 有正下界；边际信息增益递减；过度测量抬高 `u_trans` 与 `b_demand`。故存在有限 `n*`。系：**用户测试不是越多越好。**

**引理 47（不可通约的否决性）** 无桥时不存在单调 `f` 使 `f(u_A)` 成为 `κ_B` 的合法界；`max/fuse/加权和` 均为范畴错误。系：**CCA 的保守并集只在同构念内成立。**

**引理 48（不变性漂移可检出）** metric invariance ⇒ 桥残差稳定；scalar 违反 ⇒ 均值位移可由变点/CUSUM 在有界延迟内检出；TTL 提供未检出期间的保守上界。系：**效度必须持续审计。**

**定理 36（严格包含）** 单构念/无桥/人类关闭/3DCM 退化为 DPEM ⇒ 逐指令等于 MODGAUGE；再退化 ⇒ R72/R71/R68。系：**新层是旧层的严格泛化。**

**定理 37（J_CV ⇒ 构念有效主张）** 在 A117–A119（构念稳定、桥 sound 且方向正确、测量不变性成立）下，`Valid(J_CV)` ⇒ confirmatory 主张的构念效度成立；物理安全由 `J_MOD` 独立给出。证明重量在 A117–A119：**效度是理论负载且可废止的，证书不能把「未发现反例」写成「绝对有效」。**

**定理 38（不可通约组合的安全否决）** 路径含未桥接跨越 ⇒ `Valid(J_CV)` 失败；可置 stub 仅用物理证据继续，但不得宣称组合性质。系：**不会因为满意度高而「证明」碰撞率低。**

**定理 39（人类证据安全无关性）** 人类证据只否决不放松 ⇒ 其任何失效不使物理风险超过纯物理界；只降低能力/舒适度主张置信度。系：**用户测试失效是主张问题，不是安全问题。**

**定理 40（效度认证局部性与摊销）** `J_CV` 只依赖仪器/桥/NNA，不依赖机队/云规模；`CertCost_CV=O(|I|+|B|)+一次性效度研究`，可跨机队摊销。系：**效度不是每台机器人重做一遍的奢侈品。**

## 7. 本轮最大风险

**一句话**：VALID-GAUGE 把安全论证的负担从「契约表达力」转移到「**桥接证书与测量不变性**」——如果桥只在受控用户测试的人群/任务/形态内成立，却在部署中失去测量不变性（或系统开始优化被测量的构念而发生 Campbell/Goodhart 腐化），系统就会用一份预注册、盲法正确、统计显著、证书齐全的用户研究，证明一个它在真实世界**已经不再测量**的构念，而审计日志显示每一步都合规。

次级风险与缓解：
1. **效度可废止** → 不宣称绝对效度；对抗性效度测试 + 密封集 + 独立复现；证书用「未发现反例」。
2. **用户研究昂贵/低 N** → 分层贝叶斯部分池化 + 等价性检验 + 模拟功效 + 试点。
3. **Goodhart/反应性** → 人类证据只否决不认证（定理 39）；轮换仪器；NNA 漂移检测；`GOODHART_SUSPECTED`。
4. **对称群/歧义爆炸** → 预声明群表 + 类级预计算 + 增量校验；超表即集值/stub。
5. **跨文化/跨形态不变性** → 局部校准 + 有效域限制；MIC 修正为「跨形态不变性证据」。
6. **构念/桥/多重比较爆炸** → `|K|≤16`、桥深≤2、`|I|≤24` + 预注册 + FDR。
7. **伦理/隐私** → 同意、撤回、最小化、IRB、禁止隐蔽测量；伦理硬否决。
8. **「只是心理测量学」质疑** → 创新在把效度做成**可组合、可审计、受实时约束的证据契约**，尤其是**不可通约否决**与**人类证据安全无关性定理**；不发明效度理论本身。
