# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「多视角视觉」×「力觉传感」）

> 第 54 轮把技能组合建立动作占用剖面 `α_S`、动作兼容图 `G_S`、云边映射 `γ_ce` 与联合证书 `J` 之上，并用 `Explain` 反向驱动重剖分。但它留下一个未言明的前提：**`α_S` 本身是“被观测到的”**。本轮追问“观测从哪来、接触怎么算数”：多视角视觉回答“在哪里 / 看得见吗”，力觉传感回答“碰到了吗 / 多大力”。核心矛盾：**H22**：多视角存在结构性遮挡，且不同技能的动作剖面可能在**同一盲区**被系统性污染，Jaccard 兼容性因此可能是“幽灵兼容”——两条边在真实世界从未被同时看见过；**H23**：接触物理不可完全仿真，视觉又恰好看不到夹爪-物体接触界面，云端规划在往返延迟内无法保证接触安全。

## 0. 直觉与动机

**灵感 1（视觉给“何处”，触觉给“如何” → 观测-接触对偶）**
直觉：`α_S` 是一张能力地图，但地图的可信度取决于测绘条件。多视角视觉擅长全局几何（物体位姿、可达性、遮挡关系），力觉擅长局部接触（法向力、切向摩擦、滑移）。二者不是同质信息的简单加权融合，而是**对偶**：视觉决定“这个动作是否被看见”，力觉决定“这个动作是否被接触验证”。一个动作若既看不清、又没碰过，它的 `α_S(a)=1` 只是插值幻觉。第 54 轮的风险不是采样太少，而是**采到的样本本身长在盲区里**。

**灵感 2（观测测度 → 用“可信体积”代替“几何体积”）**
直觉：动作兼容性不该在 Lebesgue 测度下算 Jaccard，而应在**观测测度** `μ_O(a)=ω_S(V,a)·τ_S(a).conf` 下算：只有“被看见且可被接触验证”的动作才有权重。定义观测充分域 `A_obs={a:μ_O(a)≥θ_O}`，只在 `A_obs` 上声明兼容；盲区里的重叠一律不认。这把“动作空间交集”升级为“**可验证动作交集**”，也让 `compat` 从几何量变成证据量。

**灵感 3（三值兼容 → unknown 不是 no，更不是 yes）**
直觉：工程上最危险的不是“不兼容”，而是“看起来兼容”。因此兼容性取三值 `{yes,no,unknown}`：证据不足即 `unknown`，触发主动探测（换视角 / 加轻接触试探），而不是默认放行。**“未知不得当作可行”**成为组合规划的硬规则。第 54 轮的假阳性风险因此被显式化为可调度的探测预算，而不是藏在 `θ_a` 的余量里。

**灵感 4（跨模态互校 → 视觉预测接触，力觉确认接触）**
直觉：视觉可以在接触发生前预测“将接触 / 将滑移”（接近度、相对速度、接触几何），力觉在接触后给出真实 wrench。定义互校残差 `r` 与置信 `corr=exp(-r/σ_x)`：corr 高则双重确认，corr 低说明两通道至少一个在盲区里说谎，触发第三探针或降级。关键在于**不能假设两通道独立**：若二者共享遮挡/饱和盲区，其错误是相关的，互校会给出虚假高置信。因此必须显式扣除误差相关项 `ρ_err(v,t)`。

**灵感 5（视觉上云、力觉下沉 → 接触反射弧与云延迟解耦）**
直觉：多视角图像带宽大、可批处理，适合上云做全局几何规划；力觉高频、低延迟、局部，必须留在边端做反射。云端计划只需承诺“接触包络 `E_contact`”内的粗轨迹，边端在接触瞬间拥有否决权与反射弧。这样接触安全不再依赖云端往返延迟，形成 **云规划 - 边反射 - 力觉否决 - 视觉重规划** 的闭环，并把第 54 轮的 `γ_ce` 扩展为 `γ_ce × γ_contact`。这不是“把触觉也传上云”，而是承认**接触回路不能进云**。

**灵感 6（金字塔扩展 → 感知-接触-鲁棒性三层证书）**
直觉：第 53 轮有鲁棒性谱 `ρ`，第 54 轮有动作占用证书 `A_cert`；本轮加 `Ω_cert`（视角/遮挡证书）与 `T_cert`（接触模式/力锥/滑移证书），构成 `J⁺`。跨层传递必须同时携带“动作占用、可观测性、接触可行性”三类证据，缺一不可部署。证书第一次需要证明“**它自己是在可观测条件下产生的**”。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（多视角观测剖面）**
给定视点集合 `V`（相机位姿、焦距、基线），技能 `S` 在动作 `a` 下从视点 `v` 的观测剖面为 `ω_S(v,a)∈[0,1]`，表示任务关键几何特征（接触点、物体 6-DoF 位姿、可抓区域）未被遮挡且可分辨的置信。多视融合采用噪声或模型：
```
ω_S(V,a) = 1 - Π_{v∈V} (1 - ω_S(v,a))
```
其不确定性用遮挡上界 `occ_bound(S,V,a) = Π_{v∈V}(1-ω_S(v,a))` 控制。

**定义 122（观测测度与观测充分域）**
`μ_O(a) = ω_S(V,a) · τ_S(a).conf`，其中 `τ_S(a).conf` 为力觉接触置信（定义 123）。对任意可测集 `X`，`μ_O(X)=∫_X μ_O(a) da`。观测充分域 `A_obs = {a∈A : μ_O(a) ≥ θ_O}`。**只有落在 `A_obs` 上的 `α_S` 陈述才有资格进入证书**；`A\A_obs` 记为盲区 `B`。

**定义 123（力觉接触剖面与接触可行性）**
接触剖面 `τ_S(a) = (c_S(a), F_S(a), s_S(a))`：`c` 为接触发生概率，`F` 为接触 wrench 分布（期望 `F̄` 与协方差 `Σ_F`），`s` 为滑移概率。接触可行
```
contact_ok(S,a) = [c_S(a) ≥ θ_c] ∧ [F_S(a) ⊆ FC(μ_s)] ∧ [s_S(a) ≤ θ_s]
```
`FC(μ_s)` 为摩擦系数 `μ_s` 对应的摩擦锥。接触模式 `m_S(a)∈{free,touch,grasp,slide,insert}` 用于描述组合时的模式切换约束。

**定义 124（三值动作兼容性）**
```
compat₃(S_i,S_j) =
  yes      if μ_O((A_i∩A_j)∩A_obs) ≥ θ_a·μ_O((A_i∪A_j)∩A_obs)
              ∧ contact_ok(S_i⊗S_j) ∧ corr_eff(S_i,S_j) ≥ θ_x
  no       if μ_O((A_i∩A_j)∩A_obs) < θ_a·μ_O((A_i∪A_j)∩A_obs) − margin
  unknown  otherwise
```
分子与分母都只在 `A_obs` 上取测度：**盲区重叠不计入 yes**。`unknown` 不是失败，而是“欠证据”，必须由主动探测（定义 125、IP-125）消解后才能参与规划。

**定义 125（跨模态互校）**
视觉接触预测 `f_v` 与力觉接触测量 `f_t`，残差 `r = d(f_v,f_t)`（按 wrench 的尺度归一化），互校置信
```
corr = exp(-r/σ_x)
corr_eff = corr − λ·ρ_err(v,t)
```
其中 `ρ_err(v,t)` 为两通道历史误差的相关系数（滑动窗口估计）。互校证书 `X=(r,corr_eff,support)`，`support=min(conf_v,conf_t)`。若 `corr_eff<θ_x` 或 `support<θ_s`，标记 `cross_conflict` 并进入探测队列。

**定义 126（接触条件云边契约）**
```
C_ce⁺ = (P_c, P_e, γ_ce, γ_contact, E_contact, Veto_e, Reflex_e, Δ, Δ_F, Explain_loop)
```
- `P_c` 云端（多视角）粗计划，`P_e` 边端（力觉）细计划；
- `γ_ce:A_c→A_e` 为动作映射，`γ_contact:F_c→F_e` 为期望 wrench 映射；
- `E_contact` 为接触包络（安全 wrench 集合，硬约束）；
- `Veto_e` 为边端否决权，`Reflex_e` 为接触反射弧（滑移/超力时在 `τ_r` 内退回安全动作）；
- `Δ`、`Δ_F` 分别为动作与力对齐误差上界。

**定义 127（感知-接触-鲁棒性联合证书）**
```
J⁺ = (ρ, A_cert, Ω_cert, T_cert, γ_ce, γ_contact, δ_a, δ_F, m_F, corr_eff, evidence)
```
- `Ω_cert=(V_core, ω_min, occ_bound)` 为视角证书，`V_core` 是保证覆盖的核心视点集；
- `T_cert=(contact_modes, F_cone, slip_bound)` 为接触证书；
- `m_F` 为接触安全裕度（见定理 2）；
- `evidence` 至少包含一次盲区反例与一次接触反例。
部署条件：
```
dom=in ∧ δ_a≤Θ_a ∧ δ_F≤Θ_F ∧ m_F>0 ∧ corr_eff≥θ_x
```
且 `unknown` 边不得以任何默认值补全。

## 2. 关键算法 伪代码

### IP-121 MVO（Multi-View Observation）

```python
def multiview_profile(skill, views, actions, renderer, critical_features):
    omega = {}
    for v in views:
        for a in actions:
            obs = renderer.render(skill, v, a)
            vis  = visibility(obs, critical_features[skill])      # 遮挡/视差/分辨率
            conf = feature_confidence(obs, critical_features[skill])
            omega[(v, a)] = clip(vis * conf, 0.0, 1.0)
    return OmegaProfile(omega, fusion='noisy_or')

def fused_observability(omega, views, a, eps_occ=0.05):
    miss = prod(1.0 - omega.get((v, a), 0.0) for v in views)
    return 1.0 - miss, miss <= eps_occ          # (omega_fused, is_sufficient)
```

### IP-122 TCS（Tactile Contact Sensing）

```python
def tactile_profile(skill, actions, sensor, n_trials, mu_s):
    tau = {}
    for a in actions:
        W = [sensor.wrench() for _ in range(n_trials)]
        c = mean(contact_detected(w) for w in W)
        F = robust_wrench_distribution(W)
        s = slip_probability(W)
        feasible = wrench_in_friction_cone(F.mean, mu_s) and (s <= THETA_S)
        tau[a] = ContactProfile(c, F, s, feasible, mode=contact_mode(W))
    return tau
```

### IP-123 OWC（Observability-Weighted three-valued Compatibility）

```python
def compat3(si, sj, theta_a, theta_O, margin=0.05):
    A_obs = observable_domain(si.omega, sj.tau, theta_O)
    inter = measure((si.A & sj.A) & A_obs, mu_O)
    union = measure((si.A | sj.A) & A_obs, mu_O)
    if union < EPS:
        return 'unknown', None                    # 可观测并集太小，证据不足
    ratio = inter / union
    if (ratio >= theta_a and contact_ok(si, sj)
            and cross_corr(si, sj) >= theta_x):
        return 'yes', ratio
    if ratio < theta_a - margin:
        return 'no', ratio
    return 'unknown', ratio
```

### IP-124 CMX（Cross-Modal Corroboration）

```python
def cross_modal_corroborate(vis_pred, tac_meas, sigma_x, err_corr):
    r = normalized_wrench_distance(vis_pred.contact_wrench, tac_meas.wrench)
    corr = exp(-r / sigma_x) - LAMBDA * err_corr
    support = min(vis_pred.conf, tac_meas.conf)
    if corr < THETA_X or support < THETA_S:
        return CrossCert(r, corr, support, status='conflict')
    return CrossCert(r, corr, support, status='corroborated')
```

### IP-125 AVS（Active View-contact Sampling）

```python
def active_view_contact_probe(unknown, probes, budget):
    # probes = 候选新视角 ∪ 安全轻接触试探；目标是消解 unknown，而非最大化精度
    for _ in range(budget):
        if not unknown:
            break
        q = argmax((p for p in probes if safe(p)),
                   key=lambda p: mutual_info(p; unknown) / cost(p))
        obs = execute_probe(q)
        update_profiles(obs)                 # 更新 omega / tau / mu_O
        unknown = recompute_three_valued()   # 只把有证据的格子移出 unknown
    return unknown, probe_log
```

### IP-127 JPCC（Joint Perceptual-Contact Certificate）

```python
def joint_perceptual_contact_cert(skill_seq, Omega, Tau, gce, gcontact, budgets):
    A_core = reduce(intersection, [s.A for s in skill_seq])
    delta_a = max_alignment_error(gce, A_core)
    delta_F = max_wrench_mismatch(gcontact, Tau)
    obs_min = min(fused_observability(Omega, V_core, a) for a in A_core)
    if obs_min < THETA_O:
        return ('reject', 'unobservable', probe_plan(A_core))
    if not all(contact_ok(s, a) for s, a in zip(skill_seq, A_core)):
        return ('reject', 'contact_infeasible')
    corr = cross_modal_corroborate(vis_batch, tactile_batch,
                                   sigma_x, err_corr)
    if corr.status == 'conflict':
        return ('unknown', 'cross_conflict', corr)    # 触发 AVS，不默认放行
    m_F = min_contact_margin(Tau, E_contact, tau_r, L_F)
    if delta_a > budgets.a or delta_F > budgets.F or m_F <= 0:
        return ('reject', 'budget_or_margin', delta_a, delta_F, m_F)
    return ('ok', JPlus(rho=compose_robustness_chain(skill_seq),
                        A_cert=(A_core, buffer_zone(A_core, delta_a)),
                        O_cert=(V_core, obs_min),
                        T_cert=(contact_modes(Tau), friction_cone(Tau)),
                        gce=gce, gcontact=gcontact,
                        delta_a=delta_a, delta_F=delta_F, m_F=m_F,
                        corr_eff=corr.corr))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| MVO | O(|V|·|A|·R)（R 为渲染/特征提取） | O(|V|·|A|) | 视点标定、关键特征定义完备 |
| TCS | O(|A|·n_trials) | O(|A|·|F|) | 力锥参数 `μ_s` 校准、滑移标注 |
| OWC | O(|A|·|S|²) | O(1) 额外 | `μ_O` 可测、盲区不被当作证据 |
| CMX | O(|A|) | O(1) | 两通道时间同步、误差相关可估 |
| AVS | O(budget·(|probes|·|unknown|)) | O(|A|) | 信息增益估计无偏、探针安全 |
| CCC | O(|V|log|V|+|E|+|P_e|) | O(|V|+|E|) | 只走 yes 边、否决/反射硬实时 |
| JPCC | O(|S|·|A|+|V|·|A|) | O(|A|+|V|) | 五条件同时闭合，unknown 不降级 |

**推导 1（幽灵兼容界）**
设盲区 `B=A\A_obs`，报告兼容性 `ĉ=μ(A_i∩A_j)/μ(A_i∪A_j)`，真实可观测兼容性 `c*=μ((A_i∩A_j)\B)/μ((A_i∪A_j)\B)`。若一条边仅因 `B` 内的重叠而被判 `yes`，则 `c*=0`，而 `ĉ` 可任意大。偏差满足
```
ĉ − c* ≤ μ(B∩(A_i∩A_j)) / μ((A_i∪A_j)\B)
```
当可观测并集 `μ((A_i∪A_j)\B)→0` 时上界发散。**结论**：必须在 `A_obs` 上归一化，且在可观测并集过小时返回 `unknown`——这正是定义 124 三值化的必要性，而不是工程保守。

**推导 2（接触安全裕度与云延迟解耦）**
设接触 wrench 轨迹 `F(t)` 在 `E_contact` 内且关于时间 Lipschitz（常数 `L_F`），边端反射延迟为 `τ_r`。定义接触安全裕度
```
m_F = dist(F(t), ∂E_contact) − L_F·τ_r − δ_F
```
若 `m_F>0`，则在任何越界发生前反射弧已触发，故接触安全概率
```
P_safe ≥ 1 − P(F∉E_contact) − P(τ_reflex > τ_r)
```
**该式不含云端 RTT**：只要云计划不把 `F` 推出 `E_contact`，接触安全与云延迟无关。`γ_contact` 的力对齐误差 `δ_F` 直接吃掉裕度，故 `δ_F` 必须计入预算而非事后补偿。

**正确性定理（Perceptual-Contact Composition Soundness）**
承接第 54 轮 (A22)–(A28)，新增：**(A29)** `ω_S` 由已标定多视系统给出，`occ_bound` 可验证；**(A30)** 力觉 `τ_S` 的 `μ_s`、`s_S` 由独立标定集校准，误差 ≤ `β_t`；**(A31)** 视觉与力觉误差相关项 `ρ_err` 可在线估计，且 `corr_eff` 使用扣相关后的值。
若组合路径上所有边均为 `yes` 且 `dom=in`，则
```
P_success ≥ 1 − Σ_d(1−ρ_min(d)) − β_E − β_O − β_t
            − P(corr_eff<θ_x) − P(m_F≤0)
```
其中 `β_O` 为多视观测校准误差。**对含 `unknown` 边的路径，上式不成立**；不得把 `unknown` 代入任何默认值以复用该界。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 多视标定漂移导致 `ω_S` 过度自信 | 高 | 在线标定 + 视点冗余 + `occ_bound` 硬门控 |
| 视觉与力觉共享盲区（接触界面被夹爪遮挡且触觉饱和） | 高 | 显式估计 `ρ_err` + 第三探针 + `unknown` 硬规则 |
| 力觉仿真-现实落差使 `contact_ok` 虚高 | 高 | 真实标定集 + 域随机化 + 力锥保守收缩 |
| 三值逻辑产生过多 `unknown`，规划饥饿 | 中 | 探测预算调度 + 风险分级 + 保守回退技能 |
| 边端反射与云端计划冲突、来回震荡 | 中 | 反射后锁存 + 云端感知 `Veto_e` 的重规划 + hysteresis |

### IP-121 MVO

```python
def multiview_profile(skill, views, actions, renderer, critical_features):
    omega = {}
    for v in views:
        for a in actions:
            obs = renderer.render(skill, v, a)
            vis  = visibility(obs, critical_features[skill])
            conf = feature_confidence(obs, critical_features[skill])
            omega[(v, a)] = clip(vis * conf, 0.0, 1.0)
    return OmegaProfile(omega, fusion='noisy_or')

def fused_observability(omega, views, a, eps_occ=0.05):
    miss = prod(1.0 - omega.get((v, a), 0.0) for v in views)
    return 1.0 - miss, miss <= eps_occ
```

```python
def tactile_profile(skill, actions, sensor, n_trials, mu_s):
    tau = {}
    for a in actions:
        W = [sensor.wrench() for _ in range(n_trials)]
        c = mean(contact_detected(w) for w in W)
        F = robust_wrench_distribution(W)
        s = slip_probability(W)
```

### IP-123 OWC

```python
def compat3(si, sj, theta_a, theta_O, margin=0.05):
    A_obs = observable_domain(si.omega, sj.tau, theta_O)
    inter = measure((si.A & sj.A) & A_obs, mu_O)
    union = measure((si.A | sj.A) & A_obs, mu_O)
    if union < EPS:
        return 'unknown', None
    ratio = inter / union
    if (ratio >= theta_a and contact_ok(si, sj)
            and cross_corr(si, sj) >= theta_x):
        return 'yes', ratio
    if ratio < theta_a - margin:
        return 'no', ratio
    return 'unknown', ratio
```

```python
def cross_modal_corroborate(vis_pred, tac_meas, sigma_x, err_corr):
    r = normalized_wrench_distance(vis_pred.contact_wrench, tac_meas.wrench)
    corr = exp(-r / sigma_x) - LAMBDA * err_corr
    support = min(vis_pred.conf, tac_meas.conf)
    if corr < THETA_X or support < THETA_S:
```

```python
def joint_perceptual_contact_cert(skill_seq, Omega, Tau, gce, gcontact, budgets):
    A_core = reduce(intersection, [s.A for s in skill_seq])
    delta_a = max_alignment_error(gce, A_core)

    if corr.status == 'conflict':
        return ('unknown', 'cross_conflict', corr)

        rho=compose_robustness_chain(skill_seq),

        O_cert=(V_core, obs_min, occ_bound(Omega, V_core)),
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MVO | O(|V|·|A|·R) | O(|V|·|A|) | 视点已标定；关键特征集完备 |
| TCS | O(|A|·n_trials) | O(|A|·|F|) | `μ_s`/滑移标注独立校准 |
| OWC | O(|S|²·|A|) | O(|A|) | 盲区不入 yes；可观测并集过小→unknown |
| CMX | O(|A|·|F|) | O(1) | 时间同步；误差相关可估 |
| AVS | O(budget·|probes|·|unknown|) | O(|A|) | 信息增益无偏；探针安全 |
| CCC | O(|V|log|V|+|E|+|P_e|) | O(|V|+|E|) | 只走 yes 边；反射硬实时 |
| JPCC | O(|S|·|A|+|V|·|A|) | O(|A|+|V|) | 五条件闭合；unknown 不降级 |

**推导 1（幽灵兼容界）**
```
c*  = μ((A_i∩A_j)\B) / μ((A_i∪A_j)\B)
ĉ − c* ≤ μ(B∩(A_i∩A_j)) / μ((A_i∪A_j)\B)
```
可观测并集 → 0 时上界发散。故 OWC 必须在 `A_obs` 上归一化，并在 `μ((A_i∪A_j)∩A_obs) < EPS` 时返回 `unknown`，禁止用全空间 Jaccard 的数值复用为可行边。

**推导 2（接触安全裕度与云延迟解耦）**
```
m_F = dist(F(t), ∂E_contact) − L_F·τ_r − δ_F
m_F > 0  ⇒  P_safe ≥ 1 − P(F∉E_contact) − P(τ_reflex > τ_r)
```
该下界不含云端 RTT：只要云计划保证 `F∈E_contact`，接触安全由边端反射独立保证；`δ_F` 直接消耗裕度，必须计入预算。

**正确性定理（Perceptual-Contact Composition Soundness）**
承接 (A22)–(A28)，新增 **(A29)** 多视系统已标定且 `occ_bound` 可验证；**(A30)** `τ_S` 的 `μ_s`、`s_S` 由独立标定集校准，误差 ≤ `β_t`；**(A31)** 通道误差相关 `ρ_err` 可在线估计，`corr_eff` 使用扣相关值。若路径所有边为 `yes` 且 `dom=in`：
```
P_success ≥ 1 − Σ_d(1−ρ_min(d)) − β_E − β_O − β_t
            − P(corr_eff<θ_x) − P(m_F≤0)
```
**含 `unknown` 边的路径不享有该保证**；`unknown` 只能由 AVS 消解，不能取默认值。
