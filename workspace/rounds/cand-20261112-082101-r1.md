# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「基准测试」×「数据集构建」）

> 第 57 轮把安全赌注从"模型置信"移到"证据承诺"，再移到"元先验 + 跨模态 + 个性化"，其正确性定理里每一个数（δ_f、ε_meta(k)、ECE_k、探针数 ↓40%、假承诺率 ↓60%）都是**在某个数据集上、用某个基准测出来的**。但前七轮从未回答一个更靠前的问题：**𝒟_meta 从哪来？我们凭什么相信测量本身？** 如果数据集是"成功集邮册"（录成功、删摔倒），基准就是一面只会说"安全"的镜子；如果基准可见且可被优化，它就不再是镜子而是靶子（Goodhart）。本轮两个灵感把评测从"事后打分"提升为"一等安全机制"：**数据集构建**把 𝒟_meta 从"碰巧采到的数据"变成**带覆盖证书与统计功效表的设计物**；**基准测试**把评测从"一个分数"变成**密封、预注册、污染审计的契约**，契约本身携带证书 J_e。核心命题由"证据说可信"升级为 **"证据须附带'在哪个世界上、用哪份数据、被怎样检验过'的范围证书，才说可信"**——可信性从"全局断言"降级为"有范围、可证伪、可迁移的声明"。

核心矛盾：
- **H29（基准 vs Goodhart）**：每轮都在优化同一批指标，指标一旦可见就从"测量"变成"目标"；所谓 ↓60% 可能只是对基准的过拟合，世界没变、分数变了。
- **H30（数据集覆盖 vs 分布移动）**：覆盖证书只能覆盖被采样过的风险格子；部署流会漂移，覆盖外的自信是伪自信，且不会有任何指标报警。
- **H31（内部效度 vs 外部效度）**：台架上能测出因果效应（内部效度）不等于能迁移到部署（外部效度），两者常被同一句"实验证明"混为一谈。

## 0. 直觉与动机

**灵感 1（数据集构建 → 从成功样本到失败样本、覆盖证书、功效分析）**
直觉：机器人数据天然是幸存者偏差——摔倒的片段被删掉、失败的探针没被记录、橡皮章标注混进真值。可安全恰恰住在失败分布里。数据集构建要反过来：**按风险网格 G（材质×季节×坡度×欺骗类型×接触级别）主动采集**，并用统计功效分析反推"每个格子要采多少条才能把失败率 δ_f 分辨出来"，而不是采到什么算什么。数据集不是越大越好，是**在每个风险相关格子里有足够功效**。于是数据集带两样东西：**覆盖证书 𝒞**（哪些格子达标）和**功效表 n\***（每格目标样本量）。任何安全声明只在 𝒞 内成立；出了 𝒞 视同 OOD，退回保守动作，而不是外推。

**灵感 2（基准测试 → 密封信封、预注册、污染审计）**
直觉：基准最大的敌人不是"难"，是"被看见"。测试集一旦可见，调参就会把噪声也拟合进去（benchmark overfitting）；指标一旦成为目标，就被 Goodhart 化。那就把它当一次真正的科学实验：**预注册**（先冻结假设、主指标、统计检验、α、样本量、停止规则，再跑）；**密封测试集**（部署前公开 Merkle 根，只在评测时开封，开封即退役）；**污染审计**（canary/成员推断/最近邻重叠，估计训练集是否"见过"密封集）。基准不是分数，是一份可审计的契约；分数只有在契约未被违反时才有效。

**灵感 3（对抗数据 → 欺骗基准与反事实配对）**
直觉：第 57 轮的 EV-xmodal 依赖"模态条件独立"，而这条假设平时几乎不被触发——只有物理欺骗时才暴露。平时跑一万次成功只会反复确认它"没出事"，这不叫验证。所以要**专门构建欺骗数据集**：为每个模态造一个"它撒谎、别人不撒谎"的区域，再造成"多模态共谋"的区域，以及**反事实配对**（同一区域，有/无欺骗两版，系统必须给出可区分输出）。不测平均成功率，测**欺骗下的假承诺率 FCR_red** 与**反事实敏感度 CS**——把"系统是否真在用跨模态分歧"变成一个可判定的实验，而不是一段自述。

**灵感 4（内外效度 → 迁移证书）**
直觉：台架实验与真实部署之间隔着一次分布移动。与其笼统说"实验证明安全"，不如显式估计基准分布与部署流的位移 d_shift，并给一条**迁移界**：|m_deploy − m_bench| ≤ L_m·d_shift + η(n)（η 为有限样本噪声）。当 d_shift>θ_shift 或部署落在 𝒞 内比例不足，基准结论**作废**，系统退回保守默认——像法律上的"证据失效"，而不是打个折继续用。这把"实验能推广到真实世界"从修辞变成带条件的假设检验。

**灵感 5（评测治理 → 基准组合、轮转、访问预算）**
直觉：防 Goodhart 不能只靠技术，还要靠制度。基准应当是**组合**（多实例、隐藏轮转、密封替换），且**评测访问是有限预算**：在 dev 集上每多跑一次，它的证明力就衰减一次（等价于多重比较的 α 膨胀），必须记账并用 Holm/Bonferroni 校正。基准饱和或被泄漏就退役，从密封池换新。用"公开集与密封集的分数差 G_gap"当 Goodhart 温度计：差值变大，说明公开分正在被优化污染。

**灵感 6（五灵感合流 → 声明从"无条件可信"变成"带范围与失效条件的可信"）**
直觉：数据集构建给出**空间范围 𝒞**（在哪些世界成立）；密封基准给出**证据效力**（测试是否干净）；对抗基准给出**假设是否被真正测试**（CS）；迁移证书给出**时间/分布范围**（还能不能外推）；评测治理给出**证据是否被污染**（G_gap）。合起来，第 57 轮的"证据门"外再套一道"**声明门**"：一条安全声明要同时通过 𝒞 覆盖、密封契约、对抗覆盖、迁移界、G_gap 五关，才允许写进产物。击穿安全的方式因此从"骗过模型"升级为"骗过整套评测制度"——而制度的目的，正是让"骗过"留下证据。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（覆盖驱动数据集构建 CDS）** 风险网格 G=M×S×Θ×Ψ×L（材质类/季节/坡度桶/欺骗类型/接触级别）。每格 g 的有效样本量 n_eff(g)=Σ_i r_i（r_i 为第 57 轮 PTM 标注可靠度权重，低授权/橡皮章标注降权或剔除），目标样本量由功效分析给出 n\*(g)=min{n: 单侧二项检验 H0:p_fail≥δ_f 在显著性 α 下功效≥1−β}。覆盖证书 C(𝒟)={g:n_eff(g)≥n\*(g)}，声明覆盖域 𝒞=∪_{g∈C} g。构建算子 𝒟=CDS(G,n\*,budget)：分层重要性采样 + 风险比例分配 + 主动采集近失事件（near-miss）；负结果与失败样本强制入库、不得删除。任何指标 m 一律以 m|_𝒞 报告；g∉C 时不允许外推。

**定义 140（密封基准信封 SBE）** 基准信封 B=(version,P,H,split,prereg)。数据三分：𝒟_train/𝒟_dev/𝒟_sealed；𝒟_sealed 在任何调参前以 Merkle 根 H 承诺并公示；prereg=(假设,主指标,检验,α,功效,停止规则,分析计划) 在评测前冻结。开封密钥仅在代码冻结后释放；开封一次即退役。污染审计给出 c(B)=max{canary 命中率, 成员推断 AUC 超阈, 最近邻重叠率}。有效评测要求 H 一致 ∧ prereg 哈希一致 ∧ c(B)≤c_max。

**定义 141（对抗欺骗基准 ADT）** 欺骗集 𝒟_red={(r,m_lie,type,r_cf)}，type∈{单模态撒谎, 多模态共谋, 时序漂移(仅首访撒谎), 标注撒谎(人)}；r_cf 为只改变"是否欺骗"的反事实配对。指标：FCR_red(type)（该类型下假承诺率）、detect_recall、反事实敏感度 CS=P(输出在 r 与 r_cf 上可区分)。XMC 的独立性主张**只有在 CS≥CS_min 时才算被验证**，否则记为"未证明假设"，不得在正确性定理中当作已知条件。

**定义 142（评测台账证书 J_e）** J_e=(datasheet,split_manifest+Merkle H,C(𝒟)|_𝒞,n\* 功效表,c(B) 污染率,red-team 结果,code_hash+env_lock,seeds,完整结果含负结果,prereg_hash)。产物区每条量化声明必须引用一个 J_e；无 J_e 的声明视为不可采信（inadmissible）。可复现性：由 J_e 重跑需在容差内复现主指标，否则声明降级为"未验证"。

**定义 143（内外效度与迁移证书 VTC）** 内部效度 IV=因果识别检查表（对照、消融、混淆变量、随机化）得分；外部效度以位移 d_shift(B_bench,B_deploy)=domain-classifier AUC 映射或 G 上的覆盖失配度量。迁移界：|m_deploy−m_bench|≤L_m·d_shift+η(n)。若 d_shift>θ_shift 或部署落在 𝒞 内比例<1−γ，则基准结论作废（void），退回保守默认并记录 `claim_void`。

**定义 144（防 Goodhart 评测治理 GDR）** 基准组合 𝔹={B_1..B_k}，隐藏轮转；评测访问预算：每次在 𝒟_dev 上评测消耗一个证明信用 credit，总信用受多重比较校正（Holm/Bonferroni）约束，访问全程记账。退役规则：分数饱和或 c(B)>c_max 即退役并从密封池补位。Goodhart 温度计 G_gap=|m_public−m_sealed|，超阈即判定基准已被优化污染，相关声明不可采信。

## 2. 关键算法伪代码（完整版见产物区）

```python
def construct_dataset(G, delta_f, alpha, beta, budget, labeler):
    n_star = {g: min_n_for_power(delta_f, alpha, beta, g) for g in G}
    D = stratified_active_collect(G, n_star, budget,
                                  include=lambda e: e.near_miss or e.fail)
    n_eff = {g: sum(labeler.reliability(i) for i in D[g]) for g in G}
    C = {g for g in G if n_eff[g] >= n_star[g]}
    return D, CoverageCert(C, n_star, n_eff)            # 覆盖证书

def sealed_eval(B, model, code_hash):
    assert code_frozen(code_hash) and hash_ok(B.split, B.H)
    if contamination(B) > C_MAX: return Void('contaminated')
    if B.prereg_hash != load_prereg().hash: return Void('prereg_mismatch')
    return B.sealed.unseal().evaluate(model)            # 开封即退役

def transfer_check(B, deploy_stream):
    d = shift_distance(B.bench_dist, deploy_stream.dist)
    cov = coverage_of(deploy_stream, B.C)
    if d > THETA_SHIFT or cov < 1 - GAMMA: return Void('claim_void')
    return Bound(L_m * d + eta(len(deploy_stream)))     # 迁移界
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| CDS | O(\|G\|·N_采集) | O(N·d_e) | 功效表诚实、标注可靠度入 n_eff |
| SBE | O(N_sealed) | O(\|𝒟_sealed\|) | Merkle 承诺、开封即退役、污染 ≤c_max |
| ADT | O(\|𝒟_red\|·\|ℳ\|) | O(\|𝒟_red\|) | 反事实配对完整、共谋类型覆盖 |
| J_e | O(1) 组装 | O(results) | 每条声明可回溯、负结果不删 |
| VTC | O(N_deploy) | O(1) | d_shift 估计不偏、越界即作废 |
| GDR | O(1)/访问 | O(access_log) | 访问记账、多重比较校正、轮转 |

**正确性定理（Scoped Reproducible Falsifiable Soundness, SRFS 概要）**：在 A37–A40 上加 (A41) 覆盖与功效诚实（n_eff 计入标注可靠度，声明仅限 𝒞）；(A42) 密封与预注册（H 承诺、开封即退役、c≤c_max）；(A43) 对抗基准覆盖所有欺骗类型且反事实配对完整；(A44) 迁移界成立（|Δ|≤L_m·d_shift+η）；(A45) 评测访问记账与多重比较校正。则：(i) 任一声明的可信度上下界只在 𝒞 与 d_shift≤θ_shift 内成立，越界即 void 而非打折；(ii) 基准过拟合的偏差被 G_gap 检出，超阈则相关声明不可采信；(iii) 所有既往轮次的 δ_f、ε_meta、↓ 比例等数字由对应 J_e 重新索引，无法复现者降级为"未验证"。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 覆盖证书漏掉"未知的未知"格子 | 高 | 𝒞 外一律保守 + 主动采集新格子 + 位移检测 |
| 密封集被间接污染（代理泄漏） | 高 | 污染审计 + 开封即退役 + 定期换密封池 |
| 功效分析假设不成立（非独立/非稳态） | 中 | 块自助法/序列检验 + 声明保守功效 |
| 对抗基准本身被过拟合 | 中高 | 基准轮转 + 隐藏实例 + 访问预算 + G_gap |
| 评测治理拖慢迭代 | 中低 | 分级：探索用 dev、结论用 sealed、发布用 J_e |

## 6. 本轮最大风险

**一句话**：本轮把安全的最后一道仲裁交给评测，于是评测本身成了新的单点故障——若数据集被成功样本主导、密封集被间接污染、或功效根本不足以分辨 δ_f，那么所有漂亮的数字都只是"在一个被精心构造的世界里安全"，而覆盖证书与预注册只能证明"我们诚实地测了我们测过的东西"，无法证明"我们测到了会杀死我们的那个东西"；必须以 𝒞 外即保守、开封即退役、G_gap 超阈即作废三重制度性护栏，把"未覆盖"与"未验证"显式地当成不安全，而不是当成默认安全。

### IP-139 CDS（覆盖驱动数据集构建）

```python
def construct_dataset(G, delta_f, alpha, beta, budget, labeler):
    n_star = {g: min_n_for_power(delta_f, alpha, beta, g) for g in G}
    D = stratified_active_collect(                    # 分层+风险比例+主动找失败
            G, n_star, budget,
            include=lambda e: e.near_miss or e.fail,  # 失败样本强制入库

             for g in G}
```

### IP-144 GDR（防 Goodhart 评测治理）

```python
def governed_eval(B_portfolio, claim, log):
    B = choose_hidden(B_portfolio)                    # 隐藏轮转实例
    if log.credits_left(B) <= 0:  return 'no_proof_credit'
    log.spend(B); alpha_adj = holm_correct(log.n_queries(B))  # 多重比较校正
    res = sealed_eval(B, claim.model, claim.code_hash)
    gap = abs(res.public - res.sealed)                # Goodhart 温度计
    if gap > THETA_GAP: retire(B); return 'benchmark_polluted'
    if saturated(B, res): retire(B); refill(B_portfolio)      # 退役换新
    return res, alpha_adj, gap
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CDS | O(\|G\|·N_采集) | O(N·d_e) | 功效表诚实、标注可靠度入 n_eff（A41） |
| SBE | O(N_sealed) | O(\|𝒟_sealed\|) | Merkle 承诺、开封即退役、c≤c_max（A42） |
| ADT | O(\|𝒟_red\|·\|ℳ\|) | O(\|𝒟_red\|) | 反事实配对完整、所有欺骗类型覆盖（A43） |
| J_e | O(1) 组装 | O(results) | 每条声明可回溯、负结果不删 |
| VTC | O(N_deploy) | O(1) | d_shift 估计不偏、越界即 void（A44） |
| GDR | O(1)/访问 | O(access_log) | 访问记账、Holm 校正、轮转（A45） |

**正确性定理（Scoped Reproducible Falsifiable Soundness, SRFS）**
假设 A22–A40（第 53–57 轮）成立；**(A41)** 覆盖与功效诚实：n_eff 计入第 57 轮 PTM 标注可靠度，n\* 由预注册的功效分析给出，且所有声明只在其覆盖域 𝒞 内报告；**(A42)** 密封与预注册：𝒟_sealed 在调参前由 Merkle 根承诺，预注册哈希冻结，开封即退役，污染率 c(B)≤c_max；**(A43)** 对抗完备：对抗集覆盖单模态/共谋/时序/标注四类欺骗，反事实配对完整，CS≥CS_min 方可把 XMC 独立性当作已知前提；**(A44)** 迁移界：|m_deploy−m_bench|≤L_m·d_shift+η(n)，且 d_shift、覆盖失配可估；**(A45)** 评测访问受 credit 预算与 Holm 多重比较校正，饱和/污染基准退役。则：

1. **范围化健全性**：任一声明的可信度上界只在 `(𝒞, d_shift≤θ_shift, c(B)≤c_max, CS≥CS_min)` 内成立；越界时系统输出 `claim_void` 并退回第 57 轮保守默认，而非按旧数字打折继续用。
2. **抗过拟合**：dev 调参带来的分数膨胀被 `G_gap=|m_public−m_sealed|` 检出；G_gap>θ_gap 时相关声明不可采信，基准退役。
3. **可追溯性**：产物区每条量化声明索引一个 J_e；由 J_e 重跑不可复现者降级为"未验证"，第 53–57 轮的全部数字须按此重审。
4. **部署界（范围化）**：

```
P_safe(𝒞, d_shift≤θ) ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])
                        − P(𝓜 陈旧未检出) − P(护盾回退失败)
                        − P(𝒞 外被误用) − P(密封集污染未检出) − P(d_shift 低估)
```

关键：**数据集给范围、密封给效力、对抗给假设、迁移给时效、治理给纯洁**——五者共同把"安全"从无条件断言变成带失效条件的可证伪契约。第 57 轮的"效率与安全解耦"在本轮推广为"**论证与测量解耦**"：模型可以继续变强，但它的声明必须重新过一次干净的评测才被采信。

## 6. 本轮最大风险

**一句话**：本轮把安全的最后一道仲裁交给评测，于是评测本身成了新的单点故障——若数据集被成功样本主导、密封集被间接污染、或功效根本不足以分辨 δ_f，那么所有漂亮的数字都只是"在一个被精心构造的世界里安全"，而覆盖证书与预注册只能证明"我们诚实地测了我们测过的东西"，无法证明"我们测到了会杀死我们的那个东西"；必须以 𝒞 外即保守、开封即退役、G_gap 超阈即作废三重制度性护栏，把"未覆盖"与"未验证"显式地当成不安全，而不是当成默认安全。
