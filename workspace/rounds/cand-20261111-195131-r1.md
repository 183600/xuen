# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；发表导向新循环第 1 轮；本轮灵感：「创新点挖掘」×「论文发表」）

> 第 54 轮结束时系统已堆到约 120 个 IP、定义到 120、实验到 E161。但 **IP 数量不是论文贡献**：评审单位是"可证伪的承重主张 + 证据闭包"，不是算子清单。本轮把研究对象从"系统还能加什么"切换为"哪条主线值得发表、凭什么可信、投稿前会被哪条理由拒"。核心矛盾：H22：创新以算子为单位堆积，而论文以承重主张为单位评审；H23：内部自洽的证书体系尚未对齐外部先验工作，novelty 目前只能自证。

## 0. 直觉与动机

**灵感 1（创新点挖掘 = 从矿石到分子）**
直觉：过去 54 轮像一座矿，挖出的是"新颖性原子"（问题 / 机制 / 证据 / 先验差），而不是天然可发表的"贡献分子"。发表不是把 IP 列表贴上去，而是把原子按"一条主张 + 一组证据"重组。先做 **原子化**，再做 **可发表子图搜索**，比继续堆 IP 的边际收益高一个量级。

**灵感 2（论文 = 主张-证据图的一条承重脊柱）**
直觉：一篇论文只能有 1 条"承重主张"（load-bearing claim），其余节点要么是它的支撑、要么是消融、要么应移出正文成为后续论文。审稿人第一个问题是"你的核心 claim 是什么、凭什么信"。把 CCG 里不落在脊柱上的节点默认视为附录，能有效治愈"什么都想写"的惯性。

**灵感 3（novelty 是可辩护距离，不是形容词）**
直觉："我们是首个……"不可证伪。把每个原子相对最近先验工作写成 **delta 向量**，用加权距离量化"差多少、差在哪、差异是否被实验覆盖"。novelty = 距离 × 可验证性 × 置信度，而不是自我声明。这样审稿人可以在同一坐标系里复核你的主张。

**灵感 4（审稿人威胁模型 → 把拒稿理由提前变成实验）**
直觉：论文被拒多半不是缺创新，而是"基线不够、假设太强、sim2real 不足、不可复现、贡献不清"。把历史拒稿理由建成 RAT 表，每条配一个预先做好的 counter-experiment，投稿前先把概率最高的 3 条打掉，比写完再补实验便宜得多。

**灵感 5（发表金字塔 𝕡）**
直觉：在 𝕃（鲁棒性）、𝔸（动作协同）之上再叠一层 **发表层**：𝕡0 原始 IP → 𝕡1 新颖性原子 → 𝕡2 主张 → 𝕡3 叙事脊柱 → 𝕡4 期刊/竞赛适配。跨层传递的不再是代码，而是"证据闭包证书"。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（新颖性原子）**
新颖性原子 `ν = (π, μ, ε, δ, ρ)`：`π` 为问题原子；`μ` 为机制原子；`ε` 为证据原子（定理 / 实验 / artifact，类型集 `{thm, exp, art}`）；`δ ∈ ℝ^k` 为相对最近先验工作的先验差向量（维度如 decision-time / action-space / cross-layer / explainability / reproducibility）；`ρ = (conf, prov)` 为置信度与出处（轮次、IP 号）。一个 IP 被分解为原子多重集 `Ω(IP) = {ν_1,...,ν_m}`。

**定义 122（贡献声明图 CCG）**
`G_C = (C, E_sup, E_dep)`：`C` 为声明集，`c = (scope, strength, atoms)`；`E_sup ⊆ C × (Atoms ∪ Experiments)` 为支撑边；`E_dep ⊆ C × C` 为依赖边。**证据闭包** `closure(c)=1` 当且仅当从 `c` 出发的所有支撑链都落到具体 `ε` 且无环、无孤儿。**承重脊柱** `spine(G_C) = c*`，使 `c*` 的祖先闭包覆盖最多下游依赖，即 `c* = argmax_c Σ_{c'∈desc(c)} centrality(c')`。

**定义 123（先验差账本 PADL 与可辩护性）**
对原子 `ν`，最近先验集合 `N(ν) ⊆ P` 为检索得到的 top-k 相关工作。先验差距离 `d_δ(ν) = min_{p∈N(ν)} ||δ_ν - δ_p||_W`；可辩护性 `def(ν) = 1[d_δ(ν) ≥ θ_nov] · conf(ν) · ver(ν)`，其中 `ver(ν)` 为该差异被实验/定理覆盖的比例。论文新颖性质量 `Novelty(S) = Σ_{ν∈S} def(ν) · spread(ν)`，`spread` 用于惩罚高度相似原子的重复计数。

**定义 124（审稿威胁模型 RAT）**
`R = {(r_i, p_i, κ_i, κ̂_i)}`：`r_i` 为拒稿理由，`p_i` 为先验概率，`κ_i ∈ {0,1}` 表示当前证据是否已反驳该理由，`κ̂_i ∈ [0,1]` 为 counter 强度。覆盖 `cov(R) = Σ_{i:κ_i=1} p_i / Σ_i p_i`；残余拒稿风险 `P_reject ≈ Σ_{i:κ_i=0} p_i`。

**定义 125（发表适应度与可发表子图）**
给定目标 venue `v` 的权重向量 `w(v)`：
```
F_pub(S; v) = w_n·Novelty(S) + w_s·Significance(S) + w_r·Rigor(S)
            + w_c·Coherence(S) + w_a·Artifact(S) - w_rej·P_reject(S; v)
```
可发表子图 `S* = argmax_{S⊆G_C} F_pub(S;v)`，约束 `closure(c)=1 ∀c∈S`、`cov(R) ≥ τ_r`、`|S| ≤ κ_page`（版面预算）。

**定义 126（论文可复现证书 Π）**
`Π = (C_S, evid, art_manifest, δ_prior, R_table, repro)`。`Π` sound 当且仅当：(i) 每条 `c∈C_S` 有证据闭包；(ii) 每个证据指向可运行 artifact 或可检查定理；(iii) `cov(R) ≥ τ_r`；(iv) `δ_prior` 每条有引文与坐标。论文"可投"当且仅当 `Π` sound 且 `F_pub(S*;v) ≥ Θ_pub`。

## 2. 关键算法 伪代码

### IP-121 NAM（Novelty Atom Miner）

```python
def mine_atoms(corpus, k_sem=0.9):
    atoms = []
    for ip in corpus:
        for unit in split_unit(ip):          # 按定义/定理/实验切分
            nu = Atom(pi=extract_problem(unit),
                      mu=extract_mechanism(unit),
                      eps=extract_evidence(unit),
                      delta=embed_delta(unit),
                      prov=Provenance(round=ip.round, id=ip.id))
            atoms.append(nu)
    return dedupe(atoms, key=semantic_hash, threshold=k_sem)
```

### IP-122 CCG（Claim-Evidence Graph）

```python
def build_ccg(claims, atoms, experiments):
    G = ClaimGraph()
    for c in claims:
        G.add_claim(c)
        for a in match_atoms(c, atoms):        G.add_support(c, a)
        for e in match_experiments(c, experiments): G.add_support(c, e)
    for cj in claims:
        for ci in claims:
            if depends_on(cj, ci): G.add_dep(cj, ci)
    orphans = [c for c in G.claims if not closure(G, c)]
    return G, orphans, spine(G)
```

### IP-123 PADL（Prior-Art Delta Ledger）

```python
def prior_art_ledger(atoms, prior_index, W, theta_nov, theta_v):
    ledger = {}
    for nu in atoms:
        N = prior_index.retrieve(nu, k=5)          # 独立检索，禁止用生成模型自评
        d = min(weighted_l2(nu.delta, p.delta, W) for p in N)
        ver = evidence_coverage(nu, experiments)
        ledger[nu] = dict(N=N, d_delta=d, ver=ver,
                          defended=(d >= theta_nov and ver >= theta_v))
    return ledger
```

### IP-124 RAT（Reviewer Adversary Table）

```python
def build_rAT(claims, venue_rubric, past_reviews, evidence_pool):
    R = []
    for r in reasons(venue_rubric, past_reviews):
        p = reason_prior(r, past_reviews)
        counter = best_counter(r, evidence_pool)
        kappa = 1 if counter.strength >= tau_counter else 0
        R.append(Threat(r, p, kappa, counter.strength, counter.experiment))
    return R
```

### IP-125 PSS（Publishable Subgraph Search）

```python
def publishable_subgraph(G, R, venue, tau_r=0.8, page_budget=6):
    best = None
    for c_star in candidate_load_bearing(G):
        S = transitive_closure(G, c_star)          # 脊柱 + 全部被依赖支撑
        if not all(closure(G, c) for c in S):      continue
        if len(S) > page_budget:                   continue
        if reviewer_coverage(S, R) < tau_r:        continue
        f = fitness(S, venue)
        best = max(best, (f, S))
    return best
```

### IP-126 CERC（Claim-Evidence Reproducibility Certificate）

```python
def paper_certificate(S, ledger, R, artifacts, repro):
    checks = {
        "closure":  all(closure(S, c) for c in S),
        "novelty":  all(ledger[a].defended for a in critical_atoms(S)),
        "threat":   reviewer_coverage(S, R) >= tau_r,
        "repro":    repro.all_runs_ok(),
        "artifact": artifacts.manifest_complete(),
    }
    status = "ready" if all(checks.values()) else "blocked"
    return status, checks, PaperCert(S, checks, ledger, R)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| NAM | O(Σ|unit|·d_sem) | O(|Atoms|·k) | 原子切分互斥、去重阈值稳定 |
| CCG | O(|C|² + |C|·|Atoms|) | O(|C|+|E|) | 支撑边完备、无环 |
| PADL | O(|Atoms|·k·k_δ) | O(|Atoms|·k) | 先验检索独立、delta 坐标对齐 |
| RAT | O(|R|·|evidence|) | O(|R|) | 理由先验来自外部审稿分布 |
| PSS | O(2^|C|) 最坏，贪心/束搜索 O(|C|·b) | O(|C|²) | 闭包单调、剪枝不丢解 |
| CERC | O(|S|+|Atoms|) | O(|S|) | 证书字段可机器校验 |

**正确性定理（Claim-Evidence Closure Soundness）**
假设 **(A29)** 原子出处完整、可追溯；**(A30)** 先验检索对真实最近先验的召回 ≥ `1-ε_p`；**(A31)** 证据链中每次复现失败概率 ≤ `ε_e`。若 `Π` sound，则评审可反驳的主张出现概率满足：
```
P(∃ 可反驳主张 in S) ≤ Σ_{c∈S}[ε_p(c) + ε_e(c)] + (1 - cov(R)) + β_audit
```
直觉：闭包消除"无证据"，`ε_p` 消除"漏掉的先验"，`ε_e` 消除"跑不出来的证据"，`1-cov(R)` 是尚未提前反驳的拒稿理由；`β_audit` 为人工审计漏检率。

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 原子分解一致性 | 双人标注 Cohen κ / 原子召回 | κ ≥ 0.75，召回 ≥ 0.85 |
| E163 先验差账本可靠度 | 最近先验召回 / delta 距离扰动稳定性 | 召回 ≥ 90%，距离漂移 ≤ 10% |
| E164 证据闭包完备性 | 孤儿 claim 数 / 人工审计漏检率 | 0 孤儿，漏检 ≤ 3% |
| E165 审稿威胁预测 | 对历史真实 review 的 top-3 拒稿理由命中率 | 命中 ≥ 70%，误报 ≤ 20% |
| E166 发表适应度效度 | `F_pub` 与实际录用/竞赛名次的 AUC | AUC ≥ 0.80 |

**消融**：去掉 PADL（只看内部 IP）应显著高估 novelty；去掉 RAT（不预建 counter）应显著低估拒稿风险；去掉闭包约束应出现"孤儿 claim 泄漏进正文"。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| delta 向量由同一生成模型自评，形成循环 | 高 | 独立检索 + 外部基线 + 盲评代理 |
| 原子切分粒度失控（过细变清单，过粗丢创新） | 中 | 固定 5 类原子模板 + κ 校验 |
| 威胁模型先验偏差（只覆盖见过的拒稿） | 高 | 跨 venue 评审语料 + 红队审稿 |
| 子图搜索被版面预算截断关键支撑 | 中 | 附录/artifact 承载长证据链 |
| 把"过程证书"误当论文贡献 | 中 | 论文只收承载科学主张的原子，过程工具进 artifact |

## 6. 本轮最大风险

**一句话**：本轮把"堆 IP"改造为"挖原子—建主张—证闭包—打拒稿"的发表流水线，但其 novelty 判定的 soundness 完全取决于 **先验检索是否独立于生成回路**——若 delta 向量仍由产出这些 IP 的同一模型/同一语料自评，那么所谓"可辩护距离"就是循环论证，论文会把自洽当新颖，故必须以 **独立先验索引 + 外部基线 + 盲评代理 + 被迫的负面引用** 四重隔离，宁可承认某条主张"暂不可辩护"，也不把内部闭环包装成外部贡献。

## 9. 本轮最大风险

**一句话**：本轮把"堆 IP"改造为"挖原子—建主张—证闭包—打拒稿"的发表流水线，但其 novelty 判定的 soundness 完全取决于 **先验检索是否独立于生成回路**——若 delta 向量仍由产出这些 IP 的同一模型/同一语料自评，那么"可辩护距离"就是循环论证，论文会把自洽当新颖，故必须以 **独立先验索引 + 外部基线 + 盲评代理 + 被迫的负面引用** 四重隔离，宁可承认某条主张"暂不可辩护"，也不把内部闭环包装成外部贡献。
