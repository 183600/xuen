# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感驱动循环第 2 轮；本轮灵感：「模仿学习」×「MuJoCo」）

> 第 54 轮把技能组合提升为「动作剖面 α_S + 鲁棒性谱 ρ」的双证书体系，但其 soundness 压在一个强前提上：(A26) 假设 α_S 可由结构化仿真“完备校准”。本轮用 **模仿学习** 回答“数据从哪来”，用 **MuJoCo** 回答“物理怎么验”。核心矛盾：**H22** 模仿技能的可用域由演示分布决定，演示之外的动作剖面是外推幻觉，组合前看似兼容、执行时却落在支撑集外；**H23** MuJoCo 的接触切换使动力学分段光滑，跨接触模式的鲁棒性证书发生跳变，直接击穿第 54 轮 A27 的全局 Lipschitz 与单调假设。

## 0. 直觉与动机

**灵感 1（演示即覆盖：把 α_S 从查表变成带置信下界的统计对象）**
直觉：第 54 轮的 α_S(a) 是点估计，没采过的动作要么记 0、要么被平滑插值，于是“没证据”被误读成“能执行”或“不能执行”。模仿学习提供天然测度 μ_D：人演示过什么，才说明技能在这个区域有支撑。把动作剖面升级为 **覆盖下界** `α_S^-(a)` 与 **上界** `α_S^+(a)`，二者之差 `Γ(a)=α_S^+(a)-α_S^-(a)` 就是 **认知不确定性带**。组合只认下界，外推区强制归零。这样假兼容不是靠事后检测，而是在第一性定义上被排除。

**灵感 2（能力来自演示，可信来自覆盖）**
直觉：模仿学习给你一个很强的策略 π_θ，但强不等于可信。真正的部署判据应是 `α_S^-(a) ≥ θ_cov`，即“在这个动作上，我有统计把握它能成功”。于是技能被重新定义为 `(π_θ, D, C_S)`，其中 `C_S` 是可认证域。组合的任务不是找“能力交集”，而是找 **可认证域交集** `C_i ∩ C_j`。这把第 54 轮的风险从“采样不足”变成可量化、可优化的覆盖指标。

**灵感 3（MuJoCo 接触模式分解：把非光滑物理切成片）**
直觉：MuJoCo 里最难的不是连续控制，而是接触的“开/合”——脚落地、手抓取、物体碰撞。接触图切换的瞬间，动力学雅可比跳变，鲁棒性谱 ρ 也随之跳。用一个全局光滑模型去拟合，必然在接触边界系统性低估风险。正确做法是按 **接触模式 m** 切片：模式内用 `ρ_m(a)` 与 `L_m`-Lipschitz，跨模式用 **冲量预算** `J_{m→m'}` 记账。这样第 54 轮的 γ_ce 假设被弱化为 **分段 Lipschitz**，更接近真实但仍有界。

**灵感 4（覆盖引导的主动证伪：演示给正例，MuJoCo 给反例）**
直觉：演示只给正样本，覆盖估计天然乐观。MuJoCo 便宜，能在信任域边界 `∂T_β` 上主动搜索失败。于是数据采集变成 **正例来自人、反例来自仿真** 的双源夹逼：在边界找到失败就把该区域从 C_S 剔除，找不到就扩域。这不是随机采样，而是目标明确的 **覆盖引导证伪（CGF）**，单位样本的信息量远高于均匀采样。若仿真中存在特权专家，还可用 DAgger 式纠正标签缓解协变量偏移。

**灵感 5（覆盖-鲁棒性对偶）**
直觉：覆盖与鲁棒并非同向。多采低质量动作会扩大 `|C_S|` 却拉低 ρ_min 达标率；只采高可靠动作则 C_S 过小、组合不可行。真正要最大化的是 **可部署体积** `|{a : α_S^-(a) ≥ θ_cov ∧ ρ(a) ≥ ρ_min}|`。这把数据采集从“越多越好”变成约束优化：在 ρ 约束下扩张覆盖，最优采样点位于 `∂C_S` 而非演示中心。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（演示覆盖测度与信任域）**
演示集 `D = {(o_t,a_t)}_{t=1}^N`，动作覆盖密度 μ_D(a) 由 kNN/KDE 估计。覆盖下界 `β_D^-(a)` 满足 `P_{a~μ_D}[β_D^-(a) ≤ μ_D(a)] ≥ 1-δ_conf`（DKW/Conformal）。信任域 `T_β = {a | β_D^-(a) ≥ β_min}`。技能动作剖面上下界 `α_S^-, α_S^+` 由演示成功样本与 MuJoCo 反例共同夹逼，外推区强制 `α_S^-=0`。

**定义 122（模仿技能与可认证域）**
模仿技能 `S_IL = (π_θ, D, α_S^-, α_S^+, ρ_m, M(·), FP_D)`，其中 `M(a)` 为接触模式映射，`FP_D` 为演示指纹。**可认证域** `C_S = {a | α_S^-(a) ≥ θ_cov, M(a)∈M_known}`。认证间隙 `Γ(a)=α_S^+(a)-α_S^-(a)`，`Γ_S = max_{a∈C_S} Γ(a)`。

**定义 123（覆盖兼容性）**
`compat_β(S_i,S_j) = vol(C_i∩C_j) / vol(C_i∪C_j)`，组合可判定条件：
```
compat_β ≥ θ_a ∧ vol(C_i∩C_j) ≥ v_min ∧ Γ_{i,j} ≤ Θ_Γ ∧ ρ_{m}(a) ≥ ρ_min ∀a∈C_i∩C_j
```
与第 54 轮的区别：用可认证域 C 替代原始 α 支撑，从定义上排除 OOD 假兼容。

**定义 124（接触模式分解与分段 Lipschitz）**
接触模式 `m = (active_contacts, friction_state)`，`M(a)` 为模式映射。模式内 `||ρ_m(a)-ρ_m(a')|| ≤ L_m||a-a'||`；跨模式 `|ρ_{m'}(a^+)-ρ_m(a^-)| ≤ J_{m→m'}`，`J_max = max J_{m→m'}`。**模式升级风险** `β_mode = P_{a~π}(M(a)∉M_known)`。这弱化第 54 轮 A27 的全局 Lipschitz。

**定义 125（演示覆盖证书）**
`D_cert = (β_D^-, ε_cov, δ_conf, FP_D, OOD)`，其中 `ε_cov` 为覆盖误差、`δ_conf` 为置信度、`FP_D` 为演示指纹、`OOD` 为分布外检测器。证书有效当且仅当 `P_{a~μ_D}[α_S^-(a) ≥ θ_cov] ≥ 1-ε_cov` 且 `P[OOD(a)=in | a∈C_S] ≥ 1-δ_ood`。

**定义 126（模仿-组合联合证书）**
`J_IL = (J, D_cert, M_set, J_max, Γ_S)`，J 为第 54 轮联合证书。部署条件：
```
dom_J(T)=in ∧ D_cert有效 ∧ M(a)∈M_set ∀a∈C_core ∧ Γ_S<Θ_Γ ∧ J_max<J_budget
```

### IP-121 CDP（Coverage-Density Profiling）

```python
def coverage_profile(D, k, beta_min, delta_conf):
    kdt = KDTree([a for _,a in D])
    beta_minus = {}
    for a in action_grid:
        dists,_ = kdt.query(a, k)
        mu_hat = k/(len(D)*volume_ball(dists[-1]))
        beta_minus[a] = mu_hat - dkw_slack(len(D), delta_conf)   # 保守下界
    T_beta = {a for a,v in beta_minus.items() if v >= beta_min}
    return beta_minus, T_beta
```

```python
def profile_bounds(D_pos, D_neg_sim, T_beta, theta_cov):
    alpha_minus, alpha_plus = {}, {}
    for a in T_beta:
        lo, hi = clopper_pearson(success(D_pos,a), n(D_pos,a), conf)
        alpha_minus[a], alpha_plus[a] = lo, hi
    for a in action_grid - T_beta:
        alpha_minus[a], alpha_plus[a] = 0.0, 1.0  # 外推：下界归零
    return alpha_minus, alpha_plus
```

```python
def synthesize_skill(demos, mujoco_env, theta_cov, beta_min, dagger_rounds=2):
    pi = train_action_chunking_policy(demos)          # e.g. ACT / diffusion policy
```

### IP-123 CGC（Coverage-Graph Composition）

```python
def build_coverage_graph(skills, theta_a, v_min, Theta_Gamma):
    G = nx.DiGraph()
    for i,s1 in skills:
        for j,s2 in skills:
            if i==j: continue
            C_inter = s1.C_S & s2.C_S
            compat = vol(C_inter)/vol(s1.C_S | s2.C_S)
            Gamma = max(s1.Gamma_S, s2.Gamma_S)
            if compat>=theta_a and vol(C_inter)>=v_min and Gamma<=Theta_Gamma:
                G.add_edge(i,j, compat=compat, C_inter=C_inter,
                           rho=compose_robustness(s1.rho,s2.rho,K))
    return G

def plan_under_coverage(T, G, beta_min):
    # 保守 A*：只走可认证域，admissibility 由 LCB 保证
    return a_star(G, start='root', goal=T,
                  edge_cost=lambda e: 1-e['compat'],
                  node_valid=lambda n: n.C_S)
```

### IP-125 CGF（Coverage-Guided Falsification）

```python
def coverage_guided_falsify(pi, env, C_S, budget):
    frontier = boundary(C_S)                       # ∂C_S
    failures = []
    for _ in range(budget):
        a = acquire(frontier, strategy='max_uncertainty')
        ok, info = mujoco_rollout(pi, env, a)
        if not ok:
            failures.append((a, info.contact_mode))
            C_S = C_S - neighborhood(a)             # 剔除失败邻域
            frontier = boundary(C_S)
        else:
            C_S = C_S | neighborhood(a, relax=True) # 成功则外扩
    return C_S, failures
```

### IP-126 SJC（Sim-to-Real Joint Certificate）

```python
def joint_certificate_IL(seq, gamma_ce, delta_a_budget, Theta_Gamma, J_budget):
    C_core = reduce(intersection, [s.C_S for s in seq])
    D_cert = merge_coverage_certs([s.D_cert for s in seq])
    M_set  = reduce(union, [s.M_set for s in seq])
    Gamma_S = max(s.Gamma for s in seq)
    J_max = max_mode_impulse(seq)
    if not D_cert.valid: return ('reject','coverage')
    if Gamma_S > Theta_Gamma: return ('reject','gap')
    if J_max > J_budget: return ('reject','impact')
    if vol(C_core)==0: return ('reject','empty_cert_region')
    rho_comp = compose_robustness_chain([s.rho for s in seq], K)
    delta_a = max_alignment_error(gamma_ce, C_core)
    if delta_a > delta_a_budget: return ('reject','action_mismatch')
    return ('ok', JointCert_IL(rho_comp, C_core, D_cert, M_set, Gamma_S, J_max, delta_a))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CDP | O(N log N + |A| log N) | O(N+|A|) | DKW/Conformal 下界有效 |
| ILS | O(N·T + |A|·|M|) | O(N+|A|) | 覆盖夹逼、OOD 检测 |
| CGC | O(|S|²·|C|) | O(|S|²+|E|) | 只走可认证域、LCB sound |
| CMC | O(|M|·T·|A|) | O(|M|+|A|) | 模式分段完备、冲量有界 |
| CGF | O(b·(T+log|A|)) | O(|A|) | 边界采样收敛、负例回写 |
| SJC | O(|S|·|C|+|𝔇_ρ|) | O(|C|) | 证书合并 sound、间隙预算闭合 |

**正确性定理（Coverage-Certified Imitation Composition Soundness）**
假设第 54 轮 (A22)-(A28) 中与云边映射相关的部分保留；本轮新增 **(A29)** 演示与部署同分布或 OOD 检测无漏检；**(A30)** MuJoCo 接触模式划分覆盖部署模式集合；**(A31)** 模式内 `L_m`-Lipschitz 且跨模式冲量 `≤ J_max`；**(A32)** 覆盖下界满足 `δ_conf` 置信度。
则：
```
P_success ≥ 1 - ε_cov - δ_conf - β_mode - Σ_d(1-ρ_min(d)) - P(Γ_S>Θ_Γ) - P(δ_a>Θ_a)
```
关键：**可认证域交集非空**、**模式升级有界**、**覆盖下界单边保守**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 演示覆盖 ≠ 部署覆盖 | 高 | OOD 检测 + CGF 主动扩域 + 保守 LCB |

## 6. 本轮最大风险

**一句话**：模仿学习把动作剖面从点估计升级为带覆盖下界的可认证域，MuJoCo 把鲁棒性从光滑拟合升级为接触模式分段证书，但整条链的 soundness 现在 **同时押注“演示分布代表部署分布”与“MuJoCo 接触模式穷尽真实模式”**；一旦演示偏差让 OOD 检测漏检、或真实接触模式落在 M_known 之外，证书会在最需要它的接触边界处系统性乐观，故必须以 OOD 检测、覆盖引导证伪、真机锚点三重护栏守住 **“无覆盖不认证、无模式不部署”** 的底线。

## 2. 关键算法 伪代码

### IP-121 CDP

```python
def coverage_profile(demos, k=32, beta_min=0.1, delta_conf=0.05):
    pts = [a for _, a in demos]
    kdt = KDTree(pts)
    beta_minus = {}
    slack = dkw_slack(n=len(pts), delta=delta_conf)
    for a in action_grid:
        d, _ = kdt.query(a, k)
        mu_hat = k / (len(pts) * volume_ball(d[-1], dim=len(a)))
        beta_minus[a] = max(0.0, mu_hat - slack)      # 单边保守
    T_beta = {a for a, v in beta_minus.items() if v >= beta_min}
    return beta_minus, T_beta

def profile_bounds(rollouts_pos, rollouts_neg, T_beta, theta_cov, conf=0.95):
    alpha_minus, alpha_plus = {}, {}
    for a in action_grid:
        if a not in T_beta:
            alpha_minus[a], alpha_plus[a] = 0.0, 1.0   # OOD 强制悲观
            continue
        lo, hi = clopper_pearson(count_ok(rollouts_pos, a),
                                 count_all(rollouts_pos, a), conf)
        alpha_minus[a], alpha_plus[a] = lo, hi
    return alpha_minus, alpha_plus
```

```python
def build_coverage_graph(skills, theta_a, v_min, Theta_Gamma, K):
    G = nx.DiGraph()
    for s1 in skills:
        for s2 in skills:
            if s1 is s2: continue
            C_int = s1.C_S & s2.C_S
            compat = vol(C_int) / max(vol(s1.C_S | s2.C_S), eps)
            Gamma = max(s1.Gamma_S, s2.Gamma_S)
            if compat >= theta_a and vol(C_int) >= v_min and Gamma <= Theta_Gamma:
                G.add_edge(s1.id, s2.id, compat=compat, C_inter=C_int,
                           rho=compose_robustness(s1.rho, s2.rho, K))
    return G
```

```python
def coverage_guided_falsify(pi, env, C_S, budget):
    C_S, failures = set(C_S), []
    for _ in range(budget):
        a = acquire(boundary(C_S), strategy='max_uncertainty')
        ok, info = mujoco_rollout(pi, env, a)
        if not ok:
            failures.append((a, info.mode))
            C_S -= neighborhood(a, radius=info.impact_radius)
        else:
            C_S |= neighborhood(a, radius=info.safe_radius)
    return C_S, failures
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CDP | O(N log N + |A| log N) | O(N+|A|) | DKW/Conformal 下界有效，覆盖 ≥ 1-δ_conf |
| ILS | O(N·T + |A|·|M|) | O(N+|A|) | 覆盖夹逼、OOD 可判定 |
| CGC | O(|S|²·|C|) | O(|S|²+|E|) | 只走可认证域，路径在 LCB 下 sound |
| CMC | O(|M|·T·|A|) | O(|M|+|A|) | 模式分段完备，跨模式冲量有界 |
| CGF | O(b·(T+log|A|)) | O(|A|) | 边界采样收敛，负例回写单调收缩 |
| SJC | O(|S|·|C|+|𝔇_ρ|) | O(|C|) | 证书合并 sound，Γ/J/δ_a 预算闭合 |

**正确性定理（Coverage-Certified Imitation Composition Soundness）**
假设第 54 轮 (A22)-(A28) 中与云边映射相关的部分保留；本轮新增 **(A29)** 演示与部署同分布或 OOD 检测无漏检；**(A30)** MuJoCo 接触模式划分覆盖部署模式集合；**(A31)** 模式内 `L_m`-Lipschitz 且跨模式冲量 `≤ J_max`；**(A32)** 覆盖下界满足 `δ_conf` 置信度。
则部署成功概率：
```
P_success ≥ 1 - ε_cov - δ_conf - β_mode - Σ_d(1-ρ_min(d)) - P(Γ_S>Θ_Γ) - P(δ_a>Θ_a)
```
关键：**组合前先验可认证域交集**，**跨接触模式冲量有界**，**覆盖下界单边保守**，从而把第 54 轮“动作可对齐假象”从根上压掉。
