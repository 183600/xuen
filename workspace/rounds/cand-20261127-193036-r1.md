## 1. 直觉与动机（两个灵感的碰撞）

### 灵感 1（ROS2）：ROS2 不是提交接口，是实验室里那台「缺失的力传感器」

直觉：看到 ROS2，第一反应是把策略包成 ROS2 节点。但 F20 说评测器只认 websocket/msgpack 的 PolicyService；把 ROS2 塞进 66ms 的计分路径，等于花 DDS 发现、序列化、daemon 的钱，买评测器看不见的东西。ROS2 真正值钱的是它暴露了**接口故意剥掉的那一层**：G1 低层的 `tau_est`（估计外力矩）、`dq/ddq`、`kp/kd/tau` 指令，以及 tf2/rosbag2/QoS 带来的同步、回放、延迟注入能力（F22–F24）。换句话说，**评测接口把力觉拿走了，ROS2 把它还给了实验室**。正确姿势是双平面：

- **计分面（data plane）**：纯 Python PolicyService，外部 schema 冻结，不 import ROS2，确定性优先；
- **实验面（control plane）**：ROS2/CycloneDDS 只用于采集、低层变阻抗示教、TF2 标定、rosbag2 回放、QoS 延迟注入；
- 两面通过版本化 schema 相接，力觉在实验面被蒸馏成模型权重或纯 Python guard，**绝不作为推理输入**。

核心反直觉点：**ROS2 放进计分路径是负优化；把 ROS2 的力觉可观测性蒸馏进计分面才是正收益。**

### 灵感 2（柔顺控制）：没有力反馈时，柔顺不是控制器，是「会退让的轨迹」

直觉：经典柔顺控制（阻抗/导纳）需要力/力矩闭环，至少需要 `tau` 或 F/T 传感器；F21 说评测接口只有位置目标，F22 说力觉只在实验室。因此**主动柔顺在计分面上不可直接实现**。但柔顺的本质不是「力控环」，而是「接触时不要硬顶」：接近慢、接触软、受阻退、滑移停。这些都可以在**动作块（action chunk）层面**用轨迹整形实现：

1. **跟踪误差即伪力**：我们命令 `q_cmd`，观测到 `q_obs`；接触受阻时 `e = q_cmd - q_obs` 会在运动方向上持续增大。这个误差不需要额外传感器，是接口免费给的接触信号。
2. **虚拟导纳**：不直接命令 `q_goal`，而是命令 `q_cmd = q_obs + α(q_goal - q_obs)`；α 小则软、α 大则硬。受阻时 `q_obs` 停住，`q_cmd` 自然不再前进——这是一个**位置接口上的「被动退让」**。
3. **相位化动作块**：把接触任务分成 APPROACH / ALIGN / CONTACT / INSERT / MANIPULATE / RELEASE / RETREAT；每个相位用不同的速度/加速度/α/能量预算；`T_a` 固定（F20），但块内轨迹内容可变。
4. **力觉蒸馏**：实验室用 `tau_est` / 变阻抗示教 / Isaac Lab 接触真值，给示教打上「接触相位 + 力 profile + 柔顺参数」标签；训练一个辅助头，让策略从视觉+本体感觉**预测接触相位**。推理时没有力，但策略「见过」力对应的视觉/运动模式。

核心反直觉点：**在位置接口上，最好的柔顺不是「加一个力控器」，而是「把力觉蒸馏成视觉-本体先验，再用跟踪误差在块边界退让」——柔顺是学出来的轨迹纪律，不是算出来的力矩。**

### 三者统一（ROS2 × 柔顺 × 现有清单）

- ROS2 回答「力觉从哪来」：实验面的 `tau_est`、变阻抗示教、Isaac Lab 接触真值；
- 柔顺回答「接触任务怎么做」：相位化轨迹 + 虚拟导纳 + 跟踪误差退让 + 力觉蒸馏；
- 现有数据引擎（I2/I5）回答「怎么把力觉变成数据」：把接触相位/力 profile 作为示教标签，把「卡住→退→重试」合成成恢复示教；
- 现有部署（I6/I8）回答「怎么在预算内验证」：ROS2 回放做 L0，真机只做 L2。

本轮结论：**接触任务的胜负手不在「有没有力传感器」，而在「能不能把实验室的力觉蒸馏成计分面的视觉-运动先验，并用跟踪误差在动作块边界学会退让」。**

## 2. 对前两轮痛点的增量修订

- P4（无触觉）从「不可解」降级为「可蒸馏」：力觉在实验面存在（F22），只是不能作为推理输入；I10 用蒸馏、I11 用跟踪误差，两条路径都不要求评测时有力。
- P5（时间压力）补充：`T_a` 固定（F20）意味着「自适应 chunk 长度」在接口层不成立；改为「固定 T_a、相位化块内容」，并把 T_a 的选择做成 L0 实验（2/4/8/16）。
- P6（延迟）升级：接触任务需要更小的 T_a 才够反应；但小 T_a 增加调用频率，必须用 p99 延迟和推理预热共同定档。
- P8（示教质量）补充：接触段的质量不能只看进度，还要看「力 profile 是否平滑、有无冲击、有无卡死」；ROS2 的 `tau_est` 给质量分增加一个接触维度。
- 新增 P9（力觉不可部署）：任何依赖力/触觉的方案，若不能在推理时用视觉/本体感觉替代，直接淘汰。
- 新增 P10（跟踪误差歧义）：`e = q_cmd - q_obs` 也受延迟、重力、摩擦影响；误判接触会导致策略变怂、分数下降。
- 新增 P11（ROS2 实验面成本）：低层 debug 模式、时间同步、bag 体积、sim-to-real 都是真实成本；实验面不能拖慢计分面。
- 新增 P12（单模型边界）：I11 的 guard 是动作后处理还是「第二个模型」，需要书面确认；若不允许，降级为训练时辅助监督。

## 4. 设计原则（新增 PR6–PR9，其余保留）

- **PR6 双平面纪律**：ROS2 只住实验面；计分面是纯 Python PolicyService，运行时禁止 import ROS2。任何实验面信号必须蒸馏成权重或纯 Python guard 后才能过闸。
- **PR7 力觉蒸馏律**：力/力矩只能当训练时老师，不能当推理时输入；每个力标签必须配一个视觉/本体代理，否则视为不可部署。
- **PR8 跟踪误差优先律**：无力反馈时，第一接触信号是 `q_cmd - q_obs`；视觉滑移是第二信号；脚本化接触检测是最后手段。逐任务校准 + 滞回 + 退让。
- **PR9 能量预算律**：每条接触轨迹必须有有界的命令位移预算 `B` 和退让规则；在低层力矩限幅 `τ_max` 已知时，注入能量上界 `E ≤ F_max B`。这不是无源性证明，是可审计的安全预算。
- PR1–PR5 保留（第 2 轮 §4）。

## 6. 本轮最大风险

**一句话**：整轮方案押在「位置接口的跟踪误差足以当接触信号」——如果 `e = q_cmd - q_obs` 被延迟、重力、摩擦淹没（TECO 的接触 AUROC < 0.7），I11 会从「柔顺」退化成「变怂」，接触任务分数反而下降；因此 I11 必须先过 L0 的 AUROC/误报闸，I10 的力觉蒸馏只作为增强而非前提，任何一项不达标就退回 I3 的关键点伺服。

## 0. 核心决策：ROS2 是实验面的显微镜，柔顺是计分面的轨迹纪律

| 层 | 能做什么 | 不能做什么 | 本轮落点 |

### 0.1 四个柔顺概念（先分清，再设计）

## 1. 创新点清单

- **与现有方案差异**：不是「伺服到底」，而是「伺服对齐 + 柔顺接触」；不是「脚本恢复原语」，而是「跟踪误差触发的块边界退让」。
- **可行性**：高；纯 Python，无需新传感器。
- **资源**：1 人周工程 + L0 回放。
- **落地**：①在 3 个接触任务上采集 `q_cmd/q_obs` 对；②标定 TECO 阈值；③接入关键点伺服；④L0/L2 A/B。
- **风险**：误判接触导致变怂；缓解：滞回 + 只在接触相位激活 + 视觉确认 + 5% 标称退步即回滚。
- **I3' 降级预案**：若「混合推理」被裁定违规，改为训练时辅助监督（关键点/接触相位作辅助标签），推理纯端到端；I11 的 guard 若也被视为多模型，则同样降级为训练时动作平滑目标。

### I4 人手干预感知门控 + 固定 T_a 的块内容调度 ★★★★（修正）

### I10 ROS2 力觉蒸馏数据引擎（新） ★★★★★

### I11 跟踪误差伪力 + 虚拟导纳柔顺壳（新） ★★★★★
- **动机**：评测只有位置目标与位置观测（F21），但 `q_cmd - q_obs` 是免费的接触信号；接触受阻时误差在运动方向持续增大。无需力传感器、无需改接口。
- **方法**：
  1. **块时序对齐**：评测器可能在 chunk 内任意步调用；用观测 `q_obs` 与上一块 `q_cmd[0..T_a-1]` 做最近邻匹配，估计执行索引 `k`，取 `e = q_cmd[k] - q_obs`。
  2. **接触分数**：`c_t = σ(β_0 + β_1||e|| + β_2 cos(e, v) + β_3||Δe|| + β_4 s_t)`，`v` 为观测速度（历史栈差分），`s_t` 为视觉滑移；逐任务校准，滞回。
  3. **虚拟导纳**：`q_cmd[k] = q_obs + α_k (q_goal[k] - q_obs)`，`α_k = α(φ_t, c_t) · ramp(k)`；接触时 α 降到 0.1–0.2，退让时 α<0 或直接 hold/retreat。
  4. **能量预算**：`B = Σ||q_cmd[k+1]-q_cmd[k]||`；`E ≤ F_max B`，`F_max` 由关节力矩限幅与雅可比保守估计；`B > B_max` 或 `c_t > τ_retreat` 持续 `N_hold` 步 → 退让并重新接近。
  5. **相位化**：APPROACH（快）/ALIGN（慢）/CONTACT（很慢，小步）/INSERT（微步，力预算）/RELEASE（松）/RETREAT（退）。
  6. **接触搜索（可选）**：INSERT 相位若 `c_t` 高且进度头不增，执行有界螺旋/抖动搜索（幅度由能量预算约束），找到孔位后再插入。
- **与现有方案差异**：经典柔顺要力控环；本点是「位置接口上的行为柔顺」——用跟踪误差当伪力，用块边界退让代替 1kHz 阻抗环。零新传感器、零接口改动。
- **可行性**：高；纯 Python；但接触信号可靠性是最大不确定性。
- **资源**：1 人周；L0 回放免费。
- **落地**：①在 3 个接触任务上记录 `q_cmd/q_obs`；②算 AUROC；③标定阈值/α/预算；④接入 I3；⑤L0/L2 A/B。
- **风险**：跟踪误差被延迟/重力/摩擦淹没；误判导致变怂。缓解：逐任务基线扣除、方向性判据、视觉确认、滞回、kill criterion（AUROC<0.7 或标称退步>5% 即关闭）。
- **单模型边界**：guard 是动作后处理，不引入第二个策略；若组委会视为多模型，降级为训练时动作平滑/接触相位辅助监督。

### I12 ROS2 接触回放实验台（新） ★★★★
- **动机**：接触实验真机贵、不可重复；ROS2 的 bag/tf2/QoS 可以把「同一观测流 + 不同 checkpoint/guard 参数」变成可重复 L0。
- **方法**：
  1. **采集**：rosbag2 记录 4 相机 + `/lowstate` + `/lowcmd` + `/tf` + 接触标签；
  2. **回放**：`use_sim_time` + tf2 静态/动态变换；websocket 桥接模拟 PolicyService；QoS 注入 p50/p99 延迟、抖动、丢包；
  3. **重仿**：对接触段用 Isaac Lab 从记录初始状态重仿动作，得到接触力/滑移真值；开环观测回放只用于非接触段；
  4. **指标**：TECO AUROC、接触起始延迟、冲击速度、滑移率、能量预算、成功率、步骤分代理；
  5. **注册表**：结果写入 I8，滚动校准「离线接触指标 → 真机增益」。
- **与现有方案差异**：v1.1 的 L0 是视觉增广；本点增加「接触动力学回放」，让接触策略也能离线消融。
- **可行性**：中-高；ROS2 + Isaac Lab 工程量大，但都是现成组件。
- **资源**：1 台工作站 + 1×A100（可选）；2 人周。
- **风险**：开环回放接触动力学失真；缓解：sim-in-the-loop + 真机小样本校准；只把回放用于相对排序，不用于绝对分数承诺。

### 2.2 跟踪误差伪力 + 虚拟导纳（I11）

```python
class ComplianceGuard:
    def __init__(self, cfg):
        self.cfg = cfg
        self.prev_q = None
        self.prev_cmd = None
        self.prev_e = None
        self.c = 0.0

    def align(self, q_obs, cmd_chunk):
        # 评测器可能在 chunk 内提前调用：用最近邻估计已执行到第 k 步
        d = np.linalg.norm(cmd_chunk - q_obs[None, :], axis=1)
        return int(np.argmin(d))

    def contact_score(self, e, v, slip):
        z = (self.cfg.b0 + self.cfg.b1 * np.linalg.norm(e)
             + self.cfg.b2 * cos(e, v)
             + self.cfg.b3 * np.linalg.norm(e - self.prev_e)
             + self.cfg.b4 * slip)
        return 1.0 / (1.0 + np.exp(-z))

    def __call__(self, obs, goal_chunk, phase):
        q = obs["observation.state.left_arm"].astype(np.float32)
        if self.prev_cmd is None:
            self.prev_q, self.prev_cmd = q, goal_chunk
            self.prev_e = np.zeros_like(q)
            return goal_chunk
        k = self.align(q, self.prev_cmd)
        e = self.prev_cmd[k] - q
        v = q - self.prev_q
        slip = visual_slip(obs)                       # 0..1，第二信号
        self.c = self.contact_score(e, v, slip)
        alpha = self.alpha(phase, self.c)             # 接触时降到 0.1–0.2
        cmd = q[None, :] + alpha * (goal_chunk - q[None, :])
        cmd = limit_vel_acc(cmd, phase, self.cfg)
        if self.c > self.cfg.retreat_th and phase in ("contact", "insert"):
            cmd = retreat(q, v, self.cfg)
        B = np.sum(np.linalg.norm(np.diff(cmd, axis=0), axis=1))
        if B > self.cfg.B_max(phase):
            cmd = hold(q, len(cmd))                    # 能量预算耗尽：停/退
        self.prev_q, self.prev_cmd, self.prev_e = q, cmd, e
        return cmd
```

### 2.5 能量预算（PR9）

```python
def energy_bound(cmd, tau_max, J):
    # 保守：F_max = ||J^{-T} tau_max||，B = 命令位移总长
    F_max = np.linalg.norm(np.linalg.pinv(J).T @ tau_max)
    B = np.sum(np.linalg.norm(np.diff(cmd, axis=0), axis=1))
    return F_max * B          # 条件性能量上界，不是无源性证明
```

## 3. 实验设计（接触感知分级消融 v3）

| 级别 | 内容 | 通道/成本 | 通过判据 |
|---|---|---|---|
| E0 | 接口审计：记录 `q_cmd/q_obs`，验证时序对齐与跟踪误差可观测 | 本地 stub / 单任务 | 对齐误差 < 1 步；误差信号非零 |
| E1 | ROS2 力标签：`tau_est` vs. F/T 或 Isaac Lab 真值；接触相位 AUROC | 实验面 | AUROC ≥ 0.8；标签延迟 < 1 帧 |
| E2 | TECO 校准：接触起始 AUROC、误报率、方向性判据 | 离线 L0 | AUROC ≥ 0.7；标称误报 < 5% |
| E3 | VAF 参数：α、v_max、a_max、retreat_th、B_max 的 L0/L1 扫描 | 离线 + sim | 接触成功率 ↑，标称分数不降 > 2% |
| E4 | `T_a` 扫描：{2,4,8,16}；成功率 vs. p99 延迟 | L0/L1 | 选 p99 < 150ms 下成功率最高者 |
| E5 | F2VD 消融：有/无相位/力辅助头；有/无变阻抗示教 | L1/L2 | 接触任务增益 > I3 基线；无家族退步 |
| E6 | 真机 A/B：3 任务（PlugCharger/PlugInEthernet/PourOutMedicine）× 2 次 | L2 | 成功率/步骤分 ≥ I3 基线；冲击速度 ↓ |
| 门禁 | PR4 + 接触安全：0 越界、0 超预算、p99 < 150ms、退让可恢复 | 本地 + 回放 | 全通过 |

**Kill criteria（先写死，防止自欺）**：

- TECO 接触 AUROC < 0.7，或标称任务分数下降 > 5% → 关闭 I11，退回 I3 关键点伺服；
- I10 的力标签与 F/T/sim 真值相关性 < 0.5 → 只保留视觉接触分类器，不做力回归；
- I12 回放与真机排序的 Spearman < 0.5 → 回放只做定性筛选，不替代 L2；
- `T_a=4` 下 p99 > 150ms → 升到 `T_a=8` 或减模型/量化。

## 5. 伦理合规 checklist（更新）

- [ ] **ROS2 不进计分面**：提交包运行时禁止 import rclpy/ROS2；只允许纯 Python PolicyService + 模型权重。
- [ ] **力觉只做训练**：I10 的 `tau_est`/F/T/sim 接触真值不得作为 `get_action` 输入；推理只用 RGB/关节状态/EE/夹爪/语言。
- [ ] **单模型边界**：I11 guard 是动作后处理，不是第二个策略；I3' 降级预案备好；向组委会书面确认「动作后处理 guard」是否合规。
- [ ] **不在线学习**：I11 的阈值/α 在赛前固定；评测期不更新权重、不拟合评测分布。
- [ ] **安全预算**：接触轨迹必须有位移/速度/加速度上限与退让规则；真机测试在人监督下进行。
- [ ] **数据许可**：官方数据集 + 实验室自有数据；共训注明来源；`tau_est` 数据不对外泄露机器人敏感信息。
- [ ] **可重放**：每个真机结果附 `(bag, checkpoint, config, seed)`；不可重放的结果按 0 计。

## 7. 本轮最值得押注（一句话）

**押「力觉蒸馏 + 跟踪误差柔顺壳」：I10 把 ROS2 实验面的 `tau_est`/变阻抗示教/Isaac Lab 接触真值蒸馏成视觉-本体接触先验，I11 用 `q_cmd - q_obs` 在计分面上做无传感器接触推断与块边界退让，I12 用 ROS2 回放把接触实验变成可重复的 L0——不改接口、不加传感器、不违反单模型边界，把接触任务从「硬碰硬」变成「会退让」。**
