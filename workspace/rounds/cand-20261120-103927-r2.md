# 第 2 轮（新灵感循环第 2 轮；本轮灵感：「社会规范理解」×「场景理解」）

> **基线**：第 14 轮 MetricVoiceGauge-NCD-HUTDH-v16（定义 627–656；引理 131–136；实验 E671–E690）。
> 本轮纪律：**场景为证、规范为约、物理为底**。不推倒 v16：v16 的 BTS/TRM/WBC/CSC/NCS/MCA/WCB、v15 的 SCD/DSD/DCA/EDC、v13 的 AIO/RTIC/CPD/DGC/DDL/RTCR、v14 的 SCD/DSD/DCA/EDC、v12 的 USG/TGC/BAA/GAGP/UC、v11 的 HAS/HCC/HATD/HDT、v10 的 NGE/DSL/CC/CWM/CAE/NCP、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 与历轮不变式全部保留。两个新组件——SGCB（场景图接地证书绑定器）、SNCL（社会规范证书库与可废止推理器）——以**中立元**接入，失效即严格退回 v16（引理 140），再沿 v16→v15→…→v6 退化链退回。本轮只做三件事：把“场景理解”改写为**带接地证书的信念集**、把“社会规范”改写为**可废止的规范证书与优先级格**、把“场景—规范—物理”改写为**非对称接地的联合证书**。

## 0. 直觉与动机

**灵感 1（场景理解 → 场景不是事实，是带接地证书的信念集）**
直觉：v16 的所有证书（NC/MC/WBC）都默认输入状态 `x` 是可信的。但机器人在人群中看到的是**推断**：那是人还是柱子？他会不会往左走？这块地能不能踩？场景理解输出的从来不是真值，而是一个**可能世界的集合**——遮挡、分布外、长尾语义都让“看到的场景”与“真实场景”存在缝隙。核心创新：**可信场景信念（Credal Scene Belief, CSB）+ 接地证书（Grounding Certificate, GC）**。把感知输出形式化为一个**信念集** `B_ε(x) = {G_1, …, G_m}`（若干候选场景图），并保证真实场景 `G*` 以概率 ≥ `1−α_sn` 落在其中。每个语义命题 φ（“左前方有一名行人”“这是医院走廊”“该物体可供抓取”）携带接地证书 `GC(φ|x) = [l_φ, u_φ]`：在校准集上可证的 `P(φ|x)` 置信区间。关键反直觉点：**场景理解的正确用法不是“选一个最可能的场景图”，而是“在所有可能的场景图上保守地做证书运算”**——因为规范是否适用取决于场景语义，而场景语义本身是概率的。

**灵感 2（社会规范理解 → 规范是可废止的、有优先级的、有时序的）**
直觉：社会规范不是硬约束。“不要进入他人个人空间”会让位于“避免撞到正在跌倒的人”；“靠右行走”会让位于“前方有人逆行”；“不要打断”会让位于“紧急呼救”。规范是**可废止（defeasible）**的：默认成立，遇到更高优先级的规范或例外情形即被击败。规范还是**关系性**的（取决于角色：行人/护士/儿童）、**上下文性**的（医院 vs 仓库 vs 街道）、**时序性**的（先让行、再通行、后致意）。核心创新：**社会规范证书（Social Norm Certificate, SNC）+ 优先级格 + 可废止推理器（Defeasible Norm Reasoner, DNR）**。每条规范 `n` 携带 `SNC_n = (φ_n 适用条件, ψ_n 要求/禁止, π_n 优先级, δ_n 违反度量, M_n 时序监控器)`。规范激活不是布尔判断，而是**在信念集上做保守推理**：对禁止性规范用“可能适用”（`sup` over `B_ε`），对义务性规范用“必然适用”（`inf` over `B_ε`）——**非对称接地**。关键反直觉点：**禁止要“宁可错杀”（信念越宽 ⇒ 禁止越多），义务要“宁可漏判”（信念越窄 ⇒ 义务越少）**；这个非对称性是社会规范安全性的根基，也是它与物理证书单调性纪律的根本冲突。

**灵感 3（场景 × 规范 × 物理 → 联合证书与接地—物理分歧）**
直觉：v16 的物理证书在**相信的几何**上成立，v17 的规范证书在**相信的语义**上成立。两者可能同时成立而真实场景仍危险：一个人被沙发遮挡，几何上通道可过（物理 NC 通过），语义上“人”未被接地（安全禁止未激活），于是机器人礼貌、流畅、物理可行地走进了真实存在的个人空间。核心创新：**场景—规范联合证书（Joint Scene-Norm Certificate, JSNC）+ 感知缝隙安全界（Perception-Gap Safety Bound, PGSB）**。`JNC = 物理 NC ⊓ 规范证书 ⊓ 上下文证书 ⊓ 接地可靠性`，只收紧不扩张。PGSB 把“未观测区域/遮挡/分布外”显式折算为接地半径的惩罚，使安全类禁止在遮挡下保持激活。关键反直觉点：**“规范没被违反”与“规范被满足”是两回事**——前者可能只是因为规范从未被激活；v17 要防的不是显式违规，而是**因未接地而从未激活的规范**。

**三者如何统一**
统一为 **v16 全身行为层之上的社会—场景层**：v16 回答“在当前里程碑与动力学阶层下能安全执行哪个全身行为”（`Exec_v16`），v17 回答“在带接地证书的场景信念下、按可废止规范优先级、该行为是否社会可接受”（`Exec_v17`）。SGCB 把场景图变成带 GC 的信念集；SNCL/DNR 把规范变成带优先级的可废止证书；AGA 用非对称接地把语义不确定性折成禁止/义务激活；NTM 把让行/等待写成时序监控器并接入 BTS 的 Running 语义；CCC 用上下文证书切换规范体制；JSNC 把物理、规范、上下文、接地四者合取；PGSB 把遮挡与分布外折算成安全禁止的保守激活。共享状态 `ζ_sn = (B_ε, c*, N_active, q_NTM, GC_stack, δ_soft, mode_sn)`。**SGCB 回答“我相信看到了什么”，DNR 回答“哪些规范因此生效”，AGA 回答“在不确定下该保守到哪一步”，JSNC 回答“这一帧物理与社会是否同时可接受”**。四者不是四个补丁，而是“感知—规范—物理—调度”的社会化实现链。

## 1. 研究问题（轮次升级版）

- **Q1（场景接地证书的可靠性）**：如何构造信念集 `B_ε` 与接地证书 `GC`，使 `P(G* ∈ B_ε) ≥ 1−α_sn` 在分布外/遮挡/长尾语义下仍成立？场景图的节点、边、可供性、关系分别如何接地？如何避免“信念集过大导致规范全部激活、机器人冻结”？
- **Q2（可废止规范的激活与冲突）**：如何用非对称接地定义禁止/义务的激活？优先级格如何保证冲突消解终止、唯一、无环？安全规范与礼仪规范冲突时，如何用“最小违反”语义而不是硬失败？
- **Q3（规范时序与 BTS Running 的对齐）**：让行/等待/致意等时序规范如何写成自动机？义务未履行时 Running 的语义是什么？等待超时（waiver）如何在不死锁的前提下给出有界违反？
- **Q4（接地—物理分歧与上下文切换）**：JSNC 如何在不扩张 v16 的前提下合成四类证书？PGSB 如何在遮挡下保持安全禁止激活？上下文误分类如何界定规范体制缝隙？全失效时能否严格退回 v16？

## 2. 设计原则（在 P25–P27 基础上新增 P28–P30）

**P28 场景接地即证书前提律（Scene Grounding as Certificate Premise）**
任何规范的适用性判断都必须携带接地证书 `GC(φ_n | x)`；没有校准下界的语义谓词不得激活规范。禁止性规范用**可能适用**（`ProhibitionActive(n,x) ⇔ sup_{G∈B_ε(x)} φ_n(G) ≥ τ`），义务性规范用**必然适用**（`ObligationActive(n,x) ⇔ inf_{G∈B_ε(x)} φ_n(G) ≥ τ`）。**非对称接地**保证：禁止不会漏激活，义务不会误激活。

**P29 规范可废止与优先级格律（Defeasible Norms with Priority Lattice）**
规范库 `N` 携带严格偏序 `≻`（安全 ≻ 法规 ≻ 社会习俗 ≻ 礼仪 ≻ 偏好），每个上下文 `c` 下的冲突消解按字典序进行，高优先级禁止击败低优先级义务。消解必须是**终止、唯一、无环**的；被击败的规范进入 `Defeated` 集并记录 `δ_n`。任何规范不得通过组合新增授权。

**P30 场景—规范联合收紧律（Joint Scene-Norm Tightening）**
`JNC_n = NC_n ⊓ SNC_n ⊓ CtxCert ⊓ GroundCert`，其中 `⊓` 只做交集/收紧，任何分量缺失时退化为该分量的中立元（`⊤`）。规范时序监控器未放电（undischarged）时，BTS 的 `Post` 不得成立，`status` 只能是 `RUNNING`；监控器超时则以有界违反 `δ_n ≤ δ_max` 放行并记录。`Exec_v17 ⊆ Exec_v16`。

## 3. 与基线的接口（如何退化）

- SGCB 失效 ⇒ 场景信念退化为单一“最大似然场景图”中立元，接地证书退化为 v16 的原始几何输入，**等价 v16 路径**（但失去分布外保护）；
- SNCL/DNR 失效 ⇒ 只保留**普遍安全规范**（与场景语义无关的硬禁止：不碰撞、不夹人），社会习俗/礼仪全部退化为 `⊤`，**等价 v16（+SGCB）路径**；
- AGA 失效 ⇒ 对称接地（禁止/义务都用点估计），禁止可能漏激活，**等价 v16 + 点估计规范**；
- NTM 失效 ⇒ 时序规范退化为瞬时规范，Running 语义退回 v16，**等价 v16（+SGCB+SNCL）路径**；
- CCC 失效 ⇒ 单一上下文中立元（默认上下文），规范体制不切换，**等价 v16（+…）路径**；
- 全部失效 ⇒ MetricVoiceGauge-NCD-HUTDH-v16，再沿 v16→v15→v14→v13→v12→v11→v10→v9→v8→v7→v6 退化链退回；
- **安全继承**：JSNC 只做交集，规范只做禁止/义务约束，非对称接地只加保守性，NTM 只延迟 Post。四端口均不能新增授权或放宽阈值；`Exec_v17 ⊆ Exec_v16` 由引理 140 保证。

## 4. 预期贡献

1. **可信场景信念与接地证书**：把场景理解从“选一个场景图”改写为“在信念集上做证书运算”，给出节点/边/可供性/关系的接地证书与分布外覆盖保证；
2. **可废止规范证书与优先级格**：把社会规范从硬约束改写为带优先级、可击败、有时序的证书，给出激活—消解—违反度量的统一语义；
3. **非对称接地原理**：证明禁止用 may-appl、义务用 must-appl 是保守性的必要条件，并揭示它与物理证书单调性纪律的根本冲突（规范激活不具跨帧单调性）；
4. **接地—物理分歧的刻画与封堵**：用 PGSB 把遮挡/未观测/分布外折算成安全禁止的保守激活，给出“物理可行但规范未激活”这一新型失效模式的界；
5. **社会—场景—物理三层分离**：v12 管“允许什么”，v15 管“技能如何扩散”，v16 管“全身行为如何执行”，v17 管“行为在社会场景中是否可接受”，用 `Exec_v17 ⊆ Exec_v16 ⊆ Exec_v15 ⊆ …` 全解耦；E691–E710 覆盖接地可靠性、规范冲突、时序活性、上下文缝隙、接地—物理分歧、端到端与消融。

## 5. 本轮最大风险

**一句话**：v17 的社会安全性完全建立在场景接地之上，而物理证书只检查**相信的几何**——当遮挡、分布外或长尾语义让“人/儿童/轮椅”未被接地时，安全禁止从未被激活，机器人会执行一个物理可行、规范自洽、上下文正确、却在真实场景中侵犯个人空间或撞到弱势体的动作，即**“规范从未被激活，因而从未被违反”的假象下的规范灾难**。

## 1. 关键算法骨架

```python
# IP-416/417 Credal Scene Binder + Grounding Certificate Provider
class CredalSceneBinder:
    def __init__(self, scene_parser, calibrator, alpha_sn=0.05, k_cand=8):
        self.parser = scene_parser
        self.cal = calibrator
        self.alpha_sn = alpha_sn
        self.k = k_cand

    def bind(self, obs):
        """返回 (B_ε, GC)：信念集与逐命题接地证书"""
        candidates = self.parser.sample(obs, k=self.k)        # 候选场景图
        eps = self.cal.radius(self.alpha_sn)                  # 共形接地半径
        B = CredalSet(candidates, epsilon=eps)
        GC = GroundingCertificates(
            sup=lambda phi: max(phi(G) for G in B.candidates),
            inf=lambda phi: min(phi(G) for G in B.candidates),
            cal=self.cal,
        )
        # 覆盖自检：若校准集残差超限，扩大 ε（保守）
        if not self.cal.coverage_ok(B, self.alpha_sn):
            B = B.expand(self.cal.inflation(self.alpha_sn))
        return B, GC

# IP-419/420 Defeasible Norm Reasoner + Asymmetric Grounding
class DefeasibleNormReasoner:
    def __init__(self, library, tau=0.5, tau_occ=0.3, pgsb=None):
        self.lib = library
        self.tau = tau
        self.tau_occ = tau_occ
        self.pgsb = pgsb

    def active(self, B, GC, context, x):
        """非对称接地 + 优先级格消解"""
        A_proh, A_obl = [], []
        for n in self.lib.for_context(context):
            if n.type == 'Prohibition':
                # may-appl：可能适用即激活（含 PGSB 遮挡先验）
                if GC.sup(n.phi, B) >= self.tau or \
                   (self.pgsb and self.pgsb.occ_prior(n, x) >= self.tau_occ):
                    A_proh.append(n)
            elif n.type == 'Obligation':
                # must-appl：必然适用才激活（不引入虚假义务）
                if GC.inf(n.phi, B) >= self.tau:
                    A_obl.append(n)
        N_active, defeated = self.resolve(A_proh, A_obl)
        return N_active, defeated

    def resolve(self, proh, obl):
        """优先级格字典序消解；高优先级禁止击败低优先级义务"""
        active, defeated = list(proh) + list(obl), set()
        for p in proh:
            for o in obl:
                if self._conflicts(p, o):
                    hi, lo = (p, o) if self.lib.priority.strictly_precedes(p, o) \
                                     else (o, p)
                    defeated.add(lo)
        N_active = [n for n in active if n not in defeated]
        return N_active, defeated

    def _conflicts(self, p, o):
        return p.ctx == o.ctx and p.role == o.role and \
               p.action_scope.intersects(o.action_scope)


# IP-421 Norm Temporal Monitor
class NormTemporalMonitor:
    def __init__(self, delta_max=0.1):
        self.delta_max = delta_max
        self.q = {}                                  # {norm_id: state}

    def step(self, N_active, x, G):
        """推进所有激活规范的自动机；返回未放电义务与 waiver 记录"""
        pending, waivers = [], []
        for n in N_active:
            q = self.q.get(n.id, n.M.q0)
            q2, discharged, waited = n.M.step(q, x, G)
            self.q[n.id] = q2
            if n.type == 'Obligation' and not discharged:
                if waited > n.M.W_max:
                    self.q[n.id] = n.M.q0          # 有界 waiver
                    waivers.append((n.id, min(self.delta_max, n.delta)))
                    continue
                pending.append(n)
        return pending, waivers


# IP-422 Context Certificate Classifier
class ContextCertificateClassifier:
    def __init__(self, contexts, cal):
        self.contexts = contexts
        self.cal = cal

    def classify(self, x, B, GC):
        scores = {c: GC.sup(lambda G: G.context == c, B) for c in self.contexts}
        c_hat = max(scores, key=scores.get)
        cert = CtxCert(c=c_hat, lower=scores[c_hat],
                       gap=self.cal.regime_gap(c_hat, scores))
        return c_hat, cert


# IP-423 Joint Scene-Norm Certificate Synthesizer
class JointSceneNormCertificate:
    def __init__(self, nc_synth, dnr, ntm, ccc, pgsb):
        self.nc_synth, self.dnr, self.ntm = nc_synth, dnr, ntm
        self.ccc, self.pgsb = ccc, pgsb

    def synthesize(self, node, x, m_star, h_star):
        nc = self.nc_synth.synthesize(node, x, m_star, h_star)   # v16 物理 NC
        B, GC = self.pgsb.binder.bind(x)
        c_star, ctx_cert = self.ccc.classify(x, B, GC)
        N_active, defeated = self.dnr.active(B, GC, c_star, x)
        snc = self._norm_certificate(N_active, x, B, GC)
        pgsb_env = self.pgsb.bound(B, GC, x, N_active)

        # 只收紧：四路交集；任何一路缺失取 ⊤
        pre  = nc.Pre  & snc.Pre  & ctx_cert.pre  & pgsb_env.pre
        run  = nc.Run  & snc.Run  & pgsb_env.run
        post = nc.Post & snc.Post & pgsb_env.post
        # 回退必须仍物理安全且满足社会前置；空则物理回退优先
        fb = (nc.Fallback & snc.Pre) or nc.Fallback

        # 未放电义务：Post 不成立，强制 RUNNING
        pending, waivers = self.ntm.step(N_active, x, B.candidates[0])
        status_hint = 'RUNNING' if pending else None
        return JNC(pre, run, post, fb, N_active, defeated,
                   c_star, ctx_cert, status_hint, waivers)


# IP-424 Perception-Gap Safety Bound
class PerceptionGapSafetyBound:
    def __init__(self, binder, rho_safe=0.99):
        self.binder = binder
        self.rho_safe = rho_safe

    def occ_prior(self, norm, x):
        """安全禁止在遮挡/未观测区域的保守先验"""
        r = norm.region
        cov = self.binder.coverage(x, r)             # 该区域接地覆盖率
        return max(self.rho_safe * (1 - cov), 1 - cov)

    def bound(self, B, GC, x, N_active):
        """把未观测质量折算为安全证书的收紧"""
        occ = self.binder.unobserved_mass(B, x)
        hard = min((1 - n.delta) for n in N_active
                   if n.type == 'Prohibition' and n.is_safety)
        return SafetyEnvelope(pre=hard >= 0.5, run=True,
                              post=(occ <= self.rho_safe))
```

## 2. 推导

**引理 137（接地证书的可靠性）** 设校准保证 `P(G* ∈ B_ε(x)) ≥ 1−α_sn`。对禁止性规范 n，若 `ProhibitionActive(n,x)` 为假（即 `∀G∈B_ε, ¬φ_n(G)`），则 `P(φ_n(G*)) ≤ α_sn`；对义务性规范 n，若 `ObligationActive(n,x)` 为真（即 `∀G∈B_ε, φ_n(G)`），则 `P(φ_n(G*)) ≥ 1−α_sn`。证明：`{G* ∉ B_ε}` 是 `{φ_n(G*) 与 B_ε 上判定不一致}` 的超集，其概率 ≤ α_sn。禁止与义务的判定方向分别取 `sup` 与 `inf`，故结论成立。∎ 推论：**“未激活的禁止”几乎必然在真实场景中也不成立**——禁止漏激活的概率被共形风险预算控制；但“已激活的禁止”可能是假阳性（保守代价）。

**引理 138（非对称接地的单向保守性与非单调性）** 设 `B_1 ⊆ B_2`。则 `ProhibitionActive` 关于信念集单调递增（`B_1` 下激活 ⇒ `B_2` 下激活），`ObligationActive` 关于信念集单调递减。故禁止激活对信息增加**不单调**：信息越多、信念集越窄，禁止可能被**合法地关闭**。证明：`sup` 在子集上不增、`inf` 在子集上不减。∎ 推论：**v16 的跨帧单调性纪律不能直接搬到规范层**；规范证书必须逐帧重建，不能声明“上一帧激活、这一帧必然激活”。这与引理 131 的中断单调性形成张力，也是 v17 必须每帧重算 `N_active` 的原因。

**引理 139（优先级格冲突消解的终止性与唯一性）** 若 `≻` 为有限规范集上的严格偏序（无环），且冲突消解按“高优先级禁止击败低优先级义务、同优先级取最小违反”的字典序进行，则消解在有限步终止，且对给定 `(A_proh, A_obl, ≻)` 返回唯一极大一致激活集 `N_active`。证明：有限偏序上的字典序极大元唯一；每次击败严格减少候选集，终止。∎ 推论：**规范冲突不需要求解 NP-hard 的最大一致子集**；只要优先级无环，消解是线性扫描加击败表。

**引理 140（联合证书不扩张性与中立元）** 对任意节点 n，`JNC_n ⊆ NC_n`，且当 `SNC≡⊤`、`CtxCert≡⊤`、`GroundCert≡⊤` 时 `JNC_n = NC_n`。因此 `Exec_v17 ⊆ Exec_v16`。证明：JNC 定义为四路交集；中立元与全集求交不变。时序监控器只阻止 `Post` 成立（将 SUCCESS 降为 RUNNING），不新增动作。∎ 推论：**规范层是纯收紧层**；失效时严格回到 v16，不存在“规范放宽了物理安全”的路径。

**引理 141（时序规范的有界活性）** 设每个义务规范的监控器带等待上限 `W_max` 与违反上限 `δ_max`。若某义务在 `W_max` 内未放电，则触发 waiver：以 `δ_n ≤ δ_max` 的违反放行动作，监控器复位。则在任意有限 tick 预算内，系统不会因“无限等待让行”而死锁，且累计规范违反满足 `Σ δ_n ≤ N_obl·δ_max`。证明：waiver 是唯一出口，且每次触发都把监控器复位到 `q0`，故等待时间有界；违反量由 `δ_max` 截断。∎ 推论：**活性以有界社会违约为代价**；`W_max` 是“礼貌”与“不死锁”的显式旋钮，不是隐含假设。

**引理 142（上下文误分类的规范体制缝隙界）** 设 `P(c* ∈ CtxCert) ≥ 1−α_c`。若分类器输出 `ĉ`，则真实上下文与 `ĉ` 的期望体制缝隙满足 `E[D(c*, ĉ)] ≤ α_c + (1−α_c)·D(ĉ, c*)`。证明：以 `c* ∈ CtxCert` 为条件展开，落在外时体制距离有界 1，落在内时由 `D` 控制。∎ 推论：**上下文证书必须进入 JNC**；仅靠场景对象识别不足以封堵“医院被当成仓库”的规范体制错误。

**引理 143（接地—物理分歧的存在性与界）** 存在场景使物理 `NC` 通过而安全禁止未接地：被遮挡的人不在 `B_ε` 的可见对象集中，`φ_safety` 的 `sup` 低于阈值，但几何通道仍可通行。此时 `Δ_gp = P(真实场景不安全 | NC 通过 ∧ JNC 通过) ≤ α_sn + (1−α_sn)·P(¬PGSB 激活 | 真实不安全)`。PGSB 的遮挡先验把后一项限制在未建模的分布外区域。证明：由引理 137，接地失败概率 ≤ α_sn；条件在接地成功但 PGSB 未激活时，剩余风险即未建模 OOD。∎ 推论：**收紧物理 NC 无法单独消除 Δ_gp**——物理 NC 在相信的几何上求值，必须由 PGSB 把“未观测”显式折算为安全禁止的保守激活。

**引理 144（规范层的累积保守性上界）** 设物理、规范、上下文、接地四层证书的可行集分别为 `F_p, F_s, F_c, F_g`，且各层独立收紧。则 `|JNC| ≥ 1 − Σ_i (1 − |F_i|)`（测度意义）。当任一层接近空集时，JNC 优先保留物理层与安全规范层，丢弃软规范（习俗/礼仪），从而避免“四层交到空”。证明：由容斥下界；丢弃软规范等价于把 `F_s` 松弛为安全子集。∎ 推论：**软规范必须可被选择性丢弃**，否则 v17 会因累积保守而退化为“只会站立不动”。

## 6. 已知风险与失效模式

1. **信念集覆盖在分布外失效**：共形预测依赖可交换性，真实部署的 OOD 场景（新家具、新服饰、儿童/轮椅长尾）会破坏 `P(G*∈B_ε) ≥ 1−α_sn`。缓解：OOD 检测器、拒绝式接地、分区域/分上下文校准、在线扩张 ε、主动学习补样。

2. **规范库的文化与标注偏差**：规范是文化相关的社会事实，标注者的默认假设会污染规范库（如“距离 1.2m 即礼貌”在拥挤地铁不成立）。缓解：上下文分库、文化参数显式化、众包分歧建模、规范来源可追溯。

3. **非对称接地的过度保守**：禁止用 may-appl 会把大量“可能有人”的区域判为禁行，导致机器人冻结或绕路。缓解：τ 校准、软硬规范分层、只在安全规范上做 may-appl、信念集剪枝。

4. **优先级格的主观性与冲突**：`≻` 由人工设定，跨文化/跨场景可能不成立，甚至出现“两个安全规范互斥”。缓解：安全规范内部用最小违反、优先级来源审计、冲突检测告警。

5. **时序规范的 waiver 滥用**：为保活性而频繁 waiver，会把“礼貌让行”退化为“抢行”。缓解：waiver 预算、频率上限、按场景调 W_max、waiver 计入长期社会信用。

6. **上下文误分类的体制缝隙**：医院走廊被识别为仓库，规范体制整体错位（引理 142 的界只在覆盖成立时有效）。缓解：上下文证书入 JNC、体制切换滞后、切换前双体制交集。

7. **遮挡安全先验过强**：ρ_safe 过高会让所有未观测区域都不可通行，机器人寸步难行。缓解：按任务风险分级 ρ_safe、可通行性证书、深度/触觉补充观测。

8. **接地—物理分歧的残余 OOD**：PGSB 只能覆盖“已建模的遮挡”，对对抗性伪装、反光、透明材质仍可能漏接地。缓解：多模态冗余、异常检测、保守速度限制、人在回路。

9. **开放世界长尾规范**：未见过的新规范（新场所规则、临时管制）不在库中，系统会“合法地无礼”。缓解：规范在线学习、自然语言规范注入、人类示范、默认保守行为。

10. **与 v16 证书栈的累积保守性**：物理+规范+上下文+接地四层交集可能清空可行集，使系统只会 Fallback。缓解：引理 144 的软规范丢弃、按价值加权而非纯交集、分层优先级。

11. **规范热更新导致证书失效**：在线更新规范库/优先级会使已验证的 JSNC 失效。缓解：规范版本控制、更新前回归（E704）、金丝雀发布、更新期间维持旧规范。

12. **多智能体规范互认失败**：机器人之间、人机之间的规范不一致（谁让谁、靠哪边），可能产生“都礼貌却互相堵死”。缓解：规范协商协议、共同优先级、社会契约层、冲突时降速停等。

## 7. 本轮最大风险

**一句话**：v17 的社会安全性完全建立在场景接地之上，而物理证书只检查**相信的几何**——当遮挡、分布外或长尾语义让“人/儿童/轮椅”未被接地时，安全禁止从未被激活，机器人会执行一个物理可行、规范自洽、上下文正确、却在真实场景中侵犯个人空间或撞到弱势体的动作，即**“规范从未被激活，因而从未被违反”的假象下的规范灾难**。
