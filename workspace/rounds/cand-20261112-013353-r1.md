# 第 58 轮（承接第 57 轮「少样本元推断×跨模态对账×个性化信任」IP-133~138；灵感循环第 1 轮；本轮灵感：「路径规划」×「安全性」）

> 第 57 轮把每个检查点的承诺做成"少样本可校准、跨模态可对账、个性化有界"的证据门，纵深已经很深；但它有一个未经审视的隐含假设：**安全可以逐点判定**——只要每一脚承诺前证据门通过，整条路线就安全。路径规划与安全性这对灵感恰好击穿这个假设：**(a) 局部安全不可组合**，一串各自"有证据支持"的接触可以把机器人送进没有安全续接的死角，撤退走廊本身被后续落脚点一步步吃掉；**(b) 概率相同不等于危害相同**，同一 δ_f 的滑移在平地只是踉跄，在悬崖边是不可逆坠落，只最小化失效率会系统性偏好"低概率高后果"的捷径；**(c) 第 57 轮是反应式的**，探到死路才绕行，而不可逆接触没有试错预算，必须在第一脚不可逆动作前就持有覆盖所有探针结果的分支预案；**(d) 逐检查点 union bound 随步数线性膨胀**，长路线为守住总风险只能把每步压到不现实的小值，最后要么过度保守、要么名不副实。本轮把安全的对象从"这一脚"上移到"整条路径及其所有分支"：用**安全核 + 撤退走廊**给全局安全一个维持不变式，用**风险预算过程**替代 union bound，用**认证预案树**把"探到死路才回头"变成"承诺前已知每条分支"，用**严重度分级**把"低概率高后果"从期望优化里隔离出来。核心命题由"证据说可信"升级为 **"局部可证、全局可退、最坏可控的路径说安全"**。

核心矛盾：
- **H29（局部安全 ≠ 全局安全）**：每一步都通过证据门，只保证"这一步的失败概率不超预算"，不保证"这一步之后还有安全续接"。安全核与撤退走廊若不在规划时被显式保留，后续动作会静默消耗掉唯一退路；坏路径常常由一堆好局部动作连成。
- **H30（概率安全 vs 严重度安全）**：δ_f 把"平地踉跄"和"悬崖坠落"写成同一个数。期望风险最小化会理性地选择"多冒一次低概率灾难、少走十步安全路"——这在数学上最优，在安全上不可接受。严重度必须作为与概率正交的硬约束，而不是加权项里的一个系数。
- **H31（反应式绕行 vs 预案式分支）**：PCE+ 在检查点失败后才 reroute，等于用不可逆接触去"发现"死路。真正的问题是承诺前是否持有一张"无论探针给出何种结果，都有安全下一步"的分支预案；没有它，绕行只是把发现错误的时间推迟到代价更高的地方。
- **H32（探询路线 vs 撤退路线）**：想获取信息就要靠近不确定区、踩未知支撑点；想保安全就要留在已证核内、护住退路。两者共用同一批落脚点与同一份节拍预算，必须显式分配并强制"探询不得抵押撤退"。

## 0. 直觉与动机

**灵感 1（路径规划 → 安全是一个被维持的不变式，而不是一道门）**
直觉：下棋时"这一步不亏"与"这盘不会输"是两回事；登山时"这块石头踩得住"与"踩上去还能退回来"也是两回事。第 57 轮给出的是前者——逐点的局部合法性；路径规划要求后者——**从当前状态出发，存在一条策略使任何可达的后续都仍处于安全核内**。这正是安全博弈里的"可控前驱 / 最大安全集"：把 H（已证实安全区）当作家，反复剔除那些"存在一个现实观测，其后续无可控地回到家"的状态，收敛得到安全核 K_ret。于是承诺规则从"gate(r) 通过"变成"gate(r) 通过 ∧ r ∈ K_ret ∧ 存在一条风险 ≤ δ_ret 的撤退走廊 ρ(r)，且这一步不破坏 ρ"。安全不再是进门时查一次票，而是全程被维持的活性不变式。

**灵感 2（路径规划 → 路线是决策变量，风险要按路线预算）**
直觉：路径规划的本质是"在众多可行序列里选一条"，而安全性给每个序列一个累积代价。第 57 轮把路线视为既定、只在其上逐点探测；本轮把**顺序、绕行、增删探询点都变成决策变量**。但一旦承认路线可选，风险核算就不能再用"每步 δ_f、总共 N 步、union bound 相加"——N 会随绕行增长，界随之崩坏。改用**风险预算过程**：给整条任务一个总预算 B，按揭示的信息自适应地在剩余路段间重新分配，并用上鞅/Ville 型 anytime 界保证"任何时刻累计消耗超过预算"的概率 ≤ b，而不是对未知步数做静态相加。效率来自把预算投向边际风险削减最大的路段，安全来自任何时刻的超支都被同一张保单兜住。

**灵感 3（安全性 → 先分级严重度，再做优化）**
直觉：医院分诊不会把"擦伤"和"心脏骤停"放进同一个期望损失里排队。安全工程也如此：**灾难性事件是不可交易的**，不能用"总体期望更低"来正当化。把每个接触标注严重度 S∈{S0 无害, S1 可恢复, S2 不可逆, S3 灾难}；S3 是硬零约束（只有物理旁路才可能放行），S2 要求物理实证 + 撤退走廊 + 更高佐证数，S0/S1 才允许进入 CVaR/期望优化。这样"低概率高后果"的捷径在第一层筛选就被删掉，而不是等到期望值算完才发现它"性价比很高"。

**灵感 4（安全性 → 认证预案树与不可返回点）**
直觉：真正的安全计划不是一条线，而是一棵树——"如果探针说冰，走 A；说湿泥，走 B；说碎石且裕度不足，撤退"。AND-OR 结构天然匹配：OR 节点选动作，AND 节点要求**该动作的所有可能观测分支都安全**。在第 57 轮里，这是反应式地在线发现；本轮要求在跨越**不可返回点 PoNR**之前，就存在一棵深度/预算有界的认证预案树，所有叶子都在 K_ret 且撤退可达。PoNR 是硬门：一旦跨过就无法在预算内撤回，必须显式告知并以 L2 协商，授权再高也不能取消。

**灵感 5（合流 → 双时间尺度规划-运行时与路线级解释）**
直觉：全局安全核、预算路由、预案树都是"慢"计算，不可能塞进毫秒级控制回路；局部证据门与护盾是"快"计算，必须实时。于是分成慢环（秒级：重算安全核/路线/预案，带迟滞防抖）与快环（毫秒级：执行 + 局部守护 + 对慢环的一票否决）。慢环只能输出 K_ret 内的路线，且慢环的任何陈旧/错误都不能转化为升险——快环拥有最高否决权，慢环不可用时退回保守巡逻。对人，则把整条路线的风险、每段严重度、撤退点、PoNR 与备选路线做成路线级解释：让"我们用哪一段效率换了哪一份风险"变成可审计的陈述，而不是藏在几十次局部承诺里。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（安全核与撤退走廊 SKP）** 状态/区域集 V，已证安全区 H（物理实证过，或从未接触且默认保守安全）。可控前驱算子 `CPre(K)={s∈K : ∃a∈A(s), pre(s,a) ∧ ∀o∈Ω(s,a), succ(s,a,o)∈K ∪ H ∨ retreat_ok(s,a)}`，其中 retreat_ok 要求存在到 H 的走廊 ρ(s) 满足 R(ρ)≤δ_ret 且清障裕度 ≥m_ret。安全核 K_ret = 最大不动点 gfp(CPre)（从 V 反复剔除直至稳定），因而 K_ret 是"存在策略使任意现实观测都不离开 K_ret∪H"的最大集合，取最大而非最小以覆盖循环安全区。承诺可行性：`committable(s,a) ⇔ s∈K_ret ∧ gate(s) ∧ retreat_ok(s) ∧ a 不消耗 ρ(s) 所需落脚点`。撤退走廊预留 RCI：规划必须在每个已承诺状态保留一条到 H 的走廊，且后续动作不得复用/污染该走廊的支撑。

**定义 140（风险预算化路由 RBR）** 严重度 S(c)∈{S0,S1,S2,S3}，损失 ℓ(c,S)。路线 P=(r_0,…,r_n)。三层目标按字典序：① 硬灾难约束 `Pr(∃S3)≤ε_cat`（S3 还需 bypass），② anytime 风险 `P(∃t:R_t>B_t)≤b`，③ 在①②可行集内最小化 `CVaR_α(ℓ)+λ·E[cost]`，并以 `max min_t margin_t` 破平。风险预算过程：`R_t=Σ_{s≤t} r_s`，`B_t` 为可预测的非增节奏预算，要求 `Z_t=R_t/B_t` 为非负上鞅且 E[Z_0]≤b，由 Ville 不等式得 anytime 界（替代对未知步数的 union bound）；证据更新后可在剩余路段间重分配 `B_t`，但只许收紧当前已消耗比例、不许追认。信息探询预算与撤退预算分账：探询只能用 L0/L1 且不得降低 `min margin` 或缩短有效 ρ。

**定义 141（认证预案树 CPX 与不可返回点）** 预案 T 为 AND-OR 树：OR 节点选择动作 a（探针/接触/绕行/撤退），AND 节点枚举观测 o∈Ω(s,a) 并要求所有子节点安全。`Safe(T) ⇔ ∀leaf∈Leaves(T): leaf∈K_ret ∧ retreat_ok(leaf) ∧ depth≤D_max ∧ 每条根到叶路径累计预算≤B`。不可返回点 PoNR = 沿路线第一个满足"执行后无法在剩余预算内回到 H"的转移。规则：跨 PoNR 前必须同时具备 (i) 覆盖最坏 D_max 步的认证预案，(ii) 若该段为 L2 则完成协商，(iii) 有效撤退走廊；三者缺一即绕行或安全停。授权只能加速协同时延，不能取消 (i)(ii)(iii)。

**定义 142（严重度感知证据门 SGE）** 证据类到"可排除危害集"的映射 Excl(EV)（偏序：物理实证 > 跨模态一致 > 访问史 > 单模态裕度）。严重度门槛 `Need(S)`：S0/S1 允许概率性证据；S2 要求 Excl 覆盖不可逆危害 ∧ 存在物理实证类（EV-probe*/EV-margin）∧ retreat_ok ∧ 佐证数 ≥corrob_min(S,auth)；S3 要求 bypass 或直接拒绝。硬规则：**任何只约束平均风险的一致性/历史证据不得授权 S2 以上的接触**；低概率不能为高严重度背书。SGE 与第 57 轮 FSE 串联：先过 SGE（能不能承受这种后果），再过 FSE（有没有足够证据），最后由 RBR（预算够不够）。

**定义 143（双时间尺度规划-运行时 HPR）** 慢环 planner（秒级）计算 K_ret、RBR 与 CPX，带迟滞 h 与稳定性判据 `improve(new,old)>η` 才切换计划；快环 runtime（毫秒级）执行第 57 轮 shield/PCE+，并对慢环输出拥有**否决权**：若遥测显示慢环依赖的假设（标定、地形、预算、K_ret 证据）失效，快环立即降级到保守动作。降级链：慢环路线 → 保守巡逻 → 安全停。慢环永不输出 K_ret 之外的路线；慢环不可用或超时不得阻塞快环的安全默认。

**定义 144（路线级风险解释与 PoNR 协商 PEX）** 解释元组 `ExpR=(路线摘要, 逐段⟨风险,严重度,裕度⟩, 撤退点与走廊状态, PoNR, 备选路线, 最坏分支)`；渲染沿用第 57 轮 MXI 的个性化模态与误差模型，但**内容不可裁剪**：必须同时显示最坏情况与"哪段效率换来了哪份风险"。PoNR 前强制 L2 式协商并读回确认；拒绝则执行备选路线或安全停。授权只改变协同时延与呈现模态，不改变是否必须协商。

## 2. 关键算法伪代码（完整版见产物区）

```python
def safe_kernel(M, H, delta_ret, m_ret):        # IP-139 最大安全集
    K = set(M.regions)
    while True:
        drop = {s for s in K - H
                if not any(pre(s, a) and all(
                    succ(s, a, o) in K or retreat_ok(s, a, delta_ret, m_ret)
                    for o in Omega(s, a)) for a in A(s))}
        if not drop: return K
        K -= drop

def risk_budget_route(M, K, H, task, B, alpha, sev):
    cands = [P for P in routes_in(M, K, task)
             if all(r in K and retreat_ok(r) for r in P)
             and catastrophe_bound(P, sev) <= EPS_CAT
             and anytime_risk_ok(P, B, alpha)]      # 上鞅/Ville，非 union bound
    return min(cands, key=lambda P: (cvar(P, alpha), cost(P), -min_margin(P)))
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| SKP | O(\|V\|·\|A\|·\|Ω\|) 不动点迭代 | O(\|V\|+\|E\|) | 最大安全集保守、撤退走廊不被消耗 |
| RBR | O(\|routes\|·(\|P\|+CVaR)) | O(\|V\|) | S3 硬约束、风险过程为上鞅 |
| CPX | O(b^{D_max}) 最坏，预算/抽象截断 | O(b^{D_max}) | 全观测分支覆盖、叶子全在 K_ret |
| SGE | O(\|evidence\|) | O(\|evidence\|) | 高严重度须物理实证、禁止低概率背书 |
| HPR | 慢环摊销；快环 O(1)/步 | O(\|plan\|) | 快环否决权、只输出 K_ret 内路线、迟滞 |
| PEX | O(\|plan\|) | O(\|ExpR\|) | 内容不裁剪、PoNR 协商不可被授权绕过 |

**正确性定理（Safe Composable Path Soundness, SCPS 概要）**：在 A33–A40 上加 **(A41)** 安全核保守（K_ret 对观测取最坏、撤退走廊预留完整）；**(A42)** 风险预算过程为非负上鞅且严重度分类诚实、S3 为硬零约束；**(A43)** 预案树覆盖所有可行观测分支且证书健全；**(A44)** 双时间尺度中慢环只输出 K_ret 内路线、快环有否决权且计划切换满足迟滞。则：(i) **全局安全**：P(承诺进入 K_ret 外或撤退失效) ≤ b + 局部证据项，P(灾难) ≤ ε_cat；(ii) **局部可组合**：若每步 committable 且满足 K_ret 递归条件，则整条路径安全（对递归可行集归纳）；(iii) **非反应式**：PoNR 前存在全分支证书 ⇒ 绕行由"事后发现"变为"事前排除"，期望失败重规划次数不增；(iv) **终止**：深度 D_max 与预算 B 有限，CPX 搜索终止于 {承诺, 绕行, 协商, 安全停}。

## 5. 风险与缓解

## 6. 本轮最大风险

**一句话**：本轮把安全从"每步证据门"提升为"整条路径的递归可行与风险预算证书"，最大的风险是**安全核与预案树的建模假设本身被现实击穿**——若 K_ret 的递归定义漏掉了一种现实可达的退化（地形在执行中改变、撤退走廊被后续动作破坏、或观测分支集 Ω 本身不完备），系统会签发一张"全局已证安全"的虚假证书，这比第 57 轮的单点过度自信更危险，因为它把"没人验证过的局部"包装成了"已经证明的全局"；必须以保守抽象、证书随证据失效、快环否决权与 PoNR 硬协商四重护栏，宁可过度拒绝，也不签发无法被遥测复验的全路径证书。

## 2. 关键算法伪代码

### IP-139 SKP（安全核 + 撤退走廊不变式）

```python
def safe_kernel(M, H, delta_ret, m_ret):
    # 最大安全集：从全集开始反复剔除无安全可控前驱的状态
    K = set(M.regions)
    while True:
        drop = set()
        for s in K - H:
            ok = any(
                pre(s, a) and all(
                    (succ(s, a, o) in K) or retreat_ok(s, a, delta_ret, m_ret)
                    for o in Omega(s, a)          # 对现实可行观测取最坏
                )
                for a in A(s)
            )
            if not ok:
                drop.add(s)
        if not drop:
            return K                              # K_ret = gfp(CPre)
        K -= drop

def retreat_corridor(M, s, H, K, delta_ret, m_ret):
    # 只在 K 内、风险<=delta_ret、裕度>=m_ret 的到 H 路径，并预留其支撑点
    return shortest_path(M, s, H,
                         valid=lambda u, v: v in K and risk(u, v) <= delta_ret
                                            and clearance(u, v) >= m_ret,
                         reserve_supports=True)

def committable(M, s, a, K, rho):
    return (s in K and evidence_gate(s)[0] == 'ok'
            and rho[s] is not None and not consumes(rho[s], a))
```

### IP-140 RBR（严重度分级 + anytime 风险预算路由）

```python
def catastrophe_bound(P, sev):
    return sum(sev.p_s3(r) + sev.p_s2(r) for r in P)   # 与软风险分账

def anytime_risk_ok(P, B, alpha, b):
    # R_t = 累计风险；B_t 可预测非增；Z_t = R_t / B_t 须为非负上鞅，E[Z_0] <= b
    Z0 = initial_budget_ratio(B, b)
    return Z0 <= b and is_supermartingale(P, B) and pace_stays_within(P, B, alpha)

def risk_budget_route(M, K, H, task, B, alpha, sev):
    cands = []
    for P in routes_in(M, K, task):                # 路线本身是决策变量
        if not all(r in K and retreat_ok(r) for r in P):
            continue
        if catastrophe_bound(P, sev) > EPS_CAT:    # S3/S2 硬约束，不参与期望权衡
            continue
        if not anytime_risk_ok(P, B, alpha, b):
            continue
        cands.append(P)
    # 字典序：先 CVaR，再期望代价，最后最大化最坏段裕度（max-min 鲁棒）
    return min(cands, key=lambda P: (cvar(P, alpha), cost(P), -min_margin(P)))

def reallocate_budget(B, revealed):
    # 只许收紧已消耗比例，不许把已花掉的预算追认回来
    return B.remaining.rebalance(revealed, monotone_nonincreasing=True)
```

### IP-141 CPX（AND-OR 认证预案树 + PoNR）

```python
def contingent_certify(M, K, H, s0, D_max, B):
    def solve(s, depth, budget, path):
        if s in H or goal(s):
            return Leaf('home', s)
        if depth == 0 or budget <= 0:
            return None
        for a in ordered_actions(s):               # 探针优先，且保留撤退走廊
            if not action_safe_in_K(s, a, K) or consumes(M.rho[s], a):
                continue
            children, ok = {}, True
            for o in Omega(s, a):                  # AND：所有观测分支都要安全
                child = solve(succ(s, a, o), depth - 1,
                              budget - spend(s, a, o), path + [a])
                if child is None:
                    ok = False
                    break
                children[o] = child
            if ok:
                return Node(a, children)           # OR：选一个全分支安全的动作
        return None
    T = solve(s0, D_max, B, [])
    return T if T and all_leaves_in(K, H, T) and not has_ponr_violation(T) else None

def point_of_no_return(plan, budget):
    # 第一个执行后无法在剩余预算内回到 H 的转移
    return next((i for i, (u, v) in enumerate(plan.transitions)
                 if not can_return(v, H, budget.left)), None)

def cross_ponr_guard(plan, T, persona):
    ponr = point_of_no_return(plan, budget)
    if ponr is None:
        return 'ok'
    if T is None:                                   # 无全分支证书，禁止越界
        return 'detour_or_stop'
    if plan.level(ponr) == 'L2' and not ponr_consent(plan, persona):
        return 'detour_or_stop'                     # 授权不得取消协商
    return 'ok'
```

### IP-142 SGE（严重度感知证据门）

```python
def severity_gate(c, M, persona, sev):
    S = sev(c.region)
    need = Need(S)                                  # S0/S1 可概率；S2/S3 硬门槛
    evs = c.evidence_set
    if not excludes(evs, need):
        return ('reject', 'severity_evidence_gap', c)
    if S >= S2:
        if not has_physical(evs):                   # 跨模态一致/历史不得替代物理实证
            return ('reject', 'physical_evidence_required', c)
        if not retreat_ok(c.state, delta_ret, m_ret):
            return ('reject', 'no_retreat_corridor', c)
        if c.corrob < corrob_min(S, persona.auth):
            return ('reject', 'corrob_by_severity', c)
    if S == S3 and not has_bypass(c):
        return ('reject', 'catastrophe_forbidden', c)  # 低概率不为灾难背书
    return ('ok', c)

def compose_gate(c, M, persona, sev):
    st = severity_gate(c, M, persona, sev)          # 先问"能否承受后果"
    if st[0] != 'ok':
        return st
    return few_shot_evidence_gate(c, M, persona, ood_reg)   # 再问"证据够不够"
```

### IP-143 HPR（双时间尺度规划-运行时）

```python
def hierarchical_plan_runtime(x0, M, task, budget, H, sev):
    K = safe_kernel(M, H, delta_ret, m_ret)         # 慢环
    plan = risk_budget_route(M, K, H, task, budget, alpha, sev)
    if plan is None:
        return safe_patrol_or_stop()
    ver = M.ver
    while not done(task):
        if certificate_invalid(plan, M) or (M.ver - ver) > h:
            new = risk_budget_route(M, K, H, task, budget.left, alpha, sev)
            if new is not None and improve(new, plan) > eta:   # 迟滞防抖
                plan, ver = new, M.ver
        cp = next_checkpoint(plan)
        T = contingent_certify(M, K, H, cp, D_max, budget.left)
        guard = cross_ponr_guard(plan, T, active_persona())
        if guard != 'ok':
            alt = reroute_in_K(M, K, cp, task)
            if alt is not None:
                plan, ver = alt, M.ver
                continue
            return safe_stop()
        act = fast_shield_step(cp, M, T, sev)       # 快环：第 57 轮 shield/PCE+
        if act.veto or slow_plan_assumption_broken(M, plan):
            return safe_brake_or_degrade(plan)      # 快环一票否决，降级链
        execute(act)
    return done
```

def plan_risk_explanation(plan, T, sev):
    return ExpR(route=summary(plan),
                per_seg=[(seg, risk(seg), sev(seg), margin(seg)) for seg in plan],
                retreat_points=retreats(plan),
                ponr=point_of_no_return(plan, budget),
                alternatives=alts_in_K(plan),

def render_plan_explanation(exp, persona):
    m_E = argmax(['map', 'haptic', 'voice', 'text'],
                 key=lambda m: persona.understanding[m])
    return render(exp, m_E)                          # 只改渲染，不改内容

def ponr_consent(plan, persona):
    exp = plan_risk_explanation(plan, T=None, sev)

    return ok                                     # auth 只影响时延，不影响是否必须问

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SKP | O(\|V\|·\|A\|·\|Ω\|) 至不动点 | O(\|V\|+\|E\|) | 最大安全集保守、撤退预留（A41） |
| RBR | O(\|routes\|·(\|P\|+CVaR)) | O(\|V\|) | S3 硬约束、Z_t 上鞅（A42） |
| CPX | O(b^{D_max})，抽象/预算截断 | O(b^{D_max}) | 全观测分支覆盖、叶子全在 K_ret（A43） |
| SGE | O(\|evidence\|) | O(\|evidence\|) | 高严重度须物理实证、禁止低概率背书 |
| HPR | 慢环摊销；快环 O(1)/步 | O(\|plan\|) | 快环否决、只输出 K_ret 内路线、迟滞（A44） |
| PEX | O(\|plan\|) | O(\|ExpR\|) | 内容不裁剪、PoNR 协商不可绕过 |

**正确性定理（Safe Composable Path Soundness, SCPS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 安全核保守：K_ret 对 Ω(s,a) 取最坏、撤退走廊在每次承诺后仍完整，且 K_ret 的抽象是 K_ret 的下近似；**(A42)** 严重度分类诚实，S3 为硬零约束（仅物理旁路可放行），风险预算过程 Z_t=R_t/B_t 为非负上鞅且 E[Z_0]≤b；**(A43)** 预案树覆盖所有可行观测分支（Ω 完备或对未建模分支按不安全处理），证书健全；**(A44)** 慢环只输出 K_ret 内路线，快环对其输出有否决权，计划切换满足迟滞且依赖假设失效即降级。则：

1. **全局安全（轨迹级）**：`P(∃t: committed_t ∉ K_ret ∨ ρ 失效) ≤ b + Σ_cp(δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])`，且 `P(∃S3) ≤ ε_cat`。第 57 轮的逐点界是特例（当 K_ret 退化为 H 且无预算重分配）。
2. **局部安全可组合**：若 ∀t，`committable(s_t,a_t)` 且 `succ(s_t,a_t,o)∈K_ret ∨ retreat_ok`，则由 K_ret 的最大不动点定义对 t 归纳可得整条路径安全；这把"每步合法"升级为"整条合法"。
3. **非反应式承诺**：跨 PoNR 前 T≠None 且 Safe(T) ⇒ 任一探针结果都有安全后继，PCE+ 的绕行从"事后发现"变为"事前排除"，期望重规划次数不增。
4. **严重度隔离**：S3 的可行性不依赖期望风险，故最小化 CVaR 不会把路线推向灾难捷径；S2 的物理实证要求切断了"一致性加成 → 不可逆承诺"的越级链。
5. **终止性**：`D_max` 与 `B` 有限，CPX 搜索有限；HPR 每次检查点至多一次慢环重算（迟滞）+ k_probes 次快环探测，故在有限步终止于 {承诺, 绕行, L2 协商, 安全停}。
6. **部署界**（把新增建模风险显式列出）：

```
P_safe ≥ 1 − [ b + Σ_cp(δ_f + ε_meta + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]) ]
             − P(K_ret 抽象失效未检出) − P(撤退走廊被静默破坏)
             − P(预案分支遗漏 Ω\Ω̂) − P(慢环错误未被快环否决)
             − P(严重度分类被下调且审计失败)
```

关键：**安全核给"能回家"、预算过程给"任何时刻不超支"、预案树给"每分支都有着落"、严重度给"灾难不可交易"**；四者把第 57 轮"单点证据门"补成"路径级安全契约"，而快环否决权保证慢计划永远不能单独升险。

## 6. 本轮最大风险

**一句话**：本轮把安全从"每步证据门"提升为"整条路径的递归可行与风险预算证书"，最大的风险是**安全核与预案树的建模假设本身被现实击穿**——若 K_ret 的递归定义漏掉了一种现实可达的退化（地形在执行中改变、撤退走廊被后续动作破坏、或观测分支集 Ω 本身不完备），系统会签发一张"全局已证安全"的虚假证书，这比第 57 轮的单点过度自信更危险，因为它把"没人验证过的局部"包装成了"已经证明的全局"；必须以保守抽象、证书随证据失效、快环否决权与 PoNR 硬协商四重护栏，宁可过度拒绝，也不签发无法被遥测复验的全路径证书。
