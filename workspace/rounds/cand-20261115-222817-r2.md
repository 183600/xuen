# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「群体智能」×「预训练」）

> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**共识不是证据，同源共识只是相关的重复；预训练不是免证，只是可校准的先验**。两个灵感分别治理 v9 的两种债：**单点信任债**（块证书 Ĉ_t 全部押在一个冻结前向模型 F̂ 上，β 靠经验标定）与**记忆短视债**（中止经验只活在当前块，不跨块、不跨回合、不跨机积累）。核心反转：**v9 用滞后的 Δ_dom 滑窗判断「该不该信模型」；本轮改为用「预训练密度的领先信号 + 群体分歧的鲁棒共识 + 共形覆盖的有限样本账本」三重独立证据共同裁定，绝不让单一模型既当运动员又当裁判。**

## 0. 直觉与动机

**灵感 1（群体智能 → 鲁棒共识证书，而非「平均更准」）**
直觉：v9 把全部信任押在一个冻结前向模型 F̂ 上，这既是单点故障，也浪费了「多个预训练检查点本可互相校验」的事实。群体智能的第一课不是「更多模型平均更准」，而是**用分歧度量无知、用鲁棒聚合抵抗个别成员发疯**。
**严谨定义（摘要）**：**群体世界模型（SwarmWorldModel, SWM）**：N 个异构预训练预测器（不同语料/种子/架构/感受野，N 取奇数，默认 5）对同一动作块独立预测；坐标逐维取**中位数**作为点证书，成员间四分位展布给出分歧 D_swarm，成员否决票给出即时失效信号。关键定理（引理 87）：若 ≥⌈N/2⌉ 个成员对真值误差 ≤ β，则逐维中位数误差 ≤ β；等价地，可容忍任意 f<⌊N/2⌋ 个拜占庭成员。**但「多数成员接近真值」是可证伪的弱预言机假设，必须显式记录并主动攻击（E574/E589），而不能默认。**

**灵感 2（预训练 → 领先信任域 + 有限样本覆盖账本）**
直觉：预训练给我们两件 v9 没有的东西：(a) 一个**领先指标**——预训练表征空间的密度/重构误差，能在 Δ_dom 的 20 帧滑窗填满之前就嗅到「这不在我的预训练支持集内」；(b) 一个**可校准的误差分布**——既然有大量预训练/离线残差，就能用 split conformal 把 β 从「经验拍脑袋」升级为「有限样本覆盖 ≥1−α」。
**严谨定义（摘要）**：**预训练先验 + 共形证书（PretrainedPriorConformal, PPC）**：ρ_pre(s) 定义领先信任域 U_t^pre；共形非一致性分数 s = ĝ_pred − g_true 的 (1−α) 分位给出 β_t，使交换性下 P(g_true ≥ ĝ_pred − β_t) ≥ 1−α；ACI 以 α_{t+1}=α_t+γ(α−1{err_t>β_t}) 维持漂移下的**长期**覆盖。**诚实边界：conformal 只保证可交换情形的边缘覆盖、ACI 只保证长期覆盖，二者都不保证跳变后的「每块」覆盖——所以 PPC 必须与领先门控联用，不能单独兜底。**

**灵感 3（群体智能 → 信息素风险记忆）**
直觉：v9 的中止点只是块内静态集合，经验不跨块、不跨回合积累。蚁群用信息素把「这里出过事」写进环境，后来者无需通信即可读到。
**严谨定义（摘要）**：**信息素风险图（StigmergicRiskMap, SRM）**：每次中块中止在（位置×朝向×速度）栅格沉积风险信息素，逐周期蒸发 + 核扩散；块采样被 ρ 偏置（w∝exp(−λρ)），K_eff 被 ρ 收缩。蒸发给出上界 ρ≤Δρ/ε，从而 w≥w_min>0，**保证无永久锁死、无 Zeno**（引理 89）。单机即可运行：多个虚拟觅食者 = 群体成员 / 历史回合。

**灵感 4（群体智能 × 预训练 → 机队联邦经验池，可选增强）**
直觉：家庭机器人天然成队，A 的中止经验不该被 B 从零重学。
**严谨定义（摘要）**：**联邦预训练经验池（FleetExperiencePool, FEP）**：各机只把「通过 M₀ 硬检查且事后证书判定正确」的证书残差/违规回合上报，经拜占庭鲁棒聚合（坐标中位数）后并入本地共形校准集；安全门控在聚合**之前**（防投毒标签），鲁棒聚合在门控**之后**（防投毒统计）。通信失效即退回单机经验。

**交叉洞察（本轮真正的创新点）**：群体智能的致命弱点是**共模失效**——N 个同源预训练模型在真正陌生域上会「一起自信地错」，此时 D_swarm 坍缩、中位数多为坏值，弱预言机假设恰好被违反。但预训练密度 ρ_pre 与群体分歧 D_swarm 是**两条独立证据**。因此定义**共模警觉** I_t = 1{ρ_pre ≥ τ_pre ∧ D_swarm < τ_SW}：输入在预训练支持集之外、群体却异常一致 ⇒ 判定「自信的陌生」，直接 K_eff←1、强制全模块唤醒，并把证书从**中位数**切换为**全体成员最坏情形**（min clearance / max effort），β 收敛到 0（不再信任校准）。这把 v9 的悖论（最需要安全时证书最不可信）变成一个可检测、可响应的警报。

## 1. 研究问题（轮次升级版）

- **Q1（鲁棒共识的边界）**：在「多数预训练成员误差 ≤ β」的弱预言机假设下，中位数证书能否保证块内保守性并容忍 f<N/2 个拜占庭成员？该假设在共模失效下如何被**证伪而非默认**？「ρ_pre 高而 D_swarm 低」的共模警觉能否在跳变当帧触发？
- **Q2（覆盖保证的时效）**：split conformal 的交换性在漂移下必然破裂，ACI 只给长期覆盖；如何把「长期覆盖」与「每块安全」解耦——是让领先门控在共形失效前抢先收缩 K_eff，还是为每块构造 e-process/anytime-valid 证书？两者能否复合而不重复计数？
- **Q3（群体记忆的参数）**：蒸发率 ε、沉积量 Δρ、偏置强度 λ 如何权衡「避免重蹈覆辙」与「不永久封锁可行域」？能否证明采样在任何可行域上的概率下界 >0（无锁死）且风险栅格的期望访问频率与真实风险同序（有效记忆）？
- **Q4（群体共享的净收益）**：机队经验/预训练共享何时正迁移、何时因异质环境负迁移或拜占庭污染？安全门控与鲁棒聚合的先后顺序能否给出可证的污染上界？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P16）

**P13 鲁棒共识证书律（Swarm-Consensus Certificate, SWM）**
块证书不由单一 F̂ 给出，而由 N（奇数）个异构预训练成员的逐维中位数给出；分歧 D_swarm 与成员否决票是证书有效性的即时输入。中位数对 <N/2 个任意坏成员鲁棒；「多数成员接近真值」必须作为**显式、可证伪、需主动攻击**的假设记录，禁止隐式默认。共模警觉 I_t 成立时，证书退化为全体成员最坏情形（保守序的顶元，呼应信息序直觉）。

**P14 预训练先验与共形覆盖律（Pretrained Prior & Conformal Coverage, PPC）**
预训练表征的密度/重构残差 ρ_pre(s) 定义**领先**信任域 U_t^pre；共形非一致性分数分位数给出 β_t，使交换性下边缘覆盖 ≥1−α；ACI 维持漂移下的长期覆盖。K_eff 取 v9 门控与 ρ_pre、D_swarm、共形 p 值四者的最小值。**绝不用长期覆盖冒充每块安全**。

**P15 信息素风险记忆律（Stigmergic Risk Memory, SRM）**
中止事件在离散状态-动作栅格沉积信息素：ρ←(1−ε)ρ+Δρ·K_hit，逐周期蒸发 + 核扩散；采样权重 w∝exp(−λρ)；蒸发给出上界保证 w≥w_min>0，故不会永久封锁任何可行域；风险图跨回合、可跨机（经 FEP 共识）共享。

**P16 群体经验安全门控律（Fleet Experience Safety Gate, FEP）**
仅当回合通过 M₀ 硬检查、且事后证书被判定正确（未触及 d_safe、未碰撞）时，其残差经验才可进入共享池；**先安全门控后鲁棒聚合**（门控防投毒标签，聚合防投毒统计）；通信失效自动退回单机。

## 3. 与基线的接口（如何退化）

- SWM 失效（可用成员 <3 或推理超时）⇒ 退回单个冻结 F̂，等价 v9 的 AC 证书（定义 533）；
- PPC 失效（无校准集 / 共形不可算 / ACI 数值异常）⇒ β 取 v9 经验标定值，U_t 取 v9 的 Δ_dom/risk_SLAM 门控，等价 v9；
- SRM 失效（风险图不可用）⇒ 采样均匀、K_eff 仅由 v9 门控决定，等价 v9；
- FEP 失效（无通信 / 聚合不可信）⇒ 仅用本机经验，等价单机 v10 去 FEP；
- v9 的 AC/MW/ID 任一失效 ⇒ 按 v9 五级退化链（AC→K_eff=1；MW→手写网关；ID→全模块 active）；
- v9 的 DA/SPR/Cal 失效 ⇒ 中立元注入（Δ_dom≡0 / risk_SLAM≡0 / sensor_weight≡1），等价 v7；全失效 ⇒ v7 → v6。

以上逐项代入后必须**逐位等价**（引理 90），不接受「统计上差不多」的行为漂移。

## 4. 预期贡献

1. **鲁棒群体证书**：以逐维中位数把 v9 单点前向模型升级为 N 成员、可容 ⌊(N−1)/2⌋ 个坏成员的证书（引理 87：弱预言机 + 拜占庭容错 + 崩溃点分析）；
2. **覆盖保证的 β 与共模警觉**：split conformal + ACI 把经验余量升级为有限样本/长期覆盖，并用「预训练密度高 ∧ 群体分歧低」这一**独立证据交叉**检测同源共模失效（引理 88），这是对 v9 最大风险的直接机制化回应；
3. **信息素群体记忆**：中止经验的可蒸发、可共享、无锁死的分布式风险图（引理 89，含探索概率下界）；
4. **联邦经验池**：安全门控 + 拜占庭鲁棒聚合的机队经验共享，给出负迁移/投毒的可证上界思路；
5. **实验 E571–E590**：共识精度、共模攻击、弱预言机检验、共形覆盖与漂移、领先指标延迟、信息素调参与无锁死、负迁移/拜占庭机队、端到端。

## 5. 本轮最大风险

**一句话**：群体智能的致命弱点是**共模失效**——若 N 个预训练成员共享语料与架构，它们在真正陌生域上的分歧会同时坍缩，即「自信地一起错」，而中位数证书的弱预言机假设（多数成员误差 ≤ β）恰在此刻被违反，于是系统在最危险的分布跳变瞬间得到最一致、最虚假的安全共识；共模警觉 I_t 只能覆盖「ρ_pre 也升高」的那部分陌生性，对「预训练分布本身覆盖了错误模式」的伪在分布失效则完全失明。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-SCP**（Swarm-Consensus Predictive certificates with Pretrained priors & Conformal coverage）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮灵感：「群体智能」×「预训练」
> **继承纪律**：MetricVoiceGauge 九不变式（CVC-闭环、SpatialCert、RT-CVC、FaultCert、PrimitiveGraph、严格退化链、OTL、GCT、ER）全部保留；v8 的 DA-ML/SPR/Cal 与 v9 的 AC/MW/ID 原样继承，语义不变。新组件一律为**可选增强**：任一环节不可用 ⇒ 注入中立元或退回 v9（引理 90），严格等价而非行为漂移。**本轮唯一的口径升级**：v9 的块证书是「单一模型 + 经验 β」，v10 把它拆成三条独立证据——群体共识、预训练先验、共形账本——并显式处理三者的相关失效。

## 0. 核心 IP 设计

**退化链声明（v10 契约化增强 → v9 严格回落）：**
- Level-1：共模警觉 I_t=1（ρ_pre ≥ τ_pre ∧ D_swarm < τ_SW）⇒ K_eff←1、强制全模块唤醒、证书切最坏情形（全体 min/max）、β→0；
- Level-2：共形/共识失效（p_t<α 或否决票 ≥ q_veto）⇒ K_eff←1，退回 v9 单模型逐步证书（定义 533）；
- Level-3：SWM 失效（可用成员 <3）⇒ 单 F̂，等价 v9；
- Level-4：PPC 失效（无校准集/共形不可算）⇒ 经验 β + v9 的 Δ_dom/risk_SLAM 信任域，等价 v9；
- Level-5：SRM 失效（风险图不可用）⇒ 均匀采样 + v9 门控，等价 v9；
- Level-6：FEP 失效（无通信/聚合不可信）⇒ 单机经验，等价 v9 单机；
- Level-7：v9 的 AC/MW/ID 失效 ⇒ v9 五级链；再失效 ⇒ v8 → v7 → v6。

## 1. 符号体系增量（定义 540–547）

| P_i^k = (g_i^k, e_i^k, γ_i) | 成员 i 对块第 k 步的间隙/能耗/抓取预测 |

**新增定义 540（群体世界模型 SwarmWorldModel）** N 个冻结预测器，成员 i 输出指标轨迹 F̂_i(s,a^{1:K}) → {(g_i^k, e_i^k)}_{k≤K} 与抓取有效位 γ_i。逐维点预测取中位数：

```
ĝ_pred^k = median_i g_i^k,   ê_pred^k = median_i e_i^k,   γ̂_grasp = (Σ_i γ_i > N/2)
D_swarm  = (1/K) Σ_k (Q_3(g^k) − Q_1(g^k)) / g_scale + (1/K) Σ_k (Q_3(e^k) − Q_1(e^k)) / e_scale
```

N 取奇数以避免中位数平局；成员须在语料/架构/种子上**可审计地异构**（见定义 547 谱系折扣，防止「伪群体」）。

**新增定义 541（中位数证书 MedianCertificate）** 在定义 540 的点预测上留共形余量 β_t：

```
ĝ_min = min_{k≤K} ĝ_pred^k − β_t,     ê_max = max_{k≤K} ê_pred^k + β_t
証书有效 ⇔ ĝ_min ≥ d_safe ∧ ê_max ≤ τ_eff ∧ γ̂_grasp ∧ p_t ≥ α ∧ ¬I_t
```

其中 min 作用在「逐维中位数」之后（顺序不可交换：先中位数后取 min，才有引理 87 的坐标逐维证明）。

**新增定义 542（预训练领先信任域）** ρ_pre(s) 取冻结预训练编码器的归一化重构误差，或预训练嵌入空间到支持集流形的马氏距离。τ_pre 由分布内 ρ_pre 的 99 分位标定：U_t^pre = {ρ_pre(s_t) < τ_pre}。**领先性**：只依赖当前帧 s_t，无需 Δ_dom 的 H=20 帧滑窗。

**新增定义 543（共形证书与 ACI）** 校准集 D_cal = {(s_j, a_j^{1:K}, g_j^{1:K})}，离线或经 FEP 汇总，假设与测试块可交换。对间隙取单侧非一致性分数 s_j = max_{k≤K}(ĝ_pred,j^k − g_j^k)（越大越危险）。令 q_t 为校准分数集的 ⌈(n+1)(1−α)⌉ 序统计量，β_t = q_t。则交换性下 P(g_true ≥ ĝ_pred − β_t) ≥ 1−α。能耗侧对称地用 (e_j^k − ê_pred,j^k) 的上侧分数。漂移下交换性破裂，改用 ACI：

```
err_t = 1{ max_k(g_true^k − ĝ_pred^k) > β_t }     # 证书未覆盖
α_{t+1} = clip( α_t + γ·(α − err_t), α_min, α_max )
β_{t+1} = Quantile_{1−α_{t+1}}(校准分数)
```

标准步长条件下，(1/T)Σ err_t → α（长期覆盖）。**注意：这是长期保证，不是每块保证**；每块安全由 Level-1 的领先门控与其保守切换负责。

**新增定义 544（信息素风险图）** 栅格单元 x。中止发生于 x_p 时沉积并经核扩散：

```
ρ(x) ← (1−ε)·ρ(x) + Δρ · exp(−‖x − x_p‖² / (2σ_s²))   （对所有 x）
每周期全图蒸发：ρ(x) ← (1−ε)·ρ(x)
```

采样权重 w(x) ∝ exp(−λρ(x))；块长收缩因子 k_ρ(x) = 1/(1 + λρ(x))。ρ≡0 时 w≡1、k_ρ≡1，精确退回 v9 均匀采样。

**新增定义 545（多闸有效块长与共模警觉）**

```
I_t = 1{ ρ_pre(s_t) ≥ τ_pre ∧ D_swarm(t) < τ_SW }        # 自信的陌生
K_eff(t) = 1                                              若 ¬U_t ∨ ¬U_t^pre ∨ I_t ∨ (p_t < α) ∨ 否决票 ≥ q_veto
         = min( K_eff^{v9}(t), ⌊K_max·k_ρ(x_t)⌋ )        否则
```

I_t=1 时证书切**最坏情形成员**而非中位数：ĝ_min^worst = min_i min_k g_i^k − 0（β 置 0），ê_max^worst = max_i max_k e_i^k + 0；即完全不用可能被共模污染的校准。这是对「多数成员一起错」的保守响应。

**新增定义 546（拜占庭共识与否决）** 成员票 v_i∈{valid, invalid}。鲁棒聚合取逐维中位数；否决规则：count(invalid) ≥ q_veto = ⌈N/2⌉ 时证书无效。若真实成员中诚实者 f<N/2 且诚实者误差 ≤β，则中位数误差 ≤β（引理 87），因此拒绝任何「少数坏成员拉偏中位数」。

**新增定义 547（联邦经验池与谱系）** X_fleet 只接收满足准入门控的回合：通过 M₀ 硬检查 ∧ 事后判证书正确（无 d_safe 触碰、无碰撞）。聚合按逐维中位数/修剪均值；每条经验带**谱系标签**（传感器/本体/训练种子/环境来源），d_swarm 与共形校准按独立谱系数 α(L) 折扣，防止「同源伪群体」既骗分歧又骗校准。负迁移防护：仅当目标机与来源机的特征密度比在信任半径内才并入。

# IP-357 SwarmWorldModel：群体世界模型
class SwarmWorldModel:
    def __init__(self, members, beta, d_safe, q_veto):
        assert len(members) >= 3 and len(members) % 2 == 1
        self.members, self.beta, self.d_safe = members, beta, d_safe
        self.q_veto = q_veto

    def predict(self, state, actions):
        preds = [m.rollout(state, actions) for m in self.members]
        g = [p.min_clearance for p in preds]
        e = [p.max_effort for p in preds]
        votes = [p.grasp_valid for p in preds]
        g_pred, e_pred = median(g), median(e)
        d_swarm = ((quantile(g, .75) - quantile(g, .25)) / g_scale
                   + (quantile(e, .75) - quantile(e, .25)) / e_scale)
        return Cert(g_pred - self.beta, e_pred + self.beta,
                    sum(votes) * 2 > len(votes)), d_swarm, votes

    def vetoed(self, votes):
        return sum(1 for v in votes if not v) >= self.q_veto

    def worst_case(self, preds):
        g = min(p.min_clearance for p in preds)      # 共模警觉时用
        e = max(p.max_effort for p in preds)
        return Cert(g, e, all(p.grasp_valid for p in preds))


# IP-358 PretrainedPriorConformal：领先先验 + 共形覆盖
class PretrainedConformal:
    def __init__(self, encoder, cal_residuals, alpha=0.05, gamma=0.01,
                 alpha_min=1e-4, alpha_max=0.5):
        self.enc = encoder
        self.res = sorted(cal_residuals)
        self.alpha, self.gamma = alpha, gamma
        self.alpha_min, self.alpha_max = alpha_min, alpha_max

    def novelty(self, s):
        return self.enc.recon_error(s)                # 领先：单帧，无滑窗

    def beta(self):
        n = len(self.res)
        k = min(n, ceil((n + 1) * (1 - self.alpha)))
        return self.res[k - 1] if self.res else 0.0

    def p_value(self, residual):
        n = len(self.res)
        return (1 + sum(1 for r in self.res if r >= residual)) / (n + 1)

    def aci_update(self, err, beta):
        self.alpha = min(self.alpha_max, max(
            self.alpha_min, self.alpha + self.gamma * (self.alpha - (1 if err > beta else 0))))


# IP-359 StigmergicRiskMap：信息素风险记忆
class StigmergicRiskMap:
    def __init__(self, eps=1e-3, d_rho=1.0, lam=1.0, sigma=0.25):
        self.rho, self.eps = {}, eps
        self.d_rho, self.lam, self.sigma = d_rho, lam, sigma

    def evaporate(self):
        for x in list(self.rho):
            self.rho[x] *= (1 - self.eps)
            if self.rho[x] < 1e-9:
                del self.rho[x]

    def deposit(self, cells_around_abort):
        for x in cells_around_abort:
            self.rho[x] = self.rho.get(x, 0.0) + self.d_rho

    def weight(self, x):
        return exp(-self.lam * self.rho.get(x, 0.0))

    def k_factor(self, x):
        return 1.0 / (1.0 + self.lam * self.rho.get(x, 0.0))


# 升级 IP-354 ActionChunkCertifier：两阶段级联，保持 12ms 预算
class ActionChunkCertifierSCP:
    def __init__(self, swarm, ppc, srm, policy, K_max=10, n_coarse=64, n_fine=8):
        self.swarm, self.ppc, self.srm = swarm, ppc, srm
        self.policy, self.K_max = policy, K_max
        self.n_coarse, self.n_fine = n_coarse, n_fine

    def effective_K(self, ctx, x):
        if not ctx.trust_ok or not ctx.trust_pre or ctx.common_mode_alert:
            return 1
        if ctx.conformal_p < self.ppc.alpha or self.swarm.vetoed(ctx.votes):
            return 1
        return max(1, min(ctx.K_eff_v9, int(self.K_max * self.srm.k_factor(x))))

    def generate_chunk(self, ctx):
        K = self.effective_K(ctx, ctx.cell)
        if K == 1:
            return self._single_step_fallback(ctx)         # 等价 v9 逐步
        cands = self.policy.sample_sequences(ctx.state, K, n=self.n_coarse,
                                             weight=self.srm.weight)
        coarse = sorted(cands, key=lambda c: self.swarm.members[0].score(c))[:self.n_fine]
        best = None
        for cand in coarse:
            cert, d_swarm, votes = self.swarm.predict(ctx.state, cand)
            if ctx.novel_high and d_swarm < ctx.tau_sw:
                cert = self.swarm.worst_case(...)          # 共模警觉：最坏情形
            if not cert.valid(ctx.tau_eff, ctx.d_safe):
                continue
            pts = self._abort_points(ctx.state, cand, cert)
            if not pts:
                continue
            s = self.policy.score(cand, cert)
            if best is None or s > best.score:
                best = Chunk(cand, cert, pts, s, d_swarm, votes)
        return best or self._single_step_fallback(ctx)

    def midchunk_guard(self, chunk, k_exec, live_obs):
        if (not chunk.cert_still_valid(live_obs)
                or live_obs.conformal_p < self.ppc.alpha
                or (live_obs.novel_high and chunk.d_swarm < self.tau_sw)):
            return self._nearest_abort(chunk, k_exec)
        if (live_obs.nearest_clearance - self.d_brake(live_obs.speed)
                - self.d_safe) < chunk.remaining_len(k_exec):
            return self._nearest_abort(chunk, k_exec)
        return ('continue', k_exec + 1)

## 4. 推导

**引理 87（群体中位数鲁棒性与弱预言机）** 设 N 为奇数。若成员中有 ≥⌈N/2⌉ 个满足 |g_i − g| ≤ β（逐维、对真值 g），则中位数 m = median_i g_i 满足 |m − g| ≤ β。推论证书保守：ĝ_min = min_k m^k − β ≤ min_k g^k = g_min^true。允许至多 f ≤ ⌊(N−1)/2⌋ 个成员**任意**偏离（拜占庭），只要诚实成员数 N−f ≥ ⌈N/2⌉ 且都在 β 内。
证明：区间 I=[g−β, g+β] 含 ≥⌈N/2⌉ 个样本。N 为奇数时 ⌈N/2⌉=(N+1)/2，故 I 内样本数严格大于 I 外任一侧可能的最大样本数 (N−1)/2；排序后第 (N+1)/2 个样本必落在 I 内，即 m∈I。对每维 k 应用，再对 k 取 min 得 ĝ_min ≤ g_min^true。∎
**注（可证伪性）**：结论的条件是「多数成员误差 ≤β」，这恰是共模失效时被违反的前提；引理本身不提供对该前提的保证，故必须由定义 545 的 I_t 与 E574/E589 主动检验。

**引理 88（共形覆盖及其在漂移下的失效边界）** 若校准集与测试块可交换，则 split conformal 的 (1−α) 分位 β_t 满足 P(g_true ≥ ĝ_pred − β_t) ≥ 1−α。证明：非一致性分数 s_{n+1} 与 {s_j} 可交换，故其秩在 n+1 个值中均匀，P(s_{n+1} ≤ q_{⌈(n+1)(1−α)⌉}) ≥ 1−α；而 err≤β 蕴含覆盖。交换性破裂时该式不成立；ACI 在 err_t 有界、步长满足 Σγ=∞、Σγ²<∞ 下给出 (1/T)Σ err_t → α（长期覆盖）。**推论（诚实边界）**：ACI 不保证跳变后的单块覆盖，故 K_eff 必须由领先门控在跳变当帧先收缩（定义 542/545），不能仅依赖共形。∎

**引理 89（信息素无锁死与有效记忆）** (i) 稳态下 ρ(x) ≤ Δρ/ε（沉积与蒸发的平衡上界），故 w(x)=exp(−λρ(x)) ≥ exp(−λΔρ/ε)=w_min>0；归一化后任一单元采样概率 ≥ w_min/|X| > 0，由 Borel–Cantelli（独立随机化）每个被访问单元几乎必然无穷次被访问 ⇒ 无永久封锁。(ii) 对固定单元，期望沉积速率 ∝ 访问频率 × 真实中止率；ρ 的期望正比于经验风险，故采样偏置与真实风险同序；蒸发使陈旧风险以 (1−ε)^t 指数遗忘，避免历史错误永久惩罚。∎

**引理 90（v10 → v9 严格退化）** 逐项关闭新模块后行为与 v9 逐位等价。
证明：(i) SWM 退化为单成员时，median 退化为该成员的 F̂，D_swarm=0，否决票不可达 ⇒ 定义 541 = v9 定义 533；(ii) PPC 失效时 β_t≡β_v9、U_t^pre≡true、p_t≡1、I_t≡0 ⇒ 定义 545 的额外闸恒真，K_eff=K_eff^{v9}；(iii) SRM 失效时 ρ≡0 ⇒ w≡1、k_ρ≡1，采样与 K_eff 均退回 v9；(iv) FEP 失效时校准集只用本机，等于未启用；(v) v9 继承路径与五级退化链不变。逐位体现在所有替换均为「取恒等/真值」，无浮点近似路径。∎

**引理 91（预算守恒与级联摊销）** 粗筛 n_coarse=64 用最廉价成员，精评 n_fine=8 用全群体（N=5）；总块生成 ≤12ms（粗筛 ≤8ms + 精评 ≤4ms），摊销到 10 个控制周期 ≤1.2ms/cycle；50Hz 守卫仅含一次编码器前向（ρ_pre，≤0.2ms）+ 一次共形查表 + O(1) 停车不变式检查 ≤0.5ms；故 50Hz 总预算仍满足，p99 ≤20ms。
证明：由各步复杂度上界相加，且重计算仅在 5Hz 块边界发生。∎

## 8. 本轮最大风险

**一句话**：群体智能的致命弱点是**共模失效**——若 N 个预训练成员共享语料与架构，它们在真正陌生域上的分歧会同时坍缩，即「自信地一起错」，而中位数证书的弱预言机假设（多数成员误差 ≤ β）恰在此刻被违反，于是系统在最危险的分布跳变瞬间得到最一致、最虚假的安全共识；共模警觉 I_t 只能覆盖「ρ_pre 也升高」的那部分陌生性，对「预训练分布本身覆盖了错误模式」的伪在分布失效则完全失明。
