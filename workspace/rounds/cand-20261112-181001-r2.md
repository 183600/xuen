# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 7 轮；本轮灵感：「可靠性」×「人形机器人」）

> 第 60 轮实现了「认知驱动的场景-执行闭环」：SSM 场景语义建模、CIEC 认知意图约束、EPIR 执行感知隔离区、SERC 场景闭环、SIC 三元校验、CESC 联合决策、EPIR-Protocol。但把系统直接用于**人形机器人**时，暴露三个更本质的局限：
> 1. **场景层确定 ≠ 全身可靠**：人形机器人是浮动基、高冗余（30+ DoF）、多接触、强欠驱动的系统；第 60 轮把「可靠」落在场景置信度 scene_conf 与阻抗确定性 K_certainty 上，但**摔倒不是某个通道置信度低的问题，而是平衡、接触、执行器、人身安全等多通道的链式合成问题**——场景 99% 确定仍可能因单腿打滑而摔倒。缺**全身可靠性合成**。
> 2. **认知预算无可靠性维度**：PCE++++ 的四预算 B_scene/B_intent/B_ros/B_exec 只衡量算力、时延、消息，未把「还剩多少可恢复裕度、执行器还剩多少健康度」纳入预算。人形机器人可能为了多探测一次场景而**耗尽恢复裕度**，把「可恢复的小扰动」变成「不可逆的摔倒」——可靠性必须进入预算。
> 3. **证据链只证「做过」，不证「为何可靠」**：EPIR 保障 EV-exec 完整回传，却无法回答「为什么没有摔倒」「如果重来能否不摔」。人形机器人的可靠性需要**可追溯的因果证据**（可靠性取证），而不仅是执行证据的序列完整。
> 更深一层：人形机器人与人类共享空间，**人身安全通道（R_hum）**是任何其他通道都无法补偿的硬约束——这要求一个能「一票否决」认知意图的守护者。

## 0. 直觉与动机

**灵感 1（可靠性 → 全身可靠性的最弱环合成 WRS）**
直觉：人形机器人的可靠性不是「平均分」，而是「最短板」。链子强度由最弱一环决定；只要平衡、接触、执行器、人身安全任一通道失效，系统就发生灾难性失败（摔倒/伤人）。因此**用加权平均估计可靠性会产生「可靠性幻觉」**：平均 0.95 的系统可能藏着一个 0.6 的通道。严格地，串联系统满足 `R_sys ≤ min_c R_c ≤ mean_c R_c`；而**保守**估计应取 Fréchet 下界 `R_wb^cons = max(0, Σ_c R_c − (|C|−1))`——它对任意通道相关结构都成立。关键洞见：**可靠性合成必须显式区分「串联安全通道」与「并联冗余通道」**，安全通道一律取保守下界，绝不取平均。

**灵感 2（人形机器人 → 捕捉点可靠性场 CPF）**
直觉：人形机器人的「安全」本质是「还来不来得及救」。用发散运动分量（DCM）ξ = x_com + ẋ_com/ω 与支撑多边形 S_support 的距离定义**可恢复裕度** m(x)；据此在每个状态上定义一个可靠性场 ρ(x) = P(在时域 T 内可恢复到支撑多边形且不摔倒 | x)。关键洞见：**把「平衡约束」从不含概率的 CoM∈S_support 升级为带概率的「停留在高 ρ 区域」**，可靠性由此成为控制器的显式目标，而非事后指标；并用控制屏障函数（CBF）保证认证安全集前向不变。

**灵感 3（冗余接触 → 冗余接触可靠性分配 RCRA）**
直觉：人形机器人双手双脚甚至躯干可形成多接触，同一任务力旋量可在多个接触间分配。传统分配最小化关节力矩，但**最小力矩不等于最可靠**。应分配接触力以**最大化最弱接触的可靠性**（max-min）：让每个接触都保留足够的摩擦/法向裕度。关键洞见：**冗余是可靠性资源**——把冗余用于「抬高最弱环」，而不是「平均压低所有环」。

**灵感 4（退化 → 退化可靠性阶梯 DRL）**
直觉：人形机器人的执行器会退化（单臂无力、单腿僵硬、关节过热）。可靠性不是二值，而是可以**分级让渡**：L0 正常 → L1 任务降级（放弃子目标）→ L2 身体重构（改单臂/借支撑/重心下沉）→ L3 寻求支撑（扶墙、下蹲、抓住环境）→ L4 保护性停止（锁死关节）→ L5 保护性倒地（蜷缩护头、卸载动能）。关键洞见：**每一级切换都必须持证书（certified transition）**，并且要在可靠性场仍有余量时**提前降级**（pre-emptive degradation），而不是「感知到要摔才临时决定」。

**灵感 5（合流 → 守护可靠性契约 GRC + 可靠性闭环 RCL + PCE-R + REC）**
直觉：把上述合成 **「守护式可靠性闭环」**：WRS 给出全身可靠度 → CPF 给出状态空间的可恢复裕度 → RCRA 把任务力旋量分到最可靠的接触 → DRL 在可靠度下台阶时持证降级 → GRC 作为最高优先级的**可靠性守护者**，在 R_wb < θ_rel 时**一票否决** CIEC 的认知意图 → REC 记录链式哈希的可靠性证据链供取证。PCE++++ 扩展为 **PCE-R**，新增可靠性预算 B_rel。关键洞见：**可靠性在主从层级上高于认知**——第 60 轮「认知先行从不超过执行安全」，本轮进一步收紧为「认知先行不得超过可靠性否决线」。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（全身可靠性状态 WRS）** 全身可靠性状态 R_wb = (C, R, ⊗, θ_rel)：
- **可靠性通道**：C = C_crit ∪ C_red。安全关键串联通道 C_crit = {bal（平衡）, con（接触）, act（执行器）, hum（人身安全）}；冗余并联通道 C_red = {task（任务）, energy（能量/热）}
- **通道可靠度**：R_c ∈ [0,1] 为通道 c 在预测时域 T 内不失效的概率
- **合成算子 ⊗**：安全关键通道按**串联 Fréchet 保守下界**合成 `R_wb^cons = max(0, Σ_{c∈C_crit} R_c − (|C_crit| − 1))`；冗余通道按独立性修正 `R_wb = R_wb^cons · Π_{c∈C_red} R_c`
- **否决阈值**：θ_rel 为可靠性否决线，R_wb < θ_rel 时触发 GRC 否决
- **可靠性不等式与可靠性幻觉**：`R_wb ≤ min_{c∈C_crit} R_c ≤ mean_{c∈C_crit} R_c`；定义 Δ_ill = mean − R_wb^cons ≥ 0 为「可靠性幻觉」的度量

**定义 162（捕捉点可靠性场 CPF）** 给定浮动基状态 x = (x_com, ẋ_com) 与控制 u，发散运动分量 ξ = x_com + ẋ_com/ω，ω = √(g/z_com)。可靠性场：
- ρ(x,u) = P( ∃τ∈[0,T]: ξ(τ) ∈ S_support 且 ∀t∈[0,T]: x(t) ∈ X_safe | x,u )
- **可恢复裕度** m(x) = dist(ξ(x), ∂S_support)；**认证安全集** X_cert = { x : ρ(x) ≥ 1 − δ_bal }
- **可靠性屏障函数** h(x) = m(x) − m_safe，约束 `h(x) ≥ 0 ∧ ḣ + α·h ≥ 0`（控制屏障函数，保证 X_cert 前向不变）

**定义 163（冗余接触可靠性分配 RCRA）** 接触集 K，接触力 f_i，抓取矩阵 G，期望力旋量 w_d，摩擦锥 C_i。接触可靠度 R_i(f_i) = exp(−λ_u·u_i²)，u_i = ‖f_i^t‖/(μ_i·f_i^n) 为摩擦利用率。RCRA 为 max-min 问题：
```
max_{F, t}  t
s.t.  G·[f_1; …; f_K] = w_d
      R_i(f_i) ≥ t,   ∀i
      f_i ∈ C_i（摩擦锥 + 法向上下界 f_n^min ≤ f_i^n ≤ f_n^max）
```
当 t ∈ (0,1] 时 `R_i ≥ t ⟺ ‖f_i^t‖² ≤ (−ln t / λ_u)·(f_i^n)²`，固定 t 为旋转二阶锥约束。故对 t 二分，每次求解一个 SOCP 可行性问题。

**定义 164（退化可靠性阶梯 DRL）** 可靠性状态机 L = {L0..L5}，转移关系 T ⊆ L×L，每条转移带证书：
- L0 正常；L1 任务降级（丢弃子目标、降 v_max）；L2 身体重构（单臂/借支撑/重心下沉）；L3 寻求支撑（扶墙、下蹲、抓住环境）；L4 保护性停止（锁死关节、最大刚度保持）；L5 保护性倒地（蜷缩护头、卸载动能）
- **证书化转移**：L_i → L_j 允许当且仅当 `Cert(L_j)` 成立：R_wb(after) ≥ R_wb(before) ∧ X_cert(after) ⊆ X_safe ∧ 转移过程不进入 X_unsafe
- **提前降级**：当可靠性场时域最小值 `min_{τ≤T_h} ρ(x(τ)) < 1 − δ_pre` 时，在仍有余量时触发降级

**定义 165（守护可靠性契约 GRC）** 守护者 Γ = (M_rel, veto, τ_guard)。M_rel 实时估计 R_wb；veto 为否决算子：
```
if R_wb < θ_rel:
    C_safe = argmin_{C ∈ ERTC.contracts} risk(C)
    ERTC.preempt(C_safe);  CIEC.suspend(C_intent)     # 认知意图被否决
```
**守护者优先于认知**：GRC 优先级高于 CIEC 与 B_ft/B_ux 任务；`τ_guard < τ_recover` 是守护生效的必要条件（必须在系统仍可恢复前完成否决）。

**定义 166（可靠性闭环 RCL）** 算子 RCL(M, task, intent, delta_f_req)：
```
① WRS:  R_wb ← compose(R_bal, R_con, R_act, R_hum, R_task)
② CPF:  ρ(x) ← reliability_field(M.state); 检查 X_cert / CBF
③ GRC:  if R_wb < θ_rel: veto + DRL.preempt()
④ RCRA: F* ← max_min_reliability_alloc(w_d, contacts)
⑤ SGEC+: (K_safe, EV-exec) ← SERC(M, scene, intent, delta_f_req)   # 承接第 60 轮
⑥ DRL:  level ← ladder.transition(R_wb, Cert); 执行 level 对应策略
⑦ REC:  S_rec.append(reliability_trace, prev_hash)
⑧ Return: (R_wb, ρ, level, F*, EV-exec, REC.status)
```

**定义 167（可靠性预算 PCE-R）** 在 PCE++++ 的四预算上新增可靠性预算 B_rel = (B_bal, B_con, B_act, B_rec)：
- B_bal：可消耗的平衡裕度（允许消耗的 m(x) 总量）
- B_con：允许减少的接触数/接触置信度预算
- B_act：执行器健康度预算（温度、电流、退化率）
- B_rec：恢复时间预算（从当前状态恢复到 L0 的最大可接受时间）

VOI-R：
```
voi_rel(π) = E[ΔR_wb(π)] − λ_rel·cost_rel(π) − cost_cog(π) − cost_exec(π)
若 B_bal ≤ 0：禁止任何降低 m(x) 的探测动作；B_con ≤ 0：锁定当前接触集；
B_act ≤ 0：执行器降额；B_rec ≤ 0：禁止非恢复性任务
```

**定义 168（可靠性证据链 REC）** 在 EPIR 的消息头 (timestamp, seq_id, hash) 上增加 **prev_hash 链式哈希** 与可靠性轨迹：
- **可靠性轨迹** τ_rel = { (ξ_t, f_t, τ_joint_t, temp_t, ρ_t, R_wb_t) }
- **链式哈希** H_t = SHA256(H_{t−1} ‖ content_t)，实现**防篡改、可追溯**的可靠性取证
- **事前快照**：环形缓冲保存摔倒前 T_pre 秒的 τ_rel，用于「为什么摔倒 / 为什么没摔」的因果重建
- **三段校验**：序列连续（EPIR）+ 因果顺序（时间戳）+ 链式哈希（不可否认）

### IP-161 WRS（全身可靠性状态）

```python
class WholeBodyReliabilityState:
    def __init__(self, theta_rel=0.90):
        self.theta_rel = theta_rel
        self.ch = {'bal': 1.0, 'con': 1.0, 'act': 1.0,
                   'hum': 1.0, 'task': 1.0}

    def compose(self):
        crit = [self.ch[c] for c in ('bal', 'con', 'act', 'hum')]
        n = len(crit)
        r_series = max(0.0, sum(crit) - (n - 1))      # Fréchet 保守下界
        r_red = self.ch['task']                        # 冗余通道（独立性）
        r_wb = r_series * r_red
        mean_crit = sum(crit) / n
        return r_wb, mean_crit - r_series              # (R_wb, Δ_ill)

    def update(self, **channels):
        self.ch.update(channels)
        return self.compose()
```

### IP-162 CPF（捕捉点可靠性场）

```python
class CapturePointReliabilityField:
    def __init__(self, com_height=0.9, horizon=0.6, dt=0.01,
                 m_safe=0.05, delta_bal=0.01, sigma=0.02):
        self.omega = math.sqrt(9.81 / com_height)
        self.T, self.dt = horizon, dt
        self.m_safe, self.delta_bal, self.sigma = m_safe, delta_bal, sigma

    def dcm(self, x_com, v_com):
        return x_com + v_com / self.omega

    def margin(self, dcm_xy, polygon):
        return point_to_polygon_distance(dcm_xy, polygon)

    def reliability_field(self, state, u_seq, polygon):
        xi = self.dcm(state.x_com, state.v_com)
        traj = self._rollout(xi, u_seq, self.T, self.dt)
        m_min = min(self.margin(p, polygon) for p in traj)
        Phi = 0.5 * (1 + math.erf((m_min - self.m_safe)
                                  / (self.sigma * math.sqrt(2))))
        return Phi, m_min

    def is_certified_safe(self, state, u_seq, polygon):
        rho, m_min = self.reliability_field(state, u_seq, polygon)
        return rho >= 1 - self.delta_bal and m_min >= self.m_safe
```

### IP-163 RCRA（冗余接触可靠性分配）

```python
def max_min_reliability_allocation(w_d, G, mu, fn_lo, fn_hi, lam_u, eps=1e-3):
    import cvxpy as cp
    K = len(mu)

    def feasible(t):
        f = [cp.Variable(3) for _ in range(K)]
        cons = []
        Fvec = cp.hstack(f)
        cons.append(G @ Fvec == w_d)
        for i in range(K):
            n = f[i][2]
            cons += [n >= fn_lo[i], n <= fn_hi[i]]
            cons += [cp.norm(f[i][:2], 2) <= mu[i] * n]        # 摩擦锥
            # R_i >= t  <=>  ||f_t||^2 <= (-ln t / lam) * n^2
            cons += [cp.sum_squares(f[i][:2])
                     <= (-math.log(t) / lam_u) * cp.square(n)]
        return cp.Problem(cp.Minimize(0), cons)

    lo, hi = 1e-6, 1.0 - 1e-9
    while hi - lo > eps:                                       # 对 t 二分
        mid = 0.5 * (lo + hi)
        if feasible(mid).solve(solver=cp.ECOS) is not None:
            lo = mid
        else:
            hi = mid
    return lo
```

### IP-164 DRL（退化可靠性阶梯）

```python
class DegradationReliabilityLadder:
    LEVELS = ['L0_nominal', 'L1_task_degrade', 'L2_body_reconfigure',
              'L3_support_seek', 'L4_protective_stop', 'L5_protective_fall']

    def __init__(self):
        self.level = 0

    def _select(self, r_wb, rho_min):
        if rho_min < 0.05 or r_wb < 0.50: return 5
        if rho_min < 0.10 or r_wb < 0.65: return 4
        if rho_min < 0.20 or r_wb < 0.75: return 3
        if rho_min < 0.35 or r_wb < 0.85: return 2
        if rho_min < 0.50 or r_wb < 0.92: return 1
        return 0

    def preempt(self, r_wb, rho_min, cert_fn):
        target = self._select(r_wb, rho_min)
        while self.level < target:
            nxt = self.level + 1
            if not cert_fn(self.LEVELS[nxt]):    # 证书不成立则不降级
                break
            self.level = nxt
        return self.LEVELS[self.level]
```

### IP-165 GRC（守护可靠性契约）

```python
class GuardianReliabilityContract:
    def __init__(self, rws, ertc, ciec, ladder,
                 theta_rel=0.90, tau_guard=0.15):
        self.rws, self.ertc, self.ciec, self.ladder = rws, ertc, ciec, ladder
        self.theta_rel, self.tau_guard = theta_rel, tau_guard

    def step(self, r_wb, rho_min):
        if r_wb < self.theta_rel:                # 一票否决
            c_safe = min(self.ertc.active_contracts, key=self._risk)
            self.ertc.preempt(c_safe)
            self.ciec.suspend()
            level = self.ladder.preempt(r_wb, rho_min, self._cert)
            return {'veto': True, 'level': level, 'contract': c_safe}
        return {'veto': False, 'level': self.ladder.level}

    def _risk(self, contract):
        return contract.wcet_overrun + contract.task_risk
```

### IP-167 PCE-R（可靠性预算）

```python
class ReliabilityBudget:
    def __init__(self, bal=1.0, con=1.0, act=1.0, rec=1.0):
        self.B_bal, self.B_con, self.B_act, self.B_rec = bal, con, act, rec

    def allowed(self, action) -> bool:
        if action.lowers_margin and self.B_bal <= 0:    return False
        if action.drops_contacts and self.B_con <= 0:   return False
        if action.overdrives_actuator and self.B_act <= 0: return False
        if action.non_recovery and self.B_rec <= 0:     return False
        return True
```

### IP-168 REC（可靠性证据链）

```python
class ReliabilityEvidenceChain:
    def __init__(self, pre_window=200):
        self.head = '0' * 64
        self.chain = []
        self.pre_buffer = deque(maxlen=pre_window)   # 摔倒前快照

    def append(self, trace):
        body = json.dumps(trace, sort_keys=True).encode()
        h = hashlib.sha256(self.head.encode() + body).hexdigest()
        self.chain.append({'trace': trace, 'prev': self.head, 'hash': h})
        self.pre_buffer.append(h)
        self.head = h
        return h

    def verify(self, chain):
        prev = '0' * 64
        for rec in chain:
            body = json.dumps(rec['trace'], sort_keys=True).encode()
            h = hashlib.sha256(prev.encode() + body).hexdigest()
            if h != rec['hash'] or rec['prev'] != prev:
                return False, rec
            prev = h
        return True, None
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| WRS | O(|C_crit|) | O(1) | R_wb^cons ≤ R_true（Fréchet 下界，保守不冒进） |

**正确性定理（SGEC-R）**：
假设 A66–A70 成立：**(A66)** Fréchet 界有效；安全关键通道可任意相关，冗余通道近似独立。**(A67)** ρ 关于状态 Lipschitz，存在可行 CBF。**(A68)** RCRA 可行域非空且 t* 可二分求得。**(A69)** DRL 每条转移带证书；τ_guard < τ_recover。**(A70)** 链式哈希碰撞概率可忽略。

1. **保守可靠性**：`R_wb^cons ≤ P(∩_{c∈C_crit} A_c) ≤ min_c R_c`；平均法误差 Δ_ill ≥ 0 即可靠性幻觉，故基于平均的决策会系统性高估可靠度。
2. **守护安全**：若 GRC 在 τ_guard 内完成否决，则闭环轨迹不进入 X_unsafe。
3. **接触可靠最优**：RCRA 的解 (F*, t*) 为 max-min 最优；任何其他可行分配的 `min_i R_i` 均 ≤ t*。
4. **退化单调**：证书化 DRL 只允许 `R_wb(after) ≥ R_wb(before)` 的转移，故可靠性沿阶梯单调不降。
5. **取证不可否认**：REC 链任意篡改都会被 verify 以 1−negl 概率检出。

## 2. 关键推导

### 2.1 可靠性不能用平均（Fréchet 界）

设安全关键通道事件 A_c（通道 c 存活），P(A_c)=R_c。人形机器人不摔倒要求所有安全关键通道同时存活，即系统可靠度 R_true = P(∩_{c} A_c)。对**任意**相关结构，Fréchet 下界成立：
```
max(0, Σ_c R_c − (|C|−1))  ≤  P(∩_c A_c)  ≤  min_c R_c
```
即 **min_c R_c 已是上界，平均 mean_c R_c ≥ min_c R_c 必为高估**。因此在未知相关结构时，唯一安全的估计是下界 R_wb^cons；用加权平均会系统性高估，直接导致守护者「该否决时没否决」。

### 2.2 RCRA 的二分 + SOCP 等价

`R_i(f_i) ≥ t ⟺ exp(−λ_u u_i²) ≥ t ⟺ u_i² ≤ −ln t / λ_u`。代入 `u_i = ‖f_i^t‖/f_i^n` 得
```
‖f_i^t‖² ≤ (−ln t / λ_u)·(f_i^n)²
```
固定 t∈(0,1] 时右侧系数为正，这是旋转二阶锥约束；再加摩擦锥 `‖f_i^t‖ ≤ μ_i f_i^n` 与力平衡 `G·F = w_d`，构成 SOCP 可行性问题。对 t 二分即得 max-min 最优 t*（单调性：t 越大可行域越小）。

### 2.3 守护者的前向不变性

设 τ_recover 为系统从当前状态仍可恢复到 X_cert 的最长时间。若 GRC 在 τ_guard 内把控制切换到 C_safe 且 C_safe 满足 CBF 条件 `ḣ + αh ≥ 0`，则对任意 t，`h(x(t)) ≥ h(x(0))e^{−αt} ≥ 0`，故轨迹不离开 X_safe。条件 `τ_guard < τ_recover` 保证否决发生在「还来得及」的窗口内。

```python
class WholeBodyReliabilityState:
    def __init__(self, theta_rel=0.90):
        self.theta_rel = theta_rel
        self.ch = {'bal': 1.0, 'con': 1.0, 'act': 1.0,
                   'hum': 1.0, 'task': 1.0}

    def compose(self):
        crit = [self.ch[c] for c in ('bal', 'con', 'act', 'hum')]
        n = len(crit)
        r_series = max(0.0, sum(crit) - (n - 1))      # Fréchet 保守下界
        r_wb = r_series * self.ch['task']
        mean_crit = sum(crit) / n
        return r_wb, mean_crit - r_series              # (R_wb, Δ_ill)

    def update(self, **channels):
        self.ch.update(channels)
        return self.compose()
```

### IP-162 CPF（捕捉点可靠性场）

```python
class CapturePointReliabilityField:
    def __init__(self, com_height=0.9, horizon=0.6, dt=0.01,
                 m_safe=0.05, delta_bal=0.01, sigma=0.02):
        self.omega = math.sqrt(9.81 / com_height)
        self.T, self.dt = horizon, dt
        self.m_safe, self.delta_bal, self.sigma = m_safe, delta_bal, sigma

    def dcm(self, x_com, v_com):
        return x_com + v_com / self.omega

    def margin(self, dcm_xy, polygon):
        return point_to_polygon_distance(dcm_xy, polygon)

    def reliability_field(self, state, u_seq, polygon):
        xi = self.dcm(state.x_com, state.v_com)
        traj = self._rollout(xi, u_seq, self.T, self.dt)
        m_min = min(self.margin(p, polygon) for p in traj)
        Phi = 0.5 * (1 + math.erf((m_min - self.m_safe)
                                  / (self.sigma * math.sqrt(2))))
        return Phi, m_min

    def is_certified_safe(self, state, u_seq, polygon):
        rho, m_min = self.reliability_field(state, u_seq, polygon)
        return rho >= 1 - self.delta_bal and m_min >= self.m_safe
```

### IP-163 RCRA（冗余接触可靠性分配）

```python
def max_min_reliability_allocation(w_d, G, mu, fn_lo, fn_hi, lam_u, eps=1e-3):
    import cvxpy as cp
    K = len(mu)

    def feasible(t):
        f = [cp.Variable(3) for _ in range(K)]
        cons = [G @ cp.hstack(f) == w_d]
        for i in range(K):
            n = f[i][2]
            cons += [n >= fn_lo[i], n <= fn_hi[i]]
            cons += [cp.norm(f[i][:2], 2) <= mu[i] * n]        # 摩擦锥
            cons += [cp.sum_squares(f[i][:2])
                     <= (-math.log(t) / lam_u) * cp.square(n)]
        return cp.Problem(cp.Minimize(0), cons)

    lo, hi = 1e-6, 1.0 - 1e-9
    while hi - lo > eps:                                       # 对 t 二分
        mid = 0.5 * (lo + hi)
        if feasible(mid).solve(solver=cp.ECOS) is not None:
            lo = mid
        else:
            hi = mid
    return lo
```

```python
class DegradationReliabilityLadder:
    LEVELS = ['L0_nominal', 'L1_task_degrade', 'L2_body_reconfigure',
              'L3_support_seek', 'L4_protective_stop', 'L5_protective_fall']

    def __init__(self):
        self.level = 0

    def _select(self, r_wb, rho_min):
        if rho_min < 0.05 or r_wb < 0.50: return 5
        if rho_min < 0.10 or r_wb < 0.65: return 4
        if rho_min < 0.20 or r_wb < 0.75: return 3
        if rho_min < 0.35 or r_wb < 0.85: return 2
        if rho_min < 0.50 or r_wb < 0.92: return 1
        return 0

    def preempt(self, r_wb, rho_min, cert_fn):
        target = self._select(r_wb, rho_min)
        while self.level < target:
            nxt = self.level + 1
            if not cert_fn(self.LEVELS[nxt]):    # 证书不成立则不降级
                break
            self.level = nxt
        return self.LEVELS[self.level]
```

### IP-165 GRC（守护可靠性契约）

```python
class GuardianReliabilityContract:
    def __init__(self, rws, ertc, ciec, ladder,
                 theta_rel=0.90, tau_guard=0.15):
        self.rws, self.ertc, self.ciec, self.ladder = rws, ertc, ciec, ladder
        self.theta_rel, self.tau_guard = theta_rel, tau_guard

    def step(self, r_wb, rho_min):
        if r_wb < self.theta_rel:                # 一票否决
            c_safe = min(self.ertc.active_contracts, key=self._risk)
            self.ertc.preempt(c_safe)
            self.ciec.suspend()
            level = self.ladder.preempt(r_wb, rho_min, self._cert)
            return {'veto': True, 'level': level, 'contract': c_safe}
        return {'veto': False, 'level': self.ladder.level}

    def _risk(self, contract):
        return contract.wcet_overrun + contract.task_risk
```

```python
class ReliabilityBudget:
    def __init__(self, bal=1.0, con=1.0, act=1.0, rec=1.0):
```

### IP-168 REC（可靠性证据链）

```python
class ReliabilityEvidenceChain:
    def __init__(self, pre_window=200):
        self.head = '0' * 64
        self.chain = []
        self.pre_buffer = deque(maxlen=pre_window)   # 摔倒前快照

    def append(self, trace):
        body = json.dumps(trace, sort_keys=True).encode()
        h = hashlib.sha256(self.head.encode() + body).hexdigest()
        self.chain.append({'trace': trace, 'prev': self.head, 'hash': h})
        self.pre_buffer.append(h)
        self.head = h
        return h

    def verify(self, chain):
        prev = '0' * 64
        for rec in chain:
            body = json.dumps(rec['trace'], sort_keys=True).encode()
            h = hashlib.sha256(prev.encode() + body).hexdigest()
            if h != rec['hash'] or rec['prev'] != prev:
                return False, rec
            prev = h
        return True, None
```

**一句话**：整套守护机制的安全性完全押在「R_wb 估计器本身是否可信」上——若摩擦系数/质心/接触状态被系统性误辨识而**高估**了可靠度，GRC 的否决线将永远不被触发，「可靠性守护者」反而把「确定性证据掩盖不确定性」变成一种虚假安全感；因此必须让 WRS 只取 Fréchet 保守下界、对模型不确定性做方差膨胀，并用 REC 事后取证反向校验否决是否本该发生。
