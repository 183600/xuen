# 第 56 轮（承接第 55 轮想法区「语义-接触接地」与第 54 轮产物 v31；灵感循环新第 1 轮；本轮灵感：「仿真训练」×「单模型多任务」）

> 第 55 轮把部署安全性推进到“语义-接触证书”。本轮把视角从“部署时如何验证”前移到“能力从何而来”：**仿真训练**决定能力分布，**单模型多任务**决定参数共享，而两者都把“证据的偏差”写进同一组参数。核心矛盾：**H24**：仿真既是数据源又是评价器——若用仿真评价仿真训练出的模型，则保真度误差与优化误差同源、可能互相抵消，形成“仿真自证”；**H25**：单模型多任务共享主干，使各任务鲁棒性在参数空间耦合，平均任务性能的提升可能以最坏任务鲁棒性的塌陷为代价，因此“多任务泛化”与“sim-to-real”不能分别认证。

## 0. 直觉与动机

**灵感 1（仿真训练 → 仿真器是有偏预言机，而非环境本身）**
直觉：仿真训练真正学到的不是“任务”，而是“任务在仿真器参数下的最优反应”。质量、摩擦、延迟、渲染各有偏差；同一策略在不同仿真参数下成功，并不代表同一能力。因此必须把仿真器参数 `θ_sim` 当作 **训练变量** 而非背景，并为每个任务估计一张 **保真场** `Φ(τ,θ_sim)`：只有 `Φ` 高的区域，仿真证据才可迁移。

**灵感 2（单模型多任务 → 共享主干把鲁棒性从标量变成向量）**
直觉：单模型不是“一个更省参数的模型”，而是“把 T 个风险源绑在同一组参数上”。对单任务，鲁棒性是标量；对多任务，它是任务单形上的函数 `ρ_T(w)`。训练通常只优化加权平均 `Σ w_τ R_τ`，恰好忽略单形的顶点（最坏任务）。共享越深，任务干扰 `I_{ij}` 越强，“平均好、最坏崩”越隐蔽。

**灵感 3（两者耦合 → 证书必须定义在（任务 × 仿真参数）乘积空间）**
直觉：仿真偏差是 **任务相关** 的（接触任务怕摩擦误差，视觉任务怕渲染误差），任务干扰也是 **仿真条件** 的（某任务在低摩擦仿真里学到的捷径会污染共享主干）。因此可迁移域不是一个数，而是乘积空间中的区域 `TTR`；训练的目标不该只是最小化平均损失，而应是 **在仿真预算内扩张 `TTR` 的可证书覆盖**。

**灵感 4（仿真训练 → 证书驱动课程，而非均匀域随机化）**
直觉：域随机化把预算均匀撒在参数盒里，效率低且可能把模型拉向不可能迁移的区域。更合理的是 **证书驱动**：优先采样 `TTR` 边界与“最能推翻当前证书”的 `(τ,θ_sim)`，用最少仿真把证书覆盖推到最大。这把训练从“刷数据”变成“刷证据覆盖”。

**灵感 5（单模型多任务 → 共享/专有的可判定取舍）**
直觉：并非所有任务都该共享。用 **任务干扰账本** `I_{ij}` 量化共享某层对彼此的收益/伤害；当 `I_{ij}` 超过预算，就把该层在任务子集上分叉成轻量适配器。多任务结构不是先验拍定，而是由证书与干扰账本共同决定。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（任务-仿真保真场）**
对任务 `τ∈T` 与仿真参数 `θ_sim∈Θ_sim`，`Φ: T×Θ_sim → [0,1]` 为标定后的可迁移置信，满足 `Φ(τ,θ_sim) = P(real_success | sim_success, τ, θ_sim)`，由真实锚点集做温度/等渗校准，校准误差 `ECE(Φ) ≤ ε_Φ`。

**定义 128（可信训练域 TTR）**
`TTR_Φ = {(τ,θ_sim) | Φ(τ,θ_sim) ≥ θ_Φ}`。部署时的任务-参数对若落在 `TTR` 外，其仿真证据不被采信。

**定义 129（仿真捷径与任务干扰账本）**
特征/行为 `z` 对任务 `τ` 的捷径残差
`s_τ = E[ΔR_τ^{real} | do(z=z_shortcut)] − E[ΔR_τ^{sim} | do(z=z_shortcut)]`，
即在真实与仿真中对同一捷径做因果干预后的收益差。任务干扰
`I_{ij}(ℓ) = R_i(θ_{share,ℓ}) − R_i(θ_{split,ℓ}) + R_j(θ_{share,ℓ}) − R_j(θ_{split,ℓ})`，
表示在第 `ℓ` 层共享相对分叉的联合收益（可正可负）。

**定义 130（任务单形鲁棒谱）**
部署任务混合 `w∈Δ(T)`。`ρ_T(ε) = inf_{w∈Δ(T)} inf_{‖δ‖≤ε} P(success | θ, τ~w, δ)`，为任务单形与扰动球上的最坏成功保持概率；任务平均鲁棒性 `ρ̄_T = Σ_τ w_τ ρ_τ` 仅作参考，证书以 `ρ_T` 为准。

**定义 131（证书驱动域随机化 CDR）**
在仿真预算 `B` 下选择采样分布 `q(τ,θ_sim)`：
`q* = argmax_q min_{τ∈T_core} coverage_τ(q)`，
其中 `coverage_τ(q) = P_{(τ,θ_sim)~q}(Φ(τ,θ_sim) ≥ θ_Φ ∧ ρ_τ(θ) ≥ ρ_min)`；采样优先集中于 `TTR` 边界与证书反例附近。

**定义 132（多任务仿真联合证书 MTC）**
`J_mt = (T_core, θ_core, TTR_core, ρ_T, s_τ, g_τ, δ_sim, evidence)`：
- `T_core ⊆ T` 为有足够保真证据的核心任务集，`θ_core` 为核心参数子空间；
- `ρ_T` 任务单形最坏鲁棒谱，`s_τ` 捷径残差上界，`g_τ = 1 − max_{θ_sim} Φ(τ,θ_sim)` 任务条件现实间隙；
- `δ_sim` 仿真参数扰动实测量，`evidence` 含真实锚点、反例、干扰账本。
若 `T_core` 覆盖部署任务、`ρ_T ≥ ρ_min`、`max_τ s_τ ≤ θ_s`、`max_τ g_τ ≤ Θ_g` 且 `δ_sim ≤ Θ_sim`，则多任务仿真可部署。

### IP-127 FFC（Fidelity Field Calibration）

```python
def calibrate_fidelity(real_anchors, sim_sweep, theta_phi):
    # real_anchors: 少量真实 (tau, theta_sim, success)；sim_sweep: 每任务参数网格
    raw = {}
    for tau, theta in sim_sweep:
        raw[(tau, theta)] = estimate_transfer_prob(real_anchors, tau, theta)
    Phi = isotonic_temperature_calibrate(raw, real_anchors)   # ECE <= eps_Phi
    TTR = {(tau, theta) for (tau, theta), p in Phi.items() if p >= theta_phi}
    return Phi, TTR
```

### IP-128 TTP（Task-Simplex Profiling）

```python
def profile_task_simplex(theta_policy, tasks, sim_grid, eps):
    rho, gap = {}, {}
    for tau in tasks:
        vals = [empirical_success(theta_policy, tau, theta, eps)
                for theta in sim_grid[tau]]
        rho[tau] = min(vals)                             # 该任务最坏仿真条件
        gap[tau] = 1 - max(fidelity(Phi, tau, theta) for theta in sim_grid[tau])
    rho_T = worst_over_simplex(rho, delta_T)             # inf_{w in Delta(T)}
    return rho_T, rho, gap
```

### IP-129 SCD（Simulation Shortcut Detection）

```python
def detect_shortcuts(theta_policy, tasks, do_interventions, budget):
    s = {}
    for tau in tasks:
        real_delta, sim_delta = [], []
        for z in propose_shortcut_features(theta_policy, tau, budget):
            real_delta.append(causal_drop(theta_policy, tau, 'real', do(z)))
            sim_delta.append(causal_drop(theta_policy, tau, 'sim', do(z)))
        s[tau] = max(0.0, max(real_delta) - max(sim_delta))
    return s
```

### IP-130 TIL（Task Interference Ledger）

```python
def interference_ledger(theta, layers, tasks):
    I = {}
    for ell in layers:
        for i in tasks:
            for j in tasks:
                if i >= j: continue
                gi, gj = task_grad(theta, i, ell), task_grad(theta, j, ell)
                conflict = cosine(gi, gj)                # <0 表示梯度冲突
                I[(ell, i, j)] = estimate_share_gain(theta, ell, i, j, conflict)
    split = {(ell, i, j) for (ell, i, j), v in I.items() if v < -theta_I}
    return I, split                                     # 冲突超预算的层-任务对 → 适配器
```

### IP-131 CDR（Certificate-Directed Domain Randomization）

```python
def certificate_directed_curriculum(Phi, TTR, theta_policy, budget, rho_min):
    q = init_uniform(TTR)
    while budget.remaining() > 0:
        cand = boundary_and_counterexample_pool(Phi, TTR, theta_policy, q)
        (tau, theta) = argmax(cand, key=lambda x: coverage_sensitivity(x, theta_policy, rho_min))
        train_step(theta_policy, tau, theta)
        update_fidelity(Phi, tau, theta)
        q = reweight_by_uncertainty(Phi, TTR)
        budget.consume(tau, theta)
    return theta_policy, Phi, q
```

### IP-132 MTC（Multi-Task Sim-to-Real Certificate）

```python
def multitask_certificate(theta_policy, T, Phi, TTR, rho, s, g, budgets):
    T_core = {tau for tau in T if Phi[tau].calibrated and g[tau] <= budgets.Theta_g}
    if not T_core:
        return ('reject', 'no_core_task')
    rho_T = worst_over_simplex({tau: rho[tau] for tau in T_core}, budgets.delta_T)
    if rho_T < budgets.rho_min:
        return ('reject', 'task_simplex_robustness_fail', rho_T)
    if max(s[tau] for tau in T_core) > budgets.theta_s:
        return ('reject', 'shortcut_residue', s)
    if any((tau, th) not in TTR for tau in T_core for th in budgets.deploy_sim[tau]):
        return ('reject', 'outside_trusted_training_region')
    return ('ok', MTCert(T_core, theta_policy.core_subspace(), TTR, rho_T, s, g))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| FFC | O(N_anchor·|T|·|Θ_sim|) | O(|T|·|Θ_sim|) | 锚点校准、分布外不内插 |
| TTP | O(|T|·|Θ_sim|·N_eval) | O(|T|·|Θ_sim|) | 顶点覆盖、单形下界 sound |
| SCD | O(|T|·|Z|·(C_real+C_sim)) | O(|Z|) | 干预可识别、残差上界 |
| TIL | O(|ℓ|·|T|²·d) | O(|ℓ|·|T|²) | 梯度冲突可测、split 判定 sound |
| CDR | O(|B|·cost_step) | O(|TTR|) | 边界采样收敛、覆盖单调 |
| MTC | O(|T|·|Θ_sim| + S) | O(|T|) | 核心任务非空、预算闭合 |

**正确性定理（Multi-Task Sim-to-Real Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** `Φ` 经真实锚点校准且 `ECE ≤ ε_Φ`，锚点覆盖 `T_core`；**(A34)** 部署任务混合 `w∈Δ(T_core)` 且仿真参数落在 `TTR`；**(A35)** 捷径残差 `s_τ` 上界 sound，未被检测的捷径其真实增益 ≤ θ_s；**(A36)** CDR 在预算内使证书覆盖单调不降、且干扰账本判定 sound；**(A37)** 单模型共享层在 `θ_core` 上对任务扰动 Lipschitz。
则最坏任务部署成功概率：
```
P_success ≥ 1 − max_{τ∈T_core}[ (1−ρ_τ) + s_τ + g_τ ]
            − P(w ∉ Δ(T_core)) − P(Φ miscalibrated) − β_CDR
```
关键：**保真场把仿真证据限定在可迁移域、任务单形把鲁棒性取到最坏顶点、捷径残差把“仿真里的聪明”折算成“现实里的风险”**，三者共同阻止“仿真平均好”被误当作“多任务可部署”。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 保真场真实锚点不足、分布外外推 | 高 | 锚点最小覆盖 + 分布外拒证 + 主动采锚 |
| 捷径对因果干预不可见 | 高 | 多干预族 + 反事实审计 + 捷径残差上限 |
| 任务单形设定过窄（部署任务越界） | 高 | 单形保守扩张 + 越界检测 + 在线任务识别 |
| CDR 过拟合证书边界 | 中 | 边界留出集 + 证书反例回放 + 覆盖置信下界 |
| 共享主干任务干扰/容量不足 | 中 | 干扰账本驱动分层 + 轻量适配器 + 参数预算 |

## 6. 本轮最大风险

**一句话**：保真场、任务单形、捷径检测三者本质上都是“用仿真估计仿真自身的可信度”，一旦真实锚点不足或在分布外被外推、或捷径对因果干预不可见，MTC 就会在“仿真自证”的闭环里给一个“均匀优秀且均匀错误”的单模型发证；因此必须以 **真实锚点最小覆盖 + 分布外拒证 + 反事实捷径审计** 三重护栏，宁可在 `TTR` 外拒绝部署，也绝不把仿真的“平均优秀”当作现实的“鲁棒”。

```python
def semantic_contact_map(rgbd, seg_model, kappa, theta_k, theta_conf):
    Sigma = seg_model.predict_soft(rgbd)

def viability_kernel(Sigma, C_plus, x0, horizon, eps):

    if rho_sem(delta_s) < budgets.rho_min:
        return ('reject', 'semantic_robustness_fail')
    return ('ok', SemanticCert(Sigma_core, C_core, K_margin, rho_sem, delta_s))

# IP-125 SRS
def semantic_robustness_spectrum(Sigma_hat, eps_s, sampler):
    worst = 1.0
    for Sigma_adv in sampler.ball(Sigma_hat, eps_s, worst_case=True):
        worst = min(worst, empirical_viability(renormalize(Sigma_adv), sampler.states))
    return worst

# IP-126 CEB
def cloud_edge_semantics(Sigma_c, kappa_c, edge):
    Sigma_e, C_e = edge.local_semantics()
    mismatch = boundary_disagreement(Sigma_c, Sigma_e)
    if mismatch.area > delta_A:
        return ('reprofile', region=mismatch.hotspots, evidence=edge.explain_contact_failure())
    return ('ok', conservative_contacts(C_e, edge.margin, kappa_c, theta_m),
            merge_uncertainty(Sigma_c, Sigma_e))
```

```python
# IP-127 FFC：保真场 + 可信训练域
def calibrate_fidelity(real_anchors, sim_sweep, theta_phi):
    raw = {(tau, theta): estimate_transfer_prob(real_anchors, tau, theta)
           for tau, theta in sim_sweep}
    Phi = isotonic_temperature_calibrate(raw, real_anchors)     # ECE <= eps_Phi
    TTR = {(tau, theta) for (tau, theta), p in Phi.items() if p >= theta_phi}
    return Phi, TTR

# IP-128 TTP：任务单形最坏鲁棒
def profile_task_simplex(theta_policy, tasks, sim_grid, eps):
    rho = {tau: min(empirical_success(theta_policy, tau, th, eps)
                    for th in sim_grid[tau]) for tau in tasks}
    gap = {tau: 1 - max(fidelity(Phi, tau, th) for th in sim_grid[tau])
           for tau in tasks}
    rho_T = worst_over_simplex(rho, delta_T)                    # inf_{w in Delta(T)}
    return rho_T, rho, gap

# IP-129 SCD：反事实捷径残差
def detect_shortcuts(theta_policy, tasks, do_interventions, budget):
    s = {}
    for tau in tasks:
        real_d = [causal_drop(theta_policy, tau, 'real', do(z))
                  for z in propose_shortcut_features(theta_policy, tau, budget)]
        sim_d  = [causal_drop(theta_policy, tau, 'sim', do(z))
                  for z in propose_shortcut_features(theta_policy, tau, budget)]
        s[tau] = max(0.0, max(real_d) - max(sim_d))
    return s

# IP-130 TIL：任务干扰账本
def interference_ledger(theta, layers, tasks):
    I = {}
    for ell in layers:
        for i, j in pairs(tasks):
            conflict = cosine(task_grad(theta, i, ell), task_grad(theta, j, ell))
            I[(ell, i, j)] = estimate_share_gain(theta, ell, i, j, conflict)
    split = {(ell, i, j) for (ell, i, j), v in I.items() if v < -theta_I}
    return I, split                       # 冲突超预算 → 该层在任务对上分叉适配器

# IP-131 CDR：证书驱动课程
def certificate_directed_curriculum(Phi, TTR, theta_policy, budget, rho_min):
    q = init_uniform(TTR)
    while budget.remaining() > 0:
        cand = boundary_and_counterexample_pool(Phi, TTR, theta_policy, q)
        tau, theta = argmax(cand, key=lambda x: coverage_sensitivity(x, theta_policy, rho_min))
        train_step(theta_policy, tau, theta)
        update_fidelity(Phi, tau, theta)
        q = reweight_by_uncertainty(Phi, TTR)
        budget.consume(tau, theta)
    return theta_policy, Phi, q

# IP-132 MTC：多任务仿真联合证书
def multitask_certificate(theta_policy, T, Phi, TTR, rho, s, g, budgets):
    T_core = {tau for tau in T if Phi[tau].calibrated and g[tau] <= budgets.Theta_g}
    if not T_core: return ('reject', 'no_core_task')
    rho_T = worst_over_simplex({tau: rho[tau] for tau in T_core}, budgets.delta_T)
    if rho_T < budgets.rho_min: return ('reject', 'task_simplex_robustness_fail', rho_T)
    if max(s[tau] for tau in T_core) > budgets.theta_s: return ('reject', 'shortcut_residue', s)
    if any((tau, th) not in TTR for tau in T_core for th in budgets.deploy_sim[tau]):
        return ('reject', 'outside_trusted_training_region')
    return ('ok', MTCert(T_core, theta_policy.core_subspace(), TTR, rho_T, s, g))
```

**正确性定理（GroundEdge v32 全链证据 Soundness）**
假设 v31 的 (A26)–(A28) 与 SCT 的 (A29)–(A32) 成立；MST 追加 **(A33)** `Φ` 经真实锚点校准且 `ECE ≤ ε_Φ`、锚点覆盖 `T_core`；**(A34)** 部署任务混合 `w∈Δ(T_core)` 且仿真参数落在 `TTR`；**(A35)** 捷径残差上界 sound；**(A36)** CDR 覆盖单调、干扰账本判定 sound；**(A37)** 共享层对任务扰动在 `θ_core` 上 Lipschitz。
则端到端部署成功概率：
```
P_success ≥ 1 − Σ_d(1−ρ_min(d)) − β_E − P(δ_a > Θ_a)                 # v31 动作-协同
            − P(‖Σ−Σ̂‖∞ > ε_s) − P(κ miscalibrated) − P(K_out\K_in ≠ ∅)  # SCT 语义-接触
            − max_{τ∈T_core}[(1−ρ_τ)+s_τ+g_τ]                         # MST 多任务-仿真
            − P(w ∉ Δ(T_core)) − P(Φ miscalibrated) − β_CDR
```
关键：**动作对齐（v31）→ 接触可信（SCT）→ 训练证据可迁移（MST）**，任一环失守都只允许降级/制动/拒证，不允许用“仿真里表现好”替代“现实里被证书覆盖”。

## 5. 本轮最大风险

**一句话**：v32 把“语义-接触”与“多任务-仿真”两条证据链都建立在对“模型自评模型”的二次信任上——语义证书依赖分割置信校准，多任务证书依赖保真场校准，而保真场本身就是用少量真实锚点去外推整个 `(τ,θ_sim)` 空间；一旦锚点覆盖不足、部署任务滑出 `T_core`，或捷径对因果干预隐身，整套证书会在“仿真自证 + 语义自信”的闭环里给一个“哪儿都好、哪儿都不真”的系统发证，故必须以 **真实锚点最小覆盖 + 分布外/越界拒证 + 反事实捷径审计** 三重护栏，宁可拒证，绝不以自评代替他证。
