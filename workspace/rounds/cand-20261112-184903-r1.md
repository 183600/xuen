# 第 62 轮（承接第 61 轮「具身语义进化闭环」ESEC，IP-173~182；灵感循环第 8 轮；本轮灵感：「零样本泛化」×「对话管理」）

> 第 61 轮用 USR 打通了场景/意图/阻抗/证据的语义空间，MEL 提供零样本物理先验，DMS 做执行接地对话，SRT-Dual 解耦语义流与实时流。但把「零样本泛化」与「对话管理」并置审视，会暴露四个更根本的缺口：
> 1. **零样本是「被动推断」而非「主动辨识」**：MEL 从一次观测直接回归 φ_phys，没有「做实验」的能力。零样本之所以难，恰恰因为模型不能改变观测分布；而机器人本可以通过轻敲、滑移、按压主动制造信息量最大的接触。第 61 轮的零样本是开环的、不可证伪的。
> 2. **对话是「事后救火」而非「事前求解」**：DMS 只在 EV-exec 出现滑移/振动后才触发澄清，没有用价值信息（VOI）在**执行前**决定「该问人还是该问物」。它把对话当异常处理，而不是当信息获取与泛化的第一等机制。
> 3. **「未知物理」与「未知意图」被人为割裂**：零样本模块处理 φ 的不确定性，对话模块处理 ι 的不确定性，两者没有共享的信念空间。于是用户说「像果冻一样软」——这句话同时携带物理先验（低 k、高 η）与意图（轻触），系统却无法把它转成可执行的阻抗分布。
> 4. **置信度不可证**：MEL 的 U_epistemic/U_aleatoric 是启发式标量，没有分布无关的覆盖保证。系统可能「高置信地错」，而第 61 轮的投影误差监控只能发现漂移，不能给出「真实 φ 落在集合内」的概率承诺。

## 0. 直觉与动机

**灵感 1（零样本 = 高认知不确定性；对话 = 信息获取 → 认知对话 ED）**
直觉：零样本泛化的本质不是「猜得准」，而是「知道自己不知道，并知道去问谁」。问人有两种：问人类（语言澄清），问世界（物理探针）。二者在决策论上是同一件事——选择信息量最大的动作以降低信念熵。关键洞见：把「零样本泛化」重述为**认知对话（Epistemic Dialogue）**：机器人维护一个关于「物理属性 φ、人类意图 ι、人类可靠度 κ」的统一歧义信念，对话策略在语言动作与物理动作之间做 VOI 最优选择。零样本不再是单次前向，而是一个「提问—观测—更新—再提问」的主动闭环。

**灵感 2（物理探针 = 向世界提问 MPA）**
直觉：轻敲听刚度、滑移测摩擦、按压看蠕变、提拉判脆性——每一种探针都是一次「受控实验」，其观测分布 p(y|φ,a) 由接触力学决定。关键洞见：用**D-最优实验设计**选择探针 a* = argmax det(I_a(φ))，在安全包络内最大化 Fisher 信息；探针是「物理语言」，与人类语言共享同一个 VOI 目标。零样本泛化从「被动分类」升级为「主动系统辨识」。

**灵感 3（语言是免费的物理先验 LAG）**
直觉：人类用「软、滑、脆、黏」描述从未见过的物体，这些形容词不是标签，而是**对 φ 的软约束**。关键洞见：构建**语言-属性接地（LAG）**：把形容词映射为 φ 上的因子分布，用算子（合取=约束交集、强化=方差收缩、比较=序约束）做组合，从而对「软但脆」「比刚才那个更滑」这类**未见组合**做零样本接地。语言因此成为跨场景迁移的免费先验。

**灵感 4（可证的泛化 = 保形预测 CPG）**
直觉：与其相信一个未校准的置信度，不如给出一个**有覆盖保证的集合**。关键洞见：用**保形预测（Conformal Prediction）**把 MEL 的点估计变成 φ 的预测集合 C_α，满足 P(φ_true ∈ C_α) ≥ 1-α；部署中分布漂移破坏可交换性，则用**自适应保形推断（ACI）**在线调 α_t，维持长期覆盖率。集合的宽度直接成为「该不该问」的触发器，覆盖率直接写进执行证书。

**灵感 5（未见任务 = 已知技能的组合 CDG）**
直觉：零样本任务泛化不必从零学，而可把已知技能按语言描述组合成新程序。关键洞见：**组合式对话泛化（CDG）**：把未见任务解析为技能库上的程序合成问题，对话负责补齐缺失前置条件（参数、顺序、约束），并用技能逻辑做类型检查；只要组合通过验证，就获得可证的一次成功率。

**灵感 6（合流 → 认知对话泛化引擎 EDGE）**
直觉：把上述统一成一个闭环：观测→歧义信念→VOI 选择（问人/问物/直接执行）→信念更新→保形集合→组合执行→证书。关键洞见：**EDGE = Epistemic Dialogue for Generalization Engine**，它在第 61 轮 SRT-Dual 的语义流上增加「认知对话层」，实时流不变，从而在不牺牲 1kHz 实时性的前提下获得可证的零样本泛化。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（统一歧义信念空间 UAB）** 统一歧义信念 U = (Φ, I, K, b, τ_bayes, A_amb)。其中：
- **物理属性空间**：Φ = ℝ^5，φ = (μ_fric, k_stiff, η_damp, σ_brittle, m_mass)
- **意图空间**：I = I_known ∪ {i_new}（开放集；未知意图在似然不足时新建）
- **人类可靠度空间**：K = {novice, informed, expert} × [0,1]，κ = (level, ρ) 表示专业度与可信度
- **信念**：b_t = (b_φ, b_ι, b_κ) ∈ Δ(Φ) × Δ(I) × Δ(K)
- **贝叶斯更新**：b_{t+1} = τ_bayes(b_t, a_t, o_t) ∝ b_t(s)·p(o_t | s, a_t)，对三类变量分别用测量模型 p(o|φ,a)、p(o|ι,a)、p(o|κ,a)
- **歧义度**：A_amb(b) = H(b_φ) + λ_ι·H(b_ι) + λ_κ·H(b_κ)，其中 H 为微分熵/香农熵
- **开放集规则**：若 max_i b_ι(i) < τ_new，则创建 i_new 并进入澄清/演示对话，而非强行归入已知意图

**定义 174（混合主动认知对话 MAB）** 认知对话是 POMDP M = (S, A, O, T, Z, R, γ, b_0)。其中：
- **状态**：S = Φ × I × K × Ctx（Ctx 含执行上下文、已锁定约束、技能库状态）
- **动作**：A = A_lang ∪ A_probe ∪ A_exec
  - A_lang = {ask_attribute(w), ask_preference, ask_compare(x,y), propose_composition(p), confirm, explain}
  - A_probe = {tap, slide, press_hold, lift, rub}
  - A_exec = {execute(K), abort, wait}
- **观测**：O = 人类语言回应 ∪ 探针信号 ∪ 执行证据 EV-exec
- **转移**：T(s'|s,a) 由接触物理 + 人类回应模型定义；**探针会改变物理状态**（如按压产生塑性变形），故 T 非平凡
- **奖励**：R(s,a) = Δprogress − λ_dlg·c_lang(a) − λ_pr·c_probe(a) − λ_safe·risk(a,s) − λ_t·time(a)
- **策略**：π_ed(a|b) = argmax_a VOI(a;b) s.t. safe(a) ∧ budget_ok(a)
- **混合主动性**：机器人可发起 ask/probe，人也可主动提供信息；人类话语作为异步观测注入 b

**定义 175（多模态探针动作 MPA）** 探针库 P = {(a, p(y|φ,a), c(a), safe(a))}。其中：
- **Fisher 信息**：I_a(φ) = E_{y|φ,a}[∇_φ log p(y|φ,a) ∇_φ log p(y|φ,a)^T]
- **D-最优探针**：a* = argmax_a log det(I_a(φ)) s.t. safe(a) ∧ c(a) ≤ B_probe.remaining
- **信息增益**：IG(a) = I(φ; y | a, b) = H(b_φ) − E_{y|a,b}[H(b_φ | y,a)]
- **接触力学测量模型**（示例）：
  - tap：Hertz 接触 F ≈ (4/3)E*√R·δ^{3/2}，E* 与 k_stiff 相关 ⇒ 估 k
  - slide：滑移临界处 μ_fric = F_t/F_n ⇒ 估 μ
  - press_hold：蠕变柔量 J(t) = 1/k + t/η ⇒ 估 k, η
  - lift：断裂抓取力 F_break 与 m、σ_brittle 相关 ⇒ 估 m, σ_brittle
- **安全包络**：探针力/位移/能量满足 F_probe ≤ F_env(φ̂, U)，且探针不得使物体进入不可逆破坏区（σ_brittle 高时禁止 lift）

**定义 176（语言-属性接地 LAG）** 属性词典 L = {(w, g_w, op_w)}。其中：
- **基形容词**：g_w: Φ → ℝ_{≥0} 为 φ 上的因子分布（未归一化），如「软」= 对 k 的低均值对数正态；「滑」= 对 μ 的低均值 Beta；「脆」= 对 σ_brittle 的高均值分布
- **组合算子**：
  - 合取（"软且滑"）：g_{w1∧w2}(φ) ∝ g_{w1}(φ)·g_{w2}(φ)（product of experts）
  - 强化（"非常软"）：g_{w^+}(φ) ∝ g_w(φ)^{1/ρ}，0<ρ<1（方差收缩）
  - 比较（"比刚才更滑"）：g_{w1>w2} = g_{w1}·𝕀[attr(w1) > attr(w2)]
  - 未见词 w*：在属性嵌入空间分解 g_{w*} = Σ_j α_j g_{a_j}，α 由语言嵌入的最近邻/稀疏编码给出
- **语言条件先验**：p(φ | u) ∝ p_0(φ)·Π_{w∈parse(u)} g_w(φ)，直接注入 b_φ 作为先验
- **接地损失**：ℒ_ground = −E_{(u,φ)~D}[log p(φ|u)] + λ_c·ℒ_contrast(Emb(u), Factor(φ))
- **零样本组合接地**：对训练中未共现的 (w1,w2)，通过算子组合得到 g_{w1∧w2}，无需该组合的监督样本

**定义 177（保形预测泛化 CPG）** 保形泛化器 C = (f_MEL, s, D_cal, α, ACI)。其中：
- **非一致性分数**：s(x, φ) = (φ − f_MEL(x))^T Σ(x)^{-1} (φ − f_MEL(x))（Mahalanobis）
- **预测集合**：C_α(x) = {φ : s(x, φ) ≤ q_{1-α}}，q_{1-α} 为校准集上 ⌈(n+1)(1-α)⌉/n 经验分位数
- **可交换情形覆盖保证**：P(φ_true ∈ C_α(X)) ≥ 1-α
- **漂移下的 ACI**：α_{t+1} = clip(α_t + γ(α − err_t), α_min, α_max)，err_t = 𝕀[φ_t ∉ C_{α_t}(x_t)]；长期覆盖 ≥ 1-α−δ（γ 适当衰减）
- **意图保形集**：C_α^ι 用 APS/RAPS 分数在 b_ι 上构造，宽度 w_ι = |C_α^ι|
- **触发接口**：宽度 w_φ = E_{φ~C_α}[‖φ − mean‖]、w_ι 作为 ADT 的歧义信号

**定义 178（歧义驱动的对话触发 ADT）** 以 VOI 统一「问人/问物/执行」：
```
VOI(a; b) = E_{o|a,b}[U(b') − U(b)] − λ_c·c(a)
U(b) = −A_amb(b) − λ_s·E_b[risk]
选择规则：
  if VOI(probe) ≥ VOI(ask) ∧ VOI(probe) ≥ 0 ∧ safe(probe):
      a ← argmax_{a∈A_probe} VOI(a)          # 问世界
  elif VOI(ask) ≥ VOI(exec) ∧ VOI(ask) ≥ 0:
      a ← argmax_{a∈A_lang} VOI(a)           # 问人
  else:
      a ← execute(K(b))                      # 直接执行
触发条件（任一满足即进入选择）：
  w_φ > τ_φ ∨ w_ι > τ_ι ∨ OOD(x) > τ_ood ∨ ACI.err_recent > τ_err ∨ H(b_κ) > τ_κ
```
- **信息价值单调性**：若 a 的观测与 φ 条件独立于其他变量，则 VOI(a) ≥ 0 ⇔ IG(a) ≥ 0
- **安全优先**：任何 VOI 为负或超预算的动作被剪枝；不确定时默认保守执行而非冒险探针

**定义 179（人在环校准 HIC）** 人类查询 q ∈ Q = {category, comparison, demonstration, correction}。其中：
- **似然**：p(q|φ, κ)，κ 为可靠度；采用 tempered Bayes 抗噪声：b'_φ ∝ b_φ·p(q|φ)^{ρ}
- **期望信息增益**：EIG(q) = H(b_φ) − E_{q}[H(b_φ|q)]
- **查询选择**：q* = argmax_q EIG(q)/c(q) s.t. turns ≤ B_dlg.remaining
- **校准集增广**：仅当人类标签经探针或执行结果交叉验证后，才写入 D_cal；未验证标签只进入 b_φ，不进入保形校准，防止标签投毒破坏覆盖保证
- **可靠度更新**：κ 由历史一致性（人类标签与后续观测的一致率）在线估计

**定义 180（组合式对话泛化 CDG）** 技能库 P = {p_i}，p_i = (pre_i, post_i, eff_i, K_i, cost_i)。其中：
- **任务解析**：语言任务 τ* → 目标公式 ψ（一阶逻辑/时序逻辑片段）
- **程序合成**：寻找 p = p_1∘…∘p_k 使得 pre_1 ⊆ init、post_k ⊨ ψ、且 ∀j, post_j ⊨ pre_{j+1}
- **缺失前置条件**：若不存在合法程序，求最小缺失集 M；对 m∈M，选择问人（补参数/约束）或探针（测物理量）
- **验证**：在技能逻辑中做类型检查，生成组合证明 π_comp
- **零样本任务保证**：若 ψ 可由已知技能组合实现且 π_comp 通过验证，则执行成功率 ≥ 1 − ε_verify
- **对话协商**：propose_composition(p) 向人展示组合计划与风险，人可 confirm / 修改 / 拒绝；拒绝视为新约束进入 b_ι

**定义 181（零样本泛化联合保证 ZSG）** 在一次 EDGE 回合中，若：
1. φ 的保形集满足覆盖 P(φ ∈ C_α) ≥ 1−α（或 ACI 长期覆盖 ≥ 1−α−δ）；
2. ι 的保形集满足 P(ι ∈ C_α^ι) ≥ 1−α；
3. 任务组合验证通过（π_comp 类型正确）；
4. 对话在 B_dlg 内收敛（期望轮次 ≤ 3，概率 ≥ 1−δ）；
则零样本执行成功率满足（并集界，无需独立性假设）：
```
P(success) ≥ 1 − α − ε_verify − δ
```
该界是保守的；实际成功率通常更高，但**证书只使用该下界**，以避免乐观偏差。

### IP-185 UAB（统一歧义信念）

```python
class UnifiedAmbiguityBelief:
    def __init__(self, n_particles=512, tau_new=0.35):
        self.b_phi = ParticleBelief(n_particles, dim=5)  # μ,k,η,σ,m
        self.b_intent = np.ones(5) / 5
        self.b_kappa = ReliabilityBelief()
        self.tau_new = tau_new
        self.history = []

    def update(self, observation, action):
        # 物理属性：粒子滤波（探针/执行观测）
        if observation.type in ('probe', 'exec_evidence'):
            self.b_phi.update(observation.y, action, observation.model)
        # 意图：语言观测 + 开放集
        if observation.type == 'language':
            scores = NLU.intent_scores(observation.text)
```

```python
        return self.predicted_force(a, phi_hat) <= self.env_limits.f_max
```

```python
class LanguageAttributeGrounding:
    def __init__(self, lexicon, attribute_embed):
        self.lexicon = lexicon                 # w -> factor
        self.attr_embed = attribute_embed      # attribute axis embeddings
        self.ops = {
            'and':   lambda g1, g2: normalize(g1 * g2),
            'very':  lambda g, rho=0.5: normalize(g ** (1 / rho)),
            'more':  lambda g1, g2: g1 * indicator_order(g1, g2),
        }

    def ground(self, word):
        if word in self.lexicon:
            return self.lexicon[word]
        # 未见词：在属性嵌入空间稀疏分解
        alpha = sparse_encode(self.attr_embed.embed(word), self.attr_embed.basis)
        g = sum(alpha[j] * self.lexicon[self.attr_embed.basis[j]] for j in alpha)
        return normalize(g)

    def parse(self, utterance):
        tree = LanguageParser.parse(utterance)  # 合取/强化/比较
        return [self._eval(node) for node in tree.factors]

    def _eval(self, node):
        if node.op is None:
            return self.ground(node.word)
        return self.ops[node.op](*[self._eval(c) for c in node.children])
```

### IP-189 CPG（保形预测泛化）

```python
class ConformalPredictiveGeneralizer:
    def __init__(self, alpha=0.1, gamma=0.01, window=200):
        self.alpha = alpha
        self.alpha_t = alpha
        self.gamma = gamma
        self.scores = deque(maxlen=window)
        self.q = None
        self.errors = deque(maxlen=window)

    def calibrate(self, f_mel, calib_set):
        self.scores = [self.nonconformity(f_mel, x, phi)
                       for x, phi in calib_set]
        self.q = quantile(self.scores, 1 - self.alpha_t)

    def nonconformity(self, f_mel, x, phi):
        mu, sigma = f_mel(x)
        return (phi - mu).T @ inv(sigma) @ (phi - mu)

    def predict(self, f_mel, x):
        mu, sigma = f_mel(x)
        return ConformalSet(center=mu, cov=sigma, q=self.q)

    def observe_outcome(self, x, phi_true, f_mel):
        err = self.nonconformity(f_mel, x, phi_true) > self.q
        self.errors.append(err)
        # ACI 更新
        self.alpha_t = clip(self.alpha_t + self.gamma * (self.alpha - err),
                            self.alpha_min, self.alpha_max)
        self.q = quantile(self.scores, 1 - self.alpha_t)
        return not err

    def coverage_hat(self):
        return 1.0 - np.mean(self.errors) if self.errors else None
```

### IP-191 CDG（组合式对话泛化）

```python
class CompositionalDialogueGeneralizer:
    def __init__(self, skills, verifier, max_depth=6):
        self.skills = skills
        self.verifier = verifier
        self.max_depth = max_depth

    def synthesize(self, goal_formula, init_state):
        # 在技能图上做带前置条件的 A* / 有界 DFS
        plan = self._search(init_state, goal_formula, depth=0)
        if plan is not None:
            proof = self.verifier.check(plan, init_state, goal_formula)
            return plan, proof, []
        missing = self._minimal_missing_preconditions(init_state, goal_formula)
        return None, None, missing

    def _search(self, state, goal, depth):
        if self.verifier.satisfies(state, goal):
            return []
        if depth >= self.max_depth:
            return None
        for p in self.skills.applicable(state):
            nxt = self.skills.apply(p, state)
            rest = self._search(nxt, goal, depth + 1)
            if rest is not None:
                return [p] + rest
        return None

    def _minimal_missing_preconditions(self, state, goal):
        # 反向可达分析：找出阻断所有组合的最小前置条件集
        return self.verifier.minimal_missing(state, goal, self.skills)
```

### IP-185 UAB（统一歧义信念）

```python
class UnifiedAmbiguityBelief:
    def __init__(self, n_particles=512, tau_new=0.35):
        self.b_phi = ParticleBelief(n_particles, dim=5)   # μ,k,η,σ,m
        self.b_intent = np.ones(5) / 5
        self.b_kappa = ReliabilityBelief()
        self.tau_new = tau_new

    def update(self, observation, action=None):
        if observation.type in ('probe', 'exec_evidence'):
            self.b_phi.update(observation.y, action, observation.model)
        if observation.type == 'language':
            scores = NLU.intent_scores(observation.text)
            self.b_intent = 0.7 * self.b_intent + 0.3 * scores
            if self.b_intent.max() < self.tau_new:
                self.b_intent = open_set_expand(self.b_intent)
        if observation.type in ('human_label', 'human_confirm'):
            self.b_kappa.update(observation, self.b_phi)
        return self

    def inject_language_prior(self, utterance):
        self.b_phi.apply_factors(LAG.parse(utterance))
        return self

    def ambiguity(self):
        return (entropy(self.b_phi) + 0.5 * entropy(self.b_intent)
                + 0.2 * entropy(self.b_kappa))
```

### IP-186 ADC（混合主动对话控制器）

```python
class ActiveDialogueController:
    def __init__(self, probes, hic, budget):
        self.probes, self.hic, self.budget = probes, hic, budget

    def need_info(self, b, C_phi, C_intent):
        return (C_phi.width() > self.tau_phi
                or C_intent.width() > self.tau_intent
                or b.ood_score > self.tau_ood
                or b.aci_recent_error > self.tau_err)

    def select(self, b, C_phi, C_intent):
        candidates = [(a, self.voi_probe(a, b)) for a in self.probes.safe_actions(b)]
        candidates += [(q, self.voi_ask(q, b)) for q in self.hic.candidate_queries(b)]
        candidates.append((ExecAction(), 0.0))
        a, v = max(candidates, key=lambda x: x[1])
        return a if v > 0 else ExecAction()

    def voi_probe(self, a, b):
        return (mutual_information(b.b_phi, a) * self.value_per_nat
                - self.budget.probe_cost(a) - self.risk_penalty(a, b))

    def voi_ask(self, q, b):
        return (self.hic.expected_info_gain(q, b) * self.value_per_nat
                - self.budget.dialogue_cost(q) - self.human_time_cost(q))

    def select_missing(self, missing_set):
        for m in missing_set:
            if self.probes.can_measure(m):
                return self.probes.best_for(m)
        return self.hic.query_for(missing_set)
```

### IP-187 MPA（多模态探针）

```python
class ProbeLibrary:
    def __init__(self, env_limits):
        self.models = {
            'tap': HertzContactModel(), 'slide': FrictionModel(),
            'press_hold': CreepModel(), 'lift': BreakageModel(), 'rub': WearModel(),
        }
        self.env_limits = env_limits

    def d_optimal(self, phi_hat, budget):
        best, best_info = None, -np.inf
        for a in self.models:
            if not self.safe(a, phi_hat) or self.cost(a) > budget.remaining:
                continue
            info = np.linalg.slogdet(self.models[a].fisher(phi_hat))[1]
            if info > best_info:
                best, best_info = a, info
        return best

    def safe(self, a, phi_hat):
        if a == 'lift' and phi_hat.sigma_brittle > self.env_limits.brittle_max:
            return False
        return self.predicted_force(a, phi_hat) <= self.env_limits.f_max

    def mutual_information(self, belief, a):
        return belief.entropy() - belief.expected_entropy_after(a, self.models[a])
```

### IP-188 LAG（语言-属性接地）

```python
class LanguageAttributeGrounding:
    def __init__(self, lexicon, attribute_embed):
        self.lexicon = lexicon
        self.attr_embed = attribute_embed
        self.ops = {
            'and':  lambda g1, g2: normalize(g1 * g2),
            'very': lambda g, rho=0.5: normalize(g ** (1 / rho)),
            'more': lambda g1, g2: g1 * indicator_order(g1, g2),
        }

    def ground(self, word):
        if word in self.lexicon:
            return self.lexicon[word]
        alpha = sparse_encode(self.attr_embed.embed(word), self.attr_embed.basis)
        return normalize(sum(alpha[j] * self.lexicon[self.attr_embed.basis[j]]
                             for j in alpha))

    def parse(self, utterance):
        tree = LanguageParser.parse(utterance)
        return [self._eval(node) for node in tree.factors]

    def _eval(self, node):
        if node.op is None:
            return self.ground(node.word)
        return self.ops[node.op](*[self._eval(c) for c in node.children])
```

### IP-189 CPG（保形预测泛化）

```python
class ConformalPredictiveGeneralizer:
    def __init__(self, alpha=0.1, gamma=0.01, window=200):
        self.alpha, self.alpha_t, self.gamma = alpha, alpha, gamma
        self.scores, self.errors, self.q = deque(maxlen=window), deque(maxlen=window), None

    def calibrate(self, f_mel, calib_set):
        self.scores = [self.nonconformity(f_mel, x, phi) for x, phi in calib_set]
        self.q = quantile(self.scores, 1 - self.alpha_t)

    def nonconformity(self, f_mel, x, phi):
        mu, sigma = f_mel(x)
        return (phi - mu).T @ inv(sigma) @ (phi - mu)

    def predict(self, f_mel, x):
        mu, sigma = f_mel(x)
        return ConformalSet(center=mu, cov=sigma, q=self.q)

    def observe_outcome(self, x, phi_true, f_mel):
        err = self.nonconformity(f_mel, x, phi_true) > self.q
        self.errors.append(err)
        self.alpha_t = clip(self.alpha_t + self.gamma * (self.alpha - err),
                            self.alpha_min, self.alpha_max)
        self.q = quantile(self.scores, 1 - self.alpha_t)
        return not err

    def coverage_hat(self):
        return 1.0 - np.mean(self.errors) if self.errors else None
```

### IP-191 CDG（组合式对话泛化）

```python
class CompositionalDialogueGeneralizer:
    def __init__(self, skills, verifier, max_depth=6):
        self.skills, self.verifier, self.max_depth = skills, verifier, max_depth

    def synthesize(self, goal_formula, init_state):
        plan = self._search(init_state, goal_formula, depth=0)
        if plan is not None:
            proof = self.verifier.check(plan, init_state, goal_formula)
            return plan, proof, []
        return None, None, self.verifier.minimal_missing(init_state, goal_formula, self.skills)

    def _search(self, state, goal, depth):
        if self.verifier.satisfies(state, goal):
            return []
        if depth >= self.max_depth:
            return None
        for p in self.skills.applicable(state):
            rest = self._search(self.skills.apply(p, state), goal, depth + 1)
            if rest is not None:
                return [p] + rest
        return None
```

### IP-194 EDGE（认知对话泛化引擎）

```python
class EDGEEngine:
    def __init__(self, mel, usr, eeis, ertc, budget, probes, hic, cpg, cdg):
        self.mel, self.usr, self.eeis, self.ertc = mel, usr, eeis, ertc
        self.budget, self.probes, self.hic = budget, probes, hic
        self.uab = UnifiedAmbiguityBelief()
        self.adc = ActiveDialogueController(probes, hic, budget)
        self.cpg, self.cdg = cpg, cdg
        self.probe_log, self.dialogue_trace = [], []

    def semantic_step(self, obs, utterance):
        self.uab.update(obs)
        if utterance:
            self.uab.inject_language_prior(utterance)
            self.dialogue_trace.append(('user', utterance))

        f_mel = lambda x: self.mel(x)
        C_phi = self.cpg.predict(f_mel, obs.x)
        C_intent = intent_conformal(self.uab.b_intent, self.cpg.alpha_t)

        if self.adc.need_info(self.uab, C_phi, C_intent):
            a = self.adc.select(self.uab, C_phi, C_intent)
            o = self._run_probe(a) if isinstance(a, ProbeAction) else self._ask_human(a)
            self.probe_log.append((a, o)) if isinstance(a, ProbeAction) else \
                self.dialogue_trace.append(('robot', a, o))
            self.uab.update(o, action=a)
            C_phi = self.cpg.predict(f_mel, obs.x)

        pi_comp = None
        if is_unseen_task(utterance):
            plan, proof, missing = self.cdg.synthesize(parse_goal(utterance), self.skills_state())
            if missing:
                self.uab.update(self._execute(self.adc.select_missing(missing)))
                plan, proof, missing = self.cdg.synthesize(parse_goal(utterance), self.skills_state())
            pi_comp = (plan, proof)

        anchor = self.usr.commit(self.uab.b_phi.mean(),
                                 self.usr.intent_encoder.encode(self.uab.b_intent),
                                 self.uab.b_phi, C_phi)
        return anchor, C_phi, C_intent, pi_comp

    def execute_step(self, delta_f_req, fused, xi_exec, Z_env):
        anchor = self.usr.read_latest_anchor()
        K_safe = self.eeis.compile_with_interval(
            delta_f_req, fused, xi_exec, Z_env,
            interval=anchor.conformal_set, prior=anchor.phys_prior)
        cert = self.ertc.dispatch(K_safe)
        EV = wait_contact_and_build_evidence()
        ok = self.cpg.observe_outcome(anchor.x, EV.phi_est, self.mel)
        J = build_zsec(EV, anchor, self.uab, self.probe_log,
                       self.dialogue_trace, self.budget.snapshot())
        return K_safe, EV, J, ok
```

**正确性定理（EDGE-Complete）**：
假设 A71–A77（同想法区）成立，则：
1. **物理覆盖**：可交换情形 P(φ_true ∈ C_α) ≥ 1−α；漂移情形 ACI 长期覆盖 ≥ 1−α−δ。
2. **意图覆盖**：P(ι_true ∈ C_α^ι) ≥ 1−α；开放集意图不被静默误并。
3. **主动辨识收敛**：探针 Fisher 信息正定时后验协方差单调不增；线性化高斯模型下 D-最优探针使 tr(Σ_t)=O(1/t)。
4. **组合零样本成功**：Verify(π_comp) 通过 ⇒ P(success) ≥ 1−α−ε_verify−δ（并集界）。
5. **实时非干扰**：认知对话与保形计算均在语义流；实时流周期与第 61 轮相同。
6. **安全不降级**：预算耗尽只减少信息获取，不放松 K_safe 安全约束；全部耗尽触发 abort/retreat。

## 5. 本轮最大风险

**一句话**：保形预测的覆盖保证依赖可交换性或 ACI 的长期平均，而具身部署中的分布漂移、探针本身改变物理状态、以及人类标签的噪声/迎合偏差，会共同制造「名义覆盖很高、危险尾部仍失效」的**伪保证泛化**；必须以「条件/风险受控保形 + 探针安全包络硬约束 + 人类可靠度建模 + 最坏情形压力测试 + ZSEC 覆盖声明可审计」构建护栏，确保「可证泛化」不被误读为「绝对安全」。
