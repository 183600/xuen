# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「开源硬件」×「快速原型」）

> 第 57 轮把安全的赌注从"模型置信"移到"证据承诺"，再用少样本摊销、跨模态对账、个性化有界加了三层护栏；但它和此前所有轮次共享两个未言明的前提：**(a) 测量装置是一个匿名、稳定、已校准的真理通道**——相机、触觉、IMU、末端执行器被当作"同一台身体、同一个零点、同一种装配"，证据只被追问"有多强"，却从不被追问"是谁测的、用哪台身体测的、上次校准是什么时候"；**(b) OOD 是被动遭遇的**——语料里没有的世界只能等它出现，于是元模型的盲区只能靠 OOD 门事后拦截。**开源硬件**拆掉第一个前提：身体从常量变成"可复制、可检查、可替换、也可被篡改"的分布，BOM/固件/校准/装配继承第一次成为证据链的一等公民。**快速原型**拆掉第二个前提：稀有的、危险的、语料外的表面与场景可以被廉价地**制造**出来，反例从"等待采样"变成"主动实验设计"。但两者都是双刃：溯源只证明"是谁"，不证明"测得准"；可制造的反例只证明"这一条假设错了"，不证明"没造出来的世界是安全的"。本轮核心命题由"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为 **"硬件可溯源、反例可制造、保真度可入账，且制造/溯源证据只许证伪、不许证实"**。

核心矛盾：
- **H32（溯源 vs 真实）**：开源硬件让"谁在测量"可审计，却可能制造"护照齐全所以可信"的错觉——一份完整的 BOM、固件哈希与校准记录，能证明装置身份与可复现性，不能证明它没有系统性偏差；坏人还可以伪造 BOM/校准记录，把不可信装置洗成"认证硬件"。
- **H33（原型 vs 保真）**：3D 打印/激光切割让反例又便宜又快，但夹具与部署世界之间存在传输间隙；若夹具与元模型共享同一个建模偏差，一百次廉价试验只是把同一个错误问一百遍——**反例的数量不等于覆盖，原型的完成度不等于证据强度**。
- **H34（模块化 vs 证据连续性）**：开源硬件的卖点是快换快改，但每一次换件都在物理上切断证据链；若换件后旧证据仍被沿用，就会出现"借尸还魂"的污染证据——用旧传感器标定的后验去解释新传感器的读数。

## 0. 直觉与动机

**灵感 1（开源硬件 → 测量装置成为可审计的"证人"）**
直觉：证据链一直追问"证据有多强"，却没问"证人是谁"。开源硬件真正的价值不是便宜，而是**可复制、可检查、可替换**：公开的 BOM、固件版本、打印参数与校准流程，让第三方能重建同一个测量装置并独立复现其误差结构。于是每条证据多了一份"装置护照"：它来自哪条装配路径、经过哪次校准、是否在有效期内、是否发生过未重标的换件。关键是边界：护照是**身份与可复现性证书**，不是**准确度真值证书**——它能把"不明来源的读数"降级为不可用，却不能把"来源清楚的读数"升级为真理。因此本轮将第 57 轮"一切判定器走隔离"推广为"**一切测量装置也走隔离**"：新装置、换件后的装置、校准过期的装置，先进入影子/标定模式，只有通过与部署同分布的成对试验，其证据才被允许进入承诺链。

**灵感 2（快速原型 → 反例工厂，而不是缩小版产品）**
直觉：第 57 轮最怕"语料里没有的世界"。等待遇到它是被动的；快速原型允许我们**制造**它：透明冰面、柔性地毯、反光金属、低摩擦斜坡、遮挡物、背景板、干扰物、未见物体——用 3D 打印、激光切割与现成开源传感器，一天之内就能把一条"证书条款"打成假。原型的 KPI 因此不是完成度，而是**单位时间内的证伪信息量**；这与 UniBot 的五类泛化轴（位置/干扰物/背景/未见物体/人为干扰）天然同构。但必须把话说死：打印出来的世界是**反例生成器**，不是"真实分布的无偏样本"；它能扩大"已知失败模式"的清单，不能宣称"未知世界已被覆盖"。

**灵感 3（保真度入账 → 便宜证据必须打折）**
直觉：廉价原型试验不是免费的独立样本。若夹具与部署世界共享同一个建模偏差，"多测几遍"只是在放大相关性；若打印件公差、表面粗糙度、反光率与真实材质不同，试验结果会出现**传输间隙**。因此每条原型证据必须携带保真度 `f` 与偏离界 `ε_F`：似然按 `α(f)` 打折、共形按保真度分层、后验方差至少加上 `(L·ε_F)²`；保真度低于阈值时，证据只能否决、不能放行。把"保真度"写进账本，是为了让"廉价"在统计上付出应有的代价，而不是用数量掩盖质量。

**灵感 4（反证的不对称 → 新证据只许证伪）**
直觉：波普尔说反例可以否决理论，正例不能证实理论。开源硬件能证伪"该装置仍然可信/零点未漂/换件无影响"，快速原型能证伪"这条假设在真实世界也成立"；但两者都造不出"所有反例"，所以都不能证实"世界安全"。本轮把它写成硬规则：**EV-hw 与 EV-fab 只允许收缩安全集、抬高阈值、触发再校准与回溯隔离，永不允许扩张安全集、降低证据要求或替代承诺证据**。这条单向性把第 57 轮"个性化单向有界"从人推广到仪器与实验台：信任赢得慢、失去快，安全集只能被反例削减、不能被新工具扩张。

**灵感 5（合流 → PCE³：探-制-诺-演）**
直觉：检查点之前现在有三类信息动作：**探**（在真实世界做非破坏性探针）、**问**（人类证据/L2 协商，第 57 轮已有）、**制**（在离线台架上制造反例与标定实验）。第三类的价值函数是新的一维 VOI：当 OOD 分数高、跨模态分歧大、或硬件漂移告警时，先在台架上花小钱制造反例并重标定，通常比带着不确定去做不可逆接触便宜得多。但 `fab` 的产出只进入"否决/标定"通道，不进入"放行"通道；承诺仍然只由归因于已认证硬件的部署证据支撑。三个新机制（溯源、制反例、保真度）全部只经"信念更准（含强制加宽）"或"动作更保守"两条安全通道起作用。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（开源硬件溯源与认证 HAP）** 硬件溯源图 `H=(𝒞,ℰ)`，组件 `c∈𝒞` 携带 `id_c=Hash(design_c,BOM_c,firmware_c)`、开源等级 `o_c∈{O_design,O_interface,O_closed}`、校准记录 `K_c=(θ̂_c,U_c,t_c,proc_c)` 与装配边 `ℰ`。认证 `A(H)∈{C,D,U}`（认证/降级/未认证）。证据 `e` 的溯源 `prov(e)⊆𝒞`；**可归因** `attr(e) ⇔ A(prov(e))=C ∧ age(t_c)≤T_cal ∧ 无未重标换件`。只有 `attr(e)` 的证据可进入 SMM/FSE。第三方可复现性仅当路径上所有关键件为 `O_design` 时成立；`O_closed` 只支持黑盒认证。**语义边界**：`A` 是身份与校准有效性，不是测量真值；`A=C` 不得直接提高任何世界置信。

**定义 140（快速证伪原型 RFP）** 失效模式假设集 `ℋ`（粘附/透明/柔顺/反光/遮挡/光照/未见过物体等）；构造动作 `fab(h,ε)→F=(design_F,δ_F,f_F,τ_F,c_F)`，其中 `δ_F` 为声明的参数偏离、`f_F` 为保真度、`τ_F/c_F` 为时间/成本。夹具库 `𝔽` 可复用，目标 `τ_fab≤1 天`。实验目标不是任务成功率，而是最大化 `E[IG(φ)]/(τ_F+c_F)`（对某条证书假设 `φ` 的信息增益/代价），受 `A34` 非破坏性与安全约束。**证伪不对称**：夹具上的 `fail` 可强否决 `φ`；夹具上的 `pass` 只允许弱更新装置误差模型，不得作为世界安全的正证据。

**定义 141（保真度入账与分层共形 FAC）** 保真度 `f_F=1−d(P_dep,P_F)/d_max`，并声明传输界 `d(P_dep,P_F)≤ε_F`。似然折扣 `Like_F^{α(f)}`，`α(f)=clamp((f−f_0)/(1−f_0),0,1)`，有效样本量 `n_eff=Σα(f)`。共形按保真度分桶，桶 `b` 的经验覆盖 `≥1−α−δ_fid`（桶数 `|B|` 的 union bound）。传输风险界 `|R_dep−R_F|≤L·ε_F`；后验方差强制 `σ²←σ²+(L·ε_F)²`。**不可逆接触硬门**：需要 `f_F≥f_irr` **且**在"与部署同型硬件"上做过的成对试验；否则原型证据不得进入不可逆接触必要证据集。**单向更新**：`fail` ⇒ 收缩安全集/提高阈值/触发回溯；`pass` ⇒ 不扩张安全集。

**定义 142（硬件在环证书 HIL-C）** `C_hil=(H,A,𝔽,{ε_F,f_F},paired_trials,ood_reg^enc,ood_reg^fab,drift_log)`，准入条件：(i) 溯源链完整且关键件可复现或已黑盒认证；(ii) 每个夹具带认证保真度与偏离界；(iii) 至少在一条认证参考区域完成"夹具-部署"成对试验；(iv) `ood_reg` **分账**记录"真实遭遇"与"人工制造"两类 OOD，覆盖率不得混算；(v) 校准漂移被监控。`C_hil` 可授权：元模型/OOD 门的离线重标定、L0/L1 安全区域收缩、阈值收紧；**不可**单独授权不可逆接触，**不可**扩张安全区域。

**定义 143（硬件信任状态与换件隔离 HTS）** 状态 `s_h=(att,drift,swap,disc,rul)`；在参考探针上 `d_t=|pred−meas|/scale`，用 CUSUM 检漂移；未重标换件 ⇒ `att←D` 并执行**溯源域回滚**：凡 `prov(e)∩swapped≠∅` 的历史证据全部隔离/降权。恢复认证需"重标定 ∧ 成对试验 ∧ 有界速率"；降级实时、升级缓慢且有界。与第 57 轮 PTM 同构：**仪器信任也赢得慢、失去快**；全局硬界（不可逆接触的必要证据集）不因认证恢复而放宽。

**定义 144（制-探-诺-演算子 PCE³）** 每检查点：①元推断+跨模态对账（第 57 轮）；②硬件门：若 `¬attr(e)` 或 `s_h.att≠C` ⇒ 禁止承诺，转入标定/换件流程；③动作集 `{probe, consent, fab}`，分别计算 `VOI_world / VOI_human / VOI_fab`；若 `n(o)>θ_ood` 或 `D(r)>θ_D` 或 `drift` 告警且 `VOI_fab≥θ_fab`、`budget.fab_left>0` ⇒ 选信息增益最高的夹具执行离线证伪，更新只走"否决/重标定"通道；④承诺 ⇔ `attr(e) ∧ FSE(第 57 轮) ∧ ∃g:R≤δ_f(g)`；⑤否则 reroute→协商(L2)→安全停。终止：每检查点 `k_probes+k_cons+k_fab` 内终止。

## 2. 关键算法伪代码（完整版见产物区）

```python
def attest(M, r, e, H, s_h):
    if not prov_complete(e, H) or s_h.att != 'C':      # 未认证装置不产生承诺证据
        return 'reject', quarantine(e)
    if swapped_without_recal(e, H):                    # 换件即溯源域回滚
        H = rollback_provenance(H, e.prov); s_h.att = 'D'
    return ('ok', e) if calib_valid(e, H) else ('reject', 'calib_stale')

def fabricate_falsify(h, bench, budget):
    F = bench.pick_or_build(h)                         # 3D 打印/激光切割夹具
    y = run_paired_fixture(F, ref_region=bench.ref)    # 与一条认证参考区成对
    f, eps = bench.certify_fidelity(F, y)              # 保真度与传输界
    return F, y, f, eps

def fidelity_update(belief, y, f, eps, L):
    if y == 'fail':                                    # 反例：立即收缩
        belief.safe_set = contract(belief.safe_set, y)
        belief.theta = tighten(belief.theta)
    else:                                              # 正例：只弱更新误差模型
        belief.hw_err = bayes_update(belief.hw_err, y, w=alpha(f))
    belief.var += (L * eps) ** 2                       # 传输间隙 → 强制加宽
    return belief

def pce3_checkpoint(cp, M, H, s_h, bench, budget, personae):
    M, fused, inf, D = meta_infer_and_fuse(M, cp.region, M.obs[cp.region], meta)
    if not all(attest(M, cp.region, e, H, s_h)[0] == 'ok' for e in evidence(cp)):
        return calibrate_or_stop(cp, H)                # 先修装置，再谈承诺
    if (inf.cls == 'OOD' or D > theta_D or drift_alert(s_h)) and budget.fab_left > 0:
        h = argmax(hypotheses(cp), key=lambda x: voi_fab(x, M, inf) - cost_fab(x))
        if voi_fab(h, M, inf) >= theta_fab:
            F, y, f, eps = fabricate_falsify(h, bench, budget)
            M = fidelity_update(M, y, f, eps, L)       # 只否决/重标定，不放行
            budget.spend_fab(F)
    if few_shot_evidence_gate(core_contact(cp), M, personae, ood_reg)[0] != 'ok':
        return reroute_or_negotiate(cp, M, personae)
    return commit(cp, M)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| HAP | O(\|𝒞\|+\|ℰ\|) 每次归因；哈希缓存 O(1) | O(\|𝒞\|+\|ℰ\|) | 溯源完整、校准有效期、换件回滚 |
| RFP | O(τ_fab+c_F) 离线；在线选夹具 O(\|ℋ\|) | O(\|𝔽\|) | 只作证伪、夹具可复用、预算受限 |
| FAC | O(\|B\|·N_cal) 分层共形 | O(\|B\|·N_cal) | 保真度诚实、传输界、覆盖 union bound |
| HIL-C | O(\|𝔽\|·N_pair) 离线 | O(\|𝔽\|) | 成对试验、OOD 分账、仅授权 L0/L1 |
| HTS | O(1)+O(H_swap) | O(\|𝒞\|) | 单向有界、回滚完备、审计 |
| PCE³ | +O(k_fab·(d_F+c_F)) | O(\|V\|+\|σ\|+\|𝔽\|) | 双/三通道 VOI、k_p+k_c+k_f 终止 |

**正确性定理（Provenance-Fabrication-Fidelity Soundness, PFFS 概要）**：在 A33–A40 之上加 (A45) 溯源与校准声明诚实、未重标换件检出率 `≥1−δ_swap`、回滚完备；(A46) 夹具保真度与偏离界诚实，且 `fab` 证据只进入否决/重标定通道；(A47) 保真度分层共形覆盖 `≥1−α−δ_fid`，传输间隙满足 `|R_dep−R_F|≤L·ε_F`；(A48) HTS 单向有界、全局硬界不放宽。则：
(i) **承诺健全性**：`P(fail) ≤ δ_f+ε_meta(k)+δ_probe+ε_h+δ_ood·α_conf+δ_xm·1[L1]+δ_swap+δ_fid+L·ε_F`；且 `fab` 的 `pass` 不出现在任何正证据项中。
(ii) **反例单调性**：加入任意数量的 `fab` 反例，只会使授权安全集单调收缩、证据阈值单调抬高，不存在"多做原型反而更敢承诺"的路径。
(iii) **溯源完整性**：任何未归因、未认证、校准过期或换件未重标的测量，均无法进入承诺链；`A=C` 本身不提升世界置信。
(iv) **终止性**：每检查点 `fab` 次数 `≤k_fab`，PCE³ 在 `k_probes+k_cons+k_fab` 内终止于 {承诺, 绕行, L2 协商, 安全停}。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |

## 6. 本轮最大风险

**一句话**：本轮把"装置可信"与"世界被覆盖"分别押在开源硬件溯源和快速原型反例上，但**溯源只证明是谁在测、原型只证明哪条假设被证伪，二者都不证明真实分布已被覆盖**——若把"护照齐全"误当"测得准"、把"夹具上通过"误当"真实世界安全"，或让夹具与元模型共享同一个建模偏差，系统就会在大量廉价、同源、低保真试验制造的**覆盖幻觉**中，比第 57 轮更快地以"可复现"为名做出错误承诺；必须以"新证据只许证伪、不许证实"、保真度入账与传输界、换件即回滚、不可逆接触硬门四重纪律，宁可承认"没造出来的世界仍未验证"。

def falsification_bench(cp, M, hypotheses, budget):
    best, best_gain = None, 0.0
    for h in hypotheses:
        F = bench.pick_or_build(h)                  # 打印/切割/复用夹具
        gain = expected_info_gain(h, cp, M) / (F.tau + F.cost + 1e-6)
        if gain > best_gain and admissible_fixture(F):
            best, best_gain = (h, F), gain
    if best_gain < theta_fab:
        return None                                  # 宁可绕行，也不刷无信息原型
    h, F = best
    y = run_paired_fixture(F, ref=bench.certified_ref)  # 与认证参考区成对
    return h, F, y

def apply_fab_outcome(M, y, F):
    if y == 'fail':                                  # 反例：强否决
        M.safe_set = contract(M.safe_set, F)
        M.theta = tighten(M.theta)
        M.ood_reg_fab.add(F.hypothesis)
    else:                                            # 正例：只弱更新装置误差
        M.hw_err = bayes_update(M.hw_err, y, w=alpha(F.f))
    M.var += (L * F.eps) ** 2                        # 传输间隙 → 强制加宽
    return M

def fidelity_accounting(residuals, f, eps, L, alpha_conf, B=5):
    buckets = stratify(residuals, by=f, bins=B)      # 保真度分层
    belts = {}
    for b, rs in buckets.items():
        belts[b] = conformal(rs, alpha=alpha_conf / len(buckets))  # union bound
    floor = (L * eps) ** 2
    return belts, floor                              # 后验/区间至少加宽 floor

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| HAP | O(\|𝒞\|+\|ℰ\|) 归因；缓存后 O(1) | O(\|𝒞\|+\|ℰ\|) | 溯源完整、校准有效、换件回滚（A45） |
| RFP | 离线 O(τ_F+c_F)；在线 O(\|ℋ\|) | O(\|𝔽\|) | 只作证伪、夹具可复用、预算受限（A46） |
| FAC | O(\|B\|·N_cal) | O(\|B\|·N_cal) | 保真度诚实、覆盖 union bound、传输界（A47） |
| HIL-C | 离线 O(\|𝔽\|·N_pair) | O(\|𝔽\|) | 成对试验、OOD 分账、仅授权 L0/L1 |
| HTS | O(1)+O(H_swap) | O(\|𝒞\|) | 单向有界、回滚完备（A48） |
| PCE³ | O(\|CP\|·(k_p+k_c+k_f)·(C_VOI+d)+A*) | O(\|V\|+\|σ\|+\|𝔽\|) | 三通道 VOI、k_p+k_c+k_f 终止 |

**正确性定理（Provenance-Fabrication-Fidelity Soundness, PFFS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A45)** 溯源/校准声明诚实，未重标换件检出率 `≥1−δ_swap`、溯源域回滚完备；**(A46)** 夹具保真度与偏离界诚实，`fab` 证据只进入否决/重标定通道；**(A47)** 保真度分层共形覆盖 `≥1−α−δ_fid`，传输间隙满足 `|R_dep−R_F|≤L·ε_F`；**(A48)** HTS 单向有界，全局硬界不因认证恢复而放宽。则：

1. **承诺健全性**：`P(fail) ≤ δ_f+ε_meta(k)+δ_probe+ε_h+δ_ood·α_conf+δ_xm·1[L1]+δ_swap+δ_fid+L·ε_F`；`fab` 的 `pass` 项系数为 0。
2. **反例单调性**：对任意夹具集合与任意反例，授权安全集单调收缩、阈值单调抬高；不存在"多做原型更敢承诺"的升险路径。
3. **溯源完整性**：未归因/未认证/校准过期/换件未重标的测量无法进入承诺链；`A=C` 不进入世界似然，只用于"允许被考虑"。
4. **终止性与部署界**：每检查点 `fab≤k_fab`，PCE³ 终止于四态；对检查点取联合界：
```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf
                   + δ_xm·1[L1] + δ_swap + δ_fid + L·ε_F)
             − P(𝓜 陈旧未检出) − P(护盾回退失败) − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```
关键：**溯源给可审计性、原型给反例、保真度给折扣；三者都不扩张安全集**。第 57 轮的"效率与安全解耦"在本轮加强为"**证伪与证实解耦**"：越多的原型试验只能让系统更保守，不能让它更自信。

### 5.1 赛事痛点与切入点

UniBot 世界挑战赛（Unitree G1 平台、32 项桌面任务、5 类泛化场景、通才模型单模型评测）当前的公开瓶颈是：**榜首成功率仍低、泛化轴多、真实数据昂贵、跨实验室复现困难**。本轮不另造一个 VLA，而是给现有 VLA/数据/评测管线加三层"物理证据基础设施"：

1. **RFP → 定向数据工厂**：用 3D 打印/激光切割快速制造五类泛化轴的夹具与道具，针对失败模式批量采集"难例"，比盲目扩大真实数据更便宜；所有夹具记录 `δ_F` 与 `f_F`，避免把夹具过拟合当成泛化。

## 7. 本轮最大风险

**一句话**：本轮把"装置可信"与"世界被覆盖"分别押在开源硬件溯源和快速原型反例上，但溯源只证明是谁在测、原型只证明哪条假设被证伪，二者都不证明真实分布已被覆盖——若把"护照齐全"误当"测得准"、把"夹具通过"误当"真实安全"，或让夹具与元模型共享同一个建模偏差，系统就会在大量廉价、同源、低保真试验制造的**覆盖幻觉**中，比第 57 轮更快地以"可复现"为名做出错误承诺；必须以"新证据只许证伪、不许证实"、保真度入账与传输界、换件即回滚、不可逆接触硬门四重纪律，宁可承认"没造出来的世界仍未验证"。
