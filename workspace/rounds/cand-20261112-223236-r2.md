# 第 62 轮（承接第 61 轮「具身语义进化闭环」ESEC / IP-173~182；灵感循环第 8 轮；本轮灵感：「双足机器人」×「腕部相机」）

> 第 61 轮把固定基座机械臂的「场景→意图→约束→阻抗→证据」统一进 USR，用 MEL 做零样本物理属性推断、DMS 做多轮对话接地、SRT-Dual 解耦语义流与实时流。但那套闭环**隐含了一个从未被检验的静态世界假设**：
> 1. **固定基座假设失效**：USR 语义锚点默认在世界系、基座不动。双足是浮动基座，行走时 base 位姿持续变化——同一个 `scene_emb` 对应的观测视角、接触集合、支撑多边形都在变，**「时间新鲜」不等于「几何新鲜 / 语义新鲜」**。
> 2. **被动外部视觉假设失效**：MEL 消费固定外部相机。腕部相机是 eye-in-hand：窄视场、随臂运动、易被自身或工件遮挡；`scene_emb` 强烈依赖视角，而且**「看哪里」本身就是一个可决策的动作**。
> 3. **操作-平衡解耦假设失效**：EEIS 仅按任务力/阻抗编译 `K_safe`，完全不管末端反作用力经全身雅可比映射到 CoM/ZMP——在窄支撑或单脚支撑相位，一个「任务最优」的刚度可能直接把机器人推倒。
> 4. **实时流与步态相位无关**：双足每一步的足底冲击是脉冲扰动，会污染力/触觉证据、让 DMS 误报「滑移」、让阻抗跟踪出现瞬态超调。
> 5. **预算缺少「看」与「走」**：PCE+++++ 只覆盖语义/执行/大模型，没有「视角重定向成本」与「迈步成本」；而双足恰恰可以在「看不清」时选择「走一步再看」。

## 0. 直觉与动机

**灵感 1（双足机器人 → 浮动基座全身语义锚定 FSA）**
直觉：第 61 轮的锚点 `Anchor_t = (scene_emb, intent_emb, phys_prior, ts, version)` 是一个**「上帝视角的不动快照」**。真实的双足机器人没有不动的地面，也没有不动的相机。关键洞见：把锚点升级为**浮动基座语义锚（FSA）**，显式携带 `(^W T_B, Σ_B, C_t, γ_gait, ^B T_C, o_vis)`。锚点有效必须同时满足**三重新鲜度**：时间新鲜（`now − ts < τ_fresh`）、几何新鲜（基座位姿漂移 < ε_pose 且重投影误差 < ε_reproj）、语义新鲜（当前观测嵌入与锚点嵌入的一致性 `C_sem ≥ τ_csem`）。更锋利的一点：**语义嵌入不是 SE(3) 等变的**——基座移动时不能把 `scene_emb` 刚性变换过去；只能传播物理先验 `φ_phys` 与接触集合 `C_t`，语义嵌入必须标脏后重推理（或走等变投影头）。这从根上否定了「一个向量走天下」。

**灵感 2（腕部相机 → 视角条件语义编码 VCSE + 主动腕部感知 AWP）**
直觉：腕部相机的观测是**视角条件的**：`z_scene = E_scene(V; ^W T_C)`。同一物体从不同视角给出不同嵌入，且近距时会自遮挡、运动模糊。关键洞见：引入**可观测性分数 o(v) ∈ [0,1]**（任务相关表面片的可见度 × 分辨率 × 入射角），把「看不清」变成一个可计算的量；再把它接进动作空间 `A_perc = {wrist_reorient, servo_align, retreat, orbit, step}`。决策用 VOI：`a* = argmax [IG(a) − λ_g cost_gaze − λ_l cost_step]`。**「迈一步再看」不是散步，而是主动获取大视差基线**——深度不确定主导时（`σ_z² ∝ z²/(f·b)`），迈步的信息增益远高于腕部旋转；自遮挡主导时，腕部重定向更值。这一条把感知、行走、操作真正焊在一起。

**灵感 3（双足 × 腕相机 → 阻抗-平衡可行域 IBFS + 平衡条件化编译 BCI）**
直觉：这是本轮最硬的一条。末端阻抗产生的反作用力 `f = K_p Δx + K_d Δẋ` 会经全身动力学改变 CoM 加速度与 ZMP。第 61 轮把 `K` 当自由变量，双足上它必须满足**平衡可行域**。关键洞见：给定扰动 `e = [Δx; Δẋ]` 的分布 `N(0, Σ_e)`，ZMP 关于反作用力是（局部）线性的 `p_zmp = p_zmp⁰ + J_z f`，于是「ZMP 以概率 1−α 留在支撑多边形内」可写成对 `K` 的**线性矩阵不等式（LMI）**：`J_z K Σ_e Kᵀ J_zᵀ ⪯ (m_max / z_{1−α/2})²`。这是一个凸可行域 `IBFS`，可在其中求离 `K_prior` 最近的解。实时路径不必解 SDP：用一个各向同性收缩因子 `s = min(1, min_j m_j^max / (z_{1−α/2}·√(g_jᵀ K Σ_e Kᵀ g_j)))`，`K_safe = s·K_prior`，O(d²) 微秒级完成，保证「先站住，再干活」。

**灵感 4（步态相位门控 → SRT-Dual-G + 接触相位证据净化 CPE）**
直觉：双足的接触是**离散事件**（足跟触地、足尖离地、摆动相、双支撑相）。冲击瞬间的加速度脉冲会污染力/触觉证据，使 `EV-exec` 出现假「滑移/振动」。关键洞见：把步态相位 `γ_gait` 与接触集合 `C_t` 提升为一等公民——①冲击窗口 `W_imp` 内冻结/限速阻抗更新；②`EV-exec` 打上「脉冲污染」标记并把可靠性 `r` 传给 DMS，滑移告警需跨窗口持续才触发；③单脚支撑相自动收缩 IBFS 与锚点协方差；④实时流拒绝「接触集合不一致」的语义锚点（双支撑时推断的先验不能直接用于单脚支撑）。

**灵感 5（PCE++++++ → 八维认知-感知-运动预算）**
直觉：第 61 轮 `B_cog5`（实为六维）缺少「看」与「走」。扩展为 **`B_cog8 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_loco, B_gaze)`**：`B_gaze = (视角重定向频率, 腕关节速度, 运动模糊, 遮挡容忍)`；`B_loco = (步频, 能量, CoM 偏移, 步态切换)`。VOI 变成 `voi_8 = IG − cost_mel − cost_usr − cost_exec − cost_gaze − cost_loco`。级联降级：**视角重定向 → 迈步代偿 → 冻结语义锚点 → 纯保守编译**，无论怎么降，`IBFS` 与 ERTC 实时契约绝不降级。

**本轮的核心科学问题（一句话）**：当「看清（腕部相机）」与「站住（双足平衡）」与「干活（末端阻抗）」共享同一具身体时，如何在一个**几何/语义/接触都在漂移**的世界里，仍然给出可证明的语义-控制一致性与平衡安全性？

## 1. 形式化定义（增量：定义 173–184）

**定义 173（浮动基座语义锚 FSA）** 语义锚升级为观测记录
```
A_t = (version, z_scene, intent_emb, φ_phys, ^W T_B, Σ_B, C_t, γ_gait, ^B T_C, o_vis, r_ev, ts)
```
- `^W T_B, Σ_B`：基座在世界系位姿及其协方差（来自腿部里程计/IMU 融合）
- `C_t ⊆ {L_foot, R_foot}`：当前接触集合；`γ_gait ∈ [0,1)`：步态相位
- `^B T_C`：腕部相机相对基座位姿；`o_vis ∈ [0,1]`：该视角的任务可观测性
- `r_ev ∈ [0,1]`：最近证据可靠性（由 CPE 给出）
- 关键：`z_scene` 是**在 `^W T_C` 下观测到的嵌入**，与位姿绑定；不是世界系不变量

**定义 174（三重新鲜度与锚点传播 TFA）** 有效性判定与降级传播
```
fresh_time = (now − A_t.ts) < τ_fresh
fresh_geo  = d_SE3(^W T_B(now), A_t.^W T_B) < ε_pose
             ∧ mean_{p∈L_vis} ‖π(p; ^W T_C(now)) − π(p; A_t.^W T_C)‖ < ε_reproj
fresh_sem  = C_sem(z_scene(now), A_t.z_scene) ≥ τ_csem
Valid(A_t) = fresh_time ∧ fresh_geo ∧ fresh_sem
```
当基座移动但无新语义观测时，仅允许**受限传播**：
```
Σ_B' = A(Δt) Σ_B A(Δt)ᵀ + Σ_odom
φ_phys' = φ_phys ⊕ w_motion,  Σ_φ' = Σ_φ + Q_motion
z_scene' = z_scene 且置 semantic_degraded = True   # 不做刚性旋转
```
（因为 `E_scene` 对 SE(3) 不等变；刚性旋转嵌入在数学上无定义。）

**定义 175（视角条件语义编码 VCSE）** 全局-腕部双尺度融合
```
z_scene = Fuse( z_global, z_wrist, o_vis )
z_wrist = E_scene(V_wrist; ^B T_C)
o_vis   = min_{p ∈ P_task} [ vis(p, v) · min(1, f·r_p / (d_p · cos θ_p)) ]
```
- `vis`：遮挡指示（含自遮挡、工件遮挡）；`f` 焦距、`r_p` 表面分辨率、`d_p` 距离、`θ_p` 入射角
- `o_vis < o_min` 时腕部支路降权，回退全局外部相机支路
- 多视角一致性用对比对齐：同一物理状态不同视角的嵌入互为正样本，不同状态为负样本（避免直接要求等变）

**定义 176（主动腕部感知 AWP）** 视角即动作
```
A_perc = {wrist_reorient(Δq), servo_align(target), retreat(d), orbit(ψ), step(foot, Δx)}
IG(a)  = H(φ_phys | obs) − E_{o'∼p(·|a)} H(φ_phys | obs, o')
VOI(a) = IG(a) − λ_g·cost_gaze(a) − λ_l·cost_step(a) − λ_t·t(a)
a* = argmax_{a∈A_perc} VOI(a)
     s.t. a 的基座/关节轨迹 ∈ IBFS，且不进入冲击窗口
```
判据（深度 vs 遮挡）：深度不确定主导时优先 `step`（基线 `b` 增大，`σ_z² ∝ z²/(f·b)`）；自遮挡/局部材质主导时优先 `wrist_reorient`。

**定义 177（阻抗-平衡可行域 IBFS）** 把「别推倒自己」写成对 K 的约束
对扰动 `e=[Δx;Δẋ] ∼ N(0,Σ_e)`，反作用外力的 ZMP 线性化 `p_zmp = p_zmp⁰ + J_z f`，`f = K e`（`K=[K_p K_d]`）。定义
```
IBFS = { K : ∀j, P( |(J_z K e)_j| ≤ m_j^max ) ≥ 1−α,
               K_d ⪰ K_d_min ≻ 0,
               f ∈ F_friction ∩ [−F_brittle, F_brittle] }
```
其单侧概率约束等价于 LMI：`(J_z K) Σ_e (J_z K)ᵀ ⪯ diag(m_j^max / z_{1−α/2})²`。

**定义 178（平衡条件化阻抗编译 BCI）** 先平衡、后任务
```
离线:  K_ref = argmin_K ‖W(K − K_prior)‖_F²   s.t.  K ∈ IBFS        (SDP)
实时:  s = min(1, min_j  m_j^max / (z_{1−α/2}·√(g_jᵀ K_prior Σ_e K_priorᵀ g_j)))
       K_safe = clip(s·K_prior, K_min, K_max)                        (O(d²), ~µs)
若 s < s_min ⇒ IBFS 近似为空：触发「迈步/重心前移」恢复支撑，或降级为最小刚度 κ_min
```
`K_safe` 是任务刚度与平衡裕度之间的**Pareto 前沿**：`s` 越小越稳、越难干活。

**定义 179（步态相位门控双流 SRT-Dual-G）** 三时钟 + 事件回调
```
语义流      f_sem ∈ [10,100]Hz : MEL → DMS → USR.commit → AWP
全身实时流  f_rt  = 1kHz       : FSA.read → BCI → WBC.dispatch
步态/接触   事件触发            : 足跟触地 / 足尖离地 / 双支撑切换
门控规则:
  (a) t ∈ W_imp(t_strike) = [t_s − δ_pre, t_s + δ_post]: 冻结阻抗更新、扩大 Σ_anchor
  (b) C_t = {single} ⇒ K_p^max ← β_ss·K_p^max (β_ss<1)，Σ_anchor ← ρ·Σ_anchor (ρ>1)
  (c) C_t = {L,R}   ⇒ 允许最大支撑多边形与完整 IBFS
  (d) 实时流拒绝 C_t(anchor) ≠ C_t(now) 的锚点
```

**定义 180（接触相位证据净化 CPE）** 脉冲感知的证据
```
I_imp = 1[ t ∈ W_imp ] ∨ 1[ ‖a_com‖ > a_thresh ]
EV_purified = RobustFilter(EV_raw; Huber, window=W)
slip_alarm  ⇔  (slip_residual > τ_slip) for N_out 个非冲击窗口连续成立
r_ev = exp(−(n_out_imp/ N_imp)) · (1 − I_imp·0.5)       ∈ [0,1]
```
DMS 仅在 `r_ev ≥ r_min` 时才把滑移/振动转成对话动作。

**定义 181（全身接触一致跨模态对账 XMC-WB）** 在 USR 基础上加接触一致性
```
D⁺_wb = D⁺_sem + ‖C_t(anchor) − C_t(now)‖_H + w_p·|p_zmp − p_zmp^target|
        + w_o·(1 − o_vis) + w_r·(1 − r_ev)
XMC-WB 输出 fused_wb 与 D⁺_wb；D⁺_wb > τ_wb 触发 MEL 重推理 + AWP 重选视角
```

**定义 182（全身语义-平衡联合证书 J_wb）**
```
J_wb = (J_sem_exec, δ_zmp, p_zmp, C_t, o_vis, γ_gait, r_ev, trace(Σ_B), anchor_version)
Valid(J_wb) ⇔ Valid(J_sem_exec)
             ∧ δ_zmp = dist(p_zmp, ∂P_support) ≥ δ_min
             ∧ C_t(anchor) = C_t(now)
             ∧ o_vis ≥ o_min
             ∧ r_ev ≥ r_min
             ∧ trace(Σ_B) ≤ σ_B^max
```

**定义 183（八维认知-感知-运动预算 PCE++++++）**
```
B_cog8 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_loco, B_gaze)
B_gaze = (retarget_rate, wrist_vel, blur_tol, occlusion_tol)
B_loco = (step_rate, energy_budget, com_dev_budget, transition_budget)
voi_8(a) = IG(a) − cost_mel − cost_usr − cost_exec − cost_gaze − cost_loco
```
级联降级（安全项永不降级）：
```
B_gaze 耗尽 ⇒ 禁止 wrist_reorient/orbit，仅保留必需的 servo_align
B_loco 耗尽 ⇒ 禁止 step，AWP 只能腕部重定向
两者皆耗尽 ⇒ 冻结语义锚点，仅用 φ_phys 传播 + 保守 IBFS 编译
```

**定义 184（移动主动感知闭环 LAPC + 主动零样本物理推断 AZPI）**
```
LAPC(M, V_wrist, V_global, T, P, L, δ_f):
  语义流:  (φ, z, π, U) ← MEL.infer(V_global, V_wrist, T, P, L, M.anchor)
           a_perc ← AWP.select(VOI, B_cog8, IBFS)
           a_diag ← DMS.step(U, EV_purified)
           A_t ← FSA.commit(z, intent_emb, φ, base_pose, C_t, γ_gait, o_vis)
  实时流:  A_t ← FSA.read(); if not Valid(A_t): 受限传播/保守扩展
           K_prior ← Π(A_t.z + A_t.intent_emb)
           K_safe ← BCI.compile(K_prior, C_t, γ_gait, Σ_e)
           WBC.dispatch(K_safe); EV_raw ← wait_contact()
           EV_purified, r_ev ← CPE(EV_raw, γ_gait)
           J_wb ← certify(...); if ¬Valid(J_wb): 保守回退
```
AZPI：`φ* = argmax_φ P(φ | V_{1:n*}, T, P)`，其中视角序列 `{v_i}` 由 AWP 选择以最大化期望信息增益 `Σ IG(a_i)`；主动视角应使后验熵 `H(φ|·) ≤ H_0 − Σ IG(a_i)`，从而把零样本物理属性误差从被动观测的 `δ_phys` 降到 `δ_phys^active`。

## 2. 一句话风险

**本轮最大风险**：「感知（腕部相机）—平衡（双足）—操作（末端阻抗）」三者的可行域在某些相位（单脚支撑 + 窄支撑 + 腕部自遮挡）可能**同时收缩到空集**，系统在「看不清、站不稳、动不了」之间陷入保守死锁或被迫牺牲平衡；必须在线检验 `IBFS ≠ ∅` 与 `P_support` 非退化，并预置「迈步恢复支撑 / 主动撤退观察 / 最小刚度 κ_min」的分层兜底。

```python
class TaskConditionedDetector:
    def __init__(self, backbone, d_us=256, safe_reserve=0.2,
                 r_min=0.95, ece_target=0.05):
        self.backbone = backbone
        self.q_task = OpenVocabQueryHead(d_us)      # 可被 B_det 裁剪
        self.q_safe = SafetyQueryHead()             # 固定负障碍查询，永不裁剪
        self.head_exist = CalibratedExistenceHead()
        self.head_pose = SE3PoseHead()
        self.head_unc = CovarianceHead(conservative=True)
        self.head_aff = AffordanceHead()
        self.safe_reserve = safe_reserve
        self.r_min = r_min
        self.ece_target = ece_target

    def detect(self, obs, q_task, proposals=None):
        # 1) 共享骨干（多视角 RGB-D）
        f = self.backbone(obs.images, obs.depth, obs.K)
        # 2) 双头并行：任务条件头 + 安全头
        cand_task = self.q_task(f, q_task, proposals)      # 开放词汇 proposal
        cand_safe = self.q_safe(f)                         # 边缘/缝隙/透明/运动/形变
        # 3) 安全头召回优先：先保留全部安全候选，再合并任务候选
        cand = merge_with_priority(cand_safe, cand_task,
                                   safe_reserve=self.safe_reserve)
        # 4) 逐候选解码头
        Y = []
        for c in cand:
            p = self.head_exist(f, c)                      # 校准后的存在概率
            T, b, Sigma = self.head_pose(f, c)             # SE(3) + 保守协方差
            o = self.occlusion_state(f, c)
            a = self.head_aff(f, c)
            r = cosine(E_det(c), E_intent(q_task))         # 接触相关性
            Y.append(Detection(c.class_open, c.mask, T, b, p, Sigma, o, a, r))
        # 5) 校准自检：ECE 超限则扩大协方差并降 r
        if self.ece(Y) > self.ece_target:
            for y in Y:
                y.Sigma = inflate(y.Sigma, kappa=1.5)
                y.r *= 0.8
        return Y
```

### IP-184 POH（概率物体假设集）

```python
class ProbabilisticObjectHypotheses:
    def __init__(self, gamma_d=0.98, q_proc=1e-4, e_min=0.3, r_min=0.3):
        self.H = {}
        self.gamma_d = gamma_d
        self.q_proc = q_proc
        self.e_min = e_min
        self.r_min = r_min

    def predict(self, dt, world_model, last_action):
        # 世界模型给先验；未观测假设协方差随时间增长
        for h in self.H.values():
            h.T = world_model.predict_pose(h, last_action, dt)
            h.Sigma = h.Sigma + self.q_proc * np.eye(6) * dt
            if h.occluded:
                h.e *= self.gamma_d ** (dt * 30)          # 缓慢衰减，不立即删除
        return self.H

    def update(self, Y, dwmc):
        matches, unmatched_h, unmatched_y = dwmc.match(self.H, Y)
        for h, y in matches:
            # 存在性对数几率贝叶斯更新
            h.e = sigmoid(logit(h.e) + log_likelihood_ratio(y, h))
            h.T, h.Sigma = ekf_update(h.T, h.Sigma, y.T, y.Sigma)
            h.last_seen = now()
            h.occluded = (y.o != 'visible')
        for h in unmatched_h:
            h.e *= self.gamma_d
            h.occluded = True
        for y in unmatched_y:
            # 惊喜检测：安全头命中优先级最高
            provenance = 'safe_head' if y.from_safe_head else 'task_head'
            self.H[new_id()] = Hypothesis.from_detection(y, provenance)
        # 低存在性且长时间未观测才删除，保留物体永久性
        self.H = {k: h for k, h in self.H.items()
                  if h.e >= 0.05 or h.age < T_MAX}
        return self.contact_relevant()

    def contact_relevant(self):
        return [h for h in self.H.values()
                if h.e >= self.e_min and h.r >= self.r_min]
```

### IP-185 LAWM（潜空间动作条件世界模型）

```python
class LatentActionWorldModel:
    def __init__(self, d_z=128, d_a=8, M=5, H=16):
        self.enc = LatentEncoder(d_z)
        self.trans = ActionConditionedTransition(d_z, d_a)
        self.dec_o = ObservationDecoder()
        self.dec_c = ContactDecoder()                 # 力/位姿
        self.head_fail = FailureHead(n_kinds=4)       # slip/collision/force/drop
        self.ensemble = [copy.deepcopy(self) for _ in range(M)]
        self.d_z, self.H = d_z, H

    def encode(self, obs, Hc):
        return self.enc(obs.images, obs.depth, obs.proprio, Hc)

    def rollout(self, z0, actions):
        # actions: [a_0, ..., a_{H-1}]，a 为阻抗/运动命令
        rollouts = []
        for model in self.ensemble:
            z = z0
            traj = []
            for tau, a in enumerate(actions):
                z = model.trans.sample(z, a)
                F, T = model.dec_c(z)
                p_fail = model.head_fail(z, a)
                traj.append(RolloutStep(tau, z, F, T, p_fail))
            rollouts.append(traj)
        # 集成统计：均值 + 认知不确定性（保守取上分位）
        return aggregate(rollouts, conservative=True)

    def risk(self, K, z0, H):
        # 候选阻抗 K 的反事实 rollout：返回 CVaR 与安全概率
        actions = expand_impedance_to_actions(K, H)
        R = self.rollout(z0, actions)
        violations = [any(step.p_fail > TAU_FAIL for step in traj)
                      for traj in R.members]
        P_safe = 1.0 - np.mean(violations)
        losses = [self.loss(traj) for traj in R.members]
        cvar = mean(sorted(losses)[-max(1, int(ALPHA * len(losses))):])
        return P_safe, cvar, R.uncertainty
```

### IP-186 DWMC（检测-世界模型互校正）/ XMC-dw

```python
class DetectionWorldModelCorrection:
    def __init__(self, s_min=0.55, u_surprise=0.6,
                 chi2_thresh=CHI2_095, k_alarm=3):
        self.s_min, self.u_surprise = s_min, u_surprise
        self.chi2_thresh, self.k_alarm = chi2_thresh, k_alarm
        self.alarm_count = 0
        self.pending_reset = False

    def match(self, H, Y):
        # 匈牙利匹配：类别/开放词汇 + 位姿 + 掩码 IoU
        C = cost_matrix(H, Y)
        matches, unmatched_h, unmatched_y = hungarian(C)
        return matches, unmatched_h, unmatched_y

    def support(self, h, y, Sigma_wm):
        d2 = mahalanobis(y.det, predict_measurement(h), Sigma_wm + y.Sigma)
        return y.p * mask_iou(h.mask, y.mask) * np.exp(-0.5 * d2), d2

    def arbitrate(self, H, Y, Sigma_wm):
        stats = {'support': [], 'innovation': [], 'hallucination': 0,
                 'surprise': 0, 'beta': 1.0, 'H': H, 'Y': Y}
        for h, y in self.match(H, Y)[0]:
            s, d2 = self.support(h, y, Sigma_wm)
            h.supported = s >= self.s_min
            h.unsupported = not h.supported
            stats['support'].append(s)
            stats['innovation'].append(d2)
            if d2 > self.chi2_thresh:
                self.alarm_count += 1
            else:
                self.alarm_count = 0
        for h in H:
            if not h.supported:
                stats['hallucination'] += 1
                h.Sigma *= 2.0                    # 无支撑：不作控制先验
        for y in Y:
            if y.unmatched:
                stats['surprise'] += 1
                if y.from_safe_head:
                    trigger_immediate_tightening(y)   # 安全优先
        mean_s = np.mean(stats['support'] or [0])
        mean_d2 = np.mean(stats['innovation'] or [0])
        stats['beta'] = sigmoid(A0 + A1 * mean_s - A2 * mean_d2
                                - A3 * stats['hallucination'] / max(1, len(H)))
        if self.alarm_count >= self.k_alarm:
            self.reality_gap_alarm()                 # 重置 WM 潜变量
        return stats

    def reality_gap_alarm(self):
        # 连续多帧新息超限：模型漂移，重置潜在并放大协方差
        self.alarm_count = 0
        self.pending_reset = True
        self.inflate_all_covariances(kappa=2.0)
```

```python
class PredictiveAnchorTube:
    def __init__(self, H=16, rho0=0.02, v_max=1.0):
        self.H, self.rho0, self.v_max = H, rho0, v_max

    def build(self, t0, z0, Hc, wm, isg, det_bounds, hard_bounds):
        stages = []
        z = z0
        for tau in range(self.H):
            # 每个候选阻抗先过 ISG；只保留认证集
            K_set = isg.admissible_set(z, det_bounds, hard_bounds, wm)
            F_env = wm.predict_force_envelope(z, K_set, quantile=0.95)
            Sigma_tube = wm.predict_covariance(z) + (self.rho0 + self.v_max * tau) ** 2 * np.eye(6)
            stages.append(TubeStage(tau, K_set, F_env, Sigma_tube,
                                    support=wm.support(z), valid=len(K_set) > 0))
            z = wm.transition_mean(z, choose_nominal(K_set))
        # 硬约束：不确定度随时域单调不减
        assert all(stages[i].Sigma_tube.trace() <= stages[i + 1].Sigma_tube.trace()
                   for i in range(len(stages) - 1))
        return AnchorTube(t0=t0, stages=stages, version=next_version())

    def slice(self, now, tube, last_valid=None):
        tau = int((now - tube.t0) / DT)
        if 0 <= tau < len(tube.stages) and tube.stages[tau].valid:
            return tube.stages[tau]
        if last_valid is not None:
            return inflate(last_valid, kappa=1.2)     # 过期切片保守扩展
        return None                                   # 无有效管 => K_⊥
```

### IP-188 ISG（想象安全门）与 WCR

```python
class ImaginationSafetyGate:
    def __init__(self, wm, alpha=0.1, delta=0.05, eps=0.01,
                 beta_min=0.6, margin_extra=1.2):
        self.wm = wm
        self.alpha, self.delta, self.eps = alpha, delta, eps
        self.beta_min, self.margin_extra = beta_min, margin_extra

    def admissible_set(self, z, K_det, K_hard, wm, beta=1.0):
        # K_det 由检测/POH/物理下界给出，且恒有 K_det ⊆ K_hard
        base = intersect(K_det, K_hard)
        if beta < self.beta_min:
            # WM 不可信：只解释，不参与收紧；额外安全裕度
            return tighten(base, factor=self.margin_extra)
        wm_set = []
        for K in base:
            P_safe, cvar, U = wm.risk(K, z, H=wm.H)
            if P_safe >= 1 - self.delta and cvar <= self.eps:
                wm_set.append(K)
        # 只收紧不放松：一定是 base 的子集
        return intersect(base, wm_set)

    def filter(self, K_prior, z, tube_stage, K_det, K_hard, K_fallback):
        adm = self.admissible_set(z, K_det, K_hard,
                                  self.wm, beta=tube_stage.beta)
        if K_prior in adm:
            return K_prior
        if adm:
            return argmax_utility(adm)
        return K_fallback                              # 非空安全回退核
```

### IP-189 CFD（反事实诊断对话）

```python
class CounterfactualDialogueDiagnosis:
    def __init__(self, c_min=0.7, sigma_wm=0.5, delta_min=0.05):
        self.c_min, self.sigma_wm, self.delta_min = c_min, sigma_wm, delta_min

    def cfr(self, K_prime, support, U_wm, in_support, delta_risk):
        return (support * np.exp(-U_wm / self.sigma_wm)
                * float(in_support) * float(abs(delta_risk) >= self.delta_min))

    def explain(self, K_exec, K_prime, wm, z, support):
        p0, _, _ = wm.risk(K_exec, z)
        p1, cvar, U = wm.risk(K_prime, z)
        delta = p1 - p0
        cf = self.cfr(K_prime, support, U, in_support=True, delta_risk=delta)
        if cf < self.c_min:
            return DialogueAction('ask_clarify',
                                  question='我无法可靠预测该改动，建议先做一次低风险探针，确认？',
                                  evidence={'CFR': cf})
        text = (f'若将 K 调整为 {K_prime}，预测滑移概率 '
                f'{p0:.2f}→{p1:.2f}（区间 [{p1 - U:.2f},{p1 + U:.2f}]），'
                f'支持度 {support:.2f}，CFR {cf:.2f}。')
        return DialogueAction('explain_counterfactual', text=text,
                              evidence={'CFR': cf, 'U_wm': U, 'CVaR': cvar})
```

```python
def DWEC(robot, obs, L, delta_f_req):
    # ---------------- 检测-想象流 10-30Hz ----------------
    q_task = robot.usr.intent_query(L, robot.dms.b_intent)
    H_prior = robot.poh.predict(robot.dt, robot.lawm, robot.last_action)
    Y = robot.tcd.detect(obs, q_task, proposals=H_prior.proposals())
    Hc = robot.poh.update(Y, robot.dwmc)
    z = robot.lawm.encode(obs, Hc)
    dw_stats = robot.dwmc.arbitrate(H_prior, Y, robot.wm_sigma)
    if robot.dwmc.pending_reset:
        z = robot.lawm.encode(obs, Hc)                # 潜变量重置
        robot.dwmc.pending_reset = False
    tube = robot.pat.build(now(), z, Hc, robot.lawm, robot.isg,
                           robot.det_bounds(Hc), robot.hard_bounds)
    robot.usr.commit_wm(Hc, z, dw_stats, tube)

    # ---------------- 语义流 5-30Hz ----------------
    phi, z_scene, pi, U = robot.mel.infer(
        obs.V, obs.T, obs.P, L,
        robot.usr.object_emb(Hc), robot.usr.wm_summary(tube, dw_stats))
    a_diag, C_pending, b_intent = robot.dms.step(
        U, dw_stats, robot.cfd, robot.usr.wm_summary(tube, dw_stats))
    if a_diag.type in ('explain_counterfactual', 'propose_constraint_from_cf'):
        robot.dms.audit(a_diag, cf=robot.cfd.last_certificate)

    # ---------------- 实时流 1-10kHz ----------------
    stage = robot.pat.slice(now(), tube, robot.last_stage)
    if stage is None:
        K_safe = robot.K_fallback                     # 非空安全回退核
    else:
        K_prior = robot.usr.project_wm(robot.usr.anchor, stage)
        K_safe = robot.isg.filter(K_prior, z, stage,
                                  robot.det_bounds(Hc),
                                  robot.hard_bounds,
                                  robot.K_fallback)
        K_safe = robot.eeis.compile_with_prior(
            delta_f_req, K_safe, stage.F_env, phi)

    cert = robot.ertc.dispatch(K_safe)
    EV = robot.wait_contact()
    if tube.breached(EV):
        robot.pat.mark_breach(tube)
        robot.dwmc.request_recompute()
        K_safe = robot.K_fallback
        cert = robot.ertc.dispatch(K_safe)

    # ---------------- 校准回路（低频） ----------------
    robot.poh.update_from_evidence(EV)
    robot.lawm.calibrate(EV)                          # PIT / 集成方差
    robot.tcd.calibrate(EV)                           # ECE / 协方差
    J = build_Jdw(cert, dw_stats, robot.tcd.stats(), tube,
                  robot.lawm.stats(), robot.cfd.stats(), EV, K_safe)
    return K_safe, EV, J
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TCD | 骨干 O(N_pix·d)；双头 O(N_q·d) | 骨干 + proposal 缓存 ~1–2GB | 安全头召回 ≥ r_min；存在概率 ECE ≤ ε_cal；协方差保守 |
| POH | 匹配 O(N_h·N_y)（匈牙利小规模）；更新 O(N_h) | O(N_h·d) | 存在性贝叶斯更新；遮挡不立即删除；Σ 随未观测时间增长 |
| LAWM | rollout O(H·M·(d_z²+d_z d_a)) | M×模型 ~0.5–1.5GB | 集成不确定性覆盖真实误差（校准）；失败概率有界 |
| DWMC | O(N_h·N_y) | O(N_h) | 支持度/新息一致；无支撑预测不作控制先验；现实鸿沟告警 |
| PAT | 构建 O(H·|𝒦|·M)；实时切片 O(1) | O(H·|𝒦|) | 管不确定度随时域单调不减；破管必回退 K_⊥ |
| ISG | O(|𝒦_det|·M·H)（离线/低频）；实时 O(1) | O(|𝒦|) | 𝒦_adm ⊆ 𝒦_det ∩ 𝒦_hard；非空回退核 |
| CFD | O(M·H) 反事实 | O(1) | CFR < c_min 禁止断言；解释可追溯 |
| PCE+++++++ | O(1) 预算检查 | O(1) | 安全头保留预算；降级不降低安全约束 |
| J_dw | O(1) 组装 | O(1) | 所有门控项可审计；任一失败拒绝签发 |

**正确性定理（DWEC-Complete）**：
假设第 61 轮 A61–A70 成立，并新增：
- **(A71) 检测校准**：TCD 的存在概率与位姿协方差校准良好（ECE ≤ ε_cal，Σ_pred ⪰ Σ_true），安全头召回 ≥ r_min，且安全头保留预算永不被裁剪；
- **(A72) POH 一致性**：存在性/位姿更新为贝叶斯/ EKF 形式，未匹配假设按 γ_d 衰减，协方差随未观测时间单调增长；
- **(A73) LAWM 校准**：集成模型对真实下一状态的可信集覆盖率 ≥ 1−γ，认知不确定性 U_wm 上界真实模型误差，失败头 PIT 校准；
- **(A74) DWMC 仲裁**：支持度/新息按定义计算，测量优先规则严格执行，现实鸿沟告警在连续 k 帧 d² > χ² 后触发；
- **(A75) ISG 安全**：𝒦_det ⊆ 𝒦_hard，K_⊥ ∈ 𝒦_det ∩ 𝒦_hard 且非空；β < β_min 时世界模型不参与收紧；
- **(A76) PAT 有效性**：管切片满足 ρ(τ) 单调不减与 support(τ) 期望单调不增；破管检测覆盖力/位姿/接触事件；
- **(A77) CFR 断言门**：CFR ≥ c_min 才允许反事实断言，且 CFR 计算中的 support、U_wm、训练支撑集可审计；
- **(A78) 预算安全**：B_cog8 单调消耗，B_det 的安全头与 ISG 永不降级，B_wm 耗尽只影响预演质量。

则：
1. **检测接地与物体永久性**：对遮挡/短暂漏检，POH 的存在概率与位姿误差有界（A71+A72）；物体不会因单帧漏检被当作消失，接触相关子集 H^c 的误删率 ≤ δ_poh。
2. **想象-安全分离（WMHB）**：对任意世界模型输出（包括对抗性幻觉），dispatched K_safe ∈ 𝒦_det ∩ 𝒦_hard 或 K_safe = K_⊥（A74+A75）。因此世界模型幻觉不直接转化为力/速度违规；安全违规概率由检测校准、安全头召回与 K_⊥ 非空性界定，而非由 LAWM 精度界定。
3. **预测-测量互校**：若真实动力学在集成可信集内（A73），则无支撑预测被识别为幻觉、未解释检测被识别为惊喜（A74）；现实鸿沟告警的漏报率 ≤ γ，模型漂移不会被静默吸收。
4. **延迟鲁棒性**：实时流只消费 PAT 的 O(1) 切片，不调用 LAWM/MEL（定义 177）；语义流延迟 ≤ H·DT 时，管以单调增长的 Σ_tube 保守推进；延迟超过 H 或用尽时回退到上一有效切片 + 保守扩展；破管立即 K_⊥（A76）。
5. **反事实对话可靠性**：当 CFR ≥ c_min 时，反事实解释的预测区间以 ≥ 1−γ 概率覆盖真实风险变化；当 CFR < c_min 时，DMS 必不断言，只能请求澄清/探针（A77）。
6. **预算安全**：任一 B_cog8 维度耗尽触发对应降级；B_wm 耗尽退化为第 61 轮静态锚点 + 保守扩展，B_det 耗尽仍保留安全头并降低速度/力上限；ISG 与 K_⊥ 始终生效（A78）。

**推论（安全-性能分离）**：在 A71–A78 下，DWEC 的安全违规率不随 LAWM 规模/精度单调恶化；加大世界模型只可能提升任务成功率与前瞻性，不会降低安全下界。这为「大模型可以更激进地想象，但不能更激进地执行」提供了形式依据。

**消融设计**：
1. 去掉 POH（单帧 argmax 检测）⇒ 预期遮挡下物体永久性崩溃、抓取重试率上升；
2. 去掉 LAWM（无预演）⇒ 预期动态任务与接触瞬态成功率下降，延迟注入下退化最明显；
3. 去掉 DWMC（无条件信任 WM 或无条件信任检测）⇒ 预期幻觉/惊喜检测 AUROC 降至随机附近；
4. 去掉 ISG（允许 WM 扩展安全集）⇒ 预期对抗性幻觉注入下出现力违规，直接验证「只收紧不放松」的必要性；
5. 去掉 PAT（退回静态 anchor）⇒ 预期 200–500ms 延迟下接触力超调与破管率显著上升；
6. 去掉安全头保留预算 ⇒ 预期透明/反光/缝隙场景负障碍漏检率上升，验证双头非对称设计。

**统计与可复现**：每个实验 ≥ 5 个随机种子；报告均值 ± 95% CI；对安全指标（力违规、破管、不安全断言）使用单侧置信上界；所有 rollout 与阈值、证书字段写入 J_dw 审计日志，保证可回放。

## 5. 本轮最大风险

**一句话**：检测器与世界模型在分布外场景中可能同时失准（检测漏掉透明/反光/缝隙障碍，世界模型又自信地预测安全），而 DWMC 的支持度/信任估计若被系统性高估、或 PAT 在延迟与遮挡下破管却未触发 K_⊥，就会形成「想象-现实合谋」——这是本轮方案的最大风险；必须以检测安全头的独立保留、测量优先仲裁、只收紧不放松的 ISG、非空安全回退核与 J_dw 硬门控把想象限制在安全边界之内。
