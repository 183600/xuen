# 第 64 轮（承接第 63 轮「LIRO 几何-技能-干扰闭环」IP-193~203；灵感循环 III 第 1 轮；本轮灵感：「数据标注」×「研究空白」）

> 第 63 轮把 ROSE 推进为 LIRO：稠密几何先验（LSF）、通用技能组合（USL/CSP）、四类干扰不变表征与认证（DIR/AIC）。但第 63 轮自述的最大风险不是「几何编码器不够好」，而是一个更普遍的结构缺陷：**J_liro 是一张没有定义域的全称证书**。它默认支撑数据充分且可信，于是 E_geo 在无标注的 OOD 几何上把先验外推成确定性幻觉。
> 本轮的两个灵感词恰好构成一对对偶：**数据标注**是唯一能主动收缩无知的资源；**研究空白**是「标注也收缩不了」的那部分无知。把二者分开，我们才能同时回答两个问题：**该标什么**，以及**什么根本不是标注能解决的**。

## 0. 直觉与动机

**灵感 1（数据标注 → AAP：标注是带来源与可靠性的证据原子，不是燃料）**
直觉：现有 agent 把标注当成「越多越好的训练数据」。但安全关键系统的标注至少有三件事必须显式建模：**来源**（人类专家 H / 群包 C / 仿真 S / 弱程序 W / 基础模型自监督 F）、**可靠性**（且是区域条件化的——某标注员在训练分布内可靠，不代表在 OOD 上可靠）、**成本与证明链**（每条标签要能追溯是谁、何时、用什么验证器给的）。把标注原子化 a = (c, x, y, s, κ, w, ν, t, h)，构成 **AAP 标注原子图**。在此之上，主动标注不再「随机采样」，而是问：**这一条标注能让我证书的空白质量 β 下降多少，除以它的成本是多少？** 即标注的 value-of-information（VoI）。

**灵感 2（研究空白 → ECM + GDC：给证书补上定义域）**
直觉：一张没有定义域的证书，在分布外就是空头支票。**ECM 证据覆盖图**为每个 claim c 定义覆盖 ρ_c(x) 与空白集 Γ = {x : ρ_c(x) < δ}；**GDC 空白感知证书**把 J_liro 从全称命题改为**条件命题**：J_gala = (J_liro, Γ, coverage_spec, provenance_hash)，语义是「**在 Γ 之外** J_liro 有效；进入 Γ 必须弃权/降级/标注/探索，绝不静默超信」。这是一个 **fail-closed** 设计：宁可说「我不知道」，也绝不把幻觉包装成保证。第 63 轮的几何幻觉在这里被结构性挡住——OOD 几何落进 Γ，GeoInit 先验自动降权。

**灵感 3（关键二分：数据空白 vs 研究空白 → ARM + RGM）**
直觉（本轮最重要的一步）：「不知道」不是一个东西，至少可按**标注能否修复**分成两类。
- **数据空白（data gap）**：加标注就能收缩。特征：覆盖低，但标注响应曲线 β(b) 随预算 b 明显下降。
- **研究空白（research gap）**：现有标注源、现有传感器、现有方法加多少标注都收缩不了。特征：β(b) 很快进入平台期，而已知决策风险仍高于容差——这不是「缺数据」，是「缺方法 / 缺传感 / 缺物理实验」。
**ARM 标注响应模型**在线估计 β(b) 曲线，**RGM 研究空白挖掘器**把「平台期 + 残余风险」翻译成结构化研究问题报告：(区域描述、claim、成因、建议的新实验/新传感/新标注协议)。这把「研究空白」从一个写作概念，变成可由系统自动测量、排序、交付的对象。对 UniBot 这类研究型项目，这本身就是可展示的产出：系统不只完成任务，还告诉你下一步该研究什么。

**灵感 4（合流 → GALA：Gap-Aware Label Acquisition 空白感知标注获取）**
闭环：部署查询 → ECM 判覆盖 → 未覆盖进 Γ → GDC 决定弃权/降级 → ARM 判断是数据空白还是研究空白 → 数据空白走 ALQ 主动标注 / SGE 安全探索自标注（CBF 守护）→ 标注原子入 AAP 并更新覆盖 → β 收缩 → 证书收紧 → 剩余平台期交给 RGM 出研究空白报告。**第 63 轮是「几何-技能-干扰三层联合的鲁棒操作」，GALA 是「证据层：知道自己的保证从哪来、到哪失效、下一步该标注还是该研究」。**

**灵感 5（原位升级）**
- **AIC → AIC-C**：干扰集 ℰ 只在覆盖内被认证；空白内干扰用 gapPenalty 保守膨胀，或直接 UNVERIFIED，绝不过度认证。
- **USL / SSB → PSL**：技能与场景带 provenance；provisional 技能只能在覆盖内使用；场景银行的 Mine 优先挖高空白区，Mut 专往 Γ 里采样以生成高信息量未标注查询。
- **OCB → OCB-A**：臂空间加入 deploy / annotate_H / annotate_S / explore_F / defer，奖励 = 认证风险下降 − 标注成本 − 弃权惩罚。
- **OLP-Geo / WCV-Geo**：学习率与球半径乘覆盖置信 γ_cov(x)，覆盖低则更保守——几何先验只在它被标注支撑的地方敢「确定」。

## 1. 形式化定义（增量：定义 201–216）

- **定义 201（GALA 闭环）**：GALA = (LIRO, AAP, ECM, ALQ, GDC, ARM, RGM, SGE, AIC-C, PSL, OCB-A, J_gala)。定位：LIRO 的「证据层」升级，全部新增组件挂载在第 63 轮骨架上。不变式：**标注、覆盖估计、响应曲线、研究空白挖掘只发生在语义流与低频线程；实时路径只做 O(1) 覆盖查表 + GDC 守卫分支 + 原 LIRO 实时管线**，学习/写操作零侵入。
- **定义 202（标注原子 a）**：a = (c, x, y, s, κ, w, ν, t, h)，c∈𝒞 为 claim（如某几何区域的 φ、某技能 σ 的前置条件、某干扰类的 q̂），x∈𝒳 为查询，y∈𝒴 为标签，s∈𝒮={H,C,S,W,F} 为来源，κ>0 为获取成本，w∈[0,1] 为区域条件化可靠性，ν 为验证器 id，t 为时间戳，h = H(h_prev, c, x, y, s, w) 为证明链哈希。原子图 G_A 的边为 derived-from / verified-by / contradicts。
- **定义 203（证据覆盖 ρ_c）**：ρ_c(x) = min(1, m_c(x)/τ_c)，其中 m_c(x) = Σ_{a∈D_c} w_a · K_h(x, x_a) 是**可靠性加权核密度质量**，K_h 为带宽 h 的核，τ_c 为该 claim 的目标证据质量。ρ_c 高 ⇔ x 附近有足够多可信标注。
- **定义 204（空白集与三分解）**：Γ_δ(c) = {x∈𝒳 : ρ_c(x) < δ}。总空白 Γ = Γ_epi ∪ Γ_dist ∪ Γ_rel：Γ_epi 为低证据质量（缺标注）；Γ_dist 为距标注支撑的嵌入距离 > ε_ood（分布外）；Γ_rel 为标注间冲突度 > ε_dis（可靠性不足）。部署空白的质量 β = P_X[X∈Γ]。
- **定义 205（数据空白 vs 研究空白）**：给定容差 δ、决策风险容差 R_tol、预算 b、可用来源集 𝒮。**数据空白** 𝒟 = {x∈Γ : ∃s∈𝒮，其边际空白收缩率 −∂β/∂κ_s > λ}；**研究空白** ℛ = {x∈Γ : ∀s∈𝒮，边际收缩率 ≤ λ，且残余决策风险 R(x) > R_tol}；**不可约空白** 𝒜 = {x : 条件熵 H(Y|x) > h_0 且跨源不变性检验失败}。三者之并覆盖 Γ，且以「标注响应」而非「主观感觉」区分。
- **定义 206（ARM 标注响应模型）**：β_c(b) 为预算 b 下经最优 ALQ 分配后的期望空白质量；用保序回归（isotonic regression）拟合观测点 {(b_i, β_i)}，得平台估计 β_∞ = lim_{b→∞} β_c(b) 与边际 m(b) = −dβ/db。判据：m(0)>λ ⇒ 存在数据空白；β_∞>δ 且 ∀s m_s(b*)<λ 且 R>R_tol ⇒ 研究空白。
- **定义 207（GDC 空白感知证书）**：J_gala = (J_liro, Γ_map, coverage_spec, provenance_hash, β̂, δ_hp, rgm_id)。语义为条件命题：`x ∉ Γ ⇒ J_liro 在 x 上有效`；`x ∈ Γ ⇒ 仅允许 ABSTAIN_Δ`（降级到第 62 轮 ROSE 或 safe_idle，并记录触发原因）。全局 Valid(J_gala) ⇔ J_liro 在 𝒳∖Γ 上有效 ∧ β̂ ≤ β_max。**这是一张带定义域的证书，而不是一张全称空头支票。**
- **定义 208（覆盖-风险分解对象）**：R_deploy ≤ α_conf + β + L_f·ε_rel + ε_conc，其中 α_conf 为覆盖区上的保形误覆盖率，ε_rel 为可靠性估计误差，ε_conc = √(log(2/δ_hp)/(2n_mon)) 为空白质量在线估计的集中项，n_mon 为部署查询监测数。
- **定义 209（ALQ 主动标注查询）**：给定剩余预算 b、未标注池 U、当前证据 D，选批 B* = argmax_{B⊆U, cost(B)≤b} VoI(B)/cost(B)，VoI(B) = β̂(D) − E_{y_B}[β̂(D∪B)]。用当前可靠性模型与标签噪声模型预测标注后覆盖；仅在覆盖确实上升时计入收益。
- **定义 210（子模性与预算贪心）**：覆盖增益 F(B) = P_X[ρ_{D∪B}(x) ≥ δ] − P_X[ρ_D(x) ≥ δ]。在「半径为 r(w) 的球并」覆盖模型下，F 单调子模。单位成本贪心给出 F(B_greedy) ≥ (1−1/e)·OPT；任意成本用 cost-benefit 贪心给出 ≥ (1−1/e)/2·OPT（Khuller 型界）。
- **定义 211（区域条件化标注员可靠性）**：将 𝒳 划分为区域 {R_k}（由 ARM 响应聚类给出），对来源 s、区域 k 估计混淆矩阵 Π_{s,k}(y|y*)，用 Dawid-Skene/EM 变体估计隐真值与可靠性 w_a；OOD 区域的可靠性向层级先验收缩（hierarchical Bayes），避免「全局可靠的标注员在 OOD 被过度信任」。
- **定义 212（SGE 安全空白探索）**：在无标注员的空白区，用控制障碍函数 h_safe(x)≥0 守护探索策略 π_expl，失败即回退 π_fb 并记录空白。探索产生的自标注原子标记 s=F、w 默认 0.2、附 novelty 标签；仅当预期决策影响 > 阈值时才请求人工复核。**安全约束优先于信息增益。**
- **定义 213（研究空白报告 r）**：r = (region_descriptor, claim c, cause∈{no_annotator, annotator_disagreement, distribution_shift, model_bias, physical_ambiguity}, β_∞, residual_risk, suggested_action∈{new_sensor, new_experiment_protocol, new_annotation_rubric, new_method})。按 residual_risk × 决策频率排序，RGM 输出 top-K 报告。
- **定义 214（覆盖感知干扰集 AIC-C）**：ℰ_Γ = {η∈ℰ : ρ_dir(η) ≥ δ}。覆盖内沿用第 63 轮采样认证；覆盖外不再外推 margin，而是令 ρ_dir^Γ = min_{η∈ℰ_Γ} margin(τ,η) − gapPenalty(β)，或当 β>β_max 直接返回 UNVERIFIED。保证 ℰ_Γ⊆ℰ、ρ_dir^Γ ≤ ρ_dir，**永不比第 63 轮更乐观**。
- **定义 215（PSL 溯源技能/场景账本）**：USL-P 中每技能 σ 携带 P_σ（支撑 pre/eff/π_σ 的标注原子集）；σ 仅在 {x: ρ_σ(x)≥δ} 上「已认证」，其余为 provisional。SSB-P 的场景签名增加标注完备度向量 ann(s)∈[0,1]^{|𝒞|}；Mine 优先高空白场景，Mut 优先在 Γ 内变异，使变异体成为高信息量未标注查询。
- **定义 216（OCB-A 标注预算老虎机）**：臂 = {deploy, annotate_H, annotate_S, explore_F, defer} × {USL 模式} × {MEL 模式}（聚合为 K=16）；奖励 = ΔR_certified − κ_ann·cost_ann − κ_defer·defer_penalty，归一化后 EXP3 更新；硬安全下界：GDC 要求弃权时 deploy 臂被强制裁剪，不得突破。

## 2. 关键算法骨架（完整伪代码见产物区）

```python
# ECM：证据覆盖与空白三分解（语义流，按 claim 增量）
rho = min(1.0, sum(a.w * K(x, a.x) for a in evidence[c]) / tau[c])
Gamma = (rho < delta) or (novelty(x) > eps_ood) or (disagreement(x) > eps_dis)
# GDC：带定义域的证书守卫（实时流，O(1) 查表）
if in_gap(x, Gamma):  return ABSTAIN_merge(LIRO_degrade(x), reason=gap_reason(x))
else:                 return LIRO(x)   # 原 J_liro 有效
# ALQ：按 VoI/成本 贪心选标注批次
B = greedy_budgeted_coverage(unlabeled_pool, budget, value=expected_gap_reduction)
# ARM：拟合 beta(b)，判定数据空白 / 研究空白
beta_inf, m = isotonic_response(observed_budget_gap_pairs)
if m(0) > lam and m_available(b) > lam:  label = "data_gap"
elif beta_inf > delta and residual_risk > R_tol:  label = "research_gap"
# RGM：生成研究空白报告
reports = rank_by(residual_risk * freq, top_k).emit(structured_gap_report)
# AIC-C：只在覆盖内认证
rho_dir = min(margin(tau, eta) for eta in sample(E_cap)) - gap_penalty(beta)
if beta > beta_max: cert = UNVERIFIED
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 5（覆盖-风险分解）**：设覆盖区上保形校准可交换（A83）、可靠性估计误差 ≤ ε_rel（A85）、空白质量由 n_mon 次部署查询监测，则以概率 ≥1−δ_hp，R_deploy ≤ α_conf + β + L_f·ε_rel + √(log(2/δ_hp)/(2n_mon))——**空白质量 β 是风险的线性预算项，标注的收益第一次被写进风险不等式**。
- **定理 4（GDC 的 fail-closed 正确性）**：若实时派发必经覆盖查表，则任何 x∈Γ 都不会产生不带 ABSTAIN 标记的正证书；特别地，第 63 轮 OOD 几何幻觉（A77 失效区）因落入 Γ_dist 而被结构性拦截，GeoInit 先验被降权、派发被阻断或降级——**幻觉从「注入确定性错误」变成「显式的空白」**。
- **定理 5（ALQ 的空白收缩保证）**：球并覆盖模型下 F 单调子模，预算贪心满足 F(B_greedy) ≥ (1−1/e)/2·OPT；故 β_ALQ ≤ β_0 − (1−1/e)/2·(β_0 − β*)。**主动标注的收益有最坏情况保证，不是启发式。**
- **命题 6（数据/研究空白的可辨识性）**：若真实响应 β(b) 单调且最终平台 β_∞，且两类空白在 (β_∞, m(b*), R) 上有间隔 Δ>0，则 ARM 的误分类率 ≤ 2exp(−2nΔ²)；间隔消失时二者不可辨识（此时应报「不确定空白」而非强行归类）。
- **命题 7（AIC-C 的保守性）**：ℰ_Γ⊆ℰ 且 ρ_dir^Γ≤ρ_dir；若 η*∈Γ，认证返回 UNVERIFIED，假阳性认证概率为 0（构造保证）。代价是可用性下降，需用「覆盖率-可用性」权衡曲线刻画。
- **实时性**：实时路径新增仅 O(1) 空白查表（<0.02ms）+ GDC 分支（<0.01ms），LIRO 原有 1.7ms，总计 ≤1.8ms，仍在 2ms 契约内；所有学习/写操作仍在语义流。

> 承接第 63 轮 IP-193~203（LIRO：LSF×USL×CSP×DIR×AIC×SSB×OLP-Geo×WCV-Geo×Shield-Skill×OCB-Skill×J_liro）。本轮不推翻 LIRO，而是补上它缺的**证据层**：第 63 轮的所有保证都默认「支撑数据充分且可信」，却没有定义这些保证的**定义域**。GALA 把「数据标注」升级为**带来源、可靠性、成本、证明链的原子**，把「研究空白」升级为**可测量、可分型、可交付的一等对象**，并用一条**条件证书**把二者绑定：在证据覆盖处给保证，在空白处显式弃权，在标注也修不好的地方输出研究问题。
>
> 核心二分：**数据空白（可被标注收缩）** vs **研究空白（标注不可收缩，需新传感/新实验/新方法）**。前者交给 ALQ + SGE，后者交给 RGM。这是本轮相对第 63 轮最本质的推进：**从「优化一个闭环」到「知道闭环的保证在哪里失效、以及下一步该标还是该研究」**。

## 2. 形式化定义（完整版）

**定义 201（GALA 闭环）** GALA 是 LIRO 的「证据层」升级：在第 63 轮「语义流 ∘ 实时流」骨架上挂载 AAP（标注原子溯源）、ECM（证据覆盖图）、ALQ（主动标注）、GDC（条件证书）、ARM（标注响应模型）、RGM（研究空白挖掘）、SGE（安全空白探索）、AIC-C（覆盖感知认证）、PSL（溯源技能/场景账本）、OCB-A（标注预算调度）。不变式：**一切标注、覆盖估计、响应拟合、报告生成只发生在语义流与低频线程；实时路径只做 O(1) 覆盖查表、GDC 守卫分支与 LIRO 原有前向/编译/派发**——证据层与实时控制严格时序隔离，零学习写操作（继承 A75/A82）。

**定义 202（标注原子 a 与证明链）** a = (c, x, y, s, κ, w, ν, t, h)：
- `c ∈ 𝒞` 是该标签支持的 claim（可指向物理参数 φ 的某个分量、技能 σ 的 pre/eff、干扰集 ℰ 的某子域、几何先验 g 的某区域）；
- `x ∈ 𝒳` 为查询（多模态观测或其特征嵌入），`y ∈ 𝒴` 为标签；
- `s ∈ 𝒮 = {H, C, S, W, F}` 为来源，`κ > 0` 为获取成本（人工分钟 / 仿真算力 / 金额归一化）；
- `w ∈ [0,1]` 为**区域条件化可靠性**（定义 211）；
- `ν` 为验证器 id（人工复核 / 物理一致性检查 / 交叉验证器）；
- `t` 为时间戳；`h = H(h_prev ‖ c ‖ x ‖ y ‖ s ‖ w)` 为证明链哈希。
原子图 G_A 的边为 `derived-from`（弱标签→模型标签）、`verified-by`（复核）、`contradicts`（冲突）。任何证书引用 `provenance_hash = MerkleRoot({h_a})`，实现**标注级可审计**。

**定义 203（证据覆盖 ρ_c）** 对 claim c 与查询 x，
`ρ_c(x) = min(1, m_c(x)/τ_c)`，`m_c(x) = Σ_{a∈D_c} w_a · K_h(x, x_a)`，
其中 K_h 为带宽 h 的核（默认高斯或 Epanechnikov），τ_c 为该 claim 的目标证据质量（由风险容差反标定）。ρ_c 高 ⇔ x 附近存在足够多可信标注。为避免维度灾难，x 取任务相关嵌入（第 63 轮 x' 与几何指纹 fp_cloud 的联合低维投影）。

**定义 204（空白集与三分解）** `Γ_δ(c) = {x : ρ_c(x) < δ}`。总空白
`Γ = Γ_epi ∪ Γ_dist ∪ Γ_rel`，
其中 `Γ_epi = {ρ_c(x) < δ}`（缺标注）、`Γ_dist = {d_supp(x) > ε_ood}`（距标注支撑的嵌入距离超阈，分布外）、`Γ_rel = {disagree(x) > ε_dis}`（标注间冲突度超阈，可靠性不足）。部署空白质量 `β = P_X[X∈Γ]`。**关键设计**：`Γ_dist` 用「到支撑的距离」而非「模型置信度」判定，使未知未知（unknown unknowns）被保守地归入空白（fail-closed），而不是被高置信模型吞掉。

**定义 205（数据空白 / 研究空白 / 不可约空白）** 给定容差 δ、决策风险容差 R_tol、预算 b、可用来源集 𝒮：
- 数据空白 `𝒟 = {x∈Γ : ∃s∈𝒮, −∂β/∂κ_s > λ}`：存在某来源，其边际空白收缩率超过机会成本 λ。
- 研究空白 `ℛ = {x∈Γ : ∀s∈𝒮, −∂β/∂κ_s ≤ λ ∧ R(x) > R_tol}`：所有可用来源都已饱和，但残余决策风险仍超容差。
- 不可约空白 `𝒜 = {x : H(Y|x) > h_0 ∧ 跨源不变性检验失败}`：标签本身高度随机/歧义（如透明物体接触瞬间的摩擦），多源一致地无法降低熵。
三者构成对 Γ 的**操作化**划分：不是哲学分类，而是由「标注响应」定义的测量分类。

**定义 206（ARM 标注响应模型）** 设 β_c(b) 为预算 b 下经最优 ALQ 分配后的期望空白质量。在线收集观测对 {(b_i, β_i)}，用保序回归拟合单调非增曲线 β̂_c(b)（保证物理合理：更多标注不应增加空白），并估计平台 β_∞ 与边际 m(b) = −dβ̂/db。判定规则：
- `m(0) > λ` 且 `m(b*) > λ` ⇒ 归为数据空白；
- `β_∞ > δ` 且 `∀s, m_s(b*) ≤ λ` 且 `R > R_tol` ⇒ 归为研究空白；
- 其余且高熵/跨源不变性失败 ⇒ 归为不可约空白；
- 间隔不足 ⇒ 输出「未定型空白」而不强行归类（避免把不可辨识误报成研究空白）。

**定义 207（GDC 空白感知证书）** `J_gala = (J_liro, Γ_map, coverage_spec, provenance_hash, β̂, δ_hp, rgm_id)`。语义是**条件命题**：
`x ∉ Γ ⇒ J_liro 在 x 上有效`；`x ∈ Γ ⇒ 仅允许 ABSTAIN_Δ`（降级到第 62 轮 ROSE 或 safe_idle，并记录触发原因与证据缺口）。
全局 `Valid(J_gala) ⇔ J_liro 在 𝒳∖Γ 上有效 ∧ β̂ ≤ β_max`。这是把全称证书变成**带定义域的可审计证书**：没有任何一条保证会在未覆盖输入上被静默声明。

**定义 208（覆盖-风险分解）** 存在常数 L_f（任务风险对标签误差的 Lipschitz 常数），使
`R_deploy ≤ α_conf + β + L_f·ε_rel + ε_conc`，
`ε_conc = √(log(2/δ_hp)/(2n_mon))`，
其中 α_conf 为覆盖区上的保形误覆盖率，ε_rel 为可靠性估计误差，n_mon 为在线监测的部署查询数。该式是定理 4 的核心：**空白质量 β 与标注可靠性误差 ε_rel 是风险的两个可操作预算项**。

**定义 209（ALQ 主动标注查询）** 给定剩余预算 b、未标注池 U、当前证据 D：
`B* = argmax_{B⊆U, cost(B)≤b} VoI(B)/cost(B)`，
`VoI(B) = β̂(D) − E_{y_B}[β̂(D∪B)]`。
期望对标签 y_B 取，用当前可靠性模型与噪声模型预测标注后覆盖。**只允许真实提升覆盖的标注计入 VoI**——若某区域的 ρ 已接近 1，或标注源在该区域可靠性被收缩至极低，则 VoI≈0，不会浪费预算。搜索用定义 210 的预算贪心。

**定义 210（子模性与预算贪心保证）** 覆盖增益 `F(B) = P_X[ρ_{D∪B}(x)≥δ] − P_X[ρ_D(x)≥δ]`。在「每个标注原子覆盖以 x_a 为心、半径 r(w_a) 的球」的并集模型下，F 是单调子模的（标准最大覆盖）。因此：
- 单位成本：贪心 `F(B_greedy) ≥ (1−1/e)·OPT`；
- 任意成本：cost-benefit 贪心 `F(B_greedy) ≥ (1−1/e)/2·OPT`。
于是空白收缩 `β_ALQ ≤ β_0 − (1−1/e)/2·(β_0 − β*)`（见定理 5）。

**定义 211（区域条件化标注员可靠性）** 将 𝒳 划分为区域 {R_k}（由 ARM 响应与场景指纹聚类）。对来源 s、区域 k，估计条件化混淆矩阵 `Π_{s,k}(y|y*)`，用 Dawid-Skene/EM 变体联合估计隐真值 y* 与可靠性：
`w_a = 1 − (1/(|𝒴|−1))·E[𝟙[ŷ_a ≠ y*]]`。
对 OOD 区域，`Π_{s,k}` 向层级先验（全局混淆矩阵）收缩：`Π_{s,k} ← (1−γ_k)Π_{s,k} + γ_k Π_s^prior`，γ_k 随该区域标注量增加而减小。**目的**：阻止「全局可靠的标注员在 OOD 被过度信任」，这是定义 204 中 Γ_rel 的来源。

**定义 212（SGE 安全空白探索）** 在高空白且无标注员的区域，执行探索策略 π_expl，受控制障碍函数约束 `h_safe(x_t) ≥ 0`（安全集前向不变）。若预测将违反 h_safe，立即回退 π_fb 并把该处记为研究空白候选。探索轨迹产生自标注原子：s=F、w 默认 0.2、附 novelty 标签与状态覆盖证据；仅当预期决策影响 `|∂R/∂ρ|·Δρ > δ_verify` 时才请求人工复核升级可靠性。**安全约束严格优先于信息增益**：不允许以「探索未知」为由越过安全边界。

**定义 213（研究空白报告 r）** 对每个持续空白区生成
`r = (region_descriptor, c, cause, β_∞, residual_risk, suggested_action)`，
cause ∈ {no_annotator, annotator_disagreement, distribution_shift, model_bias, physical_ambiguity}；suggested_action ∈ {new_sensor, new_experiment_protocol, new_annotation_rubric, new_method}。排序分 = residual_risk × 决策频率。RGM 输出 top-K，并维护跨任务持久空白图（同一空白在多个任务中出现则升权）。**这是系统的「研究空白交付物」**：不是让 agent 自己写论文，而是把「哪里需要新研究」变成可复核的结构化证据。

**定义 214（AIC-C 覆盖感知干扰认证）** 第 63 轮认证对 η∈ℰ 取最坏 margin。GALA 先求覆盖内干扰集 `ℰ_Γ = {η∈ℰ : ρ_dir(η) ≥ δ}`，认证改为
`ρ_dir^Γ = min_{η∈ℰ_Γ} margin(τ, η) − gapPenalty(β)`，
其中 gapPenalty(β) = c_g·β（把空白质量折算成保守裕度扣减）。若 `β > β_max` 或 `ℰ_Γ = ∅`，返回 `UNVERIFIED` 而非正认证。构造上 `ℰ_Γ⊆ℰ`、`ρ_dir^Γ ≤ ρ_dir`，**AIC-C 永远不会比第 63 轮更乐观**；代价是可用性下降，用「覆盖率-可用性曲线」度量。

**定义 215（PSL 溯源技能/场景账本）** USL-P：每技能 σ 携带 `P_σ = {a : a 支撑 σ 的 pre/eff/π_σ}`；σ 仅在 `C_σ = {x : ρ_σ(x) ≥ δ}` 上「已认证」，其余标记 provisional，provisional 技能只能用于 SGE 探索或经 Shield-Skill 强约束后执行。SSB-P：场景签名在 (V_sig, T_sig, fp_cloud, φ_sig, dyn_annot) 之外增加 `ann(s) ∈ [0,1]^{|𝒞|}`（每 claim 的标注完备度）。Mine 优先匹配**高空白**场景；Mut 优先在 Γ 内做几何/物理变异，使变异体成为高信息量未标注查询——场景银行从「存险情」升级为「存空白并生成标注需求」。

**定义 216（OCB-A 标注预算老虎机）** 臂空间 = {deploy, annotate_H, annotate_S, explore_F, defer} × {USL 模式: full_seq/single_skill/cached_seq/frozen} × {MEL 模式: full/distill/cached/frozen}，聚合为 K=16。每语义步 EXP3 采样臂 a_t，奖励
`r_t = ΔR_certified(t) − κ_ann·cost_ann(t) − κ_defer·defer_penalty(t)`，
归一化到 [0,1] 后重要性加权更新。硬安全下界：当 GDC 对当前查询要求 ABSTAIN 时，deploy 臂被强制裁剪为 defer/annotate，**预算优化不得突破安全约束**。

### IP-204 AAP（标注原子与证明链）

```python
@dataclass(frozen=True)
class AnnotationAtom:
    c: str                 # claim id
    x: torch.Tensor        # query embedding
    y: Any                 # label
    s: str                 # H/C/S/W/F
    kappa: float           # cost
    w: float               # region-conditioned reliability
    verifier: str
    t: float
    h: str                 # provenance hash

class AnnotationAtomGraph:
    def __init__(self, tau_by_claim: Dict[str, float]):
        self.atoms: Dict[str, List[AnnotationAtom]] = defaultdict(list)
        self.tau = tau_by_claim
        self.edges: Dict[str, List[Tuple[str, str]]] = defaultdict(list)  # (rel, atom_h)
        self._merkle: Dict[str, str] = {}

    def add(self, c, x, y, s, kappa, w, verifier="auto") -> AnnotationAtom:
        prev = self._merkle.get(c, "GENESIS")
        h = sha256(f"{prev}|{c}|{hash_tensor(x)}|{y}|{s}|{w}".encode()).hexdigest()
        a = AnnotationAtom(c, x, y, s, kappa, w, verifier, time.time(), h)
        self.atoms[c].append(a)
        self._merkle[c] = h
        return a

    def provenance_root(self, claims) -> str:
        return sha256("|".join(sorted(self._merkle[c] for c in claims)).encode()).hexdigest()

    def contradictory(self, c) -> List[Tuple[AnnotationAtom, AnnotationAtom]]:
        # 同 query 附近、不同来源、标签冲突的原子对（供 Γ_rel 与 RGM 使用）
        return find_conflicts(self.atoms[c])
```

### IP-205 ECM（证据覆盖图与三分解）

```python
class EvidenceCoverageMap:
    def __init__(self, kernel_bandwidth=0.1, delta=0.3, eps_ood=2.5, eps_dis=0.4):
        self.h, self.delta, self.eps_ood, self.eps_dis = kernel_bandwidth, delta, eps_ood, eps_dis

    def rho(self, claim, x, aag: AnnotationAtomGraph, tau):
        mass = sum(a.w * gaussian_kernel((x - a.x).norm() / self.h)
                   for a in aag.atoms[claim])
        return min(1.0, mass / max(tau, 1e-9))

    def support_distance(self, x, aag, claim):
        pts = torch.stack([a.x for a in aag.atoms[claim]]) if aag.atoms[claim] else None
        return float('inf') if pts is None else (pts - x).norm(dim=1).min().item()

    def classify(self, claim, x, aag, tau, disagreement_fn):
        if self.rho(claim, x, aag, tau) < self.delta:        return "epi"
        if self.support_distance(x, aag, claim) > self.eps_ood:  return "dist"
        if disagreement_fn(claim, x) > self.eps_dis:         return "rel"
        return None                                          # covered

    def gap_flag(self, claim, x, aag, tau, disagreement_fn) -> bool:
        return self.classify(claim, x, aag, tau, disagreement_fn) is not None

    def beta(self, claim, queries, aag, tau, disagreement_fn) -> float:
        if not queries: return 0.0
        return sum(self.gap_flag(claim, q, aag, tau, disagreement_fn)
                   for q in queries) / len(queries)
```

### IP-206 ALQ（主动标注查询）

```python
class ActiveLabelQuery:
    """VoI/成本 的预算覆盖贪心；VoI 用当前可靠性模型预测。"""
    def __init__(self, ecm: EvidenceCoverageMap, reliability_model, lambda_cost=0.1):
        self.ecm, self.rel, self.lam = ecm, reliability_model, lambda_cost

    def _marginal_gain(self, claim, x, covered_mask, aag, tau, r_eff):
        # 该点当前是否空白，以及以半径 r_eff(x) 覆盖后预计新覆盖的质量
        if covered_mask.get(x_id(x), False):
            return 0.0
        return self.ecm.rho(claim, x, aag, tau) * r_eff(x)

    def select_batch(self, claim, pool, budget, aag, tau):
        selected, spent, covered = [], 0.0, {}
        # cost-benefit greedy：每轮选 增益/成本 最大者（定义 210）
        while True:
            best, best_ratio = None, 0.0
            for x in pool:
                if x.id in covered: continue
                s_hat, kappa = self.rel.best_source(claim, x)      # 选最优来源
                if kappa <= 0 or spent + kappa > budget: continue
                r_eff = self.rel.coverage_radius(s_hat, claim, x)  # 由可靠性决定
                gain = self._marginal_gain(claim, x, covered, aag, tau, lambda _: r_eff)
                ratio = gain / kappa
                if ratio > best_ratio + 1e-9:
                    best, best_ratio = (x, s_hat, kappa, r_eff), ratio
            if best is None: break
            x, s_hat, kappa, r_eff = best
            covered[x.id] = True
            selected.append((x, s_hat, kappa))
            spent += kappa
        return selected, spent
```

### IP-208 ARM（标注响应模型）

```python
class AnnotationResponseModel:
    """保序回归拟合 beta(b)，区分 data gap / research gap / 未定型。"""
    def __init__(self, lam=0.02, R_tol=0.05):
        self.obs = defaultdict(list)   # claim -> [(b_i, beta_i)]
        self.lam, self.R_tol = lam, R_tol

    def observe(self, claim, spent, beta):
        self.obs[claim].append((spent, beta))

    def fit(self, claim):
        pts = sorted(self.obs[claim])
        b = np.array([p[0] for p in pts]); y = np.array([p[1] for p in pts])
        beta_iso = isotonic_decreasing(y)                 # 单调非增约束
        slope = np.gradient(beta_iso, b, edge_order=2)
        m = -slope                                       # 边际收缩率（>0 表示标注有效）
        beta_inf = beta_iso[-1] if len(beta_iso) else 1.0
        return b, beta_iso, m, beta_inf

    def classify(self, claim, residual_risk, available_sources):
        b, beta_iso, m, beta_inf = self.fit(claim)
        if len(b) < 2: return "undetermined"
        if m[0] > self.lam and (m[-1] > self.lam or available_sources):
            return "data_gap"
        if beta_inf > self.ecm_delta and all(mi <= self.lam for mi in m) and residual_risk > self.R_tol:
            return "research_gap"
        if residual_risk > self.R_tol and self._high_entropy(claim):
            return "irreducible"
        return "undetermined"
```

```python
            for i, arm in enumerate(self.ARMS[:self.K]):
                if arm[0] == "deploy": probs[i] = 0.0      # 硬安全下界

                         - self.kappa_defer * defer_penalty, 0, 1)

        self.w[idx] *= np.exp(self.eta * r_hat / self.K)
```

## 4. 推导

**引理 5（覆盖-风险分解）** 设部署查询 X 落入空白 Γ 的概率为 β。在覆盖区 𝒳∖Γ 上，由保形校准的可交换性（A83），对任意任务风险 r，`P[r(X, Y) > α_conf | X∉Γ] ≤ δ_conf`（按构造的保形分位）。在 Γ 上不假设任何模型，取最坏风险 1。于是由全概率公式：
`R_deploy = (1−β)·R_covered + β·R_gap ≤ (1−β)·α_conf + β·1 = α_conf + β(1−α_conf) ≤ α_conf + β`。
再由标签可靠性误差 ε_rel 经任务风险对标签的 Lipschitz 常数 L_f 传递（A85），以及 n_mon 次部署查询对 β 的 Bernoulli 估计用 Hoeffding 不等式，得
`R_deploy ≤ α_conf + β + L_f·ε_rel + √(log(2/δ_hp)/(2n_mon))`，以概率 ≥1−δ_hp。∎

> 直觉：**标注不是「提升模型精度」，而是直接买低 β；β 在风险不等式里是一个线性预算项。** 这解释了为什么标注的价值可以被精确排序，也解释了为什么研究空白（β 不随标注下降）是比数据空白更根本的风险来源。

**定理 4（GDC 的 fail-closed 正确性）** 设实时派发函数 D(x) 的每个分支在返回正证书前都经过 `GDC.guard(x)`，且 guard 满足：`classify(x) ≠ None ⇒ 返回 ABSTAIN`。则对任意 x∈Γ，不存在不带 ABSTAIN 标记的正证书被执行。（反证：若存在，则该分支绕过了 guard 或 guard 在 x∈Γ 时返回 PROCEED，均与假设矛盾。）特别地，第 63 轮的 OOD 几何幻觉：由 A84，语义新颖/OOD 查询以概率 ≥1−α_ood 满足 `d_supp(x) > ε_ood`，即落入 Γ_dist；于是 guard 返回 ABSTAIN，GeoInit 先验被降权或派发被阻断，**幻觉不可能以静默保证的形式传播**。∎

> 这条定理正面回应第 63 轮的 A77：它不要求 E_geo 在 OOD 上不幻觉（那太难保证），只要求**系统知道自己在 OOD，并把「不知道」变成可审计的弃权**。正确性从「模型泛化」转移到了「覆盖守卫」。

**定理 5（ALQ 的空白收缩保证）** 在球并覆盖模型下，覆盖增益 F(B) 是单调子模（最大覆盖的经典性质：增加一个球带来的新增覆盖随已选球增多而不增）。单位成本时，Nemhauser–Wolsey–Fisher 定理给出 `F(B_greedy) ≥ (1−1/e)·OPT`；任意成本时，Khuller 的 cost-benefit 贪心给出 `F(B_greedy) ≥ (1−1/e)/2·OPT`。由于 `β = 1 − P_X[ρ≥δ]`（对单 claim），空白收缩与覆盖增益同量：
`β_ALQ ≤ β_0 − (1−1/e)/2·(β_0 − β*)`。
结合引理 5，标注预算 b 通过该式直接降低风险上界。∎

**命题 6（数据空白/研究空白的可辨识性）** 设真实响应 β(b) 单调非增且趋于平台 β_∞；两类空白在特征 `(β_∞, m(b*), R)` 上可分，间隔为 Δ>0。ARM 的保序回归在 n 个观测点上的分类错误率由单调回归的一致性与两样本分离给出 `err ≤ 2·exp(−2nΔ²)`（Hoeffding 型）。当 Δ→0（平台高度与残余风险都落在容差边缘）时，两类在有限样本下不可辨识——此时正确行为是输出「未定型空白」并请求更多标注/实验，而不是强行归类。∎

**命题 7（AIC-C 的保守性）** 由定义 `ℰ_Γ = {η∈ℰ : ρ_dir(η)≥δ} ⊆ ℰ`，故 `min_{η∈ℰ_Γ} margin ≥ min_{η∈ℰ} margin`；再减去非负 gapPenalty，得 `ρ_dir^Γ ≤ ρ_dir`。若真实最坏干扰 η* 落在 Γ（未被覆盖），认证器在 `β>β_max` 时返回 UNVERIFIED，否则仍以 β 的惩罚项保守扣减，不会输出比第 63 轮更高的裕度。因此**假阳性正认证概率为 0（构造）**；代价是覆盖率下降，需以「覆盖率-可用性曲线」量化。∎

**命题 8（标注的边际收益递减与平台）** 对同质空白（空白质量均匀、核半径为 r_cov），覆盖一个体积 V 的区域所需标注数近似为 `N ≈ (V / V_cov)·log(1/(1−β))`（覆盖过程的收集者型近似），故 `β(b) ≈ β_0·exp(−b/c)`，边际 m(b) 指数衰减——这解释了「数据空白」的快速下降与「研究空白」的早期平台。该近似仅在空白同质且覆盖模型成立时有效，异质空白（如语义歧义）会偏离，需 ARM 的在线拟合而非解析外推。∎

- **(A84)** 空白/新颖度检测器已校准：语义 OOD 查询以概率 ≥1−α_ood 满足 `ρ<δ` 或 `d_supp>ε_ood`（fail-closed 检测）；
- **(A85)** 可靠性 EM 的区域收缩使 OOD 过信误差 ≤ ε_rel，任务风险对该误差 Lipschitz 常数 L_f<∞；
- **(A86)** 覆盖函数在球并模型下单调子模，且各标注源条件独立；
- **(A87)** 标注响应 β(b) 单调非增且最终平台；两类空白在 `(β_∞, m, R)` 上可分离（或正确返回「未定型」）；
- **(A88)** GALA 实时路径新增延迟 ≤0.05ms，且无任何学习写操作。
则：
1. **风险可分解**：`R_deploy ≤ α_conf + β + L_f·ε_rel + ε_conc`，空白质量是显式风险预算（引理 5）。
2. **证书 fail-closed**：任何 x∈Γ 都不会获得静默正证书；第 63 轮 OOD 几何幻觉被结构性拦截（定理 4）。
3. **标注有最坏情况收益**：`F(B_greedy) ≥ (1−1/e)/2·OPT`，`β_ALQ` 有显式收缩界（定理 5）。
4. **研究空白可交付**：若不满足数据空白判据且残余风险超容差，RGM 输出结构化、可排序、跨任务持久的研究空白报告（定义 205/213）。
5. **认证不更乐观**：`ρ_dir^Γ ≤ ρ_dir`，空白时返回 UNVERIFIED，假阳性正认证为 0（命题 7）。
6. **实时性可控**：总延迟 ≤1.73ms，零学习写操作，继承第 61–63 轮锚点新鲜度与降级路径。

## 7. 已知风险

**一句话**：整个 GALA 的收益依赖「覆盖/空白判定本身可信」；若 ECM 的覆盖分在分布外把「空白」系统性误判为「已覆盖」（或大面积误报空白），GDC 要么重新注入第 63 轮的幻觉、要么退化为永久弃权——**用一套未经验证的元不确定性去守护不确定性，是本轮所有论证共同依赖的单点假设（A84）**。

**次级风险与缓解**：
1. **元不确定性不可校准**：ECM 的 ρ 与 novelty 阈值本身可能 OOD 失效 → 在留出混合集上校准阈值，并设「空白误判代价非对称」的保守先验（宁多报空白）；对 ρ 做保形化，给出 β 的置信上界而非点估计。
2. **标注预算与实时性冲突**：ALQ 选批与人工标注延迟 → 完全异步，实时只用当前 Γ 守卫；预算耗尽时自动退化为纯弃权/降级，不阻塞控制。
3. **标注员区域可靠性估计样本不足**：OOD 区域几乎无标注 → 层级贝叶斯收缩到保守先验（默认不可信），并把「无法估计可靠性」本身归入 Γ_rel。
4. **研究空白误报**：把「标注还没跑到」误判为研究空白 → ARM 必须观测到平台期（至少两个预算点的边际低于 λ）才报；否则标为「未定型」并继续采集。
5. **SGE 自标注污染**：低可靠自标注进入 AAP 会自我强化 → 自标注 w≤0.2 且不参与覆盖认证，只用于生成待复核/待标注查询；高影响项强制人工升级。
6. **GDC 弃权过多导致任务不可用**：覆盖不足时系统频繁弃权 → 用 OCB-A 在「标注/探索/降级」间调度预算；对低风险查询允许「已知边界内的保守降级」而非完全停机，并记录降级证书。
7. **证明链存储开销**：每条原子一个哈希与 Merkle 更新 → 原子按 claim 分桶、哈希截断到 128 bit、只对证书引用路径保留完整链，其余冷存。
