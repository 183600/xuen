### 第 5 轮灵感驱动研究记录

**灵感词**：语音识别、微调

**继承关系**：第 4 轮 CADVS-v4（IP-489~492）把证据铸造扩展为七硬门 kc_evidence_forged_v4 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem ∧ kc_val ∧ kc_bal，fail-closed；软评分 ECS_v4 = ECS_v3·η_val·η_bal；执行集 Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。但 v4 有两处根本弱点：(i) 七硬门是「逐帧独立、硬阈值」判决，未建模证据的时间连续性、相互约束与不确定性传播，也未校准置信度；(ii) 价值/平衡模型与阈值的自适应只能靠全量重训或全局平均，站点异构（R51）与维护负债（R52）无解，且微调本身可能侵蚀安全对齐。本轮以「语音识别」的格解码/置信度/拒识与「微调」的参数高效适配为灵感，形成 CADVS-v5（IP-493~496），执行集升级为 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。

**直觉与动机**：

1. **语音识别真正做的不是「听清单词」，而是「在噪声与歧义中维护多个假设，再用语言模型重打分，置信度足够才判决，否则拒识」**。v4 的七硬门等价于「逐帧独立阈值」；ASR 的成熟做法是：声学模型给发射概率、语言模型给转移先验、WFST 组合成解码图、束搜索/Viterbi 找最优路径、N-best/lattice 保留备选、混淆网络（confusion network）做逐位置后验。映射到证据铸造：让七个锚点各贡献「证据 token 的发射似然」，让 LTEM/MSRG/联邦先验贡献「证据转移先验」，组合成证据格（evidence lattice）并流式解码。硬门从「每帧布尔与」升级为「对整条证据路径的后验风险约束」：kc_lat(δ) = P(存在违规路径 | 观测) < δ。直觉上，这是把「所有门同时为真」换成「以至少 1−δ 的概率，真实证据路径不碰任何违规状态」——既保留硬安全，又显式承认感知歧义。

2. **语音识别的置信度估计与拒识（keyword spotting、OOV、conformal）说明：未校准的分数会系统性误导下游**。v4 的 α_val、μ_pass、ξ_wrench 都是「裸分数」，阈值 0.6/0.75 是经验拍定，且分数分布随任务与站点漂移。ASR 领域用温度缩放/等渗回归做校准，用 conformal prediction 给出分布无关的误接受风险上界，用 OOV 检测在分布外弃权。映射：引入证书置信度校准与拒识（CCR）——校准 α_val 等分数，用 split conformal 给出 P(accept ∧ 违规) ≤ α 的接受风险界，用 LTEM novelty 做「证据 OOV」弃权。直觉上，这回答「这个'通过'到底有多可信、该不该弃权，而不是被迫二选一」。

3. **现代语音识别（Whisper/wav2vec）都是「大规模预训练 + 参数高效微调（LoRA/adapter/prompt）」**。v4 的站点异构（R51）与维护负债（R52）源于「全量重训/全局 FedAvg」。映射：冻结全局基座 Φ_global，各站只训练低秩适配器 Δ_i = B_i A_i（rank r），联邦只聚合 Δ_i，通信 O(d²)→O(r·d)，且每站保留个性化。更关键的是近期研究发现「微调会破坏安全对齐」——映射到本框架即「适配器微调可能侵蚀七硬门」。因此引入锚定微调（PEAFT）：把微调限制在证书保持的信任域内（‖Δ‖_F ≤ ρ，且 guard set 上硬门判决不变），并做 EWC 防遗忘。直觉上，这是「让系统能低成本变聪明，但不许在变聪明的过程中变坏」。

4. **论文创新点：把 ASR 的「格解码 + 置信度 + 自适应」与证书演算统一为「证据解码演算（Evidence Decoding Calculus）」**：(a) 证据格上的风险规避判决定理（违规路径后验 < δ）；(b) 校准证书的 conformal 接受风险界（分布无关）；(c) 锚定微调的安全保持定理（信任域 + Lipschitz 保证硬门不变）。三者把 v4 的「静态七硬门」升级为「带不确定性与可自适应性的动态证据决策」，同时正面回应 v4 的实时性风险（流式解码与低秩适配器都更省算力/通信）。

**关键洞见**：v4 问「证据是否齐全且达标」；v5 问「在歧义下，真实证据路径以多大概率安全，这个概率是否可信，以及模型能否低成本自适应而不侵蚀安全」。九硬门 kc_evidence_forged_v5 = (∧_{i=1}^7 kc_i) ∧ kc_lat ∧ kc_conf ∧ kc_ft，fail-closed；软评分 ECS_v5 = ECS_v4·η_conf·η_lat。七硬门保留为「MAP 路径上的确定性必要条件」，新增三门分别管「备选路径的残余风险」「置信度可信度/分布外」「适配器不侵蚀安全」。

**形式化目标（增量）**：
1. 定义证据字母表 E、观测序列 o_{1:t}、发射模型 P(o_t|e_t)、转移先验 P(e_t|e_{t-1})、证据格 L = Compose(Emit, Prior)，及逐位置后验 γ_t(e)=P(e_t=e|o_{1:t})。
2. 定义风险规避硬门 kc_lat(δ)：P(∃t: 路径经过违规状态 | o_{1:t}) < δ。
3. 定义证书置信度校准（温度缩放/等渗）与 split conformal 阈值 q̂，硬门 kc_conf：校准置信度 ≥ τ_conf ∧ conformal 接受 ∧ 非 OOV。
4. 定义参数高效锚定微调 PEAFT：θ=θ_0+B A，rank r；信任域 ‖Δ‖_F ≤ ρ；guard set G 上硬门不变；联邦仅聚合 Δ_i。
5. 定义硬门 kc_ft：∀x∈G, gate_v5(x;θ_0+Δ)=gate_v5(x;θ_0) ∧ ‖Δ‖_F ≤ ρ。
6. 定义 EFA-v5 九硬门 + 软评分 ECS_v5 = ECS_v4·η_conf·η_lat。
7. 定义 Exec_CADVS-v5 ⊆ Exec_CADVS-v4：v5 在 v4 每条通过路径上再追加 kc_lat ∧ kc_conf ∧ kc_ft，故只缩不涨。

**本轮最大风险**：**证据格解码与 conformal 校准都建立在「发射/转移模型正确、样本可交换」的假设上，而真实部署非平稳、非IID 且存在对抗性分布外证据；一旦这些假设失效，后验会系统性过度自信，使「风险规避硬门」退化为有保证的假象，反而比 v4 的朴素阈值更危险**。

### IP-493 ELD：证据格解码器（控制环内，流式，目标 < 0.1 ms）

```python
@dataclass
class EvidenceLatticeDecoder:
    """ELD：七锚点证据流 → WFST 证据格 → 流式 Viterbi/前向后向 → 后验与风险"""
    beam: int = 8                       # 束宽（实时性旋钮）
    delta: float = 1e-3                 # 违规路径后验风险上界
    vocab: tuple = ("CONTACT", "SLIP", "FORCE_OK", "EE_OK",
                    "BAL_OK", "VALUE_OK", "MEM_OK", "NOVEL", "OOV")

    def emission(self, o_t) -> np.ndarray:
        """P(o_t|e)：3DCF 覆盖似然、EEK 力/位姿似然、BCK 边际似然、VACK 价值似然"""
        ...

    def transition(self, e_prev) -> np.ndarray:
        """P(e_t|e_prev)：LTEM 转移统计 + MSRG 物理约束 + Φ_global 先验"""
        ...

    def decode(self, o_1t) -> LatticeResult:
        """流式前向 Viterbi 保 MAP 路径；前向后向得 γ_t(e) 与混淆网络 CN"""
        ...

    def risk(self, lat: LatticeResult, violating: set) -> float:
        """违规路径后验质量 = sum over paths visiting any violating state"""
        return lat.posterior_mass(violating)

    def kc_lat(self, lat: LatticeResult) -> bool:
        """引理 43：通过 ⟹ 违规路径后验质量 < δ"""
        return self.risk(lat, VIOLATING_STATES) < self.delta
```

### IP-494 CCR：置信度校准与拒识（离线拟合 + 在线 O(1) 查表）

```python
@dataclass
class ConfidenceCalibrationRejection:
    """CCR：证书置信度校准 + split conformal 接受风险界 + 证据 OOV 拒识"""
    temperature: float = 1.0
    iso_map: Any = None               # 等渗回归映射（可选，优先于温度缩放）
    alpha: float = 0.05               # 目标误接受率
    q_hat: float = 0.0                # 非一致性分数 (1-alpha) 分位阈值
    tau_conf: float = 0.5
    novelty_oov: float = 0.8

    def calibrate(self, s: float) -> float:
        if self.iso_map is not None:
            return float(self.iso_map(s))
        return float(sigmoid(logit(clip(s, 1e-6, 1 - 1e-6)) / self.temperature))

    def fit_conformal(self, calib_conf, calib_violated) -> float:
        """非一致性分数 nonconf_i = 1 - conf_i（仅用未违规校准样本）；
        q_hat = 经验分位数 ceil((n+1)(1-alpha))/n。"""
        ...

    def kc_conf(self, conf: float, novelty: float) -> bool:
        """引理 44：通过 ⟹ 校准置信度达标 ∧ conformal 接受 ∧ 非 OOV"""
        return (novelty < self.novelty_oov
                and conf >= self.tau_conf
                and (1.0 - conf) <= self.q_hat)
```

### IP-495 PEAFT：参数高效锚定微调（离线/异步，不在控制环）

```python
@dataclass
class ParameterEfficientAnchoredFineTuner:
    """PEAFT：冻结基座 + 低秩适配器 + 信任域 + guard set 证书保持"""
    rank: int = 8
    rho: float = 0.05                 # ||Δ||_F 上界
    l_gate: float = 1.0               # 硬门 Lipschitz 常数
    guard_set: list = field(default_factory=list)

    def adapt(self, local_data, site_id) -> Adapter:
        """θ = θ0 + B A；仅训练 A∈R^{r×d}, B∈R^{d×r}（基座冻结）；
        约束：min L_task + λ·EWC(θ0)
              s.t. ||B A||_F <= rho 且 ∀x∈G: gate_v5(x;θ0+BA)=gate_v5(x;θ0)"""
        ...

    def federated_aggregate(self, adapters: list[Adapter]) -> Adapter:
        """仅聚合低秩因子（通信 O(r·d)），聚合前对 ||Δ_i||_F 做安全裁剪"""
        ...

    def kc_ft(self, adapter: Adapter) -> bool:
        """定理 7：通过 ⟹ 适配器在 guard set 上保持硬门判决且未越信任域"""
        if fro_norm(adapter.B @ adapter.A) > self.rho:
            return False
        return all(gate_v5(x, adapter) == gate_v5(x, None) for x in self.guard_set)
```

### IP-496 EFA-v5：九硬门 + 软评分

```python
@dataclass
class EvidenceForgingAssemblerV5:
    """EFA-v5：七硬门（MAP 路径必要条件）+ kc_lat + kc_conf + kc_ft；fail-closed"""
    efa_v4: EvidenceForgingAssemblerV4
    eld: EvidenceLatticeDecoder
    ccr: ConfidenceCalibrationRejection
    peaft: ParameterEfficientAnchoredFineTuner

    def hard_gate(self, o_1t, x, t_now, rule_id, hic, eec, bcc,
                  object_class, geo_sig, theta_domain_fp, traj, context,
                  adapter: Adapter) -> tuple[bool, str]:
        # 1) 七硬门（MAP 路径上的确定性必要条件，保持与 v4 的嵌套）
        ok4, reason = self.efa_v4.hard_gate(
            x, t_now, rule_id, hic, eec, bcc,
            object_class, geo_sig, theta_domain_fp, traj, context)
        if not ok4:
            return False, reason
        # 2) 证据格残余风险（备选假设）
        lat = self.eld.decode(o_1t)
        if not self.eld.kc_lat(lat):
            return False, 'LATTICE_RISK'
        # 3) 置信度校准 + OOV 拒识 + conformal 接受界
        conf = self.ccr.calibrate(lat.map_confidence)
        if not self.ccr.kc_conf(conf, lat.novelty):
            return False, 'LOW_CONFIDENCE'
        # 4) 适配器未侵蚀安全
        if not self.peaft.kc_ft(adapter):
            return False, 'FT_EROSION'
        return True, 'FORGED_V5'

    def ecs_v5(self, x, t_now, rule_id, lat, conf,
               A_att=0.0, eta_mem=0.5, eta_val=0.5, eta_bal=0.5) -> float:
        base = self.efa_v4.ecs_v4(x, t_now, rule_id, A_att, eta_mem, eta_val, eta_bal)
        eta_lat = 1.0 - self.eld.risk(lat, VIOLATING_STATES)
        eta_conf = self.ccr.calibrate(lat.map_confidence)
        return base * eta_conf * eta_lat
```

| PEAFT 训练（离线） | O(E·r·d) | O(r·d) | E=epochs | 慢时域，GPU |
| 联邦聚合适配器 | O(n·r·d) | O(r·d) | n=站点数 | 秒级；通信 O(r·d) ≪ O(d²) |
| EFA-v5 九硬门 | **O(1) + ELD** | O(1) | — | < 0.15 ms（含格解码） |
| 端到端在线增量 | ~0.1–0.3 ms | — | — | **较 v4 的 ~1–5 ms 显著下降** |

**通信开销**：站点仅上传低秩适配器因子（~r·d 参数，r=8，d=1e4 时约 8×10⁴ 个数 ≈ 320 KB/轮），相比全模型/全统计量大幅下降；ELD 证据格与校准表不下发原始数据；guard set 仅传证书摘要（哈希 + 判决），不传原始样本。

**实时性缓解（正面回应 v4 R49）**：流式 Viterbi 只维护 B 条活跃路径，增量前向；无每帧 QP/LCP 重解；BCK 的 Wrench 锥可由预计算查表 + 格转移先验近似；适配器推理为一次低秩矩阵乘。

## 4. 正确性论证（增量更新）

### 引理 43（风险规避格判决的安全界）

**陈述**：设发射/转移模型给出证据格后验，真实违规事件 V = {证据路径经过任一违规状态}。若 kc_lat 通过即 risk = P_L(V | o_{1:t}) < δ，且模型相对真实分布的校准误差满足 |P_true(V|o) − P_L(V|o)| ≤ ε_cal，则 P_true(V | o_{1:t}) < δ + ε_cal。

**证明**：由全概率公式，P_true(V|o) = Σ_{路径 π∈V} P_true(π|o)；对每条路径用校准误差界三角不等式，得 P_true(V|o) ≤ P_L(V|o) + ε_cal < δ + ε_cal。∎

**工程含义**：把「逐帧硬与」的 0/1 安全换成「可量化残余风险」，并用 CCR 的校准误差把 δ 放宽为 δ+ε_cal，风险不再被隐藏。

### 引理 44（conformal 接受风险界）

**陈述**：设校准样本与在线样本可交换，非一致性分数 nonconf = 1 − conf，q̂ 为校准集 (1−α) 经验分位。则 P(accept ∧ 违规) ≤ α + 1/(n+1)。

**证明**：标准 split conformal 覆盖率定理：可交换性下 P(nonconf_{new} ≤ q̂) ≥ 1−α；违规样本的非一致性分数以概率 ≥1−α 落在 q̂ 内，故误接受率上界为 α（加有限样本修正 1/(n+1)）。∎

**工程含义**：给出分布无关的接受风险保证，弥补 v4 阈值无理论依据的缺陷；非平稳时用 ACI 在线修正。

### 定理 5（证据解码演算：格风险 + 校准 + 拒绝）

**陈述**：在 (C1) 发射/转移模型校准误差 ≤ ε_cal、(C2) 校准与在线样本可交换 下，EFA-v5 的接受集满足：
(i) 安全违规率 ≤ δ + ε_cal + α + 1/(n+1)；
(ii) 若进一步 novelty 检测 AUROC ≥ 1−γ，则分布外误接受率 ≤ γ；
(iii) ECS_v5 与真实失败的排序一致性不低于 ECS_v4（软因子单调不增、且携带校准信息）。

**证明**：(i) 由引理 43、44 的并集界；(ii) OOV 拒识把分布外样本移出接受集，误接受仅剩漏检；(iii) η_conf, η_lat ∈ [0,1] 为乘性因子且与风险正相关，保持排序。∎

### 定理 6（锚定微调的安全保持）

**陈述**：设硬门函数 gate_v5(·;θ) 在参数上 L_gate-Lipschitz，guard set G 上对基座 θ_0 的最小判决边际为 m = min_{x∈G} |gate_v5(x;θ_0) − 1/2|。若适配器满足 ‖Δ‖_F ≤ ρ 且 L_gate·ρ < m，则 ∀x∈G，gate_v5(x;θ_0+Δ)=gate_v5(x;θ_0)。

**证明**：|gate_v5(x;θ_0+Δ) − gate_v5(x;θ_0)| ≤ L_gate‖Δ‖_F < m ≤ 基座判决到决策边界的距离，故符号不变。∎

**工程含义**：把「微调会侵蚀安全对齐」这一经验现象转成可验证的信任域约束；kc_ft 即在部署前做 guard-set 回归测试。

### 定理 7（联邦 PEFT 的隐私-效用-鲁棒权衡改进）

**陈述**：在定理 3 的 (ε,δ)-DP、非IID D_div、毒化 β 设定下，若各站仅聚合秩 r 适配器，则泛化误差界为 O(√(r·d/(nε²)) + D_div^local + β/ε)，通信复杂度由 O(d²) 降为 O(r·d)；其中 D_div^local ≤ D_div 因个性化适配器吸收站点偏移。

**证明**：将定理 3 的有效维度 d 替换为适配器参数维度 r·d，其余 DP/毒化项不变；本地适配器拟合站点分布后残余偏移 D_div^local 收缩。∎

### 定理 8（v5 执行集严格收缩）

**陈述**：Exec_CADVS-v5 ⊆ Exec_CADVS-v4，且因 kc_lat/kc_conf/kc_ft 均非恒真，包含严格。

**证明**：v5 硬门 = (∧_{i=1}^7 kc_i) ∧ kc_lat ∧ kc_conf ∧ kc_ft，是 v4 硬门再合取三项，路径集只缩不涨；非恒真由构造对抗证据（高风险格、低置信/OOV、越界适配器）保证严格。∎

**诚实声明**：(C1)(C2) 是强假设——真实部署非平稳、非IID，可交换性被破坏，ε_cal 可能随分布漂移增大；证据格的发射/转移模型可能设定错误，导致后验过度自信；定理 6 依赖 Lipschitz 常数与边际的准确估计，高维深度模型上难以严格保证。缓解：ACI 在线覆盖率跟踪、OOD 检测、guard set 定期扩充、Lipschitz 正则与谱归一化。

## 7. 本轮最大风险（最终确认）

**一句话**：**证据格解码与 conformal 校准都建立在「发射/转移模型正确、样本可交换」的假设上，而真实部署非平稳、非IID 且存在对抗性分布外证据；一旦这些假设失效，后验会系统性过度自信，使「风险规避硬门」退化为有保证的假象，反而比 v4 的朴素阈值更危险。**
