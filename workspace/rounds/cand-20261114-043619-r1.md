# 第 71 轮（承接第 70 轮「BELIEF-RAS 贝叶斯状态估计层 + 基线复现 + 原型验证」IP-264~274；本轮灵感：「实时推理」×「多机器人协作」）

> R70 把 epistemic 从动作模态（R69）升维为世界状态后验 b_t(s)，并给出了可复现协议与原型验收。但它把 b_t 当成一个**无时间戳、可无限精算、由单一观察者拥有**的对象：实时性只是「P99 多快」的工程指标，协作只是「多机共享一张图」的数据融合。这正是 R70 自陈最大风险「后验会自信地错」的两个放大器：
> - **实时推理**：在 deadline 前，b_t 不是「算出来的」，而是「算到一半被迫交卷的」。R70 没有把「停止计算」产生的近似误差计入不确定性；一个只跑 3 步粒子滤波的后验，其熵可能远低于真实后验，系统把「没算完」误读成「已确定」。
> - **多机器人协作**：队友的消息不是独立证据，而是**带时间戳、带共同祖先、可能过期/回放/共谋的证据**。把「最新收到的信念」直接融合，会在时间错位处制造信息幻觉；多机一致可能只是「共享了同一个错误源」（回声室），而不是「看到了同一个真相」。
>
> 核心命题：**把「实时」从延迟约束升级为证据的时间语义，把「协作」从状态融合升级为独立性受检的证据交换；用同一份 deadline 预算统一调度「再算一会 / 再问队友 / 现在动手」；并立一条铁律——过期或相关的证据只能改变先验，不能制造置信。** 命名 **CHRONO-RAS**（Chronology-aware, Horizon-bounded, Redundancy-verified, Online Risk-Aware Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「我的信念是什么」，R71 问「**我的信念是什么时刻的、由谁独立提供的、还来得及算完吗**」——时间是证据的一个维度，队友是证据的一个来源，而不是免费的真相。

## 0. 直觉与动机

**灵感 1（实时推理 → 信念是易腐品，不是常量）**
直觉：R70 的 b_t 被写成一个「当前状态的后验」，仿佛它天然属于现在。但在硬实时系统里，b_t 是**在某个 wall-clock t 被计算、指向某个状态时刻 τ 的商品**，它有生产时间、有效期、以及「没算完」的残差。人做紧急判断时也一样：不是「我知道」，而是「在必须行动之前，我所知道的够不够新、够不够准」。因此实时推理的第一性对象不是 FPS，而是 **belief age 与 anytime 残差**。一个系统可以 P99 很快，却一直在用 80ms 前的信念；也可以算得很久，却在 deadline 前只跑出半收敛的后验。R70 的 P99 指标对这两种情况都失明。

**灵感 2（多机器人协作 → 一致不等于正确，共识可能只是共享祖先）**
直觉：多机协作最容易犯的错，是把「别人也这么说」当成证据。若两台机器人来自同一台相机、同一张上游地图、同一条被延迟的消息，它们的一致**没有增加一点独立信息**。更糟的是，融合「最新值」会在时间错位处制造虚假的锐化：机器人 A 的信念指向 t−100ms，B 指向 t−20ms，直接融合会把两个不同时刻的状态平均成一个看起来更窄、实际上没有对应任何真实时刻的分布。协作因此有两种截然不同的收益：**独立证据带来的真降熵**，与**共同祖先/陈旧复制带来的假降熵**。R71 必须把两者在数学上分开。

**灵感 3（统一预算 → 「算 / 说 / 做」在争夺同一份毫秒）**
直觉：控制周期只有 D 毫秒。多算一步粒子滤波，就少一次通信；多问一个队友，就晚一点动手；立即动手，就放弃可能更准的信念。R69 的交互是「看/问/触」，R70 的 BSE 是「预测/更新」，但两者都没有把**计算**当成一个可选动作，也没有把**通信**与**执行**放到同一张预算表上。R71 把它们统一成三个可调度动作：compute、communicate、act，用「每毫秒的期望风险下降」排序；当边际收益递减时，贪心即可近似最优。这把实时性从「必须满足的约束」变成「可被价值化的资源」。

**灵感 4（时间诚实 → 不能让陈旧证据凭空降熵）**
直觉：贝叶斯融合的熵降必须由互信息支付。若一条消息已经过期，它关于「现在」的互信息已经衰减；若它和本地证据共享祖先，它的有效样本量小于 1。直接把它当独立新鲜证据，就会得到「熵掉了，但世界没变清楚」的**置信赤字（confidence debt）**。R68 的铁律是「不确定就收紧」；R71 的铁律是「**没有信息支持的熵降，不许用来放松**」。这条规则是实时协作系统防止「自信地错」的最后一道闸。

**灵感 5（严格包含 + 新威胁模型 → 协作与实时都会放大攻击面）**
直觉：只要没有队友、没有 slack、消息全过期或不独立，CHRONO 就必须逐指令退化到 R70；这样新层永远是旧层的严格泛化，而不是必须被信任的黑箱。但新增的通道也带来新攻击：伪造时间戳让陈旧消息显得新鲜（clock spoofing）、重放旧共识（replay）、用大量同源机器人制造假多数（sybil/echo chamber）、在 deadline 前塞满通信让系统被迫使用过期信念（deadline flooding）。**实时性越高，错误传播越快**——所以时间证明、来源证明与证据纪律必须与调度器同层设计，而不能事后补。

## 1. 形式化定义（增量：定义 331–350）

**定义 331（CHRONO-RAS 总览）** CHRONO-RAS = (TBF, ABI, JSC, TEF, IDG, FCD, VHC, TAP, BCR, VQAuditor-IV, AIC-CHRONO, RAS-Baselines v3, Proto-Val v3, BELIEF-RAS†)。四不变式：
(i) **实时零学习写操作**（继承 R70 定义 310-i）；
(ii) **单一 deadline 预算**：计算、通信、执行共享同一控制周期 D，准入控制保证最坏响应时间可调度；
(iii) **时间诚实**：任何熵降必须由「年龄折扣 × 独立性折扣」后的互信息支付；不足部分记为置信赤字 κ，只能用于收紧、不得用于放松；
(iv) **独立共识**：一致只有在来源独立时才算证据；单源、同源、过期或不可认证的一致性一律保持 U_epi 未消解。

**定义 332（时间索引信念场 TBF）** 在 wall-clock t 计算、指向状态时刻 τ 的信念
b_{t|τ}(s) = p(s_τ | o_{1:t}, m_{1:t}, ξ_{1:t-1}),  τ ∈ [t−H, t+H]。
一个信念必须与其二元时间标签 (t, τ) 一起被传输、审计和使用；age a = t − τ。单时刻后验 b_t = b_{t|t} 是 TBF 的对角线，而不是全部。

**定义 333（不确定性的资源分解）** 把 R69/R70 的 epistemic 再按「用什么资源才能消解」拆开：
U = U_ale + U_epi^obs + U_epi^comp + U_epi^comm，
其中 U_ale = E_{s∼b}[tr Σ_obs(s)] 为不可约噪声；U_epi^obs 为再观测/交互可消解部分（R69/R70）；U_epi^comp 为 anytime 算法在 deadline 前停止所产生的近似残差（可用 KL(b^{(n)}‖b^{(∞)}) 或证书 ε_n 上界）；U_epi^comm 为在 deadline 内由独立队友证据可消解的部分（按年龄与独立性折扣）。四者货币不同：观测、毫秒、消息/带宽、时间。只有 U_epi^comp 能靠「再算」消解，只有 U_epi^comm 能靠「再问」消解；消解不掉的残余统一进入 λ_floor。

**定义 334（带证书的 anytime 贝叶斯滤波 ABI）** BSE 可在任意停止时刻 τ_stop 返回 (b^{(n)}, ε_n)，满足 ε_n ≥ sup_s |b^{(n)}(s) − b^{(∞)}(s)|（或 KL 上界），且 ε_n 随迭代单调不增。若到 deadline 仍不能满足 ε_n ≤ ε_max，则令 U_epi^comp = ε_n，并禁止把该信念用于放松安全约束。ABI 的关键不是「更快」，而是**把没算完的部分显式标价**。

**定义 335（实时预算与可调度性）** 控制周期 D，分配 c = (c_comp, c_comm, c_act)，满足 c_comp + c_comm + c_act ≤ D。各模块 WCET 已知；基线 slack S = D − WCET_base。仅当响应时间分析通过、且本次调度将使用的所有信念满足 age ≤ T_val（定义 342）时，协作推理才被准入。**准入控制是安全的一部分，不是性能优化。**

**定义 336（通信消息语义）** 消息 m = (j, t_send, t_ref, ŝ, Σ 或粒子摘要, π_m, ι_m, sig_j)：发送者 j、发送时刻、状态参考时刻、信念摘要、来源谱系哈希 π_m、独立性类别 ι_m、签名。接收端年龄按 a = t_recv − t_ref 计，而不是按 t_send；消息必须带单调计数器且在重放窗口内。**时间的参考点是状态，不是发送动作。**

**定义 337（时间对齐与陈旧膨胀）** 将发送端信念预测到接收端参考时刻 τ：
b_{t_recv|τ} = T_{τ←t_ref} b_{t_send|t_ref}，
并做陈旧膨胀 Σ ← Σ + Q(τ−t_ref) + σ_stale²(τ−t_ref) I。等价地在 Fisher 信息矩阵上做年龄折扣：J(Δ) = β(Δ) J(0)，β(Δ) = exp(−Δ/τ_corr)。**任何跨机融合必须先对齐时间，再谈信息。**

**定义 338（证据独立图 IDG）** 以证据源（传感器、机器人、上游消息）为顶点，以共享来源谱系为边。独立性类别 ι 由源之间的相关性上界给出。有效样本量
n_eff = (Σ_i w_i)² / Σ_i Σ_j w_i w_j ρ_{ij}，
其中 ρ_{ij} ∈ [0,1] 为共同祖先导致的相关性；k 个两两相关 ρ 的源满足 n_eff ≤ k / (1 + (k−1)ρ)。共识要求 n_eff ≥ n_min；**十个回声室仍然只是一票。**

**定义 339（时间诚实融合 TEF）** 对数域更新
log b⁺(s) = log b⁻(s) + Σ_m β(a_m) · ι_m · log[p(y_m|s) / p(y_m|m⁻)] + const，
并施加熵降上限
H[b⁻] − H[b⁺] ≤ I_eff({m}; s) + ε_cert。
若未截断的融合会带来更大的熵降，超出部分记为置信赤字 κ；安全缩放必须使用 λ_floor(U + κ)。**κ 是「借来的确定性」，必须连本带息从安全裕度里扣回。**

**定义 340（假共识与认知羊群 FCD）** 当 ≥ k 个源给出一致判断时称共识事件。若 n_eff < n_min，或实际熵降超过 I_eff，则为**假共识**。定义羊群指数
ℋ = (H_before − H_after) / I_eff；
ℋ > 1 表示「置信被制造出来而非信息被获得」。检测到 ℋ > 1 时回滚到融合前信念，并把该来源图标记为可疑。

**定义 341（计算—通信—执行联合 VoI 调度 JSC）** 决策时的候选动作：
- compute：再跑一轮迭代/采样，成本 δ_c 毫秒；
- communicate：向机器人 j 查询或广播摘要，成本 δ_m(j) 毫秒 + 带宽；
- act：立即提交任务动作，时间成本 0，风险由当前信念给定。
选择 a = argmax ΔR(a)/cost(a)，s.t. 总成本 ≤ D 且满足定义 335/342；ΔR 为期望风险下降。边际收益递减时目标函数子模，贪心达 (1−1/e) 近似最优；最优策略呈阈值结构：先算到边际 VoI 低于通信，再通信，最后动手。**「再算」「再问」「现在做」是同一个优化问题的三个分支。**

**定义 342（有效性视界与动作认证 VHC）** 对动作 a，其后果时域 H_a 与风险容差 ε 定义有效性视界
T_val(a) = max{ Δ : 对任意 age ≤ Δ 的信念膨胀，动作风险 ≤ ε }。
动作只能基于 age ≤ T_val(a) 的信念下发；否则必须重算、改选更保守（T_val 更大）的动作，或退化到 R70。**信念过期不是信息少一点，而是动作证书失效。**

**定义 343（deadline 单调安全）** 错过 deadline 的信念永远不得用于**放松**安全：晚到的消息/信念只能作为先验或收紧项。形式化：若 t > deadline(b)，则相对 R70 兜底，λ 单调不降。这是 R68「任何不确定 → 只收紧」在实时维度上的严格延伸。

**定义 344（时间证明 TAP）** 每台机器人的时钟须经单调计数器 + 签名时间戳 + 有界偏斜 |skew| ≤ δ_clock 认证；接收端拒绝新鲜度窗口外或计数器复用的消息。若时间证明不可用，该消息的独立性类别降级为「不可信先验」，不得降低熵、不得放松 λ。

**定义 345（拜占庭 + 陈旧共识上界 BCR）** k 台机器人中 f 台拜占庭，新鲜度窗口 Δ，来源相关性 ρ，欺骗率 δ_p。采用来源聚类 + 截断/中位数鲁棒融合，并要求独立簇数 n_eff ≥ 2f + 1；则假共识概率 ≤ g(f, k, δ_p, ρ, Δ)，其中 g 随 f、ρ、Δ 单调增，随独立簇数指数降。**多数不是安全，独立多数才是。**

**定义 346（参与式审计 VQAuditor-IV）** 审计新增：时间戳/重放合规、动作时信念年龄、置信赤字是否记账、假共识事件、拜占庭举报、deadline miss、同源消息是否被重复计权。结论回灌 AuditBuf，成为下一轮 JSC 与 FCD 的先验。

**定义 347（AIC-CHRONO 对抗集）** ℰ_CHRONO = ℰ_BELIEF × ℰ_time（时钟偏斜 / 重放 / 延迟尖峰 / deadline flooding）× ℰ_consensus（共谋 / 回声室 / 陈旧投毒 / 伪造来源 / sybil）× ℰ_sched（优先级反转 / 饥饿 / WCET 低估）× ℰ_anytime（非单调早停 / 粒子坍缩 / 证书失效）。

**定义 348（证书 J_CHRONO）** J_CHRONO = (J_BELIEF, deadline_miss_rate, max_age_p99, confidence_debt, FCR, n_eff_min, clock_skew_p99, replay_rejects, chrono_ver)。Valid ⇔ Valid(J_BELIEF) ∧ 安全环 deadline miss = 0 ∧ max age ≤ 对应 T_val ∧ debt ≤ κ_max ∧ FCR ≤ τ_fcr ∧ n_eff ≥ n_min。

**定义 349（严格退化链与基线协议 v3）** 若无队友、无 slack、消息全过期/不独立/不可认证，CHRONO 逐指令退化为 BELIEF-RAS（→ FLUID-RAS → CALM-RAS → R68）。RAS-Baselines v3 在 v2 基础上增加：R70-Local、Latest-Value-Fusion、Sync-Fusion（只对齐时间不折龄）、Fixed-Schedule、Compute-Only、Comm-Only；指标含风险、成功率、deadline miss、假共识率、通信字节、计算毫秒。

**定义 350（原型验收 Proto-Val v3）** 三环境：Isaac Sim 多机（N=2–5）、ROS 2 + 真机（注入延迟/偏斜/丢包/重放）、硬件在环实时测试台。验收：安全环 P99 < 6.5ms、零 deadline 诱发违规、max belief age ≤ T_val、FCR < 2%、f=1/5 拜占庭下假共识 < 5%、可调度率 100%、且在「独立队友 + 有 slack」时显著优于 R70（Wilcoxon p<0.01）。

```python
class TemporalBeliefField:
    def __init__(self, bse, horizon_ms):
        self.bse, self.horizon = bse, horizon_ms
        self.ring = RingBuffer(horizon_ms)          # 存 b_{t|tau}

    def at(self, tau):
        return self.ring.interpolate_or_predict(tau)

    def insert(self, b, t, tau):
        self.ring.put((t, tau), b)                  # 绝不丢弃时间标签

# IP-276 ABI：带证书的 anytime BSE（没算完的部分显式标价）
def anytime_bse(o, b_prev, deadline_ns):
    b, eps = b_prev, INF
    while time_ns() < deadline_ns and not scheduler.preempted():
        b, eps = bse_step(b, o)                     # 单调改进
    eps = max(eps, bse_convergence_bound(b))        # 证书下界
    return b, eps                                   # eps -> U_epi^comp

# IP-277 JSC：计算/通信/执行共享同一 deadline 预算
def schedule(actions, budget_ns, b_tbf):
    cands = [('act', now, risk_now(b_tbf))]
    cands += [('compute', delta_c, d_risk_compute(b_tbf))]
    cands += [('comm', delta_m(j), d_risk_comm(j, b_tbf))
              for j in teammates if idg.independent(j)]
    cands = [c for c in cands if vhc.feasible(c, b_tbf) and budget_ns.allow(c)]
    return greedy_by_value_per_ns(cands)            # 子模 -> (1-1/e)

# IP-278 TEF：时间诚实融合（年龄折扣 + 独立性折扣 + 熵降封顶）
def time_honest_fuse(b, messages, idg):
    logb, info = log(b), 0.0
    for m in messages:
        a  = now() - m.t_ref
        beta = exp(-a / TAU_CORR)                   # 年龄折扣
        iota = idg.independence(m.provenance)       # 独立性折扣
        logb = logb + beta * iota * m.log_lik(b)
        info += beta * iota * m.mutual_info(b)
    b_post = normalize(exp(logb))
    cap = entropy(b) - info - EPS_CERT
    if entropy(b_post) < cap:                       # 不许凭空降熵
        b_post = temper_to_entropy(b_post, cap)
        debt   = cap - entropy(b_post)
        audit.book_confidence_debt(debt)            # 只许收紧
    return b_post, debt

# IP-279 IDG：来源谱系与有效样本量
def effective_n(messages):
    W  = sum(m.weight for m in messages)
    rho = correlation_from_provenance(messages)     # 共同祖先 -> rho
    return W**2 / sum(wi * wj * rho[i][j]
                      for i, wi in enumerate(messages)
                      for j, wj in enumerate(messages))

    return (clock_attestation.verify(m)
            and m.counter > last_counter[m.sender]
            and abs(m.t_send - now()) <= FRESH_WINDOW)

# IP-283 BCR：拜占庭 + 陈旧鲁棒融合
def robust_consensus(beliefs, idg, f):
    clusters = provenance_clusters(beliefs)         # 同源先聚类
    if len(clusters) < 2 * f + 1:
        return None                                 # 不够独立，宁可不共识
    return trimmed_median_fuse(clusters)            # 每簇只投一票

# IP-286 CHRONO-RAS 主闭环
def CHRONO_RAS_round(M, obs):
    # 0) 时间证明 + 来源独立图
    msgs = [m for m in M.inbox.drain() if M.tap.accept(m)]
    M.idg.update(msgs)

    # 1) 预测到统一参考时刻（先对齐，再融合）
    tau     = M.clock.now()
    aligned = [M.tbf.predict(m, tau) for m in msgs]
    b_pred  = M.tbf.at(tau)

    # 2) 时间诚实融合 + 假共识检测
    b_fused, debt = M.tef.fuse(b_pred, aligned, M.idg)
    if M.fcd.false_consensus(b_pred, b_fused, M.tef.last_info):
        b_fused, debt = b_pred, debt + M.tef.last_info

    # 3) anytime BSE 到 deadline，拿证书 epsilon
    b_t, eps = M.abi.update(obs, b_fused, M.deadline - M.wcet.remaining())
    U_ale, U_obs = M.aud.ale_obs(b_t)
    U_comp, U_comm = eps, M.idg.comm_reducible(b_t, M.teammates, tau)

    # 4) 联合调度：算 / 说 / 做
    plan = M.jsc.schedule(b_t, M.deadline, debt)
    if plan.kind == 'compute':
        b_t, eps = M.abi.continue(plan.steps);  U_comp = eps
    elif plan.kind == 'comm':
        M.tbf.send(M.idg.summary(b_t), target=plan.robot)
        U_comm = M.idg.remaining(b_t)

    # 5) 有效性视界认证 + 风险缩放（deadline 只许收紧）
    if not M.vhc.certify(plan.act, b_t):
        plan.act, U_comp = M.fallback.conservative(plan.act), max(U_comp, TAU_AGE)
    U_floor = U_ale + U_obs + U_comp + U_comm + debt
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))

    # 6) 认证执行 + 审计 + 证书
    A = M.ach.propose(plan.act, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    M.vqa_iv.submit_async(b_t, msgs, debt, plan, lam)
    M.cert.emit(J_CHRONO(b_t, debt, ...))
    return k, lam, plan.act, (U_ale, U_obs, U_comp, U_comm, debt)
```

## 3. 推导

**引理 23（陈旧信息衰减）** 对满足混合性的马尔可夫状态，I(s_τ; m_{t_ref}) 随 Δ = τ − t_ref 非增；指数遗忘模型下 J(Δ) = e^{−Δ/τ_c} J(0)，故任何不做年龄折扣的融合都会高估信息，高估量恰可定义为置信赤字 κ。系：**「新鲜」不是消息的属性，而是消息与当前参考时刻关系的属性。**

**引理 24（相关证据的有效样本量）** 若 k 个源两两相关性 ρ，则 n_eff ≤ k/(1+(k−1)ρ)；当 ρ→1（共享祖先）时 n_eff→1。系：多机共识的方差下降由 n_eff 而非 k 决定；十个回声室只提供一票的信息量，却会让朴素融合的熵降十倍。

**引理 25（anytime 残差可界）** 若 BSE 迭代以速率 α 收缩，则 ε_n ≤ Cα^n；在 deadline 前可执行的迭代数为 n(D) = ⌊(D − WCET)/δ_c⌋，故 U_epi^comp ≤ Cα^{n(D)}。系：**早停不是免费的，它的代价可以被预算表精确记账**，并直接进入 λ_floor。

**定理 20（时间诚实融合无免费置信）** 在引理 23–24 与定义 339 下，任何被 TEF 接受的融合满足 H[b⁻] − H[b⁺] ≤ I_eff；超额熵降要么被截断，要么以 κ 记账并从安全裕度扣除。因此不存在「用陈旧/相关证据降低 λ」的路径，安全单调性保持。

**定理 21（计算—通信—执行联合调度的近似最优性）** 若 compute/communicate 的期望风险下降随投入毫秒边际递减、且证据源独立，则目标函数在预算约束下子模；贪心达到 (1−1/e) 近似，且最优策略存在阈值结构（先算后问再做），阈值由各自的边际 VoI/ms 决定。系：R69 的「先交互再执行」与 R70 的「先估计再执行」都是该策略在特定成本下的特例。

**定理 22（严格包含 R70）** 在 A99–A101 与定义 331 下，CHRONO 的期望风险 ≤ BELIEF ≤ FLUID ≤ R68；当无队友、无 slack、消息全过期/不独立/不可认证时，CHRONO 与 BELIEF 逐指令相同。因此 R71 不引入必须被信任的新黑箱：**新能力全部是可关闭的增益。**

**定理 23（拜占庭 + 陈旧共识上界）** 采用来源聚类 + 每簇一票 + 时间证明，且 n_eff ≥ 2f + 1 时，f 台拜占庭与年龄 Δ 的联合影响满足假共识概率 ≤ g(f,k,δ_p,ρ,Δ)；当 ρ→1 或 Δ→∞ 时 g→1，说明**同源与陈旧会把任何多数规则退化为无效**，此时系统必须回退 R70。

**定理 24（deadline 单调安全）** 若调度器强制执行定义 342–343，则不存在基于 age > T_val 的动作下发；deadline miss 只会使 λ 不降、动作更保守。故实时性不会以安全为代价，最坏情形严格不弱于 R70 兜底。

## 6. 本轮最大风险

**一句话**：CHRONO-RAS 把「新鲜」与「独立」当作可计算的事实，但这两者最终都依赖**可被伪造的时间戳与来源声明**——只要对手让陈旧或共谋的证据看起来新鲜且独立，系统就会在 deadline 前「合法地」建立假共识；而实时性越高，这个错误传播得越快，**「按时得到的错误共识」比「迟到的诚实不确定」更危险**。

**定义 332（时间索引信念场）** b_{t|τ} 以 (t, τ) 二元标签被传输、融合与审计；b_t = b_{t|t} 仅为对角线。**信念不是「现在的」，而是「关于某个时刻的、在某时刻算出的」。**

**定义 333（资源分解）** U_ale 为不可约噪声；U_epi^obs 由观测/交互消解；U_epi^comp 由计算毫秒消解；U_epi^comm 由独立通信消解。四者不可简单相加为同一语义，但共同进入 λ_floor 时必须按各自货币折算。

**定义 334（anytime 证书）** BSE 可在任意停止时刻返回 (b^{(n)}, ε_n)，ε_n 单调不增且为真实误差上界；deadline 前不达 ε_max 时 U_epi^comp=ε_n，禁止放松安全。

**定义 335（可调度性）** 仅当响应时间分析通过且所用信念满足 age ≤ T_val 时准入协作推理；准入失败即走本地 R70 路径。

**定义 336（消息语义）** 年龄以 t_ref 计，不以 t_send 计；消息带来源谱系 π_m、独立性类 ι_m、签名与单调计数器。**时间参考状态，而不是发送动作。**

**定义 337（时间对齐与陈旧膨胀）** 跨机融合先预测到公共 τ，再加过程噪声与陈旧方差；Fisher 信息按 β(Δ)=e^{−Δ/τ_c} 折扣。

**定义 338（独立图与 n_eff）** 共享祖先产生相关性 ρ；k 个两两相关源满足 n_eff ≤ k/(1+(k−1)ρ)；共识要求 n_eff ≥ n_min。

**定义 339（时间诚实融合）** 对数域似然按 β(a)ι 加权；熵降封顶 H⁻−H⁺ ≤ I_eff+ε_cert；超额记 κ 并从安全裕度扣除。

**定义 340（假共识）** n_eff 不足或 ℋ>1 即假共识；回滚融合前信念，标记来源图，并计入审计。

**定义 341（联合 VoI 调度）** 候选 compute/communicate/act；按 ΔR/cost 贪心，预算 ≤ D；边际递减下 (1−1/e) 近似；最优策略呈「先算—再问—后做」阈值结构。

**定义 342（有效性视界）** T_val(a) 由动作后果时域与风险容差决定；age > T_val(a) 的动作无证书，必须重算/改保守/退化。

**定义 343（deadline 单调安全）** 迟到信念只能作为先验或收紧项；错过 deadline 时 λ 相对 R70 兜底单调不降。

**定义 344（时间证明）** 单调计数器 + 签名时间戳 + 有界偏斜；不可认证消息降级为「不可信先验」，不得降熵或放松 λ。

**定义 345（拜占庭 + 陈旧上界）** 来源聚类 + 每簇一票 + 截断中位数；n_eff ≥ 2f+1；假共识概率随 f、ρ、Δ 单调增，随独立簇数指数降。

**定义 346–350** VQAuditor-IV 审计时间/来源/赤字/假共识/deadline；AIC-CHRONO 覆盖 time/consensus/sched/anytime 四类攻击；J_CHRONO 证书覆盖实时与协作维度；无队友/无 slack/全过期时逐指令退化 BELIEF；Proto-Val v3 验收 P99<6.5ms、零 deadline 违规、FCR<2%、f=1/5 假共识<5%、独立协同时显著优于 R70。

```python
# IP-275 TBF：时间索引信念场
class TemporalBeliefField:
    def __init__(self, bse, horizon_ms=200):
        self.bse, self.ring = bse, RingBuffer(horizon_ms)

    def at(self, tau):
        return self.ring.interpolate_or_predict(tau)

    def predict(self, m, tau):
        # 先把消息信念推到公共参考时刻，再做任何加权
        return (m.belief.predict(tau),
                m.cov + process_noise(tau - m.t_ref) + stale_inflation(tau - m.t_ref))

    def insert(self, b, t, tau):
        self.ring.put((t, tau), b)          # 标签不可丢

# IP-276 ABI：deadline 截断的 anytime BSE
def anytime_bse(b_prev, o, deadline_ns):
    b, eps = b_prev, INF
    while time_ns() < deadline_ns:
        b, eps = bse_step(b, o)             # 每次迭代都给出新证书
        if eps <= EPS_MAX:
            break
    return b, max(eps, convergence_bound(b))  # U_epi^comp

# IP-277 JSC：算/说/做共享预算
def joint_schedule(b, D, teammates):
    cands = [('act', 0, risk_now(b))]
    cands.append(('compute', DELTA_C, delta_risk_compute(b)))
    for j in teammates:
        if idg.independent(j) and tap.fresh(j):
            cands.append(('comm', latency(j), delta_risk_comm(b, j)))
    cands = [c for c in cands if c.cost <= D and vhc.feasible(c, b)]
    return max(cands, key=lambda c: c.delta_risk / max(c.cost, 1e-6))

# IP-278 TEF：时间诚实融合（折扣 + 封顶 + 记债）
def time_honest_fuse(b, msgs):
    logb = log(b)
    info = 0.0
    for m in msgs:
        a    = now() - m.t_ref
        beta = exp(-a / TAU_CORR)
        iota = idg.independence(m.provenance)
        logb = logb + beta * iota * m.log_lik(b)
        info += beta * iota * m.mutual_info(b)
    b_post = normalize(exp(logb))
    cap = entropy(b) - info - EPS_CERT
    debt = 0.0
    if entropy(b_post) < cap:
        debt = cap - entropy(b_post)
        b_post = temper_to_entropy(b_post, cap)   # 不许凭空降熵
        audit.book_debt(debt)                     # 只许收紧
    return b_post, debt

# IP-279 IDG / IP-280 FCD / IP-281 VHC / IP-282 TAP / IP-283 BCR
def effective_n(msgs):
    W = sum(m.w for m in msgs)
    rho = provenance_correlation(msgs)
    return W**2 / sum(mi.w * mj.w * rho[i][j] for i, mi in enumerate(msgs)
                      for j, mj in enumerate(msgs))

def is_false_consensus(b0, b1, info_eff, n_eff):
    return n_eff < N_MIN or (entropy(b0) - entropy(b1)) > info_eff + EPS

def certify_action(a, b, eps_risk):
    return now() - b.tau <= validity_horizon(a, eps_risk)

def accept(m, attest):
    return attest.verify(m) and m.counter > last[m.sender] \
       and abs(m.t_send - now()) <= FRESH_WINDOW

def robust_fuse(beliefs, f):
    clusters = provenance_clusters(beliefs)
    if len(clusters) < 2 * f + 1:
        return None                     # 独立簇不够，拒绝共识
    return trimmed_median([c.median for c in clusters])

# IP-286 CHRONO-RAS 主闭环
def CHRONO_RAS_round(M, obs):
    msgs = [m for m in M.inbox.drain() if M.tap.accept(m)]
    M.idg.update(msgs)
    tau = M.clock.now()
    b_prev = M.tbf.at(tau)
    aligned = [M.tbf.predict(m, tau) for m in msgs]

    b_fused, debt = M.tef.fuse(b_prev, aligned)
    if M.fcd.false_consensus(b_prev, b_fused, M.tef.info, M.idg.n_eff):
        b_fused, debt = b_prev, debt + M.tef.info

    b, eps = M.abi.update(obs, b_fused, M.deadline - M.wcet.used())
    U_ale, U_obs = M.aud.ale_obs(b)
    U_comp = eps
    U_comm = M.idg.comm_reducible(b, M.teammates, tau)

    plan = M.jsc.schedule(b, M.deadline, M.teammates)
    if plan.kind == 'compute':
        b, eps = M.abi.continue(plan.steps); U_comp = eps
    elif plan.kind == 'comm':
        M.tbf.send(M.idg.summary(b), target=plan.robot)
        U_comm = M.idg.remaining(b)

    if not M.vhc.certify(plan.act, b):
        plan.act = M.fallback.conservative(plan.act)
        U_comp = max(U_comp, TAU_AGE)

    U_floor = U_ale + U_obs + U_comp + U_comm + debt
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    A = M.ach.propose(plan.act, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)

    M.vqa_iv.submit_async(b, msgs, debt, plan, lam)
    M.cert.emit(J_CHRONO(b, debt, ...))
    return k, lam, plan.act, (U_ale, U_obs, U_comp, U_comm, debt)
```

## 4. 推导

**引理 23（陈旧信息衰减）** 混合马尔可夫状态下 I(s_τ;m_{t_ref}) 随 Δ 非增；指数遗忘给出 J(Δ)=e^{−Δ/τ_c}J(0)。故不做年龄折扣的融合必然高估信息，高估量即 κ。

**引理 24（相关证据的有效样本量）** k 个两两相关 ρ 的源满足 n_eff ≤ k/(1+(k−1)ρ)；ρ→1 时 n_eff→1。系：多机共识的价值由独立簇数决定，而不是机器人数量。

**引理 25（anytime 残差可界）** 收缩速率为 α 的 BSE 满足 ε_n ≤ Cα^n；可执行迭代数 n(D)=⌊(D−WCET)/δ_c⌋，故 U_epi^comp ≤ Cα^{n(D)}。早停代价可被预算表精确记账。

**定理 20（时间诚实融合无免费置信）** TEF 接受的融合满足 H⁻−H⁺ ≤ I_eff；超额熵降被截断或以 κ 记账并从安全裕度扣除，故不存在以陈旧/相关证据降低 λ 的路径。

**定理 21（联合调度近似最优）** 边际收益递减且证据独立时，compute/communicate 的期望风险下降在预算约束下子模；贪心达 (1−1/e)，最优策略呈「先算—再问—后做」阈值结构；R69/R70 的固定顺序是其特例。

**定理 22（严格包含 R70）** 无队友、无 slack、消息全过期/不独立/不可认证时，CHRONO 与 BELIEF 逐指令相同；一般情况下期望风险 ≤ BELIEF ≤ FLUID ≤ R68，安全侧永不更弱。

**定理 23（拜占庭 + 陈旧上界）** 来源聚类 + 每簇一票 + 时间证明 + n_eff ≥ 2f+1 下，假共识概率 ≤ g(f,k,δ_p,ρ,Δ)；ρ→1 或 Δ→∞ 时 g→1，系统必须回退 R70。

**定理 24（deadline 单调安全）** 强制 VHC 与定义 343 时，不存在基于 age > T_val 的动作下发；deadline miss 只会使 λ 不降、动作更保守，实时性不以安全为代价。

## 7. 本轮最大风险

**一句话**：CHRONO-RAS 的「新鲜」与「独立」最终依赖可被伪造的时间戳与来源声明——一旦对手让陈旧或共谋证据看起来新鲜且独立，系统就会在 deadline 前合法地建立假共识，而实时性越高，错误传播越快；**「按时得到的错误共识」比「迟到的诚实不确定」更危险**。
