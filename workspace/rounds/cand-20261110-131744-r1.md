# 第 44 轮（新循环第 1 轮） · Arena-Intent-Cert：把「意图识别」升格为对抗性逆博弈，把「机器人竞赛」升格为合法性×安全性×得分三轴证书（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈的最大风险是「共形预测只保边际覆盖，按人格/多用户条件覆盖可被欺骗」。本轮灵感词「意图识别」「机器人竞赛」恰好把这颗雷挖到根上：在竞赛里，意图识别的对象不是一个被动数据分布，而是一个**会因你的策略而改变行为的对手**；可交换性恰好在最需要它的时刻失效。于是本轮不再假设「数据来自同一分布」，而是把意图识别重写为**逆博弈**——对手是 ε-理性的，观测是策略性生成的，覆盖必须对**任意自适应序列 time-uniform** 成立。竞赛还额外给了两样此前没有的东西：**硬规则**（可编译为监控器、可裁判、可审计）与**显式得分**（可优化、可比较）。由此把 v20 的「安全 / 可用」二轴，升级为「安全 ≻ 合法性 ≻ 得分」三轴字典序证书。

## 0. 直觉与动机

**灵感 1（意图识别 → 不是分类，是逆博弈；可交换性必须被替换）**：直觉上，若把对手当成固定分布做共形预测，对手只要「读懂你的预测器再反向操作」，覆盖率保证就形同虚设——这正是 v20 最大风险的竞赛版。严谨地说，竞赛中的观测 o_t 由对手策略 π_θ 与我的策略 a_t 共同生成，是闭环、非平稳、可被操纵的序列。因此引入 **ε-理性类型集 Θ_ε**（只保留近似最优响应的意图，排除「为骗你而故意犯傻」的无限对抗力），并用 **e-process 置信序列**构造 **time-uniform 安全意图集** Ĥ_t^safe：对任意自适应序列，P(∀t, h*∈Ĥ_t^safe) ≥ 1−α。它不要求可交换性，代价是集合更保守。核心一句：**对手会变，所以覆盖必须是时间一致（anytime-valid）的，而不是一次性可交换的。**

**灵感 2（机器人竞赛 → 规则是可证明的，得分是可优化的，二者必须分层）**：竞赛与开放世界的差别是**规则显式且裁判可执行**。规则是硬约束（越界、犯规、超时、接触力上限），必须像安全一样被证明；得分是软目标（进球、时间、姿态分），只需高置信下界。把二者混进一个奖励里是灾难：优化得分会诱导钻规则空子。因此定义 **三轴证书 K=(K_safe, K_legal, K_score)**，选择策略时按**字典序** 安全 ≻ 合法性 ≻ 得分：先证明不犯规不伤人，再在合法安全集里最大化得分 LCB。竞赛由此从「演示场」变成「可验证策略的基准协议」。

**灵感 3（耦合 → 双意图集 + 意图租约：安全用保守集，得分用激进集）**：安全与得分对意图精度的需求相反：安全要**最坏情况意图**，得分要**最可能意图**。用一个集合同时满足二者必然二选一失败。于是拆成 **Ĥ^safe（对抗、保守、anytime-valid）** 与 **Ĥ^perf（校准、激进、高精度）**：安全证书只读前者，得分估计只读后者；后者错了只丢分，绝不丢安全。再加一条竞赛特有的时间维度——**意图租约**：对手会佯攻（feint），上一秒的意图下一秒可能致命，因此意图也带 (Ĥ, τ, λ_intent, κ) 并按定义 41 衰减，过期即退回最坏情况集。核心一句：**安全集可以笨，但必须永不被骗；性能集可以错，但只能错在记分牌上。**

**耦合升级**：SIE（战略意图引擎）把对手编译成 ε-理性类型分布 + 双意图集 + 意图租约；CCP（竞赛证书规划器）把规则编译成硬监控器、把得分编译成 LCB 目标，做字典序约束规划；ARV（竞技场裁判验证器）用可执行裁判 + 自博弈锦标赛 + 佯攻投毒，把反例回灌 CKB/SCV。四层架构由 v8 的「人格契约 + 并发证书」升级为 v9 的「战略意图 + 三轴竞赛证书」。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（竞赛规约与三轴证书）**：竞赛规约 A=(R, S, O, T, δ_R)。R={φ_1..φ_m} 为可执行规则谓词（STL/时序逻辑），S 为得分泛函，O 为可观测性，T 为时域，δ_R≥0 为规则鲁棒裕度。对轨迹 τ，合法性谓词 Legal(τ)=∧_{φ∈R} (ρ_φ(τ) ≥ δ_R)，其中 ρ_φ 为鲁棒语义。策略 π 的**三轴证书** K(π)=(K_safe, K_legal, K_score)：K_safe 为最坏意图下不违反安全不变式；K_legal 为最坏意图下仍满足全部规则；K_score 为得分期望的置信下界。**字典序选择**：π* = argmax_{π: K_safe∧K_legal} K_score。**命题**：字典序把「得分优化」限制在「已证明安全且合法」的集合内，故得分策略无法以犯规/伤人为代价；若证书各轴均 sound，则 π* 的合成证书 sound。

**定义 45（ε-理性逆博弈意图集）**：类型空间 Θ，效用 U_θ，对手策略 π_θ，我方策略 a。定义类型 θ 的后悔 Regret_θ(π_θ, a)=max_{π'} U_θ(π',a) − U_θ(π_θ,a)。**ε-理性类型集** Θ_ε(a)={θ∈Θ : Regret_θ(π_θ,a) ≤ ε}。给定观测历史 o_{1:t} 与联合动作 a_{1:t}，逆博弈意图集 Î_t = {θ∈Θ_ε : L(o_{1:t} | θ, a_{1:t}) > 0}（或用贝叶斯逆规划得后验 support）。**含义**：对手不会为了骗你而无限度地打烂自己的比赛；ε 就是「欺骗的预算」。ε→0 是完美理性（最危险、最可预测），ε→∞ 退化为任意对抗（最保守）。

**定义 46（e-conformal time-uniform 安全意图集）**：对每个候选类型 θ 维护一个检验「观测序列由 θ 生成」的 e-process E_t(θ)（非负测试鞅）。在有限 Θ 或 ε-网离散化下，取 **安全意图集** Ĥ_t^safe = {θ : E_t(θ) < 1/α}（必要时除以 |Θ| 做并集修正）。**定理（Ville 型 time-uniform 覆盖）**：对真实类型 θ* 生成的任意（可自适应、非可交换）序列，P(∃t : θ* ∉ Ĥ_t^safe) ≤ α。**推论**：不依赖可交换性即可获得全过程覆盖；代价是集合膨胀（保守性），且保证只相对于类型空间 Θ 成立。**注**：这是对 v20 定义 39 的关键修补——把「一次性边际覆盖」换成「时间一致覆盖」。

**定义 47（双意图集、意图租约与安全-性能解耦）**：Ĥ_t^safe 如定义 46；Ĥ_t^perf 由 v20 定义 39 的 Mondrian 共形给出（高精度、仅用于得分）。**意图租约** ℓ_I=(Ĥ^safe, τ, λ_intent, κ)：λ_intent 由对手策略变化率的经验上界/变点检测给出，新鲜度判据沿用定义 41。**解耦定理**：(i) 安全证书只依赖 Ĥ^safe，故 Ĥ^perf 的任何错误都不改变 K_safe 的 soundness；(ii) 得分 LCB 关于 Ĥ^perf 单调（集合越小、估计越紧、得分越高），故性能集的价值只体现在记分牌上。**回退**：若佯攻检出（e-process 近期拒绝 + 变点告警）或租约过期，则 Ĥ^perf←Ĥ^safe，策略自动从「利用」切到「最坏情况防守」。

**定义 48（三轴证书的一致选择与规则硬约束）**：候选策略池 {π_1..π_b}，每个 π_j 独立计算 K_j=(K_safe, K_legal, K_score)。**一致选择**：π* = argmax_{j: K_safe,j∧K_legal,j} K_score,j；若选择集为空，则触发**合法让步/安全停机**，绝不静默放行。**定理**：若每个 K_j 在其有效域内 sound，且选择只取 safe∧legal 的分支，则输出策略的三轴证书 sound（并行只增加候选，不破坏可靠性）。**规则硬约束**：K_legal 的规则监控器固定最高关键级，其预算不随 HI 模式收缩（继承定义 42）。

**定义 49（裁判一致性与规则鸿沟）**：形式规则 R 与可执行裁判 R̂ 之间存在**规则鸿沟** g_R = sup_τ |ρ_R(τ) − ρ_{R̂}(τ)|（含语义歧义、时序窗口、边界判定差异）。**裁判一致性**：仅当 ρ_R(τ) ≥ δ_R + g_R 时才宣称「无可争议的合法」。**命题**：若实际轨迹满足 ρ_R ≥ δ_R + g_R，则任何与 R 相差不超过 g_R 的裁判实现 R̂ 都不会判负；故 g_R 必须由规则 fuzz 显式估计并计入裕度，而非假设 R=R̂。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 STRATEGIC-INTENT-ENGINE（战略意图引擎 SIE）
1. **ε-理性逆博弈推断**：类型空间 Θ（进攻/防守/佯攻/拖延/协同）、效用 U_θ、贝叶斯逆规划粒子滤波；只保留 Θ_ε，拒绝「无限非理性」的对抗力。
2. **e-conformal 安全意图集**：逐类型 e-process + Ville 修正，输出 time-uniform Ĥ^safe；空集时退化为全 Θ（保守兜底），绝不放宽。
3. **双意图集与仲裁**：Ĥ^safe（安全）/Ĥ^perf（得分）物理隔离；类型系统 + 静态检查保证 perf 集不得进入安全路径。
4. **意图租约与佯攻检测**：按 λ_intent 衰减；e-process 拒绝 + 变点检测识别佯攻；检出即过期、退回最坏情况。

### 2.2 IP-61 COMPETITION-CERT-PLANNER（竞赛证书规划器 CCP）
1. **规则编译**：R → STL/时序监控器 + 裕度 δ_R；规则监控器最高关键级、硬预算。
2. **得分编译**：S → 事件级回报 + 经验 Bernstein/e-process 置信下界 K_score。
3. **字典序约束规划**：在 safe∧legal 集内最大化 K_score；用 H_safe 定可行域、用 H_perf 估收益（约束-目标分离）。
4. **对手感知策略**：best-response / minimax / 混合；「利用模式 ↔ 防守模式」由意图租约新鲜度与佯攻告警切换。

### 2.3 IP-62 ARENA-REFEREE-VALIDATOR（竞技场裁判验证器 ARV）
1. **可执行裁判 + 规则鸿沟审计**：R̂ 独立实现，规则 fuzz 估计 g_R，红队构造边界轨迹。
2. **自博弈锦标赛**：种群对战 + Elo 评级 + 淘汰/变异，生成对抗课程；留出对手防过拟合。
3. **佯攻与意图投毒 fuzz**：假意图、低置信诱导、策略突变、协同欺骗；检验 Ĥ^safe 是否被骗。
4. **竞赛基准与可复现性**：固定种子/场地/裁判版本/回放日志；跨种子方差与回放确定性作为硬指标。

## 5. 本轮最大风险

**一句话**：整套对抗覆盖的 soundness 只相对于「类型空间 Θ + ε-理性模型」成立——若真实对手的意图不在 Θ 内，或故意以超出 ε 的非理性方式佯攻，安全意图集会把它排除在外，从而在「可证明安全」的外壳下静默失效；因此必须默认把未知类型并入最坏情况集，并以规则监控 + 安全不变式做独立双保险。

## 2. 关键算法（伪代码）

### IP-60 SIE：ε-理性逆博弈、e-conformal 与双意图集
```
def infer_intent_types(obs, actions, Theta, eps):
    # ε-理性过滤：只保留近似最优响应类型，排除"为骗你而故意犯傻"
    Theta_eps = [th for th in Theta if regret(th, actions) <= eps]
    # 贝叶斯逆规划 / 粒子滤波：用观测似然更新类型后验
    post = bayes_update(Theta_eps, obs, actions, prior=uniform(Theta_eps))
    return post

def econformal_safe_set(post, alpha, eproc_state, obs):
    # 每个类型维护 e-process；Ville 保证 time-uniform（不要求可交换）
    H = []
    for th in post.support():
        e = eproc_state.update(th, obs)          # 非负测试鞅
        if e < 1.0 / alpha:                      # 未被拒绝 => 保留
            H.append(th)
    return H if H else post.support()            # 空集退化为全类型（保守兜底）

def dual_intent_sets(obs, actions, alpha_safe, alpha_perf):
    post   = infer_intent_types(obs, actions, THETA, EPS)
    H_safe = econformal_safe_set(post, alpha_safe, eproc[SAFE], obs)
    H_perf = mondrian_conformal(post, alpha_perf)     # v20 定义39，仅用于得分
    assert type_tag(H_safe) == 'SAFE'                 # 类型系统隔离，防 perf 泄漏
    return H_safe, H_perf

def intent_lease(H_safe, t, lam_intent, kappa):
    return Lease(intent_set=H_safe, tau=t, lam=lam_intent, kappa=kappa)

def detect_feint(eproc_state, change_detector):
    # 佯攻 = 意图突变：e-process 近期拒绝 + 变点告警
    return eproc_state.recently_rejected() or change_detector.alarm()

def intent_fresh(lease, t, theta_intent):
    return lease.intent_set is not None and \
           (lease.m_intent - lease.lam_intent * (t - lease.tau)) >= theta_intent
```

### IP-61 CCP：规则编译、三轴证书与字典序选择
```
def compile_rules(R, delta_R):
    return [stl_monitor(phi, margin=delta_R) for phi in R]   # 最高关键级

def compile_score(S):
    return lambda traj: event_weighted_sum(S, traj)          # 事件级回报

def three_axis_certificate(pi, H_safe, rules, score_samples, delta_R, g_R, beta):
    # 安全：最坏意图下的鲁棒不变集
    K_safe  = robust_reachable_safe(pi, H_safe, C_global)
    # 合法：规则鲁棒语义 + 规则鸿沟裕度（定义49）
    K_legal = all(min_rho(m, pi, H_safe) >= delta_R + g_R for m in rules)
    # 得分：经验 Bernstein / e-process 置信下界
    K_score = lower_confidence_bound(score_samples, beta)
    return Certificate(K_safe, K_legal, K_score)

def lexicographic_select(candidates):
    ok = [c for c in candidates if c.K_safe and c.K_legal]
    if not ok:
        return safe_stop_or_concede()            # 空集绝不静默放行
    return max(ok, key=lambda c: c.K_score)      # 安全/合法之后才比得分

def score_aware_plan(pi, H_perf, H_safe, budget):
    # 约束-目标分离：H_perf 估收益，H_safe 定可行域
    return constrained_game_solve(pi, objective=H_perf, constraints=H_safe,
                                  budget=budget)

def arena_mode(intent_lease, feint_flag, t):
    if feint_flag or not intent_fresh(intent_lease, t, THETA_INTENT):
        return 'DEFEND'                          # 意图不可信 => 最坏情况防守
    return 'EXPLOIT'                             # 意图新鲜可信 => 主动得分
```

### IP-62 ARV：可执行裁判、自博弈锦标赛与佯攻投毒
```
def executable_referee(trajectory, R):
    return all(stl_robustness(phi, trajectory) >= 0 for phi in R)

def rule_gap_audit(R, R_hat, fuzz_cases):
    # 规则鸿沟 g_R：形式规则 vs 裁判实现的边界差异
    return max(abs(stl_robustness(phi, t) - ref_robustness(R_hat, phi, t))
               for phi in R for t in fuzz_cases)

def selfplay_tournament(population, rounds, referee, seed):
    ratings = init_elo(population)
    for _ in range(rounds):
        for a, b in sample_matches(population, seed):
            traj = play(a, b)
            assert referee(traj)                 # 任何犯规都视为 bug
            ratings = update_elo(ratings, a, b, score(traj))
        population = evolve(population, ratings) # 淘汰 + 变异，保种群多样性
    return population, ratings

def feint_poisoning_fuzz(intent_model):
    # 假意图 / 低置信诱导 / 策略突变 / 协同欺骗
    cases = generate_feints(intent_model)
    return [c for c in cases if not safety_holds_under(intent_model, c)]

def reproducible_match(a, b, arena, seed, ref_version):
    log = play_with_replay(a, b, arena, seed, ref_version)
    assert replay(log) == log.trajectory          # 回放确定性
    return log
```

```
def arena_transition_guard(e, x, cert, H_safe, intent_lease, rules, t):
    theta    = cert.alpha_e[e] * cert.theta_sim[e]
    m_safe   = robust_margin(cert, H_safe)
    m_lease  = cert.lease.m - cert.lease.lam * (t - cert.lease.tau)
    m_intent = intent_lease.m_intent - intent_lease.lam_intent * (t - intent_lease.tau)
    legal    = all(rho_phi(x, rules) >= delta_R + g_R for phi in rules)
    return legal and min(m_safe, m_lease, m_intent) >= theta

def schedule_arena(tasks, overload, mode):
    if overload:                                   # HI：只删不增
        tasks = [t for t in tasks if t.kappa >= K_LEGALITY]
        reserve_budget(RULE_MONITOR, B_rule)       # 规则/安全预算硬隔离

    if mode == 'DEFEND':
        tasks = [t for t in tasks if t.kappa >= K_SEMANTIC]  # 砍利用/投机
    return edf_with_rta(tasks)

def certify_light_v4(x, guards, H_safe, mode, budget_us, criticality):

    status, margin = monitor_step_INT8(quantize_obs(x))
```

## 6. 本轮最大风险

**一句话**：整套对抗覆盖的 soundness 只相对于「类型空间 Θ + ε-理性模型」成立——若真实对手的意图不在 Θ 内，或故意以超出 ε 的非理性方式佯攻，安全意图集会把它排除在外，从而在「可证明安全」的外壳下静默失效；因此必须默认把未知类型并入最坏情况集，并以规则监控 + 安全不变式做独立双保险。
