# 第 44 轮（新循环第 4 轮） · Viability-Cert × Retrieval-Cert：把「平衡控制」与「检索增强生成」接成「召回→验证→弃权」的坠落截止期闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形边际覆盖 + 多用户契约空集」，但它仍把一个更基础的对象当成了常量：**「当前状态是否还站得住」被隐含在静态边际证书 m_lo 里**。本轮灵感词「平衡控制」「检索增强生成」正好戳中这两个盲点：**平衡控制**说明安全性不是单点谓词，而是**存在一条时域策略把状态留在可行性核（viability kernel）内**；**检索增强生成**说明经验复用是边缘端把在线重算降下来的唯一现实手段，但检索优化的是相关性/概率，**不是可靠性**。二者拼接出的新问题——**检索到的平衡策略「看起来对」却不可行**——是 v20 完全没有的失效模式。本轮提出 VCR：**检索负责召回、验证负责精度、弃权负责兜底**，并以「坠落时间下界 τ_fall」作为硬决策截止期。

## 0. 直觉与动机

**灵感 1（平衡控制 → 从「边际」升级到「可行性核」）**：直觉上，一个人「离桌沿还有 5cm」和「再走一步就会摔」是两件事：前者是 margin，后者是 viability。人形机器人尤其如此——质心（COM）在支撑多边形外并不必然要摔（还能迈步/摆臂/屈膝），而 COM 在支撑内也不必然安全（可能是不可恢复的捕获点）。因此静态 m_lo 只能回答「此刻离约束多远」，回答不了「此刻还救不救得回来」。把平衡显式化为**可行性核 V_ε** 与**坠落时间下界 τ_fall**：前者是「存在策略使未来 H 步都不摔」的状态集合，后者是「最坏扰动下至少还能撑多久」的 sound 下界。一个「平衡原语」（迈步、撑地、下蹲、受控倒地）不是一段视频，而是一份**契约** P_p / π_p / Q_p：前条件成立、执行反馈策略、后状态仍落在可行性核内。这样检索到的就不是「相似片段」，而是**可被检查的证书载体**。

**灵感 2（RAG → 安全关键场景里「检索精度无关紧要，召回+验证+弃权才要紧」）**：常规 RAG 追求 top-k 命中率与答案相关性；但对平衡控制，top-1 检索错一次就是摔。这里做一个**指标反转**：只要检索返回一个**集合** S_α，且保证「真正可用的原语以 ≥1−α 概率在集合里」（集合召回），再用运行时证书**逐个验证**，那么检索的误报（precision 差）**根本不会进入执行**——它只消耗算力，不破坏 soundness。真正的安全性三件套是：**(i) 集合召回**（找得到）、**(ii) 验证器 sound**（看得穿）、**(iii) 弃权 + 兜底**（认怂有路）。这解释了为什么「RAG 幻觉」在人形上应被重新定义为「**检索诱导的过度自信**」：不是生成了错文本，而是**执行了一个未被验证的、条件不匹配的平衡原语**。配套地，知识库要存**反例记忆**（什么状态下哪个原语摔过），且只允许「已证明不可用」的原语被剪枝，避免负迁移破坏召回。

**灵感 3（耦合 → 坠落截止期把检索变成一个 anytime 控制问题）**：平衡给检索加了一个别的 RAG 没有的硬约束——**决策必须在 τ_fall 之前完成**。于是「检索多宽、验证多深、在线 WBC 跑多远」变成一个**带截止期的预算分配**问题：这既是字面意义的「平衡控制」（在「多花算力找更好原语」与「赶紧进入保命回退」之间平衡），也是 v20 并发/租约框架的自然延伸——τ_fall 就是最强的租约，过期不是重取，而是已经摔了。进一步，组成配置还要处理**分布漂移**：地面变滑、负载变化、推力超界时，原语库的支持域（support）失效，集合召回会**静默崩塌**；必须用支持证书 + 条件召回检验触发弃权，而不是指望共形的边际保证。

**与 v8 的耦合**：人格契约**不得放宽**平衡约束（平衡是硬交集，不是可协商的偏好）；检索任务属最低关键级，过载时先被 HI 模式裁掉，直接走在线回退；平衡证书以最高关键级接入租约表，λ 由最大质心速度界出；几何证书、接触调度与可行性核求交。四层架构由 v8 的「仿真-检索-边缘 + 人格 + 并发」升级为 v9 的「仿真-检索-边缘 + 人格 + 并发 + **可行性/检索认证层**」。

## 1. 形式化定义（增量：定义 44–50）

**定义 44（平衡可行性核与平衡证书）**：状态 s=(x, ẋ, C(接触集), θ_terrain, m_payload)，安全集 S_safe（不跌倒、关节/接触力/摩擦锥不越界）。**可行性核** V_ε = { s : ∃策略 π，∀t∈[0,H]，s_t∈S_safe 且 balance_margin(s_t) ≥ ε }。**平衡证书** b(s)=(ν, τ_fall, c_ok, ℓ)：ν 为可行性裕度，τ_fall 为最坏可容许扰动下的**坠落时间 sound 下界**，c_ok 为接触调度可行，ℓ 为定义 41 的租约。**sound 条件**：ν≥ε ∧ c_ok ∧ ℓ 新鲜 ⟹ s∈V_ε 且首次跌落时间 ≥ τ_fall。**工程化**：精确 V 不可算，取降阶模型（LIPM/质心捕获点）的**内近似** V̂ ⊆ V，仅在 V̂ 边界上做全身验证；soundness 依赖「内近似 + τ_fall 保守下界」而非精确性。

**定义 45（认证平衡原语与 assume-guarantee 组合）**：原语 p=(P_p, π_p, Q_p, cert_p)：P_p 为前条件集（接触态、捕获点区域、摩擦/坡度/负载范围），π_p 为反馈策略（步长/落脚/躯干/阻抗），Q_p 为后状态可行性不变式。**应用 soundness**：s∈P_p ∧ cert_p sound ⟹ 执行 π_p 后状态留在 Q_p ⊆ V_ε。**组合**：p_1;p_2 sound 当且仅当 Q_{p_1} ⊆ P_{p_2}，且接触/扳手满足 IP-47 的 rely-guarantee 契约（p_1 保证的接触不破坏 p_2 的依赖）。这把 IP-47 从「子自动机接口」扩展为「平衡原语的时域契约组合」。

**定义 46（集合召回式平衡检索）**：原语库 L，查询 q=φ(s, env)。检索器返回集合 S_α(q) ⊆ L。对每个查询定义**规范可用原语** p*(q)（在适用且可恢复的原语中按代价最小者，测试时未知）。用分裂共形校准非一致性分数 ρ(q,p)，取阈值 q̂ 为校准集 (1−α) 分位，令 S_α(q)={p : ρ(q,p) ≤ q̂}。**集合召回保证**：在可交换性假设下 P(p*(q) ∈ S_α(q)) ≥ 1−α。**关键点**：该保证只约束「集合里至少有一个真可用原语」，**不约束 top-1 precision**；误报由定义 47 的验证器过滤。

**定义 47（检索-验证-弃权 RVA 契约与安全性定理）**：流水线 RVA(s)=⟨S_α(q), Verify, Fallback⟩，
Verify(p,s) = precond(p,s) ∧ compose_ok(p,s) ∧ b(s') sound（s' 为影子预测状态）；
若存在通过者则执行最优者，否则**弃权**进入回退格 F(s)。**安全性定理**：若 (i) 集合召回成立，(ii) Verify 对 p∉适用时不会误判通过（验证器 sound），(iii) 回退格 F(s) 的所有分支 sound（至少 protective_stop 恒定义），则任意一次执行的结果状态都留在 V_ε 内，**且该结论与检索 precision 无关**。**推论（算力配置）**：把预算投在「更深的验证 + 更可靠的兜底」在安全性上不劣于投在「更高的 top-1 命中率」；检索质量只影响**可用性/代价**，不影响**安全性**。

**定义 48（坠落截止期下的 anytime 检索控制）**：总时延 T = T_ret + T_verify + T_act，安全判据 T ≤ τ_fall − δ（δ 为切换与执行余量）。把预算 (检索宽度 k, 验证深度 d, 在线 WBC 视界 h) 视为分配变量，目标 max P(在截止期前找到并验证可行原语)，约束 T ≤ τ_fall − δ。执行用**最优停止**：一旦出现已验证候选即停；当剩余时间 < T_fallback 立即切回退，不再追求更好候选。**命题**：(a) 成功概率对预算单调不降；(b) 只要切换发生在 τ_fall 之前，截止期本身不破坏 soundness——超时只损失可用性（更保守的回退），不产生不安全执行。这使「检索」从 best-effort 变成**可被截止期审计的 anytime 控制器**。

**定义 49（支持证书与条件召回失效）**：库的支持域用查询空间上的支持测度 μ_L 描述；对查询 q 计算新颖度 novelty(q)，用共形阈值 q_β 给出**支持证书** in_support(q)=[novelty(q) ≤ q_β]，满足对库内分布 P(in_support) ≥ 1−β。**命题**：定义 46 的集合召回是**边际**保证；条件召回 R_cond(q)=P(p*∈S_α | q) 可在支持域外任意低。**失效协议**：in_support(q) 失败 ⇒ 令 S_α←∅（α→1）⇒ 必弃权 ⇒ 只走回退。**定理（分布漂移不产生静默不安全）**：若弃权由支持证书触发，则漂移至多造成**可用性下降**（更多回退），不会把未经验证的原语送入执行；代价被显式记在「弃权率」上。

**定义 50（反例检索与非对称记忆）**：负记忆 N 存 (上下文, 原语, 失效证据)。检索剪枝规则：仅当「**已证明** p 在 s 的前条件下不可用」（可判定的前条件违例/证书反例）才把 p 从 S_α 删除；任何仅「相似性低」的删除禁止。**命题（剪枝保召回）**：若删除只基于 sound 的不可用证明，且 p*(q) 确实可用，则 p*(q) 不会被删，集合召回保证保持；故负记忆是**非对称**的——只能提升 precision、不能损害 soundness，也不能（在证明充分时）损害召回。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 VIABILITY-CERT（平衡可行性证书引擎 BVC）
1. **降阶可行性核**：LIPM/质心捕获点构造内近似 V̂ ⊆ V；边界样本做全身 WBC 可达性验证，输出 ν 与 τ_fall 的保守下界。
2. **平衡证书签发**：b=(ν, τ_fall, c_ok, ℓ)，与定义 41 租约共用单调时钟；ν≤0 或租约过期即判「不可用」而非「不安全」（单调降级）。
3. **接触调度证书**：把落脚点/接触序列的可行性作为独立证书，交给 IP-49 几何证书与 IP-47 组合代数求交。
4. **影子验证**：执行前对候选原语做短视界影子推演 + 边界 WBC 复核，不通过则拒绝。

### 2.2 IP-61 CERTIFIED-BALANCE-RETRIEVAL（认证平衡检索 CBR）
1. **集合召回检索**：分裂共形校准非一致性分数，返回 S_α 并携带「集合召回 ≥1−α」的校准记录；ANN 索引按 (接触态, 捕获点区域, 地形/摩擦, 负载) 分层。
2. **验证器**：前条件匹配（可判定子集）+ 组合检查 + 平衡证书复核；输出 VERIFIED / ABSTAIN，绝无「默认通过」。
3. **支持证书与漂移弃权**：novelty + 共形阈值；OOD 直接把集合置空并进入回退，记录弃权审计。
4. **非对称反例记忆**：只按「已证明不可用」剪枝；负样本同时用于训练更紧的支持阈值（提升条件召回），而非直接删候选。

### 2.3 IP-62 BALANCE-DEADLINE-ORCHESTRATOR（坠落截止期编排器 BDO）
1. **τ_fall 预算表**：由 BVC 给出每次决策的截止期；按剩余时间分配检索宽度/验证深度/WBC 视界。
2. **anytime 顺序与停止**：先廉价前条件预筛，再深度证书验证；命中即停，剩余时间 < T_fallback 立即切回退。
3. **回退格（sound）**：online WBC-MPC → 单步捕获 → 受控下蹲 → protective_stop，逐级更保守且每级有 sound 证书或恒定义兜底。
4. **并发/关键级集成**：检索任务最低关键级（HI 模式先砍）；平衡证书最高关键级，租约 λ 用最大质心速度界；人格契约与检索结果都只能与平衡约束**求交**，不能放宽。

### IP-60 BVC：可行性核、平衡证书与接触调度

def viability_certificate(s, H, eps):
    s_ro = reduce_to_centroidal(s)                 # LIPM / capture point
    nu   = viability_margin_inner(s_ro)            # V̂ ⊆ V，保守
    tau  = time_to_fall_lower_bound(s_ro, H)       # sound 下界
    c_ok = contact_schedule_feasible(s, H)         # 摩擦锥/落脚序列
    b    = BalCert(nu=nu, tau_fall=tau, c_ok=c_ok,
                   lease=acquire_lease('balance', s, 0.0, K_SAFETY))
    if not (nu >= eps and c_ok and lease_valid(b.lease, eps, now())):
        return BalCert.unknown(s)                  # 不判「不安全」，只判「不可用」
    return b

def shadow_check(p, s, horizon):
    # 短视界影子推演 + 边界全身复核；失败即拒绝，不默认通过
    s_hat = rollout_reduced(p.pi, s, horizon)
    if not inside(V_hat, s_hat): return False
    if on_boundary(s_hat) and not wbc_feasible(p.pi, s):
        return False
    return True

### IP-61 CBR：集合召回、验证、弃权与反例记忆
```
def conformal_set(q, L, alpha, persona_layer):
    # 分层校准：按接触态/捕获点区域/地形/负载分桶
    cal = calibration[persona_layer]
    qhat = quantile([rho(qi, p_star_i) for qi, p_star_i in cal], 1 - alpha)
    cand = L.ann_search(q, k=K_MAX)
    S = [p for p in cand if rho(q, p) <= qhat]
    S = prune_only_provably_inapplicable(S, q, N)   # 非对称负记忆
    if not in_support(q):                           # 支持证书失败
        return []                                   # α→1，强制弃权
    return S

def verify(p, s):
    return (precond_decidable(p, s) and
            compose_ok(p, s) and                    # Q_prev ⊆ P_p，IP-47
            shadow_check(p, s, H_SHADOW))

def retrieve_verify_act(s, q, L, alpha, tau_fall):
    t0 = now(); S = conformal_set(q, L, alpha, layer_of(q))
    for p in anytime_order(S, s):                   # 廉价前条件距离优先
        if now() - t0 > tau_fall - T_FALLBACK - DELTA:
            break                                   # 立即切回退
        if verify(p, s):
            return execute(p, s)
    return balance_fallback(s)                      # 弃权 = 有路可退，不是停机
```

### IP-62 BDO：坠落截止期预算、回退格与并发

def allocate(tau_fall, t_elapsed, load):
    remaining = tau_fall - t_elapsed - DELTA
    if remaining < T_FALLBACK:
        return Budget(k=0, d=0, wbc=T_FALLBACK)     # 直接保命
    # 在延迟约束下最大化「找到已验证可行原语」的概率（最优停止）
    return argmax_success(k, d, h, s.t. T_ret(k)+T_ver(d)+T_exec(h) <= remaining)

def balance_fallback(s):
    for f in [online_wbc_mpc, single_capture_step, controlled_crouch, protective_stop]:
        if f.guaranteed(s):                          # 每级自带 sound 证书
            return f.run(s)
    return protective_stop(s)                        # 恒定义，最后兜底

def rva_admit(p, s, I, active):
