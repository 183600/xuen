# 第 58 轮（承接第 57 轮「少样本×多模态×个性化证据承诺」IP-133~138；灵感循环第 1 轮；本轮灵感：「跨物体泛化」×「多任务学习」）

> 第 57 轮把安全的赌注从"模型置信"换成"证据质量"——元先验摊销、跨模态对账、个性化信任，使"坏证据长寿"被隔离；但它的风险自陈暴露了更深的病根：**(a)** 元先验的"语料"是按【区域】组织的，而物理机制是按【对象/材质/结构】存在的——同一块铝板在坡道、平台、台阶上是三个区域，系统却要分别从零学三遍，且新物体的第一个区域永远落在语料之外；**(b)** 元推断把所有任务混在一个摊销器里，行走的风险结构与搬运、攀爬不同，共享表示会把"对行走安全"的捷径写成"对所有任务安全"；**(c)** "跨模态一致"与"个性化授权"提高了证据效率，却没有回答一个更根本的问题——**证据凭什么可以从 A 搬到 B**。本轮两个灵感合流为一句：**泛化不是插值，是可审计的因子迁移；共享不是平均，是经干扰证书筛选的机制复用**。跨物体泛化把知识粒度从区域抬到"对象×因子"，多任务学习把共享粒度收紧到"机制核×任务头"；两者共同的护栏是**不变性证书 + 有界先验迁移 + 交互审计**。核心命题升级为 **"少样本可校准、跨模态可对账、个性化有界、跨物体可审计、跨任务可拆分的证据说可信"**。

核心矛盾：
- **H29（泛化 vs 伪不变性）**：跨物体泛化只在共享因子真不变时有益；一个在训练对象族内看似稳定、却在未覆盖交互下失效的因子，会让系统"合法地"把错误先验搬进新物体——比不迁移更危险，因为它带着证书。
- **H30（共享 vs 任务干扰）**：多任务共享提高样本效率，但把安全相关的任务差异平均掉，会得到一个"对谁都不安全"的折中；共享核越强，单任务错误传播越广。
- **H31（组合爆炸 vs 证书成本）**：因子化带来组合泛化，但每增加一阶交互，需要验证的证书数量指数增长；把所有交互都证明一遍不可能，必须把证书预算花在安全相关且高使用率的因子上。

## 0. 直觉与动机

**灵感 1（跨物体泛化 → 把"区域"升级为"对象×因子"）**
直觉：区域是"坐标"，对象是"机制"。同一物理机制（湿铝板会滑）跨越坡道、平台、台阶反复出现；按区域学是把同一个规律抄很多遍，还没法迁移到没去过的新物体。把对象 o 分解为因子向量（材质/几何/表面状态/关节柔顺/质量分布）与组合图 G_o，区域只是因子在某一坐标上的投影；于是泛化 = **在因子层迁移**，新物体 = 已见因子的新组合。关键警告：组合泛化不是插值，因子之间可能有非可加交互（湿冰×大坡度 ≫ 湿+大坡度之和），所以必须配交互审计。

**灵感 2（多任务学习 → 共享机制核，冲突即拆分）**
直觉：四个任务共用同一具身体和同一套物理，共享"机制核"能省样本；但任务的风险结构不同，强行共享安全相关参数会学出"折中步态"。设计不是"多任务一起训"，而是**按证书粒度共享**：仅当任务对在机制核上的因果效应分歧 I(t,t')≤θ_I 时共享，否则拆出任务特异头；安全相关因子永不平均，冲突时拆分并各自举证。证据也按任务记账：任务 t' 的证据只有落在同一认证任务族内，才能给任务 t 当先验，且仍不能当 t 的证据。

**灵感 3（不变性证书 → 把"泛化的责任"显式化）**
直觉：第 57 轮把判定权交给元模型，风险藏在权重里；本轮把泛化变成一张可审计的"身份证"——不变性证书 ι 明确写出：在哪些对象族、哪些上下文、验证到几阶交互、违例率多少、覆盖多宽。迁移只在证书覆盖内发生；证书之外一律退回第 57 轮的 OOD 门与共形带。这样"我不知道"第一次有了明确的地址，而不是靠元模型自信与否来猜。

**灵感 4（负迁移护栏 → 迁移只改规划先验、不改安全估计；冲突让位目标）**
直觉：最危险的不是"不迁移"，而是"错误地迁移且被当成证据"。因此规定：跨物体/跨任务迁移**只能收缩规划先验，且 KL 预算有界**；**安全估计 P_fail 一律按证书置信集内最坏机制值计算**，迁移买的是探针数与承诺时延，不买安全余量。目标物体的目标证据与迁移先验冲突时，**目标赢**，迁移被丢弃并登记负迁移事件，必要时降级因子证书。把"迁移"关进先验的笼子里，安全性就退化为"证书违例率 + 交互残差上界"，可计算。

**灵感 5（主动迁移探询 → 为家族而探，且专门去证伪）**
直觉：第 57 轮的探针是为当前区域降不确定；本轮探针还应服务**整个家族**——探一次材质因子，可能让未来十个物体受益。于是 VOI 增加"迁移价值"：预期家族后验熵下降 × 未来使用频次。更关键的是加一类**证伪探针**：目标不是降不确定，而是主动寻找能让不变性失效的干预（换湿度、换坡度、换负载），因为"没找到反例"和"没去找反例"是两回事。探询预算 k_tr，触发条件与终止性沿用 PCE+。

**灵感 6（与第 57 轮合流 → 迁移层是"证据地图"的第二维）**
直觉：第 57 轮的 𝓜 是 (区域→证据)；本轮把它扩成 (对象×因子→机制证书) 的**机制地图** 𝓜_μ，两者通过 r↦o(r)↦f(r) 对齐。证据门增加一个"先验来源"字段：来自迁移的先验必须挂 ι 且 KL≤κ；证书失效/冲突/交互越界任一发生，该先验自动退回保守基座。整个迁移层继承第 57 轮"一切判定器走隔离"——不变性证书与共享核的更新也在影子模式跑回归。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（对象因子分解 OFD）** 对象 o∈𝒪，因子集 ℱ={mat,geo,surf,art,mass}，o=(v_o,G_o)，v_o∈∏_f Dom(f)，G_o 为因子组合图。区域投影 π:𝒱→𝒪×ℱ，r↦(o(r),f(r))。因子信念 B_f 为跨对象共享的机制参数分布；对象局部信念 b_{o,f}=B_f|_{\text{supp}(o)}。迁移算子 T_f:B_f×G_{o'}↦b_{o',f}，仅在证书覆盖内定义。机制地图 𝓜_μ 记录 (o,f,ι) 三元组。

**定义 140（机制不变性证书 MIC）** 对因子 f、对象族 𝔽、任务 t、上下文集 C，机制函数 μ_{f,t}(c;o)=E[Y|do(f=v),c,o]（Y 为滑移/承载/稳定等安全相关结果）。不变性：sup_{o,o'∈𝔽,c∈C}|μ_{f,t}(c;o)−μ_{f,t}(c;o')|≤ε_inv。证书 ι_{f,t}=(𝔽,C,ε_inv,α_cov,d_int,n_test,V)，V 为违例事件表，覆盖率 ≥1−α_cov。目标 o' 可用迁移当且仅当 c(o')∈C ∧ 交互阶≤d_int ∧ o'∈𝔽 闭包；证书外禁止迁移（退回定义 133 的 OOD/共形带）。

**定义 141（多任务机制共享 TSC）** 风险/策略分解 π=h_t∘Φ，Φ 共享机制核，h_t 任务头。任务对干扰 I(t,t')=sup_{c∈C_safe}TV(P(Y|do(Φ),t,c),P(Y|do(Φ),t',c))，并辅以安全相关因子的梯度冲突余弦。认证共享族 T_cert={(t,t'):I(t,t')≤θ_I}。冲突处理：拆分（任务特异覆盖）而非平均；∀f∈ℱ_safe 禁止跨任务平均。证据任务记账：EV(t') 仅在 (t,t')∈T_cert 时可作 t 的先验，永不自动成为 t 的证据。

**定义 142（组合泛化与交互审计 CGA）** 新对象 o\*=⊕_{i≤k}(f_i,v_i) 为已见因子组合。交互残差 R_int(o\*)=|μ(o\*)−⊕_i μ(f_i)|，⊕ 为可加/对数可加基线。交互审计到阶 d_int：已覆盖交互集 ℐ_{d_int}(𝔽)；未覆盖交互按最坏情形加宽 w_int；若未覆盖交互落在 ℱ_safe 且 R_int 的置信上界 >θ_int ⇒ 拒绝组合、退回 OOD。组合证书 τ_{o\*}=(因子来源,ℐ_{d_int},R_int 上界,w_int)。

**定义 143（迁移证据门 TEG 与负迁移护栏）** 第 57 轮证据类扩展一个**弱类 EV-transfer**：仅 L1、需 ι 覆盖 ∧ 无冲突 ∧ 至少 1 条目标特异佐证；不可进入不可逆接触必要证据集。迁移先验 b^T 须满足 KL(b^T‖b_fallback)≤κ；b_fallback 为第 57 轮保守基座（OOD 共形带或手工先验）。**安全估计规则**：承诺判定用的 P_fail 一律以 ι 置信集内最坏机制值计算，b^T 只进入规划/VOI/步态选择。冲突规则：若目标特异似然比 L_target 与 b^T 的对抗超出 θ_conf ⇒ 丢弃 b^T、登记负迁移、按证据强度决定是否降级 ι。不可逆接触必要证据集保持第 57 轮不变（EV-probe\*/visit/margin + 佐证），EV-transfer 与 EV-xmodal 均禁用。

**定义 144（任务-因子主动迁移探询 ATC / PCE++）** 迁移 VOI：VOI_trans(f,t,π)=Ê[ΔH(B_f|π)]·Ê[N_future(f,t)]−cost(π)，N_future 为预计受益区域/对象/任务数。证伪探针 π_falsify=argmax_π P̂(detect violation|π)，仅在 ι 的边界上下文上执行。每检查点：①第 57 轮元推断；②因子迁移与组合审计；③任务共享检查；④若 R>δ_f(g) 或证书不覆盖 ⇒ 证伪探针（预算 k_tr）或退回第 57 轮 PCE+；⑤承诺需过第 57 轮证据门 + TEG。总预算 k_p+k_c+k_tr，终止于 {承诺,绕行,L2 协商,安全停}。

## 2. 关键算法伪代码（完整版见产物区）

```python
def transfer_prior(B, r, o_star, task, certs, kappa):
    prior = fallback_belief(r, task)                 # 第 57 轮保守基座
    if not cert_covers(certs, o_star, task):         # 证书外：禁止迁移
        return prior, {'transfer': False, 'reason': 'no_cert'}
    bT = factor_transfer(B, o_star, task)            # 因子层迁移
    if kl(bT, prior) > kappa:                        # 有界 KL
        return prior, {'transfer': False, 'reason': 'kl_budget'}
    return bT, {'transfer': True, 'cert': certs[(o_star, task)]}

def composition_guard(o_star, mu, audit, theta_int):
    R = interaction_residual(o_star, mu)
    if uncovered_safe_interaction(o_star, audit) and R.ub > theta_int:
        return 'refuse', widen(mu, R)                # 拒绝组合，退回 OOD
    return 'ok', widen(mu, R)                        # 覆盖内也保留交互加宽

def safety_eval(mu, cert, r, task):                  # 迁移不改安全估计
    return worst_case(mu, cert_confidence_set(cert, r, task))
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| OFD | O(\|ℱ\|·d_f)/对象 | O(\|𝒪\|·\|ℱ\|·d_f) | 因子分解与投影一致、证书覆盖可判 |
| MIC | 离线 O(N_fam·\|C\|·d_int)；查询 O(1) | O(\|𝔽\|·\|ℱ\|·\|T\|) | ε_inv/α_cov 声明诚实、证书外禁迁移 |
| TSC | O(\|T\|²·d_Φ)/更新 | O(\|T\|·d_Φ) | 干扰检测诚实、安全因子不平均（A43） |
| CGA | 最坏 O(2^{d_int})，d_int≤3 | O(\|ℐ_{d_int}\|) | 未覆盖交互按最坏值、越界即拒 |
| TEG | O(\|σ\|) | O(\|σ\|) | 迁移仅改先验、P_fail 用最坏值（A44） |
| PCE++ | O(\|CP\|·(k_p+k_c+k_tr)·(C_VOI+d_φ+N_future)) | O(\|𝒱\|+\|σ\|+\|𝓜_μ\|) | 迁移 VOI 悲观、三预算终止 |

**正确性定理（Transfer-Audited Soundness, TAS 概要）**：在 A33–A40 上加 (A41) 证书诚实（覆盖 ≥1−α_cov、违例率 ≤ε_inv、证书外禁迁移）；(A42) 交互审计到 d_int，未覆盖交互按最坏值处理；(A43) 干扰检测诚实且安全因子不平均；(A44) 迁移先验 KL≤κ、冲突时目标证据优先、P_fail 用证书置信集内最坏值。则：(i) 迁移路径承诺失效率 ≤ 第 57 轮上界 + ε_inv + R_int^{ub} + δ_xm·1[L1]，且 EV-transfer 仅 L1；(ii) **无伤害性**：b^T 只进入规划/VOI，P_fail 恒用最坏机制值，故相对第 57 轮的失效率不增；越界、冲突、证书失效任一发生即退保守基座；(iii) 任务共享仅在 T_cert 内，冲突拆分不增加单任务风险；(iv) PCE++ 在 k_p+k_c+k_tr 内终止于 {承诺,绕行,L2 协商,安全停}。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 伪不变性（证书内看似稳定、边界外失效） | 高 | 证伪探针 + 边界上下文覆盖审计 + 证书外禁迁移 + 违例即降级 |
| 交互盲区（未覆盖高阶交互） | 高 | 交互审计到 d_int、未覆盖按最坏值、安全相关越界即拒绝组合 |
| 共享核把单任务错误broadcast | 中高 | 干扰证书 + 冲突拆分 + 安全因子永不平均 + 影子模式回归 |

| 证书成本/组合爆炸 | 中 | 证书预算按安全相关性×使用率分配；d_int≤3；复用族证书 |

## 6. 本轮最大风险

**一句话**：本轮把泛化押在"不变性证书"上，风险从"坏先验普遍"变为"伪不变性"——一个在训练族内看似稳定、却在未覆盖交互或任务组合下失效的因子，会被证书合法地搬进新物体新任务，且共享核让它传播得更快；必须以交互审计、迁移只改规划先验不改安全估计、不可逆接触禁用迁移证据、任务冲突即拆分四重护栏兜底，宁可退回第 57 轮又宽又慢的非参区间，也不让"族内经验"冒充"跨族规律"。

### IP-140 MIC（机制不变性证书）

```python
def certify_invariance(f, family, task, C, d_int, n_test):
    samples = [probe(f, o, c, task) for o in family for c in C]  # 干预，不碰不可逆接触
    mu = {o: fit_mechanism(samples, o, f, task) for o in family}
    eps_inv = max(abs(mu[o](c) - mu[o2](c))
                  for o in family for o2 in family for c in C)
    V = [event for event in violation_events(samples) if event.significant]
    return Cert(f=f, family=family, C=C, eps_inv=eps_inv,
                alpha_cov=coverage_bound(samples), d_int=d_int,
                n_test=n_test, V=V)

def cert_covers(certs, o_star, task):
    c = certs.get((o_star.factor_key, task));  if c is None: return False
    return (o_star.context in c.C and
            o_star.interaction_order <= c.d_int and
            o_star.family in c.family and
            not c.has_unresolved_violation())              # 证书外一律 False

def certify_update(cert, verdict_event):
    if verdict_event.falsifies(cert):                      # 事后证伪：降级+回溯
        cert.eps_inv = min(1.0, cert.eps_inv * gamma_inv)
        cert.V.append(verdict_event); cert.demote()
    elif verdict_event.confirms(cert):
        cert.coverage = min(1.0, cert.coverage + gamma_cov)
    return cert
```

def composition_audit(o_star, mu_factors, audit, theta_int):
    baseline = additive_or_logadditive(mu_factors)
    R = interaction_residual(o_star, mu_factors, baseline)  # 点估计 + 置信上界

def transfer_prior(B, r, o_star, task, certs, kappa):
    prior = fallback_belief(r, task)                        # 第 57 轮保守基座
    if not cert_covers(certs, o_star, task):
        return prior, {'transfer': False, 'reason': 'no_cert'}
    bT = factor_transfer(B, o_star, task)
    if kl(bT, prior) > kappa:                               # 有界 KL：迁移只收缩先验
        return prior, {'transfer': False, 'reason': 'kl_budget'}
    return bT, {'transfer': True, 'cert': certs[(o_star.factor_key, task)]}

def safety_eval_with_transfer(mu, cert, r, task, bT):
    # 关键：迁移不进入安全估计，安全估计取证书置信集内最坏机制值
    return worst_case(mu, cert_confidence_set(cert, r, task))

def transfer_evidence_gate(c, certs, persona):
    if c.ev != 'EV-transfer': return round57_gate(c)        # 其余证据类沿用第 57 轮
    if c.level != 'L1': return ('reject', 'transfer_on_L2')
    if not cert_covers(certs, c.o_star, c.task):
        return ('reject', 'no_cert')
    if not conflict_ok(c.target_likelihood, c.bT, THETA_CONF):
        register_negative_transfer(c); return ('reject', 'target_wins')
    if c.target_corroboration < 1:
        return ('reject', 'no_target_support')
    return ('ok', 'EV-transfer')                            # 仍不得用于不可逆接触

def irreversible_evidence_set_ok(sched):
    # 不可逆接触：EV-transfer / EV-xmodal 一律不得入必要证据集

### IP-144 ATC / PCE++（主动迁移探询）

def transfer_voi(f, task, M, B, usage_model):
    dH = expected_entropy_drop(B[f], M)
    Nf = usage_model.expected_future(f, task)               # 未来受益区域/对象/任务数
    return dH * Nf - probe_cost(f)

def falsification_probe(f, cert, M):
    boundary = cert.boundary_contexts()                     # 证书边界，不是舒适区
    return argmax(probe_set(boundary),
                  key=lambda p: detect_violation_prob(p, f, cert, M))

def pce_plus_plus(x0, M, task, budget, certs, persona):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        inf = meta_few_shot_infer(M, cp.region, M.obs[cp.region], meta)   # IP-133
        o, f = project_region(cp.region, M.objects)
        bT, tinfo = transfer_prior(meta.B, cp.region, o, task, certs, KAPPA)
        M.b[cp.region], j_t = compose_with_audit(meta.B, o, task, M.audit)
        if tinfo['transfer']:
            M.prior[cp.region] = bT                          # 只进规划/VOI
        sigma = foothold_schedule(x0, cp, M); R = schedule_risk(sigma, M,
                                                                prior=M.prior)
        while (select_gait(R) == 'halt' or not cert_covers(certs, o, task)) \
              and budget.probes_left() > 0:
            if not cert_covers(certs, o, task) and budget.tr > 0:
                p = falsification_probe(f, certs[(o.factor_key, task)], M)
            else:
                p = argmax(admissible_probes(cp, M, F_abs),
                           key=lambda q: transfer_voi(f, task, M, meta.B, usage)
                                         + voi_meta_pessimistic(q, M, inf) - cost(q))
                if transfer_voi(f, task, M, meta.B, usage) < THETA_VOI: break
            M, _, D = xmodal_fuse(M, cp.region, execute_probe(p, cap=F_abs))  # IP-134
            if budget.tr > 0 and not cert_covers(certs, o, task): budget.spend_tr(p)
            else: budget.spend(p)
            sigma = reselect_footholds(x0, cp, M); R = schedule_risk(sigma, M,
                                                                    prior=M.prior)
        g = select_gait(R); lv = contact_level(cp)
        ev = tag_evidence_p_plus(M, cp, lv, tinfo, j_t)      # 打上迁移来源与证书
        if g != 'halt' and few_shot_evidence_gate_plus(
                core_contact(cp), M, persona, certs, ood_reg)[0] == 'ok' \
           and irreversible_evidence_set_ok([core_contact(cp)]):
            sched.append(commit(sigma, g)); log.append(ev); continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M, prior=M.prior)) != 'halt':
            route = alt; continue
        return negotiate_or_stop(cp, M, sigma, R, consent,
                                 tau_int=tau_int(persona.active.auth))
    return sched, log, M

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| OFD | O(\|ℱ\|·d_f)/对象 | O(\|𝒪\|·\|ℱ\|·d_f) | 因子分解与投影一致、证书覆盖可判 |
| MIC | 离线 O(N_fam·\|C\|·d_int)；查询 O(1) | O(\|𝔽\|·\|ℱ\|·\|T\|) | ε_inv/α_cov 声明诚实、证书外禁迁移（A41） |
| TSC | O(\|T\|²·d_Φ)/更新 | O(\|T\|·d_Φ) | 干扰检测诚实、安全因子不平均（A43） |
| CGA | 最坏 O(2^{d_int})，d_int≤3 | O(\|ℐ_{d_int}\|) | 未覆盖交互按最坏值、越界即拒（A42） |
| TEG | O(\|σ\|) | O(\|σ\|) | 迁移仅改规划、P_fail 用最坏值（A44） |
| PCE++ | O(\|CP\|·(k_p+k_c+k_tr)·(C_VOI+d_φ+N_future)) | O(\|𝒱\|+\|σ\|+\|𝓜_μ\|) | 迁移 VOI 悲观、三预算终止、四态完备 |

**正确性定理（Transfer-Audited Soundness, TAS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 机制不变性证书诚实：覆盖 ≥1−α_cov、违例率 ≤ε_inv、证书外一律不迁移；**(A42)** 交互审计到阶 d_int，未覆盖交互按最坏值处理，安全相关越界即拒绝组合；**(A43)** 任务干扰检测诚实，安全相关因子永不跨任务平均，冲突时拆分；**(A44)** 迁移先验 KL≤κ、冲突时目标证据优先、承诺判定的 P_fail 恒取证书置信集内最坏机制值。则：

1. **迁移承诺健全性**：迁移路径 P(fail) ≤ δ_f + ε_meta(k) + δ_probe + ε_h + ε_inv + R_int^{ub} + δ_xm·1[L1]；EV-transfer 仅 L1，且不进入不可逆接触必要证据集。
2. **无伤害性（相对第 57 轮）**：b^T 只进入规划/VOI/步态选择；P_fail 恒用证书置信集内最坏机制值。因此迁移无法降低安全估计，只能在证书覆盖内降低期望探针数与承诺时延；越界、冲突、证书失效任一发生即退回保守基座，失效率不增。
3. **共享局部性**：共享核仅在 T_cert 内更新，冲突拆分保证单任务风险不被其他任务拉高；EV(t') 仅作 t 的先验、不作 t 的证据。
4. **终止性**：每检查点证伪探针 ≤k_tr、共识探针 ≤k_cons、常规探针 ≤k_p，PCE++ 在 k_p+k_c+k_tr 内终止于 {承诺,绕行,L2 协商,安全停}。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + ε_inv·1[transfer]
                  + R_int^ub + δ_xm·1[L1] + δ_ood·α_conf)
             − P(𝓜 或 𝓜_μ 陈旧未检出) − P(护盾回退失败)
             − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

关键：**迁移给效率、证书最坏值给保底**（与第 57 轮"元先验给效率、共形给保底"对偶）；**EV-transfer 用"仅 L1 + 目标佐证 + 冲突目标赢"把伪不变性的失败隔离在非不可逆层**；**多任务共享用"干扰证书 + 冲突即拆分"把负迁移关进局部**；三个机制全部经"规划更省或动作更保守"两个安全通道起作用。

## 6. 本轮最大风险

**一句话**：本轮把泛化押在"不变性证书"上，风险从"坏先验普遍"变为"伪不变性"——一个在训练族内看似稳定、却在未覆盖交互或任务组合下失效的因子，会被证书合法地搬进新物体新任务，且共享核让它传播得更快；必须以交互审计、迁移只改规划先验不改安全估计、不可逆接触禁用迁移证据、任务冲突即拆分四重护栏兜底，宁可退回第 57 轮又宽又慢的非参区间，也不让"族内经验"冒充"跨族规律"。
