# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「长程任务」×「轻量化设计」）

> R69 教会闭环「提问」，但它是**近视的**：每一步都按当前 U_epi 花同样的计算、按同样的交互预算去问，仿佛任务的第 1 步与第 10^6 步没有区别。长程任务把这种均匀主义击穿——真正决定成败的往往只是少数**承诺点**（跨过门槛、松手、并线、给出不可撤回的答复），绝大多数步骤是「可回退的滑行」；轻量化设计又禁止我们为每一步都支付 R69 的 2.6ms 与 O(H) 记忆。
>
> 本轮把两个灵感当成一对**张力**，而不是两个并列功能：**长程任务要求「在关键处多算、在关键处多记」；轻量化要求「平均少算、常驻少记」。** 解法不是折中，而是把计算与记忆**在时间上非均匀化**：用可逆性与未来杠杆检测承诺点，在承诺点升到 R69 全量；在非承诺点用可认证的轻量学生，并把省下的算力记入一本**风险账本**，用随时有效（anytime-valid）监控担保「省算不省风险」。再加**证书化选项**把长程压缩成短程、把 O(H) 历史压缩成 O(1) 的安全充分统计量。
>
> 核心命题：**TELOS-RAS = FLUID-RAS + 承诺点调度 + 长程风险账本 + 证书化时间抽象；它在承诺点不退让，在非承诺点可摊销，并以 R68 ⊂ R69 ⊂ TELOS 的严格回退链保证安全侧永不裸奔。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**在漫长任务里，什么时候值得认真，什么时候可以轻轻走过**」。

## 0. 直觉与动机

**灵感 1（长程任务 → 难度不是均匀的，而是集中在承诺点）**
直觉：长程任务不是把短任务重复 H 次。真正决定最终结果的是少数**不可逆或高杠杆**的时刻：推门进入、抓取松手、并线、提交答案、签下名字。之前每一步都可回退，错了还能改；承诺点之后，错误被锁定，并沿时间长尾放大。人也是这样：长途驾驶大部分时间在巡航，真正紧张的是并线、匝道、湿滑路面。工程含义是：不必每一步都做 R69 的完整不确定性分解；把重算集中在承诺点，才是长程任务的自然计算结构。

严谨方向：用「可达安全集的收缩」定义可逆性，用「模态后果差」定义未来杠杆，承诺分是二者的加权；承诺点是 C ≥ τ_C 的时刻。假设 A99 要求承诺点稀疏，且非承诺点的错误可在 T_rec 步内被恢复，因此不会锁死。

**灵感 2（轻量化 → 不是把模型变小，而是把「省算」变成可审计的债务）**
直觉：轻量化最危险的做法是「偷偷少算」：模型小一点、采样少一点、跳过验证。短期看不出，长期在尾部爆。正确的轻量化是**摊销**：在非承诺点走便宜路径，把便宜路径相对全量路径的「未验证风险」当作一笔附加费记到账本上；等到锚点验证（标定、选项完成、人工确认）确认这段路安全，再把附加费退还。这样省算不是免费的，而是有账可查、有借有还。计算梯级（学生 → K=1 → K=4 → 交互）让系统可以在任意时刻选择「够用就好」的精度。

严谨方向：风险账本 R_t；每步扣 r̂+s，锚点退款；任何不可逆动作之前必须 R_t ≥ 0。证书里同时记录账本余额与锚点密度，使「省算」本身成为可审计对象。

**灵感 3（长程任务改变的是统计对象：从每步保证到时间一致保证）**
直觉：短任务可以说「每步误报率 1%」，跑 100 步大约出一次；长任务跑到 10^6 步，任何固定的每步错误率都会被乘法放大，而且你往往不知道任务何时结束，无法预先设定 H 去做 union bound。所以长程安全必须是**随时有效**的：无论跑到第几步，告警的假阳性都不超过 α。e-process / 置信序列正是为此而生，更新只需 O(1) 状态，天然轻量。长程任务与轻量化在这里不是矛盾，而是同一个要求：**用不随 H 增长的统计量，守不随 H 衰减的保证**。

严谨方向：E_t 为非负上鞅，Ville 不等式给出 P(sup_t E_t ≥ 1/α) ≤ α；双时间尺度标定 = 每步 O(1) 快监控 + 只在低杠杆窗口做全量慢重标定。

**灵感 4（时间抽象 → 长程与轻量化的共同解）**
直觉：人处理长程不靠「把 10^6 步都想一遍」，而靠把熟悉片段打包成技能：开门、取物、归位。每个技能有前置条件、效果、终止条件与风险上界；规划器只在技能层组合，只有前置/后置不匹配时才回到原子层。这样有效规划长度从 H 降到 H/L，计算与记忆都降一个量级。关键是技能必须**带证书**，否则组合出的长程计划只是把幻觉放大。证书化选项把「复用」从工程技巧变成可验证的安全论证。

严谨方向：选项 ω=(pre, π, post, T, r, id)，组合风险次可加，前置/后置匹配误差 ε_m；规划器在选项层运行，只有承诺点才展开到原子层。

**灵感 5（旧风险在新尺度下变形，必须换威胁模型）**
直觉：R69 的最大风险是「模态分布不可信 → 追问幻影」。到长程尺度，它变成更隐蔽的版本：**承诺点漏检**（在最该认真处省算）、**预算饥饿攻击**（逼系统长期走便宜路径，再在尾部利用）、**交互疲劳**（人开始敷衍，回答退化为噪声）、**选项证书伪造**（把不安全的技能拼进长计划）、**记忆投毒**（压缩后只留下错误的安全摘要）。R69 的投毒集只覆盖单步交互；长程需要新的对抗集，并且回退链必须能在任一组件失效时逐级降级，而不是整链崩溃。

严谨方向：ℰ_LONG = ℰ_FLUID × ℰ_starve × ℰ_spoof × ℰ_fatigue × ℰ_forge × ℰ_mem；TELOS → R69 → R68 三级回退。

## 1. 形式化定义（增量：定义 310–323）

**定义 310（TELOS-RAS 总览）** TELOS-RAS = (CPD, RLD, BAF, CFD, OCI, MCM, TSC, IBB, CCA, RAS-WM†)。三不变式：
(i) **摊销轻量**：存在硬上限 B_max 与窗口均值 B_avg，任意长度 W 的窗口内计算量 ≤ B_avg·W + B_burst，且任意单步 ≤ B_max；轻量不是「平均小」，而是「有界突发」。
(ii) **账本不透支**：每步维护风险余额 R_t；cheap-path 必须支付附加费 s_t；锚点验证可退款；R_t < 0 时禁止任何不可逆动作。
(iii) **承诺点优先**：C(x,a) ≥ τ_C 的步骤必须至少走到计算梯级 ℓ2，并携带承诺证书；否则整步作废，退回 R69/R68。

**定义 311（可逆性、杠杆与承诺点 CPD）** 对状态 x、动作 a、安全集 S：
ρ(x,a) = sup_π P(∃τ ≤ T_rec : f_π(x,a) ∈ S)（可恢复概率）；
L(x,a) = sup_{m,m'∈M} E[ℓ(ξ_m, ξ_{m'})]（模态后果差，即未来杠杆）；
C(x,a) = σ(α(1−ρ) + βL + γI_obs)（I_obs 为观测不可逆性，如丢失关键视角后再也看不到）。
C ≥ τ_C 即为承诺点。A99：承诺点密度 δ_C 小，且非承诺点存在 T_rec-恢复策略，错误不锁死。

**定义 312（计算梯级 BAF）** ℓ0：CFD 学生单步；ℓ1：FMP K=1；ℓ2：FMP K=4 + AUD + FMA；ℓ3：ℓ2 + MINT 交互 + OCI 选项重规划。每级有认证成本 b_ℓ 与单步风险上界 ε_ℓ，满足 b0 < b1 < b2 < b3、ε0 ≥ ε1 ≥ ε2 ≥ ε3。任意级返回的 (a, U_ale, U_epi, 证书) 均合法，故计算可在任意级停止——这是「anytime」的工程含义，不是把 ODE 截断。

**定义 313（承诺点感知调度 CAS）** 给定账本余额 R_t、预计剩余承诺点数 N_C(t) 与储备 R_res，每步风险目标
δ_t = (R_t − R_res) / max(1, N_C(t))。
调度规则：
ℓ* = min { ℓ : ε_ℓ(x) + λ_ledger·s_ℓ ≤ δ_t }，其中 s_ℓ = ε_ℓ − ε3 为未验证附加费；
若集合为空取 ℓ3；若 ℓ3 仍不可行，则不执行不可逆动作，进入保守悬停/求助。
A100（调度单调性）：ε_ℓ 随 ℓ 递减、b_ℓ 随 ℓ 递增，故最优策略是 C 与 U_epi 的阈值策略。注意风险预算按**剩余承诺点数**而非剩余步数分配——这是与 R69 逐步骤紧最重要的差别。

**定义 314（长程风险账本 RLD）** R_0 = R_budget；每步更新
R_{t+1} = clip(R_t − r̂_t − s_{ℓ_t} + a_t, 0, R_max)，
其中 r̂_t 为当前步的认证风险上界，s_{ℓ_t} = ε_{ℓ_t} − ε3 为未验证附加费，a_t 为锚点退款（仅当锚点验证了对应历史块，且 a_t ≤ A_max）。不变式：任何不可逆动作执行前 R_t ≥ r̂_t + s_{ℓ_t}；否则降到 ℓ3 或停止。R 是「风险偿付能力」，不是对真实风险的估计。

**定义 315（随时有效监控 TSC-fast）** 对安全假设 H0（无慢漂移/无故障），构造非负上鞅 E_t，满足 E_0=1 且 E[E_t | F_{t−1}] ≤ E_{t−1}。当 E_t ≥ 1/α 时告警。由 Ville 不等式，P(∃t ≥ 0 : E_t ≥ 1/α) ≤ α 对任意 H 成立。E_t 只保留 O(1) 状态；需要漂移方向时，用 e-process 反演得到随时有效置信序列。这是长程「horizon-invariant」保证的统计骨架。

**定义 316（双时间尺度标定 TSC）** 快层每步 O(1) 更新 E_t 与残差统计；慢层全量 COF 重标定只在 C(x) ≤ τ_safe 的低杠杆窗口，或 E_t 告警时触发。调度目标：
max I(θ; y | window) / downtime，s.t. 账本不透支、重标定期间不执行不可逆动作。
这样既避免在承诺点做重标定，也避免标定频率随 H 线性增长。

**定义 317（共形蒸馏与选择性升级 CFD）** 教师 π_T = FMP K=4（含 AUD/FMA）；学生 π_S 为单步流或回归蒸馏，输出 (a, U_ale^S, U_epi^S, conf)。定义非共形分 s(x,ξ) = disagreement(π_S, π_T)（离线校准集）。按承诺分 C 分层做分组共形（Mondrian conformal），阈值 τ_α(C) 满足在每层内 P(s ≤ τ_α(C)) ≥ 1 − α_sel。在线仅当 s ≤ τ_α(C) 且 C < τ_C 时允许走 ℓ0；否则升级。漂移下用 ACI/e-conformal 更新阈值，并把选择错误指示量再喂入一个 e-process，得到任意时刻的选择错误控制 ≤ α_sel（仅用 ACI 时只保证长期平均 ≤ α_sel + o(1)）。**学生只负责「知道自己不知道」，不负责给最终安全结论**——这是对 R69「模态幻觉」的直接约束。

**定义 318（证书化选项 OCI）** 选项 ω = (pre_ω, π_ω, post_ω, T_ω, r_ω, id_ω)。当 post_ω1 ⊨ pre_ω2 时定义组合 ω1⊗ω2，且
r(ω1⊗ω2) ≤ r_ω1 + r_ω2 + ε_m，T(ω1⊗ω2) ≤ T_ω1 + T_ω2。
若组合后 post 不成立或超时，触发锚点与重规划。规划器在选项层运行，只有承诺点才展开到 ℓ2/ℓ3；这使有效规划长度从 H 降到 H/L，同时把复用变成可验证的安全论证。

**定义 319（安全充分记忆 MCM）** m_t = Compress(h_{0:t})，|m_t| ≤ M。对安全查询类 Q_safe，要求
sup_{q∈Q_safe} |P(q | m_t) − P(q | h_{0:t})| ≤ ε_mem。
压缩保留：E_t 状态、账本余额与锚点、选项进度、最近残差/模态摘要、审计 sketch；丢弃可重建的低层细节。目标 min I(h;m) s.t. ε_mem ≤ ε。这把 R69 的 O(H) 审计历史变成 O(1) 常驻记忆。

**定义 320（交互预算银行 IBB）** 长程交互预算 N_int(H) = κH（另加每窗口速率上限）。允许存取与批量。D_t 为交互债：把当前问题推迟到未来所增加的期望代价。当期问询当且仅当
VoI_H(g) − c(g) ≥ E_t[VoI_H(g')] − E_t[c(g')] + ι·D_t，
否则存入银行，在低承诺、可合并的窗口批量执行。这里
VoI_H(g) = [H(M|o) − E_{y∼p(·|g,o)}H(M|o,y)] + η·E[Δ 未来承诺点风险 | g]
是**长程 VoI**：不仅奖励「现在更确定」，更奖励「避免未来一次不可逆选错」。A102：VoI_H 子模 ⇒ 阈值贪心有 (1−1/e) 近似。R69 的 MINT 是 η=0、无银行的近视特例。

**定义 321（链式证书 CCA 与 J_TELOS）** 每步 d_t = H(J_FLUID_t ‖ d_{t−1})；每个选项完成/锚点记录 Merkle 根。长程证书
J_TELOS = (d_T, R_T, anchor_density, b_avg, b_max, p_eproc, option_root, ε_mem, telos_ver)。
Valid ⇔ 所有锚点处 J_FLUID 有效 ∧ 账本从未透支 ∧ 摊销预算未越界 ∧ 证据纪律满足 ∧ e-process 未告警（或告警已被锚点处理）。常驻存储 O(1)，验证 O(log H)。

**定义 322（长程对抗集 AIC-LONG）** ℰ_LONG = ℰ_FLUID × ℰ_starve × ℰ_spoof × ℰ_fatigue × ℰ_forge × ℰ_mem：
- ℰ_starve：诱导系统长期走便宜路径或耗尽重算预算，再在尾部制造承诺点；
- ℰ_spoof：把不可逆步骤伪装成可逆（扰动状态使 C 低报）；
- ℰ_fatigue：高频低价值交互让人敷衍，使回答退化为噪声；
- ℰ_forge：伪造选项 pre/post/风险证书，诱导组合出越界计划；
- ℰ_mem：投毒历史，使压缩摘要保留错误的安全证据。
并入 AIC：ℰ_TELOS = ℰ_FLUID × ℰ_LONG。

**定义 323（三级回退与包含关系）** TELOS → R69 → R68：
- 若 CPD 不可信/账本为负/预算不可行 ⇒ 本步强制 ℓ3；若仍不可行则悬停并求助（R69 的保守交互/停止）；
- 若 CFD 未校准/ECE 越界 ⇒ 禁用 ℓ0，退 R69 每步 K=1；
- 若交互预算耗尽或证据纪律不满足 ⇒ 禁用 MINT，退 R68 纯 λ_floor 保守。
行为层面：R68 = R69 关闭 MINT 且 K=1；R69 = TELOS 取 δ_C=1 且禁用 ℓ0；故 **R68 ⊂ R69 ⊂ TELOS**。

## 2. 关键算法骨架

```python
# IP-264 CPD：承诺点/可逆性检测（廉价，O(1)）
def commitment_score(z, o, option_progress):
    rho = recoverability_estimate(z, o)          # 可达安全集收缩
    L   = modal_leverage(z, o)                   # 模态后果差
    return sigmoid(A*(1-rho) + B*L + G*obs_irreversibility(o))

# IP-266/313 CAS：按剩余承诺点数分配风险预算
def schedule(C, U_epi, ledger, n_commit_remaining):
    delta_t = (ledger.R - ledger.R_res) / max(1, n_commit_remaining)
    for ell, (b, eps) in enumerate(LADDER):       # ell = 0..3
        surcharge = eps - LADDER[3].eps
        if C >= TAU_C and ell < 2: continue        # 承诺点禁止走学生
        if ledger.can_afford(eps + surcharge) and eps + ledger.lam*surcharge <= delta_t:
            return ell
    return None                                   # 触发悬停/求助

# IP-265 RLD + IP-270 TSC-fast：账本与随时有效监控
def ledger_step(ledger, eproc, x, ell, anchor=False):
    r_hat = LADDER[ell].eps
    s     = LADDER[ell].eps - LADDER[3].eps
    refund = ledger.anchor_refund() if anchor else 0.0
    ledger.R = clip(ledger.R - r_hat - s + refund, 0.0, ledger.Rmax)
    eproc.update(x)                               # O(1) 状态
    return ledger.R >= 0.0 and not eproc.alarm()

# IP-267 CFD：学生可弃权，承诺点不得由学生单独定案
def accept_student(student, teacher, x, C, alpha_sel):
    xi, uale, uepi, conf = student(x)
    score = disagreement(xi, teacher.prototype(x))
    if C >= TAU_C:
        return None                               # 强制升级
    if score <= conformal_threshold(alpha_sel) and conf >= TAU_CONF:
        return xi, uale, uepi
    return None                                   # 升级到 K=1 / K=4

# IP-275 TELOS 主闭环（R69 闭环 + 调度 + 账本 + 选项 + 回退）
def TELOS_round(M, obs, t, option):
    z, o = M.mtm.forward(obs)
    M.eproc.update(M.residual(o))
    alarm = M.eproc.alarm()
    C = M.cpd.score(z, o, option.progress)
    ell = M.cas.schedule(C, M.aud.cheap_uepi(z), M.ledger, option.n_commit_remaining)

    xi = None
    if ell == 0:
        out = M.cfd.accept_student(M.student, M.fmp, o, C, M.alpha_sel)
        if out is None:
            ell = 2 if C >= TAU_C else 1
        else:
            xi, U_ale, U_epi = out
    if ell is None or not M.ledger.can_afford(LADDER[ell]):
        return M.fallback_hover_or_ask(o)          # R69/R68 回退

    if ell >= 1:
        samples = M.fmp.sample(o, 4 if ell >= 2 else 1)
        U_ale, U_epi, modes = M.aud.decompose(samples, z)

    # 慢重标定只在低杠杆窗口或告警时进行
    if (alarm or M.tsc.due(t)) and C <= TAU_SAFE:
        M.tsc.slow_recalibrate(o)

    # 承诺点/高 U_epi 才动用交互银行
    if ell >= 3 and U_epi > TAU_EPI and M.ibb.allow(C, option.next_commitment):
        g = M.mint.choose_interaction(modes, o, M.ibb)
        if g:
            U_epi = M.cia.update_belief(modes, M.cia.execute(g))

    if option.active:
        a, done = option.step(o)                   # 选项层执行，不展开原子
    elif ell == 0:
        a, done = xi, False                        # 学生路径
    else:
        mode = M.select_mode(modes, U_epi)
        a, k = M.dispatch(mode, U_ale, U_epi)
        done = False

    # 承诺证书：不可逆动作必须有账本余额 + 选项前置/后置证书
    if C >= TAU_C and not M.cca.has_commitment_cert(a, option):
        return M.fallback_hover_or_ask(o)

    solvent = M.ledger_step(M.ledger, M.eproc, o, ell, anchor=(option.active and done))
    if not solvent:
        return M.fallback_hover_or_ask(o)
    if option.active and done:
        M.cca.anchor(option.id)
    M.cca.append(J_FLUID=M.jfluid(...), R=M.ledger.R, C=C, ell=ell)
    return a
```

## 3. 推导

**假设** A99（承诺点稀疏 + 非承诺点可恢复）、A100（调度单调）、A101（选项可组合）、A102（VoI_H 子模）、A103（选择性共形：可交换或弱相依）、A104（承诺点验证下界：任何达到 R69 承诺点风险的策略，在承诺点的验证成本 ≥ b_H）。

**引理 19（承诺点稀疏性的摊销收益）** 设承诺点密度为 δ_C，轻路径成本 b_L、重路径成本 b_H，R69 的均匀成本 b_R，且 b_L < b_R < b_H。则 TELOS 的摊销成本为
b̄ = (1−δ_C)b_L + δ_C b_H。
当 δ_C < (b_R − b_L)/(b_H − b_L) 时 b̄ < b_R。由 A99，非承诺点被认证的单步风险 ≤ ε0 ≤ ε_R69，承诺点走 R69 同等路径，故期望风险不高于 R69；账本对便宜路径收取 s_ℓ，确保未被验证的尾风险不会「免费」消失。系：**承诺点越稀疏，轻量化收益越大；但承诺点检测的假阴性会同时破坏收益与安全**（见第 6 节）。

**引理 20（随时有效监控的 horizon 无关性）** 设 E_0=1，E_t 在 H0 下为非负上鞅且 E[E_t|F_{t−1}] ≤ E_{t−1}。则对任意停时 τ 与任意 H，
P(∃t ≤ H : E_t ≥ 1/α) ≤ α。
由 Ville 不等式，告警预算不随 H 增长，因此固定 O(1) 监控器可以守卫无界长程任务；不需要预先知道 H，也不需要对每步 p 值做 union bound。系：长程安全的正确统计对象是「任意时刻的假阳性」，而不是「固定 H 的假阳性」。

**引理 21（选项组合的风险次可加与终止）** 若 ω1, …, ωk 满足 post_ωi ⊨ pre_ω{i+1}（允许 ε_m 匹配误差），则
r(ω1⊗…⊗ωk) ≤ Σ_i r_ωi + (k−1)ε_m，
且当每个选项在 T_ωi 内终止的概率为 1 时，组合在 Σ_i T_ωi 内终止。若某个后置条件失败，则以重规划成本 b_replan 触发锚点；在 A101 下，规划器可以把有效决策长度从 H 降到 H/L，而无需展开每个原子步。这是长程任务「少算」的主要来源。

**引理 22（选择性升级的分布无关控制）** 在 A103 下，按 C 分层用分组共形阈值 τ_α(C)，只在 s ≤ τ_α(C) 时接受学生，则每层内的选择错误率 ≤ α_sel（从而对「教师认为有歧义」的高 C 层也可给条件保证）。漂移下用 ACI 更新阈值，长期选择错误率 ≤ α_sel + o(1)；若把选择错误指示量再喂入 e-process，则得到任意时刻的 α_sel 控制。系：CFD 把 R69 的「模态幻觉」从「信错」转成「弃权 + 升级」；但这只保证与教师一致，不保证教师本身正确，故仍需 R69 的 MCG 模态校准门与证据纪律同时生效。

**引理 23（记忆压缩的风险膨胀）** 若 m_t 在 Q_safe 上 ε_mem-充分，且决策损失 ℓ 关于安全查询的后验有界（ℓ ∈ [0,1]），则用 m_t 替代 h_{0:t} 的期望决策损失满足
|E_m[ℓ] − E_h[ℓ]| ≤ 2ε_mem。
若用 count-min / reservoir / Merkle sketch，ε_mem 随记忆预算 M 以 O(1/√M) 下降；因此 O(1) 记忆可以换来可控而非零的风险膨胀。系：轻量化不能消除风险，只能把风险变成「可预算、可审计的 ε」。

**定理 18（证书条件下的严格包含）** 在 A99–A104 且所有证书有效时：
(i) 若 δ_C=1 且禁用 ℓ0，TELOS 逐指令等于 R69；
(ii) 若再关闭 MINT 且取 K=1，逐指令等于 R68；
(iii) TELOS 的总失败概率 ≤ α_total = α_eproc + α_sel + α_ledger（α_ledger 为账本/证书认证失效概率），且该界不随 H 增长；
(iv) 任意未验证的便宜路径都已被账本收取附加费，且在任何不可逆动作前必须由锚点或 ℓ3 偿付。
因此在「证书有效」事件上，TELOS 的安全侧不弱于 R69；效率侧只是把计算从「每步均匀」改为「承诺点集中 + 非承诺点摊销」。这不是无条件的风险 ≤，而是**以 1−α_total 概率的、可审计的包含**。

**定理 19（长程-轻量化 Pareto）** 在 A99–A104 下：
(i) 摊销计算 ≤ (1−δ_C)b_L + δ_C b_H，且当 δ_C < (b_R−b_L)/(b_H−b_L) 时严格优于 R69；
(ii) 由 A104，任何要在承诺点获得 R69 级验证的策略，其摊销验证成本下界为 δ_C b_H；TELOS 只比该下界多付 (1−δ_C)b_L，故在 δ_C b_H ≫ b_L 的长程稀疏承诺区间达到同阶最优；
(iii) 证书与记忆从 R69 的 O(H) 降为 O(1) 常驻、O(log H) 验证；
(iv) 反之，若 δ_C→1（每步都是承诺点）或对抗性 ℰ_spoof 抬高 C，TELOS 自动退回 R69，轻量化收益消失但不牺牲安全。
系：**长程-轻量化不是两个目标的折中，而是「承诺点稀疏性」这一结构性质的兑现**；结构消失时，收益应诚实地消失。

## 6. 本轮最大风险

**一句话**：TELOS 的全部轻量化收益由**承诺点检测器**担保——一旦它漏检一个不可逆/高杠杆决策（尤其在被 ℰ_spoof 对抗时），系统就会在最该重算的地方走最便宜的路径，而风险账本只会为它「看得见」的承诺点收费；长程任务会把这种**账本看不见的省算**复利成低频但灾难性的尾事件。**轻量化的危险不在算得少，而在少算得无声无息。**

**次级风险与缓解**：
1. **账本 Goodhart**（r̂ 低估真实风险）→ 认证上界 + 锚点审计 + 独立 e-process 交叉检查；账本永不被当作点估计。
2. **预算饥饿攻击** → 摊销预算设硬下限「安全储备」，任何不可逆动作前保留 ℓ3 能力；E311 对抗训练。
3. **交互疲劳/交互债在 worst time 到期** → IBB 的债息与承诺点前置约束 + 批量问询 + E309。
4. **共形保证在非交换/强漂移下失效** → ACI/e-conformal + 慢重标定 + MCG 校准门，失效即退 R69。
5. **选项证书伪造/组合脆弱** → 选项证书 id 链 + 前置/后置独立验证 + ℰ_forge 训练 + 组合风险次可加上界。
6. **记忆压缩丢掉罕见安全线索** → 安全查询类 Q_safe 显式定义 + sketch 保留稀有事件 + 引理 23 的 ε_mem 预算。

**最大风险一句话**：**TELOS 的轻量化收益完全押在承诺点检测的可信度上——漏检一个不可逆决策，系统就会在最该认真处省算，而账本为这段未被识别的承诺点记零账，长程会把这种无声的省算复利成灾难性尾事件。**

## 2. 形式化定义（要点版）

**定义 310（总览与三不变式）** TELOS-RAS 由 10 个组件构成；不变式：摊销轻量（窗口均值 B_avg + 硬上限 B_max + 有界突发 B_burst）；账本不透支（cheap-path 付 s_ℓ，锚点退款，不可逆动作前 R_t≥0）；承诺点优先（C≥τ_C 必须 ℓ2 以上并携带承诺证书）。

**定义 311（CPD）** `ρ` 为 T_rec 内可恢复概率，`L` 为模态后果差，`C=σ(α(1−ρ)+βL+γI_obs)`；A99：承诺点稀疏，非承诺点错误可在 T_rec 内恢复。

**定义 312（BAF 计算梯级）** ℓ0 学生单步 / ℓ1 K=1 / ℓ2 K=4+AUD+FMA / ℓ3 +MINT+OCI；`b0<…<b3`，`ε0≥…≥ε3`；任意级返回均合法，可随时停止。

**定义 313（CAS 调度）** `ℓ*=min{ℓ: ε_ℓ+λs_ℓ ≤ δ_t}`，其中 `δ_t=(R_t−R_res)/max(1,N_C(t))`；空集取 ℓ3；ℓ3 不可行则不执行不可逆动作；A100 单调性 ⇒ 阈值最优。

**定义 314（RLD 账本）** `R_{t+1}=clip(R_t−r̂_t−s_ℓ+a_t,0,R_max)`；不可逆动作前 `R_t≥r̂_t+s_ℓ`；锚点退款只针对已验证历史块，`a_t≤A_max`。

**定义 315（TSC-fast / e-process）** `E_0=1` 且 `E[E_t|F_{t−1}]≤E_{t−1}`；`E_t≥1/α` 告警；Ville ⇒ 任意 H 上 `P(sup_t E_t≥1/α)≤α`；O(1) 状态。

**定义 316（TSC-slow）** 全量 COF 仅在 `C≤τ_safe` 低杠杆窗口或告警时触发；目标 `max I(θ;y|window)/downtime`，s.t. 账本不透支、重标定期间禁止不可逆动作。

**定义 317（CFD）** 学生输出 `(a,U_ale,U_epi,conf)`；非共形分 `s=disagreement(π_S,π_T)`；按 C 分层做分组共形（Mondrian），`s≤τ_α(C)` 且 `C<τ_C` 才走 ℓ0，否则升级；漂移下 ACI/e-conformal，并把选择错误指示量喂入 e-process 以得任意时刻控制（仅 ACI 则只保证长期平均）；学生只负责「知道自己不知道」。

**定义 318（OCI）** `ω=(pre,π,post,T,r,id)`；`post_ω1⊨pre_ω2` 时组合；`r≤Σr_i+(k−1)ε_m`；后置失败/超时则锚点 + 重规划；规划器在选项层运行。

**定义 319（MCM）** `m_t=Compress(h_{0:t})`，`|m_t|≤M`；`sup_{q∈Q_safe}|P(q|m_t)−P(q|h)|≤ε_mem`；目标 `min I(h;m)` s.t. `ε_mem≤ε`；保留账本/e-process/选项进度/稀有事件 sketch。

**定义 320（IBB）** 预算 `N_int(H)=κH` + 窗口速率上限；交互债 `D_t`；当且仅当 `VoI_H−c ≥ E[VoI_H'−c']+ιD_t` 才问，否则存入银行、低承诺窗口批量执行；`VoI_H = 即时熵降 + η·避免未来承诺点选错的期望风险降`；A102 子模 ⇒ 阈值贪心 (1−1/e) 近似；R69 MINT 是 η=0 特例。

**定义 321（CCA / J_TELOS）** `d_t=H(J_FLUID_t‖d_{t−1})`；锚点记 Merkle 根；`J_TELOS=(d_T,R_T,anchor_density,b_avg,b_max,p_eproc,option_root,ε_mem,telos_ver)`；Valid ⇔ 锚点 J_FLUID 有效 ∧ 账本未透支 ∧ 摊销预算未越界 ∧ 证据纪律满足 ∧ e-process 未告警；常驻 O(1)、验证 O(log H)。

**定义 322（AIC-LONG）** `ℰ_LONG=ℰ_FLUID×ℰ_starve×ℰ_spoof×ℰ_fatigue×ℰ_forge×ℰ_mem`；分别覆盖预算饥饿、承诺点伪装、交互疲劳、选项证书伪造、记忆投毒。

**定义 323（三级回退）** CPD 不可信/账本为负/预算不可行 → 强制 ℓ3 或悬停求助；CFD 未校准/ECE 越界 → 禁用 ℓ0 退 R69；交互预算耗尽/证据纪律失败 → 禁用 MINT 退 R68。行为层面 `R68 ⊂ R69 ⊂ TELOS`。

```python
# IP-264 CPD
def commitment_score(z, o, option_progress):
    rho = recoverability_estimate(z, o)
    L   = modal_leverage(z, o)
    return sigmoid(A*(1-rho) + B*L + G*obs_irreversibility(o))

# IP-266 CAS：按剩余承诺点数分配风险预算
def schedule(C, U_epi, ledger, n_commit_remaining):
    delta_t = (ledger.R - ledger.R_res) / max(1, n_commit_remaining)
    for ell, (b, eps) in enumerate(LADDER):
        surcharge = eps - LADDER[3].eps
        if C >= TAU_C and ell < 2: continue
        if ledger.can_afford(eps + surcharge) and eps + ledger.lam*surcharge <= delta_t:
            return ell
    return None

# IP-265 RLD + IP-270 TSC-fast
def ledger_step(ledger, eproc, x, ell, anchor=False):
    r_hat = LADDER[ell].eps
    s     = LADDER[ell].eps - LADDER[3].eps
    refund = ledger.anchor_refund() if anchor else 0.0
    ledger.R = clip(ledger.R - r_hat - s + refund, 0.0, ledger.Rmax)
    eproc.update(x)
    return ledger.R >= 0.0 and not eproc.alarm()

# IP-267 CFD：学生可弃权
def accept_student(student, teacher, x, C, alpha_sel):
    xi, uale, uepi, conf = student(x)
    score = disagreement(xi, teacher.prototype(x))
    if C >= TAU_C: return None
    if score <= conformal_threshold(alpha_sel) and conf >= TAU_CONF:
        return xi, uale, uepi
    return None

# IP-275 主闭环
def TELOS_round(M, obs, t, option):
    z, o = M.mtm.forward(obs)
    M.eproc.update(M.residual(o)); alarm = M.eproc.alarm()
    C = M.cpd.score(z, o, option.progress)
    ell = M.cas.schedule(C, M.aud.cheap_uepi(z), M.ledger, option.n_commit_remaining)

    xi = None
    if ell == 0:
        out = M.cfd.accept_student(M.student, M.fmp, o, C, M.alpha_sel)
        if out is None: ell = 2 if C >= TAU_C else 1
        else: xi, U_ale, U_epi = out
    if ell is None or not M.ledger.can_afford(LADDER[ell]):
        return M.fallback_hover_or_ask(o)

    if ell >= 1:
        samples = M.fmp.sample(o, 4 if ell >= 2 else 1)
        U_ale, U_epi, modes = M.aud.decompose(samples, z)

    if (alarm or M.tsc.due(t)) and C <= TAU_SAFE:
        M.tsc.slow_recalibrate(o)

    if ell >= 3 and U_epi > TAU_EPI and M.ibb.allow(C, option.next_commitment):
        g = M.mint.choose_interaction(modes, o, M.ibb)
        if g: U_epi = M.cia.update_belief(modes, M.cia.execute(g))

    if option.active:
        a, done = option.step(o)
    elif ell == 0:
        a, done = xi, False
    else:
        mode = M.select_mode(modes, U_epi)
        a, k = M.dispatch(mode, U_ale, U_epi); done = False

    if C >= TAU_C and not M.cca.has_commitment_cert(a, option):
        return M.fallback_hover_or_ask(o)

    if not M.ledger_step(M.ledger, M.eproc, o, ell, anchor=(option.active and done)):
        return M.fallback_hover_or_ask(o)
    if option.active and done: M.cca.anchor(option.id)
    M.cca.append(J_FLUID=M.jfluid(...), R=M.ledger.R, C=C, ell=ell)
    return a
```

## 4. 推导

**假设** A99（承诺点稀疏 + 非承诺点可恢复）；A100（成本递增/风险递减的调度单调性）；A101（选项可组合）；A102（VoI_H 子模）；A103（可交换或弱相依下的选择性共形）；A104（承诺点验证下界：达到 R69 级承诺点风险至少需 b_H）。

**引理 19（承诺点稀疏性的摊销收益）** 设承诺点密度 δ_C，轻/重路径成本 b_L/b_H，R69 均匀成本 b_R，且 b_L<b_R<b_H。则 TELOS 摊销成本 `b̄=(1−δ_C)b_L+δ_C b_H`；当 `δ_C < (b_R−b_L)/(b_H−b_L)` 时 `b̄<b_R`。A99 保证非承诺点单步风险 ≤ ε0 ≤ ε_R69，承诺点走 R69 同等路径，故期望风险不高于 R69；账本对便宜路径收 s_ℓ，未验证尾风险不被免费隐藏。

**引理 20（随时有效监控的 horizon 无关性）** 若 `E_0=1`，E_t 在 H0 下为非负上鞅且 `E[E_t|F_{t−1}]≤E_{t−1}`，则对任意停时 τ 与任意 H，`P(∃t≤H:E_t≥1/α)≤α`。Ville 不等式使告警预算不随 H 增长；固定 O(1) 监控器可守卫无界长程任务，无需预知 H，也无需对每步 p 值做 union bound。系：长程安全的正确统计对象是「任意时刻的假阳性」，不是「固定 H 的假阳性」。

**引理 21（选项组合的次可加与终止）** 若 `post_ωi⊨pre_ω{i+1}`（允许 ε_m 误差），则 `r(ω1⊗…⊗ωk)≤Σr_ωi+(k−1)ε_m`；若每项在 T_ωi 内终止概率为 1，则组合在 `ΣT_ωi` 内终止。后置条件失败时以 b_replan 触发锚点；A101 下规划器把有效决策长度从 H 降到 H/L，无需展开每个原子步。

**引理 22（选择性升级的分布无关控制）** A103 下，按 C 分层用分组共形阈值 τ_α(C)，只在 `s≤τ_α(C)` 接受学生，则每层内选择错误率 ≤ α_sel（故对高 C 的「教师认为有歧义」层也可给条件保证）；漂移下 ACI 更新阈值，长期错误率 ≤ α_sel+o(1)；把选择错误指示量再喂入 e-process 可得任意时刻控制。系：CFD 把 R69 的「模态幻觉」从「信错」转成「弃权+升级」；但只保证与教师一致，不保证教师本身正确，故 MCG 与证据纪律必须同时生效。

**引理 23（记忆压缩的风险膨胀）** 若 m_t 在 Q_safe 上 ε_mem-充分，且损失 ℓ∈[0,1]，则 `|E_m[ℓ]−E_h[ℓ]|≤2ε_mem`。count-min/reservoir/Merkle sketch 使 ε_mem 随记忆预算 M 以 O(1/√M) 下降；O(1) 记忆换来可控而非零的风险膨胀。

**定理 18（证书条件下的严格包含）** A99–A104 且证书有效时：(i) δ_C=1 且禁用 ℓ0 ⇒ TELOS 逐指令等于 R69；(ii) 再关闭 MINT 且 K=1 ⇒ 等于 R68；(iii) 总失败概率 `≤ α_total=α_eproc+α_sel+α_ledger`（α_ledger 为账本/证书认证失效概率），且不随 H 增长；(iv) 任意未验证便宜路径已被账本收附加费，任何不可逆动作前必须由锚点或 ℓ3 偿付。故在「证书有效」事件上安全侧不弱于 R69，效率侧只是把计算从「每步均匀」改为「承诺点集中 + 非承诺点摊销」；这是以 `1−α_total` 概率的、可审计的包含，而非无条件的风险 ≤。

**定理 19（长程-轻量化 Pareto）** A99–A104 下：(i) 摊销计算 `≤(1−δ_C)b_L+δ_C b_H`，当 `δ_C<(b_R−b_L)/(b_H−b_L)` 时严格优于 R69；(ii) A104 给出摊销验证下界 δ_C b_H，TELOS 只多付 (1−δ_C)b_L，在 `δ_C b_H≫b_L` 的稀疏承诺区间同阶最优；(iii) 证书/记忆从 O(H) 降为 O(1) 常驻、O(log H) 验证；(iv) δ_C→1 或 ℰ_spoof 抬高 C 时自动退回 R69，收益消失但安全不牺牲。系：长程-轻量化不是折中，而是**承诺点稀疏性**的兑现；结构消失时收益应诚实消失。

## 7. 本轮最大风险

**一句话**：TELOS 的全部轻量化收益由**承诺点检测器**担保——一旦它漏检一个不可逆/高杠杆决策（尤其在被 ℰ_spoof 对抗时），系统就会在最该重算的地方走最便宜的路径，而风险账本只会为它「看得见」的承诺点收费；长程任务会把这种**账本看不见的省算**复利成低频但灾难性的尾事件。**轻量化的危险不在算得少，而在少算得无声无息。**

**次级风险与缓解**：账本 Goodhart（认证上界 + 锚点审计 + e-process 交叉检查）；预算饥饿（安全储备硬下限 + 不可逆动作前保留 ℓ3）；交互债在 worst time 到期（债息 + 承诺点前置 + 批量问询）；共形保证在强漂移下失效（ACI/e-conformal + 慢重标定 + MCG，失效即退 R69）；选项证书伪造（id 链 + 前置/后置独立验证 + ℰ_forge）；记忆压缩丢失罕见线索（Q_safe 显式定义 + 稀有事件 sketch + ε_mem 预算）。

**最大风险一句话**：**TELOS 的轻量化收益完全押在承诺点检测的可信度上——漏检一个不可逆决策，系统就会在最该认真处省算，而账本为这段未被识别的承诺点记零账，长程会把这种无声的省算复利成灾难性尾事件。**
