# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「云边协同」×「上下文理解」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**云端供给算力与语义，边缘守住实时与安全**。两个灵感分别治理 v9 遗留的两种债：算力天花板债（F̂ 前向模型与超大上下文编码器无法在机载 20ms 内运行）、意图歧义债（语音/任务/场景上下文未被结构化，长程任务易"正确执行错误目标"）。底线：**任何云端输出都不得直接进入硬安全路径；任何上下文推断都不得改写 M₀ 与停车不变式**。新组件一律为可选增强，失效即注入中立元，严格等价退回 v9 的 ACMD 行为。

## 0. 直觉与动机

**灵感 1（云边协同 → 带租约的云端动作块）**
直觉：过去把"云边协同"理解为把重计算丢到云端，但边缘机器人真正稀缺的是**可信的算力时延**，不是算力总量。v9 已经把决策变成块 ζ=(a^{1:K},Ĉ,P)，这恰好就是天然的云端缓存单元：云端算一块，边缘按块执行。于是核心问题从"怎么调度"变成**分布式缓存一致性**——块会不会过期？会不会被回滚？网络断了谁兜底？
核心创新：**陈化租约证书（Aged-Lease Certificate, ALC）**。云端的块证书携带租约 (epoch, seq, L)，其误差界随年龄单调增长：
```
β(τ) = β₀ + ρ·τ + β_net(τ)
```
租约到期、网络信任域破坏或序号回退 ⇒ 边缘立即 K_eff ← 1，退回本地逐步执行（等价 v9→v8）。云端永远只提供"有保质期的建议（leased advice）"，不提供"无条件的真相"。配套**算力迁移价值（VoC）调度**：每模块比较云端质量增益与陈旧代价、带宽代价、断网风险，只有 VoC>0 且网络信任才外迁。**安全影子律**：凡可能影响安全的云输出，边缘必须有本地保守替身，硬安全永不等网络。

**灵感 2（上下文理解 → 非侵入式语义上下文）**
直觉：v9 的语音/情感/场景信号都是逐帧局部的。"把杯子拿过来"里的"那个杯子"、与上一句话的指代关系、当前任务阶段——这些是跨轮、跨模态的**上下文状态**，单帧分类器学不到。但直觉同时警告：上下文理解是**概率性、可能自信错误**的，绝不能让它去改安全阈值。
核心创新：**上下文契约与安全包络（Context Contract & Safety Envelope）**。上下文被拆成层级假设集 H_t=(C_task, C_dialog, C_scene, C_social)，边缘轻量上下文（对话状态、韵律）+ 云端重型上下文（VLM 场景图、长对话历史）保守融合；只有在置信足够、次优间隔足够、证据不冲突时才形成**上下文承诺** C_t，否则返回弃权元 ⊥_ctx。承诺只允许作用于：候选采样先验、软评分、蒸馏唤醒/休眠、澄清对话触发——**M₀ 与停车不变式对上下文逐位不变**（引理 89）。低置信时主动发起澄清问句，把"猜"变成"问"。

**灵感 1 × 灵感 2 的耦合**
云端既是重算力又是重语义的来源。二者共享同一套租约与陈旧度机制：**上下文假设也带时间戳与陈旧度**，陈旧的语义先验按 β 折扣，过期即弃权。这样"云边协同"与"上下文理解"不是两个模块硬拼，而是同一条"新鲜度—可信度"轴上的两件事：**算力可以旧，但必须知其旧；语义可以猜，但必须会弃权**。

## 1. 研究问题（轮次升级版）

- **Q1（云端块的时效安全）**：如何设计租约、陈化证书与序号防回滚，使"云端块在新鲜租约内执行"的安全性可归约为 v9 的块证书安全性？网络分区、时钟偏斜、重放/回滚攻击下，边缘能否在有限时间内必然退回 K_eff=1？
- **Q2（上下文非侵入）**：在什么形式化约束下，上下文理解只能改变软目标与候选先验、而无法改变 M₀ 与停车不变式？保守融合与弃权能否给出可校准的"误承诺率"上界？
- **Q3（云边算力迁移）**：以什么目标函数（质量增益 vs 陈旧代价/带宽/断网风险）决定模块外迁，才能既突破边缘算力天花板、又不把硬安全押在网络 SLA 上？安全影子如何构造才保证云失效时逐位退回 v9？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 安全影子律（Safety Shadow, SS）**
凡输出可能影响硬安全（M₀、SpatialCert、FaultCert、停车不变式）的模块，边缘必须保有一个本地保守替身；云端版本只能是"更优建议"，不得成为硬安全的唯一依赖。硬安全路径上禁止出现任何网络等待（no network on hard-safety path）。

**P14 陈化租约律（Aged-Lease Certificate, ALC）**
云端动作块只在有效租约内被采纳：租约含单调 epoch/seq、签发时刻 t_issue、时长 L、块哈希与签名；误差界 β(τ) 随年龄单调不减，τ > L 或 epoch/seq 不单调或签名无效 ⇒ 拒绝，K_eff ← 1 本地执行。云端块绝不"无租约执行"。

**P15 上下文非侵入律（Context Non-Interference, CNI）**
上下文理解只可作用于候选采样先验、软评分项、蒸馏唤醒/休眠、澄清对话触发；M₀ 判据与停车不变式对上下文逐位不变。置信不足、次优间隔不足或证据冲突时返回弃权元 ⊥_ctx，行为严格等价 v9。

## 3. 与基线的接口（如何退化）

- 网络失效/租约过期/分区/时钟越界 ⇒ 云端契约注入 v^{⊥,net}，云端块作废，K_eff ← 1，等价 v9 的本地分块并退回 v8 逐步；
- 租约序号回退或签名无效（疑似回放/回滚攻击）⇒ 拒绝并作废当前云端块，降级为本地执行，记录安全事件；
- 上下文冲突/低置信/陈旧 ⇒ C_t ← ⊥_ctx，上下文贡献恒等元，等价 v9（无上下文）；
- 云边契约中间件失效 ⇒ 切换 v9 的 ContractMiddleware 本地契约路径；
- 全部失效 ⇒ 退回 MetricVoiceGauge-ACMD v9，再退回 v8/v7/v6。

## 4. 预期贡献

1. **带租约的陈化动作块**：把云边协同形式化为"有保质期的决策缓存一致性"，将 v9 块证书扩展为时间单调的误差界 β(τ)，使"陈旧即失效"成为可证明的安全性质（引理 87–88）；
2. **上下文非侵入框架**：层级假设集 + 保守融合 + 弃权元 + 安全包络，把"上下文可能错"从安全威胁降级为任务质量损失（引理 89、91）；
3. **算力迁移价值调度与安全影子**：在不把硬安全押上网络的前提下突破边缘算力天花板，云失效逐位退回 v9（引理 90、92）；
4. **语义—时效联合闭环**：E571–E590 覆盖网络抖动/分区/时钟偏斜/回放攻击、上下文校准与误识别对抗、算力迁移价值、澄清对话与端到端任务。

## 5. 本轮最大风险

**一句话**：方案把 v9 的局部不变量换成了一个跨机器的时序不变量（租约新鲜度）——若边缘时钟偏斜或续约在分区瞬间滞后，边缘就可能在"最需要安全的网络最差时刻"执行一个已过期甚至已撤销的陈旧块，而上下文又可能在同一刻自信地选错任务帧，形成"陈旧执行 × 语义误解"的叠加失效。

**新增定义 540（云边契约 CloudEdgeContract）** 在 v9 定义 535 的 κ_m 上增加执行位置与网络语义：
```
κ_m^ce = (In_m, Out_m, ℓ_m, D_m, Ŵ_m, v_m^⊥, v_m^{⊥,net}, π_m, φ_m^elig)
```
其中 ℓ_m∈{E(edge), C(cloud), H(hybrid)}。部署期静态验证两条：**(a) 硬安全路径无云端依赖**（M₀、SpatialCert、FaultCert、d_stop、AC 守卫的 ℓ 恒为 E）；**(b) 边缘侧剩余 WCET 和 Σ_{ℓ_m=E} Ŵ_m ≤ B_edge**（决策 20ms）。网络失效时 C/H 模块注入 v^{⊥,net}（云端输出的"缺席元"），与计算超时注入的 v^⊥ 区分日志。

**新增定义 541（陈化租约证书 Aged-Lease Certificate）** 云端在 t_issue 随块签发：
```
Ĉ_t(τ) = ( ĝ_min − β(τ),  ê_max + β(τ),  γ̂_grasp ),   β(τ) = β₀ + ρ·τ + β_net(τ)
```
ρ 为前向模型误差随时间的上界增长率（由信任域内滚动标定得到），β_net(τ) 覆盖压缩/丢包/降采样引入的额外误差，β（0 阶项）沿用 v9 定义 533。β 对 τ 非减，故**证书只会随年龄变保守、不会变激进**。证书有效 ⇔ τ≤L ∧ 边界成立 ∧ 用当前 τᵢ(t) 复核通过。

**新增定义 542（动作块租约 ChunkLease 与栅栏）**
```
lease = (e, n, t_issue, L, h_ζ, σ_c)
```
边缘仅在 `admit` 通过时采纳云端块：`e ≥ e_cur ∧ n > n_cur ∧ sig_ok ∧ t_now − t_issue ≤ L + ε_clock`。单调 epoch/seq 充当**栅栏令牌（fencing token）**，阻止已撤销/旧版本块被重放；`ε_clock` 为允许时钟偏斜。租约到期、分区或 admit 失败 ⇒ 云端块立即作废，`K_eff ← 1`，切换本地执行（不阻塞）。

**新增定义 543（上下文假设集与保守融合 ConservativeFusion）** 层级上下文：
```
C = (C_task, C_dialog, C_scene, C_social),   H_t = { (h, b_h, τ_h) }
```
融合算子 ⊗：仅当多源证据对同一 h 不冲突时累积支持；冲突质量不分配给任何错误假设，而投入无知元 ⊤（不承诺）。多源置信取 `conf(h) = min_s conf_s(h) · disc(τ_h)`（disc 为随年龄的折扣），即**信任最弱一致源**。冲突度 > τ_conflict ⇒ 直接弃权。

**新增定义 544（上下文承诺 ContextCommitment）**
```
C_t = h*       若 conf(h*) ≥ τ_ctx ∧ conf(h*) − conf(second) ≥ δ_margin ∧ τ_{h*} ≤ τ_ctx,max
    = ⊥_ctx    否则（弃权）
```
弃权元 ⊥_ctx 使所有下游软项取恒等元，行为严格等价 v9。承诺含"任务帧 h_task、指代消解 h_ref、澄清问句候选"。

**新增定义 545（上下文安全包络 Contextual Safety Envelope）** 上下文对决策的作用被限制在四个通道，且幅度受限：
```
作用(C_t) ∈ { 候选采样先验 π_cand, 软评分 J_soft, 蒸馏唤醒/休眠, 澄清对话触发 }
|ΔJ_soft| ≤ κ_ctx · conf(C_t)
M₀(s,a) = M₀(s,a) |_C ,  d_stop(s,p) = d_stop(s,p) |_C      （对 C 逐位不变）
```
即上下文是**软目标的加性偏置**与**候选分布的再加权**，不触碰任何硬判据。κ_ctx 由 E576 对抗标定。

**新增定义 546（算力迁移价值 Value of Offloading）**
```
VoC_m = E[ΔQuality_m] − λ_s·ρ_m·τ̄_net − λ_b·BW_m − λ_risk·P(¬U_net)
```
仅在 `VoC_m > 0 ∧ ℓ_m ≠ E-safety ∧ U_net` 时把模块外迁云端；τ̄_net 为预测网络时延，ρ_m 为该模块的陈旧敏感度（=其陈化误差斜率）。硬安全模块注册表禁止外迁（P13）。

**新增定义 547（上下文条件唤醒 ContextWake）** 扩展 v9 定义 538：dormant 模块在以下任一条件唤醒：`c_m ≥ τ_on`（v9）；`Δ_dom ≥ τ_dom`（v9）；或上下文任务帧进入 support(m) 且 `conf(h) ≥ τ_on^ctx`。上下文只能**唤醒**、不能**休眠**未获 φ^elig 的模块，且安全模块永不参与。

**新增定义 548（网络信任域与联合信任域）**
```
U_net = { RTT_p99 ≤ RTT_max ∧ loss ≤ loss_max
          ∧ lease.valid ∧ clock_skew ≤ ε_clock }
U_t   = U_metric ∧ U_net
```
K_eff 门控（v9 定义 539）改为以 U_t 为准：网络不信任 ⇒ `K_eff=1`，与 Δ_dom/risk_SLAM 越阈同效。云端块一律在 U_net 内才可采纳。

**新增定义 549（上下文层级与陈旧度）** 各层独立年龄与关键度：`C_dialog`（边缘，≤2ms）、`C_task`（边缘+云端，τ≤0.5s）、`C_scene`（云端 VLM 场景图，τ≤1.0s）、`C_social`（云端长程，τ≤2.0s）。任一层超龄或冲突只使**该层**弃权，不连带其他层；`C_scene` 弃权时场景相关软先验取恒等元。

**定义 493（六层指标层级）** 继承 v8/v9：M=(M₀,M₁,M₂,M₃,M_dom,M_SLAM) 不变。
**定义 495/524（MetaWeight/情感，5 维）** 继承不变；情感软评分可接受上下文偏置（受定义 545 约束）。
**定义 521（DA-OTL）** 继承不变；云端 F̂ 只替代"预测"，不替代阈值 τᵢ(t) 的本地复核。
**升级定义 533（块证书，v10）** 由 Ĉ_t 升级为陈化租约证书 Ĉ_t(τ)；本地块令 τ≡0、β_net≡0，退化为 v9 证书。
**升级定义 539（有效块长，v10）**
```
K_eff(t) = 1                                          若 ¬U_t
         = min( K_lease , ⌊K_max·(1 − min(1, Δ_dom/τ_dom))⌋ )   否则
```
其中 `K_lease = ⌊(L − ε_clock)/Δt⌋` 为租约剩余可执行步数。**块的执行时域不得超过租约时长**，防止"执行着执行着租约就过期了"。

# IP-358 租约管理器
class ChunkLeaseManager:
    def __init__(self, eps_clock_ms=2.0, dt_ms=20.0):
        self.epoch, self.seq = -1, -1
        self.lease = None
        self.eps_clock, self.dt = eps_clock_ms, dt_ms

    def admit(self, lease, now, verify_sig):
        return (lease.epoch >= self.epoch
                and lease.seq > self.seq
                and verify_sig(lease)
                and now - lease.t_issue <= lease.L + self.eps_clock)

    def renew(self, lease, now, verify_sig):
        if not self.admit(lease, now, verify_sig):
            return False                      # 拒绝：疑似过期/回放/回滚
        self.epoch, self.seq, self.lease = lease.epoch, lease.seq, lease
        return True

    def valid(self, now):
        return (self.lease is not None
                and now - self.lease.t_issue <= self.lease.L + self.eps_clock)

    def max_steps_left(self, now):
        if not self.valid(now):
            return 0
        left = self.lease.L + self.eps_clock - (now - self.lease.t_issue)
        return max(0, int(left // self.dt))


# IP-361 陈化租约证书
def aged_bounds(cert, age_ms, rho, beta_net):
    beta = cert.beta0 + rho * age_ms + beta_net(age_ms)   # 单调不减
    return cert.g_min - beta, cert.e_max + beta

def cert_valid(cert, age_ms, lease_ok, cur_thresholds):
    if not lease_ok:
        return False
    g_lo, e_hi = aged_bounds(cert, age_ms, cert.rho, cert.beta_net)
    return (g_lo >= cert.d_safe and e_hi <= cur_thresholds.tau_eff
            and cert.grasp_valid)


# IP-359 上下文融合（保守 + 弃权）
class ContextFusionUnit:
    def __init__(self, tau_ctx=0.70, delta_margin=0.15, tau_conflict=0.40):
        self.tau_ctx, self.delta_margin = tau_ctx, delta_margin
        self.tau_conflict = tau_conflict

    def fuse(self, edge_hyp, cloud_hyp, now):
        srcs = [h for h in (edge_hyp, cloud_hyp)
                if h is not None and now - h.t_issue <= h.tau_max]
        if not srcs:
            return Abstain()                       # ⊥_ctx
        if conflict_degree(srcs) > self.tau_conflict:
            return Abstain()                       # 冲突 ⇒ 不分配错误质量
        conf = {}
        for h in hypotheses_union(srcs):
            # 信任最弱一致源；按年龄折扣
            conf[h] = min(c * discount(now - s.t_issue) 
                          for s, c in support(srcs, h))
        top, second = top2(conf)
        if top is None:
            return Abstain()
        if (conf[top] >= self.tau_ctx
                and conf[top] - conf[second] >= self.delta_margin):
            return Commitment(top, conf[top])
        return Abstain()

## 4. 推导

**引理 87（陈化租约证书的保守性）** 设信任域 U_t 内、任意年龄 τ≤L 的真实前向模型误差满足 ‖F̂−F‖∞ ≤ β_true(τ) ≤ β₀+ρτ+β_net(τ)=β(τ)。则对云端块 (i) 任意块内步的真实间隙 g_k ≥ ĝ_min−β(τ)（证书随年龄仍保守）；(ii) 若证书在 τ 时刻有效，则 v9 引理 82 的中止安全性结论对 Ĉ(τ) 成立。证明：(i) 由一致误差界，g_k ≥ F̂g_k−β_true(τ) ≥ F̂g_k−β(τ) ≥ min_k F̂g_k−β(τ)=ĝ_min−β(τ)；(ii) 将引理 82 的 β 替换为单调非减的 β(τ)，其证明逐行不变；β 非减保证"越旧越保守"，不会出现"证书随年龄变激进"。∎

**引理 88（租约分段安全性 / 无陈旧执行）** 设边缘与云端时钟偏斜 ≤ ε_clock，租约采纳规则如定义 542，且栅栏 epoch/seq 单调。则 (i) 任何已过期（τ>L+ε_clock）或已撤销（epoch/seq 被更新）的块不可能通过 `admit`；(ii) 网络分区后，边缘在 ≤ L+ε_clock 时间内必然进入 `lease.valid=False`，从而 `K_eff←1` 本地执行。证明：(i) `admit` 的第四项拒绝 τ>L+ε_clock，单调栅栏拒绝 epoch<e_cur 或 seq≤n_cur，签名校验拒绝伪造；(ii) 分区后无新租约续期，t−t_issue 单调增长，必在 L+ε_clock 处越过界，`valid` 转假，定义 548 令 U_t 假、K_eff=1；本地执行不依赖网络，故有限时间内必然退回 v9/v8 语义。∎

**引理 89（上下文非侵入安全）** 若 M₀、d_stop、SpatialCert、FaultCert 与 AC 守卫的实现不读取 C_t（定义 545 构造保证），则对任意上下文假设（含错误承诺），硬安全不变式与 v9 逐位一致。上下文仅改变候选先验与软评分，其最优偏移被 |ΔJ_soft|≤κ_ctx·conf(C_t) 约束。证明：硬判据是状态-动作的函数，与 C 无关，故任意 C 下其真值不变；软通道仅影响候选排序，不改变 Feasible 集合与停车条件；因此误识别最多导致次优候选（任务质量损失），不能产生硬安全违背。∎

**引理 90（云边/上下文退化与 v9 逐位等价）** 对每个云边契约，断网或租约失效注入 v^{⊥,net}、上下文弃权注入 ⊥_ctx 后，下游端口读数与 v9 对应模块缺席/退化分支逐位一致；安全影子（P13）保证硬安全读数不受云端影响。故云边上下文失效时系统行为严格 ∈ v9 行为集，安全由 v9 引理 82–86 传递。证明：v^{⊥,net} 按定义 540 取"该端口云端输出缺席"的恒等元，与 v9 中该模块不存在时的取值相同；⊥_ctx 使软项取恒等元，与 v9 无上下文相同；安全影子使所有硬判据在两种情形下同一函数；组合后逐位等价。∎

**引理 91（保守融合的误承诺界）** 设保守融合取一致源最小置信并对年龄折扣，冲突质量投入无知元。则 P(错误承诺) ≤ min_s P(源 s 假阳性) / (1−P(冲突门漏检))，且在冲突度>τ_conflict 时误承诺概率=0（因弃权）。证明：承诺要求所有支持源一致且 conf(h*)≥τ_ctx，错误承诺必至少一个源对 h* 假阳性且融合未识别冲突；用 union bound 取最小源界；冲突门触发时直接弃权，条件概率为 0。∎

**引理 92（可调度性守恒）** 云边中间件仅把 ℓ_m∈{C,H} 且非安全关键的模块异步外迁，边缘侧执行集合的 WCET 和 ≤ B_edge（定义 540 静态校验）；网络调用以非阻塞轮询接入主环并受 deadline_guard 约束，故 v9 引理 86 的 50Hz 结论保持，典型决策预算利用率进一步下降。证明：外迁只减少边缘侧执行项，Σ_{ℓ_m=E}Ŵ_m 不增；非阻塞轮询不占用等待时间；主环时间上界仍为感知 2ms + 决策 20ms，故 50Hz 保持。∎
