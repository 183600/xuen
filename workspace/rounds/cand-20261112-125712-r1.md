# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「数据集」×「低延迟推理」）

> 第 57 轮把安全押在"元先验 + 共形保底 + 跨模态对账 + 个性化信任"上，纵深五层，但它的最大风险自陈恰好点破了一个从未被当作对象的假设：**"语料"本身是给定的、中立的、充分的**。元推断器只对它见过的世界负责，而"见过的世界"由数据集决定；数据集从哪来、覆盖了哪些分层、标签是谁标的、还能不能再用——这些全在系统之外。同时第 57 轮把"元推断时延"列为中低风险，却默认了一个更强的物理前提：**推理可以慢到任意程度而不影响安全**。对一台在碎石/冰面/斜坡上靠连续节拍维持平衡的四足机器人，这个前提是错的——推理超时本身就是一种跌倒机制。本轮两个灵感各补一刀：**数据集**把"世界被看见的程度"变成一等安全对象（出处、分层覆盖、数据债、概念漂移），**低延迟推理**把"证据能否赶在节拍之前生产出来"变成一等安全约束（anytime 质量曲线、推理余量、级联降级、证据缓存与即时作废）。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"数据可溯源、推理守期限、快信道只可否决的证据说可信"**。

核心矛盾：
- **H29（数据量 vs 数据充分）**：OOD 门只能识别"支撑集之外"的点，看不见"支撑集内部但分层欠采样"的空洞——一个大而偏的数据集会给出分布内的自信错误；覆盖必须按"决策相关分层"声明，而不是按样本总数。
- **H30（深思 vs 节拍）**：更多证据降低认知风险却抬高时延风险；对靠连续接触维持平衡的四足，想得越久越可能摔倒，"想清楚"与"站得稳"在同一段时间预算上竞争，最优停止点未必是证据最充分处。
- **H31（低延迟近似 vs 校准保真）**：为赶期限必须蒸馏/量化/缓存/级联，而近似会悄悄破坏第 57 轮的 ECE 与 OOD 保证——速度与健全性的交易在未被审计时是隐形的，于是"更快"可能意味着"更自信地错"。

## 0. 直觉与动机

**灵感 1（数据集 → 覆盖证书：把"没见过的世界"显式记账）**
直觉：第 57 轮的 OOD 门像"离家越远越警惕"的门卫，只对**远离**训练分布的点报警；但危险若恰好落在训练分布的"家"里某个从未被踩过的房间（某材质×某季节×某坡度的组合），门卫不会响。数据集不该只被问"有多大"，而要被问"**按决策相关的分层，每一格被看了几次、谁看的、多久以前看的、标签可信吗**"。于是引入**分层覆盖证书**与**数据债**：覆盖不足的格子被显式标为"分布内空洞"，在承诺前必须补盲或降级。数据从"背景假设"变成"可审计的资产/负债"。

**灵感 2（数据债 → 探针的两种价值：为现在探 vs 为将来教）**
直觉：一次探针不只服务当前区域（第 57 轮的即时 VOI），还在为未来的同类区域**还数据债**——它把某个欠采样分层补上一格。这给探询一个"组合价值"：补盲探针的收益跨区域摊销。但这也制造新的浪费与博弈：为采集而采集会挤占当前安全预算；被污染或低可信来源的标注不能计入覆盖。于是数据采集价值必须被**当前期限与出处可信度双重门控**，来源不可信的数据只入隔离区。

**灵感 3（低延迟推理 → anytime 安全：任何时刻都有一个"已到手"的合法动作）**
直觉：安全系统不能有"正在思考、暂时无动作"的空窗。把推理看成 anytime 算法：算得越久质量越高，但**在任何时刻都必须能给出一个已被证明合法的保守动作**（缓存证据、反射、减速、停）。承诺只在"证据门阈值能在控制期限 τ_d 内到达"时成立；否则不是"用更快的猜测"，而是"退回已到手的证据或更保守的动作"。**思考超时是失败模式，不是性能问题。**

**灵感 4（快信道 → 只可否决：快可以怀疑，慢才能相信）**
直觉：低延迟通道（本体感觉、电流尖峰、IMU）比深度推理快几个数量级，但噪声大、易混叠，不足以**建立**证据；然而它极适合**作废**证据——世界一变（打滑、塌陷、突起），快信道立刻让缓存证据失效。于是确立不对称原则：**快信道只可否决、不可确认**（EV-veto），把"信任赢得慢、失去快"从人类推广到所有证据源。这与第 57 轮"信任失去快"同构，却把它提升为架构级不变量。

**灵感 5（合流 → 数据-期限证据门 DFE 与 PCE+++）**
直觉：第 57 轮证据门要求"校准证书"；本轮再加两把锁：**覆盖证书**（这个分层的数据够不够、新不新、出处可信吗）与**期限证书**（这条证据是不是在 τ_d 内由已认证路径产出的）。级联（反射→小模型→全元模型→人）按"能否在期限内达标"选级，而不是按"哪个最准"选级；缓存证据带 TTL 与变更签名。三条新机制全部只经"信念更准 / 更保守 / 更快作废"三个安全通道起作用。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（数据集出处与分层覆盖证书 DPC）** 数据集记录 d_i=(x_i,y_i,π_i,τ_i,s_i)，出处 π_i=(来源,传感器,采集者,同意范围,可信度)，分层 s_i∈𝒮=材质×季节×坡度×区域类。决策相关区域 A 的覆盖 κ_A(z)=A 中被"n_s≥n_min ∧ 年龄≤TTL_s ∧ 出处可信≥ρ_prov"分层覆盖的比例。充分性证书 A(𝒟,Z,ε) ⇔ ∀z∈Z: κ(z)≥1−ε ∨ z∈OOD_constructed（显式构造的分布外）。数据债 D_data(z)=w₁(1−κ)+w₂·staleness+w₃·provenance_uncert+w₄·label_conflict。**DPC 与 OOD 互补**：OOD 是局部密度检验（管"支撑集外"），DPC 是分层质量检验（管"支撑集内的欠采样空洞"），二者缺一不可。

**定义 140（数据债驱动的探询 DDA）** 探针 p 的价值 = 即时认知 VOI（第 57 轮）+ 组合数据价值 VOI_teach(p)=E[ΔD_data(stratum(r_p))]−λ_c·cost(p)。采集门控：仅当"不损害当前期限与安全 ∧ 出处可信≥ρ_prov ∧ 在同意范围内"才允许计入覆盖与训练。主动补盲在债务最高的可达分层中选非破坏探针。来源不可信/越同意范围的数据只入隔离区，不计覆盖、不进 𝒟_meta。

**定义 141（期限约束推理 DBI）** 推理算子 π 具 anytime 曲线：计算预算 t 后输出具已认证误差/校准 q_cert(t)（随 t 单调不劣），达标时刻 t*(θ)。控制期限 τ_d（步态周期/接触决策窗）。推理余量 S=τ_d−t*(θ)。**期限健全承诺** ⇔ 存在已认证路径使 S≥0。若不存在，唯一合法动作是"证据已到手"的缓存/反射动作或保守动作（减速/停），**禁止退化为未认证的快速猜测**。总风险 R_total ≤ R_epistemic(t)+R_temporal(t)，二者随 t 反向，存在最优停止 t°。

**定义 142（证据缓存与即时作废 ECX）** 缓存项 e=(region,evidence,timestamp,world_signature,TTL)。有效 ⇔ 年龄≤TTL(动力学类) ∧ 变更检测器静默。快信道检测器（本体/电流/IMU）时延 ≪τ_d。**不对称规则**：快信道可在任意时刻**作废**缓存证据（EV-veto），但不得**建立**可满足证据门的确认性证据；TTL 按动力学类：静态地形长、可变形/天气暴露短。变更签名=低延迟可观测量的分布指纹。

**定义 143（推理级联与期限预算 RCB）** 级联 ℓ∈{反射,蒸馏小模型,全元模型,人协商}，各级 (τ_ℓ, ε_ℓ, c_ℓ) 为时延/认证误差/成本。调度选满足 τ_ℓ+t_evidence(ℓ)≤τ_d ∧ ε_ℓ≤ε_req 的最低级；无级可达则转保守动作（不降级到更差级）。期限感知 VOI：VOI/ms，把时延当作可计价资源；认知恒温器的对偶——期限紧则少想、多靠缓存与反射。

**定义 144（数据-期限证据门 DFE 与证书 J_d）** 证据类：EV-probe\*（须同时满足：第 57 轮校准证书 ∧ 该分层覆盖证书 ∧ 期限证书）；EV-margin/EV-visit/EV-xmodal/EV-human 继承；新增 **EV-veto**（快信道，仅可否决/降级/强制再探，永不单独满足任何证据门）。不可逆接触必要证据集不得含 EV-veto 或 EV-xmodal。证书 J_d=(provenance_log,coverage_cert,staleness_log,latency_log,cascade_log,deadline_violations,veto_log)，继承 J_p 全检。

## 2. 关键算法伪代码（完整版见产物区）

```python
def data_coverage_gate(r, D, strata, eps):          # IP-139
    s = stratum(r)
    cov = covered_fraction(D, s, n_min, ttl(s), rho_prov)
    debt = data_debt(D, r, s)
    return (cov >= 1 - eps and not ood_constructed(r)), cov, debt

def deadline_sound_commit(inf, tau_d, req):          # IP-141
    t_star = inf.time_to_threshold(req)              # anytime 曲线反解
    if t_star is None or t_star > tau_d:             # 期限内不可达
        return cached_or_conservative(inf, req)      # 绝不未认证快猜
    return commit(inf.evidence_at(t_star))

def fast_veto(stream, cache):                        # IP-142: 只可否决
    for e in cache:
        if world_signature(stream) != e.signature or age(e) > e.ttl:
            e.valid = False                          # 快信道仅作废
    return cache
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| DPC | O(\|𝒮\|) 查询；审计 O(N_hold) | O(\|𝒟\|) 出处元数据 | 覆盖下界诚实、审计集独立于训练语料 |
| DDA | O(\|𝒮\|·d_b) | O(\|𝒟\|) | 采集门控不越期限/同意范围 |
| DBI | O(log T) 反解 t\* | O(1) | anytime 曲线认证、超时监控可靠 |
| ECX | O(\|cache\|) 快信道 | O(\|cache\|) | 快信道只作废、TTL 按动力学类 |
| RCB | O(L) 选级 | O(L) | 不降级到更差级、无级则保守 |
| DFE | O(\|σ\|) | O(\|σ\|) | 三证书齐全、EV-veto 不单独满足 |

**正确性定理（CCPS-D 概要）**：在 A37–A40 上加 (A41) 覆盖证书诚实且完备（分层覆盖下界、审计独立于训练语料）；(A42) anytime 曲线认证诚实、期限监控可靠（超时≤δ_t）；(A43) 快信道只作废不确认。则：(i) 数据空洞导致的分布内失效率 ≤ε+δ_ood；(ii) 无期限健全路径时系统只走保守动作，P(超时承诺)≤δ_t；(iii) 快信道单调降低承诺率（不作升险）；(iv) 终止性继承 PCE+ 且每检查点级联≤L 级。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 覆盖证书本身是估计 → 假充分 | 高 | 保守覆盖下界 + 分层 union bound + **独立留出审计集**（不得与训练语料同源） |
| 期限压力 → 只保守不前进（活性丧失） | 中高 | 预计算/缓存/级联 + 预算下限 + "不确定下仍前进"的保守动作集 |
| 快信道噪声 → 误否决/抖动 | 中 | 迟滞 + 否决证据加权 + 否决审计 |
| 数据污染/覆盖造假 | 中 | 出处可信 + 同意范围 + 隔离区 + 留出审计 |
| anytime 证书难获得 | 中 | 经验校准 + 共形 + 可回退第 57 轮完整路径 |

## 6. 本轮最大风险

**一句话**：覆盖证书本身也是从数据里估出来的——若**审计集与训练语料共享同一个盲区**（审计者也没见过那个缺失的世界），系统会恰好为它看不见的空洞开具"充分"证书，而期限压力又逼它更快地采信缓存与已覆盖证据，于是假覆盖会变成一次又快、又自信、又错误的承诺；必须以独立留出审计、覆盖下界的保守估计、快信道只可否决三重护栏，绝不让"审计"与"训练"看同一份世界。

## 2. 关键算法伪代码

### IP-139 DPC（数据集出处与分层覆盖证书）

```python
def coverage_certificate(D, Z, eps, audit):
    bad = []
    for z in Z:
        s = stratum(z)
        n   = count(D, s, provenance_trust >= rho_prov)
        fresh = age_max(D, s) <= ttl(s)
        if n < n_min or not fresh:
            if not ood_constructed(z):
                bad.append((z, data_debt(D, z)))     # 分布内空洞
    # 审计集必须独立于训练语料，否则盲区会被同源审计掩盖
    return Adequacy(ok=(len(bad) == 0), holes=bad,
                    audit_independent=audit.source != D.source,
                    lower_bound=clip_union_bound(bad, eps))
```

```python
    if not (p.consent_ok and p.provenance_trust >= rho_prov):
        return -inf                                   # 越权/不可信：不入覆盖
    dD = expected_debt_reduction(D, stratum(p.region))
    return dD - lambda_c * cost(p) - lambda_lat * latency(p, deadline)

def choose_probe(cands, D, M, inf, deadline):
    for q in cands:
        q.score = voi_meta_pessimistic(q, M, inf) + teaching_value(q, D, M, deadline)
    q = max(cands, key=lambda x: x.score)
    return q if q.score >= theta_voi and q.fits(deadline) else None
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DPC | O(\|𝒮\|) 查询；审计 O(N_hold) | O(\|𝒟\|) 出处元数据 | 覆盖下界诚实、审计独立于训练语料（A41） |
| DDA | O(\|𝒮\|·d_b) | O(\|𝒟\|) | 采集不越期限/同意范围、污染不入覆盖 |
| DBI | O(log T) 反解 t\* | O(1) | anytime 曲线认证、超时≤δ_t（A42） |
| ECX | O(\|cache\|) | O(\|cache\|) | 快信道只作废、TTL 按动力学类（A43） |
| RCB | O(L) | O(L) | 不降级到更差级、无级则保守 |
| DFE | O(\|σ\|) | O(\|σ\|) | 三证书齐全、EV-veto 不单独满足 |
| PCE+++ | O(\|CP\|·(k_p+k_c)·(C_VOI+L+d_φ)) | O(\|V\|+\|σ\|+\|cache\|) | 期限感知 VOI、级联≤L、四态完备 |

**正确性定理（Data-Deadline Soundness, DDS）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；**(A41)** 覆盖证书诚实且完备：κ 的分层下界为真、审计集与训练语料来源独立（audit.source ≠ D.source）；**(A42)** anytime 曲线认证诚实、期限监控可靠（违约可检出，超时 ≤δ_t）；**(A43)** 快信道只作废不确认（EV-veto 永不进入确认证据集）。则：

1. **数据充分性**：若覆盖证书为真，则分布内数据空洞导致的承诺失效率 ≤ ε + δ_ood；反之若审计同源导致证书假充分，该失效不被本条覆盖（见第 6 节，须以独立审计消解）。
2. **期限健全性**：若不存在期限健全路径，系统只执行"证据已到手"或保守动作，故 P(超时承诺) ≤ δ_t；且质量随思考时间单调不劣，不存在"想得越久越不安全"的悬崖（只存在认知/时延的风险交换）。
3. **否决单调性**：EV-veto 只减少可承诺集合，故对任意检查点 P(commit | veto) ≤ P(commit)；快信道不会成为升险路径。
4. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1] + ε_data + δ_t)
             − P(𝓜 陈旧未检出) − P(审计同源) − P(级联认证失真) − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

关键：**数据覆盖给"看不见的世界"记账、anytime 给"来不及的思考"兜底、快信道给"过时的证据"作废**；三者分别对应 H29/H30/H31，且都只经"更保守/更准/更快作废"三个安全通道起作用，不引入任何升险路径。

## 6. 本轮最大风险

**一句话**：覆盖证书本身也是从数据里估出来的——若**审计集与训练语料共享同一个盲区**（审计者也没见过那个缺失的世界），系统会恰好为它看不见的空洞开具"充分"证书，而期限压力又逼它更快地采信缓存与已覆盖证据，于是假覆盖会变成一次又快、又自信、又错误的承诺；必须以独立留出审计、覆盖下界的保守估计、快信道只可否决三重护栏，绝不让"审计"与"训练"看同一份世界。
