# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC / IP-153~160；灵感循环第 2 轮；本轮灵感：「模块化设计」×「数据采集」）

> 第 60 轮的 SGEC 已经把「场景→意图→约束→阻抗→执行→EV-exec→场景」闭合成环，并用 EPIR 处理了 ROS 的乱序与丢包。但它仍把闭环当成一个**单体系统**，并假设数据会「自然产生」。由此暴露三个结构性缺口：
> 1. **安全责任不可分离**：SSM 固定 N 个场景、单一 Kalman 后验、全局阻抗先验；新增一个场景或替换一个识别器，必须整体重训、整体重验证。系统无法回答「这次退化是哪个模块造成的」，也无法只替换一个零件而不动整张安全证书。
> 2. **数据采集是执行副产物**：EV-exec 只在任务已经发生时被动产生，数据分布由「已经走过的场景」决定。湿滑楼梯、玻璃隔板、弱摩擦桌面这类**低频但高后果**的场景被系统性欠采样，导致先验在最需要它的地方最不靠谱——这不是模型容量问题，而是**取证分布问题**。
> 3. **数据没有护照**：模块用了哪批数据、什么标定、多旧、覆盖哪些场景，全部不可审计。一个模块的分布漂移会通过共享先验污染其它模块，事后也无法区分「模块错了」还是「数据脏了」。
>
> 一句话先押注：
>
> **第 60 轮解决「闭环怎么转」，本轮解决「闭环由哪些可独立证明的零件组成、燃料从哪里来」——提出模块化主动数据闭环 MODAC：用模块能力契约 MCC 把每个能力变成可局部验证的安全责任单元，用模块组合代数 MCA 在接口处保持安全，用主动数据采集 ADA 把采集变成「面向约束相关不确定性」的安全探针，用数据护照 DPP 让每条样本可追溯，用模块化数据飞轮 MDF 让更新局部化、可回滚，最后用模块化安全证书 MSC 把「模块版本 + 数据来源 + 接口裕度」绑成一张可审计证书。核心命题：安全不能靠单体模型的整体重训，而要靠「可组合的局部安全 + 面向接口盲区的主动取证」。**

## 0. 直觉与动机

**灵感 1（模块化设计 → 能力模块与契约 MCC）**
直觉：模块化不是把代码拆成几个文件，而是把**安全责任拆成可独立证明的单元**。航空业的 LRU（航线可更换单元）之所以能热替换，不是因为零件小，而是因为每个零件都有明确的接口、环境假设、性能保证和失效边界。机器人能力也应如此：场景识别器、意图映射器、阻抗编译器各自声明「我在什么输入域内能保证什么」，一旦输入越界就返回保守底 `⊥`，**绝不外推**。关键洞见：**能力域 Π_i 与保守底 ⊥ 是模块化的安全前提**；没有它们，模块化只是把单体故障拆成分布式故障。

**灵感 2（模块化设计 → 组合安全代数 MCA）**
直觉：两个各自正确的模块拼在一起，完全可能整体失效——因为模块 1 的输出保证可能不满足模块 2 的输入假设。真正要管的不是模块内部的正确性，而是**接口处的裕度**：`m_ij(x) = dist(G_i(x), ∂A_j)`，即模块 i 的保证离模块 j 的假设边界还有多远。关键洞见：**组合只在「保证 ⇒ 假设」成立时合法；接口裕度最薄的地方，就是数据采集最该去的地方**。这把「模块化设计」和「数据采集」第一次真正缝在了一起：采集不是按模块平均分配，而是按接口盲区分配。

**灵感 3（数据采集 → 约束相关的主动取证 ADA）**
直觉：被动采集像「等病人自己来医院」，主动采集像「按风险筛查」。但主动采集不能乱试——探测动作本身可能撞坏东西。所以我们只允许**已被当前执行证书 J_exec 覆盖的安全探针**：改变视角、做一次受控轻触、请求一次人类标注。采集目标也不是「最大化信息熵」这种通用指标，而是**最大化对当前安全约束最有影响的那个参数的信息增益**：如果系统怕的是摩擦系数 μ，就去测 μ，而不是去测无关的振动频谱。关键洞见：**采集的价值 = 对约束的信息增益 − 探针风险成本；先证明探针安全，再谈采集收益**。

**灵感 4（数据采集 → 数据护照与数据契约 DPP）**
直觉：安全先验的每一分置信，都应该能追溯到「哪条样本、哪次标定、哪个场景格、什么时候过期」。给每条样本发一本护照：来源、标定版本、场景覆盖格、测量不确定度、前序哈希、许可与有效期。模块在训练前先声明数据契约：需要多少样本、覆盖哪些格、标定误差上限、最大数据年龄、允许的分布漂移。关键洞见：**没有护照的数据不得进入安全先验；过期或越界的数据不是「稍微不准」，而是「不可用于签发证书」**。

**灵感 5（合流 → MODAC + PCE⁶ + MSC）**
直觉：模块化让更新可以局部化：只重训能力赤字最大的模块，只回归它所在的那条组合路径，只在 canary 通过后替换，失败就回滚到上一张证书。数据采集为这个飞轮提供「定向燃料」：优先采接口裕度薄、能力赤字大、且探针安全的区域。最后 MSC 把模块版本向量、数据护照根、接口最小裕度、残余风险和回归编号绑在一起，任何一项不满足就 fail-closed 回退到已验证的单体安全配置。形成闭环：**执行→审计能力赤字→安全探针→护照入库→局部更新→组合回归→证书替换/回滚**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（模块能力契约 MCC）** 能力模块 `μ_i = (S_i, A_i, G_i, Π_i, Δ_i, E_i, ⊥_i)`。其中：
- **端口签名** `S_i = (In_i, Out_i)`：带单位、坐标系、频率、取值范围约束的类型化端口。
- **环境假设** `A_i(x)`：模块可被使用的环境前提（如「力传感器已标定」「点云时间戳对齐误差 ≤ δ_T」）。
- **输出保证** `G_i(x, y)`：在 `x ∈ Π_i` 且 `A_i(x)` 成立时，输出 `y` 必须满足的安全/性能谓词。
- **能力域** `Π_i ⊆ In_i`：保证成立的输入域；`Π_i` 之外不得外推。
- **数据契约** `Δ_i`：训练/校准该模块所需的数据充分条件（见定义 164）。
- **证据义务** `E_i`：模块必须产出的证据（测试覆盖、标定记录、回归编号）。
- **保守底** `⊥_i`：能力域外的安全输出；`x ∉ Π_i ⇒ y = ⊥_i`，并触发上层降级。
- **良构性**：`G_i` 只在 `Π_i` 上可证；任何 `Π_i` 外的行为不进入安全证书。

**定义 162（模块组合代数 MCA）** 给定模块 `μ_1, μ_2`，若端口类型可统一，且
```
∀x ∈ Π_1 ∩ Π_2:  A_1(x) ∧ G_1(x) ⇒ A_2(x)
```
则组合 `μ_12 = μ_1 ⊕ μ_2` 合法，其能力域 `Π_12 = Π_1 ∩ Π_2 \ F_12`，其中 `F_12` 为接口契约失效集。定义：
- **接口裕度** `m_12(x) = min_{c ∈ C_12} (G_1^c(x) − A_2^c(x))`，即每个接口约束上的最小松弛；`m_12(x) ≥ m_min` 才允许在线组合。
- **精化序** `μ' ⊑ μ`：`Π' ⊇ Π`、`A' ⇐ A`、`G' ⇒ G`，即新模块在更大输入域上提供更强保证。
- **组合证书** `Cert(μ_12) = (Cert(μ_1), Cert(μ_2), m_12, hash(接口))`；组合安全由局部证书 + 接口条件归纳得到，而不是重新证明整条链路。
- 组合满足**结合律**但不满足交换律（数据流方向与接口假设有方向性）。

**定义 163（主动数据采集 ADA）** 设安全证书当前绑定参数为 `φ`（如摩擦 μ、场景身份 z、意图 I、阻抗边界 K），信念为 `b_t`，候选采集动作 `a ∈ 𝒜`（受控轻触、改变视角、请求标注、重放历史）：
- **约束相关信息增益**：`IG_c(a|b) = H_b(φ) − E_{o∼p(o|b,a)}[H_{b'}(φ)]`，只对**当前证书真正依赖的约束**计信息，不做通用熵最大化。
- **采集成本**：`c(a) = λ_e·Energy(a) + λ_t·Time(a) + λ_s·Storage(a) + λ_r·Risk(a)`。
- **安全探针集**：`𝒜_safe = {a | J_exec(a) 有效 ∧ ResidualRisk(a) ≤ R_max}`；探针必须在执行证书覆盖范围内。
- **采集策略**：`a* = argmax_{a∈𝒜_safe} [IG_c(a|b) + λ_cov·CoverageGain(a) − c(a)]`；当 `max ≤ 0` 时停止采集，转入保守利用。
- **不可采条件**：若最优探针的残余风险上界超过 `R_max`，即使信息增益再大也不采；宁可不学，不可冒险。

**定义 164（数据护照与数据契约 DPP）** 样本护照 `p = (x, y, τ, src, calib_id, cell, u, hash_prev, license, expiry)`：观测、标签、时间戳、来源、标定版本、场景覆盖格、测量不确定度、前序哈希、许可范围、有效期。数据契约
```
Δ_i = (Cov_i, ε_cal, T_fresh, N_min, W_shift, Scope_i)
```
- **接受谓词** `Accept(p, Δ_i)`：覆盖格满足 `Cov_i`、标定误差 ≤ `ε_cal`、数据年龄 ≤ `T_fresh`、样本数 ≥ `N_min`、分布漂移 ≤ `W_shift`、使用范围符合 `Scope_i`。
- **隔离**：不满足的样本进入 quarantine，不参与训练，但可用于告警。
- **可审计性**：所有进入 MSC 的参数必须能沿 `hash_prev` 链回溯到被接受的护照；链断即视为不可信。

**定义 165（模块化数据飞轮 MDF 与能力赤字）** 模块 `μ_i` 的能力赤字
```
δ_i = E_{x∼Π_i}[1 − success_i(x)] + λ_u·Uncertainty_i(Π_i)
```
接口赤字 `δ_ij = E_{x∼∂Π_i∩∂Π_j}[(m_min − m_ij(x))_+]`。采集优先级 `w_i = δ_i + λ_int·max_j δ_ij`。局部更新 `θ_i' = Learn(θ_i, D_new ∪ Replay(D_old))`，且必须通过三道门：
1. **局部重证**：`Cert(μ_i')` 在 `Π_i'` 上重新成立；
2. **组合回归**：`μ_i'` 所影响的组合路径全部通过回归套件，且接口裕度不下降；
3. **Canary**：小流量替换，监控风险不超基线。
任一门失败则回滚到上一张 MSC；更新只允许改变受影响的那一个割集，避免全局灾难性遗忘。

**定义 166（模块化主动数据闭环 MODAC）** 算子 `MODAC(M, task)`：
```
① Snapshot: 固化模块图 G=(V,E)、模块版本向量 v、当前 MSC
② Execute:  用 SGEC 闭环执行一步，采集 EV-exec / EV-scene
③ Audit:    计算各模块 δ_i、各接口 δ_ij；定位能力赤字最大的模块/接口
④ Check:    若输入越出 Π_i 或契约失效 → 输出 ⊥，回退已验证单体配置
⑤ Probe:    ADA 在 𝒜_safe 中选择探针 a*（J_exec 覆盖）
⑥ Collect:  执行 a*，生成数据护照 p；Accept(p) 失败则隔离并告警
⑦ Update:   θ_i' ← Learn(θ_i, p ∪ replay)；局部重证
⑧ Compose:  MCA 检查接口裕度；组合回归；签发新 MSC
⑨ Deploy:   Canary 替换；风险超阈则回滚；更新数据账本
⑩ Return:  (决策, MSC, 护照账本, 赤字报告)
```

**定义 167（六维模块-数据预算 PCE⁶）** `B_md = (B_scene, B_intent, B_ros, B_exec, B_mod, B_data)`：
- `B_mod = (Swap_budget, Verify_budget, Interface_margin_min, Rollback_budget)`：热替换次数、组合验证算力、接口裕度下限、回滚预留。
- `B_data = (Probe_budget, Label_budget, Bandwidth, Storage)`：安全探针次数、人工标注配额、数据带宽、护照存储。
- **VOI**：`voi_md(π) = VOI_meta(π) − cost_cog − cost_exec − cost_mod − cost_data`，其中 `cost_mod = λ_swap·Swap + λ_ver·Verify + λ_m·(m_min − m_12)_+`，`cost_data = λ_p·Probe + λ_l·Label + λ_bw·Bandwidth`。
- **降级阶梯**：`B_data` 耗尽 → 冻结学习、回退第 60 轮「通用场景先验」；`B_mod` 耗尽 → 冻结模块图、回退已验证单体配置；`B_scene/B_intent/B_ros/B_exec` 沿用第 60 轮策略。**任何降级只收缩安全集与证书置信，绝不扩大可行动作集，绝不把未验证模块放进证书。**

**定义 168（模块化安全证书 MSC）** `MSC = (v, contract_status, data_root, m_min^obs, residual_risk, regression_id, valid)`：
- `v`：模块版本向量；`contract_status`：每个模块 `(A_i,G_i,Π_i,Δ_i)` 的满足位。
- `data_root`：所有相关护照的 Merkle 根；`m_min^obs`：组合路径上观测到的最小接口裕度。
- **有效性**：`Valid(MSC) ⟺ 所有 contract_status 满足 ∧ data_root 可追溯且未过期 ∧ m_min^obs ≥ m_min ∧ 无未验证模块 ∧ regression_id 通过 ∧ residual_risk ≤ R_max`。
- **绑定**：MSC 与第 60 轮 `J_exec`、EV-exec 链通过 `(task_id, episode, chain_root, v, data_root)` 绑定；任一方失效则执行证书 fail-closed。

## 2. 关键算法伪代码

### IP-161/162 MCC + MCA（契约与组合）

```python
@dataclass
class ModuleContract:
    name: str
    sig_in: tuple
    sig_out: tuple
    assume: Callable          # A_i(x)
    guarantee: Callable       # G_i(x, y)
    competence: Callable      # Π_i(x)
    data_contract: "DataContract"
    evidence: list
    bottom: object = BOTTOM

def check_contract(mu, x, y=None):
    if not mu.competence(x):
        return mu.bottom, "OUT_OF_COMPETENCE"
    if not mu.assume(x):
        return mu.bottom, "ASSUMPTION_VIOLATED"
    if y is not None and not mu.guarantee(x, y):
        raise ContractViolation(mu.name)
    return y, "OK"

def interface_margin(mu1, mu2, x):
    return min(g - a for g, a in zip(
        mu1.guarantee_slack(x), mu2.assume_slack(x)))

def compose(mu1, mu2, m_min=0.05):
    assert types_unify(mu1.sig_out, mu2.sig_in)
    region = intersect(mu1.competence, mu2.competence)
    if not implies_on(mu1.guarantee, mu2.assume, region):
        return None
    m = lambda x: interface_margin(mu1, mu2, x)
    if min(m(x) for x in sample(region, n=256)) < m_min:
        return None
    return ComposedModule(mu1, mu2, region, m,
                          cert=(mu1.cert, mu2.cert, "compose"))
```

### IP-163 ADA（约束相关主动采集）

```python
def select_probe(belief, graph, budget, safe_actions):
    target = binding_parameter(graph)          # 证书真正依赖的 φ
    best, best_score = None, -1e9
    for a in safe_actions:                     # 已由 J_exec 覆盖
        if budget.cost(a) > budget.remaining(a.type):
            continue
        ig = monte_carlo_info_gain(belief, a, target)
        cov = coverage_gain(a, graph.deficit_cells())
        score = ig + LAMBDA_COV * cov - budget.cost(a)
        if score > best_score:
            best, best_score = a, score
    return best if best_score > 0 else None
```

```python
def accept(passport, contract):
    return (covers(passport.cell, contract.Cov) and
            passport.calib_err <= contract.eps_cal and
            age(passport) <= contract.T_fresh and
            passport.n >= contract.N_min and
            drift(passport) <= contract.W_shift and
```

### IP-165/166 MDF + MODAC（飞轮与闭环）

```python
def modac_step(M, task):
    graph = M.graph.snapshot()
    ev = M.sgec_step(task)                      # 复用第 60 轮闭环
    deficits = audit_deficits(graph, ev)
    ok, why = check_all_contracts(graph, M.state)
    if not ok:
        return fallback_monolith(M, why)        # fail-closed

    target = argmax_priority(deficits, graph)
    if target is None:
        return M.decision, M.msc, M.ledger, deficits

    a = select_probe(M.belief, graph, M.budget.B_data,
                     M.safe_actions())          # 探针安全
    if a is None:
        M.freeze_learning()
        return M.decision, M.msc, M.ledger, deficits

    p = make_passport(M.execute(a))
    if not accept(p, target.mu.data_contract):
        M.quarantine(p)
        return M.decision, M.msc, M.ledger, deficits

    cand = local_update(target.mu, p, replay=graph.replay(target))
    if not local_reverify(cand):
        return rollback(M, cand)
    if not composition_regression(cand, graph):
        return rollback(M, cand)
    msc = issue_msc(cand, graph, p)
    if not msc.valid:
        return rollback(M, cand)
    canary_deploy(cand, msc, budget=M.budget.B_mod)
    M.ledger.append(p)
    return M.decision, msc, M.ledger, deficits
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MCC | O(1)/次契约检查；O(\|A\|+\|G\|) 编译 | O(\|模块\|) | 能力域外必返回 ⊥，不外推 |
| MCA | O(k²) 两两接口检查（DAG 上可 O(k)） | O(k²) 接口矩阵 | 保证 ⇒ 假设时组合证书可归纳 |
| ADA | O(\|𝒜\|·IG 估计)（Thompson 采样 O(\|𝒜\|)） | O(\|𝒜\|·粒子数) | 探针 ∈ 𝒜_safe ⇒ 不突破执行安全包络 |
| DPP | O(1) 哈希 + O(log N) 索引 | O(N) 护照 | 链断/过期/越界数据不可入证 |
| MDF | O(局部更新 + 回归) | O(回放池) | 三道门失败 ⇒ 回滚 |
| MODAC | O(T·(审计 + 探针 + 回归)) | 复用 + 护照账本 | 任一契约失效 ⇒ 单体回退 |

**正确性定理（MODAC）**：假设 A22–A65 与第 60 轮假设成立；新增 **(A66)** 每个 `μ_i` 的 `(A_i,G_i)` 在 `Π_i` 上可靠，能力域外返回 `⊥`；**(A67)** 组合条件 `A_1∧G_1⇒A_2` 在 `Π_1∩Π_2` 上成立；**(A68)** 所有探针 `a∈𝒜_safe` 均被当前 `J_exec` 覆盖；**(A69)** 护照校验与哈希链可靠；**(A70)** 更新必须通过局部重证、组合回归与 canary；**(A71)** 六维预算单调消耗。则：

1. **组合安全保持**：若模块图中每条边满足 (A67)、每个节点满足 (A66)，且 `Valid(MSC)`，则组合系统在 `∩Π_i` 上不产生任何局部保证之外的行为；归纳于 DAG 拓扑序可证。
2. **采集不破坏安全**：由 (A68)，任何数据采集动作执行时 `J_exec` 仍有效；故「主动采集」不能成为新的不安全来源。
3. **数据来源健全**：由 (A69)，进入 MSC 的每个参数都可沿护照链回溯到被 `Accept` 的样本；污染/过期/越界数据无法影响证书置信。
4. **更新有界**：由 (A70)，局部更新只能改变受影响割集；任一门失败即回滚，旧场景性能不因新数据发生无界漂移。
5. **降级安全**：由 (A71)，任一元预算耗尽只触发「冻结学习/冻结模块图/单体回退/保守先验」，不扩大安全集。

```python
@dataclass
class ModuleContract:
    name: str
    sig_in: tuple
    sig_out: tuple
    assume: Callable          # A_i(x)
    guarantee: Callable       # G_i(x, y)
    competence: Callable      # Pi_i(x)
    data_contract: "DataContract"
    evidence: list
    bottom: object = BOTTOM

def check_contract(mu, x, y=None):
    if not mu.competence(x):
        return mu.bottom, "OUT_OF_COMPETENCE"
    if not mu.assume(x):
        return mu.bottom, "ASSUMPTION_VIOLATED"
    if y is not None and not mu.guarantee(x, y):
        raise ContractViolation(mu.name)
    return y, "OK"

def interface_margin(mu1, mu2, x):
    return min(g - a for g, a in zip(
        mu1.guarantee_slack(x), mu2.assume_slack(x)))

def compose(mu1, mu2, m_min=0.05):
    assert types_unify(mu1.sig_out, mu2.sig_in)
    region = intersect(mu1.competence, mu2.competence)
    if not implies_on(mu1.guarantee, mu2.assume, region):
        return None
    m = lambda x: interface_margin(mu1, mu2, x)
    if min(m(x) for x in sample(region, n=256)) < m_min:
        return None
    return ComposedModule(mu1, mu2, region, m,
                          cert=(mu1.cert, mu2.cert, "compose"))
```

## 3. 一个具体推导：为什么「模块都正确」不等于「组合安全」

设场景识别模块 `μ_1` 的保证是「阻抗先验均值误差 ≤ 0.1」（归一化单位），阻抗编译模块 `μ_2` 的假设是「先验均值误差 ≤ 0.05 才允许收窄 K_safe」。各自单独测试都通过，但接口裕度为
```
m_12 = G_1 − A_2 = 0.1 − 0.05 = 0.05
```
若 `m_min = 0.05`，恰好贴边；此时若 `μ_1` 在湿滑场景的误差上界因分布漂移变成 0.12，则 `m_12 = −0.02 < 0`，组合失效，但两个模块的单元测试仍然全绿。更危险的是：如果数据采集只覆盖 `μ_1` 的常见场景，`μ_1` 的**平均**误差仍为 0.08，看起来「合格」，而 `Π_1∩Π_2` 内最薄的那一格（湿滑边界）没有任何样本。于是组合证书在「所有模块都通过」的表象下失效。

因此本方案把三条约束写进 MSC：
1. `m_min^obs` 必须由**接口处的样本**估计，而不是模块内部平均误差；
2. ADA 的 `CoverageGain` 以 `1/m_ij` 加权，优先采集接口薄处；
3. 任一新模块替换后，必须在该割集上重跑组合回归，否则 MSC 直接 `valid=false`。

**数值示例（VOI 选点）**：候选探针 `a_1`（轻触测摩擦）使 `H(μ)` 从 0.8 降到 0.3 nat，风险成本 0.1；`a_2`（多拍一帧点云）使 `H(μ)` 从 0.8 降到 0.7 nat，成本 0.05。则
```
IG_c(a_1)=0.5, score=0.5−0.1=0.4
IG_c(a_2)=0.1, score=0.1−0.05=0.05
```
选 `a_1`；若 `a_1` 的残余风险上界超过 `R_max`，即使 0.4 > 0.05 也不得执行，退回 `a_2` 或停止采集。这条规则防止「为了学习而主动制造危险」。
