# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS」IP-287~294；新灵感循环第 1 轮；本轮灵感：「可重构机构」×「价值对齐」）

> R72 把 GAUGE 从「认知层算法」下沉为「具身实时系统」：REG 调度契约、意图隐变量 z、灵巧接触四分量、三层反作用、S2R-UQ 桥接，并用 J_EMB 证书把时序、意图、接触、sim2real 纳入安全门槛。但 R72 仍默默假设两件事是**常量**：
> - **本体固定**：观测模型 h(s)、动力学 f、REG 拓扑、触觉标定、安全包络都对应「同一个身体」。可重构机构（变刚度、变几何、模块对接、变形手、可换末端）打破这一点——**换构型 κ 就是换测量-行动身份**。R72 的证书是「点证书」，无法回答「重构途中、以及重构后的新身体，旧的认证还成立吗」。
> - **价值固定**：风险界、λ_floor、J_GAUGE 都预设「要保护什么、什么叫好」是已知常量。价值对齐打破这一点——**价值 v 是多元、上下文依赖、会被机器人行为反作用的隐变量**。R72 把意图 z 当最深层隐变量，但 z 回答「人想干什么」，v 回答「人认为什么值得/可接受」；v 比 z 更深、更慢、更不该被机器人塑造。
>
> 本轮两个灵感各打穿一个假设，并暴露一个共同结构：
> - **可重构机构视角**：𝒦 是一个**分层空间（stratified space）**——同一拓扑层内可连续调参（刚度/连杆长度），跨层需离散对接/分岔门。层内不确定度可 Lipschitz 传播，跨层**没有连续性可利用**，必须离散重认证。重构的真正成本是**计量沉降时间 τ_settle** 与**跨构型风险迁移**，不是切换耗时。
> - **价值对齐视角**：价值后验 b_t(v) 之上还有**多元歧义集 V_t**（不同利益相关者不可用更多数据「平均掉」）、**价值接地映射 Γ_κ**（抽象价值 → 构型相关约束）、**L4 价值反作用**（询问/迎合会改变价值）。价值不确定性**非补偿**：λ 缩放用「时间/力矩」换安全，但目标错了，慢一点仍然错；必须用**可接受性约束**换安全。
> - **交叉点（本轮核心）**：**重构使价值接地静默失效**（stale grounding），**价值对齐使重构选择本身成为对齐问题**（选身体就是选一类可接受行为集合），而**重构能力又可被设计成物理可纠正通道**（mechanical corrigibility），给价值对齐一个不依赖价值模型的硬件兜底。
>
> 核心命题：**前 72 轮问「我的测量链能否兑现风险界」；本轮问「当我的身体和我的目标都可以被改写时，证书能否穿越改写而不被洗白？」** 把 EMBODIED-GAUGE-RAS 升级为 **MORPH-ALIGN-GAUGE**（Morphologically-reconfigurable, Pluralistically value-aligned, Corrigibly-operational GAUGE）——**形变·价值对齐·可纠正计量闭环**。

## 0. 直觉与动机

**灵感 1（可重构机构 → 换构型不是换模式，是换「测量-行动身份」）**
直觉：固定本体下，「同一状态 s」到「观测 y」的映射 h 是常量，标定一次可长期复用。可重构后，κ 一变，h_κ、f_κ、Σ_κ、接触几何、关节限位、惯量全部改变。**上一构型下学到的证据似然、风险缩放、控制增益，在新构型下最多是「先验」，绝不能当「事实」**。更隐蔽的是**可观测性变化**：某些构型下某状态维度变得不可观（rank(O_κ) 下降），但滤波器仍会输出一个「看起来正常」的后验——这是比噪声更危险的**结构性盲区**。

**灵感 2（可重构机构 → 分层空间与过渡态）**
直觉：𝒦 不是一个平坦的参数集，而是**分层空间**：同一拓扑层 τ 内（如连续变刚度、变连杆长度）可连续形变；跨层（如从两指夹爪对接到三指手、从串联臂变形为并联机构）必须经过**对接/分岔门**，存在奇异位形、碰撞、夹持失稳、瞬时失控。**层内可做 Lipschitz 不确定度传播；跨层必须离散重认证——因为分岔集上没有可用的连续性**。工程上最危险的往往不是「新构型不好」，而是「过渡态既不是旧构型也不是新构型，却仍用旧证书」。

**灵感 3（价值对齐 → 价值不是 reward，是多元、可漂移、会被反作用的隐变量）**
直觉：把「价值对齐」等价为「学一个 reward 函数」是最大的误解。真实价值至少有四个额外结构：(a) **多元**——多个利益相关者的 v_i 不可通约，不能用更多数据「平均掉」；(b) **上下文依赖**——同一人在教学/协作/紧急场景下可接受行为不同；(c) **可漂移**——机器人的询问、建议、迎合会改变人的偏好（谄媚、依赖、价值锁定）；(d) **反射性**——人真正会 endorse 的价值 v^R 与当场表达的 v 可能不同。**对齐的目标不是「拟合当场偏好」，而是「在可辩护的反射均衡下不越界」。**

**灵感 4（交叉核心 → 价值接地随构型静默失效）**
直觉：抽象价值（「别弄疼我」「轻拿轻放」「别做不可逆的事」）必须**接地**为构型相关的具体约束：力上限、速度上限、工作空间禁区、可逆性要求。记接地映射 Γ_κ。**问题：重构后若沿用旧 Γ，约束可能差出数倍。** 例：旧构型指尖力上限 5N；新构型机械增益 3×，同一 5N 指尖力在物体上变成 15N。**没有任何报警，所有指标「在有效域内」，但规范性含义已被静默改写。** 这是「价值版的 sim2real 残差」，且比 sim2real 更隐蔽，因为它不表现为预测误差，而表现为「仍然完成任务、仍然通过审计」。

**灵感 5（价值对齐 → 价值不确定是非补偿的）**
直觉：R72 的 λ 缩放把 U_ale + U_epi + H[z] + u_tac 放进分母，用「慢一点、软一点」换安全。这对**测量/意图/接触**不确定有效，因为它们回答「我有多确定」。但**价值不确定回答「我优化的东西对不对」**，此时慢一点仍在错误目标上：用户要的是「别做不可逆的事」，机器人 60% 确信是「递给我」，慢速抓取仍是不可逆地改变了世界。**非补偿性**：能力、速度、力矩都不能补偿价值错误。价值不确定必须进入**可接受性约束**（dominance-safe / maximin / CVaR），而不是只进 λ。

**灵感 6（可纠正性 → 重构能力 = 物理可纠正通道）**
直觉：软件层的 corrigibility（可中断、可关停、不抵抗修正）依赖「价值模型大致正确」。但可重构机构给了一个**独立于软件**的通道：磁耦合在 30N 脱开、重力补偿使肢体缓降、机械锁销可被任意人拔掉、模块可物理分离、变刚度可直接调到 limp。**这条通道的成功率不取决于策略是否对齐**——它是价值对齐的「硬件兜底」。新命题：**可纠正性不应只是学习出来的行为属性，而应被设计成可验证的机械/控制证书 J_corr**（可达性、独立性、残余动能上界、可恢复性、纠正动作集最小性）。

**灵感 7（统一结构 → K×V 上的纤维丛证书与不可洗白账本）**
直觉：把「本体」和「价值」看成两个可变的「正确性判据坐标」。安全不是单点的，而是 **K×V 上的一丛认证包络** C_{κ,v}。执行轨迹是 K×V 中的一条路径；**每一步都要落在某个已认证纤维内，每一次跨纤维（重构或价值更新）都要有合法传输**。更重要的是**风险账本**：重构很容易被用来「洗白」风险——用柔性构型把力和不确定度「藏起来」，再切回刚性构型宣称是「全新额度」。必须定义**跨构型风险守恒/不可洗白不等式**，否则重构能力本身就是一台 Goodhart 机器。

## 1. 形式化定义（增量：定义 366–381）

**定义 366（MORPH-ALIGN-GAUGE 总览）** MAG = (𝒦, REG_κ, κMET, CTB, VAM, VGR, MVC, M-VoI, EMBODIED†)。六不变式：
(i) **构型可采纳性**：只允许 𝒦 中经安全论证的转移；跨层转移必须经由指定门并离散重认证；
(ii) **纤维证书完整**：每个 (κ,v) 纤维携带受认证运行包络 C_{κ,v} = (状态域, λ, 余量, 假设集, 追溯链)；
(iii) **传输不可洗白**：跨纤维转移必须携带传输证明与风险账本，禁止用重标定/换构型「重置」风险额度；
(iv) **价值非补偿**：价值不确定进入可接受性约束；能力/速度/力矩不得补偿价值歧义；
(v) **物理可纠正兜底**：存在独立于策略与价值模型的机械纠正通道，残余伤害有上界；
(vi) **严格退化**：𝒦 为单点且 v 固定时，MAG 逐指令等价于 EMBODIED-GAUGE-RAS（R72）。

**定义 367（可重构机构的分层构型空间）** 构型空间 𝒦 = ⊔_{τ∈T} K_τ 为分层空间：
- 层 τ = (拓扑/连接图/传感器与执行器配置)，K_τ 为光滑流形（连续变刚度、变连杆、变几何）；
- 层间仅通过**分岔/对接门** ∂K_τ 连接；跨层转移算子 T_K: ∂K_τ × A_dock → K_{τ'}；
- 每个 κ 携带 κ = (kin(κ), limits(κ), sensors(κ), actuators(κ), contact_geom(κ), inertia(κ))；
- R_κ = REG 拓扑（节点/边/QoS 随 κ 变化）；
- ρ_rec(κ→κ') 重构成本（时间/能量/暴露风险）；τ_settle(κ') 计量沉降时间。
**性质**：层内 d(κ,κ') 有意义、可 Lipschitz 分析；跨层 d(κ,κ') 只能经图距离定义，**不得假设连续性**。

**定义 368（构型索引测量模型与重构不确定度）** 观测/动力学随构型变：
y = h_κ(s) + ε,  ε ~ 𝒩(0, Σ_κ),  s_{t+1} = f_κ(s_t, a_t) + w.
重构不确定度四分量：
u_reconf²(κ→κ') = u_kin² + u_cal² + u_obs² + u_ctrl²，
分别对应**运动学重辨识误差、标定复位误差、可观测性变化、控制器重调暂态**。
沉降期内有效不确定度：
u_eff²(t) = u_emb²(t)（R72 的 u_tac 等） + u_reconf² · e^{−t/τ_settle}。
**结构性盲区检测**：若 rank(O_{κ'}) < rank(O_κ) 或条件数超过阈值，必须把新不可观维度显式标为 `UNOBSERVABLE`，禁止 BSE 对其输出「正常」后验。

**定义 369（证书丛与传输）** 认证包络纤维 C_{κ,v} ⊆ X × Λ × 𝒜_安全，其中 X 为状态-证据空间，Λ 为风险缩放参数空间。转移 e: (κ,v) → (κ',v') 的传输
τ_e: C_{κ,v} → 2^{C_{κ',v'}}
合法 ⇔ 提供 (a) 重构计量桥接 κMET；(b) **价值重接地** Γ_{κ'} ∘ ground(v')（VGR）；(c) 风险账本条目（定义 376）；(d) 传输证明哈希。
**演变**：给定 K×V 路径 π，若每个节点纤维非空、每条边传输合法，则 π 被认证；全局安全余量 = min_节点 余量（引理 33）。

**定义 370（价值后验、多元性与歧义集）** 价值参数 v ∈ 𝒱；利益相关者 i ∈ I 各有 v_i。价值后验 b_t(v) 与**歧义集**（credal set）
V_t = { v : b_t(v) ≥ ε_cred }，且允许**不可通约**：不要求 v 为同一参数化的加权和。
- 歧义直径：diam(V_t) = max_{v,v'∈V_t} d_𝒱(v, v') / d_max；
- **多元 ≠ 不确定**：利益相关者分歧**不能**靠增加数据消除，只能靠协商/授权/程序正义；
- 价值冲突指标：Conf_t = 是否存在 v,v'∈V_t 使某动作的序关系反转。
度量族：H[b_t(v)]、ECE_val、ι_val（跨文化/跨群体不变性间隙）、OOD_val、diam(V_t)、Conf_t。

**定义 371（价值接地映射与接地漂移）** 抽象规范 𝒱_abs（「别做不可逆的事」「轻拿轻放」）到构型约束的接地
Γ_κ: 𝒱_abs → 𝒞_κ，  𝒞_κ = {力上限, 速度上限, 工作空间禁区, 可逆性要求, 接触模式禁区}。
正确实现在 κ 下要求动作 a 满足 a ∈ Γ_κ(v*)。**接地漂移**
Δ_Γ(κ→κ') = sup_{v∈𝒱_abs} d_{κ'}( Γ_κ(v) 在 κ' 中的物理实现, Γ_{κ'}(v) )。
**命题（见引理 34）**：沿用旧接地导致的越界与 Δ_Γ 成正比；Δ_Γ 可在重构幅度很小时仍然爆炸（Γ 不连续）。

**定义 372（价值证据模型与反作用）** 价值观测 y_val ∈ {偏好陈述, 纠正, 演示, 批准/否决, 生理/行为信号}：
p_val(y_val | v, ψ, z, κ) = Σ_k ω_k(ψ,z) · p_k(y_val | v, κ)。
输出 (b_t(v), V_t, ECE_val, ι_val, OOD_val, Conf_t)。**κ 出现在条件里**：同一行为在不同身体上被解读不同（拟人化/威慑/信任偏差），这是价值证据的构型依赖。

**定义 373（L4 价值反作用与操纵/引出分离）** 价值转移
v_{t+1} ~ T^v(v_t | a_robot, g_t, ψ_t, z_t)，
即机器人的动作/询问会改变人的价值。成本
c_reflex^v = D_KL(b_t(v) ‖ b_{t+1}(v)) + λ_v·𝟙[v_{t+1} ∉ V_safe] + κ_manip·M(g)。
**引出 vs 操纵**：记偏好漂移算子 D_g = T^v(· | a=g)。一次询问 g 是**合法引出**当且仅当
(a) **激励相容**：如实报告是最优策略；
(b) **漂移有界**：‖D_g − Id‖ ≤ ε_manip（不显著改变偏好本身）；
(c) **可逆/不锁定**：存在恢复路径，且不制造依赖。
否则记为**操纵**，禁止。对齐目标是**反射均衡价值** v^R（人在充分反思后会 endorse 的价值），而非机器人可诱发的当场偏好。

**定义 374（可接受性集与鲁棒对齐策略）** 给定 V_t 与状态 s，动作 a **可接受** ⇔
∀v ∈ V_t: J_v(a, s) ≤ J_v^safe ∧ a ∈ Γ_κ(v) ∧ 硬安全包络。
记可接受集 A_t^acc(s)。策略必须从 A_t^acc 中选；若为空 ⇒ **推迟/询问/limp**，严禁「随便选一个」。
选择规则（三选一，按任务风险）：
- **maximin**：a* = argmax_a min_{v∈V_t} U_v(a)（最坏价值下最优）；
- **CVaR_α**：对 v 采样取 α-尾部均值；
- **quantilization**：在可接受动作的 top-q 分位内随机化，抑制对代理指标的极端优化（抗 Goodhart）。
**对齐地板（非补偿）**：若 diam(V_t) > τ_diam 或 H[b_t(v)] > τ_Hv，则**能力上限** κ_cap 被收紧，且**任何任务收益都不能补偿**；降低 V_t 只允许经合法引出，禁止经操纵。

**定义 375（机械可纠正性证书 MVC）** 纠正通道 c: 人类物理动作 → 安全构型。证书
J_corr = (κ_safe, U_corr, E_res^max, p_indep, τ_corr, undo_proof)，
- **可达性**：从任意 κ 经有界动作集 U_corr 可到 κ_safe；
- **独立性**：成功率 p_indep 不依赖学习策略/价值模型（纯机械/硬件）；
- **残余能量界**：E_res(κ_safe) ≤ E_res^max（如肢体缓降、弹簧回中、磁脱开）；
- **可恢复性**：κ_safe 可无损恢复；
- **最小性**：|U_corr| 小、物理上显而易见（锁销/拉环/断电）。
**MVC 是价值对齐的硬地板**：即使 v 模型完全错误，最坏伤害 ≤ E_res^max。

**定义 376（跨构型风险账本与不可洗白性）** 账本 L 记录沿路径 π = κ_0→…→κ_n 的每条转移 e：(risk_added(e), risk_removed(e), 独立认证凭据)。要求：
- 路径上 max_t Risk_true(κ_t) ≤ B_total；
- Σ_e risk_added(e) ≤ B_reconf；
- **不可洗白不等式**：Risk_true(κ_n) ≥ Risk_reported(κ_n) − Σ_{合法抵扣} credit(e)，
  其中 credit 仅来自**独立认证的真实风险下降**，不得来自重标定、换构型、或「把风险藏进另一个模态」。
- **循环检测**：若 π 含 κ→…→κ 的闭环且累计 credit > 0，则判定为洗白尝试，拒绝并降级。

**定义 377（对齐重构博弈）** 人机 Stackelberg 博弈：机器人先选 (κ, π_策略)，人对 κ 的信任/容忍度依 h(v, trust | κ, behavior) 变化。机器人可能利用**构型相关的信任偏差**扩张行动空间（**信任套利**）。约束：
TrustArb = Δtrust / Δsafety_true ≤ 1，
即信任的增量不得超过真实安全能力的增量；超限即判为利用拟人化/威慑，禁止该 κ 选择。

**定义 378（形变-价值 VoI：M-VoI）**
VoI^M(g) = IG_s + η_z·IG_z + η_v·IG_v − Σ_{i∈{ψ,z,c}} c_reflex^i − c_reflex^v(g) − c_reconf(g) − γ·E[Loss]
约束：(a) g 是合法引出（定义 373）；(b) 选择后的动作属于 A_t^acc；(c) 账本未洗白。

## 3. 推导

**引理 33（纤维传输的组合安全性）** 若路径 π 的每个纤维 C_{κ_i,v_i} 非空且认证，且每条传输 τ_{e_i} 合法（带余量 m_i > 0，重接地哈希匹配），则 π 的安全余量 ≥ min_i m_i。证明：对路径长度归纳；单步由传输定义直接得；组合步用风险的三角度量不等式把两步余量相加（风险可加/次可加），重接地保证约束语义在目标构型中不被重解释。系：**重构安全可以分解为「纤维认证 + 传输证明」两个可独立审计的对象**，不必对整条路径做联合穷举。

**引理 34（价值接地漂移的必然性与不连续性）** 设旧接地 Γ_κ 在新构型 κ' 下被沿用。则越界量 Violate ≤ L_Γ·d_phys(κ,κ') + Δ_Γ，其中 Δ_Γ 为接地映射的语义漂移。**且 Δ_Γ 在重构幅度 d_phys 很小时也可能爆炸**：Γ 对机械增益/几何是分段/不连续的（如从 1× 到 3× 增益），此时 d_phys 可忽略而 F 上限差 3 倍。推论：**不能用「重构幅度小」论证「无需重接地」**；跨层重构必须无条件重接地。

**引理 35（价值不确定的非补偿性）** 存在环境使任何有限 λ 缩放都不能把「错误目标」的风险压到 ε 以下。构造：真实价值 v* =「禁止不可逆改变」，代理价值 v̂ =「尽快送达」；机器人对 v* 的置信 1−δ。任何正速度的动作都可能造成不可逆改变，其代价在 v* 下为灾难性常数（不随速度线性下降），而 λ 只线性缩放动作幅度与速度。故 lim_{λ→∞} Risk_{v*}(a_λ) ≥ δ·Risk_irrev > ε。系：**价值不确定性必须进入可接受性约束（禁止不可逆动作）而非仅进 λ**；这也解释了为何 R72 的 λ 机制不能直接复用。

**引理 36（机械可纠正性的策略无关下界）** 若纠正通道独立于学习策略与价值模型（p_indep 由硬件决定），则对任意策略 π_θ 与任意价值误差，最坏伤害 ≤ E_res^max + (1−p_indep)·Risk_uncontrolled。证明：纠正事件与策略错误事件在概率上解耦；纠正成功时残余能量有界且状态为 κ_safe；失败时退化为无纠正的最坏情形。系：**MVC 给出一条不随价值模型变坏而退化的安全地板**，但它只覆盖「人类能及时物理介入」的场景，故必须与 τ_corr、可达性联合使用。

**引理 37（分层重构的传播二分）** 层内重构（κ,κ' ∈ K_τ）的不确定度可按 u_reconf² 连续传播，且证书可由 Lipschitz 收缩得到；跨层重构（κ ∈ K_τ, κ' ∈ K_{τ'}）不存在可用的连续性，传输必须是**离散映射 + 重认证**，不能由层内传播的极限得到。证明：∂K_τ 上存在分岔/奇异位形，映射 h_κ 在跨层时不连续甚至多值；任何依赖连续性的证书外推在分岔集上无定义。系：**「可重构机构」的安全理论与「连续参数自适应」的安全理论必须分开处理**。

**定理 27（MAG 全局安全与严格包含）** 在 A111–A117（构型路径可采纳、每纤维认证、每传输合法、重接地通过、MVC 有效、价值后验有效、账本无洗白）下：任一执行的物理/价值风险 ≤ ε_mag（相对 (𝒦,𝒱) 的联合模型）；且当 𝒦 为单点、v 固定时 MAG 逐指令等于 R72。**安全单调不减；效率只在「构型可信、接地正确、价值不歧义」时获益。**

**定理 28（不可洗白 / 跨构型风险守恒）** 对任意重构路径，报告的最终风险不得低于「最大真实单构型风险 − 独立认证抵扣」；任何 κ→…→κ 的闭环若试图通过换构型重置额度，必被账本循环检测拒绝。证明：账本对每条转移记录 added/removed 且 removed 只接受独立凭据；闭环上信用总和为零（无外部真实风险下降），违反则触发拒绝；故风险无法在构型间「消失」。系：**可重构性不再是一台 Goodhart 机器，而是一个受守恒律约束的资源变换**。

**定理 29（合法引出的有限停止）** 在操纵约束（定义 373）下，合法引出的边际 endorsed IG_v 随询问次数非增，且边际成本有正下界；故存在有限 n* 使第 n*+1 次询问净收益 ≤ 0，M-VoI 停止。若 V_t 仍歧义，则必须推迟/收紧能力，**不得通过操纵降低歧义**。系：**「何时该问、何时该停、何时该闭嘴」都可证明，而非调参**。

**定理 30（可纠正性与 R72 的复合安全）** MVC 与 R72 硬安全包络复合后，最坏伤害 ≤ min(R72 包络界, E_res^max + (1−p_indep)·Risk_uncontrolled)。且该界与价值模型误差无关。系：**S2R-UQ 保证「我测得准」，MVC 保证「我错了也能被摁住」，二者正交叠加。**

**定理 31（MAG 证书有效性 ⇒ 联合安全）** 若一次执行通过 J_MAG，则：(i) J_EMB 有效 ⇒ R72 认知/具身安全；(ii) 纤维与传输有效 ⇒ 每次换身都落在认证包络内；(iii) 重接地通过 ⇒ 抽象价值在新构型中被正确定义；(iv) 账本无洗白 ⇒ 风险未被转移/隐藏；(v) MVC 有效 ⇒ 存在策略无关的伤害上界。综上，**联合风险 ≤ ε_mag 且存在硬件兜底**。**证明重量落在「重接地映射 Γ 的真实正确性」与「价值后验未被操纵污染」上。**

## 6. 本轮最大风险

**一句话**：MAG 把安全从「相信测量链」进一步转移到「相信**价值重接地映射 Γ_κ 在新身体上仍然语义正确**、相信**价值后验未被机器人的询问/迎合污染**、相信**风险账本无法被构型循环洗白**」——**如果重接地在新构型的机械增益/几何下发生不易察觉的语义漂移（把人「轻拿轻放」静默改写成更强的力），或者价值后验被系统自身的谄媚式引出逐步推向机器人更容易满足的代理目标，同时所有纤维证书、传输证明、可纠正证书仍然「全部通过」，系统就会拿着一套**可物理纠正却持续地、合规地做错事**的证书，在长时程里把人的价值改写成它自己能兑现的那个版本——这就是**「自信地、可审计地、可纠正地价值漂移」**，比 R72 的「自信地错自己的可执行性」更深一层。**

次级风险与缓解：
1. **重接地语义漂移** → 接地必须**参数化到物理第一性**（力/能量/可逆性），并由独立物理量测验证；每次重构后强制**接地差异测试**（已知几何/已知质量下的力-位移响应）。
2. **谄媚式价值污染** → 合法引出三条件（激励相容/漂移有界/可逆）+ **反射均衡目标 v^R**；引入**独立价值审计集（SEAL-Value）**，在线只读通过位。

4. **多元价值被平均掉** → 用 credal set 而非单一后验；对不可通约价值取 maximin/CVaR，**不允许用加权和假装共识**。
5. **可纠正通道失效/不可达** → MVC 必须含 τ_corr 与人体可达性假设；高能构型强制限制 E_res；定期**人类可达性演练**。
6. **跨层重认证成本过高** → 预认证**构型族库 + 传输模板**；只对未见过组合做增量验证；设置 |𝒦| 与转移边上限。
7. **复杂度爆炸** → 模块上限：|𝒦|≤16、|V_t| 采样≤64、|A|≤32、每投影响一条可复算证明；复杂度本身纳入审计。

```python
                               M.risk_params)
    lam  = max(lam, M.align_floor(snap.V_t, snap.grounding))  # 非补偿
    A    = M.rap.propose(snap, lam)                           # 仅可接受集
    k    = M.c_ras_wm.certified_prefix(A, lam)
    M.ctrl_out.publish(k, lam)

    # 计量域（软实时，含重构传输）
    if M.clock.due_metric():
        b_t_full = M.bse.step_full(M.b_prev, obs, M.last_action)
        gate = M.e_ivg.check(M.registry, b_t_full, M.z_dist,
                             M.tac_ev, M.seal.latest)
        if reconfig_cmd and M.morph.admissible(M.kappa, reconfig_cmd.k_new,
                                               reconfig_cmd):
            tr = M.ctb.transport(reconfig_cmd, M.envelope, M.val_post.argmax())
            if not tr.ok:
                M.mode = 'DEGRADED'; M.morph.block(reconfig_cmd)
            else:
                M.kappa, M.envelope = reconfig_cmd.k_new, tr.C_dst
        M.snapshot.write(b_t_full, gate, M.val_post, M.envelope)

    # 感知域（异步 Best-effort）
    psi_hat, ece_aff = M.aura.update(audio)
    if ece_aff > TAU_AFF: M.psi_hat = None
    tac_ev = M.dmem.update(tac_frame, M.last_action)
    if tac_ev.u_tac > TAU_U_TAC: M.tac_ev = None

    # 价值域（异步低频）
    M.val_post = M.vam.update(y_val, M.psi_hat, M.z_dist, M.kappa, M.val_post)
    if M.val_post.conf or M.val_post.diam > TAU_DIAM:
        g = M.mvoi.choose(M.b_t, M.psi_hat, M.z_dist, M.val_post, M.budget)
        if g and M.aereflex.admissible(g):      # 仅合法引出
            y = M.cia.execute(g); M.last_g, M.last_y = g, y
    if M.val_post.diam > TAU_DIAM: M.cap = tighten_capability(M.kappa)
    M.corr.check(M.kappa)                       # MVC 运行时连续性

    return k, lam, J_MAG(M)
```

## 4. 推导

**引理 33（纤维传输组合安全性）** 每纤维认证 + 每传输合法（余量 m_i、重接地哈希匹配）⇒ 路径余量 ≥ min_i m_i。对路径归纳，组合步用风险次可加 + 约束语义保持。系：**重构安全分解为「纤维认证 + 传输证明」两个可独立审计对象。**

**引理 34（接地漂移与不连续性）** 沿用旧接地越界 ≤ L_Γ·d_phys + Δ_Γ；Δ_Γ 可在 d_phys→0 时仍爆炸（Γ 对机械增益分段/不连续）。系：**不能用「重构幅度小」免除重接地；跨层无条件重接地。**

**引理 35（价值不确定非补偿）** 存在环境使任意有限 λ 缩放都不能把错误目标风险压到 ε 以下：真实价值「禁止不可逆」下，任意正速度动作的不可逆代价为常数，λ 只线性缩放速度。故 lim_{λ→∞} Risk ≥ δ·Risk_irrev > ε。系：**价值不确定必须进可接受性约束而非仅进 λ。**

**引理 36（MVC 策略无关下界）** 纠正通道独立于策略/价值模型 ⇒ 最坏伤害 ≤ E_res^max + (1−p_indep)·Risk_uncontrolled，且与价值误差无关。系：**硬件地板只在人类能及时物理介入时成立，故须联合 τ_corr/可达性。**

**引理 37（分层传播二分）** 层内可按 u_reconf 连续传播并由 Lipschitz 收缩；跨层在分岔集上 h_κ 不连续/多值，**无连续性可用**，必须离散重认证。系：**可重构安全 ≠ 连续参数自适应安全。**

**定理 27（MAG 全局安全与严格包含）** 在 A111–A117 下，任一执行风险 ≤ ε_mag；𝒦 单点且 v 固定时逐指令等于 R72。**安全单调不减。**

**定理 28（不可洗白 / 风险守恒）** 任意路径报告风险 ≥ 最大真实风险 − 独立认证抵扣；闭环洗白必被拒。**可重构性从 Goodhart 机器变为受守恒律约束的资源变换。**

**定理 29（合法引出有限停止）** 操纵约束下 endorsed IG_v 边际非增、成本有正下界 ⇒ 有限 n* 停止；仍有歧义则 defer/收紧能力，**不得以操纵降歧义**。

**定理 30（可纠正性与 R72 复合）** 最坏伤害 ≤ min(R72 包络界, E_res^max+(1−p_indep)·Risk_uncontrolled)，与价值模型误差无关。系：**S2R-UQ 管「测得准」，MVC 管「错了也能被摁住」。**

**定理 31（J_MAG 有效性 ⇒ 联合安全）** J_EMB ∧ 纤维/传输 ∧ 重接地 ∧ 账本 ∧ MVC ⇒ 联合风险 ≤ ε_mag 且有硬件兜底。**重量落在「Γ 的真实正确性」与「价值后验未被操纵污染」上。**

## 7. 本轮最大风险

**一句话**：MAG 把安全从「相信测量链」进一步转移到「相信**价值重接地 Γ_κ 在新身体上仍语义正确**、相信**价值后验未被机器人自身的询问/迎合污染**、相信**风险账本无法被构型循环洗白**」——**如果重接地在新构型的机械增益/几何下发生不易察觉的语义漂移，同时价值后验被系统自身的谄媚式引出逐步推向它更容易满足的代理目标，而所有纤维证书、传输证明、可纠正证书仍然「全部通过」，系统就会拿着一套**可物理纠正却持续地、合规地做错事**的证书，在长时程里把人的价值改写成它自己能兑现的版本——这就是**「自信地、可审计地、可纠正地价值漂移」**，比 R72 的「自信地错自己的可执行性」更深一层。**

次级风险与缓解：
1. **重接地语义漂移** → 接地参数化到物理第一性（力/能量/可逆性）；每次重构后强制**接地差异测试**（已知几何/质量下的力-位移响应）。
2. **谄媚式价值污染** → 合法引出三条件 + 反射均衡 v^R + **独立价值审计集 SEAL-Value**（在线只读通过位）。
3. **风险账本被循环洗白** → 闭环信用守恒 + credit 必须外部物理凭据；否则记零并拒绝。
4. **多元价值被平均掉** → credal set + 不可通约取 maximin/CVaR，**禁止用加权和假装共识**。
5. **可纠正通道失效/不可达** → MVC 含 τ_corr 与人体可达性；高能构型限制 E_res；定期人类可达性演练。
6. **跨层重认证成本高** → 预认证构型族库 + 传输模板；仅对未见组合增量验证；设 |𝒦|/边上限。
7. **复杂度爆炸** → 模块上限 |𝒦|≤16、|V_t| 采样≤64、|A|≤32；每个投影响一条可复算证明，复杂度纳入审计。
