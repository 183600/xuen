# 第 9 轮（本次会话第 1 轮 / 全局第 9 轮；灵感：「语义地图」×「价值对齐」）

> **基线**：第 8 轮 MetricVoiceGauge-DA-SPR-Cal（定义 493–540；引理 77–81；实验 E531–E550）。
> 本轮纪律：不把语义地图当作「多一层视觉特征」，也不把价值对齐当作「再训一个奖励模型」。语义地图负责**给风险以含义**（where / what / who），价值对齐负责**给调权以约束**（should / how much）。两者通过同一张 **Semantic-Value Field** 耦合；新增模块必须与 v8 的 DA/SPR/Cal 正交，任一失效可平滑退化回 v8。

## 0. 直觉与动机

**灵感 1（语义地图 → 风险从几何量变成有含义的量）**
v8 的地图风险只有占据熵 H(map)：一堵墙、一张床、一个浴室隔间在占据栅格里几乎一样「不确定」，但它们的道德/操作含义完全不同。语义地图给每个节点附带标签分布、可供性、人类活动先验、隐私敏感度与易碎性，于是「风险」可以被**分型**：几何风险、人类活动风险、隐私穿透风险、易碎物风险、指称接地失败风险。它们可加、可解释、可单独消融，而不是把所有未知都塞进一个地图熵。

**灵感 2（价值对齐 → 权重不是「调」出来的，而是被「约束」出来的）**
v7/v8 的权重由风险 + 情感调节，但没有任何机制回答：**这是谁的价值？哪些价值不可交易？** 一个在厨房里为了效率把速度权重调高的情感模块，可能在无人察觉时压过了安全价值。价值对齐在这里不是训练一个更大的奖励模型，而是一个**运行时可检查的约束**：声明价值向量 v、每个语义标签的价值 logit B、指标层到价值的暴露矩阵 Γ；任何自适应权重 w_adapt 都必须投影到「价值可行集」——硬价值有地板（safety、privacy、human autonomy），软价值才允许与效率折中。这样「对齐」成为一个每周期可验证的证书，而不是一次性的离线口号。

**交叉洞察（1+1>2）**
语义地图天然提供**上下文** c，而价值恰恰是上下文相关的：厨房里安全/卫生权重高，卧室里隐私地板高，走廊里效率权重高，儿童房附近人类自主与安全同时升高。于是同一张语义图节点可以同时存「语义证据」和「价值 logit」，我们把它称为 **语义-价值场（Semantic-Value Field, SVF）**：

```
w*(c) = softmax( log v + Bᵀ ℓ_N(c) )       （语义决定“值多少”，价值决定“该多重”）
```

这样价值对齐在 50Hz 下不需要调用大模型：只需一次有界的图查询 + 一次小规模凸投影。语义变化会同时改变风险与价值目标，但二者通过**不同的注入通道**进入系统（risk_ground 进风险向量与阈值，w* 进可行集），因此可正交退化。

## 1. 研究问题

- **Q1（语义风险）**：如何定义有界、可解释、对语义不确定性单调的 risk_ground，使其与 v8 的 Δ_dom、risk_SLAM 不重复计数？
- **Q2（指称接地）**：语音指令如何绑定到语义图中的唯一指称，并在歧义时**请求澄清而非盲执行**？接地分数如何校准？
- **Q3（价值可行调权）**：如何把价值对齐写成运行时可投影的凸可行集，使硬价值地板在任意自适应（含情感重权）下不可被突破？
- **Q4（冲突仲裁）**：当语义风险与效率压力、或不同操作者价值偏好冲突时，如何做字典序仲裁并发布可审计的 ValueCert，同时保证任一模块失效可退化回 v8？

## 2. 设计原则（在 P7–P9 上升级为 P10–P14）

**P10 语义-价值场（Semantic-Value Field, SVF）**
语义图节点 c 携带标签分布 ℓ(c)、可供性 α(c)、不确定性 u(c) 与价值 logit 行 B_ℓ；邻域聚合后给出上下文价值目标 w*(c)。语义与价值共享同一证据，避免「风险说一套、价值说另一套」。

**P11 语义接地一致性（Semantic Grounding Consistency, SGC）**
语音指称 r 在语义图中取 top-2 匹配 s1,s2，接地分
```
g_sem = s1 · min(1, (s1−s2)/δ_margin) · 1[α(c*) ⊇ aff(r)]
```
仅当唯一性、置信边际、可供性同时满足才放行；否则进入澄清分支。**歧义不是失败，而是必须显式暴露的状态。**

**P12 语义风险分型（Semantic Risk Typing, SRT）**
```
risk_ground = λ_u·u + λ_h·H_human + λ_p·P_priv + λ_f·F_frag + λ_g·(1−g_sem)
```
五项均在 [0,1]，λ 为非负且和为 1，故 risk_ground ∈ [0,1]，与 Δ_dom（特征分布）、risk_SLAM（位姿/地图熵）通道正交。

**P13 价值可行投影（Value-Feasible Projection, VFP）**
定义价值暴露 e(w)=Γᵀw（Γ 行随机：每个指标层把权重分配给哪些价值），硬价值地板 e_k ≥ f_k，对齐球 ‖e(w)−w*(c)‖² ≤ 2ε。每个控制周期把 v8 产出的 w_adapt 投影到
```
W_feas(c) = { w ∈ Δⁿ⁻¹ : e_k(w) ≥ f_k (k∈H), ½‖e(w)−w*(c)‖² ≤ ε }
```
若不可行或投影位移过大，退到预注册的 w_safe 并触发 M₀。**情感重权只能在可行集内调权，不能突破价值地板。**

**P14 价值证书与冲突仲裁（ValueCert + VCA）**
ValueCert 记录语义证据哈希、接地分、w*、e、对齐边际、地板满足情况与仲裁记录；语义-价值冲突按字典序处理：安全 ≻ 隐私 ≻ 人类自主 ≻ 公平 ≻ 效率。冲突只有三种可观测出口：澄清、拒绝并解释、w_safe 回退。

## 3. 与 v8 的接口（如何退化）

- **L1**：SVF 失效 ⇒ M_sem/M_val 关闭，risk_ground ≡ 0、w* 取固定先验，完整退回 v8；
- **L2**：SGC 失效 ⇒ g_sem ≡ 1，退回 v7 VoiceCommandTyping，不做语义指称校验；
- **L3**：SRE 失效 ⇒ risk_ground ≡ 0，仅保留接地合法性检查；
- **L4**：CVM 失效 ⇒ w* 取离线固定 w_ref，投影与地板仍生效；
- **L5**：VFP 失效 ⇒ 直接用 w_safe（静态满足地板），放弃自适应调权；
- **L6**：VCA/ValueCert 失效 ⇒ 任何检测到的冲突默认 M₀，证书缺省为「未验证」；
- **L0**：全部失效 ⇒ 完整退回 MetricVoiceGauge-DA-SPR-Cal v8，再退回 v7。

> 退化正交性依据：SVF 只写语义图；SGC 只写 g_sem；SRE 只写 risk_ground；CVM 只写 w*；VFP 只写 w_final 与 risk_value；VCA 只写 action。任一模块失效不改变其余模块的输入分布。

## 4. 预期贡献

1. **语义风险分型**：把语义地图从「视觉附加层」变成有界、可消融的风险源，与感知域偏移、SLAM 风险正交；
2. **可校准的指称接地**：语音指令在歧义时显式澄清，杜绝「自信地执行错对象」；
3. **运行时价值可行调权**：硬价值地板不可被自适应/情感重权突破，投影具备非扩张稳定性；
4. **可审计 ValueCert + 语义-价值冲突字典序仲裁**：形成「语义-接地-价值-指标-动作-证书」闭环，实验 E551–E570 覆盖敏感性、校准、地板不变式、冲突仲裁、对抗标签与退化等价性。

## 5. 本轮最大风险

**一句话**：语义标签与价值 logit 本身来自有限人类数据；一个「自信但错误」的标签（例如把浴室误判为走廊）会恰好在该保护隐私时**降低隐私地板**，而投影仍会输出一个自洽、可复现、看起来完全合规的 ValueCert——「用一张可能错的语义图去定义价值约束，再用一个自洽的投影为它背书」。

**定义 541（语义-价值场 SemanticValueField）**
```
G_sem = (C, E, ℓ, α, u, B)
ℓ: C→Δ^{|L|−1},  α: C→2^A,  u: C→[0,1],  B∈ℝ^{|L|×k}
ℓ_N(s) = Σ_{c∈N(s)} ω(s,c)·ℓ(c) / Σ_{c∈N(s)} ω(s,c),   ω(s,c)=exp(−d(s,c)/d₀)
w*(s) = softmax( log v + Bᵀ·ℓ_N(s) ) ∈ Δ^{k−1}
```
同一节点既提供语义证据（ℓ, α, u），也提供价值上下文（Bᵀℓ）。这是本轮「语义地图」与「价值对齐」的**唯一耦合点**，其余接口全部正交。

**定义 542（语义不确定性 SemanticUncertainty）**
```
u(c) = clip( H(ℓ(c))/log|L| + β·σ_cal(c), 0, 1 )
```
H 为标签熵，σ_cal∈[0,1] 为跨源标签分歧（视觉 / 激光 / 先验地图）的归一化残差。|L|=1 时 H=0。

**定义 543（指称接地一致性 SemanticGrounding）**
对语音指称 r，令 C_r={c: sim(φ_txt(r), ψ(c)) ≥ δ_match}，取 top-2 相似度 s₁≥s₂：
```
g_sem(r) = s₁ · min(1, (s₁−s₂)/δ_margin) · 1[ α(c*) ⊇ aff(r) ]
amb(r)   = 1[ s₁−s₂ < δ_margin ] ∨ 1[ |C_r| > 1 ]
```
仅当 g_sem ≥ τ_ground 且 amb=0 才允许执行；否则请求澄清。**高相似但低边际 = 歧义，不是高置信。**

**定义 544（语义风险 SemanticRisk）**
```
risk_ground(s) = λ_u·u(c(s)) + λ_h·H_human(s) + λ_p·P_priv(s) + λ_f·F_frag(s) + λ_g·(1−g_sem(s))
λ = (0.30, 0.25, 0.25, 0.10, 0.10),  Σλ = 1
```
五项均归一化到 [0,1]，故 risk_ground ∈ [0,1]，注入风险向量与阈值时不会数值爆炸。

**定义 545（人类活动语义风险 HumanActivityRisk）**
```
H_human(s) = max_{c∈N(s)} ℓ_human(c)·ρ(c,t)·exp(−d(s,c)/d_h)
```
ℓ_human(c)∈[0,1] 为语义人类存在先验（餐厅/走廊高），ρ(c,t)∈[0,1] 为时间活动因子（如厨房午间高）。这是 SLAM 地图熵无法表达的**语义-时间**风险。

**定义 546（隐私穿透 PrivacyPenetration）**
```
P_priv(s) = max_{c∈N(s)} S_priv(c) · σ( (d_priv − d(s,c)) / w_priv )
```
S_priv(c)∈[0,1] 为语义隐私敏感度（浴室 1.0、卧室 0.9、走廊 0.1），σ 为 logistic，给出连续的「接近隐私区」风险而非硬布尔。

**定义 547（上下文价值模型 ContextualValueModel）**
```
w*(c) = softmax( log v + Bᵀ ℓ_N(c) )
```
人类偏好对 (ξ⁺ ≻ ξ⁻ | c) 用 Bradley–Terry 模型解释：
```
P(ξ⁺≻ξ⁻ | c) = σ( ⟨w*(c), Φ(ξ⁺,c)−Φ(ξ⁻,c)⟩ )
L_pref(v,B) = −Σ_{(ξ⁺,ξ⁻,c)∈D_pref} log σ( ⟨w*(c), ΔΦ⟩ )
```
价值特征 Φ 的分量：安全=最小净空、效率=1/耗时、隐私=隐私穿透积分、人类自主=人类接管/确认次数、公平=多主体服务时长的基尼系数。**价值对齐在这里是可学习的，不是手写常数。**

**定义 548（价值暴露 ValueExposure）**
```
Γ ∈ ℝ^{n×k},  Γ_{i,k} ≥ 0,  Σ_k Γ_{i,k} = 1  （每个风险维把权重分配给 k 个价值）
e(w) = Γᵀ w ∈ Δ^{k−1}
```
默认 Γ（可审计、可被领域专家改写）：

| 风险维 | safety | efficiency | privacy | autonomy | fairness |
|---|---|---|---|---|---|

**定义 549（价值可行集 ValueFeasibleSet）**
```
H = {safety, privacy, autonomy},   f = (f_safe,f_priv,f_auto) = (0.35,0.15,0.10)
W_feas(c,u) = { w∈Δ^{n−1} : e_k(w) ≥ f_k (k∈H),  ½‖e(w)−w*(c)‖² ≤ ε_align(u) }
ε_align(u) = ε₀ + ε_u·u
```
默认 ε₀=0.02、ε_u=0.05。设计前提 Σ_{k∈H} f_k = 0.60 ≤ 1，且 w_safe 静态满足地板。

**定义 550（价值可行投影 ValueFeasibleProjection）**
```
w_proj = Π_{W_feas(c,u)}( w_adapt ) = argmin_{w∈W_feas(c,u)} ‖w − w_adapt‖²
```
用 Dykstra 交替投影到「概率单纯形 ∩ 硬价值半空间 ∩ 对齐椭球」。若不可行或迭代后仍违反约束，输出 w_safe 并置冲突标志。

**定义 551（对齐损失与价值风险 ValueAlignmentMargin）**
```
A(w,c) = ½‖e(w) − w*(c)‖²
risk_value(s) = max(0, A(w_adapt,c) − ε_align(u)) + Σ_{k∈H} max(0, f_k − e_k(w_adapt))
```
risk_value 衡量「自适应权重在投影前偏离价值可行集多少」，是有界信号（A∈[0,1]，地板项 ≤Σf）。

**定义 552（语义-价值冲突 SemanticValueConflict）**
```
C_conf(s) = 1[ W_feas(c,u)=∅ ]
          ∨ 1[ ‖w_proj − w_adapt‖ > δ_conf ]
          ∨ 1[ risk_ground > τ_ground ∧ e_eff(w_adapt) > e_eff(w_ref)+δ_eff ]
```
第三项刻画「语义风险已高，情感/效率却仍想加速」的典型错位。

**定义 553（字典序仲裁 LexicographicArbitration）**
优先级：`safety ≻ privacy ≻ human_autonomy ≻ fairness ≻ efficiency`。仲裁规则：
1. 先尝试带硬地板的投影；成功且位移 ≤ δ_conf ⇒ accept；
2. 失败/位移过大 ⇒ 用 w_safe（只降低软价值，不降低硬价值）；
3. 若 risk_ground>τ_ground 或 g_sem<τ_ground 或 amb=1 ⇒ clarify / refuse_and_explain / M₀，**绝不以效率交换硬价值**。

**定义 554（价值证书 ValueCert）**
```
VC = ( h_sem, g_sem, w*, e, A, ε_align−A, floors_ok, C_conf, action, t )
h_sem = H( map_version ‖ {c_i,ℓ(c_i),u(c_i)}_{i∈N(s)} ‖ top-k 指称 )
```
证书与 ROS 证书一起发布；任何审计者可仅凭 VC 与公开的 Γ、f 复算 e、A 与地板检查。**证书必须可复现，否则不算对齐证据。**

**定义 555（对齐漂移监测 AlignmentDriftMonitor）**
对 A_t 做单边 CUSUM：
```
S_t = max(0, S_{t−1} + A_t − A₀ − ν)
alarm ⇔ S_t > h
```
A₀ 为标定期望对齐损失，ν 为容忍漂移，h 为报警阈值。报警后请求人类偏好反馈；在重对齐完成前收紧 ε 或提高 τ_ground。

**定义 556（语义-价值阈值更新 SV-ThresholdUpdate）**
```
τ_i(t) = clip( τ_i(0) + η·θ(t) + κ_i·Δ_dom + κ^g_i·risk_ground + κ^v_i·risk_value, ε_min,i, ε_max,i )
```
κ^g,κ^v ≥ 0；M₀/M₁/M_sem/M_val 取大系数（默认 1.0/0.8/0.6/0.6），M₂/M₃ 取小系数（0.2/0.15）。语义越不确定、对价值偏离越大，安全阈值只收紧不放宽。

**定义 557（八层指标闭合 MetricLadder v9）**
```
M = (M₀, M₁, M₂, M₃, M_dom, M_SLAM, M_sem, M_val)
```
M_sem 监控 risk_ground < τ_ground ∧ g_sem ≥ τ_ground ∧ amb=0；M_val 监控 A ≤ ε_align ∧ 地板满足。二者退化映射 δ_sem、δ_val 均定义为「直接触发 M₀ 硬约束检查」。

**定义 558（语义-价值退化 SemanticValueDegradation）**
按第 0 节 L1–L6 定义逐级映射；形式化地，任一模块 off 时，其写集被替换为 v8 的对应常量/函数，且读集不变，故系统轨迹与相应基线**逐周期等价**（引理 88）。

**定义 559（SVA 系统标识）**
```
Φ_SVA = {τ 自适应+域+语义+价值, risk 7 维, calib 在线, semantics grounded, values feasible+floored}
Φ_v8  = {τ 自适应+域,           risk 5 维, calib 在线}
```
v9 与 v8 的可判定差异仅在三处写集：risk 向量、τ 的附加项、w 的可行集投影。

**定义 560（语义证据绑定 SemanticEvidenceBinding）**
```
h_sem(t) = H( map_version(t) ‖ { (c_i, argmax ℓ(c_i), u(c_i)) }_{c_i∈N(s_t)} ‖ top-k 指称 )
```
h_sem 绑定「当时看到的语义证据」与「当时发出的证书」，防止事后换图导致证书不可追溯。

## 2. 形式化定义（要点）

- **定义 541（SVF）**：语义节点 = 标签分布 + 可供性 + 不确定性 + 价值 logit；邻域核加权后同时产出 risk 证据与 w*。
- **定义 542（不确定性）**：标签熵 + 跨源分歧，归一化到 [0,1]；让「语义不确定」与「感知域偏移」成为两件事。
- **定义 543（接地）**：唯一性 × 置信边际 × 可供性；歧义显式暴露，不把 top-1 当真理。
- **定义 544（语义风险）**：五项凸组合，λ 和为 1 ⇒ 有界；每项可单独消融与解释。
- **定义 545–546（人类/隐私）**：把「谁在这、这能不能看」写成语义-时间风险，补足 SLAM 地图熵的盲区。
- **定义 547（CVM）**：上下文 softmax + Bradley–Terry 偏好学习；价值随语义上下文变化，但学习目标是全局可解释的。
- **定义 548（暴露）**：Γ 行随机，e=Γᵀw 仍是概率分布；指标层与价值之间的映射公开、可审计。
- **定义 549–550（可行集/投影）**：硬价值地板 + 对齐球；凸集投影，逐周期执行，不可行即回退。
- **定义 551（价值风险）**：投影前的违反量，进入风险向量与阈值，不进入奖励本身。
- **定义 552–553（冲突/仲裁）**：语义高风险 + 想提速 = 冲突；字典序保证硬价值不可交易。
- **定义 554–555（证书/漂移）**：VC 可复算；CUSUM 监测偏好漂移，避免「一次对齐、永久正确」的幻觉。
- **定义 556–560（阈值/闭合/退化/标识/绑定）**：新信号只收紧阈值；八层闭合；逐级退化；证书绑定证据。

```python
# IP-354 SemanticValueField：语义-价值场
class SemanticValueField:
    def __init__(self, labels, v, B, d0=1.0, k=5):
        self.labels = list(labels)
        self.v = np.asarray(v, float)                 # (k,) 全局价值先验
        self.B = np.asarray(B, float)                 # (|L|, k) 标签价值 logit
        self.d0 = d0
        self.nodes = {}                               # id -> {pos, label_dist, affordance, u}
        self.map_version = 0

    def upsert_node(self, node_id, pos, label_dist, affordance, u):
        self.nodes[node_id] = dict(
            pos=np.asarray(pos, float),
            label_dist=np.asarray(label_dist, float),
            affordance=set(affordance),
            u=float(np.clip(u, 0.0, 1.0)))
        self.map_version += 1

    def neighborhood(self, s, radius=None, max_nodes=16):
        radius = radius if radius is not None else 3.0 * self.d0
        cand = [(float(np.linalg.norm(n['pos'] - s)), cid, n)
                for cid, n in self.nodes.items()]
        cand = [x for x in cand if x[0] <= radius]
        cand.sort(key=lambda x: x[0])
        return cand[:max_nodes]

    def value_target(self, s):
        """返回 w*(s) 与邻域语义不确定性 u_N(s)"""
        nb = self.neighborhood(s)
        if not nb:
            return softmax(np.log(self.v + 1e-9)), 0.0
        wsum = 0.0
        agg = np.zeros(len(self.labels))
        u_sum = 0.0
        for d, _, n in nb:
            w = np.exp(-d / self.d0)
            agg += w * n['label_dist']
            u_sum += w * n['u']
            wsum += w
        agg /= max(wsum, 1e-9)
        u_nb = float(np.clip(u_sum / max(wsum, 1e-9), 0.0, 1.0))
        logits = np.log(self.v + 1e-9) + self.B.T @ agg
        return softmax(logits), u_nb

    def evidence_hash(self, s, topk_nodes):
        import hashlib, json
        payload = dict(version=self.map_version,
                       nodes=[(cid, np.argmax(n['label_dist']).item(), round(n['u'], 4))
                              for cid, n in topk_nodes])
        return hashlib.sha256(json.dumps(payload, sort_keys=True).encode()).hexdigest()[:16]


# IP-355 SemanticGroundingChecker：指称接地
class SemanticGroundingChecker:
    def __init__(self, svf, embed_text, embed_node,
                 tau_ground=0.55, delta_match=0.50, delta_margin=0.15):
        self.svf = svf
        self.embed_text = embed_text
        self.embed_node = embed_node
        self.tau_ground = tau_ground
        self.delta_match = delta_match
        self.delta_margin = delta_margin

    def check(self, referent_text):
        """返回 (g_sem, ambiguous, cid*, topk)"""
        r = self.embed_text(referent_text)
        scored = [(float(r @ self.embed_node(n, cid)), cid, n)
                  for cid, n in self.svf.nodes.items()]
        scored.sort(reverse=True, key=lambda x: x[0])
        if not scored:
            return 0.0, True, None, []
        s1, cid1, n1 = scored[0]
        s2 = scored[1][0] if len(scored) > 1 else 0.0
        aff_ok = self._affordance_ok(referent_text, n1)
        margin = min(1.0, max(0.0, (s1 - s2) / self.delta_margin))
        g = max(0.0, s1) * margin * (1.0 if aff_ok else 0.0)
        ambiguous = (s1 - s2 < self.delta_margin) or (not aff_ok)
        return g, ambiguous, cid1, scored[:3]

    def _affordance_ok(self, text, node):
        # 文本动作词 ↔ 节点可供性：grasp/place/open/enter/observe...
        needed = parse_affordance(text)
        return needed is None or needed in node['affordance']


# IP-356 SemanticRiskEstimator：语义风险分型
class SemanticRiskEstimator:
    def __init__(self, svf, lam=(0.30, 0.25, 0.25, 0.10, 0.10),
                 d_h=2.0, d_priv=1.0, w_priv=0.30, beta=0.5):
        self.svf = svf
        self.lam = np.asarray(lam, float)
        self.d_h = d_h
        self.d_priv = d_priv
        self.w_priv = w_priv
        self.beta = beta

    def risk(self, s, cid, g_sem=1.0, fragility=0.0, t=0.0):
        u = self.svf.nodes[cid]['u'] if cid is not None else 0.0
        h = self._human_activity(s, t)
        p = self._privacy(s)
        f = float(np.clip(fragility, 0.0, 1.0))
        r = (self.lam[0] * u + self.lam[1] * h + self.lam[2] * p
             + self.lam[3] * f + self.lam[4] * (1.0 - np.clip(g_sem, 0.0, 1.0)))
        return float(np.clip(r, 0.0, 1.0))

    def _human_activity(self, s, t):
        best = 0.0
        for d, _, n in self.svf.neighborhood(s):
            lh = n.get('human_prior', 0.0) * n.get('time_factor', lambda _t: 1.0)(t)
            best = max(best, lh * np.exp(-d / self.d_h))
        return float(np.clip(best, 0.0, 1.0))

    def _privacy(self, s):
        best = 0.0
        for d, _, n in self.svf.neighborhood(s):
            sp = n.get('privacy', 0.0)
            best = max(best, sp * sigmoid((self.d_priv - d) / self.w_priv))
        return float(np.clip(best, 0.0, 1.0))


# IP-357 ContextualValueModel：上下文价值学习（离线）+ 在线目标
class ContextualValueModel:
    def __init__(self, k=5, lr=0.05, epochs=300, l2=1e-3):
        self.k = k
        self.v = np.ones(k) / k
        self.B = np.zeros((0, k))      # fit 时按标签数初始化
        self.lr = lr
        self.epochs = epochs
        self.l2 = l2

    def fit(self, prefs, label_dists):
        """prefs: [(pos_idx, neg_idx, label_dist, phi_pos, phi_neg)]"""
        self.B = np.zeros((len(label_dists[0]), self.k))
        for _ in range(self.epochs):
            gv = np.zeros_like(self.v)
            gB = np.zeros_like(self.B)
            for pos, neg, ld, phi_p, phi_n in prefs:
                z = np.log(self.v + 1e-9) + self.B.T @ ld
                w = softmax(z)
                dphi = phi_p - phi_n
                margin = float(w @ dphi)
                coeff = -sigmoid(-margin)                 # dL/dmargin
                dz = coeff * (np.diag(w) - np.outer(w, w)) @ dphi
                gv += dz / (self.v + 1e-9)
                gB += np.outer(ld, dz)
            self.v = softmax(np.log(self.v + 1e-9) - self.lr * gv)
            self.B -= self.lr * (gB + self.l2 * self.B)
        return self

    def target(self, label_dist):
        return softmax(np.log(self.v + 1e-9) + self.B.T @ label_dist)


# IP-358 ValueFeasibleProjector：价值可行投影
class ValueFeasibleProjector:
    def __init__(self, Gamma, floors, eps0=0.02, eps_u=0.05,
                 n_iter=15, delta_conf=0.15, w_safe=None):
        self.G = np.asarray(Gamma, float)                 # (n,k) 行随机
        self.f = dict(floors)                             # {'safety':0.35,...}
        self.eps0 = eps0
        self.eps_u = eps_u
        self.n_iter = n_iter
        self.delta_conf = delta_conf
        self.GtG_inv = np.linalg.inv(self.G.T @ self.G + 1e-9 * np.eye(self.G.shape[1]))
        self.w_safe = np.asarray(w_safe, float) if w_safe is not None \
            else np.ones(self.G.shape[0]) / self.G.shape[0]

    def exposure(self, w):
        return self.G.T @ w

    @staticmethod
    def _proj_simplex(w):
        n = len(w)
        u = np.sort(w)[::-1]
        css = np.cumsum(u)
        r = np.nonzero(u * np.arange(1, n + 1) > css - 1.0)[0][-1]
        theta = (css[r] - 1.0) / (r + 1.0)
        return np.maximum(w - theta, 0.0)

    def _proj_floor(self, w, k, fk):
        g = self.G[:, k]
        val = float(g @ w)
        return w if val >= fk else w + ((fk - val) / float(g @ g)) * g

    def _proj_align(self, w, w_star, eps):
        y = self.G.T @ w
        r = y - w_star
        nr = float(np.linalg.norm(r))
        if 0.5 * nr * nr <= eps:
            return w
        y_proj = w_star + r * (np.sqrt(2.0 * eps) / max(nr, 1e-12))
        dw = self.G @ self.GtG_inv @ (y_proj - y)        # 最小范数修正
        return w + dw

    def project(self, w_adapt, w_star, u_sem=0.0):
        eps = self.eps0 + self.eps_u * u_sem
        if sum(self.f.values()) > 1.0 + 1e-9:
            return self.w_safe.copy(), True, {'reason': 'floor_infeasible'}
        sets = [('simplex', None)] + [('floor', k) for k in self.f] + [('align', None)]
        corr = [np.zeros_like(w_adapt) for _ in sets]
        w = np.asarray(w_adapt, float).copy()
        for _ in range(self.n_iter):
            for idx, (kind, k) in enumerate(sets):
                y = w + corr[idx]
                if kind == 'simplex':
                    w_new = self._proj_simplex(y)
                elif kind == 'floor':
                    w_new = self._proj_floor(y, k, self.f[k])
                else:
                    w_new = self._proj_align(y, w_star, eps)
                corr[idx] = y - w_new
                w = w_new
        e = self.exposure(w)
        floors_ok = all(e[k] >= self.f[k] - 1e-6 for k in self.f)
        align_ok = 0.5 * float(np.linalg.norm(e - w_star) ** 2) <= eps + 1e-6
        if not (floors_ok and align_ok):
            return self.w_safe.copy(), True, {'reason': 'projection_infeasible'}
        dist = float(np.linalg.norm(w - w_adapt))
        return w, dist > self.delta_conf, {'proj_dist': dist, 'eps': eps}


# IP-359 ValueConflictArbiter：字典序仲裁
class ValueConflictArbiter:
    def __init__(self, tau_ground=0.60, delta_eff=0.05):
        self.tau_ground = tau_ground
        self.delta_eff = delta_eff

    @staticmethod
    def _eff(w):
        return float(w[2])        # EFF 维

    def arbitrate(self, risk_ground, g_sem, ambiguous, w_adapt, w_ref, conflict):
        if ambiguous or g_sem < self.tau_ground:
            return 'clarify'
        if risk_ground > self.tau_ground and self._eff(w_adapt) > self._eff(w_ref) + self.delta_eff:
            return 'refuse_and_explain'
        if conflict:
            return 'safe_fallback'
        return 'accept'


# IP-360 ValueCert + IP-363 主闭环关键片段
def make_value_cert(svf, vfp, cid, topk, g_sem, w_star, w, u_sem,
                    risk_value, conflict, action, t):
    e = vfp.exposure(w)
    floors_ok = all(e[k] >= vfp.f[k] - 1e-6 for k in vfp.f)
    eps = vfp.eps0 + vfp.eps_u * u_sem
    return dict(h_sem=svf.evidence_hash(cid, topk), g_sem=float(g_sem),
                w_star=np.asarray(w_star).tolist(), w=np.asarray(w).tolist(),
                e=e.tolist(), A=0.5 * float(np.linalg.norm(e - w_star) ** 2),
                margin=eps - 0.5 * float(np.linalg.norm(e - w_star) ** 2),
                floors_ok=bool(floors_ok), risk_value=float(risk_value),
                conflict=bool(conflict), action=action, t=t)

        floor_viol = sum(max(0.0, vfp.f[k] - e_adapt[k]) for k in vfp.f)
        risk_value = max(0.0, 0.5 * float(np.linalg.norm(e_adapt - w_star) ** 2) - eps) + floor_viol
        w_final, conflict, info = vfp.project(w_adapt, w_star, u_sem)
    risk_7d[-1] = min(risk_value, 1.0)                # 注入第 7 维

    # --- 6) 字典序仲裁（IP-359） ---
    action = 'accept'
    if vca is not None:
        action = vca.arbitrate(risk_ground, g_sem, ambiguous, w_adapt, w_ref, conflict)
        if action == 'clarify':
            return M.ask_clarification(s, referent=M.current_referent)
        if action == 'refuse_and_explain':
            return M.safe_stop(s, reason='semantic_value_conflict')
        if action == 'safe_fallback':
            w_final = vfp.w_safe if vfp is not None else w_final

    # --- 7) 阈值收紧（IP-556，DA-OTL 扩展） ---
    if M.online_learner is not None:
        M.online_learner.update_domain_shift(delta_dom)
        M.online_learner.update_semantic_risk(risk_ground)
        M.online_learner.update_value_risk(risk_7d[-1])
        tau = M.online_learner.get_thresholds()
    else:
        tau = M.metric_ladder.thresholds

    # --- 8) 价值证书（IP-360） ---
    cert = None
    if vfp is not None and svf is not None and M.cert_sink is not None:
        cert = make_value_cert(svf, vfp, cid, topk, g_sem, w_star, w_final,
                               u_sem, risk_7d[-1], conflict, action, M.time)
        M.cert_sink.publish(cert)

    # --- 9) 跑 v8 主流程，用 w_final / tau 覆盖 ---
    out = M.metricvoicegauge_round_8(
        M, s, obs, audio_stream, ell=ell,
        domain_adapter=domain_adapter, slam_risk=slam_risk, calib_fi=calib_fi,
        weight_override=w_final, threshold_override=tau)

    return (*out, {'risk_ground': risk_ground, 'risk_value': risk_7d[-1],
                   'g_sem': g_sem, 'u_sem': u_sem, 'conflict': conflict,
                   'action': action, 'value_cert': cert})


# IP-361 AlignmentDriftMonitor：CUSUM
class AlignmentDriftMonitor:
    def __init__(self, A0=0.01, nu=0.01, h=0.05, eps_after=0.01):
        self.A0, self.nu, self.h = A0, nu, h
        self.eps_after = eps_after
        self.S = 0.0

    def update(self, A_t):
        self.S = max(0.0, self.S + A_t - self.A0 - self.nu)
        return self.S > self.h
```

## 4. 推导

**引理 82（语义风险有界性与单调性）**
risk_ground = Σ_j λ_j r_j，其中 r_j∈[0,1] 且 λ_j≥0、Σλ_j=1，故 risk_ground∈[0,1]。对任一 r_j 单调不减；特别地，u↑、H_human↑、P_priv↑、F_frag↑ 或 g_sem↓ 都只会增大 risk_ground。证明：凸组合的坐标单调性；各分量由定义 542–546 均为 [0,1]。

**引理 83（语义不确定性→阈值只收紧）**
若 u 增大而其他量不变，则 risk_ground 增大（引理 82）；又 κ^g_i≥0，故定义 556 中 τ_i 的附加项 κ^g_i·risk_ground 单调不减。因 τ_i 是「违背概率/风险上界」，τ_i 增大意味着判据更严，只会更早触发向 M₀ 的退化。故语义不确定性不会错误地放宽安全阈值。证明：逐项比较定义 556 的 clip 前后表达式；clip 为单调函数。

**引理 84（接地可靠性，条件于校准）**
设相似度 s₁ 经校准满足 P(c* 正确 | s₁,s₂) ≥ s₁·min(1,(s₁−s₂)/δ_margin)，且可供性检查无误，则 g_sem ≤ P(c* 正确)。于是 g_sem ≥ τ_ground ⇒ 指称正确概率 ≥ τ_ground；g_sem < τ_ground 或 amb=1 时系统进入澄清分支。因此在校准假设下不存在「接地失败但静默执行」。**注意：该引理把校准误差显式隔离为一个可检验假设，而不是无条件成立。**

**引理 85（价值投影的存在性、唯一性、非扩张与地板不变式）**
W_feas(c,u) 是概率单纯形（闭凸）、有限个半空间 {e_k≥f_k}（闭凸）与对齐椭球 {½‖e−w*‖²≤ε}（闭凸）的交，故为闭凸集。若 w_safe∈W_feas，则非空，欧氏投影存在且唯一（Hilbert 投影定理），且投影算子 Π 是 firmly nonexpansive：‖Π(x)−Π(y)‖ ≤ ‖x−y‖。Dykstra 交替投影在非空闭凸交上收敛到 Π。地板不变式：对任意 w∈W_feas 有 e_k(w)≥f_k；投影输出要么在 W_feas 内，要么为离线构造的 w_safe（同样满足地板）。因此硬价值地板在任意周期不被突破。证明：凸集投影标准性质 + Dykstra 收敛定理（Boyle–Dykstra 1986）。

**引理 86（语义上下文变化下的对齐稳定性）**
softmax 的 Jacobian 为 diag(w*)−w*w*ᵀ，其谱范数 ≤ 1/4（w*∈Δ）。故 ‖∂w*/∂ℓ_N‖ ≤ ‖B‖₂/4。结合 ℓ_N 对节点标签分布的核加权 Lipschitz 性与引理 85 的非扩张性，相邻周期的权重变化满足
```
‖w'_t − w'_{t+1}‖ ≤ ‖w_adapt,t − w_adapt,t+1‖ + 2·(‖B‖₂/4)·‖ℓ_N,t − ℓ_N,t+1‖ + O(ε_u Δu)
```
即语义标签的小变化只引起权重的小变化；不存在因阈值边界导致的权重抖动放大。证明：链式法则 + 投影非扩张 + 可行集 Hausdorff 距离界（对齐球中心移动 w* 的幅度由上式界定）。

**引理 87（无静默价值违反 / 冲突无空洞）**
设 VFP 与 VCA 在线。(i) 若投影前地板 e_k(w_adapt)<f_k，则 risk_value>0，投影后由引理 85 地板成立，或回退 w_safe，两种情况都写入 ValueCert；(ii) 若 C_conf=1，VCA 只能返回 accept（仅当无违反且 risk_ground≤τ_ground）、clarify、refuse_and_explain 或 safe_fallback，四者均为可观测动作；(iii) 若 VFP 不可用（L5），系统直接用 w_safe，仍满足地板。故不存在「软通过、硬违反」的静默路径。证明：对每种分支枚举检查写集与动作集。

**引理 88（八层软硬闭合与逐级退化等价）**
δ_sem 与 δ_val 均定义为「直接触发 M₀ 硬约束检查」，且 τ_ground、τ_val 与 τ_safe 使用同一「风险上界」尺度。因此任一软层违背都必经 M₀，无空洞。退化等价：各新模块的写集互不相交（第 0 节），关闭任一模块时其写集被替换为 v8 常量/函数，读集不变；由结构归纳，系统轨迹逐周期等于对应的 v8 子集。特别地，L1–L6 任意组合的关闭都与声明的基线等价。证明：写集正交性 + 逐周期归纳。

**引理 89（WCET 可加性）**
SVF 查询为 |N(s)|≤16 个节点的核加权，O(16·|L|)；SGC 在预计算节点嵌入上取 top-2，O(|C_r|·d_emb) 但 |C_r| 由空间索引截断、且指令频率远低于 50Hz；SRE 为 O(|N|)；CVM target 为 O(k·|L|)=O(250)；VFP 为 15×(单纯形 O(n log n) + |H| 个半空间 O(n) + 对齐 O(nk+k²))，n=7、k=5，约 1.6k flops；ADM O(1)；ValueCert 为一次哈希。故新增主环开销 ≤2ms（解析估计，实验 E563 实测抖动）。

## 8. 本轮最大风险

**一句话**：语义标签与价值 logit 都来自有限人类数据，一个「自信但错误」的标签（如把浴室误判为走廊）会在最需要保护隐私时**降低隐私地板**，而投影仍会输出一个自洽、可复现、看起来完全合规的 ValueCert——「用一张可能错的语义图去定义价值约束，再用一个自洽的投影为它背书」。
