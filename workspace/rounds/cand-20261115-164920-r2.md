# 第 8 轮（灵感循环第 2 轮；本轮灵感：「位姿估计」×「多任务学习」）

> **基线**：第 7 轮 MetricVoiceGauge-OTL-GC-ER（定义 493–529；引理 69–76；实验 E513–E525）。
> 本轮纪律：**先证位姿可信，再谈共享表征**。位姿估计把“机器人在哪”从点估计升级为 SE(3) 上的分布；多任务学习把“多套指标/多条任务”从各自为战升级为共享主干 + 任务头。二者耦合的真正危险是：一个被高估置信度的位姿，会经由共享主干同时污染安全证书、抓取几何与奖励权重。因此本轮不追求“更多模块”，而建立一条单向证据链：**位姿标定 → 证书膨胀 → 不确定度降级 → 任务亲和性门控 → 无害回滚**。

## 0. 直觉与动机

**灵感 1（位姿估计 → 位姿不是坐标，而是带预算的信念）**
直觉：v7 的 SpatialCert 默认位姿已知，于是把“感知误差”折叠进了一个拍脑袋的安全裕度。真实系统里，位姿估计输出的是 `(T̂, Σ)`：一个 SE(3) 上的点估计加上协方差。安全问题的正确提法不是“位姿是多少”，而是“在置信水平 1−δ 下，真实位姿可能落在多大的椭球里，这个椭球要把安全边界撑开多少”。据此提出**位姿条件证书（Pose-Conditioned Certificate, PCC）**：证书不再验证一条轨迹，而是验证一族被不确定椭球膨胀后的轨迹；位姿不确定度成为可分配、可消耗的安全预算，而不再是被隐藏的假设。

**灵感 2（多任务学习 → 指标、位姿、抓取、语言本就是一个共享表征问题）**
直觉：v7 的 M₀–M₃、OTL、GCT、ER 各自拥有特征与更新回路，计算冗余，且在 50Hz WCET 下相互挤占预算。多任务学习提示：它们共享同一个世界表征，尤其**位姿编码器天然被安全、抓取、导航三条任务共用**。但朴素共享会带来负迁移：语料偏置、梯度冲突会把一个任务的噪声灌进另一个任务。据此提出**任务亲和性门控共享（Task-Affinity Gated Sharing, TAGS）**：共享主干只在任务梯度亲和度足够高时启用，否则退回任务私有头。

**交叉直觉**：两个灵感的真正耦合点，不是“用位姿当多任务输入”，而是**位姿是共享主干上最危险的那根神经**。位姿头一旦过置信，多任务共享会把错误同时放大到证书、抓取与奖励，于是所有任务“一致地错”。因此本轮把“共享”本身当作需要认证的行为：共享更新必须通过**无害证书**，位姿头必须接受**隔离检疫**。这把多任务学习从“省算力的工程技巧”升级为“可审计的安全性主张”。

## 1. 研究问题（轮次升级版）

- **Q1（位姿校准）**：如何在线判定位姿协方差 Σ 是否校准（而不是仅仅“看起来小”），并在未校准时拒绝将其用于安全证书？
- **Q2（证书膨胀）**：如何把 SE(3) 置信椭球传播为可计算的膨胀安全集，使“证书通过 ⇒ 以 ≥1−δ 概率无碰撞”，同时不把系统膨胀到不可用？
- **Q3（共享门控）**：在任务梯度冲突时，如何划分“可共享子空间”与“必须私有”的更新，并保证单任务不因共享而变差？
- **Q4（复合退化）**：位姿失效、共享失效、二者同时失效时，如何逐级退回 v7，且退化路径可形式化验证而非口头声明？

## 2. 设计原则（在 P7–P9 基础上升级为 P10–P13）

**P10 位姿信念与校准门（Pose Belief + Calibration Gate）**
维护位姿信念 `b(ξ) = N(ξ̂, Σ)`（ξ 为 SE(3) 局部切空间坐标）。仅当归一化估计误差平方（NEES）统计落在 χ² 置信带内、且独立一致性检查未报警时，才允许该 Σ 进入证书；否则进入“位姿检疫”。

**P11 证书膨胀（Certificate Inflation）**
把点轨迹的安全距离改写为最坏置信椭球下的下界：
```
γ_pose(x) = d₀(x) − c_δ · (1 + R_obj) · √(λ_max(Σ)) − ε_sensor
certified ⇔ γ_pose(x) ≥ margin_min
```
其中 `c_δ = √(χ²₆(δ))`，`R_obj` 为物体/机械臂特征半径，用于把旋转不确定度折算为位移，`d₀` 为名义位姿下的距离。

**P12 不确定度分层降级（Uncertainty-Weighted Ladder）**
每个指标层 i 对位姿的敏感度用 Lipschitz 常数 `L_i` 描述，传播不确定度：
```
ε_i = L_i · c_δ · √(λ_max(Σ)) + ε_i^sensor
c_i = exp(−ε_i / ε_ref,i)
```
`c_i < c_min,i − h` 时该层降级到保守模式，`c_i > c_min,i + h` 时恢复（h 为滞回），避免在阈值附近反复抖动。

**P13 亲和性门控共享（Affinity-Gated Sharing）**
任务 j 的梯度 `g_j = ∇_θ L_j`；亲和度 `a_jk = cos(g_j, g_k)`。只对 `a_jk ≥ a_min` 的任务对启用共享；对冲突分量做投影（PCGrad 式），并用**无害证书**决定是否接受共享步；拒绝则退回任务私有头更新。

## 3. 与基线的接口（如何退化）

- **位姿估计器失效 / 协方差未校准** ⇒ 位姿检疫：冻结位姿头，改用带漂移增长的最后已知位姿；漂移超预算后在 M₀ 层触发保持/停机，证书退化为 v7 的最坏情况膨胀；
- **多任务共享失效 / 无害证书拒绝** ⇒ 关闭共享主干，改走任务私有头，等价于 v7 的独立模块更新；
- **位姿 + 共享同时失效** ⇒ 直接回到 MetricVoiceGauge v7（固定 SpatialCert + 独立任务）；
- **OTL / GCT / ER 仍为可选增强**：任一不可用则按其 v7 退化链处理，本轮不改变其语义。

## 4. 预期贡献

1. **位姿条件证书（PCC）**：把 SE(3) 协方差显式传播到安全判据，给出可检验的 1−δ 覆盖保证；
2. **不确定度分层降级（UWL）**：指标置信度随位姿不确定度单调下降，形成无抖动的层间退化；
3. **亲和性门控共享（TAGS）**：把多任务共享拆成“可共享子空间 + 任务私有残差”，并用无害证书拒绝负迁移；
4. **复合退化代数**：位姿与共享两个开关的 4 种组合均可归约到 v7 或可验证的安全停机，实验 E526–E545 覆盖校准、膨胀、共享、退化与端到端。

## 5. 本轮最大风险

**一句话**：位姿协方差若被系统性低估（过置信），膨胀后的安全集将失去其 1−δ 保证；而多任务共享又会把同一错误位姿头扩散到证书、抓取与奖励，使系统在“各任务都同意”的假象下更快地一致犯错——最大风险不是模块失效，而是**失效被共享放大且证书仍然通过**。

**定义 530（位姿信念 PoseBelief）** 在 SE(3) 局部切空间上：
```
b_t(ξ) = N(ξ̂_t, Σ_t),   ξ ∈ R⁶
T_t = T̂_t · exp(ξ^),    ξ ~ b_t
E_δ = { ξ : ξᵀ Σ_t⁻¹ ξ ≤ χ²₆(δ) }
```

**定义 531（位姿膨胀下界）** 设名义位姿下轨迹点到障碍集 `O` 的距离为 `d₀(x)`，物体/机械臂特征半径为 `R_obj`，则
```
d_inf(x, O) ≥ d₀(x) − c_δ (1 + R_obj) √(λ_max(Σ_t)) − ε_sensor
```

**定义 532（位姿条件证书 PCC）**
```
γ_pose(x) = d₀(x) − c_δ (1 + R_obj) √(λ_max(Σ_t)) − ε_sensor
PoseCert(x, δ) = ( γ_pose(x) ≥ margin_min, γ_pose(x) )
```

**定义 533（在线校准残差）** 若存在独立位姿校验源（动捕、回环、已知标定板）：
```
e_t = ξ_tᵀ Σ_t⁻¹ ξ_t,          E[e_t] = 6
calibrated ⇔ |mean_{t∈W} e_t − 6| ≤ κ_cal ∧ max_{t∈W} e_t ≤ χ²₆(1−α)
```
无独立校验源时，`calibrated = false`，不得把 `Σ_t` 用于安全证书，只能用于日志。

**定义 534（分层不确定度与置信）**
```
ε_i = L_i · c_δ · √(λ_max(Σ_t)) + ε_i^sensor
c_i = exp(−ε_i / ε_ref,i) ∈ (0,1]
```

**定义 535（多任务模型分解）**
```
z = f_θ(o)
y_j = h_φj(z),   j ∈ 𝒯
L(θ, φ) = Σ_j λ_j L_j(φ_j, θ)
```

**定义 536（任务亲和度）**
```
a_jk = ⟨g_j, g_k⟩ / (‖g_j‖·‖g_k‖ + ϵ) ∈ [−1, 1]
```

**定义 537（冲突投影共享梯度）** 对每个 j，先投影掉与其他任务的负冲突分量，再平均：
```
ĝ_k = g_k / (‖g_k‖ + ϵ)
g_j⊥ = g_j − Σ_{k≠j, a_jk < 0} ⟨g_j, ĝ_k⟩ ĝ_k
g_shared = (1/|𝒯|) Σ_j g_j⊥
```
仅对 `a_jk ≥ a_min` 的任务团内部执行共享；跨团保持私有头。

**定义 538（无害证书 NoHarm）** 设共享步长 `η`、探测集上的损失 `L_j`、曲率上界 `L_max`：
```
Δ_j^bound = −η ⟨g_j, g_shared⟩ + (η²/2) L_max ‖g_shared‖²
NoHarm ⇔ ∀ j : Δ_j^bound ≤ ε_j
```
`NoHarm` 成立才接受 `θ ← θ − η g_shared`；否则回滚并对每个任务执行私有更新 `φ_j ← φ_j − η_j g_j^φ`。

**定义 539（位姿检疫 PoseQuarantine）**
```
Quarantine ⇔ ¬calibrated ∨ max_{t∈W} e_t > χ²₆(1−α) ∨ disagree(pose_head, check) > τ_q
```
检疫期间：位姿特征不进入共享主干（`z` 中位姿通道置零并被掩码），PCC 仅使用漂移回退的保守协方差。

**定义 540（漂移回退 PoseDriftFallback）**
```
Σ_t = Σ_{t0} + Q·(t − t0),    Q ⪰ 0
```
`Q` 由最大速度/角速度先验给出；`Σ_t` 单调增 ⇒ `γ_pose` 单调减。

**定义 541（不确定度分层退化算子 D）** 对每个层级 `M_i`：
```
D(c_i)[M_i] =
    M_i,                  c_i ≥ c_min,i + h        （正常）
    M_i^{cons},           c_min,i − h < c_i < c_min,i + h （滞回保持）
    δ_i(M_i) → M_{i−1},   c_i ≤ c_min,i − h        （降级到下层）
```
其中 `M_i^{cons}` 为保守模式（收紧阈值、冻结 OTL 自适应）。

**定义 542（复合退化代数）** 令 `E(λ_pose, λ_mtl)` 为两开关组合下的系统语义：
```
E(0,0) = MetricVoiceGauge-OTL-GC-ER v7
E(1,0) = PCC + UWL + 独立任务更新
E(0,1) = v7 SpatialCert + TAGS/NoHarm 共享
E(1,1) = MetricVoiceGauge-PAM
```
并声明归约方向：任一开关为 0 时，被关闭模块的接口返回其 v7 常量（`Σ→∅` 或 `g_shared→∅`）。

**定义 543（任务团与滞回）** 以 `a_jk ≥ a_min` 构造无向图，取其连通分量作为任务团 `C_m`。为避免阈值抖动，团的分裂/合并需连续 `N_h` 轮满足相反判定：
```
split(C_m) 需连续 N_h 轮 min_{j,k∈C_m} a_jk < a_min − h_a
merge(C_m,C_n) 需连续 N_h 轮 min_{j∈C_m,k∈C_n} a_jk > a_min + h_a
```

**定义 544（PAM 闭环状态）**
```
Φ_PAM = ( b_t(ξ), E_δ, PoseCert, {c_i}, {C_m}, NoHarm, λ_pose, λ_mtl, δ_total )
```

**定义 545（风险预算切分）** 由联合界：
```
δ_total = δ_pose + δ_share + δ_track
δ_pose  ← 位姿椭球覆盖；δ_share ← 共享步被误接受的界；δ_track ← 漂移回退
```
任一项用尽即提升保守等级，而不是挪用其他项的预算。

## 2. 形式化定义（补充要点）

**定义 532′（证书的否定语义）** `¬PoseCert(x, δ)` 不表示“必然碰撞”，而表示“在 1−δ 置信下无法排除碰撞”。因此证书失败的正确响应是保守规划或 M₀ 保持，而非“继续但降低速度”这种未经证明的折中。

**定义 537′（共享子空间）** 对任务团 `C_m`，定义可共享梯度子空间
```
G(C_m) = span{ g_j⊥ : j ∈ C_m }
```
共享更新必须落在 `G(C_m)` 内；任何正交残差 `g_j − proj_{G(C_m)}(g_j)` 只允许更新私有头。这给出“共享/私有”的线性代数分解，而非调参式折中。

**定义 542′（归约等价）** `E` 满足：对任意输入，若 `λ_pose = 0`，则 `E` 与替换 `PoseCert ≡ true` 的 v7 在可观测输出上同分布；若 `λ_mtl = 0`，则 `E` 与替换 `g_shared ≡ 0` 的 v7 同分布。

## 3. 关键算法骨架

```python
# IP-351/352/353：位姿信念、证书膨胀、不确定度分层
class PoseBelief:
    def __init__(self, Sigma0, delta=0.95):
        self.xi_hat = None
        self.Sigma = Sigma0
        self.delta = delta
        self.t_last = None

    def update(self, xi_hat, Sigma, t):
        self.xi_hat, self.Sigma, self.t_last = xi_hat, Sigma, t

    def drift(self, t, Q):
        if self.t_last is None:
            return self.Sigma
        return self.Sigma + Q * (t - self.t_last)

    def radius(self):
        lam = max(np.linalg.eigvalsh(self.Sigma))
        return np.sqrt(chi2.ppf(self.delta, 6) * max(lam, 0.0))


class PoseConditionedCert:
    def __init__(self, belief, R_obj, eps_sensor, margin_min):
        self.belief = belief
        self.R_obj = R_obj
        self.eps_sensor = eps_sensor
        self.margin_min = margin_min

    def margin(self, d0):
        r = self.belief.radius()
        return d0 - r * (1.0 + self.R_obj) - self.eps_sensor

    def certify(self, d0):
        gamma = self.margin(d0)
        return gamma >= self.margin_min, gamma


class UncertaintyLadder:
    def __init__(self, Lipschitz, eps_sensor, eps_ref, c_min, h):
        self.L = Lipschitz
        self.eps_sensor = eps_sensor
        self.eps_ref = eps_ref
        self.c_min = c_min
        self.h = h
        self.state = {i: "normal" for i in Lipschitz}

    def confidence(self, i, pose_radius):
        eps_i = self.L[i] * pose_radius + self.eps_sensor[i]
        return float(np.exp(-eps_i / self.eps_ref[i]))

    def demote(self, i, c_i):
        lo, hi = self.c_min[i] - self.h, self.c_min[i] + self.h
        if c_i <= lo:
            self.state[i] = "degraded"
        elif c_i >= hi:
            self.state[i] = "normal"
        return self.state[i]


# IP-354/355/356：共享主干、亲和性门控、无害证书
class TaskAffinityGate:
    def __init__(self, a_min=0.0):
        self.a_min = a_min

    def affinity(self, grads):
        G = np.stack([g / (np.linalg.norm(g) + 1e-12) for g in grads])
        return G @ G.T

    def conflict_project(self, grads):
        G = np.stack(grads)
        norm = np.linalg.norm(G, axis=1) + 1e-12
        Ghat = G / norm[:, None]
        A = Ghat @ Ghat.T
        out = []
        for j in range(len(grads)):
            g = G[j].copy()
            for k in range(len(grads)):
                if k != j and A[j, k] < 0.0:
                    g = g - (g @ Ghat[k]) * Ghat[k]
            out.append(g)
        return np.mean(out, axis=0)


class NoHarmCertifier:
    def __init__(self, L_max, eps):
        self.L_max = L_max
        self.eps = eps

    def bound(self, j, g_j, g_shared, eta):
        return -eta * (g_j @ g_shared) + 0.5 * eta**2 * self.L_max * (g_shared @ g_shared)

    def accept(self, grads, g_shared, eta):
        for j, g_j in enumerate(grads):
            if self.bound(j, g_j, g_shared, eta) > self.eps[j]:
                return False
        return True


# IP-357：位姿检疫
class PoseQuarantine:
    def __init__(self, kappa_cal, tau_q, window=50):
        self.kappa_cal = kappa_cal
        self.tau_q = tau_q
        self.window = window
        self.nees = []

    def update(self, nees_t, disagree_t):
        self.nees.append(nees_t)
        self.nees = self.nees[-self.window:]
        mean_e = float(np.mean(self.nees))
        max_e = float(np.max(self.nees))
        return (abs(mean_e - 6.0) > self.kappa_cal
                or max_e > chi2.ppf(0.99, 6)
                or disagree_t > self.tau_q)


# IP-360：PAM 主闭环关键片段
def metricvoicegauge_pam(M, s, obs, pose_obs=None, task_batch=None,
                         pose_belief=None, poscert=None, uladder=None,
                         trunk=None, heads=None, gate=None, noharm=None,
                         quarantine=None, eta=1e-3):
    lam_pose = pose_obs is not None and poscert is not None
    lam_mtl = task_batch is not None and trunk is not None

    # 1) 位姿：更新 / 校准 / 检疫 / 漂移回退
    if lam_pose:
        xi_hat, Sigma, nees_t, disagree_t = pose_obs
        pose_belief.update(xi_hat, Sigma, M.t)
        if quarantine is not None and quarantine.update(nees_t, disagree_t):
            lam_pose = False                      # 检疫：切断位姿证书
            pose_belief.Sigma = pose_belief.drift(M.t, Q=M.Q_drift)
        else:
            ok, gamma = poscert.certify(M.nominal_clearance())
            if not ok:
                return M.hold_safely(reason="pose_uncertain")   # M0 保持

    # 2) 不确定度分层降级（不依赖共享是否启用）
    if pose_belief is not None and uladder is not None:
        r = pose_belief.radius()
        for i in uladder.L:
            c_i = uladder.confidence(i, r)
            M.set_layer_mode(i, uladder.demote(i, c_i))
    else:
        M.set_layer_mode_all("normal")

    # 3) 多任务共享：亲和性门控 + 无害证书 + 失败回滚
    if lam_mtl:
        grads = trunk.task_gradients(task_batch, heads)
        A = gate.affinity(grads)
        g_shared = gate.conflict_project(grads)
        if noharm.accept(grads, g_shared, eta):
            trunk.step(g_shared, eta)
        else:
            trunk.freeze_shared()                 # 退回任务私有头
            for j, h in enumerate(heads):
                h.step(grads[j], eta)
    else:
        if heads is not None:
            for j, h in enumerate(heads):
                h.step_private(task_batch[j], eta)

    # 4) v7 主路径：CVC / SpatialCert / RT-CVC / FaultCert / 奖励 / 证书发布
    C, spatial_cert, claims, metrics, rewards = M.v7_round(s, obs)
    return C, spatial_cert, claims, metrics, rewards, {
        "lam_pose": lam_pose, "lam_mtl": lam_mtl,
        "pose_gamma": gamma if lam_pose else None,
        "layers": dict(M.layer_modes),
    }
```

## 4. 推导（引理 77–84）

**引理 77（膨胀证书的覆盖界）** 设 SE(3) 局部线性化误差有界为 `e_lin`，且真实位姿满足 `ξ ∈ E_δ`。若定义 531 的下界成立且 `PoseCert(x,δ)=true`，则真实几何与障碍的最小距离至少为 `margin_min − e_lin`，故碰撞概率不超过 `δ + P(e_lin 超界)`。证明要点：由 `d_inf` 的 Lipschitz 性与三角不等式，`d_true ≥ d_inf − e_lin ≥ margin_min − e_lin`；覆盖概率由 `ξ∈E_δ` 给出。注意这是**有条件的**保证，不是无条件的“绝不碰撞”。

**引理 78（不确定度单调降级）** `c_i` 关于 `λ_max(Σ)` 单调不增；因此在 `Σ_t` 单调增的漂移阶段，每个层级的 `c_i` 单调减，配合滞回 `h>0`，层级切换次数有限且不会在阈值附近无限抖动。证明：`ε_i` 线性增，`exp(−·)` 单调减；滞回把切换区间拉开 `2h`，每次穿越至少需要不确定度的有限增量。

**引理 79（冲突投影的非负改进）** 对任意任务对 `(j,k)` 满足 `a_jk < 0`，投影后的 `g_j⊥` 满足 `⟨g_j, g_j⊥⟩ ≥ ⟨g_j, g_shared^{naive}⟩`，即投影不会降低任务 j 在其自身损失上的一阶下降量；当 `a_jk ≥ 0` 时投影为空操作。证明：投影减去的是与 `g_j` 内积为负的方向 `ĝ_k` 的倍量 `⟨g_j,ĝ_k⟩ĝ_k`，该倍量为负，减去负向量等价于沿 `g_j` 正方向加项，故内积不降。

**引理 80（无害回退不劣于 v7）** 若 `NoHarm` 接受，则每个任务在探测集上的一阶+曲率上界损失增量不超过 `ε_j`；若拒绝，系统回滚并按私有头更新，其更新方向与 v7 的独立任务更新一致。因此无论接受或拒绝，PAM 在探测集上的损失不劣于 v7 加 `ε_j`。证明：接受分支由定义 538 直接给出；拒绝分支删除共享项 `g_shared=0`，剩余私有梯度与 v7 相同。

**引理 81（复合退化正确性）** 定义 542 的四种组合满足：`E(0,0)=v7`；`E(1,0)` 与 `E(0,1)` 分别只在位姿证书记录或任务更新处与 v7 不同；`E(1,1)=PAM`。且 `E` 对开关的关闭是逐分量替换，故退化不产生级联依赖。证明：PCC 的输入仅为 `(Σ, d₀)`，与共享主干无关；TAGS 的输入仅为 `g_j`，与位姿证书无直接边；两条支路在 v7 主路径前汇合，关闭任一支路等价于把该支路输出替换为 v7 常量。

**引理 82（漂移先于失安触发）** 设 `Σ_t = Σ₀ + Qt`，`Q ⪰ 0` 且 `λ_max(Q)>0`，`margin_min>0`。则存在有限 `t*` 使 `γ_pose < margin_min`；由于 `γ_pose` 连续单调减，M₀ 保持在 `t*` 或之前触发，系统不会在无证书状态下无限运行。证明：`√(λ_max(Σ_t)) → ∞`，故 `γ_pose → −∞`；由连续性存在最早穿越点。

**引理 83（检疫隔离）** 检疫期间位姿通道被掩码，故任意任务损失对位姿头参数的梯度为 0，即 `∂L_j/∂θ_pose = 0`。因此位姿估计错误不能经共享主干传播到其他任务；其他任务只能使用自身传感器与私有头。证明：前向计算中位姿特征被常量替换（定义 539），反向传播对该常量的梯度被截断。

**引理 84（WCET 预算）** 在 `d=6` 时，`λ_max(Σ)` 用幂迭代 `O(d²)`/次、取 3 次迭代；位姿膨胀与分层更新合计目标 ≤ 0.3ms/周期；TAGS 的梯度投影为 `O(|𝒯|²·|θ_shared|)`，通过仅在任务团内计算、且共享主干摊销编码成本，目标总 WCET 仍 ≤ 22ms（50Hz 的 44% 余量）。该引理是**预算主张**，须由 E535 实测确认，不能仅由复杂度推导。

## 8. 结果口径说明

本轮只提交**预注册设计与判据**，不宣称已获得实测数值。E526–E545 的“关键目标”是可检验的预测；任何与引理 77/82/83 相反的结果（尤其是 E541 的静默通过）都应视为**理论假设被推翻**，而不是调参问题。这样的口径避免把“事后挑出的好看种子”写成结论。

## 9. 本轮最大风险

**一句话**：位姿协方差若被系统性低估（过置信），膨胀后的安全集将失去其 1−δ 保证；而多任务共享又会把同一错误位姿头扩散到证书、抓取与奖励，使系统在“各任务都同意”的假象下更快地一致犯错——最大风险不是模块失效，而是**失效被共享放大且证书仍然通过**。
