# 第 11 轮（新灵感循环第 2 轮；本轮灵感：「运动控制」×「开源生态」）
> **基线**：第 10 轮 MetricVoiceGauge-STF-NRB-LS（定义 540–548；引理 87–91；实验 E571–E590）。
> 本轮纪律：**闭环硬包络 + 可组合供应链**。两个灵感分别治理 v10 的两种债：**开环债**（v10 的块证书认证的是一条由 F̂_q 预测出来的名义轨迹，β_STF 是预测余量；真实跟踪误差、接触冲击、执行器饱和与状态估计误差都不在证书里；真正的约束只是 50Hz 四检在离散时刻对状态抽查，而 v10 自认的最大风险正是"语义分割面被长尾/对抗纹理穿透时守卫不响"）、**单体信任债**（v10 是自研单体栈，模块之间的假设靠人脑维持；一旦引入第三方感知/规划/驱动模块或在线更新，证书前提会被静默改写，却没有假设-保证契约、来源证明、能力隔离与撤销机制；v10 的退化链只处理运行时失效，不处理"编译期/供应链被替换"）。必须保持 v10 铁律：任一新模块失效 ⇒ 行为严格**等价**（证书/几何路径）或**支配**（只收缩、只加严）于 v10，绝不行为漂移。

## 0. 直觉与动机

**灵感 1（运动控制 → 把"预测正确"换成"闭环不变"）**
直觉：v10 的证书像一张地图——它证明"按这张图走，未来 0.2 秒不会撞"；但机器人真正安全，靠的是"就算地图错了，我也不会撞"。运动控制里最硬的东西从来不是更准的模型，而是**反馈**：鲁棒管（tube）、控制障碍函数（CBF）、收缩度量、能量罐。它们把安全承诺从"模型预测对"改写为"在扰动集内，实测状态被一个前向不变集兜住"。这正面绕开 v10 最大风险赖以成立的逻辑：语义守卫失效与否，闭环不变式都不需要知道"误差为什么变大"，只需要知道"误差落在哪个有界集里"。更关键的是，运动控制给出**第二条独立残差通道**：动力学创新度 ε_dyn = 实测状态与 F̂_q 一步预测的偏差。对抗纹理可以骗过语义嵌入 ν，却未必骗得过动力学残差（纹理不改变质量/摩擦/延迟），反之亦然（未知接触会改动力学却不一定改变外观）。两个通道取 max 融合，不做任何补偿。

**灵感 2（开源生态 → 开放生态，封闭包络）**
直觉：开源生态的强项是组合与复用，软肋是供应链：你永远不知道明天拉下来的同一个版本号是不是昨天那个。安全上正确的姿态不是"只信自研"，而是**不信任任何上游，但能验证组合**：每个模块发布机器可读的假设-保证契约；组合检查器只在所有假设被上游保证或运行时监视器清偿时才签发组合证书；发布物带签名、可复现构建与来源证明；运行时对加载的二进制做 attested 哈希；模块跑在能力沙箱里，安全滤波器不可被旁路；任何更新必须先过"无更差"回归，否则撤销并回滚到 last-known-good。一句话：**谁都可以贡献，但只有能证明"不使包络变差"的版本才被允许进入认证集**。这把 v10 的"退化链"从运行时补丁升级为贯穿发布、组合、部署、撤销的完整信任生命周期。

**咬合（两个灵感其实是同一条信任边界的两侧）**
MEC 的闭环保证依赖四个前提：扰动界 Ŵ、收缩度量 (M,ρ)、障碍模型 h 与回退集 S_b。这四样恰好都是可被第三方模块替换/更新/污染的**工件**。CSE 不产生新的物理安全，它保证"当前运行的 MEC 前提，正是被签名、被组合检查、被回归验证过的那一份"；MEC 不保证"模块可信"，它保证"即使语义感知被骗，实测状态仍被不变集兜住"。于是安全被拆成两层独立防线：**供应链层保真**（你跑的是你验过的），**运动层保底**（即使验过的假设只在有界集内成立，越界也先收缩/停）。任一层失效，另一层仍在，且都退回 v10，不产生新物理行为。

与 v10 的对照可以压成一句话：v10 说"我把语义误差检测得更早"；v11 说"我不再要求检测必须成功——我把安全搬到实测状态的闭环不变集里，并用供应链证明这个不变集的每一条假设都还是我验过的那一条"。v10 换的是**更细的分割面**（仍是同一个承重结构）；v11 换的是**承重结构的位置**（从感知预测搬到动力学闭环）和**前提的出处**（从人脑维护搬到机器可查的组合证书）。

## 1. 研究问题（轮次升级版）

- **Q1（闭环包络）**：如何为块级名义计划构造可验证的鲁棒前向不变包络（收缩管 + 鲁棒 CBF 安全滤波 + 认证回退集），使 (a) 只要实测扰动落在在线估计的 Ŵ 内，安全不依赖 ν/τ_sem 是否命中；(b) 对 Ŵ 的依赖是显式、可标定、可单调收缩的（Ŵ 变大只会使管变粗、动作集变小）；(c) 滤波器不可行/超时/验证失败时，行为严格支配（⊆）于 v10 的安全停驻；(d) 200Hz 滤波 ≤0.5ms、≤0.5W，整体仍守 25W 与 50Hz 决策预算？
- **Q2（组合供应链）**：如何形式化模块级假设-保证契约、组合检查、证明携带发布、运行时来源证明、能力沙箱与撤销，使 (a) 只有所有假设被清偿的 DAG 才能进入认证集；(b) 任何未证明/被撤销/哈希不符的模块只能退回 last-known-good=v10 或 Π_r；(c) 更新必须通过"无更差"行为包含回归，且回归本身的覆盖率与统计功效被记录为证据；(d) 全程留痕、可离线复核、可被第三方审计？
- **Q3（双通道融合）**：如何把语义创新度 ν̄ 与动力学创新度 ε̄_dyn 融合成一个单调、非补偿的威胁指数，使任一通道越阈都只许膨胀管/收缩 K_eff/触发回退，且两通道的漏报不因"另一个看起来正常"而被抵消；在相关失效（同一物理原因同时抬高两者）下如何给出诚实的上界而非虚假的独立性假设？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 运动包络律（Motion Envelope, MEC）**
硬安全由实测状态上的闭环不变式给出，不由名义轨迹的正确性给出。任何块证书必须附带：收缩度量与 RPI 管、鲁棒 CBF 条件、认证回退集；预测/语义余量只许**膨胀**管半径，绝不许**缩小**硬约束。安全滤波器位于不可旁路的可信核，模块无权关闭；滤波器不可行/超时/验证失败 ⇒ 执行认证回退（⊆ v10 停驻），不得"继续按名义计划跑"。

**P17 组合安全律（Compositional Safety, CSE）**
只组合假设可清偿的模块。每个模块发布 (A_m, G_m, R_m, v^⊥_m, evidence_m)；组合证书只在 DAG 中每条 A_m 被上游 G 或声明了误差界的运行时监视器清偿、且无环、且版本解析取最保守可行解时签发。未清偿假设 ⇒ 拒绝入认证集或运行 Π_r。禁止 ambient authority：模块能力最小化，未声明 I/O 一律拒绝；安全滤波与账本写入属于可信核，模块不可写。

**P18 无更差更新律（No-Worse Update, CSE）**
任何更新/第三方模块进入认证集必须同时满足：(i) 发布物签名 + 可复现构建哈希 + 来源证明与运行中二进制哈希一致；(ii) 在认证包络上通过"行为包含"回归（新行为集 ⊆ 旧行为集，硬不变式保持），且证据包（测试分布、覆盖率、统计功效、对抗场景）随发布签名；(iii) 资源配额不越界。任一条不满足 ⇒ 撤销并回滚 last-known-good（默认 v10 镜像），撤销状态进入透明日志并随心跳扩散。开放生态，封闭包络：可以自由分叉，但分叉只有自证"不更差"后才能承载认证动作。

## 3. 与基线的接口（如何退化）

- **MEC 失效**（QP 不可行/超时、收缩验证失败、Ŵ 溢出 r_max、状态估计失效、能量罐耗尽）⇒ 执行认证回退：v10 停车不变式与最近中止点 p*；由于 MEC 的约束集 ⊆ v10 可行集，激活时行为是 v10 的**收缩**，失效时回到 v10 原路径，二者都不产生新物理动作；
- **CSE 失效**（清单缺失、签名/哈希不符、组合检查未过、撤销或超出 T_rev）⇒ 隔离未认证模块，回滚 last-known-good（= v10 认证镜像）；无 LKG ⇒ Π_r（P13）并语音披露；来源证明失败是"审查失明"的一种，收缩不扩权；
- **STF 失效** ⇒ 按 v10：T≡0、K_eff←1、β←β_base（失去领先语义指标，但 MEC 仍在）；
- **NRB 失效** ⇒ v10 的 Π_r；其快规范作为 CBF 的额外约束项，失效时改用静态保守界 d_eth+δ_r；
- **AC/ID/MW/v8 失效** ⇒ 完全沿用 v10 的 Level-3…Level-6（AC⇒K=1；ID⇒全模块常开、归因冻结；MW⇒手写网关；v8⇒中立元注入⇒v7⇒v6）；
- **新增安全件**（MEC 滤波、CSE 证明/组合检查、透明日志）一律 φ^elig=false，永不参与创新点蒸馏；只有"残差估计器/清单打包"这类感知侧辅助可蒸馏。

## 4. 预期贡献

1. **闭环安全包络**：把 v10 的"预测余量 + 语义抽查"升级为"鲁棒不变管 + 200Hz 实测状态 CBF 滤波 + 认证回退"，使安全承诺在语义守卫漏报时仍然成立（引理 92–93），并把 v10 的最大风险从"换更好的探测器"转成"换承重结构"；
2. **双通道残差**：语义 ν 与动力学 ε_dyn 取 max 融合、非补偿、各自标定，给出两通道相关失效下的诚实漏报上界（引理 96）；
3. **可组合安全供应链**：假设-保证清单、组合检查器、证明携带发布、运行时证明、能力沙箱、透明撤销日志与"无更差"回归，把开放生态的复用能力引入安全栈而不引入不可审计的信任（引理 94–95）；
4. **E591–E610** 覆盖管验证、CBF 时延/不可行率、接触能量、双通道解耦、供应链篡改、组合反例、无更差回归检出力、撤销扩散、长跑与竞赛。

## 5. 本轮最大风险

**一句话**：MEC 的保证只在"真实扰动 ∈ Ŵ、收缩度量与障碍模型在其验证域内"时成立，而 Ŵ、M、h 都是可被第三方模块/更新替换的工件——一个签名正确、可复现、且通过全部"无更差"回归的新版本，仍可能把真实扰动悄悄推出 Ŵ（例如新增接触工况、传感器时延、执行器磨损），此时管与 CBF 的保证变成空话，而系统仍以为自己拥有硬包络；来源证明保的是"真实性"，不是"真理性"，回归测试只覆盖它见过的分布。

| ε_dyn(t), ε̄_dyn | 动力学创新度 ε_dyn=√V(x_t−F̂_q(x_{t−1},u_{t−1}))；5 帧 EMA |
| τ_dyn, r_max | 动力学残差阈值与管半径硬上限（E593 标定） |
| h_i, α_i, Γ_i | 第 i 个 CBF/障碍函数、class-K 衰减、鲁棒裕量 |
| S_b, u_b | 认证回退集（前向不变）与回退动作（最小制动/停驻） |
| Ĉ_t^⊕ | 结构化运动证书 (ĝ_min, ê_max, γ̂_grasp, β_STF, n_t, tube_cert, f_cert, att_t) |
| SM_m | 安全清单 (id, ver, A_m, G_m, R_m, v^⊥_m, evidence_m, deps_m, caps_m) |
| C_comp | 组合证书：DAG 拓扑序、假设清偿映射、版本解析见证、哈希 |
| PCR/att_t | 证明携带发布 / 运行时来源证明向量：签名、构建哈希、SBOM、证据包、撤销纪元 |
| ATL | 审计透明日志：Merkle 树 + 签名检查点 + 撤销累加器 + gossip |
| ρ_thr | 双通道威胁：max(ν̄/τ_sem, ε̄_dyn/τ_dyn, β_STF/β_max) |

**新增定义 549（受控动力学与扰动集）** x_{k+1}=f(x_k,u_k)+w_k，w_k∈W，0∈W；名义模型 F̂_q 为 v10 的 INT8 GRU。实测状态 x̂_k 由状态估计器给出，误差 e_est∈E_est，因此闭环使用的有效扰动为 W_eff = W ⊕ E_est。安全论证只允许使用 W_eff 的上界，不允许使用"标称无扰动"。

**新增定义 550（收缩管与 RPI）** 跟踪误差 e_k=x_k−x_ref_k。若存在 M≻0、ρ∈[0,1)、σ_w≥0 使 V(e_{k+1})≤ρ²V(e_k)+σ_w² 在验证域 Ω 内成立，则 E_∞={e:V(e)≤σ_w²/(1−ρ²)} 是前向不变的；管 T_k=x_ref_k⊕E_∞。**管证书** valid ⇔ (i) (M,ρ,σ_w) 在 Ω 上的验证证据哈希匹配（SOS/采样+SDP 或区间验证）；(ii) min_{x∈T_k}dist(x,O) ≥ d_safe；(iii) W_eff 的上界包含 β_STF；(iv) 状态估计误差界 E_est 有效。ρ≥1 或 (i) 失败 ⇒ 无管证书，直接退 v10。

**新增定义 551（动力学创新度与自适应扰动界）** ε_dyn(t)=√V(x̂_t−F̂_q(x̂_{t−1},u_{t−1}))，ε̄_dyn 为 5 帧 EMA。在线集合隶属估计：r̂_t = max( r_max·γ_decay, Quantile_{1−δ}(ε_dyn 最近 N 帧) )，γ_decay∈(0,1] 为慢遗忘因子；Ŵ_t={w:V(w)≤r̂_t²}。**单调性约束**：r̂_t 只在有新的上界证据时下降，且下降速率受 γ_decay 限制（防止一次"安静"就忘记历史大残差）。r̂_t>r_max ⇒ 触发 Π_r（定义 546）而非继续膨胀管。

**新增定义 552（鲁棒 CBF 与安全滤波 QP）** 对每个安全约束 i（净空、人际距离 d_eth、力矩/速度上限、能量罐、规范快约束），h_i 连续、L_h-Lipschitz，要求
```
h_i(f(x,u)) − (1−α_i)h_i(x) ≥ L_h·r̂_t      （∀w∈Ŵ_t 的充分条件）
```
则对任意 w∈Ŵ_t 有 h_i(x_{k+1}) ≥ (1−α_i)h_i(x) ≥ 0。QP：
```
u* = argmin_u  ||u−u_ref||²_Q + λ_E·(E_tank 使用量)
     s.t.     上述鲁棒 CBF 条件（所有 i）
              u ∈ U（执行器/速度/力矩）
              u ∈ U_fast（NRB 快规范投影：d_eth+δ_r、禁抓注册物品）
```
**认证回退**：块生成时（5Hz）预计算 u_b∈S_b 使 h_i 在 S_b 上前向不变（例如最小制动到 p*）；QP 不可行/超时/数值失败 ⇒ 立即执行 u_b，并在下一块强制 Π_r。S_b 非空是块证书 valid 的必要条件（否则不生成块）。

**新增定义 553（结构化运动证书）** Ĉ_t^⊕ = (ĝ_min, ê_max, γ̂_grasp, β_STF, n_t, tube_cert, f_cert, att_t)。valid ⇔ Ĉ_t⁺ valid（v10 定义 543）∧ tube_cert valid（定义 550）∧ f_cert valid（S_b 非空且 QP 在预算内可行）∧ att_t 通过（定义 556）∧ 双通道威胁 ρ_thr≤1（定义 559）。任一不满足 ⇒ 不生成/不延长块，退 v10 停驻或 Π_r。

**新增定义 554（安全清单与假设-保证契约）** 模块 m 发布 SM_m=(id, ver, A_m, G_m, R_m, v^⊥_m, evidence_m, deps_m, caps_m)。A_m 为可机器检查的假设谓词（例：扰动上界、传感器速率、状态估计误差、输入时延上界）；G_m 为保证（例：管不变、CBF 前向不变、净空≥d_safe、行为包含）；R_m=(M_m,E_m,D_m) 资源；evidence_m=H(校准数据‖测试轨迹‖证明脚本‖统计功效)；caps_m 为最小能力集。

**新增定义 555（组合契约检查 CCC）** 输入为 SM 的 DAG。检查：(i) 每条 A_m 被某个上游 G_{m'} 蕴含，或被一个声明了误差界与可用性假设的运行时监视器清偿；(ii) 无环（有环 ⇒ 拒绝，不做不动点近似）；(iii) 版本解析取**最保守可行解**（在满足依赖约束的所有版本组合中，按 (管半径上界, 动作集大小, 权限集) 的字典序取最小）；(iv) 所有 caps 满足最小权限且安全滤波/日志能力不在任何普通模块的 caps 中。通过则签发 C_comp（含拓扑序与清偿见证哈希），否则模块不入认证集。

**新增定义 556（证明携带发布与运行时证明）** PCR=(artifact_hash, recipe_hash, SBOM, evidence_hash, C_comp, rev_epoch)，由发布密钥签名。运行时 att_t=(H(loaded code) == artifact_hash) ∧ Verify(sig) ∧ (rev_epoch ≥ 当前撤销纪元) ∧ (SBOM 与加载依赖一致)。启动与每 1s 复核；不符即隔离并回滚 LKG。T_rev 内未取得新撤销纪元（离线/网络分区）⇒ att_t=unknown ⇒ Π_r（不冒充已验证）。

**新增定义 557（能力沙箱与不可旁路核）** 每个模块在沙箱中运行，只能调用 caps_m 声明的系统调用/I/O/共享内存；未声明一律拒绝。安全滤波 QP、回退集执行、ATL 写入、时钟与传感器健康检查位于**可信核**，普通模块（含第三方感知/规划）无写权限；模块更新不得改变 caps，改变即需重新走 CCC+PCR。

**新增定义 558（无更差回归 NWC）** 对候选版本 m_new 与认证版本 m_old，在认证包络 Ω_cert 上检验行为包含 B(m_new)|_{Ω_cert} ⊆ B(m_old)|_{Ω_cert}：差分轨迹（同一观测/扰动脉络下动作差在证书允许的保守方向上）、硬不变式（净空、d_eth、力矩、管不变）、对抗与接触场景、覆盖率与统计功效。通过阈值与样本量预注册；未过 ⇒ 不认证。NWC 的证据包进入 PCR，但不宣称覆盖 Ω_cert 之外的分布。

**新增定义 559（双通道威胁与非补偿融合）** ρ_thr = max(ν̄/τ_sem, ε̄_dyn/τ_dyn, β_STF/β_max)。融合规则只允许 max（或更保守的联合上界），禁止加权和/几何平均进入安全判定。两通道相关失效时使用联合置信上界：P(miss) ≤ min(ε_sem, ε_dyn, ε_joint)，其中 ε_joint 由 E597 的相关性实验给出；若 ε_joint 不可标定，则强制回退到单通道最保守值（不允许用独立性假设换取更小的界）。

# IP-377 MotionEnvelopeCertifier：闭环包络 + 200Hz 安全滤波
class MotionEnvelopeCertifier:
    def __init__(self, Fq, M, rho, sigma_w, r_max, tau_dyn,
                 barriers, alpha, Q, U, U_fast, S_b, dt=0.005):
        self.Fq, self.M, self.rho, self.sigma_w = Fq, M, rho, sigma_w
        self.r_max, self.tau_dyn = r_max, tau_dyn
        self.h, self.alpha, self.Q = barriers, alpha, Q
        self.U, self.U_fast, self.S_b, self.dt = U, U_fast, S_b, dt
        self.r_hat, self.eps_bar = 0.0, 0.0
        self.tank = EnergyTank(E_cap=...)

    # 50Hz：动力学创新度 + 自适应扰动界（定义 551）
    def update_innovation(self, x_hat, x_prev, u_prev):
        e = x_hat - self.Fq.step(x_prev, u_prev)
        eps = sqrt(max(0.0, e.T @ self.M @ e))
        self.eps_bar = 0.2 * eps + 0.8 * self.eps_bar
        self.r_hat = max(self.r_hat * self.gamma_decay,
                         conformal_quantile(self.recent_eps, delta=0.01))
        if self.r_hat > self.r_max:              # 不许无限膨胀
            return 'shrink_to_pi_r'
        return 'ok'

    # 5Hz：块生成时的管与回退集认证（定义 550/552/553）
    def certify_chunk(self, x_ref_path, x0, cert10):
        if not self.contraction_verified():     # (M,rho,sigma_w) 证据哈希匹配
            return None                         # 无管证书 ⇒ 退 v10
        E_inf = self.sigma_w**2 / (1 - self.rho**2)
        for k, x_ref in enumerate(x_ref_path):
            if min_clearance_to_obstacles(x_ref, E_inf) < self.d_safe:
                return None                     # 管净空不足
        if not self.has_forward_invariant_backup(self.S_b):
            return None                         # 无回退集 ⇒ 不生成块
        return CertPlusPlus(cert10, tube=(self.M, self.rho, self.r_hat),
                            f_cert=hash_backup_cert(self.S_b), att=None)

    # 200Hz：鲁棒 CBF-QP（定义 552）
    def filter(self, x_hat, u_ref, live):
        if self.tank.empty():
            return self.backup_action('energy')
        cons = []
        for h_i, a_i, L_i in self.h:
            # 鲁棒离散 CBF：留出 L_i * r_hat 的最坏扰动裕量
            cons.append(lambda u, h_i=h_i, a_i=a_i, L_i=L_i:
                        h_i(self.f(x_hat, u)) - (1 - a_i) * h_i(x_hat)
                        - L_i * self.r_hat)
        cons += self.U_fast.as_constraints(live)     # NRB 快规范（d_eth+δ_r）
        cons += [self.tank.constraint()]
        try:
            u = solve_qp(self.Q, u_ref, cons,
                         bounds=self.U, timeout=0.0005)   # ≤0.5ms
        except (Infeasible, Timeout):
            return self.backup_action('qp')              # 认证回退 u_b
        return u

    def backup_action(self, why):
        return self.S_b.nearest_control(self.x_hat)      # ⊆ v10 停驻

## 4. 推导

**引理 92（闭环包络的安全性不依赖语义检测）** 设 (A1) 真实扰动 w_k∈W_eff 且 r̂_t 是其有效上界（E593；含状态估计误差）；(A2) 收缩参数 (M,ρ,σ_w) 在验证域 Ω 内的证据哈希匹配，ρ<1；(A3) 每个执行步要么由定义 552 的鲁棒 CBF-QP 产生，要么由认证回退 u_b∈S_b 产生，且 S_b 前向不变。则对任意块、任意语义结果（包括 ν≤τ_sem 的对抗纹理与长尾新颖），执行轨迹满足 h_i(x_k)≥0（∀i,k），即净空、人际距离与力矩约束保持。证明：由 (A2) 得 E_∞ 前向不变，故跟踪误差始终∈E_∞，管净空证书给出实际状态净空≥d_safe；对 CBF，由 h 的 Lipschitz 性与 w∈Ŵ_t 得 h_i(x_{k+1})≥h_i(f(x,u))−L_h r̂_t≥(1−α_i)h_i(x_k)≥0，归纳即得；QP 失败时 (A3) 的 u_b 在 S_b 上保持 h_i≥0。全过程未使用 ν、τ_sem、STF 或 NRB 的输出。∎

**引理 93（MEC 的支配性与退化等价）** (i) MEC 激活时，QP 约束在 v10 可行集上增加至少一条非平凡约束（鲁棒 CBF 裕量 ∪ U_fast ∪ 能量罐），故物理动作集 A_MEC ⊆ A_v10；(ii) MEC 失效时执行 u_b∈S_b，S_b 由块证书要求为 v10 停车不变式的子集（定义 552/553），故动作仍 ⊆ v10；(iii) 因此任一时刻的行为对 v10 是**支配**（不新增、只收缩）；当 MEC 与 CSE 都失效且回退到 v10 原路径时，行为与 v10 **严格等价**；(iv) 额外开销由契约表给出：QP ≤0.5ms@200Hz、ε_dyn ≤0.1ms@50Hz、管检查 ≤0.6ms@5Hz、证明 ≤0.2ms@1Hz，合计 ≤0.5W，25W 预算内。∎

**引理 94（组合契约的可靠性）** 若 CCC 对 DAG 签发 C_comp（每条 A_m 被上游 G 或运行时监视器清偿，无环，版本取最保守可行解），且所有运行时监视器的假设在其声明域内成立，则组合系统满足 G_comp=⋀_m G_m。证明：按拓扑序归纳；每条 A_m 或由上游 G_{m'}（已由归纳假设成立）蕴含，或由监视器在其声明域内保证；无环保证归纳良基；最保守版本解析保证不因版本替换而削弱已证保证（若某版本组合的保证更弱，按字典序不会被选中）。∎ 注：该引理不保证监视器自身可信——监视器属于可信核并由 PCR/att 保护（定义 557/556），其残余风险见第 8 节。

**引理 95（无更差更新与来源证明）** 设更新 m_new 满足 (i) PCR 签名与运行时哈希一致、撤销纪元有效；(ii) NWC 在 Ω_cert 上通过行为包含；(iii) R_m 配额不越界。则 (a) 认证包络内的物理行为集 B(m_new)|_{Ω_cert}⊆B(m_old)|_{Ω_cert}，不引入新的不安全动作；(b) 任何对 m_new 的发布后篡改以 ≥1−2^{−κ} 概率被运行时哈希/签名检出（κ=256，继承 v10 引理 90 的哈希论证）；(c) 撤销后回滚 LKG（v10 镜像）与 v10 严格等价。证明：(a) 由 NWC 定义；(b) 抗第二原像性；(c) LKG 即认证的 v10 镜像。∎ 关键限定：包含关系只在 Ω_cert 与其测试分布上被验证，**不覆盖分布外行为**。

**引理 96（双通道融合的单调性与诚实漏报界）** 令 ρ_thr=max(ν̄/τ_sem, ε̄_dyn/τ_dyn, β_STF/β_max)。(a) 单调：任一通道残差上升 ⇒ ρ_thr 非降 ⇒ 管半径 r̂ 非降、K_eff 非增、回退概率非降，不会因另一通道"正常"而抵消；(b) 漏报：若两通道漏报事件分别为 M_sem、M_dyn，则 P(M_sem∩M_dyn)≤min(P(M_sem),P(M_dyn))（无需独立性）；若进一步用 E597 标定的联合上界 ε_joint，则 P(双通道同时漏报)≤ε_joint；当 ε_joint 不可标定时系统取 min(ε_sem,ε_dyn) 作为保守值，禁止用独立性公式把界做小；(c) 与 v10 的关系：v10 只使用 M_sem，v11 的 ρ_thr 在 ε_dyn/τ_dyn≤1 时与 v10 的判据等价或更保守（β_STF/β_max 项只增不减）。∎

**引理 97（预算与活性）** 在契约表配额内，MEC/CSE 不改变 v10 的 50Hz 决策周期（新增均在独立 200Hz 线程或块边界），RAM 增量 ≤0.4MB、功耗增量 ≤0.5W；Π_r 下任务可完成率沿用 v10 的 E578 假设（≥85%），MEC 回退的可行性由 S_b 非空预先保证；若 QP 不可行率高于预注册阈值，则 MEC 自动降级为"解析 CBF 过滤 + 更慢执行"，而非取消过滤。∎

## 8. 本轮最大风险

**一句话**：MEC 的保证只在"真实扰动 ∈ Ŵ、收缩度量与障碍模型在其验证域内"时成立，而 Ŵ、M、h 都是可被第三方模块/更新替换的工件——一个签名正确、可复现、且通过全部"无更差"回归的新版本，仍可能把真实扰动悄悄推出 Ŵ（例如新增接触工况、传感器时延、执行器磨损），此时管与 CBF 的保证变成空话，而系统仍以为自己拥有硬包络；来源证明保的是"真实性"，不是"真理性"，回归测试只覆盖它见过的分布。
