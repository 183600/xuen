# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「实时推理」×「动态避障」）

> R69 把不确定性一分为二，并给了系统一张嘴：可约的歧义就去看、去问、去触。但 R69 里的「时间」只是一个预算数字——「P99 < 2.6ms、交互 ≤1 次/单位时间」。它默认**世界在推理期间静止**：采样 K 条轨迹、等一句回答，世界不动，证书不会过期。
>
> 「动态避障」戳破了这个默认：**障碍物在你想的时候也在走**。在 t 时刻认证为安全的计划，到 t+Δ 执行时可能已经不安全的；而 R69 恰恰鼓励系统多花时间（升 K、去交互）换取确定性——**用时间买信息，但时间本身正在改变世界**。
>
> 「实时推理」给出的正确解法不是「更快」，而是**可中断、可降级、带质量-时延契约的 anytime 推理**：任何时刻都能交出一个动作，只是质量不同；推理应由「值不值得再想一步」来停止，而不是由预先写死的 K 来停止。
>
> 核心命题：**把 R69 的「时间预算约束」升级为「时间安全语义」——思考的截止时间不是工程师设的 P99，而是世界给出的三重时钟：碰撞钟、预测钟、保底钟，取最小值。** 截止前，用 anytime 阶梯 + 价值计算（VoC）决定「再想多久」；截止后，只允许执行已认证的保底反射。命名 **TEMPO-RAS**（Time-budgeted Epistemic Metareasoning with Predictive Obstacle-safety）。
>
> 一句话定位：R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我还剩多少时间可以想，想出来的东西还作数吗**」——实时不是快，是**让推理的保质期与世界的变化速率对齐**。

## 0. 直觉与动机

**灵感 1（动态避障 → 快照安全是一句谎言）**
直觉：静态避障可以「规划出一条无碰轨迹」；动态避障里，这句话的时态就错了——没有「无碰轨迹」，只有「在一段时间内保持无碰的轨迹」。障碍物有速度，自车有执行延迟，认证又发生在规划时刻。R69 的 C-RAS-WM 认证是对**快照**做的，执行时世界已经换了一帧。正确对象不是一个点，而是一个**管**：把可达集按「漂移率 × 时延 + 执行延迟」膨胀，再对膨胀后的集合认证。这会让安全裕度看起来变小，但它是诚实的；不膨胀的证书不是更安全，只是更自欺。

**灵感 2（实时推理 → anytime 是契约，不是口号）**
直觉：R69 的 K=1/N_step=2 与 K=4 是写死的两档，像一台只有两个挡位的发动机。但流策略的 ODE 天然可截断：走 1 步、2 步、4 步，或采 1 个/4 个样本，都能交出一个动作——**质量不同、时延不同，但都可用**。把这组织成一条「推理阶梯」：ℓ₀ 反射（O(1)）、ℓ₁ 单步、ℓ₂ R69 常规、ℓ₃ R69 歧义、ℓ₄ 交互。实时性因此不再是「能不能在 P99 内跑完」，而是一种**契约**：每一级都承诺最坏时延与质量下界，且任何一级都能被随时打断并回退到 ℓ₀。

**灵感 3（三重时钟 → 截止时间是世界给的，不是工程给的）**
直觉：人过马路时不会看手表的 P99，而是同时盯三件事：车还有几秒到（碰撞钟）、自己的预判还能信多久（预测钟）、还剩多少余量能一脚刹住（保底钟）。三者取最小，才是「还能想多久」。R69 的 P99 只是「预测钟」在静止世界里的特例；在动态场景中它可能远大于真正的截止时间，让系统在「自以为安全」的窗口里想太久。

**灵感 4（元推理 → 停止是一个经济学问题，不是一个阈值问题）**
直觉：多升一级推理有价值（动作更好），也有成本（吃掉保质期、增加漂移暴露）。所以应该比较**边际价值**：只要「再想一步的期望收益 > 它消耗的时间 × 漂移折旧 + 计算成本」就继续，否则停。R69 的 mode_head 门控（歧义大才升 K）其实是这个规则在「时间免费、漂移为零」时的退化——它只看收益，不看成本。真实世界里，**最有价值的推理，可能是决定不再推理**。

**灵感 5（动态场景里的交互 → 问得太晚，等于没问，还更糟）**
直觉：R69 的 MINT 假设「问了就有答案」，却没算答案的**到达时延**。在人流中，你问「您要往左还是往右」，对方开口要 0.6 秒，这 0.6 秒里他已经走了 0.8 米。有效 VoI 必须按「答案到达时是否仍然有效」打折，还要减去「等待期间必须维持一条安全保持轨迹」的代价。更关键：若到达时延 ≥ 截止时间，**提问是被严格支配的**——信息为零、风险为正。R69 的「k 源一致」是正确性纪律，本轮要补的是**时效性纪律**；两条纪律正交，缺一不可。

**灵感 6（包含关系与新威胁 → 新层必须是旧层的退化，同时带来新攻击面）**
直觉：当漂移率 ρ→0、执行延迟→0、回答时延→0 时，三重时钟趋于无穷、推理几乎免费，本轮应当**逐指令退化**为 R69。这保证不是在 R69 旁边再放一个需要独立信任的黑箱。但「会看表」也带来新攻击面：敌手可以制造歧义把系统拖进高阶推理（**计算 DoS / 强制超时**）、可以把回答延迟到证书过期后再送达（**过期答案投毒**）、可以逼出一次本身就不安全的急刹（**保底反射陷阱**，例如急刹被追尾）。所以本轮必须同时交付：执行时再认证、时限账本、保底反射的自身认证。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（TEMPO-RAS 总览）** TEMPO-RAS = (AIP, DRC, TVH, MRC, TSC, CAS, SID, RGI, DLB, RAS-WM‡)。三不变式：
(i) **可中断**：任意推理等级都能在有界时间内交出一个可执行动作（继承 R69 零学习写操作与提交/换装不变式）；
(ii) **保底可用**：任意时刻必须存在一条已认证、未过期的保底反射轨迹；不存在 ⇒ 禁止继续推理，立即执行最保守的已认证动作；
(iii) **认证不可跳过**：时间压力只能降低计划质量（选更低 rung），**永远不能降低认证标准**。

**定义 311（anytime 推理阶梯 AIP）** 阶梯 ℒ = {ℓ₀,…,ℓ_m}，ℓ₀ = 反射（制动/原地保持，O(1)），ℓ₁ = 单步流采样（N_step=1），ℓ₂ = R69 常规（N_step=2, K=1），ℓ₃ = R69 歧义（K=4），ℓ₄ = 交互（MINT）。每级带三元组 (q_ℓ, L_ℓ, ε_ℓ)：动作质量下界、最坏时延、质量下降上界；要求 L 单调增、q 单调非减。任意 ℓ 可被打断并回退至 ℓ₀，回退不改变已认证的安全包络。

**定义 312（漂移率 DRC）** 对世界占据/速度场定义 ρ_t = lim_{δ→0} (1/δ)·E[W₁(P_{t+δ}, P_t)] / d_safe，用短滞后预测新息估计；按方向分解为横向 ρ_lat（最危险）与纵向 ρ_lon。语义：**世界每秒吃掉多少安全裕度**。

**定义 313（三重时钟 TVH）** 碰撞钟 τ_ttc = (d_min − d_safe)/v_rel⁺；预测钟 τ_pred = 预测分布仍满足校准（R69 MCG 的时域版）的最长时域；保底钟 τ_reflex = 当前保底反射轨迹的认证剩余有效期。**截止时间 τ_hard = min(τ_ttc, τ_pred, τ_reflex)**，允许推理的窗口为 [t, t+τ_hard)。

**定义 314（时间安全管 TSC）** 在时延 Δ 与漂移界 ρ̄ 下，膨胀可达集 ℛ_⊕(Δ) = ℛ(Δ) ⊕ B(ρ̄Δ) ⊕ A_delay（A_delay 为自车执行延迟）。计划 π 的时间证书要求 ∀τ∈[0,Δ]：𝒪(π(τ)) ∩ ℛ_⊕^obs(τ) = ∅。证书带 TTL：expire = t + τ_hard。

**定义 315（价值计算 VoC 与停止规则 MRC）** 选级 b* = argmax_{ℓ∈ℒ, L_ℓ<τ_hard} VoC(ℓ)，其中 VoC(ℓ) = E[U(π_ℓ)] − c(L_ℓ) − κ·L_ℓ·ρ_t（后两项为计算成本与漂移折旧）。停止规则：若 VoC(ℓ_{k+1}) − VoC(ℓ_k) ≤ 0，或 L_{ℓ_{k+1}} ≥ τ_hard，则停。**R69 的 mode_head 门控是 ρ=0、L=0 时该规则的退化。**

**定义 316（安全推理不变式 RGI）** 记 𝒫_reflex(t) 为 t 时刻已认证反射集。不变式：∀t, 𝒫_reflex(t) ≠ ∅；且推理只在 τ_reflex(t) > L_{当前rung} 时推进；若即将耗尽，立即中断并执行最大裕度反射。**「任何时刻都有退路」是全部时间安全证明的基石（定理 19）。**

**定义 317（动态歧义的对抗策略 CAS）** 障碍物意图多模态 {m_k}，权重 w_k。若消歧所需时间 Δ_disamb > τ_hard，则**不追求识别**，改选 contingency 计划：π_hedge = argmax_π min_k Safety(π, m_k)，s.t. 覆盖质量 Σ_{k∈C} w_k ≥ 1−δ。R69 的「先问再做」是 Δ_disamb < τ_hard 的特例。

**定义 318（时效性交互 SID）** 信息动作 g 在 t 发出、t+Δ_g 收到。有效 VoI：VoI_eff(g) = VoI₀(g)·P(valid at t+Δ_g) − c(g) − c_hold(Δ_g)，其中 c_hold 是等待期间维持安全保持轨迹的代价与风险。若 Δ_g ≥ τ_hard 或 VoI_eff ≤ 0，则不交互。答案到达后仍须同时通过 R69 的 k 源证据纪律**与**定义 319 的 TTL；过期答案只作先验，不作定案。

**定义 319（执行时再认证 / TTL）** 动作与证书携带 (timestamp, ρ̄ 界, τ_hard, plan_hash)。在 actuation 时刻 t′ 做 dispatch revalidation：若 t′ > expire、或实测 ρ > ρ̄、或观测偏移超界，则证书作废并回退 ℓ₀。**规划时安全 ≠ 执行时安全**；再认证开销 < 0.05ms。

**定义 320（时限账本 DLB 与计算 DoS）** 单位时间最坏计算预算 B_max 与强制回退次数上限。若外部输入持续触发高阶 rung（敌手制造歧义或 OOD），账本在耗尽前先降级并告警，绝不允许「计算饥饿 → 超时 → 无保底」。这是 R69「交互预算」的计算资源版。

**定义 321（时限干扰集 ℰ_TEMPO）** ℰ_TEMPO = ℰ_FLUID × ℰ_latency（计算 DoS/强制超时）× ℰ_stale（迟到回答/过期证书被误用）× ℰ_reflex（保底反射本身不安全，如急刹被追尾）。

**定义 322（时限审计 VQAuditor-T）** 审计「时间决策」：是否在保底耗尽前继续推理、是否漏做再认证、是否在截止后采纳过期答案、Δ_g 是否被低估。结论回灌账本，成为下轮 rung 的质量/时延先验。

**定义 323（证书 J_TEMPO）** J_TEMPO = (J_FLUID, τ_hard_min, rung_used, voc_trace_hash, reflex_margin, dispatch_reval_hash, staleness_p99, tempo_ver)。Valid ⇔ Valid(J_FLUID) ∧ ∀t 有保底 ∧ 每次执行都过再认证 ∧ 账本未透支。

**定义 324（向 R69 的退化）** 当 ρ→0、A_delay→0、Δ_g→0 ⇒ τ_hard→∞、τ_reflex→∞、c_hold→0：VoC 停止规则退化为 R69 的 mode_head/ambiguity 门控，CAS 退化为 MINT，TSC 退化为快照认证。故 **R69 = TEMPO 在「静止世界 + 零延迟」边界上的逐指令退化**，安全侧不弱于 R69。

## 2. 关键算法骨架

```python
# IP-264 AIP：可中断 anytime 阶梯（任意级都能立即交出动作）
class AnytimePolicy:
    def rung(self, ell, o_t):
        if ell == 0: return reflex_stop(o_t)                    # O(1) 保底反射
        if ell == 1: return self.flow.sample(o_t, K=1, N_step=1)[0]
        if ell == 2: return self.flow.sample(o_t, K=1, N_step=2)[0]   # R69 常规
        if ell == 3: return self.flow.best_of(o_t, K=4, N_step=2)     # R69 歧义
        if ell == 4: return self.mint_choose(o_t)               # 交互（含等待）
        raise ValueError

# IP-265/266 DRC + 三重时钟：截止时间是世界给的
def deadline_clock(o_t, reflex_cert, pred, mc_gate):
    rho        = drift_rate(o_t)                                # 定义 312
    tau_ttc    = clearance_time(o_t)                            # 碰撞钟
    tau_pred   = pred.valid_horizon(o_t, mc_gate)               # 预测钟
    tau_reflex = reflex_cert.time_to_expiry(o_t)                # 保底钟
    return min(tau_ttc, tau_pred, tau_reflex), rho

# IP-267 MRC：价值计算停止规则（收益 - 计算成本 - 漂移折旧）
def choose_rung(ladder, tau_hard, rho):
    best, best_voc = 0, ladder[0].value
    for ell in ladder[1:]:
        if ell.latency >= tau_hard: break                  # 来不及 → 不升
        voc = ell.value - ell.cost(ell.latency) - KAPPA*rho*ell.latency
        if voc <= best_voc: break                          # 边际 VoC<=0 → 停
        best, best_voc = ell, voc
    return best

# IP-270 SID：时效性交互（迟到答案严格打折；来不及就不问）
def speculative_interact(o, budget, tau_hard):
    best = None
    for g in info_action_candidates(o):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o): continue
        d_g = estimate_answer_latency(g)
        if d_g >= tau_hard: continue                       # 问了也白问
        voi = (info_gain(g) * p_valid(d_g)
               - cost(g) - hold_cost(d_g))
        if best is None or voi > best.voi: best = (g, voi, d_g)
    return best if best and best.voi > 0 else None         # 否则去对冲

# IP-276 主闭环（继承 R69，在时间维度上加三层：保底、元推理、再认证）
def TEMPO_RAS_round(M, obs):
    z, o = M.mtm.forward(obs)                          # R69 一次前向
    c, U_cal, thr = M.cof.step(o)                      # R69 标定
    tau_hard, rho = M.drc.deadline_clock(o, M.reflex_cert, M.pred, c.mc_gate)
    # 1) RGI：先保底，后思考；没有退路就不做高阶推理
    if not M.rgi.reflex_available(o, tau_hard):
        return M.rgi.emergency(o)
    # 2) anytime 阶梯 + 元推理停止（时间不足时自动降到低阶）
    ell = M.mrc.choose_rung(M.ladder, tau_hard, rho)
    xi  = M.aip.rung(ell, o)                           # 可中断
    # 3) 动态歧义：来得及消歧才交互，来不及则对冲
    if M.aud.ambiguity(xi) > TAU_EPI:
        if M.drc.time_to_disambiguate(o) < tau_hard:
            xi = M.sid.speculative_interact(o, M.budget, tau_hard) or xi
        else:
            xi = M.cas.hedge(o, M.aud.modes(xi))       # 覆盖集鲁棒计划
    # 4) 对「推理时延 + 执行延迟」膨胀可达集后再认证
    cert = M.tsc.certify(xi, o, delay=M.aip.latency(ell),
                         drift_bound=rho, ttl=tau_hard)
    if not cert.ok:
        xi, cert = M.rgi.fallback(o)
    # 5) 执行时再认证：船到桥头再验票（规划时安全 != 执行时安全）
    if not M.tsc.revalidate(cert, o_now, rho_now, t=M.t_now):
        xi, cert = M.rgi.fallback(o_now)
    # 6) R69 证据纪律仍生效；过期答案只作先验，不作定案
    xi = M.cia.apply_with_ttl(xi, cert, evidence=M.sid.pending)
    # 7) 时限审计 + 证书
    M.vqa_t.submit_async(ell, tau_hard, rho, cert, M.dlb.snapshot())
    return xi, cert, ell
```

## 3. 推导

**引理 19（有效性时域对漂移的单调性）** τ_hard 关于 ρ 与 v_rel 单调不增；且 τ_reflex 关于 ρ 单调不增。系：漂移越快，可负担的推理越少——「更快」不是一种优化选择，而是被世界强制的降级路径。

**引理 20（时效折扣 VoI）** 记等待代价含安全保持轨迹风险 c_hold(Δ_g) 与漂移暴露 κΔ_g。则 VoI_eff(g) ≤ VoI₀(g) − c_hold(Δ_g) − κΔ_g；且当 Δ_g ≥ τ_hard 时 VoI_eff ≤ 0。系：动态场景中「问一个来不及回答的问题」被「立即对冲」严格支配；R69 只优化 VoI₀，系统性忽略了时间项。

**引理 21（contingency 覆盖安全）** 若 π_hedge 对覆盖集 C 内所有模态安全、且 Σ_{k∈C} w_k ≥ 1−δ，则对未识别模态的碰撞概率 ≤ δ + ε_model。系：来不及识别时，**对冲比识别更安全**——前提是覆盖集本身正确（这正是本引理的假设 A105，也是最大风险所在）。

**定理 18（TEMPO 严格包含 R69）** 在 A99–A103（漂移有界、执行延迟有界、阶梯质量单调）下，TEMPO 在任意状态的期望风险 ≤ R69；且当 ρ→0、A_delay→0、Δ_g→0 时两者**逐指令相同**（定义 324）。R69 是「静止世界 + 零延迟」边界；安全全保留，时延收益来自 rung 选择与非交互对冲。

**定理 19（安全推理 / 无盲区）** 若 RGI（定义 316）保持、且每次执行前过 TSC 再认证（定义 319），则系统在任意时刻都存在一条已认证的后续轨迹；推理时长不改变「存在安全动作」这一性质 ⇒ 因超时导致的碰撞概率 ≤ ε_reflex。关键：**可中断 + 保底 + 执行时再验票，三者缺一不可**。

**定理 20（停止规则的近优性）** 在质量-时延阶梯单调、时延可加、漂移折旧线性（A104）下，定义 315 的边际 VoC 停止规则在硬截止 τ_hard 下是 (1−η)-近优的；固定 K 的 R69 在 τ_hard < L_{K=4} 时误差无界（要么盲目超时、要么浪费本可用于行动的时间）。

## 6. 本轮最大风险

**一句话**：TEMPO-RAS 把安全押在「任何时刻都存在一条已认证的保底反射」上——但在密集动态场景中这个前提可能根本不存在（没有安全退路），或者反射本身才是最危险的动作（急刹被追尾）；而漂移率被低估会让 τ_hard 虚高、系统误以为「还有时间再想」，**时间不是免费的，但「以为还有时间」最致命**。

**次级风险与缓解**：
1. **保底反射陷阱**（反射本身不安全）→ 反射也纳入 TSC 认证 + 定义 316 的反射裕度，不达标即提前减速；
2. **漂移率低估/对抗机动** → 保守 ρ̄ + 预测新息在线校正 + E303 低估率硬门；
3. **计算 DoS / 强制超时** → DLB 账本 + B_max 截断 + 账本透支前主动降级；
4. **过期答案被误用** → TTL + 执行时再认证 + 证据纪律双门（E310 零误用）；
5. **contingency 覆盖集错设** → 覆盖质量下限 + 未覆盖质量显式计入风险 + E308 对抗测试。

class AnytimePolicy:
    def rung(self, ell, o_t):

        if ell == 1: return self.flow.sample(o_t, K=1, N_step=1)[0]
        if ell == 2: return self.flow.sample(o_t, K=1, N_step=2)[0]   # R69 常规

# IP-265/266：漂移率 + 三重时钟（截止时间是世界给的）
def deadline_clock(o_t, reflex_cert, pred, mc_gate):
    rho        = drift_rate(o_t)                          # 定义 312
    tau_ttc    = clearance_time(o_t)                      # 碰撞钟
    tau_pred   = pred.valid_horizon(o_t, mc_gate)         # 预测钟（R69 MCG 时域版）
    tau_reflex = reflex_cert.time_to_expiry(o_t)          # 保底钟
    return min(tau_ttc, tau_pred, tau_reflex), rho

# IP-267：VoC 停止规则（收益 - 计算成本 - 漂移折旧）
def choose_rung(ladder, tau_hard, rho):
    best, best_voc = 0, ladder[0].value
    for ell in ladder[1:]:
        if ell.latency >= tau_hard: break                 # 来不及 → 不升
        voc = ell.value - ell.cost(ell.latency) - KAPPA*rho*ell.latency
        if voc <= best_voc: break                         # 边际 VoC<=0 → 停
        best, best_voc = ell, voc
    return best

# IP-270：时效性交互（答得晚就严格打折；来不及就不问）
def speculative_interact(o, budget, tau_hard):
    best = None
    for g in info_action_candidates(o):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o): continue
        d_g = estimate_answer_latency(g)

        voi = info_gain(g) * p_valid(d_g) - cost(g) - hold_cost(d_g)
        if best is None or voi > best.voi: best = (g, voi, d_g)
    return best if best and best.voi > 0 else None        # 否则去对冲

## 4. 推导

**引理 19（有效期对漂移单调）** `τ_hard` 关于 `ρ` 与 `v_rel` 单调不增，`τ_reflex` 关于 `ρ` 单调不增。系：漂移越快，可负担推理越少——「更快」不是优化选择，而是被世界强制的降级路径。

**引理 20（时效折扣 VoI）** `VoI_eff(g) ≤ VoI₀(g) − c_hold(Δ_g) − κΔ_g`；当 `Δ_g ≥ τ_hard` 时 `VoI_eff ≤ 0`。系：动态场景中「问一个来不及回答的问题」被「立即对冲」严格支配；R69 只优化 `VoI₀`，系统性忽略时间项。

**引理 21（contingency 覆盖安全）** 若 `π_hedge` 对覆盖集 `C` 内所有模态安全且 `Σ_{k∈C} w_k ≥ 1−δ`，则未识别模态碰撞概率 `≤ δ + ε_model`。系：来不及识别时，对冲比识别更安全——前提是覆盖集正确（A105，亦为本轮最大风险）。

**定理 18（TEMPO 严格包含 R69）** A99–A103 下，TEMPO 任意状态期望风险 ≤ R69；且 `ρ→0, A_delay→0, Δ_g→0` 时两者逐指令相同。R69 = 「静止世界 + 零延迟」边界；安全不让步，时延收益来自 rung 选择与非交互对冲。

**定理 19（安全推理 / 无盲区）** 若 RGI 保持且每次执行前过 TSC 再认证，则任意时刻都存在已认证后续轨迹；推理时长不改变「存在安全动作」⇒ 超时碰撞概率 `≤ ε_reflex`。可中断 + 保底 + 执行时再验票，三者缺一不可。

**定理 20（停止规则近优）** 质量-时延阶梯单调、时延可加、漂移折旧线性（A104）下，定义 315 的边际 VoC 停止规则在硬截止 `τ_hard` 下是 `(1−η)`-近优；固定 K 的 R69 在 `τ_hard < L_{K=4}` 时误差无界（盲目超时或浪费行动窗口）。

## 7. 本轮最大风险

**一句话**：TEMPO-RAS 把安全押在「任何时刻都存在一条已认证的保底反射」上——但在密集动态场景中这个前提可能根本不存在（没有安全退路），或者反射本身才是最危险的动作（急刹被追尾）；而漂移率被低估会让 `τ_hard` 虚高、系统误以为「还有时间再想」，**时间不是免费的，但「以为还有时间」最致命**。

**次级风险与缓解**：保底反射陷阱（反射也纳入 TSC 认证 + 定义 316 裕度，不达标即提前减速）；漂移率低估/对抗机动（保守 `ρ̄` + 新息在线校正 + E303 低估率硬门）；计算 DoS/强制超时（DLB + `B_max` 截断 + 透支前降级）；过期答案误用（TTL + 再认证 + 证据纪律双门，E310 零误用）；contingency 覆盖集错设（覆盖质量下限 + 未覆盖质量显式计风险 + E308 对抗）。
