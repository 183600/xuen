# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「传感器标定」×「虚实迁移」）

> R69 做了两件漂亮的事：把不确定性一分为二（aleatoric 收紧、epistemic 去问），并让「看/问/触」成为可通过 C-RAS-WM 认证、可被审计的动作。它还用一条对偶通道回应了 R68 的最大风险：传感器残差 `r_res` 会被标定吸收，但动作在策略密度下的似然 `Δa` 不会。问题在于——**这条「不会被标定吸收」的第二意见，本身建立在一个从未被标定的对象上：策略与世界模型。** `p_θ` 在仿真/有限数据上训练，它对「什么叫正常行为」的定义自带一个**现实差距（reality gap）**。于是 R69 实际上是在用一把没校准过的尺子去量另一把尺子：
> - **误报**：真实世界只是与仿真不同（摩擦、延迟、柔顺、载荷），`Δa` 就升高 → 系统误判「缓变故障」，为自保一路收紧，效率塌掉；
> - **漏报**：仿真被域随机化覆盖得过宽，策略对错误行为也给出高似然 → `Δa` 沉默，真正的故障被「这是迁移差距」解释掉，比 R68 的「标定吸收」更隐蔽；
> - **根因错位**：R69 自陈的最大风险（模态分布不可信 → 自信地追问幻影）根本不是流模型的毛病，而是**训练分布/数据配比**的毛病，也就是虚实迁移的毛病。
>
> 本轮两个灵感正好把这把尺子也纳入标定：
> - **传感器标定**给出的不是一个数，而是一张**证书**：参数估计 + Fisher 信息/可辨识性 Gramian + 有效支撑集 + 保质期。没被励磁过的方向，残差再小也不等于标定正确。
> - **虚实迁移**给出的不是一次域随机化，而是**把现实差距当作可辨识参数去辨识**：sim-to-real 与传感器标定是同一个逆问题的两个层级——都靠锚点、都靠励磁、都只在被励磁的支撑集内有效。
>
> 核心命题：**把「标定」从传感器层上升到模型层。R69 信任的策略密度，和 R68 信任的传感器参数一样，都必须带着可辨识性证书（支撑集、误差椭球、保质期）才能被使用；现实差距是被励磁才可辨识的参数；同一个信息动作可以同时消解任务歧义与励磁差距参数（双用途），但安全永远优先；当（传感器, 差距）的联合可信集宽到可以解释任意外观时，证书作废，退回 R68 纯保守——绝不用「这是迁移差距」把真故障洗白。** 命名 **BRIDGE-RAS**（Bidirectional Reality-gap Identification with Dual-purpose Gainful Excitation）。

> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我用来求证的模型本身还准吗，它从仿真带过来的那套信念在这个真实场景里还有效吗**」——校准不是一张一次性执照，而是一张有辖区、有保质期、要靠励磁续期的证书。

## 0. 直觉与动机

**灵感 1（传感器标定 → 「已标定」不是布尔值，而是一张带辖区与保质期的证书）**
直觉：现场标定从来不是「拍一张标定板就一劳永逸」。你没绕某个轴转过，那个轴的外参就不可观测；你没在高温下励磁过，温漂系数就无法辨识。于是「标定成功（残差 ≈ 0）」可能只是**自洽**，不是**正确**——参数可以在一个与观测零空间正交的方向上任意偏，而残差纹丝不动。R68/R69 把标定压缩成一个标量 `r_res` 和一个 `U_cal`，恰好丢掉了这个结构。R70 把标定升级为四元组 **C_θ = (θ̂, Λ_θ, S_θ, T_exp)**：估计、误差协方差（Fisher 信息之逆）、有效支撑集（被充分励磁的状态/位姿集合）、保质期（漂移模型下的失效时刻）。一句话：**标定是一张有辖区、有期限的许可证，不是一条永久事实。**

**灵感 2（虚实迁移 → 现实差距是可辨识参数，而不是需要被随机化掩盖的噪声）**
直觉：sim-to-real 本质上是对仿真器做系统辨识——摩擦、延迟、柔顺、执行器增益、传感时延，都是有物理含义的参数 `γ`。域随机化是「用分布覆盖未知」，代价是把 `γ` 的先验放得很宽，导致策略学会「什么都能接受」。R70 反过来：用成对的 sim–real 锚点（同一段励磁轨迹在仿真与真机上的响应）去**估计** `γ`，并像标定一样给它一张 `(γ̂, Λ_γ, S_γ, T_exp)` 证书。差距不是要消灭的敌人，而是要**被观测、被记账、被限权**的状态。

**灵感 3（对偶 → 传感器标定与虚实迁移是同一个逆问题的两个层级）**
直觉：令 `c` 为传感器参数（世界 → 测量），`γ` 为差距参数（仿真动力学 → 真实动力学）。两者都靠锚点（标定靶 / 成对 rollout）、都靠励磁（足够丰富的运动）、都只在被励磁的方向上可辨识、都会随温度/负载/磨损漂移。既然如此，就该有一本**统一的可辨识性账本** `L = {(c, O_c, S_c), (γ, O_γ, S_γ)}`，而不是两套互不相干的补丁。R69 的 MINT 只看任务模态熵；R70 让它同时看到「这次动作能给差距参数注入多少 Fisher 信息」，于是同一个动作可能既看清岔路、又让摩擦系数更可辨。

**灵感 4（第三通道 → 用「差距解释度」区分真故障、迁移差、与不可辨识标定）**
直觉：R69 的 `Δa` 升高至少有三种解释：(i) 真的缓变故障；(ii) 良性现实差距；(iii) 某个未被励磁、因而不可辨识的标定方向在悄悄偏。只加一个差距项还不够，必须把 `c` 与 `γ` 的**联合可信集**摊开：在 `C_c × C_γ` 内取最坏似然，得到「可解释异常包络」。异常落在包络内 ⇒ 不必报故障（但要记账）；落在包络外且 `r_res` 低 ⇒ 真故障，且是被标定/迁移联合掩盖的故障；包络本身宽到能解释一切 ⇒ 证书作废，退回 R68 纯保守。这样 R69 的「要么误报要么漏报」才被拆成一个可判别的三分。

**灵感 5（信息动作是双刃剑的升级版 → 励磁也要安全，且不能自我循环地论证）**
直觉：R69 已经意识到「交互会引入新攻击面」；R70 的新攻击面更深——**励磁动作本身可能是有害的**（为了辨识摩擦而打滑、为了辨识延迟而急停），而且可能是**自欺的**：如果由同一个（可能错的）模型来决定「去励磁哪些方向」，它可能系统性地避开那些会暴露自己错误的方向，形成「闭环不可辨识」——系统不停地给自己发证书，越会论证越无法发现自己论证的循环。因此必须交付：励磁的硬安全包络、独立锚点审计、差距模型的容量上限（防止「迁移吸收」），以及证书的「自证无效」规则。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（BRIDGE-RAS 总览与四不变式）** BRIDGE-RAS = (SCC, GID, DEX, TCS, GRL, FDR, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i / R68 定义 276-i）；
(ii) **可辨识性诚实**：任何标定/差距估计不得在其证书支撑集之外被当作确定量使用；出了辖区一律声明「未知」，不得外推；
(iii) **信息不得凌驾安全**：任何励磁/交互动作必须先过硬安全包络，可辨识性增益永远不优先于安全（R69 证据纪律的强化）；
(iv) **严格包含**：当差距为零、证书全局有效且无未辨识方向时，BRIDGE 逐指令退化为 FLUID-RAS，再退化为 CALM-RAS。

**定义 311（双层级标定对象）** 传感器标定参数 `c ∈ C ⊂ ℝ^{d_c}`（内参、外参、噪声、时延）；现实差距参数 `γ ∈ Γ ⊂ ℝ^{d_γ}`（摩擦、阻尼、柔顺、执行器增益、传感/控制时延、质量负载）。二者统一记为 `θ ∈ {c, γ}`。锚点集：`c` 用已知标定靶/已知运动，`γ` 用同一段励磁轨迹的成对 sim–real rollout；`γ=0` 表示仿真与真实一致。

**定义 312（可辨识性 Gramian 与标定证书 SCC）** 给定励磁轨迹 `u_{1:T}` 与观测模型 `h(·;θ)`（线性化 Jacobian `H_t = ∂h/∂θ`），Fisher 信息 `J(θ) = Σ_t H_t^T Σ^{-1} H_t`（非线性系统可辨识性 Gramian 的推广）。证书 `C_θ = (θ̂, Λ_θ, S_θ, T_exp)`：
- `Λ_θ ⪰ J(θ̂)^{-1}`（Cramér–Rao 误差下界；Laplace 近似取等号）；
- 支撑集 `S_θ = { x : λ_min(J(θ;x)) ≥ κ_θ }`，即励磁足够、参数可分辨的状态集合；
- 保质期 `T_exp`：由漂移模型 `θ(t+1)=θ(t)+w_t`（`w_t` 慢变）与 `Λ_θ` 的增长率给出的有效截止时刻。
**「已标定」⇔ `x ∈ S_θ` ∧ `t < T_exp` ∧ `λ_min(J) ≥ κ_θ`**。注意：`r_res ≈ 0` 只是残差自洽，**不蕴含**上式（见引理 19）。

**定义 313（现实差距辨识 GID 与差距证书）** 差距由参数化映射给出：`f_real ≈ f_sim(·;γ)`、`h_real ≈ h_sim(·;γ)`。用成对锚点最小化 sim–real 响应差得到 `γ̂`，Fisher 信息 `J_γ`，证书 `C_γ = (γ̂, Λ_γ, S_γ, T_exp^γ)`，形式同定义 312。差距诱导的行为似然偏移 `b_γ(ξ,o) = E_real[−log p_θ(ξ|o;γ)] − E_sim[−log p_θ(ξ|o;0)]`；报告「差距解释度」用其线性化代理 `Δa_γ = b_γ(ξ,o)`。

**定义 314（统一可辨识性账本 IHL）** `L = {(c, J_c, S_c, T_c), (γ, J_γ, S_γ, T_γ)}`，并维护联合可信集 `C_{cγ} = C_c × C_γ`（若两者相关则用联合后验）。账本的每次更新都附带「本次励磁给哪些方向增加了信息、哪些方向仍然是零空间」。**任何下游决策（尤其 R69 的 FMA）必须查询账本，而不是查询单个标量残差。**

**定义 315（双用途励磁与增广动作空间）** 在 R69 的 `ξ=(a,g)` 上再增广励磁分量 `e ∈ 𝒜_exc`：`ξ = (a, g, e) ∈ 𝒜_task × 𝒜_info × 𝒜_exc`。动作 `e` 对任务模态的 Fisher 信息为 `I_task(e)`，对 `(c,γ)` 的信息为 `I_id(e)`。**双用途** ⇔ 两者均非零；**共享增益**受两个观测子空间重叠度限制（见引理 21），因此一般不能指望一个动作既消歧又完成辨识。

**定义 316（可辨识性感知配给 DEX）** 候选动作 `e` 的联合信息价值
`J(e) = VoI_task(e) + β_g · IG_gap(e) − c(e)`，
其中 `VoI_task` 继承 R69 定义 298，`IG_gap(e) = ½ log det(J_γ + I_id(e)) − ½ log det(J_γ)`（D-最优增益，加单位阵做正则），`β_g` 由证书半径自适应（半径大才值得辨识）。约束：硬安全包络 ∧ 交互预算 ∧ 励磁位移/时间预算。选择 `e* = argmax J(e)`；若 `J(e*) ≤ 0` 则不励磁，退化为 R69 的纯任务交互。安全为字典序第一目标：任何 `e` 只要触碰硬包络即被剪除，`β_g` 再大也不能复活它。

**定义 317（迁移证书 TCS）** `TCS(x,t) = Valid` ⇔ `x ∈ S_c ∩ S_γ` ∧ 两个证书均未过期 ∧ `r_γ := √(tr Λ_γ) ≤ τ_γ` ∧ **差距可解释半径** `R_expl := sup_{θ∈C_{cγ}} |Δa(θ)| ≤ τ_expl`。`TCS` 是 R69 流似然通道的**门控**：只有 `Valid` 时 `Δa` 才能作为故障证据；否则流似然被声明为「在本辖区不可信」，一律走保守分支。`R_expl` 的直观含义：联合可信集最多能把多大的异常「解释掉」。

**定义 318（差距鲁棒似然 GRL）** 不使用插件估计 `γ̂`，而是对联合可信集取最坏情形：
`a_score^robust(ξ,o) = max_{(c,γ) ∈ C_{cγ}} [−log p_θ(ξ | o(c,γ); γ)]`。
这是分布鲁棒/最小似然准则，目的是消除「用点估计把不确定性抹平成自信」的漏报。对应地定义**可解释异常** `Δa_expl = a_score^robust − a_score(o; 0)`。

**定义 319（三通道故障判别 FDR）** 观测量：`r_res`（R68 传感器残差，对可检测故障敏感）、`Δa`（R69 流似然差）、`Δa_expl`（差距+不可辨识标定的可解释部分）。定义**残余异常** `Δa_res = Δa − Δa_expl`（负值截断为 0）。判别：
1. `TCS` 无效 ⇒ **不可信**：禁用 FMA 与差距校正 VoI，退化 R68 保守；
2. `TCS` 有效 ∧ `r_res ≤ τ_r` ∧ `Δa_res ≤ τ_a` ⇒ **正常 / 良性差距**（只记账，不报故障）；
3. `TCS` 有效 ∧ `r_res > τ_r` ⇒ **可检测传感器故障**（交 R68）；
4. `TCS` 有效 ∧ `r_res ≤ τ_r` ∧ `Δa_res > τ_a` ⇒ **被标定/迁移联合掩盖的缓变故障**（R69 FMA 的本意，但现在扣除了差距解释）。
**迁移解释预算**：若 `R_expl > τ_expl`（即任何异常都能被解释），直接进入分支 1，**绝不允许差距模型无限吸收异常**。

**定义 320（励磁安全：信息—安全分离）** 励磁动作 `e` 需过 C-RAS-WM 前缀认证，额外要求端到端物理风险 `risk(e) ≤ ε_exc` 且不得使任何安全裕度单调变差。若任务与励磁冲突，采用时间分离：任务优先，励磁只在「计划允许的低风险窗口」执行；窗口不存在则放弃励磁。**可辨识性是可选项，不是安全关键项。**

**定义 321（回锚与续期 RAS-R）** 当 `x ∉ S_c ∩ S_γ`、证书过期、或 `R_expl` 越界时，触发回锚管理器：在安全窗口内求解 `e_re = argmax IG(c,γ | e)`，满足定义 320 与回锚频率约束 `rate ≤ ρ_re`。回锚失败的后果是单调降级：先禁用差距 VoI，再禁用交互，最后回到 R68 纯保守。回锚成功则更新账本并续期证书。

**定义 322（证书门控与严格包含）** 门控顺序：`TCS` 无效 → R68 保守；`TCS` 有效但差距可信集退化（`Λ_γ → 0` 且 `γ=0`）且 `S_γ` 全局 → 跳过 DEX，BRIDGE 逐指令等于 FLUID-RAS；再无 `c` 未辨识方向 → 等于 CALM-RAS。安全侧永不弱于 R69，效率侧只在证书允许时获得「差距校正红利」。

**定义 323（对抗性迁移干扰集）** `ℰ_transfer` 包含：差距参数投毒（用伪造锚点把 `γ̂` 拉向错误值）、可辨识性遮蔽（让 `J_γ` 在关键方向秩亏）、证书膨胀（放大 `R_expl` 以吸收真故障）、闭环不可辨识（励磁策略系统性避开暴露自身错误的方向）。并入 AIC：`ℰ_BRIDGE = ℰ_FLUID × ℰ_transfer`。

**定义 324（在线 D-最优励磁与预算）** 在流式场景中维护 `J_γ` 与 `J_c` 的递归更新；励磁选择采用带成本的 D-最优贪心：`e* = argmax [log det(J + I_id(e)) − log det J − μ·c(e)]`，并用遗忘因子处理漂移。预算按「每单位时间励磁位移 / 次数」硬约束，保证慢回路不侵占实时控制回路。

**定义 325（证书 J_BRIDGE）** `J_BRIDGE = (J_FLUID, cert_c_hash, cert_γ_hash, R_expl, gap_credible_radius, delta_a_res_p95, re_anchor_count, transfer_ver)`。Valid ⇔ `Valid(J_FLUID)` ∧ `TCS` 在本回合有效 ∧ 激励/回锚未越界 ∧ 独立锚点审计通过。

## 2. 关键算法骨架

```python
# IP-264 SCC：标定证书（不是标量残差）
class CalibrationCertificate:
    def __init__(self, theta_hat, fisher, support, expiry):
        self.theta, self.J, self.S, self.T = theta_hat, fisher, support, expiry
    def valid(self, x, t):
        return (x in self.S) and (t < self.T) and (lambda_min(self.J) >= KAPPA)
    def covariance_bound(self):
        return inv(self.J)                    # Cramér–Rao / Laplace

# IP-265 GID：现实差距作为可辨识参数（成对 sim-real 锚点）
class GapIdentifier:
    def fit(self, paired_rollouts):           # (u, y_sim, y_real)
        gamma_hat, J_gamma = nonlinear_least_squares(
            resid=lambda g: y_real - f_sim(u, g),
            jac=lambda g: -df_sim_dgamma(u, g))
        return CalibrationCertificate(gamma_hat, J_gamma,
                                      support_of(J_gamma), expiry_of(J_gamma))

# IP-266 DEX：可辨识性感知的双用途配给（安全字典序第一）
def choose_information(modes, ledger, budget, o_t):
    best = None
    for e in candidate_actions(modes):        # 看/问/触/励磁 的联合候选
        if not budget.allow(e):                 continue
        if not c_ras_wm.certify(e, o_t):        continue   # 硬安全包络
        if risk_of(e) > EPS_EXC:                continue
        voi = task_voi(modes, e)
        ig  = d_optimal_gain(ledger, e)         # ½ log det(J + Iid) - ½ log det J
        score = voi + beta_g(ledger) * ig - cost(e)
        if best is None or score > best.score:
            best = (e, score)
    return best if best and best.score > 0 else None

# IP-267/268/269 TCS + GRL + FDR：门控、鲁棒似然、三通道判别
def transfer_gate(ledger, x, t):
    valid = (x in ledger.S_c and x in ledger.S_gamma
             and ledger.t_c > t and ledger.t_gamma > t)
    R_expl = worst_case_explained_anomaly(ledger.C_c_gamma, x)
    return valid and (R_expl <= TAU_EXPL), R_expl

def robust_likelihood(policy, xi, o, ledger):
    return max(-policy.log_likelihood(xi, apply(o, c, g))
               for (c, g) in credible_samples(ledger.C_c_gamma))

def fault_discriminator(r_res, a_score, a_robust, ledger):
    valid, R_expl = transfer_gate(ledger, o.x, o.t)
    if not valid:                       return 'UNTRUSTED'   # -> R68 保守
    delta_a = a_score - a_score_calibrated
    delta_res = max(0.0, delta_a - a_robust)               # 扣除差距解释
    if r_res > TAU_R:                   return 'SENSOR_FAULT'
    if delta_res > TAU_A:               return 'HIDDEN_SLOW_FAULT'
    return 'NORMAL_OR_BENIGN_GAP'

# IP-274 主闭环（继承 R69，在「第二意见」处插入模型标定层）
def BRIDGE_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(o)     # R68 标注
    # 1) 先问账本：本辖区证书是否有效？
    valid, R_expl = transfer_gate(M.ledger, o.x, o.t)
    # 2) 任务不确定性（沿用 R69），但交互选择增加励磁项
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    g = (M.dex.choose_information(modes, M.ledger, M.budget, o)
         if (valid and U_epi > TAU_EPI) else None)
    if g is not None:
        U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    # 3) 第二意见：只在证书有效时启用；否则直接保守
    a_hat = M.grl.robust_likelihood(M.fmp, M.last_action, o, M.ledger)
    verdict = M.fdr.classify(M.last_r_res, M.last_a, a_hat, M.ledger)
    slow = (verdict == 'HIDDEN_SLOW_FAULT')
    # 4) 风险缩放：与 R69 相同，但 UNTRUSTED 退回 R68
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ...)
    if verdict == 'UNTRUSTED' or slow:
        lam = max(lam, LAMBDA_HARD); k = min(k, k_cal_shrink(x_prime, U_cal))
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 5) 慢回路：回锚/续期 + 参与式审计 + 证书
    M.ras_r.maybe_reanchor_if(M.ledger, o, M.budget)
    M.vqa_i.submit_async(g, verdict, R_expl, a_hat)
    return k, lam, mode, (U_ale, U_epi, verdict)
```

## 3. 推导

**引理 19（残差自洽 ≠ 标定正确）** 设参数误差 `δ = θ̂ − θ*`，残差 `r = h(θ*) − h(θ̂) ≈ H δ`。若 `δ` 落在 `H` 的零空间（`Hδ ≈ 0`），则 `‖r‖ ≈ 0` 而 `‖δ‖` 可以任意大；此时 `J = H^TΣ^{-1}H` 在 `δ` 方向 `λ_min(J) ≈ 0`。由 Cramér–Rao，`E‖δ‖² ≥ tr(J^{-1}) → ∞`。系：**R68/R69 用 `r_res ≈ 0` 作为「标定可信」的判据，只在被励磁方向成立；未励磁方向上的错误对残差完全隐形。** 这正是定义 312 必须携带 `S_θ` 与 `λ_min(J)` 的原因，也是 R70 对 R68 最深层假设的修正（不只是打补丁）。

**引理 20（迁移差距的可辨识窗口与判别上限）** 差距估计误差 `δ_γ ~ 𝒩(0, Λ_γ)`，`Λ_γ ⪰ J_γ^{-1}`。差距对似然的线性化影响 `b_γ^T γ`，故可解释异常的上界 `R_expl ≈ ‖b_γ‖·√(tr Λ_γ) + 高阶项`。因此把「故障 vs 差距」分开的能力由 `SNR = |b_γ^T δ_γ^fault| / ‖b_γ‖√(tr Λ_γ)` 决定：励磁越充分（`λ_min(J_γ)` 越大）窗口越窄、判别 AUC 越高；反之差距与故障不可分辨。系：**E289 类实验的 AUC 存在一个由励磁决定的硬上界，不能靠调阈值突破，只能靠加励磁。**

**引理 21（双用途励磁的共享增益有限）** 设一个动作对 `[任务模态; 差距参数]` 的联合 Fisher 信息为分块矩阵 `O = [[O_t, O_x],[O_x^T, O_g]]`。则
`log det O = log det O_t + log det(O_g − O_x^T O_t^{-1} O_x) ≤ log det O_t + log det O_g`，
等号当且仅当 `O_x = 0`（观测子空间正交）。`O_x` 的大小由两方向观测的互信息界定。系：**「边做边标定」不是免费的：共享增益最多等于两个独立增益之和，且只有在观测子空间近正交时才接近；冲突时必须调度时间分离（任务优先，励磁利用低风险窗口）。** 这直接约束定义 316 的 `IG_gap` 不能重复计数。

**引理 22（差距校正判别的一致性）** 若真实异常可分解为 `Δa = b_γ^T γ* + Δa_fault + ε`，且 `C_{cγ}` 以概率 `1−α` 覆盖 `(c*,γ*)`，则 `Δa_res = Δa − Δa_expl` 是 `Δa_fault` 的保守（上偏）估计，且在 `TCS` 有效时误报率 `≤ α`，漏报率由 `τ_a` 与 `‖b_γ‖√(tr Λ_γ)` 决定。**关键前提是 `R_expl ≤ τ_expl`**：一旦联合证书宽到 `R_expl → ∞`，判别退化为「全解释」，此时必须按定义 319 分支 1 判为不可信，而不是判为正常。系：**不设迁移解释预算的差距模型，会把 R68 的标定吸收升级为迁移吸收。**

**定理 18（BRIDGE 严格包含 FLUID 与 CALM）** 在定义 310–322 下，BRIDGE 在任意状态 `(x,t)` 的期望风险不高于 FLUID-RAS；且当 `Λ_γ = 0, γ* = 0, S_c = S_γ = 全集, t < T_exp`（证书永不失效且差距为零）时，`IG_gap ≡ 0`、`Δa_expl ≡ 0`、`TCS ≡ Valid`，BRIDGE 逐指令等于 FLUID-RAS；再令 `U_epi = 0` 且禁用交互，则等于 CALM-RAS。**安全侧不做任何让步，效率侧只在证书允许的辖区获得差距校正红利。**

**定理 19（励磁/回锚安全与无突变）** 任何通过定义 320 认证的励磁动作物理风险 `≤ ε_exc`；回锚只改变证书状态与后续门控，不改变当前已认证的安全包络；当 `TCS` 失效、回锚失败、或被 `ℰ_transfer` 攻击时，`λ` 单调不降、交互与差距校正单调关闭，最终退化为 R68。R68 定理 15 的提交/换装不变式保持 ⇒ 控制连续、无突变。

## 6. 本轮最大风险

**一句话**：BRIDGE-RAS 用「现实差距」去解释行为似然异常，本意是消除良性域移造成的误报；但差距模型比标定层更能吸收异常——**任何真故障都可以被贴上「这是迁移差距」的标签，于是 R68 的「标定吸收故障」被升级成「迁移吸收故障」，系统带着一张漂亮的迁移证书一路自信地错下去**；更糟的是，决定去励磁哪些方向的仍是那个可能已错的模型，形成「闭环不可辨识」，越论证越无法自证。

**次级风险与缓解**：差距/标定联合可信集过宽（`R_expl > τ_expl` 即判不可信，绝不当正常）；励磁本身不安全（定义 320 硬包络 + 定理 19）；对抗性锚点投毒与证书膨胀（ℰ_transfer + 独立锚点审计 + 证书签名的单调性检查）；慢回路侵占实时（异步 + 快回路只查表）；闭环不可辨识（引入与主模型独立的物理锚点/外部测量做审计，禁止模型给自己的励磁方向打分）。

**定义 310（总览与四不变式）** BRIDGE = (SCC, GID, DEX, TCS, GRL, FDR, RAS-WM‡)；零学习写操作继承；**可辨识性诚实**（证书外一律声明未知，不外推）；**信息不得凌驾安全**（励磁先过硬包络）；**严格包含**（零差距 + 全局证书 ⇒ 逐指令退化为 FLUID，再退化为 CALM）。

**定义 311–312（双层级标定与 SCC）** `c`（内参/外参/噪声/时延）与 `γ`（摩擦/阻尼/柔顺/增益/时延/负载）统一为 `θ`；证书 `C_θ=(θ̂, Λ_θ, S_θ, T_exp)`，`Λ_θ ⪰ J^{-1}`，`S_θ={x: λ_min(J)≥κ_θ}`；**「已标定」⇔ `x∈S_θ ∧ t<T_exp ∧ λ_min(J)≥κ_θ`**。`r_res≈0` 不蕴含该式（引理 19）。

**定义 313（GID 差距辨识）** `f_real≈f_sim(·;γ)`、`h_real≈h_sim(·;γ)`；成对 sim–real 锚点最小二乘得 `γ̂` 与证书 `C_γ`；差距似然偏移 `Δa_γ = E_real[−log p_θ] − E_sim[−log p_θ]`。

**定义 314（IHL 统一账本）** `L = {(c,J_c,S_c,T_c),(γ,J_γ,S_γ,T_γ)}`，维护联合可信集 `C_{cγ}` 与「本次励磁新增哪些方向的信息、哪些仍是零空间」。**FMA 必须查账本，而非单个残差标量。**

**定义 315–316（双用途励磁与 DEX）** 动作增广为 `ξ=(a,g,e)`；`e* = argmax[VoI_task + β_g·IG_gap − cost]`，s.t. 硬安全包络 ∧ 交互/励磁预算。安全为字典序第一目标；`β_g` 随证书半径自适应（半径大才值得辨识）。

**定义 317（TCS）** `Valid ⇔ x∈S_c∩S_γ ∧ 未过期 ∧ √(trΛ_γ)≤τ_γ ∧ R_expl≤τ_expl`。**TCS 是 R69 流似然通道的门控**：无效时 `Δa` 不得作为故障证据。

**定义 318–319（GRL 与 FDR）** `a_score^robust = max_{C_{cγ}}[−log p_θ(ξ|o(c,γ);γ)]`，`Δa_expl = a_score^robust − a_score(·;0)`，`Δa_res=max(0,Δa−Δa_expl)`。判别：TCS 无效→`UNTRUSTED`；`r_res>τ_r`→`SENSOR_FAULT`；`Δa_res>τ_a`→`HIDDEN_SLOW_FAULT`；否则 `NORMAL_OR_BENIGN_GAP`。**`R_expl>τ_expl` 直接判 `UNTRUSTED`，绝不当正常。**

**定义 320–321（励磁安全与回锚）** 励磁过 C-RAS-WM 认证且 `risk(e)≤ε_exc`、不恶化安全裕度；任务与励磁冲突时时间分离、任务优先。出支撑/过期/解释半径越界触发 D-最优回锚 `e_re`（`rate≤ρ_re`）；失败则单调降级至 R68。

**定义 322–325（门控、对抗、证书）** 门控顺序保证严格包含；`ℰ_BRIDGE=ℰ_FLUID×ℰ_transfer`（锚点投毒/可辨识性遮蔽/证书膨胀/闭环不可辨识）；`J_BRIDGE=(J_FLUID, cert_c_hash, cert_γ_hash, R_expl, radius, Δa_res_p95, re_anchor_count, transfer_ver)`。

## 3. 关键算法伪代码

```python
# IP-264 SCC：标定证书，而非标量残差
class CalibrationCertificate:
    def valid(self, x, t):
        return (x in self.S) and (t < self.T) and (lambda_min(self.J) >= KAPPA)
    def cov(self):  return inv(self.J)          # Cramér–Rao / Laplace

# IP-265 GID：现实差距作为可辨识参数
def fit_gap(paired_rollouts):
    g_hat, J_g = nonlinear_least_squares(
        resid=lambda g: y_real - f_sim(u, g),
        jac=lambda g: -df_sim_dgamma(u, g))
    return CalibrationCertificate(g_hat, J_g, support_of(J_g), expiry_of(J_g))

# IP-266 DEX：双用途配给，安全字典序第一
def choose_information(modes, ledger, budget, o_t):
    best = None
    for e in candidate_actions(modes):                 # 看/问/触/励磁
        if not budget.allow(e) or not c_ras_wm.certify(e, o_t): continue
        if risk_of(e) > EPS_EXC:                        continue
        score = (task_voi(modes, e)
                 + beta_g(ledger) * d_optimal_gain(ledger, e)
                 - cost(e))
        if best is None or score > best.score: best = (e, score)
    return best if best and best.score > 0 else None    # 无利可图 -> R69

# IP-267/268/269 TCS + GRL + FDR
def transfer_gate(ledger, x, t):
    ok = (x in ledger.S_c and x in ledger.S_gamma
          and ledger.t_c > t and ledger.t_gamma > t)
    R_expl = worst_case_explained_anomaly(ledger.C_c_gamma, x)
    return ok and (R_expl <= TAU_EXPL), R_expl

def robust_likelihood(policy, xi, o, ledger):
    return max(-policy.log_likelihood(xi, apply(o, c, g))
               for (c, g) in credible_samples(ledger.C_c_gamma))

def classify(r_res, a_obs, a_robust, ledger, o):
    ok, R_expl = transfer_gate(ledger, o.x, o.t)
    if not ok:                          return 'UNTRUSTED'
    d_res = max(0.0, (a_obs - a_cal) - a_robust)
    if r_res > TAU_R:                   return 'SENSOR_FAULT'
    if d_res > TAU_A:                   return 'HIDDEN_SLOW_FAULT'
    return 'NORMAL_OR_BENIGN_GAP'

# IP-274 主闭环（继承 R69）
def BRIDGE_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(o)
    ok, R_expl = transfer_gate(M.ledger, o.x, o.t)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    g = (M.dex.choose_information(modes, M.ledger, M.budget, o)
         if (ok and U_epi > TAU_EPI) else None)
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    a_hat = M.grl.robust_likelihood(M.fmp, M.last_action, o, M.ledger)
    verdict = classify(M.last_r_res, M.last_a, a_hat, M.ledger, o)
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ...)
    if verdict in ('UNTRUSTED', 'HIDDEN_SLOW_FAULT'):
        lam = max(lam, LAMBDA_HARD); k = min(k, k_cal_shrink(x_prime, U_cal))
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.ras_r.maybe_reanchor_if(M.ledger, o, M.budget)     # 慢回路
    M.vqa_i.submit_async(g, verdict, R_expl, a_hat)
    return k, lam, mode, (U_ale, U_epi, verdict)
```

## 4. 推导

**引理 19（残差自洽 ≠ 标定正确）** `r≈Hδ`。若 `δ∈Null(H)` 则 `‖r‖≈0` 而 `‖δ‖` 任意大，且 `λ_min(J)≈0`, `E‖δ‖²≥tr(J^{-1})→∞`。系：`r_res≈0` 只在被励磁方向成立；未励磁方向的错误对标定残差完全隐形——这修正了 R68/R69 最深层假设。

**引理 20（差距可辨识窗口与判别上限）** 差距似然偏移 `b_γ^Tγ`，`Λ_γ⪰J_γ^{-1}`，`R_expl≈‖b_γ‖√(trΛ_γ)`。故障/差距判别 `SNR=|b_γ^Tδ^fault|/(‖b_γ‖√(trΛ_γ))`；励磁越充分窗口越窄、AUC 越高。系：AUC 有由励磁决定的硬上界，调阈值不能突破，只能加励磁。

**引理 21（双用途共享增益有限）** `O=[[O_t,O_x],[O_x^T,O_g]]`，`log det O = log det O_t + log det(O_g−O_x^T O_t^{-1}O_x) ≤ log det O_t + log det O_g`，等号当 `O_x=0`。系：边做边标定不免费；冲突时只能时间分离（任务优先）。

**引理 22（差距校正判别一致性）** 若 `Δa=b_γ^Tγ*+Δa_fault+ε` 且 `C_{cγ}` 以 `1−α` 覆盖真值，则 `Δa_res` 是 `Δa_fault` 的保守估计；`TCS` 有效时误报 `≤α`。前提 `R_expl≤τ_expl`；否则退化为全解释，必须判 `UNTRUSTED`。系：不设解释预算 ⇒ 标定吸收升级为迁移吸收。

**定理 18（严格包含 FLUID 与 CALM）** 任意 `(x,t)` 风险 ≤ FLUID；当 `Λ_γ=0, γ*=0, S_c=S_γ=全集, t<T_exp` 时 `IG_gap≡0, Δa_expl≡0, TCS≡Valid`，逐指令等于 FLUID；再令 `U_epi=0` 且禁交互则等于 CALM。安全不让步，效率仅在证书辖区获差距校正红利。

**定理 19（励磁/回锚安全与无突变）** 认证励磁 `risk≤ε_exc`；回锚只改证书状态与门控，不改当前安全包络；`TCS` 失效/回锚失败/受 `ℰ_transfer` 攻击时 `λ` 单调不降、交互与差距校正单调关闭，最终退化 R68；R68 定理 15 换装不变式保持 ⇒ 连续无突变。

## 7. 本轮最大风险

**一句话**：BRIDGE-RAS 用「现实差距」解释行为似然异常，本意是消除良性域移误报；但差距模型比标定层更能吸收异常——**任何真故障都能被贴上「这是迁移差距」而免于报警，R68 的「标定吸收故障」由此升级为「迁移吸收故障」，系统带着漂亮的迁移证书一路自信地错下去**；更隐蔽的是，决定励磁哪些方向的仍是那个可能已错的模型，形成「闭环不可辨识」，越自证越无法发现自证是循环的。

**次级风险与缓解**：联合可信集过宽（`R_expl>τ_expl` 即判不可信，绝不当正常）；励磁不安全（定义 320 硬包络 + 定理 19）；锚点投毒/证书膨胀（ℰ_transfer + 独立锚点审计 + 证书单调性检查）；慢回路侵占实时（异步 + 快回路查表）；闭环不可辨识（引入独立物理锚点/外部测量审计，禁止模型给自己的励磁方向打分）。
