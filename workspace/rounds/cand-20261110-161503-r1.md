# 第 47 轮（承接第 46 轮产物 v23；本轮灵感：多模态交互 × 差异化定位） · CMG-Position：证据级多模态落位与差异化定位治理（四层架构 v11）

> 承接第 46 轮 v23 MVR × VAD × SAB。第 46 轮把语音指令接入记忆检索与安全绑定，但语音仍只被当作「意图通道」：VAD 解析槽位后得到一个意图锚点，SAB 用单体预测 g(v) 与姿态证书做指数绑定。这隐含假设 H5：各交互模态是同质、可替换的输入，融合发生在意图层，且所有可用模态都值得同时开启。真实 UniBot 场景中，**注视**给粗方位、**指示手势**给一条射线、**语音空间指代**（"那个红色的""左边第二个"）给语义区域、**深度**给度量结构、**记忆先验**给历史位置——五者的误差模型、延迟、能耗与有效域完全不同。两个灵感词精确命中 H5：**多模态交互**要求把融合从意图层下沉到「证据/定位」层，并允许系统主动发起消歧对话；**差异化定位**同时给出两种读法——技术读法：每种模态对定位证书的增益不同，应按「增益/成本」做差异化激活；战略读法：项目应凭「可证书化、能量感知、可审计的多模态落位」与通用端到端 VLA 区分，而不是拼模型规模。二者耦合出的新问题是：**当某个自信但错误的模态主导融合时，冲突检测可能失效，融合证书会被「合法地」收窄，系统在形式 sound 的证书下执行错误指代——技术增益与差异化叙事会共同掩盖这一静默失效**。

## 0. 直觉与动机

**灵感 1（多模态交互 → 从意图级求和到证据级落位）**
直觉：用户说「把那个红杯子递给我」并同时看/指，这句话的价值不在"红杯子"这个字符串，而在于它把注意力约束到一个三维区域。若只在意图层做加权投票，系统知道"要红杯子"，却不知道"红杯子在证书意义下的哪一块空间"，也无法判断语音与手势是否其实指向不同物体。因此把每个模态建模为一个**定位证据因子**（锚点 + 精度矩阵 + 可信度 + 有效域 + 能耗），融合发生在几何/落位层；当因子互相矛盾时就地触发消歧，而不是静默取平均。

**灵感 2（差异化定位 → 差异化定位增益 DGL）**
直觉："定位"有两种含义，本轮刻意让它们同构。技术上，不是所有模态都值得开：在弱纹理、远距离、遮挡、快速运动等条件下，某个模态对证书半径的缩减可能接近零，却仍消耗能量与延迟。定义**差异化定位增益** Δ_m(φ|S)=r_φ(S)−r_φ(S∪{m})（加入模态 m 使证书半径的缩减），再除以成本得到 D_m=Δ_m/(c_m+λ_τ τ_m+λ_risk Risk_m)。这样"该开哪个模态"与"哪个模态让我们与众不同"共用同一套增益语言；在子模性下贪心激活有 1−1/e 保证。

**灵感 3（差异化定位 → 定位矩阵与 claim–evidence 台账）**
直觉：研究叙事最容易犯的错是把"我们也做了 X"当成"我们在 X 上领先"。于是把项目定位本身做成可审计对象：列出声明集 C，对每条声明在若干轴（证书 soundness、能量效率、可审计性、多模态落位精度、泛化、延迟）上与基线比较；只有当某条声明在自己宣称的轴上占优、且其余轴非劣（容差 δ）时才记为"差异化"，否则记为"持平"。定位矩阵不是 PPT，而是决定"下一轮该做哪个实验"的实验选择器，并防止负证据被叙事吞掉。

**耦合升级**：在 v10 四层架构上新增 **证据级多模态落位层**。CMGL 负责因子收集、冲突图与鲁棒融合；DGX 用 DGL 在能量租约下做差异化模态激活；ADQ 在冲突时按期望信息增益选择追问（重说 / 重指 / 看向 / 二选一）；DPA 维护定位矩阵并反向约束实验设计与对外声明。v11 四层：根信任层新增「冲突未检出」这一显式假设；L1 几何层因子化；L2 上下文预测扩展为指代候选分布；L3 CAR 守卫加入冲突标志与膨胀下界；L4 DCL 采集冲突与消歧样本。

## 1. 形式化定义（增量：定义 59–64）

**定义 59（多模态证据因子）**
交互模态集合 M_int={gaze, deictic, voice-deixis, depth, memory-prior}。模态 m 输出因子
e_m=(ĝ_m, Λ_m, ρ_m, c_m, τ_m, V_m)，
其中 ĝ_m∈A 为公共锚点空间中的落位估计，Λ_m≻0 为精度矩阵，ρ_m∈(0,1] 为经独立校准的可信度，c_m 为能耗、τ_m 为延迟、V_m⊆Φ 为有效域（如深度在透明/镜面层无效）。语音指代经语义解析映射为区域因子而非单点。

**定义 60（差异化定位增益 DGL）**
对目标谓词 φ 与已激活因子集 S，
Δ_m(φ|S)=r_φ(S)−r_φ(S∪{m})，D_m(φ|S)=Δ_m/(c_m+λ_τ τ_m+λ_risk Risk_m)。
称 φ 下模态 m 相对 S **有差异化价值**当且仅当 D_m≥δ_D 且 m 的因子与 S 的极大一致子集相容。假设 r_φ 在集合上单调且子模，则带能量约束的贪心激活满足 r(S_greedy)≥(1−1/e)r(S*) 的近似保证。

**定义 61（交叉模态冲突）**
对 i,j 两因子，D_ij=(ĝ_i−ĝ_j)ᵀ(Λ_i^{-1}+ρ_i^{-1}Λ_j^{-1})^{-1}(ĝ_i−ĝ_j)。给定显著性 β，若 D_ij>χ²_{d,1−β} 则连边 (i,j)。冲突图 G_c 的**极大一致子集** MCS 为不含冲突边的最大因子集；若存在多个规模相近（相差 ≤1）的 MCS，则判为**不可判定冲突**，必须进入消歧。

**定义 62（证书化多模态落位）**
在 MCS S 上做鲁棒融合（Huber-IRLS 或椭球交），得到 P_t 与半径
r_t = max_{m∈S} ( r_m + γ·d_m )，其中 d_m 为 m 到融合中心的马氏距离。
**条件 soundness**：若 (i) 无未检出冲突，(ii) 各因子单独 sound，(iii) 膨胀下界 γ·max d_m ≥ 任意两因子分歧，则
P(X_t∈P_t | 因子有效, ¬未检出冲突) ≥ 1−α−β。
膨胀项的作用是：**任何单一自信模态都不能把证书压到低于分歧下界**，从而把"自信但错误"从静默失效转成可见的宽证书或冲突。

**定义 63（主动消歧对话策略）**
问题库 Q={重说, 重指, 注视目标, 二选一, 操作员接管}，每个 q 有成本 c_q 与预期响应模型 P(a|q)。以候选指代分布 H 的期望信息增益
q* = argmax_{q∈Q} E_{a~P(·|q)}[H(H)−H(H|a)] / (c_q+λ_τ τ_q)
s.t. 能量租约 ℓ_e 可行。多轮至冲突消解或触发 fail-closed；对话证据同样作为因子进入 CMGL，而非直接授权动作。

**定义 64（差异化定位矩阵 DPM）**
声明集 C={c_k}，评价轴 A={证书 soundness, 能量效率, 可审计性, 多模态落位精度, 泛化, 延迟}。对声明 c_k 与基线 b 得到矩阵 M[k,b,a]。称 c_k 在轴 a 上**差异化**当且仅当
M[k,b,a] 显著优于基线（置信区间不重叠）且 ∀a'≠a: M[k,b,a'] ≥ M[b,b,a'] − δ。
否则记为持平/落后。定位向量 p=|{c_k: 差异化}|；p 低于阈值时触发「收窄范围或改写声明」，而不是放宽统计口径。

## 2. 新增产出与既有 IP 升级

**IP-69 CMGL（Cross-Modal Grounding & Localization）**
- 五类因子接入与公共锚点空间对齐；语音指代→区域因子
- 冲突图构建、MCS 搜索与不可判定冲突判定
- Huber-IRLS 鲁棒融合 + 分歧膨胀下界，输出 P_t 与冲突标志
- 融合失败时输出保守盒并上报，不返回"最佳猜测"

**IP-70 DGX（Differentiated-Gain eXecutor）**
- 在线估计 r_φ(S) 与 Δ_m，维护分模态增益表
- 子模贪心激活，受 IP-63 能量租约 ℓ_e 约束
- 模态休眠/预热与增益重估；低增益模态默认关闭而非常开

**IP-71 ADQ（Active Disambiguation Questioner）**
- 期望信息增益问题选择，支持重说/重指/注视/二选一/接管
- 多轮状态机与超时撤回；对话证据回注 CMGL 作为因子
- 与 SAB 安全队列联动：消歧未完成不得执行

**IP-72 DPA（Differentiated Positioning Auditor）**
- claim–evidence 台账：每条声明绑定实验编号、指标、置信区间
- 定位矩阵与差异化/持平判定，自动列出"被基线追平"的声明
- 反向实验选择：优先补最能产生差异化证据的轴

**既有 IP 升级**
IP-67 VAD：输出语音空间指代因子与候选分布，而非仅意图锚点
IP-68 SAB：绑定使用融合证书 P_t 与分歧下界，冲突未消解即入队
IP-63 ECPS：效用函数接入 DGL，模态决策改为差异化激活
IP-62 CCA：新增冲突漏检红队、消歧诱导偏差测试、定位声明审计
IP-61 DCL：采集冲突样本、消歧轨迹与被基线追平的声明对应数据
IP-51 CAR：守卫加入 conflict_flag 与膨胀下界检查
IP-45 总线：新增 modality-factor / conflict-graph / disambiguation / positioning-ledger 话题

## 3. 算法骨架

CMGL 每控制周期：
1. 收集各模态因子 e_m，检查有效域 V_m，丢弃无效因子
2. 构建冲突图 G_c，枚举 MCS；若最大 MCS 唯一则继续，否则标记不可判定
3. 在 MCS 上鲁棒融合，按分歧膨胀下界计算 P_t 与 r_t
4. 输出 (P_t, r_t, conflict_flag, MCS)
DGX：
1. 读能量租约 ℓ_e 与当前 S
2. 对候选 m 估计 Δ_m 与 D_m
3. 子模贪心加入 D_m≥δ_D 且能量可行的模态
4. 输出激活集 S*，发预热/休眠指令并更新 ℓ_e
ADQ：
1. 若 conflict_flag 且存在 ≥2 个近规模 MCS，构建候选指代分布 H
2. 按期望信息增益/成本选问题 q*，执行并接收响应因子
3. 回注 CMGL 重融合；超时或增益不足则 fail-closed/操作员接管
DPA（离线/每轮）：
1. 汇总实验，填充 M[k,b,a] 与置信区间
2. 判定差异化/持平，更新定位向量 p
3. 输出下一轮应补的实验与需撤回的声明

## 4. 本轮最大风险

**一句话**：最大风险是交叉模态信任校准错误——一个自信但系统性偏差的模态（如误听的空间指代或被场景偏置的注视）既可能逃过冲突检测，又会在鲁棒融合中把证书压到分歧下界以下，而 DPA 的"差异化"叙事会倾向保留这类漂亮指标，最终系统以形式 sound 的证书执行错误指代；因此必须以独立审计集校准 ρ_m、强制分歧膨胀下界、把消歧对话当作证据而非授权，并让定位台账显式记录负证据。

### IP-69 CMGL

def collect_factors(modalities, phi):
    E = []
    for m in modalities:
        if not m.valid_for(phi):        # 有效域 V_m 检查
            continue
        g_hat, Lambda, rho, cost, tau = m.estimate(phi)
        E.append(Factor(m.name, g_hat, Lambda, rho, cost, tau))
    return E

def conflict_graph(E, beta):
    G = {e.id: set() for e in E}
    for i, j in combinations(E, 2):
        diff = i.g_hat - j.g_hat
        S = inv(inv(i.Lambda) + inv(i.rho) * inv(j.Lambda))
        D = diff.T @ inv(S) @ diff
        if D > chi2_ppf(1 - beta, dim):
            G[i.id].add(j.id); G[j.id].add(i.id)
    return G

def max_consistent_sets(E, G):
    # 精确搜索（|E|≤6，可枚举）；返回规模排序的 MCS 列表
    sets = [S for S in powerset(E) if is_independent(S, G)]
    return top_by_size(sets)

def robust_fuse(E_mcs, gamma):
    mu, Sigma = huber_irls(E_mcs, k=1.345)
    d = [mahalanobis(e.g_hat, mu, Sigma) for e in E_mcs]
    r = max(e.r for e in E_mcs) + gamma * max(d)
    return Ellipsoid(mu, Sigma, r), r

def cmgl(modalities, phi, beta, gamma):
    E = collect_factors(modalities, phi)
    if not E:
        return None, 'no-factor'
    G = conflict_graph(E, beta)
    mcs = max_consistent_sets(E, G)
    if len(mcs) >= 2 and mcs[0].size - mcs[1].size <= 1:
        return None, 'undecidable-conflict'   # 交给 ADQ，绝不静默融合
    P_t, r_t = robust_fuse(mcs[0], gamma)
    flag = 'conflict' if G_has_edge(G) else 'ok'
    return (P_t, r_t, flag, mcs[0]), flag
```

### IP-70 DGX
```
def differential_gain(S, m, phi, r_phi):
    r_now = r_phi(S, phi)
    r_add = r_phi(S | {m}, phi)
    delta = max(0.0, r_now - r_add)
    cost = m.cost + lam_tau * m.tau + lam_risk * risk(m, phi)
    return delta, delta / max(cost, eps)

def dgx_activate(S_avail, phi, lease_e, delta_D=0.02):
    S = set()
    while True:
        best, best_D = None, 0.0
        for m in S_avail - S:
            _, D = differential_gain(S, m, phi, r_phi)
            if D > best_D and lease_e.feasible_with(S | {m}):
                best, best_D = m, D
        if best is None or best_D < delta_D:
            break
        S.add(best)
    if not S:
        return set(), 'fail-closed-energy'
    return S, 'ok'
```

### IP-71 ADQ
```
def expected_info_gain(q, H, resp_model):
    ig = 0.0
    for a, p_a in resp_model(q).items():
        H_post = posterior(H, q, a)
        ig += p_a * (entropy(H) - entropy(H_post))
    return ig

def adq_disambiguate(H, Q, lease_e, budget_turns=3):
    for t in range(budget_turns):
        best_q, best_score = None, -inf
        for q in Q:
            if not lease_e.feasible(q.cost):
                continue
            score = expected_info_gain(q, H, resp_model) / (q.cost + lam_tau*q.tau)
            if score > best_score:
                best_q, best_score = q, score
        if best_q is None:
            return None, 'fail-closed-energy'
        a = execute_and_observe(best_q)         # 需用户配合，超时即中止
        if a is None:
            return None, 'timeout'
        H = posterior(H, best_q, a)
        if entropy(H) < tau_ent:
            return H, 'resolved'
    return H, 'unresolved'
```

def is_differentiating(M, k, b, a_star, delta):
    if not significant_better(M[k][b][a_star], M[b][b][a_star]):
        return False
    for a in AXES:

            return False
    return True

def positioning_audit(claims, baselines, experiments):
    M = fill_matrix(claims, baselines, experiments)   # 含置信区间
    p, report = 0, []
    for c in claims:
        diff_axes = [a for a in AXES if is_differentiating(M, c, c.baseline, a, DELTA)]
        if diff_axes:
            p += 1
            report.append((c, 'differentiating', diff_axes))
        else:
            report.append((c, 'parity-or-behind', []))
    return M, p, report
```

def global_decision_v11(c_t, omega_t, B_t, v_t, M_mem, calib, S_phi, Q_safe):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CMGL 冲突图 | O(|E|²·d²) | O(|E|²) | β 控制误检率；未连线即视为相容 |
| MCS 枚举 | O(2^{|E|})，|E|≤6 | O(2^{|E|}) | 最大 MCS 唯一才融合，否则转消歧 |
| 鲁棒融合 | O(k·|E|·d³)（IRLS 迭代 k 次） | O(d²) | 膨胀下界 γ·max d 抑制自信错误模态 |
| DGX 贪心 | O(|M_int|²) 每周期 | O(|M_int|) | 子模下 (1−1/e) 近似 |
| ADQ | O(|Q|·|A|·turns) | O(|A|·turns) | 每轮选期望信息增益/成本最大者 |
| DPA | O(|C|·|B|·|A|) 离线 | O(|C|·|B|·|A|) | 显著性 + 非劣容差双条件 |

**定理 1（条件 soundness）**：若各因子在有效域内单独 sound（覆盖率 ≥ 1−α），冲突检测在真实冲突下漏检率 ≤ β，且融合半径满足 r_t ≥ max_m(r_m+γ d_m)、γ d_m 覆盖任意两因子分歧，则融合证书的覆盖率 ≥ 1−α−β。**推论**：把 γ 设为可审计常数、冲突漏检率作为根信任假设显式记录，可将"自信错误模态"从静默失效转化为宽证书或冲突标志。

**定理 2（激活近似）**：r_φ 单调子模时，DGX 在能量租约可行域内得到的 r(S_greedy) ≥ (1−1/e)·r(S*)。

**定理 3（定位审计不可自证）**：DPA 的差异化判定只依赖预注册实验与置信区间；若某声明在宣称轴上不显著或任一其余轴劣于 δ，则不得记为差异化。该规则防止"叙事先行"污染实验选择（但依赖人工预注册，见风险）。

## 4. 实验设计 E115–E120

| 实验 | 指标 | 门槛 |
|---|---|---|
| E115 冲突检测 | ROC-AUC；FPR | AUC ≥ 0.90；FPR ≤ 2% |
| E116 融合证书 | 经验覆盖率；半径比 | 覆盖率 ≥ 1−α−β；r_t ≤ 0.7×单模态最优 |
| E117 主动消歧 | 消歧成功率；平均轮数；能耗 | ≥ 95%；≤ 1.8 轮；≤ 8% |
| E118 DGX 增益效率 | 单位焦耳半径缩减；激活模态数 | ≥ 1.5× 全开基线；均值 ≤ 3 |
| E119 定位矩阵 | 差异化声明数；误报数 | p ≥ 3；误报 0 |
| E120 100h 闭环 | 交互任务成功率；证书违例 | ≥ 96%；违例 0 起；冲突→消歧→成功 ≥ 90% |

**回退策略**：E115 FPR > 2% → 增大 β 并统一采用保守膨胀，暂不启用细粒度 MCS；E117 轮数 > 2.5 或能耗 > 10% → 冲突直接进安全队列并要求操作员确认；E118 增益估计不稳 → 回退固定模态组合（保留能量租约）；E119 p < 2 → 不修改统计口径，改用 DPA 的"收窄定位"建议，砍掉无差异化声明，聚焦证书化落位。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 自信但系统性偏差的模态主导融合 | 高 | 独立审计集校准 ρ_m；强制分歧膨胀下界；γ 上界可审计 |
| 冲突检测漏检（相关系数抵消） | 高 | 用独立残差/时序一致性做二次检测；漏检率写入根信任假设，超阈值 fail-closed |
| 消歧对话被用户误答或诱导 | 中 | 对话证据只作因子不作授权；多轮不一致则转操作员 |
| DGL 估计在小样本下方差大 | 中 | 分模态增益表滑动窗口 + 悲观下界；不足则默认全开并计能量 |
| DPA 被"差异化"叙事反向污染 | 高 | 实验预注册、盲评、负证据强制入库；被基线追平即自动降级声明 |

## 6. 本轮最大风险

**一句话**：交叉模态信任校准错误会让一个自信但系统性偏差的模态同时逃过冲突检测并压低融合证书，而 DPA 的差异化叙事又倾向保留漂亮指标，最终系统在形式 sound 的证书下执行错误指代；因此必须以独立审计集校准可信度、用分歧膨胀下界兜底、把消歧对话仅当作证据，并让定位台账强制记录负证据。
