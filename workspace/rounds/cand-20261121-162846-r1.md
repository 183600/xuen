## 0. 本轮一句话

**语言既是任务规格，也是用户共创的协议；多语言不是翻译功能，而是让分散、嘈杂、可能被污染的用户贡献能被聚合成一份可靠任务本体的"纠错码"。**

SAGE 把「抓没抓住」变成可观测量；本轮把「这条指令到底要机器人做什么、这个说法算不算数」变成**可共创、可审计、可回滚**的量。用户共创提供覆盖长尾的能力来源，多语言冗余提供检验贡献质量的结构；两者在同一个接口（自然语言规格）上相遇。

---

## 1. 直觉（先不给公式）

### 画面 1 · 用户共创不是"多收数据"，而是"多来源的规格制定权"

SAGE 的任务本体（32 个任务 token、技能专家、阶段先验）由少数工程师**自上而下**写死。可是 5 类泛化场景——位置、干扰物、背景、**未见物品**、人为干扰——恰恰落在工程师想象不到的长尾里。谁见过那个"没见过的杯子"？现场用户。谁最清楚"这个电池该从哪个唇边抠出来"？操作过的人。

所以"用户共创"的第一性原理不是"多收几段示教"，而是：**能力来源从设计者扩展到用户群体**。但这是一条**能力供应链**，不是免费数据：

- 用户是**噪声大、注意力贵、可策略化、甚至可对抗**的传感器；
- 用户提交的不是普通样本，而是**会改变策略行为的规格增量**；一条坏贡献能让整个任务路由错到另一个技能上，而 SAGE 已证明路由错误会**复合放大**（L2/L5）；
- 用户之间会冲突：同一个物体，不同人叫不同名字、给出不同抓法、甚至对"成功"的定义不同。

因此正确的原语不是"开放输入"，而是**有类型、有出处、有法定人数、有影子回放、可卸载回滚的规格编辑**（spec edit），并且**能力闭合**：编辑只能在既有技能库里重新绑定，不能新增执行器、不能扩大物理动作空间。

### 画面 2 · 多语言不是翻译，而是"同一语义的冗余编码"

把同一条指令用 K 种语言 / K 种说法写出来，本质上是对同一个隐变量 `s`（任务规格）做了 K 次**带噪观测**。这正是通信里的**重复码**：单个观测会被表层噪声（翻译漂移、同义词、语序、方言）带偏，但多个**独立**观测的多数解码能把噪声压下去。

这个类比给出三个非平凡的推论：

1. **多语言是共创的纠错码**：用户用母语贡献，系统不需要信任任何单条贡献，只需要看它在跨语言 / 跨改写下是否**语义一致**。保不住翻译的是表层癖好，保得住翻译的才是真知识。
2. **独立比数量重要**：如果 K 种语言全由同一个机器翻译引擎生成，错误高度相关，重复码就退化成单次观测。K 再大也没用。**有效样本量由贡献者/译者的独立性决定，而不是条数**。
3. **多语言是共创的可及性层**：不提供多语言，共创就被英语流利度卡住，能贡献长尾知识的人反而进不来。

### 画面 3 · 两个灵感在同一个接口上相遇

SAGE 的语言接口 `z_task = argmax cos(E_L(ℓ), e_k)` 假设：语言干净、单语、规范、每个任务一条。真实世界三个失效面——**别名**（同一任务不同叫法）、**改写**（同一任务的句式变化）、**未见物品**（指令里的名词训练集没有）。

- 只做多语言、不做共创：你得到一个更鲁棒但**仍然封闭**的本体——它认识更多说法，却学不到用户知道的新知识。
- 只做共创、不做多语言：你得到一堆无法交叉验证的贡献，坏贡献直接进本体，且把非英语用户挡在门外。
- **两者合起来**：用户用母语贡献 → 对齐到共享规格图 → 跨语言一致性 + 回放闸门过滤 → 有界编辑落库 → 可审计账本。**用户既是能力来源，也是需要被治理的不可靠组件。**

一个类比：多语言支持不是给数据库写 32 套查询，而是定义**一套 schema**；用户共创不是往表里随便插行，而是**带签名的迁移脚本**——可以提交、只能在隔离区构建、必须通过回归测试才能安装、永远可回滚。

## 2. 上一轮留下的真正缺口（本轮要打的靶）

SAGE 的 IP-01 是本线唯一有量化上界的红利（oracle +4.26），但它把全部赌注压在"语言指令能被正确读成任务 token"上。这条假设有三个可测量的裂缝：

1. **别名裂缝**：官方 32 个数据集名与 teaser 32 个任务名并不逐词一致。本轮用 CamelCase 规范化后复核：**10/32 字符串不一致**；其中 2 个是**纯词法无法救回**的硬别名（`ArrangePlates ↔ Clear Plates`、`PourOutMedicine ↔ Open Pill Bottle`）。若路由靠字符串/词面，这两个任务会**确定性地**走错专家。
2. **改写裂缝**：同一任务换语序、同义词、量词、否定、指代，词面向量就会漂移；而评测的 `observation.language` 是**句式未知**的。
3. **未见物品裂缝**：第 5 类泛化是"未见物品"，但训练集每个任务只有**一条规范指令**、行级**没有语言字段**（只有 `task_index`）。新物品的名字/属性根本不在本体里——**再大的多语言模型也变不出没人写过的知识**。

这三条正好对应两个灵感的落点：别名/改写靠**多语言等价类 + 冗余共识**，未见物品靠**用户共创**补知识。COOP 的贡献不是"又训了一个多语言模型"，而是**把本体从"工程师写死"改成"可治理地长出来"**。

## 3. 本轮新增事实（本地可复现探针，2026-11-21）

> 说明：以下为**词法代理实验**。它验证"本体缺口真实存在、别名边能补齐"，不验证语义多语言；语义结论需 E801/E803 的多语言编码器实验。

| 编号 | 实验 | 结果 | 含义 |
|---|---|---|---|
| G1 | 词法路由：数据集名 → teaser 任务名（char-trigram 余弦） | **30/32** | 形态差异大多可被词法救回，缺口比"10/32 不一致"小 |
| G2 | G1 的失败点 | 仅 2 个：`ArrangePlates→Clear Plates`、`PourOutMedicine→Open Pill Bottle` | 这 2 个是**语义别名**，任何词面方法都无解 |
| G3 | 别名感知本体（给每个任务加已知表层形式） | **32/32** | 一条共创别名边即可补齐；缺口是**结构性的、可被编辑修好的** |
| G4 | 共识解码玩具：K 个独立带噪"用户视图"多数投票 | K=1→0.941，K=3→0.975，K=5→0.990，K=9→0.998，K=15→1.000 | 独立冗余确实降方差 |
| G5 | 共识解码玩具：K 个**相关**视图（共享同一噪声） | 恒为 **0.941**（与 K=1 相同） | **相关噪声下，加语言不加信息**——独立性是命门 |

**结论（三条）**：
- **T4 本体缺口是结构性的**：至少 2/32 任务的正确路由**不可能**由词面得到，必须由共创/语义编辑补边。
- **T5 冗余有效但有前提**：多语言共识的收益完全取决于贡献者/译者的**独立性**；把同一个 MT 引擎跑 K 遍是自欺。
- **T6 共创必须被治理**：既然一条编辑能改变路由，坏编辑的代价会沿 SAGE 的专家混合复合放大——所以编辑要有类型、有界、可回放、可回滚。

## 4. 研究问题（本轮新增）

- **Q16（共创的可兑现性）**：在**没有在线用户**的赛制下（评测 API 只有固定 `observation→action`，不给中途语言纠正），离线用户共创的规格编辑能否真的转化为 5 类 OOD 上的终态成功率，而不是只让本体"看起来更全"？
- **Q17（共识过滤器）**：跨语言一致性能否作为一个**可自动化的质量过滤器**——拒绝表层癖好、保留真实任务知识？它的假接受/假拒绝各是什么代价？
- **Q18（治理下界）**：要让一条共创编辑不污染其他任务，最少需要什么（法定人数、trust-region、回放回归测试、出处账本、回滚）？缺哪一项会突破什么上界？
- **Q19（未见物品）**：用户贡献的**物体属性/抓法**知识，能否在训练分布外的新物品上迁移？其收益是否超过"只做视觉泛化"的基线？
- **Q20（独立性度量）**：如何**在线估计**贡献者/译者的独立性（有效样本量 `K_eff`），并在独立性不足时自动降级为"单视图 + 保守阈值"而不是假装共识？
- **Q21（不可译知识）**：文化/语言特有、跨语言无对应词的知识（少数群体的叫法、地区性物体）会被共识过滤器**系统性误杀**——如何保留"异议账本 / 影子本体"，使共创不因求稳而丧失长尾？
- **Q22（代理评测）**：让用户共创**失败分解的标注口径**（六因子），能否提升 SAGE IP-06 代理指标与真机成功率的相关性（E601 的最大风险）？

## 5. 设计原则（在 SAGE P1–P6 上追加）

- **P13 语言是规格，也是共创协议**：任何表层形式都映射到同一规格图 `s`；贡献以**规格编辑**而非原始文本入库。
- **P14 共创是供应链，不是数据管道**：每条编辑必须带 `(贡献者, 语言, 目标规格, 编辑类型, 证据, 时间戳)`，经隔离构建、法定人数、影子回放后才能"安装"，且永远可卸载。
- **P15 能力闭合**：编辑只能把规格**重新绑定到既有技能库**或调整路由/约束，**不能新增执行器、不能扩大物理动作空间**。这是安全上界，也是赛制合规（单 checkpoint / 单 API）的叙述。
- **P16 独立优于数量**：多语言共识的收益按**有效样本量** `K_eff` 计，不按条数计；独立性不足时自动降级。
- **P17 共识不得抹除异议**：被拒但语义合理的贡献进**影子本体 / 异议账本**，不丢弃；待新证据到来可重新裁决。求稳不能以牺牲长尾为代价。
- **P18 每条编辑必须能翻译成计分货币或代理效度**：否则只进影子区，不进主线（承接 P1）。

## 6. 最小可提交闭环（MVP）与退化链

**MVP = SAGE IP-06（代理评测） + SAGE IP-02（抓握确认） + COOP 的规格编辑账本（IP-15） + 跨语言共识（IP-16） + 回放闸门（IP-17） + 基线 VLA**。
理由：IP-15/16/17 是纯离线、零真机成本的结构件，直接加固 SAGE 最脆的路由接口；IP-06/IP-02 是 SAGE 已定的必保项。

**严格退化链（任一环节不可用 ⇒ 行为回退而非漂移）**：
- **L0 多语言编码器不可用** ⇒ 退回单语（规范英文）共创，共识退化为"多用户改写一致性"；
- **L1 独立性不足（`K_eff` 低）** ⇒ 关闭共识投票，改用"单视图 + 高阈值 + 只接受低风险编辑"；
- **L2 回放闸门不可用** ⇒ 编辑只进**影子本体**，不安装到在线路由；
- **L3 编辑账本损坏/被污染** ⇒ 整体回滚到规范本体快照（versioned checkpoint of ontology）；
- **L4 整条共创链失效** ⇒ 纯 SAGE 基线（保留可跑通、可信度合规的安全网）。

## 7. 预期贡献（可验收）

1. **把"用户共创"从口号变成可治理的软件工程对象**：给出规格编辑代数、出处账本、法定人数、影子回放与回滚，证明"共创可以不靠信任任何单个用户"。
2. **把"多语言"从功能变成纠错码**：给出共识解码器、有效样本量 `K_eff` 的在线估计、以及"相关噪声下加语言不加信息"的可复现证据（G4/G5），这是全赛道可复用的方法论。
3. **量化本体缺口**：词法路由 30/32、2 个语义硬别名、别名边补齐 32/32（G1–G3），把"多语言/别名"从定性担忧变成可审计缺口。
4. **正面攻击 SAGE 最大风险**：让用户共创**失败分解标注口径**，直接提升代理↔真机相关性（Q22），而不是又加一个无法验证的模块。
5. **保留长尾的机制**：异议账本 / 影子本体，避免共识过滤器把共创的初衷（覆盖长尾）过滤掉。

## 8. 本轮最大风险

**一句话**：让共创变安全的那个跨语言共识过滤器，同时也是一个**同质化器**——它系统性拒绝的恰恰是共创最该捕获的、语言/文化特有的长尾知识，而如果所有"独立"语言其实来自同一个 MT 引擎，它还会在相关性噪声下**看起来有效、实则什么也没过滤**，于是 COOP 可能得到一个干净、可审计、却比基线**更没能力**的本体。

# 第 2 轮产物 · 创新点清单 v2（UniBot 线）：**UniBot-COOP**

> **COOP = Co-created Ontology Of Procedures**（共创 · 跨语言任务规格本体）。
> **定位**：承接第 1 轮 **UniBot-SAGE**（抓握确认 / 技能路由 / 推理期适应 / chunk 缝合 / 代理评测）。SAGE 把「抓没抓住」变成可观测量；COOP 把「语言指令到底对应哪个任务规格、这个说法算不算数」变成**可共创、可审计、可回滚**的量。语言既是任务规格，也是用户共创的协议；多语言是让嘈杂贡献可被聚合的纠错码。
> **编号**：SAGE 的 U1–U12 / L1–L7 / E601–E618 / IP-01–IP-08 保留为历史并继续生效；本轮启用 **C1–C14（定义）、CL1–CL8（引理）、E801–E820（实验）、IP-15–IP-22（创新点）**。
> **数据纪律**：榜单数字仍来自 `unibot.unitree.com/leaderboard_data.json`（**teaser / 占位表**，检索 2026-11-17，非官方终稿）。本轮新增数字来自本地可复现探针 `exp/coop/coop_probe.py`（2026-11-21），输入 `exp/r16_leaderboard_data.json` 与 32 个官方 `*_info.json` 名称表；输出 `exp/coop/coop_probe.json`。该探针是**词法代理**，不是语义多语言结论，凡引用均标注。

## 0. 本轮结论摘要

**一句话路线**：在 SAGE 的「抓握 / 技能 / 适应 / 工程」四层栈之上，加一层**共创治理层**——把语言本体从「工程师写死」升级为「用户以母语提交、经跨语言一致性 + 回放闸门过滤、以有界编辑落库、可审计可回滚」的活本体。物理动作空间**闭合**（只允许把规格重新绑定到既有技能），因此共创扩大的是**规格覆盖**，不是**执行器权限**。

**为什么是这个组合（本轮本地探针 + SAGE 既有硬事实）**：

| 证据 | 数值 | 推出的设计 |
|---|---|---|
| 数据集名 vs teaser 任务名，CamelCase 规范化后仍不一致 | **10/32** | 纯字符串本体先天不闭合 |
| 词法路由（char-trigram 余弦）在 32 个数据集名上 | **30/32**（G1） | 形态差异大多可被词法救回，缺口比"10/32"小 |
| 词法路由的失败点 | **仅 2 个语义硬别名**：`ArrangePlates→Clear Plates`、`PourOutMedicine→Open Pill Bottle`（G2） | 这 2 个**任何词面方法都无解**，必须靠语义/共创补边 |
| 别名感知本体（加已知表层形式） | **32/32**（G3） | 一条共创别名边即可补齐；缺口是**可编辑修好的** |
| 共识解码玩具，K 个**独立**带噪视图多数投票 | K=1→0.941，3→0.975，5→0.990，9→0.998，15→1.000（G4） | 独立冗余确实降方差 |
| 同上，K 个**相关**视图（共享噪声） | 恒 **0.941**，与 K=1 相同（G5） | **相关噪声下加语言不加信息**；独立性是命门 |

**合规红线（沿用 SAGE P5/P6）**：单 checkpoint、单 API；不读评测侧私有信息；不硬编码任务名 / 端口 / 场景；共创编辑只改策略内部的本体与路由，不改官方接口语义；编辑不得新增执行器或物理原语（能力闭合，P15）。

## 1. 本轮已完成的本地探针（可复现）

### 1.1 探针设置

- 输入：`exp/r16_leaderboard_data.json`（32 个 teaser 任务名）、`exp/round_mv/*_info.json`（32 个官方数据集名）。
- 路由基线：对数据集名做 CamelCase 切分 → char-trigram 集合 → 余弦相似度 → 取最近的任务名原型。
- 真值：32 个数据集名到 teaser 任务名的人工语义映射（脚本内 `PAIRS`，可逐条审计）。
- 共识玩具：对任务名施加"用户噪声"（删词、同义词替换、语序打乱），生成 K 个视图；视图各自路由后多数投票；比较**独立噪声**与**共享噪声**。

### 1.2 结果（`exp/coop/coop_probe.json`）

| 编号 | 量 | 结果 |
|---|---|---|
| G1 | 词法路由 top-1 | **30/32 = 0.938** |
| G2 | 失败点 | `ArrangePlates→Clear Plates`（误判为 Arrange Test Tubes）、`PourOutMedicine→Open Pill Bottle`（误判为 Pack Phone） |
| G3 | 别名感知本体 top-1 | **32/32 = 1.000** |
| G4 | 共识（独立噪声） | K=1: 0.941 → K=3: 0.975 → K=5: 0.990 → K=9: 0.998 → K=15: 1.000 |
| G5 | 共识（相关噪声） | 恒为 **0.941**（K=1..15 不变） |

### 1.3 解释与边界

- **G1 修正了"8/32 非逐词一致"的直觉**：字符串不一致有 10 个，但词法路由只错 2 个——说明**大部分形态差异不是路由威胁**，真正的威胁是**语义别名**。这让我们把有限的共创预算花在正确的地方。
- **G3 是"可修性"的证据**：只要补上别名边，本体就闭合；不需要重训主干。这直接支撑"编辑而非重训"的共创形态。
- **G4/G5 是"独立性"的证据**：多语言收益不是自动的。若 K 个"语言"共享同一 MT 噪声，`K_eff≈1`，共识毫无作用（见 CL2）。这是本轮最重要的方法论结论，也是最大风险的技术根源。
- **边界**：本探针是**词法/字符串代理**，不能替代真实多语言语义编码器实验（E801）。G4/G5 只证明"独立降方差、相关不降"这一统计事实在玩具上成立，不证明语义多语言在真机上有效。

## 3. 创新点详述

### IP-15 · SpecEdit Ledger 规格编辑账本（P0）

- **动机**：SAGE 的任务本体由工程师写死；长尾（未见物品 / 新说法 / 新抓法）进不来。但直接让用户改本体 = 让不可信输入改策略行为，坏贡献会沿专家混合复合放大。需要把"贡献"变成**带类型的编辑**。
- **与现有方案的差异**：常见做法是"收集更多示教 / 更多语言数据再训练"；我们把贡献变成**对规格图的有限编辑**，不重训主干，因而可审计、可回滚、成本低。
- **技术可行性**：高。规格图（LSG：verb / entities / attributes / relations / constraints）在 SAGE/LENS 的语义层已有雏形；编辑类型有限（C4），可形式校验。
- **落地步骤**：①定义编辑代数 `E`（C4）；②实现编译器：自然语言贡献 → `(target, edit, evidence)`；③出处账本（append-only，带签名/哈希）；④版本化本体快照；⑤回滚 = 切快照。
- **风险**：①编辑语义漂移（用户意图 ≠ 编译结果）⇒ 要求用户确认编译后的结构化 diff；②账本膨胀 ⇒ 快照 + 增量日志；③隐私 ⇒ 贡献脱敏、只存规格不存原始视频。

### IP-16 · CrossLingual Consensus 跨语言共识（P0）

- **动机**：单条贡献不可信；但同一语义在不同语言/改写下的**一致部分**是可信的。多语言冗余 = 重复码（C7/C8）。
- **与现有方案的差异**：别人把多语言当翻译/数据增广；我们把它当**质量过滤器**，并显式建模**独立性**（`K_eff`），拒绝"同一 MT 跑 K 遍"的伪共识。
- **技术可行性**：中。需要多语言句编码器（公开可用）+ LSG 解析；`K_eff` 可用锚点集上的误差相关估计。
- **落地步骤**：①锚点集（人工确认语义的少量指令对）；②对每条贡献求 `p(s|ℓ)`；③按出处/独立性加权聚合（C7）；④`K_eff` 低于阈值 → 降级为单视图 + 保守阈值（L1）；⑤异议进影子本体（IP-19）。
- **风险**：①**相关噪声**（G5）⇒ 必须用多来源译者/贡献者，不能自欺；②**同质化**（见 §8）⇒ 保留异议；③编码器对低资源语言差 ⇒ 明确语言覆盖表，不假装支持。

### IP-17 · ReplayGate 回放闸门（P0）

- **动机**：一条编辑可能修好目标任务，却**悄悄改变其他任务的路由**。SAGE 已证明路由错误会复合放大；必须在上线前做回归。
- **与现有方案的差异**：普通 CI 只测代码；我们把**本体编辑**当代码，做**路由回归测试**（用缓存数据 + 人工改写集）。
- **技术可行性**：高、零真机。缓存数据有 `task_index`、state/action，足以复算路由输入。
- **落地步骤**：①构造回放集（32 任务规范句 + 每任务多改写 + 别名）；②编辑前后各跑一次路由，计算混淆矩阵变化；③判据：非目标任务的 argmax 变化 ≤1%，目标任务置信度上升；④不达标 → 拒绝或只进影子本体。
- **风险**：①回放集与真机分布不符 ⇒ 用 OOD 切分 + 真机锚点标定；②过度保守拒绝好编辑 ⇒ 预注册假拒绝上限（E805）；③缓存数据偏置 ⇒ 明确回放集来源。

### IP-18 · Capability Closure 能力闭合（P0）

- **动机**：共创若允许新增执行器/原语，就等于把安全边界交给用户；且违反"单模型通才"精神。
- **与现有方案的差异**：多数共创/持续学习系统默认"能力可扩张"；我们显式**关闭**物理能力扩张，只开放**规格→技能的重新绑定**。
- **技术可行性**：高（形式检查 + 白名单编辑类型）。
- **落地步骤**：①技能库 `K` 冻结（SAGE 的专家头）；②编辑类型白名单；③静态检查：编辑后的动作支撑集 ⊆ `∪_k support(skill_k)`；④运行时断言。
- **风险**：①闭合过严导致有用能力进不来 ⇒ 用"规格重绑定"覆盖大部分长尾；确实需要新原语时走人工代码评审（不在共创通道）。

### IP-19 · Dissent Ledger / Shadow Ontology 异议账本（P1）

- **动机**：共识过滤器会误杀少数/文化特有知识（Q21）。若直接丢弃，共创就退化为"主流语言的多数暴政"。
- **与现有方案的差异**：普通系统只保留"通过"的贡献；我们保留"未决"的贡献，并给复裁决通道。
- **落地步骤**：①被拒但语义合理（`p(s|ℓ)` 高但共识不足）的贡献入影子本体；②标注"未决原因"；③新证据到来时重新裁决，一键转正/永久拒绝；④影子本体**不参与在线路由**，只做离线检索与人工复核。
- **风险**：①影子本体被误当在线知识 ⇒ 强制隔离；②存储与复核成本 ⇒ 按信息价值排序。

### IP-20 · CoCreated Failure Taxonomy 共创失败分解（P1）

- **动机**：SAGE IP-06 的最大风险是"代理指标与真机不相关"。让真正做任务的人（用户）共创**阶段标注口径**（reach/grasp/transport/align/insert/release），能直接提升代理效度（Q22）。
- **与现有方案的差异**：别人用 VLM 自动打标；我们让用户共创**标注规范 + 争议裁决**，VLM 只是执行者。
- **落地步骤**：①用户共创标注手册与边界案例；②双标注 + 一致性检查；③用真机锚点做相关性标定（E809）；④把六因子作为其他 IP 的边际收益排序器。
- **风险**：①标注成本高 ⇒ 主动学习选样；②用户标注偏差 ⇒ 多标注者 + 一致性门槛；③与自动标注冲突 ⇒ 以真机相关性裁决。

### IP-21 · Instruction Diversity Mining 指令多样性挖掘（P1）

- **动机**：训练集每任务只有一条规范指令、行级无语言字段；需要主动构造**独立**的表层多样性，而不是等数据自然出现。
- **与现有方案的差异**：普通增广是"同一模板换词"；我们要求**跨来源、跨语言、跨句式**，并用 IP-16 的独立性度量去重。
- **落地步骤**：①LLM 生成 + 用户贡献 + 回译三源；②按语义聚类去重；③每任务目标 ≥8 种独立表层形式；④低置信的进影子本体。
- **风险**：①LLM 生成与用户贡献高度相关 ⇒ 独立性不足（G5）；②语义漂移 ⇒ 锚点校验。

### IP-22 · CoopAudit 共创审计看板（P2）

- **动机**：共创是供应链，需要可观测的治理指标。
- **落地步骤**：①出处/法定人数/编辑类型统计；②权限蠕变检测（累计编辑位移、表面积增长）；③共识健康度（`K_eff`、异议率、影子本体规模）；④导出报告。
- **风险**：指标好看 ≠ 真机好 ⇒ 必须与 E809/E820 对齐。

## 4. 符号与定义（C1–C14）

| 符号 | 含义 |
|---|---|
| `s` | 任务规格（规格图 LSG 的实例），语言无关 |
| `ℓ` | 表层语言形式（某语言、某句式、某别名） |
| `τ_ℓ` | 从 `s` 到 `ℓ` 的"表层化"映射（含语言/句式噪声） |
| `𝒢` | 规格图 schema：verb / entities / attributes / relations / constraints |
| `u` | 贡献者（用户 / 译者 / 标注者） |
| `c` | 贡献 `(u, ℓ, s_target, e, evidence, t)` |
| `E` | 编辑代数 `{ADD_SURFACE, SPLIT_SPEC, BIND_ATTR, TIGHTEN_REL, ABSTAIN}` |
| `𝒦` | 冻结技能库（SAGE 的专家头 + 原语） |
| `a(·)` | 语义对齐器：`ℓ ↦ p(s|ℓ)` |
| `ρ` | 编辑在规格嵌入空间的位移上界（trust-region 半径） |
| `K_eff` | 有效独立视图数 |
| `ΔR` | 回放集上的路由回归量（非目标任务 argmax 变化率） |
| `τ_c` | 共识接受阈值 |
| `τ_r` | 回放回归阈值 |
| `Ω` | 异议账本 / 影子本体 |

**定义 C1（表层视图）** `ℓ = τ_ℓ(s, ν)`，`ν` 为表层 nuisance（语言、同义词、语序、别名）。`s` 是唯一要恢复的量。
**定义 C2（规格图）** `s = (V, X, A, R, Con)`：动词、实体、属性、关系、约束；`𝒢` 定义合法的节点/边类型。
**定义 C3（贡献）** `c = (u, ℓ, s_target, e, evidence, t)`；`evidence` 可为示教片段、失败片段、文字说明。
**定义 C4（编辑代数）** `e ∈ E`：
- `ADD_SURFACE(s, ℓ')`：给规格 `s` 增加一个表层形式；
- `SPLIT_SPEC(s, cond, s_1, s_2)`：按视觉条件把一条指令拆到两个技能；
- `BIND_ATTR(obj_class, attr, grasp_strategy)`：物体属性→抓法/技能；
- `TIGHTEN_REL(s, relation, bound)`：收紧空间/时序约束；
- `ABSTAIN(s)`：标记为不可接地，触发降级而非硬猜。
每条编辑带 `support(e) ⊆ V∪X∪A∪R∪Con` 与嵌入位移 `‖Δe‖`。
**定义 C5（能力闭合）** 编辑只能把 `s` 映射到 `𝒦` 中既有技能；形式化：编辑后策略动作集 `⊆ ∪_{k∈𝒦} support(k)`。
**定义 C6（语义对齐）** `a(ℓ) = p(s | ℓ)`，由多语言编码器 + `𝒢` 解析器给出。
**定义 C7（共识）** 对目标 `s` 的贡献集 `C_s`，`A(s) = Σ_i w_i · 1[a(ℓ_i) ∈ B_ε(s)] / Σ_i w_i`，`B_ε(s)` 为语义半径 `ε` 内的规格球；接受当 `A(s) ≥ τ_c` 且独立贡献者数 `≥ M`。
**定义 C8（独立性 / 有效样本量）** 设各视图误差两两相关 `ρ̄`，则 `K_eff = K / (1 + (K−1) ρ̄)`；`ρ̄→1 ⇒ K_eff→1`。
**定义 C9（回放闸门）** `ΔR(e) = max_{t ≠ target} 1[argmax route_t 改变]`；安装当 `ΔR(e) ≤ τ_r`。
**定义 C10（trust-region）** `‖Δe‖ ≤ ρ`，且 `ADD_SURFACE` 的语义距离 `d(a(ℓ'), a(s)) ≤ ε`。
**定义 C11（异议账本）** `Ω = {(c, reason) : 被拒但 a(ℓ) ∈ B_ε(s_target)}`；只读、可复裁决、**不参与在线路由**。
**定义 C12（共创失败分解）** `P(success) ≈ ∏_{j∈Ŝ} P_j`，`Ŝ` 的标注口径由用户共创；与 SAGE U11 对齐。
**定义 C13（权限蠕变）** `Π(T) = Σ_{e∈accepted(T)} ‖Δe‖` 与表面积增长 `|surface(T)| − |surface(0)|`；超阈值冻结审计。
**定义 C14（共创效用）** `U(e) = Δ terminal success`（真机 A/B）或 `Δ proxy↔real |r|`（E809），二者至少一项为正才允许安装。

## 5. 推导（引理 CL1–CL8）

**引理 CL1（共识降方差、不降偏差）** 设每个视图误差 `e_i = β + ξ_i`，`β` 为系统性翻译漂移（偏差），`ξ_i` 为零均值独立噪声（方差 `σ²`）。则 K 视图均值 `ē = β + (1/K)Σξ_i`，`Var(ē) = σ²/K`，但 `E[ē] = β` 不随 K 减小。⇒ 共识只能压随机噪声，**压不掉系统性漂移**；接受判据必须同时约束 `β`（锚点校验）。∎

**引理 CL2（独立性支配数量 / 有效样本量）** 设视图误差两两相关 `ρ̄`，则均值方差 `Var(ē) = (σ²/K)(1 + (K−1)ρ̄)`，等效独立样本数 `K_eff = K/(1+(K−1)ρ̄)`，且 `lim_{K→∞} K_eff = 1/ρ̄`。故 `ρ̄=1`（同一 MT 引擎）时 `K_eff=1`，加语言不加信息；与本地探针 G5（相关噪声恒 0.941）一致。⇒ 必须度量并保证贡献者/译者的**多样性**，而非条数。∎

**引理 CL3（表层癖好应被拒绝）** 若某编辑的效果在语义保持变换（翻译/改写）下不保持，则其效果是表层 nuisance `ν` 的函数而非 `s` 的函数。将其提升进本体等于把 `ν` 的信息注入路由；由数据处理不等式，编辑效果中关于 `s` 的互信息不超过跨视图保持的部分。⇒ 跨视图不一致的编辑不应进入在线本体（进 `Ω`）。∎

**引理 CL4（能力闭合给出物理风险上界）** 若编辑后动作集 `⊆ ∪_{k∈𝒦} support(k)`，则任何执行动作的物理风险 `≤ max_{k∈𝒦} risk(k)`，与用户贡献无关。⇒ 共创不能扩大物理风险包络；这是可对组委会陈述的合规性质。∎

**引理 CL5（trust-region 约束路由劫持）** 设路由 logits 对规格嵌入 `L`-Lipschitz，编辑位移 `‖Δe‖ ≤ ρ`。则对任意非目标任务 `t`，`|Δ logit_t| ≤ Lρ`，故其路由概率变化被 `Lρ` 界定。取 `ρ` 使 `Lρ ≤ δ`，则单条编辑无法显著劫持其他任务；回放闸门（C9）提供经验兜底。∎

**引理 CL6（接受阈值的非对称最优）** 设接受收益 `V`、坏编辑代价 `C`（`C ≫ V`），阈值 `τ` 下假接受率 `α(τ)`、假拒绝率 `β(τ)`。净效用 `N(τ) = (1−β(τ))V − α(τ)C`。因 `C ≫ V`，最优 `τ*` 偏保守；与 SAGE L3 的"高精度低召回"同构。⇒ 默认取高阈值，宁拒勿滥。∎

**引理 CL7（异议账本的条件价值）** 保留被拒贡献的成本 `c_s`，其在未来证据到来时以概率 `p` 产生价值 `V`。当 `pV > c_s` 时保留优于丢弃。由于 `c_s`（存储+复核）远小于重收长尾知识的成本，只要 `p` 不极低，保留异议即正期望。⇒ 求稳不应丢弃长尾（P17）。∎

**引理 CL8（共创覆盖的语义上界）** 可被共创覆盖的规格集 `⊆` 贡献者词汇/概念并集的语义凸包。若某物体/关系在任何贡献语言中都不可表达，则共创无法覆盖它。⇒ 必须保留**视觉规格推断**作为兜底（承接 LENS 的视觉绑定），不能把共创当作万能覆盖。∎

```python
# ===== IP-15 + IP-16 + IP-17 + IP-18：一条贡献从提交到安装 =====
class SpecEdit:
    kind: str          # ADD_SURFACE / SPLIT_SPEC / BIND_ATTR / TIGHTEN_REL / ABSTAIN
    target: str        # spec id
    payload: dict
    support: set       # 受影响的规格节点
    delta_emb: "vec"   # 嵌入位移，供 trust-region

def compile_contribution(c):
    """用户自然语言/示教 -> 结构化编辑（IP-15）"""
    s_dist = aligner(c.ell)                 # C6: p(s|ell)
    if s_dist.entropy() > H_MAX:            # 语义不清
        return SpecEdit("ABSTAIN", None, {"ell": c.ell}, set(), 0.0)
    edit = edit_parser(c)                   # 规则 + LLM，输出白名单类型
    return edit

def consensus(target, contribs, anchor_set):
    """IP-16：跨语言加权共识 + 独立性修正（CL1/CL2）"""
    views = [aligner(c.ell) for c in contribs]
    rho = estimate_error_correlation(views, anchor_set)   # C8
    k_eff = len(views) / (1 + (len(views) - 1) * rho)
    if k_eff < K_EFF_MIN:
        return None, k_eff                # L1：独立性不足 -> 降级
    w = [c.trust / (1 + rho * (len(views) - 1)) for c in contribs]
    score = sum(wi * (v.in_ball(target, EPS)) for wi, v in zip(w, views)) / sum(w)
    return (score >= TAU_C and distinct_users(contribs) >= M), k_eff

def replay_gate(edit, replay_set, router):
    """IP-17：本体编辑的路由回归测试（零真机）"""
    before = {t: router(t) for t in replay_set}
    router_apply(edit)
    after = {t: router(t) for t in replay_set}
    drift = max((before[t] != after[t] and before[t].task != edit.target)
                for t in replay_set)
    router_revert(edit)
    return not drift

def install(edit, contribs, replay_set, router, anchor_set):
    # 1) 能力闭合（IP-18）
    if not within_closed_skill_space(edit, SKILL_LIB):
        return "REJECT_CLOSURE"
    # 2) trust-region（C10）
    if norm(edit.delta_emb) > RHO:
        return "REJECT_TRUST_REGION"
    # 3) 共识（IP-16）
    ok, k_eff = consensus(edit.target, contribs, anchor_set)
    if not ok:
        dissent_ledger.add(edit, reason="NO_CONSENSUS", k_eff=k_eff)  # IP-19
        return "SHADOW"
    # 4) 回放闸门（IP-17）
    if not replay_gate(edit, replay_set, router):
        dissent_ledger.add(edit, reason="REGRESSION")
        return "SHADOW"
    # 5) 安装 + 版本化（IP-15）
    ledger.append(edit)
    ontology_snapshot.commit(edit)
    return "INSTALLED"
```

```python
# ===== IP-16：有效样本量在线估计（CL2）=====
def estimate_error_correlation(views, anchors):
    """用锚点集上各视图的误差是否同向，估计 rho。"""
    errs = []
    for v in views:
        e = [v.disagree(a) for a in anchors]   # 0/1 误差向量
        errs.append(e)
    pairs = []
    for i in range(len(errs)):
        for j in range(i + 1, len(errs)):
            pairs.append(phi_corr(errs[i], errs[j]))
    return max(0.0, mean(pairs)) if pairs else 0.0
```

```python
# ===== IP-20：共创失败分解（与 SAGE U11 对齐）=====
def cocreated_taxonomy(episode, user_labels, kappa_min=0.6):
    """用户共创阶段标注；一致性不足的片段不进统计。"""
    if fleiss_kappa(user_labels) < kappa_min:
        return None                       # 争议片段，人工裁决
    factors = {j: 1.0 for j in
               ["reach", "grasp", "transport", "align", "insert", "release"]}
    first_fail = None
    for j in factors:
        if user_labels[j] is False and first_fail is None:
            first_fail = j
    if first_fail:
        for j in list(factors)[list(factors).index(first_fail):]:
            factors[j] = 0.0              # 首个失败点之后被吸收
    return factors
```
