# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「迁移学习」×「机械臂」）

> 第 54 轮把技能从“能力”细化为动作空间占用 `α_S`，并用 SCOM/CEC/AEC 把技能组合与云边协同变成可判定路径。本轮引入 **迁移学习 × 机械臂**：当技能要跨机械臂复用（不同自由度、连杆比、关节限位、惯量/摩擦、末端工具），第 54 轮的“动作兼容”只说明两个技能在同一动作空间可拼接，**并不说明源臂策略在目标臂上可迁移**。核心矛盾：H22 任务语义相同、动作剖面看似可对齐，但形态差使“任务无关零空间”发生改变，迁移在零空间上系统性失效；H23 负迁移是延迟显现的慢性漂移，源域签发的证书在目标域可能静默过期，需要**可撤销租约 + 在线绊线**。

## 0. 直觉与动机

**灵感 1（迁移的不是策略，而是任务可见的动作商）**
直觉：换一条机械臂，任务的“坐标系”通常不变（末端位姿、接触力、抓取点），变的是实现同一任务动作的冗余方式。于是把源动作空间按任务帧投影 `Π_T` 商掉零空间：`A_s/∼ ≅ A_t/∼`。只迁移任务相关子空间上的策略，零空间交给目标臂重学。**能迁移的是任务“看得见”的部分，不能迁移的是臂“自己才知道”的部分。**

**灵感 2（迁移性是剖面，不是成功率标量）**
直觉：一个源臂对目标臂的迁移成功率 0.8，可能意味着 80% 的动作区很好、20% 的动作区灾难性负迁移。用 `τ_{s→t}(a,d)` 在动作区 × 鲁棒维度上给出保留率剖面，并只对 `τ ≥ θ_τ` 的 **可迁移核 `U_τ`** 签发证书。标量成功率会掩盖局部崩塌，而局部崩塌恰好常发生在关节限位、奇异位形与接触边界。

**灵感 3（机械臂形态指纹 → 迁移源检索）**
直觉：不同臂的差异可由低维形态指纹刻画：自由度、连杆长度比、关节限位、惯量比、摩擦/背隙、负载与工具。先用指纹距离检索“形态近邻”源臂，以近邻的历史迁移成绩做先验，再做小预算目标域校准。这把迁移从“拍脑袋选源”变成**基于形态的检索 + 校准**，也使源选择可解释。

**灵感 4（负迁移是慢性中毒 → 租约 + 绊线）**
直觉：负迁移很少在第一步爆炸，而是漂移累积后在接触或极限动作处暴露。给每次迁移签发**可撤销租约 `lease = (作用域, TTL, 回退锚点, 撤销谓词)`**；边端用任务不变量残差做 CUSUM/共形检验，一旦超阈立即吊销租约并回退到源锚点安全策略。证书因此不是一次性许可证，而是**带有效期和撤销条件的租约**。

**灵感 5（保护性课程：冻结可迁移核，只学零空间残差）**
直觉：目标域适配不要全参数微调，而是把策略分解为 `Π_T∘π_s + Π_N∘π_res`，冻结任务相关核，只在零空间学习有界残差，并用第 54 轮联合证书 `J` 做安全滤波。这样把“迁移学习”变成**带证书的动作空间约束优化**，而不是黑箱 fine-tune。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（形态映射与任务相关动作商）**
源臂动作空间 `A_s`、目标臂动作空间 `A_t`，形态映射 `φ_{s→t}: A_s → A_t`，任务帧投影 `Π_T: A → A_T`。称 `a_s ∼ a_t` 当且仅当 `Π_T(φ_{s→t}(a_s)) = Π_T(a_t)`；商空间 `A/∼` 称为**任务相关动作商**。策略 `π_s` 在 `φ` 下 `ε`-任务不变，若
```
sup_{a∈U} || Π_T(φ(π_s(a))) − Π_T(π_t(a)) || ≤ ε_task。
```
零空间 `N = ker(Π_T ∘ Dφ)`，其维数 `n_null = dim(A) − rank(Π_T∘Dφ)`。

**定义 122（迁移性剖面与可迁移核）**
源→目标迁移性剖面
```
τ_{s→t}(a,d) = clip( E[R_t(π_s; a,d)] / max(E[R_s(π_s; a,d)], ε_0), 0, 1+τ_max )，
```
其中 `R` 为任务回报、`d∈𝔇_ρ` 为鲁棒维度。可迁移核
```
U_τ(θ_τ) = { a : τ_{s→t}(a,d) ≥ θ_τ ∀d 且 ρ_t(a,d) ≥ ρ_min }。
```
`τ>1` 表示正迁移，`τ<1` 表示负迁移；**只有 `U_τ` 内的动作可进入证书**。

**定义 123（形态指纹与迁移先验）**
机械臂形态指纹
```
m(arm) = (n_dof, {l_i/L}, {q_i^min, q_i^max}, {I_i/I_0}, μ_f, β_b, m_payload, tool_type)。
```
归一化距离 `d_m(s,t) = ||W_m(m_s − m_t)||_2`。迁移先验 `τ_prior(s→t)=g(d_m(s,t))`，`g` 为由历史迁移成绩拟合的单调非增函数。检索取 `k` 个形态近邻作为候选源。

**定义 124（形态迁移证书 MTC）**
```
C_mt = (φ, U_τ, Δρ^cert_α, δ_kin, B_cal, lease, evidence)，
lease = (scope, TTL, anchor, revoke)。
```
- `Δρ^cert_α`：置信水平 `1−α` 下逐维鲁棒性保留偏差上界；
- `δ_kin`：形态映射误差上界；
- `B_cal`：目标域校准预算；
- `anchor`：回退锚点策略；
- `revoke`：吊销谓词（由 NTT 触发）。
若 `a∈U_τ`、`δ_kin<Θ_k` 且租约有效，则迁移可部署。**Soundness**：对 `a∈U_τ`，
```
Pr[ ρ_t(a,d) ≥ ρ_s(a,d) − Δρ^cert_α(d) ] ≥ 1−α。
```

**定义 125（负迁移绊线 NTT）**
任务不变量残差
```
r_t = || Π_T(φ(a_s)) − Π_T(a_t^obs) ||_Σ + λ·|Δ task_reward|。
```
CUSUM 统计量 `S_t = max(0, S_{t−1} + r_t − μ_0 − k)`。报警条件
```
S_t > h  或  conformal_pvalue(r_t) < α_ntt。
```
报警即 `revoke(lease)` 并回退 `anchor`。NTT 需同时约束**检测延迟 `D`** 与**误报率 `α_ntt`**。

**定义 126（零空间残差适配与保护性课程）**
目标策略
```
π_t = Π_T∘π_s + Π_N∘π_res，  ||π_res||_{H∞} ≤ B_res，  a_t ∈ A_t^safe。
```
保护性课程 `C = (冻结 U_τ → 边界动作主动采样 → 零空间残差学习 → 证书重签)`。组合证书
```
C_adapt = compose(C_mt, J)，
```
其中 `J` 为第 54 轮的动作-鲁棒性联合证书。

**新增假设**
- **(A29)** `φ` 在 `U_τ` 上 `L`-Lipschitz，且可用目标域小预算校准；
- **(A30)** 任务帧 `Π_T` 与目标安全集 `A_t^safe` 已知且可判定；
- **(A31)** 校准样本在 `U_τ` 上分组条件可交换，或可用加权共形修正；
- **(A32)** NTT 误报率 `≤ α_ntt`，检测延迟 `≤ D_max`。

## 2. 关键算法伪代码

### IP-121 TDM（Task-relevant Domain Map）

```python
def task_quotient(source_arm, target_arm, task_frame, probes):
    J_task = numerical_jacobian(task_frame.success, probes)
    U, S, Vt = svd(J_task)
    T_basis = Vt[:rank_threshold(S)]      # 任务相关子空间
    N_basis = null_space(J_task)          # 任务无关零空间
    phi = fit_morphology_map(source_arm, target_arm, probes)
    return Quotient(phi, T_basis, N_basis, spectral_gap(S))
```

### IP-122 TFP（Transferability Profile）

```python
def transfer_profile(src, tgt, phi, U, dims, budget):
    calib = active_calibrate(tgt, U, budget)
    tau = {}
    for a, d in sample_action_dims(U, dims):
        r_s = rollout(src.policy, a, d)
        r_t = rollout_on_target(src.policy, phi(a), d, calib)
        tau[(a, d)] = clip(r_t / max(r_s, EPS), 0.0, 1.0 + TAU_MAX)
    U_tau = {a for a in U if all(tau[(a, d)] >= theta_tau for d in dims)}
    return TransferProfile(tau, U_tau), calib
```

### IP-123 MTC（Morphology Transfer Certificate）

```python
def morphology_certificate(src, tgt, profile, calib, alpha):
    scores = {d: [profile.rho_src(c, d) - profile.rho_tgt(c, d) for c in calib]
              for d in profile.dims}
    dq = {d: weighted_conformal_quantile(scores[d], 1 - alpha) for d in scores}
    delta_kin = max_alignment_error(profile.phi, profile.U_tau)
    if not profile.U_tau or delta_kin > THETA_K:
        return ('reject', 'morphology_mismatch', delta_kin)
    lease = Lease(scope=profile.U_tau, ttl=TTL,
                  anchor=src.safe_policy, revoke=NTT)
    return ('ok', MTC(profile.phi, profile.U_tau, dq, delta_kin, lease))
```

### IP-124 NTT（Negative Transfer Tripwire）

```python
def ntt_monitor(lease, stream, mu0, k, h, alpha):
    S = 0.0
    for t, obs in enumerate(stream):
        r = invariant_residual(obs) + lam * abs(task_reward_residual(obs))
        S = max(0.0, S + r - mu0 - k)
        p = conformal_pvalue(r, lease.calib_scores)
        if S > h or p < alpha:
            return ('revoke', t, S, p)
        if t > lease.ttl:
            return ('expire', t)
    return ('valid', len(stream))
```

### IP-125 NSR（Null-Space Residual Adaptation）

```python
def safe_residual_adapt(pi_s, quotient, target, B_res, J_cert):
    pi_res = init_zero()
    for stage, region in curriculum(quotient.U_tau):
        pi_t = compose(pi_s, pi_res, quotient.T_basis, quotient.N_basis)
        a = pi_t.act(obs)
        if not J_cert.allows(a) or norm_Hinf(pi_res) > B_res:
            pi_res = project(pi_res, B_res)
            a = safe_filter(pi_t, target.safe_set)
        pi_res = update(pi_res, target.rollout(a))
    return pi_t, recompute_certificate(pi_t, quotient)
```

### IP-126 TSC（Transfer Skill Composition）

```python
def transfer_skill_composition(G_src, tgt, task, budget):
    best = None
    for src in rank_by_morphology(tgt, sources, prior=tau_prior):
        profile, calib = transfer_profile(src, tgt, ...)
        for path in k_shortest_paths(G_src, task):
            C = compose_transfer_cert(path, profile, J)
            if C.sound and C.lease.scope_covers(path):
                best = argmin(best, C, key=lambda c: c.cost_align + c.cost_transfer)
    return best or ('reject', 'no_transferable_core')
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| TDM | `O(|probes|·|A| + n³)` | `O(n²)` | 任务子空间谱隙显著、φ 可辨识 |
| TFP | `O(B_cal·|U|·|𝔇_ρ|)` | `O(|U|·|𝔇_ρ|)` | 校准覆盖可迁移核、剖面无偏 |
| MTC | `O(B_cal log B_cal)` | `O(B_cal)` | 分组条件共形、δ_kin 有界 |
| NTT | `O(1)`/步 | `O(W)` | 误报 ≤ α_ntt、延迟 ≤ D_max |
| NSR | `O(E·|A|)` | `O(|A|)` | 残差有界、安全滤波不越界 |
| TSC | `O(|Src|·|P|·|E|)` | `O(|V|+|E|)` | 证书可组合、租约作用域闭合 |

**定理（Morphology Transfer Soundness with Revocable Lease）**
在 (A29)–(A32) 与第 54 轮 (A22)–(A28) 成立时，若 `C_mt` 在 `U_τ` 上以水平 `α` 签发，则对任意 `a∈U_τ, d∈𝔇_ρ`：
```
Pr[ ρ_t(a,d) ≥ ρ_s(a,d) − Δρ^cert_α(d) ] ≥ 1 − α − P(φ 违反 Lipschitz)。
```
目标域部署成功概率：
```
P_success^t ≥ 1 − Σ_d (1 − ρ_t(d)) − P(δ_kin > Θ_k)
            − P(负迁移 ∧ D_max 内未检出) − β_E，
```
且
```
P(负迁移 ∧ D_max 内未检出) ≤ α_ntt + P(D > D_max)。
```
关键在于：**证书只覆盖可迁移核，租约把“一次性正确”变成“持续可撤销的正确”**。

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 迁移性剖面校准 | `τ` 预测 vs 实测、ECE | ECE ≤ 0.08 |
| E163 负迁移绊线 | 检测延迟分布 / 误报率 | 延迟 P95 ≤ 20 步，FPR ≤ 3% |
| E164 跨臂迁移增益 | 成功率 vs 从头训练/全量 fine-tune | 样本效率 ≥ 3×，成功率 +15% |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 任务动作商在形态变化下并非不变量 | 高 | 任务帧敏感性检验 + 目标域主动探测 + 拒绝迁移 |
| 小预算校准不覆盖 `U_τ` 边界 | 高 | 分组条件共形 + 边界/极限动作优先采样 |
| NTT 检测延迟导致慢性负迁移 | 高 | 多信号 CUSUM + 物理守恒残差 + 短 TTL 租约 |
| 形态指纹检索偏向数据多的源臂 | 中 | 分组平衡 + 先验校准 + 每源最小证据量 |
| 零空间残差学习越界 | 中 | 安全滤波 + H∞ 范数投影 + 第 54 轮 J 证书 |
| 仿真到真机的动力学差异被误判为负迁移 | 中 | 域随机化 + 动力学参数在线辨识 + 双阈值 |

## 6. 本轮最大风险

**一句话**：本轮把跨机械臂迁移从“成功率”升级为“任务相关动作商 + 可撤销迁移租约”，但其 soundness **同时依赖任务商在形态变化下真正不变、目标域小预算校准对 `U_τ` 边界有覆盖、以及 NTT 在 `D_max` 内检出负迁移**；一旦形态映射 `φ` 在小样本下不可辨识、或校准集系统性缺失极限动作，证书会把“源域可迁移假象”签成“目标域可部署事实”，随后负迁移在接触/限位处慢性累积并绕过绊线，故必须以 **目标域主动边界校准 + 分组共形 + 短租约回退锚点** 三重护栏，宁可拒绝迁移，也不签发无法撤销的迁移证书。

## 2. 关键推导：为什么“动作剖面兼容”不等于“可迁移”

以平面 3R 机械臂为例，关节空间 `q=(q1,q2,q3)`，末端位置 `x∈ℝ²`。雅可比 `J(q)∈ℝ^{2×3}`，`rank J=2`（非奇异时），故
```
dim T = 2,   dim N = dim ker J = 1。
```
源臂与目标臂若仅连杆长度不同，末端任务帧相同，但零空间方向 `n_s(q) ≠ n_t(q)`。设源策略分解为
```
π_s(q) = π_s^T(q) + π_s^N(q),   π_s^N = n_s(n_sᵀπ_s)。
```
直接迁移到目标臂得到残差
```
r_N = || Π_{N_t} π_s || = || n_t n_tᵀ (π_s^T + n_s n_sᵀ π_s) ||。
```
即使 `Π_T φ π_s = Π_T π_t`（末端轨迹完全一致），只要 `n_t ≠ n_s`，`r_N>0`；该残差正是目标臂上关节限位/奇异回避失效的来源。**命题（非正式）**：在任务轨迹相同、连杆比差异为 `Δl` 的一族 3R 平面臂上，`r_N` 随 `||n_t−n_s||` 单调增，且关节限位违反概率随 `r_N` 增大。因此迁移证书必须显式记录 `N` 的差异，而不能只看 `α_S` 的任务帧覆盖。

**三个直接推论**
1. **可迁移核应优先取任务相关子空间**：`U_τ` 在 `T` 上的投影应接近满覆盖，在 `N` 上应允许为空。
2. **负迁移的早期信号是零空间残差而非任务误差**：任务误差可能被反馈暂时掩盖，零空间残差先累积。
3. **租约应绑定 `U_τ` 与形态指纹**：目标臂或工具一换，`lease` 立即失效，必须重签。

### IP-121 TDM

```python
def task_quotient(source_arm, target_arm, task_frame, probes):
    J_task = numerical_jacobian(task_frame.success, probes)
    U, S, Vt = svd(J_task)
    T_basis = Vt[:rank_threshold(S)]
    N_basis = null_space(J_task)
    phi = fit_morphology_map(source_arm, target_arm, probes)
    gap = S[rank_threshold(S)-1] - S[rank_threshold(S)]
    if gap < GAP_MIN:
        return ('reject', 'task_subspace_ambiguous', gap)
    return Quotient(phi, T_basis, N_basis, gap)
```

### IP-122 TFP

```python
def transfer_profile(src, tgt, phi, U, dims, budget):
    calib = active_calibrate(tgt, U, budget, prioritize=boundary_actions)
    tau = {}
    for a, d in sample_action_dims(U, dims):
        r_s = rollout(src.policy, a, d)
        r_t = rollout_on_target(src.policy, phi(a), d, calib)
        tau[(a, d)] = clip(r_t / max(r_s, EPS), 0.0, 1.0 + TAU_MAX)
    U_tau = {a for a in U
             if all(tau[(a, d)] >= theta_tau for d in dims)}
    return TransferProfile(tau, U_tau, calib)
```

### IP-123 MTC

```python
def morphology_certificate(src, tgt, profile, calib, alpha):
    dq = {}
    for d in profile.dims:
        scores = [profile.rho_src(c, d) - profile.rho_tgt(c, d) for c in calib]
        dq[d] = weighted_conformal_quantile(scores, level=1-alpha)
    delta_kin = max_alignment_error(profile.phi, profile.U_tau)
    if not profile.U_tau or delta_kin > THETA_K:
        return ('reject', 'morphology_mismatch', delta_kin)
    lease = Lease(scope=profile.U_tau, ttl=TTL,
                  anchor=src.safe_policy,
                  revoke=lambda obs: NTT(obs) or fingerprint_changed(tgt))
    return ('ok', MTC(profile.phi, profile.U_tau, dq, delta_kin, lease))
```

### IP-124 NTT

```python
def ntt_monitor(lease, stream, mu0, k, h, alpha):
    S = 0.0
    for t, obs in enumerate(stream):
        r = invariant_residual(obs) + lam * abs(task_reward_residual(obs))
        S = max(0.0, S + r - mu0 - k)
        p = conformal_pvalue(r, lease.calib_scores)
        if S > h or p < alpha:
            lease.revoke(reason=('cusum' if S > h else 'conformal', t))
            return ('revoke', t, S, p)
        if t > lease.ttl:
            return ('expire', t)
    return ('valid', len(stream))
```

### IP-125 NSR

```python
def safe_residual_adapt(pi_s, quotient, target, B_res, J_cert):
    pi_res = init_zero()
    for stage, region in curriculum(quotient.U_tau):
        pi_t = compose(pi_s, pi_res, quotient.T_basis, quotient.N_basis)
        a = pi_t.act(obs)
        if not J_cert.allows(a) or norm_Hinf(pi_res) > B_res:
            pi_res = project(pi_res, B_res)
            a = safe_filter(pi_t, target.safe_set)
        pi_res = update(pi_res, target.rollout(a))
    return pi_t, recompute_certificate(pi_t, quotient)
```

### IP-126 TSC

```python
def transfer_skill_composition(G_src, tgt, task, budget):
    best = None
    for src in rank_by_morphology(tgt, sources, prior=tau_prior):
        profile, calib = transfer_profile(src, tgt, ...)
        for path in k_shortest_paths(G_src, task):
            C = compose_transfer_cert(path, profile, J)
            if C.sound and C.lease.scope_covers(path):
                cand = (C.cost_align + C.cost_transfer, C)
                best = cand if best is None or cand[0] < best[0] else best
    return best[1] if best else ('reject', 'no_transferable_core')
```

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TDM | `O(|probes|·|A| + n³)` | `O(n²)` | 任务子空间谱隙显著、`φ` 可辨识 |
| TFP | `O(B_cal·|U|·|𝔇_ρ|)` | `O(|U|·|𝔇_ρ|)` | 校准覆盖 `U_τ`，剖面误差有界 |
| MTC | `O(B_cal log B_cal)` | `O(B_cal)` | 分组共形覆盖 `≥1−α`，`δ_kin<Θ_k` |
| NTT | `O(1)`/步 | `O(W)` | FPR `≤α_ntt`，延迟 `≤D_max` |
| NSR | `O(E·|A|)` | `O(|A|)` | `||π_res||≤B_res`，安全滤波不越界 |
| TSC | `O(|Src|·|P|·|E|)` | `O(|V|+|E|)` | 证书可组合、租约作用域闭合 |

**定理（Morphology Transfer Soundness with Revocable Lease）**
假设 (A29)–(A32) 与第 54 轮 (A22)–(A28) 成立，`C_mt` 在 `U_τ` 上以水平 `α` 签发，且 `lease` 在每次动作前校验。则对任意 `a∈U_τ, d∈𝔇_ρ`：
```
Pr[ ρ_t(a,d) ≥ ρ_s(a,d) − Δρ^cert_α(d) ] ≥ 1 − α − P(φ 违反 Lipschitz)
```
目标域部署成功概率：
```
P_success^t ≥ 1 − Σ_d(1−ρ_t(d)) − P(δ_kin>Θ_k)
            − P(负迁移 ∧ D_max 内未检出) − β_E
P(负迁移 ∧ D_max 内未检出) ≤ α_ntt + P(D>D_max)
```
**证明思路**：可迁移核内由加权共形给出逐维偏差覆盖；`δ_kin` 有界保证 `Π_T∘φ` 与目标任务帧一致；NTT 的 CUSUM 控制检测延迟、共形通道控制误报，二者任一触发即吊销租约并回退 `anchor`，故未检出负迁移的概率被 `α_ntt + P(D>D_max)` 控制；`β_E` 继承第 54 轮边端仿真误差项。∎

**与第 54 轮证书的关系**
```
J  = (ρ, A_cert, γ_ce, δ_a, evidence)                    # 动作-鲁棒性联合证书
C_mt = (φ, U_τ, Δρ^cert_α, δ_kin, B_cal, lease, evidence) # 形态迁移证书
C_adapt = compose(C_mt, J) = (ρ_t, A_cert∩U_τ, γ_ce∘φ, δ_a+δ_kin,
                              lease, evidence ∪ calib)
```
组合要求 `U_τ ⊆ A_cert` 且 `lease.scope` 覆盖组合路径；否则拒绝。

## 8. 本轮最大风险

**一句话**：v32 把跨机械臂迁移从“成功率”升级为“任务相关动作商 + 可撤销迁移租约”，但其 soundness **同时依赖任务商在形态变化下真正不变、目标域小预算校准对 `U_τ` 边界有覆盖、以及 NTT 在 `D_max` 内检出负迁移**；一旦形态映射 `φ` 在小样本下不可辨识、或校准集系统性缺失极限动作，证书会把“源域可迁移假象”签成“目标域可部署事实”，随后负迁移在接触/限位处慢性累积并绕过绊线，故必须以 **目标域主动边界校准 + 分组共形 + 短租约回退锚点** 三重护栏，宁可拒绝迁移，也不签发无法撤销的迁移证书。
