# 第 47 轮（承接第 46 轮 v23；本轮灵感：结构优化 × MuJoCo） · Morph-Cert：结构-观测协同优化下的结构条件化姿态证书与 MuJoCo 数字孪生（架构 v11）

> 承接第 46 轮 v23 Memory-Safety-Voice。v23 已把记忆检索、语音意图、能量租约与姿态证书统一到全局决策 Π，但仍隐含假设 H5：机体结构（连杆质量/惯量分布、关节刚度与柔顺、相机安装位形与基线）在整个部署周期内固定，且证书所依赖的物理模型不变。现实中 UniBot 为布线、负载与深度相机安装会替换支架、增减配重、调整相机外参，甚至因碰撞导致关节预紧力漂移；同时结构优化又会主动改变几何/材料/传感器布局。两个灵感词精确命中 H5：**结构优化**把机器人本体从常量变成可设计变量，它既能缩小证书半径，也会使旧证书失效；**MuJoCo**提供接触丰富的数字孪生，可在部署前批量评估候选结构、在部署后量化仿真-现实残差。二者耦合出的新问题：**如何把结构变量、观测布局与姿态证书联合优化，并在结构发生未申报漂移或仿真-现实残差超界时，使证书 fail-closed 而不是静默继承旧结构的覆盖保证**。

## 0. 直觉与动机

**灵感 1（结构优化 → 证书是结构的函数，不是机器人的常量）**
直觉：姿态证书的半径不是凭空标定出来的，它依赖相机装在哪、基线多宽、连杆多硬、质量怎么分布。换一个 3mm 支架、把深度相机外移 2cm、或者关节预紧力变了，旧的共形校准就失去意义。因此证书必须带“结构护照”：$P_t(S)$ 只在结构指纹 $H_S$ 的有效域内成立。反过来，结构也可以被优化：更合理的相机基线与安装角会降低弱纹理/遮挡层的不确定性，更小的末端惯量会降低接触冲击引起的姿态漂移。

**灵感 2（MuJoCo → 可审计的数字孪生，而不是现实的替身）**
直觉：MuJoCo 能在几小时内跑完数千个接触、摩擦、遮挡场景，还能对“换支架/加配重/改柔顺”做反事实回放，这是实机做不到的。但 MuJoCo 的接触参数、摩擦锥、执行器延迟与真实硬件有差距；它只能给出可检验的假设、候选排序和残差上界，不能替代实机证书。因此 MuJoCo 的产物必须是带不确定性的 $(\delta_s,\Theta)$，而不是一个“仿真里通过”的勾。

**灵感 3（耦合 → 结构-观测协同设计与证书迁移界）**
直觉：如果证书半径随结构连续变化，那么结构小改可以“迁移”证书：新半径 ≤ 旧半径 + $L_S\cdot d_S(S,S') + L_\delta\cdot\delta_s$。这给出两种安全动作：要么把结构改动控制在小距离内并支付膨胀项，要么触发再认证。协同设计则把结构参数、传感器位置、控制限速与证书半径放进同一目标，在 MuJoCo 中做多目标搜索，再用独立实机审计集校准迁移界。

**架构升级（v11）**：在 v23 五链路之上补“本体结构”维度。根信任层增加结构护照 $\ell_s$；L1 几何层由固定半径查表升级为结构条件化半径 $r_\omega(m;H_S)$；L2 记忆/语音检索以结构指纹为键，结构不符时禁止跨结构复用；L3 CAR 守卫加入结构有效性与残差界；L4 DCL 采集结构扰动与仿真-现实配对样本，用于标定 $L_S$、$L_\delta$ 与 $\delta_s$。

## 1. 形式化定义（增量：定义 59–63）

**定义 59（结构变量与结构指纹）**
结构 $S=(G,m(\cdot),I(\cdot),K(\cdot),\Sigma_{sensor})$，分别为几何/拓扑、质量分布、惯量、关节刚度/柔顺与传感器安装位形。结构指纹
$H_S=\mathrm{Hash}(\text{CAD/BOM},\ \hat m,\hat I,\ \text{相机外参},\ \text{关节预紧/背隙})$，
结构护照 $\ell_s=(H_S,S,D_{valid},\delta_s,\tau_S)$，其中 $D_{valid}$ 为证书有效域，$\delta_s$ 为仿真-现实残差上界，$\tau_S$ 为认证时刻。结构距离
$d_S(S,S')=\|W\odot(S-S')\|_1$
对质量、惯量、外参、刚度分别加权归一。

**定义 60（结构条件化姿态证书与迁移界）**
证书 $P_t(S)=Ball(\hat x_t,r_\omega(m;H_S))$，其 soundness 只在 $H_S$ 有效且 $S\in D_{valid}$ 时声明：
$\Pr(X_t\in P_t(S)\mid \omega_t,m_t,\ell_s\ \text{valid})\ge 1-\alpha_p$。
**迁移界**：若 $d_S(S,S')\le\varepsilon_S$，则
$r_\omega(m;S')\le r_\omega(m;S)+L_S\,d_S(S,S')+L_\delta\,\delta_s$。
超出 $\varepsilon_S$ 或指纹不匹配时，证书立即失效，不允许“就近复用”。

**定义 61（MuJoCo 数字孪生与仿真-现实残差）**
对结构 $S$ 建 MuJoCo 模型 $T(S;\theta_{phys})$，$\theta_{phys}$ 为摩擦、接触刚度、执行器延迟等辨识参数。对配对场景 $\xi\sim\mathcal D$ 同时采集实机与仿真轨迹，定义可观测量差
$\delta_s=\mathrm{Quantile}_{1-\beta}\big(\sup_\xi\|y_{real}(\xi)-y_{sim}(\xi;\theta_{phys})\|\big)$。
残差有效域 $\Theta=\{\theta:\text{paired residual}\le\delta_s\}$；只有 $\theta_{phys}\in\Theta$ 的仿真结果可用于结构排序与迁移界，不得用单一“通过/不通过”替代覆盖声明。

**定义 62（结构-观测协同设计）**
联合设计变量 $(S,\text{placement},\text{limits})$，目标
$\min\ \mathbb E_{\xi\sim\mathcal D}[\mathrm{rad}(P_t(S))]+\lambda_e\mathbb E[E(S)]+\lambda_m\,\mathrm{mass}(S)$
s.t. 结构强度/柔顺 $g(S)\le0$、可达性、接触稳定、传感器视场，以及
$\Pr(\text{coverage}\ge1-\alpha_p)\ge1-\beta$。
MuJoCo 批量回放提供目标与约束估计，最终由独立实机审计集确认，避免在仿真中自证。

**定义 63（结构漂移检测与再认证）**
在线观测结构残差向量
$z_t=(\text{关节力矩残差},\ \text{IMU 模态频率偏移},\ \text{相机外参残差},\ \text{质量估计偏差})$，
输出漂移距离 $\hat d_S(t)$。当 $H_S$ 失配或 $\hat d_S(t)>\varepsilon_{re}$ 时，$\ell_s$ 作废 → 所有结构条件化证书作废 → CAR fail-closed，并触发再认证。再认证完成前只允许低速/保守姿态盒。

## 2. 三大新增产出与既有 IP 升级

**IP-69 MORPH-OPT（Structure-Observer Co-Design）**
- 结构参数化：支架拓扑/厚度、配重位置、关节柔顺、相机基线/俯仰/安装点
- 目标：期望证书半径、能耗、质量、接触稳定性的多目标
- MuJoCo 批量回放做候选排序；CMA-ES/拓扑优化做搜索；实机审计集做最终确认

**IP-70 MJ-TWIN（MuJoCo Digital Twin & Sim-to-Real Auditor）**
- 系统辨识：摩擦、接触刚度、执行器延迟、传感器噪声
- 配对回放与残差分位数 $\delta_s$，维护有效域 $\Theta$
- 失败场景挖掘：把真实失败注入仿真，生成结构扰动与证书迁移样本

**IP-71 STRUCT-CERT（Structure Passport & Certificate Transfer）**
- 结构指纹与护照签发/撤销
- 结构条件化半径表 $r_\omega(m;H_S)$ 与迁移界检查
- 在线漂移检测、再认证触发器、fail-closed 级联

**既有 IP 升级**
- IP-60 PSE：签发 $P_t(S)$，同时返回 $H_S$ 与迁移膨胀项
- IP-63 ECPS：能量模型加入结构质量/惯量；结构变化后重估功耗
- IP-61 DCL：采集结构扰动与仿真-现实配对样本
- IP-62 CCA：新增结构替换、关节松动、仿真参数漂移红队
- IP-51 CAR：守卫加入 $H_S$ 有效、$\hat d_S\le\varepsilon_{re}$、$\delta_s\le\delta_{max}$
- IP-45 总线：新增 structure-fingerprint / structure-drift / sim2real-residual 话题

## 3. 算法骨架

MORPH-OPT（离线/低频）：
1. 由 CAD/BOM 与实测惯量生成候选 $S$ 与 MuJoCo 模型
2. 对每个候选跑任务分布 $\mathcal D$，估计 $r_\omega(m;S)$、能耗与接触失败率
3. 用迁移界筛选“可认证”候选，剔除仿真过拟合（残差 $\delta_s$ 超界）
4. 在实机审计集上复核 top-k，签发结构护照与初始半径表

运行时（每控制周期）：
1. 读 $H_S,\hat d_S(t),\delta_s$ 与 $\ell_s$ 有效期
2. 若指纹失配或漂移超界 → 证书作废、fail-closed、进入低速再认证
3. 否则用 $r_\omega(m;H_S)$ 签发 $P_t(S)$，并把迁移膨胀项并入半径
4. CAR 用结构条件化证书守卫；ECPS 用结构相关功耗更新能量租约

## 4. 本轮最大风险

**一句话**：结构优化与 MuJoCo 会强烈激励“在仿真里把结构改到刚好安全”，但仿真接触参数与真实硬件存在系统偏差；若结构指纹漏检未申报改动（关节松动、支架微裂、配重滑移），结构条件化证书会带着错误的迁移界继续签发，安全保证被静默破坏——因此必须让仿真只做排序、实机审计集签证书，并对任何指纹/漂移越界默认 fail-closed。

## 2. 关键算法伪代码

### IP-69 MORPH-OPT：结构-观测协同设计
```
def morph_opt(S0, task_dist, mj, real_audit, budget, lam_e, lam_m):
    candidates = sample_structures(S0, budget)   # 拓扑/厚度/配重/相机位形/柔顺
    scored = []
    for S in candidates:
        if not structural_constraints(S):        # 强度、振动、可达、FOV
            continue
        twin = mj.build(S)
        theta = sysid(twin, real_audit.paired)   # 摩擦/接触刚度/延迟辨识
        if not in_valid_domain(theta, real_audit.delta_s):
            continue                             # 仿真不可信，禁止用于排序
        roll = mj.batch_rollout(twin, task_dist, theta)
        r = estimate_cert_radius(roll)           # 分层：透明/高光/弱纹理/遮挡
        E = estimate_energy(S, roll)
        J = mean(r) + lam_e * E + lam_m * mass(S)
        if transfer_bound_ok(S, S0, r, real_audit.delta_s):
            scored.append((J, S, r))
    topk = smallest(scored, k=5)
    # 关键：仿真只排序，最终证书必须由实机审计集确认
    return [S for S in topk if real_audit.confirm(S)]
```

### IP-70 MJ-TWIN：配对回放与残差审计
```
def paired_residual(twin, real, scenarios, q=0.95):
    diffs = []
    for xi in scenarios:
        yr = real.rollout(xi)
        ys = twin.rollout(xi, twin.theta)
        diffs.append(max_metric_gap(yr, ys))     # 位姿/接触冲量/执行延迟
    return quantile(diffs, q)

def audit_twin(twin, real, scenarios, beta=0.05, delta_max=None):
    ds = paired_residual(twin, real, scenarios, 1 - beta)
    if delta_max is not None and ds > delta_max:
        return False, ds       # 标记：仿真仅可用于失败挖掘，不可排序/迁移
    return True, ds
```

### IP-71 STRUCT-CERT：结构条件化证书与漂移守卫
```
def fingerprint(robot):
    return hash((cad_rev(robot), measured_mass_inertia(robot),
                 camera_extrinsics(robot), joint_preload(robot)))

def cert_radius(S, m, omega, H_S, passport, L_S, L_delta):
    if passport.H_S != H_S or now() > passport.expiry:
        return None                                  # 结构失配：无证书
    base = radius_table[H_S][m][omega]
    inflate = L_S * struct_dist(S, passport.S) + L_delta * passport.delta_s
    return base + inflate

def drift_guard(z_t, eps_re):
    d_hat = weighted_norm(z_t)   # 力矩残差/IMU 模态频率/外参/质量
    if d_hat > eps_re:
        revoke_all_structure_certs()
        return 'FAIL_CLOSED', d_hat
    return 'OK', d_hat
```

### 全局集成：CAR 结构条件化守卫
```
def car_guard(cert, S, H_S, passport, z_t, lease_e, t, Delta, E_min):
    ok, d_hat = drift_guard(z_t, eps_re)
    if not ok:
        return 'FAIL_CLOSED'
    if not structure_valid(H_S, passport, d_hat):
        return 'FAIL_CLOSED'
    r = cert_radius(S, cert.m, cert.omega, H_S, passport, L_S, L_delta)
    if r is None or r > cert.r_max:
        return 'FAIL_CLOSED'
    if not energy_lease_valid(lease_e, t + Delta, E_min):
        return 'FAIL_CLOSED'
    if not coverage_check(cert.P_t, r):
        return 'FAIL_CLOSED'
    return 'EXECUTE'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MORPH-OPT | $O(N\cdot C\cdot T)$（离线） | $O(N\cdot d_S)$ | 仅在 $\theta\in\Theta$ 且实机审计通过时签发结构护照 |
| MJ-TWIN 残差 | $O(R\cdot T)$ | $O(R\cdot d_y)$ | 残差覆盖 $\ge1-\beta$ 时才可用于迁移界 |
| 指纹计算 | $O(d)$ | $O(1)$ | 指纹失配 ⇒ 证书立即作废 |
| 半径查询 | $O(1)$ | $O(\|H_S\|\cdot\|m\|\cdot\|\omega\|)$ | 返回半径含迁移膨胀项 |
| 漂移守卫 | $O(d_z)$ | $O(1)$ | $\hat d_S>\varepsilon_{re}$ ⇒ fail-closed |
| CAR 全局守卫 | $O(1)$ | $O(1)$ | 任一前提失败 ⇒ 不执行 |

**命题（结构条件化 soundness，在假设 A1–A4 下）**
A1：结构指纹能检测所有超出 $\varepsilon_S$ 的改动；A2：$L_S,L_\delta$ 由带结构标签的实机审计集保守标定；A3：漂移检测满足 $\Pr(\hat d_S>\varepsilon_{re}\mid d_S>\varepsilon_S)\ge1-\beta$；A4：$\theta_{phys}\in\Theta$。则当 CAR 返回 `EXECUTE` 时，
$\Pr(X_t\in P_t(S)\mid \omega_t,m_t,\ell_s\ \text{valid})\ge1-\alpha_p-\beta$。
若任一前提不成立，CAR 必须返回 `FAIL_CLOSED`。该保证是条件性的，不覆盖 A1–A4 的失配本身；这正是 CCA 红队与现场再认证需要压测的部分。

| E117 仿真-现实残差 | 配对回放 $\delta_s$ 覆盖率；残差偏差 | 覆盖率 $\ge95\%$；偏差 $\le15\%$ |
| E118 协同设计收益 | 期望证书半径；质量/能耗；任务成功率 | 半径降 $\ge15\%$；质量/能耗不升；成功率 $+5\%$ |
| E119 结构漂移红队 | 换支架/关节松动/配重滑移下的 unsafe execute | unsafe execute $=0$；fail-closed 正确率 $100\%$ |
| E120 100h 结构热插拔闭环 | 再认证耗时；停机占比；安全违例 | 再认证 $\le10$min；停机 $\le2\%$；违例 $=0$ |

**预期结果（待实测）**：E115/E117 决定整个方案是否可用；若 E117 的 $\delta_s$ 不收敛，则 Morph-Cert 降级为“固定结构 + 护照审计”，禁止任何仿真驱动的结构迁移。E118 的收益应主要来自相机安装位形与末端惯量优化，而非激进减重。

**回退策略**：E115 召回 $<90\%$ → 增加物理防拆封签并收紧 $\varepsilon_{re}$；E117 残差不可信 → 禁用以 MuJoCo 排序的结构设计，只保留护照与漂移守卫；E119 出现 unsafe execute → 回退固定结构，取消跨结构证书复用。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 仿真过拟合结构，实机证书失效 | 高 | 仿真只排序；实机审计集签证书；$\delta_s$ 超界即拒绝 |
| 结构漂移漏检（关节松动/支架微裂） | 高 | 力矩+IMU 模态+外参+质量多模态指纹；保守阈值；定期物理检查 |
| 迁移界过松导致安全但不可用 | 中 | 收紧 $\varepsilon_S$；分层再认证；小步结构变更 |
| 结构优化减重降刚度引发振动 | 中 | 强度/振动/接触稳定性硬约束；实机模态测试 |
| 指纹依赖 CAD 版本，难以稳定 | 中 | 以实测惯量/外参为主键，CAD 仅作辅助 |
| 结构与感知联合搜索维度过高 | 中 | 分阶段优化（先传感器布局后拓扑）；代理模型 |
| 额外传感/计算开销 | 低 | 低频指纹、事件触发、增量哈希 |

## 6. 本轮最大风险

**一句话**：MuJoCo 与结构优化会诱导“在仿真里把结构改到刚好安全”，一旦仿真接触参数与真实硬件存在系统偏差，或结构指纹漏检未申报改动（关节松动、支架微裂、配重滑移），结构条件化证书会携带错误迁移界继续签发，使安全保证被静默破坏；因此必须坚持“仿真只排序、实机审计签证书、指纹/漂移越界默认 fail-closed”。
