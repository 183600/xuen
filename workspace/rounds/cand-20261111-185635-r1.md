# 第 56 轮（承接第 55 轮 v32 GroundEdge-GenSim++++；新灵感配对「腕部相机」×「运动控制」第 1 轮）

> 第 55 轮把“语义标签”升级为“可执行的接触约束”，用全身生存核与语义护盾兜住不可逆接触。本轮追问这些约束的来源：它们由一只装在手腕上、随手臂一起运动的相机提供。核心矛盾：**H24**：腕部相机的观测算子依赖动作——相机位姿是末端位姿的函数，运动又引入模糊与时延，因此“先感知、后控制”的分离原理失效，感知质量本身成为受控资源；**H25**：“看得清”与“动得稳”天然对冲——看清接触细节要靠近且慢，安全裕度要远离且快，而真正接触的瞬间恰恰最容易被夹爪与工件遮挡。

## 0. 直觉与动机

**灵感 1（腕部相机 → 动作依赖的观测通道，而非固定前置模块）**
直觉：腕部相机不是外部监视器，它长在手上。相机外参随末端位姿变化，画面里的目标、夹爪与遮挡关系都由“当前动作”决定；手臂越快，曝光期内的位移越大，运动模糊越重，图像时延也被放大。于是观测方程必须写成 `y_t = O(x_t,u_t) + η_t(u_t)`，噪声、可见性、模糊都是 `u_t` 的函数。感知不再是控制前的一次查表，而是回路里一个可调、可劣化、必须被预算的资源。这也意味着经典分离原理（先估计状态再按确定性等价控制）在这里不成立：动作同时改变转移与观测，正确的对象是一个 **观测受控的 POMDP**。

**灵感 2（运动控制 → 感知-运动联合生存核）**
直觉：第 55 轮的生存核只问“动作是否动力学可行、接触是否语义可信”，没问“执行这个动作时我还看不看得见”。给生存核再加一个 **可观测裕度** `m_o`：特征点在视场内、离视场边界有余量、交互矩阵可逆性够好、模糊不超过阈值。可行动集因此变成“既站得稳又看得清”的交集；当二者冲突时，控制必须显式选择“先移动到一个能看清的观测站，再执行精细动作”，而不是硬着头皮在盲区里闭环。

**灵感 3（主动观测 → 先看后动与可观测路标图）**
直觉：窄视野是腕部相机的宿命，但窄视野可以用“移动”补偿——把运动规划的一部分预算花在“走到能看见目标的位置”。于是在配置空间上建 **可观测路标图**：节点是能稳定看见目标/接触区的观测站，边是“移动途中仍有足够视觉伺服信息”的可通行段。执行变成 look–move–look；观测站不是路过的副产品，而是路径上的一等公民。

**灵感 4（手眼标定与遮挡 → 误差管 + 最后一眼承诺）**
直觉：腕部相机把“手眼外参误差”直接注射进末端控制误差：标定差 2mm，精细装配就可能差 2mm。接触容差 `τ_c` 是硬约束，所以必须把 `δ_he` 传播成末端误差管并检查 `δ_p ≤ τ_c`；不够就降低速度、软化刚度，或借接触做在线手眼标定。更棘手的是，真正接触时相机常被夹爪和工件挡住——最需要看清的一刻最看不清。因此要在遮挡前存一张 **最后一眼快照**，并保证在遮挡时长 `T_occl` 内仅靠本体感知与力反馈的漂移仍小于容差，否则不许进入接触。

**灵感 5（感知诱导的速度上限 → 视觉伺服稳定裕度）**
直觉：视觉伺服是一个带时延的反馈环。曝光时间 `t_e` 与速度 `v` 给出模糊上界 `||v||·t_e ≤ b_max`；图像处理与通信给出时延 `τ_l`；二者共同压低可用环路带宽，进而决定相位裕度。运动控制不能只按电机能力给速度上限，而要按“相机还跟不跟得上”给 `v_max(τ_l, t_e, φ_m)`。速度也并非越慢越安全：过慢会拉长暴露时间、压低吞吐，正确做法是让速度落在 **模糊-时延-裕度** 的可行窗内。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（腕部观测算子）**
手眼变换 `T_he` 给出相机在末端坐标系的固定安装；末端位姿 `T_we(x)` 由状态决定，故相机位姿 `T_wc(x)=T_wb(x)·T_be(x)·T_he`。观测
`y_t = O(x_t,u_t)+η_t(u_t)`，
其中 `O` 为相机投影/渲染，噪声协方差
`Σ_η(u)=σ_0²I + σ_v²||v_e(u)||² + σ_ω²||ω_e(u)||²`，
`v_e,ω_e` 为末端线/角速度（运动模糊项）。可见性 `vis(x,u)∈{0,1}` 由目标是否落在视场 `FOV(T_wc)` 且未被自遮挡/夹爪遮挡决定。
**注**：由于 `u` 同时进入 `f`（转移）与 `O`（观测），确定性等价不成立；定义 129 的核是观测受控 POMDP 的保守内近似。

**定义 128（可观测裕度）**
对任务相关特征集 `F`（接触点、边缘、孔位），
`m_o(x,u)=min_{f∈F} [ w_v·d_FOV(f) + w_b·(b_max - ||v_e(u)||·t_e) + w_c·σ_min(J_f(x,u)) ]`
（各项归一化后加权；`σ_min(J_f)` 为视觉交互矩阵最小奇异值，`d_FOV` 为特征到视场边界的角度/像素距离）。`m_o ≥ θ_o` 表示“看得清且跟得住”。

**定义 129（感知-运动联合生存核）**
`K_vis(Σ) = { x | ∃ u∈A_WB, λ, (π_o 可选):
  x∈K(Σ) ∧ λ∈FC(μ) ∧ supp(λ)⊆C^+(Σ)
  ∧ ( m_o(x,u) ≥ θ_o ∨ ∃π_o: x --π_o--> x' ∧ m_o(x',u') ≥ θ_o ∧ T_look ≤ T_budget ) }`。
即：要么当前动作就可观测，要么存在一条在 `T_budget` 内到达观测站的主动观测前缀。

**定义 130（手眼误差管与标定条件接触）**
手眼误差 `δ_he`、运动学/编码器误差 `δ_kin`、视觉估计误差 `δ_vis`，末端位置不确定度
`δ_p = ||J_he δ_he|| + ||J_q δ_kin|| + δ_vis`。
接触容差 `τ_c`，**标定条件接触可行** 当且仅当 `δ_p + m_c ≤ τ_c`（`m_c` 为接触控制裕度）。误差管
`Tube(δ_he) = { p | ||p - p̂||₂ ≤ δ_p }`。接触刚度按不确定性自适应：`K_c = K_0·max(0, (τ_c-δ_p)/τ_c)`，越不确定越软。

**定义 131（感知诱导速度上限）**
给定曝光 `t_e`、模糊预算 `b_max`、视觉时延 `τ_l`、期望相位裕度 `φ_m`，允许速度集
`A_vis = { u | ||v_e(u)||·t_e ≤ b_max ∧ f_c(τ_l) ≥ (φ_m/π)·(1/τ_l) }`，
其中可容许闭环带宽按 `f_c ≈ (φ_m/π)/τ_l` 保守估计。运动控制约束取 `u∈A_WB ∩ A_vis`。

**定义 132（遮挡承诺证书）**
在最后一次可靠观测 `t_0` 处保存快照 `ŝ_0` 与信念 `b_0`。遮挡时长 `T_occl` 内仅用本体感知/力反馈传播，漂移
`ε_drift(T)=sup_{t≤T} ||ŝ_t - s_t||`。**承诺可行** 当且仅当 `ε_drift(T_occl)+δ_p ≤ τ_c`。证书
`O_cert=(T_he, δ_he, δ_p, m_o, v_max, t_0, ε_drift(T_occl), evidence)`。
联合证书扩展为 `J_v=(J_s, O_cert, ρ_vis)`，`ρ_vis` 为对模糊/时延/手眼扰动的视觉鲁棒性谱。

## 2. 关键算法 伪代码

### IP-127 EIV（Eye-in-hand Observation Operator）

```python
def eye_in_hand_observation(x, u, T_he, cam, scene):
    T_wc = fk(x) @ T_he
    feats = project(scene, T_wc, cam.intrinsics)
    v_e, w_e = end_effector_twist(x, u)
    sigma_eta = sigma0**2 + sigma_v**2 * v_e.norm()**2 + sigma_w**2 * w_e.norm()**2
    vis = [in_fov(f, cam) and not occluded(f, scene, T_wc) for f in feats]
    return Observation(feats, sigma_eta, vis, T_wc)
```

### IP-128 APS（Active Perception Scheduler / Observability Roadmap）

```python
def observability_margin(x, target, T_he, cam):
    obs = eye_in_hand_observation(x, nominal_u(x), T_he, cam, target.scene)
    return min_feature_margin(obs)                 # d_FOV, blur term, sigma_min(J)

def build_observability_roadmap(target, X_free, T_he, cam, theta_o):
    nodes = [x for x in sample(X_free)
             if observability_margin(x, target, T_he, cam) >= theta_o]
    G = visibility_graph(nodes,
                         edge_ok=lambda a, b: servo_visible(a, b, target))
    return nodes, G

def look_then_move(x, goal, G, T_budget, T_he, cam, theta_o):
    if observability_margin(x, goal, T_he, cam) >= theta_o:
        return plan_direct(x, goal)
    station = argmin(G.nodes, lambda n:
                     cost_to_reach(x, n) + cost_from(n, goal)
                     if cost_to_reach(x, n) <= T_budget else INF)
    if not feasible(station):
        return None, 'no_observable_station'
    return plan_direct(x, station) + plan_direct(station, goal)
```

### IP-129 VSR（Visual-Servo Robustness）

```python
def visual_servo_robustness(x, u_nom, perturbations, sampler, tau_c):
    worst = 1.0
    for d in sampler.ball(perturbations, dims=('blur', 'latency', 'handeye')):
        u_c = visual_servo_controller(x, u_nom, handeye=d)
        err = tracking_error(u_c, x, d)
        ok = (err <= tau_c) and (u_c in A_vis(d))
        worst = min(worst, empirical_success(ok, sampler))
        if worst == 0.0:
            break
    return worst
```

### IP-130 HEC（Hand-Eye Calibration tube & conditioned contact）

```python
def calibration_conditioned_contact(delta_he, delta_kin, delta_vis, tau_c, m_c):
    delta_p = norm(J_he @ delta_he) + norm(J_q @ delta_kin) + delta_vis
    if delta_p + m_c > tau_c:
        return ('reject', 'calibration_tube_exceeds_tolerance', delta_p)
    K_c = K0 * max(0.0, (tau_c - delta_p) / tau_c)
    return ('ok', ErrorTube(delta_p, tau_c - delta_p, stiffness=K_c))

def online_handeye_update(prior, contact_obs):
    # 借“腕部相机+接触力+本体感知”的接触事件修正外参，收缩误差管
    return kalman_update(prior, contact_obs, model='eye_in_hand_contact')
```

### IP-131 LVC（Latency/Blur Velocity Cap）

```python
def perception_velocity_cap(exposure, b_max, latency, phi_m, gain_scale):
    v_blur = b_max / max(exposure, 1e-6)
    f_c = (phi_m / math.pi) / max(latency, 1e-6)
    v_servo = f_c * gain_scale
    return min(v_blur, v_servo)

def motion_qp(u_nom, x, Kernel, C_plus, cap, W):
    return qp_solve(H=W, g=-W @ u_nom, constraints=[
        viability_constraint(x, u, Kernel.K_in),   # x_{t+1} in K_vis
        contact_constraint(u, C_plus),
        velocity_cap_constraint(u, cap),           # ||v_e(u)|| <= cap
        friction_cone_constraint(u, mu),
        joint_limit_constraint(u),
    ])
```

### IP-132 OCC（Occlusion Commit Certificate）

```python
def occlusion_commit(x, t0, tau_c, T_occl, delta_p, model):
    snap = last_reliable_observation(x, t0)
    drift = proprioceptive_drift_bound(T_occl, snap, model)
    if drift + delta_p > tau_c:
        return ('abort', 'no_commit_without_visibility', drift)
    return ('ok', OcclusionCert(snap, t0, drift, T_occl))

def joint_visual_certificate(J_s, O_cert, rho_vis, budgets):
    if O_cert.delta_p + budgets.m_c > budgets.tau_c:
        return ('reject', 'calibration_tube')
    if O_cert.m_o < budgets.theta_o:
        return ('reject', 'observability')
    if O_cert.eps_drift + O_cert.delta_p > budgets.tau_c:
        return ('reject', 'occlusion_drift')
    if rho_vis < budgets.rho_vis_min:
        return ('reject', 'visual_robustness')
    return ('ok', VisualJointCert(J_s, O_cert, rho_vis))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| EIV | O(\|F\|·proj + render) | O(\|F\|) | 手眼外参标定、遮挡模型准确 |
| APS | O(\|X\|·\|F\| + \|V\|log\|V\| + \|E\|) | O(\|V\|+\|E\|) | 观测站完备、边可通行 sound |
| VSR | O(N_adv·T·QP) | O(\|X\|) | 扰动球覆盖模糊/时延/手眼 |
| HEC | O(\|contact\|·k) | O(k) | δ_p 上界 sound、在线更新收敛 |
| LVC | O(1) + O(QP) | O(\|A\|) | 模糊/时延模型保守、速度窗非空 |
| OCC | O(T_occl·integration) | O(1) | 漂移上界 sound、快照可信 |

**正确性定理（Perception–Motion Co-Design Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** `||δ_he|| ≤ ε_he` 且 `δ_p` 为末端误差的 sound 上界；**(A34)** 真实曝光/时延落在 `(t_e, b_max, τ_l)` 预算内；**(A35)** 执行精细接触动作时要么 `m_o ≥ θ_o`，要么存在合法的观测前缀 `π_o`；**(A36)** 遮挡漂移 `ε_drift(T_occl) ≤ ε_occ`。
则单步“安全且可观测”概率：
```
P_safe&obs ≥ 1 - [语义/全身项: P(||Σ-Σ̂||>ε_s)+P(κ miscal.)+P(K_out\K_in≠∅)+P(fallback fails)]
              - P(δ_p > τ_c - m_c) - P(m_o < θ_o) - P(ε_drift > ε_occ) - P(v > v_max(τ_l,t_e,φ_m))
```
关键：**感知质量被预算而非被假设**，控制器要么看得够清，要么显式去“看一眼”，绝不把“上一帧看起来没问题”当作“接触时一定看得见”。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 手眼标定温漂/碰撞后失准 | 高 | 在线接触标定 + 误差管自适应 + 超管即降速/软化 |
| 模糊/时延模型失配 | 高 | 数据驱动标定 + 保守速度窗 + 退化为停看再动 |
| 观测站不可达或被动障碍遮挡 | 中 | 多站备份 + 视野膨胀 + 云端重规划 |
| 过度保守限速导致吞吐塌陷 | 中 | 只在精细接触段限速 + 任务分层 + 自适应恢复 |
| 遮挡期本体/力积分漂移超界 | 高 | 最后一眼快照 + 力反馈锚定 + 超界中止 |

## 6. 本轮最大风险

**一句话**：腕部相机把“感知”变成“动作的函数”，使感知-运动联合证书在原理上更诚实，但其 soundness **三重依赖手眼误差管的紧致性、模糊/时延模型的保守性、以及遮挡期漂移上界的可靠性**；一旦标定温漂被低估、或真实时延在高速段突破预算，控制器会在“自认为看得清”的盲区里以过快的速度闭环并进入接触，把视觉伺服的发散直接变成不可逆的碰撞——因此必须以 **在线手眼标定收缩误差管 + 模糊/时延的保守速度窗 + 遮挡前最后一眼承诺** 三重护栏，宁可停下来多看一眼，绝不把上一帧的清晰当作接触时刻的可见。

# 第 56 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（SCG×WBV×SSF×SCC×SRS×CEB + EIV×APS×VSR×HEC×LVC×OCC）

- **定义 121（语义-接触图）**：`C(Σ)={(p,c) | κ(Σ̄(p),c)≥θ_κ ∧ conf(Σ(p))≥θ_conf}`。
- **定义 122（全身语义-接触生存核）**：`K(Σ)={x | ∃u∈A_WB,λ: f(x,u,λ)=ẋ ∧ supp(λ)⊆C(Σ) ∧ x_{t+1}∈𝒳_safe}`。
- **定义 123（语义边界裕度）**：`m_s(p)=dist(p,∂Ω_{Σ̄(p)})`，`C^+(Σ)={ (p,c)∈C(Σ) | m_s(p)≥θ_m(κ,c) }`。
- **定义 124（全身语义护盾）**：`u*=argmin_u ||u-u_nom||²_W s.t. x_{t+1}∈K(Σ), supp(λ)⊆C^+(Σ), λ∈FC(μ), u∈A_WB`；不可行则 `u_stop∈𝒳_safe`。
- **定义 125（语义鲁棒性谱）**：`ρ_sem(ε)=inf_{||Σ-Σ̂||_∞≤ε_s} P(viable(x,Σ)|Σ̂)`。
- **定义 126（语义-接触联合证书）**：`J_s=(Σ_core,C_core,K_margin,ρ_sem,δ_s,evidence)`，四项预算全过才可部署。
- **定义 127（腕部观测算子）**：`T_wc(x)=T_wb(x)·T_be(x)·T_he`，`y=O(x,u)+η(u)`，`Σ_η(u)=σ_0²I+σ_v²||v_e||²+σ_ω²||ω_e||²`；因 `u` 同入转移与观测，确定性等价失效。
- **定义 128（可观测裕度）**：`m_o(x,u)=min_f [w_v·d_FOV(f)+w_b·(b_max-||v_e(u)||t_e)+w_c·σ_min(J_f)]`。
- **定义 129（感知-运动联合生存核）**：`x∈K_vis(Σ)` ⇔ 存在可行 `(u,λ)` 满足全身/接触约束，且 `m_o≥θ_o` 或存在 `T_budget` 内到达观测站的观测前缀 `π_o`。
- **定义 130（手眼误差管）**：`δ_p=||J_heδ_he||+||J_qδ_kin||+δ_vis`，接触可行 ⇔ `δ_p+m_c≤τ_c`；`K_c=K_0·max(0,(τ_c-δ_p)/τ_c)`。
- **定义 131（感知诱导速度上限）**：`A_vis={u | ||v_e(u)||t_e≤b_max ∧ f_c(τ_l)≥(φ_m/π)/τ_l}`。
- **定义 132（遮挡承诺证书）**：`O_cert=(T_he,δ_he,δ_p,m_o,v_max,t_0,ε_drift,evidence)`，承诺可行 ⇔ `ε_drift(T_occl)+δ_p≤τ_c`。

```python
def semantic_contact_map(rgbd, seg_model, kappa, theta_k, theta_conf):
    Sigma = seg_model.predict_soft(rgbd)
    C = set()
    for p in grid(rgbd):
        l = argmax(Sigma[p])
        if confidence(Sigma[p]) < theta_conf:
            continue
        for c in CONTACT_TYPES:
            if kappa[l][c] >= theta_k:
                C.add((p, c))
    return Sigma, C, boundary_margin(Sigma)

def conservative_contacts(C, M, kappa, theta_m):
    return {(p, c) for (p, c) in C if M[p] >= theta_m(kappa[argmax_at(p)][c])}
```

```python
def viability_kernel(Sigma, C_plus, x0, horizon, eps):
```

### IP-124 SCC

```python
def semantic_contact_certificate(traj, Sigma, kappa, rho_sem, budgets):
    Sigma_core = core_semantics(traj, Sigma)
    C_core = contacts_used(traj) & conservative_contacts(Sigma_core, M, kappa, theta_m)
    if not C_core:
        return ('reject', 'no_core_contact')
    K_margin = min(distance_to_boundary_K(x, Sigma) for x in traj)
    delta_s = semantic_perturbation(Sigma_core, calibrated_eps)
    if K_margin < budgets.theta_K or delta_s > budgets.Theta_s:
        return ('reject', 'semantic_budget_exceeded', K_margin, delta_s)
    if rho_sem(delta_s) < budgets.rho_min:
        return ('reject', 'semantic_robustness_fail')
    return ('ok', SemanticCert(Sigma_core, C_core, K_margin, rho_sem, delta_s))
```

```python
def visual_servo_robustness(x, u_nom, perturbations, sampler, tau_c):
```

**正确性定理（Whole-Body Semantic-Contact-Visual Soundness）**
假设 (A26)–(A28)（动作/云边）与 (A29)–(A32)（语义/全身）成立；**(A33)** `||δ_he||≤ε_he` 且 `δ_p` sound；**(A34)** 真实曝光/时延落在 `(t_e,b_max,τ_l)` 内；**(A35)** 精细接触动作满足 `m_o≥θ_o` 或存在观测前缀；**(A36)** `ε_drift(T_occl)≤ε_occ`。则
```
P_safe&obs ≥ 1 - Σ_d(1-ρ_min(d)) - P(compat<θ_a)
              - P(||Σ-Σ̂||>ε_s) - P(K_out\K_in≠∅)
              - P(δ_p>τ_c-m_c) - P(m_o<θ_o) - P(ε_drift>ε_occ) - P(v>v_max)
```
关键：**语义可信、全身可行、观测可得** 三层同时成立才放行；任何一层未被预算，都退化为“停看再动”。

## 6. 本轮最大风险

**一句话**：把语义-接触与腕部视觉并入同一证书，使“可信接触、全身可行、观测可得”首次被显式联合门控，但其 soundness **三重依赖手眼误差管的紧致性、模糊/时延模型的保守性、以及遮挡漂移上界的可靠性**；一旦标定温漂被低估或高速段真实时延突破预算，控制器会在自认为看得清的盲区里以过快速度闭环并进入接触，把视觉伺服发散直接变成不可逆碰撞——因此必须以 **在线手眼标定收缩误差管 + 模糊/时延保守速度窗 + 遮挡前最后一眼承诺** 三重护栏，宁可停下来多看一眼，绝不把上一帧的清晰当作接触时刻的可见。
