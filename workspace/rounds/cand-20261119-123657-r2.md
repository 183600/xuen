# 第 15 轮（灵感循环第 2 轮；本轮灵感：「动力学」×「材料选型」）

> **基线**：第 14 轮 MetricVoiceGauge-NCD-HUTDH-v15（技能扩散：SCD/DSD/DCA/EDC；定义 607–626；引理 125–130；实验 E661–E670）。
> 本轮纪律：**结构化动力学证书 + 材料条件化证书库 + 切换能量不增**。不推倒 v15：v15 的技能扩散、v14 的 SCD/DSD/DCA/EDC 继承链，以及 v13 的 AIO/CPD/DDL/RTCR、v12 的 USG/TGC/BAA/GAGP/UC、v11 的 HAS/HCC/HATD/HDT 全部保留。三个新组件——DCE（动力学认证包络，含 PEC）、MCCL（材料条件化证书库，含 MDCC）、MCP（模式提交协议，含 DESC）——一律以**中立元**接入，失效即严格退回 v15，再沿 v15→v14→…→v6 退化链回退。本轮只做三件事：把"动力学"从学习残差改写为**参数集上的可证可达包络**、把"材料"从固定假设改写为**带条件证书的离散模式**、把二者合成一条"换材料即换证书、且切换瞬态只弱不强"的共设计。

## 0. 直觉与动机

**灵感 1（动力学 → 结构化动力学证书与可达包络）**
直觉：v15 的动力学是"隐式"的——HDT 用谐波项拟合、BAA 用残差网络补偿，证书却只加在动作层。问题是：学习残差在训练分布内很准，一旦进入新颖接触（薄壁、斜面、可变形物），它既没有包络、也没有外推保证。而物理给了免费的硬结构——能量守恒、无源性、单边接触互补、摩擦锥约束——这些在分布外仍然成立。核心创新：**动力学认证包络（Dynamics-Certified Envelope, DCE）+ 无源能量证书（Passivity-Energy Certificate, PEC）**。DCE 把真实参数限制在一个可识别区间/多面体 `Θ` 内，用区间/zonotope 前向传播可达集，并把积分余项、接触冲击映射、扰动界全部显式并入，输出一个**必然包含真实可达集**的包络 `R_k`；PEC 用能量罐保证任何一步都不净注入超过执行器预算的能量，从而给冲击速度一个硬上界。关键反直觉点：**学习残差只能"在包络内收紧"，不能"替代包络"**——先有 `R_k ⊇ TrueReach_k` 的 soundness，再让残差减少保守性；顺序反了，快但不安全。

**灵感 2（材料选型 → 材料条件化证书库与材料—动力学兼容证书）**
直觉：v15 默认只有一个固定末端接触材料，但真实系统会按任务"选材"：刚性指尖用于精确插入、软硅胶用于抓取易碎物、低摩擦垫用于滑动对齐。材料直接决定刚度 `κ`、摩擦系数 `μ_f`、恢复系数 `e`，因而决定接触动力学与安全边界。把材料当成"换零件"是错的，它是一次**离散动力学模式切换**。核心创新：**材料条件化证书库（Material-Conditioned Certificate Library, MCCL）+ 材料—动力学兼容证书（Material-Dynamics Compatibility Certificate, MDCC）**。每种材料 `m` 在离线阶段获得自己的证书 `C_m=(Acc_m,R_m,E_m,q_m)`；在线选材只能从**已预认证材料集**中挑，且必须满足 MDCC：目标技能所需授权 `A_req ⊆ Acc_m`、规划状态落在 `R_m` 内、且过渡窗口内各模式证书的交集仍覆盖 `A_req`。于是选材**只弱不强**：它不能凭空新增授权，只能选一个"恰好覆盖当前任务且已被认证"的材料。

**灵感 3（动力学×材料选型 → 模式提交、驻留时间与能量预算的切换证书）**
直觉：既然换材料=换动力学模式，那么"中途换材料"就是切换系统问题。冲击/回弹可能在切换瞬间注入能量，朴素的"哪个材料指标好就换哪个"会造成抖振、极限环甚至失稳。经典结论在这里恰好可用：多 Lyapunov 函数 + 驻留时间 + 能量罐能保证切换瞬态有界。核心创新：**模式提交协议（Mode-Commit Protocol, MCP）+ 驻留—能量切换证书（Dwell-Energy Switched Certificate, DESC）**。MCP 把选材改写为一个受约束的提交动作：先在候选材料上做 MDCC 过滤，再要求 DESC 通过（驻留时间够、能量罐非负、冲击恢复系数在界内），全部通过才允许切换；否则退到默认材料并停机/柔顺。这把"动力学"和"材料选型"合成同一个对象：**一个以（材料, 动力学模式）为索引、只在切换不增能量时允许迁移的证书图**。

**三者如何统一**
统一为 **v15 技能层之下的物理可行性层**：v15 回答"这一帧组哪个技能、扩散几步"（`Exec_v15`），v16 回答"该技能用哪种材料、在哪个动力学模式下物理可证"（`Exec_v16`）。DCE 给状态可达包络，PEC 给能量/冲击界，MCCL 给每材料证书，MDCC 给材料—技能匹配，MCP/DESC 给切换许可。共享状态 `ζ_phys=(m, θ̂, Θ, R_k, E_tank, τ_dwell, C_{m}, MDCC, mode)`。**DCE 回答"真实状态可能在哪"，MCCL/MDCC 回答"这个材料下哪些动作被预认证"，MCP/DESC 回答"现在能不能换过去"**。三者不是三个补丁，而是"动力学—材料—切换"的共设计链。

## 1. 研究问题（轮次升级版）

- **Q1（动力学的可证soundness）**：在参数不确定性 `θ∈Θ`、接触冲击、积分余项与有界扰动同时存在时，如何构造 `R_k` 使 `TrueReach_k ⊆ R_k` 严格成立？学习残差以何种方式注入才只收紧包络、不破坏包含性？包络在长时间开环传播后的膨胀如何靠闭环/重识别抑制？
- **Q2（材料条件证书的可组合性）**：给定材料族 `{m}`，如何离线生成可比较的 `C_m` 并使 `Acc_m` 的语义一致（同一动作在不同材料下意义不同）？MDCC 需要哪些条件才能在过渡窗口内保持"交集覆盖"？材料参数老化/磨损后 `Θ_m` 失效如何被在线检测？
- **Q3（切换安全与最优性）**：中途换材料的驻留时间与能量预算如何从多 Lyapunov/能量罐共同推出？"停留旧材料多跑几步"与"换新材料减少假拒绝"之间的最优切换点由什么决定？冲击恢复系数不确定时如何保证切换不增能量？
- **Q4（与 v15 的兼容与活性）**：v16 会不会因包络过保守而把 v15 的可行动作全部过滤掉、导致频繁 `a_ask`？MCCL 的缺失材料是否会让任务无法完成？新模块能否守住 50Hz/p99≤22ms，并在任一失效时严格退回 v15？

## 2. 设计原则（在 P22–P24 基础上新增 P25–P27）

**P25 动力学硬约束律（Dynamics as Hard Constraint）**
任何被执行的动作必须由 DCE 包络认证：`x_k ∈ R_k`，且 `R_k ⊇ TrueReach_k` 在 `θ∈Θ`、扰动界与接触模型内严格成立。学习残差只允许**在包络内部**收紧候选、减少保守性，**不得替代或放宽** `R_k`。包络的 soundness 优先于包络的紧致性；二者冲突时一律取更保守者。

**P26 材料条件化证书律（Material-Conditioned Certificate）**
所有证书以材料 `m` 为索引，`C_m=(Acc_m,R_m,E_m,q_m)`。在线选材只能从**已预认证材料集** `M_cert` 中选取，且必须满足 MDCC：`A_req⊆Acc_m`、规划状态 `⊆R_m`、过渡窗口内 `⋂_{m'∈active}Acc_{m'}⊇A_req`。未经 MDCC 的材料禁止执行；材料选择本身**不能新增任何授权**。

**P27 切换能量不增律（Switching Non-Increase）**
离散材料/模式切换必须同时满足驻留时间与能量罐非负：`τ_dwell ≥ ln μ / λ` 且 `E_tank^{k+1} ≥ 0`，冲击能量损失由恢复系数界 `e∈[e_min,e_max]` 保守估计。任一条件不满足时，只能**安全塌缩**到默认材料并停机/柔顺，禁止"赌一把"直接切换。

## 3. 与基线的接口（如何退化）

- DCE 失效 ⇒ 关闭区间传播，只用 v15 的学习残差加固定保守裕度，`R_k` 退化为 v15 的名义轨迹球邻域，**等价 v15 计算路径**；
- PEC 失效 ⇒ 关闭能量罐，仅保留 v15 的速度/力限幅，**等价 v15（+DCE）证书路径**；
- MCCL 失效 ⇒ 单一默认材料（v15 隐含材料），无材料切换，**等价"v15 证书 + 固定材料"**；
- MDCC 失效 ⇒ 选材锁定默认材料，DCE/PEC 仍对默认材料有效，**等价单材料安全路径**；
- MCP/DESC 失效 ⇒ 禁止中途切换，只能在静止/断电时换材，**等价静态材料 + v15**；
- 全部失效 ⇒ MetricVoiceGauge-NCD-HUTDH v15，再沿 v15→v14→v13→…→v6 退化链回退；
- **安全继承**：DCE 只收缩状态集、PEC 只约束能量、MCCL 只提供预认证材料、MDCC 只做匹配、MCP/DESC 只做切换许可。五端口均不能新增授权或放宽任何阈值；`Exec_v16⊆Exec_v15` 由引理 134 保证。

## 4. 预期贡献

1. **结构化动力学证书**：把动力学从"学得准"改写为"在参数集上可证包含"，使证书在训练分布外仍 sound，解决学习残差无外推保证的结构性缺陷；
2. **材料条件化证书与材料—动力学兼容**：把末端材料从固定假设改写为带独立证书的离散模式，给出选材的单侧包含条件 `Exec_v16⊆Exec_v15`；
3. **驻留—能量切换证书**：把中途换材料建模为切换系统，用多 Lyapunov 驻留时间与能量罐给出切换瞬态有界性，而不是用启发式阈值；
4. **物理层—技能层分离**：v15 管"组什么技能"，v16 管"用什么材料、动力学上可证到什么程度"；E671–E688 覆盖包络 soundness、无源性、材料兼容、切换驻留、老化失效与端到端消融。

## 5. 本轮最大风险

**一句话**：MCCL 的每张材料证书都基于"新材料的标称参数"离线认证，而磨损、热软化、润滑迁移会把真实材料缓慢推出 `Θ_m`；此时 DCE 关于 `Θ_m` 仍然 sound、MDCC 仍然匹配、切换仍然不增能量，系统却在"每步都含于包络、每种材料都预认证、每次切换都不增能量"的表象下，用一个**已经不存在的材料**做出了绝对错误的安全决定——即**按证书的、按材料的、却物理上早已失效的安全决定**。

```python
class DynamicsCertifiedEnvelope:
    def __init__(self, theta_box, W, rho_int, contact, dt):
        self.Theta = theta_box          # 参数区间/多面体
        self.W = W                      # 扰动集
        self.rho_int = rho_int          # 积分余项上界
        self.contact = contact          # 接触模型（含冲击映射 I_m）
        self.dt = dt

    def initial_envelope(self, x0, Sigma0):
        return Box(center=x0, half=Sigma0)

    def propagate(self, R_k, u_k, m):
        # 1) 在 Θ 上对 f 做区间/zonotope 外扩
        R_next = interval_step(R_k, u_k, self.Theta, self.dt)
        # 2) 并入扰动与积分余项
        R_next = R_next.minkowski_sum(self.W).inflate(self.rho_int)
        # 3) 若出现接触，叠加冲击映射的保守像
        if self.contact.touches(R_k, m):
            R_next = self.contact.impact_overapprox(R_next, m, self.Theta)
        return R_next

    def contains(self, R_k, x):
        return R_k.contains(x)

    def sound_margin(self, R_k, x):
        # 到包络边界的最小距离（用于是否可继续执行的判据）
        return R_k.distance_to_boundary(x)


class PassivityEnergyCertificate:
    def __init__(self, E_budget, e_min, e_max, m_eff, dissipation):
        self.E_budget = E_budget
        self.e_min, self.e_max = e_min, e_max
        self.m_eff = m_eff
        self.dissipation = dissipation

    def impact_loss(self, v_minus, m):
        # 最坏情形取恢复系数上界（能量损失最小）
        e_hi = self.e_max[m] if isinstance(self.e_max, dict) else self.e_max
        return 0.5 * (1 - e_hi ** 2) * self.m_eff * v_minus ** 2

    def step(self, E_tank, u_energy, v_minus, m):
        E_inject = min(u_energy, self.E_budget)
        E_next = E_tank + E_inject - self.impact_loss(v_minus, m) \
                 - self.dissipation(E_tank)
        return E_next

    def admissible(self, E_next):
        return E_next >= 0.0


class MaterialConditionedCertificateLibrary:
    def __init__(self, materials):
        self.materials = materials       # {m: C_m}
        self.default = materials["default_soft"]

    def certificate(self, m):
        return self.materials[m]

    def selectable(self, A_req, R_plan):
        out = []
        for m, C in self.materials.items():
            if A_req.issubset(C.Acc_m) and R_plan.issubset(C.R_m):
                out.append(m)
        return out


class MaterialDynamicsCompatibility:
    def compatible(self, m_prev, m_next, R_next, A_req, active_materials):
        C = self.mcl.certificate(m_next)
        if not A_req.issubset(C.Acc_m):
            return False
        if not R_next.issubset(C.R_m):
            return False
        # 过渡窗口内：所有活跃模式证书的交集仍须覆盖 A_req
        inter = None
        for mm in active_materials | {m_next}:
            acc = self.mcl.certificate(mm).Acc_m
            inter = acc if inter is None else inter.intersect(acc)
        return inter is not None and A_req.issubset(inter)


class DwellEnergySwitchedCertificate:
    def __init__(self, mu, lam):
        self.mu = mu
        self.lam = lam
        self.tau_min = math.ceil(math.log(self.mu) / self.lam)

    def check(self, V_prev, V_next, dwell_elapsed, E_tank):
        # 多 Lyapunov：切换跳升受 μ 界，段内按 λ 衰减
        if V_next > self.mu * V_prev:
            return False
        if dwell_elapsed < self.tau_min:
            return False
        return E_tank >= 0.0


class ModeCommitProtocol:
    def __init__(self, mcl, mdcc, desc, dce, pec):
        self.mcl, self.mdcc, self.desc = mcl, mdcc, desc
        self.dce, self.pec = dce, pec

    def commit(self, m_prev, candidates, R_next, A_req, active, dwell, E_tank):
        for m_next in candidates:
            if m_next == m_prev:
                return m_next, False
            if not self.mdcc.compatible(m_prev, m_next, R_next, A_req, active):
                continue
            if not self.desc.check(0.0, 0.0, dwell, E_tank):
                continue
            return m_next, False
        return self.mcl.default, True   # 无可提交：默认软材料 + 塌缩


def metricvoicegauge_round_16_dynamics_material(M, s, obs, ctx):
    # ---- v15 主路径原样保留（SCD/DSD/DCA/EDC + v14 继承路径）----
    results = M.v15.run_cycle(runners={...}, ctx=ctx)

    # ---- 动力学参数集与包络 ----
    theta_box = hcc.dynamics_parameter_box()       # 由辨识给出 Θ
    dce = DynamicsCertifiedEnvelope(theta_box, ctx.W, ctx.rho_int,
                                    contact=ctx.contact_model, dt=ctx.dt)
    pec = PassivityEnergyCertificate(ctx.E_budget, ctx.e_min, ctx.e_max,
                                     ctx.m_eff, ctx.dissipation)
    R = dce.initial_envelope(obs.x, obs.Sigma)

    mcl = MaterialConditionedCertificateLibrary(ctx.materials)
    mdcc = MaterialDynamicsCompatibility(mcl)
    desc = DwellEnergySwitchedCertificate(ctx.mu, ctx.lam)
    mcp = ModeCommitProtocol(mcl, mdcc, desc, dce, pec)

    m_cur = ctx.material
    E_tank = ctx.E_tank
    dwell = 0

    # ---- 逐技能组合执行 ----
    for step in range(k_star):
        a_hat, prob_lower, q_lower, fallback = scd.cds_step(
            x=obs, budget_remaining=dsg.remaining, i_current=step)
        A_req = ctx.skill_pool.authorization_of(a_hat)

        # 材料候选：只从预认证集中挑，且满足 MDCC
        cand = mcl.selectable(A_req, R)
        m_next, collapsed = mcp.commit(m_cur, cand, R, A_req,
                                       ctx.active_materials, dwell, E_tank)
        if collapsed:
            execute(mcl.default.fallback(obs))     # 认证回退
            break

        # 切换时更新能量罐与驻留计数
        if m_next != m_cur:
            E_tank = pec.step(E_tank, ctx.u_energy, ctx.v_minus[m_cur], m_next)
            m_cur, dwell = m_next, 0
        else:
            dwell += 1

        # DCE 传播 + 能量可行性 + 包络包含检查
        R = dce.propagate(R, ctx.u, m_cur)
        E_tank = pec.step(E_tank, ctx.u_energy, ctx.v_minus[m_cur], m_cur)
        if not pec.admissible(E_tank) or not dce.contains(R, obs.x):
            execute(mcl.default.fallback(obs))
            break

        # 参数集失配：材料老化/磨损退出 Θ
        if hcc.dynamics_parameter_box_drift() > ctx.eps_Theta:
            ctx.trigger_recalibration(m_cur)
            execute(mcl.default.fallback(obs))
            break

        execute(a_hat, material=m_cur)

    ctx.E_tank = E_tank
    ctx.material = m_cur

    # ---- v15/v14 继承输出 ----
    return M.inherited_v15_path(ctx)
```

## 3. 推导

**引理 131（DCE 的包含性/soundness）** 设真实动力学 `x_{k+1}=f(x_k,u_k;θ)+w_k`，`θ∈Θ`、`w_k∈W`、积分余项 `‖r_int‖≤ρ_int`，接触冲击由 `I_m` 给出。若 `x_k∈R_k` 且 `R_{k+1}=f(R_k,u_k,Θ)⊕W⊕B(ρ_int)`（接触时再叠加 `I_m` 的保守像），则 `x_{k+1}∈R_{k+1}`。证明：对 `f` 在 `Θ` 上取区间外扩覆盖所有 `f(x_k,u_k;θ)`；Minkowski 和覆盖扰动与积分余项；冲击映射的区间像覆盖 `e_m∈[e_min,e_max]` 的全部落点。三者取并仍包含真实值。对 k 归纳即得。∎ 推论：**包络的 soundness 只依赖 `Θ`、`W`、`ρ_int` 与 `I_m` 的界，不依赖学习残差**；残差只能用于在 `R_k` 内收紧候选。

**引理 132（PEC 的能量与冲击速度上界）** 若 `E_tank^k≥0` 且每步注入 `≤E_budget`，冲击损失按 `e_hi=max e_m` 保守估计，则任意时刻 `E_tank^k≥0`，且冲击前速度满足 `|v^-|≤√(2E_budget/(m_eff(1-e_hi^2)))`。证明：能量罐递推 `E^{k+1}=E^k+E_inject-ΔE_impact-ΔE_diss`；因 `E_inject≤E_budget`、损失项非负且按最小损失（`e_hi`）估计，故 `E^{k+1}` 的下界由 `E_budget-ΔE_impact` 给出；令其为 0 反解 `|v^-|` 即得上界。∎ 推论：**能量罐把"冲击多猛"变成可预算量**；材料越软（`e` 小）冲击损失越大、可容许冲击速度越高。

**引理 133（驻留—能量切换的瞬态有界性）** 设切换系统在模式 `m` 上 `V_m` 以速率 `λ` 衰减、切换时 `V_{m'}≤μV_m`，且 DESC 保证 `τ_dwell≥⌈ln μ/λ⌉`、`E_tank≥0`。则任意有限切换序列下 `V` 有界，且切换瞬态内 `A_req⊆⋂_{active}Acc_m`。证明：标准多 Lyapunov 论证——两次切换之间 `V` 至少衰减 `e^{-λτ_dwell}≤1/μ`，切换跳升至多 `μ`，故切换前后 `V` 不增；能量罐非负保证冲击不注入净能量。交集覆盖由 MDCC 的过渡窗口条件直接给出。∎ 推论：**驻留时间是"换材料的最小冷静期"**；频繁换材被 `τ_dwell` 结构性禁止。

**引理 134（材料选型的单侧性）** 若在线选材只从 `M_cert` 中取且必须通过 MDCC，则对任意 `m`，`Exec_v16(m)⊆Exec_v15`；且切换窗口内 `Exec_v16⊆⋂_{active}Acc_m⊆Acc_{m_prev}⊆Exec_v15`。证明：`A_req⊆Acc_m` 且 `Acc_m⊆Acc_{m_prev}`（材料证书是 v15 授权在材料条件化后的子集），MDCC 的交集条件进一步收缩；执行前还有 DCE 包含与 PEC 可行两道门。故不新增授权。∎ 推论：**换材料只能是"换一个更贴合的已认证子集"，不是"换一个更宽的授权"**。

**引理 135（软材料的力—不确定度权衡下界）** 设材料刚度 `κ`，接触时长为 `t_c≈π√(m_eff/κ)`，峰值力 `F_peak≈|v^-|√(m_eff κ)`，而接触参数阻尼/刚度不确定性使位置证书半宽 `σ_x` 满足 `σ_x ≥ c·√(m_eff/κ)·δ_κ`（`δ_κ` 为刚度相对误差）。则对任意选材，
```
F_peak · σ_x ≥ c' · |v^-| · m_eff · δ_κ ,
```
即不能同时把峰值力与位置不确定度任意减小。证明：将 `F_peak` 与 `σ_x` 的表达式相乘，`κ` 与 `1/√κ` 部分抵消，得到与 `κ` 无关的下界。∎ 推论：**"更软"降低冲击力却抬高位置证书半宽，故 MDCC 必须按任务（力敏感 vs 位置敏感）选材，而非全局最优材料**。

**引理 136（残差—包络的合成）** 设学习残差 `ĝ` 的误差界 `‖g-ĝ‖≤δ_g`，且仅在 `R_k` 内使用。则以 `R_k∩{x:‖g(x)-ĝ(x)‖≤δ_g}` 作候选集不破坏 soundness，且保守性单调不增。证明：交集只可能收缩候选集，`R_k` 仍包含真实状态；`δ_g` 的界由共形/区间校准给出，故收缩后的候选仍位于真实可达集的外扩内。∎ 推论：**残差是"包络内的精修刀"，不是"包络外的通行证"**。

**引理 137（切换瞬态的活动性损失界）** 切换协议下无可执行认证动作的概率满足
```
P(no_exec) ≤ P(θ̂∉Θ) + P(τ_dwell 未满) + P(E_tank 耗尽) + P(MDCC 失配) .
```
证明：执行需同时通过参数集、驻留、能量、材料兼容四道门，任一失败即回退；由并集界即得。∎ 推论：**活动性损失可分解到四个可测量来源**，从而可逐项优化而非整系统调参。

**引理 138（材料老化的证书失效下界）** 设材料参数随磨损/温度漂移速率至多 `γ`（每千次接触的 `Θ` 偏移），则经过 `N` 次接触后，若校准周期 `T_cal` 满足 `γ·N > diam(Θ_m)`，`θ̂` 将以不可忽略概率越出 `Θ_m`，此时仅靠 DCE 无法恢复 soundness。证明：`N` 次接触后参数偏移上界 `γN`；当超过 `Θ_m` 的直径时，真实参数可能在 `Θ_m` 外，而 DCE 只对 `Θ_m` 内参数 sound。∎ 推论：**必须把"材料老化"纳入 `Θ_m` 的时变扩张或缩短重校准周期**，否则 v16 的"按材料证书"会在长时运行中静默失效。

## 7. 已知风险与失效模式

1. **参数集 Θ 欠覆盖**：辨识只给出点估计或过窄区间，真实参数在 Θ 外，DCE 的 soundness 名义成立、实际失效。缓解：区间辨识、残差外扩、在线集员更新、`ε_Θ` 强制塌缩。
2. **包络膨胀导致活性塌缩**：长时间开环传播使 `R_k` 迅速膨胀，v15 的可行动作被全部过滤。缓解：闭环重识别、temporal 收缩、event-triggered 重规划、包络紧致性判据。
3. **接触模型与冲击映射失配**：单边接触、粘滑、碰撞时序未建模，`I_m` 的区间像偏窄。缓解：多模型/混合接触自动机、保守 `e` 区间、冲击速度限幅、硬件在环验证。
4. **材料证书语义不一致**：同一动作在不同材料下物理意义不同，`Acc_m` 直接比较会出错。缓解：统一动作坐标系与标定协议、按材料重定义动作语义、形式化 `Exec` 包含检查。
5. **老化/磨损/热软化**：真实材料缓慢退出 `Θ_m`，证书静默失效（见引理 138）。缓解：时变 `Θ_m`、加速老化建模、缩短重校准、磨损传感器。
6. **DESC 的 μ/λ 估计保守性**：多 Lyapunov 界过保守导致驻留时间过长、切换几乎不可用。缓解：数据驱动但 sound 的界、分段二次 Lyapunov、能量罐替代、允许静止换材。
7. **能量罐耗尽**：连续冲击使 `E_tank` 归零，系统频繁停机。缓解：能量预算按任务分配、软材料优先、冲击前减速、可充电式恢复策略。
8. **默认材料回退过频**：MDCC 失配或候选为空时频繁退默认，任务完成率下降。缓解：扩充预认证材料库、按任务预选材料、放宽非安全项而非授权项。
9. **材料切换抖振**：两个材料指标接近时反复切换。缓解：驻留时间硬约束、滞回带、切换代价计入预算、禁止同帧回切。
10. **MCCL 规模与实时性**：材料证书库过大使查询/校验超时。缓解：分层索引、预计算交集、异步离线更新、限 `M_cert` 规模。
11. **v15 与 v16 双重保守叠加**：SCD 的证书交集与 DCE 的包络同时收缩，可行集被清空。缓解：联合校准、任一模块失效走对应退化路径、活动性损失分解（引理 137）。
12. **soundness 与紧致性冲突被误用**：为追求紧致而放宽 `Θ/W/ρ_int`，破坏包含性。缓解：P25 优先级写死、形式化检查、E671 回归门禁。

## 8. 本轮最大风险

**一句话**：MCCL 的每张材料证书都基于"新材料的标称参数"离线认证，而磨损、热软化、润滑迁移会把真实材料缓慢推出 `Θ_m`；此时 DCE 关于 `Θ_m` 仍然 sound、MDCC 仍然匹配、切换仍然不增能量，系统却在"每步都含于包络、每种材料都预认证、每次切换都不增能量"的表象下，用一个**已经不存在的材料**做出了绝对错误的安全决定——即**按证书的、按材料的、却物理上早已失效的安全决定**。
