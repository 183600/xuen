# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「持续学习」×「运动学」）

> 第 54 轮把技能组合从“能力匹配”推进到“动作-鲁棒性双证书” `J=(ρ,A_cert,γ_ce,δ_a)`，但其证书是**静态签发**的：默认签发时刻的动作剖面 `α_S` 与有效域 `V` 在部署期内不变。本轮引入**时间轴（持续学习）**与**几何轴（运动学）**，追问：当技能被持续更新后，旧证书何时失效？核心矛盾：H22：持续学习导致动作剖面发生漂移，且在近奇异区被 Jacobian 病态放大，静态证书的 soundness 假设被破坏；H23：稳定性-可塑性两难在证书层面的表现——过度保护已认证动作则丧失可塑性，无条件信任更新则旧证书失效并触发负迁移。

## 0. 直觉与动机

**灵感 1（从静态动作剖面到运动学轨迹）**
直觉：技能 `S` 不是一张固定的动作占用图 `α_S(a)`，而是一条随持续学习演化的轨迹 `α_{S_t}(a)`。灾难性遗忘在动作空间里有两个可观测形态：**边界漂移**（已认证动作的覆盖度改变）与**工作空间塌缩**（某些动作维度因新任务训练而不可达）。运动学提供了正确度量：动作邻近性不是欧氏距离，而是被 Jacobian 加权的黎曼距离；关节空间里“很小的一步”，在任务空间里可能“很大”。

**灵感 2（奇异放大 → 证书漂移风险）**
直觉：一阶运动学给出 `δx = 𝕁(q)δq`。当 `𝕁` 接近奇异（`σ_min→0`）时，反向映射 `δq = 𝕁⁺δx` 被 `κ=σ_max/σ_min` 放大。于是同样大小的参数更新，在近奇异动作上造成的证书漂移远大于在高可操作度动作上。**“已认证但接近奇异”的动作才是证书最脆弱的地方**，这正是第 54 轮 `A_cert` 未刻画的风险。

**灵感 3（零空间持续学习 → 不遗忘的可塑性）**
直觉：运动学冗余意味着 `δq ∈ ker(𝕁)` 不改变末端任务动作。若把持续学习的更新投影到零空间，就能在**不改变已认证任务行为**的前提下吸收新技能——这是“可塑性”与“稳定性”在几何上的部分解耦。range-space 的更新才需要触发重认证。这把抽象的 stability-plasticity 两难变成一个可计算的投影算子。

**灵感 4（运动学弹性锚定 → 按奇异裕度分配稳定性）**
直觉：像 EWC 一样给参数加锚定，但锚定权重不应均匀：对近奇异动作锚得重（`λ(a)∝1/σ_min²`），对高可操作度、冗余动作放得松。这样“稳定性”被花在证书关键区，“可塑性”留给冗余区，形成**运动学弹性预算**。

**灵感 5（证书续期微积分 → 从一次性签发到 TTL + 局部重认证）**
直觉：每轮更新后都全量重认证不可承受，完全信任更新又危险。引入证书 TTL 与**漂移剖析器**，把决策路由到 {续期, 局部补丁重认证, 零空间投影更新, 全量重认证, 回滚}。证书从“一次性证明”变成“可续期的活文档”。

**灵感 6（持续运动学层 𝕂）**
直觉：在第 54 轮动作-协同层 `𝔸` 之上叠加 **`𝕂` 层**：`𝕂_0` 关节构型流形、`𝕂_1` Jacobian/可操作度、`𝕂_2` 零空间更新、`𝕂_3` 证书有效期。跨层证书同时携带 `ρ`、`A_cert`、`γ_ce` 与新的**漂移界 `D_cert` 与 TTL `τ_cert`**。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（时变动作剖面与持续更新轨迹）**
技能在时刻 `t` 的剖面 `α_{S_t}: A → [0,1]`。更新算子 `U_t: S_t ↦ S_{t+1}`。给定轨迹 `{S_t}_{t=0..T}`，**剖面漂移** `D_α(t,t') = sup_{a∈A} |α_{S_t}(a) − α_{S_{t'}}(a)|`；**工作空间收缩** `ΔW(t,t') = W(t) \ W(t')`，其中 `W(t) = {a : α_{S_t}(a) ≥ θ_cov}`。

**定义 122（运动学度量与可操作度）**
执行映射 `f_S: Q → A`，Jacobian `𝕁_S(q) = ∂f_S/∂q ∈ ℝ^{m×n}`。可操作度 `w(q) = √det(𝕁𝕁ᵀ)`，最小奇异值 `σ_min(q)`，条件数 `κ(q) = σ_max/σ_min`。黎曼度量 `g_q(δq,δq') = δqᵀM(q)δq'`，`M = 𝕁ᵀ𝕁 + εI`。**运动学距离** `d_K(a,a') = inf_γ ∫ √(g_{q(t)}(q̇,q̇)) dt`。奇异集 `Σ = {q : σ_min(q) ≤ σ_0}`，**奇异裕度**即 `σ_min(q)`。

**定义 123（证书漂移与奇异放大风险）**
证书 `J_t` 携带有效域 `V_t ⊆ A` 与有效期 `τ_cert`。一次更新后的**证书漂移**：
```
D_cert(J_t, S_{t+1}) = sup_{a∈V_t} |α_{S_{t+1}}(a) − α_{S_t}(a)| · κ(a)
```
参数更新幅度为 `Δθ` 时，**奇异放大风险** `R_drift(a) = κ(a)·||Δθ||`。证书在 `t+1` 仍 sound 当且仅当：
```
D_cert ≤ δ_cert  ∧  V_t ⊆ W(t+1)  ∧  ∀d, ρ_{S_{t+1}}(d) ≥ ρ_min(d)
```
**运动学遗忘** `KF(t,t') = vol(V_t \ V_{t'})`；**运动学可塑性** `KP(t,t') = vol(V_{t'} \ V_t)`。

**定义 124（零空间证书保持更新）**
分解更新 `δq = δq_∥ + δq_⊥`，其中 `δq_⊥ ∈ ker(𝕁)`，`δq_∥ ∈ row(𝕁)`。零空间投影 `P_null = I − 𝕁⁺𝕁`。一阶意义上
```
f(q+δq) − f(q) = 𝕁 δq_∥ + O(||δq||²)
```
若 `||P_null δq − δq|| ≤ ε_ns`，称更新为**证书保持的**，无需重认证；否则沿 range-space 触发定义 126 的重认证。这个定义把“是否遗忘”转成“更新落在哪个子空间”。

**定义 125（运动学弹性锚定）**
锚定权重 `λ(a) = λ0 / (σ_min(a)+ε)²`。持续训练目标：
```
L = L_task(θ) + Σ_{a∈V_t} λ(a)·(α_{S_{t+1}}(a) − α_{S_t}(a))²
```
**可塑性预算** `B_p` 限制高锚定区之外允许的总漂移；弹性分配规则：优先把更新预算分配到低 `λ(a)`（高 `σ_min`、冗余）区域。

**定义 126（持续运动学联合证书 CKJ）**
```
CKJ = (J_t, V_t, τ_cert, g_q, D_cert, KF, KP, reval_plan, evidence)
```
可部署判据：`dom_J(T)=in ∧ D_cert≤δ_cert ∧ τ_cert>0 ∧ reval_plan 可执行`，其中 `reval_plan ∈ {renew, local_patch, null_space, full_reval, rollback}`。

**定义 127（稳定性-可塑性证书前沿）**
证书策略 `π`：更新序列 → 重认证动作。其效果为 `(KF(π), KP(π), cost(π))`。**前沿**
```
SPF = {π : ¬∃π', KF(π')≤KF(π) ∧ KP(π')≥KP(π) ∧ cost(π')≤cost(π)（至少一严格）}
```
持续学习的目标不是单点最优，而是把策略保持在 SPF 上。

## 2. 关键算法 伪代码

### IP-121 KDP（Kinematic Drift Profiler）

```python
def kinematic_drift_profile(skill, V, eps=1e-8):
    prof = {}
    for a in V:
        q = skill.ik(a)
        Jm = skill.jacobian(q)
        s = smallest_singular_value(Jm)
        kappa = cond(Jm) if s > eps else float('inf')
        prof[a] = (kappa, s, skill.alpha(a))
    return prof

def estimate_drift(prof, delta_update, delta_cert):
    risk = {a: (float('inf') if kappa == float('inf')
                else kappa * delta_update)
            for a, (kappa, s, _) in prof.items()}
    return max(risk.values()) <= delta_cert, risk
```

### IP-122 CKA（Certificate-preserving Kinematic Adaptation）

```python
def certificate_preserving_update(skill, grad, lr, eps_ns=1e-3):
    Jm = skill.jacobian(skill.q)
    Jpinv = pinv(Jm)
    delta = -lr * grad
    delta_null = (np.eye(len(delta)) - Jpinv @ Jm) @ delta
    if norm(delta_null - delta) <= eps_ns:
        return ('null_only', delta_null)          # 一阶不改变任务动作，免重认证
    return ('range', delta - delta_null, delta_null)  # range 分量需重认证
```

### IP-123 KEWC（Kinematic Elastic Weight Consolidation）

```python
def kinematic_ewc_loss(skill, theta, theta_anchor, lambda0, eps=1e-8):
    loss = task_loss(skill, theta)
    for a in skill.certified_actions:
        q = skill.ik(a)
        s = smallest_singular_value(skill.jacobian(q))
        lam = lambda0 / (s + eps) ** 2              # 近奇异重锚定
        loss += lam * (alpha(theta, a) - alpha(theta_anchor, a)) ** 2
    return loss
```

### IP-124 CRR（Certificate Revalidation Router）

```python
def revalidation_router(skill, cert, delta_update, budget):
    ok, risk = estimate_drift(cert.prof, delta_update, cert.delta_cert)
    if ok and remaining_ttl(cert) > 0:
        return ('renew', cert)
    patch = {a for a, r in risk.items() if r > cert.delta_cert}
    if vol(patch) / vol(cert.V) <= budget.patch_frac:
        return ('local_revalidate', patch)
    if projected_null_fraction(skill) >= budget.ns_floor:
        return ('null_space_adapt', cert)
    if cert.rollback_anchor is not None:
        return ('full_revalidate', cert.V, cert.rollback_anchor)
    return ('rollback', cert.rollback_anchor)
```

### IP-125 SPF（Stability-Plasticity Frontier）

```python
def stability_plasticity_frontier(policies, updates, cost_budget):
    pts = []
    for pi in policies:
        KF, KP, cost = evaluate(pi, updates)
        if cost <= cost_budget:
            pts.append((KF, KP, cost, pi))
    return pareto_nondominated(pts, maximize='KP', minimize=('KF', 'cost'))
```

### IP-126 KTC（Kinematic Temporal Certificate）

```python
def continual_kinematic_certify(cert, updates, delta_cert, tau_cert, budget):
    cur = cert
    for u in updates:
        if u.t - cur.issued > tau_cert:
            return ('expired', cur)
        ok, risk = estimate_drift(cur.prof, u.delta, delta_cert)
        if not ok:
            action = revalidation_router(cur.skill, cur, u.delta, budget)
            cur = apply_revalidation(action)
            if cur is None:
                return ('rollback', u)          # 宁可回滚，不带病部署
        cur.KF += vol(cur.V - cur.V_new)
        cur.KP += vol(cur.V_new - cur.V)
        cur.issued = u.t
    return ('ok', cur)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| KDP | O(|V|·(mn² + t_SVD)) | O(|V|) | σ_min 采样覆盖关键动作 |
| CKA | O(mn² + n³) | O(n²) | 零空间投影误差 ≤ ε_ns |
| KEWC | O(|V|·mn + |θ|) | O(|θ|+|V|) | λ(a) 锚定权重单调于 1/σ_min² |
| CRR | O(|V| + |π|) | O(|V|) | 风险上界 sound、路由互斥 |
| SPF | O(|Π|·|U|·cost(eval)) | O(|Π|) | Pareto 非支配正确 |
| KTC | O(|U|·|V|) | O(|V|) | TTL 单调、回滚锚点可恢复 |

**正确性定理（Continual Kinematic Certificate Soundness）**
承接第 54 轮 (A26)–(A28)；新增 **(A29)** `f_S` 在有效域上局部 `C²` 且 `||𝕁||≤J_max`；**(A30)** 漂移估计 `D̂_cert` 是真实漂移上界，置信度 `1−β_E`；**(A31)** 零空间投影数值误差 `≤ε_ns`；**(A32)** 重认证与回滚延迟 `≤τ_loop` 且回滚锚点可恢复。
则对任意满足 `D̂_cert≤δ_cert` 且未超 `τ_cert` 的更新序列：
```
P(部署期内证书 sound) ≥ 1 − β_E − P(range-space 未认证更新) − P(σ_min < σ_safe) − P(回滚失败)
```
并由一阶展开：
```
||f(q+δq) − f(q)|| ≤ J_max·||δq_∥|| + (L_f/2)·||δq||²
||δq|| ≤ κ(q)·||δx||
```
第一式说明**零空间分量只贡献二阶项**——这是“零空间可塑性不破坏证书”的严格依据；第二式说明近奇异处同样的任务漂移需要更小的参数步长，故 `R_drift∝κ`。

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 漂移预测准确度 | `D̂_cert` vs 实测 `||f(q')−f(q)||` 的 MAE | MAE ≤ 0.03 |
| E163 失效漏报安全 | 证书应失效而误判有效的比例 | 漏报 = 0（硬约束） |
| E164 重认证成本 | 局部补丁 vs 全量重认证成本 | 成本降 ≥ 60%，soundness 不降 |
| E165 稳定性-可塑性 | `(1−KF, KP)` 对 EWC/replay/finetune | 在 SPF 上不劣于所有基线 |
| E166 近奇异负迁移 | `σ_min<σ_safe` 区负迁移率 | 相对基线降 ≥ 50% |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| Jacobian 局部线性化在接触/碰撞下失效 | 高 | 分段线性化 + 接触约束感知 + 保守 `δ_cert` |
| 零空间投影数值误差累积 | 高 | 高精度 SVD + 投影残差在线监测 + 超阈值重认证 |
| 锚定过强导致可塑性枯竭 | 中 | `λ(a)` 上限 + 可塑性预算 `B_p` + SPF 监控 |
| TTL 与更新频率不匹配 | 中 | 自适应 TTL + 漂移触发优先于时间触发 |
| 真实 σ_min 难以在线估计 | 高 | 结构化仿真标定 + 不确定区间 + 奇异裕度冗余 |

## 6. 本轮最大风险

**一句话**：持续运动学证书把旧证书的续期押在 **Jacobian 局部线性化、零空间投影数值精度与奇异裕度在线估计** 三重近似上；一旦真实技能在近奇异或接触约束下偏离 `C²` 假设，漂移界会系统性低估，旧证书可能在**未触发重认证时静默失效**，故必须以 **接触感知的分段线性化 + 投影残差在线监测 + 漏报零容忍的回滚绊线** 兜底，宁可频繁重认证，绝不把“漂移界内”当作“真实 sound”。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（KDP×CKA×KEWC×CRR×SPF×KTC）

> 承接第 54 轮产物 v31。本轮在动作-鲁棒性双证书 `J=(ρ,A_cert,γ_ce,δ_a)` 之上，加入**时间维（持续学习）**与**几何维（运动学）**六个算子，使证书从“一次性静态证明”升级为“带 TTL、可续期、可回滚的活证书”：
> - **KDP（Kinematic Drift Profiler）**：按奇异裕度剖析证书漂移风险，量化 `D_cert`；
> - **CKA（Certificate-preserving Kinematic Adaptation）**：零空间投影更新，一阶不改变已认证任务动作；
> - **KEWC（Kinematic Elastic Weight Consolidation）**：`λ(a)∝1/σ_min²` 的按动作弹性锚定；
> - **CRR（Certificate Revalidation Router）**：`renew/local/null/full/rollback` 重认证路由；
> - **SPF（Stability-Plasticity Frontier）**：`(KF,KP,cost)` 的 Pareto 前沿；
> - **KTC（Kinematic Temporal Certificate）**：`CKJ` 随更新序列续期、失效与回滚。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/118/120 以纳入时间维与运动学度量。

```python
        q = skill.ik(a)
        s = smallest_singular_value(skill.jacobian(q))
        lam = lambda0 / (s + eps) ** 2
        loss += lam * (alpha(theta, a) - alpha(theta_anchor, a)) ** 2
    return loss
```

### IP-124 CRR

```python
def revalidation_router(skill, cert, delta_update, budget):
    ok, risk = estimate_drift(cert.prof, delta_update, cert.delta_cert)
    if ok and remaining_ttl(cert) > 0:
        return ('renew', cert)
    patch = {a for a, r in risk.items() if r > cert.delta_cert}
    if vol(patch) / vol(cert.V) <= budget.patch_frac:
        return ('local_revalidate', patch)
    if projected_null_fraction(skill) >= budget.ns_floor:
        return ('null_space_adapt', cert)
    if cert.rollback_anchor is not None:
        return ('full_revalidate', cert.V, cert.rollback_anchor)
    return ('rollback', cert.rollback_anchor)
```

```python
def stability_plasticity_frontier(policies, updates, cost_budget):
    pts = []
    for pi in policies:
        KF, KP, cost = evaluate(pi, updates)
        if cost <= cost_budget:
            pts.append((KF, KP, cost, pi))
    return pareto_nondominated(pts, maximize='KP', minimize=('KF', 'cost'))
```

### IP-126 KTC

```python
def continual_kinematic_certify(cert, updates, delta_cert, tau_cert, budget):
    cur = cert
    for u in updates:
        if u.t - cur.issued > tau_cert:
            return ('expired', cur)
        ok, risk = estimate_drift(cur.prof, u.delta, delta_cert)
        if not ok:
            action = revalidation_router(cur.skill, cur, u.delta, budget)
            cur = apply_revalidation(action)
            if cur is None:
                return ('rollback', u)
        cur.KF += vol(cur.V - cur.V_new)
        cur.KP += vol(cur.V_new - cur.V)
        cur.issued = u.t
    return ('ok', cur)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| KDP | O(|V|·(mn²+t_SVD)) | O(|V|) | `σ_min` 采样覆盖关键动作 |
| CKA | O(mn²+n³) | O(n²) | 投影残差 ≤ ε_ns |
| KEWC | O(|V|·mn+|θ|) | O(|θ|+|V|) | `λ(a)` 单调于 `1/σ_min²` |
| CRR | O(|V|+|π|) | O(|V|) | 风险上界 sound、路由互斥 |
| SPF | O(|Π|·|U|·cost) | O(|Π|) | Pareto 非支配正确 |
| KTC | O(|U|·|V|) | O(|V|) | TTL 单调、回滚锚点可恢复 |

**正确性定理（Continual Kinematic Certificate Soundness）**
承接第 54 轮 (A26)–(A28)；新增 **(A29)** `f_S` 局部 `C²` 且 `||𝕁||≤J_max`；**(A30)** `D̂_cert` 为真实漂移上界，置信度 `1−β_E`；**(A31)** 零空间投影误差 `≤ε_ns`；**(A32)** 重认证/回滚延迟 `≤τ_loop` 且锚点可恢复。
则对任意满足 `D̂_cert≤δ_cert` 且未超 `τ_cert` 的更新序列：
```
P_sound ≥ 1 − β_E − P(range-space 未认证更新) − P(σ_min < σ_safe) − P(回滚失败)
```
关键推导：
```
||f(q+δq) − f(q)|| ≤ J_max·||δq_∥|| + (L_f/2)·||δq||²
||δq|| ≤ κ(q)·||δx||
```
前者说明零空间分量只贡献二阶项，后者说明近奇异处 `R_drift∝κ` 必须收紧参数步长。

## 6. 本轮最大风险

**一句话**：持续运动学证书把旧证书的续期押在 **Jacobian 局部线性化、零空间投影数值精度与奇异裕度在线估计** 三重近似上；一旦真实技能在近奇异或接触约束下偏离 `C²` 假设，漂移界会系统性低估，旧证书可能在**未触发重认证时静默失效**，故必须以 **接触感知的分段线性化 + 投影残差在线监测 + 漏报零容忍的回滚绊线** 兜底，宁可频繁重认证，绝不把“漂移界内”当作“真实 sound”。
