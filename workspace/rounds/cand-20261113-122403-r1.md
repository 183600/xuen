# 第 66 轮（承接第 65 轮「VISTA 故障可归因闭环」IP-214~223；灵感循环第 3 轮；本轮灵感：「视觉定位」×「比赛策略」）

> 第 65 轮把“几何可证伪”升级为“故障可归因”，其自述的最大风险一针见血：**归因本身可能错，而且是自信地错**——它依赖“故障属于有限假设集”与“视觉/几何失效相互独立”两个假设；真实故障常是未知类型的组合，透明、镜面、对抗 patch 又会让视觉与几何共享同一个分布外失效源，于是 FIR 把未知复合故障强行塞进最近假设、只膨胀错误的球，系统还因为“已经归因”而更自信地继续执行。本轮不再继续扩充假设集（那是治标，且永远追不上真实故障空间），而是换一个提问方式：第 65 轮问“**它是哪一类故障**”，ARENA 问“**我这个归因本身可不可信、我是否已经迷失、以及在对手面前我该把多少风险花在探针上、多少花在执行上**”。
>
> 本轮核心命题：
>
> **把“封闭集贝叶斯归因”升级为“开放集对抗博弈 + 视觉定位锚 + 无悔专家组合”：用视觉定位提供带结构 Jacobian 的世界系锚残差与空间故障先验；用重定位/回环机制在“归因失效”时主动承认迷失而非硬分类；用带预算的对抗博弈把“未知复合故障”纳入 minimax 而不是枚举；用攻防风险预算与专家组合回答“探针还是执行、该信哪个归因模型”。**

## 0. 直觉与动机

**灵感 1（视觉定位 → 不是“又一个视觉残差”，而是一个带结构的世界系锚）**
直觉：VISTA 的视觉证据是“任务观测量残差” `e_vis`，它不知道自己在世界里的位置，因此任何几何错、地图错、力偏置都可能表现为“视觉不对”。视觉定位（place recognition + 局部特征匹配 + PnP/RANSAC）给出了另一种量：**机器人相对已知地图的 6-DoF 位姿** `T^vis`。把它与本体/几何预测位姿 `T̂^geo` 相减得到锚残差 `e_anc = log((T̂^geo)^{-1}T^vis)`。关键在于它的**结构**：力偏置不会移动相机，所以 `e_anc` 对 H_force 的 Jacobian 恒为零；地图/运动学误差才会移动它。这就给签名矩阵补上了 VISTA 缺的一行——能在自由空间里把“力传感器坏了”和“几何/地图错了”分开。但必须诚实：视觉定位自己也会**感知别名**（重复纹理、对称、透明），此时它输出的是**多假设位姿**而非单一真值；它和几何若共用同一张地图，还会共享地图误差（共因）。所以视觉定位不是真值，而是一个**结构已知、失效模式可命名的锚**。

**灵感 2（视觉定位 → “故障地图 + 重定位”，把归因从分类变成定位）**
直觉：VISTA 的故障先验是全局的、与位置无关的；但真实故障高度**地点相关**：某个反光角落、某块软垫、某段湿滑地面。视觉定位把每帧证据落到地图坐标 `x`，于是故障先验变成 `P(H|x)`，历史回访积累成一张**故障锚图**——这就是竞赛里的“侦察报告”。更重要的是定位系统的第二个教训：机器人会**被绑架（kidnapping）**，此时继续用旧粒子滤波更新只会越错越自信；正确做法是检测“所有位姿假设都解释不了观测”，然后**全局重定位**。归因同理：当没有任何故障假设（含“未知”）能解释残差时，正确动作不是 argmax，而是宣布 `unknown_regime`、重置后验、在开放集上重定位。**VISTA 的“因已归因而更自信”，本质就是缺少 kidnapping 检测。**

**灵感 3（视觉定位 → 故障位姿图与回环，纠正“过去的归因”）**
直觉：定位系统用位姿图把许多局部估计拼成全局一致地图，并用**回环闭合**发现“我早先认为自己在 A，其实在 B”。归因也需要跨时间、跨回访的一致性：把每个检查点的故障状态 `(t_i,x_i,θ_i)` 作为节点，把受控探针给出的故障空间增量、多传感器一致性、以及“回到同一地点重新检验”的回环约束作为边。若回环残差大，说明**早先的归因是错的**，应重开该节点。这样归因第一次有了“可被后续证据推翻”的机制，而不是一次 argmax 定终身。

**灵感 4（比赛策略 → 把故障当对手：带预算的开放集 minimax）**
直觉：VISTA 的 ℋ 是一个封闭“选手名单”，真实世界却会派出名单外的组合拳。比赛策略的第一课是：**不要假设对手只在你的名单里出招，而要问他最多能造成多大破坏，然后选一个 maximin 的打法**。于是把故障建模为对手，在**预算集** `Θ_ε`（幅度 + 总变差预算，允许复合、缓慢漂移、名单外故障）里选择故障轨迹，机器人选择策略（探针计划、执行前缀、膨胀半径），求解零和博弈 `V* = max_π min_{θ∈Θ_ε} E[任务收益 − λ·伤害]`。归因输出从“点后验”变成**均衡支持集**（对手最可能/最坏会打的那些故障）。若 `V*` 低于安全阈值，就必须防守（探针/后退）；高于阈值才进攻（执行）。未知复合故障不再需要枚举——它们在预算球里。

**灵感 5（比赛策略 → 攻防风险预算 + 专家联赛）**
直觉：比赛里“什么时候侦察、什么时候进攻”是核心策略：侦察耗时间、暴露意图，进攻拿分但冒风险。机器人同理：探针消耗力/时间，执行拿进度。给每个回合一个有限**风险预算 B**，用约束 POMDP 的拉格朗日价格 λ 在“进攻（执行）”与“防守（探针/后退）”之间分配；探针只在**能改变打法**时才值得（scouting only when it changes the play），这比 VISTA 的“最大化故障互信息”更锋利。另一方面，谁也不敢保证哪一个归因模型是对的，于是让多个归因模型（不同假设集、不同独立性假设、不同先验）组成**专家联赛**，用 Hedge/指数权重按“安全违规 + 任务代价”在线更新权重，得到无悔界；当**所有专家都很差**时，这本身就是“未知故障/模型误配”的检测信号，应提高歧义半径 ρ 并转入防守。锦标赛/排行榜不是比喻：权重就是排行榜，回环就是赛季复盘。

**灵感 6（ARENA：Adversarial RE-localization with No-regret Attribution，对抗重定位与无悔归因的竞赛式安全闭环）**
闭环：视觉定位锚图（ALM）→ 故障定位与重定位（FLR：多假设信念 + kidnapping 检测）→ 故障位姿图/回环（FGM）→ 带预算对抗归因博弈（GAB：minimax + DRO）→ 攻防策略与风险预算（SPC）→ 专家组合无悔选择（EPX）→ 策略感知探针（STP）→ 策略风险证书（SRC）→ 按均衡支持定向膨胀（RSC-G）与博弈最坏编译（WCV-G）→ 竞赛规划与对抗认证（CSP-G/AIC-G）→ J_arena。第 65 轮把“接触”拆成接触前/中/后；ARENA 把“归因”拆成**归因之前（我迷路了吗）/归因之中（对手会怎么打）/归因之后（过去的归因还成立吗）**。

**灵感 7（VISTA 组件原位升级）**
- **FIR → GAB**：封闭集 argmax 后验 → 开放集带预算 minimax / DRO 均衡支持，显式输出 `V*`、`Θ*`、`unknown_regime`。
- **VCV → ALM/FLR**：视觉接触验证升级为“视觉定位锚 + 故障锚图 + 多假设故障信念 + 重定位”。
- **AFA → STP**：探针目标从“故障互信息”改为“**能改变策略的博弈值提升**”；信息不改变打法就不探。
- **CSC → SRC**：块级前缀证书升级为“博弈最坏 + 风险预算”的步级证书，预算耗尽强制防守。
- **RSC-V/WCV-V → RSC-G/WCV-G**：按均衡支持/对抗分布定向膨胀与编译，未知方向联合保守。
- **CSP-V → CSP-G**：边代价增博弈值、歧义半径、风险预算；新增 `scout`（侦察）、`relocalize`、`defend` 元技能。
- **AIC-V → AIC-G**：对抗集增视觉定位别名/地图投毒/对手遮挡，认证从平均改为锦标赛式 worst-case。
- **J_vista → J_arena**：证书不再要求“归因确定”，而要求“最坏情况可证或已诚实进入未知安全模式”。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（ARENA 闭环）**：ARENA = (VISTA, ALM, FLR, FGM, GAB, SPC, EPX, STP, SRC, RSC-G, WCV-G, CSP-G, AIC-G, J_arena)。定位：VISTA 的“开放集 + 对抗 + 重定位”升级。不变式：**视觉定位、故障信念、博弈求解、专家权重、证书只在语义流；实时流只做锚残差采集、重定位触发检测、前缀执行与早停，零学习写操作。**
- **定义 234（视觉定位锚与锚残差）**：视觉定位 `VL(img_t, M) → { (T_j, w_j, Σ_j) }`，先做全局地点识别给候选地点，再做局部特征 + PnP/RANSAC 得 6-DoF 位姿假设与 inlier 协方差；多假设由感知别名（重复纹理、对称、透明）产生。锚残差 `e_anc(t)=log((T̂^geo_t)^{-1}T^vis_t) ∈ ℝ⁶`，`T̂^geo` 为本体/几何预测位姿。其**结构性质**：`∂e_anc/∂θ_force ≡ 0`（力偏置不移动相机），故锚残差是分离 H_force 与 H_geo 的独立行；但地图误差同时进入 `T̂^geo` 与 `T^vis`，故锚残差**不能**独立证明地图错，只能在 `novelty(x)` 低时使用。多假设时用混合模型 `p(e_anc|·)=Σ_j w_j N(e_anc; μ_j, Σ_j)`。
- **定义 235（故障锚图 FAM）**：`A: x ↦ (p_0(θ|x), Σ_0(θ|x), novelty(x))`，按空间单元记录历史故障先验、严重度方差与“视觉/几何覆盖新颖度”。`novelty(x)` 高（地图未覆盖、外观分布外）时提高开放集质量与歧义半径 ρ，并降低锚残差权重。FAM 支持跨回合“侦察报告”，使先验地点相关。
- **定义 236（开放集故障信念与故障别名）**：维护粒子 `{(θ^{(n)}, w^{(n)})}`，状态空间 `Θ=Θ_known ∪ Θ_unknown`，θ 为连续严重度与复合模式（非固定标签）。证据模型 `p(z_t|θ,x_t)`。**故障别名集** `Alias(z)={θ: D(p(·|z,θ)‖p(·|z,θ*))≤ε_alias}`；`alias_mass(z)=max_{[θ]} Σ_{θ'∈[θ]} w(θ')` 为最大等价类质量。`alias_mass` 高即“不可辨识/别名”，必须保留多假设，**禁止 argmax 定标签**（这正是 VISTA 的病根）。
- **定义 237（归因绑架检测与重定位 FLR）**：边缘证据 `L_t=Σ_n w^{(n)}p(z_t|θ^{(n)},x_t)`。CUSUM `g_t=max(0, g_{t-1}+log δ − log(L_t/L̄))`；若 `g_t>h` 或有效样本数 `ESS<ε_ess` 持续 k 步，则判**故障政权切换/归因绑架**：`unknown_regime=True`，按 FAM 先验在开放集上重新初始化粒子、注入大质量 `θ_unknown`，并要求 `relocalize`（含视觉全局重定位或 `null_test`/`scout`）。该检测同时是**模型误配的拟合优度检验**：真实故障不在 Θ 中时 `L_t` 系统性下降。
- **定义 238（故障位姿图与归因回环 FGM）**：节点 `(t_i,x_i,θ_i,Σ_i)`；边三类：(i) 探针给出的故障空间增量 `‖θ_j−θ_i−Δθ_probe‖²_{Σ}`；(ii) 多传感器一致性 `‖r−Aδ−b‖²`；(iii) **回环**：回到同一地点 `x` 重新检验时 `e_loop=‖θ_i−θ_j‖²_{Σ_loop}`。用鲁棒位姿图（switchable constraints）求 MAP；回环残差大 ⇒ 早先归因错误，重开该节点并触发 FLR。故障图是可被后续证据**推翻**的记忆。
- **定义 239（对抗故障预算集）**：对手选择故障轨迹 `θ_{1:T}∈Θ_ε={θ: Σ_t‖θ_t‖_1 + λ_TV Σ_t‖θ_{t+1}−θ_t‖_1 ≤ ε}`，允许复合、缓慢漂移、名单外模式；可选单纯形约束“至多一个主导模式”。载荷/地图不确定 `‖A−A₀‖≤ε_A`。**Θ_ε 是开放的**：不枚举标签，只限制“故障能有多大、变得多快”。
- **定义 240（归因博弈与分布鲁棒均衡 GAB）**：机器人策略 `π=(探针计划 u_{1:T}, 执行前缀 k, 膨胀 r)`，对手故障 θ。零和博弈
  `V*(x)=max_π min_{θ∈Θ_ε} E[R_task(π,θ) − λ_d D(π,θ)]`。
  为吸收真实故障的随机性，采用分布鲁棒版本：对手在 Wasserstein 球 `{Q: W(Q,P̂)≤ρ}` 内选分布，`ρ=0` 退化为贝叶斯、`ρ→∞` 退化为最坏情况。归因输出 = **均衡支持集** `Θ* = supp(Q*)`（对手最优响应会打的故障）与 `V*`；决策规则：`V*<V_safe ⇒ 防守`，`V*≥V_safe ⇒ 进攻`。未知复合故障无需进名单，只需进预算球。
- **定义 241（攻防策略与风险预算 SPC）**：每回合有限风险预算 `B`（如期望伤害/力-时间积分上限）。约束 POMDP：`max E[R_task] − λ E[D] s.t. E[D]≤B`，对偶变量 λ 即“风险价格”。每步用索引策略比较：**进攻索引** `Idx_exec=预期进度/λ`；**防守索引** `Idx_probe=预期博弈值提升/λ−探针代价`；取较大者。探针只在能改变决策（探针↔执行、膨胀哪个方向、是否重定位）时入选。安全前进可“回收”部分预算，但硬安全上限不可回收。
- **定义 242（专家组合无悔归因 EPX）**：专家集 `{E_k}`，每个专家是一个归因模型（假设集/独立性假设/似然/先验）。第 t 回合专家给出 `(θ̂_{k,t}, π_{k,t})`，损失 `ℓ_{k,t}=1[安全违规]+c·任务遗憾`。Hedge 更新 `w_{k,t+1}∝w_{k,t}exp(−ηℓ_{k,t})`。悔界 `Regret_T≤√(T log K/2)`。若 `min_k (1/T)Σ_tℓ_{k,t}>ℓ_0`（**没有专家可靠**），判模型误配，提高 ρ、降低 `V_safe` 容忍、转防守。霸权竞争的策略与对手均可视为无悔学习者，故长期收敛到粗相关均衡——但这只是渐近/平均保证，不能替代逐步安全（见定义 244）。
- **定义 243（策略感知探针 STP）**：`u*=argmax_u [V*_{t+1}(bel(·|u))−V*_t] − cost(u)`，s.t. 预测 `f_n≤f_safe`、形变 `≤ε_strain`；若采用该探针后 `argmax` 决策不变，则 `u*∅`（不探）。它严格强于 AFA：AFA 最大化后验熵/互信息，STP 最大化**决策价值**；也强于 IDP 的纯可辨识性——可辨识但不改变打法时仍不探。
- **定义 244（策略风险证书 SRC）**：逐步风险 `ρ_s=min_{θ∈Θ_ε∩supp(bel)} margin_s(θ)`；认证前缀
  `k*=max{k: min_{θ∈Θ_ε}P[∃s≤k: margin_s(θ)<0]≤α_step ∧ V*_{1:k}≥V_safe ∧ Σ_{s≤k}E[D_s]≤B}`。
  预算耗尽、`alias_mass>τ_alias`、或 `unknown_regime=True` 时 `k*=0` → 强制防守/重定位。与 VISTA 不同：这里用**最坏值 + 风险预算**而非后验支持集，且允许“承认不知道”。
- **定义 245（RSC-G 均衡定向膨胀）**：由对手最优响应分布 `Q*` 取各方向分位 `r_m=Quantile_{Q*}(|θ_m|, 1−α_m)`；只膨胀 `Q*` 支持的模态；可辨识零空间方向对所有球**联合**膨胀并置 `unidentifiable=True`；模型误配/`unknown` 质量高时全局膨胀 + `safe_mode`。融合 `r=√(Σ_m r_m²)`。相比 VISTA，膨胀依据是**对手会打哪里**而非单点后验。
- **定义 246（WCV-G 博弈最坏编译）**：在 `Q*` 下做分布鲁棒 CVaR 编译：`min_{K∈K} CVaR_{α}^{Q*}[exec_loss(K,θ)]`，对 `Θ*` 交集取安全核；空交集或 `V*<V_safe` 时回退 `B(φ̂,r)` 并置 `defend_required=True`。尾部采样按 `Q*` 而非后验。
- **定义 247（CSP-G / AIC-G 竞赛规划与对抗认证）**：CSP-G 在块边增 `λ_g·(−V*)+λ_ρ·ρ+λ_B·B_spent`，元技能 `scout`（主动侦察，更新 FAM）、`relocalize`（FLR）、`defend`（后退/柔顺/等待）。AIC-G 干扰集 `ℰ_G=ℰ_V×ℰ_loc×ℰ_game`：`ℰ_loc` 含视觉定位感知别名、反光/重复纹理、地图投毒/过期；`ℰ_game` 含对手主动遮挡/移动物体/制造共因。认证改为**锦标赛式 worst-case**：在 `n_cert` 个对抗场景上取最坏，而非平均；并报告“名单外”留出集的最坏值。
- **定义 248（ARENA 证书 J_arena 与对 VISTA 的退化）**：`J_arena=(J_vista, game_value, ambiguity_radius, relocalization_flag, anchor_cov, alias_mass, expert_weights_hash, risk_budget_spent, unknown_regime, aic_g_ver)`。验证：

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（锚残差的结构分离）**：在线性化下，`e_anc` 对力偏置的 Jacobian 为零，因此在自由空间（零力窗）中锚残差为 H_geo/H_force 增加了一行近正交证据，改善 `SᵀΣ⁻¹S` 的秩与条件数；若地图与几何误差同源（共用地图），该行退化为几何误差的复制，不可用于分离 H_geo，只能由 FAM 的 `novelty` 与多假设位姿显式标注。
- **引理 10（归因绑架检测与假自信时长）**：CUSUM 对政权切换的平均检测延迟约 `h/KL(P_1‖P_0)`，虚警率随 h 指数下降；当真实故障不在 Θ 内时，`E[log L_t]` 以 `KL(P_true‖P_model)>0` 的速率下降，故 FLR 会在有限步内触发重定位。由此，**“已归因后继续自信执行”的期望时长有界**，这是 VISTA 缺失的性质。
- **定理 9（博弈鲁棒安全）**：若 `V*≥V_safe` 且前缀在 `Θ_ε` 上逐步认证，则对任意预算内故障，期望伤害 `≤(1−V*)/λ_d`；若真实故障越出 `Θ_ε`，则由引理 10 在有限延迟内触发 `unknown_regime` 并进入防守，系统**不会把名单外故障硬归因后继续进攻**。
- **定理 10（专家组合的无悔与优雅退化）**：Hedge 给出 `Regret_T≤√(T log K/2)`；若 `min_k` 平均损失 `>ℓ_0`（无可靠专家），元检测提高 ρ 并转防守，使最坏情况损失随模型误配单调有界，而不是随“自信程度”上升。ARENA 因而把 VISTA 的“归因错误 ⇒ 更自信”反转为“**归因不可靠 ⇒ 更保守**”。
- **命题（严格推广）**：`ε=0,ρ=0,Θ=ℋ`、单专家、无别名时 ARENA 退化为 VISTA；`Θ*` 落在零空间时退化为 PRISM 的不可辨识报告。故 ARENA 不推翻前两轮，而是把它们的隐含假设变成**可检验、可付费、可拒绝**的显式旋钮。
- **实时性**：视觉定位的全局检索/重定位在语义流；实时流只增锚残差投影（共享特征，<0.15ms）、CUSUM 政权检测（<0.02ms）、SRC 预算早停（<0.02ms），目标 ≤2.6ms（A94 修订契约）。

**定义 233（ARENA 闭环）** ARENA 是 VISTA 的“开放集 + 对抗 + 重定位”升级：在 VISTA 的语义流/实时流骨架上挂载 ALM（视觉定位锚图）、FLR（故障定位与重定位）、FGM（故障位姿图）、GAB（带预算对抗归因博弈）、SPC（攻防风险预算）、EPX（专家组合无悔）、STP（策略感知探针）、SRC（策略风险证书），并原位升级 RSC-V→RSC-G、WCV-V→WCV-G、CSP-V→CSP-G、AIC-V→AIC-G、J_vista→J_arena。不变式：**视觉定位、故障信念、博弈求解、专家权重与证书只在语义流；实时流只做锚残差采集、政权切换检测、前缀执行与早停，零学习写操作。**

**定义 234（视觉定位锚与锚残差）** 视觉定位 `VL(img_t,M)` 先以全局描述子做地点识别取候选，再以局部特征匹配 + PnP/RANSAC 解 6-DoF 位姿，输出多假设
`{(T_j,w_j,Σ_j)}_{j=1}^{J}`，`Σ_j` 由 inlier 数与残差估得。锚残差
`e_anc(t)=log((T̂^geo_t)^{-1}T^vis_t)∈ℝ⁶`，
其中 `T̂^geo` 为本体运动学/LiDAR 几何给出的预测位姿，`T^vis=Σ_j w_j T_j`（多假设下保留混合）。
结构性质：(i) 力偏置不移动相机，故 `∂e_anc/∂θ_force≡0` —— 这是 VISTA 的 `e_vis` 不具备的、用于分离 H_force 与 H_geo 的**独立行**；(ii) 若 `T̂^geo` 与 `T^vis` 共用同一地图，地图误差同时进入两者，锚残差**不能**独立证明地图错，此时必须在 `novelty(x)` 低时降权并标 `anchor_confounded`。
混合似然 `p(e_anc|θ,x)=Σ_j w_j N(e_anc; μ_j(θ), Σ_j+Σ_geo)`。

**定义 235（故障锚图 FAM）** 故障锚图是空间索引
`A: x ↦ (p_0(θ|x), Σ_0(θ|x), novelty(x))`，
由历史回访与离线故障注入统计得到；`p_0(θ|x)` 为地点相关故障先验（某反光角落地点的 `H_geo` 先验更高、软垫地点 `H_model` 更高），`novelty(x)` 为外观/几何覆盖新颖度。`novelty(x)` 高时：提高开放集质量 `m_unknown`、提高歧义半径 `ρ`、降低锚残差权重。FAM 是跨回合“侦察报告”，使先验地点相关，替代 VISTA 的全局均匀先验。

**定义 236（开放集故障信念与故障别名）** 故障状态 `θ∈Θ=Θ_known∪Θ_unknown` 取连续严重度与复合模式（非固定标签）。粒子信念 `bel={(θ^{(n)},w^{(n)})}` 按
`p(z_t|θ,x_t)` 更新。对参考 `θ*` 定义**故障别名集**
`Alias(z)={θ: D_KL(p(·|z,θ)‖p(·|z,θ*))≤ε_alias}`，
`alias_mass(z)=max_{[θ]∈Alias/∼} Σ_{θ'∈[θ]}w(θ')`。
`alias_mass` 高表示“不同故障在观测上等价”，必须保留多假设并输出 `alias`，**禁止 argmax 强行定标签**（VISTA 的病根）。当且仅当 `alias_mass≤τ_alias` 才允许定向处置。

**定义 237（归因绑架检测与重定位 FLR）** 边缘证据 `L_t=Σ_n w^{(n)}p(z_t|θ^{(n)},x_t)`。CUSUM
`g_t=max(0, g_{t-1}+log δ − log(L_t/L̄))`，
`L̄` 为近期均值。若 `g_t>h`，或有效样本数 `ESS=1/Σ_n(w^{(n)})²<ε_ess` 持续 k 步，则判**故障政权切换/归因绑架**：置 `unknown_regime=True`，按 FAM 先验 `p_0(θ|x)` 在开放集上重新初始化粒子，并注入质量 `m_unknown` 给 `θ_unknown`；触发 `relocalize`（视觉全局重定位 + `null_test`/`scout`）。其统计含义是**拟合优度检验**：真实故障不在模型内时，`E[log L_t]` 以 `KL(P_true‖P_model)>0` 的速率下降，故检测必在有限步内发生。检测后旧后验被**丢弃**而非继续加权——这是与 VISTA “越归因越自信”的正面切割。

**定义 238（故障位姿图与归因回环 FGM）** 节点 `(t_i,x_i,θ_i,Σ_i)`。边：
- 探针边：`e_probe=θ_j−θ_i−Δθ_probe`，信息矩阵 `Σ_probe^{-1}`；
- 一致性边：`e_cons=r−Aδ−b`，信息矩阵 `Σ_cons^{-1}`；
- 回环边：回到地点 `x` 重测时 `e_loop=θ_i−θ_j`，信息矩阵 `Σ_loop^{-1}`。
鲁棒位姿图（switchable constraints，开关 `s_e∈[0,1]`）求
`min_{θ,s} Σ_e s_e‖e_e‖²_{Σ_e}+Ψ(s_e)`。
若回环边 `‖e_loop‖²_{Σ_loop}>τ_loop` 且开关被压低，判**早先归因错误**：重开该节点、标记 `attribution_revised`，并触发 FLR。故障图因此是可被后续证据**推翻**的持久记忆，而非一次 argmax 的定论。

**定义 239（对抗故障预算集）** 对手选择故障轨迹
`θ_{1:T}∈Θ_ε={θ: Σ_t‖θ_t‖_1+λ_TVΣ_t‖θ_{t+1}−θ_t‖_1≤ε}`，
允许复合、缓慢漂移与名单外模式；可选单纯形约束 `‖θ_t‖_1≤1` 表示“至多一个主导模式”。载荷/地图不确定 `‖A−A₀‖≤ε_A`。**Θ_ε 是开放的**：不枚举标签，只约束“故障能有多大、变化能有多快”，因此未知复合故障天然落在球内。ε 由 FAM 的 `novelty` 与历史严重度分位设定。

**定义 240（归因博弈与分布鲁棒均衡 GAB）** 机器人策略 `π=(探针计划 u_{1:T}, 执行前缀 k, 膨胀 r)`，对手故障 `θ`。零和博弈
`V*(x)=max_π min_{θ∈Θ_ε} E[R_task(π,θ)−λ_d D(π,θ)]`，
`D` 为力超限/滑移/损伤，`R_task` 为进度。分布鲁棒版本：对手在 Wasserstein 球 `{Q: W(Q,P̂)≤ρ}` 内选分布，
`V*_ρ(x)=max_π min_{Q: W(Q,P̂)≤ρ} E_Q[R_task−λ_d D]`。
`ρ=0` 退化为贝叶斯、`ρ→∞` 退化为最坏情况；`ρ` 由 `novelty`、专家误配检测、`alias_mass` 自适应。归因输出为**均衡支持集** `Θ*=supp(Q*)` 与 `V*`；决策：`V*<V_safe⇒防守（defend/scout）`，`V*≥V_safe⇒进攻（execute）`。未知复合故障无需进名单，只需进预算球——这是对 VISTA 有限假设集的根本替代。

**定义 241（攻防策略与风险预算 SPC）** 每回合有限风险预算 `B`（期望伤害或力-时间积分上限）。约束 POMDP
`max_π E[R_task]−λ E[D] s.t. E[D]≤B`，
对偶变量 λ 为“风险价格”。每步比较索引：
- 进攻：`Idx_exec=E[progress]/λ`；
- 防守：`Idx_probe=(V*_{t+1}−V*_t)/λ−cost(u)`。
取较大者；`scout` 与 `defend` 同属防守动作。探针仅在能改变决策时入选（见定义 243）。安全前进可按 `η_B` 回收预算，但硬安全上限 `D_max` 不可回收；预算耗尽即 `k*=0`、强制防守。这样“何时侦察、何时进攻”由风险价格和预算内生决定，而非固定启发式。

**定义 242（专家组合无悔归因 EPX）** 专家 `{E_k}_{k=1}^K`，每个是完整归因模型（假设集/独立性假设/似然/先验/是否使用锚残差）。第 t 回合损失 `ℓ_{k,t}=1[安全违规]+c·任务遗憾`。Hedge：
`w_{k,t+1}∝w_{k,t}exp(−ηℓ_{k,t})`，`η=√(8log K/T)`。
悔界 `Regret_T=Σ_tℓ_{π_t,t}−min_kΣ_tℓ_{k,t}≤√(T log K/2)`。
误配检测：若 `min_k (1/T)Σ_tℓ_{k,t}>ℓ_0`（**没有专家可靠**），则提高 `ρ`、降低 `V_safe` 容忍、转防守，并触发 FLR。组合输出为加权归因 `Σ_k w_k θ̂_k` 与加权策略；专家权重 `w` 即“联赛排行榜”。长期看，若机器人与对手均为无悔学习者，经验博弈收敛到粗相关均衡；但该保证是**平均/渐近**的，必须与逐步 SRC 的硬安全并行使用。

**定义 243（策略感知探针 STP）** 
`u*=argmax_{u∈A}[V*_{t+1}(bel(·|u))−V*_t]−cost(u)`，
s.t. 预测 `f_n≤f_safe`、形变 `≤ε_strain`；若采用 `u` 后 `argmax` 决策（防守/进攻、膨胀方向、是否重定位）不变，则 `u*=∅`，不探。AFA 最大化后验熵/故障互信息，IDP 最大化可辨识性增益；STP 最大化**决策价值**：可辨识但不改变打法时仍不探，因此比 AFA/IDP 更省风险预算。易损物体只允许 `visual_probe/relocalize` 类零接触动作。

**定义 244（策略风险证书 SRC）** 逐步风险 `ρ_s=min_{θ∈Θ_ε∩supp(bel)} margin_s(θ)`。认证前缀
`k*=max{k: min_{θ∈Θ_ε}P[∃s≤k: margin_s(θ)<0]≤α_step ∧ V*_{1:k}≥V_safe ∧ Σ_{s≤k}E[D_s]≤B}`。
若 `alias_mass>τ_alias`、`unknown_regime=True`、或预算耗尽，则 `k*=0`，强制 `defend/relocalize`。与 CSC 的区别：CSC 在“归因后验支持集”上验证并给出块级 `k*`；SRC 在**预算集最坏情况**上验证，并用风险预算作为可耗竭资源，且允许“承认不知道”而停。

**定义 245（RSC-G 均衡定向膨胀）** 由对手最优响应 `Q*` 取各方向分位
`r_m=Quantile_{Q*}(|θ_m|,1−α_m)`；只膨胀 `Q*` 支持的模态。可辨识零空间方向对所有球**联合**膨胀并置 `unidentifiable=True`；若 `Q*` 给 `θ_unknown` 的质量高，则全局膨胀并置 `safe_mode`。融合
`r=√(Σ_m r_m²)`。
相比 VISTA 的“按单点后验膨胀”，RSC-G 按“对手会打哪里”膨胀：在预算内最坏方向保守、在对手不会打的方向保持精度，避免为不存在的故障过度保守。

**定义 246（WCV-G 博弈最坏编译）** 在 `Q*` 下做 DRO-CVaR 编译
`min_{K∈𝒦} CVaR_{α}^{Q*}[exec_loss(K,θ)]`
s.t. 对所有 `θ∈Θ*` 安全核交集非空；`V*<V_safe` 或交集为空时回退 `B(φ̂,r)` 并置 `defend_required=True`。尾部采样按 `Q*`（可用对偶重采样/场景优化），而非 VISTA 的后验采样。目标是让编译出的 `K_safe` 在对手最优分布下而非“平均后验”下安全。

**定义 247（CSP-G / AIC-G 竞赛规划与对抗认证）** CSP-G 在块边代价增 `λ_g·(−V*)+λ_ρ·ρ+λ_B·B_spent`；元技能：
- `scout`：主动侦察，更新 FAM 与专家权重（不接触或轻接触）；
- `relocalize`：FLR 全局重定位；
- `defend`：后退/柔顺/等待/降低阻抗。
AIC-G 干扰集 `ℰ_G=ℰ_V×ℰ_loc×ℰ_game`：`ℰ_loc` 含视觉定位感知别名（重复纹理/对称）、反光/透明、地图投毒/过期/坐标漂移；`ℰ_game` 含对手主动遮挡、移动物体、制造共因（同一 OOD 物体同时骗几何与视觉）。认证改为**锦标赛式 worst-case**：在 `n_cert` 个对抗场景（含留出的“名单外”场景）上取最坏，而非平均；`J_dir` 增 `loc_alias_ver`、`map_poison_ver`、`game_scenario_ver`。

**定义 248（ARENA 证书 J_arena 与对 VISTA 的退化）**
`J_arena=(J_vista, game_value, ambiguity_radius, relocalization_flag, anchor_cov, alias_mass, expert_weights_hash, risk_budget_spent, unknown_regime, aic_g_ver)`。
验证规则
`Valid(J_arena) ⇔ Valid(J_vista)`
`∧ (alias_mass≤τ_alias ∨ 已 relocalize)`
`∧ (V*≥V_safe ∨ 已 defend)`
`∧ 风险预算未超（B_spent≤B）`
`∧ 前缀在 Q* 下认证`
`∧ (anchor 不可用/受混杂 ⇒ 标 visual_unobservable 且未用于否决接触)`
`∧ aic_g_ver 为当前版本`。
**关键变化：不再要求“归因确定”（VISTA 的 `max_H P≥1−δ_fi`），只要求“最坏情况可证（V*≥V_safe）或已诚实进入未知安全模式（unknown_regime ∧ defend）”。** 审计链新增：为何进攻/防守（V*）、为何停（SRC/预算）、是否迷失（relocalization_flag）、锚是否可信（anchor_cov/novelty）、哪个专家在领先（expert_weights_hash）。
退化：`ε=0,ρ=0,Θ=ℋ`、单专家、无别名时严格退回 VISTA；`Θ*` 落在可辨识零空间时退回 PRISM 式“不可辨识”报告。故 ARENA 是前两轮的严格推广，并把它们的隐含假设变成可检验、可付费、可拒绝的显式旋钮。

### IP-225 FLR（故障定位与重定位）

```python
class FaultLocalizer:
    """开放集粒子信念 + 别名质量 + kidnapping 检测。语义流。"""
    def __init__(self, fault_map, eps_ess=0.3, h=4.0, k_persist=3, tau_alias=0.6):
        self.map, self.eps_ess, self.h = fault_map, eps_ess, h
        self.k_persist, self.tau_alias = k_persist, tau_alias
        self.g, self.bad = 0.0, 0

    def update(self, resid, e_anc, x):
        L = self._marginal_likelihood(resid, e_anc, x)
        self.g = max(0.0, self.g + np.log(1.05) - np.log(L / self._baseline + 1e-12))
        self.particles = self._reweight(self.particles, resid, e_anc, x)
        ess = 1.0 / np.sum([w * w for _, w in self.particles])
        self.bad = self.bad + 1 if ess < self.eps_ess else 0
        if self.g > self.h or self.bad >= self.k_persist:
            return self.relocalize(x), True
        return self.particles, False

    def relocalize(self, x):
        prior = self.map.at(x)                       # 地点相关 p0(theta|x)
        self.g, self.bad = 0.0, 0
        self.particles = self._sample_open_set(prior, m_unknown=0.25)
        return self.particles

    def alias_mass(self, z):
        classes = self._equiv_classes(z, eps_alias=0.1)
        return max(sum(w for _, w in c) for c in classes)

    def marginalize(self):
        return self._weighted_modes(self.particles)  # 保留多假设，不 argmax
```

### IP-229 EPX（专家组合无悔）

```python
class ExpertPortfolio:
    def __init__(self, experts, eta=None, ell0=0.35):
        self.experts, self.eta, self.ell0 = experts, eta, ell0
        self.w = np.full(len(experts), 1.0 / len(experts))

    def update(self, losses):
        self.w *= np.exp(-self.eta * np.asarray(losses))
        self.w /= self.w.sum()

    def misspecified(self):
        avg = np.array([np.mean(self.hist[k]) for k in range(len(self.experts))])
        return avg.min() > self.ell0           # 没有专家可靠 → 未知故障/模型误配

    def attribute(self, z):
        return sum(wk * ek.attribute(z) for wk, ek in zip(self.w, self.experts))
```

```python
class StrategyProbe:
    PROBES = ('null_test', 'visual_probe', 'scout', 'press', 'rub', 'tap', 'lift')

    def choose(self, bel, V_now, f_safe, fragile):
        best, best_gain = None, 0.0
        for u in self.PROBES:
            if fragile and u not in ('null_test', 'visual_probe', 'scout'):
                continue
            if predicts(f_n=u) > f_safe or predicts(strain=u) > EPS_STRAIN:
                continue
            V_next = expected_game_value(bel, u)     # 更新后的 V*
            gain = (V_next - V_now) - probe_cost(u)
            if gain > best_gain:
                best, best_gain = u, gain
        return best, best_gain                       # None 表示“不探，按当前策略打”
```

```python
class StrategyRiskCertificate:
    def certified_prefix(self, A, bel, Q_star, B_left, alpha_step, V_safe):
        k_best = 0
        for k in range(1, len(A) + 1):
            worst = min(safety_margin(A[:k], theta) for theta in support(Q_star))
            viol = max(prob_violation(A[:k], theta) for theta in support(Q_star))
            spend = max(expected_damage(A[:k], theta) for theta in support(Q_star))
            if worst < 0 or viol > alpha_step or spend > B_left:
                break
            if game_value(A[:k], Q_star) < V_safe:
                break
            k_best = k
        return k_best                                # 0 ⇒ 防守/重定位
```

```python
def ARENA_round(M, obs):
    V, T, P, L, P_cloud, W, tactile, img, depth, flow = obs
    # ———— 语义流 ————
    M.lsf.update_geometry(P_cloud)

    if k_star == 0:

    # 8) 执行 + 实时早停
    for a in res.A[:k_star]:

        if M.rt.regime_break(bel):
```

## 4. 推导

**引理 9（锚残差的结构分离）** 设局部线性化 `e_anc ≈ J_geo θ_geo + J_map θ_map + J_cal θ_cal + ε`。力偏置只改变接触力读数，不改变相机位姿，故 `J_force=0`；因此在零力窗内，`e_anc` 为 H_force 提供一行**恒零载荷**证据，把 H_force 与 H_geo 的签名列分开，改善 `SᵀΣ⁻¹S` 的秩与条件数 `κ_fi`。若 `T̂^geo` 与 `T^vis` 共用地图，`J_geo` 与 `J_map` 共线，`e_anc` 退化为几何误差的复制，此时只能由 `novelty` 标 `anchor_confounded` 并降权——**这说明锚是结构化证据而非独立真值**。∎

**引理 10（归因绑架检测与假自信时长）** 令 `P_0` 为模型预测分布、`P_1` 为真实故障分布。CUSUM 对 `P_1` 的平均检测延迟 `E[τ]≈h/KL(P_1‖P_0)`（h 为阈值），虚警率 `≈e^{−h}` 量级。当真实故障不在 Θ 内时，`E[log L_t]` 相对基线以 `KL(P_true‖P_model)>0` 的速率下降，故 `g_t` 单调上升，FLR 在 `O(h/KL)` 步内触发。触发后旧粒子被丢弃并重初始化，于是“已归因 ⇒ 继续自信执行”的时长期望有界。∎

**定理 9（博弈鲁棒安全）** 设 `V*≥V_safe` 且 SRC 对前缀 `k*` 在 `Θ_ε` 上逐步认证、风险预算 `B` 未超。则对任意 `θ∈Θ_ε`，
`E[D(π,θ)] ≤ (R_task^max − V*)/λ_d ≤ (R_task^max − V_safe)/λ_d`。
若真实故障 `θ_true∉Θ_ε`，由引理 10 在有限延迟内 `unknown_regime=True`，SRC 置 `k*=0` 并 `defend`，故系统不会在名单外故障上继续进攻。合并得：在预算内伤害有界，在预算外则在有界延迟内进入安全模式。∎

**定理 10（专家组合的无悔与优雅退化）** Hedge 的经典界给出 `Regret_T≤√(T log K/2)`，即平均损失不超过事后最优专家的平均损失加 `O(√(log K/T))`。若 `min_k (1/T)Σ_tℓ_{k,t}>ℓ_0`，说明所有专家都不可靠（模型误配或未知故障），EPX 提高 `ρ` 并把 `V_safe` 容忍下调、转防守。由于 `V*_ρ` 关于 ρ 单调不增而伤害界关于 ρ 单调收紧，最坏伤害随误配程度**有界**，不会因“自信”上升。故 ARENA 把 VISTA 的“归因错误 ⇒ 更自信”反转为“归因不可靠 ⇒ 更保守”。∎

**命题（严格推广）** 取 `ε=0, ρ=0, Θ=ℋ`、单专家、`alias_mass=0`、FAM 均匀先验，则 GAB 退化为 `max_π E[R−λ_dD]` 在 ℋ 上取最坏，等价于 VISTA 的“后验支持集 + 定向处置”；FLR 不触发；SRC 退化为 CSC。若 `Θ*` 落在 `S` 的零空间，GAB 无法定向，RSC-G 联合膨胀并输出 `unidentifiable`，与 PRISM 一致。故 ARENA 不推翻前两轮，而把它们的隐含假设显式化为 `(ε, ρ, alias_mass, expert regret)` 四个可检验旋钮。∎

**命题（探针的决策价值）** 设 AFA 的互信息探针使后验熵下降 `ΔH`，但若 `argmax` 决策不变，则 STP 的期望增益为 0、选择不探；反之若某探针不降低熵却能把 `V*` 从 `V_safe` 下方抬到上方，则 STP 选择它而 AFA 不会。故 STP 的决策价值 `ΔV*` 与决策改变一一对应，在风险预算固定时支配 AFA/IDP。∎

## 7. 已知风险

**一句话**：ARENA 把“归因对不对”换成“在预算 `Θ_ε` 内最坏能有多坏”，但证书只对**预算内部**成立——若真实复合故障越出 ε，或视觉定位与几何共用同一张被投毒的地图而重新变成共因，系统仍可能把“名单外故障”当成“预算内可控故障”；而无悔/均衡保证是**平均或渐近**的，安全却必须**逐回合**成立，一次不可逆越界不会被悔界抵消，于是“已认证鲁棒”可能变成 VISTA“已归因”之后的新一代假自信——这是本轮全部 minimax、专家组合与重定位论证共同依赖的隐藏假设（A94）。

**次级风险与缓解**：
1. **预算 ε 设定过紧**：越界故障被当成可控；缓解：用 FAM `novelty` 与历史严重度分位上浮 ε，并保留 `unknown` 质量；SLD 式在线扩张 ε，越界即重定位。
2. **视觉定位与几何共用地图的共因**：锚残差无法独立证明地图错；缓解：标 `anchor_confounded`，引入非地图锚（IMU/轮式里程/外部固定相机）作为第二锚，或在地图低覆盖区禁用锚否决。
3. **感知别名导致多假设爆炸**：粒子数增长；缓解：等价类合并、`alias_mass` 截断、触发 `scout` 主动去别名，而非强行 argmax。
4. **博弈求解实时性**：DRO/minimax 场景优化在语义流仍可能超时；缓解：场景缓存、对偶梯度热启动、只在 `V*` 接近 `V_safe` 时精细求解，否则用界。
5. **专家组合的“平均安全”陷阱**：无悔是平均损失，单回合可灾难；缓解：SRC 的逐步硬约束独立于专家，任何专家都不得突破风险预算；专家只影响“选哪个模型”，不影响硬安全门。
6. **风险预算被进度“刷分”**：若允许无限回收预算，策略会冒险；缓解：硬上限 `D_max` 不可回收、回收率 `η_B<1`、预算记账不可抵扣（类似步骤分的安全扣分）。
7. **回环修正引发震荡**：反复重开节点可能不稳定；缓解：开关变量 + 滞回阈值 + 每个节点限次重开；修正必须经 FGM 全局一致后才写回。
8. **锦标赛式认证对留出场景过拟合**：`ℰ_game` 覆盖不到真实对手；缓解：保留未见场景集、定期轮换、报告最坏而非平均；把“未见场景最坏值”作为一等指标。

---

**本轮结论（一句话）**：第 65 轮把“可证伪”升级为“可归因”，本轮把“可归因”升级为“**可怀疑自己的归因**”——用视觉定位锚、开放集对抗预算与重定位/回环，把“归因错误 ⇒ 更自信”反转为“归因不可靠 ⇒ 更保守”。
