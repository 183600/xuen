# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「动力学」×「轮足机器人」）

> 第 54 轮把技能组合从能力匹配推进到动作空间与鲁棒性双证书，但其动作剖面 `α_S` 本质是运动学/可达性描述：它回答“这个动作能不能做”，不回答“在这个速度、坡度、载荷和接触模式下做，会不会滑、翻、失稳或烧电机”。轮足机器人的核心恰恰是动力学：同一组轮速/关节角在滚动模式可行，在越障/落脚模式可能因动量、摩擦锥和冲击而不可行。本轮引入 **动力学模式剖面、混合模式图、动态切换证书、模型阶次契约、保形动力学包络、动力学残差解释**，把“动作可达”升级为“动力学可证”。核心假设：**H22**：轮足技能组合的失败主要发生在接触模式切换处，而非单个技能内部；**H23**：云端降阶模型与边端全阶模型之间的动力学差异必须在证书中显式预算，否则云端可行计划会在边端系统性失稳；**H24**：动力学失败必须能归因到 traction / stability / torque / impact / model 五类残差之一，否则无法驱动模式级重规划。

## 0. 直觉与动机

**灵感 1（从动作剖面到动力学期约剖面）**
直觉：技能 `S` 的动作剖面 `α_S` 只说明动作在集合意义上“可达”，但轮足机器人真正的约束是 **接触力是否落在摩擦锥/接触力旋量锥内**。把每个技能看成状态-模式-参数空间上的一个“动力学期约体” `D_S = {δ_S ≥ 0}`，其中 `δ_S` 是接触力旋量锥（CWC）余量、关节力矩余量、速度余量和载荷余量的最小值。组合时先问：`D_{S_i}` 的后继是否落入 `D_{S_j}` 的前集，而不是只问动作集合是否相交。

**灵感 2（轮足的本质是混合模式图）**
直觉：轮足机器人不是“轮式 + 腿式”两个技能的简单相加，而是一个 **混合自动机**：轮滚、轮驱、腿撑、轮腿混合、腾空等接触模式之间切换。技能组合的可行性由 `(技能, 接触模式)` 节点图和带冲击/动量约束的边决定。特别是 `轮滚 → 腿撑` 的越障切换，往往决定整条长程任务能否完成。

**灵感 3（动态切换证书：把“能切”变成“切换后仍在安全域”）**
直觉：切换瞬间的冲击和动量损失最危险。需要一张 **动态切换证书 DTC**：切换前状态在源技能不变量内；冲击映射后的后状态落在目标技能的动力学期约域内；冲击冲量、能量损失、摩擦锥余量均在预算内。这样，组合图上的每条边都可检查，而不是靠仿真试错。

**灵感 4（模型阶次契约：云端粗、边端细，但误差要入账）**
直觉：云端用降阶模型（质心动力学 + 轮式倒立摆 + 集总接触）做长程模式规划；边端用全阶刚体/柔顺接触模型执行。两者之间的模型误差 `ε_m` 必须显式进入证书：云端的动力学余量要扣除 `L_δ ε_m` 才能下发给边端；边端用广义动量残差监视器实时校验，一旦残差超界就触发回退/重规划。这把第 54 轮的云边动作契约升级为 **模型阶次契约**。

**灵感 5（保形动力学包络与安全主动探测）**
直觉：仿真得到的动力学余量不能直接当真实保证。用 **保形预测** 把仿真/少量真机标定转成有限样本覆盖保证：`P(δ_true ≥ δ_pred − q_{1−α}) ≥ 1−α`。当包络过于保守时，边端在 **控制屏障函数（CBF）安全集** 内做小幅度主动激励（轮速/关节力矩探针），只降低不确定性、不越安全边界；再用自适应保形更新包络。

**灵感 6（动力学残差解释驱动模式级重规划）**
直觉：失败不是“技能坏了”，而是某个动力学约束先破。用动量残差观测器把失败分解为 traction / impact / torque / model / state-estimation 五类，解释结果直接映射到修复动作：降速、改模式序、加腿撑、重估 `μ`、回退到保守包络。这使第 54 轮的 Explain 从动作空间根因升级为动力学根因。

## 1. 形式化定义（增量：定义 121–129）

**定义 121（混合接触模式）**
混合接触模式 `m = (C_w, C_f, C_a, σ)`：`C_w` 为轮-地接触集，`C_f` 为足-地接触集，`C_a` 为腾空相位，`σ` 为步态相位/接触调度。`m` 可行当且仅当接触非穿透、运动学闭合与驱动约束同时成立。模式切换 `m→m'` 由守卫 `G_{m→m'}` 与复位映射 `Δ_{m→m'}` 定义。

**定义 122（接触力旋量锥与动力学余量）**
对接触集 `C(m)`，接触力旋量锥
```
W_m = { G_m λ : λ ∈ FC_m }
FC_m = ∏_{i∈C(m)} { (f_i, τ_i) : f_{i,n} ≥ 0, ||f_{i,t}|| ≤ μ_i f_{i,n}, |τ_{i,roll}| ≤ τ_{r,i,max} }
```
其中 `G_m` 为抓取映射，`λ` 为全部接触力/力矩。任务动作 `a` 在状态 `x` 处的需求旋量
`w_req(x,a) = [m(\ddot{p}_c − g); \dot{L}]`。
动力学可行性要求 `w_req ∈ W_m`。定义归一化余量
```
η_cwc(x,m,a) = max_λ min_j s_j(λ)/s_0
              s.t. G_m λ = w_req(x,a), λ ∈ FC_m
```
`η_cwc ≥ 0` 表示存在满足需求的接触力分配且离锥边界至少 `η_cwc`；不可行时 `η_cwc < 0`，其绝对值可解释为到锥边界的距离。

**定义 123（动力学期约剖面）**
技能 `S` 在参数 `θ`（摩擦、刚度、质量、载荷、坡度）下的动力学期约剖面
```
δ_S(x,m,a;θ) = min{ η_cwc, η_τ, η_v, η_imp, η_load }
η_τ = min_j (τ_j^max − |τ_j|)/τ_j^max
η_v = min_j (v_j^max − |v_j|)/v_j^max
η_imp = 1 − ||Δv||/Δv^max
η_load = min_i N_i/N_i^0
```
动力学期约域 `D_S = {(x,m,a,θ) : δ_S ≥ 0}`。若 `δ_S ≥ η_min`，则技能在该状态-模式-动作上动态可部署。`δ_S` 与第 54 轮 `α_S` 互补：`α_S` 管“动作可达”，`δ_S` 管“动力学可承受”。

**定义 124（动力学兼容性）**
令 `Reach_i(τ)` 为技能 `S_i` 在策略 `π_i` 与参数不确定集 `Θ` 下的 `τ` 步可达集，`Pre_j^{m_j}` 为 `D_{S_j}` 在模式 `m_j` 下的控制前集。定义
```
dcompat(S_i,S_j | m_i,m_j) =
  Pr_{x~Unif(Reach_i(τ))}[ x ∈ Pre_j^{m_j}
    ∧ Δ_{ij}(x) ∈ D_{S_j}
    ∧ δ_trans(x) ≥ η_min ]
```
要求 `dcompat ≥ θ_d`。这是概率意义下的“动力学兼容”，与第 54 轮动作 Jaccard 系数 `compat` 正交。

**定义 125（混合模式图）**
`G_H = (V_H, E_H)`，节点 `V_H = {(S,m) : S∈𝒮, m∈ℳ}`，边
`E_H = {((S_i,m_i),(S_j,m_j)) : dcompat ≥ θ_d ∧ DTC 有效}`。每条边附带
`C_dyn = (Reach_i, DTC, η_min, P_impact, C_mo)`。

**定义 126（动态切换证书 DTC）**
边 `i→j` 的证书
`T_{ij} = (X_i^pre, X_j^post, Δ_{ij}, J_max, E_loss, η_trans, evidence)`
满足：
1. `X_i^pre ⊆ D_{S_i}`，且在 `π_i` 下对时长 `τ` 不变；
2. `X_j^post = Δ_{ij}(X_i^pre) ⊆ D_{S_j}`；
3. 冲击冲量 `J_impact = ||∫_{t^-}^{t^+} f_c dt|| ≤ J_max`；
4. 切换全程 `min_t δ_trans(t) ≥ η_min`；
5. 能量损失 `E_loss ≤ E_max`，且无超出执行器能力的负功。
全部条件必须在保形下界上成立；`evidence` 至少包含仿真 rollout、边端回放与接触参数标定记录。

**定义 127（模型阶次契约）**
`C_mo = (f_c, f_e, X_core, ε_m, L_δ, r_max, revalidate)`：
- `f_c` 为云端降阶模型，`f_e` 为边端全阶模型；
- 在证书核心域 `X_core` 上 `||f_e − f_c||_W ≤ ε_m`；
- 动力学余量 Lipschitz：`|δ_e − δ_c| ≤ L_δ ε_m`；
- 边端广义动量残差 `r` 满足 `||r|| ≤ r_max`；
- 云端证书在边端有效的充分条件：`δ_c ≥ η_min + L_δ ε_m` 且 `||r|| ≤ r_max`；否则触发 `revalidate`。

**定义 128（保形动力学包络）**
给定标定轨迹的非一致性分数
`r_i = max_t [δ_pred(x_t,m_t,a_t) − δ_true(x_t,m_t,a_t)]`。
取有限样本分位数 `q_{1−α} = Quantile(⌈(n+1)(1−α)⌉/n; {r_i})`，定义
`δ_LCB = δ_pred − q_{1−α}`，`D_S^{1−α} = {δ_LCB ≥ η_min}`。
在可交换性下，`P(δ_true ≥ δ_LCB) ≥ 1−α`。分布漂移时用 ACI：
`α_{t+1} = α_t + γ(α − err_t)`，`err_t = 1[δ_true < δ_LCB]`。

**定义 129（动力学残差解释）**
广义动量 `p = M(q)\dot{q}`，动量观测器残差 `r = K(p − p̂)`。按接触模式与观测器通道分解
`r = r_trac + r_imp + r_torque + r_model + r_state`。
动力学解释
`Explain_dyn = (j*, |r_{j*}|/r_{j*}^max, repair)`，`j* = argmax_j |r_j|/r_j^max`。
修复映射：
- traction → 降速 / 增加腿法向载荷 / 绕行更粗糙地形；
- impact → 降低落差 / 改接触顺序 / 增大柔顺；
- torque → 减载 / 换模式 / 延长支撑相；
- model → 重估 `μ, k, m` / 切保守包络；
- state → 重新标定状态估计 / 降速通过。

## 2. 关键算法伪代码

### IP-121 DRP（Dynamics Regime Profiling）

```python
def dynamics_profile(skill, modes, theta_samples, sim, alpha):
    data = []
    for theta in theta_samples:
        for traj in sim.rollout(skill.policy, theta, modes):
            for (x, m, a) in traj:
                eta = cwc_margin_qp(x, m, a)          # min slack of contact wrench cone
                eta = min(eta, torque_margin(x, a),
                               speed_margin(x, a),
                               load_margin(x, m))
                data.append((x, m, a, theta, eta))

    f_eta = fit_margin_regressor(data)                 # 神经/分段线性/区间模型
    scores = [f_eta(x, m, a) - eta for (x, m, a, _, eta) in data]
    q = conformal_quantile(scores, alpha)              # 有限样本修正
    return DynamicsProfile(f_eta, q,
                           domain=lambda x, m, a: f_eta(x, m, a) - q)
```

### IP-122 HMG（Hybrid Mode Graph）

```python
def build_hybrid_mode_graph(skills, modes, theta_set, theta_d, eta_min, alpha):
    G = nx.DiGraph()
    for S in skills:
        for m in modes:
            G.add_node((S.id, m),
                       profile=dynamics_profile(S, [m], theta_set, sim, alpha))

    for (Si, mi), (Sj, mj) in itertools.product(G.nodes, repeat=2):
        if (Si, mi) == (Sj, mj):
            continue
        R = reachable_set(Si, mi, theta_set)
        if dynamics_compat(R, Sj, mj, eta_min) < theta_d:
            continue
        T = check_dtc(Si, mi, Sj, mj, R, eta_min)
        if T.valid:
            G.add_edge((Si, mi), (Sj, mj),
                       dcompat=dynamics_compat(R, Sj, mj, eta_min),
                       dtc=T,
                       cost=transition_cost(Si, mi, Sj, mj))
    return G
```

### IP-123 DTC（Dynamic Transition Certificate）

```python
def check_dtc(Si, mi, Sj, mj, R, eta_min):
    Xpre = invariant_core(Si, mi) & R
    if not subset(Xpre, dynamics_domain(Si, mi, eta_min)):
        return DTC(False, reason='source_not_invariant')

    Xpost = impact_map(mi, mj, Xpre)
    if not subset(Xpost, dynamics_domain(Sj, mj, eta_min)):
        return DTC(False, reason='post_not_in_target')

    J = max_impact_impulse(Xpre, mi, mj)
    if J > Jmax:
        return DTC(False, reason='impact_budget')

    eta_t = min_over_transition(Si, mi, Sj, mj, Xpre)
    if eta_t < eta_min:
        return DTC(False, reason='margin_violation')

    return DTC(True, Xpre, Xpost, J, energy_loss(Si, Sj), eta_t)
```

### IP-124 MOC（Model-Order Contract）与边端执行

```python
def edge_execute(plan, f_e, C_mo, eta_min):
    x = plan.initial_state
    for (S, m, a_c) in plan.steps:
        a_e = gamma_ce(a_c)
        delta_c = S.profile.predict(x, m, a_e)

        # 云端余量必须先扣除模型阶次误差
        if delta_c < eta_min + C_mo.L_delta * C_mo.eps:
            return ('reject', 'cloud_margin_after_model_budget', delta_c)

        r = momentum_observer(f_e, x, tau)
        if norm(r) > C_mo.r_max:
            return ('reject', explain_dyn(r, m))

        tau = clf_cbf_qp(S.policy, x, m, a_e, delta_c, C_mo)
        x = f_e.step(x, tau)
    return ('ok', x)
```

### IP-125 CAR（Conformal Adaptive Re-profiling）

```python
def conformal_update(profile, new_traj, alpha, gamma=0.05):
    scores = [profile.predict(x, m, a) - eta_true
              for (x, m, a, eta_true) in new_traj]
    profile.calib.extend(scores)
    q = conformal_quantile(profile.calib, profile.alpha)

    err = mean(1 for s in scores if s > q)
    if drift_detected(profile.calib, scores):
        profile.alpha = profile.alpha + gamma * (alpha - err)
        profile.alpha = clip(profile.alpha, 0.001, 0.2)

    return profile.with_(q=q)
```

### IP-126 DRE（Dynamics Residual Explanation）

```python
def explain_dyn(r, mode):
    parts = decompose_residual(r, mode)       # trac / imp / torque / model / state
    j = argmax(parts, key=lambda k: abs(parts[k]) / rmax[k])
    repair = {
        'traction': ['slow_down', 'increase_leg_normal_force', 'detour'],
        'impact':   ['reduce_drop', 'reorder_contacts', 'increase_compliance'],
        'torque':   ['reduce_payload', 'switch_mode', 'extend_stance'],
        'model':    ['reestimate_mu_k_m', 'conservative_envelope'],
        'state':    ['recalibrate_estimator', 'slow_down'],
    }[j]
    return ExplainDyn(root_cause=j, score=abs(parts[j]) / rmax[j], repair=repair)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| DRP | O(N_θ·T·|ℳ|·C_QP) | O(N_θ·T) | CWC-QP 精确、保形可交换性 |
| HMG | O(|V_H|²·(Reach + DTC)) | O(|V_H|²) | dcompat 阈值 sound、DTC 覆盖切换 |
| DTC | O(|X_pre|·C_QP) | O(|X_pre|) | 前/后不变集包含、冲量与能量预算 |
| MOC | O(C_QP + n²) 每控制周期 | O(n²) | 误差界 `ε_m`、Lipschitz 常数、残差界 |
| CAR | O(n log n) | O(n) | 保形覆盖、ACI 漂移适应 |
| DRE | O(n²) | O(n) | 残差可分解、修复映射可执行 |

**正确性定理（Dynamics-Certified Hybrid Composition Soundness）**

假设：
- **(A34)** 每个 `(S,m)` 存在控制不变集 `X_{S,m} ⊆ D_S` 及 barrier 证书 `h_{S,m} ≥ 0`；
- **(A35)** 每条 DTC 边满足 `X_j^post ⊆ D_{S_j}`、`J ≤ J_max`、`η_trans ≥ η_min`；
- **(A36)** 每个 `(S,m)` 的保形包络满足 `P(δ_true ≥ δ_LCB) ≥ 1−α`；
- **(A37)** 模型阶次契约满足 `|δ_e − δ_c| ≤ L_δ ε_m`，且 `||r|| ≤ r_max ⇒ δ_e ≥ δ_c − L_δ ε_m`；
- **(A38)** 切换冲击事件与模型失配事件按 union bound 计入。

则对含 `k` 个技能、`k−1` 次切换的组合计划：
```
P_success ≥ 1 − Σ_i α_i
              − Σ_e P(J_e > J_max)
              − P(∃t: ||r_t|| > r_max)
              − P(δ_c < η_min + L_δ ε_m)
```
**证明草图**：在每段技能内，barrier 证书保证状态不离开 `D_{S_i}`；DTC 保证切换后状态进入下一段动力学期约域；保形下界把真实 `δ` 换成有覆盖保证的 `δ_LCB`；模型阶次契约消耗 `L_δ ε_m` 余量；最后对 `k` 个覆盖事件、`k−1` 个冲击事件和残差越界事件做 union bound。

**实用推论（组合余量）**
```
δ_comp = min_i δ_{S_i}^LCB − L_δ ε_m − Σ_e Δη_e
Δη_e = max(0, η_pre(e) − η_post(e))
```
仅当 `δ_comp ≥ η_min` 时部署。该推论把证书检查变成标量比较，便于在云端做路径剪枝。

```python
def dynamics_profile(skill, modes, theta_samples, sim, alpha):
    data = []
    for theta in theta_samples:
        for traj in sim.rollout(skill.policy, theta, modes):
            for (x, m, a) in traj:
                eta_cwc = cwc_margin_qp(x, m, a)       # 接触力旋量锥 QP
                eta = min(eta_cwc,
                          torque_margin(x, a),
                          speed_margin(x, a),
                          impact_margin(x, m),
                          load_margin(x, m))
                data.append((x, m, a, theta, eta))

    f_eta = fit_margin_regressor(data)                 # 神经/分段线性/区间模型
    scores = [f_eta(x, m, a) - eta for (x, m, a, _, eta) in data]
    q = conformal_quantile(scores, alpha)              # ⌈(n+1)(1-α)⌉/n 分位
    return DynamicsProfile(f_eta, q,
                           domain=lambda x, m, a: f_eta(x, m, a) - q)

def cwc_margin_qp(x, m, a):
    w = required_wrench(x, a)
    # max min slack，s.t. G_m λ = w, λ ∈ FC_m
    eta, lam = solve_qp(max_min_slack, w, G(m), FC(m))
    return eta

def load_margin(x, m):
    return min(N_i(x, m) / N_i_ref for i in contacts(m))
```

### IP-122 HMG

```python
def build_hybrid_mode_graph(skills, modes, theta_set, theta_d, eta_min, alpha):
    G = nx.DiGraph()

    for S in skills:
        for m in modes:
            prof = dynamics_profile(S, [m], theta_set, sim, alpha)
            G.add_node((S.id, m), profile=prof)

    for (Si, mi), (Sj, mj) in itertools.product(G.nodes, repeat=2):
        if (Si, mi) == (Sj, mj):
            continue
        R = reachable_set(Si, mi, theta_set)
        dc = dynamics_compat(R, Sj, mj, eta_min)
        if dc < theta_d:
            continue
        T = check_dtc(Si, mi, Sj, mj, R, eta_min)
        if T.valid:
            G.add_edge((Si, mi), (Sj, mj),
                       dcompat=dc,
                       dtc=T,
                       cost=transition_cost(Si, mi, Sj, mj))
    return G

def dynamics_compat(R, Sj, mj, eta_min):
    ok = [x for x in R
          if x in predecessor(Sj, mj)
          and impact_map(mi, mj, x) in dynamics_domain(Sj, mj, eta_min)
          and min_margin_transition(x) >= eta_min]
    return len(ok) / max(1, len(R))
```

```python
def check_dtc(Si, mi, Sj, mj, R, eta_min):
    Xpre = invariant_core(Si, mi) & R
    if not subset(Xpre, dynamics_domain(Si, mi, eta_min)):
        return DTC(False, reason='source_not_invariant')

    if not subset(Xpost, dynamics_domain(Sj, mj, eta_min)):
```

```python
def edge_execute(plan, f_e, C_mo, eta_min):
    x = plan.initial_state
    trajectory = []

    for (S, m, a_c) in plan.steps:
        a_e = gamma_ce(a_c)
        delta_c = S.profile.predict(x, m, a_e)

        # 边端动量残差在线否决

        if norm(r) > C_mo.r_max:

            clf=S.clf, cbf=S.cbf,
            margin=delta_c - eta_min,
            model=f_e,
        )
        x = f_e.step(x, tau)
        trajectory.append((x, m, a_e, delta_c, r))
```

### IP-125 CAR

```python
def conformal_update(profile, new_traj, alpha, gamma=0.05):
    scores = [profile.predict(x, m, a) - eta_true
              for (x, m, a, eta_true) in new_traj]
    profile.calib.extend(scores)

    q = conformal_quantile(profile.calib, profile.alpha)
    err = mean(s > q for s in scores)

    if drift_detected(profile.calib, scores):
        profile.alpha = clip(profile.alpha + gamma * (alpha - err),
                             0.001, 0.2)

    profile.q = q
    return profile

def conformal_quantile(scores, alpha):
    n = len(scores)
    k = math.ceil((n + 1) * (1 - alpha))
    return sorted(scores)[min(k, n) - 1]
```

## 4. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性保证 |
|---|---|---|---|
| DRP | O(N_θ·T·|ℳ|·C_QP) | O(N_θ·T) | CWC-QP 精确、保形可交换性 |
| HMG | O(|V_H|²·(Reach + DTC)) | O(|V_H|²+|E_H|) | dcompat 阈值 sound、DTC 覆盖切换 |
| DTC | O(|X_pre|·C_QP) | O(|X_pre|) | 前/后不变集包含、冲量/能量预算 |
| MOC | O(C_QP+n²) 每控制周期 | O(n²) | `ε_m` 误差界、Lipschitz、残差界 |
| CAR | O(n log n) | O(n) | 保形覆盖、ACI 漂移适应 |
| DRE | O(n²) | O(n) | 残差可分解、修复映射可执行 |

**正确性定理（Dynamics-Certified Hybrid Composition Soundness）**

承接第 54 轮 (A26)–(A28)，新增：
- **(A34)** 每个 `(S,m)` 存在控制不变集 `X_{S,m} ⊆ D_S` 及 barrier 证书 `h_{S,m} ≥ 0`；
- **(A35)** 每条 DTC 边满足 `X_j^post ⊆ D_{S_j}`、`J ≤ J_max`、`η_trans ≥ η_min`；
- **(A36)** 每个 `(S,m)` 的保形包络满足 `P(δ_true ≥ δ_LCB) ≥ 1−α`；
- **(A37)** 模型阶次契约满足 `|δ_e − δ_c| ≤ L_δ ε_m`，且 `||r|| ≤ r_max ⇒ δ_e ≥ δ_c − L_δ ε_m`；
- **(A38)** 切换冲击事件与模型失配事件按 union bound 计入。

则含 `k` 个技能、`k−1` 次切换的组合计划满足：
```
P_success ≥ 1 − Σ_i α_i
              − Σ_e P(J_e > J_max)
              − P(∃t: ||r_t|| > r_max)
              − P(δ_c < η_min + L_δ ε_m)
```

**证明草图**：
1. 每段技能内，barrier 证书 `h_{S_i,m_i} ≥ 0` 保证状态不离开 `X_{S_i,m_i} ⊆ D_{S_i}`；
2. DTC 的 `X_j^post ⊆ D_{S_j}` 保证切换后进入下一段可行域，`J ≤ J_max` 与 `E_loss ≤ E_max` 保证冲击不破坏该包含；
3. 保形下界把真实余量 `δ_true` 替换为有 `1−α` 覆盖保证的 `δ_LCB`；
4. MOC 的 `L_δ ε_m` 消耗云端余量，残差监视器保证边端实际余量不低于 `δ_c − L_δ ε_m`；
5. 对 `k` 个覆盖事件、`k−1` 个冲击事件、残差越界事件做 union bound，得到上式。

**实用推论（组合余量）**
```
δ_comp = min_i δ_{S_i}^LCB − L_δ ε_m − Σ_e Δη_e
Δη_e = max(0, η_pre(e) − η_post(e))
```
仅当 `δ_comp ≥ η_min` 时部署。该推论把路径可行性检查压缩成一次标量比较，可直接用于 A* 剪枝。

## 5. 推导与解析探针（轮足专有）

### 5.1 轮滚动模式的牵引/载荷余量

考虑两轴轮足简化模型：质量 `m`，质心高度 `h`，轴距 `L`，坡度 `α`，纵向加速度 `a_x`，垂向加速度 `a_z=0`，轮胎摩擦系数 `μ`。总切向力与法向力为
```
F_t = m(a_x + g sin α)
N   = m(g cos α − a_z)
η_trac = μ − |F_t|/N
```
前后轴载荷
```
N_f = N/2 − m(a_x + g sin α) h/L
N_r = N/2 + m(a_x + g sin α) h/L
η_load,F = N_f/(N/2)
```
`η_load,F < 0` 表示前轮离地。注意 `η_trac` 与 `η_load,F` 可以独立失效：总摩擦可能够，但载荷转移先让某个轮离地；也可能载荷仍正，但总摩擦已不足。

取 `m=20 kg`、`h=0.4 m`、`L=0.6 m`、`μ=0.6`、`a_z=0`，解析探针结果如下（非整机实测）：

| 坡度 α | `a_x` | `η_trac` | `η_load,F` | 判定 |
|---:|---:|---:|---:|---|
| 0° | 0.0g | +0.600 | +1.000 | 可行 |
| 10° | 0.0g | +0.424 | +0.765 | 准静态可行 |
| 10° | 0.4g | +0.018 | +0.223 | 贴边，动态余量极小 |
| 10° | 0.6g | −0.186 | −0.047 | 前轮离地 + 滑移 |
| 15° | 0.4g | −0.082 | +0.091 | 载荷仍正，但总摩擦已不足 |
| 20° | 0.2g | +0.023 | +0.231 | 贴边 |
| 20° | 0.4g | −0.190 | −0.053 | 双重失效 |

这张表说明：**动作空间上同一条“向前滚”动作，在 `10° / 0.6g` 时已经从动力学上不可行**，而第 54 轮的动作剖面仍会把它标成“可覆盖”。这正是 H22 的动机。

### 5.2 模式切换为何能救：接触材料改变摩擦锥

轮接触与足接触的摩擦系数通常不同。取轮 `μ_w=0.6`、足 `μ_f=0.9`，同样坡度/加速度下：

| 工况 | 轮滚 `η_trac` | 腿撑 `η_trac` | 结论 |
|---|---:|---:|---|
| 10°, 0.6g | −0.186 | +0.114 | 切腿撑可恢复牵引 |
| 15°, 0.4g | −0.082 | +0.218 | 切腿撑可恢复牵引 |
| 20°, 0.4g | −0.190 | +0.110 | 切腿撑可恢复牵引 |

这解释了为什么 HMG 必须把 `(技能, 接触模式)` 作为节点：**同一个“前进”技能，换一个接触模式就换了一个摩擦锥**。同时，腿法向载荷调整可以修复 `η_load`，但**不能单独修复 `η_trac`**：例如 `10° / 0.6g` 下把质心前移 `0.05 m`，`η_load,F` 从 −0.047 升到 +0.059，但 `η_trac` 仍为 −0.186。要修复牵引，必须降速、增加法向载荷（腿蹬地）或切换到更高摩擦的接触模式。这是轮足“轮-腿耦合”的直接体现，也是 CWC-QP 必须联合优化轮扭矩与腿力的原因。

### 5.3 组合余量的数值示例

假设某条两段计划：
- 第一段 `δ_1^LCB = 0.20`，第二段 `δ_2^LCB = 0.18`；
- 切换处 `η_pre = 0.22`、`η_post = 0.12`，故 `Δη_e = 0.10`；
- 模型阶次误差 `ε_m = 0.05`，`L_δ = 1.5`，故模型预算 `0.075`；
- 要求 `η_min = 0.05`。

则
```
δ_comp = min(0.20, 0.18) − 0.075 − 0.10 = 0.005 < 0.05
```
计划被否决。此时有两种修复：降低切换冲击使 `η_post` 提高到 `0.17`（`Δη_e=0.05`），或切换到 `ε_m` 更小的边端模型/更保守的包络。这个例子说明 **DTC 不是“切换成功”就结束，而是要把切换造成的余量损失计入整条路径**。

## 8. 本轮最大风险

**一句话**：本轮方案的最大风险是 **动力学证书的“虚假安全”**——CWC 余量与保形包络都建立在接触参数、冲击模型和仿真标定的正确性上，一旦地面摩擦/刚度估计偏乐观、或切换冲击被低阶模型低估，证书会把“动力学上不可行”误判为“可部署”，因此必须坚持 **保形下界 + 动量残差在线否决 + 变量程保守回退** 三重护栏，绝不让预测余量直接充当安全余量。
