# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「用户共创」×「个性化交互」）

> R69 给闭环装上了一张「嘴」：不确定就问、看不清就看、拿不准就摸。但它默认「被问的人」是一个**静止、诚实、与系统无关的 oracle**——问一次，证据加一；问三次，证据加三。R70 的两个灵感把这个默认拆开：
> - **用户共创**：用户不只是「回答问题的人」，还是**共同作者**——他改预算、改偏好、改交互方式，甚至改系统「该怎么问」。共创写下的东西会**持久**存在，跨越回合、跨越场景。
> - **个性化交互**：问不问、怎么问、问多深，本身是**因人而异**的成本与效用；同一个动作对甲是体贴，对乙是冒犯。
>
> 两者合起来暴露了 R69 最深的裂缝：**R69 的证据纪律建立在「多个源相互独立」上，而个性化恰恰把「多个源」变成了「同一个人的多次回声」。** 更危险的是，共创让「一次回答」有机会变成「长期策略」——R69 好不容易用「单次交互不得定案」挡住的东西，会从持久通道绕回来。
>
> 核心命题：**把交互拆成两条时间尺度严格分离的通道——瞬时通道（R69 的信念更新，实时、零持久写、用户只是证据源）与持久通道（用户共创，异步、版本化、必须过安全编译器与审计）。个性化只允许在安全核认证的集合内「选」，不允许把集合「扩大」；共创只允许改「偏好壳」，不允许碰「安全核」。** 命名 **PACT-RAS**（Personalized, Auditable Co-creation with Two-channel safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**谁有权回答，谁有权把回答写回系统**」——个性化不是给用户一个向量，而是给用户一份**可审计、可撤回、不能动安全核的共创契约**。

## 0. 直觉与动机

**灵感 1（用户共创 → 用户从「证据源」升级为「共同作者」）**
直觉：R69 里用户的回答只改变当前回合的模态后验，回合结束就蒸发。但真实的人机关系不是「问答」而是「共事」：用户会说「以后别用那种语气」「这个动作我不喜欢」「把安全距离调大一点」「遇到这种情况先问我而不是自己决定」。这些话不是关于当前状态的证据，而是关于**未来策略的编辑**。共创的本质是：用户把自己的偏好、边界、甚至判断规则，写进一个**共享产物**里，系统按这个产物行事。问题是，写进去的东西会留下来——所以它不能走实时回路，否则「一次情绪化的回答」就会变成「永久的人格」。
形式化直觉：交互有两个时间常数——episode 内的 τ_fast（信念更新，毫秒级）与跨 episode 的 τ_slow（策略编辑，小时/天级）。R69 只有 τ_fast；R70 必须为 τ_slow 建立独立的**写路径、验证、版本与回滚**。混在一起，就是把「证据」和「立法」混为一谈。

**灵感 2（个性化交互 → 问的成本与效用是用户条件下的）**
直觉：R69 的 VoI 用统一的社交成本 c(g)。但「被机器人盯着看 2 秒」对害羞的人是高成本，对好奇的人是低收益甚至正收益；「被问一句」对专家是打扰，对新手是安全感。个性化不是把用户塞进一个特征向量，而是让**成本函数、候选动作集、解释深度**都成为 p_u 的函数。关键是：个性化改变的是「在安全集合里选哪个」，不是「安全集合有多大」。
形式化直觉：把 VoI 从 VoI(g) 升级为 VoI_u(g)，把 c(g) 升级为 c_u(g) = c_phys + c_social(p_u) + c_privacy(p_u) + c_cognitive(p_u)；但约束集仍是 SK 认证的 𝒜_safe，个性化只做**集合内的排序**。

**灵感 3（安全核 / 偏好壳 → R69 是「无个性化」的边界）**
直觉：如果把「安全」和「偏好」放在同一个可编辑对象里，用户共创迟早会把安全改没——不是恶意，而是人不知道哪个参数是安全关键。所以必须硬分：**安全核 SK 不可编辑**（λ_min、C-RAS-WM 包络、证据纪律、证书字段），**偏好壳 PS 可编辑**（预算、语气、模态权重、解释深度、成本参数）。个性化映射 T_p 必须满足 T_p(𝒜_safe) ⊆ 𝒜_safe：它只能在已认证的集合里挑，不能把边界往外推。
理论姿态与 R69 一致：**新层必须是旧层的严格泛化**。当 p_u = p_0（默认画像）、无持久编辑、无强制探索时，PACT 必须逐指令等于 FLUID-RAS；当画像不可信/漂移/被投毒时，必须**逐指令退回** FLUID-RAS。

**灵感 4（有效独立性 → 「问同一个人三次」不是「问三个源」）**
直觉：R69 的 k-正交证据纪律假设源之间独立。但个性化交互里，最方便的证据源就是「再问同一个用户一次」——而同一个人的回答高度自相关：他的偏好、心情、表达习惯、甚至对「被问」的反应，都会让多次回答同向。更糟的是，系统会**按画像选问题**，于是问题本身就被画像污染了：你越相信他喜欢 A，就越问那些能确认 A 的问题，他的回答也就越像 A。R69 的投毒上界 δ_p·ρ^{k−1} 在这里是**乐观的**，因为 k 被高估了。
形式化直觉：定义**有效独立源数 κ_eff**（相关矩阵的参与率），用 κ_eff 替换 k。若 κ_eff < 2，则「已消解」不成立，U_epi 必须保持未消解并走 R69 保守。这条修正看似小，实则是 R70 的**安全阀**：个性化天然降低证据多样性，所以个性化越深，越需要跨模态/跨时间的正交证据，而不是更多次追问。

**灵感 5（共创是双刃剑 → 需要「代码级」的治理）**
直觉：一旦用户能写持久策略，就有了 R69 没有的攻击面：伪造历史喂养画像、用大量小号（sybil）把共享策略推向某个方向、用精心设计的回答操纵画像、利用探索预算反向探测系统、把「共创」当成社会工程。还有非恶意但同样危险的东西：**责任真空**（用户改坏了，算谁的？）、**过滤气泡**（系统只问画像喜欢问的，用户只看到画像预测的）、**多数/权力用户暴政**（少数人的偏好被平均掉）。
所以本轮必须同时交付：编辑语言（受限、非图灵完备）、编译器（静态检查+投影+反事实回归）、审计与归因（谁改的、同意了吗、能回滚吗）、群体聚合（影响裁剪+少数保护）、以及**反认知闭合的探索预算**。否则 PACT 不是进步，而是给 R69 的「会问的嘴」配了一支「能改宪法的笔」。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PACT-RAS 总览）** PACT-RAS = (SK, PS, PPM, PVoI, PEC, CPC, CAA, PFA, PLC, RAS-WM‡)。三不变式：
(i) **安全核不可编辑**：SK 固定，任何画像、共创编辑、实时学习都不得修改或放松 SK；
(ii) **通道分离与快照冻结**：实时回路只读版本冻结的偏好壳快照 PS_v，持久写只发生在回合边界之外；
(iii) **单调个性化与可审计共创**：个性化只能在 SK 认证的安全集合内选择/排序（不得扩大集合）；每个持久编辑必须携带作者、同意、反事实测试、版本与回滚点。

**定义 311（双通道交互）** 瞬时通道：b ← Update(b, y; g)，只影响本回合模态选择与 λ，零持久写。持久通道：e: PS_v → PS_{v+1}，影响未来回合，必须过 CPC，且不在实时预算内。形式化：实时状态转移是 (o_t, PS_{v(t)}) 的函数，v(t) 在 episode 内冻结；共创事件只能在 episode 边界改变 v。⇒ **共创永不进实时回路**。

**定义 312（偏好壳与画像）** 画像 p_u ∈ 𝒫 ⊂ ℝ^d（低维、可解释）：风险容忍 ε_u ∈ [ε_min, ε_max]、交互啰嗦度 β_u、模态偏好 w_u、隐私预算 ρ_u、解释需求 η_u、拒绝历史。偏好壳 PS = (p_u, q(p_u), 约束, 预算, 同意状态)。画像以**后验** q(p_u) 维护，不取点估计——「我对你的判断有多确定」本身是不确定性的一部分。

**定义 313（安全核 SK 与单调个性化）** SK = (λ_min, ℰ_cert, A_cert, 提交/换装不变式)，继承 R68/R69。个性化映射 T_p: 2^{𝒜} → 2^{𝒜} 满足 T_p(A) ⊆ A；风险缩放 λ_u = clip(λ_floor,u(U), λ_min, λ_max)，其中 λ_min 是硬下界，λ_global 是 R69 的保守默认。允许耐受型用户取 λ_u ∈ [λ_min, λ_global]、敏感型取 λ_u ≥ λ_global，但**任何 p_u 都不得低于 λ_min**。⇒ 个性化可以在认证包络内做权衡，不能突破认证底线。

**定义 314（个性化 VoI）** c_u(g) = c_phys(g) + c_social(g; p_u) + c_privacy(g; p_u) + c_cognitive(g; p_u)；VoI_u(g) = H(M|o,p_u) − E_{y~p(·|g,o,p_u)}[H(M|o,y,p_u)]；g* = argmax_{g ∈ 𝒜_info} [VoI_u(g) − c_u(g)]，s.t. g ∈ SK 认证集、预算未超、且**同意状态允许**。拒绝是一等证据：用户拒绝模态 m 后，m 进入 no-go，除非重新同意；拒绝不得被惩罚（不扣效用）。

**定义 315（画像条件下的不确定性）** U_ale 不变；U_epi,u = H(M|o,p_u)·g(Δ_min)；新增 **画像不确定性** U_prof = H(p_u|D_u)。总可约不确定性 U_epi^tot = U_epi,u + γ·U_prof。系统必须同时消解「模态歧义」与「画像歧义」；只消解前者就宣称「已定案」是不合法的——这正是 R69 在个性化场景下的盲点。

**定义 316（有效独立源数 κ_eff）** 证据源 y_1..y_k 的相关矩阵 R（含同一用户的时间自相关 ρ_u 与画像条件相关），κ_eff = (tr R)² / tr(R²) ∈ [1,k]。证据纪律从「k ≥ 2」升级为「κ_eff ≥ κ_min」；同一用户重复回答、同一模态重复探询默认计入同一源，除非有跨模态/跨时间/跨情境的正交性证明。

**定义 317（共创编辑语言）** e = (τ, target, value, scope, ttl, consent)，target 只能落在偏好壳：预算、模态权重、成本参数、解释深度、信息动作白名单、画像先验；**禁止** target：λ_min、SK 谓词、证据纪律、证书字段。编辑语言非图灵完备（无任意代码），以限制攻击面。

**定义 318（共创编译器 CPC）** CPC: (e, PS_v, replay D) → {accept, reject, needs_consent}：
1. 静态检查：target ∈ 可编辑集、类型/范围合法、不含 SK 字段；
2. 投影：PS' = Π_SK(apply(e, PS_v))，把 λ 夹到 [λ_min, λ_max]、κ_eff 下限、证书字段只读；
3. 反事实回归：分层重放 D，要求安全违规增量 = 0、κ_eff 不低于 κ_min、ECE ≤ τ、群体最差效用不下降；否则 reject/quarantine；
4. 版本自增、证书签发、回滚点登记。
⇒ 把用户编辑当**代码**对待：评审、测试、灰度、回滚。

**定义 319（画像认知控制器 PEC）** 维护 q(p_u)；每回合以 ε_explore 的概率（或预算化比例）选择**反确认动作** g† = argmax_g E_y[KL(q(p_u|y) ‖ q(p_u))]，即「最能让系统发现自己看错人」的动作，而不是最有用于消解模态的 g*。另设漂移/陈旧检测：若近期回答在 q 下的预测似然低于阈值，触发重标定/重新同意。**反闭合约束**：高利害个性化要求 ε_explore ≥ ε_min > 0；若用户拒绝探索且无法满足，则**限制个性化深度**而非偷偷继续——「不被意外，就不配个性化」。

**定义 320（画像投毒干扰集 ℰ_profile）** 伪造历史喂养、sybil 共创（大量小号推动共享策略）、偏好操纵（用精心回答把画像推向某方向）、探索预算反向利用、隐私推断、回答与内容共谋。并入 AIC：ℰ_PACT = ℰ_FLUID × ℰ_profile。

**定义 321（共创审计与归因 CAA）** 每个持久编辑记录：作者（用户/系统推断/管理员）、同意记录、diff、反事实测试结果、回滚指针、群体影响。审计必须能回答「是谁让系统变成这样」；并提供反事实解释：「若你的画像没有被这样编辑，系统本会做 X」。⇒ 用可追溯性闭合责任真空。

**定义 322（群体公平聚合 PFA）** 共享策略的共创更新按用户影响裁剪（单人权重 ≤ w_max）与加权聚合；约束最大化平均效用，s.t. 任一群体的最差效用 ≥ 阈值（maximin/少数保护），防止多数或权力用户把策略推离少数群体。个性化在单用户层做，共创在群体层做，二者用**影响裁剪**解耦。

**定义 323（个性化生命周期证书 J_PACT）** J_PACT = (J_FLUID, SK_hash, profile_version, q_calibration_ece, κ_eff, ε_explore_actual, edit_provenance_hash, consent_hash, population_impact, drift_score, pact_ver)。Valid ⇔ Valid(J_FLUID) ∧ 所有持久编辑已认证 ∧ κ_eff ≥ κ_min ∧ ECE ≤ τ ∧ 同意有效 ∧ 无 SK 放松。

**定义 324（两级退化）** 画像无效/漂移/被投毒/同意撤回 → p_u := p_0、λ := λ_global、个性化全部关闭；CPC 不可用或编辑未认证 → 编辑 fail-closed 拒绝；κ_eff < κ_min → U_epi 视为未消解。⇒ R69 是「无个性化、无共创」边界，安全侧不做让步。

**定义 325（同意门控交互）** 每个信息模态有同意状态；拒绝是合法观测，更新 c_u 与约束；系统必须提供替代模态或退回保守；拒绝不得降低用户效用/优先级。个性化不得以「为你好」为名绕过同意。

**定义 326（画像漂移与再同意）** 画像带 TTL 与漂移检测；drift_score > τ_d 时冻结 q、要求重标定/再同意后方可恢复个性化；旧编辑保留版本与回滚能力，不因新画像而静默失效。

# IP-265 PPM：画像后验（不是点估计）
class PreferenceModel:
    def snapshot(self, user, version):       # 实时回路只读冻结快照
        return self.store[user][version]     # (p_u, q)
    def update_posterior(self, user, y, g):  # 仅在持久/审计路径调用
        self.q = bayes_update(self.q, y, g)

# IP-266 PVoI：用户条件下的交互选择
def choose_interaction_personalized(modes, o, p_u, q, budget, consent):
    best = None
    for g in info_action_candidates(modes, p_u):
        if not budget.allow(g) or not consent.allows(g):      continue
        if not c_ras_wm.certify_info(g, o):                   continue
        voi   = entropy(modes, p_u) - expected_entropy(modes, p_u, g, o)
        score = voi - (c_phys(g) + c_social(g, p_u)
                       + c_privacy(g, p_u) + c_cognitive(g, p_u))
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None          # 无利可图 → R69

# IP-267 PEC：反确认探索，防止画像自我加固
def maybe_disconfirm(q, p_u, t):
    if t % max(1, round(1.0 / EPS_EXPLORE)) != 0:
        return None
    return argmax_g E_y[KL(q(p_u | y) || q(p_u))]             # 关于「人」的信息

# IP-270 EIS：有效独立源数
def kappa_eff(R):
    return (trace(R) ** 2) / trace(R @ R)                     # ∈ [1, k]

# IP-268 CPC：把共创编辑当代码编译
def compile_edit(e, PS_v, replay):
    if e.target not in EDITABLE_TARGETS:     return Reject("safety_kernel")
    PS_new = project_SK(apply_edit(e, PS_v))                  # Π_SK 投影
    if not regression_ok(PS_new, replay):    return Quarantine(e)
    return accept(PS_new, cert=emit(PS_v, e, replay))

# IP-274 主闭环：冻结快照 + 瞬时写 + 异步审计
def PACT_round(M, obs, user):
    v        = M.ps.version                                   # 冻结，不写
    p_u, q   = M.ppm.snapshot(user, v)
    z, o     = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    K        = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    modes, U_ale, U_epi = M.fmp.decompose(M.fmp.sample(o, K), p_u)
    g        = M.pvoi.choose(modes, o, p_u, q, M.budget, M.consent)
    g_dag    = M.pec.maybe_disconfirm(q, p_u, M.t)             # 预算化反确认
    g        = g_dag or g                                     # 探索优先但受限
    if g and not M.c_ras_wm.certify_info(g, o): g = None
    U_epi_after = M.cia.update_belief(modes, M.cia.execute(g)) if g else U_epi
    # 画像不可信 / 有效独立源不足 / 漂移 → 逐指令退回 R69
    if (M.eis.kappa_eff(M.evidence.R) < KAPPA_MIN or M.pec.drift(q)
            or not M.plc.valid(M.plc.J_PACT)):
        p_u, U_epi_after = P0, U_epi
    lam = max(M.efs.risk_scale(...),
              lam_floor_global(U_ale + (0.0 if g else U_epi_after)),
              lam_floor_u(p_u, U_ale))       # λ_u ≥ λ_min 由 clip 保证
    k    = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.caa.log_async(g, p_u, v, U_epi_after, M.eis.kappa_eff(M.evidence.R))
    return k, lam, mode, (U_ale, U_epi_after)

## 3. 推导

**引理 19（共创编辑的安全核保持）** 对任意通过 CPC 的编辑 e，结果 PS_{v+1} 满足 SK：λ_u ≥ λ_min、κ_eff ≥ κ_min、C-RAS-WM 包络与提交/换装不变式不变。证明要点：编辑目标受类型系统限制 + Π_SK 投影 + 反事实回归 fail-closed 拒绝。系：**共创不能扩大安全集合**；残余风险由 SK 承担（可认证），偏好选择由用户归因（可审计）。

**引理 20（个性化证据的有效独立性收缩）** 设同一用户回答的时间自相关为 ρ_u、画像条件相关为 ρ_p，则 κ_eff ≤ k；R69 的投毒上界退化为 δ_p·ρ^{κ_eff−1} + ε_σ。若 ρ_u → 1，则 κ_eff → 1，同一用户的重复回答不再提供独立证据，U_epi 不能认证为「已消解」。系：**问同一个人三次 ≠ 问三个源**；个性化必须从跨模态/行为/时间通道获得正交性，而不是增加追问次数。

**引理 21（个性化风险上界）** 对任意 p_u ∈ 𝒫，单用户风险 R_u ≤ ε(λ_min) = ε_max；且 PACT 在 p_u 下的安全集合是全局认证集合的子集。证明：T_p(A) ⊆ A + λ 的 clip 下界。⇒ 个性化可以改变「在安全集合里怎么选」，不能改变「安全集合本身」。

**定理 18（PACT 严格包含 R69）** 取 p_u = p_0、无持久编辑、ε_explore = 0、无拒绝，则 PACT 与 FLUID-RAS 逐指令相同；对任意 p_u，R_u ≤ ε_max；当画像无效/κ_eff < κ_min/ECE > τ/漂移/投毒疑云时，PACT 逐指令退回 FLUID-RAS。故 R69 = PACT 的「无个性化、无共创」边界，安全侧不做任何让步。

**定理 19（反认知闭合）** 设真实画像 p*，系统后验 q。若 ε_explore = 0 且交互按「最有利于模态消歧」选择，则关于 p* 的查询分布会集中在画像一致区域，q 对 p* 的 KL 不降（确认偏差），错误画像以概率 → 1 存活。若 ε_explore ≥ ε_min > 0，则 q 的校准误差按 O(1/√(N ε_explore)) 下降，错误画像存活 N 回合的概率 ≤ exp(−c N ε_explore)。系：**个性化深度必须被探索预算封顶**；没有「被顶撞」的通道，个性化就是自我实现的预言。

**引理 22（共创聚合的少数保护）** 在单人影响裁剪 w_max 与 maximin 约束下，任一用户/群体对共享策略的影响有界，且最差群体效用不低于阈值；单点 sybil 不能把策略推过界。证明：影响范数 ≤ w_max·N_eff 与约束投影。系：个性化在单用户层做，共创在群体层做，用裁剪解耦，避免「权力用户改写所有人的系统」。

## 4. 推导

**引理 19（共创编辑的安全核保持）** 任意通过 CPC 的编辑 e 都满足 `λ_u≥λ_min`、`κ_eff≥κ_min` 且 C-RAS-WM 包络不变。证明：目标类型限制 + `Π_SK` 投影 + 反事实回归 fail-closed。系：共创不能扩大安全集合；残余风险归 SK（可认证），偏好选择归用户（可审计）。

**引理 20（有效独立性收缩）** 同用户自相关 `ρ_u` 与画像条件相关使 `κ_eff≤k`；R69 上界退化为 `δ_p·ρ^{κ_eff−1}+ε_σ`；`ρ_u→1 ⇒ κ_eff→1`，重复追问不再提供独立证据，`U_epi` 不得认证为已消解。系：**问同一个人三次 ≠ 问三个源**；正交性必须来自跨模态/行为/时间，而非追问次数。

**引理 21（个性化风险上界）** 任意 `p_u∈𝒫` 有 `R_u≤ε(λ_min)=ε_max`，且个性化后的安全集合是全局认证集合的子集。证明：`T_p(A)⊆A` 与 λ 的 clip 下界。

**定理 18（PACT 严格包含 R69）** `p_u=p_0`、无持久编辑、`ε_explore=0`、无拒绝时，PACT 与 FLUID-RAS 逐指令相同；任意 `p_u` 下 `R_u≤ε_max`；画像无效/`κ_eff<κ_min`/ECE 越界/漂移/投毒疑云时逐指令退回 FLUID-RAS。故 R69 = 「无个性化、无共创」边界，安全不让步。

**定理 19（反认知闭合）** `ε_explore=0` 且按模态消歧选查询时，查询分布集中于画像一致区域，`q` 对真实 `p*` 的 KL 不降，错误画像以概率 →1 存活。`ε_explore≥ε_min>0` 时，校准误差按 `O(1/√(Nε_explore))` 下降，错误画像存活 N 回合概率 `≤exp(−cNε_explore)`。系：个性化深度必须被探索预算封顶——**不被意外，就不配个性化**。

**引理 22（共创聚合的少数保护）** 单人影响裁剪 `w_max` + maximin 约束下，任一用户/群体影响有界，最差群体效用不低于阈值，单点 sybil 不能把策略推过界。系：个性化在单用户层、共创在群体层，用影响裁剪解耦。

## 7. 本轮最大风险

**一句话**：PACT 把「问用户」升级为「问用户画像 + 让用户改策略」，但个性化天然收缩证据多样性、共创天然固化历史——**系统越体贴，越可能只是在确认自己已经相信的那个用户；它会把「问错」升级成「用一个可审计的画像，长期地、自信地服务一个不存在的人」**，而审计日志看起来完全干净。

**次级风险与缓解**：共创改坏安全（安全核不可编辑 + CPC 投影/回归 + 引理 19）；画像投毒/sybil（ℰ_profile + κ_eff 纪律 + PFA 裁剪 + 引理 22）；认知闭合/过滤气泡（PEC 反确认预算 + 定理 19 + 深度封顶）；责任真空（CAA 归因/同意/回滚 + 反事实解释）；隐私与同意被绕过（同意门控 + 拒绝一等化 + 隐私预算进 c_u）；实时预算（冻结快照 + 持久路径离线 + 均摊探索）。
