# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因」IP-214~223；灵感循环第 2 轮；本轮灵感：「轮足机器人」×「研究空白」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险正是整条链的隐藏假设 A88：**故障必须落在有限假设集 ℋ 内，且视觉与几何的失效相互独立。** 真实故障常是未知类型的复合；透明/镜面/对抗 patch 又会让视觉与几何共享同一分布外失效源。于是 FIR 会把未知复合故障强行塞进最近假设、只膨胀错误的球——系统因为「已经归因」而更自信地继续执行。本轮不再加第 4 个传感器，而是换一个提问层级：第 65 轮问「是哪一类已知故障」，HYDRA 问「**系统此刻处在哪个混合模态、守卫在何时切换、以及这块残差根本不在已知世界里（研究空白）吗**」。

**核心命题：**

> **把「故障归因」升级为「模态归因 + 空白探测」：用轮足机器人「滚动 / 过渡 / 迈步」的混合模态结构，替换 VISTA 依赖力阈值的人工三阶段与封闭假设集；把「研究空白」从被强行归类的误差，变成显式建模、可度量、可主动填补的一等潜变量；并用「可设计的混合激励」把 VISTA 被动获得的可辨识性变成可以规划的能力。**

## 0. 直觉与动机

**灵感 1（轮足机器人 → 真正的隐藏变量是混合模态，不是传感器）**
直觉：VISTA 把块切成 approach/touch/load，默认「接触状态」可由力阈值可靠读出。轮足机器人恰好暴露这个默认的反例：同一台机器既能**滚动**（轮-地持续接触、非完整约束、牵引极限），也能**迈步**（离散落脚、冲击接触、抓地与翻倒裕度）；而「此刻在滚还是在迈、何时切换」是**本体的潜变量，不是观测量**。轮式给出连续约束下的低频几何/牵引信息，腿式给出冲击瞬间的宽带接触信息——两者提供的可观测性在物理上根本不同。于是一个大残差，不一定意味着「某个传感器坏了」，更可能是「**我们以为在滚动，其实已打滑进入迈步/失稳模态**」，或「**守卫比我们以为的早/晚切换**」。第 65 轮的不可辨识，本质是**模态与守卫不可观测**，而不是假设集不够大。

**灵感 2（研究空白 → 不要强行归类，要把「空白」本身建模）**
直觉：第 65 轮最危险的失败不是「归因错了」，而是「**明明不在已知假设集里，却被强行归因**」。科学的做法不是把 ℋ 扩到无限（退化为过拟合），而是给「不在已知流形附近」这件事一个**显式、可标定的分数**：在已知签名流形上做 split-conformal novelty 检验；当残差远离所有已知模态-故障流形，系统进入 `research_gap` 状态——不宣称归因、对所有球保守膨胀、并把它记录成一张「待填的空白卡片」。**研究空白不是要消灭的噪声，而是要被记录、被度量、被设计实验去填补的对象。**

**灵感 3（轮足的模态时序 → 可辨识性可以被「设计」，而不只是被「获得」）**
直觉：VISTA 引理 7 说三阶段被激励时故障可分离——但「是否被激励」是听天由命。轮足 locomotion 正好相反：模态是**我们自己选的**。滚动段提供持续的非完整/牵引约束（辨识 μ 与几何），受控冲击段提供**宽带激励**（辨识接触模型、恢复系数、落地重置），过渡/腾空段提供广义「零力窗」（辨识 F/T 偏置与守卫时刻）。因此**选择下一个模态与过渡点，就是在为归因设计激励**：把 VISTA 被动的 κ_fi 升级为可优化的 κ_H，并主动「跨过最可疑的守卫」——这正是一台轮足机器人面对未知地形时「先滚一下还是先迈一步」的实验设计。

**灵感 4（两灵感合流 → HYDRA：Hybrid-mode Gap-awaRe Attribution，混合模态空白感知归因）**
像九头蛇：砍掉一个已知故障假设，混合模态里又长出两个未知头；所以不能只关已知的头，必须给「未知头」建模（gap）。
闭环：混合模态文法 HMG（潜在模态 + 未知守卫）→ 模态条件签名 ρ_q → 开集空白度 g(ρ)（conformal）→ 模态-故障联合后验 FIR-H（含 H_gap）→ 若空白/模糊：守卫激励探针 GEP（主动跨守卫做判别实验）→ 定向球 RSC-H（r_geo/r_force/r_model/r_mode/r_gap，只膨胀被归因或空白者）→ 混合安全证书 + 认证模态前缀 CSC-H（逐模态 barrier + 过渡兼容，承诺 k* 个**过渡**而非 k* 步）→ 实时早停与重归因。第 65 轮是「接触前/中/后」三阶段，HYDRA 把它升成「**滚动 / 过渡 / 迈步 / 未知**」的混合自动机，并承认守卫本身是带不确定性的估计量。

## 2. 关键算法骨架

```python
# HMG：从本体/视觉推断潜在混合模态与守卫（语义流）
sigma_post, guard = hmg.infer(o_window, H_nom)      # σ∈{roll,trans,step,unc}, guard~N(ĝ,Σ_g)
rho = {q: mode_signature(o_window, q) for q in Q}   # 模态条件签名

# GAP：开集空白判定（conformal，禁止强行归因）
gap_score = novelty(rho, known_manifolds)           # dist to M, 已标定
is_gap = gap_score > q_gap(alpha_gap)

# FIR-H：模态-故障联合后验
post = fir_h.posterior(rho, sigma_post, guard)      # 含 H_mode / H_gap
if post['H_gap'] >= delta_gap:
    do_not_attribute(); inflate(balls, 'r_gap')     # 只膨胀空白球，禁归因
elif max(post.values()) >= 1 - delta_fi:
    balls, w_vis, H = fir_h.directed_demote(argmax(post), balls, w_vis, H)
else:
    a = gep.choose(post, sigma_post, guard, f_safe) # 跨守卫判别实验
    execute(a); recompute()

# CSC-H：认证模态前缀（逐模态 barrier + 过渡兼容）
prefix = csc_h.certify(mode_plan, B, post, guard_cov, m_H, alpha_h)
for trans in prefix[:prefix.k_star]:
    dispatch_mode(trans)
    if csc_h.guard_monitor(trans, guard).abort:     # 守卫时序早停
        break
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（混合签名可辨识性）**：若模态日程 π 同时激励「持续约束模态（roll，识牵引/几何）+ 冲击过渡（step，识接触模型/重置）+ 低载窗（null_roll/flight，识 F/T 偏置）+ 非零速度跨守卫（识守卫时刻）」，则 S_H 列满秩、κ_H>0，Laplace 后验错误率 ≤ exp(−n·κ_H/2)；当 Q 退化为单模态、过渡固定时，恰退化为 VISTA 引理 7。**这解释了第 65 轮的不可辨识：不是假设太少，而是模态/守卫未被激励。**
- **引理 10（GEP 的近最优性）**：高斯线性模型下 I(θ;ρ|a)=½log det(I+Σ⁻¹S_aS_aᵀ) 对实验集合单调子模，贪心选探针达 (1−1/e) 近似；故 GEP 的贪心「跨守卫」选择在信息增益意义下近最优，且可加安全约束剪枝。
- **引理 11（混合 barrier 组合）**：若所有被访问模态满足流不变性、所有被执行的过渡在守卫不确定球 G_e^⊕ 上满足 B_{q'}∘R_e≥0，则模态前缀永不进入不安全集；k* 由「前 k 个过渡最小裕度≥0」反解，联合界给 P[越界]≤α_h+α_vis+δ_gap+α_geo。
- **定理 9（HYDRA 端到端）**：在 A88'（有限但开集的模态-故障空间 + 守卫有界不确定）下，Valid(J_hydra) ⇒「空白不被强行归因 ∧ 已知故障被分离 ∧ 混合前缀安全 ∧ 失效优雅降级」。证书链由 VISTA 的「几何-技能-干扰-接触-归因」扩到「…-**模态-空白**」。
- **命题（gap 校准与空白不可自证）**：在可交换性下 P[s(ρ)>q_gap|分布内]≤α_gap；但**未被激励/从未访问的模态无法被检测**（检测功效无免费午餐）。故开集安全必须附带「模态覆盖假设」：每个模态需以 ≥p_min 概率被探针访问，否则只能声明「条件安全」。
- **实时性**：HMG 推断、GAP 标定、FIR-H、GEP、CSP-H 全在语义流；实时流只增模态/守卫残差（<0.15ms）与守卫早停（<0.03ms），目标仍 ≤2.5ms（A93 契约）。

## 2. 形式化定义（完整版）

**定义 233（HYDRA 闭环）** HYDRA 是 VISTA 的「开集 + 混合模态」升级：在 VISTA 的「语义流 ∘ 实时流」骨架上，把阶段切分升级为混合模态文法 HMG，把 FIR 升级为含开集空白的联合后验 FIR-H，把 AFA 升级为守卫激励探针 GEP，把 CSC 升级为逐模态 barrier + 过渡兼容的 CSC-H，并原位升级 RSC/WCV/CSP/AIC 与 J。不变式：**模态推断、守卫估计、空白标定、激励规划与证书构建只在语义流；实时路径只做模态/守卫残差采集、守卫早停、认证模态前缀派发，零学习写操作。**

**定义 234（混合自动机名义模型）** H_nom=(Q,X,F,Inv,E,G,R)：
- `q_roll`：轮-地持续接触，流满足非完整约束，牵引上限 `|f_t|≤μ f_n`；
- `q_trans`：过渡/腾空，接触力可为零或跳变，是最广义的「零力窗」与守卫所在；
- `q_step`：离散落脚/冲击，重置 `R_e` 含恢复系数与摩擦（Hunt–Crossley 型）；
- `q_unc`：接触不确定模态（打滑、沉陷、部分接触），名义模型给不出闭式流时使用保守包络。
不变式 `Inv(q)` 编码该模态的安全集（滚动：牵引/侧翻；迈步：支撑多边形/ZMP/捕获点）。真实系统 H* 与 H_nom 的差分为四类：模态替换、守卫偏移、流扰动（μ/刚度/几何）、重置错（冲击模型），它们正是归因目标。

**定义 235（潜在模态与模态条件签名）** 真实模态 `σ_t` 不可直接观测，由 `o_t=(y_vis,f,proprio)` 经 HMG（HMM/混合自动机观测模型）推断：`P(σ_t|o_{1:t})`。模态条件签名 `ρ_q=Φ(o_{t−τ:t})|σ=q∈ℝ^{d_q}`。**VISTA 的 P={approach,touch,load} 是 Q={roll,trans,step,unc} 在「忽略滚动/冲击、只按力阈值」下的退化投影**；一旦存在滚动接触或守卫模糊，该投影即不可辨识。

**定义 236（开集空白度与 gap 判定）** 设已知签名流形 `M=∪_{已知(m,H)}M_{m,H}`（每个模态-故障对一条低维流形/密度）。非一致性分数 `s(ρ)=dist(ρ,M)²_{Σ⁻¹}`（或 `−log p_max(ρ)`）。在标定集 `{s_i}` 上取 `q_gap(α_gap)` 为第 `⌈(n+1)(1−α_gap)⌉/n` 分位数；`s(ρ)>q_gap(α_gap)` 时 `research_gap=True`。**保证（可交换性下）：分布内误报率 ≤α_gap。诚实声明：检测未知空白的功效取决于空白与已知流形的分离度，无分布无关的召回保证。**

**定义 237（模态-故障联合后验 FIR-H）** 扩展假设 `ℋ_H=ℋ_VISTA∪{H_mode,H_gap}`，其中 H_mode 表示「模态/守卫错位」（以为在 roll 实为 slip/step，或守卫早/晚切），H_gap 表示「不在已知世界」。联合后验
`P(σ,H|ρ) ∝ p(ρ|σ,H) P(σ|H) P(H)`，
`P(σ|H)` 由混合自动机转移先验给（守卫用估计分布 `N(ĝ,Σ_g)`）。判定顺序**先空白、后故障**：
1. 若 `P(H_gap|ρ)≥δ_gap` → `research_gap`：禁止任何归因，只膨胀 r_gap；
2. 否则若 `max_{σ,H}P(σ,H|ρ)≥1−δ_fi` → 对 `(σ*,H*)` 定向处置；
3. 否则 ambiguous → GEP。

**定义 238（混合签名矩阵与可设计可辨识性）** 线性化 `E[ρ_q|θ]=S_q θ`，`S_H=stack_{q∈Q}S_q`，`κ_H=λ_min(S_HᵀΣ⁻¹S_H)/λ_max(·)`，θ 含几何、F/T 偏置、接触模型、守卫时刻、视觉幅度。可辨识 ⇔ S_H 列满秩。由于 S_H 依赖被访问的模态日程 π，故 `κ_H=κ_H(π)` 是**可优化量**；第 65 轮 κ_fi 是其在「单模态 + 固定过渡」下的特例。

**定义 239（守卫激励探针 GEP）** 令 `Z=(σ_{t+1:t+H},1[gap])`，选
`a*=argmax_{a∈A_safe} I(Z; ρ_{1:3}(a)|ρ_{1:2})`，
s.t. `P(traj_a ∩ G_{ij}≠∅)≥p_G`（必须是真正的跨守卫实验）、`max f_n≤f_safe`、`max strain≤ε_strain`、翻倒裕度 `≥ρ_flip`、`k*` 预览可早停。
`A_safe={guard_test, impact_probe, null_roll, gap_probe, visual_probe}`。易损物体或陡坡时禁用冲击/加载探针，退化为 `visual_probe`/`null_roll`。**探针的首要目的从 VISTA 的「估 φ」、AFA 的「分故障」进一步变为「分辨模态与空白」。**

**定义 240（混合安全证书与认证模态前缀 CSC-H）** 每模态持 barrier `B_q:X→ℝ`，要求 `B_q(x)≥0` 于安全集、`∇B_q·F_q(x)≤−γ|B_q(x)|` 于 `Inv(q)`。对过渡 `e=(q,q')`，兼容条件
`∀x∈G_e^⊕: B_{q'}(R_e(x))≥0`，
其中 `G_e^⊕=G_e⊕B(0,r_mode)` 吸收守卫不确定。认证前缀以过渡数计：`k*=max{k: ∀j≤k, margin_j≥0 ∧ P[∃j≤k 越界]≤α_h}`，且 `k*≤m_H`（`m_H`=停止距离+镇定时间折算的过渡数）。执行 k* 个过渡后强制重规划与重归因。

**定义 241（RSC-H 归因定向球）** 维护 `r_geo,r_force,r_model,r_mode,r_gap` 与 `w_vis`，融合 `r=√(r_geo²+r_force²+r_model²+r_mode²+r_gap²)`。定向处置：

### IP-224 HMG（混合模态推断）

```python
class HybridModeGrammar:
    """HMM/混合自动机观测模型；实时只回传 σ 后验与守卫估计，学习在语义流。"""
    def infer(self, o_win, H_nom):
        # 观测模型：模态条件的视觉/力/本体残差
        loglik = {q: self.obs_loglik(q, o_win) for q in H_nom.Q}
        sigma = self.forward_backward(loglik, self.trans_prior(H_nom.E))
        # 守卫：由跨越剩余距离/时间反解，给高斯近似
        guard = self.estimate_guard(o_win, sigma, H_nom.G)
        return sigma, guard                      # guard = (g_hat, Sigma_g, e_star)
```

### IP-225 GAP（开集空白判定）

```python
class GapDetector:
    def __init__(self, manifolds, alpha_gap=0.05):
        self.M = manifolds                      # 已知模态-故障流形/密度
        self.scores = []                        # 标定非一致性分数

    def score(self, rho):
        return min(distance(rho, M) ** 2 for M in self.M)   # Sigma^{-1} 加权

    def calibrate(self, rho_cal):
        self.scores = sorted(self.score(r) for r in rho_cal)

    def is_gap(self, rho):
        n = len(self.scores)
        k = math.ceil((n + 1) * (1 - self.alpha_gap)) - 1
        return self.score(rho) > self.scores[min(k, n - 1)]
```

### IP-226 FIR-H（模态-故障联合归因）

```python
class HybridFaultIsolation:
    HYP = ('H0', 'H_geo', 'H_force', 'H_model', 'H_vis', 'H_policy',
           'H_mode', 'H_gap')

    def posterior(self, rho, sigma_post, guard):
        logp = {}
        for q, ps in sigma_post.items():
            for H in self.HYP:
                if H == 'H_mode':
                    val = self.lik_mode(rho, q, guard, ps)
                elif H == 'H_gap':
                    val = self.lik_gap(rho)          # 与 s(rho) 一致
                else:
                    val = self.lik[(q, H)](rho) + math.log(ps + 1e-12)
                logp[(q, H)] = val + math.log(self.prior[H] + 1e-12)
        return normalize(logp)                        # dict[(q,H)] -> prob

    def decide(self, post, delta_gap, delta_fi):
        p_gap = sum(p for (q, H), p in post.items() if H == 'H_gap')
        if p_gap >= delta_gap:
            return 'GAP', None, False             # 禁止归因
        (q, H), p = max(post.items(), key=lambda kv: kv[1])
        return (H, q), (p >= 1 - delta_fi), (p < 1 - delta_fi)
```

```python
class HybridChunkSafetyCertificate:
    def certify(self, mode_plan, B, post, guard_cov, m_H, alpha_h):
        k_best, cum = 0, 0.0
        for k, e in enumerate(mode_plan.transitions[:m_H]):
            q, qn = e.src, e.dst
            # 1) 逐模态流不变性（守卫不确定扩张集上取最坏）
            if min_flow_barrier(B[q], e.invariant, guard_cov) < 0:

            # 2) 过渡兼容：在 G_e^⊕ 上取最坏

                break

                break
            k_best = k + 1
        return Prefix(k_star=k_best, m_H=m_H)

        # 实时：实际守卫是否比估计早/晚太多
```

## 4. 推导

**引理 9（混合签名可辨识性）** 设 `ρ_q=S_q θ+ε, ε∼N(0,Σ)`，`S_H=stack_q S_q`。四类激励分别贡献独立回归子：
- **持续约束模态 q_roll**：非完整约束残差与牵引残差对 `θ_geo, θ_μ` 敏感（低频、持续）；
- **冲击过渡 q_step**：重置 `R_e` 的 Jacobian `∂R_e/∂x` 与冲击前后速度差对 `θ_model, θ_reset` 敏感，且冲击是宽带输入，使这些列与低频列在频域近正交；
- **低载窗 q_trans/null_roll**：`f_n≈0` 时 F/T 读数给出纯 DC 偏置 `θ_force`，且此时视觉无形变，故 `θ_force` 与 `θ_geo` 的列方向不同；
- **非零速度跨守卫**：过渡时刻对 `θ_guard` 的敏感度 `∂t_e/∂θ_guard≠0`；若守卫以零相对速度被跨越，该列坍缩。
故当四类激励都存在时，`S_H` 列满秩、`κ_H>0`。Laplace 近似下后验协方差 `≈(S_HᵀΣ⁻¹S_H)⁻¹`，归因错误率 `≤exp(−n·κ_H/2)`。若 `Q` 退化为单模态且过渡固定，`S_H` 与 VISTA 的 S 同构，`θ_guard` 与部分 `θ_model` 列不可分——这正是第 65 轮的不可辨识。∎

**引理 10（GEP 的近最优性）** 高斯线性观测下，实验 `a` 的信息增益
`I(θ;ρ|a)=½ log det(I+Σ⁻¹S_aS_aᵀ)`。
函数 `f(A)=½log det(I+Σ⁻¹S_AS_Aᵀ)` 对实验集合 A 单调且子模（Krause–Guestrin 的 Bayesian experimental design 结论）。故贪心选探针（每步取边际信息最大者）达到 `(1−1/e)` 近似最优。加入安全约束（力/形变/翻倒裕度）是对候选集 `A_safe` 的预剪枝，不改变子模性；跨守卫约束 `p_G` 仅进一步限制候选，仍为子模集合上的贪心。∎

**引理 11（混合 barrier 组合）** 设被访问模态序列 `q_0→q_1→…→q_k`，每步 `B_{q_j}≥0`。若 (i) 每模态在 `Inv(q_j)` 上满足 `∇B_{q_j}·F_{q_j}≤−γ|B_{q_j}|`，则模态内不越界；(ii) 每个过渡在 `G_e^⊕` 上满足 `B_{q_{j+1}}∘R_e≥0`，则过渡后仍安全。归纳得整段前缀安全。守卫不确定以 `G_e^⊕=G_e⊕B(0,r_mode)` 吸收；视觉 conformal 覆盖 `1−α_vis`、gap 误报 `α_gap`、模态后验尾部 `δ_fi`，联合界给
`P[前缀内越界] ≤ α_h + α_vis + α_gap + δ_fi + α_geo`。
`k*` 取满足「所有过渡最小裕度≥0 且累计预算≤α_h」的最大前缀，且 `k*≤m_H`，故块承诺不引入超出单过渡的安全新风险。∎

**定理 9（HYDRA 端到端归因-安全）** 在 A88'（模态-故障空间开集但可标定、守卫不确定有界、`|Q|` 有限）下：
1. **空白优先**：若 `P(H_gap|ρ)≥δ_gap`，系统禁止归因、只膨胀 r_gap（定义 237/241），从结构上阻断 VISTA「自信地错误归因」；
2. **已知故障可分离**：四类激励被访问时 `S_H` 列满秩，归因后验指数集中（引理 9），只膨胀被归因的球，不误降级正确几何；
3. **可辨识性可设计**：`κ_H(π)` 可被 CSP-H/GEP 以子模贪心近似最优地提升（引理 10），把被动三阶段升级为主动激励；
4. **混合安全**：逐模态 barrier + 过渡兼容 + `k*≤m_H` 保证前缀安全（引理 11）；
5. **优雅降级**：视觉失效→w_vis↓ 退回 VISTA；力失效→H_force；两者同失效→gap+safe_idle；未建模模态→gap+compliant retreat；
6. **实时性**：语义流承担 HMG/GAP/FIR-H/GEP/CSP-H/AIC-H；实时流仅模态/守卫残差与早停，`≤2.5ms`，零学习写操作。∎

**命题（gap 校准与空白不可自证）**
(i) 在可交换性下，`P[s(ρ)>q_gap|分布内]≤α_gap`（split-conformal 标准结论）。
(ii) **检测功效无免费午餐**：若某模态 `q*` 在标定集与在线运行中都从未被激励，则其签名不出现在 M 中，任意 `s(ρ)` 都不会因「应该去 q*」而升高；系统无法自证该空白。因此开集安全必须附带**模态覆盖假设**：每个 `q∈Q` 需以 `≥p_min` 概率被探针或运行日程访问，否则 `J_hydra` 只能声明「条件安全」，`hybrid_cert` 标注 `coverage='conditional'`。∎

**命题（相对第 65 轮的保守性改进）** 第 65 轮对任意拒绝都把单一 r 膨胀 κ_infl 倍，球体积膨胀 `κ_infl^{d_φ}`。HYDRA 在 H_force 时只膨胀 r_force，r_geo 不变；在 H_gap 时只膨胀 r_gap 且不归因。若几何正确且真实为力偏置，HYDRA 的几何搜索域体积仅为 VISTA 的 `1/κ_infl^{d_geo}`；若为未知复合故障，VISTA 会错误膨胀某个已知球（可能恰好是正确几何），而 HYDRA 保守但**不误导**。∎

## 7. 已知风险

**一句话**：HYDRA 把「有限假设集的不可辨识」换成了「混合模态的覆盖不可验证」——开集检测只能保证分布内误报率，**检测不到一个从未被激励的模态**；而唯一能暴露它的「跨守卫探针」恰恰可能是压垮易损物体、触发打滑或翻倒的那一步。更糟的是守卫估计来自同一批可能被共因欺骗的本体/视觉观测，系统可能在一个被低估的 `r_mode` 下**自信地跨过错误的守卫**，把「研究空白」从被误归类升级为「被证明不存在」。这是本轮全部主动可辨识性与混合证书论证共同依赖的隐藏假设（A88'）。

**次级风险与缓解**：
1. **未激励模态不可检测**：有限覆盖假设的固有限制；缓解：显式 `coverage='conditional'` 标注，运行期强制周期性 `null_roll`/`guard_test` 课程，未访问模态一律按最保守共享膨胀。
2. **跨守卫探针的物理伤害**：探针本身可能越过不可逆点；缓解：GEP 前置 `k*` 预览、易损/陡坡禁用冲击探针、力/形变/翻倒三重预算、视觉-only 退化。
3. **守卫估计与真实守卫共因偏差**：透明/反光/低摩擦同时污染视觉与本体；缓解：AIC-H 显式建共因，`r_mode` 取最坏，共因下只要求判 gap 并降级。
4. **模态词汇表错误（Q 缺失模态）**：真实系统可能有 Q 中没有的模态（如侧滑-滚混合）；缓解：H_gap 覆盖「未知模态」，G_gap 累积后离线扩 Q，扩表前保持保守。
5. **混合 barrier 的求解难度**：高维非线性 barrier 可能不可解；缓解：用 sum-of-squares/采样近似 + 保守包络，不可解即降级为采样验证并标 `cert='sampled'`。
6. **模态边缘化 CVaR 的样本效率**：`n_worst=10` 在高维模态后验下可能欠采样；缓解：按模态后验分层采样，尾部至少覆盖每个非零后验模态一次。
7. **conformal 在分布漂移下失准**：gap 阈值与 `α_vis` 名不副实；缓解：按模态分视界在线重校准 + 漂移检测触发重标定。
8. **实时预算**：HMG 前向-后向与守卫监控逼近 2.5ms；缓解：模态推断降频到语义流、实时只做守卫残差与早停、与 LSF 共享编码。
