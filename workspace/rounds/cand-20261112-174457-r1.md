# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 7 轮；本轮灵感：「仿真训练」×「长程任务」）

> 第 60 轮用 SSM×CIEC×EPIR×SERC×PCE++++ 把闭环从「执行层→证据层」推进到「认知驱动的场景-执行闭环」。但**三个更深的局限**暴露出来：
> 1. **先验全是「人手写死」的**：π_scene(K|z) 的均值方差、ϕ_intent→constraint 的五条规则、τ_scene/τ_K 阈值都由人工设定。真实机器人有几十种桌面粗糙度、上百种意图表达，手写先验既覆盖不全也无法随数据改进。**「仿真训练」**本可以大规模生成这些先验，但一旦引入仿真，sim2real gap 就成为一个**比手写先验更隐蔽的错误源**——模型会在分布内极其自信，在分布外安静地错。
> 2. **长程任务把「单步正确」放大成「系统漂移」**：第 60 轮的 SIC/CESC 只保证单次接触的 K_safe 与单步约束锁定。但当任务变成 T=100~1000 次接触的长程序列时：场景信念逐接触漂移、CIEC 的 2s 锁在长程中反复叠加、EPIR 的 window=100 会**截断**早期证据、B_cog 在任务后半段耗尽。单步 99% 的安全率在 T=500 时只剩 0.6% 的任务成功率——**长程正确性不是单步安全的乘法**。
> 3. **闭环仍然「先失败后适应」**：SERC 是 reactive 的，靠执行下滑才更新场景/信念。仿真真正的价值不是离线拟合先验，而是**在执行前做「前视排练」**：用数字孪生把未来若干步跑一遍，把「失败」提前到不花钱的虚拟空间里。

## 0. 直觉与动机

**灵感 1（仿真训练 → 仿真只是「可校准的提议分布」STCP）**
直觉：不要问「仿真准不准」，要问「仿真的置信度能被现实校准到多准」。把仿真器参数 θ~P_Θ 做域随机化，得到场景-阻抗先验 q_sim(K|z)；但**绝不直接信任 q_sim 的分位数**，而是把它当作一个非一致性分数（nonconformity score），用少量真实「锚点接触」做 **Mondrian 共形校准**，输出的是有有限样本覆盖保证的集合 C_α(z) 而非一个点估计。关键洞见：**仿真的输出不是答案，而是一个可被现实打折的提议（proposal）**；共形校准把「仿真告诉我 K≈k*」改写成「真实 K 落在 C_α(z) 内，概率 ≥1−α」。若分类器把湿滑误判为粗糙桌面，Mondrian 校准按**预测标签**分层，会给出该错误标签下真实 K 的覆盖集——它通常会变宽甚至与 K_safe 不相交，从而**触发安全回退而不是错误收敛**。

**灵感 2（长程任务 → 长程正确性是「不变量账本 + 进度」LHIL）**
直觉：长程任务不是「一万次单步接触」，而是「一组必须始终成立的安全不变量 + 一个单调推进的进度势」。每个 option（抓取、搬运、放置、插拔）登记自己的前置/后置/不变量（Pre/Post/Inv）；长程执行期间维护一个**不变量账本 L**，每步用 EV-exec 校验 L 中所有活跃不变量。关键洞见：**安全性来自「不变量在整条轨迹上单调保持」，活性来自「进度势 Φ 不停滞」**；把「任务成功」拆成 safety(induction) 与 liveness(progress) 两个可分别证明的目标，避免用单步成功率去乘一个无意义的 T 次方。

**灵感 3（长程约束 → 约束租约 CL，而非永久锁）**
直觉：第 60 轮的 φ_lock 是「收到意图就锁 2s」，在长程中会造成两种病：锁在任务后期**堆叠**成过度保守，或旧锁**过期后无声放宽**。改为**约束租约** ℓ=(C_intent, ttl, owner, deps, renew)：租约可续期、可显式解除、可沿 option 链继承；多个活跃租约取**交集**（只收窄、不放宽），解除必须携带后置证据证书。关键洞见：**约束空间的演化必须单调收窄（narrowing-only）**，放宽是一次需要证书的「显式事务」，而不是计时器到点的副作用。

**灵感 4（仿真训练 × 前视 → 数字孪生排练 STR）**
直觉：在执行一个 option 之前，用当前真实信念 b_τ 播种数字孪生，做 N_r 条悲观集成 rollout，用 Clopper–Pearson 上界估计「该 option 违反不变量」的概率 R_up；若 R_up>ρ 就重规划/细化，否则带着「前视证书」执行。关键洞见：**排练的价值必须用 VOI 衡量**——只在「排练能避免的真实失败代价 > 排练算力成本」时排练；长程任务里把 B_sim 优先分配给不确定性高、失败代价大的 option 边界。

**灵感 5（仿真训练 × 长程 → 分歧监测与再校准 SRDM）**
直觉：仿真训练最危险的不是误差大，而是**误差不被发现**。用 CUSUM 监测「仿真预测的 EV-exec 分布」与「真实 EV-exec」的能量距离/Mahalanobis 距离；一旦系统性偏移超阈值，判定 sim 漂移：加宽共形 α、下调仿真先验权重、触发真实锚点探测并重置校准。关键洞见：**长程任务里必须给「现实」留预算**——B_horizon 中固定划出一部分专门用于锚点接触，否则模型会越跑越自信、越自信越错。

**灵感 6（长程证据 → 哈希压缩 HEC）**
直觉：EPIR 只留最近 100 条，长程任务的早期证据会被丢掉，导致「任务级合规性」无法追溯。用「哈希链 + Merkle 山脉」把 EV-exec 累积成 append-only 摘要：每 K 步打一个 checkpoint 锚定到云端，任意历史事件的包含证明 O(log T)、一致性证明 O(1)。关键洞见：**长程证据不需要保存全部原文，只需要保存「不可伪造的顺序承诺」**。

**灵感 7（合流 → 仿真锚定的长程闭环 SALC）**
直觉：STCP 给「可信的场景先验集合」，LHIL 给「必须保持的不变量」，CL 给「单调收窄的约束」，STR 给「执行前的前视风险」，SRDM 给「仿真何时不可信」，HEC 给「长程证据完整性」，PCE+++++ 给「排练/锚点/执行的统一预算」。闭环变成：**观察→共形先验→账本→租约→排练→编译→执行→分歧监测→证据压缩→账本推进**，实现「仿真先行、现实校准、长程有证」。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（仿真训练共形先验 STCP）** 设仿真器族 M_sim(θ)，θ~P_Θ（域随机化：摩擦、质量、传感器噪声、通信时延）。对场景 z，仿真生成样本 {(θ_j, K*_j)}，拟合提议分布 q_sim(K|z)。给定真实锚点校准集 D_z = {(ẑ_i, K_i)}_{i=1}^{n_z}（ẑ_i 为场景分类器输出），非一致性分数 s(z,K) = −log q_sim(K|z)（或对高斯分量取 Mahalanobis 距离）。按**预测标签做 Mondrian 分层**：
- 分位数 q_z = D_z 中第 ⌈(n_z+1)(1−α)⌉ 小的分数（超过 n_z 时取 +∞）
- 校准先验集合 C_α(z) = {K : s(z,K) ≤ q_z}
- **覆盖修正**：因 ẑ 可能 ≠ z_true，定义有效水平 α_eff = α + P(ẑ≠z_true)，用 α_eff 替换 α，得到对真实标签的保守覆盖。
- **安全交集**：K_safe^cal(z) = C_α(z) ∩ K_safe^base；若为空集，返回 FALLBACK_GENERAL，**绝不**用 q_sim 的众数强行填充。
- **漂移后可交换性**：共形保证只在「同一漂移域内可交换」时成立；SRDM 报警即宣告旧域结束，清空并重建 D_z。

**定义 162（长程不变量账本 LHIL）** 任务规划为 option 链 O = (o_1,…,o_T)，每个 o_k=(Pre_k, Post_k, Inv_k, Φ_k, T_k^max)。账本 L_τ = {(j, Inv_j, owner_j, t_j^reg, dep_j, σ_j)}，其中 σ_j 为不变量强度（strong/soft）。执行轨迹 E_{1:τ}：
- **不变量保持**：InvHold(τ) ⇔ ∀j∈L_τ: Inv_j(E_{1:τ}) = true。
- **链式衔接**：Post(o_k)(E) ⇒ Pre(o_{k+1})，否则禁止推进（不得「跳过验收」）。
- **活性**：Φ_τ − Φ_{τ−T_stall} > δ_Φ，否则判定 deadlock，触发 replan。
- **账本演化**：注册仅当 owner 启动且 Pre 成立；注销仅当 owner 完成且 Post 成立；strong 不变量只能由**显式证书**注销，soft 不变量可随 owner 完成注销。
- **长程正确性**：LHCorrect(τ) ⇔ InvHold(τ) ∧ ChainOK(τ) ∧ ProgressOK(τ)。

**定义 163（约束租约 CL）** 租约 ℓ=(C_intent, t_0, ttl, owner, deps, renew_pred, kind)，kind∈{narrowing, safety}。活跃租约集 L_τ，有效约束：
```
C_eff(τ) = ⋂_{ℓ∈L_τ} C(ℓ)
```
- **单调收窄**：新增租约只能取交集；任何放宽必须提交「重新协商证书」Cert_relax，证明放宽后仍满足所有 safety 不变量，否则拒绝。
- **释放**：owner 完成且 Post 成立 ⇒ 可释放 narrowing 租约；safety 租约（如「危险→停」）不可自动过期，只能由等价安全事件解除。
- **续期**：renew_pred(EV-exec)=true 才允许续期；否则 ttl 到点释放，防止「僵尸锁」。
- **响应**：τ_response 沿用定义 154，但把 τ_lease 与 τ_response 分开：τ_response 管「意图→约束生效」，τ_lease 管「约束→资源占用时长」。

**定义 164（数字孪生排练 STR）** 给定信念 b_τ（场景粒子、sim-real 偏移、账本状态）、候选 option o、约束 C_eff。排练算子：
```
Rehearse(b_τ, o, C_eff, N_r, θ~P_Θ^pess):
    for j=1..N_r:
        x_τ ~ b_τ; θ_j ~ PessimisticEnsemble(P_Θ)
        Y_j = Rollout(M_sim(θ_j), x_τ, o, C_eff)
    R_hat = (1/N_r) Σ 1[Y_j violates Inv_o ∪ C_eff]
    R_up  = ClopperPearson_upper(R_hat, N_r, β)
    return R_up
```
- **悲观集成**：取 P_Θ 的 CVaR_β 分位子集或 worst-case θ 集，避免用均值模型自欺。
- **前视证书**：Cert_str = (R_up, N_r, θ-set hash, b_τ hash, 时间戳)；仅当 R_up ≤ ρ 才允许执行。
- **排练的 VOI**：VOI_rehearse = E[避免的失败代价] − c_sim·N_r·H_o；仅当 VOI_rehearse>0 才排练，N_r 由预算与 VOI 联合选。

**定义 165（仿真-现实分歧监测 SRDM）** 观测特征 φ(EV-exec)，令 d_τ = D_E(φ̂_sim, φ_real)（能量距离）或 Mahalanobis 距离。CUSUM：
```
S_τ = max(0, S_{τ−1} + d_τ − μ_0 − k)
alarm = (S_τ > h)
```
报警后执行再校准：① 加宽 α（α←min(1, 2α)）；② 仿真先验权重 w_sim←γ·w_sim；③ 触发一次真实锚点探测并追加 D_z；④ 清空排练证书缓存；⑤ 重置 S_τ=0 并记录「域切换点」。要求 alarm 时 **safety 租约全部保持、narrowing 租约不做任何放宽**。

**定义 166（长程证据压缩 HEC）** 证据链 h_τ = H(h_{τ−1} ‖ EV_τ)，H 为抗碰撞哈希；每 K 步生成 checkpoint C_k=(h_{kK}, sig, k)。用 Merkle 山脉（MMR）维护 append-only 承诺：
- 包含证明 π_incl(τ)：O(log T)
- 一致性证明 π_cons(k1,k2)：O(log T)
- 云端只存 checkpoint，边端可丢原文；验证「EV_τ 属于某 checkpoint」只需 (h_τ, π_incl, C_k)。
- **长程完整性**：任意历史事件可被第三方验证，且无法在不改变后续 checkpoint 的情况下篡改早期证据。

**定义 167（长程-仿真预算 PCE+++++）** B = (B_sim, B_scene, B_intent, B_ros, B_exec, B_horizon)：
- B_sim = (Rollouts_remaining, Fidelity_level, Ensemble_size)
- B_horizon = (Steps_remaining, Anchor_probe_budget, Drift_allowance)
- **锚点预留**：B_horizon 中至少保留 η 比例专用于 SRDM 报警后的锚点探测，任何排练不得挪用。
- **排练调度**：在每个 option 边界解 argmax_{N_r} VOI_rehearse(N_r) s.t. N_r ≤ B_sim.rollouts。
- **长程降级**：若 B_horizon.steps_remaining 低且任务未完成 ⇒ 触发「保守模式」（放弃探索性 option，只执行 Inv 已证明的 option）；若 B_sim 耗尽 ⇒ 关闭排练，退回第 60 轮 SERC。

**定义 168（仿真锚定长程闭环 SALC）** 算子 SALC(M, O, b_0)：
```
① 观察: telemetry_τ ← sense()
② STCP: ẑ_τ ← scene_classifier(telemetry); C_α(ẑ_τ) ← conformal_set(ẑ_τ)
③ LHIL: L_τ ← load_ledger(O, τ); 校验 InvHold(τ−1)
④ CL:   L_τ ← renew/release leases; C_eff ← ∩ C(ℓ)
⑤ STR:  if VOI_rehearse(τ)>0 and B_sim ok:
             R_up ← Rehearse(b_τ, o_τ, C_eff, N_r)
             if R_up > ρ: return REPLAN(o_τ, R_up)
⑥ Compile: K_safe ← EEIS.compile(C_α∩C_eff∩K_safe^base, δ_f_req)
             if ∅: return FALLBACK_GENERAL
⑦ Dispatch: send_impedance_params(K_safe.best, Cert_eeis‖Cert_str)
⑧ Execute: EV-exec ← wait_contact(); HEC.append(hash_chain(EV-exec))
```

### IP-161 STCP（仿真共形先验）

```python
class SimTrainedConformalPrior:
    def __init__(self, sim_model, alpha=0.1):
        self.sim = sim_model
        self.alpha = alpha
        self.calib = defaultdict(list)   # predicted_scene -> scores
        self.q = {}
        self.domain_id = 0

    def score(self, scene, K):
        return -self.sim.log_density(scene, K)

    def add_anchor(self, z_hat, K_true):
        self.calib[z_hat].append(self.score(z_hat, K_true))

    def calibrate(self):
        for z, scores in self.calib.items():
            n = len(scores)
            if n == 0:
                self.q[z] = np.inf
                continue
            rank = min(n, int(np.ceil((n + 1) * (1 - self.alpha_eff(z)))))
            self.q[z] = sorted(scores)[rank - 1]

    def alpha_eff(self, z):
        return min(1.0, self.alpha + self.misclassification_rate.get(z, 0.05))

    def conformal_set(self, z_hat):
        q = self.q.get(z_hat, np.inf)
        return lambda K: self.score(z_hat, K) <= q

    def reset_domain(self):
        self.domain_id += 1
        self.calib.clear(); self.q.clear()
```

### IP-162 LHIL（长程不变量账本）

```python
class LongHorizonInvariantLedger:
    def __init__(self):
        self.active = {}      # id -> invariant record
        self.next_id = 0
        self.progress_hist = deque(maxlen=64)

    def register(self, inv, owner, strong=False):
        if not inv.pre_ok(self.evidence):
            raise PreconditionViolation(owner)
        j = self.next_id; self.next_id += 1
        self.active[j] = dict(inv=inv, owner=owner,
                              strong=strong, t=len(self.evidence))
        return j

    def update(self, ev_exec):
        self.evidence.append(ev_exec)
        for j, rec in list(self.active.items()):
            if not rec['inv'].check(self.evidence):
                if rec['strong']:
                    return ('VIOLATION', j)
                self.active.pop(j)          # soft 可失效，但需记录
        return ('OK', None)

    def advance(self, option):
        if not option.post_ok(self.evidence):
            return 'BLOCK_ADVANCE'
        for j, rec in list(self.active.items()):
            if rec['owner'] == option.id:
                if rec['strong'] and not option.discharge_cert:
                    return 'NEED_CERT'
                self.active.pop(j)
        return 'ADVANCE'
```

### IP-163 CL（约束租约）

```python
class ConstraintLeaseManager:
    def __init__(self):
        self.leases = {}
        self.cert_relax_log = []

    def acquire(self, C_intent, owner, ttl, kind='narrowing', deps=()):
        lid = uuid4()
        self.leases[lid] = dict(C=C_intent, owner=owner,
                                t0=now(), ttl=ttl, kind=kind,
                                deps=set(deps))
        return lid

    def effective(self):
        C_eff = UNIVERSE
        for l in self.leases.values():
            C_eff = intersect(C_eff, l['C'])      # 只收窄
        return C_eff

    def renew(self, lid, ev_exec):
        l = self.leases[lid]
        if l['kind'] == 'narrowing' and l['renew_pred'](ev_exec):
            l['ttl'] = now() + l['ttl_span']
        return l

    def release(self, lid, cert=None):
        l = self.leases[lid]
        if l['kind'] == 'safety' and cert is None:
            return 'DENY_SAFETY_LEASE'
        if cert and cert.proves_relax_safe:
            self.cert_relax_log.append((lid, cert))
            self.leases.pop(lid)
            return 'RELEASED'
        return 'DENY'

    def gc(self):
        for lid, l in list(self.leases.items()):
            if l['kind'] == 'narrowing' and now() > l['t0'] + l['ttl']:
                self.leases.pop(lid)
```

### IP-164 STR（数字孪生排练）

```python
def sim_twin_rehearsal(belief, option, C_eff, budget, beta=0.05):
    if not budget.sim_ok() or voI_rehearse(belief, option) <= 0:
        return None
    N = budget.choose_rollouts(belief, option)
    fails = 0
    for _ in range(N):
        x0 = belief.sample()
        theta = pessimistic_sample(belief.sim_ensemble)
        traj = rollout(belief.sim, theta, x0, option, C_eff)
        fails += int(violates(traj, option.inv) or violates(traj, C_eff))
    R_hat = fails / N
    R_up = clopper_pearson_upper(R_hat, N, beta)
    budget.spend_sim(N)
    return dict(R_up=R_up, N=N, theta_hash=belief.sim_ensemble.hash,
                belief_hash=hash(belief))
```

### IP-165 SRDM（分歧监测）

```python
class SimRealDivergenceMonitor:
    def __init__(self, mu0, k=0.5, h=5.0):
        self.S = 0.0; self.mu0 = mu0; self.k = k; self.h = h

    def update(self, sim_pred_feats, real_feats):
        d = energy_distance(sim_pred_feats, real_feats)
        self.S = max(0.0, self.S + d - self.mu0 - self.k)
        return self.S > self.h

    def recalibrate(self, stcp, lease_mgr):
        stcp.alpha = min(1.0, 2 * stcp.alpha)
        stcp.sim_weight *= 0.5
        stcp.request_anchor_probe()
        stcp.reset_domain()
```

```python
class HorizonEvidenceCommitment:

        self.K = K
```

**假设**：A66（锚点在同一漂移域内可交换；Mondrian 校准按预测标签成立）；A67（每个 option 的不变量在其执行期间可观测、可判定）；A68（悲观集成覆盖真实 θ 的 β 分位；rollout 独立同分布）；A69（CUSUM 的漂移前均值 μ_0 与允许偏移 k 已标定，检测延迟 ≤ D_max）；A70（预算单调消耗，锚点预留 η 不被挪用，B_exec 耗尽时存在安全 fallback）。

**定理（SALC 长程健全性）** 若 A66–A70 成立，则对任意长度 T 的执行：
1. **单步安全**：P(K_true ∈ C_α(ẑ_τ) ∩ C_eff) ≥ 1−α_eff；若交集为空，SALC 返回 FALLBACK_GENERAL，故**不存在「以错误先验强行下发」的路径**。
2. **长程不变量**：若每个 option 执行期间 Inv 保持且推进前 Post 成立，则由归纳，∀τ: InvHold(τ)；strong 不变量只能由证书注销，故不存在「悄悄丢失安全约束」的转移。
3. **约束安全**：C_eff(τ) 在无证书放宽时单调收窄（C_eff(τ+1)⊆C_eff(τ)），因此约束集不会因长程租约过期而意外变宽。
4. **排练有效性**：若排练未报警（R_up≤ρ），则真实失败概率 ≤ ρ + P(sim 偏移未检出)；后者由 SRDM 的检测延迟与锚点预算 η 控制。
5. **证据完整性**：在哈希抗碰撞假设下，任何被 checkpoint 锚定的 EV-exec 不可被篡改而不被发现；长程任务级合规可被第三方以 O(log T) 证明验证。

**长程成功的保守下界**：设每个 option 的真实成功概率 p_k、每次 anchor 再校准后信念误差回到 ε_anchor、每 H 步至少一次锚点（在 B_horizon 允许时），则
```
P(task success) ≥ 1 − Σ_{k=1}^{T} (1−p_k) − P(sim 漂移未被检出) − P(anchor 预算耗尽)
```
该式表明：**长程成功的关键不是把单步 p 提到 0.999，而是让「漂移未检出」与「锚点耗尽」两项可控**——这正是 STR+SRDM+B_horizon 的设计目标。

```python
class SimTrainedConformalPrior:
    def __init__(self, sim_model, alpha=0.1, misclass_rate=None):
        self.sim = sim_model
        self.alpha = alpha
        self.misclass_rate = misclass_rate or {}
        self.calib = defaultdict(list)      # predicted_scene -> scores
        self.q = {}
        self.sim_weight = 1.0
        self.domain_id = 0

    def score(self, scene, K):
        return -self.sim.log_density(scene, K)

    def alpha_eff(self, z):
        return min(1.0, self.alpha + self.misclass_rate.get(z, 0.05))

    def add_anchor(self, z_hat, K_true):
        self.calib[z_hat].append(self.score(z_hat, K_true))

    def calibrate(self):
        for z, scores in self.calib.items():
            n = len(scores)
            if n == 0:
                self.q[z] = np.inf
                continue
            rank = min(n, int(np.ceil((n + 1) * (1 - self.alpha_eff(z)))))
            self.q[z] = sorted(scores)[rank - 1]

    def conformal_set(self, z_hat):
        q = self.q.get(z_hat, np.inf)
        return lambda K: self.score(z_hat, K) <= q

    def reset_domain(self):
        self.domain_id += 1
        self.calib.clear(); self.q.clear()
```

```python
class LongHorizonInvariantLedger:
    def __init__(self, T_stall=12):
        self.active = {}
        self.evidence = []
        self.next_id = 0
        self.T_stall = T_stall
        self.phi_hist = deque(maxlen=64)

    def register(self, inv, owner, strong=False):
        if not inv.pre_ok(self.evidence):
            raise PreconditionViolation(owner)
        j = self.next_id; self.next_id += 1
        self.active[j] = dict(inv=inv, owner=owner,
                              strong=strong, t_reg=len(self.evidence))
        return j

    def update(self, ev_exec):
        self.evidence.append(ev_exec)
        for j, rec in list(self.active.items()):
            if not rec['inv'].check(self.evidence):
                if rec['strong']:
                    return ('VIOLATION', j)
                self.active.pop(j)
        return ('OK', None)

    def advance(self, option):
        if not option.post_ok(self.evidence):
            return 'BLOCK_ADVANCE'
        for j, rec in list(self.active.items()):
            if rec['owner'] == option.id:
                if rec['strong'] and not option.discharge_cert:
                    return 'NEED_CERT'
                self.active.pop(j)
        return 'ADVANCE'

    def progress_ok(self, phi):
        self.phi_hist.append(phi)
        if len(self.phi_hist) < self.T_stall:
            return True
        return self.phi_hist[-1] - self.phi_hist[-self.T_stall] > 0
```

```python
def sim_twin_rehearsal(belief, option, C_eff, budget, beta=0.05):
    if not budget.sim_ok() or voI_rehearse(belief, option) <= 0:
        return None
    N = budget.choose_rollouts(belief, option)
    fails = 0
    for _ in range(N):
        x0 = belief.sample()
        theta = pessimistic_sample(belief.sim_ensemble)
        traj = rollout(belief.sim, theta, x0, option, C_eff)
        fails += int(violates(traj, option.inv) or violates(traj, C_eff))

                belief_hash=hash(belief), timestamp=now())
```

```python
def simulation_anchored_long_horizon_closure(M, options, budget):
    ledger = LongHorizonInvariantLedger()
    leases = ConstraintLeaseManager()
    srmd = SimRealDivergenceMonitor(mu0=M.calibrated_mu0)
    hec = HorizonEvidenceCommitment()
    stcp = SimTrainedConformalPrior(M.sim_model, alpha=M.alpha)

    for tau, option in enumerate(options):
        telemetry = M.sense()
        z_hat = M.scene_classifier(telemetry)
        C_alpha = stcp.conformal_set(z_hat)

        if not ledger.invariant_ok():
            return ('HALT', 'invariant_violation')

        leases.renew_all(M.ev_exec); leases.gc()
        C_eff = leases.effective()

        cert_str = sim_twin_rehearsal(M.belief, option, C_eff, budget)
        if cert_str is None or cert_str['R_up'] > M.rho:
            return ('REPLAN', option, cert_str)

        K_safe = M.eeis.compile(
            intersect(C_alpha, C_eff, M.K_safe_base), M.delta_f_req)
        if K_safe is None:
            return ('FALLBACK_GENERAL', z_hat)

        dispatch(K_safe.best, [M.cert_eeis, cert_str])
        ev_exec = M.wait_contact()
        digest = hec.append(ev_exec)

        if srmd.update(M.sim_predict(option), ev_exec.features):
            srmd.recalibrate(stcp, leases)
            stcp.add_anchor(z_hat, ev_exec.K_estimate)
            stcp.calibrate()

        status = ledger.update(ev_exec)
        if status[0] == 'VIOLATION':
            return ('SAFE_STOP', status[1])
        if not ledger.progress_ok(option.progress):
            return ('REPLAN', 'deadlock')
        if ledger.advance(option) != 'ADVANCE':
            return ('REPLAN', 'postcondition_failed')

        budget.B_steps -= 1
        if budget.degrade_mode() != 'NORMAL':
            return (budget.degrade_mode(), tau)

    return ('TASK_COMPLETE', hec.checkpoints[-1])
```

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| STCP | 校准 O(Σ n_z log n_z)；查询 O(1) | O(Σ n_z) | Mondrian 覆盖 ≥ 1−α_eff |
| LHIL | O(\|L\|) / 步 | O(\|L\|+T) | 归纳保持 + strong 证书注销 |
| CL | O(#leases) / 步 | O(#leases) | 交集单调收窄；safety 不可自动过期 |
| STR | O(N_r·H·C_sim) / 边界 | O(N_r) | P(R_up≥R)≥1−β |
| SRDM | O(1) / 步 | O(1) | CUSUM 检测延迟有界 |
| HEC | O(1) 摊销追加；O(log T) 证明 | O(T) 叶/O(K) checkpoint | 抗碰撞下不可篡改 |
| SALC | 各节点之和 | 复用 | 见定理 SALC |

**定理（SALC 长程健全性）** 在 A66–A70 下：
1. **单步安全**：P(K_true ∈ C_α(ẑ)∩C_eff) ≥ 1−α_eff；若交集为空则回退，故不存在用错误仿真先验强行下发的路径。
2. **长程不变量**：若每个 option 执行期间 Inv 保持且推进前 Post 成立，则归纳得 ∀τ: InvHold(τ)；strong 不变量仅凭证书注销。
3. **约束安全**：无 Cert_relax 时 C_eff(τ+1)⊆C_eff(τ)，长程租约到期不会使约束意外变宽。
4. **排练有效性**：R_up≤ρ 时真实失败率 ≤ ρ + P(sim 漂移未检出)，后者由 SRDM 检测延迟与锚点预留 η 控制。
5. **证据完整性**：抗碰撞假设下，被 checkpoint 锚定的 EV-exec 不可篡改，长程任务级合规可第三方 O(log T) 验证。

**长程成功保守下界**：
```
P(task success) ≥ 1 − Σ_{k=1}^{T}(1−p_k)
                    − P(sim drift undetected)
                    − P(anchor budget exhausted)
```
因此本轮优化的重点不是把 p_k 推到极限，而是把后两项变成可预算、可监测的量。

## 5. 实验设计 E192–E197

| E193 LHIL | 1000 步不变量保持；deadlock 检出延迟 | 违反 0；延迟 ≤ 3 步 |
| E194 CL | 僵尸锁存活时间；过度保守时长；safety 误释放 | 0 次；−50%；0 次 |

**消融设计**：
- w/o STCP（用点先验）：观察误判场景下的灾难性收敛；
- w/o LHIL（用单步 SIC 乘性成功率）：观察长程不变量丢失；
- w/o CL（恢复 2s 永久锁）：观察僵尸锁与过度保守；
- w/o STR：观察「先失败后适应」的执行代价；
- w/o SRDM：观察仿真漂移下的虚假自信；
- w/o HEC（EPIR window=100）：观察早期证据不可追溯。

## 6. 本轮最大风险

**一句话**：仿真训练会制造「分布内校准良好」的假象，而长程任务会把未检出的 sim2real 偏差通过场景先验、租约与排练反复自证，累积成高置信度的系统性失效；必须以「Mondrian 共形覆盖修正」「SRDM 报警即清域重建」「锚点预算 η 不可挪用」「strong 不变量证书注销」「空交集即回退」五重护栏，确保「仿真的自信」永远从属于「现实的证据」。
