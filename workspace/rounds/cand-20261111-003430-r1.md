# 第 51 轮（承接第 50 轮 v14；灵感循环第 6 轮；本轮灵感：激光雷达 × 谐波减速器 × 评测指标） · CoStride-ChannelCert：通道证书 × 资源有界证书 × 指标宪法（八层架构 v15）

> 承接第 50 轮 CoStride-Distill。v14 把安全升级为共创契约 × 双足可行证书 × 证书引导蒸馏，并立下"蒸馏只许近似搜索、绝不近似评估"的不对称；但整座证书栈悬在三个未言明的端点假设上：**H11：安全栈消费的环境几何是完备、新鲜、均匀可信的——地图即世界；H12：执行通道是良界直通——‖u‖≤u_max 就是执行的全部真相；H13：评测是对开发的单向验收——先建系统后产出即可采信**。三个灵感词精确命中：**激光雷达**打破 H11（点云是部分观测：自旋扫描 × 快速步态 = 运动畸变；黑面 = 空洞、玻璃/镜面 = 幻影、雨雾 = 噪声；遮挡 = 不可知体积；标定温漂与振动 = 缓慢漂移；屏障 B 与可行证书 B_v 的求值全部消费地图——**证书强度被传感通道封顶**）；**谐波减速器**打破 H12（柔轮弹性：电机角≠连杆角，关节是一根已知刚度的扭簧；啮合纹波在已知倍频 k·f_mesh 上、幅值随负载增长；滞回在换向处最宽；不可背驱 → 电机端读不出碰撞，必须输出端传感；柔轮疲劳与绕组热 → u_max 随循环数与温度**折旧**——而捕获步恰是"最大扭矩 × 最快换向"的最大纹波工作点）；**评测指标**打破 H13（Goodhart 定律：任何被用作目标的指标都会被游戏化；安全数字若非出自持外对抗协议即是自评；v14 的四个新信任锚——τ_eval 可达性、内核保守度、共创授权、再认证门——本身没有被制度化地度量）。三者耦合出一个统一抽象：**一切证书皆资源有界（resource-bounded certificate）**——传感证书消耗覆盖新鲜度、执行证书消耗寿命循环与热预算、用户共创证书（v14 的 ω_u）消耗兑现记录、租约消耗时间；守卫该问的不是"证书有效吗"而是"证书剩余资源够本动作吗"。本轮在 v14 之上给两端各加一道通道证书、给全栈装上资源余量与常设评测机构，不推倒任何一层。

## 0. 直觉与动机

**灵感 1（激光雷达 → 保真场：把"带洞的地图"当一等公民）**
直觉：地图不是世界，是带洞的信念。双足机器人快速步态下，自旋激光雷达的每个点时间戳不同，运动畸变随速度与步态相位增长；玻璃后的幻影点、黑面的空洞、镜面的镜像、雨雾的噪点都是**有认证失效模式的表面等级**；机器人身后与遮挡体后的体积是"不可知"，而人的影子随人移动、留下需要刷新的尾迹。若屏障求值把洞当自由空间，`B≥0` 的真实含义只是"在我没看见的地方没看见危险"。正确动作：引入**保真场** `f_t: W→[0,1]`（覆盖新鲜度 × 表面等级 × 配准误差 × 时间戳一致性），让所有几何证书消费它；低保真体积按认证膨胀率计入占用——宁可把雾当墙；保真是**主动资源**：看哪、何时重扫、驻足补扫，是提议的一部分。步速与保真耦合：走越快畸变越大，感知自己给出速度上限，与可行性剪辑汇合成 `v* = min(v_viable, v_sense, v_thermal)`。

**灵感 2（谐波减速器 → 执行通道是被认证的弹性信道，且证书会折旧）**
直觉：谐波减速器是双足关节的标准解（近零背隙、大减速比），但它打破了"指令扭矩 = 关节扭矩"的会计恒等式：柔轮让关节成为一根已知刚度的扭簧 `τ ≈ k_el(θ_m−θ_l)`；齿啮合误差产生已知频率 `k·f_mesh` 的纹波、幅值随传递扭矩增长；啮合摩擦的滞回在换向处最宽；波发生器+柔轮+负载构成有阻尼共振模；柔轮弯曲疲劳让寿命以循环数计，绕组热让 `u_max` 随温度下降。于是三件事必须做：(i) **捕获重演**——捕获步恰是最大扭矩、最快换向 = 纹波与滞回的最大工作点，捕获序列必须在认证传动模型下重演证书，激励到共振的换向策略直接拒绝；(ii) **纹波感知屏障裕量**——屏障判据吸收 `m_rip = R_0 + R_1·τ_peak + 滞回(换向次数)`，重复补偿只许吃掉一半，另一半作为认证残差持续监测；(iii) **寿命账本**——循环数与峰值冲击事件入账，`u_max(t) = D(T_w, N)·u_max⁰`，守卫消费 derating 包络；碰撞后的保护决策必须先读账本：剩余包络可能不足以执行原定捕获，需降级到保护姿态。不可背驱还意味着碰撞检测必须输出端扭矩传感——执行端同样需要"传感证书"，与灵感 1 汇合。

**灵感 3（评测指标 → 指标宪法：把评测从验收升级为常设对抗机构）**
直觉：v14 的安全数字挂在四个新信任锚上（求值成本、内核保守性、用户授权、再认证门），但"锚是否成立"没有被制度化地度量；Goodhart 定律保证：一旦 `r_fb`、延迟或成功率成为优化目标，它们就会被刷。因此评测自身要被形式化为**指标宪法**：五族指标**不可互相补偿**（安全数字永远不与效率数字平均）；soundness 只承认**持外对抗协议**产出的数字（红队持实现访问权、独立预算、直接向根信任汇报而非向开发汇报）；阈值**预注册**（先冻结后实现，改阈值 = 新版本入台账）；强制**分布报告**（无尾均值不算数）；**游戏化探测器**（优化指标与独立行为探针分歧 → 触发审计）；**在野持续重评**（通道健康漂移 → 自动再认证触发）；**评测阶梯**（仿真 → 缩比台架 → 全尺寸封闭场 → 开放半受控），每级对"地面真值质量"（如捕获步速度下动捕的延迟与精度）出认证。

**耦合升级**：三者不是三个补丁——**保真衰减最快的时刻（快步态）、纹波最大的时刻（大扭矩换向）、证书最关键的时刻（近捕获边界）是同一时刻**；共振（执行端）会振动标定（感知端），捕获预备要先扫退路。v15 的结构：v14 八层不动，**L1 升级为感知通道与几何层（SCC + 保真场）**、**L3.5 升级为动力通道与可行层（ACC + HVC+ / CRM）**、**L5 升级为指标宪法下的真机评测层（MCB）**，跨层新增**资源余量通道**（所有证书带资源向量，守卫消费余量而非布尔有效性）。

## 1. 形式化定义（增量：定义 87–93）

**定义 87（保真场与传感通道证书 SCC）**
工作空间 `W` 上保真场 `f_t: W→[0,1]`，由四因子合成：覆盖新鲜度 `χ(x,t)`（体积上次被可靠观测的时长 vs 认证半衰期 `τ_f(κ,v)`，步速越快半衰期越短）、表面等级 `s(x)∈{良,黑面,玻璃,镜面,噪源}`（每级带认证的可检测先验与失效模式表）、配准误差上界 `ε_reg(κ,v) ≤ ε_0 + ε_1·v·T_sweep`（自运动畸变认证模型）、时间戳一致性。传感通道证书 `SCC_t(ROI) := (coverage(ROI,f_t) ≥ c_min ∧ ε_reg ≤ ε_cap ∧ ROI 内关键表面已标注 ∧ ts 一致)`。洞的治理规则（单调保守）：`f_t(x) ≤ f_floor` 的体积按认证膨胀率 `ρ(f)` 计入占用，`ρ` 单调（保真越低膨胀越大）；玻璃/镜面后方一律记未知而非自由。主动感知动作 `o_b`（指向/重扫/驻足）成为一等提议维度。

**定义 88（保真耦合可行证书 HVC+）**
`B_v` 升维为 `B_v(z,q,f): Z×Q_m×F→ℝ`，满足**对 f 单调**：ROI 内未知体积越多（f 越低），证书裕量要求越大；`C_cert(f) = {z : B_v(z,q,f) ≥ 0}`。单调性给出**传感退化组合引理**：f 退化只会收缩认证集、绝不扩大——只需证明单调性（远比证明 B_v 本身便宜），即可获得"传感坏了 → 系统变保守"的结构性保证。感知速度上限 `v_sense(z,κ,f)` 由 `ε_reg(κ,v)` 与当前捕获域宽度联合倒出；联合速度调度 `v* = min(v_viable, v_sense, v_thermal)`。

**定义 89（执行通道证书 ACC：认证传动模型与寿命账本）**
每个谐波关节的认证传动模型 `Σ_a = (k_el, R_0, R_1, {k·f_mesh}, H_hyst, f_res, Q, D(T_w,N))`：扭转簧 `τ = k_el(θ_m−θ_l) + δ_fr`；纹波界 `|τ_r(t)| ≤ R_0 + R_1·|τ_load|`（频率 `k·f_mesh` 已知）；滞回带 `H_hyst`（换向处最宽）；共振模 `(f_res, Q)` 认证；热-寿命降额 `u_max(t) = D(T_w, N)·u_max⁰`，柔轮疲劳账本 `N`（循环数 + 峰值冲击事件）只增不减。证书要求：输出端扭矩传感强制（不可背驱 → 电机端读数不可用于碰撞检测）、derating 包络在线强制、账本入 CCL++。执行通道失效项 `α_act` 显式化。

**定义 90（纹波感知屏障裕量与捕获重演）**
屏障判据升级为 `B ≥ m_rip(轨迹) = R_0 + R_1·τ_peak(轨迹) + hysteresis(换向次数)`；捕获序列放行前必须在 `Σ_a` 下**重演**：沿 torque-reversal 轮廓做最坏纹波/共振激励检验，激励到 `(f_res, Q)` 的策略拒绝，降级为更慢但纹波更小的捕获；重复补偿（repetitive control）只许吸收 `m_rip` 的一半，剩余一半作为认证残差持续监测。

**定义 91（提议-感知-处置：联合提议扩维）**
student 候选扩为 `(u_r, a, m, q, ι, κ, o_b)`（+观测动作）；`G_exact` 精确求值清单扩为：`B ∧ B_v(z,q,f) ∧ PFL ∧ Inv ∧ 共识 ∧ 版本 ∧ 租约 ∧ 前瞻保真可行（计划消费的每个 ROI 在其被消费时刻保真 ≥ 阈值）∧ derating 包络 ∧ 寿命余量 ∧ m_rip 残差正常 ∧ 看门狗`。守卫仍只做精确求值、搜索仍可蒸馏——v14 不对称不变，只是求值清单变长（成本重新离线认证）。

**定义 92（指标宪法 MCB 与证伪式评测）**
指标五族且**族间不可补偿**：安全（证伪式：违例数，只承认持外对抗协议）、可用（`r_fb`、延迟、fast-path 命中）、质量（保守度 `|C_cert(f)|/|V|`、覆盖、判层错误）、治理（台账完整率、审计覆盖率、越权/幻影拦截率）、通道健康（保真覆盖、`ε_reg` 残差、纹波残差、derating 余量、寿命消耗率）。反 Goodhart 五机制：预注册、持外对手（持源码 + 独立预算 + 向根信任汇报）、分布报告（分位数强制）、游戏化探测（指标-行为分歧审计）、在野重评（漂移 → 自动再认证）。评测阶梯每级带地面真值质量认证。

**定义 93（十源归因与资源余量账本）**
DDA 八源 → **十源**（+传感保真、+传动），含共振→标定的跨源耦合消歧；CCL++ 扩展事件：保真跌破、膨胀占用、幻影拦截、纹波残差越界、derating 变更、寿命里程碑、评测分歧与游戏化告警。所有证书升级为**资源有界证书** `(C, μ)`：`μ` 为资源余量向量（时间新鲜度/循环/热/覆盖/兑现），带消费模型；守卫校验 `μ ≥ consumption(action)` 而非布尔有效性。v14 的版本钉住、租约、看门狗、`ω_u` 都是该抽象的特例。

## 3. 算法骨架

每个宏周期（v14 十步的通道化改写）：
1. 读目标、证书 `(C_t, μ_t)`、租约、CCL++、版本哈希；校验**所有证书资源余量**（保真新鲜度、derating、寿命、兑现、租约时间）；余量不足 → 资源恢复动作（重扫/冷却/降权）或 fail-closed。
2. SCC 更新保真场：点云去畸变（认证模型，按 κ,v）→ 表面分级 → 膨胀占用合成 → 新鲜度衰减；ROI 保真跌破 → 主动重扫或降速。
3. HTD-Cert 展开；节点声明观测需求；前沿标注 ι 与 κ。
4. 意图信念 `b' = 后验 × 已签承诺`，且 `σ(b') ≤ σ_max(f_t)`；σ 低 → 只留 primitive 或 CRM。
5. UCC 三道闸：能力格 ∧ 可行性剪辑 ∧ 保真剪辑；通过 → 契约更新 → 异步重解/重蒸馏/再认证。
6. KDX 提议-感知-处置：student 提议 `(u_r,a,m,q,ι,κ,o_b)`；`G_exact` 全清单精确求值；通过才执行；否则更多候选 → 限量完整搜索 → CRM。
7. HVC+ 复核 `B_v(z,q,f) ≥ 0` 与 time-to-boundary；接近边界 → 捕获准备（策略已重演认证；预备先扫退路）。
8. ACC 在线包络检查：输出端扭矩 vs 认证模型残差；越界 → 传动异常 → 降额/停走/CRM；循环与峰值冲击入账本。
9. 执行前后 CBG+ 复核：边界蕴含 ∧ 屏障(含 `m_rip`) ∧ 可行 ∧ PFL ∧ 共识 ∧ 版本 ∧ 通道余量；通过才追加 CCL++。
10. 异常（滑移/捕获失败/纹波越界/保真跌破/游戏化告警）→ DDA 十源归因 → 最早安全点再分解/重校准/重蒸馏/CRM。
11. 离线/并行：PFV+LFF（传感 + 执行 + 动力注入）证伪；MCB 在野重评（漂移 → 再认证触发）；XFER 估计 δ 并膨胀 α。
12. 全部路径不可行 → 技能合成/人工接管/保护姿态（先读寿命账本定保护等级）/fail-closed；绝不绕过通道证书、L3.5 与精确守卫。

## 4. 本轮最大风险

**正确性定理（Channel-Compositional Soundness with Resource Margins）**
假设：(A1)–(A12) 承接 v14（其中 MRC 按 CRM、守卫清单按定义 91 扩展）；新增 **(A13)** 膨胀占用规则与保真单调性经台架认证：`f` 低 ⇒ 占用保守膨胀，`B_v(z,q,f)` 对 f 单调且求值与 `C_cert(f)` 定义精确一致；**(A14)** 认证传动模型上界真实覆盖真机纹波/滞回/共振（含负载相关项与磨损余量），输出端传感失效概率计入 `α_act`，残差越界即强制降额；**(A15)** 指标宪法被遵守：一切 soundness 数字仅从持外对抗协议采信，漂移触发自动再认证。则沿路径、交互序列与步态相位，
`P(∀t≤T: z(t)∈Z_safe) ≥ 1 − Σ_i α_i − Σ_i ε_hand,i − α_lease − α_intent − α_user − α_viable − α_cap − α_sense − α_act − Σ_ℓ δ_{ℓ→d}`；
且四条不对称保持：学生误差只提高 `r_fb`（不损 soundness）；传感退化只收缩 `C_cert(f)`（单调引理）；纹波只消耗 `m_rip` 与 derating 包络（不许静默放松阈值）；效率指标永不补偿安全指标（宪法）。**通道证书不进入"证书正确"的证明——它们进入失效预算并受在野证伪治理**；这仍是条件保证：认证集的台架覆盖度、传动模型的真实包络、宪法本身的执行是新的信任锚。

## 6. 本轮最大风险

**一句话**：整条安全链第一次把承重点放在两端的"认证模型覆盖度"上——若真机传感失效模式（黑面幻影、雨雾多径、共振致标定漂移）或执行失效模式（磨损后纹波漂移、换向谐振、账本失准）逃出认证集，"通道退化→保守收缩"的单调保护链就会以"我已认证"的姿态失效；因此通道证书必须资源有界 + 在野证伪 + 残差越界即降额，指标宪法必须常设对抗而非一次性验收。
