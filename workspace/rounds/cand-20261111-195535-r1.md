# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「开源硬件」×「排行榜」）

> 第 54 轮把技能组合推进到动作空间剖面 `α_S` 与云边联合证书 `J`。本轮把视角从"动作空间"转向 **硬件的可复现性与公开比较**：开源硬件让同一技能运行在无数派生板卡上，排行榜让"谁更强"变成公共信号。核心矛盾：H22：证书在参考硬件上成立，却在派生的开源硬件变体上因传感器标定/执行器容差/板级噪声而失效，形成"证书幻觉"；H23：排行榜用均值聚合跨硬件成绩，掩盖长尾硬件上的系统失效，并被参与者的刷榜、选择性报告、仿真污染所俘获。

## 0. 直觉与动机

**灵感 1（开源硬件 → 硬件从常量变成第一性坐标）**
直觉：过去我们把硬件当作"执行底座"，技能 S 的能力写成 `ρ_S`、`α_S`。但开源硬件意味着同一份技能会在无数 fork 上运行：不同 MCU、不同 IMU 标定、不同舵机死区、不同电源纹波。因此能力应是 **硬件条件函数**：`ρ_S(d; h)`、`α_S(a; h)`，其中 `h` 是硬件指纹。**硬件是坐标，不是背景。**

**灵感 2（硬件谱系图 → 证书继承而非证书重算）**
直觉：开源硬件天然形成 fork 谱系：参考设计 → 派生板 → 社区改版。若每块板都重新做全量实验不可行。于是把硬件组织成 **谱系图 `G_H`**，边表示改版关系。父板证书可沿边继承，但必须扣减 **硬件漂移预算 `δ_h`**；漂移超预算的边必须重新认证（re-certify）。这把"证书可复现性"变成图上的继承问题，而不是每次从零重测。

**灵感 3（排行榜 → 从均值排名到分层稳健下界）**
直觉：排行榜若只报平均成功率，会奖励"在主流硬件上过拟合"的技能。应把排行榜做成 **分层稳健榜**：按硬件指纹/谱系簇/风险等级分层，在每层报告认证下界 `LB = ρ_cert - β`，总分取最差层的稳健聚合（min / CVaR / worst-k），并给出 bootstrap 排名区间。**一个技能的名次，只有在它最差的硬件层也被认证时才可信。**

**灵感 4（排行榜完整性 → 防刷榜、防污染、可审计）**
直觉：排行榜是激励系统，必然被 Goodhart 化。需要 **排行榜完整性证书 `LIC`**：记录覆盖矩阵（哪些硬件/动作/环境层被测试）、隐藏硬件层（holdout）、可复现构建哈希、种子与仿真版本、以及排名稳定性区间。提交物必须附 **开源硬件清单 + 构建可复现证明 + 硬件证明（PUF/安全元件）**，以区分"真实硬件跑过"与"仅仿真声称"。

**灵感 5（生态层：开源硬件技能卡与负迁移绊线）**
直觉：开源硬件社区会像共享驱动一样共享"技能包"。每个技能应携带 **硬件条件技能卡 `Card_S = (H_S, ρ_S(·;h), α_S, build_hash, license)`**，声明其有效硬件域 `H_S`。跨 fork 复用时，先用硬件漂移与动作覆盖做兼容性门控；若检测到负迁移（在子板性能反而下降），触发绊线并回退到父板证书 + 重新认证队列。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（硬件配置空间与硬件指纹）**
硬件配置 `h = (BOM, board_rev, sensor_spec, actuator_spec, calib_hash, fw_commit, puf_id)`。硬件指纹 `φ(h) = H(BOM || board_rev || calib_hash || fw_commit || puf_id)`，其中 `H` 为抗碰撞哈希。硬件空间 `ℍ`，观测到的工作点集合 `H_obs ⊆ ℍ`。

**定义 122（硬件条件鲁棒性谱与有效域）**
技能 S 的硬件条件鲁棒性谱 `ρ_S(d; h)`，动作剖面 `α_S(a; h)`。**硬件有效域** `H_S = {h ∈ ℍ | ∀d: ρ_S(d;h) ≥ ρ_min(d) ∧ cover(S,A_T;h)=1}`。证书 `Cert_S = (ρ_S, α_S, H_S, build_hash, evidence)`。

**定义 123（硬件谱系图与继承算子）**
硬件谱系图 `G_H = (V_H, E_H)`，节点为硬件指纹，边 `(h_p→h_c)` 表示派生关系。继承算子 `Inherit(Cert_{h_p}, h_c, δ_h) = Cert_{h_c}`，当且仅当 `drift(h_p,h_c) ≤ δ_h`；否则返回 `re-certify`。

**定义 124（硬件漂移）**
`drift(h_p,h_c) = w_b·d_BOM + w_s·d_sensor + w_a·d_actuator + w_c·d_calib + w_f·d_fw`，各分量为归一化差异（传感器噪声谱、执行器死区/带宽、标定参数、固件行为差异）。**漂移预算** `δ_h` 由任务安全等级决定。要求 `drift` 沿谱系路径**次可加**。

**定义 125（分层稳健排行榜与认证秩）**
排行榜按硬件层 `ℓ ∈ L`（硬件族/谱系簇/风险等级）分层。技能 i 在层 ℓ 的认证下界 `LB_i(ℓ) = ρ_cert,i(ℓ) - β(n_ℓ, 1-α)`（β 为有限样本置信修正）。稳健分数 `R_i = Agg_ℓ LB_i(ℓ)`，其中 `Agg ∈ {min, CVaR_τ, worst-k}`。**认证秩** `rank_cert(i) = rank(R_i)`，并给出 bootstrap 秩区间 `[r_i^-, r_i^+]`。仅当 `r_i^+ - r_i^- ≤ W` 时名次可发布，否则标记 `unranked`。

**定义 126（排行榜完整性证书）**
`LIC = (Coverage, Hidden, Repro, RankStab, Attest)`：
- `Coverage`：硬件层 × 动作层 × 环境层的覆盖矩阵；
- `Hidden`：隐藏硬件层集合与冻结承诺 `commit(H_holdout)`；
- `Repro`：构建哈希、种子、仿真版本、容器镜像摘要；
- `RankStab`：bootstrap 秩区间与排名翻转概率；
- `Attest`：硬件证明（PUF 响应/安全启动测量）。若 `Coverage` 缺层或 `RankStab` 超窗，则榜单条目标记 `unranked`。

## 2. 关键算法 伪代码

### IP-121 HWP（Hardware Provenance Profiling）

```python
def hardware_fingerprint(device):
    manifest = device.read_manifest()          # BOM, rev, fw, calib
    puf = device.puf_challenge_response()      # 绑定物理硬件
    h = {**manifest, 'puf_id': stable_id(puf)}
    return phi(h) if verify_signature(manifest) else raise_tamper()

def estimate_drift(hp, hc):
    return (w_b*bom_dist(hp,hc) + w_s*sensor_spectrum_dist(hp,hc)
            + w_a*actuator_tolerance_dist(hp,hc)
            + w_c*calib_dist(hp,hc) + w_f*firmware_behavior_dist(hp,hc))
```

### IP-122 HCI（Hardware-Conditioned Inheritance）

```python
def inherit_certificate(cert_parent, h_parent, h_child, delta_h, task):
    d = estimate_drift(h_parent, h_child)
    if d > delta_h:
        return ('re-certify', d)
    # 漂移感知地收紧有效域与鲁棒性谱
    rho_child = {dim: max(0.0, cert_parent.rho[dim] - kappa*d)
                 for dim in cert_parent.rho}
    H_child = shrink_domain(cert_parent.H, d)
    if domain_contains(H_child, h_child) and min(rho_child.values()) >= rho_min(task):
        return ('ok', Cert(rho_child, cert_parent.alpha, H_child,
                           cert_parent.build_hash,
                           evidence=['inherit', h_parent, h_child, d]))
    return ('re-certify', d)
```

### IP-123 SRB（Stratified Robust Benchmark）

```python
def stratified_robust_rank(entries, strata, alpha=0.05, tau=0.1):
    per = {}
    for i, e in entries.items():
        per[i] = {}
        for l in strata:
            xs = e.results[l]
            lb = clopper_pearson_lower(sum(xs), len(xs), alpha)  # 认证下界
            per[i][l] = lb if len(xs) >= n_min else None
    R = {i: agg([v for v in per[i].values() if v is not None],
                mode='cvar', tau=tau) for i in entries}
    order = sorted(R, key=R.get, reverse=True)
    lo, hi = bootstrap_rank_interval(per, B=2000)
    return order, R, {i: (lo[i], hi[i]) for i in entries}
```

### IP-124 LIC（Leaderboard Integrity Certificate）

```python
def issue_lic(entry, strata, holdout_commit, build_hash):
    cov = coverage_matrix(entry.results, strata)
    missing = [l for l in strata if cov[l] < min_cov]
    stab = rank_flip_probability(entry, strata)
    if missing or stab > W or not verify_build(entry.manifest, build_hash):
        return ('unranked', LIC(cov, holdout_commit, build_hash, stab, entry.attest))
    return ('ranked', LIC(cov, holdout_commit, build_hash, stab, entry.attest))
```

### IP-125 OSH-T（Open-Source Hardware Transfer）

```python
def osh_transfer(skill_card, h_target, G_H, delta_h, A_T):
    path = shortest_path(G_H, src=skill_card.h_ref, dst=h_target,
                         weight=estimate_drift)
    cert = skill_card.cert
    for (hp, hc) in edges(path):
        status, cert = inherit_certificate(cert, hp, hc, delta_h, A_T)
        if status == 're-certify':
            return ('queue_recert', path, hc)
    if not cover_check(cert.alpha, A_T):
        return ('reject', 'action_mismatch')
    return ('ok', cert)
```

### IP-126 GTW（Goodhart Tripwire）

```python
def goodhart_tripwire(entry, hidden_strata, rank_history):
    # 1) 隐藏硬件层掉分检测
    drop = mean(entry.public_scores) - mean(entry.hidden_scores)
    # 2) 排名异常跃迁（选择性报告/刷榜）
    jump = max(rank_history) - min(rank_history)
    # 3) 仿真-真机差距
    sim_gap = entry.sim_claim - entry.real_score
    if drop > theta_drop or jump > theta_jump or sim_gap > theta_gap:
        return ('flag', dict(drop=drop, jump=jump, sim_gap=sim_gap))
    return ('clean', None)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| HWP | O(|manifest|) | O(1) | 指纹抗碰撞、PUF 不可伪造 |
| HCI | O(|E_H| + |𝔇_ρ|) | O(|H_S|) | 漂移度量满足三角不等式、单调扣减 |
| SRB | O(|L|·|S| + B·|S|log|S|) | O(|S|·|L|) | 认证下界有效、分位可估计 |
| LIC | O(|S|·|L| + B) | O(|S|·|L|) | 覆盖不可抵赖、承诺隐藏 |
| OSH-T | O(|E_H|log|V_H| + |S|·|A|) | O(|V_H|) | 路径漂移可加、覆盖可判定 |
| GTW | O(|S|·|L|) | O(|S|) | 隐藏层不可见、阈值 sound |

**正确性定理（Hardware-Indexed Leaderboard Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 硬件指纹在观测集上抗碰撞且 PUF 绑定真机；**(A30)** 漂移 `drift` 沿谱系路径次可加，即 `drift(h1,h3) ≤ drift(h1,h2)+drift(h2,h3)`；**(A31)** 隐藏硬件层与公开层同分布（或差异被 `Δ_dist` 界定）；**(A32)** 每个上榜条目满足 `Coverage ≥ min_cov` 且 `RankStab ≤ W`。
则对任一上榜技能 i：
```
P(真机成功率 ≥ R_i - ε) ≥ 1 - α - P(δ_h > Θ_h) - Δ_dist - P(Goodhart)
```
即：**排行榜分数是"认证下界"而非"实验均值"，且证书只在其硬件有效域内被信任。**

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 硬件指纹稳定性 | 同板复现率 / 跨板碰撞率 | 复现 ≥ 99%，碰撞 ≤ 1e-6 |
| E163 证书继承 soundness | 继承证书在子板上的失效率 | 误继承 ≤ 5% |
| E164 分层稳健榜 vs 均值榜 | 长尾硬件失效发现率 | 提升 ≥ 20% |
| E165 抗刷榜 | 隐藏层掉分检出率 / 误报 | 检出 ≥ 90%，误报 ≤ 3% |
| E166 开源硬件迁移 | 跨 fork 部署成功率提升 | Δ ≥ 15% |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 硬件指纹可被克隆/伪造 | 高 | PUF + 安全启动 + 远程挑战应答 + 供应链签名 |
| 漂移度量不满足三角不等式 | 高 | 校准漂移度量 + 分段线性化 + 保守上界 |
| 隐藏层与公开层分布偏移 | 高 | 分层抽样 + 分布检验 + 轮换隐藏层 |
| 排行榜被"选择性报告"俘获 | 中 | 强制覆盖矩阵 + 预注册 + 承诺-揭示 |
| 证书继承过度保守导致可用性下降 | 中 | 自适应 `δ_h` + 增量重认证队列 + 优先级调度 |
| 开源硬件供应链断供/改版 | 中 | 硬件谱系图版本化 + 替代板映射 + 回滚锚点 |

## 6. 本轮最大风险

**一句话**：把开源硬件与排行榜引入后，证书从"环境-动作条件"进一步变成"硬件指纹条件"，排行榜从"均值信号"变成"认证下界信号"，但其 soundness **同时依赖硬件指纹不可伪造、漂移度量沿谱系次可加、以及隐藏硬件层与公开层同分布**；一旦指纹可克隆或隐藏层分布漂移，榜单会给出"可复现的假安全"，故必须以 **PUF 真机证明 + 保守可加漂移上界 + 轮换隐藏层 + 预注册覆盖矩阵** 四重护栏，宁可让条目 `unranked`，也不让排行榜成为新的证书幻觉。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（HWP×HCI×SRB×LIC×OSH-T×GTW）

> 承接第 54 轮产物 v31。本轮在动作-鲁棒性双证书体系之上，增加 **硬件条件化、证书继承、分层稳健排行榜、榜单完整性、开源硬件迁移、Goodhart 绊线** 六大算子：

> - **GTW（Goodhart Tripwire）**：刷榜/选择性报告/仿真污染检测。
>

```python
def osh_transfer(skill_card, h_target, G_H, delta_h, A_T):
    path = shortest_path(G_H, src=skill_card.h_ref, dst=h_target,
                         weight=estimate_drift)
    cert = skill_card.cert
    for (hp, hc) in edges(path):
        status, cert = inherit_certificate(cert, hp, hc, delta_h, A_T)
        if status == 're-certify':
            return ('queue_recert', path, hc)
    if not cover_check(cert.alpha, A_T):
        return ('reject', 'action_mismatch')
    return ('ok', cert)
```

```python
def goodhart_tripwire(entry, hidden_strata, rank_history):
    drop = mean(entry.public_scores) - mean(entry.hidden_scores)
    jump = max(rank_history) - min(rank_history)
    sim_gap = entry.sim_claim - entry.real_score
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| HWP | O(|manifest|) | O(1) | 指纹抗碰撞、PUF 不可伪造 |
| HCI | O(|E_H| + |𝔇_ρ|) | O(|H_S|) | 漂移三角不等式、扣减单调 |
| SRB | O(|L|·|S| + B·|S|log|S|) | O(|S|·|L|) | 认证下界有效、稳健聚合 sound |
| LIC | O(|S|·|L| + B) | O(|S|·|L|) | 覆盖不可抵赖、承诺隐藏 |
| OSH-T | O(|E_H|log|V_H| + |S|·|A|) | O(|V_H|) | 路径漂移次可加、覆盖可判定 |
| GTW | O(|S|·|L|) | O(|S|) | 隐藏层不可见、阈值 sound |

**正确性定理（Hardware-Indexed Leaderboard Soundness）**
假设第 54 轮 (A26)-(A28) 成立；**(A29)** 硬件指纹抗碰撞且 PUF 绑定真机；**(A30)** `drift` 沿谱系路径次可加；**(A31)** 隐藏硬件层与公开层同分布（差异由 `Δ_dist` 界定）；**(A32)** 上榜条目满足 `Coverage ≥ min_cov` 且 `RankStab ≤ W`。
则对任一上榜技能 i：
```
P(真机成功率 ≥ R_i - ε) ≥ 1 - α - P(δ_h > Θ_h) - Δ_dist - P(Goodhart)
```
关键：**分数是认证下界而非均值**，**证书只在硬件有效域内被信任**，**榜单条目必须可复现且通过隐藏层检验**。

## 5. 本轮最大风险

**一句话**：把开源硬件与排行榜引入后，证书从"环境-动作条件"进一步变成"硬件指纹条件"，排行榜从"均值信号"变成"认证下界信号"，但其 soundness **同时依赖硬件指纹不可伪造、漂移度量沿谱系次可加、以及隐藏硬件层与公开层同分布**；一旦指纹可克隆或隐藏层分布漂移，榜单会给出"可复现的假安全"，故必须以 **PUF 真机证明 + 保守可加漂移上界 + 轮换隐藏层 + 预注册覆盖矩阵** 四重护栏，宁可让条目 `unranked`，也不让排行榜成为新的证书幻觉。
