# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 1 轮；本轮灵感：「自监督学习」×「实例分割」）

> 第 60 轮 SGEC 把「场景」从物理障碍升级为可预测的阻抗先验 π_scene(K|z)，用 SSM×CIEC×EPIR×SERC 实现了「场景先验提前收敛 K_safe、意图即时锁定约束、证据链防消息丢失」。但它留下**两个结构性隐患**：
> 1. **「整幅场景标签」与「局部接触实例」之间的粒度错配**：SSM 把整张桌面/楼梯当作单一场景类别 z，用全局特征更新 π_scene(K|z)。而机器人真正接触的是**某个具体物体的某个局部实例**（陶瓷杯沿、桌布褶皱、纸箱棱边、金属托盘边缘）——同一场景内不同实例的阻抗可能相差一个数量级。全局场景标签会把「杯沿的脆性」平均进「桌面的刚性」，造成**实例级语义塌缩**：先验越确定，错误越致命。
> 2. **场景先验依赖人工标注的场景类别**：Z_scene 的 10 类场景、每类 μ_scene/Σ_scene 都靠人工先验或离线标注；换新环境、新物体就要重新标注，**无法从无标签执行遥测中自增长**。而机器人最廉价、最海量的数据恰恰是无标签的执行遥测（力-位移-电流-视觉流）。
>
> 本轮灵感「自监督学习」×「实例分割」正好各补一块短板：**实例分割**把「场景」下沉为「接触实例」，**自监督学习**让实例阻抗表征从无标签遥测中自己长出来。核心命题：**把场景先验 π_scene(K|z) 升级为实例先验 π_IL(K|e_i)，其中 e_i 是自监督学到的实例阻抗嵌入，原型库随执行自增长。** 一句话——从「场景查表」走向「实例检索 + 表征自增长」。

## 0. 直觉与动机

**灵感 1（实例分割 → 接触实例分割 CIS）**
直觉：视觉实例分割把像素分配给不同物体；执行层也应把「接触信号场」分配给不同实例。一次接触中，力/触觉/关节电流是一个**时空张量场**，不同物体实例在其中留下不同「指纹」：玻璃杯→高频脆振 + 低阻尼；毛绒玩具→低频大形变 + 高阻尼；金属边→锐利阶跃 + 高刚度；湿滑地面→持续滑移 + 低摩擦。因此对**力-位移-触觉张量**做实例分割，输出掩码 {M_i} 与每个实例的阻抗签名 ψ_i。
关键洞见：**这里的「实例」不是视觉像素，而是「阻抗行为一致的时空连通域」**——同一物体的不同接触点应聚为同一实例，不同物体即使空间相邻也应分开。分割的依据是阻抗动力学的一致性，而非几何邻近性。

**灵感 2（自监督学习 → 执行表征自监督 SSEL）**
直觉：执行遥测天然带**免费的自监督信号**：
- 掩码重建：遮住 t 时刻部分力/触觉通道，用其余时空上下文重建（masked telemetry modeling）；
- 时序预测：用 t 之前的力-位移预测 t+1 的接触力；
- 跨模态对齐：视觉分割掩码 ↔ 力场掩码应互为正样本（对比学习 InfoNCE）；
- 姿态/速度不变性：同一实例在不同抓取姿态、不同速度下，其阻抗嵌入应不变（数据增强不变性）；
- 闭环误差即标签：执行后的 EV-exec 与执行前预测的偏差本身就是一个自由 label。
关键洞见：**不需要人工场景标签，执行过程本身就是监督**——这正好把第 60 轮「人工先验 π_scene」替换为「自监督增长的实例先验 π_IL」。自监督在这里不是噱头，而是解决「场景类别标注不可扩展」的唯一现实路径。

**灵感 3（自监督 × 实例分割 → 实例阻抗库 IIL）**
直觉：把 SSEL 学到的实例嵌入 e_i 与实测阻抗 K_i 配对，存进**实例阻抗库**（原型 codebook）。新接触 → 分割出实例 → 编码 e_i → 最近原型检索 → 给出实例级先验 π_IL(K|e_i) → 喂给 EEIS 编译。
关键洞见：**这是把第 60 轮「场景级查表」细化为「实例级最近邻检索」**，且原型库能在执行中自增长（自监督伪标签 + 新颖性检测 + 防遗忘）。库越大，先验越准；越准，执行误差越小；误差越小，伪标签越干净——形成正反馈，但必须用门控防止它变成「自我强化的错误」。

**灵感 4（三灵感合流 → 自监督实例接地闭环 SIGL）**
直觉：CIS 分割 → SSEL 编码 → IIL 检索先验 → EEIS 编译 K_safe → 执行 → EV-exec → 用预测误差做自监督 → 更新编码器与原型库 → 再分割。形成**「分割-编码-检索-执行-自监督-再分割」**闭环。
与第 60 轮 SERC 的区别：SERC 更新的是「场景后验」（离散、需人工类别），SIGL 更新的是「实例表征与原型库」（连续、可迁移、可自增长）。SERC 是「认识场景」，SIGL 是「认识物体」。

**灵感 5（风险与预算 → 新颖性门控与 PCE+++++）**
直觉：自监督最大的坑是**伪标签确认偏误（confirmation bias）**与**分布漂移下的过度自信**。若实例嵌入把「湿滑地面」误聚成「陶瓷盘」，检索会给出错误先验，而自监督又会不断强化这个错误——这是比第 60 轮更危险的「闭环自欺」。必须加四道闸：嵌入空间的新颖性距离门控（OOD 检测）、双编码器伪标签一致性投票（co-teaching）、原型库的 EWC + replay（防灾难遗忘）、以及实例级 SIC 三元校验。预算从 B_cog 扩为 B_cog+ = (B_seg, B_ssl, B_lib, B_exec)。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（接触实例分割 CIS）** 给定接触时空张量 X_t = (F_t, Δx_t, I_t)（力、位移、关节电流）与可选视觉张量 V_t，实例分割算子 Φ_CIS：
```
Φ_CIS(X_t, V_t) = {(M_i, ψ_i, e_i)}_{i=1}^{m}
```
其中：
- **实例掩码** M_i ∈ {0,1}^{T×S}（T 为时间窗、S 为触元/接触点集合），表示第 i 个阻抗一致连通域；
- **阻抗签名** ψ_i = (K_p,i, K_d,i, ζ_i, f_res,i)（刚度、阻尼、阻尼比、共振频率），由 M_i 内遥测拟合；
- **实例嵌入** e_i = f_θ(M_i ⊙ X_t) ∈ R^d。
约束：Σ_i M_i ≤ 1（每个时空点至多属一个实例，允许「未接触」空集）；|M_i| ≥ τ_area（抑制碎片）；若 d(ψ_i, ψ_j) < τ_merge 则合并 i,j（同一物体的分段接触）。

**定义 162（自监督执行表征 SSEL）** 编码器 f_θ: X → R^d，自监督预训练目标：
```
L_ssl(θ) = L_mask + λ₁·L_temp + λ₂·L_cross + λ₃·L_inv + λ₄·L_pred
```
- **L_mask**：掩码遥测重建，随机遮挡 15% 时空点，重建被遮挡的 F；
- **L_temp**：时序预测，用 t 前窗口预测 t+1 接触力；
- **L_cross**：视觉掩码 ↔ 力场掩码的对比对齐（InfoNCE），同一实例的 (V 掩码, F 掩码) 为正样本，batch 内其他实例为负样本；
- **L_inv**：同一实例在不同姿态/速度增强下嵌入不变；
- **L_pred**：执行后 EV-exec 偏差作为自由 label 的预测误差回归。
关键：**L_cross 与 L_inv 保证嵌入是「实例身份」而非「传感器噪声」的编码**，这是后续检索可靠的前提。

**定义 163（实例阻抗库 IIL）** 原型库 P = {(c_j, μ_j, Σ_j, n_j)}_{j=1}^{N_p}：c_j ∈ R^d 为原型嵌入，μ_j/Σ_j 为对应阻抗高斯先验，n_j 为样本计数。检索与更新：
```
d(e_i, c_j) = sqrt((e_i − c_j)ᵀ Σ_e⁻¹ (e_i − c_j))
j* = argmin_j d(e_i, c_j)
if d_min ≤ τ_novel:
    π_IL(K|e_i) = N(K; μ_{j*}, Σ_{j*} + σ_e²I)
else:
    π_IL(K|e_i) = π_scene^general        # 未知实例回退
μ_{j*} ← (n_{j*}·μ_{j*} + K_obs) / (n_{j*} + 1)   # 在线均值
Σ_{j*} ← Welford_update(Σ_{j*}, K_obs)            # 在线协方差
if d_min > τ_novel for k consecutive frames: insert c_{N_p+1} = e_i
```
关键：**τ_novel 是「认知谦逊」的旋钮**——库外实例一律回退通用先验，宁可保守也不硬套。

**定义 164（自监督实例接地闭环 SIGL）** 算子 SIGL(M, X_t, V_t, δ_f_req)：
```
① CIS:      {(M_i, ψ_i, e_i)} ← Φ_CIS(X_t, V_t)
② SSL-enc:  e_i ← f_θ(M_i ⊙ X_t)
③ IIL:      (π_IL(K|e_i), d_min) ← P.retrieve(e_i)
④ Novelty:  if d_min > τ_novel: π_IL ← π_scene^general; flag_unknown = True
⑤ EEIS:     K_safe^i ← EEIS.compile(δ_f_req, π_IL, Z_env)   # 逐实例编译
⑥ Dispatch: ERTC.lock(K_safe^i); send_impedance_params(K_safe^i, Cert)
⑦ Execute:  X_{t+1} ← wait_contact()
⑧ EV-exec:  EV_i ← build_exec_evidence(X_{t+1}, K_safe^i)
⑨ SSL-upd:  L_pred = ‖F_{t+1} − F̂_{t+1}‖
             if PLCG.consistent(e_i, K_obs^i): P.update(e_i, K_obs^i)
             θ ← θ − η∇L_ssl (仅在 B_ssl 允许时)
⑩ Return:   (instances, {K_safe^i}, EV-exec, {π_IL}, flag_unknown)
```

**定义 165（实例级 SIC 三元一致性）** SIC_inst = (inst_certainty(e_i), K_certainty(K|e_i), exec_feasibility(K|e_i))：
- **实例置信**：inst_certainty(e_i) = softmax_j(−d(e_i, c_j)) 在原型上的检索后验；
- **判定**：SIC_inst_valid = inst_certainty(e_i) ≥ τ_inst ∧ d_min ≤ τ_novel ∧ exec_feasibility = true；
- **更新**：inst_certainty ← β·inst_certainty + (1−β)·exp(−L_pred)，即用自监督预测误差反向校准检索置信。
与第 60 轮 SIC（场景-阻抗-置信度）的关系：SIC_inst 是 SIC 在**实例粒度**上的细化，二者是包含关系而非替代。

**定义 166（伪标签一致性门控 PLCG）** 双编码器 f_θ1、f_θ2（不同初始化/不同增强），对实例 i 给出阻抗预测 (K_i¹, K_i²)：
- **一致性**：cons_i = exp(−‖K_i¹ − K_i²‖ / σ)；
- **入库规则**：若 cons_i ≥ τ_cons 且两者都通过 SIC_inst 门控，则接受伪标签 K_i ← (K_i¹ + K_i²)/2 并 P.update；
- **否则**：标记 low-confidence，仅用于推理、**不入库**（切断确认偏误的自我强化）；
- **类别不平衡**：class-balanced replay buffer，每原型保留 n_j 条代表遥测。

**定义 167（认知预算 PCE+++++）** B_cog+ = (B_seg, B_ssl, B_lib, B_exec)：
- **B_seg** = (mask_resolution, max_instances, seg_latency)
- **B_ssl** = (grad_steps, replay_size, encoder_update_rate)
- **B_lib** = (prototype_capacity, retrieval_budget, crosstalk_tolerance)
- **B_exec** = (WCET_slack, Bus_bw_slack, Thermal_slack, Prio_headroom)（原有）

**PCE+++++ VOI 扩展**：
```
voi_cog+(π) = VOI_meta_pessimistic(π) − cost_seg(π) − cost_ssl(π) − cost_lib(π) − cost_exec(π)
cost_seg = λ_seg·Mask_compute + λ_lat·Seg_latency
cost_ssl = λ_grad·Grad_steps + λ_mem·Replay_mem
cost_lib = λ_ret·Retrieval_ops + λ_ct·Prototype_crosstalk
```
**降级链**：B_seg 耗尽 → 沿用上一帧掩码（mask persistence）；B_ssl 耗尽 → 冻结 θ，仅做原型检索；B_lib 达容量 → 按重要性/LRU 淘汰原型；B_exec 耗尽 → 第 60 轮原有降级。任一维度耗尽都必须先降到**保守先验**，再谈性能。

**定义 168（防灾难遗忘与原型演化）** 原型库与编码器联合更新带 EWC + replay：
```
L_ewc = L_ssl + (λ_ewc/2)·Σ_j Ω_j·‖θ − θ_j*‖²
```
其中 Ω_j 为原型 j 的 Fisher 信息对角近似，θ_j* 为上次巩固参数；replay buffer 每原型保留代表样本。新原型插入前对「与最相似原型是否显著不同」做 Wald 检验（均值差 / 合并方差），避免把噪声当新类——**「库外即未知」与「噪声即新类」是同一枚硬币的两面，必须用统计检验区分**。

### IP-161 CIS（接触实例分割）

```python
class ContactInstanceSegmenter:
    def __init__(self, min_area=8, merge_thresh=0.25):
        self.min_area = min_area
        self.merge_thresh = merge_thresh

    def segment(self, force_field, disp_field, current, visual=None):
        # force_field: [T, S], disp_field: [T, S], current: [T, S]
        energy = np.abs(force_field) + 0.5 * np.abs(disp_field) + 0.2 * np.abs(current)
        binary = energy > self._adaptive_threshold(energy)
        regions = self._connected_components(binary)  # 时空 6-邻域连通
        instances = []
        for mask in regions:
            if mask.sum() < self.min_area:
                continue
            psi = self._fit_impedance_signature(force_field, disp_field, mask)
            instances.append({'mask': mask, 'psi': psi})
        instances = self._merge_similar(instances, self.merge_thresh)
        return instances

    def _fit_impedance_signature(self, F, dx, mask):
        # 二阶系统拟合: F = K_p*dx + K_d*ddx (+ 谐振项)
        K_p, K_d = self._least_squares_impedance(F[mask], dx[mask])
        zeta = K_d / (2 * np.sqrt(max(K_p, 1e-6)))
        f_res = self._dominant_freq(F[mask])
        return {'K_p': K_p, 'K_d': K_d, 'zeta': zeta, 'f_res': f_res}
```

### IP-162 SSEL（自监督执行表征）

```python
class SelfSupervisedExecEncoder(nn.Module):
    def __init__(self, in_ch=3, d=64):
        super().__init__()
        self.enc = nn.Sequential(
            nn.Conv2d(in_ch, 32, 3, padding=1), nn.GELU(),
            nn.Conv2d(32, 64, 3, padding=1), nn.GELU(),
            nn.AdaptiveAvgPool2d(1), nn.Flatten(), nn.Linear(64, d)
        )
        self.mask_head = nn.Linear(d, in_ch)          # L_mask
        self.temp_head = nn.Linear(d, 1)              # L_temp
        self.proj = nn.Linear(d, 32)                  # L_cross / L_inv

    def forward(self, x, mask=None):
        if mask is not None:
            x = x * (1 - mask)                        # 随机遮挡
        e = self.enc(x)
        return e, self.mask_head(e), self.temp_head(e)

    def ssl_loss(self, x, x_next, e_pos, e_neg, pred_err):
        e, rec, pred = self.forward(x, self._random_mask(x))
        L_mask = F.mse_loss(rec, x.mean(dim=(2, 3)))
        L_temp = F.mse_loss(pred, x_next.mean(dim=(1, 2, 3)))
        z = F.normalize(self.proj(e), dim=-1)
        L_cross = info_nce(z, e_pos, e_neg)           # 跨模态对齐
        L_inv = 1 - F.cosine_similarity(e, e_pos, dim=-1).mean()
        L_pred = F.mse_loss(pred, pred_err)           # 闭环误差自监督
        return L_mask + L_temp + L_cross + L_inv + L_pred
```

### IP-163 IIL（实例阻抗库）

```python
class InstanceImpedanceLibrary:
    def __init__(self, d=64, capacity=256, tau_novel=0.35, sigma_e=0.05):
        self.c = np.zeros((0, d))
        self.mu = np.zeros((0, 4))       # [K_p, K_d, zeta, f_res]
        self.Sigma = np.zeros((0, 4, 4))
        self.n = np.zeros(0)
        self.capacity = capacity
        self.tau_novel = tau_novel
        self.sigma_e = sigma_e

    def retrieve(self, e):
        if len(self.c) == 0:
            return None, np.inf
        d = np.linalg.norm(self.c - e, axis=1)
        j = int(np.argmin(d))
        return (self.mu[j], self.Sigma[j] + self.sigma_e**2 * np.eye(4)), d[j]

    def update(self, e, K_obs, significant=True):
        prior, d_min = self.retrieve(e)
        if d_min > self.tau_novel:
            if significant and len(self.c) < self.capacity:
                self._insert(e, K_obs)
            return
        j = int(np.argmin(np.linalg.norm(self.c - e, axis=1)))
        self.n[j] += 1
        delta = K_obs - self.mu[j]
        self.mu[j] += delta / self.n[j]
        self.Sigma[j] += np.outer(delta, K_obs - self.mu[j])
        if self.n[j] > 1:
            self.Sigma[j] /= (self.n[j] - 1)

    def _insert(self, e, K_obs):
        self.c = np.vstack([self.c, e])
        self.mu = np.vstack([self.mu, K_obs[None]])
        self.Sigma = np.concatenate([self.Sigma, np.eye(4)[None] * 0.1])
        self.n = np.append(self.n, 1)
```

### IP-164 SIGL（自监督实例接地闭环）

```python
def self_supervised_instance_grounding_loop(M, X_t, V_t, delta_f_req):
    instances = M.cis.segment(X_t.force, X_t.disp, X_t.current, V_t)
    results = []
    for inst in instances:
        e_i = M.ssl.enc(inst['mask'] * X_t.tensor)
        prior, d_min = M.iil.retrieve(e_i.detach().numpy())
        unknown = d_min > M.iil.tau_novel
        if unknown:
            prior = M.scene_prior_general
        K_safe = M.eeis.compile(delta_f_req, prior, M.env)
        M.ertc.lock(K_safe)
        dispatch_impedance_params(K_safe.best, M.cert)
        results.append({'inst': inst, 'K_safe': K_safe, 'unknown': unknown})

    X_next = wait_contact()
    for r in results:
        EV = build_exec_evidence(X_next, r['K_safe'])
        e_i = M.ssl.enc(r['inst']['mask'] * X_t.tensor)
        K_obs = EV.impedance
        if M.plcg.consistent(e_i, K_obs):
            M.iil.update(e_i.detach().numpy(), K_obs)
        if not M.budget.is_ssl_exhausted():
            M.ssl.train_step(X_t.tensor, X_next.tensor, pred_err=EV.residual)
    return results, X_next
```

### IP-166 PLCG（伪标签一致性门控）

```python
class PseudoLabelConsistencyGate:
    def __init__(self, tau_cons=0.85, sigma=0.1):
        self.tau_cons = tau_cons
        self.sigma = sigma

    def consistent(self, e_i, K_obs):
        K1 = self.model1.predict(e_i)
        K2 = self.model2.predict(e_i)
        cons = np.exp(-np.linalg.norm(K1 - K2) / self.sigma)
        agree = np.linalg.norm(K_obs - 0.5 * (K1 + K2)) < 2 * self.sigma
```

```python
class ContactInstanceSegmenter:
    def __init__(self, min_area=8, merge_thresh=0.25):
        self.min_area = min_area
        self.merge_thresh = merge_thresh

    def segment(self, force_field, disp_field, current, visual=None):
        energy = np.abs(force_field) + 0.5 * np.abs(disp_field) + 0.2 * np.abs(current)
        binary = energy > self._adaptive_threshold(energy)
        regions = self._connected_components(binary)
        instances = []
        for mask in regions:
            if mask.sum() < self.min_area:
                continue
            psi = self._fit_impedance_signature(force_field, disp_field, mask)
            instances.append({'mask': mask, 'psi': psi})
        return self._merge_similar(instances, self.merge_thresh)

    def _fit_impedance_signature(self, F, dx, mask):
        K_p, K_d = self._least_squares_impedance(F[mask], dx[mask])
        zeta = K_d / (2 * np.sqrt(max(K_p, 1e-6)))
        f_res = self._dominant_freq(F[mask])
        return {'K_p': K_p, 'K_d': K_d, 'zeta': zeta, 'f_res': f_res}
```

### IP-162 SSEL（自监督执行表征）

```python
class SelfSupervisedExecEncoder(nn.Module):
    def __init__(self, in_ch=3, d=64):
        super().__init__()
        self.enc = nn.Sequential(
            nn.Conv2d(in_ch, 32, 3, padding=1), nn.GELU(),
            nn.Conv2d(32, 64, 3, padding=1), nn.GELU(),
            nn.AdaptiveAvgPool2d(1), nn.Flatten(), nn.Linear(64, d)
        )
        self.mask_head = nn.Linear(d, in_ch)
        self.temp_head = nn.Linear(d, 1)
        self.proj = nn.Linear(d, 32)

    def forward(self, x, mask=None):
        if mask is not None:
            x = x * (1 - mask)
        e = self.enc(x)
        return e, self.mask_head(e), self.temp_head(e)

    def ssl_loss(self, x, x_next, e_pos, e_neg, pred_err):
        e, rec, pred = self.forward(x, self._random_mask(x))
        L_mask = F.mse_loss(rec, x.mean(dim=(2, 3)))
        L_temp = F.mse_loss(pred, x_next.mean(dim=(1, 2, 3)))
        z = F.normalize(self.proj(e), dim=-1)
        L_cross = info_nce(z, e_pos, e_neg)
        L_inv = 1 - F.cosine_similarity(e, e_pos, dim=-1).mean()
        L_pred = F.mse_loss(pred, pred_err)
        return L_mask + L_temp + L_cross + L_inv + L_pred
```

### IP-163 IIL（实例阻抗库）

```python
class InstanceImpedanceLibrary:
    def __init__(self, d=64, capacity=256, tau_novel=0.35, sigma_e=0.05):
        self.c = np.zeros((0, d))
        self.mu = np.zeros((0, 4))
        self.Sigma = np.zeros((0, 4, 4))
        self.n = np.zeros(0)
        self.capacity, self.tau_novel, self.sigma_e = capacity, tau_novel, sigma_e

    def retrieve(self, e):
        if len(self.c) == 0:
            return None, np.inf
        d = np.linalg.norm(self.c - e, axis=1)
        j = int(np.argmin(d))
        return (self.mu[j], self.Sigma[j] + self.sigma_e**2 * np.eye(4)), d[j]

    def update(self, e, K_obs, significant=True):
        _, d_min = self.retrieve(e)
        if d_min > self.tau_novel:
            if significant and len(self.c) < self.capacity:
                self._insert(e, K_obs)
            return
        j = int(np.argmin(np.linalg.norm(self.c - e, axis=1)))
        self.n[j] += 1
        delta = K_obs - self.mu[j]
        self.mu[j] += delta / self.n[j]
        self.Sigma[j] += np.outer(delta, K_obs - self.mu[j])
        if self.n[j] > 1:
            self.Sigma[j] /= (self.n[j] - 1)

    def _insert(self, e, K_obs):
        self.c = np.vstack([self.c, e])
        self.mu = np.vstack([self.mu, K_obs[None]])
        self.Sigma = np.concatenate([self.Sigma, np.eye(4)[None] * 0.1])
        self.n = np.append(self.n, 1)
```

```python
def instance_sic(inst, prior, d_min, feasible, L_pred, beta=0.9):
    dists = np.array([np.linalg.norm(inst['e'] - c) for c in prior.library.c])
```

### IP-166 PLCG（伪标签一致性门控）

```python
class PseudoLabelConsistencyGate:
    def __init__(self, model1, model2, tau_cons=0.85, sigma=0.1):
        self.model1, self.model2 = model1, model2
        self.tau_cons, self.sigma = tau_cons, sigma

    def consistent(self, e_i, K_obs):
        K1 = self.model1.predict(e_i)
        K2 = self.model2.predict(e_i)
        cons = np.exp(-np.linalg.norm(K1 - K2) / self.sigma)
        agree = np.linalg.norm(K_obs - 0.5 * (K1 + K2)) < 2 * self.sigma
        return cons >= self.tau_cons and agree
```
