# 第 47 轮（承接第 46 轮 v23；本轮灵感：论文创新点 × 异常检测） · AD-Cert：异常检测驱动的分布漂移鲁棒姿态证书（五层架构 v11）

> 承接第 46 轮 v23 Memory-Safety-Voice。v23 把记忆检索、语音分发、安全绑定接入能量-上下文-深度框架，但整套证书体系仍建立在隐含假设 H5：**标定分布与部署分布可交换（exchangeability）**。UniBot 实机一旦遇到透明/镜面/弱纹理的分布外场景、镜头污染、光照突变、未见物体，共形证书的名义覆盖率 1-α 会静默失效——这是比能量耗尽更隐蔽的失效源。两个灵感词精确命中 H5：**异常检测**提供了探测「不可交换」信号的探针，其分数可解释为密度比 p_test(x)/p_cal(x) 的估计，从而把加权共形预测的覆盖保证引入；**论文创新点**是元层提醒——过去 10 轮堆了 60+ IP，真正可发表的是「异常分数作为证书膨胀算子 + 有界漂移下的覆盖定理」这一理论接口，而非又一个工程模块。耦合出新问题：**如何把三轴异常分数（输入/残差/上下文）变成证书签发的一等公民，在漂移下仍给出可证明的覆盖下界，同时不因异常检测器自身盲区制造虚假安全感**。

## 0. 直觉与动机

**灵感 1（异常检测 → 覆盖保证的裂缝）**
直觉：共形预测的 1-α 覆盖率是「可交换世界」里的承诺。真实部署中，异常（OOD 场景、传感器退化、对抗纹理）正是破坏可交换性的东西。异常检测不是旁路告警，而是**可交换性的诊断器**：它的分数单调于 -log p(x)，因此天然是密度比的代理。把异常分数当作权重喂给加权共形（weighted conformal），覆盖率下界就能从「可交换」放宽到「有界协变量漂移」。

**灵感 2（论文创新点 → novelty ledger）**
直觉：工程集成堆不出论文。真正新颖的是一条**可证明的接口**：异常分数 a → 证书半径 R(a) → 覆盖下界 P ≥ 1-α - ε(a)。需要显式维护 novelty ledger，把「工程集成（IP 编号堆叠）」与「理论贡献（定理/界限）」分层，避免把模块数量当创新。

**灵感 3（三轴异常 → 信任质量）**
直觉：单一输入异常不够。姿态估计器的**残差异常**（预测残差超过标定分位）和上下文预测器与观测的**上下文异常**（预测退化层与实测层冲突）各自独立地破坏覆盖。三轴融合成信任质量 T_t∈(0,1]，直接调制证书半径、能量门控与语音安全绑定。

**耦合升级**：在 v10 四层架构上加第 0.5 层 **ADM 异常监控层**（作为根信任的输入）。ADM 输出三轴 a_t 与密度比权重 ŵ；SWC 用 ŵ 重算加权分位签发漂移鲁棒证书；AIL 用 a_t 膨胀半径并在越界时 fail-closed；ECPS/MVR/SAB/CAR 全部以 T_t 为门控乘子。五层 v11：根信任层（含能量租约 + 异常权重）→ L1 几何层（异常膨胀半径）→ L2 上下文层（上下文异常回灌）→ L3 安全层（T_t 门控）→ L4 采集层（异常主动收割）。

## 1. 形式化定义（增量：定义 59–63）

**定义 59（三轴异常分数）**
a_t = (a_in, a_res, a_ctx) ∈ R³₊：
- 输入异常 a_in(x_t) = -log p̂_feat(x_t)，p̂_feat 为感知特征的 energy-based 密度模型；
- 残差异常 a_res = (1/σ̂_res)·||r_t||，r_t 为姿态估计残差，σ̂_res 为标定残差尺度；
- 上下文异常 a_ctx = KL( P(ω|c_t,m) || P̂_obs(ω) )，即预测可观测性分布与实测经验分布的散度。

**定义 60（异常分数作为密度比估计）**
在协变量漂移假设 p_test(x) ≠ p_cal(x)、p(y|x) 不变下，likelihood ratio w(x)=p_test(x)/p_cal(x)。若 a_in 归一化为对数密度，则权重估计
ŵ(x) = exp(â_in^cal - â_in(x))，并投影到 [w_min, w_max]。
**漂移有界假设 H5'**：存在 ε_w 使 E|ŵ(x) - w(x)| ≤ ε_w。

**定义 61（漂移鲁棒加权共形证书）**
非一致性分数 s(x,y)=base(x,y)（**不得**用异常分数污染 base，避免循环论证）。对标定集 {(x_i,s_i)} 赋权 w_i=ŵ(x_i)。漂移鲁棒证书
C_t = { y : s(x_t,y) ≤ Q_{1-α}( {s_i}, {w_i} ) }。
**覆盖下界**：P(Y_{t+1}∈C_t) ≥ 1-α - ½·ε_w。

**定义 62（信任质量融合）**
T_t = exp( -Σ_{i∈{in,res,ctx}} η_i·a_i ) ∈ (0,1]，η_i≥0 为标定灵敏度。
T_t 作为所有下游决策的**门控乘子**：效用乘以 T_t，风险除以 T_t。

**定义 63（异常触发的证书膨胀/失效）**
半径 R_t = r_ω(m)·(1 + λ·max(0, a_in - a_cal)) / T_t。
**失效判据**：若 a_in > a_fail 或 ŵ ∉ [w_min,w_max] 或 T_t < T_min，则证书作废、fail-closed。**膨胀单调性**：a 越大 R_t 越大（保守），杜绝「异常时反而自信」。

## 2. 新增 IP 与既有 IP 升级

**IP-69 ADM（Anomaly Detection Monitor）**
- 三轴评分器：energy-based 特征 OOD + 姿态残差标准化 + 上下文 KL
- 密度比估计与有界投影 ŵ
- 异常分数流式发布（100ms），供 SWC/AIL/CAR 订阅

**IP-70 SWC（Shift-Weighted Certificate）**
- 带权分位计算（加权共形）
- ε_w 在线审计：用独立审计集估计密度比误差
- 覆盖下界证书随证书一起签发（coverage receipt）

**IP-71 AIL（Anomaly Inflation Layer）**
- 半径膨胀算子 R(a,T)
- 失效级联：a 越界→证书作废→CAR fail-closed
- 膨胀单调性守卫（红队测试）

**既有 IP 升级**
IP-60 PSE：半径查表 r_ω(m) → R_t(a,T)
IP-63 ECPS：效用 U ← T_t·U，风险 ← Risk_e/T_t
IP-66 MVR：记忆检索增加异常距离项，T_t<T_min 时禁用记忆复用
IP-68 SAB：绑定概率 B ← B·T_t，低于 θ_safe 入队
IP-61 DCL：异常主动收割（按 a_t 排序的主动学习采样）
IP-62 CCA：新增异常逃逸红队、膨胀单调性测试、密度比误差注入
IP-51 CAR：守卫加入 T_t≥T_min 与 ε_w≤ε_max
IP-45 总线：anomaly-score / weight / coverage-receipt / trust-mass 话题

## 3. 算法骨架

AD-Cert 每控制周期：
1. 采集 x_t，计算三轴 a_t=(a_in,a_res,a_ctx)
2. ADM 估计 ŵ，投影到 [w_min,w_max]，更新 ε_w
3. 融合 T_t=exp(-Ση_i a_i)
4. SWC 带权分位签发 C_t，附覆盖收据（含 1-α-½ε_w）
5. AIL 计算 R_t，若越界/失效→作废证书
6. PSE 用 R_t 签发 P_t(m_t)，ECPS 效用乘以 T_t
7. CAR 守卫 T_t≥T_min、ε_w≤ε_max、R_t 未膨胀越界
8. 异常样本回灌 DCL 主动收割

## 4. 本轮最大风险

**一句话**：异常检测器自身的盲区会制造「虚假安全感」——对抗性或全新异常可让 a_in 保持低分，从而 ŵ 接近 1、证书不膨胀，覆盖下界 P≥1-α-½ε_w 中的 ε_w 被低估，结果比不装异常检测更危险，因为系统误以为已获得漂移鲁棒保证；因此必须以独立对抗审计集校准 ε_w 上界、对密度比误差做保守上界注入，并在 a_ctx/a_res 与 a_in 冲突时按最保守轴 fail-closed。

## 3. 关键算法 伪代码

### IP-69 ADM
```
def anomaly_scores(x_t, pose_res, ctx_pred, obs_dist):
    a_in  = -log_density(feat_enc(x_t)) - log_z_cal
    a_res = pose_res / sigma_res
    a_ctx = kl_div(ctx_pred, obs_dist)
    return np.array([a_in, a_res, a_ctx])

def density_ratio(a_in, a_in_cal, w_min=0.1, w_max=10.0):
    w_hat = exp(a_in_cal - a_in)          # 对数密度差 => 密度比
    return clip(w_hat, w_min, w_max)

def trust_mass(a, eta):
    return exp(-dot(eta, a))              # 三轴融合，单调递减
```

### IP-70 SWC
```
def weighted_quantile(scores, weights, q):
    order = argsort(scores)
    s, w = scores[order], weights[order]
    cw = cumsum(w) / sum(w)
    i = searchsorted(cw, q, side='left')
    return s[min(i, len(s)-1)]

def shift_weighted_certificate(x_t, cal_scores, w_cal, alpha, base_score):
    q = weighted_quantile(cal_scores, w_cal, 1 - alpha)
    C = {y for y in grid if base_score(x_t, y) <= q}   # base 不用异常分数
    eps_w = audit_density_ratio_error(w_cal)           # 独立审计集
    receipt = {'nominal': 1 - alpha,
               'eps_w': eps_w,
               'lower_bound': max(0.0, 1 - alpha - 0.5 * eps_w)}
    return C, receipt
```

### IP-71 AIL
```
def inflate_radius(r_omega, a, T, cal, lam=0.5):
    if a[0] > cal.a_fail or T < cal.T_min:
        return None                                    # 证书作废
    boost = 1 + lam * max(0.0, a[0] - cal.a_cal)
    R = r_omega * boost / max(T, 1e-6)                 # 单调膨胀
    return R
```

### 全链路门控
```
def adcert_decision(x_t, pose_res, ctx_pred, obs_dist, m, cal, eta):
    a = anomaly_scores(x_t, pose_res, ctx_pred, obs_dist)
    w_hat = density_ratio(a[0], cal.a_in_cal)
    T = trust_mass(a, eta)
    C, receipt = shift_weighted_certificate(
        x_t, cal.scores, cal.w, cal.alpha, cal.base_score)
    R = inflate_radius(cal.r_omega[m], a, T, cal)
    if R is None:                                       # 异常越界 => 失败关闭
        return 'fail-closed', receipt
    P_t = pose_certify(m, R)
    if m in memory_decision and T >= cal.T_min:         # 记忆需信任质量达标
        m = memory_decision[m]
    U   = T * modality_utility(m, ctx_pred, cal)        # 效用受信任质量门控
    B   = T * safety_bind(ctx_pred, P_t, obs_dist)      # 绑定受信任质量门控
    if B < cal.theta_safe:
        return 'queued', receipt
    return 'execute', receipt
```

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ADM 三轴评分 | O(d_feat + d_pose + |Ω|) | O(d_feat) | 分数单调于 -log 密度，可作密度比代理 |
| SWC 带权分位 | O(n log n) 每周期 | O(n) | 有界漂移下覆盖 ≥ 1-α-½ε_w（T1） |
| AIL 膨胀 | O(1) | O(1) | 单调膨胀 + 越界 fail-closed（T2） |
| 全链路门控 | O(|M| + n log n) | O(n) | 全部下游约束以 T_t 门控 |

**定理 T1（漂移鲁棒覆盖）**：设 p(y|x) 漂移不变，H5' 成立（E|ŵ-w|≤ε_w），非一致性分数 s 与异常分数解耦，则加权共形证书满足
P(Y_{t+1}∈C_t) ≥ 1-α-½ε_w。
*证明思路*：加权经验分布与真实加权分布的全变差 ≤ ½E|ŵ-w|≤½ε_w；共形分位的覆盖缺口不超过该 TV 距离，得下界。若 s 依赖异常分数，加权与分数相关，TV 界不再成立，保证作废（C3）。

**引理 T2（膨胀单调性）**：对 a_in' ≥ a_in，有 R(a_in') ≥ R(a_in)；且 T 单调递减于每个 a_i，故 R 对任意异常分量单调不减。由此杜绝「异常更高却更自信」。

## 7. 本轮最大风险

**一句话**：异常检测器自身的盲区会制造「虚假安全感」——对抗性或全新异常可让 a_in 保持低分，从而 ŵ 接近 1、证书不膨胀，覆盖下界 1-α-½ε_w 中的 ε_w 被低估，结果比不装异常检测更危险，因为系统误以为已获得漂移鲁棒保证；因此必须以独立对抗审计集校准 ε_w 上界、对密度比误差做保守上界注入，并在三轴冲突时按最保守轴 fail-closed。
