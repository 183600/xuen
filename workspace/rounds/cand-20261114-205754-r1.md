# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「机器人」×「视觉感知」）

> R69 把「不确定」一分为二，给 epistemic 一条主动消解的出路，并用「VoI > 成本」作为发放 resolution bonus（λ 从 λ_floor(U_ale+U_epi) 降到 λ_floor(U_ale)）的判据。但这套机制藏着一个它自己没看见的循环：**观测 o_t 被当成外生测量，而对一个会看东西的机器人，o_t 是它自己「选择去看」的结果**——看哪里、看多久、靠多近、用什么曝光/孔径、焦点落在哪，全都参与了 o_t 的构造。当视角依赖信念、信念又决定视角时，R69 的 VoI 不再是「世界给我的信息」，而可能是「我为了确认自己而制造的信息」。
>
> 这就是本轮要处理的核心：**自证式感知（self-confirming perception）**。R69 自陈的最大风险是「模态分布不可信 ⇒ 问错比不问更危险」；在视觉里它升级为「**看错比不看更危险**」，而且更隐蔽——系统会真心以为自己完成了一次「主动消歧」。
>
> 两个灵感正好给出解药：
> - **视觉感知**给出物理判据——**视差（parallax）**。单一视角只能给出自洽的错觉；真正的深度、材质与可行性（affordance）只有通过**改变视角**才能被证伪。视差不是又一个置信度指标，而是一个**可被物理检验、能对抗自证的签名**。
> - **机器人**给出约束与代价——视角不自由：转头、靠近、曝光都受运动学与安全包络限制；换取视差的动作本身就是一次有风险的移动，而且第三方可以**塑造你能看到什么**（镜面、贴图、光照、雾）。
>
> 核心命题：**把 R69 的 resolution bonus 从「VoI > 成本」升级为「parallax-certified」：任何 epistemic 消解必须在认证可达视角集内保持视角不变、通过多视几何一致性、并通过任意停止下仍有效的证据检验；否则一律视为 pseudo-resolution，撤销 bonus 并退回（比 R69 更保守的）λ。** 命名 **PARALLAX-RAS**（Perception-aware, Anytime-valid Resolution via Active Look-around And cross-view eXamination）。
>
> 一句话定位：R66 问谁控制，R67 问未来怎样，R68 问测量还准吗，R69 问该向谁求证，R70 问「**我看到的，是因为它真的如此，还是因为我把头转到了我想看到的地方**」。

## 0. 直觉与动机

**灵感 1（视觉感知 → 单帧是自洽的幻觉，视差是证伪）**
直觉：判断「这块地面能不能踩」，人不会只盯一帧；人会走两步——反光随视点游移、影子边缘错位、运动视差显出纹理，于是「玻璃」与「地板」被分开。单帧里它们可以是**像素级同一**的，也就是同一个**感知混叠类（perceptual aliasing class）**。R69 的策略在这些混叠类上采样得到多模态分布，它以为自己面对的是「动作歧义」；其实有一半来自「感知歧义」。对感知歧义重采样策略没有用（同一个模糊输入只会得到同一批动作），对动作歧义去换视角也是浪费。**视差给出「消解是否为真」的物理判据**：真几何在视点变化下满足多视极线/重投影一致，假结构（贴图、镜面、伪造投影）在视差下露馅。这把 epistemic 从「信念更新」变成「可证伪检验」。

**灵感 2（机器人 → 视角有代价、受限、且可被操纵）**
直觉：机器人的视角受头部自由度、底盘可达域、安全包络与时间窗约束。更重要的是，**为看清而移动**这一步本身就是有风险的控制动作（凑近玻璃桌那一步可能就踩塌了）。所以它必须像 R69 的信息动作一样过 C-RAS-WM 认证，并额外支付「换视风险」。同时，对手不必对你撒谎，只要**塑造你能看到什么**：镜面、反光地面、只在特定视角像立体的广告牌（parallax spoofing）、雾与强光。这是 R69「交互投毒」在视觉侧的升级——从「给你假答案」升级为「决定你问得出什么问题」。

**灵感 3（可选停止 → R69 的 VoI 有系统性统计偏差）**
直觉：R69 的 VoI 公式隐含假设「信息动作与假设独立」。但主动感知里，动作是**基于当前信念选的**：怀疑 H1，就去看 H1 预测的位置。这正是统计里的**可选停止（optional stopping）**——一直观察到「显著」为止，名义错误率就爆了。于是「消歧成功」的置信度被系统性高估，resolution bonus 是**伪造的**。调阈值治标不治本；正解是 **anytime-valid 推理（e-value / test martingale）**：在任意停止时刻都保持第一类错误 ≤ α，硬性对抗「看到想看的就停」。这是本轮最硬的理论支点。

**灵感 4（三分 → 别再拿策略重采样去解「看不清」）**
直觉：R69 的 U_epi 混了两件本质不同的事：(a) 世界本身有多个可能，我只看到了一个投影（感知混叠，只能换视角/换模态）；(b) 世界看清了，但怎么干有多个合理解（动作歧义，靠重采样/交互）。混在一起会逼系统用「多采样」解决「看不清」——永远解决不了还烧算力；或用「凑近看」解决「都对」——纯浪费。R70 把 U_epi 拆成 U_perc 与 U_act，分别走视差通道与 R69 交互通道。

**灵感 5（可证伪性 → 这是科学姿态，不是工程调参）**
直觉：R69 的 bonus 是一次**信念更新**；R70 要求它是**可证伪的更新**。视差证书本质是 Popper 式的：一个假设只有在你事先说清「什么观察会推翻我」之后，才算被支持。自证式感知的病根正是它从不指定证伪条件，只去找支持。PARALLAX 强制系统在移动之前**预注册**：若 H1 为真，换到 ν' 应看到什么；若 H2 为真，应看到什么；两条预测必须**可区分**（否则这次观察没有信息量），实测必须落入其中之一的**高密度区**，且跨视角几何一致。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PARALLAX-RAS 总览）** PARALLAX-RAS = (VCM, PAD, PAC, PVT, SCI, PACT, GHA, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **视差预算硬约束**：换取视差的运动 ≤ 1 次/单位时间、位移/转角 ≤ (ε_ν, θ_ν)、必须在 C-RAS-WM 认证包络内可达，且换视风险计入安全账；
(iii) **可证伪纪律**：任何 resolution 必须附「预注册的可区分预测」+ anytime-valid e-value + 多视几何一致性；缺一不发 bonus。

**定义 311（视角条件观测模型 VCM）** 世界 w = (G, S)（几何 G、材质/语义 S）。观测 o_t = O(w; ν_t) + η，其中 ν_t = (p_t ∈ SE(3), f_t 焦距, a_t 孔径, e_t 曝光, τ_t 积分时间, φ_t 注视点) ∈ 𝒱 为视角/成像参数。策略条件由 o_t 改为 (o_t, ν_t)。要点：**o_t 是受控查询的输出，不是外生测量**，这彻底改变它的统计语义——它的似然依赖系统自己选的 ν。

**定义 312（感知混叠类与感知歧义）** 在当前视角 ν 下，混叠类 [w]_ν = {w′ : O(w′; ν) = O(w; ν)}。感知歧义 U_perc(ν) = H([w]_ν | o, ν)（离散化到 Affordance 标签：可踩/可抓/可碰/危险）。它是「换个视角**或许**能分开」的不确定性，与策略采样无关。

**定义 313（不确定性三分）** U_ale = Σ_k ŵ_k tr Σ_k（模态内噪声，继承 R69）；U_perc = 定义 312（跨视角可解）；U_act = R69 的 U_epi 去掉 U_perc 后的动作歧义（同视角内、靠交互/重采样可解）。三者分通道，禁止跨通道挪用：不许用重采样解 U_perc，也不许用换视角解 U_act。

**定义 314（可达视角集与换视风险）** 𝒱_adm(x_t) = {ν : 从 x_t 出发可达、整段换视运动在 C-RAS-WM 认证包络内、时间窗内完成}。换视风险 r(ν→ν′) = 该运动段在认证 WM 下的最坏风险，要求 ≤ ε_ν。𝒱_adm 为空 ⇒ 视差不可用，直接退 R69。

**定义 315（视差证书 PAC）** 对从 ν_0 到 ν_1 声称的消解后信念 b，PAC 要求同时满足：
(a) **视角不变性**：对认证扰动集 Δ𝒱 ⊂ 𝒱_adm，argmax b(· | o_{ν_1+Δν}, ν_1+Δν) 对所有 Δν 保持同一模态；
(b) **几何一致性**：ν_0, ν_1 的多视极线/重投影残差 ≤ ε_geo（真结构满足，贴图/镜面破坏）；
(c) **可证伪性**：事前给出的各假设预测在 ν_1 上可区分（KL(p_i‖p_j) ≥ κ），且实测落入某假设预测区（RMSE ≤ ε_pred）。
任一失败 ⇒ pseudo-resolution。

**定义 316（自证指数 SCI）** 以「与假设无关的均匀先验会选的视角」为反事实基线，SCI = E_y[ log p(y | ν_1, H_sel) − log p(y | ν_1, H_neutral) ]。它度量「这份证据有多少是因为我特意去看它才出现的」。SCI > τ_sci ⇒ 证据主要来自视角选择而非世界，不得计入 resolution。数值上用倾向得分/逆概率加权估计，绕开反事实不可观测。

**定义 317（anytime-valid 消解检验 PVT）** 序贯观测 y_1..y_τ（τ 为可选停止时刻），构造 test martingale E_τ = ∏_{t=1}^τ p(y_t | H_1, ν_t) / p(y_t | H_0, ν_t)（或 e-value 组合）。PVT 认证 H_1 当且仅当 E_τ ≥ 1/α 且 PAC 通过。由 Ville 不等式，任意（含数据依赖的）停止时刻 P_{H_0}(E_τ ≥ 1/α) ≤ α——**直接消除可选停止偏差**。这是 R69 与 R70 的分水岭：前者是「期望」信息增益，后者是「可检验」的证据债券。

**定义 318（视差主动控制器 PACT）** 选 ν* = argmax_{ν∈𝒱_adm} [VoI_parallax(ν) − c_move(ν) − r(ν)]，其中 VoI_parallax(ν) = I([w]_{ν_0}; y_ν) 的**事前可区分性**估计（用各假设预测分布的分离度计算），r(ν) 为换视风险，c_move 为时间/能量。若 max ≤ 0 或 𝒱_adm = ∅ ⇒ 不换视，U_perc 保持未解，走定义 320。

**定义 319（gaze hijacking 与 parallax spoofing）** 对手控制环境光学或诱导视角：镜面/反光地面制造假反射、贴图广告牌在 ν_1 伪装 3D 但在 ν_2 穿帮、雾/强光抹掉判别性视差、用动态遮挡强制系统只能从「对对手有利」的视角看。并入 ℰ_PARALLAX = ℰ_FLUID × ℰ_gaze × ℰ_spoof。攻击目标不是让观测错，而是让**视差证据失效或反向**。

**定义 320（伪消解退避，比 R69 更保守）** 若 PAC 失败 / SCI > τ_sci / PVT 未达 e 阈值 / 𝒱_adm = ∅ / 判定被劫持 ⇒ 撤销 bonus，λ = λ_floor(U_ale + U_perc + U_act)。注意：R69 只把「未解 U_epi」并入；R70 把「**未认证**的已解 U_perc」也视同未解——因为自证式消解比不消解更危险（它关掉了保守通道）。同时给该感知打「不可信」戳记。

**定义 321（感知证书 J_PARALLAX）** J_PARALLAX = (J_FLUID, geo_residual, SCI, e_value, ν_log, U_perc_before/after, U_act_before/after, parallax_ver)。Valid ⇔ Valid(J_FLUID) ∧ PAC ∧ PVT ∧ SCI ≤ τ_sci。

**定义 322（视角证据正交性）** 同一混叠类上、依赖同一视角族（高相关视点）的重复观察不累积证据（自证不增值）；只有**视差基线足够大**或**成像模态不同**（如加主动结构光、或触觉探针）的观察才按近似独立计入 e-value。这是 R69「k 个正交证据源」在视觉侧的严格化：**正交性 = 视角/物理模态的去相关**。

**定义 323（按需升级视觉）** 默认单目低分辨率；当 U_perc 高或 PVT 的 e-value 逼近阈值时，才升级到多视/主动光源/触觉探针（与 R69 的 g_probe 打通）。升级本身受预算与安全约束。

**定义 324（与 R69 的包含关系）** 当 𝒱_adm = {ν_0}（无法换视）或 VoI_parallax ≤ 成本时，PARALLAX 把 U_perc 并入 R69 的 U_epi 并按未解处理，逐指令退化为 R69（当 U_perc 已认证时 λ 相等）。R69 是「只有一个视角」的边界。

**定义 325（测量-行为-感知三对偶）** R68 的残差通道（测量自洽）、R69 的流似然通道（行为自洽）、R70 的视差通道（**看到的是不是真的**）构成三条正交旁证；标定只能吸收第一条，交互投毒主要污染第二条，gaze hijacking 主要污染第三条——三者交叉可分离故障类型。

**定义 326（组合误采纳上界）** 在 PAC + PVT + SCI 三重门控下，pseudo-resolution 的误采纳率 ≤ α（PVT）+ δ_geo（几何容差）+ δ_pred（预测容差）。若去掉 PVT，误采纳率可随观察次数趋于 1（自证循环）；若去掉 PAC，贴图/镜面攻击可使其任意高。

## 2. 关键算法骨架

```python
# IP-264 VCM：视角条件观测（把 o 从“测量”变为“受控查询的输出”）
class ViewpointPerception:
    def observe(self, world, nu):
        # nu = (pose, focal, aperture, exposure, tau, fovea)
        return self.render(world, nu)                    # o = O(w; nu)

# IP-265 PAD：不确定性三分（aleatoric / perceptual / action）
def decompose3(policy, percept, nu, K):
    samples = policy.sample(percept.o, nu, K)
    U_ale, modes = within_mode_noise(samples)
    U_perc = perceptual_alias_entropy(percept, nu)       # 来自混叠类
    U_act  = mode_entropy_after_conditioning(modes)      # 去掉 U_perc 后的动作歧义
    return U_ale, U_perc, U_act, modes

# IP-266/267 PAC + PVT：视差证书（几何一致性 + 视角不变性 + anytime-valid）
def parallax_certificate(perc, nu0, nu1, hyp):
    o1      = perc.observe(perc.world, nu1)
    geo_ok  = epipolar_residual(o1, perc.buffer[nu0]) <= EPS_GEO
    inv_ok  = all(same_mode(o1, nu1 + dnu, hyp) for dnu in admissible(nu1))
    e_val   = pvt_e_value(hyp.preds, o1)                 # test martingale
    pred_ok = distinguishable(hyp.preds) and match(o1, hyp)
    return ParallaxCert(geo_ok, inv_ok, e_val >= 1.0 / ALPHA, pred_ok)

# IP-268 自证指数（倾向得分加权，衡量证据有多少来自“特意去看”）
def self_confirmation(perc, nu1, hyp, neutral):
    w = propensity_weight(nu1, hyp, neutral)             # 逆概率加权
    return w * (loglik(hyp, perc.o) - loglik(neutral, perc.o))

# IP-269 PACT：换视控制器（VoI_parallax − 成本 − 风险；不可达即退 R69）
def choose_view(perc, nu0, hyp_set, budget):
    best = None
    for nu in reachable_views(nu0, budget):              # 𝒱_adm
        if not c_ras_wm.certify_view(nu0, nu, budget):   continue
        score = voi_parallax(hyp_set, nu) - move_cost(nu) - risk(nu)
        if best is None or score > best.score: best = (nu, score)
    return best if best and best.score > 0 else None     # 无利可图/不可达 → R69

# IP-275 主闭环（继承 R69，在 resolution 发放处插入视差证书）
def PARALLAX_round(M, obs):
    nu0 = M.eye.current_view
    o0  = M.vcm.observe(M.world, nu0)
    U_ale, U_perc, U_act, modes = M.pad.decompose3(M.fmp, (o0, nu0), K=adaptive(U_perc))
    # 1) 先判断值不值得换视；不可达/无利可图 → 直接保守
    nu1 = M.pact.choose_view(M.vcm, nu0, modes.hyp, M.budget)
    cert = None
    if nu1 is not None:
        o1   = M.vcm.observe(M.world, nu1)
        cert = M.pac.certify(nu0, nu1, modes.hyp)
        sci  = M.sci.score(nu1, modes.hyp, M.neutral)
        if cert.ok and sci <= TAU_SCI:
            U_perc = M.pac.update(U_perc, cert)          # 真正的消解
        else:
            cert = cert.deny()                           # pseudo-resolution：不降
    # 2) 动作歧义仍交给 R69 交互（仅在感知已被认证后）
    g = (M.mint.choose_interaction(modes, M.budget)
         if (U_act > TAU_ACT and cert and cert.ok) else None)
    if g is not None:
        U_act = M.cia.update_belief(modes, M.cia.execute(g))
    # 3) 三通道退避：未认证的感知消解 == 未消解
    U_floor = (U_ale
               + (0.0 if (cert and cert.ok) else U_perc)
               + (0.0 if g is not None else U_act))
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if not (cert and cert.ok):
        lam = max(lam, LAM_PERC_UNTRUSTED)               # 感知不可信 → 更保守
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(modes, U_act, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_p.submit_async(nu0, nu1, cert, sci, U_perc, U_act)
    return k, lam, mode, (U_ale, U_perc, U_act)
```

## 3. 推导

**引理 19（视差可分辨性上界）** 设深度差 ΔZ、基线 b、焦距 f，两假设的重投影位移约 δx ≈ f·b·ΔZ / Z²。当 δx 小于一个像素（δx < 1），单目无纹理条件下两假设不可分；要分辨更细的差异，必须增大基线 b 或改用主动成像（结构光/触觉）。要点：**换视距离线性决定可分辨的最小差异**，PAC 的几何可达性是可计算的物理量，不是先验拍脑袋。

**引理 20（可选停止膨胀 → R69 的 bonus 有偏）** 若用固定阈值 α 反复做主动观察直到「显著」，n 次尝试的误消解率 ≥ 1 − (1−α)^n，随 n 单调膨胀；而 PVT 的 test martingale 满足任意停止下 P_{H_0}(E_τ ≥ 1/α) ≤ α。系：**R69 的「VoI > 成本即发 bonus」在多视角序列上等价于无校正的可选停止**，观察越多、越容易自我确认。

**引理 21（视差证书充分性）** 若 PAC(a)(b)(c) 成立且 PVT 通过，则 pseudo-resolution 概率 ≤ α + δ_geo + δ_pred；进而带 bonus 的期望风险 ≤ 不带 bonus 的保守风险。要点：三条门控分别挡住「视角特异的巧合」「几何伪造」「先验驱动的伪证据」。

**定理 18（PARALLAX 修复 R69 的 bonus 漏洞）** 存在可构造的自证/劫持世界，使 R69 因 VoI > 成本而授予 bonus，但真实风险严格高于保守（如贴图广告牌仅在选中视角像可踩地面）；PARALLAX 在该世界因 PAC 失败或 SCI 超阈而撤销 bonus。反之当 PAC + PVT 通过，PARALLAX 的期望风险 ≤ R69。故 PARALLAX 对 R69 是**安全侧严格更强、效率侧条件收益**——不是又一个并列黑箱，而是给旧 bonus 装上了可证伪的闸门。

**定理 19（换视安全与无突变）** 换视动作经 C-RAS-WM + 视差预算约束 ⇒ 物理风险 ≤ ε_ν；交互只改变「选哪个假设/模态」，不改变安全包络；撤销 bonus 时 λ 单调不降；提交/换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变。

## 6. 本轮最大风险

**一句话**：PARALLAX 的全部收益押在「视差几何在真实感知管线里足够可靠」上——**若多视标定/时间同步本身有误差，或环境纹理/光照让视差不可用（白墙、纯镜面、动态遮挡），PAC 会系统性失败，系统退回比 R69 更保守的 λ，效率收益归零；而一旦为了「保可用」放宽 ε_geo，贴图/镜面攻击就能伪造视差，把 pseudo-resolution 洗成真消解**——到那时，最危险的不是看错，而是系统拿着「已认证」的章去看错。

1. **换视本身不安全**（凑近/转身越界）→ 定义 314 可达集 + C-RAS-WM 认证 + 定理 19；
2. **gaze hijacking / parallax spoofing** → ℰ_PARALLAX 对抗训练 + 几何一致性硬门 + E306；
3. **e-value 数值不稳/算力开销** → 序贯 O(1) 更新 + 仅在 U_perc 高时启用；
4. **长期不可达导致过度保守** → 把「无法认证」显式上报，触发人类接管或降级任务，而不是偷偷放宽阈值；
5. **视角证据伪正交**（多视标定同源误差被当独立）→ 定义 322 的去相关判据 + E311。

# IP-264 VCM：视角条件观测
class ViewpointPerception:
    def observe(self, world, nu):
        return self.render(world, nu)                    # o = O(w; nu)

# IP-265 PAD：三分
def decompose3(policy, percept, nu, K):
    samples = policy.sample(percept.o, nu, K)
    U_ale, modes = within_mode_noise(samples)
    U_perc = perceptual_alias_entropy(percept, nu)
    U_act  = mode_entropy_after_conditioning(modes)
    return U_ale, U_perc, U_act, modes

# IP-266/267 PAC + PVT：视差证书
def parallax_certificate(perc, nu0, nu1, hyp):
    o1      = perc.observe(perc.world, nu1)
    geo_ok  = epipolar_residual(o1, perc.buffer[nu0]) <= EPS_GEO
    inv_ok  = all(same_mode(o1, nu1 + dnu, hyp) for dnu in admissible(nu1))
    e_val   = pvt_e_value(hyp.preds, o1)                 # test martingale
    pred_ok = distinguishable(hyp.preds) and match(o1, hyp)
    return ParallaxCert(geo_ok, inv_ok, e_val >= 1.0 / ALPHA, pred_ok)

# IP-268 SCI：自证指数（逆概率加权）
def self_confirmation(perc, nu1, hyp, neutral):
    w = propensity_weight(nu1, hyp, neutral)
    return w * (loglik(hyp, perc.o) - loglik(neutral, perc.o))

# IP-269 PACT：换视控制器
def choose_view(perc, nu0, hyp_set, budget):
    best = None
    for nu in reachable_views(nu0, budget):              # 𝒱_adm
        if not c_ras_wm.certify_view(nu0, nu, budget):   continue
        score = voi_parallax(hyp_set, nu) - move_cost(nu) - risk(nu)
        if best is None or score > best.score: best = (nu, score)
    return best if best and best.score > 0 else None     # 不可达/无利可图 → R69

# IP-275 主闭环（继承 R69）
def PARALLAX_round(M, obs):
    nu0 = M.eye.current_view
    o0  = M.vcm.observe(M.world, nu0)
    U_ale, U_perc, U_act, modes = M.pad.decompose3(M.fmp, (o0, nu0), K=adaptive(U_perc))
    nu1  = M.pact.choose_view(M.vcm, nu0, modes.hyp, M.budget)
    cert = None
    if nu1 is not None:
        o1   = M.vcm.observe(M.world, nu1)
        cert = M.pac.certify(nu0, nu1, modes.hyp)
        sci  = M.sci.score(nu1, modes.hyp, M.neutral)
        if cert.ok and sci <= TAU_SCI: U_perc = M.pac.update(U_perc, cert)
        else:                          cert = cert.deny()
    g = (M.mint.choose_interaction(modes, M.budget)
         if (U_act > TAU_ACT and cert and cert.ok) else None)
    if g is not None: U_act = M.cia.update_belief(modes, M.cia.execute(g))
    U_floor = (U_ale
               + (0.0 if (cert and cert.ok) else U_perc)
               + (0.0 if g is not None else U_act))
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if not (cert and cert.ok): lam = max(lam, LAM_PERC_UNTRUSTED)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(modes, U_act, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_p.submit_async(nu0, nu1, cert, sci, U_perc, U_act)
    return k, lam, mode, (U_ale, U_perc, U_act)

## 4. 推导

**引理 19（视差可分辨性上界）** 深度差 ΔZ、基线 b、焦距 f 下重投影位移 `δx ≈ f·b·ΔZ/Z²`；`δx<1px` 时单目无纹理不可分，需更大基线或主动光/触觉。系：换视距离线性决定可分辨的最小差异，PAC 的几何可达性是可计算物理量。

**引理 20（可选停止膨胀）** 固定阈值 α 反复观察直到「显著」，n 次误消解率 ≥ `1−(1−α)^n`；PVT 的 test martingale 在任意停止下 `P_{H_0}(E_τ≥1/α)≤α`。系：R69 的「VoI>成本即 bonus」在多视角序列上等价于无校正的可选停止——观察越多越自我确认。

**引理 21（视差证书充分性）** PAC(a)(b)(c)+PVT ⇒ pseudo-resolution ≤ `α+δ_geo+δ_pred`，带 bonus 的期望风险 ≤ 保守风险。三条门控分别挡「视角特异巧合」「几何伪造」「先验驱动伪证据」。

**定理 18（PARALLAX 修复 R69 的 bonus 漏洞）** 存在可构造的自证/劫持世界使 R69 授予 bonus 但风险严格高于保守（贴图广告牌仅在选中视角像可踩）；PARALLAX 因 PAC 失败或 SCI 超阈撤销 bonus。反之 PAC+PVT 通过时风险 ≤ R69。故 PARALLAX 安全侧严格更强、效率侧条件收益。

**定理 19（换视安全与无突变）** 换视经 C-RAS-WM + 视差预算 ⇒ 物理风险 ≤ ε_ν；交互只改假设/模态、不改安全包络；撤销 bonus 时 λ 单调不降；提交/换装不变式保持 ⇒ 控制连续无突变。

## 7. 本轮最大风险

**一句话**：PARALLAX 的全部收益押在「视差几何在真实感知管线里足够可靠」上——**若多视标定/时间同步有误差，或环境纹理/光照让视差不可用（白墙、纯镜面、动态遮挡），PAC 会系统性失败，系统退回比 R69 更保守的 λ，效率收益归零；而一旦为「保可用」放宽 ε_geo，贴图/镜面攻击就能伪造视差，把 pseudo-resolution 洗成真消解**——最危险的不是看错，而是系统拿着「已认证」的章去看错。

**次级风险与缓解**：换视越界（定义 314 可达集 + C-RAS-WM + 定理 19）；gaze hijacking/parallax spoofing（ℰ_PARALLAX 对抗训练 + 几何硬门 + E306）；e-value 数值/开销（序贯 O(1) + 仅 U_perc 高时启用）；长期不可达致过度保守（显式上报并触发接管，不偷放宽阈值）；视角证据伪正交（定义 322 去相关判据 + E311）。
