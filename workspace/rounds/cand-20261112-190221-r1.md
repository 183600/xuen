# 第 61 轮（承接第 60 轮「认知驱动的场景-执行闭环」SGEC IP-153~160；灵感循环第 7 轮；本轮灵感：「竞品分析」×「仿真到现实」）

> 第 60 轮的 SGEC 把「执行层→证据层」升级为「场景→意图→约束→阻抗→执行→EV-exec→场景更新」的认知闭环，用 SSM/CIEC/EPIR/SERC/PCE++++ 覆盖了场景语义、意图锁定、消息完整性与认知预算。但它存在一个**未被命名的隐藏偏差——自我参照的置信（self-referential confidence）**：
> 1. **先验的单源自证**：π_scene(K|z) 来自仿真标定或离线统计，SIC 的 scene_conf 又用真实遥测"自我更新"；系统从未检验"我的仿真/先验是否真的对应当前现实"。仿真-现实鸿沟（sim-to-real gap）被默认忽略，一旦发生，第 60 轮的"场景置信度"会**高估现实可信度**。
> 2. **失败归因的缺位**：当 EV-exec 偏离预期，SGEC 只会下调 scene_conf（一个标量），无法回答"这次偏离是场景误判、仿真偏差，还是执行本身换了一种行为模式"。没有"替代假设"，就没有诊断。
> 3. **创新定位的模糊**：作为参赛方案，SGEC 从未系统对照同类方法（固定阻抗、sim-to-real RL、数字孪生、证据链审计），"新在哪、凭什么可证伪"缺乏可核验的矩阵。

## 0. 直觉与动机

**灵感 1（仿真到现实 → 数字孪生影子流 DTS）**
直觉：第 60 轮的 EPIR 为"消息丢失"建了边端影子副本；现在为"现实本身"再建一个影子——**数字孪生并行运行**，对每个 seq_id 产出 EV-sim，与真实 EV-real 按序列号对齐，残差 r = EV-real ⊖ EV-sim 就是"现实鸿沟"的原始信号。关键洞见：**孪生不是真值，而是一个永远可错的"竞品"**；把孪生当基准去"校准现实"是本末倒置，正确的用法是让残差去"校准我们对孪生的信任"。

**灵感 2（竞品分析 → 竞品策略库 CPB 与行为指纹）**
直觉：只看"自己 vs 孪生自己"无法区分"仿真错了"还是"现实进入了另一种行为模式"。引入一组**竞品策略**（固定阻抗、导纳、PID 力控、学习型策略、人类遥操作基线）在孪生里并行 rollout，得到 {EV-sim_j}。关键洞见：**竞品是行为空间的"基向量"**——真实行为落在哪个竞品预测附近，就说明现实正在"像谁一样动"，鸿沟因此从标量升级为**有标签的偏差**。

**灵感 3（合流 → 竞品反事实三角定位 CCA + 现实鸿沟证书 S2RC）**
直觉：用三点三角定位现实：A=EV-real、B₀=孪生对自身的预测、B_j=孪生对竞品的预测。若 A 离 B_j 比离 B₀ 更近且差距超过 ε_attr，则"现实行为身份漂移"，偏差可归因到 j。同时用 1-Wasserstein 距离量化标量鸿沟 δ_s2r，并签发**现实鸿沟证书**：γ_real = γ_sim·exp(−λ_gap·δ_s2r)。关键洞见：**先定位、再折扣**——归因回答"像谁"，证书回答"多可信"，两者是独立安全闸门。

**灵感 4（竞品先验贝叶斯融合 CPF）**
直觉：域随机化（domain randomization）的每个配置其实就是一个"先验竞品"。把 M 个仿真变体当作 M 个假设，用真实证据做**递归贝叶斯模型选择**更新权重 w_j，混合先验 π_scene = Σ w_j N(μ_j, Σ_j)。权重熵 H(w) 就是"变体可辨识度"：熵高说明现实无法区分这些仿真，先验应加宽。关键洞见：**sim-to-real 标定 = 在一组仿真竞品中做模型选择**。

**灵感 5（闭环 CSRT + PCE+++++ + 差异化定位 DPC）**
直觉：把上述部件闭合成 CSRT：场景先验→孪生 rollout→真实执行→残差→证书/归因→权重更新→（必要时）主动标定探针。新增仿真预算 B_sim，防止"无限 benchmark"。最后用 DPC 覆盖矩阵把"竞品分析"落到参赛叙事：对照四类基线、五条能力轴，逐条给出可证伪断言。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（竞品策略库 CPB, Competitor Policy Bank）** CPB = {(π_j, φ_j, w_j)}_{j=0}^{m}，其中 j=0 为自身策略 π_self，j≥1 为竞品策略（固定阻抗、导纳控制、PID 力控、学习型策略、人类遥操作基线）。φ_j: rollout → R^d 为**行为指纹**：φ_j = (F_peak, t_settle, σ_os, E_contact, κ_traj)，分别刻画峰值接触力、调节时间、超调、接触冲量与轨迹刚度。w_j 为假设先验权重，Σ_j w_j = 1。CPB 提供"替代假设基"，使现实偏差可被**归因**而非仅被**量化**。

**定义 162（数字孪生影子流 DTS, Digital Twin Shadow）** DTS = (T_sim, S_sim, Λ)。T_sim 为数字孪生（版本 v_sim）；S_sim: seq_id → EV-sim = (timestamp, seq_id, ŷ_sim, v_sim, hash) 为与 EPIR 影子副本 S_shadow 同构的仿真证据流；Λ 为按 seq_id 的对齐算子。**残差** r(seq) = Λ(EV-real(seq), EV-sim(seq)) ∈ R^d 为归一化证据残差。若孪生滞后（EV-sim 缺失），用前视窗口 W_twin 内插，**不阻塞实时执行**。

**定义 163（仿真-现实鸿沟证书 S2RC, Sim-to-Real Gap Certificate）** 给定场景 z、策略 π 与残差样本 R_{1:n}：
- **鸿沟度量**：δ_s2r(z,π) = W_1(P̂_real(·|z,π), P̂_sim(·|z,π))，W_1 为 1-Wasserstein 距离（一维投影下即排序后 L1）。
- **证书**：C_s2r = (δ_s2r, CI_95, n, v_sim, drift)；CI_95 由 bootstrap 给出，drift = |δ_s2r(t) − δ_s2r(t−Δt)|/Δt 为漂移率。
- **置信折扣**：γ_real = γ_sim · exp(−λ_gap · δ_s2r)，λ_gap 为残差似然的 Lipschitz 常数。
- **包络判定**：in_envelope ⟺ δ_s2r ≤ δ_max ∧ γ_real ≥ τ_K；否则 out_of_envelope，强制回退基础 EEIS 保守解。

**定义 164（竞品反事实归因 CCA, Competitive Counterfactual Attribution）** 给定真实证据 A = EV-real 与仿真预测 {B_j = EV-sim(π_j)}_{j=0}^m，指纹距离 d(A,B_j) = ||φ(A) − φ(B_j)||_Σ（Mahalanobis）：
- **归因**：a* = argmin_j d(A, B_j)。
- **漂移判定**：若 a* ≠ 0 且 margin Δ_attr = d(A,B_0) − d(A,B_{a*}) > ε_attr，标记"行为身份漂移"，把竞品 a* 的鸿沟证书与先验作为诊断假设。
- **覆盖判定**：若 min_j d(A,B_j) > ε_cover，声明"未知行为模式"，**拒绝归因**并触发保守回退（防止把 OOD 行为误归因给最像的错竞品）。
关键：CCA 把标量鸿沟升级为"有标签的鸿沟"。

**定义 165（竞品先验贝叶斯融合 CPF, Competitive Prior Bayesian Fusion）** 维护 M 个仿真变体（域随机化配置）作为"先验竞品" {(μ_j(z), Σ_j(z), v_sim^j)}_{j=1}^M：
- **混合先验**：π_scene(K|z) = Σ_{j=1}^M w_j N(K; μ_j(z), Σ_j(z))。
- **权重更新（递归贝叶斯模型选择）**：w_j ← w_j L_j(EV-real) / Σ_k w_k L_k(EV-real)，L_j 为真实证据在变体 j 预测分布下的似然。
- **可辨识度**：H(w) = −Σ_j w_j log w_j；γ_sim = 1 − H(w)/log M。
- **先验加宽**：若 H(w) 高 ⇒ 变体难区分 ⇒ 混合先验叠加过程噪声 σ_gap² 加宽；若某 w_j 塌缩到 0，则该变体被现实证伪并剪枝。

**定义 166（竞品-仿真-现实闭环 CSRT, Competitive Sim-to-Real Triangulation Loop）** 算子 CSRT(M, scene, intent, δf_req)：
```
① SSM: z ← R_scene.update(telemetry)
② CPF: (μ,Σ) ← Σ_j w_j N(μ_j(z), Σ_j(z))
③ EEIS: K_safe^scene ← compile_with_prior((μ,Σ), δf_req)
④ DTS: {EV-sim_j}_{j=0}^m ← T_sim.rollout(π_j, z, K_safe^scene)
⑤ Real: K_safe ← EEIS.compile(...); EV-real ← execute(K_safe); EPIR.append(EV-real)
⑥ Align: r ← Λ(EV-real, EV-sim_0)
⑦ S2RC: C_s2r ← certify(r); γ_real ← γ_sim·exp(−λ_gap·δ_s2r)
⑧ CCA: (a*, Δ_attr, cover) ← attribute(EV-real, {EV-sim_j})
⑨ CPF: w ← BayesSelect(w, EV-real); H ← entropy(w)
⑩ Guard: if out_of_envelope or not cover: K_safe ← EEIS.compile_conservative(); a* ← UNKNOWN
⑪ ActiveCal: if H > θ_H or drift: π_probe ← argmax_j IG(j); return probe request
⑫ Return (K_safe, C_s2r, a*, w, γ_real)
```
关键：第 ⑩ 步把"归因失败"与"鸿沟超包络"作为两个**独立**安全闸门——任一触发即放弃场景先验，回到基础 EEIS。

**定义 167（PCE+++++ 仿真认知预算）** B_cog+ = (B_scene, B_intent, B_ros, B_sim, B_exec)，新增 B_sim = (Rollout_budget, Benchmark_bandwidth, Attribution_samples, Twin_fidelity)。
- **成本**：cost_sim = λ_twin·Rollout_cost + λ_bench·Benchmark_cost + λ_attr·Attribution_cost。
- **VOI**：voi_csrt(π) = VOI_meta_pessimistic − cost_cog − cost_sim − cost_exec。
- **耗尽策略**：B_sim 耗尽 ⇒ 冻结 w、停止归因、混合先验方差 +σ_gap²、仅保留 DTS 残差监控（降级为"只测不调"）；B_exec 耗尽 ⇒ 原有降级。

**定义 168（差异化定位证书 DPC, Differentiation Positioning Certificate）** 给定基线集合 B = {固定阻抗控制, 域随机化 sim-to-real RL, 纯数字孪生预测, 证据链审计}，能力轴 A = {场景先验, 意图锁定, 证据完整性, 鸿沟量化, 竞品归因}：
- **覆盖矩阵** M[b,a] ∈ {覆盖, 部分, 无}。
- **DPC** = (M, novelty_axes, falsifiable_claims F1–F4)。
- **断言**：本方案在 A 上的联合覆盖为唯一非零列组合；每条 F 可被 E192–E196 证伪。
关键：把"竞品分析"从修辞变成可核验的覆盖矩阵。

## 2. 关键算法伪代码（完整版见产物区）

```python
def csrt_loop(M, scene, intent, delta_f_req):
    z = M.ssm.update(M.telem_force, M.telem_pos)
    mu, Sigma = M.cpf.mixture_prior(z)
    K_scene = M.eeis.compile_with_prior((mu, Sigma), delta_f_req)

    sim_preds = M.cpb.rollout_all(M.dts.twin, z, K_scene)      # {j: EV-sim_j}
    K_safe = M.eeis.compile(delta_f_req, M.fused, M.xi, M.env, K_scene)
    ev_real = execute_and_build_evidence(K_safe)
    M.epir.append(ev_real.__dict__)

    r = M.dts.residual(ev_real)                                # 对齐残差
    cert = certify_s2r(r, M.dts.twin.version)                  # S2RC
    attr = competitive_attribution(ev_real, sim_preds)         # CCA

    M.cpf.update(ev_real)                                      # CPF
    if cert.status == 'out_of_envelope' or not attr.covered:
        K_safe = M.eeis.compile_conservative()
        attr.a_star = 'UNKNOWN'
    if M.cpf.weight_entropy() > M.theta_H or cert.drift > M.theta_drift:
        M.probe_request = M.cpb.active_probe(M.cpf)            # 主动标定
    return K_safe, cert, attr, M.cpf.weights
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CPB | O(m·H) rollout/次 | O(m) | 竞品覆盖 ε_cover-网时归因可辨 |
| DTS | O(1)/步对齐 | O(W_twin) | 对齐误差 ≤ δ_align，残差平稳 |
| S2RC | O(n log n) W1 + O(B·n) bootstrap | O(n) | 鸿沟估计一致，证书校准 ECE ≤ 0.05 |
| CCA | O(m·d) 距离 | O(m·d) | 归因准确率 ≥ 85%，OOD 拒答 |
| CPF | O(M·d²) 更新 | O(M·d²) | 后验一致，混合先验 1−α 覆盖 |
| CSRT | O(闭环)，主导项 m·H | 复用 | 包络内 δ_s2r 单调不增 |

**正确性定理（CSRT）**：假设 A66–A73 成立。
- **(A66) 竞品覆盖**：CPB 是行为空间的 ε_cover-网。
- **(A67) 孪生同步**：DTS 的 seq 对齐误差 ≤ δ_align。
- **(A68) 残差平稳**：场景内残差分布平稳，W_1 估计一致。
- **(A69) 归因可辨**：若真实行为由假设 j 生成，则 d(A,B_j) < d(A,B_k) − ε_attr（k≠j）。
- **(A70) 后验一致**：CPF 满足 Doob 一致性，w → 真变体。
- **(A71) 闭环收缩**：CSRT 迭代在包络内使 δ_s2r 单调不增。
- **(A72) 预算单调**：B_cog+ 单调消耗，耗尽触发对应降级。
- **(A73) 覆盖完整**：DPC 矩阵行/列完整。

则：
1. **鸿沟可定位**：A66∧A69 ⇒ a* 以概率 ≥ 1−δ 识别真实行为模式；若 min_j d(A,B_j) > ε_cover，则拒绝归因（不误报）。
2. **置信保守性**：A68 且残差似然满足 λ_gap-Lipschitz 比 ⇒ γ_real = γ_sim·e^{−λ_gap·δ_s2r} 是真实场景置信度的**保守下界**。
3. **先验收敛**：A70 ⇒ 混合先验以 O(1/√n) 收敛到真变体先验；被证伪变体权重指数衰减。
4. **安全回退**：A67∧A72 ⇒ 任一闸门（out_of_envelope / not cover / budget exhausted）触发保守解，不产生超包络承诺。
5. **定位可核验**：A73 ⇒ DPC 的每条断言可映射到 E192–E196 的指标。

## 4. 实验设计 E192–E196

| 实验 | 指标 | 目标 |
|---|---|---|
| E192 CCA | 归因准确率；行为漂移检测延迟 | ≥ 85%；≤ 2 接触 |
| E193 DTS | 孪生 seq 对齐误差；残差平稳性（ADF 检验） | δ_align ≤ 5 ms；p < 0.05 平稳 |
| E194 S2RC | 鸿沟估计校准 ECE；out-of-envelope 误报率 | ECE ≤ 0.05；误报 ≤ 5% |
| E195 CPF | 变体识别率；后验熵下降；先验 1−α 覆盖 | ≥ 90%；≥ 40% 熵降；≥ 95% 覆盖 |
| E196 CSRT 端到端 | sim-real 失败预测 AUC；不安全承诺率；ΔECE | AUC ≥ 0.90；不安全 ↓ 50%；ΔECE ≥ 15% |

**消融**：E196b 分别去除 CPB（无竞品）、DTS（无孪生）、S2RC 折扣，验证三者对 AUC 与不安全承诺率的独立贡献。

## 5. 本轮最大风险

**一句话**：若竞品库未覆盖真实失效模式（OOD 竞品缺失），CCA 会把鸿沟"自信地"误归因给最像的错竞品，S2RC 又因残差对错假设偏小而**高估仿真可信度**，导致"仿真自洽、现实灾难"的假阳性安全；必须以「最小归因距离 > ε_cover ⇒ 拒绝归因 + 保守回退」与「孪生仅作为可错的竞品、永不作真值」两条铁律兜底。

### IP-161 CPB（竞品策略库）

```python
class CompetitorPolicyBank:
    def __init__(self, policies, fingerprint_fn):
        self.policies = policies                      # {'self': pi_self, 'impedance': ..., ...}
        self.fingerprint_fn = fingerprint_fn
        self.weights = {k: 1.0 / len(policies) for k in policies}

    def rollout_all(self, twin, scene, K_scene, horizon=5):
        preds = {}
        for name, pi in self.policies.items():
            traj = twin.rollout(pi, scene, K_scene, horizon)
            preds[name] = {
                'traj': traj,
                'fingerprint': self.fingerprint_fn(traj),
                'sim_version': twin.version,
            }
        return preds

    def active_probe(self, cpf):
        best, best_ig = None, -1.0
        for name, pi in self.policies.items():
            ig = cpf.expected_information_gain(name)
            if ig > best_ig:
                best, best_ig = name, ig
        return best
```

### IP-162 DTS（数字孪生影子流）

```python
class DigitalTwinShadow:
    def __init__(self, twin, lookahead=5):
        self.twin = twin
        self.lookahead = lookahead
        self.sim_log = {}

    def predict(self, seq_id, K_safe, scene, policy):
        y_sim = self.twin.step(K_safe, scene, policy)
        msg = EVSim(timestamp=time.time(), seq_id=seq_id, y=y_sim,
                    sim_version=self.twin.version)
        msg.hash = sha256(y_sim)
        self.sim_log[seq_id] = msg
        return msg

    def residual(self, ev_real):
        ev_sim = self.sim_log.get(ev_real.seq_id)
        if ev_sim is None:
            ev_sim = self._interpolate(ev_real.seq_id)   # 前视窗口内插，不阻塞
        if ev_sim is None:
            return None
        return normalize(ev_real.y - ev_sim.y)

    def _interpolate(self, seq_id):
        window = [self.sim_log[s] for s in
                  range(seq_id - self.lookahead, seq_id + self.lookahead + 1)
                  if s in self.sim_log]
        return interpolate(window, seq_id) if len(window) >= 2 else None
```

### IP-163 S2RC（仿真-现实鸿沟证书）

```python
def certify_s2r(residuals, sim_version, delta_max=0.15,
                lambda_gap=2.0, n_min=30, boot=500):
    if residuals is None or len(residuals) < n_min:
        return S2RCertificate(status='insufficient', delta=float('inf'),
                              ci=None, n=0, sim_version=sim_version, drift=0.0)
    delta = wasserstein1(residuals, REF_RESIDUAL)
    ci = bootstrap_ci(residuals, stat=wasserstein1, n_boot=boot)
    drift = abs(delta - wasserstein1(residuals[:-1], REF_RESIDUAL))
    status = 'in_envelope' if delta <= delta_max else 'out_of_envelope'
    return S2RCertificate(status=status, delta=delta, ci=ci,
                          n=len(residuals), sim_version=sim_version,
                          drift=drift, gamma_discount=math.exp(-lambda_gap * delta))
```

### IP-164 CCA（竞品反事实归因）

```python
def competitive_attribution(ev_real, sim_preds, eps_attr=0.05, eps_cover=0.20):
    phi_a = fingerprint_of(ev_real)
    dists = {name: mahalanobis(phi_a, p['fingerprint'])
             for name, p in sim_preds.items()}
    a_star = min(dists, key=dists.get)
    margin = dists['self'] - dists[a_star]
    covered = min(dists.values()) <= eps_cover
    drift = covered and a_star != 'self' and margin > eps_attr
    return Attribution(a_star=a_star if covered else 'UNKNOWN',
                       margin=margin, drift=drift,
                       covered=covered, dists=dists)
```

### IP-165 CPF（竞品先验贝叶斯融合）

```python
class CompetitivePriorFusion:
    def __init__(self, variants):
        self.variants = variants            # [(mu_fn, Sigma_fn, sim_version), ...]
        self.w = np.ones(len(variants)) / len(variants)

    def _log_likelihood(self, ev_real, j):
        mu_fn, Sigma_fn, _ = self.variants[j]
        mu = mu_fn(ev_real.scene)
        Sigma = Sigma_fn(ev_real.scene) + 1e-6 * np.eye(len(mu))
        return gaussian_logpdf(ev_real.y, mu, Sigma)

    def update(self, ev_real):
        logL = np.array([self._log_likelihood(ev_real, j)
                         for j in range(len(self.w))])
        logw = np.log(self.w + 1e-12) + logL
        self.w = softmax(logw)
        self.w[self.w < 1e-4] = 0.0
        self.w /= max(self.w.sum(), 1e-12)

    def mixture_prior(self, scene):
        mus = np.array([v[0](scene) for v in self.variants])
        Sig = np.array([v[1](scene) for v in self.variants])
        mu = np.tensordot(self.w, mus, axes=1)
        Sigma = sum(self.w[j] * (Sig[j] + np.outer(mus[j] - mu, mus[j] - mu))
                    for j in range(len(self.w)))
        if self.weight_entropy() > 0.5 * math.log(len(self.w)):
            Sigma += self.sigma_gap ** 2 * np.eye(len(mu))
        return mu, Sigma

    def weight_entropy(self):
        w = self.w[self.w > 0]
        return -np.sum(w * np.log(w))
```

### IP-166 CSRT（竞品-仿真-现实闭环）

```python
def competitive_sim_to_real_loop(M, scene, intent, delta_f_req):
    z = M.ssm.update(M.telem_force, M.telem_pos)

    mu, Sigma = M.cpf.mixture_prior(z)
    K_scene = M.eeis.compile_with_prior((mu, Sigma), delta_f_req)

    sim_preds = M.cpb.rollout_all(M.dts.twin, z, K_scene)
    K_safe = M.eeis.compile(delta_f_req, M.fused, M.xi, M.env, K_scene)

    ev_real = execute_and_build_evidence(K_safe)
    M.epir.append(ev_real.__dict__)

    r = M.dts.residual(ev_real)
    cert = certify_s2r(r, M.dts.twin.version)
    attr = competitive_attribution(ev_real, sim_preds)

    M.cpf.update(ev_real)
    gamma_real = (1.0 - M.cpf.weight_entropy() / math.log(len(M.cpf.w)))
    gamma_real *= cert.gamma_discount

    if cert.status == 'out_of_envelope' or not attr.covered or gamma_real < M.tau_K:
        K_safe = M.eeis.compile_conservative()
        attr.a_star = 'UNKNOWN'
        M.safety_events.append(('simreal_guard', cert.status, attr.a_star))

    if M.cpf.weight_entropy() > M.theta_H or cert.drift > M.theta_drift:
        M.probe_request = M.cpb.active_probe(M.cpf)

    M.sic_confidence = gamma_real
    return M, K_safe, cert, attr, M.cpf.weights
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| CPB | O(m·H) / 次 | O(m·d) | 覆盖 ε_cover-网时归因可辨 |
| DTS | O(1) / 步对齐 | O(W_twin) | 对齐误差 ≤ δ_align |
| S2RC | O(n log n) + O(B·n) | O(n) | 鸿沟估计一致，ECE ≤ 0.05 |
| CCA | O(m·d) | O(m·d) | 归因 ≥ 85%，OOD 拒答 |
| CPF | O(M·d²) / 更新 | O(M·d²) | 后验一致，1−α 覆盖 |
| CSRT | O(闭环)，主导 m·H | 复用 | 包络内 δ_s2r 单调不增 |

**正确性定理（CSRT）**：若 A66–A73 成立，则：
1. 鸿沟可定位：A66∧A69 ⇒ a* 以概率 ≥ 1−δ 识别真实行为模式；min_j d > ε_cover 时拒绝归因。
2. 置信保守性：A68 且残差似然 λ_gap-Lipschitz ⇒ γ_real 是真实场景置信度的保守下界。
3. 先验收敛：A70 ⇒ 混合先验 O(1/√n) 收敛到真变体，被证伪变体权重指数衰减。
4. 安全回退：A67∧A72 ⇒ 任一闸门触发保守解，不产生超包络承诺。
5. 定位可核验：A73 ⇒ DPC 每条断言映射到 E192–E196。

**与第 60 轮的关键差异**：SGEC 的 scene_conf 是"真实遥测的自更新"（可能自我强化）；CSRT 的 γ_real 是"被仿真-现实残差**折扣**过的置信"（可能自我否定）。前者保证"场景内一致"，后者保证"跨域可迁移"。

## 7. 本轮最大风险

**一句话**：若竞品库未覆盖真实失效模式（OOD 竞品缺失），CCA 会把鸿沟"自信地"误归因给最像的错竞品，S2RC 又因残差对错假设偏小而**高估仿真可信度**，导致"仿真自洽、现实灾难"的假阳性安全；必须以「最小归因距离 > ε_cover ⇒ 拒绝归因 + 保守回退」与「孪生仅作为可错的竞品、永不作真值」两条铁律兜底。
