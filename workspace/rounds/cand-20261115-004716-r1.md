# 第 3 轮（灵感循环第 3 轮；本轮灵感：「微调」×「数据采集」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440），
> 以及其下的 LeanGauge（第 1 轮）与 MODGAUGE。
> 本轮纪律：**不重写 6C、不推翻五不变式**——把第 2 轮「一次性预训练 + 冻结先验 + 被动断路器」
> 升级为「**持续维护的计量先验**」：微调负责“适应”，数据采集负责“为适应供给证据”，
> 二者由一个**证据账本**约束成闭环。ToolGauge 的 6C、退化链、TB-Contract、语言主张绑定全部保留。

## 映射（升级而非重写）

| 灵感词 | 第 2 轮对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| 微调 | MP-Φ **冻结** + P-Quarantine **事后**断路 | **TR-FT**：信任域内、证据门控、LoRA 低秩的在线微调 | 分布偏移的解药不是“更早报警”，而是“受控地改” |
| 数据采集 | T-Box 单次探测，回执**用完即弃** | **VoD 主动采集 + 计量数据湖**：为每条数据定价、留存、审计、撤回 | 数据不是越多越好，只有“能改变已认证决策的那一条”才值钱 |
| 二者耦合 | 预训练一次、部署后只读 | **证据飞轮 4D**：Detect→Design→Distill→Deploy，棘轮式只升不降 | 采集为微调供给，微调为采集定价；用会计约束切断自我确认 |

**核心命题**：把第 2 轮“预训练先验 + 静态校准”升级为
「**证据记账 → 主动采集 → 信任域微调 → 证书化部署 → 漂移再触发**」的两速闭环：
- **快环**（50Hz + 6C）保持不变；
- **慢环**（分钟–小时级）维护一个**可审计、可回滚、可遗忘**的计量先验；
- 任何权重改动都必须由账本中的**独立有效证据**支付，否则退回 ToolGauge 冻结先验。

**不变式保持声明**：
- MODGAUGE 五不变式全部保留；
- 新增 **I-EB（证据平衡）**：参数改动 ⇔ 证据支撑；无证据不动权；
- 新增 **I-RATCHET（棘轮）**：只有通过独立审计的显著改进才允许部署，否则原子回滚；
- **严格退化链延长**：FlywheelGauge 失效（预算耗尽 / 证书连续失败 / 数据湖不可用 / 漂移器失效）
  ⇒ 冻结当前 θ，退回 ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。微调与采集都是增强项，不是依赖项。

## 0. 直觉与动机

**灵感 1（微调 → 从“冻结的信仰”到“受控的适应”）**
直觉：第 2 轮最大的风险是 sim→real 偏移 η。它用 P-Quarantine 在污染**发生之后**拉闸——
这是事后止损，不是事前适应，而且一次全局暂停会误伤所有正常盲区。微调的正确用法不是
“拿部署数据把模型再训一遍”（会灾难性遗忘、会被噪声带偏），而是**在信任域内只动可动的那一小块**：
冻结物理不变量，只适应环境 nuisance；用 EWC 与 KL 锚住已验证盲区；用共形重校准保住 1−α 覆盖；
用小秩（LoRA）把“一次改动的影响半径”限制在可审计范围内。微调的目标不是“更准”，
而是“**在不破坏任何已认证子图的前提下，把 η 降下来**”。

**灵感 2（数据采集 → 数据是资产，也是负债）**
直觉：ToolGauge 的回执是“用完即弃”的：本地校准完就丢，下一个盲区从零开始。数据采集的启示
是把回执变成**有护照、有账期、可估值、可撤回**的资产。但数据同时是负债：相关样本会伪装成
独立证据，投毒样本会把偏差焊进权重。因此采集必须同时回答三个问题：**采什么**（边际价值最高）、
**留什么**（去重 / 去毒 / 保覆盖）、**何时删**（认证遗忘）。采集策略也不能只看模型自己的
不确定性——那会形成回音室；必须保留固定比例的外部审计与随机探索。

**灵感 3（耦合 → 证据会计：让“数据”与“权重”双向对账）**
直觉：微调与采集单独看都是成熟技术；把它们焊在一起才产生新风险——模型决定采什么，
采到的数据又改模型，形成自我确认回路。解药是会计学式的**复式记账**：左边是模型里每条主张
（claim）的证据支撑，右边是数据湖里每条回执能支付的证据量；**任何一次微调都必须是
“有证据的支出”**。账面不平衡（证据负债 > 0）时不许动权重，只能去采集。这样“微调”被证据门控、
“采集”被微调定价，飞轮才不会空转或自嗨。第 2 轮把语言主张绑定到回执（定义 423），
本轮把**权重本身**也绑定到回执（I-EB）——这是主张绑定不变式的权重级扩展。

## 1. 形式化定义（增量：定义 432–447）

**定义 432（两速架构与快慢环契约）**
*直觉：慢环可以想很久，但绝不能让快环等它；新模型要么完整上线，要么完全不上线。*
快环 = 50Hz 控制 + ToolGauge 6C；慢环 = 飞轮 4D。慢环只写影子缓冲 θ_shadow，不触碰在线 θ_live；
部署是 copy-on-write + **原子指针交换**。快环对慢环的唯一可见接口是 (a) 追加只读回执，
(b) 在安全点接受一次原子换指针。形式化：`swap(θ_shadow, θ_live)` 为原子操作，swap 前后
任一 50Hz 周期看到的 θ 要么是旧、要么是新，不存在半更新；慢环任一阶段失败 ⇒ θ_live 不变。

**定义 433（计量数据湖 MDL 与数据护照）**
*直觉：每条回执都要能回答“谁、用什么工具、在什么环境下、什么时候采的、有没有被独立审计”。*
记录 x = (r, pp, ℓ, lin)。护照 pp = (source_id, tool, env_hash, sig, ts, seq, π_ver, audit_flag)；
lin 记录祖先（由哪次采集 / 哪条回执派生）。准入：valid(r) ∧ pp 完整 ∧ sig 可验。
数据湖 append-only；删除只能通过“撤回标记 + 认证遗忘”（定义 442）完成，保留审计痕迹。

**定义 434（证据账本与证据负债）**
*直觉：模型说的每一句话，账上都得有发票。*
对部署契约 EC 中每条可微调主张 c（参数 u_c），支撑信息 supp(c) = 数据湖中对 u_c 有 Fisher 信息的
有效回执集合；证据负债 d(c) = max(0, n_min(c) − n_eff(supp(c)))（n_eff 见定义 435）。
总负债 D(θ) = Σ_c d(c)。**证据平衡不变式 I-EB**：若 θ 相对 θ_t 在子空间 S 上改动非零，
则 S 中每条主张必须满足 d(c)=0，或该改动被显式记为“证据赤字实验”（只允许发生在影子模型上，
不得部署）。

**定义 435（有效证据量与 Fisher 支撑）**
*直觉：同一角度拍一百张照片不是一百份证据；只有独立信息才算。*
对回执集 R，令 I(R) = Σ_j J_j 为 Fisher 信息矩阵（J_j 由该回执的观测模型给出），
n_eff(R) = (tr I)² / tr(I²)（有效秩 / 参与比），并以最小特征值方向 I_min 作为稳健下界。
支撑判据用矩阵序 **I(R) ≽ n_min·I**，而不是计数 |R| ≥ n_min。这直接封堵“重复采集刷证据”。

**定义 436（数据估值 VoD）**
*直觉：一条数据值多少钱，取决于“没有它，已认证决策会差多少”。*
给定**外部不可采集**的审计集 A_ext 与当前模型 θ_t，回执 r 的一阶影响估值
v(r) = −∇_θ L(A_ext; θ_t)ᵀ H_{θ_t}^{-1} ∇_θ ℓ(r; θ_t)，H 为 A_ext 上损失的 Hessian
（LiSSA / 共轭梯度近似）。稳健版对候选批 B 用 trimmed influence（截尾分位），并做一次廉价
“探针微调”在留出集上实测 Δ；最终 v̂(r) = clip(trimmed_influence + probe_correction, −v_max, v_max)。

**定义 437（主动采集策略 π_collect）**
*直觉：预算有限时，先摘“最能把负债清零、又最独立”的果子。*
状态 S_t = (R 的覆盖 / 不确定度图, θ_t, 漂移估计 η̂, 数据湖覆盖 C_lake)；动作 a = 一组
(s, tool, args, 是否请求标签)，成本 Σc ≤ B_collect。目标：
`max_a E[Σ_{r∈a} v̂(r) − λ_c·cost(a) − λ_r·redundancy(a)]`
s.t. 覆盖约束（每个高负债格至少访问 1 次）、审计比例 ρ、探索下限 ε_exp（定义 443）、每源上限。
在 v̂ 单调次模假设下，成本-收益贪心给 (1−1/e)/2 近似（引理 52）。

**定义 438（数据策展与污染隔离）**
*直觉：进厨房前先洗菜；可疑的先隔离，不直接下锅。*
Curate(D_raw) → (D_cur, Q, A)：
1. **去重**：近邻哈希 + 信息冗余度（I 的新增特征值 < δ_dedup 即丢弃）；
2. **隔离**：跨模态残差稳健 z 分数 |z| > τ_poison，或与护照环境哈希矛盾 ⇒ 进隔离区 Q
   （**不丢弃**，供取证与遗忘）；
3. **审计抽样**：固定比例 ρ 由**外部流程**独立复核，进入 A_ext，永不参与训练；
4. **每源上限** c_src：单源贡献信息量 ≤ ε_src，防单点投毒。
只有 D_cur 可进入微调。

**定义 439（信任域微调 TR-FT）**
*直觉：只允许在“不会推翻已知物理”的方向上小步走。*
θ_{t+1} = argmin_θ L(θ; D_cur) + λ_E Σ_i F_i (θ_i − θ_{t,i})² + β·KL(q_θ ‖ q_{θ_t})
s.t. (i) sup_{s∈V_gold} D_KL(q_θ(u_s) ‖ q_{θ_t}(u_s)) ≤ ε_forget；
(ii) θ − θ_t ∈ span(LoRA 低秩子空间)，且 θ_frozen 上的梯度投影为零；
(iii) Σ_θ ≽ κ_phys·I（继承定义 420 的保守性夹紧）。
V_gold 是**外部金标盲区集**，其回执绝不由本系统的采集策略产生（防自我确认）。

**定义 440（微调证书 FT-Cert）**
*直觉：没有体检报告，不许换器官。*
FT-Cert = (θ_t, θ_{t+1}, hash(D_cur), hash(code), 金标回归结果, A_ext 覆盖重估, ε_forget 实测,
η̂, 序贯检验统计量, 签署者)。部署判据（全部满足）：
1. A_ext 上风险改进的下置信界 LCB_δ(ΔR) > 0（序贯 e-value，允许可选停止）；
2. 金标集退化 ≤ ε_gold；
3. A_ext 上共形覆盖 ≥ 1−α−η̂；
4. I-EB 成立且 D(θ_{t+1}) ≤ D(θ_t)；
5. 契约回归测试通过（继承第 2 轮）。
任一不满足 ⇒ 不部署，并把缺口定位到具体主张 c，转回采集。

**定义 441（棘轮部署与回滚 RPD）**
*直觉：只往上棘，不往下滑；换上去也要能一键退回。*
双缓冲 (θ_live, θ_shadow)；canary 比例 p_c 的盲区先用 θ_shadow 修复并在线比较；
若 canary 期出现覆盖跌破 SLA 或回归失败 ⇒ 原子回滚并写入“部署事件账”。
棘轮语义：只有 FT-Cert 通过的部署才推进版本号；版本号单调，回滚是“切回上一版本”，不是改历史。

**定义 442（认证遗忘 / 数据撤回）**
*直觉：发现某条数据是毒，必须能把它从权重里“抠掉”，而不是只删文件。*
revoke(r)：若 r 已用于微调，则用影响函数的二阶 Newton 更新近似移除，或在低秩子空间内对受影响
分片精确重训；要求移除后输出分布与“从未见过 r 的重训模型”之间 TV ≤ ε_unlearn
（成员推断 MIA + 输出距离双重验证）。护照 lin 给出“哪些版本受污染”的传播闭包。

**定义 443（探索下限与独立审计）**
*直觉：不能只问自己想问的问题，否则永远听不到反面意见。*
采集策略强制：每轮至少 ε_exp 比例的动作由**与模型不确定度无关**的固定随机 / 网格规则选取；
审计集 A_ext 由外部流程按 ρ 补充且本系统不可写入。形式化：
π_collect = (1−ε_exp)·π_greedy + ε_exp·π_uniform。这保证漂移区域被访问的概率有下界（引理 55）。

**定义 444（漂移检测与飞轮触发）**
*直觉：不是每天重训，而是“有证据表明世界变了”才重训。*
在 A_ext 流上维护 e-value / CUSUM，监测覆盖残差与标准化预测残差；e-value ≥ 1/δ_drift 触发慢环。
给出平均运行长度 ARL 与误报率控制；未触发时慢环休眠，零开销。

**定义 445（数据 / 微调预算契约 DC-Contract）**
*直觉：飞轮也要有油表和刹车。*
DC = (B_collect, B_ft, ρ, ε_forget, ε_gold, ε_unlearn, τ_flywheel, rollback)。采集 / 训练 / 证书成本
受硬顶约束；超预算 ⇒ 只保留最高 VoD 的子集并降级；慢环永远不得占用快环预算（继承引理 50/56）。

**定义 446（可复现性与数据版本）**
*直觉：证书上的每个数字都必须能在一年后被重放出来。*
Manifest = (θ_0 hash, D_cur 版本与顺序, code hash, seed, 超参)。要求同一 Manifest 重放得到
位级一致（或给定容差内）的 θ；不可复现 ⇒ 拒绝部署（防“不可审计的改进”）。

**定义 447（整合与严格退化链）**
*直觉：飞轮转不动时，系统必须能退回一台“不需要飞轮也能工作”的机器。*
FlywheelGauge 失效（采集预算耗尽 / 微调证书连续 2 次失败 / 数据湖不可用 / 漂移检测器失效）
⇒ 冻结当前 θ，退回 ToolGauge（定义 416–431 原样）；ToolGauge 失效 ⇒ LeanGauge ⇒ MODGAUGE。
令 π_collect = ∅、TR-FT = 恒等 ⇒ **FlywheelGauge ≡ ToolGauge**。

# IP-321 证据账本：Fisher 支撑 + n_eff + 负债
class EvidenceLedger:
    def support(self, claim):
        R = self.lake.effective(claim.param)            # 仅有效、去重、独立回执
        I = sum(fisher(r, claim) for r in R)            # Fisher 信息矩阵
        tr, tr2 = trace(I), trace(I @ I)
        n_eff = (tr ** 2) / tr2 if tr2 > 0 else 0.0
        return I, n_eff
    def debt_claim(self, c):
        return max(0.0, c.n_min - self.support(c)[1])
    def debt(self, theta):
        return sum(self.debt_claim(c) for c in claims(theta))
    def can_update(self, subspace):                     # I-EB 门控
        return all(self.debt_claim(c) == 0 for c in subspace.claims)

# IP-322 数据湖 + 数据护照
class DataLake:
    def admit(self, r, passport):
        if not valid(r) or not passport.complete(): return False
        self.append(Record(r, passport))                # append-only
        return True
    def effective(self, param):
        return [x.r for x in self.records
                if x.passport.audit_ok and not near_dup(x, param)]

# IP-323 数据估值 + 主动采集
class Collector:
    def value(self, r):
        g    = grad_loss(self.audit, self.theta)        # 外部审计集 A_ext
        hg   = self.hinv(g)                             # LiSSA 近似 H^{-1}g
        infl = -hg @ grad_loss_one(r, self.theta)
        return clip(trim(infl) + self.probe(r), -V_MAX, V_MAX)
    def plan(self, S, budget):
        cand    = self.candidates(S)                    # 高负债 × 可采集
        greedy  = cost_benefit_greedy(cand, self.value, budget)
        explore = self.uniform_subset(cand, eps_exp=0.1)          # 定义 443
        plan    = merge_capped(greedy, explore, budget, src_cap=EPS_SRC)
        return audit_interleave(plan, rho=0.05)         # 定义 438

# IP-324 信任域微调 + 微调证书
class TRFT:
    def finetune(self, theta, D_cur):
        theta1 = lora_sgd(objective(theta, D_cur,
                        ewc=EWC(theta, fisher),
                        kl_anchor=theta),
                        freeze=theta.frozen_mask, rank=8)
        return project_low_rank(theta1), clamp_min(theta1.Sigma, KAPPA_PHYS)
    def certify(self, theta0, theta1, D_cur):
        c  = FT_Cert(theta0, theta1, hash(D_cur))
        ok = (c.lcb_delta_risk(self.audit) > 0
              and c.gold_regression() <= EPS_GOLD
              and c.coverage(self.audit) >= 1 - ALPHA - c.eta_hat
              and c.ledger_balanced()                   # I-EB
              and contract_regression(c))
        return ok, c

# IP-325 棘轮部署 + 认证遗忘
class Deployer:
    def ratchet(self, M, theta1, cert):
        if not cert.ok: return M.theta_live             # 不部署
        M.shadow = theta1
        if not self.canary(M, frac=0.05):
            return self.rollback(M)                     # 原子回滚
        atomic_swap(M.theta_live, M.shadow)             # 定义 432 / 引理 56
        M.version += 1
        return M.theta_live
    def revoke(self, r):
        for sh in self.lake.lineage(r):                 # 护照传播闭包
            self.theta = unlearn(self.theta, r, sh, eps=EPS_UNLEARN)

# IP-326 FlywheelGauge 4D 慢环
def flywheel_4d(M):
    if not M.drift.triggered(): return                  # Detect：休眠，零开销
    S     = M.state()                                   # 负债图 + 漂移估计
    plan  = M.collector.plan(S, M.dc.B_collect)         # Design：主动采集
    recs  = M.tcv.execute(plan, M.env)                  # 复用定义 418 执行语义
    D_cur, Q, A = Curate(recs, M.lake)                  # 策展 + 隔离 + 审计
    if not M.ledger.can_update(subspace(D_cur)):        # I-EB 证据门控
        return M.collector.request_more(D_cur)          # 只采不训
    theta1 = M.trft.finetune(M.theta_live, D_cur)       # Distill：信任域微调
    ok, cert = M.trft.certify(M.theta_live, theta1, D_cur)
    if ok: M.deployer.ratchet(M, theta1, cert)          # Deploy：棘轮
    else:  M.collector.request_more(cert.missing_claims)
    M.audit.append(A)                                   # 外部审计回流

# 主闭环：快环原封不动
def FlywheelGauge_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s); submit_async(toolgauge_6c, M, s)   # 第 2 轮不变
    if M.flywheel_due(): submit_async(flywheel_4d, M)             # 慢环异步
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 3. 推导

**引理 51（棘轮安全保证）** 设 A_ext 与 θ 独立，序贯检验（e-value）在水平 δ 下有效，金标退化阈 ε_gold。
则对任意 T 轮，`P(∃t<T: R(θ_{t+1}) > R(θ_t) + ε_gold) ≤ Tδ`。
证明：每轮部署是对“改进 ≤ 0”的单侧检验，e-value 在可选停止下仍是上鞅；坏部署被拒概率 ≥ 1−δ，
再按 union bound 合并；canary 与回滚只会进一步降低坏部署概率。
系：ε_gold→0 时部署序列在风险意义下是“上鞅棘轮”——只允许统计显著的下降。

**引理 52（VoD 的次模性与采集近似）** 若 v̂ 非负、单调，且新增回执的边际价值随已选集合增大
不增（信息增益收益递减 + 去重惩罚），则 F(a) = Σv̂ − λ_r·redundancy 单调次模；成本-收益贪心在
预算约束下达到 ≥ ½(1−1/e)·OPT；成本均匀时 ≥ (1−1/e)·OPT。
证明：标准次模最大化（Khuller 等）+ 覆盖约束用阈值枚举 / 拉格朗日。
系：n_eff 支撑使“刷同源重复数据”的边际价值趋零，故贪婪自动避开冗余。

**引理 53（微调遗忘界与覆盖保持）** 若 TR-FT 在 V_gold 上的 KL 约束 ≤ ε_forget，且微调后用 A_ext
重估共形分位数，则任一经认证盲区的后验预测 TV 变化 ≤ √(ε_forget/2)（Pinsker）；A_ext 上覆盖满足
`P(coverage ≥ 1−α−η̂−O(√(log(1/δ)/|A_ext|))) ≥ 1−δ`（共形 + 集中不等式）。
证明：Pinsker + 共形交换性 + Hoeffding。系：ε_forget 是可调的“安全旋钮”，不是口号。

**引理 54（数据投毒的破坏点）** 若 D_cur 中被控样本比例 ≤ ε_poison，策展用 trimmed influence +
每源信息上限 + 独立审计 A_ext，则微调参数偏差 `||θ1 − θ*|| ≤ C·ε_poison·√(d_cur/|A_ext|) + o(ε_poison)`。
证明：稳健统计的截尾估计 breakdown point + 影响函数线性化；每源上限把单源最大影响从 O(1)
压到 O(ε_src)。系：无策展时偏差可无界（对照 E444）。

**引理 55（探索下限的漂移捕获）** 在 ε_exp 探索下限与漂移区域“正概率可访问”假设下，
T 轮内从未访问某漂移格的概率 ≤ (1−ε_exp·p_min)^T；漏检时间随 T 指数衰减。
证明：独立探索动作的几何分布 + union bound。系：这是回音室 / 确认偏误的形式化断路器（E449）。

**引理 56（时序、预算与可复现性保持）** 慢环完全异步、影子缓冲、原子换指针；50Hz 快环新增开销
仅为一次原子读，< 0.05ms（比第 2 轮回执验证更小）；单次飞轮时延 ≤ B_collect + B_ft + τ_cert ≤ τ_flywheel；
超预算由 DC-Contract 截断并降级；Manifest 重放保证位级可复现 ⇒ 回滚与审计可执行。
证明：与引理 45/50 同构 + 确定性种子与数据顺序。系：FlywheelGauge ≡ ToolGauge（令慢环恒不触发）。

## 6. 本轮最大风险（一句话）

**一句话**：证据飞轮最怕的不是“数据不够”，而是“数据太多且都长得一样”——当采集策略由模型自身的
后验驱动时，高度相关的回执会**同时抬高 n_eff 与 VoD**，形成自我确认闭环，把第 2 轮一次性的分布
偏移固化为写进权重、看似有证书背书、还能自我复制数据偏好的持久错误；越到后期，金标集越可能随
漂移“过期”，使棘轮锁死在一个错误的世界模型上（E444/E449/E455 为证伪实验，外部金标、独立审计、
探索下限、稳健聚合、认证遗忘为五重兜底）。

**次级风险与缓解**：
1. **相关数据刷证据** → n_eff（Fisher 有效秩）替代计数 + 去重 + 每源信息上限（定义 435/438）；

4. **微调灾难性遗忘** → 信任域 KL + EWC + 冻结物理不变量 + 共形重校准（定义 439、引理 53）；
5. **证书造假 / 不可复现** → Manifest 重放 + 外部签署 + 位级一致性（定义 440/446）；
6. **棘轮锁死** → 金标集定期外部换血 + 漂移触发全量重新认证 + 回滚保留旧版本（定义 441/444）；
7. **慢环拖垮实时性** → 影子缓冲 + 原子换指针 + DC-Contract 硬预算（定义 432/445、引理 56）。

# IP-321 证据账本：n_eff 支撑 + 负债 + I-EB
class EvidenceLedger:
    def support(self, claim):
        I = sum(fisher(r, claim) for r in self.lake.effective(claim.param))
        tr, tr2 = trace(I), trace(I @ I)
        return I, ((tr ** 2) / tr2 if tr2 > 0 else 0.0)
    def debt_claim(self, c):
        return max(0.0, c.n_min - self.support(c)[1])
    def can_update(self, subspace):
        return all(self.debt_claim(c) == 0 for c in subspace.claims)

# IP-322 数据湖
class DataLake:
    def admit(self, r, passport):
        if not valid(r) or not passport.complete(): return False
        self.append(Record(r, passport)); return True

# IP-323 数据估值 + 主动采集
class Collector:
    def value(self, r):
        g = grad_loss(self.audit, self.theta)
        return clip(trim(-self.hinv(g) @ grad_loss_one(r, self.theta))
                    + self.probe(r), -V_MAX, V_MAX)
    def plan(self, S, budget):
        cand    = self.candidates(S)
        greedy  = cost_benefit_greedy(cand, self.value, budget)
        explore = self.uniform_subset(cand, eps_exp=0.1)
        return audit_interleave(
            merge_capped(greedy, explore, budget, src_cap=EPS_SRC), rho=0.05)

    theta1 = M.trft.finetune(M.theta_live, D_cur)         # Distill
    ok, cert = M.trft.certify(M.theta_live, theta1, D_cur)
    (M.deployer.ratchet(M, theta1, cert) if ok
     else M.collector.request_more(cert.missing_claims))  # Deploy
    M.audit.append(A)

# 主闭环：快环原封不动
def FlywheelGauge_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s); submit_async(toolgauge_6c, M, s)
    if M.flywheel_due(): submit_async(flywheel_4d, M)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 51（棘轮安全）** `P(∃t<T: R(θ_{t+1}) > R(θ_t)+ε_gold) ≤ Tδ`（e-value 可选停止 + union bound；canary/回滚进一步降低）。
**引理 52（VoD 次模 + 采集近似）** 单调次模下成本-收益贪心 ≥ ½(1−1/e)OPT；成本均匀 ≥ (1−1/e)OPT；n_eff 使重复数据边际价值趋零。
**引理 53（遗忘界 + 覆盖）** V_gold 上 KL≤ε_forget ⇒ 后验预测 TV ≤ √(ε_forget/2)（Pinsker）；A_ext 重估后覆盖 `≥1−α−η̂−O(√(log(1/δ)/|A_ext|))` 以 1−δ 成立。
**引理 54（投毒破坏点）** 被控比例 ≤ ε_poison 时 `||θ1−θ*|| ≤ C·ε_poison·√(d_cur/|A_ext|)+o(ε_poison)`（trimmed + 每源上限 + 独立审计）；无策展时可无界。
**引理 55（探索捕获）** 漂移格 T 轮未访问概率 ≤ (1−ε_exp·p_min)^T；回音室断路器。
**引理 56（时序/预算/可复现）** 快环新增 <0.05ms（一次原子读）；飞轮时延 ≤ τ_flywheel；DC 硬顶；Manifest 位级重放 ⇒ 可回滚可审计。

## 8. 本轮最大风险

**一句话**：证据飞轮最怕的不是“数据不够”，而是“数据太多且都长得一样”——当采集策略由模型自身的
后验驱动时，高度相关的回执会**同时抬高 n_eff 与 VoD**，形成自我确认闭环，把第 2 轮一次性的分布
偏移固化为写进权重、看似有证书背书、还能自我复制数据偏好的持久错误；越到后期金标集越可能随漂移
“过期”，使棘轮锁死在一个错误的世界模型上——以 E444/E449/E455 证伪，外部金标（V_gold）、
独立审计（A_ext）、探索下限（ε_exp）、稳健聚合（trimmed + 每源上限）、认证遗忘（revoke）五重兜底。
