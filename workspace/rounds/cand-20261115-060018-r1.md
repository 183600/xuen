# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「对话管理」×「语音交互」）

> R69 把「不确定」分成 aleatoric / epistemic，并用「流匹配多模态策略 + 主动多模态交互」去消解后者。但它对「交互」的建模仍是一次性的：MINT 计算单步 VoI(g)，选一个 g，得到一个人/环境的回答 y，再用「k 个正交证据源一致」定案。这里藏着三个未言明的前提：(1) 回答是**一次查询**，不是**一段对话**；(2) 回答者与提问者共享同一个问题含义（已接地）；(3) 同一个人的多次回答可以被当作独立证据。真实语音交互把这三条逐一击穿：人会反问你、会误解你的问法、会在犹豫时停顿、会用语气而不是词句回答、也会演戏；而「同一个人的第二句话」不是第二个证人，只是同一个证人的复述。
>
> 本轮两个灵感正好补上「对话」与「声音」：
> - **对话管理**给出状态：共同基础（common ground）、伙伴模型（对方知道什么/是否听懂/是否愿意说）、修复（clarify/rephrase/confirm）与多轮终止——「问」不是抽取，是**共建**；
> - **语音交互**给出通道：内容之外还有韵律、停顿、语速、打断与副语言；它既是「对方有多确信」的弱证据，也是新的可欺骗面。
>
> 核心命题：**把 R69 的「单步证据获取」升级为「多轮共同基础建构」；只有当一个回答被接地（进入 common ground）且来源多样性足够时，才允许它更新模态后验；语音副语言只作弱校准证据，永不单独定案；对话只做慢环，快环用已认证的安全兜底，因此安全侧仍不弱于 R69/R68。** 命名 **GROUND-RAS**（Common-Ground-aware Risk-adaptive Open Uncertainty Negotiation Dialogue）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我们真的在说同一件事吗、对方听懂了吗、我该何时闭嘴**」——不确定性的消解不是一次查询，而是一段需要共同基础的关系。

## 0. 直觉与动机

**灵感 1（对话管理 → 问是一次查询，对话是一次共建）**
直觉：R69 的 MINT 像一个只允许问一句话的记者：算好哪个问题最值钱，问完就把答案当作 y。但人解决歧义不是这样：先试探性地说半句，看对方是否接话；对方皱眉就换个说法；对方说「你是说左边那个？」就确认；对方沉默就等。对话管理把这套东西形式化为**信念状态 + 对话动作 + 终止/修复**。关键的语义升级：答案不是从环境中「读」出来的，而是**在双方共同基础里被构建出来的**。没有接地，y 只是一个字符串，不是一个证据。

**灵感 2（共同基础 → 新终止条件：不是「熵降了」，而是「我们都说好了」）**
直觉：R69 的 VoI 只问「这个动作能不能降低模态熵」。但在语音对话里，熵降了也可能是错觉：ASR 听错了、对方答非所问、对方以为你问的是另一个对象。GROUND-RAS 增加一个**接地判据**：一个命题只有经过确认（显式复述 / 隐式无修复 / 可执行指代成功）才进入 common ground C，才允许更新模态后验 M。这把「获取答案」升级成「获取可共同执行的承诺」，直接对应机器人真正的需求——它要的不是一个标签，而是一个能向人类解释、能被审计的共识。

**灵感 3（单源相关 → R69 的 k-正交纪律在多轮里失效）**
直觉：R69 的引理 18 说「k 个正交证据源多数一致，错误率 ≤ δ_p ρ^{k−1}」。但在对话里，k 次追问往往来自**同一个人**；同一个人的错误、误解、欺骗高度相关（ρ→1），第二句「对，是左边」几乎不提供新信息。这不是参数没调好，而是**统计假设错了**。GROUND-RAS 显式定义有效独立源数 k_eff = 1 + (k−1)(1−ρ)，并要求**来源多样性**：人（语音内容）+ 传感器（视觉/力/几何）+ 自身动作后果（proprioceptive/efference copy）三者才算正交；同一人的多轮只算同一个源的不同时间片。

**灵感 4（语音 → 副语言是弱证据，也是新攻击面）**
直觉：同样一句「在左边」，语速快、音高上扬、句尾拖长、夹杂停顿，传达的确定性完全不同；犹豫、反问语调、叹气、笑声都可以是「我不确定」或「我在敷衍」的信号。语音因此是比文本更丰富的证据通道。但它也更容易被伪造：录音重放、语音克隆、刻意放慢/提高音调、背景音掩盖。所以副语言证据必须**校准且限权**：它可以把可信度从 0.5 推到 0.65，但不能从 0.5 推到 0.95；ECE_v 越界即降为 advisory。

**灵感 5（轮次时序 → 「等」和「打断」也是信息动作）**
直觉：R69 的动作空间有看/触/问，但没有「何时说、说多久、是否让对方说完」。语音交互里，打断（barge-in）会摧毁对方正在组织的信息；过早补问会把「我在想」误读成「我不知道」；适当沉默反而能引出更完整的回答。GROUND-RAS 把 g_turn = (speak, yield, wait, backchannel) 加入动作空间，并用「等待的 VoI vs 错过时间窗的风险」决定何时闭嘴。这是 R69 的 g_ask 无法表达的维度。

**灵感 6（疲劳与双时间尺度 → 对话不能塞进 2.6ms 控制环）**
直觉：对话是慢的（ASR、理解、生成、播放，数百毫秒到数秒），控制是快的（毫秒级）。R69 把所有交互塞进实时环，隐含假设「问一句几乎不花时间」。GROUND-RAS 明确**双时间尺度**：快环保留 R69 的反射与安全兜底；对话环异步进行，只能从「已认证动作集」里选，不能扩大安全包络。这样对话的延迟、失败、超时都不影响控制安全，也解释了为什么 R68/R69 的实时预算仍然成立。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（GROUND-RAS 总览）** GROUND-RAS = (CDM, PME, CGU, SAG, PVC, SDG, MVID, DTP, RPR, TTS, CFB, DTSS, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **对话预算硬约束**（总轮数、总时长、社交成本、疲劳；扩展 R69 定义 293-ii）；
(iii) **接地先于更新**：任何回答 y 只有在通过接地判据（定义 316）后，才允许以权重 ≤ 1 更新 M；未接地只进入「暂存假设」；
(iv) **双时间尺度安全分离**：对话动作只能在已认证动作集 𝒜_cert 内做选择，不得扩大安全包络；快环在对话期间执行安全兜底。

**定义 311（对话状态）** s_t^D = (b_t(M), C_t, θ_p, f_t, h_t)。b_t(M) 为模态后验（继承 R69 的模态集与权重）；C_t 为共同基础（双方互知命题集合）；θ_p 为伙伴模型（定义 312）；f_t 为疲劳/社交成本累积；h_t 为对话历史（含语音观测）。对话是 POMDP，观测 y_t^v 由定义 313 给出，动作由定义 315 给出。

**定义 312（伙伴模型）** θ_p = (K_p, ρ_p, β_p, κ_p, λ_p)：
- K_p ⊆ 命题空间：伙伴的知识覆盖（他知道什么）；
- ρ_p ∈ [0,1]：回答可靠度（诚实且正确）；
- β_p ∈ [−1,1]：合作倾向/激励（正=帮助，负=诱导）；
- κ_p ∈ [0,1]：理解力（听懂问句的概率）；
- λ_p(·)：回答时延分布（与不确定性相关）。
θ_p 有后验 b_t(θ_p)，随对话更新；**R69 隐含 θ_p = (全知, 1, 1, 1, 点质量)**。伙伴模型是本轮最关键的「新增信念」：不建模对方，就无法判断「不知道」「没听懂」「不愿说」「在骗我」四种截然不同的沉默。

**定义 313（语音观测）** y^v = (y_txt, y_pros, y_time, y_nonverb, a_s)。y_txt 为 ASR 文本（带置信度 c_asr）；y_pros 为韵律特征（F0 轮廓、能量、语速、停顿、犹豫标记）；y_time 为时延/打断/重叠；y_nonverb 为笑声/叹气/点头声等；a_s ∈ 𝒜_speech = {inform, confirm, deny, clarify, request, refuse, social, nonanswer} 为言语行为类型。R69 的标量 y 是 y^v 在「inform + 无噪声 + 无韵律 + 无时序」上的投影。

**定义 314（语音证据通道与校准）** 副语言证据 e_pros = f_pros(y_pros, y_time) ∈ ℝ^{d_e}，给出对「伙伴确信度/理解度/真诚度」的似然比。校准要求：可靠图单调、ECE_v ≤ τ_v；若越界，e_pros 只可作 advisory（只影响成本与追问措辞，不影响后验更新）。语音证据的信任权重上限 w_v ≤ w_v^max(ECE_v, δ_spoof)（引理 21）。

**定义 315（对话动作空间）** 对话动作 g_D = (g_turn, g_say)：
- g_turn ∈ {speak, yield, wait, backchannel, barge_in}；
- g_say = (g_ask, g_confirm, g_rephrase, g_demonstrate, g_none)，其中 g_ask 继承 R69；g_confirm 复述候选模态请求确认；g_rephrase 换一种接地方式重问；g_demonstrate 用示范/指代代替语言。
总动作 ξ = (a, g_D) ∈ 𝒜_+^D；g_D 也必须过 C-RAS-WM 认证（继承定义 302）与对话预算（定义 323）。

**定义 316（接地算子与接地判据）** Ground(C, p, y^v) → C′：命题 p（如「目标是左杯」）进入 C 当且仅当满足以下至少两条且无冲突：
(g1) 显式确认（confirm/复述/指代成功）；
(g2) 隐式无修复（下一轮未出现 clarify/deny/疑问语调）；
(g3) 可执行验证（按该命题执行一个低风险探针并观察预期后果）；
(g4) 跨源一致（至少一个非语言源支持）。
接地状态 gnd(p) ∈ {grounded, provisional, contradicted}。只有 grounded 的 p 允许以全权重更新 M；provisional 以折扣权重 γ_gnd < 1 更新；contradicted 触发修复（定义 321）。

**定义 317（接地感知的答案模型）** P(y^v, a_s, y_time | M=m, C, θ_p, g_D)。与 R69 的 p(y|m) 不同，它显式分解为
P(y_txt | m, κ_p) · P(a_s | m, β_p) · P(y_pros | m, ρ_p, κ_p) · P(y_time | m, λ_p)，
并条件在共同基础 C 上。R69 是其「κ_p=1, β_p=1, λ_p=δ, 韵律无信息, 且 C 可空更新」的退化。

**定义 318（有效独立源与来源多样性）** 设有 k 个证据源，两两误差相关 ρ̄；有效独立源数 k_eff = 1 + (k−1)(1−ρ̄)。来源多样性 D = 1 − max_{i≠j} |corr(e_i, e_j)|。证据纪律升级为：需要 k_eff ≥ k_min 且 D ≥ D_min，才允许定案；同一伙伴的多轮只计作**一个源的时间片**，其 ρ̄ 由 θ_p 的后验估计。R69 的「k 个正交源」是 D=1 且 ρ̄=0 的特例。

**定义 319（多轮对话信息增益 MVID）** 在第 t 轮，
VoI_D(g_D; b, C) = I(M; y^v, a_s, y_time | do(g_D), C) + η·I(C; y^v | do(g_D)) − c(g_D) − c_f(f_t)。
第二项是**接地增益**（把命题放进共同基础的价值）；c_f 随疲劳 f_t 超线性增长。选择 g_D* = argmax VoI_D，s.t. 安全、预算、接地约束；若 max VoI_D ≤ 0 或预算耗尽 → 终止对话，回 R69/R68 兜底。

**定义 320（对话策略）** π_D(g_D | s^D) 在信念空间上求解受限 POMDP：
max_π E[Σ_t γ^t (VoI_D − c)]，s.t. 安全/预算/接地约束。实时实现用「一步前瞻 + 短 rollout」近似（R69 定义 308 廉价门控在对话层的对应）；不追求全局最优，只保证**不劣于 R69 的单步策略**（引理 22 的单调改进条件）。

**定义 321（修复算子）** 当 gnd(p)=contradicted、c_asr < τ_asr、或 e_pros 报「不理解」时触发。修复动作 r ∈ {澄清对象, 换措辞, 示范, 降低语速, 请求复述, 放弃并兜底}；修复本身计入预算与疲劳；修复失败达 R_max 次 → 终止对话，U_epi 视为未消解，回 R68 纯保守。

**定义 322（轮次时序策略）** 等待/打断的决策：给定期望剩余信息，等待的边际价值 V_wait(τ) = E[I(M; y_{>τ})] − c_wait·τ；打断成本 c_barge；选择 τ* = inf{τ: V_wait(τ) ≤ c_barge + c_wait}。端点检测阈值 τ_eop 与「对方是否在组织语言」的韵律/停顿证据耦合；低 ASR 置信时不抢话，避免把噪声变成错误证据。

**定义 323（对话预算与疲劳）** 预算 B = (N_turn^max, T_conv^max, C_social^max)。疲劳 f_{t+1} = clip(f_t + α·1[g_D≠wait] + β·1[repair] + γ·1[重复问题], 0, 1)；单位社交成本 c_f(f) = c_0/(1−f)（凸增），f > f_max 强制终止。R69 的「≤1 次/单位时间」是 f≈0 时 B 的局部线性化。

**定义 324（双时间尺度安全壳）** 快环 𝒪_fast（≤2.6ms）执行 R69/R68 的反射策略，并在对话期间保持一个已认证的安全兜底 a_hold ∈ 𝒜_cert；慢环 𝒪_slow（对话，≥100ms）只输出「在 𝒜_cert 中选择哪个模态/哪个已认证动作」。形式化：π_D 的值域 ⊆ 2^{𝒜_cert}，且对话期间 a_hold 的 C-RAS-WM 前缀证书始终有效。⇒ 对话的延迟/失败/超时不影响安全不变量。

**定义 325（语音欺骗与投毒干扰集）** ℰ_voice = {重放, 语音克隆, 韵律伪装, 背景音掩盖, ASR 对抗扰动, 以 speech act 伪装的社交工程（把 request 伪装成 inform）, 共同基础投毒（先确认一个假前提再问）}。并入 AIC：ℰ_GROUND = ℰ_FLUID × ℰ_voice。

**定义 326（参与式审计 VQAuditor-D）** 审计对象新增：问句是否诱导、grounding 是否真的成立、单源是否被重复计权、语音证据是否越权、修复是否被滥用、对话是否在疲劳下强行继续。审计结论回灌 AuditBuf，成为下一轮 π_D 的成本先验与 SDG 的相关先验。

**定义 327（证书 J_GROUND）** J_GROUND = (J_FLUID, dialogue_state_hash, grounding_status, k_eff, source_diversity, ece_v, speech_act_dist, turn_count, fatigue, ungrounded_update_count, ground_ver)。Valid ⇔ Valid(J_FLUID) ∧ 未发生未接地更新 ∧ k_eff ≥ k_min ∧ ECE_v ≤ τ_v ∧ 预算未越界。

## 2. 关键算法骨架

```python
# IP-264 CDM：接地感知对话管理器（慢环，异步；快环只读最近一次已接地的 sD）
class GroundDialogueManager:
    def __init__(self, pm, cgu, sag, pvc, sdg, mv, policy, tts):
        self.pm, self.cgu, self.sag, self.pvc = pm, cgu, sag, pvc
        self.sdg, self.mv, self.policy, self.tts = sdg, mv, policy, tts

    def step(self, sD, g_D):
        yv = self.tts.exchange(g_D)                 # 语音观测 y^v（含韵律/时序）
        act = self.sag.classify(yv)                 # speech act + ASR 置信
        if act == 'clarify' or yv.c_asr < TAU_ASR:
            return self.repair(sD, yv)              # 先修复，绝不更新后验
        e_pros = self.pvc.calibrated_evidence(yv)   # 弱证据，带信任上限
        theta = self.pm.update(sD.theta, yv)        # 更新伙伴模型
        C2 = self.cgu.ground(sD.C, sD.focus, yv)    # 接地判据 g1–g4
        return sD.replace(theta=theta, C=C2, yv=yv, e_pros=e_pros)

# IP-265 PME：伙伴模型在线估计（知识/可靠度/合作/理解力/时延）
def update_partner(theta, yv, prior):
    return bayes_filter(theta, likelihood(yv | theta), prior, robust=True)

# IP-266 CGU：接地算子（只有 grounded 才允许全权重更新）
def ground(C, p, yv, other_sources):
    ok = sum([explicit_confirm(yv), not needs_repair(yv),
              executable_probe_ok(p), cross_source_agree(p, other_sources)])
    return C | {p} if ok >= 2 else C          # provisional 折扣 / contradicted 修复

# IP-267 SAG：言语行为分类（防止 request 伪装成 inform）
def classify(yv):
    return speech_act_head(yv.txt, yv.pros, yv.time)  # 8 类；低置信 -> clarify

# IP-268 PVC：校准的副语言证据（ECE 越界只作 advisory）
def prosody_evidence(yv):
    e = prosody_encoder(yv.pros, yv.time)
    return e * trust_cap(ece_v) if ece_v <= TAU_V else advisory_only(e)

# IP-269 SDG：有效独立源与来源多样性门控（修正 R69 的 k-一致）
def source_gate(evidence, rho_bar, types):
    k_eff = 1 + (len(evidence) - 1) * (1 - rho_bar)
    D = 1 - max_pairwise_corr(evidence)
    return (k_eff >= K_MIN and D >= D_MIN), k_eff, D

# IP-270 MVID + IP-271 DTP：多轮 VoI 与对话动作选择
def choose_dialogue_action(sD, budget):
    best = None
    for g in dialogue_candidates(sD):            # ask/confirm/rephrase/wait/...
        if not budget.allow(g) or not c_ras_wm.certify(g): continue
        score = voi_multiturn(sD, g) + ETA * grounding_gain(sD, g) \
                - cost_social(g) - cost_fatigue(sD.f)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None   # 终止 -> R69 兜底

# IP-273 TTS：端点检测 / 等待 / 打断
def turn_timing(sD):
    tau = 0
    while value_of_wait(sD, tau) > cost_wait * sD.step + cost_barge:
        tau += sD.step
    return tau

# IP-275 DTSS：双时间尺度安全壳（对话永不进快环）
def GROUND_RAS_round(M, obs, sD):
    # --- 快环：与 R69 相同，先保证安全 ---
    a_hold = M.fast.hold(obs)                    # 已认证安全兜底
    modes, U_ale, U_epi = M.fluid.infer(obs)     # R69 的多模态推断
    # --- 慢环：异步对话，只做选择，不扩包络 ---
    g_D = M.cdm.policy(sD, M.budget) if U_epi > TAU_EPI else None
    if g_D is not None:
        sD = M.cdm.step(sD, g_D)                 # 实际在慢线程执行；此处为逻辑顺序
        ok, k_eff, D = M.sdg.gate(sD.evidence, sD.rho_bar, sD.types)
        if sD.gnd_focus == 'grounded' and ok:
            modes = M.cdm.update_mode(sD)         # 仅接地 + 多样才更新
    # --- 选择：只在已认证集合内选模态 ---
    a = M.fast.select_within_cert(modes, a_hold, M.cert_set)
    return a, sD, M.cert.ground_j(sD)
```

## 3. 推导

**引理 19（单伙伴多轮的有效独立源坍缩）** 设同一伙伴的 k 次回答误差两两相关 ρ，则总 Fisher 信息满足 I_total ≤ k_eff·I_single，k_eff = 1 + (k−1)(1−ρ)。当 ρ→1，k_eff→1，追加轮次的信息增益 → 0；R69 引理 18 的 δ_p ρ^{k−1} 上界在此退化为 δ_p（无改善）。系：**重复追问同一个人不是「更多证据」，而是「同一个证据的更多副本」**；真正的正交性只能来自异质源（人/传感器/执行后果）。

**引理 20（未接地证据的更新折扣）** 设 s = P(grounded | y^v)。若以全权重更新，后验的期望 KL 误差 ≥ (1−s)·D_KL(p_true ‖ p_updated)；安全更新权重需 γ_gnd ≤ s。故「未接地不更新」是 s=0 的端点，provisional 的折扣是 0<s<1 的连续插值。系：R69 直接用 p(M|y) 更新，等价于隐含假设 s=1——这正是「问错比不问更危险」的数学根源。

**引理 21（语音证据的校准上限）** 设副语言通道可欺骗率 δ_spoof、校准误差 ECE_v。若赋予信任权重 w_v，攻击者通过伪造韵律可获得的期望后验偏移 ≥ w_v·δ_spoof − ECE_v。要保证偏移 ≤ ε_v，需 w_v ≤ (ε_v + ECE_v)/δ_spoof。⇒ 语音证据必须限权；R69 的「单源不得定案」在语音上尤其重要，因为语音是最容易被克隆/伪装的通道。

**引理 22（等待的边际价值与有限终止）** 若回答时延与不确定性正相关（λ_p 在「不确定」条件下随机占优），则等待的边际信息价值 V_wait(τ) 先增后减，最优 τ* 存在且为阈值策略。信息增益在轮次上次模（submodular），疲劳成本凸增；在仅含基数预算的简化下，贪心对话策略的累积增益 ≥ (1−1/e)·OPT，且期望轮数有限。系：**对话必须会停**；不会停的对话在疲劳下收益递减、成本超线性。

**定理 18（GROUND 严格包含 FLUID/R68）** 在 A99–A101（单轮、诚实全能伙伴 κ=β=1、无噪声且韵律无信息、C 可空更新、无疲劳）下，π_D 退化为 R69 的单步 MINT，两阶段风险与 FLUID 逐指令相同；当对话不可用/预算为 0/ECE_v 越界时也逐指令退化。因此 R69 是 GROUND 在「无对话、无接地、单源」边界上的严格特例，安全侧不做任何让步。

**定理 19（双时间尺度安全与无突变）** 对话环值域 ⊆ 𝒜_cert，且快环在对话期间始终维持 a_hold 的有效 C-RAS-WM 前缀证书；对话只能缩小/选择动作集，不能扩大安全包络。因此无论对话延迟、ASR 失败、投毒或超时，控制连续、无突变，物理风险 ≤ max(ε_int, ε_fast)（继承 R68 定理 15、R69 定理 17）。⇒ **对话可以很慢，但机器人不会因为「在聊天」而变得不安全。**

**定理 20（接地-证据纪律下的错误采纳上界）** 在 k_eff 个有效独立源、各源欺骗率 δ_i、接地概率 s 下，错误模态采纳率 ≤ (1−s)·1 + s·(多数投票错误率) + ε_σ；当 s→1 且 k_eff ≥ k_min 时退回 R69 引理 18 的形式；当 s→0 时上界为 1。系：**接地不是锦上添花，而是错误率上界里的乘法因子**——不接地，再多的「一致」也只是共同确认了一个可能错误的前提。

## 6. 本轮最大风险

**一句话**：GROUND-RAS 把「问一次」升级为「谈一轮」，但它把全部信任押在**伙伴模型与接地检测**上——一旦系统把「对方没听懂 / 在演戏 / 声音被克隆」误判为「对方知道但不愿说」，它就会在一个错误的共同基础上越谈越自信，把 R69 的「问错一次」放大成「双方共同确认的错误」：**对话越像真的，被共同构建的错误越难推翻。**

```python
    def step(self, sD, g_D):
        yv = self.tts.exchange(g_D)                  # 语音观测

# IP-270/271 MVID + DTP
def choose_dialogue_action(sD, budget):
    best = None
    for g in dialogue_candidates(sD):
        if not budget.allow(g) or not c_ras_wm.certify(g): continue
        score = voi_multiturn(sD, g) + ETA * grounding_gain(sD, g) \
                - cost_social(g) - cost_fatigue(sD.f)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None      # 终止 -> R69

# IP-275 DTSS：双时间尺度安全壳
def GROUND_RAS_round(M, obs, sD):
    a_hold = M.fast.hold(obs)                     # 快环安全兜底（<=2.6ms）
    modes, U_ale, U_epi = M.fluid.infer(obs)      # R69 多模态推断
    g_D = M.cdm.policy(sD, M.budget) if U_epi > TAU_EPI else None
    if g_D is not None:
        sD = M.cdm.step(sD, g_D)                  # 慢线程执行
        ok, k_eff, D = M.sdg.gate(sD.evidence, sD.rho_bar, sD.types)
        if sD.gnd_focus == 'grounded' and ok:
            modes = M.cdm.update_mode(sD)          # 接地 + 多样才更新
    a = M.fast.select_within_cert(modes, a_hold, M.cert_set)
    return a, sD, M.cert.ground_j(sD)
```

## 4. 推导

**引理 19（单伙伴多轮的有效独立源坍缩）** 同一伙伴 k 次回答误差两两相关 ρ，则 `I_total ≤ k_eff·I_single`，`k_eff=1+(k−1)(1−ρ)`；ρ→1 时 k_eff→1，R69 引理 18 的 `δ_p ρ^{k−1}` 退化为 δ_p。系：重复追问同一个人不是更多证据，而是同一证据的副本；正交性只能来自异质源。

**引理 20（未接地证据的更新折扣）** 设 `s=P(grounded|y^v)`。全权重更新的期望 KL 误差 ≥ `(1−s)·D_KL(p_true‖p_updated)`；安全权重需 `γ_gnd ≤ s`。「未接地不更新」是 s=0 端点，provisional 折扣是连续插值。系：R69 直接 `p(M|y)` 更新等价于假设 s=1——这正是「问错比不问更危险」的数学根源。

**引理 21（语音证据的校准上限）** 可欺骗率 δ_spoof、校准误差 ECE_v、信任权重 w_v 下，伪造韵律可获得的期望后验偏移 ≥ `w_v·δ_spoof − ECE_v`；要偏移 ≤ ε_v 需 `w_v ≤ (ε_v+ECE_v)/δ_spoof`。⇒ 副语言必须限权，语音是最易克隆的通道。

**引理 22（等待价值与有限终止）** 若回答时延与不确定性正相关，V_wait(τ) 先增后减，最优 τ* 为阈值策略；信息增益次模、疲劳成本凸增，在基数预算下贪心 ≥ `(1−1/e)·OPT` 且期望轮数有限。系：对话必须会停。

**定理 18（GROUND 严格包含 FLUID/R68）** A99–A101（单轮、诚实全能伙伴、无噪无韵律、C 可空、无疲劳）下 π_D 退化为 R69 的单步 MINT，风险逐指令相同；对话不可用/预算为 0/ECE_v 越界时同样退化。R69 = 「无对话、无接地、单源」边界。

**定理 19（双时间尺度安全与无突变）** 对话环值域 ⊆ 𝒜_cert，快环始终维持 a_hold 的 C-RAS-WM 前缀证书；对话只能缩小/选择动作集，不能扩大安全包络。故对话延迟/ASR 失败/投毒/超时下控制连续无突变，物理风险 ≤ max(ε_int, ε_fast)（继承 R68 定理 15、R69 定理 17）。

**定理 20（接地-证据纪律下的错误采纳上界）** 在 k_eff 个有效独立源、各源欺骗率 δ_i、接地概率 s 下，错误采纳率 ≤ `(1−s) + s·多数投票错误率 + ε_σ`；s→1 时退回 R69 引理 18 形式，s→0 时上界为 1。系：接地是错误率上界里的乘法因子，不接地则再多的「一致」也只是共同确认了一个可能错误的前提。

## 7. 本轮最大风险

**一句话**：GROUND-RAS 把「问一次」升级为「谈一轮」，但把全部信任押在**伙伴模型与接地检测**上——一旦系统把「对方没听懂 / 在演戏 / 声音被克隆」误判为「对方知道但不愿说」，它就会在一个错误的共同基础上越谈越自信，把 R69 的「问错一次」放大成「双方共同确认的错误」：**对话越像真的，被共同构建的错误越难推翻。**

**次级风险与缓解**：伙伴模型误配（鲁棒贝叶斯 + 悲观后验 + E303）；语音克隆/重放（限权 + 活体检测 + ℰ_voice 对抗训练）；ASR 噪声被当作证据（低置信即停止更新 + 修复优先）；对话疲劳与社交成本（凸成本 + 强制终止 + E309）；慢环拖垮实时（双时间尺度 + 对话永不进快环 + E310/E316）；共同基础投毒（接地需多源 + 可执行验证 + VQAuditor-D）。
