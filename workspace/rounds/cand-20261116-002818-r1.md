# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「专利布局」×「任务分解」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**主张先于执行、分解不越过缝合、组合不赌单点**。两个灵感治理 v9 的两笔债：**举证债**（块证书的有效性靠“最近没检测到域偏移”这一阴性证据，Δ_dom 的 20 帧滑窗滞后即形成盲区）与**长程债**（v9 只回答“下一块怎么走”，不回答“整任务如何切成可独立认证、可替换履行的子任务”）。所有新组件一律为可选增强：失效即退回 T_⊥（v9 的 K=1 全模块逐步执行），严格等价 v9，而非行为漂移。

## 0. 直觉与动机

**灵感 1（专利布局 → 从“一条宽主张”到“可举证的主张组合”）**
直觉：v9 的块证书像一条过宽的专利权利要求——它声称“信任域内 K 步都安全”，支撑却只是“最近 20 帧没检测到域偏移”。专利布局真正的教训不是“多申请几个”，而是：每条权利要求必须有**边界**、有**支持**（enablement）、可**确定**（definiteness），且审查历史一旦收缩就**不可回溯扩张**。移植到安全架构：**主张组合经纪（ClaimPortfolioBroker, CPB）** + **防御性主张台账（ClaimLedger, CL）**。每个可执行子任务携带主张剖面 C_v=(R_v,A_v,Σ_v,η_v)；执行前必须生成**正向主张图表**（逐条子句的有符号残差见证），只有 PROVED 才放行；UNPROVED 与 REFUTED 同为 fail-closed，但前者触发重观测、后者触发分案。台账用哈希链把“曾被驳斥的区域”钉死，在线只许收缩。对应 **P17 主张-边界律**、**P19 主张单调收缩律**。

**灵感 2（任务分解 → 把一条长证书切成可独立认证与替换的短主张）**
直觉：HTN/任务分解的价值不只是“分层规划”，而是把一条脆弱的长时程证书，变成许多**局部化、可替换、可独立举证**的短主张。核心创新：**主张化任务分解器（ClaimTaskDecomposer, CTD）**：T=(V,E,<,ρ,χ)，内部节点是 SEQ/AND/OR/FALLBACK，叶节点是 v9 的 AC 块；每条 SEQ 边配**缝合证书**（Post_u⟹Pre_v + 不变式保持 + 中止点交接）。主张被驳斥时，**分案细化器（DivisionalRefiner, DR）**按分离谓词把失败叶一分为二、缩 K、缩 β、提高感知频率，深度受限，最后回退 T_⊥。**在先技术检索（PriorArtReuse）**只给候选、不继承证书——历史成功不能冒充当前安全。对应 **P18 分解-缝合律**。

**两灵感交汇 = 主张-分解组合（Claim–Decomposition Portfolio, CDP）**
专利布局问“哪些边界清晰的主张能以多小的成本覆盖多大的状态空间”，任务分解答“整任务如何切成这些主张”，v9 的 AC/MW/ID 答“每片如何执行与退化”。三者合流：一个分解方案是一个“专利族”，其覆盖区域是族内主张的并集；经纪器只在**正向图表 PROVED 且 FTO PASS** 的方案中选择；高风险档要求**双覆盖**——两个失效签名独立的方案同时可证，单点驳斥最多损失一份覆盖，绝不损失安全。安全不进入优化目标：价格/成功率只能影响“选哪个已认证方案”，不能扩张可执行集。

**灵感映射表（专利概念 → 技术机制）**

| 专利布局概念 | 技术机制 |
|---|---|
| 权利要求边界 | 认证区域 R_v 与假设集 A_v |
| 支持 / enablement | 主张图表逐子句的带残差证据 |
| 确定性 / definiteness | R_v 由可计算前向包络或静态谓词定义，禁止“没报警” |
| 分案 / 连续案 | DR 按分离谓词细化；叶再分解 |
| 在先技术 | 情节记忆检索，仅产生候选，不继承证书 |
| 自由实施（FTO） | 硬约束过滤器，违规方案不得进入选择集 |
| 审查历史禁反言 | 在线单调收缩 + 台账反洗白 |
| 组合布局 / 防御深度 | 双覆盖 + 独立失效签名 |

## 1. 研究问题（轮次升级版）

- **Q1（正向举证的非循环性）**：如何用**局部、因果、可观测**的见证（一步预测残差、保形区间、几何包络、静态条件）定义 R_v 与 A_v，使“PROVED”既不依赖 20 帧分布滑窗，也不把同一个前向模型既当被证对象又当证人？正向举证相对 v9 阴性检测的假阴性代价有多大？
- **Q2（分解组合的可靠性）**：在什么缝合条件下，逐叶主张的可靠性可以提升为整棵分解树的安全不变式？SEQ/AND/OR/FALLBACK 四类组合、并行效果交换、缝误差累积与中止点交接分别需要什么额外证书？
- **Q3（组合覆盖与细化终止）**：在算力预算与双覆盖要求下，如何维持非空的组合覆盖？单调收缩 + 深度受限分案能否同时避免“无限分案”与“回退风暴”，并保证高风险档的独立性不是同源冗余？

## 2. 设计原则（在 P13–P16 基础上新增 P17–P20）

**P17 主张-边界律（Claim-Boundary / Positive Admission）**
任何执行必须先有一张 PROVED 的主张图表：逐子句见证 R_v、A_v、Σ_v 且最小裕度 η_v≥0。UNPROVED 与 REFUTED 都不放行；禁止用“未检测到异常”替代“已证明满足”。主张必须可确定：R_v 的每个子句要么是可计算的保守包络，要么是离线验证的静态谓词。

**P18 分解-缝合律（Assume-Guarantee Composition）**
叶主张只在自身区域内有效；跨叶安全由缝合证书承担：SEQ 边须证 Post_u⟹Pre_v、不变式保持、中止点交接；AND 边须证效果交换与资源不交；OR/FALLBACK 须证各分支后置条件的并集覆盖父后置条件。没有缝合证据的分解不得执行，禁止“逐叶都安全所以整体安全”的口头跃迁。

**P19 主张单调收缩律（Claims Only Narrow）**
在线细化只能取 R 的子集，任何扩张必须走离线再认证；台账记录每次驳斥区域，在线主张若为历史驳斥区域的严格超集则直接拒绝。由此在线可执行集在驳斥点单调不增，避免“乐观重试”造成安全漂移与事后洗白。

**P20 组合防御律（Portfolio Defense / Double Coverage）**
高风险子任务须有两个失效签名独立的 PROVED 方案；独立性的判据是“不共享同一传感器、同一前向模型、同一关键缝谓词”。单点失效最多移除一份覆盖，broker 立即切换到另一份或 T_⊥。安全只依赖 fail-closed 准入，不依赖冗余恰好成功。

## 3. 与基线的接口（如何退化）

- CPB 失效 ⇒ 只用 CTD 产出的单一分解，逐叶仍走 v9 AC，等价 v9；
- CTD 失效 ⇒ 直接调用 v9 AC 生成单块，跳过分解层，等价 v9；
- DR 失效 ⇒ 不细化，主张被驳斥即回退 T_⊥，等价 v9 的 K=1；
- CL 失效 ⇒ 进入“可运行但不记账”模式，本地闭环不受影响，等价 v9；
- FTO 失效（保守默认）⇒ 只接受 T_⊥ 与最高安全档，禁止任何未经硬约束检查的方案，等价 v9 的保守模式；
- v10 全部失效 ⇒ 完整走 v9 五级链（AC→MW→ID→DA/SPR/Cal→v8→v7→v6）；
- 任务/资费/成功率诉求与 FTO 冲突 ⇒ **拒绝方案**，绝不修改 R_v、A_v 或 M₀ 阈值来“放行”。

## 4. 预期贡献

1. **正向主张图表**：把块证书的准入从“阴性检测”翻转为“逐子句正向举证”，并用局部创新残差与保形区间切断对 Δ_dom 滑窗的依赖；
2. **主张化任务分解**：CTDT + 四类组合 + 缝合证书，使长时程安全论证局部化、可组合、可替换；
3. **主张-分解组合**：分案细化、在先技术复用、FTO 过滤、双覆盖与防洗白台账，构成一个可审计的“安全专利族”；
4. **可验证的退化代数**：v10 的每一层失效都精确落到 v9 的某个退化格点，新增组件不改变既有九不变式。

## 5. 本轮最大风险

**一句话**：正向举证仍以“主张谓词与见证本身可信”为前提——若 R_v/A_v 仍复用同一套 20 帧滞后检测或同一个前向模型来自证，举证只是把盲点从“检测”搬到“举证”；而若为切断这种循环把谓词收得过紧，系统会在真实分布边缘频繁落入 T_⊥，形成“安全但完不成任务”的回退风暴。

**新增定义 540（主张化任务分解树 CTDT）** T=(V,E,<,ρ,χ)。每个节点 v 携带 (Pre_v,Post_v,Inv_v)；ρ(v)∈{SEQ,AND,OR,FALLBACK}；叶节点 ℓ∈Leaves(T) 附主张 C_ℓ（定义 541），其执行体是 v9 AC 块；χ 标注时间窗、截止期与算力预算。T 对初始状态 s₀ 可行，当且仅当存在一条根到叶的执行链使前置条件闭合：
```
Pre_root(s₀) ∧ ⋀_{(u,v)∈SEQ} (Post_u ⟹ Pre_v) ∧ ⋀_{v∈AND} (effects commute ∧ resources disjoint)
```
OR/FALLBACK 只要求实际选中分支满足前/后置条件；内部节点不直接执行，只承担“分解义务”。叶主张只在 R_ℓ 内有效，跨叶安全由定义 543 的缝合证书承担。

**新增定义 541（主张剖面 ClaimProfile）** C_v=(R_v,A_v,Σ_v,η_v)：
- R_v⊆S 为认证区域，必须是**可确定**的状态谓词：由前向可达包络（区间/椭球/支撑函数）、几何间隙、静态环境条件与任务前置条件的交定义；禁止用“最近 20 帧 Δ_dom 未越阈”单独定义；
- A_v=(α_1,…,α_q) 为假设集：传感器自检通过、鲁棒扰动界 β_robust 成立、负载/关节/人机模式、时间同步与时钟新鲜度；
- Σ_v 为 v9 证书包（块证书 Ĉ_v、中止点集 P_v、执行时限 D_v、K_eff 门控参数）；
- η_v=min_j slack_j 为所有子句与证书不等式的**有符号最小裕度**（左减右）。
C_v 在 s 有效 ⇔ s∈R_v ∧ A_v 全部成立 ∧ η_v≥0。
**非循环性设计**：安全不等式使用离线验证的鲁棒界 β_robust（平台动力学、传感误差、未建模扰动的保守包络）作**证明**依据；学习前向模型的局部一步创新残差只作**反驳**见证，永不作为证明见证。学习模型可以提出计划、评估期望收益，但不能给自己签发安全证书。

**新增定义 542（主张图表 ClaimChart）** 对 C_v 在 s 的图表是见证元组 w=(w_sensor,w_robust,w_geom,w_cert,w_innov,w_time)，逐条把子句映射到带符号残差与时间戳的证据：
- `w_sensor`：正自检证据（诊断脉冲、量程校验、时间戳新鲜），不是“没报错”；
- `w_robust`：沿候选轨迹用 β_robust 做区间/椭球传播得到的证明见证；
- `w_geom`：保守几何包络与停车不变式（v9 定义 534）的证明见证；
- `w_cert`：v9 块证书与中止点集的签名字段；
- `w_innov`：最近 W 步一步预测残差；只作**反驳**见证；
- `w_time`：证据时间戳与新鲜窗口 T_fresh。
判定：
```
PROVED   ⇔ 全部证明子句残差 ≥0 ∧ 证据新鲜 ∧ 无反驳见证
REFUTED  ⇔ 任一子句残差 <0 ∨ 任一反驳见证越阈
UNPROVED ⇔ 证据缺失/过期/不可判定
```
执行准入：仅 PROVED 可执行；UNPROVED 与 REFUTED 同为 fail-closed。区别仅在下游处置：UNPROVED 触发重观测/换传感器/回退，REFUTED 触发分案细化（定义 545）。

**新增定义 543（缝合证书 SeamCertificate）** 对 SEQ 边 (u,v)：
```
seam(u,v) = ⟨Post_u ⟹ Pre_v⟩ ∧ ⟨Inv_u ∧ Inv_v 保持⟩ ∧ ⟨中止点交接⟩ ∧ ⟨缝误差界 ε_seam⟩
```
其中“中止点交接”要求 u 的中止点集在 v 的入口仍满足 v9 停车不变式（定义 534）；缝误差界 ε_seam 由两叶证书的模型/几何误差上界与时间戳偏移合成。可行性在可达集过近似上检查（区间/支撑函数），不要求逐点枚举。AND 并行边额外要求效果交换（effects commute）与资源不交（关节/力/感知带宽）；OR/FALLBACK 边要求各分支后置条件的并集覆盖父后置条件，且分支入口共享同一 Pre。未证缝合的分解不得执行。

**新增定义 544（主张组合 ClaimPortfolio）** P={p_i=(T_i,κ_i,R_i^P,π_i,σ_i)}，κ_i 为期望算力，R_i^P 为 T_i 可被图表证明的状态集，π_i 为先验成功率，σ_i 为失效签名：
```
σ(T) = (传感器模态集, 前向模型 id, 关键缝谓词族, 规划器 id, 证书标定版本)
```
两个方案“独立” ⇔ 关键失效签名交集为空（至少不共享同一传感器、同一模型、同一关键缝谓词）。选择规则：
```
T* = argmax_{p_i∈P}  η(T_i,s)·π_i
s.t.  chart(C_root(T_i),s)=PROVED
      ∧ FTO(T_i,s)=PASS
      ∧ κ_i ≤ B_avail
      ∧ (risk_tier=high ⇒ ∃j≠i: chart(C_root(T_j),s)=PROVED ∧ σ(T_i)∩σ(T_j)=∅)
```
选择集为空 ⇒ T_⊥。**关键**：安全是约束，不是优化项；π_i 只影响已认证方案之间的排序，不能把 BLOCK/UNPROVED 方案抬进可执行集。

**新增定义 545（分案细化 DivisionalRefinement）** 给定被驳斥的 C_v 与反驳见证 w，选分离谓词 b（障碍在左/右、物体类别、速度区间、抓取姿态族、人机距离档），生成：
```
C_{v,1}=C_v|b,  C_{v,2}=C_v|¬b
```
并把失败叶再分解为更短 K、更小 β、更高感知频率的子叶。约束：
(i) R_{v,1}∪R_{v,2}⊆R_v（只收缩，绝不超出父区域）；
(ii) 分离裕度 margin(b,w)≥ε_split（区域测度严格下降）；
(iii) 深度 ≤d_max；
(iv) 每片必须重新生成 PROVED 图表，旧证据不继承；
(v) 无可分离子句/超深/预算不足 ⇒ T_⊥。分案不是“再规划整个任务”，而是把失败主张切成两个更窄、更容易取证的主张。

**新增定义 546（在先技术复用 PriorArtReuse）** 情节记忆 M_ep 存 (任务嵌入 e, 分解 T, 结果, 环境签名)。给定新任务嵌入 e_t，检索 top-k 相似；复用条件：R_root 覆盖当前 s 且缝证书在环境签名下仍成立。复用只产生**候选**分解（含叶的顺序与模板参数），不继承任何按旧证据的证书与 η；每个叶仍须现场 chart。收益是降低 CTD 搜索算力，不是降低证明义务。检索相似但危险的任务（同嵌入、异动态）必须被 chart 拦截，而不是被“历史成功率”放行。

**新增定义 547（自由实施检查 FTO）** 对分解 T 与状态 s：
```
FTO(T,s)=PASS ⇔ ∀h∈H, ∀可选中止路径 π: worst_case(T,π,s) ⊨ h
```
H 为硬约束集（M₀ 间隙、SpatialCert、FaultCert、关节/力矩、人机距离、速度上限）。FTO 是与成功率/价格/时延无关的**过滤器**；BLOCK 的方案不得进入选择集，即使 π_i 最高。FTO 失效时的保守默认是只接受 T_⊥ 与最高安全档。

**新增定义 548（防御性主张台账 ClaimLedger）** L 为按块边界（5Hz）追加的哈希链：
```
entry_t = (claim_id, H(R_v), H(chart witnesses), H(Σ_v), H(prev), t, sign)
```
用途：(i) 审计可复现；(ii) 防篡改（哈希链 + 签名）；(iii) **反主张洗白**：在线任一主张若其 R 是历史已 REFUTED 区域的严格超集，直接拒绝；扩张只能走离线再认证；(iv) 支撑跨机共享时的“审查历史”。台账故障 ⇒ “可运行但不记账”模式，不阻塞本地闭环，等价 v9；恢复后以最后一个可信锚点续链，缺口标为 UNPROVED 而非伪造。

δ_trigger = {σ<τ_safe ∧ γ_grasp valid ∧ Δ_dom<τ_dom ∧ risk_SLAM<τ_SLAM

# IP-357 ClaimTaskDecomposer：主张化任务分解
class ClaimTaskDecomposer:
    def __init__(self, templates, memory, ac, max_depth=4):
        self.templates, self.memory, self.ac = templates, memory, ac
        self.max_depth = max_depth

    def decompose(self, task, s):
        # 1) 在先技术检索：只给候选，不继承证书
        for T in self.memory.retrieve(task.embedding, k=8):
            if covers(T.root.region, s) and self._seams_statically_hold(T, s):
                return self._revalidate(T, s)          # 叶仍须现场 chart
        # 2) 模板展开 + 逐叶生成 v9 AC 块与主张
        T = self._expand(task, s)
        for leaf in T.leaves():
            leaf.claim = self.ac.claim_profile(leaf, s)  # 定义 541
        return T

    def _expand(self, task, s, depth=0):
        if depth >= self.max_depth or self.templates.is_primitive(task):
            return DNode.leaf(task, self.ac)
        m = self.templates.select(task, s)
        kids = [self._expand(sub, s, depth + 1) for sub in m.split(task)]
        return DNode.seq(m.pre, m.post, m.inv, kids)

    def _revalidate(self, T, s):
        T = clone(T)                               # 不修改记忆中的旧树
        for leaf in T.leaves():
            leaf.claim = self.ac.claim_profile(leaf, s)
        return T


# IP-358 ClaimPortfolioBroker：正向举证 + FTO + 双覆盖
class ClaimPortfolioBroker:
    def __init__(self, fto, ledger, ac, risk_tier='high'):
        self.fto, self.ledger, self.ac = fto, ledger, ac
        self.risk_tier = risk_tier

    def chart(self, claim, s):
        """定义 542：只返回 PROVED / UNPROVED / REFUTED"""
        w = self.ac.collect_witnesses(claim, s)
        if w.sensor_ok and w.robust_ok and w.geom_ok and w.cert_ok \
           and w.residuals_nonnegative and w.fresh:
            if w.innov_over_threshold:               # 学习模型只能反驳
                return 'REFUTED', w
            return 'PROVED', w
        if w.any_refutation:
            return 'REFUTED', w
        return 'UNPROVED', w

    def select(self, portfolio, s, budget):
        valid = []
        for p in portfolio:
            verdict, _ = self.chart(p.T.root, s)
            if verdict != 'PROVED':
                continue
            if self.fto.check(p.T, s) != 'PASS':
                continue
            if p.cost > budget:
                continue
            if self.ledger.is_laundering(p.T, s):     # 反洗白
                continue
            valid.append((p, self._margin(p.T, s)))
        if not valid:
            return self._fallback(s)                  # T_perp
        valid.sort(key=lambda x: -x[1])
        best = valid[0][0]
        if self.risk_tier == 'high':
            indep = [p for p, _ in valid[1:]
                     if self._independent(best, p)]
            if not indep:
                return self._fallback(s)              # 无独立备份 ⇒ 底方案
        self.ledger.append(best.T, s, best.chart_witness)
        return best

    def _independent(self, a, b):
        return len(a.sig & b.sig) == 0                # 定义 544 的失效签名

    def _fallback(self, s):
        return T_perp(self.ac, s)                     # v9 K=1 全模块逐步


# IP-359 DivisionalRefiner：按分离谓词分案
class DivisionalRefiner:
    def __init__(self, d_max=3, eps_split=0.05):
        self.d_max, self.eps_split = d_max, eps_split

    def refine(self, claim, witness, depth):
        if depth >= self.d_max:
            return None
        b = self._select_separator(claim, witness)    # margin(b) >= eps_split
        if b is None:
            return None
        left  = self._narrow(claim, b,     shorter_K=True, smaller_beta=True)
        right = self._narrow(claim, not b, shorter_K=True, smaller_beta=True)
        left.leaves, right.leaves = self._recertify(left, right)
        return [left, right]

    def _select_separator(self, claim, witness):
        for b in claim.candidate_separators(witness):
            if margin(b, witness) >= self.eps_split:
                return b
        return None

## 4. 推导

**引理 87（正向准入的无过担 / No-Overclaim）**
设图表见证满足可靠性假设：证明子句残差 ≥0 且证据新鲜 ⟹ 该子句在执行区间内成立；鲁棒界 β_robust 是真实扰动上界；反驳见证只可能扩大拒绝集，不会放宽证明。若叶 ℓ 被执行，则 chart(C_ℓ,s)=PROVED，故 s∈R_ℓ、A_ℓ 成立、η_ℓ≥0；由 v9 引理 82，ℓ 的块证书在中止点集上有效，M₀/SpatialCert 保持。
证明：执行闸门只接受 PROVED；由定义 541/542 逐子句代入，再引用 v9 引理 82。关键点：v9 的“Δ_dom 20 帧滑窗滞后”不进入准入判定；Δ_dom 可以影响计划选择，但 R_v/A_v 的证明由保守包络与正自检承担，局部创新残差只作反驳。故 v9 的“在最需要安全时证书最不可靠”不会被直接继承。∎
（条件性：若平台存在未建模扰动使 β_robust 失效，则结论失效；实验 E572/E554 专门测此边界。）

**引理 88（分解组合可靠性 / Assume-Guarantee Lifting）**
若 T 的每个执行叶都有 PROVED 主张，且每条实际穿越的 SEQ/AND 缝都有 PROVED 缝合证书，则根节点的 Post/Inv 在任务结束时成立；整体证书裕度满足
```
η(T) ≥ min_{ℓ∈executed} η_ℓ − Σ_{seams} ε_seam
```
证明：对分解树做结构归纳。叶执行后 Post_ℓ∧Inv_ℓ；SEQ 缝给出 Post_u⟹Pre_v 且不变式保持，故链条传递；AND 需效果交换与资源不交，故并行结果与串行化等价；OR/FALLBACK 只取实际分支，父后置条件由分支并集覆盖。误差界由各叶 η_ℓ 与缝 ε_seam 的最坏情形相加得到；若 η(T)<0 则图表会 REFUTED，不会执行。∎

**引理 89（组合防御 / 单点失效不越界）**
在高风险档，broker 只执行满足“存在两个失效签名独立的 PROVED 方案”的选择集；若其中一份主张被驳斥，最多移除一份覆盖，broker 切换到另一份 PROVED 方案或 T_⊥，且任意时刻执行前都有 PROVED 图表。故不存在“无证明执行”；安全性不依赖冗余成功，只依赖 fail-closed 准入。
证明：由定义 544 的选择约束与定义 542 的准入规则直接得到；独立性保证同一单点故障（同一传感器/同一模型/同一关键缝）不会同时驳斥两份方案，但即使同时驳斥，T_⊥ 仍要求 K=1 + M₀ 守卫，安全不变式不破。∎

**引理 90（单调收缩与反洗白 / No Safety Drift）**
在线细化只取子集（定义 545(i)）；台账拒绝历史驳斥区域的严格超集（定义 548(iii)）。对任意 (s,a)，一旦其所在区域被 REFUTED 并记账，之后任何在线主张若包含它必被拒绝；故在线可执行集在驳斥点单调不增，除非离线再认证。
证明：对驳斥序列做归纳。基例：首次驳斥记账后，所有在线主张的 R 若不包含该点则不受影响；若包含，则与历史驳斥区域构成超集关系，被 is_laundering 拒绝。归纳步同理。∎
（注：该引理保护的是“不把已证伪的状态悄悄放回”，不是“覆盖不减”；覆盖会因细化而收缩，这是有意为之。）

**引理 91（分案终止 / No Decomposition Zeno）**
每次成功细化要求分离裕度 ≥ε_split，故区域测度至少减少 δ(ε_split)>0；深度 ≤d_max；状态空间测度有限。因此一条路径上的细化次数 ≤min(d_max, ⌊μ(R₀)/δ⌋)；无可用分离谓词、超深或预算不足即 T_⊥，而 T_⊥ 不再触发细化（K=1 由 v9 中块守卫接管）。故无无限分案与分解 Zeno。
证明：由定义 545(ii)(iii)(v) 与测度的单调性直接得到。∎

**引理 92（算力守恒与长程摊销）**
每个叶是一个 v9 AC 块，叶内仍保持 v9 的 5Hz/50Hz 分离；CTD 的模板展开与先验检索只发生在任务/叶边界；CPB 每叶一次图表 O(|A|)，DR 仅在驳斥时触发；选择约束 κ_i≤B_avail，先验复用只减搜索、不减证明。故每周期算力 ≤ v9 上界 + O(|A|+log|P|)，50Hz 保持；台账 O(1)/块边界，哈希链写入可异步。∎

**推论 93（FTO 与安全不可交易）**
若 FTO(T,s)=BLOCK，则 T 不进入选择集；由引理 89，任何执行都有 PROVED 图表与 FTO PASS。故成功率、价格、时延的任意排序都不能扩张可执行动作集；安全动作集 A_safe(s) 与这些经济/任务变量无关。∎

## 8. 本轮最大风险

**一句话**：正向举证仍以“主张谓词与见证本身可信”为前提——若 R_v/A_v 仍复用同一套 20 帧滞后检测或同一个前向模型来自证，举证只是把盲点从“检测”搬到“举证”；而若为切断这种循环把谓词收得过紧，系统会在真实分布边缘频繁落入 T_⊥，形成“安全但完不成任务”的回退风暴。
