### 第 2 轮灵感驱动研究记录

**灵感词**：多机协同、多端口部署

**直觉与动机**：
上一轮把证书从「布尔有效」扩展为「时空有效域」（STCK），并补上了抓取动力学（GCK）与证据挖掘（DAKI）。但上一轮的所有证书都隐含一个**单机、单宿主、单传输**的假设：证书在生成处有效，就默认在消费处也有效。当系统进入多机协同与多端口部署后，这个假设会同时从两个方向破裂：

1. **多端口部署（传输拓扑维）**：同一张证书可能经共享内存、DDS/UDP、DDS/TCP、5G、WiFi 等不同端口抵达消费端。每条端口的带宽、单向 P99 时延、抖动、丢包与安全等级都不同。证书在源头「还剩 50ms 有效期」，但若它要穿过一条 P99 单向时延 30ms、抖动 10ms 的 5G 链路，到达时可能已经过期。也就是说，**证书的有效期必须被传输路径消耗**，而不能只由生成时刻决定。现有 TCVM 只检查「证书年龄 < 窗口」，却不知道这段年龄里有多少是「在路上合法花掉的」，于是把「新鲜」误判成「有效」。

2. **多机协同（信任拓扑维）**：证书在机器人 A 上由 A 的传感器与控制器担保，但 B 消费它时，B 真正信任的是「A 的证书」，而不是「A 的证书经 C、D 转发后的副本」。每经过一跳，证据强度应当衰减（trust attenuation）；并且多机联合能力（如两人协同搬运、编队通过窄门）不是单机证书的简单并集，而是「空间域交集非空 + 时窗重叠 + 两两一致性 + 联盟信任 + 拜占庭法定人数」的联合谓词。现有 MRCC 只做两两位姿一致性检查，既没有信任衰减，也没有联盟能力的形式化，更没有对恶意节点的法定人数约束。

**关键洞见**：本轮的核心直觉是把证书有效性从 (空间, 时间) 二元组升级为 **(空间, 时间, 端口路径, 信任路径)** 四元组；并引入「新鲜度契约」与「信任衰减」，使证书在跨端口、跨机传播时不会出现「源头有效、消费端失效」。多端口部署把「时间有效性」变成「路径可承受的有效性」，多机协同把「单机担保」变成「可衰减的联盟担保」。两者结合，CADVS 的证书链第一次具备**拓扑感知**：证书不仅要问「何处何时有效」，还要问「经由哪条端口、由谁担保、还剩多少信任」。

**形式化目标（增量）**：
1. 端口可达证书 PRC：`PRC_π = (π, transport, B_π, D_π^p99, J_π, L_π, Sec_π, [t_π^0, t_π^1])`；定义端口图 `G_Π` 与路径最坏时延 `D_max(Π_path) = Σ D_π^p99 + (h−1)·J_max`。
2. 新鲜度契约：证书在转发时刻 `t_fwd` 的剩余有效期必须满足 `Δt_cec − (t_fwd − t_gen) ≥ D_max(Π_path) + ε_sync`；否则拒绝进入该端口路径（fail-closed）。
3. 信任衰减：`θ(Π_path) = θ_0 · Π_{π∈Π_path} γ_π · γ_hop^(h−1)`，`γ_π ∈ (0,1]`；消费端要求 `θ ≥ θ_min`，且证书来源可追溯到原始签发者。
4. 联盟能力证书 CCC：`CCC = (C, D_C = ∩ D_i, T_C = ∩ T_i, G_consensus, θ_C, scope)`；联盟可行当且仅当 `D_C ⊇ W_τ ∧ T_C ⊇ H_τ ∧ G_consensus 连通 ∧ 两两误差 < γ_consist ∧ θ_C ≥ θ_min ∧ |C| ≥ 3f+1`。
5. 定义 CADVS-v2 执行集：`Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29`，并给出多机多端口条件下的能力增量与诚实边界。

**本轮最大风险**：**端口时延模型失真与多机信任衰减被绕过会叠加成「源头有效、消费端失效」的伪证书（certified-but-stale）——它在单机视角下完全无异常，却会在跨机协同的关键时刻同时击穿时效与信任两条防线。**

## 2. 关键算法骨架

### IP-481 Port Reachability Certificate (PRC)

```python
@dataclass
class PortReachabilityCertificate:
    """PRC：单端口/传输通道的能力与可达性证书"""
    port_id: str                      # 'shm' | 'dds_udp' | 'dds_tcp' | 'eth' | 'wifi' | '5g'
    transport: str                    # 'intra_process' | 'shared_mem' | 'udp' | 'tcp'
    bandwidth_mbps: float
    d_p99: float                      # 单向 P99 时延（s）
    jitter: float                     # 抖动上界（s）
    loss: float                       # 丢包率
    security_level: int               # 0=明文, 1=DTLS, 2=DDS-Security
    t_valid: tuple = (0.0, float('inf'))

    def reachable(self, t_now: float) -> bool:
        return self.t_valid[0] <= t_now <= self.t_valid[1]

    def usable(self, t_now: float, min_sec: int = 1) -> bool:
        """端口可用 = 能力未过期 ∧ 安全等级达标 ∧ 非全丢包"""
        return (self.reachable(t_now)
                and self.security_level >= min_sec
                and self.loss < 1.0)

    def cert_payload(self) -> dict:
        return {
            'cert_id': f'prc_{self.port_id}',
            'payload': {
                'transport': self.transport,
                'bandwidth_mbps': self.bandwidth_mbps,
                'd_p99': self.d_p99,
                'jitter': self.jitter,
                'loss': self.loss,
                'security_level': self.security_level,
            },
            't_stamp': time.time(),
            'validity_window': 1.0,
            'src_node': 'port_monitor',
        }
```

### IP-482 Multi-Port Certificate Transport Fabric (MPCTF)

```python
@dataclass
class MultiPortCertificateTransportFabric:
    """MPCTF：多端口证书传输织构 + 新鲜度契约 + fail-closed 路由"""
    prc_table: dict[str, PortReachabilityCertificate] = field(default_factory=dict)
    port_graph: dict[str, list[tuple[str, str]]] = field(default_factory=dict)  # node -> [(nbr, port_id)]
    epsilon_sync: float = 0.001       # 跨机时钟偏差上界（s）
    max_hops: int = 4

    def _prc(self, port_id: str, t_now: float) -> PortReachabilityCertificate | None:
        prc = self.prc_table.get(port_id)
        return prc if prc is not None and prc.usable(t_now) else None

    def worst_case_delay(self, path: list[str], t_now: float) -> float:
        """D_max(Π_path) = Σ d_p99 + (h-1)·J_max；任一端口不可用则返回 +inf"""
        if not path:
            return 0.0
        total, jitter_max = 0.0, 0.0
        for port_id in path:
            prc = self._prc(port_id, t_now)
            if prc is None:
                return float('inf')
            total += prc.d_p99
            jitter_max = max(jitter_max, prc.jitter)
        return total + (len(path) - 1) * jitter_max

    def admit(self, cert, path: list[str], t_fwd: float) -> bool:
        """新鲜度契约：剩余有效期 ≥ 路径最坏时延 + 时钟偏差"""
        remaining = cert.Delta_t_cec - (t_fwd - cert.t_gen)
        return remaining >= self.worst_case_delay(path, t_fwd) + self.epsilon_sync

    def route(self, cert, src: str, dst: str, t_fwd: float) -> list[str] | None:
        """枚举 ≤ max_hops 的简单路径，选满足契约且时延最小者；无则 fail-closed"""
        best, best_delay = None, float('inf')
        for path in self._enumerate_paths(src, dst, self.max_hops):
            if self.admit(cert, path, t_fwd):
                d = self.worst_case_delay(path, t_fwd)
                if d < best_delay:
                    best, best_delay = path, d
        return best  # None → 消费端拒绝使用该证书

    def forward(self, cert, path: list[str], t_now: float) -> dict:
        """转发前再校验一次，防止路由后端口被降级（TOCTOU 防护）"""
        if not self.admit(cert, path, t_now):
            raise FreshnessContractViolation(cert.cert_id, path)
        return {'cert': cert, 'port_path': path, 't_fwd': t_now,
                'D_max': self.worst_case_delay(path, t_now)}
```

### IP-483 Federated Certificate Consensus (FCC)

```python
@dataclass
class FederatedCertificateConsensus:
    """FCC：跨机证书联邦 + 信任衰减 + Byzantine 法定人数"""
    theta_min: float = 0.6
    gamma_port: dict[str, float] = field(default_factory=lambda: {
        'shm': 1.0, 'dds_tcp': 0.98, 'dds_udp': 0.95,
        'eth': 0.97, 'wifi': 0.90, '5g': 0.85,
    })
    gamma_hop: float = 0.95           # 每多一跳的额外衰减
    peer_timeout: float = 1.0
    byzantine_f: int = 1

    def trust(self, theta0: float, path: list[str]) -> float:
        """θ(Π_path) = θ0 · Π γ_π · γ_hop^(h-1)"""
        theta = theta0
        for port_id in path:
            theta *= self.gamma_port.get(port_id, 0.8)
        if len(path) > 1:
            theta *= self.gamma_hop ** (len(path) - 1)
        return theta

    def quorum_ok(self, n: int) -> bool:
        """n ≥ 3f+1 才能容忍 f 个拜占庭节点"""
        return n >= 3 * self.byzantine_f + 1

    def federated_accept(self, cert, path: list[str], n_peers: int,
                         t_now: float) -> tuple[bool, str]:
        if t_now - cert.t_gen > cert.Delta_t_cec:
            return False, 'expired'
        theta = self.trust(cert.theta0, path)
        if theta < self.theta_min:
            return False, f'trust {theta:.3f} < {self.theta_min}'
        if not self.quorum_ok(n_peers + 1):
            return False, f'quorum {n_peers + 1} < {3*self.byzantine_f+1}'
        return True, 'ok'

    def consensus_check(self, local, peers: dict) -> tuple[bool, list[str]]:
        """两两一致性：‖p_i − p_j − Δ_rel‖ < γ_consist"""
        violations = []
        for pid, peer in peers.items():
            err = np.linalg.norm(local.pose_est - peer.pose_est - local.rel_pose(pid))
            if err > local.gamma_consist:
                violations.append(f'{pid}: {err:.3f}')
        return len(violations) == 0, violations
```

### IP-484 Coalition Capability Certificate (CCC)

```python
@dataclass
class CoalitionCapabilityCertificate:
    """CCC：多机联盟能力证书（空间/时间交集 + 共识连通 + 联合信任）"""
    members: list[str]
    spatial_domains: dict[str, set]      # rid -> 覆盖区域（球/凸包采样点集）
    temporal_windows: dict[str, tuple]   # rid -> [t0, t1]
    consensus_graph: dict[str, list[str]]
    theta0: float = 0.9
    byzantine_f: int = 1
    theta_min: float = 0.6

    def joint_domain(self) -> set:
        it = iter(self.spatial_domains.values())
        return set.intersection(*map(set, it)) if self.spatial_domains else set()

    def joint_window(self) -> tuple:
        t0 = max(w[0] for w in self.temporal_windows.values())
        t1 = min(w[1] for w in self.temporal_windows.values())
        return (t0, t1)

    def consensus_connected(self) -> bool:
        seen, stack = set(), [self.members[0]]
        while stack:
            u = stack.pop()
            if u in seen:
                continue
            seen.add(u)
            stack.extend(self.consensus_graph.get(u, []))
        return seen.issuperset(self.members)

    def feasible(self, task) -> tuple[bool, str]:
        D_C, T_C = self.joint_domain(), self.joint_window()
        if not D_C.issuperset(task.required_workspace):
            return False, 'spatial intersection insufficient'
        if T_C[0] > T_C[1] or T_C[0] > task.t_start or T_C[1] < task.t_end:
            return False, 'temporal intersection insufficient'
        if not self.consensus_connected():
            return False, 'consensus graph disconnected'
        if len(self.members) < 3 * self.byzantine_f + 1:
            return False, 'quorum insufficient'
        theta_C = self.theta0 if self.consensus_connected() else 0.0
        if theta_C < self.theta_min:
            return False, 'coalition trust insufficient'
        return True, 'feasible'
```

### IP-485 Certificate Provenance & Revocation Ledger (CPRL)

```python
@dataclass
class CertificateProvenanceLedger:
    """CPRL：证书溯源 DAG + 撤销沿依赖传播"""
    nodes: dict[str, dict] = field(default_factory=dict)    # cid -> {issuer, parents, port_path, t}
    revoked: dict[str, float] = field(default_factory=dict) # cid -> revoke_time

    def append(self, cid: str, issuer: str, parents: list[str],
               port_path: list[str], t: float):
        self.nodes[cid] = {'issuer': issuer, 'parents': parents,
                           'port_path': port_path, 't': t}

    def revoke(self, cid: str, t: float):
        self.revoked[cid] = t

    def _ancestors(self, cid: str) -> set[str]:
        out, stack = set(), [cid]
        while stack:
            u = stack.pop()
            for p in self.nodes.get(u, {}).get('parents', []):
                if p not in out:
                    out.add(p)
                    stack.append(p)
        return out

    def _descendants(self, cid: str) -> set[str]:
        out, stack = set(), [cid]
        while stack:
            u = stack.pop()
            for v, meta in self.nodes.items():
                if u in meta['parents'] and v not in out:
                    out.add(v)
                    stack.append(v)
        return out

    def tainted(self, cid: str) -> bool:
        """被撤销，或任一祖先被撤销 → 不可信"""
        return cid in self.revoked or bool(self._ancestors(cid) & set(self.revoked))

    def propagate_revocation(self, cid: str, t: float, ttl: int = 4) -> set[str]:
        """撤销沿 DAG 向下传播，TTL 限制传播深度"""
        revoked_now, frontier = {cid}, {cid}
        for _ in range(ttl):
            nxt = set()
            for u in frontier:
                for v in self._descendants(u):
                    if v not in revoked_now:
                        revoked_now.add(v)
                        nxt.add(v)
            frontier = nxt
            if not frontier:
                break
        for c in revoked_now:
            self.revoked.setdefault(c, t)
        return revoked_now
```

## 4. 正确性论证（增量更新）

### 引理 35（端口感知新鲜度契约）

**陈述**：设证书在 `t_gen` 生成，时域长度 `Δt_cec`；在 `t_fwd` 进入端口路径 `Π_path`，满足新鲜度契约 `r(t_fwd) = Δt_cec − (t_fwd − t_gen) ≥ D_max(Π_path) + ε_sync`。若实际单向传输时延 `d ≤ D_max(Π_path)` 且两端时钟偏差不超过 `ε_sync`，则消费端观测到的证书年龄 `age ≤ Δt_cec`，即证书在消费端仍处于时域有效期内。

**证明**：消费时刻 `t_consume = t_fwd + d`。消费端按自身时钟计算的年龄上界为
`age = (t_consume − t_gen) + ε_sync = (t_fwd − t_gen) + d + ε_sync`
`≤ (t_fwd − t_gen) + D_max(Π_path) + ε_sync`
`≤ (t_fwd − t_gen) + r(t_fwd) = Δt_cec`。∎

**工程含义**：这正是对上一轮 TCVM 的补丁——TCVM 只看「年龄 < 窗口」，而引理 35 要求**在转发点就预扣路径时延**，把「路上合法花掉的时间」从有效期中扣除。未通过契约的证书在路由阶段即被拒绝（fail-closed），而不是等到消费端才发现过期。

### 引理 36（信任衰减的单调性）

**陈述**：设 `θ(Π_path) = θ_0·Π_{π∈Π_path} γ_π·γ_hop^(h−1)`，其中 `0 < γ_π ≤ 1`、`0 < γ_hop ≤ 1`。则对任意路径扩展 `Π_path' = Π_path · π'`，有 `θ(Π_path') ≤ θ(Π_path)`；且当 `θ(Π_path) < θ_min` 时，所有更长的扩展路径同样被拒绝。

**证明**：`θ(Π_path') = θ(Π_path)·γ_{π'}·γ_hop ≤ θ(Π_path)`（因 `γ_{π'} ≤ 1, γ_hop ≤ 1`）。单调不增，故下界一旦跌破 `θ_min` 不可恢复。∎

**工程含义**：信任衰减给「多跳转发」一个形式化的成本，避免 MRCC 时代「对端说什么都信」的虚假通过。它也解释了为何跨机协同应尽量少跳、优先高安全端口。

### 引理 37（联盟能力证书的可行性充分条件）

**陈述**：给定任务 `τ`（工作域 `W_τ`、时域 `H_τ = [t_start, t_end]`）与联盟 `C`。若 (i) `D_C = ∩ D_i ⊇ W_τ`；(ii) `T_C = ∩ T_i ⊇ H_τ`；(iii) 共识图 `G_consensus` 连通且所有边满足 `‖p_i − p_j − Δ_rel‖ < γ_consist`；(iv) `θ_C ≥ θ_min`；(v) `|C| ≥ 3f+1`；则联盟 `C` 可在认证安全意义下执行 `τ`。

**证明**：由 (i)，`∀w∈W_τ, ∀i∈C: w ∈ D_i`，即每个成员的空间证书覆盖任务全域；由 (ii)，`∀t∈H_τ, ∀i∈C: t ∈ T_i`，时域全覆盖；由 (iii)，所有成员共享同一参考系至容差 `γ_consist` 内，协同动作的位姿误差有界；由 (iv) 信任达标，由 (v) 法定人数可容忍 `f` 个拜占庭成员仍达成一致。四条合取即为联盟可行性谓词，故任务可执行。∎

**诚实声明**：`D_C` 可能为空（成员空间域互不相交）或过度保守，此时 `feasible` 返回 false，系统应退化为任务分解而非强行协同。

### 引理 38（溯源-撤销一致性）

**陈述**：设 `Prov_DAG` 记录证书依赖，`revoke(cid)` 后经 `propagate_revocation(cid, t, ttl)` 传播。若对所有依赖链 `cid → … → c'`，其跳数不超过 `ttl`，且消费端在使用前调用 `tainted(c')`，则任何直接或间接依赖被撤销证书的 `c'` 都不会被当作可信证书消费。

**证明**：`propagate_revocation` 沿 `E_dep` 向下逐层扩展，深度受 `ttl` 限制；在 `ttl` 覆盖依赖链长度时，所有后代被加入 `revoked`。`tainted(c')` 同时检查自身与祖先，故任一祖先被撤销即返回 true，消费端拒绝。∎

**工程含义**：撤销不是「发一条消息就完事」，而必须沿溯源 DAG 追责；`ttl` 需 ≥ 最长依赖链，否则会出现「祖先已撤销、后代仍可信」的漏洞。

### 定理（CADVS-v2 执行集保持收缩与多机多端口能力提升）

**陈述**：在 v1 假设 (A1)–(A5) 之外，追加：
(A6) 端口模型准确：对所有可用端口，实际单向时延 ≤ `D_π^p99 + J_π`，且时钟偏差 ≤ `ε_sync`；
(A7) 联盟共识成立：法定人数 `|C| ≥ 3f+1`，两两位姿误差 < `γ_consist`，联合信任 `θ_C ≥ θ_min`，且 `Prov_DAG` 无被撤销祖先。
则 `Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29`；且对满足 (A1)–(A7) 的多机任务段，消费过期证书的概率 `P_stale ≤ P_sla_viol`（端口 SLA 违约率），联盟任务成功概率 `P_succ ≥ 1 − δ_task`。

**证明**：
- **包含性**：v2 的每一步在 v1 的十二证 + STCK/GCK/DAKI 门控之上，额外要求 PRC 可用、新鲜度契约通过（引理 35）、FCC 信任与法定人数通过（引理 36）、CCC 联盟可行（引理 37）、CPRL 未污染（引理 38）。这些是**追加的合取门**，只会缩小执行集；所有回退路径仍复用 v1/v29。故 `Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29`。
- **新鲜度**：由引理 35，满足契约的证书在消费端 `age ≤ Δt_cec`；不满足契约的证书在路由期即被拒绝。仅当端口实际时延超出 `D_π^p99 + J_π`（即 A6 被违反）时才可能产生 `P_stale`，其上界为端口 SLA 违约率。
- **联盟能力**：由引理 37 与 (A7)，联盟可行时各成员证书覆盖任务域/时域且共识一致；引理 38 保证无撤销污染。故任务成功概率由单机 v1 的水平提升至 `1 − δ_task`（δ_task 来自未被建模的动力学/感知扰动）。

**诚实声明**：(A6) 与 (A7) 在工程中**并非恒真**。真实网络存在长尾时延（P99 之外的 1% 可能达数百 ms）、跨机时钟漂移、端口突发拥塞；真实联盟存在掉队、通信分区、恶意节点。CADVS-v2 不依赖静态假设，而是通过 MPCTF 的 fail-closed 路由、FCC 的法定人数与信任衰减、CPRL 的撤销传播、以及端口 SLA 监控来**运行时管理**这些风险。

## 5. 已知风险与缓解（增量更新）

| 风险编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| R19–R36 | v29/v1 全部既有风险 | — | 原样继承 | 不变 |
| R37 | **端口时延模型失真**（P99 之外的长尾/突发拥塞使实际时延 > D_max） | **极高** | 1) 新鲜度契约 fail-closed；2) PRC 周期重估 + 在线 P99.9 采样；3) 路径冗余与快速切换；4) 保守裕度 `κ_net > 1` 放大 D_max | 极端拥塞下仍可能瞬时违约，依赖回退 |
| R38 | **跨机时钟失同步**（ε_sync 低估导致时序判断错误） | 高 | 1) PTP 硬件时间戳 + HLC 混合逻辑时钟；2) 单调时钟测量年龄而非墙钟；3) 周期性 ε_sync 标定 | 长分区后时钟漂移，需重同步握手 |
| R39 | **信任衰减标定失当**（过严→联盟碎片化；过松→拜占庭渗透） | 高 | 1) 按端口实测误码/认证强度标定 γ_π；2) 安全等级硬门控；3) 离线红队校准 θ_min | 标定依赖历史数据，新端口需冷启动 |
| R40 | **联盟空间/时间交集为空或过度保守** | 中 | 1) 凸包/椭球而非球体建模；2) 任务分解为子联盟；3) 交集可视化与在线重规划 | 强异构编队下仍可能不可行 |
| R41 | **端口故障切换振荡 + 证书去重失效**（重复风暴） | 中 | 1) 迟滞阈值 + 最小驻留时间；2) cid 哈希去重 + 端口优先级；3) 指数退避 | 多端口同时抖动时仍可能放大流量 |
| R42 | **撤销传播滞后**（TTL 不足或分区导致后代漏撤） | 高 | 1) TTL ≥ 最长依赖链；2) 撤销 gossip + 反熵；3) 消费前同步查 `tainted` | 网络分区期间存在窗口期 |
| R43 | **多端口-多机联合的「伪新鲜 + 伪信任」叠加**（端口模型失真 ∧ 信任衰减被绕过） | **极高** | 1) 新鲜度与信任**双重 fail-closed**，任一不过即拒；2) 证书携带 port_path + provenance，消费端独立复核；3) 端到端红队演练（伪造摘要 + 延迟注入） | 两模型同时失配时仍可能漏网，是本方案最隐蔽的失效模式 |

## 6. 本轮最大风险（最终确认）

**一句话**：**端口时延模型失真与多机信任衰减被绕过会叠加成「源头有效、消费端失效」的伪证书（certified-but-stale）——它在单机视角下完全无异常，却会在跨机协同的关键时刻同时击穿时效与信任两条防线，是整个 CADVS-v2 走向真实多机多端口部署的生死线。**
