# 第 41 轮 · 双灵感落地 v8：可认证持续学习 × 无源柔顺控制 × 证书记忆回放（四层架构 v6）

> 承接第 40 轮（v17：可认证流匹配执行 × 度量语义几何锚定 × 证书驱动课程引擎，四层架构 v5）。本轮灵感词「持续学习、柔顺控制」补上 v17 证书体系缺失的**时间维度与接触维度**：v17 的证书是「某一时刻、自由空间」的快照，本轮把它变成「终生有效、接触安全」的活约束——用参数空间阻抗控制抗遗忘，用无源性给柔顺控制一个可组合的能量证书，用证书记忆回放把二者闭合成终生学习引擎。

## 0. 直觉与动机

**灵感 1（持续学习 → 证书的时间失效）**：v17 的 CertBundle 隐含假设「任务分布静止」，但真实部署是任务流 τ₁,τ₂,…。持续学习的老问题是灾难性遗忘，而**遗忘对证书体系是致命的**：旧技能的 L_v、h_min、κ 都是相对旧权重认证的，权重一动，证书就变成一张过期的体检报告，RCA 却仍按它放行——这是比第 40 轮「装饰性证书」更隐蔽的失效。关键洞察是：EWC 的二次惩罚 (θ−θᵢ)ᵀFᵢ(θ−θᵢ) 与机械阻抗 ½(x−xᵢ)ᵀK(x−xᵢ) 是同一个数学对象，**Fisher 信息就是参数空间的刚度矩阵**。于是「抗遗忘」可重写为「参数空间阻抗控制」：刚度 K_i 决定对旧任务的记忆粘性，阻尼 D_i 抑制新任务梯度造成的参数振荡。遗忘不再是定性担忧，而是可由「位移能量」E_i=½(θ−θᵢ)ᵀKᵢ(θ−θᵢ) 给出上界的可认证量。

**灵感 2（柔顺控制 → 证书的物理底座）**：v17 的 CBF 证书都是位置空间安全（clearance），一进接触就崩：刚性位置控制下，1mm 的位置误差在 10⁴ N/m 刚度下就是 10 N 的力，轻松超限。柔顺控制的本质是**用储能与耗散吸收位置不确定性**——把「必须精确到达」换成「允许在阻抗椭球内屈服」。更重要的是，无源性（passivity）是比 Lipschitz 更强的组合性质：v17 的组合证书 κ_comp=min κᵢ 但 L 会逐层累积，技能一多就乘爆；而负反馈互联的无源系统仍无源，能量池 E_tank 直接相加。于是证书获得一个**可加、跨任务守恒**的物理量——能量，这正是 Lipschitz 乘积爆炸的时间版解药。柔顺证书 CertPass={Z_min, E_tank^min, η_pass} 管住接触，和 v17 的几何证书拼成完整安全域。

**灵感 3（两者耦合 → 阻抗记忆即终生学习的锚）**：持续学习需要「记住什么不能忘」，柔顺控制需要「用多大刚度去接触」。本轮把两者统一为**阻抗记忆**：每个技能存 (Kᵢ,Dᵢ) 作为可执行阻抗锚点，新技能学习时以旧锚点作弹性约束（参数空间），执行时以阻抗椭球吸收接触不确定性（任务空间）。无源性保证：只要每个技能模块与能量池无源，任意串/并联组合在终生时间轴上都无源——**证书第一次同时对「时间」和「组合」封闭**。

**三灵感的耦合**：持续学习给出「证书在时间上不失效」，柔顺控制给出「证书在接触上不失效」，证书记忆把两者焊成终生闭环：遗忘监测触发回放，能量池耗尽触发降刚，重认证回写总线。

## 1. 形式化定义

**定义 27（终生技能流与证书记忆 M）**：任务流 {τ₁,…,τ_T} 非平稳、无回访保证。证书记忆 M={(Cᵢ, Sᵢ, Aᵢ)}：Cᵢ 为任务 i 的 CertBundle，Sᵢ 为锚点样本集（约束回放），Aᵢ=(Kᵢ,Dᵢ,Fᵢ) 为阻抗锚点（刚度、阻尼、Fisher 重要度）。M 是唯一跨任务保留的持久状态，容量预算 |M|≤B_mem。

**定义 28（参数空间阻抗与遗忘证书）**：学习新任务时参数受二阶阻抗动力学约束：M_p θ̈ + D θ̇ + K(θ−θ_old) = −∇L_new，其中 K=Σᵢ Kᵢ（对角块，Kᵢ≈diag(Fᵢ)+εI）。定义位移能量 Eᵢ(θ)=½(θ−θᵢ)ᵀKᵢ(θ−θᵢ)。**定理（遗忘上界）**：若任务损失 Lᵢ 为 βᵢ-光滑且在 θᵢ 处近似驻点，且 Kᵢ ⪰ λ_min I，则 Lᵢ(θ_T) − Lᵢ(θᵢ) ≤ βᵢ·Eᵢ(θ_T)/λ_min。故 CertForget={εᵢ}：只要 Eᵢ(θ_T) ≤ εᵢ，旧任务遗忘被 εᵢ 封顶，可在线监测、超限即触发回放/重认证。

**定义 29（无源柔顺技能与能量池）**：技能 i 为端口哈密顿系统：(q̇,ṗ)=(∂H/∂p, −∂H/∂q + u + f_ext)，交互端口 (f,v)，期望阻抗 Z_d(s)=K_d+D_d s+M_d s²。能量池 E_tank,i 累积耗散，执行时满足功率约束 Ḣ ≤ fᵀv − 耗散。CertPass={Z_min, E_tank^min, η_pass}：Z_min 为最小刚度（太软会失位）、E_tank^min 为可用储能下界、η_pass 为无源裕度。**定理（无源组合）**：两个无源技能经负反馈互联仍无源，互联后储能 H=H₁+H₂、能量池 E=E₁+E₂；n 个技能串联/并联的总裕度为 ΣE_tank,i（可加，不随 n 乘爆）。能量池见底时切入「纯阻尼安全模式」（K→0, D>0），系统退化但保持无源。

**定义 30（接触感知 CBF 与阻抗调度）**：复合安全集 S = {x : h_geo(x) ≥ B_t ∧ h_force(x) ≥ 0 ∧ E_tank ≥ E_min}，其中 h_force = f_max − ‖f_ext‖（接触力上限），h_geo 承接 IP-49 的 ESDF 间隙。阻抗调度 κ_imp(x) 由间隙裕度驱动：h_geo 越小 → K(x) 越低（更软），满足单调性 ∂K/∂h_geo ≥ 0，使「柔顺即把安全裕度物理兑换成接触力裕度」。调度带滞回以防颤振。

## 2. 三大产出设计

### 2.1 IP-51 CERT-CONTINUAL-SKILL（可认证持续学习）
1. 证书记忆库：每任务存 Cᵢ、锚点样本 Sᵢ、阻抗锚点 Aᵢ=(Kᵢ,Dᵢ,Fᵢ)；按遗忘风险与覆盖度做预算淘汰。
2. 阻抗正则：以定义 28 的参数空间阻抗约束更新（Fisher 刚度 + 阻尼项），双时间尺度——锚点慢更新、任务适配快更新。
3. 遗忘监测：在线估 Eᵢ(θ)，超 εᵢ → 触发 IP-53 回放并请 RCA 重颁该技能证书；连续超限则冻结该锚点（保护优先于可塑）。
4. 可塑扩展：当新任务在现有锚点下无法满足证书，按预算新增低秩列/专家头（渐进网络式），旧列只读，避免全局覆盖。
5. 重认证判据：遗忘上界、无源裕度、几何有效域三者的最小者决定证书是否仍可签发。

### 2.2 IP-52 PASSIVITY-COMPLIANT-CONTROL（无源柔顺控制）
1. 变阻抗/导纳骨干：端口哈密顿实现，阻抗参数 (K_d,D_d,M_d) 由 IP-43 韵律通道调制，形成「柔顺韵律」。
2. 能量池：每技能独立能量池 + 共享总线池，见底切纯阻尼安全模式；池间能量可借还但总量守恒（可审计）。
3. 接触力感知：F/T 与关节力矩估计入 h_force，扩展 IP-49 的 CBF-QP 为 S 上的复合 QP；退化时投影到最近安全控制。
4. 阻抗调度：按定义 30 由间隙裕度与接触力反馈在线调 K，带滞回；调度本身受 CertPass 约束。
5. 组合证书：为 IP-47 提供无源组合谓词，串联/并联/反馈三种拓扑给闭式能量裕度。

### 2.3 IP-53 CERT-MEMORY-REPLAY（证书记忆与回放）
1. 回放权重 = 遗忘风险 · 证书赤字 · 覆盖缺口 三者归一化乘积，优先回放「正在失效且少被复习」的锚点。
2. 证书快照：按版本存 Cᵢ 与对应权重哈希，支持回滚与审计（防第 40 轮警示的证书漂移）。
3. 终生课程：把 IP-50 的课程带推广为非平稳目标——D_center 追踪证书赤字，同时用遗忘项压低「以牺牲旧任务换新任务」的采样偏好。
4. 闭环：回放 → 阻抗正则更新 → 重认证 → 契约热更新回 IP-45 总线。
5. 容量治理：锚点样本按「梯度多样性 + 约束紧致度」贪心压缩，预算内保最大覆盖。

## 2. 关键算法

### IP-51 可认证持续学习（伪代码）
```
def continual_update(theta, task, memory, eps):
    # 参数空间阻抗：K 为旧锚点 Fisher 刚度块，D 为阻尼
    K = block_diag([a.K for a in memory.anchors], eps*I)
    D = 2*sqrt(K)                       # 临界阻尼近似，抑制新任务振荡
    for batch in task.loader:
        g = grad(L_new(theta, batch))
        theta = theta - lr*(g + K @ (theta - memory.anchor_theta)
                            + D @ (theta - memory.prev_theta))

def forgetting_monitor(theta, memory, eps):
    for i, a in enumerate(memory.anchors):
        E = 0.5 * (theta - a.theta) @ a.K @ (theta - a.theta)
        if E > eps[i]:
            IP53.replay(a.S); RCA.reissue(a.skill); mark_risk(i)
        if E > 4*eps[i]: freeze_anchor(i)      # 保护优先于可塑
```

### IP-52 无源柔顺控制（伪代码）
```
def compliant_control(q, p, x_ref, K_d, D_d, tank):
    v_ref = (x_ref - q) / dt
    f_cmd = K_d @ (x_ref - q) + D_d @ (v_ref - dq)     # 阻抗律
    p_in  = f_cmd @ dq                                  # 端口功率
    if tank.E + p_in*dt < E_min:
        K_d, D_d = 0.0, D_safe                        # 纯阻尼安全模式
        f_cmd = D_safe @ (v_ref - dq)
    tank.E += (p_in - dissipation(dq))*dt
    return f_cmd, tank

def contact_cbf_qp(x_hat, u_ref, h_geo, h_force, tank, B_t):
    constraints = [h_geo >= B_t, h_force >= 0, tank.E >= E_min]
    return QP(u_ref, constraints, alpha=alpha_class_k)
```

### IP-53 证书记忆回放（伪代码）
```
def replay_priority(a, memory, coverage):
    risk  = normalize(a.E / a.eps)            # 遗忘风险
    deficit = cert_deficit(a.skill)           # 证书赤字（承接 IP-50 定义 26）
    gap   = 1.0 - coverage(a)                 # 覆盖缺口
    return risk * deficit * gap

def lifelong_step(theta, memory, task_stream, band, budget):
    t = next(task_stream)
    theta = continual_update(theta, t, memory, eps)
    forgetting_monitor(theta, memory, eps)
    worst = argmax([replay_priority(a, memory, coverage) for a in memory.anchors])
    if worst_priority > tau:
        theta = continual_update(theta, replay_task(worst.S), memory, eps)
    band.center += eta*(success(theta, band) - target) - lambda_f*forget_rate(theta)
    memory.compress(budget, by=['grad_diversity','constraint_tightness'])
    if cert_drift_detected(): RCA.reissue(); Registry.hot_reload(contracts)
```

|---|---|---|
| 阻抗正则更新 | 每步 O(d_θ²) 稀疏块乘，Fisher 块预存 | **定理**：Eᵢ≤εᵢ ⟹ 遗忘 ≤ βᵢεᵢ/λ_min |
| 遗忘监测 | O(Σ dim Kᵢ) / 任务，可批量化 | 上界可证（β-光滑 + 驻点假设） |
| 柔顺控制 | 每控制周期 O(d_q²)（阻抗律）+ O(1) 能量池 | 端口功率约束；见底切安全模式仍无源 |
| 接触 CBF-QP | O(m³)，m 为约束数（3~6），小规模 | 复合安全集 S 前向不变；QP 可行时闭环安全 |
| 无源组合 | O(|V|+|E|)，与技能数线性 | **定理**：负反馈互联无源，E_tank 可加 |
| 回放优先级 | O(|M|)/步；预索引 O(log|M|) | 优先级单调于遗忘风险；压缩保覆盖下界 |
| 终生课程 | O(1) 带更新 + O(|M|) 遗忘项 | Robbins-Monro ⟹ 收敛到含遗忘惩罚的目标成功率 |

## 4. 实验设计（E73-E78，硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E73 抗遗忘证书 | 8 任务序列后旧任务成功率降幅；遗忘上界命中率 | ≤5%；≥99% |
| E74 阻抗正则效率 | 平均遗忘/后向迁移 vs EWC/replay；锚点内存 | 遗忘≤EWC−30%；内存≤50% |
| E75 无源组合 | 5 技能串联/反馈能量池始终 ≥0；裕度可加性 | 0 次穿底；误差≤10% |
| E76 柔顺接触安全 | 峰值接触力/近碰撞率 vs 刚性位置控制 | 峰值降≥40%；近碰撞降≥50% |
| E77 终生课程 | T=10 任务累计达标样本 vs v17；重颁次数 | 节省≥30%；重颁≤2/任务 |
| E78 端到端 sim-to-real | 接触丰富任务零样本成功率；无源违约 | ≥80%；违约=0 |

失败即回退：E73/E75 不达标 → 回退 v17（无时间项证书），IP-51 降为离线 EWC 基线，IP-52 仅在自由空间启用；IP-53 保留为审计工具。

## 5. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| Fisher 刚度在非凸损失面给不出紧遗忘上界 → 证书过保守 | 高 | 仅对任务关键子空间取 Fisher；E73 第一守门；支持经验系数回退 |
| 能量池在接触冲击下频繁穿底 → 长期纯阻尼、任务失败 | 高 | 冲击前预充能 + 阻抗预测调度 + 多池借还；E75 守门 |
| 过度柔顺导致定位任务失位（太软） | 中 | Z_min 下界证书 + 任务分层（插入软、装配硬）+ 调度带滞回 |
| 锚点内存无限增长 | 中 | 预算压缩 + 梯度多样性贪心 + 证书覆盖下界审计 |
| 终生课程非平稳震荡 | 中 | 双时间尺度 + 遗忘惩罚 + 滞回 + EWMA |
| 无源假设被未建模执行器动力学破坏（摩擦/饱和） | 高 | 执行器无源化层（能量观测器）+ 实测无源裕度在线校正；E75/E78 守门 |

## 6. 本轮最大风险

**一句话**：整套设计押在「阻抗即证书」这一同构上——若 Fisher 刚度在真实非凸损失面上给不出紧的遗忘上界，或能量池在接触冲击下频繁穿底而退化到纯阻尼，则「终生可认证 + 接触可认证」会同时塌成两张过期文档，故 E73/E75 为本轮成败判据。
