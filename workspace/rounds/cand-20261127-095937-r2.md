### 第 2 轮灵感驱动研究记录

**灵感词**：深度学习、对比实验

**承接与问题定位**：
前几轮把证书体系从「感知-合规-能量」推进到「结构-力学」（USMC）、「语义-重构-协同」（SRC-USC），又叠加了「成本-记忆-可扩展」（v26）。但整条链仍是**手工构造阈值 + 精确验证**的范式：SMC 的 `α`、RMC 的 `δ_dyn`、MCC 的 `ε_cons/β` 多由经验给定；MCC 的 `O(N²T)` 成对检查、SMC 的 conformal 重校准、RMC 的逆动力学复核在真实平台上代价高；更关键的是，**证书本身的安全边际从未被“数据驱动地校准”，也从未被“对照实验地证伪”**。

**直觉解释（先给直觉）**：
- 深度学习给的不是“更聪明的证书”，而是**证书的压缩器与加速器**。一个神经网络可以学着去预测“精确验证器会给出多大 margin”，从而把大多数显然安全的输入直接放行、把少数边界样本退还给精确验证器。它像一位经验丰富的预审员：**只允许说“通过”当它确信精确验证器也会通过；拿不准就上交复审**。若让学习模型直接替代验证器，就等于“用不可验证的模型去证明安全”，逻辑上自我拆台。因此核心设计原则是**单向可靠性（one-sided soundness）+ 边界回退（defer-to-exact）**。
- 对比实验给的不是“再跑几个数字”，而是**证书体系的证伪机制**。每新增一个证书维度（语义/重构/协同/成本/记忆/学习），都必须回答三个可比问题：相对基线是否**显著**降低安全违规？代价是否**等价或更低**？收益在消融后是否**归因于该维度**而非数据泄漏或调参偶然？因此核心设计原则是**配对设计 + 预注册 + 多重比较校正 + 效应量 + 等价性检验**。

**严谨定义（再给定义）**：
1. **学习型证书代理（LCS）**：设精确验证器的实值 margin 为 `V(x)`，通过阈值为 `τ`。学习 `f_θ(x)` 逼近 `V`，并构造可证误差包络 `U(x)`，满足 `∀x∈𝒳_cover: |f_θ(x)-V(x)| ≤ U(x)`。三值判决：
   - 若 `f_θ(x) ≥ τ + U(x)` → 接受（可证 `V(x) ≥ τ`）；
   - 若 `f_θ(x) < τ - U(x)` → 拒绝（可证 `V(x) < τ`）；
   - 否则 → **回退**精确验证器。
   由此得到 `LCS_accept ⇒ Exact_accept`，且回退率 `r_fb = ℙ(|f_θ-τ| ≤ U)` 决定摊销收益。
2. **神经非一致性评分（NCS）**：用深度集成/能量分数学习 conformal 的非一致性分数 `s_φ(x,y)`，按语义组 `g` 做 **Mondrian/分组 conformal** 校准，取 `α_g = α/G`，保证组内边际覆盖 `ℙ(Y∈C_g(x)) ≥ 1-α_g`；同时用分组覆盖诊断与 OOD 分数触发保守重校准。
3. **可微证书层（DCL）**：把证书约束写成可行域 `𝒞 = {z : g(z) ≤ 0}`，用可微凸投影 `Π_𝒞` 得到 `z* = Π_𝒞(y)`，并用隐式微分反传。`δ_proj = ‖z*-y‖` 只度量“修复幅度”；真正的可行性违规必须用求解器残差 `ε_solver` 与实际约束值监控：`g(z̃) ≤ L_g ε_solver`（或直接取 `max(0, g(z̃))`），不能把 `L_g δ_proj` 当作违规上界。
4. **对照证书基准（CCB）**：对系统 A（新证书）与 B（基线），在配对场景 `s=1..S` 上记录差异 `d_s`；预注册单侧假设，报告配对 bootstrap 置信区间、效应量（Cliff's δ / Cohen's d）、Holm–Bonferroni 校正后的显著性，并用 TOST 做代价等价性检验；消融矩阵与负对照用于归因。
5. **学习-对照统一准入门（LC-UC）**：`Exec_v27 = Exec_v26 ∩ Fil_learn ∩ Fil_compare ⊆ Exec_v26`。`Fil_learn` 是运行时的可靠性过滤器（回退语义），`Fil_compare` 是部署/版本晋升时的证据过滤器（证据过期或漂移检测失败则禁用对应模块，退回 v26）。

**本轮形式化目标**：
1. 定义 LCS，并证明**单侧 soundness**：在误差包络有效的前提下，LCS 的接受/拒绝永不与精确验证器相反；给出回退率—摊销成本的显式权衡。
2. 定义 NCS，给出分组有限样本覆盖界 `≥ 1-α_g - 1/(n_g+1)`，并分析组样本不足时的保守退化策略。
3. 定义 DCL，给出求解器残差 `ε_solver`—约束违规的 Lipschitz 界（明确 `δ_proj` 不等于违规量）与隐式梯度正确性（a.e.）。
4. 定义 CCB，给出配对检验的 I 类错误控制、Holm 的 FWER 控制、TOST 的等价性判据与最小可检测效应量（power）公式。
5. 将四者并入 v27 单调退化链：学习代理失效/对照证据失效/投影失效时，系统可**逐级退回** v26 的精确七证体系，保持 `Exec_v27 ⊆ Exec_v26 ⊆ …`。

**本轮最大风险**：学习型代理的误差包络在分布外极易变得空洞或失效，而对比实验又可能被基准过拟合与选择性报告“装饰”成显著收益——最大的风险是系统在 OOD 下信任了一个**自信地犯错**的学习验证器，同时用一份**被污染的对账证据**为其背书。

```python
# ============================================================
# IP-451 Learned Certificate Surrogate (LCS) — 学习型证书代理
# ============================================================
@dataclass
class LearnedCertificateSurrogate:
    exact_verifier: 'ExactCertificateVerifier'   # 返回实值 margin V(x)
    f_theta: 'nn.Module'                          # 学习型 margin 预测器
    tau: float = 0.0                              # 通过阈值
    eps_surrogate: float = 0.05                   # 允许的最大包络宽度
    # 以下由 calibrate() 填充
    L_V: float = None                             # 精确 margin 的 Lipschitz 常数
    L_f: float = None                             # 代理的 Lipschitz 常数
    rho_cover: float = None                       # 校准集对输入域的覆盖半径
    max_cal_residual: float = None                # 校准集上 max |f_theta - V|
    n_cal: int = 0

    # ---------- 1) 离线校准：构造确定性误差包络 ----------
    def calibrate(self, cal_inputs: Tensor, cal_margins: Tensor,
                  domain_radius: float) -> None:
        """U(x) = max_cal |f-V| + (L_V + L_f) * rho_cover"""
        self.n_cal = len(cal_inputs)
        residuals = []
        for x, Vx in zip(cal_inputs, cal_margins):
            residuals.append(abs(float(self.f_theta(x)) - float(Vx)))
        self.max_cal_residual = max(residuals) if residuals else float('inf')
        # L_V 由精确验证器的解析/区间界给出；L_f 由网络谱范数上界给出
        self.L_V = self.exact_verifier.lipschitz_constant()
        self.L_f = spectral_norm_upper_bound(self.f_theta)
        # 覆盖半径：每个域内点到最近校准锚点的最大距离（用 ε-net 估计）
        self.rho_cover = estimate_covering_radius(cal_inputs, domain_radius)

    def certified_error_envelope(self) -> float:
        if None in (self.L_V, self.L_f, self.rho_cover, self.max_cal_residual):
            return float('inf')
        return self.max_cal_residual + (self.L_V + self.L_f) * self.rho_cover

    # ---------- 2) 在线三值判决：只做单向可靠的放行/拒绝 ----------
    def decide(self, x: Tensor) -> tuple[bool, str]:
        U = self.certified_error_envelope()
        # 包络无效、过宽、或 x 不在覆盖域：一律回退精确验证
        if (not math.isfinite(U)) or (U > self.eps_surrogate) \
                or (not self.in_cover(x)):
            return self.exact_verifier.margin(x) >= self.tau, 'exact_oob'
        m_hat = float(self.f_theta(x))
        if m_hat >= self.tau + U:
            return True, 'surrogate_accept'      # 可证 V >= tau
        if m_hat < self.tau - U:
            return False, 'surrogate_reject'     # 可证 V < tau
        return self.exact_verifier.margin(x) >= self.tau, 'fallback_band'

    def in_cover(self, x: Tensor) -> bool:
        return nearest_anchor_distance(x, self.anchors) <= self.rho_cover

    # ---------- 3) 运行期包络自适应：漂移时自动收紧/关闭 ----------
    def update_envelope(self, residual_window: list[float]) -> None:
        """在线残差超出离线 max_cal_residual 时，扩大包络；超 eps_sur 即停用代理"""
        if residual_window:
            self.max_cal_residual = max(self.max_cal_residual,
                                        max(residual_window))
        if self.certified_error_envelope() > self.eps_surrogate:
            self.disable()   # 全量回退精确验证，等价于 Exec_v26

    def expected_cost(self) -> float:
        U = self.certified_error_envelope()
        r = self._estimate_fallback_rate(U)      # 由校准集 margin 分布估计
        return (1 - r) * c_sur + r * c_exact

# IP-452 Neural Conformal Scorer (NCS) — 神经非一致性评分
# ============================================================
@dataclass
class NeuralConformalScorer:
    scorer: 'nn.Module'                 # s_phi(x, y)
    group_fn: Callable                  # g = group_fn(x)
    alpha: float = 0.05
    G: int = 5
    q_table: dict = None                # {g: q_g}
    ood_detector: 'OODDetector' = None
    alpha_g: float = None               # = alpha / G（同时覆盖）

    def calibrate(self, cal_X: Tensor, cal_Y: Tensor) -> None:
        self.alpha_g = self.alpha / self.G
        buckets = defaultdict(list)
        for x, y in zip(cal_X, cal_Y):
            buckets[self.group_fn(x)].append(float(self.scorer(x, y)))
        self.q_table = {}
        for g, scores in buckets.items():
            n = len(scores)
            if n < 10:                  # 组样本不足：退化为全局保守分位
                continue
            level = math.ceil((n + 1) * (1 - self.alpha_g)) / n
            self.q_table[g] = quantile(scores, min(level, 1.0))

    def predict_set(self, x: Tensor, candidates: Tensor) -> Tensor:
        g = self.group_fn(x)
        if self.ood_detector is not None and self.ood_detector.is_ood(x):
            return candidates                 # OOD：全候选集（保守）
        if g not in self.q_table:             # 未见组：回退全局集
            return candidates
        scores = self.scorer(x, candidates)
        return candidates[scores <= self.q_table[g]]

    def group_coverage_report(self, X: Tensor, Y: Tensor) -> dict:
        return {g: empirical_coverage(self.predict_set(x, ALL_CLASSES), y)
                for x, y in zip(X, Y)
                for g in [self.group_fn(x)]}

# IP-453 Differentiable Certificate Layer (DCL) — 可微证书层
# ============================================================
class DifferentiableCertificateLayer(nn.Module):
    """证书约束下的端到端可微投影层 z* = argmin_{z in C} 1/2||z-y||^2"""

    def __init__(self, constraint_fn: Callable, L_g: float,
                 solver: str = 'cvxpy_diff'):
        super().__init__()
        self.g = constraint_fn
        self.L_g = L_g
        self.solver = solver

    def forward(self, y: Tensor) -> tuple[Tensor, dict]:
        z_star, solver_info = differentiable_projection(
            y, self.g, solver=self.solver, return_info=True)
        delta_proj = torch.norm(z_star - y, dim=-1)
        eps_solver = solver_info.get('residual', 0.0)      # 求解器精度
        actual_violation = torch.clamp(self.g(z_star), min=0.0)
        # 真实违规就是实测约束值；Lipschitz 项只作为独立的一致性上界报告
        theoretical_bound = self.L_g * eps_solver
        return z_star, {'delta_proj': delta_proj,
                        'eps_solver': eps_solver,
                        'violation_bound': actual_violation,
                        'theoretical_bound': theoretical_bound}

    def certified_forward(self, y: Tensor, delta_max: float) -> tuple[Tensor, bool]:
        z_star, info = self.forward(y)
        ok = bool((info['violation_bound'] <= delta_max).all()
                  and (info['theoretical_bound'] <= delta_max).all())
        return z_star, ok
```

```python
# ============================================================
# IP-455 Learning-Compare Unified Certificate (LC-UC)
# ============================================================
@dataclass
class LearningCompareUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'   # v26 七证
    lcs: dict = None            # {cert_name: LearnedCertificateSurrogate}
    ncs: NeuralConformalScorer = None
    dcl: DifferentiableCertificateLayer = None
    ccb_ledger: 'EvidenceLedger' = None
    drift_monitor: 'DriftMonitor' = None

    def admits(self, multi_plan, sensor_data: dict) -> tuple[bool, dict]:
        # 1) 证据门（部署/版本级）：无有效对照证据一律禁用学习模块
        learn_enabled = self.ccb_ledger.is_valid(
            modules=['LCS', 'NCS', 'DCL'],
            max_age_steps=self.ccb_ledger.max_age)
        if not learn_enabled:
            return self.src_usc.admits(multi_plan, sensor_data), {'mode': 'v26'}

        # 2) 漂移门：分布漂移超阈 -> 学习模块整体回退
        if self.drift_monitor.drift_score(sensor_data) > self.drift_monitor.threshold:
            return self.src_usc.admits(multi_plan, sensor_data), {'mode': 'v26_drift'}

        # 3) 逐个证书：代理判决带“回退”，回退即调精确验证
        decisions = {}
        for cert_name, surrogate in (self.lcs or {}).items():
            ok, src = surrogate.decide(sensor_data[cert_name])
            decisions[cert_name] = {'ok': ok, 'source': src}
            if not ok:
                return False, {'mode': 'learn_reject', 'cert': cert_name,
                               'decisions': decisions}

        # 4) 语义证书用 NCS 替换手工分数（分组覆盖）
        if self.ncs is not None:
            pred = self.ncs.predict_set(sensor_data['semantic_obs'],
                                        sensor_data['semantic_candidates'])
            if not semantic_set_contains_gt(pred, sensor_data['semantic_gt']):
                return False, {'mode': 'ncs_reject'}
        else:
            if not self.src_usc.smc.verify_all(*sensor_data['smc_args']):
                return False, {'mode': 'smc_reject'}

        # 5) 可微证书层：投影 + 可行性上界
        if self.dcl is not None:
            z_star, ok = self.dcl.certified_forward(
                sensor_data['action'], sensor_data['delta_max'])
            if not ok:
                return False, {'mode': 'dcl_infeasible'}
            multi_plan = multi_plan.with_action(z_star)

        # 6) 底层 v26 七证仍然必须全通过（学习模块只加速/松弛，不放宽）
        base_ok = self.src_usc.admits(multi_plan, sensor_data)
        return base_ok, {'mode': 'v27', 'decisions': decisions}
```

**关键实现约束**：
1. `LCS.calibrate` 的 `L_V` 必须来自精确验证器的**解析 Lipschitz 界或区间算术上界**，不得用有限差分估计；`L_f` 用谱范数乘积上界。否则包络无效，`U=∞` 强制回退。
2. `NCS` 的分组必须在校准前固定（不得用测试集调组），且 `G` 参与多重覆盖预算 `α_g=α/G`。
3. `DCL` 的投影必须由可微凸优化层（如 diffcp/CvxpyLayer）给出；非凸情形用局部 QP 近似并把近似误差计入 `δ_proj`，不得省略。
4. `CCB` 的阈值、指标方向、MDE、消融清单必须在查看测试结果前写入 `pre_registered`；`report` 自动拒绝事后改假设。

## 2. 复杂度分析（本轮增量）

| 模块 | 离线成本 | 在线成本 | 相对 v26 的变化 |
|---|---|---|---|
| LCS 校准 | `O(n_cal · (c_exact + c_f))` + 覆盖半径估计 | `O(c_f)`；回退时 `O(c_exact)`；期望 `(1-r_fb)c_f + r_fb c_exact` | 当 `r_fb` 小且 `c_f ≪ c_exact` 时摊销显著降本；最坏情况不劣于精确验证（回退率 1） |
| LCS 包络更新 | `O(1)` | `O(1)` | 漂移超阈即停用，退化为 v26 |
| NCS 校准 | `O(n_cal · c_s)` | `O(c_s · |𝒴|)` 打分 + 查表 `O(1)` | 与手工分数同阶；分组校准增加 `O(G)` 空间 |
| DCL 投影 | 无 | 凸投影 `O(d³)`（d 为动作维）；隐式反传 `O(d³)` | 把“事后拒证”变为“可微修复”，单步增加一次投影 |
| CCB | `O(S · seeds · (c_new+c_base) + n_boot · S)` | 0（离线/版本晋升） | 纯离线治理成本，不进入控制环 |
| LC-UC 准入 | 0 | 证据门 + 漂移门 `O(1)` + 各证书在线成本 | 关键路径 = 回退样本的精确验证成本；非回退样本更快 |

**实时性论证**：设精确验证器单次成本为 `c_exact`（如 MCC 的 `O(N²T)`），代理前向为 `c_f=O(1)`。在线期望成本为 `(1-r_fb)c_f + r_fb c_exact`。只要 `r_fb < 1 - c_f/c_exact` 即严格优于全量精确验证；当包络过宽（`U>ε_sur`）或 OOD 时 `r_fb→1`，系统自动退回 v26 的实时预算，**不会出现“学习模块拖垮控制周期”的失效模式**。

## 3. 正确性论证（本轮增量）

### 引理 16（LCS 的单侧可靠性）
**陈述**：若误差包络 `U(x)` 在 `𝒳_cover` 上满足 `|f_θ(x)-V(x)| ≤ U(x)`，则 LCS 的判决永不与精确验证器相反：
- `decide(x)=surrogate_accept ⇒ V(x) ≥ τ`；
- `decide(x)=surrogate_reject ⇒ V(x) < τ`。
因此 `LCS_accept ⊆ Exact_accept`，且三值判决的“回退”分支不引入任何额外误判。

**证明**：
1. 若 `f_θ(x) ≥ τ+U(x)`，由包络 `V(x) ≥ f_θ(x)-U(x) ≥ τ`，接受正确。
2. 若 `f_θ(x) < τ-U(x)`，由包络 `V(x) ≤ f_θ(x)+U(x) < τ`，拒绝正确。
3. 其余分支直接调用精确验证器，按定义正确。
4. 三值判决的“接受”只会发生在分支 1，故 `LCS_accept ⇒ Exact_accept`。∎

**推论 16.1（回退—成本权衡）**：若校准集上 margin 的经验分布为 `F_V`，则 `r_fb ≤ ℙ(V ∈ [τ-2U, τ+2U])`（因 `|f_θ-V|≤U`），期望成本不超过 `(1-r_fb)c_f + r_fb c_exact`。当 `U` 增大时回退率上升、成本趋近精确验证，安全性与 v26 一致。

### 引理 17（NCS 的分组有限样本覆盖）
**陈述**：对固定组 `g`，若校准分数与测试分数在组内可交换，且 `n_g ≥ 10`，则 Mondrian conformal 预测集满足
`ℙ(Y ∈ C_g(X) | g(X)=g) ≥ 1 - α_g - 1/(n_g+1)`。
若 `α_g = α/G`，则 `G` 个组的同时覆盖至少 `1-α`（并集界）。

**证明**：组内交换性下，经典 split-conformal 分位数 `q_g = ⌈(n_g+1)(1-α_g)⌉/n_g` 的边际覆盖下界为 `1-α_g-1/(n_g+1)`（Vovk et al. 2005，有限样本版）。对 `G` 个组取并集界：`ℙ(∃g 未覆盖) ≤ Σ_g α_g = G·(α/G)=α`，故同时覆盖 ≥ `1-α`。组样本不足时 `predict_set` 返回全候选集，覆盖为 1（保守），不破坏下界。∎

**注**：本引理只保证**组条件覆盖**，不保证个体条件覆盖；NCS 的 OOD 检测与重校准用于缓解组内偏移，但不构成无分布假设的个体覆盖保证（见 R20）。

### 引理 18（DCL 的投影可行性界）
**陈述**：设 `g` 为 `L_g`-Lipschitz，`z* = Π_𝒞(y)`，`δ_proj = ‖z*-y‖`。注意 `δ_proj` 只度量“修复幅度”，**不是**可行性违规上界。精确投影满足 `z*∈𝒞 ⇒ g(z*) ≤ 0`；当投影由带容差求解器给出、实际输出为 `z̃` 且 `‖z̃-z*‖ ≤ ε_solver` 时，有 `g(z̃) ≤ L_g ε_solver`。因此运行时必须以实测值 `max(0,g(z̃))` 为准，并用 `L_g ε_solver` 作为独立的保守上界。

**证明**：投影落在闭集 `𝒞` 上，故 `g(z*)≤0`。由 `g` 的 Lipschitz 性与三角不等式，`g(z̃) ≤ g(z*) + L_g‖z̃-z*‖ ≤ L_g ε_solver`。另一方面，若直接对求解器输出精确求值，则真实违规就是 `max(0,g(z̃))`。两者取更保守者即可，但不得用 `L_g δ_proj` 冒充违规上界（当 `y` 本身不可行时 `δ_proj` 很大而 `g(z̃)` 可能已为 0；反之当 `y` 可行但求解器偏置时 `δ_proj` 也可能低估违规）。∎

**实现约束**：`DCL.certified_forward` 以 `violation_bound = max(0, g(z̃))` 为主判据，并在 `info` 中同时报告 `δ_proj`、`ε_solver` 与 `L_g ε_solver` 供审计；`ok` 要求 `violation_bound ≤ δ_max` 且 `L_g ε_solver ≤ δ_max`。

### 引理 19（CCB 的统计有效性）
**陈述**：设配对差异 `d_s` 独立同分布、单侧原假设 `H0: E[d] ≤ 0`（A 不优于 B）。则在 `H0` 下，配对 bootstrap 的 `(1-α)` 单侧 CI 下界以渐近概率 `≥1-α` 不高于 0；对 `m` 个指标使用 Holm 校正后，族错误率 `FWER ≤ α_fwer`。TOST 在 `(Δ_L,Δ_U)` 内的等价性由两个单侧检验的 `α` 水平共同控制。

**证明**：bootstrap CI 的渐近有效性来自经验分布对真实分布的弱收敛与分位数连续性（标准结论）。Holm 步骤：排序后第 `k` 小的 p 值阈值 `α/(m-k+1)`，其拒绝集在全局原假设下 FWER ≤ `α`（Holm 1979）。TOST 等价性：`H0: |E[d]| ≥ Δ` 被拒绝当且仅当两个单侧 `α` 检验均拒绝，故等价性结论的 I 类错误 ≤ `α`。∎

**注**：CCB 只保证“在预注册指标与场景分布上的统计结论”，不保证跨分布外推；负对照与消融用于排除泄漏，但不能替代 OOD 测试（见 R22）。

### 引理 20（LC-UC 的单调退化与 v27 包含关系）
**陈述**：对任意计划 `π`，`LC-UC.admits(π)=True ⇒ SRC-USC.admits(π)=True`。因此 `Exec_v27 ⊆ Exec_v26`。当证据门失效、漂移超阈、包络过宽或投影不可行时，`LC-UC` 返回 `SRC-USC` 的原判决，单调链不断裂。

**证明**：
1. `LC-UC.admits` 的第 6 步显式要求 `src_usc.admits(multi_plan)=True`；任何学习模块的通过都不能绕过该合取项。
2. `LCS` 的接受由引理 16 保证蕴含精确验证通过；`NCS` 的预测集只用于构造语义证书，最终仍受 `src_usc` 约束；`DCL` 只修改动作且要求 `src_usc` 对新动作通过。
3. 三条退化路径分别返回 `src_usc.admits` 的原结果，故 `Exec_v27 ⊆ Exec_v26` 在每种模式下成立；对 v26 以下的链，由 v26 已有引理 12 归纳保持。∎

### 定理（v27 的学习-对照双扩展安全-有效-可复现完备性）
**陈述**：对任意计划 `π`，`LC-UC.admits(π)=True` 当且仅当：
(1) `π` 通过 v26 七证（物理/语义/重构/协同/成本/记忆/可扩展）；
(2) 所有启用的学习代理均处于“可证包络有效且未超 `ε_sur`”的状态，或已回退精确验证；
(3) NCS 的分组覆盖在当前漂移门下仍满足 `≥1-α_g`（同时覆盖 `≥1-α`）；
(4) DCL 的投影求解器残差满足 `g(z̃) ≤ δ_max`；
(5) 对应学习/对照模块拥有**未过期且通过预注册检验**的 CCB 证据（Holm 校正后显著、效应量超 MDE、代价 TOST 等价、消融归因成立）。

**证明**：必要性由 `admits` 的合取结构与引理 16–20 直接得到：任一条件不满足即拒证或回退，不会误放行。充分性：v26 七证由引理 12 保证底层安全；引理 16 保证学习代理不放宽；引理 17 保证语义覆盖；引理 18 保证动作可行性；引理 19 保证证据的统计有效性；引理 20 保证整体包含关系。故五条件共同构成“学习只加速、不放宽，对照只证伪、不背书”的闭环。∎

## 4. 对照实验设计（本轮核心新增，可执行）

### 4.1 实验因素与基线

| 组别 | 配置 | 目的 |
|---|---|---|
| B0 | v26 精确七证（全量） | 安全/成本基线 |
| B1 | v26 + LCS（无回退，直接信任） | 负对照：验证“无包络学习”会误放行 |
| B2 | v26 + LCS（有回退，`ε_sur=0.05`） | 验证摊销收益与 soundness |
| B3 | v26 + NCS（手工分数 → 学习分数） | 验证分组覆盖与语义任务收益 |
| B4 | v26 + DCL（事后拒证 → 可微修复） | 验证可行性修复率与梯度质量 |
| B5 | v27 全量（LCS+NCS+DCL+CCB 证据门） | 完整方案 |
| B6 | v27 去掉 CCB 证据门 | 消融：证据门是否必要 |
| B7 | v27 打乱 NCS 分组（随机组） | 负对照：分组泄漏检测 |
| B8 | v27 的 LCS 用测试集校准（泄漏） | 负对照：证明包络不能靠测试集 |

### 4.2 预注册假设与统计协议

- **H1（安全）**：B5 相对 B0 的证书违规率不升，且 B1 显著升（证明回退必要）。
- **H2（成本）**：B5 的 P99 准入延迟相对 B0 降低 ≥30%，且 TOST 证明不劣于 B0 的 1.1 倍上界。
- **H3（语义）**：B3 的分组覆盖同时满足 `≥1-α`，且 NCS 相对手工分数的 R@K 提升 ≥3 个百分点（Holm 校正后）。
- **H4（可行性）**：B4 的相对 B0 的动作修复率提升，且 `g(z̃) ≤ δ_max` 的满足率 100%。
- **H5（归因）**：B5 相对 B6 的收益在 Holm 校正后显著，证明 CCB 证据门有独立贡献。

**统计流程**：
1. **配对**：同一场景 + 同一随机种子 + 同一初始状态，A/B 成对运行；`S≥200` 场景，`seeds≥5`。
2. **效应量**：连续指标用 Cohen's d，比例/有序指标用 Cliff's δ；报告点估计 + 配对 bootstrap 10⁴ 次的 95% CI。
3. **多重比较**：对 `m` 个预注册指标做 Holm–Bonferroni，控制 `FWER≤0.05`；未预注册指标只作探索性报告，不参与结论。
4. **等价性**：成本类指标用 TOST，等价界 `Δ_L=-0.1×B0, Δ_U=+0.1×B0`。
5. **功效**：由预实验估计 `σ_d`，用 `MDE=(z_{1-α}+z_{1-β})σ_d/√S` 反推 `S`，确保 `1-β_power≥0.8`；若 `S` 不足则只报告 CI，不报告“显著”。
6. **可复现**：固定种子、记录硬件/库版本、公开 `scenarios` 与 `pre_registered`、提供一键复跑脚本；负对照 B1/B7/B8 必须按预期失败，否则视为实验管道泄漏。

| 指标 | B0 (v26) | B5 (v27) 目标 | 判据 |
|---|---|---|---|

| B1 无回退违规率 | — | 显著高于 B0 | 负对照必须失败，证明回退必要 |

## 6. 本轮最大风险（最终确认）

**一句话**：**LCS 的误差包络在 OOD 下可能空洞化或失效，NCS 的分组覆盖在组内漂移下可能欠覆盖，DCL 的非凸投影可能破坏可行性，而 CCB 又可能被基准过拟合与选择性报告污染——四者叠加时，系统可能以“学习加速 + 统计显著”的外观，信任一个在分布外自信犯错、并由被污染证据背书的验证器，从而在群体级安全失效已发生时仍错误放行，破坏 v27 单调退化链的事前拦截承诺。**
