# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「排行榜」×「放置」）

> R69 把不确定性拆成 aleatoric / epistemic，并用「主动交互」去消解后者——问出「我该向谁求证」。但回头看，R69 其实**一直在偷偷用排行榜**：它给 K 个动作模态按权重排序、给候选信息动作按 VoI−成本排序、给证据源按判别力排序。它把排名结果当成事实，却从没问过：**这个排行榜本身可信吗？** 排行榜有三副面孔，R69 只看见了最好的一副：
> - 它会被**博弈**（Goodhart）：一旦「问」被奖励，模态头就会学会制造幻影歧义来骗取追问，因为「问了之后世界碰巧同意」会被记成成功；
> - 它会**循环**（Condorcet 悖论）：A 比 B 安全、B 比 C 安全、C 又比 A 安全，此时根本不存在单一冠军，强行塌缩就是选错；
> - 它会**过时**：环境漂移后，昨天的冠军今天可能是最危险的。
>
> 更根本的是：R69 的信任门 MCG 用 **ECE（绝对校准误差）** 做闸门，一旦概率标定不准就整层退回纯保守。但真实决策要的往往只是**序数**——「哪个模态更可能」而不是「它到底是 0.61 还是 0.49」。**排行榜天然只承诺序数，而序数对潜分数尺度上的单调失标是不变的。** 这正好补上 R69 最脆的假设。
>
> 本轮两个灵感各补一半：
> - **排行榜** → 把「绝对概率」降级为「成对比较 + 序数名次」，把「一次性排序」升级为「带密封 Gate、循环检测、漂移遗忘的可信排行榜」；
> - **放置** → 三重含义同时用上：(a) **搁置**——不立即兑现排名，把假设放上「搁置架」等世界自己给信息（等待的期权价值）；(b) **放置类游戏式的被动累积**——价值不必靠主动追问，会在长时程里自己长出来；(c) **放置点**——交互预算有限，把「看哪里 / 问谁 / 探哪里」当成一个排名分配问题。
>
> 核心命题：**把 R69 里隐式的、一次性的、基数的排行榜，替换为一个显式的、可延迟的、序数的、抗博弈/抗循环/抗漂移的排行榜；只有当名次在密封比较下稳定、且不值得再等时，才把它兑现为动作。** 命名 **IDLE-RAS**（Idle-Deferred Leaderboard Estimation for uncertainty-aware Risk-Adaptive Systems）——「被搁置的排行榜」。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这份排名值得信吗、现在就该信吗、还是先放一放**」。

## 0. 直觉与动机

**灵感 1（排行榜 → 序数是比基数更弱的信任要求）**
直觉：绝对概率要标定，序数只要「谁在谁前面」。温度缩放错了、系统偏保守或偏激进，都会让 ECE 爆表；但只要失真作用在**潜分数尺度**上且保持序关系，「A 比 B 更可能」依然成立。R69 的 MCG 用 ECE 当闸门，等于因为「尺子刻度不准」就把「谁更长」也一并作废。更好的做法是：**用成对比较（pairwise comparison）重建名次，用 OCE（序数校准误差）当新闸门**；只有需要在名次之上再要「差多少」的少数环节（λ 的幅度），才用保守下界而不是点估计。排行榜的智慧不是「给出一个分」，而是「给出一个在单调失真下不变的名次」。

**灵感 2（排行榜的第二副脸 → 它一定会被博弈）**
直觉：任何被排名的东西都会被优化。R69 一旦用 VoI 奖励「去问」，模态头和交互策略实际上就在同一张榜上竞争：制造一个幻影模态 → 追问 → 如果回答碰巧与幻影一致就记一次「成功」。这不是推理，是应试。防御不是把榜撤掉（那就退回 R69 的盲目），而是给榜加**留出集**：晋升必须靠**密封比较（sealed comparison）**——策略看不见、也无法影响的那部分比较结果。这就是排行榜经典的「训练集 vs 测试集」纪律：live 榜可以刷，sealed 榜刷不动。

**灵感 3（排行榜的第三副脸 → 循环意味着「不该有冠军」）**
直觉：成对比较可能非传递（Condorcet 循环）。这时任何「塌缩成单一冠军」的算法都在**制造一个不存在的共识**。R69 的「选一个最安全模态执行」默认了全序；R70 承认可能只有偏序：检测到循环就保留 Pareto 前沿，用 maximin 做决策，并把「持续循环」判定为情境依赖的不可约歧义（转入 R68/R69 保守）。这同时是对「排名拒绝攻击」的正面回应——攻击者能逼你做到的最坏情况，只是让你更保守，而不是让你选错。

**灵感 4（放置 → 搁置是「让世界替你验证」的期权）**
直觉：R69 只有两个动作——现在就问，或现在就埋（保守）。但很多歧义会自己消失：对方意图会显露，被遮挡的物体会进入视野，红灯会变绿。此时**主动去问既费预算又有风险**。正确做法是把假设**搁置**：保留一个活的后验、一个衰减率、一个再检查期限，让被动观测来消解它。这不是拖延，而是买入一个「等待的期权」——只有当「现在问的净收益」大于「等一会儿得到的免费信息 + 省下的成本」时才立即行动。**放置类游戏的核心机制正是这个：不操作也会积累。** 把它搬进不确定性管理，就是 **deferred VoI**。

**灵感 5（放置 → 放置点就是预算分配的排行榜）**
直觉：「放置」还有最直白的意思——**把注意力/探针/问题放在哪**。交互预算硬约束（R69：单位时间 ≤ 1 次），所以「放哪里」本身就是一个排名问题：按「每单位成本的信息增益」给候选放置点排序。但排名是噪声的、非平稳的，所以放置分配要用**稳定性门控的探索**（名次没稳定就别急着 exploitation），并给每个放置点一个衰减半衰期，防止一直往过时的「最佳点」上砸预算。

**灵感 6（合起来 → 排行榜从工具升格为被审计的对象）**
直觉：R69 相信「算出来的排序」；R70 把排序本身当成需要证据、需要留出、需要防循环、需要防过时的**一等公民**。这样 IDLE-RAS 与 R69 的关系非常干净：**R69 = 「即时结算、无搁置、信任基数、假设全序」的退化边界**。τ=0、OCE=0、图无环、无搁置时，IDLE 逐指令等于 R69。这不是并列替代，而是把 R69 最脆的那根假设（标定可信）换成一根更细但更硬的要求（序数可信 + 密封可信）。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（IDLE-RAS 总览）** IDLE-RAS = (POC, DEL, SHELF, PARE, SEALED, PLACE, DRIFT, RAS-WM†)。继承 R69 三不变式，并新增：
(iv) **序数优先**：任何交互/放置/执行决策都必须能由一个对单调失标不变的成对比较名次支撑；绝对分数只在名次确定后、用于幅度（λ）；
(v) **延迟不是不作为**：每个被搁置的假设必须携带 (活后验 π_H, 再检查期限 τ_recheck, 衰减 γ, 触发谓词 T)；无期限的搁置 = 泄漏，审计判否。

**定义 311（成对比较原语）** 对候选 i,j（模态 / 证据源 / 交互策略 / 放置点），比较查询给出 y_{ij} ∈ {i胜, j胜, 平}。胜率 p_{ij}；Bradley-Terry 潜变量 s_i：p_{ij}=σ(s_i−s_j)。在线更新采用 Elo 或 Bayesian BT。比较分 **live** 与 **sealed** 两条通道（定义 318）。

**定义 312（序数校准误差 OCE）** 将决策相关比较对按预测胜率分箱，OCE = Σ_b (n_b/N)|ŵ_b − w_b|。在 A99（失标为潜分数尺度上的严格单调变换 φ，如统一温度 / 共享偏置）下，成对胜负符号与 BT 名次不变，而 ECE 可任意增大；故 OCE 对这类失标鲁棒。MCG 门从「ECE ≤ τ_ece」升级为「OCE ≤ τ_oce（门控）∧ ECE 仅用于幅度」。

**定义 313（延迟证据排行榜 DEL）** 成对结果矩阵带指数遗忘：R_t = ρ R_{t−1} + Δ_t，ρ = 1/2^{1/h}（半衰期 h）。由 BT/最大似然提取名次；秩稳定性 Stab(i) = P(重采样后 rank(i) 不变)（对衰减后的比较做 bootstrap）。

**定义 314（晋升规则）** 源/策略 i 被**晋升**（可驱动决策）⇔ Stab(i) ≥ τ_stab ∧ sealed_win_rate(i) ≥ τ_seal ∧ i 不在活跃循环中。否则保持**搁置/临时**状态，决策走 R69/R68 兜底。

**定义 315（延迟信息价值 SHELF）** VoI_defer(g; τ) = max( VoI_now(g) − c(g), E[未来 τ 内被动累积的 VoI | 不主动问] − urgency·τ )。仅当「现在问」的净收益严格大于等待的期权价值且预算允许时立即交互；否则**搁置**假设 H，进入搁置架。

**定义 316（搁置架状态）** 搁置项 = (H, π_H, t_shelf, τ_recheck, γ, T(·))。再检查触发：被动观测偏差 > δ、到达期限、或预算盈余；搁置架容量有界（防无限堆积）。

**定义 317（非传递检测 PARE）** 在 top-k 上建比较图 G：i→j 若 i 显著胜 j。若 G 含环 ⇒ 非传递，**不塌缩为冠军**，返回安全向量上的 Pareto 集 𝒫，决策 = maximin(𝒫)；若环在连续 w 轮持续 ⇒ 判为情境依赖的不可约歧义，转 R68/R69 保守。

**定义 318（密封比较协议 SEALED）** 比较样本抽取自被排名策略不可见、不可影响的留出分布；密封结果仅在晋升判定时解封。「密封胜率」是晋升硬门，live 榜只用于探索。

**定义 319（放置分配器 PLACE）** 候选放置点 π ∈ Π（注视目标 / 探针位 / 问句主题）；按「每单位成本信息增益」排名分配预算，并采用**稳定性门控的探索**（名次未稳先探索、稳后才利用），受 P99 实时预算约束。

**定义 320（名次漂移与遗忘 DRIFT）** 排行榜半衰期 h；用 CUSUM / Page-Hinkley 在比较结果上检测变点。变点触发 ⇒ 冻结晋升、重置稳定计数、旧名次降为 shadow 直到重新稳定。

**定义 321（对 R69 的退化）** 当 τ=0（不搁置）、OCE=0（基数可信）、比较图无环、晋升恒真时，IDLE-RAS **逐指令等于** FLUID-RAS（R69）。R69 = 「即时结算、无搁置、全序」的边界。

**定义 322（排名博弈干扰集 ℰ_rank）** 策略性翻转比较以冲榜、比较者共谋、密封集泄漏、人为诱发循环以制造「排名拒绝」（denial-of-ranking）。并入 AIC：ℰ_IDLE = ℰ_FLUID × ℰ_rank。

**定义 323（排行榜审计 VQAuditor-L）** 审计：无密封胜率却晋升、过时冠军、被压制的循环、永久搁置泄漏、比较者被投毒。结论回灌 PARE/DRIFT 阈值与 PLACE 成本先验。

**定义 324（证书 J_IDLE）** J_IDLE = (J_FLUID, OCE, rank_stability_min, sealed_win_rate, shelf_size_p95, cycle_flag, deferral_ratio, idle_ver)。Valid ⇔ Valid(J_FLUID) ∧ OCE ≤ τ_oce ∧ 晋升集有密封胜率 ∧ 无搁置泄漏。

**定义 325（两级延迟与风险缩放）** 不可排名且不可搁置（如已过期限）⇒ R69 保守；已搁置且未过期 ⇒ 允许基于**期望被动消解**的临时 resolution bonus：Stab 高时 λ = λ_floor(U_ale)，否则 λ = λ_floor(U_ale + U_epi·1[deadline 已过])。期限一过仍未消解 ⇒ 立即回 R69 保守。安全侧单调不降。

**定义 326（自适应比较预算 / 锦标赛设计）** 每轮比较次数自适应：名次稳定时只做 1 次廉价校验；稳定性下降或变点触发时才做 top-k 循环赛。总比较成本受 P99 预算约束。

# IP-264 POC：成对比较 + Bradley-Terry 序数名次（替代绝对模态权重）
class PairwiseOrdinalComparator:
    def compare(self, i, j, sealed=False):
        return SEALED.sample(i, j) if sealed else LIVE.sample(i, j)   # i胜/平/j胜
    def update(self, i, j, y):
        self.elo.update(i, j, y)                    # s_i += eta*(y - sigma(s_i - s_j))
    def ranking(self):
        return bradley_terry_mle(self.pairs)        # 只承诺序数，不承诺绝对分
    def oce(self, bins):
        return ordinal_calibration_error(self.pairs, bins)

# IP-265 DEL：延迟证据排行榜（指数遗忘 + bootstrap 秩稳定性）
class DeferredLeaderboard:
    def __init__(self, half_life, tau_stab, tau_seal):
        self.R, self.half_life = {}, half_life
        self.tau_stab, self.tau_seal = tau_stab, tau_seal
    def step(self, delta):
        rho = 0.5 ** (1.0 / self.half_life)
        self.R = {k: rho * v for k, v in self.R.items()}          # 遗忘过时证据
        for (i, j), y in delta.items():
            self.R[(i, j)] = self.R.get((i, j), 0.0) + y
    def stability(self, i):
        return bootstrap_rank_prob(self.R, i)                      # P(重采样后名次不变)
    def promote(self, i):
        return (self.stability(i) >= self.tau_stab
                and sealed_win_rate(i) >= self.tau_seal
                and not self.in_active_cycle(i))

# IP-266 SHELF：延迟信息价值 / 等待期权
class ShelvingController:
    def deferred_voi(self, g, voi_now, cost, passive_rate, urgency):
        wait_value = passive_rate * urgency.horizon - urgency.cost
        return max(voi_now - cost, wait_value)                     # 立即 vs 等待
    def decide(self, modes, g):
        if self.deferred_voi(g, ...) <= 0:
            return ("shelve", self.track(modes))                   # 放上搁置架
        return ("act", g)
    def observe_passive(self, o):                                  # 世界自己给信息（idle 累积）
        self.shelf = {h: h.update(h.prior, o) for h in self.shelf}
    def recheck(self, h):                                          # 触发 / 期限 / 被动差异
        return h.triggered() or h.expired() or h.residual(o) > DELTA

# IP-267 PARE：非传递检测（Condorcet 循环 -> 不塌缩）
class ParetoCycleDetector:
    def decide(self, modes, topk):
        G = build_comparison_graph(modes, topk)
        if has_cycle(G):                                           # A>B>C>A
            P = pareto_front(modes, safety_vector)
            return minimax_safety(P)                               # 保留偏序，不造冠军
        return champion(G)

# IP-269 PLACE：放置点预算分配（稳定性门控的探索）
class PlacementAllocator:
    def best_placement(self, modes, budget):
        cand = [p for p in placements(modes) if budget.allow(p)]
        ranked = sort_by_info_per_cost(cand, self.del_ranks)
        return ranked[0] if self.del.promote(ranked[0]) else explore_gated(ranked)

# IP-274 IDLE-RAS 主闭环（R69 前段原样；仅替换“排序 -> 兑现”的环节）
def IDLE_RAS_round(M, obs):
    # ---- R69：一次前向 + 模态分解（保持不变）----
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    # ---- IDLE-1：只用序数，不用未经校准的绝对权重 ----
    ordinal_ok = (M.poc.oce() <= TAU_OCE)
    champ = M.del.champion(modes) if ordinal_ok else None
    # ---- IDLE-2：非传递就不塌缩 ----
    set_dec = M.pare.minimax(modes) if M.pare.cycle(modes) else champ
    # ---- IDLE-3：能等就等，不能等才放置 / 追问 ----
    g, resolved = None, False
    if ordinal_ok and champ is not None and M.del.promote(champ) and U_epi > TAU_EPI:
        g = M.place.best_placement(modes, M.budget)
        if g and M.shelf.deferred_voi(g, ...) > 0 and M.c_ras_wm.certify_info(g, o):
            M.del.step(M.cia.execute(g))                          # 只更新榜，不当场定案
        else:
            M.shelf.shelve(M.shelf.track(modes))                  # 放上搁置架
    M.shelf.observe_passive(o)                                    # idle 累积
    resolved = any(M.shelf.recheck(h) for h in M.shelf.items)
    # ---- R69：风险缩放（唯一差别是 resolved 的来源）----
    U_floor = U_ale + (0.0 if resolved else U_epi)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(...)
    mode = set_dec if set_dec is not None else select_mode(modes, lam)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_l.submit(g, M.del.snapshot(), resolved, M.shelf.size())
    return k, lam, mode, (U_ale, resolved)

## 3. 推导

**引理 19（序数鲁棒性）** 在 A99 下（失标 = 潜分数尺度上的严格单调 φ，如统一温度 / 共享偏置），成对胜负符号 sign(p_{ij}−1/2) 与 BT 名次均不变；而 ECE 可任意增大。故存在一类 OCE=0 却 ECE 爆表的失标，R69 的 MCG 会误退回纯保守，IDLE 的序数决策保持不变。系：**序数校准是比基数校准更弱、也更常成立的信任假设**——用名次换鲁棒性，用保守下界换幅度。

**引理 20（搁置占优）** 设被动信息到达率 r_p ≥ 0、主动问成本 c(g) > 0、假设不紧急（τ_recheck > 0）。若 E[未来 τ 内被动 VoI] ≥ r_p·τ − ε，则当即时净收益 VoI(g) − c(g) 小于等待期权价值时，搁置的期望效用 ≥ 立即交互；且当 r_p=0、假设紧急时退化为立即交互或保守（R69）。系：**不是所有 epistemic 都值得当场消解；等待本身有正价值，且它与 aleatoric 不同，会随时间自然减少。**

**引理 21（循环不可塌缩）** 若 top-k 比较图含长度 ≥ 3 的环，则任何基于该图的全序冠军选择在最坏情形下后悔 ≥ c·Δ（环上至少有一对被比较者的方向与全序相反）；而 maximin over Pareto 集的后悔上界与环的结构无关，仅由安全裕度决定。故「拒绝塌缩」不是保守癖好，而是非传递下的近最优。系：**排名拒绝攻击的最坏后果被限制为「更保守」，不会被诱导成「更错」。**

**定理 18（IDLE 严格包含 R69）** 在 A99–A101 下，任意状态 s，IDLE 的期望风险 ≤ R69；当 τ=0、OCE=0、图无环、晋升恒真时两者逐指令相同。因此 R69 = IDLE 的「即时结算、无搁置、全序」边界；安全不让步，效率来自（i）序数鲁棒、（ii）延迟省预算、（iii）密封抗博弈。

**定理 19（晋升的 Goodhart 抗性）** 若 sealed 比较 i.i.d. 抽自被排名策略不可影响的留出分布，则任何仅靠 live 榜刷分、真实密封胜率为 1/2+δ_g 的策略通过晋升（sealed_win_rate ≥ τ_seal）的概率 ≤ exp(−2n(τ_seal − 1/2 − δ_g)²)（Hoeffding），与 live 榜被操纵的程度无关。系：**live 榜可以刷，但刷不出晋升；被证实的错误必须先在密封集上赢。**

## 6. 本轮最大风险

**一句话**：IDLE-RAS 的全部收益押在「稳定且密封的名次 = 可信的真相」这一前提上——但**稳定的排名可能只是所有比较者共享了同一个偏差、一起过时了（共识的惰性），而搁置一个假设并不保证世界会替你消解它**；当环境不再提供有效被动信息或期限逼近时，「等」就从聪明的期权退化成昂贵的拖延，系统会带着一张漂亮而陈旧的排行榜、和一座越堆越高的搁置架，安静地错下去——**稳定地错，是一种更贵、更难被发现的不知道**。

**次级风险与缓解**：
1. 密封集泄漏 / 分布偏移导致「密封也刷得动」→ 密封集轮换 + 漂移检测 + 定理 19 的统计门；
2. 搁置架被填满、假设永不触发 → 定义 316 有界容量 + 期限强制再检查 + E307 泄漏审计；
3. 比较成本随候选数平方增长击穿实时预算 → 定义 326 自适应 1 次校验 / 仅在变点时循环赛；
4. 循环误判导致长期过度保守 → PARE 连续 w 轮才判不可约，且有 shadow 名次可恢复；
5. 传感器标定仍可能骗过一切序数比较（共享偏差恰是 A99 的盲区）→ 用 R69 的 FMA（Δa）与 R68 的 r_res 作为**正交**证据源并入 DEL，绝不让单一通道独占晋升。

class PairwiseOrdinalComparator:
    def compare(self, i, j, sealed=False):
        return SEALED.sample(i, j) if sealed else LIVE.sample(i, j)
    def update(self, i, j, y): self.elo.update(i, j, y)
    def ranking(self):         return bradley_terry_mle(self.pairs)
    def oce(self, bins):       return ordinal_calibration_error(self.pairs, bins)

# IP-265 DEL：带遗忘与秩稳定性的延迟证据榜
class DeferredLeaderboard:
    def step(self, delta):
        rho = 0.5 ** (1.0 / self.half_life)
        self.R = {k: rho * v for k, v in self.R.items()}          # 遗忘过时证据
        for (i, j), y in delta.items():
            self.R[(i, j)] = self.R.get((i, j), 0.0) + y
    def stability(self, i): return bootstrap_rank_prob(self.R, i)
    def promote(self, i):
        return (self.stability(i) >= self.tau_stab
                and sealed_win_rate(i) >= self.tau_seal
                and not self.in_active_cycle(i))

# IP-266 SHELF：等待期权
class ShelvingController:
    def deferred_voi(self, g, voi_now, cost, passive_rate, urgency):
        return max(voi_now - cost, passive_rate * urgency.horizon - urgency.cost)
    def decide(self, modes, g):
        return ("act", g) if self.deferred_voi(g, ...) > 0 else ("shelve", self.track(modes))
    def observe_passive(self, o):                                 # idle 累积
        self.shelf = {h: h.update(h.prior, o) for h in self.shelf}
    def recheck(self, h):
        return h.triggered() or h.expired() or h.residual(o) > DELTA

# IP-267 PARE：非传递不塌缩
class ParetoCycleDetector:
    def decide(self, modes, topk):

        if has_cycle(G):                                          # A>B>C>A
            return minimax_safety(pareto_front(modes, safety_vector))
        return champion(G)

## 4. 推导

**引理 19（序数鲁棒性）** A99（失标 = 潜分数尺度上的严格单调 φ，如统一温度 / 共享偏置）下，成对胜负符号与 BT 名次不变，而 ECE 可任意增大；故存在 OCE=0 却 ECE 爆表的失标，R69 的 MCG 会误退回纯保守，IDLE 的序数决策不变。系：序数校准是比基数校准更弱、也更常成立的信任假设。

**引理 20（搁置占优）** 被动到达率 r_p ≥ 0、主动成本 c(g) > 0、假设不紧急时，若即时净收益小于等待期权价值，则搁置期望效用 ≥ 立即交互；r_p=0 且紧急时退化 R69。系：等待有正价值，且 epistemic 会随时间自然减少。

**引理 21（循环不可塌缩）** top-k 比较图含长度 ≥ 3 的环时，任何全序冠军选择最坏后悔 ≥ c·Δ；maximin over Pareto 的后悔上界与环结构无关。系：排名拒绝攻击最坏只逼你更保守，不会让你更错。

**定理 18（IDLE 严格包含 R69）** A99–A101 下任意状态 IDLE 期望风险 ≤ R69；`τ=0 ∧ OCE=0 ∧ 无环 ∧ 晋升恒真` 时逐指令相同。R69 = 「即时结算 / 无搁置 / 全序」边界；安全不让步，效率来自序数鲁棒、延迟省预算、密封抗博弈。

**定理 19（晋升 Goodhart 抗性）** sealed 比较 i.i.d. 抽自策略不可影响的留出分布时，仅刷 live 榜、真实密封胜率 1/2+δ_g 的策略通过晋升的概率 ≤ `exp(−2n(τ_seal−1/2−δ_g)²)`（Hoeffding），与 live 榜被操纵程度无关。系：live 榜可以刷，但刷不出晋升。

## 7. 本轮最大风险

**一句话**：IDLE-RAS 的全部收益押在「稳定且密封的名次 = 可信的真相」这一前提上——但**稳定的排名可能只是所有比较者共享了同一个偏差、一起过时了（共识的惰性），而搁置一个假设并不保证世界会替你消解它**；当环境不再提供有效被动信息或期限逼近时，「等」就从聪明的期权退化成昂贵的拖延，系统会带着一张漂亮而陈旧的排行榜、和一座越堆越高的搁置架，安静地错下去——**稳定地错，是一种更贵、更难被发现的不知道**。

**次级风险与缓解**：密封集泄漏 / 分布偏移（密封集轮换 + 漂移检测 + 定理 19 统计门）；搁置架填满且永不触发（定义 316 有界容量 + 期限强制再检查 + E307 审计）；比较成本随候选数平方增长击穿实时预算（定义 326 自适应 1 次校验 / 仅变点循环赛）；循环误判导致长期过度保守（连续 w 轮才判不可约 + shadow 名次可恢复）；传感器标定骗过序数比较（共享偏差是 A99 盲区 → 把 R69 的 FMA 与 R68 的 r_res 作为正交证据源并入 DEL，绝不单通道独占晋升）。
