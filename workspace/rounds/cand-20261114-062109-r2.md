# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「视觉编码器」×「目标检测」）

> R69 教会系统「问」，并把不确定性拆成 aleatoric / epistemic。但它有一个从未被审查的本体论假设：**模态是先验存在的、可直接加权的对象**。R69 的模态来自流策略自己的 K 个采样与一次轨迹聚类——权重 ŵ_k = |m_k|/K 是「样本密度」，不是「有证据支持的置信度」。于是 R69 自陈的最大风险被具体化为两件事：
> - **幻觉模态**（没有真实指称的采样簇）被当成一个可追问的候选，系统于是去问一个幻影；
> - **坍缩模态**（真实存在、但采样稀少或被聚类吞并的候选）根本不进入后验，系统连「我漏掉了什么」都不知道。
> 这两件事在纯生成模型内部**不可观测**：它只有自己的样本，没有外部参照。
>
> 本轮两个灵感提供的正是「外部参照」与「集合级纪律」：
> - **视觉编码器**给出一个冻结的、可认证的**指称空间**：动作模态必须先落到观测中的某个证据区域（哪个杯、哪个人、哪个缝隙），才有资格被称为「一个可问的对象」；
> - **目标检测**给出**集合预测**的整套方法论：object query、Hungarian 一一匹配、NMS、objectness 校准、背景/未知类、precision/recall。它把「模态权重可信吗」从一个自指的校准问题，变成一个**可对着外部证据审计的检测问题**。
>
> 核心命题：**一个不确定性只有在被「接地」为一个检测对象之后，才允许被交互消解；接不上地的模态不是待问的歧义，而是不可问的未知。** 命名 **GOLD-RAS**（Grounded Object-Level Detection for risk-adaptive systems）。一句话：R69 问「我该向谁求证」，R70 先问「**我说的那个『谁』，真的在场上吗**」。

## 0. 直觉与动机

**灵感 1（视觉编码器 → 把「关于什么」变成可计算的对象）**
直觉：R69 的模态是动作轨迹，它天然回答「怎么做」，却不回答「对什么做」。但人类的犹豫几乎总是**指称犹豫**：不是「怎么抓」不清楚，而是「抓哪一个」不清楚。视觉编码器（冻结、自监督、带局部 Lipschitz 与鲁棒性半径证书）把观测切成区域证据场；一个动作模态若真是关于场景中某物的，就应能预测它在证据场中的**支撑区域**（要抓的杯、要绕过的人、要穿过的缝）。于是「模态—证据」的对应关系成了一个可以 Hungarian 匹配的几何/嵌入问题。R69 的模态由此从「无根的样本簇」变成「有指称的对象」。

**灵感 2（目标检测 → 模态是「检测对象」，不是「聚类结果」）**
直觉：R69 用 DTW/Fréchet 聚类给模态和权重，但聚类是启发式、不可微、对阈值敏感；它的权重是样本频率，天生过自信。目标检测处理的恰是同一类问题：**在一个开放场景里，用固定大小的集合预测『有哪些对象』，用一一匹配消除重复，用校准后的 objectness 表达『这真的是一个对象吗』，并用背景类表达『这里什么都没有』**。把模态看作检测对象，R69 的两个盲点立刻变成可测指标：幻觉模态 = 未匹配的检测（假阳 FP）；坍缩模态 = 未被任何模态匹配的高证据区域（假阴 FN）。**R69 只能看见自己想到了什么；R70 第一次能看见自己没想到什么。**

**灵感 3（三分而非二分 → 「未知」不是「歧义」）**
直觉：R69 的 U_epi 把两件事混在一起：(a) 我知道有几个**可指认**的候选，只是不知道选哪个；(b) 场上似乎有东西，但我**指不出来、叫不出、甚至不知道它算不算一个候选**。前者可以问（「左边这个还是右边这个？」），后者不该问——问一个指不出来的东西，只会得到幻觉式的答案。检测的「背景/未知类」正好提供这个区分：把不确定性分成 U_ale（模态内噪声）、U_epi^g（已接地的可问歧义）、U_nov（未接地/未知本体的不可问未知）。**可问性（interrogability）成为交互的硬前置条件，而不是 VoI 的一个乘子。**

**灵感 4（主动检测 → 注视就是「提高召回」，探针就是「拉开两个对象」）**
直觉：R69 的 gaze/probe 是信息动作，但它的 VoI 是在「模态权重」上算的。改写成检测语言后，它们有了更精确的语义：**注视 = 选择 ROI 去降低假阴（找出现在场但没被检测到的证据）**；**探针 = 施加一个物理动作，使两个已接地候选的效应区域分离，从而让检测器把它们分开**；**问句 = 只用指称（deictic）方式确认已接地且已命名的候选**。同一套 VoI，现在作用在「集合的歧义」上：VoI(g) = E[H(S) − H(S')]，S 为接地模态集合。这比 R69 在簇权重上算熵更接近信息的真实来源。

**灵感 5（接地是新的攻击面 → 需要「接得很牢的谎言」威胁模型）**
直觉：R69 的漏洞是「模型可以幻觉一个模态」；R70 的漏洞升级为「攻击者可以为幻觉**制造证据**」——对抗补丁、摆拍物体、被投毒的类无关区域提议，都能让一个假模态通过 Hungarian 匹配与 objectness 校准。更隐蔽的是**漏检**：检测器对稀有但关键的模态系统性低召回，于是系统对「剪掉了正确模态」毫无察觉，反而更自信。所以本轮必须同时交付：objectness 校准、recall 审计（MRA）、编码器证书与补丁防御、以及**接地质量下限 ε_u**——让接地只能「降低但不能清零」先验支持，从而在最坏情况下仍被 R69 兜住。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（GOLD-RAS 总览）** GOLD-RAS = (VEG, MOD, GRO, OCG, IAG, ADA, GCA, MRA, ECP, RAS-WM‡)。四不变式：继承 R69 的 (i) 实时零学习写操作、(ii) 交互预算、(iii) 证据纪律；新增 (iv) **接地优先**：任何模态在进入交互候选集前必须通过接地门（定义 314–317），未接地模态只能进入 U_nov 与保守通道，绝不进入问句。

**定义 311（证据场与类无关区域）** 冻结视觉编码器 Φ_v（带局部 Lipschitz 常数 L_Φ 与鲁棒性半径 ρ_Φ 的证书）。类无关区域提议器 P 产生观测 o 的证据区域集合 R(o) = {r_i}（框/掩码 + 嵌入 e_i = Pool(Φ_v(o), r_i)），不做语义分类。记证据场 E(o) = {(r_i, e_i, s_i^r)}，s_i^r 为区域 objectness（校准见 313）。**关键：接地只需要「指称」，不需要「命名」**——开放本体下仍可问「是这一个吗」，只要指得出来。

**定义 312（模态-对象与效应区域）** 对 R69 的模态 m_k（动作轨迹），接地头 ψ 预测其**支撑区域** b_k（该动作「关于」的观测区域）与嵌入 e_k^m，并要求效应一致性：动作导致的预期变化区域与 r_i 的几何/嵌入相容。模态-对象 o_k = (m_k, b_k, e_k^m, s_k^o)，s_k^o 为模态 objectness。

**定义 313（objectness 校准）** 在带接地真值的 held-out 片段上，对 s_k^o、s_i^r 做温度/等渗校准，得校准分与逐类 ECE。**模态权重不再等于聚类频率**：接地似然 L_k = exp(−C_{k,A(k)}/τ_g)（匹配则用匹配代价，未匹配则 ε_0），后验按贝叶斯融合 w_k^g ∝ ŵ_k · L_k。

**定义 314（接地匹配 GRO）** 代价 C_{k,i} = λ_e‖e_k^m − e_i‖² + λ_g·GIoU(b_k, r_i) + λ_eff·effect_mismatch，Hungarian 求一一匹配 A；C_{k,A(k)} ≤ τ_g 为已接地。对模态-对象做 NMS（GIoU/嵌入相似度）去重。未匹配模态 = **幻影候选（FP）**；未匹配且高 objectness 的区域 = **漏检候选（FN）**。

**定义 315（接地质量下限与稳健后验）** w̃_k = (1−ε_u)·w_k^g + ε_u·ŵ_k，ε_u ∈ [0,1]。ε_u=1 ⇒ 完全不用接地 ⇒ 逐指令回到 R69；ε_u=0 ⇒ 完全信任接地。**ε_u 是信念空间的「安全下限」，与 R68/R69 在动作空间的 λ_floor 对偶**：它保证接地错误（尤其漏检）不能把先验支持清零，从而不能制造虚假确定性。

**定义 316（三分不确定性）**
- U_ale = Σ_k w̃_k tr Σ_k；
- U_epi^g = H(w̃|_{已接地且可指称})·g(Δ_min)（**可问**：已知候选集合内的选择歧义）；
- U_nov = 1 − Σ_{已接地可指称} w̃_k（**不可问**：未接地的质量 + 高证据区域的未知质量）。
三者语义不同，分通道处置；R69 的 U_epi 恰为 U_epi^g + U_nov 在 ε_u=1、无未知类时的退化。

**定义 317（可问性谓词 IAG）** 一个模态可被追问 iff：已接地（314）∧ 有指称（存在 b_k 与匹配区域）∧ objectness 校准可信（ECE ≤ τ_ece）∧ 决策相关（移除该模态会改变安全最优动作超过 δ）。可问性是对交互的**硬门**，不是乘子：不可问模态的 VoI 定义为 0，且不进入候选枚举。

**定义 318（开放本体门 OCG）** 若证据区域存在高 objectness 但语义/嵌入距已知本体远（开集未知），或 U_nov 超过阈值，则禁止在环内追问，改为：保守执行 + 记入「本体缺口」审计 + 请求**系统级**（非实时、带人）澄清。开集未知 ≠ 背景：背景是「确实没有可指称对象」，未知是「有对象但我不认识」。

**定义 319（接地一致性通道 GCA）** 标定校正前后证据场的一致性 Δg = d_OT(E(o), E(o_cal))（区域集合的最优传输距离，按质量加权）。与 R68 的 r_res、R69 的 Δa 组成三通道 (r_res, Δa, Δg)。Δg 测「标定是否改变了**指称结构**」，是对「标定把故障解释掉」的第二重外部检查。

**定义 320（主动检测动作 ADA）** g_gaze 选择 ROI 以最大化期望召回增量（降低 FN 质量）；g_probe 施加物理动作以最大化已接地候选间的效应区域分离（提高 Δ_min/可检测性）；g_ask 仅对可问模态生成**指称式**问句（「左边这个，还是右边这个？」），不要求语义标签。三者与任务动作共享 R69 的增广动作空间与 C-RAS-WM† 认证。

**定义 321（检测感知 VoI）** VoI(g) = E[H(S|o) − H(S|o,y_g)]，S 为接地模态集合（含未匹配区域的漏检质量）。g* = argmax[VoI − c]，且仅在 U_epi^g > τ_epi 且 IAG 通过时启用；否则退化 R69/R68。

**定义 322（证据纪律升级）** 交互后的定案需至少两个**正交**证据源一致：{残差 r_res, 流似然 Δa, 接地结构 Δg/检测一致性}。**一个检测器只算一个源**，不得用自己的 objectness 自证；单源（包括单次人类回答）仍不得定案。检测一致性通过「同一区域在两种观测/两个视角下是否仍可匹配」来衡量。

**定义 323（模式召回审计 MRA）** 维护一个旁路监视器：对每个高 objectness 但未被任何模态匹配的区域，记录「潜在漏检」。若漏检质量随时间上升或与任务失败相关，则触发：降低 ε_u（更信接地）之前必须先提高召回，或直接回退保守。**这是 R69 完全没有的监视器——它审计「我没想到什么」，而非「我想到的有多准」。**

**定义 324（编码器证书与补丁防御 ECP）** 冻结 Φ_v 附证书 (L_Φ, ρ_Φ, 训练分布半径)；监测：区域嵌入的上下文不一致、随机平滑下的区域分类稳定性、跨帧证据漂移。检测到补丁/对抗区域或编码器越出证书半径 ⇒ 接地不可信 ⇒ ε_u := 1（精确回退 R69），并触发 GCA 告警。

**定义 325（证书 J_GOLD）** J_GOLD = (J_FLUID, grounding_precision, grounding_recall, objectness_ece, phantom_rate, unknown_rate, mode_F1, encoder_drift, epsilon_u, grounding_log_hash, gold_ver)。Valid ⇔ Valid(J_FLUID) ∧ objectness_ece ≤ τ_ece ∧ 接地门与证据纪律满足 ∧ 编码器在证书内。

**定义 326（威胁模型 ℰ_GOLD 与调度）** ℰ_GOLD = ℰ_FLUID × ℰ_ground，ℰ_ground 含：对抗补丁/摆拍物体（制造接得很牢的假模态）、类无关提议投毒、检测器系统性漏检、指称歧义攻击（故意把两个对象做成几乎一样）、跨模态共谋（证据与回答一起演）。调度：默认只在 R69 的歧义路径（mode_head 报歧义）运行 ROI 级检测，全局嵌入缓存，P99 增量预算见 §4。

## 2. 关键算法骨架

```python
# IP-264/265 VEG+MOD：证据场与模态-对象（冻结编码器，零语言/检测训练）
def build_evidence(encoder, o):
    regions = class_agnostic_proposals(o)                 # 不做语义分类
    E = [(r, encoder.roi(o, r), region_objectness(r)) for r in regions]
    return E

def make_mode_objects(modes, E, psi):
    objs = []
    for m in modes:
        b, e = psi.support_and_effect(m)                  # 动作「关于」哪里
        objs.append(ModeObj(m=m, box=b, emb=e, s=mode_objectness(m)))
    return objs

# IP-266 GRO：Hungarian 一一匹配 + NMS + 幻影/漏检
def ground(objs, E, tau_g):
    C = cost_matrix(objs, E)                              # 嵌入+GIoU+效应
    A = hungarian(C)
    grounded = [(k, i) for k, i in A if C[k, i] <= tau_g]
    phantoms = [k for k in range(len(objs)) if k not in {k for k,_ in grounded}]
    missed   = [i for i in range(len(E)) if i not in {i for _,i in grounded}
                and E[i].s > TAU_OBJ]
    objs = nms(objs, grounded)                            # 去重
    return grounded, phantoms, missed

# IP-267/268/270 OCG+IAG+GCA：三分、可问性、第三通道
def decompose_grounded(objs, grounded, prior_w, eps_u):
    L    = grounding_likelihood(objs, grounded)           # 未匹配 -> eps0
    w_g  = normalize(prior_w * L)
    w    = (1-eps_u)*w_g + eps_u*prior_w                  # 质量下限，eps_u=1 -> R69
    U_ale = sum(w[k]*trace(cov(objs[k].m)) for k in range(len(objs)))
    U_epi = entropy(w[interrogable(objs, grounded)]) * sep_factor(objs)
    U_nov = 1 - w[interrogable(objs, grounded)].sum()
    return U_ale, U_epi, U_nov, w

def interrogable(objs, grounded):
    return [k for k,_ in grounded
            if objs[k].ece <= TAU_ECE and decision_relevant(objs[k])]

# IP-269/271 ADA：注视=提召回，探针=拉开对象，问句=指称确认
def choose_action(objs, missed, budget):
    cands = []
    if missed:  cands += gaze_rois(missed)                # 找出现在场但没检测到的
    cands += probe_actions(objs, grounded)                # 最大化效应区域分离
    cands += [ask(k) for k in interrogable(objs, grounded)]
    return best_by_voi_minus_cost(cands, budget)          # 无利可图/不可问 -> None

# IP-273 主闭环：R69 上插入「接地门」，失败即精确回退
def GOLD_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(o)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    modes = M.fmp.sample(o, K)
    if not M.mode_head_ambiguous and not M.gca.suspect(o):
        return M.fluid_round(modes, o, z)                 # 常规路径：零检测开销
    # 歧义/疑似故障路径：先接地，再决定「能不能问」
    if not M.ecp.certified(o):                             # 编码器/补丁不可信
        return M.fluid_round(modes, o, z, eps_u=1.0)       # 精确回退 R69
    E      = build_evidence(M.veg, o)
    objs   = make_mode_objects(modes, E, M.mod)
    gr, ph, miss = ground(objs, E, TAU_G)
    U_ale, U_epi, U_nov, w = decompose_grounded(objs, gr, mode_prior(modes), EPS_U)
    tri = M.gca.three_channel(o, o_cal)                    # (r_res, da, dg)
    if U_nov > TAU_NOV or M.ocg.open_set(E, gr):
        g = None                                           # 未知不可问：只保守+升级
    else:
        g = choose_action(objs, miss, M.budget)            # 可问才问
    if g is not None:
        ans = M.cia.execute(g); U_epi = M.cia.update_belief(objs, gr, ans)
    U_floor = U_ale + U_epi + U_nov                        # 未消解/未知都收紧
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    if tri.suspicious or M.ecp.untrusted:
        lam = max(lam, LAMBDA_GOLD); k = min(k, k_cal_shrink(...))
    mode = select_mode(objs, gr, w, U_epi, lam)
    M.vqa_g.submit_async(gr, ph, miss, U_nov, tri, g, ans)
    return k, lam, mode, (U_ale, U_epi, U_nov, tri)
```

## 3. 推导

**引理 19（幻影追问率的外生上界）** 设接地匹配对「无真实指称的模态」的假阳率为 α（在带真值片段上可测），则 GOLD 追问幻影的概率 ≤ α + (1−α)·1[U_epi>τ]。对比 R69：其幻影率只由模态权重的自指校准误差 ECE 控制，且**不可外部审计**。要点：R70 把这个概率换成一个可用 held-out 接地真值直接估计的量——这是认识论上的进步（可证伪），不是数值上的绝对下降；当检测器有偏时 α 可能大于 ECE。

**引理 20（漏检可观测性）** R69 的漏检（真模态未被采样/被聚类吞并）在其自身后验中概率质量为 0，不可观测。GOLD 定义漏检质量 μ_miss = Σ_{未匹配高 objectness 区域} s_i^r / Z；在检测召回 ρ 下，μ_miss ≥ (1−ρ)·μ_true。故 GOLD 能在 R69 完全盲视的失效模式上给出正的告警信号；代价是新增一个假阴来源（检测器本身）。系：**R70 的安全性取决于召回，而不只是精度**。

**引理 21（质量下限的稳健性）** 对任意接地似然 L（包括被对抗操纵、把真模态判为未匹配），有 w̃ ≥ ε_u·ŵ（逐分量）。因此接地最多把真模态的先验支持压到 ε_u 倍，不会清零。若任务损失对模态选择是 L-Lipschitz，则最坏情况下相对 R69 的风险增量 ≤ L·ε_u·TV(ŵ)。ε_u=1 时增量为 0（R69 边界），ε_u=0 时无此保护。**这把「接地风险」变成一个显式可调、可认证的量，而不是一个隐藏假设。**

**定理 18（GOLD 严格包含 FLUID）** 在 A99–A102 下：(a) ε_u=1 或编码器不可信或 U_nov 越界时，GOLD 与 FLUID 逐指令相同；(b) 接地可信且 ε_u<1 时，GOLD 只在「已接地可指称候选」上交互，U_nov 全部进保守通道，故其交互集合 ⊆ FLUID 的交互集合；(c) 由引理 21，任意接地错误造成的风险增量 ≤ L·ε_u·TV(ŵ)。因此 **FLUID 是 GOLD 在「完全不接地」边界上的退化，GOLD 的安全侧永不弱于 FLUID 加上一个可显式控制的 ε_u 项**。

**定理 19（接地不能制造新模态 / 无免费午餐）** 接地只做两件事：对已有模态做似然重加权与去重，以及对证据区域做指称。它不产生新的任务动作（除注视/探针等已认证的信息动作）。故 GOLD 的可执行任务动作集 ⊆ R69 的动作集（经重加权）。推论：**若接地把唯一正确模态判为幻影（漏检），GOLD 会比 R69 更自信地犯错**；所以精度不能替代召回，必须有 MRA 与 ε_u。这也是本轮不宣称「接地=真实」的形式化表达。

**引理 22（主动检测的 VoI 分解）** 在 A99 下，注视的期望信息增益主要来自降低漏检质量（∂VoI/∂μ_miss > 0），探针的增益主要来自增大已接地候选的 Δ_min（∂VoI/∂Δ_min > 0）；二者与 R69 的「在簇权重上算熵」相比，把信息增益锚定到可观测的集合变化 S→S'。系：当无高 objectness 未匹配区域且已接地候选间距已大时，所有信息动作的 VoI−c ≤ 0，自动退化 R69 的「不问」。

## 6. 本轮最大风险

**一句话**：GOLD-RAS 把信任从「模型的模态权重可信吗」换成了「检测器找到的证据可信吗」，但证据是**可以被布置的**——对抗补丁、摆拍物体能制造一个**接得很牢的假模态**，而真正关键的稀有模态又可能被检测器系统性漏检（召回失败）；此时质量下限 ε_u 只能保证不比 R69 更糟，却无法保证「接地」等于「真实」——**被定位的谎言，比没被定位的歧义更危险**。

**次级风险与缓解**：
1. **漏检造成过度自信**（剪掉正确模态）→ 引理 20–21 + MRA 召回审计 + ε_u 质量下限，ε_u 不得在召回未达标时降低；
2. **接地证据可伪造**（补丁/摆拍/提议投毒）→ ECP 编码器证书 + 随机平滑 + 跨视角一致性 + ℰ_ground 对抗训练；
3. **开放本体误问**（把未知当已知追问）→ OCG 硬门 + 「未知≠背景」纪律 + 只在指称层发问；
4. **检测延迟击穿实时预算** → 仅在歧义路径运行 + 全局特征缓存 + ROI 级检测 + 不可信时零检测回退；
5. **检测器单源自证** → 一个检测器只算一个证据源，定案需三通道中至少两源一致（定义 322）。

## 3. 关键算法伪代码

```python
# IP-264/265 VEG+MOD：证据场与模态-对象（冻结编码器）
def build_evidence(encoder, o):
    regions = class_agnostic_proposals(o)                 # 不做语义分类
    return [(r, encoder.roi(o, r), region_objectness(r)) for r in regions]

def make_mode_objects(modes, E, psi):
    return [ModeObj(m=m, **(lambda b,e: dict(box=b, emb=e,
            s=mode_objectness(m)))(*psi.support_and_effect(m))) for m in modes]

# IP-266 GRO：Hungarian 一一匹配 + NMS + 幻影/漏检
def ground(objs, E, tau_g):
    A = hungarian(cost_matrix(objs, E))                   # 嵌入+GIoU+效应
    grounded = [(k,i) for k,i in A if C[k,i] <= tau_g]
    phantoms = [k for k in range(len(objs)) if k not in {k for k,_ in grounded}]
    missed   = [i for i in range(len(E)) if i not in {i for _,i in grounded}
                and E[i].s > TAU_OBJ]
    return grounded, phantoms, nms(objs, grounded), missed

# IP-267/268/270 OCG+IAG+GCA：三分、可问性、第三通道
def decompose_grounded(objs, grounded, prior_w, eps_u):
    w_g = normalize(prior_w * grounding_likelihood(objs, grounded))
    w   = (1-eps_u)*w_g + eps_u*prior_w                   # eps_u=1 -> R69
    inter = interrogable(objs, grounded)
    U_ale = sum(w[k]*trace(cov(objs[k].m)) for k in range(len(objs)))
    U_epi = entropy(w[inter]) * sep_factor(objs)
    U_nov = 1 - w[inter].sum()
    return U_ale, U_epi, U_nov, w

# IP-269/271 ADA：注视=提召回，探针=拉开对象，问句=指称确认
def choose_action(objs, grounded, missed, budget):
    cands = gaze_rois(missed) + probe_actions(objs, grounded) \
          + [ask(k) for k in interrogable(objs, grounded)]
    return best_by_voi_minus_cost(cands, budget)          # 无利可图/不可问 -> None

# IP-273 主闭环：R69 上插入「接地门」，失败即精确回退
def GOLD_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(o)
    modes = M.fmp.sample(o, 1 if M.fmp.mode_head(z) < TAU_MODE else 4)
    if not M.mode_head_ambiguous and not M.gca.suspect(o):
        return M.fluid_round(modes, o, z)                 # 常规路径：零检测开销
    if not M.ecp.certified(o):
        return M.fluid_round(modes, o, z, eps_u=1.0)       # 编码器不可信 -> 精确回退
    E = build_evidence(M.veg, o); objs = make_mode_objects(modes, E, M.mod)
    gr, ph, objs2, miss = ground(objs, E, TAU_G)
    U_ale, U_epi, U_nov, w = decompose_grounded(objs2, gr, mode_prior(modes), EPS_U)
    tri = M.gca.three_channel(o, o_cal)                    # (r_res, da, dg)
    g = None if (U_nov > TAU_NOV or M.ocg.open_set(E, gr)) \
              else choose_action(objs2, gr, miss, M.budget)
    if g is not None:
        U_epi = M.cia.update_belief(objs2, gr, M.cia.execute(g))
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi + U_nov))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    if tri.suspicious or M.ecp.untrusted:
        lam = max(lam, LAMBDA_GOLD); k = min(k, k_cal_shrink(...))
    mode = select_mode(objs2, gr, w, U_epi, lam)
    M.vqa_g.submit_async(gr, ph, miss, U_nov, tri, g, U_epi)
    return k, lam, mode, (U_ale, U_epi, U_nov, tri)
```

## 4. 推导

**引理 19（幻影追问率的外生上界）** 设接地对无真实指称模态的假阳率为 α（held-out 可测），则追问幻影概率 ≤ α + (1−α)·1[U_epi>τ]。对比 R69：幻影率仅由自指 ECE 控制且不可外部审计。要点：R70 把该概率换成一个可用接地真值直接估计、因而**可证伪**的量；当检测器有偏时 α 可能大于 ECE，故不承诺绝对下降。

**引理 20（漏检可观测性）** R69 中坍缩模态的后验质量为 0、不可观测。定义 `μ_miss = Σ_{未匹配高 objectness} s_i^r/Z`，检测召回 ρ 下 `μ_miss ≥ (1−ρ)μ_true`。故 GOLD 能在 R69 的盲区给出告警；代价是引入检测器自身的假阴。系：**安全性取决于召回，不只是精度**。

**引理 21（质量下限稳健性）** 对任意接地似然（含对抗操纵），`w̃ ≥ ε_u ŵ` 逐分量成立。若任务损失对模态选择 L-Lipschitz，则最坏风险增量 ≤ `L·ε_u·TV(ŵ)`；ε_u=1 时增量为 0。**把接地风险变成显式可调、可认证的量。**

**引理 22（主动检测 VoI 分解）** 注视增益主要来自降低 μ_miss（∂VoI/∂μ_miss>0），探针增益主要来自增大 Δ_min；信息增益锚定到可观测的集合变化 S→S'。当无未匹配高证据区域且候选间距已大时，所有 VoI−c ≤ 0，自动退化 R69 的「不问」。

**定理 18（GOLD 严格包含 FLUID）** A99–A102 下：(a) ε_u=1、编码器不可信或 U_nov 越界 ⇒ 与 FLUID 逐指令相同；(b) 接地可信时交互集合 ⊆ FLUID 的交互集合；(c) 任意接地错误的风险增量 ≤ `L·ε_u·TV(ŵ)`。**FLUID = GOLD 的「完全不接地」边界；安全侧永不弱于 FLUID。**

**定理 19（接地不能制造新模态）** 接地只重加权/去重已有模态并对区域做指称，不生成新任务动作（除已认证信息动作），故可执行动作集 ⊆ R69 的动作集。推论：若接地把唯一正确模态判为幻影，GOLD 会比 R69 更自信地犯错——**精度不能替代召回**，故必须有 MRA 与 ε_u。

## 7. 本轮最大风险

**一句话**：GOLD-RAS 把信任从「模型的模态权重可信吗」换成了「检测器找到的证据可信吗」，但证据是**可以被布置的**——对抗补丁、摆拍物体能制造一个**接得很牢的假模态**，而真正关键的稀有模态又可能被检测器系统性漏检（召回失败）；此时质量下限 ε_u 只能保证不比 R69 更糟，却无法保证「接地」等于「真实」——**被定位的谎言，比没被定位的歧义更危险**。

**次级风险与缓解**：漏检致过度自信（引理 20–21 + MRA + ε_u 不得在召回未达标时降低）；接地证据可伪造（ECP 证书 + 随机平滑 + 跨视角一致性 + ℰ_ground 对抗训练）；开放本体误问（OCG 硬门 + 「未知≠背景」）；检测延迟击穿预算（仅歧义路径 + 特征缓存 + ROI 级 + 零检测回退）；检测器单源自证（一个检测器只算一个源，定案需三通道 ≥2 一致）。
