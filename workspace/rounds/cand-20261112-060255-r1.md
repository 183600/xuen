# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「多机协作」×「运动学」）

> 第 57 轮把安全的赌注从"模型置信"推到"证据承诺"，再推到"可摊销的元先验+共形保底"；它的风险自陈说得很清楚：一旦语料存在系统性盲区，"坏先验"就会普遍化，而 OOD 门一旦漏检，EV-probe 被禁、只剩又宽又慢的非参区间。但这份自陈漏掉了两个更根本的结构问题：**(a) 所有证据仍由单机采集**——一支机器人队伍看起来有 N 倍观测，实际上若共享相机、共享地形、共享机体结构与控制器，它们只是把同一个错误问了 N 遍；把 N 个相关见证当独立样本平均，会把单机偏差放大成"舰队共识"，这是比单机过度自信更可怕的分布式假信念；**(b) 所有证据都在回答"这个区域是什么"**，却从不回答"这具身体能否到达它、并且还能全身而退"——一个几何上安全、证据上充分的落脚点，可能要求一个不可恢复的姿态去够，安全因此不是点的性质，而是轨迹的性质。本轮两个灵感各补一刀：**多机协作**把证据从私产变成可审计的账本，但第一定律是"相关性杀死样本量"（n_eff=n/(1+(n−1)ρ)），并用互保质押与单向有界同伴信任把"他人佐证"关进笼子；**运动学**给出唯一不需要被相信的判据——工作空间、关节限位、摩擦锥、支撑多边形、以及**撤退锥**——并由此发明一种"结构性安全"的探针：触点的全部可能结局都落在可恢复集里，于是探测的安全性不再依赖对地表的任何信念，正好解开第 57 轮"OOD 禁探"的死结。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"可协作担保、可运动学撤退、且把相关系数显式记账的证据说可信"**。

核心矛盾：
- **H29（跨机相关 vs 样本量）**：N 台机器人一致不等于 N 个独立样本；共享传感器/材质簇/天气/机体/控制器造成的误差相关会让"舰队共识"成为回音室。朴素平均把单机偏差变成分布式假信念，且越"协作"越自信。
- **H30（几何安全 vs 运动学可达）**：一个点在几何上安全、在证据上充分，仍可能作为轨迹不可达、接近奇异、摩擦锥不可行或"进去了出不来"；第 57 轮的区域级证据完全没有"这具身体能否兑现"的维度。运动学判据是物理的、无需学习，但模型误差（柔性、滑移、未建模关节限位）会让"结构性保证"悄悄失效。
- **H31（协作 vs 博弈/拜占庭）**：同伴可能过时、错误、自利或恶意；若同伴证据直接入证据门，全队变成分布式攻击面；可若永不信任同伴，协作一无所获。信任必须能"赢得慢、失去快"，且**永远不能让系统更敢赌**。

## 0. 直觉与动机

**灵感 1（多机协作 → 证据账本 + 相关性折算 + 互保质押）**
直觉：一支机队就是一场分布式实验，每台机器的探针是一个样本；但"十五台机器共用一只相机"只算一个样本。于是同伴证据不以"信念"入账，而以**签名证据凭证**入账：每条记录携带来源 π=(传感器集, 机体形态, 位姿, 时刻, 模型版本)，跨机一致只有在**声明独立且被审计验证**时才折算成证据；折算用设计效应 n_eff=n/(1+(n−1)ρ̄)，ρ̄ 由标定残差在共享区域上的相关性估计并全程披露。若某同伴为一个区域背书后被证伪，其质押 reputation 被实时扣减——但同伴信任与第 57 轮的操作者信任同构：**升级慢、降级快、单向有界**，任何同伴都无法通过"背书"让系统变得更激进。

**灵感 2（运动学 → 安全从"点"变"轨迹"，从"信念"变"结构"）**
直觉：运动学是唯一"不需要被相信"的判据——工作空间边界、关节限位、奇异值、摩擦锥、支撑多边形都是物理约束，不是从语料学来的先验。于是给每个候选接触补一张**运动学可达性证书 KAC**：可达裕度、可操作度、奇异裕度、摩擦锥裕度、支撑裕度、撤退可行性同时达标，才谈"承诺"。更关键的是由此发明**运动学撤退探针 KRP**：利用冗余自由度/单趾轻触，让"成功/打滑/踩空"所有可能结局都把状态映射回**可恢复集 ℛ**——安全性由构造保证（P(safe)≥1−α_R），**与地表是什么无关**。因此 KRP 可以在 OOD 区域、共形带建立之前使用：这正是第 57 轮"OOD 禁探、只能绕行"死结的结构性出口。

**灵感 3（两灵感合流 → 证据门从"数量"升级为"可担保性"）**
直觉：第 57 轮证据门问"有没有足够证据"，本轮改为问"这条证据**由谁、以什么独立性、在什么运动学前提下**做出"。新增两类证据：**EV-kprobe**（结构性安全探针，无需信念）与 **EV-peer**（跨机佐证，按 n_eff 折算并按质押担保）；EV-probe*/EV-visit 需追加 KAC 前提。硬规则：**不可逆接触的必要证据必须来自本机身体**（local EV-probe* ∨ EV-margin*），且 KAC 通过——同伴一致、跨模态一致、甚至 KRP 的结构性安全，都不能单独授权不可逆接触，因为"别人能过"与"这个点轻触安全"都不等于"这具身体在这条轨迹上承重安全"。

**灵感 4（协作拓扑 → 谁去探、替谁探）**
直觉：不必每台机器探每个区域。把探针分配成"单位风险的信息收益"：侦察机只在自身撤退锥内探，证据上账本但**承诺永远本地化**；形态相近同伴的探针价值按形态残差打折。协作的价值不在"投票"，而在**分摊探针成本**与**用不同形态/不同视角打破单机相关误差**——只有后者能真正增加 n_eff。

**灵感 5（PCRD → 探-诺-演 + 撤退/委派）**
直觉：承诺前多一个"撤退"分支。若不存在运动学认证的步态，不要立刻协商或停：先试 KRP（若撤退锥安全），拿到局部证据后重规划；或委派给形态匹配且独立性可证的同伴（若信息收益 > 通信与相关折价）。四态算子 **PCRD = 探 → 诺 → 撤 → 委派 → 协商/停**，三个新机制仍只经"信念更准（含加宽）"或"动作更保守"两条安全通道起作用。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（跨机证据账本 XEL）** 机队 F，证据凭证 e_i=(r,ev,J_{p,i},π_i,s_i)，π_i=(传感器集,morphology m_i,pose,t,model ver)，s_i 为互保质押。相关性 ρ_ij=Corr(ε_i,ε_j) 由共享区域标定残差估计并披露；对含本机与 k 条同伴证据的组，ρ̄ 为平均两两相关，**设计效应** D_eff(ρ̄,k)=1+(k−1)ρ̄，**有效样本量** n_eff=(k+1)/D_eff。EV-peer 可用条件：来源完备 ∧ ρ̄ 已审计 ∧ n_eff≥corrob_peer(lv) ∧ 同伴信任 p_i≥p_min。同伴信任 p_i 与 PTM 同构（单向有界）：证实有界恢复、证伪实时降级并按质押扣减；p_i 只能收紧、不能放宽本机证据门的任何阈值。**拜占庭界** |B|/|F|≤f_byz，质押扣减在单会话内生效。

**定义 140（运动学可达性证书 KAC）** 对候选触点 q 与接触力旋量 w，定义裕度组：m_ws(q) 工作空间边界距离；m_sing(q)=σ_min(J(q))/σ_max(J(q))；m_cone(w)=1−‖w_t‖/(μ(q)w_n)；m_sup(σ) 计划步态下 CoM 到支撑多边形边界距离；m_ret(σ) 撤退可行性（存在恢复步态）。KAC(r,σ) ⇔ 全部裕度 ≥ 各自阈值 ∧ ∃g 使 σ 的每个落脚点运动学可行 ∧ m_ret≥0。**KAC 是轨迹级判据，不是区域级判据**：它显式区分"点安全（第 57 轮）"与"轨迹可兑现"。

**定义 141（撤退锥与运动学撤退探针 KRP）** 可恢复集 ℛ={x: ∃恢复策略 π_rec，在有界扰动下 P(到达安全站姿)≥1−α_R}。对姿态 x 与接触动作，撤退锥 RC(x,action)={结果 o: T(x,o)∈ℛ}；若接触结果的全支撑集 supp(o)⊆RC，则该接触**结构性安全**。KRP 是一类受限接触（限力 F_k、限时 τ_k、带撤离策略），满足 supp(o)⊆RC。则 P(safe|KRP)≥1−α_R，**与对地表的信念无关**。EV-kprobe 为 KRP 的合格标记：可在 OOD 区域与共形带建立前执行；其观测照常入图，但若无 EV-probe* 的统计校准契约，**不得单独授权不可逆接触**（轻触安全 ≠ 承重安全）。

**定义 142（协作地图共识 CMC）** 共享地图带逐条证据来源与版本向量 vv。合并算子 Merge 为证据加权且相关性折算：b_r ← Widen(Fuse({b_r^m},{ρ_m}), D_corr)，其中冲突不取平均而取**加宽**（分歧是信息，不是噪声）。**本地否决权**：本机矛盾证据永远加宽本地信念并阻断本地承诺，任何舰队多数/共识都不得覆盖本地硬约束或本地矛盾——共识不是真值。

**定义 143（多机证据门 MEG / FSE+）** 证据类扩充为 {EV-kprobe, EV-peer, EV-probe*, EV-visit*, EV-margin*, EV-xmodal(限 L1), EV-human}。门规则：(G1) EV-kprobe ⇔ RC 认证 ∧ 力/时受限，可用于 OOD 探索，但不入不可逆必要集；(G2) EV-peer ⇔ XEL 条件 ∧ 仅可降低所需本机佐证数，**不可替代本机证据**；(G3) EV-probe*/EV-margin* ⇔ 第 57 轮契约 ∧ KAC(r,σ)；(G4) 不可逆接触必要证据集 = 本机 (EV-probe* ∨ EV-margin*) ∧ KAC ∧ 无本地-舰队冲突记录，**不含** EV-peer / EV-xmodal / EV-kprobe；(G5) 授权（PTM）与同伴信任只能收紧阈值，永不放宽全局硬界。

**定义 144（探-诺-撒-委算子 PCRD / PCE++）** 每检查点：①元推断（ID→摊销后验 / OOD→共形带）；②对账（D>θ_D ⇒ 共识探针）；③**运动学核验**：KAC 通过否；④若不通过或有缺口：先试 KRP（RC 安全时，预算 k_ret），再重规划；并可选**委派**：argmax_{i∈F} (I_eff(探针;i)/(risk_i·comms_i·D_eff_i)) ≥ θ_del；⑤承诺 ⇔ ∃g:R≤δ_f(g) ∧ MEG 通过；否则绕行→降档→L2 协商（τ_int(auth)）或安全停。每检查点 KRP≤k_ret、委派≤k_del，四态完备。

## 2. 关键算法伪代码（完整版见产物区）

```python
def cross_robot_evidence(fleet, r, ev, local):     # IP-139: 相关性折算
    peers = [e for i, e in fleet.items() if i != local and e.r == r]
    rho = audit_correlation(peers, local, M)       # 共享区域残差估计
    n_eff = (len(peers) + 1) / (1 + (len(peers)) * rho)
    ok = n_eff >= corrob_peer(ev.level) and all(p_trust(i) >= P_MIN for i in peers)
    return Evidence(kind='EV-peer', ok=ok, n_eff=n_eff, rho=rho)

def kinematically_certified(robot, sigma, M):      # IP-140: 轨迹级核验
    for q, w in footholds(sigma):
        if min(m_ws(q), m_sing(q), m_cone(w), m_sup(sigma), m_ret(sigma)) < 0:
            return False                            # 任一点不可兑现即整条轨迹不合格
    return exists_feasible_gait(sigma, robot.model)

def retreat_probe(robot, q, M):                    # IP-141: 结构性安全
    if not supp(outcomes(q)) <= retreat_cone(robot.x, q, robot.model):
        return None                                 # 撤退锥不足，禁止探测
    obs = execute_probe(q, cap=F_K, timeout=TAU_K)
    return Evidence(kind='EV-kprobe', obs=obs, safe_floor=1 - alpha_R)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| XEL | O(\|F\|·d_π + N_cal²) / 区域 | O(\|F\|·\|𝒟\|) | ρ 估计诚实、n_eff 保守、质押实时 |
| KAC | O(\|σ\|·(d_IK+d_J)) / 步态 | O(\|σ\|) | 裕度阈值保守、模型误差纳入 |
| KRP | O(d_IK)+O(1)/探针 | O(1) | 撤退锥不变式 supp(o)⊆RC |
| CMC | O(\|F\|·\|V\| log\|V\|) / 合并 | O(\|V\|·\|F\|) | 冲突加宽、本地否决 |
| MEG | O(\|σ\|·\|F\|) | O(\|σ\|) | 不可逆必要集仅本机证据 |
| PCRD | O(\|CP\|·(k_p+k_c+k_ret+k_del)·C_VOI) | O(\|V\|+\|σ\|) | 四态完备、预算终止 |

**正确性定理（Cooperative Kinematic Personalized Soundness, CKPS）**：在 A22–A40 上加 (A41) XEL 相关性模型诚实且 n_eff 保守（ρ 被高估安全、被低估不安全，故须上置信界）；(A42) KAC 裕度对柔性/滑移/未建模限位保守；(A43) 撤退锥不变式成立（扰动有界、恢复策略可执行）；(A44) 拜占庭比例 ≤f_byz 且质押扣减及时；(A45) 形态迁移残差有界。则：
(i) **相关折价**：舰队一致提供的置信度不超过 n_eff 个独立本机探针；把相关同伴当独立产生的假信念 ≤ 设计效应界（ρ→1 时与单机相同，ρ→0 时线性增益）。
(ii) **结构性安全**：KRP 的安全概率下界 ≥1−α_R，且**不依赖地表信念**；因此 OOD 区域的探测死结可解，且不违反第 57 轮的 OOD 禁探（禁的是依赖信念的 EV-probe，不是结构性安全的 KRP）。
(iii) **不可逆隔离**：不可逆接触的失效率上界仍由本机 δ_f+ε_meta+δ_probe+ε_h 决定；EV-peer/EV-xmodal/EV-kprobe 的贡献只进入非不可逆层，故分布式相关误差与结构模型误差都不会直接抬高不可逆层的赌注。
(iv) **交互单调性强化**：协作、运动学、撤退三个机制只能经"信念更准（含加宽）"或"动作更保守（KAC 不过则降档/绕行、KRP 限力限时）"影响系统；同伴信任与质押不放宽任何全局硬界。
(v) **终止性**：每检查点 PCE++ 在 k_probes+k_cons+k_ret+k_del 内终止于 {承诺,绕行,L2 协商,安全停}。

**部署界**：
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]) − P(ρ 低估)·P_false_consensus − P(KAC 模型失配) − P(ℛ 不变式破坏) − P(𝓜 陈旧未检出)。

def evidence_ledger_ingest(fleet, local, rec):
    rec.provenance = (rec.sensors, rec.morphology, rec.pose, rec.t, rec.model_ver)
    rec.sig = sign(local.key, rec)                    # 不可否认、可回溯
    fleet.ledger[rec.r].append(rec)

def cross_robot_support(fleet, local, r, level):
    peers = [e for e in fleet.ledger[r]
             if e.sig_ok and e.provenance.morphology_compatible(local)]
    if not peers: return Evidence('EV-peer', ok=False, n_eff=0)
    rho = upper_conf(corr_estimate(peers + [local], fleet.calib), alpha=0.05)  # 宁可高估
    n_eff = (len(peers) + 1) / (1 + len(peers) * rho)
    ok = (n_eff >= corrob_peer(level)
          and all(fleet.trust[i].p >= P_MIN for i in peers_id(peers)))
    return Evidence('EV-peer', ok=ok, n_eff=n_eff, rho=rho)

def peer_trust_update(fleet, i, verdict, audit):     # 与 PTM 同构：单向有界
    if verdict == 'falsified':
        fleet.trust[i].p = max(P_MIN, fleet.trust[i].p - eta_down)
        fleet.ledger.stake[i] = max(0, fleet.ledger.stake[i] - slash(verdict))
        audit.flag_all(fleet.ledger.evidence_by(i))   # 回溯降权其历史证据
    else:
        fleet.trust[i].p = min(P_MAX_PEER, fleet.trust[i].p + eta_up)
        fleet.ledger.stake[i] += reward_cap(verdict)

def kac_certify(robot, sigma):
    for q, w in footholds(sigma):
        m_ws   = distance_to_workspace_boundary(q, robot.model)
        m_sing = sigma_min(jacobian(q)) / sigma_max(jacobian(q))
        m_cone = 1 - norm(w.tangential) / (mu(q) * w.normal)

               m_sup - SUP_MIN, m_ret) < 0:

def retreat_cone(robot, q, action):
    outs = outcome_support(action, robot.model, disturbance_bound=D_MAX)
    return all(in_recoverable_set(T(robot.x, o), robot) for o in outs)

def kinematic_retreat_probe(robot, q, M):

### IP-144 PCRD（探-诺-撒-委算子）

```python
def probe_commit_retreat_delegate(x0, robot, M, task, budget, fleet, consent):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        inf = meta_few_shot_infer(M, cp.region, M.obs[cp.region], meta)
        M.b[cp.region] = inf.post if inf.cls == 'ID' else worst_in(inf.belt)
        sigma = foothold_schedule(x0, cp, M); R = schedule_risk(sigma, M)
        while select_gait(R) == 'halt' and budget.probes_left > 0:
            cert = kac_certify(robot, sigma)                  # ③ 运动学核验
            if not cert.ok:
                q = cert.repair_target()
                ev = kinematic_retreat_probe(robot, q, M)     # ④a 撤退探针
                if ev and ev.safe_floor >= 1 - ALPHA_R:
                    M.obs[q.region].append(ev.obs); log.append(ev)
                    budget.spend_kret()
                    sigma = reselect_footholds(x0, cp, M); R = schedule_risk(sigma, M)
                    continue
                peer = delegate_probe(robot, fleet, cp, M)     # ④b 委派
                if peer and peer.I_eff / peer.cost >= theta_del:
                    cross_robot_support(fleet, robot, cp.region, 'L1')
                    budget.spend_del(); continue
            p = argmax(admissible_probes(cp, M, F_abs),
                       key=lambda q: voi_meta_pessimistic(q, M, inf) - cost(q))
            if voi_meta_pessimistic(p, M, inf) < theta_voi: break
            M, _, D = xmodal_fuse(M, cp.region, execute_probe(p, cap=F_abs))
            if D > theta_D and 'consensus' not in cp.done:
                p2 = most_disagreeing_modality_probe(M, cp.region)
                M, _, D = xmodal_fuse(M, cp.region, execute_probe(p2, cap=F_abs))
                cp.done.add('consensus')
            sigma = reselect_footholds(x0, cp, M); R = schedule_risk(sigma, M)
            budget.spend(p)
        g = select_gait(R)
        ev = tag_evidence_p(sigma, M, contact_level(cp))
        if g != 'halt' and multi_robot_evidence_gate(core_contact(cp), robot, fleet,
                                                     M, ood_reg)[0] == 'ok':
            sched.append(commit(sigma, g)); log.append(ev); continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt': route = alt; continue
        return negotiate_or_stop(cp, M, sigma, R, consent,
                                 tau_int=tau_int(personas.active.auth))
    return sched, log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| XEL | O(\|F\|·d_π + N_cal²)/区域 | O(\|F\|·\|𝒟\|) | ρ 上置信界、n_eff 保守、质押实时（A41） |
| KAC | O(\|σ\|·(d_IK+d_J))/步态 | O(\|σ\|) | 裕度保守、模型残差纳入（A42） |
| KRP | O(d_IK)+O(1)/探针 | O(1) | supp(o)⊆RC（A43） |
| CMC | O(\|F\|·\|V\|log\|V\|)/合并 | O(\|V\|·\|F\|) | 冲突加宽、本地否决、版本向量 |
| MEG | O(\|σ\|·\|F\|) | O(\|σ\|) | 不可逆仅本机证据 + KAC |
| PCRD | O(\|CP\|·(k_p+k_c+k_ret+k_del)·(C_VOI+d_φ)+\|CP\|·A*) | O(\|V\|+\|σ\|) | 四态完备、预算终止 |

**正确性定理（Cooperative Kinematic Personalized Soundness, CKPS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** XEL 相关性模型诚实且以 ρ 上置信界折算，n_eff 保守；(A42) KAC 六类裕度对柔性、滑移、未建模关节限位保守，模型失配以在线残差监测并触发降档；(A43) 撤退锥不变式成立（有界扰动下恢复策略可执行）；(A44) 拜占庭比例 ≤f_byz 且质押扣减在单会话内生效；(A45) 跨形态迁移残差有界。则：

1. **相关折价**：含 k 条同伴证据的舰队一致，其等效独立样本数 ≤ n_eff=(k+1)/(1+kρ̄)；由此产生的代价满足 P_false_consensus ≤ f(ρ̄,k)，且 ρ̄→1 时退化为单机、ρ̄→0 时恢复线性增益。
2. **结构性安全**：KRP 满足 P(safe)≥1−α_R，且该下界**与地表信念无关**；因此 OOD 区域在共形带建立前可安全探测，直接解除第 57 轮"OOD 禁探"死结（禁的是依赖信念的 EV-probe，而非结构保证的 KRP）。
3. **不可逆隔离**：不可逆接触失效率仍由本机 δ_f+ε_meta(k)+δ_probe+ε_h 决定；EV-peer、EV-xmodal、EV-kprobe 只进入非不可逆层，故分布式相关误差与结构模型误差不直接抬高不可逆层赌注。
4. **交互单调性强化**：协作、运动学、撤退只能经 (a) 校准/加宽信念 或 (b) 更保守动作（KAC 不过则降档/绕行、KRP 限力限时、冲突加宽）影响系统；同伴信任与质押只收紧不放宽全局硬界。
5. **终止性**：每检查点 PCE++ 在 k_probes+k_cons+k_ret+k_del 内终止于 {承诺,绕行,L2 协商,安全停}。

**部署界**：
```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])
             − P(ρ 低估)·P_false_consensus
             − P(KAC 模型失配) − P(ℛ 不变式破坏)
             − P(𝓜 陈旧未检出) − P(护盾回退失败)
```
关键：**相关性的代价显式入账**（协作不再是免费的样本量）；**结构性安全与信念解耦**（KRP 给 OOD 一个不靠先验的出口）；**不可逆层只认本机身体**（把分布式相关误差和结构模型误差隔离在非不可逆层）。

## 6. 本轮最大风险

**一句话**：本轮把安全的一部分押在"运动学是无需相信的真值"上，而最脆弱的恰恰是模型本身——一旦 KAC 裕度与撤退锥不变式被未建模的柔性、滑移或关节限位打破，"结构性安全"会在没有任何信念可被质疑的情况下静默失效；叠加 ρ 低估造成的舰队回音室，最坏情形是整队共用一个错误的运动学模型，并因"多机一致 + 结构认证"而比单机更快地一起踏入不可恢复区，因此必须以保守裕度、在线残差监测、KRP 限力限时、以及"不可逆接触只认本机校准证据"四重护栏，宁可慢、宁可绕，绝不把结构模型当成不会被骗的地表。
