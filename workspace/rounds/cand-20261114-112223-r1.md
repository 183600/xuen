# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~301；新一轮灵感循环第 1 轮；本轮灵感：「多任务学习」×「嵌入式系统」）

> R73 用 MMS/DPEM/CCA/ΣREFLEX/CPB 把证据计量做成了可组合契约，解决了「换模块 = 重审系统」。但它默认了两件在真实机器人上几乎从不成立的事：
> - **模块独立假设**：CCA-PAR 只在 conformal 一致性审计通过、|ρ̂|<ρ_max 时允许缩窄，而 ρ̂ 是**在线估计的标量**。多任务学习（共享 backbone、共享预处理、共享校准数据）恰恰让误差**结构性相关**：ρ 随任务组合、输入域、工况漂移；共享表征还会产生**共同模式失效**——一个 backbone 遇到分布外样本，会让所有 task head 同时自信地错。R73 把「相关」当成可估计的统计量，而不是由**共享结构决定的上界**。这与它自己批判的「把接触不确定度误读为位姿不确定度」是同型错误：**把共同原因误读为可忽略的残差相关**。
> - **资源可加假设**：SER 的 u_out ≥ u_A + L_B·u_A、ΣREFLEX 的 Σ_i c_i ≤ B、MReg 的预算闭合，全部假定成本与资源可加。嵌入式系统里算力/内存/总线/功耗/热是**共享且耦合**的：多任务共享一次前向，成本是次可加的；cache/总线争用让一个模块的 WCET 依赖另一个模块；功耗→温度→降频→WCET 变长是物理闭环；int8/定点量化引入新的实现诱导不确定度。R73 的 WCET 是**逐模块**的，没有共享执行器的可调度性、能量账本与热预算。
> - **认证的联合性缺失**：R73 逐模块做 SEAL/conformal，证书是「边际覆盖」。但控制器一次决策消费**全部证据**，安全事件是**联合事件**（所有模态同时可信）。边际覆盖 1−α_t 不推出联合覆盖；多任务学习又诱导「一个 backbone 认证所有任务」的叙事。缺一张**多任务联合覆盖证书**。
>
> 本轮两个灵感正好补这三块：**多任务学习** → 共享表征的**共同模式审计 + 联合覆盖 + 负迁移防火墙**；**嵌入式系统** → **资源-不确定度交换律 + 共享成本账本 + 热-功耗反作用层 L5 + 可调度组合证书 + 资源感知降级**。
>
> 核心命题：**不再问「这个模块化系统可信吗」，而问「当所有模块共享同一块硅、同一份功耗/热预算、同一个表征时，证据契约能否仍然组合出可证的系统安全？」** 把 R73 的「计量契约代数」下沉为 **SUBGAUGE-RAS**（Shared-substrate Unified Budget GAUGE）——**共享基底计量**。

## 0. 直觉与动机

**灵感 1（多任务学习 → 共享既是收益来源，也是共同模式失效源）**
直觉：多任务学习的收益来自共享，风险也来自共享。共享 backbone 的输出误差**不是独立的**：在一个没见过的光照/材质/遮挡下，所有 task head 会同时偏——这就是可靠性工程里的**共因失效（common-cause failure）**。R73 的 PAR 缩窄把两个模态当独立证据做方差合并；如果它们共享 90% 的输入通路，缩窄就是在**重复计算同一份信息**，系统会过度自信。更隐蔽的是**负迁移**：为任务 B 加一个 head、或重训 backbone，会把任务 A 已认证的校准悄悄打穿，而 A 的证书还在、审计日志还全绿。→ 必须把「共享什么、和谁共享、最坏相关多大」写成契约字段；把「加任务」纳入审计（防火墙）；把认证从边际覆盖升级为**联合覆盖**。

**灵感 2（嵌入式系统 → 资源-不确定度交换律）**
直觉：在嵌入式计算里，精度是**买来的**：更高分辨率深度、更多采样、fp32 而非 int8、更高帧率，都换成更低的 u，但花 mW/ms。于是每个模块有一条**资源-不确定度曲线** u_i(r)，边际收益递减（凸）。系统问题变成固定预算下的**风险最小化分配**（注水）。这与 R73 的「反作用预算」正交：R73 是「动作改变噪声」，这里是「算力改变噪声」。两者必须在同一账本里合算。

**灵感 3（共享成本 → Aumann-Shapley 账本）**
直觉：共享前向的成本不能简单按模块均摊（谁该为 backbone 付多少？），否则组合单调性失去基础（有的模块被补贴、有的被重复收费）。用**连续 Shapley / Aumann-Shapley**：沿「所有模块按比例放大」的路径对边际成本积分，得到唯一满足效率（分摊总和 = 实测总成本）、对称、哑元、可加性的分摊。这样「共享」不会变成隐形补贴：账本闭合，CCA 的预算闭合校验在**分摊后**仍然成立。

**灵感 4（热-功耗 → L5 资源反作用层）**
直觉：机器人不只被视角反作用（R73 L4），还被自己的**功耗**反作用：多任务并发 → 功耗上升 → 结温上升 → 降频 → WCET 变长 → 截止期风险上升；同时温度漂移让传感器噪声上升（R73 的 u_calib 只覆盖外参，不覆盖全局热环境）。这是 L5：**资源反作用**。它与 L4 同构：动作/工作负载 → 物理状态 → 噪声与时间预算 → 决策。必须进入 ΣREFLEX，并且要有**热闭环稳定性**条件（否则降频 runaway）。

**灵感 5（嵌入式部署 → 联合证书、可调度性与安全降级）**
直觉：一个「组合证书」在嵌入式上不只要问「不确定度是否闭合」，还要问「跑得完吗、会不会过热、掉电时先关谁」。R73 的 J_MOD 缺 J_SCHED（响应时间/利用率/总线阻塞/能量/热）。热替换也不仅要「同契约、同分布」，还要**资源偏序**：新实现不能更慢/更费电/暴露更大。掉电降级要有**安全最优序**（每 mW 换回多少安全），而不是随便关。

**统一直觉**：R73 把系统看成**一组独立的契约模块**；本轮把它看成**一组共享一块物理基底的契约模块**。共享带来两个新的一等公民：**共同模式（相关与共因）** 与 **资源（算力/能量/热/时间）**。二者都不是「噪声」，但都直接改写证据的可靠性。SUBGAUGE 的核心主张是：**把共享本身纳入契约与证书——共享必须被声明、被分摊、被联合校准、被调度审计。**

## 1. 形式化定义（增量：定义 383–396）

**定义 383（SUBGAUGE-RAS 总览与六不变式）** SUBGAUGE-RAS = (MODGAUGE-RAS†, SSC, SAA, CME/JCC, NTF, χ_T, J_SCHED, ROB)。六不变式：
(i) **契约完整性**（继承 R73）：无完整证据契约不入图；
(ii) **组合单调性**（继承并加强）：所有组合路径经 CCA 校验，且预算在**分摊后**闭合；
(iii) **反作用通道完备**（扩展）：每个模块声明 χ_R，且必须声明热-资源通道 χ_T（可为平凡）；
(iv) **主张绑定**（扩展 C4/C5）：每个组件 ∈ {C1,C2,C3,C4,C5,工程附件}；
(v) **严格退化链**（扩展）：模块级 stub → 资源感知降级 ROB → 系统级 R68，安全侧只增不减；
(vi) **共享账本闭合**（新增）：对每个共享资源 c，Σ_i A_i(c) = C_total(c)；对每对模块，若共同模式暴露集 E_i ∩ E_j ≠ ∅，必须声明相关上界 ρ̄(E_i∩E_j, regime)。**未计量的共享一律按「完全相关 + 最坏资源」计费并禁止 PAR 缩窄。**

**定义 384（共享基底契约 SSC）** SSC = (EC, R, G_s, θ_num, E_cm, ρ̄, χ_T, π_deg, J_sched_ref)：
- EC：R73 证据契约；
- R = (peak_mem, energy_mj, thermal_envelope, bus_bw, executor_set)：共享资源声明；
- G_s：共享子图引用（backbone 参数、共享预处理、共享校准数据），用于共同模式追溯；
- θ_num ∈ {fp32, fp16, int8, fixed<F>}：数值域（决定实现诱导不确定度 u_impl）；
- E_cm ⊆ Ε = {power, thermal, clock, bus, backbone, calib-data, illumination, vibration}：**共同模式暴露集**；
- ρ̄: 2^Ε × regime → [0,1]：声明的最坏相关上界函数；
- χ_T：热-功耗反作用通道（定义 391）；
- π_deg：资源降级优先级（定义 392）；
- J_sched_ref：可调度性证书引用（定义 393）。

**定义 385（资源-不确定度曲线 RUC）** 模块 i 的 u_i: ℝ_+ → (0,∞]，满足：u_i(0)=∞（零资源 = stub），在有效域内连续、严格递减、凸。资源轴可为向量（频率、分辨率、位宽、采样数），按归一化标量 r 投入。标定方式：在受控资源档位上测后验不确定度/误差，拟合单调凸曲线并做保形上包络（避免乐观插值）。系统目标：min Σ_i φ_i(u_i(r_i)) s.t. Σ_i r_i ≤ R_budget，φ_i 为风险映射（增凸）。

**定义 386（共享成本分摊 SAA）** 设实测成本函数 C(x)（x_i 为模块 i 的资源需求，连续可微）。**Aumann-Shapley 分摊**：
A_i = ∫_0^1 (∂C/∂x_i)(t·x) · x_i dt，Σ_i A_i = C(x)（效率）。
性质：对称、哑元（不共享者不付费）、可加（可分离成本分解一致）。离散/不可微（cache、总线争用）时用消融实测边际 + 采样近似，误差 ≤ M·Δx（M 为 Lipschitz 常数）。**账本审计**：|Σ_i A_i − C_measured| ≤ ε_ledger，否则该组合非法入图。

**定义 387（共同模式暴露 CME 与相关上界）** 对任意模块对 (i,j)，声明
ρ_ij(regime) = ρ̄(E_i ∩ E_j, regime)。
**PAR 缩窄的升级条件**：允许缩窄当且仅当
(a) E_i ∩ E_j = ∅；或
(b) **共同模式审计**通过：在 SEAL-CM 上按暴露层 σ = E_i∩E_j 做**分组条件 conformal 校准**，且该层最坏相关 ρ_ij^worst ≤ ρ_max，且保持集上覆盖率 ≥ 1−α。
否则 u_out = max(u_A,u_B) 且注入否决指示 `CM_SHARED`。**关键**：E_cm 是**结构承诺**，漏报暴露即契约违规（由 SEAL-CM 压力集审计）；ρ̂ 的点估计不能替代 ρ̄ 的上界。

**定义 388（多任务联合覆盖 JCC）** 设 T 个任务/模块的 nonconformity 分数 s_t。联合分数
s(x,y) = max_t s_t(x,y) / q_t，
在 SEAL-CM 上做 split conformal 得 q，使 P(∀t: y_t ∈ C_t) ≥ 1−α_joint。称**联合覆盖证书**。记覆盖缺口 g = min_t(1−α_t) − (1−α_joint) ≥ 0；g 是「边际认证冒充联合认证」的可测惩罚项。

**定义 389（负迁移防火墙 NTF）** 新增任务 k（或重训共享 backbone）可入图，当且仅当对每个已认证任务 i：
Δrisk_i(k) ≤ ε_int（干扰预算）∧ ΔECE_i(k) ≤ ε_ece ∧ 联合覆盖 JCC(k ∪ cert) 保持 ≥ 1−α_joint（在 SEAL-CM 保持集上）。
不通过 ⇒ **拒绝**，或降级为 **observer**（只记录、不进认证路径、不进 MReg 的认证子图，按 CPB 归为附件）。这给出「加任务不降低既有保证」的单调性。

**定义 390（实现诱导不确定度 u_impl 与 DPEM 七分量）** 嵌入式部署引入量化/降精度/近似推理不确定度。对均匀量化步长 Δ，单量化量噪声方差 ≤ Δ²/12；经 Lipschitz L 的模块传播 ⇒ u_impl ≤ L·Δ/√12。动态范围溢出**不是方差**而是有效域违规（直接 stub）。DPEM 在嵌入式下升级为七分量：
u_depth² = u_range² + u_material² + u_edge² + u_calib² + u_interf² + u_motion² + u_impl²。
**float32 → int8 的热替换必须重认证 u_impl（同 EC、不同 SSC.θ_num）。**

**定义 391（热-功耗反作用通道 χ_T 与 L5）** 动作/工作负载 g 与并发任务集决定功率 P(g)；热模型
T_{t+1} = T_t + a·P(g) − b·(T_t − T_amb)。
结温调制时间与噪声：WCET 乘子 m(T)（降频段 m≥1）、噪声膨胀 κ(T)。ΣREFLEX 扩展为 L5：
c_reflex^T = E[Δ(能耗, 截止期风险, 噪声)]，预算 Σ_t Σ_i c_reflex^i + E_used ≤ B_total；稳态集加 T_safe = {T ≤ T_max, E_remaining ≥ E_min}。**局部稳定性条件**：热回路增益 |a·∂P/∂workload / b| < 1，否则降频 runaway（此条件写入契约，不满足则禁止该并发配置）。

**定义 392（资源感知降级 ROB）** 剩余能量 E < E_thr 时，选降级集 S 释放至少 ΔE，最小化损失安全价值 Σ_{i∈S} v_i（v_i = 该模块贡献的风险降低），按 v_i / c_i（每 mW 换回的安全）贪心排序。分数版最优、整数版有界近似；**保守安全性**（降级只移除缩窄与证据，不引入乐观）对任意 S 都成立。

**定义 393（可调度组合证书 J_SCHED）** 模块图新增执行器/周期/截止期标注。组合可调度当且仅当：
∀i, R_i ≤ D_i（含共享总线/DMA 阻塞）∧ Σ U_i ≤ U_max ∧ 每超周期能耗 ≤ E_budget ∧ 稳态 T ≤ T_max。
J_SCHED 与 J_MOD 做合取，得到嵌入式组合证书。

**定义 394（共享基底热替换偏序 ≼_SSC）** impl′ ≼_SSC impl 当且仅当同一 SSC 且逐项不劣：u_i′(r) ≤ u_i(r) ∀r、WCET′ ≤ WCET、mem′ ≤ mem、能量′ ≤ 能量、E_cm′ ⊆ E_cm。若 impl′ ≼_SSC impl 且 cert′ 有效，则热替换保持 J_MOD ∧ J_SCHED（无需全系统重审）；仅有单轴变差时只重认证该轴。

**定义 395（证据能效 EMT）** EMT_i = (风险降低 ΔRisk_i) / (能耗 mJ)；系统 EMT = (相对全 stub 的风险降低) / (总能耗)。用于 C5 的预注册可证伪指标。

**定义 396（MBench 扩展与主张 C4/C5）** 新增：
- **MB4（共享基底安全基准）**：共享 backbone 的多任务感知栈 + 注入共同模式偏移，测联合覆盖、共因检出、负迁移拒绝率。
- **MB5（资源-不确定度基准）**：固定 mW/ms 预算下分配策略对比（注水 vs 均匀 vs 无共享），测证据能效与保留安全。
- **C4（共享基底可证安全）**：共同模式暴露 + 联合覆盖 + NTF 使系统安全在共享表征/算力/热预算下仍可证，显著优于「独立校准 + 独立预算」。
- **C5（资源-不确定度最优交换）**：RUC + SAA + 注水在固定嵌入式预算下以更低能耗达到同等或更好后验精度与保留安全。

## 2. 关键算法骨架

```python
# IP-302 SSC：共享基底契约（EC 的严格扩展）
@dataclass(frozen=True)
class SharedSubstrateContract:
    ec: EvidenceContract                       # R73 证据契约
    executor: str; period_us: float; deadline_us: float
    peak_mem_kb: float; energy_mj: float; bus_bw: float
    num_domain: str                            # 'fp32'|'fp16'|'int8'|'fixed<F>'
    shared_refs: FrozenSet[str]                # backbone / 预处理 / 校准数据
    exposure: FrozenSet[str]                   # E_cm：共同模式暴露
    rho_bar: Callable[[FrozenSet[str], str], float]   # 声明的最坏相关上界
    chi_T: Callable[[Action], ThermalMod]      # L5 热-资源通道
    pi_deg: float                              # 降级优先级（安全/mW）
    sched_ref: str                             # J_SCHED 引用

# IP-303 SAA：共享成本账本（把次可加成本还原为公平可加账本）
def aumann_shapley(cost_fn, x, grid=64):
    # A_i = ∫_0^1 ∂C/∂x_i(t·x)·x_i dt，沿对角路径数值积分
    A = np.zeros(len(x))
    for t in np.linspace(0, 1, grid):
        g = grad(cost_fn, t * x)
        A += g * x * (1.0 / grid)
    return A

def ledger_audit(modules):
    measured = measure_total_cost(modules)        # 实测 mW / ms / KB
    alloc = aumann_shapley(measured.cost_fn, modules.demand)
    ok = abs(alloc.sum() - measured.total) <= EPS_LEDGER
    # 未声明共享 ⇒ 按完全相关 + 最坏资源计费，且禁止 PAR 缩窄
    return ok and all(declared_share(m) for m in modules)

# IP-304 CME + JCC：共同模式审计与多任务联合覆盖
def par_allowed(a, b, regime, seal_cm):
    common = a.exposure & b.exposure
    if not common:
        return True, 0.0                          # 结构独立：允许按 ρ=0 缩窄
    if not seal_cm.group_conditional_covers(common, regime):
        return False, 1.0                         # 该暴露层未校准：禁止缩窄
    rho = max(a.rho_bar(common, regime), b.rho_bar(common, regime))
    return (rho <= RHO_MAX), rho                  # 用上界而非点估计

def joint_conformal_calibrate(scores, alpha):
    # scores[t][n]，先逐任务归一化 q_t，再对联合分数取分位数
    s = np.max(scores / np.quantile(scores, 0.5, axis=1, keepdims=True), axis=0)
    return np.quantile(s, 1 - alpha, method='higher')

# IP-305 NTF：负迁移防火墙（加任务的前置审计）
def admit_task(k, certified, seal_cm):
    for i in certified:
        if risk_delta(k, i) > EPS_INT or ece_delta(k, i) > EPS_ECE:
            return False, 'NEG_TRANSFER'
    if joint_coverage(k + certified, seal_cm) < 1 - ALPHA_JOINT:
        return False, 'JOINT_COVERAGE'
    return True, 'OK'                             # 否则拒绝，或降为 observer 附件

# IP-306 chi_T + ROB：L5 热-资源反作用与安全最优降级
def thermal_step(T, power, a, b, T_amb):
    return T + a * power - b * (T - T_amb)

def thermal_cost(g, state, ssc):
    P = ssc.power_model(g, state.tasks)
    T2 = thermal_step(state.T, P, ssc.a, ssc.b, ssc.T_amb)
    wcet_mult = ssc.m(T2); noise = ssc.kappa(T2)
    return wcet_mult, noise, T2

def resource_bailout(modules, energy_needed):
    order = sorted(modules, key=lambda m: m.ec.pi_deg, reverse=True)  # 安全/mW 高者先保留
    free, drop = 0.0, []
    for m in reversed(order):
        drop.append(m); free += m.energy_mj
        if free >= energy_needed:
            break
    return drop                              # 保守性对任意子集成立

# IP-307 J_SCHED：可调度组合证书（RTA + 利用率 + 能量 + 热）
def sched_audit(modules, T_steady):
    for m in modules:
        m.wcet_eff = m.wcet_us * thermal_multiplier(T_steady)
    return (rta_feasible(modules, blocking=bus_blocking(modules))
            and utilization(modules) <= U_MAX
            and energy_per_hyperperiod(modules) <= E_BUDGET
            and T_steady <= T_MAX)

# IP-308 SUBGAUGE 主闭环（在 R73 MODGAUGE_round 上增加共享基底层）
def SUBGAUGE_round(M, obs, audio, tac_frame, depth_img):

    M.apply_resource(r)                      # 调分辨率/位宽/帧率/并发度

    t_ev = M.dmem.update(tac_frame, M.last_action)

    if not M.ledger.audit(): return M.safe_mode('LEDGER')
    if not M.jcc.holds(): return M.safe_mode('JOINT_COVERAGE')
    if not M.ntf.admit_pending(): return M.reject_pending_or_observer()
    # 4) 反作用：L1–L4（R73）+ L5 热-资源
    g = M.ervoi.choose(...)
    s2, cost, T2 = sigmareflex_step_v5(M.mods, g, M.state, M.budget)   # 含 chi_T
```

## 3. 推导

**引理 38（共享账本闭合 ⇒ 组合单调性在共享下保持）** 由 Aumann-Shapley 的效率性，Σ_i A_i = C(x)；故「共享前向」的实测总成本被无重复、无遗漏地分解到模块。CCA 的预算闭合在分摊后校验，SER 的单调传播 u_out ≥ u_A + L_B·u_A 仍成立。系：**共享不再是组合代数的漏洞，而是一笔可审计的账。**

**引理 39（共享表征下独立融合的过度自信）** 设两个证据真实相关 ρ_0，R73 用点估计 ρ̂ 做融合。等方差 σ 时
σ_fused²(ρ) = σ²(1+ρ)/2，
故 ρ̂ < ρ_0 ⇒ σ_fused²(ρ̂) / σ_true² = (1+ρ̂)/(1+ρ_0) < 1，覆盖率 < 1−α。**证明**：高斯 GLS 方差公式直接代入；相关性被低估 ⇒ 方差被低估。系：**共享 backbone 让 ρ_0 随任务组合与工况漂移，点估计不可靠；必须用暴露集上的上界 ρ̄。** 这是 C4 的理论核心。

**引理 40（联合覆盖缺口）** 对联合事件 ∩_t A_t：
1 − Σ_t α_t ≤ P(∩_t A_t) ≤ 1 − max_t α_t。
故边际覆盖（每个 P(A_t) ≥ 1−α_t）只给出下界 1−Σα_t，与「每个都可信」相差最多 Σα_t − max_t α_t。**证明**：并集界与 P(∩) ≤ min_t P(A_t)。系：**T 个任务都用 1−α 边际认证，不能推出联合 1−α；JCC 是必需的，不是保守性选择。**

**引理 41（NTF 的单调加入）** 若新增任务通过定义 389 的审计，则所有已认证任务的保证不退化；若不通过则被拒绝或降为 observer ⇒ 认证子图不变。归纳于加入序列 ⇒ 任务集单调扩张时系统级保证不下降。**证明**：审计条件逐项覆盖 Δrisk、ΔECE 与联合覆盖；observer 不进入认证路径。系：**R73 只证了「同契约替换保持」，本轮补上「加任务保持」——多任务系统最需要的性质。**

**引理 42（资源-不确定度分配是注水）** 在 u_i 严格递减凸、φ_i 增凸下，min Σ_i φ_i(u_i(r_i)) s.t. Σ r_i ≤ R 的 KKT 条件给出
−φ_i′(u_i(r_i))·u_i′(r_i) = λ（活跃约束），
即各模块边际风险降低相等；对 λ 二分即可 O(n log n) 求解，且解唯一。系：**「把算力花在哪」从工程直觉变成可证的最优分配。**

**引理 43（热反作用的 Lipschitz 性与有限停止）** 在 T < T_max 内，T′ 对 P Lipschitz、降频乘子对 T Lipschitz ⇒ c_reflex^T 在接近包络处有正下界；结合引理 36 的预算吸收 ⇒ ΣREFLEX（含 L5）存在有限停止 n*。**但**：热回路是正反馈结构，需 |a·∂P/∂workload / b| < 1 才局部稳定，否则降频 runaway，停止性论证失效。系：**L5 的加入不破坏有限停止，但要求把热稳定性写成契约前提，而不是默认。**

**定理 30（SUBGAUGE 严格包含 MODGAUGE）** 取共享集为空（G_s=∅）、χ_T 平凡、u_impl=0、NTF 不激活、JCC 退化为逐任务 ⇒ SUBGAUGE 逐指令等于 R73；再退化等于 R71/R68。由定义 383 与引理 38/41，**安全单调不减；共享收益仅在共享账本、联合覆盖、可调度性均通过时兑现。**

**定理 31（共享基底安全保持）** 在 A114–A116 下：
A114 **暴露完备性**：E_cm 覆盖所有实际共享失效因（SEAL-CM 压力集审计通过）；
A115 **联合保形有效性**：JCC 在共享模式分布与已知偏移下覆盖率 ≥ 1−α_joint；
A116 **资源曲线可靠性**：u_i(r) 为实测上包络且凸，SAA 误差 ≤ ε_ledger。
则 Valid(J_MOD) ∧ Valid(J_SCHED) ∧ NTF 通过 ⇒ 物理执行风险 ≤ ε_shared（相对具身测量模型与共享基底表达力）。**证明重量落在 A114（漏报一个共同原因即全盘失效）与 A115（conformal 在分布外仍有效）上。**

**定理 32（ROB 的保守安全与近似最优）** 任意降级集 S 只移除证据与缩窄，不引入乐观 ⇒ 系统不确定度单调不减，安全性（保守方向）保持。分数资源下按 v_i/c_i 排序达到最优；整数资源下为有界近似（最坏情形受背包比约束）。系：**掉电时「先关谁」有可证的安全方向；最优性只在分数/近似意义下成立，不夸大为精确最优。**

## 6. 本轮最大风险

**一句话**：SUBGAUGE 把系统安全的证明负担从「契约表达力」（R73）进一步转移到「**共同模式暴露声明的完备性与共享校准分布的可信性**」——多任务共享会把所有模块的认证绑到**同一份校准数据、同一个 backbone、同一块时钟/电源/热场**上；只要存在一个未被声明的共享失效因（共享训练数据的偏差、共用的固件 bug、全局温度梯度、共模电源纹波），所有模块就会基于**同一被污染的分布**同时「合规地」过度自信：逐任务覆盖、联合覆盖、账本闭合、调度可行**全部通过**，而它们在分布外是**同时**错的。此时系统不是败于某个模块不准，而是败于**共享基底把 N 个证据压缩成了 1 个伪证据**——而审计日志会证明每一步都合规。

次级风险与缓解：
1. **暴露集漏报（共因未声明）** → SEAL-CM 压力集主动搜索共享失效因（电源/时钟/热/数据源）；未声明共享一律按完全相关计费并禁止 PAR 缩窄（定义 383(vi)）；E410 专门演练漏报。
2. **JCC 在分布外失效** → 联合 conformal 加分组条件 + 滑动重校准 + 偏移检出；一旦偏移超限，退回逐任务保守并集（u=max），不追求缩窄。
3. **Aumann-Shapley 在不可微成本下失真（cache/总线）** → 消融实测边际 + 误差上界 ε_ledger；超限即判账本非法，转最坏计费。
4. **热正反馈 runaway** → 稳定性条件 |a·∂P/∂w / b|<1 写入契约；近包络强制降并发；E404 长时程验证。
5. **u_impl 被当成小噪声** → 量化按保守方差上界，溢出按域违规 stub；float→int8 必须重认证（定义 390）。
6. **NTF 过严扼杀多任务收益** → 分级：certified / observer / appendix；只对认证路径严格，旁路任务仍可提供提示但不进风险预算。
7. **ROB 整数近似非最优** → 明确只承诺保守安全方向，最优性标注为近似；关键任务（接触/安全否决）不参与降级。
8. **复杂度/集成膨胀** → 沿用定义 377 的结构上限；新增共享层字段做版本化与默认平凡值，保证 R73 配置可零改动运行（定理 30）。

## 2. 形式化定义（要点版）

**定义 383（六不变式）** 契约完整性 / 组合单调性（分摊后闭合）/ 反作用通道完备（含 χ_T）/ 主张绑定（C1–C5）/ 严格退化链（stub→ROB→R68）/ **共享账本闭合**（ΣA_i=C_total；未计量共享按完全相关 + 最坏资源计费并禁 PAR 缩窄）。

**定义 384（SSC）** EC 的严格扩展：资源包络 R、共享子图 G_s、数值域 θ_num、共同模式暴露 E_cm、相关上界 ρ̄、热通道 χ_T、降级优先级 π_deg、J_SCHED 引用。

**定义 385（RUC）** u_i(0)=∞，有效域内连续、严格递减、凸；实测档位 + 保形上包络。系统分配：min Σ φ_i(u_i(r_i)) s.t. Σr_i≤R。

**定义 386（SAA）** Aumann-Shapley 路径积分分摊，满足效率/对称/哑元/可加；不可微用消融边际 + 误差上界；|ΣA_i−C_measured|≤ε_ledger 才入图。

**定义 387（CME）** PAR 缩窄仅当 E_i∩E_j=∅，或 SEAL-CM 分组条件 conformal 通过且最坏 ρ̄≤ρ_max；否则 `u_out=max` + 否决 `CM_SHARED`。暴露是结构承诺，漏报即契约违规。

**定义 388（JCC）** 联合分数 s=max_t s_t/q_t，在 SEAL-CM 上校准 q；认证联合事件 P(∀t)≥1−α_joint；缺口 g≥0。边际覆盖不推联合覆盖。

**定义 389（NTF）** 新任务/重训仅当对每个已认证 i 满足 Δrisk≤ε_int、ΔECE≤ε_ece、JCC 保持；否则拒绝或降 observer（不进认证子图）。

**定义 390（u_impl / DPEM†）** 量化方差 ≤Δ²/12；传播上界 L·Δ/√12；溢出=域违规 stub；float→int8 必须重认证 u_impl（同 EC、不同 θ_num）。

**定义 391（χ_T / L5）** 负载→功率→结温→降频(WCET 乘子)/噪声膨胀；纳入 ΣREFLEX 预算与稳态集；稳定性前提 |a·∂P/∂w / b|<1。

**定义 392（ROB）** 能量不足时按 v_i/c_i 降级；任意降级集保守安全；分数最优、整数有界近似；安全否决模块不参与降级。

**定义 393（J_SCHED）** 共享执行器响应时间分析 + 利用率 + 总线/DMA 阻塞 + 超周期能量 + 稳态温度；与 J_MOD 合取。

**定义 394（≼_SSC 热替换）** 同 SSC 且 u′≤u、WCET′≤WCET、mem′≤mem、E′≤E、E_cm′⊆E_cm ⇒ 保持 J_MOD ∧ J_SCHED；单轴变差只重认证该轴。

**定义 395（EMT）** 证据能效 = 风险降低/能耗；系统 EMT 相对全 stub。

**定义 396（MB4/MB5 与 C4/C5）** 见符号表；MB4 共享模式偏移 + 联合覆盖 + NTF；MB5 固定 mW/ms 分配对比。

## 3. 关键算法伪代码

```python
# IP-302 SSC：共享基底契约（EC 的严格扩展）
@dataclass(frozen=True)
class SharedSubstrateContract:
    ec: EvidenceContract
    executor: str; period_us: float; deadline_us: float
    peak_mem_kb: float; energy_mj: float; bus_bw: float
    num_domain: str                             # 'fp32'|'fp16'|'int8'|'fixed<F>'
    shared_refs: FrozenSet[str]                 # backbone / 预处理 / 校准数据
    exposure: FrozenSet[str]                    # E_cm
    rho_bar: Callable[[FrozenSet[str], str], float]
    chi_T: Callable[[Action], ThermalMod]
    pi_deg: float; sched_ref: str

# IP-303 SAA：共享成本账本（次可加成本 → 公平可加）
def aumann_shapley(cost_fn, x, grid=64):
    A = np.zeros(len(x))
    for t in np.linspace(0, 1, grid):
        A += grad(cost_fn, t * x) * x / grid
    return A                                    # ΣA_i = C(x)（效率）

def ledger_audit(modules):
    measured = measure_total_cost(modules)
    alloc = aumann_shapley(measured.cost_fn, modules.demand)
    return abs(alloc.sum() - measured.total) <= EPS_LEDGER \
           and all(declared_share(m) for m in modules)

# IP-304 CME + JCC
def par_allowed(a, b, regime, seal_cm):
    common = a.exposure & b.exposure
    if not common: return True, 0.0
    if not seal_cm.group_conditional_covers(common, regime): return False, 1.0
    rho = max(a.rho_bar(common, regime), b.rho_bar(common, regime))
    return (rho <= RHO_MAX), rho                # 用上界，不用点估计

def joint_conformal_calibrate(scores, alpha):
    s = np.max(scores / np.quantile(scores, 0.5, axis=1, keepdims=True), axis=0)
    return np.quantile(s, 1 - alpha, method='higher')

# IP-305 NTF
def admit_task(k, certified, seal_cm):
    for i in certified:
        if risk_delta(k, i) > EPS_INT or ece_delta(k, i) > EPS_ECE:
            return False, 'NEG_TRANSFER'
    if joint_coverage(k + certified, seal_cm) < 1 - ALPHA_JOINT:
        return False, 'JOINT_COVERAGE'
    return True, 'OK'

# IP-306 chi_T + ROB
def thermal_step(T, power, a, b, T_amb):
    return T + a * power - b * (T - T_amb)

def resource_bailout(modules, energy_needed):
    order = sorted(modules, key=lambda m: m.ec.pi_deg, reverse=True)
    free, drop = 0.0, []
    for m in reversed(order):
        drop.append(m); free += m.energy_mj
        if free >= energy_needed: break
    return drop                                 # 任意子集保守安全

# IP-307 J_SCHED
def sched_audit(modules, T_steady):
    for m in modules:
        m.wcet_eff = m.wcet_us * thermal_multiplier(T_steady)
    return (rta_feasible(modules, blocking=bus_blocking(modules))
            and utilization(modules) <= U_MAX
            and energy_per_hyperperiod(modules) <= E_BUDGET
            and T_steady <= T_MAX)

# IP-308 SUBGAUGE 主闭环（R73 三域 + 共享基底层 + 双证书）
def SUBGAUGE_round(M, obs, audio, tac_frame, depth_img):
    r = water_fill(M.ruc, M.budget.remaining, M.risk, T_hat=M.thermal.predict())
    M.apply_resource(r)                         # 分辨率/位宽/帧率/并发度
    d_ev = M.dpe.update(depth_img, rgb, M.cam_state, M.motion, M.peers,
                        theta_num=M.ssc.dpe.num_domain)      # DPEM† 七分量
    t_ev = M.dmem.update(tac_frame, M.last_action)
    if not M.ledger.audit(): return M.safe_mode('LEDGER')
    if not M.jcc.holds():    return M.safe_mode('JOINT_COVERAGE')
    if not M.ntf.admit_pending(): return M.reject_pending_or_observer()
    g = M.ervoi.choose(b_t, psi_hat, z_dist, t_ev.c_dist, M.budget, M.fmp, M.bse)
    s2, cost, T2 = sigmareflex_step_v5(M.mods, g, M.state, M.budget)  # 含 chi_T
    if s2 is not None: M.last_g, M.state = g, s2
    if M.power.remaining < M.budget.E_thr:
        M.degrade(resource_bailout(M.mods, M.budget.dE))
    if not sched_audit(M.mods, T2): return M.safe_mode('SCHED')
    return M.ctrl.step(), J_MOD(M.mreg), J_SCHED(M.mods)   # 双证书
```

## 4. 推导

**引理 38（共享账本闭合 ⇒ 组合单调性保持）** Aumann-Shapley 效率性给出 Σ_i A_i=C(x)；实测总成本被无重复无遗漏分解，CCA 在分摊后校验，SER 单调传播仍成立。系：**共享是账，不是漏洞。**

**引理 39（共享表征下独立融合过度自信）** 真实相关 ρ_0、点估计 ρ̂<ρ_0，等方差时 σ_fused²(ρ)=σ²(1+ρ)/2 ⇒ 方差比 (1+ρ̂)/(1+ρ_0)<1 ⇒ 覆盖率<1−α。系：**共享 backbone 使 ρ_0 随任务/工况漂移，必须用暴露集上界 ρ̄；这是 C4 的理论核心。**

**引理 40（联合覆盖缺口）** 1−Σ_t α_t ≤ P(∩A_t) ≤ 1−max_t α_t；边际覆盖不推联合覆盖。系：**JCC 必需，非保守选择。**

**引理 41（NTF 单调加入）** 通过审计 ⇒ 既有任务保证不降；不通过 ⇒ 拒绝/observer ⇒ 认证子图不变；归纳得任务集单调扩张下保证不下降。系：**补上 R73 只证替换、未证「加任务」的空缺。**

**引理 42（注水最优分配）** u_i 严格递减凸、φ_i 增凸 ⇒ KKT：−φ_i′(u_i)u_i′(r_i)=λ；λ 二分 O(n log n)，解唯一。系：**「算力花在哪」可证最优。**

**引理 43（χ_T 有限停止与稳定性）** T′ 对 P Lipschitz、降频乘子对 T Lipschitz ⇒ c_reflex^T 近包络有正下界，结合引理 36 ⇒ 有限停止；但需 |a·∂P/∂w / b|<1 否则 runaway。系：**L5 不破坏停止，但热稳定性是契约前提。**

**定理 30（SUBGAUGE 严格包含 MODGAUGE）** 共享集空、χ_T 平凡、u_impl=0、NTF 不激活、JCC 退化逐任务 ⇒ 逐指令等于 R73，再退化等于 R71/R68。安全单调不减；共享收益仅在账本/联合覆盖/可调度性通过时兑现。

**定理 31（共享基底安全保持）** 在 A114 暴露完备性 / A115 联合保形有效性 / A116 资源曲线上包络可靠性下：Valid(J_MOD) ∧ Valid(J_SCHED) ∧ NTF ⇒ 物理执行风险 ≤ ε_shared。**证明重量落在 A114（漏报一个共同原因即全盘失效）与 A115（conformal 分布外有效性）。**

**定理 32（ROB 保守安全与近似最优）** 任意降级只移除证据/缩窄 ⇒ 不确定度单调不减、保守方向安全；分数最优、整数有界近似。系：**掉电「先关谁」有可证安全方向，最优性只作近似承诺。**

## 7. 本轮最大风险

**一句话**：SUBGAUGE 把安全证明的负担从「契约表达力」进一步移到「**共同模式暴露声明的完备性与共享校准分布的可信性**」——共享把 N 个模块的认证绑到同一份数据/backbone/时钟/电源/热场上；只要存在一个未声明的共享失效因（数据偏差、共用固件 bug、全局温度梯度、共模电源纹波），所有模块会基于**同一被污染的分布**同时「合规地」过度自信：逐任务覆盖、联合覆盖、账本闭合、调度可行全部通过，而它们在分布外同时出错。**系统不是败于某个模块不准，而是败于共享基底把 N 个证据压缩成了 1 个伪证据**，而审计日志证明每一步都合规。

次级风险与缓解：
1. **暴露集漏报** → SEAL-CM 主动搜索共享失效因；未声明共享按完全相关 + 最坏资源计费并禁 PAR 缩窄；E410 演练漏报。
2. **JCC 分布外失效** → 分组条件 + 滑动重校准 + 偏移检出；超限退回保守并集。
3. **SAA 不可微失真** → 消融实测边际 + ε_ledger；超限判账本非法转最坏计费。
4. **热正反馈 runaway** → 稳定性条件写入契约；近包络强制降并发；E404 长时程验证。
5. **u_impl 被低估** → 保守方差上界，溢出按域违规 stub；int8 必重认证。
6. **NTF 过严扼杀收益** → certified/observer/appendix 分级；旁路任务不进风险预算。
7. **ROB 整数非最优** → 只承诺保守安全方向；安全否决模块不参与降级。
8. **集成膨胀** → 沿用结构上限；新字段版本化 + 默认平凡值，R73 配置零改动可跑（定理 30）。
