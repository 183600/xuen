# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~302；新一轮灵感循环第 1 轮；本轮灵感：「创新点」×「用户画像」）

> R73 用「证据契约 + 组合代数 + 热替换定理」把安全证明从全系统审计搬到了模块契约上，并用 CPB 把庞杂组件蒸馏成三条可证伪主张。但 CPB 只问了「这个组件服务哪条主张」，没有问三个更狠的问题：**对谁、相对什么基线、删掉它会不会变差？** 同时，R73 的证书只问「组合是否合法」，没有问「这张证书是给谁做决策用的、他承担什么风险、他看不看得懂、他是否在证据因果图里」。
>
> 本轮两个灵感正好把这两刀合成一把：
> - **创新点** → 创新不是「我新增了什么」，而是「**删掉它，某个决策者的决策损失会可复现地变差多少**」。据此建立**见证式创新（Witnessed Innovation）**与**创新差值代数 IDA**：有基线、有删除检验、有隔离消融、有新颖性重叠扣除，防止「同一机制换三个名字算三个创新点」。
> - **用户画像** → 画像不是市场细分，而是**证据因果图上的一个决策节点 + 一个非对称损失函数 + 一个证据预算 + 一个是否承担物理风险的角色**。据此建立**画像投影 PCP**：把全证据状态保守地投影成某画像的决策视图；任何投影只能加宽不确定度，绝不能凭空制造信心；安全真值跨画像取 meet，呈现可以不同、真值不能不同。
>
> 核心命题：**不再问「这个证据能否证明这个主张」，而问「这个主张对谁构成可复现的决策改进，且这种改进是否以某个受影响者的不可补偿风险为代价？」** 把 R73 的 MODGAUGE-RAS 扩展为 **PACT-RAS**（Persona-Anchored Claim Theory for RAS）——**画像锚定的主张理论**。

## 0. 直觉与动机

**灵感 1（创新点 → 从「功能清单」到「删除后谁的决策变差」）**
直觉：机器人论文里的创新点常常是「我们加入了 A、B、C」，但审稿人真正想知道的是「去掉 A，哪个指标会掉，掉多少，是否可复现」。一个组件如果没有隔离消融、没有相对基线的差值、没有删除检验，它在认识论上就不是创新点，只是工程附件。于是把创新点定义成一个**有符号的决策差值**：ΔL_p(c;β) = L_p(在基线 β 下的决策损失) − L_p(在 β∪{c} 下的决策损失)。再加三道闸：最近先验基线、TOST 删除检验、机制新颖性重叠扣除。这样「创新点」第一次变成可被证伪、可被计分、也可被**证伪为零**的对象。

**灵感 2（用户画像 → 画像是一个因果图上的决策节点，不是一个人口标签）**
直觉：同一张安全证书会被不同的人以不同方式使用：现场操作员要在 200ms 内决定是否接管；安全审计员要在离线审计里复算追溯链；监管者要判断是否批准部署；旁观者只想确认自己不会被撞。把「用户」抽象成一个标量风险数字，是一次**有损投影**；更糟的是，为了讨好某个画像而把仪表盘做漂亮，可能恰好把另一个画像的风险藏起来。正确的抽象是把画像建成**证据因果图 ECG（IP-302）里的一个决策节点 d_p**，附带非对称损失 L_p（漏报比误报贵，∞ 表示不可接受）、证据预算 B_p（延迟、可见量、呈现格式）、责任级别 Λ_p 和角色 ρ_p（是否承担物理风险）。画像相关性因此等于**因果可达性**：只保留 d_p 的因果祖先证据。

**灵感 3（合成 → 主张-画像-基线三元组，以及一条不可越狱的安全线）**
直觉：把两个灵感合起来，得到一条很干净的纪律：
1. 每个安全主张必须绑定**受影响者**（ρ=bearer）；受影响者不在场，主张不能进核心认证路径（否则就是**画像购物**）。
2. 画像只改变**举证负担与呈现方式**，不改变安全阈值与风险单调定理。不能让「换一个更容易满足的用户」变成「换一个更安全的世界」。
3. 创新的收益可以在画像间做 Pareto，但**受影响者的损失是 VETO**：不能被其他画像的收益补偿。
4. 任何画像视图都必须由全证据状态**保守投影**得到；跨画像的安全判定取 meet。于是「让仪表盘好看」在本体系里被证明为不可能——除非你把受影响者从名单里删掉，而那正是审计要抓的。

## 1. 形式化定义（增量：定义 400–415）

**定义 400（PACT-RAS 总览与六不变式）** PACT-RAS = (MODGAUGE-RAS†, PPM, PCP, PICA, IDA, AIT, J_PERSONA)。六不变式：
(i) **继承性**：R73 五不变式与 IP-302 的 ECG 全部保持；
(ii) **画像完备**：任何安全主张的画像集 P_C ⊇ P_affected；受影响者未登记的提案不得进入核心认证路径；
(iii) **投影保守**：π_p(X) ⪯ X（任何画像视图不得比全证据状态更自信）；
(iv) **安全不随画像变**：风险阈值、否决语义、风险单调定理与画像无关；画像只改变举证负担与呈现；
(v) **创新即差值**：每个创新点必须附带基线 β、见证度量 m、预注册阈值 δ_min、隔离消融与删除检验；
(vi) **受影响者否决**：若存在 p∈P_affected 使 L_p 恶化超过 ε_p，则整个创新主张被否决（非补偿），不得用其他画像的收益补偿。

**定义 401（用户画像 PPM）** p = (d_p, A_p, O_p, L_p, B_p, Λ_p, ρ_p, exposure_p)：
- d_p：ECG 中的决策节点（不是人口统计标签）；
- A_p：可执行动作集（批准部署 / 接管 / 停机 / 维护 / 采购 / 疏散）；
- O_p：结果空间；
- L_p: A_p × O_p → ℝ≥0 ∪ {∞}：非对称损失，∞ 表示不可接受结果；
- B_p：证据预算（最大延迟 ℓ_p、最大可见量 n_p、呈现格式）；
- Λ_p：责任级别（0..1），决定追溯链与可复算要求；
- ρ_p ∈ {bearer, decider, verifier, operator}；ρ_p = bearer 表示承担物理风险；
- exposure_p ≥ 0：暴露强度。
**P_affected = {p : ρ_p = bearer 或 exposure_p > 0}**。同一实体可以同时是 decider 与 bearer，但两个角色必须分别声明、分别计算损失。

**定义 402（画像投影 PCP）** 设全证据状态 X 与因果图 G（IP-302）。π_p(X) = widen(X|_{Anc_G(d_p)}; B_p)：保留 d_p 的因果祖先证据，再按预算 B_p 做区间加宽；丢弃节点只能加宽区间，不能收紧。性质：
- **保守性**：π_p(X) ⪯ X（细化序：π_p 的每个区间包含 X 的对应区间）；
- **因果相关性**：只保留能沿因果路径到达 d_p 的证据；
- **决策充分性**：若 argmin_a E[L_p | π_p(X)] = argmin_a E[L_p | X]，称 π_p 对 p 充分；否则标记 INSUFFICIENT，升级预算或拒绝该画像视图。
**画像因此是一个从证据状态到决策视图的、保守的、可审计的函子；不是过滤器。**

**定义 403（主张 PICA）** C = (φ, Σ, β, P_C, m, δ, 𝔈, H)：命题 / 运行范围 / 基线 / 画像集 / 度量向量 / 声明改进 / 证据包 / 预注册哈希。安全主张必须 P_C ⊇ P_affected；纯效率主张可以只绑定 decider/operator，但必须显式标注「不含受影响者，故不构成安全主张」。

**定义 404（创新见证 IW）** IW(c, C, p*, isolation, removal, NPA, δ_min)：组件 c 就主张 C 对画像 p* 构成见证式创新，当且仅当
(1) **隔离**：只切换 c 的消融显示 ΔL_{p*} 的下置信界 ≥ δ_min；
(2) **删除**：删除 c 后，TOST 在预注册等效界 ε_rm 内**不能**保持原指标（即删除确实变差）；
(3) **最近先验 NPA**：与最近先验工作的机制差与能力差都能写成可检验命题；
(4) **无害**：∀p∈P_affected，ΔL_p ≥ −ε_p（无人被伤害）。
**创新不是「新增了什么」，而是「删掉它，谁的决策会变差，变差多少」。**

**定义 405（创新类型）** τ_I ∈ {safety, efficiency, scientific, engineering}：
- safety：∃p∈P_affected 使 ΔL_p > 0；
- efficiency：只降低 decider/operator/verifier 的成本或延迟，不改变受影响者风险；
- scientific：在指定基准上改进预测或解释，但未证明下游决策损失改进；
- engineering：无隔离消融或无删除检验。
类型不可越狱：engineering 不能冒充 safety，scientific 不能冒充 safety。CPB 的「组件→主张」升级为「组件→(主张, 画像, 创新类型, 基线)」。

**定义 406（创新差值代数 IDA）** 对组件 c 与基线 β：Δ_p(c;β) = L_p(π_p(X_β)) − L_p(π_p(X_{β∪c}))。
- **SER**：Δ_p(c1∘c2;β) = Δ_p(c1;β) + Δ_p(c2;β∪c1) + I_p。I_p 为交互项：I_p>0 表示协同，可直接给下界；I_p<0 表示干扰，**必须实测**，不得假定可加。
- **PAR**：收益取 Pareto 前沿，不取标量和；成本取并集；禁止把同一机制在两个主张里重复计分。
- **VETO**：∃p∈P_affected, ΔL_p < −ε_p ⇒ witnessed = false，且整个组合被否决（非补偿）。
- **新颖性重叠**：N(IW_a, IW_b) = 1 − |share(mechanism, evidence)| / |union(mechanism, evidence)|；组合创新计数上界 ≤ Σ N。

**定义 407（受影响者登记与画像完备性）** P_affected 由**独立的暴露分析**给出，而不是由作者自由选择。**画像购物（persona shopping）** 形式化为：P_affected ⊄ P_C，或某个 p∈P_affected 的决策节点 d_p 不在 ECG 中（受影响者在证据图中不存在）。任一发生 ⇒ 安全主张不得进入核心认证路径。

**定义 408（画像覆盖证书 J_PERSONA）** J_p = (τ_p, π_p, coverage_p, trace_p, expiry_p)。Valid 当且仅当：π_p 保守且对 p 充分；coverage_p ≥ 1−α_p；追溯可复算；未过期；p∈P_affected ⇒ d_p 在 ECG 中可达。J_PACT = J_MOD ⊗ (⊗_{p∈P} J_p) ⊗ J_ECG ⊗ J_AIT。

**定义 409（反创新剧场审计 AIT）** 四道闸：
(a) **基线闸**：β 必须是最强可比基线，不是空基线；
(b) **删除闸**：TOST 删除检验；删掉不变差 ⇒ 不是创新源；
(c) **画像闸**：必须指出受益画像 p* 与完整 P_affected，且 P_affected 不被恶化；
(d) **重叠闸**：与已有 IP 的机制重叠 > ω_max ⇒ 只能算「改进」，不能算「新创新点」。
任一失败 ⇒ 降级为 engineering appendix，不进正文创新点列表。

**定义 410（呈现不变性）** 同一安全命题 φ 在不同画像投影下的保守判定必须一致：verdict = meet_{p∈P_affected} tier(π_p(X))。**呈现可以不同，安全真值不能不同**；若某画像显示「安全」而另一受影响画像显示「不安全」，系统取不安全（非补偿）。

**定义 411（画像漂移与再校准）** 画像不是静态的：团队角色、任务、监管、人员更替都会改变 L_p 与 B_p。定义 Δ_persona = TV(L_p^t, L_p^0) + |B_p^t − B_p^0|；超过阈值 ⇒ J_p 失效，必须重新征询（participatory re-elicitation）或降低主张层级。**不能让画像在部署后被悄悄替换成更容易满足的那个。**

**定义 412（严格退化）** 取 P = {p_∞}（全知、零预算约束、承担全部风险、L 为指示损失），关闭 AIT，IDA 退化为标量差值，则 PACT-RAS 逐指令等于 R73 MODGAUGE-RAS（再退化到 R72/R71/R68）。

**定义 413（创新的可证伪性记录）** 每个创新点附带 F = (δ_min, power, α, seeds, sealed holdout, TOST margin)。F 之外无创新。每个创新点必须能回答三问：**删掉它谁变差？变差多少？这个「谁」是否包含受影响者？**

**定义 414（MB4 画像基准）** MB4：三组画像（受影响者 / 决策者 / 验证者）× 两个任务 × 有/无投影预算；预注册决策损失、覆盖率、审计时间。≤3h 单卡可复现（画像征询用脚本化问卷 + 历史决策日志回放）。

**定义 415（治理残差）** 形式化只能保护登记在册的画像。定义 R_gov = P(存在未登记但真实的受影响者)。R_gov 不能由系统内部证明为零，只能由独立登记、第三方红队与事后复盘降低。**这是 PACT 的理论边界，不是实现 bug。**

## 2. 关键算法骨架

```python
# IP-303 PPM：用户画像（ECG 决策节点 + 非对称损失 + 预算 + 角色）
@dataclass(frozen=True)
class Persona:
    d_p: str                       # ECG 决策节点（IP-302）
    actions: Tuple[Action, ...]
    loss: LossMatrix               # A×O → R>=0 ∪ {inf}
    budget: EvidenceBudget         # latency, n_items, format
    accountability: float
    role: str                      # bearer/decider/verifier/operator
    exposure: float

def affected(personas):
    return [p for p in personas if p.role == 'bearer' or p.exposure > 0]

# IP-304 PCP：画像投影（因果祖先 + 只加宽 + 充分性检验）
def project(X, p, G):
    anc = causal_ancestors(G, p.d_p)
    if not (anc & X.evidence_nodes):
        raise PersonaNotRepresented(p)        # 画像购物：受影响者不在因果图
    V = restrict(X, anc)
    V = widen_to_budget(V, p.budget)          # 只加宽，绝不收紧
    if not decision_sufficient(V, X, p):      # 校准集上 argmin 是否一致
        return Insufficient(V, p)             # 升级预算或拒绝
    return V

# IP-305 PICA：主张（命题/范围/基线/画像/度量/证据/预注册）
@dataclass(frozen=True)
class Claim:
    phi: str; scope: Domain; baseline: Config
    personas: FrozenSet[Persona]; metrics: Tuple[str, ...]
    delta: Dict[str, float]; evidence: EvidenceBundle
    prereg_hash: str

# IP-306 IDA：创新差值代数（SER/PAR/VETO + 新颖性重叠）
def compose_innovation(a, b, op):
    if op == 'SER':
        return IW(delta=a.delta + b.delta + measure_interaction(a, b),
                  novelty=a.novelty + b.novelty - overlap(a, b),
                  veto=a.veto | b.veto)
    if op == 'PAR':
        return Pareto([a, b])                 # 收益取前沿、成本取并集
    if op == 'VETO':
        if a.harm_affected or b.harm_affected:
            return Rejected                   # 非补偿：受影响者不可被牺牲

# IP-307 AIT：反创新剧场审计（四闸）
def anti_theater(iw):
    gates = [
        iw.baseline != EMPTY_BASELINE,
        not tost_equivalent(remove(iw.c), iw.baseline, iw.eps_rm),
        iw.p_star in iw.claim.personas and affected(iw.claim.personas) <= iw.claim.personas,
        novelty_overlap(iw, existing_ips) <= OMEGA_MAX,
        all(delta_loss(p, iw) >= -EPS[p] for p in affected(iw.claim.personas)),
    ]
    return all(gates) or 'APPENDIX'

# IP-308 J_PERSONA + IP-309 PACT 主闭环（R73 三域不变，叠加画像层）
def PACT_round(M, obs, audio, tac_frame, depth_img):
    k, lam, J_mod = MODGAUGE_round(M, obs, audio, tac_frame, depth_img)  # R73 原样
    X = M.snapshot.read_latest()
    views = {p: project(X, p, M.ecg) for p in M.personas}
    for p, V in views.items():
        assert conservative(V, X)                  # 引理 38，运行时断言
    verdict = meet(tier(views[p]) for p in affected(M.personas))  # 定义 410
    J_persona = combine(J_mod, views, M.ecg, M.ait)               # 定义 408
    M.audit_log.write(views, verdict, J_persona)                  # 谁看到什么版本
    return k, lam, J_persona, verdict

# IP-310 画像漂移监控（定义 411）
def monitor_persona_drift(personas, new_logs):
    for p in personas:
        L_new = reestimate_loss(p, new_logs)
        if tv(L_new, p.loss) + budget_diff(p) > TAU_PERSONA:
            p.cert.valid = False                  # 证书失效 → 再征询
            escalate(p, 'PERSONA_DRIFT')

## 3. 推导

**引理 38（投影保守性：无法凭空制造信心）** π_p 是 X 的确定性函数，且只做「按因果祖先丢弃 + 区间加宽」。对任意单调查询 q，[l_q(π_p(X)), u_q(π_p(X))] ⊇ [l_q(X), u_q(X)]。故任何画像视图不能产生比全状态更窄的区间。系：**「把仪表盘做漂亮」在本体系里被证明为不可能——除非丢弃受影响者，而那正是审计要抓的。**

**引理 39（因果相关性与决策充分性）** 若 d_p 的决策只依赖 Anc(d_p)，则 π_p 保留全部决策相关信息；若预算迫使丢弃节点，则相应区间必须加宽；当且仅当 argmin 决策不变时 π_p 对 p 充分。系：**画像不是过滤器，而是该画像决策的充分统计量（或显式标记不充分）。**

**引理 40（创新非可加性）** 对 SER，Δ(c1∘c2) = Δ(c1) + Δ(c2|β∪c1) + I；I<0 时不能假定可加；对 PAR，收益是 Pareto 前沿而非标量和。存在证据重叠 ω 时，组合创新计数 ≤ Σ N。系：**创新点数守恒：同一机制不能重复计分。**

**引理 41（删除检验的证伪性）** 若删除 c 后指标在预注册等效界 ε_rm 内（TOST），则在给定功效下不能声称 c 是创新来源；反之，若隔离消融显著且删除显著，则 c 的贡献可归因。系：**「加了很多模块」与「有创新点」在统计上被分开。**

**引理 42（受影响者单调性）** 增大 P_affected 只会降低或保持系统层级与主张强度：tier(P ∪ {p}) ≤ tier(P)。系：**把更多人算进受影响者是安全的；把人从名单里删掉才是危险的。**

**定理 30（PACT 严格包含 R73）** 取单全知画像 p_∞、关闭 AIT、IDA 退化为标量、P_affected={p_∞}，则 PACT 逐指令等于 R73 MODGAUGE（再退化 R72/R71/R68）。安全单调不减。

**定理 31（画像索引的安全迁移）** 若 ∀p∈P_affected∪P_decision，Valid(J_p) 且 AIT 通过，则：(i) 任何画像视图不高估安全（引理 38）；(ii) 系统判定取 meet，是保守下界（定义 410）；(iii) 每个被见证的创新对 p* 的决策损失有下界改进，且对所有受影响者不越否决阈。**但保护范围严格等于登记在册的画像集——定理不会保护一个没被写进 P_affected 的人。**

**定理 32（反剧场可靠性）** 若 AIT 四闸通过，则所声称的 Δ 可归因于 c（在预注册协议与给定功效下）；若删除检验显示等价，则不能声称 c 为创新源。逆否命题直接给出自动降级规则。

**定理 33（创新组合的 Pareto 保持与计数上界）** IDA 的 SER/PAR 组合在每个画像上保持弱改进（Pareto），且组合的「创新点数」≤ Σ 单项新颖性；VETO 组合保证受影响者不被补偿性牺牲。系：**创新可以组合，但不能被「组合」出来。**

## 6. 本轮最大风险

**一句话**：PACT 把「创新」和「安全」都变成了以画像为索引的对象，但画像集本身是由被评估方选择的——如果 P_affected 漏掉了真正的风险承担者（旁观者、未来操作员、维护工人），或者 L_p 被误设成一个只关心演示成功的损失函数，那么系统会生成一张**形式完全合法、四闸全过、审计日志完美**的创新证书，证明它「显著改善了用户的决策损失」，而那个真正被改变命运的人，从未出现在因果图里：**我们会用最严谨的代数，认证一个虚构用户的创新。**

## 2. 形式化定义（要点版）

**定义 400（PACT-RAS 与六不变式）** 继承性 / 画像完备（P_C⊇P_affected）/ 投影保守（π_p⪯X）/ 安全不随画像变 / 创新即差值 / 受影响者否决（非补偿）。

**定义 401（PPM 用户画像）** 画像不是人口标签，而是 **ECG 决策节点 + 非对称损失 + 证据预算 + 责任级别 + 角色**。同一实体可同时是决策者与风险承担者，但两个角色分别声明、分别计损。

**定义 402（PCP 画像投影）** 保留 d_p 的因果祖先证据，按预算做**区间加宽**；丢弃节点只能加宽。三性质：保守性、因果相关性、决策充分性（argmin 不变；否则 INSUFFICIENT）。

**定义 403（PICA 主张）** 安全主张必须覆盖 P_affected；效率主张必须显式标注「不含受影响者，故非安全主张」，防止类型越狱。

**定义 404（IW 创新见证）** 隔离下置信界 ≥δ_min；TOST 删除不能等价；最近先验机制差/能力差可检验；∀p∈P_affected，ΔL_p≥−ε_p。**创新 = 删掉它谁变差、变差多少。**

**定义 405（创新类型）** safety / efficiency / scientific / engineering；类型不可越狱；CPB 的「组件→主张」升级为「组件→(主张, 画像, 类型, 基线)」。

**定义 406（IDA 创新差值代数）** SER：Δ=Δ1+Δ2|β1+I，I<0 必须实测；PAR：Pareto 前沿、成本并集；VETO：受影响者受害即整体否决；新颖性重叠 N 扣除重复计分。

**定义 407（画像购物）** P_affected ⊄ P_C，或 d_p 不在 ECG 中 ⇒ 安全主张不得进入核心认证路径。**受影响者在证据图中不存在，是治理失败而非统计失败。**

**定义 408（J_PERSONA）** 保守性 + 充分性 + 覆盖率 ≥1−α_p + 追溯可复算 + 未过期 + 受影响者节点可达；组合进 J_PACT。

**定义 409（AIT 四闸）** 基线闸（最强可比基线）/ 删除闸（TOST）/ 画像闸（受益者+受影响者+无恶化）/ 重叠闸（>ω_max 只算改进）。任一失败 ⇒ 工程附件。

**定义 410（呈现不变性）** 同一条安全命题跨画像判定取 meet；呈现可不同，真值不能不同；一个画像说安全、另一个受影响画像说不安全 ⇒ 取不安全。

**定义 411（画像漂移）** Δ_persona 超阈 ⇒ J_p 失效、再征询或降级；禁止部署后把画像换成更容易满足的那个。

**定义 412（严格退化）** 单全知画像 + 关闭 AIT + 标量 IDA ⇒ PACT 逐指令等于 R73 MODGAUGE（再退化 R72/R71/R68）。

**定义 413（可证伪性记录）** F=(δ_min,power,α,seeds,sealed holdout,TOST margin)；每个创新点必须回答「删掉谁变差/变差多少/是否含受影响者」。

**定义 414（MB4）** 三组画像 × 两任务 × 有/无投影预算；预注册决策损失、覆盖率、审计时间；脚本化征询 + 历史日志回放。

**定义 415（治理残差）** R_gov=P(∃未登记真实受影响者)；系统内部不可证零，只能靠独立登记/第三方红队/事后复盘降低。

# IP-303 PPM：用户画像
@dataclass(frozen=True)
class Persona:
    d_p: str                     # ECG 决策节点
    actions: Tuple[Action, ...]
    loss: LossMatrix             # A×O → R>=0 ∪ {inf}
    budget: EvidenceBudget       # latency, n_items, format
    accountability: float
    role: str                    # bearer/decider/verifier/operator
    exposure: float

def affected(personas):
    return [p for p in personas if p.role == 'bearer' or p.exposure > 0]

# IP-304 PCP：画像投影（因果祖先 + 只加宽 + 充分性）
def project(X, p, G):
    anc = causal_ancestors(G, p.d_p)             # IP-302 ECG 祖先集
    if not (anc & X.evidence_nodes):
        raise PersonaNotRepresented(p)           # 画像购物：受影响者不在因果图
    V = widen_to_budget(restrict(X, anc), p.budget)   # 只加宽
    if not decision_sufficient(V, X, p):         # 校准集上 argmin 是否一致
        return Insufficient(V, p)                # 升级预算或拒绝
    return V

# IP-305 PICA：画像索引主张
@dataclass(frozen=True)
class Claim:
    phi: str; scope: Domain; baseline: Config
    personas: FrozenSet[Persona]; metrics: Tuple[str, ...]
    delta: Dict[str, float]; evidence: EvidenceBundle
    prereg_hash: str

# IP-306 IDA：创新差值代数
def compose_innovation(a, b, op):
    if op == 'SER':
        return IW(delta=a.delta + b.delta + measure_interaction(a, b),
                  novelty=a.novelty + b.novelty - overlap(a, b),
                  veto=a.veto | b.veto)
    if op == 'PAR':
        return Pareto([a, b])                    # 收益取前沿、成本取并集
    if op == 'VETO':
        if a.harm_affected or b.harm_affected:
            return Rejected                      # 非补偿

# IP-307 AIT：反创新剧场四闸
def anti_theater(iw):
    gates = [
        iw.baseline != EMPTY_BASELINE,
        not tost_equivalent(remove(iw.c), iw.baseline, iw.eps_rm),
        iw.p_star in iw.claim.personas and affected(iw.claim.personas) <= iw.claim.personas,
        novelty_overlap(iw, existing_ips) <= OMEGA_MAX,
        all(delta_loss(p, iw) >= -EPS[p] for p in affected(iw.claim.personas)),
    ]
    return all(gates) or 'APPENDIX'

# IP-308 J_PERSONA + IP-309 PACT 主闭环
def PACT_round(M, obs, audio, tac_frame, depth_img):
    k, lam, J_mod = MODGAUGE_round(M, obs, audio, tac_frame, depth_img)  # R73 原样
    X = M.snapshot.read_latest()
    views = {p: project(X, p, M.ecg) for p in M.personas}
    for p, V in views.items():
        assert conservative(V, X)                # 引理 38 运行时断言
    verdict = meet(tier(views[p]) for p in affected(M.personas))  # 定义 410
    J_persona = combine(J_mod, views, M.ecg, M.ait)               # 定义 408
    M.audit_log.write(views, verdict, J_persona)  # 记录谁看到哪个版本的什么结论
    return k, lam, J_persona, verdict

# IP-310 PDM：画像漂移监控
def monitor_persona_drift(personas, new_logs):
    for p in personas:
        L_new = reestimate_loss(p, new_logs)
        if tv(L_new, p.loss) + budget_diff(p) > TAU_PERSONA:
            p.cert.valid = False
            escalate(p, 'PERSONA_DRIFT')
```

## 4. 推导

**引理 38（投影保守性：无凭空信心）** π_p 是 X 的确定性函数且只丢弃+加宽 ⇒ 任意单调查询区间包含全状态区间 ⇒ 画像视图不能更自信。系：**仪表盘无法被做漂亮，除非丢掉受影响者。**

**引理 39（因果相关性与决策充分性）** 决策只依赖 Anc(d_p) 时投影保留全部相关信息；预算丢节点必须加宽；argmin 不变 ⇔ 充分。系：**画像是决策的充分统计量，或其不充分的显式标记。**

**引理 40（创新非可加性）** SER 的交互项 I 可正可负；PAR 取 Pareto 前沿；重叠 ω 使组合计数 ≤ΣN。系：**创新点数守恒，同一机制不能重复计分。**

**引理 41（删除检验的证伪性）** TOST 等价 ⇒ 不能声称 c 为创新源；隔离显著且删除显著 ⇒ 贡献可归因。系：**「加模块」与「有创新」被统计地分开。**

**引理 42（受影响者单调性）** tier(P∪{p}) ≤ tier(P)。系：**扩大受影响者集合是安全的；删名单是危险的。**

**定理 30（PACT 严格包含 R73）** 单全知画像 + 关 AIT + 标量 IDA ⇒ 逐指令等于 R73 MODGAUGE ⇒ R72/R71/R68。安全单调不减。

**定理 31（画像索引安全迁移）** ∀p∈P_affected∪P_decision，Valid(J_p) 且 AIT 通过 ⇒ (i) 画像视图不高估安全；(ii) meet 是保守下界；(iii) 被见证创新对 p* 有下界改进且不越受影响者否决阈。**保护范围 = 登记在册的画像集。**

**定理 32（反剧场可靠性）** AIT 四闸通过 ⇒ Δ 可归因于 c（预注册+功效）；删除等价 ⇒ 不可声称；逆否给出自动降级。

**定理 33（创新组合 Pareto 保持与计数上界）** SER/PAR 组合在每个画像上保持弱改进；创新点数 ≤Σ 单项新颖性；VETO 保证受影响者不被补偿牺牲。系：**创新可组合，但不能被「组合」出来。**

## 8. 本轮最大风险

**一句话**：PACT 把创新与安全都变成以画像为索引的对象，但画像集是由被评估方选择的；若 P_affected 漏掉真正的风险承担者，或 L_p 被误设成只关心演示成功的损失函数，系统就会用一套形式合法、四闸全过、审计日志完美的代数，认证一个**虚构用户**的创新——**定理 31 只保护登记在册的人，而危险恰恰来自没被登记的人。**
