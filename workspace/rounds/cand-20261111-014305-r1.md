# 第 51 轮（承接第 50 轮 v14；新灵感循环第 1 轮；本轮灵感：视觉语言模型 × 模型蒸馏） · GroundDistill：开放词汇接地证书 × 语言契约准入 × 接地感知蒸馏（八层架构 v15）

> 承接第 50 轮 v14 CoStride-Distill。v14 的 propose–dispose 只把不对称施加在**动作搜索**上：student 近似搜索、G_exact 精确处置。但它隐含三个新假设：**H11：感知语义是闭集、可精确求值、点估计即真值**——对象类别/属性/指代由固定检测器给出，语义从不进入安全论证；**H12：蒸馏只发生在动作层，teacher 的语义标签被默认为真值**——于是"蒸馏只损失可用性"的论证默认了标签本身无错；**H13：自然语言只以"设计者已离线形式化好"的共创条款出现**——语言→形式化的接地被假设为零误差、零歧义。两个灵感词精确命中：**视觉语言模型**打破 H11/H13（开放词汇、语言条件化、强提议弱校准、OOD 幻觉），**模型蒸馏**在 VLM 语境下打破 H12（蒸馏"答案"会制造"自信地错"的学生，且语义漂移比动作漂移更难被物理证书发现）。三者耦合出的新问题：**语义接地必须与动作搜索同构地拆成"提议—处置"；自然语言共创必须先过接地证书再过能力格；VLM 蒸馏只能蒸馏"谓词分解与弃权"，绝不能蒸馏"认证"本身**。

## 0. 直觉与动机

**灵感 1（视觉语言模型 → 开放词汇感知是"提议器"，不是"真值源"）**
直觉：VLM 的真正强项是"把开放词汇的 ⟨语言, 图像⟩ 变成候选指代/属性/关系假设"，弱项是校准、计数、细粒度空间关系与 OOD。把它放在安全路径的"真值"位置，等于让幻觉直接变成动作。正确切口是照搬 v14 在动作层做对的事：VLM 只产生 **grounding proposals**（top-k 指代 + 属性/关系合取 + 权重）；一个**精确接地校验器**只用已认证的度量-语义地图 `M` 与**可校验谓词集 `V_cov`** 去确认。开放词汇把"提议空间"放大，但"可确认空间"仍是有限的：超出 `V_cov` 的谓词永远不能自动确认，只能追问或回退。这就是把"只近似搜索、绝不近似评估"从动作层搬到语义层。

**灵感 2（视觉语言模型 → 指代歧义应按"动作等价商"而非"视觉相似度"度量）**
直觉：若 VLM 在两个杯子间犹豫，但两个杯子诱导的认证动作集相同（都能安全抓、都过 PFL），则歧义对执行无害，直接做；若在杯子和刀之间犹豫，即便视觉差异很小，也必须追问。也就是说，**"不确定"只有在跨过动作等价类时才危险**。形式化：用证书诱导的等价关系 `r ~_ctx r'`（两者可选认证动作集相同）对候选指代取商，歧义只在商空间上计数。这把不确定性从像素层抬到安全层：既显著降低用户追问负担，又不放松任何硬门槛。

**灵感 3（模型蒸馏 → 蒸馏"分解与弃权"，而不是蒸馏"答案"）**
直觉：VLM teacher 的价值不是"说出那个词"，而是把开放词汇 `ℓ` 分解成 `V_cov` 内可精确校验的谓词合取；student 若只模仿答案，就会在 OOD 上自信胡说。接地感知蒸馏（GAD）的标签因此是三元组 `(谓词分解, 认证裕量, 弃权)`；损失含**弃权校准**： teacher 判为"不可表达/跨等价类/地图失配"的样本，student 必须学会弃权。弃权只增加追问与回退，不产生错误放行——这是"蒸馏损失可用性、不损失 soundness"在语义层的精确对应。

**灵感 4（语言共创 → 自然语言先接地、再过能力格）**
直觉：用户说"厨房里可以快一点，但别碰台面上的玻璃杯"。VLM 把它编译成候选条款，但每一步都要落地：厨房→区域接地证书；玻璃杯→指代接地证书；"快一点"→能力格 + 双足可行性剪辑。任一接地失败即追问，而不是猜。关键约束：VLM 既无权新增授权，也无权改写不可委托条款——编译器是"翻译提议者"，准入权在精确检查器手里。

**灵感 5（VLM × 证伪 → 语义场景生成器）**
直觉：PFV 的数值扰动覆盖不到"语义组合"层面的失效（逆光下的黑色电缆、有人抱着大箱子堵在玻璃门前、与背景同色的把手）。让 VLM teacher 生成开放词汇的**语义扰动场景**，给 PFV 预算提优先级；精确证伪器仍只负责定罪。语义场景生成器的假阴性只浪费预算，不产生放行——与 LFF 完全同构。

**耦合升级**：仍八层 v15。L1 由"闭集几何感知"升级为**开放词汇感知 + 接地校验**；L2.5 在共创契约前增加**语言→契约准入**；跨层在 KDX 旁增加**接地蒸馏通道 GAD**，在 LFF 旁增加**语义场景通道 SFF**。安全不对称升级为**双层提议—处置**：动作层=学生近似搜索、G_exact 精确处置；语义层=VLM 近似提议、`V_ground` 精确处置。两层共享同一句红线：**提议错误只损失可用性/增加追问，永不损失 soundness**。

## 1. 形式化定义（增量：定义 87–92）

**定义 87（开放词汇接地算子与提议集）**
接地算子 `Γ_θ:(o, ℓ, ctx) → P={(r_i, φ_i, p_i)}_{i=1..k}`，其中 `r_i` 为指代（对象/区域/关系图元），`φ_i` 为属性与关系的合取，`p_i` 为未校准权重。`P` 只具**提议地位**，不具真值地位；任何安全路径不得直接消费 `P`，只能消费由定义 88 签发的接地证书。

**定义 88（可校验谓词覆盖与接地证书）**
认证度量-语义地图 `M=(O, A, R, h_M)`：对象集、闭集属性（颜色/类别/材质/可通行性，带认证精度）、度量区域与关系，`h_M` 为地图版本哈希。可校验谓词集 `V_cov={φ : φ 可由 M 精确求值}`，其求值成本经离线认证 `≤ τ_ground` 并带运行时看门狗。
接地证书 `G_c(ℓ,o,ctx)=(φ^*, R^*, Amb_G, h_M)` 合法当且仅当：
(i) **可表达**：`φ^*∈V_cov` 且 `φ^*` 在 `V_cov` 语义下与 `ℓ` 等价；若 `ℓ` 含 `V_cov` 外谓词（如"那个看起来很不稳定的"），拒绝并返回缺失谓词集；
(ii) **认证指代**：`R^*={r∈R : eval_exact(M,r,φ^*)}` 非空，且 `R^*` 完全由 `M` 决定（VLM 不能"说"出指代）；
(iii) **动作产物歧义**：令 `[r]` 为 `r` 在关系 `r ~_ctx r' ⇔ Act_cert(r,ctx)=Act_cert(r',ctx)` 下的等价类（`Act_cert` 为以该指代为参数时可选的认证动作集，含 PFL 与可行性约束），
`Amb_G = 1 − max_{c} Σ_{i: [r_i]=c} p_i`（主导等价类之外的提议质量）；要求 `Amb_G ≤ τ_amb`，否则必须追问；
(iv) **地图一致**：`h_M` 与当前地图哈希一致，否则 fail-closed。
`G_c` 由 `V_ground` 精确签发，VLM 与 student 均无权签发。

**定义 89（语言→契约准入 LCA）**
编译器 `Λ_θ:(ℓ_c,ctx) → {κ_cand}`（自然语言共创条款 → 候选契约，允许返回多个候选）。准入 `Adm(κ_cand)` 精确检查：(i) schema 良构；(ii) 每个术语都有合法 `G_c`；(iii) `clause ⊑ scope.cap`（能力格）；(iv) 不触根信任（PFL/屏障类别/MRC/审计不可委托）；(v) 双签署模板可生成。**0 个或多于 1 个候选一律转为"追问/用户确认"，禁止静默择一**；VLM 编译错误只能导致拒绝或追问，不能扩大授权。

**定义 90（接地感知蒸馏 GAD）**
teacher `Γ_T`、student `Γ_S`。由 `V_ground` 在 teacher 提议上生成三类认证标签：
`D_dec={(o,ℓ,ctx,φ^*)}`（分解标签）、`D_abs={(o,ℓ,ctx,⊥)}`（弃权标签：不可表达/跨等价类/地图失配）、`D_mrg`（认证裕量标签）。
损失 `L_GAD = L_imitate(D_dec) + λ_m L_margin(D_mrg) + λ_a L_abstain(Γ_S, D_abs) + λ_d L_disagree(Γ_S, Γ_T)`，其中 `L_abstain` 要求 student 在 `D_abs` 上弃权率 ≥ 1−ε_abs 或在跨等价类处不确定性高于阈值。部署：student 提议 → `V_ground` 精确校验 → 通过才成为事实。**蒸馏只逼近"提议与谓词分解"，不替代 `M`、`V_cov`、动作等价商与认证**。

**定义 91（语义证伪前端 SFF）**
`SFF_ψ : (证书集, 弱点区域) → 语义场景分布`；由 VLM teacher 生成开放词汇场景（属性替换、关系组合、遮挡/光照/对抗纹理/文本注入），与 LFF 的数值权重相乘后分配 PFV 预算。只有**精确证伪器**能定罪；SFF 的假阴性只浪费预算，不产生放行。

**定义 92（接地账本与十源归因）**
`CCL-G` 在 `CCL++` 上追加：接地证书（含 `φ^*, Amb_G, h_M`）、弃权/追问事件与追问预算、LCA 准入结果、SFF 定罪场景哈希、VLM–student 分解分歧。DDA 归因扩为**十源**：感知/关节/边界/意图/接触/传输/**动力**/**动作蒸馏**/**语义接地**/**语言编译**。追问预算 `B_ask` 与超时回退显式入账，**不得用"猜一个"换性能**。

## 2. 新增产出与既有 IP 升级

**IP-91 SGC（Semantic Grounding Certificate）**：开放词汇提议 + `V_cov` 精确确认 + 动作等价商歧义度量；`V_ground` 签发、成本认证、看门狗兜底。
**IP-92 LCA（Language-to-Contract Admission）**：自然语言→候选契约编译器 + 精确准入（能力格/不可委托/接地/双签署）；多解即追问。
**IP-93 GAD（Grounding-Aware Distillation）**：蒸馏"谓词分解 + 弃权 + 裕量"，认证门控部署；语义层 propose–dispose。
**IP-94 SFF（Semantic Falsifier Front-end）**：VLM 生成开放词汇语义场景给 PFV 提优先级；无定罪权。
**IP-95 CBM（Clarification Budget Manager）**：追问/回退的预算与用户负担管理；歧义跨等价类才追问，超预算即保守回退或人工接管。

**既有 IP 升级**
IP-80 SIG：意图后验增加"已认证接地"项；接地歧义跨等价类时强制 σ 落到硬下界并追问。
IP-82 IPC：新增"追问/澄清"协议状态；用户确认既作意图证据也作接地证据。
IP-86 UCC：自然语言共创一律经 LCA；能力格与不可委托条款不变。
IP-89 KDX：动作候选必须携带 `G_c` 标识；引用未接地/歧义指代的候选被精确守卫直接拒绝。
IP-90 LFF：与 SFF 组合（数值权重 × 语义场景），共用同一 PFV 预算池。
IP-83 PFV：注入语义扰动场景（逆光、同色、遮挡、文本注入）。
IP-84 XFER：传输缺口增加"接地覆盖差"维度（不同场地的 `V_cov`/`M` 覆盖差异）。
IP-77 DDA：八源 → 十源（+语义接地、+语言编译）。
IP-61 DCL：采集接地拒绝、VLM–student 分解分歧、追问未响应、跨等价类误判样本。
IP-62 CCA：红队语义幻觉、场景文本提示注入、对抗纹理、OOD"自信地错"、越权语言条款。
IP-51 CAR：守卫追加"接地证书有效 ∧ 地图版本匹配 ∧ `V_cov` 覆盖判定 ∧ 求值看门狗正常"。
IP-45 总线：新增 grounding-cert / ambiguity / clarification-request / map-version 话题。
IP-75 ASC：抽象只能使用已确认接地；开放词汇提议可提示抽象候选，但不得直接定型。
IP-74 HTD-Cert：分解节点绑定接地证书，边蕴含需要已接地前置条件。
IP-72 RRP：e-process 纳入接地/弃权/追问证据；跨层传输仍带 δ。
IP-76 CCL：升级为 `CCL-G`（定义 92），仍只追加。
IP-66/67/68：语音成为开放词汇接地入口（说话+指向=多模态提议）；记忆存储接地历史与地图版本；SAB 处理澄清多轮。

## 3. 算法骨架

每个宏周期：
1. 读目标、证书、租约、`CCL-G`、契约版本哈希 `h(κ_c)` 与地图哈希 `h_M`；任一失效 → fail-closed。
2. HTD-Cert 展开/复用 DAG；节点前置条件改为"已签发的接地证书或可精确校验的几何谓词"。
3. **语义提议—处置**：VLM/`Γ_S` 提议 `(r_i,φ_i,p_i)`；`V_ground` 只接受 `V_cov` 可表达、`M` 可确认、`Amb_G≤τ_amb` 的 `G_c`；否则进入追问（CBM）或保守回退。
4. 更新意图信念：`b'` 融合"已签承诺 + 已认证接地"；`Amb_G` 跨等价类时 σ 落到硬下界。
5. UCC 校验：自然语言条款先过 LCA（接地 + 能力格 + 不可委托 + 双签署）；多解即追问；通过后异步触发 teacher 重解/重蒸馏，旧 student 即刻失效。
6. KDX 提议—处置：student 提议 `(u_r,a,m,q,ι,κ)` 且携带 `G_c`；`G_exact` 精确求值 B/B_v/PFL/Inv/共识/版本/租约/接地；通过才执行；否则更多候选 → 限量完整搜索 → CRM。
7. 执行前后 CBG+ 复核边界蕴含 ∧ 屏障 ∧ 可行 ∧ PFL ∧ 共识 ∧ 版本 ∧ 接地；通过才追加 `CCL-G`。
8. 实测违反（含滑移/推撞/捕获失败/抓错指代）：DDA 十源归因；语义类违反回灌 DCL 并触发 GAD 重蒸馏。
9. 离线/并行：PFV 预算由 LFF（数值）× SFF（语义）共同分配并证伪；新反例回灌 DCL/CCA，共蒸馏 student 与 LFF/SFF。
10. 所有路径（接地、抽象、契约、动作）均不可行 → 追问 → 技能合成/人工接管/保护姿态/fail-closed，绝不绕过 `V_ground`、L3.5 与 `G_exact`。

## 4. 本轮最大风险

**一句话**：整个"语义层 propose–dispose 只损失可用性、不损失 soundness"的论证，承重点从动作层悄悄转移到了**感知地图 `M`/可校验谓词集 `V_cov` 与动作等价商的正确性**上——如果 `M` 本身有错、`V_cov` 把不可靠谓词当成可精确求值、或动作等价商把危险的不同动作误判为等价，那么 VLM 的幻觉会被"精确校验器"盖章成事实；而 GAD 又会在分布漂移下把学生训练成"在恰恰该弃权时最自信"，于是追问/回退这道最后防线可能最先失效。

## 2. 关键算法 伪代码

### IP-91 SGC（提议—处置）
```
def ground_and_verify(o, ell, ctx, proposer, M, V_cov):
    P = proposer.propose_grounding(o, ell, ctx, n=K_G)   # 仅提议，不当真值
    phi = decompose_into(P, V_cov)                       # 只能分解到可校验谓词
    if phi is None:
        return Grounding(ok=False, reason='not_expressible',
                         missing=missing_predicates(ell, V_cov))
    R = {r for r in M.regions if eval_exact(M, r, phi)}   # 指代由 M 决定
    if not R:
        return Grounding(ok=False, reason='no_certified_referent')
    classes = [action_equiv_class(r, ctx) for r in R]     # Act_cert 相等即同类
    amb = 1.0 - max(prop_mass(P, c) for c in distinct(classes))
    if amb > TAU_AMB:
        return Grounding(ok=False, reason='ambiguous', amb=amb, candidates=R)
    return Grounding(ok=True, phi=phi, region=choose(R),
                     amb=amb, h_M=M.hash)                 # V_ground 签发
```

### IP-92 LCA（语言→契约准入）
```
def lca_admit(ell_c, ctx, compiler, auth, M, V_cov):
    cands = compiler.compile_contract(ell_c, ctx)         # 允许 0/多解
    admitted = []
    for k in cands:
        if not all(ground_and_verify(o, term, ctx, compiler, M, V_cov).ok
                   for term in k.terms):
            continue                                      # 术语未接地 → 拒
        if not lattice_leq(k.relaxation, auth.scope_of(ctx.user).cap):
            continue                                      # 超能力格 → 拒
        if touches_root_trust(k):
            continue                                      # 不可委托 → 拒
        admitted.append(k)
    if len(admitted) != 1:
        return ('clarify', admitted)                      # 0/多解都追问
    return ('accept', sign(admitted[0]))
```

### IP-93 GAD（蒸馏分解与弃权）
```
def gad_train(teacher, student, D, M, V_cov):
    dec, abst, mrg = [], [], []
    for (o, ell, ctx) in D:
        g = ground_and_verify(o, ell, ctx, teacher, M, V_cov)
        if g.ok:
            dec.append((o, ell, ctx, g.phi)); mrg.append((o, ell, g))
        else:
            abst.append((o, ell, ctx, g.reason))          # 弃权标签
    loss = L_imitate(dec) + LAMBDA_M * L_margin(mrg) \
         + LAMBDA_A * L_abstain(student, abst) \
         + LAMBDA_D * L_disagree(student, teacher)
    student.update(loss)
    return certification_gate(student, heldout)           # 零违例 + 弃权校准通过才服役
```

def falsify_semantic(certs, budget, vlm_teacher, lff, exact_falsifier):

### IP-73 JCPS（v15：语义接地 + 双层提议—处置）
```
def joint_costride_schedule(goal, C_t, leases, energy, q_prev, omega, b, kappa_c):
    h, hM = hash(kappa_c), current_map_hash()
    dag = htd_cert(goal, C_t, contracts=kappa_c, leases=leases)
    if dag is None:
        return ('synthesize_or_fail_closed', None)
    # —— 语义层处置：动作所依赖的每个指代先拿到接地证书 ——
    for ref in dag.frontier_referents():
        g = ground_and_verify(current_o(), ref.ell, ctx, student, M, V_cov)
        if not g.ok:
            return ask_or_fallback(g.reason, g.candidates, ctx)
        if not guard.exact_check_grounding(g, hM):
            return ('safe_fallback', None)
    if not viability_ok(current_z(), current_mode(), kappa_c):
        return ('crm', biped_mrc(current_state(), current_mode(), student))
    b = sharpened_intent(b, kappa_c.signed_intent, user_evidence_weight(...), ctx)
    sigma = intent_scale(b)
    best = None
    for cand in student.propose(o, ctx, n_cand=N_FAST):   # 候选含 (a,m,q,ι,κ,G_c)
        if not Inv[cand.iota](current_state()) or cand.hash != h:
            continue
        if not guard.grounding_refs_valid(cand, hM):       # 未接地/歧义 → 拒
            continue
        if not barrier_ok(extend_z(current_z(), cand.kappa), b, LAMBDA, HORIZON):
            continue
        pick = choose_abstraction_viability(dag.frontier(), cand, sigma,
                                            capture=C_k, hvc=HVC)
        if pick and pick.value * sigma > (best.value if best else -inf):
            best = pick
    if best and guard.exact_check(best, h):                # 动作层处置
        return best
    if full_search_fallback() is not None:
        return fallback
    return ('crm', biped_mrc(...))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SGC / `V_ground` | 提议 O(1) 推理；确认 `Σ cost(eval_exact) ≤ τ_ground` | O(|M|) | 指代由 `M` 决定；`φ^*∈V_cov`；`Amb_G≤τ_amb` 才签发 |
| LCA | O(|cands|·|terms|·c_ground) | O(契约史) | 超格/触根信任/未接地/多解 → 拒或追问；VLM 无授权 |
| GAD | 离线训练；在线 O(1) 提议 | O(|student|) | 部署须过认证门：held-out 零违例 + 弃权校准 |
| SFF | O(1) 采样 | O(|scenes|) | 无定罪权；假阴性只浪费预算 |
| CBM | O(1) 判定 | O(1) | 超预算/不可表达 → 保守回退，禁止猜 |
| `G_exact` | 原动作求值 + 接地证书校验 ≤ τ_g | O(1) | 看门狗超预算强制安全慢模式 |
| CBG+ | 原 ∪ {接地 ∧ 地图版本 ∧ `V_cov`} | O(1) | 缺任一即 fail-closed |

**正确性定理（Grounded, Distilled, Viability-Compositional Soundness）**
假设：(A1)–(A12) 承接 v14（契约 sound、CBG 边界蕴含、租约、初始证书、CCL 只追加、意图支撑覆盖、δ 膨胀、CRM 可达、`C_cert` 内近似、捕获覆盖、`G_exact` 成本认证、共创过格）；新增 **(A13)** 认证地图 `M` 与 `V_cov` 对认证感知扰动集 sound：`eval_exact(M,·,φ)` 的结果与物理真值一致（误差计入 `α_map`）；**(A14)** 动作等价商保守：`r ~_ctx r'` 仅在二者诱导的认证动作集完全相等时成立（宁可判不等价、多追问，不可把危险差异判为等价）；**(A15)** `Amb_G` 的提议质量上界在 VLM 权重未校准时仍成立（采用保守上包络而非点估计）；**(A16)** 追问/弃权/保守回退在安全语义中**永远是可行动作**（不执行任何未认证动作即不违反安全），且 CBM 超预算时回退路径可用。则沿路径与交互序列，
`P(∀t≤T: z(t)∈Z_safe) ≥ 1 − Σ_i α_i − Σ_i ε_hand,i − α_lease − α_intent − α_user − α_viable − α_cap − α_map − Σ_ℓ δ_{ℓ→d}`；
且**VLM 与 student 的语义误差不进入该上界**：任何语义事实只有经 `V_ground` 签发 `G_c` 才进入动作层，VLM/student 错误只能改变追问率 `ρ_ask`、弃权率与回退率（可用性/用户负担），因为 (A16) 保证"拒绝行动"本身安全；语言共创只有经 `Adm` 才改变约束，编译器错误只能导致拒绝或追问。这仍是**条件保证**：`M`/`V_cov`/动作等价商的保守性、以及弃权校准在分布漂移下的有效性，是新的信任锚，由 PFV/SFF/DCL/CCA 的持续证伪与地图版本审计负责，不在定理覆盖范围内。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| `M`/`V_cov` 本身有错，精确校验给幻觉盖章 | 高 | 地图版本哈希入守卫；只把认证精度达标的谓词纳入 `V_cov`；PFV/SFF 持续证伪地图；`α_map` 显式入账 |
| 动作等价商过于乐观，把危险差异判为等价 | 高 | 保守定义（动作集∧PFL∧安全结局三重相等）；红队跨类误判；宁可多问不可错并 |
| 弃权校准在分布漂移下失效，学生最该弃权时最自信 | 高 | conformal 弃权 + 漂移检测 + 认证门（held-out 零违例 + 弃权 ECE）；失效即回退全 teacher |

| 追问负担过高（clarification fatigue） | 中 | 动作等价商消除无害歧义；CBM 预算与用户负担指标；批量确认 |
| 蒸馏标签循环论证（标签来自同一地图） | 中 | 独立人工标注 held-out；跨场地 `V_cov` 覆盖差纳入 XFER；标签覆盖审计 |
| 语义场景生成触碰伦理/安全边界 | 中 | 仿真先行 + 场景约束白名单；SFF 只生成不执行；定罪仍走精确证伪器 |

## 6. 本轮最大风险

**一句话**：语义层的"propose–dispose 只损失可用性"把承重假设从动作层转移到了 `M`/`V_cov` 与动作等价商的正确性上——一旦认证地图有错、`V_cov` 把不可靠谓词当成可精确求值、或等价商把危险的不同动作误判为等价，VLM 的幻觉就会被"精确校验器"盖章成事实；而 GAD 又可能在分布漂移下把学生训练成"在恰恰该弃权时最自信"，让追问/回退这道最后防线最先失效。
