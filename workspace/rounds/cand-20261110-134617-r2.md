# 第 44 轮（新循环第 4 轮） · Anytime × Annotation：把「实时控制的截止时刻」与「数据标注的标签质量」纳入证书闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形边际覆盖 + 多用户契约空集」，但它仍压着两个未言明的单点假设：**(H1) 证书计算被默认为「必在控制周期内完成」**——只建模了测量陈旧（租约）与并发交错（RG），却没建模「计算本身被截止时刻截断」时证书是否仍 sound；**(H2) 证书所依赖的标签被默认为真值**——语义类标、几何边界、人格校准标签都来自人类标注，标注噪声被当作可忽略，且标注被当成离线预处理而非闭环中的实时资源。本轮灵感词「实时控制」「数据标注」精确命中这两个假设：**实时控制**迫使我们把「计算时间」提升为证书的一等维度，用 anytime / deadline-truncated 证书让「没算完」也绝不误放；**数据标注**迫使我们把「标签质量」提升为证书的一等维度，用标注噪声鲁棒边际 + 标注质量证书让「标错了」也绝不静默失效。二者耦合处（just-in-time 标注 × 控制截止）是本轮真正的新问题：标注到达太晚只能退回更保守证书，标注质量自证会形成循环审计。

## 0. 直觉与动机

**灵感 1（实时控制 → 「没算完也是证书，只是更保守」）**：直觉上，安全关键控制不能等证书「算完美」，但更不能在没算完时假装有证书。关键转变是把证书从「一次性输出」改成**随时可截断的证书族** {C^{(j)}}：算 1ms 得到一个很粗但 sound 的可行集，算 10ms 得到更紧的可行集；**任何截止时刻停下，拿到的都是一个合法的（只是保守的）证书**。这正是 anytime 算法的安全语义：截断只损失可用性（可行集变小），永不损失 soundness。它与第 43 轮的租约**正交**：租约管「状态旧了」，anytime 管「证书没算完」；两者是（状态年龄 × 计算截断）两个独立坐标。

**灵感 2（数据标注 → 「标签是证书的地基，地基会抖」）**：直觉上，VLM 的类别标签、障碍物的几何标注、共形校准的人格标签都来自人，标错是常态。若直接把标注当真值，共形覆盖、几何安全界、人格契约都会被噪声静默穿透。因此把标注提升为**带不确定性的证据**：每个标签携带来源、可靠性、时间戳，证书边际必须按标签噪声上界保守膨胀（m_used = m_hat − κ_m·ρ）。标注质量本身也要有**质量证书**（可靠性 LCB + 漂移审计）；质量下降只会让证书更保守，不会更不安全。

**灵感 3（耦合 → just-in-time 标注：让标签赶在控制决策之前到达）**：标注是慢资源（人，秒级），控制是快回路（毫秒级）。若把所有标注都塞进快回路，实时性必崩。正确架构是**分层时标**：内层几何/CBF 安全证书**绝不等待人工标注**，只用 anytime sound 计算 + 已有标注的内插；外层语义/目标/人格证书可向人工发**即时标注请求**，按「紧迫度 × 期望边际增益 / 人类时间」调度，赶不上截止就用膨胀后的保守边际回退。标注由此从离线预处理变成**受截止约束的实时资源**，而它的迟到只换来保守，不换来不安全。

**耦合升级**：DAC（随时证书）让每个证书在任意截断处 sound；AQC（标注质量证书）把标签噪声传播进每一层边际；RTA（实时标注仲裁）在截止压力下调度「人」这一慢资源。四层架构由 v8 的「人格契约层 + 并发证书层」升级为 v9 的「随时证书层 + 标注质量层 + 实时标注层」，且**不推倒任何既有层级**。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（随时证书族与截断 sound 性）**：证书计算产生细化序列 C^{(0)} ⊆ C^{(1)} ⊆ … ⊆ C^{(N)} ⊆ S_safe（C^{(j)} 为第 j 步细化后「已被证明安全」的可行动作/状态集）。称 {C^{(j)}} 为**随时证书族**，当且仅当：(a) **逐点 sound**：∀j，C^{(j)} ⊆ S_safe；(b) **单调精细化**：j≤k ⇒ C^{(j)} ⊆ C^{(k)}（多算永不删掉安全选项）；(c) **截断可用**：控制截止 d 时刻实际完成 j(d)，就用 C^{(j(d))} 守卫。**定理（截断 sound）**：任意截断时刻使用的 C^{(j(d))} 都 sound；可用性 A(j)=|C^{(j)}∩A_u| 对 j 单调不减。**注**：早期证书是「合法的保守子集」，可能为空——空集触发安全停机而非放行。

**定义 45（截止-保守性权衡与安全保持动作）**：设控制周期 T_c、细化步长 δ。定义截止 d 的保守代价 L(d)=|C^{(N)}|−|C^{(j(d))}|。**安全保持动作** a_hold（制动/停驻）由构造保证 a_hold ∈ C^{(0)}（任何截断下都在），故截断永不导致「无安全动作可选」的死锁。实时证书调度问题：在各自计算时间之和 ≤ T_c 下，为每个被守卫谓词选择截断 j，使期望 L(d) 最小且 A(j) ≥ 可用性阈值。

**定义 46（标注噪声鲁棒边际）**：设证书由标签场 L 决定，标注产出 L̂，误差受歧义集约束：真标签 ∈ B(L̂, ρ)（ρ 为标注者相关噪声上界，见定义 47）。若证书边际 m 对标签在度量 d_L 下 Lipschitz 常数为 κ_m，则**鲁棒边际** m_used = m(L̂) − κ_m·ρ 满足 ∀L∈B(L̂,ρ)：m_used ≤ m(L)（保守不越过真值）。**命题（噪声校正共形）**：非一致性分数对标签亦 κ_s-Lipschitz 时，把分位阈值抬到 q+κ_s·ρ 可恢复 P(h∈Ĥ) ≥ 1−α。**推论**：标注越差 ⇒ ρ 越大 ⇒ 边际越保守 ⇒ 可用性降而 soundness 保。

**定义 47（标注质量证书与标注租约）**：对标注源 s 与标签类型 v 维护质量证书 Q_{s,v}=(r_{s,v}, provenance, t_q, audit)。r_{s,v} 由金标准子集 + 交叉一致性估计，且用于定义 46 的必须是**可靠性置信下界**：ρ_{s,v} = 1 − LCB(r_{s,v})。**标注租约** ℓ^a=(L̂, ρ, t_L, h) 表示标签在有效期 h 内、按质量 ρ 可用；过期或可靠性下降 ⇒ ρ↑ ⇒ 边际膨胀（与定义 41 的证书租约同构，但管的是「标签旧/差」而非「状态旧」）。

**定义 48（实时标注仲裁 just-in-time labeling）**：标注请求 r=(v, 候选集, 期望边际增益 g_r, 截止 d_r, 人类最坏服务时间 c_r, 紧迫度 π_r)。人工作为单一（或池化）实时资源，调度器在 Σ c_r x_r ≤ budget 与「标注须先于其守卫使用」的时序约束下，最大化 Σ π_r·g_r·x_r。**规则**：按 (π_r·g_r)/c_r 的密度贪心 + EDF + 可调度性测试。**定理（迟到安全）**：未被采纳或未按时完成的标注，只使对应边际停留在膨胀值（定义 46），故任何标注迟到/缺失都不产生不安全放行。

**定义 49（三时标闭包与统一 sound 不变式）**：三个时标：控制周期 T_c（ms）、证书细化 τ（≤T_c）、标注延迟 T_a（s）。统一守卫不变式 **I_tac ≜ [C_{τ(t)} sound] ∧ [证书租约 ℓ 有效] ∧ [标注租约 ℓ^a 有效且 ρ=LCB] ∧ [m_used = m_hat − κ_m·ρ]**. **定理（三时标 sound 与安全单调性）**：若每次决策只使用决策时刻实际完成的 C_{τ(t)}、未过期租约、以及按 LCB 膨胀的边际，则任意「计算截断 × 测量陈旧 × 标注噪声/迟到」组合都不会放行不安全动作；且三个扰动轴都只把决策推向更保守方向（可行集收缩或回退 a_hold），最坏结果是可用性损失，不是不安全。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 DEADLINE-ANYTIME-CERTIFICATE（随时证书引擎 DAC）
1. **单调细化构造**：用区间算术 / branch-and-bound / CBF 迭代收紧构造 C^{(j)}，保证 C^{(j)}⊆C^{(j+1)}⊆S_safe；对非单调的神经证书器套单调松弛壳。
2. **截断守卫**：守卫读「此刻实际完成」的 C^{(j(d))}，记录 j(d) 与截断原因（时间/抢占）；未完成部分不参与放行。
3. **安全保持兜底**：C^{(j(d))}=∅ 或缺少可行动作时立即 a_hold；a_hold∈C^{(0)} 由构造保证。
4. **保守代价计量**：输出 L(d) 与可用性 A(j) 曲线，供定界与回退。

### 2.2 IP-61 ANNOTATION-QUALITY-CERTIFICATE（标注质量证书 AQC）
1. **标签溯源与质量台账**：每标签记 (source, t_L, label type, agreement, gold audit)；对每源估计可靠性 LCB。
2. **噪声传播器**：把 ρ 经 κ_m 传播到语义/几何/人格各层边际，统一 m_used=m_hat−κ_m·ρ。
3. **噪声校正共形**：校准分位按 κ_s·ρ 抬升，维持 1−α 覆盖；漂移即抬 ρ。
4. **循环审计防线**：金标准子集与日常标注独立采样 + 交叉标注 + 外部基准，防止「用坏标签审计坏标签」的自证。

### 2.3 IP-62 REAL-TIME-ANNOTATION-ARBITER（实时标注仲裁 RTA）
1. **即时标注请求生成**：由守卫谓词的边际缺口与紧迫度触发（不是全图标注）。
2. **截止调度**：EDF-密度 + 人类最坏服务时间 + 可调度性测试；标注池负载均衡。
3. **迟到回退**：未完成即用膨胀边际，绝不阻塞内层安全回路。
4. **主动标注价值**：按「期望边际增益 / 人类时间」选样，优先闭合最影响未来决策的标签缺口。

## 3. 四层架构 v9

```
L1: TRI-FUSE(INT8) + IP-49 LIO → C_ms + B_t + L_m
    多源标签 → IP-61 AQC(质量台账/ρ LCB) → 噪声膨胀边标
L2: CTC + VLM + IP-35 仲裁 → R_φ(w) 分支池
    → IP-60 DAC 以 anytime 细化 C^{(j)}（j 由截止决定）
L3: IP-51 CAR(截断守卫 + m_used) ← IP-58 CCR(证书租约 × 标注租约 联合判据)
    → IP-47 组合(截断兼容契约) → IP-39 规划(CBF margin=m_used)
    → IP-45 总线(truncation/annotation-lease/quality) → IP-48/IP-43
    → IP-53 CMC(ρ 参数化 + anytime 截断监控器)
L4: IP-60 DAC + IP-61 AQC + IP-62 RTA(just-in-time 标注仲裁)
    + IP-55 CKB(质量感知检索) ← IP-54 SCV(截断×噪声×延迟仿真)
    → IP-44 蒸馏 + IP-50 课程 → RCA 重颁 → 质量/契约热更新
运行期：控制截止 → 选截断 j(d) → 用 C^{(j(d))} 与膨胀边际守卫 → 缺口触发标注请求
        → 标注未达 → 停留膨胀边际/保守回退 a_hold → 反例与质量漂移回灌 Sim/CKB
```

## 4. 实验设计（E95–E102 硬门槛，承接 E87–E94）

| 实验 | 指标 | 门槛 |

| E96 截止-保守权衡 | p99 控制延迟；A(j) 随 j 曲线；a_hold 触发率 | < T_c；单调不减；过载 <10% |

| E101 循环审计对抗 | 金标准污染下质量检测；自证失效检出 | ≥95%；0 漏检 |
| E102 名义回归 | 新增机制对名义成功率/延迟影响 | 成功率降 <2pp；延迟不劣于 v20 |

回退：E95/E96 不达标 → 缩短 T_c 或固定保守截断点，牺牲效率保 sound；E97/E98 不达标 → ρ 取先验保守上界（≤1），放弃部分可用性；E99 不达标 → 关闭 just-in-time 标注，只做离线标注 + 保守外推；E101 不达标 → 禁止自审计，强制外部金标准或离线复核；任何红线失败 → 全链路熔断回退 v20。

## 5. 本轮最大风险

**一句话**：标注质量证书可能**自证**——若金标准审计本身由被审/同源标注者产出，ρ 会被系统性低估，于是「所有本地检查都通过」却让标签噪声静默穿透证书、同时 anytime 截断与标注膨胀叠加使可用性崩塌；因此 E97（噪声鲁棒）与 E101（循环审计）必须设为红线，且默认回退到「内层不用人工标注 + ρ 取先验上界」这条永不失 sound 的底线。

## 1. 符号体系（增量：定义 44–49 符号）

| 符号 | 含义 | 定义 |
|---|---|---|
| C^{(j)} | 第 j 步细化后的安全可行集 | C^{(0)}⊆C^{(1)}⊆…⊆S_safe，逐点 sound |
| j(d) | 截止 d 实际完成的细化步 | 守卫只用 C^{(j(d))} |
| A(j) | 可用性 | \|C^{(j)}∩A_u\|，对 j 单调不减 |
| L(d) | 保守代价 | \|C^{(N)}\|−\|C^{(j(d))}\| |
| a_hold | 安全保持动作 | 构造保证 a_hold∈C^{(0)} |
| ρ_{s,v} | 标注噪声上界 | 1−LCB(r_{s,v})，按源/标签类型 |
| κ_m / κ_s | 边际 / 分数对标签的 Lipschitz 常数 | 用于噪声膨胀 |
| m_used = m_hat − κ_m·ρ | 鲁棒边际 | 保守不越过真值 |
| ℓ^a=(L̂,ρ,t_L,h) | 标注租约 | 标签、噪声上界、时刻、有效期 |
| r=(v,g_r,d_r,c_r,π_r) | 标注请求 | 目标、增益、截止、人类最坏服务时间、紧迫度 |
| I_tac | 三时标守卫不变式 | 截断 sound ∧ 租约 ∧ 标注租约 ∧ 膨胀边际 |

## 2. 关键算法（伪代码）

### IP-60 DAC：随时证书与截断守卫
```
def anytime_certify(x, guards, deadline):
    C = C_initial_conservative(x)          # a_hold ∈ C 且 C ⊆ S_safe
    j = 0
    while not C.done() and monotonic_now() < deadline:
        C = refine(C, next_guard(guards))  # 单调收紧：只删未被证明安全的动作
        j += 1
    return C, j                            # 任意截断点都 sound

def guarded_action(C, goal, persona):
    feasible = C.feasible_actions(goal) & persona.A_u
    if not feasible:
        return a_hold if a_hold in C else safe_stop()   # 空集绝不放行
    return plan(feasible)
```

### IP-61 AQC：质量台账、噪声传播与校正共形
```
def annotation_robust_margin(m_hat, kappa_m, rho_lcb):
    return m_hat - kappa_m * rho_lcb       # 定义 46：保守不越过真值

def corrected_conformal_q(scores, alpha, kappa_s, rho_lcb):
    return quantile(scores, 1 - alpha) + kappa_s * rho_lcb  # 噪声校正覆盖

def reliability_lcb(source, gold_pairs, delta=0.05):
    # 金标准子集上与日常标注独立采样、交叉标注、外部基准
    r_hat = agreement(source, gold_pairs)
    return clamp(r_hat - hoeffding_radius(len(gold_pairs), delta), 0, 1)

def annotation_lease_valid(le, t, h):
    return (t - le.t_L) <= h and le.rho == 1 - reliability_lcb(le.source)
```

### IP-62 RTA：just-in-time 标注仲裁
```
def jit_annotation_schedule(requests, human_wcet, deadline):
    # EDF + 密度贪心；未排入/未完成者不阻塞安全回路
    reqs = sorted(requests, key=lambda r: (r.d_r, -(r.pi * r.g_r / r.c_r)))
    chosen, used = [], 0
    for r in reqs:
        if used + r.c_r <= min(r.d_r, deadline) and schedulable(human_wcet, chosen + [r]):
            chosen.append(r); used += r.c_r
    return chosen
```

### IP-51/58 升级：三时标联合守卫
```
def tac_guard(e, x, cert, lease, annot_lease, t, theta):
    C, j = cert.truncated_at(t)             # 实际完成的 C^{(j(d))}
    if not lease_valid(lease, theta, t):
        return downgrade()                  # 状态陈旧：单调降级
    if not annotation_lease_valid(annot_lease, t, h):
        annot_lease.rho = 1.0               # 标签过期/差：极限保守
    m_used = annotation_robust_margin(cert.m_hat[e], kappa[e], annot_lease.rho)
    return min(C.margin[e], lease.decayed(t), m_used) >= theta

def budget_split(T_c, refinement_need, annotation_wait):
    # 内层安全回路不等待标注：标注等待预算只给外层语义/人格
    t_refine = min(T_c, refinement_need)
    t_annot  = max(0.0, T_c - t_refine)
    return t_refine, t_annot
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性保证 |
|---|---|---|---|
| IP-60 随时证书 | 每步 O(refine)；截断 O(j(d)) | 证书 O(\|C\|) | 逐点 sound + 单调精细化 ⟹ 任意截断 sound |
| IP-60 截断守卫 | O(1) 读当前 C | O(1) | 只用实际完成 C^{(j(d))} ⟹ 不误用未完成部分 |
| IP-60 a_hold 兜底 | O(1) | O(1) | a_hold∈C^{(0)} ⟹ 截断不产生死锁/放行 |
| IP-61 噪声传播 | O(1) per 边际 | O(1) | κ_m-Lipschitz + ρ 上界 ⟹ m_used 保守不越真值 |

## 4. 实验设计（E95–E102，硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E95 随时证书 soundness | 随机截断下不安全放行；C^{(j)} 单调性违例；截断点覆盖率 | 0；0；≥99% |
| E96 截止-保守权衡 | p99 控制延迟；A(j) 随 j 曲线；a_hold 触发率；保守代价 L(d) | <T_c；单调不减；<10%；<15% |
| E97 标注噪声鲁棒 | 各 ρ 下不安全放行；校正共形覆盖率；边际膨胀倍数 | 0 起；≥1−α(α=0.1)；<2x |
| E98 标注质量证书 | ρ LCB 有效率；质量漂移检出率；可靠度高估致违例 | ≥95%；≥95%；0 起 |
| E99 实时标注仲裁 | 截止前到达率；单位人类时间边际增益；迟到回退率；标注池公平性 | ≥80%；≥基线 1.5x；<20%；达标 |
| E100 三时标长跑 | 100h 截断×陈旧×噪声组合不安全事件；可用性；a_hold 次数 | 0 起；≥基线 90%；<1 次/h |
| E101 循环审计对抗 | 金标准污染下质量检测率；自证失效检出；外部基准一致性 | ≥95%；0 漏检；≥90% |
| E102 名义回归 | 名义成功率降幅；决策延迟相对 v20；误回退率 | <2pp；不劣于 v20；<5% |

回退：E95/E96 不达标 → 缩短 T_c 或固定保守截断点，牺牲效率保 sound；E97/E98 不达标 → ρ 取先验保守上界（≤1），放弃部分可用性；E99 不达标 → 关闭 just-in-time 标注，只做离线标注 + 保守外推；E100 不达标 → 收紧截断与标注超时；E101 不达标 → 禁止自审计，强制外部金标准或离线复核；任何红线失败 → 全链路熔断回退 v20。

| 风险 | 等级 | 缓解措施 |

| 标注质量证书自证（金标准同源），ρ 系统性低估导致静默失效 | 高 | E101 红线；金标准独立采样 + 交叉标注 + 外部基准；ρ 默认取先验上界，仅在多重独立审计通过后收紧 |

## 6. 本轮最大风险

**一句话**：标注质量证书可能**自证**——若金标准审计本身由被审/同源标注者产出，ρ 会被系统性低估，于是「所有本地检查都通过」却让标签噪声静默穿透证书、同时 anytime 截断与标注膨胀叠加使可用性崩塌；因此 E97（噪声鲁棒）与 E101（循环审计）必须设为红线，且默认回退到「内层不用人工标注 + ρ 取先验上界」这条永不失 sound 的底线。
