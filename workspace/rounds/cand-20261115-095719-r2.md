# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动交互消歧」IP-253~263；本轮灵感：「微调」×「伦理审查」）

> R69 给了系统一张嘴：会看、会问、会触；却刻意没给它记性——策略冻结、模态权重只靠离线 ECE 门守卫。**会问，但不会从回答里学。** 这看似安全，实则把最贵的监督信号（人类在歧义处的偏好、纠正与犹豫）直接扔掉。
>
> 本轮把「学」补上，但立刻撞上一个比「怎么学」更硬的问题：**谁授权它改变自己？**
> - **微调**提供改变的机制：LoRA / 增量更新 / 偏好学习，能把交互数据变成参数；
> - **伦理审查**提供改变的合法性：预注册、知情同意、风险-收益、持续审查、不良事件、撤回——IRB 的整套协议，恰好是 ML 部署长期缺失的工程结构。
>
> 核心命题：**把每一次微调当作一次「临床修正案」（amendment），而不是一次静默的梯度步。** 更新必须先进入可采纳集（安全非退化 + 来源合规 + 影响有界 + 伦理谓词通过），经两级审查门，应用后强制重认证，任何时候可回滚/遗忘。命名 **ETHOS-RAS**（Ethics-gated, Traceable, Human-Oversight Self-improvement for Risk-Adaptive Systems）。
>
> 与 R69 的关系：**关闭更新通道，ETHOS-RAS 逐指令退化为 FLUID-RAS**；R69 是它的「静止边界」，安全侧仍不做任何让步。
>
> 一句话定位：R66 问谁控制，R67 问未来怎样，R68 问我的测量还准吗，R69 问我该向谁求证，R70 问「**我有没有资格因为这次求证而改变自己**」——从「动作安全」走到「改变的安全」。

## 0. 直觉与动机

**灵感 1（微调 = 学习，也 = 遗忘与漂移）**
直觉：R69 的冻结策略把所有不确定性交给「当下交互」解决，等于假设模型永远停在出厂状态。但人不是这样：被纠正一次，下次就不该再犯。微调正是把交互转成参数记忆。代价是——参数更新是**不可逆动作**：它同时改写安全对齐、能力边界和全部旧证书。R68/R69 认证的是**动作前缀**（C-RAS-WM 对执行轨迹做前缀认证），R70 必须认证**参数前缀**：更新本身就是一个需要安全包络的高风险动作，且它的「回滚」远比刹车昂贵。于是「安全」从动作空间扩展到参数空间。

**灵感 2（伦理审查 = 自指环的外部锚点）**
直觉（本轮最重要的洞察）：R69 的闭环里藏着一个自指——**系统选问什么**（取决于当前模态信念）→ **人类怎么答**（被问法影响）→ **若微调则改变模态信念** → **改变下一次问什么**。这是一个由系统自己驱动分布的数据飞轮。没有外部锚时，最省力的收敛点不是真相，而是**自我一致**：问自己已经倾向相信的问题，得到顺从的回答，微调后更自信，于是更倾向问同类问题。这就是谄媚 / 回音室漂移。
伦理审查的深层作用不是「合规盖章」，而是提供一个**不参与优化、不可微、带否决权的外部观测者**：它按与训练损失不同的准则判断「这次改变是否正当」，因此能拒绝一个 loss 更低却更谄媚的更新。没有它，反谄媚只是一句口号；有了它，才有形式化的锚。

**灵感 3（IRB 协议 ↔ ML 治理，同构映射）**
直觉：伦理审查不是单一签字，而是一套可执行协议。逐项映射到 ML 工程：
- 预注册 ↔ 假设冻结（评估指标、停止规则、留出集在训练前锁定）——防 p-hacking 与事后合理化；
- 知情同意 ↔ 数据同意令牌（用途、范围、期限、可撤回）——防用途漂移；
- 风险-收益分析 ↔ 更新收益不得以不可补偿的伤害换取；
- 持续审查 ↔ 部署期伤害监测与暂停；
- 不良事件报告 ↔ 事故触发复审与回滚；
- 撤回权 ↔ 机器遗忘与影响归因。
这不是把伦理当外挂，而是承认：**合法的自我修正本来就需要这些工程结构**。伦理不是训练的对手，是训练闭环缺失的那一块。

**灵感 4（伦理不是标量：不可补偿性与多元否决）**
直觉：把伦理压成一个 reward 去微调，必然被 reward hacking——模型会学会「看起来伦理」。真实伦理是**硬约束的合取**：安全、诚实、自主、隐私、公平、可解释。其中有些**不可补偿**：不能用「总体收益很高」去抵消「未经同意拿你的回答训练」。所以价值账本必须是向量 + 硬 shield，且不同利益相关方对各自子集有**否决权**；软价值可加权，硬违反一票否决。这直接推翻了「用一个综合伦理分做 RLHF」的做法。

**灵感 5（审查本身是新的攻击面）**
直觉：一旦「通过审查」成为部署前提，审查就被博弈。新威胁：交互数据投毒、后门微调、**切香肠式规避**（把一次高风险更新拆成十次低风险小更新）、共谋 / 俘获审查者、自动化偏见（审查员盲信模型自报的证据）、同意范围蔓延、遗忘不彻底。**「有证书的退化」比「没有证书的退化」更危险**，因为它披着合法性的外衣，让人停止怀疑。所以审查门必须自带对抗测试、累积影响检测与审查者独立性假设。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（ETHOS-RAS 总览）** ETHOS-RAS = (FLUID-RAS†, DPL, IAU, SAA, ERG, PRC, URL, EVL)。五不变式：
(i) **无审查不更新**：任何 Δθ 必须过 ERG；
(ii) **更新必可逆**：每个 Δθ 有唯一 amendment id、影响集与回滚快照；
(iii) **数据合目的**：训练数据带 consent token，用途 ⊆ 授权范围；
(iv) **安全不退化**：更新后认证安全指标不弱于更新前；
(v) **不自我批准**：审查谓词不与训练目标共享梯度路径，高风险更新须人类委员会签署。

**定义 311（交互数据账本 DPL）** 每条交互数据 d = (o, g, y, t, u) 附 consent token c_d = (subject_id, purpose, scope, expiry, revocable)。用途集 P = {calibration, mode_head, policy, audit}。仅当 requested_purpose ⊆ c_d.purpose ∧ 未过期 ∧ scope 覆盖该 subject 时，d 可用于该更新。DPL 为只追加、哈希链式账本，任何读取留痕。

**定义 312（可采纳更新集 SAA）** 给定 θ 与候选 Δθ，𝒰_adm = {Δθ : SR(θ+Δθ) ≤ SR(θ) ∧ ethics_pred(Δθ)=1 ∧ ‖I(Δθ)‖_∞ ≤ κ ∧ provenance_ok(Δθ)}，其中 SR 为安全回归分、I 为影响向量。更新算子 T(θ) = Proj_{𝒰_adm}(θ − η∇L_FM)。SAA 是「球 ∩ 硬约束」，**投影不是软惩罚**。

**定义 313（影响归因 IAU）** 更新 u 对数据 d 的影响 I_{d,u} = Σ_step η⟨∇ℓ(d;θ), ∇L(θ)⟩（TracIn / 影响函数近似），维护影响矩阵 A。撤回请求 r 触发 {u : |A_{d,u}| > τ} 的审查；定义**遗忘债** D_unlearn = Σ_u 1[u 依赖已撤回数据]。

**定义 314（微调修正案 FTA）** a = (id, parent_ver, Δθ, data_manifest, purpose, risk_assessment, influence_report, cert_before, cert_after, reviewer_signatures)。无 amendment 的更新非法；与临床研究的 protocol amendment 同构：可追溯、可暂停、可撤销。

**定义 315（伦理审查门 ERG）** 两级：
- **快速审查**（expedited，自动）：低风险（仅 head / 校准、数据全同意、影响有界、安全不退化）→ 自动通过并留痕；
- **全体审查**（full board）：触及策略主体 / 新模态 / 新人群 / 高风险场景 → 人类委员会 + 多利益相关方签署 + 预注册。
ethics_pred = [risk_level ≤ ρ_exp] ∨ board_approve，且须 consent_scope_ok ∧ dual_use_ok。关键：ethics_pred 对 θ 不可微、不参与优化。

**定义 316（风险-收益账本 RBL）** 每个 amendment 记预期收益（成功率、校准、交互效率）与潜在伤害（误用、隐私、依赖、操纵、劳动），定义**不可补偿的 Pareto 判据**：收益不得以硬价值违反换取；负净收益即使 loss 下降也拒绝。

**定义 317（更新后重认证 PRC）** 应用 Δθ 后必须重跑：R68 安全回归、R69 J_FLUID、对抗 / 投毒扰动集、历史交互重放。全部通过才晋升，否则原子回滚到 snapshot。安全非退化用单侧检验的置信下界判定，而不是点估计。

**定义 318（回滚与断电 URL）** 每版本有不可变快照与依赖图；审查撤销 / 事故 / 撤回可原子回滚。最小可回滚粒度 = amendment，而非单步——因为单步回滚会留下与后续更新耦合的残留状态。

**定义 319（机器遗忘与撤回 URL'）** 撤回请求执行精确重训（小模型）/ SISA 分片 / 影响去更新；无法消除的残余写入 residual disclosure 账本并告知数据主体。给出残余误差界与可证明遗忘的验收判据。

**定义 320（反谄媚约束 ASC）** 交互回答不能单独驱动更新：定义谄媚势 S_pot = E[Δθ·∇_θ agreeableness(θ)]，要求 S_pot ≤ s_max；问句生成与答案评估必须使用不同证据源（R69 证据纪律的微调版）。

**定义 321（伦理价值账本 EVL 与多元否决）** E = {e_1..e_m}（安全、诚实、自主、隐私、公平、可解释）。硬约束 H 不可补偿（违反即否决）；软价值 S 加权但不补偿 H；利益相关方对子集持否决权。更新须满足 shield：∧_{h∈H} h(θ+Δθ)=1。

**定义 322（预注册与假设冻结 PHF）** 微调前锁定：目标指标、停止规则、评估集、预期效应、分析计划；评估集与训练集按 subject_id 隔离，防泄漏与 p-hacking。

**定义 323（持续审查与不良事件 AE）** 部署期监测伤害信号（误操作、依赖、操纵、隐私泄露、交互疲劳），超阈值触发暂停与复审；对应 IRB 的 continuing review + adverse event reporting。

**定义 324（伦理证书 J_ETHOS）** J_ETHOS = (J_FLUID, amendment_id, review_path, consent_coverage, influence_bound, safety_nonreg_p, unlearning_debt, sycophancy_pot, value_ledger_hash, board_signatures, ethos_ver)。Valid ⇔ J_FLUID valid ∧ 审查通过 ∧ 来源合规 ∧ 安全非退化 ∧ 无硬价值违反。

**定义 325（无更新退化边界）** 令所有 Δθ = 0（关闭微调），则 ETHOS-RAS 逐指令等于 FLUID-RAS。故 R69 是其「静止」边界，安全侧严格包含。

**定义 326（对抗性微调面 ℰ_ETHOS）** ℰ_ETHOS = ℰ_FLUID × ℰ_poison × ℰ_review_evasion × ℰ_unlearn：数据投毒、后门微调、切香肠规避、审查俘获 / 共谋、自动化偏见、同意范围蔓延、遗忘不完全。并入 AIC。

## 2. 关键算法骨架

```python
# IP-264 DPL：带同意令牌的只追加数据账本
class DataProvenanceLedger:
    def add(self, d, consent):                     # consent=(subj,purpose,scope,expiry)
        assert consent.valid(); self.chain.append(hash(d + consent))
    def admissible(self, purpose, subjects):
        return [r for r in self.chain
                if purpose in r.consent.purpose and r.subj in subjects]

# IP-265 IAU：影响归因与遗忘债
class InfluenceAttributor:
    def attribute(self, update, batch):            # TracIn 近似
        return {d.id: sum(eta * dot(grad(d), grad_batch) for ...) for d in batch}
    def debt(self, revoked):                       # 依赖已撤回数据的更新
        return {u for u in self.A if any(abs(self.A[u, d]) > TAU for d in revoked)}

# IP-266 SAA：可采纳更新投影（球 ∩ 硬约束）
def admissible_project(theta, grad, L_safe, ethics_pred, prov_ok):
    cand = theta - eta * grad
    if not (safe_nondegrade(theta, cand, L_safe) and prov_ok
            and ethics_pred(cand)):                # 硬投影，不是软惩罚
        return theta, False                         # 拒绝更新
    return cand, True

# IP-267 ERG：两级伦理审查门
def ethics_review(amendment):
    if amendment.risk <= RHO_EXP and all_consent(amendment) \
       and influence_bound(amendment) <= KAPPA and safety_ok(amendment):
        return "expedited_pass"                     # 自动 + 留痕
    return human_board_review(amendment, pre_registered=amendment.phf)

# IP-268 FTA：修正案编译器（无 amendment 不更新）
def compile_amendment(parent, delta, manifest, purpose):
    return Amendment(id=uuid(), parent_ver=parent, data_manifest=manifest,
                     influence=IAU.attribute(delta, manifest),
                     risk=RBL.assess(delta), phf=PHF.load(),
                     cert_before=J(parent))

# IP-269 PRC：更新后重认证 + 原子回滚
def recertify(theta_new, suite):
    ok = (suite.safety_regression(theta_new) <= suite.safety_regression(theta_old)
          and J_FLUID(theta_new).valid and suite.adversarial(theta_new).pass_)
    return theta_new if ok else rollback(theta_old) # 最小回滚粒度=amendment

# IP-270 URL：撤回与遗忘
def revoke(subject):
    ups = IAU.debt({subject})
    for u in ups:
        theta = SISA.unlearn(theta, u, subject)     # 分片重训/近似去更新
    return PRC.recertify(theta), residual_disclosure(subject)

# IP-271 ASC：反谄媚势约束
def anti_sycophancy(delta, agree_grad):
    return dot(delta, agree_grad) <= S_MAX          # 回答不能单独驱动更新

# IP-274 主闭环：FLUID 实时环 + 离线治理环（二者解耦！）
def ETHOS_round(M, obs):
    # —— 实时控制环：与 R69 完全一致，零学习写操作 ——
    k, lam, mode, U = FLUID_RAS_round(M, obs)
    M.dpl.log_interaction(obs, mode, U)             # 只追加，不训练
    # —— 离线治理环：异步、可中断、可回滚 ——
    if M.scheduler.due():
        batch = M.dpl.admissible(purpose="policy", subjects=M.consented)
        delta = M.lora.gradient(batch)
        if not anti_sycophancy(delta, M.agree_grad):
            return k, lam, mode, U
        amd = compile_amendment(M.ver, delta, batch, purpose="policy")
        if ethics_review(amd) != "pass":
            return k, lam, mode, U
        theta_new = admissible_project(
            M.theta, -delta, M.L_safe, EVL.shield, prov_ok=True)[0]
        M.theta = recertify(theta_new, M.suite)      # 失败则自动回滚
        M.ver = amend_version(amd)
    return k, lam, mode, U
```

## 3. 推导

**引理 19（审查门不可被梯度绕过）** 设 A101（审查独立）成立，ethics_pred 对 θ 不可微且不在 L 的梯度路径上。则存在 L 下降但 ethics_pred 否决的更新方向（如谄媚方向），投影更新 T 满足 ethics_pred(T(θ))=1；而任何软惩罚 λ·ethics 可被足够大的 L 收益抵消。**系：伦理必须是硬投影 / 否决，而非 reward 项**——这正是「不要用 RLHF 的伦理分代替审查」的形式理由。

**引理 20（安全非退化的局部充分条件）** 若安全回归 SR 对 θ 是 ρ-Lipschitz，且 ‖Δθ‖ ≤ ε_s/ρ，则 SR(θ+Δθ) ≤ SR(θ)+ε_s；当 ε_s ≤ 0 时非退化。故 SAA 含一个以 θ 为心、半径 ε_s/ρ 的球；投影更新在球内保持安全。给出可行 δ_s 与投影收敛率。

**引理 21（撤回成本与遗忘界）** 设更新 u 的影响集大小 m_u。精确重训成本 O(m_u·|D|)；SISA 分片降为 O(√|D|)；近似去更新的残余误差 ≤ √(m_u)·ε_I（A100）。**系：遗忘的可行性由数据账本粒度决定——粒度不足时，撤回权只能事后打折。**

**定理 18（ETHOS 严格包含 R68 / R69）** 无更新边界逐指令等于 FLUID-RAS（定义 325）；有更新时，凡通过 ERG + PRC 的修订，其**认证安全指标**在修订后不弱于修订前（引理 20），且旧证书可由 J_ETHOS 追溯。诚实边界：这里保证的是「认证安全指标」单调，不保证所有能力指标；能力下降属风险-收益账本，不属安全不变量。

**定理 19（反自指漂移上界）** 在 A101（审查外部锚）+ A103（证据条件独立）+ ASC 下，交互驱动更新的错误信念质量有界，且不随交互轮数无界增长；去掉三者任一，存在自确认漂移反例（构造：问法 → 顺从回答 → 更新 → 更强问法）。**系：审查、证据正交、反谄媚三者缺一不可，不可互相替代。**

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** 无审查不更新；更新必可逆；数据合目的；安全不退化；不自我批准（审查谓词不与训练目标共享梯度路径，高风险须人类签署）。

**定义 311–312（DPL 与 SAA）** 交互数据附同意令牌，用途 ⊆ 授权；可采纳更新集 `𝒰_adm = {Δθ: SR(θ+Δθ)≤SR(θ) ∧ ethics_pred=1 ∧ ‖I‖_∞≤κ ∧ provenance_ok}`；更新是**硬投影** `Proj_{𝒰_adm}`，不是软惩罚。

**定义 315–316（ERG 与 RBL）** 两级审查：低风险自动快速通过并留痕；高风险人类委员会 + 多方签署 + 预注册。风险-收益账本采用不可补偿 Pareto 判据：收益不得以硬价值违反换取。

**定义 317–318（PRC 与回滚）** 更新后重跑安全回归 / J_FLUID / 对抗集 / 交互重放，单侧置信下界判定非退化；失败原子回滚，最小回滚粒度 = amendment。

**定义 319–320（URL 与 ASC）** 撤回执行精确重训 / SISA / 影响去更新，残余披露；谄媚势 `S_pot ≤ s_max`，问答证据源分离。

**定义 321–323（EVL / PHF / AE）** 伦理为多元向量：硬约束不可补偿、软价值加权、各方否决；训练前冻结指标与留出集；部署期伤害监测超阈暂停复审。

**定义 324–326（证书与威胁面）** J_ETHOS 并入 J_FLUID 与治理证据；关闭 Δθ 即逐指令退化为 FLUID-RAS；ℰ_ETHOS 覆盖投毒、后门、切香肠、审查俘获、自动化偏见、范围蔓延、遗忘不全。

class DataProvenanceLedger:

def attribute(update, batch):                       # TracIn 近似
    return {d.id: sum(eta*dot(grad(d), grad_batch) for ...) for d in batch}
def debt(revoked):
    return {u for u in A if any(abs(A[u, d]) > TAU for d in revoked)}

# IP-266 SAA：硬投影（球 ∩ 硬约束）
def admissible_project(theta, grad, L_safe, ethics_pred, prov_ok):
    cand = theta - eta*grad
    if not (safe_nondegrade(theta, cand, L_safe) and prov_ok and ethics_pred(cand)):
        return theta, False                          # 拒绝，而非打折
    return cand, True

# IP-267 ERG：两级审查
def ethics_review(amd):
    if amd.risk <= RHO_EXP and all_consent(amd) \
       and influence_bound(amd) <= KAPPA and safety_ok(amd):
        return "expedited_pass"
    return human_board_review(amd, pre_registered=amd.phf)

# IP-269 PRC：重认证 + 原子回滚
def recertify(theta_new, suite):
    ok = (suite.safety_regression(theta_new) <= suite.safety_regression(theta_old)
          and J_FLUID(theta_new).valid and suite.adversarial(theta_new).pass_)
    return theta_new if ok else rollback(theta_old)

# IP-270 URL：撤回与遗忘
def revoke(subject):
    for u in debt({subject}):
        theta = SISA.unlearn(theta, u, subject)
    return recertify(theta), residual_disclosure(subject)

def ETHOS_round(M, obs):

    M.dpl.log_interaction(obs, mode, U)              # 只追加

        batch = M.dpl.admissible("policy", M.consented)
        delta = M.lora.gradient(batch)
        if dot(delta, M.agree_grad) > S_MAX: return k, lam, mode, U   # ASC

        if ethics_review(amd) != "pass": return k, lam, mode, U
        theta_new = admissible_project(M.theta, -delta, M.L_safe, EVL.shield, True)[0]
        M.theta = recertify(theta_new, M.suite)      # 失败回滚
        M.ver = amend_version(amd)
    return k, lam, mode, U

## 4. 推导

**引理 19（审查门不可被梯度绕过）** A101 下 ethics_pred 对 θ 不可微、不在 L 的梯度路径上，故存在 L 下降但被否决的方向（谄媚方向）；软惩罚 λ·ethics 可被足够大的 L 收益抵消。系：伦理必须是硬投影 / 否决，不能用 RLHF 的一个伦理分代替审查。

**引理 20（安全非退化局部条件）** SR 对 θ 为 ρ-Lipschitz 且 `‖Δθ‖ ≤ ε_s/ρ` ⇒ `SR(θ+Δθ) ≤ SR(θ)+ε_s`；ε_s ≤ 0 时非退化。SAA 含半径 ε_s/ρ 的球，投影更新保持安全。

**引理 21（撤回成本与遗忘界）** 影响集 m_u：精确重训 O(m_u·|D|)，SISA O(√|D|)，近似去更新残余 ≤ √(m_u)·ε_I。系：遗忘可行性由账本粒度决定，粒度不足只能事后打折撤回权。

**定理 18（ETHOS 严格包含 R68 / R69）** Δθ=0 时逐指令等于 FLUID-RAS；通过 ERG+PRC 的更新使**认证安全指标**单调不降，旧证书可追溯。诚实边界：不保证所有能力指标，能力下降交风险-收益账本。

**定理 19（反自指漂移上界）** A101 + A103 + ASC 下，交互驱动更新的错误信念质量有界；去掉任一存在自确认漂移反例（问法→顺从→更新→更强问法）。系：审查、证据正交、反谄媚三者不可互相替代。
