# 第 69 轮（承接第 68 轮「CALM-RAS 自标定风险自适应闭环」IP-243~252；灵感循环新循环第 1 轮；本轮灵感：「自然语言指令」×「机器人」）

> 第 68 轮 CALM-RAS 用「在线标定 + 自监督 + 单模型多任务」把「测量本身的可信度」补进了闭环，但它自陈的最大风险是一句无法在 R68 框架内化解的判词：**标定能力越强，落在标定带宽内的缓变故障越隐形**。根因不是 EKF 不够好，也不是 canary 不够全，而是**标定目标是任务无关（task-agnostic）的**：COF 只问「这组参数能否把残差解释小」，从不问「这个残差对当前要做的事是否重要」。于是「解释掉残差」与「销毁故障证据」在同一个目标函数里等价。
>
> 本轮两个灵感恰好提供了 R68 缺失的两个维度：
> - **自然语言指令**给出**任务相关性规范**：它说明什么是目标、什么是成功、哪些对象/关系/接触/力/空间约束必须成立、哪些差异可以忽略。它不是传感器健康的真值，但它定义了「哪些测量误差会改变任务结果」。
> - **机器人**给出**可执行、可干预的身体**：指令不是聊天文本，而是可被编译成时序约束、可被接触/力/位姿验证、可被安全探测主动激励的物理程序。机器人能把「不可辨识」变成「可辨识」，也能把「语义歧义」变成「一次提问」。
>
> 核心命题：
>
> **把自然语言指令从「任务条件字符串」升级为「任务相关性规范」：指令编译成可验证的时序约束 φ_ℓ，用约束对测量误差的敏感度 J_ℓ=∂ρ_φ/∂c 把标定空间劈成两半——语义零空间 ker(J_ℓ)（任务不敏感，可安全吸收/忽略）与任务保护子空间 row(J_ℓ)（任务敏感，禁止静默吸收）；再用独立语义残差、任务诱导激励、问/试/停仲裁与语义 canary，把 R68 的「越标定越隐形」改写成「只在任务不敏感方向上隐形，在任务敏感方向上必被看见」。—— LENS-RAS（Language-Enabled Null-space Separation for Risk-Adaptive Systems）**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**这个不准，对我被要求做的事，究竟算不算数**」——任务无关的误差可以标定掉；任务相关的误差必须被保护、被监测、被归因；任务本身说不清时，先问，不许猜。

## 0. 直觉与动机

**灵感 1（自然语言指令 → 误差的「相关性」是传感器-任务二元函数，不是传感器的一元属性）**
直觉：一个 1 N 的力零偏，对「把箱子推到桌边」可能完全无害，对「把鸡蛋轻放进托盘」却是灾难；一个 3 mm 的外参平移误差，对「抓大块积木」无感，对「把针插入孔」致命。R68 把这类误差统一压进同一个标定潜变量 c 与同一个不确定度 U(ĉ)，因此它无法表达「同一个误差在不同任务下安全含义不同」。自然语言指令恰好把「什么算数」说了出来：目标对象、目标区域、接触模式、力/速度上限、不可碰撞物、成功判据。把这些编译成时序逻辑约束 φ_ℓ 后，误差 δ 的安全性不再由 ‖δ‖ 决定，而由它对约束鲁棒性 ρ_φ 的影响 J_ℓδ 决定。**相关性（relevance）是任务与误差的联合属性**，这是本轮的第一性转念。

**灵感 2（语义零空间 → 「可安全吸收」第一次有了可证明的边界）**
直觉：R68 的引理 13 用频率把故障分成「快变（不可吸收）/慢变（可吸收）」，但它没有回答「慢变故障被吸收后，任务是否还安全」。LENS 补上第二个切分维度：**任务敏感度**。若慢故障在任务时域内落在 J_ℓ 的零空间里，则无论它多大，都不会改变任何硬约束的满足性——它在任务语义上等价于零，吸收它（甚至忽略它）是无害的。反之，若它在保护子空间里有非零投影，那么物理效应不会因为「标定把它解释了」而消失；机器人仍会在真实世界里违背约束。此时标定只能改变「报告的残差」，不能改变「原始观测的语义残差」——这正是独立语义通道要抓的东西。R68 的「隐形」因此被精确分成两类：**语义零空间内的无害隐形**与**保护子空间内的有害隐形**；后者被通道分离与保护更新规则封死。

**灵感 3（机器人 → 语言提供规范，身体提供激励；任务多样性就是系统辨识的激励信号）**
直觉：纯软件系统只能被动观察；机器人可以「动一下」来让不可辨识变可辨识。更妙的是，**不同指令天然要求不同的工作点**：抓鸡蛋用小力、推箱子用大力、插孔用高精度、擦桌子用长接触。这些任务诱导的工况差异，恰好是区分「零偏（对所有载荷一致的加性误差）」与「增益/迟滞/摩擦漂移（随载荷/方向变化的乘性误差）」所需要的激励。语言指令因此不只是「标签」，还是**激励调度器**：它把机器人带到能让 c 与故障在信息几何上分开的工况。若当前指令集不足以激励出可辨识性（κ_id < κ_min），LENS 不赌，而是冻结保护方向、按故障保守归因，或在安全集内执行一次认证探测/向人提一个规范锚问题。

**灵感 4（指令可错 → H_instruction 必须是一等假设，不能被传感器故障背锅）**
直觉：如果盲目相信指令，一个歧义指令会制造「假传感器故障」：桌上有两个红杯，指令说「拿红杯」，机器人拿错，力/位姿轨迹自然异常；若没有「指令错了」这个假设，系统会把异常归因给力传感器并触发降级——越降级越做不对。R68 的 H 集合只有 H_cal / H_sensor^trans / H_model，缺了 **H_instruction**。LENS 把归因顺序改成「先验证指令，再标定，再归因硬件」：先检查指令在当前场景是否可满足、指代是否有歧义、是否与物理先验矛盾；若指令本身不可行/高熵，正确动作是**问人**或**弃权**，而不是修传感器。语言是证据，但不是无条件的真值；它有自己的失效模式（歧义、漏约束、注入、规格游戏）。

**灵感 5（问 vs 试 vs 停 → 语义不确定与物理不确定必须走不同的证据通道）**
直觉：面对不确定，机器人有三种动作：问人（消解语义/规范）、做安全探测（消解物理/标定）、停下（预算耗尽）。三者信息增益与风险完全不同，不能混进同一个「探索奖励」。LENS 把它们显式分开：语言通道只更新 grounding/规范后验，物理探测只更新 c/故障后验，且探测必须落在当前指令硬约束与 CALM-RAS 认证集内。选择准则是「单位风险的信息增益」，并且**任务完成误差绝不允许回写标定**——否则语义错误会被「解释成」几何漂移，重演 R68 的循环证据。

**灵感 6（合流 → LENS-RAS 的九个组件）**
1. **LGC Language-Grounded Constraint Compiler**：ℓ → φ_ℓ（硬/软约束、成功谓词、对象绑定、可探测动作、歧义孔位）；
2. **SCO Semantic Constraint Observer**：STL 鲁棒性 r_sem，独立证据通道，绝不进入 COF；
3. **SGU Semantic-Gauge Update**：把 COF 新息分解为 Δc_F（零空间，自由吸收）与 Δc_P（保护子空间，需见证/可辨识才吸收）；
4. **TIE Task-Induced Excitation engine**：用任务集的工作点差异构造激励矩阵，计算 c/故障可辨识度 κ_id；
5. **IPA Instruction-validity Pre-attribution**：H_instruction 先验，先验指令再归因传感器；
6. **AAA Ask-Act-Abstain Arbitrator**：问人 / 认证探测 / 安全停三选一；
7. **GAR Gauge Anchor Requester**：用语言获取规范锚（「桌面是平的吗？」「杯子是空的吗？」），只用于锚定保护方向；
8. **SCC Semantic Canary Commit**：CAC 第六关——在标定带宽内但对任务致命的语义 canary；
9. **RAS-WM‡ 继承核**：CALM-RAS 全部保留，只在标定更新、归因、提交三处插入语义门。

## 1. 形式化定义（增量：定义 293–309）

**定义 293（LENS-RAS 总览）** LENS-RAS = (LGC, SCO, SGU, TIE, IPA, AAA, GAR, SCC, CALM-RAS†)。五条不变式：
(i) **语义证据通道分离**：r_sem 只用于监控、归因、仲裁与提交认证，绝不进入 COF 标定更新、MTM 训练标签或故障头训练；
(ii) **任务保护子空间**：COF 更新分解为 Δc = Δc_F + Δc_P，Δc_F ∈ ker(J_ℓ) 可自由吸收；Δc_P ∈ row(J_ℓ) 仅在独立见证成立且 κ_id ≥ κ_min 时允许，否则置零并路由为 H_sensor^trans；
(iii) **指令可错**：H_instruction 为一等假设，归因顺序为「指令有效性 → 标定 → 硬件故障」；
(iv) **语言只收紧不放宽**：由语言/语义不确定性推出的任何量只能抬高 λ_floor、收缩 k，不能降低安全约束或放宽红线；
(v) **继承不变式**：实时流零学习写操作、标定红线、速率限制、CAC 原子提交全部保留。

**定义 294（指令编译与约束程序）** 编译映射 `LGC: (ℓ, scene, ontology) → φ_ℓ`，其中
`φ_ℓ = (φ^H, φ^S, s_ℓ, Ω_ℓ, A_probe, a_ℓ)`：
φ^H 为硬约束集（安全、接触、对象身份、空间关系、力/速度/位姿上限、不可碰撞物），φ^S 为软偏好，s_ℓ 为成功谓词，Ω_ℓ 为对象/关系绑定，A_probe 为指令允许的探测动作，a_ℓ 为未填孔位及其值域/安全关键性。信号 `y(t) = (pose, wrench, tactile, visual_feat, events)`。每个约束 φ_j 用 STL/ProbSTL 表示，鲁棒性 `ρ_{φ_j}(y,t) ∈ ℝ`，负值表示违反，绝对值表示裕度。

**定义 295（语义残差与独立观测器）** `r_sem(t) = (ρ_min(t), {ρ_j^S(t)}, κ_g(t))`，其中 `ρ_min = min_j ρ_{φ_j^H}`，`κ_g` 为 grounding 置信度。违反度 `v_sem = max(0, −ρ_min)`。SCO 只读原始观测 y 与冻结的 φ_ℓ，**不读 ĉ、不读 MTM 的校准后状态**；其变化点统计量用于慢故障的在线检出。通道分离是 LENS 能打破 R68 循环证据的结构性前提。

**定义 296（grounding 后验与指令有效性）** `p(g | ℓ, scene) ∝ p(ℓ | g)·p(g | scene)`，grounding 熵 `H_g = H(g | ℓ, scene)`。在当前模型与认证控制器下，定义指令可行集 `F_ℓ = {τ : τ ⊨ φ_ℓ^H, τ 可由认证控制器执行}` 与可行概率 `p_feas`。指令置信 `c_ℓ = p_feas · exp(−H_g)`。若 `F_ℓ = ∅`、`p_feas < p_min` 或 `c_ℓ < c_min`，判为 H_instruction，进入问/弃权分支，禁止直接归因传感器。

**定义 297（任务敏感雅可比与语义规范分离）** 在状态 `(x_t, c, y_t)` 处，
`J_ℓ(t) = ∂ρ_φ(y_t; c)/∂c ∈ ℝ^{m×12}`。
取奇异值分解 `J_ℓ = UΣVᵀ`，保护子空间 `P_ℓ(t) = span{v_i : σ_i > ε_task}`，语义零空间 `F_ℓ(t) = span{v_i : σ_i ≤ ε_task}`。投影算子 Π_P、Π_F 满足 Π_P + Π_F = I。故障敏感雅可比 `J_f = ∂ρ_φ/∂f`。语义可观测 Gram 矩阵 `O_ℓ = Σ_t J_ℓ(t)ᵀ Σ_sem^{-1} J_ℓ(t)`。

**定义 298（语义规范标定更新）** COF 新息 ν 分解为
`Δc_F = Π_F Kν`，`Δc_P = Π_P Kν`。
Δc_F 走标准 EKF + 速率限制；Δc_P 仅在见证 `W` 满足 `log[p(W|H_cal)/p(W|H_sensor^trans)] > κ_w` **且** `κ_id ≥ κ_min` 时按 `ρ_w Δc_P`（0≤ρ_w≤1）收缩吸收，否则 Δc_P = 0。定义吸收比 `A = ‖Δc_P‖ / (‖Δc_F‖ + ‖Δc_P‖ + ε)`，写入证书。标定后残差 `r_cal = r − r_cal(ĉ)` 可供 MTM 使用，但 SCO 始终看原始 r_sem。

**定义 299（任务诱导激励与可辨识度）** 任务集 `{ℓ_i}` 诱导不同工作点，堆叠激励矩阵
`Φ = [J_ℓ(ℓ_1); …; J_ℓ(ℓ_N); J_f(ℓ_1); …; J_f(ℓ_N)]`。
定义 `κ_id = σ_min(Φ)/σ_max(Φ)`。κ_id ≥ κ_min 表示当前任务集足以把「标定漂移」与「真实故障」在残差模式上分开；κ_id < κ_min 时保护方向禁止吸收，并可调度认证探测（定义 301）或规范锚（定义 303）提升秩。这里语言指令是**激励调度器**：任务越多样，Φ 的秩与条件数越好。

**定义 300（归因假设集与先验顺序）** `H' = H_instruction ∪ H_cal ∪ H_sensor^trans ∪ H_model`。联合后验
`P(H' | ρ, face, r_sem, ĉ, U) ∝ p(ρ | H', ĉ)·p(face | ·)·p(r_sem | H')·P(H')`。
归因顺序固定为：先算 `P(H_instruction)`（可行性、歧义、物理矛盾），若超过阈值则问/弃权；否则再在 H_cal 与 H_sensor^trans 之间按标定后残差与 κ_id 归因；最后才允许降级。**任务误差不能作为标定证据**。

**定义 301（问/试/停仲裁）** 可选动作 `A = {ask(q), probe(a), stop}`。价值
`V(α) = E[IG(α)] / (cost(α) + λ_risk·risk(α))`。
ask 只更新语义/规范后验（q 由 a_ℓ 的关键孔位生成）；probe 只更新物理后验，且 `a ∈ A_probe ∩ Z_cert`，满足 φ_ℓ^H 的硬约束；stop 在 `max V < V_min` 或预算耗尽时触发安全停。人可靠性 `ρ_h` 建模为锚证据噪声；重复提问有边际成本。

**定义 302（语义安全预算）** 安全裕度消耗
`B = L_c·U(ĉ) + L_f·R_f + L_g·ε_g·d + L_s·ε_sem`，
其中 d 为任务组合深度，ε_g 为 grounding 误差，ε_sem 为语义残差不确定度。任何一项增大都只能使 `λ_floor` 上升、`k` 下降：
`λ_floor^LENS = max(λ_floor^CALM, 0.8·1[c_ℓ<c_min ∨ v_sem>0 ∨ rank(O_ℓ)<r_min])`。
**语言不能购买安全裕度，只能消耗它。**

**定义 303（规范锚）** 人类澄清或已知物理锚给出线性约束 `A_anchor c = b + η`，η ~ 𝒩(0, Σ_h)，可信度 w_h。规范锚是唯一允许锚定保护方向的「外部证据」，且只用于**收缩** c 的后验（更小的 Σ_c），不用于直接更新故障后验。若 w_h < w_min，锚只能作为软先验，不能解锁 Δc_P。

**定义 304（语义 canary）** 构造指令-故障对 `(ℓ_canary, δ_canary)`，使 δ_canary 落在 R68 标定带宽内（ω_δ ≤ ω_cal）但对 φ_{ℓ_canary}^H 致命（例如力增益故障 ×「轻拿鸡蛋」、摩擦漂移 ×「缓慢滑入」）。要求 `v_sem(δ_canary) > v_min`。SCC 要求候选适配器不得降低 canary 的语义检出率；若 `‖r_canary(δ̂′)‖ < 0.3‖r_canary(δ̂)‖` 且 `v_sem` 仍超阈，一票否决。

**定义 305（J-LENS 证书）** `J_LENS = (J_CALM, instruction_hash, φ_ℓ_hash, H_g, p_feas, r_sem_vec, P_ℓ, A, witness_log, probe_log, query_log, semantic_canary_verdict, lens_ver)`。Valid ⇔ Valid(J_CALM) ∧ 硬约束满足或人类显式豁免 ∧ 保护方向吸收均有见证/可辨识 ∧ SCC 通过 ∧ 红线未越界。

**定义 306（语义等价类）** 两个故障 `f_1, f_2` 关于指令 ℓ 语义等价，记 `f_1 ~_ℓ f_2`，当且仅当在任务时域 H 上 `J_ℓ(f_1 − f_2) = 0`。安全保证只需覆盖商空间 `ℱ/ ~_ℓ` 的非零类；这正是「吸收零空间故障无害」的形式基础，也是「保护子空间故障不可静默吸收」的边界。

**定义 307（语义可观测性与见证秩）** 见证秩 `r_W = rank([O_ℓ; O_f; A_anchorᵀ A_anchor])`，其中 `O_f = Σ_t J_fᵀ Σ_sem^{-1} J_f`。当 `r_W < dim(P_ℓ)` 时，保护方向不可辨识，禁止吸收；系统必须选择探测/提问/保守归因。该定义把 R68 的 U(ĉ)（估计方差）与真正的可辨识性分开：低方差 ≠ 可辨识。

**定义 308（规格覆盖审计）** 对编译出的 φ_ℓ，审计器生成反事实指令 `ℓ'`（对象互换、量词换域、否定翻转、边界值），检查 `φ_{ℓ'}` 是否会给出相同约束集；若相同，说明约束过弱或指代绑定过粗，标记为**规格漏洞**并写入 J_LENS 的覆盖项。这是对「指令漏掉人真正在乎的维度」这一最大风险的唯一可操作缓解。

**定义 309（管线）** 离线：构建类型化指令语法与 STL 编译器、训练 SCO 的鲁棒性估计（合成指令 + 仿真注入）、构造任务激励集与语义 canary 集。在线：每条指令编译一次并缓存 → 检查可行性与歧义 → 每控制步计算 r_sem 与 J_ℓ → SGU 约束标定 → IPA 归因 → AAA 仲裁 → CAC-L 每 60s 提交 → VQA-L 异步审计规格覆盖与标定事件。

## 3. 推导

**引理 16（语义零空间吸收的无害性）** 设任务时域 H 内故障 δ 满足 `J_ℓ(t)δ = 0, ∀t∈H`（即 δ ∈ ∩_t ker J_ℓ(t)）。则对任一硬约束 φ_j，鲁棒性满足 `ρ_{φ_j}(y; c+δ) = ρ_{φ_j}(y; c)`；因此任何基于 φ_ℓ 的检验都无法、也无需区分 δ，且吸收 δ 不改变约束满足性。反之，若 `‖Π_P δ‖ > ε_task` 且约束裕度 `m_j < L_j‖δ‖`，则 δ 可以改变某硬约束的满足性，必须由 SCO 或保护更新规则处理。**系**：R68 的「慢故障不可见」只对语义零空间内的故障无害；任务相关慢故障不能以「标定已解释」为由被忽略。

**引理 17（通道分离下的检出保持）** SCO 的输入是原始观测 y 与冻结的 φ_ℓ，不依赖 ĉ。因此对任意标定吸收策略 do(absorb)，有
`p(r_sem | H_sensor^trans, do(absorb)) = p(r_sem | H_sensor^trans)`，
`p(r_sem | H_cal, do(absorb)) = p(r_sem | H_cal)`。
即 R68 的标定后验不进入语义检验的似然比，`KL(p_fault ‖ p_cal)` 不因吸收而缩小。**系**：只要故障在任务保护子空间有非零投影且语义约束覆盖它，R68 的「越标定越隐形」不再成立；吸收只改变报告残差，不改变原始物理证据。注意此引理的严格形式要求 SCO 不使用闭环动作反馈中的校准后状态；若使用，则需以冻结策略或 canary 回放消除反馈耦合（见定义 304）。

**引理 18（任务诱导可辨识性）** 设任务集给出线性化残差模型 `r_i = J_c(ℓ_i)δc + J_f(ℓ_i)δf + ε_i`，堆叠矩阵 Φ = [J_c; J_f]。若 `κ_id = σ_min(Φ)/σ_max(Φ) ≥ κ_min`，则对 δc 与 δf 的广义似然比检验的可分误差随样本数 N 以 `exp(−N κ_id² / (8σ²))` 衰减；若 κ_id = 0（某方向在 Φ 的零空间），则任何被动观测都无法区分该方向上的 c 与 f。**系**：语言指令通过改变工作点（力/速度/精度/接触模式）改变 Φ 的秩；任务多样性是标定-故障可辨识性的免费激励源。κ_id 不足时，SGU 必须冻结保护方向，或由 AAA 调度认证探测/规范锚。

**定理 16（LENS-RAS 的任务相对安全）** 在 A92–A99 下，对任意故障 δ 与指令 ℓ：
1. 若 δ ∈ ∩_t ker J_ℓ(t)，则吸收/忽略 δ 不改变任何硬约束满足性（引理 16），任务相对安全；
2. 若 δ 在保护子空间有非零投影且语义约束覆盖该方向，则 SCO 的检出概率 ≥ 1 − ε_ground − ε_cover，且该检出概率不随 COF 吸收而下降（引理 17）；
3. 保护方向的静默吸收概率 ≤ 1 − κ_id 界（引理 18）；κ_id < κ_min 或见证不足时 Δc_P = 0，残余被路由为 H_sensor^trans，零静默吸收；
4. 指令错误不转化为传感器误归因：`P(归因 H_sensor | H_instruction 真) ≤ ε_ins`，由 IPA 的先验顺序与可行性检验保证；
5. 端到端风险满足 `P(|τ_cmd − τ*| > ε) ≤ α_CALM + α_sem`，其中 `α_sem ≤ ε_ground + ε_cover + ε_ins`；且任何语义不确定性只通过 λ_floor 上升与 k 收缩传导，绝不放宽。

**定理 17（语义 canary 提交安全）** 对「吸收型坏适配器」（把任务相关慢故障学成标定、从而让 r_sem 不再触发），SCC 的语义 canary 检出率 `r_sem_canary ≥ 0.95`；与 R68 五关合并后，有害适配器上线概率 ≤ `(1−r_canary)(1−r_sem_canary)·p_h ≤ 0.0025·p_h`。提交窗口内 k*RAS 冻结、λ 连续，换装无控制突变；SCC 失败与回滚失败均触发 k = 0 全局降级。**系**：R68 的 canary 只覆盖「已知故障不能被修好」，SCC 额外覆盖「任务相关慢故障不能被标定头修好」——这正是 R68 最大风险的直接补丁。

## 6. 本轮最大风险

**一句话**：LENS-RAS 的全部安全性押在「编译出的约束程序 φ_ℓ 忠实且完备地表达了人真正在乎的东西」上——**若指令漏掉一个物理关键维度（例如只说「把杯子放桌上」，没说「杯里有水、不能倾斜」），或 grounding 把「左边」静默绑到了错误对象，那么该维度上的故障既在语义零空间之外不可见、又会被 R68 的标定吸收，系统将以「满足所有形式约束」的方式合规地制造事故——这是规格游戏（specification gaming）与语义完备性的原罪：形式化越成功，漏掉的那一维越致命。**

**次级风险与缓解**：
1. **LLM/grounding 幻觉与对抗注入**：类型化语法 + 可行性检查 + 反事实覆盖审计（定义 308）+ 指令来源认证；任何放宽安全的指令必须人类显式签核；
2. **语义通道被标定污染**：SCO 只读原始观测与冻结 φ_ℓ，禁止读 ĉ/校准后状态；用 canary 回放检测反馈耦合（引理 17 的实现前提）；
3. **保护方向过度冻结导致可用性下降**：κ_id 不足时优先调度认证探测/规范锚，而非永久冻结；AAA 有预算与超时；
4. **任务激励不足**：κ_id < κ_min 时保守归因为故障并记录「不可辨识事件」，作为主动学习/任务设计信号；
5. **人类锚不可靠/疲劳**：w_h 建模 + 提问预算 + 只用于收缩，避免「问了就信」；
6. **STL 监控漏检**：约束覆盖与采样率绑定，SCO 的窗口/事件触发需覆盖接触瞬态；E288/E295 专门压测。

## 2. 形式化定义（要点版）

**定义 293（总览与五不变式）** LENS-RAS 包在 CALM-RAS 外层；不变式为：语义证据通道分离（r_sem 不进 COF/训练）；任务保护子空间（Δc_P 需见证且 κ_id≥κ_min）；指令可错（H_instruction 先验）；语言只收紧不放宽；R68 的实时零学习写操作、标定红线、速率限制、CAC 原子提交全部继承。

**定义 294（指令编译）** `LGC: (ℓ, scene, ontology) → φ_ℓ`；φ^H 硬约束、φ^S 软偏好、s_ℓ 成功谓词、Ω_ℓ 对象/关系绑定、A_probe 允许探测、a_ℓ 歧义孔位。信号 y=(pose, wrench, tactile, visual_feat, events)，约束用 STL/ProbSTL 表示，ρ 负值即违反。

**定义 295（语义残差）** SCO 只读原始 y 与冻结 φ_ℓ，输出 r_sem；`v_sem>0` 即硬约束违反。它是独立证据通道，不随 COF 的 ĉ 改变。

**定义 296（指令有效性）** grounding 后验、熵 H_g、可行集 F_ℓ、可行概率 p_feas、指令置信 c_ℓ；`F_ℓ=∅ ∨ p_feas<p_min ∨ c_ℓ<c_min ⇒ H_instruction`，先问/弃权，不归因传感器。

**定义 297（语义规范分离）** SVD `J_ℓ=UΣVᵀ`；σ_i>ε_task 张成保护子空间 P_ℓ，其余为零空间 F_ℓ；`O_ℓ=Σ_t J_ℓᵀΣ_sem^{-1}J_ℓ`。

**定义 298（语义规范标定）** `Δc_F=Π_F Kν`（标准 EKF+速率限制）；`Δc_P=Π_P Kν` 仅在见证 log-LR>κ_w 且 κ_id≥κ_min 时按 ρ_w 收缩吸收，否则置零并路由为 H_sensor^trans；吸收比 A 入证书。

**定义 299（任务诱导激励）** `Φ=[J_ℓ(ℓ_i); J_f(ℓ_i)]_{i=1..N}`，`κ_id=σ_min(Φ)/σ_max(Φ)`；κ_id 不足时冻结保护方向或调度探测/规范锚。语言指令是激励调度器：不同力/速度/精度/接触模式天然提升 Φ 的秩。

**定义 300–301（归因顺序与问/试/停）** 先算 H_instruction（可行性/歧义/物理矛盾），再 H_cal 与 H_sensor^trans；动作集 {ask, probe, stop}，价值 `E[IG]/(cost+λ·risk)`；ask 只更新语义后验，probe 只更新物理后验且必须在 A_probe∩Z_cert 内。

**定义 302–303（语义安全预算与规范锚）** `B=L_cU+L_fR_f+L_gε_gd+L_sε_sem`；任何一项增大只抬高 λ_floor、收缩 k。规范锚 `A_anchor c=b+η` 只用于收缩 c 后验，可信度 w_h 低时不能解锁 Δc_P。

**定义 304–305（语义 canary 与证书）** 构造标定带宽内但对任务致命的 `(ℓ_canary, δ_canary)`；适配器不得降低语义检出率，若「修好」故障则一票否决。J_LENS 在 J_CALM 上增加指令/约束哈希、r_sem、保护子空间、吸收比、见证/探测/提问日志与 SCC 裁决。

**定义 306–308（语义等价 / 见证秩 / 覆盖审计）** `f_1~_ℓf_2 ⇔ J_ℓ(f_1−f_2)=0`；安全只需覆盖商空间非零类。见证秩 `r_W=rank([O_ℓ;O_f;A_anchorᵀA_anchor])`，不足则禁止吸收。覆盖审计用反事实指令检查 φ_ℓ 是否过弱，标记规格漏洞。

**定义 309（管线）** 离线编译/训练/构造 canary；在线每条指令编译一次 → SCO → SGU → IPA → AAA → SCC → VQA-L 异步审计。

def gauge_update(cof, z_cal, r, sigma_stat, spec, M, witness):

## 4. 推导

**引理 16（语义零空间吸收的无害性）** 若 `J_ℓ(t)δ=0, ∀t∈H`，则对所有硬约束 `ρ_{φ_j}(y;c+δ)=ρ_{φ_j}(y;c)`；δ 属语义等价类 `[0]_ℓ`，吸收/忽略不改变任务满足性。若 `‖Π_Pδ‖>ε_task` 且裕度 `m_j<L_j‖δ‖`，δ 可改变任务结果，必须被 SCO 或保护规则处理。**系**：R68 的「慢故障不可见」只对零空间故障无害。

**引理 17（通道分离下的检出保持）** SCO 输入为原始 y 与冻结 φ_ℓ，不依赖 ĉ；故对任意吸收策略 `p(r_sem|H_fault, do(absorb))=p(r_sem|H_fault)`，`p(r_sem|H_cal, do(absorb))=p(r_sem|H_cal)`。语义似然比不随标定后验缩小。**系**：任务相关慢故障的检出功率不被 COF 吸收削弱；吸收只改报告残差，不改原始物理证据。

**引理 18（任务诱导可辨识性）** 线性化 `r_i=J_c(ℓ_i)δc+J_f(ℓ_i)δf+ε_i`，Φ=[J_c;J_f]；`κ_id=σ_min(Φ)/σ_max(Φ)`。κ_id≥κ_min 时 GLRT 可分误差随 N 以 `exp(−Nκ_id²/(8σ²))` 衰减；κ_id=0 时被动观测不可分。**系**：语言指令通过改变工作点提升 Φ 的秩，任务多样性是免费激励；κ_id 不足则冻结保护方向或调度探测/锚。

**定理 16（LENS-RAS 任务相对安全）** 在 A92–A99 下：
1. δ∈∩_t ker J_ℓ ⇒ 吸收/忽略 δ 不改变硬约束满足性（引理 16）；
2. δ 在保护子空间有非零投影且有语义覆盖 ⇒ SCO 检出 ≥1−ε_ground−ε_cover，且不随 COF 吸收下降（引理 17）；
3. 保护方向静默吸收概率受 κ_id 与见证约束；κ_id<κ_min 或见证不足 ⇒ Δc_P=0，残余路由为 H_sensor^trans，零静默吸收；
4. `P(归因 H_sensor | H_instruction 真) ≤ ε_ins`（IPA 先验顺序）；
5. `P(|τ_cmd−τ*|>ε) ≤ α_CALM+α_sem`，`α_sem≤ε_ground+ε_cover+ε_ins`；语义不确定性只抬高 λ_floor、收缩 k。

**定理 17（语义 canary 提交安全）** 对「吸收型坏适配器」，SCC 检出率 `r_sem_canary≥0.95`；与 R68 五关合并后有害适配器上线概率 `≤(1−r_canary)(1−r_sem_canary)p_h≤0.0025p_h`；提交窗口内 k*RAS 冻结、λ 连续，换装无突变；SCC 失败或回滚失败触发 k=0 全局降级。**系**：R68 canary 只防「已知故障被修好」，SCC 额外防「任务相关慢故障被标定头修好」，直接补 R68 最大风险。

## 7. 本轮最大风险

**一句话**：LENS-RAS 的全部安全性押在「编译出的约束程序 φ_ℓ 忠实且完备地表达了人真正在乎的东西」上——**若指令漏掉一个物理关键维度（例如只说「把杯子放桌上」，没说「杯里有水、不能倾斜」），或 grounding 把「左边」静默绑到了错误对象，那么该维度上的故障既在语义零空间之外不可见、又会被 R68 的标定吸收，系统将以「满足所有形式约束」的方式合规地制造事故——这是规格游戏（specification gaming）与语义完备性的原罪：形式化越成功，漏掉的那一维越致命。**

**次级风险与缓解**：LLM/grounding 幻觉与对抗注入（类型化语法 + 可行性检查 + 反事实覆盖审计 + 来源认证）；语义通道被标定污染（SCO 只读原始观测，禁止读 ĉ）；保护方向过度冻结（优先调度探测/规范锚而非永久冻结）；任务激励不足（保守归因 + 记录不可辨识事件）；人类锚不可靠/疲劳（w_h 建模 + 提问预算 + 只收缩）；STL 监控漏检（约束覆盖与采样率绑定，E288/E295 压测）。
