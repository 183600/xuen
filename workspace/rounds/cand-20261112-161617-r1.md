# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC / IP-153~160；灵感循环第 7 轮；本轮灵感：「智能体」×「同步定位与建图」）

> 第 60 轮把「执行层→证据层」闭环升级为「认知驱动的场景-执行闭环」：SSM 用场景-阻抗先验提前收窄 K_safe，CIEC 用意图锁定实时约束，EPIR 用序列号+哈希保障 ROS 消息丢失下的证据链，SERC 把三者串成闭环，PCE++++ 引入四维认知预算。但**四个与「空间」和「主动性」有关的根本局限**仍未解决：
> 1. **场景是标签，不是地图**：SSM 的 z_scene 是贴在整段执行上的一个全局标签，没有位置身份。真实工作区里往往有「三张看起来一样的桌子」，π_scene(K|'table_smooth') 会被无差别广播到所有桌子，K_safe 因此丢失了「在哪」这一维；同一张桌子今天和明天的阻抗差异也无处存放。
> 2. **认知是被动，不是主动**：CIEC 只等待遥测与人类意图，从不主动选择「摸哪里、用多大力」来减少不确定性。接触本身既是执行也是测量，但第 60 轮没有把「探针」当成可优化的信息动作。
> 3. **证据链有时序，无空间拓扑**：EPIR 只校验 timestamp/seq/hash，能防消息丢失，却防不了「每条消息都自洽、彼此却在空间上对不上」——同一地点的两条 EV-exec 被 ROS 乱序后仍各自合法，却与地图位姿矛盾。缺少 SLAM 式的**回环交叉校验**。
> 4. **智能体没有信念修订**：地图、计划、意图、信任被分散在 SSM/CIEC/EPIR 中，地图变了（物体被移动、回环把整张图拉正）不会以最小代价反馈到计划；智能体也没有「我该多信任这张地图」的校准机制。

## 0. 直觉与动机

**灵感 1（SLAM → 语义-阻抗地图 SIM）**
直觉：第 60 轮的「场景」是贴在整段执行上的一个标签，而不是工作空间里的一个位置。SLAM 告诉我们：地图不是一张图，而是一个带协方差的位姿图。把每个关键帧/地点挂上「语义标签 + 阻抗先验 + 协方差」，场景就从标量标签升级为**空间场** π(K|x)：同一类桌面在不同地点可以有不同先验，同一地点被反复接触后先验会收紧。关键洞见：**阻抗安全参数应当「定位锚定」——同一段 K_safe 只在它被观测过的空间邻域内有效**。

**灵感 2（智能体 → 主动阻抗探测 AIP）**
直觉：第 60 轮的认知是被动等待遥测；智能体的本质是「为了减少不确定性而行动」。既然一次接触既能执行又能测量，就应该让智能体主动选择「摸哪里、用多大力、摸多久」，用一次安全探针同时换取定位与阻抗的信息增益。关键洞见：**把探针选择写成贝叶斯 D-最优实验设计**——信息增益是目标，风险与能量是硬约束，选「最值得摸的那一下」而不是「按顺序摸一遍」。

**灵感 3（SLAM 回环 → 证据因子图 EFG）**
直觉：EPIR 的 timestamp/seq/hash 是「日志一致性」，不是「世界一致性」。SLAM 的回环检测给了答案：把 EV-exec 建成因子图，因果因子管先后、哈希因子管真伪、空间因子管「这条证据发生在哪个地点」，回环因子在重访同一地点时做交叉校验。关键洞见：**证据链的完整性不只是「顺序完整」，更是「时空拓扑完整」**；顺序对但地点错，和丢包一样危险。

**灵感 4（智能体信念 → 信念修订 ABR）**
直觉：智能体不是「执行计划的机器」，而是「维护信念的机器」。地图变了（物体被移动、回环把整张图拉正）、人的意图变了、执行证据推翻了旧先验，计划都必须以最小代价修订。借用 AGM 信念修订的「最小改变」原则：只回退受影响的计划后缀，而不是全盘重规划。关键洞见：**智能体的可靠性取决于「地图-计划-意图-信任」四者的一致性，以及信任随预测误差的在线校准**。

**灵感 5（合流 → AIMS 闭环）**
直觉：SIM 给出「在哪、那儿的阻抗先验是什么」，AIP 决定「下一步摸哪最值」，MAIC 在定位可信时把先验收窄为 K_safe(x)，EFG 保证证据时空自洽，ABR 在信念冲突时最小修订，PCE+++++ 管住地图/探测/推理预算。闭环：**定位建图 → 主动探测 → 地图锚定编译 → 执行 → 证据入图 → 回环校正 → 信念修订 → 地图更新**。

**灵感 6（安全 → 地理围栏证书 J_geo 与 PCE+++++）**
直觉：地图锚定的 K_safe 有一个致命前提——「我知道我在哪」。因此证书必须带空间有效期：K_safe 只在定位协方差足够小、地点可辨识、回环已确认的**地理围栏 V_geo** 内有效；一旦走出围栏或漂移超界，立即退回全局场景先验。关键洞见：**把 SLAM 的协方差直接写进安全证书，让「不确定的位置」不能携带「确定的安全承诺」**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（语义-阻抗地图 SIM）** 地图 M = (V, E, X, Z, Π, Σ)，其中：
- **位姿图**：V 为关键帧/地点集合，x_i ∈ SE(3)，Σ_i 为位姿协方差；E 为里程计/回环边 (i,j)，约束 z_ij、信息矩阵 Ω_ij
- **语义层**：z_i ∈ Z_scene，置信度 c_i（由 SSM 提供）
- **阻抗层**：π_i(K) = N(K; μ_i, Σ_{K,i})，由该地点 EV-exec 增量更新
- **阻抗场**：π(K|x) = Σ_{i∈V} w_i(x)·π_i(K)，w_i(x) = softmax_i(−½ (x−x_i)ᵀ Σ_i^{-1} (x−x_i))
- **地点可辨识度**：amb(x) = 1 − max_i w_i(x)，越大越不可辨识
- **地图更新**：位姿图 Gauss-Newton 后端 + 阻抗层共轭/Kalman 前端更新

**定义 162（主动阻抗探测 AIP）** 探针动作 a = (x_a, f_a, Δt)，观测 y_a = h_a(K(x_a)) + ε，ε ~ N(0, R_a)。高斯观测下的互信息为
IG(a) = ½ log det(I + Σ_prior H_aᵀ R_a^{-1} H_a)，
探针选择规则：
```
a* = argmax_{a∈A_feas} [ IG(a) − λ_R·Risk(a) − λ_E·E(a) ]
     s.t. Risk(a) ≤ R_max,  E(a) ≤ e_probe,  a 在 K_safe(x_a) 下可行
```
其中 A_feas 的每个候选先通过 MAIC 的安全门控；在线用贪心自适应选择。

**定义 163（地图锚定阻抗编译 MAIC）** 门控
g(x) = 1[σ_x² ≤ τ_pose] · 1[amb(x) ≤ τ_amb] · 1[回环已确认] · 1[‖∇_x μ(x)‖ ≤ G_max]，
地图锚定安全集与编译结果
K_safe(x) = g(x) ? {K ∈ K_base | P(K|x) ≥ τ_K ∧ SIC_valid(K)} : K_safe^global。
阻抗场施加 Lipschitz 约束 ‖μ_i − μ_j‖ ≤ G_max·d(x_i, x_j)，防止相邻地点的安全参数跳变造成「跨过一条缝就从不安全变安全」。

**定义 164（证据因子图 EFG）** G_E = (N_E, F_E)，变量 e_i = (t_i, seq_i, hash_i, x_i, EV_i)：
- **因果因子**：ψ_c(e_i, e_j) = 1[(t_i < t_j) ∧ (seq_i < seq_j)]，否则 0
- **哈希因子**：ψ_h(e_i) = 1[hash_i = H(EV_i)] ∧ 1[与边端影子副本一致]
- **空间因子**：ψ_s(e_i, e_j) = exp(−½‖x_i − x_j − Δx_ij‖²_{Ω_ij})
- **回环因子**：ψ_lc(e_i, e_j) = 1[place(e_i) = place(e_j) ∧ |EV_i − EV_j| ≤ ε]
MAP 估计 e* = argmax_e Π ψ，证据漂移 δ_E = 回环残差。若 δ_E > τ_drift，触发「证据回环」：拉取边端影子段、重排序列、纠正顺序并标记受影响证据。

**定义 165（智能体信念修订 ABR）** 信念 B = (M, P, I, T)，分别为地图、计划、意图状态、信任度。修订算子
B ∘ o = argmin_{B' ⊨ o} d(B, B')，d = w_M·d_M + w_P·d_P + w_I·d_I + w_T·d_T。
不一致集 Inc(B) = {计划引用地图中不存在的地点/物体; 计划与地图冲突; 意图与已锁定约束冲突; 信任与证据漂移冲突}。修订采用依赖导向回退：只改受影响的计划后缀 P[k:]，而非全盘重规划；信任校准 T ← clip(T + α(e_pred − e_obs), 0, 1)。

**定义 166（AIMS 闭环算子）** AIMS(M, B, scene, intent, delta_f_req)：
```
① SIM.update(odom, perception) → M
② if place_changed(M) or amb(x) > τ_amb or σ_x² > τ_pose:
       a* ← AIP.select(M); y ← probe(a*); SIM.fuse(y)
③ g ← MAIC.gate(M, x)
   K_safe ← g ? MAIC.compile(M, x, delta_f_req) : K_safe^global
④ CIEC.receive_intent(intent); ERTC.lock(C_intent)
⑤ EV_exec ← CLEP.execute(K_safe)
⑥ EFG.add(EV_exec, x); if δ_E > τ_drift: EFG.loop_close()
⑦ SIM.fuse_impedance(EV_exec, x)
⑧ if Inc(B) ≠ ∅: B ← ABR.revise(B, obs); dispatch(repaired_plan)
⑨ PCE+++++.charge(); if exhausted: fallback
⑩ return (M, B, K_safe, EV_exec, J_geo)
```

**定义 167（空间认知预算 B_spatial 与 PCE+++++）** B_spatial = (B_map, B_probe, B_agent, B_ros, B_exec)：
- **B_map** = (keyframe_rate, PGO_compute, map_memory)
- **B_probe** = (probe_count, probe_energy, info_gain_target)
- **B_agent** = (planning_latency, revision_count, context_window)
- **B_ros / B_exec** 继承第 60 轮
- **空间认知价值**：voi_aims(π) = VOI_meta(π) − cost_map(π) − cost_probe(π) − cost_agent(π) − cost_exec(π)
- **降级**：B_map 耗尽 → 冻结地图并膨胀 Σ；B_probe 耗尽 → 退回被动场景先验；B_agent 耗尽 → 冻结计划、反应式执行；B_ros 异常 → 本地闭环；B_exec 耗尽 → 原有降级

**定义 168（地理围栏阻抗证书 J_geo）** J_geo = (place_id, x, Σ_x, place_conf, K_safe, V_geo, δ_E, expiry, src_hash)，其中地理围栏
V_geo = {x | σ_x²(x) ≤ τ_pose ∧ amb(x) ≤ τ_amb}。
证书有效当且仅当 x ∈ V_geo ∧ σ_x² ≤ τ_pose ∧ amb(x) ≤ τ_amb ∧ δ_E ≤ τ_drift ∧ now < expiry。一旦出围栏或漂移超界，J_geo 立即失效并强制重编译；一次任务的三联证书为 J_joint = (J_exec, J_geo, J_data)。

### IP-161 SIM（语义-阻抗地图）

```python
class SemanticImpedanceMap:
    def __init__(self, n_places=64):
        self.poses = {}            # id -> SE3
        self.pose_cov = {}         # id -> 6x6
        self.semantic = {}         # id -> (label, conf)
        self.imp_prior = {}        # id -> (mu, Sigma_K)
        self.edges = []            # (i, j, z_ij, Omega_ij)
        self.n = n_places

    def update_pose_graph(self):
        for it in range(5):
            H, b = np.zeros((6*self.n, 6*self.n)), np.zeros(6*self.n)
            for (i, j, z, Om) in self.edges:
                r = se3_log(inv(self.poses[i]) @ self.poses[j] @ inv(z))
                J = self._jacobian(i, j)
                H += J.T @ Om @ J
                b += J.T @ Om @ r
            dx = np.linalg.solve(H + 1e-6*np.eye(len(H)), -b)
            self._apply(dx)
        self.pose_cov = {i: np.linalg.inv(H[i*6:(i+1)*6, i*6:(i+1)*6])
                         for i in range(self.n)}

    def fuse_impedance(self, ev_exec, x):
        i = self.nearest_place(x)
        mu, Sig = self.imp_prior[i]
        K_obs, R = ev_exec.K_safe, ev_exec.K_cov
        S = Sig + R
        G = Sig @ np.linalg.inv(S)
        self.imp_prior[i] = (mu + G @ (K_obs - mu),
                             (np.eye(len(mu)) - G) @ Sig)

    def impedance_field(self, x, top_k=5):
        ids = self.nearest_places(x, top_k)
        ws = softmax([-0.5 * (x - self.poses[i]).T @ np.linalg.inv(self.pose_cov[i])
                      @ (x - self.poses[i]) for i in ids])
        mu = sum(w * self.imp_prior[i][0] for w, i in zip(ws, ids))
        Sig = sum(w**2 * self.imp_prior[i][1] for w, i in zip(ws, ids))
        amb = 1.0 - max(ws)
        return mu, Sig, amb
```

### IP-162 AIP（主动阻抗探测）

```python
class ActiveImpedanceProber:
    def __init__(self, map_model, risk_max=0.2, e_probe=1.0):
        self.M, self.risk_max, self.e_probe = map_model, risk_max, e_probe

    def select(self, x, candidates):
        best, best_score = None, -np.inf
        for a in candidates:
            mu, Sig, _ = self.M.impedance_field(a.x)
            H = a.observation_jacobian()
            IG = 0.5 * np.log(np.linalg.det(
                 np.eye(len(mu)) + Sig @ H.T @ np.linalg.inv(a.R) @ H))
            risk = a.risk_estimate(mu)
            energy = a.energy_estimate()
            if risk > self.risk_max or energy > self.e_probe:
                continue
            if not self.M.maic_feasible(a.x):
                continue
            score = IG - 0.5 * risk - 0.1 * energy
            if score > best_score:
                best, best_score = a, score
        return best
```

### IP-163 MAIC（地图锚定阻抗编译）

```python
class MapAnchoredCompiler:
    def __init__(self, map_model, tau_pose=1e-3, tau_amb=0.4, G_max=5.0):
        self.M, self.tau_pose, self.tau_amb, self.G_max = \
            map_model, tau_pose, tau_amb, G_max

    def gate(self, x):
        _, Sig_x, amb = self.M.impedance_field(x)
        sigma2 = np.trace(Sig_x)
        lip_ok = self.M.local_lipschitz(x) <= self.G_max
        lc_ok = self.M.loop_closure_confirmed(x)
        return (sigma2 <= self.tau_pose and amb <= self.tau_amb
                and lip_ok and lc_ok)

    def compile(self, x, delta_f_req, K_base):
        mu, Sig, _ = self.M.impedance_field(x)
        if not self.gate(x):
            return K_base.safe_global(delta_f_req)
        ell = chi2_ellipsoid(Sig, tau_K)
        K_scene = {K for K in K_base.grid if (K - mu) @ np.linalg.inv(Sig) @ (K - mu) <= ell}
        return K_base.solve(K_scene, delta_f_req)
```

### IP-164 EFG（证据因子图）

```python
class EvidenceFactorGraph:
    def __init__(self, tau_drift=0.05):
        self.nodes, self.factors = [], []
        self.tau_drift = tau_drift

    def add(self, ev_exec, x):
        self.nodes.append(EvidenceNode(ev_exec, x))
        self._add_causal_and_hash_factors()

    def loop_close(self, shadow):
        for e in self.nodes:
            for s in shadow.recent():
                if self._same_place(e.x, s.x):
                    self.factors.append(LoopFactor(e, s))
        delta_E = self._map_residual()
        if delta_E > self.tau_drift:
            shadow.pull_range(self._affected_seq())
            self._reorder_and_flag()
        return delta_E

    def _map_residual(self):
        r = [f.residual() for f in self.factors if isinstance(f, LoopFactor)]
        return float(np.sqrt(np.mean(np.square(r)))) if r else 0.0
```

### IP-165 ABR（智能体信念修订）

```python
class AgentBeliefRevisor:
    def __init__(self, w=(1.0, 1.0, 0.5, 0.3)):
        self.w = w

    def inconsistent(self, B):
        out = []
        for step in B.plan:
            if step.place not in B.map.places():
                out.append(('missing_place', step))
            elif B.map.conflicts(step):
                out.append(('map_conflict', step))
        if B.intent.locked and B.intent.conflicts(B.constraints):
            out.append(('intent_conflict', B.intent))
        if B.trust < 0.5 and B.map.drift > B.tau_drift:
            out.append(('trust_drift', B.map))
        return out

    def revise(self, B, obs):
        inc = self.inconsistent(B)
        if not inc:
            return B
        k = min(step.index for _, step in inc if hasattr(step, 'index'))
        B.plan = B.plan[:k] + self.replan(B.plan[k:], B.map, B.intent)
        B.trust = np.clip(B.trust + 0.1 * (B.map.pred_err - obs.err), 0, 1)
        return B
```

```python
def aims_loop(M, B, intent, delta_f_req):
    M.update_pose_graph()
    x = M.current_pose()
    if M.place_changed() or M.ambiguity(x) > M.tau_amb:
        a = ActiveImpedanceProber(M).select(x, M.probe_candidates(x))
```

### IP-167 PCE+++++（空间认知预算）

```python
class SpatialCognitiveBudget:
    def __init__(self, map_ops=200, probe_ops=10, agent_ops=50, exec_budget=None):
        self.B_map, self.B_probe, self.B_agent = map_ops, probe_ops, agent_ops
        self.ops_map = self.ops_probe = self.ops_agent = 0
        self.B_exec = exec_budget or ExecBudget()

    def mode(self):
        if self.ops_map >= self.B_map:
            return 'frozen_map'
        if self.ops_probe >= self.B_probe:
            return 'passive_prior'
        if self.ops_agent >= self.B_agent:
            return 'frozen_plan'
        return 'normal'

    def charge(self, action):
        self.ops_map += action.map_cost
        self.ops_probe += action.probe_cost
        self.ops_agent += action.agent_cost
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SIM | 位姿图 O(\|E\|·6²·k) / 阻抗融合 O(d_K²) | O(\|V\|·(6+d_K)) | 回环后位姿误差 ≤ δ_pose，阻抗场 Lipschitz |
| AIP | O(\|A\|·d_K³) / 探针 | O(\|A\|) | 信息增益 ≥ (1−1/e)·OPT（自适应子模） |
| MAIC | O(\|K\|·d_K) / 地点 | O(\|K\|) | K_safe(x) 仅在 V_geo 内有效 |
| EFG | O(\|N_E\|) 增量 / O(\|N_E\|·\|F\|) 回环 | O(\|N_E\|) | δ_E ≤ τ_drift，证据链时空一致 |
| ABR | O(\|P\|·\|Inc\|) | O(\|P\|) | 修订终止且计划后缀最小 |

**正确性定理（AIMS）**：

### IP-161 SIM（语义-阻抗地图）

```python
class SemanticImpedanceMap:
    def __init__(self, n_places=64):
        self.poses, self.pose_cov = {}, {}
        self.semantic, self.imp_prior = {}, {}
        self.edges, self.n = [], n_places

    def update_pose_graph(self):
        for _ in range(5):
            H, b = np.zeros((6*self.n, 6*self.n)), np.zeros(6*self.n)
            for (i, j, z, Om) in self.edges:
                r = se3_log(inv(self.poses[i]) @ self.poses[j] @ inv(z))
                J = self._jacobian(i, j)
                H += J.T @ Om @ J
                b += J.T @ Om @ r
            dx = np.linalg.solve(H + 1e-6*np.eye(len(H)), -b)
            self._apply(dx)
        self.pose_cov = {i: np.linalg.inv(H[i*6:(i+1)*6, i*6:(i+1)*6])
                         for i in range(self.n)}

    def fuse_impedance(self, ev_exec, x):
        i = self.nearest_place(x)
        mu, Sig = self.imp_prior[i]
        S = Sig + ev_exec.K_cov
        G = Sig @ np.linalg.inv(S)
        self.imp_prior[i] = (mu + G @ (ev_exec.K_safe - mu),
                             (np.eye(len(mu)) - G) @ Sig)

    def impedance_field(self, x, top_k=5):
        ids = self.nearest_places(x, top_k)
        ws = softmax([-0.5 * (x - self.poses[i]).T @ np.linalg.inv(self.pose_cov[i])
                      @ (x - self.poses[i]) for i in ids])
        mu = sum(w * self.imp_prior[i][0] for w, i in zip(ws, ids))
        Sig = sum(w**2 * self.imp_prior[i][1] for w, i in zip(ws, ids))
        return mu, Sig, 1.0 - max(ws)
```

### IP-162 AIP（主动阻抗探测）

```python
class ActiveImpedanceProber:
    def __init__(self, map_model, risk_max=0.2, e_probe=1.0):
        self.M, self.risk_max, self.e_probe = map_model, risk_max, e_probe

    def select(self, x, candidates):
        best, best_score = None, -np.inf
        for a in candidates:
            mu, Sig, _ = self.M.impedance_field(a.x)
            H = a.observation_jacobian()
            IG = 0.5 * np.log(np.linalg.det(
                 np.eye(len(mu)) + Sig @ H.T @ np.linalg.inv(a.R) @ H))
            risk, energy = a.risk_estimate(mu), a.energy_estimate()
            if risk > self.risk_max or energy > self.e_probe:
                continue
            if not self.M.maic_feasible(a.x):
                continue
            score = IG - 0.5 * risk - 0.1 * energy
            if score > best_score:
                best, best_score = a, score
        return best
```

### IP-163 MAIC（地图锚定阻抗编译）

```python
class MapAnchoredCompiler:
    def __init__(self, map_model, tau_pose=1e-3, tau_amb=0.4, G_max=5.0):
        self.M, self.tau_pose, self.tau_amb, self.G_max = \
            map_model, tau_pose, tau_amb, G_max

    def gate(self, x):
        _, Sig_x, amb = self.M.impedance_field(x)
        return (np.trace(Sig_x) <= self.tau_pose
                and amb <= self.tau_amb
                and self.M.local_lipschitz(x) <= self.G_max
                and self.M.loop_closure_confirmed(x))

    def compile(self, x, delta_f_req, K_base):
        mu, Sig, _ = self.M.impedance_field(x)
        if not self.gate(x):
            return K_base.safe_global(delta_f_req)
        ell = chi2_ellipsoid(Sig, self.tau_K)
        K_scene = {K for K in K_base.grid
                   if (K - mu) @ np.linalg.inv(Sig) @ (K - mu) <= ell}
        return K_base.solve(K_scene, delta_f_req)
```

```python
class EvidenceFactorGraph:
    def __init__(self, tau_drift=0.05):
        self.nodes, self.factors, self.tau_drift = [], [], tau_drift

    def add(self, ev_exec, x):
        self.nodes.append(EvidenceNode(ev_exec, x))
        self._add_causal_and_hash_factors()

    def loop_close(self, shadow):
        for e in self.nodes:
            for s in shadow.recent():
                if self._same_place(e.x, s.x):
                    self.factors.append(LoopFactor(e, s))
        delta_E = self._map_residual()
        if delta_E > self.tau_drift:
            shadow.pull_range(self._affected_seq())
            self._reorder_and_flag()
        return delta_E

    def _map_residual(self):
        r = [f.residual() for f in self.factors if isinstance(f, LoopFactor)]
        return float(np.sqrt(np.mean(np.square(r)))) if r else 0.0
```

### IP-165 ABR（智能体信念修订）

```python
class AgentBeliefRevisor:
    def __init__(self, w=(1.0, 1.0, 0.5, 0.3)):
        self.w = w

    def inconsistent(self, B):
        out = []
        for step in B.plan:
            if step.place not in B.map.places():
                out.append(('missing_place', step))
            elif B.map.conflicts(step):
                out.append(('map_conflict', step))
        if B.intent.locked and B.intent.conflicts(B.constraints):
            out.append(('intent_conflict', B.intent))
        if B.trust < 0.5 and B.map.drift > B.tau_drift:
            out.append(('trust_drift', B.map))
        return out

    def revise(self, B, obs):
        inc = self.inconsistent(B)
        if not inc:
            return B
        k = min(step.index for _, step in inc if hasattr(step, 'index'))
        B.plan = B.plan[:k] + self.replan(B.plan[k:], B.map, B.intent)
        B.trust = np.clip(B.trust + 0.1 * (B.map.pred_err - obs.err), 0, 1)
        return B
```
