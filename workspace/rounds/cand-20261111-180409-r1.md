# 第 56 轮（承接第 55 轮想法区「语义-接触接地」与第 54 轮产物 v31；灵感循环第 1 轮；本轮灵感：「场景驱动创新」×「姿态估计」）

> 第 55 轮把“感知标签”升级成“可执行的语义-接触约束”，并用生存核 + 护盾把单次接触的可信性写进证书 `J_s`。但这条证书链仍把两件事当作背景：**场景是人工给定的、离散的任务标签**；**身体姿态是已观测到的、近似无偏的量**。本轮引入「场景驱动创新」与「姿态估计」正是来拆这两个背景假设：场景驱动创新要求创新由真实部署场景牵引，但人工挑选的场景在高维姿态-接触空间里只是极稀疏的点；姿态估计提供了跨视角、跨构型的公共坐标，却恰在遮挡/自接触/脚底接触处最不可信。核心矛盾：**H24（场景不可度量）**：若场景不可度量，“场景驱动”会退化为“演示驱动”的过拟合——场景之间既无法判断是否同类，也无法判断是否真的覆盖了部署分布；**H25（接触处姿态最不确定）**：姿态误差在接触点附近因自遮挡与接触遮挡而相关且偏大，把它当作独立高斯噪声会正好在 v32 语义边界裕度最需要精确的地方低估误差，使“语义上可信的接触”在姿态坐标里已经滑出支撑面。

## 0. 直觉与动机

**灵感 1（场景驱动创新 → 场景是姿态-接触测度，不是任务标签）**
直觉：一个场景真正约束机器人的，不是“搬箱子/上楼梯”这几个字，而是“身体在哪些姿态下、以什么接触排程、与哪些表面持续作用”。把场景写成姿态-接触轨迹上的概率测度 `P_σ`，场景的“同类/新颖/覆盖”才第一次变成可计算量；否则所谓创新只能靠人挑 demo，无法证明新场景不是旧场景换皮。

**灵感 2（姿态估计 → 场景的公共坐标与可迁移证据）**
直觉：RGB/深度/IMU 下的姿态估计给出与外观解耦、跨视角相对稳定的身体构型。它让“人类演示的场景”“另一台机器人的场景”“仿真里的场景”可以落到同一个姿态-接触空间比较。但姿态不是免费午餐：它把感知误差压缩进关键点，而关键点又被前向运动学放大成接触点位置误差。

**灵感 3（两者耦合 → 认证集要投影到姿态空间，缺口才可见）**
直觉：v32 的生存核 `K(Σ)` 与保守接触集 `C⁺(Σ)` 是在状态-接触空间定义的；只有经前向运动学投影到姿态-接触空间，才能回答“这个场景要求的姿态有没有被认证”。覆盖缺口 `γ(σ)` 不是任务失败率，而是“场景要求的交互点落在认证集之外”；一个在仿真里偶然成功的场景，仍可能完全未被认证。

**灵感 4（姿态不确定性 → 接触证书的裕度必须减去姿态诱导位移）**
直觉：若姿态可信集为 `Ξ_α`，则接触点可能在整个 `FK(Ξ_α)` 上移动。语义边界裕度 `m_s` 必须扣除这一姿态诱导位移 `Δ_k` 后才能作为控制裕度；否则分割置信再高，脚掌也可能被姿态误差推到语义边界外。更严重的是遮挡下姿态后验是多峰的，均值附近可能根本没有可信解——必须逐峰认证或拒证，而不是对均值做一次高斯近似。

**灵感 5（场景驱动创新 → 主动生成“证书边界场景”，而非堆 demo）**
直觉：创新不应只来自人类想象的新任务，而应来自 **能最大化“新颖度 × 认证缺口 × 场景有效性”的场景组合**：去生成那些既没被旧场景覆盖、又确实落在物理可行流形上、并能戳到当前证书边界的场景。这样场景生成本身变成一个带安全与预算约束的优化问题，产出的不是更多 demo，而是更密的证据覆盖与更早的失败暴露。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（场景-姿态签名）**
场景 `σ = (E, G, T, P_σ)`：`E` 为环境/布局，`G` 为目标，`T` 为时域，`P_σ` 为交互轨迹 `(ξ_{1:T}, c_{1:T})` 上的概率测度；`ξ_t ∈ SE(3)^K` 为身体关键点/关节姿态（含基座），`c_t ∈ {0,1}^K` 为脚/手/躯干的接触排程。姿态估计器给出校准后验 `q_θ(ξ,c | o)`。签名 `Sig(σ) = Law_σ(ξ,c)`，场景距离
`d_S(σ_1,σ_2) = W_{2,λ}(Sig(σ_1), Sig(σ_2))`，
ground metric `d_pose(ξ,ξ') = Σ_k w_k d_SE3(ξ_k,ξ'_k) + w_c Σ_k |c_k-c'_k|`，`W_{2,λ}` 为熵正则最优传输。于是“是否同类”与“是否新颖”都成为可度量量。

**定义 128（认证交互集与姿态覆盖缺口）**
由 v32 的 `K(Σ)`、`C⁺(Σ)` 经前向运动学投影得到认证交互集
`C_cert = {(ξ,c) | FK(ξ) 的接触与 C⁺(Σ) 可配准 ∧ ξ ∈ Proj(K(Σ))}`。
场景覆盖 `Cov(σ) = P_σ((ξ,c) ∈ C_cert)`，缺口 `γ(σ) = 1 - Cov(σ)`。对场景组合 `S = {(σ_i,w_i)}`，`Cov_LCB(S)` 用按场景聚类/切片的 bootstrap 下界；新奇度 `Nov(σ; S_ref) = min_{σ'∈S_ref} d_S(σ,σ')`。关键：覆盖缺口度量的是“认证集之外”，不是“仿真里失败”。

**定义 129（姿态条件化接触证书）**
姿态可信集 `Ξ_α = {ξ | q(ξ|o) ≥ q_α}`，且 `P(ξ∈Ξ_α) ≥ 1-α`。对关键点 `k`，接触点 `p_k(ξ)=FK_k(ξ)`；姿态诱导接触位移
`Δ_k = sup_{ξ,ξ'∈Ξ_α} ||p_k(ξ)-p_k(ξ')|| ≤ L_k · diam(Ξ_α)`。
姿态条件可供性 `κ(l,c|ξ)`。保守接触集
`C⁺(Σ,Ξ_α) = {(k,c) | κ(l(p_k),c|ξ̂) ≥ θ_κ ∧ m_s(p_k) - Δ_k ≥ θ_m(c) ∧ (k,c) 在 Ξ_α 的每个连通分量上均成立}`。
若 `Ξ_α` 多峰（自遮挡/接触遮挡），逐峰认证取交集；任一分量不成立则拒证。证书分量 `(Ξ_α, Δ, δ_pose, r_contact)`。

**定义 130（保接触重定向）**
源姿态轨迹 `ξ^S`（人类演示或异构机器人），目标重定向 `R: ξ^S → ξ^R`。保接触缺陷
`d_R = max_t [ w_c Σ_k c_{k,t} ||p^R_k(ξ^R_t) - T_t p^S_k(ξ^S_t)|| + w_s max(0, θ_sup - m_sup(ξ^R_t)) + w_j viol(ξ^R_t) ]`，
其中 `m_sup` 为支撑多边形裕度，`viol` 为关节限位/CoM 违反。可迁移条件：`d_R ≤ Θ_r`、接触排程逐帧一致 `c^R_t = c^S_t`、且 `(ξ^R,c) ⊆ C_cert`。这把“人类/他机场景”转成“本机可认证场景”的准入判据。

**定义 131（场景组合创新目标）**
场景语法 `G` 参数化环境、材质、障碍、人体行为与扰动；可采纳集
`A = {σ∈G | 运动学可行 ∧ 接触自洽 ∧ 观测似然支持 ∧ 仿真风险 ≤ ε_safe}`。
预算 `B` 下选择场景分布 `q∈Δ(G)`：
`q* = argmax_q E_{σ~q}[ Nov(σ;S_ref) · γ(σ) · V(σ) ] / cost(q)`，
s.t. `supp(q) ⊆ A`、`Risk(σ) ≤ ε_safe`、`E[cost] ≤ B`，其中 `V(σ)∈[0,1]` 为姿态-场景几何一致性（重投影/接触残差校准）。`γ` 让生成器去戳证书边界，`Nov` 防止旧场景换皮，`V` 阻止“怪姿态”骗取缺口；部署时仍只允许走已认证子集。

**定义 132（场景-姿态联合证书）**
`J_sp = (S_core, C_cert, Ξ_α, δ_pose, d_R, Cov_LCB, γ_crit, evidence)`：
- `S_core` 覆盖部署先验的核心场景集，`C_cert` 认证交互集，`Ξ_α` 姿态可信集；
- `δ_pose = max_k Δ_k`，`d_R` 保接触重定向缺陷；
- `Cov_LCB` 覆盖下界，`γ_crit = max_{σ∈S_core∩Critical} γ(σ)`；
- `evidence` 含接触-姿态残差、跨视角/跨构型验证与缺口反例。
若 `Cov_LCB ≥ 1-ε_cov`、`δ_pose ≤ Θ_p`、`d_R ≤ Θ_r`、`γ_crit = 0` 且 `Ξ_α` 各分量通过接触条件校准，则场景-姿态可部署。

## 2. 关键算法 伪代码

### IP-127 SPS（Scenario-Pose Signature）

```python
def scenario_pose_signature(scenario, pose_model, n_episodes, n_particles, metric):
    samples = []
    for episode in scenario.rollout(n_episodes):
        q = pose_model.posterior(episode.observations())   # calibrated (xi,c) posterior
        for xi, c in q.sample(n_particles):
            samples.append((xi, c, q.logprob(xi, c)))
    Sig = WeightedEmpiricalMeasure(samples)
    return Sig, estimate_ot_distance(Sig, metric)          # cache pairwise d_S
```

### IP-128 PCG（Pose Coverage Gap）

```python
def pose_coverage_gap(scenarios, cert_set, pose_model, n_boot, alpha):
    per = {}
    for s in scenarios:
        Sig, _ = scenario_pose_signature(s, pose_model, ...)
        hits = [in_certified(xi, c, cert_set) for xi, c, w in Sig.samples]
        per[s.id] = weighted_mean(hits, Sig.weights)
    Cov_LCB = clustered_bootstrap_lower(per, n_boot)        # cluster by scenario
    gaps = {s.id: 1.0 - per[s.id] for s in scenarios}
    return Cov_LCB, gaps, gap_map(gaps, pose_space_grid)
```

### IP-129 PCP（Pose-Conditioned Contact certificate）

```python
def pose_conditioned_contacts(Sigma, kappa, pose_post, alpha, theta_m, L_fk):
    modes = credible_modes(pose_post, alpha)                # keep multimodal, never average
    if not modes:
        return None, 'no_credible_pose'
    common, worst_delta = None, 0.0
    for mode in modes:
        Xi = mode.credible_set(alpha)
        local = set()
        for k in KEYPOINTS:
            delta_k = L_fk[k] * diameter(Xi, contact_metric)
            worst_delta = max(worst_delta, delta_k)
            p = fk(mode.mean, k)
            l = argmax_label(Sigma, p)
            for c in CONTACT_TYPES:
                if (kappa[l][c] >= theta_k
                    and boundary_margin(Sigma, p) - delta_k >= theta_m(c)
                    and mode.coverage >= 1 - alpha / len(modes)):
                    local.add((k, c))
        common = local if common is None else (common & local)
    return common, worst_delta
```

### IP-131 SPI（Scenario Portfolio Innovation）

```python
def scenario_portfolio_innovation(grammar, cert_set, pose_model, ref_portfolio, budget):
    q = init_proposal(grammar)
    while budget.remaining() > 0:
        sigma = sample(grammar, q)
        if not admissible(sigma):
            continue
        Sig, _ = scenario_pose_signature(sigma, pose_model, ...)
        cov = coverage(sigma, Sig, cert_set)
        value = novelty(Sig, ref_portfolio) * (1.0 - cov) * validity(sigma, Sig)
        update_proposal(q, sigma, value)                    # push mass to cert boundary
        budget.consume(sigma)
        if cov < 1.0:
            log_counterexample(sigma, Sig)                  # gap witness for next round
    return select_portfolio(q, admissible, safety_eps=eps_safe)
```

### IP-132 SPC（Scenario-Pose Certificate）

```python
def scenario_pose_certificate(portfolio, cert_set, pose_post, retarget_defects, budgets):
    S_core = cover_deployment_prior(portfolio)
    if any(not certified(s, cert_set) for s in S_core):
        return ('reject', 'uncertified_core_scenario')
    Cov_LCB = clustered_bootstrap_lower({s.id: coverage(s, cert_set) for s in S_core}, budgets.n_boot)
    if Cov_LCB < 1 - budgets.eps_cov:
        return ('reject', 'coverage_lower_bound_fail', Cov_LCB)
    delta_pose = max_contact_displacement(pose_post.credible_set(budgets.alpha))
    if delta_pose > budgets.Theta_p:
        return ('reject', 'pose_uncertainty_exceeds_budget', delta_pose)
    if max(retarget_defects.values()) > budgets.Theta_r:
        return ('reject', 'retargeting_defect_exceeds_budget')
    gamma_crit = critical_gap(S_core, cert_set)
    if gamma_crit > 0:
        return ('reject', 'critical_gap', gamma_crit)
    return ('ok', ScenarioPoseCert(S_core, cert_set, delta_pose, retarget_defects, Cov_LCB, gamma_crit))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SPS | O(N_ep·N_p·(C_pose+d_S)) | O(N_ep·N_p) | 后验校准、OT 度量经验证 |
| PCG | O(|S|·N·|C_cert| + n_boot) | O(|S|·N) | 场景聚类下界 sound |
| PCP | O(|Ξ|·K·|C| + FK) | O(|Ξ|·K) | 可信集覆盖、Lipschitz 界 sound |
| CPR | O(T·IK) | O(T·K) | 接触排程保持、缺陷界可测 |
| SPI | O(B·(gen+eval)) | O(B) | 可采纳性/安全约束、覆盖估计 |
| SPC | O(|S|·N + n_boot) | O(|S|·N) | 核心场景非空、缺口判定 sound |

**正确性定理（Scenario-Pose Grounding Soundness）**
假设 v31 的 (A26)–(A28) 与 v32/SCT 的 (A29)–(A32) 成立；追加 **(A38)** 姿态后验经校准且 `P(ξ∈Ξ_α) ≥ 1-α`、接触条件 ECE ≤ ε_pose；**(A39)** `Δ_k ≤ L_k·diam(Ξ_α)` 的 Lipschitz 界 sound，且 `Ξ_α` 各连通分量的覆盖估计可靠；**(A40)** 重定向保持接触排程且 `d_R ≤ Θ_r`；**(A41)** 场景生成器支撑 ⊆ `A`，`d_S` 估计误差 ≤ ε_W，`Cov_LCB` 为有效下界。则部署后安全概率：
```
P_safe ≥ 1 - P(ξ ∉ Ξ_α) - P(δ_pose > Θ_p) - P(d_R > Θ_r)
           - (1 - Cov_LCB) - P(σ ∉ A) - P(|d̂_S - d_S| > ε_W)
           - [SCT/v31 证书项]
```
关键：**姿态可信集把接触误差显式放大为控制裕度的扣减，认证集投影把“场景覆盖”变成可判定量，保接触重定向把跨构型证据限制在接触不变的前提下**；三者任一层失守都只允许拒证或降级，绝不允许用“姿态看起来很稳”替代“接触已被认证”。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 遮挡/自接触处姿态“自信地错” | 高 | 接触条件校准 + 多峰可信集 + 触觉/本体锚定，证据不足即拒证 |
| 场景签名对视角/构型不不变 | 高 | 多视角一致性 + 构型归一化 + OT 度量外部验证 |
| 覆盖缺口在认证集外无法估计 | 高 | 仿真缺口图 + OOD 检测 + 主动采样边界，缺口一律按未认证处理 |
| 重定向保关键点但不保动力学 | 高 | 支撑多边形/接触力可行性联合约束 + 动力学回放验证 |
| 场景生成器产生不可执行场景 | 中 | 可采纳语法 + 物理有效性 + 授权门控，只认证可执行子集 |
| 场景创新过拟合姿态模型的盲区 | 高 | 多姿态模型集成 + 跨构型留出 + 真实锚点复核 |

## 6. 本轮最大风险

**一句话**：用姿态估计给场景提供公共坐标、再以覆盖缺口驱动创新，整套链条的 soundness 都压在“姿态后验在接触处仍然可信”这一假设上；一旦自遮挡或接触遮挡让姿态在接触点附近多峰且偏置，`Δ_k` 会低估真实位移、重定向会在错误坐标里“保持接触”，生成器还会系统性地把场景推到姿态模型的盲区，从而在“覆盖看起来提升”的同时把认证集变成一张错误的姿态地图——因此必须以 **多峰可信集 + 接触条件校准 + 触觉/本体锚定 + 跨构型留出** 四重护栏，宁可对姿态证据不足的场景拒证，也绝不把“姿态估计的高置信”当作“接触几何的已证实”。

> - **SPACE（Scenario-Pose Anchored Certification & Exploration）· IP-127~132**：把“场景驱动创新 × 姿态估计”升级为“场景可度量、缺口可定位、跨构型证据可准入、创新可优化”的闭环。
>
> 一句话：v31 认证“动作能否对齐”，SCT 认证“接触是否可信”，SPACE 认证“场景是否真的被覆盖、姿态坐标是否可信”；三层串起来，才是从数据到部署再到场景创新的完整证据链。

### 2.1 SCT 层（IP-121~126，第 55 轮想法落地）

```python
# IP-121 SCG
def semantic_contact_map(rgbd, seg_model, kappa, theta_k, theta_conf):
    Sigma = seg_model.predict_soft(rgbd)
    C = {(p, c) for p in grid(rgbd) for c in CONTACT_TYPES
         if confidence(Sigma[p]) >= theta_conf
         and kappa[argmax(Sigma[p])][c] >= theta_k}
    M = boundary_margin(Sigma)                      # m_s(p)
    return Sigma, C, M

# IP-122 WBV
def viability_kernel(Sigma, C_plus, x0, horizon, eps):
    K, margins = set(), []
    for x in sample_state_space(x0, horizon):
        feas, u, lam = solve_contact_dynamics(x, C_plus, friction_cone=mu)
        if feas:
            K.add(x); margins.append(distance_to_infeasible(x, C_plus))
    return KernelApprox(inner_hull(K), outer_hull(K, eps),
                        min(margins) if margins else 0.0)

# IP-123 SSF
def semantic_shield(u_nom, x, Kernel, C_plus, W):
    u = qp_solve(H=W, g=-W @ u_nom,
                 constraints=[viability_constraint(x, u, Kernel.K_in),
                              contact_constraint(u, C_plus),
                              friction_cone_constraint(u, mu),
                              joint_limit_constraint(u)])
    return (u, 'ok') if u is not None and projection_gap(u, u_nom) <= Delta_u \
        else (safe_brake(x), 'shield_infeasible')

# IP-124 SCC
def semantic_contact_certificate(traj, Sigma, kappa, rho_sem, budgets):
    Sigma_core = core_semantics(traj, Sigma)
    C_core = contacts_used(traj) & conservative_contacts(Sigma_core, M, kappa, theta_m)
    if not C_core: return ('reject', 'no_core_contact')
    K_margin = min(distance_to_boundary_K(x, Sigma) for x in traj)
    delta_s = semantic_perturbation(Sigma_core, calibrated_eps)
    if K_margin < budgets.theta_K or delta_s > budgets.Theta_s:
        return ('reject', 'semantic_budget_exceeded', K_margin, delta_s)
    if rho_sem(delta_s) < budgets.rho_min:
        return ('reject', 'semantic_robustness_fail')
    return ('ok', SemanticCert(Sigma_core, C_core, K_margin, rho_sem, delta_s))

# IP-125 SRS
def semantic_robustness_spectrum(Sigma_hat, eps_s, sampler):
    worst = 1.0
    for Sigma_adv in sampler.ball(Sigma_hat, eps_s, worst_case=True):
        worst = min(worst, empirical_viability(renormalize(Sigma_adv), sampler.states))
    return worst

# IP-126 CEB
def cloud_edge_semantics(Sigma_c, kappa_c, edge):
    Sigma_e, C_e = edge.local_semantics()
    mismatch = boundary_disagreement(Sigma_c, Sigma_e)
    if mismatch.area > delta_A:
        return ('reprofile', region=mismatch.hotspots, evidence=edge.explain_contact_failure())
    return ('ok', conservative_contacts(C_e, edge.margin, kappa_c, theta_m),
            merge_uncertainty(Sigma_c, Sigma_e))
```

### 2.2 SPACE 层（IP-127~132，本轮新增）

```python
# IP-127 SPS：场景-姿态签名
def scenario_pose_signature(scenario, pose_model, n_episodes, n_particles, metric):
    samples = []
    for episode in scenario.rollout(n_episodes):
        q = pose_model.posterior(episode.observations())   # calibrated (xi,c) posterior
        for xi, c in q.sample(n_particles):
            samples.append((xi, c, q.logprob(xi, c)))
    Sig = WeightedEmpiricalMeasure(samples)
    return Sig, estimate_ot_distance(Sig, metric)          # d_S with SE(3)+contact metric

# IP-128 PCG：覆盖缺口
def pose_coverage_gap(scenarios, cert_set, pose_model, n_boot):
    per = {}
    for s in scenarios:
        Sig, _ = scenario_pose_signature(s, pose_model, ...)
        hits = [in_certified(xi, c, cert_set) for xi, c, w in Sig.samples]
        per[s.id] = weighted_mean(hits, Sig.weights)
    Cov_LCB = clustered_bootstrap_lower(per, n_boot)        # cluster by scenario
    gaps = {s.id: 1.0 - per[s.id] for s in scenarios}
    return Cov_LCB, gaps, gap_map(gaps, pose_space_grid)

# IP-129 PCP：姿态条件化接触证书
def pose_conditioned_contacts(Sigma, kappa, pose_post, alpha, theta_m, L_fk):
    modes = credible_modes(pose_post, alpha)                # keep multimodal, never average
    if not modes:
        return None, 'no_credible_pose'
    common, worst_delta = None, 0.0
    for mode in modes:
        Xi = mode.credible_set(alpha)
        local = set()
        for k in KEYPOINTS:
            delta_k = L_fk[k] * diameter(Xi, contact_metric)
            worst_delta = max(worst_delta, delta_k)
            p = fk(mode.mean, k)
            l = argmax_label(Sigma, p)
            for c in CONTACT_TYPES:
                if (kappa[l][c] >= theta_k
                    and boundary_margin(Sigma, p) - delta_k >= theta_m(c)
                    and mode.coverage >= 1 - alpha / len(modes)):
                    local.add((k, c))
        common = local if common is None else (common & local)   # certify per mode, intersect
    return common, worst_delta

# IP-130 CPR：保接触重定向
def contact_preserving_retarget(xi_src, c_sched, robot, Theta_r):
    xi_tgt = retarget_kinematic(xi_src, robot)              # contact-aware IK
    xi_tgt = refine_with_support_polygon(xi_tgt, c_sched, robot)
    dR = contact_defect(xi_src, xi_tgt, c_sched, robot)     # Def.130
    if dR > Theta_r or contact_schedule(xi_tgt) != c_sched:
        return ('reject', 'contact_not_preserved', dR)
    if not in_certified_interaction_set(xi_tgt, c_sched):
        return ('reject', 'outside_certified_set')
    return ('ok', RetargetCert(xi_tgt, dR))

# IP-131 SPI：场景组合创新
def scenario_portfolio_innovation(grammar, cert_set, pose_model, ref_portfolio, budget):
    q = init_proposal(grammar)
    while budget.remaining() > 0:
        sigma = sample(grammar, q)
        if not admissible(sigma):
            continue
        Sig, _ = scenario_pose_signature(sigma, pose_model, ...)
        cov = coverage(sigma, Sig, cert_set)
        value = novelty(Sig, ref_portfolio) * (1.0 - cov) * validity(sigma, Sig)
        update_proposal(q, sigma, value)                    # push mass to cert boundary
        budget.consume(sigma)
        if cov < 1.0:
            log_counterexample(sigma, Sig)                  # gap witness for next round
    return select_portfolio(q, admissible, safety_eps=eps_safe)

# IP-132 SPC：场景-姿态联合证书
def scenario_pose_certificate(portfolio, cert_set, pose_post, retarget_defects, budgets):
    S_core = cover_deployment_prior(portfolio)
    if any(not certified(s, cert_set) for s in S_core):
        return ('reject', 'uncertified_core_scenario')
    Cov_LCB = clustered_bootstrap_lower({s.id: coverage(s, cert_set) for s in S_core},
                                        budgets.n_boot)
    if Cov_LCB < 1 - budgets.eps_cov:
        return ('reject', 'coverage_lower_bound_fail', Cov_LCB)
    delta_pose = max_contact_displacement(pose_post.credible_set(budgets.alpha))
    if delta_pose > budgets.Theta_p:
        return ('reject', 'pose_uncertainty_exceeds_budget', delta_pose)
    if max(retarget_defects.values()) > budgets.Theta_r:
        return ('reject', 'retargeting_defect_exceeds_budget')
    gamma_crit = critical_gap(S_core, cert_set)
    if gamma_crit > 0:
        return ('reject', 'critical_gap', gamma_crit)
    return ('ok', ScenarioPoseCert(S_core, cert_set, delta_pose, retarget_defects,
                                   Cov_LCB, gamma_crit))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SCG | O(|Ω|·(|L|+|C|)) | O(|Ω|·|L|) | 置信校准、可供性标定 |
| WBV | O(|X|·T·QP) | O(|X|) | 核外近似 sound、接触集完备 |
| SSF | O(QP)/步 | O(|A_WB|) | QP 可行或安全回退 |
| SCC | O(|轨迹|·|Ω|) | O(|Ω|) | δ_s 预算闭合、核心接触非空 |
| SRS | O(N_adv·|X|) | O(|X|) | 扰动球覆盖、最坏可复现 |
| CEB | O(|∂Ω|·|C|) | O(|∂Ω|) | 边界不一致检测、重分割收敛 |
| SPS | O(N_ep·N_p·(C_pose+d_S)) | O(N_ep·N_p) | 后验校准、OT 度量经验证 |
| PCG | O(|S|·N·|C_cert|+n_boot) | O(|S|·N) | 场景聚类下界 sound |
| PCP | O(|Ξ|·K·|C|+FK) | O(|Ξ|·K) | 可信集覆盖、Lipschitz 界 sound |
| CPR | O(T·IK) | O(T·K) | 接触排程保持、缺陷界可测 |
| SPI | O(B·(gen+eval)) | O(B) | 可采纳性/安全约束、覆盖估计 |
| SPC | O(|S|·N+n_boot) | O(|S|·N) | 核心场景非空、缺口判定 sound |

**正确性定理（GroundEdge v32 全链证据 Soundness）**
假设 v31 的 (A26)–(A28) 与 SCT 的 (A29)–(A32) 成立；SPACE 追加 **(A38)** 姿态后验经校准且 `P(ξ∈Ξ_α) ≥ 1-α`、接触条件 ECE ≤ ε_pose；**(A39)** `Δ_k ≤ L_k·diam(Ξ_α)` 的 Lipschitz 界 sound，`Ξ_α` 各连通分量覆盖估计可靠；**(A40)** 重定向保持接触排程且 `d_R ≤ Θ_r`；**(A41)** 场景生成器支撑 ⊆ `A`，`d_S` 估计误差 ≤ ε_W，`Cov_LCB` 为有效下界。
则端到端部署成功概率：
```
P_success ≥ 1 − Σ_d(1−ρ_min(d)) − β_E − P(δ_a > Θ_a)                 # v31 动作-协同
            − P(‖Σ−Σ̂‖∞ > ε_s) − P(κ miscalibrated) − P(K_out\K_in ≠ ∅)  # SCT 语义-接触
            − P(ξ ∉ Ξ_α) − P(δ_pose > Θ_p) − P(d_R > Θ_r)              # SPACE 姿态-重定向
            − (1 − Cov_LCB) − P(σ ∉ A) − P(|d̂_S − d_S| > ε_W)          # SPACE 场景-覆盖
```
关键：**动作对齐（v31）→ 接触可信（SCT）→ 场景被认证覆盖且姿态坐标可信（SPACE）**，任一环失守都只允许拒证/降级/制动，不允许用“场景在仿真里成功”或“姿态看起来很稳”替代“交互点被证书覆盖”。

## 5. 本轮最大风险

**一句话**：SCT 把“语义标签”变成接触约束，SPACE 又把“场景覆盖与姿态坐标”叠在接触约束之上，整条链因此多了一层最隐蔽的循环信任——**用姿态估计去定义场景、用场景去评估姿态模型的覆盖**；一旦自遮挡/接触遮挡使姿态在接触点附近多峰且偏置，`δ_pose` 会低估真实接触位移，CPR 会在错误坐标里“保持接触”，SPI 还会主动把场景推到姿态模型的盲区，最终让“覆盖提升”只是姿态地图的自我印证，故必须以 **多峰可信集 + 接触条件校准 + 触觉/本体锚定 + 跨构型留出** 四重护栏，宁可对姿态证据不足的场景拒证，也绝不把“姿态高置信”当作“接触几何已证实”。
