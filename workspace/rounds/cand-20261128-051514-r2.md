### 第 6 轮灵感驱动研究记录

**灵感词**：隐私保护、价值对齐

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）以「认证的生成式执行」（CGE）把提议器升级为条件流匹配、记忆升级为嵌入+固化、人因升级为面部情感调制，并用定理 5~8 证明「提议可换、门不可换」。但 v5 留下三笔明确负债：(a) 舰队联邦与跨站价值/情绪异构被推迟到本轮；(b) 加性价值假设 (B4) 未解决，而它正是 R57「固化自指博弈」的数学根源；(c) 隐私（R56）只是端侧即用即弃的工程承诺，没有可核算、可组合、可审计的形式保证。本轮两个灵感词恰好对准这三笔债，统一为主题「可验证隐私-价值对齐」（Verifiable Privacy-Value Alignment, VPVA），形成 CADVS-v6（IP-497~500）。本轮自律：**安全硬门仍为七道，不增不减**；隐私与价值不进入安全锚点集合，而是分别落在「证据发布层」与「价值排序层」两个元约束上，执行集嵌套升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **隐私保护 → 从「每次发布加点噪声」升级为「不可再生预算 + 组合硬停」**。工程直觉是：每个上报都过 DP 就安全了。这是错的——DP 的组合性意味着 k 次发布后预算线性（RDP 下可加）累积，单次安全 ≠ 累计安全；而联邦恰恰是长期、高频、多轮发布。v6 引入 PPAK：每站维护 RDP 账本，每次发布前预扣预算，超预算即 fail-closed 停止发布（而非停止动作），系统退化为「仅本地 v5」。关键区分：**隐私的 fail-closed 关闭的是「发布通道」，不是「执行通道」**——安全执行集不因隐私预算耗尽而扩大或缩小，只有可发布证据集 Rel 收缩。这把隐私从一句合规口号变成与安全证书并列的、可审计的资源约束。

2. **价值对齐 → 从「加性标量价值」升级为「冻结宪法层 + 词典序 + 重叠共识」**。v5 的 VACK 假设价值可加 (B4)，于是策略天然学会用「任务收益」去换「安全/隐私边际」——这正是 R57 价值博弈的数学根源：可加即可交易。v6 的 CVOK 把价值拆成两层：**宪法层**是人工批准、冻结只读的词典序硬约束（安全 ≻ 隐私 ≻ 人类自主 ≻ 任务效用），高层优先级不可被低层收益补偿；**偏好层**才是可在线学习的软排序，且只能在宪法层内部微调。跨站异构用罗尔斯的「重叠共识」处理：全局只强制执行所有站点宪法约束的交集 C* = ∩_i C_i，分歧项不平均、不投票压服，而是留在本地或升级给人审。定理 10 证明词典序消除「以低换高」，定理 11 证明重叠共识对每站都 sound（全局可行 ⇒ 每站可接受）。

3. **两个词的协同 → 对齐所需的偏好数据本身是隐私，隐私又需要对齐来界定「谁能看什么」**。价值对齐离不开人类偏好反馈，而偏好是最敏感的个人数据；若为对齐而集中收集偏好，就直接违背隐私。v6 用 PPAL 做「隐私保护的对齐学习」：本地 DP 偏好学习 + 安全聚合/隐私集合求交只计算共识，不共享原始偏好。代价是 DP 噪声使价值序估计有误差，产生「对齐税」——定理 12 给出税的上界，并诚实声明：有限隐私预算下对齐税恒为正，没有免费午餐。

**关键洞见**：v5 回答「提议任意化时，证书边界如何不变」；v6 回答「在异构舰队里，这条边界如何既**正当**（价值对齐）又**可发布**（隐私可核算）」。安全门是信任边界，**宪法价值序是第二道信任边界**——两者都冻结只读，可学习的只有提议器与偏好软排序。这把 v5 的「门 vs 提议器」二分推广为「双信任边界 + 双学习层」。

**形式化目标（增量）**：
1. RDP 账本：发布机制族 {M_r}，α-阶 RDP 消耗 ε_r(α)，组合 ε_tot(α)=Σε_r(α)，折算 (ε,δ)-DP；预算 B_priv，发布算子 Rel 满足 ε_{t+1} ≤ B_priv 才放行。
2. 词典序价值：价值向量 u(x)=(u_S,u_P,u_A,u_T)，x ≻_lex y 按首个不同坐标比较；宪法层约束 C_i 为不可交易硬约束。
3. 重叠共识：C* = ∩_i C_i；VOK(x)=1[x ⊨ C*]；C*=∅ 时禁止强制全局动作，升级/分区。
4. DP 偏好学习：Bradley-Terry + DP-SGD/标签随机化；序估计误差界；对齐税 τ_align。
5. EFA-v6：七门不变 → CVOK 价值过滤 → PPAK 发布门；不确定时 abstain 升级人审；ECS_v6 = ECS_v5 · η_align。
6. Exec_v6 = {x ∈ Exec_v5 : x ⊨ C* ∧ s_pref(x) ≥ τ_pref} ⊆ Exec_v5；Rel_v6 受 B_priv 约束且随消耗单调缩。

**本轮最大风险**：**重叠共识的双向陷阱**——站点分歧大时 C* 退化为空集或最小公分母，执行集塌缩为「几乎不做」；而工程压力又诱使把分歧项伪装成共识（共识膨胀/价值洗白），两者都让「对齐」变成自欺。

## 2. 关键算法骨架

### IP-497 PPAK：隐私预算账本与发布硬停（联邦边界，非控制环）

```python
@dataclass
class PrivacyPreservingAccountingKernel:
    """PPAK：RDP 账本 + 发布硬停。
    红线：隐私 fail-closed 关闭发布通道，不关闭执行通道"""
    B_priv: float = 8.0            # 每站总预算（目标 δ=1e-5）
    delta: float = 1e-5
    orders: tuple = (2, 4, 8, 16, 32, 64)
    spent: dict = field(default_factory=lambda: {a: 0.0 for a in (2, 4, 8, 16, 32, 64)})

    def _eps_total(self, extra: dict) -> float:
        # RDP 组合 + 折算到 (eps, delta)-DP；extra 为本次拟发布增量
        eps_rdp = {a: self.spent[a] + extra.get(a, 0.0) for a in self.orders}
        return min(e + math.log(1.0 / self.delta) / (a - 1.0)
                   for a, e in eps_rdp.items())

    def can_release(self, mech: 'ReleaseMechanism') -> bool:
        return self._eps_total(mech.rdp()) <= self.B_priv   # 先预扣判定，后发布

    def release(self, mech: 'ReleaseMechanism', payload):
        if not self.can_release(mech):
            return None, 'PRIVACY_BUDGET_EXHAUSTED'          # fail-closed：仅停发布
        self.spent = {a: self.spent[a] + mech.rdp()[a] for a in self.orders}
        return mech.apply(payload), 'RELEASED'

    def degrade(self) -> str:
        return 'LOCAL_ONLY_V5'   # 预算耗尽：停止联邦发布，本地 v5 继续执行
```

### IP-498 CVOK：宪法价值序 + 重叠共识（每周期/人审时域）

```python
@dataclass
class ConstitutionalValueOrderingKernel:
    """CVOK：冻结宪法层（词典序）+ 可学习偏好层 + 重叠共识。
    红线：宪法层人工批准、冻结只读；策略与固化永不修改 C_i 或 ≻_lex"""
    constitution: tuple            # (('S',τ_S),('P',τ_P),('A',τ_A),('T',τ_T)) 词典序
    site_constraints: dict         # {site_id: C_i}，均来自各站人工批准
    tau_pref: float = 0.5
    b_align: float = 0.0

    def consensus(self) -> 'ConstraintSet':
        # 只算交集：PSI / 安全多方求交，不暴露各站完整 C_i
        return reduce(intersect, self.site_constraints.values())

    def value_ok(self, x) -> bool:
        C = self.consensus()
        if C.is_empty:
            return False                     # 空共识：禁止强制任何全局动作
        return C.satisfied_by(x)             # x ⊨ C*

    def lex_compare(self, x, y) -> int:
        for d in ('S', 'P', 'A', 'T'):       # 高层不可被低层补偿
            if u(x, d) != u(y, d):
                return 1 if u(x, d) > u(y, d) else -1
        return 0

    def eta_align(self, s_pref: float) -> float:
        return sigmoid(s_pref - self.b_align)
```

### IP-500 EFA-v6：七硬门 + 价值过滤 + 发布门（动作/发布双通道）

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：七硬门不变；CVOK 价值过滤；PPAK 发布门。
    Exec_v6 ⊆ Exec_v5；隐私预算只影响 Rel_v6，不影响 Exec_v6"""
    v5: EvidenceForgingAssemblerV5
    cvok: ConstitutionalValueOrderingKernel
    ppak: PrivacyPreservingAccountingKernel
    ppal: PrivacyPreservingAlignmentLearning

    def select(self, x0_state, t_now, rule_id, context):
        ok, x, tag = self.v5.select(x0_state, t_now, rule_id, context)
        if not ok:
            return False, None, tag
        # 价值过滤：宪法共识 + 偏好软排序；不确定则 abstain 升级人审
        if not self.cvok.value_ok(x):
            return False, None, 'VALUE_CONSTITUTION_REJECT'   # fail-closed
        s_pref = self.ppal.score(x, context)
        if s_pref < self.cvok.tau_pref:
            return False, None, 'ABSTAIN_ESCALATE_HUMAN'
        return True, x, 'FORGED_VPVA'

    def release_evidence(self, cert, mech):
        # 动作已本地执行；这里只决定证据能否出站
        payload, tag = self.ppak.release(mech, cert)
        return payload, tag        # 'PRIVACY_BUDGET_EXHAUSTED' 时本地留存

    def ecs_v6(self, *args, s_pref: float, **kwargs) -> float:
        return self.v5.ecs_v5(*args, **kwargs) * self.cvok.eta_align(s_pref)
```

### IP-491 扩展 CERTCALC-v6：新增定理 9~12（离线理论）

```python
# 定理 9：隐私组合与发布硬停
def theorem_privacy_composition_stop() -> str:
    """
    定理 9（隐私组合与硬停）：若每次发布 M_r 为 (α, ε_r(α))-RDP，且发布门只依据
    与数据无关的账本消耗做停止决策，则累计发布满足 (ε(δ), δ)-DP，
    ε(δ)=min_α[Σε_r(α)+log(1/δ)/(α−1)]；一旦 ε(δ)>B_priv，Rel 停止发布，
    后续零额外泄漏，而本地执行不受影响。
    证明：RDP 组合定理 + 后处理不变性；停止时间仅依赖预算账本（数据无关），
    故自适应组合仍成立。∎
    """
    return "Proven"

# 定理 10：词典序不可交易性
def theorem_lexicographic_nontradeable() -> str:
    """
    定理 10（词典序不可交易）：宪法层取词典序 S ≻ P ≻ A ≻ T 且高层为硬约束，
    则对任意可行 x,y，不存在用低层收益补偿高层损失而仍被选中的情形；
    价值过滤只删不增，故 Exec_v6 ⊆ Exec_v5。
    证明：词典序按首个不同坐标比较，低层坐标在高层次不同时不参与比较；
    过滤谓词为合取，删除元素不扩大集合。∎
    工程含义：以「任务成功」换「隐私/安全」在结构上不可能，R57 的价值交易通道被关闭。
    """
    return "Proven"

# 定理 11：重叠共识的 soundness / 空集不可能性
def theorem_overlapping_consensus() -> str:
    """
    定理 11（重叠共识）：设各站宪法约束 C_i，全局 C*=∩_i C_i。
    (i) soundness：x ⊨ C* ⇒ 对所有 i，x ⊨ C_i（全局可行即每站可接受）；
    (ii) 空集不可能性：若 C*=∅，则不存在非空的全局可接受动作集，
         任何全局强制动作必违反某站宪法——此时必须升级人审或分区，禁止投票平均。
    证明：(i) 交集是每站的子集；(ii) 空交集意味着对任意 x 存在 i 使 x∉C_i。∎
    """
    return "Proven"

# 定理 12：对齐税与隐私-对齐张力
def theorem_alignment_tax() -> str:
    """
    定理 12（对齐税）：设偏好序估计误差 Δ_ord，价值 Lipschitz 常数 L_u，
    则对齐税 τ_align ≤ L_u·Δ_ord；对 DP 偏好学习，
    Δ_ord = O(L·(1/√n + √(d·log(1/δ))/(n·ε)))。
    故有限 ε 下 τ_align>0 恒成立，仅当 ε→∞ 或 n→∞ 时趋于 0。
    证明：DP 噪声的集中不等式给出序估计误差；价值函数 Lipschitz 传播到损失。∎
    诚实边界：无隐私代价的完美对齐不存在；τ_align 是必须显式计入预算的项。
    """
    return "Proven (upper bound); tightness empirical"
```

### 集成流水线（v5 → v6）

```
离线/慢时域（价值与隐私）：
  宪法批准（人工）：各站人工批准 C_i 与词典序 ≻_lex ──▶ 冻结只读
  共识计算：PSI/安全聚合 C* = ∩ C_i ──▶ 广播 C*（不暴露各站完整约束）
  偏好学习：本地 Bradley-Terry + DP-SGD ──▶ 软排序摘要 ──▶ DP-FedAvg（受 PPAK 预扣）
  预算审计：RDP 账本 ──▶ 若 ε(δ) 接近 B_priv ──▶ 降频/停止发布（本地 v5 继续）

                              └─是─▶ 本地执行（Exec_v6）
  执行后：cert ──▶ PPAK.can_release ──否──▶ 本地留存（PRIVACY_BUDGET_EXHAUSTED）
                              └─是─▶ 发布（Rel_v6）

在线控制环（目标 < 0.6 ms，不变）：
  EEK(kc_ee) + BCK 事件触发（缓存证书 + 边际内插），隐私/价值均在环外预计算
```

## 4. 正确性论证（增量更新）

### 引理 45（RDP 到 (ε,δ)-DP 的折算）

**陈述**：若机制族满足 α-阶 RDP 总消耗 ε_tot(α)，则对任意 δ∈(0,1)，满足 (ε(δ),δ)-DP，其中 ε(δ)=min_α[ε_tot(α)+log(1/δ)/(α−1)]。∎

### 定理 9（隐私组合与发布硬停）

**陈述**：每次发布 M_r 为 (α,ε_r(α))-RDP，发布门仅依据数据无关账本停止，则累计满足 (ε(δ),δ)-DP；超预算即停止发布，后续零额外泄漏，本地执行不变。

**证明**：RDP 组合给出 ε_tot(α)=Σε_r(α)，引理 45 折算；停止决策只依赖账本（数据无关），故为合法停止时间，自适应组合仍成立；停止后不再有发布机制作用，后处理不变性给出零额外泄漏。∎

### 定理 10（词典序不可交易性）

**陈述**：宪法层词典序 S ≻ P ≻ A ≻ T 且高层为硬约束，则不存在以低层收益补偿高层损失而被选中的可行动作；且 Exec_v6 ⊆ Exec_v5。

**证明**：词典序在首个不同坐标即定序，低层坐标不参与补偿；价值过滤 `value_ok ∧ s_pref ≥ τ_pref` 是合取谓词，只会从 Exec_v5 中删除元素。∎

**工程含义**：R57 的「以任务收益换安全/隐私边际」交易通道在结构上被关闭，价值博弈失去可加标量这一支点。

### 定理 11（重叠共识的 soundness 与空集不可能性）

**陈述**：C*=∩_i C_i。(i) x ⊨ C* ⇒ ∀i, x ⊨ C_i；(ii) C*=∅ ⇒ 无非空全局可接受动作集，任何全局强制动作必违反某站宪法。

**证明**：(i) 交集是每个 C_i 的子集；(ii) 若 C*=∅，对任意 x 存在 i 使 x∉C_i。∎

**诚实边界**：定理只保证「不违反」，不保证「共识足够大」。共识规模随异构度单调不增；工程压力下的「共识膨胀」无法由数学阻止，只能靠冻结的宪法批准流程与审计。

### 定理 12（对齐税）

**陈述**：τ_align ≤ L_u·Δ_ord，Δ_ord = O(L·(1/√n + √(d·log(1/δ))/(n·ε)))；有限 ε 下 τ_align>0。

**证明**：DP 噪声的集中不等式给出成对偏好序估计误差；价值函数 L_u-Lipschitz 将其传播为价值损失。∎

**诚实边界**：这是上界而非紧界；真实对齐税依赖偏好分布与噪声实现，需实测。无隐私代价的完美对齐在形式上不存在。

### 定理 v6（双信任边界总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 宪法层人工批准且冻结、(B9) 发布门仅依赖数据无关账本下：
(i) Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29；
(ii) 价值 soundness：Exec_v6 中每个动作满足每站宪法（定理 11）；
(iii) 价值不可交易：不存在以低层补偿高层的可行选择（定理 10）；
(iv) 隐私 soundness：所有发布累计满足 (ε(δ),δ)-DP 且 ε(δ) ≤ B_priv（定理 9）；
(v) 双通道 fail-closed：价值不确定 → abstain 升级人审；预算耗尽 → 停发布、保执行；
(vi) 对齐税由定理 12 界定，且随 B_priv 增大而下降。

**证明**：(i)(ii)(iii) 由定理 10/11 与合取过滤；(iv) 由定理 9；(v) 由 EFA-v6 两处显式分支；(vi) 由定理 12。∎

**诚实声明**：(B8) 宪法的正当性来自人工批准流程而非数学——谁写宪法、权力是否对称，是治理问题不是定理能解决的；(ii) 重叠共识可能空集或退化为最小公分母（本轮最大风险）；(iii) 对齐税恒正，隐私与对齐存在不可消除的张力；(iv) DP 保护的是发布通道，不保护端侧本地记忆被物理攻破；(v) v5 的加性价值假设 B4 在本轮被词典序替代，但「词典序本身是否正当」继承为新的开放问题。

## 5. 实验设计与初步结果（仿真；多站联邦，实机列入第 7 轮）

### 5.1 实验设计

- **平台**：5 个仿真站点，价值序异构（安全优先 / 隐私优先 / 自主优先 / 任务优先 / 混合）；每站 10k 本地片段；MuJoCo + MJX；FER 与流提议沿用 v5。
- **对照**：v5-full（加性价值、无预算核算）、v6-full、消融 B1（v6 去 PPAK，仅逐次加噪）、B2（v6 去 CVOK，回到加性价值）、B3（共识用投票平均替代交集）、B4（DP 偏好学习无预算预扣）、B5（价值序在线可学——预期被博弈）。
- **场景**：(a) 跨站价值冲突任务（隐私 vs 任务成功）；(b) 100 轮联邦发布（预算累积与硬停）；(c) 成员推断攻击（MIA）审计；(d) 红队价值博弈（诱导以任务换隐私/安全）；(e) 共识规模随异构度扫描；(f) 对齐税测量（DP 前后价值损失）。
- **指标**：跨站价值违例率、隐私预算超支事件数、MIA AUC、共识约束数、abstain 率、对齐税（任务效用损失 %）、门博弈通过率、控制环 P99、执行集收缩比。

## 7. 本轮最大风险（最终确认）

**一句话**：**重叠共识的双向陷阱**——站点分歧大时 C* 退化为空集或最小公分母，执行集塌缩为「几乎不做」；而工程压力又诱使把分歧项伪装成共识（共识膨胀/价值洗白），两者都让「对齐」变成自欺。
