# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~302；灵感循环第 2 轮；本轮灵感：「分布外泛化」×「参数高效微调」）

> R73 用「契约 + 组合 + 证书」把具身证据计量做成了可组合的代数，并给出了 J_MOD 组合证书与热替换定理。但 R73 的体系有两处**根上的隐含前提**，恰好就是它自己在结尾承认的最大风险：
> - **分布前提被隐藏**：conformal 覆盖率、SEAL 校准、J_MOD 的有效性全部默认「校准分布 = 部署分布」的可交换性。真实部署里光照、材质、相机型号、本体磨损、任务分布都会漂移；漂移一旦发生，证书**不会报错**，只会**静默地给出错误的覆盖**。R73 说「证明重量落在契约表达力上」，本轮要把这句话变成一个**可计量的移位向量**，而不是一句免责声明。
> - **学习参数是黑箱**：material_net、IRL 意图网、AURA 情感网、深度噪声校准都是学出来的。R73 的热替换定理只处理「同契约换实现」，却不处理「同模块适应新域」。全量重训昂贵且让证书作废；朴素微调便宜但**没有证书**——它甚至可能为了目标域牺牲源域，制造一个更隐蔽的 OOD 失效。
>
> 本轮两个灵感正好补两块：
> - **分布外泛化** → **SDA（Shift Detection & Attribution）+ SBC（Shift-Bounded Conformal）+ SHA（Shift Algebra）**：把「漂移」变成逐模块、逐噪声分量的**移位向量 ε⃗**；把覆盖率退化写成 `coverage ≥ 1−α−Δ(ε)`（TV 距离下 Δ(ε)=ε，干净可证）；把 ε 沿 SER/PAR/VETO 组合成单调代数，使「组合不会凭空恢复覆盖」成为定理。
> - **参数高效微调** → **CAP（Conformal Adaptation with few Parameters）+ CBA（Certificate-Bounded Adaptation）+ χ_A（适应反作用通道）**：把 PEFT 的「低维」下移到**校准层**——只学 d_φ 维非一致性分数修正 `s_φ=s_0+φᵀg`，于是少样本即可完成可证适应；把神经模块的 LoRA/Adapter 更新约束在**证书球** B_η 内（`δ_f≤L·η`），球内膨胀证书、球外强制再校准；适配本身作为一种动作进入 ΣREFLEX 预算。
>
> 核心命题：**不再问「证书在训练分布上是否有效」，而问「证书能否在分布漂移下被显式计量、在低维自适应下被保持，并让『适应还是重校准』成为一条由证书漂移自动触发的策略？」** 把 R73 的计量契约代数重构为 **PACE-GAUGE-RAS**（Parameter-efficient Adaptation with Certified Evidence）——**可证适应计量学**。

## 0. 直觉与动机

**灵感 1（分布外泛化 → 覆盖率是分布的函数，不是一个常数）**
直觉：conformal prediction 的 `1−α` 是一句「在可交换性下成立」的话。论文里它常被当成产品保修条款，但它的适用域和训练分布绑死。机器人现场有三类漂移：**(a) 协变量漂移**（换了相机/光照/材质，p(x) 变、p(y|x) 不变）；**(b) 标签/概念漂移**（同一意图在不同人身上语义变，p(y|x) 变）；**(c) 支持漂移**（出现校准集里根本没有的材质类别或接触模式）。三者的可证性完全不同：(a) 在密度比可估时可用加权 conformal 修补；(b) 只有在有目标标签时才可修；(c) **原则上不可修**——这是本轮的诚实边界。R73 的 `b_t(m)` 只有五类材质，真实材质是连续谱，这正是「契约表达力」的具体形态。因此第一个组件必须是 **SDA**：不只说「OOD 了」，还要说**漂移在哪**（哪个模块、哪个噪声分量、是否共因），因为归因决定了该「局部再校准」还是「整模块 stub」。

**灵感 2（参数高效微调 → 低维 = 少样本 = 可证的统计效率）**
直觉：LoRA 的卖点不是省显存，而是**用极少的自由度承载一个领域偏移**。统计学习理论里，假设类的有效自由度直接决定泛化界（`gap ~ sqrt(d/n)`）。把这两件事接起来：如果校准层的领域修正只允许 d_φ 个参数（`φ∈R^{d_φ}`），那么目标域需要的标注样本 `n_t` 只需 `O(d_φ)` 量级，而不是全模型的 `O(d_model)`。于是「参数高效」被翻译成「**认证高效**」——这正是 C3/C4 想要的可证伪收益。更激进也更漂亮的一步：把 PEFT 作用在**非一致性分数**上而不是网络权重上，得到 **CAP**：`s_φ(x,y)=s_0(x,y)+φᵀg(x,y)`，用目标域小样本做分位数匹配。它是「校准器也可以被参数高效微调」——目前几乎没有工作这样组织 conformal。

**灵感 3（把适配当动作 → 适配也有反作用与攻击面）**
直觉：在线适配会改变模型噪声与有效域，进而改变证据质量与下游决策。若不在契约里记账，就会出现「**越适应越不安全，且审计看不见**」。所以适配必须：进入 ΣREFLEX 预算（χ_A 通道）、受证书球约束（超球即拒）、并对**投毒适配数据**有防御（对手供给的目标样本可以把低维修正引向危险区域）。低维在这里是双刃剑：它让证书紧，也让对手**只需操纵少数几个方向**就能劫持适配。这条风险会写进本轮最大风险。

**灵感 4（移位代数 → 组合律必须与不确定度代数同构）**
直觉：R73 已经证明「组合不产生认知免费午餐」（引理 34）。移位必须继承同样的姿态：SER 只能让 ε 增（串联漂移叠加）；PAR 只有在**跨模态移位独立**时才允许缩窄（若两模态被同一温度/光照共因驱动，融合不能抵消漂移）；VETO 在 `ε_i>ε_i^max` 时直接否决。这样「OOD 泛化」就不是一个模型属性，而是模块图上的一个**单调代数量**，可以在 MReg 每轮审计。

**灵感 5（主张蒸馏 → 第四条可证伪主张 C4，而不是无限扩张）**
直觉：R73 的 CPB 用 C1/C2/C3 三条主张守住了「不是工程堆叠」的底线。本轮若只是加模块，会立刻退回堆叠。因此新增**恰好一条** C4：「**低维可证适应**——在移位界内，CAP/CBA 比全量重校准省一个量级的认证与标注成本，同时比朴素 PEFT 多一个可证覆盖下界」。C1–C3 继承，C4 必须被隔离消融。凡是不能绑定 C1–C4 的组件，一律工程附件。

## 1. 形式化定义（增量：定义 383–392）

**定义 383（PACE-GAUGE-RAS 总览与六不变式）** PACE-GAUGE-RAS = (MODGAUGE-RAS†, SDA, SBC, CAP, CBA, SHA, χ_A)。六不变式：
(i) **移位可归因**：每次部署必须产出逐模块移位向量 ε⃗（定义 384），不可只给全局 OOD 分数；
(ii) **移位单调组合**：所有跨模块移位经 SHA（定义 389）组合，ε 只增不减，无「融合后覆盖变好」路径；
(iii) **适配在证书球内**：任何在线参数更新必须满足 `δ_f≤η_ball`（定义 387），否则触发再校准或 stub；
(iv) **再校准触发确定性**：证书漂移 `g_cert` 越过带迟滞的阈值 γ 即确定性触发（定义 388），禁止抖动振荡；
(v) **主张绑定**：每个组件 ∈ {C1,C2,C3,C4, 工程附件}（定义 392），附件不进 MReg、不进正文；
(vi) **严格退化**：令 ε=0、Δθ=0、SDA=id、CAP=∅，则 PACE 逐指令等于 MODGAUGE，再退化等于 R72/R71/R68。

**定义 384（移位向量与归因 SDA）** 设校准分布 P_0（SEAL）与部署分布 P_t。移位向量
ε⃗ = (ε_1, …, ε_M; ε_cc)，
其中 ε_i 是第 i 个模块证据条件分布的 TV 距离上界，`ε_cc` 是环境共因（温度/振动/光照）分量。归因映射 `A:(D_0,D_t)↦ε⃗` 由三个子检测器给出：**协变量检测**（输入/证据边缘分布的两样本检验）、**残差检测**（同输入下预测残差漂移）、**支持检测**（新类/新材质在 b_t(m) 的未知类质量）。总移位 `ε_tot=⊕_i ε_i`（⊕ 见定义 389）。**归因的价值**：若漂移集中在 `u_material`，只需 CAP 局部修正；若 `ε_cc` 高，禁用 PAR 缩窄并对共因模块联合再校准。

**定义 385（移位约束 conformal SBC）** 若 `TV(P_0,P_t)≤ε`，则对任意 conformal 事件 E 有 `|P_t(E)−P_0(E)|≤ε`，故
`P_t(Y∈C_α(X)) ≥ 1−α−Δ(ε)`，取 `Δ(ε)=ε`（TV 的干净上界）。
当可估密度比 `w=dP_t/dP_0` 且有界 `1/B≤w≤B` 时，用加权 conformal 可把 Δ(ε) 收紧为 `Δ_w(ε)`，但需额外记账权重估计误差 ρ_w。**SBC 输出三元组** (C_α, Δ, ρ_w)，进入契约的 `u_shift` 字段。

**定义 386（低维校准适配器 CAP）** 非一致性分数加低维修正：
`s_φ(x,y) = s_0(x,y) + Σ_{j=1}^{d_φ} φ_j g_j(x,y)`，`d_φ ≪ n_t`。
用目标域小样本 `{(x_k,y_k)}_{k=1}^{n_t}`（或仅用其分位数约束）拟合 φ，使目标域经验分位数匹配 `1−α−Δ`。产出 `C_α^φ` 与**有效样本量** `n_eff(d_φ)`。CAP 的可证效率：对 `β` 的目标宽度差，所需 `n_t = O(d_φ log(1/β)/β²)`；全模型适配需 `n_t = O(d_model log(1/β)/β²)`。**CAP 是「校准层的 PEFT」**。

**定义 387（证书球与 PEFT 安全适配 CBA）** 模块证据映射 `f_θ:X→E`。PEFT 更新 `θ'=θ+UVᵀ`，`rank(UVᵀ)=r`，`‖UVᵀ‖₂≤η`。功能漂移 `δ_f(θ,θ')=sup_x‖f_{θ'}(x)−f_θ(x)‖≤L_f·η`。**证书球** `B_η={θ': δ_f≤η_ball}`。球内：把 conformal 分位数膨胀 `δ_f`（即用 `q_{1−α}+δ_f`），覆盖仍成立；球外：必须走再校准。**CBA 是「模型层的 PEFT」**。与 CAP 的分工：CAP 修分数统计，CBA 修特征映射；二者可串联，漂移按 SER 叠加。

**定义 388（证书漂移与再校准触发）** 证书漂移
`g_cert = max_k |bound_k(θ',P_t) − bound_k(θ,P_0)|`
（k 遍历退化链、风险单调、覆盖、时序隔离四类性质）。触发策略
`π_adapt ∈ {HOLD, PEFT, RECAL, STUB}`：
`g_cert≤γ_lo ⇒ HOLD/PEFT`；`γ_lo<g_cert≤γ_hi ⇒ RECAL`；`g_cert>γ_hi 或归因失败 ⇒ STUB`。
迟滞带 `[γ_lo,γ_hi]` 保证确定性且无振荡。

**定义 389（移位代数 SHA）** 在 CCA 上增加移位分量：
- **SER（A∘B）**：`ε_out ≥ ε_A ⊕ ε_B`，`⊕` 为单调上界（取 `max` 或 `ε_A+ε_B+L·ε_A` 的保守式）；有效域 `D_out=D_A∩D_B` 再按 ε 收缩。
- **PAR（A⊕B 融合）**：仅当跨模态移位**独立**（`ρ_ε≈0` 且无共因）且一致性审计通过才允许缩窄；否则 `Δ_out=max(Δ_A,Δ_B)` 且禁用缩窄；`ε_cc` 高时直接退保守。
- **VETO**：若任一模态 `ε_i>ε_i^max`，整体否决（非补偿）。
**移位下界（引理 41）**：不存在「组合后 ε 低于所有输入且通过审计」的路径。

**定义 390（适应反作用通道 χ_A）** 适配是动作：`χ_A: Δθ ↦ (Θ_noise′, D′, c_adapt)`。它声明「我的更新如何移动噪声参数与有效域」，成本 `c_adapt` 计入 ΣREFLEX 总预算：`Σ_t Σ_i (c_reflex^i + c_adapt^i) ≤ B_total`。**适配不能逃出反作用预算**——否则「用适配换安全」会变成不记账的透支。

**定义 391（OOD 威胁面 AIC-SHIFT）** 在 R73 深度威胁面上新增：**渐进漂移攻击**（缓慢改变光照/温度使 OOD 分数长期低位）、**适配投毒**（供给精心构造的目标样本，把低维 φ 引向危险子空间）、**共因致盲**（同时驱动多模态使 PAR 一致性审计误判为「独立」）、**支持逃逸**（制造校准集外的新材质/新模式使 Δ(ε) 失去意义）。防线：锚定适配（外部基准只用本体/接触/已知几何）、数据来源证明、证书球硬约束、`ε_cc` 第三方独立测量、支持检测触发 stub。

**定义 392（C4 主张绑定 CPB†）** 绑定表扩展为四条：
- **C1（继承）** 物理感知证据计量 ← (DPEM, DMEM†) ← MB1 ← AB1 ← (ECE, 覆盖率, 碰撞率, 误抓率)；
- **C2（继承）** 反作用预算组合 ← (ΣREFLEX, ERVOI†, PVOP) ← MB2 ← AB2 ← (交互次数, 人类负担, 停止方差)；
- **C3（继承）** 契约式模块化 ← (MMS, CCA, J_MOD) ← MB3 ← AB3 ← (逐指令等价, 认证成本比, 迁移行数)；
- **C4（新增，可证适应）** ← (SDA, SBC, CAP, CBA, SHA) ← MB4（OOD 适配基准）← AB4（CAP/CBA vs 全量重校准 vs 朴素 LoRA vs 不适配）← (覆盖缺口, 目标样本效率, 认证成本比, 安全违例率)。
非绑定组件 = 工程附件。

## 2. 关键算法骨架

```python
# IP-303 SDA：移位检测与归因（计量域 5Hz，独立于主闭环）
class ShiftAttributor:
    def update(self, sealed_stats, live_batch, common_cause):
        eps = {}
        for mod, st in seald_stats.items():
            cov  = two_sample_tv(live_batch[mod].x, st.x)        # 协变量漂移
            res  = residual_shift(live_batch[mod].y, st.y)       # 残差漂移
            sup  = support_novelty(live_batch[mod].x, st.x)      # 支持逃逸
            eps[mod] = max(cov, res, sup)                        # TV 上界（保守）
        eps['cc'] = common_cause_shift(common_cause)             # 温度/振动/光照
        return ShiftVector(eps, total=sha_fold(eps.values()))

# IP-304/305 SBC + CAP：移位约束 conformal + 低维校准适配
def shift_bounded_conformal(s0, g_feats, src_cal, tgt_sample, alpha, d_phi):
    phi = fit_lowrank_quantile(s0, g_feats, tgt_sample, alpha, d_phi)  # 只需 n_t=O(d_phi)
    eps = attributor.total
    delta = eps                                              # TV 下界退化（定义 385）
    q_phi = empirical_quantile([s0(x,y)+phi@g(x,y) for (x,y) in src_cal+tgt_sample],
                               1 - alpha - delta)
    n_eff = effective_sample_size(src_cal, tgt_sample, d_phi)  # 低维 → n_eff 高
    return ConformalSet(q_phi, delta=delta, n_eff=n_eff, phi=phi)

# IP-306 CBA：证书球内 PEFT（模型层）
def certificate_bounded_peft(module, target_batch, eta_ball, L_f):
    delta_theta = lora_step(module, target_batch)             # 只更新低秩 UV^T
    eta = spectral_norm(delta_theta)
    delta_f = L_f * eta                                       # Lipschitz 功能漂移界
    if delta_f > eta_ball:                                    # 出球 → 拒绝在线更新
        return module, 'RECAL_REQUIRED'
    module = apply_update(module, delta_theta)
    module.cert.inflate_conformal(delta_f)                    # 膨胀而非作废证书
    return module, 'PEFT_OK'

# IP-307 SHA：移位代数（与 CCA 同构）
def sha_compose(e_a, e_b, op):
    if op == 'SER':  return max(e_a, e_b)                     # 串联只能更差
    if op == 'PAR':  return e_a if abs(e_a.rho_b) < RHO_EPS else max(e_a, e_b)
    if op == 'VETO': return float('inf') if max(e_a, e_b) > E_MAX else min(e_a, e_b)

# IP-308 χ_A + 策略：适配反作用与再校准触发（迟滞）
def adaptation_policy(mods, g_cert, gamma_lo, gamma_hi, budget):
    if g_cert <= gamma_lo:      return 'PEFT', mods
    if g_cert <= gamma_hi:      return 'RECAL', mods            # 确定性触发
    return 'STUB', [stub(m) for m in mods]

# IP-309 PACE 主闭环（在 MODGAUGE 上插入三处，核心零改动）
def PACE_round(M, obs, audio, tac_frame, depth_img):
    eps = M.sda.update(M.seal_stats, M.live, M.common_cause)    # 每 5Hz
    d_ev = M.dpe.update(depth_img, rgb, M.cam_state, M.motion, M.peers)
    d_ev = M.sbc.attach(d_ev, eps['dpe'])                       # 覆盖率退化进契约
    t_ev = M.dmem.update(tac_frame, M.last_action)
    b_t  = M.bse.step_full(..., d_ev=d_ev, t_ev=t_ev)
    # 证书漂移 → 适配策略（HOLD/PEFT/RECAL/STUB）
    g_cert = M.cert_drift.estimate(b_t, eps)
    pi, mods = adaptation_policy(M.mods, g_cert, M.g_lo, M.g_hi, M.budget)
    if pi == 'RECAL': M.recal.schedule(mods)                    # 慢环，异步
    M.mreg.audit(eps)                                           # 组合合法性 + 移位单调
    k, lam = MODGAUGE_control_step(M, b_t)                      # 控制域完全不变
    return k, lam, J_PACE(M.mreg, eps, g_cert)                  # 组合证书（含移位/漂移）
```

## 3. 推导

**引理 38（移位下覆盖率退化）** 设 `TV(P_0,P_t)≤ε`。对任意 conformal 事件 E，`P_t(E)≥P_0(E)−ε`，故 `coverage_{P_t}≥1−α−ε`；且 Δ 单调、`Δ(0)=0`。系：**OOD 不会静默保留覆盖——覆盖是分布的函数，必须被显式记账**；支持漂移（P_t 在 P_0 支撑外）时 ε=1，界退化为平凡，必须 stub，这是诚实的边界。

**引理 39（低维适配的样本效率）** CAP 的分数类自由度 `d_φ`，在 `g` 有界与目标样本可交换下，经验分位数的一致偏差 `≤ O(sqrt(d_φ log(n_t/δ)/n_t))`（覆盖数论证）。故达到宽度差 β 需 `n_t=O(d_φ log(1/β)/β²)`；全模型适配 `d_model≫d_φ` 需 `n_t=O(d_model log(1/β)/β²)`。系：**PEFT 的「低维」直接兑换为「少目标样本 + 紧证书」——这是 C4 的核心可证伪点**。

**引理 40（证书球内适配的安全保持）** 若 `δ_f≤η_ball`，用膨胀分位数 `q+δ_f`，则覆盖仍成立（分数逐点漂移 ≤δ_f）；结合引理 35，系统级性质只引用 EC 与组合校验，归纳于 MReg DAG ⇒ 球内适配逐指令保持安全，代价是证书宽度 +2δ_f。系：**证书不是「要么作废要么撒谎」的二元物，它可以在球内被「膨胀地保持」**。

**引理 41（移位代数的单调性与无免费午餐）** SER 的 ε 按 ⊕ 单调不减；PAR 缩窄要求跨模态移位独立且一致性审计通过，共因 `ε_cc` 高时禁用；VETO 非补偿。⇒ 不存在组合后 ε 低于所有输入且通过审计的路径。系：**OOD 泛化不能被「多模态融合」凭空买回，只能被显式计量或显式拒绝**。

**引理 42（适配-再校准阈值）** 设代价调整风险 `R(π)=safety_loss(g_cert,π)+C(π)`，`C(RECAL)>C(PEFT)>C(HOLD)`，`safety_loss` 对 g_cert 单调不减、斜率 κ。则存在阈值 `g*=(C_RECAL−C_PEFT)/κ`：`g_cert<g*` 时 PEFT 支配，`g_cert>g*` 时 RECAL 支配；结合迟滞带得确定性策略（定义 388）。系：**「该省还是该重训」不是经验调参，而是证书漂移的单阈值决策**。

**定理 30（PACE 严格包含 MODGAUGE）** 令 ε=0、Δθ=0、SDA=id、CAP=∅、χ_A 平凡，则 PACE 的每条路径逐指令等于 MODGAUGE；由 R73 定理 27 再退化等于 EMBODIED/R71/R68。安全单调不减，效率仅在位移/适配被正确记账时获益。

**定理 31（可证适配 ⇒ 系统安全）** 在 A114（移位有界 `TV≤ε_max` 且支撑重叠）、A115（适配数据来源可证 + 外部锚定）、A116（`d_φ log n_t ≪ n_t`）下：若 (i) SDA 的 ε 是真移位的上界（soundness），(ii) CAP 的覆盖下界成立，(iii) 适配在证书球内，(iv) SHA 组合合法，则 `Valid(J_PACE) ⇒ 物理执行风险 ≤ ε_mod + ε_shift + ε_adapt`，其中 `ε_shift=Δ(ε_tot)`、`ε_adapt=2δ_f`。**证明重量落在 SDA 的 soundness（估计的 ε 是否真上界）与支撑重叠假设上。**

**定理 32（适配策略阈值最优）** 在引理 42 的单调性与凸性下，最优策略是证书漂移的阈值策略：`PEFT` 当 `g_cert≤g*`，`RECAL` 当 `g*<g_cert≤γ_hi`，`STUB` 当归因失败或支持逃逸；迟滞带保证无振荡。系：**PACE 给出的是策略而是一个可证明的决策边界**。

**定理 33（无免费 OOD 覆盖——分离结果）** 对任意仅使用**无标签**目标数据的适配器，在允许任意标签/概念漂移且不假设支撑重叠的分布族上，不存在非平凡的分布无关覆盖保证（可构造 P_t 把质量放到未见标签/未见模式，使任何固定集的覆盖率可被压到 0）。⇒ 必须有 (a) 有标签目标样本，或 (b) 密度比/结构假设，或 (c) 诚实报告 `ε=1` 并 stub。系：**这是本轮方案的诚实边界，也是「分布外泛化」不能被工程话术绕过的原因。**

## 6. 本轮最大风险

**一句话**：PACE 的安全证明依赖移位上界 ε 的 **soundness**（估计值必须真是真移位的上界），而低维 PEFT 恰好让系统可以「廉价地」越过这个上界——一个秩 1、范数很小的更新就能翻转决策边界，功能漂移 `δ_f` 很小但**语义漂移**可以极大；于是系统会在「证书球内、覆盖下界成立、审计合规」的情况下，被投毒或渐进漂移推到一个证书数学上有效、语义上已越界的区域，**既便宜又自信地适应失败**。

次级风险与缓解：
1. **SDA 低估移位（估计非上界）** → 用保守置信上界（bootstrap/浓度不等式）+ 多重检验校正；ε 只允许高估不允许低估；低估即触发否决。
2. **支持逃逸使 Δ(ε) 失去意义** → 支持检测 + 未知类质量；`ε=1` 时强制 stub；不允许用低维 φ 外推到支撑外。
3. **低维适配的表达偏差**（目标域修正不在 d_φ 子空间）→ 监测残差；偏差超阈值升级为全量重校准（引理 42 的阈值策略自动覆盖）。
4. **证书球只界功能范数不界语义** → 加入任务级锚定探针（本体/接触/已知几何）作为证书球的**外部约束**，而非只看参数范数。
5. **共因致盲导致 PAR 假独立** → 第三方独立共因传感器 + `ε_cc` 门控；相关可疑时禁用缩窄。
6. **适配投毒** → 数据来源证明 + 锚定适配 + 低维空间的**方向审计**（不只看范数，还看更新方向是否被外部锚定约束）。
7. **迟滞带参数化导致的策略抖动或迟滞过宽** → 迟滞带纳入预注册，E401/E402 扫描；过宽时降级为固定 RECAL。
8. **MB4 过拟合** → 密封保持集 SEAL-MB4 + 预注册 + 三方复现（E408）；C4 只认预注册指标。

**定义 391（AIC-SHIFT）** 渐进漂移攻击 / 适配投毒 / 共因致盲 / 支持逃逸。防线：锚定适配、来源证明、证书球硬约束、ε_cc 独立测量、支持检测触发 stub。

**定义 392（C4 绑定）** C1–C3 继承；C4（可证适应）← (SDA,SBC,CAP,CBA,SHA) ← MB4 ← AB4 ← (覆盖缺口, 目标样本效率, 认证成本比, 安全违例率)。非绑定=工程附件。

## 3. 关键算法伪代码

```python
# IP-303 SDA：移位检测与归因（计量域 5Hz，独立于主闭环）
class ShiftAttributor:
    def update(self, sealed_stats, live_batch, common_cause):
        eps = {}
        for mod, st in sealed_stats.items():
            cov = two_sample_tv(live_batch[mod].x, st.x)          # 协变量漂移
            res = residual_shift(live_batch[mod].y, st.y)         # 残差漂移
            sup = support_novelty(live_batch[mod].x, st.x)        # 支持逃逸
            eps[mod] = max(cov, res, sup)                         # TV 上界（保守）
        eps['cc'] = common_cause_shift(common_cause)              # 温度/振动/光照
        return ShiftVector(eps, total=sha_fold(eps.values()))     # 只增不减

# IP-304/305 SBC + CAP：移位约束 conformal + 低维校准适配
def shift_bounded_conformal(s0, g_feats, src_cal, tgt_sample, alpha, d_phi):
    phi  = fit_lowrank_quantile(s0, g_feats, tgt_sample, alpha, d_phi)  # n_t=O(d_phi)
    eps  = attributor.total
    delta = eps                                                # TV 下界（定义 385）
    q_phi = empirical_quantile([s0(x,y)+phi@g(x,y) for (x,y) in src_cal+tgt_sample],
                               1 - alpha - delta)
    n_eff = effective_sample_size(src_cal, tgt_sample, d_phi)  # 低维 → n_eff 高
    return ConformalSet(q_phi, delta=delta, n_eff=n_eff, phi=phi)

# IP-306 CBA：证书球内 PEFT（模型层，异步）
def certificate_bounded_peft(module, target_batch, eta_ball, L_f, anchors):
    dtheta = lora_step(module, target_batch)                   # 只更新低秩 UV^T
    eta = spectral_norm(dtheta)
    d_f = L_f * eta                                            # Lipschitz 功能漂移界
    if d_f > eta_ball:                                         # 出球 → 拒绝在线更新
        return module, 'RECAL_REQUIRED'
    if not direction_anchor_ok(dtheta, anchors):               # 方向审计（防投毒）
        return module, 'STUB'
    module = apply_update(module, dtheta)
    module.cert.inflate_conformal(d_f)                         # 膨胀而非作废证书
    return module, 'PEFT_OK'

# IP-307 SHA：移位代数（与 CCA 同构）
def sha_compose(e_a, e_b, op, rho_eps, e_cc):
    if op == 'SER':  return max(e_a, e_b)                      # 串联只能更差
    if op == 'PAR':
        if e_cc > E_CC_MAX or abs(rho_eps) > RHO_EPS:          # 共因/相关 → 禁缩窄
            return max(e_a, e_b)
        return fused_shift(e_a, e_b, rho_eps)                  # 仅独立时允许
    if op == 'VETO': return float('inf') if max(e_a, e_b) > E_MAX else min(e_a, e_b)

# IP-308 χ_A + 策略：适配反作用与再校准触发（迟滞）
def adaptation_policy(mods, g_cert, gamma_lo, gamma_hi, budget):
    if g_cert <= gamma_lo:      return 'PEFT', mods
    if g_cert <= gamma_hi:      return 'RECAL', mods            # 确定性触发
    return 'STUB', [stub(m) for m in mods]

# IP-309 PACE 主闭环（在 MODGAUGE 上插入三处，控制域零改动）
def PACE_round(M, obs, audio, tac_frame, depth_img):
    eps  = M.sda.update(M.seal_stats, M.live, M.common_cause)   # 5Hz
    d_ev = M.dpe.update(depth_img, rgb, M.cam_state, M.motion, M.peers)
    d_ev = M.sbc.attach(d_ev, eps['dpe'])                       # 覆盖率退化进契约
    t_ev = M.dmem.update(tac_frame, M.last_action)
    b_t  = M.bse.step_full(..., d_ev=d_ev, t_ev=t_ev)
    g_cert = M.cert_drift.estimate(b_t, eps)                    # 证书漂移
    pi, mods = adaptation_policy(M.mods, g_cert, M.g_lo, M.g_hi, M.budget)
    if pi == 'RECAL': M.recal.schedule(mods)                    # 慢环，异步
    M.mreg.audit(eps)                                           # 组合合法 + 移位单调
    k, lam = MODGAUGE_control_step(M, b_t)                      # 控制域完全继承
    return k, lam, J_PACE(M.mreg, eps, g_cert)                  # 组合证书
```

## 4. 推导

**引理 38（移位下覆盖率退化）** `TV(P_0,P_t)≤ε ⇒ coverage_{P_t}≥1−α−ε`；Δ 单调、Δ(0)=0。支持漂移时 ε=1，界平凡，必须 stub。系：**覆盖是分布的函数，OOD 不可能静默保留覆盖**。

**引理 39（低维适配的样本效率）** CAP 分数类自由度 d_φ ⇒ 经验分位数一致偏差 `≤O(sqrt(d_φ log(n_t/δ)/n_t))`；达宽度差 β 需 `n_t=O(d_φ log(1/β)/β²)`；全模型适配需 `O(d_model log(1/β)/β²)`。系：**低维 = 少目标样本 + 紧证书，这是 C4 的核心可证伪点**。

**引理 40（证书球内适配的安全保持）** `δ_f≤η_ball` 时用膨胀分位数 `q+δ_f` 覆盖仍成立；结合 R73 引理 35，系统级性质只引用 EC 与组合校验，归纳于 MReg DAG ⇒ 球内适配逐指令保持安全，代价是宽度 +2δ_f。系：**证书可在球内被「膨胀地保持」，不是二元作废**。

**引理 41（移位代数的单调性与无免费午餐）** SER 的 ε 单调不减；PAR 缩窄要求移位独立且审计通过，ε_cc 高时禁用；VETO 非补偿。⇒ 不存在组合后 ε 低于所有输入且通过审计的路径。系：**OOD 泛化不能被多模态融合凭空买回**。

**引理 42（适配-再校准阈值）** 代价调整风险 `R(π)=safety_loss(g_cert,π)+C(π)`，`C(RECAL)>C(PEFT)>C(HOLD)`，safety_loss 斜率 κ ⇒ 阈值 `g*=(C_RECAL−C_PEFT)/κ`：`g_cert<g*` PEFT 支配，`g_cert>g*` RECAL 支配；迟滞带保证确定性。系：**「省还是重训」是证书漂移的单阈值决策，不是经验调参**。

**定理 30（PACE 严格包含 MODGAUGE）** ε=0、Δθ=0、SDA=id、CAP=∅、χ_A 平凡 ⇒ PACE 逐指令等于 MODGAUGE；由 R73 定理 27 再退化等于 EMBODIED/R71/R68。安全单调不减。

**定理 31（可证适配 ⇒ 系统安全）** 在 A114（`TV≤ε_max` 且支撑重叠）、A115（适配来源可证 + 外部锚定）、A116（`d_φ log n_t≪n_t`）下：若 SDA 的 ε 是 sound 上界、CAP 覆盖下界成立、适配在证书球内、SHA 合法，则 `Valid(J_PACE) ⇒ 风险 ≤ ε_mod + Δ(ε_tot) + 2δ_f`。**证明重量落在 SDA soundness 与支撑重叠假设上**。

**定理 32（适配策略阈值最优）** 引理 42 的单调/凸性下，最优策略为证书漂移阈值策略：PEFT（`≤g*`）/RECAL（`g*<·≤γ_hi`）/STUB（归因失败或支持逃逸）；迟滞带保证无振荡。

**定理 33（无免费 OOD 覆盖——分离结果）** 对任意仅用无标签目标数据的适配器，在允许任意标签/概念漂移且不假设支撑重叠的分布族上，不存在非平凡分布无关覆盖保证（可构造 P_t 把质量放到未见标签/模式使覆盖压到 0）。⇒ 必须有 (a) 有标签目标样本、(b) 密度比/结构假设、或 (c) 诚实报 `ε=1` 并 stub。系：**这是方案的诚实边界，OOD 泛化不能被工程话术绕过**。

## 7. 本轮最大风险

**一句话**：PACE 的全部保证依赖移位上界 ε 的 **soundness**，而低维 PEFT 恰恰让系统能「廉价地」越过这个上界——一个秩 1、谱范数很小的更新可使 `δ_f` 很小却**语义翻转**，于是系统会在「证书球内、覆盖下界成立、审计合规」的状态下，被投毒或渐进漂移推到证书数学有效、语义已越界的区域，**既便宜又自信地适应失败**。

次级风险与缓解：
1. **SDA 低估移位** → ε 只许高估不许低估（bootstrap/浓度上界 + 多重检验校正）；低估即否决。
2. **支持逃逸使 Δ(ε) 失效** → 支持检测 + 未知类质量；`ε=1` 强制 stub；禁止低维 φ 外推到支撑外。
3. **低维表达偏差**（目标修正不在 d_φ 子空间）→ 残差监测，超阈自动升级为全量再校准（引理 42 阈值策略覆盖）。
4. **证书球只界范数不界语义** → 任务级锚定探针（本体/接触/已知几何）作为证书球外部约束，不只看参数范数。
5. **共因致盲** → 第三方独立共因传感器 + ε_cc 门控；相关可疑即禁用 PAR 缩窄。
6. **适配投毒** → 数据来源证明 + 锚定适配 + 低维更新**方向审计**（不只看范数，看方向是否被锚定约束）。
7. **迟滞带抖动/过宽** → 迟滞带预注册，E401/E402 扫描；过宽降级为固定 RECAL。
8. **MB4 过拟合** → SEAL-MB4 + 预注册 + 三方复现（E408）；C4 只认预注册指标。
