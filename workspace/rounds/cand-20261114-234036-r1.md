# 第 3 轮（灵感循环第 3 轮；本轮灵感：「真机评测」×「分层规划」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440）。
> 本轮纪律：**在 ToolGauge 上改进，而不是推倒重来**——三条升级轴分别落在「验证的独立性」「评测资源的规划」「失败后的恢复」；
> MODGAUGE 五不变式、6C 骨架、TB-Contract、严格退化链全部保留；同时审计并修复第 2 轮遗留的 7 处统计/架构缺陷（见 §5）。

## 三位一体映射（升级而非重写）

| 灵感词 | 第 2 轮对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| 真机评测 | V 阶段：同机同会话的一条 cross.modal 回执 | **F-Gate 真机验收门**：留出真机 + 预注册指标 + e-过程 anytime 有效 | 第 2 轮的「独立回执」并不独立——同机、同先验、同传感器栈，等于让系统用自己的考卷给自己打分 |
| 分层规划 | 扁平逐盲区 6C + 单层 TB-Contract 预算 | **HEP 分层评测规划**：fleet ⊃ embodiment ⊃ task-family ⊃ blind-spot ⊃ probe | 真机评测稀缺、昂贵、部分不可逆；扁平预算无法表达「先评什么、评多细、何时停」 |
| 真机评测方法论 × 分层规划 | P-Quarantine 全局断路器 + 失败即 stub | **H-Quarantine 分层隔离 + Rollback 回滚 + HEP-Cert 分层证书** | 一个坏先验不该停掉整机；一次失败也不该把一个还能用的旧子图 stub 掉 |

**核心命题**：把 ToolGauge 的「单盲区 6C + 单条独立回执验证」升级为
「**分层评测规划 → 真机验收门控 → 修复/回滚 → 分层证书**」：
把「真机评测」当作**最稀缺且唯一的真值来源**（因此必须被规划、预注册、留出复用记账），
把「分层规划」当作**在评测资源约束下选择抽象层级与停止时机**的决策框架；
数值真值仍由计量层独占，VLA 仍只做三件被审计的事（提假设 / 选工具 / 写主张）。

**不变式保持声明**：
- MODGAUGE 五不变式全部保留；**6C 扩为 7C**（H→C→E→C→V→F→U），F 失败走 R（Rollback），U 仅当 F 通过；
- **退化链延长**：FieldGauge 失效（无真机预算 / HEP 失败 / 留出集耗尽）⇒ 退回 ToolGauge 单机 V 阶段 ⇒ LeanGauge ⇒ MODGAUGE；
- **恢复语义细化**：优先 Rollback 到最后已验证子图；**只有无可用旧版本时**才 stub + RED。

## 0. 直觉与动机

### 灵感 1：真机评测——「独立性」是买来的，不是假设出来的

直觉：第 2 轮把最大风险（摊销先验的跨盲区相关偏差）的防线押在 V 阶段「至少一条未参与拟合的 cross.modal 回执」上。
但这条回执与训练数据共享同一台机器、同一套传感器、同一批材质、同一个 MP-Φ——它们的误差是**强相关**的。
交叉验证 z 检验的前提（残差独立）在最需要它的时候恰好失效。真机评测研究给出的解药不是更强的统计检验，而是
**制度性的独立**：(a) 留出机器 / 留出任务族（cross-embodiment holdout）；(b) 预注册指标与分析口径；
(c) 重复测量并显式建模机器随机效应（同一台机器内的多次测量不算独立样本，只是 cluster 内的重复）；
(d) 真机时间是不可再生的稀缺资源。因此评测不是免费的 `eval()`：它要**预算**、要**留出账本**、要**防止反复复用同一批留出样本**。

### 灵感 2：分层规划——「评到多细」本身就是一个规划问题

直觉：盲区数量 × 任务族 × 探测工具构成组合爆炸，而真机预算往往只有几十次试次。
扁平策略只有两个极端：全评（烧光预算）或只评便宜的代理（自欺）。
分层规划的智慧是：在**抽象层**（fleet / task-family）先做低成本、高覆盖的 AND/OR 验收，
只在失败/不确定分支上**向下精化**到 embodiment / blind-spot / probe；并且抽象必须满足 **downward refinement（A120）**：
抽象层判「通过」必须能推出其下所有具体精化都通过，否则抽象会**掩盖**只在真机上出现的低频失效。
这把第 2 轮的 TB-Contract 从「工具调用预算」升级为「**评测预算 + 抽象层级 + 停止规则**」的三元契约。

### 灵感 3：两者相乘——评测门必须对「可选停止 + 自适应复用」免疫

直觉：只要允许「失败后夹紧重试 1 次」「每个盲区独立检验」「按结果决定下一个盲区评不评」，
经典固定 α 检验就必然膨胀（一台小型 p-hacking 机器）。真机评测的实践纪律（预注册 + 一次分析）在闭环系统里不现实，
因为系统必须边跑边修。可行解是 **anytime-valid 推断**：用 e-过程 / 混合鞅构造验收统计量，
使「无论看多少次、按什么顺序看、因何停止」总误接受率 ≤ α（Ville 不等式），
再用**留出复用账本**把「同一批真机样本被多少个假设用过」显式记账——复用不是禁止，而是**计价**（有效样本量随 log 复用次数衰减）。

## 1. 形式化定义（增量：定义 432–447）

**定义 432（评测域层级 H-Eval）** 分层评测域 𝓔 = (V, ≺, lev, ∧/∨)，层级 lev ∈ {L0 fleet, L1 embodiment, L2 task-family, L3 blind-spot cell, L4 probe}；
v ≺ v′ 表示 v′ 是 v 的精化；内部节点为 AND（全部子节点须通过）或 OR（任一子节点通过即可）。
每个节点 v 携带谓词 P_v ∈ {PASS, FAIL, UNKNOWN} 与一个可估价的评测单元。HEP 只允许沿 ≺ 向下展开（定义 435）。

**定义 433（真机评测单元与代价）** e = (v, π, m, n_req, c_real, τ, destr, h_pre)：
π 为执行协议；m 为度量；n_req 为达到统计功效所需配对数；c_real 为真机代价（硬件时长+磨损+人工）；
τ 为最坏时延；destr ∈ {0,1} 标记是否部分不可逆；h_pre 为**预注册哈希**（指标、样本量、停止规则、分析口径的承诺，定义 438）。
真机评测返回 (y ∈ ℝ^m, 校准后状态快照)，后者用于定义 439 的反作用检测。

**定义 434（抽象可靠性与精化间隙）** 抽象谓词 P_abs 对节点 v 是**可靠的（sound，无假通过）**当且仅当
P_abs(v)=PASS ⇒ 对一切 v′ ≺ v 有 P_v′=PASS。定义**精化间隙**
ε_abs = sup_v P(P_v=FAIL | P_abs(v)=PASS)。
A120（抽象可靠性条件）：接受证书只允许使用 ε_abs ≤ ε_abs^max 的抽象层；ε_abs > 0 时必须把 ε_abs 计入风险账本，
超过阈值则**禁止在该层停手**、强制向下精化。这是对第 2 轮「V 阶段交叉验证」缺失的「验证有效性前提」的显式化。

**定义 435（分层评测规划 HEP）** HEP 计划为 (T, ρ, B_real)：T 是 𝓔 上的 AND/OR 树（含前置/效果与代价），ρ 为停止规则，
B_real 为真机预算。目标：在期望真机代价 ≤ B_real 下最大化证书覆盖，或等价地在证书置信 ≥ 1−δ 下最小化代价。
规划按**信息价值/代价**（定义 446）排序，粗到细展开；HTTP 意义上的「抽象通过 ⇒ 不展开」受 A120 约束。

**定义 436（真机验收门 F-Gate 与 e-过程）** 对候选替换 Δ，在留出集 H 上取配对真机测量
X_i = ℓ_m(Δ) − ℓ_m(baseline)，零假设 H0: E[X_i] ≤ μ0。取可预测下注 λ_i ∈ [0, 1/b)，构造
E_t = Π_{i=1..t} (1 + λ_i (X_i − μ0)/b)。
F-Gate 接受 Δ 当且仅当 sup_{t≤T} E_t ≥ 1/α **且**预注册方向性指标满足。
由 Ville 不等式，任意可选停止与自适应选择单元下 P_{H0}(sup_t E_t ≥ 1/α) ≤ α（引理 51）。

**定义 437（留出复用账本与复用计价）** 账本 L 记录每个留出单元 u 被哪些假设用过，复用重数 m(u)。
**硬分割**：用于校准/训练的单元永不得进入验收集。**软复用计价**：有效样本量
n_eff = Σ_u 1/(1 + log m(u))，且第 j 个假设按其 α-花费 α_j = α·6/(π² j²) 计（Robbins 序列）。
账本既支持复用，也让复用的统计代价显式化（引理 53）。

**定义 438（预注册与偏离）** 每个评测单元在取数前固定 (m, n_req, ρ, 分析口径) 并哈希为 h_pre。
偏离记录 D（事后换指标、改子组、延长观测）。**未登记偏离**使证书直接失效，除非在**全新留出集**上重跑。
这是把真机评测的实践纪律（预注册）编码为可执行的证书条件。

**定义 439（评测反作用与状态漂移）** 真机评测返回评测前后校准快照，漂移
d_e = dist(calib_before, calib_after)。若 d_e > d_max，该评测回执标记 perturbing，所有依赖旧校准的缓存契约失效并需重验。
**评测本身也是计量工具调用**，必须通过 TCV（定义 418）与 PROBING（定义 430）；区别是：普通探测承诺零副作用，
评测**允许有界副作用**——这是必须显式承认的例外（引理 54）。

**定义 440（分层评测证书 HEP-Cert）** HEP-Cert(Δ) = (T_abs, used_units, {E_t}, ε_abs, D, drift_ledger, h_pre)。
**有效**当且仅当：(i) 所有 PASS 的抽象节点满足 A120（ε_abs ≤ ε_abs^max）；
(ii) F-Gate e-值 ≥ 1/α；(iii) 无未登记偏离；(iv) max d_e ≤ d_max；(v) 账本一致（无硬分割违规）。
无效 ⇒ 不得热替换。证书同时是第 2 轮 RepairCert（定义 427）的**评测证据层**，两者合并进 EC。

**定义 441（回滚与分层隔离）** F 失败时：若存在最近一次 E-verified 子图，则 **Rollback**（恢复到该子图），
否则才 stub + RED。**H-Quarantine**：按证据定位最小充分节点 v*，只隔离 Q ⊆ descendants(v*)（定义 428 的层级细化）；
被隔离子树的先验禁用并回退 BP-Cal，其余子树照常运行。隔离只收缩先验定义域，绝不扩大任何接受集。

**定义 442（跨具身部分池化先验）** MP-Φ 在 H-Eval 的 L1 上做部分池化：共享参数 μ_shared + 每具身随机效应 δ_e。
某具身验收失败时，只隔离其 δ_e 并将共享参数向物理锚 p_phys 收缩（KL 锚，继承定义 420），
不牺牲其他具身（修复第 2 轮 P-Quarantine 的全局熔断缺陷）。该先验的质量界由分层元泛化（引理 52 的具身层）约束。

**定义 443（评测预算契约 EB-Contract）** EB = (B_real, H_holdout, α_schedule, d_max, rollback_policy, prereg_set)：
真机预算、留出集与硬分割、α-花费表、漂移上限、回滚策略、预注册集合。
EB 是 TB-Contract（定义 424）在**评测资源**上的细化，也是 IV-Contract（定义 407）的上层契约。
F-Gate 与 HEP 全异步，故 EB 不进入硬实时约束（引理 56）。

**定义 444（评测独立性得分）** 对评测单元 e 与训练/机内验证来源，定义
ρ_indep(e) = |corr(误差_e, 误差_train)|。
要求 ρ_indep ≤ ρ_max；否则 e 记为**半独立**，有效样本量打折 n_eff ← n_eff·(1−ρ_indep)。
这形式化了「同机回执不是独立回执」：第 2 轮 V 阶段的 cross.modal 典型满足 ρ_indep ≈ 1，因而 n_eff ≈ 0。

**定义 445（FieldGauge 七段闭环 7C）** 修复循环 = H(ypothesize) → C(ompile) → E(xecute) → C(alibrate) → V(erify) → **F(ield-gate)** → U(pdate)：
1–5 段继承 ToolGauge（定义 421）；6. F：由 HEP 选出的留出真机单元上跑 e-过程验收，产出 HEP-Cert；
7. U：仅当 HEP-Cert 有效才热替换并绑定证书；F 失败 ⇒ R（Rollback，定义 441）。

**定义 446（规划判据：单位代价信息价值 VoI）** 对节点 v，VoI(v) = ΔH(P_v | 已观测) / c_real(v)，
其中 ΔH 为对根证书置信的期望熵减。HEP 每次选 argmax VoI 的边界节点；当证书置信 ≥ 1−δ 或预算耗尽即停。
VoI 让「抽象层便宜但信息少」与「真机层贵但决定性」在同一标尺上比较——这是第 2 轮单层增益注 β（定义 419）的层级推广。

**定义 447（继承、组合与退化）** 未被本轮重定义的记号沿用定义 416–431。
令 B_real=0、H=∅、HEP=∅、F≡V，则 FieldGauge ≡ ToolGauge；再令 VLA=∅、T₀={被动观测}、MP-Φ=物理先验 GP 则回到 LeanGauge。
完整退化链：**FieldGauge ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE**。

# IP-321 HEP：分层评测规划（AND/OR + 预算 + VoI 停止）
class HEP:
    def plan(self, delta):
        frontier = [self.tree.root]
        while frontier and self.budget.left() > 0:
            v = max(frontier, key=self.voi)          # 定义 446：信息价值/真机代价
            frontier.remove(v)
            if v.level < L4:
                r = self.abstract_test(v)            # 低成本代理/抽象验收
                if r is PASS and self.sound(v):      # 仅当 A120 成立才允许停手（定义 434）
                    self.mark_pass(v, "abstract")
                else:
                    frontier.extend(self.tree.children(v))   # 向下精化
            else:
                yield v                              # 叶：真机配对评测单元

# IP-322 F-Gate：e-过程真机验收门（任意停止/自适应选择下 ≤ α）
class FGate:
    def __init__(self, alpha, b, mu0, ledger):
        self.alpha, self.b, self.mu0 = alpha, b, mu0
        self.E, self.t = 1.0, 0
        self.ledger = ledger
    def look(self, x, unit):
        self.ledger.charge(unit)                     # 复用计价 + 硬分割检查（定义 437）
        lam = self.predictable_lambda()              # 可预测下注，0 ≤ lam < 1/b
        self.E *= (1 + lam * (x - self.mu0) / self.b)
        self.t += 1
        return self.E >= 1.0 / self.alpha            # Ville：任意停止均 ≤ α（引理 51）
    def certificate(self, hep, dev, drift):
        return HEPCert(hep=hep, E=self.E, alpha=self.alpha,
                       eps_abs=hep.eps_abs, dev=dev, drift=drift,
                       valid=(hep.eps_abs <= EPS_ABS_MAX
                              and self.t > 0 and self.E >= 1 / self.alpha
                              and not dev.unregistered
                              and drift.max <= D_MAX))

# IP-323 HLedger：留出复用账本
class HoldoutLedger:
    def __init__(self, holdout, calib):
        self.hold, self.calib = set(holdout), set(calib)
        self.uses = defaultdict(set)
        assert self.hold.isdisjoint(self.calib)      # 硬分割（定义 437）
    def charge(self, u):
        assert u in self.hold and u not in self.calib
        self.uses[u].add(self.current_hyp)
    def n_eff(self):
        return sum(1 / (1 + log(len(self.uses[u]))) for u in self.hold)

# IP-325 回滚与分层隔离
def rollback_or_stub(M, s, reason):
    if M.mver.has_verified_subgraph(s):
        M.mver.rollback(s)                           # 优先回滚（定义 441）
        M.hquar.quarantine_minimal(s, reason)        # 只隔离最小充分子树
        return "ROLLBACK"
    return stub_and_red(s, reason)                   # 无旧版本才 stub（严格退化）

# IP-326 FieldGauge 7C 闭环：在 ToolGauge 的 V 之后插入 F，失败走 R
def fieldgauge_7c(M, delta, s):
    H    = M.lbox.hypothesize(s, M.dbox.R[s])                 # H
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s)) # C
    rec  = M.tcv.execute(prog, M.env)                         # E（PROBING）
    if len(rec) < n_min(s):  return rollback_or_stub(M, s, "insufficient")
    mu, Sig = M.apcal.calibrate(rec, H, s)                    # C
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):# V（机内，半独立）
        mu, Sig = M.apcal.calibrate(rec, ["UNKNOWN"], s)
        if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
            return rollback_or_stub(M, s, "cross_failed")
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s)       # U 候选
    if not contract_regression(new_ec):
        return rollback_or_stub(M, s, "regression_failed")
    # F：分层评测规划 + 真机 e-过程验收（全异步，不阻塞 50Hz）
    plan = M.hep.plan(new_ec)                                 # 定义 435/446
    gate = M.fgate(new_ec, M.ledger)                          # 定义 436/437
    for unit in plan:
        x, drift = M.field.measure(unit, new_ec)              # 配对真机测量
        M.field.check_drift(unit, drift)                      # 定义 439
        if gate.look(x, unit):
            break                                             # 提前通过（可选停止合法）
        # 未通过不立即判死：HEP 继续按 VoI 精化；预算耗尽才下结论
    cert = gate.certificate(M.hep, M.deviations, M.field.drift())
    if not cert.valid:
        return rollback_or_stub(M, s, "field_gate_failed")    # R 回滚
    M.mreg.hot_replace(M.dpe, new_ec)                         # U
    M.dbox.update_from_posterior(s, mu, Sig)
    bind_claims(new_ec, H, prog, rec, cert)                   # 证书 = 修复证书 + 评测证据层
    M.hquar.update(cert)                                      # 定义 441
    return True

        if s not in M.inflight and M.hep.can_afford(s):
            M.inflight.add(s); submit_async(fieldgauge_7c, M, M.pending(s), s)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)     # 主控不变
```

## 3. 推导

**引理 51（F-Gate 的 anytime 有效性）** 设 X_i 为配对真机测量，H0: E[X_i] ≤ μ0，λ_i 关于过去可预测且 0 ≤ λ_i < b。
则对**任意可选停止时刻**与**任意自适应选择被评单元的策略**，P_{H0}(∃t: E_t ≥ 1/α) ≤ α。
证明：非负超鞅 + Ville 不等式。
**系 51.1（族错误控制无需 Bonferroni）** K 个盲区、每个至多 L 次 look、允许失败重试与自适应排序，
总误接受率仍 ≤ α——这正是第 2 轮「夹紧重试 1 次 + 逐盲区独立 z 检验」缺失的性质。
**系 51.2（期望试次）** 若真实效应 E[X] ≥ μ0 + θ，则达到接受所需期望在机试次 ≤ O((b/θ)²·log(1/α))。

**引理 52（分层评测的成本-置信界）** 设 AND/OR 树高 h、分支因子 k、叶数 B = k^h，抽象测试可靠（A120，ε_abs=0），
且恰有 q 个失败叶。粗到细 HEP 的期望真机叶评测数 ≤ q，抽象测试数 ≤ q·h·k；而扁平策略需 Ω(B) 次真机评测。
故当 q ≪ B 时节省因子约为 k^{h−1}/(h·k)。
若抽象**不可靠**（ε_abs>0），抽象 PASS 可掩盖至多比例 ε_abs 的失败叶，期望漏检 ≤ ε_abs·B；
因此证书必须计入 ε_abs 且要求 ε_abs ≤ ε_abs^max，否则强制向下精化（定义 434/440）。
**推论 52.1（具身层元泛化）** 部分池化先验（定义 442）把引理 47 的 η 项分解为具身间 η_cross 与具身内 η_within；
只有 η_cross 需要真机留出来测，η_within 由机内回执承担——真机预算由此被"花在刀刃上"。

**引理 53（留出复用与自适应泄漏界）** 对同一批 n 个留出单元做 m 次自适应复用：
naive 固定 α 检验的误接受 ≤ 1 − (1−α)^m；而 e-账本 + α-花费给出总误接受 ≤ α，**与 m 无关**。
此外，从假设类 ℋ 中自适应选择假设时，复用的额外泛化间隙
ε_reuse ≤ √((log|ℋ| + log(1/δ)) / (2 n_eff)) + O(m·√(log|ℋ|/n))，
其中 n_eff = Σ_u 1/(1+log m(u))。结论：复用必须计价，且有效样本量随复用次数**对数衰减**而非线性崩溃。

**引理 54（评测反作用与契约安全）** 若漂移 d_e ≤ d_max 且契约回归边际 ρ > d_max，则评测后系统仍处于已验证包络内；
若 d_e > d_max，则评测回执标记 perturbing，所有依赖旧校准的缓存契约失效并需重验（定义 439）。
系：普通探测的「零副作用」语义不能无条件套用到评测；评测是**有界副作用**的一等行为，必须经 TCV 与 PROBING。

**引理 55（分层回滚与分层隔离的系统级安全）** Rollback 到最后 E-verified 子图恢复该子图的引理 44 数值等价性；
H-Quarantine 只收缩先验定义域、不扩大任何接受集（Q ⊆ descendants(v*)）。
故 FieldGauge 的系统级不变式与 ToolGauge 相同，且「误停面积」严格小于第 2 轮全局 P-Quarantine。

**引理 56（时序、预算与退化）** HEP 与 F-Gate 全部异步于 50Hz 路径之外；50Hz 周期新增仅证书字段写入 O(1) < 0.05ms；
EB-Contract 的真机预算不进入硬实时约束（引理 45 保持）。
令 B_real=0、H=∅、F≡V 则 FieldGauge ≡ ToolGauge，退化链与零副作用语义逐级保持。

## 6. 本轮最大风险（一句话）

**一句话**：分层评测规划的「经济性」会与「有效性」系统性错位——VoI 驱动的规划器会本能地在便宜的抽象层反复取证、
回避昂贵的真机层，而一旦 A120 的抽象可靠性在某个任务族上不成立（存在只在真机出现的低频失效模式），
系统就会拿到一张**看起来完备、实则从未被真机检验**的分层证书；更糟的是，e-过程只保证「在选定零假设下不误报」，
它无法阻止零假设本身选错、也无法阻止留出集被评测反作用（定义 439）悄悄污染——
评测越复用、越自适应，证书越可能只是在证明「我们很擅长通过自己出的考卷」。

**次级风险与缓解**：
1. **抽象不可靠掩盖真机失效**（A120 破裂）→ 定义 434 强制 ε_abs 入账；E444 逐任务族测 ε_abs；超过阈值禁止停手；
2. **留出集被评测反作用污染** → 定义 439 漂移检测 + 定义 437 单元退役机制；E447 量化污染；
3. **真机预算耗尽导致证书真空** → EB-Contract 硬顶 + 「未验证」是一等结局（Rollback 而非假装通过）；E452；
4. **自适应复用泄漏** → e-账本 + α-花费 + n_eff 对数衰减（定义 437/引理 53）；E442；
5. **VoI 估计偏差导致只评便宜层** → 分层强制覆盖约束 + 预注册最低真机试次；E443/E454；
6. **回滚本身引入状态不一致** → rollback 前后契约回归 + 状态快照校验（引理 55）；E446；
7. **部分池化把坏具身经验泄漏给好具身** → 共享参数向物理锚 KL 收缩 + 每具身隔离测试；E445/E448。

## 2. 形式化定义（要点）

**定义 432/433（H-Eval / 评测单元）** 五层 AND/OR 评测域；评测单元携带协议、度量、样本量、真机代价、破坏性标志、预注册哈希。
**定义 434（A-Box 抽象可靠性）** P_abs PASS ⇒ 所有精化 PASS；ε_abs = sup P(FAIL|PASS)；ε_abs > ε_max ⇒ 禁止停手。
**定义 435/446（HEP / VoI）** 在预算内按单位代价信息价值选点，粗到细展开，置信达 1−δ 即停。
**定义 436（F-Gate）** 留出真机配对差 X_i，e-过程 E_t = Π(1+λ_i(X_i−μ0)/b)；sup E_t ≥ 1/α 则接受。
**定义 437（留出账本）** 校准/验收硬分割；同一单元复用 m 次则权重 1/(1+log m)；第 j 假设 α_j = α·6/(π²j²)。
**定义 438（预注册）** 取数前固定指标/样本量/停止/分析；未登记偏离 ⇒ 证书失效，须在全新留出集重跑。
**定义 439（评测反作用）** 漂移 d_e > d_max ⇒ 回执 perturbing，旧校准缓存契约失效；评测须过 TCV/PROBING。
**定义 440（HEP-Cert）** 五项有效性：A120、e ≥ 1/α、无未登记偏离、漂移 ≤ d_max、账本一致；无效不得热替换。
**定义 441/442（Rollback / 分层隔离 / 部分池化）** 优先回滚；只隔离最小充分子树；共享先验向物理锚收缩。
**定义 443/444/445/447（EB / 独立性 / 7C / 退化）** 真机预算契约；ρ_indep 量化独立性；7C 闭环；FieldGauge⇒ToolGauge⇒LeanGauge⇒MODGAUGE。

## 3. 关键算法骨架

# IP-321 HEP：分层评测规划（VoI/代价 + A120 门控）
class HEP:
    def plan(self, delta):
        frontier = [self.tree.root]
        while frontier and self.budget.left() > 0:
            v = max(frontier, key=self.voi)              # 定义 446
            frontier.remove(v)
            if v.level < L4:
                if self.abstract_test(v) is PASS and self.sound(v):  # A120（定义 434）
                    self.mark_pass(v, "abstract")
                else:
                    frontier.extend(self.tree.children(v))           # 向下精化
            else:
                yield v                                  # 真机叶单元

# IP-322 F-Gate：e-过程 anytime 有效验收
class FGate:
    def __init__(self, alpha, b, mu0, ledger):
        self.alpha, self.b, self.mu0, self.ledger = alpha, b, mu0, ledger
        self.E, self.t = 1.0, 0
    def look(self, x, unit):
        self.ledger.charge(unit)                     # 复用计价 + 硬分割（定义 437）
        lam = self.predictable_lambda()              # 可预测下注：0 ≤ lam < 1/b
        self.E *= (1 + lam * (x - self.mu0) / self.b)
        self.t += 1
        return self.E >= 1.0 / self.alpha            # Ville（引理 51）
    def certificate(self, hep, dev, drift):
        return HEPCert(hep, self.E, self.alpha, hep.eps_abs, dev, drift,
                       valid=(hep.eps_abs <= EPS_ABS_MAX
                              and self.t > 0 and self.E >= 1 / self.alpha
                              and not dev.unregistered
                              and drift.max <= D_MAX))

# IP-323 HLedger：留出复用账本（硬分割 + n_eff）
class HoldoutLedger:
    def __init__(self, holdout, calib):
        self.hold, self.calib = set(holdout), set(calib)
        assert self.hold.isdisjoint(self.calib)      # 定义 437 硬分割
        self.uses = defaultdict(set)
    def charge(self, u):
        assert u in self.hold and u not in self.calib
        self.uses[u].add(self.current_hyp)
    def n_eff(self):
        return sum(1 / (1 + log(len(self.uses[u]))) for u in self.hold)

# IP-325 回滚优先，stub 兜底
def rollback_or_stub(M, s, reason):
    if M.mver.has_verified_subgraph(s):
        M.mver.rollback(s)                           # 定义 441
        M.hquar.quarantine_minimal(s, reason)        # 只隔离最小充分子树
        return "ROLLBACK"
    return stub_and_red(s, reason)                   # 无旧版本才 stub

# IP-326 7C 闭环：ToolGauge 的 V 之后插入 F，失败走 R
def fieldgauge_7c(M, delta, s):
    H    = M.lbox.hypothesize(s, M.dbox.R[s])                  # H
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s))  # C
    rec  = M.tcv.execute(prog, M.env)                          # E
    if len(rec) < n_min(s): return rollback_or_stub(M, s, "insufficient")
    mu, Sig = M.apcal.calibrate(rec, H, s)                     # C
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)): # V（机内，半独立）
        mu, Sig = M.apcal.calibrate(rec, ["UNKNOWN"], s)
        if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
            return rollback_or_stub(M, s, "cross_failed")
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s)
    if not contract_regression(new_ec):
        return rollback_or_stub(M, s, "regression_failed")
    plan = M.hep.plan(new_ec)                                  # F：HEP 分层规划
    gate = M.fgate(new_ec, M.ledger)                           # e-过程验收门
    for unit in plan:
        x, drift = M.field.measure(unit, new_ec)               # 真机配对测量
        M.field.check_drift(unit, drift)                       # 定义 439
        if gate.look(x, unit): break                           # 可选停止合法
    cert = gate.certificate(M.hep, M.deviations, M.field.drift())
    if not cert.valid: return rollback_or_stub(M, s, "field_gate_failed")  # R
    M.mreg.hot_replace(M.dpe, new_ec)                          # U
    M.dbox.update_from_posterior(s, mu, Sig)
    bind_claims(new_ec, H, prog, rec, cert)
    M.hquar.update(cert)
    return True

# IP-326 主闭环
def FieldGauge_round(M, obs, audio, tac, depth, det):

        if s not in M.inflight and M.hep.can_afford(s):
            M.inflight.add(s); submit_async(fieldgauge_7c, M, M.pending(s), s)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)      # 50Hz 不变
```

## 4. 推导

**引理 51（F-Gate anytime 有效性）** H0: E[X] ≤ μ0，λ_i 可预测且 0 ≤ λ_i < b，则对任意可选停止与自适应选择，
P_{H0}(∃t: E_t ≥ 1/α) ≤ α（Ville）。
系 51.1：K 盲区 × L 次 look × 重试，总误接受仍 ≤ α（无需 Bonferroni）——修复第 2 轮的重试膨胀。
系 51.2：真实效应 ≥ θ 时，达到接受的期望试次 ≤ O((b/θ)²·log(1/α))。

**引理 52（分层评测成本-置信界）** 高 h、分支 k、叶 B=k^h、抽象可靠（ε_abs=0）、q 个失败叶时，
HEP 真机叶评测 ≤ q、抽象测试 ≤ q·h·k；扁平需 Ω(B)。节省因子约 k^{h−1}/(h·k)。
若 ε_abs>0，漏检 ≤ ε_abs·B，故证书须计入 ε_abs，超过 ε_max 强制向下精化。
推论 52.1：部分池化把引理 47 的 η 分解为具身间 η_cross 与具身内 η_within；真机预算只用于测 η_cross。

**引理 53（留出复用与自适应泄漏）** 同一 n 单元复用 m 次：naive 固定 α 误接受 ≤ 1−(1−α)^m；
e-账本 + α-花费总误接受 ≤ α（与 m 无关）。自适应选择假设类 ℋ 时额外间隙
ε_reuse ≤ √((log|ℋ|+log(1/δ))/(2 n_eff)) + O(m√(log|ℋ|/n))，n_eff = Σ1/(1+log m)。
结论：复用必须计价，有效样本量随复用次数对数衰减。

**引理 54（评测反作用）** d_e ≤ d_max 且契约回归边际 ρ > d_max ⇒ 评测后仍在已验证包络内；
d_e > d_max ⇒ 回执 perturbing、旧校准缓存契约失效并重验。评测是「有界副作用」的一等行为，零副作用语义不适用。

**引理 55（回滚与分层隔离的系统级安全）** Rollback 恢复已验证子图的引理 44 等价性；H-Quarantine 只收缩先验定义域、
不扩大接受集（Q ⊆ descendants(v*)）；系统级不变式与 ToolGauge 相同，且误停面积严格小于全局 P-Quarantine。

**引理 56（时序/预算/退化）** HEP 与 F-Gate 全异步，50Hz 新增 < 0.05ms；EB 真机预算不进入硬实时（引理 45 保持）；
B_real=0、H=∅、F≡V 时 FieldGauge ≡ ToolGauge；退化链与零副作用语义逐级保持。

## 8. 本轮最大风险

**一句话**：VoI 驱动的分层评测规划会系统性地偏向便宜的抽象层而回避昂贵的真机层，
一旦 A120 的抽象可靠性在某个任务族上不成立（只剩真机才能暴露的低频失效），
系统就会拿到一张**看起来完备、实则从未被真机检验**的证书；而 e-过程只保证「在选定零假设下不误报」，
无法阻止零假设选错或留出集被评测反作用污染——评测越复用、越自适应，证书越可能只是在证明
「我们很擅长通过自己出的考卷」。以 E441/E442/E444/E447/E454 证伪，以 A120 + ε_abs 入账（定义 434）、
HLedger 复用计价（定义 437）、分层隔离与 Rollback（定义 441）三重兜底。
