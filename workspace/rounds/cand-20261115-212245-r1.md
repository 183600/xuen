# 第 10 轮（灵感循环第 2 轮；本轮灵感：「结构优化」×「双臂协作」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**协作结构优化 + 臂间证书 + 协调契约**。两个灵感不是两个并列模块，而是同一件事的两面：**双臂协作的本质是引入跨体耦合结构，而结构优化正是决定"哪些耦合该存在"**。因此本轮按**拓扑层（CSO）/ 契约层（DAC）/ 证书层（MCC）**三层分解。任一新层失效必须注入中立元（冻结拓扑 / 解耦 / 串行化），逐臂逐周期严格等价退回 v9，而非行为漂移。

## 0. 直觉与动机

**先澄清"结构优化"的读法。** 在机器人语境里它常指机械连杆的拓扑优化；但在本系统里，机械结构已是既定硬件，真正可优化且尚未被碰过的是**计算与协作的结构**：模块之间、两臂之间的连接拓扑。v9 的 ID 只回答"哪些**节点**值得算"，却没人回答"哪些**边**值得连"。这是一个维度缺口：双臂系统的协调代价、通信代价、死锁风险几乎全部长在边上。故本轮把结构优化的对象定为**协作图 G_c 的离散拓扑**。

**灵感 1（结构优化 → 协作结构优化器 CSO，把蒸馏从节点级升到拓扑级）**
直觉：如果一条协调边长期贡献为零（c_e < τ_off^e）且剪掉后系统仍落在可容许族内，那它就是在为"看起来更协同"的叙事支付真金白银的时延和安全余量。核心创新：**协作结构优化器（CooperativeStructureOptimizer, CSO）**——在邻域编辑 {角色互换、边剪枝、边新增、共享/复制切换} 上做周期性束搜索，目标 J_struct 由任务进展、协调代价、安全余量侵蚀、切换开销加权；**只有落在可容许拓扑族 A_safe 内的编辑才被实现**。它把 P12"提炼不删码"从节点推广到边：删掉的是一条边，留下的是该边的解耦中立配置，逐臂等价于 v9。边归因 c_e 让拓扑优化有实证依据，而不是凭直觉做架构。

**灵感 2（双臂协作 → 双臂协调器 DAC + 臂间证书 MCC）**
直觉：v9 是单自我闭环，双臂带来三个全新安全接口——**臂间碰撞**（共享工作空间）、**物体所有权**（抓取交接）、**会合时序**（协同搬运动作必须在时间上对齐）。核心创新有两件：**双臂协调器（DualArmCoordinator, DAC）**把跨臂交互声明为协调契约 κ^c_{a→b}（共享坐标系、所有权前置、会合屏障、截止期、中立元=解耦），所有权用两阶段提交的原子账本管理；**臂间间隙证书（MutualClearanceCertifier, MCC）**把两个 AC 块证书**配对组合**成联合证书 Ĉ^{AB}，把 v9 的单臂停车不变式升级为**相互停车不变式**（两臂同时刹停仍保持 d_safe^cross 分离）。优雅之处在于这是对 v9 机制的**组合**而非替换：MCC 是两个 AC 的积，DAC 是两个 MW 的纤维积。

**灵感 3（综合 → 协作结构就是被优化的双臂耦合拓扑）**
直觉：把两个灵感当并列会得到"优化器 + 协调器"的堆砌；真正的洞见是让 CSO 去优化 DAC/MCC 所强制的那个拓扑。于是得到清晰的三层分工：**CSO 决定"有哪些耦合"（拓扑）→ DAC 定义"每条耦合的语义与失效"（契约）→ MCC 认证"已实现的联合运动是否安全"（证书）**。三层各自可退化：拓扑层退化=冻结在上一可容许配置（等价静态双臂基线）；契约层退化=工作空间分区（等价两条独立 v9 环）；证书层退化=两臂交替串行（等价交替 v9 单臂执行）。

## 1. 研究问题（轮次升级版）

- **Q1（联合证书可靠性）**：如何把逐臂块证书组合成联合证书，使"信任域内逐臂误差 ≤ β^a 且臂间误差 ≤ β^{AB}"假设下，双臂交叉/对向运动的安全性与分别单臂认证统计等价？相互停车不变式是否充分，还是必须引入横向余量项？
- **Q2（结构优化的安全边界）**：可容许拓扑族 A_safe 的结构不变式应该包含哪些条件，才能保证任意被接受的结构编辑都有到 v9 等价实例的退化路径？边级归因能否把"凭直觉剪耦合"变成"凭证据剪耦合"，且不在分布漂移时剪掉安全所依赖的边？
- **Q3（协调无死锁与退化活性）**：在所有权两阶段提交、会合屏障、以及 MCC/ DAC 级联退化下，如何保证无死锁、无饿死、无活锁？串行化退化与解耦退化是否严格保序、可组合？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 协作结构律（Cooperative Structure Optimization, CSO）**
协作图 G_c 的一等可优化对象是**拓扑**而非参数。结构编辑（角色赋值、边增删、共享/复制切换）只有在 σ' ∈ A_safe 时才可实现；A_safe 由结构不变式 I_struct 定义（监控独立、所有权唯一、边可退化、屏障无环）。每条被剪除的边必须留下解耦中立配置，其逐臂行为 ≡ v9 对应实例。结构优化只改拓扑与调度，不改代码可达性（P12 由节点推广到边）。

**P14 臂间证书律（Mutual-Clearance Certificate, MCC）**
联合运动以"块对"为单位认证：ζ^{AB} = (ζ^A, ζ^B, Ĉ^{AB}, P^{AB})。联合证书包含逐臂界与臂间最坏间隙界；相互停车不变式要求任意联合前缀 (p,q) 下两臂同时刹停后仍分离 ≥ d_safe^cross。单臂是 B 臂为空的退化情形，严格回到 v9 的 AC。

**P15 协作契约律（Coordination Contract, DAC）**
跨臂交互一律声明为协调契约 κ^c_{a→b} = (共享坐标系, 所有权前置, 会合屏障, 截止期, 中立元=解耦)。所有权为原子令牌，两阶段提交、D_handoff 超时即解耦（不阻塞）；会合屏障无环。任一协调契约失效注入中立元即"解耦"，得到工作空间分区模式，等价两条独立 v9 环 + 静态几何屏障。

## 3. 与基线的接口（如何退化）

- **CSO 失效 / 编辑被拒** ⇒ 冻结拓扑于上一可容许配置 G_c^*，等价静态双臂基线（两臂各跑 v9，仅保留一个固定几何屏障）；
- **MCC 失效 / 联合证书连续无效** ⇒ 串行化：任一时隙仅一臂 active，另一臂注入中立 hold a^⊥，块边界交换，等价交替 v9 单臂执行（引理 88）；
- **DAC 失效** ⇒ 工作空间分区（解耦），每条跨臂边注入中立元，等价两条独立 v9 环；
- **v9 ACMD 任一失效** ⇒ 按 v9 五级链逐臂退化（AC→K_eff=1；MW→手写网关；ID→全模块常开；DA/SPR/Cal→中立元；全失效→v7）；
- **全部失效** ⇒ 完整退回 v9，再退回 MetricVoiceGauge-OTL-GC-ER v7、v6。

## 4. 预期贡献

1. **联合证书组合框架**：把逐臂 AC 证书以笛卡尔积 + 相互停车不变式组合，得到局部化且可组合的双臂安全论证（MCC，引理 87）；
2. **协调契约与所有权账本**：把双臂的共享坐标系、抓取交接、会合时序代数化为可退化的契约，无死锁（DAC，引理 90）；
3. **协作结构优化器**：把 v9 的节点级蒸馏升到拓扑级，用边归因 + 可容许族约束实现"有证据的结构剪枝"，并给出安全投影定理（CSO，引理 89、91）；
4. **六层退化格**：拓扑/契约/证书三层各自的中立元构成完整退化链，与 v9 逐位等价；E571–E590 覆盖联合证书、相互中止、结构收敛、无死锁、所有权交接、共享/复制权衡与双臂端到端任务。

## 5. 本轮最大风险

**一句话**：结构优化依赖边归因 c_e 判定"哪条耦合冗余"，而 c_e 是在**当前任务分布**下测得的——一旦分布漂移（例如被抓物体从刚体变成可形变、需要双臂共享同一世界模型才能维持约束），CSO 可能恰好剪掉了安全所依赖的那条边，此时解耦中立配置虽严格等价于 v9，却把"双臂协作才能完成"的任务降级成"两臂各自安全但任务失败"，即「结构优化在分布漂移时把未来才显贵的耦合当成当下冗余剪掉」。

## 1. 符号体系增量（定义 540–549）

**新增定义 540（协作图 Coordination Graph）** 双臂协作结构表示为 G_c = (V_c, E_c, r, m_share)：V_c = {A, B} ∪ V_shared（共享世界模型 W_shared、被抓物体 O_shared、共享任务规划器）；E_c ⊆ V_c×V_c 为跨臂耦合边，e=(u,v) 表示 u 的输出是 v 的输入且需跨臂同步；r = (r_A, r_B) ∈ {leader, follower, symmetric}²；m_share: V_shared → {shared, duplicated}。一个*结构配置* σ=(G_c, r, m_share)。σ 是离散拓扑对象——这是"结构优化"与 v9 ID（节点级）、v8 调参（连续参数级）的本质区别。

**新增定义 541（可容许拓扑族 Admissible Topology Family）** A_safe = {σ : I_struct(σ)}，结构不变式 I_struct 含四条：
- **(i) 监控独立性**：至少存在一个不依赖被优化对象（物体/共享模型）的臂间几何监控通道（MCC 独立测距），保证任意退化后仍有 mutual clearance 证据；
- **(ii) 所有权唯一性**：任一刚体同一时刻至多一个排他所有者（定义 544）；
- **(iii) 可退化性**：∀e∈E_c，删边配置 σ_{−e} 存在中立配置 σ^⊥_{−e}，其逐臂行为 ≡ v9 对应实例（解耦模式）；
- **(iv) 无环屏障**：会合屏障图无环，保证无死锁（引理 90）。
只有 σ∈A_safe 可实现；CSO 每次编辑必须落在 A_safe 内。

**新增定义 542（联合块与联合证书 Joint Chunk & Joint Certificate）** 联合决策单元 ζ^{AB}_t = (ζ^A_t, ζ^B_t, Ĉ^{AB}_t, P^{AB}_t)，ζ^a 为臂 a 的 v9 动作块。联合证书在逐臂界之外增加臂间最坏间隙：
```
ĝ^{AB}_min = min_{k ≤ min(K_A,K_B)} dist_path(s^A_k, s^B_k) − β^{AB}
```
联合证书有效 ⇔ 两臂证书各自有效 ∧ ĝ^{AB}_min ≥ d_safe^cross ∧ ê^{AB}_max ≤ τ_eff^AB ∧ 所有权前置满足。P^{AB} ⊆ {1..min(K_A,K_B)}。

**新增定义 543（相互停车不变式 Mutual Stopping Invariant）** 联合前缀 (p,q) 安全停驻 ⇔ 两臂同时刹停后轨迹间最小距离 ≥ d_safe^cross。实用保守充分条件（分离式刹车界）：
```
dist(s^A_p, s^B_q) − d_brake(v^A_p) − d_brake(v^B_q) ≥ d_safe^cross + δ_lat·1[对向]
```
联合中止点 p* = max P^{AB} ≤ 当前联合执行步；P^{AB} 为空则拒绝联合块并退化为串行化（定义 547）。

**新增定义 544（协调契约与所有权账本 Coordination Contract & Ownership Ledger）** 跨臂契约 κ^c_{a→b} = (F_shared, pre_own, Barrier_{a→b}, D^c, v^c_⊥, guard_b)。pre_own 为所有权前置；Barrier 为会合屏障（双方到达才放行）；D^c 为协调截止期；中立元 v^c_⊥ = decouple（断开该边、工作空间分区）。所有权账本 o_t: O_shared → {none,A,B,shared}，转移为两阶段提交（intent→ack→commit），受 D_handoff 约束；超时注入 v^c_⊥ 而非阻塞。唯一性由原子 CAS 保证。

**新增定义 545（结构目标与结构编辑 Structural Objective & Edit）**
```
J_struct(σ) = norm(Prog(σ)) − λ_c·C_coord(σ) − λ_s·(1 − Margin(σ)) − λ_t·Lat(σ)
```
邻域 N(σ)={角色互换, 边剪枝 e, 边新增 e', 共享/复制切换}。每 T_struct=1000 周期在 N(σ)∩A_safe 内做束搜索（beam=8）；接受需 ΔJ_struct > ΔJ_min 且连续 H_struct=3 次确认（定义 549）。

**新增定义 546（边级归因 Edge Attribution）** 把 v9 ID 的节点归因扩展为边归因：
```
c_e ← clip( 0.9·c_e + 0.1·norm( J_struct(σ) − J_struct(σ^⊥_{−e}) ), 0, 1 )
```
即断开 e、以解耦中立配置运行一个探针回合的边际收益。c_e < τ_off^e 且 σ_{−e}∈A_safe 的边进入剪枝候选；高 c_e 边进入保留集。边归因让结构优化有实证依据。

**新增定义 547（串行化退化 Serialization Fallback）** MCC 失效或联合证书连续无效时，两臂交替执行：任一时隙仅一臂 active，另一臂停驻于安全位姿 a^⊥（中立 hold），在联合块边界交换 active 臂；停驻臂不产生运动，间隙由静态分区屏障保障。逐臂轨迹 ≡ 交替的 v9 单臂 AC 执行（引理 88）。

**新增定义 548（角色与共享模式语义 Role & Sharing Semantics）** leader 臂负责规划与块生成，follower 臂以 leader 目标为输入做从属规划（协调代价低、耦合高）；symmetric 两臂独立规划 + DAC 协调（耦合低、可能冲突）。shared 世界模型只维护一份、两臂只读；duplicated 各自维护（更快、可能不一致）。role/sharing 都是调度与数据流选择，不改变单臂算法。

**新增定义 549（结构迟滞与无 Zeno Structural Hysteresis）** 结构编辑需 J_struct(σ')−J_struct(σ) > ΔJ_min 且连续 H_struct 个评估周期保持；两次被接受编辑间隔 ≥ T_struct。故结构翻转率 ≤ 1/(T_struct·Δt)，有限窗口内编辑次数有界，无拓扑抖振。

## 2. 形式化定义（要点与升级）

**定义 532/533（动作块/块证书）** 继承 v9；每臂各持一个 AC 实例。
**定义 535（中间件契约）** 继承 v9；DAC 在其上叠加跨臂端口，不修改原契约字段。
**升级定义 496（软证书，v10）** δ_trigger 增加双臂条件：`∧ ĝ^{AB}_min ≥ d_safe^cross ∧ 所有权前置成立`；联合证书失效与单臂条件同样触发 M₀ 硬检查。
**升级定义 531（软硬约束衔接）** M₀ 判据增加联合入口：任一联合守卫违规 ⇒ 立即联合中止或串行化，不等联合块边界。
**升级定义 539（有效块长门控）** 联合块长 K^{AB}_eff = min(K^A_eff, K^B_eff) 并额外受 ĝ^{AB}_min 余量门控；任一项破坏信任域即 K^{AB}_eff=1 并转串行化。

# ---------------- IP-357 CooperativeStructureOptimizer ----------------
@dataclass(frozen=True)
class StructConfig:
    roles: tuple          # ('leader','follower') / ('symmetric','symmetric') ...
    sharing: dict         # {'W_shared':'shared', 'planner':'duplicated'}
    edges: frozenset      # {('A','W_shared'), ('W_shared','B'), ...}

class CooperativeStructureOptimizer:
    def __init__(self, adm, objective, beam=8, T_struct=1000,
                 H_struct=3, dJ_min=0.02, lam=(1.0, 0.5, 1.0, 0.2)):
        self.adm, self.J = adm, objective        # adm: sigma -> bool (A_safe)
        self.beam, self.T_struct = beam, T_struct
        self.H_struct, self.dJ_min, self.lam = H_struct, dJ_min, lam
        self.sigma = None                        # 当前可容许配置
        self.pending, self.hold = None, 0

    def neighbors(self, sigma):
        yield StructConfig(swap_roles(sigma.roles), sigma.sharing, sigma.edges)
        for e in sigma.edges:                    # 边剪枝
            yield StructConfig(sigma.roles, sigma.sharing, sigma.edges - {e})
        for e in candidate_edges(sigma):         # 边新增
            yield StructConfig(sigma.roles, sigma.sharing, sigma.edges | {e})
        for k in sigma.sharing:                  # 共享/复制切换
            yield StructConfig(sigma.roles, toggle(sigma.sharing, k), sigma.edges)

    def propose(self, cycle_idx, ctx):
        if cycle_idx % self.T_struct:
            return self.sigma
        safe = [s for s in self.neighbors(self.sigma) if self.adm(s)]
        safe.sort(key=self.J, reverse=True)      # beam=8 取前 8
        cand = safe[: self.beam]
        if not cand:
            return self.sigma
        best = cand[0]
        if self.J(best) - self.J(self.sigma) <= self.dJ_min:
            self.pending, self.hold = None, 0
            return self.sigma
        if best != self.pending:                 # 结构迟滞（定义 549）
            self.pending, self.hold = best, 1
            return self.sigma
        self.hold += 1
        if self.hold >= self.H_struct:
            self.sigma, self.pending, self.hold = best, None, 0
        return self.sigma

    def attribute_edge(self, e, J_with, J_without):
        self.c_e[e] = 0.9 * self.c_e.get(e, 0.0) + \
                      0.1 * max(0.0, norm(J_with - J_without))   # 定义 546


# ---------------- IP-359 MutualClearanceCertifier ----------------
class MutualClearanceCertifier:
    def __init__(self, ac_a, ac_b, d_safe_cross=0.20, beta_ab=0.03,
                 delta_lat=0.02, d_brake=None):
        self.ac_a, self.ac_b = ac_a, ac_b
        self.d_safe_cross, self.beta_ab = d_safe_cross, beta_ab
        self.delta_lat = delta_lat
        self.d_brake = d_brake or (lambda v: 0.5 * v * v / 2.0)

    def generate_joint(self, sA, sB, trust_ok, ownership_ok):
        if not (trust_ok and ownership_ok):
            return None                          # 交 DAC 串行化（定义 547）
        ca = self.ac_a.generate_chunk(sA, ...)    # v9 逐臂块
        cb = self.ac_b.generate_chunk(sB, ...)
        if ca is None or cb is None:
            return None
        K = min(len(ca.actions), len(cb.actions))
        g_ab = min(self.dist(ca.path[k], cb.path[k]) for k in range(K)) - self.beta_ab
        if g_ab < self.d_safe_cross:             # 联合证书无效
            return None
        pts = [ (p, q) for p in range(K) for q in range(K)
                if self.mutual_stop_ok(ca, cb, p, q) ]      # 定义 543
        if not pts:
            return None                          # 无联合中止点 → 拒绝
        return JointChunk(ca, cb, JointCert(g_ab), pts)

    def mutual_stop_ok(self, ca, cb, p, q):
        sep = self.dist(ca.path[p], cb.path[q])
        need = self.d_brake(ca.speed[p]) + self.d_brake(cb.speed[q])
        if opposing(ca, cb):
            need += self.delta_lat
        return sep - need >= self.d_safe_cross

    def joint_guard(self, chunk, k, liveA, liveB):
        """≤0.2ms；返回 ('continue',k+1) / ('abort',(p*,q*)) / ('serialize',None)"""
        if not chunk.cert_still_valid(liveA, liveB):
            return self._nearest_joint_abort(chunk, k) or ('serialize', None)
        if not self.mutual_stop_ok_live(liveA, liveB):
            return self._nearest_joint_abort(chunk, k) or ('serialize', None)
        return ('continue', k + 1)

class DualArmCoordinator:
    def __init__(self, contracts, ledger):

        self.barriers = {}

    def acquire(self, arm, obj, t):
        """两阶段提交：intent→ack→commit；超时注入 v^c_⊥=decouple"""
        if not self.ledger.precondition(arm, obj):     # 所有权唯一性（I_struct ii）

        self.decouple(arm)                             # 超时不阻塞，退化
        return False

        return b.arrive(arm_b, deadline=t + D_rendezvous)  # 无环 → 无死锁

## 4. 推导

**引理 87（联合证书可靠性与相互中止安全性）** 设信任域内逐臂前向模型误差 ≤ β^a、臂间误差 ≤ β^{AB}。若联合证书有效，则 (i) 块内每臂满足逐臂保守界；(ii) 臂间最小距离 ≥ d_safe^cross；(iii) 若块内某时刻联合间隙跌破 d_safe^cross，则存在联合中止点 (p*,q*)∈P^{AB} 使两臂同时安全停驻。证明：(i) 同引理 82；(ii) 由 ĝ^{AB}_min 取 min 与一致误差界，真实臂间距离 ≥ ĝ^{AB}_min + β^{AB} − β^{AB}_true ≥ d_safe^cross；(iii) 相互停车不变式（543）保证从 (p*,q*) 同时刹停后分离 ≥ d_safe^cross，且骨架要求 P^{AB} 非空才接受联合块，否则退化为串行化。∎

**引理 88（串行化组合等价性）** 关闭 MCC，按定义 547 交替执行两臂，则每臂轨迹与 v9 单臂 AC 在该臂上单独执行逐位相同。证明：停驻臂注入中立 hold a^⊥，不产生状态更新；active 臂时隙内运行与 v9 相同的 AC 块生成/守卫，跨臂边被 DAC 断开、无跨臂输入，故逐周期动作序列相同。∎

**引理 89（结构安全不变式与 v9 投影）** 对任意 σ∈A_safe，CSO 实现后的行为可投影到 v9 退化格点：剪除 E_c 得解耦模式（两独立 v9 环 + 静态分区屏障）；role 赋值是调度置换；shared→duplicated 等价于两臂各自本地模型（v9）。故任意可容许结构下的安全性由 v9 引理 82–86 逐臂传递。证明：由 I_struct(iii) 每条边有 v9 等价中立配置，I_struct(i) 保证剪除后仍有独立监控；对单边编辑归纳，A_safe 对邻域编辑闭合，故投影关系保持。∎

**引理 90（结构无死锁与无活锁）** 屏障图无环 + 所有权账本原子两阶段提交 ⇒ 不存在循环等待，无死锁；退化只删边/加分区，单调降低耦合，不产生新环；所有权超时注入 decouple 截断等待链，故无活锁。证明：无环定向图不存在环等待；所有权转移在 D_handoff 超时解耦；CSO 编辑在 A_safe 内且 I_struct(iv) 保持无环。∎

**引理 91（结构优化终止 / 无 Zeno）** 平稳任务分布下，每次被接受编辑使 J_struct 严格下降 ≥ ΔJ_min 且 J_struct 有下界 ⇒ 编辑次数有限；漂移分布下，结构迟滞 (H_struct,T_struct) 给出翻转率上界，任意有限窗口内编辑次数有界，无拓扑抖振。∎

**引理 92（双臂预算保持）** DAC 跨臂记账 ≤0.2ms/cycle、MCC 联合守卫 ≤0.2ms/cycle；shared 模式共享模块只算一次，duplicated 付两次；若两臂共享决策预算 B_dec^AB，部署期校验 Σ_m Ŵ_m + 跨臂开销 ≤ B_dec^AB，shared 相对 duplicated 节省 ≥ Σ_{V_shared} Ŵ_m。解耦模式下逐臂严格保持 v9 预算（引理 86）。∎

## 8. 本轮最大风险

**一句话**：结构优化依赖边归因 c_e 判定"哪条耦合冗余"，而 c_e 是在**当前任务分布**下测得的——一旦分布漂移（例如被抓物体由刚体变为可形变、必须双臂共享同一世界模型才能维持约束），CSO 可能恰好剪掉了安全所依赖的那条边，此时解耦中立配置虽严格等价于 v9，却把"双臂协作才能完成"的任务降级为"两臂各自安全但任务失败"，即「结构优化在分布漂移时把未来才显贵的耦合当成当下冗余剪掉」。
