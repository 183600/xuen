### 第 6 轮灵感驱动研究记录

**灵感词**：柔顺控制、消融实验

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把提议升级为条件流匹配、记忆升级为嵌入固化、人因升级为情感调制，并用定理 6（证书不变性）把框架推广为「任意生成器 + 认证边界」。但 v5 仍藏着两个未言明的结构性假设：(a) 七门认证的是**规划轨迹 x**，不是**被柔顺身体实际执行的轨迹 x'**——规划与实现之间存在一条没有被任何证书覆盖的鸿沟；(b) 消融实验只是惯例式附录，没有形式语义，无法区分「可证单调的消融」与「必须靠实验的非单调消融」。本轮两个灵感词统一为主题「认证柔顺执行与可证消融」（Certified Compliant Execution & Certifiable Ablation, CCE-CA），形成 CADVS-v6（IP-497~500）。自律不变：**硬门数量仍为七**，柔顺实现只经「阈值鲁棒外扩 + 物理门内部通道」接入，消融只经「证书演算的对偶算子」接入。执行集嵌套升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29——注意 v6 的规划集更小，但其实现轨迹被保证落在 v5 执行集之内。

**直觉与动机**：

1. **柔顺控制 → 把证书从「计划空间」搬到「实现空间」**。v5 的门读入一条位姿/力时间序列，仿佛机器人是一台理想的位置源。真实的机器人是柔顺体：执行器饱和、模型误差、接触力、阻抗增益有限，都会让实际轨迹 x' 偏离规划 x。若偏离无界，则 v5 的证书只是关于一个虚构对象的证明。引入**能量罐（energy tank）变阻抗/导纳控制器**：罐内能量 E_t ≥ 0 时控制器才允许注入主动功，从而把「机器人-环境」耦合系统约束在无源包络内（接触稳定性的物理前提）；同时由阻抗刚度 K_p、已认证的力矩上界 W_max、模型误差界 δ_model 导出**实现误差界 ε_real ≤ (W_max + δ_model)/λ_min(K_p) + e_trans**。关键的自洽性在于：门本来就限制了 ‖wrench‖ ≤ W_max，而 W_max 又反过来界定 ε_real——这形成一个可检验的不动点，而非循环论证。把 ε_real 经门的 Lipschitz 常数 L_i 外扩到阈值：**τ_i^6 = γ_i·τ_i^4 + L_i·ε_real（只紧不松）**，则任何在 ε_real 内被实现的 x' 都仍满足 v5 的原始门。柔顺不是新增一道门，而是把「物理门」的内部证据从「计划可行」加强为「计划可行且可被无源实现」。接触模式（自由/建立/稳定/滑动/断开）进入证书上下文，由 BCK 的事件触发与增益调度、能量罐重置共享同一状态机。

2. **消融实验 → 把消融从「仪式」变成「可证算子」**。几乎每篇系统论文都有消融表，但绝大多数消融是「删掉一个模块看指标」，既没有声明它证明了什么，也无法处理模块间的交互效应。本轮把消融形式化为执行集上的算子：模块集合 M 的幂集 (2^M, ⊆) 构成**消融格**；每个模块要么是**收紧算子** T_m（T_m(E) ⊆ E，如额外阈值、新颖度否决、实现边际），要么是**提议/使能算子** P_m（改变候选分布或可执行性，不单调改变执行集）。对收紧类可证：**消融 A^T_S 的执行集 ⊇ 完整系统执行集**，因此「在消融下出现、在完整系统不出现的真值安全违例」就是被删模块的**必要性见证**——这把消融表从描述性附录升级为因果归因的证书。对提议类只能给经验界，必须做实验；两类混在一起做消融，是当前文献里最普遍的方法论错误。进一步用 coarea 公式给出**消融界** |Vol(A_m) Δ Vol(full)| ≤ C_m·Δτ_m，据此把有限实验预算优先分配给「预测影响最大」的消融（主动实验设计），而不是平均地跑满整张表。

3. **统一视角 → 精化与消融是执行集上的互逆单调算子**。CADVS 的整条阶梯（v29 → … → v5 → v6）是一串收紧算子的复合；消融则是把这些算子逐个拆掉。二者之差恰好是**认证的价格（price of certification）**：安全边际、成功率、可用工作空间之间的可量化兑换率。这个视角让「加模块」与「减模块」第一次共享同一套偏序语言，也让「这个模块到底值不值」变成一个可计算的问题。

**关键洞见**：v4 回答「提议=规则时七门是否足够」；v5 回答「提议=任意生成器时证书边界是否不变」；v6 回答「被认证的计划能否在一个柔顺、受限、会接触的物理身体上被真实执行，并且每一份安全边际能否被因果归因」。七硬门记号 kc_evidence_forged_v4 原样复用；本轮新增的只有：实现核 PERK、实现边际 RRM（τ^6）、消融核 CAK；软评分不改（ECS_v6 = ECS_v5，实现边际只进硬门阈值，不进软分）。

**形式化目标（增量）**：
1. 柔顺实现：能量罐阻抗/导纳律，无源性条件 E_t ≥ 0，跟踪误差界 ε_real（引理 45）。
2. 实现鲁棒门：τ_i^6 = γ_i·τ_i^4 + L_i·ε_real（只紧），Exec^ε_v6 = {x : ∧_i s_i(x) ≥ τ_i^6}；定理 9 保证 ε_real 内的实现轨迹 x' ∈ Exec_CADVS-v5。
3. 消融格：2^M 上的收紧/提议二分，收紧消融 A^T_S 可证单调；提议消融 A^P_S 只给经验界。
4. 定理 9（实现鲁棒性）、定理 10（接触切换下的无源性合成）、定理 11（消融单调性与必要性见证）、定理 12（coarea 消融界与主动实验设计）；引理 45~47。
5. EFA-v6：七门 + 实现边际 + 无源性包络 + 消融台架，门集合与锚点集合不变。

**本轮最大风险**：柔顺实现的 ε_real 证书与消融结论都建立在同一个名义接触模型上——模型乐观则证书与消融实验一起自证失效（sim-to-real 循环），模型保守则执行集在接触富集任务上塌缩为空；「可证性」本身被模型误差绑架，真值始终在环外。

## 2. 关键算法骨架

### IP-497 PERK：无源性包络柔顺实现核（1 kHz 控制环内，O(n_dof)）

```python
@dataclass
class PassivityEnvelopeRealizationKernel:
    """PERK：把认证轨迹 x 实现为无源包络内的柔顺执行 x'。
    定理 9：实现误差 ε_real 有界 ⇒ 阈值外扩后 x' 回到 v5 执行集。
    定理 10：接触切换在速度匹配 + 有界注入下保持无源性。"""
    Kp: np.ndarray                 # 任务空间刚度（对称正定）
    Kd: np.ndarray                 # 任务空间阻尼
    E_tank: float = 1.0            # 能量罐（J），初始预算
    E_tank_max: float = 2.0
    beta_max: float = 1.0
    mode: str = 'free'             # free/making/stable/sliding/breaking
    e_trans: float = 2e-3          # 瞬态误差项（由带宽标定）

    def command(self, x_ref, q, dq, F_ext, dt) -> np.ndarray:
        # 期望力 = 阻抗反馈 + 前馈；再用能量罐决定可注入的主动功比例
        F_cmd = (self.Kp @ (x_ref.p - p(q))
                 + self.Kd @ (x_ref.v - J(q) @ dq)
                 + x_ref.F_ff)
        P_in = float(F_cmd @ (J(q) @ dq))
        # β 只在罐内有能量时允许注入；耗尽即退化为纯阻尼（被动）
        beta = min(self.beta_max,
                   max(0.0, self.E_tank / max(P_in * dt, 1e-9)))
        self.E_tank += (beta * P_in - P_diss) * dt
        if self.E_tank < 0.0:          # 数值兜底：绝不透支
            beta = 0.0
            self.E_tank = 0.0
        return J(q).T @ (beta * F_cmd) + g(q) + C(q, dq) @ dq

    def epsilon_real(self, W_max: float, delta_model: float) -> float:
        # 引理 45：准静态误差 + 瞬态项；刚度越大误差越小但力越硬
        return (W_max + delta_model) / float(np.min(np.linalg.eigvalsh(self.Kp))) \
               + self.e_trans

    def on_contact_event(self, new_mode: str) -> None:
        # 接触模式切换：速度匹配软着陆 + 有界能量注入 + 增益调度
        self._velocity_match()                 # 降低冲击能量
        self.E_tank = min(self.E_tank + E_budget, self.E_tank_max)
        self._schedule_gains(new_mode)         # 自由/接触/滑动不同阻抗
        self.mode = new_mode
        # 诚实边界：刚性碰撞下无源性不可保证，只能靠软接触/速度匹配限损
```

### IP-498 RRM：实现鲁棒边际与 ε 预算自洽（离线 + 每周期 O(1)）

```python
def realization_robust_thresholds(tau4, gamma, L, eps_real):
    """定理 9 的工程形式：阈值只上抬，绝不下调。"""
    return {i: gamma[i] * tau4[i] + L[i] * eps_real for i in tau4}


def epsilon_budget_consistent(perk, gates, W_max, delta_model, slack):
    """自洽不动点：ε_real 依赖 W_max，收紧阈值又使 W_max 变小。
    返回 (eps_real, ok)。若某门 L_i·eps_real > slack_i，则 fail-closed，
    不进入该任务（而不是偷偷放宽界）。"""
    eps = perk.epsilon_real(W_max, delta_model)
    ok = all(L[i] * eps <= slack[i] for i in gates)
    return eps, ok
```

```python
# 引理 45：阻抗控制下的实现误差界
def lemma_tracking_error_bound() -> str:
    """

    加上瞬态项 e_trans。取 W_max ≥ sup‖F_ext‖、δ_model ≥ sup‖Δ‖ 即得 ε_real。
    证明：由闭环刚度方程 K_p e = F_ext + Δ 取范数。∎
    """
    return "Proven (quasi-static); transient term empirical"

# 引理 46：能量罐无源性
def lemma_energy_tank_passivity() -> str:
    """
    引理 46（能量罐无源性）：若 Ė_t = β·P_in − P_diss 且 E_t ≥ 0、β∈[0,1]，
    则控制器对外端口 (v, F) 的供给率满足 s = F^T v ≥ −Ė_t + P_diss，
    即存储函数 E_t 使闭环无源。E_t=0 时 β=0，退化为纯阻尼。
    证明：标准能量罐构造（Franken et al.; Schindlbeck & Haddadin）。∎
    """
    return "Proven"

# 引理 47：门评分的 Lipschitz 传播
def lemma_lipschitz_propagation() -> str:
    """
    引理 47：若 s_i 在度量 d 下 L_i-Lipschitz，且 ‖x'−x‖ ≤ ε_real，
    则 s_i(x') ≥ s_i(x) − L_i·ε_real。故 s_i(x) ≥ τ_i + L_i·ε_real ⇒ s_i(x') ≥ τ_i。
    证明：Lipschitz 定义直接展开。∎
    """
    return "Proven"

# 定理 9：实现鲁棒性（本轮理论主轴）
def theorem_realization_robustness() -> str:
    """
    定理 9（实现鲁棒性）：设控制器无源（引理 46）且 ‖x'−x‖ ≤ ε_real（引理 45），
    门评分满足引理 47。若 x ∈ Exec^ε_v6 = {x : ∧_i s_i(x) ≥ τ_i^5 + L_i·ε_real}，

    意义：把证书从「计划可行」升级为「可被无源身体实现」。
    """
    return "Proven (given ε_real bound holds)"

# 定理 10：接触切换下的无源性合成
def theorem_passivity_composition() -> str:
    """
    定理 10：若每次接触模式切换执行速度匹配软着陆、注入能量 ≤ E_budget 且有界，
    能量罐按引理 46 重置，则分段连续闭环在每段无源，跨段总注入能量 ≤ N_switch·E_budget，
    系统 L2 稳定（相对有界注入）。刚性瞬时碰撞不满足前提，需软接触/速度匹配。
    证明：逐段无源 + 有界注入的耗散性串联。∎
    诚实边界：冲击瞬间的无源性无法用连续能量罐覆盖，只能限损。
    """
    return "Proven (soft contact); rigid impact excluded"

# 定理 11：消融单调性与必要性见证
def theorem_ablation_monotonicity() -> str:
    """
    定理 11（消融单调性）：若 S ⊆ M 且 S 中模块均为收紧算子 T_m（T_m(E) ⊆ E），
    则 Exec(A^T_S) ⊇ Exec(full)。于是 W_S = Unsafe(Exec(A^T_S) \ Exec(full))
    中每个样本都是 S 的必要性见证：删掉 S 会让一个真值不安全的轨迹通过。
    证明：收紧算子复合对逐点偏序单调，删去收紧项只能放宽。∎
    边界：提议/使能类 P_m 不满足此性质，其消融必须做实验，不能声称单调。
    """
    return "Proven for T-class; P-class empirical only"

# 定理 12：coarea 消融界与主动实验设计
def theorem_ablation_bound() -> str:
    """
    定理 12（消融界）：对阈值型收紧算子，|Vol(Exec(A_m) Δ Exec(full))|
    ≤ C_m·Δτ_m，其中 C_m 为 s_m 水平集的 (d−1) 维测度（coarea 公式）。
    推论：可按 C_m·Δτ_m 排序消融影响，把 N_abl 预算优先给预测影响最大的模块；
    预测-实测秩相关用于检验界是否可用。
    证明：体积对阈值的导数 = 水平集测度（coarea）。∎
    诚实边界：高维下 C_m 估计样本需求大；界是上界，可能松。
    """
    return "Proven (coarea); C_m estimation sample-hungry"
```

### IP-500 EFA-v6：七硬门 + 实现边际 + 无源性包络 + 消融台架

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：七硬门不变；阈值 τ^6=γτ^4+Lε（只紧）；
    实现由 PERK 无源包络承担；消融台架离线运行。"""
    v5: EvidenceForgingAssemblerV5
    perk: PassivityEnvelopeRealizationKernel
    rrm: Any                       # realization_robust_thresholds / epsilon_budget
    cak: CertifiableAblationKernel

    def select(self, x0_state, t_now, rule_id, context):
        # 1) v5 提议与级联（原样）
        ok5, x, tag = self.v5.select(x0_state, t_now, rule_id, context)
        if not ok5:
            return ok5, None, tag
        # 2) 实现误差界与自洽检查
        W_max = self.v5.certified_wrench_bound(x)
        eps, feasible = self.rrm.epsilon_budget_consistent(
            self.perk, self.v5.gates, W_max, DELTA_MODEL, self.v5.slack)
        if not feasible:
            return False, None, 'REALIZATION_BUDGET_INFEASIBLE'   # fail-closed
        # 3) 用实现鲁棒阈值复核七门（只紧）
        tau6 = self.rrm.realization_robust_thresholds(
            self.v5.tau4, self.v5.gamma, self.v5.L, eps)
        if not self.v5.recheck(x, tau6):
            return False, None, 'REALIZATION_MARGIN_REJECT'
        # 4) 下发给 PERK，携带接触模式与能量预算
        self.perk.on_contact_event(context.contact_mode)
        return True, x, 'FORGED_CCE'

    def run_ablation_suite(self, budget: int):
        """离线：只对收紧类做可证单调消融；对提议类按主动设计做实验。"""
        t_plan = self.cak.active_design(budget)
        return {
            'tightening_proofs': {S: self.cak.necessity_witness(S)
                                  for S in self.cak.T_class_subsets()},
            'proposal_experiments': [self._run_experiment(m) for m in t_plan
                                     if m in self.cak.P_class],
            'interactions': self.cak.leave_two_out(self.cak.high_impact_pairs()),
        }
```

### 集成流水线（v5 → v6）

```
离线/慢时域：
  实现标定：随机模型误差/接触工况 → 拟合 δ_model、e_trans、L_i
  消融规划：coarea 界排序 → 收紧类出必要性见证（免实验）→ 提议类做主动实验
  无源性审计：能量罐轨迹、冲击注入、模式切换抖动 → 回归门

在线准入（异步，秒级）：
  v5 级联选证 → 认证 W_max → ε_real 自洽检查（不可行即 fail-closed）
       → τ^6=γτ^4+Lε 复核七门 → 下发 PERK（接触模式 + 能量预算）

在线控制环（目标 < 0.7 ms，含柔顺律）：
  PERK.command（能量罐 O(n_dof)） + EEK + BCK（事件触发）
  接触事件：速度匹配 + 罐重置 + 增益调度（与 BCK 共享状态机）
```

## 4. 正确性论证（增量更新）

### 引理 45（阻抗实现误差界）

**陈述**：任务空间阻抗控制在外部力 F_ext 与模型误差 Δ 下，准静态误差 ‖e‖ ≤ (‖F_ext‖ + ‖Δ‖)/λ_min(K_p)；含带宽/饱和时加瞬态项 e_trans。取 W_max ≥ sup‖F_ext‖、δ_model ≥ sup‖Δ‖，得 ε_real。**证明**：闭环刚度方程 K_p e = F_ext + Δ 取范数。∎

**诚实边界**：瞬态项 e_trans 只能标定不能证明；饱和、摩擦、间隙会让界变松或失效。

### 引理 46（能量罐无源性）

**陈述**：若 Ė_t = β·P_in − P_diss 且 E_t ≥ 0、β ∈ [0,1]，则端口供给率 s = F^T v ≥ −Ė_t + P_diss，存储函数 E_t 使闭环无源。**证明**：标准能量罐构造。∎

### 引理 47（门评分 Lipschitz 传播）

**陈述**：s_i 为 L_i-Lipschitz 且 ‖x'−x‖ ≤ ε_real ⇒ s_i(x') ≥ s_i(x) − L_i·ε_real。**证明**：Lipschitz 定义。∎

### 定理 9（实现鲁棒性，总装）

**陈述**：在引理 45/46/47 下，x ∈ Exec^ε_v6 ⇒ x' ∈ Exec_CADVS-v5；且 Exec^ε_v6 ⊆ Exec_v5。**证明**：逐门 s_i(x') ≥ s_i(x) − L_i ε_real ≥ τ_i^5。∎

### 定理 10（接触切换无源性合成）

**陈述**：速度匹配软着陆 + 有界注入 E_budget + 罐重置 ⇒ 分段无源、L2 稳定（相对有界注入）；刚性碰撞不满足前提。**证明**：逐段无源 + 有界注入串联。∎

### 定理 11（消融单调性与必要性见证）

**陈述**：S ⊆ 收紧类 ⇒ Exec(A^T_S) ⊇ Exec(full)，且 W_S = Unsafe(Exec(A^T_S) \ Exec(full)) 为必要性见证。**证明**：收紧算子复合的逐点单调性。∎

**诚实边界**：提议/使能类消融不满足单调性；混合消融的单调性不成立，必须实验。

### 定理 12（coarea 消融界）

**陈述**：阈值型收紧消融满足 |Vol(A_m) Δ Vol(full)| ≤ C_m·Δτ_m；可据此排序并主动分配实验预算。**证明**：体积对阈值求导 = 水平集测度（coarea）。∎

**诚实边界**：C_m 高维估计样本需求大，界可能很松；只作优先级信号，不作安全性证明。

### 定理 v6（实现-消融总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 实现误差 ≤ ε_real、(B9) 接触切换满足速度匹配与有界注入下：
(i) Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29；
(ii) 实现鲁棒：x ∈ Exec^ε_v6 ⇒ x' ∈ Exec_v5（定理 9）；
(iii) 无源合成：软接触下 L2 稳定，冲击限损（定理 10）；
(iv) 收紧消融单调、必要性见证有效（定理 11），提议消融仅经验（诚实边界）；
(v) 消融影响可由 coarea 界排序（定理 12）；
(vi) 七锚完备性保持（v5 定理 8），柔顺是物理门内部通道、消融是证书演算对偶。

**证明**：(i) 阈值只紧 + 同门；(ii)(iii)(iv)(v) 分别由定理 9/10/11/12；(vi) 锚点集合不变。∎

**诚实声明**：(B8) ε_real 依赖名义模型与标定工况，跨工况外推无保证；(B9) 刚性冲击无源性不可证；(iv) 提议类消融与交互效应仍只能经验判断；(vi) 消融结论的可迁移性受 sim-to-real 鸿沟限制。

## 5. 实验设计与初步结果（仿真，单机；实机/舰队列入第 7 轮）

### 5.1 实验设计

- **平台**：MuJoCo 3.x + MJX，接触富集任务（插销、擦拭、开门、柔性抓取）；随机化模型误差（质量/摩擦/延迟）注入作为 δ_model 采样源；独立「真值」接触模型用于判定实现层安全违例（与证书模型不完全同源，但仍是仿真，见诚实边界）。
- **对照**：v5-full、v6-full；实现类消融 A1（无实现边际，用 v5 阈值）、A2（纯阻抗无能量罐）、A3（固定阻抗 vs 接触模式调度）、A4（无速度匹配软着陆）；消融方法类 A5（OAT 全表 vs 主动设计）、A6（收紧/提议混做 vs 分离）。
- **收紧类（可证单调，出必要性见证，免全量实验）**：新颖度门、证书过滤、实现边际、情感调制 γ、记忆计数否决。
- **提议类（非单调，需实验）**：流提议、记忆条件、情感软因子、级联预筛、可行性先验。
- **交互**：对 coarea 预测高影响模块做 leave-two-out，检验非可加性。
- **指标**：实现空间安全违例率、无源性/接触失稳率、力超调 P99/限值、ε_real 界覆盖率（实现误差 ≤ 界的比例）、规划执行集体积、空集（认证瘫痪）率、任务成功率、必要性见证数、coarea 预测-实测 Spearman、主动设计节省的完整重跑数、OAT 与 leave-two-out 差异。

## 7. 本轮最大风险（最终确认）

**一句话**：**柔顺实现的 ε_real 证书与消融结论都建立在同一个名义接触模型上**——模型乐观则证书与消融实验一起自证失效（sim-to-real 循环），模型保守则执行集在接触富集任务上塌缩为空；「可证性」本身被模型误差绑架，真值始终在环外。
