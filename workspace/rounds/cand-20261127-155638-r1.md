## 1. 直觉与动机（两个灵感的碰撞）

### 灵感 1｜安全交互：安全不是减速，而是「成功路径上的非受迫失败消除」

**直觉**：这场比赛的评分表里没有单独一栏叫「安全」，但安全是成功率的**隐形乘数**。真正悄悄吃掉成功的只有几类**非受迫失败**：撞翻相邻物、夹空/夹偏、抬升滑落、挤压/溢出（PourOutMedicine、SyringeWaterTransfer）、自碰撞、以及人机距离不足。更关键的是反直觉点：**最安全的策略不是最慢的策略，而是把可预防失败从成功路径上删掉的策略**——因为「为了安全而停下」在 180s 预算下等于超时失败。

**严谨定义**：设策略已具备完成任务所需的技能，定义**非受迫失败**为：由动作越界、接触失稳、抓取失效、人机距离不足等**可预防因素**导致的失败。安全交互的目标不是最大化保守性，而是

```
maximize   S = E[ 1(task success) ]
subject to Pr(catastrophic failure) ≤ ε,   abstention ≡ failure（禁止以停换安）
```

据此把安全拆成**三层可独立消融**的机制，按「先硬后软、先检测后选择」排序：硬几何包络（每动作合法集投影，零学习）→ 抓取状态监控（每阶段假设检验）→ 示范密度软先验（每 chunk 的 OOD 风险打分）。

### 灵感 2｜机械臂抓取：1-DOF 夹爪把抓取成败压缩成三个可观测变量

**直觉**：32 个任务几乎都建立在「抓取→搬运→放置」这条主干上，抓取是承重原语。接口把灵巧手压成 1-DOF 夹爪（F20）后，抓取质量只剩三件事：**接近位姿、闭合时机、抬升验证**。而最贵的失败不是「抓不到」，而是**抓到了坏抓取却没人发现**——策略自信地执行一条注定失败的长轨迹，把 180s 烧光。一个抓取成功监控 + 快速失败重抓，能把「沉默的失败」变成「可恢复的重试」。反直觉点：**抓取成败比看起来更可观测**——夹爪开合轨迹 + 腕相机的物体相对运动，足以在没有力传感器时推断「夹空/滑落/夹稳」。

**严谨定义**：抓取状态 `g_t ∈ {0,1}`，单步观测

```
o_t = ( g_cmd, g_obs, Δ_wrist(物体相对腕相机位移), on_table(全局相机物体是否仍在桌面) )
```

1-DOF 夹爪下「抓稳」的可观测签名是：`g_obs` 在物体宽度附近**停滞**、`Δ_wrist ≈ 0`、`on_table` 由 1→0。把监控写成贝叶斯滤波 `P(g_t | o_{1:t})` 与**最优停止**：当 `P(g_t=1) < τ_low` 连续 k 步即触发重抓，`τ_low, k` 由「180s 预算下最大化期望成功率」反解。

### 灵感 3｜交叉：示范即安全流形，安全应分三个时间尺度

**直觉**：官方示教全是**成功且安全**的轨迹——所以示教分布本身就是一张「安全流形」。于是安全可以用三层、三个时间尺度来落地：每动作（硬包络，微秒级，保证合法）、每阶段（抓取监控，毫秒级，保证不带着坏抓取空跑）、每 chunk（示范密度 + 风险敏感选择，摊薄到 8–16 步，捕捉溢出/挤压/邻近碰撞这类语义风险）。统一的反直觉点：**数据里没有失败，但「偏离安全流形」本身就是一个失败预测器**——不需要失败样本，也能学到风险的边界。

**严谨定义**：把示范集 `D={(s_i,a_i)}` 视为安全流形 `M` 的样本。定义软风险

```
R(s,a) = -log p_D( z(s), a )      # z = VLM/DINO 观测特征；低密度 ⇒ OOD ⇒ 高风险
```

三层协同：硬包络 `Π_S(a)` 给出**可证明的合法动作**；抓取监控给出**阶段级失败后验**；软先验 `R` 给出**语义级风险排序**。任何一层都必须满足：净成功率增益 > 其延迟/复杂度成本。

### 三者统一

安全交互回答「哪些失败可以且必须被消除」，机械臂抓取回答「最大的可消除失败源在哪里（抓取主干）」，示范即安全流形回答「没有失败数据时风险从哪里学」。结论：**本轮的中期胜负手是把「抓取主干上的非受迫失败」用零/低成本机制清掉——硬包络保合法性、抓取监控保不空跑、密度先验保语义风险；一切以成功率为准绳，不以保守为美德。**

## 4. 设计原则（新增 PR6/PR7，其余保留）

- **PR6 安全即成功率保险**：任何安全机制必须给出「净成功率增益（或步骤分并列增益）> 延迟/复杂度成本」的证据；**以超时换安全的退化解一律剪掉**。
- **PR7 三时间尺度分层**：硬包络（每动作，保证）→ 抓取监控（每阶段，检测）→ 密度/风险选择（每 chunk，择优）；每层可独立消融、可单独裁撤。
- PR1–PR5 保留（v1.0/v1.1）。

## 2. 本轮新增/升级项（详细六要素）

### I4 v2 人机干预门控 + 安全距离 + 预算内恢复 ★★★★★（升级）
- **动机**：人为干扰是 5 轴之一、每任务 2/10 次（F21），直接进成功率；v1.1 只做「检测到人手→停持」，但**停太久=超时失败**。
- **与现有方案差异**：从「被动停」升级为「**可预测让位 + 预算内恢复**」：检测到手/人 → 沿远离方向低速平滑让位（保持动作连续、可预测，避免抽搐）→ 人手离开后**在剩余预算内**重估并续做，而非无限停持。
- **技术可行性**：高。手部检测 + `obs_delta_indices` 历史栈（<50ms）；状态机 `NOMINAL→HUMAN_NEAR→YIELD→RESUME→NOMINAL`；恢复门限 = 剩余时间 > 预计续做时间 × 安全系数。
- **所需资源**：1 人周；复用 I10 的平滑/限速投影。
- **落地步骤**：①手/人检测与距离阈值标定；②让位轨迹生成（最小位移 + 平滑）；③恢复门限与超时保护；④L0 用近失增广回放测「让位不误触发」；⑤L2 干扰轴真机抽测。
- **风险**：误检导致频繁让位；缓解：滞回 + 距离双阈值 + 只在连续 k 帧确认后触发。

### I10 安全包络投影层（硬约束）★★★★★（新）
- **动机**：F24 确认 stub **不夹取任何范围**，越界动作的后果自负；F23 又把动作统计规律性纳入可信度。一个零学习的硬包络同时解决「合法性」与「可信度」，且成本近零。
- **与现有方案差异**：多数队伍只靠模型输出「碰运气」；本点在返回 chunk 前做**可证明的合法集投影**，保证不发出越界/突跳/穿桌动作。
- **严谨定义**：安全集
  ```
  S_t = { a : q ∈ [q_min, q_max], |Δq| ≤ v_max, |Δ²q| ≤ a_max,
              gripper ∈ [0,1], pivot ∈ bounds,
              ee_z ≥ table_z + ε, ee ∈ reachable_workspace }
  ```
  投影 `Π_S(a) = argmin_{a'∈S} ||a − a'||`。盒约束用 **clamp（精确欧氏投影）**；碰撞/桌面用**法向推出**；整段 chunk 若投影后仍不可行则**截断到可行前缀**并提前重查询。**边界来源优先用示教动作分位数（0.1–99.9%）校准**（比物理极限更贴任务分布，避免夹死），URDF 作兜底。
- **技术可行性**：高。纯几何/本体，`control_space` 感知（joint 夹关节/速度；ee 夹工作空间/净空/姿态）。
- **所需资源**：<1ms/步；1 人周。
- **落地步骤**：①从示教统计各维分位数；②实现盒投影 + 桌面净空 + 平滑（二阶差分）；③离线回放：对示教动作投影，测「偏离原动作」分布，要求成功率代理损失 ≤ε；④接入 `get_action` 返回前；⑤L1 析因（on/off）。
- **风险**：包络过紧夹死必要快速动作 → 成功率下降；缓解：分位数 + 分任务校准，L0 先验证任务保持率。

### I11 抓取状态贝叶斯监控 + 早停重抓 ★★★★★（新）
- **动机**：抓取是 32 任务的主干；最贵的失败是「坏抓取未被发现，烧光 180s」。1-DOF 夹爪 + 腕相机使抓取成败高度可观测（F20）。
- **与现有方案差异**：v1.1 的 I5 只在「已决定恢复」后执行；本点补上**检测端**：用贝叶斯后验判断抓取是否成立，快速失败并重抓，把沉默失败转为可恢复重试。
- **严谨定义**：`g_t∈{0,1}`，观测 `o_t=(g_cmd, g_obs, Δ_wrist, on_table)`。对数似然比
  ```
  LLR_t = w1·stall(g_obs|object_width) + w2·(1−‖Δ_wrist‖/σ) + w3·(1−on_table) + b
  P(g_t=1|o_{1:t}) = σ(LLR_t + logit(P(g_{t-1}=1|o_{1:t-1})))
  ```
  「抓稳」签名：`g_obs` 在物体宽度处停滞、`Δ_wrist≈0`、`on_table` 由 1→0。「夹空」：`g_obs→0`。「滑落」：抬升后 `‖Δ_wrist‖` 突增或物体离腕视野。**早停规则**：`P<τ_low` 连续 k 步 → 触发 I5 重抓；`τ_low,k` 由「180s 预算下最大化期望成功率」的最优停止反解（重抓耗时 vs 继续空跑耗时）。
- **技术可行性**：高。本体特征 + 腕相机光流/模板跟踪 + 全局在位检测；轻量逻辑/小分类器。
- **所需资源**：<5ms/步；分类器训练 1 GPU 日；1 人周。
- **落地步骤**：①在示教上构造正负样本（正=抓取后稳定段；负=接近段夹空 + 人为注入滑落/时序平移）；②训练/标定 LLR 权重；③测 AUC 与检测延迟；④反解 τ/k；⑤接 I5 重抓；⑥L0 回放 + L2 抽测。
- **风险**：误报浪费预算、漏报放过坏抓取；缓解：滞回 + 双阈值 + 按物体族校准；只在 lift 后前若干步高灵敏、运输段降敏。

### I12 抓取阶段分解与门控安全控制 ★★★★（新）
- **动机**：同一套安全规则不适用于所有阶段——接近段怕撞、闭合段怕夹空、搬运段怕滑落、放置段怕倾倒。分阶段给不同限速/净空/监控强度，比全局一个阈值更省且更准。
- **与现有方案差异**：把「安全」从单一约束升级为**阶段条件约束** `Π_{S(φ_t)}`，φ_t 为阶段。
- **严谨定义**：阶段 `φ∈{approach, align, close, lift_verify, transport, place}`，由本体（夹爪开合、ee 速度）+ 腕相机接近度分类。每阶段一组规则：
  ```
  approach:   vmax=0.30, clearance=0.03, monitor=off
  align:      vmax=0.05, clearance=0.01, monitor=off
  close:      vmax=0.02, stall_check=on,   monitor=on
  lift_verify:vmax=0.10, monitor=on, abort_if=P(g)<τ
  transport:  vmax=0.40, monitor=on, obstacle_avoid=on
  place:      vmax=0.05, clearance=0.005, monitor=off
  ```
- **技术可行性**：高。阶段分类 <2ms；规则表可解释、可消融。
- **所需资源**：<2ms/步；1 人周。
- **落地步骤**：①用示教标注阶段（夹爪/ee 速度/腕距启发式）；②训练轻量阶段分类器；③规则表与 I10 投影合并；④L0 测阶段分类精度；⑤L2 抽测。
- **风险**：阶段误判导致规则错配；缓解：分类置信低时退化为「保守并集规则」；若精度 <90% 则并入 I11 后验。

### I13 示范密度软先验 + 风险敏感 chunk 选择 ★★★（新）
- **动机**：硬包络管合法性、抓取监控管抓取，但「溢出/挤压/邻近碰撞」这类语义风险两者都抓不到；示教全是安全样本，其分布本身可作为软风险先验。
- **与现有方案差异**：不训练失败分类器（无失败数据），用**安全流形的 OOD 距离**当风险；仅在 chunk 边界做，摊薄成本。
- **严谨定义**：
  ```
  R(s,a) = mean_kNN_distance( [z(s), a] ; D )      # D = 示教安全样本
  a* = argmax_{a∈Cand, R≤R_τ} [ V_progress(a) − λ·R(a) ]   # 风险敏感选择
  ```
  `V_progress` 复用 I5 进度头；候选由流匹配/扩散动作头采样 K=3。风险过高（`R>R_τ`）直接拒绝；全被拒则回退 I10 投影后的首个候选。
- **技术可行性**：中。VLM 特征 + FAISS（可复用 I9 索引）；chunk 边界 3 次前向。
- **所需资源**：FAISS + 特征提取 ~5–10ms/边界；1 GPU 日建库；1 人周。
- **落地步骤**：①建每任务/任务簇的示教 (z,a) 库；②标定 `R_τ, λ`；③L0：近失/扰动样本分离度 + 对已知成功样本的误拒率；④仅在延迟余量 >20% 时开采样；⑤L2 抽测。
- **风险**：密度≠安全（安全的新动作也可能低密度）、延迟超预算；缓解：只做软过滤 + 高阈值 + 延迟门禁，超预算退化为「仅硬过滤」。

### 3.2 抓取状态贝叶斯监控 + 早停（I11）

```python
class GraspMonitor:
    def __init__(self, w, b, tau_low, k):
        self.w, self.b, self.tau_low, self.k = w, b, tau_low, k
        self.llr_prev, self.bad_streak = 0.0, 0
    def update(self, o, object_width):
        stall = 1.0 if (o.g_obs > 0.15*object_width and
                        abs(o.g_obs - object_width) < 0.5*object_width) else 0.0
        flow  = min(np.linalg.norm(o.delta_wrist) / SIGMA, 1.0)
        llr = (self.w[0]*stall + self.w[1]*(1.0 - flow)
               + self.w[2]*(1.0 - o.on_table) + self.b + self.llr_prev)
        self.llr_prev = llr
        p = 1.0 / (1.0 + np.exp(-llr))
        self.bad_streak = self.bad_streak + 1 if p < self.tau_low else 0
        return p, (self.bad_streak >= self.k)     # True -> 触发 I5 重抓
```

def get_action(self, obs):
    if not self._first_done: self.reset(obs); self._first_done = True
    phase = classify_phase(obs, self.hist)                 # I12: <2ms
    if phase in ("close", "lift_verify", "transport"):

    best = None
    for c in cands:
        c = project_action(c, self.prev_cmd, obs, phase)   # I10 先投影

        if best is None or s > best[0]: best = (s, c)
    chunk = best[1] if best else project_action(cands[0], self.prev_cmd, obs, phase)
    self.prev_cmd = chunk[-1]
    return chunk

## 4. 实验设计（先归因、后安全）

### 4.1 L0-A 失败归因诊断（安全栈准入门，**先做**）

在留出示教 + 单任务通道回放/真机日志上，把失败分为 `{不会做, 夹空/夹偏, 滑落, 碰撞/撞翻, 溢出/挤压, 超时, 人机}`，统计**非受迫失败占比**。

- 判据：非受迫失败 ≥ 全部失败的 40% → 安全栈（I10–I13）全力投入；20–40% → 只上 I10+I11；<20% → 安全栈降级为「I10 可信度护栏」，预算回投 I1/I2/I5。
- 产出：每个任务族的失败画像，作为 I8 注册表第一行。

### 4.2 分级消融协议（沿用 v1.1，补安全层）

| 级别 | 内容 | 成本 | 通过判据 |
|---|---|---|---|
| L0-B 包络保持 | 对示教动作做 `Π_S`，测动作偏离与任务保持代理 | 离线免费 | 偏离中位数 < δ 且任务保持代理损失 ≤ε |
| L0-C 抓取监控 | 注入夹空/滑落标签，测 AUC / 检测延迟 / 误报率 | 离线免费 | AUC>0.9，误报<5%，检测≤3 步 |
| L0-D 密度分离 | 近失/扰动 vs 正常样本的 `R` 分离度 | 离线免费 | AUC>0.8 且对正常样本误拒<5% |
| L1 析因 | `{I10 on/off} × {I11 on/off} × {I13 on/off}` 2³ | 离线 + 少量真机 | 主效应显著的 ≤3 组合进 L2 |
| L2 真机 | top 组合：≥2 任务 × 各 2 次 | 单任务通道 | Δsuccess>0 且 p99<40ms |
| 门禁 | PR4：run_client 全流程 + p99 + 动作健康度 | 本地 stub | 0 拒绝动作、p99<40ms |

### 4.3 首批 L2 排队（真机预算）

①I11 抓取监控（抓取类任务抽测）→ ②I10 包络（全任务回归，确认不降成功率）→ ③I4 人机让位（干扰轴）→ ④I12 阶段门控 → ⑤I13（仅延迟有余量）。
