# 第 3 轮（灵感循环第 3 轮；本轮灵感：「真实世界泛化」×「碰撞检测」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440）。
> 本轮纪律：**继续在前人基础上改进，而不是推倒重来**——不改 MODGAUGE 五不变式、不改 6C 的
> 「假设 → 编程 → 执行 → 校准 → 验证 → 热替换」骨架、不改「数值真值由计量层独占、VLA 降格为被审计角色」。
> 本轮只回答 ToolGauge 没有正面回答的问题：**它到底在什么意义上泛化到了真实世界？**
>
> **核心观察**：ToolGauge 的全部保证都隐含一个「实验室时空」假设——存在一个单一、平稳的部署分布，
> 且一条回执只要 `valid(r)` 就**处处、时时**有效。但在接触丰富的具身系统里，真实世界泛化失败
> 几乎总是**接触模态（contact regime）上的泛化失败**：自由空间标定得再准，第一次撞击、粘滑切换或
> 多接触拓扑一变，契约就失效。碰撞检测恰好同时是这种失败的**最强信号**和把「泛化」从平均指标
> 变成**逐模态可证命题**的**标签来源**。于是本轮把 ToolGauge 升级为
> **ContactGauge**：接触条件化、碰撞认证、被动优先的泛化计量闭环。

## 双轴映射（升级而非重写）

| 灵感词 | ToolGauge 现状 | 升级为 | 一句话动机 |
|---|---|---|---|
| 真实世界泛化 | 引理 47 的 TV 偏移 η 是全局标量；共形覆盖（定义 422）只保证平均意义；P-Quarantine 跨盲区聚合 | **G-Box + GE/G-Monitor**：接触分层的泛化包络、逐模态 e-process、泛化债务账本 | 「泛化」不是标量，而是**逐接触模态的条件覆盖**；平均覆盖好而撞击模态崩塌，是比不泛化更危险的假安全 |
| 碰撞检测 | `tap.percuss` 只是一个普通探测工具；碰撞被视为要避免的副作用；无接触模态概念 | **C-Box + CCM/CBC**：碰撞检测器 → 接触模态图、非对称漏检证书、被动碰撞挖掘、受认证微冲击探针 | 碰撞既是危险，也是**免费的、最难的标签**：自然发生的碰撞给出正是最稀缺的冲击/粘滑样本，关键是不让它污染安全证书 |
| 合流 | 泛化监控与碰撞/探测彼此独立 | **接触条件化泛化监控**：用碰撞模态给泛化证据分层，用泛化包络限制接触探针 | 同一碰撞事件既触发安全收缩，又更新接触物理后验——但必须**只收紧、不放宽**安全包络 |

**核心命题**：把 ToolGauge 的「证据有效 = 格式/签名有效」升级为
「**证据可用 = 采集模态匹配 ∧ 尚未跨模态边界 ∧ 泛化包络内**」，
把 6C 升级为 **CC-6C**（Contact-Conditioned 6C），并新增三层：
**C-Box**（碰撞检测 → 接触模态与漏检证书）、**G-Box**（逐模态泛化包络与 e-process）、
**CMiner**（被动碰撞挖掘 + 受认证微冲击探测）。
一句话：**泛化不再是对全体数据平均而言，而是在每一个被碰撞观测认证过的接触模态下、逐条可审计地成立。**

**不变式保持声明**：
- MODGAUGE 五不变式与第 2 轮「语言主张-回执绑定」全部保留；
- 新增「**接触安全单调性**」：碰撞证据可以更新接触物理后验，但**不得放宽**任何安全包络/自由空间证书，
  只允许收紧或触发再认证（定义 438）；
- **严格退化链延长**：ContactGauge（接触条件化）⇒ ToolGauge（瞬时、单上下文）⇒ LeanGauge（纯数值）
  ⇒ MODGAUGE。碰撞检测不可信 / 模态新颖 / 泛化包络越界 / 接触预算耗尽 ⇒ 立刻 SAFE-HOLD 或降级（定义 444/445）。

## 0. 直觉与动机

**直觉 1（真实世界泛化 → 「逐接触模态的条件泛化」）**
工程上说的「sim-to-real gap」并不是均匀铺在整个状态空间上的：自由空间里的运动学误差通常很小，
真正致命的是**接触瞬间**——撞击速度、恢复系数、摩擦锥、接触拓扑都在变。因此一个在 95% 无接触
样本上覆盖率 0.9 的共形预测器，可能在 IMPACT 模态上覆盖率只有 0.3，却因为平均指标漂亮而通过验收。
ToolGauge 的引理 47 把整个部署分布压缩成一个标量 η，正是这种「平均掩盖模态」的根源。
**解法**：把泛化误差按接触模态做全期望分解
`R − R̂ = Σ_c π_c·gap_c + π_novel·gap_novel`，
对每个 `c` 单独做条件共形与元泛化界；对 `π_novel` 不再假装能泛化，而是用**新颖性检测 + 弃权**把它
转换成显式的 SAFE-HOLD 风险。这不是削弱理论，而是把不可证的部分从「沉默的假设」变成「可计价的风险」。

**直觉 2（碰撞检测 → 免费的、最难的标签 + 非对称安全证书）**
碰撞检测在通常系统里被当作「避免事故的传感器」。但换个视角：**碰撞是真实世界免费送给你的
分布外测试集**。自然发生的碰撞（抓取落座、物体滑动、工具轻触）恰好覆盖了仿真最不准、样本最稀缺的
IMPACT/SLIP/MULTI 模态；只要不诱导、只挖掘，就能以零额外物理风险获得最宝贵的接触物理证据。
但这里有一个必须钉死的区分：**物理证据**（这次碰撞告诉我们材料刚度/恢复系数是多少）与
**安全许可**（系统是否被允许主动制造这种碰撞）是两件事。前者可以来自意外碰撞，后者只能来自
认证过的安全数据。混同二者，系统就会学会「反正撞了也能拟合，所以撞一下没关系」——这是本轮最危险的
伦理/工程陷阱。故定义 438 强制安全单调性：碰撞数据**只收紧、不放宽**安全包络。

**直觉 3（碰撞检测本身不可无条件信任）**
所有逐模态保证都以「模态标签正确」为前提，而标签来自碰撞检测器。碰撞检测器最不可靠的场景
（软体/透明/被遮挡接触、传感器饱和、单通道卡死）恰恰是它最需要可靠的场景。因此不能把检测器
当作真值源，而要把它当作**带非对称风险的证书签发者**：用 conformal risk control 控制**漏检**
（把碰撞判成自由 = 最危险错误）而非平均错误，用多物理通道冗余对抗共模失效，用 SAFE-HOLD
作为「证书不确定时」的硬兜底。**证书的地基必须比它认证的对象更保守。**

**设计公理（贯穿全文）**
- A1（模态相对性）：任何标定/回执只在采集它的接触模态内是证据，跨模态只算先验，不算证据。
- A2（碰撞免费但危险）：优先挖掘自然碰撞；主动制造接触必须通过接触预算与能量包络认证。
- A3（安全单调）：碰撞证据只可收紧安全约束，永不放宽；放宽只能走独立再认证。
- A4（不可证即弃权）：新颖模态、检测器不确定、包络越界时，系统必须显式 SAFE-HOLD，而不是外推。

## 1. 形式化定义（增量：定义 432–447）

**定义 432（接触观测、接触模态与接触段）** 一次接触事件由物理量描述：
法向冲量 `Jₙ = ∫ fₙ dt`、切向冲量 `Jₜ`、接触前法向相对速度 `vₙ⁻`、恢复系数 `e = −vₙ⁺/vₙ⁻`、
摩擦比 `ρ = Jₜ/Jₙ`、接触驻留时间 `τ_d`、接触拓扑 `K`（哪些刚体/连杆/工具参与，是否多接触）。
模态映射 `σ(Jₙ, |vₙ⁻|, ρ, K, τ_d)` 在带回差（hysteresis）的量化下给出
`c ∈ C = {FREE, APPROACH, IMPACT, STICK, SLIP, MULTI, SEP}`。
一个**接触段（episode）** 是模态恒定的最大时间区间 `[t_a, t_b)`；段身份 `seg_id` 是证据新鲜度的边界：
**证据不跨段复用**，因为跨段意味着一模态切换，旧证据只在旧模态内有效（公理 A1）。

**定义 433（碰撞检测器与单边漏检证书）** 检测器 `D_β` 融合力/力矩、触觉、电流、声学与深度残差，
输出 `(ĉ, A_c ⊆ C, u)`：`ĉ` 为最可能模态，`A_c` 为模态集合值预测，`u` 为不确定性。
按「是否**非预期碰撞**」定义 0-1 损失：`L = 1[U=1 ∧ Ĉ=0]`，其中 `U` 表示接触对/冲量落在计划
允许集 `I_plan` 之外的非预期碰撞。用 conformal risk control 在校准集上选阈值 `λ̂_β`，使
`E[L] ≤ β`（可交换性下）；当校准-部署 TV 距离为 `η_c` 时 `E[L] ≤ β + η_c`。
**安全关键的自由空间声明必须由至少两条物理独立通道同时支持**；单通道一致不算证书（共模失效防护）。
另设误报预算 `β_fa` 以保住可用性，`β ≪ β_fa`（漏检远比误报昂贵）。

**定义 434（接触条件化盲区 CCBS）** 盲区从 ToolGauge 的格子 `s` 升级为 `s_c = (s, c)`：
D-Box 的覆盖矩阵扩展为证据张量 `E[s, c]`。`s_c` 是盲区当且仅当
`E[s,c]` 样本数 `< n_min(c)`，或其中最新回执的 `seg_id` 已失效。覆盖不再是「这个格子看过没有」，
而是「**这个格子的这个接触模态，被当前接触段的有效回执看过没有**」。

**定义 435（证据的接触条件化可用性）** 对回执 `r`、模态 `c`、时刻 `t`：
```
valid_use(r, c, t) ⇔ valid(r)                         # 定义 417，格式/签名/seq
                  ∧ c(r) = c                          # 采集模态匹配（A1）
                  ∧ t − ts(r) ≤ T_fresh(c)            # 模态相关新鲜度
                  ∧ seg_id(r) 在 t 时刻仍连续           # 未跨模态边界
                  ∧ GE_s,c(t) = IN                      # 在泛化包络内（定义 436）
```
跨模态复用只能作为**先验**进入 AP-Cal 的 KL 锚，**不得**作为校准样本；否则一律作废（污染即拒）。
接触类回执额外携带定义 438 的接触特征向量。

**定义 436（泛化包络 GE 与逐模态 e-process）** 对每个契约参数 `u_s` 与模态 `c`，维护
交换性检验的 e-process `E_c(t) = ∏ᵢ (1 + λᵢ·b_c(rᵢ))`（`b_c` 为有界下注，`λᵢ` 自适应），
零假设是「当前部署回执与校准回执在模态 `c` 上可交换」。
定义 `GE_s,c(t) = IN` 当且仅当
① `sup_{τ≤t} E_c(τ) < 1/δ`（Ville 界下未拒绝交换性）；
② 模态 `c` 的条件共形覆盖 `≥ 1 − α − η_c`（定义 441）；
③ 模态新颖性 `p_novel(c) > α_novel`（定义 440）。
三者任一不满足即 `OUT`。**泛化包络是显式、逐模态、可审计的集合，而不是引理里的一个标量 η。**

**定义 437（接触条件化隔离 CCQ）** 维护逐模态 e-process 与逐模态残差符号序列。
若 `E_c ≥ 1/δ` 或连续 `q_c` 次残差同向，则**只冻结涉及模态 `c` 的热替换**（其余模态继续），
把该模态证据移入隔离区、回退该模态到 BP-Cal / 保守上界，并触发定向被动挖掘或受认证探针。
Ville 不等式保证在无偏移时误触发概率 `≤ δ`。这修复 ToolGauge 的 P-Quarantine 因跨盲区聚合
而被稀释、对「单模态系统性偏差」迟钝的缺陷。

**定义 438（接触特征回执、被动挖掘与安全单调性）** 接触回执
`r_c = (t, args, obs, φ, sig, ts, seq, seg_id)`，其中接触信息向量
`φ = (Jₙ, Jₜ, e, ρ, τ_d, K, 声学谱质心, 冲击后残差)`。
**被动碰撞挖掘（PCM）**：系统记录自然发生的接触事件并抽取 `φ`，作为**自由证据（free evidence）**；
不施加任何为了采集而新增的物理动作。
**安全单调性（强制）**：来自非预期碰撞的证据只允许更新接触物理后验 `u_s`，
**不得**扩大安全包络 `S_safe`、自由空间证书或允许冲量上界；`S_safe` 的放宽只能由
「独立再认证 + 人工/形式化签字」完成，且再认证不得复用触发放宽的那次碰撞数据。
形式化：`S_safe(t+1) ⊆ S_safe(t)`，除非 `re-certify ⊥ data(triggering collision)`。

**定义 439（受认证接触探针与接触预算契约 CBC）** 新工具
`contact.microimpact(E ≤ E_max(c,m), surface ∈ benign_registry) → (φ, μ, σ_decl)`：
以受控微能量接触获取材料/摩擦/恢复系数证据。仅当
① SAFE-HOLD 未激活；② 目标表面已注册为良性；③ 目标模态被判定欠采样（`n_c < n_min`）；
④ 触碰能量 `≤ E_max(c, material)` 且满足力矩硬限；⑤ 单盲区主动接触总能量 `≤ B_E`、
次数 `≤ B_N`——方可执行。收益-风险闸门（推广定义 419 的增益注）：
```
β_contact = Ĝ_t(h) − c_t − γ_R·Risk_t ≥ 0,   Risk_t = E_touch/E_max + 意外后果上界
```
**被动优先规则**：若被动接触到达率 `λ_c·I_passive(c)` 已足够，禁止主动接触探针（引理 55）。

**定义 440（开放集接触模态与新颖性弃权）** 对接触特征 `φ` 计算到已校准模态的
非一致性 `d(φ) = min_{c∈C} dist(φ, Φ_c)`，共形 p 值
`p_novel = (1 + #{i : d_i ≥ d(φ)}) / (n + 1)`。若 `p_novel ≤ α_novel`，模态判为
**NOVEL（开放集）**：`ContactGauge` 不得输出任何泛化保证，不得据此热替换契约；
系统进入受限 SAFE-HOLD 或仅执行经认证的安全动作，并请求人工/新探针方案。
这是对「真实世界泛化」的诚实边界：**未见模态不可被 iid 界覆盖，只能被显式弃权处理。**

**定义 441（逐模态条件共形覆盖）** 按模态 `c` 分层校准（Mondrian conformal），
分数取 `1−α` 分位 `τ_{h,c}`；在模态 `c` 内保证
`P(h* ∈ H_s | c) ≥ 1 − α − η_c`。有限样本修正：覆盖率单边下界
`≥ 1 − α − sqrt(ln(2/δ)/(2 n_c))`。若 `n_c < n_min(c)`，该界不足以下结论，
`GE_s,c := OUT`，触发定向被动挖掘（优先）或受认证探针（定义 439）。
**平均覆盖达标不蕴含逐模态达标**——这正是本轮对 ToolGauge 定义 422 的核心修正。

**定义 442（接触反事实一致性 V_contact）** 候选契约 `u` 诱导一个混合自动机 `H(u)`，
其**接触轨迹**是事件序列 `T(u) = ((c_k, t_k^entry, Jₙ,k, e_k, ρ_k))`。
V 阶段除继承的独立回执标准化残差 `|z| ≤ ε_cross` 外，还必须比较
`T(u)` 与观测到的接触轨迹 `T_obs`：用时间加权编辑距离
`D_trace(T(u), T_obs) ≤ ε_trace` 且每个事件的冲量/恢复系数误差在容差内。
**物理直觉**：一个只会拟合标量残差、却预测不出「何时撞击、撞击多硬、撞后是否粘滑」的契约，
不是泛化，只是插值。接触轨迹是真实世界泛化最廉价、最不可伪造的压力测试。

**定义 443（泛化债务账本 GDebt）** 每份契约携带债务向量
`g_s = (g_{s,c})_{c∈C} ∪ (g_{s,NOVEL}) ≥ 0`，`g_{s,c}` 由该模态的偏移估计 `η̂_c`、
新颖性质量 `π̂_novel`、条件覆盖缺口与未验证能量预算共同组成。
约束：`g_s ≤ G_max`（逐分量）且热替换不得使任一受影响模态的债务**相对上升**
（除非同时给出独立再认证回执）。债务是**可审计、可告警、可排序**的部署风险度量，
替代 ToolGauge 里不可见的「先验可信度」。

**定义 444（接触感知退化链）** `ContactGauge ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE`。
触发降级的条件：碰撞检测器不确定 `u > u_max`、出现 `NOVEL` 模态、`GE_s,c = OUT`、
接触能量/次数预算耗尽、SAFE-HOLD 激活、V_contact 或契约回归失败。
降级是**单向、快速、可逆需再认证**的：`ContactGauge` 是最强能力层，也依赖最多假设，
失效时先退回不依赖接触语义的 ToolGauge，再退回纯数值 LeanGauge，最后是原 MODGAUGE。

**定义 445（SAFE-HOLD 硬兜底态）** 一个**可证明碰撞无害**的保守控制律
（停止–回撤、力矩/能量硬限、仅非接触传感、冻结契约与热替换、日志全录、人机协作场景对操作者可见）。
不变式：SAFE-HOLD 期间不发起任何主动接触；`S_safe` 由硬件限幅与控制屏障双重保证；
退出需满足「检测器不确定回落到阈值下 + 至少一条独立通道确认自由空间 + 人工/自动再认证」。
SAFE-HOLD 是本轮所有弃权语义的**物理落点**，不是一个抽象状态名。

**定义 446（接触条件化主张绑定）** 扩展定义 423：任何关于「已泛化到某材料/某模态」的语言主张
必须携带 `receipts(c)`（逐模态有效回执）、`GE_s,c` 状态与 `g_s` 债务快照；
禁止对 `NOVEL` 模态作泛化主张；数值必须逐字引自回执。无引用、引用无效或引用 `OUT` 的回执 ⇒
序列化时整条剥离。剥离是纯投影，不改变任何数值行为。

**定义 447（继承与退化特例）** 未重定义的 ToolGauge 记号（R、s、λ、γ、M_ver、EC、TCV、MTC、
MP-Φ、AP-Cal、P-Quarantine 等）延续定义 416–431。
令 `C = {FREE}`、碰撞检测器恒输出 FREE、`T₀` 不含 `contact.microimpact`、`GE ≡ IN`，
则 ContactGauge ≡ ToolGauge；再令 VLA=∅、MP-Φ=物理先验 GP 则 ≡ LeanGauge。
**本轮不改变任何数值通道的语义，只改变「证据在什么条件下算证据」。**

```python
class ContactDetector:
    def detect(self, window) -> "ContactObs":
        feats = self.fuse(window)                     # F/T、触觉、电流、声学、深度残差
        c_hat = self.regime_head(feats)
        A_c   = self.conformal_set(feats, beta=self.beta)   # 定义 433 集合值
        u     = self.uncertainty(feats)
        p_nov = self.novelty_pvalue(feats)            # 定义 440
        return ContactObs(c_hat, A_c, u, p_nov, feats, seg_id=self.seg.next())

    def certified_free(self, obs) -> bool:
        # 安全关键自由声明：多物理通道一致 + 漏检风险在 beta 内 + 无新颖性
        return (len(obs.A_c) == 1 and FREE in obs.A_c
                and obs.p_nov > self.alpha_novel
                and self.redundant_channels_agree(obs)
                and obs.u <= self.u_max)

class ContactRegimeBox:
    def update(self, obs, R_cell):

        for s in covered_cells(R_cell):

                and r.seg_id == self.seg.id and GE[r.s, c] == IN)

# IP-324 G-Box：逐模态泛化包络 + e-process + 债务
class GBMonitor:
    def update(self, s, c, r):

        self.resid_sign[c].push(r.resid)

              and self.coverage_lcb(c) >= 1 - self.alpha - self.eta_hat[c]
              and r.p_nov > self.alpha_novel)

# IP-325 CC-6C：接触条件化闭环
def contactgauge_cc6c(M, s_c):
    s, c = s_c
    obs  = M.cdet.detect(M.env.window())
    if not M.cdet.certified_free(obs) and c == FREE:
        M.safe_hold.enter("collision_uncertain"); return False       # 定义 445
    H    = M.lbox.hypothesize(s_c, M.cbox.R[s], contact_mode=c)      # H（含接触假设）
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s_c),      # C
                         allow_contact=M.miner.needs(c) and M.cbc.ok(c))
    receipts = M.tcv.execute(prog, M.env)                           # E（PROBING + 力矩硬限）
    M.miner.ingest_passive(receipts)                                # 免费证据先入库
    if M.cbc.exhausted() or not all(M.cbox.valid_use(r, c, now, M.GE) for r in receipts):
        return M.degrade(s_c, "evidence_not_usable")
    mu, Sig = M.apcal.calibrate(receipts, H, s_c)                   # C
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s_c)):   # V（标量）
        return M.degrade(s_c, "cross_failed")
    if not M.vcontact.consistent(M.apcal.contract(mu, Sig), M.trace(c)):  # V（接触轨迹）
        return M.degrade(s_c, "contact_trace_failed")
    if M.gbox.GE[s, c] != IN:                                       # 泛化包络
        return M.degrade(s_c, "generalization_envelope_out")
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s_c)           # U
    if not M.gbox.debt_non_increasing(s, c, new_ec):
        return M.degrade(s_c, "debt_increase")
    if not contract_regression(new_ec):
        return M.degrade(s_c, "regression")
    M.mreg.hot_replace(M.dpe, new_ec)
    bind_claims_contact(new_ec, H, receipts, M.GE[s, c], M.gbox.debt[s, c])  # 定义 446
    return True
```

## 3. 推导

**引理 51（接触分层泛化分解与开放集代价）** 设部署分布按模态分解为
`R = Σ_{c∈C} π_c R(c) + π_novel R_novel`，且每个已校准模态 `c` 满足引理 47 的元泛化界
（把 `M, N_bl, η` 替换为模态内 `M_c, N_c, η_c`）。则
```
R − R̂ ≤ Σ_{c∈C} π_c·[2η_c + O(√((C(Θ)+log(1/δ))/M_c)) + O(√((d_u+log(1/δ))/N_c))] + π_novel·(R_novel − R̂_novel).
```
**系 51.1（弃权证书）** 若对 `NOVEL` 模态弃权并进入 SAFE-HOLD（风险 `≤ R_hold`），
则**已认证**风险满足 `R_cert ≤ (1−π_novel)·(上式已校准部分) + π_novel·R_hold`，
弃权概率 `≤ π_novel + α_novel`。推论：开放集风险不能靠 iid 界消灭，只能
**要么用预训练覆盖该模态（压低 π_novel），要么支付 R_hold**；`π_novel` 因此必须进风险账本（定义 443），
这正是 ToolGauge 引理 47 里那个「不可消除的 η 项」的模态级精确化。

**引理 52（非对称漏检界与自由空间证书）** 在可交换性下，conformal risk control 的阈值选择使
`P(非预期碰撞被漏检) ≤ β`；校准-部署 TV=`η_c` 时 `≤ β+η_c`。
若两条冗余通道失效事件独立，漏检概率 `≤ β₁β₂`；但共模失效（饱和/卡死/遮挡）破坏独立性，
必须由跨通道一致性检验与 `S_safe` 硬限兜底，此时保障来自**物理约束**而非统计。
**系（自由空间证书的代价）** 证书越保守（`β` 越小），可宣称的自由空间管状域越短，
探测/运动越慢；这是「安全 vs 可用性」的显式兑换率，必须写进调度器而不是隐藏。

**引理 53（逐模态条件覆盖的有限样本界）** 在模态 `c` 内做 Mondrian conformal，样本量 `n_c` 时
`P(h*∈H_s | c) ≥ 1 − α − sqrt(ln(2/δ)/(2n_c))`（可交换性下）。
因此 `n_c < n_min` 时该界不具信息量，`GE_s,c := OUT` 是**唯一诚实**的选择。
**系 53.1**：ToolGauge 定义 422 的全局覆盖保证在模态混合比例与校准时不同时可能整体失效；
条件覆盖是真实世界泛化的最小可接受口径。

**引理 54（接触轨迹验证保持安全不变式）** 若候选契约在包络内所有模态上的接触轨迹满足
`D_trace ≤ ε_trace` 且冲量/恢复系数在容差内，并且 `SAFE-HOLD` 触发条件未被削弱，
则热替换不改变「进入接触前的碰撞安全不变式」。
证明思路：安全不变式只依赖接触进入条件（位置/速度/允许冲量）与监测器阈值；
轨迹匹配保证这些量在观测分布内不恶化，监测器不变保证越界仍能拦截；故由归纳不变式得证。
（这是 ToolGauge 引理 49 在接触维度上的加强；仅数值等价不足以保证物理安全。）

**引理 55（被动优先的收益-风险最优性）** 设自然接触到达率为 `λ_c`，单次被动证据信息量 `I_p`，
主动探针信息量 `I_a`、风险 `Risk_a`、代价 `c_a`。则单位风险信息率
`passive: λ_c I_p / 0`（相对风险为零）优于 `active: I_a/(Risk_a+c_a)` 当且仅当
`λ_c I_p ≥ I_a/(Risk_a+c_a)·(1+o(1))`。故调度器的最优策略是
**先用被动挖掘把 `n_c` 推到门槛，只有在长期欠采样模态上才允许受认证探针**；
这直接落实公理 A2。证明由更新过程的长期平均信息率与 renewal reward 定理给出。

**引理 56（时序与硬实时保持）** 碰撞检测融合（O(|C|)）、e-process 更新（O(|C|)）与 SAFE-HOLD
判定均在 50Hz 路径内联，新增开销 `≤ 0.4 ms/周期`（ToolGauge 已用 0.2ms，总预算 < 20ms 的 5%）；
SAFE-HOLD 在一个控制周期（20ms）内生效；CC-6C 修复仍全异步，单事件 `≤ τ_repair`（定义 424）。
故 ToolGauge 引理 50 的硬实时与预算结论保持，接触探针能量/次数由 CBC 硬顶（定义 439）。

| `S_safe` | 安全包络；碰撞证据下只可收紧（安全单调性） |
| `contact.microimpact / B_E,B_N` | 受认证微冲击探针 / 接触能量与次数预算（定义 439） |
| `p_novel, α_novel` | 开放集新颖性 p 值与弃权阈值（定义 440） |
| `Mondrian / τ_{h,c}` | 逐模态条件共形与模态分位（定义 441） |
| `T(u), D_trace, ε_trace` | 契约诱导的接触轨迹、时间加权编辑距离、容差（定义 442） |
| `g_s = (g_{s,c}) ∪ (g_{s,NOVEL})` | 泛化债务向量与逐分量上界 `G_max`（定义 443） |
| `SAFE-HOLD` | 可证明碰撞无害的保守控制律与弃权落点（定义 445） |

## 2. 形式化定义（要点）

**定义 432（接触模态）** 由 `(Jₙ,Jₜ,e=vₙ⁺/vₙ⁻,ρ=Jₜ/Jₙ,τ_d,K)` 经带回差量化得到
`c ∈ {FREE,APPROACH,IMPACT,STICK,SLIP,MULTI,SEP}`；模态恒定的最大区间为接触段，段身份是证据新鲜度边界。
**定义 433（漏检证书）** `D_β` 用力/触/电流/声/深度残差融合输出 `(ĉ,A_c,u)`；对「非预期碰撞被判成自由」
的 0-1 损失做 conformal risk control，`E[L] ≤ β`（TV=`η_c` 时 `≤ β+η_c`）；
安全关键自由声明需 ≥2 条物理独立通道一致，单通道一致不算证书。
**定义 434（CCBS）** 盲区 `s_c=(s,c)`；覆盖看的是「该格该模态在当前接触段是否被有效回执看过」。
**定义 435（证据可用性）** `valid_use ⇔ valid(r) ∧ c(r)=c ∧ 未过期 ∧ seg_id 连续 ∧ GE=IN`；
跨模态数据只能作 AP-Cal 的 KL 先验，不得作校准样本。
**定义 436（泛化包络）** 逐模态 e-process 未拒绝交换性、条件覆盖 `≥1−α−η_c`、新颖性 `>α_novel` 三者同时成立
才 `GE=IN`；否则 `OUT`。泛化包络是显式集合，不是标量 η。
**定义 437（CCQ）** `E_c ≥ 1/δ` 或连续 `q_c` 次同向残差 ⇒ 只冻结模态 `c` 的热替换与证据，
回退 BP-Cal/保守上界，Ville 保证无偏移误触发 `≤δ`。
**定义 438（被动挖掘与安全单调性）** 接触回执携带 `φ`；自然碰撞作为自由证据；
**碰撞数据只更新物理后验，绝不扩大 `S_safe`**；放宽仅由不含触发数据的独立再认证完成。
**定义 439（受认证探针）** `contact.microimpact` 仅在 SAFE-HOLD 未激活、良性表面、模态欠采样、
能量 `≤E_max(c,m)`、预算 `B_E/B_N` 内执行；收益-风险闸门 `Ĝ−c−γ_R·Risk ≥ 0`；被动优先（引理 55）。
**定义 440（开放集弃权）** 接触特征共形 p 值 `p_novel≤α_novel` ⇒ NOVEL：不得给泛化保证、不得热替换，
进入 SAFE-HOLD/受限安全动作并请求人工或新探针。
**定义 441（逐模态条件共形）** Mondrian conformal 给出 `P(h*∈H_s|c) ≥ 1−α−η_c`；
有限样本下界 `≥1−α−√(ln(2/δ)/(2n_c))`；`n_c<n_min` ⇒ `GE=OUT`。平均覆盖不蕴含逐模态覆盖。
**定义 442（V_contact）** 候选契约的接触轨迹 `T(u)` 与观测 `T_obs` 需满足
`D_trace ≤ ε_trace` 且事件冲量/恢复系数在容差内；只拟合标量残差但预测不出撞击/粘滑的契约拒绝热替换。
**定义 443（泛化债务）** `g_s=(g_{s,c})∪(g_{s,NOVEL})` 由逐模态偏移、新颖性质量、覆盖缺口与未验证能量组成；
`g_s ≤ G_max` 逐分量，且热替换不得使任一受影响模态债务相对上升（除非独立再认证）。
**定义 444（退化链）** `ContactGauge ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE`；单向快速降级、需再认证才可回升。
**定义 445（SAFE-HOLD）** 停止–回撤 + 力矩/能量硬限 + 仅非接触传感 + 冻结契约与热替换 + 全日志；
期间禁止主动接触；退出需检测器不确定回落、独立通道确认自由空间与再认证。
**定义 446（接触条件化主张）** 泛化主张必须引用 `receipts(c)`、`GE_s,c` 与 `g_s` 快照；
禁止对 NOVEL 模态作泛化主张；无引用/`OUT` 引用在序列化时剥离（纯投影，不改数值行为）。
**定义 447（继承）** `C={FREE}`、检测器恒 FREE、无接触探针、`GE≡IN` ⇒ ContactGauge ≡ ToolGauge。

## 3. 关键算法骨架

```python
# IP-321 C-Box：碰撞检测 + 非对称漏检证书 + 新颖性
class ContactDetector:
    def detect(self, window):
        f = self.fuse(window)                       # F/T、触觉、电流、声学、深度残差
        return ContactObs(c_hat=self.regime_head(f),
                          A_c=self.conformal_set(f, beta=self.beta),
                          u=self.uncertainty(f),
                          p_nov=self.novelty_pvalue(f),
                          phi=contact_features(f),
                          seg_id=self.seg.next())
    def certified_free(self, o):
        return (o.A_c == {FREE} and o.p_nov > self.alpha_novel
                and self.redundant_channels_agree(o) and o.u <= self.u_max)

# IP-322 证据账本：接触条件化盲区与可用性
class ContactRegimeBox:
    def update(self, o, R):
        self.seg.update(o.c_hat)                    # 模态切换 ⇒ 新段
        for s in covered_cells(R): self.E[s, o.c_hat].append(o)
    def valid_use(self, r, c, t, GE):
        return (valid(r) and r.c == c and t-r.ts <= T_FRESH[c]
                and r.seg_id == self.seg.id and GE[r.s, c] == IN)

# IP-323 CMiner：被动碰撞挖掘 + 安全单调更新
class ContactMiner:
    def ingest(self, o, intended):
        if not o.contact: return
        r = make_receipt(o, o.phi)
        self.evidence.append(r)                     # 自由证据
        if not intended:
            self.update_physics_only(r)             # 只更新物理后验
            self.safety.envelope = tighten_only(self.safety.envelope)  # 定义 438

# IP-324 G-Box：逐模态 e-process + 覆盖 + 债务
class GBMonitor:
    def update(self, s, c, r):
        self.eproc[c].update(bet(r))
        self.sign[c].push(r.resid)
        self.GE[s, c] = IN if (self.eproc[c].sup() < 1/self.delta
                               and self.coverage_lcb(c) >= 1-self.alpha-self.eta[c]
                               and r.p_nov > self.alpha_novel) else OUT
        self.debt[s, c] = self.estimate_debt(s, c, self.GE[s, c])
        return self.GE[s, c]

# IP-325 CC-6C：接触条件化闭环
def contactgauge_cc6c(M, s_c):
    s, c = s_c
    o = M.cdet.detect(M.env.window())
    if c == FREE and not M.cdet.certified_free(o):
        return M.safe_hold.enter("collision_uncertain")          # 定义 445
    H = M.lbox.hypothesize(s_c, M.cbox.R[s], contact_mode=c)     # H
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget(s_c),       # C
                         allow_contact=M.miner.needs(c) and M.cbc.ok(c))
    receipts = M.tcv.execute(prog, M.env)                        # E（PROBING + 力矩硬限）
    if M.cbc.exhausted() or not all(M.cbox.valid_use(r, c, now, M.GE) for r in receipts):
        return M.degrade(s_c, "evidence_not_usable")
    mu, Sig = M.apcal.calibrate(receipts, H, s_c)                # C
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s_c)): return M.degrade(s_c, "cross")
    if not M.vcontact.consistent(mu, Sig, M.trace(c)):            # V_contact
        return M.degrade(s_c, "contact_trace")
    if M.gbox.GE[s, c] != IN: return M.degrade(s_c, "GE_out")     # 泛化包络
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s_c)         # U
    if not M.gbox.debt_non_increasing(s, c, new_ec): return M.degrade(s_c, "debt")
    if not contract_regression(new_ec): return M.degrade(s_c, "regression")
    M.mreg.hot_replace(M.dpe, new_ec)
    bind_claims_contact(new_ec, H, receipts, M.gbox.GE[s, c], M.gbox.debt[s, c])
    return True

# IP-326 主闭环
def ContactGauge_round(M, obs, audio, tac, depth, det):
    o = M.cdet.detect(M.env.window())            # 50Hz 内联
    M.cbox.update(o, M.R)
    if o.p_nov <= M.alpha_novel: M.safe_hold.enter("novel_contact_mode")
    for s_c in M.cbox.blind_spots():
        if s_c not in M.inflight: M.inflight.add(s_c); submit_async(contactgauge_cc6c, M, s_c)
    if M.gbox.any_triggered(): M.ccq.freeze(M.gbox.triggered_modes())
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 51（接触分层泛化分解与开放集代价）** `R−R̂ ≤ Σ_c π_c·gap_c + π_novel·(R_novel−R̂_novel)`，
其中 `gap_c` 为引理 47 在模态 `c` 内的界（`M_c,N_c,η_c`）。
系：对 NOVEL 弃权并入 SAFE-HOLD（风险 `≤R_hold`）时，
`R_cert ≤ (1−π_novel)·已校准部分 + π_novel·R_hold`，弃权概率 `≤π_novel+α_novel`。
结论：开放集风险只能靠「预训练覆盖压低 π_novel」或「支付 R_hold」，不可被 iid 界消灭；
这正是 ToolGauge 引理 47 中不可消除 η 项的模态级精确化。

**引理 52（非对称漏检界）** 可交换性下 `P(漏检非预期碰撞)≤β`，TV=`η_c` 时 `≤β+η_c`；
冗余通道独立时 `≤β₁β₂`，共模失效时保障回退到物理硬限（来自 `S_safe` 与控制屏障，而非统计）。
系：`β` 越小，可宣称自由空间管状域越短——安全/可用性兑换率必须进调度器。

**引理 53（逐模态条件覆盖）** Mondrian conformal 下
`P(h*∈H_s|c) ≥ 1−α−√(ln(2/δ)/(2n_c))`；`n_c<n_min` 时 `GE=OUT`。
系：ToolGauge 定义 422 的全局覆盖在模态混合比例变化时可整体失效；条件覆盖是真实世界泛化的最小口径。

**引理 54（接触轨迹验证保持安全）** 包络内所有模态满足 `D_trace≤ε_trace`、冲量/恢复系数在容差内，
且 SAFE-HOLD 触发条件未削弱 ⇒ 热替换不改变接触进入安全不变式。
（ToolGauge 引理 49 的接触维加强：数值等价不足以保证物理安全。）

**引理 55（被动优先最优性）** 被动信息率 `λ_c I_p`（相对风险≈0）优于主动
`I_a/(Risk_a+c_a)` 当且仅当 `λ_c I_p ≥ I_a/(Risk_a+c_a)`；故先被动挖掘至 `n_min`，
只在长期欠采样模态才允许受认证探针。

**引理 56（时序保持）** 碰撞检测/e-process/新颖性均在 50Hz 内联，新增 `≤0.4ms/周期`
（ToolGauge 0.2ms，总 < 20ms 的 5%）；SAFE-HOLD 一个周期内生效；CC-6C 仍全异步，
故引理 50 的硬实时与预算结论保持，接触能量/次数由 CBC 硬顶。

## 8. 本轮最大风险

**一句话**：ContactGauge 的全部逐模态保证都建立在碰撞检测器的漏检率之上，而检测器最不可靠的
场景（软体/透明/被遮挡接触、传感器饱和或卡死）恰是它必须可靠的场景——一次被漏掉的非预期碰撞
既造成物理伤害，又静默污染所有下游模态标签与泛化证书，使系统在最需要保守时反而「自信地泛化」；
故多物理冗余、非对称漏检控制、安全单调性与 SAFE-HOLD 硬兜底是不可外包的地基，
并由 E441/E445/E453 专门证伪。
