# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「6D位姿估计」×「柔顺控制」）

> 第 54 轮把技能做成动作空间剖面 α_S 与动作-鲁棒性联合证书 J，解决了"技能在动作空间上是否可组合"。但接触操作还有一层被忽略的耦合：**6D 位姿估计给出的是 SE(3) 上的信念而非点，柔顺控制消费这个信念并输出力**。核心矛盾：H22：位姿误差协方差未被传播进柔顺参数，点估计的"高置信"在接触瞬间变成力尖峰；H23：柔顺椭球挂在估计出的位姿坐标架上，位姿多模态/各向异性使柔顺方向与真实接触几何错配；H24：柔顺不只是执行器，它产生的接触力/力矩是可反过来精化位姿的物理探针，但探测本身消耗力预算、存在损坏风险。

## 0. 直觉与动机

**灵感 1（位姿是分布，不是点 → 信念对象）**
直觉：6D 位姿估计在对称物体、重度遮挡、sim-to-real 下天然多解。与其输出一个 `(R,t)` 再配一个漂亮但没用的置信度，不如输出 **SE(3) 位姿信念 `b(ξ)`**：局部切空间上的混合高斯 `b = Σ_m w_m N(μ_m, Σ_m)`，并显式保留模态（对称物体的翻转解不能平均成一个假中心）。后续所有柔顺量都必须 condition on `b`，而不是 condition on 点估计。

**灵感 2（位姿不确定性 → 柔顺椭球：不确定性对齐的柔顺）**
直觉：刚度矩阵 `K` 的软方向应优先对准位姿高方差方向。位姿在法向 `n` 上不确定，就把法向刚度调软；切向不确定且摩擦裕度低，就调切向刚度。**"不确定性对齐柔顺"（uncertainty-aligned compliance）** 把 `K` 从一组手调参数变成 `K(b, G)`，由信念协方差与接触几何 `G` 共同生成。位姿越不确定，柔顺椭球越"顺着不确定性躺平"，而不是各向同性硬顶。

**灵感 3（柔顺即探测：compliance-as-probe）**
直觉：接触力 `w = K J_c ξ + 噪声` 是关于位姿的测量。柔顺运动在完成任务的同时，可以**受控地压一下/蹭一下**，用接触力反推位姿，降低接触约束子空间内的不确定性。于是同一套柔顺参数既做执行又做传感：刚度越大信息越多，但力越危险——这是一个真实的 **信息-安全权衡**，不是免费午餐。由此得到 `位姿信念 → 柔顺策略 → 接触力 → 位姿信念更新` 的对偶控制闭环。

**灵感 4（力安全证书：把概率保证写进部署条件）**
直觉：给定信念 `b`、刚度 `K`、几何 `G`，可以推导力超限概率的上界 `P(‖F‖>F_max) ≤ ε_F`。把该上界与第 54 轮的联合证书 `J` 合并，得到 **位姿-柔顺联合证书 `J_pc`**。多模态信念用逐模态 union bound；摩擦锥/切向力也纳入保守包络。这样"能部署"不再只看位姿精度，而看 **在给定位姿不确定性下力是否仍被约束住**。

**灵感 5（云边：全局位姿先验 + 边端柔顺伺服 + 力事件回传）**
直觉：云端做全局 6D 位姿先验（多视角/基础模型配准，协方差较大但无累积漂移），边端做高频位姿跟踪（低延迟、协方差小但会漂）+ 阻抗伺服 + 力安全滤波；边端接触事件（力尖峰、滑移、位姿跳变）作为 `evidence` 回传云端触发重定位与柔顺策略重规划。这与第 54 轮 CEC/AEC 的"云规划-边校验-反向解释-重剖分"完全同构，只是把动作空间换成"位姿信念空间 × 力空间"。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（SE(3) 位姿信念）**
位姿信念 `b = { (w_m, μ_m, Σ_m) }_{m=1..M}`，权重 `Σ_m w_m = 1`，均值 `μ_m ∈ SE(3)`，协方差 `Σ_m ∈ Sym⁺(6)` 定义在 `μ_m` 处的切空间 `se(3)` 上。模态间协方差按 `Ad_T` 搬运：`Σ_{m→m'} = Ad_{μ_{m'} μ_m^{-1}} Σ_m Ad_{μ_{m'} μ_m^{-1}}^T`。信念支撑集 `Supp(b) = ∪_m { ξ : (ξ⊖μ_m)^T Σ_m^{-1} (ξ⊖μ_m) ≤ χ²_{6,1-δ} }`。

**定义 122（柔顺椭球与位姿-柔顺映射）**
给定接触几何 `G = (p_c, n, μ_f)`（接触点、法向、摩擦系数）与位姿信念 `b`，在接触坐标架 `R_c = [n, t_1, t_2]` 下定义刚度
```
K(b,G) = R_c · diag(k_n(b,G), k_{t1}(b,G), k_{t2}(b,G)) · R_c^T
```
柔顺椭球 `E_K = { x : x^T K x ≤ 1 }`。法向刚度满足 `k_n ≤ F_max / (|μ_n| + z_ε · s_n)`，其中 `s_n² = n^T J_c Σ_m J_c^T n`，`J_c = [I₃, -[p_c - t]_×]` 为接触 Jacobian，`z_ε = sqrt(2 ln(2M/ε_F))`。

**定义 123（不确定性对齐柔顺）**
设 `K = U diag(k_i) U^T`、`Σ_ξ = V diag(σ_i²) V^T`。对齐度
```
A(K,Σ_ξ) = Σ_i w_i |⟨u_i, v_{σ(i)}⟩| / Σ_i w_i,  w_i = 1/(1+σ_i²)
```
要求 `A(K,Σ_ξ) ≥ θ_A`。直觉：软方向（小 `k_i`）应落在高方差方向（大 `σ_i²`）上。`A` 是柔顺证书的可判定几何条件。

**定义 124（接触力安全证书）**
`C_force = (b, K, G, F_max, ε_F, evidence)`。称其有效，若
```
P(‖F‖ > F_max | b, K, G) ≤ Σ_m w_m Σ_{c∈contacts} ε_{F,m,c} ≤ ε_F
```
其中单模态单接触界 `ε_{F,m,c} = 2 exp(-(F_max - k_n|μ_n|)²/(2 k_n² s_n²))`；切向力满足 `‖F_t‖ ≤ μ_f F_n` 时，把 `F_max` 换成 `F_max/(1+μ_f)` 作保守包络。

**定义 125（柔顺探测信息增益）**
单次接触的测量模型 `w = K J_c ξ + n_w`，`n_w ~ N(0, Σ_w)`。后验 `Σ⁺ = (Σ⁻¹ + J_c^T K^T Σ_w^{-1} K J_c)^{-1}`。信息增益
```
IG(K) = 0.5 · log det(I + Σ J_c^T K^T Σ_w^{-1} K J_c)
```
多接触按块对角拼接 `H = [K_1J_{c1}; ...; K_CJ_{cC}]`。`IG` 随 `‖K‖` 单调增，与 `C_force` 的刚度上界直接冲突。

**定义 126（位姿-柔顺联合证书）**
`J_pc = (b, K, C_force, IG, γ_ce, evidence)`。可部署条件：
```
∀m: w_m>0 ⇒ Supp(b_m) ⊆ 安全接触流形 M_safe
∧ C_force valid (ε_F ≤ ε_F^max)
∧ A(K,Σ_ξ) ≥ θ_A
∧ IG(K) ≥ IG_min (仅探测阶段)
```
其中 `M_safe` 为满足无自碰撞、可达、摩擦锥内、力界内的位姿集合。

**定义 127（技能位姿-柔顺剖面）**
技能 `S` 的剖面扩展为 `α_S : A × Supp(b) → [0,1]` 与 `β_S : A → 2^{Sym⁺(3)}`（每个动作允许的刚度集合）。组合 `S_i⊗S_j` 可行，当且仅当第 54 轮动作兼容/鲁棒性条件成立，且
```
∃ a ∈ A_i∩A_j : β_{S_i}(a) ∩ β_{S_j}(a) ≠ ∅ ∧ A(K,Σ_ξ) ≥ θ_A
```
这把柔顺能力纳入第 54 轮的技能组合图 `G_S` 边判定。

## 2. 关键算法 伪代码

### IP-121 UAC（Uncertainty-Aware Compliance）
```python
def uac_stiffness(belief, geometry, F_max, eps_F):
    n, Jc = geometry.n, contact_jacobian(geometry)
    z = sqrt(2 * log(2 * len(belief) / eps_F))
    K = {}
    for m in belief.modes:
        s_n = sqrt(n.T @ Jc @ m.Sigma @ Jc.T @ n)
        mu_n = abs(n.T @ Jc @ m.mu)
        k_n_max = F_max / (mu_n + z * s_n + 1e-9)
        k_n = min(k_n_max, geometry.k_n_task)      # 任务刚度不得超过安全上界
        k_t = min(geometry.k_t_task, mu_f * k_n)   # 切向受摩擦锥约束
        K[m.id] = Rc(n) @ diag(k_n, k_t, k_t) @ Rc(n).T
    return K

def aligned_check(K, Sigma, theta_A):
    U, k = eigh(K); V, s2 = eigh(Sigma)
    return alignment(U, V, s2) >= theta_A
```

### IP-122 CAP（Compliance-as-Probe）
```python
def probe_policy(belief, task, budget):
    if max_eig(belief.Sigma) <= sigma_conf:      # 已足够确定 → 不探测
        return uac_stiffness(belief, task.geom, budget.F_max, budget.eps_F)
    K_safe = uac_stiffness(belief, task.geom, budget.F_max, budget.eps_F)
    # 在安全刚度上界内取探测更硬的一档，贴着力预算但不越界
    for gamma in linspace(1.0, 0.6, 9):
        K_probe = scale_stiffness(K_safe[task.mode], gamma)
        if force_bound(belief, K_probe, task.geom) <= budget.eps_F:
            return K_probe
    return K_safe
```

def force_safety_filter(K_des, belief, geom, F_max, eps_F):
    for _ in range(max_proj):
        eps = bound_all_modes(belief, K_des, geom)   # union bound

### IP-124 CPR（Contact Pose Refinement）
```python
def contact_pose_update(belief, wrench, geom, K):
    J = K @ contact_jacobian(geom)           # 1..C x 6
    for m in belief.modes:
        S = J @ m.Sigma @ J.T + geom.Sigma_w
        G = m.Sigma @ J.T @ inv(S)
        m.mu = se3_boxplus(m.mu, G @ (wrench - J @ zeros6))
        m.Sigma = (I - G @ J) @ m.Sigma
    return normalize_weights(belief)          # 重归一化 + 模式合并
```

### IP-125 PCC（Pose-Compliance Consistency Certificate）
```python
def pose_compliance_cert(belief, K, geom, F_max, eps_F, theta_A):
    if not all(support_in_manifold(m, geom.M_safe) for m in belief.modes):
        return ('reject', 'pose_out_of_safe_manifold')
    if not aligned_check(K, belief.Sigma, theta_A):
        return ('reject', 'compliance_frame_misaligned')
    C_force = contact_force_cert(belief, K, geom, F_max, eps_F)
    if C_force.epsilon > eps_F:
        return ('reject', 'force_budget_exceeded', C_force)
    return ('ok', JpCert(belief, K, C_force, IG=info_gain(belief, K, geom)))
```

## 3. 关键推导与正确性

**推导 1（单接触力尾界）**
设位姿误差 `ξ ~ N(μ, Σ)`，接触点法向位移 `δ_n = n^T J_c ξ ~ N(μ_n, s_n²)`，`s_n² = n^T J_c Σ J_c^T n`。线性弹性 `F_n = k_n δ_n ~ N(k_n μ_n, k_n² s_n²)`。由高斯尾界
```
P(|F_n| > F_max) ≤ 2 exp(-(F_max - k_n|μ_n|)² / (2 k_n² s_n²))
```
令右端 `≤ ε_F`，解出 `k_n ≤ F_max / (|μ_n| + z s_n)`，`z = sqrt(2 ln(2/ε_F))`。这是定义 122 中刚度的来源，也是柔顺"越不确定越软"的严格依据。

**推导 2（信息-安全权衡）**
`IG(K) = 0.5 log(1 + k_n² s_n²/σ_w²)` 关于 `k_n` 单调增；而力安全上界 `k_n^{max}` 关于 `s_n` 单调减。因此在给定力预算下，最优探测刚度为角点解 `k_n^* = min(k_n^{max}, sqrt((e^{2IG_min}-1)σ_w²/s_n²))`：
- 位姿越不确定（`s_n` 大）→ `k_n^{max}` 越小 → 越不允许硬探；
- 若信息目标低 → 直接取任务刚度，不探测。
这解释了"探测不是越硬越好"，也给出何时闭嘴不探的判据。

**推导 3（多模态安全）**
对称物体信念多峰时，单高斯会把两峰间低概率区填成高概率，导致 `s_n` 低估。改用混合后
`P(‖F‖>F_max) ≤ Σ_m w_m P_m(‖F‖>F_max)`，每模态独立取上界，再对接触点做 union bound。该界保守但 sound。

**定理（Pose-Aware Contact Safety Soundness）**
假设第 54 轮 (A22)–(A28) 成立；**(A29)** 位姿信念 `b` 经留出集校准，模态覆盖率为 `1-δ_b`；**(A30)** 接触在证书有效期内满足线性弹性且摩擦系数真值落在 `[μ_f/2, 2μ_f]`；**(A31)** 力/力矩传感延迟 ≤ `τ_F` 且偏置可在线辨识。则
```
P(‖F‖>F_max ∨ 位姿出安全流形) ≤ ε_F + δ_b + P(模型失配) + β_E
```
其中 `β_E` 为第 54 轮仿真-现实误差项。关键：**柔顺参数必须由位姿信念生成，力安全证书必须逐模态验证**，否则"高置信位姿 + 固定刚度"会在对称/遮挡场景系统性突破力界。

## 7. 本轮最大风险

**一句话**：把 6D 位姿估计从点升级为信念、再用信念生成柔顺椭球与力安全证书，确实把"接触操作"从经验调参变成了可判定的概率保证，但整套 soundness **同时押注 SE(3) 协方差的校准、线性接触模型的成立、以及多模态信念不被合并**；一旦真实接触的非线性/摩擦使力尾界系统性偏乐观，或对称物体双峰被压成单高斯，力安全证书会在最需要它的极限接触处给出"假安全"，因此必须以**协方差温度标定 + 非线性接触保守包络 + 逐模态验证 + 探测力硬门**四重护栏，宁可少探、软一点，也绝不让证书替真实力买单。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（UAC×CAP×FSF×CPR×PCC×PCT）

> 承接第 54 轮产物 v31。本轮在第 54 轮"动作-鲁棒性双证书"之上，补上接触层：**位姿信念化、柔顺不确定性对齐、柔顺即探测、力安全证书、云边位姿-柔顺迁移**。
> - **UAC（Uncertainty-Aware Compliance）**：由 SE(3) 位姿信念与接触几何生成柔顺椭球 `K(b,G)`；
> - **CAP（Compliance-as-Probe）**：把柔顺同时当执行器与传感器，做信息-安全权衡下的主动探测；
> - **FSF（Force Safety Filter）**：以位姿协方差与摩擦锥为约束的力安全投影滤波；
> - **CPR（Contact Pose Refinement）**：用接触力/力矩反向更新位姿信念（SE(3) 滤波更新）；
> - **PCC（Pose-Compliance Consistency）**：位姿-柔顺联合证书 `J_pc`；
> - **PCT（Pose-Compliance Transfer）**：云端全局位姿先验 ↔ 边端柔顺伺服 ↔ 力事件回传。

## 2. 关键算法 伪代码

### IP-121 UAC
```python
def uac_stiffness(belief, geometry, F_max, eps_F, mu_f):
    n, Jc = geometry.n, contact_jacobian(geometry)
    z = sqrt(2 * log(2 * len(belief) / eps_F))
    K = {}
    for m in belief.modes:
        s_n  = sqrt(n.T @ Jc @ m.Sigma @ Jc.T @ n)
        mu_n = abs(n.T @ Jc @ m.mu)
        k_n  = min(geometry.k_n_task, F_max / (mu_n + z*s_n + 1e-9))
        k_t  = min(geometry.k_t_task, mu_f * k_n)
        K[m.id] = Rc(n) @ diag(k_n, k_t, k_t) @ Rc(n).T
    return K
```

### IP-122 CAP
```python
def probe_policy(belief, task, budget):
    if max_eig(belief.Sigma) <= sigma_conf:
        return uac_stiffness(belief, task.geom, budget.F_max, budget.eps_F, task.mu_f)
    base = uac_stiffness(belief, task.geom, budget.F_max, budget.eps_F, task.mu_f)
    for gamma in linspace(1.0, 0.6, 9):
        K = scale_stiffness(base[task.mode], gamma)
        if bound_all_modes(belief, K, task.geom) <= budget.eps_F:
            return K
    return base
```

def force_safety_filter(K_des, belief, geom, F_max, eps_F):

### IP-124 CPR
```python
def contact_pose_update(belief, wrench, geom, K):
    J = K @ contact_jacobian(geom)
    for m in belief.modes:
        S = J @ m.Sigma @ J.T + geom.Sigma_w
        G = m.Sigma @ J.T @ inv(S)
        m.mu    = se3_boxplus(m.mu, G @ (wrench - predict_wrench(m, geom, K)))
        m.Sigma = (I - G @ J) @ m.Sigma
    return normalize_weights(belief)
```

### IP-125 PCC
```python
def pose_compliance_cert(belief, K, geom, F_max, eps_F, theta_A, IG_min=None):
    for m in belief.modes:
        if not support_in_manifold(m, geom.M_safe):
            return ('reject', 'pose_out_of_safe_manifold', m.id)
    if alignment(K, belief.Sigma) < theta_A:
        return ('reject', 'compliance_frame_misaligned')
    C = contact_force_cert(belief, K, geom, F_max, eps_F)
    if C.epsilon > eps_F:
        return ('reject', 'force_budget_exceeded', C.epsilon)
    ig = info_gain(belief, K, geom)
    if IG_min is not None and ig < IG_min:
        return ('reject', 'insufficient_probe_info', ig)
    return ('ok', JpCert(belief, K, C, ig))
```

def cloud_edge_pose_compliance(cloud_belief, edge_tracker, gamma_ce, budget):

## 3. 推导：力尾界与探测角点解

接触法向 `δ_n = nᵀJ_cξ ~ N(μ_n, s_n²)`，`F_n = k_nδ_n`，故
```
P(|F_n| > F_max) ≤ 2exp(-(F_max - k_n|μ_n|)²/(2k_n²s_n²)) ≤ ε_F
⇒  k_n ≤ F_max / (|μ_n| + z·s_n),   z = sqrt(2ln(2/ε_F))
```
信息增益 `IG(K) = 0.5log(1 + k_n²s_n²/σ_w²)`，关于 `k_n` 增；力界关于 `s_n` 降。最优探测刚度
```
k_n* = min( F_max/(|μ_n|+z s_n),  sqrt((e^{2IG_min}-1)σ_w²/s_n²) )
```
即"信息够了就不探，探则贴着力预算但不越界"。多模态安全用
`P ≤ Σ_m w_m Σ_c ε_{F,m,c}`（逐模态 + 接触 union bound），比单高斯 sound 但保守。

## 7. 本轮最大风险

**一句话**：把 6D 位姿估计从点升级为信念、再用信念生成柔顺椭球与力安全证书，确实把接触操作从经验调参变成可判定的概率保证，但整套 soundness **同时押注 SE(3) 协方差校准、线性接触模型成立、以及多模态信念不被合并**；一旦真实接触的非线性/摩擦使力尾界系统性偏乐观，或对称物体双峰被压成单高斯，力安全证书会在最需要它的极限接触处给出"假安全"，因此必须以**协方差温度标定 + 非线性接触保守包络 + 逐模态验证 + 探测力硬门**四重护栏，宁可少探、软一点，也绝不让证书替真实力买单。
