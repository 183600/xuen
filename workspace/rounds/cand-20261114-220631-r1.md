# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「UniBot世界挑战赛」×「共享控制」）

> R69 把不确定性一分为二（aleatoric / epistemic），用流匹配多模态策略生成候选动作，再用「看 / 问 / 触」主动消解歧义。但它仍站着两个未检验的假设：
>
> 1. **交互是离散、外生、单向的。** R69 的「问」把人类放在回路之外，当作一台回答隐变量的神谕：问一句，得到一个带噪读数，更新后验。但共享控制里，人和机器人接在**同一组执行器**上，人的操纵杆、力、注视是**连续、高带宽、双向**的通道；真正的证据不是「一句回答」，而是**纠正、让权、接管、迟疑**这些控制事件。
> 2. **策略是动作的唯一作者。** 实际执行的动作是人与机器人命令经仲裁律融合后的结果。于是「谁在控制、占多少、谁该负责」本身成为一等不确定量，而不能被折叠进「机器人选哪个模态」。
>
> 更要命的是一个观察者悖论：**机器人的辅助会改变人的行为，而系统又用人的行为去推断人的能力。** 医生给重病患者开药，药物看起来更危险（confounding by indication）；机器人给「看起来不行」的人更多辅助，人的表现因此变好，朴素学习便得出「他其实很行」——越辅助越放心，越放心越过度委派。共享控制里最危险的错误，正是**在最需要接管的时刻把方向盘交出去**。
>
> 两个灵感正好各补一刀：
> - **共享控制**提供连续的控制通道与权威变量 α：α 是 R68 的 λ 的严格泛化——λ 是「只允许机器人动」时的标量特例，α 是「谁的命令进入执行器、占多少」的向量；
> - **UniBot 世界挑战赛**要求一套策略跨异构身体、跨陌生操作员、跨任务族、在公开榜单和对抗评分下工作。这逼出三件事：可移植的因果结构、身体无关的先验 + 在线少样本系统辨识、以及不可被榜单游戏化的责任审计。
>
> 核心命题：**把 R69 的「离散求证」升级为「连续共享控制中的因果辨识 + 权威分配」：人的控制输入是内生证据（被机器人辅助干预所混杂），必须用预算内的干预/工具变量做因果辨识；权威 α 是新的风险旋钮，随不确定性、注意力与可移植性自适应；任何时刻必须有唯一权威或认证的混合律、至少一方可问责地注意、以及一条逐身体硬保证的单一权威兜底；当辨识失效、注意力空窗或被对抗污染时，退化为 R68/R69 的保守边界。** 命名 **TANDEM-RAS**（Trust-calibrated Authority-Negotiated Dyadic Embodiment-agnostic Meta-control for Risk-adaptive Shared autonomy）——像双人自行车：两人都踩，但必须持续协商谁扶把；同时抢把会摔，同时撒把更会摔。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我们怎样握住同一个方向盘，谁在什么时候真的有资格负责，而且换一套身体、换一个人还成立吗**」——不确定性不只是刹车或提问，也可以是一次让权、一次接管、一次「我先替你扶着，直到你证明你能行」。

## 0. 直觉与动机

**灵感 1（共享控制 → 人不是神谕，而是同一执行器上的第二个控制源）**
直觉：R69 眼中的交互是「机器人问、人类答」，人类在回路外。共享控制把人类放进回路内：两者同时对同一自由度施力/给速度，经仲裁律融合成实际命令。于是「回答」不再是离散符号，而是**连续控制信号中的残差**：人往左修正，说明他想要左；人松手，说明他放弃或没注意；人突然反向，说明意图变了或他在纠正机器人的错误。控制通道因此成为一条**免费、高带宽、但被机器人自己污染**的证据流。R70 的第一性对象不是「隐变量 + 回答」，而是「**闭环耦合的两个控制源 + 一条权威分配律**」。

**灵感 2（内生证据 → 观察者在回路里，朴素反推必然有偏）**
直觉：用人的行为反推人的能力，前提是行为不被机器人改变。但辅助恰恰会改变行为。设机器人越不确定越辅助，辅助越多人表现越好，那么「辅助多」与「表现好」正相关；朴素回归会把辅助的功劳记到人的能力上，得出「需要辅助的人其实能力强」。这是医学里的 **confounding by indication**，在共享控制里会形成**过度委派螺旋**：误判能力高 → 减少辅助/交出权威 → 表现骤降 → 但系统又把它解释为偶发噪声 → 继续委派。核心科学问题不是「怎么估能力」，而是「**怎么在机器人自己制造的混杂下估能力**」。这需要干预（小幅权威抖动）或工具变量（外生任务事件），而不是更多数据。

**灵感 3（权威作为风险旋钮 → α 是 λ 的向量化泛化）**
直觉：R68 面对不确定只会收紧 λ，R69 消歧后给 resolution bonus。但共享控制里真正的执行旋钮是**权威 α**：不是「机器人动作做小一点」，而是「这个自由度现在由谁主导、混合比例多少」。R68 的 λ 是 α 在「机器人独占执行器、人类不参与」时的标量化退化；R69 的「消歧后放松」是 α 从保守分配回到高效分配的特例。把不确定性映射到 α，而不是只映射到速度，才可能在保证安全的同时保留共享控制的流畅与效率。**权威分配是比风险缩放更高一层的控制对象。**

**灵感 4（UniBot 世界挑战赛 → 可移植性不是调参，是因果结构 + 硬安全核）**
直觉：世界挑战赛的杀伤力不在单任务难度，而在**组合泛化**：同一个策略要上不同身体、配不同操作员、跑长时程、还要在公开榜单的对抗评分下不被游戏。跨身体意味着动力学与运动学不同；跨操作员意味着意图、能力、信任、反应延迟的分布不同；对抗评分意味着有人会「装弱」诱使机器人做危险动作、或用噪声污染辨识。可移植的只能是**结构**（因果图、权威不变式、风险单调性），不能是具体参数；安全过滤器必须逐身体硬编码并认证，**绝不能被元学习**。元学习只学「先验与适应速度」，不学「安全」。

**灵感 5（共享 ≠ 冗余 → 责任扩散可能让共享更不安全）**
直觉：R68/R69 默认人类是独立的安全备份。共享控制把人变成同一回路的组件，去掉了独立性：机器人显得自信，人就停止监控；人显得能干，机器人就减少监控。两种过度信任会让**注意力同时离线**，其相关性为正，故「两人都不看」的概率可能高于任一单独控制者。也可能两人同时抢控制（权属冲突），内部力打架、执行器饱和。于是出现反直觉结论：**共享控制可以在提高任务成功率的同时降低总安全性**。R70 必须交付注意力不变式、权属冲突/空窗检测、单一权威兜底，否则「共享」只是把责任摊薄到没人负责。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（TANDEM-RAS 总览与不变式）** TANDEM-RAS = (SCL, OPM, ECI, ABX, A-VoI, RAA, SAF, META, RCL, DFG, RAS-WM⋈)。六条不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **权属唯一性**：任一时刻每个共享自由度必须恰有一个权属主体，或处于显式认证的混合律下（定义 311）；权属冲突/空窗须在反应时 δ_R 内消解（定义 315）；
(iii) **注意力不变式**：任一时刻至少一方处于可认证的注意状态，且监控责任不得被双方同时外包（定义 322）；
(iv) **内生证据纪律**：关于操作员能力/意图的推断必须来自因果估计（干预/工具变量），否则显式标记为「受混杂」并折价（定义 313–314）；
(v) **单一权威兜底可达**：任一时刻存在一个逐身体认证的控制器，可在 δ_R 内取得全部权威（定义 318）；
(vi) **不可抵赖**：权威/贡献日志防篡改，并进入证书（定义 321）。

**定义 311（共享控制律 SCL 与权威场）** 共享自由度集合 𝒟_S。人命令 u_H ∈ ℝ^{d_S}，机器人命令 u_R ∈ ℝ^{d_S}。逐自由度权威 α_t ∈ [0,1]^{d_S}，实际执行
u_t = Blend(u_H, u_R, α_t)，Blend 可在速度/力/阻抗空间定义为凸组合或认证仲裁律。**权威场** A_t = (α_t, gate_t, blend_law_t)；α=1 为人主导，α=0 为机器人主导。执行前经安全滤波：u_t ← Proj_{SafeSet(x_t)}(u_t)。R69 的纯机器人情形是 d_S=∅ 或 α≡0。

**定义 312（操作员隐状态与可信模型 OPM）** θ_H = (g*, κ, w, τ, δ, ρ)：意图、能力、工作负荷、信任、反应延迟、风险偏好。可观测量含 u_H、注视、施力、时序、纠正事件。维护 credal 集 Θ_t（conformal 覆盖率 ≥ 1−α_conf 与后验的合成）。严格区分四件事：**能做（can）、此刻愿做（will）、已承诺做（agreed）、正在注意（attentive）**。R69 的「回答」是 g* 的一次高延迟、离散、可能被投毒的观测，是本模型的特例。

**定义 313（内生证据 ECI）** 人类策略 π_H(u_H | x, θ_H, A, h_R)，其中 h_R 为机器人引导，A 为权威场。纠正量 e_t = u_H − u_R **不是**意图误差的无偏测量，它是在机器人自身干预 A_{t−δ:t} 下生成的。定义**辅助响应函数** R_H(a) = E[π_H | do(A=a)] 与**关联观测** Q_H(a) = E[π_H | A=a]，**混杂间隙** B(a) = Q_H(a) − R_H(a)。朴素能力学习用的始终是 Q，故有偏。

**定义 314（因果能力与辅助偏置）** 因果能力 κ_cf = E_{do(A=A_fix)}[任务成功 | θ_H]；辅助偏置 B_κ = κ_naive − κ_cf。辨识手段三选一或组合：(a) 预算内权威抖动 do(A = A* + ε)；(b) 工具变量——只推动机器人辅助、不直接影响人类能力的外生任务事件（难度突变、目标平移）；(c) 自然实验——换人/换身体前后的断点。可辨识条件：正性/重叠 + 排他性。

**定义 315（权属冲突与空窗 ABX）** 权属冲突 A_conf = 1[双方命令对同一自由度均有因果作用且分歧超 δ_u]；权属空窗 A_void = 1[无一方命令有因果作用，或双方注意均低于阈值]。定义冲突/空窗的**权威安全包络**：A_conf 造成内力/饱和风险，A_void 造成失控风险，二者都在 δ_R 内必须被 ABX 消解（冻结该自由度、交给认证兜底、或强制唯一权威）。

**定义 316（权威价值 A-VoI）** 对一个权威/辅助动作 a_A（让权、引导、抖动探针、提问、接管）：
A-VoI(a_A) = I(θ_H; Y | do(a_A)) − λ_c·cost(a_A) − λ_s·risk(a_A) + pragmatic_gain(a_A)。
选择 argmax，s.t. 安全与预算。R69 的 MINT 是「无共享自由度、a_A 仅为离散问句」的特例。关键区分：**认知探针**（为辨识而抖动权威，可能牺牲瞬时性能）与**务实授权**（为任务而让权，可能牺牲辨识机会）。

**定义 317（风险自适应权威 RAA）** α* = argmax_α E[U(task, safety) | Θ_t, α]，s.t. risk ≤ ε。单调性：安全关键自由度上 ∂α_H*/∂U_epi ≤ 0（越不确定越不把关键权交给未标定的人）；非关键、语义/柔性任务上可反向，因为人更擅长开放语义。当 d_S=∅ 时 α* 退化为标量，λ_floor 与 R69 的 resolution bonus 都是它的边界情形。**α 是向量值、带门控的 λ。**

**定义 318（单一权威兜底 SAF）** 逐身体认证控制器 C_body，带不变集 SafeSet_body；可在 δ_R 内取得全部权威。要求：**接管可达**、**无扰切换**（bumpless transfer，命令连续）、**取消后可控**。解耦条件：因果辨识失效、注意力不变式破裂、或 META 报 OOD 时，α 交给 C_body 或交给唯一被认证在注意的一方。

**定义 319（跨身体/跨操作员元适应 META）** 在身体族 ℬ 与操作员族 ℋ 上学习元策略 π_meta，含共享潜变量 z_body、z_op 与适应规则；在线少样本更新。**安全滤波器、SafeSet、证书生成器不参与元学习**——它们逐身体硬保证。定义**可移植间隙** PG = E_{新身体/新操作员}[risk] − E_{元训练}[risk]。

**定义 320（可移植门与 OOD）** 用密度/共形非一致性/响应模型残差检测新身体或新操作员是否越出元分布。OOD 时：禁用激进授权，退回保守 α（定义 318），并在证书标记。**元先验不得覆盖硬安全滤波。**

**定义 321（责任链账本 RCL）** 追加式、防篡改日志 L_t = {x_t, u_H, u_R, α_t, u_t, 安全滤波干预, 注意力估计, 证书哈希}；定义执行命令的**因果贡献份额** (s_H, s_R)（对 Blend 做 Shapley/消融归因）。用哈希链/签名实现不可抵赖，支撑事后责任归因与反榜单游戏。

**定义 322（责任扩散守卫 DFG）** 由注视/姿态/施力/反应时估计注意状态 att_H, att_R。注意力不变式 att_H ∨ att_R。检测 **双离线**（双方均低于阈值）与 **双在线冲突**（双方都抢控制）。双离线时在 δ_R 内逐级升级：触觉/听觉提示 → 请求接管 → 安全停。禁止「监控是别人的事」。

**定义 323（威胁模型 ℰ_TANDEM）** ℰ_TANDEM = ℰ_FLUID × ℰ_shared，其中 ℰ_shared = {武器化无能（装弱诱使机器人做危险动作）、权威抢夺、纠正投毒（注入噪声偏置辨识）、幽灵控制（事后否认在控）、共谋/榜单游戏、责任洗白}。

**定义 324（证书 J_TANDEM）** J_TANDEM = (J_FLUID, κ_cf, B_κ, causal_ident_valid, A_conf_count, A_void_count, attention_violations, PG, meta_OOD, responsibility_log_hash, safety_margin)。Valid ⇔ Valid(J_FLUID) ∧ （辨识有效或已折价）∧ 权属不变式 ∧ 注意力不变式 ∧ 兜底可达。

**定义 325（UniBot-WC 评测协议）** 划分：S1 同分布；S2 新操作员；S3 新身体；S4 长时程漂移；S5 对抗/游戏。指标：成功率、每小时安全违规、干预成本、流畅度、迁移间隙、责任审计通过率、游戏检测率。榜分 S = success − λ_s·safety − λ_i·intervention − λ_g·gaming，日志/种子可复现。

**定义 326（TANDEM 闭环）** 每拍：读 u_H/注意 → 更新 OPM → 估计/折价 κ_cf（必要时抖动或 IV）→ A-VoI 选权威动作 → RAA 定 α → ABX 融合 + 安全滤波 → DFG 守注意力 → 单一权威兜底守底 → RCL 记账 → 审计/证书。

```python
# IP-264 SCL：权威场 + 安全滤波 + 冲突/空窗检测
class SharedControlLaw:
    def fuse(self, u_H, u_R, alpha, x):
        u = alpha * u_H + (1 - alpha) * u_R        # 逐自由度；可为力/阻抗空间
        u_safe = project_cbf(u, x, self.safe_set)  # 硬安全，never meta-learned
        conflict = self.disagree(u_H, u_R) and self.both_effective(alpha)
        void     = (not self.any_effective(alpha)) or self.both_inattentive()
        return u_safe, AuthorityState(conflict, void)

# IP-265 OPM：隐状态后验 + can/will/agreed/attentive 分离
def update_operator(obs, A_hist):
    post = bayes_conformal_update(prior=theta, obs=obs, model=human_model)
    can, will = post.kappa_credal, post.avail_prob
    agreed    = evidence_of_commitment(obs)        # 口头/动作承诺，非能力
    attentive = attention_estimate(obs)            # 注视/反应/施力
    return theta_post(post, can, will, agreed, attentive)

# IP-266 ECI：在机器人自己制造的混杂下做因果辨识
def causal_competence(obs, dither_budget, iv_events):
    # 关联估计（有偏，仅作对照）
    k_naive = regress_outcome_on_authority(obs)
    # 干预/IV 估计（去混杂）
    if dither_budget.available():
        A_do = perturb(self.last_A, eps=dither_budget.eps)   # do(A)
        k_cf = iv_or_do_estimate(obs, A_do, iv_events)
    else:
        k_cf = iv_estimate(obs, iv_events)                    # 只靠外生事件
    B_k = k_naive - k_cf                                      # 辅助偏置
    return k_cf, B_k, overlap_ok(obs), exclusion_ok(iv_events)

# IP-268 A-VoI：选权威动作（让权/引导/抖动/提问）
def authority_voi(theta_post, candidates):
    best = None
    for a in candidates:
        if not budget.allow(a) or not rcl.preauthorized(a): continue
        info   = mutual_info(theta_post, a)                   # 认知增益
        prag   = expected_task_gain(theta_post, a)            # 务实增益
        score  = info + prag - cost(a) - risk(a)
        if best is None or score > best.score: best = (a, score)
    return best if best and best.score > 0 else None          # 无利可图→R69/R68

# IP-269 RAA：不确定性/注意力/可移植性 → 权威
def risk_adaptive_authority(theta_post, U_epi, U_ale, attention, meta_ood):
    alpha = solve_max_utility(theta_post, risk_cap=EPS)
    if meta_ood or (not causal_ident_valid(theta_post)):
        alpha = conservative_authority(alpha)                 # 关键自由度交给兜底
    if not attention.any(): alpha = sole_authority(self.certified_ctrl)
    return monotone_shrink_on_critical_dofs(alpha, U_epi + U_ale)

# IP-271 RCL + IP-272 DFG：责任链与责任扩散守卫
def log_and_guard(x, u_H, u_R, alpha, u, att):
```

## 3. 推导

**引理 19（内生证据的混杂偏置 / confounding by indication）** 设机器人按信念 b(θ_H) 选权威 α = f(b)，人类响应 y = κ(θ_H) + γ·(α − α₀) + ε，其中 γ 为辅助效应。若用关联数据回归 y 对 α 的系数来估 κ，则
E[κ̂_naive] = κ + γ·Cov(α, b)/Var(α) + o(1)。
因为 α 是 b 的单调函数，Cov(α,b)>0，故当辅助有效（γ>0）时能力被系统性高估。进一步，若委派规则 ∂α_H/∂κ̂ > 0，则形成闭环
κ̂_{t+1} = κ̂_t + η·γ·χ·(κ − κ̂_t)，χ = ∂α/∂κ̂；
稳定条件 η·γ·χ < 2；一旦 χ 足够大（越自信越放手）且 γ>0，κ̂ 单调漂向「高能力」不动点，即**过度委派螺旋**。要点：不是数据太少，而是**数据生成机制被策略自身篡改**；更多数据只会更自信地错。

**引理 20（权威抖动/IV 的可辨识性与探测-安全权衡）** 在正性与排他性下，幅度 ε 的随机抖动给出 |B̂_κ − B_κ| = O(σ/(√n·ε))；其安全成本 = O(ε·L_s)。故最优探测幅度 ε* ∝ (σ²/(n·L_s))^{1/3}，辨识误差与安全成本不可同时压到零。工具变量（外生任务事件）在排他性成立时可把安全成本降到 O(0) 而保持可辨识，代价是方差更高、需检验排他性。系：**共享控制中的「了解人」永远要付一笔安全税**；R69 那种零成本「问一句」只是把税转嫁给了外部回答者。

**引理 21（权威是 λ 的严格泛化）** 当 d_S=∅ 或 α≡0 时，RAA 退化为只对机器人动作做风险缩放，α* 的保守分支逐指令等于 R68 的 λ_floor(U_ale+未消解 U_epi)；当 R69 消歧成功且 d_S 仅含非关键自由度时，RAA 的 β 分支给出 R69 的 resolution bonus。即 TANDEM 的权威分配在两种边界上分别复现 R68 与 R69，且 α 的向量结构在中间区域提供二者都没有的「按自由度分配风险」能力。

**定理 18（TANDEM 严格包含 R68/R69）** 在 A99（因果辨识有效或已正确折价）、A100（注意力不变式与兜底可达）下，对任意状态 TANDEM 的期望风险 ≤ max(R68 风险, R69 风险) + δ_R·L_react；且当「人类为外生神谕（无共享自由度、无内生反馈）」时，TANDEM 与 R69 逐指令一致；当「无共享自由度且仅机器人执行」时，与 R68 逐指令一致。安全侧不因共享而让步，效率/流畅收益只在辨识有效且注意力在线时兑现。

**定理 19（共享可能比单控更不安全；注意力不变式恢复上界）** 设单控失效概率 p_H, p_R。若双方注意力独立，双离线概率 p_H p_R < min(p_H,p_R)，共享有益。但过度信任使注意力**正相关耦合**：att_H = f(机器人自信), att_R = g(人类表面能力)，二者由同一「看起来都行」的信号驱动。此时 P(双离线) 可大于 max(p_H,p_R)。构造性反例：p_H=p_R=0.1，独立时双离线 0.01；强正相关时可达 0.1。**系**：加入 DFG 的注意力不变式（至少一方注意不可外包 + 双离线 δ_R 内升级）后，双离线持续时间 ≤ δ_R，风险回到 ≤ max + δ_R·L；无此不变式时，共享控制的成功率上升可以掩盖总安全性的下降。

**引理 22（可移植间隙界）** 设元策略在 (身体, 操作员) 上的表示差异为 D(z_new, Z_train)，新任务新颖度为 ν，安全滤波器逐身体精确。则 PG ≤ L_meta·(D + ν) + mismatch(SafeSet_new, SafeSet_train)。OOD 门触发时，PG 被兜底控制器的风险封顶。要点：**可移植的是结构与先验，不是安全**；硬安全核必须逐身体重新认证，否则「通用」只是把误差搬到了新身体上。

**引理 23（责任链的抗洗白性）** 若 RCL 为哈希链且因果份额 s_H, s_R 由对 Blend 的消融归因给出，则「幽灵控制」式否认的成功概率 ≤ Pr[哈希碰撞/签名伪造] + Pr[归因估计误差 > δ_s]；后者随抖动/IV 样本与重叠度下降。故责任可归因性本身也是一个可辨识性问题，与能力辨识共享同一套干预预算。

## 6. 本轮最大风险

**一句话**：TANDEM-RAS 的全部收益押在「能从机器人自己制造的反馈回路里**因果地**辨识操作员能力与意图」这一前提上——**若辨识把「人对辅助的适应」误读成「人的能力」，系统就会触发过度委派螺旋：在最需要接管的时刻最放心地把方向盘交出去；而共享控制又恰好通过注意力的正相关耦合，让双方同时停止监控，于是它一边刷新任务成功率，一边把总安全性降到比任何单方控制都低**——此时的「共享」不是协作，而是一台**责任洗白机器**。

**次级风险与缓解**：
1. **探测本身不安全**（权威抖动的安全税）→ 引理 20 的最优幅度 + IV 优先 + 硬 CBF；
2. **责任扩散/过度信任** → DFG 注意力不变式 + 定理 19 上界 + 逐身体单一权威兜底；
3. **跨身体/跨操作员的负迁移** → META 只学先验与适应速度 + 逐身体硬安全核 + OOD 门退回保守；
4. **对抗与榜单游戏**（装弱、纠正投毒、幽灵控制）→ ℰ_shared 对抗训练 + RCL 不可抵赖 + 证据纪律；
5. **过度委派与责任洗白** → ECI 因果辨识 + B_κ 折价 + κ_cf 进入证书，辨识无效即退回 R68/R69 保守边界。

---

**本轮一句风险**：如果因果辨识不可靠，共享控制会把「能力误读」变成「系统性过度委派」，并用注意力的相关耦合让双方一起松手——共享提高成功率的同时，可能把总安全性降到比单控更低。

**定义 310（总览与六不变式）** TANDEM-RAS = (SCL,OPM,ECI,ABX,A-VoI,RAA,SAF,META,RCL,DFG,RAS-WM⋈)；零学习写操作继承；权属唯一性与 δ_R 内消解；注意力不变式（至少一方可认证注意）；内生证据纪律（因果估计或显式折价）；单一权威兜底可达；责任链不可抵赖。

**定义 311–312（SCL 与 OPM）** `u=Blend(u_H,u_R,α)` 后过硬 CBF；权威场 `A=(α,gate,blend_law)`。`θ_H` 含意图/能力/负荷/信任/延迟/风险偏好，维护 credal 集；区分 can/will/agreed/attentive。

**定义 313–314（内生证据与因果能力）** 人类策略 `π_H(u_H|x,θ_H,A,h_R)`；纠正量在机器人干预下生成，`e=u_H−u_R` 不是意图误差的无偏测量。`κ_cf=E_{do(A=A_fix)}[成功]`，`B_κ=κ_naive−κ_cf`。辨识：预算内权威抖动 / 外生事件工具变量 / 换人换身体自然实验；条件为正性重叠 + 排他性。

**定义 315–316（ABX 与 A-VoI）** `A_conf=1[双方命令均有效且分歧>δ_u]`，`A_void=1[均无效或双方注意低于阈值]`，δ_R 内消解。`a_A*=argmax[I(θ_H;Y|do(a_A))−λ_c·cost−λ_s·risk+pragmatic]`；区分认知探针与务实授权；R69 MINT 为无共享自由度特例。

**定义 317–318（RAA 与 SAF）** `α*=argmax_α E[U(task,safety)|Θ_t,α]`，s.t. risk≤ε；安全关键自由度上随不确定性单调收紧，非关键/语义任务可交还人类；`d_S=∅` 退化为 R68 λ，R69 消歧对应 resolution bonus。`C_body` 可在 δ_R 内取得全权威，要求接管可达/无扰切换/取消后可控；解耦条件为辨识失效、注意力破裂、META OOD。

**定义 319–320（META 与 OOD）** 元策略含 `z_body, z_op` 与在线少样本适应；安全滤波器/SafeSet/证书不参与元学习。`PG=E_新[risk]−E_元训练[risk]`；OOD 时禁用激进授权、退回保守 α 并在证书标记。

**定义 321–322（RCL 与 DFG）** 追加式防篡改日志 `L_t={x,u_H,u_R,α,u,滤波干预,注意估计,证书哈希}` + 因果份额 `(s_H,s_R)`；注意力不变式 `att_H∨att_R`，双离线 δ_R 内「提示→接管→安全停」，双在线冲突冻结自由度并交给兜底。

**定义 323–326（威胁/证书/评测/闭环）** `ℰ_TANDEM=ℰ_FLUID×ℰ_shared`（武器化无能、权威抢夺、纠正投毒、幽灵控制、共谋/榜单游戏、责任洗白）。`J_TANDEM=(J_FLUID,κ_cf,B_κ,causal_ident_valid,A_conf_count,A_void_count,attention_violations,PG,meta_OOD,responsibility_log_hash,safety_margin)`。UniBot-WC 分 S1–S5，榜分扣除安全/干预/游戏项。闭环见 IP-276。

## 3. 关键算法伪代码

```python
# IP-264 SCL：权威场 + 硬安全滤波 + 冲突/空窗
class SharedControlLaw:
    def fuse(self, u_H, u_R, alpha, x):
        u = alpha * u_H + (1 - alpha) * u_R
        u = project_cbf(u, x, self.safe_set)              # never meta-learned
        conflict = self.disagree(u_H, u_R) and self.both_effective(alpha)
        void     = (not self.any_effective(alpha)) or self.both_inattentive()
        return u, AuthorityState(conflict, void)

# IP-265 OPM：操作员隐状态，四态严格分离
def update_operator(obs, A_hist):
    post = bayes_conformal_update(theta, obs, human_model)
    return dict(post, can=post.kappa_credal, will=post.avail_prob,
                agreed=evidence_of_commitment(obs), attentive=attention_estimate(obs))

# IP-266 ECI：在机器人自己制造的混杂下做因果辨识
def causal_competence(obs, dither_budget, iv_events):
    k_naive = regress_outcome_on_authority(obs)           # 有偏对照
    if dither_budget.available():
        k_cf = iv_or_do_estimate(obs, perturb(self.last_A, dither_budget.eps), iv_events)
    else:
        k_cf = iv_estimate(obs, iv_events)                # 只靠外生事件
    return k_cf, k_naive - k_cf, overlap_ok(obs), exclusion_ok(iv_events)

# IP-268 A-VoI：让权/引导/抖动/提问/接管的最优选择
def authority_voi(theta, candidates):
    best = None
    for a in candidates:
        if not budget.allow(a) or not rcl.preauthorized(a): continue
        score = (mutual_info(theta, a) + expected_task_gain(theta, a)
                 - cost(a) - risk(a))
        if best is None or score > best.score: best = (a, score)
    return best if best and best.score > 0 else None     # 无利可图→R69/R68

# IP-269 RAA：不确定性/注意力/可移植性 → 向量权威
def risk_adaptive_authority(theta, U_epi, U_ale, attention, meta_ood):
    alpha = solve_max_utility(theta, risk_cap=EPS)
    if meta_ood or not causal_ident_valid(theta):
        alpha = conservative_authority(alpha)             # 关键自由度交兜底
    if not attention.any(): alpha = sole_authority(self.certified_ctrl)
    return monotone_shrink_on_critical_dofs(alpha, U_epi + U_ale)

# IP-271 RCL + IP-272 DFG：责任链与责任扩散守卫
def log_and_guard(x, u_H, u_R, alpha, u, att):
    rcl.append(hash_chain(x, u_H, u_R, alpha, u, causal_share(u_H,u_R,alpha), att))
    if not (att.H or att.R): escalate_within(delta_R)     # 提示→接管→安全停
    if att.H and att.R and conflict(u_H, u_R): freeze_and_handover(self.certified_ctrl)

# IP-276 主闭环（继承 R69，只在「共享通道」处插入 TANDEM 层）
def TANDEM_RAS_round(M, obs, u_H):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(o)
    theta = M.opm.update_operator(obs, M.A_hist)
    k_cf, B_k, ok = M.eci.causal_competence(obs, M.budget, M.iv)
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, M.K), z)
    a_A = M.avoi.choose(theta, modes, ok, B_k)
    alpha = M.raa.allocate(theta, U_epi, U_ale, M.dfg.att, M.meta.ood)
    u, a_state = M.scl.fuse(u_H, M.fmp.decode(modes[0]), alpha, obs.x)
    if a_state.conflict or a_state.void or not ok:
        u = M.saf.takeover(obs.x)
    M.dfg.log_and_guard(obs.x, u_H, M.last_u_R, alpha, u, M.dfg.att)
    M.rcl.commit(hash_chain(...)); M.meta.maybe_adapt(theta, z)
    M.vqa_s.submit_async(a_A, k_cf, B_k, alpha, a_state)
    return u, alpha, (U_ale, U_epi), (k_cf, B_k)
```

## 4. 推导

**引理 19（内生证据的混杂偏置 / confounding by indication）** 机器人按信念选权威 `α=f(b)`，人类响应 `y=κ(θ_H)+γ(α−α₀)+ε`。用关联回归估 κ 得 `E[κ̂_naive]=κ+γ·Cov(α,b)/Var(α)`；因 α 随 b 单调，辅助有效（γ>0）时能力被系统性高估。若委派规则 `∂α_H/∂κ̂>0`，闭环 `κ̂_{t+1}=κ̂_t+η·γ·χ·(κ−κ̂_t)`（χ=∂α/∂κ̂）在 `η·γ·χ≥2` 时漂向「高能力」不动点，即**过度委派螺旋**。要点：不是数据不足，而是数据生成机制被策略篡改；更多数据只会更自信地错。

**引理 20（抖动/IV 的辨识-安全权衡）** 正性与排他性下，幅度 ε 抖动的估计误差 `O(σ/(√n·ε))`，安全成本 `O(ε·L_s)`；最优 `ε* ∝ (σ²/(nL_s))^{1/3}`。工具变量在排他性成立时把安全税降到 ≈0，但方差更高且需检验排他性。系：共享控制里「了解人」永远要付安全税；R69 的零成本提问只是把税转嫁给外部回答者。

**引理 21（权威是 λ 的严格泛化）** `d_S=∅` 或 `α≡0` 时 RAA 退化到只对机器人动作做风险缩放，保守分支逐指令等于 R68 的 `λ_floor(U_ale+未消解 U_epi)`；R69 消歧成功且共享自由度非关键时给出 resolution bonus。中间区域提供二者都没有的「按自由度分配风险」能力。

**定理 18（严格包含 R68/R69）** 在 A99（辨识有效或正确折价）、A100（注意力不变式 + 兜底可达）下，任意状态风险 `≤ max(R68,R69)+δ_R·L_react`；「人类外生神谕、无共享自由度」时与 R69 逐指令一致，「无共享自由度、仅机器人执行」时与 R68 逐指令一致。安全不让步，效率/流畅收益只在辨识有效且注意在线时兑现。

**定理 19（共享可能更不安全；注意力不变式恢复上界）** 独立注意时双离线概率 `p_H·p_R<min(p_H,p_R)`，共享有益；但过度信任让注意由同一「看起来都行」信号驱动而正相关，`P(双离线)` 可大于 `max(p_H,p_R)`（反例：p=0.1 时独立 0.01，强正相关可达 0.1）。加入 DFG 注意力不变式后双离线持续 ≤ δ_R，风险回 `≤ max+δ_R·L`；无此不变式时，成功率上升可掩盖总安全性下降。

**引理 22（可移植间隙界）** `PG ≤ L_meta·(D(z_new,Z_train)+ν) + mismatch(SafeSet_new,SafeSet_train)`；OOD 门触发时 PG 被兜底风险封顶。可移植的是结构与先验，不是安全。

**引理 23（责任链抗洗白性）** 哈希链 + 消融归因份额下，「幽灵控制」否认成功率 `≤ Pr[碰撞/伪造]+Pr[归因误差>δ_s]`；后者随抖动/IV 样本与重叠度下降——责任可归因性与能力辨识共享同一套干预预算。

## 7. 本轮最大风险

**一句话**：TANDEM-RAS 的全部收益押在「能从机器人自己制造的反馈回路里**因果地**辨识操作员能力与意图」这一前提上——**若把「人对辅助的适应」误读成「人的能力」，系统就会触发过度委派螺旋，在最需要接管时最放心地交权；共享控制又通过注意力的正相关耦合让双方同时停看，于是它一边刷新任务成功率，一边把总安全性降到比任何单方控制都低**——此时的「共享」不是协作，而是一台责任洗白机器。

**次级风险与缓解**：探测不安全（引理 20 最优幅度 + IV 优先 + 硬 CBF）；责任扩散（DFG 注意力不变式 + 定理 19 上界 + 逐身体兜底）；跨身体/跨操作员负迁移（META 只学先验 + 逐身体硬安全核 + OOD 门）；对抗与榜单游戏（ℰ_shared 对抗训练 + RCL 不可抵赖）；过度委派与洗白（ECI + B_κ 折价 + κ_cf 入证书，辨识无效即退回 R68/R69 保守边界）。
