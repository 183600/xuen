# 第 55 轮（承接第 54 轮 v16+++ GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「力矩传感」×「快速原型」）

> 第 54 轮把技能组合提升为「动作空间剖面 + 云边协同 + 动作-鲁棒性联合证书」。本轮追问一个更物理的问题：**动作空间里的“可执行”到底由什么物理量担保？** 答案是把 **关节力矩** 作为动作的物理底账，并用 **快速原型** 把「证书—实体」闭环压进可迭代的原型谱系。核心矛盾：H22：位置层兼容的技能组合在力矩层可能因载荷叠加/执行器饱和而冲突，动作剖面 `α_S` 缺少“力”这一维；H23：快速原型每一步都改变质量/惯量/摩擦，上一代原型的证书在新原型上会 **静默衰减**（certificate decay），而仿真到实体的差距正是原型迭代要压缩的对象。

## 0. 直觉与动机

**灵感 1（力矩是动作的物理底账 → 从动作覆盖到力矩包络）**
直觉：技能 S 的“能做”不仅在动作空间占了一块 `α_S`，还在每个关节上留下一个 **力矩包络** `[τ⁻, τ⁺]`。同样的末端轨迹，负载不同、姿态不同，关节力矩完全不同。于是定义技能的 **力矩签名** `τ_S(a,t)` 与 **力矩裕度** `μ_S(a)=min_j (τ_max^j-|τ_S^j|)/τ_max^j`。`μ<0` 即执行器饱和：动作“名义可达、实际不可达”。这把动作空间从几何概念变为 **力-位联合可执行域**。

**灵感 2（力矩兼容性 → 组合的载荷叠加检验）**
直觉：组合不是两个动作剖面的交集，而是 **载荷的叠加** `τ_{S1⊗S2}(t)=τ_{S1}+τ_{S2}+τ_coupling`。两个单独都有裕度的技能，组合后可能同时逼近饱和。因此 `compat_τ` 除动作 Jaccard 外，必须检查沿任务轨迹的力矩叠加 `max_t τ_{S_i⊗S_j}(t) ≤ (1-ε)τ_max`。这把第 54 轮的 `compat` 从几何兼容升级为 **几何 + 载荷双兼容**。

**灵感 3（力位残差是接地证据 → Explain 获得物理根因）**
直觉：实际力矩 `τ_meas` 与基于动作/姿态/速度预测的 `τ_pred` 之差 `r_τ=τ_meas-τ_pred`。残差在噪声带内 → 动作确实“落地”；残差异常且集中在某关节 → 直接给出根因关节与方向。相比纯仿真反例，力矩残差是 **最硬的 grounding 证据**，可作 IP-118 联合证书里 `evidence` 的物理锚点，也可驱动第 54 轮 `Explain_loop` 的根因定位。

**灵感 4（快速原型 = 证书有效性半径的迭代）**
直觉：快速原型让实体以 `P_0→P_1→…` 快速演进，但每代质量/惯量/摩擦 `θ_i` 都变。把每代原型的证书 `Π_i` 看作有 **有效性半径** `r(Π_i)`：只要原型步长 `||θ_{i+1}-θ_i|| ≤ r(Π_i)`，证书可安全迁移；超过则必须重校准。这样“快速”不被禁止，而是被 **半径约束** 驯服：要么小步快跑并增量校准，要么大步则强制重测。

**灵感 5（力矩指纹做快速辨识 → 把原型迭代变成可判定的迁移）**
直觉：给原型施加一组短促探针动作，测其力矩响应，得到 **力矩指纹** `Φ(P_i)`。指纹对 `θ_i` 敏感、对控制器不敏感，可用少量样本快速估计 `Δθ` 并预测证书衰减 `Δρ, Δτ_margin`。这把“新原型能否沿用旧证书”从经验判断变为 **指纹距离 + 半径** 的可判定问题，并与第 54 轮 JTC 联合迁移证书对接。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（力矩签名与包络）**
对技能 S、动作 `a∈A`、时刻 `t`，关节力矩签名 `τ_S(a,t) ∈ ℝ^m`（m 为关节数）。力矩包络 `E_S(a)=[τ_S⁻(a), τ_S⁺(a)]` 为沿执行分布的分位包络（如 5%–95%），并要求 `E_S` 在 `a` 上分段 Lipschitz。

**定义 122（力矩裕度与力-位可执行域）**
`μ_S(a)=min_{j,t} (τ_max^j - |τ_S^j(a,t)|)/τ_max^j`，饱和集 `Sat(S)={a | μ_S(a)<0}`。力-位可执行域 `A_S^τ = {a∈A_S | μ_S(a) ≥ μ_min}`。**力-位覆盖** `cover_τ(S,A_T)=1` 当且仅当 `A_T ⊆ A_S^τ`。

**定义 123（力矩兼容性）**
`compat_τ(S_i,S_j)=1 - max_t ||max(0, τ_{S_i⊗S_j}(t)-(1-ε)τ_max)|| / ||τ_max||`，其中 `τ_{S_i⊗S_j}=τ_{S_i}+τ_{S_j}+τ_coupling`。组合可判定条件在定义 116 基础上追加：
```
compat_τ(S_i,S_j) ≥ θ_τ ∧ Sat(S_i⊗S_j)=∅
```

**定义 124（力位残差与接地证据）**
`r_τ(t)=τ_meas(t)-τ_pred(a(t),q(t),q̇(t);θ̂)`。接地判据 `ground(S,a)=1` 当且仅当 `||r_τ||_∞ ≤ κ_τ·σ_τ` 且 `μ_S(a)≥μ_min`（`σ_τ` 为传感器噪声尺度）。根因映射 `root(r_τ)=argmax_j |r_τ^j|`，方向 `sgn(r_τ^{root})` 区分欠载/过载。

**定义 125（原型谱系与证书有效性半径）**
原型谱系 `P_0,...,P_k`，每代实体参数 `θ_i∈Θ`。证书 `Π_i=(A_cert_i, ρ_i, E_i, θ̂_i, δ_i)`，`δ_i` 为 sim2real 差距估计。**有效性半径**
```
r(Π_i)=sup{Δθ : dist(θ,θ̂_i)≤Δθ ⇒ |ρ_i(θ)-ρ_i(θ̂_i)|≤β_ρ ∧ E_i(θ)⊆E_i^buffer}
```
迁移安全条件 `||θ_{i+1}-θ_i|| ≤ r(Π_i)`；否则证书作废并进入重校准。

**定义 126（力矩指纹迁移证书）**
力矩指纹 `Φ(P_i)=[τ_probe,1,...,τ_probe,n] ∈ ℝ^{m×n}`。指纹迁移证书 `TFT_{i→j}=(ΔΦ, Δθ̂, Δρ̂, ΔE, r_used)`，其中 `Δθ̂=g_Φ(ΔΦ)` 由指纹估计参数漂移，`Δρ̂=h_ρ(Δθ̂)` 预测鲁棒性谱衰减，`ΔE` 预测包络漂移。若 `||Δθ̂||≤r(Π_i)` 且 `max Δρ̂≤β_ρ`，则证书可迁移；否则拒绝并触发重校准。

## 2. 关键算法 伪代码

### IP-121 TSC（Torque Signature Characterization）

```python
def torque_signature(skill, A_probe, robot, n_rep=5):
    sig = {}
    for a in A_probe:
        traces = [robot.execute(a).joint_torque for _ in range(n_rep)]
        sig[a] = {'lo': quantile(traces, 0.05, axis=0),
                  'hi': quantile(traces, 0.95, axis=0),
                  'pred': model.predict_torque(a, robot.state)}
    return sig

def torque_margin(sig, tau_max):
    return min((tau_max - abs(sig[a]['hi'])) / tau_max for a in sig)

def force_position_domain(sig, tau_max, mu_min=0.1):
    return {a for a in sig if torque_margin({a: sig[a]}, tau_max) >= mu_min}
```

### IP-122 TCM（Torque-Compatible Composition）

```python
def compat_torque(s1, s2, tau_max, eps=0.1):
    tau = s1.sig + s2.sig + coupling_torque(s1, s2)   # 时间对齐后逐关节叠加
    overflow = np.maximum(0, tau - (1-eps)*tau_max)
    return 1 - np.linalg.norm(overflow) / np.linalg.norm(tau_max)

def build_composition_graph_v2(skills, theta_a, theta_tau, tau_e, K, tau_max):
    G = nx.DiGraph()
    for i, s1 in skills:
        for j, s2 in skills:
            if i == j: continue
            geom = jaccard(s1.alpha, s2.alpha)
            tq   = compat_torque(s1, s2, tau_max)
            if geom >= theta_a and tq >= theta_tau:
                rho = compose_robustness(s1.rho, s2.rho, K)
                G.add_edge(i, j, compat=geom, compat_tau=tq, rho_comp=rho,
                           sat_free=(len(s1.sat | s2.sat) == 0))
    return G
```

### IP-123 TGS（Torque Grounding Score）

```python
def grounding(skill, a, obs, theta_hat, kappa=3.0):
    r = obs.tau - predict_torque(a, obs.q, obs.qd, theta_hat)
    score = exp(-np.linalg.norm(r, np.inf) / (kappa * obs.sigma_tau))
    return {'score': score, 'r_tau': r,
            'root_joint': int(np.argmax(abs(r))),
            'direction': float(np.sign(r[np.argmax(abs(r))])),
            'in_envelope': inside_envelope(r, skill.sig[a]),
            'grounded': score >= g_min}
```

### IP-124 PCL（Prototype Certificate Ladder）

```python
def prototype_step(cert, theta_new, beta_rho):
    dtheta = np.linalg.norm(theta_new - cert.theta_hat)
    if dtheta <= cert.radius:
        return ('transfer', shrink(cert, dtheta))    # 证书有界收缩
    return ('recalibrate', probe_plan(cert, dtheta)) # 超出半径 → 强制重测
```

### IP-125 TFT（Torque Fingerprint Transfer）

```python
def fingerprint_transfer(cert_old, robot_new, probes, beta_rho):
    dphi  = fingerprint(robot_new, probes) - cert_old.fingerprint
    dtheta_hat = np.linalg.pinv(jacobian_phi(cert_old.theta_hat)) @ dphi
    drho  = h_rho(dtheta_hat)
    dE    = h_E(dtheta_hat)
    if np.linalg.norm(dtheta_hat) <= cert_old.radius and max(drho.values()) <= beta_rho:
        return ('ok', TFT(dphi, dtheta_hat, drho, dE, cert_old.radius))
    return ('reject', 'validity_radius_exceeded', dtheta_hat)
```

### IP-126 RAF（Rapid Artifact Falsification）

```python
def rapid_falsify(skill_seq, prototype, n_rounds=3):
    cert = initial_certificate(skill_seq)
    for k in range(n_rounds):
        obs = prototype.run_probe(skill_seq)
        g = grounding(skill_seq, obs)
        if g['score'] < g_min or not g['in_envelope']:
            return ('falsified', g['root_joint'],
                    explain_torque(g, prototype))     # 回灌 Explain_loop
        state, payload = prototype_step(cert, prototype.identify(), beta_rho)
        if state == 'recalibrate':
            prototype.schedule_probe(payload)
        else:
            cert = payload
    return ('survived', cert)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| TSC | O(|A_probe|·n_rep·m) | O(|A_probe|·m) | 探针覆盖饱和边界、分位包络稳定 |
| TCM | O(|S|²·|A|·T) | O(|S|²·|A|) | 载荷叠加可对齐、耦合项已标定 |
| TGS | O(m) | O(m) | 偏置在线校准、噪声尺度准确 |
| PCL | O(k·m) | O(k) | 有效性半径保守、重校准触发可靠 |
| TFT | O(m·n + m³) | O(m·n) | 指纹雅可比局部可逆、Lipschitz 有界 |
| RAF | O(n_rounds·(m+|A|)) | O(|A|) | 探针-证书-重测闭环收敛 |

**正确性定理（Torque-Grounded Prototype Transfer Soundness）**
承接第 54 轮 (A22)–(A28)；新增 **(A29)** 力矩传感器偏置漂移有界且在线校准，`||b_τ||≤κ_τσ_τ`；**(A30)** 指纹映射 `g_Φ` 在 `θ̂_i` 邻域局部 Lipschitz，常数 `L_Φ<∞` 且雅可比满秩；**(A31)** 每次原型迭代满足 `||θ_{i+1}-θ_i||≤r(Π_i)` 或已触发重校准。
则部署成功概率：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - P(compat<θ_a) - P(compat_τ<θ_τ)
              - P(δ_a>Θ_a) - P(||b_τ||>κ_τσ_τ) - P(||Δθ||>r(Π))
```
关键：动作空间先验 **力-位双兼容**，证书迁移受 **有效性半径** 硬约束，力矩残差提供 **物理接地与根因**。

## 6. 本轮最大风险

**一句话**：力矩接地与原型迁移把“动作可执行”从几何可达升级为力-位可达、把证书迁移变成有半径的可判定问题，但其 soundness **三重依赖力矩偏置的在线校准、指纹雅可比的局部可辨识、以及原型步长始终落在有效性半径内**；一旦把传感器温漂误判为载荷冲突、或原型一步跨出有效期，证书就会静默衰减并被当成新实体的通行证，故必须以 **在线力矩偏置辨识 + 有效性半径硬门控 + 证书保守撤回** 三重护栏，宁可撤回证书，绝不把旧证书当新实体的通行证。

```python
def prototype_step(cert, theta_new, beta_rho):
    dtheta = np.linalg.norm(theta_new - cert.theta_hat)
    if dtheta <= cert.radius:
        return ('transfer', shrink(cert, dtheta))
    return ('recalibrate', probe_plan(cert, dtheta))

def shrink(cert, dtheta):
    # 有界收缩：ρ 按 Lipschitz 下界扣减，包络按 buffer 扩边
    rho = {d: max(0.0, cert.rho[d] - L_rho[d]*dtheta) for d in cert.rho}
    E   = {a: inflate(cert.E[a], L_E*dtheta) for a in cert.E}
    return replace(cert, rho=rho, E=E, theta_hat=cert.theta_hat + dtheta*n_hat)
```

```python
def fingerprint_transfer(cert_old, robot_new, probes, beta_rho):
    dphi = fingerprint(robot_new, probes) - cert_old.fingerprint
    dtheta_hat = np.linalg.pinv(jacobian_phi(cert_old.theta_hat)) @ dphi
    drho = h_rho(dtheta_hat)
    dE   = h_E(dtheta_hat)
    if np.linalg.norm(dtheta_hat) <= cert_old.radius and max(drho.values()) <= beta_rho:
        return ('ok', TFT(dphi, dtheta_hat, drho, dE, cert_old.radius))
    return ('reject', 'validity_radius_exceeded', dtheta_hat)
```

### IP-126 RAF

```python
def rapid_falsify(skill_seq, prototype, n_rounds=3):
    cert = initial_certificate(skill_seq)
    for k in range(n_rounds):
        obs = prototype.run_probe(skill_seq)
        g = grounding(skill_seq, obs)
        if g['score'] < g_min or not g['in_envelope']:
            return ('falsified', g['root_joint'],
                    explain_torque(g, prototype))     # 回灌 Explain_loop
        state, payload = prototype_step(cert, prototype.identify(), beta_rho)
        if state == 'recalibrate':
            prototype.schedule_probe(payload)
        else:
            cert = payload
    return ('survived', cert)
```

**正确性定理（Torque-Grounded Prototype Transfer Soundness）**
假设第 54 轮 (A22)–(A28) 成立；新增 **(A29)** 力矩偏置漂移有界且在线校准 `||b_τ||≤κ_τσ_τ`；**(A30)** `g_Φ` 局部 Lipschitz 且雅可比满秩；**(A31)** 原型步长 `||θ_{i+1}-θ_i||≤r(Π_i)` 或已重校准。
则：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - P(compat<θ_a) - P(compat_τ<θ_τ)
              - P(δ_a>Θ_a) - P(||b_τ||>κ_τσ_τ) - P(||Δθ||>r(Π))
```
关键：**组合先验力-位双兼容**、**迁移受有效性半径硬约束**、**力矩残差提供物理接地与根因**。

## 6. 本轮最大风险

**一句话**：力矩接地与原型迁移把“动作可执行”从几何可达升级为力-位可达、把证书迁移变成有半径的可判定问题，但其 soundness **三重依赖力矩偏置的在线校准、指纹雅可比的局部可辨识、以及原型步长始终落在有效性半径内**；一旦把传感器温漂误判为载荷冲突、或原型一步跨出有效期，证书就会静默衰减并被当成新实体的通行证，故必须以 **在线力矩偏置辨识 + 有效性半径硬门控 + 证书保守撤回** 三重护栏，宁可撤回证书，绝不把旧证书当新实体的通行证。
