灵感驱动研究循环·新灵感三元组第 1 轮；本轮灵感：「惯性测量单元」×「中间件」

> **基线**：v23 产出 MetricVoiceGauge-NCD-HUTDH-v23 + IP-425–439（HPC-E+ 四证准入门、CESC 云边同步、FSVC 少样本有效、IPAM 知识产权认证；其上承 v22 分层 PGEV/ACSC/DCSC/CFC++，v21 语义-规范层 SDC/CAC/DCL/GIC，v20 联邦感知证书，v19/v17 证书与感知链）。
> 本轮纪律：**不推倒 v23**，全部既有模块保留。本轮只做一件事：**把“点时刻、规划器内”的证书升级为“区间有效、总线强制”的证书**——用 IMU 给证书做带误差界的时移（时间连续性），用中间件做完全中介（因果强制性），并顺手修正 v23 退化链的隐含瑕疵（“回退到基线”可能反而放大执行集）。

## 0. 直觉与动机

### 灵感 1（惯性测量单元 → 证书的“时间运输算子”）

**直觉**：v23 的证书都是“某时刻 t_k 的一张快照”：SDC 说“此刻这里有个杯子”，CAC 说“此刻覆盖区内没人”。但执行发生在快照之后：机器人还在动，控制环还在跑，相机 10–30Hz、激光 10Hz，而控制 50Hz、IMU 100–1000Hz。两张快照之间，证书凭什么继续有效？v23 用 TTL 兜底，但 TTL 是**墙钟时间**，不是**运动时间**——慢速微调 200ms 与高速旋转 200ms 的世界位移天差地别。IMU 恰好测的不是世界，而是“我自己怎么动”：它能在两帧外感受之间，以有界误差把“世界在我当前坐标系里的样子”推演出来。核心创新：**惯性时移证书（Inertial Temporal Bridge Certificate, ITBC）**。关键反直觉点：**IMU 不是“又一种传感器”，而是作用在既有证书上的一个“运输算子”**——它不新增障碍来源，只把证书沿时间搬运，并且搬运得越久，证书必须收缩得越狠（自由空间腐蚀、障碍膨胀）。更反直觉的是：**在有动态人的场景里，IMU 让证书“老得更快”而不是更慢**——因为你看不见的那段时间里，人可能走进来；所以惯性桥只是毫秒级延迟补偿器，不是秒级“免复检”的监控延长器。

**严谨定义**：设外感受锚点时刻 `t_0 < t_1 < ...`，在 `[t_k, t]` 上 IMU 给出 `a_m(τ)=a(τ)+b_a+n_a`、`ω_m(τ)=ω(τ)+b_g+n_g`，偏置界 `|b_a|≤B_a, |b_g|≤B_g`，外部扰动（机械臂反作用、轮滑）界 `|d_a|≤D_a, |d_g|≤D_g`。定义**惯性误差包络**
`ε_p(Δt) = c_0 + c_1 Δt + c_2 Δt²`，`ε_θ(Δt) = d_0 + d_1 Δt`，
其系数由离线标定 + 区间/共形方法给出，使得
`P( |Δp_true - Δp_imu| ≤ ε_p(Δt) ∧ |Δθ_true - Δθ_imu| ≤ ε_θ(Δt) ) ≥ 1-δ_imu`。
对任意集合 S 定义腐蚀 `erode(S,ε)={x:B(x,ε)⊆S}` 与膨胀 `dilate(S,ε)={x:B(x,ε)∩S≠∅}`。则时移后的证书为
`F_t = erode(F_{t_k}, ε_eff(Δt) + v_world_max·Δt)`，
`O_t = dilate(O_{t_k}, ε_eff(Δt) + v_world_max·Δt)`，
其中 `ε_eff = ε_p + R_max·ε_θ + ε_calib`（`R_max` 为最远量程，旋转对远点的杠杆放大）。**单调时移律**：`ε_p,ε_θ` 随 Δt 单调不减 ⇒ `F_t` 单调不增、`O_t` 单调不减。若 `ε_p>ε_p,max` 或 `ε_θ>ε_θ,max` 或 `Δt>T_valid`，证书**过期**，回落保守默认（限速/停机）。`v_world_max` 是对“人/动态物最快能多快进入视野”的显式假设——它把 v21 的 AbsCert 与“人距上限”回退统一成同一个时间项。

**自检与证伪**：把 IMU 推算位移与轮式/腿式里程计比对，若 `|Δp_imu-Δp_odo|>ε_p`，说明运动界被违反（打滑、碰撞、标定漂移），**立即作废时移证书**（fail-safe）。冲击事件（`|a_m|` 或 jerk 超阈）是“几何证书错了”的物理见证，写入不可篡改账本（见灵感 2 后的证伪见证）。

### 灵感 2（中间件 → 从“规划器里的证书”到“总线上的强制”）

**直觉**：再强的证书，只要有一条控制指令绕过准入门直达执行器，整个安全论证就作废。v23 的 HPC-E+ 是一个“被调用的函数”，但“谁保证每条指令都调用它”没有回答。中间件（消息总线/执行器/调度器）正是答案：它是唯一能**强制**所有指令经过同一道门、给所有消息打上**同一时基**、对超时消息**失效安全**、并把安全监控与业务逻辑**故障隔离**的地方。安全领域的经典结论是：安全函数必须是**引用监视器（reference monitor）**——完全中介、防篡改、可验证。核心创新：**中介执行引用监视器（Mediated Execution Reference Monitor, MERM）** 与 **共时可信证书（Common-Time Certificate, CTC）**。关键反直觉点：**中间件不是管道，而是整个安全论证的可信计算基（TCB）**；最锋利的证书如果跑在会让消息绕过、时钟不同步、证书消息被丢弃的总线上，等于零。因此本轮把中间件从“实现细节”提升为“被认证的组件”，并要求安全继承在**指令总线上**成立，而不只在规划器里成立。

**严谨定义**：设指令集 C、执行器写接口唯一。**完全中介**：`∀c∈C_executed, c∈dom(M)`；**防篡改**：M 及其配置位于隔离分区，无可写路径从非可信组件到达；**可验证**：M 的 WCET `W_M≤T_ctrl` 且有机器可检规格。每条指令携带**证书令牌**
`τ = (h_plan, h_cert, t_issue, t_expire, nonce, sig)`，
`Med(c) = verify_sig(τ) ∧ h_plan=H(plan(c)) ∧ h_cert=H(cert_set) ∧ t_issue≤now≤t_expire ∧ nonce∉ReplaySet`。
**共时**：分布式系统没有全局“现在”；设认证时钟偏差界为 `skew_max`，令牌只在 `[t_issue+skew_max, t_expire-skew_max]` 内可信；若 `skew_max ≥ (t_expire-t_issue)/2` 或同步丢失，令 `skew_max:=∞` ⇒ 所有令牌失效 ⇒ 受控停机（fail-safe）。**QoS 新鲜度**：消息须在截止期 `D` 内到达且观测窗口内无 miss；deadline miss ⇒ 视同证书过期。**故障包容**：感知/证书生成与监视器分区，心跳丢失 ⇒ 看门狗触发受控停机。于是
`Exec_v24 = {π∈Exec_v23 : ∀c∈π, Med(c) ∧ ClockOK ∧ QoSOK ∧ TemporalValid(π)} ⊆ Exec_v23`。

### 两者如何统一

统一为 **v23 之上的“时间-中介”层（Temporal-Mediation Layer, TML）**：ITBC 负责“证书在时间上怎么老”，MERM/CTC/QoS/FCCS 负责“证书在总线上怎么被强制执行”。共享状态 `ζ_tm = ζ_ce ∪ (E_imu, ε_p, ε_θ, token_set, skew_max, qos_hist, impact_ledger, tcb_hash)`。统一准入门 **HPC-E++ = HPC-E+ ∪ ITBC ∪ MERM ∪ CTC ∪ QFC**：只有“v23 四证 ∧ 时移有效 ∧ 时钟可信 ∧ QoS 达标 ∧ 令牌经完全中介”才执行。任何一项缺失都进入**保守包络**（限速/停机），而**不是**退回执行集更大的 v23——这修正了 v23 退化链的隐含瑕疵（见产物区引理 5）。CFC++++ 在 CFC+++ 之上增加“同一时基 + 令牌中介 + 惯性见证一致”三项仲裁。

## 1. 研究问题（Q12–Q16）

- **Q12（惯性时移的紧致性与活性）**：如何从偏置/尺度/噪声/外部扰动（尤其机械臂反作用）导出既严格又紧的 `ε_p(Δt), ε_θ(Δt)`？区间算术与共形校准如何互补（前者保证最坏界、后者给统计界）？旋转杠杆项 `R_max·ε_θ` 在远距感知下是否会让时移窗口短到不可用，如何用陀螺零偏在线标定与视觉锚点插值缓解？
- **Q13（世界动态项的可辩护性）**：`v_world_max` 如何取值才既安全又不至于让 AbsCert 永久失效？能否按区域（人形共享区 vs 隔离区）给不同的 `v_world_max` 与 `T_abs,max`？当“人可能突然进入”时，时移 AbsCert 与 v21 的人距上限如何无缝隙衔接？
- **Q14（完全中介的可证明性）**：在部分失效（消息丢失、优先级反转、节点被攻破、共享内存绕过）下如何证明 `∀c, Med(c)`？监视器 WCET 如何压进 50Hz 周期？多机器人跨域指令如何在联邦中间件上做跨域完全中介而不引入单点瓶颈？
- **Q15（时钟信任与攻击面）**：如何认证 `skew_max`（PTP/gPTP + 硬件时间戳 + 单调时钟）？如何检测 GPS 欺骗、延迟攻击、时钟回拨？`skew_max` 与 v17 APS 新鲜度阶梯、v23 CESC `T_switch`、CFC 共识轮次如何叠加而不互相误伤？
- **Q16（物理证伪反馈）**：如何把冲击/打滑事件转成对 `κ_c`、`ε_p`、`v_world_max` 的**统计有效**收紧，而不被搬放/载荷跌落的假冲击污染？不可篡改账本如何兼顾隐私与可审计？证伪只收紧、不放松，如何保证不引入活性死锁？

## 2. 设计原则（新增 P43–P47）

**P43 惯性时移律（Inertial Temporal Transport）**
证书按 `F_t=erode(F_{t_k}, ε_eff+v_world_max·Δt)`、`O_t=dilate(O_{t_k}, ε_eff+v_world_max·Δt)` 沿时间运输；`ε_eff=ε_p+R_max·ε_θ+ε_calib` 随 Δt 单调不减；超出 `ε_p,max/ε_θ,max/T_valid` 即过期并回落保守默认。时移只收缩自由空间、只膨胀障碍；IMU 与里程计失配即作废证书。

**P44 完全中介律（Complete Mediation）**
每条执行器指令必须携带证书令牌并通过唯一引用监视器 M：`∀c∈C_executed, Med(c)`。M 位于隔离 TCB、不可从非可信组件写入、WCET `W_M≤T_ctrl`；无令牌/令牌过期/计划哈希不符/重放即拒绝。中介缺失即视为“未认证指令”，一律不执行。

**P45 共时可信律（Common-Time Trust）**
证书有效性是**区间**而非点：令牌仅在 `[t_issue+skew_max, t_expire-skew_max]` 内可信；`skew_max` 必须由认证时钟给出；同步丢失或 `skew_max≥(t_expire-t_issue)/2` 即令令牌失效并受控停机。所有时间戳取硬件/单调时钟，禁止回拨。

**P46 QoS 新鲜律（QoS Freshness Contract）**
证书消息须满足截止期 `D` 且观测窗口内无 deadline miss；liveliness 丢失、deadline miss、队列溢出均视同证书过期。QoS 状态直接接入 v17 APS 新鲜度阶梯，不得用“重传成功”掩盖已过期的语义。

**P47 证伪见证律（Falsification Witness）**
IMU 冲击/打滑/里程计失配是独立物理见证：若在 `Admit=True` 且证书声称近处无障碍时发生冲击，记为**证书违反**，写入哈希链账本，并按只收紧方向更新 `κ_c、ε_p、v_world_max` 与触发重校准；证伪只能使执行集变小，绝不放松。

## 3. 与基线的接口（如何退化，且不回涨）

- ITBC 失效（IMU 掉线/失配）⇒ 时移证书全部作废 ⇒ 仅在新鲜外感受锚点后的极短窗口内执行，否则限速/停机 ⇒ 比 v23 更保守；
- MERM 失效（监视器崩溃/心跳丢失）⇒ 看门狗切断执行器写通道 ⇒ 受控停机（不是退回无中介的 v23）；
- CTC 失效（时钟失步/被攻破）⇒ `skew_max:=∞` ⇒ 全部令牌失效 ⇒ 停机；
- QFC 失效（deadline miss）⇒ 相关证书视同过期 ⇒ 保守包络；
- IFW 报警 ⇒ 收紧假设并重校准；在重校准完成前维持保守包络；
- 全部失效 ⇒ **保守包络** `Exec_v24^fail = Exec_v23 ∩ Envelope_stop ⊆ Exec_v24`（注意：是子集，不是回涨到 v23；见产物区引理 5）。
- **安全继承**：ITBC 只腐蚀/膨胀、MERM 只拒绝、CTC 只缩短有效窗、QFC 只作废、IFW 只收紧；任意失效都向更小执行集退化。

## 4. 预期贡献

1. **证书的惯性时移算子**：首次把 IMU 从“位姿传感器”提升为作用在证书上的有界误差运输算子，给出“自由空间随 Δt 单调腐蚀、障碍单调膨胀”的区间有效证书；
2. **动态世界时间项**：把 `v_world_max·Δt` 显式并入 AbsCert 时移，统一了“负信息时效”与 v21 人距上限回退，并诚实地界定惯性桥只是延迟补偿而非免复检；
3. **中间件即 TCB**：以引用监视器的完全中介/防篡改/可验证三性质形式化中间件，证明安全继承在指令总线上成立；
4. **共时可信**：把时钟偏差界变成证书有效区间的一部分，同步丢失即失效安全，封堵“重放/延迟/时钟回拨”类攻击；
5. **物理证伪闭环**：用 IMU 冲击/打滑作为碰撞前难以获得、碰撞后必然出现的真值见证，驱动只收紧的假设更新与账本审计；
6. **HPC-E++ 与 CFC++++**：五证一体（v23 四证 + 时间-中介）与共时共识，闭环 `Exec_v24 ⊆ Exec_v23 ⊆ ...`，并修正“回退即回涨”的退化链瑕疵。

## 5. 本轮最大风险

**一句话**：时间-中介层的信任根（中间件 + 时钟 + IMU）是**自指**的——若它失步、被重放或被欺骗，系统会以完全合规、可审计的方式执行一份“看起来新鲜”的过期/伪造证书（时间幻觉），而唯一的外部真值（冲击见证）只在碰撞之后才出现，无法在碰撞前证伪它。

| `TCB` | 可信计算基；MERM + 认证时钟 + 硬件看门狗 |
| `W_M` | 监视器最坏执行时间（WCET） |
| `D` | 证书/指令消息的 QoS 截止期 |
| `QoSOK` | 观测窗口内无 deadline miss 且 liveliness 存活 |
| `Impact(t)` | 冲击/打滑事件：`‖a_m‖` 或 jerk 超阈 |
| `CertViolation` | 在 `Admit=True` 且证书声称近处无障碍时发生冲击 |

## 1. 关键算法骨架（在 IP-436–439 骨架上扩展）

```python
# ============================================================
# IP-440 Inertial Temporal Bridge Certificate (ITBC)
# 把 t_anchor 时刻的证书沿时间运输；只收缩自由空间、只膨胀障碍。
# ============================================================
@dataclass
class AgedCertificate:
    cert_id: str
    F: set            # 自由空间体素/距离场
    O: set            # 障碍体素
    domain: set       # 全域（保守回退用）
    t_anchor: float
    t_valid: float = 0.0
    eps_used: float = 0.0
    valid: bool = True

class InertialTemporalBridge:
    def __init__(self, B_a, B_g, D_a, D_g, eps_p_max, eps_theta_max,
                 T_valid, v_world_max, R_max, eps_calib, delta_imu=1e-3):
        self.B_a, self.B_g, self.D_a, self.D_g = B_a, B_g, D_a, D_g
        self.eps_p_max, self.eps_theta_max = eps_p_max, eps_theta_max
        self.T_valid, self.v_world_max = T_valid, v_world_max
        self.R_max, self.eps_calib = R_max, eps_calib
        self.delta_imu = delta_imu
        self.reset(0.0)

    def reset(self, t_anchor):
        self.t_anchor = t_anchor
        self.p = np.zeros(3); self.v = np.zeros(3); self.theta = np.zeros(3)
        self.eps_p = 0.0; self.eps_theta = 0.0
        self.p_imu = np.zeros(3)
        self.valid = True

    def integrate(self, a_m, w_m, dt, p_odo=None):
        # 名义积分（仅供自检/对里程计，不直接当证书用）
        self.p = self.p + self.v * dt + 0.5 * a_m * dt * dt
        self.v = self.v + a_m * dt
        self.theta = self.theta + w_m * dt
        self.p_imu = self.p.copy()

        # 认证包络：区间算术的最坏情形增长
        self.eps_p += (np.linalg.norm(a_m) + self.B_a + self.D_a) * dt * dt
        self.eps_p += self._noise_pos_inc(dt)       # c_1·dt + c_2·dt² 的增量
        self.eps_theta += (np.linalg.norm(w_m) + self.B_g + self.D_g) * dt
        self.eps_theta += self._noise_theta_inc(dt)

        # 自检：IMU 与里程计失配超过包络 ⇒ 运动界被违反 ⇒ 作废
        if p_odo is not None and np.linalg.norm(self.p_imu - p_odo) > self.eps_p:
            self.valid = False

    def _noise_pos_inc(self, dt):
        return self._c1 * dt + self._c2 * dt * dt

    def _noise_theta_inc(self, dt):
        return self._d1 * dt

    def is_expired(self, now):
        dt = now - self.t_anchor
        return (dt > self.T_valid
                or self.eps_p > self.eps_p_max
                or self.eps_theta > self.eps_theta_max
                or not self.valid)

    def age_certificate(self, cert: AgedCertificate, now) -> AgedCertificate:
        if self.is_expired(now):
            cert.valid = False
            cert.F = set()                # 保守：无可信自由空间
            cert.O = set(cert.domain)     # 保守：全域视为障碍
            cert.t_valid = now
            return cert
        dt = now - self.t_anchor
        e = self.eps_p + self.R_max * self.eps_theta + self.eps_calib
        e += self.v_world_max * dt        # 世界动态项：人可能走进来
        cert.F = erode(cert.F, e)
        cert.O = dilate(cert.O, e)
        cert.valid = True
        cert.t_valid = now
        cert.eps_used = e
        return cert


# ============================================================
# IP-443 Common-Time Certificate (CTC)
# 令牌只在扣除时钟偏差后的区间内可信；同步丢失 ⇒ 全部失效。
# ============================================================
class CommonTimeCertificate:
    def __init__(self, skew_max, clock):
        self.skew_max = skew_max
        self.clock = clock
        self.synced = True

    def on_sync_loss(self):
        self.synced = False
        self.skew_max = float('inf')

    def valid_window(self, token):
        if not self.synced:
            return None
        lo = token.t_issue + self.skew_max
        hi = token.t_expire - self.skew_max
        return (lo, hi) if lo < hi else None

    def ok(self, token):
        w = self.valid_window(token)
        now = self.clock.now()
        return w is not None and w[0] <= now <= w[1]


# ============================================================
# IP-444 QoS Freshness Contract (QFC)
# deadline miss / liveliness 丢失 ⇒ 视同证书过期。
# ============================================================
class QosFreshnessContract:
    def __init__(self, deadline, window):
        self.deadline = deadline
        self.window = window
        self.history = deque(maxlen=window)
        self.alive = True

    def observe(self, t_arrival, t_issue):
        self.history.append((t_arrival - t_issue) <= self.deadline)

    def on_liveliness_lost(self):
        self.alive = False

    def ok(self):
        return self.alive and len(self.history) > 0 and all(self.history)


# ============================================================
# IP-442 Mediated Execution Reference Monitor (MERM)
# 唯一执行器写路径；完全中介 + 防重放 + 共时 + QoS。
# ============================================================
class MediatedExecutionReferenceMonitor:
    def __init__(self, gate, clock, qos, pk, actuator_bus, ledger):
        self.gate = gate
        self.clock = clock
        self.qos = qos
        self.pk = pk
        self.bus = actuator_bus          # 唯一写路径
        self.ledger = ledger
        self.replay = set()

    def verify_token(self, token, plan):
        if not verify_sig(self.pk, token.digest(), token.sig):
            return False
        if token.h_plan != H(plan):
            return False
        if token.nonce in self.replay:
            return False
        if not self.clock.ok(token):
            return False
        if not self.qos.ok():
            return False
        return True

    def submit(self, cmd, token, now):
        if not self.verify_token(token, cmd.plan):
            self.ledger.append(("reject_token", H(cmd), token.nonce, now))
            return Reject(reason="token")
        if not self.gate.admits(cmd.plan, cmd.state, now):
            self.ledger.append(("reject_gate", H(cmd), token.nonce, now))
            return Reject(reason="gate")
        self.replay.add(token.nonce)
        self.ledger.append(("accept", H(cmd), token.digest(), now))
        return self.bus.write(cmd)        # 只有这里能到达执行器


# ============================================================
# IP-441 Inertial Falsification Witness (IFW)
# 冲击/打滑 = 物理真值见证；只收紧、不放松。
# ============================================================
class InertialFalsificationWitness:
    def __init__(self, a_impact, jerk_thr, eps_impact, ledger,
                 delta_kappa=0.01, delta_eps=0.1):
        self.a_impact = a_impact
        self.jerk_thr = jerk_thr
        self.eps_impact = eps_impact
        self.ledger = ledger
        self.a_prev = None
        self.delta_kappa = delta_kappa
        self.delta_eps = delta_eps

    def observe(self, a_m, admitted, cert, dt):
        jerk = (np.linalg.norm(a_m - self.a_prev) / dt
                if self.a_prev is not None else 0.0)
        self.a_prev = a_m
        impact = (np.linalg.norm(a_m) > self.a_impact) or (jerk > self.jerk_thr)
        if not impact:
            return OK()
        violation = admitted and not cert.has_obstacle_within(self.eps_impact)
        self.ledger.append(("impact", now(), violation, a_m.tolist()))
        if violation:
            self._tighten(cert)
            return SafeStop()
        return OK()

    def _tighten(self, cert):
        # 只收紧：提高召回下界、放大惯性误差包络、降低世界速度假设
        self.kappa_c = min(1.0, getattr(self, "kappa_c", 0.9) + self.delta_kappa)
        self.eps_p_scale = getattr(self, "eps_p_scale", 1.0) * (1 + self.delta_eps)
        self.v_world_max = max(0.0, getattr(self, "v_world_max", 1.6) - 0.1)
        self.ledger.append(("tighten", self.kappa_c, self.eps_p_scale,
                            self.v_world_max))


# ============================================================
# IP-445 Fault-Contained Certificate Supervisor (FCCS)
# 分区 + 心跳 + 看门狗：任一安全相关分区失联即受控停机。
# ============================================================
class FaultContainedCertificateSupervisor:
    def __init__(self, partitions, watchdog_timeout):
        self.partitions = partitions          # {name: heartbeat_fn}
        self.timeout = watchdog_timeout
        self.last_seen = {name: now() for name in partitions}

    def beat(self, name):
        self.last_seen[name] = now()

    def healthy(self):
        t = now()
        return all(t - self.last_seen[n] <= self.timeout for n in self.partitions)

    def guard(self, execute_fn):
        if not self.healthy():
            return SafeStop(reason="fccs_watchdog")
        return execute_fn()

# IP-446 HPC-E++ 统一五证准入门

@dataclass
class HPCEPlusPlus:
    hpce_plus: HPCEPlus               # v23 四证（几何/规范/负信息/能量/差距/云边/少样本/IP）
    itbc: InertialTemporalBridge
    merm: MediatedExecutionReferenceMonitor
    ctc: CommonTimeCertificate
    qfc: QosFreshnessContract

    def temporal_valid(self, plan, now):
        for cert in plan.cert_set:
            aged = self.itbc.age_certificate(cert, now)
            if not aged.valid:
                return False
            if not plan.within(aged.F, aged.O):
                return False
        return True

    def admits(self, plan, token, now, *v23_args):
        if not self.hpce_plus.admits(plan, *v23_args):
            return False
        if not self.ctc.ok(token):
            return False
        if not self.qfc.ok():
            return False
        if not self.temporal_valid(plan, now):
            return False
        if not self.merm.verify_token(token, plan):
            return False
        return True

# 端到端：时间-中介流水线
# ============================================================
class TemporalMediationPipeline(PerceptionComplianceEnergyPipeline):
    def __init__(self, config):
        super().__init__(config)
        self.ledger = HashChainLedger()
        self.itbc = InertialTemporalBridge(**config['imu'])
        self.ctc = CommonTimeCertificate(config['skew_max'], config['clock'])
        self.qfc = QosFreshnessContract(config['deadline'], config['window'])
        self.ifw = InertialFalsificationWitness(config['impact'], ledger=self.ledger)
        self.fccs = FaultContainedCertificateSupervisor(
            config['partitions'], config['watchdog_timeout'])
        self.merm = MediatedExecutionReferenceMonitor(
            gate=None, clock=self.ctc, qos=self.qfc,
            pk=config['pk'], actuator_bus=config['bus'], ledger=self.ledger)
        self.hpc_pp = HPCEPlusPlus(self.hpc_e_plus, self.itbc, self.merm,
                                   self.ctc, self.qfc)
        self.merm.gate = self.hpc_pp
        self._last_admitted = False
        self._last_cert = None

    def step(self, sensor_data, token, cloud_update=None):
        # 1. IMU 高频积分（可在独立实时线程）
        for a_m, w_m, dt, p_odo in sensor_data['imu_batch']:
            self.itbc.integrate(a_m, w_m, dt, p_odo)

        # 2. 新外感受锚点 ⇒ 重置时移
        if sensor_data.get('anchor'):
            self.itbc.reset(sensor_data['anchor_time'])

        # 3. 物理证伪见证
        verdict = self.ifw.observe(sensor_data['a_last'],
                                   admitted=self._last_admitted,
                                   cert=self._last_cert,
                                   dt=sensor_data['dt'])
        if isinstance(verdict, SafeStop):
            self._last_admitted = False
            return False, {'reason': 'impact_falsification',
                           'ledger_root': self.ledger.root()}

        # 4. 既有 v23 流水线（感知 → 共识 → 准入）
        admitted, info = super().step(sensor_data, cloud_update)

        # 5. HPC-E++ 五证 + 完全中介执行
        now = self.ctc.clock.now()
        if admitted and self.hpc_pp.admits(
                info['plan'], token, now,
                sensor_data['x'], sensor_data['v'], sensor_data['z'],
                sensor_data['E_res'], sensor_data['margin_req'],
                info['modules']):
            self.fccs.guard(lambda: self.merm.submit(
                Command(info['plan']), token, now))

        self._last_admitted = admitted
        self._last_cert = info.get('cert')
        return admitted, {
            'plan': info['plan'] if admitted else None,
            'eps_p': self.itbc.eps_p,
            'eps_theta': self.itbc.eps_theta,
            'skew_max': self.ctc.skew_max,
            'qos_ok': self.qfc.ok(),
            'ledger_root': self.ledger.root(),
        }
```

## 3. 正确性论证

### 引理 1（时移可靠性 + 单调老化）
**陈述**：在 (A1) 真实相对位姿落在 `B(ε_p,ε_θ)` 内、(A2) 无动态物速度超过 `v_world_max`、(A3) 锚点证书 `Cert(t_k)` 可靠 三假设下，`Cert_t = age(Cert_{t_k}, Δt)` 在 t 时刻可靠；且对 `Δt_2 ≥ Δt_1`，`F(Δt_2) ⊆ F(Δt_1)`、`O(Δt_2) ⊇ O(Δt_1)`。

**证明**：
1. 由 A1，任一真实点相对锚点坐标系的位移不超过 `ε_eff = ε_p + R_max·ε_θ + ε_calib`（旋转对距离 `R_max` 的点产生 `R_max·ε_θ` 的位移）。
2. 由 A2，任一原本不在障碍集中的动态物在 Δt 内最多移动 `v_world_max·Δt`。故总不确定半径为 `e = ε_eff + v_world_max·Δt`。
3. 对自由空间取腐蚀：`x∈erode(F,e)` 意味着整个 `B(x,e)` 都在锚点自由空间内，因此无论真实位姿/动态物如何落入不确定球，x 都不会被真实障碍占据 ⇒ `F_t` 中的点确实自由。
4. 对障碍取膨胀：真实障碍点必落在某锚点障碍的 `e` 邻域内 ⇒ 必在 `O_t` 中。
5. `ε_p, ε_θ` 随 Δt 单调不减、`v_world_max·Δt` 随 Δt 单调增，而腐蚀随半径增大单调收缩、膨胀随半径增大单调扩张 ⇒ 单调老化。∎

> 注：若动态物速度方向未知，`v_world_max·Δt` 是各向同性上界；这解释了为何 AbsCert 的时移窗口天然短于静态障碍的时移窗口。

### 引理 2（完全中介 ⇒ 执行集子集）
**陈述**：若 MERM 是执行器唯一写路径，且 `Med(c)` 是执行的必要合取项，则 `Exec_v24 ⊆ Exec_v23`。

**证明**：
1. 任一被执行指令 c 必经过 `merm.submit`；`submit` 先 `verify_token`（含 `Med` 的验签/哈希/时窗/重放），再调用 `hpc_pp.admits`。
2. `hpc_pp.admits` 的第一个合取项即 `hpce_plus.admits`，而 `Exec_v23` 恰是 v23 中 HPC-E+ 准入的计划集合。
3. 因此 c 的计划必属于 `Exec_v23`，且额外满足时移/共时/QoS/中介四项 ⇒ `Exec_v24 ⊆ Exec_v23`。∎

### 引理 3（时钟偏差下的区间可靠性）
**陈述**：若真实时钟偏差 `|skew| ≤ skew_max`，且 `valid_window(τ)` 非空，则本地 `now` 被接受蕴含真实时刻落在 `[t_issue, t_expire]` 内。

**证明**：
1. `now_local = t_true + skew`，`|skew| ≤ skew_max`。
2. 接受条件 `t_issue + skew_max ≤ now_local ≤ t_expire - skew_max`。
3. 两式相减即得 `t_issue ≤ now_local - skew ≤ t_expire`，而 `now_local - skew = t_true`。∎
4. 当 `skew_max ≥ (t_expire-t_issue)/2` 时窗口为空，直接拒绝；同步丢失时 `skew_max=∞`，亦拒绝 ⇒ 失效安全。∎

### 引理 4（物理证伪只收紧）
**陈述**：IFW 的更新 `κ_c↑、ε_p↑、v_world_max↓` 只会收缩自由空间、膨胀障碍，绝不放大执行集。

**证明**：
1. `κ_c` 提高使 AbsCert 更难签发（召回下界更严）；`ε_p` 放大使时移膨胀半径 `e` 增大；`v_world_max` 降低使世界动态项减小——三者都使 `F_t` 更小或 `O_t` 更大。
2. 由引理 1 的单调性，执行集非增。∎

### 引理 5（失效安全细化：修正 v23 退化链的“回退回涨”瑕疵）
**陈述**：若对每个组件 f，其失效回退谓词满足 `Fil_f^fail ⊆ Fil_f`，则任一单点/组合失效后 `Exec_v24^fail ⊆ Exec_v24`（而不是回涨到执行集更大的 `Exec_v23`）。

**证明**：
1. v23 原文“回退到 v22/v20”容易被误读为恢复基线的全部执行集；若 `Exec_v24 ⊆ Exec_v23`，恢复 v23 反而是放大。
2. 本方案要求失效时把 `Fil_f` 替换为更严的 `Fil_f^fail`（最严可取“全拒/停机”），而非替换为 `True`。例如 ITBC 失效时 `Fil_temporal^fail = {π: 仅在最新锚点后的极短窗口}` ⊂ `Fil_temporal`；CTC 失效时 `Fil_clock^fail = ∅`。
3. 由 `Fil_f^fail ⊆ Fil_f` 逐项取交，`Exec_v24^fail = Exec_v23 ∩ ⋂_f Fil_f^fail ⊆ Exec_v23 ∩ ⋂_f Fil_f = Exec_v24`。∎

### 定理（HPC-E++ 时间-中介准入门的安全-活性-可审计完备性）
**陈述**：对任意计划 π，`HPCEPlusPlus.admits(π)=True` ⟺ π 同时满足：
(1) v23 四证（物理接地安全 ∧ 云边版本一致 ∧ 少样本覆盖 ≥1-α ∧ 专利保护完备）；
(2) 证书沿时间时移可靠（引理 1）；
(3) 令牌在认证时钟偏差界内有效（引理 3）；
(4) QoS 新鲜度达标；
(5) 指令经唯一引用监视器完全中介（引理 2）。
且任意单点/组合失效下 `Exec_v24^fail ⊆ Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ ...`（引理 5）。

**证明**：必要性由 `admits` 的五个合取项直接给出；充分性由引理 1–5 逐项保证，且失效安全细化保证退化链不出现回涨。∎

## 4. 已知风险与缓解

| 风险编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| R1 | 时间幻觉：信任根（IMU/时钟/中间件）失步、被重放或欺骗，导致“看起来新鲜”的过期/伪造证书被执行 | 最高 | 1) IMU 与轮/腿里程计交叉自检；2) 冗余 IMU + 硬件时间戳 PTP；3) 令牌 nonce + 单调计数器防重放；4) MERM 安全启动/远程证明 + 硬件看门狗 + 独立停机通道 | 若攻击者同时攻破所有信任根且未产生冲击，碰撞前无法获得外部真值 |
| R2 | 惯性包络过松（尤其 `R_max·ε_θ` 杠杆项）导致时移窗口极短、活性坍缩 | 高 | 1) 陀螺零偏在线标定；2) 视觉锚点插值/更高频外感受；3) 按区域自适应 `v_world_max` 与速度上限；4) 距离场预计算降低时移开销 | 远距 + 高转速 + 长时无锚点场景仍可能被迫限速 |
| R3 | 完全中介被绕过（共享内存、直接设备访问、优先级反转、WCET 超限） | 高 | 1) 能力制/内存保护/seccomp 隔离；2) 形式化 WCET 分析 + 冗余监视器；3) 只暴露唯一执行器写通道；4) 运行时验证规格 | 内核/驱动层漏洞可能绕过用户态隔离 |
| R4 | 冲击误报（搬放、载荷跌落、颠簸）触发不必要的停机与重校准 | 中 | 1) 多轴/时频特征 + 上下文门控；2) 连续多次才升级；3) 人工确认后恢复；4) 只收紧不放松，避免误报导致安全放松 | 恶劣地形下误报率与活性之间的折衷 |
| R5 | 时钟同步依赖（PTP 主时钟失效）导致全局停机 | 中 | 1) 本地保持振荡器 + 认证漂移界；2) 降级为本地单调时钟并缩短有效窗；3) 多主时钟冗余 | 长时断连下保持振荡器漂移可能超出认证界 |
| R6 | 多机器人跨域时钟一致性难以保证 | 中 | 1) 每机器人本地完全中介；2) 跨机器人令牌交换显式携带 `skew_max` 与有效窗；3) 不要求全局同时刻，只要求区间相交 | 大规模联邦下区间相交可能频繁失败 |

## 6. 本轮最大风险（最终确认）

**一句话**：时间-中介层的信任根（中间件 + 时钟 + IMU）是**自指**的——若它失步、被重放或被欺骗，系统会以完全合规、可审计的方式执行一份“看起来新鲜”的过期/伪造证书（时间幻觉），而唯一的外部真值（冲击见证）只在碰撞之后才出现，无法在碰撞前证伪它。
