# 第 68 轮（承接第 67 轮「SimRAS 仿真增强风险自适应闭环」IP-233~242；灵感循环第 1 轮；本轮灵感：「检索增强生成」×「多任务学习」）

> 第 67 轮 SimRAS 把在线闭环升级为「离线仿真预训练 + 在线世界模型 + VQA 审计」的三层架构。但它暴露出一个结构性缺陷：**知识几乎全部被“压”进了参数，以及一个按 `scene_hash` 索引的审计缓冲区**。这带来两个问题：
> 1. **知识不可检索、不可溯源、不可增量修订**：当新的故障案例、新的法规约束、新的「情绪-故障」共现模式出现时，只能重训 WM/VQA，或手工往 `AuditBuf` 塞键值；系统无法回答「这条风险判断依据的是哪条证据、哪一版知识」。
> 2. **多任务之间是“拼装”而非“协同”**：`dyn/emo/fault/risk/audit/cert` 六个头各自训练或松散联合，没有显式建模任务间的正/负迁移，安全关键任务（`fault/risk/cert`）可能被辅助任务（`emo/audit`）的梯度拖累。
>
> 本轮两条灵感恰好给出互补的两根轴：
> - **检索增强生成（RAG）**：把知识从“参数”搬到“外部、版本化、可溯源的知识库”，在线按需检索，作为显式证据注入闭环；
> - **多任务学习（MTL）**：把知识压进“共享表示”，用任务关系与梯度协调实现一次前向、多任务输出。
>
> 二者其实是一体两面：**MTL 是参数化知识，RAG 是非参数化知识**。安全关键闭环不应二选一，而应维持**双层知识系统**，并让两层互为校验。
>
> 核心命题：
>
> **把 SimRAS 的“仿真预训练 + 世界模型”升级为「双层知识闭环」RAMC（Retrieval-Augmented Multi-task Closure）：参数层用多任务共享骨干提供 <1ms 的多头先验；非参数层用版本化安全案例知识库（SCKB）提供可溯源的证据；两层的分歧作为“知识冲突”信号，触发保守回退与证书失效。**

## 0. 直觉与动机

**灵感 1（RAG → 把“审计缓冲区”升级为“安全案例知识库”）**
直觉：RAG 的关键不是“检索一段文本”，而是“在决策前注入外部、可更新、可归因的证据”。第 67 轮的 `AuditBuf` 已经是 RAG 的雏形，但它是**被动的、无结构的、无溯源的**：它只在场景哈希命中时复用结论，既不知道结论从哪来，也不知道它何时过期。SCKB 把它升级为四类结构化知识：
- `K_fault`：故障原型（几何/力/传感器/模型的签名与先验）；
- `K_ef`：情绪-故障共现案例（例如「几何误差 → 面部紧张」的因果链）；
- `K_audit`：已认证的审计报告（含反事实建议与 `λ_adjust`）；
- `K_rule`：法规/安全约束（硬性容差、不可逾越的力/几何界）。

检索结果不是“答案”，而是**证据集 `R_t`**，进入贝叶斯后验。这样知识可增量修订、可版本回滚、可审计。

**灵感 2（MTL → 六个头从“拼装”到“协同”）**
直觉：SimRAS 的六个头共享同一个物理世界，本应共享表示。MTL 让 `dyn/emo/fault/risk/audit/cert` 共享编码器，用**任务关系矩阵 A** 决定哪些任务该共享、哪些该隔离（低秩 adapter）。关键不是“多任务一定更好”，而是**安全关键任务必须有不退化地板**：辅助任务带来的负迁移必须被显式约束，否则一次梯度冲突就可能让 `cert` 头悄悄变差。

**灵感 3（合流 → 双层知识的一致性契约）**
直觉：RAG 与 MTL 的误差**并不独立**——它们往往共享同一份训练/仿真数据来源（第 67 轮的 SimEngine 就是共同祖先）。因此“两层预测一致”不能直接当作“正确”的证据，它可能只是**共享偏置的共识**。这正是本轮的枢纽：一致性契约必须引入**溯源独立度（provenance independence）**，否则会给出虚假的安全感。

**灵感 4（组件映射）**
- `AuditBuf → SCKB`：键值缓存升级为带 `source/version/valid_interval/trust` 的知识条目 + ANN 索引；
- `VQAuditor → SCKB-Writer`：审计即入库，报告带溯源哈希；
- `WM → MTBackbone`：`dyn/emo/fault` 三头并入共享骨干，另加 `risk/audit/cert` 三头；
- 新增 `MTRet`：一次查询编码、多类型检索（multi-task retrieval）；
- `EFS → EFS-RAC`：联合后验乘以检索证据的专家乘积；
- `C-RAS-WM → C-RAS-RAC`：认证前缀增加“检索一致性”与“溯源有效性”条件；
- 新增 `KVC`（知识有效性检查）与 `CPD`（跨层分歧检测）。

**灵感 5（一个反直觉的观察）**
RAG 常被当作“减少幻觉”，MTL 常被当作“提升泛化”。但在安全闭环里，二者结合会产生一个新的失效模式：**参数层与非参数层互相确认对方的错误**。若 SCKB 的案例与 MTL 的训练轨迹都来自同一套 SimEngine，那么“检索证据支持 WM 预测”只说明二者同源，不说明它们正确。这就是第 6 节的核心风险。

## 1. 形式化定义（增量：定义 266–285）

- **定义 266（RAMC 总览）**：`RAMC = (SCKB, MTRet, MTBackbone, RAC, MTCert)`。定位：SimRAS 的“单层参数知识”升级为“参数 + 非参数双层知识”。不变式：检索索引与 MTL 预训练只在离线；在线检索 ≤ 0.5ms、共享骨干 ≤ 0.8ms；**任何检索证据都不得绕过溯源校验直接放宽证书**。
- **定义 267（安全案例知识库 SCKB）**：`SCKB = {K_fault, K_ef, K_audit, K_rule}`，每个 `K_k` 是一个条目集合，支持 ANN 检索与版本化快照。
- **定义 268（知识条目）**：`e = (v_e ∈ ℝ^d, y_e, t_e, s_e, ver_e, h_e, I_e, trust_e)`：查询向量、载荷（(H,E) 分布 / λ 建议 / 约束）、写入时间、来源标识、版本号、内容哈希、有效期 `I_e = [t_start, t_end]`、可信度。
- **定义 269（多任务查询编码）**：`q_t = E_q(x'_t, π_t, P(H_t))`，单一查询向量；对每个知识类型 `k` 用类型投影 `W_k` 得到 `q_t^k = W_k q_t`，实现“一次编码、多任务检索”。
- **定义 270（多任务检索）**：`R_t^k = TopK_{e∈K_k} [ cos(q_t^k, v_e) + β·u_k(e) ] · 1[valid(e)]`，`u_k` 是任务相关的效用项（如反事实可执行性）。`R_t = ⋃_k R_t^k`。
- **定义 271（权威权重）**：`ω_e = trust_e · freshness_e · indep_e · 1[valid(e)]`，其中 `freshness_e = exp(-(t - t_e)/τ_fresh)`，`indep_e` 为溯源独立度（定义 280）。
- **定义 272（检索增强联合后验）**：`P(H,E | ρ, face, R_t) ∝ P_EFS(H,E | ρ, face) · ∏_{e∈R_t} p_e(H,E)^{ω̃_e}`，其中 `ω̃_e = Ω_max · ω_e / Σ_{e'} ω_{e'}` 为归一化权威权重（专家乘积 / product-of-experts）。
- **定义 273（证据上限）**：`Σ_e ω_e ≤ Ω_max`。上限防止大量低质量条目通过“数量堆叠”压过参数层先验，等价于限制有效证据样本量。
- **定义 274（多任务共享骨干）**：`MTBackbone_φ = (g_φ, {h_{ψ_i}}_{i=1}^6)`，共享编码器 `g_φ`，六头 `T = {T_dyn, T_emo, T_fault, T_risk, T_audit, T_cert}`。前向一次输出 `(ŝ, π, P(H), λ, audit_feat, k̂)`。
- **定义 275（任务关系矩阵）**：`A ∈ [-1,1]^{6×6}`，`A_{ij}` 由梯度余弦相似度与经验迁移增益估计。`A_{ij} > τ_share` → 全共享；`A_{ij} < 0` → 经低秩 adapter 隔离。
- **定义 276（安全加权损失与地板）**：`L = Σ_i w_i L_i`，`w_i` 用不确定性加权标定；并施加负迁移地板 `L_s ≤ (1+ε_floor)·L_s^{single}`，`s ∈ {fault, risk, cert}`。
- **定义 277（梯度冲突消解）**：若 `g_i·g_j < 0`，则 `g_i ← g_i - (g_i·g_j / ‖g_j‖²) g_j`（PCGrad），并对安全任务赋予优先级：安全任务梯度不被辅助任务投影。
- **定义 278（检索条件化 adapter）**：`h_{ψ_i}^{R} = h_{ψ_i}(g_φ(x) + LowRank_k(q_t^k))`，按检索到的知识类型选择 adapter，抑制跨类型负迁移。
- **定义 279（跨层分歧）**：参数层 `θ^P = (π^MTL, P^MTL(H), λ^MTL)`，检索共识 `θ^R`（由 `∏ p_e^{ω̃_e}` 得到）。`D_t = KL(π^MTL ‖ π^R) + ‖P^MTL(H) - P^R(H)‖_1 + |λ^MTL - λ^R|`。若 `D_t > τ_consist`，置 `tier_conflict = True`。
- **定义 280（溯源独立度）**：设参数层的训练来源集合为 `S_train`，条目 `e` 的来源集合为 `S_e`。`indep_e = 1 - |S_e ∩ S_train| / |S_e ∪ S_train| ∈ [0,1]`。同源条目 `indep_e → 0`，即使 `D_t → 0` 也不构成独立确认。
- **定义 281（矛盾检疫）**：条目 `e` 若与 ≥κ 个高权威条目在风险方向上冲突，则 `contradict_e = True`，进入隔离区，`ω_e ← 0`，并记录 `quarantine_hash`。
- **定义 282（知识陈旧与漂移）**：`kb_drift = [TV(P_obs(H,E) ‖ P_SCKB(H,E)) > δ_kb]`。漂移时对全部条目施加 `freshness` 衰减，并提高 `Ω_max` 的保守下限（更依赖参数层保守先验）。
- **定义 283（检索增强认证前缀）**：`k_RAC = max{k' ≤ m : ∀i≤k', λ_risk^{RAC}(t+i)·ρ_safe(t+i) ≥ 0 ∧ D_{t+i} ≤ τ_consist}`；最终 `k* = min(k_VISTA, k_emo, k_wm, k_RAC, m)`。
- **定义 284（J_RAMC 证书）**：`J_RAMC = (J_SimRAS, retrieval_hash, provenance_root, mtl_version, task_conflict, tier_conflict, kb_drift, indep_min)`。Valid ⇔ `Valid(J_SimRAS) ∧ provenance_root ≠ ∅ ∧ indep_min ≥ 0.3 ∧ ¬(tier_conflict ∧ indep_min < 0.6)`。
- **定义 285（RAMC 在线不变式）**：实时环路由 `MTRet → MTBackbone → EFS-RAC → C-RAS-RAC → ERS` 构成；检索与 MTL 并行；KVC/CPD 在语义流运行；所有检索证据必须携带 `provenance_root` 才能进入 `J_RAMC`。

# IP-243 SCKB：安全案例知识库
class SafetyCaseKB:
    def __init__(self, dim=256, tau_fresh=3600.0, omega_max=2.0):
        self.types = {'K_fault': [], 'K_ef': [], 'K_audit': [], 'K_rule': []}
        self.index = {k: ANNIndex(dim) for k in self.types}
        self.tau_fresh, self.omega_max = tau_fresh, omega_max

    def insert(self, k_type, entry):
        self.types[k_type].append(entry)
        self.index[k_type].add(entry.v_e, entry.h_e)

    def authority(self, e, now):
        fresh = math.exp(-(now - e.t_e) / self.tau_fresh)
        valid = 1.0 if e.I_e[0] <= now <= e.I_e[1] else 0.0
        return e.trust * fresh * e.indep * valid


# IP-244 MTRet：多任务检索器（一次编码、多类型检索）
class MultiTaskRetriever:
    def __init__(self, q_enc, proj, kb, topk=4, beta=0.1):
        self.q_enc, self.proj, self.kb, self.topk, self.beta = q_enc, proj, kb, topk, beta

    def retrieve(self, x_prime, pi, pH, now):
        q = self.q_enc(x_prime, pi, pH)
        evidence, weights = [], []
        for k_type in self.kb.types:
            qk = self.proj[k_type](q)
            cands = self.kb.index[k_type].search(qk, self.topk)
            for e, sim in cands:
                w = self.kb.authority(e, now)
                if w <= 0:
                    continue
                evidence.append(e)
                weights.append(w * (sim + self.beta * utility(k_type, e)))
        # 归一化 + 证据上限（定义 273）
        s = sum(weights) + 1e-9
        weights = [min(self.kb.omega_max, w) / s for w in weights]
        return evidence, weights


# IP-245 MTBackbone：多任务共享骨干（含安全地板与 PCGrad）
class MultiTaskBackbone:
    def __init__(self, g, heads, task_relation, eps_floor=0.01):
        self.g, self.heads, self.A, self.eps_floor = g, heads, task_relation, eps_floor

    def forward(self, x):
        z = self.g(x)
        return {name: head(z) for name, head in self.heads.items()}

    def train_step(self, batch, single_task_ref):
        grads = {t: grad_of(self.heads[t], batch) for t in self.heads}
        # 安全关键任务优先，不被辅助任务投影
        safety = {'fault', 'risk', 'cert'}
        for i in self.heads:
            for j in self.heads:
                if i == j or i in safety:
                    continue
                if dot(grads[i], grads[j]) < 0:
                    grads[i] = pcgrad(grads[i], grads[j])
        # 负迁移地板（定义 276）
        for s in safety:
            assert loss(self.heads[s], batch) <= (1 + self.eps_floor) * single_task_ref[s]
        return apply(grads)


# IP-246 EFS-RAC：检索增强的联合后验
class EmotionFaultSynthesisRAC(EmotionFaultSynthesis):
    def synthesize(self, rho, face_gate, evidence, weights):
        base, post_H = super().synthesize(rho, face_gate)
        joint = dict(base)
        for e, w in zip(evidence, weights):
            if e.y_type != 'distribution':
                continue
            for key, p in e.y.items():
                if key in joint:
                    joint[key] *= max(p, 1e-6) ** w
        return normalize(joint), post_H


# IP-247 C-RAS-RAC：检索增强认证前缀
class ChunkSafetyCertificateRAC(ChunkSafetyCertificateRASWM):
    def certified_prefix_rac(self, A, joint_post, m, wm_preds, D_seq, tau_consist):
        k_rac = 0
        for k in range(1, min(len(A), m) + 1):
            if D_seq[k - 1] > tau_consist:
                break
            k_rac = k
        k_wm = self._wm_prefix(A, wm_preds)
        k_ras = self.certified_prefix_ras(A, joint_post, m, 0.05)
        return min(k_ras, k_wm, k_rac, m)


# IP-249 CPD：跨层分歧检测（含溯源独立度）
class CrossTierDiscrepancy:
    def __init__(self, tau_consist=0.25, indep_min=0.3):
        self.tau, self.indep_min = tau_consist, indep_min

    def check(self, theta_p, theta_r, evidence):
        D = (kl(theta_p['pi'], theta_r['pi'])
             + l1(theta_p['pH'], theta_r['pH'])
             + abs(theta_p['lambda'] - theta_r['lambda']))
        indep = min([e.indep for e in evidence], default=0.0)
        return {'D': D, 'tier_conflict': D > self.tau,
                'indep_min': indep,
                'trusted_conflict': (D > self.tau) and (indep >= self.indep_min)}


# IP-252 RAMC 在线闭环
def RAMC_round(M, obs, now):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))

    # 1) 多任务共享骨干：一次前向多任务先验
    theta_p = M.mtb.forward(x_prime)
    face_gate = M.erg_wm.recognize(img, x_prime, M.vista.ach.propose_actions(x_prime))

    # 2) 多任务检索
    evidence, weights = M.mtret.retrieve(x_prime, face_gate['pi'], theta_p['pH'], now)

    # 3) 知识有效性检查 + 矛盾检疫
    evidence, weights = M.kvc.filter(evidence, weights, M.kb)

    # 4) 检索增强联合归因
    rho = M.vista.fir.signature(M.vista.stage.split(M.vista.residual_log))
    joint_post, _ = M.efs_rac.synthesize(rho, face_gate, evidence, weights)
    theta_r = retrieval_consensus(evidence, weights)

    # 5) 跨层分歧
    disc = M.cpd.check(theta_p, theta_r, evidence)
    if disc['trusted_conflict']:
        joint_post = conservative_fallback(joint_post, theta_p)  # 回退参数层保守先验

    # 6) 认证前缀
    m = min(M.vista.m, M.er.max_m_emotion)
    k_ras = M.csc_rac.certified_prefix_rac(
        M.vista.ach.propose(x_prime, H=M.vista.H), joint_post, m,
        theta_p['wm_preds'], disc['D_seq'], M.tau_consist)
    λ_risk = M.efs_rac.risk_scale(joint_post)

    tau_cmd = M.vista.pi_sigma.prefix_dispatch(A[:k_ras]) * λ_risk
    tau_cmd = M.ers.shaping(tau_cmd, joint_post)
    return k_ras, λ_risk, joint_post, face_gate, disc

## 3. 推导

**引理 13（证据上限下的后验标定）** 设每条证据 `e` 的似然 `p_e` 已标定，且 `Σ_e ω_e ≤ Ω_max`。则专家乘积后验的有效证据数 `N_eff ≤ Ω_max`，其后验方差满足 `Var[P(H,E|R_t)] ≤ Var[P_EFS] / (1 + Ω_max·I_e)`，其中 `I_e` 为单条证据的 Fisher 信息。证据上限保证：**数量不能替代质量**，低质量条目的堆叠收益递减。

**引理 14（负迁移地板）** 在 PCGrad + 安全任务优先投影下，安全任务 `s` 的梯度满足 `g_s^{MTL} = g_s^{ST} + Σ_{j∉safety} A_{sj}·proj(g_j)`。若 `A_{sj} < 0`（负迁移）则投影项被截断，故 `‖g_s^{MTL} - g_s^{ST}‖ ≤ Σ_{j: A_{sj}>0} |A_{sj}|·‖g_j‖`。取 `τ_share` 使 `A_{sj}` 的负部为零，则地板 `L_s ≤ (1+ε_floor)L_s^{ST}` 可证。

**定理 14（RAMC 端到端风险一致性）** 在 A87-A91、SimRAS 误差界及引理 13/14 下，RAMC 输出满足：
1. `P(|τ_cmd - τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_ret + α_mtl`；
2. `tier_conflict ∧ indep_min ≥ 0.6 ⇒ λ_risk ≤ λ_SimRAS`（分歧且来源独立时自动收紧）；
3. `kb_drift = True ⇒ Ω_max 下调，λ_risk ≥ 0.9`（知识陈旧时回归保守）；
4. `indep_min < 0.3 ⇒ J_RAMC 不可 Valid`（同源共识不得充当独立证据）。

**定理 15（投毒鲁棒性界）** 设投毒条目集合 `P`，`|P| = m`，每条权威权重 `≤ ω_max`。经矛盾检疫后，被保留的投毒条目对后验的总影响满足 `‖P(H,E|R_t) - P(H,E|R_t \ P)‖_TV ≤ 2·(ω_max·m)/(Ω_max + ω_max·m)`。当 `m ≤ 0.05|R_t|` 且 `ω_max ≤ 0.1Ω_max` 时，影响 `< 0.1`。

**定理 16（知识覆盖的样本复杂度）** 为使 SCKB 以半径 `τ_kb` 覆盖 95% 的在线 `(H,E,scene)` 查询，需 `N_kb ≥ (d_kb/τ_kb)^{d_kb}·log(1/δ)`。取 `d_kb ≈ 16`、`τ_kb = 0.4` 时 `N_kb ≈ 2×10^4` 即可（远小于 SimEngine 的 10^6，因为知识库只存“结论原型”而非完整轨迹）。

**定理 17（警示：同源共识不蕴含正确——共享偏置下的一致性失效）** 设参数层与 SCKB 均以 SimEngine 为唯一来源（`indep_e = 0`），且存在一个系统性偏置 `δ_bias` 同时作用于两层。则存在配置使 `D_t → 0` 而真实风险误差下界 `≥ δ_bias`。即：**跨层一致 `D_t` 只有在 `indep_e` 足够大时才是有效的错误信号**。这为定义 280 与 `J_RAMC` 中的 `indep_min` 约束提供了必要性证明。

## 2. 形式化定义（完整版）

**定义 266（RAMC 总览）** RAMC 是 SimRAS 的「参数 + 非参数双层知识」增强层：
```
RAMC = (SCKB, MTRet, MTBackbone, RAC, MTCert)
```
不变式：检索索引与 MTL 预训练只在离线；在线检索 ≤ 0.5ms、共享骨干 ≤ 0.8ms；任何检索证据都不得绕过溯源校验直接放宽证书。

**定义 267（安全案例知识库）** `SCKB = {K_fault, K_ef, K_audit, K_rule}`，每类支持 ANN 检索与版本化快照，支持增量插入、版本回滚与逻辑删除。

**定义 268（知识条目）** `e = (v_e ∈ ℝ^d, y_e, t_e, s_e, ver_e, h_e, I_e, trust_e)`。`y_e` 可为 `(H,E)` 上的分布、`λ_adjust` 建议或硬约束；`h_e` 是内容哈希，`I_e` 是有效期。

**定义 269（多任务查询编码）** `q_t = E_q(x'_t, π_t, P(H_t))`，类型投影 `q_t^k = W_k q_t`。一次编码服务多类检索，避免为每类知识重复编码。

**定义 270（多任务检索）**
```
R_t^k = TopK_{e∈K_k} [cos(q_t^k, v_e) + β·u_k(e)] · 1[valid(e)]
R_t   = ⋃_k R_t^k
```

**定义 271（权威权重）** `ω_e = trust_e · freshness_e · indep_e · 1[valid(e)]`，`freshness_e = exp(-(t - t_e)/τ_fresh)`。

**定义 272（检索增强联合后验）**
```
P(H,E | ρ, face, R_t) ∝ P_EFS(H,E | ρ, face) · ∏_{e∈R_t} p_e(H,E)^{ω̃_e}
ω̃_e = Ω_max · ω_e / Σ_{e'} ω_{e'}
```

**定义 273（证据上限）** `Σ_e ω_e ≤ Ω_max`。上限等价于限制有效证据样本量，防止低质量条目靠数量压过参数层先验。

**定义 274（多任务共享骨干）** `MTBackbone_φ = (g_φ, {h_{ψ_i}}_{i=1}^6)`，`T = {T_dyn, T_emo, T_fault, T_risk, T_audit, T_cert}`。一次前向输出 `(ŝ, π, P(H), λ, audit_feat, k̂)`。

**定义 275（任务关系矩阵）** `A_{ij}` 由梯度余弦相似度与经验迁移增益估计：`A_{ij} > τ_share` 全共享；`A_{ij} < 0` 经低秩 adapter 隔离。

**定义 276（安全加权损失与地板）** `L = Σ_i w_i L_i`，`w_i` 不确定性加权；安全任务 `s∈{fault,risk,cert}` 满足 `L_s ≤ (1+ε_floor)L_s^{single}`。

**定义 277（梯度冲突消解）** 若 `g_i·g_j < 0`，`g_i ← g_i - (g_i·g_j/‖g_j‖²)g_j`；安全任务梯度不被辅助任务投影（安全优先）。

**定义 278（检索条件化 adapter）** `h_{ψ_i}^{R} = h_{ψ_i}(g_φ(x) + LowRank_k(q_t^k))`，按检索类型选择 adapter，抑制跨类型负迁移。

**定义 279（跨层分歧）**
```
D_t = KL(π^MTL ‖ π^R) + ‖P^MTL(H) - P^R(H)‖_1 + |λ^MTL - λ^R|
```
若 `D_t > τ_consist` 则 `tier_conflict = True`。

**定义 280（溯源独立度）** `indep_e = 1 - |S_e ∩ S_train| / |S_e ∪ S_train|`。同源条目 `indep_e → 0`；此时即使 `D_t → 0` 也不构成独立确认。

**定义 281（矛盾检疫）** 条目若与 ≥κ 个高权威条目风险方向冲突，则 `contradict_e = True`，`ω_e ← 0` 并写入隔离区与 `quarantine_hash`。

**定义 282（知识陈旧与漂移）** `kb_drift = [TV(P_obs(H,E) ‖ P_SCKB(H,E)) > δ_kb]`；漂移时对全部条目施加 `freshness` 衰减并下调 `Ω_max`。

**定义 283（检索增强认证前缀）** `k_RAC = max{k'≤m : ∀i≤k', λ_risk^{RAC}(t+i)·ρ_safe(t+i) ≥ 0 ∧ D_{t+i} ≤ τ_consist}`；最终 `k* = min(k_VISTA, k_emo, k_wm, k_RAC, m)`。

**定义 284（J_RAMC 证书）**
```
J_RAMC = (J_SimRAS, retrieval_hash, provenance_root, mtl_version,
          task_conflict, tier_conflict, kb_drift, indep_min)
```
Valid ⇔ `Valid(J_SimRAS) ∧ provenance_root ≠ ∅ ∧ indep_min ≥ 0.3 ∧ ¬(tier_conflict ∧ indep_min < 0.6)`。

**定义 285（RAMC 在线不变式）** 实时环路由 `MTRet → MTBackbone → EFS-RAC → C-RAS-RAC → ERS` 构成；检索与 MTL 并行；KVC/CPD 在语义流运行；所有检索证据必须携带 `provenance_root` 才能进入 `J_RAMC`。

# IP-243 SCKB
class SafetyCaseKB:
    def __init__(self, dim=256, tau_fresh=3600.0, omega_max=2.0):
        self.types = {'K_fault': [], 'K_ef': [], 'K_audit': [], 'K_rule': []}
        self.index = {k: ANNIndex(dim) for k in self.types}
        self.tau_fresh, self.omega_max = tau_fresh, omega_max

    def insert(self, k_type, entry):
        self.types[k_type].append(entry)
        self.index[k_type].add(entry.v_e, entry.h_e)

    def authority(self, e, now):
        fresh = math.exp(-(now - e.t_e) / self.tau_fresh)
        valid = 1.0 if e.I_e[0] <= now <= e.I_e[1] else 0.0
        return e.trust * fresh * e.indep * valid


# IP-244 MTRet：多任务检索
class MultiTaskRetriever:
    def __init__(self, q_enc, proj, kb, topk=4, beta=0.1):
        self.q_enc, self.proj, self.kb = q_enc, proj, kb
        self.topk, self.beta = topk, beta

    def retrieve(self, x_prime, pi, pH, now):
        q = self.q_enc(x_prime, pi, pH)
        evidence, weights = [], []
        for k_type in self.kb.types:
            qk = self.proj[k_type](q)
            for e, sim in self.kb.index[k_type].search(qk, self.topk):
                w = self.kb.authority(e, now)
                if w <= 0:
                    continue
                evidence.append(e)
                weights.append(w * (sim + self.beta * utility(k_type, e)))
        s = sum(weights) + 1e-9
        weights = [min(self.kb.omega_max, w) / s for w in weights]
        return evidence, weights


# IP-248 KVC：有效期校验 + 矛盾检疫
class KnowledgeValidityChecker:
    def __init__(self, kappa=2, tau_conflict=0.5):
        self.kappa, self.tau = kappa, tau_conflict

    def filter(self, evidence, weights, kb):
        kept, kept_w = [], []
        for e, w in zip(evidence, weights):
            if not valid(e) or contradict_count(e, evidence) >= self.kappa:
                kb.quarantine(e)
                continue
            kept.append(e); kept_w.append(w)
        return kept, kept_w


# IP-245 MTBackbone：共享骨干 + PCGrad + 安全地板
class MultiTaskBackbone:
    def __init__(self, g, heads, task_relation, eps_floor=0.01):
        self.g, self.heads = g, heads
        self.A, self.eps_floor = task_relation, eps_floor

    def forward(self, x):
        z = self.g(x)
        return {name: head(z) for name, head in self.heads.items()}

    def train_step(self, batch, single_task_ref):
        grads = {t: grad_of(self.heads[t], batch) for t in self.heads}
        safety = {'fault', 'risk', 'cert'}
        for i in self.heads:
            for j in self.heads:
                if i == j or i in safety:
                    continue
                if dot(grads[i], grads[j]) < 0:
                    grads[i] = pcgrad(grads[i], grads[j])
        for s in safety:
            assert loss(self.heads[s], batch) <= (1 + self.eps_floor) * single_task_ref[s]
        return apply(grads)


# IP-246 EFS-RAC：专家乘积后验
class EmotionFaultSynthesisRAC(EmotionFaultSynthesis):
    def synthesize(self, rho, face_gate, evidence, weights):
        base, post_H = super().synthesize(rho, face_gate)
        joint = dict(base)
        for e, w in zip(evidence, weights):
            if e.y_type != 'distribution':
                continue
            for key, p in e.y.items():
                if key in joint:
                    joint[key] *= max(p, 1e-6) ** w
        return normalize(joint), post_H


# IP-247 C-RAS-RAC
class ChunkSafetyCertificateRAC(ChunkSafetyCertificateRASWM):
    def certified_prefix_rac(self, A, joint_post, m, wm_preds, D_seq, tau_consist):
        k_rac = 0
        for k in range(1, min(len(A), m) + 1):
            if D_seq[k - 1] > tau_consist:
                break
            k_rac = k
        k_wm = self._wm_prefix(A, wm_preds)
        k_ras = self.certified_prefix_ras(A, joint_post, m, 0.05)
        return min(k_ras, k_wm, k_rac, m)

    def check(self, theta_p, theta_r, evidence):
        D = (kl(theta_p['pi'], theta_r['pi'])
             + l1(theta_p['pH'], theta_r['pH'])
             + abs(theta_p['lambda'] - theta_r['lambda']))
        indep = min([e.indep for e in evidence], default=0.0)
        return {'D': D,
                'tier_conflict': D > self.tau,
                'indep_min': indep,
                'trusted_conflict': (D > self.tau) and (indep >= self.indep_min)}


# IP-252 RAMC 在线闭环
def RAMC_round(M, obs, now):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))

    theta_p = M.mtb.forward(x_prime)
    act_seq = M.vista.ach.propose_actions(x_prime, H=M.vista.H, steps=5)
    face_gate = M.erg_wm.recognize(img, x_prime, act_seq)

    evidence, weights = M.mtret.retrieve(x_prime, face_gate['pi'], theta_p['pH'], now)
    evidence, weights = M.kvc.filter(evidence, weights, M.kb)

    rho = M.vista.fir.signature(M.vista.stage.split(M.vista.residual_log))
    joint_post, _ = M.efs_rac.synthesize(rho, face_gate, evidence, weights)
    theta_r = retrieval_consensus(evidence, weights)

    disc = M.cpd.check(theta_p, theta_r, evidence)
    if disc['trusted_conflict']:
        joint_post = conservative_fallback(joint_post, theta_p)

    m = min(M.vista.m, M.er.max_m_emotion)
    A = M.vista.ach.propose(x_prime, H=M.vista.H)
    k_ras = M.csc_rac.certified_prefix_rac(
        A, joint_post, m, theta_p['wm_preds'], disc['D_seq'], M.tau_consist)
    λ_risk = M.efs_rac.risk_scale(joint_post)

    tau_cmd = M.vista.pi_sigma.prefix_dispatch(A[:k_ras]) * λ_risk
    tau_cmd = M.ers.shaping(tau_cmd, joint_post)
    return k_ras, λ_risk, joint_post, face_gate, disc

## 4. 推导

**引理 13（证据上限下的后验标定）** 每条证据 `p_e` 已标定且 `Σ_e ω_e ≤ Ω_max`，则有效证据数 `N_eff ≤ Ω_max`，`Var[P(H,E|R_t)] ≤ Var[P_EFS]/(1 + Ω_max·I_e)`。证据上限保证数量不能替代质量。

**引理 14（负迁移地板）** 在 PCGrad + 安全优先投影下，`g_s^{MTL} = g_s^{ST} + Σ_{j∉safety} A_{sj}·proj(g_j)`；负迁移项被截断，故 `‖g_s^{MTL} - g_s^{ST}‖ ≤ Σ_{j:A_{sj}>0}|A_{sj}|·‖g_j‖`，配合 `τ_share` 可证 `L_s ≤ (1+ε_floor)L_s^{ST}`。

**定理 14（RAMC 端到端风险一致性）** 在 A87-A91、SimRAS 误差界及引理 13/14 下：
1. `P(|τ_cmd - τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_ret + α_mtl`；
2. `tier_conflict ∧ indep_min ≥ 0.6 ⇒ λ_risk ≤ λ_SimRAS`；
3. `kb_drift = True ⇒ Ω_max 下调 ∧ λ_risk ≥ 0.9`；
4. `indep_min < 0.3 ⇒ J_RAMC 不可 Valid`。

**定理 15（投毒鲁棒性界）** 投毒集 `P`，`|P| = m`，单条权威 `≤ ω_max`。经检疫后 `‖P(H,E|R_t) - P(H,E|R_t\P)‖_TV ≤ 2·(ω_max·m)/(Ω_max + ω_max·m)`。`m ≤ 0.05|R_t|` 且 `ω_max ≤ 0.1Ω_max` 时影响 `< 0.1`。

**定理 16（知识覆盖的样本复杂度）** 以半径 `τ_kb` 覆盖 95% 在线查询需 `N_kb ≥ (d_kb/τ_kb)^{d_kb}·log(1/δ)`。取 `d_kb≈16, τ_kb=0.4` 时 `N_kb ≈ 2×10^4`，远小于 SimEngine 的 10^6（知识库只存结论原型）。

**定理 17（警示：同源共识不蕴含正确）** 设参数层与 SCKB 均以 SimEngine 为唯一来源（`indep_e = 0`），系统性偏置 `δ_bias` 同时作用于两层。则存在配置使 `D_t → 0` 而真实风险误差下界 `≥ δ_bias`。故 `D_t` 只有在 `indep_e` 足够大时才是有效错误信号——这为 `indep_min` 约束提供了必要性证明。

## 7. 本轮最大风险

**一句话**：RAMC 把「参数层与检索层一致」当作安全信号，但两层往往共享同一套 SimEngine 来源（`indep_e → 0`），于是会在系统性偏置处产生**自信而一致的错误（共享偏置共识）**，使 `D_t` 失效、`J_RAMC` 给出虚假保证，最终在真实故障处过度放宽容差——本轮所有理论依赖的核心假设是：**跨层一致性只有在溯源独立时才能作为错误信号，而现实中独立知识来源极难获得**。
