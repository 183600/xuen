# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「多任务学习」×「6D位姿估计」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**共享表征 + 位姿不确定证书**。两个灵感分别治理 v9 的两个隐含债：感知债（感知侧多个任务头各自独立前向，算力/数据效率低、知识不迁移）与几何债（证书把 6D 位姿当点估计，位姿协方差从未进入安全余量）。必须保证：共享表征带来的任何任务干扰、位姿分布的任何近似，都在证书层被显式定价；任一模块失效可经中立元严格回退到 v9，而非行为漂移。

## 0. 直觉与动机

**灵感 1（多任务学习 → 安全优先的共享表征与干扰防火墙）**
直觉：v9 的感知/几何头（6D 位姿、语义分割、关键点、可抓取性、间隙回归）目前各自独立前向；这既浪费算力，也让"位姿—抓取—间隙"三件事在表征层互不知情。MTL 用共享编码器一次前向喂多任务，数据效率与时延都应受益。但朴素 MTL 有负迁移：帮助可抓取性的梯度更新可能损害安全关键的间隙/位姿头。核心创新：**任务干扰防火墙（TaskInterferenceFirewall, TIF）**——在共享编码器做 PCGrad 式梯度手术，但采用**非对称安全锥**：安全关键任务（M₀ 间隙、6D 位姿、SpatialCert 输入）的梯度永不被投影，只把非安全任务梯度中与安全梯度冲突的分量消去；并维护**干扰账本**，负迁移超阈则自动把该任务头降级为独立适配器（严格等价 v9 的独立头）。

**灵感 2（6D位姿估计 → 位姿分布与几何敏感度证书）**
直觉：6D 位姿（SE(3)）是抓取点、间隙、可达性的几何底座。位姿从来不是一个点，而是带各向异性、且对对称物体多峰的分布。v9 的证书把位姿当点估计，余量 β 里隐含了"位姿误差"却无法分解。核心创新：**位姿不确定证书（PoseUncertaintyCertificate, PUC）**——位姿头输出 SE(3) 分布（切空间高斯 + SO(3) 矩阵 Fisher 浓度），把协方差经下游几何映射 h(·)（间隙、抓取裕度）的雅可比 J 一阶传播，得到保守界 h(μ) − κ√(JΣJᵀ) − ε_lin；并识别对称多峰歧义，歧义时改用模式集下界或强制保守回退。位姿不确定性由黑箱 β 变为可解释、可核验的证书预算项。

**灵感 3（两者的耦合：算力反哺与正迁移）**
直觉：共享前向省下的算力可反哺 v9 的分块证书生成余量。但共享不是免费午餐：它可能让位姿头借助分割/关键点的几何先验而在遮挡下更稳（正迁移），也可能被任务平均化稀释（负迁移）。因此本轮把"共享"当作**有条件的、可撤销的**结构：只有在干扰账本证明安全任务不劣化时才保留共享；否则自动退回独立头。

## 1. 研究问题（轮次升级版）

- **Q1（安全优先 MTL）**：在共享编码器上，梯度手术能否在数学上保证安全关键任务的损失下降不被非安全任务破坏（不出现"为了抓取更准而牺牲间隙"）？负迁移如何被检测、界定并安全降级？
- **Q2（位姿不确定证书）**：SE(3) 分布经非线性几何映射的一阶传播，在何种信任域/浓度条件下是保守的？对称目标的多峰歧义如何被检测并转化为证书余量，而非静默失准？
- **Q3（两创新的耦合）**：共享表征让位姿头对其他任务更鲁棒（正迁移），还是让安全头被"任务平均化"稀释？MTL 的时延收益能否真实反哺 v9 的分块预算，而不引入新的调度抖动？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 安全锥梯度律（Safety-Cone Gradient, TIF）**
共享编码器参数 θ_s，任务梯度 g_i，安全任务集 S（M₀ 间隙、6D 位姿、SpatialCert 输入）。先按安全优先级合成 g_S；对每个非安全任务 j∉S，若 g_j·g_S<0 则令 g_j ← g_j − (g_j·ĝ_S)ĝ_S（只消去冲突分量），否则保留；θ_s ← θ_s − η(g_S + Σ_{j∉S} g_j')。安全梯度永不投影、永不被抵消。

**P14 位姿不确定证书律（Pose-Uncertainty Certificate, PUC）**
位姿头输出 (μ∈SE(3), Σ_ξ∈R^{6×6} 切空间协方差, 浓度/多峰标记 ξ_amb)。对下游几何泛函 h，证书下界 h_cert = h(μ) − κ·σ_h − ε_lin，σ_h=√(J_hΣ_ξJ_hᵀ)，ε_lin 为一阶传播的二阶残差界；ξ_amb 为真（对称多峰）时改用模式集下界 min_m h_cert,m，或强制回退 v9 点估计 + 固定 β_pose。

**P15 干扰账本律（Interference Ledger, IL）**
每任务维护滑动窗口的验证代理损失与梯度余弦 cos(g_i,g_S)；若非安全任务 j 的负迁移指标 NT_j>δ_NT 持续 H_NT 回合，则断开 j 的共享通路、接独立适配器；安全任务永不降级共享（其共享通路故障时整网回退 v9 独立头）。

## 3. 与基线的接口（如何退化）

- TIF 失效 ⇒ 关闭梯度投影，各任务头使用独立编码器，等价 v9 独立前向；
- PUC 失效（Σ_ξ 未标定 / 传播非保守 / 浓度越界）⇒ 位姿当点估计，β_pose 取上轮标定常数，证书退化到 v9 形式；
- 位姿头失效 ⇒ 中立元注入：位姿取上一可信帧 + 最大膨胀，SpatialCert 退回 v9 深度间隙；
- IL 失效 ⇒ 全部头保持当前共享/独立现状、不迁移，等价 v9；
- 全部失效 ⇒ 完整退回 v9 ACMD，再退回 v8 → v7 → v6。

## 4. 预期贡献

1. **安全锥梯度手术**：把 MTL 负迁移从"训练经验"变成"带方向约束的一阶可证下降性质"，安全关键任务的更新方向受保护；
2. **位姿不确定证书**：SE(3) 分布 → 几何泛函的保守界，把 v9 的黑箱余量 β 分解为可解释的位姿项与模型项；
3. **干扰账本与自动降级**：负迁移可检测、可界定、可安全退回，避免 MTL 在部署时静默劣化；
4. **感知—决策预算闭环**：单次共享前向替代 N 个独立头，释放算力反哺 v9 分块生成；E571–E590 覆盖梯度锥、位姿标定、歧义处理、负迁移降级与端到端。

## 5. 本轮最大风险

**一句话**：PUC 的保守性依赖切空间高斯（或单峰）近似与实际位姿误差尾部的匹配，而对称物体恰恰是位姿多峰、重尾、且抓取最敏感之处——若多峰标记漏检，证书会以"小方差"给出一个自信却错误的界，即「位姿最不确定的对象拿到了最漂亮的证书」。

**新增定义 540（任务梯度与安全集 TaskGradient）** 对任务集 T={pose, seg, kp, afford, clearance, dom, slam}，每步 minibatch 计算 g_i=∇_{θ_s}L_i。安全集 S={clearance(M₀), pose, spatialcert_input}；其余为非安全集 T∖S。

**新增定义 541（安全锥投影 SafetyConeProjection）** 设 ĝ_S=g_S/‖g_S‖（‖g_S‖>0）。对 j∉S：
```
proj(g_j; g_S) = g_j − min(0, g_j·ĝ_S)·ĝ_S
```
即仅当 g_j 与 g_S 冲突（内积为负）时消去其负投影分量，使投影后与 g_S 正交；不冲突则原样保留。合成更新方向 d = g_S + Σ_{j∉S} proj(g_j;g_S)。对 i∈S 恒有 proj(g_i;g_S)=g_i。

**新增定义 542（干扰账本与负迁移指标 InterferenceLedger）** 每任务维护窗口 W_NT 上的验证代理损失 L_j^val 与梯度余弦 cos_j=cos(g_j,g_S)：
```
NT_j(t) = EMA_W [ relu(L_j^val(t) − L_j^val,ref)
                  + λ_nt · relu(−cos_j(t)) ]
```
L_j^val,ref 为该头独立训练（v9）时的参考损失；λ_nt=1.0。判据 NT_j>δ_NT（默认 0.05）连续 H_NT=3 回合。

**新增定义 543（任务头降级 HeadDemotion）** 触发后断开任务 j 到 θ_s 的梯度通路，接一个轻量独立适配器 φ_j（仅共享输入、不共享参数），头权重不变。降级后 j 的输出分布与"v9 独立头 + 同权重"逐位一致（引理 90）。安全任务 i∈S 不可降级；若其共享通路本身故障，整网回退 v9 独立前向。

**新增定义 544（SE(3) 位姿分布 PoseDistribution）** 位姿头输出 pose=μ·exp(ξ^)，ξ~N(0,Σ_ξ)；旋转块由矩阵 Fisher M(R;A) 给出，浓度 κ_F 与 Σ_R 的逆对应，平移块为 N(t;0,Σ_t)，并以块对角近似 Σ_ξ=blkdiag(Σ_R,Σ_t)。另输出采样/混合权重 π_m 供歧义检测。

**新增定义 545（位姿歧义集 PoseAmbiguitySet）** 给定目标对称群 G（有限）与后验样本，对模式 {μ·g: g∈G} 聚类；若至少两个模式的权重 π_m>p_amb（默认 0.10），置 ξ_amb=1，输出 M_pose={(μ_m,π_m,Σ_m)}。歧义也可由 Fisher 浓度各向异性与多起点拟合残差近似判别。

**新增定义 546（几何敏感度与传播上界 GeometricSensitivity）** 对 C² 泛函 h：J_h=∂h/∂ξ|_μ（6 维）；σ_h=√(J_hΣ_ξJ_hᵀ)；在信任域 ‖ξ‖≤ρ_pose 内 ε_lin=½·sup_{‖ξ‖≤ρ_pose}|ξᵀH_h(ξ)ξ|。一阶传播界：h(μ·exp ξ) ∈ [h(μ)+J_hξ−ε_lin, h(μ)+J_hξ+ε_lin]。

**新增定义 547（位姿证书 PoseCertificate）**
```
单峰： h_cert = h(μ) − κ·σ_h − ε_lin
多峰： h_cert = min_m [ h(μ_m) − κ_m·σ_{h,m} − ε_{lin,m} ]
```
覆盖率：单峰 ≈ Φ(κ)；多峰 ≥ 1−Σ_m α_m − α_amb。h_cert 直接作为 SpatialCert 的间隙下界；抓取裕度同理以抓取打分的几何泛函代入。

**新增定义 548（位姿信任域与回退 PoseTrustRegion）**
```
U_pose = { ξ_amb=0 ∧ σ_h≤σ_max ∧ ε_lin≤ε_max ∧ 残差检验通过 }
```
U_pose 不成立 ⇒ Level-1：点估计 + 固定 β_pose；位姿头失效 ⇒ Level-2：中立元位姿 μ^⊥=上一可信帧（按 ‖v‖Δt 外推）+ 最大膨胀 Σ_max，SpatialCert 回退 v9 深度间隙。β_pose 由 E575/F576 标定为 κ·σ_h 的经验上包络。

## 3. 关键算法骨架

```python
# IP-358 SafetyConeFirewall：安全锥梯度手术（训练 + 在线微适配时生效）
class SafetyConeFirewall:
    def __init__(self, safety_tasks, w_safety=None, lam_nt=1.0,
                 delta_NT=0.05, H_NT=3, eps=1e-8):
        self.S = set(safety_tasks)
        self.w = w_safety or {t: 1.0 for t in self.S}
        self.lam_nt, self.delta_NT, self.H_NT = lam_nt, delta_NT, H_NT
        self.eps = eps
        self.ledger = InterferenceLedger(lam_nt, delta_NT, H_NT)

    def safety_gradient(self, grads):
        g_S = sum(self.w[t] * grads[t] for t in self.S)
        return g_S

    def project(self, grads):
        g_S = self.safety_gradient(grads)
        nS = norm(g_S)
        if nS < self.eps:
            return grads, g_S                 # 退化：不投影（等价无共享）
        g_hat = g_S / nS
        out = {}
        for t, g in grads.items():
            if t in self.S:
                out[t] = g                    # 安全梯度永不投影
            else:
                c = dot(g, g_hat)
                out[t] = g - min(0.0, c) * g_hat   # 只消去冲突分量
        return out, g_S

    def step(self, grads, theta_s, lr, val_losses):
        proj, g_S = self.project(grads)
        d = g_S + sum(proj[t] for t in proj if t not in self.S)
        theta_s -= lr * d
        for t in self.ledger.tasks:
            self.ledger.update(t, val_losses[t], cos(grads[t], g_S))
            if t not in self.S and self.ledger.over(t):
                demote_head(t)               # 定义 543：接独立适配器
        return theta_s


# IP-359 PoseUncertaintyCertificate：位姿不确定证书
class PoseUncertaintyCertificate:
    def __init__(self, pose_head, kappa=3.0, rho_pose=0.05,
                 sigma_max=0.05, eps_max=0.01, p_amb=0.10):
        self.head = pose_head
        self.kappa, self.rho_pose = kappa, rho_pose
        self.sigma_max, self.eps_max, self.p_amb = sigma_max, eps_max, p_amb

    def estimate(self, feats):
        mu, Sigma, A_fisher, modes = self.head(feats)
        amb = detect_ambiguity(modes, self.p_amb)
        return PoseDist(mu, Sigma, A_fisher, modes, amb)

    def certify(self, h, Jfun, Hessfun, pd):
        if pd.amb:                                    # 定义 545/547
            cand = []
            for mu_m, pi_m, Sig_m in pd.modes_weights():
                h_m = h(mu_m)
                J = Jfun(mu_m)
                s = sqrt(J @ Sig_m @ J)
                e = 0.5 * rho_pose**2 * spectral_norm(Hessfun(mu_m))
                cand.append(h_m - self.kappa * s - e)
            return min(cand)                          # 并集界下界
        h0 = h(pd.mu)
        J = Jfun(pd.mu)
        s = sqrt(J @ pd.Sigma @ J)
        e = 0.5 * self.rho_pose**2 * spectral_norm(Hessfun(pd.mu))
        return h0 - self.kappa * s - e

    def trust_ok(self, pd, sigma_h, eps):
        return (not pd.amb) and sigma_h <= self.sigma_max and eps <= self.eps_max
```

## 4. 推导

**引理 87（安全锥一阶下降保证）** 设 d=g_S+Σ_{j∉S}proj(g_j;g_S)。对 j∉S：若 g_j·g_S≥0，则 proj(g_j)=g_j 且 ⟨proj(g_j),g_S⟩≥0；若 g_j·g_S<0，则 proj(g_j)⊥g_S，贡献为 0。故 ⟨d,g_S⟩=‖g_S‖²+Σ_{j∉S}⟨proj(g_j),g_S⟩≥‖g_S‖²。对充分小步长 η（η≤1/L，L 为 L_S 的 Lipschitz 光滑常数）有
L_S(θ_s−ηd) ≤ L_S(θ_s) − η‖g_S‖² + (η²L/2)‖d‖² < L_S(θ_s)。
即安全任务损失沿更新方向严格一阶下降，非安全任务的冲突梯度不能反转该方向。∎
> 注：该保证是**一阶、局部**的；全局不退化仍需 IL 监控（引理 90）兜底。

**引理 88（一阶传播保守性）** 在 U_pose 内设 h∈C²、‖∇²h‖≤H_max，则对 pose=μ·exp(ξ)，|h(pose)−h(μ)−J_hξ|≤½H_max‖ξ‖²≤ε_lin。若 ξ~N(0,Σ_ξ)，则 J_hξ~N(0,σ_h²)，P(J_hξ≥−κσ_h)=Φ(κ)。故 P(h(pose)≥h(μ)−κσ_h−ε_lin)=Φ(κ)≥1−α，即 h_cert 为 h 的单侧保守下界（κ=3 ⇒ ≈99.87%）。∎

**引理 89（歧义并集界）** 若真实模式 m*∈M_pose 的概率 ≥1−α_amb，且对每个 m，h_cert,m 在模式 m 局部分布下为有效下界（失效概率 ≤α_m），则 P(min_m h_cert,m ≤ h(pose)) ≥ 1−Σ_m α_m − α_amb。证明：min_m h_cert,m ≤ h_cert,m*；当 m* 被包含且 h_cert,m* 有效时结论成立，两事件并集界给出概率下界。∎

**引理 90（降级等价与安全收缩）** 任务 j 降级后接独立适配器 φ_j、头权重不变，其输出分布与"v9 独立头 + 同权重"逐位一致；且 j 不再有到 θ_s 的梯度通路，故安全任务与剩余共享任务的更新仅依赖 S 与剩余共享集，不受 j 干扰。降级只是从共享图**保守收缩**，不会增加任何跨任务耦合，也不降低安全任务的可达行为集（安全头未降级）。∎

**引理 91（共享前向的摊销时延与预算返还）** 独立头感知代价 C_indep=Σ_i(C_enc,i+C_head,i)；共享代价 C_shared=C_s+Σ_i C_head,i。节省 Δ=Σ_i C_enc,i−C_s。当 C_s≈max_i C_enc,i 且 N=|T|≥2 时 Δ≈Σ_{i≠argmax}C_enc,i>0。该 Δ 返还 v9 的块生成余量（E582），且因共享前向是定长单次调用，方差低于多头独立，抖动不增。∎

**引理 92（组合退化）** TIF 关闭 ⇒ 投影退化为恒等映射（不消去任何分量），各头独立编码 ⇒ 等价 v9 独立前向；PUC 关闭 ⇒ β_pose 取固定标定值、点估计入证书 ⇒ 等价 v9 证书；IL 关闭 ⇒ 不做降级、冻结共享拓扑 ⇒ 等价 v9。三者与 v9 的 AC/MW/ID 失效按中立元律（P11）逐级合成，落在 v9 退化格点内，故整体行为 ∈ v9 退化格点，安全性由 v9 引理 82–86 传递成立。∎

**引理 93（位姿项的可解释分解）** 对任意 h，v9 的块证书余量 β 在本轮被显式分解为 β=β_pose+β_model，其中 β_pose≥κσ_h+ε_lin 由位姿分布与几何雅可比给出，β_model 为前向模型误差项。故当位姿分布退化（Σ_ξ→0）时 β_pose→0，证书连续收敛到 v9 点估计形式，无跳变（E564 的位姿版）。∎

## 8. 本轮最大风险

**一句话**：PUC 的保守性依赖切空间高斯（或单峰）近似与实际位姿误差尾部的匹配，而对称物体恰恰是位姿多峰、重尾、且抓取最敏感之处——若多峰标记漏检，证书会以"小方差"给出一个自信却错误的界，即「位姿最不确定的对象拿到了最漂亮的证书」。
