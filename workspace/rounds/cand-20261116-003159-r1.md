# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「VLA」×「Isaac Sim」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**语义接地 + 仿真锻造**。两个灵感分别治理 v9 的两笔债：**语义债**（系统只会执行符号化子目标，无法理解开放词汇指令，也无法解释"为什么这样做"）与**证书债**（v9 的 β 与信任域假设缺外部真值，AC 前向模型误差只能在线自证，恰在域偏移最危险的时刻最不可证）。必须通过**仿真-语义双重降级格**保证任一新增层失效时退回 v9，而非行为漂移。

## 0. 直觉与动机

**灵感 1（VLA → 语义提案，而非语义执行）**
直觉：VLA（Vision-Language-Action）把"看、听、做"端到端压进一个大模型，天然带来开放词汇理解与自然语言接地。但它推理慢、不可解释、会幻觉，直接塞进 50Hz 安全回路是灾难。关键洞察不是"用不用 VLA"，而是"VLA 坐在回路哪个位置"——**VLA 不握方向盘，只写意图草稿**。严谨化：**VLA 语义提案器（VSP）**把指令 ℓ 映射为「子目标序列 G_ℓ + 可供性候选 A_aff + 语义证书 σ_sem」；提案必须经 PrimitiveGraph 编译、语义-空间一致性门控（SSCG）与 v9 证书链，才可能成为动作。VLA 只扩大**可表达的任务空间**，不改变**安全谓词**。

**灵感 2（Isaac Sim → 证书锻造厂）**
直觉：v9 最软的假设是"信任域内前向模型误差 ≤ β"，而这个 β 没有外部真值，只能靠在线经验，最危险的域偏移时刻恰恰最不可证。Isaac Sim 能提供 GPU 并行真值 rollout、域随机化（DR）课程与数字孪生。严谨化：**仿真证书锻造厂（SGCF）**离线锻造三件套 (β̂, 可供性图谱 A_atlas, DR 课程 C_DR)，运行期由**仿真-现实漂移审计（STAL）**把真机残差回灌、周期性重标定 β。证书从"在线自证"升级为"离线锻造 + 在线审计"，且用 conformal 把 sim-real gap 界成 δ_gap，令 β_eff = β̂ + δ_gap。

**灵感 3（耦合：语义-空间对账）**
直觉：VLA 说"杯子可抓"，几何证书说"杯子在 0.8m 外、夹爪朝向差 40°"——两个世界的判断必须对账。严谨化：**语义-空间一致性门控（SSCG）**把每条可供性声明投影到几何/动力学判据；一致才放行，分歧则**只信几何**（退回 v9），并把分歧样本回灌 SGCF 作为 DR 课程种子。这把"幻觉"从安全威胁降级为"数据来源"。

## 1. 研究问题（轮次升级版）

- **Q1（语义安全隔离）**：VLA 提案在什么接口约束下可证明永不进入安全关键路径？"提案—编译—对账—证书"四段式是否足以让开放词汇能力与 v9 安全论证正交？
- **Q2（仿真锻造可靠性）**：Isaac Sim 锻造的 β̂ 在何种 sim-real gap 界与 DR 覆盖假设下可作为真机误差上界？conformal 覆盖能否把"仿真乐观"转成可审计的保守量 δ_gap？
- **Q3（语义-空间对账）**：SSCG 能否在保持开放词汇能力的同时，把幻觉的代价压到与"无 VLA"基线统计等价（只浪费算力、不违背安全）？分歧样本回灌能否形成证书自愈闭环？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 语义提案隔离律（VLA-Semantic-Proposal Isolation, VSP）**
VLA 输出只能是「子目标序列 + 可供性候选 + 语义证书」，禁止直接输出电机指令。任一子目标必须编译到 PrimitiveGraph 的原语；任一可供性必须通过 SSCG=agree 与 v9 证书链。语义层只扩大候选分布，不触碰安全谓词。

**P14 仿真锻造证书律（Sim-Grounded Certificate, SGCF）**
块证书余量取 β_eff = β̂ + δ_gap：β̂ 为 Isaac Sim 内前向模型一致误差的 (1−α) 分位，δ_gap 为 STAL 用真机残差得到的 conformal sim-real 差距上界。SGCF 不可用时退化为缓存图谱 + β 保守膨胀（β_eff ← β_eff·(1+δ_gap^max)），严格覆盖 v9 的在线标定语义。

**P15 语义-空间对账律（Semantic-Spatial Reconciliation, SSCG）**
对每条可供性声明 a，用 SpatialCert 的几何可行性、可达性与动力学判据（抓取力旋量、碰撞间隙）计算 SSC(a,s)∈{agree, conflict}。只有 agree 进入候选集；conflict 一律丢弃并回灌 DR 课程。SSCG 自身失效 ⇒ 语义声明全部不可用，仅几何，等价 v9。

## 3. 与基线的接口（如何退化）

- SSCG 分歧/失效 ⇒ 语义层降级为几何-only，等价 v9 决策；
- VSP 失效/超时 ⇒ 退回 v9 符号指令解析器（语言→预定义原语），等价 v9 任务接口；
- STAL 失效 ⇒ β 冻结、停止重标定，沿用最后有效 β，等价 v9 在线标定；
- SGCF 失效 ⇒ 缓存 A_atlas + β 保守膨胀，等价 v9 保守前向模型；
- v9 的 AC/MW/ID 失效 ⇒ 按引理 83–86 逐级退回 v8/v7；
- 全部失效 ⇒ 完整退回 v9 ACMD → v8 → v7 → v6。

## 4. 预期贡献

1. **语义提案器（VSP）**：开放词汇指令到符号子目标的受约束接地，附可校准的语义证书与新颖度门控；
2. **仿真证书锻造厂（SGCF）+ 漂移审计（STAL）**：把 v9 的 β 从在线自证升级为"离线锻造 + conformal 覆盖 + 真机回灌"的可审计证书；
3. **语义-空间一致性门控（SSCG）**：幻觉的代价从安全威胁降为算力浪费，分歧样本反哺 DR 课程形成自愈闭环；
4. **仿真-语义双重降级格**：证明任意语义/仿真降级状态均落在 v9 退化格内；E571–E590 覆盖语义精度、对账门控、sim-real 标定、开放词汇、异步时延与端到端任务。

## 5. 本轮最大风险

**一句话**：仿真证书锻造以「DR 覆盖部署分布 ∧ sim-real gap 可被 conformal 界住」为前提，而接触丰富/可变形物体恰恰是 Isaac Sim 最不保真、也是真机最需要认证的区域——SGCF 可能恰在最需要证书的地方给出最乐观的 β_eff，形成「仿真认证的虚假安全感」。

**新增定义 540（语言子目标映射 LanguageSubgoalMap）** VSP 输出 (G_ℓ, A_aff, σ_sem) = VSP(ℓ, o_t)。每个 g_i 必须可编译到 PrimitiveGraph 的原语 p ∈ P；不可编译的子目标整条拒绝（fail-closed）。G_ℓ 是**符号计划**，不含电机指令。

**新增定义 541（语义证书 SemanticCertificate）** σ_sem = (π_task, A_aff, c_sem, ν_sem)。c_sem 由 held-out 校准集 temperature scaling 得到；ν_sem = 1 − max_{a′∈A_atlas} cos(emb(a), emb(a′))。语义证书有效 ⇔ c_sem ≥ τ_sem ∧ ν_sem < τ_nov；否则进入人工确认或限制为已知原语（定义 547）。

**新增定义 542（语义-空间一致性 SemanticSpatialConsistency）** 对可供性 a 与状态 s：
```
SSC(a,s) = agree  ⇔  Reachable(a,s) ∧ GraspWrenchFeasible(a,s)
                     ∧ F̂_clearance(s, a.precondition) ≥ d_safe
                     ∧ a.object_ref ∈ SpatialCert(s)
         = conflict  否则
```
仅 agree 的可供性进入候选集；conflict 样本 (s,a) 写入 DR 种子池。

**新增定义 543（仿真锻造三元组 SimForgeTriple）** 离线在 Isaac Sim 上执行
```
F_triple = (β̂, A_atlas, C_DR) = Forge(IsaacSim, C_DR, π_sim)
β̂ = Quantile_{1−α}( |F̂(x) − F_sim(x)| : x ∈ U_t^sim )
A_atlas = 成功轨迹的可供性嵌入质心
C_DR = 有序分布漂移课程（光照/材质/摩擦/质量/形变）
```

**新增定义 544（sim-real 差距界 SimRealGapBound）** STAL 在真机标定集上采集残差 r_i = |metric_real,i − metric_sim,i|，用 split-conformal 得
```
δ_gap = Quantile_{1−α}(r_1,…,r_n) + slack,   β_eff = β̂ + δ_gap
```
保证以 ≥1−α 概率覆盖真机误差（引理 88）。

**新增定义 545（语义降级格 SemanticDegradationLattice）** 状态 s_sem = (sem, ssc, forge) ∈ {on,off}²×{live,cached}，其安全权限恒 ≤ v9 几何层：语义层是**候选扩增器**，永不新增执行权限。偏序按能力排序，最小元 = v9 几何-only。

**新增定义 546（VLA 异步窗口 VLAAsyncWindow）** VSP 以 1–2Hz 在独立线程运行，提案有效期 T_vla=500ms；超期提案丢弃，回退到最近有效提案或符号解析器。VLA 时延不进入 50Hz 关键路径（引理 92）。

**新增定义 547（开放词汇新颖度门控 NoveltyGate）** ν_sem ≥ τ_nov ⇒ 不自动执行，二选一：请求人工确认，或仅保留几何可验证的已知原语。防"幻觉可供性"直接触发执行（引理 91）。

**新增定义 548（锻造覆盖率 ForgeCoverage）** γ_cov = P_{x∼D_deploy}[dist(x, supp(C_DR)) ≤ ε]。β̂ 的可迁移性以 γ_cov ≥ 1−α 为前提（引理 88 的条件 ii），由 DA-ML 的 Δ_dom 与嵌入距离联合估计。

```python
# IP-357 SGCF：仿真证书锻造厂（离线，Isaac Sim）
class SimGroundedCertificateForge:
    def __init__(self, sim, forward_model, alpha=0.01):
        self.sim, self.F, self.alpha = sim, forward_model, alpha

    def forge(self, dr_curriculum):
        # 1) 并行真值 rollout：GPU 批量采样信任域 U_t^sim
        xs, f_sim = self.sim.rollout_batch(dr_curriculum, n=100_000)
        # 2) 前向模型一致误差的 (1−α) 分位
        err = (self.F.predict(xs) - f_sim).abs()
        beta_hat = quantile(err, 1 - self.alpha)
        # 3) 可供性图谱：成功轨迹的嵌入质心
        atlas = build_affordance_atlas(self.sim.success_trajectories())
        return ForgeTriple(beta_hat, atlas, dr_curriculum)

    def conservative_fallback(self, cached):
        return ForgeTriple(cached.beta_hat * (1 + cached.delta_gap_max),
                           cached.atlas, cached.dr)


# IP-360 STAL：仿真-现实漂移审计（周期，conformal）
class SimulationTruthAuditLoop:
    def __init__(self, alpha=0.01):
        self.residuals, self.alpha = [], alpha

    def audit(self, real_batch, sim_batch):
        r = [(m_real - m_sim).abs()
             for m_real, m_sim in zip(real_batch, sim_batch)]
        self.residuals = (self.residuals + r)[-N_AUDIT:]
        delta_gap = quantile(self.residuals, 1 - self.alpha) + SLACK
        return delta_gap                      # β_eff = β̂ + δ_gap（定义 544）


# IP-358 VSP：VLA 语义提案器（异步，永不进安全路径）
class VLASemanticProposer:
    def __init__(self, vla, primitive_graph, atlas, tau_sem=0.7, tau_nov=0.35):
        self.vla, self.PG, self.atlas = vla, primitive_graph, atlas
        self.tau_sem, self.tau_nov = tau_sem, tau_nov

    def propose(self, instruction, obs):
        out = self.vla(instruction, obs)                  # 端到端大模型
        subgoals = out.subgoals
        # fail-closed：任一子目标无法编译到 PrimitiveGraph 则整条拒绝
        if not all(self.PG.compilable(g) for g in subgoals):
            return None
        aff = out.affordances
        c_sem = calibrate(out.logits)
        nu_sem = 1 - max(cos(emb(a), emb(a2))
                         for a in aff for a2 in self.atlas)
        if c_sem < self.tau_sem or nu_sem >= self.tau_nov:
            return SemanticProposal(subgoals, [], Cert(c_sem, nu_sem),
                                    need_confirm=True)     # 定义 547
        return SemanticProposal(subgoals, aff, Cert(c_sem, nu_sem))


# IP-359 SSCG：语义-空间一致性门控（50Hz 内联，廉价）
def semantic_spatial_gate(affordances, state, spatial_cert, F_hat):
    kept, conflicts = [], []
    for a in affordances:
        ok = (reachable(a, state) and grasp_wrench_feasible(a, state)
              and F_hat.clearance(state, a.precondition) >= D_SAFE
              and a.object_ref in spatial_cert)
        (kept if ok else conflicts).append(a)
    return kept, conflicts        # conflicts → DR 种子池（定义 542）


# 主闭环集成：MetricVoiceGauge-SVSC（在 v9 主环外挂语义/仿真两层）
def metricvoicegauge_round_10(M, s, obs, instruction=None, ...):
    # ---- 语义层：异步提案 + 内联对账（不进 50Hz 安全路径）----
    proposal = vsp_latest                      # 1–2Hz 线程写入；T_vla 过期则 None
    if proposal is None and instruction is not None:
        proposal = symbolic_parser(instruction)  # v9 回退路径
    if proposal is not None and not proposal.need_confirm:
        kept, conflicts = semantic_spatial_gate(
            proposal.affordances, s, M.spatial_cert, M.forward_model)
        dr_seed_pool.extend(conflicts)         # 分歧回灌 DR 课程
        M.primitive_graph.restrict_to(kept)    # 只扩大候选，不新增权限
    # ---- 以下严格走 v9 ACMD 主环（块证书、MW、ID）----
    return metricvoicegauge_round_9(M, s, obs)  # 语义层关闭时逐位等价 v9
```

## 4. 推导

**引理 87（语义提案隔离）** VSP 的输出空间是 (G_ℓ, A_aff, σ_sem)，不含电机指令；执行动作 a_t 只能来自 PrimitiveGraph 编译、SSCG=agree 与 v9 证书链。故 a_t 的安全性由 v9 引理 82/84 建立，VSP 仅改变候选分布，不改变安全谓词。∎

**引理 88（仿真锻造 β 的可靠性）** 若 (i) 前向模型在 sim 内一致误差 ≤ β̂ 以 1−α 成立（SGCF 分位），(ii) sim-real 指标差 ≤ δ_gap 以 1−α 成立（STAL conformal），(iii) DR 覆盖 γ_cov ≥ 1−α（定义 548），则真机误差以 ≥1−3α 满足
```
|F̂ − F_real| ≤ |F̂ − F_sim| + |F_sim − F_real| ≤ β̂ + δ_gap = β_eff.
```
证明：三角不等式逐点成立；三个高概率事件取并集界。∎

**引理 89（SSCG 保守性）** conflict 时 SSCG 从候选集删除 a；删除候选不可能引入新动作，所得策略是几何-only v9 策略的**限制**。故安全继承 v9，性能相对 v9 单调不增，损失上界为被删真阳性可供性的召回损失。∎

**引理 90（语义降级格点包含）** 对定义 545 任一状态：sem=off ⇒ 等价 Level-2；ssc=off ⇒ 等价 Level-1；forge=cached ⇒ 等价 Level-4；其余组合由表逐行映射到 v9 退化级。语义层只增候选、不减安全权限，故任意状态行为 ∈ v9 退化格。∎

**引理 91（幻觉抑制）** 对无几何支撑的幻觉可供性 a，SSC(a,s)=conflict 以 ≥1−ε_ssc 成立；即便漏检，v9 证书链仍校验间隙/力/块证书，违规即触发 M₀ 硬检查或安全停驻。故幻觉只能浪费提案算力，不能违背安全；期望浪费 ≤ (1−ε_ssc)·N_aff·C_ssc。∎

**引理 92（异步 VLA 与 50Hz 守恒）** VSP 在独立线程以 1–2Hz 运行，超 T_vla 提案丢弃并回退符号解析器；SSCG 内联 ≤0.1ms，计入 v9 感知预算；主环其余不变。故每周期 ≤ v9 的 22ms 上界，50Hz 保持（引理 86 传递）。∎

**引理 93（漂移审计闭环）** STAL 每 T_audit 用真机残差重估 δ_gap；若 sim-real 漂移增大，则 δ_gap 单调增、β_eff 单调增、块证书更保守，经 v9 定义 539 使 K_eff 收缩。故系统在漂移下以"更短块长 + 更大余量"换取证书可靠性，形成安全-性能可控折衷。∎

## 8. 本轮最大风险

**一句话**：仿真证书锻造以「DR 覆盖部署分布 ∧ sim-real gap 可被 conformal 界住」为前提，而接触丰富/可变形物体恰恰是 Isaac Sim 最不保真、也是真机最需要认证的区域——SGCF 可能恰在最需要证书的地方给出最乐观的 β_eff，形成「仿真认证的虚假安全感」。
