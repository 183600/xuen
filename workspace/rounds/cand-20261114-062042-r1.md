# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS 具身计量审计」IP-287~294；灵感循环第 1 轮（新循环起点）；本轮灵感：「仿真到现实迁移」×「伦理审查」）

> R72 完成了「认知 → 具身」的下沉：REG 实时执行图把「计量不阻塞控制」变成调度定理，IRL 把意图 z 显式纳入联合后验，DMEM 把灵巧手触觉升级为接触模式条件证据，EREFLEX/ERVOI 统一三层反作用预算，S2R-UQ 把 sim2real 参数残差传播到 WCET 与 λ_floor。但 R72 在收尾时留下两个**未被证成的默认前提**：
>
> - **默认前提 A（证书可迁移）**：S2R-UQ 只桥接了**参数** θ_real = φ(θ_sim) + Δ，随之却把在仿真中签发的 J_EMB 当成在实机上依然有效。**参数桥接是必要条件，不是充分条件**：感知分布、人的行为、接触物理、任务语境、乃至**审计集与校准集本身**都发生了位移。R72 把「仿真风险界 + 参数残差」静默等同于「实机风险界」，但**迁移没有免费的午餐**——证书必须为迁移支付显式的、可审计的代价。
> - **默认前提 B（安全即伦理）**：R72 的物理风险界（λ、λ_floor、J_EMB）回答的是「会不会撞伤/捏碎」，而不是「该不该做」。没有同意（consent）、自主（autonomy）、尊严、可申诉（contestability）、透明、分配公平、数据治理与问责。更致命的是，R72 的全部机制（风险缩放、VoI、反作用预算）都是**可补偿的标量**：一旦把「伦理」写成一个权重项，就一定存在一个效率增益足以「买走」一次道德违规。**伦理不是更贵的安全，伦理是非补偿性约束。**
>
> 本轮两个灵感正好补这两块，而且它们在同一处交汇：
> - **仿真到现实迁移**：把 sim2real 从「参数不确定度桥接」升级为**有效性迁移（Transfer of Validity, ToV）**——证书携带源域/目标域、度量相关的差距 δ_gap、覆盖保证 1−α、迁移余量、来源链与生效条件；**只有在 δ_gap 与覆盖都过关时，仿真证书才对实机生效**。域随机化不是覆盖保证；有限随机场景无法覆盖真实长尾。
> - **伦理审查**：把伦理审查从「上线前一张 IRB 批文」升级为**四时钟治理闭环**——机构时钟（审查/批文/失效）、运营时钟（同意状态/新颖性/撤销）、控制时钟（O(1) 伦理否决）、取证时钟（只增审计链）。伦理审查是一台**有有效性域、会过期、可被撤销、可被 Goodhart 攻击的测量仪器**，不是一次性盖章。
>
> 核心命题：**「在仿真中被证明安全，不等于在现实中安全——除非它为迁移支付了显式代价；在现实中安全，也不等于伦理——除非它落在被审查、被同意、可申诉、可撤销的可行域内。」** 二者合并为 **ETHOS-GAUGE-RAS**（Ethically-governed, Transfer-valid, Human-auditable, Operational, Sim2real-bounded GAUGE for RAS）——**伦理治理 × 迁移有效的具身计量审计闭环**。

## 0. 直觉与动机

**灵感 1（sim2real 迁移 → 证书不是可移植的，迁移是要付代价的）**
直觉：仿真里的「通过」是带引号的。你在仿真里把碰撞率压到 1e-5，把意图 ECE 压到 0.03，把接触四分量标定到 5ms——然后换到实机，传感器换了、人的口音变了、桌面摩擦系数变了、灵巧手磨损了。R72 只修正了「参数均值 ± 残差」，却没有修正「这个风险界本身在目标域还成不成立」。正确的姿态不是「让仿真更像现实」（永远不够），而是**给证书加一条迁移条款**：
> 实机风险 ≤ 仿真风险 + L·δ_gap + 尾部项，
其中 δ_gap 是**与所审风险泛函相关的**源/目标差异（不是全分布匹配），尾部项来自有限校准集。**只要这个上界仍然小于预算，证书才在实机上成立；否则不许自主部署。** 迁移不是「调得更准」，是「在证书里明码标价」。
更强的反直觉点：**域随机化（DR）不是覆盖保证**。DR 只是在*提议分布* p_DR 上采样；真实部署分布 p_real 的支撑可能落在 p_DR 几乎为零的地方（罕见体型、罕见方言、罕见接触几何、对抗性场景）。有限个随机世界覆盖不了真实长尾。必须用**重要性加权/加权保形预测**给出分布无关的覆盖界，并在权重有效样本量（ESS）崩塌或支撑失配时**拒绝宣称迁移有效**。

**灵感 2（伦理审查 → 伦理是可撤销的运行时状态，不是一次性的表单）**
直觉：IRB 批文像一张「驾驶证」——它规定了**准驾车型（scope）、有效期（expiry）、吊销条件（revocation）**，而不是「你永远可以开任何车」。R72 的 J_EMB 只进不出、只签不撤，是一张没有吊销机制的证书。真实伦理治理必须是：
- **有作用域**：这份批文只覆盖「协作装配 / 成年健全被试 / 室内 / 无隐私采集」这一族情景；
- **有有效期**：法规变了、模型更新了、人换了，批文失效；
- **可撤销**：被试中途说「停」，同意立即失效；机器人必须从**控制周期级**停止并停止采集；
- **可申诉**：人必须有一条能质疑、能要求解释、能叫停的通道；
- **非补偿**：任何效率、信息增益、任务成功率都不能补偿一次未同意/欺骗/越界采集。
所以伦理不能塞进 λ，它必须是**可行域约束**：先取 F_eth，再在 F_eth 内优化风险与效用。**先可行，后最优。**

**灵感 3（交汇点 → sim2real 是伦理最容易被静默击穿的地方）**
直觉：仿真里的「人」是合成的，**合成人不能同意**；域随机化会批量生成**从未被伦理审查过的情景**（比如把「老人摔倒」当成随机扰动的一种）；真实世界的长尾，本质上就是**伦理新颖性（ethical novelty）**。于是出现一种最难审计的失败：策略在仿真里通过了所有安全与伦理检查，到实机上却落在一个「数据上有覆盖、但从未被规范审查」的人群/情景上——**统计覆盖率很高，道德覆盖率是零**。因此「代表性/道德覆盖」必须与「数据覆盖」并列成为部署门控：某个子群若没有被数据覆盖**且**没有被规范审查覆盖，就不许在该子群上自主运行。

**灵感 4（四时钟 → 伦理横跨所有时间尺度，但否决只能收缩动作集）**
直觉：伦理审查（机构时钟，天/周）不可能跑在控制环（毫秒）里；但「停止」必须能在控制环里发生。解法是把伦理拆成四个时钟并只允许**单向、收缩性**的跨时钟信号：
- **机构时钟 τ_inst**：审查、批文、法规、失效（离线，天–周）；
- **运营时钟 τ_oper**：同意状态、语境分类、伦理新颖性、证书状态机（秒–分）；
- **控制时钟 τ_ctrl**：伦理可行性过滤 + 安全停止（微秒–毫秒）；
- **取证时钟 τ_audit**：只增审计链、事后重建（离线）。
关键：控制域平时仍只读快照（延续 R72 的时序隔离），但**撤销/停止走一条独立的、最高优先级、单向的中断路径**（类似急停）。它打破「只读快照」的纯粹性，但**只收缩动作集、从不增加工作**，所以不破坏硬实时（这是本轮唯一的调度例外，且可被证明安全）。

**灵感 5（伦理审查的 Goodhart → 优化「通过审查」不等于「伦理」）**
直觉：一旦系统知道审查指标，它就会优化「过审」而不是「做对」。更糟的是，审查者与被审查者若同源，就存在「共谋审计」；审查集若固定且已知，就会被记忆/过拟合；而**真实受害者往往不在审查数据里**（代表性盲区）。所以伦理审查必须：审查独立、测试集密封且随机抽样、保留**受害者可发起的申诉通道**（这是唯一不依赖审查者自觉的信号）、上线后持续监测（post-market surveillance）。**伦理保证的强度，取决于最弱的那个未被收买的信号。**

## 1. 形式化定义（增量：定义 366–381）

**定义 366（ETHOS-GAUGE-RAS 总览）** ETHOS-GAUGE-RAS = (ToV, COV, ERG, REV, ENT, RCERT, EMBODIED†)。六不变式：
(i) **迁移显式定价**：任何在源域 S_sim 签发的证书，必须携带 (S_sim, S_real, g, δ_gap, n_cal, 1−α, ε_tail, margin, prov, cond)；只有迁移上界 ≤ 预算时对实机有效；
(ii) **伦理非补偿性**：伦理约束分为道义 D、程序 P、福利 W；D 与 P 构成可行域 F_eth，**任何风险/效率/信息增益/任务收益都不能补偿 F_eth 之外的违规**；W 可进入标量目标；
(iii) **审查可追溯**：每条伦理约束可追溯到 (review_id, reviewer, scope, expiry, clause_version)，并进入只增审计链；
(iv) **可撤销性**：同意与证书可在运营时钟撤销，撤销须在 τ_revoke 内传播到控制时钟，并在 τ_erase 内停止采集、擦除缓冲；
(v) **新颖性即不上车**：实机情景若超出已审查作用域（伦理新颖性），不得自主决策，必须升级人类复核；
(vi) **严格退化包含**：ToV 失败 ⇒ 禁止实机自主（仅仿真或遥操作）；ERG 失败 ⇒ 遥操作；REV 不可执行 ⇒ 机械急停；ENT 触发 ⇒ 升级复核；全通过 ⇒ ETHOS 完整形态。**安全与伦理违规只减不增。**

**定义 367（四时钟规范架构）** 四个时间域及其接口：
- τ_inst（机构，天–周）：ERG 审查、EAC 签发、法规更新、证书吊销裁决；
- τ_oper（运营，秒–分）：同意状态机、语境分类、ENT 新颖性、RCERT 状态迁移；
- τ_ctrl（控制，μs–ms）：REV 可行性过滤、安全停止、E-RISK†；
- τ_audit（取证，离线）：审计链验证、事故重建、覆盖率重估。
接口：τ_inst → τ_oper 通过**签名 EAC/作用域**（缓存）；τ_oper → τ_ctrl 通过**只读撤销位图 + 新颖性位 + 同意位图**（常规），以及一条**独立的最高优先级撤销中断**（例外路径）；所有跨时钟写入记为只增哈希链。**跨时钟只允许「收缩动作集」方向的信号；任何「扩大动作集」的写入必须在 τ_inst 完成。**

**定义 368（ToV 可迁移证书）** 源域证书 J^ToV = (J_EMB, S_sim, S_real, g, δ_gap, n_cal, α, ε_tail, margin, prov, cond, sig)，其中 g 为被证明的风险泛函（如 P(碰撞)、期望伤害、未同意采集率）。实机有效性：
Valid_real(J^ToV) ⇔ Valid(J_EMB) ∧ δ_gap ≤ δ_max(g, budget) ∧ coverage ≥ 1−α ∧ ¬novel ∧ cert.state = active ∧ consent valid。
**迁移余量** margin = ε_budget − (R_sim + L·δ_gap + ε_tail)；margin ≥ 0 才签发实机生效证书。

**定义 369（度量相关差距 δ_gap）** 不要求全分布匹配，只要求**沿被审泛函**的差异有界。令 ℋ_g 为 g 对应的损失函数类，则
δ_gap = sup_{h∈ℋ_g} |E_{S_sim}[h] − E_{S_real}[h]|（discrepancy distance 的有限样本估计，带置信上界）。
**关键约束**：ℋ_g 必须证明**完备**——不存在未被 ℋ_g 覆盖、却实质影响 g 的维度（否则差距被低估）。审计时必须显式列出「哪些维度被排除、为什么可排除」。

**定义 370（域随机化下的覆盖保证 COV）** 域随机化给出提议分布 p_DR；真实分布 p_real 未知。用加权保形预测：权重 w(x) = p_real(x)/p_DR(x)，在加权可交换性下给出
P(R_real ≤ R̂ + q_{1−α}) ≥ 1−α，
其中 q 为加权非一致性分位数。**可靠性前置条件**：有效样本量 ESS = (Σw)²/Σw² ≥ τ_ESS；且 p_real 不得在 p_DR 近零支撑处有实质质量（支撑失配检测）。任一不满足 ⇒ **COV 不成立，禁止宣称迁移有效**。**域随机化本身不构成覆盖保证。**

**定义 371（伦理审查闸门 ERG 与 EAC）** ERG = (R, C, Scope, Expiry, InterRater, Seal)。审查产出**伦理批准证书 EAC** = (review_ids, constraint_set, scope_distribution, expiry, reviewers, κ_interrater, seal_hash, signature)。情景 x 被「审查覆盖」当且仅当 x ∈ Scope。ERG 运行在 τ_inst，是离线、独立的机构闸门；**审查者不得与被审查优化目标同源**（审计独立性，见定理 32）。

**定义 372（伦理约束三族与可行域 F_eth）** 将伦理约束分为：
- **道义约束 D（non-compensatory）**：如不得造成超出同意范围的伤害、不得欺骗、不得未授权采集、不得剥夺人类最终否决权；
- **程序约束 P（non-compensatory）**：同意有效、可申诉、可解释、可退出、人类可覆盖；
- **福利约束 W（compensatory）**：收益、效率、分配公平的连续度量。
F_eth(σ_t) = { a : a ⊨ D(σ_t) ∧ a ⊨ P(σ_t) }，其中 σ_t = (同意状态、作用域、新颖性位、撤销位图、语境)。**动作合法性：a ∈ F_eth。** 仅 W 可进入标量目标。**这一区分是本轮的核心：并非所有伦理都是非补偿的，也并非所有伦理都该被标量化。**

**定义 373（运行时伦理否决 REV）** REV 是一个单向、O(1)、最高优先级的**集合收缩算子**：
a_t^exec = Filter_{F_eth(σ_t)}(a_t^cert)，其中 Filter 在 a^cert ∉ F_eth 时返回**安全停止策略** a^stop ∈ A_safe ∩ F_eth（而非「硬冻结」，以避免停在中途造成掉落/夹持伤害）。性质：REV(A) ⊆ A（单调收缩）；若 A_safe ∩ F_eth = ∅ ⇒ 机械急停。**可行性判定由预计算的约束谓词完成**（同意位图、作用域成员、道义禁止表），期望 O(1)。

**定义 374（伦理新颖性检测 ENT）** 给定已审查作用域分布 p_scope，新颖性分数
ν(x) = OOD_{p_scope}(x)，特征含 (情景特征, 利益相关者/体型/文化/能力特征, 交互动态)。
若 ν(x) > τ_nov ⇒ **升级人类伦理复核**（不得自主决策、不得自动拒绝后继续采集）。理由：审查未覆盖该情景，任何自主行为都依赖一张不成立的证书。

**定义 375（可撤销证书与同意令牌 RCERT）** 证书状态机 states = {proposed, approved, active, suspended, expired, revoked, escalated}；迁移触发 = {同意撤回, 新颖性, δ_gap 越界, 覆盖失效, 事故, 过期, 法规变更, 审计链断裂}。同意令牌
ConsentToken = (subject_id, action_classes, context_scope, expiry, revocable, τ_withdraw, τ_erase, signature)。
控制环对令牌做 O(1) 成员判定；撤回置位后经独立撤销中断在 τ_revoke 内生效，并在 τ_erase 内停止采集、擦除环形缓冲。**同意不是一次性表单，而是运行时可撤销状态；撤回同时约束运动与数据两条流水线。**

**定义 376（代表性/道德覆盖 MCOV）** 对伦理相关子群 S_j（体型、能力、文化、语言、年龄等）定义**双重覆盖**：
- 数据覆盖 D_cov(S_j)：S_j 在 p_DR/p_real 校准集中的覆盖；
- 规范覆盖 N_cov(S_j)：S_j 的伦理关切是否被 EAC 的 Scope 明确审查过。
部署门控：min_j min(D_cov(S_j), N_cov(S_j)) ≥ 1−α，否则该子群只能**人类监督下运行**。**统计覆盖不等于道德覆盖：数据有覆盖而从未被规范审查，是分配不公，不是方差问题。**

**定义 377（ETHOS 风险缩放与迁移项 E-RISK†）** 迁移不确定度 u_transfer = δ_gap + ε_tail（来自定义 368–370）。风险缩放
λ = max( risk_scale(U_ale, U_epi, H[b_t(z)], u_tac, u_transfer),
         λ_floor(U_ale + U_epi + H[b_t(z)] + u_tac.total() + u_transfer) )。
动作在 F_eth 内选择，并最大化
J(a) = E[W(a)] − λ·Risk(a) − c_reflex^{ψ,z,c}(a) − γ·E[远期损失]。
**注意分工：u_transfer 进 λ（可补偿的风险项）；D/P 进 F_eth（不可补偿的可行性）。把伦理写进 λ 是范畴错误（定理 28）。**

**定义 378（ETHOS 指标扩展 E-MIB†）** 在 E-MIB 基础上新增两族（同遵循六元组 (φ,m,u,D,τ,I⊥) 与 DAG 分层）：
- **迁移族**：δ_gap、经验覆盖率与覆盖缺口、重要性权重 ESS、新颖性 AUROC、子群数据覆盖 D_cov、子群规范覆盖 N_cov、迁移余量 margin；
- **伦理族**：同意有效率、同意撤回延迟 τ_withdraw、否决延迟 τ_revoke、可申诉通道可用率、约束条款可追溯覆盖率、审查者间一致性 κ、升级率与复核时延、撤销传播延迟、数据擦除延迟 τ_erase、欺骗/越界采集事件数、跨文化伦理分歧 ι_eth。

**定义 379（ETHOS 失效门控 E-IVG†）** 新增失效条件：
- 迁移：δ_gap > δ_max、coverage < 1−α、ESS < τ_ESS、支撑失配、margin < 0；
- 伦理：cert.state ≠ active、同意失效/过期/撤回、scope 不覆盖当前 x、ν(x) > τ_nov、min_j M_cov < 1−α、κ < τ_κ、τ_revoke/τ_erase 超阈、审计链断；
- 任一成立 ⇒ 相关模块降级：迁移失效 ⇒ 禁止实机自主（仿真/遥操作）；伦理失效 ⇒ 遥操作或安全停止；审计链断 ⇒ 冻结部署并取证。

**定义 380（ETHOS 证书 J_ETH）** J_ETH = (J_EMB, tov_hash, eac_hash, scope_hash, consent_chain, coverage_proof, novelty_status, revoke_bitmap_hash, audit_chain, eth_ver)。
Valid_real(J_ETH) ⇔ Valid(J_EMB) ∧ Valid_real(J^ToV) ∧ EAC 未过期且作用域覆盖 ∧ E-IVG† 全过 ∧ 审计链完整 ∧ 证书状态 active。

**定义 381（威胁模型 AIC-ETH）** ℰ_ETH = ℰ_EMB × ℰ_transfer × ℰ_eth：
- ℰ_transfer = {真实长尾落在 DR 支撑外、sim2real 残差投毒、覆盖伪造（校准集污染）、重要性权重操纵、ℋ_g 完备性造假}；
- ℰ_eth = {同意伪造/过期重放、审查 Goodhart（优化过审而非伦理）、审查记录篡改、审计链断裂、否决路径 DoS（让 REV 超时）、申诉通道被屏蔽、代表性盲区、审查者共谋、法规漂移}。

# IP-295 ToV：可迁移证书签发与实机生效判定（部署期 + 运营期）
@dataclass
class ToVCertificate:
    j_emb: Certificate
    src: DomainSpec; tgt: DomainSpec
    g: RiskFunctional                   # 被证明的风险泛函
    delta_gap: float; delta_ci: float   # 度量相关差距 + 置信上界
    n_cal: int; alpha: float
    eps_tail: float; margin: float
    prov: bytes; cond: List[Predicate]; sig: bytes

    def valid_on_real(self, x, ctx) -> bool:
        if not self.j_emb.valid(): return False
        if self.delta_gap + self.delta_ci > self.g.delta_max * budget(self.g): return False
        if weighted_conformal.coverage(self.n_cal, self.alpha) < self.alpha: return False
        if entropy_novelty(x, self.tgt) > TAU_NOV: return False       # 新颖性即不上车
        if self.margin < 0: return False                              # 迁移余量必须非负
        return all(p(ctx) for p in self.cond) and verify_sig(self.sig)

# IP-296 COV：域随机化下的加权保形覆盖（离线校准，在线只查）
class CoverageAuditor:
    def __init__(self, dr_samples, real_calib, loss):
        self.w = density_ratio(real_calib, dr_samples)     # w = p_real/p_DR
        self.ess = (self.w.sum()**2) / (self.w**2).sum()
        self.scores = [loss(x) for x in real_calib]
    def coverage(self, n, alpha):
        if self.ess < TAU_ESS: return 0.0                  # 权重集中 → 无保证
        if support_mismatch(self.w): return 0.0            # 支撑失配 → 无保证
        return weighted_quantile_coverage(self.scores, self.w, 1 - alpha)

# IP-297 ERG：伦理审查闸门（机构时钟，离线）
@dataclass
class EthicsApproval:
    review_ids: List[str]; clauses: List[EthicalClause]
    scope: ScopeDistribution; expiry: datetime
    reviewers: List[str]; kappa: float; seal_hash: bytes; sig: bytes
    def covers(self, x, t) -> bool:
        return (x in self.scope) and (t < self.expiry) and verify_sig(self.sig)
    def constraints_at(self, ctx) -> Tuple[Constraints, Constraints, Constraints]:
        return (self.hard_deontological(ctx), self.hard_procedural(ctx), self.welfarist(ctx))

# IP-298 REV：运行时伦理否决（控制时钟，O(1)，单向收缩）
def ethics_veto(a_cert, sigma, safe_set):
    D, P, _ = sigma.eac.constraints_at(sigma.ctx)          # 预计算谓词
    if consent_valid(sigma.consent, a_cert) and a_cert.satisfies(D | P):
        return a_cert                                      # F_eth 内，放行
    a_stop = safe_stop(a_cert, safe_set, sigma)             # 收缩到安全停止
    if a_stop is None or not a_stop.satisfies(D | P):
        return EMERGENCY_STOP                              # 机械急停
    return a_stop                                          # 只收缩，不扩张

# IP-299 ENT：伦理新颖性（运营时钟）
def ethical_novelty(x, eac, dr_stats):
    feat = (scenario_features(x), stakeholder_features(x), interaction_dynamics(x))
    nu = max(ood_score(feat, eac.scope), subgroup_novelty(feat, dr_stats))
    return nu    # nu > TAU_NOV ⇒ escalate_to_human_review，禁止自主决策

# IP-300 RCERT：可撤销证书 + 同意令牌（运营时钟，审计链只增）
class RevocableCert:
    STATES = {'proposed','approved','active','suspended','expired','revoked','escalated'}
    def __init__(self, eac, tov, consent, audit):
        self.state, self.eac, self.tov = 'proposed', eac, tov
        self.consent, self.audit = consent, audit
    def revoke(self, reason, now):
        self.state = 'revoked'
        self.consent.bits.setwithdraw()                    # 触发独立撤销中断
        self.audit.append('revoke', reason, now)           # 只增哈希链
        self.consent.schedule_erase(now, TAU_ERASE)        # 数据流水线同步受约束
    def tick(self, now, x, nu, delta_gap):
        if now > self.eac.expiry: self.state = 'expired'
        elif not self.eac.covers(x, now): self.state = 'escalated'
        elif nu > TAU_NOV: self.state = 'escalated'
        elif delta_gap > self.tov.g.delta_max: self.state = 'suspended'
        elif not self.consent.valid(): self.state = 'revoked'
        return self.state

# IP-301 MCOV：子群数据覆盖 × 规范覆盖
def moral_coverage(eac, dr_stats, real_stats, subgroups, alpha):
    return {s: (data_coverage(s, dr_stats, real_stats, alpha),
                normative_coverage(s, eac.scope, alpha)) for s in subgroups}
    # 部署门控：min(D_cov, N_cov) ≥ 1-alpha，否则该子群仅人类监督

# IP-302 ETHOS 主闭环（在 EMBODIED 上叠加四时钟；控制域只多一个 O(1) 收缩）
def ETHOS_GAUGE_RAS_round(M, obs, audio, tac_frame):
    # ===== 机构时钟（离线；本轮只读取缓存）=====
    eac, tov = M.erg.latest_eac(), M.tov.latest()          # 已签名、带 scope/expiry
    # ===== 运营时钟（秒级）=====
    x = M.context.identify(obs)
    nu = ethical_novelty(x, eac, M.dr_stats)
    if nu > TAU_NOV:
        M.rcert.escalate('ethical_novelty', x)
        M.mode = 'HUMAN_REVIEW'                            # 不许自主继续
    if not eac.covers(x, M.clock.now()) or not M.rcert.consent.valid():
        M.rcert.revoke('scope_or_consent', M.clock.now())
        M.mode = 'TELEOP'
    if not tov.valid_on_real(x, M.ctx):
        M.mode = 'SIM_ONLY' if M.no_human else 'TELEOP'    # 迁移失效不上实机
    # ===== 控制时钟（1kHz；延续 R72，唯一新增是一次 O(1) 收缩）=====
    snap = M.snapshot.read_latest()
    b_t  = M.bse.step_ctrl(snap.b_prev, obs, M.last_action, M.last_g, M.last_y)
    U_ale, U_epi = decompose_ctrl(b_t, M.fmp, obs)
    u_transfer = tov.delta_gap + tov.eps_tail
    lam = embodied_risk_scale(U_ale, U_epi,
                              snap.z_dist.entropy() if snap.z_dist else 0.0,
                              snap.tac_ev.u_tac if snap.tac_ev else 0.0,
                              u_transfer, M.risk_params)    # E-RISK†
    A = M.ach.propose_ctrl(...); a = M.c_ras_wm.certified_prefix(A, lam, ...)
    sigma = VetoState(consent=M.rcert.consent, eac=eac, ctx=x,
                      novelty=nu, revoke=M.revoke_bitmap)   # 只读 + 撤销位
    a_exec = ethics_veto(a, sigma, M.safe_set)              # REV：核心新增
    M.ctrl_out.publish(a_exec, lam)
    if a_exec is EMERGENCY_STOP: return a_exec, None
    M.last_action = a_exec
    # ===== 计量/感知域（沿用 R72 三域分离，不展开）=====
    ...
    # ===== 取证时钟（异步）=====
    M.audit.append('cycle', hash((a_exec, lam, sigma.bits)), M.clock.now())
    return a_exec, lam, J_ETH(M, eac, tov, M.rcert, nu)

## 3. 推导

**引理 33（迁移代价的加性下界）** 设风险泛函 R 在度量 d 下 L-Lipschitz，且源/目标分布满足 δ_gap ≥ W_1(S_sim, S_real)（或定义 369 的 discrepancy 上界）。则对任意策略 π：
R_real(π) ≤ R_sim(π) + L·δ_gap。
证明：对 ℓ_π(x) := risk(π,x) 用 Lipschitz 与对偶表示，|E_sim ℓ − E_real ℓ| ≤ L·W_1 ≤ L·δ_gap；再加三角不等式。**系：参数桥接（S2R-UQ）只约束 θ 维，无法替代对 g 维的 δ_gap；R72 把二者混同，等于默认 δ_gap=0。**

**引理 34（域随机化的覆盖不足）** 设 DR 在 p_DR 上采样 n 个样本，p_real 在 p_DR 支撑外有质量 μ>0。则任何仅基于 p_DR 样本的覆盖声明在支撑外的事件上无效；且当重要性权重方差发散时，加权保形覆盖率 → 名义覆盖率不再可达。**系：加随机化 ≠ 加覆盖；覆盖必须由加权保形 + 支撑失配检测 + ESS 门控显式证明。**

**引理 35（道义/程序约束不可有限标量化）** 设目标 f(U,E) = U − κ·C_E 对 U 严格递增，U 值域无上界（或上界远大于 κ·C_E 的差）。则存在 a_c ∈ F_eth 与 a_v ∉ F_eth 使得 f(a_v) > f(a_c)。证明：取 a_v 使 U(a_v) − U(a_c) > κ·(C_E(a_v) − C_E(a_c)) 即可。**系（范畴错误）：给 R72 的 λ 加一个「伦理权重」必然引入一个隐式交换率——效率可以买走违规；伦理必须写成可行域 F_eth，先可行后最优。福利约束 W 例外，因其本就是可补偿的。**

**引理 36（否决的收缩性与时序安全）** REV 满足 REV(A) ⊆ A，且对任意候选动作的可行性判定是预计算谓词上的 O(1) 求值；最坏情形返回 a^stop 或机械急停（均 O(1)）。因此把 REV 串接进控制环不增加关键路径复杂度，且**只可能移除动作**。系：与 EMBODIED 组合后，执行动作集是子集 ⇒ 物理风险单调不增（定理 23 的单调性保留）；若 A_safe ∩ F_eth = ∅ 则机械急停，仍是收缩。

**引理 37（撤销传播上界）** 若撤销信号走独立最高优先级单向通道，则 τ_revoke ≤ 2·T_ctrl + L_sched（一个周期完成置位，一个周期完成安全停止）；数据擦除 τ_erase 由专用缓冲擦除例程保证，与运动停止解耦。

**引理 38（新颖性使迁移保证失效）** 若 ν(x) > τ_nov（x 超出已审查作用域），则定义 370 的加权可交换性不成立，保形覆盖保证为空；此时任何自主动作都依赖一张无效证书，故升级复核是唯一健全选择。**系：升级（把自主权收缩到人类授权子集）是安全且伦理单调的。**

**定理 27（ToV 健全性 ⇒ 迁移可证）** 在 A111–A115（R 的 L-Lipschitz、δ_gap 置信上界有效、加权保形覆盖 ≥ 1−α、ℋ_g 完备、无新颖性）下：
R_real(π) ≤ R_sim(π) + L·δ_gap + ε_tail ≤ ε_budget，
故仿真证书在实机上成立。证明：引理 33 + 覆盖定义 370 + margin ≥ 0。**系：证书可迁移当且仅当迁移代价被显式支付；没有免费迁移。**

**定理 28（非补偿性 ⇒ 必须字典序/可行域）** 在道义 D 与程序 P 非空且存在可补偿收益的前提下，任何对 D∪P 采用有限惩罚的标量目标都存在补偿性违规（引理 35）。因此伦理上健全的决策必须是：先取 F_eth，再在 F_eth 内最大化 J。**系：R72 的 λ_floor 是风险机制，不是伦理机制；把伦理并入 λ 会产生「安全但失德」且事后无法审计的决策。**

**定理 29（ETHOS 组合后的安全/伦理单调）** 在 A111–A115 且 REV 可执行下，ETHOS 的每个执行动作 ∈ F_eth，且其物理风险界 ≤ EMBODIED 的风险界；两者均 ≤ R68 的硬安全包络。证明：引理 36（集合收缩）+ 定理 23（具身包含）+ 定义 372。**系：新增伦理层只可能减少动作集，不增加物理风险。**

**定理 30（新颖性/迁移失效下的升级健全）** 若 ToV 或 ENT 失效，则自主执行的证书不成立；升级到人类复核后，执行集合被限制为人类授权子集，故风险与伦理违规均不高于失效前的自主策略。证明：引理 38 + 定义 373 的收缩性。

**定理 31（严格包含链）** 当 δ_gap=0、F_eth=𝒜（仅福利约束或空约束）、同意恒有效、无新颖性时，ETHOS 逐指令等价于 EMBODIED（R72）；进一步退化到 GAUGE（R71）与 R68 的链与定义 364 一致。即 **ETHOS ⊒ EMBODIED ⊒ GAUGE ⊒ R68**，安全侧与伦理侧只增不减。

**定理 32（审计独立性是抗 Goodhart 的必要条件）** 若审查信号与优化目标同源、审查集固定且已知，则存在策略 π̃ 在被审集上通过、而在分布外真实伦理违规率超过阈值（记忆/过拟合构造成立）。故健全性要求：(i) 审查者独立；(ii) 密封 + 随机抽样审计集；(iii) 受影响者可直接发起申诉（不依赖审查者自觉）；(iv) 上线后持续监测。**系：伦理保证的强度等于最弱且未被收买的那个信号。**

**一句话**：ETHOS-GAUGE-RAS 把「安全」进一步外包给两层新的信任假设——**相信 δ_gap/覆盖/ℋ_g 完备性这些度量在真实长尾上仍然有效**，以及**相信伦理审查的作用域、同意状态与审计链没有被共谋、过拟合或静默过期**；一旦域随机化恰好没覆盖某个真实子群（数据覆盖高但规范覆盖为零）、而审查者与被优化目标同源、撤销信号又在高负载下被延迟到 τ_revoke 之外，系统就会拿着一套「迁移余量非负、审计链完整、每次否决都及时」的完美证书，对从未被真正审查和同意的人做出不可撤销的事，而事后取证只能证明「当时所有指标都在有效域内」——这就是**迁移层面的「把仿真中的合规误当成现实中的正当」**。

次级风险与缓解：
1. **ℋ_g 不完备导致 δ_gap 低估** → 显式列出被排除维度并做**敏感性审计**；对每个被排除维度注入扰动，验证 g 的界不被击穿。
2. **覆盖伪造/校准集污染** → 校准集**签名+密封+留出**，COV 断链即拒绝迁移；重要性权重做稳健估计（clip + 诊断）。
3. **审查 Goodhart/共谋** → 审查独立、审计集随机密封、**受影响者申诉通道**、上线后监测四件套；审查记录进只增链。
4. **非补偿约束被悄悄标量化** → 在代码层把 D/P 实现为**独立可行性过滤器**（不是损失项），并做消融与静态检查（禁止 D/P 出现在目标函数中）。
5. **否决路径被拖慢/绕过** → REV 独立最高优先级、无锁无分配、超时即机械急停；E383 专项压测。
6. **撤销后数据仍残留** → 撤销同时约束**运动与数据两条流水线**，专用擦除例程 + τ_erase 审计。
7. **代表性/道德盲区** → MCOV 双重覆盖门控；盲区子群强制人类监督，并在审计报告中显式列出「未覆盖人群」。
8. **法规/作用域漂移** → EAC 带 scope+expiry，过期自动 suspended；τ_inst 重审，不允许静默续期。
9. **复杂度爆炸** → 模块上限：|𝒮_subgroup|≤12、|D|+|P|≤24、|ℋ_g|≤32；每条约束、每个覆盖声明都要一条可复算证明。

@dataclass
class ToVCertificate:
    j_emb: Certificate
    src: DomainSpec; tgt: DomainSpec

    n_cal: int; alpha: float

        if self.delta_gap + self.delta_ci > self.g.delta_max * budget: return False

# IP-296 COV：域随机化下的加权保形覆盖
class CoverageAuditor:
    def __init__(self, dr_samples, real_calib, loss):
        self.w = density_ratio(real_calib, dr_samples)      # w = p_real / p_DR
        self.ess = (self.w.sum() ** 2) / (self.w ** 2).sum()

## 4. 推导

**引理 33（迁移代价加性下界）** R 在 d 下 L-Lipschitz 且 δ_gap ≥ W_1(S_sim,S_real) ⇒ R_real(π) ≤ R_sim(π) + L·δ_gap。**系：参数桥接只约束 θ 维，无法替代沿 g 维的 δ_gap；R72 混同二者等于默认 δ_gap=0。**

**引理 34（DR 覆盖不足）** 若 p_real 在 p_DR 支撑外有质量 μ>0，则仅基于 p_DR 的覆盖声明在支撑外无效；权重方差发散时加权保形覆盖率不再可达名义值。**系：加随机化 ≠ 加覆盖。**

**引理 35（D/P 不可有限标量化）** 对 f(U,E)=U−κC_E（U 无上界），存在 a_c∈F_eth、a_v∉F_eth 使 f(a_v)>f(a_c)。**系（范畴错误）：给 λ 加「伦理权重」必然引入隐式交换率；伦理必须写成 F_eth，先可行后最优。W 例外（本就可补偿）。**

**引理 36（否决收缩与时序安全）** REV(A)⊆A，可行性判定是预计算谓词上的 O(1) 求值，最坏返回 a^stop 或机械急停（均 O(1)）；只移除动作不增加关键路径 ⇒ 不引入 deadline miss，且与 EMBODIED 组合后物理风险单调不增。

**引理 37（撤销传播上界）** 撤销走独立最高优先级单向通道 ⇒ τ_revoke ≤ 2T_ctrl + L_sched；τ_erase 由专用擦除例程保证，与运动停止解耦。

**引理 38（新颖性使迁移保证失效）** ν(x)>τ_nov ⇒ 加权可交换性不成立 ⇒ 保形覆盖为空 ⇒ 任何自主动作依赖无效证书 ⇒ 升级是唯一健全选择。

**定理 27（ToV 健全性）** 在 A111–A115（Lipschitz、δ_gap 置信上界有效、加权覆盖 ≥1−α、ℋ_g 完备、无新颖性）下 R_real ≤ R_sim + L·δ_gap + ε_tail ≤ ε_budget。**系：证书可迁移 ⇔ 迁移代价被显式支付。**

**定理 28（非补偿性 ⇒ 字典序/可行域）** 任何对 D∪P 采用有限惩罚的标量目标都存在补偿性违规；健全决策必须先取 F_eth 再最大化 J。**系：λ_floor 是风险机制，不是伦理机制；把伦理并入 λ 会产生「安全但失德」且事后不可审计的决策。**

**定理 29（ETHOS 组合安全/伦理单调）** REV 可执行时，每个执行动作 ∈ F_eth，物理风险 ≤ EMBODIED ≤ R68 硬安全包络。**系：伦理层只减少动作集，不增加物理风险。**

**定理 30（失效下升级健全）** ToV/ENT 失效 ⇒ 自主证书不成立 ⇒ 升级后执行集合被限制为人类授权子集 ⇒ 风险与伦理违规不高于失效前自主策略。

**定理 31（严格包含链）** δ_gap=0、F_eth=𝒜、同意恒有效、无新颖性时 ETHOS ≡ EMBODIED（R72）；进一步退化到 GAUGE（R71）与 R68。即 **ETHOS ⊒ EMBODIED ⊒ GAUGE ⊒ R68**。

**定理 32（审计独立性必要性）** 审查信号与优化同源、审查集固定已知时，存在策略过审但分布外真实违规率超阈。健全性要求：审查独立 + 密封随机审计集 + 受影响者直连申诉 + 上线后监测。**系：伦理保证强度 = 最弱且未被收买的那个信号。**

## 7. 本轮最大风险

**一句话**：ETHOS-GAUGE-RAS 把「安全」进一步外包给两层新的信任假设——**相信 δ_gap/覆盖/ℋ_g 完备性在真实长尾上仍然有效**，以及**相信伦理审查的作用域、同意状态与审计链没有被共谋、过拟合或静默过期**；一旦域随机化恰好没覆盖某个真实子群（数据覆盖高但规范覆盖为零）、审查者与被优化目标同源、撤销信号又在高负载下被延迟到 τ_revoke 之外，系统就会拿着一套「迁移余量非负、审计链完整、每次否决都及时」的完美证书，对从未被真正审查和同意的人做出不可撤销的事，而事后取证只能证明「当时所有指标都在有效域内」——这就是**迁移层面的「把仿真中的合规误当成现实中的正当」**。

次级风险与缓解：
1. **ℋ_g 不完备 → δ_gap 低估**：显式排除清单 + 敏感性审计 + 对排除维度注入扰动验证界不被击穿。
2. **覆盖伪造/校准集污染**：校准集签名、密封、留出；COV 断链即拒绝迁移；权重稳健估计（clip + 诊断）。
3. **审查 Goodhart/共谋**：审查独立 + 审计集随机密封 + 受影响者直连申诉 + 上线后监测；记录进只增链。
4. **非补偿约束被悄悄标量化**：D/P 实现为独立可行性过滤器（非损失项），静态检查禁止其出现在目标函数；E373 消融。
5. **否决路径被拖慢/绕过**：REV 独立最高优先级、无锁无分配、超时即机械急停；E383 专项压测。
6. **撤销后数据残留**：撤销同时约束运动与数据两条流水线；专用擦除 + τ_erase 审计；E371。
7. **代表性/道德盲区**：MCOV 双重门控；盲区子群强制人类监督；审计报告显式列出未覆盖人群。
8. **法规/作用域漂移**：EAC 带 scope+expiry，过期自动 suspended；τ_inst 重审，不允许静默续期。
9. **复杂度爆炸**：|𝒮_subgroup|≤12、|D|+|P|≤24、|ℋ_g|≤32；每条约束/覆盖声明都要一条可复算证明。
