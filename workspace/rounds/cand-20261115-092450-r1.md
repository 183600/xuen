# 第 4 轮（灵感循环第 4 轮；本轮灵感：「腕部相机」×「可靠性」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。腕部相机是**可选证据源**，可靠性是**一等契约维度**；任一环节不可用都必须能退回 InstructGauge ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。

## 0. 直觉与动机

**灵感 1（腕部相机 = 眼睛长在手上：分辨率最高、离作业面最近，但天生「在运动中看东西」）**
直觉：外置相机看得全、却看不清触点；腕部相机装在机械臂末端，离毛刺、反光、缝隙最近，最擅长回答一个非常局部的问题——「我马上要碰的这一点，真的是我以为的那一点吗？」但它的优势全带着代价：视场窄、易被工具或手臂自遮挡、随臂速产生运动模糊、手眼标定会漂移、线缆/带宽会掉。因此它最合适的角色不是「独立发起承诺」，而是**局部验证与否决**：让高分辨信息去 confirm / veto 一个已经由全局证据提出的计划，而不是让一个窄视场、会抖动的传感器单独决定不可逆动作。

**灵感 2（可靠性不是「打个分」，而是一份可被检验的契约）**
直觉：工程里说「这个传感器可靠」几乎没有信息量，除非同时说清三件事：**在什么工况下、误差不超过多少、以多大概率**。所以本轮把可靠性写成**传感器可靠性契约** `R=(C, ε, 1−δ, τ)`：在工况集 `C` 上，凡报告可靠度 `ρ≥τ`，则误差 ≤ `ε` 的概率 ≥ `1−δ`。这是把第 1 轮 LeanGauge 的「测量契约」从数值量测推广到**证据源本身**——传感器也要为它输出的每个判断背书，而不是只给一个热力图或置信度。

**灵感 3（可靠性工程视角：新增一条「验证冗余」，也新增一类「共因失效」）**
直觉：在可靠性框图里，腕部相机是一条并联的**验证路径**，按理能降低漏检；但它与外置相机共享光照、环境与网络，存在**共因失效**（common cause）：灯一闪、网一断，两条路一起瞎。于是「多一个传感器」并不自动等于「更可靠」，必须做 FMEA、单一故障假设与共因拆分。一个反直觉但重要的推论是：**腕部相机最有价值的时刻，恰恰是它与外置相机不共享失效模式的时候**（近距、不同视角、不同曝光），而不是它拍得最清楚的时候。

**灵感 4（与第 3 轮的结构耦合：运动模糊 ↔ 块静默点；可靠性 ↔ 分层共形）**
直觉：第 3 轮已经定义了块静默点 `q_quiesce`（无在途块、无待处理不可逆动作）。腕部相机要拍清楚，最自然的时刻正是块边界/静默点：此时臂速低、运动模糊小、工具不挡视线。于是「动作分块」不仅摊销决策开销，还顺带制造了**可捕获窗口**——这是两条线索真正的咬合点。另一方面，可靠度阈值 `τ` 不能拍脑袋，必须用**共形风险控制**校准成「信它就真敢信」的分布无关保证，这复用并改写了第 3 轮的 SC-Cal：从「按指令分层」扩展到「按可靠性分层、按工况漂移修正」。

## 1. 研究问题（本轮要回答什么）

- **Q1（证据角色）**：腕部相机应当「发起」还是「否决」？能否用证据权限格（originate / verify / veto）在不牺牲安全的前提下，榨取局部高分辨信息？
- **Q2（可靠性的可校准性）**：可靠度分数能否被校准成可检验的契约，使「ρ≥τ 才采信」的选择性风险有**分布无关、有限样本**上界，而不是经验阈值？
- **Q3（运动-捕获权衡）**：运动模糊把「看得清」与「走得快」对立起来；在什么分块/静默结构下，能同时保住 50Hz 实时性与捕获质量，并给出 dwell 的时延界？
- **Q4（退化与共因）**：腕部失效或共因失效时，系统能否**逐指令等价**退回 InstructGauge，且不因「两路一起瞎」而被一锅端？

## 2. 设计原则（雏形，正式化见产物区定义 448–463）

**P1 证据权限格（Evidence Authority Lattice）**
腕部相机对**不可逆**动作只有「否决 / 佐证」权，没有「发起」权；不可逆动作必须由腕部 + 一个**独立模态**（触觉/外置视觉）双授权。低可靠腕部证据既不得授权、也不得硬否决，只能作为建议。形式化方向：把角色写成偏序 `originate ⊒ verify ⊒ veto`，腕部只允许 `{verify, veto}`（可逆局部细化可 `originate`），任何越权一律降级为建议；由此得到「新增传感器不扩权」的单调安全性（引理 59）。

**P2 可靠性契约（Reliability Contract）**
每个证据源维护 `R=(C, ε, 1−δ, τ)`，可靠度先经保序/共形校准，阈值 `τ` 由分布无关风险控制（Learn-then-Test / CRC）选取；跨工况用 TV 修正，冷层回退全局。形式化方向：定义 449/450/454，保证「信任区内的选择性风险 ≤ α」以 `1−β` 成立。

**P3 运动门控捕获（Motion-Gated Capture）**
捕获必须满足模糊上界 `b ≤ b_max`；不满足则 `dwell`（停顿凝视）或推迟到 `q_quiesce`，绝不带着运动模糊硬拍后当真。形式化方向：定义 452/462，给出可捕获窗口与 dwell 时延界（引理 62）。

**P4 失效模式显式化与共因拆分（FMEA + Common-Cause）**
列全 7 类失效（运动模糊、自遮挡、镜头污染、高光饱和、手眼漂移、掉线/时延、共因光照/网络），逐类给出检测统计量与降级目标；共因失效必须由独立模态破除，禁止用「传感器数量」冒充「可靠性（引理 64）。

## 3. 与基线的接口（如何退化）

- 腕部掉线 / `ρ<τ` / 捕获不可行 ⇒ 该证据权重置 0，逐指令退化为 InstructGauge（外置 + 触觉 + 音频）；
- 手眼残差超限 ⇒ 自校准；自校准失败 ⇒ 降级到外置标定；再失败退回 ToolGauge；
- 可靠性共形样本不足 ⇒ 回退第 3 轮的分层共形阈值；再不足回退全局；
- InstructGauge 失效 ⇒ ToolGauge 纯数值路径 ⇒ LeanGauge ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个**证据权限格**：把「加一个新传感器」重新表述为「加一个新的验证者」，用类型/偏序防止它扩权；
2. 一个**可靠性契约 + 共形选择性风险控制**：让「信腕部」有有限样本保证，而不是经验阈值；
3. 一个**运动-捕获-分块三联定理**：证明 `q_quiesce` 提供有界模糊的捕获窗口，并给出 dwell 的时延界；
4. 一个**共因感知的降级栅格**：FMEA 驱动的 7 类失效检测与逐指令等价退化；
5. 一条完整可证伪路径：E457–E472 覆盖可靠性校准、选择性风险、运动模糊、捕获-分块、分层覆盖、污染鲁棒、手眼漂移、掉线切换、预算分配、权限格/双授权、主动视角、共因、端到端、消融、50Hz 与 sim→real。

## 5. 本轮最大风险

**一句话**：可靠性分数自己也可能「自信地错」——一旦工况漂移（光照突变、镜头渐污、温漂）使可靠性契约不再覆盖当前分布，最靠近作业面的腕部证据就会以高 `ρ` 去**否决正确动作**或**佐证错误动作**，而共因失效会让「腕部 + 外置」同时失准；因此真正的残余风险不是相机抖动，而是**可靠性估计器在 OOD 下静默漂移、契约失效却仍被当作有效**。

**核心洞察（本轮的可证伪主张）**：腕部相机应被当作**可校准的验证冗余**，而不是强传感器。其价值上界由「可靠性契约在当前工况下是否仍成立」决定；一旦超出契约覆盖域，继续用高 `ρ` 采信它反而比干脆不用更危险（引理 60/64）。因此安全性的关键不是把图像处理做得更好，而是让**契约的失效可被检测、且失效时能一键退回**。

## 2. 形式化定义（要点）

**定义 448（腕部证据流与可靠性特征）** 腕部相机在 `t` 产生观测 `(I_t, P_t, v_t, Ĥ_t, τ_t)`，其中 `P_t` 为末端 FK 位姿、`v_t` 为末端线速度、`Ĥ_t` 为当前手眼外参估计。可靠性特征 `z_t = (b_t, e_t, o_t, s_t, r_t, ℓ_t, d_t)` 分别为：运动模糊尺度、曝光/信噪比、工具与手臂自遮挡像素比、高光饱和像素比、手眼配准残差、时间戳偏差（时延）、掉线指示。原始可靠度 `ρ̂_t = g_θ(z_t) ∈ [0,1]`，`g_θ` 只允许使用在线可测量，不得读取真值或测试集标签。

**定义 449（可靠性契约 R）** `R = (C, ε, 1−δ, τ, prov)`。语义：对任意工况 `c ∈ C` 与任意 `ρ_t ≥ τ` 的时刻，
`P(‖x̂_t − x_t‖ ≤ ε | c) ≥ 1−δ`，
其中 `x` 为被腕部证据验证的局部几何/位姿量（如接触点位置、表面朝向、缝隙宽度）。`prov = (calib_id, 数据版本, 环境分层, 有效期)` 使契约可审计、可过期。契约是**可证伪**的：E457/E472 专门检验其在名义与 OOD 工况下是否成立。

**定义 450（可靠性校准 cal 与 ECE）** 令成功事件 `y_t = 1[‖x̂_t − x_t‖ ≤ ε]`。先对 `(ρ̂_t, y_t)` 做保序回归得到单调 `cal`，再用分位数/共形包装把 `ρ` 变成层内成功概率的**保守下界**。分桶校准误差
`ECE = Σ_b (n_b/N)·|acc_b − conf_b|`，分层误差 `ECE_s` 同理。要求 `cal` 单调、且不得在低样本桶外推。

**定义 451（手眼残差与漂移检测）** `r_t = robust_registration(I_t, expected_features(Ĥ_t, scene))`。对标定后基线 `r_0`，CUSUM 统计量
`C_t = max(0, C_{t−1} + (r_t − r_0) − k)`，
当 `C_t > h` 报警。漂移检测触发自校准（基于已知标定板或运动-视差约束），失败则把 `Ĥ_t` 标记为不可信并降级到外置标定，`CalibProvenance` 记录来源与不确定度。

**定义 452（运动门控捕获与 dwell）** 点扩散模糊近似 `b_t ≈ κ·v_t·T_exp / d_feat`，`d_feat` 为特征尺度、`κ` 为相机常数。捕获**可行**当且仅当
`b_t ≤ b_max  ⇔  v_t ≤ V_max := b_max·d_feat/(κ·T_exp)`。
不可行时只有两条合法路径：(i) `dwell`：在 `T_dwell` 内把末端速度压到 `≤ V_max` 后捕获；(ii) `defer`：推迟到 `q_quiesce`（第 3 轮定义 439，`v=0`）。可捕获窗口 `W_cap = {t : v_t ≤ V_max}`。禁止「先拍再当作可信」。

**定义 453（可靠性门控鲁棒融合）** 对模态 `m ∈ {wrist, ext, tactile, audio, depth}`，以污染模型
`p̃_m(x) = (1−ε_m)p_m(x) + ε_m U(x)`
吸收异常/离群证据，门控权重 `w_m = 1[ρ_m ≥ τ_m]·ρ_m`，融合后验
`p(x|E) ∝ ∏_m p̃_m(x)^{w_m}`。
输出 `FuseCert = (weights, ρ, ε, prov, predicted_error)`。`w_wrist = 0` 时融合精确退化为 InstructGauge 的多模态后验。

**定义 454（共形选择性风险控制）** 信任区 `S_τ = {t : ρ_t ≥ τ}`，选择性风险
`SR(τ) = E[L_t·1{t∈S_τ}] / E[1{t∈S_τ}]`，`L_t = 1[error_t > ε]`。
用 Learn-then-Test / 共形风险控制在校准集上对候选 `τ` 计算上置信界 `U(τ)`，取最大的 `τ̂` 使 `U(τ̂) ≤ α`，从而 `P(SR(τ̂) ≤ α) ≥ 1−β`（层内可交换；跨层修正 `Σ_s π_s·TV_s`）。冷层（`|C_cal^s| < n_min`）回退第 3 轮全局/指令分层阈值，覆盖按 `−2η` 优雅降级。

**定义 455（证据权限格与双授权）** 角色集 `A_auth = {originate, verify, veto}`，按「扩权」程度取偏序 `originate ⊒ verify ⊒ veto`。腕部相机允许：
- `verify`：任何时候（佐证已有候选）；
- `veto`：仅当 `ρ_wrist ≥ τ`，且只能**删去**候选动作；
- `originate`：仅对**可逆**局部细化（如微调接触点），且 `ρ_wrist ≥ τ`。
腕部**永不** `originate` 不可逆动作。不可逆动作 `a_irr` 需
`DualAuth(a_irr) = verify_wrist(a_irr) ∧ verify_indep(a_irr)`，
其中 `verify_indep` 来自与外置相机不同失效模式的模态（首选触觉）。任何越权调用在类型层返回 `Advisory`（建议），不进入执行路径。

**定义 456（可靠性约束主动视角 NBV-R）** 选择下一视角/位姿 `ξ`：
`J_NBV(ξ) = E[ΔH(ξ)]·ρ̂(ξ)·P_succ(ξ) − λ_m·motion_cost(ξ) − λ_b·BarrierRisk(ξ)`，
`s.t.` 捕获可行、`|C| ≤ K_MAX(ι)`、块级预算 `B_chunk ≤ B_left`、不跨不可逆屏障。返回视点计划与**预期可靠度**，供 RCS 预筛（预测不可靠的视点不得当选）。

**定义 457（可靠性预算分配）** 给定证据预算 `B`，在模态间分配 `b_m`（`Σ b_m ≤ B`）以最大化期望信息增益减失效惩罚；单位成本信息增益 `IG_m` 高但失效概率大的腕部模态必须带失效惩罚项。期望信息增益在自适应次模假设下单调次模，贪心分配有 `(1−1/e)` 近似。

**定义 458（掉线模式机与迟滞）** 模式 `M ∈ {FUSED, WRIST_ADVISORY, EXTERNAL_ONLY, NUMERIC_ONLY}`。转移由 `(ρ_wrist, dropout, calib_valid, CC_flag)` 驱动，带迟滞 `h_yst`（连续 `n_h` 帧确认）以避免抖动；最长检测延迟 `T_det`。任何转移必须保持第 3 轮安全不变量，且 `EXTERNAL_ONLY` 下逐指令等价 InstructGauge。

**定义 459（可审计腕部回执）** `receipt_w = (frame_id, z_t, ρ_t, R_id, calib_provenance, w_wrist, decision, ts)`。它并入第 3 轮 NCB（定义 441）与 `RepairCert′`（定义 447）：每条腕部驱动的结论都必须能回溯到「哪一帧、什么可靠性、哪份标定契约」。

**定义 460（可靠性分层与漂移）** `stratum_r = (光照档, 速度带, 遮挡类, 材质/反射类)`，与第 3 轮指令分层 `stratum(ι)` 正交。逐层维护可靠性图与 CUSUM；层内漂移触发重新校准或回退全局。冷层不得使用未经验证的分层阈值。

**定义 461（共因失效与独立性假设）** 共因事件集 `CC`（光照突变、镜头污染、网络分区）。模态独立**仅在所有 `CC` 事件条件化后**成立。设腕部与外置的边际失效概率为 `q_w, q_e`，共因概率 `π_cc`，则
`P(两者同时失效) = π_cc + (1−π_cc)·q_w·q_e ≥ q_w·q_e`。
即共因使并联冗余的收益上界被 `π_cc` 截断；破除方式：条件化检测 `CC`（如光照突变检测）或引入不共享该失效模式的独立模态（触觉）。

**定义 462（捕获-分块耦合）** 对块 `C` 的边界 `∂C`，定义可捕获性
`cap(C) = 1[ v(∂C) ≤ V_max ∧ o(∂C) ≤ o_max ]`。
IAC 规划（第 3 轮定义 436）增加约束/正则项 `cap(C)`：不可捕获的块边界允许插入 `dwell`（计入块级预算 `B_chunk`）或缩短 `K`；`q_quiesce` 处 `v=0`，故 `cap=1`。这把第 3 轮的分块静默点变成**主动制造的低模糊捕获窗口**。

**定义 463（腕部增强修复证书）** `RepairCert″(s) = (RepairCert′(s), {receipt_w}, FuseCert, R_id, CalibProvenance)`。审计链由「指令→块→逐步回执→主张」延长到「→证据源可靠性契约」，使一次修复的结论可被追问「凭什么信这台腕部相机」。

class CaptureScheduler:

        return v <= V_max

def robust_fuse(evidence, rhos, taus, eps):
    w = {m: (rho >= taus[m]) * rho for m, rho in rhos.items()}
    if w.get("wrist", 0.0) == 0.0:
        return baseline_fuse(evidence)             # 精确退化 InstructGauge
    logp = 0.0
    for m, e in evidence.items():
        p_tilde = (1 - eps[m]) * e.likelihood + eps[m] * e.uniform
        logp = logp + w[m] * log(p_tilde)
    return posterior(logp), FuseCert(w, rhos, eps)

# IP-332 RCS：可靠度校准 + 选择性风险控制
class SelectiveRiskController:
    def fit(self, scores, losses):

        return self
    def choose_tau(self, cal_scores, losses, alpha, beta):

                return tau
        return +inf                                # 全不信任 => 退回基线

# IP-333 WVA：权限格 + 双授权
def authorize(role, action, rho, tau, indep_verify):
    if action.irreversible:
        if role == "originate":                    # 腕部不得发起不可逆
            return Advisory("wrist_cannot_originate_irreversible")
        return DualAuth(verify_wrist=(rho >= tau),
                        verify_indep=indep_verify)  # 必须独立模态
    if role == "originate":
        return (rho >= tau)                         # 仅可逆局部细化
    if role == "veto":
        return (rho >= tau)                         # 低可靠只能建议
    return True

# IP-334 NBV-R：可靠性约束主动视角
def next_best_view(H, rho_hat, budget):
    best = None
    for xi in candidate_views(H):
        if not capture_admissible(xi) or crosses_barrier(xi):
            continue
        J = info_gain(xi) * rho_hat(xi) * success_prob(xi) \
            - lambda_m * motion_cost(xi) - lambda_b * barrier_risk(xi)
        best = max(best, (J, xi))

## 4. 失效模式与降级（FMEA）

| 失效模式 | 在线检测量 | 触发判据 | 缓解 | 降级目标 |
|---|---|---|---|---|

| 掉线/时延/带宽 | 心跳、时间戳偏差 `ℓ_t` | 掉线或 `ℓ_t > ℓ_max` | 迟滞切换、异步重连 | `EXTERNAL_ONLY` ⇒ `NUMERIC_ONLY` |

## 5. 推导

**引理 59（证据权限格的单调安全性）** 在定义 455 的权限格下，腕部证据对候选动作集 `A` 的改变只可能是：(i) `veto` 删去元素（`ρ≥τ` 时）；(ii) `originate` 增加**可逆**元素（`ρ≥τ` 时）。故 `A' ⊆ A ∪ RevAdd` 且 `A' ∩ I_irr ⊆ A ∩ I_irr`。若安全盾允许集对取子集封闭、且可逆增补经同一 `shield` 构造，则第 3 轮安全不变量 `Inv` 保持；`ρ<τ` 时 `A'=A`，腕部不改变任何决策。
*证明骨架*：按角色逐个情形讨论。`veto` 只减不增，子集保持 `Inv`（引理 52 的盾归纳）。`originate` 仅可逆且过 `shield`，故仍在 `𝔸_adm`。不可逆列被显式排除，`DualAuth` 是两个 `verify` 的合取，不引入新动作。类型层拦截越权，故不存在「传感器悄悄扩权」的路径。

**引理 60（校准可靠度 ⇒ 选择性风险控制）** 设层内样本可交换、`ρ` 经定义 450 校准、`τ̂` 由定义 454 的 LTT 在候选网格上以 Hoeffding–Bentkus 上界选出，并对 `|grid|` 做 union bound。则 `P(SR(τ̂) ≤ α) ≥ 1−β`。跨层时
`SR ≤ Σ_s π_s·SR_s + Σ_s π_s·TV_s`；
冷层回退全局时覆盖按 `−2η_global` 降级。由 E457/E458/E461 检验。
*证明骨架*：每固定 `τ`，Hoeffding–Bentkus 给 `SR(τ)` 的单侧 `1−β/|grid|` 上界；取满足上界 ≤ α 的最大 `τ`，事件「所选 `τ` 的真风险 > α」被包含于某个候选违反事件之并，概率 ≤ β。跨层用三角不等式把层内界与 TV 漂移相加。

**引理 61（鲁棒融合的污染界）** 设腕部单帧似然以 `ε_w` 污染、门控权重 `w_w ≤ 1`、污染支撑相对真似然上界 `M = sup_x U(x)/p_w(x)`。则单帧对数似然后验比的扰动满足
`|Δ log LR| ≤ w_w·log((1−ε_w) + ε_w·M) ≤ w_w·ε_w·(M−1)`。
故污染对决策的影响**线性**于 `w_w·ε_w`，且 `w_w=0` 时严格退化为基线融合（误差 = 0，而非小量）。
*证明骨架*：`p̃/p = (1−ε)+ε(U/p) ≤ (1−ε)+εM`，取对数并用 `log(1+z)≤z`；权重把单帧界按凸组合累加。`w_w=0` 使腕部因子恒为 1，乘积只剩基线模态。

**引理 62（运动门控捕获的可行性与 dwell 界）** 若允许 `dwell`，则在任意时刻可在
`T_dwell ≤ T_settle(V_max) + T_exp`
内取得 `b ≤ b_max` 的帧，其中 `T_settle` 为把末端速度从 `v` 降到 `V_max` 的最短时间（受减速度上界约束）。若禁止 `dwell`，则可捕获窗口长度
`|W_cap| ≥ 2·V_max / a_max`
（三角速度剖面下），窗口存在性要求轨迹在块边界经过低速段。特别地，`q_quiesce` 处 `v=0`，`b=0 ≤ b_max`，捕获必然可行。
*证明骨架*：模糊模型 `b=κvT_exp/d_feat` 对 `v` 单调；令 `v≤V_max` 即得。dwell 下用恒定减速度积分求 `T_settle=(v−V_max)/a_max`。`q_quiesce` 由第 3 轮定义 439 保证 `v=0`，故 `b=0`。

**引理 63（手眼漂移检测延迟与几何误差界）** 设漂移发生后残差近似线性增长 `r_t ≈ r_0 + γ(t−t_0)`，CUSUM 参考值 `k < γ`。则检测延迟
`n_det ≤ ⌈h/(γ−k)⌉ + n_0`。
若局部几何误差对残差 `L`-Lipschitz，则检测前误差
`e_geo ≤ L·(r_0 + γ·n_det)`；
检测后自校准成功则回落至 `L·r_0`，失败则 `Ĥ` 被降级、误差不再进入执行路径。
*证明骨架*：标准 CUSUM 检测延迟界；Lipschitz 传播直接放缩。自校准的成功判据要求新残差低于 `r_0 + η_cal`，否则返回失败。

**引理 64（共因独立性修正）** 设腕部与外置的失效事件分别为 `F_w, F_e`，共因事件 `CC` 发生时两者同时失效，且 `P(CC)=π_cc`；在 `¬CC` 条件下独立。则
`P(F_w ∩ F_e) = π_cc + (1−π_cc)·q_w·q_e ≥ q_w·q_e`。
故并联验证的联合失效概率至少被 `π_cc` 托底；仅当条件化 `CC`（可检测）或引入不共享 `CC` 的独立模态 `m⊥` 时，才恢复
`P(F_w ∩ F_e ∩ F_{m⊥}) = π_cc·q_{m⊥} + (1−π_cc)·q_w·q_e·q_{m⊥}` 的乘性收益。推论：「多一个传感器」不等于「更可靠」，除非失效模式真的不同。
*证明骨架*：全概率公式按 `CC` 与 `¬CC` 分解；`CC` 下两模态同失效概率为 1。条件化或独立模态把乘积结构恢复。E468 用光照突变注入验证。

**引理 65（逐指令退化等价）** 当 `ρ_wrist < τ`、腕部掉线、捕获不可行或 `M=EXTERNAL_ONLY` 时，定义 453 的 `w_wrist=0`、`M=EXTERNAL_ONLY`，且 `authorize` 对腕部返回 `Advisory`，不进入执行路径。此时 EyeGauge-8C 的 `S` 段恒等、证据融合精确等于 InstructGauge 的多模态后验，决策序列与 InstructGauge-7C **逐指令相同**；新增 `receipt_w` 在序列化时作为可选字段投影，不改变数值行为。
*证明骨架*：对决策时刻归纳。基态 `w_wrist=0 ⇒ p(x|E)` 与非腕部后验逐项相等；权限格把腕部移出执行路径；`CVC/APCal/MReg` 调用次序与 7C 相同。故归纳步保持等价。

**引理 66（可靠性预算的单调性与次模收益）** 若各模态的期望信息增益对预算满足边际递减（自适应次模），且失效惩罚为线性，则总收益 `G(B)` 单调非减且次模；贪心分配达到 `(1−1/e)·OPT`。增加总预算不降低可达可靠性下界。
*证明骨架*：次模函数的边际收益递减；经典贪心近似界；单调性由可行集扩张给出。E465 检验。

**引理 67（50Hz 时延保全）** 腕部特征与可靠度计算异步下沉（30–60Hz，独立线程/加速器），融合与权限判定只在 `q_quiesce`/提交边界发生；主循环内联增量仅为 `O(|z|)` 的查表与门控，`< 0.1ms`。捕获调度复用第 3 轮已有的静默点，不新增同步等待。故继承 ToolGauge 引理 50 的硬实时结论，99.9% 周期 `< 20ms`。
*证明骨架*：把内联路径的算子逐个计价；异步路径不在 50Hz 关键路径上；融合只在边界执行，频次与块长成反比。E471 验证。

## 9. 本轮最大风险

**一句话**：`RCW` 的可靠度与 `RCS` 的风险控制都建立在「校准集与部署工况可交换」之上，而腕部相机恰恰工作在分布最易漂移的近距离（光照、污染、温漂、反光材质）；一旦可靠性契约在 OOD 下静默失效，系统会以高 `ρ` 自信地**否决正确动作**或**佐证错误动作**，共因失效还会让「腕部 + 外置」同时失准。真正的残余风险是**可靠性估计器自身的不可靠**——缓解只能靠契约过期、分层 CUSUM、独立模态双授权与 E457/E461/E468/E472 的主动证伪，而不能靠把腕部相机做得更清晰。
