# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「场景理解」×「演示数据」）

> R69 把不确定性一分为二：aleatoric 收紧、epistemic 去问；并给了系统「看 / 问 / 触」三种可认证、可审计的信息动作。但 R69 的 epistemic 不确定性是**定义在动作模态上的**：它把 K 条流采样轨迹聚类成 {m_k}，再对这些模态算熵与间距。这里藏着一个从未被检验的假设——**动作的多峰性是原因的起点，而不是结果的投影**。
>
> 实际上，「绕左还是绕右」之所以是两个模态，几乎从来不是因为策略在动作空间里随机抖出了两条路，而是因为世界本身有两个**场景解释**：「那摊反光的是水，还是窗影？」「那个挡住通道的是可移开的椅子，还是固定的人？」**动作歧义是场景理解歧义的影子。** R69 对着影子提问：它问「绕左还是绕右」，却没有问「你看到的是水还是影子」。更糟的是，R69 无法区分两类完全不同的多峰：**（a）真实的场景歧义**，与 **（b）流模型在有限数据上幻觉出来的伪模态**。二者在动作空间里长得一模一样，但在场景假设空间里完全不同——前者对应两个物理上可区分、可验证的世界，后者对应一个不存在的世界。
>
> 本轮两个灵感各补上一块：
> - **场景理解**把「歧义」从一个动作分布的几何事实，还原成一个**关于世界的假设集合**（物体/关系/自由空间/可供性/意图），并允许系统先做**动作充分的约商**：只在「换成另一种解释就会改变风险」的地方保留不确定性，其余的场景细节一概不追问。
> - **演示数据**提供了唯一一种「人类在相似场景里实际看见了什么、做了什么」的经验证据：它既能当**先验**去剪掉不可能的 scene hypothesis，也能当**覆盖尺**去度量「我对这个场景到底有没有资格自信」，还能当**反事实弱标签**去校准场景理解。但演示数据不是真值——它有习惯偏差、示教者错配、覆盖幻觉与投毒。
>
> 核心命题：**把 epistemic 不确定性的载体从「动作模态」上移到「动作充分等价类上的场景假设」；用演示数据在“有覆盖、且与物理/模型先验一致”的地方锚定场景后验；把 VoI 从“熵减”改为“后悔减（EVPI）”，从而自动拒绝一切不改变风险的无谓追问；一旦演示不可信、覆盖不足、或场景后验越界，逐指令退回 R69，再退回 R68。** 命名 **DEMOS-RAS**（Demonstration-anchored, Evidence-calibrated Multi-hypothesis Operational Scene reasoning for Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我到底在问哪一个世界，而有没有一个可信的人在这个世界里演示过**」——R69 学会提问，R70 学会**先想清楚问题属于哪个世界，再决定值不值得问**。

## 0. 直觉与动机

**灵感 1（场景理解 → 动作多峰是场景歧义的投影，不是原因）**
直觉：一个自信的司机不会「在两条轨迹之间犹豫」；他犹豫的是「前面那滩到底是不是水」。一旦看清是水，动作立刻唯一。把动作模态当 primitive，等于把「结论的分歧」当成「原因的分歧」，于是：
- **无法归因**：同一个动作模态可能由多个完全不同的 scene hypothesis 支撑（绕左，可能是因为左边可通行，也可能是因为右边有玻璃门但看起来像通道）；R69 的 VoI 无法知道该验证哪一个。
- **无法共享证据**：场景假设是**组合式**的（同一组物体假设解释多个时刻、多个动作），而动作模态是**一次性**的；R69 每遇到一次歧义就重新采样、重新聚类、重新问，证据不能跨时间复用。
- **无法拒绝伪模态**：流模型在 OOD 场景下会生成低密度伪模态；用动作聚类无法把它与真实歧义分开。场景假设一旦显式化，「这个解释是否有物理支撑」就变成一个可检验的问题。
因此本轮把世界表示为**场景假设** h（物体与属性、关系、自由空间拓扑、可供性、他者意图），策略是 h 的条件分布；动作多峰是 h 边缘化后的**投影**。不确定性从此有了可归因、可组合、可验证的载体。

**灵感 2（动作充分的商空间 → 不是所有场景细节都值得知道）**
直觉：人不会为了决定「走左边还是右边」去分辨地砖的花纹。场景理解的分辨率应当由**决策**决定，而不是由感知网络愿意输出多少类别决定。对 h 定义一个等价关系：若两个场景假设诱导出的**动作分布与风险集**在容差内相同，则它们属于同一「动作充分类」。只在商空间 Q = H/~ 上保留 epistemic 不确定性。这一步带来三个直接收益：
- **问得更少**：大量场景细节被自动折叠，VoI 精确为零；
- **问得更准**：一个查询只要分开两个**风险不同**的等价类，而不是分开两个语义标签；
- **安全可证**：等价类直接携带安全集，选择动作不需要先相信某个完整的世界模型。
这也是本轮对 R69 最锋利的修正：R69 的模态聚类是场景假设空间的一个**粗化**（coarsening），既可能把两个不同原因压成一个模态，也可能把一个真实原因拆成两个伪模态；商空间是**按决策后果**做的粗化，方向正确得多。

**灵感 3（演示数据 → 人类已经替我们做过的场景实验）**
直觉：示范不是「动作标签」，而是「在某个场景解释下，一个有能力的人选择了什么」。因此它至少提供三种东西：
1. **先验剪枝**：若大量示教在相似场景里都把人形轮廓解释为「人」并绕行，则把「那是衣架」的先验压低；
2. **覆盖尺**：演示数据在（场景, 行为）联合空间中的局部密度，定义了「我有资格对这个场景多自信」；覆盖不到的地方，任何场景后验都必须膨胀；
3. **反事实弱标签**：当两个 scene hypothesis 都有模型支撑时，示教者的选择本身泄露了他相信哪一个——通过逆规划（inverse planning）把示范转成对 h 的弱证据。
关键在于：**演示数据不是用来直接抄动作的**（模仿学习早已证明这在分布外会自信地错），而是用来**校准关于场景解释的先验与置信半径**。这把「演示数据」从策略层上移到了认识论层。

**灵感 4（演示数据也是新的毒源 → 「有据可查」不等于「有事实支持」）**
直觉：R69 的最大风险是「问错，比不问更危险」；R70 把它升级了一格：**「有一个看起来权威的人类演示为你的错误背书」，比单纯问错更难被审计。** 演示数据至少有五种坏法：
- **习惯偏差**：示教者总走右边，不是因为场景，而是因为习惯；逆规划会把习惯误读成场景证据；
- **覆盖幻觉**：简单场景录了一万条，困难场景只有两条；局部密度在真正需要的地方恰好为零，而全局统计看起来「数据很多」；
- **示教者错配**：示范来自不同本体 / 不同代价函数 / 不同安全约束；动作最优不代表场景解释正确；
- **投毒**：故意在关键场景注入「局部密集且自洽」的示范，让系统对错误假设产生高置信；
- **洗白（demo laundering）**：一个不安全动作只要在示范里出现过，就可能被系统当作「人类认可」而绕过保守退避。
所以本轮必须同时交付：覆盖感知的可信度上界、演示-模型一致性门、来源与去重审计、「演示不得单独定案」的证据纪律，以及一条硬规则——**演示数据只能让系统更敢做，不能让它更敢信**（敢做由安全认证与后悔界约束，敢信由覆盖与一致性约束）。

**灵感 5（熵是决策盲的 → VoI 应当是后悔减，而不是熵减）**
直觉：R69 用 H(M) 的下降来度量信息价值。但熵只关心「分布有多散」，不关心「散开的地方是否改变决策」。两个反例：
- 两个场景假设概率各 0.5，但**无论哪个为真，最优动作与风险完全相同**——熵很高，VoI 精确为零；R69 会去问一个毫无意义的问题。
- 99 个假设概率 0.01、都无关紧要，1 个假设概率 0.01 却意味着「前方是悬崖」——熵很低，EVPI 很大；R69 会低估这次追问的价值。
正确的量是**期望后悔的下降**（expected value of perfect information, EVPI）：先算当前后验下的 Bayes 风险，再算「做完这次观测后的期望 Bayes 风险」，二者之差才是信息价值。它天然是非对称代价、稀有灾难与动作等价类都正确的。R70 因此把 R69 的 `H(M|o) − E[H(M|o,y)]` 替换为 `B(p) − E_y[B(p(·|y))]`，并把 R69 恢复为「风险为均匀 0-1 模态损失」时熵型 VoI 的边界情形。

**灵感 6（严格包含 + 新攻击面 → 层级不可倒置）**
直觉：DEMOS 必须像前几轮一样**包含** R69/R68，否则每加一层就多一个需要独立信任的黑箱：
- 当场景假设空间退化为动作模态本身（h ≡ m_k）、演示先验关闭、且风险为均匀模态错配损失时，DEMOS 的 EVPI 与熵减单调等价，**逐指令等于 R69**；
- 当 EVPI ≤ 成本，或场景后验只有一个动作充分类，或演示/场景证据不可信时，不交互，退回 R69；
- 当模态歧义也为零时，退回 R68 的纯保守。
新的攻击面也随之出现：**用演示数据制造伪场景先验**（让系统相信一个不存在的世界）、**覆盖投毒**（在关键场景把密度做高）、**来源重放**（复制少量示范伪造多样性）、**提问诱导**（通过示范让系统问出一个引导性问题）、**场景假设空间劫持**（只提出对攻击者有利的候选 h，使商空间本身被污染）。**一个学会「理解场景」的系统，也会被诱导着「理解错场景」。**

## 1. 形式化定义（增量：定义 310–325）

**定义 310（DEMOS-RAS 总览）** DEMOS-RAS = (SHR, DAG, BUS, ASQ, RVI, SCQ, SCE, RAS-WM‡)。五条不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i / R68 定义 276-i）；
(ii) **演示不得单独定案**：任何由演示数据产生的置信提升，必须同时通过覆盖门（定义 315）、一致性门（定义 316）与 k 正交证据纪律（定义 319）；
(iii) **决策相关性**：只有当两个场景假设属于不同动作充分类、且后悔型 VoI 为正时，才允许发起场景探询（定义 313、317）；
(iv) **行动许可与信念许可分离**：演示数据可以提高「敢做」的程度（resolution bonus），但永远不能单独提高「敢信」的程度（后验锐化）；
(v) **安全单调退化**：场景/演示/查询任一不可用或不可信时，逐指令退化为 R69；R69 再退化为 R68。

**定义 311（场景假设空间 SHR）** 一个场景假设
h = (O_h, R_h, F_h, A_h, I_h)，
其中 O_h 为物体及其属性的赋值，R_h 为物体间关系（支撑、遮挡、包含、从属），F_h 为自由空间拓扑（可通行 / 不可通行 / 可移开 / 未知），A_h 为可供性（可抓、可坐、可推、可穿越），I_h 为他者意图/角色。候选集 H(o) = {h_1,…,h_N} 由一个场景图因子图提出：符号骨架（离散）加连续参数（位姿、尺度、可通行概率）。模型先验 p_0(h|o) ∝ exp(−E_0(h,o))，E_0 为场景图能量。允许 H(o) 只覆盖被感知网络显式提出的假设——这一点本身是本轮的风险来源（定义 324）。

**定义 312（行为诱导与风险泛函）** 每个 h 诱导一个条件动作分布 π_θ(ξ | h, o)（R69 的流匹配策略以 z_t 与 h 的嵌入为条件），以及一个安全集 S(h,o) ⊆ 𝒜_+ 与一个风险泛函 r(a,h)（期望碰撞/倾覆/越界/社交侵犯的加权和）。记 r*(h) = min_{a∈S(h,o)} r(a,h) 为「知道 h 后的最优风险」。注意 r 是**非对称**的：漏掉悬崖型假设的代价远大于一次保守绕行。

**定义 313（动作充分等价与商空间 ASQ）** 对容差 (ε_a, ε_r)，定义
h ~_{ε} h′ ⇔ TV( π_θ(·|h,o), π_θ(·|h′,o) ) ≤ ε_a 且 |r*(h) − r*(h′)| ≤ ε_r。
商空间 Q = H(o)/~_{ε}，其元素称为**动作充分类** q，代表元 h_q，后验质量 w_q = Σ_{h∈q} p(h|o)，类风险 r*_q = r*(h_q)。将场景层面的 epistemic 不确定性定义为
U_epi^scene = Σ_q w_q · clip( (r*_q − r*_min) / R_max, 0, 1 )，
其中 r*_min = min_q r*_q，R_max 为风险归一化常数。**这与熵不同：一个概率很高但风险与最优类相同的类，对 U_epi^scene 贡献为零。** 模态内不可约的 U_ale 仍沿用 R69 定义 297（模态内协方差迹），二者继续分通道处置。

**定义 314（演示锚 DAG）** 演示集 D = {(o_i, ξ_i, c_i, prov_i)}_{i=1}^n，c_i 为上下文（本体、任务、代价档、时间），prov_i 为来源/采集/版本证明。在（场景, 行为）联合嵌入 φ(o,ξ) 上定义检索核 k_i = K(φ(o,ξ), φ(o_i,ξ_i))。局部有效样本量
n_eff(o) = (Σ_i k_i)² / Σ_i k_i²
（近重复示范只计一次，抵抗「重放伪造覆盖」）。演示先验由逆规划给出
p_D(h|o) ∝ Σ_i k_i · p(ξ_i | h, o_i) · p(h | o_i) / p(ξ_i | o_i)，
即「若 h 为真，示教者做出 ξ_i 的似然」对 h 的加权投票。演示信任权重 τ_D ∈ [0, τ_max] 由定义 315–316 决定，且 τ_max < 1 是硬上界：**演示永远不能把后验压成点质量**。

**定义 315（覆盖与可信半径 BUS）** 记 ρ_D(o) 为场景嵌入到第 k 近邻示范的距离（覆盖半径），s_D(o) 为到演示流形的距离（OOD 分）。演示先验**仅在覆盖有效区**内有资格：
ValidCov(o) ⇔ n_eff(o) ≥ n_min ∧ ρ_D(o) ≤ R_max ∧ 来源多样性 ≥ m_min。
未覆盖时强制 τ_D = 0，并对场景后验做覆盖膨胀：
p ← (1−κ) p + κ · p_0，κ = clip( (n_min − n_eff)/n_min + [ρ_D > R_max], 0, 1 )。
覆盖半径给出一个显式的**置信半径**：演示能支持的场景判别分辨率不可能细于 ρ_D（引理 21）。

**定义 316（一致性门 CG）** 演示先验必须与不看演示的模型先验及物理不变量一致：
χ_D = D_f( p_D(h|o) ‖ p_0(h|o) )，ν_D = 物理不变量违反量（支撑关系、自由空间连通性、动量可行性）。
若 χ_D > τ_coh 或 ν_D > 0：演示先验降权 τ_D ← τ_D · γ（γ<1），并在证书中标记 suspect；降权后仍不一致则 τ_D=0。**一致性门的作用不是证明演示正确，而是阻止演示单方面改写世界。**

**定义 317（后悔型 VoI：RVI）** 对后验 p 定义 Bayes 风险
B(p) = E_{h∼p}[ r*(h) ]。
对候选信息动作 g，令 p(·|o,y,g) 为观测到 y 后的后验，则
EVPI(g) = B(p) − E_{y∼p(·|g,o)}[ B( p(·|o,y,g) ) ]，
η(g) = EVPI(g) − c(g) − r_int(g)，
其中 c(g) 为时间/社交/能量成本，r_int(g) 为探询本身的物理风险。选择
g* = argmax_g η(g)，仅当 η(g*) > 0 时执行；否则不交互。
**性质**：若所有 h 属于同一动作充分类（r* 相同），则 EVPI ≡ 0，无论熵多大；若存在小概率高后悔假设，EVPI 会把它计入。R69 的熵型 VoI 在「风险为均匀 0-1 模态错配损失」时与 EVPI 单调等价（见定理 18）。

**定义 318（场景探询动作 SCQ）** 信息动作 g = (g_gaze, g_probe, g_ask) 带有显式观测模型 p(y | h, g)。查询不再是「最大熵的模态对」，而是**后悔加权的最优判别对**：
(q, q′) = argmax_{q≠q′} [ (r*_q − r*_q′)^+ · JSD( p(y|h_q,g) ‖ p(y|h_q′,g) ) ]，
g* = argmax_g [ EVPI_g(q,q′) − c(g) − r_int(g) ]。
语言问句一律在**反事实动作空间**中构造，而不是在原始语义标签空间中构造：不问「那是水吗？」（人类本体与感知本体可能错位、且答案难以验证），而问「如果那是水，我会绕左；如果是影子，我直行——你看到的是哪一种？」。这样人类回答天然带有决策语义，且可被后续行为交叉验证。问句由冻结 LLM 从对比提示解码，梯度不回传语言模型。

**定义 319（演示-场景证据纪律 DTA）** (i) 演示是**一个**证据源，任何单一演示（或单一模态回答）不得单独把某个 q 定案；需 k 个正交证据源（几何、时序、物理不变量、人类回答、示范）多数一致，或 EVPI 加权增益超过高置信阈值。(ii) **反事实一致性**：演示隐含的 h 必须能预测当前观测的关键后果（例如「示范绕行水洼」应预测当前该位置可通行性低）；预测失败则对该演示降权。(iii) **去重与来源审计**：n_eff 抑制重放；prov 缺失/冲突的演示不参与先验，只能进入离线审计。

**定义 320（演示投毒干扰集 ℰ_demo）** ℰ_demo = {习惯偏差, 伪相关, 覆盖投毒, 来源/标签篡改, 示教者本体/代价错配, 演示重放泄漏, 演示洗白（用示范为不安全动作背书）}。并入 AIC：ℰ_DEMOS = ℰ_FLUID × ℰ_CALM × ℰ_demo。对每一类给出对应的检测器：覆盖熵、来源哈希、反事实一致性残差、与模型先验的 KL、动作安全集的包含检验。

**定义 321（信任阶梯与逐指令退化）** 定义五级阶梯，级数越低越保守：
L0 场景 + 演示均可信且 EVPI>0 → 完整 DEMOS；
L1 演示不可信/缺失/覆盖不足 → τ_D=0，仅用 p_0 做场景后验；若场景仍可分则保留 DEMOS 的商空间与后悔 VoI，否则进入 L2；
L2 场景假设不可辨识，或 H 退化为动作模态本身 → 逐指令调用 R69（samples 的模态即 h）；
L3 无正 EVPI / 只有单一动作充分类 → 不交互，动作选择与 R69 相同；
L4 任何一致性失败、标定越界或查询不安全 → 逐指令退化为 R68 纯保守（λ=λ_floor(U_ale+U_epi)，k 收缩）。
**逐指令退化**：L2 且风险为均匀 0-1 模态错配损失时，DEMOS 的决策函数与 R69 完全相同；L3 且模态歧义为零时与 R68 相同。

**定义 322（证书 J_DEMOS）** J_DEMOS = (J_FLUID, scene_ece, class_count, w_q 分布, n_eff, ρ_D, s_D, demo_coherence_χ, evpi_ratio, demo_provenance_hash, poison_audit, demos_ver)。Valid ⇔ Valid(J_FLUID) ∧ scene_ece ≤ τ_sce ∧ 演示证据纪律满足 ∧ 已执行查询 η>0 ∧ 覆盖未越界（或已按定义 315 膨胀）。

**定义 323（场景校准门 SCE）** 对场景分类与动作充分类的后验分别做可靠性校准，得 ECE_scene。若 ECE_scene > τ_sce，禁用场景条件化的 VoI（因为商空间的划分不可信），退回 R69 的动作模态通道；若仅类别校准差但风险序保持，可保留商空间但禁用演示先验。校准门是「场景理解会骗人」时的总闸。

**定义 324（任意时间场景深度与假设空间风险）** 场景假设默认只取 top-1（p_0 最大者），仅当 mode_head 报歧义且 EVPI 上界 > 成本时扩展到 N≤8 个假设，并做由粗到细的因子图展开。显式承认**假设空间完备性风险**：若真场景不在 H(o) 中，则任何商空间、任何 VoI 都建立在错误支撑上；因此定义 325 的第三通道用于检测「所有候选都解释不了观测」的情形，检测到即进入 L4。

**定义 325（残差-似然-演示三通道对偶）** 三个诊断通道：
- r_res：传感器残差（R68，测「测量自洽」）；
- Δa：流策略行为似然差（R69，测「行为自洽」）；
- Δ_D = D_f( p_D(h|o) ‖ p(h|o,ξ_obs) )（测「演示-行为-场景三者互洽」）。
联合模式给出归因表：(r_res↓, Δa↑) ⇒ 缓变故障被标定吸收（R69 引理 17）；(Δa↓, Δ_D↑) ⇒ 示教者错配或场景先验偏置；(Δa↑, Δ_D↑) ⇒ 假设空间不完备 / OOD；(三者皆↑) ⇒ 系统性故障，进入 L4。这是 R68 反吸收引理与 R69 交互-校准对偶的第三面镜像。

# IP-264 SHR：场景假设生成（复用 R69 trunk 的 z_t + 场景图因子图头）
class SceneHypothesisReasoner:
    def propose(self, o_t, z_t):
        # 符号骨架（物体/关系/自由空间/可供性/意图）+ 连续参数
        H, logits = self.scene_graph_head(o_t, z_t)
        return H, softmax(logits)                 # h_i, p0(h_i|o)

# IP-265 DAG：演示锚（检索 + 逆规划 + 覆盖）
class DemoAnchor:
    def anchor(self, o_t, H):
        idx, w = self.retrieve(phi(o_t))          # 联合嵌入最近邻
        n_eff = (w.sum()**2) / (w**2).sum()       # 去重
        p_D = self.inverse_plan(H, idx, w)        # 示范对 h 的弱标签
        rho = self.coverage_radius(o_t)
        ok  = (n_eff >= self.n_min) and (rho <= self.R_max) and self.diverse(idx)
        tau = self.trust * min(1.0, n_eff / self.n_min) * float(ok)
        return p_D, tau, n_eff, rho

# IP-266 BUS + CG：覆盖膨胀 + 一致性门，绝不让演示单方面改写世界
def fuse_scene_prior(p0, p_D, tau, n_eff, rho):
    chi = kl(p_D, p0)
    if chi > TAU_COH or physically_inconsistent(p_D):
        tau = 0.0                                  # 一致性失败：演示失去资格
        return p0, tau, chi
    if n_eff < N_MIN or rho > R_MAX:               # 覆盖不足：回缩 + 膨胀
        kappa = coverage_kappa(n_eff, rho)
        p = (1 - kappa) * p0 + kappa * p0_dominant(p0)
        return p, 0.0, chi
    p = renormalize(p0**(1 - tau) * p_D**tau)      # 几何融合，tau < 1
    return p, tau, chi

# IP-267 ASQ：按动作充分性做商，只在会改变风险处保留不确定性
def action_quotient(H, p, policy, risk):
    Q, w = [], []
    for h in H:
        pi_h = policy.pi_given_scene(h)
        r_h  = risk.optimal(h)                     # r*(h)
        for q in Q:
            if tv(pi_h, q.pi) <= EPS_A and abs(r_h - q.r) <= EPS_R:
                q.add(h, p[h]); break
        else:
            Q.append(Class(h, pi_h, r_h, p[h]))
    U_epi = sum(q.w * clip((q.r - r_min) / R_MAX, 0, 1) for q in Q)
    return Q, U_epi

# IP-268 RVI：后悔型 VoI（EVPI），熵盲点在此被消除
def choose_scene_query(Q, p, risk, budget):
    B = bayes_risk(Q, p, risk)
    best = None
    for g in scene_query_candidates(Q):            # 注视 / 探针 / 反事实问句
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        evpi = B - expected_bayes_risk(Q, p, g, risk)
        score = evpi - cost(g) - risk_int(g)
        if best is None or score > best.score: best = (g, score, evpi)
    return best if best and best.score > 0 else None   # 无后悔可减 → 不交互

# IP-269 SCQ：反事实动作空间问句（人类回答自带决策语义）
def make_query(q, q2, o, llm):
    note = f"若 {q.name} 为真我会 {q.safe_action}；若 {q2.name} 为真我会 {q2.safe_action}。"
    return llm.decode_contrastive(note, o)         # 冻结 LLM；解码侧安全过滤

# IP-275 主闭环（继承 R69；仅在不确定性载体与外层预算处替换）
def DEMOS_RAS_round(M, obs):
    z, o = M.mtm.forward(...)
    c, U_cal, thr = M.cof.step(...)                # R68 标定
    H, p0 = M.shr.propose(o, z)                    # 1) 场景假设

    p, tau, chi = M.bus.fuse(p0, pD, tau, n_eff, rho)   # 3) 融合 + 门控
    Q, U_epi_s = M.asq.quotient(H, p, M.fmp, M.risk)    # 4) 动作充分商
    if len(Q) == 1 or tau == 0.0:

    samples = M.fmp.sample_scene(o, Q, p, K=M.adaptive_k(Q))
    U_ale, U_epi, modes = M.aud.decompose(samples)
    if g is not None and U_epi_s > TAU_EPI:
        ans = M.scq.execute(g)                     # 6) 认证后的看/探/问
        p   = M.scq.update(p, ans, discipline='k_orthogonal_agree')

    M.vqa_d.submit_async(g, ans, (n_eff, rho, chi, tau))   # 9) 演示/交互审计

## 3. 推导

**引理 19（动作充分商的无损性）** 若 h 与 h′ 满足 (ε_a, ε_r)-等价，则把二者合并为一个类后，任何候选查询的 EVPI 变化不超过 ε_r + L_r·ε_a，且 Bayes 风险变化不超过同一量级（L_r 为 r 对动作分布的 Lipschitz 常数）。因此，在同一个动作充分类内部提问，其 VoI 被 (ε_r + L_r ε_a) 界定；取 ε→0 时为零。**系**：R69 的动作模态聚类是场景假设空间的一个固定粗化；它可能把不同原因合并（丢失可归因性），也可能把一个原因拆开（制造伪模态），而动作充分商是按决策后果做的粗化，既不丢后悔、也不问无关细节。

**引理 20（熵不决定后悔）** 记 R_max = max_{h,a} r(a,h)。
(i) 若所有 h 的 r* 相同而 p 的熵为 H_0>0，则 EVPI = 0，而熵型 VoI 可以为正——熵型 VoI 会发出无价值的查询。
(ii) 若存在概率为 δ 的假设使 r* 比其余高 G，则 EVPI ≥ δ(1−δ)·G（上界为 R_max·H(p)/log|H| 的相应形式），而当 δ 很小时熵几乎不变——熵型 VoI 会低估这次查询。
故 EVPI 是决策相关的信息价值，熵是其「与风险无关的影子」。**系**：R69 在非对称代价、稀有灾难、动作等价类三种情形下都可能问错或问漏；R70 的 RVI 三条都自动处理。

**引理 21（演示覆盖的误差半径）** 设演示在（场景, 行为）空间局部密度满足 n_eff 个有效样本，示教偏差为 b_D（习惯/本体/代价错配引起的系统偏移），则演示先验相对真实场景后验的 TV 误差满足
‖p_D − p_true‖_TV ≤ √( (1−ρ_loc) / (2 n_eff) ) + b_D + O(ρ_D)，
其中 ρ_loc 为局部混合系数、ρ_D 为覆盖半径。**系**：演示能支持的置信分辨率不可能高于覆盖尺度；离开覆盖区（n_eff↓ 或 ρ_D↑）时，任何由演示产生的锐化都没有统计资格——这就是定义 315 强制膨胀的依据。

**引理 22（演示投毒上界与一致性门）** 设被投毒演示的质量占比为 δ_D，信任上界为 τ_max<1，一致性门阈值为 τ_coh，则单个投毒源对后验的 KL 推动量不超过 τ_max·δ_D·L_D（L_D 为融合算子对演示分布的 Lipschitz 常数）；若 χ_D > τ_coh，门控令 τ_D=0，推动量归零。在 k 个正交来源多数一致纪律下，错误类采纳率 ≤ δ_D τ_max ρ^{k−1} + ε_σ（ρ<1 为来源间欺骗相关）。**诚实边界**：若攻击者能同时伪造「局部高覆盖 + 来源多样 + 与模型先验自洽」的演示，则一致性门无法分辨，此时上界退化为 δ_D τ_max，只能靠离线来源审计与安全集包含检验兜底。

**定理 18（DEMOS 严格包含 R69/R68，且改善有代价）** 在边界设定「h ≡ 动作模态 m_k、τ_D=0、风险为均匀 0-1 模态错配损失」下，EVPI 与 R69 的熵减单调等价，RVI 选择的查询与动作与 R69 逐指令相同；当 EVPI ≤ 成本时二者均不交互；当模态歧义为零时二者均逐指令等于 R68。一般情形下，
Regret(DEMOS) ≤ Regret(R69) + 2·L_r·ε_scene，
其中 ε_scene 为场景假设空间/校准误差。**因此 DEMOS 不是无条件更优**：它把 R69 的「模态可信度」风险替换为「场景假设完备性与演示可信度」风险，并由 SCE（定义 323）、CG（定义 316）与假设空间检测（定义 325）共同约束 ε_scene。这个显式的替换关系，是本轮不宣称「免费午餐」的关键。

**定理 19（不产生虚假确定性 + 安全单调）** 在 CG、覆盖膨胀与证据纪律同时生效时，对任意置信阈值 1−α ≥ 1−α_floor，后验满足 P(真假设被采纳 | 置信 ≥ 1−α) ≥ 1−α−ε；且控制增益满足
λ_DEMOS ≥ λ_floor(U_ale + U_epi) ≥ λ_R68 的对应下界，
即演示与场景证据只能通过「已消解的 U_epi」获得 resolution bonus，绝不能把 λ 压到 R68 安全下界以下。任一证据源失效时，λ 单调不降地沿定义 321 的阶梯回退。**系**：演示数据可以买效率，不能买安全；「有据可查」不被兑换成「可以更冒险」。

## 6. 本轮最大风险

**一句话**：DEMOS-RAS 把效率收益押在「演示数据能代表这个场景、且场景假设空间包含真相」这一双重前提上——**若演示被偏见、错配或投毒塑造成局部密集又自洽的伪先验，或真场景根本不在候选 H(o) 中，系统就会以“有人类背书”的名义自信地相信一个错误的世界，并据此提出错误但看似合理的追问；这种错误恰好能穿过一致性门、覆盖门与证据纪律，比 R69 的“问错”更难审计——因为这次连证书都是用演示数据自己签发的。**

**次级风险与缓解**：
1. **覆盖幻觉/重放伪造** → n_eff 去重 + 来源多样性门槛 + E305/E306；

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** DEMOS-RAS 总览；继承零学习写操作；演示不得单独定案；无决策相关性不得查询；行动许可与信念许可分离；安全单调退化到 R69→R68。

**定义 311（场景假设）** h=(O,R,F,A,I)；H(o) 由场景图因子图提出；先验 p_0∝exp(−E_0)。显式承认假设空间可能不完备。

**定义 312（行为诱导与风险）** 每个 h 诱导 π_θ(ξ|h,o)、安全集 S(h,o) 与非对称风险 r(a,h)；r*(h) 为知 h 后的最优风险。

**定义 313（动作充分商 ASQ）** h~_ε h′ ⇔ TV(π(·|h),π(·|h′))≤ε_a 且 |r*(h)−r*(h′)|≤ε_r；Q=H/~_ε；U_epi^scene 按类风险超额加权，而非熵。

**定义 314–315（演示锚与覆盖）** D={(o_i,ξ_i,c_i,prov_i)}；k_i 为联合嵌入核；n_eff 抗重放；p_D 由逆规划给出；ValidCov ⇔ n_eff≥n_min ∧ ρ_D≤R_max ∧ 来源多样；未覆盖则 τ_D=0 并膨胀 p←(1−κ)p+κp_0。

**定义 316（一致性门 CG）** χ_D=D_f(p_D‖p_0)、ν_D=物理不变量违反量；超阈即降权 γ，仍不一致则 τ_D=0。作用是阻止演示单方面改写世界。

**定义 317（后悔型 VoI RVI）** B(p)=E_p[r*(h)]；EVPI(g)=B(p)−E_y[B(p(·|y,g))]；η=EVPI−c−r_int；仅当 η>0 才交互。动作等价类使 EVPI≡0；小概率灾难被正确计入。

**定义 318（场景探询 SCQ）** g 带观测模型 p(y|h,g)；判别对按 (r*_q−r*_q′)^+·JSD 选；语言问句在反事实动作空间构造（「若…我会…；你看到哪一种？」），避免语义本体错位并自带决策语义。

**定义 319（演示-场景证据纪律 DTA）** 演示只是一个证据源，需 k 正交源多数一致；反事实一致性检验；n_eff 去重 + 来源审计；缺来源的演示只能进离线审计。

**定义 320（演示投毒干扰集）** ℰ_DEMOS=ℰ_FLUID×ℰ_CALM×ℰ_demo；含习惯偏差、伪相关、覆盖投毒、来源/标签篡改、本体/代价错配、重放泄漏、演示洗白。

**定义 321（信任阶梯与逐指令退化）** L0 完整 DEMOS；L1 演示不可信→仅 p_0；L2 场景不可辨识→逐指令 R69；L3 单一动作充分类/无正 EVPI→不交互，动作同 R69；L4 任何一致性失败→逐指令 R68 纯保守。

**定义 322（证书 J_DEMOS）** J_FLUID + scene_ece + class_count/w_q + n_eff/ρ_D/s_D + χ_D + evpi_ratio + provenance_hash + poison_audit + demos_ver；Valid 需场景校准、覆盖、证据纪律与 η>0 同时满足。

**定义 323（场景校准门 SCE）** ECE_scene>τ_sce ⇒ 禁用场景条件化 VoI，退回 R69；仅类别校准差而风险序保持时可保留商空间但禁用演示先验。

**定义 324（任意时间场景深度与假设空间风险）** 默认 top-1，仅歧义且 EVPI 上界>成本时扩到 N≤8；显式承认 H 不完备风险，交由定义 325 检测并在触发时进 L4。

**定义 325（三通道对偶）** r_res（测量自洽）、Δa（行为自洽）、Δ_D（演示-行为-场景互洽）联合归因：(r_res↓,Δa↑) 缓变故障；(Δa↓,Δ_D↑) 示教者错配/场景先验偏置；(Δa↑,Δ_D↑) 假设不完备/OOD；(全↑) 系统性故障→L4。

def anchor_demo(o_t, H):

    return p_D, tau, n_eff, rho

# IP-267 CG：融合前先验证「演示没有在改写世界」
def fuse(p0, p_D, tau, n_eff, rho):

    if chi > TAU_COH or physically_inconsistent(p_D):
        return p0, 0.0, chi                        # 演示失去资格
    if n_eff < N_MIN or rho > R_MAX:

        return (1-kappa)*p0 + kappa*p0, 0.0, chi    # 回缩，不给 demo bonus
    return renormalize(p0**(1-tau) * p_D**tau), tau, chi

# IP-268 ASQ：动作充分商，只在会改变风险处保留不确定性
def quotient(H, p, policy, risk):
    Q = []
    for h in H:
        pi_h, r_h = policy.pi_given_scene(h), risk.optimal(h)
        for q in Q:
            if tv(pi_h, q.pi) <= EPS_A and abs(r_h - q.r) <= EPS_R:
                q.add(h, p[h]); break
        else:
            Q.append(Class(h, pi_h, r_h, p[h]))
    U_epi = sum(q.w * clip((q.r - min(x.r for x in Q))/R_MAX, 0, 1) for q in Q)
    return Q, U_epi

# IP-269 RVI：EVPI 取代熵减
def choose_query(Q, p, risk, budget):
    B, best = bayes_risk(Q, p, risk), None
    for g in scene_query_candidates(Q):
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        evpi = B - expected_bayes_risk(Q, p, g, risk)
        score = evpi - cost(g) - risk_int(g)
        if best is None or score > best.score: best = (g, score, evpi)
    return best if best and best.score > 0 else None   # 无后悔可减 -> 不交互

# IP-270 SCQ：反事实动作空间问句
def make_query(q, q2, o, llm):
    note = f"若 {q.name} 为真我会 {q.safe_action}；若 {q2.name} 为真我会 {q2.safe_action}。"
    return llm.decode_contrastive(note, o)          # 冻结 LLM + 解码侧安全过滤

def DEMOS_RAS_round(M, obs):

## 4. 推导

**引理 19（动作充分商的无损性）** 若 h 与 h′ 为 (ε_a,ε_r)-等价，则合并后任意查询的 EVPI 变化 ≤ ε_r + L_r·ε_a，Bayes 风险变化同阶。故在同一动作充分类内部提问，VoI 被该量界定，ε→0 时为零。系：R69 的动作模态聚类是场景假设空间的固定粗化，可能合并不相关原因或拆开单一原因；按风险后果做的商则不丢后悔、不问无关细节。

**引理 20（熵不决定后悔）** (i) 全 h 的 r* 相同、熵 H_0>0 时 EVPI=0，而熵型 VoI 可为正——白问；(ii) 概率 δ 的假设使 r* 高出 G 时 EVPI ≥ δ(1−δ)G，而熵几乎不变——漏问。系：R69 在非对称代价、稀有灾难、动作等价类三种情形下都可能问错或问漏；RVI 三条均自动处理。

**引理 21（演示覆盖的误差半径）** 局部 n_eff 个有效样本、示教偏差 b_D 时，‖p_D−p_true‖_TV ≤ √((1−ρ_loc)/(2n_eff)) + b_D + O(ρ_D)。系：覆盖半径即置信半径；离开覆盖区，任何演示驱动的锐化都没有统计资格（定义 315 强制膨胀的依据）。

**引理 22（演示投毒上界与一致性门）** 投毒质量 δ_D、信任上界 τ_max<1 时，单源对后验的 KL 推动 ≤ τ_max·δ_D·L_D；χ_D>τ_coh 时 τ_D=0，推动归零。k 个正交源多数一致下，错误采纳率 ≤ δ_D τ_max ρ^{k−1}+ε_σ。诚实边界：能同时伪造「局部高覆盖+来源多样+模型自洽」的攻击可绕过一致性门，上界退化为 δ_D τ_max，只能靠离线来源审计与安全集包含检验兜底。

**定理 18（DEMOS 严格包含 R69/R68，改善有代价）** 边界「h≡m_k、τ_D=0、均匀 0-1 模态损失」下 EVPI 与熵减单调等价，RVI 的查询与动作逐指令等于 R69；EVPI≤成本时不交互；模态歧义为零时逐指令等于 R68。一般情形 Regret(DEMOS) ≤ Regret(R69) + 2L_r ε_scene；ε_scene 为场景假设/校准误差，由 SCE、CG 与定义 325 的假设空间检测共同约束。DEMOS 把 R69 的「模态可信度」风险替换为「场景假设完备性 + 演示可信度」风险，不宣称免费午餐。

**定理 19（不产生虚假确定性 + 安全单调）** CG + 覆盖膨胀 + 证据纪律同时生效时，P(真假设被采纳 | 置信≥1−α) ≥ 1−α−ε；且 λ_DEMOS ≥ λ_floor(U_ale+U_epi) ≥ R68 对应下界。演示与场景证据只能通过已消解的 U_epi 获得 resolution bonus，绝不能把 λ 压到 R68 安全下界以下；任一证据源失效时 λ 沿阶梯单调不降。系：演示数据可以买效率，不能买安全。

## 7. 本轮最大风险

**一句话**：DEMOS-RAS 把效率收益押在「演示数据能代表这个场景、且场景假设空间包含真相」这一双重前提上——**若演示被偏见、错配或投毒塑造成局部密集又自洽的伪先验，或真场景根本不在候选 H(o) 中，系统就会以“有人类背书”的名义自信地相信一个错误的世界，并据此提出错误但看似合理的追问；这种错误恰好能穿过一致性门、覆盖门与证据纪律，比 R69 的“问错”更难审计——因为这次连证书都是用演示数据自己签发的。**

**次级风险与缓解**：覆盖幻觉/重放伪造 → n_eff 去重 + 来源多样性 + E305/E306；示教者本体/代价/任务错配 → 来源分层 + 反事实一致性 + E307，错配即 τ_D=0；场景假设空间不完备 → 定义 325 三通道检测，触发即 L4 保守并求援；演示洗白不安全动作 → 行动许可与信念许可分离 + 定理 19 + E308；商空间划分错误 → SCE 校准门，ECE 越界退回 R69；实时预算被场景图与检索击穿 → 默认 top-1 + 自适应深度 + 仅歧义时检索，E315 守时。
