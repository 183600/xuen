# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；本轮灵感：「轨迹优化」×「抓取位姿估计」）

> R69 把不确定性拆成 aleatoric/epistemic，并让系统学会「问」：流匹配采样出多峰动作，用熵 VoI 决定看不看、问不问、触不触。但 R69 有一个未经审视的隐喻——**它把「模态」当成动作轨迹空间里的簇**。在真实操控里，歧义几乎不长在动作空间，而长在**接触**里：抓盖沿还是盖心、从上方压还是从侧面扣、三指捏还是两指对握。两条轨迹在 L2 上可以很近却对应完全不同的接触拓扑；两条可以很远却只是对称物体的等价抓取。R69 的聚类因此同时犯两种错：**把不同接触混为一谈**（问错），和**把同一决策拆成两个模态**（白问）。
>
> 本轮两个灵感恰好给出「结构」与「裁决」：
> - **抓取位姿估计**把歧义变成一组有物理身份的假设（离散接触模式 × 连续 6-DoF 位姿 × 质量分布），可枚举、可校准、可被对称商掉；
> - **轨迹优化**把「哪个抓取更好」从局部的几何质量分，升级为**在假设之下求解出的最优轨迹代价 J\***，从而成为抓取假设的裁决者，并顺势把「用运动本身去求证」写进目标。
>
> 核心命题：**把 R69 的「动作轨迹聚类 + 熵 VoI」替换为「层级抓取假设 + 后悔值 VoI + 跨假设稳健包络」；不确定性不再靠一个标量 λ 或一个熵代表，而由一组假设、它们各自的最优代价、以及一个随证据单调扩张的安全包络共同表示。** 命名 **GRIT-RAS**（Grasp-hypothesis Resolution via Interactive Trajectory optimization）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我这条轨迹究竟在哪个世界里才安全——以及计划本身能不能成为一次求证**」——计划不再是对某一个世界的承诺，而是对一整族世界的稳健承诺，并随证据收缩。

## 0. 直觉与动机

**灵感 1（抓取位姿估计 → 歧义不是一团轨迹，而是一组有物理身份的假设）**
直觉：R69 用 DTW/Fréchet 在动作轨迹空间聚类来定义「模态」。但操控任务的歧义几乎从不长在动作空间里，它长在**接触**里。同一句「把杯子拿起来」至少有：抓杯口（易碰倒）、抓杯身（可能挡视线）、抓杯柄（可能滑）；而一个方块绕竖直轴转 90° 抓是**同一个决策**在对称下的复本。R69 的熵会把三者（其实只有两三种真不同）都算成歧义，也会把对称复本算成两个模态。抓取位姿估计给出一组带物理语义的层级假设：离散接触拓扑 c ∈ 𝒞、连续 6-DoF 位姿 θ ∈ SE(3)、以及质量/成功率 q。歧义于是有了「身份」——可枚举、可校准、可被对称群 S_c 商掉、可被后续证据逐个击破。**一句话：R69 在动作空间里数峰，R70 在接触空间里数世界。**

**灵感 2（轨迹优化 → 抓取假设的裁决者，而不是执行者）**
直觉：抓取质量分数是局部的、几何的；它不知道「抓起来之后要放到哪、路上会不会撞、力够不够、抓住的瞬间会不会翻转」。真正决定一个抓取假设好坏的，是**在它之下求解出的最优轨迹代价 J\***。于是轨迹优化从「给定抓取的执行器」升级为「抓取假设的裁决者」：对每个候选假设解一个风险约束轨迹优化（RCTO），比较 J\*、可行性裕度 ρ、求解状态。反过来，抓取估计为轨迹优化提供正确的接触模式，避免它在错误的接触流形上陷入局部极小。二者互为前提——这是本轮的结构核心：**估计给候选，优化给裁决；优化给轨迹，估计给接触。**

**灵感 3（层级假设分解 → 离散/连续/动态三层，各配各的可信度）**
直觉：接触模式是离散的（可枚举、易校准、错一次代价大），位姿是连续的（对称、多峰、可能只是一条流形），轨迹是动态的（受约束、可由优化证明）。R69 把三层压成一个聚类，于是用低层的连续噪声去污染高层的离散决策。R70 分层：c 用分类器 + 校准，θ 用带对称商的位姿混合，τ 用条件流匹配 + RCTO。分层让假设空间既**可表达**又**可计算**，也让「该消解哪一层」变清楚：选错接触 → 看/问；同接触下位姿连续不确定 → 探/推；轨迹执行不确定 → 反馈闭环，不问。

**灵感 4（计划即实验 → 用轨迹本身获取信息，MINT 是它的零阶退化）**
直觉：R69 的信息动作是注视/探针/问句这些「点动作」，与任务轨迹分开。但操控中最强的信息常来自**运动本身**：推一下看物体怎么滑、轻抬看是否打滑、接触探测几何、朝一个方向微移看接触点是否保持。于是把「信息」写进轨迹优化的目标：`min_τ J_task(τ;h) − β·I(M; y_τ) + λR(τ)`，约束 τ 落在跨假设稳健包络内。R69 的 MINT 恰是「信息动作视界退化为 0（不产生净位移）」的边界。**「边做边求证」不再是「先问再做」，而是同一条轨迹同时承担任务与实验。** 这样也堵住一个漏洞：R69 的独立探询动作本身可能是新的风险源；R70 要求探索轨迹也必须落在稳健包络内。

**灵感 5（安全必须对假设集稳健，而不是对假设平均）**
直觉：R69 的 λ_floor 是把风险标量收紧；它在「选错模态」时能降速，但不能保证「无论哪个模态为真都安全」。R70 要求：在证据把假设集缩小到 H_δ 之前，提交的计划必须落在**每个可信假设各自安全包络的交集** E(H_δ) 里。这是标量风险 → 集合值稳健的升级。代价是保守；回报是**可证明的跨假设安全**。而「消解」的收益不再是 λ 放松，而是**包络随证据单调扩张**——你能去的动作集合变大了。λ 只是包络体积比的标量投影：`λ_floor(·)` 从「不确定性大小」变成「包络亏空大小」，R69 的 λ 是其单模态特例。

**灵感 6（两个新幻觉 → 两个新门）**
直觉：R69 最大的风险是「流模型幻觉出模态」。R70 把风险原样搬家：**轨迹优化器会幻觉出代价**（未收敛却报一个 J\*），**抓取估计会幻觉出接触**（一个看起来可行、物理上不存在的把柄）。所以本轮必须同时交付：反事实诚实（未解假设只能给界，不准伪造 J\*）、抓取校准门（GCG）、模型失配管（ρ ≥ w）、以及「对枚举集稳健 ≠ 对真实世界稳健」的显式审计。否则 R70 只是把「会撒谎的嘴」换成了「会编造预算的规划器」。

## 1. 形式化定义（增量：定义 310–326）

**假设 A99–A101（本轮新增）**
- **A99（抓取信念校准）**：q_φ(c,θ|o) 的可靠图近似对角，ECE ≤ τ_q；真实假设 h\* 落在 b 的支撑内（**强假设，见第 6 节**）。
- **A100（代价-to-go 正则）**：J\*(h;o) 对观测/信念 L_J-Lipschitz；RCTO 的对偶界有效，未收敛时给出可用的下界。
- **A101（模型管）**：名义模型 f̂ 与真实 f 满足 ‖f−f̂‖ ≤ w；稳健 RCTO 在半径 w 的管上保持不变性；证书要求 ρ ≥ w。

**定义 310（GRIT-RAS 总览与四不变式）** GRIT-RAS = (GHE, RCTO, DRC, RVoI, REA, DITO, GCG, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **假设集稳健**：任何提交计划 τ ⊆ E(H_δ)，任何信息运动同样 ⊆ E(H_δ)；
(iii) **证据纪律 + 反事实诚实**：单源/单次回答不得定案（继承 R69 定义 293-iii）；**未求解（status≠solved）的假设不得向 RVoI 贡献伪造的 J\***，只能以乐观/悲观界进入稳健决策；
(iv) **严格包含**：当 |H_δ|=1、β=0、w=0 时，逐指令退化为 FLUID-RAS（定理 18）。

**定义 311（层级假设）** h = (c, θ, τ)：c ∈ 𝒞 为离散接触拓扑（盖沿/盖心/柄/侧壁/对指…），θ ∈ SE(3) 为 6-DoF 抓取位姿，τ ∈ 𝒯 为接近—抓取—搬运—放置的轨迹。位姿带对称群 S_c：θ ~ θ∘s, s∈S_c（圆柱绕轴、方块 90° 旋转等）。信念 b(c,θ)，轨迹由假设条件策略生成 τ ~ π_θ(·|o,c,θ)。

**定义 312（GHE 抓取假设估计）** q_φ(c,θ|o) ∝ q_contact(c|o) · q_pose(θ|o,c) · q_quality^α(c,θ|o)；每个假设带 (μ_θ, Σ_θ, S_c, p_c)。用等渗/温度回归校准成功率；对称复本在进入下游前按 S_c 归一。GHE 只负责**产生候选与先验**，不负责裁决。

**定义 313（RCTO 风险约束轨迹优化）** 对假设 h：
`min_τ J(τ;h) = ∫ (w_q L_task + w_e E + w_s L_smooth) dt`
s.t. 动力学在半径 w 的管上成立、无碰、摩擦锥、|f|≤f_max、机会约束 P(fail) ≤ ε_int。
返回 R_h = (τ\*_h, J\*_h, ρ_h, s_h, d_h)，其中 ρ_h 为可行性裕度、s_h ∈ {solved, gap, timeout, infeasible} 为求解状态、d_h 为对偶下界。**J\* 只在 s_h = solved 时可信；否则只用 d_h 作为悲观界。**

**定义 314（DRC 决策相关等价）** h ≈ h′ 当且仅当 (i) 同一接触类 c；(ii) θ′ = θ∘s, s∈S_c；(iii) |J\*_h − J\*_{h′}| ≤ δ_J；(iv) 在任务相关集上 E_h ∩ 𝒯_task = E_{h′} ∩ 𝒯_task。商集 {[h]} 的基数记为 **C_dec（决策相关模态数）**。只有 J\* 真正不同的类才算「真模态」；高熵但 J\* 相同的假设被商掉。**R69 的模态数 K̂ 在本轮被 C_dec 取代。**

**定义 315（Regret-VoI 后悔值信息价值）** 令 b 为当前信念，
`RVoI(g) = min_{[h]} E_{b(·|o)}[J\*_h] − E_{y~p(·|g,o)}[ min_{[h]} E_{b(·|o,y)}[J\*_h] ]`。
选择 `g* = argmax_g [RVoI(g) − c(g)]`，s.t. g 及其诱导运动 ⊆ E(H_δ)、预算未超。若 max[RVoI−c] ≤ 0：不交互，直接提交包络内最小后悔假设。**这是 EVPI/EVSI 的操控实例：信息值 = 期望后悔的下降，而不是熵的下降。**

**定义 316（REA 跨假设稳健包络）** H_δ = {h : b(h) ≥ δ}；`E(H_δ) = ⋂_{h∈H_δ} E_h`，其中 E_h 为 h 之下的安全轨迹/动作集。提交计划必须 ⊆ E(H_δ)。包络亏空 `cons(δ) = 1 − vol(E(H_δ))/vol(E_{h*})`；定义 **resolution bonus** 为 H_δ 收缩导致 vol(E) 的单调扩张（引理 20）。R69 的 λ_floor 是本定义在单模态、标量投影下的特例。

**定义 317（DITO 双目的信息轨迹优化）** 在稳健包络内：
`min_{τ ⊆ E(H_δ)} J_task(τ;[h]\*) − β · I(M; y_τ) + λR(τ)`，
其中 I(M; y_τ) 为假设身份 M 与沿 τ 的未来观测（触觉/接触/本体感）的互信息。β=0 且 |H_δ|=1 ⇒ R69 的任务策略；信息视界→0 ⇒ R69 的 MINT 点动作。**信息动作不再独立于任务轨迹，而是其一段。**

**定义 318（假设条件流匹配）** 复用 R68 MTM trunk 与 R69 流速度网，加入假设嵌入：`π_θ(τ | o, c, θ)`。训练目标仍为 L_FM，但条件从 o 扩展为 (o,c,θ)。这消除了 R69 的无条件采样—再聚类的两步误差：模态由 GHE 显式给出，流只负责在给定接触下的轨迹分布。

**定义 319（GCG 抓取校准门）** 抓取质量/接触分类需校准：ECE_q ≤ τ_q 且各接触类覆盖率达标。越界 ⇒ 只允许对指/已知拓扑抓取、δ→δ_floor、禁用 RVoI（与 R69 的 MCG 同构：**不让不可信的假设分布驱动交互**）。

**定义 320（跨假设证据与反事实诚实）** 证据 e ∈ {接触一致性、触觉滑移、重渲染残差、R69 的 r_geo/r_sync/r_zero/r_emo/r_wm}；单源不得定案（继承定义 293-iii）。另加**反事实诚实**：RVoI 只能使用 solved 的 J\* 或对偶界 d_h；严禁用未收敛值冒充最优代价。未解假设以 [d_h, +∞) 进入决策，最优时采取最坏界。

**定义 321（模型失配管）** 名义模型 f̂ 与真值差 ≤ w；稳健 RCTO 在管上保持约束（tube SQP）；证书条件 `ρ_h ≥ w`。w 由 R69 的 FMA 与残差在线估计，随漂移更新并写入证书；w 增大等价于包络收紧。

**定义 322（任意时间证书与预算）** 分层求解：(a) 接触粗选（q_contact，<0.3ms）；(b) 仅对 top-m（m≤2）假设做精细 RCTO，从摊销策略热启动，1–2 步 SQP；(c) 未收敛用对偶界给悲观证书；(d) 剩余预算 < b_min 时立即提交稳健保守计划。**任何时刻返回的证书都对应一个真实求解状态，不假装最优。**

**定义 323（证书 J_GRIT）** `J_GRIT = (J_FLUID, grasp_ECE, C_dec, J*_gap, ρ_min, w, envelope_vol_ratio, solve_status, RVoI, plan_hash, grit_ver)`。Valid ⇔ Valid(J_FLUID) ∧ ECE_q ≤ τ_q ∧ plan ⊆ E(H_δ) ∧ ρ_min ≥ w ∧ 反事实诚实。

**定义 324（AIC-GRIT 威胁模型）** `ℰ_GRIT = ℰ_FLUID × ℰ_model × ℰ_opt`：模型投毒（偏置动力学/碰撞体）、幻影抓取（可行但物理不存在的接触）、优化器漏洞（对抗几何利用离散化/碰撞检测）、对称诱导的虚假确定（把等价流形误当唯一解）、**假设遗漏**（真 h\* ∉ H_δ）。并入 R69 的 ℰ_poison/ℰ_flow。

**定义 325（VQAuditor-T 轨迹审计）** 审计：提交计划是否 ⊆ E(H_δ)；反事实 J\* 是否来自 solved；是否有假设在无证据下被剪枝；对称商是否正确；模型管 w 是否被诚实传播。结论回灌 AuditBuf，成为下一轮 RVoI 的成本先验与 δ 先验。

**定义 326（与 R69/R68 的包含关系）** 当 C_dec=1、β=0、H_δ={h}、w=0 且 GHE 只返回一个假设时，GRIT ≡ FLUID-RAS 逐指令相同；且 E({h})=E_h，故 GRIT 的可行集 ⊆ R69，安全侧永不更弱。**R69 = GRIT 在「单一且已知的抓取 + 不使用运动求证 + 无模型失配」边界上的退化。**

## 2. 关键算法骨架

```python
# IP-264 GHE：层级抓取假设（离散接触 × 连续位姿 × 质量；带对称群）
def grasp_hypotheses(o, K_c=3):
    c_post = contact_classifier(o)
    hs = []
    for c_i, p_c in topk(c_post, K_c):
        mu, Sig, S = pose_mixture(o, c_i)          # 6-DoF + 对称群 S_c
        q = quality_head(o, c_i, mu)               # 成功率
        hs.append(Hypothesis(c_i, mu, Sig, S, p_c, q))
    return calibrate(hs)                           # 等渗/温度校准，交 GCG 门控

# IP-265 RCTO：风险约束轨迹优化（任意时间 + 模型管 + 对偶界）
def rcto(h, o, w_model, budget):
    tau = warm_start_from_policy(o, h)             # 摊销初值，1~2 步 SQP
    for _ in budget:
        tau = sqp_step(tau, J_task, constraints, tube=w_model)
        if converged(tau): break
    J, rho, status, dual = evaluate(tau, h)        # 未解则 status!=solved
    return R(tau=tau, J=J, rho=rho, status=status, dual=dual)

# IP-266 DRC：决策相关等价（对称 + 代价相等 → 商掉；只数真模态）
def decision_modes(R, delta_J):
    classes = union_find(R, key=lambda a, b:
        a.c == b.c
        and equiv_pose(a.theta, b.theta, a.S)
        and abs(a.J - b.J) <= delta_J
        and same_task_reachable(a.env, b.env))
    return [canonical(cl) for cl in classes]       # C_dec = len(classes)

# IP-267 RVoI：后悔值信息价值（替代熵 VoI；只用 solved/对偶界）
def regret_voi(g, modes, b, o):
    J_now  = min(b.expect(m.J) for m in modes)                    # 均用可信界
    J_post = expect_y(min(b.condition(y).expect(m.J) for m in modes))
    return J_now - J_post - cost(g)                # <=0 则不交互

# IP-268 REA：跨假设稳健包络（交集随证据单调扩张）
def robust_envelope(modes, delta):
    Hd = [m for m in modes if b[m] >= delta]
    return intersect([m.env for m in Hd])          # 提交计划必须 ⊆ 此交集

# IP-269 DITO：任务 + 信息的双目的轨迹优化（MINT 的连续化）
def dito(env, h_star, beta):
    return argmin_tau_in(env, J_task(tau, h_star) - beta * MI(h_star, y_tau))

# IP-274 GRIT-RAS 主闭环（继承 R69，替换「模态/交互/安全」三处）
def GRIT_round(M, obs):
    o = M.mtm.encode(obs)                          # 复用 R68/R69 trunk
    H = M.ghe.grasp_hypotheses(o)                  # 层级抓取假设
    if M.gcg.ece(o) > TAU_Q:                       # IP-270 抓取校准门
        H = restrict_antipodal(H); delta = DELTA_FLOOR; voi_on = False
    else:
        voi_on, delta = True, DELTA
    # 1) 只解 top-m 假设（任意时间）；未解者给对偶界，不伪造 J*
    R = solve_top_m(H, M.rcto, m=2, budget=M.budget)
    modes = M.drc.decision_modes(R, DELTA_J)       # 商掉对称/等价
    # 2) 后悔值 VoI 决定是否求证；预算不足直接稳健保守
    g = None
    if voi_on and len(modes) > 1 and M.budget.left() > B_MIN:
        g = M.rvoi.choose(modes, M.belief, o, M.budget)
    # 3) 求证：用 DITO 把信息动作并入轨迹（不是独立点动作）
    env = M.rea.robust_envelope(modes, delta)
    if g is not None:
        plan = M.dito.solve(env, argmin_mode(modes), beta=M.beta)
        ans  = M.cia.execute(g, plan)              # R69 CIA，k>=2 源一致
        modes = M.rvoi.update(modes, ans)          # 后验收缩 → H_δ 变小
        env = M.rea.robust_envelope(modes, delta)  # 包络扩张（resolution bonus）
    # 4) 在稳健包络内提交最安全且后悔最小的计划
    m_star = min(modes, key=lambda m: M.belief.expect(m.J) + LAM * risk(m))
    plan   = M.rcto.recommit(m_star, env)          # 强制 plan ⊆ env
    k, lam = M.c_ras_wm.certified_prefix(plan.tau, ..., wm_preds)
    lam    = max(lam, lam_floor(conservatism(env)))  # R69 的 λ 是包络亏空的标量投影
    # 5) 轨迹审计 + 证书
    M.vqa_t.submit_async(env, modes, plan, M.w_model)
    return plan, k, lam, (env, modes)
```

## 3. 推导

**引理 19（后悔值与熵的可分离性）** 设假设代价 {J_k}、后验 w。熵 VoI 用 ΔH = H(w) − E_y[H(w|y)]；后悔 VoI 用 `RVoI = min_k E_b[J_k] − E_y[min_k E_{b|y}[J_k]]`。则
(i) 若所有 J_k 相等（对称/等价），RVoI ≡ 0，而 ΔH 可任意大 ⇒ **熵 VoI 会白问，后悔 VoI 不会**；
(ii) 对任意有界损失，`RVoI ≤ L_max · ΔH`，其中 `L_max = max_{k,l}|J_k−J_l|`（数据处理不等式 + 有界损失）。因此熵 VoI 是后悔 VoI 的一个上界，但两者在「高熵零后悔」处严格分离。**系：真正值钱的是「可分且代价不同」的歧义，而不是「模糊」；DRC 把这条从直觉变成可执行判据。**

**引理 20（稳健包络的单调扩张 = 几何 resolution bonus）** 若证据使 H_{δ′} ⊆ H_δ，则 `E(H_{δ′}) = ⋂_{H_{δ′}} E_h ⊇ ⋂_{H_δ} E_h = E(H_δ)`，故 vol(E) 单调不减；未消解的保守代价满足 `cons(δ) ≤ 1 − vol(E_{h*})/vol(E(H_δ))`。**系：R69 的 λ 放松（resolution bonus）正是本引理在一维区间上的投影；R70 把「放松一个标量」升级为「扩大一个集合」。**

**引理 21（跨假设安全上界，及其致命前提）** 若提交计划 τ ⊆ E(H_δ)，真实 h\* ∈ H_δ 的概率 ≥ 1−δ，且模型失配 w ≤ ρ_min，则灾难性失败概率 ≤ δ + P(h\* ∉ H_δ)。**注意第二项不可由算法消除，只能由覆盖性保证。** 系：稳健性是对**枚举集**的，不是对**真实世界**的；假设遗漏会静默地把「可证明安全」变成「可证明安全于错误的世界」。

**定理 18（GRIT 严格包含 FLUID-RAS）** 在 A95–A101 下，当 C_dec=1、β=0、H_δ={h}、w=0 时 GRIT 输出与 R69 逐指令相同；且对任意状态，GRIT 的可行计划集 ⊆ R69 的认证集，故安全侧永不更弱。因此 R69 = GRIT 在「单一已知抓取 + 不运动求证 + 无模型失配」边界上的退化；效率侧的收益（包络扩张、白问抑制）是新增量。

**定理 19（后悔一致性，且严格优于熵 VoI 的场景存在）** 在 A99、A100 下，RVoI 贪心交互后的期望后悔 ≤ R69 熵策略的期望后悔 + `2 ε_cal L_J`（ε_cal 为抓取信念校准误差）；当存在「高熵、零后悔」的对称/等价假设时（引理 19-i），R69 仍会交互而 GRIT 不会，故 GRIT 的期望后悔严格更小且交互次数更少。**两者都不劣于 R68 的「不交互」边界。** 系：本节把 R69 的「信息价值」从「熵减少」校正为「决策后悔减少」，这是本轮最重要的理论修正，而不只是新增模块。

## 6. 本轮最大风险

**一句话**：GRIT-RAS 的全部安全声明都写成「对**已枚举**假设集 H_δ 稳健」，而真实世界只需一个**没被枚举的抓取**（OOD 把柄、被投毒遮蔽的接触、优化器把不可行当可行）就能让稳健包络变成「在错误世界里的确定安全」；再叠加反事实规划的成本可能只是优化器幻觉，系统会用一条**为错误假设精打细算出的最优轨迹**，自信地执行一次跨假设事故——**稳健于我以为的世界，不等于稳健于真实的世界。**

**次级风险与缓解**：
1. **优化器幻觉代价**（未收敛冒充 J\*）→ 反事实诚实（定义 320）+ 对偶界 + 证书 solve_status；
2. **抓取估计失准/OOD** → GCG 校准门 + 对指退化 + E313；
3. **RCTO 击穿实时** → 摊销热启动 + top-2 + 任意时间保守提交（定义 322）；
4. **幻影抓取/模型投毒** → ℰ_GRIT 对抗训练 + 跨源证据纪律 + E309；
5. **假设遗漏（不可由算法消除）** → 只能靠保守 δ_floor、异常检测与显式审计暴露，并在证书中标注为**残余风险**，绝不宣称已消除。

**定义 316（REA）** `E(H_δ)=⋂_{h∈H_δ}E_h`；提交 ⊂ E(H_δ)；包络亏空 cons(δ)；消解 ⇒ 交集单调扩张。R69 的 λ_floor = 本定义的标量投影。

**定义 317（DITO）** `min_{τ⊆E(H_δ)} J_task − β·I(M;y_τ) + λR`；β=0 且单假设 ⇒ R69；信息视界→0 ⇒ MINT。

## 3. 关键算法伪代码

```python
# IP-264 GHE：层级抓取假设
def grasp_hypotheses(o, K_c=3):
    hs = []
    for c_i, p_c in topk(contact_classifier(o), K_c):
        mu, Sig, S = pose_mixture(o, c_i)          # 6-DoF + 对称群
        hs.append(Hypothesis(c_i, mu, Sig, S, p_c, quality_head(o, c_i, mu)))
    return calibrate(hs)                           # 交 GCG 门控

# IP-265 RCTO：风险约束轨迹优化（任意时间 + 模型管 + 对偶界）
def rcto(h, o, w_model, budget):
    tau = warm_start_from_policy(o, h)
    for _ in budget:
        tau = sqp_step(tau, J_task, constraints, tube=w_model)
        if converged(tau): break
    J, rho, status, dual = evaluate(tau, h)        # 未解 status != solved
    return R(tau, J, rho, status, dual)

# IP-266 DRC：对称 + 代价等价 → 商掉，只数真模态
def decision_modes(R, delta_J):
    cl = union_find(R, key=lambda a, b: a.c == b.c
                    and equiv_pose(a.theta, b.theta, a.S)
                    and abs(a.J - b.J) <= delta_J
                    and same_task_reachable(a.env, b.env))
    return [canonical(c) for c in cl]              # C_dec

# IP-267 RVoI：后悔值信息价值（只用 solved/对偶界）
def regret_voi(g, modes, b, o):
    J_now  = min(b.expect(m.J) for m in modes)
    J_post = expect_y(min(b.condition(y).expect(m.J) for m in modes))
    return J_now - J_post - cost(g)                # <=0 不交互

# IP-268 REA：跨假设稳健包络
def robust_envelope(modes, delta):
    Hd = [m for m in modes if b[m] >= delta]
    return intersect([m.env for m in Hd])          # 提交计划 ⊆ 交集

# IP-269 DITO：任务 + 信息双目的轨迹优化（MINT 连续化）
def dito(env, h_star, beta):
    return argmin_tau_in(env, J_task(tau, h_star) - beta * MI(h_star, y_tau))

# IP-274 主闭环（继承 R69，替换模态/信息价值/安全三处）
def GRIT_round(M, obs):
    o = M.mtm.encode(obs)
    H = M.ghe.grasp_hypotheses(o)
    if M.gcg.ece(o) > TAU_Q:
        H = restrict_antipodal(H); delta = DELTA_FLOOR; voi_on = False
    else:
        voi_on, delta = True, DELTA
    R = solve_top_m(H, M.rcto, m=2, budget=M.budget)   # 未解给对偶界
    modes = M.drc.decision_modes(R, DELTA_J)
    g = None
    if voi_on and len(modes) > 1 and M.budget.left() > B_MIN:
        g = M.rvoi.choose(modes, M.belief, o, M.budget)
    env = M.rea.robust_envelope(modes, delta)
    if g is not None:
        plan = M.dito.solve(env, argmin_mode(modes), beta=M.beta)
        ans  = M.cia.execute(g, plan)
        modes = M.rvoi.update(modes, ans)
        env   = M.rea.robust_envelope(modes, delta)     # 包络扩张
    m_star = min(modes, key=lambda m: M.belief.expect(m.J) + LAM * risk(m))
    plan   = M.rcto.recommit(m_star, env)               # 强制 ⊆ env
    k, lam = M.c_ras_wm.certified_prefix(plan.tau, ..., wm_preds)
    lam    = max(lam, lam_floor(conservatism(env)))
    M.vqa_t.submit_async(env, modes, plan, M.w_model)
    return plan, k, lam, (env, modes)
```

## 4. 推导

**引理 19（后悔值与熵的可分离性）** 若所有假设代价相等（对称/等价），`RVoI≡0` 而 `ΔH` 可任意大 ⇒ 熵 VoI 白问；对任意有界损失 `RVoI ≤ L_max·ΔH`，熵 VoI 只是后悔 VoI 的上界。系：值钱的是「可分且代价不同」的歧义；DRC 是该判据的可执行形式。

**引理 20（包络单调扩张）** `H_{δ′}⊆H_δ ⇒ E(H_{δ′})⊇E(H_δ)`，vol(E) 单调不减；未消解保守代价 `≤1−vol(E_{h*})/vol(E(H_δ))`。系：R69 的 λ resolution bonus 是本引理的一维投影。

**引理 21（跨假设安全上界与致命前提）** τ⊆E(H_δ)、P(h\*∈H_δ)≥1−δ、w≤ρ_min ⇒ 灾难失败率 ≤ `δ+P(h*∉H_δ)`。第二项不可由算法消除；假设遗漏会把「可证明安全」静默变成「对错误世界的可证明安全」。

**定理 18（GRIT 严格包含 FLUID-RAS）** C_dec=1、β=0、H_δ={h}、w=0 时逐指令相同；且任意状态 GRIT 可行计划集 ⊆ R69 认证集，安全永不更弱。R69 = GRIT 在「单一已知抓取 + 不运动求证 + 无模型失配」边界的退化。

**定理 19（后悔一致性）** A99、A100 下，RVoI 贪心交互后期望后悔 ≤ R69 熵策略 + `2ε_cal L_J`；当存在「高熵零后悔」对称假设时 GRIT 严格更优且交互更少；两者均不劣于 R68 的不交互边界。

## 7. 本轮最大风险

**一句话**：GRIT-RAS 的安全声明是「对**已枚举**假设集 H_δ 稳健」，真实世界只需一个**没被枚举的抓取**（OOD 把柄、被投毒遮蔽的接触、优化器把不可行当可行）就能让稳健包络变成「在错误世界里的确定安全」；再叠加反事实规划的成本可能是优化器幻觉，系统会用一条**为错误假设精打细算出的最优轨迹**，自信地执行一次跨假设事故——**稳健于我以为的世界，不等于稳健于真实的世界。**

**次级风险与缓解**：优化器幻觉代价（反事实诚实 + 对偶界 + solve_status）；抓取估计失准/OOD（GCG + 对指退化 + E313）；RCTO 击穿实时（摊销热启动 + top-2 + 任意时间保守）；幻影抓取/模型投毒（ℰ_GRIT 对抗训练 + 跨源证据 + E309）；**假设遗漏（不可由算法消除）**（δ_floor、异常检测、显式审计，并在证书中标注为残余风险，绝不宣称已消除）。
