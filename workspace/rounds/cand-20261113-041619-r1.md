# 第 3 轮迭代（灵感循环 v3：「多视角视觉」×「实时推理」）—— 从"事后察觉撤回"到"几何可证、任意时刻可答"

> **本轮不改赛道，改证据标准与时间标准。** 承接 v2 的旗舰 UIP-01′/09′（检测"进度被撤回"→重做）与 UIP-11/12（Gazebo 判分 + 扰动数据工厂）。v2 的软肋很明确：`regressed` 主要靠 2D 视觉/规则判据，手一遮、光一变就可能误判，进而"反复重做"烧掉延迟预算与步骤分。本轮用「多视角视觉」把回退判定升级为**多视角几何共识**，用「实时推理」把"同步等齐—整块盲执行"升级为**anytime 流式融合 + 事件触发核验**。
>
> **诚实声明**：本轮**未新增外部检索**；§0 的事实全部沿用 v2（检索日期 2026-11-12），带"推断/待核实"标签的新内容是建立在这些事实之上的推导，不作为已核实结论。

## 1. 两个灵感词：先直觉，后定义

### 1.1 多视角视觉：不是"更多像素"，是"度量 + 遮挡互补 + 交叉校验"

**直觉。** 单目看到的是"像"，多视角看到的是"位"。head 左右构成一个立体对，视差直接换出度量深度；腕部相机在插入/合盖/拉链这种接触步离物体最近，头部被手臂挡住时它是唯一见证者。更关键的是第三件事：一个 3D 假设必须同时投影到多个视角都对得上，**单视角的像素闪烁不再足以改变决策**——这正是把"回退"从猜测变成证据的机制。

**严谨定义。** 记 `O_t = {I_t^{hL}, I_t^{hR}, I_t^{wL}, I_t^{wR}}`（可用子集）。相机 `v` 的内参 `K_v`、外参 `(R_v,t_v)`，投影 `π_v(X)=K_v[R_v|t_v]X`。head 立体对视差 `d=u_L-u_R`，深度 `z=f_h b_h/d`（`b_h` 基线、`f_h` 焦距），即**无需额外模型即可得度量 3D**。腕部通过手眼变换 `T_{w→h}` 投到 head 系，或反向把物体投到腕部系。

- **重投影残差**：`r_v(X)=‖u_v−π_v(X)‖²`；立体对满足极线约束 `x_w^T F_{wh} x_h=0`。
- **遮挡感知可靠度**：`ρ_v(X)∈[0,1]`（可见性/分割置信度；被手挡住→ρ 低）。
- **鲁棒融合**：`X* = argmin_X Σ_v ρ_v·ψ(r_v(X))`，`ψ` 取 Huber，抗单视角离群。
- **多视角几何谓词**（子目标/计分步的判据）：`φ_g : X → {0,1}`，例如"杯轴与竖直夹角 <15° 且杯心距挂钩 <3cm"。判定对象是 **`X*`**，不是任何单张图。

**由此得到的操作性定义**：所谓"多视角视觉能力"，是在**外参/同步可信**的前提下，把每个子目标编码为一个可在 `X*` 上求值的度量谓词，并能给出该谓词的**跨视角见证数** `n_wit(g)`。

### 1.2 实时推理：不是"GPU 更快"，是"在预算内做出可证伪的答案"

**直觉。** 开环动作块下，用户看到的"反应慢"主要不是模型前向慢，而是"块还没执行完，环境已经变了"。多视角又会抬高推理成本（四张 JPEG 解码 + 更大输入）。所以真正的实时问题是：**在给定延迟预算内，用当前已到达的视角做出一个"够用且可自证"的决定，并明确什么时候必须再核验。**

**严谨定义。** 控制频率 `f_ctrl`、块长 `k`、推理延迟 `T_infer`，则一次决策到下一次重观测的**反应时间**

```
T_react(k) = T_infer + k / f_ctrl
```

预算约束：`P(T_react > B) ≤ ε`（B 例如 200 ms，ε 例如 0.05）。视角 `v` 的**陈旧度** `s_v(t)=t−τ_v`（`τ_v` 为拍摄时刻）。**Any-time 策略**：在墙钟时刻 `t`，用已到达子集 `V_t⊆V` 形成动作；质量对 `|V_t|` 单调不减；后到视角只能影响**下一块**（已执行动作不可撤回）。**事件触发核验**：只在 `t` 属于 `chunk 边界 ∪ 预测完成窗口 ∪ 跨视角残差尖峰` 时启动验证器，而非每个 tick 都跑。

### 1.3 耦合命题（本轮的核心判断）

> **多视角买"可验证性"，实时买"预算"；二者只在"同步等齐再想"的范式下冲突。** 解法是把验证器做成 **anytime + 事件触发 + 跨视角共识**：平时少算，回退必须"多视角一致见证"，从而同时降低误重做率和平均延迟。

## 2. v2 清单诊断：这一轮改的是"证据"与"时间"

- **升级为旗舰**：UIP-01′/09′ → **UIP-16 MV-GPV（多视角几何进度验证器）**。回退判定从 2D 启发式改为"度量位移 + ≥2 视角共识"，直接消灭 v2 最大风险"误判→反复重做"。
- **专门化**：把"撤回检测"从验证器里拆成独立可测组件 **UIP-18 CVDD（跨视角扰动检测器）**，便于单独做遮挡/标定噪声压力测试。
- **统一**：UIP-11 GSO 的仿真几何谓词与 UIP-16 的真机谓词**共用同一谓词库** → 新增 **UIP-20 SPU（共享谓词宇宙 + 标定迁移）**；GSO 从"结构裁判"升级为"**可标定的**结构裁判"。
- **实时侧重构**：UIP-13 ACS 并入 **UIP-17 ASMV（anytime 流式多视角）** 与 **UIP-19 MSR（多速率调度）**；UIP-15 CSG 保留为总闸（延迟预算/抖动/最大重做）。
- **保留**：UIP-02′ 计分步安全网、UIP-05 语义分解、UIP-08′ 多端口延迟工程、UIP-12 扰动数据工厂、UIP-14 模块化技能图。

## 3. 瓶颈假设（v3）

- **H1（最高杠杆）**：`regressed` 的可信度只取决于**跨视角一致性**；单视角回退检测在遮挡下必然假阳性，而假阳性重做的代价（延迟 + 步骤分回退）可能高于漏检。
- **H2**：head 立体对 + 手眼标定一旦可得，真机就能算出与 UIP-11 同一套几何谓词，**仿真与真机首次共享"判分语言"**，sim-to-real 可被逐谓词校准，而非只看总成败。
- **H3（反直觉）**：当 `T_infer < k/f_ctrl` 时，反应时间由**块执行**主导，优化网络收益有限；按阶段调度 `k` 比堆算力更划算。
- **H4**：四路发送大概率是握手期固定配置；因此"自适应视角"的安全收益只在**计算侧**（少编码/早退/多速率），不能假设可关相机。
- **H5**：视角价值强相位相关——搬运段 head 主导、接触段 wrist 主导；**均匀融合是最差策略**，会同时浪费带宽与延迟。

## 4. 候选与合并 → v3 清单（详见产物区）

围绕两词发散 8 个草案，修剪/合并后：升级 4 个、封存/并入 3 个、新增 5 个（UIP-16~20）。**新旗舰 = UIP-16 + UIP-18（可信回退）× UIP-17（anytime）**，由 UIP-19/20 分别供时间与标定支撑，UIP-11/12 继续做离线判分与造数据。核心叙事从"抢数据空白"推进到"**用多视角几何把这条空白变成可证伪、可校准的闭环**"。

---

## 5. 本轮最大风险

**一句话**：多视角几何验证的全部价值建立在**外参与时间同步可信**之上；若二者未知或有噪，所谓"几何共识"会退化成更自信的 2D 启发式，而它一旦驱动重做，就会把标定误差放大成系统性的错误重做循环。

**→ 本轮最值得押注：UIP-16 × UIP-18 的"跨视角共识回退" × UIP-17 的"anytime 流式核验"**——它把 v2 旗舰从"可能误判的启发式"升级为"可证伪、可做标定噪声压力测试"的机制，且完全落在选手 API 与离线算力之内。

## 1. 旗舰深潜：UIP-16 · MV-GPV（Multi-View Geometric Progress Verifier）

**机制。** 每个计分步/子目标 `g` 配一个**度量 3D 谓词** `φ_g(X)∈{0,1}`（由 UIP-20 与 GSO 共用）。每 `k` 步（或事件触发）从可用视角鲁棒三角化出 `X*`，在 `X*` 上求值，得到状态 ∈ {`done`,`ongoing`,`fail`,`regressed`}。**回退不是看某张图变了，而是看 `X*` 在度量空间里真的退回去了，且至少两个视角一致见证。**

**回退判定（严守三关，抗遮挡/抗闪烁）：**

```
regressed(t) ⇔  was_done(g, X_{t'}) ∧ ¬done(g, X_t)
              ∧ ‖ΔX_g‖ > τ_d                    # 度量位移门限（米）
              ∧ n_wit(g, t', t) ≥ 2             # ≥2 个视角见证
              ∧ conf(X_t) ≥ CONF_MIN            # 融合置信度门限
```

- `was_done`/`done` 用 `φ_g`；`ΔX_g` 取该子目标相关物体/末端的度量位移（如杯心、拉链头、RJ45 插深）。
- `n_wit` = 在该子目标 ROI 上可靠度 `ρ_v ≥ ρ_min` 且残差 `r_v < r_max` 的视角数；手挡住 head → head 不计见证，靠 wrist。
- 单视角回退只置 `suspect`（进候选队列、下一 chunk 复核），**不立即重做**；这样把 v2 的"反复重做"从机制上掐掉。

**与 v2 差异。** v2 的 `regressed` 由"时序差分或视觉/几何判据"触发，本质是 2D 启发式；v3 改为"度量 3D + 跨视角共识"，并新增 `suspect` 中间态，把"不确定"与"确定回退"分开处理。

**可行性。** 中高。head 立体对视差得深度不需要额外网络；手眼外参可离线标定一次；谓词是规则代码，不引入第二个模型（合规章）。**待核实**：外参/同步是否可得；若不可得，退化为"双视角重投影一致性 + 单体深度近似"，精度下降但机制仍在。

**资源。** 32 数据集离线写谓词 + 弱标注；1 张推理卡；N 端口各自维护 `X*` 与谓词状态（UIP-08′ 隔离）。

**落地。** ① 核实观测键/外参/同步；② 选 5 个代表任务（T26 插网线、T19 拉链、T16 叠毛巾、T27 叠碗、T10 插头）写 `φ_g`；③ 离线用数据回放标定 `τ_d, r_max, ρ_min`；④ 接入 UIP-01′ 状态机；⑤ 遮挡/标定噪声压力测试（E205）；⑥ 真机锚点。

**风险。** 谓词阈值过紧→漏检真回退；过松→误重做。用 UIP-15 的总闸 + E205 的噪声扫描定阈值，并保留"单视角 suspect 只复核不重做"的护栏。

## 2. 形式化：多视角几何与 anytime 预算

**2.1 度量重建。** 相机 `v`：`π_v(X)=K_v[R_v|t_v]X`；head 立体 `z=f_h b_h/(u_L−u_R)`；鲁棒融合

```
X* = argmin_X Σ_v ρ_v · ψ_Huber( ‖u_v − π_v(X)‖ )
```

**2.2 视角价值（相位相关）。** 定义视角 `v` 对子目标 `g` 的效用

```
U(v | g) = E[ ΔH(φ_g) ] / ( c_v · ℓ_v )
```

`ΔH` 为该视角带来的谓词不确定度下降，`c_v` 为计算/带宽成本，`ℓ_v` 为陈旧度惩罚。**均匀融合 = 忽略 `U` 的相位差异，是下界策略**（H5）。

**2.3 反应时间与预算。**

```
T_react(k) = T_infer + k / f_ctrl ,     P(T_react > B) ≤ ε
```

数值直觉（**估算，待实测**）：`f_ctrl≈30Hz` 时，`k=2 → 67ms`、`k=8 → 267ms` 的纯块执行；若 `T_infer≈80–150ms`，则小 `k` 的反应时间约 `120–220ms`，大 `k` 约 `350–420ms`。**接触密集步应取小 k。**

**2.4 载荷直觉（估算，待实测）。** 480×640、q95、4:4:4 的 JPEG 经验约 `60–120 KB/张`。四路 × 堆叠 2 = 8 张 ≈ `0.5–1.0 MB/次调用`；`k=4`（7.5 次/秒）时约 `4–7.5 MB/s/端口`，4 端口并发可达 `16–30 MB/s`。**结论：载荷由握手期"键集合+堆叠+缩放"决定，运行期能省的只有计算；因此 UIP-17 的 anytime 收益要按"计算侧"记账，不虚报带宽收益。**

**2.5 Anytime 融合。** 已到达视角集合 `V_t`，陈旧度权重 `w_v=exp(−λ s_v)`：

```
X*_t = argmin_X Σ_{v∈V_t} w_v ρ_v ψ(r_v(X))
conf_t = g(V_t, 残差)          # 单调不减于 |V_t|
```

当 `conf_t ≥ CONF_MIN` 或到达 `budget_ms` 即早退；未到视角只影响下一块（动作不可撤回）。

**2.6 核验调度（事件触发，省算力）。**

```
verify at t  ⇔  t ∈ chunk 边界
             ∨  t ∈ [ t0 + μ_g − σ_g , t0 + μ_g + σ_g ]   # 预测完成窗口
             ∨  cross_view_residual_spike(t)
```

`μ_g, σ_g` 可由公开数据的子目标完成时长统计得到（离线、零模型）。

## 3. UIP-17 · ASMV 伪代码（anytime + 早退 + 投机）

```python
class ASMVFuser:
    """UIP-17: 流式多视角融合；到预算或置信达标即早退。"""
    def __init__(self, λ=2.0, CONF_MIN=0.6, B_ms=120):
        self.λ, self.CONF_MIN, self.B_ms = λ, CONF_MIN, B_ms

    def fuse(self, frames, phase):
        deadline = now() + self.B_ms / 1000.0
        order = self._view_priority(phase)     # 接触段 wrist 先，搬运段 head 先
        feats = {}
        for v in order:
            if v not in frames:                # 握手后固定发送；此处只处理已到达
                continue
            if now() > deadline and feats:
                break                          # anytime 早退：不等齐
            feats[v] = self._encode(frames[v])
            conf = self._confidence(feats)
            if conf >= self.CONF_MIN:
                break
        X = robust_triangulate(feats, weight=staleness_weight)
        return X, self._confidence(feats)
```

> 说明：若接口允许运行期裁剪视角，则可进一步省网络；**该收益不计入主方案**，只作为条件性 bonus。

## 4. UIP-18 · CVDD：跨视角扰动检测（抗遮挡的核心）

```python
def cvdd(prev_X, X, g, preds, τ_d, min_wit=2):
    # 只在"曾经完成 → 现在未完成"时考虑回退
    if not (preds[g](prev_X) and not preds[g](X)):
        return "ongoing"
    disp = metric_displacement(prev_X, X, g)          # 杯心/拉链头/插深等
    if disp <= τ_d:
        return "ongoing"                              # 度量没动，判为视觉抖动
    wit = count_reliable_views(g, X, ρ_min=0.4, r_max=3.0)  # 跨视角见证
    if wit >= min_wit:
        return "regressed"
    return "suspect"                                  # 单视角：只复核，不重做
```

**价值。** 把遮挡导致单视角"物体消失"与真实"被拿走/被翻开"分开：前者 `wit<2` 或 `disp≤τ_d` → 只 `suspect`；后者 `disp>τ_d 且 wit≥2` → 才允许回退。**这是对 v2 最大风险"误判→反复重做"的直接机制性修复。**

## 5. UIP-19 · MSR 与 UIP-20 · SPU

### UIP-19 · MSR（Multi-Rate Scheduling）
- **机制**：动作块长 `k(g)` 按阶段选；腕部特征每次刷新（接触步），head 特征每 `m` 次刷新（搬运段头部变化慢）并缓存；核验按 §2.6 事件触发。投机：执行当前块时按"预测的下一观测"预生成候选块，到时只做一致性校验。
- **安全约束**：返回块长 `k ≤ K_MAX=action_chunk_size`；若"块长必须恰为 K_MAX"被核实，则退化为固定 `K_MAX` + 仅保留多速率特征与事件触发核验。
- **收益**：p95 延迟与方差下降，接触步反应变快；不改变模型。

### UIP-20 · SPU（Shared Predicate Universe + Calibration Transfer）
- **机制**：GSO（UIP-11）与 MV-GPV（UIP-16）共用谓词库 `Φ={φ_g}`。在配对 episode 上估计**逐谓词标定映射** `c_g: (τ_d, r_max, ρ_min, 深度偏置) → 修正量`，把仿真阈值迁到真机。
- **严谨性**：标定量是每任务几个标量，**不是第二个策略模型**，属于离线标定；合规上按"标定常数"处理（仍保留合规警醒）。
- **价值**：GSO 从"结构裁判"变成"**逐谓词可校准**的结构裁判"；用真机少量锚点即可定位"是哪个谓词在 sim-real 上漂了"。

## 6. 统一状态机（UIP-01′ 骨架 + 16/17/18/19/15）

```python
class MVGPVPolicy:                    # UIP-16 + 17 + 18 + 19 + 15
    def reset(self):
        self.g = 0; self.prev_X = None
        self.redo = 0; self.suspect = None

    def get_action(self, obs):
        if self._should_verify(obs):                    # UIP-19 事件触发
            X, conf = self.fuser.fuse(obs.frames, self._phase())
            st = self._pred_state(X, self.g)            # φ_g on 度量 3D
            if st == "done":
                self.g += 1; self.redo = 0; self.suspect = None
            else:
                ev = cvdd(self.prev_X, X, self.g, self.preds, self.τ_d)
                if ev == "regressed" and self.redo < self.R_MAX:   # UIP-18
                    self.redo += 1
                    self.g = max(0, self.g - 1)          # 回到被撤回的子目标
                elif ev == "suspect":
                    self.suspect = (self.g, X)           # 只记，下一 chunk 复核
            self.prev_X = X
        k = self._pick_k(self.g, obs)                   # UIP-19 相位自适应
        k = self._gov_clip(k)                           # UIP-15 延迟/抖动/重做预算
        return self.policy.get_action(obs, k)           # 返回长度 k ≤ K_MAX 的块
```

> 接口红线：动作块形状/ dtype / 索引顺序严格按 README；返回块长与声明不一致是否被接受**尚待核实**，E201 先测。

## 8. 合规与风险（本轮新增）

- **单模型合规**：谓词库是规则代码、S 标定是每任务几个标量，均不引入第二个策略网络；但仍需避免被判为"外部模型/多模型"。
- **标定依赖（最大风险）**：外参/同步未知或有噪 → "几何共识"退化；必须 E205 先量化失效边界，并保留"单视角只 `suspect`"的降级路径。
- **接口不确定性**：块长可否 `≤K_MAX`、四路可否运行期裁剪、head 是否硬同步——三项均为**待核实**，方案已给保守退化路径。
- **仿真过拟合**：UIP-20 只校准谓词，不等于校准视觉/接触；仍以真机锚点为最终裁判。
- **手册未取到**：评测轮次/时限/控制频率仍需飞书手册公开后核实。

## 10. 本轮最大风险 & 押注

**一句话**：多视角几何验证完全依赖可靠的外参与时间同步；标定一旦失真，"几何共识"会变成更自信的错误，并经由重做机制被系统性放大。
