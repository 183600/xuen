# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「数据采集」×「激光雷达」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**几何真值锚 + 主动采集 + 来源治理**。两个灵感分别治理 v9 的三种债：**信任债**（块证书依赖学习型前向模型 F̂，而 DA-ML 的 20 帧滑窗滞后于真实跳变——正是 v9 自陈的最大风险）、**被动债**（DA-ML/SPR 只能被动检测域偏移，检测到后没有任何手段把模型修回来）、**来源债**（在线校准/重训的数据从哪来、是否被污染、能否回放审计，v9 完全空白）。核心判据：任何新模块失效 ⇒ 注入中立元，**严格等价退回 v9**（引理 92），绝不让"几何锚"本身变成新的单点依赖。

## 0. 直觉与动机

**灵感 1（激光雷达 → 不依赖分布的学习外几何真值）**
直觉：v9 的块证书由学习型前向模型 F̂ 给出，其可靠性前提恰是"信任域内误差 ≤ β"；而 DA-ML 判断信任域靠 20 帧滑窗，域跳变瞬间正是 F̂ 最错、DA 最迟钝的时刻。激光雷达提供的是**另一种证据**：它不学分布，只做射线投射——某个体素有没有回波、回波在多远，是逐帧的物理事实。核心创新：**LiDAR 几何锚（LiDARGeometryAnchor, LGA）**：用射线投射构造自由空间下界证 g_L(t)（未知空间一律视为占用），与 F̂ 块证书做**单向否决**交叉证书 C_cross = C_v9 ∧ C_L。LGA 只能收紧、不能放宽——加装它绝不增加可接受的行动集合（引理 87）。这恰好把 v9 的"分块执行在最需要安全的时刻暴露最不可靠证书"正面拆掉：即使 Δ_dom 还没反应，几何锚本帧就能发现"预测说能过、点云说不能过"。

**灵感 2（数据采集 → 把被动域适应变成安全约束下的主动采集）**
直觉：v9 的 DA-ML 检测到域偏移后，只能等未来数据自然到来再慢慢适应；系统从不主动决定"我该去哪里、看什么，才能最快补上我不知道的那部分"。核心创新：**主动数据采集器（ActiveDataCollector, ADC）**：以几何-学习分歧 + 特征新颖度 + 未观测空间占用熵构造认知不确定性图 U(x)，只在**安全可采集集** A_coll（同时通过 C_v9 与 C_L、有中止点、有采集预算）内最大化信息增益。关键纪律：**采集本身是一次被认证的行动**（P14）——探索绝不能以安全为代价；A_coll 为空就不采集（退回纯任务模式）。这把"采集"从数据工程问题提升为控制/安全问题的对偶。

**灵感 3（数据采集 → 采集账本与有界影响更新）**
直觉：主动采集会引入新数据，新数据会改在线阈值；若没有来源治理，一条被污染/标定漂移/时延错配的样本就可能悄悄改写安全判据。核心创新：**采集账本（AcquisitionProvenanceLedger, APL）** + **有界影响更新**：每条样本带来源链（时间戳、位姿、点云哈希、触发原因、质量分、时空标定证书），安全关键阈值仅接受通过质量门与来源验证的数据，且每个重训窗口最多 W 条新样本能影响阈值，采用截尾聚合——任何一次采集回合都不能翻转 M₀ 判据（引理 90）。"数据采集"由此从"越多越好"变成"可审计、有界、可回溯"。

**一句话综合**：v9 用"中立元 + 分块 + 蒸馏"管理**算力与集成**；v10 用"几何锚 + 主动采集 + 来源账本"管理**认知**——几何锚告诉系统"你哪里可能错了"，主动采集去"把错的地方看懂"，来源账本保证"看来的东西没被污染"。三者构成一个**带物理锚的自我修复数据飞轮**，且飞轮的每一圈都可退化为 v9 的格点。

## 1. 研究问题（轮次升级版）

- **Q1（几何锚的可靠性边界）**：在射线投射、未知=占用、角分辨率稀疏、透明/镜面/雨雾条件下，g_L 何时是真实净空的**可靠下界**？LiDAR 失效（健康度低/标定漂移）时如何干净地退回 v9，而不产生"虚假一致"这种更危险的情形？
- **Q2（安全主动采集）**：如何把信息增益最大化限制在安全可采集集上，使采集机动既可认证、又在有限预算内完成，且不把系统拖入"为了采集而冒险"的循环？
- **Q3（来源治理与有界影响）**：什么样的账本结构 + 截尾聚合 + 质量门，能保证任意一次采集回合（含被投毒/标定漂移的）对安全关键阈值的影响有界、且可审计回放？

## 2. 设计原则（在 P7–P12 基础上新增 P13–P15）

**P13 几何锚单向否决律（Geometric-Anchor Veto, LGA）**
LGA 是**安全过滤器**而非新决策源：C_cross = C_v9 ∧ C_L，接受集只会缩小（C_cross ⊆ C_v9）。g_L 按"未知=占用 + 距离噪声 ε_r + 角分辨率膨胀 r·δθ"计算为真净空下界；LiDAR 健康度 h_L < τ_L 或时空标定漂移超阈时，注入中立元 g_L = +∞（不否决）并置 LiDAR 不可用标志，K_eff^{v10} = K_eff^{v9}，**严格退回 v9**。

**P14 采集即认证行动律（Acquisition-as-Certified-Action, ADC）**
任何采集机动 ζ^coll 必须 ∈ A_coll(t) = {ζ : C_v9(ζ) ∧ C_L(ζ) ∧ budget(ζ) ≤ B_coll ∧ P(ζ) ≠ ∅}。信息增益只在 A_coll 内做排序（tie-breaker），**永远不能覆盖**安全判据；A_coll = ∅ ⇒ 本回合不采集。采集有硬预算（步数/时长/能量）与冷却期，防止"探索成瘾"。

**P15 来源可审计与有界影响律（Provenance-Bounded Influence, APL）**
每条进入在线校准的数据必须有账本记录与质量分 q_i；安全关键阈值（M₀ 硬检查、SpatialCert 门限、τ_dom/τ_SLAM）只接受 q_i ≥ q_min 且来源可验证的数据；每个重训窗口新增样本 ≤ W，采用截尾/中位数聚合，单次采集回合对阈值的影响有界（引理 90）。未审计的数据路径不存在。

## 3. 与基线的接口（如何退化）

- LGA 失效（h_L<τ_L / 标定漂移 / 点云超时）⇒ g_L=+∞（不否决）、K_eff^{v10}=K_eff^{v9}，等价 v9 学习型证书；
- 未装 LiDAR / 交叉证书不可用 ⇒ C_cross := C_v9，等价 v9；
- ADC 失效（A_coll=∅ / IG 计算超时 / 预算耗尽）⇒ 不采集，纯任务模式，等价 v9；
- APL 失效（账本损坏 / 质量门不可用）⇒ 冻结在线阈值更新，只用 v9 既有阈值；
- 全部失效 ⇒ 完整退回 MetricVoiceGauge-ACMD v9，再退回 v8/v7/v6。

## 4. 预期贡献

1. **几何锚交叉证书**：首次把激光雷达射线投射作为学习型分块证书的**单向否决**真值锚，用一个模块正面消除 v9"DA 滞后 × 前向模型误差"的耦合风险（引理 87–88）；
2. **安全约束下的主动数据采集**：把信息增益探索限制在可认证行动集内，使"采集"成为受安全不变式约束的控制问题，而非数据工程副作用（引理 89）；
3. **采集账本与有界影响更新**：样本级来源链 + 截尾聚合 + 重训窗口配额，给出抗投毒/抗标定漂移的有限影响界（引理 90）；
4. **物理锚自我修复飞轮**：几何锚定位错误 → 主动采集补数据 → 账本治理后重训 → 学习模型修复，形成闭环；E571–E590 覆盖几何锚标定、健康退化、采集安全、投毒、标定漂移、HIL 与长跑。

## 5. 本轮最大风险

**一句话**：飞轮的触发器是"几何-学习分歧"，但分歧也可能来自 LiDAR 自身错误——透明玻璃、镜面反射、雨雾衰减会让几何锚"看不见障碍"而给出虚假一致，或"处处占用"而过度保守；系统随后会主动采集**错误锚点指出的区域**，把错误信念写进账本与阈值，形成"锚点错 → 采错数据 → 模型更错"的**信念污染环**。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-LGAF**（LiDAR-Geometry-Anchored Flywheel：激光雷达几何锚 × 安全主动采集 × 来源账本）

**新增定义 540（LiDAR 几何锚 LiDARGeometryAnchor）** 对轨迹 ζ 的扫掠走廊，先由 P_t 与 T_t 做射线投射得到自由/占用/未知体素（未知一律视为占用），再取走廊内到最近占用或未知体素的距离下界，扣除距离噪声 ε_r 与角分辨率膨胀 ρ_ang(r)=r·δθ：
```
g_L(ζ) = min_{x∈走廊(ζ)} dist(x, occ ∪ unknown) − ε_r − max_{x} ρ_ang(r_x)
C_L(ζ) ⇔ (h_L ≥ τ_L) ∧ (g_L(ζ) ≥ d_safe_L) ∧ C_cal
```
其中 d_safe_L = d_safe + ε_margin（ε_margin 覆盖点云稀疏与配准残差）。**关键**：g_L 是**真净空的下界**（g_L ≤ g_true），故 C_L 通过 ⇒ 真实几何净空 ≥ d_safe（引理 87）。

**新增定义 541（交叉证书 CrossCertificate）** 对任意候选块 ζ：
```
C_cross(ζ) = C_v9(ζ) ∧ C_L(ζ)
```
单向性：C_cross ⊆ C_v9。定义**模型乐观事件** E_opt(t) = 选中块 ζ* 满足 C_v9(ζ*) ∧ ¬C_L(ζ*)，即"学习模型说能过、几何锚说不能过"。触发即：切换到 ≤ 当前执行步的最大中止点 p*、K_eff←1、并在下一可执行时刻向 ADC 入队采集触发（原因=genuine disagreement）。反向的 C_L ∧ ¬C_v9 只记为保守事件 E_cons（几何可过而学习证书不肯过），用于统计过度保守，不做任何放宽。

**新增定义 542（认知不确定性图与信息增益 EpistemicUncertainty & IG）**
```
U(x) = w₁·1[F̂ 在 x 邻域与 F_L 分歧] + w₂·Novelty_DA(x) + w₃·H_occ(unknown 邻域)
IG(v) = H(U | 当前观测) − E_{z~p(·|v)}[ H(U | 观测 ∪ z) ]   （用射线投射近似）
```
U 只在"可能错"的区域升高；ADC 选位姿时就高 IG，但必须通过 A_coll 认证。

**新增定义 543（安全可采集集 CertifiableAcquisitionSet）**
```
A_coll(t) = { ζ : C_v9(ζ) ∧ C_L(ζ) ∧ budget(ζ) ≤ B_coll ∧ P(ζ) ≠ ∅ }
ζ^coll(t) = argmax_{ζ∈A_coll(t)} IG(ζ)，  若 A_coll(t)=∅ 则本回合不采集
```
采集机动本身是 AC 生成的块（可含观察性原地转/短程接近），因此天然带中止点与块证书；IG 只是排序键，不参与可行性判定。

**新增定义 544（采集账本与哈希链 ProvenanceLedger）** 每条记录
```
r_i = (id, t_i, T_i, hash(P_i), trigger_reason, q_i, C_cal_i, cert_status, prev_hash)
q_i = min(h_L(t_i), 1[C_cal valid], 1[时间同步 ok], source_trust_i)
head = SHA256(r_i‖prev_hash)
```
哈希链使任何插入/篡改/删除都可被检测（账本完整性 = head 与重放一致）。q_i 为质量门：q_i<q_min 的样本只能进"离线待审"桶，永不直接进安全阈值更新。

**新增定义 545（LiDAR 健康度与退化管理 LiDARHealth）** h_L 由六项加权：近距回波率、强度分布熵、多回波比例、地面点占比、时序配准残差、近距饱和比。h_L<τ_L ⇒ LiDAR 降级：注入中立元 g_L=+∞（不否决）、C_L:=True、K_L:=K_max、并置 lidar_degraded 审计位；此时 K_eff^{v10}=K_eff^{v9}，行为严格退回 v9。降级不等于静默：审计位进入日志与账本（可区分性，沿用 v9 的日志纪律）。

**新增定义 546（时空标定证书 SpatiotemporalCalibrationCertificate）** C_cal 有效 ⇔ |Δξ−Δξ̂| ≤ τ_ξ ∧ |Δτ−Δτ̂| ≤ τ_τ ∧ MI(P_t, I_t) ≥ τ_MI（LiDAR 与相机/里程计互信息）。任一越阈 ⇒ C_cal=False ⇒ C_L=False（宁可保守），并向 APL 写一条 calibration_drift 事件；若连续越阈超过 T_cal 回合，则按定义 545 走中立退化（避免把系统性标定错误误判为真实障碍，造成长期过保守）。

**新增定义 547（数据飞轮状态机 DataFlywheelFSM）** 状态 ∈ {idle, triggered, collecting, verifying, committing, cooldown}：
- idle→triggered：E_opt 计数超阈 ∨ U 峰值超阈 ∨ DA-ML 报警 ∨ h_L 恢复；
- triggered→collecting：A_coll≠∅ 且距上次采集 ≥ C_cool；否则回 idle；
- collecting→verifying：采集回合结束或预算耗尽；
- verifying→committing：回放验证（交叉证书在回放中仍成立、且不引入 E_opt）；
- committing→cooldown：账本提交并经截尾更新（定义 548）；
- cooldown→idle：冷却结束后可再次触发。
任一状态失败 ⇒ 回 idle 且本回合零副作用。

**新增定义 548（有界影响阈值更新 BoundedInfluenceUpdate）** 窗口样本数 N，最多接纳 W 条新样本，截尾比例 α ≥ W/N。对候选阈值 θ 的新估计用 α-截尾均值（分位数 [α/2, 1−α/2] 之外剔除）：
```
θ_new = clip( TrimmedMean_{α}( {θ_i} ∪ {new} ), θ_old − Δ_max, θ_old + Δ_max )
```
安全关键阈值（M₀ 门限、SpatialCert 门限、τ_dom/τ_SLAM）额外要求来源验证且 Δ_max 极小；因此任意 ≤W 条恶意样本对 θ 的位移被截尾分位数与 Δ_max 双重夹住（引理 90）。

**新增定义 549（几何门控有效块长 GeometricEffectiveChunk）**
```
K_L(t) = 1                                         若 h_L<τ_L ∨ ¬C_cal ∨ E_opt
       = K_max                                     若几何锚中立（退化）
       = max(1, ⌊K_max·(1 − d_frac(t))⌋)           否则，d_frac=近距分歧体素占比
K_eff^{v10}(t) = min( K_eff^{v9}(t), K_L(t) )
```
单调性：K_eff^{v10} ≤ K_eff^{v9}，故几何锚只会让决策更保守；中立时严格相等（引理 92）。

# IP-357 LiDARGeometryAnchor：几何锚（射线投射 + 健康度 + 单向否决）
class LiDARGeometryAnchor:
    def __init__(self, grid, eps_r=0.03, eps_margin=0.05,
                 d_safe=0.15, tau_L=0.6, delta_theta=0.0045):
        self.grid = grid                  # 体素占用网格（unknown 初始）
        self.eps_r, self.eps_margin = eps_r, eps_margin
        self.d_safe_L = d_safe + eps_margin
        self.tau_L, self.delta_theta = tau_L, delta_theta

    def update(self, cloud, pose, calib):
        obs = raycast_occupancy(cloud, pose, self.grid)   # free/occ/unknown
        self.h_L = self._health(cloud, obs, calib)
        self.calib_ok = calib.valid                        # 定义 546
        return obs

    def certify(self, chunk, obs):
        if self.h_L < self.tau_L or not self.calib_ok:
            return True, float('inf'), 'lidar_neutral'      # 中立：不否决
        g_L = self._clearance_lower_bound(chunk.traj, obs)
        ok = g_L >= self.d_safe_L
        return ok, g_L, ('valid' if ok else 'model_optimistic')

    def _clearance_lower_bound(self, traj, obs):
        g = min(self._dist_to_occ_or_unknown(x, obs) for x in traj)
        r_max = max(self._range(x) for x in traj)
        rho = r_max * self.delta_theta                      # 角分辨率膨胀
        return g - self.eps_r - rho

    def geometric_K(self, obs, disagreement_frac, neutral):
        if neutral:
            return None                                     # ⇒ K_L = K_max
        if disagreement_frac > 0:
            return 1
        return max(1, int(self.K_max * (1 - disagreement_frac)))


def cross_certificate(chunk, v9_cert, lga, obs):
    """C_cross = C_v9 ∧ C_L；返回 (ok, reason, g_L)"""
    cL_ok, g_L, why = lga.certify(chunk, obs)
    if not v9_cert.valid:
        return False, 'v9_invalid', g_L
    if not cL_ok:
        return False, 'cross_veto:' + why, g_L        # E_opt ⇒ 中止 + 触发采集
    return True, 'cross_valid', g_L


# IP-358 ActiveDataCollector：安全可采集集内的信息增益最大化
class ActiveDataCollector:
    def __init__(self, chunker, lga, ledger, B_coll=100, C_cool=30.0):
        self.chunker, self.lga, self.ledger = chunker, lga, ledger
        self.B_coll, self.C_cool = B_coll, C_cool
        self.state, self.last_collect_t = 'idle', -1e9

    def propose(self, ctx, candidates):
        A = []
        for z in candidates:
            v9_ok = self.chunker.certify_v9(z, ctx)          # C_v9
            c_ok, _, _ = cross_certificate(z, v9_ok, self.lga, ctx.obs)
            if c_ok and z.steps <= self.B_coll and z.abort_points:
                A.append(z)                                  # 定义 543
        if not A:
            return None                                      # A_coll=∅ ⇒ 不采集
        return max(A, key=lambda z: self._information_gain(z))  # IG 仅作排序

    def _information_gain(self, z):
        return (self._entropy(self.ctx.U, z.start)
                - sum(p * self._entropy(self.ctx.U_after(z, o))
                      for o, p in z.predicted_observations)) / z.steps


# IP-359 AcquisitionProvenanceLedger：哈希链账本 + 质量门 + 有界影响更新
class ProvenanceLedger:
    def __init__(self, q_min=0.8, W=20, alpha=0.2, delta_max=0.01):
        self.q_min, self.W, self.alpha = q_min, W, alpha
        self.delta_max, self.head, self.records = delta_max, '0'*64, []

    def append(self, t, pose, cloud_hash, trigger, q, calib, cert):
        rec = dict(t=t, pose=pose, cloud=cloud_hash, trigger=trigger,
                   q=q, calib=calib, cert=cert, prev=self.head)
        self.head = sha256(json.dumps(rec, sort_keys=True)).hexdigest()
        self.records.append(rec)
        return self.head

    def admit(self, rec):
        return rec['q'] >= self.q_min and rec['calib'].valid and self.verify(rec)

    def bounded_update(self, theta_old, candidates):
        new = [c for c in candidates if self.admit(c)][:self.W]   # 配额 W
        if not new:
            return theta_old
        est = trimmed_mean([c['theta'] for c in new], self.alpha)  # 截尾
        return clip(est, theta_old - self.delta_max, theta_old + self.delta_max)


# IP-360 DataFlywheelController：六态机（无 Zeno、失效零副作用）
class DataFlywheelController:
    def __init__(self, adc, ledger, lga, C_cool=30.0):
        self.adc, self.ledger, self.lga = adc, ledger, lga
        self.state, self.t_last = 'idle', -1e9

    def step(self, t, ctx, disagreement_count):
        trig = (disagreement_count > ctx.tau_dis
                or self._peak(ctx.U) > ctx.tau_U
                or ctx.da_alarm)
        if self.state == 'idle' and trig and t - self.t_last >= self.adc.C_cool:
            self.state = 'triggered'
        elif self.state == 'triggered':
            self.plan = self.adc.propose(ctx, ctx.candidate_chunks)
            self.state = 'collecting' if self.plan else 'idle'
        elif self.state == 'collecting':
            if self.plan.done or self.plan.steps >= self.adc.B_coll:
                self.state = 'verifying'
        elif self.state == 'verifying':
            self.state = 'committing' if self._replay_ok() else 'idle'
        elif self.state == 'committing':
            self.ledger.bounded_update(ctx.safe_thresholds, self.plan.samples)
            self.state, self.t_last = 'cooldown', t
        elif self.state == 'cooldown' and t - self.t_last >= self.adc.C_cool:
            self.state = 'idle'

## 4. 推导

**引理 87（几何锚的可靠下界与单调安全）** 设射线投射把未被任何射线穿过的体素判为未知并按占用处理，距离噪声 |ε| ≤ ε_r，角分辨率 δθ 使一条射线间隙在距离 r 处最多漏掉角宽 δθ 的障碍（其切向尺度 ≤ r·δθ）。则对任意轨迹 ζ：(i) g_L(ζ) ≤ g_true(ζ)（g_L 是真净空下界）；(ii) C_L(ζ) ⇒ g_true(ζ) ≥ d_safe（取 d_safe_L=d_safe+ε_margin ≥ d_safe）；(iii) 接受集单调：C_cross = C_v9 ∧ C_L ⊆ C_v9。故接入 LGA 不引入任何相对 v9 的新不安全行动，且其通过意味着真实几何净空达标。证明：(i) 未知=占用只会增加障碍集合 ⇒ 距离估计偏小，再减 ε_r 与 r·δθ 单调更小；(ii) 由 (i) 与 g_L ≥ d_safe+ε_margin；(iii) 合取只会删元素。∎

**引理 88（交叉证书的及时中止）** 记最大速度 v_max、LiDAR 有效量程 R_L、从采点到守卫判定总延迟 τ_g（采集+配准+投射+守卫）。若
```
R_L ≥ d_brake(v_max) + d_safe + v_max·τ_g
```
则对任意 v ≤ v_max，新出现的几何障碍在进入"刹停距离 + d_safe"之前至少已被 LGA 观测到一个守卫周期，E_opt 触发后切至中止点 p* 并停驻，不发生碰撞。特别地，当 F̂ 乐观偏差 δ > β 时，LGA 在本帧即可否决，无需等待 Δ_dom 的 20 帧滑窗，从而消除 v9 的"DA 滞后 × 模型误差"耦合风险。证明：由量程-时间预算，障碍首次可观测距离 ≥ d_brake(v)+d_safe+v·τ_g；守卫延迟 τ_g 内前进 v·τ_g，仍有 d_brake(v)+d_safe 余量可刹停；由定义 534/541 的 p* 存在性，停驻可行。∎

**引理 89（采集探索的安全不变式）** 每个采集机动 ζ^coll ∈ A_coll ⊆ C_v9 ∩ C_L 且 P(ζ^coll) ≠ ∅。对采集轨迹逐步归纳：初始状态由 v9 安全不变式成立；任意一步的候选动作都通过 C_v9 与 C_L，且存在中止点，所以该步可执行或可安全停驻；A_coll=∅ 时不执行任何采集动作。故整个采集过程（及所有回合的并）都不违背 v9 安全不变式与几何净空约束，采集不会成为新的风险源。∎

**引理 90（账本有界影响与抗投毒）** 设窗口 N 条样本、每窗口最多接纳 W 条新样本、截尾比例 α > W/N。(i) 任意 ≤W 条恶意样本全部落在截尾分位之外时被剔除，故对 α-截尾均值的影响为 0；即使部分落入保留区，其相对位移 ≤ (max−min)·W/(N(1−2α))；(ii) 更新再经 Δ_max 夹逼，故单次采集回合对安全阈值的位移 ≤ Δ_max；(iii) 哈希链使插入/篡改/删除改变 head，verify 失败即拒绝。三者合取 ⇒ 任意有限采集回合（含投毒/标定漂移样本）不能翻转 M₀ 判据（在其安全裕度 > Δ_max 时）。∎

**引理 91（飞轮无 Zeno 与采集占空比有界）** 每次采集前必须满足 t−t_last ≥ C_cool，且单回合步数 ≤ B_coll；故任意时间区间 T 内采集回合数 ≤ ⌈T/(C_cool+B_coll·Δt)⌉，采集占空比 ≤ B_coll·Δt/(C_cool+B_coll·Δt)。状态迁移次数有限，无 Zeno；失败分支零副作用返回 idle，不产生额外迁移。∎

**引理 92（中立元退化 ≡ v9）** 逐模块核对：(i) LGA 失败（h_L<τ_L ∨ ¬C_cal ∨ 超时）⇒ g_L=+∞、C_L:=True、K_L=K_max，于是 C_cross=C_v9 且 K_eff^{v10}=K_eff^{v9}，与 v9 逐位一致；(ii) 未装 LiDAR ⇒ 同上；(iii) ADC/飞轮失败 ⇒ 不采集、不改阈值，而 v9 本就不采集，任务环可观测行为相同；(iv) APL 失败 ⇒ 冻结阈值更新，沿用 v9 阈值。故全部新模块中立时，所有端口取值等于 v9，安全性由 v9 引理 82–86 直接传递。∎

## 8. 本轮最大风险

**一句话**：飞轮的触发器是"几何-学习分歧"，但分歧也可能来自 LiDAR 自身错误——透明玻璃、镜面反射、雨雾衰减会让几何锚"看不见障碍"而给出虚假一致，或"处处占用"而过度保守；系统随后会主动采集**错误锚点指出的区域**，把错误信念写进账本与阈值，形成"锚点错 → 采错数据 → 模型更错"的**信念污染环**。
