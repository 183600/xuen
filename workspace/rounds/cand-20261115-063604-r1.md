# 第 1 轮（灵感循环第 1 轮；本轮灵感：「记忆检索」×「技术融合」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 1 轮 LeanGauge / MODGAUGE 与第 2 轮 ToolGauge 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。两个新灵感各沿一条轴升级 InstructGauge：记忆检索提供「经验的先验」，技术融合提供「异质证据的合成」；二者都只能是先验/证据的增强，任一环节不可用都必须能一键退回 InstructGauge，记忆与融合是增强项、不是依赖项。

## 0. 直觉与动机

**灵感 1（记忆检索 → 经验先验，不是经验真理）**
直觉：人类工程师修一个新盲区时不会从零开始，而是先想起「上次这种高反光金属件、这种偏振配置是怎么成功的」。InstructGauge 每轮都会产出 `RepairCert′`（指令→块→回执→主张），这本身就是一条可检索的经验。把过去的修复情节组织成**经验记忆库**，用当前盲区上下文做近邻检索，就能把接地先验、假设先验、初始块长 `K₀`、校准分层热启动，降低冷启动成本并提升一致性。但记忆的危险恰恰在于「像」不等于「同」：**旧经验只能改变先验，绝不能改变物理可行域与安全阈值**。检索到的经验若与当前上下文分布不匹配，就是负迁移；记忆若被污染，就是一条会自我复制的错误先验。因此正确的接口是「检索 → 带证书的经验先验」，而不是「检索 → 直接复用动作」。

**灵感 2（技术融合 → 异质证据的合成，但相关失效会伪造共识）**
直觉：单一测量技术总有盲区——光学怕高反光，触觉怕深槽，声学怕吸声材料。把多种技术（光学/触觉/声学/热/射线）的证据融合，本应像多个独立证人互相印证，降低方差、提高覆盖。但「多个证人」只有在**独立**时才有价值：若几种技术共享同一物理假设（同光源、同夹具、同标定漂移），它们的错误是**相关**的，融合后不是「更准」，而是「更自信地错」——这就是相关失效伪造出的虚假共识。故技术融合必须配三道闸：**逐技术健康检查**（饱和/漂移/失效即降权或剔除）、**相关失效守卫**（高相关技术合并为虚拟单源，不得重复计票）、**抗拜占庭聚合**（少数技术可任意错时用中位数/截尾均值保证稳健）。融合只做证据合成，不做能力扩张，且必须可逐技术审计与回退。

**灵感 3（两者耦合 → 检索-融合的自增强回路）**
直觉：记忆检索会告诉你「上次这几项技术组合最有效」，融合又会产生新证据写回记忆，下一次检索就更偏好这几项技术——这形成一个**自增强回路**（回声室/确认偏置）。最危险的不是单次检索错或单次融合错，而是：一次相关失效被融合成「共识」→ 作为成功经验写入记忆 → 检索优先复用该技术组合 → 下次相关失效被更快「确认」。解法不是断开耦合，而是结构隔离：**记忆写入闸**（融合证据不得单独入库，必须有独立原始回执）、**检索多样性配额**（强制保留异技术探索）、**融合-记忆解耦**（检索对技术选择的先验权重设上限，不得永久排除任一健康技术）、以及**回路增益监测**（技术选择熵低于阈值即注入探索）。

## 1. 研究问题（本轮要回答什么）

- **Q1（记忆的安全性）**：如何让历史修复经验成为可审计的先验增强，而不是负迁移与投毒的入口？「检索只改先验、不改可行域」能否被类型化保证？
- **Q2（融合的可信性）**：异质技术融合在什么独立性条件下真正降低方差？相关失效与拜占庭故障下，融合的稳健界如何量化？
- **Q3（耦合的自增强）**：检索选择技术、融合写回记忆构成的闭环，是否必然导致回声室？能否用写入闸 / 多样性配额 / 增益监测把回路压成有界、可证伪？

## 2. 三条设计原则（雏形，正式化见产物区定义 448–463）

**P1 记忆先验闭包（Memory-Prior Closure）**
检索到的情节只能通过有界混合权重 `β ≤ β_max` 重排先验（假设、初始 `K₀`、接地置信、校准分层），不得新增工具/目标、不得放宽 CVC 与安全阈值、不得抬高 `K_MAX`。形式化方向：`Plan(ι ⊕ π_ret) = Plan(ι)`——记忆只改**采样分布**、不改**可行集**。越权先验一律投影回在线先验。

**P2 融合独立性守卫（Fusion Independence Guard）**
融合前必须估计技术间残差相关；高相关技术合并为「虚拟单源」，不得重复计票；少数技术可任意错时用抗拜占庭聚合；任一技术饱和/漂移/失效即降权或剔除。融合只在**可采纳融合集** `𝔸_fuse` 上成立，且出具融合证据证书 FEC，逐技术可审计、可回退。

**P3 回路解耦与多样性（Loop Decoupling & Diversity）**
记忆写入必须有独立原始回执（融合证据不得自证入库）；检索对技术先验的权重设上限且保留探索配额；监测技术选择熵 `H_T`，低于阈值则强制探索。目标是保证检索-融合回路增益 `γ < 1`，使「经验—证据」闭环有界。

## 3. 与基线的接口（如何退化）

- 无有效检索 / 全部情节未通过 AVC ⇒ 冷启动，等价 InstructGauge（记忆为空）；
- 融合不可采纳（相关过高 / 剔除过多 / 只剩单一技术）⇒ 退回最可靠单技术，等价 InstructGauge 单模态路径；
- 记忆写入闸拒绝 ⇒ 不入库，不改变任何在线行为（纯写侧约束）；
- 融合分层校准样本不足 ⇒ 回退技术无关层 ⇒ 回退全局共形；
- InstructGauge 失效 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个「检索只改先验、不改能力」的经验记忆口径 + 类比有效性证书，把负迁移与投毒压到可类型检查的范围；
2. 一个带相关失效守卫与拜占庭稳健聚合的多技术融合层，给出方差缩减与相关失效下的显式界；
3. 一个「记忆写入闸 + 多样性配额 + 回路增益监测」的解耦方案，把检索-融合自增强回路压成有界、可证伪；
4. 一条完整可证伪路径：E457–E472 覆盖检索命中、负迁移、投毒、相关失效、拜占庭、融合覆盖、回声室、对抗记忆注入与 50Hz 时序保全。

## 5. 本轮最大风险

**一句话**：记忆检索与多技术融合耦合后，会把「相关失效伪造的共识」经一次成功入库固化为「经验」，再经检索优先复用，形成自我确认的回声室；此时系统越用越「自信」，但置信度增长与真实准确率脱钩，而写入闸与多样性配额只能延缓、不能消除这一偏差。

## 2. 形式化定义（要点）

**定义 448（经验情节 e）** `e = (id, q, ι, C, ChunkCert, receipts, claims, outcome, provenance, age)`。`q` 为上下文描述子；`outcome` 记录由**独立技术回执**验证的成功/失败，而非系统自报；`provenance` 记录来源签名（真实原始 / 仿真 / 融合派生）；`age` 为入库后的时间戳。情节是 InstructGauge `RepairCert′` 的可检索化封装。

**定义 449（上下文描述子与检索）** `q = (b, m, T, 𝒯_q, s, f)`；距离 `d(q,q') = Σ_k α_k·‖q_k − q'_k‖_1 + (1−cos(b, b'))`。检索 `Ret(q, M_ep) = top-k argmin_{e} d(q, e.q)`，先取 `k_pool ≥ k` 候选，再经 AVC 过滤与多样性筛选。检索是**离线/异步**的，不进入 50Hz 路径。

**定义 450（类比有效性证书 AVC）** `AVC(e,q) ∈ {valid, invalid(reason)}`。仅当同时满足：(i) `provenance` 为独立原始回执支撑（非纯融合派生）；(ii) 上下文分布 `TV(P_ctx(e), P_ctx(q)) ≤ ρ`；(iii) `outcome` 经独立技术验证成功；(iv) `age(e) ≤ A_max`；(v) 与已选集合的多样性 `d(e, e_j) ≥ d_min`。任一失败 ⇒ `invalid`，该情节不参与先验混合。

**定义 451（记忆先验混合与非扩张）** `π_ret = Mix(π_live, {π_{e_i}}, β)`，其中 `β = min(β_max, g(conf_AVC))`。硬约束：`Plan(ι ⊕ π_ret) = Plan(ι)`、`K_MAX` 不增、CVC/安全阈值不降。若 `π_ret` 提及 `T₀` 外的工具或 `M_phys` 外的幅值，则投影回 `π_live`。即：记忆只改变假设与初始化的**采样分布**，不改变可行集。

**定义 452（负迁移界）** 若检索情节的真实上下文与 `q` 的 TV 距离为 `ε`，先验失配导致的期望超额损失 `ΔL ≤ L·β·ε + O(β²)`。当 `ε > ρ` 时 AVC 已拒绝；故在有效检索内 `ΔL ≤ L·β_max·ρ`，负迁移被「证书半径」与「混合上限」双重夹住。

**定义 453（记忆写入闸 MWG）** 情节入 `M_ep` 须同时满足：≥1 条**非融合**独立原始回执、`ChunkCert` 存在、`provenance` 签名有效、`outcome` 由独立技术验证、且不处于隔离期。**融合证据（无原始回执）一律不得单独入库**。这是切断自证污染回路的结构性条件。

**定义 454（记忆新鲜度与多样性）** `age(e) ≤ A_max`；库内技术组合熵 `H(bank) ≥ H_min`；任一技术组合占比 `≤ π_max`。超限触发淘汰或强制探索。该约束防止记忆库退化为单一组合的自我复制。

**定义 455（技术族与证据）** 技术 `τ_j ∈ 𝒯`，证据 `z_j = θ + η_j`，噪声 `η_j ~ P_j`（可非高斯），协方差 `Σ_j`，延迟 `ℓ_j`，健康态 `h_j ∈ {ok, degraded, failed}`。各技术可有独立标定与量纲，融合前须对齐到公共量。

**定义 456（融合算子与权重）** `Fuse({z_j}) = Σ_j w_j z_j`，`w ∈ Δ`（单纯形）。独立高斯时逆协方差权重 `w ∝ Σ^{-1}1` 给 `Var(ẑ) = (Σ_j 1/σ_j²)^{-1}`；含相关阵 `R` 时 `Var(ẑ) = w^T Σ w`。融合只合成证据，不新增工具能力。

**定义 457（融合防火墙 FFW）** 四道闸：(i) **健康闸**：`h_j ≠ ok` ⇒ 权重置 0 或降权；(ii) **相关守卫**：若估计相关 `ρ̂_jk > ρ_max`，将 `{j,k}` 合并为虚拟单源，只计一票——共享物理假设的技术不得重复印证；(iii) **抗拜占庭**：至多 `f` 个技术任意错时，用坐标中位数 / 截尾均值，崩溃点 `≥ 1/2`；(iv) **饱和守卫**：残差超稳健尺度 `κ·σ̂` ⇒ 剔除该技术。

**定义 458（融合证据证书 FEC）** `FEC = ({z_j}, w, ρ̂, σ̂, rejected, virtual_sources, coverage, freshness)`。逐技术记录权重、残差、是否被合并/剔除，使融合可审计、可回退，并作为记忆写入输入。

**定义 459（融合分层共形 FSC）** `stratum_fuse = (s, T_used, availability)`，即（指令层, 实际融合技术集, 可用性模式）。层内取分位 `q_s^{fuse}`，使层内覆盖 `P(θ∈Ĉ | stratum_fuse) ≥ 1−α`；若 `|C_cal^{s,fuse}| < n_min` ⇒ 回退技术无关层 `(s, ·)` ⇒ 再回退全局共形。融合选择是数据相关的，破坏全局可交换性，故必须分层。

**定义 460（回路增益与回声室指标）** 技术选择熵 `H_T(t)`；回路增益 `γ = ∂(未来检索技术先验权重)/∂(当前融合权重)`。运行约束 `γ < 1` 且 `H_T ≥ H_min`；若违反，注入探索配额 `ε_exp`（强制纳入至少一个非首选健康技术）。该指标把「回声室」从定性担忧变成可监测的标量。

**定义 461（可采纳融合集 𝔸_fuse）** 满足 FFW 且至少含两个**独立**（未被虚拟合并的）健康技术时，`𝔸_fuse` 为融合集；否则 `𝔸_fuse = {最可靠单技术}`，退化为单模态。

**定义 462（融合信息增益与相关失效下界）** 独立时 `ΔH_fuse = ½ log(σ²_single / (w^T Σ w))`；相关失效下有效源数 `n_eff = n / (1 + (n−1)ρ̄)`，`ΔH_fuse ≤ ½ log(1 + (n_eff−1))`。`ρ̄ → 1` 时 `n_eff → 1`，融合增益归零——这是相关守卫必要性的定量依据。

**定义 463（MemFuse 解释证书 RepairCert″）** `RepairCert″ = (q, Ret结果, AVC, ι, C, ChunkCert, FEC, receipts, claims)`，构成六级证据链：**检索 → 类比 → 指令 → 块 → 融合 → 主张**，使人类审计可逐级复现一次修复的「为何想起、为何相信、为何融合」。

## 4. 推导

**引理 59（记忆先验的能力闭包）** 在 `Mix` 与 `β ≤ β_max` 及 `project_to_capability` 投影下，检索不改变 `Plan` 可行集、`K_MAX` 与安全阈值；若 `π_ret` 提及 `T₀` 外工具或超包线幅值，则被投影回 `π_live`，等价于无检索。推论：记忆层不是越权通道，与 InstructGauge 引理 51 的能力闭包同构。
*证明骨架*：`Plan` 只依赖 `(ι, 目标/约束/工具集)`；`Mix` 只作用于先验分布 `π`，而 `Plan` 对 `π` 不可见；投影算子按定义把越权分量置零，故可行集不变。

**引理 60（负迁移界）** 若检索情节的真实上下文与 `q` 的 TV 距离为 `ε`，则先验失配的期望超额损失 `ΔL ≤ L·β·ε + O(β²)`；由于 AVC 仅在 `ε ≤ ρ` 时放行，`ΔL ≤ L·β_max·ρ`。故负迁移被证书半径与混合上限双重夹住，且随 `β_max` 单调。
*证明骨架*：先验扰动经 `L`-Lipschitz 损失放大为 `L·β·ε`；TV 距离控制分布失配；`O(β²)` 来自混合的二阶项。

**引理 61（写入闸抗污染）** 若融合证据不得单独入库、且入库需独立原始回执 + 独立技术验证，则单点相关失效或单技术投毒无法形成可检索的「成功经验」；要制造可检索污染须同时攻破至少两条独立通道，其概率上界 `≤ p₁·p₂`（`p_j` 为单通道被攻破概率）。
*证明骨架*：MWG 对来源与验证做合取门槛；融合派生证据在来源检查处被拒；独立通道的失效事件近似独立，故联合概率乘性下降。

**引理 62（融合方差缩减 vs. 相关失效）** 独立时 `Var(ẑ) = (Σ_j 1/σ_j²)^{-1} < min_j σ_j²`；相关 `ρ` 时 `Var(ẑ) ≤ σ²(1+(n−1)ρ)/n`，有效源数 `n_eff = n/(1+(n−1)ρ)`。`ρ → 1` 时 `n_eff → 1`，融合无收益。推论：融合收益随独立性单调，相关守卫（合并虚拟单源）是收益存在的必要条件。
*证明骨架*：对 `w^T Σ w` 在单纯形上最小化；相关阵 `R = (1−ρ)I + ρ11^T` 时闭式给出 `n_eff`。

**引理 63（拜占庭崩溃点）** 坐标中位数在 `n` 个技术、至多 `f < n/2` 个任意错时，误差 `≤ σ̂·O(√(f/n))`；`α`-截尾均值的崩溃点为 `α`。故 FFW 在 `f < n/2` 时保证有界偏差，超过崩溃点则显式降级为单技术。
*证明骨架*：中位数对至多 `n/2` 个异常值稳健；截尾均值丢弃极端分位后，污染比例受 `α` 限制。

**引理 64（融合分层共形覆盖）** 层内可交换下 `P(θ∈Ĉ | stratum_fuse) ≥ 1−α`；融合选择是数据相关选择事件，会破坏全局可交换性，故不分层时覆盖可逐层低于 `1−α`。低样本回退技术无关层时，覆盖按 `−2η` 优雅降级。
*证明骨架*：标准共形在层内可交换假设下成立；选择效应使全局校准集不再是层内可交换样本，必须按选择事件分层；回退的覆盖损失由层间 TV 距离 `η` 界定。

**引理 65（回路有界性）** 设检索-融合回路增益为 `γ`，多样性配额 `ε_exp` 保证 `H_T ≥ H_min`；若 `γ < 1`，则检索技术先验权重偏离度 `‖Δw‖` 收敛到半径 `≤ ε_exp/(1−γ)` 的有界邻域。故回声室在 `γ<1` 时被夹住；`γ → 1` 时界发散，这正是残余风险。
*证明骨架*：把技术先验更新写成仿射迭代 `w_{t+1} = γ·A w_t + ε_exp`；`γ<1` 时谱半径 < 1，几何收敛到唯一不动点的有界邻域。

**引理 66（端到端退化与 50Hz 保全）** 检索与融合均在异步路径，主循环新增周期 `< 0.2ms`；任一组件失效按退化链回到 InstructGauge / ToolGauge / LeanGauge / MODGAUGE，未涉及子图的逐指令等价性由 InstructGauge 引理 57 与 ToolGauge 引理 49 继承；新增 `RepairCert″` 的检索/融合字段仍是纯投影，不改变数值行为。
*证明骨架*：异步下沉使最坏新增周期与 `K`、`n` 解耦；退化链逐级替换为已验证组件；证书字段只读不参与控制流。

## 8. 本轮最大风险

**一句话**：`ERM` 的检索先验与 `FFW` 的融合权重在闭环处形成**自我确认回路**——相关失效若被融合成「共识」并经一次成功入库固化为经验，检索会系统性地优先复用同一技术组合，使技术选择熵下降、置信度增长与真实准确率脱钩；`MWG` 与多样性配额只能延缓这一漂移，`γ → 1` 时偏差界发散，因此真正的残余风险在「记忆—融合」接口的分布外固化，而非单次检索或单次融合本身。
