### 第 1 轮灵感驱动研究记录

**灵感词**：数据采集、工具调用

**直觉与动机**：
现有 SRC-USC（IP-447）已把安全证书链扩展到「结构-力学-语义-重构-协同」七证一体，但七证共享一个从未被审查的隐含前提：**生成与验证这些证书所依赖的数据和工具，是可信、充分且不变的**。任何证书其实都架在两座「隐形的桥」上。第一座是数据：conformal 语义覆盖依赖校准集，SOC 应力许用依赖材料实测，MCC 碰撞率依赖蒙特卡洛采样；一旦采集存在选择偏差、样本不足、标签噪声、训练/测试泄漏或部署分布漂移，那么「ℙ(s_i∈C(x))≥1-α」不过是一句没有地基的断言——垃圾进、证书出。第二座是工具：证书的计算大量外包给云边校准服务、运动规划器、物理仿真器、外部求解器、LLM 任务规划器，甚至其他机器人；若把这些黑箱无条件信任，未经验证的输出就会「洗白」进证书链，形成**证书洗钱（certificate laundering）**——一个不可靠的规划器产出的轨迹，只要前面盖了章，就可能提升执行集。受「数据采集」启发，采集本身应是一个受证书约束的主动过程：采多少、采哪里、是否可交换、输入空间是否被覆盖，都必须可证；受「工具调用」启发，工具调用应遵循 assume-guarantee 契约并携带可独立复核的后置证书，组合即证书合成。核心洞见：**数据采集是证书的「地基灌注」，工具调用是证书的「组合粘接」；缺了 DAC 与 TIC，七证大厦悬空**。

**形式化目标**：
1. 定义数据采集证书（DAC）：由「交换性/漂移」「样本充分性」「输入空间覆盖」「标签与泄漏纯度」「采集能耗」五组独立可复核条件构成，使 conformal 覆盖从「假设」升级为「采集过程可证」。
2. 定义工具调用证书（TIC）：带类型契约 (Pre, Post, Cert) 的调用、输出独立复核、assume-guarantee 组合蕴含、版本哈希钉扎与远程签名新鲜性、不可验证 oracle 的信任预算封顶、调用能耗/时延预算。
3. 构建数据-工具统一准入门（DTC-USC）：SRC-USC ∪ DAC ∪ TIC 九证一体，$Exec_{v26} = Exec_{v25} \cap Fil_{data} \cap Fil_{tool} \subseteq Exec_{v25}$。
4. 用「证书依赖 DAG」消除自证循环：准入要求证明 DAG 无环、且所有叶子扎根于「无工具或仅确定性已见证工具」的基事实，从结构上禁止证书洗钱。
5. 证明单调退化链在数据失效（漂移/不足/泄漏）与工具失效（漂移/伪造/组合失配）下的保持性，并证明「未验证工具输出不可传递地提升执行集」。
6. 设计分布漂移/主动采集效率/黑箱工具注入三类对抗实验，度量覆盖率、洗钱拦截率与准入延迟。

## 1. 关键算法骨架（在 IP-444–447 骨架上扩展）

```python
# ============================================================
# IP-448 Data Acquisition Certificate (DAC) — 数据采集证书
# ============================================================
@dataclass
class DataAcquisitionCertificate:
    """让『证书所依据的数据』本身可证：分布、样本、覆盖、纯度、能耗"""
    D_cal: 'Dataset'
    D_test: 'Dataset'                 # 部署探测集（可在线滑动窗口）
    alpha: float = 0.05
    delta: float = 0.01               # 覆盖率置信水平
    delta_exch: float = 0.01          # 交换性检验 Type-I
    eps_cov: float = 0.10             # 输入空间覆盖容差
    eta_max: float = 0.02             # 标签噪声上界
    w_budget: float = 5.0             # 密度比上界
    E_budget: float = 1.0             # 采集能耗预算 (kWh)

    def verify_exchangeability(self) -> bool:
        """D_cal 与 D_test 可交换，或协变量漂移有界可加权校正。
        用核两样本检验（MMD）+ 置换 p 值；p >= delta_exch 视为不可拒绝可交换。
        若拒绝，则退而验证密度比上界 w_max <= w_budget（分类器两样本估计）。"""
        p_val = kernel_two_sample_permutation_test(self.D_cal.X, self.D_test.X, n_perm=1000)
        if p_val >= self.delta_exch:
            return True
        w_max = estimate_density_ratio_max(self.D_cal.X, self.D_test.X)
        return w_max <= self.w_budget

    def verify_sample_sufficiency(self) -> bool:
        """有限样本覆盖：以 Hoeffding 界要求 n_cal >= log(1/delta)/(2*(alpha-alpha_0)^2)。"""
        n = len(self.D_cal)
        alpha_0 = 0.5 * self.alpha     # 目标覆盖率收紧一半，留出经验波动余量
        n_min = math.ceil(math.log(1.0 / self.delta) / (2.0 * (self.alpha - alpha_0) ** 2))
        return n >= n_min

    def verify_space_coverage(self) -> bool:
        """部署输入流形被校准集 eps_cov-覆盖：max_x∈D_test min_{x'∈D_cal} d(x,x') <= eps_cov。"""
        d = torch.cdist(self.D_test.X, self.D_cal.X).min(dim=1).values
        return float(d.max()) <= self.eps_cov

    def verify_label_quality(self) -> bool:
        """双标注/交叉验证估计标签噪声 eta <= eta_max，且校准标签非模型自产。"""
        eta_hat = estimate_label_noise(self.D_cal)
        return eta_hat <= self.eta_max and not self.D_cal.labels_from_model

    def verify_no_leakage(self) -> bool:
        """训练/校准/测试三者内容哈希两两不相交，杜绝泄漏导致的虚高覆盖。"""
        h_tr = {sha256(x) for x in self.D_cal.train_hashes}
        h_cal = {sha256(x) for x in self.D_cal.sample_hashes}
        h_te = {sha256(x) for x in self.D_test.sample_hashes}
        return not (h_cal & h_tr) and not (h_cal & h_te) and not (h_tr & h_te)

    def verify_energy(self) -> bool:
        return self.D_cal.acquisition_energy <= self.E_budget

    def verify_all(self) -> bool:
        return (self.verify_exchangeability() and
                self.verify_sample_sufficiency() and
                self.verify_space_coverage() and
                self.verify_label_quality() and
                self.verify_no_leakage() and
                self.verify_energy())


# ============================================================
# IP-449 Tool Invocation Certificate (TIC) — 工具调用证书
# ============================================================
@dataclass
class ToolContract:
    name: str
    version_hash: str
    Pre: Callable[['Input'], bool]
    Post: Callable[['Input', 'Output'], bool]
    Cert: Callable[['Input', 'Output'], bool]   # 工具需随输出携带的证书谓词
    unverifiable: bool = False                   # True => 只能用信任预算（如 LLM）
    attestation: Optional['SignedAttestation'] = None

@dataclass
class ToolInvocationCertificate:
    """让『算证书的工具』契约化：契约、复核、组合、见证、信任、开销"""
    trace: list['ToolCall']             # 有序调用 τ_1;…;τ_k 及输入输出
    contracts: dict[str, ToolContract]
    T_budget: float = 0.2               # 不可验证依赖占总证书量的比例上限
    E_budget: float = 0.5
    latency_budget_ms: float = 20.0

    def verify_contracts(self) -> bool:
        """每次调用：前置条件成立 + 版本哈希匹配 + 远程工具签名有效期与 nonce 新鲜。"""
        for call in self.trace:
            c = self.contracts[call.name]
            if not c.Pre(call.input):
                return False
            if c.version_hash != call.observed_hash:
                return False
            if c.attestation is not None:
                if not c.attestation.verify(call.observed_hash) or not c.attestation.fresh(call.nonce):
                    return False
        return True

    def verify_outputs(self) -> bool:
        """后置断言与携带证书由调用方独立复核，绝不信任工具的自我声明。"""
        for call in self.trace:
            c = self.contracts[call.name]
            if not c.Post(call.input, call.output):
                return False
            if not c.Cert(call.input, call.output):
                return False
        return True

    def verify_composition(self) -> bool:
        """assume-guarantee：相邻调用 Post_{τ_i} ⇒ Pre_{τ_{i+1}}；末调用后置蕴含目标。"""
        for a, b in zip(self.trace[:-1], self.trace[1:]):
            if not implies(self.contracts[a.name].Post, self.contracts[b.name].Pre):
                return False
        return True

    def verify_trust_budget(self) -> bool:
        """不可验证 oracle 只能以『提案』身份存在，且其贡献占比 <= T_budget；
        其输出必须被某个可验证下游工具消费并复核，否则一律不计入证书。"""
        total = max(len(self.trace), 1)
        unver = sum(1 for call in self.trace if self.contracts[call.name].unverifiable)
        if unver / total > self.T_budget:
            return False
        for i, call in enumerate(self.trace):
            if self.contracts[call.name].unverifiable:
                downstream = self.trace[i + 1:]
                if not any(not self.contracts[d.name].unverifiable for d in downstream):
                    return False
        return True

    def verify_cost(self) -> bool:
        return (sum(c.energy for c in self.trace) <= self.E_budget and
                max(c.latency_ms for c in self.trace) <= self.latency_budget_ms)

    def verify_all(self) -> bool:
        return (self.verify_contracts() and self.verify_outputs() and
                self.verify_composition() and self.verify_trust_budget() and
                self.verify_cost())

# IP-450 Data-Tool Unified Certificate (DTC-USC) — 九证一体准入门
# ============================================================
@dataclass
class DataToolUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'   # 七证
    dac: DataAcquisitionCertificate                       # 第八证
    tic: ToolInvocationCertificate                        # 第九证

    def build_dependency_dag(self, plan: 'MultiRobotPlan') -> 'DiGraph':
        """每个证书节点记录其数据来源与工具调用轨迹；基事实为叶子。"""
        g = DiGraph()
        for cert_name, support in plan.certificate_support.items():
            g.add_node(cert_name, kind='certificate')
            for dep in support.data_deps:
                g.add_node(dep, kind='data'); g.add_edge(dep, cert_name)
            for call in support.tool_trace:
                g.add_node(call.id, kind='tool'); g.add_edge(call.id, cert_name)
        return g

    def verify_dag_grounded(self, graph) -> bool:
        """无环 + 每个基事实扎根于：原始传感器数据、物理实测、或确定性已见证工具。
        关键：任何证书不得（直接或间接）仅由自身支撑——封死自证循环。"""
        if not nx.is_directed_acyclic_graph(graph):
            return False
        for leaf in [n for n, d in graph.in_degree() if d == 0]:
            if not is_grounded_base_fact(leaf):
                return False
        return True

    def admits(self, multi_plan: 'MultiRobotPlan',
               sensor_data: dict,
               data_cert: DataAcquisitionCertificate,
               tool_trace: ToolInvocationCertificate) -> bool:
        # 1-7. SRC-USC 七证（语义/结构/重构/协同）
        if not self.src_usc.admits(multi_plan, sensor_data,
                                   gt_entities=sensor_data.get('gt_entities'),
                                   queries=sensor_data.get('queries'),
                                   retrieved=sensor_data.get('retrieved')):
            return False
        # 8. 数据采集证书：覆盖/交换/充分/纯度/能耗
        if not data_cert.verify_all():
            return False
        # 9. 工具调用证书：契约/复核/组合/信任/开销
        if not tool_trace.verify_all():
            return False
        # 10. 证书依赖 DAG 扎根且无环（反洗钱的结构性条件）
        graph = self.build_dependency_dag(multi_plan)
        if not self.verify_dag_grounded(graph):
            return False
        return True

class DataToolCertifiedPipeline:
    def __init__(self, config: dict):
        self.dtc = DataToolUnifiedCertificate(

            dac=DataAcquisitionCertificate(
                D_cal=config['D_cal'], D_test=config['D_test'],

                eps_cov=config['eps_cov'], eta_max=config['eta_max'],
                w_budget=config['w_budget'], E_budget=config['E_budget']),
            tic=ToolInvocationCertificate(
                trace=config['tool_trace'], contracts=config['contracts'],
                T_budget=config['T_budget'], E_budget=config['E_budget_tool'],
                latency_budget_ms=config['latency_budget_ms']))
        self.ipam.register_module("dac", ["IP-448"],
            ["exchangeability_test", "sample_sufficiency", "space_covering",
             "label_purity", "leakage_free", "acquisition_energy"])
        self.ipam.register_module("tic", ["IP-449"],
            ["typed_tool_contract", "independent_output_check",
             "assume_guarantee_composition", "attestation_freshness",
             "trust_budget", "invocation_cost"])
        self.ipam.register_module("dtc_usc", ["IP-450"],
            ["nine_certificate_gate", "certificate_dependency_dag",
             "non_laundering", "data_tool_monotonic_chain"])

    def step(self, multi_sensor_data: dict, cloud_update=None) -> tuple[bool, dict]:
        # 1. 主动采集：在覆盖缺口/漂移区自适应补采，先过 DAC
        self._active_acquire(multi_sensor_data)
        if not self.dtc.dac.verify_all():
            return False, {'reason': 'DAC_reject',
                           'dac': self._dac_report()}
        # 2. 用已契约化的工具计算七证（求解器/校准服务/规划器）
        admitted = self.dtc.admits(
            self._plan(multi_sensor_data), multi_sensor_data,
            self.dtc.dac, self.dtc.tic)
        return admitted, {'dac': self._dac_report(),
                          'tic': self._tic_report(),
                          'dag_ok': True}

    def _active_acquire(self, sensor_data: dict):
        """采集即证书生成：优先补最大覆盖缺口 + 漂移检测高分区，受 E_budget 约束。"""
        gap = self.dtc.dac.compute_coverage_gap(sensor_data['deploy_points'])
        drift = self.dtc.dac.compute_drift_scores(sensor_data['deploy_points'])
        budget = self.dtc.dac.E_budget - self.dtc.dac.D_cal.acquisition_energy
        self.dtc.dac.D_cal.extend(self.acquirer.collect(gap, drift, budget))

    def _plan(self, sensor_data: dict) -> 'MultiRobotPlan':
        # 规划器作为工具调用，其输出由 verify_outputs 独立复核（如动力学残差）
        return self.planner.plan(sensor_data)


# 辅助函数
def kernel_two_sample_permutation_test(X, Y, n_perm=1000) -> float:
    """MMD 置换检验，返回 p 值；p 小表示可拒绝『同分布』。"""
    Z = torch.cat([X, Y], 0); n = len(X)
    def mmd2(A, B):
        K = lambda P, Q: torch.exp(-torch.cdist(P, Q) ** 2 / (2 * 1.0 ** 2))
        return (K(A, A).mean() + K(B, B).mean() - 2 * K(A, B).mean())
    obs = mmd2(X, Y).item()
    cnt = 0
    for _ in range(n_perm):
        idx = torch.randperm(len(Z))
        if mmd2(Z[idx[:n]], Z[idx[n:]]).item() >= obs:
            cnt += 1
    return (cnt + 1) / (n_perm + 1)

def estimate_density_ratio_max(X_cal, X_test) -> float:
    """训练分类器区分 cal/test，用其概率比近似 w(x) 上界（clip 防爆）。"""
    clf = DomainClassifier().fit(X_cal, X_test)
    p = clf.predict_proba(X_test)[:, 1].clip(1e-3, 1 - 1e-3)
    return float((p / (1 - p)).max())

def estimate_label_noise(D) -> float:
    """双标注不一致率或 k 折交叉验证残差率，作为噪声率估计。"""
    return float(D.double_label_disagreement_rate)

def implies(post_fn, pre_fn) -> bool:
    """在最弱前置/最强后置的抽象域上检查 Post ⇒ Pre；不可判定时返回 False（保守）。"""
    return SMTImplicationChecker().check(post_fn, pre_fn)

def is_grounded_base_fact(node) -> bool:
    """叶子仅允许：原始传感器读数、物理实测、确定性且已见证工具的输出。"""
    return node.kind in ('raw_sensor', 'physical_measurement', 'witnessed_deterministic')
```

## 2. 复杂度分析（增量）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| DAC 交换性检验 | O(n_perm · n² · d)（MMD 置换） | O(n²) 核矩阵 | n≤10⁴, n_perm=1000 |
| DAC 样本充分性 | O(1) 闭式 | O(1) | 仅算术 |
| DAC 空间覆盖 | O(n_cal · n_test · d) 最近邻 | O(n_cal · d) | n_cal,n_test≤10⁴ |
| DAC 纯度/泄漏 | O(n) 哈希 | O(n) 指纹 | SHA-256 |
| TIC 契约/输出 | O(k · c) 谓词求值 | O(k) 轨迹 | k≤50 调用 |
| TIC 组合蕴含 | O(k · |φ|) SMT | O(|φ|) 公式 | 不可判定即拒 |
| TIC 信任预算 | O(k) 扫描 | O(1) | T_budget=0.2 |
| DTC 依赖 DAG | O(V+E) 拓扑 + 扎根检查 | O(V+E) | V≤证书数，E≤依赖数 |
| DTC 端到端（增量） | +O(n_cal·n_test·d + n_perm·n²) | +O(n²) | 离线采集环 amortize，在线仅 O(k) |

**实时性保证**：DAC 的重计算（MMD/覆盖）放在**采集环**（低频、离线/准静态，1–10Hz 或事件触发），在线控制环只读取其已签发的覆盖/漂移标量，增量 O(1)；TIC 在线仅做 O(k) 谓词复核，DAG 扎根 O(V+E)。故 50Hz 控制关键路径增量可忽略，重活在采集环摊薄。

## 3. 正确性论证（增量）

### 引理 13（数据采集证书的分布-充分-覆盖-纯度-能耗五重保证）
**陈述**：`DAC.verify_all() = True` ⟹ 以 $D_{cal}$ 运行 split conformal，对部署分布上的新样本，覆盖率满足 $\mathbb{P}(Y\in C(X))\ge 1-\alpha-\Delta_{shift}$，其中 $\Delta_{shift}=0$（可交换）或 $\Delta_{shift}\le \mathrm{TV}(p_{cal},p_{test})$（有界漂移经加权校正）。

**证明**：
1. `verify_exchangeability` 通过置换检验不拒绝同分布，或给出密度比上界 $w_{max}\le w_{budget}$；后者进入加权 conformal，其覆盖偏差被 $\tfrac12\sum|p_{cal}-p_{test}|=\mathrm{TV}$ 控制（Tibshirani et al. 2019）。
2. `verify_sample_sufficiency` 用 Hoeffding 界保证经验覆盖以 $1-\delta$ 概率不低于 $1-\alpha_0$，$n_{min}$ 由 $\log(1/\delta)/(2(\alpha-\alpha_0)^2)$ 给出，故有限样本下覆盖率不会因样本过少而系统性崩塌。
3. `verify_space_coverage` 保证部署点落在校准支撑的 $\varepsilon_{cov}$-邻域内，排除「远端外推」导致的条件覆盖失效。
4. `verify_label_quality` 与 `verify_no_leakage` 分别消除标签噪声与泄漏造成的虚高覆盖（二者都会使经验覆盖 > 真实覆盖）。
5. `verify_energy` 仅约束采集代价，不改变统计结论但保证可持续性。
六条件分别对应分布、样本量、支撑、标签、纯度、代价，缺一即拒。
∎

### 引理 14（工具调用证书的契约-复核-组合-见证-信任-开销六重保证）
**陈述**：`TIC.verify_all() = True` ⟹ 调用轨迹 $\Gamma=\tau_1;\dots;\tau_k$ 的复合效果满足目标后置条件，且任何不可验证 oracle 的贡献被 $T_{budget}$ 封顶并被可验证下游消解。

**证明**：
1. `verify_contracts` 保证每个 $\tau_i$ 的前置成立且实现与签名版本一致（含 nonce 新鲜性），排除 TOCTOU 与钉扎错版。
2. `verify_outputs` 对 $\mathsf{Post}_{\tau_i}$ 与 $\mathsf{Cert}_{\tau_i}$ 做**调用方独立复核**，工具自报不作数，故单步可靠性不依赖工具诚实。
3. `verify_composition` 逐对验证 $\mathsf{Post}_{\tau_i}\Rightarrow\mathsf{Pre}_{\tau_{i+1}}$，由霍尔式推理链得复合满足末后置；蕴含不可判定时保守返回 False。
4. `verify_trust_budget` 要求不可验证工具占比 $\le T_{budget}$ 且其后必有可验证工具消费，故其错误无法原样穿透到最终证书——这正是「输出复核 + 信任封顶」对不诚实 orale 的消解。
5. `verify_cost` 约束能耗/时延，保证调用在物理预算内。
∎

### 引理 15（证书依赖 DAG 的扎根性与反洗钱）
**陈述**：若 `verify_dag_grounded(𝒢)=True`，则任一被准入的证书都可沿 $\mathcal{G}$ 反向追溯至基事实 $\mathsf{Leaf}(\mathcal{G})$，且不存在「证书仅由自身（或环形依赖）支撑」的节点。

**证明**：`nx.is_directed_acyclic_graph` 保证存在拓扑序，沿入边反向必在有限步终止于入度 0 的叶子；`is_grounded_base_fact` 逐叶校验其类型属于原始传感器/物理实测/已见证确定性工具。若某证书被未验证工具输出支撑，则该工具节点既非三种合法叶子、又必须由更下游复核消解（引理 14 第 4 点），否则叶子校验失败。因此洗钱路径（未验证输出→证书→更大执行集）在结构上被切断。
∎

### 引理 16（九位一体单调退化链终极延伸）
**陈述**：任意单点/组合失效下，$Exec_{v26}\subseteq Exec_{v25}\subseteq\cdots\subseteq Exec_{v18}$ 恒成立。

**证明**：在引理 12 基础上增加两条退化路径：
- 数据失效（漂移超界/样本不足/覆盖缺口/泄漏）→ `DAC=false` → `DTC-USC` 拒证 → 退回 $Exec_{v25}$（沿用旧校准集与保守覆盖，任务收敛但安全证书基座不变）。
- 工具失效（版本漂移/签名失效/组合失配/信任超预算）→ `TIC=false` → 拒证 → 退回 $Exec_{v25}$（禁用该工具，改用已验证确定性路径或人工接管）。
- 组合失效：两过滤器取交，$Exec_{v26}=Exec_{v25}\cap Fil_{data}\cap Fil_{tool}$ 对两个集合单调，故链保持。
∎

### 定理（DTC-USC 九证准入门的安全-合规-…-语义-重构-协同-数据-工具完备性）
**陈述**：对任意多机计划 $\Pi$ 及其支撑数据 $\mathcal{D}$、工具轨迹 $\Gamma$，`DTC-USC.admits(Π)=True` ⟺ $\Pi$ 同时满足：
(1)–(10) SRC-USC 的十项条件，
(11) 数据分布可交换或漂移有界、样本充分、输入空间被覆盖、标签纯净、无泄漏、采集能耗达标，
(12) 工具契约成立、输出独立复核、组合蕴含成立、版本/签名新鲜、不可验证依赖受信任预算约束、调用开销达标，
(13) 证书依赖 DAG 无环且所有叶子扎根于合法基事实。

**证明**：充分性由 `admits` 的合取结构与引理 1–3、5–7、9–11、13–15 直接给出：前七证保证物理-语义-协同闭环，DAC 把 conformal 覆盖从假设变为可证，TIC 把工具黑箱变为契约白箱，DAG 扎根封死自证循环。必要性：任一条件缺失即拒证，且分别对应「数据侧信道」「工具侧信道」「洗钱/循环依赖」中的一种未被缓解。∎

## 6. 本轮最大风险（最终确认）

**一句话**：**DAC 的交换性/漂移检验在对抗性协变量漂移下可能漏检、TIC 的信任预算仍为「同版本投毒/签名泄露」留下黑箱缝隙、而证书依赖 DAG 的扎根判定依赖「基事实」与「蕴含检查」的可判定性——当这三者同时被精心构造的数据侧信道与工具侧信道联合攻击时，DTC-USC 可能把被污染的数据与被洗白的工具输出当作「已扎根证书」放行，使九证一体在数据/工具这个最底层的地基上出现「合法但错误」的准入。**
