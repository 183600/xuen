# 第 44 轮（新循环第 4 轮） · Haptic-Persona × Contact-Cert：把「用户画像」落到物理接触，把「力觉传感」升为最高关键级证书模态（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 已把用户提升为一等公民，但人格 Π_u 仍是**语义/符号层**的（说什么、偏好什么、风险容忍多少），物理接触被隐含吸收进「几何证书 + CBF contact」；力觉只是执行层的传感器，不是证书的输入。本轮灵感词「用户画像」「力觉传感」正好撬开这个缺口：在交接、康复、协同搬运、装配这类**接触丰富**任务里，决定安全与个性化的不是视觉几何，而是**接触力/阻抗**；而用户画像一旦进入力觉域，就同时变成**可测量的物理能力档案**和**可被重放/伪造的生物特征**。于是本轮做两件事：**(A) 把人格物理化**——引入力觉画像 Φ_u，给出每个用户可容忍的接触包络 E_u 与偏好阻抗 K_u，个性 = 在物理包络内收缩，扩张仍需持证；**(B) 把力觉证书化并放到最高关键级**——力传感器有迟滞、蠕变、漂移、饱和与接触状态歧义（粘/滑/离/撞），朴素「力上限」不 sound；必须建立带误差界与状态歧义的**接触证书**，并用**多速率租约 + 力觉中断抢占**，让 1kHz 接触环不被 1Hz VLM 饿死。二者耦合处是本轮真正的新问题：**力觉人格可被 spoof，且跨模态冲突时若做平均会静默失 sound**。

## 0. 直觉与动机

**灵感 1（用户画像 → 「画像不是问卷，是身体」）**：第 43 轮的人格来自用户自陈与对话偏好，本质是「用户说自己是谁、想要什么」。但在接触丰富任务里，用户真正施加给机器人的是**力**：老人能承受的剪切力、儿童康复时的抓握刚度、工人协同搬运时的引导节奏。这些都写在身体上，而不在问卷里。因此把画像从语义向量升级为**力觉画像 Φ_u**：它既是物理能力档案（可容忍力包络 E_u、震颤谱、顺应特性），也是交互偏好（阻抗 K_u、接触风格 s_u），还是身份指纹（ρ_u）。一句话：**画像要能被测出来，才配用来放行力。**

**灵感 2（力觉传感 → 「最快、也最脏的证人」）**：力觉是反应最快的模态——滑移、冲击、脱手都在毫秒级显现，比视觉与语义早一个数量级；但它也是最脏的模态——迟滞、蠕变、漂移、饱和让「测得力」不等于「真实力」，而粘/滑/离/撞的接触状态在观测上天然歧义。于是力觉不能只当执行反馈，必须当**证书的证人**：每条力结论都携带 (误差界 δ_h、δ_n、接触状态歧义集 Q̂、测量时刻)。**保守性来源也不同**：几何靠位置 Lipschitz，力觉靠迟滞闭包 + 滑移检测延迟；二者绝不能压成一个标量 margin。

**灵感 3（耦合 → 「物理 liveness：画像必须被身体现场证明」）**：力觉画像越有用，越像生物特征，也越容易被重放与对抗注入。攻击者无需冒充脸，只要复现一段力轨迹就能让系统套上「高耐受力用户」的包络。因此身份不能只靠离线画像匹配，必须加**物理 liveness 挑战**（机器人施加不可预测微力探针，测顺应响应）。身份不确定时不许猜：取**候选交集包络** E_∩，空则协商。这同时封住「重放改变包络」和「张冠李戴套错力包络」两条静默失效路径。

**耦合升级**：HPE（力觉画像引擎）把用户编译成力包络与阻抗契约；COCR（接触证书运行时）用迟滞闭包签发接触证书、用多速率租约禁止慢模态陈旧门控、用力觉中断抢占快环、用保守 meet 拒绝跨模态冲突；HMV（多速率力觉验证器）在硬件在环注入重放/尖峰/漂移并做速率与冲突 fuzz。四层架构由 v8 的「人格契约 + 并发证书」升级为 v9 的「**物理力觉人格 + 接触证书 + 多速率运行时**」。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（力觉画像与物理包络）**：力觉画像 Φ_u = (ρ_u, E_u, K_u, s_u, γ_u)：
- ρ_u：接触描述子分布（力/力矩时序谱、抓握刚度、接触点转移模式、微震颤谱），由示教与在线交互估得；
- E_u ⊂ ℝ^6：用户可容忍的六维力/力矩与力变化率包络（法向、剪切、扭转、jerk 上限），是物理能力与风险偏好的合成；
- K_u：偏好阻抗 (k_u, b_u)（柔顺或刚性交互、引导灵敏度）；
- s_u：接触风格（接近速度、驻留、抓握时长）；
- γ_u ∈ [0,1]：身份置信度（识别证据支持度）。
**命题（画像只做上限）**：由 Φ_u 导出的任何控制器参数，只能把全局接触包络 E_global 收缩为 E_u ∩ E_global，不得扩张；物理包络的扩张必须走定义 45 的认证闸门并消耗信任预算 τ_u。这与第 43 轮「收缩免费、扩张持证」同构，只是对象从动作集合换成了力/阻抗集合。

**定义 45（迟滞感知的接触证书）**：传感器模型 f_m = h(f_true, history) + η，其中迟滞/蠕变算子满足 |h(f,hist) − f| ≤ δ_h(hist)，噪声 |η| ≤ δ_n；接触状态真值 q ∈ Q = {free, make, stick, slip, break}，观测只给出歧义集 Q̂(f_m, hist) ⊇ 真值。定义**保守闭包** cl(E) = E ⊖ (δ_h + δ_n + drift·Δt)（沿力方向 Minkowski 腐蚀），并要求守卫只在 cl(E) 与最坏一致状态 q ∈ Q̂ 上取鲁棒约束：
C_contact = { (q, f) : q ∈ Q̂, f ∈ cl(E) ∩ E_global ∩ E_u }。
**soundness 命题**：若 δ_h、δ_n、drift 均为上界，且滑移检测延迟 ≤ T_s ≈ 单环周期，则在任意带噪测量上守卫都不会误判「安全」。**推论**：力觉证书与几何证书的保守性来源不同，不能合并为同一 margin；也解释了为何力环必须有独立最高关键级。

**定义 46（多速率证书租约与新鲜度域）**：模态 m ∈ {force, geometry, semantic, dialogue}，周期 T_m，租约 ℓ_m=(bound_m, τ_m, λ_m, κ_m)；力模态衰减率 λ_F 由最大**力变化率**（jerk 界）而非速度界出，因接触可在 T_slip ~ ms 内改变，λ_F ≫ λ_geometry，故力租约天然最短、力环必须最快。**跨速率一致性判据**：慢模态结果 g_m 可在快环第 t 拍门控快动作，仅当 bound_m − λ_m(t−τ_m) ≥ θ 且 t−τ_m ≤ max_age_m 仍成立；否则快环只能用自身力觉证书 + 安全回退（抬升阻抗/安全脱离接触）。**命题**：禁止慢模态对快环的「陈旧门控」，否则 VLM 的一次 1Hz 结论可让 1kHz 接触环在两次结论之间失守。

**定义 47（跨模态证书保守融合）**：证书权威偏序——force 对接触状态有否决权，geometry 对自由空间有否决权，persona 只能向下收缩力包络。融合不是加权平均，而是**保守 meet**：C_total = ⊓_m C_m，可行域为 ∩_m admiss_m；若存在模态对 (i,j) 使 admiss_i ∩ admiss_j = ∅（**冲突**：geometry 判无碰撞却 force 判已接触/滑移），输出 Conflict 并触发重测 + 单调降级，绝不放行。**定理（保守融合 sound）**：若每个 C_m 在各自误差模型下 sound，且 ⊓ 只做交集与冲突拒绝，则 C_total sound；**冲突率因此成为模型误差的可观测指标**，接入第 43 轮 ICV 的线性一致性审计。

**定义 48（力觉人格认证与物理 liveness）**：身份假设 u 与 u′ 的检验叠加**物理 liveness 挑战**——机器人施加不可预测的微力探针序列，测量用户顺应响应 K_u 与震颤谱，检验其与 ρ_u 一致且不能被静态重放解释；认证输出 (û, γ_u)。**回退命题**：当 γ_u < γ_min 或候选集 U_c 非单点时不得猜测，须用**候选交集包络** E_∩ = ∩_{u∈U_c}(E_u ∩ E_global) 并降级到最保守阻抗；若 E_∩ 为空则走第 43 轮的最小让步协商。**注**：这同时封住「重放/对抗力注入改变包络」与「张冠李戴套错力包络」两条静默失效路径。

**定义 49（contact-safety 最高关键级与力觉中断抢占）**：关键级扩展为 contact-safety > safety > geometry > semantic > dialogue；接触安全环拥有硬预算 B_contact 与**力觉中断**（力尖峰/滑移事件直接抢占，不依赖 CPU 过载检测）。**调度契约**：接触环 WCET ≤ T_F − J_max（J_max 为抖动界），且 λ_F 由 jerk 界出。**定理（每拍 sound）**：若预算与抖动界成立，则每个力环 tick 的守卫都满足定义 45 的 soundness，且慢模态无法借模式切换偷走其预算（切换只删不增，B_contact 硬隔离）。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 HAPTIC-PERSONA-ENGINE（力觉画像引擎 HPE）
1. **力觉画像学习**：从示教 + 在线交互估 ρ_u、E_u、K_u、s_u；E_u 用**分层共形/鲁棒包络**给出「真实可容忍力落在包络内」的概率保证（与第 43 轮共形意图对偶）。
2. **物理化契约编译**：人格契约的力维度 → 阻抗/导纳参数与力阈值表；只收缩 E_global，扩张需持证。
3. **认证 + 物理 liveness**：微力探针 + 顺应响应匹配 + 反重放，输出 (û, γ_u)。
4. **保守回退**：γ_u 低或候选非单点 → 候选交集包络 E_∩；空则协商，绝不猜。

### 2.2 IP-61 CONTACT-CERT-RUNTIME（接触证书运行时 COCR）
1. **迟滞/漂移感知力证书**：在线估 δ_h（迟滞回线半宽）、δ_n、漂移率；守卫只用保守闭包 cl(E)。
2. **接触状态歧义估计**：以区间/多假设表示 Q̂；滑移检测带延迟上界 T_s；粘/滑切换用状态机 + 保守驻留。
3. **多速率租约表**：按模态维护 T_m、λ_m、τ_m、max_age；跨速率门控检查，禁止陈旧门控。
4. **保守 meet + 冲突拒绝**：跨模态只交集不平均，冲突即重测降级；seqlock/epoch 快照复用第 43 轮。

### 2.3 IP-62 HAPTIC-MULTIRATE-VALIDATOR（力觉多速率验证器 HMV）
1. **力注入/重放/对抗**：硬件在环注入重放力轨迹、尖峰、饱和、迟滞漂移、对抗扰动。
2. **速率/抖动压力**：VLM 满载、调度抖动、慢模态陈旧门控注入，验接触环 starvation。
3. **跨模态冲突 fuzz**：制造 geometry/force 矛盾，验保守 meet 与冲突检测不漏。
4. **接触丰富场景**：交接、康复、协同搬运、装配，在 Isaac Sim 力渲染 + 真机台架双轨验证。

## 5. 本轮最大风险

**一句话**：力传感器误差模型（迟滞/蠕变/漂移）与力觉人格识别都建立在非平稳、可被重放/对抗注入的数据上，一旦 δ_h/δ_n 被低估或用户被误识别，几何、租约、共形覆盖会「看起来全部有效」却合力套用错误用户/过窄的力包络，形成跨模态都无法察觉的静默失 sound 接触证书——故 E96/E97/E100 必须设为红线，且默认回退到「候选交集包络 + 串行最保守力控」这条永不失 sound 的底线。

# 第 44 轮产物 · 创新点清单 v21：Haptic-Persona × Contact-Cert（HPE × COCR × HMV）× 物理化个性化接触闭环（四层架构 v9）

## 2. 关键算法（伪代码）

### IP-60 HPE：力觉画像、共形力包络、物理 liveness 与保守回退
```
def learn_haptic_persona(interaction_log, alpha):
    rho = fit_contact_signature(interaction_log)     # 力/力矩谱、震颤、抓握刚度
    F   = [contact_descriptor(z) for z in interaction_log]
    E_u = conformal_force_envelope(F, alpha)         # 覆盖 P(f_true in E_u) >= 1-alpha
    K_u = fit_impedance_preference(interaction_log)  # (k_u, b_u)
    s_u = fit_contact_style(interaction_log)         # 接近速度/驻留/抓握时长
    return HapticPersona(rho, E_u, K_u, s_u, gamma=0.0)

def compile_force_contract(Phi_u, C_global):
    E_u = meet_force(Phi_u.E_u, C_global.E_global)   # 只收缩，不扩张
    if E_u.empty:
        return negotiate_minimal_concession(C_global, Phi_u)  # 复用第43轮
    return ForceContract(E_u, K_u=Phi_u.K_u, E_global=C_global.E_global)

def physical_liveness_auth(probe_response, Phi_u):
    # 不可预测微力探针的顺应响应必须匹配 rho_u，且不能由静态重放解释
    ok = complies(probe_response, Phi_u.rho) and not replay_explainable(probe_response)
    return ok, update_gamma(Phi_u.gamma, ok)

def fallback_envelope(candidates):
    # 身份不确定：取候选交集包络，绝不猜单个用户
    E = intersect_all([c.E_u for c in candidates])
    return E if not E.empty else None                # None => 协商/安全停机
```

### IP-61 COCR：迟滞闭包、接触证书、多速率租约、保守 meet 与力中断
```
def estimate_sensor_bounds(f_m, hist):
    delta_h = hysteresis_width(f_m, hist)            # 迟滞回线半宽上界
    delta_n = noise_bound(f_m)                       # 噪声界
    drift   = drift_rate_estimate(hist)              # 漂移率
    return delta_h, delta_n, drift

def conservative_closure(E, dh, dn, drift, dt):
    # 沿力方向 Minkowski 腐蚀：只保留"即使误差最大也安全"的部分
    return erode(E, dh + dn + drift * dt)

def contact_certificate(f_m, hist, E_u, E_global, dt):
    dh, dn, dr = estimate_sensor_bounds(f_m, hist)
    E = conservative_closure(intersect(E_u, E_global), dh, dn, dr, dt)
    Q = consistent_contact_states(f_m, hist)         # {free,make,stick,slip,break} 的歧义集
    if Q.disjoint({free, make, stick}):
        return Conflict("slip_or_break")             # 滑移/脱手：拒绝并降级
    return ContactCert(E=E, Q=Q, sensors=(dh, dn, dr), t=monotonic_now())

def multirate_lease_ok(lease, theta, t):
    # 慢模态结果不得在快环上"陈旧门控"
    return ((lease.bound - lease.lam * (t - lease.tau)) >= theta
            and (t - lease.tau) <= lease.max_age)

def conservative_meet(certs):
    admiss = intersect_all([c.E for c in certs])
    if admiss.empty or any_conflicting(certs):
        return Conflict(trigger_remeasure_and_downgrade=True)  # 不平均、不放行
    return admiss

def force_interrupt_schedule(force_loop, slow_tasks):
    # 力尖峰/滑移 = 物理中断，直接抢占，优先于 CPU 过载模式切换
    if force_event_pending():
        preempt_all_except(SAFETY_MONITOR, FORCE_LOOP)
    reserve_budget(FORCE_LOOP, B_contact)            # 硬预算，不随模式缩
    assert force_loop.wcet <= force_loop.T - J_max   # 抖动界 => 每拍 sound
    return edf_with_rta([force_loop] + slow_tasks)

def monitor_snapshot(cert_state):                    # 复用第43轮 seqlock
    e1 = cert_state.epoch; snap = cert_state.value; e2 = cert_state.epoch
    return snap if e1 == e2 else downgrade_snapshot(cert_state)
```

def car_transition_guard_v4(e, x, contact_cert, persona, geom_margin):

## 6. 本轮最大风险

**一句话**：力传感器误差模型（迟滞/蠕变/漂移）与力觉人格识别都建立在非平稳、可被重放/对抗注入的数据上，一旦 δ_h/δ_n 被低估或用户被误识别，几何、租约、共形覆盖会「看起来全部有效」却合力套用错误用户/过窄的力包络，形成跨模态都无法察觉的静默失 sound 接触证书——故 E96/E97/E100 必须设为红线，且默认回退到「候选交集包络 + 串行最保守力控」这条永不失 sound 的底线。
