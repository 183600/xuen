# 第 65 轮（承接第 64 轮「GRIP 接触接地四层闭环」IP-204~213；灵感循环 III 第 1 轮；本轮灵感：「数据质量」×「步态规划」）

> 第 64 轮把几何先验交给接触去证伪，把安全从"不撞"扩到"不滑、不压伤"。但它自述的最大风险暴露了一个更深的循环：**CGG 用接触残差判断几何真假，而接触模型本身是从标定数据里学来的；如果标定数据的覆盖、时序对齐、污染程度、平稳性未知，那么"接地真值"只是"用一批未经认证的数据训练出来的真值"**。与此同时，接触并不是随时都有的——对足式机器人，**接触是被步态显式调度出来的**：摆动相没有接触，触地瞬间有冲击，只有稳定支撑相才有可信的接触残差。两个灵感恰好咬在同一处：
>
> **数据质量决定"接触模型值不值得信"；步态规划决定"什么时候有接触、接触在哪里、这次接触能测到什么"。把数据质量纳入证书、把步态当成可认证的接触调度与主动探针，鲁棒性栈才第一次拥有"数据-步态-平衡"这三层此前完全缺席的维度。**

## 0. 直觉与动机

**灵感 1（数据质量 → 证书的数据前提：DQB / DPC）**
直觉：前 64 轮的证书都在证明"给定模型，系统在最坏情况下安全"，却从没有一条证书说明"模型凭什么可信"。数据质量不是一个预处理勾选项，而是一条**守恒律**：任何标定/训练数据集的缺陷，最终都会以模型误差的形式，在某个安全裕度里被花掉；若不显式扣除，证书不过是**把数据缺陷藏进了假设**。于是引入**数据质量预算 DQB**与**数据谱系证书 DPC**：每个数据分片携带质量向量 q=(覆盖、标签噪声、时序对齐、平稳性、sim2real 差距、污染、去重/泄漏)，聚合成数据集质量剖面 Q；证书的每个裕度都要扣一项"数据税" `L_q·d(Q,Q*) + c/√n_eff(Q) + L_p·ε_poison + ν·δ_drift`。数据变差，证书自动缩水，而不是静默失效。

**灵感 2（数据质量 → 有效样本量：DQ2E）**
直觉：坏数据的危害不是"多了一个坏点"，而是"好数据的有效数量变少了"。用 Kish 有效样本量 `n_eff=(Σw)²/Σw²`、稳健估计的击穿点、序贯漂移检验，把质量剖面映射为模型误差上界 `B_model`（算法稳定性 + 泛化项 + 标签噪声偏差 + 污染项）。这是本轮唯一"重"的数学：**质量→不确定性的算子必须有可测常数，且必须被实验校准**，否则它就是新的空头支票。DQ2E 不是又一条不等式，而是一份"可被实验证伪的接口契约"。

**灵感 3（步态规划 → 接触调度是证书输入：GCS / PG-CGG）**
直觉：足式机器人的接触是**离散、间歇、带冲击**的。第 64 轮的 CGG 默认"接触集 C 随时可用"，放到足式上会立刻出错：摆动相没有接触却按有接触算残差 → 误判几何幻觉；触地冲击是已知瞬态却被当成模型错误 → 主动降级正确几何。因此步态首先是一个**接触调度 S(t)**，它必须成为 CGG 的门控信号：只在"稳定支撑窗"内做 χ² 检验，触地/离地瞬态用已知瞬态模型扣除或屏蔽。**步态不是几何的被动执行，而是接触残差可解释性的前提。** 门控也不是免费的：它缩短了有效检验窗口，检测延迟上升，这是一条显式的"误报率—检出延迟"权衡。

**灵感 4（步态规划 → 落脚点即探针 + 平衡证书：FAP / BC / TPE）**
直觉：每落一脚都是一次对地形的物理实验——测高度、测摩擦、测承载刚度。第 64 轮的 APP 在机械臂上主动按压探测；在足式上，**落脚点选择就是探针选择**。FAP 在"地形信息增益最大"与"平衡/滑移/力限最安全"之间做 D-最优：候选落脚点必须使捕获点留在支撑多边形内（对球内所有 φ）、接触力与滑移裕度达标，才允许作为探针。TPE 由足-地接触力与位移直接辨识地形参数 (h, μ, k)；新增**平衡证书 BC**：`ρ_bal = 捕获点到支撑边界的有符号距离 − 状态估计不确定度 − 地形高度不确定度 − 执行误差`。安全从"不滑、不压伤"再扩展到"不摔"。

**灵感 5（三灵感合流 → STRIDE 与"数据-步态自激"风险）**
直觉：四者合流为 **STRIDE（Safe Terrain-aware Robust Intermittent-contact Data-quality Engine）**。闭环：数据质量剖面 Q → DQ2E 得模型误差 → DQB 扣减裕度 → GCS 给接触调度 → PG-CGG 门控检验 → FAP 用落脚点探测地形 → TPE 更新地形 → BC/DQG 按证书裕度调节步态（更保守）→ 执行 → 新接触产生新数据（带新质量标签）→ 回到 Q。**关键反身性**：步态越保守，越少接触新奇地形，数据覆盖越难提升，质量越难恢复——"安全降级"可能把系统锁死在永久保守。因此 DQG 必须保留一个**信息导向的最小探索预算**：在 ρ_safe ≥ 0 的前提下，按信息增益把一小部分步态预算分配给"有意义的未知"，否则数据质量与步态安全会互相拖死。

**与第 64 轮的接口**：GRIP 的 A83 假设"F/T 与触觉在标定范围内有界、接触模型在接触点邻域成立"。本轮不推翻它，而是把它拆成两条**可认证、可失效**的子假设：A88（数据质量剖面可测且 DQ2E 常数经 E231 校准）与 A89（步态接触调度被显著实现，瞬态有界且被门控）。GRIP 的 J_grip 仍是 STRIDE 的内层证书。

## 1. 形式化定义（增量：定义 217–232）

- **定义 217（STRIDE 闭环）**：STRIDE = (GRIP, DQB, DPC, DQ2E, GCS, PG-CGG, TPE, FAP, BC, DQG, GSL, RSC-D, WCV-D, OLP-D, CSP-D, AIC-D, J_stride)。定位：GRIP 的"数据-步态-平衡"三层升级；不变式：**数据质量计算、DQ2E 校准、地形辨识、步态重规划只发生在离线/低频语义流；实时流只做相位门控、残差、平衡裕度查表、首技能派发，零训练写操作。**
- **定义 218（数据质量向量与质量剖面）**：分片 d 的质量向量 q(d) = (q_cov, q_lab, q_sync, q_stat, q_s2r, q_pois, q_leak) ∈ [0,1]⁷（1 为最好）。数据集 D 的质量剖面 Q(D) = (Q_cov, …, Q_leak, n, T_span, shard_hash)，其中各维由覆盖率、标签一致率、时间同步残差、漂移检验 p 值、sim2real 差距估计、污染检测器得分、训练/评测泄漏审计聚合得到。理想剖面 Q* = 全 1。距离 `d_Q(Q,Q*) = ‖(1−Q)⊙w_Q‖∞`，w_Q 为标定出的敏感度权重。
- **定义 219（有效样本量）**：对样本权重 w_i = Π_k q_k(d_i)^{α_k}（α_k 为敏感度指数），`n_eff(D) = (Σ_i w_i)² / Σ_i w_i²`（Kish）。n_eff 对任意质量维度单调不增：某维质量下降 ⇒ 权重重分配 ⇒ n_eff 下降。n_eff 是"这批数据相当于多少条理想数据"的可计算代理。
- **定义 220（数据质量→模型误差算子 DQ2E）**：给定学习/估计器 A 与有界损失 ℓ（界 M）、均匀稳定性 β_n，质量剖面 Q：
  `B_model(Q) = R̂_w(A(D),Q) + 2β_{n_eff} + (4n_eff·β_{n_eff}+M)·√(log(1/δ)/(2n_eff)) + b_lab(η) + b_pois(ε_p)`，
  其中 R̂_w 为质量加权经验风险，b_lab(η) ≤ ηM/(1−2η)（η<1/2，对称标签噪声下的截断损失偏差），b_pois(ε_p) 为污染半径 ε_p 引起的偏差上界。DQ2E 的常数 {β_n, b_lab 斜率, L_q} 由 E231 在已知真值的标定台上**实测并用保守包络拟合**；未校准时 DQ2E 返回 ⊥（不可认证），而非猜测。
- **定义 221（污染半径与稳健估计）**：对估计器 A 定义击穿点 ε_bd(A)（总体中可任意污染而不使估计发散的样本比例）。污染半径 `ε_p(D) = max{ε : 污染比例 ≤ ε 时 ‖A(D)−A(D_clean)‖ ≤ δ_p}`。仅当 ε_p ≤ ε_bd(A) 时数据可用于证书；否则 DPC 置 `untrusted`。采用坐标中位数/截断 M-估计/随机子采样一致性作为默认稳健后端，并输出 breakdown_witness。
- **定义 222（数据谱系证书 DPC）**：DPC = (dataset_hash, Q, n_eff, ε_p, ε_bd, drift_test, leakage_audit, calib_suite_hash, dq_ver)。`Certified(DPC) ⇔ d_Q(Q,Q*) ≤ τ_Q ∧ n_eff ≥ n_min ∧ ε_p ≤ ε_bd ∧ drift_test.p > α_drift ∧ leakage_audit.pass ∧ calib_suite_hash 与 DQ2E 版本匹配`。DPC 是数据进入训练/标定流水线的"门禁凭证"，任何分片变更都会改变 dataset_hash 并使旧证书失效。
- **定义 223（数据质量预算 DQB）**：设内层证书 J_grip 的裕度为 ρ_i^grip（i ∈ {rob, dir, slip, force}）。数据税与预算：
  `ρ_i^data = ρ_i^grip − L_{q,i}·d_Q(Q,Q*) − c_δ·√(log(1/δ)/(2n_eff)) − L_{p,i}·ε_p − ν_i·δ_drift`。
  记 `ρ_data = min_i ρ_i^data`。若 DPC 未认证，则 ρ_data = −∞。DQB 是"数据质量如何花掉安全裕度"的唯一账本。
- **定义 224（步态-接触调度 GCS）**：步态 g = (β_duty, T_gait, L_step, H_step, φ_phase, terrain_class)，接触调度 S(t) ∈ {0,1}^{n_L}：腿 l 在 t 处于支撑相当且仅当相位落在支撑窗。对每次触地 t_td、离地 t_lo 定义瞬态窗 `[t_td, t_td+τ_td] ∪ [t_lo−τ_lo, t_lo]`。GCS 输出 `(S(t), settled(t), transient(t))`，并保证每个支撑相内的稳定窗长度 ≥ n_w·Δt_check（足以做 CGG 窗口检验）。GCS 同时是证书的输入：J_stride 记录 gait_schedule_hash。
- **定义 225（相位门控接触残差 PG-CGG）**：CGG 残差只在 `settled(t)=1` 时计入 χ² 窗口；瞬态窗内用已知冲击模型 `Ŵ_t = Σ_j G(c_j)f_j + Ŵ_impact(t−t_td; v_td, m_eff)` 扣除，或直接屏蔽。相位门控后的检验统计量 T̄ 只在稳定支撑样本上定义；门控率 `γ_gate = |settled 样本| / |支撑相样本|` 与有效窗口 n_eff^cgg = γ_gate·n_w 一同写入证书。**摆动相不产生 CGG 接受/拒绝事件**，避免把"没有接触"误读为"几何错误"。
- **定义 226（地形物理估计 TPE）**：地形参数 θ = (h, μ, k_bear)（高度、摩擦、承载刚度）。由足-地接触的力-位移/滑移观测：
  `f_n = k_bear·(h_foot − h) + c·ḣ_foot`（法向），滑移起始 `|f_t| = μ|f_n|`（切向）。Fisher 信息 `J_terrain = Σ_t (∂Ŵ_t/∂θ)ᵀΣ_w⁻¹(∂Ŵ_t/∂θ)`，`Σ_terrain = J_terrain⁻¹`。输出 θ̂、Σ_terrain 与地形可信掩码 `terrain_trusted`。
- **定义 227（落脚点即探针 FAP）**：候选落脚点集 X_f（由地形图、运动学可达域、支撑多边形扩张给出）。选择
  `x_f* = argmax_{x_f∈X_f} log det(J_terrain + FIM_f(x_f))`，
  s.t. `∀φ∈B(φ̂,r): ρ_bal(x_f,φ) ≥ 0`，`f_contact(x_f) ≤ f_safe`，`ρ_slip(x_f) ≥ 0`，`P[支撑多边形可实现] ≥ 1−α_est`。若所有候选不满足安全约束，返回 `probe_infeasible`，退回最保守落脚点（最大支撑裕度）而非冒险探针。
- **定义 228（平衡证书 BC）**：以发散运动分量（DCM）`ξ = x_com + ẋ_com/ω`、`ω=√(g/z_com)`，支撑多边形 P 为支撑足凸包。鲁棒平衡裕度
  `ρ_bal(t) = d(ξ_t, ∂P_t) − L_ξ·δ_state(Q) − L_h·√(tr Σ_terrain) − L_act·δ_act`，
  `ρ_bal = min_t ρ_bal(t)`。其中 δ_state(Q) 由状态估计器的数据质量经 DQ2E 给出。`ρ_bal ≥ 0` 是"不摔"的证书级条件；FAP/DQG 都必须对整个 B(φ̂,r) 采样验证它。
- **定义 229（证书引导步态调节 DQG）**：给定联合裕度 `ρ_safe = min(ρ_data, ρ_rob, ρ_dir, ρ_slip, ρ_force, ρ_bal)` 与信息预算 δ_info，DQG 输出保守化步态：
  `β_duty = σ_β(ρ_safe),  v = v_max·σ_v(ρ_safe),  L_step = L_max·σ_L(ρ_safe)`，
  其中 σ 为单调饱和映射（ρ_safe 越小 → 占空比越高、速度越低、步长越短）；且满足
  `∀φ∈B: ρ_bal(g(ρ_safe),φ) ≥ 0 ∧ ρ_slip ≥ 0 ∧ ρ_force ≥ 0`。
  **最小探索**：在安全集内以比例 δ_info 选择信息增益最大的落脚/地形子集，防止覆盖塌缩；当 ρ_safe < 0 时 δ_info=0 并退回准静态爬行或 safe_stand。
- **定义 230（步态技能库 GSL）**：GSL = {σ_i} 是 TSL 的步态扩展：σ = (name, terrain_pre, phase_pre, data_pre, eff, π_σ, gait_spec, cost)。terrain_pre 含地形类别/高度范围/摩擦下界；phase_pre 含允许的相位与占空比；data_pre 含 `Certified(DPC) ∧ n_eff ≥ n_min`；eff 含 `ρ_bal ≥ 0 ∧ contact_realized ∧ ρ_slip ≥ 0`；π_σ 输出步态参数与落脚序列关键帧。步态切换仅在双支撑窗且目标技能 eff 可验证时允许，否则插入 stand/transition 技能。
- **定义 231（RSC-D / WCV-D / OLP-D / CSP-D 原位升级）**：RSC 球半径由数据质量与相位门控共同校准：`r_{t+1} = clip((1−β)r_t + β·e_t, r_min, r_max)` 且 `r ← max(r, B_model(Q)/σ_J)`；WCV 搜索域增 `𝒯(Σ_terrain)`（地形不确定集）与 `ℬ_data`（数据误差球）；OLP 输入增地形/相位/数据质量特征 `x'''=[x''; e_gait; e_terrain; Q]`；CSP 可行性增 `ρ_bal ≥ 0` 与 `Certified(DPC)` 前置。
- **定义 232（AIC-D 与 J_stride）**：干扰集 `ℰ_D = ℰ_F × {标签噪声 η ≤ η_max} × {投毒 ε_p} × {时序偏移 |Δt| ≤ Δt_max} × {漂移} × {泄漏}`；ρ_dir、ρ_bal 在 ℰ_D 上重算。证书
  `J_stride = (J_grip, dq_hash, n_eff, ρ_data, ε_p, ε_bd, gait_schedule_hash, ρ_bal, terrain_cov, γ_gate, drift_witness, dq_ver)`。
  `Valid(J_stride) ⇔ Valid(J_grip) ∧ Certified(DPC) ∧ ρ_data ≥ 0 ∧ ρ_bal ≥ 0 ∧ gait_schedule_hash 与实际执行一致 ∧ γ_gate ≥ γ_min ∧ drift_witness 未越界`。GRIP 四层 + 数据 + 步态 + 平衡 = **七层证书链**。

## 2. 关键算法骨架

```python
# DQB / DQ2E：数据质量 → 模型误差 → 证书裕度（离线/低频）
Q = dq.profile(shards)                       # 定义 218
if not dq.certified(Q):                       # DPC 门禁
    J_stride = Bottom                          # 不可认证
B_model = dq2e.bound(Q, model_class, delta=1e-3)   # 定义 220，常数由 E231 校准
rho_data = dqb.charge(J_grip.margins, Q, B_model, eps_p, delta_drift)
r = max(r, B_model / sigma_J)                 # 数据误差进 WCV 球

# PG-CGG：只在稳定支撑窗检验（实时只做门控与残差）
if phase.settled(t):
    T_t = cgg.residual(W_meas, q, phi_hat, stance_contacts, Sigma_w)
    window.append(T_t)
elif phase.transient(t):
    T_t = cgg.residual(W_meas, q, phi_hat, stance_contacts + impact_model(t), Sigma_w)

# FAP：落脚点即探针（语义流）
x_f = argmax_{x in candidates} logdet(J_terrain + fim_terrain(x))
      s.t. all(balance_margin(x, phi) >= 0 for phi in worst_samples(B))
           and contact_force(x) <= f_safe and slip_margin(x) >= 0

# BC + DQG：平衡证书与保守化（实时查表 + 少量算术）
rho_bal = min_t (dcm_dist(x_com, xdot_com, stance_feet) - L_xi*delta_state(Q)
                 - L_h*sqrt(trace(Sigma_terrain)) - L_act*delta_act)
gait = dqg.map(rho_safe, delta_info)          # 占空比/速度/步长单调保守化
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 7（数据质量单调性）**：n_eff、B_model、ρ_data 均对质量退化单调；因此"数据变差 ⇒ 证书缩水"不是策略而是可证单调性（在 DQ2E 常数校准正确的前提下）。
- **引理 8（相位门控的误报控制与代价）**：若瞬态窗覆盖触地/离地冲击时长 τ_td/τ_lo，则稳定窗内 H0 下 T_t ~ χ²₆，误降级率 ≤ α_geo；代价是有效窗口 n_eff^cgg = γ_gate·n_w 缩短，检出延迟 ∝ 1/(γ_gate·λ)。给出误报—延迟的显式权衡。
- **引理 9（落脚点的地形可观测性）**：足-地接触力对 θ=(h,μ,k) 的 Fisher 信息 ∝ f_n²/σ_w²；k 次落脚后 E‖θ̂−θ*‖² = O(dσ_w²/(k f_n²))，故"走得越多、踩得越实，地形越可测"。
- **定理 7（数据质量→证书传递界）**：若 DQ2E 常数经校准且 DPC 认证，则真实裕度 ≥ ρ_data 以概率 ≥ 1−α_data；即数据缺陷被显式扣税，而非藏进假设。
- **定理 8（步态-平衡联合安全）**：若对所有 φ∈B、所有 t 有 ρ_bal≥0、ρ_slip≥0、ρ_force≥0，且步态调度被显著实现（或偏差在 τ_replan 内被重规划吸收），则 P[摔倒] ≤ α_data+α_est+α_geo+α_slip+α_force。
- **定理 9（STRIDE 七层证书）**：Valid(J_stride) ⇒ GRIP 有效 ∧ 数据认证 ∧ 步态调度一致 ∧ 平衡/滑移/力限安全；证书链从"几何-技能-干扰-接触"扩为"几何-技能-干扰-接触-数据-步态-平衡"。
- **实时性**：相位门控 <0.01ms、BC <0.1ms、DQG 查表 <0.05ms；数据质量/DQ2E/TPE/FAP 全在低频语义流（20–200ms 级）。叠加 GRIP 的 ≤2ms，实时路径仍 ≤2.1ms，通过共享编码与 OLP-D 缓存控制到 ≤2ms 契约（A90）。

## 5. 本轮最大风险

## 2. 形式化定义（完整版）

**定义 217（STRIDE 闭环）** STRIDE 是 GRIP 的"数据-步态-平衡"升级：在"语义流 ∘ 实时流"骨架上挂载 DQB/DPC（数据门禁）、DQ2E（质量→误差）、GCS/PG-CGG（接触调度与相位门控）、TPE/FAP（地形辨识与落脚探针）、BC/DQG/GSL（平衡证书与步态调节），并原位升级 RSC→RSC-D、WCV→WCV-D、OLP→OLP-D、CSP→CSP-D、AIC-F→AIC-D、J_grip→J_stride。不变式：**数据质量计算、DQ2E 校准、地形辨识、步态重规划只发生在离线/低频线程；实时路径只做相位门控、CGG 残差、BC 裕度、DQG 查表、WCV-D 编译与首技能派发，零训练写操作。**

**定义 218（数据质量向量与质量剖面）** 分片 d 的质量向量 q(d) = (q_cov, q_lab, q_sync, q_stat, q_s2r, q_pois, q_leak) ∈ [0,1]⁷，各维定义：
- q_cov：任务/地形/接触条件覆盖相对目标分布的覆盖比（可用最近邻距离的分位数估计）；
- q_lab：标签一致率（多标注者/真值源一致性）；
- q_sync：传感器时间同步质量，`q_sync = exp(−|Δt|/τ_sync)`；
- q_stat：平稳性，由滑窗 MMD/KS 漂移检验的 p 值映射；
- q_s2r：sim2real 差距的补，`q_s2r = exp(−d_s2r)`；
- q_pois：污染检测器的"干净概率"（稳健马氏距离尾部比例）；
- q_leak：训练/评测泄漏审计通过度（1 为无泄漏）。
数据集 D 的质量剖面 Q(D) 为上述维度的加权聚合并附带 n、时间跨度、shard_hash。理想剖面 Q*=全 1；`d_Q(Q,Q*) = ‖(1−Q)⊙w_Q‖∞`，w_Q 由 DQ2E 校准（E231）给出敏感度权重。

**定义 219（有效样本量）** 样本权重 `w_i = Π_k q_k(d_i)^{α_k}`，`n_eff(D) = (Σ_i w_i)²/Σ_i w_i²`。性质：① n_eff ≤ n；② 任一 q_k 下降 ⇒ 权重向低质样本倾斜 ⇒ n_eff 不增（在 α_k>0 时严格减）；③ n_eff 是可微、可流式更新的，适合低频线程增量维护。n_eff 是"这批数据相当于多少条理想数据"的代理，也是泛化项的唯一入口。

**定义 220（数据质量→模型误差算子 DQ2E）** 给定学习/估计器 A、有界损失 ℓ（界 M）、均匀稳定性 β_n：
```
B_model(Q) = R̂_w(A(D), Q)
           + 2β_{n_eff}
           + (4 n_eff β_{n_eff} + M)·sqrt(log(1/δ)/(2 n_eff))
           + b_lab(η) + b_pois(ε_p)
```
其中 R̂_w 为质量加权经验风险；b_lab(η) ≤ ηM/(1−2η)（η<1/2，对称标签噪声 + 截断损失）；b_pois(ε_p) 为污染半径引起的偏差上界。**校准契约**：常数 {β_n, L_q, b_lab 斜率, b_pois 系数} 必须在已知真值的标定台上实测，并取保守包络（E231）；未校准时 DQ2E 返回 ⊥（不可认证）。DQ2E 的输出同时用于：① 扣减裕度（定义 223）；② 膨胀 WCV 球（定义 231）；③ 作为 BC 中 δ_state 的输入（定义 228）。

**定义 221（污染半径与稳健估计）** 对估计器 A 定义击穿点 ε_bd(A)。污染半径 `ε_p(D) = max{ε : 污染比例 ≤ ε 时 ‖A(D)−A(D_clean)‖ ≤ δ_p}`，由稳健马氏距离尾部与随机子采样一致性估计。仅当 `ε_p ≤ ε_bd(A)` 时数据可用于证书，否则 DPC 置 `untrusted`。默认后端：坐标中位数 / 截断 M-估计 / 随机子采样一致性（RANSAC-style），并输出 breakdown_witness（使估计偏移 δ_p 的最小污染集规模）。

**定义 222（数据谱系证书 DPC）** DPC = (dataset_hash, Q, n_eff, ε_p, ε_bd, drift_test, leakage_audit, calib_suite_hash, dq_ver)。认证规则：
```
Certified(DPC) ⇔ d_Q(Q,Q*) ≤ τ_Q
              ∧ n_eff ≥ n_min
              ∧ ε_p ≤ ε_bd
              ∧ drift_test.p > α_drift
              ∧ leakage_audit.pass
              ∧ calib_suite_hash = DQ2E.version.suite_hash
```
任何分片变更改变 dataset_hash，使旧 DPC 与依赖它的 J_stride 同时失效（证书过期机制）。DPC 是数据进入训练/标定流水线的门禁凭证，也是审计链的第一环。

**定义 223（数据质量预算 DQB）** 设内层证书 J_grip 的裕度为 ρ_i^grip，i ∈ {rob, dir, slip, force}。数据税与预算：
```
ρ_i^data = ρ_i^grip − L_{q,i}·d_Q(Q,Q*) − c_δ·sqrt(log(1/δ)/(2 n_eff))
                  − L_{p,i}·ε_p − ν_i·δ_drift
ρ_data = min_i ρ_i^data
```
若 DPC 未认证，则 ρ_data = −∞。DQB 是"数据质量如何花掉安全裕度"的唯一账本；它把第 64 轮隐藏的 A83 显式化：接触模型的误差不再被假设为零，而是被 n_eff、ε_p、d_Q 计价。

**定义 224（步态-接触调度 GCS）** 步态 g = (β_duty, T_gait, L_step, H_step, φ_phase, terrain_class)。接触调度 S(t) ∈ {0,1}^{n_L}：腿 l 在 t 处于支撑相当且仅当相位落在支撑窗。对每次触地 t_td、离地 t_lo 定义瞬态窗 `[t_td, t_td+τ_td] ∪ [t_lo−τ_lo, t_lo]`。GCS 输出 `(S(t), settled(t), transient(t))`，并保证每个支撑相稳定窗长度 ≥ n_w·Δt_check（足以做 CGG 窗口检验）。GCS 是证书输入：gait_schedule_hash 写入 J_stride；实际接触与调度不一致（contact_schedule_mismatch）直接触发重规划。

**定义 225（相位门控接触残差 PG-CGG）** 在稳定支撑窗内：
```
e_t = W_t − Σ_j G(c_j)f_j,   T_t = e_tᵀΣ_w⁻¹e_t ~ χ²₆（H0）
```
瞬态窗内使用冲击模型：
```
Ŵ_t = Σ_j G(c_j)f_j + Ŵ_impact(t−t_td; v_td, m_eff)
```
或直接屏蔽该样本。摆动相**不产生 CGG 接受/拒绝事件**。门控后的窗口均值只在 settled 样本上定义；门控保留率 γ_gate 与有效窗口 n_eff^cgg = γ_gate·n_w 写入证书。门控必须保证：① 瞬态窗覆盖冲击时长；② 稳定窗样本数 ≥ n_min^cgg，否则置 `cgg_inconclusive`（既不接受也不拒绝，只保守膨胀），避免"门控过狠 → 永远无法收缩"。

**定义 226（地形物理估计 TPE）** 地形参数 θ = (h, μ, k_bear)。足-地接触模型：
```
f_n = k_bear·(h_foot − h) + c·ḣ_foot
滑移起始: |f_t| = μ|f_n|,  粘着: |f_t| < μ|f_n|
```
Fisher 信息 `J_terrain = Σ_t (∂Ŵ_t/∂θ)ᵀΣ_w⁻¹(∂Ŵ_t/∂θ)`，`Σ_terrain = J_terrain⁻¹`。输出 θ̂、Σ_terrain、`terrain_trusted`（当 det(J_terrain) > τ_terrain 且残差通过 χ² 时置真）。TPE 与 GRIP 的 FPE 共享力模型，但观测对象从"物体 φ"变为"地形 θ"，且观测发生在落脚瞬间。

**定义 227（落脚点即探针 FAP）** 候选落脚点集 X_f 由地形图、运动学可达域、支撑多边形扩张给出。选择
```
x_f* = argmax_{x_f∈X_f} log det(J_terrain + FIM_f(x_f))
s.t. ∀φ∈B(φ̂,r): ρ_bal(x_f, φ) ≥ 0
     f_contact(x_f) ≤ f_safe
     ρ_slip(x_f) ≥ 0
     P[支撑多边形可实现] ≥ 1−α_est
```
其中 FIM_f 由候选落脚点的预测力-位移轨迹解析或采样估计。若所有候选不满足安全约束，返回 `probe_infeasible`，退回**最大支撑裕度落脚点**（不冒险探针）。FAP 把第 64 轮 APP 的"主动按压探测"搬到足端：每一步既是运动也是实验，但实验必须服从平衡。

**定义 228（平衡证书 BC）** DCM `ξ = x_com + ẋ_com/ω`，`ω=√(g/z_com)`；支撑多边形 P_t 为支撑足凸包。鲁棒平衡裕度
```
ρ_bal(t) = d(ξ_t, ∂P_t) − L_ξ·δ_state(Q) − L_h·sqrt(tr Σ_terrain) − L_act·δ_act
ρ_bal = min_t ρ_bal(t)
```
δ_state(Q) 由状态估计器的数据质量经 DQ2E 给出（IMU/编码器/接触数据的质量直接进入平衡裕度）。ρ_bal ≥ 0 是"不摔"的证书级条件；FAP 与 DQG 都必须对整个 B(φ̂,r) 的采样验证它。对动态步态（含腾空相），P_t 以"可达支撑集"替代，并增加质心动量项 `ρ_mom = min_t (M_max − ‖ḣ_com‖)`。

**定义 229（证书引导步态调节 DQG）** 联合裕度 `ρ_safe = min(ρ_data, ρ_rob, ρ_dir, ρ_slip, ρ_force, ρ_bal)`，信息预算 δ_info。DQG 输出保守化步态：
```
β_duty = β_min + (β_max−β_min)·σ_β(ρ_safe)      # 裕度小 → 占空比高（更多支撑）
v      = v_max·σ_v(ρ_safe)                      # 裕度小 → 速度低
L_step = L_max·σ_L(ρ_safe)                      # 裕度小 → 步长短
```
σ 为单调饱和映射。硬约束：`∀φ∈B: ρ_bal(g,φ)≥0 ∧ ρ_slip≥0 ∧ ρ_force≥0`。**最小探索**：在安全集内以比例 δ_info 选择信息增益最大的落脚/地形子集，防止覆盖塌缩；ρ_safe<0 时 δ_info=0，退回准静态爬行或 safe_stand。DQG 是"安全—信息"张力的显式调节器：保守化保住当下安全，最小探索保住未来的数据质量。

**定义 230（步态技能库 GSL）** GSL = {σ_i} 是 TSL 的步态扩展：
```
σ = (name, terrain_pre, phase_pre, data_pre, eff, π_σ, gait_spec, cost)
```
terrain_pre 含地形类别/高度范围/摩擦下界；phase_pre 含允许相位与占空比；data_pre 含 `Certified(DPC) ∧ n_eff≥n_min`；eff 含 `ρ_bal≥0 ∧ contact_realized ∧ ρ_slip≥0`；π_σ 输出步态参数与落脚序列关键帧。步态切换仅在双支撑窗且目标技能 eff 可验证时允许，否则插入 stand/transition 技能。技能库离线蒸馏，部署后仅 θ_σ 在线微调；data_pre 使"数据不足时禁用高风险步态"成为结构约束而非建议。

**定义 231（RSC-D / WCV-D / OLP-D / CSP-D 原位升级）**
- **RSC-D**：球半径同时由残差与数据误差校准：`r_{t+1}=clip((1−β)r_t+βe_t, r_min, r_max)`，并强制 `r ← max(r, B_model(Q)/σ_J)`；DPC 失效时 r ← r_max。
- **WCV-D**：搜索域 `B(φ̂,r) ∩ 𝒢(g) ∩ K(μ̂) ∩ ℱ(f_lim) ∩ 𝒯(Σ_terrain) ∩ ℬ_data`，其中 𝒯 为地形不确定集（由 Σ_terrain 给出），ℬ_data 为数据误差球（半径 B_model/σ_J）。CVaR 尾部采样同 WCV。
- **OLP-D**：输入 `x''' = [x''; e_gait; e_terrain; Q]`，e_gait 为相位/接触调度特征，e_terrain 为地形编码，Q 为质量剖面；梯度上界增 `L_gait`、`L_terrain`、`L_Q` 项。
- **CSP-D**：可行性额外要求 `ρ_bal≥0`、`Certified(DPC)`、`contact_schedule 可实现`；否则技能不入图，规划器插入 probe/stand 或回退 safe_idle。

**定义 232（AIC-D 与 J_stride）** 干扰集
```
ℰ_D = ℰ_F × {标签噪声 η≤η_max} × {投毒 ε_p} × {时序偏移 |Δt|≤Δt_max}
        × {分布漂移} × {训练/评测泄漏}
```
ρ_dir、ρ_bal 在 ℰ_D 上重算（n_cert 由 96 增至 128，其中 32 用于数据干扰）。证书
```
J_stride = (J_grip, dq_hash, n_eff, ρ_data, ε_p, ε_bd, gait_schedule_hash,
            ρ_bal, terrain_cov, γ_gate, drift_witness, dq_ver)
Valid(J_stride) ⇔ Valid(J_grip)
              ∧ Certified(DPC)
              ∧ ρ_data ≥ 0
              ∧ ρ_bal ≥ 0
              ∧ gait_schedule_hash = 实际执行
              ∧ γ_gate ≥ γ_min
              ∧ drift_witness 未越界
```
审计链：dq_hash 追溯数据来源与质量，gait_schedule_hash 追溯接触调度，terrain_cov 追溯地形置信，drift_witness 追溯数据是否已漂移。**GRIP 四层 + 数据 + 步态 + 平衡 = 七层证书链。**

### IP-214/215 DQB + DQ2E（数据门禁与误差界）

```python
class DataQualityBudget:
    """离线/低频：质量剖面 → 有效样本量 → 模型误差 → 数据税。"""
    def __init__(self, w_Q, alpha, tau_Q, n_min, delta=1e-3):
        self.w_Q, self.alpha, self.tau_Q = w_Q, alpha, tau_Q
        self.n_min, self.delta = n_min, delta

    def profile(self, shards):
        Q = {k: weighted_mean([s.q[k] for s in shards], [s.n for s in shards])
             for k in Q_KEYS}
        n_eff = (sum(s.n * s.w for s in shards) ** 2) / \
                sum((s.n * s.w) ** 2 for s in shards)
        eps_p, eps_bd = estimate_poison_radius(shards), breakdown_point(self.estimator)
        drift = sequential_drift_test(shards)
        leak = leakage_audit(shards)
        return QualityProfile(Q, n_eff, eps_p, eps_bd, drift, leak, hash_shards(shards))

    def certified(self, Q):
        return (self.dist(Q) <= self.tau_Q and Q.n_eff >= self.n_min
                and Q.eps_p <= Q.eps_bd and Q.drift.p > ALPHA_DRIFT
                and Q.leak.pass and Q.calib_suite_hash == DQ2E_VERSION)

    def dist(self, Q):
        return max(self.w_Q[k] * (1.0 - Q.Q[k]) for k in Q_KEYS)

    def dq2e(self, Q, model, delta=None):
        if not model.calibrated:
            return BOTTOM                         # 未校准：拒绝认证
        delta = self.delta if delta is None else delta
        n = max(Q.n_eff, 1.0)
        beta_n = model.stability(n)
        gen = (4 * n * beta_n + model.M) * sqrt(log(1 / delta) / (2 * n))
        return (model.weighted_empirical_risk(Q) + 2 * beta_n + gen
                + model.label_bias(Q.eta) + model.poison_bias(Q.eps_p))

    def charge(self, margins, Q, B_model, nu, delta_drift):
        tax = self.dist(Q) + C_DELTA * sqrt(log(1 / 1e-3) / (2 * max(Q.n_eff, 1)))
        out = {i: margins[i] - L_Q[i] * tax - L_P[i] * Q.eps_p - nu[i] * delta_drift
               for i in margins}
        return min(out.values()), out
```

```python
class GaitContactScheduler:

        stance = phase_in_stance(t, gait)                 # 定义 224
        settled = stance & ~within_transient(t, gait)

class PhaseGatedCGG:
    def step(self, t, W_meas, q, phi_hat, contacts, sched, Sigma_w, r, sigma_J):
        if sched.transient[t]:
            W_pred = predicted_wrench(contacts) + impact_model(t, self.v_td, self.m_eff)
            T = residual(W_meas, W_pred, Sigma_w)          # 只记录，不计入检验窗口
            return r, self.geo_degraded, ('transient', T)
        if not sched.settled[t]:
            return r, self.geo_degraded, ('swing', None)   # 摆动相：不判定
        T = residual(W_meas, predicted_wrench(contacts), Sigma_w)
        self.window.append(T)
        if len(self.window) < self.n_min_cgg:
            return r, self.geo_degraded, ('warming', None)
        T_bar = mean(self.window)
        if T_bar > self.threshold:                         # 拒绝几何先验
            self.geo_degraded = True
            r = min(R_MAX, self.kappa_infl * r)
            r = max(r, self.delta_hall / sigma_J)
            self.window.clear()
            return r, True, ('demote', T_bar)
        r = max(R_MIN, self.kappa_shrink * r)
        self.geo_degraded = False
        return r, False, ('promote', T_bar)
```

### IP-219/220 BC + DQG（平衡证书与保守化）

```python
class BalanceCertificate:
    def __init__(self, L_xi, L_h, L_act, delta_act, omega):
        self.L_xi, self.L_h, self.L_act = L_xi, L_h, L_act
        self.delta_act, self.omega = delta_act, omega

    def margin(self, x_com, xdot_com, stance_feet, delta_state, Sigma_terrain):
        xi = x_com + xdot_com / self.omega
        P = convex_hull(stance_feet)
        return (signed_distance(xi, P)
                - self.L_xi * delta_state
                - self.L_h * sqrt(trace(Sigma_terrain))
                - self.L_act * self.delta_act)

class GaitGovernor:
    def map(self, rho_safe, delta_info, phi_ball):
        beta = clip(BETA_MIN + (BETA_MAX - BETA_MIN) * sigmoid(rho_safe),
                    BETA_MIN, BETA_MAX)
        v = V_MAX * sigmoid(rho_safe)
        L = L_MAX * sigmoid(rho_safe)
        info_budget = delta_info if rho_safe >= 0 else 0.0
        g = Gait(beta, v, L, info_budget)
        assert all(balance_margin(g, phi) >= 0 for phi in worst_samples(phi_ball))
        return g
```

## 4. 推导

**引理 7（数据质量单调性）** 设 q_k(d) 为第 k 维质量，α_k>0，w_i=Π_k q_k^{α_k}。若某维质量整体乘性下降 c<1（q_k → c·q_k），则所有 w_i 同乘 c^{α_k}（若该维对全部分片同比例），n_eff 不变；若仅部分分片下降（更现实），则权重方差增大，由 `n_eff=(Σw)²/Σw² = n/(1+CV²(w))`，CV² 增大 ⇒ n_eff 下降。DQ2E 中泛化项 `(4nβ_n+M)√(log(1/δ)/(2n))` 对 n 单调减，b_lab、b_pois 对 η、ε_p 单调增，故 B_model 对质量退化单调不减。DQB 的 ρ_i^data 对 d_Q、ε_p、δ_drift 单调减。于是"数据变差 ⇒ 证书缩水"是可证单调性（前提：DQ2E 常数校准正确，见定理 7）。∎

**引理 8（相位门控的误报控制与代价）** 设触地冲击瞬态时长 τ_td、离地 τ_lo，瞬态窗完全覆盖，则稳定支撑窗内残差 e_t = η_t（H0 且几何/接触模型正确），T_t ~ χ²₆，故稳定窗误降级率 ≤ α_geo。门控保留率 γ_gate = 1 − (τ_td+τ_lo)/T_stance（每条腿）。有效窗口 n_eff^cgg = γ_gate·n_w，非中心 χ² 的检出时间 `T_detect = O(log(1/β)/(γ_gate·λ))`，即门控越严，检出越慢。若 γ_gate·n_w < n_min^cgg，CGG 置 inconclusive 并只保守膨胀，避免"永远无法收缩"。因此门控不是免费降噪，而是把"误报"换成"延迟/保守"的显式交易。∎

**引理 9（落脚点的地形可观测性）** 接触法向力对 θ=(h,μ,k) 的偏导：∂f_n/∂h = −k_bear，∂f_n/∂k_bear = (h_foot−h)，滑移时 ∂f_t/∂μ = f_n。故 Fisher 信息
`J_terrain = Σ_t (∂f/∂θ)ᵀΣ_w⁻¹(∂f/∂θ)`，其量级 ∝ f_n²/σ_w² + k_bear²/σ_w²。k 次独立落脚后，`E‖θ̂−θ*‖² = tr((J_0+k·J_foot)⁻¹) ≤ d/(λ_min(J_0)+k·λ_min(J_foot)) = O(dσ_w²/(k f_n²))`。故"踩得越多、越实，地形越可测"；但 FAP 的平衡/滑移/力限约束可能排除信息最优落脚点，形成"信息—安全"前沿（与第 64 轮 APP 的"信息—易损"张力同构）。∎

**定理 7（数据质量→证书传递界）** 假设：(A88) DQ2E 常数经 E231 校准，且对任意认证剖面 Q，`|B_model(Q) − B_true(Q)| ≤ δ_calib`；(A88') 标签噪声 η<1/2、污染 ε_p ≤ ε_bd。则对任意 i，
`ρ_i^true ≥ ρ_i^data − δ_calib = ρ_i^grip − L_{q,i}d_Q − c_δ√(log(1/δ)/2n_eff) − L_{p,i}ε_p − ν_iδ_drift − δ_calib`
以概率 ≥ 1−α_data 成立（α_data 由泛化项与漂移检验的置信度合成）。因此若 ρ_data ≥ δ_calib，则所有真实裕度非负——数据缺陷被显式扣税，而非藏进假设。若 DPC 未认证或 DQ2E 未校准，则不给界（返回 ⊥），系统退化为第 64 轮 GRIP 的保守配置。∎

**定理 8（步态-平衡联合安全）** 假设 (A89)：步态接触调度 S(t) 被显著实现（触地/离地时刻偏差 ≤ τ_sched），偏差在 τ_replan 内被重规划吸收；BC 的 δ_state、Σ_terrain、δ_act 覆盖真实误差；ρ_slip、ρ_force 在 B(φ̂,r) 上成立。若对所有 t、所有 φ∈B 有 ρ_bal≥0、ρ_slip≥0、ρ_force≥0，则 DCM 始终在支撑多边形内、无宏观滑移、无力超限。由联合界，
`P[摔倒 ∨ 滑移 ∨ 力超限] ≤ α_data + α_est + α_geo + α_slip + α_force`。
若 contact_schedule_mismatch 发生，则证书立即失效并触发 DQG 保守化/stand，因此 mismatch 本身不构成未认证风险。∎

**定理 9（STRIDE 七层证书）** 假设第 64 轮 A83–A87、本轮 A88/A89/A90（实时路径新增组件 ≤0.1ms）。则
1. **数据可溯源**：Valid(J_stride) ⇒ Certified(DPC) ∧ ρ_data≥0，数据质量缺陷被计价（定理 7）。
2. **接触可调度**：PG-CGG 只在 settled 窗判定，瞬态被冲击模型解释，摆动相不误判（引理 8）。
3. **地形可探测**：FAP 在平衡/滑移/力限约束下最大化地形 Fisher 信息，误差 O(√(dσ_w²/(k f_n²)))（引理 9）。
4. **平衡可认证**：ρ_bal≥0 且调度被实现 ⇒ P[摔倒] 有界（定理 8）。
5. **七层链**：Valid(J_stride) ⇒ GRIP 四层 ∧ 数据 ∧ 步态 ∧ 平衡；任一层失效则证书失效并优雅降级。
6. **优雅降级**：数据未认证 → 退 GRIP 保守档；步态调度失配 → stand/爬行；地形不可信 → 只走已测地形；平衡裕度不足 → 增大占空比/降速；多通道同时失效 → safe_stand。∎

**命题（门控-检测延迟权衡）** 设稳定窗样本率 γ_gate，单样本非中心参数 λ，窗口 n_w。检出所需样本数 N ≈ 2 log(1/β)/λ（非中心 χ² 近似），墙钟延迟 `T_detect ≈ N/(γ_gate·f_s)`。故门控降低误报的代价是延迟 ∝ 1/γ_gate；DQG 在数据质量差时应主动降低 f_s 或增大 n_w 以补偿，否则会出现"误报少了、但发现太晚"的假安全。∎

## 7. 已知风险

**一句话**：数据质量是**自测量**（可由错误的质量模型、被污染的审计器或分布漂移系统性高估），而落脚点探针把"获取数据"与"物理安全"耦合在一起——一旦 DQ2E 常数失准或审计器被欺骗，"数据证书"会给出虚假的确定性；一旦信息最优落脚点落到未建模的脆弱地形上，"步态探针"会直接换来一次摔倒；更隐蔽的是保守步态会主动减少新奇接触、使数据覆盖永久停滞，把系统锁死在"安全但无用"的自我实现预言里——数据质量与步态规划因此同时成为第 65 轮新增的两个单点故障。

**次级风险与缓解**：
1. **质量指标可被游戏**：审计器本身是学习/统计模块，可能被投毒或漂移欺骗。缓解：审计器与主模型**物理/数据隔离**（独立数据源、独立标定），DPC 双签（自动审计 + 人工抽检），质量剖面做时序一致性检查；任何审计器版本变更使旧证书失效。
2. **DQ2E 常数模型相关且可能失准**：缓解：不校准即返回 ⊥；用上包络而非均值；E231 留出集验证覆盖率；对未覆盖质量区间强制取全局最保守常数。
3. **探针导致摔倒**：信息最优落脚点可能在未建模脆弱地形上。缓解：FAP 的安全约束是硬约束，且对 B(φ̂,r) 全采样验证；`probe_infeasible` 时退回最大支撑裕度；探针力/速度受限；未知地形默认 `terrain_trusted=False`，只做低信息、高支撑的落脚。
4. **安全-数据自激（保守化饿死数据）**：缓解：DQG 的 δ_info 最小探索预算 + 信息增益下界；把"覆盖停滞"作为证书的显式失效条件（drift_witness 或 coverage_stall 越界即要求人工/主动探索）；在安全集内优先选择"能覆盖新地形且平衡裕度足够"的落脚。
5. **时序同步**：接触事件对时偏极敏感，50ms 时偏可把触地冲击错当模型错误。缓解：硬件时间戳/ PTP；q_sync 进入 DPC；时偏超界直接置 `untrusted`；PG-CGG 的瞬态窗按最坏时偏加宽。
6. **动态步态与腾空相**：刚体静力学接触模型在腾空/飞行相不成立。缓解：仅在支撑相做 CGG；腾空相用惯性/动量模型；GSL 对飞行相步态设更高数据前置与更保守 ρ_bal。
7. **训练时投毒超出运行时 AIC 范围**：AIC-D 只能在运行时检测分布异常，无法回溯训练集。缓解：DPC 的 ε_p/ε_bd 与稳健估计把训练时污染纳入证书；超过击穿点则拒绝认证，而非"运行时兜底"。
8. **实时预算超支**：WCV-D/OLP-D 维度上升。缓解：共享编码、尾部采样缓存、预计算 DQG 映射表、OLP-D 缓存降级；必要时把 WCV-D 的 n_worst 从 8 降到 6 并相应增大 r。
