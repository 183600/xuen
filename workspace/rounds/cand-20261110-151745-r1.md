# 第 46 轮（承接第 45 轮 v10；本轮灵感：触觉感知 × 指标体系） · Contact-Metric：触觉接触证书 × 非补偿指标格 × 多证书联合仲裁（四层架构 v11）

> 承接第 45 轮 v10 Energy-Context-Depth。v10 把姿态升级为分层条件覆盖证书、把能耗升级为能量租约、把上下文升级为预测性深度门控，但保留两个隐含假设：H5a 所有证书都来自外感受感知（RGB/双目/深度），接触安全被默认由「手的位置在安全盒内」推出；H5b 系统健康可用一组标量指标分别评估后加权汇总。UniBot 的抓取/擦拭/插接等任务真正决定安全的是**接触点**：力超限、滑移、剪切与传感器饱和都被视觉遮挡，深度也无能为力；而指标一旦允许加权补偿，覆盖率可以掩盖力超限，指标便不再 sound。两个灵感词精确命中 H5：**触觉感知**提供局部但直接、短时有效的接触证书；**指标体系**要求把安全维度做成非补偿格（t-norm / 字典序），并显式度量补偿缝隙与审计预算。三者耦合出新问题：**如何在视觉姿态证书、能量证书、触觉接触证书之间做非补偿联合仲裁，使接触安全不能被视觉覆盖率补偿，且在触觉退化或接触落在未布传感器区域时于运动前 fail-closed**。

## 0. 直觉与动机

**灵感 1（触觉感知 → 接触边界证书，局部但决定性）**
直觉：视觉说「手到了」，触觉说「到了以后安不安全」。定义触觉场 τ_t 与接触证书 F_t=(C_t,[f⁻_t,f⁺_t],s_t,ρ_f)，其中 C_t 为接触区域、力区间由共形校准给出、s_t 为滑移概率、ρ_f 为有效触觉覆盖率。触觉证书的有效期远短于姿态证书（50–100ms vs 数百 ms），因此单列触觉租约 ℓ_f；未接触任务 ℓ_f 可空，一旦任务要求接触且 F_t 无效，直接 fail-closed，而不是降速继续碰。

**灵感 2（指标体系 → 非补偿聚合与补偿缝隙）**
直觉：安全 KPI 不能求加权平均。若安全指标集合 S 用 t-norm ⊗（min 或 product）聚合，任一安全维度为 0 则整体为 0；性能指标 P 才允许加权平均；最终用字典序 (I_S, I_P)。定义补偿缝隙 Γ=μ_w(I_S)−I_S（加权均值减非补偿值），Γ 大即说明该指标系统正在掩盖某个安全违例。给出命题：任何对安全指标赋权 w_i<1 的加权和都存在对抗剖面使单项为 0 而总分达标，故不 sound；只有 t-norm / barrier 类聚合满足「单项失效不可补偿」。

**灵感 3（交叉审计与指标驱动预算）**
直觉：触觉是视觉的独立审计通道。定义跨模态残差 r_t=dist(π(C_t), C_t^obs)，若触觉说「已接触/滑移」而视觉说「自由空间」，以触觉为准并冻结运动（接触安全不对称）。同时，指标的不确定度与敏感度决定审计预算：u_i·σ_i 越大越该被采样，模型化为预算 b 下的注水分配。

**耦合升级**：四层 v11 = v10 + 根信任层新增**触觉租约 ℓ_f**，L1 几何层新增**接触条件半径 r_ω(m,F)**，L2 上下文层新增**接触意图预测**（预测将进入接触/滑移层），L3 CAR 守卫升级为**字典序多证书门**，L4 DCL 采集加入触觉退化层与指标驱动采样；并新增一个横跨四层的**指标治理面（Metric Governance）**，只读地监视 Γ、各指标不确定度与审计覆盖，不允许参与安全决策的补偿。

## 1. 形式化定义（增量：定义 54–57）

**定义 54（触觉接触证书与触觉租约）**
触觉场 τ_t={(p_i,f_i,n_i)}（触点位置/力/法向），分层 ω^f_t∈Ω_f={FREE,CONTACT,SLIP,SAT,SHEAR,FAULT,STALE}。接触证书
F_t=(C_t,[f⁻_t,f⁺_t],s_t,ρ_f)，
**接触 soundness**：P(f_true∈[f⁻_t,f⁺_t] ∧ contact∈C_t | ω^f_t, calib_f) ≥ 1−α_f。
触觉租约 ℓ_f=(τ_f,h_f,B_f)：h_f 为新鲜度上界（50–100ms），B_f 为带宽。ℓ_f 失效 ⇔ 当前分层∈{FAULT,STALE} 或 t−τ_f>h_f。任务要求接触而 F_t 无效时，系统进入 ContactFailClosed。

**定义 55（指标体系与非补偿聚合）**
指标族 I={I_1..I_n}，分为安全集 S 与性能集 P；每个指标有估计 Î_i、不确定度 u_i、对谓词敏感度 σ_i=|∂φ/∂I_i|、阈值 θ_i。聚合算子
I_S=⊗_{i∈S} Î_i（⊗ 为 t-norm，取 min 或 product），
I_P=Σ_{i∈P} w_i Î_i，
指标判决 J=(I_S,I_P) 按**字典序**比较，安全层严格优先。
**补偿缝隙** Γ=μ_w(I_S)−I_S，其中 μ_w 为同一安全集的加权均值。
**指标 soundness**：若 I_S≥θ_S 则 P(φ)≥1−α_I。
**命题（加权和的非 sound 性）**：若存在安全指标 j 的权重 w_j<1，则存在剖面使 Î_j=0、其余指标取 1 且加权和≥θ_S，但 φ 以正概率不成立；故加权和不满足指标 soundness。证明：令其余 n−1 项为 1，则加权和=(1−w_j)+w_j·0=1−w_j；对任意 θ_S≤1−w_j 该剖面通过而单项安全指标为 0，与 φ 冲突。∎ 推论：只有 t-norm 或 barrier 约束（I_S≥θ_S ⇔ ∀i∈S: Î_i≥θ_i 的乘积形式）对安全维不可补偿。

**定义 56（多证书联合与指标门）**
联合证书 J_t=(P_t,F_t,ℓ_p,ℓ_e,ℓ_f,m_t,I_t)。
**联合 soundness**：若 ℓ_p,ℓ_e,ℓ_f 均有效、I_S≥θ_S、跨模态残差 r_t≤δ，则
P(φ(X_t,contact)|…) ≥ 1−(α_p+α_f+α_e)−ε_δ（并集界）。
**联合门**：CAR 仅在「非补偿证书全部有效 ∧ 指标字典序通过」时放行；接触任务缺 F_t 时 fail-closed，而非降级继续。

**定义 57（指标驱动审计预算）**
审计预算 b，给指标 i 分配 a_i≥0，风险 R(a)=Σ_i u_i σ_i exp(−c_i a_i)。求解 min R s.t. Σa_i≤b 得注水解
a_i*=(1/c_i)·ln(u_i σ_i c_i/λ)_+，
即不确定度×敏感度高、审计成本低的指标优先被采样，回灌 DCL。

## 2. 三大新增产出与既有 IP 升级

**IP-66 TACTILE-CERT（触觉接触证书引擎）**
- 分层判定：FREE/CONTACT/SLIP/SAT/SHEAR/FAULT/STALE
- 共形力区间与接触区域校准：按分层单独校准 [f⁻,f⁺]、s_t
- 触觉租约：短新鲜度 h_f + 带宽 B_f + 失效级联
- 接触条件姿态半径：r_ω(m,F) 在接触层额外膨胀

**IP-67 INDICATOR-LATTICE（非补偿指标格 / 指标治理面）**
- 安全/性能分层，安全维 t-norm 聚合，字典序判决
- 补偿缝隙 Γ 实时监视与告警；Γ>τ_Γ 视为指标被 gaming
- 指标 soundness 抽检（独立审计集），加权和反例回归测试

**IP-68 CROSS-MODAL ARBITER（触觉-视觉交叉仲裁）**
- 残差 r_t 与不对称仲裁：触觉报接触/滑移 → 立即冻结
- 触觉作为视觉姿态的独立审计通道，反向校准 r_ω
- 仲裁日志进 DCL 与 CCA 红队语料

**既有 IP 升级**
IP-60 PSE：半径查表升级为 r_ω(m,F_t)，接触层膨胀
IP-63 ECPS：模态效用加入触觉带宽/接触意图项
IP-61 DCL：采集加入 Ω_f 退化层与注水审计预算
IP-62 CCA：新增指标 gaming/Goodhart 红队、触觉磨损与饱和注入
IP-51 CAR：守卫升级为字典序多证书门（v7）
IP-45 总线：新增 tactile-cert / indicator-lattice / audit-budget 话题

## 3. 算法骨架

每控制周期：
1. 更新 ℓ_e、ℓ_p；读 τ_t，判定 ω^f_t，签发 F_t 与 ℓ_f。
2. 计算指标 Î_i,u_i,σ_i，做非补偿聚合 I_S 与 Γ。
3. 若任务要求接触且 F_t 无效 → ContactFailClosed。
4. 跨模态残差 r_t>δ → 冻结运动并请求重观测（触觉优先）。
5. CAR 字典序门：ℓ 全部有效 ∧ I_S≥θ_S ∧ r_t≤δ 才放行。
6. 按注水解分配审计预算，最高 u_i·σ_i 的指标进 DCL 采集。
PSE 签发 P_t(m_t,F_t)，唯一允许的补偿是性能维度内部。

## 4. 本轮最大风险

**一句话**：触觉只覆盖指尖/局部区域，若把「F_t 有效」误当作「整只手接触安全」，或运营者为压低 fail-closed 率而调松安全指标阈值/改权，非补偿指标格会被 Goodhart 绕过，出现传感器未覆盖区域的无证书接触与静默安全违例；因此必须把触觉覆盖率 ρ_f 与补偿缝隙 Γ 本身列为不可补偿的安全指标，并对阈值/权重变更做独立审计与红队回归。

## 2. 关键算法 伪代码

### IP-66 TACTILE-CERT
```
Omega_f = [FREE, CONTACT, SLIP, SAT, SHEAR, FAULT, STALE]

def tactile_stratum(tau, t, h_f, tau_s, tau_sh):
    if tau is None or t - tau.stamp > h_f: return STALE
    if tau.fault:                          return FAULT
    if tau.saturated.any():                return SAT
    if tau.slip_score > tau_s:             return SLIP
    if tau.shear_norm > tau_sh:            return SHEAR
    if tau.contact_mask.any():             return CONTACT
    return FREE

def tactile_cert(tau, t, calib_f, alpha_f):
    w = tactile_stratum(tau, t, calib_f.h_f, calib_f.tau_s, calib_f.tau_sh)
    if w in (FAULT, STALE):
        return F_t(valid=False, stratum=w)          # 不可用 -> 触发接触门
    lo, hi = calib_f.force_interval[w](tau)          # 分层共形区间
    C      = calib_f.contact_region[w](tau)
    s      = calib_f.slip_prob[w](tau)               # P(slip | tau,w)
    rho_f  = tau.valid_pads / tau.total_pads         # 触觉覆盖率
    return F_t(C, lo, hi, s, rho_f, valid=True, stratum=w)

def tactile_lease(F, t):
    if not F.valid:            return INVALID
    return Lease(tau=t, h_f=calib_f.h_f, B_f=calib_f.B_f)
```

### IP-67 INDICATOR-LATTICE（非补偿聚合 + 反例回归）
```
def indicator_aggregate(I, S_idx, P_idx, w, theta_S):
    I_S = t_norm([I[i] for i in S_idx])     # min 或 product，禁止加权
    I_P = sum(w[i]*I[i] for i in P_idx)     # 仅性能维可补偿
    mu  = weighted_mean([I[i] for i in S_idx], w)
    Gamma = mu - I_S                        # 补偿缝隙
    sound = (I_S >= theta_S)
    return J(I_S, I_P, Gamma, sound)        # 判决按 (I_S, I_P) 字典序

def proposition_weighted_sum_counterexample(n, w_j, theta_S):
    # 令安全指标 j 取 0，其余取 1
    I = [1.0]*n; I[j] = 0.0
    weighted = sum(w[i]*I[i] for i in range(n))   # = 1 - w_j
    assert weighted >= theta_S                    # 若 theta_S <= 1-w_j
    assert I[j] == 0.0                            # 单项安全失效却被掩盖
    return NOT_SOUND

def indicator_gaming_guard(J, tau_Gamma):
    if J.Gamma > tau_Gamma:
        return Alert('indicator_gaming')          # 只告警，严禁自动调权降阈
    return None
```

### IP-68 CROSS-MODAL ARBITER
```
def cross_modal_residual(P_t, F_t):
    if not F_t.valid: return INF
    return dist(project(F_t.C, P_t.hand_frame), F_t.C_obs)

def arbitrate(P_t, F_t, r, delta):
    # 接触安全不对称：触觉报危险一律以触觉为准
    if F_t.stratum in (CONTACT, SLIP, SHEAR) and not P_t.valid:
        return FREEZE_MOTION                      # 触觉优先
    if r > delta and F_t.valid and not P_t.valid:
        return FREEZE_MOTION
    if r > delta and P_t.valid and not F_t.valid:
        return HOLD_CONTACT                       # 未知接触，不得继续压入
    if r > delta:
        return FAIL_CLOSED
    return ACCEPT
```

### IP-51 CAR v7（字典序非补偿多证书门）
```
def car_guard_v7(e, x, cert, persona, lp, le, lf, F_t, I_t, r_t, delta, t):
    # 1) 根信任：三条租约全部有效（不可补偿）
    if not (pose_lease_valid(lp,t) and energy_lease_valid(le,t,E_min(e))
            and tactile_lease_valid(lf,t)):
        cascade_invalidate('pose_energy_tactile')
        return FailClosed()
    # 2) 接触任务：无有效接触证书即停（不允许降速继续）
    if task(e).requires_contact and not F_t.valid:
        return ContactFailClosed()
    # 3) 指标字典序门：安全维非补偿
    J = indicator_aggregate(I_t, S_idx, P_idx, w, theta_S)
    if not J.sound:
        return FailClosed()
    # 4) 跨模态一致性
    if r_t > delta:
        return arbitrate(x.P_t, F_t, r_t, delta)
    # 5) 半径扣减：姿态 + 能量 + 触觉滑移
    r     = radius_lookup(x.stratum, x.m_t, cert.calib, F_t)
    m_pose   = L_phi[e]*r
    m_energy = L_e*(B_min - E(t))_+
    m_tact   = L_f*F_t.s + L_rho*(1 - F_t.rho_f)   # 覆盖率不足也扣减
    m = min(cert.lookup, lp.m, persona_cap) - m_pose - m_energy - m_tact
    return m >= theta(e)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TACTILE-CERT | O(N_pad) 每周期（1kHz 可行） | O(N_pad) | 分层共形 ⇒ P(f∈[f⁻,f⁺]\|ω^f)≥1−α_f |
| INDICATOR-LATTICE | O(n)（t-norm/min） | O(n) | 安全维 t-norm + 字典序 ⇒ 单项失效不可补偿 |
| 反例回归 | O(1)/剖面，离线批量 | O(n) | 加权和在 w_j<1 时必被反例捕获 |
| 注水审计分配 | O(n log n)/审计轮 | O(n) | KKT ⇒ 风险 R 最小 |
| ARBITER | O(1)（预投影） | O(1) | 不对称仲裁 ⇒ 触觉危险不可被视觉否认 |
| CAR v7 | O(1) | - | 三租约 ∧ I_S ∧ 残差 ⇒ fail-closed 级联 |

**联合正确性定理**：若 ℓ_p、ℓ_e、ℓ_f 均有效，I_S≥θ_S（安全维 t-norm 非补偿），r_t≤δ，且 P_t、F_t、能量证书分别满足 (α_p,α_f,α_e)-sound，则联合证书 J_t 对谓词 φ(X_t,contact) 的 soundness 下界为 1−(α_p+α_f+α_e)−ε_δ；任一条件失效即进入 FailClosed 或 ContactFailClosed。
**不可补偿性推论**：由定义 55 命题，任何对 S 中指标赋权 w_i<1 的汇总都存在「单项为 0 而总分达标」的对抗剖面，因此指标治理面禁止对安全维做加权求和；Γ>τ_Γ 仅告警、不得自动调权降阈。

## 4. 实验设计 E109–E114

| 实验 | 指标 | 门槛 |
|---|---|---|
| E109 触觉证书 soundness | 力区间条件覆盖率；滑移漏检率 | ≥1−α_f(α_f=0.05)；测试集 0 漏检 |
| E110 非补偿 vs 加权和 | 对抗剖面中加权和通过但单项失效的比例；指标格通过率 | 加权和暴露缺陷 100%；指标格 0 假通过 |
| E111 跨模态仲裁 | 接触冲突检测延迟；误冻结率；未证书接触次数 | ≤50ms；<2%；0 起 |
| E112 指标 Goodhart 压测 | 调阈/改权攻击后的静默违例；Γ 检出率 | 0 起静默违例；Γ 检出 ≥95% |
| E113 审计预算效率 | 每审计小时发现的违例数 vs 均匀分配 | ≥2× |
| E114 100h 接触密集任务闭环 | 接触成功率；力超限次数；fail-closed 率；ρ_f 覆盖 | ≥基线；0 起；≤5%；ρ_f≥90% |

回退：E109 覆盖不足 → 触觉证书降级为「仅作独立告警」，接触任务强制限力 + 低速；E110/E112 指标被 gaming → 冻结阈值/权重，切回人工审计；E111 仲裁误冻结过多 → 提高 δ 但保留触觉优先规则；E114 违例 → 回退 v10（无触觉证书）并缩小接触任务范围。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 触觉仅覆盖指尖，未布区接触无证书 | 高 | 把 ρ_f 列为不可补偿安全指标；未覆盖区默认限力/禁接触；任务规划避开未布区 |
| 为压低 fail-closed 率而调松阈值/改权（Goodhart） | 高 | 阈值与权重变更需独立审计 + 反例回归；Γ 监视；禁止在线自动调权 |
| 触觉磨损/漂移导致力区间失准 | 高 | 定期原位标定 + 在线残差监测 + 租约快速过期 |
| 非补偿门过保守导致任务不可用 | 中 | 仅安全维非补偿；性能维保持可优化；分级 fail-closed（限力/冻结/停机） |
| 跨模态残差 δ 标定偏差 | 中 | 用独立审计集校准 δ；冲突样本回灌 DCL |
| 多证书并集界随证书数增长变松 | 中 | 相关性建模替代朴素并集界；关键证书 α 收紧 |

## 6. 本轮最大风险

**一句话**：触觉只覆盖指尖/局部，若非补偿指标格中的 ρ_f 与 Γ 本身未被列为不可补偿安全指标，运营者可通过调松阈值、改权或忽略未布传感器区域，让「指标通过」与「接触安全」解耦，产生 Goodhart 式静默安全违例；因此必须把触觉覆盖率与补偿缝隙纳入安全维、对阈值/权重变更做独立审计，并在未证书接触前直接 ContactFailClosed。
