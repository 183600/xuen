# 第 43 轮 · 证书排行榜 × 抓取：把「单证书部署」升级为「安全偏序下的可竞争证书生态」（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR 的 Sim-Cert-RAG 飞轮）。第 42 轮自陈最大风险是**仿真偏差累积 + 检索幻觉**：证书在「自证闭环」里自信失效。本轮灵感词「排行榜」「抓取」正好给出两条外部制衡。**排行榜**的直觉是：不要再让单一证书自证——把 CKB 里检索出的模板、LCS 的各档监控器、不同抓取策略生成的一组候选证书放进同一个**共享且留出**的场景池互相竞争，用配对比较和 PAC 排名只给出「谁在哪个有效域内更好」的**安全偏序**，而不是一个可被 Goodhart 攻击的全局总序；安全门保证任何未过门者永不进榜、永不部署。**抓取**有两重含义且恰好互补：其一，抓取是接触丰富、动力学**分段不连续**的典型任务，直接击穿第 42 轮全局 Lipschitz 常数 L_m 的假设（接触模式切换处边际跳变），必须换成**按接触模式分片**的证书；其二，「抓取」即**主动抓取评估样本**——当排行榜前几名统计上难分时，主动去抓信息量最大、且与候选生成过程隔离的场景，把评估预算花在消除歧义上。两者耦合：接触证书定义「合法比较域」，排行榜只在该域内排序，主动抓取用最少样本消除近邻歧义，证据再回流 SCV/CKB。证书由此从飞轮里的「单点制品」变成生态里的「可竞争个体」。

## 0. 直觉与动机

**灵感 1（排行榜 → 用竞争与统计显著性对抗「自证幻觉」）**：第 42 轮的证书质量靠自己的仿真与自己的检索来背书，闭环越顺，越容易把偏差固化。排行榜的直觉是把「证书好不好」从**绝对断言**降级为**相对可比的偏序**：同一批候选（不同模板、不同量化档、不同抓取策略）在**共享场景池**上两两配对比较，只有在置信下界全面压过对手时才判定支配。这样做有三重好处：(1) 错误不再由单一候选自证，而由竞争暴露；(2) 输出是偏序而非全序，天然拒绝「不同有效域强行比大小」；(3) 排名不确定时系统知道自己不确定，可回退到 max-min 或 SafeStop。排行榜不是荣誉墙，而是**带安全门的统计假设检验装置**。

**灵感 2（抓取的任务侧 → 接触模式分片证书）**：抓取是检验第 42 轮迁移界的最好试金石。接触发生的瞬间，系统从自由空间进入约束流形，边际函数 m(x) 出现跳变，全局 Lipschitz 常数会被最坏模式撑得极大，导致 α_e 保守到不可用；反过来若强行用小 L_m，跨模式时又会漏报。正确做法是：按接触签名 σ（哪些连杆接触、粘/滑状态）把状态空间分片，每片有自己的 m^σ、L_m^σ，模式切换处单独设**跨模式守卫**并把切换代价计入迁移界。抓取本身的证书用**力闭合裕度 ε** 与**滑移概率上界**表达，抓取分类学（平行夹、包络、吸附、多指）作为 KB 的一等公民。

**灵感 3（抓取的数据侧 → 主动抓取式评估）**：排行榜最贵的是样本。若对 k 个候选做全配对，样本量 ∝ k²；但部署只关心「头部是否分得清」。主动抓取式评估（active dueling）的直觉是：每轮挑一个场景，使「排名后验熵的期望下降」最大——通常是让当前并列的两三个候选在某个场景上产生最大分歧。更关键的是**污染防护**：候选证书若由某个场景生成器蒸馏而来，就不能再用该生成器的场景给它打分；主动抓取必须在**与所有候选生成过程 provenance 不相交的留出池**里进行，否则排行榜只是在奖励过拟合。

**耦合升级**：接触证书（CGC）提供模式分片的合法比较域 → 排行榜（CLB）只在该域内做安全偏序 → 主动抓取（AGE）在留出池里用最小样本消除近邻歧义 → 结果与反例回流 SCV/CKB，更新下一轮候选与排名先验。第 42 轮是「仿真→知识→边缘→仿真」的数据飞轮，本轮在其上加一层「**候选竞争→留出评估→证据回流**」的**选择飞轮**，两层正交耦合。

## 1. 形式化定义（增量：定义 38–43）

**定义 38（排行榜条目与证据）**：条目 e_i = (C_i, M_i, π_i, D_i, V_i, h_i)，分别为证书模板、监控器、策略、有效域、证据集、provenance 哈希。证据集 V_i = {(x, y, ℓ)} 记录在共享场景 x 上以标签 y 产生的观测（如边际、违例、抓取成败、滑移），h_i 记录该候选的训练/生成来源，用于污染检测。

**定义 39（安全门与认证支配偏序）**：安全门 G(e) := UCB_δ(Vio(e)) ≤ α，其中 Vio 为违例率的经验估计上置信界。**认证支配**定义为：在公共有效域 D_ij = D_i ∩ D_j 上
e_i ⪰_c e_j ⟺ G(e_i) ∧ G(e_j) ∧ LCB_δ(m_i | D_ij) ≥ UCB_δ(m_j | D_ij)。
该关系在共同域上是偏序（自反、反对称；在置信区间不重叠时传递），**未过安全门者不参与任何比较**。仅 Pareto 极大元 Max_⪰(CLB) 可被部署。

**定义 40（配对比较下的 PAC 排名）**：对任意场景 x∈P（留出池），比较结果由 sign(m_i(x) − m_j(x)) 加噪声给出。目标是返回头部集合 Ĥ 满足 P(H* = Ĥ) ≥ 1 − δ，其中 H* 为真实前 k 名。采用带安全否决的连续消除 / RUCB 变体；在间隔 Δ = min_{i∈H*, j∉H*} E_x[m_i − m_j] > 0 时，样本复杂度 O((k log k)/Δ² · log(1/δ))，全配对基线为 O(k²/Δ²)，故头部排序在 Δ 小时显著更省。

**定义 41（主动抓取式评估与污染隔离）**：每轮选择
x* = argmax_{x∈P_holdout} [ H(rank | V) − E_{obs}[H(rank | V ∪ {(x, obs)})] ]，
受预算 B 与多样性约束。**污染隔离约束**：x* ∉ ⋃_i Gen(h_i)，其中 Gen(h_i) 为候选 i 生成时可见的场景集合；P_holdout 的 provenance 与所有 Gen(h_i) 不相交。违反该约束时排名作废并触发红队审计。

**定义 42（接触模式证书与抓取证书）**：以接触签名 σ∈Σ 划分状态空间 X = ⊔_σ X_σ（Σ 枚举接触连杆集与粘/滑/分离标志）。每片边际 m^σ 在片内 L_m^σ-Lipschitz；跨片由切换守卫 h_{σ→σ'} 连接，并把切换代价 κ_{σ→σ'} 计入迁移界：
m_real(x) ≥ m_sim(x) − L_m^{σ(x)}·ε_w − κ_{σ→σ'}。
**抓取证书** G_cert = {q : ε_fc(q) ≥ ε_min ∧ P_slip(q) ≤ p_max}，其中 ε_fc 为力闭合裕度（最小抵抗旋量距离），P_slip 由接触力锥与摩擦系数不确定集界出；抓取分类学标签作为 KB 的检索键之一。

**定义 43（排行榜驱动部署与回退）**：给定 CLB，部署
e* = argmax_{e∈Max_⪰(CLB)} [ Avail(e) − λ·CVaR_β(Vio(e)) ]。
若顶部集合的排名后验熵 H(rank|V) > τ_amb，则不赌单点，退化为域受限的 max-min 证书或 SafeStop。与 oracle 排名相比的部署后悔 R_T = Σ_t [U(e*) − U(e_t)] 有界，界含排名误差项与域错配项。

## 2. 产出设计（新增 IP-57/58/59 + 升级 IP-54/55/56/51/52/47）

### 2.1 IP-57 CERT-LEADERBOARD（CLB，证书排行榜）
1. **条目注册与安全门**：候选来自 CKB 检索、LCS 各档、不同抓取策略；先过 G(e) 违例上界门，未过门者只进「隔离区」不进榜。
2. **偏序前端**：在公共有效域上用配对比较构造 ⪰_c，维护 Pareto 极大元集合与支配关系图；域不交的候选只做「不可比」标注。
3. **PAC 赛制**：Successive Elimination + RUCB 头部排序，输出带置信半径的名次区间而非单一分数。
4. **部署选择器与回退**：按定义 43 在极大元中做风险厌恶选择；排名后验熵过高 → 域受限 max-min / SafeStop。

### 2.2 IP-58 ACTIVE-GRASP-EVALUATOR（AGE，主动抓取式评估）
1. **信息增益查询**：用排名后验的近似熵（或 top-2 分歧概率）作采集函数，优先抓「能拆开并列者」的场景。
2. **provenance 隔离**：场景池按生成器打哈希，候选生成来源记录在 h_i；查询前做交集检查，命中则剔除并告警。
3. **多样性约束**：贪心信息增益 + 场景去重（状态/语义/接触模式覆盖），防止只抓单一模式导致排名偏置。
4. **预算调度**：与 Isaac Sim 预算共享，先粗排（少样本）再精排（主动抓取），红队候选单独跑污染测试。

### 2.3 IP-59 CONTACT-GRASP-CERT（CGC，接触/抓取证书）
1. **模式分片**：在线接触签名分类器给出 σ(x)，离线为每个 σ 标定 m^σ、L_m^σ 与切换守卫。
2. **抓取证书**：力闭合裕度 ε_fc、滑移概率上界 P_slip、抓取分类学先验；抓取成功/失败的接触轨迹入 KB。
3. **跨模式迁移界**：按定义 42 计算逐片 α_e^σ 与切换代价 κ，避免全局 L_m 被最坏模式撑爆。
4. **切换守卫压力测试**：在 σ→σ' 边界附近对抗采样，统计误切/漏切，反例带模式标签回流 SCV。

## 5. 本轮最大风险

**一句话**：排行榜与主动抓取构成了一个**候选与场景协同进化的对抗回路**——只要留出池的 provenance 隔离有一丝泄漏，「冠军」就只是最会迎合评估器的过拟合者，排行榜会把「过拟合」误认证为「安全」，且比第 42 轮的静默失效更具欺骗性；因此 E91（污染红队）与 E88（留出集独立性审计）必须作为一票否决的红线实验。

| R_T = Σ_t [U(e*) − U(e_t)] | 部署后悔 | 相对 oracle 排名，含排名误差与域错配项 |

### IP-57 CLB：安全门、认证偏序与 PAC 头部排序
```
def build_leaderboard(candidates, P_holdout, delta, alpha):
    # 0. 安全门：未过门者只进隔离区
    admitted = [e for e in candidates if safe_gate(e, P_holdout, delta, alpha)]
    quarantined = [e for e in candidates if e not in admitted]

    # 1. 证据收集：公共有效域上的配对比较（可并行）
    for e in admitted:
        e.V = collect_paired_evidence(e, P_holdout)

    # 2. 认证支配偏序（只在公共域比较，域不交标"不可比"）
    dom = {}
    for ei, ej in combinations(admitted, 2):
        Dij = ei.D & ej.D
        if is_empty(Dij):
            dom[(ei, ej)] = 'incomparable'
            continue
        lcb_i = lower_conf_bound(ei.V, Dij, delta)
        ucb_j = upper_conf_bound(ej.V, Dij, delta)
        if lcb_i >= ucb_j: dom[(ei, ej)] = 'dominates'
        elif ...: dom[(ei, ej)] = 'dominated'
        else: dom[(ei, ej)] = 'tie'

    # 3. 只保留 Pareto 极大元
    maximal = [e for e in admitted
               if not any(dom.get((o, e)) == 'dominates' for o in admitted)]

    # 4. PAC 头部排序（连续消除 / RUCB，带安全否决）
    head = pac_topk(maximal, P_holdout, k=3, delta=delta)

    return Leaderboard(maximal, head, quarantined, dom, version=hash(...))

def safe_gate(e, P, delta, alpha):
    # UCB of violation rate：用 Clopper-Pearson 上界
    return clopper_pearson_upper(e.V.violations, e.V.n, 1-delta) <= alpha

def select_deploy(clb, lambda_, beta, tau_amb):
    # 排名后验熵过高 -> 不赌单点
    if rank_entropy(clb.head) > tau_amb:
        return domain_restricted_maxmin(clb.maximal), 'FALLBACK'
    best = max(clb.maximal,
               key=lambda e: e.avail - lambda_*cvar(e.V.violations, beta))
    return best, 'DEPLOY'
```

### IP-58 AGE：信息增益抓取与 provenance 隔离
```
def active_grasp_query(clb, P_holdout, budget, diversity_min):
    queried = []
    for _ in range(budget):
        # 污染隔离：剔除所有候选生成过程可见的场景
        gen_union = union([gen_set(e.h) for e in clb.entries])
        admissible = [x for x in P_holdout if x.provenance not in gen_union]

        # 候选对：优先当前并列/置信区间重叠的对
        ambiguous = [(i, j) for (i, j) in clb.pairs
                     if clb.dom[(i, j)] == 'tie']

        best_x, best_gain = None, -inf
        for x in admissible:
            if not diversity_ok(x, queried, diversity_min):
                continue
            gain = expected_rank_entropy_drop(clb, x, ambiguous)
            if gain > best_gain:
                best_x, best_gain = x, gain

        if best_x is None:
            break
        obs = evaluate_all(clb.entries, best_x)   # 一次场景，多个候选共享
        clb = update_posterior(clb, best_x, obs)
        queried.append(best_x)
    return clb, queried

def expected_rank_entropy_drop(clb, x, pairs):
    # 只在并列对上计算期望信息增益，避免全排列
    H0 = rank_entropy(clb.head)
    exp = 0.0
    for (i, j) in pairs:
        p = prob_i_beats_j(clb, i, j, x)
        exp += p * rank_entropy_after(clb, i, j, winner=i) \
             + (1-p) * rank_entropy_after(clb, i, j, winner=j)
    return H0 - exp / max(1, len(pairs))

def contamination_audit(clb, P_holdout):
    # 红队：若任一候选在留出池上的边际显著优于其生成池，判为可疑
    flags = []
    for e in clb.entries:
        gap = mean_margin(e, P_holdout) - mean_margin(e, gen_set(e.h))
        if gap > 2 * stderr(e, P_holdout):
            flags.append((e, gap))
    return flags
```

### IP-59 CGC：接触分片证书与抓取证书
```
def contact_mode_certificate(x, sigma, calib):
    # sigma(x): 在线接触签名分类（连杆集 + 粘/滑/分离）
    s = classify_contact(x)
    # 逐片标定：m^sigma, L_m^sigma, 切换守卫
    m_s = calib[s].margin(x)
    L_s = calib[s].L_m
    # 跨模式迁移界：含切换代价 kappa
    alpha_s = 1.0 + (L_s * calib.eps_w + calib.kappa[s]) / max(1e-6, calib.theta[s])
    return {'sigma': s, 'm': m_s, 'alpha': alpha_s, 'theta_real': alpha_s*calib.theta[s]}

def grasp_certificate(q, contact_model, friction_unc):
    # 力闭合裕度：最小抵抗旋量距离
    eps_fc = min_resisted_wrench_distance(q, contact_model)
    # 滑移概率上界：摩擦锥不确定集上的最坏情形
    p_slip = worst_case_slip_prob(q, friction_unc)
    ok = (eps_fc >= EPS_MIN) and (p_slip <= P_MAX)
    return {'ok': ok, 'eps_fc': eps_fc, 'p_slip': p_slip,
            'taxonomy': grasp_taxonomy_label(q)}  # 平行/包络/吸附/多指

def mode_transition_guard(x, sigma_from, sigma_to):
    # 切换守卫：在模式边界附近留滞回 + 保持时间，防止抖动
    h = hysteresis(x, sigma_from, sigma_to)
    return h.guard_holds and (h.dwell_time >= T_HOLD)

def stress_contact_boundary(H, calib, N_per_boundary=500):
    # 在 sigma->sigma' 边界附近对抗采样，统计误切/漏切
    out = {}
    for (s, s2) in H.mode_edges:
        X0 = sample_near_boundary(H, s, s2, N_per_boundary)
        stats = run_batch_sim(H, X0, calib)
        out[(s, s2)] = {'false_switch': stats.false_switch / N_per_boundary,
                        'missed_switch': stats.missed_switch / N_per_boundary,
                        'margin_drop': stats.margin_drop.max()}
    return out
```

def scv_evaluate(H, pool_gen, pool_holdout, pool_redteam):

## 6. 本轮最大风险

**一句话**：排行榜与主动抓取构成了一个**候选与场景协同进化的对抗回路**——只要留出池的 provenance 隔离有一丝泄漏，「冠军」就只是最会迎合评估器的过拟合者，排行榜会把「过拟合」误认证为「安全」，且比第 42 轮的静默失效更具欺骗性；因此 E91（污染红队）与 E88（留出集独立性审计）必须作为一票否决的红线实验。
