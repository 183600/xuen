# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim++；灵感循环第 6 轮；本轮灵感：「步骤分」×「真机评测」）

> 第 54 轮把技能组合推进为动作空间剖面 α_S + 鲁棒性谱 ρ + 云边映射 γ_ce 的双证书体系。但该体系仍有两个隐含假设：**成功是二值的**、**仿真证书有效即可部署**。本轮用「步骤分」和「真机评测」拆掉这两个假设。核心矛盾：H22：二值成功掩盖了近失手与单步脆性，组合可能在仿真“全对”、真机“单步崩”；H23：真机评测预算稀缺、不可逆、分布会漂移，无法直接复用仿真证书，必须把“仿真学分”换算为带置信下界的“真机学分”。

## 0. 直觉与动机

**灵感 1（步骤分 → 把成功从 0/1 变成步骤信用向量）**
直觉：竞赛阅卷给步骤分——最终答案错了，前面正确的推理仍得分；反过来，答案对了但关键步骤跳步也可能扣分。机器人执行亦然：一个长程任务 `π` 可分解为步骤序列 `⟨σ_1,...,σ_n⟩`，每步有部分完成度 `s_t ∈ [0,1]`，总步骤分 `Score(π)=Σ_t w_t s_t`。这样即使整体失败，也能看到“走到第几步、每步多稳”。更关键的是，组合技能的好坏不再只是“是否完成”，而是“是否存在一个塌陷步”：瓶颈信用 `β = min_t s_t`。步骤分把第 54 轮的动作剖面 α_S 从“动作轴”扩展到“任务步轴”，形成 **动作 × 步骤的双轴信用剖面**。

**灵感 2（真机评测 → 仿真学分 ≠ 真机学分，必须带置信下界）**
直觉：真机评测贵、慢、危险、不可复现，不能把仿真里跑通的组合直接拿到真机上全量重测。正确做法是把真机试验当作稀缺证据：仿真给出先验步骤信用 `s^sim`，少量真机样本按步分层更新，用置信序列给出 **真机步骤信用下界** `s^L`。部署时只承认下界，不承认点估计。仿真-真机差距 `g_t = s_t^sim - s_t^real` 本身成为新的鲁棒性维度；差距大就自动降级证书。

**灵感 3（步骤分 × 真机评测 → 关键步聚焦的预算化主动评测）**
直觉：真机预算有限，应花在“最可能塌、且对总分最敏感”的步骤上。定义步骤关键度 `crit_t = λ_t · U_t · (1 - s_t^L)`，其中 `λ_t` 为对总分的敏感度、`U_t` 为真机信用的不确定度。主动评测策略每次选择 `crit_t` 最大的步骤做真机试验，并带安全壳与回滚；当某步下界已高于部署阈值，就停止在该步烧预算。这把真机评测从“均匀跑 N 次”变成“向关键步聚焦的序贯实验”。

**灵感 4（分级证书 → 从 in/out 到证书阶梯）**
直觉：考试有等级（不及格/及格/优秀），认证也应有阶梯：`ℓ0` 仅仿真、`ℓ1` 瓶颈步真机验证、`ℓ2` 全部关键步真机验证、`ℓ3` 全轨迹真机验证。每一级对应一套证据要求与风险预算 `(α_ℓ, β_ℓ, n_ℓ)`。高风险任务要求高等级，低风险任务可接受低等级；这比第 54 轮的二值“可部署/不可部署”更贴近工程现实，也避免为一次低风险部署付出全量真机评测成本。

**灵感 5（与 v54 双证书融合 → 步骤信用扩维的联合证书）**
直觉：把第 54 轮的联合证书 `J=(ρ, A_cert, γ_ce, δ_a)` 升级为分级联合证书 `J^g=(J; s^L, κ, ℓ, g)`：`s^L` 为真机步骤信用下界向量，`κ` 为置信度，`ℓ` 为证书等级，`g` 为仿真-真机差距谱。组合判定从“动作兼容 ∧ δ_a 预算”升级为“动作兼容 ∧ δ_a 预算 ∧ min_t s_t^L ≥ β_ℓ”。步骤分与动作剖面共同构成部署前的 **双轴信用检查**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（任务步骤分解与步骤信用）**
任务 `π` 的步骤分解 `Π(π)=⟨σ_1,...,σ_n⟩`，权重 `w_t ≥ 0, Σ_t w_t = 1`。执行轨迹 τ 的第 t 步信用
```
s_t(τ) = prog_t(τ) · gate_t(τ),   gate_t = ∏_{k<t} 1[s_k ≥ θ_k]
```
其中 `prog_t ∈ [0,1]` 为步内归一化进度，`gate_t` 为前缀门控（前序步不达标则后续步不得分，对应“跳步扣分”）。总步骤分 `Score(π)=Σ_t w_t s_t`，信用向量 `s(π)=(s_1,...,s_n)`。

**定义 122（步骤信用证书与分级联合证书）**
分级联合证书 `J^g = (ρ, A_cert, γ_ce, δ_a, s^L, κ, ℓ, g)`：`s^L` 为真机步骤信用下界向量，`κ=1-α` 为置信度，`ℓ` 为证书等级，`g=(g_1,...,g_n)` 为仿真-真机差距谱。瓶颈信用 `β(J^g)=min_t s_t^L`，保守总分 `Score^L=Σ_t w_t s_t^L`。组合在等级 ℓ 可部署当且仅当
```
compat ≥ θ_a ∧ δ_a ≤ Θ_a ∧ β(J^g) ≥ β_ℓ
∧ (∀t∈C_ε: s_t^L ≥ θ_t 若 ℓ ≥ ℓ2)
```

**定义 123（真机评测预算与统计桥）**
真机预算 `B=(N_max, C_max, T_safe)`：最多 N_max 次试验、成本 C_max、仅允许在安全动作包络 `T_safe ⊆ A_cert` 内执行。统计桥 `RMC: (s^sim, {τ_i}_{i≤N}) → (s^L, s^U)` 满足置信序列性质
```
P(∀t: s_t^L ≤ s_t^real ≤ s_t^U) ≥ 1-α
```
差距谱 `g_t = s_t^sim - s_t^real`；真机侧用 `s_t^U` 检测仿真高估，用 `s_t^L` 做部署判定。

**定义 124（步骤关键度与关键步集）**
总分对第 t 步的敏感度 `λ_t = ∂Score/∂s_t`（在前缀门控下退化为 `w_t`，门控已断则为 0）。真机不确定度 `U_t = s_t^U - s_t^L`。步骤关键度
```
crit_t = λ_t · U_t · (1 - s_t^L)
```
关键步集 `C_ε = {t | crit_t ≥ ε}`。

**定义 125（预算化主动真机评测与安全壳）**
评测策略 `π_eval: H → (t, a, bailout)`：H 为历史试验，选择下一步与动作 `a∈T_safe`，并给出 bailout 动作返回已认证区域。目标是在 `cost(π_eval) ≤ B` 下最小化 `P(β(J^g) < β_ℓ)`。安全约束：任何未在 `T_safe` 内的动作必须先证明存在可回滚 bailout。

**定义 126（真机证书阶梯）**
等级 `ℓ∈{ℓ0,ℓ1,ℓ2,ℓ3}` 与风险预算映射：
- `ℓ0` sim-only：无真机证据，`β_0` 仅作参考；
- `ℓ1` 瓶颈步真机：`argmin_t s_t^L` 至少 `n_1` 次真机样本，风险 `α_1`；
- `ℓ2` 关键步真机：`∀t∈C_ε` 至少 `n_2` 次真机样本，风险 `α_2=Σ_{t∈C_ε} α_t`；
- `ℓ3` 全轨迹真机：序贯检验通过 `∀t s_t^L ≥ θ_t`，风险 `α_3`。
任务风险等级 `risk(π)` 到 ℓ 的映射由部署方给定；证书带有效期 `TTL_ℓ`，过期即降级。

## 2. 关键算法 伪代码

### IP-121 SCS（Step-Credit Schema）

```python
def step_credit(trace, schema, theta):
    s, gate = {}, 1.0
    for t, sigma in enumerate(schema.steps):
        raw = schema.progress[t](trace)           # prog_t in [0,1]
        s[t] = raw if gate >= 0.5 else 0.0         # prefix gating
        gate *= 1.0 if s[t] >= theta[t] else 0.0
    score = sum(schema.w[t] * s[t] for t in s)
    return s, score
```

### IP-122 SGC（Step-Graded Certificate）

```python
def graded_certificate(J, s_lower, kappa, level, theta, beta_ladder):
    beta = min(s_lower.values())
    if level >= 2 and any(s_lower[t] < theta[t] for t in J.critical_steps):
        return ('reject', 'step_floor_violation', beta)
    if beta < beta_ladder[level]:
        return ('reject', 'bottleneck_below_level', beta)
    return ('ok', JGraded(J, s_lower, kappa, level, beta))
```

### IP-123 RMC（Real-Machine Calibration）

```python
def real_step_credit(sim_scores, real_traces, alpha, schema, theta):
    s_l, s_u = {}, {}
    m = len(schema.steps)
    for t in schema.steps:
        xs = [step_credit(tau, schema, theta)[0][t] for tau in real_traces]
        lo, hi = empirical_bernstein_ci(xs, alpha / m)
        s_l[t] = max(0.0, min(lo, sim_scores[t]))   # 仿真先验与真机证据取保守
        s_u[t] = max(hi, sim_scores[t])
    return s_l, s_u
```

### IP-124 SGA（Step-Gap Attribution）

```python
def step_gap_attribution(sim_scores, s_lower, s_upper, w, theta, k=3):
    gaps = {t: sim_scores[t] - s_lower[t] for t in sim_scores}
    blame = sorted(
        gaps,
        key=lambda t: w[t] * gaps[t] * (1 - s_lower[t]),
        reverse=True,
    )
    return gaps, blame[:k]        # top-k 塌陷步 + 每步反事实证据
```

### IP-125 AST（Active Step Testing）

```python
def active_real_testing(schema, sim_scores, budget, alpha, theta, safe_env):
    stats = init_confidence_sequences(schema, alpha)
    while budget.left() and not ladder_satisfied(stats, theta):
        t = max(schema.steps, key=lambda k: crit(k, stats, sim_scores, theta))
        a = safe_env.sample_safe_action(t)
        tau, used_bailout = run_real_trial(t, a, bailout=safe_env.bailout(t))
        if used_bailout:
            log_safety_event(t, a)
        stats[t].update(step_credit(tau, schema, theta)[0][t])
    return stats
```

### IP-126 RGL（Real-Gap Ladder）

```python
def choose_certificate_level(risk, stats, policy, ttl_ok):
    required = {'low': 1, 'medium': 2, 'high': 3}[risk]
    for level in (3, 2, 1, 0):
        if level <= required and ladder_satisfied(stats, level) and ttl_ok:
            return level
    return 'reject'
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SCS | O(n) / 轨迹 | O(n) | schema 外置、前缀门控可判定 |
| SGC | O(n + |𝔇_ρ|) | O(n) | 等级阈值单调、下界 sound |
| RMC | O(B·n) | O(n) | 置信序列覆盖、分层抽样 |
| SGA | O(n log n) | O(n) | 归因可复现、证据可追溯 |
| AST | O(B log n) | O(n + B) | 安全壳、关键度在线更新 |
| RGL | O(n) | O(n) | 风险映射给定、TTL 强制 |

**正确性定理（Step-Credited Real-Machine Soundness）**
假设 (A29) 步骤分解与外置 schema 一致且前缀门控可判定；(A30) 真机试验位于安全包络内，样本序列满足置信序列所需的（近似）鞅假设；(A31) 每个步骤的置信下界 `s_t^L` 以 `1-α_t` 覆盖真机信用。则对等级 ℓ 的证书，
```
P(∀t: s_t^real ≥ θ_t) ≥ 1 - Σ_{t∈V_ℓ} α_t
```
其中 `V_ℓ` 为该等级实际做真机验证的步骤集合。进而 `E[Score_real] ≥ Score^L`；等级越高，`V_ℓ` 越大、`Σα_t` 越小、认证越保守。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 步骤分被策略刷分（Goodhart） | 高 | 外置 schema + 对抗评分 + 留出分解 |
| 真机分布漂移使置信下界失效 | 高 | 变化点检测 + 证书 TTL + 重校准 |
| 真机测试越出安全包络 | 高 | 安全壳 + bailout + 人工监督 |
| 关键步误判导致预算错配 | 中 | 关键度在线重估 + 分层保险采样 |
| 仿真先验过强压制真机证据 | 中 | 先验衰减 + 分层贝叶斯 |
| 步骤分解粒度争议 | 中 | 多粒度 schema 交叉验证 |

## 6. 本轮最大风险

**一句话**：步骤分 + 真机评测把证书从二值推进到分级，但其 soundness **三重依赖步骤分解的可判定性、置信序列的同分布/鞅假设、以及真机测试的安全壳**；一旦步骤分被策略“刷分”（Goodhart）或真机分布漂移使置信下界失效，分级证书会系统性高估真实能力，故必须以 **外置步骤本体 + 变化点检测 + 安全壳回滚** 三重护栏，宁可降级认证，绝不把“高分低能”当作部署依据。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-RealCredit（SCS×SGC×RMC×SGA×AST×RGL）

> 承接第 54 轮产物 v31。本轮在动作-协同双证书体系之上，加入 **步骤信用、真机统计桥、关键步主动评测、真机证书阶梯** 四个维度：
> - **SCS（Step-Credit Schema）**：把长程任务分解为步骤信用向量 `s`，支持部分得分与前缀门控；
> - **SGC（Step-Graded Certificate）**：把联合证书 `J` 升级为分级证书 `J^g`，以瓶颈信用定级；
> - **RMC（Real-Machine Calibration）**：用置信序列把仿真学分换算为真机学分下界 `s^L`；
> - **SGA（Step-Gap Attribution）**：把仿真-真机差距归因到具体步骤，扩展 Explain 到步轴；
> - **AST（Active Step Testing）**：在真机预算与安全壳约束下，向关键步聚焦做序贯评测；
> - **RGL（Real-Gap Ladder）**：证书等级 ℓ0–ℓ3 与任务风险挂钩，形成可降级的认证阶梯。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115（动作剖面 → 动作-步骤双剖面）、IP-118（联合证书 → 分级联合证书）、IP-120（联合迁移证书 → 带真机差距的迁移证书）。

def active_real_testing(schema, sim_scores, budget, alpha, theta, safe_env):
    stats = init_confidence_sequences(schema, alpha)

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SCS | O(n) / 轨迹 | O(n) | schema 外置，门控可判定 |
| SGC | O(n + \|𝔇_ρ\|) | O(n) | 等级阈值单调，下界 sound |
| RMC | O(B·n) | O(n) | 置信序列覆盖 ≥ 1-α |
| SGA | O(n log n) | O(n) | 归因可复现、证据可追溯 |
| AST | O(B log n) | O(n+B) | 安全壳有效，关键度在线更新 |
| RGL | O(n) | O(n) | 风险映射给定，TTL 强制降级 |

**正确性定理（Step-Credited Real-Machine Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 步骤分解与外置 schema 一致，前缀门控可判定；**(A30)** 真机试验位于安全包络 `T_safe` 内，样本序列满足置信序列所需的（近似）鞅假设；**(A31)** 每步下界 `s_t^L` 以 `1-α_t` 覆盖真机信用。则等级 ℓ 证书满足
```
P(∀t: s_t^real ≥ θ_t) ≥ 1 - Σ_{t∈V_ℓ} α_t
```
且 `E[Score_real] ≥ Score^L = Σ_t w_t s_t^L`。等级越高，验证步集 `V_ℓ` 越大、`Σα_t` 越小、认证越保守；`ℓ3` 在全步验证下退化为经典全轨迹真机认证。

关键：**步骤信用外置可判定**、**真机下界覆盖真实**、**关键步预算化聚焦**、**证书可降级且会过期**。

## 5. 本轮最大风险

**一句话**：步骤分 + 真机评测将证书从二值推进到分级，但其 soundness **三重依赖步骤分解的可判定性、置信序列的同分布/鞅假设、以及真机测试的安全壳**；一旦步骤分被策略“刷分”（Goodhart）或真机分布漂移使置信下界失效，分级证书会系统性高估真实能力，故必须以 **外置步骤本体 + 变化点检测 + 安全壳回滚** 三重护栏，宁可降级认证，绝不把“高分低能”当作部署依据。
