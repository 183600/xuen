# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「面部表情识别」×「视觉语言模型」）

> R69 让机器人学会「问」，但它默认「问来的答案可读」。人类最直接的答案往往不在语言里，而在脸上。把「脸」当情绪标签读会同时犯三种错：
> - **语义错**：安全真正需要的不是「他是不是开心」，而是「我还能不能继续 / 他是否在忍耐 / 这个同意是否真实」——这是**许可谓词**，不是情绪类别；
> - **认识论错**：同一张脸在不同文化、角色、关系下没有唯一正确读法，只有**视角**；FER 的 ground truth 本身是复数；
> - **决策错**：R69 的「k 个正交源一致」是对称纪律，但许可与撤回的代价极不对称——**否决应当容易，许可应当困难**。
>
> VLM 能补语境（努力 vs 疼痛、礼貌微笑 vs 真心微笑），但它会谄媚、会幻觉、会被场景文字提示注入，不能进快环当裁判。
>
> 核心命题：**把表情从「情绪识别」改写为「许可谓词上的条件否决票」：用多视角 credal set 表达「谁在读这张脸」，用非对称证据门（veto 单源即可、grant 需校准下界 + 正交一致）做决策，用 VLM 慢系统只做语境解释与事后审计；情感通道只能收缩动作可行域，绝不扩张。** 命名 **PRISM-RAS**（Pluralistic Risk-relevant Interpretation of Social Multimodal evidence）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**就算能做到，我还被允许吗**」——脸不是情绪标签，是一张有条件的否决票。

## 0. 直觉与动机

**灵感 1（许可谓词 → 别识别情绪，识别「还能不能做」）**
直觉：FER 的七类情绪标签对控制几乎无用，而且伦理上危险（情绪监控）。安全真正依赖的是少数**动作相关谓词**：同意 / 撤回 / 不适 / 过载 / 疑似欺骗 / 不可观察。它们不是情绪的细化，而是**情绪 + 语境到许可的约化**。同一张「笑」在礼貌、紧张、开心三种解释下对「要不要继续靠近」的含义完全不同；但「他是否后仰、僵直、遮脸、语气与表情不一致」却直接改变可行域。谓词化同时降低标签歧义、降低隐私伤害、让安全论证只需覆盖少数谓词。

**灵感 2（视角而非真值 → 「谁在读这张脸」是一等公民）**
直觉：FER 没有单一 ground truth。文化 display rules、年龄、性别、医患/主从关系都会改变「正确」读法；标注者之间的一致性常低于模型置信度。VLM 恰好能实例化不同视角（不同文化/角色提示），但每个视角都可能是错的。于是不要输出一个后验，而输出一个 **credal set**：m 个视角各自给出谓词分布，取凸包；`P_low = min_a q_a`，`P_up = max_a q_a`。两者之差不是噪声，而是**解释分歧**——它本身就是一个可审计的安全量。

**灵感 3（非对称证据 → 否决容易，许可困难）**
直觉：把一个「其实在忍耐」的人当成同意，代价是伤害；把一个「其实同意」的人当成撤回，代价通常只是一次澄清交互。`c_G ≫ c_V`。由此 Bayes 阈值 `τ = c_V/(c_G+c_V)` 极小：**任何非平凡的不许可证据都应触发否决**，而许可需要「不许可概率的上界」几乎为零。这把 R69 的对称 k-一致纪律纠正为**单源否决、k 源许可**，并且给出了代价比的定量依据，而不是拍脑袋的保守。

**灵感 4（VLM 是慢系统 → 语境解释器 + 事后审计，而非实时裁判）**
直觉：VLM 的价值在「解释为什么这张脸可能是疼而不是用力」、生成反事实、给审计员看日志；它的风险在延迟、幻觉、谄媚、提示注入。把它放在**快环之外**：低频缓存语境假设，只用来调整视角权重与先验；再用 prompt-flip（改写/角色互换/否定/反事实）测谄媚，翻转率超阈值就把它的证据权重清零。于是 VLM 最坏只能造成「过度否决」，不能造成「不安全许可」。

**灵感 5（脸是攻击面，也是隐私面）**
直觉：表情可被策略性掩饰（社交微笑、文化性克制）、可被伪造（deepfake、屏幕回放、对抗妆容）、可被场景文字提示注入。更基本的是：**遮脸/转头本身就是撤回信号**——「看不见」不能被当成「同意」。所以需要证据有效性层（自发性、遮挡、伪造分、来源），并把「沉默/不可观察」硬编码为否决侧证据，而不是许可侧空白。

**灵感 6（严格包含 → 这是保守扩展，不是替代）**
直觉：情感通道默认关闭时，PRISM 必须逐指令等价于 R69；开启时，它只能从可行域里**删动作**，不能加动作。因此安全侧永不弱于 R69，代价是任务效率可能下降——本轮交换的不是成功率，而是**合法性（legitimacy）**：从「怎么做更安全」转向「这件事还该不该做」。这也意味着最大风险从「撞到人」变成「自以为获得了同意」。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（PRISM-RAS 总览）** PRISM-RAS = (ASP, PIP, PCL, AEG, CSM, PAV, MINT-A, VCA, SHA, VQAuditor-P, RAS-WM‡)。四不变式：
(i) **零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）；
(ii) **VETO 单调性**：任何情感证据 e 只能使可行动作集收缩，`𝒜_perm(o,e) ⊆ 𝒜_perm^{R69}(o)`；证据弃权时取等；
(iii) **非对称证据纪律**：否决可由单源/单帧/不可观察触发；许可必须同时满足「校准下界 ≥ 1−τ_V」与「≥2 个正交证据源一致」，且无否决；
(iv) **慢系统隔离**：VLM 不进入实时执行环，只更新缓存先验与审计。

**定义 311（风险相关许可谓词）** 情绪标签空间 ℰ_emo 与语境 C；许可谓词 `𝒫 = {p_consent, p_withdraw, p_discomfort, p_overload, p_deceive, p_occlude}`。约化映射 `ρ: Δ(ℰ_emo × C) → Δ(𝒫)` 由语境条件化。关键：`p_consent` 与 `p_withdraw` **不是补集**——二者可以同时低（未知），这正是「不确定」的语义位置。

**定义 312（许可偏序与可行域）** 对动作集 `𝒜_task` 上的许可关系 ≤：`a ≤ b` 表示 a 不比 b 更冒进。`𝒜_perm(o,e) ⊆ 𝒜_task` 是下集（down-set）。若 e ⊨ p_withdraw，则 `𝒜_perm = 𝒜_safe`（停/退/保持）；若 e 仅 ⊨ p_discomfort，则删除「接近/接触/加速」类动作。**consent 本身不新增动作**，只停止收缩；所有动作仍须过 R69 的 C-RAS-WM 认证。

**定义 313（视角集合与 credal set）** 视角集合 `A = {a_1,…,a_m}`（文化/角色/关系条件化的 VLM 提示，或不同训练分布的 FER 头）。每个视角给出 `q_a ∈ Δ(𝒫)`。credal set `Q = conv{q_a}`；对任意谓词子集 S，`P_low(S)=min_a q_a(S)`，`P_up(S)=max_a q_a(S)`；宽度 `W(S)=P_up−P_low` 表示解释分歧。

**定义 314（非对称许可判定）** 记 `p_¬ = P(¬permitted)`。
- **许可**：`P_up(p_¬) ≤ τ_V` 且 `P_low(p_consent) ≥ 1−τ_V` 且 `orthogonal_ok` 且无否决；
- **否决**：`P_up(p_withdraw ∨ p_discomfort ∨ p_occlude) ≥ τ_V`，或 PAV 判为遮挡/撤回；
- **其余**：UNCERTAIN → 只允许 𝒜_safe，并可触发 MINT-A 询问/观察。
其中 `orthogonal_ok` 要求显式语言、行为/轨迹、非语言三源中至少两源一致（定义 321）。

**定义 315（代价非对称与阈值）** 误许可代价 `c_G`（伤害/尊严侵犯），误否决代价 `c_V`（一次澄清/暂停），`c_G ≫ c_V`。二动作 Bayes 判定给出 `τ_V = c_V/(c_G+c_V)`；因 `c_V` 被一次 MINT-A 交互成本上界约束，`τ_V` 很小。于是**否决是低门槛的**（上界只要超过 τ_V），**许可是高门槛的**（不许可上界必须低于 τ_V）。

**定义 316（同意状态机 CSM）** 状态 `s ∈ {GRANTED, UNCERTAIN, WITHDRAWN}`。转移：
- 任意 → WITHDRAWN：单源否决证据；
- WITHDRAWN → UNCERTAIN：只能由显式再接触（口头确认 + 行为一致），表情单独不能解锁；
- UNCERTAIN → GRANTED：`P_low` 达标 + `orthogonal_ok` + 无否决；
- GRANTED → UNCERTAIN：OOD/语境切换/视角分歧 `W` 超阈。
带滞回 `τ_release > τ_V` 与锁存，防止单帧噪声抖振。

**定义 317（VLM 语境标注器 VCA）** `g_φ: (f,c,text) → {(h_i, w_i, span_i)}` 输出语境假设、权重、证据片段（如「重物搬运→用力而非疼痛」「社交场合→礼貌微笑」）及反事实。输出**低频缓存**（1–2Hz），只用于更新视角先验/权重，不直接产生动作。

**定义 318（视角校准层 PCL）** 按分层 `z`（文化/年龄段/光照/设备）做 split conformal 或 Clopper–Pearson 下界；层内覆盖率 ≥ 1−α。层外无校准 ⇒ `P_low:=0`（许可自动失败），但否决仍由未校准上界包络 + 硬规则触发。⇒ 分布偏移只降低**许可度**，不降低**安全性**（引理 23）。

**定义 319（情感证据有效性 PAV）** 有效性 `v = min(s_spont, 1−o_occ, 1−s_spoof)`：`s_spont` 由 AU 时序（起始/结束斜率、对称性、微表情）估计；`o_occ` 为遮挡；`s_spoof` 为回放/屏幕/deepfake 分。**非对称使用**：低 v 只折损许可，不折损否决（伪装的痛苦仍是暂停理由；策略性微笑不能作为许可）。

**定义 320（情感感知的增广信息动作 MINT-A）** `g_aff ∈ {g_view, g_ask, g_wait, g_display}`：换视角/补光看清、请求明确口头确认、等待表情稳定、机器人以自身表情/语言引出反应。`VoI_aff(g) = H(𝒫|o) − E_{y~p(·|g,o)}H(𝒫|o,y)`，收益减去物理/社交/隐私成本；候选须过 C-RAS-WM 认证。`VoI_aff ≤ cost` ⇒ 不交互，按 CSM 保守执行。

**定义 321（跨模态泄漏与一致性）** 显式回答 `v`、非语言 `b`（表情/姿态/语音）、行为 `τ`。不一致度 `κ = 1 − agree(v,b,τ)`。规则：`v=同意 ∧ κ` 高 ⇒ 阻断许可并标记 `p_deceive`；`v=拒绝` ⇒ 直接否决（单边）。这把 R69 的 ℰ_poison 从「人会撒谎」细化为「语言与身体可能不同步，后者更难伪装」。

**定义 322（反谄媚审计 SHA）** 对 VLM 做 prompt-flip：改写、角色互换、否定、反事实、误导性前缀；翻转率 `φ`。`φ > τ_φ` ⇒ 该视角证据权重归零，且 VLM 不得作为许可来源。另设 leading-prompt 检测：中性 vs 诱导提示下的分布差。

**定义 323（参与式同意审计 VQAuditor-P）** 审计：单源许可、忽略遮挡、提示诱导、文化分层不匹配、否决覆盖率（真不适是否被漏掉）。结论回灌 PCL/AuditBuf，成为下一轮阈值与视角权重的先验。

**定义 324（威胁模型 AIC-PRISM）** `ℰ_PRISM = ℰ_FLUID × ℰ_affect × ℰ_sem × ℰ_spoof × ℰ_privacy`：
- ℰ_affect：策略性掩饰、社交微笑、文化 display rules、夸大；
- ℰ_sem：VLM 谄媚/幻觉/刻板印象/场景文字提示注入；
- ℰ_spoof：deepfake、屏幕回放、打印人脸、对抗妆容；
- ℰ_privacy：原始人脸泄漏、重识别、超出谓词的情感画像。

**定义 325（证书 J_PRISM）** `J_PRISM = (J_FLUID, predicate_calibration_by_stratum, credal_width, veto_rate, false_grant_rate, grant_provenance_hash, vlm_audit_hash, privacy_budget, prism_ver)`。Valid ⇔ Valid(J_FLUID) ∧ 分层校准覆盖达标 ∧ 无未校准层被用于许可 ∧ VETO 单调性保持 ∧ 隐私预算未越界。

**定义 326（组合与两级退避）** 情感通道关闭 ⇒ 逐指令等价 R69。开启 ⇒ `λ_PRISM = max(λ_R69, λ_veto(s))`，`λ_veto(GRANTED)=0`、`λ_veto(UNCERTAIN)≥0.5`、`λ_veto(WITHDRAWN)=1.0`（或硬停）。`max` 保证只收紧不放松。PCL 失效 / SHA 判 VLM 不可信 / 隐私预算耗尽 ⇒ 自动 affect-off，回到 R69。

**定义 327（隐私与尊严约束）** 原始人脸不出传感器（on-device embedding only），零原始帧留存，目的限定为许可谓词而非情绪画像；遮挡/转头被尊重为撤回；提供物理 affect-off 与可审计的许可日志（哈希化）。

```python
# IP-265/313 PIP：多视角 credal set（共享 backbone，m 个轻量头）
class PluralisticInterpreter:
    def posteriors(self, face, ctx, stratum):
        q = {a: self.heads[a](self.backbone(face), ctx) for a in self.perspectives}
        return self.pcl.calibrate(q, stratum)      # 层内校准；层外 P_low=0

# IP-269/316 CSM：否决容易、许可困难的状态机
class ConsentStateMachine:
    def step(self, q, validity, ortho_ok):
        p_low_consent = min(q[a]["consent"] for a in q)
        p_up_block    = max(q[a]["withdraw"] + q[a]["discomfort"] for a in q)
        veto = p_up_block >= self.tau_V or validity.occluded or validity.spoof
        if veto:
            self.state = WITHDRAWN
        elif self.state == WITHDRAWN:
            # 表情单独不能解锁；需显式再接触 + 正交一致
            if ortho_ok and validity.explicit_regrant:
                self.state = UNCERTAIN
        elif p_low_consent >= 1 - self.tau_V and ortho_ok:
            self.state = GRANTED
        elif self.state == GRANTED and (validity.ood or self.credal_width > self.tau_w):
            self.state = UNCERTAIN
        return self.state

# IP-276 主闭环：只在 R69 的可行域上做减法
def PRISM_round(M, obs, human):
    # 1) R69 前端原样执行：不确定性与安全基线不降级
    z, o = M.mtm.forward(...)
    c, U_cal, thr = M.cof.step(...)
    U_ale, U_epi, modes = M.aud.decompose(...)
    base_lam = M.efs.risk_scale(...)               # R69 的 lambda
    # 2) 快路径情感证据（per-perspective，<1ms）
    q  = M.pip.posteriors(human.face, M.vca.cached_ctx, human.stratum)
    pv = M.pav.validity(human)                     # 自发性/遮挡/伪造
    if pv.affect_off or not M.pcl.trusted(human.stratum):
        return M.r69_round(M, obs)                 # affect-off ⇒ 逐指令 R69
    # 3) 非对称门 + 同意状态机
    state = M.csm.step(q, pv, M.cia.orthogonal_ok(human))
    # 4) 不确定且值得问 → 情感 VoI 交互（看/问/等/表达）
    if state == UNCERTAIN and M.mint_a.voi(q, obs) > M.mint_a.cost(obs):
        M.cia.execute_affect(M.mint_a.choose(q, obs))
        return M.safe_hold()                       # 未定案不执行冒进动作
    # 5) 只收紧：max(R69, lambda_veto)
    lam = max(base_lam, M.lambda_veto(state))
    A = M.ach.propose(...)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if state == WITHDRAWN:
        k = min(k, M.safe_prefix(...))             # 硬停/退避
    # 6) 异步审计（VLM 只在这里出现）
    M.vqa_p.submit_async(state, q, M.vca.cached_ctx, M.sha.flip_rate)
    return k, lam, state

def lambda_veto(state):
    return {GRANTED: 0.0, UNCERTAIN: 0.5, WITHDRAWN: 1.0}[state]
```

## 3. 推导

**引理 19（VETO 单调 ⇒ 安全支配）** 若对任意情感证据 e 有 `𝒜_perm(o,e) ⊆ 𝒜_perm^{R69}(o)`，则 PRISM 的任意可行策略也是 R69 的可行策略，故最坏情形风险 `≤` R69；当 e 弃权（`P_low=0`、无否决、`λ_veto=0`）时取等。系：情感层不是新的安全假设，而是对 R69 可行域的**单调收缩**。

**引理 20（非对称证据的 Bayes 阈值）** 令 `p=P(¬permitted)`，误许可代价 `c_G`、误否决代价 `c_V`。许可损失 `c_G p`，否决损失 `c_V(1−p)`；许可当且仅当 `p ≤ c_V/(c_G+c_V)=τ_V`。因 `c_V ≪ c_G`，`τ_V≈0`：**否决只需上界越过一个很小的正数；许可要求上界几乎为零**。若加入成本 `c_I` 的澄清动作，中间带 `(τ_V, 1−τ_V)` 由 MINT-A 接管，且 `c_I` 给 `c_V` 提供了上界 ⇒ 非对称不是保守偏见，而是代价最优。

**引理 21（校准下界的分布无关覆盖）** 层内可交换下，split conformal/Clopper–Pearson 下界 `L` 满足 `P(p_consent ≥ L) ≥ 1−α`。以 `L ≥ 1−τ_V` 作为许可条件，则误许可率 `≤ α + τ_V`。层外无校准 ⇒ `L=0`，许可自动失败。

**引理 22（遮挡即否决；沉默不是同意）** 若人脸不可观察，则 `P_low(p_consent):=0`（无法支持许可），同时 `P_up(p_withdraw):=1`（未知按可能撤回处理）。故「看不见」既不能许可，也不会被当成空白；只能进入 𝒜_safe 或触发询问。系：把「未观察到反对」与「观察不到」严格区分。

**引理 23（视角偏移的失效方向）** 测试视角落在校准分层之外时，许可下界退化为 0（丧失许可能力），但否决仍由未校准上界包络与硬遮挡/伪造规则触发。故分布偏移的代价是**过度限制**而非**不安全许可**；过度限制本身在辅助场景可能有害，必须由显式口头再接触与 MINT-A 兜底，而不能用降低否决门槛来换效率。

**定理 18（PRISM 严格包含 R69，且安全不弱）** 情感通道关闭 ⇒ 逐指令等价 R69；开启 ⇒ 可行域单调收缩（引理 19），`λ_PRISM = max(λ_R69, λ_veto) ≥ λ_R69`。因此安全侧不做任何让步，效率侧可能下降；本轮收益是**许可合规与可审计性**，不是任务成功率。R69 的 resolution bonus 仅保留给非情感歧义。

**定理 19（CSM 稳定性与无抖振）** 带滞回 `τ_release > τ_V` 与锁存的状态机，在单帧证据有界噪声下不会在 GRANTED/WITHDRAWN 间抖振；撤回延迟 ≤ 一帧 FER 延迟；重新许可至少需要一次显式再接触 + k=2 正交一致，故单帧噪声不能解锁。系：否决快、解锁慢，方向与代价非对称一致。

**定理 20（VLM 隔离 ⇒ 谄媚/幻觉不产生不安全许可）** VLM 只经 VCA 更新缓存先验/视角权重，且 SHA 在 `φ>τ_φ` 时将其权重置零；许可仍必须通过 PCL 校准下界 + 正交一致。故无论 VLM 如何谄媚/幻觉/被注入，误许可率仍由 PCL 界约束；VLM 的最坏影响是**过度否决**（安全方向）。这把「VLM 不可信」从致命缺陷降级为效率损失。

```python
def posteriors(face, ctx, stratum, heads, pcl):
    q = {a: heads[a](backbone(face), ctx) for a in heads}
    return pcl.calibrate(q, stratum)               # 层外 P_low=0

# IP-269 CSM：否决容易、许可困难
def csm_step(state, q, pv, ortho_ok, tau_V, tau_w):
    p_low = min(q[a]["consent"] for a in q)
    p_up  = max(q[a]["withdraw"] + q[a]["discomfort"] for a in q)
    if p_up >= tau_V or pv.occluded or pv.spoof:
        return WITHDRAWN
    if state == WITHDRAWN:

        return GRANTED
    if state == GRANTED and (pv.ood or credal_width(q) > tau_w):
        return UNCERTAIN
    return state
```

## 4. 推导

**引理 19（VETO 单调 ⇒ 安全支配）** 若对任意 e 有 `𝒜_perm(o,e) ⊆ 𝒜_perm^{R69}(o)`，则 PRISM 的任意可行策略也是 R69 的可行策略，最坏情形风险 ≤ R69；e 弃权时取等。情感层是对 R69 可行域的单调收缩，不是新的安全假设。

**引理 20（非对称 Bayes 阈值）** `p=P(¬permitted)`；许可损失 `c_G p`，否决损失 `c_V(1−p)`；许可 iff `p ≤ τ_V=c_V/(c_G+c_V)`。`c_G≫c_V ⇒ τ_V≈0`：否决只需上界越过极小正数，许可要求上界几乎为零。中间带 `(τ_V,1−τ_V)` 由成本 `c_I` 的 MINT-A 接管；`c_I` 给 `c_V` 上界，故非对称是代价最优而非偏见。

**引理 21（校准下界覆盖）** 层内可交换下，conformal/Clopper–Pearson 下界 `L` 满足 `P(p_consent≥L)≥1−α`；以 `L≥1−τ_V` 许可，误许可 ≤ `α+τ_V`；层外 `L=0`，许可自动失败。

**引理 22（遮挡即否决；沉默不是同意）** 人脸不可观察时 `P_low(consent):=0` 且 `P_up(withdraw):=1`；「看不见」既不能许可也不被当作空白，只能进 `𝒜_safe` 或触发询问。

**引理 23（视角偏移的失效方向）** 层外视角使许可下界退化为 0（丧失许可），否决仍由未校准上界包络 + 硬规则触发；故偏移的代价是过度限制而非不安全许可。过度限制在辅助场景可能有害，须由显式再接触与 MINT-A 兜底，不得以降否决门槛换效率。

**定理 18（PRISM 严格包含 R69 且安全不弱）** affect-off ⇒ 逐指令等价 R69；affect-on ⇒ 可行域单调收缩（引理 19），`λ_PRISM=max(λ_R69,λ_veto)≥λ_R69`。安全侧不让步，效率可下降；本轮收益是许可合规与可审计性，不是成功率。R69 的 resolution bonus 仅保留给非情感歧义。

**定理 19（CSM 稳定无抖振）** 滞回 `τ_release>τ_V` + 锁存下，单帧有界噪声不会在 G/W 间抖振；撤回延迟 ≤ 一帧 FER；重新许可至少需一次显式再接触 + k=2 正交一致，单帧噪声不能解锁。

**定理 20（VLM 隔离 ⇒ 谄媚/幻觉不产生不安全许可）** VLM 只经 VCA 更新缓存先验/视角权重，SHA 在 `φ>τ_φ` 时权重置零；许可仍须 PCL 校准下界 + 正交一致。故误许可率由 PCL 界约束，VLM 最坏只造成过度否决（安全方向）——「VLM 不可信」从致命缺陷降级为效率损失。

## 7. 本轮最大风险

**次级风险与缓解**：过度否决伤及辅助场景（显式再接触 + MINT-A + E313，且不降否决门槛换效率）；VLM 谄媚/注入（慢系统隔离 + SHA + 定理 20）；文化/视角错配（PCL 分层 + 层外禁许可 + E308）；伪造/回放（PAV + E307）；隐私与情绪监控滑坡（谓词化 + on-device + 零留存 + affect-off）。

**一句话**：PRISM 的安全性完全押在「否决通道的覆盖率」而非精度上——若 FER 对真正的痛苦/撤回存在系统性盲区（冻结反应、掩饰性恐惧、神经多样性表达、跨文化克制、遮挡），系统就会把「没看见反对」当成「同意」，产出一张**没有合法性的合法性证书**；这比诚实地说「我读不懂脸」更危险。
