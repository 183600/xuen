# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「跨物体泛化」×「模型蒸馏」）

> 第 54 轮已把技能从能力匹配推进到动作-鲁棒性双证书（`α_S`, `J=(ρ,A_cert,γ_ce,δ_a)`, `Explain`）。本轮引入 **跨物体泛化（cross-object generalization）** 与 **模型蒸馏（model distillation）**：泛化不再是在物体集合 `O` 上 IID 不掉点，而是 **物体空间 `(O,d_O)` 上的覆盖证书**；蒸馏不再是云端教师到边端学生的逐点输出匹配，而是 **值-敏感度-证书三级蒸馏**。核心矛盾：H22：蒸馏损失在训练物体上趋零，但学生对物体潜变量的敏感度（Jacobian）可任意错配，产生「蒸馏泛化幻觉」；H23：边端容量有限，存在 **容量诱发的泛化下限**，且教师的接触不连续区不可被平滑学生忠实蒸馏；H24：策略蒸馏成功不等于证书蒸馏安全，守卫需要 **单边（只拒不放错）** 保证。

## 0. 直觉与动机

**灵感 1（跨物体泛化 = 物体空间覆盖，而非 IID 均值）**
直觉：`O` 上平均成功率高，不代表最近邻物体都安全。可证的泛化应是：给定参考物体集 `O_ref`、物体度量 `d_O`，每个目标物体 `o'` 都落在某个 `o∈O_ref` 的半径 `r_O` 内，且学生在这段位移上的误差增量被 `L_S·r_O` 控制。泛化证书应签发 **覆盖半径**，而不是一个标量精度。这样「跨物体」被还原为「物体空间上的 Lipschitz 传输 + 覆盖完备」，与第 53/54 轮的鲁棒性谱、动作剖面在同一证书语言下拼接。

**灵感 2（模型蒸馏 = 值、敏感度、证书三级匹配）**
直觉：逐点 KD 只匹配 `π_S(o)≈π_T(o)`；跨物体泛化要求匹配 **一阶信息** `∂π_S/∂z ≈ ∂π_T/∂z`（物体敏感度），否则物体之间的插值区无人看管；更进一步，安全边界（接受/拒绝）也要蒸馏，且只能是 **单边** 的——学生可以更保守，但不能在教师拒绝时接受。三级蒸馏分别对应「像不像」「怎么变」「敢不敢放」，缺一层就会在某类新物体上失效。

**灵感 3（蒸馏泛化幻觉：零训练损失 ≠ 可泛化）**
直觉：一维反例。教师 `π_T(z)=z`，训练物体 `z∈{0,1}`。学生 `π_S(z)=z + A·sin(2πz)` 在 `z=0,1` 与教师完全一致，逐点蒸馏损失为 0；但 `π_S'(0)=1+2πA`，敏感度可任意大，在 `z=1/2` 处误差可达 `A`。**逐点蒸馏对物体-Lipschitz 没有任何约束**，所以「训练物体上 loss=0」不能推出覆盖半径内安全。这不是优化不充分，而是目标函数本身缺了导数项。

**灵感 4（容量诱发泛化下限）**
直觉：边端学生假设类 `H_C` 的容量（度量熵）有限，存在近似误差 `ε_app(C)=inf_{h∈H_C} sup_o ℓ(h,π_T(·|o))`。当教师策略所需的物体条件信息超过 `C` 时，任何蒸馏都留下不可消除的误差地板。泛化不只靠更多数据，还受 **边端容量预算** 限制；据此应做 **按物体区域的自适应云边分工**：高复杂度区域留在云端查询，低复杂度区域下沉边端，而不是全局压成一个小模型。

**灵感 5（单边证书蒸馏 → conformal 安全守卫）**
直觉：与其先蒸馏策略再补一个经验阈值，不如直接蒸馏 **教师证书的拒绝边界**。用分割 conformal 在目标物体分布上校准学生守卫 `G_S` 的分数阈值，使「教师拒绝而学生接受」的单边错误率 `≤α`。这给的是分布无关、有限样本的安全保证；代价是学生保守、覆盖率下降——但安全方向必须单边，宁可少放行，不可错放行。

**灵感 6（云边协同蒸馏闭环）**
直觉：边端失败不只是回传 `Explain`，还把失败物体 `o` 与动作 `a` 加入云端教师的 **物体条件校准集**；云端重训/加权，再蒸馏回边端。用 **最大分歧物体主动查询** 驱动 `r_O` 收缩，每轮至少收缩 `Δ`，形成 `覆盖收缩 - 重蒸馏 - 重校准` 闭环。这把第 54 轮的 `Explain_loop` 从「动作重剖分」扩展为「物体重覆盖」。

## 1. 形式化定义（增量：定义 121–129）

**定义 121（物体条件技能族）**
物体 `o∈O` 经编码器 `z=φ(o)∈Z`。技能 `S` 的实现是物体条件策略 `π_S(·|z(o))`。物体度量
```
d_O(o,o') = w_g·d_geo(G(o),G(o')) + w_p·||Prop(o)-Prop(o')||_1 + w_v·d_vis(V(o),V(o'))
```
归一化到 `[0,1]`，`Prop` 含质量/摩擦/可变形，`G` 为几何、`V` 为外观。`d_O` 是后续所有覆盖与泛化陈述的度量基础。

**定义 122（物体覆盖半径）**
对参考物体集 `O_ref` 与目标分布 `μ`，
```
r_O(O_ref,μ) = sup_{o'~μ} min_{o∈O_ref} d_O(o,o')
```
经验估计 `r̂_O` 用 `O_ref` 到 `μ` 采样点的最近邻距离上确界；高维时 `r_O = Θ(N^{-1/d_O})`，故必须报告内在维度或接受保守半径。

**定义 123（跨物体泛化差距）**
```
Gen_S(o') = E_{s~ν(·|o')} ℓ( π_S(·|z(o')), π* )
```
`ℓ∈[0,1]`。证书不直接估 `Gen_S(o')`，而是给其上界（见定理 CODS）。

**定义 124（三级蒸馏差异）**
```
D_val  = sup_{o∈O_ref} D( π_S(·|z(o)), π_T(·|z(o)) )
D_sens = sup_{o∈O_ref} || ∂_z π_S(·|z(o)) - ∂_z π_T(·|z(o)) ||
D_act  = sup_{o∈O_ref} Hausdorff( supp α_S(·|o), supp α_T(·|o) )
```
分别约束「值」「敏感度」「动作支撑」。`D_distill=(D_val,D_sens,D_act)`。

**定义 125（蒸馏泛化证书 DGC）**
```
J_gen = ( z, d_O, r_O, L_S, L_D, D_val, D_sens, D_act, C_e, ε_app, evidence )
```
其中 `L_S` 为学生损失对物体的 Lipschitz 常数，`L_D` 为蒸馏差异对物体的 Lipschitz 常数（用 `D_sens` 保守估计），`C_e` 为边端容量、`ε_app` 为近似地板。当
```
D_val + (L_S + L_D)·r_O + ε_app(C_e) ≤ ε_succ  ∧  D_act ≤ θ_act
```
时签发，`evidence` 至少含最近邻见证、敏感度探针、容量审计与跨物体反例。

**定义 126（容量预算与泛化下限）**
学生假设类 `H_C` 满足 `log N(ε,H_C) ≤ C`（度量熵）。容量地板
```
ε_app(C) = inf_{h∈H_C} sup_{o∈O} ℓ( h(·|z(o)), π_T(·|z(o)) )
```
关于 `C` 单调不增。若 `ε_app(C) > ε_succ`，则对该物体区域 **任何蒸馏都不可达**，必须走云端查询或拒绝部署。

**定义 127（单边证书守卫与 conformal 阈值）**
守卫 `G_S:(o,s)→{accept,reject}`。假接受事件 `FA={G_S=accept, J_T=reject}`。在目标分布校准集 `O_cal` 上取教师拒绝样本的分数 `{score_S(o)}`，令 `τ = Quantile_{1-α}`，`G_S=accept ⇔ score_S>τ`。在可交换性（或加权 conformal）下
```
P(FA) ≤ α + 1/(|O_cal|+1)
```
学生只被允许更保守；覆盖率 `Cov=P(accept | J_T=accept)` 作为第二指标报告。

**定义 128（云边协同蒸馏契约）**
```
C_cd = (T_c, S_e, O_query, Δr, τ_loop, Explain)
```
`O_query` 由最大分歧 `argmax_{o~μ} D(π_T,π_S|o)` 选出；每轮要求 `r_O^{(k+1)} ≤ r_O^{(k)} - Δr`，`Explain` 回传把失败定位到物体维度（质量/摩擦/几何）而非仅动作维度。

**定义 129（跨物体蒸馏组合证书）**
技能序列 `⟨S_1,…,S_k⟩` 在物体覆盖 `O_ref` 上组合可行，当且仅当
```
∀o∈O_ref: ∀(S_i,S_j): W2(end(S_i|o), start(S_j|o)) ≤ θ_handoff
           ∧ J_gen(S_i) 可签发 ∧ D_act(S_i) ≤ θ_act
```
组合证书 `J_comp^O = (O_ref, r_O, {J_gen(S_i)}, handoff_cert, evidence)`；它在 `μ` 上的泛化由 `r_O` 与各 `J_gen` 的 `(L_S+L_D)` 联合承担。

## 2. 关键算法 伪代码

### IP-121 OCR（Object Coverage Radius）

```python
def object_cover(O_ref, mu_samples, d_O, intrinsic_dim=None):
    r, witness = 0.0, {}
    for o in mu_samples:
        o_nn = min(O_ref, key=lambda q: d_O(o, q))
        dist = d_O(o, o_nn)
        witness[o] = (o_nn, dist)
        r = max(r, dist)
    # 高维时同时报告内在维度，避免把 N^{-1/d} 的缓慢收缩误读为“覆盖已足够”
    return r, witness, intrinsic_dim
```

### IP-122 SDR（Sensitivity-aware Distillation）

```python
def distill_sensitivity(T, S, O_ref, lam_val=1.0, lam_sens=1.0, lam_act=0.5):
    for o in O_ref:
        z = T.z(o)
        loss_val  = divergence(S.policy(z), T.policy(z))
        loss_sens = mse(jacobian(S.policy, z), jacobian(T.policy, z))
        loss_act  = hausdorff(S.action_support(z), T.action_support(z))
        S.step(lam_val*loss_val + lam_sens*loss_sens + lam_act*loss_act)
    return S
```

### IP-123 DGC（Distillation Generalization Certificate）

```python
def generalization_cert(T, S, O_ref, mu_samples, eps_succ, theta_act):
    r, wit, _ = object_cover(O_ref, mu_samples, d_O)
    D_val  = max(divergence(S.policy(T.z(o)), T.policy(T.z(o))) for o in O_ref)
    D_sens = estimate_sensitivity_gap(T, S, O_ref)
    D_act  = max(hausdorff(S.action_support(T.z(o)),
                           T.action_support(T.z(o))) for o in O_ref)
    L_S = student_loss_lipschitz(S, O_ref, d_O)
    L_D = D_sens                      # 保守：用敏感度上界代替差异的 Lipschitz 常数
    eps_app = capacity_floor(S.hypothesis_class, T, eps=eps_succ)
    gap = D_val + (L_S + L_D)*r + eps_app
    ok = (gap <= eps_succ) and (D_act <= theta_act)
    return ok, J_gen(T.z, d_O, r, L_S, L_D, D_val, D_sens,
                     D_act, S.capacity, eps_app, witness=wit, gap=gap)
```

### IP-124 CCD（Conformal Certificate Distillation）

```python
def calibrate_guard(S, O_cal, T_cert, alpha):
    reject_scores = [S.success_score(o) for o in O_cal if T_cert(o) == 'reject']
    tau = quantile(reject_scores, 1 - alpha)      # 教师拒绝样本的高分尾部被切掉
    def G_S(o):
        return 'accept' if S.success_score(o) > tau else 'reject'
    coverage = mean(G_S(o) == 'accept' for o in O_cal if T_cert(o) == 'accept')
    return G_S, tau, coverage
```

### IP-125 OIB（Object Information Budget / 自适应云边分工）

```python
def capacity_aware_split(T, regions, C_edge, eps_succ):
    assignment = {}
    for reg in regions:
        need = teacher_complexity(T, reg)      # 区域内所需容量（敏感度/模态数代理）
        if need <= C_edge and capacity_floor(T, reg) <= eps_succ:
            assignment[reg] = 'edge'
        else:
            assignment[reg] = 'cloud_query'    # 保留云端教师，边端只发查询
    return assignment
```

### IP-126 CECD（Cloud-Edge Co-Distillation）

```python
def co_distill_loop(T, S, O_ref, mu_sampler, alpha, budget=8, Delta=0.02):
    r, _, _ = object_cover(O_ref, mu_sampler(), d_O)
    for k in range(budget):
        o_star = max(mu_sampler(), key=lambda o: disagreement(T, S, o))
        T.update(o_star, T.query(o_star))       # 云端增量重训/加权
        O_ref.add(o_star)
        S = distill_sensitivity(T, S, O_ref)
        r_new, _, _ = object_cover(O_ref, mu_sampler(), d_O)
        if r_new > r - Delta:                    # 覆盖未按预算收缩 → 触发更大半径的主动采样
            O_ref |= farthest_point_sample(mu_sampler(), k=2)
        r = r_new
        G_S, tau, cov = calibrate_guard(S, O_ref, T.cert, alpha)
    return S, G_S, r, cov
```

### IP-127 OGDC（Object-Generalization Distillation Composition）

```python
def compose_cross_object(skill_seq, O_ref, mu_samples, theta_handoff, eps_succ):
    certs = []
    for s in skill_seq:
        ok, cert = generalization_cert(s.T, s.S, O_ref, mu_samples, eps_succ, theta_act)
        if not ok:
            return ('reject', 'dgc_fail', s.id, cert)
        certs.append(cert)
    for o in nearest_cover_points(O_ref, mu_samples):
        for si, sj in pairs(skill_seq):
            if wasserstein2(end_dist(si, o), start_dist(sj, o)) > theta_handoff:
                return ('reject', 'handoff_mismatch', si.id, sj.id, o)
    return ('ok', J_comp_O(O_ref, max(c.r_O for c in certs), certs, handoff_cert=True))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| OCR | O(|O_ref|·|μ|·|O|) | O(|μ|) | `d_O` 有效、最近邻见证完备 |
| SDR | O(|O_ref|·(|Z|+|A|·|Z|)) | O(|Z|·|A|) | Jacobian 可估、敏感度不饱和 |
| DGC | O(|O_ref|·|A| + |μ|·|O_ref|) | O(|O_ref|·|A|) | `L_S,L_D` 保守、容量地板可算 |
| CCD | O(|O_cal|·|A| + |O_cal| log|O_cal|) | O(|O_cal|) | 可交换性/加权 conformal |
| OIB | O(|regions|·|O|·|A|) | O(|regions|) | 复杂度代理单调、地板可信 |
| CECD | O(budget·(Q+|O_ref|·|A|)) | O(|O_ref|·|A|) | 主动查询分歧下降、Δ 可达 |
| OGDC | O(k·|O_ref|·|A| + k²·|O_ref|) | O(k·|O_ref|) | 覆盖上逐物体 handoff 成立 |

**正确性定理（Cross-Object Distillation Soundness, CODS）**
假设第 54 轮 `(A22)–(A28)` 成立；**(A29)** `ℓ` 有界于 `[0,1]`；**(A30)** `d_O` 满足三角不等式，且 `∀o'∈supp μ, ∃o∈O_ref: d_O(o,o')≤r_O`；**(A31)** 学生损失对物体 `L_S`-Lipschitz，蒸馏差异对物体 `L_D`-Lipschitz 且 `L_D≤D_sens`；**(A32)** `sup_{O_ref} D_val ≤ ε_val`、`D_act≤θ_act`；**(A33)** 学生容量 `C_e` 的近似地板为 `ε_app(C_e)`；**(A34)** 校准集与目标物体可交换（或已做加权 conformal）。则对任意 `o'∈supp μ`：
```
Gen_S(o') ≤ sup_{o∈O_ref}[ ℓ_T(o) + D_val(o) ] + (L_S + L_D)·r_O + ε_app(C_e)
```
且守卫单边错误
```
P(FA) ≤ α + 1/(|O_cal|+1)
```
与第 53/54 轮联立得到部署成功下界：
```
P_success(o') ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
                 - [ sup_{O_ref}(ℓ_T + D_val) + (L_S+L_D)r_O + ε_app(C_e) ] - α
```
**推导要点**：取 `o'` 的最近覆盖点 `o`，用 `d_O` 三角不等式与损失 Lipschitz 得 `Gen_S(o')≤ℓ_S(o)+L_S·r_O`；再用 `ℓ_S(o)≤ℓ_T(o)+D_val(o)` 与 `D_val(o')≤D_val(o)+L_D·r_O` 合并，最后加入容量近似项。关键不是等式，而是每一项都有独立可测的见证：`r_O`（覆盖）、`D_val/D_sens`（蒸馏）、`ε_app`（容量）、`α`（守卫）。

## 6. 本轮最大风险

## 2. 关键算法 伪代码

### IP-121 OCR

```python
def object_cover(O_ref, mu_samples, d_O, intrinsic_dim=None):
    r, witness = 0.0, {}
    for o in mu_samples:
        o_nn = min(O_ref, key=lambda q: d_O(o, q))
        dist = d_O(o, o_nn)
        witness[o] = (o_nn, dist)
        r = max(r, dist)
    return r, witness, intrinsic_dim   # 同时报告内在维度，防止高维覆盖半径被误读
```

### IP-122 SDR

```python
def distill_sensitivity(T, S, O_ref, lam_val=1.0, lam_sens=1.0, lam_act=0.5):
    for o in O_ref:
        z = T.z(o)
        loss_val  = divergence(S.policy(z), T.policy(z))
        loss_sens = mse(jacobian(S.policy, z), jacobian(T.policy, z))
        loss_act  = hausdorff(S.action_support(z), T.action_support(z))
        S.step(lam_val*loss_val + lam_sens*loss_sens + lam_act*loss_act)
    return S
```

### IP-123 DGC

```python
def generalization_cert(T, S, O_ref, mu_samples, eps_succ, theta_act):
    r, wit, _ = object_cover(O_ref, mu_samples, d_O)
    D_val  = max(divergence(S.policy(T.z(o)), T.policy(T.z(o))) for o in O_ref)
    D_sens = estimate_sensitivity_gap(T, S, O_ref)
    D_act  = max(hausdorff(S.action_support(T.z(o)),
                           T.action_support(T.z(o))) for o in O_ref)
    L_S = student_loss_lipschitz(S, O_ref, d_O)
    L_D = D_sens
    eps_app = capacity_floor(S.hypothesis_class, T, eps=eps_succ)
    gap = D_val + (L_S + L_D)*r + eps_app
    ok = (gap <= eps_succ) and (D_act <= theta_act)
    return ok, J_gen(T.z, d_O, r, L_S, L_D, D_val, D_sens,
                     D_act, S.capacity, eps_app, witness=wit, gap=gap)
```

### IP-124 CCD

```python
def calibrate_guard(S, O_cal, T_cert, alpha):
    reject_scores = [S.success_score(o) for o in O_cal if T_cert(o) == 'reject']
    tau = quantile(reject_scores, 1 - alpha)
    def G_S(o):
        return 'accept' if S.success_score(o) > tau else 'reject'
    coverage = mean(G_S(o) == 'accept' for o in O_cal if T_cert(o) == 'accept')
    return G_S, tau, coverage
```

### IP-126 CECD

```python
def co_distill_loop(T, S, O_ref, mu_sampler, alpha, budget=8, Delta=0.02):
    r, _, _ = object_cover(O_ref, mu_sampler(), d_O)
    for k in range(budget):
        o_star = max(mu_sampler(), key=lambda o: disagreement(T, S, o))
        T.update(o_star, T.query(o_star))
        O_ref.add(o_star)
        S = distill_sensitivity(T, S, O_ref)
        r_new, _, _ = object_cover(O_ref, mu_sampler(), d_O)
        if r_new > r - Delta:
            O_ref |= farthest_point_sample(mu_sampler(), k=2)
        r = r_new
        G_S, tau, cov = calibrate_guard(S, O_ref, T.cert, alpha)
    return S, G_S, r, cov
```

### IP-127 OGDC

```python
def compose_cross_object(skill_seq, O_ref, mu_samples, theta_handoff, eps_succ):
    certs = []
    for s in skill_seq:
        ok, cert = generalization_cert(s.T, s.S, O_ref, mu_samples, eps_succ, theta_act)
        if not ok:
            return ('reject', 'dgc_fail', s.id, cert)
        certs.append(cert)
    for o in nearest_cover_points(O_ref, mu_samples):
        for si, sj in pairs(skill_seq):
            if wasserstein2(end_dist(si, o), start_dist(sj, o)) > theta_handoff:
                return ('reject', 'handoff_mismatch', si.id, sj.id, o)
    return ('ok', J_comp_O(O_ref, max(c.r_O for c in certs), certs, handoff_cert=True))
```

**正确性定理（Cross-Object Distillation Soundness, CODS）**
假设第 54 轮 `(A22)–(A28)` 成立；**(A29)** `ℓ∈[0,1]`；**(A30)** `d_O` 满足三角不等式且 `∀o'∈supp μ, ∃o∈O_ref: d_O(o,o')≤r_O`；**(A31)** 学生损失 `L_S`-Lipschitz、蒸馏差异 `L_D`-Lipschitz 且 `L_D≤D_sens`；**(A32)** `sup_{O_ref} D_val ≤ ε_val`、`D_act≤θ_act`；**(A33)** 容量地板 `ε_app(C_e)`；**(A34)** 校准集与目标物体可交换（或已加权 conformal）。则
```
Gen_S(o') ≤ sup_{o∈O_ref}[ ℓ_T(o) + D_val(o) ] + (L_S + L_D)·r_O + ε_app(C_e)
P(FA) ≤ α + 1/(|O_cal|+1)
```
联立第 53/54 轮得部署成功下界：
```
P_success(o') ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
                 - [ sup_{O_ref}(ℓ_T + D_val) + (L_S+L_D)r_O + ε_app(C_e) ] - α
```
关键：**覆盖半径可证**、**蒸馏敏感度可测**、**容量地板可审计**、**守卫单边可校准**。四项各自可独立证伪，避免把「教师会」直接当成「学生会」。
