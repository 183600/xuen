# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「推理延迟」×「安全性」）

> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> **本轮纪律**：**延迟即安全变量 + 任意时刻证书 + 关键路径隔离**。两个灵感合治 v9 的三处软肋：其一，v9 把延迟藏在 Ŵ_m 与「50Hz 保持」里，当成性能指标而非安全变量；其二，v9 的块证书以「推理在作动前完成」为前提，一旦延迟越过预算，证书描述的是过去的世界；其三，v9 的降级是「超时后反应」，而安全需要「越界前预判」。铁律：任一新组件失效 ⇒ 延迟退化为静态 WCET、证书退化为 v9 完整块证书、执行退化为共享线程，严格逐位等价退回 v9 ACMD，而非行为漂移。

## 0. 直觉与动机

**灵感 1（推理延迟 → 延迟是一等安全资源，而非吞吐指标）**
直觉：v9 把 50Hz 当作硬约束，把推理延迟当作「只要 ≤20ms 就不算事」。但同一个动作，早 10ms 给出和晚 10ms 给出，对刹车距离的意义完全不同——**快而错与对而晚，在物理上都是不安全**。延迟真正决定的是「作动时刻的世界有多陈旧」。因此第一步是把延迟从工程指标提升为可观测的安全状态：为每个模块学一个**条件延迟尾部分布** L_m^α(x)（在线保形预测 + 极值尾拟合），再把端到端关键路径延迟 L_e2e^α 与当前动力学**可容忍反应时间** τ_react(s_t) 相比，得到每周期的「延迟安全包络」Δ_L(t)=L_e2e^α+τ_detect−τ_react。核心创新：**延迟预言机（LatencyPrognosticator, LP）**。它把「安全」变成两个时间的比较，而不是两个平均值的比较。

**灵感 2（安全性 → 任意时刻证书：把中断变成安全操作）**
直觉：一个「仅在按时算完时才有效」的证书，在延迟不确定的世界里不是证书。正确的设计是让证书随计算推进**单调变强**：任意时刻被打断，都只派发「已证前缀」上的动作，未证部分一律不执行。这样**降低延迟只能缩短时域，绝不会悄悄让安全失效**——中断从故障变成合法的降级操作。核心创新：**任意时刻安全证书（AnytimeSafetyCertifier, ASC）**：证书格 (𝒞,⊑)、派发闸门与单调覆盖。配套的**预判式降级（Preemptive Degradation, PD）**则把 v9 的「超时后注入中立元」前移为「在水位线处预测越界、提前注入」——因为等到 deadline_guard 触发时，危险已经发生。

**灵感 3（二者耦合 → 关键路径隔离与延迟-安全预算守恒）**
直觉：最坏的耦合是「最需要安全计算的时刻，恰好是重推理最慢的时刻」——域越陌生，MPC 采样越多、模型越慢，形成**延迟-安全对抗耦合**。试图把重模块做快是脆弱的；正确姿势是**架构解耦**：把安全关键路径（M₀ 硬检查、SpatialCert、中块守卫、刹车监督）放到隔离的实时执行器上，其 WCET 不随重模块延迟漂移，则安全延迟 ≤ W_safe+J_max，与推理论证延迟无关。核心创新：**关键路径隔离器（CriticalPathIsolator, CPI）**。再叠加一条**延迟-安全预算守恒**原理：τ_react 是一份守恒预算，分给「证书计算」「反应储备」「安全裕度」；没有控制器能同时扩大三者，只能在 Pareto 前沿上移动——省下的每一毫秒只能换成裕度，不能重复记账。

**合流**：LP 把延迟变成可预测的安全量，ASC 把「算到哪算到哪」变成可证明的安全操作，CPI 把安全延迟从推理论证延迟中解耦。三者相乘 = **「延迟可预测、中断可安全、安全不随延迟漂移」的 v10**。

## 1. 研究问题（轮次升级版）

- **Q1（条件延迟尾部）**：如何在热节流、GC、共租户等非平稳干扰下，给出带有限样本覆盖的条件延迟上界 L^α_m(x)，且检测到交换性破坏时自动保守放宽而非静默低估？
- **Q2（任意时刻证书）**：如何定义证书格与派发闸门，使任意中断时刻返回的证书只覆盖已验证前缀、绝不派发未证动作，并在延迟可忽略时逐位退化为 v9 块证书？
- **Q3（隔离与预判）**：在何种实时调度/缓存/内存带宽假设下，安全关键路径延迟可与推理论证延迟解耦？预判式降级能否同时消除「迟到中止」与 v9 的「虚假降级风暴」？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 延迟安全包络律（Latency-Safety Envelope, LP）**
每周期估计条件延迟尾部 L_e2e^α(t)，并计算可容忍反应时间 τ_react(s_t)（在该延迟内启动最大制动仍满足 d_safe）。安全必要条件：L_e2e^α(t)+τ_detect ≤ τ_react(s_t)（Δ_L≤0）。延迟诱导块长 K_lat(t)=⌊(τ_react−L_e2e^α−τ_detect)/Δt⌋，并强制 K_eff=min(K_dom,K_lat,H_t)。延迟在**执行前**吃掉时域，而不是在执行后被发现。

**P14 任意时刻证书律（Anytime Certificate, ASC）**
证书构成格 (𝒞,⊑)：C_i 随计算深度 i 单调增强，C_i 只声明已验证动作前缀 H_i 的安全性质，且该声明对任意后续中断都成立。派发闸门要求 k_exec ≤ H_i。中断只允许收缩 H，不允许扩张。完全算完且延迟可忽略时，C_full 与 v9 块证书逐位一致。

**P15 关键路径隔离与预判降级律（Isolation & Preemptive Degradation, CPI）**
安全关键路径 CP_safe 与推理论证路径 CP_delib 在时间/空间上隔离（抢占优先级、内存锁定、缓存/LLC 分区、无共享锁），使 L_safe ≤ W_safe+J_max 与 CP_delib 延迟无关。降级由预测水位 θ·τ_react 触发（预判），而非 deadline 越界后触发（反应）；任一预测器失效 ⇒ 回退 v9 反应式 deadline_guard。

## 3. 与基线的接口（如何退化）

- LP 失效 ⇒ L_e2e^α := 静态 WCET 上界 Ŵ_e2e，K_lat := K_max，K_eff 退回 v9 的 Δ_dom 门控，等价 v9；
- ASC 失效 ⇒ 只用完整证书 C_full（算完才派发），等价 v9 块证书与 K_eff 门控；
- CPI 失效 ⇒ 安全关键路径与重推理共享执行器，退回 v9 单进程调度（v9 最大风险随之回归）；
- PD 失效 ⇒ 预判降级关闭，只用 v9 的反应式 deadline_guard 超时注入；
- v9 的 AC/MW/ID 任一失效 ⇒ 按 v9 契约化五级链继续退化；
- 全部失效 ⇒ 完整退回 MetricVoiceGauge-ACMD v9 ⇒ v8 ⇒ v7 ⇒ v6。

## 4. 预期贡献

1. **延迟作为一等安全变量**：条件延迟尾部分布 + 时间安全包络 + 延迟诱导块长收缩，把「延迟—安全」从经验权衡变成可证不等式；
2. **任意时刻安全证书**：证书格 + 派发闸门 + 中断安全定理，使降延迟只缩时域、不破安全；
3. **关键路径隔离与预判降级**：用架构隔离切断延迟-安全对抗耦合，并用预测水位替代事后超时，配合延迟-安全预算守恒给出 Pareto 边界；
4. **预算-安全-自省闭环升级**：E571–E590 覆盖延迟尾部覆盖、任意时刻中断、隔离干扰、预判触发、对抗尾延迟与端到端任务。

## 5. 本轮最大风险

**一句话**：CPI 的隔离定理只在「CPU 调度/缓存分区有效」的前提下成立，而重推理对安全路径的真实污染常走内存带宽、LLC 与 DVFS 这些调度器看不见的通道——越是重推理满载，W_safe 的静态界越可能失效，即「最需要隔离的时刻，隔离恰好不成立」。

## 1. 符号体系增量（定义 540–547）

**新增定义 540（推理延迟场与关键路径）** 给定上下文 x_t（负载、频率、批大小、缓存状态），每模块延迟 L_m(x_t) 为随机变量。关键路径 CP(t) 为从最新观测到动作派发的最长依赖链：
```
L_e2e(t) = Σ_{m∈CP(t)} L_m(x_t) + J_sched(t)
```
CP 分为 CP_safe（安全关键）与 CP_delib（推理论证）。所有时刻以单调时钟打戳 (t_obs, t_infer, t_act)，用于延迟归因与污染检测；上报值一律是「作用于旧状态的旧决策」的时戳，而非模块内部耗时。

**新增定义 541（条件延迟尾部 Conditional Latency Tail）**
```
L_m^α(x) := inf{ ℓ : P( L_m(x) ≤ ℓ ) ≥ α }
```
估计器（LP）：上下文分桶 b(x)，桶内 split-conformal 残差分位数 q_conf 与 GPD 超阈尾分位数 q_evt 取 max；桶内交换性由 CUSUM/KS 漂移检测监视。漂移告警时令 α_eff = α + 0.5(1−α)（上限 0.9999）并加宽尾部，**宁可高估延迟、不可静默低估**。端到端 L_e2e^α 为关键路径逐模块尾部之和加调度抖动上界（保守可加）。

**新增定义 542（时间安全包络 Temporal Safety Envelope）** 设当前间隙 g(t)=dist(s_t,O)−d_safe、速度 v、最大加速度 a_max、制动减速度 a_brk。若反应延迟为 τ，则最坏位移与制动距离
```
d_stop(τ) = vτ + ½a_maxτ² + (v + a_maxτ)² / (2a_brk)
τ_react(s_t) := max{ τ ≥ 0 : d_stop(τ) ≤ g(t) }
```
延迟安全间隙与包络：
```
Δ_L(t) = L_e2e^α(t) + τ_detect − τ_react(s_t) ≤ 0  ⇔  延迟安全
```
Δ_L>0 时任何「按计划执行」的证书都不再可信，必须预判降级或安全停驻。

**新增定义 543（任意时刻证书格 Anytime Certificate Lattice）** 证书格 (𝒞,⊑)，C_i=(H_i, Ĉ_i, t_state, rank_i)，H_i 为已验证前缀长度。任意时刻算法 A 在第 i 轮迭代后发出 C_i，满足：
```
单调性：H_0 ≤ H_1 ≤ … ≤ H_n，且 C_0 = 安全停驻证书（H_0=0）
可靠性：C_i 只对前缀 {1..H_i} 声明 v9 定义 533 的最坏界，对任意后续中断均成立
全证书：C_n ≡ v9 块证书 C_full（当跑到收敛）
派发闸门 Γ：执行第 k 步 ⇔ k ≤ H_i ∧ t_state + L_e2e^α + Δt ≤ now + τ_react
```
**中断只允许取链上已有的 C_i，绝不允许外推未验证动作**；「算不完」因此退化为「时域更短」，而非「安全更弱」。

**新增定义 544（延迟诱导块长 Latency-Induced Chunk Length）**
```
K_lat(t) = max(0, ⌊(τ_react(s_t) − L_e2e^α(t) − τ_detect)/Δt⌋)
K_eff(t) = min( K_dom(t), K_lat(t), H_t )
```
K_lat 在**执行前**按预测延迟收缩时域：延迟越大块越短；K_lat=0 表示当前包络连一步都不允许承诺，直接安全停驻。K=1 时等价 v9 逐步 fallback。

**新增定义 545（安全关键路径隔离 Critical-Path Isolation）** CP_safe = {M₀ 硬检查、SpatialCert 复核、AC 中块守卫、制动监督、派发闸门}。隔离执行器性质：最高抢占优先级、内存锁定（mlock）、LLC/缓存分区、无共享锁、独立 DVFS/功耗域或等价 QoS。隔离不变式：
```
L_safe ≤ W_safe + J_max,   与 CP_delib 的延迟分布无关
污染余量 η_c(t) = L_safe(t) − (W_safe + J_max)
```
η_c>0 说明隔离假设被破坏（典型：内存带宽/LLC 争用），系统必须保守收紧或触发降级，而非继续信任 WCET 界。

**新增定义 546（预判式降级与迟滞 Preemptive Degradation）** 水位 θ_L∈(0,1)：
```
若 L_e2e^α(t) > θ_L·τ_react(s_t)  ⇒ 预判降级：
    K_eff ← min(K_eff,1)；按 v9 表 536 注入可选模块中立元 v^⊥；
    若 K_lat = 0 或 Δ_L>0 ⇒ 立即安全停驻
回退：当 L_e2e^α < θ_off·τ_react 连续 H_rearm 周期 ⇒ 解除预判（θ_off<θ_L）
```
与 v9 的 deadline_guard 相比，触发条件从「已超时」变为「预测将超时」，把中止从越界之后移到越界之前。

**新增定义 547（延迟-安全预算守恒 Latency-Safety Budget Conservation）** 令 B_safe(t)=τ_react−τ_detect。预算分配：
```
B_safe(t) = L_cert(t) + L_reserve(t) + M(t)
可行域 F(t) = { (K,α,M) : KΔt + L^α(K) + M ≤ B_safe(t) }
```
L^α(K) 随块长 K 单调不减（块越长，采样/前向推演越多、延迟尾部越大）。预算守恒意味着：降低延迟只能等量兑换为时域 KΔt 或安全裕度 M，**不存在同时增大 K、α、M 的控制律**（引理 92）。

```python
# IP-357 LatencyPrognosticator：延迟预言机
class LatencyPrognosticator:
    def __init__(self, alpha=0.99, window=400, bucket_fn=None, drift_z=3.0):
        self.alpha = alpha
        self.bucket = bucket_fn or (lambda c: (c.load, c.freq, c.batch))
        self.calib = defaultdict(lambda: deque(maxlen=window))
        self.evt = defaultdict(lambda: GPDTail(tail_frac=0.05))
        self.drift = defaultdict(lambda: DriftDetector(z=drift_z))
        self.prov = defaultdict(LatencyStats)     # 延迟归因

    def observe(self, module, ctx, measured_ms):
        key = (module, self.bucket(ctx))
        self.calib[key].append(measured_ms)
        self.prov[module].update(measured_ms)
        self.evt[key].fit(self.calib[key])
        self.drift[key].push(measured_ms)

    def tail(self, module, ctx):
        key = (module, self.bucket(ctx))
        alpha_eff = self.alpha
        if self.drift[key].alarm:                     # 交换性破坏 ⇒ 保守放宽
            alpha_eff = min(0.9999, self.alpha + 0.5 * (1 - self.alpha))
        q_conf = conformal_quantile(self.calib[key], alpha_eff)
        q_evt = self.evt[key].quantile(alpha_eff)      # 极值尾部外推
        return max(q_conf, q_evt)                      # 绝不低估

    def e2e_tail(self, ctx, critical_path):
        return sum(self.tail(m, ctx) for m in critical_path) + ctx.jitter_bound


# IP-358 AnytimeSafetyCertifier：任意时刻证书器
@dataclass(frozen=True)
class AnytimeCert:
    H: int              # 已验证前缀（可派发步数）
    cert: Cert          # 前缀指标最坏界（v9 定义 533）
    t_state: float      # 证书所依据状态的采样时刻
    rank: int           # 格序

class AnytimeSafetyCertifier:
    def __init__(self, forward_model, policy, dt):
        self.F, self.policy, self.dt = forward_model, policy, dt

    def run(self, state, delta_dom, trust_ok, deadline_ms, L_alpha):
        # C_0：安全停驻证书，H=0，任何时刻都可合法派发
        chain = [AnytimeCert(0, safe_stop_cert(state), state.t, 0)]
        for i, cand in enumerate(self.policy.anytime_candidates(state), 1):
            if now_ms() >= deadline_ms:
                break                                  # 中断=合法收缩，不扩张
            pred = self.F.rollout_prefix(state, cand, depth=i)
            c = self._certify(state, cand, pred, trust_ok, delta_dom)
            if c is None:
                continue                               # 该深度未过证 ⇒ 不入格
            chain.append(AnytimeCert(i, c, state.t, i))    # 单调增强
            if self._complete(c, cand):
                break
        return chain[-1], chain                        # 最强已完成证书

    def dispatch_gate(self, cert, k_exec, tau_react, L_alpha, now):
        return (k_exec <= cert.H                       # 只派发已证前缀
                and cert.t_state + L_alpha + self.dt <= now + tau_react)


# IP-359 CriticalPathIsolator：关键路径隔离器
class CriticalPathIsolator:
    def __init__(self, W_safe, J_max, theta=0.8, theta_off=0.6, H_rearm=10):
        self.W_safe, self.J_max = W_safe, J_max
        self.theta, self.theta_off, self.H_rearm = theta, theta_off, H_rearm
        self.exec = RealTimeExecutor(priority=MAX, memlock=True,
                                     cache_partition=LLC_SAFE,
                                     no_shared_locks=True)
        self.armed, self.rearm = False, 0

    def isolation_ok(self, L_alpha, tau_react):
        # 安全延迟只与 W_safe+J_max 有关，与 CP_delib 延迟无关
        return self.W_safe + self.J_max <= tau_react - L_alpha

    def maybe_preempt(self, L_alpha, tau_react):
        # 定义 546：预测水位触发（预判），而非 deadline 越界后触发（反应）
        if L_alpha > self.theta * tau_react:
            self.armed, self.rearm = True, 0
        elif self.armed and L_alpha < self.theta_off * tau_react:
            self.rearm += 1
            if self.rearm >= self.H_rearm:
                self.armed = False
        return self.armed


# 主闭环集成：MetricVoiceGauge-LATS
def metricvoicegauge_round_10(M, s, obs, audio_stream=None, ell=None, ...):
    t0 = now_ms()
    ctx = mw_default_ctx()

    # ---- 1) 延迟预言 + 时间安全包络（定义 541/542）----
    L_alpha = lp.e2e_tail(ctx, critical_path=CP_DELIB)
    tau_react = latency_envelope.react_time(state=s, obs=obs)
    delta_L = L_alpha + TAU_DETECT - tau_react

    # ---- 2) 预判式降级：越界之前触发（定义 546）----
    preempt = cpi.maybe_preempt(L_alpha, tau_react)
    if preempt or delta_L > 0:
        K_eff_cap = 1
        middleware.inject_optional_identity()          # v9 表 536 的 v^⊥
        if latency_chunk_length(tau_react, L_alpha) <= 0:
            execute_safe_stop()
            return M.inherited_v8_path(ctx)

    # ---- 3) 任意时刻证书生成（定义 543）----
    if current_chunk is None or current_chunk.exhausted:
        deadline = t0 + min(B_dec, max(0.0, tau_react - L_alpha) * 1000)
        cert, chain = asc.run(ctx.state, ctx.delta_dom, trust_ok,
                              deadline, L_alpha)
        current_chunk = Chunk(cert, chain)

    # ---- 4) 延迟诱导块长（定义 544）----
    K_lat = latency_chunk_length(tau_react, L_alpha)
    K_eff = min(ac.effective_K(ctx.delta_dom, ctx.tau_dom, trust_ok),
                K_lat, current_chunk.cert.H, K_eff_cap)

    # ---- 5) 隔离执行 + 派发闸门（定义 543/545）----
    with cpi.exec:                                     # 安全关键路径 ≤ W_safe+J_max
        if not asc.dispatch_gate(current_chunk.cert, k_exec,
                                 tau_react, L_alpha, now_ms()):
            execute_safe_stop()
            current_chunk = None
        elif k_exec < K_eff:
            execute(current_chunk.cert.prefix[k_exec])
            k_exec += 1
        else:
            current_chunk = None                       # 块用尽/被收缩 ⇒ 重生成

    # ---- 6) v9 继承路径 + 延迟归因 ----
    C, spatial_cert, claims, metrics, rewards = M.inherited_v8_path(ctx)
    lp.observe('e2e_delib', ctx, now_ms() - t0)
    return C, spatial_cert, claims, metrics, rewards


def latency_chunk_length(tau_react, L_alpha):
    return max(0, int((tau_react - L_alpha - TAU_DETECT) / DT))
```

## 4. 推导

**引理 87（时间安全包络充分性）** 设 (i) 每个已派发动作在当前状态下通过 v9 引理 82 的证书复核；(ii) L_e2e^α+τ_detect ≤ τ_react(s_t)；(iii) 制动执行器在 τ_react 内可启动且减速能力 ≥ a_brk。则以概率 ≥ α，从任何实际作动时刻启动制动都满足 d_stop(τ) ≤ g(t)，即不违反 d_safe。证明：d_stop(τ) 对 τ 单调递增（v,a_max,a_brk≥0）；由 τ_react 定义 d_stop(τ_react)≤g(t)；实际端到端延迟 ≤L_e2e^α 以概率 α（定义 541 覆盖），加检测延迟后 ≤τ_react；由单调性得 d_stop(实际)≤d_stop(τ_react)≤g(t)。∎

**引理 88（任意时刻派发可靠性 / 中断安全）** 设证书链满足定义 543 的单调性与可靠性，派发闸门 Γ 要求 k_exec≤H_i 且时间有效。则对任意中断时刻，系统派发的每一步都落在某个已验证前缀内，未验证动作永不派发；若算法运行至收敛且 L_e2e^α=0，则 C_full 与 v9 块证书逐位一致，K_eff=min(K_dom,K_max,H_full)=K_dom。证明：对迭代 i 归纳：C_0 只含安全停驻（H=0，无动作可派发）；每次只把已通过 _certify 的深度 i 追加进链，故链上任意 C_j 的 H_j≤j 且其前缀全部过证；中断返回链尾 C_j，Γ 限制 k_exec≤H_j，故不派发未证动作。收敛时 H_n=K_max≥K_dom（v9 候选构造保证），C_n 即 v9 完整证书。∎

**引理 89（v10 → v9 精确退化）** 令 LP 退化为静态上界：L_e2e^α:=Ŵ_e2e、K_lat:=K_max；ASC 只返回 C_full；CPI 关闭（CP_safe 与 CP_delib 共享执行器）；PD 关闭。则主闭环每一步与 v9 MetricVoiceGauge-ACMD 逐位一致；且 Δ_L 判定恒不触发（Ŵ_e2e 已在 v9 部署期验证 ≤ 决策预算）。证明：逐条代入定义 543/544/546；K_eff=min(K_dom,K_max,H_full)=K_dom；派发闸门因 k_exec≤H_full 恒真；预判 armed≡False；故只剩 v9 路径。中立元映射见表 536，逐位等价由引理 83 传递。∎

**引理 90（关键路径隔离定理）** 若 CP_safe 在独立执行器上以最高抢占优先级运行，内存锁定、LLC 分区、无共享锁、独立 DVFS 域，且 CP_delib 仅经无等待消息队列与 CP_safe 交互，则 L_safe ≤ W_safe+J_max，且该上界与 CP_delib 的延迟分布无关。从而只要 W_safe+J_max ≤ min_t(τ_react(t))，安全性不依赖重推理延迟。证明：单处理器抢占式 WCET 可加性给出执行时间 ≤ΣW_safe；无共享锁排除优先级反转与阻塞项；缓存/内存分区排除 CP_delib 造成的 LLC/带宽延迟污染；独立 DVFS 排除频率联动；无等待队列保证交互非阻塞。故上界只由 W_safe 与释放抖动 J_max 决定，与 CP_delib 无关。∎

**引理 91（预判降级的支配性与误触发界）** 设 α 覆盖成立，θ_L∈(0,1)。 (i) 对任何真实端到端延迟超过 τ_react 的事件，必有 L_e2e^α>τ_react≥θ_Lτ_react，故预判降级在越界前触发，迟滞中止概率 ≤1−α； (ii) 与 v9 反应式 deadline_guard 相比，中止延迟严格不增； (iii) 误触发（L^α>θ_Lτ_react 但真实延迟未越界）的持续时间受尾部分布与 θ_off/H_rearm 迟滞约束，单位时间误降级次数 ≤1/(H_rearm·Δt) 上界。证明：(i) 由 L^α 为真实延迟上界（概率 α）与 θ_L<1；(ii) 触发时刻由「越界后」提前到「预测越界前」；(iii) Schmitt 迟滞要求回退水位 θ_off<θ_L 且连续 H_rearm 周期，故相邻触发-回退循环至少 H_rearm 周期。∎

**引理 92（延迟-安全预算 Pareto 边界）** 固定 B_safe=τ_react−τ_detect，约束 KΔt+L^α(K)+M ≤ B_safe，且 L^α 对 K 单调不减。则 (i) 可行集 F 对 (K,α,M) 向下封闭；(ii) 不存在使 K、α、M 同时严格增大的控制律；(iii) 延迟下降 ΔL 只能等量转化为时域 KΔt 或裕度 M，不可重复计入安全。证明：(i) 减小 K 使 L^α(K) 不增、减小 α 使 L^α 不增、减小 M 使 LHS 减小，均在 F 内；(ii) 反设三者同时严格增大，则 LHS 严格增大而 RHS 不变，违反约束；(iii) 对约束移项得 KΔt+M ≤ B_safe−L^α(K)，L^α 下降 ΔL 时右侧至多增加 ΔL。∎

## 8. 本轮最大风险

**一句话**：CPI 的隔离定理只在「CPU 调度/缓存分区有效」的前提下成立，而重推理对安全路径的真实污染常走内存带宽、LLC 与 DVFS 这些调度器看不见的通道——越是重推理满载，W_safe 的静态界越可能失效，即「最需要隔离的时刻，隔离恰好不成立」。
