# 第 42 轮（新循环第 2 轮） · 三维感知 × 轻量化设计：把「几何证据」做成可认证、可按需细化的感知证书（四层架构 v7）

> 承接第 41 轮 v6（CAR × LCS × CMC，证书即转移守卫）。第 41 轮把证书从静态文档变成运行时守卫，但证书链的起点仍是一个未经审视的假设：**L1 的度量语义图 C_ms + 标量漂移界 B_t 是可信的**。三维感知恰恰在这里最脆弱：误差是结构化的（随距离、视角、遮挡、材质、动态性变化），「未知」与「空闲」必须严格区分；一个全局标量 B_t 要么大到让 ValidRegion 缩空（可用性崩塌），要么小到漏掉遮挡后的障碍（不安全）。本轮灵感词「三维感知」「轻量化设计」正是从这里切入：**三维感知**把「地图 + 标量界」升级为带空间结构、可组合、可检验的**感知证书**；**轻量化设计**让感知证书像 IP-52 的证书一样支持决策等价的细节层次（LoD）与事件触发，只在「能改变守卫符号」的区域和精度上花算力。核心主张：**自由空间只能由可认证的几何 carving 产生，学习组件只允许「加障碍」，不允许「减障碍」**；感知因此从证书链的薄弱前提，变成证书链的第一个可证环节。

## 0. 直觉与动机

**灵感 1（三维感知 → 感知不是「给地图」，而是「给证据」）**：第 41 轮把 L1 的输出写成 C_ms 加一个漂移界 B_t，隐含假设是「地图是一个点估计，误差可以用一个标量概括」。但三维感知的误差不是标量：双目深度误差随距离平方增长（σ_z≈z²σ_d/(fb)），LiDAR 在远距离与低入射角处点变稀、光束变宽，遮挡后的空间根本没有观测，透明/镜面/细线会直接漏点。把这些压成一个 B_t，只有两种结局——取最坏值，ValidRegion 被 unknown 吞掉；取平均值，遮挡后的障碍被当成自由空间。**正确的抽象不是地图，而是证据包**：哪些空间被认证为自由（F̄）、哪些被过近似为占据（Ō）、哪些根本未知（U）、当前视场/遮挡下覆盖了哪条未来走廊（C）、动态物体在有效期内可能到哪（R）。关键不变式只有两条：**O\*⊆Ō∪U（障碍要么被声明，要么未知）**、**F̄∩O\*=∅（认证自由空间里没有真障碍）**。未知永远不算自由。

更进一步，学习组件在三维感知里几乎不可避免（语义、动态物体、occupancy prior），但验证一个 3D occupancy 网络极难。于是本轮采用一条**结构性解耦**：自由空间只由带保守传感器模型的几何 carving 产生（射线求交、体素雕刻、区间 SDF），学习组件只允许**增加**障碍/未知/动态可达集，绝不允许**扩大**自由空间。这样，即使网络漏检，最坏也只是「少了一块自由空间」；而不会出现「把真障碍认证成自由」的致命错误。soundness 从此只依赖可测量的传感器模型、标定残差与时间同步，而不依赖对网络的信任。

还有一条把 3D 感知与运动安全接起来的桥：**感知只需对「不可避免碰撞走廊」（ICC）负责**。ICC 是机器人在感知延迟 + 反应延迟 + 制动距离内可能到达的点集；ICC 之外的点无论有没有障碍，都不影响这一拍的安全决定。于是「感知覆盖」不再是全图覆盖，而是「ICC 必须被认证自由或显式未知」。这既是安全定义，也是轻量化的入口：认证域从整张地图缩到一条随速度变化的管道。

**灵感 2（轻量化设计 → 只认证「会改变决定」的几何）**：三维感知的全量栈很贵：多帧融合、稠密 TSDF/ESDF、多视角立体、神经 occupancy、NeRF/3DGS，不可能每个控制拍都跑。轻量化的直觉与第 41 轮一脉相承，但作用对象从「策略证书」换成「感知证据」：
1. **决策等价 LoD**：感知只需要把当前所有几何守卫的符号定下来。P0 粗体素 carving（单帧）→ P1 多分辨率 TSDF/ESDF + 关键帧 + 动态剔除 → P2 稠密融合 + 近机细层 → P3 离线高质量重建。一旦未定守卫集 U=∅ 就停止细化；细化只改变「不确定」，不改变已定的符号。
2. **空间注视（foveation）与 ROI**：只对 ICC 管道与近机体积做细分辨率认证，远场用粗层；不在当前决定链上的体素不认证。这把「全图」换成「决策相关子集」，与 ICC 的定义天然一致。
3. **事件触发与保持时间**：静态几何在自运动下只要覆盖维持就可复用；动态物体用可达集在 T_perc 内膨胀。只在遮挡变化、新动态物体、staleness 到期、标定漂移、回环跳变时重认证。
4. **结构化减重**：几何用便宜的射线 carving，学习只做「增障」提议；若一定要用学习 occupancy，只对近机小头做严格区间认证，主干用保守膨胀。

**耦合**：三维感知回答「哪些自由空间是真的、覆盖到哪、还能信多久」；轻量化回答「为了当前守卫，感知要细化到哪一层、覆盖哪一块」。感知延迟、遮挡、稀疏不再藏在附录里，而是自动机的显式转移事件；感知太保守会表现为长期 Degraded，感知不 sound 会表现为对抗测试里的 false-free——两者都被实验当场抓住。

## 1. 形式化定义

**定义 38（感知证书 PC）**：设世界 W⊆R³，真实占据 O\*⊆W，真实自由空间 F\*=W\O\*，真实符号距离 s\*:W→R。感知证书是一个七元组
PC=(F̄,Ō,U,C,R,τ,δ)，
其中 F̄⊆W 为**认证自由空间**，Ō⊆W 为**占据过近似**，U⊆W 为**未知集**，三者满足 F̄∩Ō=∅、F̄∩U=∅、Ō∩U=∅、F̄∪Ō∪U=W；C 为覆盖证书（对 ICC 上每点给出是否被足够分辨率观测）；R 为动态物体在有效期内的可达集过近似；τ 为证书时间戳，δ 为置信水平。**Soundness** 要求
(1) O\*⊆Ō∪U（不遗漏障碍，未知可兜底）；
(2) F̄∩O\*=∅（认证自由即真自由）；
(3) 对任意 x∈F̄，有 s\*(x)≥ε（认证了 ε 的几何余量）。
**有效性**：PC 在 t 时刻有效，当且仅当 age=t−τ≤T_perc、C 对当前 ICC 成立、且 R∩F̄=∅。

**定义 39（保守几何 carving 与学习单调增障）**：传感器模型 M 给出每条观测的误差界：光束发散半角 α、测距噪声 σ_r、最大量程 r_max、入射角相关误差、时间同步误差 e_time、外参标定残差 e_cal。对观测 z，定义该观测**可认证自由**的点集 F(z)⊆W：从传感器原点沿射线、在 r_max 内、扣除 α 与 σ_r 的保守锥/球后仍可判定为空闲的点；任何被遮挡、超量程、低入射角或时间戳可疑的点一律不进 F(z)。多观测融合取交：F̄_geo=⋂_z F(z)。占据过近似 Ō_geo 由命中点按 σ_r 与 α 膨胀得到，且**永不被后续观测删成自由**（只允许被更强的占据证据覆盖）。学习模块 L（语义、动态检测、occupancy prior）只输出 (Ō_L,U_L,R_L)，并要求
F̄=F̄_geo\(Ō_L∪U_L)，Ō=Ō_geo∪Ō_L，U=W\(F̄∪Ō)。
**单调增障约束**：L 不得向 F̄ 添加任何点；若 L 判定某动态物体可剔除，必须把其在 T_perc 内的可达集 R_L 加入 R，否则不得剔除。
**命题 1**：若 F̄_geo sound 且 L 满足单调增障，则 PC sound 与 L 的准确率无关。证明：F̄⊆F̄_geo⊆F\*；且 O\*⊆Ō_geo∪U_geo⊆Ō∪U。∎

**定义 40（感知增广混合自动机 PAHA）**：H_p=H_CAR⊗H_P，H_P=(Q_p,E_p,Inv_p) 为感知自动机，Q_p={Clear,Sparse,Occluded,Blind,Dynamic}。感知守卫由 PC 导出：
g_cov(x)=min_{y∈ICC(x)} c(y)−c_min，
g_unk(x)=u_max−|U∩ICC(x)|/|ICC(x)|，
g_age(x)=T_perc−age，
g_cal(x)=e_cal_max−E_cal，
g_dyn(x)=dist(F̄,R)−d_safe。
转移规则：覆盖下降或 ICC 内未知超限 → Watch/Degraded；动态可达集与 ICC 相交 → Escalate；Blind 或标定超界 → SafeStop。不变式
I_p=I_CAR∩{g_cov≥0 ∧ g_unk≥0 ∧ g_age≥0 ∧ g_cal≥0 ∧ g_dyn≥0}。
**安全命题**：若机器人轨迹始终位于 F̄ 内、且有效期内 R 被排除，则在 [t,t+T_perc] 内无碰撞（静态障碍由 F̄ soundness，动态障碍由 R 过近似）。∎

**定义 41（决策等价感知 LoD）**：感知档 p∈{0,1,2,3}，成本 D_0<D_1<D_2<D_3，紧致度 ρ_0>ρ_1>ρ_2>ρ_3；每档输出一个 sound 的 PC_p，且守卫区间嵌套：[lo_{p+1}(g_e),hi_{p+1}(g_e)]⊆[lo_p(g_e),hi_p(g_e)]。未定守卫集
U_p(x)={e: lo_p(g_e)<0<hi_p(g_e)}，
最小充分档 p\*(x)=min{p:U_p(x)=∅}。
**命题 2（决策等价）**：若守卫只依赖认证边际的符号，且各档区间均包含真值，则用 p\*(x) 驱动的转移序列与用精确几何驱动者完全相同。证明：U_p=∅ 意味着每个守卫的符号在所有可行真值上一致，细化不会翻转任何符号。∎

**定义 42（ICC 覆盖与感知保持时间）**：给定 t₀ 时刻状态与最大制动/转向能力，ICC(t₀,T) 为在 [t₀,t₀+T] 内可能到达的点集，T 含感知延迟、反应延迟与制动时间。覆盖条件
Cov(t₀,T): ICC(t₀,T)⊆F̄∪Obs_ok，且 U∩ICC(t₀,T)=∅，
其中 Obs_ok 为被足够分辨率观测且判定为自由的区域。感知保持时间
T_perc=min{T_dyn,T_cov,T_stale,T_cal}：
T_dyn 由 R 的有效期给出（R 在 T_dyn 内是可达集过近似）；
T_cov=(d_clear−d_stop(v))/v_max，d_stop(v)=v²/(2a_max)+v·t_react；
T_stale 由传感器与场景去相关时间给出；
T_cal 由标定漂移速度与允许残差给出。
**命题 3（保持时间）**：若 PC 在 t₀ sound，且对 [t₀,t₀+T_perc] 的每个 ICC 覆盖条件成立，则自由空间断言在该区间内持续 sound。∎

**定义 43（感知证书的组合与精化）**：组合
PC₁⊗PC₂=(F̄₁∩F̄₂, Ō₁∪Ō₂, U₁∪U₂, C₁∩C₂, R₁∪R₂, min(τ₁,τ₂), min(δ₁,δ₂))。
精化 PC′⪰PC 当且仅当 F̄′⊇F̄、Ō′∪U′⊆Ō∪U、各守卫区间更紧、C′⊇C、R′⊆R。
**命题 4**：精化保 soundness 且只会提高可用性；组合保 soundness（两个 sound 证书的自由空间交集仍不含真障碍，占据/未知并集仍覆盖真障碍）。∎

**设计约束（感知单调保守性）**：学习只能加障碍/未知，不能减；不确定只能指向更保守制度；更细的感知只能扩大 F̄，不能缩小。该约束把感知的失效严格转化为**可用性下降**，而不是漏报警——与第 41 轮的守卫单调性形成同一条安全链。

## 2. 三大产出设计

### 2.1 IP-57 CERTIFIED-3D-PERCEPTION（可认证三维感知 C3P）
1. 保守传感器模型：为 LiDAR/深度/双目分别给出距离、角度、入射角、时间同步与外参误差界；射线 carving 用锥/球保守扣除，任何可疑点不认证为自由。
2. 感知证书构造：输出 F̄、Ō、U、覆盖证书 C、动态可达集 R；用区间 SDF [s_lo,s_hi] 代替标量 B_t，F̄={x:s_lo(x)≥ε}。
3. 学习单调增障：语义/动态/occupancy prior 只输出障碍、未知与可达集；动态剔除必须附带可达集，否则不许剔除。
4. 覆盖证书：由视场、遮挡、自遮挡与分辨率给出 ICC 上逐点的可观测性；不可观测点计入 U。
5. 多分辨率表示：体素哈希/八叉树；粗层常驻、细层按需；证书差分只更新可能改变守卫符号的体素。

### 2.2 IP-58 PERCEPTION-LOD-ANYTIME（感知 LoD 任意时间 PLA）
1. 四档感知：P0 单帧粗体素 carving；P1 多分辨率 TSDF/ESDF + 关键帧 + 动态剔除；P2 稠密融合 + 近机细层；P3 离线重建/真值（仅基准）。
2. 决策等价停止：每拍只在 ICC∪近机 ROI 内细化，直到 U=∅ 或预算耗尽；耗尽且 U≠∅ 按单调保守性降级。
3. 空间注视：细层只覆盖 ICC 管道与近机体积；远场粗层；ROI 随速度与转向预测前移。
4. 事件触发：遮挡变化、新动态物体、staleness 到期、标定漂移、回环跳变触发重认证；否则复用 PC。
5. 联合预算：与 IP-52 的策略证书共享每拍预算 Γ，按「决策边际敏感度/成本」分配算力。

### 2.3 IP-59 COVERAGE-GUARD-MONITOR（覆盖守卫监控 CGM）
1. 把覆盖、未知比例、staleness、标定残差与动态相交守卫编译为定点/区间算术看门狗（复用 IP-53 后端）。
2. 生成 WCET 与内存界；超预算自动下放到更粗感知档或 SafeStop。
3. 单边可靠性：输出 ok ⇒ PC 在该拍 sound 且 ICC 覆盖成立；不确定一律 warn/trip。
4. 与策略/感知网络解耦，可独立升级；trip 直接强制自动机转入 SafeStop。
5. 审计链：记录未知区域、覆盖缺口、动态事件、标定漂移与降级次数，供事后归责。

## 3. 四层架构 v7

```
L1: 传感器（LiDAR/深度/双目/IMU）→ IP-57 C3P 感知证书 PC=(F̄,Ō,U,C,R,τ,δ,E_cal,E_time)
    → 多分辨率体素/TSDF + 覆盖证书 + 动态可达集
L2: IP-36 语义图 / IP-49 LIO 只在 F̄ 上接地；语义/学习只增障；几何残差证书
L3: IP-51 CAR ⊗ 感知自动机 PAHA ← IP-58 PLA 决策等价 LoD（P0→P3 + ICC ROI + 事件触发）
    → IP-47 乘积组合 → IP-39 规划（ICC 覆盖约束）→ IP-45 总线
    → IP-48 认证流匹配执行 + IP-43 韵律即模式 → IP-53/59 CMC/CGM 看门狗
L4: IP-44 蒸馏 + IP-50 课程引擎（感知难度作为课程维度）→ RCA 重颁证书 → 契约热更新
运行期：感知证书 + LoD 调度 + ICC 覆盖守卫 + 保持时间 + 事件触发 + 看门狗
```

## 4. 实验设计（E79–E84 硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E79 感知证书 soundness | 真实障碍落入 Ō∪U 比例；F̄ 中真实障碍数；未知误判率 | 100%；0；<0.1% |
| E80 LoD 感知延迟 | 每拍感知算力 median/p99 vs 全量；档位分布 | 降≥5x；p99<10ms；P0/P1≥80% |
| E81 决策等价保真 | 轻量感知决策=全量决策的拍占比 | ≥99.9% |
| E82 ICC 覆盖/保持时间 | 期内覆盖仍有效比例；遮挡/动态漏检 | ≥99%；0 漏检 |
| E83 看门狗 WCET/内存 | WCET、内存、误 trip | ≤1ms、≤64KB、<0.1% |
| E84 端到端安全-可用（对抗感知） | 不安全事件、Nominal 占比、成功率、恢复时间 | 0 起；≥70%；≥85%；<2s |

对抗感知测试集：透明玻璃、镜面/金属、细线/栏杆、快速动态物体、强光/逆光、传感器遮挡、标定漂移、时间戳错位、远距离稀疏点云。消融：学习自由空间 vs 学习只增障；标量 B_t vs 区间 SDF；LoD 开/关；ICC 覆盖开/关。

回退：E79 失败 → 放弃学习增障，只用纯几何 carving + 更保守 unknown；E80 失败 → 只保留 P0 + SafeStop 双档；E84 可用性不达标 → 增大粗层/增加 Watch 档，而非放松 unknown。

## 5. 本轮最大风险

**一句话**：感知证书的全部 soundness 都压在「传感器模型 + 标定 + 时间同步」这组假设上，一旦透明/反光/动态/同步漂移等分布外现象让这些假设失效，系统会把「未知」误判为「自由」——这比没有证书更危险，因为错误被形式化包装成了保证。

# 第 42 轮产物 · 创新点清单 v19：可认证三维感知（C3P）× 感知 LoD 任意时间（PLA）× 覆盖守卫监控（CGM）（四层架构 v7）

> 承接第 41 轮产物 v18（IP-51/52/53）。本轮**增量插入** IP-57/58/59，并升级 IP-36/39/43/45/46/47/48/49/50/51/52/53；不推倒任何既有层级。核心是把 v18 的「证书链从几何开始」改为「证书链从**可认证的感知证据**开始」：自由空间只由保守几何 carving 产生，学习只增障；感知分辨率由决策等价 LoD 在线决定。

## 2. 关键算法（伪代码）

### IP-57 C3P：感知证书构造
```
def build_pc(obs, calib, roi, tier):
    F = roi                               # 只在 ROI（ICC ∪ 近机）内认证
    O = empty()
    for z in select(obs, tier):           # 按档位选帧/分辨率
        F &= carve_free(z, calib)         # 保守锥/球：发散/噪声/时差/标定
        O |= inflate_hits(z, calib)       # 命中点按 σ_r、α 膨胀
    O_L, U_L, R_L = learned_obstacles(obs, tier)
    F = F - (O_L | U_L)                   # 学习只能收缩自由空间
    O = O | O_L
    U = roi - (F | O)
    C = coverage_certificate(obs, roi, calib)
    R = dynamic_reachable(obs, tier) | R_L
    return PC(F, O, U, C, R, now(), delta)

def carve_free(z, calib):
    # 沿射线扣除发散半角 α、测距噪声 σ_r、时间同步 e_time、
    # 外参残差 e_cal；被遮挡/超量程/低入射角/时戳可疑 → 不认证
    return conservative_free_cone(z, alpha, sigma_r, e_time, e_cal)
```

### IP-58 PLA：决策等价感知调度
```
def perceive(x, guards, budget):
    cost = 0
    roi = ICC(x, T_stop(x)) | near_body(x)
    for p in [P0, P1, P2, P3]:            # 成本递增、界更紧
        pc = build_pc(obs, calib, roi, tier=p)
        cost += D[p]
        U = {e for e in guards if lo(pc, g_e) < 0 < hi(pc, g_e)}
        if not U: return pc, p            # 决策等价：无需更细
        if cost + D[p+1] > budget:
            return downgrade_monotone(pc), p
    return pc, P3

def next_perception_event(pc, traj):
    return min(pc.tau + T_perc(pc, traj),
               occlusion_change_time(pc),
               new_dynamic_time(pc),
               calib_drift_time(pc),
               loop_closure_time(pc))
```

### IP-59 CGM：覆盖守卫监控
```
def compile_coverage_guard(pc, icc):
    circuit = interval_arith(
        coverage(icc, pc.C) >= c_min
        and unknown_fraction(icc, pc.U) <= u_max
        and age(pc) <= T_perc
        and pc.E_cal <= e_cal_max
        and dist(pc.F, pc.R) >= d_safe)
    return Monitor(circuit,
                   trip_if = lower(circuit) < 0,
                   wcet    = bound_wcet(circuit),
                   mem     = bound_mem(circuit))

def watch(M, pc, traj):
    if M.step(pc, traj) == TRIP:
        automaton.force(SafeStop)         # 单边可靠：不确定即降级
```

def compose(pc1, pc2):
    return PC(F = pc1.F & pc2.F,
              O = pc1.O | pc2.O,
              U = pc1.U | pc2.U,
              C = pc1.C & pc2.C,
              R = pc1.R | pc2.R,

## 3. 推导与正确性

### 3.1 为什么标量 B_t 必然两难
双目深度误差近似 σ_z≈z²σ_d/(fb)。取 f=500 px、b=0.12 m、σ_d=0.5 px：
- z=10 m：σ_z≈100×0.5/60≈0.83 m；
- z=20 m：σ_z≈400×0.5/60≈3.33 m。

若用单一 B_t=3.33 m，则 10 m 处把自由空间多吞掉约 4 倍（可用性损失）；若用 B_t=0.83 m，则 20 m 处少算约 4 倍（不安全）。LiDAR 同样有角度—距离耦合：0.1° 发散在 20 m 处约 3.5 cm，1° 则约 35 cm，低入射角进一步放大；而遮挡是纯几何效应，0.5 m 的遮挡物在 5 m 处可在 20 m 处遮住 2 m 宽的区域，任何标量界都无法表达。**结论**：必须用随空间变化的区间 SDF [s_lo,s_hi] 与显式 U；B_t 只能是 s_lo 的一个全局下界，不能作为认证的全部信息。

### 3.2 为什么 ICC 是最小充分认证域
设机器人从 t₀ 起以任意允许控制运动，T 内可能到达的点集为 ICC(t₀,T)。若某点 x∉ICC(t₀,T)，则无论 x 是否有障碍，机器人都不可能在 T 内到达它，因而它不影响这一拍的安全决定；反之，若 x∈ICC(t₀,T) 且未被认证自由也未被标为未知，则无法保证在 x 处能安全停下。故「ICC 上每点 ∈F̄∪U 且 U∩ICC 被显式处理」既是安全必要条件，也是当前决定的最小充分信息。这与定义 41 的「分辨率上的决策等价」构成对偶：**空间上只认证 ICC，分辨率上只细化到 p\***。

### 3.3 轻量化的量级估计
粗体素 0.2 m 对细体素 0.05 m，体素数比约 (0.2/0.05)³=64；ICC 管道 + 近机体积通常只占全图 5%–10%，再省约 10–20 倍；两者相乘理论可达 640–1280 倍，实际受内存带宽与融合开销限制，5–20 倍是保守目标。这为 E80 的「≥5x」提供了结构性依据，而不是靠调参。

### 3.4 正确性定理
- **定理 1（PC soundness）**：若 F̄_geo sound 且学习满足单调增障，则 F̄∩O\*=∅ 且 O\*⊆Ō∪U。由命题 1。
- **定理 2（有效期内安全）**：若轨迹位于 F̄、R∩F̄=∅、且 PC 在 [t,t+T_perc] 有效，则区间内无碰撞。静态由 F̄ soundness，动态由 R 过近似。
- **定理 3（决策等价）**：若守卫只依赖边际符号、各档区间包含真值且嵌套，则 U_p=∅ 时轻量决策=精确决策。由命题 2。
- **定理 4（保持时间）**：若 t₀ sound 且 [t₀,t₀+T_perc] 的 ICC 覆盖条件成立，则自由空间断言持续 sound。由命题 3。
- **定理 5（组合/精化）**：组合保 soundness；精化 PC′⪰PC 保 soundness 且只会提高可用性。由命题 4。
- **推论（学习无害）**：在单调增障约束下，任意错误的学习模块最多导致 F̄ 缩小与降级，不会产生 false-free。这把「感知网络的可靠性」从安全证明中彻底移除。

|---|---|---|
| IP-57 射线 carving | O(N_pts·L/voxel) 或 O(N_pts) 哈希 | 保守锥/球 ⟹ F̄_geo⊆F\* |
| IP-57 区间 SDF | O(|ROI|) 体素更新，增量 | s\*∈[s_lo,s_hi]；F̄={s_lo≥ε} |
| IP-58 决策等价 LoD | 每拍 O(档数·|ROI|·|Guard|)，通常 P0/P1 | U=∅ ⟹ 决策=精确 |

## 4. 实验设计（E79–E84，硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E79 感知证书 soundness | 真实障碍落入 Ō∪U 比例；F̄ 中真实障碍数；未知误判率 | 100%；0；<0.1% |
| E80 LoD 感知延迟 | 每拍感知算力 median/p99 vs 全量栈；档位分布 | 降≥5x；p99<10ms；P0/P1≥80% |
| E81 决策等价保真 | 轻量感知决策=全量决策的拍占比 | ≥99.9% |
| E82 ICC 覆盖/保持时间 | 期内覆盖仍有效比例；遮挡/动态漏检 | ≥99%；0 漏检 |
| E83 看门狗 WCET/内存 | WCET、内存、误 trip 率 | ≤1ms、≤64KB、<0.1% |
| E84 端到端安全-可用（对抗感知） | 不安全事件、Nominal 占比、成功率、恢复时间 | 0 起；≥70%；≥85%；<2s |

**对抗感知测试集**：透明玻璃、镜面/金属、细线/栏杆、快速动态物体、强光/逆光、传感器遮挡、外参漂移、时间戳错位、远距离稀疏点云。每组需给出「真值障碍 → 落入 Ō∪U」的逐帧审计。

**消融**：学习自由空间 vs 学习只增障；标量 B_t vs 区间 SDF；LoD 开/关；ICC 覆盖开/关；P0-only vs P0→P3。

**回退路径**：E79 失败 → 放弃学习增障，只用纯几何 carving + 更保守 unknown；E80 失败 → 只保留 P0 + SafeStop 双档；E84 可用性不达标 → 增大粗层/增加 Watch 档，而非放松 unknown。

## 5. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 传感器模型/标定/同步假设被分布外现象击穿 → false-free | 高 | 保守锥/球；时戳与外参残差入守卫；对抗测试集；不确定一律 unknown；CGM 单边可靠 |
| 未知区域过多 → 长期 Degraded/SafeStop（可用性崩塌） | 高 | ICC 只认证决策相关域；LoD + 空间注视；粗层先决；E84 以 Nominal 占比守门；阈值在线标定 |
| 学习模块误删动态物体 | 高 | 单调增障：剔除必须附带可达集；否则不许剔除；审计链记录 |
| 覆盖证书过保守 → 频繁降速 | 中 | 只在 ICC 上算覆盖；多分辨率可见性；事件触发而非每拍全算 |
| LoD 档间区间不嵌套 → 决策抖动 | 中 | 强制区间嵌套检查；滞回 + τ_min；边界拍归入 Watch |
| ICC 随速度/转向预测失准 | 中 | 用可达集过近似而非名义轨迹；与 IP-39 规划共享可达性模型 |
| 体素/哈希内存膨胀 | 中 | 粗层常驻 + 细层 LRU；ROI 外不分配；证书差分 |
| 感知与策略预算争抢 | 中 | 联合预算 Γ；按决策边际敏感度/成本分配；P0 保底 |

## 6. 本轮最大风险

**一句话**：感知证书的全部 soundness 都压在「传感器模型 + 标定 + 时间同步」这组假设上，一旦透明/反光/动态/同步漂移等分布外现象让这些假设失效，系统会把「未知」误判为「自由」——这比没有证书更危险，因为错误被形式化包装成了保证。
