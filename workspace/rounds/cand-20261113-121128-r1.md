# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因」IP-214~223；灵感循环第 3 轮；本轮灵感：「消融实验」×「故障诊断」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险一针见血：**归因能力依赖「故障属于有限假设集」与「视觉/几何失效相互独立」；真实故障常是未知类型的组合，透明/镜面/对抗 patch 会让视觉与几何共享同一分布外失效源，FIR 会把未知复合故障强行塞进最近假设、只膨胀错误的球，系统因「已经归因」而更自信地继续执行。** 本轮不再扩大假设集（那只是把有限集变大），而是换一个更根本的提问：第 65 轮问「它属于哪一类」，DIVA 问「**在有限证据下我究竟能确定哪些部件坏了、哪些根本不可分辨，以及能否用一次安全干预把它们分开**」。本轮核心命题是：
>
> **把「闭集故障分类」升级为「开集一致性诊断」：用消融（干预）产生因果对比而非相关性签名，用冲突集的最小碰集表示未知/复合故障，用「确定诊断 / 可能诊断」的夹逼替代 argmax+ambiguous，并把消融本身当作可证伪的诊断器自检。**

## 0. 直觉与动机

**灵感 1（消融实验 → 干预，而不是观察）**
直觉：第 65 轮 FIR 的本质是「看签名像谁」——一种**相关性分类**。消融实验的智慧是「**拿掉一个部件，看什么变了**」——一种**因果对比**。两者对未知故障的能力天差地别：分类器遇到没见过的故障只能归到最近类；消融不问「你像谁」，而问「**如果这个部件是好的，预测会不会不一样**」。只要一次干预只作用于一个部件，因果对比就能把「共享同一失效源」的混淆拆开；拆不开时，它也能诚实地报告「拆不开」。但必须诚实：消融是**对模型做的干预**，模型错了，消融的因果性也就错了——所以消融必须自带安慰剂对照。

**灵感 2（故障诊断 → 一致性诊断，而不是模式识别）**
直觉：经典故障诊断（FDI / DX）不枚举故障类型。它只有两样东西：**部件模型**（每个部件「正常」时应满足的约束）与**观测**。当「所有部件都正常」与观测矛盾时，就得到一个**冲突集**（一组不能同时成立的「正常」假设）；把所有冲突集取**最小碰集**（minimal hitting set），就得到全部**最小诊断**——「哪几个部件坏了」能解释全部冲突。这个表示天然容纳**未知故障**（不写类型，只写 ¬ok(c)）与**复合故障**（一个碰集可含多个部件）。更关键的是它给出两个严格边界：**确定诊断 = 所有最小诊断的交集**（一定坏了），**可能诊断 = 并集**（可能坏了）。这正是第 65 轮缺的东西：不是「最像谁 + 置信度」，而是「**必然坏 / 可能坏**」的夹逼。

**灵感 3（消融实验 → 对诊断器本身做消融）**
直觉：消融在论文里常是「去掉模块看性能掉多少」。把它反过来用在系统自己身上：若对一个**已知健康**的部件做一次**假消融（placebo/sham）**，诊断结论却变了，说明诊断器或模型存在**共因缺陷**——它对不该有响应的干预产生了响应。这就是在线「诊断器的消融自检」。第 65 轮最大的危险是「归因错误却更自信」；安慰剂测试是唯一能在线戳破这种自信的低成本手段。

**灵感 4（三灵感合流 → DIVA：Diagnosis via Interventional Virtual Ablation，干预消融式开集故障诊断闭环）**
闭环：部件-参数诊断模型（CPDM）取代固定假设集 → 虚拟/良性消融产生干预残差与冲突集（ICR）→ 最小碰集给出诊断格与确定/可能边界（MHD）→ 先做可诊断性/可隔离性分析，显式标出「不可分辨类」（DIA）→ 归因不唯一时，选择**最省、可逆、零伤害**的良性消融以最大化诊断熵下降（ABA）→ 安慰剂/元消融自检（PBT）→ 按确定/可能做定向动作或保守包络（CSU）→ 块级诊断感知规划（CSP-D）→ 对抗诊断认证（AIC-D）→ J_diva。第 65 轮是「六选一的分类器」，DIVA 是「一个会做实验、会承认看不见、且能证明自己没瞎的诊断器」。

**灵感 5（VISTA 组件的原位升级）**
- **FIR → ICR/MHD**：从「对固定 ℋ 求后验」改为「对冲突集求最小碰集」；未知故障不再是 OOD，而是碰集里一个未命名的部件集合。
- **AFA → ABA**：探针目标从「ℋ 的互信息」升级为「诊断格 D 的期望熵下降」，并强制良性、可逆、零伤害与消融预算。
- **RSC-V / directed_demote → CSU**：确定诊断→定向；可能诊断→保守包络；不可分辨→最粗包络 + 禁不可逆。杜绝「argmax 错就膨胀错球」。
- **VCV / VPG → 可被诊断的证据源**：视觉仍只提供可错证据，但它的失效现在可以作为一个部件被消融、被诊断，而不再被假设为与几何独立。
- **CSP-V → CSP-D**：规划节点携带诊断格，边要求「对所有可能诊断安全」，并插入 `ablate_probe` / `placebo_test` 元技能。
- **AIC-V → AIC-D**：干扰集增「消融欺骗」（让干预看似无效/有效）、「共因签名碰撞」、「安慰剂碰撞」、「诊断投毒」。
- **J_vista → J_diva**：证书增 diagnosis_set、certain、possible、isolability_status、ablation_provenance、placebo_passed、diagnoser_reliable、ablation_budget_used。

## 1. 形式化定义（增量：定义 233–247）

- **定义 233（DIVA 闭环）**：DIVA = (VISTA, CPDM, ICR, MHD, DIA, ABA, PBT, CSU, CSP-D, AIC-D, J_diva)。定位：VISTA 的「闭集归因」升级为「开集一致性诊断 + 干预消融」。不变式：**诊断、碰集、消融规划、证书只在语义流；实时流只做良性消融执行、残差采集、早停与派发，零学习写操作。**
- **定义 234（部件-参数诊断模型 CPDM）**：把系统分解为部件集 C={c_geo, c_ft, c_model, c_vis, c_policy, c_kin, c_calib}；每个部件有正常模型 M_c(θ_c) 与异常谓词 ¬ok(c)。系统描述 SD=∧_c[ok(c)⇒constraint_c(θ_c;u,y)]。故障不再是标签，而是「哪些 ok(c) 为假」。
- **定义 235（干预消融算子）**：do(ablate(c,mode))，mode∈{virtual 数字孪生反事实, substitute 以标称模型替换, suppress 置零通道, physical-benign 零力窗/短暂可控遮挡/切换模态/亚安全微触}。只允许**可逆、零伤害、有恢复计划**的物理消融；其余一律在孪生里做。
- **定义 236（干预残差与签名矩阵）**：e=y−ŷ_full；e_a=y−ŷ_a 为消融 a 后残差；对比 Δ_c=e−e_a。签名矩阵 A∈ℝ^{r×|C|} 的第 c 列由**单部件消融**测得。可加故障模型下 e=Aθ+ε，θ 可辨识 ⇔ rank(A)=|C|；不可辨识方向即 ker(A)。
- **定义 237（冲突集与最小碰集诊断 MHD）**：若某部件子集 O⊆C 全假设为正常时与观测不一致且极小，则 O 为冲突集。全部冲突集 𝒞 的最小碰集即最小诊断集 D={d_1,…,d_m}。未知故障=未命名 ¬ok(c)，复合故障=|d|>1，**无需枚举故障类型**。
- **定义 238（诊断格与确定/可能）**：最小诊断按 ⊆ 构成格。确定诊断 Cert=∩_{d∈D} d（一定坏）；可能诊断 Poss=∪_{d∈D} d（可能坏）。后验 P(d|e)∝P(e|d)P(d)，P(d) 取部件失效率先验 × 稀疏先验（Occam）。真实最小诊断 d* 满足 Cert⊆d*⊆Poss。
- **定义 239（可诊断性与可隔离性 DIA）**：由 A 的秩/条件数 κ_dx=σ_min(A)/σ_max(A) 与列支撑判定：c_i、c_j 可隔离 ⇔ 存在**可采纳的单部件干预**使二者签名不同。DIA 输出 `unidentifiable` 类（如透明物体下 c_vis~c_geo）、`isolability_margin`、ker(A)。**不可分辨必须在动手前显式标出，而不是事后用 argmax 掩盖。**
- **定义 240（主动良性消融 ABA）**：a*=argmax_a I(D; e^{do(a)} | e)，s.t. 预测 f≤f_safe、应变≤ε_strain、时间≤T_max、可逆、有恢复计划。即把 AFA 的「固定 ℋ 互信息」升级为「诊断格期望熵下降」。增益<δ_dx 或无可采纳消融时，不强行隔离，声明 unidentifiable 并走可能诊断包络。
- **定义 241（安慰剂/元消融自检 PBT）**：对先验高可信健康的 c_0 施加**应无因果效应**的 sham 消融 a_0；若 Cert/Poss 或后验变化 δ>τ_placebo，则 `diagnoser_unreliable=True`。再做元消融：替换残差生成/冲突提取/似然模块，诊断应稳定于非本质模块。**对诊断器本身做消融，是「已归因就更自信」的在线解药。**
- **定义 242（确定/可能安全更新 CSU）**：Cert≠∅→对每个 c∈Cert 定向处置（如 c_ft∈Cert 则 r_force↑、零力窗重标定、不降几何）；Cert=∅ 且 Poss≠∅→对 Poss 取保守包络 r=√(Σ_{c∈Poss}r_c²)，但**不宣称具体原因**；unidentifiable→对 U∪Poss 取最粗包络并禁不可逆动作。替代 VISTA 的「argmax 或 ambiguous」二分。
- **定义 243（消融预算与可采纳性）**：预算 B=(F_max, ε_strain, T_max, n_switch, reversible)。消融可采纳 ⇔ 预测峰值力≤F_max ∧ 应变≤ε_strain ∧ 时间≤T_max ∧ 存在恢复计划。虚拟消融只耗算力；物理消融仅在虚拟无法分离（sim-to-real 差）时启用。
- **定义 244（CSP-D 块级诊断规划）**：规划节点携带诊断格状态；每条块边需 Valid(J_diva)、k*≥1，且对 **所有 d∈D**（或 Cert+包络）安全裕度≥0。可插入 `ablate_probe`、`placebo_test`、`null_test` 元技能；代价增 λ_dx·H(D) 与 λ_abl·预算占用。
- **定义 245（AIC-D 对抗诊断认证）**：ℰ_D=ℰ_V×ℰ_abl×ℰ_dx。ℰ_abl 含消融欺骗、消融泄漏（干预实际作用于多部件）、sim-to-real 失配；ℰ_dx 含共因签名碰撞、安慰剂碰撞、诊断投毒。要求：∀ε∈ℰ_D，要么 Cert/Poss 健全，要么输出 unidentifiable 并安全降级。n_cert 128→160。
- **定义 246（J_diva 证书）**：J_diva=(J_vista, D, Cert, Poss, isolability_status, unidentifiable_pairs, ablation_provenance, placebo_passed, diagnoser_reliable, ablation_budget_used, aic_d_ver)。Valid ⇔ Valid(J_vista) ∧（Cert≠∅ ∨ 对 Poss 包络 ∨ unidentifiable→安全模式）∧ placebo_passed ∧ 全部物理消融可采纳 ∧ provenance 哈希一致。
- **定义 247（DIVA 闭环算子）**：语义流 [LiDAR→LSF→USR/MEL→VPG→ACH→阶段切分→VCV→CPDM→ICR 消融/冲突→MHD 碰集→DIA→ABA/PBT→CSU→WCV-V→CSP-D/TSL-D→CSC→执行 k*→EV_exec→OLP→DIR→SSB→AIC-D]；实时流 [锚点读→残差采集→良性消融执行→CSC 早停→CSU 编译→π_σ 派发→J_diva 构建]。

## 2. 关键算法骨架

```python
# ICR + MHD + DIA：消融 → 冲突 → 碰集 → 确定/可能（语义流）
A = interventional_signature(model, admissible_ablations)   # 单部件消融测得
conflicts = detect_conflicts(SD, obs)                        # 极小不一致的「正常」假设集
D = minimal_hitting_sets(conflicts)                          # 未知/复合故障都在这里
cert, poss = intersect(D), union(D)
unidentifiable = dia.ker_analysis(A)                         # 透明/共因 → 显式标注
if cert:
    csu.targeted(cert)                                       # 只动确定的部件
elif poss and not unidentifiable:
    csu.envelope(poss)                                       # 可能包络，不宣称原因
else:
    csu.coarsest(poss, unidentifiable); forbid_irreversible()

# ABA：用最省的良性消融换确定性
a = aba.choose(D, budget, f_safe)                            # argmax I(D; e^{do(a)}|e)
if a and pbt.admissible(a):
    execute_ablation(a); conflicts = detect_conflicts(SD, obs); D = minimal_hitting_sets(conflicts)

# PBT：对诊断器本身做安慰剂测试
if pbt.placebo_shifts_decision(D):
    diagnoser_reliable = False; csu.coarsest(poss, unidentifiable)
```

## 3. 保证概要与推导要点

- **引理 9（干预对比的可辨识性）**：可加故障模型 e=Aθ+ε 下，θ 可辨识 ⇔ rank(A)=|C|；A 的列由单部件干预测得，故「共因混淆」只在**不存在可采纳单部件干预**时才残留，且恰好等于 ker(A)。这比 VISTA 的观测签名 S 更强：S 的列依赖故障类型库，A 的列依赖干预本身。
- **引理 10（最小碰集诊断的健全性与夹逼）**：Reiter 意义下，最小诊断集恰为全部冲突集的最小碰集；任意真实最小诊断 d* 满足 Cert⊆d*⊆Poss。故 Cert 是「一定坏」的可靠下界，Poss 是「可能坏」的可靠上界——VISTA 从未给出这种 sandwich。
- **定理 9（DIVA 开集诊断-安全）**：在 A94–A98 下，(i) 未知/复合故障以未命名部件集表示，无枚举；(ii) Cert/Poss 夹住真实最小诊断；(iii) DIA 报 unidentifiable 时 J_diva 禁止定向动作，只能包络/安全模式，从而杜绝「归因错误却更自信」；(iv) PBT 失败即 diagnoser_reliable=False、证书失效、保守回退；(v) 物理消融零伤害且可逆；(vi) 实时流只做消融执行与残差采集。
- **定理 10（消融调度近最优）**：诊断格上的期望信息增益对消融集合单调子模；在预算 B 与可采纳约束下，贪心达到 (1−1/e) 近似；若存在能完全分离的干预，则所需单部件消融数 ≤ 隔离所需的最小 group-testing 规模。
- **实时性**：消融执行+残差采集 <0.1ms，冲突/碰集（|C|≤8）<1.5ms 在语义流，ABA <20ms，PBT <1ms；实时路径仍 ≤2.5ms（A93 修订契约）。

## 5. 本轮最大风险

**一句话**：DIVA 的全部健全性建立在「CPDM 的部件分解正确、且单部件消融真的只作用于一个部件」之上；一旦存在未建模的共因通路，或消融泄漏到多个部件（物理/仿真皆可能），冲突集本身就是错的，最小碰集会给出一个**可证的错误确定诊断**——系统因「已经证明」而比 VISTA 更自信地执行错误动作，且安慰剂测试若恰好落在同一共因通路上也会被一起骗过。

## 2. 形式化定义（完整版）

**定义 233（DIVA 闭环）** DIVA 是 VISTA 的「开集诊断 + 干预消融」升级：保留 VISTA 的「语义流 ∘ 实时流」骨架与 VPG/ACH/VCV/CSC/WCV-V/CSP 组件，用 CPDM 取代固定故障假设集 ℋ，用 ICR 产生干预残差与冲突集，用 MHD 生成最小碰集诊断，用 DIA 预先标出不可分辨方向，用 ABA 做主动良性消融，用 PBT 做诊断器自检，用 CSU 执行确定/可能安全更新，并原位升级 CSP-D/AIC-D/J_diva。不变式：**诊断、碰集、可诊断性分析、消融规划、证书构建只在语义流与低频线程；实时路径只做良性消融执行、残差采集、CSC 早停与派发，零学习写操作。**

**定义 234（部件-参数诊断模型 CPDM）** 把系统分解为部件集 C={c_geo（几何先验/地图）, c_ft（F/T 与触觉）, c_model（接触/动力学模型）, c_vis（视觉感知/世界模型）, c_policy（块策略）, c_kin（运动学/标定）, c_calib（时间同步/外参）}。每个部件有正常模型 M_c(θ_c) 与异常谓词 ¬ok(c)；系统描述
SD = ∧_{c∈C} [ok(c) ⇒ constraint_c(θ_c; u, y)]。
关键区别：第 65 轮的 ℋ={H0,H_geo,H_force,H_model,H_vis,H_policy} 是**故障类型枚举**；CPDM 只声明「哪些部件正常」，故障类型是**被推断出来的**，不是被假设出来的。未知故障即一个未命名的 ¬ok(c)，复合故障即 |{c:¬ok(c)}|>1。

**定义 235（干预消融算子）** 定义干预 do(ablate(c,mode))：
- `virtual`：在数字孪生/世界模型里把 c 的贡献替换为标称值，得到反事实预测（零物理风险，仅耗算力）；
- `substitute`：以标称模型或历史回放替换 c；
- `suppress`：把 c 的观测通道置零（如视觉置为遮挡、力置为零）；
- `physical-benign`：只允许**可逆、零伤害、有恢复计划**的物理干预，如零力窗（自由空间重标定）、短暂可控遮挡、切换模态采样、亚安全阈值的微触。
物理消融必须满足定义 243 的可采纳性；不满足者一律退回 `virtual`。消融算子是对**模型**的干预，故其因果性以 CPDM 正确为前提（见风险）。

**定义 236（干预残差与签名矩阵）** 名义残差 e=y−ŷ_full；对消融 a 得到 ŷ_a 与 e_a=y−ŷ_a；干预对比 Δ_c = e − e_a（向量）或标量 ‖e‖−‖e_a‖。由**单部件消融**测得签名矩阵 A∈ℝ^{r×|C|}，其第 c 列为 Δ_c 在各残差通道上的取值。可加故障模型 e=Aθ+ε 下，θ 可辨识 ⇔ rank(A)=|C|，可诊断裕度 κ_dx=σ_min(A)/σ_max(A)，不可辨识方向恰为 ker(A)。与 VISTA 的观测签名 S 相比：S 的列来自**故障类型库**，A 的列来自**干预本身**——因此 A 能把「同一观测签名、不同因果结构」的故障分开，只要存在可采纳的单部件干预。

**定义 237（冲突集与最小碰集诊断 MHD）** 给定 SD 与观测 y，若部件子集 O⊆C 满足「假设 O 中所有部件都正常」时约束组不可满足（不存在 θ 同时满足），且 O 极小，则 O 是一个**冲突集**。记全部冲突集为 𝒞。**最小诊断集** D 为 𝒞 的**最小碰集**（与每个冲突集相交且极小的部件集合）：
D = MHS(𝒞) = { d⊆C : d 是碰集且无真子集是碰集 }。
由 Reiter 一致性诊断定理，D 恰为所有能解释观测的最小「异常部件集」。未知故障以未命名部件出现，复合故障以 |d|>1 出现，**全程不需要故障类型库**。

**定义 238（诊断格、确定/可能与后验）** 最小诊断按 ⊆ 构成诊断格。定义
Cert = ∩_{d∈D} d（一定坏的部件），Poss = ∪_{d∈D} d（可能坏的部件）。
对任意真实最小诊断 d*，有 Cert ⊆ d* ⊆ Poss（见引理 10）。后验
P(d|e) ∝ P(e|d)·P(d)，
其中 P(e|d) 由 A 与残差拟合，P(d) 取部件失效率先验（如 Weibull）乘稀疏先验（Occam，偏好 |d| 小）。诊断熵 H(D)=−Σ_d P(d|e) log P(d|e)。**安全动作以 Cert/Poss 索引，而不是以 argmax 标签索引。**

**定义 239（可诊断性与可隔离性 DIA）** 由 A 的秩、条件数与列支撑定义：
- c_i 与 c_j **可隔离** ⇔ 存在可采纳的单部件干预使 A_{:,i} 与 A_{:,j} 不成比例（结构可隔离更强：支撑不同）；
- `unidentifiable` 类 U = { c : ker(A) 含 c 方向 }，典型如透明/镜面物体下 c_vis 与 c_geo 共享同一失效源、且无法单独干预；
- `isolability_margin` = 不同诊断签名间的最小归一化距离。
DIA 在**动手之前**输出 U 与裕度。若真实故障方向落入 ker(A)，J_diva 禁止定向动作，只能包络或安全模式——这把第 65 轮「共因下强行归因」变成「共因下显式承认分不清」。

**定义 240（主动良性消融 ABA）** 探针集 A_benign = {visual_probe, occlusion_probe, null_test, modality_switch, micro_tap, ablate_component}。选择
a* = argmax_{a∈A_benign} I(D; e^{do(a)} | e)，
s.t. 预测 f_n≤f_safe(φ̂,f̂_vis)、预测应变≤ε_strain、时间≤T_max、可逆且有恢复计划。
即把第 65 轮 AFA 的「最大化固定 ℋ 的互信息」升级为「**最大化诊断格的期望熵下降**」——探针目的从「分清楚六类谁」变成「用最省的实验把可能诊断集缩小」。若最大增益<δ_dx、或物体易损（f_safe<f_min_probe）、或无可采纳消融，则放弃物理探针，声明 unidentifiable 并走可能诊断包络。

**定义 241（安慰剂/元消融自检 PBT）** 两层自检：
1. **安慰剂**：选先验高可信健康的 c_0（或由冗余通道交叉确认），施加**应无因果效应**的 sham 消融 a_0；若 Cert/Poss 或后验的总变差 δ>δ_placebo，则判 `diagnoser_unreliable=True`。
2. **元消融**：把残差生成器、冲突提取器、似然/先验模型逐一替换为标称/简化版本，若诊断结论对这些**非本质模块**敏感，则说明诊断器依赖了不应依赖的通路。
PBT 是「对诊断器本身做消融实验」，也是唯一能在线戳破「已归因就更自信」的低成本手段。

**定义 242（确定/可能安全更新 CSU）** 依诊断格分三档：
- **Cert≠∅**：对每个 c∈Cert 定向处置。c_ft∈Cert→r_force↑、零力窗重标定、**不降几何**；c_geo∈Cert→r_geo↑；c_model∈Cert→r_model↑ 且切柔顺；c_vis∈Cert→w_vis↓；c_policy∈Cert→H↓、k↓。
- **Cert=∅ 且 Poss≠∅**：对 Poss 取保守包络 r=√(Σ_{c∈Poss} r_c²)，但**不宣称具体原因**（因为没有任何部件被证明坏）。
- **unidentifiable≠∅**：对 U∪Poss 取最粗包络，禁不可逆动作，必要时 safe_idle + 柔顺退让。
与第 65 轮相比：不再出现「argmax 选错→只膨胀错球」；确定性由证据挣得，而不是由分类器宣称。

**定义 243（消融预算与可采纳性）** 预算 B=(F_max, ε_strain, T_max, n_switch, reversible)。消融 a 可采纳 ⇔
pred_peak_force(a)≤F_max ∧ pred_strain(a)≤ε_strain ∧ time(a)≤T_max ∧ ∃ 恢复计划 restore(a)。
虚拟消融只耗算力，不占物理预算；物理消融优先选零力窗（自由、可逆），其次模态切换，最后才是微触。所有物理消融必须写入 ablation_provenance 并可回放审计。

**定义 244（CSP-D 块级诊断规划）** 在 CSP 的层级 A* 上以块为边，节点状态携带诊断格 D。每条块边需：
Valid(J_diva) ∧ k*≥1 ∧ ∀d∈D（或 Cert+Poss 包络）∀s≤k*: ρ_safe(s|d)≥0。
TSL 技能 σ 绑定典型诊断签名分布；实际 A 投影到该技能签名子空间的 Mahalanobis 距离>τ_dx 即判技能 OOD。规划器可插入元技能 `ablate_probe`（ABA）、`placebo_test`（PBT）、`null_test`（零力窗）。软约束代价增 λ_dx·H(D) 与 λ_abl·已用预算，鼓励「先做便宜实验再行动」。

**定义 245（AIC-D 对抗诊断认证）** 干扰集
ℰ_D = ℰ_V × ℰ_abl × ℰ_dx。
ℰ_abl 含：消融欺骗（对抗者让故障部件的消融看似无效，或让健康部件看似有效）、消融泄漏（一次物理干预实际作用于多个部件，破坏单部件假设）、sim-to-real 失配（孪生里消融有效、真机无效）。ℰ_dx 含：共因签名碰撞（c_vis 与 c_geo 列成比例）、安慰剂碰撞（对抗者让 sham 也产生响应）、诊断投毒（污染似然/先验/冲突提取）。ρ_dir 在 ℰ_D 上重算（n_cert 128→160，其中 32 给消融/诊断对抗），J_dir 增 ablation_attack_ver、diagnoser_integrity_ver。要求：∀ε∈ℰ_D，要么 Cert/Poss 健全，要么输出 unidentifiable 并安全降级；**共因/泄漏下不要求诊断正确，只要求不给出错误的确定诊断**。

**定义 246（DIVA 证书 J_diva）** J_diva=(J_vista, D, Cert, Poss, isolability_status, unidentifiable_pairs, ablation_provenance, placebo_passed, diagnoser_reliable, ablation_budget_used, aic_d_ver)。验证规则：
Valid(J_diva) ⇔ Valid(J_vista)
∧ (Cert≠∅ ∨ 已按 Poss 取包络 ∨ (unidentifiable≠∅ ∧ 已进安全模式))
∧ placebo_passed ∧ diagnoser_reliable
∧ 所有物理消融可采纳（定义 243）且 provenance 哈希一致
∧ aic_d_ver 为当前版本。
审计链新增：为什么认为这些部件坏了（冲突集与碰集）、哪些部件分不清（ker(A)）、做过哪些消融（provenance）、安慰剂是否通过、确定性是「证据挣得」还是「包络兜底」。

**定义 247（DIVA 闭环算子）** 语义流：[LiDAR→LSF→USR/MEL→VPG→ACH 生成块→阶段切分→VCV→CPDM 约束实例化→ICR 消融/残差/冲突→MHD 最小碰集→DIA 可诊断性→ABA 主动消融/PBT→CSU 确定/可能处置→WCV-V→CSP-D/TSL-D→CSC 认证前缀→Shield→执行 k* 步→EV_exec→RSC→OLP→DIR→SSB→AIC-D]；实时流：[锚点读→残差采集→良性消融执行→阶段判定→CSC 早停→CSU 编译→WCV-V 编译→π_σ 前缀派发→J_diva 构建]。

### IP-224/225/226 CPDM + ICR + MHD

```python
class ComponentDiagnosisModel:
    """部件-参数模型：只声明「哪些部件正常」，故障类型由推断得到。"""
    COMPONENTS = ('c_geo', 'c_ft', 'c_model', 'c_vis', 'c_policy', 'c_kin', 'c_calib')

    def constraints(self, obs, c):
        return self.models[c].constraint(obs)          # ok(c) ⇒ constraint_c

    def consistent(self, obs, assume_ok):
        # 假设 assume_ok 内所有部件正常时，是否存在 θ 同时满足约束
        return solve_feasible([self.constraints(obs, c) for c in assume_ok])


class InterventionalConflict:
    """消融 → 干预残差 → 冲突集。单部件消融是可辨识性的来源。"""
    def signature(self, model, obs, admissible):
        A = np.zeros((len(obs.residuals), len(model.COMPONENTS)))
        for j, c in enumerate(model.COMPONENTS):
            a = admissible.single_component(c)         # virtual 优先
            if a is None:
                A[:, j] = np.nan                        # 不可单部件干预 → DIA 标记
                continue
            e_full = obs.y - model.predict(obs)
            e_a = obs.y - model.predict_ablated(obs, a)
            A[:, j] = e_full - e_a                      # 干预对比
        return A

    def conflicts(self, model, obs):
        # 枚举极小不一致的「正常」假设集（|C| 小，可穷举/用 QuickXplain）
        out = []
        for O in powerset(model.COMPONENTS):
            if not model.consistent(obs, O):
                if all(model.consistent(obs, O - {c}) for c in O):
                    out.append(frozenset(O))            # 极小冲突集
        return out


def minimal_hitting_sets(conflicts):
    """Reiter：最小诊断 = 冲突集族的最小碰集。未知/复合故障天然被表示。"""
    D = []
    for cand in powerset(all_components(conflicts), increasing_size=True):
        if all(cand & cs for cs in conflicts):
            if not any(d < cand for d in D):
                D.append(frozenset(cand))
    return D


def certain_possible(D):
    cert = set.intersection(*map(set, D)) if D else set()
    poss = set.union(*map(set, D)) if D else set()
    return cert, poss
```

### IP-227 DIA 可诊断性分析

```python
class DiagnosabilityAnalysis:
    def analyze(self, A):
        # 去掉无法单部件干预的列（NaN）后做秩/条件数
        cols = [j for j in range(A.shape[1]) if np.all(np.isfinite(A[:, j]))]
        A_obs = A[:, cols]
        s = np.linalg.svd(A_obs, compute_uv=False)
        kappa = s[-1] / s[0] if s[0] > 0 else 0.0
        rank = int(np.sum(s > 1e-8 * s[0]))
        unidentifiable = [j for j in range(A.shape[1]) if j not in cols]
        # 列成比例 = 不可隔离（共因）
        for i in range(len(cols)):
            for j in range(i + 1, len(cols)):
                if _proportional(A_obs[:, i], A_obs[:, j]):
                    unidentifiable += [cols[i], cols[j]]
        return {'rank': rank, 'kappa_dx': kappa,
                'unidentifiable': sorted(set(unidentifiable)),
                'isolability_margin': self._margin(A_obs)}
```

### IP-228 ABA 主动良性消融

```python
class ActiveBenignAblation:
    PROBES = ('visual_probe', 'occlusion_probe', 'null_test',
              'modality_switch', 'micro_tap', 'ablate_component')

    def choose(self, D, budget, f_safe, fragile, model, A):
        if fragile:
            # 易损：只用零接触、可逆探针
            return self._best([p for p in ('visual_probe', 'occlusion_probe', 'null_test')
                               if budget.admissible(p, f_safe)], D, model)
        best, best_ig = None, -np.inf
        for a in self.PROBES:
            if not budget.admissible(a, f_safe):
                continue
            ig = expected_diagnosis_info_gain(D, a, model, A)   # I(D; e^{do(a)} | e)
            if ig > best_ig:
                best, best_ig = a, ig
        return best if best_ig >= DELTA_DX else None
```

### IP-229 PBT 安慰剂/元消融自检

```python
class PlaceboSelfTest:
    def run(self, diagnoser, obs, cert, poss, healthy_prior):
        c0 = argmax(healthy_prior)                 # 先验最健康的部件
        a0 = sham_ablation(c0)                     # 应无因果效应的假消融
        cert2, poss2 = diagnoser.rediagnose(obs, do(a0))
        delta = total_variation(cert | poss, cert2 | poss2)
        placebo_passed = delta <= DELTA_PLACEBO
        # 元消融：替换非本质诊断模块，结论应稳定
        stable = all(diagnoser.rediagnose_with(obs, module=m) == (cert, poss)
                     for m in diagnoser.NONESSENTIAL_MODULES)
        return {'placebo_passed': placebo_passed,
                'meta_stable': stable,
                'diagnoser_reliable': placebo_passed and stable}
```

### IP-230 CSU 确定/可能安全更新

```python
def csu_update(D, balls, w_vis, H, unidentifiable):
    cert = set.intersection(*map(set, D)) if D else set()
    poss = set.union(*map(set, D)) if D else set()
    if cert:
        for c in cert:
            balls = directed_update(c, balls, w_vis, H)      # 只动确定的部件
        return balls, w_vis, H, 'targeted'
    if unidentifiable:
        # 最粗包络 + 禁不可逆
        r = np.sqrt(sum(balls['r_' + c] ** 2 for c in (poss | set(unidentifiable))
                        if 'r_' + c in balls))
        return coarsen(balls, r), w_vis, H, 'safe_mode'
    if poss:
        r = np.sqrt(sum(balls['r_' + c] ** 2 for c in poss if 'r_' + c in balls))
        return envelope(balls, r), w_vis, H, 'envelope'      # 不宣称原因
    return balls, w_vis, H, 'healthy'
```

### IP-233 DIVA 闭环算子（整合）

```python
def DIVA_round(M, obs, delta_f_req):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    # ———— 语义流（10–100Hz）————
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    y_vis = M.f_vis(img, depth, flow)
    phi_hat_geo, *_ = M.mel.infer_by_mode(M.ocb_skill.choose().mel_mode,
                                          V, T, P, L, x_prime)
    A_chunk = M.ach.propose(x_prime, H=M.H)
    visual = M.vpg.verify_and_predict(y_vis, A_chunk, M.mws.last_contacts)

    # 1) CPDM + ICR：消融签名与冲突集
    A_int = M.icr.signature(M.cpdm, obs, M.ablations)
    conflicts = M.icr.conflicts(M.cpdm, obs)
    # 2) MHD：最小碰集 → 确定/可能
    D = minimal_hitting_sets(conflicts)
    cert, poss = certain_possible(D)
    # 3) DIA：先看能不能分清
    diag = M.dia.analyze(A_int)
    unidentifiable = diag['unidentifiable']
    # 4) ABA + PBT：用最省的良性消融挣确定性，并自检
    if not cert and unidentifiable == []:
        a = M.aba.choose(D, M.budget, M.f_safe, M.object_fragile, M.cpdm, A_int)
        if a is not None:
            M.execute_ablation(a)
            conflicts = M.icr.conflicts(M.cpdm, obs)
            D = minimal_hitting_sets(conflicts)
            cert, poss = certain_possible(D)
    pbt = M.pbt.run(M.diagnoser, obs, cert, poss, M.healthy_prior)
    reliable = pbt['diagnoser_reliable']
    # 5) CSU：确定→定向、可能→包络、不可分辨→安全模式
    M.balls, M.w_vis, M.H, mode = csu_update(
        D if reliable else [], M.balls, M.w_vis, M.H, unidentifiable)
    # 6) 规划 + 认证前缀
    goal = M.dms.parse_goal((M.usr.U_ep, M.usr.U_al))
    tau = M.csp_d.plan_chunks(goal, x_prime, phi_hat_geo, M.balls, D, diag)
    k_star = M.csc.certified_prefix(tau.A, D, M.m, M.alpha_chunk)
    # 7) 实时执行 + 早停
    K_safe, EV_exec, cert_exec = realtime_step_diva(M, delta_f_req, tau, k_star, x_prime)
    # 8) 在线更新（纯语义流）
    evidence = M.olp.fuse_evidence(x_prime, W_meas, tactile, visual, D)
    M.olp.online_step(evidence, execution_loss_grad(K_safe, EV_exec, M.balls))
    M.rsc.update(EV_exec, W_meas, phi_hat_geo, D, M.balls)
    M.dir.update(sample_batch_from_history(32))
    rho_dir = M.aic_d.certify(tau, x_prime, phi_hat_geo, M.balls, D, diag)
    return M, K_safe, EV_exec, build_j_diva(
        cert_exec, J_vista=M.j_vista, diagnosis_set=D, cert=cert, poss=poss,
        isolability_status=diag, unidentifiable_pairs=unidentifiable,
        ablation_provenance=M.ablations.log, placebo_passed=pbt['placebo_passed'],
        diagnoser_reliable=reliable, ablation_budget_used=M.budget.used,
        aic_d_ver=AIC_D_VERSION)
```

## 4. 推导

**引理 9（干预对比的可辨识性）** 设可加故障模型 e=Aθ+ε，A 由单部件消融测得，ε 零均值。则 θ 可辨识 ⇔ rank(A)=|C|；最小二乘误差协方差 ∝ (AᵀΣ⁻¹A)⁻¹，κ_dx=σ_min/σ_max 控制方差放大。若某部件 c 不存在可采纳的单部件干预（A_{:,c} 不可测），则 c 方向不可直接辨识；可辨识的只是 A 列空间上的投影，不可辨识方向为 ker(A)。**与 VISTA 的观测签名 S 的关键差别**：S 的列来自「预置故障类型的注入」，A 的列来自「对部件的干预」。因此只要干预能单独作用于 c，即使两个故障在观测上完全同签名（共因），A 也能把它们分开；反之若干预本身无法单独作用，DIA 会在动手前把该方向标为不可辨识，而不是事后硬归因。∎

**引理 10（最小碰集诊断的健全性与夹逼）** 由 Reiter 一致性诊断理论：若冲突集族 𝒞 覆盖了全部「所有部件正常」假设下的不一致，则最小诊断集 D 恰为 𝒞 的全部最小碰集；每个 d∈D 是能解释观测的极小异常部件集。对任意真实最小诊断 d*（即真实异常集的最小解释），有 Cert=∩D ⊆ d* ⊆ ∪D=Poss。故 Cert 是「一定坏」的可靠下界，Poss 是「可能坏」的可靠上界。未知故障以未命名部件进入 d*，复合故障以 |d*|>1 进入，均无需故障类型库。∎

**定理 9（DIVA 开集诊断-安全）** 在 A94–A98（CPDM 正确、冲突集完备、单部件干预纯净、消融可采纳、PBT 有效）下：
1. **开集性**：诊断由冲突集的碰集生成，未知/复合故障不被硬塞进任何预置标签；VISTA 的「最近假设」误归因被结构性消除。
2. **夹逼健全**：Cert⊆d*⊆Poss（引理 10），故基于 Poss 的安全包络覆盖真实故障，基于 Cert 的定向动作只触碰确定故障。
3. **不虚假自信**：若真实故障方向落入 ker(A)（DIA 报 unidentifiable），J_diva 禁止定向动作，只允许包络/安全模式；证书因此**不能**在不可辨识时声称「已归因」。
4. **自检门**：PBT 失败→diagnoser_reliable=False→证书失效→保守回退；共因缺陷无法同时骗过 sham 消融（除非恰好同通路，见风险）。
5. **物理安全**：ABA 只选可采纳消融（零伤害、可逆），CSP-D 要求对所有可能诊断安全，CSC 限制 k*≤m。
6. **实时性**：消融执行与残差采集在实时流，诊断/碰集/消融规划在语义流，实时路径 ≤2.5ms（A93）。
综上，DIVA 把 VISTA 的「有限假设集 + 独立性」两个隐藏假设替换为「部件模型正确 + 单部件干预纯净」，并新增了 DIA/PBT 两道显式检查来暴露这两个假设何时失效。∎

**定理 10（消融调度的近最优性）** 诊断格上的期望信息增益 I(D; e^{do(a)}|e) 作为消融集合的函数是单调子模的（条件熵的收益递减）。在预算 B 与可采纳约束下，贪心选择达到最优的 (1−1/e) 近似。若存在能把 D 完全分离的干预序列，则其长度不超过 group-testing 下界 ⌈log₂|D|⌉（当干预可作用于部件组时）；若只允许单部件消融，则最坏长度为 |C|−1。该结论给出「先做便宜实验、再行动」的严格理由，也说明为什么 ABA 应优先虚拟消融（零物理成本、可批量 group-testing）。∎

**命题（相对 VISTA 的改进）** 第 65 轮在归因模糊时二选一：要么 argmax（可能错、只膨胀错球），要么 ambiguous（不处置、过度保守）。DIVA 用 Cert/Poss 取代该二分：
- 当 Cert≠∅：定向动作与 VISTA 的「正确 argmax」等价，且**不会**因未知复合故障而选错；
- 当 Cert=∅ 且 Poss 小：包络只覆盖可能部件，比 VISTA 的全局膨胀更紧；
- 当 unidentifiable：显式进入安全模式，杜绝「已归因就更自信」。
代价是 Cert=∅ 时更保守；ABA 用可采纳消融把 Cert 从空集「挣」回来，故保守性可被主动实验逐步消除。∎

## 7. 已知风险

**一句话**：DIVA 的全部健全性建立在「CPDM 的部件分解正确、且单部件消融真的只作用于一个部件」之上；一旦存在未建模的共因通路，或消融泄漏到多个部件（物理/仿真皆可能），冲突集本身就是错的，最小碰集会给出一个**可证的错误确定诊断**——系统因「已经证明」而比 VISTA 更自信地执行错误动作，且安慰剂测试若恰好落在同一共因通路上也会被一起骗过。

**次级风险与缓解**：
1. **部件模型错误（最根本）**：CPDM 漏掉一个共因通路，则冲突集不完备、碰集诊断不可靠；缓解：DIA 的残差检验 + PBT 元消融 + AIC-D 的消融泄漏攻击；持续用真实故障回灌扩充部件模型，并把「模型自身异常」作为一个可诊断部件 c_model。
2. **消融泄漏**：物理干预实际影响多个部件，破坏单部件假设；缓解：消融前后做局部性检验（非目标部件的残差应无显著变化）、优先虚拟消融、泄漏检测失败即退化为观测签名 + 包络。
3. **冲突集枚举爆炸**：|C| 增大时 2^{|C|} 不可行；缓解：QuickXplain/HS-tree 只生成极小冲突、增量式碰集、|C| 上限与分层诊断（先粗粒度部件组）。
4. **未知故障不可辨识**：真实故障方向落 ker(A)；缓解：承认 unidentifiable、安全模式、引入第三物理独立通道（IMU/本体感觉/电流）扩展 A 的秩。
5. **安慰剂碰撞**：对抗者让 sham 也响应，PBT 误判；缓解：多个独立 sham、随机化安慰剂、与 AIC-D 联合认证。
6. **消融预算耗尽仍 Cert=∅**：长期保守导致 liveness 下降；缓解：预算调度 + 允许「包络下继续执行安全子任务」+ 人类求助。
7. **sim-to-real 差**：孪生消融有效、真机无效；缓解：虚拟消融只用于生成假设，物理确认才升级为 Cert；跨域校准写入 provenance。
8. **实时预算**：ICR/碰集/DIA 必须留在语义流；缓解：ROI/部件级缓存、增量碰集、与 VISTA 的实时路径共享残差采集。
