# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「关节驱动」×「灵巧操作」）

> 第 54 轮把技能从"能力"细化为动作空间剖面 α_S，并用云边映射 γ_ce 与联合证书 J 串起规划与执行。但 α_S 仍停留在**抽象动作度量空间**：它回答"技能在哪些动作上有定义"，却没有回答"这些动作能否被真实关节驱动在接触约束下**实现并稳住**"。本轮把动作空间下沉到**关节驱动空间 U(q)** 与**接触模式空间 M**，核心矛盾：H22 动作空间可达 ≠ 驱动空间可实现（realizability gap）；H23 任务空间轨迹兼容 ≠ 接触模式可切换（contact-mode gap）；H24 鲁棒性 ρ 并非独立先验，而是由驱动权威余量 h 与接触模式稳定性**诱导**出来的物理量。

## 0. 直觉与动机

**灵感 1（关节驱动包络：能到达 ≠ 能稳住）**
直觉：机械臂/灵巧手真正能下的指令不是抽象的 a，而是关节力矩/速度/位置三元组 `u=(τ,q̇,q)`，且受 `τ_max`、`q̇_max`、功率/热约束、摩擦锥与非穿透约束。一个动作 a 若要通过逆动力学 `τ*(a)` 实现，却在某个关节上用掉 95% 额定力矩，它虽"到达"却没有余量抵抗扰动——**名义可达而鲁棒为零**。因此把 α_S 细化为**可实现关系** `R_S(a)⊆U(q)`，并定义**驱动权威余量** `h_S(a)=min_i(τ_i^max-|τ_i*(a)|)/τ_i^max`。直觉上：h 是"动作的物理存款"，ρ 只是这笔存款在扰动维上的可支出额度。

**灵感 2（灵巧操作 = 接触模式的可达与可切换）**
直觉：灵巧操作不是摆一个静态抓取姿势，而是在**接触状态机**中游走：贴附→静摩擦→滚动→滑动→再抓取。两个技能在任务动作空间上 Jaccard 很高，却可能一个要求"三点硬抓"、另一个要求"指尖开放滚动"，其接触模式根本不衔接。于是定义接触模式 `m∈M` 与**接触模式转移图 `H=(M,E_M)`**，每个技能携带模式路径 `π_S`；组合前必须做**模式衔接检查**，这把"动作兼容"升级为"接触状态兼容"。

**灵感 3（多关节耦合：余量是向量，不是标量）**
直觉：n 自由度驱动经惯性矩阵 M(q)、雅可比 J(q) 强耦合，某一关节的力矩饱和会经由零空间/动力学耦合吃掉其他关节的权威。任务空间兼容的两技能，可能一个处于可操作度高的构型、另一个逼近奇异。因此权威必须用**耦合条件数 κ(M)**、**可操作度 `w=√det(JJᵀ)`** 与**最小奇异值 σ_min(J)** 共同刻画，形成灵巧度证书。

**灵感 4（云边再分工：慢规划接触序列，快求解全身 QP）**
直觉：云端适合做"接触模式序列 + 物体级轨迹 + 抓取选择"（10–100ms 级），边端适合做"全身 QP + 力矩/阻抗控制"（1–10kHz 级）。云端计划 P_c 经**任务-驱动映射 γ_ta**（逆动力学 + 约束 QP）落到边端 u，可行性由 QP 松弛量 slack 度量。边端一旦检测到力矩饱和、滑移、接触丢失，就通过 Explain 回传，云端重排**接触模式序列**而不是仅重采样动作——这是比第 54 轮更本质的反馈闭环。

**灵感 5（三重证书：驱动 × 接触 × 鲁棒）**
直觉：第 54 轮的 `J=(ρ,A_cert,γ_ce,δ_a)` 仍以动作为中心。本轮把驱动包络 A_act、接触模式证书 D_cert 与 QP 松弛 slack 并入，得到 `J⁺=(ρ,A_cert,A_act,D_cert,γ_ta,δ_a,δ_u,slack,evidence)`。部署条件从"动作对齐"升级为"**动作对齐 ∧ 驱动有裕量 ∧ 接触可切换 ∧ QP 实时可行**"，四者缺一即否决。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（驱动空间与驱动包络）**
n 自由度系统的驱动空间 `U = ℝ^n_τ × ℝ^n_q̇`。在构型 q 与接触模式 m 下，驱动包络
```
U(q,m) = { (τ,q̇) | τ_i∈[τ_i^min,τ_i^max], |q̇_i|≤q̇_i^max,
           M(q)q̈+C(q,q̇)q̇+g(q)=τ+J_c^T λ,
           λ∈K(μ)（摩擦锥）, φ(q)≥0（非穿透） }
```
`U(q,m)` 是含接触的微分包含；任务动作 a 的**可实现关系** `R_S(a)={u∈U(q,m) | T(u)=a}`，T 为任务映射。

**定义 122（驱动权威剖面与余量谱）**
技能 S 的驱动权威剖面 `h_S: A×M → [0,1]`：
```
h_S(a,m) = min_i (τ_i^max - |τ_i^*(a,m)|) / τ_i^max
```
其中 τ*(a,m) 为最小范数实现力矩。余量谱 `η_S(d) = P_{a~p_T}(h_S(a,m) ≥ h_req(d))`。**鲁棒性被诱导**：`ρ_S(d) ≈ η_S(d)`，即 ρ 不是独立参数，而是驱动余量在扰动维 d 上的分布投影。

**定义 123（接触模式与转移图）**
接触模式 `m=(C_f, type)`，C_f 为接触对集合，`type∈{stick,slip,roll,free}`。**接触模式图** `H=(M,E_M)`，边 `(m→m')` 表示一次受控切换，代价 `c_mode(m,m') = (t_trans, e_trans, risk_trans)`。技能 S 的模式路径 `π_S=⟨m_0,...,m_k⟩`。

**定义 124（灵巧度证书）**
`D_cert(S) = (π_S, w_min, κ_max, σ_min, h_min, δ_contact)`：
- `w_min = min_{q∈Q_S} √det(J(q)J(q)^T)`；
- `κ_max = max cond(M(q))`；
- `σ_min = min σ_min(J(q))`（奇异接近度）；
- `h_min = min_{a,m} h_S(a,m)`；
- `δ_contact` 为接触状态估计不确定度。

**定义 125（任务-驱动映射与 QP 可行性裕度）**
`γ_ta: (a,m) → u` 由带约束的全身 QP 给出：
```
min_{q̈,τ,λ} ||J q̈ + J̇ q̇ - a||²_Σ + w_τ||τ||² + w_λ||λ||²
s.t. 动力学等式, λ∈K(μ), τ∈[τ^min,τ^max], q̇∈[q̇^min,q̇^max]
```
松弛量 `slack(a,m) ≥ 0` 为软约束越界量；`slack=0` 表示严格可行。**可实现判定**：`R_S(a)≠∅ ⇔ slack(a,m)=0`。

**定义 126（灵巧组合可行性）**
在乘积图 `G_S × H` 上，边 `(S_i,m_i)→(S_j,m_j)` 可行当且仅当
```
compat_task(S_i,S_j) ≥ θ_a
∧ c_mode(m_i^term→m_j^init) ≤ τ_mode
∧ h_min^{i⊗j} ≥ h_req
∧ σ_min(J) ≥ σ_req ∧ κ_max(M) ≤ κ_req
∧ slack(a,m_j)=0
```
即**任务兼容、模式衔接、驱动余量、非奇异、QP 严格可行**五重约束同时成立。

**定义 127（驱动-接触-鲁棒联合证书）**
`J⁺ = (ρ, A_cert, A_act, D_cert, γ_ta, δ_a, δ_u, slack, evidence)`，其中
- `A_act=(U_core,h_min,τ_margin_profile)` 为驱动包络证书；
- `D_cert` 为灵巧度证书；
- `δ_u` 为驱动实现误差 `||u_real-γ_ta(a,m)||`；
- `evidence` 至少含边端 QP 日志、力矩/电流曲线、接触事件序列。
部署判定 `deploy(J⁺,T)=1` 当且仅当
```
dom_J(T)=in ∧ δ_a<Θ_a ∧ h_min≥h_req(d) ∀d
∧ σ_min≥σ_req ∧ κ_max≤κ_req ∧ slack=0 ∧ risk(π_S)≤Θ_m
```

## 2. 关键算法 伪代码

### IP-121 AAP（Actuation Authority Profile）

```python
def actuation_authority_profile(skill, A_samples, contact_modes, dynamics):
    prof = {}
    for a in A_samples:
        for m in contact_modes:
            u_star, slack = inverse_dynamics_qp(dynamics, skill.q, a, m)
            if slack > 0:            # 严格不可实现
                prof[(a, m)] = 0.0
                continue
            h = min((tau_max[i] - abs(u_star.tau[i])) / tau_max[i]
                    for i in range(n_dof))
            prof[(a, m)] = h
    return prof                       # h_S(a,m)
```

### IP-122 CMG（Contact Mode Graph）

```python
def build_contact_mode_graph(contact_model, skills, tau_mode, theta_risk):
    H = nx.DiGraph()
    for m in enumerate_modes(contact_model):        # 惰性枚举
        H.add_node(m, formation=m.C_f, type=m.type)
    for m in H.nodes:
        for m2 in transition_candidates(m):         # 贴附/脱离/滚动/滑动
            c = contact_model.transition_cost(m, m2)  # (t,e,risk)
            if c.t <= tau_mode and c.risk <= theta_risk:
                H.add_edge(m, m2, cost=c)
    for s in skills:
        s.paths = k_shortest_mode_paths(H, s.m_init, s.m_goal, K=3)
    return H
```

### IP-123 DAC（Dexterity-Aware Composition）

```python
def dexterity_aware_compose(skills, H, task, theta):
    P = nx.DiGraph()                          # 乘积图 G_S × H
    for s in skills:
        for m in H.nodes:
            if m in s.paths:
                P.add_node((s.id, m))
    for (s1, m1) in P.nodes:
        for (s2, m2) in P.nodes:
            if s1.id == s2.id: continue
            if not task_compat(s1, s2, theta.theta_a): continue
            if not mode_linked(H, m1, m2, theta.tau_mode): continue
            h = min(s1.h_min, s2.h_min, compose_authority(s1, s2))
            if h < theta.h_req: continue
            if s1.sigma_min < theta.sigma_req or s1.kappa_max > theta.kappa_req:
                continue
            if slack(s1, a=None, m=m1) > 0: continue
            P.add_edge((s1.id, m1), (s2.id, m2),
                       cost=cost_align(s1, s2) + H[m1][m2]['cost'].t,
                       authority=h)
    path = a_star(P, source=task.start, goal=task.goal,
                  heuristic=lambda n: remaining_authority_bound(n))
    return path, joint_authority(path)
```

### IP-124 TAC（Task-to-Actuation Certificate）

```python
def task_to_actuation_cert(skill_seq, mode_path, dyn, a_budget, h_req):
    U_core, margins = [], {}
    for (s, m, a) in zip(skill_seq, mode_path, task_actions):
        u, slack = inverse_dynamics_qp(dyn, s.q, a, m)
        if slack > 0:
            return ('reject', 'qp_infeasible', (s.id, m, slack))
        h = min((tau_max[i] - abs(u.tau[i])) / tau_max[i]
                for i in range(n_dof))
        if h < h_req:
            return ('reject', 'authority_margin', (s.id, m, h))
        U_core.append(u)
        margins[s.id] = h
    delta_u = max_impl_error(U_core, dyn.calibration)
    if delta_u > a_budget:
        return ('reject', 'actuation_drift', delta_u)
    return ('ok', A_act(U_core, min(margins.values()), margins), delta_u)
```

### IP-125 DCC（Dexterous Cloud-Edge Contract）

```python
def dexterous_cloud_edge(T_desc, G, H, dyn, tau_qp_budget):
    P_c, mode_seq = cloud_plan(T_desc, G, H)        # 慢：模式序列+物体轨迹
    reports = []
    for (s, m, a) in zip(P_c.skills, mode_seq, P_c.actions):
        u, slack, t_qp = edge_qp_control(dyn, s, a, m)   # 快：全身 QP
        if t_qp > tau_qp_budget:
            return ('reject', 'realtime_miss', t_qp)
        if slack > 0 or torque_saturated(u) or slip_detected(dyn):
            exp = explain_contact(dyn, s, m, u)          # 接触级反向解释
            reports.append(exp)
            P_c = cloud_replan_modes(P_c, exp)           # 重排模式而非仅重采样
        if min_authority(u) < h_req:
            reports.append(explain_authority(s, u))
    return ('ok', P_c, reports)
```

### IP-126 ARC（Actuation-Robustness Certificate）

```python
def joint_certificate_v2(skill_seq, mode_path, gamma_ta, dyn,
                         delta_a_budget, delta_u_budget, h_req, rho_min):
    rho_comp = compose_robustness_chain([s.rho for s in skill_seq], K)
    if min(rho_comp.values()) < rho_min:
        return ('reject', 'robustness_fail', rho_comp)
    tac = task_to_actuation_cert(skill_seq, mode_path, dyn,
                                 delta_u_budget, h_req)
    if tac[0] != 'ok':
        return tac
    A_act, delta_u = tac[1], tac[2]
    D = dexterity_cert(skill_seq, mode_path)        # w_min, kappa_max, sigma_min
    if D.sigma_min < sigma_req or D.kappa_max > kappa_req:
        return ('reject', 'dexterity_fail', D)
    delta_a = max_alignment_error(gamma_ta, A_act.U_core)
    if delta_a > delta_a_budget:
        return ('reject', 'action_mismatch', delta_a)
    return ('ok', JointCertV2(rho_comp, A_act, D, gamma_ta,
                              delta_a, delta_u, slack=0))
```

### IP-127 DXC（Dexterous Transfer Certificate）

```python
def dexterous_transfer_certify(Jp_source, target_dyn, phi,
                               delta_h_budget, delta_m_budget):
    h_target = authority_transfer(Jp_source.A_act, target_dyn, phi)
    delta_h = Jp_source.A_act.h_min - h_target.h_min
    mode_map = contact_mode_map(Jp_source.D_cert.pi_S, target_dyn, phi)
    delta_m = contact_formation_drift(mode_map)
    if delta_h > delta_h_budget or delta_m > delta_m_budget:
        return ('reject', 'dex_budget_exceeded', delta_h, delta_m)
    if mode_map.risk > theta_mode_risk:
        return ('reject', 'contact_mode_risk', mode_map)
    return ('ok', DXC(Jp_source, target_dyn, h_target, mode_map,
                      delta_h, delta_m))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| AAP | O(|A_s|·|M|·QP(n))，QP≈O(n³) | O(|A_s|·|M|) | 驱动包络标定完备、热/摩擦约束入模 |
| CMG | O(|M|²·c_trans)（惰性枚举后大幅下降） | O(|M|+|E_M|) | 模式转移代价 sound、风险阈值保守 |
| DAC | O(|S||M| log(|S||M|) + |E|) | O(|S||M|) | 乘积图边条件 sound、启发式可采纳 |
| TAC | O(|P|·QP(n)) | O(|P|·n) | QP 可行 ⇔ 可实现、δ_u 有界 |
| DCC | 云 O(规划)+边 O(QP)·f_ctrl | O(|P|) | γ_ta Lipschitz、QP 实时、Explain 收敛 |
| ARC | O(|S|·|A| + |P|·QP(n)) | O(|A|+|P|) | 三重证书 sound、预算闭合 |

**正确性定理（Actuation-Grounded Dexterous Composition Soundness）**
假设 (A26)–(A28) 承接第 54 轮，并新增：**(A29)** 驱动包络由硬件在环标定，权威余量误差 `|h_real-h_sim|≤ε_h`；**(A30)** 单次接触模式切换成功概率 `≥1-β_m`，且切换时长 `≤τ_mode`；**(A31)** 边端 QP 在 f_ctrl 下 P95 满足 `t_qp≤τ_qp`。则
```
P_success ≥ (1-β_m)^{|π_S|} · [ 1 - Σ_d(1-ρ_min(d)) - β_E
            - P(δ_a>Θ_a) - P(h_min<h_req) - P(slack>0) - P(t_qp>τ_qp) ]
```
关键：**ρ 由 h 诱导**，**接触模式路径是组合的前置门**，**QP 严格可行是可实现的判定器**。该界为联合界（union bound），非紧但可审计。

## 6. 本轮最大风险

**一句话**：把鲁棒性下沉为驱动权威余量 h 与接触模式证书，理论上让"能到达"和"能稳住"统一，但全部 soundness 压在一个乐观假设上——**仿真标定的力矩余量与接触摩擦参数在真机上偏乐观**；一旦 h_min 被高估，系统恰会在接触最丰富、最需要鲁棒性的模式切换处饱和或滑移，故必须以 **硬件在环权威标定 + 温度/摩擦降额 + 接触模式回退** 三重护栏，绝不把仿真力矩余量当成真机可部署权威。

### IP-121 AAP

```python
def actuation_authority_profile(skill, A_samples, contact_modes, dynamics):
    prof = {}
    for a in A_samples:
        for m in contact_modes:
            u_star, slack = inverse_dynamics_qp(dynamics, skill.q, a, m)
            if slack > 0:
                prof[(a, m)] = 0.0
                continue
            h = min((tau_max[i] - abs(u_star.tau[i])) / tau_max[i]
                    for i in range(n_dof))
            prof[(a, m)] = h
    return prof
```

### IP-122 CMG

```python
def build_contact_mode_graph(contact_model, skills, tau_mode, theta_risk):
    H = nx.DiGraph()
    for m in enumerate_modes(contact_model):
        H.add_node(m, formation=m.C_f, type=m.type)
    for m in H.nodes:
        for m2 in transition_candidates(m):
            c = contact_model.transition_cost(m, m2)
            if c.t <= tau_mode and c.risk <= theta_risk:
                H.add_edge(m, m2, cost=c)
    for s in skills:
        s.paths = k_shortest_mode_paths(H, s.m_init, s.m_goal, K=3)
    return H
```

### IP-123 DAC

```python
def dexterity_aware_compose(skills, H, task, theta):
    P = nx.DiGraph()                          # G_S × H
    for s in skills:
        for m in H.nodes:
            if m in s.paths:
                P.add_node((s.id, m))
    for (s1, m1) in P.nodes:
        for (s2, m2) in P.nodes:
            if s1.id == s2.id: continue
            if not task_compat(s1, s2, theta.theta_a): continue
            if not mode_linked(H, m1, m2, theta.tau_mode): continue
            h = min(s1.h_min, s2.h_min, compose_authority(s1, s2))
            if h < theta.h_req: continue
            if s1.sigma_min < theta.sigma_req or s1.kappa_max > theta.kappa_req:
                continue
            if slack(s1, a=None, m=m1) > 0: continue
            P.add_edge((s1.id, m1), (s2.id, m2),
                       cost=cost_align(s1, s2) + H[m1][m2]['cost'].t,
                       authority=h)
    path = a_star(P, source=task.start, goal=task.goal,
                  heuristic=lambda n: remaining_authority_bound(n))
    return path, joint_authority(path)
```

### IP-124 TAC

```python
def task_to_actuation_cert(skill_seq, mode_path, dyn, a_budget, h_req):
    U_core, margins = [], {}
    for (s, m, a) in zip(skill_seq, mode_path, task_actions):
        u, slack = inverse_dynamics_qp(dyn, s.q, a, m)
        if slack > 0:
            return ('reject', 'qp_infeasible', (s.id, m, slack))
        h = min((tau_max[i] - abs(u.tau[i])) / tau_max[i]
                for i in range(n_dof))
        if h < h_req:
            return ('reject', 'authority_margin', (s.id, m, h))
        U_core.append(u)
        margins[s.id] = h
    delta_u = max_impl_error(U_core, dyn.calibration)
    if delta_u > a_budget:
        return ('reject', 'actuation_drift', delta_u)
    return ('ok', A_act(U_core, min(margins.values()), margins), delta_u)
```

### IP-125 DCC

```python
def dexterous_cloud_edge(T_desc, G, H, dyn, tau_qp_budget):
    P_c, mode_seq = cloud_plan(T_desc, G, H)        # 慢：模式序列+物体轨迹
    reports = []
    for (s, m, a) in zip(P_c.skills, mode_seq, P_c.actions):
        u, slack, t_qp = edge_qp_control(dyn, s, a, m)   # 快：全身 QP
        if t_qp > tau_qp_budget:
            return ('reject', 'realtime_miss', t_qp)
        if slack > 0 or torque_saturated(u) or slip_detected(dyn):
            exp = explain_contact(dyn, s, m, u)
            reports.append(exp)
            P_c = cloud_replan_modes(P_c, exp)           # 重排模式而非仅重采样
        if min_authority(u) < h_req:
            reports.append(explain_authority(s, u))
    return ('ok', P_c, reports)
```

### IP-126 ARC

```python
def joint_certificate_v2(skill_seq, mode_path, gamma_ta, dyn,
                         delta_a_budget, delta_u_budget, h_req, rho_min):
    rho_comp = compose_robustness_chain([s.rho for s in skill_seq], K)
    if min(rho_comp.values()) < rho_min:
        return ('reject', 'robustness_fail', rho_comp)
    tac = task_to_actuation_cert(skill_seq, mode_path, dyn,
                                 delta_u_budget, h_req)
    if tac[0] != 'ok':
        return tac
    A_act, delta_u = tac[1], tac[2]
    D = dexterity_cert(skill_seq, mode_path)
    if D.sigma_min < sigma_req or D.kappa_max > kappa_req:
        return ('reject', 'dexterity_fail', D)
    delta_a = max_alignment_error(gamma_ta, A_act.U_core)
    if delta_a > delta_a_budget:
        return ('reject', 'action_mismatch', delta_a)
    return ('ok', JointCertV2(rho_comp, A_act, D, gamma_ta,
                              delta_a, delta_u, slack=0))
```

```python
def dexterous_transfer_certify(Jp_source, target_dyn, phi,
                               delta_h_budget, delta_m_budget):
    h_target = authority_transfer(Jp_source.A_act, target_dyn, phi)
    delta_h = Jp_source.A_act.h_min - h_target.h_min
    mode_map = contact_mode_map(Jp_source.D_cert.pi_S, target_dyn, phi)
    delta_m = contact_formation_drift(mode_map)
    if delta_h > delta_h_budget or delta_m > delta_m_budget:
        return ('reject', 'dex_budget_exceeded', delta_h, delta_m)
    if mode_map.risk > theta_mode_risk:
        return ('reject', 'contact_mode_risk', mode_map)
    return ('ok', DXC(Jp_source, target_dyn, h_target, mode_map,
                      delta_h, delta_m))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| AAP | O(|A_s|·|M|·QP(n)) | O(|A_s|·|M|) | 驱动包络标定完备，热/摩擦入模 |
| CMG | O(|M|²·c_trans) | O(|M|+|E_M|) | 模式转移 sound，风险阈值保守 |
| DAC | O(|S||M| log(|S||M|)+|E|) | O(|S||M|) | 乘积图边条件 sound，最优路径 |
| TAC | O(|P|·QP(n)) | O(|P|·n) | slack=0 ⇔ 可实现，δ_u 有界 |
| DCC | O(规划)+O(QP)·f_ctrl | O(|P|) | γ_ta Lipschitz，QP 实时，Explain 收敛 |
| ARC | O(|S|·|A|+|P|·QP(n)) | O(|A|+|P|) | 三重证书 sound，预算闭合 |

**正确性定理（Actuation-Grounded Dexterous Composition Soundness）**
(A26)–(A28) 承接第 54 轮；新增 **(A29)** 驱动包络硬件在环标定，`|h_real-h_sim|≤ε_h`；**(A30)** 模式切换成功概率 `≥1-β_m` 且时长 `≤τ_mode`；**(A31)** QP 在 f_ctrl 下 `t_qp≤τ_qp`。则
```
P_success ≥ (1-β_m)^{|π_S|} · [ 1 - Σ_d(1-ρ_min(d)) - β_E
            - P(δ_a>Θ_a) - P(h_min<h_req) - P(slack>0) - P(t_qp>τ_qp) ]
```
核心：**ρ 由 h 诱导**、**接触模式是对齐前置门**、**QP 严格可行是可实现判定器**；该界为联合界，非紧但可审计。

## 5. 本轮最大风险

**一句话**：把鲁棒性下沉为驱动权威余量 h 与接触模式证书，理论上让"能到达"和"能稳住"统一，但全部 soundness 压在一个乐观假设上——**仿真标定的力矩余量与接触摩擦参数在真机上偏乐观**；一旦 h_min 被高估，系统恰会在接触最丰富、最需要鲁棒性的模式切换处饱和或滑移，故必须以 **硬件在环权威标定 + 温度/摩擦降额 + 接触模式回退** 三重护栏，绝不把仿真力矩余量当成真机可部署权威。
