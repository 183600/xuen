（灵感驱动研究循环·第 1 轮；本轮灵感：「云端协同」×「检索增强生成」）

> **基线**：上一轮产出 MetricVoiceGauge-NCD-HUTDH-v23 + IP-436–439（CESC 云边版本原子切换 / FSVC 少样本有效证书 / IPAM 知识产权认证 / HPC-E+ 四证准入门），其上承 v22 分层能量 PGEV/ACSC/DCSC、v21 语义-规范层 SDC/CAC/DCL/GIC、v20 联邦感知 PCA/CTS/CFC/HPC/CFCtrl 与 v19/v17 各模块。
> **本轮纪律**：不推倒 v23。CESC/FSVC/IPAM/HPC-E+ 以及更早的 PCA/CTS/CFC/HPC/SDC/CAC/DCL/GIC/PGEV/ACSC/DCSC 全部保留。本轮只做一件事：**把 v23 的云边协同从"云端推送一个原子版本"升级为"云边共同维护一座可检索、可溯源、可审计的证书证据库"，并用"检索只填未知、绝不推翻已知"的三值格，封堵 v23 的最大风险——版本一致性与统计覆盖承诺在协同故障下的共振崩塌**。

## 0. 直觉与动机

**灵感 1（检索增强生成 → 检索增强证书：从"生成"到"接地"）**
直觉：v23 每一拍都从"当前模型 + 当前校准"**从头生成**证书；一旦当前证据不可用（云端断联、覆盖跌破），系统只剩两条路——保守停或带病跑。而人类做安全判断时会翻"以前类似场景是怎么判的、当时证书怎么签的、依据哪条规则"。RAG 的核心正是：检索相关外部证据 → 让生成**接地**在证据上 → 附引用。把它搬到证书体系：把历史已认证的证书、校准记录、近失/缺席案例当作**外部证据库**，当前证书接地在检索到的证据上，并携带 citation_set 与可机械复核的 transfer_proof。
关键反直觉点：**RAG 的失败不是"检索不到"，而是"检索到了但不适用"（幻觉 = 忽略或误用证据）。安全证书的对应失败是"相似 ≠ 可迁移"**——嵌入余弦相似度不是分布距离，语义高度相似的案例可能来自完全不同的分布。因此检索证据的采纳标准绝不能是相似度阈值，而必须是**可迁移性证书**：用分布散度上界把源域的覆盖承诺搬运到目标域。核心创新：**检索增强证书（Retrieval-Augmented Certificate, RAC）+ 检索有效性证书（Retrieval Validity Certificate, RVC）**，RVC 的采纳谓词为 Rel ∧ Fresh ∧ Consist ∧ Indep ∧ Transfer，其中 Transfer 给出 `Cov_target ≥ Cov_source − d_TV ≥ Cov_source − sqrt(KL_ub/2)` 的保守界。

**灵感 2（云端协同 → 从"工件同步"到"联邦证据记忆"）**
直觉：v23 的云边协同是**单向广播、单版本、不可检索**的——云端把 (model, calib, proto, rule, patent) 五元组推给边端，边端原子切换。这解决了"版本不一致"，却没利用"经验"：一千台机器人在一千个现场签过的证书、踩过的近失，全被丢掉了。真正的云端协同应是**联邦记忆**：各边端把脱敏的特征/证书/溯源签名写入**只追加的 Merkle 向量索引**，云端聚合、去重、回灌，边端保留本地副本，断联也能检索。于是"云端推版本"变成"云端维护证据记忆"，CESC 的版本元组自然扩展出索引根 `v_idx`。
关键反直觉点：**共享语料是新的相关性风险源**。所有机器人若检索到同一条被投毒、或同源错误的证据，会形成比单模态误判更强的**全局共振**——这恰是 v23 最大风险的升级形态。故相似度 top-k 远远不够，必须引入**溯源多样性仲裁（Provenance Diversity Quorum, PDQ）**：可采纳证据必须来自 ≥Q 条在依赖 DAG 上相互独立的上游链（不同站点/传感器/训练run/校准session），同根证据只计一次。

**两者如何统一：检索增强的联邦证据层（RAFL）+ 三值填充格**
- v23 的判决天然是三值的：**SAFE / UNSAFE / UNKNOWN**。UNKNOWN 正是"证书不可用"——覆盖跌破、云端断联、少样本校准不足、切换窗口内无可用版本，也就是 v23 三重失效的落点。
- v24 的纪律只有一句：**检索只能把 UNKNOWN 细化为 SAFE/UNSAFE，绝不把 UNSAFE 翻成 SAFE**。这与 RAG 的"接地生成不得与已知事实/检索事实矛盾"严格同构。
- 名义路径仍只做交：`Exec_v24^nom = Safe_v23 ∩ Fil_rvc ∩ Fil_pdq ⊆ Safe_v23`；恢复路径只在 UNKNOWN 上启用：`Exec_v24^rec ⊆ (Safe_v23 ∪ Unknown_v23) \ Unsafe_v23`。
- 关键定理直觉：**子集链保护"已知安全不被放宽"，三值格保护"未知可以被有证据地补全"**——这正是 v23 想解决却不敢解决的根本张力（要么严格子集、要么活性坍缩）。RAG 给了第三条路：不是放宽安全，而是**给未知一个带迁移界、可审计的答案**。

## 1. 研究问题（轮次升级版）

- **Q12（可迁移覆盖界的可靠性）**：如何在有限样本、高维深度特征上得到有效的 `D_KL` 上界（置信 ≥1-δ₂）？Pinsker 的 `d_TV ≤ sqrt(KL/2)` 是否过松以致检索永远无法"够格"？相似度与可迁移性在什么条件下系统性背离（同一预训练骨干把不同分布映射到邻近区域）？

- **Q15（云边索引一致性与实时性）**：索引根 `v_idx` 如何纳入 CESC 的原子五元组切换与回滚？ANN 检索延迟（10–50ms）如何与 50Hz 控制环解耦（异步预取 + 缓存 + TTL + 版本失效）？只追加 Merkle 审计与"遗忘权/证据删除"如何兼容（墓碑 vs 物理重写）？

## 2. 设计原则（在 P34–P42 基础上新增 P43–P46）

**P43 检索有效性律（Retrieval Validity）**
一条证据 `e` 可被采纳，当且仅当 `Rel(e,q) ∧ Fresh(e,V) ∧ Consist(e,live) ∧ Indep(e,A) ∧ Transfer(e,q)` 同时成立：Rel 为语义相关（仅是必要条件，绝不充分）；Fresh 为版本/时效未过期；Consist 为与在线证据不矛盾（与已知 UNSAFE 冲突即拒）；Indep 为与已采纳集合溯源独立；Transfer 为可迁移性上界成立。证书必须携带 `citation_set` 与 `transfer_proof`，否则不可审计、不可执行。

**P44 三值填充律（Unknown-Only Fill）**
检索只允许细化 UNKNOWN，永不允许推翻 UNSAFE。形式化：`Exec_v24 ∩ Unsafe_v23 = ∅`，且名义路径 `Exec_v24^nom ⊆ Safe_v23`。恢复路径只对 `Unknown_v23` 生效，且必须由 RAC 的可迁移覆盖下界 `Cov_ret_lb ≥ 1-α` 与 PDQ 的独立集门槛共同担保。故检索不是"放宽安全边界"，而是"为未知补一份带证明的答案"。

**P45 溯源多样性律（Provenance Diversity）**
仲裁要求可采纳证据的最大独立溯源集 `|MIS(A)| ≥ Q` 且模态数 ≥ `M_MIN_MODALITIES`；同根证据只计一次。独立集不足 Q 时，判决回落为 UNKNOWN（而非 SAFE），从而在结构上禁止"共享语料共振"形成共识。

**P46 只追加审计律（Append-Only Audit）**
联邦证据索引只追加、不物理重写；每次追加更新 Merkle 根并写入 CESC 的 `v_idx`。删除采用墓碑（tombstone）+ 根更新，保证历史证书仍可复核而当前检索不再返回被删证据。任何索引根不一致、签名失败或本地副本缺失 → 关闭检索 → 回退 v23 的 fail-safe。

## 3. 与基线的接口（如何退化）

- 索引不可用 / 断联且无本地副本 ⇒ 可采纳集 A=∅ ⇒ 判决保持 UNKNOWN ⇒ 完全回退 v23 的保守行为；
- RVC 全部失败（无证据通过 Transfer）⇒ A=∅ ⇒ 同上；
- 独立集 `< Q`（共享语料/投毒）⇒ 判决强制 UNKNOWN ⇒ 不比 v23 更松；
- 检索结论与 v23 已知 UNSAFE 冲突 ⇒ **结构性拒绝检索**（只填未知律）⇒ 仍为 UNSAFE；
- 名义路径（v23=SAFE）⇒ 仅追加过滤 `Fil_rvc ∩ Fil_pdq` ⇒ `⊆ Safe_v23`；
- 全失效 ⇒ v23 ⇒ v22 ⇒ … ⇒ `Safe_v24^nom ⊆ Safe_v23 ⊆ Safe_v22 ⊆ …`，同时 `Exec_v24 ∩ Unsafe_v23 = ∅`。
- **与 CESC 的接口**：`v_idx` 作为版本六元组的第六位参与原子切换；切换窗口内旧索引继续服务，新索引仅在 `FewShotValid ∧ IndexRootConsistent` 通过后上线，回滚时 `v_idx` 同步回退。

## 4. 预期贡献

1. **首次把 RAG 形式化为安全证书的"证据检索"而非"文本生成"**：给出 citation-grounded certificate 与可机械复核的 transfer_proof，把"接地"从修辞变成证书字段；
2. **可迁移性证书（RVC）**：用 KL/TV 上界替代相似度阈值，显式区分"相关"与"可迁移"，为检索增强覆盖给出 `1-α-δ` 的保守下界；
3. **三值填充格**："检索只填未知、绝不推翻已知"，化解 v23"严格子集 vs 活性恢复"的根本张力，给出 Unsafe-单调不变量与名义子集链并存的证明结构；
4. **联邦证据索引 + 溯源独立仲裁**：把云边协同从版本广播升级为可检索的联邦经验记忆，并用最大独立集封堵跨机器人语料共振；
5. **直接缓解 v23 三重失效**：断联时本地索引 + 迁移界可把部分 UNKNOWN 细化为 SAFE；无法细化时仍 fail-safe，且永不把 UNSAFE 误放行；
6. **HPC-E++ 双链闭合**：子集链（名义安全不放宽）+ 三值安全链（未知可补全、已知不可推翻）并行，`Exec_v24` 的可审计性与单调性同时成立。

## 5. 本轮最大风险

**一句话**：整条恢复路径都押在 `D_KL^ub(P_edge ‖ P_j)` 这个**高维有限样本上界估计**上；一旦它被低估（维度灾难、对抗样本、或估计器把"语义相似但分布不同"判成低散度），检索就会把真正危险的 UNKNOWN "接地"成 SAFE——即**检索接地幻觉：证据看似相关、引用齐全、可审计，但迁移界并不成立**。

## 1. 关键算法骨架（在 IP-436–439 骨架上扩展）

```python
# ============================================================
# IP-440 Federated Evidence Index (FEI) — 只追加联邦证据索引
# ============================================================
@dataclass(frozen=True)
class Provenance:
    site: str
    sensor_sn: str
    train_run: str
    calib_session: str
    upstream: frozenset[str]        # 依赖 DAG 祖先哈希（骨干/标定/地图/数据源）

    def independent(self, other: "Provenance") -> bool:
        if self.upstream & other.upstream:            # 共享上游 → 不独立
            return False
        return (self.site != other.site
                and self.sensor_sn != other.sensor_sn
                and self.train_run != other.train_run
                and self.calib_session != other.calib_session)


@dataclass
class EvidenceRecord:
    id: str
    phi: Tensor                     # 脱敏深度特征，E794 隐私合规；不外传原始像素
    cert: dict                      # 证书摘要：{verdict, cov, eps_loc, rule_hash, ...}
    prov: Provenance
    v: VersionTuple
    t: float
    sig: bytes                      # 边端私钥签名
    tombstoned: bool = False

    def digest(self) -> bytes:
        return sha256(canonical_json({...}))


class FederatedEvidenceIndex:
    """只追加 Merkle 向量索引；云端聚合、边端本地副本；断联仍可检索。"""
    def __init__(self, pk_cloud, local_store, ann_index):
        self.pk_cloud = pk_cloud
        self.leaves: list[EvidenceRecord] = local_store.load()   # 本地副本
        self.ann = ann_index                                      # HNSW/IVF
        self._rebuild_ann()
        self.root = self._merkle_root(self.leaves)

    def append(self, e: EvidenceRecord, pk_edge) -> bytes:
        if not verify_signature(pk_edge, e.digest(), e.sig):
            raise EvidenceRejected("bad_signature")
        if any(l.id == e.id for l in self.leaves):        # 幂等去重
            return self.root
        self.leaves.append(e)
        self.ann.add(e.id, e.phi)
        self.root = self._merkle_root(self.leaves)
        return self.root

    def tombstone(self, eid: str, reason: str) -> bytes:
        # 遗忘权：追加墓碑，不物理重写；历史 Merkle 路径仍可复核
        self.leaves.append(EvidenceRecord.tombstone_of(eid, reason))
        self.ann.remove(eid)
        self.root = self._merkle_root(self.leaves)
        return self.root

    def retrieve(self, q_phi: Tensor, k: int, V: VersionTuple) -> list[EvidenceRecord]:
        cand = self.ann.search(q_phi, k)                  # O(log N) ANN
        out = []
        for eid in cand:
            e = self.by_id(eid)
            if e.tombstoned:
                continue
            if e.v.v_idx > V.v_idx:                       # 不检索"未来"版本证据
                continue
            out.append(e)
        return out

    def sync_from_cloud(self, root_cloud: bytes, new_leaves: list[EvidenceRecord]) -> bool:
        for e in new_leaves:
            if not verify_signature(e.prov_signer(), e.digest(), e.sig):
                return False                              # 任一条验签失败 → 整批拒收
        self.leaves.extend(new_leaves)
        self.root = self._merkle_root(self.leaves)
        return self.root == root_cloud                    # 根一致性校验


# ============================================================
# IP-441 Retrieval Validity Certificate (RVC) — 检索有效性证书
# ============================================================
class RetrievalValidityCertificate:
    def __init__(self, alpha=0.01, delta=1e-3, delta2=1e-3,
                 d_max=0.05, lambda_w=1.0, min_rel=0.7, ttl=3600.0):
        self.alpha, self.delta, self.delta2 = alpha, delta, delta2
        self.d_max, self.lambda_w, self.min_rel, self.ttl = d_max, lambda_w, min_rel, ttl

    def admissible(self, e: EvidenceRecord, q, live, V: VersionTuple):
        # Rel：语义相关——必要非充分，绝不单独作为采纳依据
        if cosine(e.phi, q.phi) < self.min_rel:
            return None
        # Fresh：时效与版本
        if now() - e.t > self.ttl or e.v.v_idx > V.v_idx:
            return None
        # Consist：与在线证据不矛盾（与已知 UNSAFE 冲突即拒）
        if contradicts(e.cert, live.cert):
            return None
        # Transfer：可迁移性上界（本层唯一决定"能否搬运覆盖"的判据）
        kl_ub = self.kl_upper_bound(q.phi_dist, e.phi_dist, self.delta2)
        if kl_ub > self.d_max:
            return None
        tv_ub = math.sqrt(kl_ub / 2.0)                    # Pinsker
        return TransferProof(kl_ub=kl_ub, tv_ub=tv_ub,
                             w=math.exp(-self.lambda_w * kl_ub), eid=e.id)

    def kl_upper_bound(self, P_edge, P_src, delta2) -> float:
        """分类器密度比 + bootstrap 上置信界；高维退化用 kernel MMD 校准。"""
        # 1) 训练 witness f（两半样本交叉拟合，避免过拟合偏乐观）
        f = fit_witness(P_edge, P_src)
        # 2) Donsker-Varadhan 变分估计（取对 KL 的上界方向）
        kl_hat = dv_estimate(f, P_edge, P_src)
        # 3) bootstrap 1-delta2 分位作为保守上界
        return bootstrap_ucb(kl_hat, delta2)


# ============================================================
# IP-442 Retrieval-Augmented Certificate (RAC) — 检索增强证书（三值）
# ============================================================
class RetrievalAugmentedCertificate:
    def __init__(self, index: FederatedEvidenceIndex,
                 rvc: RetrievalValidityCertificate,
                 pdq: "ProvenanceDiversityQuorum", k=16, m_min=30):
        self.index, self.rvc, self.pdq = index, rvc, pdq
        self.k, self.m_min = k, m_min

    def coverage_lower_bound(self, accepted) -> float:
        if not accepted:
            return 0.0
        # 单源保守界：始终有效，不依赖跨源独立性
        single = max(c - p.tv_ub for e, p in accepted for c in [e.cert["cov"]])
        if len(self.pdq.independent_roots(accepted)) < self.pdq.Q:
            return single                                  # 只信最可迁移的那一条
        # 独立源池化界：仅当 PDQ 认定独立时启用
        m_eff = sum(p.w for _, p in accepted)
        if m_eff < self.m_min:
            return single
        hoef = math.sqrt(math.log(1.0 / self.rvc.delta) / (2.0 * m_eff))
        pooled = min(e.cert["cov"] - p.tv_ub for e, p in accepted) - hoef
        return max(single, pooled)

    def decide(self, q, live) -> str:
        base = live.v23_verdict()                          # SAFE / UNSAFE / UNKNOWN
        if base == "UNSAFE":
            return "UNSAFE"                                # P44：绝不推翻已知 UNSAFE
        if base == "SAFE":
            return "SAFE"                                  # 名义路径由 Fil_rvc/Fil_pdq 另行收窄
        # base == UNKNOWN：仅此分支允许检索替换
        cand = self.index.retrieve(q.phi, self.k, live.V)
        accepted = []
        for e in cand:
            p = self.rvc.admissible(e, q, live, live.V)
            if p is not None:
                accepted.append((e, p))
        accepted = self.pdq.filter(accepted)               # 独立集/模态门槛
        cov_lb = self.coverage_lower_bound(accepted)
        if cov_lb >= 1.0 - self.rvc.alpha:
            return "SAFE"
        return "UNKNOWN"


# ============================================================
# IP-443 Provenance Diversity Quorum (PDQ) — 溯源多样性仲裁
# ============================================================
class ProvenanceDiversityQuorum:
    def __init__(self, Q=2, M_min=2):
        self.Q, self.M_min = Q, M_min

    def independent_roots(self, accepted) -> list:
        """贪心最大独立集（按迁移权重降序），O(|A|^2) 或 O(|A|·Q)。"""
        chosen = []
        for e, p in sorted(accepted, key=lambda x: -x[1].w):
            if all(e.prov.independent(c.prov) for c, _ in chosen):
                chosen.append((e, p))
        return chosen

    def filter(self, accepted) -> list:
        indep = self.independent_roots(accepted)
        modalities = {e.cert.get("modality") for e, _ in indep}
        if len(indep) < self.Q or len(modalities) < self.M_min:
            return []                                      # 强制 UNKNOWN
        return indep

    def arbitrate(self, key, votes, retrieved) -> str:
        # 与 v23 CFC+++ 组合：先过 v23 的计数/模态/层级条件，再过溯源独立集
        base = super().arbitrate(key, votes, retrieved)
        if base in ("CI", "UNKNOWN"):
            return "UNKNOWN"
        if len(self.independent_roots(retrieved)) < self.Q:
            return "UNKNOWN"
        return base


# ============================================================
# IP-445 Retrieval Poisoning Guard (RPG) — 检索投毒防护
# ============================================================
class RetrievalPoisoningGuard:
    def __init__(self, rate_limit=50, rep_decay=0.99, rep_min=0.3):
        self.rate_limit, self.rep_decay, self.rep_min = rate_limit, rep_decay, rep_min
        self.rep: dict[str, float] = {}

    def screen(self, batch: list[EvidenceRecord]) -> list[EvidenceRecord]:
        kept = []
        per_signer = Counter(e.prov.train_run for e in batch)
        for e in batch:
            signer = e.prov.train_run
            if per_signer[signer] > self.rate_limit:
                continue                                   # 速率异常：疑似批量投毒
            if self.rep.get(signer, 1.0) < self.rep_min:
                continue                                   # 信誉过低
            kept.append(e)
        return kept

    def penalize(self, signer: str, amount: float = 0.1):
        self.rep[signer] = max(0.0, self.rep.get(signer, 1.0) - amount)


# ============================================================
# IP-444 Transfer-Coverage Fallback (TCF) — 迁移覆盖回退
# ============================================================
class TransferCoverageFallback:
    """把 v23 三重失效中的 UNKNOWN 用检索迁移界细化；不可细化则保持 UNKNOWN。"""
    def __init__(self, rac: RetrievalAugmentedCertificate, static_cap):
        self.rac, self.static_cap = rac, static_cap

    def refine(self, plan, q, live):
        verdict = self.rac.decide(q, live)
        if verdict == "SAFE":
            # 恢复路径仍叠加静态人距上限，绝不越过 v23 的几何底线
            return "SAFE" if within_static_cap(plan, self.static_cap) else "UNKNOWN"
        return verdict

# IP-446 HPC-E++ — 检索接地统一准入门（双链）
# ============================================================
@dataclass
class HPCEPlusPlus:
    hpc_e_plus: "HPCEPlus"          # v23 四证（HPC-E/ CESC/ FSVC/ IPAttest）
    rac: RetrievalAugmentedCertificate
    pdq: ProvenanceDiversityQuorum
    tcf: TransferCoverageFallback

    def admits(self, plan, q, live, modules) -> tuple[bool, str]:
        base = live.v23_verdict()
        if base == "UNSAFE":
            return False, "UNSAFE"                       # 双链共同底线
        if base == "SAFE":
            if not self.hpc_e_plus.admits(plan, live.x, live.v, live.z,
                                          live.E_res, live.margin_req, modules):
                return False, "SAFE_FILTERED"            # 名义：只做交
            return True, "NOMINAL"
        # base == UNKNOWN：检索恢复路径
        verdict = self.tcf.refine(plan, q, live)
        return (verdict == "SAFE"), verdict

# 端到端：在 v23 流水线上外挂检索证据层
# ============================================================
class RetrievalAugmentedPipeline(PerceptionComplianceEnergyPipeline):
    def __init__(self, config):
        super().__init__(config)
        self.index = FederatedEvidenceIndex(config["pk_cloud"],
                                            config["local_store"], config["ann"])
        self.rvc = RetrievalValidityCertificate(**config.get("rvc", {}))
        self.pdq = ProvenanceDiversityQuorum(config.get("Q", 2),
                                             config.get("M_min", 2))
        self.rpg = RetrievalPoisoningGuard()
        self.rac = RetrievalAugmentedCertificate(self.index, self.rvc, self.pdq)
        self.tcf = TransferCoverageFallback(self.rac, config["static_cap"])
        self.gate = HPCEPlusPlus(self.hpc_e_plus, self.rac, self.pdq, self.tcf)

    def step(self, sensor_data, cloud_update=None):
        # 1) 云边索引同步（异步、非阻塞；失败不影响当前推理）
        if cloud_update and "index_root" in cloud_update:
            batch = self.rpg.screen(cloud_update["evidence"])
            self.index.sync_from_cloud(cloud_update["index_root"], batch)

        # 2) v23 名义证书链
        base_ok, info = super().step(sensor_data, cloud_update)
        live = LiveView(sensor_data, self, base_ok)

        # 3) 生成当前查询并预取（异步，控制环只读缓存）
        q = Query(phi=self.fsvc.backbone.extract_features(sensor_data["cam"]),
                  ctx=sensor_data.get("task_ctx"))
        self._async_prefetch(q, live.V)

        # 4) HPC-E++ 双链准入
        admitted, reason = self.gate.admits(
            info["plan"], q, live, self._modules_in_plan(info["plan"]))

        # 5) 把本拍证书写入本地证据索引（脱敏特征，E794）
        if info["plan"] is not None:
            self.index.append(self._make_evidence(q, info, sensor_data), self.pk_edge)
        return admitted, {**info, "verdict": reason,
                          "cov_ret_lb": self.rac.coverage_lower_bound([]),
                          "index_root": self.index.root}
```

## 3. 正确性论证

### 引理 1（迁移覆盖界的可靠性）
**陈述**：若 `kl_ub(e,q)` 以概率 ≥1-δ₂ 是 `D_KL(P_edge‖P_e)` 的有效上界，且源覆盖 `Cov_e` 以概率 ≥1-δ₁ 有效，则单源迁移下界 `Cov_e - sqrt(kl_ub/2)` 以概率 ≥1-δ₁-δ₂ 下界 `Cov_target`。
**证明**：
1. Pinsker 不等式给出 `d_TV(P_edge, P_e) ≤ sqrt(KL(P_edge‖P_e)/2) ≤ sqrt(kl_ub/2)`（在 kl_ub 有效事件上）。
2. 覆盖概率是取值 [0,1] 的有界函数，故 `|Cov_target - Cov_e| ≤ d_TV ≤ sqrt(kl_ub/2)`。
3. 由 1、2 与源覆盖有效事件，在两者交集（概率 ≥1-δ₁-δ₂）上 `Cov_target ≥ Cov_e - sqrt(kl_ub/2)`。∎

### 引理 2（池化界的有效性条件）
**陈述**：仅当被池化的证据在统计上相互独立时，`m_eff` 池化 Hoeffding 修正才有效；否则必须退化为单源保守界。
**证明**：Hoeffding 要求独立同分布样本；PDQ 的溯源独立只是**依赖结构**上的独立，不自动等于统计独立。故 RAC 在 `|MIS(A)| < Q` 或独立集未通过统计独立性检验时，只返回单源 `max_e(Cov_e - tv_ub_e)`，该式对任意相关结构均成立（取最大值天然保守）。∎

### 引理 3（只填未知 / Unsafe-单调）
**陈述**：`Exec_v24 ∩ Unsafe_v23 = ∅`，且 `Exec_v24^nom ⊆ Safe_v23`。
**证明**：
1. `decide()` 在 `base == UNSAFE` 时立即返回 UNSAFE，`admits()` 同样先判 UNSAFE 即拒——任何路径都不产生"UNSAFE→SAFE"的翻转。
2. `base == SAFE` 时，准入仍要求 `hpc_e_plus.admits` 全部通过，即 `Exec_v24^nom = Safe_v23 ∩ Fil ⊆ Safe_v23`。
3. `base == UNKNOWN` 的恢复分支只在 `Safe_v23 ∪ Unknown_v23` 内取值，且不触及 `Unsafe_v23`。
故两式成立。∎

### 引理 4（溯源独立集封堵共享语料共振）
**陈述**：若所有可采纳证据共享同一上游根，则 `|MIS(A)| = 1 < Q`（Q≥2），判决强制 UNKNOWN，无法形成 SAFE 共识。
**证明**：`indep` 要求 `upstream` 祖先集合两两不交；共享同一上游根时任意两条均不独立，最大独立集大小为 1。PDQ 的 `filter` 在独立集 <Q 时返回空集，RAC 的 `Cov_ret_lb` 回落为 0（空集）或单源、且 `RAC_SAFE` 的 `|MIS|≥Q` 不成立，故判决 UNKNOWN。∎

### 引理 5（退化链）
**陈述**：任意检索层单点/组合失效下，`Exec_v24 = Exec_v23`（回退），且名义路径 `Safe_v24^nom ⊆ Safe_v23 ⊆ Safe_v22 ⊆ …`。
**证明**：索引不可用/断联无副本 ⇒ `A=∅` ⇒ `Cov_ret_lb=0` ⇒ UNKNOWN ⇒ 交给 v23 的保守回退；RVC 全失败、独立集不足、投毒筛查全拒同理。名义路径只追加过滤器，取交单调不增。∎

### 定理（HPC-E++ 的"已知安全不放宽、未知可补全、已知不安全不可推翻"）
**陈述**：对任意计划 π：若 `HPCEPlusPlus.admits(π)=True`，则要么 `π∈Safe_v23` 且通过全部 v23 四证，要么 `π∈Unknown_v23` 且 `RAC_SAFE(π,q)` 成立（`Cov_ret_lb≥1-α ∧ |MIS(A)|≥Q`）；且任何 `π∈Unsafe_v23` 必被拒绝。
**证明**：由 `admits` 的三分支（UNSAFE 拒、SAFE 走 v23 四证、UNKNOWN 走 TCF）与引理 1–5 直接可得。必要性由分支穷尽保证；充分性由引理 1（覆盖可靠性）、引理 4（独立集）与 v23 四证的既有可靠性共同给出。∎
