# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「智能体」×「全身控制」）

> R66–R69 的整条主线一直踩着一个**未言明的假设**：安全是一个可以**逐点、逐前缀、用标量 λ 收缩**的性质。R68 用 λ_floor「不确定就慢」，R69 用 λ_floor(U_ale + 未消解 U_epi) 兜底。这个假设在固定接触、低自由度、单肢体上成立；但把它装到**全身控制（whole-body control）的智能体**上，会同时在三处失效：
> - **前缀失效**：全身安全（平衡、摩擦锥、接触力）是整条轨迹 **+ 接触日程** 的性质。换脚、落脚、手撑、坐起的那一瞬，任何「固定接触下的前缀证书」都作废——而那正是最脆弱的时刻；
> - **单调失效**：在支撑域边缘、在需要迈步救平衡时，「慢下来」不是更安全而是**更危险**：零动作不在安全集内。λ_floor 依赖的「安全集对 0 星形」前提被打破；
> - **模块失效**：两条腿各自满足关节/力矩限制，合起来却可能把质心推出摩擦锥；肢体的「模块安全」不等于全身安全。
>
> 本轮两个灵感各补一刀：
> - **全身控制**要求把安全的**单位**从「动作前缀」升级为「带接触日程的整条 stride + 一个始终可执行的守护（guard）」——从「标量收缩」升级为「**条件不变集**」；
> - **智能体**要求把「谁签字」讲清楚：会幻觉、会被提示注入的意图体（planner/VLA）不能给自己的动作发安全证，必须由绑定到身体状态与动力学模型的**身体体**签发；两者之间需要一套**内部协商**，把 R69 的「问人」先接地为「问身体」。
>
> 核心命题：**安全的单位是 stride 而不是前缀；安全的保底是守护集而不是 λ 收缩；安全的签名权属于身体而不是意图。** 命名 **SPINE-RAS**（Stride-level, Provenance-bound, Invariant-set NEtwork for embodied agents）——智能体可以换脑子，但证书必须长在脊梁上。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「测量准吗」，R69 问「向谁求证」，R70 问「**谁为整具身体的轨迹签字**」。

## 0. 直觉与动机

**灵感 1（全身控制 → 安全的单位是 stride，不是前缀）**
直觉：R68 的 `certified_prefix(A,k)` 在固定接触模式下为动作前 k 步签名，隐含「后续接触模式不变」。但全身控制最危险、最需要认证的时刻恰恰是**接触切换**：迈步、落脚、手撑、从坐到站。前缀证书在换脚那一刻失效，而那一刻正是平衡最脆弱的时候。所以证书对象必须改为 **stride σ = (接触日程 C, 整条全身轨迹 q, 接触力分配 λ_c)**，覆盖整个接触切换；并且要求一个**守护（guard）**：一旦扰动超出预测，就有一条**已经离线认证过的恢复 stride** 立刻接管。证书的时间尺度由此从「预测 H 步」缩成「维持一个集合 + 查一次守护」。

**灵感 2（全身控制 → 「慢下来」不是万能刹车：安全对动作幅度非单调）**
直觉：R68/R69 的全部保守性建立在「0 动作总在安全集内，所以 λ→0 总安全」。这对机械臂成立；对双足/人形在支撑域边缘不成立：站着不动会被重力力矩推倒，反而需要**迈一步、把质心加速到新落脚点**才能回到支撑域。用捕获点 ξ = x + ẋ/ω 看最清楚：当 ξ 已在支撑域外时，缩放速度 ẋ→λẋ 只会让 ξ 更靠近身体、更不可捕获。也就是说，安全集沿动作缩放路径**非星形**，λ 不是万能旋钮。正确的保底不是「缩到 0」，而是「切到守护 stride」——它有时比原动作**更猛**。

**灵感 3（全身控制 → 模块安全 ≠ 整体安全，冗余要预留）**
直觉：两条腿各自在关节/力矩限制内，可能一起把质心推出支撑域；两条手臂各自合规，可能共同产生一个破坏偏航角动量的力偶。全身可行性是**耦合约束**，不能在肢体层分解认证。与此同时全身控制有大量**零空间冗余**：意图体为了任务姿态，常把恢复余量悄悄花光（站在支撑域边缘、伸直膝盖、锁死关节、把手伸到极限）。所以要**安全零空间预留（SNR）**：把冗余的一部分永久留给守护，任务只能在前者仍可行的流形上优化。

**灵感 4（智能体 → 身体主权：会说话的不能自签安全）**
直觉：一个 VLA/LLM 意图体可以幻觉、可以过度乐观、可以被提示注入，甚至可以被奖励黑客诱导去「证明自己安全」。如果它同时握有证书签发权，安全就退化成一句自我声明。必须把**提议权**与**签名权**分开：意图体提议 stride；身体体（快、只信动力学与接触模型、绑定到身体状态与模型版本）要么签名，要么否决并替换为**最小任务偏离**的守护 stride。证书绑定 (状态, 模型版本, 接触日程哈希)，**不可转移、不可跨体重放、不可用语言伪造**——这就是「身体主权」。它把安全问题从「意图体是否诚实」压缩为「身体体是否被攻破」。

**灵感 5（智能体 → 把 R69 的「问人」先接地为「问身体」）**
直觉：R69 最大的风险是「问错比不问更危险」。在全身智能体里，这个问题有一个**免费的第一次消解**：先问自己的身体。身体体能给出**接地报告**（能不能做、最优任务代价、还差多少守护裕度、需要意图体放宽哪条约束）。这份报告是 R69 意义下的信息动作，但它的证据源是动力学而非人类语言，因此**不可被语言投毒**。只有当身体也说不清（守护集为空、接触模型高不确定）时，才升级到问人。主动交互的次序由此从「人优先」改成「身体优先、人类兜底」。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（SPINE-RAS 总览）** SPINE-RAS = (STRIDE, GST, GAL, SNR, BA, IA, INP, CSM, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **身体主权**：任何执行中的 stride 必须携带身体体 BA 对整条 stride（含接触切换）的签名证书 `Cert_σ`；意图体 IA 无签发权，语言/token 不构成证书；
(iii) **守护可行性**：每一步执行后 `s_{t+1} ∈ 𝒜（ρ_W ≥ 0）`，且存在对扰动管 `W` 鲁棒可行的守护 `σ_g ∈ GAL`。缺一 ⇒ 不得执行，转入守护或受控降级（定义 326）。

**定义 311（stride 与接触日程）** stride `σ = (C_{t:t+H}, q_{t:t+H}, u_{t:t+H}, λ_c)`：`C` 为接触日程（各肢体接触标志 `c_i(t)∈{0,1}` 及切换时刻），`q` 为广义坐标/速度，`u` 为关节控制，`λ_c` 为接触力。`ℱ(s,σ)` 表示从 `s` 执行 `σ` 全程满足定义 312 的全部约束。

**定义 312（全身可行性与接触耦合）** `ℱ` 由五类约束合取：浮基动力学 `M(q)q̈+h(q,q̇)=Sᵀu+ΣJ_cᵀλ_c`；单边接触 `λ_n ≥ 0` 与摩擦锥 `‖λ_t‖ ≤ μλ_n`；关节位置/速度/力矩限幅；自碰撞；质心/支撑约束（ZMP∈support(C) 或捕获点约束）。**肢体模块安全**指各肢体局部约束单独满足；**全身安全**指上述耦合系统整体满足。耦合项 `g_c(q,λ_c)` 不可由任何肢体局部约束推出（反例见引理 19 附注）。

**定义 313（守护集与可行域）** `𝒢(s) = {σ_g ∈ GAL : Cert_σg(s)=1 ∧ ∀w∈W, 执行后仍在 𝒜}`；守护裕度 `ρ(s) = min_{σ_g∈𝒢(s)} max{0, slack(σ_g)}`（或等价地：守护可吸收的最大扰动半径）。可执行域 `𝒜 = {s : ρ_W(s) ≥ 0}`，鲁棒裕度 `ρ_W(s)=min_{w∈W}ρ(s,w)`。条件不变性：`s∈𝒜 ⇒ ∃σ_g∈𝒢(s)` 使后继仍在 `𝒜`。

**定义 314（stride 证书与身体签名）** `Cert_σ(s) ∈ {0,1}`，由 BA 计算并签名：`sig = Sign_{k_body}( H(s, σ, model_ver, C_hash) )`。证书内容不可由 IA 构造；签名验证绑定身体状态与模型版本，故跨体重放、跨版本重放必然失败（定义 322、定理 19）。

**定义 315（守护库 GAL）** 一组离线认证的**接触基元**：迈步/落脚、降低质心、屈膝缓冲、手撑、坐倒、接触释放、侧滚软着陆。每个基元 `g=(Pre_g, Post_g, c_g, σ_g(θ))` 有前置条件、后置条件、标量成本与参数化 stride。守护选择：`σ_g = argmin_{g∈GAL, Pre_g(s)} [c_g + α·D_task(g, σ_prop)]`。

**定义 316（安全零空间预留 SNR）** 任务一致流形 `ℳ_task = {q : task(q)=const}`；零空间预留比 `r_guard ∈ [0,1]`。任务运动投影到 `ℳ_task ∩ {ρ ≥ ρ_min}`，即任务只能使用 `(1−r_guard)` 的零空间自由度为自身优化。`r_guard` 是「任务性能 ↔ 守护裕度」的 margin budget。

**定义 317（身体体 BA）** 快环（1kHz），持有动力学/接触模型、GAL、状态估计与签名密钥；权限 = {certify, veto, repair, sign}。BA 是唯一可信核，**无语言入口**；IA 对 BA 只能读 `report()`、只能提交候选，不能改写 BA 的模型、GAL 或密钥。

**定义 318（意图体 IA）** 慢环（5–20Hz），语义规划、候选 stride 与任务代价；可幻觉、可被提示注入、可被奖励黑客。IA **无证书权**；其输出在定义上只是「提议」，不构成安全承诺。

**定义 319（内部协商 INP）** BA 向 IA 返回**接地报告** `R(s) = (feasible?, J*_task, Δ_relax, ρ, contact_uncertainty)`：是否可行、最优任务代价、需放宽的约束及幅度、守护裕度、接触估计不确定度。IA 可发**放宽请求**；BA 在预算内回应。该报告继承 R69 MINT 的 VoI 形式，但证据源是动力学。

**定义 320（接触日程监控 CSM）** 离散状态机；不变量：(a) 无未受控的同时断触（flight 必须有守护覆盖）；(b) 最小接触驻留时间；(c) 切换顺序合法；(d) `C_hash` 单调且可审计。任一违反 ⇒ 立即切守护并触发降级审计。

**定义 321（最小偏离修复 MDR）** 否决不是任意的：`σ* = argmin_{σ∈GAL, Cert_σ=1, CSM ok} D_task(σ, σ_prop)`。即 BA 的 veto 必须附带一个「离意图最近」的可行守护，保证否决可解释、任务代价有界（定理 20）。

**定义 322（证书 J_SPINE）** `J_SPINE = (J_FLUID, stride_hash, contact_schedule_hash, ρ_min, guard_id, guard_robust_W, body_sig, model_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ 守护在 W 下鲁棒可行 ∧ ρ_W ≥ 0 ∧ 身体签名验证通过 ∧ CSM 不变量满足`。

**定义 323（身体侧失效与对抗模型 ℰ_body）** `ℰ_body = ℰ_FLUID × ℰ_body`：接触模型误差、接触误检/漏检、意图体奖励黑客、守护库不完备、签名跨体重放、通信延迟导致证书过期、BA 状态估计被攻破。

**定义 324（身体接地的问询纪律）** 任何 R69 式人类问询前，必须附 BA 的接地报告 `R(s)`；无接地报告的问询禁止（正面修复 R69「问错」）。若 `R.feasible` 则不得以「不确定」为由问人；若 `R.infeasible` 则问题空间被收窄为「放宽哪条任务约束 Δ_relax」，而不是开放域猜测。

**定义 325（鲁棒守护裕度与扰动管）** `W` 为有界扰动管（模型误差 + 接触滑移 + 延迟）。守护证书在 `W` 下验证；管递推 `S_{t+1} ⊆ f(S_t) + W`。`ρ_W` 是「最坏扰动下仍能切守护」的剩余量，是 SPINE 对 R69「标定不可吸收」在控制侧的镜像。

**定义 326（无守护边界与受控降级）** 若 `s ∉ 𝒜` 且无任何 `σ_g` 可行（如被外力瞬间推出），则**不存在「安全 0 动作」**。定义**受控降低协议**：选择最小伤害的接触序列（护头、屈膝、侧滚、软着陆），并将其作为 GAL 的最低优先级守护；证书显式标记 `degraded=1`，必须审计。这是唯一公开承认「安全已不可保证、只最小化伤害」的层，绝不冒充安全。

## 2. 关键算法骨架

```python
# IP-265 STRIDE：接触日程感知的整条 stride 认证（不是前缀）
def stride_feasible(s, sigma, model, W):
    for t in range(sigma.H):                       # 含接触切换时刻
        if not model.dynamics_ok(s, sigma, t): return False
        if not model.friction_cone_ok(sigma, t): return False
        if not model.joint_limits_ok(sigma, t): return False
        if not model.support_ok(sigma, t): return False   # ZMP / capture point
        s = model.propagate(s, sigma, t, w=W.worst(t)) if W.robust else s
    return True

# IP-267 GAL：离线认证、在线只查前置条件 + QP 求解参数
class GuardLibrary:
    def candidates(self, s):
        return [g for g in self.gal if g.pre(s)]           # 迈步/降心/手撑/坐倒/软着陆

# IP-269 BA：1kHz 身体体；唯一签名者，无语言入口
class BodyAgent:
    def certify(self, s, sigma, W):
        if not stride_feasible(s, sigma, self.model, W): return None
        if not self.robust_guard_exists(s, sigma, W):    return None
        return self.signer.sign(hash(s, sigma, self.model.ver, sigma.C_hash))
    def repair(self, s, sigma_prop):                     # 定义 321 最小偏离
        feas = [g for g in self.gal.candidates(s)
                if self.certify(s, g.sigma, self.W) and self.csm.admissible(g)]
        if not feas: return None
        return min(feas, key=lambda g: D_task(g, sigma_prop))  # 可能比提议更"猛"
    def report(self, s):                                 # 定义 319 接地报告
        return R(feasible=(self.certify(s, self.best_stride(s), self.W) is not None),
                 J_task=self.best_task_cost(s), rho=rho_W(s),
                 d_relax=self.min_relaxation(s), contact_unc=self.contact_unc(s))

# IP-271 INP：意图体 ↔ 身体体的内部协商（R69 的 VoI 变成"问身体"）
def negotiate(IA, BA, s, max_rounds=2):
    for _ in range(max_rounds):
        sigma_prop = IA.propose(s, BA.report(s))         # 提议，无签名权
        if BA.certify(s, sigma_prop, BA.W): return sigma_prop
        sigma_prop = IA.relax(s, BA.report(s))           # 按 Δ_relax 放宽后重提
    return BA.repair(s, sigma_prop)                      # 协商不成 → 最小偏离守护

# IP-274 SPINE 主闭环
def SPINE_round(IA, BA, obs):
    s = BA.estimate(obs)
    # 1) 慢环：意图体提议（含接触切换）；身体体给接地报告
    sigma = negotiate(IA, BA, s)                         # 定义 319/321
    # 2) 身体主权：无签名不执行
    cert = BA.certify(s, sigma, BA.W)
    if cert is None:
        sigma, cert = BA.controlled_descent(s)           # 定义 326，标记 degraded
    # 3) 快环执行：每步维持守护可行性（不是"慢下来"）
    while BA.running(sigma):
        s = BA.step()
        if (not BA.in_admissible(s, BA.W)) or BA.csm.violated():
            sigma = BA.guard(s)                          # 切守护，可能更"猛"
            cert  = BA.certify(s, sigma, BA.W)
        BA.renew_step_signature(s, cert)                 # 逐步续签，防过期
    # 4) 问人前先问身体：无接地报告禁止问询（定义 324）
    if BA.report(s).infeasible and not BA.report(s).grounds_question():
        raise UngroundedQueryError
    # 5) 审计：证书 + 接触日程 + degraded 标记入 AuditBuf
    BA.audit.submit(sigma, cert, BA.report(s))
    return sigma, cert
```

## 3. 推导

**引理 19（λ 收缩在全身域不安全：非单调、非星形）** 存在状态 `s`、动作 `a` 与 `λ*∈(0,1)`，使执行 `λ*a` 违反可行性（ZMP/捕获点出支撑域），而执行某守护 `σ_g`（其控制幅度 `‖u_g‖ > ‖λ*a‖`）保持可行；更强地，`λ ↦ [ℱ(s,λa)]` 的可行参数集在 `[0,1]` 上不连通。证明要点：线性倒摆的捕获点 `ξ = x + ẋ/ω`。若 `ξ` 已出支撑域，需要足够大的 `ẋ` 才能在新落脚点被捕获；缩放 `ẋ→λẋ` 使 `ξ→x`，离支撑域更远，`λ→0` 时 `ξ=x` 仍不可捕获。故 `min_λ safety` 不在 `λ=0`。系：R68/R69 的 λ_floor 是「安全集对 0 星形」这一假设的产物；全身域不满足，必须用「切换守护」替代「标量收缩」。附注：构造两条腿各自满足局部力矩/摩擦约束、但合力矩把质心推出支撑域的 `g_c` 反例，即「模块安全 ⇏ 整体安全」。

**引理 20（守护鲁棒可行 ⇒ 全 stride 安全）** 若 `∀t`：`s_t∈𝒜` 且守护 `σ_g(t)` 在扰动管 `W` 下鲁棒可行（其后继仍 `∈𝒜`），则整段 stride 内硬约束零违反。证明：对鲁棒不变集归纳，`s_{t+1} ∈ f(s_t)+W ⊆ 𝒜`，约束由 `𝒜` 定义直接继承。系：条件不变集把「预测一条长轨迹」变成「维持一个集合」，证书的时间尺度由 `H` 降为「一步 + 一次守护查找」，这正是全身控制可实时的关键。

**引理 21（零空间预留的守护裕度下界）** 设任务在零空间的利用率为 `u∈[0,1]`，`ρ` 对 `u` 单调不增且斜率有界 `L_null`；若预留比例 `r_guard`（任务只能使用 `(1−r_guard)` 的零空间），则 `ρ ≥ ρ_max − L_null·(1−r_guard)·u`。系：存在 `r_guard*` 使任务性能损失与守护裕度达到 Pareto 拐点；`r_guard` 是定义 316 中唯一需要在线调节的标量，但它调的是**冗余的用途**，不是动作的幅度。

**定理 18（SPINE 严格包含 R68/R69）** 当 (a) 接触日程恒定、(b) 安全集对 0 星形（`λa` 对 `λ∈[0,1]` 均可行）、(c) 守护库仅含 λ-缩放 时，SPINE 逐指令退化为 R68/R69（BA 的 repair 退化为 `λ_floor`，「已认证 stride」退化为「已认证前缀」）。当 (b) 或 (c) 不成立（全身域一般情形），引理 19 给出 SPINE 可行而 R68 不可行的状态集，故 SPINE 在不更保守的前提下严格更安全。⇒ R68/R69 = 「固定接触 + 星形安全集 + 单一缩放守护」的边界退化，与本系列一贯的「新层严格泛化旧层」姿态一致。

**定理 19（身体主权的不可伪造 / 不可转移）** 假设签名方案 EUF-CMA 安全且证书绑定 `(s, model_ver, C_hash)`。则任何只控制 IA（提议、语言、提示注入）的对手，使未认证 stride 执行的概率 `≤ negl(κ) + P[model_ver 碰撞] + P[BA 状态估计被独立攻破]`。跨体重放因 `(s, model_ver)` 不匹配而失败；语言注入因 token 不在签名域而失败。系：安全责任从「意图体是否诚实」塌缩为「身体体是否被攻破」，攻击面被压到一个 1kHz、无语言入口的最小可信核。

**定理 20（最小偏离修复的任务代价上界）** 若 GAL 在状态 `s` 的可行守护集上构成 `ε`-网，则由定义 321 选出的 `σ*` 满足 `D_task(σ*, σ_prop) ≤ 2·OPT(s) + ε·L_task`，其中 `OPT(s)` 为可行集内最小任务偏离、`L_task` 为任务代价的 Lipschitz 常数。系：否决不是「一票否决」，而是「有界代价的最近修复」；这使审计能区分「必要否决」与「身体体过度保守」。

## 6. 本轮最大风险

**一句话**：SPINE-RAS 把全部安全押在「守护库完备 + 接触模型在接触丰富时刻可信」这两个前提上——**若真正安全的恢复不在 GAL 里（或守护本身是在错误的接触模型下被认证的），那么系统会在它最自信、接触最复杂的那一刻依赖一个会失效的守护：备份恰恰是那个会摔倒的东西，而它摔倒时已经没有第二层。** 这不是「问错比不问更危险」的重复，而是它的控制侧镜像——**最可靠的保底，可能建立在最不可靠的模型上**。

**次级风险与缓解**：
1. **守护库不完备** → 过度保守（冻结/拒动）或错误可行 → 离线可达性枚举 + 「未知即受控降级」+ 审计标记；
2. **接触模型误差/滑移** → 守护在最坏时刻失效 → 鲁棒管 `W` + 摩擦系数安全因子 + 接触估计集成 + 必要时用 R69 信息动作（轻触/探针）主动探测接触；
3. **意图体奖励黑客/提示注入** → 诱导系统伪造安全 → 身体主权 + 签名绑定 + VQAuditor-B 审计（定理 19）；
4. **BA 自身被攻破**（最小可信核失效）→ 硬件根信任 + 无语言入口 + 独立看门狗；
5. **实时性**：1kHz WBC-QP + 守护查找 → 预计算守护库 + warm-start + anytime QP，慢环绝不进入快环；
6. **受控降级被当成免责声明** → `degraded=1` 强制审计、计入长期可靠性指标，禁止静默降级。

## 2. 形式化定义（要点版）

**定义 310（总览与三不变式）** `SPINE-RAS = (STRIDE, GST, GAL, SNR, BA, IA, INP, CSM, RAS-WM‡)`；零学习写操作继承；**身体主权**（无 BA 签名不执行，IA 无签发权）；**守护可行性**（执行后 `ρ_W ≥ 0` 且守护鲁棒可行）。

**定义 311–312（stride 与全身可行性）** `σ=(C,q,u,λ_c)` 覆盖接触切换；`ℱ` = 浮基动力学 ∧ 单边接触 ∧ 摩擦锥 ∧ 关节限幅 ∧ 自碰撞 ∧ ZMP/捕获点。**模块安全 ⇏ 整体安全**，耦合项 `g_c` 不可按肢体分解。

**定义 313（守护集与可行域）** `𝒢(s)`、`ρ(s)`、`ρ_W(s)`、`𝒜`；条件不变性 `s∈𝒜 ⇒ ∃σ_g` 使后继仍 `∈𝒜`。

**定义 314（stride 证书）** `Cert_σ=Sign_{k_body}(H(s,σ,model_ver,C_hash))`；不可由 IA 构造，跨体/跨版本重放失败。

**定义 315–316（GAL 与 SNR）** GAL = 认证恢复基元（迈步/降心/手撑/坐倒/释放/软着陆）；`r_guard` 预留零空间，任务投影到 `ℳ_task ∩ {ρ≥ρ_min}`。

**定义 317–319（BA / IA / INP）** BA 1kHz 唯一签名者、无语言入口；IA 慢环只提议；INP 接地报告 `R(s)` + 放宽请求，先问身体再问人。

**定义 320–321（CSM 与 MDR）** 接触日程不变量；否决必须附「离意图最近」的可行守护，`D_task` 有界（定理 20）。

**定义 322–323（J_SPINE 与 ℰ_body）** 证书并入 stride/接触哈希/ρ_W/守护 id/签名/模型版本；`ℰ_body = ℰ_FLUID × ℰ_body`（接触误检、奖励黑客、库不完备、重放、证书过期、BA 被攻破）。

**定义 324–326（问询纪律 / 鲁棒裕度 / 受控降级）** 无接地报告禁止问人；`ρ_W` 为 `W` 下最坏裕度；无守护可行时进入显式 `degraded` 最小伤害协议，绝不冒充安全。

## 3. 关键算法伪代码

```python
# IP-265 STRIDE：接触日程感知的整条 stride 认证（不是前缀）
def stride_feasible(s, sigma, model, W):
    for t in range(sigma.H):
        if not (model.dynamics_ok(s, sigma, t)
                and model.friction_cone_ok(sigma, t)
                and model.joint_limits_ok(sigma, t)
                and model.support_ok(sigma, t)):     # ZMP / capture point
            return False
        s = model.propagate(s, sigma, t, w=W.worst(t)) if W.robust else s
    return True

# IP-267 GAL：离线认证，在线只查前置条件 + QP 参数
class GuardLibrary:
    def candidates(self, s):
        return [g for g in self.gal if g.pre(s)]     # 迈步/降心/手撑/坐倒/软着陆

# IP-269 BA：1kHz 唯一签名者，无语言入口
class BodyAgent:
    def certify(self, s, sigma, W):
        if not stride_feasible(s, sigma, self.model, W): return None
        if not self.robust_guard_exists(s, sigma, W):    return None
        return self.signer.sign(hash(s, sigma, self.model.ver, sigma.C_hash))

    def repair(self, s, sigma_prop):                     # IP-321 最小偏离
        feas = [g for g in self.gal.candidates(s)
                if self.certify(s, g.sigma, self.W) and self.csm.admissible(g)]
        return min(feas, key=lambda g: D_task(g, sigma_prop)) if feas else None

    def report(self, s):                                 # 定义 319 接地报告
        return R(feasible=(self.certify(s, self.best_stride(s), self.W) is not None),
                 J_task=self.best_task_cost(s), rho=rho_W(s),
                 d_relax=self.min_relaxation(s), contact_unc=self.contact_unc(s))

# IP-271 INP：先问身体（证据源=动力学），再决定是否问人
def negotiate(IA, BA, s, max_rounds=2):
    for _ in range(max_rounds):
        sigma_prop = IA.propose(s, BA.report(s))         # 提议，无签名权
        if BA.certify(s, sigma_prop, BA.W): return sigma_prop
        sigma_prop = IA.relax(s, BA.report(s))           # 按 Δ_relax 放宽重提
    return BA.repair(s, sigma_prop)                      # 协商不成 → 守护

# IP-274 SPINE 主闭环
def SPINE_round(IA, BA, obs):
    s = BA.estimate(obs)
    sigma = negotiate(IA, BA, s)                         # 1) 慢环协商
    cert  = BA.certify(s, sigma, BA.W)                   # 2) 身体主权
    if cert is None:
        sigma, cert = BA.controlled_descent(s)           #    定义 326，degraded=1
    while BA.running(sigma):                             # 3) 快环维持集合
        s = BA.step()
        if (not BA.in_admissible(s, BA.W)) or BA.csm.violated():
            sigma = BA.guard(s)                          #    切守护，可能更"猛"
            cert  = BA.certify(s, sigma, BA.W)
        BA.renew_step_signature(s, cert)                 #    逐步续签防过期
    if BA.report(s).infeasible and not BA.report(s).grounds_question():
        raise UngroundedQueryError                       # 4) 无接地不许问人
    BA.audit.submit(sigma, cert, BA.report(s))           # 5) 审计 + 降级标记
    return sigma, cert
```

## 4. 推导

**引理 19（λ 收缩在全身域不安全：非单调、非星形）** 存在 `s, a, λ*∈(0,1)` 使 `λ*a` 违反可行性（ZMP/捕获点出支撑域），而某守护 `σ_g`（`‖u_g‖>‖λ*a‖`）可行；且 `λ↦[ℱ(s,λa)]` 的可行参数集在 `[0,1]` 上不连通。证明要点：捕获点 `ξ=x+ẋ/ω`；`ξ` 出支撑域时需足够大 `ẋ` 才能在新落脚点被捕获，缩放 `ẋ→λẋ` 使 `ξ→x` 更不可捕获，`λ→0` 时 `ξ=x` 仍不可捕获，故 `min_λ safety` 不在 `λ=0`。系：λ_floor 依赖「安全集对 0 星形」，全身域不满足；必须用「切换守护」取代「标量收缩」。附注给出「双肢各自合规、合力矩推翻质心」的 `g_c` 反例，即模块安全 ⇏ 整体安全。

**引理 20（守护鲁棒可行 ⇒ 全 stride 安全）** 若 `∀t`：`s_t∈𝒜` 且守护在 `W` 下鲁棒可行（后继仍 `∈𝒜`），则整段 stride 硬约束零违反。证明：鲁棒不变集归纳 `s_{t+1}∈f(s_t)+W⊆𝒜`。系：证书时间尺度从 `H` 步降为「一步 + 一次守护查找」，是全身实时化的关键。

**引理 21（零空间预留的守护裕度下界）** 零空间利用率 `u`，`ρ` 对 `u` 单调不增且斜率 `≤L_null`；预留 `r_guard` 时 `ρ ≥ ρ_max − L_null(1−r_guard)u`。系：存在 `r_guard*` 使任务损失与守护裕度达 Pareto 拐点；它调的是「冗余用途」而非「动作幅度」。

**定理 18（SPINE 严格包含 R68/R69）** 当（固定接触 ∧ 安全集对 0 星形 ∧ 守护仅含 λ-缩放）时逐指令退化为 R68/R69；否则引理 19 给出 SPINE 可行而 R68 不可行的状态集，故 SPINE 在不更保守前提下严格更安全。R68/R69 = 该三重边界上的退化。

**定理 19（身体主权不可伪造/不可转移）** 在 EUF-CMA 签名与 `(s, model_ver, C_hash)` 绑定下，仅控制 IA 的对手使未认证 stride 执行的概率 `≤ negl(κ)+P[model_ver 碰撞]+P[BA 估计被独立攻破]`；跨体重放因状态/版本不匹配失败，语言注入因 token 不在签名域失败。安全责任从「IA 是否诚实」塌缩为「BA 是否被攻破」。

**定理 20（最小偏离修复代价上界）** 若 GAL 在可行守护集上构成 `ε`-网，则 `D_task(σ*,σ_prop) ≤ 2·OPT(s)+ε·L_task`。否决是「有界代价的最近修复」，审计可据此区分必要否决与过度保守。

## 7. 本轮最大风险

**一句话**：SPINE-RAS 把全部安全押在「守护库完备 + 接触模型在接触丰富时刻可信」这两个前提上——**若真正安全的恢复不在 GAL 里（或守护本身是在错误的接触模型下被认证的），系统就会在最自信、接触最复杂的那一刻依赖一个会失效的守护：备份恰恰是那个会摔倒的东西，而它摔倒时已经没有第二层。**

**次级风险与缓解**：守护库不完备（离线可达性枚举 + 未知即受控降级 + 审计）；接触模型误差/滑移（鲁棒管 `W` + 摩擦安全因子 + 接触估计集成 + 必要时用 R69 轻触/探针主动探测）；意图体奖励黑客/注入（身体主权 + 签名绑定 + VQAuditor-B）；BA 自身被攻破（硬件根信任 + 无语言入口 + 独立看门狗）；实时性（预计算 GAL + warm-start + anytime QP，慢环隔离）；受控降级被当免责声明（`degraded=1` 强制审计、计入长期可靠性、禁止静默）。
