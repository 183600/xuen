# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「谐波减速器」×「末端位姿」）

> R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」。R69 把不确定性拆成 aleatoric / epistemic，并让系统学会「看、问、触」。但它默认了两件事：**观测 o 是外生的，动作 ξ 是自由的**。真实的机械臂不是这样——它对世界的每一次接触都要经过「电机—减速器—连杆—关节」这条链；它唯一「亲眼看见」的是电机侧编码器计数，而**末端位姿是推出来的，不是测出来的**。这条推理链上最脆弱、也最被「高分辨率编码器」掩盖的一环，正是**谐波减速器**。
>
> 谐波减速器是数字世界与物理世界之间的「翻译官」：柔轮在椭圆波发生器下发生可控弹性变形，靠错齿啮合把高速小扭矩变成低速大扭矩。它带来近乎零背隙、高减速比、高扭矩密度——也带来三个真相：
> 1. **分辨率 ≠ 精度**：电机侧编码器经减速比 N 放大后看起来极其精细，但输出侧存在随转角周期波动的**传动误差**、随负载的**扭转柔度**、以及**迟滞**。系统会「精确地不知道自己在哪」——这是**虚假精度（false precision）**。
> 2. **误差是有结构的，不是噪声**：传动误差以输入/输出转角的**谐波级数**为基（「谐波」二字最漂亮的巧合），低维、可辨识、可补偿——也因此可以被「学成一个自洽的错误模型」。
> 3. **末端位姿是误差的放大器**：关节空间小误差经雅可比 J 映射到任务空间，在奇异位形附近被放大；反过来，**运动学冗余**让同一末端位姿可由多组关节角实现——这给了我们「换一个姿势把误差看清楚」的自由。
>
> 本轮核心命题：**末端位姿不是可直接相信的测量，而是必须被「机械可辨识性」背书的推断**。R69 的信息动作是「看/问/触」，本轮补上第四类——**「动」：一次被安全认证的激励运动（excitation）**。它既是控制动作，也是辨识探针；既能让隐藏的传动误差显形，也可能激发共振、加速磨损、并把负载扰动误学成机械误差。命名 **WAVE-RAS**（Wave-error Aware Verification of End-effector — Risk-Adaptive System）。
>
> 一句话定位：R69 学会了「问别人」，R70 学会「问自己的身体」——**用一次安全的运动，去换取一个诚实的末端位姿**。

## 0. 直觉与动机

**灵感 1（谐波减速器 → 精度是被「翻译」出来的）**
直觉：把减速器想成一个翻译官。电机说一口精确的「数字母语」（编码器计数是整数），经减速比 N 翻译成关节的「物理语言」。翻译本身有口音：柔轮弹性变形、齿廓误差、装配偏心，会在输出侧留下随转角周期变化的**传动误差**；负载会让柔轮「软一下」（扭转柔度）；换向时留下**迟滞回线**。编码器分辨率被 N 除，看起来很细，但口音（系统误差）远大于分辨率。**精度的瓶颈从来不是量化，而是翻译。** 所以末端位姿的置信度不能从编码器分辨率推，必须从**机械模型的可辨识性**推。

**灵感 2（末端位姿 → 误差有形状、有方向、有奇点）**
直觉：关节误差不会均匀地变成末端误差。J 把关节误差椭球映射成任务空间椭球：沿臂展几乎不敏感，垂直臂展、绕腕方向被放大；接近奇异位形时条件数爆炸，微小关节误差 → 巨大位姿误差。更妙的是，冗余机械臂（7-DoF）可以在不改变末端位姿的前提下**在零空间换姿势**——这正是「为看清误差而改变观测几何」。于是位姿不确定度不是一个标量，而是**随位形变化的、有方向的任务空间椭球**；「换位形」是一个可主动选择的信息动作。

**灵感 3（谐波级数 → 结构化 epistemic 可以被压缩）**
直觉：R69 的 epistemic 是「模态歧义」，靠增加采样与交互降熵。传动误差的 epistemic 不一样：它**有已知的基**（转角高次谐波 × 负载/温度调制）。这意味着不必「问很多次」，只需**辨识少数几个系数**。结构化先验把「不可约的模糊」变成「一个低维参数估计问题」——这是相对 R69 的关键方法论升级：**不是所有 epistemic 都靠采样消解，有些靠建模消解**。代价是：低维模型一旦错了，会错得很自信。

**灵感 4（迟滞回线 → 标定吸收不了的第二种意见）**
直觉：R69 用「动作似然」作标定吸收不了的冗余通道。机械侧也有一个：**扭矩—扭转回线**。可逆柔度让工作点落在某条迟滞分支上；而磨损/疲劳/润滑退化会把整条分支**平移或展宽**。运动学标定（补偿一个静态偏移）只能吸收「分支内的偏移」，吸收不了「分支本身变了」。于是 **(运动学残差↓, 分支外残差↑) 就是机械缓变故障的判别信号**——R69 的 FMA 在关节层的镜像。这条通道不需要额外传感器，只需电流/扭矩估计 + 编码器。

**灵感 5（激励是双刃剑 → 自标定的新威胁模型）**
直觉：R69 说「问错比不问更危险」。本轮说「**测错比不测更危险**」。为辨识传动误差，必须施加**持续激励（persistent excitation）**：足够丰富、足够带宽的运动。但激励会 (a) 激发结构共振与减速器扭转模态，(b) 增加齿面磨损与柔轮疲劳，(c) 把负载扰动、温度漂移与机械参数**混淆（confounding）**。最坏情况：系统用自己施加的激励把负载扰动「学」成传动误差，得到一份自洽但错误的机械模型，然后给错误的末端位姿盖上「已校准」的章。所以激励必须**预算受限、安全认证、可辨识性可检验**，并且「不可辨识时要说不知道」。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（WAVE-RAS 总览）** WAVE-RAS = (HTE, HYS, POSE-Σ, PEF, DEI, RSC, WSD, PCF, PPC, OTS, PAG, RAS-WM‡)。三不变式：
(i) **实时控制流零学习写操作**（继承 R68 定义 276-i、R69 定义 293-i）；
(ii) **激励预算硬约束**：单位时间激励能量 ≤ E_exc、激励带宽 ⊂ 安全谱（避开共振与加速磨损频带）、激励轨迹必须过 C-RAS-WM 前缀认证；
(iii) **可辨识性纪律**：未通过可辨识性检验（秩/条件数/持续激励充分性）时，不得输出高于模型不确定度的位姿精度声明，必须降级为「位姿不可验证」并收缩运动包络。

**定义 311（关节传动模型 HTE）** 关节输出角 q = q_m/N + δ，δ = δ_per(φ) + δ_comp(τ) + δ_hys(τ, τ̇) + δ_th(ΔT)，其中 φ 为转角相位，δ_per(φ) = Σ_{h=1}^{H} [a_h cos(hφ) + b_h sin(hφ)]，δ_comp = C(φ)τ 为位形相关柔度，δ_hys 为迟滞算子（Prandtl–Ishlinskii / Bouc–Wen），δ_th 为热漂移。机械状态 η = ({a_h,b_h}_{h=1..H}, C(·), hys-params, th-coeffs)。

**定义 312（迟滞分支分解 HYS）** 给定 (τ, Δq) 回线，分解 Δq = b(τ) + r_⊥，b(τ) 为当前迟滞分支上的可逆柔度分量，r_⊥ 为分支正交残差。定义机械缓变故障判据：r_⊥ 的持续漂移 vs. 运动学标定残差的下降。

**定义 313（末端位姿不确定椭球 POSE-Σ）** 关节协方差 Σ_q（含编码器噪声 + η 后验不确定度 + 未建模残差），Σ_pose = J(q)Σ_qJ(q)^T ⊕ J_ω(q)Σ_qJ_ω(q)^T（SE(3) 李代数上的 6×6），任务加权范数 ‖e‖_W = sqrt(e^TWe)。可操作性 μ(q)=sqrt(det(JJ^T))；放大因子 κ(q)=σ_max(J)/σ_min(J)。位姿精度声明只有在 max eig(Σ_pose) 与 κ 满足阈值时才可给出。

**定义 314（安全激励锥 PEF）** 激励集合 𝒢_exc = {g : PE(g) ≥ ρ_pe（识别 η 的持续激励充分性）, spec(g) ∩ ℬ_res = ∅（避开共振/磨损频带）, g ∈ 𝒮_safe（C-RAS-WM 认证的位姿/速度/力矩包络）, E(g) ≤ E_exc}。这是一个**约束交集**，可能为空——空集意味着「当前不允许辨识」，必须诚实降级。

**定义 315（对偶效应辨识 DEI）** 选择 g* = argmax_{g∈𝒢_exc} [I(η; y_g | o) − λ_w·wear(g) − λ_r·risk(g)]，其中 I 为 Fisher/互信息增益，wear(g) 为磨损代理（力矩×转角×齿面滑移的积分），risk(g) 由 WM 给出。这是一步对偶控制（dual control）近似：辨识与任务共享同一动作预算。

**定义 316（冗余自标定 RSC）** 对 N_c 个位形 {q_i} 测得末端约束（视觉/接触/工件基准），堆叠观测方程 y = [J(q_1);…;J(q_{N_c})]δq + ε。可辨识矩阵 O_N = [J(q_1);…;J(q_{N_c})]，可辨识 ⇔ rank(O_N) 覆盖 η 在关节空间的投影且 cond(O_N) ≤ κ_max。零空间重构 q → q + N(q)Δ 不改变末端位姿，只改变观测几何——这是「换姿势去看」。

**定义 317（磨损/漂移检测 WSD）** 联合统计量 (r_kin↓, r_⊥↑)（运动学残差下降、分支外残差上升）或 (η̂ 漂移超阈值且不可由温度/负载解释) ⇒ 机械缓变故障疑。对应 R69 的 (r_res↓, Δa↑)。

**定义 318（物理标定指纹 PCF）** 每个减速器单元的 η 签名因制造公差而具 individuality；定义指纹 F = Hash(η̂ | 规范化工况)，用于换装/仿制/掉包检测，并接入 R68 换装不变式。指纹比对须在**不泄露可伪造明文**的前提下进行（加盐哈希 / 安全多方）。

**定义 319（位姿证明 PPC）** J_WAVE = (J_FLUID, η̂ 后验, Σ_pose 及其任务方向投影, r_⊥, 可辨识性 (rank, cond, ρ_pe), 激励预算使用, F 指纹, wave_ver)。Valid ⇔ Valid(J_FLUID) ∧ 可辨识性通过 ∧ 精度声明 ≤ 模型不确定度上界 ∧ 激励在安全谱内。

**定义 320（精度声明门 PAG）** 若 max eig(Σ_pose) 或 κ(q) 越界，或 η 不可辨识，则 PPC 必须把位姿声明降级为「不可验证」，并触发保守运动包络（λ 上调、速度/加速度收缩）。这是「诚实精度」的硬门。

**定义 321（激励投毒干扰集 ℰ_exc）** 载荷欺骗/外力共谋（把负载扰动伪装成传动误差）、激励饥饿（长期不给辨识窗口以隐藏磨损）、指纹重放/伪造、共振诱导攻击（诱发不安全激励）。并入 AIC：ℰ_WAVE = ℰ_FLUID × ℰ_exc。

**定义 322（观测-任务位形调度 OTS）** 任务冗余解 q = q_task + N(q)Δ；选择 Δ 使任务精度不被牺牲、同时改善可辨识性：argmin_Δ [α·tr(WΣ_pose(q+Δ)) + β·cond(O_N(q+Δ))]，s.t. 任务约束。这是把「换姿势」作为信息动作 g_conf 与任务动作联合优化。

**定义 323（分层误差预算 LEB）** 把末端位姿误差预算显式分为 ε_sensor（编码器/噪声）、ε_model（未辨识传动误差）、ε_id（η 后验）、ε_unmodeled（未建模/磨损）、ε_task（任务容忍）。声明 ε_total ≤ ε_task 才算「位姿合格」；各分量来源不同、不可互相抵消。

**定义 324（辨识收敛与遗忘平衡）** η̂ 用带遗忘的贝叶斯/RLS 更新 η̂_{t+1} = η̂_t + K_t(y_t − h(η̂_t))，遗忘因子 γ 决定「跟随磨损」与「抑制噪声」的折中；稳态辨识误差界 e_∞ ≤ sqrt((1−γ)/γ)·σ_ε/√(PE)。当 PE 不足时 e_∞ 上升，PPC 必须扩 Σ_pose。

**定义 325（辨识完整性审计 VQAuditor-M）** 审计：激励是否在安全谱与预算内、负载是否被混淆为机械误差、指纹是否被重放、可辨识性声明是否被夸大、位姿精度声明是否超过模型不确定度。结论回灌 AuditBuf，作为下一轮 DEI 的 wear 成本先验。

**定义 326（WAVE 闭环与严格包含）** 当 E_exc = 0 且无冗余时，DEI/RSC 不激活，η̂ 冻结在初始标定值，WAVE-RAS 逐指令退化为 R69 FLUID-RAS；当交互预算也为 0 时进一步退化为 R68。安全侧单调不弱。

```python
# IP-264 HTE：谐波传动误差模型（低维、结构化）
class HarmonicTransmissionModel:
    def forward(self, q_m, tau, tau_dot, dT, eta):
        phi = q_m / N
        d_per = sum(eta.a[h]*cos(h*phi) + eta.b[h]*sin(h*phi) for h in H)
        return (q_m/N + d_per + self.compliance(phi, tau, eta)
                + self.hysteresis(tau, tau_dot, eta) + self.thermal(dT, eta))

# IP-265 HYS：迟滞分支分解（标定不可吸收的机械第二意见）
def hysteresis_residual(tau_hist, dq_hist, eta):
    branch  = fit_prandtl_ishlinskii(tau_hist, dq_hist)   # 可逆柔度分支
    r_perp  = dq_hist - branch(tau_hist)                  # 分支正交残差
    return branch, r_perp

# IP-266 POSE-Σ：任务空间位姿不确定椭球（含奇异放大）
def pose_covariance(q, Sigma_q, W):
    J6      = vstack([geometric_jacobian(q), angular_jacobian(q)])  # 6×n
    Sigma6  = J6 @ Sigma_q @ J6.T
    kappa   = cond(J6)                                    # 奇异性放大
    return Sigma6, kappa, task_projection(Sigma6, W)

# IP-267/268 PEF+DEI：安全激励下的对偶辨识
def choose_excitation(state, budget):
    best = None
    for g in excitation_candidates(state):                # 带限、低幅、零空间为主
        if not budget.allow(g): continue
        if not spectrum_ok(g, RESONANCE_BANDS): continue
        if not c_ras_wm.certify_exc(g, state): continue
        info  = fisher_gain(g, state.eta_hat, state.Sigma_eta)
        score = info - LAMBDA_W*wear_proxy(g) - LAMBDA_R*risk(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None     # 激励不划算 → 冻结 η

# IP-269 RSC：冗余位形自标定（换姿势观测）
def redundant_self_calib(robot, eta_hat, N_c=3):
    obs = []
    for q in null_space_configs(robot, N_c):              # 不改末端位姿
        y = measure_task_constraint(robot, q)             # 视觉/接触基准
        obs.append((vstack([geometric_jacobian(q), angular_jacobian(q)]), y))
    O = vstack([J for J, _ in obs]); y = hstack([y for _, y in obs])
    if rank(O) < RANK_MIN or cond(O) > COND_MAX:
        return None, "unidentifiable"
    return solve_weighted(O, y, eta_hat), "ok"

# IP-270 WSD：机械缓变故障
def wear_suspect(r_kin, r_perp, eta_drift):
    return (r_kin < TAU_KIN) and (r_perp > TAU_PERP or eta_drift > TAU_ETA)
```

## 3. 推导

**引理 19（结构化 epistemic 的可压缩性）** 若传动误差落在 H 维谐波基内，则冗余观测下 η 的后验方差 ~ σ_ε²/(N_c·PE)，辨识误差按 O(H/N_c) 下降，而非随状态维数指数增长。要点：结构化先验把 R69 的「采样降熵」换成「参数辨识」，少量系数即可买到大部分精度；但基失配（非谐波故障，如单齿剥落）时该界失效，必须由 r_⊥ 兜底。系：**该建模的多花模型，不该建模的才花采样**。

**引理 20（末端正确 ≠ 关节正确：可辨识性秩条件）** 设 δ 经 J 映射为末端误差 Jδ。单个位形下只能观测 δ 在 row(J) 上的投影，null(J) 内的误差（在末端相互抵消的关节误差）**不可见**。堆叠 N_c 个位形后 O_N = [J(q_1);…;J(q_{N_c})]，可辨识 ⇔ λ_min(O_N^T O_N) > 0 且覆盖 η 的投影。系：**末端位姿合格不能证明关节模型正确**——补偿误差可以互相抵消；这正是 PPC 必须同时报告 rank/cond 的原因。

**引理 21（迟滞分支的不可吸收性）** 运动学标定只能吸收分支内的静态偏移。若磨损使分支基线平移 Δ_b、回线宽度变化 Δ_w，则分支正交残差满足 ‖r_⊥‖ ≥ |Δ_b| − O(noise)（宽展时 ≥ c·Δ_w），而运动学残差可被重拟合压到 ≈0。故 (r_kin↓, r_⊥↑) 是机械缓变故障的判别性联合模式，是 R69 引理 17 的机械镜像。

**引理 22（安全激励的信息-磨损 Pareto）** 安全激励锥 𝒢_exc 可能为空；非空时，可用 Fisher 信息被「共振带以外的谱预算」上界约束；在磨损代理对激励能量单调、信息对能量边际递减的温和假设下，信息-磨损前沿近似凹，故一步贪心 DEI 与最优多步策略相差常数因子。系：**不给辨识留窗口，不是安全，而是把故障留给未来**；但为辨识而无界激励，是拿寿命换精度。

**定理 18（WAVE 严格包含 R69/R68）** 令 E_exc = 0 且无冗余 ⇒ DEI/RSC 不激活、η̂ 冻结、PAG 的降级不弱于 R69；此时 WAVE-RAS 与 FLUID-RAS 逐指令相同。进一步令交互预算为 0 ⇒ 退化为 R68。安全侧单调不弱，效率侧仅从「可辨识的机械误差」中获取增益。

**定理 19（位姿证书的可靠性）** 在 A99–A102（误差落在谐波基内、可辨识秩条件成立、未建模项有界、激励在安全谱内）下，PPC 声明的位姿误差界是可靠的：P(‖e_true‖_W ≤ claimed) ≥ 1−α；任一条假设失效时 PAG 强制降级。关键：**claim 下界由 max(Σ_pose 特征值, 未建模界) 决定，而不是编码器分辨率**——证书不允许把「量化细」说成「精度高」。

**定理 20（激励安全与无突变）** 经 C-RAS-WM 认证的激励使物理风险 ≤ ε_exc、磨损增量 ≤ 预算；激励只改变 η̂/Σ_pose，不改变安全包络；失败/超时/不可辨识时冻结 η 并单调降级到 R69；换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变。

## 6. 本轮最大风险

**一句话**：WAVE-RAS 的全部精度收益押在「激励能辨识出真实的机械误差」这一前提上——但**激励本身会改变被观测的机器**（发热、磨损、迟滞分支移动），并把负载/温度扰动与机械参数混淆；若辨识用一个自洽却错误的 η̂ 收敛，PPC 会为错误的末端位姿盖上「已验证」的章——**为了测准而运动，反而把机器测偏、测坏**，测错比不测更危险。

**次级风险与缓解**：可辨识性误判（引理 20 的秩/条件数硬门 + PAG 降级）；负载混淆（对偶辨识中显式建模 τ/ΔT + E309 对抗集）；激励诱发共振/磨损（PEF 安全谱 + 磨损预算 + 定理 20）；基失配（非谐波故障由 r_⊥ 兜底，E301/E307）；指纹伪造/重放（加盐哈希 + ℰ_exc + 不泄露明文）；长时程遗忘（带遗忘辨识 + E314）。

```python
    if g_exc is not None:
        M.eta_hat, M.Sigma_eta = M.dei.identify(g_exc)
    if (not ident) or kappa > KAPPA_MAX or wear:
        M.pag.downgrade("pose_unverified"); lam = max(lam, 0.8)
    claim = M.ppc.certify(M.eta_hat, M.Sigma_eta, Sigma6, r_perp, ident)
    M.vqa_m.submit_async(g_exc, claim, wear, r_perp)
    return claim, lam
```

## 4. 推导

**引理 19（结构化 epistemic 可压缩性）** 误差落在 H 维谐波基内时，η 后验方差 ~ `σ_ε²/(N_c·PE)`，辨识误差按 `O(H/N_c)` 下降，不随状态维数指数增长。系：该建模的花模型，不该建模的才花采样；基失配（单齿剥落等）由 r_⊥ 兜底。

**引理 20（末端正确 ≠ 关节正确）** 单位形仅可观测 δ 在 row(J) 上的投影，null(J) 内误差不可见；堆叠 N_c 位形后可辨识 ⇔ `λ_min(O_NᵀO_N)>0`。系：末端位姿合格不能证明关节模型正确——补偿误差可互相抵消；故 PPC 必须同时报 rank/cond。

**引理 21（迟滞分支不可吸收性）** 运动学标定只吸收分支内静态偏移；磨损使分支基线平移 Δ_b、宽度变化 Δ_w 时，`‖r_⊥‖ ≥ |Δ_b| − O(noise)`（宽展时 ≥ c·Δ_w），而运动学残差可被重拟合压到 ≈0。故 `(r_kin↓, r_⊥↑)` 为机械缓变故障判别模式。

**引理 22（信息-磨损 Pareto）** 安全激励锥可能为空；非空时 Fisher 信息被「共振带外谱预算」上界约束；磨损对能量单调、信息边际递减时前沿近似凹，一步贪心 DEI 与最优多步相差常数因子。系：不给辨识留窗口是把故障留给未来，无界激励是拿寿命换精度。

**定理 18（WAVE 严格包含 R69/R68）** E_exc=0 且无冗余 ⇒ DEI/RSC 不激活、η̂ 冻结、PAG 不比 R69 更松；WAVE 与 FLUID 逐指令相同。交互预算为 0 ⇒ 退化为 R68。安全侧单调不弱，效率增益仅来自「可辨识的机械误差」。

**定理 19（位姿证书可靠性）** A99–A102（误差在谐波基内、可辨识秩条件、未建模有界、激励在安全谱）下，`P(‖e_true‖_W ≤ claimed) ≥ 1−α`；任一假设失效则 PAG 强制降级。claim 下界由 `max(eig Σ_pose, 未建模界)` 决定，而非编码器分辨率。

**定理 20（激励安全与无突变）** 认证激励使风险 ≤ ε_exc、磨损 ≤ 预算；激励只改 η̂/Σ_pose，不改安全包络；失败/超时/不可辨识即冻结 η 并单调降级 R69；换装不变式保持 ⇒ 控制连续、无突变。

## 7. 本轮最大风险

**一句话**：WAVE-RAS 的全部精度收益押在「激励能辨识出真实机械误差」这一前提上——但**激励本身会改变被观测的机器**（发热、磨损、迟滞分支移动），并把负载/温度扰动与机械参数混淆；若辨识收敛到一个自洽却错误的 η̂，PPC 就会为错误的末端位姿盖上「已验证」的章——**为了测准而运动，反而把机器测偏、测坏**，测错比不测更危险。

**次级风险与缓解**：可辨识性误判（引理 20 秩/条件数硬门 + PAG 降级）；负载混淆（对偶辨识显式建模 τ/ΔT + E309 对抗集）；激励诱发共振/磨损（PEF 安全谱 + 磨损预算 + 定理 20）；基失配（非谐波故障由 r_⊥ 兜底，E301/E307）；指纹伪造/重放（加盐哈希 + ℰ_exc + 不泄明文）；长时程遗忘（带遗忘辨识 + E314）。
