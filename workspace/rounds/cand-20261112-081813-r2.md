# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环新一轮；本轮灵感：「通信延迟」×「放置」）

> 第 59 轮把安全论证一路压到电流环、WCET 与阻抗证书，堵住了「执行器不是理想执行器」的抽象泄漏。但它仍然默认了三件昂贵的免费午餐：**观测在本地即时可得、所有证据共享同一时基、放置点只由静态几何决定**。本轮两个灵感正好从「时空」与「拓扑」两个方向撕开这个前提：**通信延迟**说明证据存在两套时间——事件时间与到达时间；延迟不是加性高斯噪声，而是**证据与动作之间的时空错位**，你用来决策的观测描述的是另一个时刻、甚至另一个坐标系里的世界；**放置**则不是一个点，而是三个层次耦合的决策——**接触/落足点放置**（物理承诺，往往不可逆）、**通信中继放置**（改变链路质量）、**计算任务放置**（决定证据在边缘还是云端处理，从而决定时延）。更关键的是它们**双向耦合**：放置改变通信拓扑与证据新鲜度，通信延迟又反过来收缩「可安全放置」的集合。本轮核心命题：**「让每一次放置都携带一个可验证的时空有效域；放置只发生在证据仍然新鲜、通信契约仍然成立、回退窗口仍然开放的时空交集内；反过来，让放置本身成为主动缩短证据路径、降低时延、延长可承诺窗口的设计变量」**——从第 59 轮的**执行接地（Execution-Grounded）**推进到**延迟-放置接地（Delay-Placement Grounded, DPG）**。

核心矛盾：

- **H32（延迟非噪声·证据的时空错位）**：第 59 轮的 ERTC/EEIS 把端到端抖动压到毫秒级，却只覆盖**单机内部**从决策到电流环的链路；一旦证据来自另一台机器人、边缘节点或云端，通信延迟可达 20~500 ms，且带排队、丢包、时钟偏斜。把延迟当高斯噪声加宽协方差是错的：延迟是**确定性/半确定性的时间偏移**，它让「基于 t_e 时刻信念选择的落足点」被放到 t_e+τ 时刻的世界上。若不显式建模事件时间、到达时间与每跳延迟账本，所有共形覆盖率与安全界都建立在**错位样本**上。
- **H33（放置是承诺·延迟下可达集收缩）**：第 59 轮把「承诺」编译成阻抗参数，但承诺最终要落到一个**物理放置点**（落足点、抓取点、接触点）。延迟 τ 导致位置/姿态不确定性按动力学膨胀，安全落足集合 `P_valid(τ)` 随 τ 单调收缩；当 τ 超过**坍缩时间 τ_collapse(δ_f)**，任何放置点都不再满足摩擦锥/支撑多边形/力限幅余量。此时正确动作不是「更用力地放置」，而是 **WAIT / 换点 / 降速 / 停**。没有 `τ_collapse` 的概念，系统会在延迟增大时仍然自信地落错。
- **H34（放置-通信双向耦合·三层放置未联合）**：接触放置改变机体姿态与天线朝向，中继放置改变链路质量，计算放置改变证据处理时延；三者共同决定端到端证据年龄。反之，链路质量又约束哪些放置点可被及时验证。现有做法把「规划落足点」「部署中继」「调度边缘任务」分成三条独立流水线，结果每层都局部最优、全局却互相拆台：为了一个几何更优的落足点，可能把机体转到通信盲区；为了降低云端时延，可能把关键计算放到散热受限的节点上。
- **H35（分布式不一致·陈旧多数与不可逆落点）**：多机/多节点对同一放置点持有不同事件时间的视图。通信延迟下，一个「多数派」可能全部基于陈旧证据，而唯一新鲜的少数派被投票淹没。对**不可逆放置**（承重落足、易碎物抓取），必须规定「陈旧多数不得否决新鲜少数」「跨事件时间桶不得直接融合」「无最新桶法定人数则降级为本地安全放置或停」。

## 0. 直觉与动机

**灵感 1（通信延迟 → 延迟账本与事件时间证据 DPEO）**
直觉：收到一条观测时，先别问「它说了什么」，先问「它说的是什么时候的世界、走了哪条路、迟到了多久」。一条证据应携带：事件时间区间 `[t_e^-,t_e^+]`（曝光/积分/采样窗口）、到达时间 `t_a`、每跳传播/排队/处理延迟、时钟偏斜界 `θ_sync`、网络路径与版本、以及它**对哪个放置点仍然有效**。延迟不是给协方差加一个方差，而是给证据加一个**有效域**：超过新鲜期的证据只能用于校准日志或保守回退，不能支撑不可逆放置。

**灵感 2（放置 → 放置有效锥 PVC 与鲁棒放置合成 RPS）**
直觉：延迟 τ 内，机体会继续运动、扰动会继续作用，真实状态位于一个随时间膨胀的**可达管**里。一个落足点是否安全，不取决于名义轨迹是否踩中，而取决于「整根可达管」是否都落在摩擦锥、支撑多边形、关节限位与力限幅的安全域内。于是 `P_valid(τ)` 是 τ 的单调收缩集；τ 越大，可放置点越少。把高层 `δ_f` 编译成各约束的余量（滑移、倾覆、力超限、延迟、放置），再在 `P_valid(τ)` 内选「进度最大、回退成本最低」的放置点，就得到**带证书的放置承诺**。

**灵感 3（放置 → 放置-通信联合设计 PCCD）**
直觉：既然放置会改变通信、通信延迟又会收缩放置，那就不要分开做。把三类放置变量放进同一个目标：接触点 `p_c`、中继点 `p_r`、计算落点 `p_x`；链路时延/丢包/带宽是它们的函数；证据年龄与任务进度是链路与放置的函数。联合优化当然 NP-hard，但可以分解：先固定通信放置求安全接触集，再固定接触集用子模贪心/整数规划布置中继与计算，交替若干轮并有界终止。**放置第一次不只是「往哪里放」，而是「把证据路径缩短到哪里」。**

**灵感 4（通信延迟 → 时效感知放置调度 APS）**
直觉：不是所有区域都值得同样新鲜。高风险、不可逆的放置点需要「刚更新过」的证据；低风险巡检点可以容忍更旧的证据。为每个放置点定义新鲜度截止 `D_i(δ)`：超过它，放置就从「可承诺」降为「需重探/降速/停」。调度器在探针预算、通信预算与放置预算下，最小化**加权平均信息年龄（AoI）**，而不是最大化探针次数。探针本身也有放置：把探针放到「能同时刷新多个高价值区域」的位置，是一种传感器放置问题。

**灵感 5（分布式 → 延迟有界放置共识 DBPC）**
直觉：多机协商「这个落点能不能踩」时，最危险的不是没有共识，而是**用陈旧共识覆盖新鲜证据**。做法是按事件时间分桶：只在同一时间桶内做有效共识；最新桶达到法定人数才允许不可逆放置；旧桶可以提示风险，但不能否决最新桶的新鲜事实；跨地图/坐标系版本必须先调和变换与协方差；分区或无最新桶法定人数时，降级为本地安全放置或停，绝不强行全局一致。

**灵感 6（不可逆放置 → 预承诺/回退契约 PCB 与六预算 PCE+++++）**
直觉：放置是承诺的物理落地，而物理落地常常不可逆。与其「落下去再后悔」，不如引入**预承诺 + 释放窗口**：在 `t_commit` 下发，但真正生效在 `t_apply`；两者之间保留一个 abort 窗口，任何更新的证据都可在窗口内撤销。同时定义**可回退时域 H_rev**：在力、位移、时间未超过阈值前，回退是安全的；超过则视为不可逆，必须走更强的证据门。第 59 轮的四预算再补 `B_comm`（链路/同步/AoI）与 `B_place`（不可逆放置次数、回退次数、放置风险预算），得到六预算 `B_probe/B_ft/B_ux/B_exec/B_comm/B_place`；任一预算耗尽只能让动作更保守。

## 1. 形式化定义（增量：定义 153–160）

**定义 153（延迟-放置证据对象 DPEO）**
*直觉：证据 = 一个信念 + 一段事件时间 + 一条延迟账本 + 一个「对哪些放置点还有效」的适用域。*
形式化：证据
```
e = ⟨ b_e, F_e, I_e=[t_e^-,t_e^+], t_a^e, θ_sync^e, Π_net^e, m_e, ρ_e(·), w_e(·) ⟩
```
其中 `b_e` 是参考帧 `F_e` 中的信念（位姿/区域/力/语义分布），`I_e` 是事件时间有效区间，`t_a^e` 是到达时间，`θ_sync^e` 是时钟偏斜上界，`Π_net^e` 是从源到消费者的网络路径与每跳版本，`m_e` 是地图/标定版本，`ρ_e(p)∈[0,1]` 是该证据对候选放置点 `p` 的**放置适用度**，`w_e(τ)=exp(−max(0,τ)/τ_0)` 是陈旧度权重。

延迟账本与证据年龄：
```
d_e       = t_a^e − t_e^+                                   # 观测到的到达延迟
d̄_e       = Σ_{h∈Π_net^e} (d_h^prop + d_h^queue + d_h^proc) + θ_sync^e   # 可证明上界
τ_e(t)    = t − t_e^+ + 2θ_sync^e                           # 使用时刻的证据年龄（含双边偏斜）
```
放置支撑谓词 `e ≽ (p, W=[t_c,t_c+Δ_exec])` 当且仅当：
```
(i)   τ_e(t_c) ≤ T_valid(e)                                  # 证据仍在保鲜期
(ii)  d̄_e + Δ_exec ≤ D_max(p, δ_f^req)                      # 延迟预算支撑该放置
(iii) F_e 与消费者帧可由 Π_frame 复合，且 m_e 在 δ_map 内可调和
(iv)  ρ_e(p) ≥ ρ_min                                        # 证据与放置点空间相关
(v)   p ∈ P_valid(τ_e(t_c)+Δ_exec)                          # 放置有效锥仍非空
```
若任一条件失败，`e` 只能进入校准日志或触发保守回退，**不得支撑不可逆放置**。

**定义 154（放置有效锥 PVC 与坍缩时间）**
*直觉：延迟期间世界不会停下来；安全放置必须让整根「可能状态管」都安全，而不是让名义点安全。*
形式化：设 `t_e` 时刻状态估计为 `x̂_e`，误差椭球 `E(Σ_e)`，动力学 Lipschitz 常数 `L`，扰动上界 `w_max`，从证据到放置生效的时延 `τ = τ_e(t_c)+Δ_exec`。可达集保守外包：
```
R(τ) = x̂_e ⊕ E(e^{Lτ} Σ_e e^{Lᵀτ}) ⊕ B(r_w(τ))
r_w(τ) = (e^{Lτ}−1)/L · w_max          （L→0 时退化为 w_max·τ）
```
工程上可用更紧的二阶界 `r(τ)=r_0+v_max τ+½a_max τ²`（含通信延迟与执行延迟）。对放置点 `p`，定义约束余量 `m_j(p,R(τ))`（滑移、倾覆、力超限、关节限位、碰撞）。安全放置集：
```
P_valid(τ) = { p ∈ P_free : m_j(p,R(τ)) ≥ m_j^safe(δ_f^req), ∀j }
τ_collapse(δ_f^req) = sup{ τ ≥ 0 : P_valid(τ) ≠ ∅ }
```
`P_valid(τ)` 随 τ 单调收缩；若 `τ > τ_collapse`，**任何放置都不安全**，必须进入 `{WAIT, RE_PROBE, SLOW, REROUTE, STOP}` 降级集。

**定义 155（鲁棒放置合成 RPS）**
*直觉：把「允许多大概率失败」翻译成「落点周围必须留多宽的余量」，再在余量内选最优放置。*
形式化：风险分配
```
δ_f^req = δ_slip + δ_tip + δ_force + δ_delay + δ_place      （Boole 联合界）
m_j^safe(δ_j) = Φ^{-1}(1−δ_j/c)·σ_j + m_j^0                 （或共形分位数）
```
放置合成：
```
p* = argmax_{p∈P_free}  λ_g·progress(p) − λ_r·risk(p) − λ_b·retract_cost(p)
s.t.  p ∈ P_valid(τ(p))                                   # 有效锥非空
      τ(p) = τ_e(t_c)+Δ_exec+d̄_e ≤ τ_collapse(δ_f^req)     # 延迟未坍缩
      contact_wrench(p) ∈ FrictionCone(μ, γ_f(δ_slip))     # 摩擦锥内余量
      CoM_proj ∈ SupportPolygon(p, γ_s(δ_tip))             # 支撑多边形内余量
      reachable(p) ∧ joint_limits ∧ force_limits
      reversibility(p) ≥ R_min(δ_f^req) 或 走不可逆证据门
```
输出放置证书
```
Cert_place = (p*, support_poly, margin_vector, τ_budget, d̄_e,
              risk_alloc, assumptions, map_version, planner_version, timestamp)
```
若可行集为空，`RPS` 必须返回 `∅` 与原因，而不是返回「最不坏」的点。

**定义 156（放置-通信联合设计 PCCD）**
*直觉：接触点、中继点、计算落点是同一张图上的三类放置；链路时延是它们的函数，证据年龄又是链路时延的函数。*
形式化：变量 `p = (p_c, p_r, p_x)`；链路 `(i,j)` 的时延/丢包/带宽模型
```
d_ij(p) ≤ d̄_ij(p) = d_prop(‖p_i−p_j‖) + d_queue(load) + d_proc(p_x)
ℓ_ij(p) ≤ ℓ̄_ij(p),   b_ij(p) ≥ b_min
```
端到端证据时延与信息年龄：
```
D_e2e(p) = Σ_{(i,j)∈path(p)} d̄_ij(p) + d_sync(p)
Ā_w(p)   = lim_{T→∞} (1/T)∫_0^T Σ_i w_i (t − u_i(p,t)) dt
```
联合优化：
```
max_{p_c,p_r,p_x}  E[G(p_c)] − λ_A·Ā_w(p) − λ_R·Risk(p_c) − λ_C·Cost(p_r,p_x)
s.t.  D_e2e(p) ≤ D_max(δ_f^req),  ℓ_ij(p) ≤ ℓ_max,
      p_c ∈ P_valid(τ(p)),  connectivity(G(p)),  capacity(p_x),  energy(p_r,p_x)
```
该问题含设施选址 + 图连通 + 接触规划，NP-hard。采用分解：
1. 固定 `(p_r,p_x)`，求安全接触放置 `p_c`（RPS）；
2. 固定 `p_c`，若中继目标为覆盖/年龄缩减且满足单调子模性，用贪心得 `1−1/e` 近似；否则用 MILP/分支定界；
3. 交替至多 `K_alt` 轮或目标改进 `<ε`；每轮保留可行上界用于提前剪枝。
输出联合证书 `Cert_pccd=(p_c,p_r,p_x, D_e2e_bound, AoI_bound, connectivity_proof, version)`。

**定义 157（时效感知放置调度 APS）**
*直觉：新鲜度是有限资源；把探针放在能同时刷新多个高价值区域的位置，比均匀刷新更划算。*
形式化：区域/放置候选 `i`，最近一次有效更新时间 `u_i(t)`，信息年龄 `Δ_i(t)=t−u_i(t)`。加权平均 AoI：
```
Ā_w = lim_{T→∞} (1/T) ∫_0^T Σ_i w_i Δ_i(t) dt
```
每个放置点的新鲜度截止：
```
D_i(δ) = max{ τ : risk_i(τ) ≤ δ }        # 由 PVC 反解，通常 D_i ≤ τ_collapse
```
调度动作 `a=(p, modality, t)`，成本 `c(a)=c_probe+c_comm+c_exec`，更新收益为多个区域 AoI 的下降。在 `B_probe, B_comm, B_place` 约束下最小化
```
J_aps = Ā_w + λ_r·Σ_{i: Δ_i>D_i} risk_i(Δ_i) + λ_c·Σ c(a)
```
求解：加权贪心 / Whittle 指数 / 模型预测（短视界）。硬规则：`Δ_i(t) > D_i(δ)` 的放置点**不得**进入不可逆承诺集，只能 `RE_PROBE` 或降级。

**定义 158（延迟有界放置共识 DBPC）**
*直觉：只允许「同一事件时间桶」内的证据投票；陈旧多数不能否决新鲜少数；没有最新桶法定人数就不做全局不可逆放置。*
形式化：智能体集 `A`，提案 `π=(p, t_e, map_version, evidence_ids, τ_e)`。按事件时间分桶
```
B_k = ((k−1)δ_t, kδ_t],   π ∈ B_k ⇔ t_e ∈ B_k
```
有效共识条件：
```
(C1) 所有参与提案 τ_e ≤ τ_max 且 d̄_e ≤ D_max
(C2) 法定人数 Q 全部来自同一个最新事件时间桶 B_k*
(C3) 地图/帧版本满足 |m_i−m_j| ≤ δ_map，且变换协方差 ≤ ε_T
(C4) 旧桶提案只能标记风险（veto_hint），不能覆盖 B_k* 的新鲜多数
(C5) 无 B_k* 法定人数 / 分区 / 版本不可调和 ⇒ 本地安全放置或 STOP
```
输出 `Cert_dbpc=(B_k*, quorum_set, proposal_hashes, map_version_chain, partition_flag, timestamp)`。不可逆放置必须携带该证书；只有 `(C1)–(C5)` 全过才允许跨机承诺。

**定义 159（放置承诺/回退契约 PCB 与六预算 PCE+++++）**
*直觉：放置要先「预约」再「生效」，中间留一个可撤销窗口；超过可回退时域就升级为不可逆承诺，需要更强证据。*
形式化：承诺
```
c = (p, t_commit, t_apply, Δ_exec, evidence_set, reversibility)
```
生效前窗口 `[t_commit, t_apply)` 内，若新证据使 `risk(c) > δ_f^req` 或 `τ_collapse` 被越过，则 **ABORT**。可回退时域：
```
H_rev = max{ h : retract_force(h) ≤ F_rev ∧ displacement(h) ≤ x_rev ∧ h ≤ t_rev }
```
`h ≤ H_rev` 且存在安全回退动作 ⇒ 可回退放置；否则为不可逆放置，必须满足 `EV-human` 或 `EV-xmodal(L1)` 等更强证据门（不得用 `EV-place` 自证）。
六预算：
```
B = (B_probe, B_ft, B_ux, B_exec, B_comm, B_place)
B_comm  = (BW_slack, D_slack, Sync_slack, Loss_tol)
B_place = (Irrev_left, Retract_left, Risk_left, Time_left)
```
六者单调、互不挪用；VOI 显式扣除通信与放置成本：

### IP-152 DPEO（延迟-放置证据对象与支撑判定）

```python
class DelayPlacementEvidence:
    def __init__(self, belief, frame, t_event_lo, t_event_hi, t_arrival,
                 clock_skew, net_path, map_version, place_relevance):
        self.b = belief
        self.F = frame
        self.I = (t_event_lo, t_event_hi)
        self.t_a = t_arrival
        self.theta = clock_skew
        self.path = net_path            # per-hop prop/queue/proc bounds, versions
        self.m = map_version
        self.rho = place_relevance      # p -> [0,1]

    def delay_upper(self):
        return sum(h.prop + h.queue + h.proc for h in self.path) + self.theta

    def age(self, t):
        return max(0.0, t - self.I[1]) + 2 * self.theta

    def supports(self, placement, window, delta_f, pvc, budget):
        tau = self.age(window.t_c) + window.delta_exec
        if tau > T_VALID: return False, "stale"
        if self.delay_upper() + window.delta_exec > budget.D_max(placement, delta_f):
            return False, "delay_budget"
        if not frames_composable(self.F, placement.frame, self.path, self.m):
            return False, "frame_or_map"
        if self.rho(placement.p) < RHO_MIN:
            return False, "irrelevant"
        if not pvc.nonempty(tau, delta_f):
            return False, "placement_cone_empty"
        return True, "ok"

    def to_ledger(self):
        return DelayLedger(event_interval=self.I, arrival=self.t_a,
                           delay_upper=self.delay_upper(), clock_skew=self.theta,
                           path_hash=hash_path(self.path), map_version=self.m)
```

### IP-153 PVC（放置有效锥与鲁棒放置合成）

```python
class PlacementValidityCone:
    def __init__(self, dynamics, uncertainty):
        self.L = dynamics.lipschitz
        self.w_max = uncertainty.disturbance_bound
        self.sigma_e = uncertainty.cov

    def reachable_bound(self, tau):
        if self.L < 1e-9:
            r_w = self.w_max * tau
        else:
            r_w = (math.exp(self.L * tau) - 1.0) / self.L * self.w_max
        r_0 = math.sqrt(np.linalg.eigvalsh(self.sigma_e)[-1])
        return r_0 + r_w                     # 保守标量界，或返回椭球

    def margins(self, p, tau, world):
        R = self.reachable_bound(tau)
        return {
            'slip': world.friction_margin(p, R),
            'tip': world.support_margin(p, R),
            'force': world.force_margin(p, R),
            'collision': world.clearance(p, R),
        }

    def valid(self, p, tau, delta_f):
        m = self.margins(p, tau, world)
        return all(m[j] >= safe_margin(j, delta_f) for j in m)

    def collapse_time(self, delta_f, p_space, tau_hi):
        lo, hi = 0.0, tau_hi
        if self.valid_any(p_space, lo, delta_f) is None:
            return 0.0
        for _ in range(40):
            mid = 0.5 * (lo + hi)
            if self.valid_any(p_space, mid, delta_f) is not None:
                lo = mid
            else:
                hi = mid
        return lo


class RobustPlacementSynthesizer:
    def synthesize(self, p_space, tau, delta_f, prefer):
        alloc = allocate_risk(delta_f)       # slip/tip/force/delay/place
        feas = [p for p in p_space
                if pvc.valid(p, tau, delta_f)
                and prefers_reachable(p, prefer)
                and reversibility(p) >= R_MIN]
        if not feas:
            return None, Failure("P_valid_empty_or_delay_collapse")
        best = max(feas, key=lambda p: (
            LAMBDA_G * progress(p) - LAMBDA_R * risk(p) - LAMBDA_B * retract_cost(p)
        ))
        cert = PlacementCertificate(
            p=best, tau=tau, delay_budget=alloc.delay,
            margin_vector=pvc.margins(best, tau, world),
            risk_alloc=alloc, assumptions=pvc.assumptions(),
            map_version=world.map_version, planner_version=PLANNER_V
        )
        return best, cert
```

### IP-154 PCCD（放置-通信联合设计）

```python
class PlacementCommCoDesigner:
    def solve(self, task, graph, contact_space, relay_space, compute_space, budgets):
        p_r, p_x = self.init_comm_placement(graph, relay_space, compute_space)
        best = None
        for _ in range(K_ALT):
            # (1) 固定通信，求接触放置
            p_c, cert_place = rps.synthesize(
                contact_space, tau=self.e2e_delay(graph, p_r, p_x),
                delta_f=task.delta_f, prefer=task.progress
            )
            if p_c is None:
                p_r, p_x = self.relax_comm(graph, p_r, p_x)
                continue
            # (2) 固定接触，优化中继/计算（子模贪心或 MILP）
            p_r, p_x = self.optimize_comm(
                graph, p_c, relay_space, compute_space,
                objective=lambda pr, px: (
                    -LAMBDA_A * self.aoi_bound(graph, p_c, pr, px)
                    -LAMBDA_C * self.cost(pr, px)
                ),
                constraints=lambda pr, px: (
                    self.e2e_delay(graph, pr, px) <= budgets.D_max and
                    self.loss_bound(graph, pr, px) <= LOSS_MAX and
                    self.connected(graph, pr)
                )
            )
            cand = (p_c, p_r, p_x)
            score = self.score(task, cand)
            if best is None or score > best.score:
                best = Candidate(cand, score)
            if self.converged(best, _): break
        cert = CoDesignCertificate(
            p_c=best.p_c, p_r=best.p_r, p_x=best.p_x,
            d_e2e_bound=self.e2e_delay(graph, best.p_r, best.p_x),
            aoi_bound=self.aoi_bound(graph, *best),
            connectivity_proof=self.connectivity_cert(graph, best.p_r),
            iterations=_, version=PCCO_V
        )
        return best, cert
```

### IP-155 APS（时效感知放置调度）

```python
class AoIPlacementScheduler:
    def __init__(self, regions, weights, freshness_deadline):
        self.regions = regions
        self.w = weights
        self.D = freshness_deadline       # D_i(delta) from PVC inversion
        self.last_update = {i: -inf for i in regions}

    def aoi(self, i, t):
        return t - self.last_update[i]

    def weighted_aoi(self, t):
        return sum(self.w[i] * self.aoi(i, t) for i in self.regions)

    def schedule(self, t, budget, candidates):
        urgent = [i for i in self.regions if self.aoi(i, t) > self.D[i]]
        scored = []
        for a in candidates:
            gain = sum(self.w[i] * min(self.aoi(i, t), self.D[i])
                       for i in a.covers)
            cost = budget.comm_cost(a) + budget.probe_cost(a)
            risk = sum(risk_i(self.aoi(i, t)) for i in a.covers)
            scored.append((a, gain - LAMBDA_C * cost - LAMBDA_R * risk))
        if urgent:
            return self.must_refresh(urgent, scored, budget)
        a, score = max(scored, key=lambda x: x[1])
        if score <= THETA_AOI: return None
        budget.spend(a)
        for i in a.covers: self.last_update[i] = t
        return a
```

### IP-156 DBPC（延迟有界放置共识）

```python
class DelayBoundedPlacementConsensus:
    def __init__(self, delta_t, quorum, tau_max, delta_map):
        self.delta_t = delta_t
        self.quorum = quorum
        self.tau_max = tau_max
        self.delta_map = delta_map

    def bucket(self, t_event):
        return math.floor(t_event / self.delta_t)

    def decide(self, proposals, now):
        admitted = [p for p in proposals
                    if p.tau_e(now) <= self.tau_max and p.delay_upper <= D_MAX]
        if not admitted: return Decision.local_safe_or_stop("no_fresh_proposal")
        buckets = {}
        for p in admitted: buckets.setdefault(self.bucket(p.t_e), []).append(p)
        k_star = max(buckets)
        latest = buckets[k_star]
        if len(latest) < self.quorum:
            return Decision.local_safe_or_stop("no_latest_quorum")
        if not map_versions_compatible(latest, self.delta_map):
            return Decision.local_safe_or_stop("map_version_conflict")
        # 陈旧桶只能提示风险，不能覆盖最新桶
        hints = [p for k, ps in buckets.items() if k < k_star for p in ps]
        winner = self.quorum_merge(latest)
        return Decision.commit(
            p=winner.p, cert=ConsensusCertificate(
                bucket=k_star, quorum=[p.id for p in latest],
                hints=[p.id for p in hints], partition=False,
                map_version_chain=self.version_chain(latest), timestamp=now
            )
        )
```

### IP-157 PCB（放置承诺/回退契约）

```python
class PlacementCommitmentManager:
    def commit(self, p, certs, t_now, delta_exec, budget, evidence_level):
        reversible = self.reversible_horizon(p) >= H_REV_MIN
        if not reversible and evidence_level not in ('EV-human', 'EV-xmodal-L1'):
            return Reject("irreversible_requires_stronger_evidence")
        if not budget.place_can_afford(reversible):
            return Reject("B_place_exhausted")
        c = Commitment(p=p, t_commit=t_now, t_apply=t_now + delta_exec,
                       certs=certs, reversible=reversible)
        self.pending.append(c)
        return c

    def tick(self, t_now, new_evidence):
        for c in list(self.pending):
            if t_now < c.t_apply:
                if self.risk_with(c, new_evidence) > c.risk_budget:
                    self.abort(c, reason="pre_apply_risk_increase")
            else:
                if not self.preconditions_hold(c, new_evidence):
                    self.abort(c, reason="release_precondition")
                else:
                    self.execute(c)
```

**正确性定理（Delay-Placement Grounding Soundness, DPGS）**
假设 A22–A55（第 53–59 轮）成立，并新增：**(A56)** DPEO 的每跳延迟上界、事件时间区间与时钟偏斜界诚实覆盖真实值；`ρ_e` 的适用域保守。**(A57)** PVC 的可达集外包包含真实可达状态；余量函数保守；`τ_collapse` 计算音完备。**(A58)** RPS 的风险分配满足 Boole 联合界；可行集为空当且仅当不存在满足约束的放置点（或至少不返回伪可行解）。**(A59)** PCCD 的链路时延/丢包模型为上界；子模贪心/MILP 在其假设域内给出有证书的解。**(A60)** APS 的 AoI 递推准确，超截止放置被强制移出承诺集。**(A61)** DBPC 的桶划分、法定人数与版本调和规则不可绕过；分区/无最新桶法定时只能降级。**(A62)** PCB 的 `H_rev` 保守；abort 窗口被执行；六预算单调、互不挪用。则：

1. **延迟-放置安全性**：若 `τ ≤ τ_collapse(δ_f^req)` 且 `p*∈P_valid(τ)`、`Cert_place` 有效，则滑移/倾覆/力超限的联合概率 ≤ `δ_slip+δ_tip+δ_force+δ_delay`（Boole 界）；若 `τ>τ_collapse`，系统只能进入降级集，不会执行不可逆放置。
2. **证据新鲜度约束**：任何被 `Cert_place` 支撑的放置都满足 `Δ_i ≤ D_i(δ)` 且 `d̄_e+Δ_exec ≤ D_max`；过期证据只能进入校准日志或触发重探/降级。
3. **放置-通信一致性**：若 `Cert_pccd` 有效，则实际路径时延/丢包不超过证书上界；通信契约违例（`D_slack<0` 或 `Sync_slack<0`）会禁止跨机融合或分布式共识，而不是继续冒险。
4. **共识安全性**：任何不可逆放置的全局承诺都携带 `Cert_dbpc`，其法定人数全部来自同一最新事件时间桶；陈旧多数不能否决新鲜少数；分区时降级为本地安全放置或停。
5. **可回退性**：在 `H_rev` 内且 abort 窗口未关闭时，承诺可被撤销；不可逆放置必须通过更强证据门；`B_place` 耗尽后只允许可回退放置或停。
6. **终止性与部署界**：PCE+++++ 在 `k_probes+k_cons+k_ft+k_ux+k_exec+k_place` 内终止于 `{承诺(带 Cert_place/Cert_dbpc), 绕行, 降档, L2 协商, 安全停, 延迟坍缩停, 共识失败停}`。对检查点取联合界：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                   + δ_ft·1[回滚窗口] + δ_kg·1[检索失败] + δ_ux·1[μ_mis>θ]
                   + δ_exec·1[ξ_exec漂移] + δ_ertc·1[契约违例]
                   + δ_delay·1[τ>τ_collapse] + δ_place·1[P_valid=∅]
                   + δ_dbpc·1[陈旧多数] + δ_pccd·1[链路模型失配])
         − P(𝒢 结构性错误未检出) − P(护盾回退失败) − P(τ_int 超时 ∧ 安全停失效)
         − P(固件回滚失败) − P(时钟同步失效 ∧ 未降级)
```

关键：**DPEO 把「通信延迟」从噪声变成可审计的延迟账本与证据有效域**；**PVC 把「放置」从静态几何点变成随时间收缩的安全集**；**RPS 把 δ_f 编译成落点余量与放置证书**；**PCCD 把接触/中继/计算三类放置统一到一张通信-证据图上**；**APS 用 AoI 把新鲜度变成可调度资源**；**DBPC 阻断陈旧多数对不可逆落点的覆盖**；**PCB 用预承诺/回退窗口处理不可逆性**；**六预算确保任何资源耗尽只会让动作更保守**。

```python
    F: str                          # source frame
    t_event_lo: float
    t_event_hi: float
    t_arrival: float
    clock_skew: float               # symmetric bound
    net_path: list                  # list[Hop]
    map_version: str
    place_relevance: object         # p -> [0,1]

    def delay_upper(self) -> float:
        return sum(h.prop + h.queue + h.proc for h in self.net_path) + self.clock_skew

    def age(self, t: float) -> float:
        return max(0.0, t - self.t_event_hi) + 2.0 * self.clock_skew

            return False, "stale"

            return False, "placement_irrelevant"
        if not pvc.nonempty(tau, delta_f):
            return False, "placement_cone_empty"
        return True, "ok"

    def ledger(self):
```

```python
class PlacementValidityCone:
    def __init__(self, lipschitz, disturbance, sigma, timestep):
        self.L = lipschitz
        self.w = disturbance
        self.sigma = sigma
        self.dt = timestep

    def radius(self, tau):
        if self.L < 1e-9:
            growth = self.w * tau
        else:
            growth = (math.exp(self.L * tau) - 1.0) / self.L * self.w
        r0 = math.sqrt(max(np.linalg.eigvalsh(self.sigma)[-1], 0.0))
        return r0 + growth

    def margins(self, p, tau, world):
        R = self.radius(tau)
        return {
            "slip": world.friction_margin(p, R),
            "tip": world.support_margin(p, R),
            "force": world.force_margin(p, R),
            "clearance": world.collision_margin(p, R),
            "joint": world.joint_margin(p, R),
        }

    def valid(self, p, tau, delta_f):
        m = self.margins(p, tau, world)
        return all(m[k] >= SAFE_MARGIN[k](delta_f) for k in m)

    def nonempty(self, tau, delta_f, samples):
        return any(self.valid(p, tau, delta_f) for p in samples)

    def collapse_time(self, delta_f, samples, hi=1.0):
        if not self.nonempty(0.0, delta_f, samples):
            return 0.0
        lo = 0.0
        for _ in range(40):
            mid = 0.5 * (lo + hi)
            if self.nonempty(mid, delta_f, samples):
                lo = mid
            else:
                hi = mid
        return lo


class RobustPlacementSynthesizer:
    def allocate_risk(self, delta_f):
        # Boole: delta_f = slip + tip + force + delay + place
        return RiskAllocation(
            slip=delta_f / 5,
            tip=delta_f / 5,
            force=delta_f / 5,
            delay=delta_f / 5,
            place=delta_f / 5,

    def synthesize(self, p_space, tau, delta_f, progress, risk, retract_cost, evidence_level):

        feas, reasons = [], {}
```

### IP-155 APS（时效感知放置调度）

```python
class AoIPlacementScheduler:
    def __init__(self, regions, weights, deadlines):
        self.regions = regions
        self.w = weights
        self.D = deadlines
        self.u = {i: -math.inf for i in regions}

    def aoi(self, i, t):
        return t - self.u[i]

    def weighted_aoi(self, t):
        return sum(self.w[i] * self.aoi(i, t) for i in self.regions)

    def overdue(self, t):
        return [i for i in self.regions if self.aoi(i, t) > self.D[i]]

    def schedule(self, t, candidates, budget):
        urgent = self.overdue(t)
        scored = []
        for a in candidates:
            gain = sum(self.w[i] * min(self.aoi(i, t), self.D[i]) for i in a.covers)
            cost = budget.comm_cost(a) + budget.probe_cost(a)
            risk = sum(risk_of_age(i, self.aoi(i, t)) for i in a.covers)
            scored.append((a, gain - LAMBDA_C * cost - LAMBDA_R * risk))
        if urgent:
            # 高价值过期区域优先；找不到则返回 RE_PROBE/降级，不进入不可逆承诺
            return self.refresh_urgent(urgent, scored, budget)
        a, score = max(scored, key=lambda x: x[1])
        if score <= THETA_AOI:
            return None
        if not budget.can_spend(a):
            return None
        budget.spend(a)
        for i in a.covers:
            self.u[i] = t
        return a
```

```python
class DelayBoundedPlacementConsensus:
    def __init__(self, delta_t, quorum, tau_max, delta_map, eps_transform):
        self.delta_t = delta_t
        self.quorum = quorum
        self.tau_max = tau_max
        self.delta_map = delta_map
        self.eps_transform = eps_transform

    def bucket(self, t_event):
        return math.floor(t_event / self.delta_t)

    def decide(self, proposals, now):
        admitted = [
            p for p in proposals
            if p.tau_e(now) <= self.tau_max and p.delay_upper <= D_MAX
        ]
        if not admitted:
            return Decision.degrade("no_fresh_proposal")
        buckets = {}
        for p in admitted:
            buckets.setdefault(self.bucket(p.t_event), []).append(p)
        k_star = max(buckets)
        latest = buckets[k_star]
        if len(latest) < self.quorum:
            return Decision.degrade("no_latest_quorum")
        if not self.versions_compatible(latest):
            return Decision.degrade("map_or_transform_conflict")
        if not self.transforms_within_eps(latest):
            return Decision.degrade("transform_uncertainty")
        winner = self.quorum_merge(latest)
        stale_hints = [p.id for k, ps in buckets.items() if k < k_star for p in ps]
        return Decision.commit(
            p=winner.p,
            cert=ConsensusCertificate(
                bucket=k_star,
                quorum=sorted(p.id for p in latest),
                stale_hints=stale_hints,
                map_version_chain=sorted({p.map_version for p in latest}),
                partition=False,
                timestamp=now,
            ),
        )

    def versions_compatible(self, latest):
        vs = [p.map_version for p in latest]
        return max(vs) - min(vs) <= self.delta_map
```

```python
class PlacementCommitmentManager:
    def __init__(self, h_rev_min):
        self.h_rev_min = h_rev_min
        self.pending = []
        self.abort_log = []
        self.retract_log = []

    def reversible_horizon(self, p):
        # 在力/位移/时间阈值内，且存在安全回退动作
        f_ok = p.contact_force_estimate <= F_REV
        x_ok = p.displacement_estimate <= X_REV
        t_ok = p.retract_duration <= T_REV
        action_ok = exists_safe_retract(p)

            return Reject("irreversible_needs_strong_evidence")

            return Reject("B_place_exhausted")

            p=p, t_commit=now, t_apply=now + delta_exec,
```

```python
    def __init__(self, probe, ft, ux, exec_b, comm, place):
        self.probe = probe
        self.ft = ft
        self.ux = ux
        self.exec = exec_b
        self.comm = comm
        self.place = place

    def voi(self, pi, M):
        return (voi_meta_pessimistic(pi, M)
                - self.exec.cost(pi)
                - self.comm.cost(pi)
                - self.place.cost(pi)
                - LAMBDA_AGE * self.comm.expected_age(pi))

    def gate(self, pi):
        if self.comm.D_slack < 0:
            return Degrade("no_cross_node_fusion")
        if self.comm.Sync_slack < 0:
            return Degrade("no_distributed_consensus")
        if self.comm.BW_slack < 0:
            return Degrade("low_bandwidth_telemetry")
        if self.place.Irrev_left <= 0:
            return Degrade("reversible_only")
        if self.place.Risk_left < 0:
            return Degrade("slow_or_stop")
        return Allow(pi)

    def spend(self, pi, irreversible=False):
        self.probe.spend(pi)
        self.comm.spend(pi)
        self.place.spend(pi, irreversible=irreversible)
```

1. **延迟-放置安全性**：若 `τ≤τ_collapse(δ_f^req)`、`p*∈P_valid(τ)` 且 `Cert_place` 有效，则滑移/倾覆/力超限的联合概率 ≤ `δ_slip+δ_tip+δ_force+δ_delay`（Boole 界）；若 `τ>τ_collapse`，系统只能进入降级集，不执行不可逆放置。
2. **证据新鲜度约束**：任何被 `Cert_place` 支撑的放置满足 `Δ_i≤D_i(δ)` 且 `d̄_e+Δ_exec≤D_max`；过期证据只能进入校准日志或触发重探/降级。

5. **可回退性**：在 `H_rev` 内且 abort 窗口未关闭时承诺可撤销；不可逆放置必须通过更强证据门；`B_place` 耗尽后只允许可回退放置或停。

## 4. 解析结果与预注册实验

### 4.1 延迟-放置坍缩的解析例子

取工程近似 `e(τ)=v_maxτ+½a_maxτ²`，`v_max=1.5 m/s`、`a_max=5 m/s²`，要求放置点到安全边界的最小余量 `m_safe`：

```
m_safe = 1.5τ + 2.5τ²   ⇒   τ_collapse = (−1.5 + sqrt(2.25+10·m_safe))/5
```

| `m_safe` | `τ_collapse` | 工程含义 |
|---|---|---|
| 0.02 m | ≈19 ms | 高速动态放置对 20 ms 以上通信延迟极敏感 |
| 0.05 m | ≈32 ms | 100 ms 级跨机证据已无法支撑不可逆落足 |
| 0.10 m | ≈61 ms | 需要 60 ms 内完成证据到执行的闭环 |
| 0.20 m | ≈111 ms | 只有极保守/大余量放置能容忍 100 ms 延迟 |

结论：**通信延迟 50~500 ms 的场景下，「延迟下继续按原落点放」在多数动态步态中不可行；正确策略是减速/等待/换更保守落点，或通过中继/计算放置把证据路径压进 τ_collapse。** 这为 PCCD 与 APS 提供了明确的物理动机。

### 4.2 AoI 的解析基线

若区域 `i` 以周期 `T_i` 刷新，平均 AoI 为 `T_i/2`；若一次探针放置同时覆盖 `k` 个区域，则这些区域共享同一刷新周期，加权平均 AoI 为
```
Ā_w = Σ_i w_i T_i / 2,   Σ_i w_i = 1
```
因此 APS 的收益来自两处：**(i)** 用覆盖多个高权重区域的探针放置替代逐区域刷新；**(ii)** 按 `D_i(δ)` 分配刷新频率，把资源从低风险区域转移到不可逆放置点。预注册目标是在相同 `B_probe+B_comm` 下把 `Ā_w` 降低 ≥35%。

## 6. 本轮最大风险

**一句话**：本轮把「放置」建立在「延迟上界 + 可达集外包 + 新鲜度截止 + 最新桶共识」四重保守假设之上，**只要延迟账本漏计某一跳排队、或可达集外包因未建模的接触/柔性/打滑而失真、或 `τ_collapse` 被高估，系统就会在「证书齐全」的假象下把不可逆落点放到已经坍缩的安全集之外**——而这类错误无法靠事后校准挽回，只能在放置前用「PVC 空集即停」「超新鲜期即禁止不可逆」「陈旧多数不可否决」「六预算耗尽即降级」四道硬闸挡住，宁可频繁 WAIT/重探，也绝不允许带证落错。
