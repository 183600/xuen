# 第 70 轮（承接第 69 轮「FLUID-RAS 不确定性二分与主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「人机交互」×「语义地图」）

> R69 把不确定性一分为二，并教会系统「问」：aleatoric 收紧、epistemic 用看/问/触去消解。但 R69 的「问」默认了一件从未写进证书的事：**问的是一个可以当场指认、答完即用、用完即弃的局部歧义**。它没有「共同基础」——机器人不知道人类是否知道它指的是哪一个；也没有「记忆」——同一个问题换个场景又要再问一遍。更危险的是，R69 的证据纪律只防「单源回答」，防不住「人机一起把同一个错误对象认成了共识」。
>
> 本轮两个灵感各补一块：
> - **语义地图**提供跨时间、跨对象、可被双方指认的**共享指代底座**：对象身份、属性、空间关系、来源、时效与「已知的未知」都写在图上；
> - **人机交互**提供维护共同基础的过程规范：共同基础（common ground）、最小协作努力（least collaborative effort）、混合主动（mixed initiative）、信任校准与可读性（legibility）。
>
> 核心命题：**把 R69 的「问一个模态」升级为「在共享语义地图上建立并维护共同基础」；交互的价值不再只是降低机器人私有的后验熵，而是降低人机联合努力下的接地债（grounding debt）。** 命名 **COMMONS-RAS**（Common-ground Object-centric Map, Mixed-initiative, Open-vocabulary, Negotiated Semantics）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我们说的是同一个东西吗？我们已经共同知道什么？**」——语义地图是共同基础的外存，人机交互是它的读写协议。

## 0. 直觉与动机

**灵感 1（语义地图 → 共同基础需要一个外存）**
直觉：人机之间真正共享的从来不是某个隐状态向量，而是**一个可以共同指认、可以反复回访的世界**。我说「把那个红色的杯子递给我」，你不需要重建我的策略后验，只需要在你们共同的场景里找到一个稳定对象。语义地图正是这个外存：它把「什么在哪里、叫什么、有什么属性、和谁相邻、谁说的、什么时候说的、还可不可信」写下来。于是 R69 的一次性消歧可以变成**可摊薄的接地**：问一次、记下来、以后复用。它同时让「指代」从隐变量变成可检查的图节点，直接暴露 R69 最怕的「幻影模态」在指代层的对应物——**幻影指代**。

**灵感 2（人机交互 → 问不是免费的，共同基础要花联合努力）**
直觉：R69 的 VoI 只算机器人自己的信息收益，把人的注意力当成免费资源。但 HCI 的基本事实是：**提问把认知成本转移给了人**。人可能看不清、没注意、叫不出名字，或者已经被问烦。Clark 的「最小协作努力」说，双方会共同把理解成本压到「够当前目的」为止；Horvitz 的混合主动说，系统应按期望效用决定何时主动、何时闭嘴。于是本轮把目标从「机器人后验熵最小」改成「**人机联合努力下的接地债最小**」：有时自己多看两眼比问人更便宜；有时一句可读的对比问句比十次自由问答更省。

**灵感 3（地图使「可回答性」成为一等约束）**
直觉：R69 担心的是「模态权重不可信 → 追问幻影」。地图把这个风险具体化：如果目标对象不在人可见范围、没有可命名的特征、或根本不在共享图上，那么**这个问题在人这一侧是不可回答的**。此时问不是「信息少一点」，而是「负信息」：人只能猜，猜错还会被系统当成证据。地图让我们在问之前就能估出指代可达性 A（可见性 × 显著性 × 可命名性 × 视角一致性），A 太低就先做「建立可指认性」的动作（靠近、指、显示、换视角），而不是硬问。

**灵感 4（持久化 → 收益是复利，错误也是复利）**
直觉：R69 的回答用完即弃；COMMONS 的回答写进图，成为下一轮的共同基础。好处是摊薄：同一个对象的名字只需接地一次，之后所有任务共享。坏处同样致命：一旦人机在感知混叠下把 A 认成了 B，这个错误会被写进「共识」，此后被反复复用、被审计层当作已接地事实、被证书判为 Valid。**共享的错误比私有的错误更难纠正**——因为系统会用它去解释新证据。地图把一次性的「问错」升级为可积累的「错得一致」。

**灵感 5（混合主动 → 需要权威分区，而不是谁声音大听谁）**
直觉：有了共同地图，人也会主动改图：「那不是杯子，是碗」「这个房间叫实验室」。系统不能全盘接受（自动化偏差、地图投毒），也不能全盘拒绝（算法厌恶、用户失去控制感）。HCI 的答案是**权威分区**：人对命名、偏好、目标、社会规范有权威；机器人对度量位姿、碰撞几何、动力学有权威；身份/属性这类需要感知的字段是共管的，必须与独立证据一致才入共同基础。信任不是一次性开关，而是按字段、按来源、按时效持续校准的量。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（COMMONS-RAS 总览与四不变式）** COMMONS-RAS = (SCGM, CGG, MINT-C, CLQ, AVA, APT, SMD, MPI, TRUST, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **共同基础健全性**：只有通过指代绑定与溯源检查的证据才能进入共同基础 CG；未接地回答至多是私有证据；
(iii) **权威分区**：人类对语义/规范字段有权威，机器人对安全关键几何字段有权威；任何单次修正不得扩张安全包络；
(iv) **最小联合努力**：交互按「机器人成本 + 人类成本 + 未来再接地成本」的联合代价选择，而非机器人单侧 VoI。

**定义 311（语义共同地图 SCGM）** 对象中心图 M_t = (O_t, E_t)。每个对象 o 有字段 φ ∈ Φ = {id, pose, shape, attrs, affordances, name, relations, preference}；每个字段带后验 b_t(o,φ)、溯源集 Π(o,φ)、时间戳 t_φ、权威 α(φ) ∈ {human, robot, joint}、接地状态 γ ∈ {private, shared, contested}。开放词表嵌入 e(o) 锚定到几何，允许「已知的未知」：显式记录高熵字段，避免把「没写」误当「没有」。

**定义 312（共同基础算子 CGG 与接地债）** 设机器人信念 b_R、用户模型给出的估计 b_H。字段级一致 A(o,φ) = 1[W₂(b_R(o,φ), b_H(o,φ)) ≤ ε_φ]；互知证据 a(o,φ) ∈ {0,1} 来自确认/回指/共同注意/既往已验证交互日志。共同基础 CG_t = {(o,φ) : A ∧ a}。任务 π 需要字段集 Fields(π)，接地债 D_g(π) = Σ_{(o,φ)∈Fields(π)} w_φ · d(b_R,b_H) · 1[(o,φ)∉CG_t]。D_g 超过 ε_g 时，任务不得被宣称为「已对齐」。

**定义 313（指代可达性 AVA）** A(o,φ,t) = v·s·n·p，其中 v 为可见性、s 为显著性、n 为可命名性（共享词表/地标是否覆盖）、p 为视角一致性；各项∈[0,1]，由地图几何、人的位姿/注视（若有）、词表覆盖在线估计。门限：A < A_min 时禁止对该字段发起「问」，只允许先做建立可指认性的动作（靠近/指向/显示/换视角）或自探索。

**定义 314（混合主动共同基础 VoI：MINT-C）** 对信息动作 g（问/指/展示/自探索），
VoI_C(g) = A(g)·[H(B_CG) − E_{y~p(·|g)}H(B_CG|y)] − c_R(g) − c_H(g) − c_T(g) − c_F(g)，
其中 c_R 为机器人执行成本、c_H 为人的注意力/表达成本、c_T 为重复提问带来的信任损耗、c_F 为「错误接地被持久化」的期望后悔。约束：安全认证、联合预算、权威分区。若 max VoI_C ≤ 0 则不交互，逐指令退化为 R69 的 FLUID。

**定义 315（对比式可读问句 CLQ）** 给定候选对象 o_i,o_j 或字段歧义，选择区分特征集 F 与已入 CG 的空间锚点 r，最大化可辨性/描述长度比 D(F)/L(F)，约束 F 在共享词表内、r 满足 A(r) ≥ A_min、视角一致。问句 q = Realize("F 那个，在 r 旁边？")。可读性 L(q) = P(人指认到预期对象)。问句由地图锚定模板 + 冻结 LLM 实现，禁止无锚点自由生成。

**定义 316（回答即地图证据）** 人的回答 y 是关于绑定指代 o 的字段 φ 的证据，不是关于机器人隐动作模态的直接证据。似然 p(y | b(o,φ), A) 经指代绑定（共指/关联）后按字段融合，保留溯源；高影响字段需独立佐证（继承 R69 证据纪律）。写入 CG 前必须通过定义 312 的一致 + 互知检查。

**定义 317（权威分区 APT）** 字段到权威的映射：name/preference/goal/social_norm → human；pose/collision_geometry/dynamics → robot；identity/attrs → joint。修正接受规则：human 字段直接接受并记溯源；joint 字段需至少一个正交观测一致，否则标 contested 且不入 CG；robot 字段只作为假设验证，绝不直接覆盖安全包络。

**定义 318（地图漂移与陈旧 SMD）** 对象可能移动、改名、消失，开放词表嵌入会漂移。每对象陈旧度 ν_t = e^{−Δt/T_o}，漂移检测结合观测残差与场景变化；陈旧/漂移字段从 CG 降级为 private（不是静默继续信任），并触发重接地或修复。

**定义 319（地图投毒免疫 MPI）** 攻击者可通过交互或伪造感知注入假地标/别名/关系。免疫：溯源链、跨视角/跨模态一致性、来源可靠度、更新速率上限、可疑字段隔离（quarantine）。被隔离字段不得进入 CG，且其影响按先验质量与隔离轮数衰减。

**定义 320（信任校准与追问节律 TRUST）** 跟踪回答者可靠度 r_H、同一字段重复提问率 ρ_q、当前信任状态。对已在 CG 的字段重复提问视为违反 Grice 量准则，计入 c_T；同时防止「不敢问」造成的过度自信。目标是适当依赖（appropriate reliance），而非最大化或最小化提问次数。

**定义 321（解释与可争议性）** 每个由地图驱动的决策须暴露：用了哪些字段、其溯源与置信、以及「为什么是它而不是另一个」的对比解释。用户可就某字段提出异议；异议字段进入 contested，按 APT 处理，不允许被静默覆盖。

**定义 322（COMMONS 证书 J_COMMONS）** J_COMMONS = (J_FLUID, CG_coverage, D_g_before/after, A_min, query_legibility, repetition_rate, authority_violations, map_provenance_hash, quarantine_count, commons_ver)。Valid ⇔ Valid(J_FLUID) ∧ CG 健全 ∧ 无权威越界 ∧ 投毒检查通过。

**定义 323（威胁模型 ℰ_COMMONS）** ℰ_COMMONS = ℰ_FLUID × ℰ_map × ℰ_misground × ℰ_overask。ℰ_map：投毒/陈旧/混叠；ℰ_misground：指代错配、人机共构的错误共同基础；ℰ_overask：社交工程、追问疲劳、以提问诱导用户泄露。

**定义 324（退化链）** 若 CG 不可用/不健全、漂移或投毒可疑、A < A_min、或权威冲突未解，则回退到 FLUID（私有 VoI）；FLUID 亦不可行时回退 R68 纯保守。退化时 λ 单调不降，联合努力预算不得借回退被突破。

**定义 325（联合努力预算与接地调度）** J = c_R + c_H + c_future，带决策截止；允许在人的注意力便宜时（空闲/低负荷）预接地，而不是只在决策点问。单位时间打扰次数有硬上限；超时视为未接地。

**定义 326（人类主动修正协议）** 人可主动纠正/提问；系统以 accept / defer / ask-back 三选一响应，冲突按 APT 与证据解决；全过程入审计日志，成为下一轮 TRUST 与 CLQ 的先验。

# IP-264/265 SCGM + CGG：共享语义地图与共同基础度量
class SemanticCommonGroundMap:
    def bind(self, z, pose):
        for o in self.detect_and_associate(z, pose):
            self.update_fields(o, z, pose)          # pose/attrs/name/relations
            self.log_provenance(o, source='perception')
        return self

    def common_ground(self, task_fields, user_model):
        cg, debt = set(), 0.0
        for (o, f) in task_fields:
            agree  = w2(self.b[o, f], user_model.b[o, f]) <= EPS[f]
            mutual = self.has_ack(o, f)             # 回指/确认/共同注意
            if agree and mutual:
                cg.add((o, f))
            else:
                debt += self.w[f] * self.dist(o, f) * self.unc(o, f)
        return cg, debt

# IP-266/268 MINT-C + AVA：联合努力下的接地决策
def choose_grounding(map_, task, human, budget):
    best = None
    for g in candidates(map_, task):                # ask / point / show / self-explore
        A = map_.accessibility(g.referent, human)   # 定义 313

## 3. 推导

**引理 19（可回答性上界与「幻影指代」）** 对任意提问 g，其信息收益受指代可达性封顶：VoI_C(g) ≤ A(g)·IG_max − c_R(g) − c_H(g)。故当 A < (c_R+c_H)/IG_max 时，提问被自探索严格支配。系：R69 的「幻影模态」在指代层有对应物——问一个不可指认的对象，答案不是低信息，而是**负信息**（人只能猜，且猜错会被写入地图）。

**引理 20（共同基础的摊薄与复利）** 在溯源完整的 CG 上，同一字段一旦接地，只要未发生漂移就保持 shared；N 个任务上的期望提问次数从无地图时的 Θ(N) 降为 Q₀ + O(N·p_drift)（p_drift 为漂移率）。故单次接地成本按 N 摊薄。反向系：若融合不保留溯源或忽略陈旧，CG 会退化为「看起来共享」的私有信念，摊薄立刻变成**重复提问或错误复用**。

**引理 21（地图投毒的持久影响界）** 设一次未验证注入给字段的后验质量为 m，正常证据质量为 n。若不设隔离，注入后字段权重 ≈ m/(m+n)，且可被重复注入累积到主导；若设隔离与更新速率上限 η，则持续影响 ≤ η/(1−η)。系：**假共同基础比私有错误更危险**，因为它会被复用、被审计当作已接地事实，且错误率不随证据源数量 k 下降（与 R69 引理 18 的地板同构）。

**引理 22（权威分区的安全界）** 若人类修正只作用于 human 权威字段，系统安全包络不变；joint 字段需正交证据，robot 字段不得被直接覆盖，则由修正导致的不安全动作概率 ≤ ε_cross。系：混合主动的安全性不靠「少听人」或「多听人」，而靠**按字段分配权威**。

**定理 18（COMMONS 严格包含 FLUID ⊂ CALM）** 在 A103–A106 下，COMMONS 的期望风险 ≤ FLUID ≤ CALM；当 CG 为空、A < A_min、漂移/投毒可疑或权威冲突未解时，两者逐指令相同（定义 324）。当 CG 健全时，COMMONS 额外获得**持久化/摊薄红利**（更少提问、更低联合努力），且该红利不来自放松安全约束。安全侧单调，效率侧仅在接地成功时增益。

**定理 19（混合主动安全与无突变）** 接地只改变「指向哪个对象/用哪个字段」，不改变安全包络；一切信息动作仍过 C-RAS-WM 前缀认证；人类修正经 APT 门控；退化时 λ 单调不降；R68 的提交/换装不变式（定理 15）保持 ⇒ 控制连续、无突变。

**A103–A106** A103 指代可辨识性：A 的估计校准，A ≥ A_min 时人能以高概率指认；A104 地图漂移有界且可检测；A105 溯源完整性：攻击者不能在不被检测下同时伪造指代、来源与时间戳；A106 权威分区健全：安全关键字段不接受未经正交验证的单源覆盖。

## 4. 推导

**引理 19（可回答性上界与幻影指代）** `VoI_C(g) ≤ A(g)·IG_max − c_R − c_H`；当 `A < (c_R+c_H)/IG_max` 时提问被自探索严格支配。系：R69 的「幻影模态」在指代层的对应物是「幻影指代」——问一个无法指认的对象，答案不是低信息而是负信息。

**引理 20（共同基础的摊薄与复利）** 溯源完整的 CG 上，字段一旦接地且未漂移就保持 shared；N 个任务的期望提问数从无地图时的 `Θ(N)` 降为 `Q₀ + O(N·p_drift)`。反向系：不保留溯源或忽略陈旧时，CG 退化为「看起来共享」的私有信念，摊薄变成重复提问或错误复用。

**引理 21（地图投毒的持久影响界）** 未验证注入质量 m、正常证据 n：无隔离时字段权重 `≈m/(m+n)` 且可累积主导；有隔离与更新速率上限 η 时持续影响 `≤η/(1−η)`。系：**假共同基础比私有错误更危险**——它被复用、被审计当作已接地，且错误率不随源数 k 下降（与 R69 引理 18 的地板同构）。

**引理 22（权威分区的安全界）** 人类修正仅作用于 human 字段 ⇒ 安全包络不变；joint 字段需正交证据；robot 字段不可直接覆盖 ⇒ 修正导致的不安全动作概率 `≤ε_cross`。系：混合主动的安全性靠「按字段分配权威」，不靠「多听/少听人」。

**定理 18（COMMONS 严格包含 FLUID ⊂ CALM）** A103–A106 下期望风险 `COMMONS ≤ FLUID ≤ CALM`；CG 为空、`A<A_min`、漂移/投毒可疑或权威冲突时逐指令相同（定义 324）。CG 健全时获得持久化/摊薄红利（更少提问、更低联合努力），红利不来自放松安全约束。

**定理 19（混合主动安全与无突变）** 接地只改「指向哪个对象/用哪个字段」，不改安全包络；信息动作仍过 C-RAS-WM 前缀认证；人类修正经 APT 门控；退化时 λ 单调不降；R68 提交/换装不变式（定理 15）保持 ⇒ 控制连续、无突变。

**A103–A106** A103 指代可辨识性（A 校准，A≥A_min 时高概率可指认）；A104 地图漂移有界且可检测；A105 溯源完整性（不能无检测地同时伪造指代/来源/时间戳）；A106 权威分区健全（安全关键字段不接受未经正交验证的单源覆盖）。

## 7. 本轮最大风险

**一句话**：COMMONS 的全部收益押在「语义地图忠实、且人机共同基础为真」这一前提上——若人机在感知混叠与相互确认下共构出一个错误指代，它会被持久化、被后续任务复用、还会被 J_COMMONS 判为 Valid，**共享的错误比私有的错误更难纠正**：地图把一次性的「问错」变成了会复利的「错得一致」。

**次级风险与缓解**：指代可达性被高估（AVA 校准 + 宁可自探索，E318）；追问疲劳与过度打扰（TRUST 节律 + 联合努力预算，E324–E325）；地图投毒与开放词表漂移（MPI 隔离 + SMD 降级，E322–E323）；权威冲突（APT 字段级仲裁 + 正交证据，E321）；地图成为新单点故障（退化链逐指令回 FLUID，E328）；问句语言幻觉（地图锚定模板 + 冻结 LLM，E319）。
