# 第 1 轮迭代（灵感词：少样本学习 × VLA）—— 从「手工仿真工程」转向「少样本可组合 VLA」

> 承接状态文件里的 UIP v2（GSO 计分神谕、DRF 扰动数据工厂、MSGR 模块化技能图、滚动验证）。本轮不是推倒重来，而是用两个新灵感词修补 v2 的两个结构性软肋：① 逐任务手写几何谓词/干扰脚本，本质是“多样本手工工程”，遇到 `unseen_object_*` 仍要重写；② 把 VLA 当成一个可替换的动作生成器，没有利用它真正的能力——开放词汇语义与跨任务动作先验。核心转向：**少样本不是“拿少量数据微调一个大模型”，而是“用少量支持样本完成语义对齐、技能选择与动作参数化迁移”**。

## 0. 本轮先纠正一个接口级错误（比新增想法更重要）

本轮重新核对 README（https://github.com/unitreerobotics/unibot_submission ，2026-11-12）后确认：

- `action_chunk_size` 是 `metadata` 里的**一个全局整数** `T_a`；`get_action` 每次必须返回形状 `(T_a, …)` 的完整动作块，索引 0 先执行，其余按序执行，直到评测端再次调用。**不能返回变长块，也没有块内重观测。**
- 因此 v2 的 **UIP-13 ACS“按任务阶段动态选 k”在接口上不可实现**；UIP-01′ 的“每 k 步核验”也只能发生在**块边界**。这是本轮必须修剪的硬约束。
- 推论：实时性不是“运行期自适应块长”，而是**离线选一个全局 `T_a`**，并用 `T_a·δ + L` 近似反应时间（`δ` 为控制周期，`L` 为单次推理延迟）。VLA 越慢，`T_a` 被迫越大，反应越迟钝——这直接决定了少样本适配只能在块边界做。
- 另一条可利用的事实：每个端口对应一个独立机器人/episode，`reset()` 每 episode 一次；若端口进程跨 episode 存活，则**按语言键控的 episode 级记忆**是合法的（但必须每端口隔离，不能跨端口共享状态）。这是一个待验证假设 A1，不能当成必然。

## 1. 直觉解释（先不严谨）

想象一个人第一次走进一间陌生厨房，要“把红色杯子挂到架子上”。他不需要重新学习“抓握”这件肌肉技能，也不需要 1000 条演示；他做的是三件少样本的事：

1. **语义对齐**：认出“这个红色物体是杯子”（哪怕杯子形状没见过）；
2. **技能选择**：调用“抓—举—挂”这几个已知技能，而不是从零学；
3. **参数迁移**：根据杯子的实际位置/尺寸，把已知抓握动作**相对物体**平移、旋转、缩放。

VLA 提供第 1 步的开放词汇先验和第 2 步的语言条件先验；少样本学习提供第 3 步的快速校准。**真正缺的不是“更多任务数据”，而是把“已知技能”对齐到“新物体实例”的机制**。这也解释了为什么 v2 的 Gazebo 路线有价值但不够：它能造“已知任务”的更多样本，却很难自动造出“未见物体”的语义-动作对应。

## 2. 严谨定义（再把直觉收紧）

**任务**：\(T=(\ell, s_0, \{g_1,\dots,g_m\}, \{w_1,\dots,w_m\}, D)\)，其中 \(\ell\) 是语言指令，\(s_0\) 是初始场景，\(g_j\) 是第 \(j\) 个计分步谓词，\(w_j\) 是其分值，\(D\) 是人为干扰过程。评测分布 \(p_{test}\) 与训练分布 \(p_{train}\) 的差异主要在物体实例、位姿、背景与干扰时机，而非任务名称。

**少样本支持集**：\(S_T=\{(o_i,a_i)\}_{i=1}^{K}\)。本轮区分三种合法形态：

- **离线元学习**：在 32 个训练任务上做 episodic 采样，学一个“看到 K 条演示就能适配”的初始化/适配器；
- **运行期非参数少样本**：把支持集存成键值记忆，测试时按相似度检索动作块（不更新大权重）；
- **转导式少样本**：测试 episode 自身的前几帧就是“1-shot 支持”，用它们构造当前物体/场景原型。

**关键约束**：测试时**没有成功标签、没有步骤分反馈**。因此任何需要监督信号的测试时梯度更新都不合法/不可靠；测试时只能用自监督一致性、检索、转导原型与不确定性拒识。

**技能分解**：设技能集合 \(\mathcal S=\{s_1,\dots,s_n\}\)，策略分解为

\[
\pi(a_{t:t+T_a}\mid o_t,\ell)=\sum_{s\in\mathcal S} q_\phi(s\mid o_t,\ell)\, f_{\theta_s}(a_{t:t+T_a}\mid o_t,\ell,M_s),
\]

其中 \(q_\phi\) 是技能路由器，\(f_{\theta_s}\) 共享 VLA 骨干、只带技能专属适配器，\(M_s\) 是该技能的支持记忆。32 个任务≈10 个可复用技能，意味着**少样本的“样本”可以在技能层跨任务共享**，而不必每个任务各自 K-shot。

**物体中心动作迁移**：设物体位姿 \(g_o=(R_o,t_o)\in SE(3)\)，动作块 \(A\) 为末端轨迹。存进记忆时存相对动作 \(A^{rel}=g_o^{-1}\circ A\)；遇到新物体 \(o'\) 时输出 \(A'=g_{o'}\circ A^{rel}\)，夹爪开度按物体宽度比缩放。这样同一个“抓杯子”演示可以迁移到不同位置、朝向、尺寸的杯子。若控制空间是 `joint`，则用 \(q'=\mathrm{IK}(g_{o'}\circ g_o^{-1}\circ \mathrm{FK}(q))\)。

**误差分解**（不是泛化界，而是实验设计的可测分解）：

\[
R_{test}\approx R_{ground}+R_{route}+R_{transfer}+R_{recover}+R_{exec},
\]

分别对应“没认对物体/关系”“选错技能”“动作迁移不准”“干扰后不恢复”“底层执行误差”。少样本主要压 \(R_{ground}\) 与 \(R_{route}\)，VLA 主要压 \(R_{ground}\)，物体中心记忆主要压 \(R_{transfer}\)，验证器/恢复模板主要压 \(R_{recover}\)。这个分解直接给出 E201–E210 的 ablation 结构。

## 3. 四个关键判断

- **J1（靶点）**：`unseen_object_*` 的主要伤害是**抓取位姿与可供性**，而不是高层步骤顺序。所以少样本应优先投在“物体定位→抓握参数”上，而不是重训整个策略。
- **J2（VLA 的定位）**：VLA 的价值是**开放词汇语义 + 跨任务动作先验**，不是毫米级接触精度。接触密集步（插网线、合盖、拉链）仍需几何伺服/短程纠正，不能迷信大模型端到端。
- **J3（测试时信号）**：没有标签时，最可靠的少样本信号是**跨视角/跨时间的自一致性**与**转导原型**，不是伪标签。伪标签一旦错，会通过 VLA 的强先验放大成系统性错误。
- **J4（固定块长）**：`T_a` 是全局的，VLA 延迟与 `T_a` 必须联合选型；“块内反应”不存在。任何声称“每 k 步重规划”的方案都要先证明 \(k=T_a\)。

## 4. 候选合并 → v3 清单（详见产物区）

围绕“少样本 × VLA”发散 8 个草案，合并后得到 v3：旗舰 **UIP-16 FSP-VLA**（技能原型 + 检索增强 + 物体中心迁移），由 **UIP-17 物体中心动作迁移**、**UIP-18 转导式测试时适配**、**UIP-19 保形拒识**、**UIP-20 恢复模板检索**、**UIP-21 留一物体元训练**、**UIP-22 慢-快 VLA** 支撑。v2 的 UIP-11/12/14 保留为离线评估与数据/技能先验；**UIP-13 明确修剪**；UIP-01′ 降为“块边界验证器”；UIP-08′ 保留为纯工程。

## 5. 本轮最大风险

**一句话**：最大的风险不是“少样本不够多”，而是把“检索到的相似演示”误当成“可迁移的动作”——物体中心对齐一旦错误，VLA 的强语义先验会把错误放大；必须用保形拒识（UIP-19）和真机校准锚点兜底。

**→ 本轮最值得押注**：**UIP-16 FSP-VLA × UIP-17 物体中心迁移 × UIP-20 恢复模板检索** 组成的“少样本技能适配 + 块边界恢复”闭环。它不依赖测试时标签，不需要改变接口，且直接对准 `unseen_object_*` 与 `human_*` 两大数据空白；VLA 提供语义先验，少样本提供实例校准，二者正好互补。

# 第 1 轮产物 · UniBot 创新点清单 v3（UIP-16~22，承接 v2）

> 本轮主线：**少样本学习 × VLA**。目标不是把 VLA 当黑盒，而是把“技能先验”与“实例校准”分开：VLA 负责开放词汇语义与技能路由，少样本记忆负责物体中心的动作迁移与恢复模板。所有结论按“接口事实 / 假设 / 待验证预测”三级标注。

## 0. 口径、接口事实与假设

### 0.1 本轮核实的接口事实（2026-11-12）

| 事实 | 内容 | 对本轮的含义 |
|---|---|---|
| `action_chunk_size` 全局固定 | `metadata` 中一个整数 \(T_a\ge 1\)；每次 `get_action` 必须返回形状 `(T_a, …)` 的完整动作块 | **不能运行期改块长**；v2 的 UIP-13 ACS 失效；验证/适配只能发生在块边界 |
| 块内无重观测 | 评测端执行完索引 0→\(T_a-1\) 后才再次调用 | “每 k 步核验”必须满足 \(k=T_a\)；小 \(T_a\) 换取反应性，但增加调用次数与延迟暴露 |
| 观测键 | 4 路相机（left/right high、left/right wrist）、双臂 state、ee pose、gripper、lower_body、`observation.language` | 语言可用；可用腕部相机做物体中心定位；不要声明无用键（每帧都是载荷） |
| 控制空间互斥 | `joint` 或 `ee`，握手后不可切换 | 物体中心动作迁移在 `ee` 下最自然；`joint` 需 IK，精度/限位风险更高 |
| N 端口 | 每端口对应独立机器人/episode；必须 N 个连续端口；每端口状态隔离 | 端口间不能共享 episode 状态；跨 episode 记忆必须按语言/任务键控，且是假设 A1 |
| 可信度 | 逐步延迟及其波动、动作统计规律性被记录 | 测试时大梯度适配、异常动作、抖动都会伤可信度；适配必须预算化 |

### 0.2 沿用 v2 的赛制事实

- 32 任务、每任务计分点合计 100；末步分值恒 ≥ 前序步；排名=平均成功率 + 步骤分。
- `generalization` 字段含 `unseen_object_*` 与 `human_*`；`human_*` 大量是“把已完成进度撤回”。
- 公开数据只有“已见物体、无干扰”的演示，`unseen_object_*` 与 `human_*` 是两大分布空白。
- Gazebo/GSO 仍是离线结构裁判；DRF 仍是扰动支持数据工厂。

### 0.3 本轮关键假设（必须逐条验证，不能默默当真）

- **A0（计分语义）**：步骤分是“曾经达成即锁定”（\(S_{ever}\)），还是“episode 结束时仍成立才算”（\(S_{final}\)）？公开文本未核实。本方案对两种语义都给出决策规则，但默认按更保守的 \(S_{final}\) 设计恢复。
- **A1（跨 episode 记忆）**：同一端口进程在多个 episode 间存活，且任务可能变化。若 A1 不成立，TAP-EP 退化为“仅用当前 episode 前几帧”，仍可工作，只是少样本增益下降。
- **A2（单模型合规）**：测试时不得调用外部大模型/外部 API；技能头、适配器、检索记忆都必须属于同一条骨干的部署物。若规则允许外部工具，本方案可放宽，但不依赖它。
- **A3（无测试标签）**：评测端不返回成功信号/步骤分；测试时只能用自监督与转导信号。
- **A4（延迟预算未知）**：所有在线适配都必须有硬预算；默认“每 episode 最多 1 次轻量校准，其余全部离线”。
- **A5（固定块长）**：\(T_a\) 全局固定，块内不可打断。

## 2. 旗舰深潜：UIP-16 · FSP-VLA

### 2.1 机制

FSP-VLA 把一次 `get_action` 拆成四个可解释模块，全部在一条 VLA 骨干上完成：

1. **语义/可供性编码**：VLA 视觉-语言编码器对 4 路图像 + `observation.language` 编码，输出物体/关系 token 与可供性热图；
2. **技能路由**：用技能原型 \(p_s\) 与当前 token 的相似度，叠加 VLA 的语言条件先验，得到技能后验 \(q(s\mid o,\ell)\)；
3. **物体中心检索**：到该技能的支持记忆 \(M_s\) 中检索 \(K\) 个“相对物体”的动作块，按物体位姿变换到当前场景；
4. **动作块生成与融合**：VLA 动作专家生成先验块，与检索块做注意力融合，输出严格 `(T_a, …)` 的完整块。

```text
obs (4 cameras + state + language)
        │
        ├─ VLA encoder ──► 语义/可供性 token ──► 技能路由 q(s|o,ℓ)
        │                                             │
        ├─ episode 原型（转导）──► 物体中心检索 M_s ◄──┘
        │                              │
        └────────────► VLA action expert ──► 融合 ──► (T_a, action)
```

### 2.2 与 v2 的差异

- v2 的 MSGR 是“任务→技能图”的离散路由；FSP-VLA 让技能路由**由视觉-语言相似度与支持样本共同决定**，因此能处理训练时没见过的任务组合。
- v2 的 UIP-01′ 试图在块内滚动验证；FSP-VLA 承认块内不可观测，改成**块边界验证 + 下一块重规划**。
- v2 的 DRF/GSO 是“造数据/判分”；FSP-VLA 把它们变成**支持记忆与评估器**，而不是在线依赖。

### 2.3 可行性

高。全部在选手 API 内：`get_action` 可返回任意来源的动作块；`reset()` 可清空 episode 状态；记忆可放在进程内。唯一硬条件是单次推理延迟与显存，必须用 UIP-22/量化/共享骨干解决。

### 2.4 资源

- 离线：32 个公开数据集（统一键与动作空间）；1 张推理卡做 VLA 微调；技能原型与支持记忆可离线构建。
- 在线：1 条骨干 + 小型技能适配器；检索是 CPU/GPU 向量相似度，开销远小于一次 VLA 前向。
- 数据：按“物体实例”而不是“episode”做训练/验证切分，避免泄漏。

### 2.5 落地步骤

1. 统一 32 数据集的观测键、动作键、语言与时间轴，确定 `control_space`（优先 `ee`）与全局 \(T_a\)；
2. 训练/加载 VLA 骨干，冻结大部分参数，只训技能适配器与检索投影头；
3. 离线构建每个技能的支持记忆（相对物体动作块 + 视觉-语言键）；
4. 在本地回放/仿真中测检索精度、块边界验证、物体中心迁移；
5. 用 UIP-11 GSO 做离线选型，真机时段只做校准锚点；
6. 上线前做端口隔离、延迟压测、动作统计平滑（UIP-15）。

### 2.6 风险

- 检索到“语义相似但几何不相似”的演示 → 抓取位姿错误；用 UIP-19 拒识与 UIP-17 的几何校验兜底。
- 技能路由在长尾任务上过度自信 → 软路由 + 通用回退头。
- 物体位姿估计误差会直接进入动作变换 → 用腕部相机短程伺服修正，而不是一次性开环。

## 3. 少样本的三种用法与边界

| 用法 | 何时发生 | 需要标签？ | 主要作用 | 主要风险 |
|---|---|---|---|---|
| 离线 episodic 元训练（UIP-21） | 训练期 | 有（训练集动作） | 学“如何从 K 条演示适配” | 任务/物体划分泄漏；元过拟合 |
| 运行期非参数检索（UIP-16/17） | 每次 `get_action` | 无 | 复用精确动作块、补长尾 | 相似度错误、动作不可迁移 |
| 转导式 episode 原型（UIP-18） | 每 episode 前几帧 | 无 | 适配当前物体实例/背景 | 前几帧遮挡、原型漂移 |

**边界**：测试时不做监督梯度更新；最多做一次轻量、无标签的归一化/适配器校准，且必须可回滚。若规则或延迟不允许，直接关闭 UIP-18，只保留检索。

## 4. 关键机制细节

### 4.1 UIP-17 · OCA-T：物体中心动作迁移

- **存储**：对每条支持轨迹，估计物体位姿 \(g_o\)，把末端动作块转成相对位姿 \(A^{rel}=g_o^{-1}\circ A\)；同时存物体点云/图像特征、夹爪宽度、语言子目标。
- **使用**：当前物体 \(o'\) 的位姿为 \(g_{o'}\)，输出 \(A'=g_{o'}\circ A^{rel}\)；夹爪开度 \(d'=d\cdot(w'/w)\)，其中 \(w,w'\) 是物体宽度估计。
- **`ee` vs `joint`**：`ee` 下变换是精确的刚体变换；`joint` 下需要 \(q'=\mathrm{IK}(g_{o'}\circ g_o^{-1}\circ \mathrm{FK}(q))\)，会受关节限位、奇异点、IK 误差影响。**建议首选 `ee`**，把 `joint` 作为精度对照。
- **失败模式**：物体对称性导致位姿多解（杯子/碗）；铰链物体（拉链、盒盖）不能只用刚体变换，需要“物体功能坐标系”（如拉链方向、盖子转轴）。对这类任务，检索键要加入功能轴，而不是只用 6D 位姿。

### 4.2 UIP-18 · TAP-EP：转导式测试时适配

- **episode 原型**：用前 1–3 帧的 VLA 特征，按语言做目标物体分割/定位，得到 \(p^{epi}=\frac{1}{m}\sum_j e(o_j)\)；用它重排检索候选，而不是重训模型。
- **测试时归一化**：只更新 LayerNorm/FiLM 的仿射参数（或一个低秩适配器），目标是最小化“相邻块预测的下一帧特征”与“实际下一帧特征”的余弦距离；最多 1 次，学习率小，带回滚。
- **自一致性**：对同一观测做两种轻量增强（裁剪/亮度），要求技能后验与检索排序一致；不一致时不更新，只降低置信度。
- **预算**：每 episode 仅一次，且只在第一个块边界；若延迟超预算，直接跳过。把“是否适配”作为 UIP-19 的一个决策，而不是默认开启。

### 4.3 UIP-19 · CAST：保形拒识

- **非一致性分数**：\(r_i=d(q,q_i)\)，其中 \(q\) 是当前物体/技能查询，\(q_i\) 是支持样本键。用支持集的经验分位数取阈值 \(\hat r\)；若 \(r>\hat r\)，拒识。
- **拒识后的动作**：回退到脚本化安全技能（对准、夹紧、抬起、退回），或输出“保持+小幅探测”块；绝不输出高置信度的错误迁移。
- **理论边界**：保形预测的有限样本覆盖需要交换性假设；未见物体/背景破坏交换性。因此**只把阈值当风险监测器，不当保证**。在报告中明确写“经验覆盖率”，不写“保证”。
- **价值**：把“检索错误”从灾难性失败降级为“少做一步/多花几秒”，在步骤分与成功率上都更稳。

### 4.4 UIP-20 · RIDE：恢复模板检索与代价敏感重做

- **检测**：块边界用 UIP-01′ 的验证器输出 `done/ongoing/fail/regressed`；`regressed` 由“子目标谓词从真变假”或“物体位姿回到先前状态”触发。
- **模板库**：DRF/GSO 生成“干扰前→撤回→恢复”三元组；只存**短恢复块**（例如重新抓取、重新合盖、重新拉上），索引为（技能、被撤回步骤、当前物体位姿/夹爪状态）。
- **检索**：用当前观测与索引检索 top-1/2 恢复块，做物体中心变换后输出；恢复块通常短于正常块，因此要填充/复用最后一步到 \(T_a\)，保证形状合法。
- **代价敏感决策**：设第 \(j\) 步权重 \(w_j\)，恢复成本 \(c_j\)（时间、碰撞风险），下游可达收益 \(B_j=\sum_{l>j}w_l P(g_l\mid \text{restore})\)。则
  \[
  \text{redo if } P(g_j\mid a)\,\big(w_j\cdot\mathbb 1[S_{final}]+B_j\big)>c_j.
  \]
  若 A0 是 \(S_{ever}\)，直接分已锁定，\(w_j\) 项为 0，只在“不恢复会阻断后续步骤”时重做；若 A0 是 \(S_{final}\)，则必须恢复当前步。这个规则让方案对计分语义不确定**稳健**。
- **少样本优势**：恢复动作短、模式少（重新抓/重新合/重新拉），比学习完整策略更省样本，天然适合 K-shot 模板检索。

### 4.5 UIP-21 · META-SKILL：留一物体元训练

- **episodic 采样**：每个 meta-episode 采样一个任务族，支持集 \(S\) 来自已见物体，查询集 \(Q\) 来自**留出的物体实例/位姿/背景**；K∈{1,2,5}。
- **切分原则**：按物体实例切分，不按 episode 随机切分；否则同一物体的相邻帧会泄漏到查询集，指标虚高。
- **目标**：
  \[
  \mathcal L=\mathcal L_{action}(Q)+\lambda_1\mathcal L_{skill}(S,Q)+\lambda_2\mathcal L_{cons}(Q)+\lambda_3\mathcal L_{verifier}(Q),
  \]
  其中技能对比损失把同一技能的跨任务样本拉近，cons 损失约束相邻块预测一致，verifier 损失用 GSO/几何谓词做辅助监督。
- **适配器**：共享 VLA 骨干 + 技能专属低秩适配器；元学习只更新适配器初始化，不更新骨干。这样既满足单模型，又避免 32 个独立模型。
- **防泄漏**：未见物体的图像、位姿、类别名不得进入训练；语言模板可以做同义改写，但不能把测试物体名写进训练。

### 4.6 UIP-22 · SF-VLA：慢-快分层

- **慢规划器**：1–2 Hz，输入语言 + 稀疏视觉 token，输出当前技能/子目标与粗动作意图；可用 VLA 的 VLM 部分。
- **快执行器**：10–20 Hz，输入腕部图像 + 本体状态 + 子目标 token，输出短程末端增量/关节目标；用几何伺服与轻量策略，保证接触精度。
- **固定 \(T_a\)**：整块仍由快执行器填满；慢规划器只在块边界更新。若 \(L_{slow}+L_{fast}\) 超过 \(T_a\delta\)，则慢规划器降频或缓存。
- **少样本位置**：少样本适配主要投在慢规划器的技能路由与快执行器的抓取参数上，而不是整网微调。

## 5. 形式化推导

### 5.1 技能分解与少样本共享

\[
q(s\mid o,\ell)=\mathrm{softmax}_s\left(\frac{\langle e(o,\ell),p_s\rangle}{\tau}+\log \pi_{VLA}(s\mid o,\ell)\right),
\quad
p_s=\frac{1}{K}\sum_{i=1}^{K}e(o_i,\ell_i).
\]

32 个任务共享约 10 个技能，因此每个技能的有效支持样本数约为 \(32K/10\)，比“每任务 K-shot”多 3 倍以上。这是少样本可行的结构性理由，而不是魔法。

### 5.2 物体中心迁移的误差传播

设物体位姿估计误差为 \(\epsilon_o\)，动作迁移误差近似 \(\|\epsilon_{A'}\|\le \|g_{o'}\|\|\epsilon_{A^{rel}}\|+\|\epsilon_{g_{o'}}\|\|A^{rel}\|\)。第二项说明：**物体位姿误差会随动作幅度放大**。因此：
- 对大幅度搬运，优先用腕部短程伺服修正末段；
- 对接触密集任务，不要完全依赖一次性位姿变换，要在块边界重估位姿。

### 5.3 保形拒识

对支持集计算 \(r_i\)，取 \(\hat r\) 为 \(\lceil (K+1)(1-\alpha)\rceil/K\) 分位数。若查询分数 \(r\le\hat r\)，接受检索；否则拒识。报告两个数：经验接受率与接受样本上的成功率。**不要报告“1-α 保证”**，因为测试物体分布不满足交换性。

### 5.4 两种计分语义下的重做决策

见 4.4 的公式。关键结论：

- 若 \(S_{ever}\)：已完成步骤的分数不可逆，恢复只对“后续步骤依赖”有价值；盲目重做会浪费延迟，甚至引入新风险。
- 若 \(S_{final}\)：恢复当前步的收益是 \(w_j\) 加上下游收益；接触密集任务的 \(c_j\) 高，但 \(w_j\) 也高，通常值得恢复。
- 因此策略应**先估计语义，再决定重做强度**；在语义未知时，用“下游依赖”作为保守触发器，避免无脑重做。

### 5.5 \(T_a\) 与延迟的权衡

设控制周期 \(\delta\)，单次 VLA 推理延迟 \(L\)。为避免执行停顿，需要
\[
T_a\ge \left\lceil \frac{L}{\delta}\right\rceil.
\]
有效反应时间 \(T_{react}=T_a\delta+L\)。全局 \(T_a^*\) 应最大化
\[
\mathbb E[\text{score}(T_a)]-\lambda\,\mathrm{Var}[\text{latency}(T_a)]-\mu\,\mathrm{AnomalyRate}(T_a).
\]
这解释了为什么“VLA 越慢，接触密集任务越吃亏”：不是模型不准，而是 \(T_a\) 被迫变大，块边界之间无法纠错。

### 5.6 误差分解

\[
R_{test}\approx R_{ground}+R_{route}+R_{transfer}+R_{recover}+R_{exec}.
\]

实验上分别用“冻结路由/冻结迁移/去掉恢复/去掉检索”的 ablation 估计各项，而不是只报一个总分。这样即使总分不涨，也能知道少样本到底帮了哪一层。

## 6. 伪代码

### 6.1 FSP-VLA 推理循环（严格返回完整块）

```python
class FSPVLA:
    def __init__(self, backbone, skill_memory, T_a, K=3,
                 tau_conf=0.5, alpha=0.1, adapt_budget_ms=80):
        self.backbone = backbone
        self.mem = skill_memory          # per-skill object-centric memory
        self.T_a = T_a
        self.K = K
        self.tau_conf = tau_conf
        self.alpha = alpha
        self.adapt_budget_ms = adapt_budget_ms

    def reset(self):
        self.g = 0                       # current scoring-step index
        self.episode_proto = None
        self.adapted = False
        self.last_action = None

    def get_action(self, obs):
        # Called only at chunk boundaries; no intra-chunk observation.
        self._verify_boundary(obs)       # UIP-01' + UIP-20: done/fail/regressed
        self.episode_proto = self._update_proto(obs)  # UIP-18: label-free

        s, conf = self._route_skill(obs)              # UIP-16: q(s|o,l)
        if conf < self.tau_conf:                      # UIP-19: conformal fallback
            chunk = self._safe_primitive(obs, s)
        else:
            keys, vals, w = self.mem.retrieve(s, obs, self.episode_proto, self.K)
            prior = self.backbone.sample_chunk(obs, s)  # (T_a, ...)
            chunk = self._fuse_object_centric(prior, keys, vals, w, obs)
        chunk = self._shape_check(chunk)              # exactly (T_a, ...)
        self.last_action = chunk
        return self._to_action_dict(chunk)

    def _verify_boundary(self, obs):
        st, conf = self.verifier(obs, self.lang, self.g)
        if conf < self.conf_thr:
            return
        if st == "done":
            self.g += 1
        elif st == "regressed" and self._worth_redo(obs, self.g):
            self.mem.activate_recovery(self.g)        # UIP-20
        # fail/ongoing: keep current subgoal; do not blindly retry
```

def worth_redo(step_j, w_j, downstream, cost, semantics, conf):
    direct = w_j if semantics == "final" else 0.0
    gain = conf * (direct + downstream)
    return gain > cost

**预注册预测（待验证）**：

- P1：FSP-VLA 在未见物体上的抓取成功率高于全量微调 VLA，因为物体中心迁移直接对准几何变化；延迟不显著增加。
- P2：位姿方差越大，物体中心迁移相对世界坐标的增益越大。
- P3：保形拒识以少量接受率为代价，显著降低灾难性失败；若接受率过低，则回退阈值。
- P4：在 \(S_{final}\) 语义下，RIDE 对反向撤回的步骤分增益最大；在 \(S_{ever}\) 下增益主要来自下游依赖。
- P5：\(T_a\) 与总分呈 U 形，接触密集任务的最优 \(T_a\) 更小。

## 8. 合规、风险与反脆弱

- **单模型**：所有技能头/适配器/检索投影共享一条骨干；不调用外部 VLM/API。检索记忆是训练数据的非参数索引，不引入第二个模型。
- **无测试标签**：不做监督测试时更新；TAP-EP 只用自监督与转导，且可一键关闭。
- **端口隔离**：每端口独立的 `reset()`、记忆命名空间与历史；绝不跨端口共享 episode 状态。
- **接口红线**：`get_action` 永远返回完整 `(T_a, …)` 块、正确 dtype、正确 token；不做“短块”投机。
- **动作规律性**：融合/恢复块要做平滑与限幅，避免统计异常；延迟要有硬预算与降级路径。
- **仿真过拟合**：GSO 只做结构/顺序裁判；真机时段必须做校准锚点，报告“代理-真机”相关性。
- **计分语义**：A0 未核实前，不把“反向撤回一定扣分”写成事实；用双语义决策规则。
- **保形假设**：未见物体破坏交换性；只报告经验覆盖，不宣称保证。

## 10. 本轮最大风险 & 押注

**一句话**：若“物体中心对齐”不可靠，检索会把相似演示变成系统性错误，而 VLA 的语言先验会让错误更自信；因此保形拒识与真机校准锚点不是可选项，而是这套方案能否成立的前提。

**→ 押注**：**UIP-16 FSP-VLA × UIP-17 物体中心迁移 × UIP-20 恢复模板检索**。理由：它同时对准 `unseen_object_*`（少样本语义/几何对齐）与 `human_*`（块边界恢复）两大数据空白，完全落在 API 权限内，不依赖测试标签，也不改变接口；VLA 提供先验，少样本提供校准，二者互补而不是叠加。
