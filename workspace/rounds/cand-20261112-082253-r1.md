# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；本轮灵感：「机器人」×「多模态融合」）

> 第 59 轮把证据链一路压到电流环、WCET 与阻抗证书，堵住了「执行器不是理想执行器」的抽象泄漏。但它留下了一个更隐蔽、更根本的假设：**多模态证据是相互独立的见证者**。第 59 轮甚至已经局部立法：EV-exec 只能参与对账，绝不能作为佐证——这其实是对「执行模态不独立」的一次局部承认。本轮两个灵感把这条局部承认推广成全局危机：**机器人**不是被动挂着传感器的融合容器，它的身体（运动学、柔顺、温度、标定、电源、振动）是横跨所有模态的**共同因**；**多模态融合**因此不能继续做「独立投票的乘积」，而必须做**因果校正后的证据核算**。更关键的是，机器人是少数能够**主动干预世界**的观测者：多模态之间的独立性不是声明出来的，而是可以通过动作**挣来的**。本轮核心命题：**「先质疑一致性，再为独立性付出来源；把『多模态一致』从统计巧合升级为因果可识别的佐证」**——从第 59 轮的**执行接地（Execution-Grounded）**推进到**具身因果融合接地（Embodied Causal Fusion Grounded, ECFG）**。

核心矛盾：

- **H35（伪佐证·身体是共同因）**：视觉、力觉、本体、声学、执行五路证据在同一个身体上共享大量隐变量：位姿误差让视觉与力觉同时偏移；关节柔顺让力矩、位置、声学同时变化；电源纹波和温漂让所有电学模态一起漂移。给定目标命题 θ（例如「物体刚度」），这些模态**条件不独立**。把它们当独立似然相乘，等价于把同一份证据数了很多遍；一致不是「五票赞成」，而可能只是「一个共同因被五个传感器同时感知」。这会把证据门的 k-of-N 佐证变成**伪佐证（spurious corroboration）**，导致后验过度自信、δ_f 被系统性低估。
- **H36（独立性是因果量，不是声明量）**：第 56~59 轮用 `indep_declared` 这种布尔声明来换取跨模态佐证资格。但独立性不是可以「声明」的属性，而是图结构性质：只有当两路模态在给定 θ 与已观测共同因后**条件独立**，它们的一致性才提供额外信息。需要把「声明」替换成**可审计的因果独立性证书**；没有证书就只配做对账，不配做佐证——这正是第 59 轮 EV-exec 规则的正确推广。
- **H37（干预不是免费的实验）**：机器人可以用动作打破混杂：换个角度抓、改变阻抗、移动基线、改变接触点、调制光照，让共同因的通道按已知方式变化，而 θ 的因果效应保持不变。但每一次干预都消耗时间、能量、探针/执行预算，甚至可能把系统带入不可逆状态。因此问题不是「要不要主动感知」，而是**在安全动作集内，选择单位风险信息增益最大的干预**；不存在安全且可识别的干预时，必须退回保守融合，而不是「为了独立性硬做实验」。
- **H38（共同模失效与跨具身迁移）**：模态之间不仅有连续的相关噪声，还有离散的共同失效：同一电源、同一 OS、同一标定源、同一时钟、同一网络。共同模失效下，k-of-N 的 N 是虚的；真正有效的是**机制上独立的失效组数**。另一方面，耦合图是**形态相关**的：四足、机械臂、人形、灵巧手的 `E_morph` 完全不同；把一套融合模型直接迁移，等于把源形态的共同因结构强加给目标形态。必须把图分解为**传感器物理边（可迁移）**与**形态耦合边（需少量干预标定）**。

## 0. 直觉与动机

**灵感 1（机器人 → 身体即共同因，ζ_body）**
直觉：机器人融合的默认图景是「世界 θ → 若干独立传感器 → 融合」。真实图景是「世界 θ 与身体状态 ζ_body → 若干传感器 → 融合」，其中 ζ_body 同时连向几乎所有模态。ζ_body 至少包含：位姿/标定误差、关节柔顺与传动间隙、温度与热漂移、电源电压/电流纹波、机体振动、接触几何、时间同步偏差。它们不是各自模态的私有噪声，而是**共享载荷**。把 ζ_body 显式建模成隐变量并条件化，是把「一致」还原为「同一共同因」的第一步。

**灵感 2（多模态融合 → 从独立投票到因果校正融合）**
直觉：经典贝叶斯融合 `p(θ|m) ∝ p(θ) Π_i p(m_i|θ)` 只有在给定 θ 后模态条件独立时才成立。具身条件下正确写法是 `p(θ|m) ∝ p(θ) ∫ p(ζ_body) Π_i p(m_i|θ,ζ_body) dζ_body`。这在工程上可以落成一个**共享因子模型**：每个模态的观测 = θ 的因果效应 + 共享因子载荷 × ζ_body + 私有噪声。用因子分析/变分推断估出 ζ_body 与残差相关阵 R，再用**有效独立度 N_eff**（而不是模态数 N）去计算佐证强度。N_eff 直接给出「伪佐证赤字」：当所有模态完全相关，N_eff→1，五路证据只值一票。

**灵感 3（机器人 → 动作即干预，do(a)）**
直觉：面对混杂，被动观测只能做「后门调整」；但机器人可以**做实验**。改变抓取角度、阻抗、接触点、基线运动或光照，相当于对共同因通道施加 `do(a)`。好的干预让 ζ_body 的载荷 `B(a)` 发生已知变化，而 θ 的因果通道 `A(a)` 保持不变或按已知方式变化；对两次干预做差分，就能把 θ 从 ζ_body 中分离出来。这就是「**用动作挣独立性**」：不是相信模态一致，而是主动制造一个只有 θ 能解释的差异。干预设计的目标是**单位风险/成本的信息增益最大**，且动作必须落在第 59 轮 EEIS 的 `K_safe` 内。

**灵感 4（多模态融合 → 共同模失效组与相关共形）**
直觉：连续相关之外，还有离散的共同失效。把模态按**失效机制**分成组：电学组（电源/ADC/总线）、机械组（结构/传动/接触）、光学组（光照/遮挡/标定）、计算组（OS/时钟/网络）。同组内失败高度相关，不能相互佐证；跨组才可能独立。证据门因此应数**独立失效组** `k_corr`，而不是模态数；风险预算按组分配，校准用**组内共形 + 组间联合界**——组内允许任意依赖，组间用 Boole 联合界，覆盖率 `≥ 1−Σα_g` 在最坏依赖下仍成立。代价是保守，但这是安全该付的代价。

**灵感 5（合流 → ECMF 闭环，把「一致性」升级为「可识别的因果一致」）**
直觉：把上面四件事串成一个替换 XMC+ 的闭环：**建图 → 估共同因 → 算 N_eff/k_corr → 若佐证不足且预算允许，设计并执行安全干预 → 用干预前后的不变性检验挣得独立性 → 因果校正融合 → 产出因果证据与证书**。EV-exec 不再被永久放逐：它可以通过一次执行干预（例如改变阻抗后重测力-位移曲线）来证明自己提供了独立于视觉/本体的信息，从而获得**有界、可撤销、由检验功效封顶**的佐证权重；没有通过检验时仍严格回到第 59 轮的「只对账、不佐证」。

**灵感 6（跨具身 → 图分解与少量干预标定）**
直觉：耦合图 `G_body = (V, E_sensor ∪ E_morph)`。`E_sensor` 是传感器物理（相机噪声随光照、力传感器随温度），跨形态相对稳定；`E_morph` 是形态耦合（腿式冲击→IMU/视觉；臂式柔顺→力/位姿；灵巧手接触→触觉/力），随运动学与动力学改变。迁移时冻结 `E_sensor`，只从目标形态的少量安全干预中估计 `E_morph`；用 H-散度/不变性给出迁移风险界。这样「跨具身多模态融合」不是重新训练一个黑箱，而是**迁移一张可解释的因果图**。

## 1. 形式化定义（增量：定义 153–161）

**定义 153（具身模态因果图 EMCG）**
*直觉：把「身体」画进图里；模态不是并列的传感器，而是同一具身体的多个投影。*
形式化：`G_body = (V, E)`，节点
```
V = {θ} ∪ ℳ ∪ Z_body ∪ 𝒜,
ℳ = {vis, tap, prop, acou, exec},   Z_body ⊂ R^{d_z},   𝒜 = 可用动作
```
边 `E = E_cause ∪ E_load ∪ E_action ∪ E_morph`，每类边有结构方程：
```
E_cause :  m_i = a_i(θ, φ_body) + ε_i^{own}
E_load  :  所有 m_i 共享载荷 b_i(φ_body)^T ζ,  ζ ∈ Z_body
E_action:  do(a) 改变 a_i(·) 与/或 b_i(·)
E_morph :  b_i、a_i 对形态描述子 φ_body 的依赖
φ_body = (运动链, 连杆惯量, 关节柔顺, 执行器带宽, 传动间隙, 热参数)
```
记载荷矩阵 `B(φ) ∈ R^{N×d_z}`、因果通道 `A(φ) ∈ R^N`。图必须**声明式可审计**：每条 `E_load`/`E_morph` 边绑定来源（物理模型、标定实验、历史数据）与置信度。未声明但可能存在的共同因进入**敏感度项**，不得当作不存在。

**定义 154（共享因解耦融合 SCD）**
*直觉：先把「身体造成的一致」扣掉，剩下的才配叫独立证据。*
形式化：线性高斯共享因子模型
```
ζ ~ N(0, I_{d_z})
m_i = a_i(θ, φ) + b_i(φ)^T ζ + ε_i,     ε ~ N(0, Σ_ε)
```
后验
```
p(θ | m) ∝ p(θ) ∫ p(ζ) Π_i p(m_i | θ, ζ) dζ
```
工程近似：
1. 用因子分析/变分 EM 估 `B` 与 `ζ̂`（含温度、位姿误差等可观测代理）；
2. 残差 `r_i = m_i − a_i(θ̂) − b_i^T ζ̂`，估计残差协方差 `Σ_ε`；
3. 条件化后的相关阵 `R_cond = D_ε^{-1/2} Σ_ε D_ε^{-1/2}`；
4. 用 `R_cond` 做融合，用**未条件化**的 `R` 做证据门（门要比融合更保守）。
定义 SCD 算子 `SCD(m, G_body) = (ζ̂, Σ_ζ, R, R_cond, Σ_ε)`。

**定义 155（有效独立度 N_eff 与伪佐证赤字）**
*直觉：五路完全相关的证据只值一票；有效票数不是数模态，而是看相关阵的「设计效应」。*
形式化：对相关阵 `R ∈ R^{N×N}`（对角为 1），定义
```
N_eff(R) = (1^T 1)^2 / (1^T R 1) = N^2 / Σ_{i,j} R_{ij}
```
等相相关 `R_{ij}=ρ (i≠j)` 时 `N_eff = N / (1+(N−1)ρ)`：ρ→0 得 N，ρ→1 得 1。定义
```
w_corr = N_eff / N ∈ (0,1],       Δ_corr = N − N_eff     （伪佐证赤字）
```
高斯等方差下，naive 融合的后验方差 `σ²/N`，因果校正后为 `σ²/N_eff`；naive 把不确定度低估了 `w_corr` 倍。证据门必须用 `N_eff` 与 `w_corr`，而不是 N。

**定义 156（共同模失效组与相关风险预算 CMRB）**
*直觉：同一条电源上的三个传感器不是三个人，而是同一个人戴了三顶帽子。*
形式化：按失效机制把模态划分为 `ℳ = ⊔_{g=1}^{K} G_g`；同组内允许任意依赖，跨组按联合界处理。组证据 `e_g ∈ {support, neutral, oppose, fail}`，
```
k_corr = Σ_{g=1}^{K} 1[e_g = support]
```
风险分配 `δ = Σ_g δ_g`，`δ_g = π_g · δ`（`Σπ_g=1`；默认均匀）。组内共形阈值 `q_g(α_g)`；组间联合界给出
```
P(θ ∈ C) ≥ 1 − Σ_{g=1}^{K} α_g
```
该界**不要求组内独立**，只要求组内可交换；跨组即使相关，Boole 界仍成立（只是保守）。因果证据门要求
```
k_corr ≥ k_req   ∧   N_eff ≥ N_min   ∧   关键组 ¬fail
```
不可逆接触仍继承第 59 轮硬禁令：`k_corr` 再高也不能替代 `EV-human`/`EV-xmodal(L1)`。

**定义 157（干预可识别性与主动去混杂 AID）**
*直觉：与其猜两个模态为什么一致，不如做一个只有 θ 能解释的动作。*
形式化：干预 `do(a)` 改变载荷与因果通道为 `B(a), A(a)`。干预杠杆
```
Λ(a) = I(θ; m | do(a)) − I(θ; m)
```
线性高斯下
```
I(θ; m | do(a)) = ½ log(1 + σ_θ² A(a)^T Σ_m(a)^{-1} A(a))
```
**可识别性充分条件**：若存在 `a_1,a_2` 使 `B(a_1)=B(a_2)` 而 `A(a_1)≠A(a_2)`，则对两次干预做差分
```
Δm = [A(a_1)−A(a_2)] θ + ε
```
共同因载荷被消掉，θ 可识别（至多差一个已知缩放）。更一般地，若堆叠设计 `[A(a)]_{a∈𝒜}` 对 θ 满列秩，则 θ 可识别。
安全干预集
```
𝒜_safe(cp) = { a : K_safe(a) ≠ ∅ ∧ C_rt ok ∧ B_id > 0 ∧ Risk(a) ≤ δ_int ∧ a 可回退 }
```
干预设计
```
a* = argmax_{a∈𝒜_safe} [ Λ(a) − λ_r·Risk(a) − λ_c·Cost(a) ]
```
若 `𝒜_safe = ∅` 或 `Λ(a*) ≤ 0`，返回 `NO_IDENTIFYING_INTERVENTION`：**不挣，就不给佐证**。

**定义 158（跨具身图分解与迁移界 XEMB）**
*直觉：传感器物理可以搬，身体耦合不能白搬；换形态等于换了一张共同因图。*
形式化：`G_body(φ) = (V, E_sensor ∪ E_morph(φ))`，`φ` 为形态描述子。目标图
```
G_T = (V, E_sensor ⊕ E_morph(φ_T))
```
用目标形态上 `N_calib` 次安全干预估 `E_morph(φ_T)`。迁移风险界（标准 H-散度形式）
```
R_T(f) ≤ R_S(f) + d_H(P_S^{G}, P_T^{G}) + λ
```
在正则条件下 `d_H ≤ O(1/√N_calib)`。若 `d_H` 或标定残差超过阈值，**拒绝迁移**，退回目标形态自己的图与保守融合，而不是「努力适配」。

**定义 159（ECMF 闭环算子）**
*直觉：融合不再是「加权平均」，而是一段带实验设计的因果推断流程。*
形式化：
```
ECMF(M, cp, θ, δ_f^req):
 ① G_body ← update_graph(φ_body, M.calib, version)
 ② ζ̂, Σ_ζ ← SCD.infer(M.obs, G_body)
 ③ R, R_cond, N_eff ← effective_independence(M.obs, ζ̂, G_body)
 ④ D_causal ← causal_disagreement(M.obs, ζ̂, G_body)
 ⑤ if N_eff < N_min ∨ k_corr < k_req:
      if B_id > 0 ∧ 𝒜_safe ≠ ∅:
         a* ← AID.design(G_body, θ, δ_int, B_id)
         M, obs' ← CLEP.execute_intervention(M, a*, δ_f^req)   # 复用 59 轮安全执行
         G_body ← update_graph_from_intervention(G_body, a*, obs')
         goto ②
      else:
         return DEGRADE_CAUSAL(M, cp, "no_identifying_intervention")
 ⑥ fused ← causal_fuse(M.obs | ζ̂, R_cond, G_body)
 ⑦ EV-causal ← build_causal_evidence(G_body, ζ̂, N_eff, k_corr, D_causal, a*)
 ⑧ Cert_id ← build_identification_certificate(G_body, ζ̂, a*, Λ, p_inv, risk)
 ⑨ M ← update_beliefs_with_causal(M, cp, fused, EV-causal)
 ⑩ return M, fused, D_causal, EV-causal, Cert_id
```
关键顺序：**先估共同因，再算佐证，再决定是否干预，最后才融合**。融合使用的相关结构与证据门使用的相关结构可以不同——门必须更保守。

**定义 160（因果证据 EV-causal、因果证据门与证书 J_causal）**
*直觉：一致性本身不是证据；「一致性经得起干预检验」才是证据。*
形式化：
```
EV-causal = (G_body_version, ζ_residual, N_eff, k_corr, D_causal,
             intervention_id, invariance_p, info_gain, credit κ, degraded_flag)
```
佐证信用
```
κ_i = 1[p_inv ≤ α_id] · min(1, Λ(a*)/Λ_req) · 1[Risk(a*) ≤ δ_int] · 1[a* 是识别性干预]
```
无干预 ⇒ `κ_i = 0`；检验功效不足 ⇒ 上界自动收紧。因果证据门
```
ok = (N_eff ≥ N_min) ∧ (k_corr ≥ k_req) ∧ (D_causal ≤ θ_D_c)
     ∧ (κ_{i∈佐证集} ≥ κ_req) ∧ (关键组 ¬fail)
```
`EV-causal` 只审计「佐证是否挣来」，不能替代独立观测；不可逆接触仍需更强门。
```
J_causal = (G_body, ζ_traj, R_cond, N_eff_traj, k_corr_traj,
            intervention_log, invariance_tests, Cert_id_chain,
            EV-causal_log, transfer_calibration, version)
```

**定义 161（辨识预算 B_id 与 PCE⁺）**
*直觉：独立性不能拿安全预算去买；买不起就承认不知道。*
形式化：
```
B_id = (interventions_left, info_gain_left, identification_risk_left, calibration_left)
```
PCE⁺ 的 VOI 扩展
```
voi_causal(π) = VOI_meta_pessimistic(π) − cost_exec(π) − cost_causal(π)
cost_causal = λ_id·max(0, I_req − B_id.info_gain_left)
            + λ_risk·max(0, Risk(π) − B_id.identification_risk_left)
            + λ_cal·max(0, N_calib_req − B_id.calibration_left)
```
四类预算（探针/微调/解释/执行）之外再加 `B_id`；五者单调、互不挪用。`B_id` 耗尽 ⇒ **停止挣取新佐证**，只允许保守融合、对账或降级；绝不允许「用安全换独立性」。

## 2. 关键算法伪代码

```python
class SharedCauseDisentangler:
    def __init__(self, d_z):
        self.d_z = d_z

    def infer(self, obs, graph):
        # 观测 m_t (T x N)；可观测的体温/位姿误差作为 z 的代理
        M = np.asarray(obs.matrix)                     # T x N
        Z_proxy = np.asarray(obs.body_proxy)            # T x d_proxy
        B, A = graph.loading(obs.phi)

        # 因子分析 EM：缺失用 mask，避免把缺失当 0
        B_hat, z_hat, Sigma_eps = factor_analysis_em(
            M, A, Z_proxy, n_factors=self.d_z, mask=obs.mask)

        # 条件化后的残差相关阵
        resid = M - A[None, :] * obs.theta_hat[:, None] - z_hat @ B_hat.T
        Sigma_eps = robust_cov(resid, mask=obs.mask)
        R_cond = corr_from_cov(Sigma_eps)
        R_marg = corr_from_cov(B_hat @ B_hat.T + Sigma_eps)

        zeta_cov = np.cov(z_hat, rowvar=False) if z_hat.shape[1] > 1 else np.zeros((1,1))
        return SCDResult(z_hat=z_hat, zeta_cov=zeta_cov, R=R_marg,
                         R_cond=R_cond, Sigma_eps=Sigma_eps, B=B_hat)
```

### IP-154 NEFF（有效独立度与伪佐证赤字）

```python
def effective_independence(obs, scd, graph):
    R = scd.R_cond
    N = R.shape[0]
    N_eff = (N ** 2) / np.sum(R)
    N_eff = max(1.0, min(float(N), float(N_eff)))
    w_corr = N_eff / N
    deficit = N - N_eff

    # 仍然保留未条件化的 R 供证据门使用（更保守）
    N_eff_gate = (N ** 2) / np.sum(scd.R)
    return EffectiveIndependence(
        N_eff=N_eff, N_eff_gate=max(1.0, min(N, N_eff_gate)),
        w_corr=w_corr, deficit=deficit,
        R_cond=R, R_marginal=scd.R
    )

def naive_vs_causal_variance(obs, indep, theta_prior_var):
    # 高斯近似：naive 精度用对角，causal 精度用完整相关阵
    sig = np.array([obs.sigma[i] for i in range(len(obs.modalities))])
    naive_prec = np.sum(1.0 / sig ** 2)
    causal_prec = 1.0 / (sig @ indep.R_cond @ sig)
    return 1.0 / naive_prec, 1.0 / causal_prec
```

### IP-155 CMRB（共同模失效组与相关共形）

```python
@dataclass
class CommonModeGroup:
    name: str
    modalities: list
    failure_modes: list

class CommonModeRiskBudget:
    def __init__(self, groups, alpha_total):
        self.groups = groups
        self.alpha = self._allocate(alpha_total)

    def _allocate(self, alpha_total):
        # Boole 联合界：Σ alpha_g = alpha_total；默认均匀
        K = len(self.groups)
        return {g.name: alpha_total / K for g in self.groups}

    def group_evidence(self, obs, group):
        # 组内只输出一个证据，不允许组内模态互相投票
        vals = [obs.label_support[m] for m in group.modalities if m in obs.label_support]
        if not vals:
            return "fail"
        if any(v == "fail" for v in vals):
            return "fail" if group.is_critical else "neutral"
        return majority([v for v in vals if v != "fail"])

    def gate(self, obs, N_eff, k_req, N_min):
        e = {g.name: self.group_evidence(obs, g) for g in self.groups}
        k_corr = sum(1 for v in e.values() if v == "support")
        critical_fail = any(e[g.name] == "fail" for g in self.groups if g.is_critical)
        ok = (k_corr >= k_req and N_eff >= N_min and not critical_fail)
        return ok, CausalGateResult(k_corr=k_corr, evidence=e,
                                    critical_fail=critical_fail)

    def conformal_quantile(self, group_name, calib_scores):
        a = self.alpha[group_name]
        n = len(calib_scores)
        k = int(np.ceil((n + 1) * (1 - a)))
        return np.sort(calib_scores)[min(k, n) - 1]
```

### IP-156 AID（主动干预去混杂）

```python
class ActiveInterventionDesigner:
    def __init__(self, eeis, ertc, lambda_risk=1.0, lambda_cost=1.0):
        self.eeis = eeis
        self.ertc = ertc
        self.lr = lambda_risk
        self.lc = lambda_cost

    def expected_info_gain(self, action, belief, graph):
        A_a, B_a = graph.channels_under(action)
        Sigma_m = B_a @ belief.zeta_cov @ B_a.T + belief.Sigma_eps
        precision = A_a.T @ np.linalg.solve(Sigma_m, A_a)
        info = 0.5 * np.log1p(belief.theta_var * precision)
        return info

    def safe_actions(self, cp, belief, delta_int):
        cands = admissible_actions(cp, belief)
        out = []
        for a in cands:
            K_safe, _ = self.eeis.compile(delta_int, belief.fused, belief.xi_exec,
                                          belief.b_r[cp.region], action=a)
            if K_safe is None:
                continue
            if not self.ertc.feasible(a):
                continue
            if a.risk > delta_int or not a.reversible:
                continue
            out.append(a)
        return out

    def design(self, graph, belief, cp, delta_int, budget):
        acts = self.safe_actions(cp, belief, delta_int)
        if not acts or budget.identification_risk_left <= 0:
            return None
        scored = []
        for a in acts:
            info = self.expected_info_gain(a, belief, graph)
            gain = info - self.lr * a.risk - self.lc * a.cost
            scored.append((gain, a, info))
        gain, a, info = max(scored, key=lambda x: x[0])
        if gain <= 0:
            return None
        return InterventionPlan(action=a, info_gain=info, risk=a.risk,
                                identification_test=build_invariance_test(a))
```

```python
class CrossEmbodimentTransfer:
    def __init__(self, source_graph, target_phi, min_calib=3, max_divergence=0.2):
        self.G_S = source_graph
        self.phi_T = target_phi
        self.min_calib = min_calib
        self.max_div = max_divergence

    def candidate_graph(self):
        # 冻结 E_sensor，只复制 E_morph 的先验
        return EmbodiedCausalGraph(
            nodes=self.G_S.nodes,
            E_sensor=self.G_S.E_sensor,
            E_morph={self.phi_T: self.G_S.E_morph_prior(self.phi_T)},
            B=self.G_S.B, A=self.G_S.A,
            edge_sources={"sensor_physics": 1.0, "morph_prior": 0.5},
            version=self.G_S.version
        )

    def calibrate(self, graph, calib_obs, interventions):
        if len(interventions) < self.min_calib:
            return None
        return graph.update_from_calibration(self.phi_T, calib_obs, interventions)

    def transfer_bound(self, source_risk, divergence_estimate, n_calib):
        # H-散度经验估计 + 标定项；n_calib 越多界越紧
        delta_cal = 1.0 / np.sqrt(max(n_calib, 1))
        bound = source_risk + divergence_estimate + delta_cal
        return bound

    def accept(self, divergence_estimate):
        return divergence_estimate <= self.max_div
```

### IP-158 ECMF（具身因果融合闭环）

```python
def embodied_causal_fusion(M, cp, theta, delta_f_req, budget):
    """替换 XMC+ 的因果融合闭环。默认保守：没有挣到独立性就不给佐证。"""
    for it in range(MAX_IDENT_ROUNDS):
        # ① 建图 / ② 估共同因 / ③ 算有效独立度
        G_body = update_graph(M, cp)
        scd = M.scd.infer(M.obs[cp.region], G_body)
        indep = effective_independence(M.obs[cp.region], scd, G_body)

        # ④ 因果分歧：先扣掉共同因再比
        D_causal = causal_disagreement(M.obs[cp.region], scd, G_body)

        # ⑤ 共同模证据门
        gate_ok, gate = M.cmrb.gate(M.obs[cp.region], indep.N_eff_gate,
                                    k_req=M.k_req, N_min=M.N_min)
        if gate_ok and D_causal <= M.theta_Dc:
            fused = causal_fuse(M.obs[cp.region], scd, G_body)
            EV = build_causal_evidence(G_body, scd, indep, gate, D_causal,
                                       intervention=None, credit=0.0)
            M = update_beliefs_with_causal(M, cp, fused, EV)
            return M, fused, D_causal, EV, None

        # ⑥ 佐证不足：尝试一次安全干预
        a_star = M.aid.design(G_body, M.belief[cp.region], cp,
                              delta_int=delta_f_req / 4, budget=budget)
        if a_star is None or budget.id_left <= 0:
            return degrade_causal(M, cp, "no_identifying_intervention")

        # ⑦ 走 59 轮 CLEP/ERTC/EEIS 执行干预，保证动作本身安全
        M, obs_new = closed_loop_exec_probe(M, cp, delta_f_req, budget,
                                            action_override=a_star.action)
        if obs_new is None or M.exec_degraded:
            return degrade_causal(M, cp, "intervention_exec_degraded")

        # ⑧ 不变性检验：只有在预注册方向上显著，才给信用
        p_inv, effect = invariance_test(obs_new, scd, a_star)
        credit = 0.0
        if p_inv <= M.alpha_id:
            credit = min(1.0, a_star.info_gain / M.Lambda_req)
        M = update_graph_from_intervention(M, G_body, a_star, effect, p_inv)
        budget.spend_id(a_star.info_gain, a_star.risk)
        M.last_credit = credit

        if credit <= 0.0:
            continue     # 干预失败：不加信用，下一轮会更保守或退出

    # 轮数耗尽：回到第 59 轮规则，只对账不佐证
    return degrade_causal(M, cp, "identification_rounds_exhausted")
```

### IP-159 J_causal（因果融合证书）

```python
@dataclass
class CausalCertificate:
    G_body: EmbodiedCausalGraph
    zeta_snapshot: np.ndarray
    R_cond: np.ndarray
    N_eff: float
    k_corr: int
    intervention_log: list
    invariance_tests: list
    Cert_id_chain: list
    EV_causal_log: list
    transfer_calibration: dict
    version: int

    def verify(self):
        if self.version < 0:
            return False
        if not (1.0 <= self.N_eff <= len(self.R_cond) + 1e-9):
            return False
        if self.k_corr > len(self.EV_causal_log) + 1:
            return False
        for ev, cert in zip(self.EV_causal_log, self.Cert_id_chain):
            if ev.intervention_id != cert.intervention_id:
                return False
            if ev.invariance_p > cert.alpha_id:
                return False
        return True

    def audit_corroboration(self):
        # 只有通过不变性检验的模态才允许计入 k_corr
        return sum(1 for ev in self.EV_causal_log
                   if ev.invariance_p <= ev.alpha_id and not ev.degraded_flag)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| EMCG | O(\|E\| + d_z³)/标定；图查询 O(1) | O(N·d_z + \|E\|) | 边来源可审计；未声明共同因进入敏感度项 |
| SCD | O(T·N·d_z² + d_z³)/区域 | O(T·N + d_z²) | 因子模型残差校准；缺失数据 mask 处理 |
| NEFF | O(N²)/区域 | O(N²) | `N_eff ≤ N`；等相相关退化为 `N/(1+(N−1)ρ)`；门用条件/边际双版本 |
| CMRB | O(K+N)/门；离线共形 O(N_cal log N_cal) | O(K+N_cal) | 组内任意依赖、组间联合界；`k_corr ≤ K`；关键组 fail-closed |
| AID | O(\|𝒜_safe\|·(N d_z² + C_info))/决策 | O(\|𝒜\|) | 只在 `K_safe` 内选；`Λ≤0` 或不可回退即放弃 |
| XEMB | O(N_calib·(T·N·d_z²))/迁移 | O(N_calib·T·N) | H-散度界；超过阈值拒绝迁移 |
| ECMF | O(K_id·(SCD + AID + CLEP))/检查点 | 复用 SCD/CMRB/AID | 默认信用为 0；干预失败不增加佐证；轮数有界 |
| J_causal | O(1)/追加审计 | O(接触数 + 干预数) | 证书链版本单增、检验与干预一一对应、信用可复算 |

**正确性定理（Embodied Causal Fusion Soundness, ECFS）**
假设 A22–A55（第 53–59 轮）成立；**(A56)** EMCG 对已声明共同因满足因果充分性（给定 `Z_body` 后无未观测混杂）；未声明共同因的总效应被敏感度参数 `Γ` 上界，且 `Γ` 进入证书。**(A57)** SCD 的因子模型可识别（载荷列满秩、噪声协方差结构约束），残差相关估计误差 `O(1/√T)`。**(A58)** AID 的干预满足 positivity、无直接作用于 θ 的后门路径、且动作落在第 59 轮 `K_safe` 与 ERTC 契约内；不变性检验水平为 `α_id`、功效为 `1−β_id`。**(A59)** CMRB 的分组覆盖全部已知共同失效模式；组内共形可交换、组间用 Boole 联合界。**(A60)** XEMB 的 `E_sensor` 在源/目标形态间不变，`E_morph` 由 `N_calib` 次安全干预标定；迁移界中的 H-散度可估。**(A61)** PCE⁺ 的五类预算单调、互不挪用；`B_id` 耗尽只能导致更保守。则：

1. **伪佐证抑制**：naive 融合的后验方差相对因果校正融合低估 `w_corr = N_eff/N` 倍；因此 naive 证据门的实际通过率高于名义值，而用 `N_eff` 与 `k_corr` 的门把伪佐证导致的过度自信压回名义风险以内。
2. **共享因校准健全性**：`ECE ≤ ε_meta(k) + δ_shared`，其中 `δ_shared = O(‖B‖·‖Σ_ζ‖^{1/2} + Γ)`；当 `ζ` 被精确条件化且 `Γ=0` 时退化为第 59 轮的校准界。
3. **因果佐证健全性**：若 `κ_i > 0`，则存在通过水平 `α_id` 的不变性检验；在 A58 下，`κ_i` 高估真实独立信息量的概率不超过 `β_id + 检验多重性校正`；无干预或检验失败时 `κ_i=0`，严格回到第 59 轮「EV-exec 不佐证」。
4. **共同模安全性**：`k_corr` 只数独立失效组；在组内任意依赖下，组间共形覆盖率 `P(θ∈C) ≥ 1−Σα_g`；关键组 fail 时门直接拒绝，不因其他组的高票而放行。
5. **跨具身迁移安全性**：`R_T ≤ R_S + d_H + O(1/√N_calib)`；`d_H` 超阈值即拒绝迁移，退回目标形态自建图，避免把源形态共同因强加给目标。
6. **终止性与部署界**：ECMF 在 `K_id + 1` 轮内终止于 `{因果承诺(带 Cert_id), 对账-only, 绕行, 降档, L2 协商, 安全停, 因果降级停}`。对检查点取联合界：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                   + δ_ft·1[回滚窗口] + δ_kg·1[检索失败] + δ_ux·1[μ_mis>θ_mis]
                   + δ_exec·1[ξ_exec漂移] + δ_ξ_ood·1[执行OOD] + δ_ertc·1[契约违例]
                   + δ_eeis·1[μ分析漏报]
                   + δ_shared·1[ζ未辨识] + δ_id·1[干预失败] + δ_cm·1[共同模漏分组]
                   + δ_xemb·1[跨具身])
         − P(𝒢 因果图结构性错误未检出) − P(护盾回退失败) − P(τ_int 超时 ∧ 安全停失效) − P(固件回滚失败)
```

关键：**EMCG 把「一致性」拆成「共同因 + 独立残差」**；**SCD/NEFF 把伪佐证量化成有效票数**；**AID 把「独立性」从声明变成可检验、可撤销、有预算的干预实验**；**CMRB 把 k-of-N 从数模态改成数独立失效组**；**XEMB 让跨具身迁移只搬传感器物理、不白搬身体耦合**；**ECMF 把融合变成一个默认保守、只在挣到时才放宽的因果推断闭环**。三条安全单向通道延续：**信念更准（去共同因）、不确定性更大（N_eff/共同模/敏感度）、动作更保守（干预失败即退回不佐证）**。

**定义 153（EMCG）** 记载荷 `B(φ)∈R^{N×d_z}`、因果通道 `A(φ)∈R^N`；每条 `E_load`/`E_morph` 边绑定来源与置信度；未声明共同因用敏感度参数 `Γ` 上界，不得当作不存在。

**定义 154（SCD）** 因子模型 + 变分/EM 推断，输出 `(ζ̂,Σ_ζ,R,R_cond,Σ_ε)`；融合用 `R_cond`，证据门用更保守的 `R`。

**定义 155（NEFF）** `N_eff=N²/ΣR_ij∈[1,N]`；naive 融合后验方差 `σ²/N`，校正后 `σ²/N_eff`，低估因子 `w_corr`；证据门必须用 `N_eff_gate`。

**定义 156（CMRB）** 组内任意依赖、组间联合界；`k_corr≤K`；关键组 fail 直接拒绝；不可逆接触仍继承第 59 轮硬禁令。

**定义 157（AID）** 线性高斯下 `I(θ;m|do(a))=½log(1+σ_θ²A(a)^TΣ_m(a)^{-1}A(a))`；充分识别条件：存在 `a_1,a_2` 使 `B(a_1)=B(a_2)` 而 `A(a_1)≠A(a_2)`，差分消去共同因；`a*=argmax_{a∈𝒜_safe}[Λ(a)−λ_rRisk(a)−λ_cCost(a)]`；`Λ≤0` 或 `𝒜_safe=∅` ⇒ 不挣信用。

**定义 158（XEMB）** `G_T=(V,E_sensor⊕E_morph(φ_T))`；`R_T≤R_S+d_H+O(1/√N_calib)`；`d_H` 超阈值拒绝迁移。

```python
def effective_independence(obs, scd, graph):
    R = scd.R_cond
    N = R.shape[0]
    N_eff = max(1.0, min(float(N), (N ** 2) / np.sum(R)))
    N_eff_gate = max(1.0, min(float(N), (N ** 2) / np.sum(scd.R)))
    return EffectiveIndependence(
        N_eff=N_eff, N_eff_gate=N_eff_gate,
        w_corr=N_eff / N, deficit=N - N_eff,
        R_cond=R, R_marginal=scd.R)

def naive_vs_causal_variance(obs, indep):
    sig = np.array([obs.sigma[i] for i in range(len(obs.modalities))])
    naive_prec = np.sum(1.0 / sig ** 2)
    causal_prec = 1.0 / (sig @ indep.R_cond @ sig)
    return 1.0 / naive_prec, 1.0 / causal_prec
```

### IP-155 CMRB（共同模失效组）

```python
@dataclass
class CommonModeGroup:
    name: str
    modalities: list
    failure_modes: list
    is_critical: bool = False

class CommonModeRiskBudget:
    def __init__(self, groups, alpha_total):
        self.groups = groups
        self.alpha = {g.name: alpha_total / len(groups) for g in groups}

    def group_evidence(self, obs, group):
        vals = [obs.label_support[m] for m in group.modalities if m in obs.label_support]
        if not vals:
            return "fail"
        if any(v == "fail" for v in vals):
            return "fail" if group.is_critical else "neutral"
        return majority([v for v in vals if v != "fail"])

    def gate(self, obs, N_eff, k_req, N_min):
        e = {g.name: self.group_evidence(obs, g) for g in self.groups}
        k_corr = sum(1 for v in e.values() if v == "support")
        critical_fail = any(e[g.name] == "fail" for g in self.groups if g.is_critical)
        ok = (k_corr >= k_req and N_eff >= N_min and not critical_fail)
        return ok, CausalGateResult(k_corr=k_corr, evidence=e,
                                    critical_fail=critical_fail)

    def conformal_quantile(self, group_name, calib_scores):
        a = self.alpha[group_name]
        n = len(calib_scores)
        k = int(np.ceil((n + 1) * (1 - a)))
        return np.sort(calib_scores)[min(k, n) - 1]
```

### IP-156 AID（主动干预去混杂）

```python
class ActiveInterventionDesigner:
    def __init__(self, eeis, ertc, lambda_risk=1.0, lambda_cost=1.0):
        self.eeis, self.ertc = eeis, ertc
        self.lr, self.lc = lambda_risk, lambda_cost

    def expected_info_gain(self, action, belief, graph):
        A_a, B_a = graph.channels_under(action)
        Sigma_m = B_a @ belief.zeta_cov @ B_a.T + belief.Sigma_eps
        precision = A_a.T @ np.linalg.solve(Sigma_m, A_a)
        return 0.5 * np.log1p(belief.theta_var * precision)

    def safe_actions(self, cp, belief, delta_int):
        out = []
        for a in admissible_actions(cp, belief):
            K_safe, _ = self.eeis.compile(delta_int, belief.fused,
                                          belief.xi_exec, belief.b_r[cp.region],
                                          action=a)
            if K_safe is None or not self.ertc.feasible(a):
                continue
            if a.risk > delta_int or not a.reversible:
                continue
            out.append(a)
        return out

    def design(self, graph, belief, cp, delta_int, budget):
        acts = self.safe_actions(cp, belief, delta_int)
        if not acts or budget.identification_risk_left <= 0:
            return None
        scored = [(self.expected_info_gain(a, belief, graph)
                   - self.lr * a.risk - self.lc * a.cost, a)
                  for a in acts]
        gain, a = max(scored, key=lambda x: x[0])
        if gain <= 0:
            return None
        return InterventionPlan(action=a, info_gain=gain, risk=a.risk,
                                identification_test=build_invariance_test(a))
```

```python
class CrossEmbodimentTransfer:

            E_sensor=self.G_S.E_sensor,

            edge_sources={"sensor_physics": 1.0, "morph_prior": 0.5},
            version=self.G_S.version)

        if len(interventions) < self.min_calib:
            return None
        return graph.update_from_calibration(self.phi_T, calib_obs, interventions)
```

### IP-160 PCE⁺（辨识预算耦合）

```python
class IdentificationBudget:
    def __init__(self, interventions=4, info_gain=1.0,
                 identification_risk=0.05, calibration=8):
        self.interventions_left = interventions
        self.info_gain_left = info_gain
        self.identification_risk_left = identification_risk
        self.calibration_left = calibration

    def spend_id(self, info_gain, risk):
        self.interventions_left = max(0, self.interventions_left - 1)
        self.info_gain_left = max(0.0, self.info_gain_left - info_gain)
        self.identification_risk_left = max(0.0, self.identification_risk_left - risk)

    def cost_causal(self, info_req, risk, calib_req, lam=(10.0, 20.0, 5.0)):
        return (lam[0] * max(0.0, info_req - self.info_gain_left)
                + lam[1] * max(0.0, risk - self.identification_risk_left)
                + lam[2] * max(0.0, calib_req - self.calibration_left))

    def voi_causal(self, voi_meta, cost_exec, cost_causal):
        return voi_meta - cost_exec - cost_causal

    def exhausted(self):
        return (self.interventions_left <= 0 or self.info_gain_left <= 0
                or self.identification_risk_left <= 0)
```
