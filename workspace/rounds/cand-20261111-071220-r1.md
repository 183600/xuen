# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「迭代验证」×「快速原型」）

> 第 54 轮把技能组合升级为动作-鲁棒性联合证书 J，但体系重心已从“能否组合”偏向“证书是否可信”：J 依赖 A26（剖面完备）、A27（γ_ce Lipschitz）、A28（Explain 实时收敛）三条强假设，而这些假设本身从未被独立检验。本轮不再增加证书维度，而是让证书 **可执行、可证伪、可在迭代中收敛**。核心矛盾：**H22：证书生成与证书验证同源（同一套仿真、同一组假设），验证退化为自证；H23：快速原型与形式保证之间存在保真度落差，快则失真、真则昂贵。**

## 0. 直觉与动机

**灵感 1（证书可执行化：把 J 编译成最小证伪器）**
直觉：一份不可执行的证书等于一条备注。`J=(ρ,A_cert,γ_ce,δ_a,evidence)` 的每个字段都应翻译成至少一个“如果它错了就必然报警”的测试：`ρ` 对应维度扰动测试，`A_cert` 对应 `A_core` 边界内外的动作点，`γ_ce` 对应非单调/极限动作点，`evidence` 对应历史反例回放。于是 `compile(J) → H_J=(T_J,O_J,B_J)`，证书从“声明”变成“可运行的证伪程序”。**当无法为某字段构造任何测试时，该字段应被视为“未验证”而非“已证明”。**

**灵感 2（原型保真度阶梯：先廉价证伪，再昂贵证明）**
直觉：快速原型的价值不在“替代真实验证”，而在“以最低成本尽早证伪”。设保真度阶梯 `Λ={ℓ0 契约桩, ℓ1 运动学仿真, ℓ2 物理仿真, ℓ3 边端在环}`，保真度与成本严格单调递增。规则是 **逐级晋升**：低层做大规模快速证伪，只有证伪率降到阈值才允许升层，且不允许无条件跳级。这把“快速原型”与“形式严谨”从对立变成顺序关系：**廉价层负责杀死错误假设，昂贵层负责认证存活的少量候选**。

**灵感 3（反例驱动的迭代验证：边界不是写出来的，是被打出来的）**
直觉：迭代验证的算子不是“重跑”，而是“被反例推动的边界精化”。给定证书 `J_t` 与证伪器 `H_t`，每轮产生反例集 `Cex_t`，精化算子 `J_{t+1}=refine(J_t,Cex_t)` 只做三类收缩：收紧 `δ_a`、抬高 `θ_a`、收缩 `A_core`。这与 CEGIS 同构：**用反例而非直觉逼近可信边界**。收敛判据是连续两轮证伪率 `<ε` 且边界漂移 `<η`。

**灵感 4（验证独立性守卫：防止同源自证）**
直觉：若证书生成器与证伪器共享同一套仿真与假设，测试通过只证明“系统与自己一致”。引入 **验证独立性** `I(H,J) = 1 - |Assump(Gen_J)∩Assump(H_J)| / |Assump(Gen_J)∪Assump(H_J)|`，`I` 低于阈值时验证结果不计入可信度。实现手段：不同实现（解析 vs 数值）、不同团队/配置、变形关系测试（metamorphic）、以及 held-out 长尾反例集。**独立性成本必须计入验证预算，否则快速迭代会系统性滑向自我印证。**

**灵感 5（最小可行预言机：把验证成本压到可承受）**
直觉：全量预言机太贵，导致“验证不起 → 跳过验证”。定义最小可行预言机 `O* = argmin cost(O) s.t. power(O) ≥ 1-ε`，用“边际证伪力/成本”贪心选择。类比变异测试的 kill rate：只保留最能杀死错误证书的少数检查。**MVO 让迭代验证在真实预算内可持续，而不是停在理想流程里。**

**灵感 6（原型漂移雷达：快速原型的隐性债）**
直觉：快速原型会随数据/环境漂移悄悄偏离证书假设（分布漂移、阈值过期）。`PDR` 持续比较原型输出分布与证书签发时的分布 `KS` 距离，超阈即触发重验证，把“一次性绿”变成“持续绿”。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（证书可执行化）**
编译映射 `compile: J → H_J=(T_J,O_J,B_J)`，`T_J` 为测试集、`O_J` 为独立预言机、`B_J` 为预算。**可证伪覆盖** `cov(H_J,J) = |{f∈fields(J): ∃t∈T_J 可证伪 f}| / |fields(J)|`。若 `cov < θ_cov`，则 `J` 标记为 `under_validated`，不得部署。

**定义 122（原型保真度阶梯）**
`Λ=(ℓ0,ℓ1,ℓ2,ℓ3)`，保真度 `f_ℓ` 与成本 `c_ℓ` 严格单调递增。晋升谓词：
```
promote(ℓ_k→ℓ_{k+1}) ⇔ φ_k ≤ ε_k ∧ I_k ≥ θ_ind ∧ gap(ℓ_k,ℓ_{k+1}) ≤ Δf
```
不允许跳级；若必须跳级，需提交 **跨层落差证书** `G_gap` 并满足 `f_{ℓ_{k+2}}-f_{ℓ_k} ≤ Δf_skip`。

**定义 123（迭代验证算子）**
`IVL: (J_t,H_t,B_t) → (J_{t+1},H_{t+1},B_{t+1})`，单轮：
```
Cex_t = H_t.run()
if Cex_t ≠ ∅:      J_{t+1} = refine(J_t, Cex_t)   # 收紧 δ_a / 抬高 θ_a / 收缩 A_core
elif ℓ < ℓ_max:    ℓ ← promote(ℓ)                  # 逐级晋升
else:              accept(J_t)
```
收敛：`φ_t = |Cex_t|/|T_t| < ε` 且 `||∂J_t - ∂J_{t-1}|| < η` 连续两轮。

**定义 124（验证独立性）**
`I(H,J) = 1 - |Assump(Gen_J)∩Assump(H_J)| / |Assump(Gen_J)∪Assump(H_J)|`。仅当 `I ≥ θ_ind` 时，`H_J` 的通过结果才计入 `J` 的可信度；否则记为 `self-consistent`（自洽但未验证）。

**定义 125（证伪率与验证声隙）**
第 `t` 轮证伪率 `φ_t`；迭代停止后 **验证声隙**
```
β_val = Σ_{t=1}^{K} φ_t·w_t + (1-I)·γ_self
```
其中 `w_t` 为轮次权重、`γ_self` 为自证惩罚。`β_val` 进入最终部署界，替代“证书一次通过即视为真”的隐含零声隙假设。

**定义 126（最小可行预言机 MVO）**
`O* = argmin_{O⊆O_all} Σ_{o∈O} c_o s.t. power(O) ≥ 1-ε`，`power(O)=P_{cex~𝒟}[O 捕获 cex]`。若 `power` 可估，贪心近似保证 `(1-1/e)` 近似比；不可估时用变异测试 kill rate 作代理。

## 2. 关键算法 伪代码

### IP-121 CXC（Certificate Executability Compiler）

```python
def compile_certificate(J, theta_cov=0.95):
    T = []
    for d, rho_d in J.rho.items():
        T += robustness_tests(dim=d, bound=rho_d, gen=mutate_dim(d))
    T += action_tests(J.A_cert)          # A_core 边界内/外/边界点
    T += mapping_tests(J.gamma_ce, J.delta_a)  # 非单调点、极限动作
    T += replay_tests(J.evidence)        # 历史反例回放
    O = IndependentOracle(shared=set())  # 不复用证书生成器的代码路径
    cov = falsifiable_coverage(T, J)
    if cov < theta_cov:
        return Harness(T, O, status='under_validated', cov=cov)
    return Harness(T, O, status='executable', cov=cov)
```

### IP-122 FLL（Fidelity Ladder Ladder）

```python
def step_ladder(level, H, eps, theta_ind, delta_f):
    res = H.run()
    phi = len(res.counterexamples) / max(1, res.total)
    ind = independence(H, generator=certificate_generator)
    if ind < theta_ind:
        return ('reject', 'self_consistent', ind)
    if phi > eps:
        return ('stay', res.counterexamples, phi)
    if level == MAX_LEVEL:
        return ('accept', None, phi)
    if fidelity(level + 1) - fidelity(level) > delta_f:
        return ('require_gap_cert', level + 1)
    return ('promote', level + 1, phi)
```

### IP-123 IVL（Iterative Validation Loop）

```python
def iterative_validate(J, ladder, budget, eps=0.02, eta=0.01, K=8):
    history = []
    for t in range(K):
        H = compile_certificate(J)
        if H.status == 'under_validated':
            return ('reject', 'under_validated', H.cov)
        cex, level = ladder.run(H, budget)
        phi = len(cex) / max(1, H.total)
        history.append((phi, boundary(J)))
        if cex:
            J = refine_certificate(J, cex)       # 只收缩，不扩张
        elif level == MAX_LEVEL:
            if phi < eps and boundary_drift(history[-2:]) < eta:
                return ('valid', J, t, beta_val(history, independence=H.ind))
        else:
            level = promote(level)
    return ('budget_exhausted', J, K)
```

### IP-124 VIN（Validation Independence Guard）

```python
def independence(H, generator):
    a_gen = generator.assumption_set()
    a_h = H.assumption_set()
    if not (a_gen | a_h):
        return 1.0
    return 1 - len(a_gen & a_h) / len(a_gen | a_h)

def accept_evidence(H, generator, theta_ind=0.5):
    ind = independence(H, generator)
    return ('counted' if ind >= theta_ind else 'self_consistent', ind)
```

### IP-125 MVO（Minimum Viable Oracle）

```python
def minimal_viable_oracle(oracles, target_power, budget):
    chosen, spent = set(), 0
    power = 0.0
    while power < target_power:
        cand = [(marginal_power(o, chosen) / o.cost, o) for o in oracles - chosen]
        if not cand:
            break
        _, o = max(cand, key=lambda x: x[0])
        if spent + o.cost > budget:
            break
        chosen.add(o)
        spent += o.cost
        power = estimate_power(chosen)
    return chosen, power, spent
```

### IP-126 PDR（Prototype Drift Radar）

```python
def drift_radar(proto, cert, stream, theta_drift):
    for batch in stream:
        d = ks_distance(proto.dist(batch), cert.issue_dist)
        if d > theta_drift:
            return ('drift', batch, d, trigger_revalidate=True)
    return ('stable', None, 0.0)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CXC | O(|fields(J)|·|𝒟_test|) | O(|T_J|) | 每字段可证伪、预言机独立 |
| FLL | O(Σ_ℓ |T_ℓ|) | O(1) | 保真度单调、不跳级 |
| IVL | O(K·(|T|·|Cex|)) | O(K·|Cex|) | 精化单调收缩、收敛可判 |
| VIN | O(|Assump|) | O(|Assump|) | 假设集可枚举、来源可追溯 |
| MVO | O(|O_all|²·|𝒟|) | O(|O_all|) | power 可估、贪心近似 |
| PDR | O(|stream|·|batch|) | O(|batch|) | 分布可比、阈值可校准 |

**正确性定理（Iteratively-Validated Certificate Soundness）**
设第 54 轮 (A26)–(A28) 成立；新增 **(A29)** `H_J` 与 `Gen_J` 独立，`I ≥ θ_ind`；**(A30)** 保真度阶梯逐级晋升且 `gap(ℓ_k,ℓ_{k+1}) ≤ Δf`；**(A31)** IVL 在 `K` 轮内收敛，`φ_t < ε`。则真实部署失败概率满足：
```
P_fail ≤ ε + β_val + Σ_{k=0}^{ℓ_max-1} Δf_k + P(budget_exhausted)
```
含义：**证书的可信度不是一次证明得到的，而是独立证伪 × 保真度阶梯 × 迭代收敛共同界的残差**；任一因子缺失，`β_val` 都会显式上升而不是被隐藏。

## 4. 实验设计 E162–E167

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 证书编译覆盖 | `cov(H_J,J)`、编译耗时 | ≥ 95%，≤ 30s/证书 |
| E163 迭代验证收敛 | 收敛轮数 `K`、证伪率曲线 | K ≤ 5，末轮 φ < 0.02 |
| E164 验证独立性效应 | `I` vs 真实失败率 | 低独立（I<0.3）组失败率显著更高，用于验证 VIN 必要性 |
| E165 保真度阶梯 vs 跳级 | 逐级晋升 vs 跳级真实失败率 | 逐级失败率降低 ≥ 30% |
| E166 MVO 成本-证伪力 | 成本 vs `power(O)` 帕累托 | 达 90% power 时成本 ≤ 40% 全量 |
| E167 漂移雷达提前量 | 漂移触发到真实失效的提前时间 | 中位数 ≥ 3 个批次 |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 验证独立性不足（同源自证） | 高 | 独立实现 + 变形测试 + 第三方 held-out 长尾集 |
| 原型保真度落差导致虚假通过 | 高 | 强制逐级晋升 + `Δf` 落差证书 + 保守 `ρ_min` |
| 迭代不收敛 / 验证预算爆炸 | 中 | 反例去重 + 优先级采样 + 早停与降级策略 |
| MVO 漏检长尾反例 | 高 | 保留 tail oracles + 周期性全量复核 |
| 原型分布漂移使旧证书过期 | 中 | PDR 持续监控 + 漂移触发重验证 |

## 6. 本轮最大风险

**一句话**：迭代验证与快速原型最大的风险不是“测得慢”，而是 **验证过拟合**——当证书生成器与快速原型共享假设、且每轮只用同一分布的反例做收缩时，系统会迅速收敛到一个“处处自洽、局部全绿、全局全错”的证书；因此必须把 **验证独立性 I 作为硬门槛（而非事后指标）、把保真度阶梯设为不可跳级、并保留永不参与迭代的 held-out 长尾反例集**，否则越快的迭代只会越快地把错误固化成“已验证”的假象。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++ / ProtoCert-Loop（CXC×FLL×IVL×VIN×MVO×PDR）

> 承接第 54 轮产物 v31。本轮不新增“证书维度”，而是新增 **证书的验证生命周期**：把联合证书 J 编译成可执行证伪器，在保真度阶梯上迭代证伪，并用独立性守卫与最小预言机控制验证成本。
> - **CXC（Certificate Executability Compiler）**：`compile(J) → H_J`，证书可执行化与可证伪覆盖检查；
> - **FLL（Fidelity Ladder Ladder）**：契约桩 → 运动学 → 物理 → 边端在环的逐级晋升；
> - **IVL（Iterative Validation Loop）**：反例驱动的证书边界精化（CEGIS 式）；
> - **VIN（Validation Independence Guard）**：验证独立性 `I` 硬门槛，阻断同源自证；
> - **MVO（Minimum Viable Oracle）**：成本约束下最大化证伪力的最小预言机；
> - **PDR（Prototype Drift Radar）**：原型分布漂移监控，触发证书重验证。
>
> IP 编号：IP-121~IP-126（共 6 个新增）；升级 IP-115/116/118/120 以接入验证生命周期。

```python
    if not (a_gen | a_h):
        return 1.0
    return 1 - len(a_gen & a_h) / len(a_gen | a_h)

def accept_evidence(H, generator, theta_ind=0.5):
    ind = independence(H, generator)
    return ('counted' if ind >= theta_ind else 'self_consistent', ind)
```

### IP-125 MVO

```python
def minimal_viable_oracle(oracles, target_power, budget):
    chosen, spent, power = set(), 0, 0.0
    while power < target_power:
        cand = [(marginal_power(o, chosen) / o.cost, o) for o in oracles - chosen]
        if not cand:
            break
        _, o = max(cand, key=lambda x: x[0])
        if spent + o.cost > budget:
            break
        chosen.add(o); spent += o.cost
        power = estimate_power(chosen)
    return chosen, power, spent
```

### IP-126 PDR

```python
def drift_radar(proto, cert, stream, theta_drift):
    for batch in stream:
        d = ks_distance(proto.dist(batch), cert.issue_dist)
        if d > theta_drift:
            return ('drift', batch, d, trigger_revalidate=True)
    return ('stable', None, 0.0)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CXC | O(|fields(J)|·|𝒟_test|) | O(|T_J|) | 每字段可证伪，预言机独立 |
| FLL | O(Σ_ℓ |T_ℓ|) | O(1) | 保真度单调，不跳级 |
| IVL | O(K·|T|·|Cex|) | O(K·|Cex|) | 精化单调收缩，收敛可判 |
| VIN | O(|Assump|) | O(|Assump|) | 假设来源可追溯，硬门槛 |
| MVO | O(|O_all|²·|𝒟|) | O(|O_all|) | power 可估，贪心 (1-1/e) 近似 |
| PDR | O(|stream|·|batch|) | O(|batch|) | 分布可比，阈值可校准 |

**正确性定理（Iteratively-Validated Certificate Soundness）**
设第 54 轮 (A26)–(A28) 成立；新增 **(A29)** `I(H_J,Gen_J) ≥ θ_ind`；**(A30)** 保真度阶梯逐级晋升且 `gap(ℓ_k,ℓ_{k+1}) ≤ Δf`；**(A31)** IVL 在 `K` 轮内收敛且 `φ_t < ε`。则：
```
P_fail ≤ ε + β_val + Σ_{k=0}^{ℓ_max-1} Δf_k + P(budget_exhausted)
```
关键：**可信度是残差而非承诺**——独立性差、跳级、或未收敛，都会显式抬高 `β_val`，而不是被“测试通过”掩盖。

## 6. 本轮最大风险

**一句话**：迭代验证与快速原型最大的风险不是“测得慢”，而是 **验证过拟合**——当证书生成器与快速原型共享假设、且每轮只用同一分布的反例做收缩时，系统会迅速收敛到一个“处处自洽、局部全绿、全局全错”的证书；故须以 **验证独立性 I 作为硬门槛、保真度阶梯不可跳级、held-out 长尾集永不参与迭代** 三重护栏，否则越快的迭代只会越快地把错误固化成“已验证”的假象。
