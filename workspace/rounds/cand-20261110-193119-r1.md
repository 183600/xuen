# 第 47 轮（承接第 46 轮产物 v23；本轮灵感：Gazebo × 抓取位姿估计） · Sim-Real Grasp-Cert：物理仿真证伪与仿真-现实证书迁移下的模式感知抓取姿态保证（五层架构 v11）

> 承接第 46 轮产物 v23。v23 把姿态证书、能量租约、记忆检索、语音-安全绑定串成全局决策 Π，但仍在两个隐含假设下运行：**H5a「姿态证书对应单一姿态模，且真值标签在 SE(3) 中唯一」**；**H5b「证书只需在实机上用历史数据校准，无需物理级真值，也无需系统化反例生成」**。**抓取位姿估计**精确击中 H5a：物体对称性（圆柱 SO(2)、长方体 24 重对称）使"正确抓取姿态"本质是等价类/多峰集合，若仍用单点盒证书，估计器选到等价但标签不同的模就会静默失配；接触物理（摩擦锥、力闭合、滑移）又使几何邻近不等于抓取成功。**Gazebo** 击中 H5b：它提供物理级真值与可无限并行的反例工厂，能主动搜索证书失效场景；但它同时引入新的 sim-to-real gap，使"仿真里通过"变成一种可能被**证书洗白（certificate laundering）**的假保证。三者耦合出新问题：**如何用仿真证伪加固抓取姿态证书，并把加固后的证书以带缺口界与租约期限的方式迁移到实机；若缺口被低估、对称模被漏覆盖，抓取会在接触层静默失败，仿真越"绿"实机越可能"红"**。

## 0. 直觉与动机

**灵感 1（Gazebo → 反例工厂 + 物理真值 + 新的不信任源）**
直觉：仿真的价值不在于"证明对"，而在于"高效地找出错"。把 Gazebo 建模为证伪 oracle `S: Ξ→O`，场景 `ξ=(物体网格, 位姿, 材质/透明高光, 摩擦, 质量, 光照, 传感器噪声)`。给定当前证书 `C`，证伪搜索最大化违约指示 `V(C,ξ)`：真值等价类逃出证书，或"标注成功"却在物理上滑移/碰撞。但仿真与现实的物理/视觉分布不同，必须把 gap 显式建模进证书；否则仿真覆盖率越高，实机越可能静默违例。→ **SFL + 缺口感知**。

**灵感 2（抓取位姿估计 → 模式感知集合证书 + 物理可行性证书）**
直觉：抓取位姿不是点，而是"对称群商空间上的模集合"。对旋转对称物体，`q` 与 `gq` 物理等价；对多面体，是离散等价类。于是证书应是 `{(q_k,P_k,w_k)}`，保证真值等价类落入其并集，而不是某个单点盒。同时，几何位姿正确 ≠ 抓取成功：需要力闭合裕度/滑移概率作为第二重物理证书，由仿真大规模标注、实机少量校准。两重证书不可互相替代。

**灵感 3（耦合 → 仿真-现实双证书与可过期许可证）**
直觉：仿真给出"宽"的物理证据（海量、有真值、但分布偏），实机给出"窄"的统计证据（真实、但样本少）。两者不能简单相加，必须用分布差异上界把仿真证书"通胀"后迁移，并赋予一个随上下文（尤其透明/高光/弱纹理退化层 `Ω_deg`）变化的缺口界与过期时间。若实机漂移监测发现 gap 变大，许可证过期 → 级联 fail-closed 或退化为保守抓取。

**耦合升级**：在 v10 根信任 + L1–L4 上新增 **L5 仿真证伪层（Simulation Twin Plane）**，并把 L1 几何层从"姿态证书"扩展为"姿态证书 → 抓取模式证书 → 物理可行性证书"三级下游。根信任层新增 **sim-to-real 许可证 `ℓ_s`**，与姿态租约 `ℓ_p`、能量租约 `ℓ_e` 并列。五层 v11：根信任（`ℓ_p,ℓ_e,ℓ_s`）+ L1 几何/抓取 + L2 上下文/gap 预测 + L3 CAR/抓取安全绑定 + L4 DCL/仿真数据护照 + L5 SFL/S2R 迁移。

## 1. 形式化定义（增量：定义 59–64）

**定义 59（对称商空间与模式感知抓取姿态证书 GMC）**
设物体对称群 `G ≤ SE(3)` 作用在抓取位姿空间 `Q` 上，商空间 `Q/G`。观测 `o_t` 下估计器输出候选抓取。模式证书
`C_t^g = {(q_k, P_k, w_k)}_{k=1}^K`，其中 `q_k∈Q`，`P_k⊆Q` 为商度量 `d_G(q,q')=min_{g∈G}‖q−gq'‖` 下的球，`Σ_k w_k=1`。
**模式覆盖 soundness**：`P( [q_true]_G ∈ ∪_{k=1}^K P_k | o_t ) ≥ 1−α_g`。
**模紧致性**：`diam_G(P_k) ≤ D_max`，防止用巨大球把并集凑满。

**定义 60（抓取物理可行性证书）**
对抓取 `q` 与物体/夹爪，定义力闭合裕度 `m_fc(q)`（接触力旋量到摩擦锥边界的最小缩放）与滑移指示 `slip(q)`。物理证书
`Phys_k = P( success(q) ∧ m_fc(q)≥γ | q∈P_k, ξ ) ≥ 1−β`。
**几何-物理分离**：抓取成功需同时满足 `∃k: [q_true]_G∈P_k` 与 `Phys_k`，二者不可互相替代。

**定义 61（Gazebo 证伪 oracle 与场景覆盖）**
仿真器 `S: Ξ→O`。场景 `ξ=(mesh, pose, material, friction, mass, light, noise)`。违约指示
`V(C,ξ)=1[ [q_true]_G ∉ ∪P_k ∨ (labeled_success ∧ S(ξ)=slip/collision) ]`。
预算 `N` 下证伪搜索产生反例集合 `F_N`，经验违约率 `v̂=|F_N|/N`，其上界 `v̄` 由 Clopper–Pearson 给出。
**场景覆盖**：按 `(Ω_deg 层 × 对称类型 × 材质 × 摩擦档)` 离散为网格 `X`，要求每个格子至少采样 `n_min` 次；否则保证只在"被搜过的分布"上成立。

**定义 62（仿真-现实缺口与迁移证书）**
设同一上下文 `c` 下仿真/实机结果分布为 `P_s(·|c), P_r(·|c)`。缺口 `d(c)=TV(P_s,P_r)`，用域分类器在独立审计集上估计上界 `ε(c)`（含有限样本置信）。
迁移证书：每模 `r_real = r_sim + L_r·ε(c) + b_phys`，`L_r` 为覆盖率对半径的 Lipschitz 常数，`b_phys` 为物理模型误差项。
**sim-to-real 许可证** `ℓ_s=(c, ε(c), t0, T_s, drift_stat)`。许可证有效 ⇒ 迁移 soundness
`P(real coverage) ≥ 1−α_g−ε(c)−δ_est`；过期或 drift 超阈 ⇒ 级联失效。

**定义 63（联合抓取安全谓词）**
`S_safe(t) = [X_t∈P_t] ∧ [∃k: [q_true]_G∈P_k] ∧ [Phys_k] ∧ [E(t)≥E_min] ∧ [ℓ_s 有效]`。
任一子项为假 ⇒ CAR fail-closed；不得以"其他项很强"补偿。

**定义 64（证伪驱动的主动场景调度）**
预算 `N` 下选择场景序列 `{ξ_i}`：
`ξ_{i+1} = argmax_{ξ∈Ξ} [ λ_v·V(C,ξ) + λ_c·1[cell(ξ) 未达覆盖] − λ_cost·cost(ξ) ]`。
即对抗梯度搜索与覆盖导向采样的混合，目标是最大化反例产出同时保证场景网格覆盖，避免只搜到"仿真容易崩"的偏斜子空间。

## 2. 新增产出与既有 IP 升级

**IP-69 GMC（Grasp Mode Certificate）**
- 对称群检测：物体类别先验 + 点云/网格对称性检验，输出 `G` 及置信
- 商空间聚类：quotient k-means 得到抓取模 `q_k` 与权重 `w_k`
- 分域共形校准：sim/real 各自校准半径，取保守包络后再做 gap 通胀
- 模覆盖审计：独立审计集检查并集覆盖率与模紧致性

**IP-70 SFL（Simulation Falsification Loop）**
- Gazebo 场景生成器：物体资产、材质（透明/高光 = `Ω_deg`）、摩擦/质量域随机化
- 双模搜索：对抗梯度 + 覆盖导向采样（定义 64）
- 反例护照：记录 `ξ`、违约类型、复现种子、仿真版本
- 统计证书：Clopper–Pearson 上界 + 场景网格覆盖报告
- 反例回灌 DCL/CCA

**IP-71 S2R-CT（Sim2Real Certificate Transfer）**
- 上下文条件缺口估计：按 `c`（含 `Ω_deg` 层）训练域分类器，估计 `ε(c)`
- 证书通胀与许可证签发：`ℓ_s` 带 `T_s` 过期与 drift 监测
- 漂移监测：在线比较实机残差/抓取成功率与仿真预测，超阈吊销许可证
- 保守回退：许可证失效时切到"实机-only 校准 + 缩小抓取集合 + 力控柔顺"

**既有 IP 升级**
IP-60 PSE：姿态证书 `P_t` 作为抓取候选生成的上游，抓取层继承不确定性并二次传播
IP-63 ECPS：查询 `ℓ_s` 状态；许可证临近过期时提前请求实机校准或保守抓取
IP-61 DCL：仿真数据带 sim 护照，实机校准按缺口加权；采集任务包含"证伪反例复现"
IP-62 CCA：新增 Gazebo 红队、对称模漏覆盖测试、证书洗白（sim-only 通过）检测
IP-51 CAR：守卫扩展为 `S_safe`（定义 63），许可证明细进入 fail-closed 级联
IP-45 总线：新增 sim-scenario / grasp-cert / sim2real-gap / license 话题

## 3. 算法骨架

每控制周期：
1. 采观测 `o_t`、上下文 `c_t`、`B_t`、`ℓ_e`、`ℓ_p`
2. PSE 签发姿态证书 `P_t`
3. GMC 在对称商空间输出 `{(q_k,P_k,w_k)}`（对称性不确定则直接 fail-closed）
4. SFL 用当前证书 + 最近反例库做在线小预算快速证伪（离线大预算后台）
5. S2R-CT 估 `ε(c_t)`、通胀半径、检查并更新 `ℓ_s`
6. 用仿真 + 实机成功率下界过滤 `Phys_k` 不达标的模
7. 选最小期望代价模；SAB 绑定不通过则入安全队列；`S_safe` 不满足则 fail-closed
8. 反例与成功/失败写入 DCL，更新场景覆盖与许可证

## 4. 本轮最大风险

**一句话**：sim-to-real 缺口 `ε(c)` 最容易恰好在 `Ω_deg` 退化层（透明/高光/遮挡）被低估，使仿真证书只做轻微通胀就"全绿"，而实机的对称抓取模仍落在迁移集合之外或物理稳定性静默失效——这是一种"仿真制造虚假信心"的证书洗白；因此必须用独立实机审计集给 `ε(c)` 保守上界、按 `Ω_deg` 分层估计缺口，并对任何许可证明细存疑的情况直接 fail-closed。

### IP-69 GMC

```
def detect_symmetry(obj):
    G_cls = class_symmetry_prior(obj.label)        # SO(2)/D2/D4/...
    G_geo = mesh_symmetry_test(obj.mesh, tol=1e-3) # 网格几何验证
    G = consistent_or_none(G_cls, G_geo)
    return G                                       # None => 对称性不确定

def dG(q1, q2, G):
    return min(norm(q1 - g_apply(g, q2)) for g in G_samples(G))

def quotient_kmeans(Q, G, K, iters=30):
    centers = quotient_fps(Q, G, K)
    for _ in range(iters):
        assign = [argmin_k(dG(q, centers[k], G)) for q in Q]
        centers = [quotient_mean([Q[i] for i in range(len(Q))
                                  if assign[i] == k], G) for k in range(K)]
    w = normalize(counts(assign))
    return centers, w

def gmc_certify(obs, G, sim_calib, real_calib, alpha_g, D_max, K_max=8):
    Q = collision_free_grasps(obs)
    centers, w = quotient_kmeans(Q, G, K=min(K_max, len(Q)))
    cert = []
    for k, qk in enumerate(centers):
        r_s = conformal_quantile(sim_calib,  qk, level=1 - alpha_g/2)
        r_r = conformal_quantile(real_calib, qk, level=1 - alpha_g/2)
        r = min(D_max, max(r_s, r_r))              # 两域保守包络
        cert.append((qk, Ball(qk, r), w[k]))
    return cert
```

### IP-70 SFL

```
def falsify(cert_fn, Xi_grid, budget, p_adv=0.6, n_min=30, conf=0.95):
    F, cover = [], defaultdict(int)
    for i in range(budget):
        if rand() < p_adv:
            xi = adversarial_step(Xi_grid, cert_fn)      # 最大化 V(C,ξ)
        else:
            xi = coverage_sample(Xi_grid, cover, n_min)  # 补未覆盖格子
        out = gazebo_rollout(xi)
        cover[cell(xi)] += 1
        if violation(cert_fn(xi), xi, out):
            F.append(Passport(xi, out, seed=xi.seed, sim_ver=SIM_VER))
    v_hat = len(F) / budget
    v_upper = clopper_pearson_upper(len(F), budget, conf)
    uncovered = [c for c in Xi_grid if cover[c] < n_min]
    return F, v_upper, uncovered
```

### IP-71 S2R-CT

```
def domain_gap_upper(real_audit, sim_audit, c, alpha):
    clf = train_domain_clf(real_audit[c], sim_audit[c])
    auc = heldout_auc(clf)
    tv = max(0.0, 2 * auc - 1)                       # 保守代理
    eps = tv + finite_sample_margin(len(real_audit[c]), alpha)
    return min(1.0, eps)

def transfer(C_sim, c, eps, L_r, b_phys, now, T_s, D_max):
    C = [(q, Ball(q, min(D_max, P.r + L_r * eps + b_phys)), w)
         for (q, P, w) in C_sim]
    lic = License(context=c, eps=eps, t0=now, T=T_s, drift=0.0, valid=True)
    return C, lic

def monitor_license(lic, real_outcomes, sim_pred, eps_crit):
    lic.drift = ewma(abs(real_outcomes - sim_pred))
    if now - lic.t0 > lic.T or lic.drift > eps_crit:
        lic.valid = False
    return lic
```

```
def sim_real_grasp_decision(obs, c_t, B_t, v_t, calib):
    P_t = pse_certify(obs, c_t)
    G = detect_symmetry(obs)
    if G is None:
        return 'fail-closed', 'symmetry-unknown'
    C_sim = gmc_certify(obs, G, sim_calib, real_calib, alpha_g, D_max)
    eps = domain_gap_upper(real_audit, sim_audit, c_t, alpha)
    C, lic = transfer(C_sim, c_t, eps, L_r, b_phys, now, T_s, D_max)
    if not lic.valid or E(t) < E_min or B_t < B_min:
        return 'fail-closed', 'license-or-energy'
    feasible = [m for m in C if phys_lcb(m.q, c_t) >= 1 - beta]
    if not feasible:
        return 'fail-closed', 'no-feasible-mode'
    q = min(feasible, key=lambda m: expected_cost(m, B_t))
    if safety_bind(v_t, q, omega_t) < theta_safe:
        return 'queue', q
    return 'execute', q, lic
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| GMC 商空间聚类 | `O(K·|Q|·|G|·iters)` | `O(|Q|)` | 模式覆盖率 ≥ `1−α_g`，且 `diam_G(P_k)≤D_max` |
| SFL 证伪 | `O(N·T_sim)` 离线可并行；在线 `O(n_on·T_sim)` | `O(N)` 反例 | 场景覆盖达标时，违约率上界 `v̄`（置信 `1−δ`） |
| S2R-CT 缺口/迁移 | `O(n_audit·d)` | `O(K)` | `ε(c)` 覆盖真实 gap（置信 `1−α`）时迁移 soundness 成立 |
| 全局决策 | `O(K+|M|)` | `O(K+|Q|)` | 任一子证书/许可证明细失效即 fail-closed |

**正确性定理（复合 soundness）**：在（i）对称群 `G` 检测正确；（ii）各域内共形可交换性成立；（iii）`ε(c)` 以概率 `1−α` 覆盖真实 `TV(P_s,P_r)`；（iv）`Phys_k` 的仿真-实机物理缺口有界；（v）场景网格覆盖达标 的条件下，联合抓取安全谓词 `S_safe` 的失败概率满足
`P(¬S_safe) ≤ α_p + α_g + ε(c) + δ_est + β + v̄`。
任一条件失效或许可证过期时，决策退化为 fail-closed（失败概率视为 0，代价是任务可用性下降）。反之，仅"仿真通过"不能推出实机 soundness——这正是证书洗白的入口。

## 4. 实验设计 E115–E120

| 实验 | 指标 | 门槛 |
|---|---|---|
| E115 模式证书覆盖 | 模式覆盖率、模数量、模直径 | 覆盖率 ≥ 95%（`α_g=0.05`）；模数 ≤ 5；`diam≤D_max` |
| E116 证伪反例与覆盖 | 每万场景反例数、网格覆盖率、新失效模式 | 反例 ≥ 20/1e4；覆盖 ≥ 95% 格子；发现 ≥ 3 类新 `Ω_deg` 失效 |
| E117 缺口估计与迁移 | `ε` 覆盖真实 gap 的比例、迁移后实机覆盖率 | `ε` 覆盖 ≥ 95%；迁移覆盖率 ≥ `1−α−2%` |
| E118 抓取成功迁移 | 仿真 vs 实机成功率相关性 | 相关系数 ≥ 0.8；成功率跌幅 ≤ 10% |
| E119 对称/退化分层 | 各 `Ω_deg` 层覆盖率、对称类型分层 | 透明/高光层与整体相差 ≤ 3% |
| E120 100h 闭环 | 实机抓取成功率、安全违例、drift 告警 | 成功率 ≥ 92%；安全违例 0；告警 ≤ 2 次/周 |

**回退策略**：E115 覆盖率 < 90% → 增大 `K`/`D_max` 或引入多假设对称群；E117 gap 低估 > 5% → `ε` 加保守常数、降低仿真权重；E118 成功率跌幅 > 15% → 仿真仅用于反例生成，校准全部用实机；E120 drift 告警过频 → 缩短 `T_s` 并加密实机审计。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| sim-to-real gap 被低估（证书洗白） | 高 | 域分类器上界 + 独立实机审计 + 保守 `ε` + 许可证过期 |
| 对称群误检导致漏覆盖 | 高 | 几何对称性检验；冲突或多假设时 fail-closed / 多群并行 |
| 抓取模集合爆炸 | 中 | 限制 `K`、按期望代价合并模、`D_max` 约束 |
| 仿真资产/材质偏斜（透明/高光） | 高 | `Ω_deg` 分层 gap、域随机化、实机分层校准 |
| 证伪过拟合仿真 bug | 中 | 固定仿真版本、可复现种子、跨仿真器抽检 |
| sim/real 校准数据泄漏 | 高 | 严格数据护照隔离、独立 held-out 审计集 |

## 6. 本轮最大风险

**一句话**：最大的风险是 `ε(c)` 在 `Ω_deg` 退化层（透明/高光/遮挡）上恰好低估真实 sim-to-real 缺口，使仿真证书只做轻微通胀便"全绿"，而实机的对称抓取模仍逃出迁移集合或物理稳定性静默失效——这是仿真制造虚假信心的证书洗白；因此必须以独立实机审计给 `ε(c)` 保守上界、按 `Ω_deg` 分层估计，并对任何许可证明细存疑直接 fail-closed。
