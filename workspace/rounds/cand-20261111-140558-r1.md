# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「人机协作」×「检索增强生成」）

> 第 54 轮把技能组合落到动作空间剖面 α_S、组合图 G_S 与云边联合证书 J。但它留下三个未被回答的问题：**证书从哪来、证书何时失效、谁有权为证书签字？** 本轮引入两个外来机制：用 RAG 组织「证据」而非「文本」，用 HRI 把「人」变成可门控、可校准、可追责的证据源。核心矛盾：H22：检索相似 ≠ 当前动作空间可用，RAG 的「相关性」极易伪装成「有效性」；H23：人的确认可能只是对检索结果的回声，人机共识可能只是共同偏差。

## 0. 直觉与动机

**灵感 1（检索的是证据，不是文本 → 从 RAG 到 RAV）**
直觉：技能库里最贵的资产不是技能参数，而是**失败证据**。一次边端反例 `(a_region, root_cause)` 比一百条成功日志更能约束规划。因此 RAG 的索引单元应是 **证书 / 反例 / 人类证词**，而不是自然语言片段。新任务到来时，先检索相似动作区间的证据作为先验，再**强制在当前 α_S 上重新验证**。生成器只允许产出候选路径，结论必须由验证算子 `V` 给出。这把 RAG 从「检索增强生成」改写为 **「检索增强验证」（Retrieval-Augmented Verification, RAV）**：`s_R`（相关）与 `s_V`（有效）必须分离，二者同时过阈值才算 grounded。

**灵感 2（人是带约束的噪声 oracle，不是遥控器）**
直觉：第 54 轮的最大风险是动作剖面欠采样。让人类专家在**低置信动作区间**上做判读，是直接缓解。但人不是真值：他有延迟 ℓ_h、历史可靠度 r_h、以及**权限范围 Ω_h**（只对自己训练过的动作子空间有资格签字）。于是人是 `Oracle_h(region) → (verdict, conf)`，且必须被**不确定性门控**：只在 `U(A_T) > θ_u` 时查询，并受查询预算 B_h 约束。这把「人机协作」从交互设计问题变成**证据获取的主动学习问题**。

**灵感 3（共识幻觉 → 反例优先与盲查询）**
直觉：RAG 最隐蔽的失败是「检索到的都支持我」，人类最隐蔽的失败是「机器说可以，我也说可以」。两者叠加会产生**自证循环**：相似度高的证据被检索出来 → 人类看到后倾向于确认 → 确认又被写回索引 → 下次检索更相似。破解只能靠制度而非模型：**反例优先检索**（负证据权重更高、命中即否决）、**独立盲查询**（不把检索结论展示给人类）、以及 **provenance 隔离**（人类证词不得作为自身再次被检索的佐证）。

**灵感 4（证据有时效与版本身份 → 污染半径）**
直觉：一条证书是绑定在 `(embodiment, skill_version, action_region, time)` 上的，换了机器人或升级了技能，证书不是「参考」而是「噪声」。证据必须**版本化 + TTL + 矛盾图**：新反例与旧证书矛盾时，按依赖边递归失效（quarantine），并计算**污染半径** `rad(e) = {p | p 依赖 e}`。这让「检索」具备可审计的失效语义，而不是永远相信索引。

**灵感 5（共享检索本体与证据金字塔）**
直觉：人类说的是粗语义（「把杯子递过来」），机器人动作剖面是细粒度 `(a_c,a_e)`。若检索的 key 只存在于机器人侧，人类证词就无法对齐。需要**共享检索本体 O_shared**：同一动作区间在人机两侧有共同标识。并在第 54 轮动作-鲁棒性金字塔上再加一层 **证据层 𝔼**：`𝔼_0` 原始 episode → `𝔼_1` 证书/反例 → `𝔼_2` 人类证词 → `𝔼_3` 可检索索引。跨层传递必须携带 provenance 链 Π，否则证据不可回溯、不可隔离。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（证据项与证书登记册）**
证据项 `e = (type, payload, meta)`，其中 `type ∈ {cert, counterexample, attestation}`：
- `cert`：第 53–54 轮的 `C_comp / J / TRC_Joint`；
- `counterexample`：边端反例 `(a_region, root_cause, sim_id)`；
- `attestation`：人类证词 `(h_id, a_region, verdict, conf)`。

`meta = (embodiment_id, skill_ver, a_region, t_e, provenance, ttl)`。登记册 `ℛ = {e}`。检索 `retrieve(q, k, F) = TopK_{s_R(e,q)} {e ∈ ℛ | F(e)}`，`F` 至少过滤版本身份、TTL 与 quarantine 状态。

**定义 122（检索增强验证 RAV）**
候选生成器 `G_ℓ` 依据检索集 `E_k = retrieve(q_T, k, F)` 产生候选组合路径集 `P_cand`。验证算子
```
V(p, E_k, α_current) → {accept, reject, abstain}
```
`accept` 当且仅当同时满足：
```
s_R(e, q_T) ≥ θ_r        (相关)
s_V(e; α_current) ≥ θ_v  (有效性：证据动作区间可在当前剖面上复核)
e ⊢ p                    (证据覆盖 p 的每条边与关键动作)
```
即 **retrieve → re-verify → ground**。只有 `s_R` 过线一律记 `abstain`，绝不允许「相关即接受」。

**定义 123（人类证词与不确定性门控）**
人类 oracle `h`，参数 `(r_h, ℓ_h, Ω_h, B_h)`：可靠度、延迟、可签署动作子空间、查询预算。动作不确定性（归一化基尼不纯度）：
```
U(A_T) = (1/|A_T|) · Σ_{a∈A_T} 4·α_S(a)·(1-α_S(a)) ∈ [0,1]
```
门控查询策略 `π_q`：当 `U(A_T) > θ_u` 且 `region ⊆ Ω_h` 且预算未耗尽时，向 h 发起 `query(region)`，返回证词 `Att = (region, verdict∈{feasible,infeasible,unknown}, conf, h_id)`。

**定义 124（人机证书共签）**
共签证书 `J' = J ⊕ Att`。对有效证词（`conf·r_h ≥ θ_h` 且未过期且 `region ⊆ Ω_h`）定义噪声或融合：
```
feasible:   α̃(a) = 1 - (1 - α(a))·(1 - w)，  w = conf · r_h
infeasible: α̃(a) = 0
unknown:    α̃(a) = α(a)
```
关键性质：`w ≤ r_h < 1`，故人类证词只能**提升下界、不能制造确定性**；它把「未采样」变成「有界证据」，而不是把「未知」变成「已知」。共签后的证书必须记录 `Att` 到 provenance 链，且 `Att` 永不作为自身再次被检索的佐证。

**定义 125（证据污染、时效与矛盾图）**
`valid(e, t) = (t - t_e ≤ ttl_e) ∧ (emb_match(e) = current) ∧ ¬quarantined(e) ∧ ¬∃e' [newer(e',e) ∧ contradict(e,e') ∧ conf(e') ≥ θ_x]`。
矛盾图 `G_×`：边 `(e,e')` 表示同一动作区间上 verdict/ρ 冲突。失效传播 `rad(e) = {p | p 依赖 e}`，quarantine 时沿依赖边递归标记，所有依赖该证据的证书降级为 `abstain`。

**定义 126（人机检索增强协同契约）**
`C_hrag = (P_c, P_e, ℛ, π_q, V, Π)`，`Π` 为 provenance 链。部署当且仅当：
```
V(P_e, E_k, α_current) = accept
∧ U(Ã_T) ≤ θ_u^post                      (检索+人类证词覆盖后残余不确定性)
∧ ¬∃ unexpired counterexample 覆盖 A_core
∧ ∀ att ∈ Π: att 有效 ∧ region ⊆ Ω_h ∧ r_h ≥ θ_r^h
```
即：**检索接地、人类证词有界、反例未被压制、证据可回溯**，四者缺一即拒绝部署。

def register_evidence(episode, model_ver):

### IP-122 RAV（Retrieval-Augmented Verification）

```python
def retrieve_then_verify(task, alpha, registry, k=8):
    E = registry.retrieve(embed_task(task), k,
                          filter=lambda e: valid(e, now()) and not quarantined(e))
    # 反例优先：覆盖候选动作区的有效反例直接否决，不给生成器辩解机会
    ce = [e for e in E if e.type == 'counterexample'
          and covers(e.meta.a_region, task.A_T)]
    if ce:
        return ('reject', ce)

    accepted = []
    for p in generate_candidates(E, task):
        if not evidence_entails(E, p):          # e ⊢ p
            continue
        verdicts = [verify_edge(edge, E, alpha) for edge in p.edges]
        if any(v == 'reject' for v in verdicts):
            continue
        if all(v == 'accept' for v in verdicts):
            accepted.append((p, build_provenance(p, E)))
        else:
            accepted.append((p, ('abstain', residual_uncertainty(p, alpha))))
    return ('ok', accepted)

def verify_edge(edge, E, alpha):
    hits = [e for e in E if e.type == 'cert' and covers(e.meta.a_region, edge.A)]
    if not hits: return 'abstain'
    s_R = max(similarity(e, edge) for e in hits)
    s_V = max(validity(e, alpha) for e in hits)   # 在当前 alpha 上复核，不看历史成功
    if s_R >= theta_r and s_V >= theta_v: return 'accept'
    if s_V < theta_v:                     return 'reject'
    return 'abstain'
```

### IP-123 UGH（Uncertainty-Gated Human Query）

```python
def human_gated_query(plan, alpha, human, theta_u, budget):
    atts, spent = [], 0
    for region in uncertain_regions(plan, alpha, theta_u):   # 按 U 降序
        if spent >= budget: break
        if not region.subset_of(human.Omega): continue       # 权限外不签
        ans = human.ask_blind(region)                        # 不展示检索结论
        spent += 1
        atts.append(Attestation(region, ans.verdict, ans.conf, human.id))
    return atts
```

### IP-124 HCS（Human Co-Signing）

```python
def cosign_certificate(J, atts, human, theta_h):
    alpha_tilde = dict(J.alpha)
    for att in atts:
        w = att.conf * human.r_h
        if w < theta_h or not valid(att, now()): continue
        for a in att.region:
            if att.verdict == 'feasible':
                alpha_tilde[a] = 1 - (1 - alpha_tilde[a]) * (1 - w)
            elif att.verdict == 'infeasible':
                alpha_tilde[a] = 0.0
    return J.with_alpha(alpha_tilde,
                        provenance=J.provenance + [('att', a.id) for a in atts])
```

### IP-125 EPC（Evidence Pollution Control）

```python
def quarantine(e, contradiction_graph):
    stack, seen = [e], set()
    while stack:
        x = stack.pop()
        if x.id in seen: continue
        seen.add(x.id)
        mark_quarantined(x)
        stack += contradiction_graph.dependents(x)   # 沿依赖边传播污染半径
    return seen

def evidence_valid(e, now, current_emb, contradiction_graph, theta_x):
    if now - e.meta.t_e > e.meta.ttl:            return False
    if e.meta.embodiment_id != current_emb:      return False
    if is_quarantined(e):                        return False
    newer = contradiction_graph.newer_than(e, now)
    return not any(c.similarity(e) >= theta_x for c in newer)
```

### IP-126 HRAC（Human-RAG Coordination）

```python
def hrag_coordinate(task, alpha, registry, human, budgets):
    E = registry.retrieve(embed_task(task), budgets.k, filter=valid_now)
    status, cands = retrieve_then_verify(task, alpha, registry, budgets.k)
    if status == 'reject':
        return ('reject', 'counterexample', cands)

    plan = select_min_cost(cands)
    atts = human_gated_query(plan, alpha, human, budgets.theta_u, budgets.B_h)
    J    = joint_certificate(plan, alpha, budgets.delta_a, budgets.rho_min)
    J'   = cosign_certificate(J, atts, human, budgets.theta_h)

    if U(J'.alpha, task.A_T) > budgets.theta_u_post:
        return ('abstain', 'residual_uncertainty')      # 宁可 abstain，不硬签
    return ('ok', J', provenance_chain(J', E, atts))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CER | O(log N) 摊还（索引） | O(N) | meta 完备、版本可追溯 |
| RAV | O(k·\|p\|·\|A\|) | O(k+\|p\|) | `s_R` 与 `s_V` 分离、反例优先 |
| UGH | O(\|A_T\|) + 人类延迟 ℓ_h | O(\|Att\|) | 门控阈值、权限 Ω_h、盲查询 |
| HCS | O(\|Att\|·\|A\|) | O(\|A\|) | `w ≤ r_h < 1`、噪声或单调 |
| EPC | O(\|E\| + \|rad(e)\|) | O(\|E\|) | 依赖图 sound、TTL 硬失效 |
| HRAC | O(检索 + 验证 + 一轮人机往返) | O(\|Π\|) | 四条件合取、abstain 保守 |

**正确性定理（Human-RAG Grounded Composition Soundness）**
假设承接第 54 轮 (A22)–(A28)，并新增：**(A29)** 证据有效性过滤 `F` sound（不会放过过期/异体/被污染证据）；**(A30)** 人类可靠度 `r_h` 经 Beta 后验校准，单次证词错误率上界 `1-r_h`；**(A31)** 反例覆盖检测 sound（覆盖即命中）。则：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a > Θ_a)
            - P(误用失效证据) - P(query)·(1-r_h) - P(U(Ã_T) > θ_u^post)
```
关键：**人类证词只提高下界、不产生确定性**（`w<1`），**检索相似度不构成接受理由**（必须 `s_V` 过线），**任何未过期反例直接否决**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 检索相似被误当有效 | 高 | `s_R`/`s_V` 分离 + 强制本地复核 |
| 人机共识幻觉（回声室） | 高 | 盲查询 + 独立探针 + provenance 隔离 |
| 证据投毒 / 索引污染 | 高 | 来源签名 + 反例优先 + quarantine 传播 |
| 人类延迟拖垮闭环 | 中 | 异步共签 + abstain 降级 + 预算门控 |
| 人机检索本体漂移 | 高 | O_shared 版本化 + 动作区间双向对齐测试 |

## 6. 本轮最大风险

**一句话**：人机协作与 RAG 的最大风险是**共识幻觉**——检索相似度与人类确认互相印证，把「共同偏差」包装成「多方证据」，证书在自证循环中系统性高估可用性；一旦检索索引与人类本体同步漂移，系统会精确地为它实际无法执行的区域签发证书，故必须以 **反例优先检索 + 独立盲查询 + provenance 隔离** 打破自证循环，宁可 abstain，绝不把「检索到且人点头」当成「可部署」。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-HRAG（CER×RAV×UGH×HCS×EPC×HRAC）

> 承接第 54 轮产物 v31。本轮在动作-鲁棒性双证书体系之上，增加 **证据登记、检索增强验证、人机门控共签、证据污染控制** 四大算子：
> - **CER（Certificate Evidence Registry）**：以证书/反例/人类证词为索引单元的版本化证据登记册；
> - **RAV（Retrieval-Augmented Verification）**：`retrieve → re-verify → ground`，相关性 `s_R` 与有效性 `s_V` 严格分离；
> - **UGH（Uncertainty-Gated Human Query）**：按动作不确定性门控、带权限 Ω_h 与预算的盲查询；
> - **HCS（Human Co-Signing）**：噪声或共签 `J' = J ⊕ Att`，人类证词只提升下界、不制造确定性；
> - **EPC（Evidence Pollution Control）**：TTL + 版本身份 + 矛盾图 + 污染半径递归隔离；
> - **HRAC（Human-RAG Coordination）**：检索接地 + 人类证词 + 反例否决的四条件部署契约。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-117/118/120 以接入证据层 𝔼。

| `w = conf·r_h` | 证词有效权重，恒 `<1` |
| `α̃ = α ⊕ Att` | 共签后的动作覆盖下界 |
| `valid(e,t)` | 时效 ∧ 版本身份 ∧ 未隔离 ∧ 无更新矛盾 |
| `rad(e)` | 污染半径：依赖 e 的证书集合 |
| `Π` | provenance 链（不可用于自证） |
| `C_hrag=(P_c,P_e,ℛ,π_q,V,Π)` | 人机检索增强协同契约 |

### IP-122 RAV

```python
def retrieve_then_verify(task, alpha, registry, k=8):
    E = registry.retrieve(embed_task(task), k,
                          filter=lambda e: evidence_valid(e, now(), CUR_EMB, GX, theta_x))
    ce = [e for e in E if e.type == 'counterexample'
          and covers(e.meta.a_region, task.A_T)]
    if ce:
        return ('reject', ce)                         # 反例命中有否决权

    accepted = []
    for p in generate_candidates(E, task):
        if not evidence_entails(E, p):                # e ⊢ p
            continue
        verdicts = [verify_edge(edge, E, alpha) for edge in p.edges]
        if any(v == 'reject' for v in verdicts):
            continue
        if all(v == 'accept' for v in verdicts):
            accepted.append((p, build_provenance(p, E)))
        else:
            accepted.append((p, ('abstain', residual_uncertainty(p, alpha))))
    return ('ok', accepted)

def verify_edge(edge, E, alpha):
    hits = [e for e in E if e.type == 'cert' and covers(e.meta.a_region, edge.A)]
    if not hits: return 'abstain'
    s_R = max(similarity(e, edge)    for e in hits)
    s_V = max(validity(e, alpha)     for e in hits)   # 在当前剖面上复核
    if s_R >= theta_r and s_V >= theta_v: return 'accept'
    if s_V < theta_v:                     return 'reject'
    return 'abstain'
```

### IP-123 UGH

```python
def human_gated_query(plan, alpha, human, theta_u, budget):
    atts, spent = [], 0
    for region in uncertain_regions(plan, alpha, theta_u):   # 按 U 降序
        if spent >= budget: break
        if not region.subset_of(human.Omega): continue       # 权限外不签
        ans = human.ask_blind(region)                        # 不展示检索结论
        spent += 1
        atts.append(Attestation(region, ans.verdict, ans.conf, human.id))
    return atts
```

### IP-124 HCS

```python
def cosign_certificate(J, atts, human, theta_h):
    alpha_tilde = dict(J.alpha)
    for att in atts:
        w = att.conf * human.r_h
        if w < theta_h or not valid(att, now()): continue
        for a in att.region:
            if att.verdict == 'feasible':
                alpha_tilde[a] = 1 - (1 - alpha_tilde[a]) * (1 - w)   # noisy-OR
            elif att.verdict == 'infeasible':
                alpha_tilde[a] = 0.0
    return J.with_alpha(alpha_tilde,
                        provenance=J.provenance + [('att', a.id) for a in atts])
```

### IP-125 EPC

```python
def quarantine(e, GX):
    stack, seen = [e], set()
    while stack:
        x = stack.pop()
        if x.id in seen: continue
        seen.add(x.id)
        mark_quarantined(x)
        stack += GX.dependents(x)          # 沿依赖边传播污染半径 rad(e)
    return seen

def evidence_valid(e, now, cur_emb, GX, theta_x):
    if now - e.meta.t_e > e.meta.ttl:        return False
    if e.meta.embodiment_id != cur_emb:      return False
    if is_quarantined(e):                    return False
    newer = GX.newer_than(e, now)
    return not any(similarity(c, e) >= theta_x for c in newer)
```

### IP-126 HRAC

```python
def hrag_coordinate(task, alpha, registry, human, budgets):
    E = registry.retrieve(embed_task(task), budgets.k, filter=valid_now)
    status, cands = retrieve_then_verify(task, alpha, registry, budgets.k)
    if status == 'reject':
        return ('reject', 'counterexample', cands)

    plan = select_min_cost(cands)
    atts = human_gated_query(plan, alpha, human, budgets.theta_u, budgets.B_h)
    J    = joint_certificate(plan, alpha, budgets.delta_a, budgets.rho_min)
    J'   = cosign_certificate(J, atts, human, budgets.theta_h)

    if U(J'.alpha, task.A_T) > budgets.theta_u_post:
        return ('abstain', 'residual_uncertainty')
    return ('ok', J', provenance_chain(J', E, atts))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CER | O(log N) 摊还 | O(N) | meta 完备、版本/时效能判定 |
| RAV | O(k·\|p\|·\|A\|) | O(k+\|p\|) | `s_R`/`s_V` 分离、反例优先 |
| UGH | O(\|A_T\|) + ℓ_h | O(\|Att\|) | 门控 sound、权限 ⊆ Ω_h |
| HCS | O(\|Att\|·\|A\|) | O(\|A\|) | `w<1`、噪声或单调、证词不造真 |
| EPC | O(\|E\|+\|rad(e)\|) | O(\|E\|) | 依赖图 sound、TTL 硬失效 |
| HRAC | O(检索+验证+人机往返) | O(\|Π\|) | 四条件合取、abstain 保守 |

**正确性定理（Human-RAG Grounded Composition Soundness）**
假设第 54 轮 (A22)–(A28) 成立；新增 **(A29)** 证据过滤 `F` sound；**(A30)** `r_h` 经 Beta 后验校准，单次证词错误率 ≤ `1-r_h`；**(A31)** 反例覆盖检测 sound。则：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a > Θ_a)
            - P(误用失效证据) - P(query)·(1-r_h) - P(U(Ã_T) > θ_u^post)
```
关键：**人类证词只提高下界（w<1）**，**检索相似不构成接受理由**，**未过期反例一票否决**。

## 5. 本轮最大风险

**一句话**：人机协作与 RAG 的最大风险是**共识幻觉**——检索相似度与人类确认互相印证，把「共同偏差」包装成「多方证据」，证书在自证循环中系统性高估可用性；一旦检索索引与人类本体同步漂移，系统会精确地为它实际无法执行的区域签发证书，故必须以 **反例优先检索 + 独立盲查询 + provenance 隔离** 打破自证循环，宁可 abstain，绝不把「检索到且人点头」当成「可部署」。
