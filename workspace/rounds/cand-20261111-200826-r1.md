# 第 56 轮（承接第 55 轮 v32 SemanticViability-GenSim；灵感循环第 2 轮；本轮灵感：「最优控制」×「创新点挖掘」）

> 第 55 轮把安全从“动作覆盖”下探到“语义-接触生存核”，但护盾仍是**单步 QP、近视的**：它只看一步是否落在 `K(Σ)` 内，不看代价-to-go，也不把“感知”当成可优化的控制输入。本轮用**最优控制**把生存核升级为**语义鲁棒值函数**，用**创新点挖掘**把“还缺哪个实验/定理”变成可计算的缺口算子。核心矛盾：**H24（近视性）** 单步可行 ≠ 长程最优，保守护盾会在核边界“冻结”，或选择把未来可行集提前耗尽的动作；**H25（感知外生性）** 既有证书把 `δ_s` 当外生扰动，但机器人本可通过“看近一点、摸一下、轻推”主动降低语义不确定——感知是控制输入，不是噪声。

## 0. 直觉与动机

**灵感 1（最优控制 → 把生存核变成值函数）**
直觉：`K(Σ)` 只回答“这一步能不能活”，`V(x)` 回答“从这里出发最好能活多好、还能走多远”。把护盾从 `argmin ||u-u_nom|| s.t. x'∈K` 换成 `argmin ℓ(x,u)+V(x')`，近视的可行性约束就变成**带代价-to-go 的最优性条件**。进一步，语义不确定不应事后检验，而应作为 Hamiltonian 里的**对手**：`V_ε(x)=inf_π sup_{Σ∈B_ε} ...`，这是一个 Hamilton-Jacobi-Isaacs 问题；第 55 轮的生存核只是 `V_ε` 的有限子水平集。

**灵感 2（最优控制 → 共态即语义归因）**
直觉：Pontryagin 共态 `p=∂V/∂x` 是“状态再危险一点，未来代价涨多少”的影子价格。把它投影到接触雅可比与语义区域，就得到**语义显著性**：不是分类器梯度说哪里亮，而是**安全值函数说哪块语义最要命**。这把前几轮的 Explain 从“感知解释”升级为“控制解释”，并天然回答“此刻该不该花代价去探测”。

**灵感 3（最优控制 → 对偶控制：感知是动作）**
直觉：经典对偶控制里，控制既调节状态又**激励系统以学习参数**。语义不确定下同理：`a_I∈{拉近,触摸,轻推,侧倾}` 是能改变信念 `b(Σ)` 的动作。定义信息价值 `VoI(a_I)=E[V(b')]-V(b)-c_I(a_I)`，只有 `VoI>0` 才探测。关键词是**安全探测**：探测本身也受 `C^+(Σ)` 与屈服力约束，不能为了看一眼把脚踩穿。

**灵感 4（创新点挖掘 → 假设-证据缺口算子）**
直觉：创新点不是拍脑袋，而是**“定理依赖的假设”与“已有证据”之间的覆盖缺口**。把既有 IP 组成格子 `𝒢=(IP,A,E,T)`，每条 soundness 边上的假设若没有直接实验支撑，就是缺口。定义 `gap(ip)=Σ_a w_a(1-cover(a,E_ip))+w_t·1[定理未被反例检验]`，再乘“影响力×可执行性”得到挖掘优先级。这样“下一轮该做什么”从灵感变成**可排序的搜索**。

**灵感 5（创新点挖掘 → 反事实语义攻击当矿机）**
直觉：最快的创新点挖掘是找**最小改动就能让现有证书失效**的地方。定义反事实语义攻击：在 `||ΔΣ||≤ε_s` 内找使 `V_ε` 最大或使护盾不可行的最小编辑；它同时产出（i）最坏测试用例、（ii）证书的薄弱语义区域、（iii）下一个 IP 的候选方向。**攻击成功处就是创新点所在处。**

**灵感 6（最优控制 → 值函数云边接口）**
直觉：第 54 轮的云边接口传动作 `γ_ce`，动作对齐误差难有全局保证；若云端传的是**值函数/代价-to-go** `V_c`（附误差界 `ε_V`），边端用 `V_c` 作 MPC 终端代价，则组合安全性可由**值函数次优性界**给出，而不是靠动作 Lipschitz 的局部假设。这把“动作对齐”升级为“价值对齐”。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（语义信念状态）**
`z=(x,b)`，`b∈Δ(Σ)` 为标签图后验；观测 `y` 与探测动作 `a_I` 后按贝叶斯更新 `b'=τ(b,y,a_I)`。语义不确定球 `B_ε(Σ̂)={Σ | d(Σ,Σ̂)≤ε}`，`d` 取 `||·||_∞` 或 Wasserstein。

**定义 128（语义鲁棒值函数 SRVF）**
```
V_ε(x) = inf_π sup_{Σ∈B_ε(Σ̂)} E[ Σ_{t=0}^{T-1} ℓ(x_t,u_t) + ℓ_T(x_T) ]
s.t. x_{t+1}=f(x_t,u_t,λ_t), supp(λ_t)⊆C^+(Σ), x_t∈𝒳_safe
```
若 `x` 对某个 `Σ∈B_ε` 不可行，则 `V_ε(x)=∞`。语义鲁棒生存核 `K_ε={x | V_ε(x)<∞}`，且 `K_ε ⊆ ∩_{Σ∈B_ε} K(Σ)`（比第 55 轮的点核更保守、更可部署）。

**定义 129（语义-接触 HJI 方程）**
在 `K_ε` 内 `V_ε` 满足
```
0 = min_{u∈A_WB} max_{Σ∈B_ε} { ℓ(x,u) + ∇V_ε^T f(x,u,λ(Σ)) }
```
边界 `V_ε=∞ on ∂K_ε`；若最优 `u` 在接触集上不唯一，取最小范数解。该 HJI 的黏性解即鲁棒值函数；离散时间用 Bellman 备份 `V_{k+1}=min_u max_Σ [ℓ+γV_k]`。

**定义 130（对偶控制与信息价值 VoI）**
增广代价 `J_I=E[Σ_t ℓ(x_t,u_t)+λ_I c_I(a_{I,t})]`，`c_I` 为探测代价（时间/能量/风险）。信息价值
```
VoI(a_I|b) = E_{y~p(·|b,a_I)}[V_ε(b')] - V_ε(b) - λ_I c_I(a_I)
```
只有 `VoI(a_I|b)≥θ_V` 才执行探测；探测动作必须满足 `a_I∈A_I^safe(b)`，接触类探测限于 `C^+` 且法向力 `<F_yield`。

**定义 131（共态语义显著性 CSS）**
沿名义最优轨迹 `(x_t^*,u_t^*)`，共态 `p_t=∇_x V_ε(x_t^*)`。对语义区域 `Ω_l`：
```
sal(Ω_l) = Σ_t | p_t^T ∂f/∂Σ |_{Ω_l} | / max(m_s(Ω_l), ε0)
```
即单位语义裕度上的值敏感度；`CSS=top-k(sal)` 给出“最该被解释/重分割”的区域。`p_t` 同时给出探测的影子价格 `λ_I^*=|∂V/∂b|`。

**定义 132（创新缺口与新态度量）**
IP 格子 `𝒢=(V_IP,E_A,E_E,E_T)`。对 IP 的 soundness 假设 `a` 与证据集 `E_ip`：
```
cover(a,E_ip) = max_{e∈E_ip} sim(a,e) · power(e)
gap(ip) = Σ_{a∈A_ip} w_a (1-cover(a,E_ip)) + w_t · 1[定理未被反例检验]
mine(𝒢,k) = top-k_{ip} [ gap(ip) · impact(ip) · feasibility(ip) ]
```
新颖性 `nov(ip)=min_{q∈文献} d(claim_ip,q)+κ·1[与既有 IP 逻辑冲突]`；只有 `gap` 高且 `nov` 高才进入候选。该算子只提**可证伪的下一实验/定理**，不产出无法检验的口号。其部署版把 `𝒢` 换成机器人的技能-证据图，输出“最该补数据/补探测”的技能。

## 2. 关键算法 伪代码

### IP-127 SRVF（Semantic-Robust Value Function）

```python
def semantic_robust_value(f, ell, Sigma_hat, eps, grid, gamma=0.99):
    V = {x: float('inf') for x in grid}
    for x in grid:
        if not any(viable(x, Sigma) for Sigma in ball(Sigma_hat, eps)):
            continue
        V[x] = 0.0 if terminal(x) else float('inf')
    for _ in range(N_iter):
        V_new = {}
        for x in grid:
            best = float('inf')
            for u in A_WB:
                worst = -float('inf')
                for Sigma in ball(Sigma_hat, eps):      # 对手选语义
                    lam = contact_forces(x, u, Sigma)
                    if lam is None:
                        worst = float('inf'); break
                    xp = f(x, u, lam)
                    worst = max(worst, ell(x, u) + gamma * V.get(xp, float('inf')))
                best = min(best, worst)
            V_new[x] = best
        if max_abs_diff(V, V_new) < tol:
            V = V_new; break
        V = V_new
    return V, {x for x in grid if V[x] < float('inf')}     # K_eps
```

高维时把网格备份替换为 level-set / deep value，仅保留**保守子水平集**与区间包络。

### IP-128 SR-MPC（Robust Value-Based Safety Filter）

```python
def sr_mpc(x, u_nom, V_eps, Sigma_hat, eps, H):
    u_seq = solve(
        min  sum_{k=0}^{H-1} ell(x_k, u_k) + V_eps(x_H)
        s.t. x_0 = x, x_{k+1} = f(x_k, u_k, lam_k),
             supp(lam_k) subset C_plus(Sigma_hat, eps),
             lam_k in FC(mu), u_k in A_WB,
             V_eps(x_H) <= V_max_k
    )
    if u_seq is None:
        return safe_brake(x), 'infeasible'
    if cost_gap(u_seq, u_nom) > Delta_u:
        return u_seq[0], 'value_override'
    return u_seq[0], 'ok'
```

递归可行性由终端约束 `V_eps(x_H)≤V_max` 与 `V_eps` 的 HJI 下降条件保证。

### IP-129 ASP（Active Semantic Probing）

```python
def active_probe(b, x, A_I_safe, V_eps, lam_I):
    best, best_voi = None, 0.0
    for a in A_I_safe:
        if not safe_probe(x, a):
            continue
        post = [tau(b, y, a) for y in sample_obs(b, a)]
        val = mean(V_eps(bp) for bp in post) - V_eps(b) - lam_I * cost_I(a)
        if val > best_voi:
            best, best_voi = a, val
    return best if best_voi >= theta_V else None
```

### IP-130 CSS（Co-State Semantic Saliency）

```python
def cosal_saliency(traj, V_eps, grad_f, regions):
    sal = defaultdict(float)
    for x, u in zip(traj.x, traj.u):
        p = grad(V_eps, x)
        for (l, region) in regions.items():
            dsig = semantic_sensitivity(grad_f, x, u, l)
            sal[l] += abs(p @ dsig) / max(region.margin, eps0)
    return sorted(sal.items(), key=lambda kv: -kv[1])
```

### IP-131 IGM（Innovation / Capability Gap Miner）

```python
def mine_innovation(IP_graph, lit_index, k):
    cands = []
    for ip in IP_graph.nodes:
        gap = sum(w[a] * (1 - cover(a, ip.evidence)) for a in ip.assumptions)
        gap += w_t * (0 if ip.theorem_falsified else 1)
        nov = min(dist(ip.claim, q) for q in lit_index) + conflict_penalty(ip)
        if gap > theta_g and nov > theta_n and ip.falsifiable:
            cands.append((ip, gap * ip.impact * ip.feasibility, nov))
    return sorted(cands, key=lambda c: -c[1])[:k]
```

反事实攻击器负责填充 `ip.theorem_falsified`：在 `B_ε` 内搜索最小语义编辑，令护盾不可行或 `V_ε` 越界。

### IP-132 VHO（Value Handoff, Cloud-Edge）

```python
def value_handoff(cloud, edge, task, eps_V):
    V_c, grad_c, err = cloud.coarse_value(task)      # reduced abstraction
    assert err <= eps_V
    def terminal_cost(x):
        return V_c(project(x))
    return edge.mpc(terminal_cost=terminal_cost, terminal_grad=grad_c)
```

安全组合：若边端每步满足 `V_c(x_{k+1}) ≤ V_c(x_k) - ℓ + ε_V` 且 `V_c(x)≤V_max ⇒ x∈𝒳_safe`，则闭环不越界。

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SRVF | O(N_iter·\|X\|·\|A_WB\|·\|B_ε\|) 网格；deep 版 O(训练) | O(\|X\|) | 对手覆盖球、Bellman 单调收敛 |
| SR-MPC | O(H·QP·\|B_ε\|) / 步 | O(H·\|A_WB\|) | 终端约束、`V` 下降条件 |
| ASP | O(\|A_I\|·N_y·V_eval) | O(\|b\|) | VoI 校准、探测安全集 |
| CSS | O(\|轨迹\|·\|区域\|·J) | O(\|区域\|) | 值函数可微/次梯度、裕度归一 |
| IGM | O(\|IP\|·\|A\|·\|E\|+检索) | O(\|IP\|) | 覆盖度量校准、可证伪性 |
| VHO | O(云端 DP + 边端 MPC) | O(\|V_c\|) | `ε_V` 界、终端不变集 |

**正确性定理（Semantic-Robust Value Safety & Suboptimality）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** `V_ε` 是 HJI 的 `ε_V`-近似解且 `K_ε⊆∩_{Σ∈B_ε}K(Σ)`；**(A34)** SR-MPC 终端集 `Ω_T⊆{V_ε≤V_max}` 且每步可行；**(A35)** 真实语义始终在 `B_ε`，探测动作满足 `A_I^safe`；**(A36)** 云边 `V_c` 的抽象误差 `≤ε_V` 且边端终端下降条件成立。则对任意 `Σ∈B_ε`：
```
P_safe ≥ 1 - P(Σ∉B_ε) - P(V_ε approx violated) - P(terminal set escaped)
J_closed ≤ (1+κ) J* + ε_V/(1-γ) + λ_I Σ c_I
```
关键：**语义对手进 HJI、值下降保递归可行、探测显式计成本、云边传值不传动作**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| HJI 维数灾难 | 高 | 降阶/相对坐标 + deep value + 区间包络，只保证保守子水平集 |
| 语义对手过悲观导致冻结 | 高 | 校准 `B_ε` 半径 + CVaR 替代最坏 + 分层值函数 |
| 主动探测带来风险 | 高 | `A_I^safe` 硬约束 + 屈服力上限 + 探测前预检 |
| 共态在非光滑处不稳 | 中 | 次梯度/平滑 + 反事实一致性校验 |
| 缺口算子被指标游戏 | 中 | 强制可证伪实验 + 新颖性检索 + 外部评审 |
| 云边值函数抽象失配 | 高 | 误差界 `ε_V` 可测 + 终端不变集 + 拒绝式回退 |

## 6. 本轮最大风险

**一句话**：用最优控制把生存核升级为语义鲁棒值函数、用缺口算子指导创新，理论上把“近视护盾”和“拍脑袋选题”同时变成可计算问题，但其 soundness **三重依赖 HJI 近似的保守性、语义对手球半径的校准、以及值函数云边抽象的误差界**；一旦 `V_ε` 在未见语义区域被高估（把不可行判成可行）或 `B_ε` 半径失真，SR-MPC 会在“看起来代价很低”的伪安全区里选择透支未来的动作，而 IGM 又会因证据覆盖度量失真把资源导向伪缺口——因此必须以 **保守值包络 + 校准的语义球 + 可证伪缺口** 三重护栏，宁可在值函数上保守，绝不把“近似最优”当作“已被证明安全”。

| `ρ_sem(ε_s)` | 语义扰动球内最坏可行保持概率 |
| `δ_s` | 核心接触区语义扰动实测量 |
| `J_s` | 语义-接触联合证书 |

**定义 121（语义-接触图）**
语义图 `Σ: Ω→Δ(L)`；接触可供性 `κ: L×C→[0,1]`。语义接触集
`C(Σ) = {(p,c) | κ(Σ̄(p),c) ≥ θ_κ ∧ conf(Σ(p)) ≥ θ_conf}`，其中 `Σ̄(p)=argmax_l Σ(p,l)`，`conf` 为校准后验置信。

**定义 122（全身语义-接触生存核）**
全身动作空间 `A_WB = A_b × A_a × A_l × A_t`，质心动力学 `ẋ=f(x,u,λ)`，接触力 `λ∈FC(μ)`。生存核
`K(Σ) = {x | ∃u∈A_WB, λ : f(x,u,λ)=ẋ ∧ supp(λ)⊆C(Σ) ∧ x_{t+1}∈𝒳_safe}`。
**语义可行性** `viable(x,Σ)=1 ⇔ x∈K(Σ)`。

**定义 123（语义边界裕度）**
对标签区域 `Ω_l` 与边界 `∂Ω_l`，接触点 `p` 的语义裕度 `m_s(p)=dist(p,∂Ω_{Σ̄(p)})`。保守接触集
`C^+(Σ) = {(p,c)∈C(Σ) | m_s(p) ≥ θ_m(κ,c)}`，`θ_m` 随可供性置信升高而降低。

**定义 124（全身语义护盾）**
给定名义动作 `u_nom`：
`u* = argmin_u ||u-u_nom||²_W s.t. x_{t+1}∈K(Σ), supp(λ)⊆C^+(Σ), λ∈FC(μ), u∈A_WB`。
若可行集为空，回退 **最小风险制动** `u_stop∈𝒳_safe`；护盾把“感知不确定”挡在“不可逆接触”之前。

**定义 125（语义鲁棒性谱）**
在第 53 轮维度谱 `ρ` 上增加语义维：
`ρ_sem(ε_s) = inf_{||Σ-Σ̂||_∞ ≤ ε_s} P(viable(x,Σ) | Σ̂)`，
即分割扰动球内全身可行性的最坏保持概率，与 `ρ` 的其他维度共用证书框架。

**定义 126（语义-接触联合证书）**
`J_s = (Σ_core, C_core, K_margin, ρ_sem, δ_s, evidence)`：
- `Σ_core` 核心接触区语义分布，`C_core ⊆ C^+(Σ_core)` 核心接触集；
- `K_margin = min_{x∈轨迹} dist(x, ∂K(Σ))`；
- `δ_s = ||Σ_core - Σ̂_core||`；
- `evidence` 含边界反例与力反馈日志。
若 `Σ_core` 置信校准通过、`K_margin≥θ_K`、`ρ_sem≥ρ_min` 且 `δ_s<Θ_s`，则语义-接触可部署。

## 2. 关键算法 伪代码

### IP-121 SCG（Semantic-Contact Grounding）

```python
def semantic_contact_map(rgbd, seg_model, kappa, theta_k, theta_conf):
    Sigma = seg_model.predict_soft(rgbd)          # per-pixel label distribution
    C = set()
    for p in grid(rgbd):
        l = argmax(Sigma[p])
        if confidence(Sigma[p]) < theta_conf:
            continue
        for c in CONTACT_TYPES:
            if kappa[l][c] >= theta_k:
                C.add((p, c))
    M = boundary_margin(Sigma)                     # m_s(p) for every p
    return Sigma, C, M

def conservative_contacts(C, M, kappa, theta_m):
    return {(p,c) for (p,c) in C
            if M[p] >= theta_m(kappa[argmax_at(p)][c])}
```

### IP-122 WBV（Whole-Body Viability Kernel）

```python
def viability_kernel(Sigma, C_plus, x0, horizon, eps):
    K, margins = set(), []
    for x in sample_state_space(x0, horizon):
        feas, u, lam = solve_contact_dynamics(x, C_plus, friction_cone=mu)
        if feas:
            K.add(x)
            margins.append(distance_to_infeasible(x, C_plus))
    # eps-网与区间包络给出外/内近似
    return KernelApprox(K_in=inner_hull(K),
                        K_out=outer_hull(K, eps),
                        margin=min(margins) if margins else 0.0)
```

### IP-123 SSF（Semantic Shield Filter）

```python
def semantic_shield(u_nom, x, Kernel, C_plus, W):
    u = qp_solve(
        H=W, g=-W @ u_nom,
        constraints=[
            viability_constraint(x, u, Kernel.K_in),   # x_{t+1} in K_in
            contact_constraint(u, C_plus),             # support(lambda) subset C+
            friction_cone_constraint(u, mu),
            joint_limit_constraint(u),
        ],
    )
    if u is None or projection_gap(u, u_nom) > Delta_u:
        return safe_brake(x), 'shield_infeasible'
    return u, 'ok'
```

### IP-124 SCC（Semantic-Contact Certificate）

```python
def semantic_contact_certificate(traj, Sigma, kappa, rho_sem, budgets):
    Sigma_core = core_semantics(traj, Sigma)
    C_core = (contacts_used(traj)
              & conservative_contacts(Sigma_core, M, kappa, theta_m))
    if not C_core:
        return ('reject', 'no_core_contact')
    K_margin = min(distance_to_boundary_K(x, Sigma) for x in traj)
    delta_s = semantic_perturbation(Sigma_core, calibrated_eps)
    if K_margin < budgets.theta_K or delta_s > budgets.Theta_s:
        return ('reject', 'semantic_budget_exceeded', K_margin, delta_s)
    if rho_sem(delta_s) < budgets.rho_min:
        return ('reject', 'semantic_robustness_fail')
    return ('ok', SemanticCert(Sigma_core, C_core, K_margin,
                               rho_sem, delta_s))
```

### IP-125 SRS（Semantic Robustness Spectrum）

```python
def semantic_robustness_spectrum(Sigma_hat, eps_s, sampler):
    worst = 1.0
    for Sigma_adv in sampler.ball(Sigma_hat, eps_s, worst_case=True):
        Sigma_adv = renormalize(Sigma_adv)
        p = empirical_viability(Sigma_adv, sampler.states)
        worst = min(worst, p)
    return worst
```

### IP-126 CEB（Cloud-Edge Semantic Boundary Protocol）

```python
def cloud_edge_semantics(P_c, Sigma_c, kappa_c, edge):
    Sigma_e, C_e = edge.local_semantics()
    mismatch = boundary_disagreement(Sigma_c, Sigma_e)
    if mismatch.area > delta_A:
        exp = edge.explain_contact_failure()
        return ('reprofile', region=mismatch.hotspots, evidence=exp)
    C_shared = conservative_contacts(C_e, edge.margin, kappa_c, theta_m)
    return ('ok', C_shared, merge_uncertainty(Sigma_c, Sigma_e))
```

**正确性定理（Whole-Body Semantic-Contact Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** `Σ` 置信经温度/分位数校准，ECE≤ε_cal；**(A30)** `K_in⊆K(Σ)⊆K_out` 且护盾不可行时回退 `u_stop∈𝒳_safe`；**(A31)** 真实语义扰动 `||Σ-Σ̂||_∞≤ε_s`；**(A32)** 云边边界回传延迟≤τ_sem 且重分割收敛。则部署后单步安全概率：
```
P_safe ≥ 1 - P(||Σ-Σ̂||_∞ > ε_s) - P(κ miscalibrated)
           - P(K_out \ K_in ≠ ∅) - P(shield fallback fails)
```
关键：**语义不确定性进证书、生存核保守包含、护盾兜底**；任何一层失守，都不允许把“分割看起来很确定”当作“接触一定成立”。

## 7. 本轮最大风险

**一句话**：语义-接触接地与全身生存核把“感知标签”升级为“可执行的接触约束”，但其 soundness **三重依赖分割置信的校准、接触可供性的跨域迁移、以及生存核外近似的紧致性**；一旦边界处置信过度自信、或可供性在未见材质上系统偏移，护盾会在“自认为可行”的伪生存核内放行动作，让全身控制器把所有肢体压上虚假支撑面，造成不可逆跌倒——因此必须以 **边界校准 + 在线 κ 更新 + 核保守度预算** 三重护栏，宁可保守制动，绝不把语义的“高置信”当作接触的“已证实”。
