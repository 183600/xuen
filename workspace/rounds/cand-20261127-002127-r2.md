> **基线**：承接当前态 MetricVoiceGauge-NCD-HUTDH-v23 + IP-436–439（CESC/FSVC/IPAM/HPC-E+），其上承 v22 分层 PGEV/ACSC/DCSC/CFC++、v21 语义-规范层（SDC/CAC/DCL/GIC）、v20 联邦感知证书与 v19/v17 各模块。
> 本轮纪律：**不推倒 v23。** 只做两件事：**(a) 把 v23 的"经验前提"（κ_c 召回下界、conformal 覆盖、版本/专利一致性）交给预注册的用户测试去证伪，使"用户测试"从 UX 附属升级为证书的证伪通道；(b) 把证书从"任务空间可证明"下沉为"关节空间可执行"，用全臂扫掠体、冗余零空间安全管与完整刚体动力学能量上界，封堵"末端安全而整臂碰撞/超扭矩/能量低估"的缺口。** 共享状态扩展为 **ζ_v24 = ζ_ce ∪ (UTFC 证据账本, JSEC 证书, RBEUB 能量上界, override 遥测)**。

## 0. 直觉与动机

**灵感 1（用户测试 → 证书的证伪通道，以及"被用户关掉的安全"）**

直觉：v23 的可靠性全部落在若干**无法从系统内部验证的经验前提**上——κ_c 是对"人"的召回率，conformal 覆盖是对"分布"的承诺，而这两者的真值只能由**真实用户**来提供。用户测试因此不是收尾的可用性检查，而是唯一能**证伪**这些前提的采样通道。但最危险的结果不是"测试中机器人撞了"，而是"测试中机器人太保守，用户把安全层关掉了"：此时证书形式有效率为 100%，部署有效率却为 0。故用户测试必须被设计成**预注册、分层、对抗性、anytime-valid** 的统计协议；用户的"旁路/关闭"行为必须作为**一级安全指标**遥测，而不是产品体验指标。

严谨定义：设风险队列集合 C（成人、儿童、轮椅、蹲姿、遮挡、逆光、非常规衣着……），队列 c 的召回率 κ_c，预注册要求 κ_req。定义 anytime-valid 置信序列下界 κ_c^LB(t) 与系统召回下界 **κ̂(t) = min_{c∈C} κ_c^LB(t)**（最差队列决定），并要求：

1. **只用下界**：AbsCert 仅当 `κ̂ ≥ κ_req` 且每个队列 `n_c ≥ n_min` 时签发；样本不足的队列取 `κ_c^LB = 0`（最保守）。
2. **只收紧**：用户反馈、舒适度、旁路压力都**不允许放宽** Exec；放宽只能走正式证书路径。
3. **旁路即风险**：`BYPASS_SAFETY` 事件（用户禁用安全层）计入风险账本并触发重新测试，`PROTECTIVE_STOP`（用户主动停机）不算风险。

关键反直觉点：**"用户满意"与"系统安全"在这里不是正相关——用户越觉得约束碍事，越可能关掉它；因此把用户测试做成"让用户更满意"的优化，反而会系统性侵蚀安全。**

**灵感 2（关节空间控制 → 证书的可执行性下沉与冗余不变性）**

直觉：v23 的 ACSC/P41 已经进入配空间，但仍有两个隐含假设：(i) 证书覆盖的是**末端/末端工具**，而关节空间控制下真正会撞人的是**整条臂的扫掠体**（肘、腕、连杆）；(ii) 冗余臂对同一条末端轨迹有无穷多组关节解，**零空间自运动**可以让末端保持安全而把肘甩进人所在区域。再加上 P41 的 `E_arm=∫Σ|τ_i q̇_i|dt` 只是机械功的一个粗糙代理，遗漏了电机效率、摩擦损耗与重力保持功耗，**不能作为电池消耗的上界**。关节空间控制要求证书直接编译为关节侧的约束：位置/速度/加速度/扭矩/奇异裕度/自碰撞，且对冗余零空间**量化全称**而非"选一条 IK 解"。

严谨定义：给定任务空间计划 π，要求存在关节轨迹 lift `q(t)`，使得对轨迹上的每个时刻与每个零空间自运动 `q'(θ)=q+N(q)θ, |θ|≤θ_max`：

- 关节/速度/加速度/扭矩约束在区间包络内成立；
- **整臂扫掠体**与障碍的最小间隙 ≥ margin（用区间正运动学包络，而非点采样）；
- 奇异裕度 `σ_min(J(q)) ≥ δ_sing`；
- 自碰撞检查覆盖同一零空间管。

若不存在这样的 lift，则**拒绝计划**，而不是"换一个 IK 解再试"。

关键反直觉点：**"末端轨迹安全"与"整臂安全"在冗余臂上是两个不同命题；证书必须对冗余解空间做全称量化，否则只是在一条任意选中的 IK 分支上自证。**

**灵感 3（统一：经验前提 × 执行前提 = 证伪闭环）**

直觉：用户测试与关节空间控制是同一件事的两面——前者证伪证书的**分布前提**（"人会不会被看见"），后者证伪证书的**可实现前提**（"看见了之后，关节空间里到底能不能安全地执行"）。一个可信证书必须同时被这两类现实持续检验。更关键的是二者**耦合**：用户测试带来的保守化（降速、加大间距）会改变关节轨迹与时长，从而改变能量与奇异裕度；因此参数变更不能默认"更保守就继承"，必须**增量再认证**。

严谨定义：把 v23 的单向证书链升级为**证伪闭环**：`用户测试 → 更新 κ̂/覆盖证据 → 收缩感知域 → 重新规划 → 关节空间 lift 与能量核验 → 执行 → 遥测（含 override）→ 回到用户测试`。闭环上的每一步只允许**收缩**执行集；任何一步失败都向更保守的 v23/v22 退化。

## 2. 设计原则（在 P37–P42 基础上新增 P43–P46）

**P43 用户测试证伪律（User-Test Falsification）**
证书的经验前提不是公理。κ_c 只能取**预注册分层队列的 anytime-valid 下界**，系统召回取最差队列 `κ̂ = min_c κ_c^LB`；样本不足队列取 0；AbsCert 仅在 `κ̂ ≥ κ_req` 且全队列达标时签发。用户测试只能**收紧** Exec；`BYPASS_SAFETY` 遥测是一级风险并触发重测。测试通过不等于部署覆盖：必须叠加显式的分布外折扣 `κ_deploy = κ̂ - Δ_shift`，`Δ_shift` 由部署环境与测试环境的可观测偏移估计。

**P44 关节空间可执行律（Joint-Space Executability）**
每个通过 v23 的任务空间计划必须存在关节 lift `q(t)`，且对**所有** `q'(θ)=q+N(q)θ, |θ|≤θ_max`：关节/速度/加速度/扭矩约束在区间包络内成立；**整臂扫掠体**与障碍间隙 ≥ margin；`σ_min(J) ≥ δ_sing`；自碰撞安全。无 lift 即拒绝。故 `Exec_v24 ⊆ Exec_v23`：关节空间只做"存在性过滤"，不新增自由空间。

**P45 动力学能量上界律（Dynamics Energy Upper Bound）**
用完整刚体动力学 `τ = M(q)q̈ + C(q,q̇)q̇ + g(q) + τ_f` 计算逐时刻电池功耗上界 `P_batt = P_mech^+/η_m + P_loss - σ_reg·P_mech^-`（`σ_reg` 为保证的再生回收率下界，默认 0），并用 Lipschitz 界控制离散积分截断误差。储备不变量改用 `E_draw^+`，替代 P41 的 `Σ|τ_i q̇_i|`；后者在摩擦/保持力矩占比高时可能低估。能量上界只增不减，故只会收缩执行集。

**P46 测试-执行耦合律（Test-Execution Coupling）**
任何由用户测试或用户反馈引起的参数变更（速度缩放、间距、阈值）都必须把受影响的证书节点标记为 dirty，并对受影响时间窗**重新核验** JSEC/RBEUB；不得假设"更慢/更远"在能量与奇异裕度上单调更安全。门禁只接受未过期、未 dirty 的证书；否则退回 v23 保守模式。

## 3. 与基线的接口（如何退化）

- UTFC 失效/样本不足/分布外折扣过大 ⇒ `κ̂ = 0` ⇒ AbsCert 不可签发 ⇒ 全域"假设有人" ⇒ 比 v23 更保守；
- JSEC 失效/无关节 lift ⇒ 拒绝该计划，退回 v23 任务空间证书 + 静态降速 ⇒ 子集；
- RBEUB 失效（动力学模型不可信）⇒ 退回"最坏静态保持功耗 + 无再生回收"的保守能量上界 ⇒ 子集；
- TECV 失效 ⇒ 所有证书视为过期 ⇒ 退回 v23 默认模式 ⇒ 子集；
- 四者全失效 ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ ... ⊆ Exec_v18`；
- **安全继承**：UTFC 只收紧 κ，JSEC 只做存在性过滤，RBEUB 只抬高能量估计，TECV 只强制再认证；任意失效都向更保守方向退化。UTFC 与 JSEC 的统计/几何计算均在离线或低频路径完成，控制路径只做 O(1) 证书查询。

## 4. 预期贡献（在 7–9 基础上延伸）

10. **用户测试证伪协议**：把 κ_c 与 conformal 覆盖从"经验假设"变成"预注册、分层、对抗、anytime-valid"的可审计证据，首次给出"测试-部署分布偏移折扣"的显式条款；
11. **旁路遥测作为一级安全指标**：区分保护性停机与危险旁路，把"用户关掉安全层"纳入证书有效性，封堵"形式安全、部署失效"；
12. **关节空间全臂证书**：区间正运动学整臂扫掠包络 + 冗余零空间安全管 + 奇异裕度，把"末端安全"升级为"整臂全称安全"；
13. **动力学能量上界**：用完整刚体动力学修正 P41，给出电池消耗的严格上界与离散误差界，使能量储备不变量可机械复核；

## 5. 本轮最大风险

**一句话**：用户测试的样本分布与真实部署分布之间存在不可消除的差距（并被 Goodhart 效应放大），会使 UTFC 给出"虚假的经验安全感"；而关节空间全臂区间包络的膨胀又可能把可执行集压到接近空集，最终用户以"关闭安全层"恢复可用性——安全证书被它自己的验证协议与保守性**共同架空**。

## 1. 关键算法骨架

```python
# ============================================================
# IP-440 User-Test Falsification Certificate (UTFC)
# ============================================================
@dataclass
class CohortEvidence:
    name: str
    n: int = 0
    k: int = 0
    n_min: int = 200
    delta_c: float = 1e-3

    def lower_bound(self) -> float:
        """Anytime-valid Hoeffding 置信序列下界（可替换为 betting e-process）。"""
        if self.n < self.n_min:
            return 0.0
        rad = math.sqrt(
            (math.log(1.0 / self.delta_c) + math.log(math.log(2 * self.n) + 2.0))
            / (2.0 * self.n)
        )
        return max(0.0, self.k / self.n - rad)


class UserTestFalsificationCertificate:
    def __init__(self, cohorts: list[str], kappa_req: float,
                 delta: float = 1e-3, delta_shift: float = 0.02):
        self.cohorts = {
            c: CohortEvidence(c, delta_c=delta / max(len(cohorts), 1))
            for c in cohorts
        }
        self.kappa_req = kappa_req
        self.delta_shift = delta_shift
        self.override_log: list[tuple[float, str]] = []
        self.protocol_hash: bytes = b""      # 预注册协议哈希（防事后改口径）
        self.samples: list[dict] = []

    def pre_register(self, protocol: bytes):
        self.protocol_hash = sha256(protocol)
        self.samples.clear()

    def ingest(self, cohort: str, detected: bool, gt_present: bool,
               ts: float, protocol_ok: bool):
        # 只接受预注册协议产生的样本；事后改口径的样本不计入
        if not protocol_ok or cohort not in self.cohorts:
            return
        ev = self.cohorts[cohort]
        ev.n += 1
        ev.k += int(detected and gt_present)
        self.samples.append({"cohort": cohort, "detected": detected,
                             "gt": gt_present, "ts": ts})

    def kappa_hat(self) -> float:
        return min(ev.lower_bound() for ev in self.cohorts.values())

    def kappa_deploy(self) -> float:
        return max(0.0, self.kappa_hat() - self.delta_shift)

    def valid(self) -> bool:
        return (
            self.protocol_hash != b""
            and all(ev.n >= ev.n_min for ev in self.cohorts.values())
            and self.kappa_deploy() >= self.kappa_req
        )

    def log_override(self, kind: str, ts: float):
        assert kind in ("PROTECTIVE_STOP", "BYPASS_SAFETY")
        self.override_log.append((ts, kind))

    def bypass_rate(self, window_h: float) -> float:
        n = sum(1 for _, k in self.override_log if k == "BYPASS_SAFETY")
        return n / max(window_h, 1e-9)

    def safety_ok(self, rho_max: float, window_h: float) -> bool:
        # 旁路是一级风险：超阈值即视为证书被用户拒绝
        return self.bypass_rate(window_h) <= rho_max

            if smin < self.delta_sing:
                return self._reject(q_traj, "singularity")

            q_traj, self.robot.eps_q, self.theta_max, self.margin, True,
            time.now(),

# IP-443 Rigid-Body Energy Upper Bound (RBEUB)
# ============================================================
class RigidBodyEnergyUpperBound:
    def __init__(self, robot, eta_m: float = 0.85,
                 sigma_reg: float = 0.0, p_loss_fn=None):
        self.robot = robot
        self.eta_m = eta_m
        self.sigma_reg = sigma_reg      # 保证的再生回收率【下界】，默认 0
        self.p_loss_fn = p_loss_fn or (lambda q, dq: 0.0)

    def power_bound(self, q, dq, ddq):
        tau = self.robot.rnea(q, dq, ddq)       # 含重力/科氏/摩擦
        p_mech = float(np.dot(tau, dq))
        p_loss = float(self.p_loss_fn(q, dq))
        p_batt = (max(0.0, p_mech) / self.eta_m
                  + p_loss
                  - self.sigma_reg * max(0.0, -p_mech))
        return tau, p_batt

    def energy_upper(self, q_traj, dq_traj, ddq_traj, dt, L_P):
        ps = [self.power_bound(q, dq, ddq)[1]
              for q, dq, ddq in zip(q_traj, dq_traj, ddq_traj)]
        # 梯形积分 + Lipschitz 截断误差界：N*L_P*dt^2/12
        trap = sum(0.5 * (ps[i] + ps[i + 1]) * dt for i in range(len(ps) - 1))
        err = len(ps) * L_P * dt * dt / 12.0
        return max(0.0, trap) + err

    def reserve_ok(self, E_res, E_fallback, E_upper,
                   E_reach_safe, E_margin):
        return E_res >= E_fallback + E_upper + E_reach_safe + E_margin

# IP-445 Test-Execution Co-Verification (TECV)
# ============================================================
class TestExecutionCoVerification:
    def __init__(self, ttl: float = 1.0):
        self.ttl = ttl
        self.dirty: set[str] = set()

    def mark_dirty(self, changed_params: dict):
        # 任何用户测试/反馈驱动的参数变更都使相关证书失效
        for key in changed_params:
            self.dirty.add(key)

    def reverify(self, dirty_keys, horizon, engines):
        for key in list(dirty_keys):
            if key in engines:
                engines[key].recompute(horizon)   # 只重算受影响窗口
                self.dirty.discard(key)

    def fresh(self, cert, issued_at: float, now: float) -> bool:
        return cert is not None and cert.valid and (now - issued_at) <= self.ttl


# ============================================================
# IP-446 HPC-E++ Penta-Certificate Gate
# ============================================================
@dataclass
class HPCEPlusPlus:
    hpc_e_plus: 'HPCEPlus'
    utfc: UserTestFalsificationCertificate
    jsec_engine: JointSpaceExecutability
    rbeub: RigidBodyEnergyUpperBound
    tecv: TestExecutionCoVerification
    rho_max: float = 0.1
    window_h: float = 1.0

    def admits(self, plan, task_ctx, joint_traj, energy_ctx, now) -> bool:
        # 1) v23 四证/五证基础门
        if not self.hpc_e_plus.admits(*task_ctx):
            return False
        # 2) 用户测试证伪门（含分布外折扣与旁路率）
        if not (self.utfc.valid()
                and self.utfc.safety_ok(self.rho_max, self.window_h)):
            return False
        # 3) 关节空间可执行门（整臂 + 冗余零空间管）
        jcert = self.jsec_engine.certify(plan, task_ctx.obstacles, task_ctx.q0)
        if not jcert.valid:
            return False
        # 4) 动力学能量上界门
        E_up = self.rbeub.energy_upper(*energy_ctx)
        if not self.rbeub.reserve_ok(
                energy_ctx.E_res, energy_ctx.E_fallback, E_up,
                energy_ctx.E_reach_safe, energy_ctx.E_margin):
            return False
        # 5) 测试-执行耦合新鲜度门
        if not self.tecv.fresh(jcert, jcert.issued_at, now):
            return False
        return True
```

## 3. 正确性论证

### 引理 5（UTFC 的 anytime-valid 召回下界）
**陈述**：若每个队列的样本在预注册协议下可交换，且 `δ_c = δ/K`，则 `P(∀t, ∀c: κ_c^LB(t) ≤ κ_c) ≥ 1-δ`，从而 `κ̂(t)=min_c κ_c^LB(t)` 是系统召回的有效下界；样本不足队列取 0 不会高估。

**证明**：
1. Hoeffding 置信序列对任意停时 t 满足 `P(∃t: κ_c^LB(t) > κ_c) ≤ δ_c`（标准 anytime-valid 结果；亦可换成 betting e-process）。
2. 对 K 个预注册队列取并集界，总失败概率 ≤ Σδ_c = δ。
3. 样本不足时 `κ_c^LB=0 ≤ κ_c`，仍为下界。
4. 因此 `κ̂ = min_c κ_c^LB ≤ min_c κ_c`，系统召回不被高估；叠加 `Δ_shift≥0` 只会更保守。∎

### 引理 6（JSEC 的整臂与冗余全称可靠性）
**陈述**：若 `certify` 返回 valid，则对任意满足 `q'(t)=q(t)+N(q)θ(t), |θ|≤θ_max` 且跟踪误差在 `eps_q` 内的关节轨迹，整臂与障碍间隙 ≥ margin、关节/速度/加速度/扭矩约束成立、`σ_min(J)≥δ_sing`。

**证明**：
1. 区间正运动学的包含性：`q ∈ [q_lo,q_hi] ⇒ FK(q) ∈ [FK]([q_lo,q_hi])`，故区间包络覆盖真实扫掠体；时间插值界覆盖路点之间。
2. 零空间盒：`_null_space_box` 取 `q ± (|N|·θ_max + eps_q)`，任意 `|θ|≤θ_max` 的 `q+Nθ` 落在该盒内，故盒上的间隙检查对全部自运动成立。
3. 奇异裕度：`σ_min(J)≥δ_sing>0` 保证局部可逆与有界关节速度（对有界任务速度）。
4. 三类检查全部通过才置 valid；任一失败即拒绝，故不存在"末端安全而整臂越界"的 lift。∎

### 引理 7（RBEUB 对电池消耗的支配性）
**陈述**：若 `η_m∈(0,1]` 为电机效率、`σ_reg` 为再生回收率的下界，则逐时刻 `P_batt ≥ P_elec`；配合 Lipschitz 误差界，`E_draw^+ ≥ 实际电池消耗`。

**证明**：
1. 实际电功率 `P_elec = P_mech^+/η_m + P_loss - R`，其中再生回收 `R ∈ [0, P_mech^-]`。由 `R ≥ σ_reg·P_mech^-`（σ_reg 是下界）得 `P_elec ≤ P_mech^+/η_m + P_loss - σ_reg·P_mech^- = P_batt`。
2. 梯形积分误差由 Lipschitz 常数控制：单区间 ≤ L_P Δt²/12，总误差 ≤ N·L_P·Δt²/12；加上该界后仍支配真实积分。
3. P41 的 `Σ|τ_i q̇_i|` 不含 `/η_m`、`P_loss` 与保持力矩项；在摩擦/保持占比高时可能低于 `P_batt`，故不能作为上界。RBEUB 替换只会抬高能量需求。∎

### 引理 8（TECV 阻止"更保守即继承"的错误单调性）
**陈述**：任何参数变更后，未经受影响窗口再认证的证书不会被门禁接受，故 `Exec_v24` 不会因"降速/加距"被错误放宽，也不会因能量/奇异裕度变化被静默放行。

**证明**：`mark_dirty` 把变更键加入 dirty 集；`fresh` 要求证书未过期且未被 dirty；门禁第 5 步拒绝脏/过期证书。由于门禁是合取，任一新条件失败只会缩小执行集。∎

### 定理（HPC-E++ 五证准入门的安全-合规-可部署完备性）
**陈述**：对任意计划 π，`HPCEPlusPlus.admits(π)=True` 当且仅当 π 同时满足：(1) v23 物理接地安全与规范合规；(2) 用户测试证伪通过（最差队列召回下界与旁路率达标）；(3) 关节空间整臂可执行且冗余零空间安全；(4) 动力学能量上界满足储备不变量；(5) 证书新鲜且未被测试-执行耦合标记为脏。

**证明**：由 `admits` 的五个合取条件与引理 5–8 直接可得；任一条件缺失即拒证，对应五类风险之一。充分性由五个条件的联合保证。∎
