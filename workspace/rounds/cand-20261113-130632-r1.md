# 第 68 轮（承接第 67 轮「SimRAS 仿真增强闭环」IP-233~240；灵感循环第 5 轮；本轮灵感：「双臂协作」×「成功率」）

> 第 67 轮 SimRAS 用「虚拟仿真预训练 + 世界模型滚动推理 + 视觉问答审计」把 RAS 的在线反应式闭环升级为前瞻式闭环。但 SimRAS 仍然默认**单一执行体**：它的所有成功/故障推理都写在一个标量概率上。双臂协作把这一假设击穿——两条臂通过**同一个被操作物体**形成闭合的力/运动链，失败不是两臂失败的并集，而是**耦合结构的断裂**。
>
> 本轮灵感的核心命题是：
>
> **把「单臂风险闭环」升级为「双臂成功率闭环」：以耦合图（coupling graph）为骨架，把任务成功率分解为「最小割支配 + 共因修正」，用 max-min 预算均衡把成功率变成可整形的控制量，并用互指归因打破双臂对称歧义，构成 DARC（Dual-Arm Reliability Closure）。**
>
> DARC 问的不是「某条臂控制多少」，而是「**两条臂的成功率如何经耦合结构互相折算、如何均衡、在哪个同步栅栏处交汇**」。它把「成功率」从被记录的结果，变成被认证、被预算、被前瞻预测的闭环对象。

## 0. 直觉与动机

**灵感 1（双臂协作 → 成功率是拓扑量，不是标量）**
直觉：单臂任务的成功率近似可写成一个标量 `p`；双臂任务里，`p_A·p_B` 只在两臂**独立**时成立。但双臂共享物体、共享标定、共享感知、共享节拍，失败高度相关。若把任务建模为一张耦合图 `G_c`（节点是「抓取/搬运/交接/插入」等承诺单元，边是力闭合、共享物体、共视等物理耦合），任务成功 ⇔ 图不断裂。于是「成功率」是这张图的连通可靠性，是一个**拓扑不变量**，而不是坐标上的一个数。

**灵感 2（成功率 → 最小割支配与 max-min 均衡）**
直觉：连通可靠性由**最弱割**主导。设边 `e` 失败概率 `q_e`，割 `C` 的失败概率 `Q(C)=∏_{e∈C} q_e`，则任务成功率的上界是 `1 - max_C Q(C)`，即「最难维持的那一刀」。这带来一个反直觉但重要的推论：**提升成功率不是把每条边都做得更好，而是让所有割的失败概率尽量相等**。在总预算 `B` 固定（注意力、传感帧率、认证前缀长度都必须分配）时，这就是一个 water-filling / max-min 问题：把预算倾给当前最弱割的边。成功率由此从 KPI 变成**控制律**。

**灵感 3（双臂协作 → 互指归因与双胞胎歧义）**
直觉：双臂故障归因有一个单臂没有的对称性——交换 A/B 两臂，假设 `H_A ↔ H_B` 必须等变。若两臂残差签名 `ρ_A ≈ ρ_B`，后验会收敛到 `P(H_A)≈P(H_B)≈1/2`，形成**双胞胎歧义（twin ambiguity）**：到底是哪条臂坏了，观测本身不可辨识。打破它必须引入**对称破缺探针**：对一臂施加已知微扰 `ε`，看哪一臂的响应异常。这与 RAS 的「情绪探针」、SimRAS 的「反事实审计」是同一族主动辨识思想，但这里的辨识对象是**归因对称性**，而非观测噪声。

**灵感 4（三灵感合流 → DARC：Dual-Arm Reliability Closure）**
DARC 在 SimRAS 之上增加六个组件，且复用其世界模型做前瞻：
1. **CGR Coupling Graph Reasoner**：从任务计划与 WM 滚动预测构建**时变耦合图** `G_c(t)`，为每条物理耦合边估计可靠性 `p_e(t) = ∏_i p_e(t+i)`；
2. **MFA Mutual Fault Attribution**：对双臂残差做**对称等变**的联合归因，输出 `{H_A, H_B, H_X, H_CC, H_S}`，并量化双胞胎歧义度 `τ_twin`；
3. **SRC Success-Rate Certificate**：用最小割支配给出成功率上下界 `[S_lb, S_ub]`，并显式扣除共因项 `κ_cc`；
4. **CAB Coupling-Aware Budget**：在预算约束下做 max-min / water-filling 均衡，把成功率「整形」到目标；
5. **SCP Success-Coupled Prefix**：把认证前缀从单臂 `k` 升级为**成对前缀** `k*_pair`，即下一个安全**同步栅栏**；
6. **DSC Dual-arm Sync Controller**：把 RAS 的 `λ_risk` 升级为**共享** `λ_shared`，并加 `|λ_A-λ_B|≤δ_sync` 的力闭合约束。

**灵感 5（SimRAS / RAS 组件的双臂化升级）**
- **SimRAS 的 WM → CGR-WM**：`fault_head` 不再只预测单臂 `P(H)`，而是预测**边可靠性轨迹** `p_e(t+i)`，使耦合图随时间演化；
- **RAS 的 λ_risk → λ_shared**：双臂必须共享同一风险缩放（否则相对柔顺度失配，破坏力闭合），差值上界由最大允许力残差反解；
- **C-RAS-WM 的 k_wm → k*_pair**：认证前缀不再是单臂步数，而是两臂与同步裕度的**三向取小**；
- **AIC-SimRAS → AIC-D**：干扰集新增 `ℰ_coupling`（共享物体变形、接触瞬断）、`ℰ_sync`（相位漂移）、`ℰ_common`（共享标定/共视漂移）；
- **J_SimRAS → J_DARC**：证书新增 `coupling_graph_hash`、`S_lb`、`C*`、`sync_margin`、`λ_shared`。

## 1. 形式化定义（增量：定义 266–280）

- **定义 266（DARC 总览）**：`DARC = (CGR, MFA, SRC, CAB, SCP, DSC, DARC-WM)`。定位：SimRAS 的「单臂风险闭环」升级为「双臂成功率闭环」。不变式：耦合图构建、割枚举、预算求解、互指归因只在语义流；实时流只做边可靠性增量更新、同步栅栏判定、共享 λ 裁剪，零学习写操作。
- **定义 267（耦合图）**：`G_c = (V, E, ω)`。节点 `v ∈ V` 为承诺单元（grasp_A, grasp_B, transfer, insert…）；边 `e=(u,v) ∈ E` 为物理耦合（力闭合、共享物体、共视/共标定）；耦合强度 `ω_e ∈ [0,1]`，`ω_e=1` 表示完全刚性耦合（边一断任务即失败）。
- **定义 268（边可靠性与割失败）**：边 `e` 在时域 `[t, t+h]` 内保持的概率 `p_e(t)`，`q_e = 1 - p_e`。割 `C ⊆ E` 的失败概率 `Q(C) = ∏_{e∈C} q_e + κ_cc(C)`，其中 `κ_cc(C)` 为共因修正项（共享标定/共视/物体变形导致的**非独立**失败）。
- **定义 269（任务成功率）**：`S_task = P(不存在失败割)`。支配界：`1 - Σ_C Q(C) ≤ S_task ≤ 1 - max_C Q(C)`。记 `C* = argmax_C Q(C)` 为「最弱割」。
- **定义 270（成功率证书 SRC）**：`SRC = (S_lb, S_ub, C*, κ_cc, h)`，其中 `S_ub = 1 - Q(C*)`，`S_lb = 1 - Σ_C Q(C)`，`h` 为前瞻时域。证书由 WM 滚动预测的 `p_e(t+i)` 合成。
- **定义 271（耦合预算与均衡）**：总预算 `B`，分配 `β_e ≥ 0, Σ_e β_e ≤ B`；边可靠性对预算的响应 `q_e(β_e) = q_e^0 · exp(-α_e β_e)`（边际收益递减）。均衡律：`β* = argmin_β max_C Σ_{e∈C} (ln q_e^0 - α_e β_e)`。
- **定义 272（相位同步裕度）**：`m_sync(t) = m_0 - κ_sync·|Δφ(t)|`，`Δφ` 为双臂相位差，`κ_sync` 为耦合刚度。`m_sync ≥ 0` 才允许继续执行成对前缀。
- **定义 273（互指假设集）**：`H ∈ {H_A, H_B, H_X, H_CC, H_S}`，分别为：A 臂故障、B 臂故障、耦合故障（共享物体/接触）、共因故障（共享标定/共视）、同步故障。**对称算子** `Π` 交换 A↔B，要求似然满足 `p(ρ_A, ρ_B | H_A) = p(ρ_B, ρ_A | H_B)`。
- **定义 274（双胞胎歧义度）**：`τ_twin = 1 - |P(H_A | ·) - P(H_B | ·)| ∈ [0,1]`。`τ_twin → 1` 表示 A/B 不可辨识。
- **定义 275（对称破缺探针）**：对臂 `X∈{A,B}` 施加已知微扰 `ε`，观测残差变化 `Δρ_X`。探针的 Fisher 信息 `I_probe = E[(∂ ln p(Δρ | ε,H)/∂ε)^2]`；选择使 `KL(p(·|H_A) || p(·|H_B))` 最大的探针。
- **定义 276（成功率耦合认证前缀）**：`k*_pair = max{k : ∀s≤k, margin_A(s)≥0 ∧ margin_B(s)≥0 ∧ m_sync(s)≥0 ∧ |λ_A(s)-λ_B(s)|≤δ_sync}`。它是两臂下一次可以安全交汇的**同步栅栏**。
- **定义 277（共享风险缩放）**：`λ_shared(t) = min(λ_A(t), λ_B(t))`，并要求 `|λ_A - λ_B| ≤ δ_sync = Δf_max / κ_λ`，其中 `κ_λ` 为柔顺度对 λ 的敏感系数。
- **定义 278（AIC-D 干扰与共因）**：`ℰ_D = ℰ_SimRAS × ℰ_coupling × ℰ_sync × ℰ_common`。`ℰ_common` 显式捕获「共享标定漂移 → 两臂同时失准」「共享物体变形 → 力闭合同时失效」的因果链。
- **定义 279（J_DARC 证书）**：`J_DARC = (J_SimRAS, coupling_graph_hash, S_lb, C*, sync_margin, λ_shared, aic_d_ver)`。Valid ⇔ `Valid(J_SimRAS)` ∧ `S_lb ≥ S_goal` ∧ `m_sync ≥ 0` ∧ `|λ_A-λ_B| ≤ δ_sync`。
- **定义 280（DARC-WM 前瞻成功率）**：用 WM 的 `dyn_head`/`fault_head` 滚动输出 `{p_e(t+i)}_{i=1}^{h}`，构建时变耦合图序列 `{G_c(t+i)}`；前瞻成功率 `S_task(t+h) = ∏_{i=1}^h S_ub(G_c(t+i))` 的保守下界用 `min_i S_ub(G_c(t+i))` 近似。

```python
# IP-241 CGR：耦合图推理器（时变图 + WM 前瞻边可靠性）
class CouplingGraphReasoner:
    def build(self, task_plan, wm, x_prime, act_seq, k=5):
        V = task_plan.commitment_units()          # {grasp_A, grasp_B, transfer, insert}
        E = task_plan.physical_couplings()        # {(u,v): omega}
        preds = wm.rollout(x_prime, act_seq, k=k)
        edges = {}
        for (u, v), omega in E.items():
            p = 1.0
            for pred in preds:                    # 时域内边保持概率
                pH = pred['pH']
                p *= (1.0 - max(pH.get(u, 0.0), pH.get(v, 0.0)))
            p = max(0.02, min(0.999, p))
            edges[(u, v)] = {'omega': omega, 'p': p, 'q': 1.0 - p}
        return CouplingGraph(V, edges)


# IP-242 SRC：最小割支配的成功率证书
class SuccessRateCertificate:
    def certify(self, G, kappa_cc):
        cuts = enumerate_cuts(G)                 # 双臂 |E|<=16，可枚举/或用 max-flow
        Q = {C: self._cut_failure(G, C) + kappa_cc.get(C, 0.0) for C in cuts}
        C_star = max(Q, key=Q.get)
        S_ub = 1.0 - Q[C_star]
        S_lb = max(0.0, 1.0 - sum(Q.values()))    # 联合界
        return SRC(S_lb=S_lb, S_ub=S_ub, C_star=C_star)

    def _cut_failure(self, G, C):
        q = 1.0
        for e in C:
            q *= G.edges[e]['q']
        return q


# IP-243 CAB：max-min / water-filling 预算均衡
def balance_budget(G, B, alpha, eps=1e-3):
    beta = {e: 0.0 for e in G.edges}
    cuts = enumerate_cuts(G)
    while sum(beta.values()) < B - eps:
        # 取当前失败概率最大的割
        C = max(cuts, key=lambda C: sum(
            math.log(max(G.edges[e]['q'], 1e-9)) - alpha[e] * beta[e]
            for e in C))
        e = max(C, key=lambda e: alpha[e])       # 给该割边际增益最大的边
        beta[e] += min(B - sum(beta.values()), 1e-2)
    return beta


# IP-244 MFA：对称等变的互指归因 + 双胞胎歧义检测
class MutualFaultAttribution:
    HYP = ['H_A', 'H_B', 'H_X', 'H_CC', 'H_S']

    def attribute(self, rho_A, rho_B, phi, prior):
        post = {h: prior[h] * self._likelihood(h, rho_A, rho_B, phi)
                for h in self.HYP}
        post = normalize(post)
        twin = 1.0 - abs(post['H_A'] - post['H_B'])
        return post, twin

    def _likelihood(self, h, rho_A, rho_B, phi):
        # 强制对称等变：h=H_A 用 (rho_A,rho_B)，h=H_B 用 (rho_B,rho_A)
        if h == 'H_B':
            rho_A, rho_B = rho_B, rho_A
        base = self._signature_match(h, rho_A)
        if h == 'H_S':
            base *= math.exp(-abs(phi) / self.tau_phi)
        return base

    def choose_probe(self, post):
        # 选使 A/B 可辨识 KL 最大的单臂微扰
        return max(PROBES, key=lambda p: p.kl_identify(post))


# IP-245 SCP：成功率耦合认证前缀（同步栅栏）
def coupled_prefix(G, A_A, A_B, m, lam, delta_sync):
    k_best = 0
    for k in range(1, min(len(A_A), len(A_B), m) + 1):
        if margin(A_A[k - 1], 'A', G) < 0: break
        if margin(A_B[k - 1], 'B', G) < 0: break
        if sync_margin(k) < 0: break              # 同步栅栏先到
        if abs(lam['A'] - lam['B']) > delta_sync: break
        k_best = k
    return k_best


# IP-250 DARC 闭环
def DARC_round(M, obs):
    # 1) SimRAS 前向（单臂前瞻闭环，复用）
    sim = M.simras_round(obs)

    # 2) CGR：时变耦合图
    G = M.cgr.build(M.task_plan, M.wm, sim.x_prime, sim.act_seq, k=5)

    # 3) MFA：互指归因；双胞胎歧义 -> 对称破缺探针
    rho_A, rho_B = M.vista.fir.signature_split(sim.residual_log)
    post_H, twin = M.mfa.attribute(rho_A, rho_B, sim.phi, M.prior_H)
    if twin > M.tau_twin:
        probe = M.mfa.choose_probe(post_H)
        M.execute_coupling_probe(probe)           # 单臂微扰，破缺 A/B 对称
        rho_A, rho_B = M.vista.fir.signature_split(M.vista.residual_log)
        post_H, twin = M.mfa.attribute(rho_A, rho_B, sim.phi, M.prior_H)

    # 4) SRC：成功率证书（含共因修正）
    kappa_cc = M.cc_estimator.estimate(G, post_H)
    src = M.src.certify(G, kappa_cc)

    # 5) CAB：若成功率下界不足，做预算均衡后再认证
    if src.S_lb < M.S_goal:
        beta = balance_budget(G, M.B_budget, M.alpha)
        G = M.cgr.apply_budget(G, beta)
        src = M.src.certify(G, kappa_cc)

    # 6) DSC + SCP：共享 λ、同步栅栏
    lam = M.dsc.share_lambda(sim.lambda_risk, delta_sync=M.delta_sync)
    k_pair = coupled_prefix(G, sim.A_A, sim.A_B, sim.m_ras, lam, M.delta_sync)

    # 7) 双前缀派发
    tau_A = M.vista.pi_sigma.prefix_dispatch(sim.A_A[:k_pair]) * lam['A']
    tau_B = M.vista.pi_sigma.prefix_dispatch(sim.A_B[:k_pair]) * lam['B']

    return {'k_pair': k_pair, 'S_lb': src.S_lb, 'S_ub': src.S_ub,
            'C_star': src.C_star, 'twin': twin, 'lambda': lam,
            'post_H': post_H, 'tau_A': tau_A, 'tau_B': tau_B}
```

## 3. 推导

**引理 14（最小割支配）** 设 `C*` 为最弱割，`S_task = 1 - P(∪_C 割C失败)`。联合界给出 `|S_task - (1 - Q(C*))| ≤ Σ_{C≠C*} Q(C)`。若存在分离间隙 `Q(C*) ≥ (1+γ)·Q(C), ∀C≠C*`，则 `S_task = 1 - Q(C*) + O(γ^{-1} Q(C*))`。即成功率由最弱割**支配**，其余割只造成二阶修正。

**引理 15（预算均衡最优性）** 最大化 `S_ub = 1 - max_C Q(C)` 等价于最小化 `max_C Σ_{e∈C}(ln q_e^0 - α_e β_e)`。目标 `max` of affine 函数在 `β` 上是凸的，约束 `Σβ_e ≤ B, β_e ≥ 0` 为单纯形。KKT 条件 ⇒ 存在对偶变量 `μ`，最优解使所有**活跃割**的加权边际收益相等：`α_e · q_e(β_e) / Q(C) = μ`（water-filling）。故均衡不是启发式，而是该凸问题的唯一最优（在割族可分时）。

**引理 16（对称破缺可辨识）** 在 `Π` 对称下，当 `ρ_A = ρ_B` 时似然满足 `p(ρ_A,ρ_B|H_A)=p(ρ_A,ρ_B|H_B)`，后验必为 `P(H_A)=P(H_B)=1/2`，`τ_twin=1`。存在探针 `ε` 使 `KL(p(·|H_A,ε) || p(·|H_B,ε)) = κ_probe > 0` 时，重复 `n` 次探针的错误概率 `P_e ≤ exp(-n·κ_probe)`。故**可辨识当且仅当存在产生正 KL 的对称破缺探针**；无探针时归因不可辨识，任何强行判决都只是先验。

**定理 14（同步栅栏安全）** 若 `k ≤ k*_pair`，则由定义 276，`∀s≤k` 两臂 margin `≥0` 且 `m_sync(s)≥0`；又由定义 277 的 `|λ_A-λ_B|≤δ_sync`，共享物体的力残差满足 `|Δf| ≤ κ_λ·|λ_A-λ_B| ≤ κ_λ·δ_sync = Δf_max`。因此成对前缀执行期间力闭合不被破坏。

**定理 15（单臂退化一致性）** 当所有耦合边 `ω_e → 0` 且 `κ_sync → 0` 时，`G_c` 退化为两条不相交路径，`C*` 退化为单臂割，`S_lb → p_A·p_B`（串联可靠性），`k*_pair → min(k_A, k_B)`，`λ_shared → λ_risk`。此时 DARC 精确退化为两个独立 SimRAS 环路，保证**向后兼容**。

**定理 16（端到端成功率下界）** 在引理 14–16 与 SimRAS 定理 11 下，以概率 `≥1-δ`：`S_task ≥ S_lb - ε_wm - ε_cc`，其中 `ε_wm` 为 WM 边可靠性滚动误差（引理 11 的累积界），`ε_cc` 为共因项 `κ_cc` 的估计误差；且成对前缀的违规概率为 0（定理 14）。特别地，若忽略共因项（`κ_cc≡0`），`S_ub` 会系统性偏乐观 `Σ_C κ_cc(C)`。

## 6. 本轮最大风险

**一句话**：DARC 的全部成功率界都建立在「给定耦合图后各边失败近似独立」这一分解假设上，但双臂协作中**真正的杀手恰是共因失败**（共享标定漂移、共享物体变形、共视误差会同时击穿多条边），这种强正相关会使最小割的乘积分解与联合界同时失效，导致系统**系统性地高估成功率、过度认证**（`S_lb` 虚高、`k*_pair` 过长），把本应提前停机的双臂任务放行到真实故障发生——这是本轮所有理论依赖的核心假设：**共因相关 `κ_cc` 可被观测并显式扣除，且扣除后的残余相关性足够弱**。

**次级风险与缓解**：
1. **预算均衡的割族爆炸**：`|E|` 增大时割枚举不可行 → 双臂场景限制为 series-parallel 图，用 max-flow 求最弱割；
2. **探针扰动副作用**：对称破缺探针可能引入额外接触风险 → 仅在 `τ_twin>0.7` 且任务处于低力阶段时触发；
3. **WM 前瞻误差放大**：`h` 步滚动误差随 `h` 增长 → 前瞻时域 `h≤5`，并以 `min_i S_ub` 作保守下界；
4. **同步裕度标定偏差**：`κ_sync` 随物体刚度变化 → 在线辨识物体刚度并自适应更新；
5. **共享 λ 过度保守**：取 `min` 可能牺牲单臂性能 → 仅在力闭合边活跃时收紧，非耦合阶段回退独立 λ。

**定义 268（边可靠性与割失败）**
```
Q(C) = ∏_{e∈C} q_e + κ_cc(C)
```
`κ_cc(C)` 为共享标定/共视/物体变形导致的非独立失败修正。

**定义 269（任务成功率）**
```
1 - Σ_C Q(C) ≤ S_task = P(无失败割) ≤ 1 - max_C Q(C)

```

**定义 272（相位同步裕度）** `m_sync=m_0-κ_sync·|Δφ| ≥ 0` 才允许执行成对前缀。

# IP-241 CGR
class CouplingGraphReasoner:
    def build(self, task_plan, wm, x_prime, act_seq, k=5):
        preds = wm.rollout(x_prime, act_seq, k=k)
        edges = {}
        for (u, v), omega in task_plan.physical_couplings().items():
            p = 1.0
            for pred in preds:
                pH = pred['pH']
                p *= (1.0 - max(pH.get(u, 0.0), pH.get(v, 0.0)))
            p = max(0.02, min(0.999, p))
            edges[(u, v)] = {'omega': omega, 'p': p, 'q': 1.0 - p}
        return CouplingGraph(task_plan.commitment_units(), edges)


# IP-242 SRC
class SuccessRateCertificate:
    def certify(self, G, kappa_cc):
        cuts = enumerate_cuts(G)
        Q = {C: self._cut_failure(G, C) + kappa_cc.get(C, 0.0) for C in cuts}
        C_star = max(Q, key=Q.get)
        return SRC(S_lb=max(0.0, 1.0 - sum(Q.values())),
                   S_ub=1.0 - Q[C_star], C_star=C_star)

    def _cut_failure(self, G, C):
        q = 1.0
        for e in C:
            q *= G.edges[e]['q']
        return q


# IP-243 CAB
def balance_budget(G, B, alpha, eps=1e-3):
    beta = {e: 0.0 for e in G.edges}
    cuts = enumerate_cuts(G)
    while sum(beta.values()) < B - eps:
        C = max(cuts, key=lambda C: sum(
            math.log(max(G.edges[e]['q'], 1e-9)) - alpha[e] * beta[e]
            for e in C))
        e = max(C, key=lambda e: alpha[e])
        beta[e] += min(B - sum(beta.values()), 1e-2)
    return beta


# IP-244/245 MFA + 对称破缺探针
class MutualFaultAttribution:
    HYP = ['H_A', 'H_B', 'H_X', 'H_CC', 'H_S']

    def attribute(self, rho_A, rho_B, phi, prior):
        post = {h: prior[h] * self._likelihood(h, rho_A, rho_B, phi)
                for h in self.HYP}
        post = normalize(post)
        return post, 1.0 - abs(post['H_A'] - post['H_B'])

    def _likelihood(self, h, rho_A, rho_B, phi):
        if h == 'H_B':
            rho_A, rho_B = rho_B, rho_A       # 对称等变
        base = self._signature_match(h, rho_A)
        if h == 'H_S':
            base *= math.exp(-abs(phi) / self.tau_phi)
        return base

    def choose_probe(self, post):
        return max(PROBES, key=lambda p: p.kl_identify(post))


# IP-246/247 SCP + DSC
def coupled_prefix(G, A_A, A_B, m, lam, delta_sync):
    k_best = 0
    for k in range(1, min(len(A_A), len(A_B), m) + 1):
        if margin(A_A[k-1], 'A', G) < 0: break
        if margin(A_B[k-1], 'B', G) < 0: break
        if sync_margin(k) < 0: break
        if abs(lam['A'] - lam['B']) > delta_sync: break
        k_best = k
    return k_best

## 4. 推导

**引理 14（最小割支配）** 设 `C*` 为最弱割。`S_task=1-P(∪_C 割C失败)`，联合界给出 `|S_task-(1-Q(C*))| ≤ Σ_{C≠C*} Q(C)`。有分离间隙 `Q(C*)≥(1+γ)Q(C)` 时，`S_task=1-Q(C*)+O(γ^{-1}Q(C*))`。成功率由最弱割支配。

**引理 15（预算均衡最优性）** 最大化 `S_ub=1-max_C Q(C)` 等价于最小化 `max_C Σ_{e∈C}(ln q_e^0-α_e β_e)`。目标为 `β` 的凸函数，约束为单纯形，KKT ⇒ 各活跃割的加权边际收益相等（water-filling），故均衡是凸问题唯一最优。

**引理 16（对称破缺可辨识）** `Π` 对称且 `ρ_A=ρ_B` 时后验必为 `P(H_A)=P(H_B)=1/2`（`τ_twin=1`）。存在探针 `ε` 使 `KL(p(·|H_A,ε)||p(·|H_B,ε))=κ_probe>0` 时，`n` 次探针错误概率 `P_e≤exp(-n·κ_probe)`。可辨识当且仅当存在正 KL 的对称破缺探针。

**定理 14（同步栅栏安全）** 若 `k≤k*_pair`，则 `∀s≤k` 两臂 margin `≥0`、`m_sync(s)≥0`；又 `|λ_A-λ_B|≤δ_sync`，力残差 `|Δf|≤κ_λ·|λ_A-λ_B|≤Δf_max`，力闭合不被破坏。

**定理 15（单臂退化一致性）** 当 `ω_e→0` 且 `κ_sync→0`，`G_c` 退化为两条不相交路径，`S_lb→p_A·p_B`，`k*_pair→min(k_A,k_B)`，`λ_shared→λ_risk`。DARC 精确退化为两个独立 SimRAS 环路。

**定理 16（端到端成功率下界）** 在引理 14–16 与 SimRAS 定理 11 下，以概率 `≥1-δ`：`S_task ≥ S_lb-ε_wm-ε_cc`，成对前缀违规概率为 0。若忽略共因项 `κ_cc≡0`，`S_ub` 将系统性偏乐观 `Σ_C κ_cc(C)`。

## 6. 本轮最大风险

**一句话**：DARC 的所有成功率界都依赖「给定耦合图后各边失败近似独立」的乘积分解，而双臂协作中最致命的恰是**共因失败**（共享标定、共享物体变形、共视误差同时击穿多条边），强正相关会让最小割乘积分解与联合界同时失效，导致**成功率被系统性高估、认证过度宽松**（`S_lb` 虚高、`k*_pair` 过长），把本应提前停机的任务放行到真实故障发生——核心假设是：**共因相关 `κ_cc` 可被观测并显式扣除，且残余相关性足够弱**。

**次级风险与缓解**：
1. **割族爆炸**：`|E|` 增大时割枚举不可行 → 双臂限制为 series-parallel 图，用 max-flow 求最弱割；
2. **探针副作用**：破缺探针可能引入接触风险 → 仅在 `τ_twin>0.7` 且低力阶段触发；
3. **WM 前瞻误差**：误差随 `h` 增长 → 前瞻 `h≤5`，以 `min_i S_ub` 作保守下界；
4. **同步刚度漂移**：`κ_sync` 随物体刚度变化 → 在线辨识刚度并自适应更新；
5. **共享 λ 过度保守**：`min` 可能牺牲单臂性能 → 仅力闭合边活跃时收紧，非耦合阶段回退独立 λ。
