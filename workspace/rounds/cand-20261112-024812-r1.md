# 第 58 轮（承接第 57 轮「少样本元推断×跨模态对账×个性化有界信任」IP-133~138；灵感循环第 4 轮；本轮灵感：「场景泛化」×「场景驱动创新」）

> 第 57 轮把"证据说可信"做成了少样本可校准、跨模态可对账、个性化有界的闭环，但它的风险自陈（"坏先验普遍"）暴露了一个更根本的问题：**整套证书 J_p 是"某个部署场景"的证书，而不是"任意部署场景"的证书**。所有阈值（θ_ood、θ_D、θ_voi、ε_meta、δ_f）都由工程师针对一个场地/任务/操作者群体手工标定；换一个场景（新任务、新地形分布、新操作者、新风险预算），证书的主体随之失效，而系统没有任何机制告诉部署者"哪一部分还成立、哪一部分必须重证"。更糟的是，第 57 轮把安全押在"元先验"上，而元先验的正确性又依赖训练语料覆盖部署场景——场景泛化问题在这里被压缩成了一个隐含假设。本轮两个灵感形成一对张力：**场景泛化**要求把安全做成"与场景无关的不变量"，把效率做成"随场景变化的可调层"；**场景驱动创新**则要求让每个新场景主动暴露假设、甚至催生新证据类与探针——即让场景成为"创新与测试的发生器"。二者方向相反：泛化想抹去场景特殊性，场景驱动想利用场景特殊性。本轮用**冻结的安全核 + 有界的场景条件层 + 迁移证书**把这对张力变成可证伪的结构：核不因场景而变（连元先验都不能进核），效率层可以因场景而变但只能走"信念更准/动作更保守"两个安全通道，二者之间的边界由一张可机器检查的三色迁移证书显式声明。核心命题从"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"场景不变核可泛化、场景条件层可驱动、迁移边界可证伪的迁移式可信"**。

核心矛盾：
- **H29（泛化 vs 具体）**：要泛化就得把场景特殊性剥离出去，安全核越普适越保守；要性能就得利用场景特殊性，越贴合场景越没有泛化保证。一个"放之四海而皆准"的核可能保守到不可用，一个"为某场地调优"的系统可能根本不能迁移。
- **H30（迁移证书的诚实与无穷回退）**：迁移证书本身也是一个模型——它声称"假设 a 在新场景不变"，但凭什么相信这个声明？验证验证者会无穷回退。更隐蔽的是，所谓"场景不变核"可能暗含旧场景的假设（例如模态条件独立、操作者风险偏好有界、地形统计平稳），于是泛化成了把旧偏见洗白成普适安全的洗白机。
- **H31（场景驱动 vs 安全棘轮）**：让场景驱动创新，就是把"改机制/改阈值/加证据类"的权力交给部署压力；这正是第 57 轮"个性化只能单向"想防的棘轮。若新场景可以合法地要求放松某个核参数，安全核就名存实亡。

## 0. 直觉与动机

**灵感 1（场景泛化 → 冻结安全核 + 分层 ODD + 迁移证书）**
直觉：第 57 轮的 J_p 像一张"针对某条航线的适航证"，换航线就得重新审定，但没人说清楚哪些条款是"所有航线通用"、哪些是"这条航线特有"。场景泛化的第一性做法是**把证书拆成两层**：一层是**冻结的安全核 SISK**——无证据不承诺、交互单调、信任单向、跨模态仅限 L1 等，对任意场景签名 σ_S 都必须成立，且核内不允许出现任何可调的场景参数；另一层是**场景条件层 SCA**——阈值、元先验、探针策略都可以是 σ_S 的函数，但只能沿"信念更准或动作更保守"两个方向演化，且有界速率。层与层之间的迁移不再靠口头声明，而靠**三色迁移证书 J_g**：把每条假设标成绿（场景不变，可携带）、黄（只需收紧，安全）、红（可能被违反，必须重证或降到 L0）。这样"能不能迁移"从一个工程判断变成一个可检查、可失败的证明义务。配套的**分层 ODD** 把第 57 轮的区域级 OOD 门抬到场景级：不只问"这个区域像不像训练过的区域"，还问"整个部署像不像被验证过的场景"，两者任一漂移都触发降级到"已知安全子场景"或 L0。

**灵感 2（场景驱动创新 → 场景条件自适应 + 假设审计 + 对抗场景合成）**
直觉：既然效率必须贴合场景，就别把场景当噪声，当**实验设计者**。第 57 轮的最大盲区是"语料里没有的世界"——被动等部署撞上盲区太晚。场景驱动创新把它反转为：**让场景主动生成测试**。每当检查点的失败/分歧/回退超出预期，**假设审计 AGA** 从失败反推"哪条绿/黄假设其实被违反了"，再**对抗合成**一批专门攻击这条假设的虚拟场景（材质×坡度×季节×操作者类型的组合），用安全核 SISK 作为不可违反的护栏去搜索；找到反例就把该假设从绿降黄、从黄降红。更激进的是**能力生长**：若审计反复证明现有证据类（EV-probe/visit/margin/xmodal/human）不足以覆盖某类场景，系统可以提出**新的证据类**（例如"长时热成像一致性"），但新能力必须对安全核给出健全性证明、且不得放松任何核约束——**场景可以驱动系统变强，不能驱动系统变松**。

**灵感 3（两灵感合流 → 安全核的可证伪性成为第一公民）**
直觉：前两轮的所有机制（元推断、对账、个性化）都建立在"某场景下假设成立"之上，本轮把它们统一收进"安全核 + 条件层"。但真正的难点是 H30：谁来保证核真的是不变的？答案是**把可证伪性写进核的定义**——安全核必须携带"预条件 + 能失败的测试套件"；一个不能在对抗合成场景上失败的核，不算被认证的核（"不可证伪的不变量 = 信仰"）。于是场景驱动创新不仅服务性能，更是**核的证伪引擎**：它越是努力攻击核，核的可信度越高；若它找到核的反例，则触发全局隔离（scenario quarantine）——不是打个补丁，而是冻结部署、重跑全场景回归，直到核被重新证明。这把第 56 轮"一切判定器走隔离"、第 57 轮"元模型走隔离"再推一步为"**连安全核本身也要走隔离**"。

**灵感 4（PCE++ → 场景先过闸、再复用第 57 轮内核）**
直觉：第 57 轮的 PCX 是一个"场景内"算子；本轮 PCE++ 在它前面加两道闸——**场景 ODD 闸**（σ_S 漂移 ⇒ 降级）与**核检查闸**（SISK 不通过 ⇒ 拒绝），后面复用 PCX，失败再回流到假设审计与迁移证书。所有新增机制仍只经两个安全通道起作用，故交互单调性得以从"场景内"延伸到"跨场景"。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（场景签名与场景契约 SSC）** 场景签名 σ_S=(τ,𝒯,𝒪,β,𝒞,h)：任务型 τ、地形/材质分布 𝒯、操作者群体 𝒪、风险预算 β、接触谱 𝒞、时域 h。声明签名 σ_S^decl 与运行时检测 σ_S^det=(τ̂,𝒯̂,Ô,β̂,𝒞̂,ĥ) 的距离 d_S=Σ_i w_i·dist_i；场景契约要求 d_S≤θ_odd，否则触发场景级 OOD（定义 141）。

**定义 140（场景不变安全核 SISK）** 一个四元组核 K=(E,I,T,N)：E 证据门健全（无证据类即拒）、I 交互单调（只经"信念更准/动作更保守"）、T 信任单向有界、N 无证据不承诺。核满足两条元约束：(i) **无场景参数**——K 的任何谓词都不读取 Θ_S 中的可调参数；(ii) **可证伪**——K 附带预条件集 Pre(K) 与一个测试套件 T_K，存在对抗场景 σ^† 使 T_K 失败（否则 K 视为未认证）。K 的变更只能通过全场景重证（scenario quarantine），不得增量修补。

**定义 141（分层 ODD 与场景级 OOD，HODD）** 两层门：区域级 OOD 门 n_r(o)（第 57 轮，判断单区域观测是否分布外）；场景级 OOD 门 n_S(σ^det)=−log p̂(σ^det|σ^decl)>θ_odd。任一门越界 ⇒ 系统进入"已知安全子场景" 𝒮_safe(σ^det) 或 L0-only；若不存在可达子场景，则安全停。子场景本身必须携带其 J_g（定义 142）。

**定义 142（三色迁移证书 J_g）** 给定原场景 A 的假设集 𝒜_A 与新场景声明 σ_B，逐条染色：绿（scenario_invariant(a) 且 a 不引用 A 特有参数）、黄（monotone_safe_under(a,σ_B)，仅需收紧阈值）、红（其余）。J_g=(A→B, 染色, 每条的见证/反例, 重证计划)。部署条件：**无红假设**，或所有红假设已有重证且重证只收紧动作。红假设未重证 ⇒ 仅 L0。

**定义 143（场景条件自适应 SCA）** 场景条件参数 Θ_S={θ_ood,θ_D,θ_voi,ε_meta,δ_f,k_probes,...} 是 σ_S 的函数。更新算子 δΘ 必须满足：不触碰 K；epistemic 方向只允许加宽后验/增加证据，动作方向只允许降低速度/增大佐证数/缩短 τ_int/降档；单步 |δθ|≤Δ_S，累计变化受速率约束；每次更新写 scen_params_log。**核参数化 = 类型错误**。

**定义 144（假设审计与能力生长 AGA）** 失败集 ℱ ⇒ 违反假设集 V=infer_violated(ℱ)；对抗合成 𝒜𝒮=argmax_{σ^†∈Synth} 1[σ^†⊨Pre(K) ∧ σ^† 违反 V]（在核护栏内搜索反例）；若 |𝒜𝒮|>0 ⇒ 相应假设降色。能力生长：候选新证据类 e_new 可注册当且仅当 (i) sound_against(e_new,K) 且 (ii) 不放松任何核约束（relaxes(e_new,K)=∅）；注册只增不改。场景驱动创新的正式边界：**创新可扩张证据空间与保守动作空间，永不扩张核的放行空间**。

def kernel_check(system, sigma_S):                 # IP-139: 冻结核，不读 Θ_S
    assert no_kernel_param(system, sigma_S)         # 核内无场景参数
    assert evidence_gate_sound(system)              # E
    assert interaction_monotone(system)             # I
    assert trust_single_direction(system)           # T
    assert no_commit_without_evidence(system)       # N
    return 'KERNEL_OK' if falsifiable(system) else 'UNFALSIFIABLE_REJECT'

def transfer_certificate(A, sigma_B, assumptions):  # IP-142: 三色
    colors = {a: ('green' if scenario_invariant(a) and not refs_private(a, A)
                  else 'yellow' if monotone_safe_under(a, sigma_B)
                  else 'red') for a in assumptions}
    if any(c == 'red' and not reestablishable(A, sigma_B, a)
           for a, c in colors.items()):
        return ('restrict_L0', colors)
    return ('ok', colors)

def scenario_adaptive_step(theta_S, ev, sigma_S):   # IP-143: 单向有界

    return apply(theta_S, d)                         # 记录 scen_params_log

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| SISK | O(\|T_K\|)（离线）| O(\|K\|) 静态 | 无场景参数、可证伪 |
| SSC/HODD | O(d_S)/检查点 | O(\|σ_S\|) | 声明-检测距离诚实 |
| SCA | O(\|Θ_S\|) | O(\|Θ_S\|) | 不触碰核、单向有界 |
| J_g | O(\|𝒜\|·\|σ_B\|) | O(\|𝒜\|) | 染色诚实、无未重证红假设 |
| AGA | O(\|Synth\|·C_eval) | O(\|𝒜𝒮\|) | 合成受核护栏、能力只增 |
| PCE++ | +O(d_S)+O(\|T_K\|) | O(\|V\|+\|σ\|) | 场景闸+核闸+第 57 轮终止 |

**正确性定理（Transferable Calibrated Soundness, TCS 概要）**：在 A37–A40 上加 (A41) 核不变性：K 的每条谓词在任意 σ_S∈ODD 下成立（由可证伪测试套件支持；反例未被发现不等于成立）；(A42) 迁移证书诚实：绿/黄/红染色与见证无伪、红假设未重证时不放行；(A43) 场景条件层单向有界且不触碰核；(A44) 对抗合成在核护栏内且能力生长只增不放。则：(i) 跨场景承诺失效率 ≤ 场景内失效率（第 57 轮界）+ δ_odd，红假设未证则根本不进入承诺（可用性归零而非安全性归零）；(ii) 交互单调性从场景内延伸到跨场景；(iii) 若 A41 被反例推翻，系统退化为"仅 L0"而非错误泛化。

## 6. 本轮最大风险

**一句话**：本轮把"跨场景安全"押在"存在一个真正场景不变的核"上，风险从第 57 轮的"坏先验普遍"升级为"坏假设普适"——若安全核在定义时就暗含了旧场景的假设（模态条件独立、操作者风险偏好有界、地形统计平稳），那么迁移证书会把"在 A 上验过"洗成"对一切 σ_S 安全"，而场景驱动创新又会不断生产只针对旧假设审计过的新能力，使一个**无法被任何单一场景证伪的核**成为最大盲区；必须以可证伪核（预条件+能失败的测试套件）、红假设强制 L0、能力只增不放、以及"核变更=全场景隔离重证"四重约束，宁可承认"未认证"也不制造"普适安全"的幻觉。

## 2. 关键算法伪代码

### IP-139 SISK（场景不变安全核）

```python
def kernel_check(system, sigma_S):
    if not no_kernel_param(system, sigma_S):
        return ('reject', 'kernel_parametrized')       # 核内读取 Θ_S = 类型错误
    checks = [evidence_gate_sound(system),             # E: 无证据类即拒
              interaction_monotone(system),            # I: 只经两安全通道
              trust_single_direction(system),          # T: 单向有界
              no_commit_without_evidence(system)]      # N
    if not all(checks):
        return ('reject', 'kernel_violation', checks)
    if not falsifiable(system, Pre(K), T_K):           # 可证伪性
        return ('reject', 'unfalsifiable_kernel')
    return ('ok', 'KERNEL_OK')

def kernel_amend(K, proposal):
    # 核永不增量修补；任何变更 → 全场景隔离重证
    return scenario_quarantine(revalidate(K + proposal, all_scenarios()))
```

def hierarchical_odd_gate(sig_decl, sig_det, M):

### IP-141 SCA（场景条件自适应，单向有界）

```python
def sca_update(theta_S, ev, sigma_S):
    delta = propose_delta(ev, sigma_S)
    safe = {}
    for k, v in delta.items():
        if k in KERNEL_PARAMS: continue                # 禁改核参数
        if riskier(v): continue                        # 只允许更保守
        if abs(v) > Delta_S[k]: v = sign(v) * Delta_S[k]  # 速率有界
        safe[k] = v
    theta_S = apply(theta_S, safe)
    scen_log.append((sigma_S, safe, ev))
    return theta_S
```

### IP-142 J_g（三色迁移证书）

```python
def transfer_certificate(A, sigma_B, assumptions):
    colors, witness, recheck = {}, {}, {}
    for a in assumptions:
        if scenario_invariant(a) and not refs_private(a, A):
            colors[a] = 'green'
        elif monotone_safe_under(a, sigma_B):
            colors[a] = 'yellow'; recheck[a] = tighten_plan(a, sigma_B)
        else:
            colors[a] = 'red'; witness[a] = search_counterexample(a, sigma_B)
    reds = [a for a, c in colors.items() if c == 'red']
    if reds and not all(reestablishable(A, sigma_B, a) for a in reds):
        return ('restrict_L0', Jg(A, sigma_B, colors, witness, recheck))
    return ('ok', Jg(A, sigma_B, colors, witness, recheck))
```

def assumption_audit(failures, corpus):

        constraints=Pre(K), budget=synth_budget,

    for a in V:

        if persistent(a): recolor(a, to='red'); request_recheck(a)
    return V, counterexamples

def capability_grow(e_new):
    if not sound_against(e_new, K): return ('reject', 'unsound_evidence')
    if relaxes(e_new, K): return ('reject', 'relaxes_kernel')  # 只增不放
    return register_evidence_class(e_new)                       # 只扩张证据空间

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SISK | O(\|T_K\|) 离线 | O(\|K\|) 静态 | 无场景参数、可证伪（A41）|
| SSC/HODD | O(d_S)/检查点 | O(\|σ_S\|) | 声明-检测诚实、子场景自带 J_g |
| SCA | O(\|Θ_S\|)/更新 | O(\|Θ_S\|) | 不触核、单向有界（A43）|
| J_g | O(\|𝒜\|·\|σ_B\|) | O(\|𝒜\|) | 染色诚实、红假设限 L0（A42）|
| AGA | O(\|Synth\|·C_eval) | O(\|𝒜𝒮\|) | 合成受核护栏、能力只增（A44）|
| PCE++ | O(d_S)+O(\|T_K\|)+PCX | O(\|V\|+\|σ\|) | 场景闸+核闸+PCX 终止 |

**正确性定理（Transferable Calibrated Soundness, TCS）**
假设 A22–A32、A33–A36、A37–A40 成立；新增 **(A41)** 核不变性：K 的每条谓词对任意 σ_S∈ODD 成立，且 K 可证伪（Pre(K)、T_K 存在且可能失败；"未发现反例"不作为成立证据）；**(A42)** 迁移证书诚实：三色染色与见证/反例无伪，红假设未重证时只放行 L0；**(A43)** 场景条件层单向有界：SCA 不触碰 K，所有更新只经"信念更准/动作更保守"，单步与速率有界；**(A44)** AGA 在核护栏内合成、能力生长只增不放（relaxes(e_new,K)=∅）。则：

1. **跨场景承诺健全性**：P(fail|σ_B) ≤ P(fail|σ_B, 场景内界) + δ_odd；红假设未证则根本不进入承诺（可用性归零而非安全性归零）；
2. **交互单调性跨场景保持**：SCA/AGA 只能经 (a) 校准信念更新或 (b) 更保守动作参数影响系统；场景驱动创新不产生升险通道；
3. **核证伪的诚实退化**：若对抗合成找到 K 的反例，系统进入 scenario_quarantine 并退化为 L0，而非错误泛化；
4. **部署界**：

```
P_safe(σ_B) ≥ 1 − Σ_cp (第 57 轮界) − δ_odd − P(子场景误选)
              − P(红假设漏标) − P(K 的反例未被合成发现)
```

关键：**泛化不靠"元先验更对"，而靠"核与场景解耦"**——效率押在可变的场景条件层，安全押在冻结且可证伪的核；**场景驱动创新的边界是"只增证据/只减动作"，永不放宽核**；**未认证就承认未认证**（红假设/核反例 ⇒ L0），不制造"普适安全"幻觉。

```
根信任 + 能力格
│
├─ L0 分布式底座与执行边 (GPC/SEN/TBC)
├─ L0.5 任务迁移与仿真证据 (TIX,XFR,CRC,SFE,FDR,RAB,DST,SBC)
├─ L0.5+ 鲁棒性层 (TRO,RXC,RCO,REX,RTA,TRC,RUR)
├─ L0.5++ 动作-协同层 (ACS,SCOM,CEC,AEC,JTC)
├─ L0.5* 证据-交互层 (SMM,PCE,BVK,ISE,TAF,MEC)
├─ L0.5*⁺ 元认知-信任层 (MFSL,XMC,PTM,MXI,FSE,J_p)
├─ L0.5# 场景泛化层 (SISK,SSC/HODD,SCA,J_g,AGA) ← v58 新增（横切，非层级）
├─ L1 几何感知
├─ L2 任务/上下文/记忆/语音
...
└─ L6 原型证伪/XFER/LFF/IXD
```

说明：场景泛化层不是新的垂直能力层，而是**横切所有层的元层**——它规定"哪些谓词可在层间迁移（绿/黄）、哪些必须重证（红）"，因此画为横切带 `L0.5#`。

JCPS 输出扩展为：
`(..., J_p, σ_S, Θ_S, J_g, 𝒮_safe, scen_params_log, odd_state, AGA_log, J_t)`

其中新增：`σ_S` 场景签名；`Θ_S` 场景条件参数；`J_g` 三色迁移证书；`𝒮_safe` 已知安全子场景；`scen_params_log` 场景条件更新日志；`odd_state` 分层 ODD 状态；`AGA_log` 假设审计与能力生长日志；`J_t` 组合迁移证书。

云边协议 CEB++ → **CEB#**：云端下发的是**场景条件层**的增量（Θ_S 建议与合成场景库），边端回传的是**假设违反/核反例证据**；任何核（K）的变更都不能由云端下发，只能在边端/离线触发 scenario_quarantine 全场景重证——**云可以教系统更懂场景，不能教系统改核**。

## 6. 本轮最大风险

**一句话**：本轮把"跨场景安全"押在"存在一个真正场景不变的核"上，风险从第 57 轮的"坏先验普遍"升级为"坏假设普适"——若安全核在定义时就暗含了旧场景的假设（模态条件独立、操作者风险偏好有界、地形统计平稳），迁移证书会把"在 A 上验过"洗成"对一切 σ_S 安全"，而场景驱动创新又不断生产只针对旧假设审计过的新能力，使一个**无法被任何单一场景证伪的核**成为最大盲区；必须以可证伪核（预条件+能失败的测试套件）、红假设强制 L0、能力只增不放、以及"核变更=全场景隔离重证"四重约束，宁可承认"未认证"也不制造"普适安全"的幻觉。
