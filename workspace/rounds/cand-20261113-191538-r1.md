# 第 69 轮（承接第 68 轮「CALM-RAS 自标定·自监督·单模型多任务闭环」IP-243~252；灵感循环第 1 轮；本轮灵感：「预测性维护」×「跨任务泛化」）

> R68 的 CALM-RAS 把「标定」从离线常数升级为一等公民在线潜变量，解决了「我的测量还准吗」。但它自陈的最大风险暴露了一个致命盲点：**标定越强，缓变故障越隐形**。COF 的速率限制（ω_cal ≈ 0.1 Hz）只保证频率 ω_f ≥ 3ω_cal 的快故障不被吸收；任何慢于 0.1 Hz 的真实退化（轴承磨损、密封慢泄漏、渐进老化、缓慢松动）都会被当作「漂移」标定掉，然后被遗忘——而 R68 的整条安全链（CFA → CAC → λ_floor）都建立在「标定后的残差才进入故障归因」之上，被标定吸收的东西根本不会进入归因。
>
> 本轮两个灵感恰好从两侧夹住这个洞：
> - **预测性维护（PdM）** 不回答「现在是不是故障」，而回答「还剩多久、趋势如何」。慢退化在频域上与漂移不可分，但在**可逆性**上可分：漂移随温度/静息回到基线（可逆），退化不会（不可逆、单调）。PdM 天生适合处理被 R68 判成「漂移」的那部分慢变量。
> - **跨任务泛化** 同时提供两样东西：单部件退化样本极稀疏（等它坏一次要几个月），但退化模式跨部件/任务共享 → 分层先验/元学习可少样本估 RUL；且**跨任务一致性**是免费归因证据（共因退化同时污染多任务 vs 传感器特异问题只污染单任务）。
>
> 核心命题：**把 R68 的单一标定潜变量 c 劈成「可逆校准 c^rev（可被标定吸收）」与「不可逆健康 h（只许单调、只许抬升风险）」；用静息-回返探针把 h 变成稀疏可观测锚点；用单侧（棘轮）滤波保证误归因只增不减；用跨任务分层先验补足稀疏标签——PRISM-RAS（Prognostic, Reversible/Irreversible-Split, cross-task Maintenance RAS）。**
>
> 一句话定位：R68 问「我的测量还准吗」，R69 问「**如果它正在慢慢变坏，我什么时候知道、还剩多少安全余量**」——并把预测严格限制为「只能更保守」，杜绝 PdM 在安全闭环里最常见的滥用：用「还早」来推迟动作。

## 0. 直觉与动机

**灵感 1（预测性维护 → 慢变量不是噪声，是信号；但必须先分可逆/不可逆）**
直觉：R68 把慢于 ω_cal 的残差一律当标定漂移吸收，是因为它只有「标定」这一个慢状态。工程上慢状态至少两类：(a) 热漂、弹性形变、自动曝光——**可逆**，随温度/静息回到基线；(b) 磨损、蠕变、慢泄漏、渐进老化——**不可逆**，单调累积。二者在单帧残差上完全不可分（结构性不可辨识），但在**时间可逆性**上可分：冷却/静息后 (a) 归零，(b) 留存。PdM 的核心动作——RUL、退化趋势、维护窗口——只对 (b) 有意义。所以不是「更用力地标定」，而是**先分类慢变量，再各归其位**。

**灵感 2（静息-回返探针 → 把不可辨识问题变成稀疏可观测问题）**
直觉：机器人天然有大量静息段（任务间隙、待机、换料、冷却）。静息 + 热稳态时，可逆分量理应回到 0，此时残余的零偏就是不可逆退化 h 的直接读数——零成本的「健康体检」。不需要连续可辨识 h，只需在静息锚点测量、在锚点之间用退化模型外推。这把「慢故障被吸收」从「永远看不见」变成「下一个静息点就会浮出水面」。

**灵感 3（单侧/棘轮滤波 → 让误归因的方向永远朝安全）**
直觉：R68 最危险的不是「归因错了」，而是「把故障归成标定」会让风险**下降**。R69 把健康状态 h 设计成**单侧（只增不减）滤波**：任何被误塞进 h 的残差都只会抬高健康告警与风险下限。于是错分方向被强制成安全方向——即便判别器不完美，也不会因「解释掉」而放松。只有在**经验证的维护之后**才允许 h 复位。这把「先标定后归因」升级为「**先分可逆性，再把不可逆部分接到风险闸上**」。

**灵感 4（跨任务泛化 → 稀疏退化标签的解药，也是共因/局部的判别器）**
直觉：退化标签极稀疏（等一次真实失效几个月），但 (i) 退化模式跨部件共享——新部件可用经验贝叶斯/元学习继承退化率先验，少样本即可估 RUL；(ii) 跨任务一致性是免费的归因证据——同一物理子系统退化会同时抬高多个任务的 h（共因），某个传感器特有的问题只污染单个任务（局部）。但跨任务迁移也会带来负迁移，所以必须加**迁移门**（源-目标散度小才接受），否则回退宽先验。

**灵感 5（安全反转 → PdM 在安全闭环里的唯一合法姿态）**
直觉：PdM 在工业界的默认用法是「预测到还早 → 延迟维护/继续跑」。在安全闭环里这极其危险。R69 立一条纪律：**预测只能收紧，绝不能放宽**。RUL 越小 → 风险下限 λ_floor 越高、允许包络越窄、维护需求越早发出；RUL 再大也不允许把 λ 压回基线以下。预测性维护在这里的产物不是「可以再等等」，而是「**在失效前主动降额（prognostic derating）**」。

**灵感 6（合流 → PRISM-RAS 六层）**
1. **HSD Health-State Decomposer**：可逆/不可逆标定分解 + 单侧健康滤波；
2. **RRP Rest-Reversal Probe**：静息-回返探针调度与锚点测量；
3. **DTE Degradation Trend Estimator**：CUSUM 起始检测 + 单侧斜率下界；
4. **RUL-LB**：保守 RUL 下界 + 维护窗口；
5. **XDG/DCA**：跨任务分层先验迁移（带门控）+ 跨任务一致性归因；
6. **SIR/PDR/MDV**：安全反转纪律 + 预测性降额 + 维护验证闭环；RAS-WM† / CALM† 全套继承，只把「标定」拆成 c^rev 与 h 两条状态。

## 1. 形式化定义（增量：定义 293–310）

**定义 293（PRISM-RAS 总览）** PRISM-RAS = (HSD, RRP, DTE, RUL-LB, XDG, DCA, SIR/PDR, MDV, RAS-WM†, CALM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68）：预测与健康滤波全部在慢/影子流，实时流只读 λ_floor 与降额包络；
(ii) **可逆/不可逆分离**：任何慢残差先分 c^rev（可吸收）与 h（不可吸收，只许抬风险）；
(iii) **预测只收紧（SIR）**：∂λ_floor/∂RUL ≤ 0，永不因「还早」下调风险下限或放宽包络；
(iv) **复位需经验证**：h 只在维护后通过静息探针验证下降才复位，否则升级告警。

**定义 294（可逆/不可逆分解）** c_t = c^rev_t + h_t。c^rev_t 为可逆校准误差（热漂、弹性形变、自动曝光），服从温度驱动 OU：c^rev_{t+1} = A_rev·c^rev_t + B_T·(T_t − T_0) + w^rev，谱半径 ρ(A_rev) < 1（均值回复）；h_t 为不可逆健康退化（定义 295）。R68 的 c_t 被拆成这两项，COF 只允许更新 c^rev。

**定义 295（健康状态与退化模式）** h_t = Σ_{m=1}^{M} ξ^m_t·d^m，ξ^m_t ≥ 0，d^m ∈ ℝ^{d_c} 为第 m 种退化方向（磨损/蠕变/泄漏/老化…）。退化速率 λ^m_t = ξ̇^m_t ≥ 0；在一个维护周期内 ξ^m_t 单调非减（棘轮），仅在验证维护后复位。失效阈值 ξ^m_max 来自设计规格或跨任务库（A97）。

**定义 296（静息-回返探针 RRP）** 静息事件 e_t = 1[σ_stat(t) > 0.9 ∧ |ΔT| < ε_T ∧ dwell > τ_rest]。探针观测 z_h(t) = offset(r_t, ĉ^rev_t) = h_t + n_probe。语义：可逆分量应回零，残留即不可逆退化；这是 h 的稀疏可观测锚点（A96）。

**定义 297（单侧健康滤波）** 健康估计采用单侧投影 Kalman（棘轮）：ξ̂_t = max(ξ̂_{t−1}, KF_update(ξ̂_{t−1}, z_h))，仅在 e_t = 1 时更新，期间按退化模型外推。约束集 Ξ = {ξ : Δξ ≥ 0}。性质：估计是真实退化的**上包络**（保守，见引理 17）。

**定义 298（退化观测与温度归一）** z_h = r_t − r_cal(ĉ^rev_t) − r̂_temp(T_t)，r̂_temp 由温度-残差回归给出。若 c^rev 与温度模型能解释 z_h → 归可逆；否则进入 h。温度归一误差 ε_T 是 c^rev/h 混淆的主要来源（风险）。

**定义 299（退化起始检测与趋势）** 对 ξ̂ 序列做单侧 CUSUM：S_t = max(0, S_{t−1} + Δξ̂_t − k_drift)，S_t > H_cusum ⇒ 退化起始 onset。斜率取单侧置信下界 ξ̇_lb = max(0, ξ̇̂ − z_{1−α}·σ_ξ̇)（保守，用于 RUL 下界）。

**定义 300（RUL 下界）** RUL_lb = (ξ_max − ξ_ub)/ξ̇_lb（ξ̇_lb > 0；否则 ∞），ξ_ub 为 ξ 的单侧上界。给出保守剩余寿命：真实 RUL 以 ≥ 1−α 概率不低于 RUL_lb（引理 19，A97 单调性）。维护窗口 = [RUL_lb, RUL_lb + W]。

**定义 301（跨任务退化一致性）** 退化交互图 G_D：节点 = 任务/部件，边 = 共享物理子系统。各任务对 h 的估计 {h^(i)} 的一致性统计量 C_h = Σ_{(i,j)∈E} w_ij‖h^(i) − h^(j)‖² / Σ w_ij。C_h 低 ⇒ 共因退化（H_deg^common）；C_h 中 ⇒ 局部退化（H_deg^local）；C_h 高 ⇒ 任务/传感器特异（H_sensor^task），进入 R68 的 H_sensor^trans 分支。

**定义 302（跨任务退化先验迁移与门控）** 退化率先验分层：λ^m_c ~ LogNormal(μ^m, (σ^m)²)，超参 (μ^m, σ^m) 由所有任务/部件的经验贝叶斯估计。新部件 c′ 的后验 = adapt(prior, few-shot data)。**迁移门** g_transfer = 1[MMD(φ(c′), φ(src)) < τ_mmd ∧ val_err(c′) < δ_val]；门关则回退宽先验。防负迁移（引理 18、定理 17）。

**定义 303（安全反转纪律 SIR）** 对任意预测输出（RUL、趋势、退化后验），动作映射 A 满足：A 只能降低允许包络、提高 λ_floor、提前维护。形式化 ∂λ_floor/∂RUL ≤ 0，且逐点 λ_floor^PRISM ≥ λ_floor^CALM。「还早」永不产生放宽动作。

**定义 304（预测性降额曲线 PDR）** λ_floor^pdm(RUL_lb) = 0.6（RUL_lb > H_warn）；在 [H_crit, H_warn] 内从 0.8 线性升到 1.0；RUL_lb ≤ H_crit ⇒ 1.0 且强制降额包络（速度/力/接触上限按 h 收缩）。与 R68 的 λ_floor(U) 取 max，只升不降。

**定义 305（维护决策与验证 MDV）** 当 RUL_lb < H_warn ⇒ 发出维护需求（含证据：ξ̂、ξ̇_lb、一致性 C_h、不确定度）。维护后必须通过**复位验证**：z_h(maintenance⁺) < γ_reset·ξ̂_pre 才允许 h 复位；否则判 maintenance_ineffective 并升级（防「纸面维护」）。

**定义 306（可逆吸收预算 RCB）** 单维护周期内可逆分量可吸收的残差能量上限 B_rev；超过即视为不可逆（强制进 h）。语义：可逆标定的自由度被预算约束，防止「用可逆通道慢慢吃掉慢性退化」。

**定义 307（退化审计缓冲 DRB）** 长时程环形缓冲，保存静息锚点、ξ̂ 轨迹、RUL 预测与事后真值；支持反事实审计「该退化在何时本应被检出」（VQAuditor-P）与 RUL 校准（可靠性图）。

**定义 308（AIC-PRISM 干扰集）** ℰ_PRISM = ℰ_CALM × ℰ_split × ℰ_prog × ℰ_xtd；ℰ_split = {可逆/不可逆误分、温度混淆、静息不足、探针偏差}；ℰ_prog = {RUL 高估、趋势反转漏检、退化模式混淆、维护无效}；ℰ_xtd = {负迁移、伪一致、源域偏置}。

**定义 309（J_PRISM 证书）** J_PRISM = (J_CALM, rev_state_hash, h_state_hash, ξ̂, RUL_lb, C_h, transfer_gate, maintenance_verdict, prism_ver)。Valid ⇔ Valid(J_CALM) ∧ RUL 覆盖检验通过 ∧ ξ 在红线内 ∧ 维护验证通过（若刚维护）。

**定义 310（PRISM 管线）** 实时流（R68，< 2.6ms）不变；慢流每静息事件/固定周期：RRP → HSD → DTE → RUL-LB → XDG/DCA → SIR/PDR → MDV；影子流训练退化先验与温度模型；所有健康写操作只写 c^rev 与 ξ，实时流只读 λ_floor 与降额包络。

# IP-253 HSD：可逆/不可逆分解 + 单侧（棘轮）健康滤波
class HealthStateDecomposer:
    def __init__(self, d_rev=8, d_modes=3):
        self.c_rev = np.zeros(d_rev); self.P_rev = Q_REV0.copy()
        self.xi    = np.zeros(d_modes); self.P_h = Q_H0.copy()

    def step(self, r, sigma_stat, temp, rest_event):
        # 1) 可逆分量：双向 EKF，温度驱动均值回复
        self.c_rev = A_REV @ self.c_rev + B_T @ (temp - T0)
        self.P_rev = A_REV @ self.P_rev @ A_REV.T + Q_REV
        if rest_event:                      # 静息：可逆分量应回零
            self.c_rev, self.P_rev = kalman_update(self.c_rev, self.P_rev, z=0.0, R=R_REST)
        # 2) 不可逆分量：只在静息探针更新，且 Δξ ≥ 0（棘轮）
        if rest_event:
            z_h = residual_offset(r, self.c_rev, temp)      # 温度归一后的锚点测量
            xi_new, P_new = kalman_update(self.xi, self.P_h, z=z_h, R=R_PROBE)
            self.xi = np.maximum(self.xi, xi_new)           # 单侧投影：只增不减
            self.P_h = P_new
        h = self.xi @ D_MODES
        return self.c_rev, h, self.xi.copy(), self.P_h

    def verified_reset(self, z_h_post, gamma_reset=0.5):
        if z_h_post < gamma_reset * (self.xi @ D_MODES).max():
            self.xi[:] = 0.0; self.P_h = Q_H0.copy(); return True
        escalate('maintenance_ineffective'); return False


# IP-254 RRP：静息-回返探针调度
class RestReversalProbe:
    def is_rest(self, sigma_stat, dT, dwell):
        return sigma_stat > 0.9 and abs(dT) < EPS_T and dwell > TAU_REST


# IP-255 DTE：CUSUM 起始 + 单侧斜率下界
class DegradationTrendEstimator:
    def update(self, xi_hist):
        self.cusum = max(0.0, self.cusum + (xi_hist[-1] - xi_hist[-2]) - K_DRIFT)
        onset = self.cusum > H_CUSUM
        slope_lb = max(0.0, slope_hat(xi_hist) - Z_ALPHA * sigma_slope(xi_hist))
        return onset, slope_lb, self.cusum


# IP-256 RUL-LB：保守剩余寿命
def rul_lower_bound(xi_ub, slope_lb, xi_max):
    if slope_lb <= 1e-9: return np.inf, 1.0
    return max(0.0, (xi_max - xi_ub) / slope_lb), coverage_conf(xi_ub, slope_lb)


# IP-257 XDG：跨任务/部件退化先验迁移 + 门控
class CrossTaskDegradationGeneralizer:
    def prior(self, comp, mode, few_shot):
        mu, sig = self.hyper[mode]                       # 经验贝叶斯超先验
        if self.gate(comp, self.src_domain):
            return adapt(mu, sig, few_shot), True        # 迁移
        return broad_prior(mode), False                  # 门关 → 宽先验

    def gate(self, comp, src):
        return (mmd(self.features(comp), self.features(src)) < TAU_MMD
                and few_shot_val(comp) < DELTA_VAL)


# IP-258 DCA：跨任务一致性归因
def degradation_consistency(h_per_task, G_D):
    C = weighted_variance(h_per_task, G_D)
    if C < TAU_COMMON: cause = 'H_deg_common'
    elif C < TAU_LOCAL: cause = 'H_deg_local'
    else:               cause = 'H_sensor_task'      # 交给 R68 H_sensor^trans
    return cause, C


# IP-259 SIR + PDR：预测性降额（只升不降）
def prognostic_derating(rul_lb, H_warn, H_crit):
    if rul_lb > H_warn: return 0.6
    if rul_lb > H_crit: return 0.8 + 0.2 * (1 - (rul_lb - H_crit) / (H_warn - H_crit))
    return 1.0                                        # 最保守 + 强制降额包络


# IP-260 MDV：维护需求 + 复位验证
class MaintenanceDecisionVerifier:
    def decide(self, rul_lb, xi, P_h, C_h):
        return {'demand': rul_lb < H_WARN, 'window': rul_lb,
                'evidence': (xi.copy(), P_h.copy(), C_h)}

    def verify_after(self, hsd, z_h_post):
        return hsd.verified_reset(z_h_post)


# IP-262 PRISM 慢闭环（与 R68 实时环并行，0 实时占用）
def PRISM_slow_loop(M, obs, rest_event, temp):
    r = M.residuals(obs)
    # 1) 可逆/不可逆分解（棘轮：h 只增）
    c_rev, h, xi, P_h = M.hsd.step(r, sigma_stat(M), temp, rest_event)
    # 2) 起始 + 趋势下界
    onset, slope_lb, cusum = M.dte.update(M.xi_hist)
    # 3) 保守 RUL 下界
    rul_lb, conf = rul_lower_bound(xi_ub(xi, P_h), slope_lb, M.xi_max)
    # 4) 跨任务先验 + 一致性归因
    prior, gated = M.xdg.prior(M.comp, M.mode, M.few_shot)
    cause, C_h = M.dca.consistency(M.h_per_task, M.G_D)
    # 5) 安全反转：预测只收紧
    lam_pdm = prognostic_derating(rul_lb, H_WARN, H_CRIT)
    assert lam_pdm >= M.calm.lam_floor_baseline       # 只升不降
    M.calm.set_lam_floor(max(lam_pdm, M.calm.lam_floor(U=M.calm.U)))
    if lam_pdm > 0.8: M.envelope.derate(h)            # 预测性降额
    # 6) 维护决策 + 审计
    if onset or rul_lb < H_WARN: M.mdv.decide(rul_lb, xi, P_h, C_h)
    M.drb.log((c_rev, h, xi, slope_lb, rul_lb, cause, C_h, gated))
    return c_rev, h, xi, rul_lb, lam_pdm, cause
```

## 3. 推导

**引理 16（可逆/不可逆的时间可分性与静息探针可辨识）** 在 A95（c^rev 为谱半径 < 1 的均值回复过程）与 A96（存在静息热稳态锚点）下，静息时 E[c^rev] → 0（温度归一后），故 z_h = h + n_probe 是 h 的无偏锚点观测。n_rest 次静息后 h 的估计误差 ≤ O(√(R_probe/n_rest))；锚点之间由单调外推维持上包络。系：**h 无需连续可辨识，只需在静息点可辨识**——这把 R68 的「结构性不可分」降级为「稀疏可观测」。

**引理 17（单侧滤波的 fail-safe 性）** 定义 297 的投影使 ξ̂ 对任一误归因事件单调非减，故对任意样本路径 λ_floor^PRISM ≥ λ_floor^CALM 逐点成立：把故障误判为退化只会更保守。**注意方向性**：该保证只覆盖「误入 h」；若真实退化被误归为 c^rev（可逆流形内），则会减掉并可能漏检——这是残余风险（见第 6 节），不能由本引理覆盖。

**引理 18（跨任务一致性的判别力与迁移误差界）** 设共因退化对所有受影响任务产生同向偏移 δ_c、局部原因只偏移单任务 δ_l。则一致性统计量 C_h 在共因假设下期望 ∝ 任务间噪声方差，在局部假设下期望 ∝ δ_l²；当 δ_c/σ 足够大且受影响任务数 |N(G_D)| 增大时，两类假设的 KL 分离度 ∝ |N(G_D)|·δ_c²/σ²。迁移侧：在 A98（退化模式低秩可共享）下，经验贝叶斯先验的目标超额风险 ≤ √(β_xtd/n_target) + ε_meta，β_xtd 为源-目标散度；门控保证 β_xtd ≤ τ_mmd 才启用。

**引理 19（RUL 下界的保守覆盖）** 若真实退化单调（A96/A97），且 ξ̇_lb 与 ξ_ub 分别为斜率与健康状态的单侧 (1−α) 置信界，则 P(RUL_true ≥ RUL_lb) ≥ 1−α。系：维护需求按 RUL_lb 发出，只会偏早、不会偏晚——与 SIR 一致。

**定理 16（PRISM 端到端安全：吸收反转）** 在 A87–A99 下：
1. 对 ω_f < ω_cal 的慢退化，R68 会将其吸收进 c；PRISM 由单调性把它路由到 h，因而 h 进入 λ_floor 与 RUL，**慢退化不再被「解释掉」**；且 λ_cmd^PRISM ≥ λ_cmd^R68（引理 17）。
2. 预测性维护只收紧：由定义 303/304，任意预测分支满足 ∂λ_floor/∂RUL ≤ 0，且无任何分支下调 λ 或放宽包络。
3. 残余漏检通道仅剩「可逆流形伪装」：P(miss) ≤ β_rev + P(温度归一误差 > ε_T)，β_rev 为可逆性检验的假阴性率；这是 R69 相对 R68 唯一未闭合的通道。
4. 维护需求带保守 RUL，维护后强制复位验证；无效维护升级，杜绝「纸面维护」导致的假安全。

**定理 17（跨任务迁移的安全性）** 迁移门仅当 MMD < τ_mmd 且少样本验证误差 < δ_val 时接受源先验。被拒绝时回退宽先验，其后悔界 ≤ O(√(log n/n))；被接受时负迁移超额风险 ≤ 源-目标散度 β_xtd（引理 18）。故跨任务泛化使目标任务相对宽先验基线的性能退化被 τ_mmd 界住，不会因「借鉴了错误部件」而系统性变差。

## 6. 本轮最大风险

**一句话**：PRISM-RAS 的可逆/不可逆分离完全依赖「可逆性」这一判据与静息锚点——**若某种真实退化恰好落在可逆流形内（慢变但随温度/静息可恢复的故障，如随温度卡滞又松开的阀门、与热膨胀强相关的裂纹闭合、或静息期样本不足使探针失真），它会被 c^rev 吸收并遗忘，而 PRISM 比 R68 更响亮的「健康良好、RUL 充裕」证书反而成为更强的假安全信号**——这是「标定悖论」升级后的「健康悖论」：诊断能力越强，落在其可逆假设之外的故障越隐形。

**次级风险与缓解**：
1. **温度归一误差导致 c^rev/h 混淆** → 多温度点标定 + 温度作为协变量纳入探针 + ε_T 触发保守回退（把不确定统一并入 h）；
2. **跨任务负迁移** → 迁移门（MMD + 少样本验证）+ 门关回退宽先验 + J_PRISM 记录 transfer_gate；
3. **RUL 高估** → 只用单侧下界斜率与上界健康、维护窗口提前、DRB 事后校准；
4. **维护验证被绕过/纸面维护** → 复位验证由独立静息探针完成，失败即升级并冻结降额包络；
5. **静息探针不足/非稳态** → 探针质量门（dwell + |ΔT| + σ_stat）+ 探针不足时 h 不确定度上升、λ_floor 抬升（只紧不松）。

# IP-253 HSD：可逆/不可逆分解 + 单侧棘轮健康滤波
class HealthStateDecomposer:
    def __init__(self, d_rev=8, d_modes=3):
        self.c_rev = np.zeros(d_rev); self.P_rev = Q_REV0.copy()
        self.xi    = np.zeros(d_modes); self.P_h = Q_H0.copy()

    def step(self, r, sigma_stat, temp, rest_event):
        self.c_rev = A_REV @ self.c_rev + B_T @ (temp - T0)      # 可逆：温度驱动 OU
        self.P_rev = A_REV @ self.P_rev @ A_REV.T + Q_REV
        if rest_event:                                           # 静息：可逆应回零
            self.c_rev, self.P_rev = kalman_update(self.c_rev, self.P_rev, z=0.0, R=R_REST)
            z_h = residual_offset(r, self.c_rev, temp)           # 温度归一锚点
            xi_new, P_new = kalman_update(self.xi, self.P_h, z=z_h, R=R_PROBE)
            self.xi = np.maximum(self.xi, xi_new)                # Δξ ≥ 0（棘轮）
            self.P_h = P_new
        return self.c_rev, self.xi @ D_MODES, self.xi.copy(), self.P_h

    def verified_reset(self, z_h_post, gamma_reset=0.5):
        if z_h_post < gamma_reset * (self.xi @ D_MODES).max():
            self.xi[:] = 0.0; self.P_h = Q_H0.copy(); return True
        escalate('maintenance_ineffective'); return False

        return self.cusum > H_CUSUM, max(0.0, slope(hist) - Z_ALPHA*sigma_slope(hist)), self.cusum

def rul_lower_bound(xi_ub, slope_lb, xi_max):
    return (max(0.0, (xi_max - xi_ub)/slope_lb), coverage(xi_ub, slope_lb)) \
           if slope_lb > 1e-9 else (np.inf, 1.0)

    def prior(self, comp, mode, few_shot):
        mu, sig = self.hyper[mode]
        if self.gate(comp, self.src):
            return adapt(mu, sig, few_shot), True
        return broad_prior(mode), False
    def gate(self, comp, src):
        return mmd(self.feat(comp), self.feat(src)) < TAU_MMD and few_shot_val(comp) < DELTA_VAL

# IP-258 DCA：跨任务一致性归因
def attribution_by_consistency(h_tasks, G_D):
    C = weighted_variance(h_tasks, G_D)
    cause = 'H_deg_common' if C < TAU_COMMON else ('H_deg_local' if C < TAU_LOCAL else 'H_sensor_task')
    return cause, C

# IP-259 SIR/PDR：预测只收紧
def prognostic_derating(rul_lb, H_warn, H_crit):
    if rul_lb > H_warn: return 0.6
    if rul_lb > H_crit: return 0.8 + 0.2*(1 - (rul_lb-H_crit)/(H_warn-H_crit))
    return 1.0

# IP-260 MDV：维护需求 + 复位验证
class MaintenanceDecisionVerifier:
    def decide(self, rul_lb, xi, P_h, C_h):
        return {'demand': rul_lb < H_WARN, 'window': rul_lb, 'evidence': (xi, P_h, C_h)}
    def verify_after(self, hsd, z_h_post): return hsd.verified_reset(z_h_post)

# IP-262 PRISM 慢闭环
def PRISM_slow_loop(M, obs, rest_event, temp):
    c_rev, h, xi, P_h = M.hsd.step(M.residuals(obs), sigma_stat(M), temp, rest_event)
    onset, slope_lb, cusum = M.dte.update(M.xi_hist)
    rul_lb, conf = rul_lower_bound(xi_ub(xi, P_h), slope_lb, M.xi_max)
    prior, gated = M.xdg.prior(M.comp, M.mode, M.few_shot)
    cause, C_h   = attribution_by_consistency(M.h_per_task, M.G_D)
    lam_pdm = prognostic_derating(rul_lb, H_WARN, H_CRIT)
    M.calm.set_lam_floor(max(lam_pdm, M.calm.lam_floor(U=M.calm.U)))   # 只升不降
    if lam_pdm > 0.8: M.envelope.derate(h)                              # 预测性降额
    if onset or rul_lb < H_WARN: M.mdv.decide(rul_lb, xi, P_h, C_h)
    M.drb.log((c_rev, h, xi, slope_lb, rul_lb, cause, C_h, gated))
    return c_rev, h, xi, rul_lb, lam_pdm, cause
```

## 4. 推导

**引理 16（时间可分性与静息探针可辨识）** A95（c^rev 均值回复，ρ(A_rev)<1）+ A96（静息热稳态锚点）⇒ 静息时 E[c^rev]→0，`z_h = h + n_probe` 为 h 的无偏锚点观测；n_rest 次静息后估计误差 O(√(R_probe/n_rest))。h 只需在静息点可辨识，不需连续可辨识。

**引理 17（单侧滤波 fail-safe）** 定义 297 的投影使 ξ̂ 对任一误归因单调非减 ⇒ λ_floor^PRISM ≥ λ_floor^CALM 逐点成立：故障误判为退化只会更保守。**方向性**：该保证只覆盖「误入 h」；真实退化误入 c^rev 仍可能漏检——残余风险。

**引理 18（一致性判别力与迁移界）** 共因退化对受影响任务同向偏移 δ_c、局部原因只偏移单任务 δ_l；C_h 在两假设下的 KL 分离度 ∝ |N(G_D)|·δ_c²/σ²。A98 下经验贝叶斯先验的目标超额风险 ≤ √(β_xtd/n_target)+ε_meta，β_xtd 为源-目标散度；门控要求 β_xtd ≤ τ_mmd。

**引理 19（RUL 下界覆盖）** 真实退化单调（A96/A97）、ξ̇_lb 与 ξ_ub 为单侧 (1−α) 置信界 ⇒ P(RUL_true ≥ RUL_lb) ≥ 1−α；维护需求按 RUL_lb 发出只会偏早。

**定理 16（吸收反转：端到端安全）** A87–A99 下：
1. ω_f < ω_cal 的慢退化在 R68 被吸收进 c；PRISM 由单调性路由到 h ⇒ h 进入 λ_floor 与 RUL，慢退化不再被「解释掉」，且 λ_cmd^PRISM ≥ λ_cmd^R68；
2. 预测只收紧：任意分支 ∂λ_floor/∂RUL ≤ 0，无分支下调 λ 或放宽包络；
3. 残余漏检仅剩「可逆流形伪装」：P(miss) ≤ β_rev + P(温度归一误差>ε_T)；
4. 维护需求带保守 RUL，维护后强制复位验证，无效维护升级。

**定理 17（迁移安全）** 迁移门仅在 MMD<τ_mmd 且少样本验证误差<δ_val 时接受；拒绝时回退宽先验，后悔界 O(√(log n/n))；接受时负迁移超额风险 ≤ β_xtd。跨任务泛化相对宽先验基线退化被 τ_mmd 界住。

## 7. 本轮最大风险

**一句话**：PRISM-RAS 的可逆/不可逆分离完全依赖「可逆性」判据与静息锚点——**若真实退化落在可逆流形内（慢变但随温度/静息可恢复的故障，如随温度卡滞又松开的阀门、热膨胀相关的裂纹闭合，或静息样本不足使探针失真），它会被 c^rev 吸收并遗忘，而 PRISM 比 R68 更响亮的「健康良好、RUL 充裕」证书反而成为更强的假安全信号**——这是「标定悖论」升级后的「健康悖论」：诊断能力越强，落在其可逆假设之外的故障越隐形。

**次级风险与缓解**：温度归一误差（多温度点标定 + 温度协变量 + ε_T 触发保守回退，不确定统一并入 h）；跨任务负迁移（迁移门 + 门关回退 + J_PRISM 记录）；RUL 高估（单侧下界 + 维护窗口提前 + DRB 事后校准）；纸面维护（独立静息探针复位验证 + 失败升级并冻结降额）；静息探针不足（质量门 + 探针不足时抬升 λ_floor，只紧不松）。
