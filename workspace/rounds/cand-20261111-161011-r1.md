# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；本轮灵感：「可扩展性」×「视觉伺服」）

> 第 54 轮把技能组合推进为「动作空间剖面 + 云边协同 + 联合证书」。但它有一个隐含的规模前提：每加一个技能/一台边端/一个相机，都要把组合图 O(|S|²) 全量重建、把联合证书在每台相机上重新验证。本轮用「视觉伺服」把这个前提打开——技能的动作合法性其实由 **视觉反馈回路** 定义（可见性、特征条件数、交互矩阵），而「可扩展性」要求证书能 **模板化、局部增量重验证、跨视角复用**。核心矛盾：H22：证书的 soundness 随技能库/边端规模增长而失效（过期、不可复用），而全量重验证不可扩展；H23：视觉伺服闭环使动作可行性依赖观测域，第 54 轮的动作剖面 α_S 在观测域漂移下会静默失真。

## 0. 直觉与动机

**灵感 1（视觉伺服把动作合法性锚定到观测域）**
直觉：一个动作 `a` 不是先验可行，而是在给定相机/特征/深度下才可行。视觉伺服有天然的局部可控性判据：交互矩阵 `L(s,Z) ∈ R^{k×6}`，其最小奇异值 `σ_min` 与条件数 `κ` 决定该位姿附近能否收敛、会不会出现特征奇异。于是把第 54 轮的动作剖面升级为 **视觉伺服动作剖面** `α_S^{vs}(a | V)`，并加一维 **灵巧谱** `ρ_vs(a) = (σ_min, κ, 可见特征数, 深度区间)`。直觉上：**动作空间 ∩ 观测域 = 真正可执行域**；离开观测域，ρ 与 α 都只是外推。

**灵感 2（可扩展性 = 证书模板化 + 实例绑定，而不是重算）**
直觉：同一种技能在不同相机、不同机器人上只差一组参数（内参、外参、深度尺度、特征类型）。与其对每个实例重新验证，不如把证书做成 **参数化模板 `Φ(θ)` + 有效域 `Θ`**：只要部署参数 `b` 落在 `Θ` 内，实例即继承模板的 soundness。这把「每实例一次验证」变成「每模板一次验证 + 每实例一次包含检查」。可扩展性因此不是工程加速，而是 **soundness 的复用结构**。

**灵感 3（接口签名让组合与重验证局部化）**
直觉：第 54 轮的组合图是全连接的 O(|S|²)，因为任意两技能都可能动作空间相交。视觉伺服给出了更细的「类型」：技能声明它 **消费哪些特征、产出哪些特征**（`F_in → F_out`）。两个技能只有共享特征类型时才会有真正耦合；新增技能只影响其特征类型邻域 `N(S)`。于是组合图构建与证书重验证都能 **增量局部化**，且可证明「未触及的边其旧证书仍然 sound」。

**灵感 4（视觉孔径预算：把带宽分配给证书新鲜度）**
直觉：可扩展的边端群里，视觉带宽是共享稀缺资源。证书不是永真的，它随视觉延迟/分辨率下降而「过时」。把每台机器人的视觉帧率/分辨率视为 **视觉孔径 `β_v`**，证书带 **有效期 `h_v`**，用边际收益分配孔径以最大化全局有效证书数。于是「可扩展性」被显式建模为 **资源-证书覆盖问题**，而不是假设网络无限好。

**灵感 5（证书代数：模板的偏序与组合）**
直觉：证书应能半格化：`⊑` 表示更弱/更保守；组合是 meet，模板实例化是单调映射。有了代数结构，缓存（memoization）与增量更新才有正确性依据：**缓存命中不破坏 soundness 当且仅当绑定在有效域内且模板序单调**。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（视觉伺服动作空间）**
`A_vs = A × V × O`，`A` 为第 54 轮动作空间，`V` 为观测域（相机内参/外参、可见特征集、深度区间），`O` 为伺服律参数（IBVS/PBVS、增益）。技能 S 在观测域 V 下的可行动作集 `A_S(V) = {a | α_S(a) ≥ θ_cov ∧ servo_converges(a,V)}`。

**定义 122（视觉灵巧谱）**
对动作 a 在观测 V 下取特征交互矩阵 `L(s,Z)`，定义灵巧谱
`ρ_vs(a|V) = (σ_min(L), κ(L)=σ_max/σ_min, n_vis, Z_range)`，
伺服可行当且仅当 `σ_min ≥ σ_0 ∧ κ ≤ κ_0 ∧ n_vis ≥ n_0 ∧ Z_range ⊆ Z_vis`。

**定义 123（视觉伺服域证书 VSD）**
`VSD = (F_in, F_out, Z_int, C_vis, κ_max, τ_v, ρ_vs^{min})`：技能消费/产出的特征类型、深度区间、可见性锥、条件数上界、允许视觉延迟、灵巧谱下界。`VSD` 的 **有效域** 为 `dom(VSD) = {V : C_vis(V) ∧ Z_int(V) ∧ κ(V) ≤ κ_max}`。

**定义 124（接口签名与细化序）**
技能接口 `ι_S = (F_in, F_out, VSD_S, band_S)`。细化 `ι_A ⊑ ι_B` 当且仅当 `F_in^B ⊆ F_in^A ∧ F_out^A ⊇ F_out^B ∧ dom(VSD_A) ⊆ dom(VSD_B) ∧ band_A ⊆ band_B`。组合 `S_i ⊗ S_j` 合法当且仅当 `F_out^{S_i} ⊒ F_in^{S_j}`（类型可对接）且 `dom(VSD_i) ∩ dom(VSD_j) ≠ ∅`。

**定义 125（证书模板与实例绑定）**
模板 `Φ(θ)` 携带参数 `θ` 与有效域 `Θ`，实例绑定 `b = bind(skill, robot, camera)`。实例证书有效当 `b ∈ Θ`。继承规则：`b ∈ Θ ∧ ρ_vs(b) ≥ ρ_vs^{min} ⟹ cert(Φ,b)` sound。

**定义 126（局部重验证邻域）**
新增技能 S 的影响邻域 `N(S) = {S' | F_in/out(S') ∩ F_in/out(S) ≠ ∅}`。**局部性假设 (A29)**：技能间耦合只通过共享特征类型发生，未共享特征者动作/鲁棒性耦合可忽略（`compat < ε`）。

**定义 127（可扩展性证书）**
`S_cert = (template_id, b, Δ_verify, h_v, β_v, probe_plan)`：模板与绑定、增量重验证记录、有效 horizon、视觉孔径、探测计划。若 `b∈Θ ∧ age ≤ h_v ∧ N(S) 全部重验证通过`，则称系统在规模 `|S|` 下 **证书 sound**。

## 2. 关键算法 伪代码

### IP-121 VSP（Visual-Servo Profiling）

```python
def visual_servo_profile(skill, V_samples, Z_samples):
    prof = {}
    for V in V_samples:
        for Z in Z_samples:
            L = estimate_interaction_matrix(skill, V, Z)
            s_min, kappa = min_singular(L), cond(L)
            prof[(V,Z)] = dict(sigma_min=s_min, kappa=kappa,
                               n_vis=visible_features(skill,V),
                               feasible=(s_min>=S0 and kappa<=K0))
    return prof
```

### IP-122 ISC（Interface Signature Compiler）

```python
def compile_interface(skill, prof):
    F_in  = feature_types_consumed(skill)
    F_out = feature_types_produced(skill)
    VSD   = fit_validity_domain(prof)          # 保守凸包/区间收缩
    band  = action_band(prof)
    return Interface(F_in, F_out, VSD, band)

def refine(iA, iB):
    return (iB.F_in <= iA.F_in and iB.F_out <= iA.F_out
            and subset(iA.VSD.domain, iB.VSD.domain)
            and subset(iA.band, iB.band))
```

### IP-123 TSV（Template Bind & Verify）

```python
def bind_and_verify(template, skill, robot, camera):
    b = bind(template.theta, skill, robot, camera)
    if not in_region(b, template.Theta):
        return ('reject','binding_out_of_domain', b)
    rho_vs = measure_dexterity(skill, robot, camera)
    if min(rho_vs) < template.rho_vs_min:
        return ('reject','dexterity_fail', rho_vs)
    return ('ok', S_cert(template.id, b, delta=0,
                         h_v=template.h_v, beta_v=template.beta_v))
```

### IP-124 ILR（Incremental Local Revalidation）

```python
def add_skill_incremental(S, G, templates):
    N = feature_neighborhood(S, G)             # 定义 126
    for S2 in N:
        if not compatible(compile_interface(S), G.nodes[S2].interface):
            return ('reject','interface_mismatch', S2)
        if bind_and_verify(templates[S], S, S2.robot, S2.camera)[0] != 'ok':
            return ('reject','revalidate_fail', S2)
    G.add_node(S)
    G.add_edges_from((S,S2) for S2 in N if compatible(...))
    return ('ok', G, cost=len(N))
```

```python
def allocate_visual_aperture(certs, B_total, value_fn):
```

### IP-126 CSC（Certificate Scaling / Composition Algebra）

```python
def compose_certs(c1, c2):
    if not compatible(c1.interface, c2.interface):
        return ('reject','type_mismatch')
    dom = intersect(c1.VSD.domain, c2.VSD.domain)
    if is_empty(dom):
        return ('reject','empty_visual_domain')
    rho = meet(c1.rho_vs, c2.rho_vs)          # 更保守者胜出
    h_v = min(c1.h_v, c2.h_v)                 # 有效期取短
    return ('ok', S_cert(compose_templates(c1.t,c2.t), dom, 0, h_v, ...))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| VSP | O(|V|·|Z|·k·6) | O(|V||Z|) | 交互矩阵估计误差有界 |
| ISC | O(|F|·|VSD|) | O(|F|) | 有效域保守、细化序反变 |
| TSV | O(|θ|) | O(1) | 绑定∈Θ、灵巧谱下界 |
| ILR | O(|N(S)|·|θ|) | O(|N|) | 局部性假设 (A29) |
| AVB | O(|cert| log |cert|) | O(|cert|) | 价值函数次模 |
| CSC | O(|F|+|VSD|) | O(|F|) | meet 单调、域交保守 |

**正确性定理（Scalable Visual-Servo Composition Soundness）**
假设第 54 轮 (A22)–(A28) 成立；**(A29)** 局部性假设；**(A30)** 模板有效域 `Θ` 的拟合保守（`Θ ⊆ 真实可行域`）；**(A31)** 交互矩阵估计误差 `||L̂-L|| ≤ ε_L` 且 `σ_min - ε_L ≥ σ_0`；**(A32)** 视觉延迟 `τ_v ≤ τ_v^max`。则对规模为 n 的技能库，
```
P_success(n) ≥ 1 - Σ_d(1-ρ_min(d)) - P(b∉Θ) - P(age>h_v) - P(局部性失效) - n·ε_L
```
且增量重验证的摊还成本 `O(|N(S)|)` 而非 `O(n²)`；只要未触及边的局部性成立，其旧证书 soundness 不被新技能破坏。

## 4. 实验设计 E162–E167

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 交互矩阵/灵巧谱精度 | `σ_min`, `κ` 预测 MAE | MAE ≤ 8% / 10% |
| E163 跨视角模板迁移 | 未见相机成功率 | 下降 ≤ 6%，重验证成本 ↓ ≥ 10× |
| E164 增量重验证成本 | 加技能耗时 vs 库规模 | 近线性，远低于 O(n²) |
| E165 组合 soundness | 局部性失效下的误报率 | ≤ 3% |
| E166 视觉延迟/退化鲁棒性 | 成功率 vs 帧率/分辨率 | P95 延迟 ≤ 50ms 下 ≥ 90% |
| E167 边端规模扩展 | 10/50/200 机器人证书 sound 率、带宽 | sound 率 ≥ 95%，带宽近线性 |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 模板有效域乐观，跨视角失效 | 高 | 保守凸包 + 留一相机验证 + 反例回灌 |
| 局部性假设被隐式耦合打破 | 高 | 特征耦合探测 + 全局抽检绊线 |
| 特征接口脆弱/语义漂移 | 高 | 类型本体 + 版本化签名 + 运行时类型检查 |
| 证书过期未察觉 | 中 | horizon 衰减 + 主动探测 + 降级模式 |
| 孔径分配导致抖动 | 中 | 次模保证 + 迟滞 |

## 6. 本轮最大风险

**一句话**：视觉伺服域证书 + 模板化把「每实例重验证」变成「每模板验证 + 包含检查」，从而在技能库与边端规模上可扩展，但其 soundness 依赖 **模板有效域的保守性、局部性假设、视觉延迟有界** 三根支柱；一旦有效域被乐观拟合、或特征类型出现未声明的隐式耦合，增量验证会给出「局部 sound、全局失效」的假证书，且这种失效随规模放大——故必须以 **保守域拟合 + 未声明耦合绊线 + 全局抽检** 三重护栏，宁可牺牲覆盖率，也不让可扩展性建立在未经检验的局部性幻觉上。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim-VS（VSP×ISC×TSV×ILR×AVB×CSC）

> 承接第 54 轮产物 v31。本轮在「动作-鲁棒性双证书」之上，加入 **视觉伺服** 作为动作合法性的观测域锚点，并用 **可扩展性** 把证书从实例级提升为模板级、从全量验证提升为局部增量验证。
> - **VSP（Visual-Servo Profiling）**：交互矩阵/灵巧谱 `ρ_vs`，把动作可行性条件化到观测域 V；
> - **ISC（Interface Signature Compiler）**：特征类型接口 `ι_S` 与细化序 `⊑`，让组合按类型对接；
> - **TSV（Template Bind & Verify）**：证书模板 `Φ(θ)` + 有效域 `Θ` + 实例绑定 `b`；
> - **ILR（Incremental Local Revalidation）**：仅重验证特征邻域 `N(S)`，摊还 O(|N|)；
> - **AVB（Aperture Value Budgeting）**：按边际价值分配视觉孔径 `β_v` 与证书 horizon `h_v`；
> - **CSC（Certificate Scaling / Composition Algebra）**：证书半格 `⊑`/meet，支持缓存与增量更新；
> - **VSC（Visual-Servo Certificate）**：联合证书 `J` 扩展视觉域分量。
>
> IP 编号：IP-121~IP-127（共 7 个新增），升级 IP-115/116/117/118 以纳入观测域与模板复用。


### IP-125 AVB

```python
def allocate_visual_aperture(certs, B_total, value_fn):
    # h_v(β) = h0 * f(β)，value 次模；贪心 (1-1/e) 近似
    alloc = init_aperture(certs)
    while budget_left(alloc, B_total):
        c = argmax(certs, key=lambda c: marginal(value_fn, c, alloc))
        alloc[c] = bump(alloc[c])
    return alloc
```

```python
def compose_certs(c1, c2):
    if not type_connect(c1.iface, c2.iface):
        return ('reject', 'type_mismatch')
    dom = intersect(c1.VSD.domain, c2.VSD.domain)
    if is_empty(dom):

    return ('ok', S_cert(
        template_id=compose_templates(c1.t, c2.t),
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| VSP | O(|V|·|Z|·k·6) | O(|V||Z|) | 交互矩阵估计误差 ≤ ε_L |
| ISC | O(|F|·|VSD|) | O(|F|) | 有效域保守、细化序反变 |
| TSV | O(|θ|) | O(1) | `b∈Θ`、`ρ_vs ≥ ρ_vs^{min}` |
| ILR | O(|N(S)|·|θ|) | O(|N|) | 局部性 (A29)，未触及边证书不变 |
| AVB | O(|cert| log |cert|) | O(|cert|) | 价值次模，贪心 ≥ (1-1/e)OPT |
| CSC | O(|F|+|VSD|) | O(|F|) | meet 单调、域交保守 |

**正确性定理（Scalable Visual-Servo Composition Soundness）**
假设第 54 轮 (A22)–(A28) 成立；**(A29)** 局部性假设：耦合只经共享特征类型发生；**(A30)** 模板有效域保守拟合 `Θ ⊆ 真实可行域`；**(A31)** 交互矩阵误差有界且 `σ_min - ε_L ≥ σ_0`；**(A32)** 视觉延迟 `τ_v ≤ τ_v^max`。则规模为 n 的技能库：
```
P_success(n) ≥ 1 - Σ_d(1-ρ_min(d)) - P(b∉Θ) - P(age>h_v)
               - P(局部性失效) - n·ε_L
```
**关键**：全量 O(n²) 重验证可替换为局部 O(|N(S)|) 增量重验证而不损失 soundness，只要 (A29)+(A30) 成立；证书代数保证缓存命中与 meet 组合单调。

## 6. 本轮最大风险

**一句话**：视觉伺服域证书 + 模板化把「每实例重验证」变成「每模板验证 + 包含检查」，从而在技能库与边端规模上可扩展，但其 soundness 依赖 **模板有效域的保守性、局部性假设、视觉延迟有界** 三根支柱；一旦有效域被乐观拟合、或特征类型出现未声明的隐式耦合，增量验证会给出「局部 sound、全局失效」的假证书，且这种失效随规模放大——故必须以 **保守域拟合 + 未声明耦合绊线 + 全局抽检** 三重护栏，宁可牺牲覆盖率，也不让可扩展性建立在未经检验的局部性幻觉上。
