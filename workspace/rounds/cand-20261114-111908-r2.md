# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环第 2 轮；本轮灵感：「论文发表」×「机械臂」）

> R69 把不确定性拆成 aleatoric / epistemic，并让系统学会「问」。但它的证据制度是**事后**的：先拿到回答，再做贝叶斯更新。任何事后更新都逃不过科学界最古老的两个陷阱——**HARKing**（看到结果再编假设）与 **p-hacking**（换阈值、换检验直到显著）。R69 自陈的最大风险「把诚实的不知道升级成被证实的错误」，本质上就是一次**不可复现却看起来很显著**的发表。更隐蔽的是，R69 的 MCG 只用「被采纳的交互」标定模态可信度——这正是**发表偏倚**：只统计阳性结果，于是系统对自己的置信度系统性乐观。
>
> 本轮两个灵感把「制度」带进闭环：
> - **论文发表**不是「写文章」，而是一套**抗自欺的证据制度**：预注册（把假设与决策规则封存在看数据之前）、独立复现（换一套仪器/一条因果通道重做）、负结果登记（失败也要进样本）、对抗评审（reviewer 负责提出竞争假设）、效应量与功效（不显著 ≠ 无差异）。
> - **机械臂**给出一个物理上罕见的「免费实验台」：冗余自由度。手臂可以在**零空间**里自运动——关节在动，末端一阶不动。R69 的看/问/触都会扰动任务，而零空间探询几乎不扰动任务，是天然的**低成本、可认证**的信息动作。
>
> 核心命题：**把 R69 的「单次交互 → 事后贝叶斯」升级为「预注册试验 → 独立复现 → 负结果登记 → 对抗评审 → 证据分级」；只有达到 A 级（可发表级）证据才解锁 resolution bonus，否则逐指令退化为 FLUID-RAS（再退化为 R68）。** 命名 **PEER-RAS**（Pre-registered Evidence & Embodied Replication for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我怎么证明我这次求证没有被自己骗**」——从「会提问」到「会做可复现的实验」。

## 0. 直觉与动机

**灵感 1（论文发表 → 证据制度，而非证据本身）**
直觉：科学共同体的可靠性不来自单次实验有多显著，而来自一套**在看见数据之前就把话说明白**的制度。R69 的 `update_belief(modes, answer)` 是彻头彻尾的「看到结果再决定怎么信」：拿到回答之后才选先验、才定阈值、才决定用哪对模态。这正是 HARKing。把它改成「先封存假设与决策规则，再执行动作」，就等于给系统装了一个不会事后找借口的审稿人。**预注册不是形式主义，它是把自由度从「事后」挪到「事前」的唯一办法**；自由度不会消失，只会以多重比较的形式在别处爆炸。

**灵感 2（机械臂 → 冗余自由度是「不扰动任务的实验台」）**
直觉：R69 的所有信息动作都有任务代价——注视会改变机身姿态、探针会施加力、问句会消耗社交预算。但对 n>6 的冗余机械臂，雅可比存在零空间 N=I−J†J：关节沿 Nz 运动时末端速度 J(Nz)=0。于是可以「一边保持末端执行任务、一边改变腕部视角/激励接触/读取关节力矩」。这把「交互有成本」这条 R69 的硬假设，在最常见的机械臂形态上放松了一大截：**信息可以近乎免费地获得，只要你会用冗余**。但「一阶不动」不等于「真的不动」，二阶项、奇异性和能耗必须被认证——这正是严谨性的落点。

**灵感 3（独立复现 → 因果独立，而不是相关一致）**
直觉：R69 要求「k 个证据源一致」。可如果同一块蒙尘的镜头同时污染了视觉特征与语言描述，两个「源」的一致只是**同谋**，不是复现。真正的复现必须换一条**因果独立**的测量链：运动学闭合、关节力矩、末端六维力、视觉、语言各自经不同物理路径到达同一个判断。**一致不是证据，独立地一致才是证据**。这把 R69 引理 18 的「k 源」升级为「有效独立数 k_eff」。

**灵感 4（负结果登记 → 校准不能被选择效应污染）**
直觉：论文发表最大的系统性偏差是只报阳性。R69 的模态校准（MCG）如果只吃「成功消解」的样本，就会像只统计中奖者的彩票公司——它必然高估自己的置信度。解决办法不是更聪明的校准器，而是**登记全集**：失败、空结果、超时、中止，统统进样本。校准的公平性来自样本的完整性，而不是来自算法的复杂度。

**灵感 5（功效与效应量 → 「没测出来」不是「没有」）**
直觉：R69 在交互后若仍不确定，会退化为保守——这没问题；危险的是它可能把「一次欠功效的交互没测出差异」误读成「确认安全」。统计上，n 不够时功效不足，不显著既可能是真无差异，也可能只是没看见。因此系统应当**拒绝执行欠功效的确认性试验**，而不是执行后做过度解读：不跑一个注定读不出结论的实验，比跑完再解释更安全。

**灵感 6（对抗评审 → 竞争假设是证据的磨刀石）**
直觉：reviewer #2 的价值不在于否定，而在于提出一个**同样能解释数据的竞争假设**。R69 的消歧只有「当前模态集合内部的选择」，缺少「会不会根本不在这个集合里」的追问。让一个冻结的对抗评审在交互前提出最难受的替代模态 m′ 与最判别实验 g′，只有经得起 g′ 的结论才配升级。**没有被认真反驳过的确认，只是更精致的确认偏误。**

## 1. 形式化定义（增量：定义 310–323）

**定义 310（PEER-RAS 总览）** PEER-RAS = (PRU, NIA, ERE, NRR, ARB, ECG, RAS-WM†)，在 FLUID-RAS 之上增加「证据制度层」。三不变式：
(i) **无预注册不确认**：任何用于消解 U_epi 的确认性交互，必须先预注册（定义 312）；未预注册的观察只能作为探索性证据，不得直接改变模态选择；
(ii) **任务不变性硬约束**：零空间信息动作的末端任务偏差一阶为零、二阶 ≤ ε_task，且远离奇异（定义 313）；
(iii) **登记完备性**：所有交互（含失败/空结果/中止/超时）必须进入负结果登记（定义 315）；标定与证书只允许使用登记全集。

**定义 311（研究性交互试验 τ）** τ = (M, g, {p_m(·|g)}_{m∈M}, δ, Δ_eff, n, s, H(τ))。其中 M 为注册模态集；g 为信息动作；p_m 为模态 m 下证据的预注册预测分布；δ: 𝒴^n → M ∪ {⊥} 为**封存决策规则**；Δ_eff 为最小可检测效应（MDE）；n 为计划样本量；s 为随机种子与场景承诺；H(τ) 为盐化哈希承诺。

**定义 312（预注册 PRU）** 执行 g 之前，把 H(τ) 追加写入只读日志 ℒ_reg；确认性分析只允许运行 δ。任何事后改动（换检验、换阈值、删样本、事后挑模态）一律标记为探索性，记入 ℒ_expl，且不得解锁 resolution bonus（定义 318）。**封存性**：H(τ) 一旦写入，(M, δ, n) 不可修改；要改必须新开试验 τ′，且 τ 作为负结果登记。形式地，`assert_sealed(H(τ), analysis)` 校验 `fingerprint(analysis) == ledger[H(τ)].decision_rule_fp`。

**定义 313（零空间信息动作 NIA）** 对冗余机械臂，雅可比 J(q) ∈ ℝ^{6×n}，n>6，零空间投影 N(q) = I − J†J。信息动作 g_null 的关节速度 q̇_g = N(q) z，满足一阶末端不动 J q̇_g = 0。二阶末端偏差 ẍ_task = J̇ N z + J q̈_g，界为 ‖ẍ_task‖ ≤ κ(q)‖z‖² + c_f ‖z‖，其中 κ 由 J̇ 与 N 的曲率决定。认证条件：σ_min(J) ≥ σ_safe（远离奇异）、‖ẍ_task‖Δt²/2 ≤ ε_task、能耗 ∫‖τ‖²dt ≤ e_max。允许用途：(a) 腕部绕目标环视以改变视角；(b) 受控接触/摩擦激励；(c) 关节力矩的零空间一致性探测。任一条件不满足 ⇒ g_null 作废，退回 R69 的有限成本信息动作。

**定义 314（具身复现 ERE）** 证据通道划分为因果独立组 𝒞 = {C_kin, C_torque, C_ft, C_vis, C_lang}，独立性由冻结的因果图 G_evid 声明。复现的对象不是原始证据，而是**决策**：对每组独立估计器 f_i 得 m̂_i = f_i(evidence_{C_i})；复现成功 ⇔ 多数独立组在封存 δ 下给出同一 m̂，且组间在 G_evid 中满足 d-分离。若通道相关 ρ_ij>0，按**有效独立数** k_eff = 1 + Σ_{i<j}(1−ρ_ij) 折算（定义 316）。

**定义 315（负结果登记 NRR）** 登记记录 r = (τ, outcome ∈ {confirm, reject, null, aborted, timeout, underpowered}, reason, ts)。标定统计量一律在 NRR 全集上计算 ECE_reg，而非仅在「被采纳」子集上计算 ECE_sel。定义**发表偏倚量** B_pub = max(0, ECE_sel − ECE_reg)；B_pub 超阈值 τ_pub 即判定「模态校准被选择性报告污染」，触发 R69 的 MCG（定义 306）。

**定义 316（对抗评审与反驳 ARB）** 评审器 ρ 在预注册后、执行前给出竞争模态 m′≠m 与判别实验 g′：m′ = argmax_{m′≠m} surprise(m′, modes)，g′ = argmax_{g′∈𝒢} KL(p_m(·|g′) ‖ p_{m′}(·|g′))，预算内取最大。反驳 = 以 τ′ = (M, g′, …) 预注册并复现。仲裁：仅当 (a) 封存 δ 通过 ∧ (b) 独立复现成功 ∧ (c) 效应量 ≥ Δ_eff 三者同时满足，才判定「确认」；否则维持 U_epi 未消解并走 R69 兜底。错误采纳上界推广 R69 引理 18：≤ δ_p·ρ^{k_eff−1} + ε_σ。

**定义 317（功效门与欠功效拒绝）** 设证据标准差 σ、显著性 α、功效 1−β，则最小样本量 n* = ⌈2(z_{1−α/2}+z_{1−β})²σ²/Δ_eff²⌉（双侧）。若预算内 n < n*，PRU 拒绝开确认性试验（标记 underpowered），U_epi 保持未消解并走 R69 保守。**禁止**把「欠功效试验不显著」推断为「等价于安全」。

**定义 318（证据分级 ECG 与分级退避）**
- **A 级（可发表级）**：预注册 + 独立复现（k_eff ≥ 2）+ 登记完备 + 效应量达标 → 解锁完整 bonus：λ = λ_floor(U_ale)；
- **B 级（仅预注册）**：未独立复现或登记不全 → 部分 bonus：λ = λ_floor(U_ale + 0.5·U_epi^res)；
- **C 级（探索性）**：未预注册/事后分析 → 不得降 λ：λ = λ_floor(U_ale + U_epi)。
只有 A 级证据能改变模态选择并进入 J_PEER 的确认区；B/C 只更新下一轮先验。

**定义 319（评审预算与停止）** 交互预算 b = b_expl + b_conf，且 b_conf ≥ γ·b。停止规则：达成 A 级、或 NRR 显示边际 VoI < 成本、或 n* 在预算内不可满足时停止。评审与复现成本计入 R69 MINT 的 c(g)。

**定义 320（PEER 证书 J_PEER）** J_PEER = (J_FLUID, reg_hash, τ_ids, evidence_grade, k_eff, effect_size, n_planned/n_actual, B_pub, underpowered_count, peer_ver)。Valid ⇔ Valid(J_FLUID) ∧ 所有确认性交互均已预注册 ∧ 登记完备 ∧（grade=A ⇒ k_eff≥2 ∧ effect≥Δ_eff）。

**定义 321（对 R69/R68 的包含与退化）** 当 (a) 无冗余自由度或零空间探针不满足 ε_task、(b) 预算不足以达到 n*、(c) 预注册/复现任一失败、(d) B_pub > τ_pub 时，PEER-RAS 逐指令退化为 FLUID-RAS；再经 R69 退化到 R68。安全侧永不弱于 R69。反之，A 级证据因附加了独立复现约束，其错误采纳率不高于 R69 的「已消解」，bonus 因此是**有资格证明的 bonus**。

**定义 322（研究性审计 VQAuditor-P 与可复现清单）** 审计「论文式」要素：假设是否可证伪、决策规则是否封存、通道因果独立性是否成立、负结果是否登记、欠功效试验是否被拒绝、效应量是否报告。输出可复现清单 R_checklist，供人审与跨机复现。

**定义 323（元分析与证据沉淀）** 跨轮把所有 A 级试验汇总为元分析表，估计模态先验 p(M) 与各通道可靠性 ρ_i；该表是 R69 的 mode_head 与 MCG 的校准数据来源。**系统最终发表的不是单个结论，而是一个可累积、可被推翻的证据分布。**

## 2. 关键算法骨架

```python
# IP-264 PRU：预注册（封存假设、决策规则、样本量）
def preregister(modes, g, pred_dists, decision_rule, mde, n, salt):
    tau = Trial(modes, g, pred_dists, decision_rule, mde, n)
    h = sha256(salt + tau.canonical())
    ledger.append({h: tau})                 # append-only，写入即封存
    return h

def assert_sealed(h, analysis):
    if analysis.fingerprint() != ledger[h].decision_rule_fp:
        raise Exploratory("post-hoc change -> grade C")

# IP-265 NIA：零空间信息动作（一阶不动末端，二阶/能耗/奇异三重认证）
def nullspace_info_action(arm, z, eps_task, e_max):
    J = arm.jacobian()
    if smin(J) < SIGMA_SAFE: return None                  # 近奇异禁用
    N  = np.eye(arm.n) - pinv(J) @ J
    qd = N @ z
    if arm.task_accel_bound(qd) * arm.dt**2 / 2 > eps_task: return None
    if arm.energy(qd) > e_max: return None
    return qd

# IP-266 ERE：因果独立通道上的决策级复现
def replicate(evidence, G_evid, decision_rule, k_eff_required=2):
    groups = causal_independence_groups(G_evid)           # 由冻结因果图给出
    votes  = [decision_rule(f_i(evidence[C])) for C, f_i in groups]
    k_eff  = effective_independence(groups, G_evid)       # 1 + Σ(1-ρ_ij)
    ok     = mode_agreement(votes) and d_separated(groups, G_evid)
    return ok and k_eff >= k_eff_required, k_eff, votes

# IP-267 NRR：负结果登记 + 反发表偏倚校准
def register(tau, outcome, reason):
    registry.append(Record(tau, outcome, reason))
    ece_sel = ece(accepted_only(registry))
    ece_reg = ece(all_records(registry))
    return max(0.0, ece_sel - ece_reg)                    # B_pub

# IP-268 ARB：对抗评审提出最难受的竞争模态与最判别实验
def adversarial_review(modes, g, budget):
    m   = current_mode(modes)
    m_p = argmax(lambda m2: surprise(m2, modes), modes)
    g_p = argmax(lambda g2: KL(p_m(g2), p_m_p(g2)), info_candidates(modes))
    return (m_p, g_p) if budget.allow(g_p) else (m_p, None)

# IP-269 ECG：功效门 + 证据分级 + 分级退避
def required_n(sigma, mde, alpha=0.05, beta=0.2):
    return math.ceil(2 * (z(1-alpha/2) + z(1-beta))**2 * sigma**2 / mde**2)

def grade(prereg_ok, replicated, k_eff, effect, mde, n_act, n_plan):
    if not prereg_ok:                         return "C"
    if n_act < n_plan and effect < mde:       return "underpowered"
    if replicated and k_eff >= 2 and effect >= mde: return "A"
    return "B"

def lambda_for(grade, U_ale, U_epi_res):
    return {"A": lam_floor(U_ale),
            "B": lam_floor(U_ale + 0.5 * U_epi_res),
            "C": lam_floor(U_ale + U_epi_res)}[grade]

# IP-273 主闭环：在 FLUID 的「要不要问」之外，加「怎么证明没被自己骗」
def PEER_RAS_round(M, obs):
    z, o = M.mtm.forward(obs)
    c, U_cal, thr = M.cof.step(z, o)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    if U_epi <= TAU_EPI:
        return FLUID_RAS_round(M, obs)        # 无歧义：逐指令退化为 R69
    # 1) 零空间免费探询（冗余机械臂专属）
    g0 = nullspace_info_action(M.arm, M.nia_policy(z), EPS_TASK, E_MAX)
    # 2) 预注册：假设集、决策规则、MDE、样本量全部先封存
    n_star = required_n(M.sigma_evid, M.mde)
    h = preregister(modes, g0, M.predict(modes, g0), M.RULE, M.mde, n_star, M.salt)
    # 3) 对抗评审：先让 reviewer 提出最难受的替代模态
    m_p, g_p = adversarial_review(modes, g0, M.budget)
    # 4) 执行 + 独立通道复现（不是原始证据一致，是决策一致）
    ev = M.execute(g_p or g0)
    ok, k_eff, votes = replicate(ev, M.G_evid, M.RULE)
    # 5) 负结果登记：失败也要进样本，校准用全集
    B_pub = register(h, "confirm" if ok else "null", votes)
    # 6) 功效门 + 分级退避
    gr = grade(prereg_ok=True, replicated=ok, k_eff=k_eff,
               effect=effect_size(ev), mde=M.mde,
               n_act=len(ev), n_plan=n_star)
    if gr in ("C", "underpowered") or B_pub > TAU_PUB:
        return FLUID_RAS_round(M, obs)        # 任一制度失败 -> 严格退化为 R69
    U_epi_res = U_epi if gr == "A" else 0.5 * U_epi
    lam = max(M.efs.risk_scale(...), lambda_for(gr, U_ale, U_epi_res))
    mode = select_mode(modes, U_epi_res, lam)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(mode.a, M.vista.H), ..., wm_preds)
    if m_p is not None: M.vqa_p.submit_async(h, m_p, g_p, gr, k_eff, B_pub)
    return k, lam, mode, (U_ale, U_epi_res)
```

## 3. 推导

**引理 19（零空间探询的一阶不变性与二阶界）** 对冗余机械臂 q̇ = N z，有 J q̇ = J(I−J†J)z = 0，故末端速度一阶为零；末端加速度含 J̇ N z 项，满足 ‖ẍ_task‖ ≤ κ(q)‖z‖² + c_f‖z‖。若 σ_min(J) ≥ σ_safe，则 κ(q) 有界。故在认证半径内，零空间探询对任务的扰动可压到 ε_task。**系**：存在一类信息动作，其任务成本可任意小（代价转移到关节能耗与曲率），从而放宽 R69「交互必有成本」的假设，但不取消它（能耗与奇异是硬代价）。

**引理 20（预注册抑制 HARKing）** 若数据后可自由从 R 个候选检验/规则中选择，FWER 至多为 1−(1−α)^R（Bonferroni 上界），即错误采纳可被选择自由度放大；预注册把规则固定为单一 δ，FWER 回到 α。故预注册将「事后可解释性」从错误采纳的放大器变成无关项。**系**：R69 的 `update_belief` 若不封存，等价于 R→∞ 的极端情形，其「已验证」不可信。

**引理 21（独立复现的有效独立性）** 记单通道欺骗/偏差率 δ_p，通道间相关 ρ_ij，令 k_eff = 1+Σ(1−ρ_ij)。多数一致下的错误采纳率 ≤ δ_p·ρ^{k_eff−1}+ε_σ。当所有通道共享同一混杂（ρ=1）时 k_eff=1，复现退化为 R69 的「单源」，不提供任何新保证。**系**：证据的价值取决于**因果独立性**，而非通道数量；宣言 G_evid 必须在看数据前冻结，否则「独立性」本身可被事后编造。

**引理 22（负结果登记消除发表偏倚）** 若采纳选择与「看起来可信」正相关，则仅用采纳子集估计的 ECE_sel ≤ ECE_reg（乐观偏），B_pub = ECE_reg − ECE_sel ≥ 0；登记全集后，校准样本与部署分布一致，偏倚项消失。**系**：MCG 的可信度不是校准器性质，而是样本完整性性质；不登记负结果，再好的校准器也会系统性自信。

**引理 23（欠功效的不可推断性）** 当 n < n* 时功效 < 1−β，不显著结果可能在 Δ_eff 处同时容纳「无差异」与「有差异」；故不能用「不显著」降低 λ。拒绝执行欠功效确认试验，等价于在信息不足时保持 R69 的保守——这是**在统计上正确的保守**，而不是懒惰的保守。

**定理 18（PEER 严格包含 FLUID/R68）** 在定义 321 的退化条件下，PEER-RAS 与 FLUID-RAS 逐指令相同，再经 R69 包含 R68。A 级证据的 bonus 不低于 R69 的已消解 bonus（附加 k_eff≥2 与效应量门槛只会降低错误采纳率）；B/C/underpowered/B_pub 越界只会让 λ 更保守。故安全侧单调不弱，效率侧获得**可认证**的 bonus。

**定理 19（证据制度的无突变与可复现）** 分级门只在制度失败时把 λ 下调（或不变），从不低于 R69 的 λ_floor；零空间动作经定义 313 三重认证，任务偏差 ≤ ε_task；预注册日志 append-only、证书含 reg_hash，故任意两次执行可被第三方核验其决策规则未被事后修改 ⇒ 控制连续、证据可复现。

## 6. 本轮最大风险

**一句话**：PEER-RAS 的全部可靠性押在「预注册的**假设空间 M 是完备的**」这一前提上——若真实原因根本不在注册模态集里，那么预注册、独立复现、对抗评审、负结果登记会共同产生一个**高度可复现、统计显著、证据链完整、却被系统性证错**的答案；这比 R69 的「不可复现的错误」更危险，因为它带着一张看起来无懈可击的「同行评审通过」证书——**可复现的错误，是最有说服力的错误**。

**次级风险与缓解**：
1. **通道独立性是宣称而非事实**（共有混杂使 ρ→1）→ G_evid 事前冻结 + 混杂注入红队 + E303；
2. **零空间探询的二阶/奇异/能耗代价被低估** → 定义 313 三重认证 + E301/E312/E313；
3. **预注册制度拖慢实时环路** → 确认性试验放在低频异步路径 + 复杂度预算；
4. **元分析把历史偏倚固化** → NRR 全集 + B_pub 门控，偏倚越界即冻结先验；
5. **过度保守导致系统「只会做实验不会做任务」** → 预算 b_expl/b_conf 配比 + E311 交互频率稳定。

## 2. 形式化定义（要点版）

**定义 310（总览与三不变式）** PEER-RAS 在 FLUID-RAS 上加证据制度层：无预注册不确认；零空间探询一阶不动末端且二阶 ≤ ε_task；登记完备（标定只用全集）。

**定义 311–312（试验与预注册）** τ 含注册模态集、预注册预测分布、封存决策规则 δ、MDE、样本量；执行前追加 H(τ) 到只读日志，事后改动即降为探索性（C 级），不得解锁 bonus。封存性由 `assert_sealed` 校验。

**定义 313（零空间信息动作）** `q̇_g=N z`，`J q̇_g=0`；`ẍ_task=J̇Nz+Jq̈_g`，界 `κ‖z‖²+c_f‖z‖`；认证 `σ_min(J)≥σ_safe ∧ ‖ẍ_task‖Δt²/2≤ε_task ∧ 能耗≤e_max`。用途：环视、受控接触激励、零空间力矩一致性。

**定义 314（具身复现）** 按冻结因果图 G_evid 分独立通道组，复现**决策** m̂_i；成功 ⇔ 多数一致 ∧ d-分离；用 k_eff 折算相关通道。

**定义 315（负结果登记）** 记录 `outcome∈{confirm,reject,null,aborted,timeout,underpowered}`；校准用 ECE_reg，`B_pub=ECE_sel−ECE_reg` 越界触发 MCG。

**定义 316（对抗评审）** 竞争模态 `m′=argmax surprise`，判别实验 `g′=argmax KL(p_m‖p_{m′})`；三条件（δ 通过 ∧ 复现成功 ∧ effect≥Δ_eff）同时满足才确认；错误采纳 ≤ `δ_p·ρ^{k_eff−1}+ε_σ`。

**定义 317（功效门）** `n<n*` 拒绝确认性试验；禁止把「不显著」当「等价安全」。

**定义 318（证据分级与退避）** A（预注册+复现 k_eff≥2+效应达标）→ `λ=λ_floor(U_ale)`；B（仅预注册）→ `λ=λ_floor(U_ale+0.5U_epi^res)`；C（探索性）→ `λ=λ_floor(U_ale+U_epi)`。

**定义 319–320（预算与证书）** `b=b_expl+b_conf, b_conf≥γb`；停止于 A 级/边际 VoI<成本/n* 不可满足。`J_PEER=(J_FLUID, reg_hash, τ_ids, grade, k_eff, effect, n_plan/act, B_pub, underpowered, peer_ver)`。

**定义 321（包含与退化）** 无冗余 / n* 不可达 / 预注册或复现失败 / B_pub 越界 ⇒ 逐指令退化为 FLUID-RAS → R68；安全侧永不弱于 R69。

**定义 322–323（审计与元分析）** VQAuditor-P 输出可复现清单 R_checklist；跨轮汇总 A 级试验为元分析，估计 p(M) 与通道可靠性，反哺 mode_head/MCG。

## 3. 关键算法伪代码

```python
# IP-264 PRU：预注册（封存假设、决策规则、样本量）
def preregister(modes, g, pred_dists, decision_rule, mde, n, salt):
    tau = Trial(modes, g, pred_dists, decision_rule, mde, n)
    h = sha256(salt + tau.canonical()); ledger.append({h: tau}); return h

def assert_sealed(h, analysis):
    if analysis.fingerprint() != ledger[h].decision_rule_fp:
        raise Exploratory("post-hoc change -> grade C")

# IP-265 NIA：零空间探询（一阶不动末端，三重认证）
def nullspace_info_action(arm, z, eps_task, e_max):
    J = arm.jacobian()
    if smin(J) < SIGMA_SAFE: return None
    qd = (np.eye(arm.n) - pinv(J) @ J) @ z
    if arm.task_accel_bound(qd) * arm.dt**2 / 2 > eps_task: return None
    if arm.energy(qd) > e_max: return None
    return qd

# IP-266 ERE：决策级独立复现
def replicate(evidence, G_evid, decision_rule, k_req=2):
    groups = causal_independence_groups(G_evid)
    votes  = [decision_rule(f_i(evidence[C])) for C, f_i in groups]
    k_eff  = effective_independence(groups, G_evid)      # 1 + Σ(1-ρ_ij)
    ok     = mode_agreement(votes) and d_separated(groups, G_evid)
    return ok and k_eff >= k_req, k_eff, votes

# IP-267 NRR：负结果登记 + 反发表偏倚
def register(tau, outcome, reason):
    registry.append(Record(tau, outcome, reason))
    return max(0.0, ece(accepted_only(registry)) - ece(all_records(registry)))

# IP-268 ARB：对抗评审
def adversarial_review(modes, g, budget):
    m   = current_mode(modes)
    m_p = argmax(lambda m2: surprise(m2, modes), modes)
    g_p = argmax(lambda g2: KL(p_m(g2), p_m_p(g2)), info_candidates(modes))
    return (m_p, g_p) if budget.allow(g_p) else (m_p, None)

# IP-269 ECG：功效门 + 分级 + 退避
def required_n(sigma, mde, alpha=0.05, beta=0.2):
    return math.ceil(2*(z(1-alpha/2)+z(1-beta))**2*sigma**2/mde**2)

def grade(prereg_ok, replicated, k_eff, effect, mde, n_act, n_plan):
    if not prereg_ok:                          return "C"
    if n_act < n_plan and effect < mde:        return "underpowered"
    if replicated and k_eff >= 2 and effect >= mde: return "A"
    return "B"

def lambda_for(grade, U_ale, U_epi_res):
    return {"A": lam_floor(U_ale),
            "B": lam_floor(U_ale + 0.5*U_epi_res),
            "C": lam_floor(U_ale + U_epi_res)}[grade]

# IP-273 主闭环（继承 R69，在「消歧」处插入证据制度）
def PEER_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(z, o)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    if U_epi <= TAU_EPI: return FLUID_RAS_round(M, obs)
    g0     = nullspace_info_action(M.arm, M.nia_policy(z), EPS_TASK, E_MAX)
    n_star = required_n(M.sigma_evid, M.mde)
    h      = preregister(modes, g0, M.predict(modes, g0), M.RULE, M.mde, n_star, M.salt)
    m_p, g_p = adversarial_review(modes, g0, M.budget)
    ev        = M.execute(g_p or g0)
    ok, k_eff, votes = replicate(ev, M.G_evid, M.RULE)
    B_pub     = register(h, "confirm" if ok else "null", votes)
    gr        = grade(True, ok, k_eff, effect_size(ev), M.mde, len(ev), n_star)
    if gr in ("C", "underpowered") or B_pub > TAU_PUB:
        return FLUID_RAS_round(M, obs)                 # 制度失败 -> 严格退化
    U_res = U_epi if gr == "A" else 0.5*U_epi
    lam   = max(M.efs.risk_scale(...), lambda_for(gr, U_ale, U_res))
    mode  = select_mode(modes, U_res, lam)
    k     = M.c_ras_wm.certified_prefix(M.ach.propose(mode.a, M.vista.H), ..., wm_preds)
    M.vqa_p.submit_async(h, m_p, g_p, gr, k_eff, B_pub)
    return k, lam, mode, (U_ale, U_res)
```

## 4. 推导

**引理 19（零空间探询不变性）** `J(Nz)=0` ⇒ 末端速度一阶为零；`ẍ_task=J̇Nz+Jq̈_g`，界 `κ(q)‖z‖²+c_f‖z‖`；σ_min(J)≥σ_safe 时 κ 有界。系：存在任务成本可压到 ε_task 的信息动作，代价转移到能耗与曲率（不取消成本，只转移成本）。

**引理 20（预注册抑制 HARKing）** 事后从 R 个规则中挑选，FWER ≤ 1−(1−α)^R；封存单一 δ 后回到 α。系：R69 的事后 `update_belief` 等价于 R→∞，其「已验证」不可信。

**引理 21（独立复现的有效独立性）** 错误采纳 ≤ `δ_p·ρ^{k_eff−1}+ε_σ`，`k_eff=1+Σ(1−ρ_ij)`；ρ=1 时退化为单源，无增益。系：证据价值取决于因果独立性而非通道数量。

**引理 22（负结果登记消除发表偏倚）** 正相关选择下 `ECE_sel ≤ ECE_reg`，`B_pub≥0`；登记全集后偏倚项消失。系：MCG 可信度是样本完整性性质，不是校准器性质。

**引理 23（欠功效不可推断）** `n<n*` 时功效 <1−β，不显著不能降 λ；拒绝欠功效试验 = 统计上正确的保守。

**定理 18（严格包含 R69/R68）** 定义 321 条件下逐指令相同；A 级附加 k_eff≥2 与效应量门槛只会降低错误采纳率；B/C/underpowered/B_pub 越界只让 λ 更保守 ⇒ 安全单调不弱，效率 bonus 可认证。

**定理 19（无突变与可复现）** 分级门只在制度失败时下调 λ；NIA 三重认证保任务偏差 ≤ε_task；append-only 日志 + reg_hash 使第三方可核验决策规则未被事后修改 ⇒ 控制连续、证据可复现。

## 7. 本轮最大风险

**一句话**：PEER-RAS 的全部可靠性押在「预注册的**假设空间 M 是完备的**」这一前提上——若真实原因根本不在注册模态集里，预注册、独立复现、对抗评审、负结果登记会共同产生一个**高度可复现、统计显著、证据链完整、却被系统性证错**的答案；这比 R69 的「不可复现的错误」更危险，因为它带着一张看起来无懈可击的「同行评审通过」证书——**可复现的错误，是最有说服力的错误**。

**次级风险与缓解**：通道独立性是宣称而非事实（G_evid 事前冻结 + 混杂注入红队 + E303）；零空间探询的二阶/奇异/能耗代价被低估（定义 313 三重认证 + E301/E312/E313）；预注册拖慢实时环路（确认性试验放低频异步路径）；元分析固化历史偏倚（NRR 全集 + B_pub 门控）；过度保守导致「只会做实验不会做任务」（b_expl/b_conf 配比 + E311）。
