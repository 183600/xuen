# 第 13 轮 · PROFLEX：把 CHUNK-SERVO 的「最后 3 厘米」再推到「最后 3 毫米」——用本体感觉力代理、可重构柔顺、双臂可重构夹具，把接触变成跨任务共享的物理原语

> 检索/复核日期：**2026-11-02（UTC）**。本轮是灵感循环第 1 轮，三个词是「力觉传感」「可重构机构」「跨任务泛化」。本轮**不推倒第 12 轮 CHUNK-SERVO**，而是在它的控制层上面再加一层：CHUNK-SERVO 解决「怎么看到并走到目标附近」，PROFLEX 解决「贴上去以后怎么不靠眼睛、靠接触把最后 3 毫米做完」。本轮不新增外部网络检索，赛事/接口/数据事实沿用第 12 轮已核实的 A 级结论；凡属推断的新内容一律标为 C 级假设，并写进实验门。

## 0. 一句话押注

**接口没有力/触觉传感器，但有「上一块指令位姿 vs 本块实测位姿」的残差；把它校准成力代理，用块内轨迹柔顺 + 块间力事件自适应，再用双臂把「环境」夹稳，就能在不新增学习模型的前提下，把插入/挂/拧/拔从视觉问题变成接触问题。**

三个词各落一处：

| 灵感词 | 落点 | 不做什么 |
|---|---|---|
| **力觉传感** | 用笛卡尔位置跟踪误差 `K_x(x_cmd − x_meas)` 减自由空间偏置，得到 6D 外力代理；块边界采样，检测接触/卡死/滑移/插入深度；夹爪闭合误差做抓取力代理 | 不假装有 F/T 传感器；不做 30Hz 力闭环（接口不允许） |
| **可重构机构** | 软件可重构柔顺：按相位切换 `K_d(φ)`，在插入尖端构造可编程 RCC；双臂角色可重构：一臂当主动夹具/支架，另一臂相对它做精密操作 | 不改硬件；不假设底层一定是阻抗控制器 |
| **跨任务泛化** | 9 个任务无关的接触原语（接近/对齐/预接触/螺旋插入/就位/旋拧/拔出/释放/恢复），VLA 只负责选原语和给参数；力代理阈值按机器人标定、不按任务标定 | 不做 32 个任务各一套控制器；不做逐任务学习残差 |

## 1. 直觉与动机：第 12 轮已经把「看得见」的部分做完了，剩下的是「看不见」的部分

第 12 轮 CHUNK-SERVO 的贡献是把 30 步开环 chunk 切成 5 步闭环块，用演示检索的相对位姿做视觉伺服。它在**接近段**是对的：头双目 58mm 基线、0.5–1m 工作距离、焦距约 282px，像素级对齐能到几毫米。但它有一个结构性上限：

1. **夹爪自己会挡住目标**。越接近插入，腕部相机越看不见孔/槽/杯架；头部视角又被手臂遮挡。视觉伺服在最后 1cm 恰恰最不可靠。
2. **透明/反光/细线目标**（药瓶、注射器、网线、拉链、锁孔）在双目和特征匹配上都不稳定。
3. **接触事件发生在视觉刷新之间**。第 12 轮的反馈周期是 `H_c/f_c + τ`，H_c=5、30Hz、RTT=50–150ms 时约 217–317ms。在这 200–300ms 里，物体可能已被顶偏、卡住、滑脱，或者被人挪走。
4. **视觉只能给几何，给不了「顶住了没有、进去多深、是不是卡了、是不是滑了」**。而这四个量恰好是插入/挂/拧/拔的成败判据。

人类的做法不是「看得更准」，而是「摸」。经典装配里，视觉把销钉送到孔上方 3–5mm，剩下的靠**柔顺 + 力反馈**：销钉被倒角一推就自己找正，力突然下降说明进孔，力持续上升而深度不动说明卡死，切向力与位移不一致说明滑移。这正是本轮要补的层。

但接口是硬的：挑战赛 API 只给四路 RGB、双臂关节、EE 位姿、夹爪、下身体、语言；**没有 depth、没有 F/T、没有触觉**。所以「力觉传感」不能照搬，必须重新定义：

> **力觉不是传感器读数，而是「命令—实际」的不一致。** 我们发出的 EE 目标位姿是已知的，下一块观测里的 EE 实测位姿是已知的；在位置控制下，两者的差就是环境反作用力的一阶代理。自由空间里这个差是重力下垂/摩擦/控制稳态误差，可以标定掉；接触时它会突然变大，而且方向与运动受阻方向一致。

这句话是本轮所有设计的支点。它把一个「接口没有的传感器」变成了「接口已经有的两个量之差」，而且不需要第二个模型。

同时注意一个残酷但重要的事实：**chunk 内 evaluator 开环执行，我们在块内拿不到任何新观测**。所以本轮不承诺 30Hz 力控。我们做的是三件在接口下真正可做的事：

- **块内**：把动作块本身塑造成「柔顺轨迹」——小步长、横向低刚度、轴向限速、螺旋搜索，让物理接触自己去纠正，而不是等我们反馈；
- **块间**：用块边界采样的力代理做事件判定与参数自适应（接触、卡死、滑移、就位），周期约 `H_c/f_c`（H_c=5 时 167ms）；
- **结构上**：用双臂把被操作物/受器变成「夹具」，把相对位姿控制从 base 系搬到「夹持物坐标系」，让人为扰动和基座漂移变成共模误差。

## 2. 形式化：先把「力代理」「可重构柔顺」「相对夹具」「跨任务原语」定义清楚

### 2.1 时间与接口模型

设控制频率 `f_c`（沿用 30Hz 假设，G0 实测），提交块长 `H_c`（固定），网络+推理等效延迟 `τ`。一次 `get_action` 后，evaluator 开环执行 `H_c` 步，然后才把新观测交回策略。于是：

```text
反馈周期        T_fb = H_c / f_c + τ
力代理采样周期  T_F  = H_c / f_c
```

H_c=5、f_c=30、τ=50ms 时：`T_fb≈217ms`，`T_F≈167ms`。这不是力控带宽，是**力事件判定带宽**。任何「力闭环」的增益都必须按这个周期设计，否则延迟直接导致振荡（第 12 轮已给出 d=1 的稳定域 `0<KH_c<1`）。

### 2.2 力代理（proprioceptive force proxy）

记第 `t` 块：

- `x_t^c ∈ SE(3)`：上一块我们下发的 EE 绝对目标（已知）；
- `x_t ∈ SE(3)`：本块观测里的 EE 实测位姿（API 给）；
- `q_t ∈ R^14`：双臂关节（API 给）；
- `g_t ∈ [0,1]^2`：夹爪开合（API 给）。

在笛卡尔位置控制假设下，环境外力旋量的一阶代理为：

```math
\hat{\mathcal F}_t
= K_x \odot \big(x_t^c \ominus x_t\big) - b(q_t)
```

其中 `⊖` 把 SE(3) 相对位姿映到 6 维 twist（平移 + 旋转向量），`K_x=diag(k_p I_3, k_r I_3)` 是等效笛卡尔刚度，`b(q_t)` 是自由空间偏置（重力下垂、摩擦、控制稳态误差），用自由空间演示按姿态拟合。接触事件：

```math
c_t = \mathbb 1\big[\|\hat{\mathcal F}_t\|_W > \theta_f\big]
```

沿插入轴 `u` 的进度与受阻：

```math
p_t = (x_t \ominus x_{t-1})\cdot u,\qquad
r_t = (x_t^c \ominus x_t)\cdot u
```

- **卡死（jam）**：`‖\hat{\mathcal F}_t‖>θ_f` 且 `p_t<ε` 且 `r_t>θ_r` 连续 `K` 块；
- **滑移（slip）**：`|g_t−g_{t−1}|>θ_g` 且切向力代理与切向位移不一致，或夹爪闭合量在负载下持续漂移；
- **就位（seat）**：轴向进度停止但力代理回落到低值，且深度达到演示目标。

这个代理的优点是：它只用 API 已有的量，且 `x_t^c` 是我们自己发的，不存在额外通信。缺点是：**它只能可靠地测「变化/事件」，不能可靠地测绝对力**（因为 `K_x`、摩擦、负载未知）。所以本轮把力觉用作事件检测与相对调节，不把它写成「读到 12.3N」。

### 2.3 可重构柔顺（software RCC）

在插入尖端 `C` 定义柔顺坐标系，admittance 模型：

```math
M_d\ddot x + D_d\dot x + K_d(\phi)\,x = \hat{\mathcal F}
```

`φ` 是相位（APPROACH / PRE_CONTACT / INSERT / SEAT / TWIST / PULL / RELEASE），`K_d(φ)` 是**可重构刚度**：

```math
K_d(\phi)=\mathrm{diag}\big(k_p(\phi)I_3,\;k_r(\phi)I_3\big)
```

经典 RCC 的「远端柔顺中心」条件，在软件里写成：把柔顺中心放在插入尖端，离 EE 距离 `L`，则旋转刚度与平移刚度满足

```math
k_r = k_p\,L^2
```

这样绕尖端转而不是绕 EE 转，销钉头会自己找孔。插入段取 `k_{p,\text{lat}} \ll k_{p,\text{axial}}`，横向让、轴向顶。这里的关键不是「柔顺」这个词，而是：**同一个控制器通过切换 `K_d(φ)` 在 32 个任务里复用**，这就是「可重构机构」的软件实现。

### 2.4 双臂可重构夹具与相对控制

记左右 EE 在 base 系的位姿 `T_L, T_R`，相对位姿 `T_{LR}=T_L^{-1}T_R`。若左臂夹住物体 `O` 且夹持刚性，则 `T_O = T_L T_{LO}`。右臂的期望相对位姿 `T_{LR}^d` 来自演示检索（第 12 轮 DG-KEYFRAME）。误差：

```math
e = \log\!\big(T_{LR}^{-1}T_{LR}^d\big)\in\mathbb R^6
```

控制律：`T_R^{cmd} = T_L^{meas}\,T_{LR}^d\,\exp(-K e)`。当左臂把物体夹稳时，base 漂移、人挪物体、桌面被碰，都会同时移动 `T_L` 和 `T_R`，在 `T_{LR}` 里**共模抵消**。这是「可重构机构」的第二层含义：**把一条手臂重新配置成夹具/支架**，让另一条手臂在一个稳定的相对坐标系里做精密操作。

### 2.5 跨任务接触原语

定义原语集合：

```text
P = { APPROACH, ALIGN, PRE_CONTACT, SPIRAL_INSERT, SEAT, TWIST, PULL, RELEASE, RECOVER }
```

每个原语 `p` 有参数 `θ_p = (轴 u, 搜索半径 R, 轴向步长 β, 力阈值 θ_f, 刚度 K_d, 容差, 超时, 验证条件)`。任务差异只体现在「选哪个原语序列 + 参数」，不体现在「换一个控制器」。VLA 仍是唯一学习模型：它输出 30 步语义计划，计划被一个确定性相位解释器映射到原语序列；相位不确定时回退 VLA 开环。力代理只做原语内的事件判定。

形式化地，一条执行轨迹是原语序列 `p_{1:n}` 与参数 `θ_{1:n}` 的拼接；跨任务泛化要求：对任意任务 `t`，存在一个短序列使接触段成功率不低于单任务专用控制器的一个可接受下界。这不是定理，是本轮要验证的假设（G5/G8）。

## 3. 算法骨架：在 CHUNK-SERVO 上加四层

```text
L0  VLA 语义规划        30 步 chunk，异步，唯一学习模型         （第 12 轮）
L1  视觉伺服            5 步块，相对目标，接近段               （第 12 轮）
L2  力代理              块边界 6D 外力代理，事件判定           （本轮新增）
L3  可重构柔顺          相位相关 K_d(φ) + 可编程 RCC           （本轮新增）
L4  双臂可重构夹具      相对位姿控制 + 共模抑制               （本轮新增）
L5  跨任务原语库        9 原语 + 参数 + 安全包络              （本轮新增）
```

在线主循环（每个 `get_action`）：

1. 读观测，更新 `x_t, q_t, g_t`；
2. 计算力代理 `\hat{\mathcal F}_t`，判定 `c_t`、jam、slip、seat；
3. 异步 VLA 计划（保持第 12 轮：永不阻塞，过期用旧计划 + 伺服）；
4. 相位解释器给出 `φ`，选原语 `p`；
5. 若在接近段：走第 12 轮视觉伺服，输出 5 步块；
6. 若在接触段：
   - 用 `K_d(φ)` 生成块内柔顺轨迹；
   - 插入原语用「螺旋搜索 + 轴向限速」；
   - 卡死则小回撤 + 横向抖动 + 重对齐；
   - 滑移则重抓（夹爪闭合 + 停顿 + 重定位）；
7. 若任务属于「可夹持」集合且双臂可用：左臂夹稳受器，右臂在 `T_{LR}` 下执行；
8. 人为扰动 / 编辑检测：停 → 重定位（第 11 轮）→ 重规划；
9. 任何异常：返回上一组合法块或安全 hold；绝不返回 NaN/错形状。

## 4. 为什么不是别的：三个容易被想到但本轮明确不做的方向

1. **「加一个力/触觉传感器」**：接口没有，也不允许改评测硬件。放弃。
2. **「训一个力预测网络/残差策略」**：违反单模型风险，且需要力标签；接口也没有。放弃。力代理是确定性估计，不引入第二个学习模型。
3. **「把 chunk 降到 1 步做 30Hz 力控」**：`action_chunk_size` 固定，且 RTT 不允许；即使降到 1 步，反馈仍是 `1/f_c+τ≈83–183ms`，不是 30Hz 力控。放弃「真力控」叙事，改做「分块力自适应 + 块内柔顺」。
4. **「完整 sim-to-real 训练柔顺策略」**：数字孪生只做标定/风洞，不训策略。保留第 12 轮的剪枝。

- 从「单臂相对目标」升级到「双臂相对夹具」；

- 从「最后 3 厘米」升级到「最后 3 毫米的接触判定与柔顺」。

**剪枝**：不做真 F/T、不做 30Hz 力控、不做力预测网络、不做逐任务柔顺参数、不做完整 sim-to-real 策略训练。

## 6. 可证伪的预测与实验门（本轮只立门，不宣称结果）

- **G0 控制器辨识**：底层是纯位置还是笛卡尔阻抗？阶跃响应能否测出 `K_x`、接触刚度 `k_e`、`τ`？若测不出，力代理只用于事件、不用于力调节。
- **G1 力代理事件检测**：仿真注入已知接触/滑移/卡死，AUROC ≥0.85，接触检测延迟 ≤1 个块；真机用单任务通道抽检。
- **G2 螺旋插入收敛**：仿真 peg-in-hole，间隙 0.5–2mm，搜索半径覆盖初始误差，成功率 ≥90%，轴向力不超安全阈值。
- **G3 可重构柔顺**：有/无 RCC 的插入成功率与峰值力对比；RCC 应显著降峰值力、提成功率。
- **G4 双臂相对夹具**：人为移动受器/基座扰动下，相对控制的误差应显著低于 base 系控制。
- **G5 真机单任务 A/B**：CHUNK-SERVO（视觉） vs PROFLEX（视觉+力代理+柔顺），≥3/5 任务 +10pp，变形任务不回归。
- **G6 延迟/吞吐**：p99 不升过门；力代理 CPU 开销可忽略。
- **G7 全量干跑**：N 端口隔离、reset 干净、内存不涨。
- **G8 消融**：力代理 on/off、RCC on/off、双臂 on/off、螺旋 on/off、原语 vs 任务专用。

**预测（C 级，待证伪）**：在插入/挂/拧类任务上，PROFLEX 比纯视觉高 8–15pp；在变形/语义任务上不涨甚至略降，因此按任务分档启用，而不是全局开。

## 7. 已知风险（本轮就要写清楚）

| 风险 | 为什么危险 | 缓解 |
|---|---|---|
| 力代理不可辨识 | `K_x`、摩擦、负载未知，绝对力测不准；自由空间偏置随姿态变化 | 只做事件/相对调节；自由空间拟合偏置；G0 不过就退回视觉 |
| 底层不是阻抗控制 | 块内「柔顺轨迹」可能被刚性位置控制器抵消，变成硬顶 | G0 先辨识；不行就只用螺旋搜索 + 低轴向速度，不宣称 RCC |
| 块内开环 | 接触力在 167ms 内可能已超限 | 轴向限速、步长上限、力代理超阈值立即回撤；安全包络 |
| 螺旋搜索慢 | 大初始误差下搜索时间可能超 180s | 先用视觉把误差压到 <5mm；搜索半径自适应；超时回退 |
| 双臂夹具干扰任务 | 有些任务需要双手同时操作，左臂不能当夹具 | 只对「可夹持」子集启用；其他任务回退单臂 |
| 夹爪滑移误判 | 闭合量变化也可能来自物体变形 | 与力代理/视觉残差联合判定；不单凭夹爪 |
| 单模型合规 | 相位解释器若用学习分类器会被质疑是第二个模型 | 用确定性规则 + 同一 VLA checkpoint 特征（C1/C2/C3）；提交材料写清 |
| 评价噪声 | 5 次/任务只能看方向 | 配对 A/B + bootstrap；320 trials SE≈2.4pp；不拿 +1–2pp 当结论 |
| 安全 | 卡死时继续顶可能损坏物体/机器人 | 力阈值、最大顶进行程、最大重试、检测即停 |

## 8. 一句话风险

**本轮最大的风险是：接口只给位置、不给力，所谓「力觉」本质是位置跟踪误差的代理；如果底层控制器足够硬或摩擦/重力偏置足够大，这个代理会在最需要它的接触瞬间既迟钝又容易误判。**

## 3. 问题形式化

### 3.1 时间模型与可达反馈率

一次 `get_action` 后，evaluator 开环执行 `H_c` 步再返回观测。因此：

```math
T_{\mathrm{fb}} = \frac{H_c}{f_c} + \tau,\qquad
T_F = \frac{H_c}{f_c}.
```

| 场景 | `H_c` | `f_c` | `τ` | `T_fb` | `T_F` |
|---|---:|---:|---:|---:|---:|
| WLA 默认 | 30 | 30 | 50ms | 1050ms | 1000ms |
| CHUNK-SERVO | 5 | 30 | 50ms | 217ms | 167ms |
| 高延迟 | 5 | 30 | 150ms | 317ms | 167ms |
| 低控制频率 | 5 | 10 | 50ms | 550ms | 500ms |
| 接触优先 | 3 | 30 | 50ms | 150ms | 100ms |

**结论**：`T_F` 是力事件的采样周期，不是力控带宽。任何「力增益」必须按 `T_F` 设计，且不能声称 30Hz 力控。

### 3.2 位置控制下的外力代理

设底层对 EE 位姿跟踪一个虚拟弹簧：

```math
\mathcal F_{\mathrm{ext}} \approx K_x \odot (x^c \ominus x) - b(q)
```

其中 `⊖` 把 `x^c x^{-1}` 映到 twist。用自由空间数据拟合 `b(q)`：

```math
b(q)=\arg\min_{b}\sum_{(x^c,x,q)\in\mathcal D_{\mathrm{free}}}\big\|K_x(x^c\ominus x)-b(q)\big\|^2
```

`b(q)` 用低阶多项式或按关节分箱的查表，避免引入学习模型。接触残差：

```math
\hat{\mathcal F}_t=\mathcal F_t-b(q_t).
```

**可辨识性**：`K_x` 与 `b` 只在「无力矩遥测」时可通过已知负载/阶跃/自由空间拟合到比例意义；绝对力不可辨识。因此所有阈值按事件标定，不按物理单位宣称。

### 3.3 接触事件与插入状态机

```math
\begin{aligned}
c_t &= \mathbb 1[\|\hat{\mathcal F}_t\|_W>\theta_f]\\
p_t &= (x_t\ominus x_{t-1})\cdot u\\
r_t &= (x_t^c\ominus x_t)\cdot u\\
\mathrm{jam}_t &= \mathbb 1[\|\hat{\mathcal F}_t\|_W>\theta_f]\cdot\mathbb 1[p_t<\epsilon]\cdot\mathbb 1[r_t>\theta_r]\\
\mathrm{slip}_t &= \mathbb 1[|g_t-g_{t-1}|>\theta_g]\ \vee\ \mathbb 1[\text{tangential force vs motion inconsistent}]\\
\mathrm{seat}_t &= \mathbb 1[|p_t|<\epsilon]\cdot\mathbb 1[\|\hat{\mathcal F}_t\|_W<\theta_s]\cdot\mathbb 1[d_t\ge d_{\mathrm{seat}}]
\end{aligned}
```

事件做 `K` 块多数滤波，避免单块噪声触发。

### 3.4 可重构柔顺与可编程 RCC

在柔顺中心 `C` 定义 admittance：

```math
M_d\ddot x+D_d\dot x+K_d(\phi)x=\hat{\mathcal F}
```

`K_d(φ)` 按相位切换：

| 相位 | `k_p,lat` | `k_p,axial` | `k_r` | 目的 |
|---|---:|---:|---:|---|
| APPROACH | 高 | 高 | 高 | 快速、抗扰 |
| ALIGN | 中 | 中 | 中 | 视觉对齐 |
| PRE_CONTACT | 低 | 中 | 低 | 柔顺接触 |
| INSERT | 很低 | 中 | 很低 | 让倒角导正 |
| SEAT | 低 | 高 | 低 | 压实但不侧滑 |
| TWIST | 低 | 中 | 低（轴向） | 旋转找牙 |
| PULL | 中 | 中 | 中 | 拔出 |
| RELEASE | 高 | 高 | 高 | 松开 |

可编程 RCC 条件：柔顺中心在尖端，离 EE `L`，则

```math
k_r=k_{p,\mathrm{lat}}L^2
```

若 `L≈0.05–0.1m`，`k_{p,lat}` 小，则 `k_r` 也小，绕尖端转而不是绕 EE 转。

### 3.5 块内柔顺轨迹（离散化）

由于块内拿不到新观测，用上一块力代理 `\hat{\mathcal F}_t` 零阶保持 + 几何预测 `\tilde{\mathcal F}` 驱动 admittance，前向积分出 `H_c` 个位置目标：

```math
x_{k+1}=x_k+\Delta t\,v_k,\qquad
v_{k+1}=v_k+\Delta t\,M_d^{-1}\big(\tilde{\mathcal F}_k-D_dv_k-K_d(\phi)x_k\big)
```

`\tilde{\mathcal F}_k` 在块内取 `\hat{\mathcal F}_t` 与几何预测的凸组合；块边界再用新观测校正。这是「轨迹级柔顺」，不是「力闭环」。

### 3.6 双臂相对夹具

```math
T_{LR}=T_L^{-1}T_R,\qquad
e=\log(T_{LR}^{-1}T_{LR}^d)
```

若左臂刚性夹住物体 `O`，`T_O=T_LT_{LO}`，则

```math
T_R^{d}=T_OT_{OR}^d=T_LT_{LO}T_{OR}^d=T_LT_{LR}^d
```

于是 `T_{LR}` 与 `T_L`（以及 base）无关，base 漂移与人为移动物体成为共模量。控制：

```math
T_R^{cmd}=T_L^{\mathrm{meas}}T_{LR}^d\exp(-Ke)
```

### 3.7 跨任务原语库

```text
P = {APPROACH, ALIGN, PRE_CONTACT, SPIRAL_INSERT, SEAT, TWIST, PULL, RELEASE, RECOVER}
```

每个原语 `p` 的参数：

```text
θ_p = (u, R, β, θ_f, K_d, tol, T_max, verify)
u      插入/接近轴
R      螺旋最大半径
β      每转轴向步长
θ_f    力阈值
K_d    刚度配置
tol    位置/姿态容差
T_max  超时
verify 完成判据（力降/深度/夹爪/视觉）
```

原语是**任务无关**的；任务只提供 `u`、目标深度、容差和 VLA 语义。跨任务泛化因此是「结构复用」而不是「学一个通用策略」。

### 4.2 在线主循环伪代码

```python
class ProflexPolicy:
    def get_action(self, obs):
        self._tick(obs)                      # update x, q, g, images
        self._force_proxy(obs)               # \hat F_t, events
        self._maybe_request_plan(obs)        # async VLA, never blocks
        self._maybe_update_goal(obs)         # DG-KEYFRAME retrieval

        phi = self.phase_interpreter(obs)    # deterministic
        p   = self.primitive_for(phi)        # from plan + rules

        if p in (APPROACH, ALIGN, PRE_CONTACT):
            chunk = self.visual_servo_chunk(obs, p)      # round 12
        elif p == SPIRAL_INSERT:
            chunk = self.spiral_insert_chunk(obs, p)
        elif p == SEAT:
            chunk = self.seat_chunk(obs, p)
        elif p == TWIST:
            chunk = self.twist_chunk(obs, p)
        elif p == PULL:
            chunk = self.pull_chunk(obs, p)
        elif p == RELEASE:
            chunk = self.release_chunk(obs, p)
        else:
            chunk = self.recover_chunk(obs)

        if self.dual_arm_active:
            chunk = self.relative_to_left(chunk, obs)

        return self.adapter.to_api(chunk, obs, self.token)
```

### 4.3 力代理与事件

```python
def _force_proxy(self, obs):
    xc, x = self.last_cmd_pose, obs.ee_pose
    F = hadamard(Kx, se3_log(xc @ inv(x))) - self.bias(obs.q)
    self.F_hat = lowpass(F, alpha=self.alpha)
    self.c = norm_w(self.F_hat) > self.theta_f

    p = dot(se3_log(x @ inv(self.prev_pose)), self.u)
    r = dot(se3_log(xc @ inv(x)), self.u)
    self.jam = (norm_w(self.F_hat) > self.theta_f and p < self.eps
                and r > self.theta_r)
    self.slip = (abs(obs.g - self.prev_g) > self.theta_g)
    self.seat = (abs(p) < self.eps and norm_w(self.F_hat) < self.theta_s
                 and self.depth >= self.d_seat)
    self.maj = majority_filter(self.events, K=self.K)
```

### 4.4 螺旋插入

```python
def spiral_insert_chunk(self, obs, p):
    # r(theta) = r0 + alpha*theta/(2pi)
    # z(theta) = z0 + beta*theta/(2pi)
    thetas = self.theta0 + self.dtheta * arange(H_c)
    r = self.r0 + self.alpha * thetas / (2*pi)
    z = self.z0 + self.beta  * thetas / (2*pi)
    x_lat = self.x0 + r[:,None] * stack([cos(thetas), sin(thetas)], -1)
    traj = compose(self.frame, x_lat, z, self.fixed_rot)
    if self.maj.jam:
        self.r0 = min(self.r0 + self.dr_jam, self.R_max)
        traj = self.retract_then(traj)      # small back-off first
    if self.maj.seat:
        self.phase = SEAT
    return traj
```

### 4.5 相位解释器（确定性）

```text
if not contact and d_t > d_far:            APPROACH
elif not contact and d_t > d_c:            ALIGN
elif contact and depth < d_seat and not jam: SPIRAL_INSERT

elif task_is_extraction:                   PULL
```

### 4.7 双臂夹具流程

```python
def relative_to_left(self, right_chunk, obs):
    TLR = inv(obs.T_left) @ obs.T_right
    e = se3_log(inv(TLR) @ self.TLR_ref)
    T_right_cmd = obs.T_left @ self.TLR_ref @ expm(-self.K_rel @ e)
    return replace(right_chunk, right_ee=T_right_cmd)
```

## 5. 力代理的推导与可辨识性

### 5.1 一阶推导

设底层对 EE 施加虚拟弹簧—阻尼：

```math
\mathcal F_{\mathrm{ctrl}}=K_x(x^c-x)+D_x(\dot x^c-\dot x)
```

准静态 `\dot x≈0`、忽略惯性：

```math
\mathcal F_{\mathrm{ext}}=\mathcal F_{\mathrm{ctrl}}-\mathcal F_{\mathrm{grav}}-\mathcal F_{\mathrm{fric}}
```

于是 `\hat{\mathcal F}=K_x(x^c\ominus x)-b(q)`，`b` 吸收重力/摩擦/稳态误差。**方向**在受阻方向上与 `x^c-x` 一致；**幅值**只能到比例意义。

### 5.2 可辨识性与误差界

- `K_x` 未知：用已知质量负载做静态标定，或用仿真阶跃。若不可标定，令 `K_x=I`，则 `\hat{\mathcal F}` 是「米制位置误差」，事件阈值直接按米制标定。
- `b(q)` 随姿态变化：用自由空间覆盖多姿态；未见姿态用最近邻/线性插值。
- 摩擦：低速时静摩擦会造成死区，导致小力漏检；用「运动受阻」一致性门控（只在指令运动但实际不动时判接触）。
- 延迟：`x^c` 是上一块的目标，`x` 是本块实测，二者时间对齐到块；块内动态不可见。

**结论**：力代理适合检测「接触/卡死/滑移/就位」这类**事件**，不适合报告绝对力；所有下游控制都必须写成事件驱动或相对调节。

## 6. 可重构柔顺与 RCC 推导

### 6.1 横向柔顺降低对齐误差

设孔中心 `x_h`，接触横向刚度 `k_c`，机器人横向柔顺刚度 `k_a`。平衡：

```math
k_a(x^c-x)=k_c(x-x_h)
\;\Rightarrow\;
x-x_h=\frac{k_a}{k_a+k_c}(x^c-x_h)
```

因此 `k_a→0` 时 `x→x_h`，横向误差被柔顺吞掉；`k_a` 越小，允许的初始偏差越大。这就是 RCC 的线性化解释。

### 6.2 柔顺中心条件

若希望绕尖端（距 EE `L`）旋转而不是绕 EE 旋转，则旋转刚度应为

```math
k_r=k_{p,\mathrm{lat}}L^2
```

推导：绕尖端转 `δθ` 在 EE 处产生平移 `Lδθ`；等效旋转刚度 `k_r≈k_{p,lat}L^2`。取 `L` 为夹爪到插入点的距离。

### 6.3 分块力环稳定性

设接触刚度 `k_e`，力误差 `e_k=F_d-\hat F_k`，用上一块测量更新位置偏置：

```math
\delta_{k+1}=\delta_k+K_f e_{k-1}
```

则特征方程 `z^2-z+K_fk_e=0`，稳定域

```math
0<K_fk_e<1.
```

所以 `K_f<1/k_e`；工程上取 `K_f=1/(3k_e)` 留裕度。若 `k_e` 未知，用保守 `K_f` 或只做开环螺旋，不做力调节。

### 6.4 安全包络

- 最大顶进行程 `d_max`；
- 最大力代理 `θ_f^max`；
- 连续卡死 `K` 块 → 回撤；
- 最大重试 `N_retry`；
- 超时 `T_max`；
- 任何事件触发立即停止轴向推进。

## 7. 螺旋搜索：覆盖与收敛

### 7.1 参数化

```math
x_{\mathrm{lat}}(\theta)=x_0+\big(r_0+\alpha\theta/(2\pi)\big)
\begin{bmatrix}\cos\theta\\ \sin\theta\end{bmatrix},\qquad
z(\theta)=z_0+\beta\theta/(2\pi)
```

### 7.2 覆盖条件

孔半径 `r_h`，销半径 `r_p`，间隙 `c=r_h-r_p`。要保证扫过孔，径向步长应满足

```math
\Delta r\le 2c
```

每转轴向步长 `β` 应小于倒角引导深度。最大半径 `R` 覆盖初始误差。离散化后：

```math
N_{\mathrm{rev}}=\frac{R-r_0}{\alpha},\qquad
\Delta\theta\le \frac{2c}{r_0+\alpha\theta}.
```

时间上界 `T_search≈N_rev·2π/ω`，`ω` 由 `β` 和轴向速度决定。若不满足，先用视觉把初始误差压到 `R` 内。

### 7.3 收敛论证

在准静态、孔在搜索圆内、倒角存在、力不超限的假设下，螺旋轨迹是稠密的，且倒角会把销钉导入孔；`β` 足够小保证不会越过孔。不是严格全局收敛（可能有障碍/遮挡/变形），所以设超时与回退。

## 8. 双臂相对控制的共模抑制

### 8.1 代数

若 `T_L` 因 base 漂移或人移动物体而变化 `Δ`，而 `T_R` 因同一刚体运动也变化 `Δ`（因为右臂目标定义在物体上），则

```math
T_{LR}'=(T_L\Delta)^{-1}(T_R\Delta)=T_L^{-1}T_R=T_{LR}
```

共模抵消。误差只取决于左 grasp 是否刚性、`T_{LR}^d` 是否准确。

### 8.2 条件与失效

- 左 grasp 刚性：用力代理/夹爪闭合监控；滑移则重抓。
- `T_{LR}^d` 来自演示检索：置信度低则回退 base 系。
- 任务需要双手同时操作：左臂不能当夹具，禁用。
- 人把物体从左手拿走：左力代理突变 → `RECOVER`。

## 11. 正确性论证

### 命题 1（力代理一致性）

在准静态、笛卡尔位置控制、`b(q)` 正确标定的条件下，`\hat{\mathcal F}_t` 与真实外力旋量在受阻方向上同号，且幅值单调；因此接触事件的检测在阈值意义下是**可靠正例、可能漏检**的。

**论证**：`\mathcal F_ext=K_x(x^c-x)-b`；若外力沿 `-u`，则实测 `x` 沿 `-u` 偏离 `x^c`，`x^c-x` 沿 `+u`，与外力相反，故检测方向一致；幅值受 `K_x` 比例影响。摩擦/死区导致小力漏检，故只说可靠正例。

### 命题 2（柔顺降低横向误差）

在 §6.1 的线性化模型下，横向稳态误差 `x-x_h=(k_a/(k_a+k_c))(x^c-x_h)`，随 `k_a` 单调减；`k_a→0` 时误差趋 0。

**证明**：解平衡方程即得；对 `k_a` 求导 `d/dk_a [k_a/(k_a+k_c)]=k_c/(k_a+k_c)^2>0`。

### 命题 3（RCC 中心）

若 `k_r=k_{p,lat}L^2`，则绕尖端旋转的等效刚度与绕 EE 平移刚度匹配，接触力矩使销钉绕尖端转动，横向位移被倒角引导。

**论证**：小角度 `δθ` 在 EE 处产生 `Lδθ` 位移；能量 `½k_rδθ²=½k_{p,lat}(Lδθ)²`，故 `k_r=k_{p,lat}L²`。

### 命题 4（分块力环稳定域）

§6.3 的离散力环在 `0<K_fk_e<1` 时稳定，`K_fk_e=1` 临界振荡，`>1` 发散。

**证明**：特征方程 `z²-z+K_fk_e=0`；根在单位圆内当且仅当 `0<K_fk_e<1`（Jury 判据）。

### 命题 5（双臂共模抑制）

若左 grasp 刚性且 `T_{LR}^d` 准确，则 base 漂移/物体整体移动不改变 `T_{LR}`，相对误差 `e` 不变。

**证明**：§8.1 代数。

### 命题 6（螺旋覆盖，条件性）

若孔心在最大搜索圆内、径向步长 `Δr≤2c`、轴向步长小于倒角深度、力不超限，则螺旋轨迹扫过孔口，倒角引导插入。

**论证**：稠密螺旋 + 覆盖条件；非全局保证，需超时/回退。

### 命题 7（跨任务复用，经验假设）

9 原语覆盖接触段的主要物理模式；任务差异可由参数吸收。**这是假设，不是定理**，由 G5/G8 验证。

### 边界与反例

- 透明/反光/变形：视觉与力代理都可能失效；禁用或回退。
- 底层纯刚性位置控制：块内柔顺被抵消；退化为螺旋搜索。
- 力代理偏置随姿态剧变：误判；用姿态覆盖与门控。
- 人为扰动不在视野且不在夹持物上：漏检；用本体/夹爪兜底。
- 多物体接触/双手操作：双臂夹具不可用；回退单臂。
