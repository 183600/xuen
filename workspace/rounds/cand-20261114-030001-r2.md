# 第 71 轮（承接第 70 轮「BELIEF-RAS」IP-264~274；灵感循环第 2 轮；本轮灵感：「迁移学习」×「语言指令」）

> R70 把 epistemic 从「动作模态」提升为「世界状态后验 b_t(s)」，并交付了基线协议与原型验收。但它有一个被写进「最大风险」却未被正面处理的假设：**观测模型 p(o|s) 与策略 π 都是在某个源分布上训练好的；部署时世界变了，系统仍会拿它解释一切。** 贝叶斯滤波只对「状态不确定」谦逊，对「模型从哪来、还适不适用」保持沉默。一旦源模型在目标域系统性错误，BSE 会给出一个熵很低、却离真相很远的后验——**H[b_t] 变小反而意味着风险变大**。
>
> 本轮两个灵感正好从「知识从哪来」与「任务怎么被说清楚」两侧切入：
> - **迁移学习**把「模型从哪来」变成一等公民：技能库、可迁移性、负迁移、目标域风险上界。它既可能救场（少样本 + 源先验），也可能致命（把源域的自信偏见原样搬进目标域）。
> - **语言指令**把「任务是什么」变成一个可组合、可检索、可审计、但也**天然欠定**的接口：同一句指令可以有多个合法接地；它既能作为迁移的索引，也能作为语义一致性的第二意见；但它也会撒谎、会含糊、会与源模型共享同一个偏见。
>
> 核心命题：**把「迁移」当作一个有风险、可认证、可拒绝的知识搬运过程；把「语言指令」当作一个欠定的任务先验与检索键，而不是地面真值。新增两个正交不确定性通道——U_transfer（源知识还适用吗）与 U_ground（指令到底指什么）；只有二者都被认证消解，才发放迁移 resolution bonus；否则退回 R70 的目标域保守。** 命名 **TILT-RAS**（Transfer-Instructed Learning with Trust）。
>
> 一句话定位：R68 问「测量准吗」，R69 问「向谁求证」，R70 问「世界是什么状态」，R71 问「**我脑子里的这套本事，是从哪个世界学来的；现在这个世界，配得上它吗；而我对任务的理解，是不是也只是其中一种读法**」。

## 0. 直觉与动机

### 灵感 1（迁移学习 → 先验是一张借条，不是资产）

直觉：迁移学习常被叙述为「用源任务的数据解决目标任务的少样本问题」。但在安全系统里必须反过来问：**源知识是一张借条，目标域是还款人**。借条能不能兑现，取决于三个条件：

1. **支撑重叠**：目标输入落在源技能被训练过的区域（support / covariate overlap）；
2. **机制不变**：同样的输入在目标域产生同样的结果（p(y|x) 不变；例如摩擦、负载、传感器增益没变）；
3. **接口兼容**：源技能的前置/后置条件在目标域仍成立（坐标系、动作空间、单位、时延）。

三者任一破裂，迁移就可能变成**负迁移**：源先验越强、越自信，错误越难被目标数据纠正。更危险的是，负迁移不会表现为「熵高」，而表现为「熵低且错」——它恰好骗过 R70 用 H[b_t] 做风险缩放的机制。所以迁移必须有一个**独立的可信度通道**，并且必须能「被拒绝」。

### 灵感 2（语言指令 → 任务是一个程序，不是一个向量）

直觉：把一个任务编码成一个隐向量再迁移，等于把「任务是什么」的黑箱又加深一层。语言指令提供另一种可能：把任务写成一段**可解析的、带类型的前置/后置条件程序**（“把红色积木放到蓝色托盘左侧，避开杯子”），于是：

- **可组合**：复杂任务 = 技能库里原语的程序组合；迁移发生在原语与组合规则上；
- **可检索**：源技能用自然语言描述，指令与描述做语义匹配，作为迁移的索引；
- **可校验**：执行后的观测可以对照指令的 success predicate，形成独立于源模型的语义一致性证据；
- **可澄清**：指令天然欠定（“左边”是观察者左边还是物体左边？），歧义本身是一个可以「问」的 epistemic 对象——这正好接上 R69/R70 的主动交互。

但语言不是地面真值：它可能是错的、含糊的、被误听的、甚至被对手构造的。**语言只能当先验与证据，不能当覆盖传感器与安全认证的命令。**

### 灵感 3（负迁移打破「熵 = 无知」的等式）

直觉：R70 的核心假设是「H[b_t] 小 ⇒ 我确定 ⇒ 可以放松」。迁移引入了一种新的「确定地错」：源先验把后验收窄到一个错误模式，H[b_t] 很低，KL(b_t ‖ truth) 却很大。于是必须显式区分：

- **U_epi**：在「模型对」的前提下，状态不确定；
- **U_transfer**：连「该用哪个源、源还对不对」都不确定。

后者不能靠交互状态来消解，只能靠**目标域证据 + 可迁移性认证 + 必要时的小样本标定**。这也是本轮必须新增一个独立通道的根本原因：**不是所有无知都能通过「多看一眼」解决，有些无知只能通过「换一套知识」解决。**

### 灵感 4（语言 × 迁移 = 共享偏见风险）

直觉：语言指令做迁移检索有一个隐蔽陷阱：源模型、语言描述、指令可能**共享同一个偏见**。比如源数据集里「杯子」总在右边，源技能的语言契约也写成「杯子在右侧」，用户也就这么说。三者一致，系统会得到一个「高置信」的迁移，但一致的不是真相，而是同一个数据采集偏差。**共识不等于证据。** 因此：

- 语言匹配只能生成**候选集**（共形检索），不能直接定案；
- 迁移采纳必须经过**目标域风险下界**检验（safe transfer），不能只看源域精度或语义相似度；
- 指令一致性只能作为**第二意见**，且必须与「反事实/主动探针」正交。

### 灵感 5（嵌套 → 旧层是边界情形）

直觉：关掉迁移（只用目标域从零/在线学习的模型）、把语言指令退化为一个固定任务 ID、令 U_transfer=U_ground=0，TILT 必须逐指令回到 BELIEF→FLUID→R68。安全侧只允许「更早保守」，不允许因为「语言说可以」或「源模型很自信」而比 R70 更激进。**每一层新知识都必须能卸载，否则它不是能力，是负债。**

## 1. 形式化定义（增量：定义 331–349）

**定义 331（TILT-RAS 总览与四不变式）** TILT-RAS = (SCL, TCG, NTG, CRET, LGI, CLAR, SEM, BSE†, AUD†, TRC, BAA, RAS-WM†)。四不变式：
(i) **实时零学习写操作**（继承 R70 定义 310-i）：部署期只允许低维、有界的在线适应（偏置/尺度/门控），不允许全参数微调；
(ii) **迁移安全单调**：任何源知识的使用都必须通过 NTG 认证；未认证 ⇒ 退回目标域 R70，安全侧不得更激进；
(iii) **语言证据纪律**：语言指令只能作为先验/证据/检索键，不能覆盖传感器残差、安全包络与 C-RAS-WM 认证；单条指令不得单独定案；
(iv) **可卸载性**：任意源技能与任意语言先验都能在不重启的前提下被禁用，且禁用后行为严格回到 R70 对应边界。

**定义 332（技能库与迁移契约 SCL）** 技能库 𝒦={(k_i, c_i, D_i, Ω_i)}_{i=1}^M：k_i 是源技能（策略/控制器），c_i=(φ_i^pre, φ_i^post, e_i) 是其**语言契约**（前置条件、后置条件/效果、自然语言描述），D_i 是源数据（部署侧只存统计量，不存原始数据），Ω_i⊂𝒳 是声明适用域。契约是**部分规格**：它不保证在 Ω_i 内正确，只声明「若 φ_i^pre 成立，则期望 φ_i^post」。

**定义 333（迁移域差异与可迁移性参数 TCG）** 目标域 T 的小标定集 D_T^cal（无/少标签）与无标签流 D_T^u。对每个源 i 定义可迁移性 θ_i=(ov_i, sh_i, mech_i)：
- ov_i：支撑重叠，ov_i = P_{x∼T}[x∈Ω_i]（分类器/密度比估计）；
- sh_i：协变量漂移，sh_i = MMD(𝒟_i|Ω_i, 𝒟_T|Ω_i) 或域分类器 AUC−0.5；
- mech_i：机制差异，用目标标定集上的校准残差与源残差比较（无标签时用置信一致性/预测翻转率代理）。

源先验进入 BSE 的权重不是常数，而是 w_i ∝ π_i·exp(−λ_o·ov_i − λ_s·sh_i − λ_m·mech_i)，并再经 NTG 硬门控。

**定义 334（语言接地图 LGI）** 指令 ℓ 经类型化文法解析为任务程序 P_ℓ=(g_1,…,g_n; C; ψ)，其中 g_j 是技能原语实例，C 是约束（时序、空间、安全），ψ 是 success predicate。接地 g: P_ℓ → 可执行计划（含未绑定参数）。给定 (ℓ, o_t) 的接地后验 p(g|ℓ,o_t) 由解析歧义 × 参数歧义 × 感知歧义三部分构成。

**定义 335（指令歧义不确定性 U_ground）** U_ground = H[g|ℓ,o_t]（接地后验熵），并区分**可问歧义**（用户能澄清：指代、左右、优先级）与**不可问歧义**（环境本身不可辨：遮挡、听不清）。只有当存在信息动作使 U_ground 可降且 VoI>成本时，才允许澄清；否则 U_ground 直接进入保守通道。

**定义 336（语言检索的共形候选集 CRET）** 用校准集构造指令–技能匹配分数 s(ℓ,k_i)，输出候选集 C_α(ℓ)={k_i: s(ℓ,k_i) ≥ τ_α}，使得在指令–技能对可交换假设下 P(k*∈C_α(ℓ))≥1−α（k* 为按源任务语义应选的技能）。**C_α 只用于生成候选，不用于定案**；|C_α| 越大，U_transfer 的检索分量越高。

**定义 337（负迁移守卫 NTG）** 设源技能在目标域的期望风险 R_T(k_i)，目标域从零/在线模型的风险 R_T(∅)。迁移被**认证**当且仅当存在单侧下置信界

    LCB_δ(R_T(∅) − R_T(k_i)) > 0，

且契约检查（前置条件）在目标域成立、支撑重叠 ov_i≥ov_min、机制检查未报警。该下界由源风险 + 域适应界（Ben-David 型：R_T ≤ R_S + d_HΔH + λ）+ 目标标定集给出。**认证失败即拒绝迁移**，而不是「平均还行就上」。这是对「负迁移表现为低熵」的正面防御。

**定义 338（迁移感知的状态后验 BSE†）** 

    b_t^T(s) ∝ p(o_t|s,θ) · Σ_i w_i ∫ p(s_t|s_{t−1},k_i) b_{t−1}^T(s_{t−1}) ds_{t−1},

其中 w_i 由定义 333 与 NTG 联合门控：未认证源的 w_i=0。**关键**：NTG 失败时不是「降低 w_i」，而是「整源剔除并退回目标域先验」，避免残留源先验继续制造低熵错误。

**定义 339（迁移不确定性 U_transfer）** U_transfer = H(w) + Σ_i w_i·D_KL(p_T(·|k_i) ‖ p_T(·|∅)) 的加权分歧（或动作级 TV/JS），其中 H(w) 是「该信哪个源」的熵，第二项是「源与目标域从零模型到底差多少」。**它与 U_epi 正交**：U_epi 是给定模型下的状态无知；U_transfer 是模型族层面的无知。二者不可相加后只用一个 λ 处理。

**定义 340（语义一致性校验 SEM）** 执行一段计划后，用观测 o_{t:t+h} 检查 success predicate ψ 与每个原语的后置条件 φ_i^post 的满足度，得到语义残差 r_sem∈[0,1]。r_sem 高且源模型仍自信 ⇒ 不是状态问题，是**源契约在目标域失效**的独立证据（与 R69 的流似然、R70 的 r_res 正交）。

**定义 341（指令澄清协议 CLAR）** 当 U_ground 高且 VoI(问)>成本时，从指令文法生成最小澄清问句（指代消解、约束优先级、成功判据三选一），经 MINT/CIA 的同一条认证与证据纪律通道执行。澄清结果只能更新接地后验，不能直接改写源技能；若澄清后仍高，则 U_ground 进入保守通道。

**定义 342（四通道退避与迁移 resolution bonus）**

    λ = λ_floor(U_ale + α_epi·U_epi + α_tr·U_transfer + α_g·U_ground),

其中 α_tr=0 当且仅当 NTG 认证且 SEM 未报警；α_g=0 当且仅当 U_ground<τ_g 或澄清后下降；α_epi 同 R70 定义 320。**任何一项未认证，α 恒为 1**；TILT 不得比 BELIEF 更激进。

**定义 343（目标域在线适应的有界性 BAA）** 部署期只允许适应参数 η∈ℋ（低维：传感器偏置、执行器增益、门控温度），且 ‖η_t−η_0‖≤B_η、更新率≤ρ；每次适应必须过 NTG 的「不劣化」检验。全参数微调被禁止（违反定义 331-i）。

**定义 344（迁移溯源与审计 VQAuditor-III）** 每个决策记录：检索候选集 C_α、NTG 下界、被采纳/拒绝的源、契约检查结果、语义残差 r_sem、指令哈希、在线适应 η_t。审计对象新增「语言是否诱导」「源是否被过度信任」「拒绝迁移是否及时」。

**定义 345（AIC-TILT 对抗/投毒集）** ℰ_TILT = ℰ_BELIEF × ℰ_transfer × ℰ_ground：源数据投毒、负迁移诱导、指令注入/歧义利用、语言与源共谋（同一偏见）、共形校准集污染。所有主张须在该干扰集下报告。

**定义 346（证书 J_TILT）** J_TILT = (J_BELIEF, source_set, NTG_LCB, U_transfer, U_ground, C_α, r_sem, adapt_η_budget, tilt_ver)。Valid ⇔ Valid(J_BELIEF) ∧ (每个采纳源均认证 ∨ 未采纳) ∧ U_transfer/U_ground 已按定义 342 进入退避 ∧ 审计记录完整。

**定义 347（组合迁移的接口误差）** 计划由 n 个原语组合：误差界 ε_plan ≤ Σ_j ε_j + Σ_j interface(g_j,g_{j+1})，其中 interface 度量相邻原语在状态/动作/时序接口上的不匹配。**组合不是免费午餐：每多接一个源技能，就多一个接口可能破裂。**

**定义 348（可迁移性的可辨识条件与锚点）** 若目标域无标签、无支撑重叠、机制任意变化，则 NTG 不可辨识（任何源都可通过某个域适应界）。因此必须有至少一个**锚点**：小目标标定集、或一个已知在目标域可靠的锚技能、或语言 success predicate 的可观测部分。无锚点 ⇒ 禁止迁移（退 R70）。**这条定义把「零样本安全迁移」从默认能力降级为需要额外证据的特权。**

**定义 349（嵌套退化边界）** 令 𝒦={∅}（无源）、U_transfer≡0、U_ground≡0、CRET 恒返回空、NTG 恒拒绝、η≡η_0，TILT 的每条决策与 BELIEF 逐指令相同；继续关闭交互则退化为 FLUID/R68。该边界必须可自动断言（E343）。

## 2. 关键算法骨架

```python
# IP-275 SCL：技能库与迁移契约（只存统计量与契约，不存原始源数据）
class SkillLibrary:
    def __init__(self, skills):                     # (k_i, contract_i, stats_i, Omega_i)
        self.skills = skills
    def contract_check(self, k_i, o_t):             # 前置条件 φ_pre 在目标域的满足度
        return k_i.contract.pre_satisfaction(o_t)
    def retrieve(self, ell):                        # 语言 → 技能候选（粗筛）
        return [k for k in self.skills if k.contract.describe_matches(ell)]

# IP-278 CRET：共形语言检索（只产候选集，不定案）
def conformal_retrieve(ell, lib, scores, tau_alpha):
    cand = [k for k in lib.skills if scores(ell, k) >= tau_alpha]
    return cand, len(cand)                          # |C_α| 进入 U_transfer 检索分量

# IP-277 NTG：负迁移守卫（安全核心）
def transfer_gate(k_i, D_T_cal, D_T_u, delta):
    ov   = support_overlap(k_i.Omega, D_T_u)
    sh   = domain_shift(k_i.stats, D_T_u)
    mech = mechanism_residual(k_i, D_T_cal)
    if ov < OV_MIN or mech > MECH_MAX:
        return False, None                          # 契约/支撑不过：直接拒绝
    R_src = k_i.source_risk
    bound = R_src + domain_adaptation_bound(sh, k_i.stats, D_T_cal, delta)
    R_fb  = target_only_risk(D_T_cal)               # 目标域从零/在线模型
    lcb   = lower_confidence_bound(R_fb - bound, D_T_cal, delta)
    return lcb > 0, lcb                             # 只有「可证明更好」才迁移

# IP-281 SEM：语义一致性（独立于源似然的第二意见）
def semantic_consistency(plan, obs, psi):
    ok = [post_condition(prim, obs) for prim in plan]
    return 1.0 - mean(ok) * (1.0 - psi.satisfaction(obs))   # 失败度 r_sem

# IP-282 BSE†：迁移感知后验（认证失败整源剔除）
def bse_transfer_step(b_prev, o_t, accepted, gates):
    if not accepted:
        return bse_target_only(b_prev, o_t), {}, 0.0   # 退 R70 目标域
    w = normalize([exp(-LAMBDA * gates[k.id][1]) for k in accepted])  # 以 LCB 作温度
    b = mixture_update(b_prev, o_t, accepted, w)
    return b, dict(zip([k.id for k in accepted], w)), entropy(w)

# IP-289 TILT-RAS 主闭环（在 R70 BELIEF 上插入语言与迁移层）
def TILT_RAS_round(M, obs, ell):
    # 1) 语言接地：解析 → 候选技能集 → 接歧义
    P, p_g, U_ground = M.lgi.parse_and_ground(ell, obs)
    cand, size = M.cret.retrieve(ell, M.lib, M.scores, M.tau_alpha)
    # 2) 迁移认证：每个候选源先过 NTG，未认证即剔除
    gates = {k.id: M.ntg.transfer_gate(k, M.D_T_cal, M.D_T_u, M.delta)
             for k in cand}
    accepted = [k for k in cand if gates[k.id][0]]
    # 3) 状态后验：认证源 + 目标域兜底
    b_t, w, H_w = M.bse.step_transfer(M.b_prev, obs, accepted, gates)
    U_ale = M.aud.aleatoric_from_belief(b_t)
    U_epi = entropy(b_t)
    U_transfer = H_w + source_target_disagreement(accepted, w, M.fmp, obs)
    # 4) 语义一致性：源契约是否在目标域失效
    r_sem = M.sem.consistency(P, obs, P.psi) if P else 0.0
    # 5) 澄清：只在可问且 VoI>成本时
    if U_ground > M.tau_g and not M.slow_fault:
        q = M.clar.choose_question(P, b_t, M.budget)
        if q is not None:
            y = M.clar.execute(q)                    # 同 MINT 认证 + 证据纪律
            P, p_g, U_ground = M.lgi.update(P, y)
    # 6) 四通道退避：未认证的 transfer/ground 一律计入
    auth_tr = all(gates[k.id][0] for k in accepted) and r_sem < M.tau_sem
    U_floor = (U_ale
               + (0.0 if auth_tr else U_transfer)
               + (0.0 if U_ground < M.tau_g else U_ground)
               + U_epi)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    # 7) 安全认证 + 有界在线适应
    A = M.ach.propose_from_program(P, b_t, H=M.vista.H) if P else M.ach.propose(...)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)  # 语言不覆盖认证
    eta = M.adapt.bounded_update(obs, budget=B_ETA)
    if not accepted or r_sem > M.tau_sem:
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, U_floor))  # 回 R70 保守
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam
    # 8) 审计 + 证书
    M.vqa_iii.submit_async(ell, cand, gates, w, U_transfer, U_ground, r_sem, eta)
    M.jcert.emit(J_TILT(...))
    M.b_prev = b_t
    return k, lam, A[:k], (U_ale, U_epi, U_transfer, U_ground)
```

## 3. 推导

**引理 26（负迁移的低熵悖论）** 设源先验 p_S 在目标域相对真实机制有 KL 散度 ε>0，且源先验集中（方差 σ_S² 小）。迁移后后验方差 ≤ σ_S²，但后验均值偏差 ≥ √(2ε)（Pinsker）。因此 H[b_t] 可任意小，而期望风险 ≥ c·√ε。系：**在迁移下，H[b_t] 不再是无知的可靠代理；必须引入与 H[b_t] 正交的 U_transfer（定义 339），否则 R70 的退避机制会被负迁移反向利用**。

**引理 27（NTG 的安全迁移界）** 在域适应界 R_T ≤ R_S + d_HΔH + λ（A105：有界假设类、域可分）与目标标定集可交换（A106）下，定义 337 的 LCB 以概率 ≥1−δ 给出 R_T(k_i) ≤ R_T(∅) − LCB。因此「认证通过」⇒ 以 1−δ 概率不劣于目标域从零模型；反之，若真实负迁移，LCB>0 的概率随标定集增大指数下降。系：**把「迁移好不好」从平均精度叙事变成单侧风险断言**，负迁移可被拒绝而不是被平均掉。

**引理 28（语言检索的共形覆盖）** 在指令–技能对可交换（A107）下，定义 336 的 C_α 满足 P(k*∈C_α)≥1−α，与匹配模型是否正确无关。系：**语言可以错，但「候选集包含正确技能」的覆盖率仍有分布无关保证**；|C_α| 是诚实的「语言不确定性」度量，而不是模型的自信分数。

**引理 29（语言作为第二意见的独立性条件）** 若语义残差 r_sem 与源流似然 a_score 在给定真实机制下条件独立（A108），则联合判别 (r_sem↑, a_score 正常) 对「源契约失效」的检测 AUC 严格高于任一单通道。若二者因共享数据偏见而相关（ρ→1），增益消失——**这正是语言与源共谋的风险，必须用反事实探针/目标标定打破相关性**。

**引理 30（组合接口误差累积）** 定义 347 下，n 个原语组合的计划误差上界为 Σ ε_j + Σ interface_j。若接口误差独立同分布均值 μ，则组合数 n 的最优选择满足边际收益 ≤ μ；超过后「多接一个技能」反而降低可靠性。系：**迁移的收益不是单调的；技能库越大，检索越容易，但组合越脆**。

**定理 23（四层严格嵌套）** A99–A108 下，TILT 的期望风险 ≤ BELIEF ≤ FLUID ≤ R68；当 𝒦={∅}、U_transfer=U_ground=0、NTG 恒拒绝、η 冻结时逐指令相同（定义 349）。安全侧四条退避保证新通道只能更早保守。

**定理 24（语言不能放宽安全）** 定义 331-iii/iv 下，任何语言指令或语言先验都不能改变 C-RAS-WM 认证结果；若语言与认证冲突，以认证为准。因此语言层最多改变「选哪个已认证动作」，不改变安全包络，提交/换装不变式（R68 定理 15）保持。

**定理 25（可卸载性与在线适应有界）** 在定义 343 的有界适应下，任意时刻禁用全部源与语言先验，系统在一个控制周期内回到 R70 目标域行为；η 的有界性保证不会因长期在线适应而漂移到未认证区域。**可卸载性是「新知识不是负债」的形式化保证。**

## 6. 本轮最大风险

**一句话**：**TILT 的最大风险是「语言与源模型共享同一个偏见」——当源数据、源技能的语言契约、用户指令三者一致时，系统会得到一个低熵、低 U_transfer、低 U_ground 的「三重认证」，但一致的只是同一个采集偏差，不是真相；迁移让错误更自信，语言让错误更合理，而 TILT 的退避机制恰恰会被这种「共识」骗过。**

**次级风险与缓解**：

1. **NTG 的域适应界依赖可交换性与有界假设类**，真实机制变化（p(y|x) 变）时下界可能过松 → 机制残差 + 锚点要求 + 拒绝迁移的默认策略；
2. **语言文法覆盖不足**会把「没听懂」误报为「没歧义」 → 语法外检测 + U_ground 下限 + 澄清；
3. **技能组合的接口误差在多源迁移下累积** → 定义 347 误差预算 + 组合数上限 + E348；
4. **共形校准集被污染**会破坏覆盖率保证 → 鲁棒共形/分割共形 + ℰ_ground 投毒实验 + 审计；
5. **在线适应慢性漂移** → 定义 343 有界性 + 定期锚定回 η_0 + E349；
6. **最根本的**：没有锚点的零样本迁移在数学上不可辨识，任何声称「零样本安全迁移」的主张都应被拒绝（定义 348）。

## 2. 形式化定义（要点版）

**定义 331（总览与四不变式）** TILT-RAS 继承 R70 全部组件（†），新增 SCL/TCG/NTG/CRET/LGI/CLAR/SEM/BAA/Nesting。四不变式：(i) 实时零学习写操作，只允许有界在线适应；(ii) 迁移安全单调：未过 NTG 的源一律剔除，退回目标域 R70；(iii) 语言只作先验/证据/检索键，不覆盖安全认证；(iv) 可卸载性：任一源/语言先验可热插拔禁用，禁用后逐指令回 R70。

**定义 332（技能库与迁移契约 SCL）** 技能库 𝒦={(k_i,c_i,D_i,Ω_i)}，契约 c_i 是部分规格：声明「若 φ_i^pre 成立，则期望 φ_i^post」，不保证在 Ω_i 内绝对正确。契约是「可检查的承诺」，不是「已验证的真理」。

**定义 333（可迁移性参数 TCG）** θ_i=(ov_i, sh_i, mech_i)。ov_i=P_{x∼T}[x∈Ω_i]；sh_i=MMD(𝒟_i|Ω_i, 𝒟_T|Ω_i)（或域分类器 AUC−0.5）；mech_i=目标标定集与源残差的校准差（无标签时用置信一致性/预测翻转率代理）。源权重 w_i ∝ π_i·exp(−λ_o ov_i − λ_s sh_i − λ_m mech_i)，再经 NTG 硬门控。

**定义 334（语言接地图 LGI）** ℓ 解析为 P_ℓ=(g_1..g_n; C; ψ)。接地后验 p(g|ℓ,o_t) 由解析歧义 × 参数歧义 × 感知歧义构成；输出计划与未绑定参数集。

**定义 335（指令歧义 U_ground）** U_ground=H[g|ℓ,o_t]。区分可问歧义（用户可澄清）与不可问歧义（环境遮挡/听不清）。只有 VoI>成本时才澄清；否则直接进保守通道。

**定义 336（共形检索 CRET）** 校准集打分 s(ℓ,k_i)，C_α(ℓ)={k_i: s(ℓ,k_i)≥τ_α}。可交换性下 P(k*∈C_α)≥1−α。只产候选，不定案；|C_α| 作为不确定性的诚实度量。

**定义 337（负迁移守卫 NTG）** 认证条件：

    LCB_δ(R_T(∅) − R_T(k_i)) > 0
    ∧ φ_i^pre 在目标域成立
    ∧ ov_i ≥ ov_min
    ∧ mech_i ≤ mech_max。

下界由源风险 + 域适应界（R_T ≤ R_S + d_HΔH + λ）+ 目标标定集给出。认证失败即拒绝，绝不「平均还行就上」。

**定义 338（迁移感知 BSE†）** b_t^T(s) ∝ p(o_t|s,θ)·Σ_i w_i∫p(s_t|s_{t−1},k_i)b_{t−1}^T(s_{t−1})ds_{t−1}；未认证源 w_i=0。NTG 失败时整源剔除并退回目标域先验，避免残留源先验继续制造低熵错误。

**定义 339（迁移不确定性 U_transfer）** U_transfer=H(w)+Σ_i w_i·D_KL(p_T(·|k_i)‖p_T(·|∅))。H(w) 是「信哪个源」的熵；第二项是「源与目标域从零模型的差异」。与 U_epi 正交。

**定义 340（语义一致性 SEM）** 执行后检查 ψ 与各 φ_i^post 的满足度，得 r_sem∈[0,1]。r_sem 高且源仍自信 ⇒ 源契约在目标域失效，与 r_res、Δa 正交。

**定义 341（澄清协议 CLAR）** U_ground 高且 VoI>成本时，从文法生成最小澄清问句（指代/约束优先级/成功判据三选一），经 MINT/CIA 认证与证据纪律执行；澄清只更新接地后验，不改写源技能。

**定义 342（四通道退避）** λ=λ_floor(U_ale+α_epi·U_epi+α_tr·U_transfer+α_g·U_ground)。α_tr=0 仅当 NTG 认证且 SEM 未报警；α_g=0 仅当 U_ground<τ_g 或澄清后下降；α_epi 同 R70。任一项未认证 ⇒ α=1；TILT 不得比 BELIEF 更激进。

**定义 343（有界在线适应 BAA）** η∈ℋ 低维（偏置/增益/门控温度），‖η_t−η_0‖≤B_η、更新率≤ρ；每次适应须过 NTG 的「不劣化」检验；禁止全参数微调。

**定义 344（迁移溯源审计 VQAuditor-III）** 记录 C_α、NTG_LCB、采纳/拒绝源、契约检查、r_sem、指令哈希、η_t；审计「语言是否诱导」「源是否被过度信任」「拒绝是否及时」。

**定义 345（AIC-TILT）** ℰ_TILT=ℰ_BELIEF×ℰ_transfer×ℰ_ground：源投毒、负迁移诱导、指令注入/歧义利用、语言-源共谋、共形校准集污染。

**定义 346（证书 J_TILT）** Valid ⇔ Valid(J_BELIEF) ∧ (所有采纳源均认证 ∨ 未采纳) ∧ U_transfer/U_ground 已按定义 342 退避 ∧ 审计完整。

**定义 347（组合接口误差）** ε_plan ≤ Σ_j ε_j + Σ_j interface(g_j,g_{j+1})。组合数不是越多越好；接口误差给出组合上限。

**定义 348（可辨识与锚点）** 无标签、无重叠、机制任意变化时 NTG 不可辨识。必须有锚点（小目标标定集/可靠锚技能/可观测 success predicate）；无锚点 ⇒ 禁止迁移。

**定义 349（嵌套退化）** 𝒦={∅}、U_transfer=U_ground=0、CRET 返回空、NTG 恒拒绝、η≡η_0 ⇒ 与 BELIEF 逐指令相同；再关交互 ⇒ FLUID/R68。

# IP-275/276/277：技能库、可迁移性、负迁移守卫
class Skill:
    def __init__(self, policy, pre, post, desc, domain, stats, source_risk):
        self.policy, self.pre, self.post = policy, pre, post
        self.desc, self.domain = desc, domain
        self.stats, self.source_risk = stats, source_risk

class NGT:
    def __init__(self, delta, ov_min, mech_max):
        self.delta, self.ov_min, self.mech_max = delta, ov_min, mech_max

    def certify(self, k, D_T_cal, D_T_u):
        ov   = support_overlap(k.domain, D_T_u)
        sh   = domain_shift(k.stats, D_T_u)
        mech = mechanism_residual(k, D_T_cal)
        if ov < self.ov_min or mech > self.mech_max:
            return False, None, {"reason": "contract_or_support"}
        bound = k.source_risk + domain_adaptation_bound(sh, k.stats, D_T_cal, self.delta)
        fb    = target_only_risk(D_T_cal)
        lcb   = lower_confidence_bound(fb - bound, D_T_cal, self.delta)
        ok    = lcb > 0
        return ok, lcb, {"ov": ov, "sh": sh, "mech": mech, "lcb": lcb}

# IP-278：共形检索（只给候选，不拍板）
def conformal_retrieve(ell, lib, score_fn, tau_alpha):
    cand = [(k, score_fn(ell, k)) for k in lib if score_fn(ell, k) >= tau_alpha]
    return cand, len(cand)

# IP-279/280：语言接地与澄清
class LanguageGrounder:
    def parse(self, ell, state):
        parses, p_parse = typed_grammar(ell)
        plans = [bind(p, state) for p in parses]
        post   = normalize([p_parse[i] * plan_likelihood(plans[i], state)
                            for i in range(len(plans))])
        return plans, post, entropy(post)

    def clarify(self, plans, post, budget):
        if entropy(post) < TAU_G: return None
        q = min_clarification_question(plans, post, mode="referent|priority|success")
        return q if voi(q, post) > cost(q) and budget.allow(q) else None

# IP-281：语义一致性（第二意见）
def semantic_residual(plan, obs, psi):
    post_ok = mean([satisfies(g.post, obs) for g in plan.primitives])
    succ_ok = satisfies(psi, obs)
    return 1.0 - 0.5 * (post_ok + succ_ok)            # 越高越可疑

# IP-282：迁移感知 BSE（认证失败整源剔除）
def transfer_belief(b_prev, o_t, accepted, lcbs, lib):
    if not accepted:
        return target_only_bse(b_prev, o_t), {}, 0.0
    w = normalize([exp(LAMBDA * lcbs[k.id]) for k in accepted])  # LCB 越大权重越高
    b = mixture_update(b_prev, o_t, accepted, w)
    return b, {k.id: w[i] for i, k in enumerate(accepted)}, entropy(w)

# IP-289：TILT-RAS 主闭环
def TILT_round(M, obs, ell):
    # A. 语言接地 + 共形候选
    plans, p_g, U_ground = M.lgi.parse(ell, obs)
    cand, size = conformal_retrieve(ell, M.lib, M.score, M.tau_alpha)
    # B. 迁移认证（硬门控）
    gates = {}
    accepted = []
    for k, _ in cand:
        ok, lcb, diag = M.ntg.certify(k, M.D_T_cal, M.D_T_u)
        gates[k.id] = (ok, lcb, diag)
        if ok: accepted.append(k)
    # C. 迁移感知后验与四通道
    b_t, w, H_w = transfer_belief(M.b_prev, obs, accepted,
                                  {k.id: gates[k.id][1] for k in accepted}, M.lib)
    U_ale = M.aud.aleatoric(b_t)
    U_epi = entropy(b_t)
    U_transfer = H_w + source_target_disagreement(accepted, w, M.fmp, obs)
    # D. 语义残差 + 澄清
    r_sem = semantic_residual(plans[argmax(p_g)], obs, plans[argmax(p_g)].psi) if plans else 0.0
    if U_ground > M.tau_g and not M.slow_fault:
        q = M.lgi.clarify(plans, p_g, M.budget)
        if q:
            y = M.clar.execute(q)
            plans, p_g, U_ground = M.lgi.update(plans, p_g, y)
    # E. 四通道退避（未认证一律计入）
    auth_tr = bool(accepted) and all(gates[k.id][0] for k in accepted) and r_sem < M.tau_sem
    U_floor = U_ale + U_epi \
              + (0.0 if auth_tr else U_transfer) \
              + (0.0 if U_ground < M.tau_g else U_ground)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    # F. 计划 → 动作；语言绝不覆盖安全认证
    plan = plans[argmax(p_g)] if plans else None
    A = M.ach.propose_from_program(plan, b_t) if plan else M.ach.propose(...)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    eta = M.adapt.bounded_update(obs, B_eta=M.B_eta, rho=M.rho)
    if not auth_tr or M.slow_fault:
        lam = max(lam, 0.8)
        k   = min(k, M.k_cal_shrink(A, U_floor))
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam
    # G. 审计、证书、可卸载记录
    M.vqa_iii.submit_async(ell, cand, gates, w, U_transfer, U_ground, r_sem, eta)
    M.jcert.emit(J_TILT(...))
    M.b_prev = b_t
    return k, lam, A[:k], (U_ale, U_epi, U_transfer, U_ground)

## 4. 推导

**引理 26（负迁移低熵悖论）** 若源先验在目标域的机制 KL 为 ε、方差为 σ_S²，则迁移后验方差 ≤ σ_S²，但均值偏差 ≥ √(2ε)。故 `H[b_t]` 可任意小、风险 ≥ c√ε。**迁移破坏了「熵=无知」的等式**，必须新增 U_transfer。

**引理 27（NTG 安全迁移界）** 域适应界 + 可交换标定集下，`LCB_δ(R_T(∅)−R_T(k_i))>0` ⇒ 以 1−δ 概率 `R_T(k_i) ≤ R_T(∅)`。认证通过是**单侧风险断言**，不是平均精度叙事；真实负迁移越强，通过率越低。

**引理 28（共形覆盖）** 指令–技能对可交换下，`P(k*∈C_α)≥1−α`，与打分模型是否正确无关。语言可以错，但候选集的覆盖率有分布无关下界；`|C_α|` 是诚实的语言不确定性。

**引理 29（语言第二意见的独立性）** 若 r_sem 与 a_score 在真实机制下条件独立，则联合判别 AUC 严格高于单通道；若二者因共享偏见相关（ρ→1），增益消失。故必须用反事实探针/目标标定打破相关性。

**引理 30（组合接口误差）** n 原语组合误差 ≤ Σε_j+Σinterface_j；接口误差均值为 μ 时，组合数的最优选择满足边际收益 ≤ μ。技能库越大，检索越易，组合越脆。

**定理 23（严格嵌套）** A99–A108 下 `TILT ≤ BELIEF ≤ FLUID ≤ R68`；退化边界（定义 349）逐指令相同。安全侧只允许更早保守。

**定理 24（语言不能放宽安全）** 语言与 C-RAS-WM 冲突时以认证为准；语言最多改变「选哪个已认证动作」，不改安全包络，提交/换装不变式保持。

**定理 25（可卸载、适应有界）** 禁用全部源与语言先验后一个控制周期内回到 R70 目标域行为；η 有界防止长期适应漂移到未认证区域。

## 8. 本轮最大风险

**一句话**：**TILT 的最大风险是「语言与源模型共享同一个偏见」——当源数据、源技能的语言契约、用户指令三者一致时，系统会得到一个低熵、低 U_transfer、低 U_ground 的「三重认证」，但一致的只是同一个采集偏差，不是真相；迁移让错误更自信，语言让错误更合理，而 TILT 的退避机制恰恰会被这种「共识」骗过。**

**次级风险与验收缓解**：

1. **NTG 界过松/假设违背**（机制变化、假设类无界）→ 默认拒绝迁移 + 锚点要求（定义 348）+ E342/E352；
2. **语言文法覆盖不足**（把「没听懂」误报为「没歧义」）→ 语法外检测 + U_ground 下限 + E355；
3. **共形校准集污染** → 鲁棒/分割共形 + ℰ_ground 投毒 + E350；
4. **组合接口误差累积** → 定义 347 误差预算 + 组合数上限 + E348；
5. **在线适应慢性漂移** → 定义 343 有界 + 周期锚定回 η_0 + E349；
6. **最根本的**：无锚点零样本迁移在数学上不可辨识，任何「零样本安全迁移」主张都应被拒绝（定义 348）。
