# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~301；灵感循环第 1 轮；本轮灵感：「成本控制」×「文化适应性」）

> R73 把「证据计量」做成了可组合契约（EC / MReg / CCA / ΣREFLEX / CPB），并宣称三类系统级性质在热替换下保持。但它有三个**被自身成功掩盖的隐含假设**：
> - **成本是标量脚注**：R73 有预算（B_total、WCET、CertCost），却没有**价格**。不确定度、能量、金钱、算力、人类注意力、隐私之间没有汇率；「缩窄总是好的」被默认；PVOP 的目标里没有观测成本，参数 λ 只惩罚残余不确定度，不惩罚**为获得证据所付出的代价**。于是系统可以为了 1% 的 u 下降而烧掉 10 倍电量、占用人类 10 分钟、或侵犯一次隐私，而审计日志只会说「u 更小，所以更好」。
> - **价值是单文化的**：R73 的 λ、否决集、误差代价矩阵、CPB 指标都隐含一个「通用人类」。跨文化部署时，意图先验、距离/触碰/凝视规范、隐私预期、错误代价、对机器人主动性的容忍度全都不同。更致命的是：**conformal 的交换性按文化群破裂**——边际覆盖率 1−α 可以在总体上成立，却在少数群体上系统性欠覆盖；「平均安全」会把少数人的伤害平均掉。
> - **两者是耦合的**：某些感知动作在某些文化语境中**本身就是成本/违规**（摄像头、录音、近距凝视、主动触碰），所以「可采证据的动作集」是文化条件化的；反过来，「买多少确定性」的边际价值也随风险厌恶、隐私敏感度、社会规范而变。成本控制不能是文化中立的，文化适应也不能无视成本。
>
> 本轮把这两个灵感提升为同一根理论支柱：**证据的「汇率」不是常数，而是契约中声明的、上下文条件化的对象。** 成本控制问「能买多少确定性」；文化适应问「用谁的价值函数来定价」；二者交汇于 **VoI（信息价值）**。R73 的契约柱是「类型 + 预算 + 通道」，组合柱是「单调 + 审计 + 热替换」；本轮加第三根柱子：**价值（value）**——成本向量、保护轴、规范格、分组覆盖与延迟裁决。
>
> 核心命题：**不再问「证据够不够准」，而问「在当前文化语境与预算下，这份证据值不值得买、由谁承担代价、以及在价值不可比时系统是否有权替人做决定？」** 把 R73 的「计量契约代数」升级为 **ECONGAUGE-RAS**（ECONomic & cultural evidence metrology with GAUGE audits for RAS）——**证据-价值契约**。

## 0. 直觉与动机

**灵感 1（成本控制 → 证据是买来的，而且不是用同一种货币买的）**
直觉：计量学论文习惯把「更小的不确定度」当作绝对善，但工程现实是——每一个 u 的下降都有账单：更多采样、更高分辨率、更贵的传感器、更多标注、更长校准、更多人类确认、更高能耗。更重要的是，**账单不止一种货币**：能量、时间、算力、金钱、人类注意力大体可通约；隐私、尊严、社会规范**不可通约**——不能用「省了 3 度电」去补偿「多拍了一张卧室照片」。因此成本必须是一个**向量**，并且带**非补偿的保护轴**（与 R71 的否决语义同构：保护轴越界不能被其他轴的收益抵消）。
第二个直觉：**便宜可能更贵**。一个廉价传感器输出更大的 u，这个 u 会沿组合传播，变成下游的重试、人类接管、认证与返工成本。所以成本必须像不确定度一样**沿契约传播**：`cost_out = cost_in + cost_self + λ_down · u_out`。把 u 压成一次性采购价，会系统性高估「便宜模块」，这正是成本控制最常见的自欺。
第三个直觉：**成本归一化是可识别性的前提**。如果 A 方法比 B 方法多花 10 倍算力，那么「A 更准」并不识别 A 的机制；它只识别「A 更有钱」。任何主张都必须在**等成本切片**与**等安全切片**上同时报告，否则竞品分析会退化为资源竞赛。

**灵感 2（文化适应性 → 价值是局部的，但底线必须是通用的）**
直觉：文化适应不是「换一套礼貌用语」，而是换一整套**条件似然与代价矩阵**：同样的手势在不同文化中含义相反；同样的距离在一处是礼貌、在另一处是冒犯；同样的「主动帮助」在一处是体贴、在另一处是冒犯自主性；同样的摄像头在一处是便利、在另一处是监控。把文化适应做成语言/人格层，是在 R73 批判的「类型擦除」之上再叠一层「价值擦除」。
但也不能滑向「什么都可以」的相对主义：**身体安全、非胁迫、可撤回、隐私最低线、非歧视**必须是通用底线。正确结构是一个**规范格**：局部规范可以有多样边缘（问候距离、凝视时长、触碰许可、披露程度、主动性），但所有局部规范的**交（meet）**是不可协商的通用底线；适应只能在边缘区移动，不能触碰底线。跨群体还要加**外部性审计**：为群体 h 做的适应，不得降低群体 h′ 的底线。
技术上的关键推论：**文化条件校准必须是分组（Mondrian）的**。边际 conformal 的 1−α 覆盖不蕴含任一子群的 1−α 覆盖；在文化分布漂移下，用总体覆盖率给少数群体背书，是一种**统计上的文化抹除**。分组校准又带来一个残酷的成本事实：小群体样本少，达标认证的**人均成本 ∝ 1/p_h**——成本控制与文化公平会发生真实冲突，不能靠口号调和，只能靠层级迁移、显式覆盖率债务与公平预算来管理。

**灵感 3（两者交汇 → 不确定度的汇率是文化条件化的）**
直觉：同一份深度证据，对一个「高风险厌恶 + 隐私不敏感」的语境可能值得买；对一个「隐私极度敏感」的语境可能**根本不允许采**。所以可采动作集 `A_adm(h)`、风险厌恶 `λ(h)`、误差代价 `L_h`、保护轴上限都随文化上下文 h 变。VoI 不是全局常数，而是 `VoI(a | h, budget)`。这也解释了为什么 R73 的 PVOP 在跨文化部署时会「合法地做错事」：它优化的是一个未经声明、被默认为普适的价值函数。
进一步：当两个语境的规范在保护轴上**不可比**（没有共同标量汇率）时，系统不应偷偷加权求和。正确行为是 **SafeDefer**：保持安全状态、在时限内请求人类裁决、给出可回退路径。不可比不是死锁——死锁是「无路可走」，延迟是「主动选择不走，并承担等待成本」。

**灵感 4（对 R73 的自我修正）**
R73 的 C3/引理 35 说「同契约替换实现 ⇒ 系统级性质保持」。但文化适应改变的不是实现，而是**契约本身**（先验、代价矩阵、有效域、否决集）。所以「热替换定理」不覆盖文化迁移，必须新增**契约族**与**迁移证书**：`EC(h)` 是一族契约，适应算子只能在规范边缘区与标定层上移动，且必须证明通用底线与物理安全不变式保持。同理，R73 的 stub 降级假设「失效就退到空证据」；但预算耗尽不是失效，正确语义是**沿服务层级单调降级**（更低分辨率/更少采样/更晚更新），最后才是 stub。这两条修正让「严格包含」更精确：**在单文化、可通约成本、无保护轴、无预算耗尽的极限下逐指令退回 R73。**

**灵感 5（统一抽象：证据-价值契约）**
把 R73 的 EC 扩为 `EC⊕ = (EC, CBC, HIM, NL)`：证据契约 + 成本契约 + 人类接口契约 + 规范约束。组合时同时校验四件事：类型对、预算闭合、**成本闭合**、**规范底线保持**。这样「成本控制」与「文化适应」不是两个附加章节，而是两个新的**契约字段**与两个新的**组合校验**——与 R73 的模块化哲学一致：新维度 = 新字段 + 新校验，而不是主闭环里再手写一层。

## 1. 形式化定义（增量：定义 383–400）

**定义 383（ECONGAUGE-RAS 总览与十不变式）** ECONGAUGE-RAS = (MMS†, CBC, CBA, EBA, HIM, NL, GCA, CTX, ECP, CVL†, CPB†, MODGAUGE-RAS†)。在 R73 五不变式上增五条：
(vi) **成本显式性**：每个模块必须声明成本契约（定义 384），未计入成本的资源视为不可用；运行时计量与声明不符即降级；
(vii) **保护轴非补偿**：隐私/尊严/规范等保护轴（定义 384）不允许被可通约轴的收益抵消，组合取分量上限而非加权和；
(viii) **分组覆盖**：人类相关证据的覆盖率必须按文化上下文分组保证，或显式声明覆盖率债务并回退保守界（定义 390）；只用边际覆盖率视为无效；
(ix) **通用底线不变**：文化适应只能在规范格的边缘区移动，通用底线（定义 389）在迁移前后逐项保持；
(x) **不可比即延迟**：保护轴上不可比的候选不得做标量合并，必须进入 SafeDefer（定义 393）。

**定义 384（成本契约 CBC）** CBC = (C_comm, C_prot, c_marg, u_marg, A_adm, β_cost, ℓ_down, seal_ref)：
- `C_comm = (energy, time, compute, money, attention)`：**可通约成本轴**；
- `C_prot = (privacy, dignity, norm)`：**保护轴**，只有上限与越界指示，没有价格；
- `c_marg: A × X → R^{|C_comm|+|C_prot|}_{≥0}`：动作的边际成本；
- `u_marg: A × X → R_{≥0}`：该动作带来的**可认证**不确定度下降（假设次模、边际递减；不可认证的下降不计）；
- `A_adm(h) ⊆ A`：文化条件化的可采动作集（某些传感/交互在 h 下直接不可采）；
- `β_cost`：可通约预算向量 + 保护轴上限；
- `ℓ_down: u ↦ R^{|C_comm|}`：残余不确定度导致的下游期望代价（重试/接管/返工/认证）；
- `seal_ref`：成本与隐私审计集引用。
**方向约定**：便宜 = 成本小、u 大；贵 = 成本大、u 小。成本契约声明的是**前沿**，不是单点。

**定义 385（成本代数 CBA 与生命周期成本）** 两个成本向量的组合：
- 可通约轴：`c_out = c_in + c_self + ℓ_down(u_out)`（向量加法）；
- 保护轴：`c_prot,out = max(c_prot,in, c_prot,self)`（分量取大，**禁止相减/抵消**）；
- 预算可行性：`c_comm,out ≤ β_comm` 且 `c_prot,out ≤ β_prot`（逐轴）。
**成本闭合**：下游声明消耗 ≤ 上游生成，且生命周期总成本 ≤ 声明预算。**单调性**：在固定策略下，u_out 增大不可能使 cost 减小（因为 `ℓ_down` 非减）；因此「便宜但更不确定」的模块必须显式走服务层级（定义 394），不能伪装成同契约实现。

**定义 386（证据-成本前沿与 VoI）** 对动作 a，给定上下文 h 与当前证据状态：
`VoI(a | h) = (E[Loss(u_current)] − E[Loss(u_after(a))]) / (w·c_marg(a) + w·ℓ_down(u_after(a)))`，
其中标量 `w` 只有在**已声明汇率**时才允许存在。未声明汇率时，只定义 **Pareto 前沿** `F_h = {a : ¬∃a′ 使 c(a′)≤c(a) 且 u(a′)≤u(a)，至少一严格}`，以及保护轴不可比集。**声明汇率纪律**：汇率必须显式写入契约并经人类/伦理审查，禁止从数据中静默学习一个「隐私的价格」。

**定义 387（文化上下文与文化后验）** 文化上下文 `h ∈ H`（当前实例化的有限近似，连续谱见风险 6）。`b_t(h)` 由**声明的区域设置、用户显式选择、经同意的交互线索**给出；**禁止**仅从受保护属性（种族/宗教/母语口音等）推断并用于优化（定义 399）。风险聚合在可信集 `H_t` 上取**最坏情况或 CVaR**，而非按群体占比加权平均——按占比平均会把少数群体的伤害平均掉。

**定义 388（文化条件人类接口契约 HIM）** HIM(h) = (p_h(z | ·), L_h, C_h, Ω_h, A_adm(h), lexicon_h, proxemics_h, privacy_h)：
- `p_h(z|·)`：意图/状态先验；`L_h`：误差代价矩阵（如误拒帮助 vs 冒犯自主性）；
- `Ω_h`：文化条件安全集（物理安全 ∩ 规范边缘区）；
- `A_adm(h)`：可采感知/交互动作（摄像头/录音/近距/触碰的许可）；
- HIM 是**一等模块**，有 EC、有 cert、可热替换；不是文案层。

**定义 389（规范格 NL 与通用底线）** 规范集合 `N` 配偏序 `⊑`、交 `∧`、并 `∨` 构成格。**通用底线** `N_univ = ∧_{h∈H} N_h`，至少含：身体安全、非胁迫与可撤回、隐私最低线、非歧视。**边缘区** `N_h \ N_univ` 含问候距离、凝视时长、触碰许可、披露程度、主动性、语气。**适应约束**：任何 `T_h: N_h0 → N_h1` 必须满足 `T_h(N_univ) = N_univ`，且不得降低其他群体的底线（外部性）。当 `n1, n2 ∈ N` 不可比时，**禁止**用标量效用合并（定义 393）。

**定义 390（分组 conformal 校准 GCA 与覆盖率债务）** 对每个上下文 h 维护校准集 `D_h`，输出 `C_{α,h}` 使 `P(Y ∈ C_{α,h} | H = h) ≥ 1−α`（Mondrian conformal）。当 `|D_h| < n_min(α, δ)` 时：
- 从层级父群体迁移（层级贝叶斯/加权保形）并在证书中写明显式**覆盖率债务** `debt_h = (1−α) − 实际下界`；
- 若无父群体或债务超过 `debt_max`，回退到**最坏群体保守界** `min_h′ (1−α_h′)`，并降低自治等级；
- **禁止**用总体边际覆盖率冒充分组覆盖。`n_min = Ω(α^{-1} log δ^{-1})`。

**定义 391（文化迁移算子 CTX 与迁移证书 J_CTX）** `CTX: (EC_{h0}, D_{h1}, HIM(h1)) → EC_{h1}`。步骤：替换 HIM → 在 `D_{h1}` 上重校准 → 验证底线保持与外部性 → 重算成本闭合。`J_CTX` 校验：`N_univ` 逐项不变、分组覆盖达标或债务显式、保护轴上限未被放宽、成本闭合。**认证成本** `CertCost_ctx = O(|HIM| + n_{h1})`，而非 `O(系统)`。

**定义 392（成本-文化联合规划 ECP）** 联合动作 `a` 的可行集先经保护轴与规范过滤，再做字典序/约束优化：
1. 硬约束：`a ∈ A_adm(h)`、`c_prot ≤ β_prot`、`Ω_h`、R73 物理安全集；
2. 在剩余可行集上最大化 `Progress(a) − λ(h)·E[L_h] − Σ_i VoI 归一化成本`；
3. 若第 2 步的最优集在保护轴上不可比 ⇒ SafeDefer（定义 393）。
**注意**：先硬约束后优化，使得成本/隐私不能被「更大的进度」买通。

**定义 393（不可比性与安全延迟 SafeDefer）** 若候选集 `P` 在保护轴偏序上存在不可比元素，系统不得选取一个「加权赢家」，而进入 SafeDefer(s)：
- 维持一个已验证的 Safe 状态（不持续推进任务）；
- 在 `T_defer` 内向指定人类请求裁决，给出各候选的保护轴代价与可回退路径；
- 若超时，执行**预注册的保守回退**（最小暴露、最小动作、最大可撤回）；
- **活性**：SafeDefer 不是死锁，要求存在有限时间内的退出路径；进度损失有上界 `ΔProg_defer`。

**定义 394（成本感知退化链与服务层级）** 每个模块声明服务层级 `t0 ≽ t1 ≽ … ≽ tk`，每层是同一 EC 的**显式特化**：`u(t0) ≤ u(t1) ≤ …`、`cost(t0) ≥ cost(t1) ≥ …`，且每层仍满足各自声明的有效域。预算耗尽时沿层级单调降级（降分辨率/降采样率/延迟更新/关闭可选模态），**最后**才是 R73 的 stub。层级顺序是偏序且良基，降级有限步终止。**这修正 R73 的 stub-only 语义：预算压力不是失效，而是可声明的服务降级。**

**定义 395（成本-文化证书 J_ECON）** `J_ECON = J_MOD ⊗ J_cost ⊗ J_norm ⊗ J_group ⊗ J_ctx`：
- `J_cost`：成本闭合、生命周期成本、运行时计量一致、保护轴未越界；
- `J_norm`：规范格边缘区合法、通用底线保持、外部性审计通过；
- `J_group`：分组覆盖达标或覆盖率债务显式且未超限；
- `J_ctx`：迁移证书有效。
`Valid(J_ECON) ⇒` 物理风险界 + 分组覆盖 + 底线不变 + 成本闭合。

**定义 396（成本归一化基线）** 任何比较必须报告三个切片：(i) **等成本**（预算向量相同）；(ii) **等安全**（物理风险/分组覆盖相同）；(iii) **等人类负担**（注意力/干预次数相同）。定义成本归一化证据效率 `C-NEER = Δ安全 / Δ生命周期成本`。只在「更多资源」切片上取胜的主张标记为**不可识别**，降级为附录。

**定义 397（MBench-C 成本与文化最小基准）** MB-C1 成本前沿辨识；MB-C2 预算约束交互；MB-C3 跨文化分组校准与迁移；MB-C4 规范冲突与 SafeDefer；MB-C5 稀有群体认证税与层级迁移。各 ≤3 小时单卡/单台可复现，预注册脚本 + 固定种子 + 密封集 SEAL-C。

**定义 398（成本-文化复杂度结构上限）** 可通约轴 ≤5、保护轴 ≤3、活跃上下文 `|H| ≤ 8`、服务层级 ≤4、规范格节点 ≤64、延迟裁决候选 ≤8；全部作为可审计的部署期/运行时图性质。

**定义 399（文化隐私与伦理审计 SEAL-NORM）** 禁止以受保护属性为优化输入；文化上下文只来自显式声明、同意或聚合统计；校准数据来源须审计（避免「校准数据殖民」）；报告**分组伤害**而非总体均值；保留人类否决与撤回；第三方伦理审查。**任何降低底线的「文化适应」直接判为无效证书。**

**定义 400（主张扩展 C4/C5）**
- **C4（成本感知证据计量）**：显式成本契约 + 生命周期成本传播 + VoI 分配，在**等成本**下比「最大精度」「固定阈值」「无脑多采」获得更好的安全-成本 Pareto；且成本归一化使机制主张可识别。
- **C5（文化条件适应）**：分组 conformal + 规范格底线 + 迁移证书，在**跨文化迁移**下保持每组覆盖与通用底线，而边际-only 校准会在少数群体上欠覆盖并可能违反底线；适应认证成本为 `O(模块+群体)`，而非 `O(系统)`。

## 2. 推导

**引理 38（不免费证据下界）** 在分割保形框架下，要以置信度 1−δ 认证覆盖率 1−α，每组校准样本至少 `n_min = Ω(α^{-1} log δ^{-1})`；因此认证成本存在正下界 `Σ_h n_h c_cal`。不存在「零成本地把 u 降到证书可认证的水平」的路径。系：**成本不是实现细节，而是与覆盖率同等级的可证伪资源约束。**

**引理 39（成本归一化的可识别性）** 若方法 A 的预算严格大于 B，则 A 在任何单调指标上的优势都不能识别其机制 M；存在一个「更多资源但无 M」的对照同样获胜。故明确机制主张必须在等成本切片上成立，否则不可识别。系：**成本控制同时是竞品分析的方法论纪律，而不只是工程优化。**

**引理 40（边际覆盖率不蕴含分组覆盖率）** 由全概率公式 `P(Y∈C) = Σ_h p_h P(Y∈C|h)`，总体 ≥1−α 只约束加权和；存在分组覆盖远低于 1−α 而总体仍达标的分配。故用边际覆盖率给少数群体背书无效。系：**文化适应的第一技术条件不是语言模型，而是分组校准。**

**引理 41（保护轴非补偿下的底线保持）** 若适应算子只修改边缘区、且保护轴组合取分量上限（定义 385/389），则对任意迁移链，`N_univ` 逐项不变；任何试图用可通约轴收益抵消保护轴越界的路径都不在可行集内。系：**「文化相对主义 + 通用底线」可以被写成组合单调性，而不是伦理口号。**

**引理 42（成本感知降级的单调性与终止）** 服务层级是良基偏序，且 `u` 随层级单调不减、`cost` 单调不增；每次降级严格下移一层，故在 ≤k 步内到达最低层或 stub；每层契约有效时物理安全不变式保持。系：**预算压力下的安全是「慢下来/变糙」，不是「突然失明」。**

**引理 43（不可比延迟的安全性）** 若 SafeDefer 的保守回退在 `T_defer` 内可达且属于已验证 Safe 集，则延迟期间不进入 `ObjRisk`；活性要求每个延迟态存在有限退出路径。进度损失上界由 `ΔProg_defer` 给出。系：**「不替人做价值判断」本身可以是一个可证的安全策略，而非功能缺失。**

**定理 30（ECONGAUGE 严格包含）** 当 `|H|=1`、成本可通约且无保护轴、无服务层级、无 SafeDefer、`ℓ_down ≡ 0` 时，ECONGAUGE 逐指令退化为 MODGAUGE-RAS，再退化为 R72/R71/R68。**安全单调不减；成本/文化维度只在契约声明时生效。** 注意：该定理不覆盖「文化契约改变」的迁移（由定理 32 处理）。

**定理 31（联合证书有效性 ⇒ 安全 + 分组覆盖 + 底线）** 在 A-econ 假设（成本可计量、覆盖率估计有效、规范格模型覆盖真实规范、保护轴上限真实）下：`Valid(J_ECON) ⇒` (i) 各模块 cert 有效；(ii) 成本闭合且保护轴未越界；(iii) 每组覆盖达标或债务显式；(iv) `N_univ` 不变；(v) 物理执行风险 ≤ ε_econ（相对成本模型与**规范模型**的表达力）。**证明重量现在落在「规范模型是否覆盖真实文化边缘」与「成本计量是否被恶意低报」上。**

**定理 32（文化迁移保持通用安全 + 认证局部化）** 若 `CTX` 只替换 HIM 与分组校准层、保持所有关联 EC 的类型/物理有效域/否决语义，且 `J_CTX` 有效，则通用底线与 R73 物理安全不变式在迁移后逐指令保持；认证成本从 `O(系统)` 降为 `O(|HIM| + n_{h1})`。系：**文化适应是模块化的，但它的单元是「HIM + 群体校准」，不是「国家/语言」这种粗标签。**

**定理 33（成本-公平张力 / 稀有文化认证税）** 固定总校准预算 B 与统一覆盖率 1−α：若按总体独立同分布采样，则群体 h 的期望样本数为 `n p_h`；要所有群体达标需 `n ≥ n_min / min_h p_h`，总成本 `B ≥ (n_min / min_h p_h)·c_cal`。因此当 `p_h → 0` 时，该群体的**人均认证成本 ∝ 1/p_h → ∞**；任何只最小化总成本、不设公平约束或层级迁移的方案，必然在少数群体上违反 C5（覆盖欠账）。**系（市场失灵）**：若按人口占比加权期望效用优化，权重 `p_h → 0` 的群体伤害对目标函数几乎无影响，最优解可合法地牺牲其底线——因此必须用 max-min/CVaR + 通用底线，而不能用期望效用。**

## 6. 本轮最大风险

**一句话**：ECONGAUGE 把「安全/隐私/尊严」也变成了可计算、可优化的契约对象——一旦成本模型与规范模型被写成可审计的图，系统就会**精确地优化一个可测的价值代理**，同时结构性地牺牲那些难以计量、统计稀有、或根本不愿被计量的文化群体；每一张证书都有效，公平却在证书之外流失。

次级风险与缓解：
1. **可计算的歧视（Goodhart on value）** → 通用底线硬约束 + 保护轴非补偿 + 分组伤害报告 + max-min/CVaR，而非期望效用；定理 33 作为常驻告警。
2. **文化本质主义**（把文化当离散标签） → H 明确声明为有限近似；连续谱用局部校准 + 保守回退；禁止从受保护属性推断（定义 399）；模型误设纳入 A-econ 假设。
3. **成本低报/恶意模块** → 运行时计量 + `seal_ref` 成本审计 + 声明-实测不一致即降级（E401）。
4. **隐私/尊严被「汇率化」** → 保护轴只有上限、无价格；汇率必须显式声明并伦理审查，禁止静默学习（定义 386）。
5. **稀有群体认证税导致服务不平等** → 层级迁移 + 显式覆盖率债务 + 公平预算；债务超限即降低自治而非假装达标（定理 33、E399）。
6. **不可比被误当死锁** → SafeDefer 的活性证明 + 预注册保守回退 + 进度损失上界（引理 43、E404）。
7. **校准数据殖民** → 数据来源审计 + 同意与撤回 + 第三方伦理审查；不可审计的数据不得进 SEAL-C（定义 397/399）。
8. **成本归一化被误读为「越便宜越好」** → 生命周期成本含 `ℓ_down`；等安全切片必须同时报告（定义 396）。

> - **EBA/ECP/SafeDefer**：证据-成本前沿与 VoI、成本-文化联合规划、保护轴不可比时的安全延迟；
> - **CPB†**：新增 C4（成本感知计量）/ C5（文化条件适应），并强制所有主张在等成本/等安全切片上比较。
>
> 核心命题：**证据的「汇率」不是常数，而是契约中声明的、文化条件化的对象；系统安全从「证据够不够准」升级为「这份证据值不值得买、由谁承担代价、价值不可比时是否有权替人决定」。**
>
> IP 编号：IP-302~310（共 9 个）+ R73 组件的 † 化。理论姿态延续：**新维度是旧契约的新字段与新校验，严格包含旧系统；安全侧只增不减。**

## 2. 形式化定义（要点版）

**定义 383（总览与十不变式）** R73 五不变式 + 成本显式性 / 保护轴非补偿 / 分组覆盖 / 通用底线不变 / 不可比即延迟。

**定义 384（CBC 成本契约）** 可通约轴 + 保护轴；`c_marg`、`u_marg`（可认证、次模）、`A_adm(h)`、`β_cost`、`ℓ_down`。**保护轴无价格。**

**定义 385（CBA 成本代数）** 可通约轴相加并加下游代价；保护轴取分量最大；预算逐轴检验。**便宜可能更贵**：残余 u 的下游代价必须计入。

**定义 386（证据-成本前沿与 VoI）** 未声明汇率 → 只允许 Pareto；汇率必须显式声明并伦理审查，禁止静默学习「隐私的价格」。

**定义 387（文化上下文）** `h` 来自声明/同意/聚合线索；禁止从受保护属性推断用于优化；风险聚合取最坏/CVaR。

**定义 388（HIM）** 文化条件化的先验、代价矩阵、安全集、可采动作、词典/距离/隐私策略；一等模块。

**定义 389（规范格与通用底线）** `N_univ = ∧_h N_h`；适应只在边缘区；跨群体外部性审计；不可比禁止标量合并。

**定义 390（GCA 分组校准）** Mondrian conformal；样本不足用层级迁移 + 覆盖率债务；债务超限回退最坏群体保守界并降自治。

**定义 391（CTX 迁移）** 换 HIM + 重校准 + 底线/外部性/成本闭合验证；认证成本 `O(|HIM|+n_h)`。

**定义 392（ECP 联合规划）** 先硬约束（规范/保护轴/物理安全），后优化进度-风险-成本；不可比进 SafeDefer。

**定义 393（SafeDefer）** 安全保持 + 限时裁决 + 预注册回退；活性 = 有限退出路径；进度损失有界。

**定义 394（成本感知退化链）** 服务层级单调降级（分辨率/采样率/更新率/可选模态），最后才是 stub；修正 R73 的 stub-only 语义。

**定义 395（J_ECON）** 模块证书 ⊗ 成本闭合 ⊗ 规范底线 ⊗ 分组覆盖 ⊗ 迁移证书。

**定义 396（成本归一化基线）** 等成本 / 等安全 / 等人类负担三切片 + `C-NEER`；只在更多资源上取胜 = 不可识别。

**定义 397（MBench-C）** MB-C1 成本前沿 / C2 预算交互 / C3 跨文化校准迁移 / C4 规范冲突延迟 / C5 稀有群体认证税；预注册 + 密封集。

**定义 398（结构上限）** 可通约轴 ≤5、保护轴 ≤3、`|H|≤8`、层级 ≤4、规范节点 ≤64、延迟候选 ≤8。

**定义 399（SEAL-NORM 伦理审计）** 禁止受保护属性优化；数据来源透明；分组伤害报告；人类否决与撤回；第三方审查；降低底线即无效证书。

**定义 400（C4/C5 主张）** C4 成本感知计量（等成本 Pareto + 可识别性）；C5 文化条件适应（分组覆盖 + 底线保持 + 迁移局部化）。

# IP-302/303：成本契约与成本代数
@dataclass(frozen=True)
class CostContract:
    c_comm: Tuple[str, ...]                 # energy/time/compute/money/attention
    c_prot: Tuple[str, ...]                 # privacy/dignity/norm
    c_marg: Callable[[Action, EvidenceState], VecCost]
    u_marg: Callable[[Action, EvidenceState], float]   # 可认证的 u 下降
    adm: Callable[[CultureCtx], Set[Action]]
    beta: VecBudget
    l_down: Callable[[float], VecCost]
    seal_ref: str

def compose_cost(c1, c2, u_out):
    comm = c1.comm + c2.comm + L_DOWN_WEIGHT * to_cost(u_out)
    prot = max_vec(c1.prot, c2.prot)        # 保护轴禁止抵消
    return VecCost(comm, prot)

def budget_ok(c, beta):
    return all(c.comm[i] <= beta.comm[i] for i in range(len(c.comm))) \
       and all(c.prot[i] <= beta.prot[i] for i in range(len(c.prot)))

# IP-304/305：HIM 与规范格
@dataclass(frozen=True)
class HIM:
    h: CultureCtx
    intent_prior: Callable
    loss_matrix: Callable[[str], np.ndarray]
    norms: NormSet
    adm_sensing: FrozenSet[str]
    lexicon: Lexicon
    proxemics: Proxemics

FLOOR = meet_all(norm_sets)                   # N_univ，部署期固定

def adapt(ctx, him_new):
    assert floor_preserved(him_new.norms, FLOOR)
    assert no_negative_externality(him_new, ctx)
    ec_new = replace_human_contract(ctx.ec, him_new)
    return certify_transfer(ec_new, groups=[him_new.h])   # J_CTX

# IP-306：分组 conformal + 覆盖率债务
class GroupCalibrator:
    def quantile(self, h, score):
        if len(self.D[h]) >= n_min(self.alpha, self.delta):
            return mondrian_quantile(self.D[h], self.alpha), 0.0
        parent = self.hierarchy.parent(h)
        q, debt = self.transfer(parent, h)
        if debt > self.debt_max:
            return worst_group_quantile(self.D), self.alpha
        return q, debt

# IP-308/309：成本-文化联合规划 + SafeDefer
def econ_culture_plan(b_t, h_post, mods, budget):
    cands = []
    for h in credible_set(h_post):                        # 最坏/CVaR
        for a in intersect(mods.adm, HIM[h].adm_sensing):
            c = sum(compose_cost(m.c_marg(a), 0, m.u_after(a)) for m in mods)
            if not budget_ok(c, budget) or not norm_ok(a, h): continue
            val = progress(a) - HIM[h].loss_lambda * expected_loss(a, h)
            cands.append(Cand(a, h, val, c, u_next(a)))
    pareto = protected_pareto(cands)
    if incomparable(pareto):
        return SafeDefer(pareto, deadline=T_DEFER, fallback=safe_hold())
    return best_commensurable(pareto)

# IP-310：ECONGAUGE 主闭环
def ECONGAUGE_round(M, obs, audio, tac_frame, depth_img, locale):
    h, b_h = M.cul.update(locale, M.user_settings, obs, audio)   # 声明/同意优先
    d_ev = M.dpe.update(depth_img, rgb, M.cam_state, M.motion, M.peers)

    psi_hat, ece = M.aura.update(audio)
    M.y_intent_buf.append(extract_intent_obs(obs, audio, M.last_action))

    if M.clock.due_metric():
        b_t = M.bse.step_full(..., d_ev=d_ev, t_ev=t_ev)
        z_dist, ece_z, iota_z = M.irl.update(M.y_intent_buf, psi_hat, b_t)
        a = econ_culture_plan(b_t, b_h, M.mods, M.budget)         # IP-308/309
        if isinstance(a, SafeDefer):
            M.defer.enter(a)
        else:
            M.last_action = a
        M.costmeter.commit(M.mods, a)                             # 运行时成本计量
        M.mreg.audit_cost_norm(h)
        M.snapshot.write(b_t, z_dist, d_ev, t_ev, a, h)

    snap = M.snapshot.read_latest()
    lam = embodied_risk_scale(snap.U_ale, snap.U_epi, snap.H_z,

    A = M.ach.propose_ctrl(..., econ_bias=snap.a); k = M.c_ras_wm.certified_prefix(A, lam)
    M.ctrl_out.publish(k, lam)

## 4. 推导要点

**引理 38（不免费证据下界）** 组覆盖 1−α 需每组 `n_min = Ω(α^{-1} log δ^{-1})` 校准样本，认证成本有正下界；零成本达到可认证 u 水平不存在。

**引理 39（成本归一化可识别性）** 预算更大的方法在任何单调指标上的优势不识别机制；机制主张必须在等成本切片成立。

**引理 40（边际覆盖 ≠ 分组覆盖）** 全概率加权和可被小组欠覆盖补偿；必须 Mondrian。

**引理 41（保护轴非补偿 ⇒ 底线保持）** 边缘区适应 + 分量上限 ⇒ `N_univ` 逐项不变；用可通约收益抵消保护轴越界的路径不可行。

**引理 42（层级降级单调终止）** 良基偏序 + u 单调不减 / cost 单调不增 ⇒ ≤k 步到最低层或 stub，安全不变式保持。

**引理 43（SafeDefer 安全性）** 保守回退可达 ⇒ 延迟期间不入 ObjRisk；活性要求有限退出路径；进度损失 ≤ΔProg_defer。

**定理 30（ECONGAUGE 严格包含）** 单文化、可通约成本、无保护轴、无层级、无延迟、`ℓ_down≡0` ⇒ 逐指令退化为 MODGAUGE → R72/R71/R68。

**定理 31（J_ECON 有效 ⇒ 安全 + 分组覆盖 + 底线）** 在 A-econ 假设下，物理风险 ≤ε_econ，每组覆盖达标或债务显式，`N_univ` 不变，成本闭合。证明重量落在**规范模型表达力**与**成本计量可信性**上。

**定理 32（文化迁移保持通用安全 + 认证局部化）** 只换 HIM/校准层且 J_CTX 有效 ⇒ 底线与物理不变式逐指令保持；`CertCost = O(|HIM|+n_h)`。

**定理 33（成本-公平张力 / 稀有文化认证税）** 总预算 B、统一覆盖 1−α、总体 i.i.d. 采样下，群体 h 期望样本 `n p_h`；全群体达标需 `n ≥ n_min/min_h p_h`，人均成本 ∝1/p_h →∞。只最小化总成本必然违反少数群体覆盖；按人口加权期望效用会合法牺牲 `p_h→0` 群体的底线。**故必须 max-min/CVaR + 通用底线 + 层级迁移。**

| E406 校准数据来源审计 | 数据殖民/代表性 | 来源透明，无未授权群体数据 |
| E407 严格包含回归 | R73/R72/R71/R68 全退化组合 | 单文化极限下逐指令差 = 0 |
| E408 主张包完整性 | C1–C5 各有 MB+AB+预注册 | 五主张闭环，无孤悬组件 |

## 7. 本轮最大风险

**一句话**：ECONGAUGE 把「安全/隐私/尊严」也变成可计算、可优化的契约对象——系统会**精确地优化一个可测的价值代理**，同时结构性地牺牲那些难以计量、统计稀有、或不愿被计量的文化群体；每一张证书都有效，公平却在证书之外流失。

次级风险与缓解：
1. **可计算的歧视** → 通用底线硬约束 + 保护轴非补偿 + 分组伤害报告 + max-min/CVaR；定理 33 常驻告警。
2. **文化本质主义** → H 声明为有限近似；连续谱局部校准 + 保守回退；禁止受保护属性推断；模型误设入 A-econ。
3. **成本低报** → 运行时计量 + 成本审计 + 声明-实测不一致即降级（E401）。
4. **隐私/尊严汇率化** → 保护轴只有上限无价格；汇率显式声明并伦理审查；禁止静默学习（定义 386）。
5. **稀有群体认证税** → 层级迁移 + 覆盖率债务 + 公平预算；债务超限降低自治而非假装达标（定理 33/E399）。
6. **不可比误当死锁** → SafeDefer 活性证明 + 预注册回退 + 进度损失上界（引理 43/E404）。
7. **校准数据殖民** → 来源审计 + 同意/撤回 + 第三方伦理审查；不可审计数据不进 SEAL-C。
8. **成本归一化被误读为越便宜越好** → 生命周期成本含 `ℓ_down`；等安全切片同时报告（定义 396）。
