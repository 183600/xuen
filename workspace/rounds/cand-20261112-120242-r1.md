# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 1 轮；本轮灵感：「多任务学习」×「运动控制」）

> 第 60 轮 SGEC 把「场景」从物理障碍升级为可预测的阻抗先验 π_scene(K|z)，用 SSM×CIEC×EPIR×SERC 实现了「场景先验提前收敛 K_safe、意图即时锁定约束、证据链防消息丢失」。但整条链路仍隐含一个**单任务假设**：K_safe、B_exec、EV-exec、Cert_eeis 都只描述一个主动任务。真实机器人是**多技能并发**的——边走边抓、边平衡边操作、双臂协同装配。由此暴露三个结构性局限：
> 1. **单任务闭环无法表达资源共享与任务干扰**：两个任务同时占用同一组关节的力矩预算、同一质心的稳定裕度、同一工作空间时，各自「单独安全」的证书会叠加出一个「联合危险」的执行配置；单任务证据也看不见这种跨任务侵蚀。
> 2. **多任务学习的共享表征把安全约束耦合在一起**：MTL 靠共享层提升样本效率，但梯度跨任务传播——为任务 A 更新共享层，可能悄悄拉低任务 B 的安全裕度（负迁移/灾难性干扰），而该退化在任务 A 的证据里完全不可见。
> 3. **技能组合缺乏可组合的安全证书**：即便每个技能都有 Cert_eeis，技能组合后是否仍安全没有**组合算子**；朴素地对各自 K_safe 求交，既可能因过度保守而交集为空，又可能在资源耦合处给出「每个都安全、合起来危险」的证书幻觉。

## 0. 直觉与动机

**灵感 1（多任务学习 → 任务不变/任务特定解耦 MTSR）**
直觉：多任务学习之所以有效，是因为运动技能共享同一套「物理语法」——刚体动力学、接触模型、运动学。但**安全不能共享**：关节限位、自碰撞、力矩上限、支撑多边形稳定是**跨任务不变核 K_inv**；力上限、精度、阻抗偏好、速度是**任务特定约束 C_i**。关键洞见：把策略分解为 z = Φ(o)（任务不变表征）⊕ z_i（任务特定潜码），并强制共享层的更新只能沿**安全中性子空间**进行——「共享提效，安全解耦」。

**灵感 2（运动控制 → 阻抗技能空间的安全组合 SCC）**
直觉：运动控制的每个技能本质上是一个**带证书的阻抗契约** s_i = (轨迹, K_i, C_i, ω_i, Cert_i)。组合动作（如「端着水杯走路」）在阻抗空间里不是简单相加：串联接触用 K_eq=(K_i⁻¹+K_j⁻¹)⁻¹，并联耦合用 K_eq=K_i+K_j，权重叠加用 K_eq=W_iK_i+W_jK_j。关键洞见：组合必须在**安全集交集**内进行，且组合证书要显式扣除**资源耦合代价** ρ(R_ij)——同一关节的力矩、同一质心的稳定裕度不能重复计算，否则就是重复记账式的乐观。

**灵感 3（负迁移 → 任务干扰检测 TID 与安全梯度手术 SGS）**
直觉：MTL 的负迁移在运动控制里就是「练了抓取，反而把放置的力控练坏了」。检测需要两个信号：**梯度冲突** cos(g_i,g_j)<0（更新方向打架）与**安全干扰** Δm_{j|i}<0（更新 i 让 j 的安全裕度下降）。关键洞见：冲突本身不必然是坏事，**被冲突侵蚀的安全裕度才是坏事**——所以梯度手术必须加一道「安全可行门」，任何使某个 m_k 跌破阈值的投影一律拒绝。

**灵感 4（证据层 → 多任务证据台账 MTEL）**
直觉：多任务并发时每个任务产生自己的 EV-exec，但它们描述的是**同一台物理机器人**。任务 A 的接触力证据与任务 B 的位置证据必须在同一物理状态上**交叉对账**：由两路证据反推的共享状态若相差超过 ε_cons，说明至少一路不可信，此时必须降级为隔离执行，而不是继续按「组合证书」硬跑。

**灵感 5（预算 → 任务级预算 PCE+++++）**
直觉：第 60 轮的认知预算只按「场景/意图/ROS/执行」切分，没有按**任务**切分。多任务下必须新增 B_task（任务头算力）、B_shared（共享层梯度/带宽）、B_comp（组合证书验证开销）、B_evid（交叉对账开销）。安全关键任务获得预算优先权；预算不足时按**干扰图独立集**退化为串行执行，而不是超预算并发。

**灵感 6（合流 → 多任务运动闭环 MTMCL）**
直觉：把上面五件事串成闭环：任务分解→共享表征→干扰检测→安全梯度手术→组合证书→并发执行→多任务证据→交叉对账→安全可行方向回填共享表征。核心原则只有一句：**「组合前先证、冲突时先保安全、证据不一致就降级」**。与第 60 轮 SERC 的关系是正交扩展：SERC 管「一个任务在场景里怎么安全落地」，MTMCL 管「多个任务怎么一起安全落地」。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（多任务技能表示 MTSR）** MTSR = (Φ, {E_i}, {π_i}, K_inv, {C_i}, D_safe)。其中：
- **共享表征**：Φ: O × H → Z_s，编码任务不变的动力学/接触语法；
- **任务潜码**：z_i = E_i(task_i) ∈ Z_i，编码任务特定的目标/阻抗偏好；
- **任务头**：π_i: Z_s × Z_i → A，输出动作或阻抗参数 K_i；
- **任务不变安全核**：K_inv = {关节限位, 自碰撞, 力矩上限, ZMP/支撑多边形稳定}，对任意任务与任意组合都必须成立；
- **任务特定约束**：C_i = (F_max,i, v_max,i, K_i 可行域, ε_traj,i)；
- **解耦公理**：(D1) 任务头更新不改变 K_inv 的裕度；(D2) 共享层更新在安全敏感方向上的分量被投影消除，即 Δθ_Φ = P_neutral(∇θ L)，其中 P_neutral = I − ∇K_inv(∇K_inv)⁺。
安全解耦的意义：共享层只携带「物理语法」，安全裕度只由 K_inv 与各自 C_i 承载，从而让「效率」与「安全」在不同的参数子空间里演化。

**定义 162（任务干扰度量 TID）** 给定任务 i,j 的损失梯度 g_i = ∇θ L_i，以及安全裕度函数 m_k(θ)（k 遍历所有活跃任务与不变核）：
- **梯度冲突**：c_ij = cos(g_i, g_j)；
- **安全干扰**：Δm_{k|i} = m_k(θ − η g_i) − m_k(θ)，即在任务 i 的更新步下任务 k 的裕度变化；
- **干扰指数**：I_ij = w_g·[−c_ij]₊ + w_m·max_k[−Δm_{k|i}]₊；
- **负迁移判定**：NTT(i,j) = 1 ⇔ I_ij > τ_int ∨ ∃k: m_k(θ − η g_i) < m_k^min；
- **干扰图**：G_int = (V_tasks, E_int)，边权为 I_ij，供调度器（定义 168）求安全并集。
注意 I_ij 是**有向的**：任务 i 的更新对 j 的伤害，与 j 对 i 的伤害不一定对称，故实际维护两条有向边。

**定义 163（安全梯度手术 SGS）** 对冲突边 (i,j) 做正交投影，并加安全可行门：
```
g_i⊥ = g_i − (g_i·g_j / (||g_j||² + ε))·g_j      if g_i·g_j < 0
accept(g_i⊥) ⇔ ∀k: m_k(θ − η g_i⊥) ≥ max(m_k^min, m_k(θ) − ε_deg)
```
若投影被安全门拒绝，则**冻结共享层**，只更新任务头（隔离共享更新）；若任务头更新仍被拒绝，则标记该任务对必须**串行执行**（交给定义 168）。核心保证：任何被接受的更新都不会让任一安全裕度下降超过 ε_deg，K_inv 恒成立。

**定义 164（安全组合证书 SCC）** 技能 s_i = (pre_i, post_i, K_i, C_i, ω_i, Cert_i)，组合算子 ⊗：
- **前置相容**：SAT(pre_i ∧ pre_j)，后置兼容 post_i ⊕ post_j 非空；
- **资源耦合矩阵**：R_ij ∈ [0,1]^d，分量对应共享关节力矩、质心稳定、工作空间、总线带宽、热预算的占用重叠度；
- **耦合代价**：ρ(R_ij) = Σ_l λ_l·R_ij[l]；
- **组合裕度**：m_{i⊗j} = min(m_i, m_j) − ρ(R_ij)；
- **组合阻抗**：K_{i⊗j} = compose(K_i, K_j) ∈ K_i ∩ K_j ∩ K_inv（按接触拓扑选串联/并联/加权律）；
- **证书有效**：Cert(s_i⊗s_j) ⇔ m_{i⊗j} ≥ 0 ∧ K_{i⊗j} ≠ ∅ ∧ 前置相容；
- **单调性**：当 R_ij = 0 时 m_{i⊗j} = min(m_i,m_j)，即组合**绝不能凭空增加安全**——证书只允许变保守、不允许变乐观。这一条是防止「证书幻觉」的关键公理。

**定义 165（多任务证据台账 MTEL）** 证据集合 EV_task = {EV_i}，交叉对账包含三件事：
- **状态一致性**：由 EV_i、EV_j 反推的共享物理状态满足 ||proj(x_i) − proj(x_j)||_Σ ≤ ε_cons；
- **因果先序**：若任务 B 消费任务 A 的输出，则强制 EV_A ≺ EV_B，依赖关系构成 DAG G_evid，禁止环路；
- **冲突处理**：若一致性被破坏且无法用已标定噪声解释，标记「任务证据冲突」，组合证书降级为**孤立模式**（各任务单独执行、互不共享状态）。
MTEL 的意义是把第 60 轮的「单链证据完整性」提升为「多链证据一致性」：不仅每条链不能断，链与链之间还不能互相矛盾。

**定义 166（任务级预算 PCE+++++）** B_mt = (B_shared, B_task, B_comp, B_evid, B_exec)：
- B_shared：共享层梯度/带宽预算；B_task：各任务头算力预算；
- B_comp：组合证书验证次数；B_evid：交叉对账次数；B_exec：原有执行预算；
- **VOI 扩展**：voi_mt(π) = VOI_meta(π) − cost_shared − cost_task − cost_comp − cost_evid − cost_exec；
- **耗尽策略**：B_comp 耗尽 ⇒ 禁用并发组合、退化为串行；B_evid 耗尽 ⇒ 只信任任务不变核 K_inv；B_shared 耗尽 ⇒ 冻结共享层、仅训任务头；任一操作都不得绕过 K_inv。

**定义 167（多任务运动闭环 MTMCL）** 算子 MTMCL(M, T)：
```
① 任务接收 T = {t_i}；TAS.select(G_int, B_mt) → 允许并发的集合 S、阻塞集合 B
② for t_i ∈ S: z_i ← E_i(t_i); a_i ← π_i(Φ(o), z_i)        # 共享表征 + 任务头
③ TID: 计算 g_i 与 m_k，构建有向干扰图 G_int
④ SGS: 冲突对正交投影 + 安全可行门 → 接受 / 冻结共享 / 标记隔离
⑤ SCC: 对候选组合求 K_{⊗S}、m_{⊗S}，仅证书有效者允许并发
⑥ Dispatch: 下发组合阻抗 K_{⊗S} 与各任务级契约 Cert_i
⑦ Execute: 各任务遥测 → EV_i
⑧ MTEL: 交叉对账 + 因果校验；冲突则降级为孤立模式
⑨ 反馈: 仅沿安全中性方向回填 Φ；回填场景/意图先验（接第 60 轮 SERC）
⑩ Return: (K_{⊗S}, {EV_i}, Cert_comp, G_int, 降级状态)
```

**定义 168（任务感知调度 TAS）** 在干扰图 G_int 上求**安全加权独立集**：
```
max_{S⊆V}  Σ_{i∈S} ω_i·u_i
s.t.  对任意 i,j∈S:  (i,j)∉E_int 且 Cert(s_i⊗s_j) 有效
      Σ_{i∈S} cost_i ≤ B_mt
      安全关键任务优先级单调高于性能任务
```
贪心实现：按 ω_i·u_i 降序尝试加入 S，加入前用 SCC 验证与**已选全部任务**的组合证书与预算；失败则放入阻塞队列 B 下一轮串行执行。TAS 保证：并发集合要么「被证明安全」，要么「被推迟而不是被冒险」。

### IP-161 MTSR（多任务技能表示）

```python
class MultiTaskSkillRepresentation:
    def __init__(self, obs_dim, latent_dim, tasks):
        self.Phi = SharedEncoder(obs_dim, latent_dim)          # 任务不变
        self.embed = {t: TaskEmbedding(latent_dim) for t in tasks}
        self.heads = {t: TaskHead(latent_dim, act_dim) for t in tasks}
        self.safety_kernel = InvariantSafetyKernel()            # K_inv

    def forward(self, obs, task):
        z_shared = self.Phi(obs)
        z_task = self.embed[task]()
        return self.heads[task](z_shared, z_task), z_shared

    def safe_update(self, task, grad_shared, grad_head, theta):
        margins = self.safety_kernel.margins(theta)
        if not self.safety_kernel.preserves(margins, grad_head):
            grad_head = self.safety_kernel.project(grad_head)
        grad_shared = self.safety_kernel.neutral_projection(grad_shared)
        self.Phi.apply(grad_shared)                             # 安全中性子空间
        self.heads[task].apply(grad_head)
```

### IP-162 TID（任务干扰检测）

```python
class TaskInterferenceDetector:
    def __init__(self, w_g=1.0, w_m=2.0, tau_int=0.3):
        self.w_g, self.w_m, self.tau_int = w_g, w_m, tau_int

    def detect(self, grads, margin_fns, theta, eta=1e-2):
        edges = {}
        for i, gi in grads.items():
            for j, gj in grads.items():
                if i == j:
                    continue
                c = cosine(gi, gj)
                dm = min(m(theta - eta * gi) - m(theta)
                         for m in margin_fns.values())
                I = self.w_g * max(0.0, -c) + self.w_m * max(0.0, -dm)
                if I > self.tau_int:
                    edges[(i, j)] = I                       # 有向边
        return edges
```

### IP-163 SGS（安全梯度手术）

```python
class SafetyGradientSurgery:
    def __init__(self, eps_deg=1e-3):
        self.eps_deg = eps_deg

    def operate(self, gi, gj, margin_fns, theta, eta):
        if dot(gi, gj) >= 0:
            return gi, 'no_conflict'
        g_perp = gi - (dot(gi, gj) / (norm(gj) ** 2 + 1e-12)) * gj
        if self.safety_gate(g_perp, margin_fns, theta, eta):
            return g_perp, 'projected'
        g_head_only = self.freeze_shared(g_perp)            # 冻结共享层
        if self.safety_gate(g_head_only, margin_fns, theta, eta):
            return g_head_only, 'head_only'
        return None, 'isolate'                              # 交调度器串行

    def safety_gate(self, g, margin_fns, theta, eta):
        for m in margin_fns.values():
            if m(theta - eta * g) < max(m(theta) - self.eps_deg, m.min_safe):
                return False
        return True
```

### IP-164 SCC（安全组合证书）

```python
class SafeCompositionCertificate:
    def __init__(self, coupling, lambdas):
        self.coupling, self.lambdas = coupling, lambdas

    def compose(self, si, sj):
        if not sat(si.pre & sj.pre):
            return None, 'precondition_conflict'
        R = self.coupling(si, sj)                            # 资源占用重叠
        rho = sum(self.lambdas[l] * R[l] for l in R)
        m = min(si.margin, sj.margin) - rho                  # 只能变保守
        K = compose_impedance(si.K, sj.K)                    # 串联/并联/加权
        if m < 0 or K not in intersect(si.K_set, sj.K_set, K_inv):
            return None, 'not_certified'
        return Skill(si.tasks | sj.tasks, K, m), 'certified'

    def validate(self, skill_set):
        acc = skill_set[0]
        for s in skill_set[1:]:
            acc, mode = self.compose(acc, s)
            if acc is None:
                return None, mode
        return acc, 'certified'
```

### IP-167 MTMCL（多任务运动闭环）

```python
def multi_task_motion_control_loop(M, task_set):
    S, blocked = M.tas.schedule(task_set, M.g_int, M.budget_mt, M.scc)

    grads, margins = {}, {}
    for t in S:
        a_t, _ = M.mtsr.forward(M.obs, t.id)
        grads[t.id] = M.loss_grad(t, a_t)
        margins[t.id] = M.mtsr.safety_kernel.margin_fns(M.theta)

    edges = M.tid.detect(grads, margins, M.theta)
    for (i, j) in list(edges):
        g, mode = M.sgs.operate(grads[i], grads[j], margins, M.theta, M.eta)
        if mode == 'isolate':
            S.discard(i); S.discard(j)
            blocked.update({i, j})
        else:
            grads[i] = g

    combined, mode = M.scc.validate([M.skills[t] for t in S])
    if combined is None:
        return serial_fallback(S, blocked)

    dispatch_impedance(combined.K, M.cert)
    ev = {t: build_exec_evidence(M, t) for t in S}
    rec = M.mtel.reconcile(ev, M.obs)
    if not rec.consistent:
        return degrade_to_isolated(S, rec)

    M.mtsr.safe_update_many(grads, margins, M.theta)         # 仅安全中性方向
    return M, combined, ev, rec
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MTSR | O(N_task·d) 前向 / O(d²) 安全中性投影 | O(d² + N_task·d) | K_inv 违约率 = 0；共享层更新不降安全裕度 |
| TID | O(N_task²·c_margin) | O(N_task²) | 负迁移检测 AUC ≥ 0.9 |
| SGS | O(N_task²·k) | O(d) | 接受更新后 m_k 下降 ≤ ε_deg |
| SCC | O(N_task·d) 组合验证 | O(N_task²) | 证书 sound：Cert⇒真实组合安全 |
| MTEL | O(N_task·m_evid) | O(N_task) | 证据不一致检测率 ≥ 99% |
| TAS | 贪心 O(N_task²) | O(N_task²) | 并发集合必被证书覆盖或推迟 |

**正确性定理（MTSC）**：假设 A66–A70 成立。
**(A66) MTSR**：存在任务不变/任务特定正交分解，安全中性投影误差 ≤ δ_dec，K_inv 与 C_i 可微且有裕度定义。**(A67) TID**：干扰指数估计误差 ≤ δ_int，权重 w_g、w_m 标定。**(A68) SGS**：安全可行门可在线判定，被接受更新满足 m_k(θ′) ≥ m_k(θ) − ε_deg。**(A69) SCC**：耦合矩阵 R_ij 是真实资源共享的上界，故 m_{i⊗j} 是真实组合裕度的**下界**（sound but possibly conservative）。**(A70) MTEL/TAS**：交叉对账覆盖所有共享物理状态，调度器在预算内完成验证。

则：
1. **安全不退化**：任意 SGS 接受步都不会让 K_inv 或任何活跃 C_i 的裕度下降超过 ε_deg；
2. **组合 soundness**：Cert(s_i⊗s_j) ⇒ 联合执行的各安全裕度 ≥ 0（因组合裕度是真实裕度下界，永不乐观）；
3. **证据一致性**：MTEL 报告一致 ⇒ 组合状态可被所有任务证据共同解释；
4. **预算安全性**：任一 B_mt 分量耗尽 ⇒ 触发串行/隔离/冻结，绝不超预算并发；
5. **效率不劣化**：无资源耦合（R=0）时组合退化为 min 裕度，MTL 共享表征的样本效率提升不被安全门吞掉。

**推论（无负迁移的充分条件）**：若 G_int 中所有边均不进入 S（即 S 是干扰图的独立集）且所有组合证书有效，则多任务并发相对单任务执行，不产生任何由负迁移导致的安全退化。

### IP-161 MTSR（多任务技能表示）

```python
class MultiTaskSkillRepresentation:
    def __init__(self, obs_dim, latent_dim, tasks):
        self.Phi = SharedEncoder(obs_dim, latent_dim)          # 任务不变
        self.embed = {t: TaskEmbedding(latent_dim) for t in tasks}
        self.heads = {t: TaskHead(latent_dim, act_dim) for t in tasks}
        self.safety_kernel = InvariantSafetyKernel()            # K_inv

    def forward(self, obs, task):
        z_shared = self.Phi(obs)
        z_task = self.embed[task]()
        return self.heads[task](z_shared, z_task), z_shared

    def safe_update(self, task, grad_shared, grad_head, theta):
        margins = self.safety_kernel.margins(theta)
        if not self.safety_kernel.preserves(margins, grad_head):
            grad_head = self.safety_kernel.project(grad_head)
        grad_shared = self.safety_kernel.neutral_projection(grad_shared)
        self.Phi.apply(grad_shared)                             # 安全中性子空间
        self.heads[task].apply(grad_head)
```

### IP-162 TID（任务干扰检测）

```python
class TaskInterferenceDetector:
    def __init__(self, w_g=1.0, w_m=2.0, tau_int=0.3):
        self.w_g, self.w_m, self.tau_int = w_g, w_m, tau_int

    def detect(self, grads, margin_fns, theta, eta=1e-2):
        edges = {}
        for i, gi in grads.items():
            for j, gj in grads.items():
                if i == j:
                    continue
                c = cosine(gi, gj)
                dm = min(m(theta - eta * gi) - m(theta)
                         for m in margin_fns.values())
                I = self.w_g * max(0.0, -c) + self.w_m * max(0.0, -dm)
                if I > self.tau_int:
                    edges[(i, j)] = I                       # 有向边
        return edges
```

### IP-163 SGS（安全梯度手术）

```python
class SafetyGradientSurgery:
    def __init__(self, eps_deg=1e-3):
        self.eps_deg = eps_deg

    def operate(self, gi, gj, margin_fns, theta, eta):
        if dot(gi, gj) >= 0:
            return gi, 'no_conflict'
        g_perp = gi - (dot(gi, gj) / (norm(gj) ** 2 + 1e-12)) * gj
        if self.safety_gate(g_perp, margin_fns, theta, eta):
            return g_perp, 'projected'
        g_head_only = self.freeze_shared(g_perp)            # 冻结共享层
        if self.safety_gate(g_head_only, margin_fns, theta, eta):
            return g_head_only, 'head_only'
        return None, 'isolate'                              # 交调度器串行

    def safety_gate(self, g, margin_fns, theta, eta):
        for m in margin_fns.values():
            if m(theta - eta * g) < max(m(theta) - self.eps_deg, m.min_safe):
                return False
        return True
```

### IP-164 SCC（安全组合证书）

```python
class SafeCompositionCertificate:
    def __init__(self, coupling, lambdas):
        self.coupling, self.lambdas = coupling, lambdas

    def compose(self, si, sj):
        if not sat(si.pre & sj.pre):
            return None, 'precondition_conflict'
        R = self.coupling(si, sj)                            # 资源占用重叠
        rho = sum(self.lambdas[l] * R[l] for l in R)
        m = min(si.margin, sj.margin) - rho                  # 只能变保守
        K = compose_impedance(si.K, sj.K)                    # 串联/并联/加权
        if m < 0 or K not in intersect(si.K_set, sj.K_set, K_inv):
            return None, 'not_certified'
        return Skill(si.tasks | sj.tasks, K, m), 'certified'

    def validate(self, skill_set):
        acc = skill_set[0]
        for s in skill_set[1:]:
            acc, mode = self.compose(acc, s)
            if acc is None:
                return None, mode
        return acc, 'certified'
```

```python
def multi_task_motion_control_loop(M, task_set):
    S, blocked = M.tas.schedule(task_set, M.g_int, M.budget_mt, M.scc)

    grads, margins = {}, {}
    for t in S:
        a_t, _ = M.mtsr.forward(M.obs, t.id)
        grads[t.id] = M.loss_grad(t, a_t)
        margins[t.id] = M.mtsr.safety_kernel.margin_fns(M.theta)

    edges = M.tid.detect(grads, margins, M.theta)
    for (i, j) in list(edges):
        g, mode = M.sgs.operate(grads[i], grads[j], margins, M.theta, M.eta)
        if mode == 'isolate':
            S.discard(i); S.discard(j)
            blocked.update({i, j})
        else:
            grads[i] = g

    combined, mode = M.scc.validate([M.skills[t] for t in S])
    if combined is None:
        return serial_fallback(S, blocked)

    dispatch_impedance(combined.K, M.cert)
    ev = {t: build_exec_evidence(M, t) for t in S}
    rec = M.mtel.reconcile(ev, M.obs)
    if not rec.consistent:
        return degrade_to_isolated(S, rec)

    M.mtsr.safe_update_many(grads, margins, M.theta)         # 仅安全中性方向
    return M, combined, ev, rec
```

### IP-168 TAS（任务感知调度）

```python
class TaskAwareScheduler:
    def schedule(self, tasks, g_int, budget, scc):
        order = sorted(tasks, key=lambda t: -(t.priority * t.utility))
        selected, blocked = [], []
        for t in order:
            if any((t.id, s.id) in g_int for s in selected):
                blocked.append(t.id)
                continue
            candidate = [s.skill for s in selected] + [t.skill]
            combo, mode = scc.validate(candidate)
            if combo is not None and budget.fits(combo):
                selected.append(t)
            else:
                blocked.append(t.id)
        return {t.id for t in selected}, set(blocked)   # blocked 下一轮串行
```
