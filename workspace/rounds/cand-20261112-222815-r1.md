# 第 62 轮（承接第 61 轮「具身语义进化闭环」ESEC IP-173~182；新灵感循环第 1 轮；本轮灵感：「失败恢复」×「数据采集」）

> 第 61 轮构建了 ESEC：USR 把场景/意图/阻抗/证据映射到共享语义空间，MEL 提供多模态零样本物理推断，DMS 实现执行接地的多轮对话，SRT-Dual 用语义流-实时流解耦大模型时序，PCE+++++ 做六维预算兜底，J_sem_exec 给出语义-执行联合证书。但**四个更深的局限**仍然存在：
> 1. **失败只是一个「降级触发器」，不是一次「诊断」**：ESEC 在锚点过期、投影误差超标或 EV-exec 异常时只有保守扩展与冻结两种反应。系统知道自己「不确定」，却不知道**错在场景、物理先验、意图、对话、时序还是硬件**；没有结构化的失败表征，就没有针对性的恢复。
> 2. **恢复只有一条固定后路，不可组合、不可验证、不会失败**：保守扩展对「滑移」「抓空」「传感器污染」「意图突变」一视同仁；恢复动作本身没有前置/后置条件，无法证明「这一步恢复一定把我带回安全核」；更致命的是，**如果恢复失败，系统没有二级恢复**。
> 3. **数据采集完全被动**：证据缓冲只记录、不选择。成功样本海量而失败样本稀少，导致 MEL 对失败分布的估计被系统性压低；真正需要数据的时刻（失败刚发生、认知不确定性最高）恰恰是系统最危险、最不敢「做实验」的时刻。
> 4. **恢复与采集目标天然冲突，学习与恢复时间尺度断裂**：恢复要「立刻降低风险」，采集要「暂时进入信息丰富但风险更高的状态」；二者若各自为政，就会在错误时刻采集、或在需要数据时错过窗口。与此同时，反思与训练是小时级，恢复是毫秒级，新学到的恢复策略无法及时变成实时反射。

## 0. 直觉与动机

**灵感 1（失败恢复 → 失败流形与恢复距离 FRM）**
直觉：在经典控制里，故障不是布尔值，而是状态相对安全集的一次「越界」。一个杯子滑落 1 mm 与机械臂撞上桌面，在信号上都表现为「力/位置异常」，但前者可在一毫秒内通过降低 K_p 挽回，后者已经不可逆。关键洞见：**把失败显式表示为 USR 空间中的「失败流形」上的点，并把恢复定义为「状态沿最短路径回到安全核」**——失败不再是标签，而是带有方向、距离与可恢复性的几何对象。这样「严重程度」就从人工规则变成可计算的恢复距离 d_rec。

**灵感 2（失败恢复 → 可验证恢复技能库 RRL）**
直觉：人类技师处理故障不是「执行一条兜底规则」，而是「选择一项有明确适用条件的技能」：先泄压、再回撤、再重新夹取；如果不行，换一种抓法。关键洞见：**恢复应当被建模为带前置/后置条件、风险上界和证书的技能 σ，而不是一个 if-else 后路**。技能可组合、可回滚、可验证；系统在恢复前先用「生存核（viability kernel）」判断当前状态是否还在可恢复集内，再用恢复可达性决定「自救、升级求助还是安全中止」。恢复本身也是一等公民，需要自己的证书。

**灵感 3（数据采集 → 失败触发的主动实验设计 FADA）**
直觉：失败是机器人数据里最贵、也最富信息的样本。一段成功轨迹只告诉你「这样能行」，一次失败却同时告诉你「边界在哪、模型错在哪、下次该问什么」。关键洞见：**把数据采集从「被动日志」升级为「带安全约束的主动实验」**——系统可选择做一次受控诊断探针（轻触扫描估计摩擦）、向人请求一次示范、请求遥操作接管、或在数字孪生里做反事实重放。选择依据不是「采多少」，而是**每单位风险/时间/人类打扰换来的期望信息增益**。对诊断探针，进一步用 D-最优实验设计求激励轨迹，使 Fisher 信息最大化而接触力始终在安全界内。

**灵感 4（数据采集 → 失败来源数据单元与可审计账本 FODU/DPL）**
直觉：从失败里学到的模型如果不知道「这条数据从哪来、当时为什么失败、采集是否安全、用户是否授权」，那它不是资产而是负债——可能把一次传感器故障学成物理规律，也可能在错误的场景上过拟合。关键洞见：**每条失败样本都应封装为一个「失败来源数据单元」FODU**：原始多模态观测 + 失败嵌入 + 根因后验 + 采集动作 + 恢复轨迹 + 结果 + 证书哈希 + 授权标签。所有 FODU 通过只追加的 Merkle 账本链接，使「数据—失败—恢复—模型版本」四者可审计、可回滚、可删除。数据价值则由它覆盖失败流形的「新区域」决定，而非样本数量。

**灵感 5（合流 → 反思流与「把深思编译成反射」RSC/SCA）**
直觉：恢复是毫秒级，根因归因与学习是秒到小时级，二者不能混在一条流水线里。关键洞见：在 SRT-Dual 的语义流、实时流之外增加第三条**反思流（reflection flow, 0.01–1 Hz）**：它慢慢做归因、采集、训练与验证，但一旦某个恢复技能被证书验证通过，就把它**编译成实时流中的有限状态反射宏动作**（带最坏执行时间 WCET 与安全证书）。于是系统获得一种「代谢」能力——**把这一次的深思熟虑，编译成下一次的条件反射**。模型更新则在影子模式中进行，只有通过「失败回归测试集」且不降低安全盾牌强度，才允许晋升。

**灵感 6（合流 → 八维预算与恢复-数据联合证书 PCE++++++/J_rec）**
直觉：恢复与采集都需要资源：恢复有恢复时域、可升级次数、可调用技能数；采集有存储、人类时间、探针风险、标注预算。关键洞见：把第 61 轮的六元组预算扩展为**八维 B_cog8 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_rec, B_data)**；恢复预算耗尽时只能升级或中止，数据预算耗尽时退回被动日志。并用 **J_rec** 把「失败根因、恢复技能与结果、采集过程、数据来源、模型版本」绑成一张可验证证书，保证「每一次失败都不被浪费，也不被滥用」。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（失败事件与失败流形 FRM）** 设机器人状态 x_t = (q, q̇, τ, K, contact, EV_exec)，硬安全集
```
S_hard = { x | F ≤ F_max ∧ |q̇| ≤ v_max ∧ contact_stable ∧ Valid(J_sem_exec) }
```
失败事件
```
f_t = (t, s_t, v_t, c_t^obs, e_t^fail, severity_t)
```
其中：
- **症状向量** s_t = (slip, vibration, force_exceed, timeout, tracking_error, semantic_drift, clarification_loop) ∈ ℝ^7
- **违反约束** v_t ∈ {force, velocity, contact, semantic, timing, hardware, none}
- **可观测原因候选** c_t^obs ⊆ C（见定义 174）
- **失败嵌入** e_t^fail = E_fail(s_t, x_t, [d_scene, d_intent, d_imp, d_ev]) ∈ ℝ^d_us，由 XMC+++ 的四项语义分歧度与状态共同编码
- **严重度** severity_t = d_rec(x_t) / H_rec ∈ [0, ∞)（定义 175）

失败流形 M_fail = { e_t^fail } ⊂ ℝ^d_us；失败记忆 M_f = {(f_i, b_i, σ_i, outcome_i, fod_i)} 保存最近 N_f 次失败及其根因后验、恢复技能、结果与数据单元。

**定义 174（根因归因 RCA）** 原因类
```
C = {scene, physics, intent, dialogue, timing, sensor, actuator, environment}
```
给定因果 DAG G（原因 → 症状，含混杂边），根因后验
```
P(c | s) ∝ P(c) · ∏_{j} P(s_j | c),   c ∈ C
```
仅靠似然仍会被相关症状误导，故引入**反事实归因**：对 USR 的第 c 个语义分量做干预 do(z_c ← z'_c)（例如换用次优场景嵌入、把物理先验置为通用先验），
```
Δ_c = D⁺_sem(z) - D⁺_sem(do(z_c ← z'_c))
```
Δ_c 越大，说明「若该分量正确，分歧本应显著变小」，即该分量越可能是根因。最终归因分数
```
A(c) = softmax_c( α·log P(c|s) + β·Δ_c + γ·Shapley_c )
```
其中 Shapley_c 为四项 USR 分歧度在因果图约束下的 Shapley 分摊，用于公平处理分量交互。输出 (b_cause, δ_cause)：b_cause ∈ Δ(C) 为根因后验，δ_cause 为其校准置信度（由温度标定与保形预测给出）。

**定义 175（安全核、生存核与恢复可达集）** 
- **硬安全核** K_hard = S_hard。
- **生存核** K_viable ⊆ K_hard：存在控制策略使系统永远停留在 K_hard 内的最大状态集（受控不变集）。
- **恢复可达集** 给定恢复时域 H_rec、风险上界 ρ、失败概率 δ：
```
R_{ρ,δ} = { x | ∃π_rec, P(∃t ≤ H_rec: x_t ∈ K_viable | x, π_rec) ≥ 1-δ
                ∧ max_t Risk(x_t, a_t) ≤ ρ }
```
- **恢复距离** d_rec(x) = min_{π_rec} E[ Σ_{t≤H_rec} (λ_t·1 + λ_e·‖a_t‖² + λ_r·Risk(x_t,a_t)) ]，若不可达则 d_rec = ∞。
- **失败三分类**：transient（x ∈ K_viable）、recoverable（x ∈ R_{ρ,δ}）、critical（x ∉ R_{ρ,δ}）。
注意 d_rec 不是欧氏距离，而是「恢复代价」；这正是把「严重程度」从人工阈值变成控制可达性问题的关键。

**定义 176（可验证恢复技能与恢复策略）** 恢复技能
```
σ = (pre_σ, post_σ, ctrl_σ, ΔK_σ, H_σ, ρ_σ, cert_σ)
```
- pre_σ, post_σ：前置/后置状态谓词（必须由状态估计与证书可判定）
- ctrl_σ：底层控制器（回撤、柔顺泄压、重夹、局部重规划、安全停止、请求接管）
- ρ_σ：技能执行期间的风险上界；cert_σ：技能证书（前置成立 ⇒ 以概率 ≥ 1-δ 在 H_σ 内到达 post_σ 且风险 ≤ ρ_σ）
- **可组合性**：σ₁ ∘ σ₂ 合法当且仅当 post_{σ₁} ⇒ pre_{σ₂}；组合证书由两张证书拼接并做不变式检查
- **失败安全（fail-safe）**：若 σ 在执行中失败，系统必须仍处于 pre_σ 的 fallback 子集内，且可重新归因、重新选择技能——禁止「恢复失败后无状态可用」

恢复技能库 Σ = {retract, compliance_slack, re_grasp, re_approach, local_replan, safe_stop, human_handover, ...}。恢复策略
```
π_rec: (e_fail, b_cause, d_rec, x) → σ ∈ Σ 或 σ₁∘…∘σ_k 或 escalate
```
选择准则：在证书通过且 pre 成立的技能中，最小化 E[恢复代价] - λ_c·cause_match(c, σ)，其中 cause_match 由根因—技能适配矩阵给出（如 physics→compliance_slack/re_grasp，timing→safe_stop，sensor→escalate）。

**定义 177（恢复技能编译 RSC）** 编译算子
```
compile: σ ↦ reflex_σ = (FSM, WCET, guard, cert_reflex)
```
把慢速恢复技能折叠为实时流可执行的有限状态宏动作，要求：
1. **WCET 可证**：单步执行时间上界 ≤ 实时周期预算；
2. **保守性**：reflex_σ 在 pre_σ 上的行为是 σ 的保守近似（不扩大风险集）；
3. **可撤销**：任意时刻可被安全盾牌抢占（preemptible）；
4. **晋升门槛**：σ 在影子/仿真中通过 N_promote 次失败回放，且 cert_reflex 与失败回归测试集均通过。
编译成功后，下一次同类失败可直接由实时流以反射方式处理，将恢复延迟从「语义流级（~100 ms）」降到「控制级（~ms）」。

**定义 178（失败触发主动数据采集 FADA）** 采集动作空间
```
A_acq = { probe(u), ask_demo, teleop, counterfactual_replay, passive_log }
```
- probe(u)：施加受控激励 u（小幅力/位姿扫描）以辨识物理属性 φ_phys
- ask_demo：请求人类示范/纠正（交互式模仿，DAgger 风格）
- teleop：请求遥操作接管并记录轨迹
- counterfactual_replay：在数字孪生中以随机化参数重放失败，获得带标签的反事实结果
- passive_log：不改行为，仅记录

给定根因信念 b_cause、状态 x，采集动作的**安全信息价值**
```
VOI_acq(a) = E_{o~P(o|x,a)}[ H(b_cause) - H(b_cause' | o) ]
             / ( λ_r·R_max(a,x) + λ_t·T(a) + λ_h·H_human(a) )
```
约束：R_max(a,x) ≤ ε_probe 且执行 a 期间 J_sem_exec 不得失效（安全盾牌优先于信息增益）。动作选择
```
a* = argmax_{a ∈ A_acq} VOI_acq(a)  s.t.  VOI_acq(a*) > τ_voi ∧ B_data 未耗尽
```
**诊断探针的 D-最优设计**：对 φ = (μ, k, η, σ) 选择激励
```
u* = argmax_{u ∈ U_safe} log det( I(φ; u) ),   U_safe = {u | F(u) ≤ ε_probe·F_max}
```
其中 I(φ;u) 为 Fisher 信息矩阵。这把「采集数据」从拍脑袋变成**带硬安全约束的最优实验设计**。

**定义 179（失败来源数据单元 FODU 与数据账本 DPL）** 
```
FODU = ( o_multimodal, e_fail, b_cause, δ_cause,
         a_acq, recovery_trace, outcome,
         J_rec_hash, provenance, consent_tag, ts, robot_id )
```
- **数据账本** DPL：只追加的 Merkle 账本，每个 FODU 的哈希作为叶子；任何训练样本必须能沿 `sample → FODU → Merkle root` 追溯
- **失败覆盖度**：Cov(D) = M_fail 被 D 中样本的 ε-ball 覆盖的测度（按原因类加权）
- **数据价值**：val(fod) = ΔCov(fod; D) + λ_r·E[未来风险下降 | fod]，即「新覆盖的失败区域」+「预期风险下降」
- **策展目标**：在存储/标注/人类预算约束下最大化 Σ val，去重（按 e_fail 近邻），并拒绝 provenance 不完整或 consent 不满足的样本。数据量不是目标，**失败流形的覆盖才是**。

**定义 180（八维认知-恢复-数据预算 PCE++++++）** 
```
B_cog8 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_rec, B_data)
```
- B_rec = (H_rec, ρ_rec, N_escalate, N_skill_call)
- B_data = (Storage, Human_minutes, ε_probe, Label_budget, Adapt_compute)
- **成本**：
```
cost_cog8 = cost_cog5 + λ_rec·(recovery_time/H_rec + escalations/N_escalate)
                     + λ_data·(probe_risk/ε_probe + human_used/Human_budget + adapt_compute/Adapt_compute)
```
- **降级阶梯（安全永不降级）**：
  - B_data 耗尽：停止主动采集，仅 passive_log；已有数据仍可用于离线训练
  - B_rec 耗尽：不再尝试新技能，直接 escalate（求助/遥操作/安全中止）
  - B_mel / B_usr 耗尽：沿用第 61 轮蒸馏/缓存/冻结锚点策略
- VOI 扩展：voi_cog8 = VOI_meta - cost_cog8 - safety_margin，仅当 voi_cog8 > 0 才执行恢复或采集

**定义 181（安全持续自适应 SCA）** 自适应算子 U: θ → θ'（仅作用于 MEL 的 LoRA 适配器、DMS 策略头、USR 投影头的非安全部分）必须满足
```
(1) E[L_reg(θ')] ≤ E[L_reg(θ)] + ε_reg          # 失败回归测试集不显著退化
(2) SafetyShield(θ') = SafetyShield(θ)           # 安全盾牌强度不降低
(3) Provenance(D_new) = 完整                    # 新数据全部可追溯
(4) Cov(D_new ∪ D_old) ≥ Cov(D_old)              # 覆盖度单调不降
```
晋升流程：**影子模式 → 金丝雀（小比例任务）→ 全量**；任一步骤失败即回滚到上一认证版本。安全关键投影头 Π 与硬约束编译器的参数**禁止**由失败数据直接更新，只能走「证书 + 人工批准」通道。

**定义 182（恢复接地的对话与升级协议 RDP）** 升级层级
```
L0 自主恢复（技能/反射）
L1 诊断探针（主动采集，仍自主）
L2 澄清对话（DMS ask_clarify）
L3 人类示范 / 遥操作接管
L4 安全中止 / 请求现场介入
```
升级决策：设 U_rec 为继续自主恢复的期望效用，U_esc 为升级的期望效用，
```
escalate(L) ⇔ E[U_esc(L)] - λ_cog·Interruption(L) > E[U_rec] + safety_margin
```
且 critical 状态强制 L≥3。恢复成功后，连续 k 次同类任务成功则降一级（de-escalation）。每次升级/降级都写入 J_rec，并向用户给出**可解释的失败说明**（根因后验 + 已尝试技能 + 证书），而不是一句「出错了」。

**定义 183（恢复-数据联合证书 J_rec）** 
```
J_rec = ( failure_id, b_cause, δ_cause,
          σ / reflex_σ, J_skill,
          d_rec, recovered | safe_abort,
          acquisition = (a_acq, R_max, VOI_acq),
          FODU_ids, provenance_root,
          adapt_version, J_sem_exec )
```
验证规则
```
Valid(J_rec) ⇔ 全程 SafetyInvariant 成立
             ∧ (recovered ∨ safe_abort)
             ∧ d_rec ≤ H_rec（若 recovered）
             ∧ ProvenanceComplete(FODU_ids)
             ∧ R_max(a_acq) ≤ ε_probe
             ∧ J_sem_exec 在恢复前后均有效
```
J_rec 与第 61 轮 J_sem_exec 的关系：J_sem_exec 证明「这一步执行忠于语义」，J_rec 额外证明「这一步失败被正确归因、被安全恢复、被合规地转化为数据」。

**定义 184（三流架构 SRT-Tri 与失败恢复-数据采集闭环 FREC）** 
```

  # 1) 检测
  f ← FRM.detect(x, J_sem_exec, XMC+++.divergence())
  if f is None: return RealtimePipeline.step(...)          # 正常路径
  # 2) 归因
  b_cause, δ_cause ← RCA.attribute(f, USR)
  # 3) 分类与恢复

  else:

      trace ← RRL.execute_with_shield(σ, x)                # 盾牌全程在线
      if trace.failed: re-attribute and retry（B_rec 允许时）
  # 4) 采集（只在不扩大风险时）
  a ← FADA.choose(b_cause, x)                              # 受 ε_probe 与 B_data 约束
  if a: o ← execute_acquisition(a); b_cause ← update(o)
  # 5) 证书与数据
  fod ← DPL.record(f, b_cause, a, trace, J)
  J ← J_rec.build(f, b_cause, σ, trace, fod, adapt_version)
  # 6) 反思/学习（异步）
  ReflectionPipeline.enqueue(f, b_cause, σ, trace, fod)
  return J
```

```python
class FailureRepresentation:
    def __init__(self, d_us=256):
        self.encoder = FailureEncoder(d_us)
        self.failure_manifold = FailureManifoldIndex(d_us)

    def detect(self, x, J_sem_exec, div_terms):
        s = {
            'slip': x.ev.slip_detected,
            'vibration': x.ev.vibration,
            'force_exceed': x.F > x.F_max,
            'timeout': x.dt > x.tau_deadline,
            'tracking_error': x.track_err > x.tau_track,
            'semantic_drift': div_terms.total > x.tau_sem,
            'clarification_loop': x.dms.clarify_count > x.tau_clarify,
        }
        violated = self._first_violation(x, J_sem_exec)
        if violated is None and not any(s.values()):
            return None
        e_fail = self.encoder(s, x, div_terms.as_vector())
        self.failure_manifold.add(e_fail)
        return FailureEvent(t=now(), symptoms=s, violated=violated,
                            e_fail=e_fail, severity=None)  # 由 RRL 填 d_rec

class RootCauseAttributor:
    def __init__(self, dag, classes, calibrator):
        self.dag = dag                 # 原因 -> 症状 的因果图
        self.classes = classes         # 8 类原因
        self.calibrator = calibrator   # 温度标定 / 保形预测

    def posterior(self, f):
        logp = self.dag.log_prior(self.classes)
        for j, sj in f.symptoms.items():
            if sj:
                logp += self.dag.log_likelihood(symptom=j, causes=self.classes)
        return softmax(logp)

    def counterfactual(self, f, usr):
        base = usr.divergence()
        out = {}
        for c in self.classes:
            z_alt = usr.intervene_component(c, mode='alternative')
            out[c] = base - usr.divergence_with(z_alt)
        return normalize(out)

    def attribute(self, f, usr):
        p = self.posterior(f)
        delta = self.counterfactual(f, usr)
        shap = usr.shapley_terms(constraint_dag=self.dag)
        score = softmax(0.5*np.log(p + 1e-9) + 0.3*delta + 0.2*shap)
        b_cause, delta_conf = self.calibrator.calibrate(score, f)
        return b_cause, delta_conf
```

### IP-185 RRL（恢复可达性、技能选择与安全执行）

```python
class RecoveryReachabilityLayer:
    def __init__(self, library, H_rec=2.0, eps_risk=0.1, delta=0.01):
        self.library = library          # Σ: 带 pre/post/cert 的技能
        self.H_rec = H_rec
        self.eps_risk = eps_risk
        self.delta = delta
        self.d_rec_estimator = RecoveryDistanceEstimator()
        self.cause_skill_affinity = build_affinity()  # 根因 x 技能 适配矩阵

    def classify(self, x):
        if self.in_viability_kernel(x):
            return 'transient'
        d = self.d_rec_estimator.estimate(x, self.library, self.H_rec)
        return 'recoverable' if d <= self.H_rec else 'critical'

    def select(self, f, b_cause, d_rec, x):
        feasible = [s for s in self.library
                    if s.pre(x) and s.cert.valid() and s.risk_bound <= self.eps_risk]
        if not feasible:
            return ESCALATE
        def score(s):
            cause_match = sum(b_cause[c] * self.cause_skill_affinity[c][s.name]
                              for c in b_cause)
            return -self.d_rec_estimator.after(s, x) - 1.0*cause_match
        return max(feasible, key=score)

    def execute_with_shield(self, sigma, x):
        # 安全盾牌：任何时刻不满足硬约束则抢占并转 safe_stop
        trace = RecoveryTrace(skill=sigma.name)
        while not sigma.post(x):
            if not sigma.pre(x):
                trace.failed = True
                return trace                      # 回到 fallback 子集，允许重新归因
            a = sigma.ctrl(x)
            if not self.shield.certify(a, x):     # 盾牌优先于技能
                a = self.library['safe_stop'].ctrl(x)
            x = self.step(x, a)
            trace.append(x, a, self.shield.risk(a, x))
            if trace.elapsed > sigma.H:
                trace.failed = True
                return trace
        trace.success = True
        return trace

    def compile_to_reflex(self, sigma):
        fsm = synthesize_fsm(sigma)               # 有限状态宏动作
        wcet = verify_wcet(fsm)
        if wcet > REALTIME_BUDGET or not verify_reflex_cert(fsm, sigma):
            return None
        return ReflexMacroAction(fsm=fsm, wcet=wcet, cert=build_reflex_cert(fsm))
```

### IP-186 FADA（失败触发主动数据采集）

```python
class FailureTriggeredAcquisition:
    def __init__(self, budget, eps_probe=0.05, tau_voi=0.1):
        self.budget = budget
        self.eps_probe = eps_probe
        self.tau_voi = tau_voi

    def safe_information_value(self, a, b_cause, x):
        r_max = self.risk_bound(a, x)
        if r_max > self.eps_probe or not self.usr.safety_case_holds(a, x):
            return -np.inf
        eig = self.expected_information_gain(a, b_cause)  # 互信息 I(C; O)
        cost = (1.0*r_max + 0.2*a.duration + 0.5*a.human_cost)
        return eig / max(cost, 1e-6)

    def choose(self, b_cause, x):
        if self.budget.data_exhausted():
            return AcquisitionAction('passive_log')
        scores = {a.name: self.safe_information_value(a, b_cause, x)
                  for a in self.actions(x)}
        name, val = max(scores.items(), key=lambda kv: kv[1])
        if not np.isfinite(val) or val < self.tau_voi:
            return AcquisitionAction('passive_log')
        return self.action_by_name(name)

    def design_probe(self, phi_prior, x):
        # D-最优激励：最大化 Fisher 信息，同时满足接触力/速度硬约束
        best, best_info = None, -np.inf
        for u in self.safe_excitation_set(x):
            info = fisher_information(phi_prior, u)
            if np.linalg.det(info) > best_info:
                best, best_info = u, np.linalg.det(info)
        return best
```

```python
    def curate(self, pool, budget):
        accepted = []
        D = Dataset([])
        for fod in sorted(pool, key=self.value_estimate, reverse=True):
            if not self.provenance_ok(fod) or not self.consent_ok(fod):

            accepted.append(fod); D.add(fod); budget.consume(fod)
```

### IP-188 SCA（安全持续自适应）

```python
class SafeContinualAdapter:
    def __init__(self, model, regression_suite, eps_reg=0.01):
        self.model = model
        self.regression = regression_suite   # 来自 M_f 的失败回归测试集
        self.eps_reg = eps_reg

    def try_update(self, D_new):
        theta0 = self.model.snapshot_adapters()
        base_reg = self.regression.evaluate(self.model)
        for batch in D_new.shuffled_batches():
            loss = self.model.task_loss(batch) \
                 + self.model.ewc_penalty(theta0) \
                 + self.model.kl_to_reference(batch)
            loss.backward(); self.model.step()
        new_reg = self.regression.evaluate(self.model)
        if new_reg > base_reg + self.eps_reg \
           or not self.model.shield_intact() \
           or not self.provenance_complete(D_new) \
           or self.coverage_decreased(D_new):
            self.model.restore(theta0)
            return UpdateResult(accepted=False, reason='regression_or_safety')
        return UpdateResult(accepted=True, version=self.model.version)
```

### IP-189/192 SRT-Tri + FREC（三流闭环）

```python
class SRT_Tri:
    def __init__(self, realtime, semantic, reflection):
        self.rt = realtime
        self.sem = semantic
        self.ref = reflection
        self.failure_buffer = Queue()
        self.anchor = SharedMemoryAnchor()
        self.ledger = FailureOriginDataLedger()

    def realtime_step(self, x, delta_f_req):
        # 1-10kHz：消费锚点 + 恢复反射；永不阻塞
        if self.failure_buffer.has_critical():
            return self.rt.safe_stop(x)
        return self.rt.step(x, delta_f_req, self.anchor.read_latest())

    def semantic_step(self, obs):
        # 10-100Hz：MEL + DMS + USR（沿用第 61 轮）
        out = self.sem.step(obs)
        f = FRM.detect(out.x, out.J_sem_exec, out.div)
        if f: self.failure_buffer.put(f)
        self.anchor.commit(out)
        return out

    def reflection_step(self):
        # 0.01-1Hz：归因 -> 恢复验证 -> 采集 -> 落账 -> 自适应 -> 编译
        f = self.failure_buffer.get(timeout=0.0)
        if f is None: return
        b, d = RCA.attribute(f, self.sem.usr)
        cls = RRL.classify(f.x)
        if cls == 'critical':
            RDP.escalate(level=3, reason=b, evidence=f)
            J = J_rec.safe_abort(f, b, d)
        else:
            sigma = π_rec.select(f, b, f.x)
            trace = RRL.execute_with_shield(sigma, f.x)
            a = FADA.choose(b, f.x)
            fod = self.ledger.record(f.obs, f, b, a, trace, f.J_sem_exec)
            J = J_rec.build(f, b, sigma, trace, fod, self.sem.version)
            self.ref.adapt_if_ready(fod)
            reflex = RRL.compile_to_reflex(sigma)
            if reflex: self.rt.register_reflex(reflex)
        self.ledger.audit(J)
```

| PCE++++++ | O(1) 预算检查 | O(1) | 任一预算耗尽触发安全降级 |

**正确性定理（FREC-Safe / No-Failure-Wasted）**
假设 A61–A70，并新增：
- **(A71)** 失败检测器在 H_detect 内检出所有「可观测失败」，漏检率 ≤ η_detect；
- **(A72)** 根因归因器经温度标定/保形预测，满足 P(c* ∈ top-k) ≥ 1-α_cal；
- **(A73)** 硬安全集 S_hard 非空，且安全盾牌 Shield 对每个动作在 O(1) 内可判定并阻断越界动作；
- **(A74)** 每个恢复技能 σ 的证书 cert_σ 是可靠的（前置成立 ⇒ post 以 ≥ 1-δ 达成且风险 ≤ ρ_σ）；
- **(A75)** 采集动作的 R_max 上界可计算且保守；VOI 估计无偏；
- **(A76)** DPL 的哈希函数抗碰撞，账本只追加；
- **(A77)** SCA 的回归测试集 F_reg 覆盖 M_f 中每类失败的至少 k 个样本；
- **(A78)** 三流通过无锁共享内存与消息队列通信，实时流读取不阻塞。

则：
1. **安全不变性**：只要 Shield 全程在线，系统在正常执行、恢复、诊断探针、人类接管交接期间均不会违反 S_hard。（恢复与采集不得以安全为代价。）
2. **有界恢复**：若 x ∈ R_{ρ,δ}，则 FREC 以 ≥ 1-δ 的概率在 H_rec 内到达 K_viable，且全程风险 ≤ ρ。
3. **归因可靠性**：对可观测失败，真实根因以 ≥ 1-α_cal 的概率落在 top-k 归因结果中；归因证书可作为 J_rec 的一部分审计。
4. **学习不退化**：任何被 SCA 接受的模型更新，在失败回归测试集上的性能退化 ≤ ε_reg，且安全盾牌强度不降低；否则自动回滚。
5. **无失败浪费 / 数据合规**：每个被检出的失败要么恢复、要么安全中止，并产生一张有效 J_rec 与一个可追溯的 FODU；每个进入训练的样本均可沿 DPL 追溯到其失败来源与授权标签。
6. **覆盖单调性**：在策展规则下 Cov(D) 单调不降；新增数据的价值由其覆盖的失败流形新区域度量，而非数量。
7. **预算安全**：任一 B_cog8 维度耗尽触发对应降级；B_data 耗尽只损失信息、B_rec 耗尽只导致升级，二者都不降低安全性。

**边界说明（重要）**：上述定理是**条件性**的——它保证「已检出、已建模、可安全采集」的失败被安全恢复与合规利用，但**不保证对未检出、未命名、不可安全探测的失败（unknown unknowns）有效**。这正是下一节风险与 E210 红队实验要正面处理的部分。

**实验原则**：E210 必须包含「系统设计者也不知道的失败」——用独立红队构造新材质、新接触几何、传感器污染与复合故障，检验 FREC 是否会在「检测不到」时仍然保持安全中止，而不是自信地继续。所有实验都应报告**负结果**与失效边界，而不是只报告成功率。

## 5. 本轮最大风险

**一句话**：FREC 最大的风险不是恢复失败，而是**「可检测、可安全采集的失败」构成一个自我确认的闭环**——系统只会对它已经能命名、能安全探测的失败模式越变越强，而真正的 unknown unknowns 因为检测不到、又不敢探测，被永久排除在数据与训练之外，最终指标越来越漂亮、盲区却越来越深；必须以「独立红队未知失败集 + 检测器漏检率上界 + 安全中止优先于自信恢复 + 覆盖度外推审计」作为不可外包的外部校准，才能避免「越学越稳、越稳越盲」的失败恢复幻觉。

---

**本轮结论**：把失败从「降级触发器」升级为「带根因、距离、技能与证书的一等对象」，并把数据采集从「被动日志」升级为「受安全约束的主动实验」，用三流架构把深思编译成反射——但这一切只在「失败可被看见」的前提下成立。

## 2. 关键定义与命题（压缩版）

**定义 173（失败事件与失败流形）**：失败是状态相对硬安全集 S_hard 的一次结构化越界，由症状、违反约束、原因候选、失败嵌入与严重度组成；失败嵌入落入 USR 的失败流形 M_fail，支持近邻检索与覆盖度计算。严重度定义为 severity = d_rec/H_rec，而非人工阈值。

**定义 174（根因归因）**：在因果 DAG 上做贝叶斯后验，并对 USR 的四个语义分量做反事实干预，得到「若该分量正确、分歧本应下降多少」的 Δ_c；再用 Shapley 公平分摊分量交互。输出 (b_cause, δ_cause)。关键：**归因不是猜标签，而是对语义-控制链路的可干预分解**。

**定义 175（安全核、生存核、恢复可达集）**：K_viable 是「存在控制策略使系统永远不越界」的最大集合；R_{ρ,δ} 是「存在恢复策略在 H_rec 内以 ≥ 1-δ 概率回到 K_viable 且全程风险 ≤ ρ」的集合；d_rec 是到 K_viable 的最小期望恢复代价。失败因此分为 transient / recoverable / critical。**这把「严重」从形容词变成了可达性判定。**

**定义 176（可验证恢复技能）**：技能带前置/后置条件、控制律、阻抗增量、时域、风险上界与证书；技能可组合（post₁⇒pre₂），且必须失败安全（执行失败仍落在 fallback 子集，可重新归因）。恢复策略在可行技能中最小化恢复代价减根因-技能适配度。

**定义 177（恢复技能编译）**：把技能编译为实时流可执行的 FSM 反射宏动作，要求 WCET 可证、行为保守、可抢占、经 N_promote 次失败回放与回归测试才能晋升。效果：**恢复延迟从语义流的 ~100 ms 降到控制级 ~ms**。

**定义 178（失败触发主动数据采集）**：在安全约束 R_max ≤ ε_probe 下，选择使「每单位风险/时间/人类打扰的信息增益」最大的采集动作；诊断探针用 D-最优实验设计求激励轨迹。关键：**数据采集不是多拍几张，而是带硬约束的最优实验。**

**定义 179（FODU 与数据账本）**：每条失败样本封装为 FODU，包含观测、失败嵌入、根因后验、采集动作、恢复轨迹、结果、证书哈希、来源与授权；DPL 只追加、可验证、可删除；数据价值 = 新覆盖的失败流形 + 预期风险下降。**数据量不是目标，失败覆盖才是。**

**定义 180（八维预算）**：在六元组基础上增加 B_rec 与 B_data；预算耗尽分别触发「升级求助」与「退回被动日志」，安全永不降级。

**定义 181（安全持续自适应）**：仅更新非安全适配器；接受条件为失败回归集退化 ≤ ε_reg、盾牌不降级、溯源完整、覆盖单调；流程为影子→金丝雀→全量，失败即回滚。安全关键投影头与硬约束编译器禁止由失败数据直接更新。

**定义 182（恢复对话与升级）**：L0 自主→L1 探针→L2 澄清→L3 示范/遥操作→L4 中止；按恢复效用与打断成本比较升级；critical 强制 L≥3；成功后逐级降级；向用户输出可解释失败说明与数据授权请求。

**定义 183（J_rec）**：把「失败根因、恢复技能与结果、采集风险、FODU 溯源、模型版本、J_sem_exec」绑成一张可验证证书。J_sem_exec 证明「执行忠于语义」，J_rec 进一步证明「失败被正确归因、被安全恢复、被合规转化为数据」。

**定义 184（SRT-Tri 与 FREC）**：三流解耦——实时流只做控制与反射恢复，语义流做感知/对话/锚点，反思流做归因/采集/学习/编译；实时流永不阻塞于反思流。FREC 算子串起「检测→归因→恢复/采集→证书/落账→自适应→编译→回归」。

**命题 1（恢复-采集对偶）**：恢复动作与采集动作都可视为对 (状态分布, 信念分布) 的联合作用：恢复主要降低状态风险、附带降低根因熵；采集主要降低根因熵、附带改变状态。二者可在同一约束 POMDP 中统一为
```
max_π E[Σ_t γ^t ( -λ_r·Risk_t - λ_c·Cost_t + λ_i·I(C;O_t) + λ_rec·RecoveryProgress_t ) ]
s.t. Risk_t ≤ ρ,  SafetyShield(a_t)=True,  ∀t
```
因此「先恢复还是先采集」不是流程问题，而是**在安全可行域内比较边际效用**的问题。

```python
class FailureRepresentation:
    def detect(self, x, J_sem_exec, div_terms):
        s = {'slip': x.ev.slip_detected, 'vibration': x.ev.vibration,
             'force_exceed': x.F > x.F_max, 'timeout': x.dt > x.tau_deadline,
             'tracking_error': x.track_err > x.tau_track,
             'semantic_drift': div_terms.total > x.tau_sem,
             'clarification_loop': x.dms.clarify_count > x.tau_clarify}
        violated = self._first_violation(x, J_sem_exec)
        if violated is None and not any(s.values()):
            return None
        e_fail = self.encoder(s, x, div_terms.as_vector())
        self.failure_manifold.add(e_fail)
        return FailureEvent(t=now(), symptoms=s, violated=violated, e_fail=e_fail)

class RootCauseAttributor:
    def attribute(self, f, usr):
        p = self.posterior(f)                       # 因果 DAG 后验
        delta = self.counterfactual(f, usr)         # 四分量干预
        shap = usr.shapley_terms(self.dag)          # 分量交互分摊
        score = softmax(0.5*np.log(p+1e-9) + 0.3*delta + 0.2*shap)
        return self.calibrator.calibrate(score, f)  # (b_cause, δ_cause)

    def counterfactual(self, f, usr):
        base = usr.divergence()
        return normalize({c: base - usr.divergence_with(usr.intervene(c))
                          for c in self.classes})
```

### IP-185 RRL + IP-189 RSC

```python
class RecoveryReachabilityLayer:
    def classify(self, x):
        if self.in_viability_kernel(x): return 'transient'
        d = self.d_rec_estimator.estimate(x, self.library, self.H_rec)
        return 'recoverable' if d <= self.H_rec else 'critical'

    def select(self, f, b_cause, d_rec, x):
        feasible = [s for s in self.library
                    if s.pre(x) and s.cert.valid() and s.risk_bound <= self.eps_risk]
        if not feasible: return ESCALATE
        return max(feasible, key=lambda s:
                   -self.d_rec_estimator.after(s, x)
                   - 1.0*self.cause_match(b_cause, s))

    def execute_with_shield(self, sigma, x):
        trace = RecoveryTrace(skill=sigma.name)
        while not sigma.post(x):
            if not sigma.pre(x):
                trace.failed = True; return trace       # fallback，可重新归因
            a = sigma.ctrl(x)
            if not self.shield.certify(a, x):
                a = self.library['safe_stop'].ctrl(x)   # 盾牌优先
            x = self.step(x, a); trace.append(x, a)
            if trace.elapsed > sigma.H:
                trace.failed = True; return trace
        trace.success = True; return trace

    def compile_to_reflex(self, sigma):
        fsm = synthesize_fsm(sigma); wcet = verify_wcet(fsm)
        if wcet > REALTIME_BUDGET or not verify_reflex_cert(fsm, sigma):
            return None
        return ReflexMacroAction(fsm, wcet, build_reflex_cert(fsm))
```

### IP-186 FADA

```python
class FailureTriggeredAcquisition:
    def safe_information_value(self, a, b_cause, x):
        r = self.risk_bound(a, x)
        if r > self.eps_probe or not self.usr.safety_case_holds(a, x):
            return -np.inf
        eig = mutual_information(b_cause, a)            # I(C; O)
        return eig / max(r + 0.2*a.duration + 0.5*a.human_cost, 1e-6)

    def choose(self, b_cause, x):
        if self.budget.data_exhausted():
            return AcquisitionAction('passive_log')
        scores = {a.name: self.safe_information_value(a, b_cause, x)
                  for a in self.actions(x)}
        name, val = max(scores.items(), key=lambda kv: kv[1])
        return self.action_by_name(name) if np.isfinite(val) and val >= self.tau_voi \
               else AcquisitionAction('passive_log')

    def design_probe(self, phi_prior, x):
        return max(self.safe_excitation_set(x),
                   key=lambda u: np.linalg.det(fisher_information(phi_prior, u)))
```

```python
class FailureOriginDataLedger:
    def record(self, o, f, b, a, trace, J):
        fod = FODU(obs=o, e_fail=f.e_fail, b_cause=b, a_acq=a,
                   recovery_trace=trace, outcome=trace.status,
                   provenance=provenance_of(o, a), consent_tag=consent_of(o),
                   ts=now(), robot_id=ROBOT_ID)
        fod.J_rec_hash = self.merkle.append(canonical_hash(fod))
        return fod

    def curate(self, pool, budget):
        D = Dataset([])
        for fod in sorted(pool, key=self.value_estimate, reverse=True):
            if not (self.provenance_ok(fod) and self.consent_ok(fod)): continue
            if D.near_duplicate(fod.e_fail, eps=0.05): continue
            if self.coverage_gain(fod, D) + self.expected_risk_drop(fod) <= 0: continue
            if budget.insufficient(fod): continue
            D.add(fod); budget.consume(fod)
        return D

class SafeContinualAdapter:
    def try_update(self, D_new):
        theta0 = self.model.snapshot_adapters()
        base = self.regression.evaluate(self.model)
        for batch in D_new.batches():
            (self.model.task_loss(batch)
             + self.model.ewc_penalty(theta0)
             + self.model.kl_to_reference(batch)).backward()
            self.model.step()
        new = self.regression.evaluate(self.model)
        if (new > base + self.eps_reg or not self.model.shield_intact()
            or not self.provenance_complete(D_new) or self.coverage_decreased(D_new)):
            self.model.restore(theta0); return UpdateResult(False, 'regression_or_safety')
        return UpdateResult(True, self.model.version)
```

### IP-190 RDP + IP-192 SRT-Tri/FREC

```python
class RecoveryDialogueProtocol:
    LEVELS = ['L0_autonomous', 'L1_probe', 'L2_clarify',
              'L3_demo_teleop', 'L4_safe_abort']
    def decide(self, f, b_cause, d_rec, budget):
        if d_rec == np.inf or f.critical:
            return 'L3_demo_teleop'
        for L in self.LEVELS[1:]:
            if self.expected_utility(L) - self.interrupt_cost(L) > self.expected_utility('L0'):
                return L
        return 'L0_autonomous'

class SRT_Tri:
    def reflection_step(self):
        f = self.failure_buffer.get(timeout=0.0)
        if f is None: return
        b, d = RCA.attribute(f, self.sem.usr)
        cls = RRL.classify(f.x)
        if cls == 'critical':
            RDP.decide(f, b, np.inf, self.budget)
            J = J_rec.safe_abort(f, b, d)
        else:
            sigma = pi_rec.select(f, b, f.d_rec, f.x)
            trace = RRL.execute_with_shield(sigma, f.x)
            a = FADA.choose(b, f.x)
            fod = self.ledger.record(f.obs, f, b, a, trace, f.J_sem_exec)
            J = J_rec.build(f, b, sigma, trace, fod, self.sem.version)
            self.ref.adapt_if_ready(fod)
            if (reflex := RRL.compile_to_reflex(sigma)) is not None:
                self.rt.register_reflex(reflex)      # 深思 -> 反射
        self.ledger.audit(J)
```

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 保证 |
|---|---|---|---|
| FRM/RCA | O(|C|·d_us+|S|·|C|) | O(N_f·d_us) | top-1 ≥ 80%，ECE ≤ 0.05 |
| RRL | 在线 O(|Σ|)；离线 O(|Σ|·H_rec·N_grid) | O(|Σ|+N_grid) | 恢复成功 ≥ 95%；恢复期违规 = 0 |
| FADA | O(|A_acq|·|C|) | O(|A_acq|) | R_max ≤ ε_probe |
| FODU/DPL | O(1) 追加；O(log N) 证明 | O(N_fod) | 100% 可追溯 |
| SCA | O(Adapt_compute) | O(|θ_adapter|) | 回归退化 ≤ ε_reg |
| SRT-Tri | 实时 ≤ 1 ms | 共享内存+账本 | 实时不阻塞；WCET 可证 |
| PCE++++++ | O(1) | O(1) | 预算耗尽安全降级 |

**定理（FREC-Safe / No-Failure-Wasted）**：在 A61–A70 与新增 A71–A78（检测漏检率 ≤ η_detect；归因校准；盾牌 O(1) 可判定；技能证书可靠；采集风险上界保守；账本抗碰撞；回归集覆盖失败类；三流无阻塞）下：
1. **安全不变性**：盾牌在线时，正常执行、恢复、探针、接管交接全程不违反 S_hard。
2. **有界恢复**：x ∈ R_{ρ,δ} ⇒ 以 ≥ 1-δ 概率在 H_rec 内回到 K_viable，且风险 ≤ ρ。
3. **归因可靠性**：真实根因以 ≥ 1-α_cal 概率落在 top-k。
4. **学习不退化**：被 SCA 接受的更新使失败回归集退化 ≤ ε_reg，盾牌强度不降，否则回滚。
5. **无失败浪费/数据合规**：每个可观测失败产生有效 J_rec 与可追溯 FODU；进入训练的样本均可沿 DPL 回溯。
6. **覆盖单调**：策展下 Cov(D) 单调不降。
7. **预算安全**：B_data 耗尽只损失信息，B_rec 耗尽只导致升级，二者都不降低安全性。

**边界**：定理只覆盖「已检出、已建模、可安全采集」的失败；对 unknown unknowns 不提供保证——这必须由 E210 独立红队与安全中止策略兜底。

## 6. 本轮最大风险

**一句话**：FREC 最大风险是「可检测、可安全采集的失败」形成自我确认闭环——系统对已命名失败越学越强，却对检测不到、也不敢探测的 unknown unknowns 永久失明，指标越来越漂亮而盲区越来越深；必须用独立红队未知失败集、漏检率上界、安全中止优先于自信恢复、覆盖度外推审计作为外部校准。
