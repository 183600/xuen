### 第 4 轮灵感驱动研究记录

**灵感词**：协同控制、视觉伺服

**继承关系**：第 3 轮 CADVS-v3（IP-485~488）在 v2 三锚点（空间 3DCF、物理 MSRG、人因 HICK）之上追加了末点锚 EEK（kc_ee）与记忆锚 LTEM（kc_mem），并以联邦聚合 FFA 做慢时域校准，形成五硬门 kc_evidence_forged_v3 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem，执行集 Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。本轮不推翻 v3，而是把证据从「单机、当前、历史」推进到「耦合闭环与共享感知资源」，形成 CADVS-v4（IP-489~492），执行集嵌套升级为 Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。

**直觉与动机**：

1. **协同控制：把「我安全」升级为「我们安全」**。v3 的 FFA 是分钟级、统计式、非实时的证据共享；继承来的 MRCC 只是周期广播 LocalCertSummary 并做一致性检查，它们都不是控制意义上的协同。真正的协同控制要求多台机器人在同一闭环内共同承担一个任务（共抬、双臂装配、编队搬运），此时安全性本质上是**耦合**的：单机各自的 FQC、kc_ee 全通过，耦合闭环仍可能因跨机视觉耦合、通信时延与共享对象动力学而发散。引入协同控制证书 CCC：以 assume-guarantee 契约描述每台机器人的假设 A_i 与保证 G_i，用耦合增益矩阵谱半径 ρ(G) 与时延裕度 τ_max 判定闭环收缩，构成硬门 kc_coop。协同层运行在 10–50 Hz，不侵入 200 Hz 内环。

2. **视觉伺服：把「独占特征」升级为「共享且会被遮挡的特征」**。v1 的 VSCK 是单机独占式的：FQC = (cond(J_s), track_conf, depth_var) 只回答「我这台相机的特征质量如何」。协同任务里视觉特征是共享资源——peer 的机械臂/本体可能遮挡我的特征，两台机器人可能争用同一特征并由此产生未声明的耦合。把 VSCK 升级为共享视觉伺服 SVSCK：为特征建立带 epoch 的托管租约，基于 peer 的计划运动做遮挡预测，并强制「特征划分（互斥）」或「显式主从（共享+耦合证书）」两种模式之一，构成硬门 kc_svs。

3. **因果证书账本：防止协同证书被「重打时间戳」洗白**。协同证书天然互相依赖，形成有向依赖图；若允许派生证书重新盖当前时间戳，一个来自 200 ms 前的过期 peer 证书会被包装成「刚刚有效」，协同门就变成互相背书的形式主义。引入 CCL：证书携带向量时钟 vc 与依赖集 deps，派生证书的有效时刻继承依赖闭包中**最旧**的 t_gen，并检测依赖环。这样「我们互相认为对方安全」不能再靠循环引用自证。

**关键洞见**：v3 回答「证据在哪/是否成立/谁背书/末端是否真实/历史上是否可靠」；v4 追加两个系统级锚——协同锚回答「这个耦合闭环是否整体收缩」（CCC），共享感知锚回答「协同动作后我们的视觉特征是否仍然可用」（SVSCK），并用因果账本 CCL 保证前两者不是建立在过期/循环的互相背书之上。七硬门 kc_evidence_forged_v4 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem ∧ kc_coop ∧ kc_svs，fail-closed；软评分 ECS_v4 仅用于回退分级与仪表盘，不参与安全决策。

**形式化目标（增量）**：
1. 定义耦合视觉伺服误差动力学 ė_i(t) = −λ_i L_i⁺ e_i(t) + Σ_{j≠i} C_ij L_j⁺ e_j(t−τ_ij) + d_i(t)，其中 e_i = s_i − s_i*，C_ij = ∂s_i/∂ξ_j 为跨机耦合雅可比；定义局部/耦合增益 g_i = λ_i‖L_i⁺‖、c_ij = ‖C_ij L_j⁺‖，耦合增益矩阵 G（G_ii = 0，G_ij = g_i c_ij），以及小增益条件 ρ(G) ≤ 1 − γ_margin。
2. 定义 assume-guarantee 契约 Contract_i = (A_i, G_i)：A_i 是对 peer 的假设（其控制位于包络内、其证书因果新鲜、其承诺的特征可用），G_i 是本机的保证（轨迹留在安全集、特征保持可见、控制有界）；定义契约放电条件 ⊨_AG：⋀_j G_j ⇒ ⋀_i A_i 且 A_i ∧ plant_i ⇒ G_i。定义 kc_coop = AG 放电 ∧ ρ(G) ≤ 1−γ_margin ∧ (∀(i,j): τ_ij ≤ τ_max) ∧ CCL 依赖新鲜。
3. 定义共享特征托管租约 lease(f) = (owner, t_lease, ttl, epoch) 与遮挡预测 o_{ij,f} = P(peer j 的计划体扫掠体遮挡机器人 i 对特征 f 的视线)；定义 kc_svs = (遮挡后存活特征数 ≥ m_min) ∧ (cond(L_i^{F_i'}) < κ_max) ∧ (∀f: o_{ij,f} ≤ o_budget) ∧ (租约无同 epoch 冲突 ∧ 无环) ∧ (并发共享特征要么被划分、要么有显式主从耦合证书)。
4. 定义因果证书 cert = (id, payload, t_gen, Δt_val, vc, deps) 与因果年龄 age(c) = t_now − min_{d ∈ closure(deps)} t_gen(d)；定义 CCL.valid(c) = (t_now ≤ t_gen + Δt_val) ∧ (age(c) ≤ Δt_dep) ∧ (依赖图无环) ∧ (所有 deps 有效)。
5. 定义 EFA-v4 七硬门与 Exec_CADVS-v4 ⊆ Exec_CADVS-v3：在 v3 每条路径上再追加 kc_svs（伺服层，使用缓存的特征/遮挡结果）与 kc_coop（协调层），故只缩不涨。

**本轮最大风险**：**协同证书的循环依赖与时延/时钟共谋**——当每台机器人的安全证书都以 peer 的证书为前提、而 peer 的证书又反过来依赖它时，通信时延、时钟偏移与遮挡预测误差会让整个舰队同时「互相证明对方安全」，从而对一个已经发散的耦合闭环集体误发通行证；这种相关失效比 v3 的联邦非 IID 更危险，因为故障是同时、同向、不可靠单机监控发现的。

## 2. 关键算法骨架

### IP-489 CCCK：协同控制证书（协调层 10–50 Hz，O(N²)）

```python
@dataclass
class CooperativeControlCertificateKernel:
    """CCCK：assume-guarantee 契约 + 耦合小增益 + 时延裕度；kc_coop 硬门"""
    N: int
    gamma_margin: float = 0.10      # 小增益裕度
    tau_max: float = 0.020          # s，协同边时延上界（由各机相位裕度离线标定）
    dt_dep: float = 0.050           # s，依赖证书最大因果年龄
    iters: int = 24                 # 幂迭代次数

    def coupling_gain(self, fqc_i, C_ij, L_j_pinv) -> float:
        """G_ij = g_i·‖C_ij L_j⁺‖；C_ij 由共享特征/共享对象几何在线估计"""
        g_i = fqc_i.lambda_gain * np.linalg.norm(fqc_i.L_pinv, 2)
        return g_i * np.linalg.norm(C_ij @ L_j_pinv, 2)

    def build_G(self, active_edges, gains) -> np.ndarray:
        G = np.zeros((self.N, self.N))
        for (i, j) in active_edges:
            G[i, j] = gains[(i, j)]
        return G

    def small_gain(self, G: np.ndarray) -> tuple[bool, float]:
        """ρ(G) 用幂迭代近似；要求 ρ(G) ≤ 1 − γ_margin"""
        w = np.ones(self.N)
        for _ in range(self.iters):
            r = G @ w
            nrm = np.max(r)
            if nrm < 1e-12:
                return True, 0.0
            w = r / nrm
        rho = float(np.max((G @ w) / np.maximum(w, 1e-12)))
        return rho <= 1.0 - self.gamma_margin, rho

    def ag_discharged(self, i, peer_certs) -> bool:
        """A_i 由所有活动 peer 的 G_j 证书合取满足；证书须 CCL 有效"""
        for j, c in peer_certs.items():
            if j == i:
                continue
            if not (c.valid and c.guarantee.covers(self.assumption(i, j))):
                return False
        return True

    def kc_coop(self, i, G, active_edges, delays, peer_certs, ledger,
                t_now) -> tuple[bool, str]:
        if not self.ag_discharged(i, peer_certs):
            return False, 'AG_UNDISCHARGED'
        ok, rho = self.small_gain(G)
        if not ok:
            return False, 'COUPLED_UNSTABLE'
        if any(delays[e] > self.tau_max for e in active_edges):
            return False, 'DELAY_EXCEEDED'
        if not ledger.all_fresh(peer_certs.values(), t_now, self.dt_dep):
            return False, 'DEP_STALE'
        return True, 'COOP_FORGED'

    def degrade(self, reason: str) -> str:
        """协同门失败的回退：物理耦合仍在，不能简单删边；
        删边只代表『失去对耦合的认知』，必须降级为独立安全模式或停。"""
        return {'AG_UNDISCHARGED': 'HOLD_AND_REPLAN',
                'COUPLED_UNSTABLE': 'SPLIT_OR_STOP',
                'DELAY_EXCEEDED': 'FREEZE_COUPLING',
                'DEP_STALE': 'FREEZE_COUPLING'}.get(reason, 'STOP')
```

@dataclass
class SharedVisualServoCertificateKernel:
    """SVSCK：特征托管租约 + 遮挡预测 + 划分/主从；kc_svs 硬门"""
    m_min: int = 8
    kappa_max: float = 50.0
    tau_conf: float = 0.7
    o_budget: float = 0.20
    lease_ttl: float = 0.10          # s
    horizon: float = 0.15            # s，peer 计划运动预测时域

    def predicted_occlusion(self, f, cam_i, planned_vol_j, t_now) -> float:
        """特征射线 vs peer 计划体扫掠体求交；返回遮挡概率（可离线/低频缓存）"""
        ray = cam_i.ray_to(f)
        return planned_vol_j.intersection_prob(ray, horizon=self.horizon)

    def custody_ok(self, F_i, leases, t_now) -> bool:
        """每个特征：租约有效、同 epoch 无冲突 owner、无租约环"""
        if leases.has_cycle():
            return False
        for f in F_i:
            l = leases.get(f)
            if l is None or l.ttl_expired(t_now):
                return False
            if leases.conflicting_owner(f, l.epoch):
                return False
        return True

    def kc_svs(self, i, features, cam_i, peers, leases, t_now) -> tuple[bool, str]:
        visible = []

### IP-491 CCL：因果证书账本（防止过期/循环互相背书）

```python
@dataclass
class CausalCertificateLedger:
    """CCL：向量时钟 + 依赖闭包最旧时刻；派生证书不能变新"""
    dt_dep: float = 0.050

    def age(self, c, t_now) -> float:
        oldest = c.t_gen
        for d in c.dependency_closure:
            oldest = min(oldest, d.t_gen)
        return t_now - oldest

    def valid(self, c, t_now) -> bool:
        if c.t_gen + c.dt_val < t_now:
            return False
        if self.age(c, t_now) > self.dt_dep:
            return False
        if self._has_cycle(c):                 # 向量时钟/DFS 检测
            return False
        return all(self.valid(d, t_now) for d in c.deps)

    def derive(self, deps, payload, t_now, dt_val) -> Cert:
        """派生证书：t_gen 记为 t_now，但 vc/依赖保留；age 由闭包最旧时刻决定"""
        vc = merge_vector_clocks([d.vc for d in deps])
        return Cert(payload=payload, t_gen=t_now, dt_val=dt_val,
                    vc=vc, deps=deps)

    def all_fresh(self, certs, t_now, dt_dep) -> bool:
        self.dt_dep = dt_dep
        return all(self.valid(c, t_now) for c in certs)
```

### IP-492 EFA-v4：七硬门 + 软评分 + 证据铸造流水线 v4

```python
@dataclass
class EvidenceForgingAssemblerV4:
    """EFA-v4：v3 五门 + kc_coop + kc_svs；fail-closed"""
    scf: SpatialCoverageFieldKernel
    msrg_cache: dict
    hic: HumanIntentCertificateKernel
    eek: EndEffectorFidelityKernel
    ltem: LongTermEpisodicMemory
    ccc: CooperativeControlCertificateKernel
    svs: SharedVisualServoCertificateKernel
    ledger: CausalCertificateLedger
    mu_S: float = 0.75

    def hard_gate(self, x, t_now, rule_id, hic, eec, object_class,
                  geo_sig, theta_domain_fp, *,
                  features, cam_i, peers, leases,
                  G, active_edges, delays, peer_certs) -> tuple[bool, str]:
        # --- v3 五硬门 ---
        if self.hic.veto_active(hic):
            return False, 'HIC_STOP'
        if not self.scf.kc_coverage(x, t_now):
            return False, 'COVERAGE_BLIND'
        s2rc = self.msrg_cache.get(rule_id)
        if s2rc is None or s2rc.verdict != 'accept' or s2rc.mu_pass < self.mu_S:
            return False, 'PHYSICS_UNPROVEN'
        if not self.eek.kc_ee(eec):
            return False, 'EE_UNPROVEN'
        pass_mem, eta_mem, novelty = self.ltem.query(
            object_class, geo_sig, theta_domain_fp, rule_id)
        if not pass_mem:
            return False, 'MEMORY_REJECT'
        # --- v4 共享感知锚 ---
        ok_svs, why = self.svs.kc_svs(
            self.me, features, cam_i, peers, leases, t_now)
        if not ok_svs:
            return False, why
        # --- v4 协同闭环锚 ---
        ok_coop, why = self.ccc.kc_coop(
            self.me, G, active_edges, delays, peer_certs, self.ledger, t_now)
        if not ok_coop:
            return False, why
        return True, 'FORGED_V4' + ('|NOVELTY' if novelty else '')

    def ecs_v4(self, base_ecs_v3, eta_mem, eta_coop, eta_svs) -> float:
        return base_ecs_v3 * eta_mem * eta_coop * eta_svs
```

### 集成流水线（v3 → v4）

```

  Φ_global 追加耦合增益/时延分位数 → 初始化 CCCK 的 g_i/τ_max 先验

  各机：估计 C_ij（共享特征/对象几何）→ 发布 G_i 契约证书
      ──▶ CCL 记录 vc/deps ──▶ CCCK：AG 放电 + ρ(G) 小增益 + 时延 + 新鲜
      ├─ AG_UNDISCHARGED → HOLD_AND_REPLAN
      ├─ COUPLED_UNSTABLE→ SPLIT_OR_STOP（拆分工位或停）
      ├─ DELAY_EXCEEDED  → FREEZE_COUPLING（冻结协同，保持单机安全）
      └─ DEP_STALE       → FREEZE_COUPLING

伺服层（~200 Hz，单机 + 缓存遮挡）：
  VSCK FQC → SVSCK：遮挡预测（低频缓存）+ 租约校验 → kc_svs
  EEK：力/力矩/触觉 → EEC → kc_ee
      ├─ FEATURE_STARVED / ILL_CONDITIONED → 回退 PBVS/深度/教师
      ├─ CUSTODY_CONFLICT → 释放/重分配特征租约
      └─ UNDECLARED_SHARED_COUPLING → 升级为显式主从或停

```

## 4. 正确性论证（增量更新）

### 引理 41（耦合视觉伺服的收缩界）

**陈述**：设各机局部 FQC 有效（cond(L_i) < κ_max），耦合误差动力学为 ė_i = −λ_i L_i⁺ e_i + Σ_{j≠i} C_ij L_j⁺ e_j(t−τ_ij) + d_i。若 (a) 耦合增益矩阵满足 ρ(G) ≤ 1 − γ_margin（G_ij = λ_i‖L_i⁺‖·‖C_ij L_j⁺‖），(b) 每条活动边时延 τ_ij ≤ τ_max = min_i φ_{m,i}/ω_{c,i}（φ_{m,i} 为局部相位裕度，ω_{c,i} 为局部增益穿越频率），(c) 扰动有界 ‖d_i‖ ≤ d_max，则耦合误差 e = [e_1;…;e_N] 对 d 输入-状态稳定（ISS），并指数收敛到半径 O(d_max/γ_margin) 的球。

**证明（要点）**：把每个局部伺服环视为一个 ISS 子系统，其增益为 g_i；跨机耦合视为互联通道，增益 c_ij 并附加时延。ρ(G) ≤ 1−γ_margin 是小增益定理在 N 子系统网络上的充分条件（Perron 特征向量给出统一 Lyapunov 权重）。时延条件保证每条延迟环在穿越频率处附加相位滞后小于可用相位裕度，故局部环不因延迟失稳。由互联 ISS 小增益定理与 Razumikhin 型泛函，得到整体 ISS 与指数收敛到扰动球。∎

**工程含义**：kc_coop 通过即表示「耦合闭环整体收缩」，而不只是「每台单机看起来正常」。代价是小增益条件偏保守，可能拒绝一些实际稳定的协同任务（见 R49）。

### 引理 42（共享特征托管的可靠性界）

**陈述**：设遮挡预测误差有界 |o_{ij,f} − ô_{ij,f}| ≤ ε_occ，租约 epoch 单调且无环。若 kc_svs 通过，则 (a) 每台活动机器人在 peer 计划运动后仍保有 ≥ m_min 个预测遮挡 ≤ o_budget 的特征，且 cond(L_i^{F_i'}) < κ_max；(b) 并发机器人对同一特征的使用要么互斥（partition），要么有显式主从耦合证书，不存在未声明的共享特征耦合；(c) 在预测误差 ε_occ 内，伺服环的 FQC 在下一协调周期内保持有效。

**证明（要点）**：(a) 由逐特征遮挡判定与条件数检查直接得出；(b) 由租约 owner 唯一性与 shared_mode 分支保证；(c) 由遮挡预测的 Lipschitz/误差界与 o_budget 的裕度推出。∎

**工程含义**：kc_svs 把「我的特征质量」扩展为「对方动作后我的特征仍可用」，并把共享特征耦合显式化，避免它绕过 kc_coop 偷偷进入闭环。剩余风险是遮挡预测误差本身。

### 引理 43（因果账本的防洗白性）

**陈述**：若 CCL.valid(c) 成立，则对 c 的依赖闭包中任一证书 d，都有 t_now − t_gen(d) ≤ Δt_dep；且任何派生证书的有效新鲜度不超过其依赖闭包的最旧时刻；依赖图含环时 c 无效。

**证明（要点）**：对依赖 DAG 做结构归纳。基例：叶子证书仅受自身 Δt_val 约束。归纳步：派生证书的 age 定义为闭包最旧 t_gen 之差，重写 t_gen 不能改变闭包中最旧值；向量时钟合并保持偏序单调；环检测拒绝自证。∎

**工程含义**：协同门无法被「重新打时间戳」的过期 peer 证书满足，也无法靠 A↔B 循环引用自证；这是 kc_coop 不沦为形式主义背书的前提。

### 定理 v4（执行集收缩与系统级锚点补全）

**陈述**：在 (B1)~(B4)（继承 v3 的末端传感器、记忆忠实、联邦先验、v2 假设）以及 (B5) 耦合闭环满足引理 41 的小增益/时延条件、(B6) 遮挡预测误差 ≤ ε_occ 且租约协议无环、(B7) 舰队时钟偏移有界且 peer 非拜占庭 之下，则：
(i) Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ … ⊆ Exec_v29（严格收缩）；
(ii) 耦合闭环在证书通过时以引理 41 的界指数收缩；
(iii) 共享视觉特征在证书通过时以引理 42 的界保持可用且耦合已声明；
(iv) 协同证据不能通过重打时间戳或循环依赖被伪造（引理 43）；
(v) 七硬门 fail-closed，任一不通过即拒；仅 HIC veto 旁路至 S_stop。

**证明**：(i) v4 在 v3 每条路径上追加 kc_svs 与 kc_coop，故只缩不涨；严格性由 v3 未检查的「单机均通过但耦合发散」与「特征被 peer 遮挡」两类路径被关闭保证。(ii)~(iv) 分由引理 41、42、43。(v) 由 EFA-v4.hard_gate 的合取结构。∎

**诚实声明**：(B5) 的小增益是充分非必要条件，保守性会降低协同任务可用性；(B6) 的遮挡预测在快速运动/透明物体/镜面反射下误差可能超过 ε_occ；(B7) 是最脆弱假设——时钟偏移、DDS 丢包或拜占庭 peer 会同时破坏 CCL 的新鲜性判定与 AG 放电，使整个舰队「集体误证」。缓解：PTP/硬件时间戳、每边独立心跳与超时、peer 证书签名与信誉、协同失败时退化为单机安全模式而非继续协同。

## 7. 本轮最大风险（最终确认）

**一句话**：**协同证书的循环依赖与时延/时钟共谋**——当每台机器人的安全证书都以 peer 的证书为前提、而 peer 的证书又反过来依赖它时，通信时延、时钟偏移与遮挡预测误差会让整个舰队同时「互相证明对方安全」，从而对一个已经发散的耦合闭环集体误发通行证；这种相关失效比 v3 的联邦非 IID 更危险，因为故障是同时、同向、且无法靠单机监控独立发现的。
