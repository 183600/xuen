### 第 5 轮（新循环第 1 轮）灵感驱动研究记录

**灵感词**：闭环控制、腕部相机

**继承关系**：第 4 轮 CADVS-v4（IP-489~492）在 v3 五锚点（3DCF/MSRG/HICK/EEK/LTEM）基础上追加价值锚 VACK（kc_val）与平衡锚 BCK（kc_bal），形成七硬门 kc_evidence_forged_v4 = ∧_{i=1..7} kc_i，fail-closed；执行集 Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。本轮以「闭环控制」「腕部相机」为灵感，不推翻 v4，而是把「末点证据」从两个新维度补强：腕部相机把末点从瞬时点测量升级为连续视觉伺服闭环（视觉锚 WCVK），闭环控制把「证书」本身从开环门控升级为受控不变的安全边际演化（闭环稳定锚 CLCG），形成 CADVS-v5（IP-493~496）。执行集嵌套升级为 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。

**直觉与动机**：

1. **腕部相机：把 EEK 的「点测量」变成「眼在手视觉伺服闭环」**。EEK 只比对末点瞬时力/位姿，回答不了「接近过程中特征是否可观测、是否收敛、遮挡是否临近、手眼标定是否漂移」。腕部相机（eye-in-hand）提供随末端运动的连续视觉通道，用图像雅可比 L_s 把像素特征误差 e_vis 映射到相机速度 ṡ = L_s v_c，使「接近」成为一个可观测、可反馈的闭环过程。引入视觉闭环证书 VCC = (e_vis, σ_min(L_s), κ_occ, δ_calib, τ_lat, t)，硬门 kc_vis 要求误差小、可观测性好、遮挡低、标定漂移小、视觉时延可控；软因子 η_vis 进入评分。让「末点真实」进一步成为「接近过程可观测且收敛」。

2. **闭环控制：把「证书」本身纳入闭环，而不是一次性门控**。v1~v4 的硬门是开环的「通过/拒绝」快照，未建模「安全边际在闭环中如何演化、时延与遮挡如何扰动它」。把九个归一化有符号边际 μ_i(t) 视为受控状态，引入闭环证书调节器 CLCG：规则降权/速度缩放/阻抗软化/回退姿态作为控制 u，时延/遮挡/模型误差作为扰动 w。用离散控制屏障函数（CBF）与 ISS-Lyapunov 证明安全集 A = {μ : min_i μ_i ≥ 0} 在 kc_loop 成立时是鲁棒受控不变的，输出闭环证书 LCC = (s_min, τ_margin, ρ_cert, V̇, t)。让「一次通过」升级为「全程保持在安全集内」。

3. **二者的耦合：相机是闭环的传感器，闭环是相机的稳定化保证**。腕部相机测边际，调节器保证边际不越界，证书回灌规则库形成「视觉-证书闭环」；缺了相机，闭环没有观测；缺了闭环，相机时延与遮挡会让「视觉通过」退化为陈旧证书（stale certificate）。

**关键洞见**：v4 七锚点回答「覆盖/物理/人因/末点/记忆/价值/平衡」；v5 追加视觉闭环锚回答「接近过程是否视觉可观测且收敛」（WCVK）与闭环稳定锚回答「所有证书边际在时延/遮挡扰动下是否受控不变」（CLCG）。九硬门 kc_evidence_forged_v5 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem ∧ kc_val ∧ kc_bal ∧ kc_vis ∧ kc_loop，fail-closed；软评分 ECS_v5 = ECS_v4 · η_vis · η_loop。

**形式化目标（增量）**：
1. 定义视觉闭环证书 VCC = (e_vis, σ_min, κ_occ, δ_calib, τ_lat, t) 与硬门 kc_vis = (e_vis ≤ ε_vis) ∧ (σ_min ≥ σ_min^0) ∧ (κ_occ ≤ κ_max) ∧ (δ_calib ≤ δ_max) ∧ (τ_lat ≤ τ_max)，软因子 η_vis = (1−e_vis/ε_vis)_+ · min(1, σ_min/σ_min^0) · (1−κ_occ) · (1−δ_calib/δ_max)_+ · (1−τ_lat/τ_max)_+。
2. 定义九锚点归一化有符号边际 μ_i(t)，安全集 A = {μ : min_i μ_i ≥ 0}，s_min = min_i μ_i。
3. 定义闭环证书调节器 CLCG 的线性化证书动力学 μ_{k+1} = A μ_k + B u_k + E w_k + c，u = sat(Kμ)，w = (τ_lat, κ_occ, δ_calib, ε_model)；离散 CBF h(μ) = min_i μ_i，受控不变条件 h_{k+1} ≥ (1−γ)h_k − L_w‖w_k‖。
4. 定义时延裕度 τ_margin = τ_max − τ_lat，τ_max = PM/ω_c（相位裕度/穿越频率）；收缩率 ρ_cert = ρ(A+BK)；ISS-Lyapunov V(μ)=½‖μ‖²，V̇ ≤ −αV + β‖w‖²。
5. 定义闭环证书 LCC = (s_min, τ_margin, ρ_cert, V̇, cbf_ok, iss_ok, t)，硬门 kc_loop = (s_min>0) ∧ (τ_margin>0) ∧ (ρ_cert<1) ∧ cbf_ok ∧ iss_ok，软因子 η_loop = min(1, s_min/h_ref) · min(1, τ_margin/τ_max) · (1−ρ_cert)_+。
6. 定义 EFA-v5 九硬门与软评分 ECS_v5 = ECS_v4 · η_vis · η_loop。
7. 定义 Exec_CADVS-v5 ⊆ Exec_CADVS-v4：在 v4 每条路径上再追加 kc_vis（视觉伺服阶段）与 kc_loop（全时段闭环），故只缩不涨。

**本轮最大风险**：**视觉闭环时延（腕部相机 30–60 Hz，端到端 30–100 ms）远大于 1 ms 控制周期，证书可能在安全边际已经崩塌之后仍报告「通过」（陈旧证书 / stale certificate），把视觉盲区变成新的安全违例来源。**

### IP-498 CDK：保守蒸馏（离线训练，在线 O(1) 前向）

```python
@dataclass
class ConservativeDistillationKernel:
    """CDK：把九门教师蒸馏为可进环学生；单向保守 + 共形假放行控制"""
    teacher: Any                       # v5 九门教师（MFGK/CFAC/BCK/CCK/VACK...）
    student: Any                       # 轻量 VLM / GNN / MLP 集成
    lam_fa: float = 10.0               # 假放行惩罚（远大于假拒）
    lam_fr: float = 1.0
    lam_kd: float = 1.0
    alpha_d: float = 0.05
    tau_s: np.ndarray = field(default_factory=lambda: np.full(9, 0.5))
    buffer: float = 0.1                # 在线裕度安全缓冲
    audit_set: list = field(default_factory=list)

    def train(self, data, calib):
        # 1) 教师软标签 + 硬证书
        soft_T, kT = self.teacher.batch_certify(data)
        # 2) 非对称损失：假放行远贵于假拒 -> 学生天然偏保守
        loss = self._asymmetric_loss(self.student(data), soft_T, kT)
        self._sgd(loss)
        # 3) 共形校准学生保守裕度：选 τ_s 使 F̂A ≤ α_d
        self.tau_s = self._conformal_false_accept(calib, self.student)
        # 4) 审计集上验证单向保守，失败则继续加严 τ_s
        while self._empirical_fa(self.audit_set) > self.alpha_d:
            self.tau_s += 0.05
        return self

    def certify(self, x, t_now: float) -> StudentCert:
        m = self.student.margins(x)
        kcS = bool(np.all(m - self.buffer >= self.tau_s))
        kT_cache = self.teacher.cached_gate(x)     # 规则/上下文粒度缓存
        return StudentCert(kc_S=kcS, margins=m, kc_T_cache=kT_cache, t=t_now)

    def kc_distill(self, sc: StudentCert, cache_age: float) -> bool:
        """引理 46：kc_S ∧ kc_distill ⟹ kc_T（缓存新鲜或保守缓冲足够时）"""
        if cache_age > self.teacher.T_max:
            return False                            # 缓存过期 -> fail-closed
        if not sc.kc_S:
            return True                             # 学生拒绝时无需教师背书
        return bool(sc.kc_T_cache) or self._margin_covers_staleness(sc, cache_age)

    def _asymmetric_loss(self, logits, soft_T, kT): ...
    def _conformal_false_accept(self, calib, student) -> np.ndarray: ...
    def _margin_covers_staleness(self, sc, age) -> bool: ...
```

### IP-499 CSRL：证书盾强化学习（离线训练，环外）

```python
@dataclass
class CertificateShieldedRLTrainer:
    """CSRL：九门为盾的约束 MDP；盾保证训练期安全，塑形保证最优策略不变"""
    shield: Any                        # v5 九门教师（kc_T）
    ecs: Any                           # ECS_v5 裕度
    gamma: float = 0.99
    cost_budget: float = 0.0           # 安全训练：零违例预算
    lagrangian: float = 0.0

    def act(self, s, policy):
        a, logp = policy(s)
        if not self.shield.kc_T(s, a):             # 盾：拒绝越界动作
            a = self.shield.project(s, a)          # 最近合法动作（CBF-QP 投影）
        return a, logp

    def shaped_reward(self, s, a, s2, r):
        return r + self.gamma * self.ecs.margin(s2) - self.ecs.margin(s)

    def train(self, env, policy, iters):
        for _ in range(iters):
            traj = self._rollout(env, policy, shielded=True)
            # 代价恒为 0（盾保证），Lagrange 乘子仅在近似盾下非零
            self.lagrangian = max(0.0, self.lagrangian
                                  + self.lr * (traj.cost_mean - self.cost_budget))
            # CPO / Lagrangian-PPO 更新；势函数塑形不改变最优策略
            policy = self._cpo_update(policy, traj, self.lagrangian)
        return policy

    def discover_rules(self, env, policy) -> list[Rule]:
        """在 S_k 内搜索高覆盖/高效率轨迹，抽象为候选规则交给 DAKI"""
        return self._abstract_rules(self._rollout(env, policy, shielded=True))

    def _rollout(self, env, policy, shielded): ...
    def _cpo_update(self, policy, traj, lag): ...
    def _abstract_rules(self, traj) -> list: ...
```

### IP-500 CERL：反例驱动的主动共形校准（异步，分钟级）

```python
@dataclass
class CounterexampleRecalibrationLoop:
    """CERL：把师生分歧/覆盖违例当反例，做加权共形 + ACI，主动对抗分布漂移"""
    buffer: list = field(default_factory=list)
    aci_gamma: float = 0.01
    alpha: float = 0.1

    def collect(self, rollouts, calib_density):
        for (x, kT, kS) in rollouts:
            if kS != kT or self._coverage_violation(x):
                w = self._importance_weight(x, calib_density)
                self.buffer.append((x, kT, kS, w))
        return self

    def recalibrate(self, cfac, cdk):
        # 1) 加权共形：用 w 修正反例采样带来的选择偏差
        cfac.calibrate(self._weighted_set(), weights=self._weights())
        # 2) ACI：在线校正 alpha，跟踪漂移
        self.alpha = self._aci_update(self.alpha)
        # 3) 学生重训/加严：分歧区域提高 tau_s
        cdk.tighten_on(self._disagreement_regions())
        return cfac, cdk

    def _coverage_violation(self, x) -> bool: ...
    def _importance_weight(self, x, density) -> float: ...
    def _weighted_set(self) -> list: ...
    def _weights(self) -> list: ...
    def _aci_update(self, alpha) -> float: ...
    def _disagreement_regions(self) -> list: ...
```

### IP-501 CEDF：契约—扩张不动点（离线理论 + 调度器）

```python
def contract_expand_fixed_point(S, R, D, E, eps=1e-6, max_iter=100):
    """
    S_{k+1} = D(S_k)             # 蒸馏/新硬门：安全包络收缩
    R_{k+1} = E(R_k, S_{k+1})    # RL：仅在 S_{k+1} 内扩张可达集
    不变量：R_k ⊆ S_k
    """
    for k in range(max_iter):
        S_next = D(S)
        R_next = E(R, S_next)
        assert R_next <= S_next                 # 运行时断言不变量
        if S_next == S and R_next == R:
            return R_next, S_next               # 最大不动点
        S, R = S_next, R_next
    return R, S

# 定理 10（契约—扩张）：D 单调（x∈D(S) ⇒ x∈S）且 E 约束（E(R,S)⊆S），
# 则 S_k 单调不增、R_k 单调不减，且 R_k⊆S_k 对所有 k 成立；
# 有界有限格上交替序列收敛到最大不动点 (R*,S*)。
```

### IP-502 EFA-v6：九门 + 蒸馏门 + 软评分

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：九门 + kc_distill；ECS_v6 = ECS_v5 · η_distill"""
    scf: SpatialCoverageFieldKernel
    msrg_cache: dict
    hic: HumanIntentCertificateKernel
    eek: EndEffectorFidelityKernel
    ltem: LongTermEpisodicMemory
    vack: ValueAlignmentCertificateKernel
    bck: BalanceControlKernel
    cfac: ConformalForceAffordanceCalibrator
    cck: ContactConsistencyKernel
    cdk: ConservativeDistillationKernel
    mu_S: float = 0.75
    w: tuple = (0.4, 0.4, 0.2)

    def hard_gate(self, x, t_now, rule_id, hic, sc: StudentCert,
                  object_class, geo_sig, theta_domain_fp, traj, context,
                  cache_age: float) -> tuple[bool, str]:
        if self.hic.veto_active(hic):              return False, 'HIC_STOP'
        # 控制环热路径：学生替代教师（BCK/CCK/VACK 教师仅异步审计）
        if not sc.kc_S:                            return False, 'STUDENT_REJECT'
        if not self.cdk.kc_distill(sc, cache_age): return False, 'DISTILL_UNPROVEN'
        if not self.scf.kc_coverage(x, t_now):     return False, 'COVERAGE_BLIND'
        s2rc = self.msrg_cache.get(rule_id)
        if s2rc is None or s2rc.verdict != 'accept' or s2rc.mu_pass < self.mu_S:
            return False, 'PHYSICS_UNPROVEN'
        pass_mem, eta_mem, novelty = self.ltem.query(object_class, geo_sig, theta_domain_fp, rule_id)
        if not pass_mem:                           return False, 'MEMORY_REJECT'
        return True, 'FORGED' + ('|NOVELTY' if novelty else '')

    def ecs_v6(self, x, t_now, rule_id, A_att=0.0, eta_mem=0.5,
               eta_val=0.5, eta_bal=0.5, eta_ground=0.5,
               eta_contact=0.5, eta_distill=0.5) -> float:
        base = (self.scf.gamma3d(x, t_now)**self.w[0]
                * getattr(self.msrg_cache.get(rule_id), 'mu_pass', 0.0)**self.w[1]
                * (1 + self.w[2]*A_att))
        return (base * eta_mem * eta_val * eta_bal
                * eta_ground * eta_contact * eta_distill)
```

## 3. 三时标集成流水线（v5 → v6）

```
离线慢时标 A（教师训练 + 蒸馏，GPU 小时级）：
  教师九门（MFGK/CFAC/BCK/CCK/VACK）在演示 + 仿真 + RL 轨迹上产出 κ_T
    ──▶ CDK.train：非对称损失 + 共形假放行校准 + 审计集加严 → 学生 f_S, τ_s
    ──▶ 冻结学生版本 v_s，发布到控制环（携带 teacher T_max / Δ_stale 曲线）

离线慢时标 B（证书盾 RL，仿真中，小时级）：
  约束 MDP：r=任务奖励，c=1−kc_T，盾 Safe(s)
    ──▶ CSRL：CPO/Lagrangian-PPO + ECS 势函数塑形
    ──▶ 候选规则（DAKI）→ 仍须过 v5 九门 → 入 KC 库
    ──▶ 轨迹中 κ_S≠κ_T / 覆盖违例 → B_ce
    ──▶ CERL：加权共形 + ACI → 更新 CFAC.alpha/λ̂ 与学生 τ_s
    ──▶ 回到 A（学生重训），形成「蒸馏—扩张—反例」闭环

在线快时标（1 kHz，热路径只用学生）：
  每周期：
    sc = CDK.certify(x, t)                     # 学生九门裕度，< 0.3 ms
    F_safe = FSF.filter(F_des, F_meas, E_t)    # 复用 v5 力安全滤波
    EFA-v6.hard_gate(..., sc, cache_age=t−t_teacher)
      ├─ HIC_STOP            → S_stop
      ├─ STUDENT_REJECT      → 收紧至 E_core / 教师异步复核
      ├─ DISTILL_UNPROVEN    → fail-closed：回退教师（降频）或停机
      ├─ COVERAGE_BLIND      → 回退 STCK + 教师
      ├─ PHYSICS_UNPROVEN   → 规则降权
      ├─ MEMORY_REJECT       → 教师介入或重新 MSRG
      └─ FORGED              → 执行
  异步审计（10–100 Hz）：抽样重算教师 κ_T，估计 F̂A；超 α_d 则热更新 τ_s 或回退教师
```

## 5. 正确性论证（增量更新）

### 引理 46（保守蒸馏的单向误差界）

**陈述**：设学生在校准/审计集上满足经验假放行 F̂A ≤ α_d，且部署与校准可交换。则 `kc_S ⟹ kc_T` 的违背概率 ≤ α_d；进而 Exec_S ⊆ Exec_T 以概率 ≥ 1−α_d 成立。教师缓存陈旧时，额外违背 ≤ O(Δ_stale·L_T)，其中 L_T 为教师证书对上下文的 Lipschitz 常数。

**证明**：假放行事件正是 `kc_S=1 ∧ kc_T=0`，由共形/CRC 在可交换性下的经验风险上界得 E[FA] ≤ α_d。学生裕度经 Δ_stale 缓冲后，仅当真实证书在缓存窗口内漂移超过缓冲才额外违背，漂移量由 L_T·Δ_stale 界定。∎

**工程含义**：把「学生便宜」与「教师可信」用一个可测的单向契约连接；学生越差，校准只会把 τ_s 抬高（更保守），不会放宽安全集。

### 引理 47（证书盾的训练期不变性）

**陈述**：若 CSRL 每次实际执行的动作 a 满足 kc_T(s,a)=1（盾投影保证），则训练期任意 rollout 的安全代价 c=0，安全违例数为 0，与策略质量无关。策略改进仅在 Π_shield 内发生，故 Exec_RL ⊆ S_k。

**证明**：盾在动作进入环境前做 `a ← project(a)`，投影目标集即 Safe(s)；由构造 c(s,a)=0。RL 更新只改变 Safe(s) 上的动作分布，不改变其外延。∎

**工程含义**：RL 的探索风险被结构性消除——这正是「先认证、后优化」；代价是盾可能过保守，导致探索受限（R64）。

### 引理 48（证书势函数塑形的最优策略不变性）

**陈述**：令 r' = r + γΦ(s') − Φ(s)，Φ(s)=ECS_v5(s) 有界。则对任意 MDP，argmax_π E[Σγ^t r'] = argmax_π E[Σγ^t r]。即用证书裕度做塑形只加速学习，不改变最优策略，也不改变约束最优解（在约束 MDP 中塑形项可按同法吸收进势函数）。

**证明**：Ng, Harada, Russell (1999) 势函数定理：势函数塑形不改变任意状态-动作的最优 Q 排序；约束情形下把 Φ 同时加入代价或保持代价不变时，Lagrange 函数仅相差一个望远镜求和项，最优策略集不变。∎

**工程含义**：ECS 裕度是「可测量的代理」，直接当奖励会诱发 R62 的刷分；作为势函数则只提供方差缩减，不改变优化目标，是更安全的用法。

### 引理 49（反例采样的选择偏差修正）

**陈述**：设反例由策略 π_ce 主动采样，部署分布为 p_deploy，校准分布为 p_calib。用重要性权重 w(x)=p_deploy(x)/p_calib(x)（截断到 [w_min,w_max]）做加权共形，则在校准—部署可交换性被反例选择破坏时，覆盖 gap 由未覆盖漂移质量 δ_unc 与权重截断偏差 O(κ_w) 界定：|P(E_λ ⊆ E*) − (1−α)| ≤ δ_unc + O(κ_w) + O(1/√n)。

**证明**：加权共形等价于在重加权分布上的可交换校准；选择偏差被 w 校正，剩余项来自权重截断与有限样本。δ_unc 为反例缓冲未覆盖的漂移方向概率质量。∎（sketch）

**工程含义**：主动反例把 R53/R54 的「被动失效」转为「可控的覆盖补盲」，但反例选择本身会改变校准分布，必须显式重加权，否则共形保证反而被自己的采样器破坏。

### 定理 7（契约—扩张不动点与单调性）

**陈述**：设 D 为收缩算子（x∈D(S) ⇒ x∈S），E 为约束扩张算子（E(R,S)⊆S），且 D、E 单调。令 S_{k+1}=D(S_k)，R_{k+1}=E(R_k,S_{k+1})，R_0⊆S_0。则：
(i) S_{k+1} ⊆ S_k（安全包络单调收缩）；
(ii) R_k ⊆ S_k 对所有 k 成立（可达能力始终被认证）；
(iii) R_{k+1} ⊇ R_k（能力单调扩张，若 E 找到新规则）；
(iv) 在有限有界格上序列收敛到最大不动点 (R*,S*)，且 R* ⊆ S*。
进一步，若 D 新增非恒真硬门，则 S 严格收缩；若 E 找到过九门且增覆盖的规则，则 R 严格扩张。

**证明**：(i)(ii) 对 k 归纳：S_{k+1}=D(S_k)⊆S_k；R_{k+1}=E(R_k,S_{k+1})⊆S_{k+1}⊆S_k，且 R_k⊆S_k。(iii) E 为扩张算子，在新增规则通过九门时严格增。(iv) 单调有界序列在有限格上稳定；稳定性即不动点，由单调性其为此交替的最大不动点。严格性由「非恒真」「增覆盖」构造反例。∎

**工程含义**：这是对 v1~v5「执行集只缩不涨」的**精确修正**——收缩的是安全包络，扩张的是可达能力；二者不矛盾，由不变量 R_k⊆S_k 统一。CADVS 从「不断加锁」升级为「在锁内不断开新门」。

### 定理 8（v6 综合保证）

**陈述**：在 (B1)~(B8)（继承 v5）及 (B9) 学生—教师可交换、(B10) 盾投影可行、(B11) 反例权重有界 下：
(i) Exec_CADVS-v6 ⊆ Exec_CADVS-v5（严格，若 kc_distill 非恒真）；
(ii) 学生假放行风险由引理 46 界；
(iii) 训练期安全违例为 0（引理 47）；
(iv) 证书塑形不改变最优策略（引理 48）；
(v) 主动反例下覆盖 gap 由引理 49 界；
(vi) 契约—扩张序列收敛且 R*⊆S*（定理 7）。

**证明**：(i) Exec_v6 = Exec_v5 ∩ {kc_S} ∩ {kc_distill}；由引理 46，kc_S∧kc_distill ⟹ kc_T，而 kc_T 已是 v5 条件，故只缩不涨；非恒真由「学生误放行」反例保证严格。(ii)~(vi) 分由引理 46–49、定理 7。∎

**诚实声明**：(B9) 学生—教师可交换是命门——学生若在分布外「自信地保守」反而会大量假拒（能力塌缩），若「自信地放行」则穿透共形界；(B10) 极端接触下盾投影可能不可行，只能停机；(B11) 反例重要性权重在重尾漂移下方差爆炸。缓解：学生集成 + 温度标定 + 审计集滚动更新；盾不可行回退 E_core；权重截断与分层共形。这些只降低、不消除风险。

## 8. 本轮最大风险（最终确认）

**一句话**：**RL 会优化「可测量的证书」而非「真实安全」**——一旦学生证书与 ECS 裕度成为训练信号，策略可能学会在教师—学生分歧区刷分（证书洗白），蒸馏反而把这条分歧通道制度化；在分布漂移下，系统会越优化越像「被认证的不安全」，而盾只会忠实地守住一个被代理指标悄悄挪动的边界。
