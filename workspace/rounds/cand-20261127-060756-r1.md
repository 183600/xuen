### 第 1 轮灵感驱动研究记录

**灵感词**：结构优化、具身智能大模型

**直觉与动机**：
现有 v25（SRC-USC）已把「物理结构-力控-轻量化」与「语义-重构-协同」证书化，但仍把「智能」当作一个外部给定、不可审计的黑箱策略：具身大模型（VLA/世界模型）只被当作产生 π 的预言机，模型本身的「结构」——参数拓扑、计算图、显存/能耗/散热足迹——从未进入证书链。受「结构优化」启发：拓扑优化不仅能优化机械本体，也能优化大模型的计算拓扑（结构化稀疏、专家路由、层宽分配），二者共享同一套「设计场-目标-约束-灵敏度-最优性条件」形式化。受「具身智能大模型」启发：模型是物理闭环中的耗能、发热、会犯错的部件，其接地（grounding）、世界模型误差、推理能耗必须被证书约束，而不能被假设正确。核心洞见：**结构优化是「证书编译器」：它把物理拓扑 ρ_p 与计算拓扑 ρ_c 编译成一组可机械复核的共享预算约束；具身大模型是「证书消费者」：它的每一次规划都在消耗由结构优化预分配的刚度/能量/热/时延预算。** 由此，「轻量化」不再只是减重，而是「把省下的质量预算换成推理预算，同时不击穿热与力容量约束」的跨域预算再分配问题。

**形式化目标**：
1. 定义具身基础模型接地证书（EFG）：指称接地 conformal 覆盖 ℙ(Γ(tok)∈C(x))≥1-α_g；动作投影残差 ‖a−Π_Exec(a)‖≤ε_act；策略 Lipschitz 界 ‖π(o₁)−π(o₂)‖≤L_π‖o₁−o₂‖；校准弃权（OOD 误接受率≤α_g）。
2. 定义预测世界模型证书（WMC）：一步预测误差 ≤ε_wm（conformal）；H 步 rollout 收缩界 ε_wm(1−λ^H)/(1−λ)；物理守恒残差 ≤ε_phys；不确定性校准覆盖 ≥1−α_wm。
3. 定义结构-计算协同设计证书（SCDC）：联合设计场 (ρ_p,ρ_c) 满足质量/能量/热/应力/刚度-力容量/时延六类耦合约束；联合 KKT 残差 ≤r_kkt；协同设计间隙 J_joint ≤ J_seq(1+δ_cd)。
4. 构建具身-结构统一准入门（ESUC v26）：SRC-USC ∪ EFG ∪ WMC ∪ SCDC 十证一体，Exec_v26 = Exec_v25 ∩ Fil_ground ∩ Fil_wm ∩ Fil_codesign ⊆ Exec_v25。
5. 证明十证单调退化链在接地幻觉/世界模型漂移/协同设计失配下的保持性，并显式处理「多边际 conformal 证书复合」的联合覆盖问题（Bonferroni / 联合 conformal）。

# ============================================================
# IP-448 Embodied Foundation Model Grounding Certificate (EFG)
# ============================================================
@dataclass
class EmbodiedFoundationModelGroundingCertificate:
    """指称接地 + 动作投影 + Lipschitz 安全 + 校准弃权"""
    policy: 'VLA_Policy'
    smc: 'SemanticMappingCertificate'
    alpha_g: float = 0.05          # 接地风险水平
    eps_act: float = 1e-2          # 动作投影残差 (归一化单位)
    L_pi: float = 2.0              # 离线随机平滑得到的 Lipschitz 上界
    max_ood_accept: float = 0.05   # OOD 误接受率上限

    def verify_referential_grounding(self, instruction: str,
                                     plan: 'Plan', obs: Tensor) -> bool:
        """∀ 指称 token：接地实体存在且落入 conformal 预测集"""
        for tok in plan.referent_tokens():
            ent = self.ground(tok, obs)          # Γ(tok)
            if ent is None:
                return False                     # 无法接地 → 拒证（不得猜）
            if not self.smc.covers(ent, obs):    # ℙ(Γ(tok)∈C(x)) ≥ 1-α_g
                return False
        return True

    def verify_action_projection(self, actions: Tensor) -> bool:
        """a_t 必须落在 v25 证书可行集内：‖a - Π_Exec(a)‖ ≤ ε_act"""
        for a in actions:
            a_proj = project_to_exec_v25(a)      # 凸 QP 投影
            if torch.norm(a - a_proj).item() > self.eps_act:
                return False                     # 接地间隙超限 → 拒证
        return True

    def verify_lipschitz(self, obs_batch: Tensor, eps_ball: float) -> bool:
        """‖π(o1)-π(o2)‖ ≤ L_π‖o1-o2‖（离线证书，在线仅查表）"""
        for o in obs_batch:
            for o2 in sample_ball(o, eps_ball, n=64):
                lhs = torch.norm(self.policy(o) - self.policy(o2)).item()
                rhs = self.L_pi * torch.norm(o - o2).item()
                if lhs > rhs + 1e-9:
                    return False
        return True

    def verify_abstention(self, ood_scores: Tensor, labels: Tensor) -> bool:
        """校准弃权：模型对 OOD 样本的误接受率 ≤ max_ood_accept"""
        accept = ood_scores < self.policy.ood_threshold
        false_accept = (accept & (labels < 0)).float().mean().item()
        return false_accept <= self.max_ood_accept

    def verify_all(self, instruction, plan, obs,
                   obs_batch=None, ood_scores=None, labels=None) -> bool:
        ok = self.verify_referential_grounding(instruction, plan, obs)
        ok = ok and self.verify_action_projection(plan.actions)
        if obs_batch is not None:
            ok = ok and self.verify_lipschitz(obs_batch, eps_ball=0.01)
        if ood_scores is not None:
            ok = ok and self.verify_abstention(ood_scores, labels)
        return ok

# IP-449 Predictive World Model Certificate (WMC)
# ============================================================
@dataclass
class PredictiveWorldModelCertificate:
    """一步误差 + 收缩 rollout + 物理守恒 + 不确定性校准"""
    f_theta: 'WorldModel'
    eps_wm: float = 0.02
    lam_wm: float = 0.95
    eps_phys: float = 1e-2
    horizon: int = 10
    alpha_wm: float = 0.05

    def verify_one_step(self, dataset) -> bool:
        for x, u, x_next in dataset:
            if torch.norm(self.f_theta(x, u) - x_next).item() > self.eps_wm:
                return False
        return True

    def verify_rollout_stability(self, x0: Tensor, actions: Tensor,
                                 gt_rollout: Tensor) -> bool:
        """收缩证书：H 步误差 ≤ ε_wm(1-λ^H)/(1-λ)"""
        x = x0
        for t in range(self.horizon):
            x = self.f_theta(x, actions[t])
        bound = self.eps_wm * (1 - self.lam_wm ** self.horizon) / (1 - self.lam_wm)
        return torch.norm(x - gt_rollout[-1]).item() <= bound + 1e-9

    def verify_physical_consistency(self, x: Tensor, u: Tensor,
                                    x_next: Tensor) -> bool:
        """能量/动量守恒残差 ≤ ε_phys（与 EVC 的 E_max 直接对接）"""
        d_energy = abs(self.energy(x_next) - self.energy(x) - self.work(u))
        return d_energy <= self.eps_phys

    def verify_calibration(self, dataset) -> bool:
        """预测不确定性 σ 的经验覆盖 ≥ 1-α_wm"""
        errs, sigmas = [], []
        for x, u, x_next in dataset:
            mu, sigma = self.f_theta.predict(x, u)
            errs.append(torch.norm(mu - x_next).item())
            sigmas.append(sigma.item())
        # 标准化残差的分位数检验
        z = torch.tensor([e / max(s, 1e-6) for e, s in zip(errs, sigmas)])
        q = torch.quantile(z, 1 - self.alpha_wm)
        return q <= 1.0 + 1e-3

    def verify_all(self, dataset, x0=None, actions=None, gt_rollout=None) -> bool:
        ok = self.verify_one_step(dataset) and self.verify_calibration(dataset)
        if x0 is not None:
            ok = ok and self.verify_rollout_stability(x0, actions, gt_rollout)
        return ok

# IP-450 Structural-Computational Co-Design Certificate (SCDC)
# ============================================================
@dataclass
class StructuralComputationalCoDesignCertificate:
    """物理拓扑 ρ_p 与计算拓扑 ρ_c 的共享预算耦合证书（设计期）"""
    rho_p: Tensor                      # [N_elem] 物理密度场
    rho_c: Tensor                      # [N_comp] 计算密度/门控场
    mass_max: float = 12.0             # kg
    energy_budget: float = 5.0e5       # J/任务
    T_max: float = 358.15              # 85°C
    T_amb: float = 298.15              # 25°C
    f_inf: float = 20.0                # Hz
    F_req: float = 80.0                # N
    sigma_y: float = 2.5e8             # Pa
    gamma_s: float = 1.5
    delta_cd: float = 0.05
    r_kkt: float = 1e-3

    def verify_mass(self) -> bool:
        return self.total_mass(self.rho_p, self.rho_c) <= self.mass_max

    def verify_energy(self) -> bool:
        e = (self.E_loco(self.rho_p) + self.E_inference(self.rho_c)
             + self.E_cooling(self.rho_p))
        return e <= self.energy_budget

    def verify_thermal(self) -> bool:
        """关键耦合：轻量化↑ → 热阻 R_th(ρ_p)↑ → 结温↑ → 推理频率被迫降"""
        P = self.E_inference(self.rho_c) * self.f_inf      # W
        T = self.T_amb + P * self.R_th(self.rho_p)
        return T <= self.T_max

    def verify_stiffness_capacity(self) -> bool:
        """刚度-力容量耦合：拓扑减重不得击穿接触任务峰值力"""
        C_hom = self.homogenize(self.rho_p)
        F_max = min(self.actuator_limit,
                    self.sigma_y * self.A_eff(self.rho_p) / self.gamma_s)
        return (F_max >= self.F_req) and self.psd(C_hom)

    def verify_stress(self) -> bool:
        sigma = self.von_mises(self.rho_p)
        return sigma.max().item() <= self.sigma_y / self.gamma_s

    def verify_latency(self) -> bool:
        return self.inference_latency(self.rho_c) <= 1.0 / self.f_inf

    def verify_kkt(self) -> bool:
        """联合 Lagrangian 驻点残差（非凸 ⇒ 仅局部必要条件）"""
        return self.kkt_residual(self.rho_p, self.rho_c) <= self.r_kkt

    def verify_codesign_gap(self) -> bool:
        """联合设计不劣于顺序设计超过 δ_cd（量化跨域耦合收益）"""
        return self.J_joint(self.rho_p, self.rho_c) <= \
               self.J_seq() * (1.0 + self.delta_cd)

    def verify_all(self) -> bool:
        return (self.verify_mass() and self.verify_energy()
                and self.verify_thermal() and self.verify_stiffness_capacity()
                and self.verify_stress() and self.verify_latency()
                and self.verify_kkt() and self.verify_codesign_gap())

# IP-451 ESUC — 具身-结构统一准入门 v26（十证一体）
# ============================================================
@dataclass
class EmbodiedStructuralUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'   # v25 七证
    efg: EmbodiedFoundationModelGroundingCertificate
    wmc: PredictiveWorldModelCertificate
    scdc: StructuralComputationalCoDesignCertificate
    alpha_total: float = 0.05
    n_cert: int = 10

    def per_cert_alpha(self) -> float:
        """Bonferroni：10 个边际 conformal 证书 ⇒ 联合覆盖 ≥ 1-α_total。
        注意：边际覆盖简单相乘并不成立，必须用并集界或联合 conformal。"""
        return self.alpha_total / self.n_cert

    def admits(self, plan: 'Plan', sensor_data: dict) -> bool:
        # 0. 设计期证书先行：SCDC 失败则整机/整模型不得进入运行时
        if not self.scdc.verify_all():
            return False
        # 1. v25 七证（结构-语义-重构-协同）
        if not self.src_usc.admits(plan, sensor_data):
            return False
        # 2. 接地证书：语言计划 → 物理可执行
        if not self.efg.verify_all(
            plan.instruction, plan, sensor_data['obs'],
            obs_batch=sensor_data.get('obs_batch'),
            ood_scores=sensor_data.get('ood_scores'),
            labels=sensor_data.get('ood_labels')
        ):
            return False
        # 3. 世界模型证书：规划所用模型可信
        if not self.wmc.verify_all(
            sensor_data['wm_val'],
            x0=sensor_data.get('x0'),
            actions=plan.actions,
            gt_rollout=sensor_data.get('gt_rollout')
        ):
            return False
        return True

# 端到端流水线增量：v25 之后追加设计期 SCDC + 运行时 EFG/WMC
# ============================================================
class EmbodiedStructuralPipeline:
    def __init__(self, config: dict):
        self.esuc = EmbodiedStructuralUnifiedCertificate(
            src_usc=config['src_usc'],
            efg=EmbodiedFoundationModelGroundingCertificate(
                policy=config['policy'], smc=config['src_usc'].smc,
                alpha_g=config['alpha_total'] / 10,
                eps_act=config['eps_act'], L_pi=config['L_pi']
            ),
            wmc=PredictiveWorldModelCertificate(
                f_theta=config['world_model'],
                eps_wm=config['eps_wm'], lam_wm=config['lam_wm'],
                horizon=config['horizon']
            ),
            scdc=config['scdc'],
            alpha_total=config['alpha_total']
        )
        self.ipam.register_module("efg", ["IP-448"],
            ["referential_grounding", "action_projection", "lipschitz_certificate", "calibrated_abstention"])
        self.ipam.register_module("wmc", ["IP-449"],
            ["one_step_bound", "contraction_rollout", "physical_consistency", "uncertainty_calibration"])
        self.ipam.register_module("scdc", ["IP-450"],
            ["joint_mass_energy_thermal", "stiffness_force_capacity", "kkt_stationarity", "codesign_gap"])
        self.ipam.register_module("esuc", ["IP-451"],
            ["decuple_certificate_gate", "joint_conformal_coverage", "embodied_structural_monotonic_chain"])

    def step(self, plan: 'Plan', sensor_data: dict) -> tuple[bool, dict]:
        admitted = self.esuc.admits(plan, sensor_data)
        return admitted, {
            'grounding': {
                'referential_ok': self.esuc.efg.verify_referential_grounding(
                    plan.instruction, plan, sensor_data['obs']),
                'projection_ok': self.esuc.efg.verify_action_projection(plan.actions),
            },
            'world_model': {
                'one_step_ok': self.esuc.wmc.verify_one_step(sensor_data['wm_val']),
                'calibration_ok': self.esuc.wmc.verify_calibration(sensor_data['wm_val']),
            },
            'codesign': {
                'mass_ok': self.esuc.scdc.verify_mass(),
                'energy_ok': self.esuc.scdc.verify_energy(),
                'thermal_ok': self.esuc.scdc.verify_thermal(),
                'force_capacity_ok': self.esuc.scdc.verify_stiffness_capacity(),
            },
        }

## 2. 复杂度分析（增量）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |

**实时性保证**：SCDC 是**设计期**证书（拓扑优化 + FE + 热仿真，秒~分钟级），不进运行时关键路径；运行时只做 O(1) 的标量约束复核。EFG 接地在感知频率（10–30Hz），动作投影在规划频率（5–10Hz），WMC 在规划层（1–5Hz）。相比 v25，运行时增量约 +3~6ms（N=5, T=32），仍满足 50Hz 控制环与 20ms 多机协调环。

## 3. 正确性论证（增量）

### 引理 13（接地证书的指称-投影-Lipschitz-弃权四重保证）
**陈述**：`EFG.verify_all(...) = True` ⟺ 语言计划满足：
(1) 指称接地覆盖 ℙ(Γ(tok)∈C(x)) ≥ 1−α_g；
(2) 动作投影残差 ‖a−Π_Exec(a)‖ ≤ ε_act；
(3) 策略 Lipschitz 界 ‖π(o₁)−π(o₂)‖ ≤ L_π‖o₁−o₂‖；
(4) 校准弃权误接受率 ≤ α_g。

**证明**：
1. `verify_referential_grounding` 复用 SMC 的 conformal 校准器；由 conformal prediction 的边际覆盖定理，对可交换观测有 ℙ(Γ(tok)∈C(x)) ≥ 1−α_g。无法接地时直接返回 False，等价于「宁可弃权不可臆测」。
2. `verify_action_projection` 把大模型输出投影到 v25 已验证的凸可行集；残差是「语言意图」与「物理可执行」之间的显式接地间隙。ε_act 由低级跟踪误差反推。
3. `verify_lipschitz` 用随机平滑/区间传播给出 L_π 的离线证书；在线仅查表，保证观测小扰动不会引发动作跳变（这是 VLA 幻觉进入物理层的主要通道）。
4. `verify_abstention` 用 OOD 分数阈值 + 校准集统计误接受率，保证模型在分布外选择弃权而非乱给动作。
四条分别对应语义正确性、物理可行性、局部稳定性、分布外鲁棒性，缺一不可。
∎

### 引理 14（世界模型误差的收缩传播与能量预算兼容）
**陈述**：若 `WMC.verify_all(...) = True`，则对任意初始状态与 H 步计划：
(1) H 步 rollout 误差 ≤ ε_wm(1−λ_wm^H)/(1−λ_wm)；
(2) 规划轨迹上的能量漂移 ≤ H·ε_phys，不突破 EVC 的 E_max；
(3) 模型不确定性经验覆盖 ≥ 1−α_wm。

**证明**：
1. 由一步误差界 ε_wm 与收缩因子 λ_wm<1 的递推 e_{t+1} ≤ λ_wm e_t + ε_wm，展开得几何级数上界。
2. 每步能量守恒残差 ≤ ε_phys，H 步累积 ≤ H·ε_phys；只要 H·ε_phys ≤ E_max 的在线余量（由 SCDC/EVC 预分配），规划不会击穿能量证书。
3. `verify_calibration` 对标准化残差 z=e/σ 做 1−α_wm 分位数检验，q≤1 即表示 σ 的覆盖达到名义水平。
注意：λ_wm<1 是**假设**，接触/碰撞等混合动力学可能不满足，故必须在线监控并在失效时退化（见引理 17）。
∎

### 引理 15（结构-计算协同设计的可行性与局部最优性间隙）
**陈述**：若 `SCDC.verify_all() = True`，则联合设计 (ρ_p,ρ_c)：
(1) 同时满足质量、能量、热、应力、刚度-力容量、时延六类耦合约束；
(2) 联合 KKT 残差 ≤ r_kkt，即 (ρ_p,ρ_c) 是联合 Lagrangian 的 r_kkt-近似驻点；
(3) J_joint ≤ J_seq(1+δ_cd)，即跨域协同不劣于顺序设计超过 δ_cd。

**证明**：
1. 六个 `verify_*` 分别对应六个约束的可行性判定，全部为 True 即约束可行。
2. 对非凸问题，KKT 条件仅为局部最优的必要条件；‖∇L‖≤r_kkt 表示该点附近不存在一阶可行下降方向，故为局部 Pareto 候选点（非全局保证）。
3. 顺序设计先优化 ρ_p 再优化 ρ_c（或反之），联合设计在更大的乘积空间上优化，故 J_joint ≤ J_seq 在精确求解时成立；δ_cd 吸收非凸与数值误差。
4. 关键非平凡处：热约束把 ρ_p（热阻）与 ρ_c（推理功耗）真正耦合，因此顺序设计会系统性低估「轻量化→热阻↑→推理降频」的代价，联合设计的收益正来自显式建模该耦合。
∎

### 引理 16（多边际 conformal 证书的联合覆盖）
**陈述**：设 k=10 个证书各自的 conformal 风险水平取 α_i=α_total/k，则十证同时成立的联合覆盖 ≥ 1−α_total。

**证明**：令 E_i 为第 i 个证书失效事件，ℙ(E_i)≤α_i。由并集界 ℙ(∪E_i) ≤ Σℙ(E_i) ≤ k·(α_total/k)=α_total，故 ℙ(十证全成立) ≥ 1−α_total。
**注意**：若各证书取同一 α 而不做 Bonferroni/联合校准，则联合覆盖只能保证 ≥1−kα，而非 1−α。这是 v25 未显式处理、v26 必须修正的统计漏洞。更紧的做法是用 e-value/联合 conformal 或对依赖结构建模，Bonferroni 只是最保守的可部署基线。
∎

### 引理 17（十位一体单调退化链）
**陈述**：任意单点/组合失效下，`Exec_v26 ⊆ Exec_v25 ⊆ ... ⊆ Exec_v18` 恒成立。

**证明**：ESUC 的 `admits` 是 v25 七证与新三证的合取，故 Exec_v26 是 Exec_v25 的子集。三条新增退化路径：
- 接地幻觉/指称漂移 → `EFG=false` → ESUC 拒证 → 退回 v25，切换到脚本化/遥操作策略（保留结构-语义-重构-协同，仅失去大模型任务级自主）。
- 世界模型漂移/收缩假设失效（接触/碰撞）→ `WMC=false` → ESUC 拒证 → 退回 v25 的无模型反应式控制（保留 SMC 几何与力控证书）。
- 协同设计失配（热/力容量/KKT 超限）→ `SCDC=false` → ESUC 拒证 → 冻结到保守设计点（静态结构 + 量化模型 + 降频），仍满足 v25。
- 组合失效取交集，单调性由集合交的传递性保持。
∎

### 定理（ESUC 十证准入门的安全性-合规性-可部署性-可保护性-结构-语义-重构-协同-接地-世界模型完备性）
**陈述**：对任意计划 Π（含语言指令、动作块、所用世界模型与设计点），`ESUC.admits(Π)=True` ⟺ Π 同时满足：
(1)–(10) v25 的十项（物理接地、云边一致、少样本 conformal、专利保护、结构、力控、轻量化、语义、重构、协同），
(11) 大模型指称接地与动作投影可行，
(12) 策略 Lipschitz 稳定与 OOD 校准弃权，
(13) 世界模型一步/rollout/守恒/校准可信，
(14) 物理-计算协同设计六约束可行且局部 Pareto 近似。
**证明**：由 `ESUC.admits` 的合取结构与引理 1–17 直接可得；必要性来自任一子证书失败即拒证，充分性由引理 16 的联合覆盖与引理 17 的单调链保证。∎

## 6. 本轮最大风险（最终确认）

**一句话**：**「多个边际 conformal 证书各自通过」并不等于「联合安全」——Bonferroni 虽能给出 1−α_total 的并集界，却会把每个 α_i 压到极小而使 Exec_v26 趋于空集；更危险的是，SCDC 的热-结构耦合与 WMC 的收缩假设都只在仿真/标定分布内成立，一旦真实热漂移或接触冲击让 λ_wm<1 失效，十个证书可能在群体级「逐项合规」的假象下同时越过安全边界，使 v26 的十证门在物理-语义-计算三重耦合失效已蔓延后仍错误放行。**
