# 第 64 轮（承接第 63 轮「LIRO 几何-技能-干扰联合闭环」IP-193~203；灵感循环 III 第 1 轮；本轮灵感：「常识推理」×「视觉伺服」）

> 第 63 轮 LIRO 把「几何—技能—干扰」三层物理安全做成了可认证闭环，但它对世界的「理解」仍然只有两种成分：**稠密几何**（点云法向/曲率）与**手写符号谓词**（`pre/eff`）。对「控制」也只有一种成分：**阻抗编译 + 力反馈**。这暴露出三个新的根基性短板：
> 1. **常识缺位**：`pre_grasp`、`pre_insert` 是闭世界硬规则，没有默认推理、没有例外、没有「未知」。系统无法推断「这个杯子易碎所以别捏」「刀沿危险」「高而窄的瓶子横向推会倒」「杯里有水所以要保持竖直」「这是把手所以该抓这里」「在别人家里翻抽屉不礼貌」。这些不是几何能算出来的，而是**关于物体属性、可供性、因果与规范的默认知识**。
> 2. **细操作缺内环**：LIRO 的实时流是「OLP-Geo 前向 → WCV-Geo 编译 → 阻抗派发」，最后几毫米的对准（插孔、穿线、倒水、拧盖、贴边）依赖开环阻抗与接触后力纠偏。**没有显式的图像/特征空间闭环**，视觉只在 USR 里做一次性语义编码，浪费了相机 30–60Hz 的高频误差信号。
> 3. **先验不可证伪**：第 63 轮最大风险是「E_geo 幻觉几何注入确定性错误」。其根源不是几何不准，而是**没有一个独立于先验的高频物理现实检验器**：几何、常识、技能规划共享同一套先验，错了就一起错，证书照样签发。
>
> 本轮核心主张：**把常识推理降格为「可击败的慢先验」，把视觉伺服升格为「高频的快证伪器」，让二者互相约束而不是互相背书。** 常识决定「看什么、伺服到哪里、哪些约束不能碰」，视觉伺服执行并产出残差；残差反过来证伪常识/几何先验，驱动属性后验与几何信任度在线校准。LIRO 保证「几何-技能-干扰层面物理安全」，COSMO 追加保证「系统对物体属性与后果的默认假设是**被持续检验**的，且细操作在特征空间闭环收敛」。

## 0. 直觉与动机

### 直觉 0（两个灵感词是「慢先验 × 快证伪」的一对）

常识推理是**慢的、开放的、可击败的**：它用默认规则从稀疏观察推断未观测属性与后果（易碎、hot、on-top、会倒、该抓把手），但每条规则都可能被例外推翻。视觉伺服是**快的、局部的、需要目标的**：它把像素/特征误差压到零，但不知道该对准什么，也不知道对准的东西是否危险/得体。把二者分开做会得到两个坏结果：只做常识 → 生成漂亮但开环、执行不准、且无法验证的「计划」；只做伺服 → 精确而快速地锁定一个错误目标。**正确做法是闭环嵌套：常识给伺服选特征、选参考、设约束与增益；伺服的残差作为独立证据，回头修正常识与几何先验的置信度。**

### 灵感 1（常识推理 → CKR + ACC：从「硬谓词」到「证据化可击败约束」）

直觉：常识不是事实，而是**带例外的默认**。看到「薄壁透明杯」应默认「易碎」但允许「若是塑料杯则例外」；看到「刀」应默认「刃口危险」但允许「刀已入鞘」。系统必须能同时表达「相信」「不确定」「未知」，并在证据冲突时**放弃**而不是硬扛。

严谨：建立常识知识库 `KB = {(body_r ⇒_d head_r, w_r, D_r)}`，`⇒_d` 为可击败蕴含，`w_r` 为规则强度，`D_r` 为例外/反驳器集合；用**证据逻辑（evidential logic）**在 grounded 原子上传播质量函数 `m(·)`，显式保留未知质量 `m(Θ)`，得到信念 `Bel(a)` 与似然 `Pl(a)`。常识状态 `c_t = (props, rels, afford, causal, norms)` 是隐变量；`CKR` 用「神经接地谓词（校准后的分类器）+ 证据传播」联合推断 `c_t` 与下一步后果预测 `ŝ_{t+1}^{cs}`。`ACC` 把高信念、可硬化的常识编译为**控制屏障函数（CBF）约束**（易碎→力上限、含水→姿态约束、高温→最小距离、高窄→抗倾覆裕度），把低信念/软常识编译为 CSP 代价项，并为每条约束附上**击败条件**与**来源**，使运行时可撤销。

### 灵感 2（视觉伺服 → CVS + SVR：从「开环阻抗」到「常识条件特征闭环 + 残差证伪」）

直觉：最后几毫米不该靠猜。直接对**任务相关图像特征**做闭环，误差在像素/特征空间里被显式压小。但「伺服什么」必须由常识和技能决定：抓把手要伺服把手轴线与夹爪开口的对齐；插孔要伺服孔轴与销轴的二维投影；倒水要伺服液面/杯口倾角。并且，**伺服的积分残差是一个几乎免费的物理现实检验器**：如果几何先验说「接触面在这」，而伺服持续需要非零修正才能维持对准，那先验大概率错了。

严谨：`CVS` 定义特征映射 `s_t = Φ_{c,σ}(O_t)`（由常识/技能条件选择特征子集与参考轨迹 `s*`），控制律 `v_c = −λ_c Ĵ_e⁺(e + k_I ξ) + v_ff`，`e = s − s*`，`ξ = ∫e dt` 为积分状态，`λ_c = λ_0·g_risk(c)` 按风险自适应（易碎/高温降增益，自由空间升增益）。`SVR` 定义**结构化残差** `ξ_t`（常数偏置下 `ξ_∞ ∝ −b/(λ k_I)`，`b` 为模型/几何偏差诱导的特征偏置），用 CUSUM 检测其持续性，用「候选原因方向重建」做归因（几何幻觉 / 属性错误 / 外部扰动 / 传感器故障），并据此更新**几何信任度** `λ_geo ∈ [0,1]` 与 WCV 有效球半径 `r_eff`。

### 灵感 3（融合 → CBP + Shield-CS + WCV-CS：把「点先验」变成「被检验的后验」）

直觉：物体属性（质量、摩擦、易碎、温度、内容、重心）不该是一个由 `GeoInit` 一次给出的点估计，而应是**先验 + 视觉伺服/触觉/力证据**融合后的分布；安全球应取这个分布的 credible ball，而不是先验的点 ± 固定半径。语义约束（别捏碎、别洒、别烫到、别推倒）应在控制层用 CBF 保证前向不变，而不是只在规划层检查一次。

严谨：`CBP` 维护属性后验 `p(prop | L, B, E_vis, E_tact, E_force)`，用 `Bel` 作先验、伺服残差与力/触觉作似然，输出校准的 `P_δ`（分组保形）。`WCV-CS` 用 `P_δ × B(φ̂, r_eff)` 作为鲁棒编译域；`Shield-CS` 用优先级 CBF-QP：安全 ≻ 常识硬约束 ≻ 用户硬指令 ≻ 软偏好 ≻ 默认，不可满足时返回 `cannot_comply` 并解释，而不是静默放宽。这样「常识」不再是一次性文本规则，而是**进入密集控制、且在控制中被检验/撤销的约束**。

### 灵感 4（合流 → COSMO：常识-伺服-信念闭环）

直觉：LIRO 的内环是「几何→技能→干扰→物理证书」；COSMO 在其外套一层「企业常识 → 约束/特征选择 → 视觉伺服 → 残差证伪 → 属性/几何后验 → 重规划」的**可证伪外环**。关键不是再加一个模块，而是让「先验」与「现实检验」在架构上**分离**：常识/几何属于语义流（慢、可错、可击败），视觉伺服属于实时流（快、连续、与先验弱耦合），SVR 是两者之间的审计员。

严谨：`COSMO = (LIRO, CKR, ACC, CVS, SVR, CBP, Shield-CS, WCV-CS, USL-C, CSP-C, OLP-CS, SSB-C, AIC-CS, OCB-CS, J_cosmo)`。闭环：`[多模态观测 → CKR 常识推断 → ACC 编译约束/特征目标 → CSP-C 规划（含常识代价）→ Shield-CS 优先级 CBF 投影 → CVS 特征伺服 → SVR 残差证伪/归因 → CBP 属性与几何后验更新 → WCV-CS 重新编译 → OLP-CS 更新 → SSB-C 记账 → AIC-CS 联合认证 → J_cosmo]`。

### 灵感 5（LIRO 组件的原位升级）

- **USL → USL-C**：技能 `pre/eff` 增入常识谓词与**例外字段** `except`；谓词不再是布尔，而是 `(Bel, Pl)`，CSP 用信念阈值而非硬真值。
- **CSP → CSP-C**：代价增入「期望常识违背」`E[1 − Bel(respect)]` 与「主动检验信息价值」`−VoI(probe)`；允许规划一个「先看一眼/先轻碰一下」的探针技能来降低关键属性的后验熵。
- **Shield-Skill → Shield-CS**：技能参数投影升级为「优先级 CBF-QP」，语义硬约束（别洒/别捏碎）在伺服全程前向不变，而非仅前置检查。
- **OLP-Geo → OLP-CS**：输入扩为 `x_cosmo = [x'; z_cs; z_svr]`（常识嵌入 + 结构化残差），遗憾界增入常识/残差维度，但对偶地因 `λ_geo` 校准使有效不确定集更诚实。
- **WCV-Geo → WCV-CS**：球心/半径由 `CBP` 后验 credible ball 给出，`r_eff = r/λ_geo`（几何信任下降时**主动放大**而不是维持过度自信的小球）。
- **AIC → AIC-CS**：干扰集增入「常识分布外」（新物体类别、新家庭/文化规范）与「伺服特征退化」（纹理缺失、反光、遮挡），证书联合认证 `ρ_dir`、`ρ_cs`、`ρ_servo`。
- **SSB → SSB-C**：场景签名增入「常识指纹」（物体类别-属性-规范分布）与「伺服特征指纹」（可跟踪特征数/纹理/反光），使场景银行能检索「同类常识误判」与「同类伺服退化」。
- **OCB-Skill → OCB-CS**：臂空间增入伺服模式 `{IBVS, PBVS, hybrid, force_only}` 与常识模式 `{full_KB, abstain, ask_probe}`，奖励扣除「常识误判导致的返工」。

## 1. 形式化定义（增量：定义 201–216）

- **定义 201（COSMO 闭环）**：`COSMO = (LIRO, CKR, ACC, CVS, SVR, CBP, Shield-CS, WCV-CS, USL-C, CSP-C, OLP-CS, SSB-C, AIC-CS, OCB-CS, J_cosmo)`。不变式：**常识与几何先验只在语义流演进且可被撤销；视觉伺服在实时流连续运行且与先验弱耦合；SVR 是唯一有权降低 `λ_geo` 与常识信念的组件**。
- **定义 202（常识状态）**：`c_t = (props_t, rels_t, afford_t, causal_t, norms_t)`，`props` 为物体属性（质量/摩擦/易碎/温度/内容/重心），`rels` 为空间-支撑-包含关系，`afford` 为可供性（可抓/可推/可拧/可倒/承载面），`causal` 为后果预期（推倒/洒出/碎裂/滑落），`norms` 为规范（私有/危险/礼貌）。`c_t` 为隐变量，仅通过观测与行为证据间接可估。
- **定义 203（可击败常识知识库）**：`KB = {(body_r ⇒_d head_r, w_r, D_r)}`，`body_r/head_r` 为 grounded 一阶谓词合取，`w_r ∈ (0,1]` 规则强度，`D_r` 为反驳器集合（例外条件）。语义：`⇒_d` 非单调，加入 `D_r` 中的证据可撤销 `head_r` 的信念。
- **定义 204（证据化常识推断）**：对 grounded 原子 `a`，质量函数 `m_a: 2^Θ → [0,1]`，`Bel(a) = Σ_{S⊆{a}} m_a(S)`，`Pl(a) = Σ_{S∩{a}≠∅} m_a(S)`，未知质量 `m_a(Θ) = 1 − Bel(a) − Bel(¬a)`。规则按 Dempster 组合传播；神经接地谓词输出经温度/等渗校准后作为单元素质量源。
- **定义 205（常识后果预测）**：`(ŝ_{t+1}^{cs}, Σ_cs) = F_cs(c_t, a_t)`，预测可观测后果（是否滑动/倾倒/溢出/碎裂）及其协方差；`F_cs` 为「规则推演 + 小型因果网络」混合，输出参与 CSP-C 代价与 ACC 约束。
- **定义 206（ACC 约束编译）**：`ACC(c_t, σ) → C_cs = {(φ_k, b_k, hard_k, defeat_k)}`，`b_k = Bel(φ_k 的常识前提)`，`hard_k = 1[b_k ≥ τ_hard(k) 且严重度 ≥ s_k]`，`defeat_k` 为撤回条件。硬约束编译为 CBF，软约束编译为代价。
- **定义 207（语义控制屏障函数）**：安全集 `𝒮_k = {z: h_k(z) ≥ 0}`，如 `h_fragile = f_max(prop) − ‖f‖`、`h_spill = cos θ_max − n_z`、`h_thermal = ‖p_ee − p_hot‖ − d_min`、`h_topple = ZMP 裕度`。要求伺服闭环满足 `ḣ_k ≥ −α_k h_k`（前向不变）。
- **定义 208（常识条件视觉伺服 CVS）**：`s_t = Φ_{c,σ}(O_t) ∈ ℝ^k`，`s* = s*(σ, c_t)`，`e_t = s_t − s*`，`v_c = −λ_c Ĵ_e⁺(e_t + k_I ξ_t) + v_ff`，`λ_c = λ_0·g_risk(c_t)`，`ξ_t = ∫_0^t e_τ dτ`（带抗饱和）。`Φ` 按可供性/技能选择特征（把手轴、孔轴投影、杯口椭圆、液面线、边缘）。
- **定义 209（伺服残差与模型误差下界）**：常数模型/几何偏置 `b` 下闭环稳态 `ξ_∞ = −b/(λ_c k_I)`；因此结构化残差 `‖ξ_∞‖ = ‖b‖/(λ_c k_I)` 是偏置大小的**显式代理**。定义归一化残差 `r_t = ‖ξ_t‖ / (‖ξ_t‖ + ε_0)` 与残差方向 `û_t = ξ_t/‖ξ_t‖`。
- **定义 210（SVR 证伪与归因）**：CUSUM `g_t = max(0, g_{t−1} + ‖ξ_t‖ − ν)`，`g_t > h_svr` 报警。原因假设 `H = {geo, prop, ext, sensor}`；对每个假设 `j` 有特征偏置方向模板 `J_j Δ_j`，归因后验 `P(H_j | ξ) ∝ π_j exp(−‖ξ − J_j Δ̂_j‖²/2σ_j²)`。归因到 `geo` 则降 `λ_geo`，到 `prop` 则触发 CBP 更新，到 `ext` 则交 ERTC/RSC，到 `sensor` 则降视觉权重并请求重观测。
- **定义 211（几何信任校准）**：`λ_geo ∈ [0,1]`，`λ_geo ← λ_geo·(1−η_geo) + η_geo·(1−r̄_t)`（`r̄_t` 为窗口平均残差）；有效球半径 `r_eff = r / max(λ_geo, λ_min)`。`λ_geo↓` ⇒ 球放大 ⇒ WCV-CS 更保守，**主动消除「幻觉几何 + 过度自信小球」的组合**。
- **定义 212（CBP 属性后验）**：`p(prop | L, B, E_vis, E_tact, E_force) ∝ Bel_prior(prop)·Π_k ℓ_k(E_k | prop)`；输出分组保形集 `P_δ = {prop: score(prop) ≤ q_δ}`，保证 `P(prop* ∈ P_δ) ≥ 1−α_prop`。`P_δ` 的直径直接决定 WCV-CS 的球心不确定度。
- **定义 213（USL-C 常识增强技能库）**：`σ = (name, pre, eff, except, π_σ, cost, 𝒫_feas)`，`pre/eff` 为 `(Bel, Pl)` 值而非布尔；`except` 为撤回首技能的例外谓词；`π_σ` 额外输出 `(s*, Φ, λ_c)` 供 CVS 使用。
- **定义 214（CSP-C 可击败规划）**：目标 `G` 满足以 `Bel(G) ≥ 1−α_goal` 判定；代价 `J(τ) = Σ cost + λ_cs Σ E[1−Bel(respect_k)] − λ_voi Σ VoI(probe)`；`VoI(probe) = H(prop) − E[H(prop | probe)]` 为探针降低的属性熵。允许「先看/先轻碰」探针技能入序列。
- **定义 215（Shield-CS 优先级 CBF 屏蔽）**：`(v*, ε) = argmin_{v,ε≥0} ‖v − v_nom‖² + κ‖ε‖²` s.t. `∇h_k·(f+gv) ≥ −α_k h_k − ε`（硬约束集，按优先级分层求解）；若最小松弛 `ε* > ε_max` 返回 `cannot_comply(reason={safety|common_sense|user})` 并附违反谓词。
- **定义 216（J_cosmo 联合证书）**：`J_cosmo = (J_liro, ρ_cs, ρ_servo, cover_prop, λ_geo, surprise_log, kb_ver, feature_fp)`；`Valid ⇔ Valid(J_liro) ∧ ρ_cs ≥ 0 ∧ ρ_servo ≥ 0 ∧ cover_prop ≥ 1−α_prop ∧ λ_geo ≥ λ_min`。

## 2. 关键算法骨架（完整伪代码见产物区）

```python
# CKR：常识推断（语义流）
c_t, Bel, Pl = ckr.infer(x_prime, g, scene_graph, history)   # 证据化可击败推理

apply(v_safe)                                    # 1kHz 伺服
xi, r = svr.update(cvs.features, s_star, v_safe) # 结构化残差
if svr.cusum_alarm(r):
    cause = svr.attribute(xi)                     # geo/prop/ext/sensor
    lambda_geo = svr.update_geometry_trust(lambda_geo, r, cause)
# CBP + WCV-CS：后验 credible ball 重新编译
prop_post, P_delta = cbp.update(prior=Bel, evis=cvs.evidence, etact=T, eforce=f)
```

**定义 204（证据化常识推断）** 每个 grounded 原子 `a` 携带质量函数 `m_a: 2^{{a,¬a}} → [0,1]`：`m_a({a}) = b_a`，`m_a({¬a}) = d_a`，`m_a({a,¬a}) = u_a`，`b_a + d_a + u_a = 1`。`Bel(a) = b_a`，`Pl(a) = b_a + u_a`。规则传播（单源近似）：`b_head ← b_head + w_r·b_body·u_head`，`d_head ← d_head + w_r·b_body·d_head`；反驳器 `d ∈ D_r` 触发时 `b_head ← b_head·(1−Bel(d))`。多源用 Dempster 组合：`m_{12}(A) = (1/(1−K))Σ_{B∩C=A} m_1(B)m_2(C)`，`K = Σ_{B∩C=∅} m_1(B)m_2(C)` 为冲突质量；冲突过高（`K > K_max`）时输出 `abstain` 而非强行合并。神经接地谓词的原始概率经温度缩放 + 等渗回归校准后作为 `b_a`，保证 `|Bel − freq| ≤ ε_cal`。

**定义 209（伺服残差与模型误差）** 设特征动力学 `ṡ = L v + b + n`（`b` 为模型/几何诱导的常数偏置，`n` 为噪声）。PI 闭环稳态 `ξ_∞ = −b/(λ_c k_I)`，故 `‖b‖ = λ_c k_I ‖ξ_∞‖`。定义 `r_t = ‖ξ_t‖/(‖ξ_t‖+ε_0) ∈ [0,1)` 与方向 `û_t = ξ_t/(‖ξ_t‖+ε_0)`。纯 P 控制仅有 `e_∞=b/λ_c`，无方向分离能力；积分项把「不可见偏置」变成**可测、有方向、可归因**的向量。

后验 `P(H_j | ξ) ∝ π_j·exp(−‖ξ − J_j Δ̂_j‖²/(2σ_j²))`，`Δ̂_j = (J_jᵀJ_j)⁺J_jᵀξ`。归因 `prop` → 触发 `CBP` 更新；`geo` → 降 `λ_geo`；`ext` → 交 `ERTC/RSC`；`sensor` → 降视觉权重并请求主动重观测（改变视角/光照/靠近）。

**定义 211（几何信任校准）** `λ_geo ∈ [λ_min, 1]`，更新 `λ_geo ← clip(λ_geo·(1−η_geo) + η_geo·(1−r̄_t), λ_min, 1)`，其中 `r̄_t` 为窗口平均残差；有效球半径 `r_eff = r / max(λ_geo, λ_min)`。**关键方向性**：残差大 ⇒ `λ_geo↓` ⇒ `r_eff↑` ⇒ WCV-CS 搜索域变大 ⇒ 更保守。这把第 63 轮「几何越确定、球越小、越可能错过真值」反转为「残差越大、几何越不可信、球越大」。

**定义 212（CBP 属性后验）** `p(prop | L, B, E_vis, E_tact, E_force) ∝ Bel_prior(prop)·Π_k ℓ_k(E_k | prop)`。`Bel_prior` 来自 CKR；`E_vis` 为 CVS 的特征残差与视觉属性分类；`E_tact` 为接触事件（滑/粘/形变）；`E_force` 为力-位移曲线推断的刚度/摩擦。输出 `P_δ = {prop: score(prop) ≤ q_δ}`，`q_δ` 为分组保形分位数（按物体类别/场景族分组），保证 `P(prop* ∈ P_δ) ≥ 1−α_prop`。`P_δ` 的直径（而非点估计方差）决定 `WCV-CS` 的球心不确定度。

**定义 213（USL-C 常识增强技能库）** `σ = (name, pre, eff, except, π_σ, cost, 𝒫_feas)`，`pre/eff` 为 `(Bel, Pl)` 值；`except` 为撤回该技能适用性的例外谓词（如 `except_grasp = wet(handle) ∨ fragile(obj) ∧ ¬soft_grip`）；`π_σ(x_cosmo, θ)` 额外输出 `(s*, Φ, λ_c)` 供 CVS。`π_σ` 仍为小型 MLP，新增输出头 3 维（特征选择 logits、参考偏移、增益比例）。

**定义 214（CSP-C 可击败规划）** 目标满足改为信念判定 `Bel(G) ≥ 1−α_goal`。代价 `J(τ) = Σ_i cost(σ_i, θ_i) + λ_cs Σ_t E[1−Bel(respect_t)] − λ_voi Σ VoI(probe_i)`，`VoI(probe) = H(props_key) − E[H(props_key | probe)]`。允许探针技能 `{look_from, gentle_touch, lift_slightly, ask_probe}` 入序列；探针作为「主动实验」降低关键属性后验熵，其收益计入 CSP-C 搜索。求解器在 `USL-C` 技能图上做层级 A*，实时仅展开首技能。

**定义 215（Shield-CS 优先级 CBF 屏蔽）** 分层 QP：
```
层 0（安全）：min ‖v−v_nom‖²  s.t.  ∇h_k^safety·(f+gv) ≥ −α_k h_k
层 1（常识硬约束）：在层 0 可行域内加 ∇h_k^cs·(f+gv) ≥ −α_k h_k
层 2（用户硬指令）：...
层 3（软偏好）：以代价项而非约束
```
各层用松弛变量 `ε_k ≥ 0`，仅当高层无法满足时才松弛低层；若层 0/1 的最小松弛 `ε* > ε_max`，返回 `cannot_comply(reason)` 并附违反谓词。**常识硬约束在伺服全程前向不变**，而非仅在技能前置检查一次。

**定义 216（J_cosmo 联合证书）** `J_cosmo = (J_liro, ρ_cs, ρ_servo, cover_prop, λ_geo, surprise_log, kb_ver, feature_fp)`：
- `ρ_cs = min_{k: hard_k=1} Bel(φ_k) − (1−severity_k)`，为常识约束的信念加权裕度；
- `ρ_servo = 1 − r̄_T`，为伺服残差裕度；
- `cover_prop` 为 `P_δ` 的历史覆盖率（滚动窗口）；
- `feature_fp` 为特征退化指纹（可跟踪特征数、纹理熵、反光率）。
`Valid(J_cosmo) ⇔ Valid(J_liro) ∧ ρ_cs ≥ 0 ∧ ρ_servo ≥ ρ_min ∧ cover_prop ≥ 1−α_prop ∧ λ_geo ≥ λ_min ∧ kb_fresh`。审计链额外记录：常识推断输入/版本、归因事件、`λ_geo` 轨迹、被撤销的约束（defeat log）。

```python
class EvidentialAtom:
    def __init__(self, bel=0.0, doubt=0.0):
        self.b, self.d = bel, doubt            # m({a}), m({¬a}); unknown = 1-b-d
    def bel(self):  return self.b
    def pl(self):   return self.b + (1.0 - self.b - self.d)

def dempster(m1, m2):
    # m1, m2: dict[frozenset[int], float]; 0 -> a, 1 -> not a, 2 -> unknown
    out, K = defaultdict(float), 0.0
    for A, pa in m1.items():
        for B, pb in m2.items():
            inter = A & B
            if not inter:
                K += pa * pb
            else:
                out[inter] += pa * pb
    if K > 0.99:                               # 冲突过高 -> abstain
        return None
    return {A: v / (1.0 - K) for A, v in out.items()}

class CommonsenseReasoner:
    def __init__(self, kb, predicate_heads, tau_hard):
        self.kb = kb                           # List[DefeasibleRule]
        self.heads = predicate_heads           # 校准后的神经接地谓词
        self.tau_hard = tau_hard

    def infer(self, x_prime, g, scene_graph, history):
        atoms = self._ground(scene_graph)      # 物体/部件/关系 grounded 节点
        m = {a: self.heads[a](x_prime, g) for a in atoms}   # 校准 mass
        changed = True
        while changed:                         # 证据传播至不动点（深度受限）
            changed = False
            for rule in self.kb:
                if not all(m[p].bel() > 0.5 for p in rule.body):
                    continue
                b_body = min(m[p].bel() for p in rule.body)
                head = rule.head
                # 反驳器：任一 backer 成立则按强度削减
                back = max([m[d].bel() for d in rule.defeaters] + [0.0])
                w_eff = rule.w * b_body * (1.0 - back)
                new = EvidentialAtom(m[head].b + w_eff * (1.0 - m[head].b),
                                     m[head].d)
                if abs(new.b - m[head].b) > 1e-4:
                    m[head] = new; changed = True
        c_t = self._assemble_state(m)          # props/rels/afford/causal/norms
        return c_t, m
```

```python
class ServoVisualResidualFalsifier:
    def __init__(self, nu=0.02, h_svr=1.0, eta_geo=0.05, lam_min=0.2):
        self.g, self.nu, self.h, self.eta, self.lam_min = 0.0, nu, h_svr, eta_geo, lam_min

    def update(self, xi):
        r = np.linalg.norm(xi) / (np.linalg.norm(xi) + 1e-3)
        self.g = max(0.0, self.g + np.linalg.norm(xi) - self.nu)

    def attribute(self, xi, J_geo, J_prop, tau_ext):
        cands = {}
        for name, J in [('geo', J_geo), ('prop', J_prop)]:
            d = np.linalg.pinv(J) @ xi

        cands['ext'] = 0.5 * np.linalg.norm(xi) ** 2 if np.linalg.norm(tau_ext) > TAU_EXT else np.inf
        cands['sensor'] = 0.3 * np.linalg.norm(xi) ** 2 if feature_loss_flag() else np.inf
        return min(cands, key=cands.get), cands

    def update_geometry_trust(self, lam_geo, r):
        lam_geo = np.clip(lam_geo * (1 - self.eta) + self.eta * (1 - r), self.lam_min, 1.0)
```

```python
def shield_cs_qp(v_nom, z, C_cs, alpha=1.0, eps_max=0.1):
    # 分层：安全 -> 常识硬约束 -> 用户硬指令；软偏好不进约束
    hard = [c for c in C_cs if c.hard]
    # 先检查高层可行性（松弛仅允许在低层）
    for lvl in range(len(hard) + 1):
        constraints = []
        for c in hard[:lvl]:
            Lf, Lg = lie_derivatives(c.h, z)
            constraints.append((Lg, -(Lf + alpha * c.h(z))))  # Lg v >= -Lf - a h
        v, eps = solve_qp(v_nom, constraints)
        if eps <= eps_max:
            return v, 'lock'
    return None, 'cannot_comply'
```

## 4. 推导

**引理 5（伺服残差是模型偏置的显式代理）** 设单特征 `s ∈ ℝ` 动力学 `ṡ = λ_s(v + b/λ_s) + n`（把偏置写成等效速度偏置），控制 `v = −λ(e + k_I ξ)`，`e = s − s*`，`ξ = ∫e`。闭环 `ė = −λλ_s(e + k_I ξ) + λ_s b/λ_s·... ` 取 `b` 为常数特征偏置并令 `λ_s=1`，则 `ė = −λe − λk_I ξ + b`，`ξ̇ = e`。稳态 `e_∞ = 0`（积分消除），`ξ_∞ = b/(λk_I)`，故 `‖b‖ = λ k_I ‖ξ_∞‖`。**纯比例控制** `v=−λe` 时 `e_∞ = b/λ`，只给出幅值、不给出可分离方向；积分残差携带方向，可做原因归因。若含时变/噪声，`ξ` 有界且 `‖ξ‖` 随 `‖b‖` 单调（在 `|ξ|≤ξ_max` 内）。∎

**引理 6（语义 CBF 前向不变）** 若 `h_k(z_0) ≥ 0` 且控制满足 `ḣ_k = L_f h_k + L_g h_k v ≥ −α_k h_k`，则由比较引理 `h_k(z_t) ≥ h_k(z_0)e^{−α_k t} ≥ 0`。故对**已编译的**硬约束，伺服全程不越界。该引理不保证 `h_k` 的语义正确性——若 `h_k` 由错误常识生成，得到的是「错误约束被完美满足」。∎

**定理 4（幻觉几何可检测且可撤销）** 设视觉特征对几何参数局部可观测：`J_g = ∂s/∂φ` 列满秩（`σ_min(J_g) > 0`），噪声有界 `‖n_t‖ ≤ δ_n`，几何幻觉产生 `b_g = J_g Δ_g`。若 `‖b_g‖ > λ k_I ν + δ_n`，则 CUSUM 的漂移 `E[‖ξ‖−ν] > 0`，报警期望延迟 `E[τ] ≤ h_svr/(‖b_g‖−λk_Iν)`；虚警率由 `h_svr` 与 `ν` 控制（`≤ exp(−2h_svr²/σ_ξ²)` 近似）。归因步骤中 `J_geo` 与 `J_prop` 张成不同方向时，重建残差最小化以高概率选中 `geo`。随后 `λ_geo↓` 使 `r_eff = r/λ_geo↑`，当 `r_eff ≥ ‖φ*−φ̂_0‖` 时 `B(φ̂_0,r_eff)` 重新覆盖真值 `φ*`，从而撤销第 63 轮假设 A77 的「几何先验必真」单点依赖。**代价**：`r_eff↑` 使 WCV-CS 更保守、`ρ_rob` 下降，即用性能换安全。∎

**定理 5（常识风险的非对称性）** 设 `Bel` 经校准：对任一危险谓词 `h`，`P(h | Bel(h)=b) = b ± ε_cal`。硬约束仅在 `b ≥ τ_hard(s_h)` 启用。则「真实危险被漏判」概率 `P(h ∧ Bel(h)<τ_hard) ≤ P(Bel(h)<τ_hard | h) ≤ α_h(τ_hard)`，总漏判 `≤ Σ_h π_h α_h`；而「虚假危险被误判」只在 `¬h ∧ Bel(h)≥τ_hard` 时发生，其后果是过约束（保守代价、任务不可用），不产生物理不安全。**故常识层应偏向保守**（`τ_hard` 随严重度降低）。但这把风险转移到「过度约束/过度拒绝」——这是次级风险，也是 `defeat` 与 `ask_probe` 存在的原因。∎

**定理 6（COSMO 联合安全与独立失效链）** 设 `Valid(J_liro)` 给出 `P[物理安全] ≥ 1−α_dir−δ_cert`（第 63 轮定理 3），`Valid(J_cosmo)` 额外给出 `ρ_cs≥0` 与 `cover_prop≥1−α_prop`。由联合界 `P[物理安全 ∧ 语义约束满足] ≥ 1 − α_dir − δ_cert − α_cs − α_prop`，前提是 `λ_geo` 校准有效（定理 4）且常识保形集在同分布内覆盖。**但两条链不共享假设**：物理链可成立而语义链失败（如社会规范错误、物理自洽），反之亦然。因此 `Valid(J_cosmo)` 不能由 `Valid(J_liro)` 推出，必须分别记录 `ρ_cs/cover_prop` 与 `ρ_dir`。∎

**命题（探针的信息价值与延迟代价）** 探针 `probe` 的期望信息增益为 `VoI(probe) = H(props_key) − E[H(props_key | probe)]`。对高斯后验，`E[H_after] = 0.5 log(2πe(Σ − Σ_probe))`，故 `VoI = 0.5 log det(Σ)/det(Σ_after)`。若探针耗时 `t_probe` 且任务时限余量 `t_slack`，则只有当 `λ_voi·VoI ≥ λ_time·t_probe/t_slack` 且探针不触发更高优先级安全约束时才执行。**探针不是免费的，也不是中性的**：`gentle_touch` 本身可能改变被估计对象（压痕、移位），故探针动作也纳入 `ACC` 的 CBF 约束。∎

**命题（CVS 收敛与增益-偏置权衡）** 对 `‖b‖` 有界的 PI 伺服，稳态积分偏差 `‖ξ_∞‖ = ‖b‖/(λk_I)`；提高 `λ` 可减小偏置残差，但噪声敏感度随 `λ` 线性增大（`‖e_noise‖ ≈ λ‖n‖/(λ) ...` 的传递峰值），且易碎/高温场景需要低增益以限制冲击。故 `g_risk` 是「精度—柔和—鲁棒」三者的显式折中，`SVR` 的 `ξ` 在低增益下更慢但更可信。∎

## 7. 已知风险

**一句话**：视觉伺服只能证伪「物理/几何」层面的常识，**无法证伪「社会/语用」层面的常识**——若 `KB` 在特定用户/家庭/文化上系统性错误（误判私有性、礼貌、可接受力度），`ACC` 会把错误默认编译成 CBF 硬约束或漏掉约束，而 `CVS` 仍会沿错误目标平滑、快速、低残差地执行，`SVR` 因「物理上完全自洽」而无从报警，最终系统拿着物理与伺服双绿证书，稳定且流畅地做语义上错误的事。

**次级风险与缓解**：
1. **过度约束/过度拒绝**：常识偏保守 + CBF 硬化 ⇒ 可行域被压空。缓解：`defeat` 运行时撤销、`ask_probe` 主动降熵、`ε` 分层松弛、`cannot_comply` 附解释而非静默。
2. **常识知识库长尾/文化偏差**：OOD 规范无法覆盖。缓解：用户/场景级 `kb_ver` 与规范配置、OOD 检测（`m(Θ)` 高 ⇒ abstain/询问）、把规范决策上移给 `DMS` 而非 CBF。
3. **CVS 特征退化**：纹理缺失、反光、遮挡导致 `Φ` 跟踪失败或 `Ĵ` 病态。缓解：`feature_fp` 监控、条件数阈值触发 `request_reobserve`、退化为 PBVS/力伺服、`λ_geo` 同步降。
4. **SVR 误归因**：`J_geo` 与 `J_prop` 方向近似共线时无法区分。缓解：主动激励（小幅探测运动）增大可辨识性、多假设粒子、归因不确定时同时降 `λ_geo` 与增大 `P_δ`。
5. **探针改变被估计对象**：轻碰/抬升本身引入状态变化。缓解：探针纳入 ACC/CBF、以最小侵入动作为先、探针后重新校准后验。
6. **PI 伺服积分饱和/时延失稳**：低增益 + 延迟下积分发散。缓解：抗饱和 `ξ_max`、Smith 预测器、增益调度、`‖ξ‖` 超限即视为模型错误而非继续积分。
7. **证书组合的独立性被误用**：`Valid(J_liro)` 被当作语义安全。缓解：`J_cosmo` 强制双链字段、审计链分离、缺字段即 `Valid=false`。
