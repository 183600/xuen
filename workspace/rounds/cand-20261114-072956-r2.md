# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「评测基准」×「腕部相机」）

> R66–R69 是一条「不断加层」的路：R66 加控制权、R67 加未来预测、R68 加计量标定、R69 加不确定性二分与主动交互。每一层都宣称「安全侧不让步」，但**没有一层回答一个更根本的问题：我凭什么相信这些结论？** R69 自陈的最大风险是「模态分布不可信 → 追问幻影、把谎言盖章」，可它用来发现缓变故障的第二意见（FMA）依赖一个从未被检验的前提——**行为证据独立于策略自身的动作**。
>
> 本轮两个灵感恰好从两侧拆掉了这个前提，又给出了补丁：
> - **腕部相机**不是「又一路输入」，而是一路**被动作驱动的传感器**：它的位姿由末端执行器决定，它看到的画面是策略自己「摆」出来的。于是（i）R69 的 FMA 证据被策略自条件化，「自我实现的感知」可以让漂移在似然里隐形；（ii）同一耦合又提供了**do(pose) 干预手柄**——腕部相机的位姿可控，使我们第一次能在不改任务状态的前提下做因果评测；（iii）近距离高分辨率使它可充当**非接触视觉探针**，替代 R69 里昂贵又危险的物理探针。
> - **评测基准**不是「论文最后一节」，而是整个技术栈的**认识论仪器**。R66–R69 的 60 多个实验若只在成功率排行榜上收敛，就无法区分「系统真安全」与「基准饱和/泄漏/被 Goodhart 套利」。基准本身必须可证伪、可审计、可干预、统计有效。
>
> 核心命题：**R70 不再加一层安全壳，而是造一把能证伪前四轮的尺子，并修掉这把尺子照出的自指 bug。** 具体地：用腕部相机的「执行即观测」建立**自条件化指数 ECI**，对 R69 的 FMA 做门控与去耦（ADL）；用腕部位姿的 do-干预建立**干预式基准 PROBE-Bench**（do(pose)/do(hand-eye)/do(lighting) 反事实重放）；用**VoI 校准、泄漏审计、canary/隐藏因果因子、anytime-valid 置信序列**把「成功率」升级为「认识论记分卡」；最后用**视觉探针**重定义交互成本。命名 **PROBE-RAS**（Probing Risk via Observation-perturbation and Behavioral Epistemics）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我怎么知道自己不是在自欺**」——腕部相机既是照见自己的镜子，也是把自己骗过去的陷阱。

## 0. 直觉与动机

**灵感 1（腕部相机 → 观测是动作的函数，「测量」与「被测量」被同一个回路缠住）**
直觉：第三人称相机是「世界的证人」，腕部相机是「手的证人」。它离接触最近、分辨率最高，能看清抓取瞬间的滑移、位姿与遮挡；但它装在末端，**它的视角就是策略自己摆出来的**。绝大多数腕部相机策略在训练中都会隐式学到「把物体/夹爪保持在画面中央或某个标准构图」——这本来是个好习惯，却恰好是一个**扰动抑制控制器**：手眼标定漂了一个角度，策略会不自觉地转动腕部把物体重新摆回「熟悉的构图」，于是漂移在图像里被抵消，流似然看不出异常。R69 把 FMA 当作「标定不可吸收」的第二意见，可它没意识到：**吸收漂移的不只是标定层，还有策略自己的动作**。这是「认识论乱伦（epistemic incest）」——用被自己污染的证据来审判自己。

**灵感 2（腕部相机 → 位姿可控 = 天然的 do-干预手柄）**
直觉：普通基准只能「换场景、换物体、换随机种子」，然后报告成功率；它回答的是相关性问题，不是因果问题。但腕部相机的位姿是一个**可以单独操纵的变量**：在数字孪生里改 `do(p_wrist)`、改 `do(T_hand-eye)`、改 `do(θ_intr)`、改光照，在真机上用一个辅助支架/第二只标定臂重放腕部视角——**任务状态不变，只动「看的方式」**。于是可以问出排行榜问不出的问题：同一策略在「看得清」与「看不清但世界没变」下差多少？它到底是在用腕部的近距离细节，还是在背物体的颜色先验（捷径）？它声称的「交互能消歧」，在真实重放下是否真的降低了错误？这把「评测」从**观察**升级为**干预**。

**灵感 3（评测基准 → 标量排行榜是坏估计量：饱和、泄漏、Goodhart）**
直觉：成功率是一个被选择效应污染的估计量——大家在同一测试集上反复调参、按结果早停，赢家是「对这份测试集运气最好的人」（winner's curse）。更糟的是腕部相机会**泄漏答案**：近距离画面里常常直接出现物体身份、目标槽位、甚至人类示范留下的线索；策略可以完全不做操作推理，靠「认出这是哪个物体」拿高分。基准若不显式做**模态本质性分解**与**隐藏因果因子**，就会把捷径当成能力。而一旦基准成为目标，它就被 Goodhart：公开集涨、隐藏集不涨甚至跌。基准必须自带**canary 任务**与**Goodhart gap**度量，并采用**预注册 + anytime-valid 置信序列**，让「早停看结果」本身不再能制造假阳性。

**灵感 4（二分与包含 → 新层必须还能退化回旧层）**
直觉：R69 最重要的理论姿态是「FLUID 是 R68 在永不交互边界的严格退化」。R70 必须继承这个纪律：**当 ECI 低、且无需干预式评测时，PROBE-RAS 必须逐指令退化为 FLUID-RAS**。否则每加一层就多一个要独立信任的黑箱，最终整个技术栈变成一叠互相担保、却无人审计的声明。所以本轮不是「用基准否定前四轮」，而是「用基准**条件化地**确认前四轮」：给出它们成立的可检验前提，并在前提被违反时安全降级（FMA 关闭 → 回 R68 保守）。

**灵感 5（视觉探针 → 更便宜的信息动作，但换了威胁模型）**
直觉：R69 的物理探针（触/力）信息量大、但慢、危险、可能损坏物体；腕部相机在高分辨率近距离下能看滑移、看接触形变、从散焦/遮挡推断深度，是一个**非接触探针**，把交互成本 c(g) 显著压低，从而改变 VoI 的阈值（原来不值得问的，现在值得看）。但它有自己的失效面：夹爪自遮挡、运动模糊、镜头污渍、反光/透明物体——**视觉探针会给出高置信的错答案**。所以「更便宜」不等于「更安全」，必须给出替换的净收益条件。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PROBE-RAS 总览）** PROBE-RAS = (WAM, ECI, ADL, COR, VCB, LEA, ADV-B, CS, WVP, RAS-WM‡)。它是「被测系统 π（可为 FLUID-RAS）+ 评测仪器 PROBE-Bench」的联合体。三不变式：
(i) **评测不可反观测**：被测策略在推理时不能读到基准的隐藏因果因子、canary 标签与 do-干预计划（信息隔离，防止对尺子过拟合）；
(ii) **证据去自条件化**：任何声称「独立于策略」的行为证据，必须通过 ECI 门控，或在动作解耦观测上计算；不满足则不得作为第二意见使用；
(iii) **预注册 + anytime-valid**：主终点与假设在见到测试数据前固定，统计推断使用对任意停时有效的置信序列。

**定义 311（腕部观测的动作耦合 WAM）** 设场景状态 s_t、关节/末端位姿 q_t（由 a_{<t} 决定）、手眼外参 T_he、内参 θ_intr、光照/遮挡 ℓ_t。腕部观测
`o^w_t = R(s_t, p^w_t, θ_intr, ℓ_t) + n_t`，其中 `p^w_t = Φ(q_t) ∘ T_he` 是腕部相机世界位姿。记动作-观测耦合 `o^w_t = h(a_{<t}, s_t)`。定义**耦合强度** `κ = I(A_{<t}; O^w_t | S_t)`（以归一化互信息/NMI 估计）。

**定义 312（自条件化指数 ECI 与证据独立性）** 对某一行为证据通道 e（如 R69 的 a_score），定义其自条件化指数
`ECI(e) = 1 − I(E; S_t ⊕ drift | A_{<t}) / I(E; S_t ⊕ drift)`。
直觉：把「外部状态/漂移」对证据的解释力，扣除「动作历史」已经解释掉的部分。`ECI→0`：证据基本由外部世界驱动，可当第二意见；`ECI→1`：证据几乎完全由策略自己的动作摆布，**不具独立性**。门控阈值 τ_eci：`ECI(e) > τ_eci ⇒ e 不得单独作为独立性证据`。

**定义 313（反事实观测重放 COR）** 对观测做 do-算子：`do(p^w = p₀)`、`do(T_he = T₀+δ)`、`do(θ_intr = θ₀+Δ)`、`do(ℓ = ℓ')`、`do(occluder = b)`。实现：数字孪生重渲染；或真机上以辅助标定臂/多机位同步重放腕部视角。COR 在**固定 s_t** 下只改「看的方式」，产出反事实观测族 `𝒪^cf`。定义重放保真度 `ε_r`（重放分布与真实干预分布的 TV/Wasserstein 上界）。

**定义 314（动作解耦似然 ADL）** 用 COR 构造与当前动作解耦的观测 `o^ADL`（`do(p^w=p₀)` 的规范位姿重放，或用不随末端运动的全局相机 o^g），并把 R69 的 FMA 改写为
`a_score^ADL = −log p_θ(ξ_obs | o^ADL)`，`Δa^ADL = |a_score^ADL(o^ADL) − a_score^ADL(o^ADL_cal)|`。
当 ECI(a_score) ≤ τ_eci 时可直接用原 FMA；否则必须用 ADL；两者都不可用（无全局相机且重放不可信）时，**禁用第二意见**，退回 R68 纯保守。

**定义 315（PROBE-Bench 记分卡，向量而非标量）** 一次评测输出
`S = (SR, SV, ECE, β_VoI, IC, LG, φ_sensor, GG, C_int, EI)`：
- `SR` 任务成功率（带置信序列）；`SV` 每小时安全违规数；
- `ECE` 不确定性/模态权重校准误差；`β_VoI` 实测信息增益对预测 VoI 的回归斜率；
- `IC` 干预一致性（真实决策/误差 vs do-重放下的决策/误差）；`LG` 泄漏差 `SR(全模态) − SR(去腕部)`；
- `φ_sensor` 传感器 Shapley 值；`GG` Goodhart 差 `SR(公开) − SR(隐藏 canary)`；
- `C_int` 单位成功所需交互成本；`EI` 证据完整性（通过独立性门控的决策占比）。
**记分卡只定义偏序（Pareto）与预注册加权的敏感性分析，不提供无约束的单一综合分**——单一分正是 Goodhart 的入口。

**定义 316（VoI 校准 VCB）** 对每次交互（看/问/触/视觉探针），记录预测增益 `v̂ = VoI(g)` 与实测增益 `v = H(M|o) − H(M|o,y)`（模态后验熵的真实下降）。定义 `β_VoI = Cov(v,v̂)/Var(v̂)`、`ECE_VoI = E|E[v|v̂]−v̂|`。判据：`β_VoI = 1` 且 `ECE_VoI ≤ τ_v` 为「VoI 可信」。R69 的「交互越多越好」只有在此条件下成立。

**定义 317（泄漏与模态本质性 LEA）** 对模态子集 `U ⊆ {wrist, global, proprio, language}` 做遮蔽评测，得 `SR(U)`。模态 Shapley `φ_m = Σ_{U⊆M\{m}} |U|!(|M|−|U|−1)!/|M|! [SR(U∪{m})−SR(U)]`。定义**捷径判据**：若 `φ_wrist` 高但 `IC` 低、且 `do(identity-swap)`（只在腕部图里换物体身份/颜色而不改几何）使 `SR` 骤降，则判为腕部捷径（识别而非操作）。另做**具身留出**：内参/外参/夹爪/光照在训练-测试间不共享。

**定义 318（对抗基准 ADV-B：隐藏因果因子与 canary）** 设公开因子 F_pub、隐藏因果因子 F_hid（质量、摩擦、关节间隙、柔性、真实接触延迟等只在测试出现），canary 任务集 T_can 与主集同分布但标签不外泄。定义 `GG = SR(F_pub) − SR(F_pub, F_hid)` 与 `GG_can = SR(T_main) − SR(T_can)`。基准轮换（定期刷新隐藏因子与场景）以防记忆。

**定义 319（anytime-valid 统计协议 CS）** 主终点预注册；用 e-value / 混合资本构造置信序列 `(L_t, U_t)`，满足 `P(∀t: θ∈[L_t,U_t]) ≥ 1−α`；支持有效早停。多重比较用 e-value 合并或预注册层级检验。报告一律给**下置信界**，禁止只报点估计与「最优种子」。

**定义 320（腕部视觉探针 WVP）** 用腕部近距视频构造非接触探针：滑移 `g_slip`（接触区光流残差）、接触 `g_contact`（形变/遮挡边界）、深度 `g_depth`（散焦/视差）。增广动作 `g_vis ⊆ g_probe`，成本 `c(g_vis) < c(g_force)`。失效面：自遮挡率 `p_occ`、模糊、污渍、反光/透明。定义净收益条件见引理 21。

**定义 321（证书 J_PROBE）** `J_PROBE = (J_FLUID, ECI, β_VoI, ECE_VoI, IC, LG, GG, EI, cs_alpha, probe_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ ECI ≤ τ_eci（否则 FMA 已禁用且回退 R68） ∧ 评测在预注册协议下通过置信序列下界`。

**定义 322（评测-部署信息隔离）** 基准的隐藏因子、canary 标签、do-计划在策略推理时不可见；策略只能看到 `o_t` 与自身动作历史。任何「知道自己在被哪种干预测试」的通道都视为泄漏并按 LEA 审计。

**定义 323（交互预算的重定义：执行即信息）** 因腕部相机随动作运动，任务动作本身携带信息。定义单位动作信息量 `ι(a_t) = I(M; O^w_{t+1} | O^w_t, a_t)`。若 `ι(a_t)` 超过阈值且该任务动作仍满足任务/安全约束，则允许将其**计入信息动作预算**（exploration subsidy），避免 R69 把「看」与「做」重复计费或漏计。

**定义 324（退化与兼容）** 若 ECI ≤ τ_eci、β_VoI 可信、且不启用 COR/LEA/ADV-B（即只做在线部署、不做干预评测），PROBE-RAS 逐指令等于 FLUID-RAS。故 FLUID-RAS = PROBE-RAS 在「证据已被证明独立 + 评测退化为观察」边界上的特例；R68 再是其「永不交互」特例。安全侧单调不弱。

**定义 325（失效模式分类与安全降级）** 四类：ECI 越界（证据污染）、重放不可信（ε_r 过大）、基准泄漏/Goodhart（GG 超阈）、视觉探针失效（p_occ 超阈）。任一触发对应降级：禁用 FMA → ADL；禁用 ADL → R68；禁用干预评测 → 仅报告观察性结果并标注不可因果；禁用视觉探针 → 物理探针或 R69 兜底。

**定义 326（本轮结论对象）** 输出三件套：`(a) 前四轮结论在 PROBE-Bench 下的条件化重述（哪些成立、依赖哪些前提）；(b) PROBE-RAS 的独立性与降级证明；(c) 可复现的基准协议（预注册、隐藏因子、anytime-valid 报告）。`

## 2. 关键算法骨架

```python
# IP-264/265 WAM + ECI：估计动作对腕部观测/证据的自条件化程度
def estimate_eci(action_hist, wrist_obs, drift_probe, evidence):
    # 用轻量预测器拟合 o^w ≈ f(a_hist) 与 e ≈ g(a_hist)，残差用于 MI 估计
    kappa = nmi(predict(wrist_obs, action_hist), wrist_obs)
    # 证据的条件互信息：外部漂移 vs 动作历史
    eci   = 1.0 - cond_mi(evidence, drift_probe, given=action_hist) \
                  / max(mi(evidence, drift_probe), EPS)
    return clip(eci, 0.0, 1.0), kappa

# IP-266 COR：在固定场景下只改“看的方式”做反事实重放
def counterfactual_replay(scene, o_t, plan):
    outs = []
    for p in plan.poses:            # do(p_wrist = p)
        for d in plan.he_drift:    # do(T_he = T0 + d)
            outs.append(render(scene, p, T_he=T0_plus(d),
                               intr=plan.intr, light=plan.light))
    return outs                    # ≈ 观测族 O^cf，用于干预评测

# IP-267 ADL：动作解耦的行为似然（修补 R69 FMA 的独立性前提）
def adl_second_opinion(policy, xi_obs, o, o_cal, eci):
    if eci <= TAU_ECI:
        return policy.flow_anomaly(xi_obs, o, o_cal)          # 原 FMA 可信
    o_adl, o_adl_cal = canonical_replay(o), canonical_replay(o_cal)
    if o_adl is None:
        return DISABLED                                        # 回 R68
    return abs(-policy.log_likelihood(xi_obs, o_adl)
               + policy.log_likelihood(xi_obs, o_adl_cal))

# IP-268 VCB：VoI 校准（预测增益 vs 实测增益）
def voi_calibration(pairs):        # pairs: [(voi_hat, voi_realized), ...]
    beta = cov(pairs) / var(voi_hats(pairs))
    ece  = mean(abs(mean_realized_by_bin - mean_hat_by_bin))
    return beta, ece                    # 可信 ⇔ |beta-1| 小 且 ece ≤ τ_v

# IP-269 LEA：遮蔽 + Shapley + identity-swap 检测腕部捷径
def leakage_audit(policy, bench):
    sr = {U: eval_success(policy, bench, modalities=U)
          for U in powerset(['wrist','global','proprio','lang'])}
    shapley = {m: shapley_value(sr, m) for m in sr[ALL]}
    shortcut = (shapley['wrist'] > TAU_SHAP)
                and eval_success(policy, bench, do_identity_swap=True) < TAU_SHORTCUT
    return sr, shapley, shortcut

# IP-270 ADV-B：公开集 vs 隐藏因果因子 / canary
def goodhart_gap(policy, bench):
    return (eval_success(policy, bench, factors=PUB)
            - eval_success(policy, bench, factors=PUB | HIDDEN))

# IP-271 CS：anytime-valid 置信序列（e-value 混合资本）
class ConfidenceSequence:
    def __init__(self, alpha): self.capital = 1.0; self.alpha = alpha
    def update(self, reward01):
        self.capital *= (1 + self.alpha * (2*reward01 - 1))
        return (self.capital, 1/self.capital)   # 有效停时下仍覆盖

# IP-274 主闭环：R69 + 独立性门控 + 视觉探针 + 记分卡
def PROBE_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    eci, _ = M.eci.estimate(M.action_hist, o.wrist, M.drift_ref, M.last_evidence)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    # 第二意见先过 ECI 门控：污染则改 ADL，仍不可用则禁用（回 R68）
    a_hat = M.adl.second_opinion(M.fmp, M.last_action, o, o.calibrated, eci)
    slow  = (a_hat is not DISABLED) and (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)

         if (U_epi > TAU_EPI and not slow) else None)
    if g is not None and g.kind == 'visual' and M.wvp.occlusion_risk(o) > TAU_OCC:
        g = M.mint.fallback_probe(modes, o, M.budget)
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 评测日志：ECI、ADL 分、VoI 预测/实测、是否走降级
    M.scorecard.log(eci=eci, a_hat=a_hat, voi_hat=g.voi if g else 0.0,
                    degraded=(a_hat is DISABLED))
    return k, lam, mode, (U_ale, U_epi)
```

## 3. 推导

**引理 19（自条件化对行为似然的遮蔽）** 设腕部相机策略在训练中学到把目标保持在观测构型 `o^w_*` 附近（如居中、固定尺度），即存在一个视图镇定回路，使 `‖o^w(p^w_t(s,δ)) − o^w_*‖ ≤ ρ‖δ‖`，`ρ<1` 为其增益。手眼漂移 δ 进入后，策略通过改变动作使腕部视图回到 `o^w_*`，则行为似然的漂移增量满足 `E[Δa | δ] ≤ L·(1−ρ)‖δ‖ + √(trΣ_flow)`。当 `ρ→1`（强居中策略），`Δa→0` 而真实误差随 δ 增大。**故在腕部相机闭环中，R69 的「(r_res↓, Δa↑) ⇒ 缓变故障」不再必然成立**：FMA 的独立性前提 `ECI(a_score)≈0` 被违反；必须改用 ADL 或门控禁用。

**引理 20（do(pose) 干预的可识别性）** 在固定场景 s 下，若 COR 重放与真实干预分布的误差有界 `ε_r`，且策略/风险泛函关于观测的 Lipschitz 常数为 L_r，则对任意两个腕部位姿干预 `p, p'`，`|R̂(do(p)) − R(do(p))| ≤ L_r ε_r`；当真实干预效应差 `|R(do(p)) − R(do(p'))| > 2L_r ε_r` 时，**干预排序与真实排序一致**。故腕部相机把「成功率相关性评测」升级为「条件下的因果排序」，其有效性由 `ε_r` 显式标定。

**引理 21（视觉探针替换的净收益）** 以视觉探针替代物理探针，降低交互成本 `Δc > 0`，但引入自遮挡/反光导致的假接触率 `p_occ` 与假阴性。设假阳性的风险代价为 `r_fp`，则替换的期望 VoI 净收益 `ΔU = Δc − p_occ·r_fp + (1−p_occ)·Δinfo`；当 `p_occ < p* = (Δc + Δinfo)/(r_fp + Δinfo)` 时净收益为正。**更便宜 ≠ 更安全**：透明/反光物体上 `p_occ` 可越界，须回退物理探针。

**引理 22（标量排行榜的选择偏差）** 若 N 个策略在同一测试集上按经验成功率选优、且各自观测含均值无关的噪声，则被选中者的真实成功率期望低于其公布值的量随 N 与噪声方差单调增大（winner's curse）。任何按「看结果再决定跑多久/报哪个种子」产生的点估计都不是无偏的；只有预注册 + anytime-valid 置信序列能控制假阳性。**这把「评测基准」本身变成一个需要证明的统计对象。**

**定理 18（ECI 门控的 ADL 恢复第二意见，且严格包含 R69）** 在 A99–A101（视图镇定增益有界、重放保真度有界、门控阈值经校准）下：(i) 当 `ECI ≤ τ_eci` 时沿用原 FMA，其漂移敏感性下界 `s₀>0` 保持；(ii) 当 `ECI > τ_eci` 时改用 ADL，漂移敏感性下界由 `L_z·inf_p‖o^ADL−o^ADL_cal‖ − √(trΣ_flow)` 给出，不再被策略动作抵消；(iii) 若 ADL 也不可用，禁用第二意见并令 `λ←max(λ, 0.8)`、`k←k_cal_shrink`，即回 R68。因此 **PROBE-RAS 的安全侧逐指令不弱于 FLUID-RAS，且 FLUID-RAS 是其在 `ECI≤τ` 且评测退化为观察时的特例。**

**定理 19（基准的 Goodhart/泄漏上界与不可欺条件）** 设公开基准与含隐藏因果因子 F_hid 的真实风险差为 GG，canary 集与主集的分布差为 GG_can，泄漏导致的腕部捷径增益为 LG。则任何仅凭公开集报告的性能提升 `Δ̂` 满足 `Δ_true ≥ Δ̂ − (GG + GG_can + LG)`。若隐藏因子覆盖了影响部署的主要因果变量、且采用预注册与 anytime-valid 置信序列，则在水平 α 下「宣称提升而真实不提升」的概率 ≤ α。**基准的可靠性 = 隐藏因子覆盖率 × 统计有效性，而不是测试集大小。**

**定理 20（VoI 校准 ⇔ 交互的风险单调性；失准则交互可能有害）** 若 `β_VoI = 1` 且 `ECE_VoI ≤ τ_v`，则对任意状态，选择 `VoI(g)−c(g)>0` 的交互使期望风险不增；若 `β_VoI < 1`（系统性高估信息增益），则存在状态使交互后的期望风险严格大于不交互，且随 `v̂` 增大而无界放大。这形式上证明了 R69 的直觉——**「问错，比不问更危险」不是修辞，而是 VoI 失准的必然结果**；PROBE-RAS 用 `β_VoI` 把它变成一个可测、可门控的量。

**定理 21（视觉探针交互的安全性）** 在引理 21 的净收益条件与 R69 的 C-RAS-WM 认证下，视觉探针的物理风险 ≤ ε_int（非接触，天然低于物理探针）；其认识论风险由 `p_occ` 与假接触率刻画，`p_occ > p*` 时自动回退物理探针。故视觉探针把「更便宜的交互」建立在显式的失效条件上，而非隐含的乐观假设。

**定义 311–312（WAM 与 ECI）** 腕部观测 `o^w=h(a_{<t},s)`；耦合强度 `κ=NMI(A;O^w|S)`。`ECI(e)=1−I(E;S⊕drift|A)/I(E;S⊕drift)`；`ECI>τ_eci ⇒ e 不得单独作为独立性证据`。

**定义 313–314（COR 与 ADL）** `do(p_wrist=p₀)` 等干预在固定 s 下只改观测方式，重放保真度 `ε_r`；ADL 在 `o^ADL`（规范位姿重放或全局相机）上算似然。ECI≤τ 用原 FMA；否则 ADL；再否则禁用并回 R68。

**定义 315（PROBE-Bench 记分卡）** 输出向量 `S=(SR,SV,ECE,β_VoI,IC,LG,φ_sensor,GG,C_int,EI)`；仅定义 Pareto 偏序与预注册加权敏感性分析，**不提供无约束单一综合分**（防止 Goodhart）。

**定义 316（VCB）** 记录每次交互的 `v̂=VoI(g)` 与实测 `v=H(M|o)−H(M|o,y)`；`β_VoI`、`ECE_VoI` 判可信。R69「交互越多越好」仅在此条件下成立。

**定义 317–318（LEA 与 ADV-B）** 遮蔽模态子集求 `SR(U)` 与 Shapley；`identity-swap` 只改腕部图内身份/颜色判捷径；隐藏因果因子 F_hid（质量/摩擦/间隙/柔性/接触延迟）+ canary + 定期轮换，度量 `GG`、`GG_can`。

**定义 319（CS）** 预注册主终点；e-value/混合资本构造 `(L_t,U_t)`，`P(∀t:θ∈[L_t,U_t])≥1−α`；报告给下置信界，禁止「最优种子」。

**定义 320（WVP）** 腕部近距视频构造 `g_slip/g_contact/g_depth`，成本低于物理探针；失效面自遮挡/模糊/污渍/反光/透明。净收益条件见引理 21。

**定义 321–326（证书/隔离/预算/退化/降级/结论对象）** `J_PROBE` 并入独立性、校准、泄漏、Goodhart 与统计参数；评测-部署信息隔离；执行即信息（`ι(a_t)` 可计入信息预算）；满足条件时逐指令退化 FLUID-RAS；四类失效对应降级树；输出「条件化重述 + 独立性证明 + 可复现协议」。

```python
# IP-264/265 WAM + ECI
def estimate_eci(action_hist, wrist_obs, drift_probe, evidence):
    kappa = nmi(predict(wrist_obs, action_hist), wrist_obs)
    eci   = 1.0 - cond_mi(evidence, drift_probe, given=action_hist) \
                  / max(mi(evidence, drift_probe), EPS)
    return clip(eci, 0.0, 1.0), kappa

# IP-266 COR：固定场景，只改“看的方式”
def counterfactual_replay(scene, plan):
    return [render(scene, p, T_he=T0_plus(d), intr=plan.intr, light=plan.light)
            for p in plan.poses for d in plan.he_drift]

# IP-267 ADL：修补 R69 FMA 的独立性前提
def adl_second_opinion(policy, xi_obs, o, o_cal, eci):
    if eci <= TAU_ECI:
        return policy.flow_anomaly(xi_obs, o, o_cal)
    o_adl, o_adl_cal = canonical_replay(o), canonical_replay(o_cal)
    if o_adl is None:
        return DISABLED                            # 回 R68
    return abs(-policy.log_likelihood(xi_obs, o_adl)
               + policy.log_likelihood(xi_obs, o_adl_cal))

# IP-268 VCB：VoI 校准
def voi_calibration(pairs):
    return cov(pairs) / var(voi_hats(pairs)), ece_by_bin(pairs)

# IP-269 LEA：遮蔽 + Shapley + identity-swap
def leakage_audit(policy, bench):
    sr = {U: eval_success(policy, bench, modalities=U)
          for U in powerset(['wrist','global','proprio','lang'])}
    shapley = {m: shapley_value(sr, m) for m in sr[ALL]}
    shortcut = (shapley['wrist'] > TAU_SHAP) and \
               (eval_success(policy, bench, do_identity_swap=True) < TAU_SHORTCUT)
    return sr, shapley, shortcut

# IP-270 ADV-B
def goodhart_gap(policy, bench):
    return (eval_success(policy, bench, factors=PUB)
            - eval_success(policy, bench, factors=PUB | HIDDEN))

# IP-271 CS：anytime-valid 置信序列
class ConfidenceSequence:
    def __init__(self, alpha): self.capital, self.alpha = 1.0, alpha
    def update(self, reward01):
        self.capital *= (1 + self.alpha * (2*reward01 - 1))
        return self.capital, 1.0 / self.capital

# IP-274 主闭环
def PROBE_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    eci, _ = M.eci.estimate(M.action_hist, o.wrist, M.drift_ref, M.last_evidence)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    a_hat = M.adl.second_opinion(M.fmp, M.last_action, o, o.calibrated, eci)
    slow  = (a_hat is not DISABLED) and (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    g = (M.mint.choose_interaction(modes, o, M.budget, probe=M.wvp)
         if (U_epi > TAU_EPI and not slow) else None)
    if g is not None and g.kind == 'visual' and M.wvp.occlusion_risk(o) > TAU_OCC:
        g = M.mint.fallback_probe(modes, o, M.budget)
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.scorecard.log(eci=eci, a_hat=a_hat, voi_hat=(g.voi if g else 0.0),
                    degraded=(a_hat is DISABLED))
    return k, lam, mode, (U_ale, U_epi)
```

## 4. 推导

**引理 19（自条件化对行为似然的遮蔽）** 若策略学到视图镇定，使 `‖o^w(p^w_t(s,δ))−o^w_*‖ ≤ ρ‖δ‖`，则 `E[Δa|δ] ≤ L(1−ρ)‖δ‖ + √(trΣ_flow)`。强居中（ρ→1）时 `Δa→0` 而真实误差随 δ 增大：**R69 的 `(r_res↓,Δa↑)` 判据在腕部闭环中不再必然成立**，除非 ECI 低或改用 ADL。

**引理 20（do(pose) 可识别性）** 固定场景下若重放误差 ≤ ε_r、风险泛函 L_r-Lipschitz，则 `|R̂(do(p))−R(do(p))| ≤ L_r ε_r`；当真实干预效应差 > 2L_r ε_r 时干预排序一致。腕部相机因此把相关性评测升级为条件下的因果排序。

**引理 21（视觉探针净收益）** `ΔU = Δc − p_occ·r_fp + (1−p_occ)·Δinfo`；当 `p_occ < p* = (Δc+Δinfo)/(r_fp+Δinfo)` 时替换为正收益；透明/反光物体越界时回退物理探针。

**引理 22（排行榜选择偏差）** 在共享测试集上按经验成功率选优，被选中者公布值高于真实值的量随候选数 N 与噪声方差单调增大（winner's curse）；预注册 + anytime-valid CS 是控制假阳性的必要条件。**评测基准本身是统计对象。**

**定理 18（ECI 门控的 ADL 恢复第二意见，且严格包含 R69）** A99–A101 下：(i) `ECI≤τ_eci` 沿用 FMA，漂移敏感性下界 `s₀>0`；(ii) `ECI>τ_eci` 改用 ADL，敏感性由动作解耦观测的位移给出，不被策略动作抵消；(iii) ADL 不可用则禁用第二意见、`λ←max(λ,0.8)`、`k←k_cal_shrink`（回 R68）。故 PROBE-RAS 安全侧逐指令不弱于 FLUID-RAS；FLUID-RAS = 其「ECI≤τ 且评测退化为观察」特例。

**定理 19（Goodhart/泄漏上界与不可欺条件）** `Δ_true ≥ Δ̂ − (GG + GG_can + LG)`；若 F_hid 覆盖部署主要因果变量且采用预注册 + anytime-valid CS，则「宣称提升而真实不提升」的概率 ≤ α。**基准可靠性 = 隐藏因子覆盖率 × 统计有效性**，不是测试集大小。

**定理 20（VoI 校准 ⇔ 风险单调；失准则交互有害）** `β_VoI=1 ∧ ECE_VoI≤τ_v ⇒ 选 VoI(g)>c(g) 的交互使期望风险不增`；若 `β_VoI<1`（系统性高估），存在状态使交互后风险严格增大且随 v̂ 无界放大。R69 的「问错比不问更危险」被形式化为 VoI 失准的必然结果，并由 `β_VoI` 可测、可门控。

**定理 21（视觉探针交互安全性）** 在引理 21 净收益条件与 C-RAS-WM 认证下，物理风险 ≤ ε_int（非接触，低于物理探针）；认识论风险由 p_occ 与假接触率刻画，越界自动回退。**更便宜不等于更安全，但失效条件是显式的。**

## 7. 本轮最大风险

**一句话**：PROBE-Bench 的全部因果解释力都押在「`do(pose)` 重放是忠实的」这一前提上——**若数字孪生/重渲染的 sim-to-real 误差 ε_r 与被测系统真实误差同量级，这把尺子就会精确地量出一个并不存在的因果世界；更糟的是，一旦基准成为优化目标，策略会学会迎合尺子（Goodhart），R70 就从「防止自欺」退化为「自欺的自动化」**。

**次级风险与缓解**：ECI 估计不校准（人工注入实验标定 + 可证界，E302/E311）；视觉探针在透明/反光物上高置信出错（p_occ 越界回退物理探针，E307）；隐藏因子覆盖不全致 GG 低估（失效模式驱动的因子清单 + 轮换，E308/E314）；anytime-valid 降功效（预注册主终点 + 分层检验，E309）；评测本身变成无人审计的新黑箱（协议开源 + 独立复现，E315）。
