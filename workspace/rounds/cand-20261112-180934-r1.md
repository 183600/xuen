# 第 62 轮（承接第 61 轮「具身语义进化闭环」ESEC/IP-173~182；灵感循环第 1 轮；本轮灵感：「放置」×「数据配比」）

> 第 61 轮把系统从「模块拼接」推进到「表征对齐」：USR 统一场景/意图/阻抗/证据，MEL 提供零样本物理先验，DMS 接地多轮对话，SRT-Dual 解耦语义与实时。但它在「放置」这一最基础、最苛刻的操作上暴露四个硬伤：
> 1. **放置不可供性**：USR 编码了「这是什么场景/意图」，却没有编码「可以放在哪、能放多准、放完稳不稳」——支撑面、容器内腔、间隙/公差、堆叠稳定性、朝向可达性都不在表征里。MEL 能说「这是玻璃、易碎」，却不能说「这块玻璃只能以 0.8mm 间隙插入左侧凹槽，重心投影须落在支撑多边形内 60%」。
> 2. **放置是相位过程，不是阻抗点**：第 61 轮 Π: ℝ^d_us → K_safe 输出单个阻抗点，而放置有 approach→align→seat→release 四相位；同一 K 在接近相位太硬、在就位相位太软，点投影把相位语义抹平。
> 3. **数据配比盲区**：PCE+++++ 只有「认知预算」，没有「数据预算」。MEL 的零样本偏见（如低估摩擦）不是模型结构问题，而是训练数据在「放置流形」上的覆盖空洞；系统从不记录「哪类放置失败最多、该补哪类数据、仿真/真实/合成按什么比例补」。
> 4. **失败不回流为数据策略**：ESEC 的 EV-exec 只用于在线约束调整与证书，从不把失败坐标写回数据混合器；于是同一个「深凹槽+低摩擦+遮挡」失败可以在几十次任务中重复出现，而数据引擎毫无感知。

## 0. 直觉与动机

**灵感 1（放置 → 放置可供性与公差表征 PATR）**
直觉：人类说「放得下吗」时，脑中不是一张物体分类标签，而是一个**约束几何场**：支撑面在哪、容器口多大、最小间隙多少、重心落在哪、倾斜多少会倒。关键洞见：把放置从「目标位姿 g」升级为**放置可供性-公差张量** `P = (S_sup, C_con, τ_gap, m_stab, Ω_orient, z_phase)`，并用放置 token 集编码进第 61 轮的 USR。这样「放置约束」与「场景/意图/阻抗/证据」在同一个 ℝ^d_us 中可运算，Π 不再只看到「意图像什么」，而能看到「目标孔有多深、多窄、多滑」。

**灵感 2（放置相位 → 相位条件阻抗调度 PCIS）**
直觉：放置像「插钥匙」：先松手探入、再横向对中、再轴向压入、最后释放回弹。每一相位需要完全不同的刚度/阻尼各向异性。关键洞见：把单点投影 Π 升级为 **Π_place: (p_emb, z_phase) → K_phase(t)**，并显式约束各相位：
- `approach`：低法向刚度、高阻尼、大旋转柔顺（防碰撞）；
- `align`：低横向刚度、较高轴向刚度（自对中）；
- `seat`：高轴向刚度 + 力上限 + 低横向刚度（吸收公差）；
- `release`：法向力斜坡卸载（防回弹/掉落）。
相位由接触证据与 PATR 间隙共同推断，形成「相位状态机 + 阻抗调度表」。

**灵感 3（数据配比 → 放置流形上的数据混合 PMDM）**
直觉：数据配比不是「全局一个 sim:real 比例」，而是**在放置流形每个单元上分别配比**。关键洞见：定义放置流形 `M = Z_gap × Z_mat × Z_occ × Z_geo × Z_dyn × Z_phase`，把每条数据（仿真/真实/合成/示教/失败回放）投影到单元 c；数据混合 π(c) ∈ Δ^{K-1} 是**单元条件**的。失败证据给出「误差密度」ν(c)，覆盖计数给出「数据密度」μ_π(c)；数据配比要做的，是把数据质量**搬运**到误差密度高的单元——这正是最优传输。

**灵感 4（双关同构 → 「数据放置」与「物体放置」同构）**
直觉：物体放置 = 把物体放到目标位姿且满足间隙/稳定约束；数据放置 = 把各数据源的「质量」放到单纯形上且满足覆盖/成本约束。二者同构：目标分布是「孔」，数据源是「待放置物」，混合比例是「位姿」，覆盖证书是「就位判据」，成本是「接触力」。关键洞见：**用放置的语言重写数据配比**——定义放置-数据传输距离 `W₂(μ_π, ν)`；当 `W₂ ≤ τ_seat` 时称数据「就位」；数据空洞就是「没放进去的孔」。这让两个灵感词不是并列，而是同一数学结构的两个实例。

**灵感 5（协同进化 → 放置-数据协同进化闭环 PADEL + 数据预算）**
直觉：放置失败 → 定位流形单元 → 判断是「模型不会」还是「数据没覆盖」→ 选择数据获取动作（多仿真/多真实/合成/示教）→ 配比优化 → 重训 → 影子部署 → 回填证据。关键洞见：把 DMS 的「澄清」扩展为**数据澄清**（「我需要 20 条深凹槽低摩擦的真实放置示教，是否采集？」），把 PCE+++++ 扩展为 **PCE++++++：B_data = (样本预算, sim/real 成本, 采集时延, 配比熵下限, 重训预算)**。数据配比成为与实时控制同级的闭环控制量，而非离线超参。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（放置可供性与公差表征 PATR）** 对物体 o 与支撑/容器 U，放置可供性-公差张量定义为
`P(o,U) = (S_sup, C_con, τ_gap, m_stab, Ω_orient, z_phase)`，其中：
- **支撑场** `S_sup: X×Y → [0,1]`：候选落点 $(x,y)$ 处存在稳定支撑面的概率；
- **包容场** `C_con: X → [0,1]`：点 $x$ 位于容器内腔/凹槽的概率；
- **间隙场** `τ_gap(x,d) ∈ ℝ_{≥0}³`：物体沿方向 $d=(d_x,d_y,d_z)$ 放入时，到最近障碍的三向最小间隙；
- **稳定裕度** `m_stab(g) ∈ [0,1]`：目标位姿 g 下重心投影到支撑多边形边界的归一化距离；
- **朝向可行集** `Ω_orient(g) ⊆ SO(3)`：不产生侧翻/自碰撞/奇异的目标朝向集合；
- **接触相位** `z_phase ∈ {approach, align, seat, release, retreat}`；
- **放置 token 集** `P_tok = {(x_i, s_i, c_i, τ_i, m_i, ω_i, z_i)}_{i=1}^{N_p}`，经编码器 `E_place: P_tok → p_emb ∈ ℝ^{d_us}`；
- **放置成功判据**：位置误差 `‖p−g‖ ≤ τ_pos` ∧ 姿态误差 `≤ τ_ang` ∧ `m_stab(g) ≥ m₀` ∧ 接触力 `≤ F_safe` ∧ 释放后位移 `≤ τ_drift`。

**定义 174（放置流形 M 与流形单元）** `M = Z_gap × Z_mat × Z_occ × Z_geo × Z_dyn × Z_phase`，各维离散化为若干 bin，笛卡尔积得到单元集 `C`；每个放置任务（及其失败证据）映射到唯一单元 `c ∈ C`。部署任务分布记为 `q(c)`；第 k 个数据源在单元上的经验分布为 `μ_k(c)`；单元条件混合为 `π(c) ∈ Δ^{K−1}`；有效覆盖为 `n_eff(c;π) = N · Σ_k π_k(c) μ_k(c)`。

**定义 175（相位条件阻抗调度 PCIS）** 阻抗调度为
`σ = (K_p^⊥(z_phase), K_p^∥(z_phase), K_d(z_phase), K_o(z_phase), F_max(z_phase), v_max(z_phase))`，
由 `Π_place(p_emb, z_phase) → K_phase` 生成。相位转移带滞回护栏：
- `approach→align`：`min_d τ_gap ≤ δ_a`；
- `align→seat`：`‖e_lat‖ ≤ ε_lat` ∧ `F_n ∈ [F_seat^lo, F_seat^hi]`；
- `seat→release`：`F_axial ≥ F_seat` ∧ 位移平台期 `|Δx| ≤ ε_plateau`；
- `release→retreat`：`F_n ≤ F_release`；
- **安全不变式**：对任意相位，`F_n ≤ F_max(z_phase)` 且 `F_max` 关于相位单调不增（seat 之后只减不增）。

**定义 176（放置误差密度 ν 与数据空洞 H）** 对单元 c 与失败模式 `m ∈ {slip, tilt, jam, drop, collision, misalign}`，定义归一化损失
`ℓ(c) = E[1−success + λ_f·sat(F_exceed) + λ_s·slip + λ_t·tilt + λ_d·drop]`。
用带遗忘因子的 Beta/Dirichlet 后验维护 `ν_t(c)`，并以置信上界 `ν_ucb(c)` 判定空洞：
`H = { c ∈ C : ν_ucb(c) ≥ θ_err ∧ n_eff(c) ≤ θ_cov }`。
只有**上界**超过阈值的数据空洞才值得采集，避免把偶然失败误判为系统性缺陷。

**定义 177（数据源池与单元条件配比单纯形）** 数据源池
`D = {D_k}_{k=1}^{K}`，典型 K=7：sim-rigid、sim-deformable、real-rigid、real-deformable、synthetic、human-demo、failure-replay。
单元条件配比 `π(c) ∈ Δ^{K−1}`，满足 `π_k(c) ≥ π_min`（安全关键源保底）、`H(π(c)) ≥ H_min`（探索下限）、`Cost(π) = Σ_c w(c) Σ_k π_k(c)·(c_k^sample + c_k^acquire + α·c_k^train) ≤ B_data`。

**定义 178（放置-数据最优传输 PDT）** 令 `μ_π = Σ_k ∫ π_k(c) μ_k(c) dc` 为数据覆盖测度，`ν` 为归一化误差密度。数据配比写成一个熵正则最优传输问题：
`π* = argmin_π W₂²(μ_π, ν) + λ·Cost(π) − β·H(π)`，s.t. 覆盖与成本约束；
当 `W₂(μ_π, ν) ≤ τ_seat` ∧ `max_c ν_ucb(c) ≤ θ_err` 时称数据**已就位（seated）**。有限单元上可用 Sinkhorn + 单纯形投影交替求解。

**定义 179（放置覆盖证书 PCC）** `PCC = (n_eff(·), ν_ucb(·), W₂(μ_π,ν), H(π), Cost(π), suite_hash, model_hash)`。
验证规则：`Valid(PCC) ⇔ max_c ν_ucb(c) ≤ θ_err ∧ W₂ ≤ τ_seat ∧ min_{c∈C_high} n_eff(c) ≥ ρ`。PCC 与模型版本绑定，部署前必须通过。

**定义 180（数据配比控制器 DMC）** 双层优化：
`min_π L_val(θ*(π)) + λ Cost(π)`，s.t. `θ*(π) = argmin_θ Σ_k Σ_c π_k(c) L_train,k,c(θ)`。
为避免每步重训，用**影响函数/响应代理**估计源-单元梯度对齐 `a_{k,c} = ⟨g_{k,c}, g_val,c⟩`，在单纯形上做指数梯度更新：
`π(c) ← Proj_Δ[ π(c) ⊙ exp(−η(a_{·,c} + λ c_cost − β ∇H)) ]`，再做 `π_min` 下限与归一化。

**定义 181（放置-数据协同进化闭环 PADEL）** 闭环算子：
`execute → evidence+phase → failure taxonomy → update ν → detect H → plan acquisition → re-mix π → retrain (MEL, Π_place) → PCC gate → shadow deploy → promote/rollback`。
其中数据获取动作集 `A_data = {add_sim(c,n), add_real(c,n), add_synth(c,n), add_demo(c,n), add_failure_replay(c), no_op}`。

**定义 182（放置安全部署护盾 PSD）** 新模型 θ′ 的部署门控：
(i) `Valid(PCC(θ′))`；
(ii) 在高风险单元上 `ν_ucb^{θ′}(c) ≤ ν_ucb^{θ_old}(c) + δ_gate`；
(iii) `ERTC.verify(θ′.phase_gain_bounds)`；
(iv) **单元级回退路由**：仅当 `ν_ucb^{θ′}(c) < ν_ucb^{θ_old}(c) − margin` 时该单元用新模型，否则回退旧模型；
(v) 影子运行 N 个 episode 且零安全违规；
(vi) 允许阻抗空间内的凸混合 `K = αK_{θ′} + (1−α)K_{θ_old}` 作为灰度过渡。

**定义 183（PCE++++++ 认知-数据预算 B_cog⋆）** 在第 61 轮六元预算上增加数据与放置两项：
`B_cog⋆ = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_data, B_place)`，其中
`B_data = (N_samples, ratio_bounds, acquisition_latency, train_budget, entropy_floor)`，
`B_place = (τ_tol, trials_per_cell, release_trials, human_confirm_budget)`。
价值函数：`voi⋆ = VOI_meta − cost_cog5 − cost_data − cost_place`。降级：B_data 耗尽 ⇒ 冻结配比、仅用缓存模型；B_place 耗尽 ⇒ 保守放置（放宽容差、降速、请求人类确认）。

**定义 184（零样本放置泛化保证 ZSPG）** 若数据混合 μ_π 在放置流形上构成任务分布 q 的 ε-网，且每个单元的误差上界满足 `ν_ucb(c) ≤ δ`，则对任意 `c ~ q`，以概率 ≥ 1−α 有放置成功率 `≥ 1 − δ − O(L_ℓ·ε)`，其中 L_ℓ 为损失对流形坐标的 Lipschitz 常数。

## 2. 本轮方法总览（从直觉到可执行）

1. **表征层**：在 USR 增加 `E_place`，把支撑/包容/间隙/稳定/朝向/相位编码为 `p_emb`；MEL 的物理先验 φ_phys 与 `p_emb` 共同约束 EEIS 编译。
2. **控制层**：把第 61 轮的单点 `Π` 换成相位条件 `Π_place`；实时流按相位查表 + 轻量 MLP，相位由证据驱动，并受 ERTC 单调力上限保护。
3. **数据层**：所有执行证书携带流形单元坐标 c，回流到误差密度估计器；空洞检测用置信上界而非点估计。
4. **配比层**：把单元条件配比写成一个熵正则最优传输 + 成本约束问题，用指数梯度/影响函数代理求解，避免反复重训。
5. **闭环层**：PADEL 把「数据澄清」接入 DMS，把 PCC/PSD 接入部署；新模型逐单元灰度替换，绝不整包上线。

## 3. 关键不变式（为产物区推导铺路）

- **I1（相位安全）**：相位单调前进且力上限单调不增 ⇒ 不会在 seat 后出现「越压越硬」的力尖峰。
- **I2（数据就位）**：`W₂(μ_π,ν) ≤ τ_seat` 且高风险单元覆盖 ≥ ρ ⇒ 由 Lipschitz 损失，`|E_{μ_π}ℓ − E_νℓ| ≤ L_ℓ·τ_seat`。
- **I3（空洞优先）**：采集应投向「上界高、样本少、单位成本低」的单元；这是对 worst-cell 目标的贪心上界下降。
- **I4（安全部署）**：PSD 保证被提升的模型在每个单元上都不比旧模型差超过 δ_gate，且 ERTC 验证通过，因此「数据变好」不会以「控制变坏」为代价。

## 4. 本轮最大风险

**一句话**：若误差密度 ν(c) 本身是由稀疏、非代表、且被系统选择性观测到的失败估计出来的，那么「按 ν 配比数据」会形成自我强化的测量反馈环——越补越只补「好测的单元」，真实长尾反而被系统性忽略；必须以「配比熵下限 + 分层探索采集 + 独立留出放置套件 + OOD 漂移哨兵 + PSD 单元级回退」把数据闭环钉在可证伪的地面上。

class PlacementAffordanceTolerance:
    def __init__(self, d_us=256, grid=64):
        self.grid = grid
        self.support_net   = SupportFieldNet()
        self.contain_net   = ContainmentNet()
        self.clearance_net = ClearanceNet()
        self.stability_net = StabilityNet()
        self.orient_net    = OrientationNet()
        self.encoder       = PlacementTokenEncoder(d_us)

    @torch.no_grad()
    def build(self, depth, seg, obj_mesh, scene_emb, phys_prior):
        S  = self.support_net(depth, seg, scene_emb)          # [H,W] ∈ [0,1]
        C  = self.contain_net(depth, seg, obj_mesh)           # [H,W] ∈ [0,1]
        tau= self.clearance_net(depth, obj_mesh, C)           # [H,W,3] ≥ 0
        m  = self.stability_net(obj_mesh, S, C, phys_prior)   # [H,W] ∈ [0,1]
        Om = self.orient_net(obj_mesh, S, phys_prior)         # [H,W,6] 6D 旋转候选
        tokens = tokenize(S, C, tau, m, Om, grid=self.grid)
        p_emb = self.encoder(tokens)                          # [d_us]
        return PATRState(S, C, tau, m, Om, p_emb)

    def check_success(self, EV, g, tau_pos, tau_ang, m0):
        return (EV.pose_err <= tau_pos and EV.ang_err <= tau_ang
                and EV.m_stab >= m0 and EV.f_max <= EV.F_safe
                and EV.drift_after_release <= EV.tau_drift)

    def min_gap(self, axis='approach'):
        # 沿接近方向的最小三向间隙，供相位状态机使用
        return self.tau[:, :, AXIS_IDX[axis]].min()

### IP-185 PCIS（相位条件阻抗调度）

```python
PHASES = ['approach', 'align', 'seat', 'release', 'retreat']

class PhaseConditionedImpedance:
    def __init__(self, d_us=256, ertc=None,
                 delta_a=0.01, eps_lat=0.002, F_seat=8.0, F_release=1.0):
        self.heads = {p: PhaseGainHead(d_us) for p in PHASES}
        self.ertc = ertc
        self.delta_a, self.eps_lat = delta_a, eps_lat
        self.F_seat, self.F_release = F_seat, F_release
        self.F_max_prev = float('inf')

    def infer_phase(self, patr, EV, prev):
        gap = patr.min_gap('approach')
        if prev == 'approach' and gap <= self.delta_a:
            return 'align'
        if prev == 'align' and EV.lateral_err <= self.eps_lat \
           and self.F_seat * 0.3 <= EV.normal_force <= self.F_seat * 1.5:
            return 'seat'
        if prev == 'seat' and EV.axial_force >= self.F_seat and EV.disp_plateau:
            return 'release'
        if prev == 'release' and EV.normal_force <= self.F_release:
            return 'retreat'
        return prev

    def gains(self, p_emb, phase, phys_prior):
        raw = self.heads[phase](torch.cat([p_emb, phys_prior], dim=-1))
        K = self._constrain(raw, phase, phys_prior)
        self.ertc.assert_phase_bounds(phase, K)      # 越界直接拒绝，不进入执行
        return K

    def _constrain(self, K, phase, phys):
        # 相位可行域投影
        K.Kp_n = clamp(K.Kp_n, *self.ertc.bounds(phase, 'Kp_n'))
        K.Kp_t = clamp(K.Kp_t, *self.ertc.bounds(phase, 'Kp_t'))
        K.Kd   = clamp(K.Kd,   *self.ertc.bounds(phase, 'Kd'))
        # 相位单调力上限：seat 之后只减不增
        if phase in ('release', 'retreat'):
            K.F_max = min(K.F_max, self.F_max_prev)
        else:
            self.F_max_prev = K.F_max
        # 脆性材料软化
        if phys.brittle > TAU_BRITTLE:
            K.Kp_n *= 0.5
        return K
```

### IP-186 DER（误差密度与数据空洞）

```python
class ErrorDensityEstimator:
    def __init__(self, n_cells, kappa=1.64, lf=0.5, ls=0.4, lt=0.3, ld=0.6):
        self.alpha = np.full((n_cells, N_MODES), 0.5)
        self.beta  = np.full((n_cells, N_MODES), 0.5)
        self.count = np.zeros(n_cells)
        self.kappa, self.lf, self.ls, self.lt, self.ld = kappa, lf, ls, lt, ld

    def update(self, cell, EV):
        mode = classify_failure(EV)   # slip/tilt/jam/drop/collision/misalign/ok
        loss = (1.0 - float(EV.success)
                + self.lf * sat(EV.f_exceed)
                + self.ls * float(EV.slip)
                + self.lt * float(EV.tilt)
                + self.ld * float(EV.drop))
        loss = float(np.clip(loss, 0.0, 1.0))
        self.alpha[cell, mode] += loss
        self.beta[cell, mode]  += (1.0 - loss)
        self.count[cell] += 1

    def ucb(self, cell):
        a = self.alpha[cell].sum()
        b = self.beta[cell].sum()
        mean = a / (a + b)
        std  = np.sqrt(a * b / ((a + b) ** 2 * (a + b + 1.0)))
        return float(np.clip(mean + self.kappa * std, 0.0, 1.0))

    def detect_holes(self, coverage, theta_err=0.30, theta_cov=50):
        holes = []
        for c in range(self.alpha.shape[0]):
            if self.ucb(c) >= theta_err and coverage.n_eff(c) <= theta_cov:
                holes.append(DataHole(cell=c, nu_ucb=self.ucb(c),
                                      n_eff=coverage.n_eff(c),
                                      dominant_mode=self.dominant_mode(c)))
        return holes

    def grad_cell(self):
        # 每个单元的下降方向：对当前 ν_ucb 的负梯度近似
        return np.array([self.ucb(c) for c in range(self.alpha.shape[0])])
```

### IP-187/188/189 PMDM + PDT + DMC（配比、传输、控制器）

```python
class PlacementDataMixtureController:
    def __init__(self, K, n_cells, cost_model, budget,
                 lr=0.05, lam=0.5, beta=0.1, pi_min=0.02, H_min=0.10):
        self.K, self.n_cells = K, n_cells
        self.pi = np.full((K, n_cells), 1.0 / K)
        self.cost_model, self.budget = cost_model, budget
        self.lr, self.lam, self.beta = lr, lam, beta
        self.pi_min, self.H_min = pi_min, H_min

    def ot_distance(self, mu, nu, eps=0.01):
        """在放置流形单元图上计算熵正则 2-Wasserstein（Sinkhorn）。"""
        C = self.cell_ground_cost()          # [n_cells,n_cells] 单元间几何距离
        return float(np.sqrt(sinkhorn2(mu, nu, C, eps)))

    def step(self, nu_ucb, cost_vec):
        # 指数梯度：降低高误差密度单元的源权重，抬高高覆盖/低成本源
        reward = np.outer(np.ones(self.K), -nu_ucb)          # [K,n_cells]
        logits = np.log(self.pi + 1e-12) + self.lr * reward
        logits -= self.lr * self.lam * cost_vec[:, None]
        logits += self.lr * self.beta * self._entropy_grad()
        self.pi = softmax(logits, axis=0)
        self.pi = np.maximum(self.pi, self.pi_min)
        self.pi /= self.pi.sum(axis=0, keepdims=True)
        self._enforce_entropy_floor()

    def plan_acquisition(self, holes, batch=32):
        """单位成本上界下降贪心：优先高 ν_ucb × 低 n_eff × 低成本。"""
        items = []
        for h in holes:
            for k in SOURCE_IDS:
                dn = batch
                gain = ucb_reduction(h.n_eff, dn) * h.nu_ucb
                cost = self.cost_model(k, h.cell, dn)
                items.append((gain / max(cost, 1e-9), k, h.cell, dn, cost))
        items.sort(key=lambda x: x[0], reverse=True)
        plan, used = [], 0.0
        for score, k, cell, dn, cost in items:
            if used + cost > self.budget.remaining: 
                continue
            plan.append((k, cell, dn))
            used += cost
        return plan

    def retrain_trigger(self):
        # 只有当 W2 超过 τ_seat 或空洞比例 > ρ_hole 时才触发重训
        return self.w2 > self.tau_seat or self.hole_ratio > self.rho_hole
```

### IP-190 PADEL（放置-数据协同进化闭环）

```python
class PADEL:
    def __init__(self, patr, pcis, mel, usr, eeis, ertc, der, coverage,
                 mixture, shield, budget, heldout_suite):
        self.patr, self.pcis, self.mel = patr, pcis, mel
        self.usr, self.eeis, self.ertc = usr, eeis, ertc
        self.der, self.coverage = der, coverage
        self.mixture, self.shield = mixture, shield
        self.budget, self.heldout_suite = budget, heldout_suite
        self.theta = mel.state_dict()

    def step(self, obs, goal, delta_f_req):
        # 1) 语义流：PATR + MEL 先验
        patr = self.patr.build(obs.depth, obs.seg, obs.obj_mesh,
                               self.usr.scene_emb, self.mel.phys_prior)
        p_emb = patr.p_emb
        # 2) 实时流：相位条件阻抗 + EEIS 编译
        phase = self.pcis.infer_phase(patr, obs.EV, obs.prev_phase)
        K = self.pcis.gains(p_emb, phase, self.mel.phys_prior)
        K_safe = self.eeis.compile(delta_f_req, obs.fused, obs.xi_exec,
                                   obs.Z_env, K, patr)
        EV, cert = self.ertc.dispatch_and_wait(K_safe)
        ok = self.patr.check_success(EV, goal)
        # 3) 失败回流：写入流形单元
        for c, ev in self.label_cells(EV, patr):
            self.der.update(c, ev)
            self.coverage.add(c, ev.source)
        # 4) 空洞检测 + 采集规划
        holes = self.der.detect_holes(self.coverage)
        if holes and self.budget.B_data.remaining > 0:
            plan = self.mixture.plan_acquisition(holes)
            new_data = self.acquire(plan)              # sim/real/synth/demo
            self.coverage.update(new_data)
            self.mixture.step(self.der.grad_cell(), self.mixture.cost_vec())
        # 5) 条件重训 + 证书 + 护盾门控
        if self.mixture.retrain_trigger():
            theta_new = self.retrain(self.mixture.pi)
            pcc = self.build_pcc(theta_new, self.heldout_suite)
            if self.shield.gate(theta_new, self.theta, pcc, self.ertc):
                self.shield.shadow(theta_new, n_episodes=N_SHADOW)
                if self.shield.zero_violation():
                    self.theta = theta_new
                    self.shield.update_router(theta_new, pcc)
        # 6) 数据/放置预算降级
        if self.budget.B_data.exhausted:
            self.mixture.freeze()
        if self.budget.B_place.exhausted:
            self.eeis.set_conservative_mode(speed=0.5, tol_scale=1.5,
                                            require_human_confirm=True)
        return K_safe, EV, cert, ok
```

### IP-191 PSD（放置安全部署护盾）

```python
class PlacementSafetyShield:
    def __init__(self, delta_gate=0.02, margin=0.01, n_high_risk=64):
        self.delta_gate, self.margin = delta_gate, margin
        self.n_high_risk = n_high_risk

    def gate(self, new, old, pcc, ertc):
        if not pcc.valid:
            return False
        if not ertc.verify(new.phase_gain_bounds):
            return False
        for c in self.high_risk_cells:
            if pcc.nu_ucb[c] > old.nu_ucb[c] + self.delta_gate:
                return False
        return True

    def route(self, cell, new, old):
        # 单元级回退：只有显著更优才切换
        if new.pcc.valid and new.nu_ucb[cell] < old.nu_ucb[cell] - self.margin:
            return new
        return old

    def blend(self, K_new, K_old, alpha):
        # 阻抗空间凸混合，灰度过渡，且再次过 ERTC
        K = alpha * K_new + (1.0 - alpha) * K_old
        self.ertc.assert_bounds(K)
        return K
```

## 3. 推导

**推导 1（覆盖-误差上界）** 设单元 c 的损失 `ℓ ∈ [0,1]`，有效样本数 `n_eff(c)`，Rademacher 复杂度 `R_n`。以概率 ≥ 1−α：
`ℓ(c) ≤ ℓ̂(c) + 2R_{n_eff(c)} + sqrt(log(1/α) / (2 n_eff(c)))`。
因此 `ν_ucb` 可作为右侧的可计算代理。补入 Δn 条数据带来的不确定项下降约为
`Δ_c ≈ sqrt(log(1/α)/2) · (1/√n − 1/√(n+Δn))`，
它对 n 单调递减，故数据空洞检测 `n_eff` 小且 `ν_ucb` 大的单元，正是单位样本收益最高处。

**推导 2（放置-数据传输的期望损失界）** 若单元损失 `ℓ: M → [0,1]` 关于流形坐标 `L_ℓ`-Lipschitz，则由 Kantorovich–Rubinstein 对偶：
`|∫ℓ dμ_π − ∫ℓ dν| ≤ L_ℓ · W₁(μ_π, ν) ≤ L_ℓ · W₂(μ_π, ν)`。
于是最小化 `W₂(μ_π,ν)` 是在把数据覆盖测度推向误差密度测度；当 `W₂ ≤ τ_seat` 时，数据分布上的期望损失与误差密度加权损失之差 ≤ `L_ℓ τ_seat`。这与推导 1 的单元上界相乘，得到「覆盖就位 + 单元 UCB 低 ⇒ 泛化放置成功率有下界」的链条。

**推导 3（采集贪心的近似保证）** 设 worst-cell 目标 `F(n) = max_c ν_ucb(c; n_c)`。在 `ν_ucb ≈ a/√n` 的收益递减近似下，向单元 c 增加 Δn 的边际收益为
`ΔF_c ∝ ν_ucb(c) · [1/√n_c − 1/√(n_c+Δn)]`。
按「边际收益 / 单位成本」排序的贪心采集在单调子模近似下获得常数近似（标准 1−1/e 型界）。这给出了 IP-189 中 `plan_acquisition` 的排序依据，也解释了为什么不能只按 `ν_ucb` 排序而必须除以采集成本。

**推导 4（相位力上限的安全性）** 若 `F_max(z_phase)` 在 seat 之后单调不增，且每相位增益被 ERTC 可行域投影，则对任意相位序列 `z_0→…→z_t`，法向力满足 `F_n(t) ≤ F_max(z_t) ≤ F_max(z_{t−1}) ≤ …`，不会出现「就位后继续加硬」的力尖峰；再结合力环的采样保持，得到执行期的力上界不变式。

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PATR | O(H·W·D + N_p·d_us)，GPU ~8–15ms | O(H·W) ≈ 4k floats | 支撑/包容 IoU ≥ 0.85，间隙误差 ≤ 1mm |
| PCIS | O(d_us) 每相位，推理 ~0.1ms | O(5·d_us) | 相位滞回无抖动，增益始终在 ERTC 可行域 |
| DER | O(\|C\|) 更新，单 episode O(1) | O(\|C\|·N_modes) | 后验校准 ECE ≤ 0.05，UCB 覆盖率 ≥ 1−α |
| PMDM/PDT | 离线 O(I·K·\|C\|)；Sinkhorn O(\|C\|²/ε²) | O(\|C\|²) 稀疏图 | 单纯形投影精确；W₂ 单调下降至驻点 |
| PADEL | 重训主导（分钟级），不在实时环 | 同 MEL + 数据缓存 | 每次提升均过 PCC + PSD，安全不退化 |
| PSD | O(\|C_high\|) 门控 + 影子 N episode | O(\|C\|) | 高风险单元不退化；单元级回退零误切换 |

**正确性定理（PADEL-Complete）** 假设 A61–A70 及：
**(A71) PATR**：支撑/包容/间隙/稳定场关于几何与物理参数 Lipschitz，估计误差 ≤ δ_patr。
**(A72) PCIS**：相位转移护栏有滞回，`F_max` 相位单调不增，增益投影到 ERTC 可行域。
**(A73) DER**：失败模式标注可靠，Beta 后验的 UCB 有效（覆盖率 ≥ 1−α）。
**(A74) PDT**：各数据源在正权重单元上满支撑，熵正则 OT 有唯一解。
**(A75) PADEL**：采集动作能在 B_data 内实现请求的单元覆盖；重训收敛到 ε_stationary 驻点。
**(A76) PSD**：留出放置套件与部署分布同分布，ERTC 验证可靠。

则：
1. **放置约束忠实性**：若 PATR 误差 ≤ δ_patr 且投影误差 ≤ ε_proj，则 `K_phase` 满足相位可行域，放置成功率随 `m_stab` 提升而单调不降。
2. **相位安全**：由 A72 与推导 4，执行期力不超相位上限，seat 后无反向加硬，力尖峰概率 ≤ δ_force。
3. **数据配比收敛**：在 A73/A74 下，PMDM 的指数梯度/OT 交替收敛到 ε-最优配比；空洞单元的有效样本数单调增加。
4. **配比-泛化衔接**：若 `W₂(μ_π,ν) ≤ τ_seat` 且 `max_c ν_ucb(c) ≤ δ`，则由推导 1/2，未见放置任务成功率 ≥ `1 − δ − O(L_ℓ τ_seat)`（ZSPG）。
5. **部署安全**：PSD 门控保证被提升模型在每个高风险单元上不差于旧模型超过 δ_gate，且 ERTC 验证通过；单元级回退使「数据改善」不以「控制退化」为代价。
6. **预算安全**：B_data 耗尽冻结配比并回退缓存模型；B_place 耗尽切换保守放置并要求人类确认，不违反实时契约。

## 6. 本轮最大风险

**一句话**：若误差密度 `ν(c)` 是由稀疏、非代表、且被系统选择性观测到的失败估计出来的，那么「按 ν 配比数据」会形成自我强化的测量反馈环——越补越只补「好测的单元」，真实长尾反而被系统性忽略；必须以「配比熵下限 + 分层探索采集 + 独立留出放置套件 + OOD 漂移哨兵 + PSD 单元级回退」把数据闭环钉在可证伪的地面上。
