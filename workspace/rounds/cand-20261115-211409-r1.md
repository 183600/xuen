# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「ROS」×「动作空间」）

> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**把「中间件」从单进程约定升级为可认证的分布式接口，把「动作分块」从域门控升级为动作空间门控**。两个灵感各治 v9 一处软肋：ROS 治「MW 只是单进程手写调度、不可观测不可组合」的集成债；动作空间治 v9 最大风险——`K_eff` 依赖滞后 20 帧的 `Δ_dom`。铁律：任一新组件失效 ⇒ 退回 v9 的域门控 / 进程内执行，严格等价，而非行为漂移。

## 0. 直觉与动机

**灵感 1（ROS → 认证动作协议 + 可观测图）**
直觉：ROS 真正的贡献不是「发消息」，而是三件事：标准接口、晚绑定（late binding）、可自省的计算图。ROS2 的 action 接口（goal/feedback/result/cancel/preempt）几乎就是 v9 动作块的原型，但 ROS2 有两个致命缺口：DDS 无硬实时确定性；QoS 只有 deadline/liveliness 的「尽力」语义，没有「证书」与「中立元」。所以正确姿势不是「用 ROS」，而是**补上 ROS 缺的那一层**：让 action goal 携带块证书与取消上界 `ℓ_cancel`，让 QoS 携带新鲜度证书、失效即注入中立元；同时划红线——50Hz 硬环必须留在同进程零拷贝（component container），ROS 只承担 5Hz 规划、证书分发、遥测与回放。核心创新：**认证动作协议 CAP** + **认证 QoS**。

**灵感 2（动作空间 → 层化证书图集）**
直觉：v9 用 `Δ_dom` 门控块长，但 `Δ_dom` 是「已经发生了什么」的事后统计，有 20 帧滑窗滞后；而**安全只取决于「接下来要执行哪些动作」——这在执行前就已知**。前向模型误差在动作空间里高度异方差：接触/抓取切换处误差爆炸，自由空间平滑段误差很小；把整个动作空间 A 用同一个 β 既浪费又危险。核心创新：**分层动作空间证书图集 ASA**——离散层按 PrimitiveGraph 分层（模式切换 = 误差不连续面），连续层按残差分位树划格；每格有局部 `β_i`、中止模板密度 `ρ_i`、样本数 `n_i`、格内制动动作 `b_i`。块长由**格遍历风险**前馈决定：`K_eff = min(v9 的 K_dom, K_ASA, K_stratum)`。模式切换处强制检查点，使中止点集结构性变密（顺带解决 v9 E553 靠调参的问题）。

**灵感合流**：ROS 的 action 协议给动作块一个可分布、可取消、可回放的外壳；动作空间图集给这个外壳一个**执行前**的可靠证书。二者相乘 = 「分布式但认证、分块但前馈」的 v10。

## 1. 研究问题（轮次升级版）

- **Q1（前馈证书）**：如何在动作空间上构造有限格划分，使格内一致误差界 `β_i` 在高置信下成立，并让 `K_ASA` 的截断点在模式切换处落到合法检查点？格遍历风险的折扣是否需要与制动距离耦合？
- **Q2（分布式认证）**：如何把 v9 的进程内 MW 变成 ROS2 图上可组合的 CAP，同时用取消上界 `ℓ_cancel` 与时钟偏斜 `ε_skew` 把远端执行的安全性折回 v9 引理 82？分区/脑裂时如何保证只过度退化、绝不过度信任？
- **Q3（萎缩悖论）**：当证书本身抑制了低样本格的数据采集，如何保证可用动作空间不随时间单调收缩？抗萎缩采样与周期回放再标定能否给出覆盖非降的可证条件？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 认证动作协议律（Certified Action Protocol, CAP）**
动作块以 ROS2-action 兼容的 goal/feedback/result/cancel/preempt 五元消息分发。每 goal 携带 `(a^{1:K}, Ĉ, P, ℓ_cancel, t_gen, holder)`；取消必须在 `ℓ_cancel` 个控制周期内到达最近合法中止点并转入安全停驻；服务器只接受其自身格表能背书的 goal，否则 REJECTED（客户端退化为 K=1 本地）。取消/抢占语义使 ER 响应可在块内生效。

**P14 分层动作空间证书图集律（Action-space Certificate Atlas, ASA）**
动作空间两层分解：离散层 `A = ⊔_π A_π`（PrimitiveGraph 的原始动作层，切换面即误差不连续面）+ 连续层（每层 A_π 按残差分位树细分格 `A_{π,i}`）。每格存证书 `C_{π,i}=(β_{π,i}, ρ_{π,i}, n_{π,i}, b_{π,i})`。块长由格遍历风险前馈截断；模式切换索引强制进入检查点集；低样本/低中止密度的格不得承载 K>1。

**P15 认证 QoS 与可回放等价律（Certified QoS & Replay）**
消息携带 `(value, t_gen, t_exp, cert, holder)`；消费者强制新鲜度 `t−t_gen ≤ τ_fresh`、截止期、以及 liveliness 心跳 `≤ ℓ_bond`；任一失败即注入陈旧中立元 `v^⊥_stale`（50Hz 决策端口取保守单步 fallback）。证书采用 `durability=transient_local` 以支持 late-join 的安全监视节点。所有 CAP 消息、证书、时钟与门控决策写入 rosbag2，要求同输入**逐位复现**门控/退化序列（将 v9 引理 83 从「可观测等价」强化为「可回放等价」）。

## 3. 与基线的接口（如何退化）

- ASA 失效（图集损坏/覆盖不足）⇒ `K_eff` 退回 v9 的 `Δ_dom` 门控 + 全局标定 β，等价 v9 粒度；
- CAP 失效（无 action 服务）⇒ 退回进程内 v9 `ActionChunkCertifier`，等价 v9 集成方式；
- 分布式节点失效/网络分区 ⇒ 未在有效期内认证的端口注入 `v^⊥_stale`，保守 `K=1`，不劣于 v9 fallback；
- 认证 QoS 服务（新鲜度/心跳）失效 ⇒ 视为 stale，相关端口全部注入 `v^⊥`，可观测地强制退化；
- 全部失效 ⇒ 完整退回 v9 MetricVoiceGauge-ACMD ⇒ v8 ⇒ v7 ⇒ v6。

## 4. 预期贡献

1. **CAP 认证动作协议**：把 v9 块证书嵌进 ROS2-action 语义，补上 DDS 缺失的实时期限与取消上界，使块可跨节点组合、可抢占、可审计；
2. **ASA 前馈门控**：用动作空间局部误差界替代滞后 `Δ_dom` 作为主门控，直接对 v9 的「最需要安全时证书最不可靠」风险下药；
3. **认证 QoS + 可回放等价**：把「陈旧数据」与「静默死节点」纳入中立元退化链，并用 rosbag2 把退化证明变成可重放实验；
4. **萎缩悖论与抗萎缩**：显式指出证书会诱发动作空间收缩，给出 UCB 式探索项 + 周期回放再标定的缓解，并把它列为可证伪的命题；
5. **实验 E571–E592** 覆盖异方差验证、图集标定、前馈 vs 滞后、取消/抢占、偏斜/分区、陈旧注入、逐位回放、萎缩长跑与端到端。

## 5. 本轮最大风险

**一句话**：ASA 的每格 `β_i` 只在标定分布上成立，而规划器在激进优化时恰恰把动作推进低样本/接触突变格；证书因此诱发**动作空间萎缩**——越不确定的格越被 `K=1` 门控、越拿不到新数据，可用动作空间随时间单调收缩；叠加 ROS 分布式，任一节点持有过期格表时还会用旧 β 为新动作背书——「证书既是安全护栏，也可能成为探索的慢性毒药」。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-ACAP**（Metric Voice Gauge with Action-space Certificate Atlas & Certified Action Protocol）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮灵感：「ROS」×「动作空间」
> **继承纪律**：MetricVoiceGauge 九不变式（CVC-闭环、SpatialCert、RT-CVC、FaultCert、PrimitiveGraph、严格退化链、OTL、GCT、ER）与 v9 的 AC/MW/ID 全部保留。新组件一律为**可选增强**：任一环节不可用 ⇒ 退回 v9 门控/进程内执行，严格等价（引理 87–92），而非行为漂移。
> **架构红线**：50Hz 硬环**必须**留在同进程零拷贝（component container / intra-process），ROS2(DDS) 只承担 5Hz 规划、证书分发、遥测与回放。否则 DDS 抖动会摧毁 v9 引理 86 的 50Hz 守恒——这是本方案不可让渡的工程约束。

**新增定义 540（认证动作协议 CAP）**
一次 CAP 交互由五类消息构成：
```
Goal   g = (id, a^{1:K}, Ĉ, P, ℓ_cancel, t_gen, holder)
Feedbk f = (id, k_exec, margin, guard_ok)
Result r = (id, status, p*, cert_out)
Cancel c = (id, ℓ_cancel)
Preempt p = (id, cause)          # 高优先级事件（如 ER 情感突变）
```
状态机：`PENDING → ACTIVE → {SUCCEEDED, ABORTED(p*), PREEMPTED}`，另在 ACTIVE 前可 `REJECTED`。
- **接受判据**：server 仅接受满足 `∀p∈P_t: stop_ok(s_p)`、`K≤K_ASA`、且本机格表覆盖其格遍历的 goal；否则 `REJECTED`（client 退化为 K=1 本地规划）。
- **取消语义**：收到 `Cancel` 后必须 ≤ `ℓ_cancel` 个控制周期到达最近合法中止点 `p*≤k_exec` 并转入安全停驻，`r` 回报 `p*` 与残余证书。
- **抢占语义**：`Preempt(cause)` 与 `Cancel` 同构，但允许 server 直接执行「目标切换」（如情感响应触发的新目标），仍受 `ℓ_cancel` 约束。

**新增定义 541（分层动作空间证书图集 ASA）**
动作空间两轴分解：
1. **离散层**：`A=⊔_{π∈Π}A_π`，π 取自 PrimitiveGraph（抓取逼近、闭合、提起、移动、释放……）。层间面 `∂A` 为模式切换，是接触动力学的**误差不连续面**。
2. **连续层**：每层 `A_π` 由残差分位回归树划分为有限格 `{A_{π,i}}`。切分判据（拒绝碎片化）：
```
一次候选切分被接受 ⇔ max(β_left, β_right) < β_parent − ε_β
```
每格证书 `C_{π,i}=(β_{π,i},ρ_{π,i},n_{π,i},b_{π,i})`，其中 `β_{π,i}` 是置信度 `1−δ` 下的局部一致误差上界，`ρ_{π,i}` 是该格可构造中止模板的比例。

**新增定义 542（格遍历风险与 K_ASA）**
对候选块 `a^{1:K}`，令 `W=(c(a^1),…,c(a^K))`：
```
β_chunk(a^{1:K}) = max_{k≤K} β_{c(a^k)}
R_K(a) = Σ_{k=1}^{K} γ^{k−1} · β_{c(a^k)},   γ∈(0,1]
K_ASA(a) = max{ K : R_K ≤ R_max ∧ ∀k≤K: ρ_{c(a^k)} ≥ ρ_min ∧ n_{c(a^k)} ≥ n_min }
K_eff(t) = min( K_dom^{v9}(t), K_ASA(a), K_stratum(a) )
```
`R_K` 随 K 单调非减（`β≥0`）⇒ `K_ASA` 良定义且可增量前缀增长，在线开销 O(K)。

**新增定义 543（分层断点与检查点丰富的 safety set）**
模式切换索引集 `S(a^{1:K})` 中的每个 k 强制成为检查点，要求 `k∈P_t` 且切换前后两格的制动证书均成立（`stop_ok`）。未认证的切换直接把 `K_stratum` 截到 `k−1`。于是中止点集在误差最大的模式切换处**结构性**变密，而非依赖 v9 E553 的人工密度调参。

**新增定义 544（格内停车证书与制动动作）**
每格有规范制动动作 `b_{π,i}(s)`（该层最小风险动作：近零速 + 柔顺保持 / 释放接触）。停车证书：
```
stop_ok_{π,i}(s) ⇔ dist_robot(s,O) ≥ d_stop^{π,i}(v,s) + d_safe
d_stop^{π,i} = 由 b_{π,i} 在格 (π,i) 标定动力学下的预测轨迹长度 + β_{π,i} 余量
```
中止点 p 合法 ⇔ `stop_ok_{c(b_p)}(s_p)`——注意用**制动动作所在格**的模型，而非前进动作格：把「刹车」也当作动作空间里的一类动作来认证。这取代 v9 定义 534 的标量 `d_brake`。

**新增定义 545（认证 QoS 与陈旧中立元）**
消息 `m=(value,t_gen,t_exp,cert,holder)`，消费者在 t 收到时强制：
```
fresh:    t − t_gen ≤ τ_fresh           ∧   t_gen ≤ t + ε_skew_allow
deadline: t − t_goal_gen ≤ D_m
livel:    相邻心跳间隔 ≤ ℓ_bond
```
任一失败 ⇒ 注入 `v^⊥_stale`（该端口中立元）；50Hz 决策端口的 `v^⊥_stale` 取保守单步 fallback。证书与格表使用 `durability=transient_local`：新加入的安全监视节点（late-join）立即拿到当前证书/格表，避免冷启动无背书。

**新增定义 546（分布式预算与时钟偏斜）**
全局决策预算 `B = B_intra + Σ_nodes B_node`。跨节点证书有效期折减为：
```
τ_fresh_eff = τ_fresh − ε̂_skew,   ε̂_skew = PTP/chrony 估计 + 安全裕度
```
若偏斜不可估计或 `ε̂_skew ≥ τ_fresh` ⇒ 证书视为过期，禁止用于 K>1（只过度退化，绝不过度信任）。跨节点 EDF 用 anchor+relative 截止期，不依赖完美时钟同步。

**新增定义 547（证书溯源与确定性回放）**
所有 CAP 消息、证书、`/clock`、参数快照、门控决策写入 rosbag2。回放要求：同一输入包 + 同一种子 ⇒ 门控/中止/中立元序列**逐位一致**（对决策日志）。附带「证书回放模糊测试」：对历史包注入延迟、丢包、陈旧、偏斜、脑裂，检验 `v^⊥`/`v^⊥_stale` 路径可达且安全。

**新增定义 548（图集维护、抗萎缩采样与格级蒸馏）**
在线残差驱动增量划格/合并；候选评分加 UCB 探索项：
```
score'(cand) = score(cand) + λ_expl / sqrt(n_{c(a^1)})
```
每 `T_cal` 周期用回放包对低样本格离线再标定。v10 的 `φ^elig` 增加「格胜任度」：模块在低覆盖格的贡献不计入休眠判断（避免把「没被测过」误判为「无用」）。

# IP-358 ActionSpaceAtlas：分层证书图集
class ActionSpaceAtlas:
    Stratum = Callable[[Action], int]          # PrimitiveGraph 层映射 π(a)
    def __init__(self, strata, cells, beta_eps=1e-3, delta=0.01):
        self.strata = strata                   # π -> 残差分位树
        self.cells = cells                     # (π,i) -> CellCert(beta,rho,n,b)
        self.beta_eps, self.delta = beta_eps, delta

    def cell_of(self, a):
        pi = self.strata.layer(a)
        return (pi, self.strata[pi].leaf(a))  # O(d_a)

    def fit_split(self, node, residual_samples):
        """残差分位树：只在能显著降低 beta 时才切（定义 541）"""
        cand = node.best_split(residual_samples, quantile=1 - self.delta)
        if cand and cand.beta_child_max < node.beta - self.beta_eps:
            return cand
        return None                            # 拒绝碎片化

    def walk(self, actions, gamma=0.95, R_max=0.05):
        """返回 (K_ASA, K_stratum, beta_chunk, checkpoint_set)"""
        R, beta_max, K_asa = 0.0, 0.0, len(actions)
        K_strat, checkpoints = len(actions), set()
        prev_pi = None
        for k, a in enumerate(actions, start=1):
            cell = self.cell_of(a)
            cert = self.cells[cell]
            if self.strata.layer(a) != prev_pi and prev_pi is not None:
                checkpoints.add(k - 1)         # 模式切换前一步为检查点
                if not self._switch_certified(prev_pi, cell):
                    K_strat = min(K_strat, k - 1)
            R += (gamma ** (k - 1)) * cert.beta
            beta_max = max(beta_max, cert.beta)
            ok_cell = (cert.rho >= RHO_MIN) and (cert.n >= N_MIN)
            if R > R_max or not ok_cell:
                K_asa = k - 1
                break
            prev_pi = self.strata.layer(a)
        return max(1, K_asa), max(1, K_strat), beta_max, checkpoints


# IP-357 CertifiedActionProtocol：认证动作协议（ROS2-action 兼容）
@dataclass
class Goal:
    id: str; actions: list; cert: ChunkCert; abort_pts: set
    cancel_bound: int; t_gen: float; holder: str
    status: str = "PENDING"

class ChunkServer:
    def __init__(self, atlas: ActionSpaceAtlas, guard, executor):
        self.atlas, self.guard, self.executor = atlas, guard, executor
        self.active = {}

    def on_goal(self, g: Goal, state):
        K_asa, K_strat, beta, cps = self.atlas.walk(g.actions)
        if len(g.actions) > min(K_asa, K_strat):        # 本机无法背书
            return Result(g.id, "REJECTED", None, None)
        if not all(self._stop_ok(state, p) for p in g.abort_pts):
            return Result(g.id, "REJECTED", None, None)
        self.active[g.id] = Running(g, checkpoints=cps)
        return self._run(g.id)

    def on_cancel(self, c: Cancel):
        run = self.active[c.id]
        p = self._nearest_abort(run, run.k_exec)        # ≤ ℓ_cancel 内到达
        if run.k_exec - p > c.cancel_bound:
            p = run.k_exec                              # 就地保守停驻
        self.executor.safe_stop_at(p)
        return Result(c.id, "ABORTED", p, run.cert)

    def on_preempt(self, p: Preempt):
        return self.on_cancel(Cancel(p.id, self.active[p.id].goal.cancel_bound))


# IP-359 CertifiedQoS：新鲜度 + 截止期 + 心跳；失效注入陈旧中立元
def receive(port, msg, now, tau_fresh, eps_skew, ell_bond, last_beat):
    stale = (now - msg.t_gen > tau_fresh) or (msg.t_gen > now + eps_skew)
    dead  = (now - last_beat[msg.holder] > ell_bond)
    if stale or dead or not verify_cert(msg.cert):
        inject(port, NEUTRAL_STALE[port])               # v^⊥_stale
        log_stale(port, reason=("stale" if stale else
                                "dead" if dead else "badcert"))
        return False
    deliver(port, msg.value); return True


# 主闭环：MetricVoiceGauge-ACAP（50Hz 守卫仍在同进程，5Hz 规划走 CAP）
def metricvoicegauge_round_10(M, s, obs, ...):

    results = middleware.run_cycle(runners={...}, ctx=ctx)   # v9 契约路径
    ctx.delta_dom, ctx.tau_dom = results['DA_ML'], M.tau_dom

    if current_chunk is None or current_chunk.exhausted:     # 5Hz 块生成
        cands = policy.sample_sequences(ctx.state, K_MAX, n=64)
        cands = anti_atrophy.rerank(cands, atlas)            # IP-361 UCB 探索
        best = None
        for cand in cands:
            K_asa, K_strat, beta, cps = atlas.walk(cand[:K_MAX])
            K = min(K_MAX, K_asa, K_strat)                   # 前馈门控
            if K == 0: continue

            if pred.min_clearance - beta < D_SAFE: continue

                best = Chunk(cand, Cert(pred, beta), pts, K)
        current_chunk = best or single_step_fallback(ctx.state)  # ≡ v9/v8

    # 50Hz 廉价守卫（同进程零拷贝；atlas 只在块边界查，守卫 O(1)）
    verdict, k_next = chunker.midchunk_guard(current_chunk, k_exec, obs)
    if verdict == 'abort':
        current_chunk.execute_safe_stop_at(k_next)
        current_chunk = None
    else:
        execute(current_chunk.actions[k_next])

    C, spatial_cert, claims, metrics, rewards = M.inherited_v9_path(ctx)
    distiller.step(cycle_idx, ctx)                            # 格胜任度入资格

    return C, spatial_cert, claims, metrics, rewards

## 4. 推导

**引理 87（CAP 远端执行安全性）** 设 goal 携带证书与中止集 `P_t`，server 与 client 时钟偏斜 ≤ ε，取消在 `ℓ_cancel` 内被履行。则把 `ℓ_cancel·v_max` 并入停车不变式后，从 `p*` 执行的制动轨迹终点距障碍 ≥ `d_safe`。证明：`stop_ok` 已用格内制动动作的标定动力学 + `β` 余量计算；取消上界只增加可在 `ℓ_cancel` 步内消耗的额外距离，将其加入 `d_stop` 得保守界，再套用 v9 引理 82。若 server 无法在 `ℓ_cancel` 内到达任何 `p*`，则接受判据早已要求 `K≤K_ASA` 或直接 `REJECTED`。∎

**引理 88（前馈门控消除 Δ_dom 滞后）** 在覆盖格（`n_i≥n_min`，`β_i` 以 `1−δ` 置信校准）内，`β_chunk` 以 `1−δ` 覆盖真实误差，故计划前缀的证书有效性不依赖 `Δ_dom` 的检测滞后。v9 的最坏场景（分布突变、`Δ_dom` 滞后）下，ASA 仍按**即将访问的格**门控；残余风险被限制在未覆盖格，而 `n_min` 使这些格只能取 `K=1`（等价 v9 fallback）。∎

**引理 89（截断单调性与分层检查点安全）** `R_K` 对 K 非减（`β≥0`），故 `K_ASA` 良定义且前缀增长；`K_stratum` 截断点落在模式切换前的检查点，检查点要求 `stop_ok` 成立；任一截断序列的末端均满足停车证书 ⇒ 安全停驻可达。∎

**引理 90（陈旧/偏斜的保守性）** 注入 `v^⊥_stale` 是 v9 引理 83 意义下的中立元注入；偏斜只使 `τ_fresh_eff=τ_fresh−ε̂_skew ≤ τ_fresh`，故只会**过度退化**、不会过度信任；检测时延 ≤ `ℓ_bond` + 传输时延。∎

**引理 91（可回放等价，强化引理 83）** 决策是 `(输入, 时钟, 参数, 证书)` 的确定函数；固定种子并去除墙钟依赖后，逐位回放复现相同门控/中止/中立元序列。故 v9 引理 83 从「可观测等价」强化为「可回放等价」。前提：RNG 种子固定、无隐藏 wall-clock、证书签发确定。∎

**引理 92（抗萎缩覆盖，条件命题）** 若每个规划周期对每个 `n_i<n_min` 的格以探索项 `λ_expl/√n_i` 赋予正概率，则由 Borel–Cantelli，`n_i` 以概率 1 越过 `n_min`，覆盖集合随时间非减；反之，存在只优化即时得分的策略使低样本格永不被访问，`n_i` 冻结、覆盖单调非增（萎缩）。⇒ 抗萎缩采样不是可选项，而是覆盖非降的必要条件。∎

## 8. 本轮最大风险

**一句话**：ASA 的每格 `β_i` 只在标定分布上成立，而规划器在激进优化时恰恰把动作推进低样本/接触突变格；证书因此诱发**动作空间萎缩**——越不确定的格越被 `K=1` 门控、越拿不到新数据，可用动作空间随时间单调收缩；叠加 ROS 分布式，任一节点持有过期格表时还会用旧 β 为新动作背书——「证书既是安全护栏，也可能成为探索的慢性毒药」。
