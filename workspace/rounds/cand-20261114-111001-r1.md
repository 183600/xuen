# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；新循环第 1 轮；本轮灵感：「UniBot」×「知识图谱」）

> R69 问「我该向谁求证」。把这个问题放进 UniBot 世界挑战赛，第一件事是承认：**赛场上没有人可问**。语言指令在 episode 内固定，模型以远端 policy 服务接入，评测包含「人为干扰」，唯一能回答问题的只有世界本身——多一次注视、换一个视角、做一次轻触或重抓。更要命的是，UniBot 的失败通常不是「单步估计不准」，而是**关系没迁移对**：32 项真实桌面任务、5 类泛化扰动（位置变化、干扰物、桌面背景、未见物品、人为干扰），同一个权重必须同时回答「杯子在盘子左边还是右边」「透明杯能不能沿用同一抓法」「人把目标挪走之后这还是不是同一个任务」。单步 VLA 在 demo 分布内很准，一旦关系重排、指代歧义或物体没见过的属性组合出现，就断。
>
> **知识图谱**正好是「关系」的载体：对象—属性—可供性—子目标—任务—扰动，天然提供跨任务复用的骨架。但知识图谱也是本方案最大的陷阱：**图是假设，不是事实**。LLM 会幻觉边，数据会制造伪相关，32k 演示里的场景共现足以把「红杯总在左边」错记成「左边才抓得到」。R69 的教训在此重演：**一个自信的错误先验，比没有先验更危险**。
>
> 核心命题：**把知识图谱从「静态符号库」改造成「可执行、可校准、可证伪的关系先验」；只有被数据支持、被在线观测接地、并通过图级证书的边，才允许改变策略；否则逐指令退化为 R69 的 FMP 基座。** 命名 **KARMA**（Knowledge-Anchored Relational Manipulation & Adaptation），全称串起五个动作：建图、认证、路由、类比、验证。
>
> 一句话定位：R69 问「向谁求证」，R70 问「**在不能问人的赛场上，哪些关系值得信、哪些只是 demo 的巧合**」——知识不是答案，而是一组可被世界反驳的假设。

## 0. 赛事事实核查（检索日期 2026-11-14，先核实再设计）

- **赛题与评分**：基于 Unitree G1 人形机器人，围绕桌面操作（抓取、放置、双手协调）设 32 项真实任务；以**平均成功率 + 平均步骤分**排名，覆盖位置变化、干扰物、桌面背景、未见物品、人为干扰 5 类泛化场景（https://unibot.unitree.com/ ，检索 2026-11-14）。
- **提交接口**：policy 需实现 `metadata` / `get_action(obs)` / `reset()`；`control_space ∈ {joint, ee}`；观测含 4 路 RGB（左右高位相机 + 左右腕相机）、双臂关节、左右末端位姿、夹爪开度、下位本体与 episode 内固定的 `observation.language`；返回带时间轴的 action chunk；线上按 N 台机器人开 N 个连续端口（自 8765 起），`token` 在握手与每步双重校验（https://github.com/unitreerobotics/unibot_submission ，检索 2026-11-14）。
- **数据**：32 个任务各一个 HuggingFace 仓库，LeRobot v3、Dex1 平行夹爪、4 路相机；主办方口径 32,000 条演示 / 169 小时，HF 元信息合计约 33,276 episodes、811GB（https://huggingface.co/collections/unitreerobotics/unibot-v1-challenge-dataset ，检索 2026-11-14）。
- **榜单**：检索日官方排行榜显示「Coming Soon」，因此本方案**不依赖任何未公开榜首数字**；任务背景中的「头部成功率不足三成」只当作设计假设，不进入实验基线。
- **媒体口径**：赛事于 2026-07-10 发布，强调 DAPTO 2 任务集与规模化真机评测（凤凰网科技 2026-07-10，https://tech.ifeng.com/c/8ueO0H1KMK7 ，检索 2026-11-14）。

核查直接钉死四条设计边界：**不能问人、不能改语言、不能看测试集、推理必须能开 N 个副本**。任何创新点若越过这四条，就只是论文，不是参赛方案。

## 1. 直觉与动机

**灵感 1（UniBot → 瓶颈是关系泛化与长程复合，而不是单步精度）**
直觉：32 个任务看似彼此独立，其实共享一小套「关系原语」：接近、对准、闭合、抬升、移动、下放、释放、交接；5 类扰动也不是五种新任务，而是对**同一条关系链**做变换——挪位置改了几何关系，加干扰物改了指代关系，换背景改了外观先验，未见物品改了属性—可供性关系，人为干扰改了动态关系。因此，真正的杠杆不是再堆一个更大的 VLA，而是把「关系」显式化、可复用、可验证。知识图谱就是把 32 条长尾任务压成一张**共享骨架**的天然工具。

**灵感 2（知识图谱 → 把任务压成子目标 DAG，把对象压成属性—可供性路径）**
直觉：如果一个模型知道「透明杯 → 反光/弱纹理 → 边缘抓取或侧壁抓取」，「细长试管 → 高重心 → 低加速度」，「盘子 → 平面支撑 → 双手协同」，那么遇到没见过的「透明试管」时，它不必从零试错，只要在图上走一条属性—可供性路径。知识图谱在这里不是数据库，而是**类比迁移的度量空间**：两个对象的相似性由它们在图上的最短解释路径定义，而不是由像素或语言 embedding 单独定义。

**灵感 3（知识图谱 → 但图是假设：伪相关、覆盖缺口、幻觉）**
直觉：从 32k 条演示里挖图，最危险的产物不是「缺边」，而是「看起来支持度很高的伪边」。例如 32 个任务桌面布局相似，红杯经常出现在盘左，统计上「红杯—左侧」会被高支持；但位置扰动一换，这条边就把抓取先验带偏。LLM 生成的关系同样会幻觉出「玻璃杯可磁吸」这种语法通顺、物理荒谬的边。所以本轮必须给每条边配三样东西：**见证数、独立扰动下的稳定性、在线可证伪性**。没有这三样，边只能当提示，不能当先验。

**灵感 4（不能问人 → 主动感知是唯一的「提问」）**
直觉：R69 的信息动作是「看 / 问 / 触」；UniBot 里「问」被禁用，「看 / 触 / 换视角 / 重抓」还在。于是 VoI 的目标从「问到一个回答」退化为「做一个让世界自己暴露关系的动作」：腕相机凑近看夹爪是否真的闭合、躯干侧转获得第二个视角、轻抬探测物体是否被带起、失败后换一个抓取面重试。这是一个更干净的设定：**没有社会性欺骗，只有感知与物理的双重不确定性**，KARMA 只需对「世界会不会给出可判别的观测」负责。

**灵感 5（步骤分 → 图级进度与可恢复性）**
直觉：平均步骤分奖励「做到几成」。但黑箱评测的步骤分公式未公开，直接优化它是盲目的。可行的代理是：把每个子目标的谓词接地为 `p_s ∈ [0,1]`，用 DAG 的加权进度 `ρ_step` 作为步骤分的单调代理，并在子目标边界做验证与回退。这样即使官方口径不同，图的**结构**也保证「不会为了终点而牺牲已完成的部分」，并在失败时知道该退回哪一步，而不是整段重来。

**灵感 6（理论姿态 → 图只能当加速器，不能当新黑箱）**
直觉：每加一层就多一个需要独立信任的黑箱，是 R66–R69 一路避免的错误。KARMA 的定位必须是：**图命中且可信 → 获得检索、类比、步骤分收益；图缺席、冲突或被投毒 → 逐指令退回 R69 基座。** 这不是并列替代，而是严格包含。安全侧不让步，效率侧才谈收益。

## 2. 形式化定义（增量：定义 310–322）

**定义 310（KARMA 总览与三不变式）** KARMA = (KGB, EHG, EGC, SDR, RCG, AGA, APV, PDE, HGD, GVC, RAS-WM‡)。三不变式：
(i) **零特权信息**：只使用公开数据集、公开任务说明与自采 rollout，不使用测试集、不利用评测器内部信息；
(ii) **图不改安全包络**：图只改变先验、检索、验证与子目标路由，所有物理动作仍过 R69 的 C-RAS-WM 前缀认证与 FMP 执行器；
(iii) **逐指令可退化**：无可信子图、无正 VoI、或检测到致命冲突时，行为与 R69 FMP+RAS-WM† 基座完全相同（定义 322）。

**定义 311（异构可执行图谱 EHG）** 图 G = (V, E, τ_V, τ_E, Π, w)。节点类型：任务 t、子目标 s、对象 o、属性 a、可供性 f、扰动 p、失败模式 m、演示段 d。边类型至少含：`part-of`（t→s）、`precedes`（s→s）、`has-attr`（o→a）、`affords`（(o,a)→f）、`achieved-by`（s→f）、`perturbed-by`（p→任意边/节点）、`caused-by`（m→前置条件）、`witnessed-by`（d→s）。每条边带来源 Π(e)（数据集仓库、episode 号、LLM 提议或 rollout）与权重 w(e)。

**定义 312（子目标 DAG 与谓词接地）** 任务 t 对应 DAG D_t = (S_t, E_t)。每个子目标 s 有谓词 φ_s: 𝒵×𝒪→{0,1}（如 `in_gripper(o)`、`above(o, target)`、`upright(o)`、`contact(o)`），接地器 g_s 用 4 路 RGB 与本体估计软满足度 p_s = P(φ_s=1 | o)。可观测性 o_s ∈ [0,1] 由视角几何、遮挡、材质（透明/反光）与腕相机距离估计。步骤分代理 ρ_step = Σ_s w_s p_s / Σ_s w_s，w_s 由 DAG 关键度与不可逆性给出（释放、跨越、断电更高）。

**定义 313（边支持、校准与可信子图 EGC）** 边 e 有见证数 n_e 与成功数 k_e，采用 Beta(a0+k_e, b0+n_e−k_e) 后验；误差上界 err_e = 1 − LCB_α(e)。可信子图 G_cert = { e : err_e ≤ τ_e ∧ fresh(e) ∧ grounded(e) }，其中 `fresh` 要求来源未被新 rollout 推翻，`grounded` 要求至少一个视觉/接触见证。任务 t 的图覆盖 κ(t) = 其路径必需边落在 G_cert 的比例。

**定义 314（关系不确定性与感知不确定性二分）** U_ale 为视觉与接触噪声（不可约），沿用 R69 的 λ_floor；U_rel 为「当前观测绑定到哪个子目标/对象/路径」的后验熵（可约）。只有 U_rel 触发检索或主动感知；二者不简单相加，而是进入不同通道。这与 R69 的 aleatoric/epistemic 二分结构同构，但对象从「动作模态」换成了「关系绑定」。

**定义 315（图条件检索 RCG）** 对当前子目标 s 与绑定对象 o，演示段 d 的检索得分
`score(d) = sim_visual(d,o) + α·(−dist_G(o,o_d)) + β·diversity(d) − γ·leakage(d)`，
取 top-k 作为 FMP 的上下文/适配器条件。`leakage` 惩罚与当前 scene 过度相同的段，避免把「同场景记忆」误当「关系泛化」。

**定义 316（类比可供性迁移 AGA）** 未见对象 o\* 经属性路径 π（如透明→反光→边缘可见性）映射到锚点 o_a；抓取参数分布取混合 `Σ_a w_a 𝒩(μ_a, Σ_a)`，迁移置信 `conf ∝ exp(−L_A·len(π)·d_A(o*,o_a))`。当 conf < τ_A 时不迁移，交基座；这条门限给类比迁移一个可证的使用边界（引理 20）。

**定义 317（主动感知验证 APV）** 无人类可问，信息动作 g 只能来自自运动：换视角、腕相机凑近、轻触/轻抬探针、重抓。信息增益 VoI(g) = H(binding | o) − E_{y∼p(·|g,o)}[H(binding | o,y)]；选择 g\* = argmax_g [VoI(g) − λ_lat·c(g)]，s.t. 安全前缀认证与时间预算。若无正收益，不动作、交基座。

**定义 318（扰动解耦 PDE）** 5 类扰动对应图变换 T_p。对边 e 定义不变性缺口 `IG_e(p) = |P(e | x) − P(e | T_p x)|`。若一条边的高支持主要来自 nuisance 共现（场景、背景、固定布局），则存在 p 使 IG_e(p) 显著非零；因此 PDE 不是「数据增强」，而是**伪相关的证伪器**。

**定义 319（幻觉与冲突检测 HGD）** 对每条被使用的边，在线计算冲突 `c_e = d(预测关系, 观测关系)`。c_e > τ_c ⇒ 降权并记 U_rel，触发 APV 或回退；连续冲突 ⇒ 冻结该边、写入 AuditBuf，并停止将其用于后续 episode。

**定义 320（图级证书 GVC）** J_KARMA = (J_FLUID, κ_min, min_e err_e, ρ_step 的置信区间, retrieval_provenance_hash, max_p IG_e(p), latency_p99, kg_hash)。Valid ⇔ J_FLUID Valid ∧ κ ≥ κ_min ∧ 冲突在容限内 ∧ 没有未接地边被用于改变动作。

**定义 321（AIC-KG 干扰集）** 图投毒（注入高支持伪边）、关系幻觉（LLM 提议但无数据见证）、指代歧义（「左边的杯子」在干扰物下不唯一）、数据泄漏（同 scene 跨 split）。ℰ_KARMA = ℰ_FLUID × ℰ_KG，用于对抗训练与红队测试。

**定义 322（严格退化与包含）** 若 κ(t) < κ_min、或 G_cert 为空、或 max_g[VoI−成本] ≤ 0、或 HGD 报致命冲突，则绕过图：FMP 采样、R69 风险缩放、C-RAS-WM 认证保持不变，行为逐指令等于 R69 基座。图是可选加速器，不是新的信任根。

## 3. 为什么这不是「知识图谱 + VLA」的常规组合

常规做法是：LLM 离线生成一张任务图，运行时用图检索提示或做任务分解，然后交给 VLA。它有四个未回答的问题，也正是 KARMA 的四个交付：

1. **边凭什么可信？** → EGC 的见证数 + 校准误差上界 + 在线接地，只有 G_cert 能改动作。
2. **图会不会把 demo 的巧合当规律？** → PDE 用 5 类扰动做不变性缺口检验，把伪相关边逐出。
3. **图错了怎么办？** → HGD 在线冲突检测 + 定义 322 的逐指令退化，安全侧不劣于基座。
4. **看不见/看不清时怎么办？** → APV 把「问人」换成主动感知，用 VoI 决定是否值得动一下。

一句话：**别人把图当知识，KARMA 把图当可证伪的假设。**

## 4. 推导

**引理 19（组合共享的样本复杂度）** 设任务 t 是共享子目标词表 S 与边集 E 上的一条路径，单个子目标技能误差上界 ε_s。若 32 个任务各自独立学习低层技能，总误差随任务数与时长线性累积；若共享 S/E 并做图路由，路径复合误差 ≤ Σ_{s∈path} ε_s + Σ_{e∈path} ε_e，样本主要花在 |S|+|E| 上。系：**32 个任务不需要 32 套技能，KARMA 把数据效率从「任务数」转到「关系数」**。

**引理 20（类比迁移的 Lipschitz 界）** 设抓取成功率对对象属性在图度量 d_G 上满足 L_A-Lipschitz，则未见对象 o\* 借用锚点 a 的先验时，|succ(o\*) − succ(a)| ≤ L_A·d_G(o\*, a)。故 d_G > τ_A 时迁移无意义，应直接回退；这给 AGA 的 `conf < τ_A` 门限一个可证依据。

**引理 21（伪相关的可检测性）** 若边 e 的真实支撑来自 nuisance z，则存在扰动 p 使 IG_e(p) ≥ δ_z；只要有 n_e 个独立扰动见证，PDE 以至少 1 − exp(−2n_e δ_z²) 的概率把 e 从 G_cert 剔除。系：**在 5 类扰动上都稳定，比在 demo 上支持数高更能证明一条边。**

**定理 18（KARMA 严格包含 R69 基座）** 在定义 322 的回退条件下，KARMA 与 R69 基座逐指令相同；因此安全侧不劣化。效率侧只有在 G_cert 非空且 VoI > 0 时才获得检索、类比与子目标收益。图不能降低安全阈值，也不能绕过认证。

**定理 19（步骤分与复合误差）** 若官方步骤分在「已接地子目标满足」上单调（A-step），则使用 SDR 的图级进度不会降低官方步骤分；且图级谓词验证把长程失败检测从「终局才发现」提前到「子目标边界」，复合错误期望下降至少 `1 − Π_s (1 − d_s)`，d_s 为子目标可检测率。A-step 不成立时，SDR 只作为训练/调试代理，不进入证书。

## 5. 本轮最大风险

**一句话**：KARMA 的全部增益押在「图上一条边在 demo 之外仍然成立」这一假设上——**若伪相关被校准上界误判为高可信，系统会在未见物品与人为干扰上把最近邻场景的抓取先验自信地迁过去；图越「可证」，错误越系统性，而且赛场上没有人能纠正它**。

# 第 70 轮产物 · 创新点清单 v1：KARMA（Knowledge-Anchored Relational Manipulation & Adaptation：知识图谱锚定的可证关系泛化闭环；KGB×EHG×EGC×SDR×RCG×AGA×APV×PDE×HGD×GVC×RAS-WM‡）

> 承接第 69 轮 IP-253~263（FLUID-RAS）。R69 把不确定性拆成 aleatoric/epistemic，并用流匹配策略与主动多模态交互去消解可约歧义。但把 R69 放进 UniBot 世界挑战赛，约束变了：**不能问人、语言固定、测试集不可见、必须开 N 个服务副本**。于是 R69 的「问」退化为「看/触/换视角/重抓」，而真正的瓶颈也从「单步歧义」变成「**关系无法跨任务、跨物体、跨扰动迁移**」——32 项桌面任务、5 类泛化扰动（位置、干扰物、背景、未见物品、人为干扰），一个通才模型必须在同一权重里复用同一套关系原语。
>
> 本轮把**知识图谱**引入，但不是当成静态符号库，而是当成**可执行、可校准、可证伪的关系先验**：只有通过「数据见证 + 扰动解耦 + 在线接地 + 图级证书」的边，才允许改变动作；否则逐指令退回 R69 基座。定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**在不能问人的赛场上，哪些关系值得信、哪些只是 demo 的巧合**」。
>
> IP 编号：IP-264~IP-275（共 12 个）。理论姿态：**图为加速器而非信任根；安全侧严格包含 R69 基座。**

## 3. 形式化定义（要点版）

**定义 310（总览）** KARMA = (KGB, EHG, EGC, SDR, RCG, AGA, APV, PDE, HGD, GVC, RAS-WM‡)；三不变式：零特权信息、图不改安全包络、逐指令可退化。

**定义 311（EHG）** 节点：任务/子目标/对象/属性/可供性/扰动/失败/演示段；边：`part-of, precedes, has-attr, affords, achieved-by, perturbed-by, caused-by, witnessed-by`；每条边带 provenance 与权重。

**定义 312（SDR）** 任务 DAG 上每个 s 有可执行谓词 φ_s 与 4 路视觉/本体接地器；`ρ_step` 为加权软满足度；evaluator 步骤分未知时，ρ_step 只作代理，不写进安全证书。

**定义 313（EGC）** Beta 后验 + 误差上界；`G_cert = {e: err_e≤τ_e, fresh, grounded}`；`κ(t)` 度量路径覆盖。

**定义 314（不确定性二分）** U_ale 走 R69 λ_floor；U_rel 走检索/主动感知；二者分通道，不简单相加。

**定义 315（RCG）** 检索得分 = 视觉相似 + 图距离 + 场景多样性 − 泄漏惩罚；top-k 作 FMP 条件。

**定义 316（AGA）** 属性路径类比；迁移置信随路径长度与属性距离指数衰减；低于门限回退基座。

**定义 317（APV）** 无人类回答，信息动作 = 换视角/凑近/轻触/重抓；`g*=argmax[VoI−λ_lat·c]`，过安全认证。

**定义 318（PDE）** 5 类扰动 = 图变换；`IG_e(p)` 证伪 nuisance 支撑的伪边。

**定义 319（HGD）** 在线冲突 c_e；超限降权/触发 APV/回退；连续冲突冻结边。

**定义 320（GVC）** `J_KARMA=(J_FLUID, κ, min_e err_e, ρ_step CI, retrieval hash, max IG, latency_p99, kg_hash)`。

**定义 321（AIC-KG）** `ℰ_KARMA = ℰ_FLUID × ℰ_KG`：图投毒、关系幻觉、指代歧义、同 scene 泄漏。

**定义 322（严格退化）** 无可信子图/无正 VoI/致命冲突 ⇒ 行为逐指令等于 R69 基座。

## 4. 关键算法伪代码

```python
# IP-264 KGB：离线建图（LLM 只提议，数据做见证，不做运行时依赖）
def build_knowledge_graph(repos, episodes, llm):
    G = init_schema()
    for ep in episodes:
        segs = segment_actions(ep)                    # 动作分段 + 视觉事件
        objs = detect_track_objects(ep)               # 对象/属性/交互轨迹
        for s, seg in zip(align_subgoals(segs, ep.language), segs):
            G.add_edge(task(ep), "part-of", s, prov=ep.id)
            G.add_edge(seg, "witnessed-by", s, prov=ep.id)
            for o in objs:
                G.add_edge(s, "achieved-by", affordance(o, seg), prov=ep.id)
        for prop in llm.propose_relations(ep):        # 仅提议，不直接入图
            if data_supports(prop, episodes):
                G.add_edge(prop.src, prop.rel, prop.dst,
                           prov=("llm", ep.id), verified=True)
    return G

# IP-266 EGC：从见证数计算误差上界，得到可信子图
def certify_edges(G, alpha=0.05, tau_e=0.1):
    G_cert = Graph()
    for e in G.edges:
        n, k = G.support(e)
        err = 1.0 - beta_lcb(k + 1, n - k + 1, alpha)   # 误差上界
        if err <= tau_e and G.is_fresh(e) and G.is_grounded(e):
            G_cert.add(e, err=err)
    return G_cert

# IP-271 PDE：用 5 类扰动的不变性缺口剔除伪相关边
def perturbation_decoupling(G_cert, slices):
    for e in list(G_cert.edges):
        for p, data in slices.items():                  # pos/distract/bg/unseen/human
            ig = abs(p_edge(e, data.base) - p_edge(e, data.perturbed))
            if ig > TAU_IG and len(data) >= n_min:
                G_cert.demote(e, reason=f"nuisance:{p}")  # 逐出可信子图
                break
    return G_cert

# IP-267 SDR：子目标谓词接地与步骤分代理
def step_progress(D_t, obs):
    p = {s: D_t.ground(s, obs) for s in D_t.nodes}      # 软满足度 [0,1]
    rho = sum(D_t.w[s] * p[s] for s in D_t.nodes) / sum(D_t.w.values())
    o_min = min(D_t.obs[s] for s in D_t.nodes)
    return rho, p, o_min

# IP-268/269：图条件检索 + 类比可供性
def graph_conditioned_prior(G_cert, s, o, obs):
    demos = retrieve(G_cert, s, o, k=8,
                     score=lambda d: vis_sim(d, o) - alpha * dist_G(o, d.obj)
                                     + beta * diversity(d) - gamma * leakage(d, obs))
    if o.seen:
        return {"demos": demos, "grasp": None}
    anchors = analogical_paths(G_cert, o)               # 属性—可供性路径
    if not anchors or max(a.conf for a in anchors) < TAU_A:
        return {"demos": demos, "grasp": None}          # 交给基座
    return {"demos": demos, "grasp": mixture_grasp(anchors)}

# IP-275 主闭环：图只做路由/检索/验证，执行仍由 R69 FMP + RAS-WM 完成
def KARMA_round(M, obs, ep_state):
    z, o = M.mtm.forward(obs)                           # R69 条件编码
    rho, p_s, o_min = M.sdr.step_progress(M.dag[ep_state.task], o)
    binding = M.grounder.bind(obs, M.dag[ep_state.task], p_s)
    U_rel = entropy(binding.candidates)
    # 1) 关系歧义：只在可信子图上做主动感知，绝不问人
    g = None
    if U_rel > TAU_REL and M.egc.coverage(ep_state.task) >= KAPPA_MIN:
        g = M.apv.choose(binding, obs, M.budget)        # 换视角/凑近/轻触
        if g is not None:
            obs, binding = M.apv.execute(g, obs)        # 过 C-RAS-WM 认证
            U_rel = entropy(binding.candidates)
    # 2) 图条件先验：仅 G_cert 边可影响动作
    prior = M.rcg.prior(M.g_cert, binding.best, obs)
    # 3) 执行：R69 FMP 采样 + 风险缩放 + 安全前缀认证
    xi = M.fmp.sample(o, K=1)
    if prior.grasp is not None:
        xi = M.fmp.reweight(xi, prior.grasp)            # 只重加权，不改包络
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + unresolved(U_rel)))
    k = M.c_ras_wm.certified_prefix(xi, ..., M.wm_preds)
    # 4) 在线证伪：图说一套、观测说另一套时，降权并记录
    conflict = M.hgd.check(binding, prior, obs)
    if conflict.fatal:
        M.egc.demote(conflict.edges); return M.fallback(xi, k, lam)
    # 5) 证书与审计
    M.gvc.submit(rho, M.egc.coverage(ep_state.task), conflict, prior.hash)
    return xi["action"][:k], lam, rho
```

## 5. 推导

**引理 19（组合共享的样本复杂度）** 设任务 t 是共享子目标词表 S 与边集 E 上的一条路径，单技能误差上界 ε_s。独立学习时误差随任务数与时长累积；图路由下路径复合误差 ≤ Σ_{s∈path} ε_s + Σ_{e∈path} ε_e，样本主要花在 |S|+|E|。系：32 个任务不必有 32 套技能，数据效率从「任务数」转到「关系数」。

**引理 20（类比迁移的 Lipschitz 界）** 抓取成功率对属性图度量 d_G 满足 L_A-Lipschitz 时，|succ(o\*) − succ(a)| ≤ L_A·d_G(o\*,a)。超过 τ_A 的迁移无意义，应回退；这给 AGA 的置信门限提供理论依据。

**引理 21（伪相关的可检测性）** 若边 e 的支撑来自 nuisance z，则存在扰动 p 使 IG_e(p) ≥ δ_z；n_e 个独立见证下，PDE 以至少 1 − exp(−2n_eδ_z²) 概率剔除 e。系：**扰动稳定性比 demo 支持数更能证明关系**。

**定理 18（严格包含 R69 基座）** 在定义 322 的条件下，KARMA 与 R69 基座逐指令相同；安全侧不劣化。只有 G_cert 非空且 VoI>0 时才获得检索/类比/子目标收益；图不能降低安全阈值或绕过认证。

**定理 19（步骤分与复合误差）** 若官方步骤分在已接地子目标满足上单调（A-step），SDR 的图级进度不降低官方步骤分；图级验证把失败检测提前到子目标边界，复合错误期望下降至少 1 − Π_s(1 − d_s)。A-step 不成立时 ρ_step 只作训练/调试代理，不进入证书。

| 类比可供性（AGA） | < 0.1 ms | O(锚点数) | 仅未见对象触发 |
| 主动感知 VoI（APV） | < 0.1 ms | O(候选动作) | 仅 U_rel 高时触发 |
| FMP 执行 + RAS-WM 认证 | 与 R69 持平（< 2.6 ms） | 40 MB | 复用 R69 执行栈 |
| **端到端常规路径** | **< 3.0 ms**（K=1） | — | 不含网络；N 端口可复制 |
| **端到端验证路径** | **< 3.8 ms** | — | 仅在子目标边界/冲突时 |

工程约束：运行时**不调用 LLM**；图、检索索引、语言解析结果全部离线/缓存。N 个端口各自加载只读图副本，避免跨进程锁。

## 7. 实验设计 E301–E315

## 8. 最值得押注的创新点

**IP-266（EGC）+ IP-267（SDR）**：它们在最小工程量下同时服务两个最硬的指标——**步骤分**（子目标部分信用）与**5 类泛化**（只信被扰动稳定性认证过的边），且不改变基座的安全边界，可独立上线验证。先证明「伪边能被剔除、ρ_step 与官方步骤分同向」，再谈 AGA/APV 的增益，是风险最低、最快能上榜单的一刀。

## 9. 本轮最大风险

**一句话**：KARMA 的全部增益押在「图上一条边在 demo 之外仍然成立」这一假设上——**若伪相关被校准上界误判为高可信，系统会在未见物品与人为干扰上把最近邻场景的抓取先验自信地迁过去；图越「可证」，错误越系统性，而且赛场上没有人能纠正它**。

**次级风险与缓解**：图投毒/幻觉（EGC 误差上界 + HGD 在线冲突 + AIC-KG 红队）；步骤分公式未知导致 ρ_step 错位（E302 的 A-step 检验，不成立则只作代理）；检索泄漏（DPG 的 scene/episode 分块 + leakage 惩罚）；主动感知越界（APV 过 C-RAS-WM 认证 + 时延预算）；N 端口复制导致图副本不一致（kg_hash 固定 + 只读加载）。
