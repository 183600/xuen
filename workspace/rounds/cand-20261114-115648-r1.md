# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~301；灵感循环第 4 轮；本轮灵感：「本体感知」×「末端执行器控制」）

> R73 用 MMS/DPEM/CCA/ΣREFLEX/CPB 把证据计量变成可组合契约，并声称系统级安全在热替换下由组合规则自动保持。但 R73 留了一个**它自己没看见的结构性漏洞**，恰好被本轮两个灵感词命中：
> - **信任根未审计**：定义 378 用「本体/接触/已知几何」作为深度自标定的外部基准——**本体感知被当成真值**。可是关节编码器有量化、谐波减速器有回差与传动误差、连杆在负载下会弹性变形、温度会漂移、采样有同步偏斜、运动学参数本身有标定误差。**审计者自己没有被审计。** 这比 R73 的「隐共享物理耦合」更根本：它是循环认证。
> - **计量/控制交汇没被建模**：末端执行器控制是「证据被消费成动作」的地方，也是「动作产生新证据」的地方。命令位姿与实测位姿之差 r（伺服残差）现在被当成要压小的跟踪误差；但它其实是关于负载、柔顺、回差、运动学参数的**计量观测**。更尖锐的是：**控制器把 r 压到零，就同时把这份证据抹掉了**——控制与计量在对偶方向上打架（dual control）。
> - **换工具 ≠ 换实现**：R73 的热替换定理只保证「同一 EC 的两种实现」可互换；但末端执行器一换（平行夹爪→灵巧手→焊枪），**物理参考系（TCP/工具坐标系）本身变了**，这不是实现替换，而是**规范（gauge）被重新固定**的问题。R73 的定理在这里是空的。
>
> 本轮三个灵感正好补这三块：
> - **本体感知** → **PEM（Proprioceptive Evidence Metrology）**：本体感知六分量不确定度（编码器/传动/负载柔顺/热/同步/运动学参数）+ 与 DPEM 同构的契约化；**关键不是给编码器加一个方差，而是承认本体是相对量测，它不能独自固定全局位姿与尺度**。
> - **末端执行器控制** → **EEC + SRM**：TCP 证书 = 关节证据经雅可比链的 CCA 串联；伺服残差成为一等证据通道（SRM），并以**残差诚实约束**（持续激励/PE）解决「控制压小残差 = 抹除证据」的对偶冲突；AACE 把速度/力/阻抗包络挂到 TCP 不确定度与锚龄上。
> - **信任根** → **T-DAG + 规范理论**：把「谁锚定契约」形式化。内部相对量测对**计量规范群** G_met（SE(3) × 尺度 × 偏置）不变；没有外部见证（硬限位/重力/标定件/已知几何）把规范固定，所有内部一致性审计全过也不能给出有界物理误差。**R73 的最大风险被精确重述为：规范自由度未被见证固定。**
>
> 核心命题：R73 问「证据计量能否成为可组合的契约」；R74 追问「**契约由谁锚定**」——把信任根做成**带见证、会随动作侵蚀、可换工具重锚定**的契约，并证明：**无见证的自指校准在结构上不可认证（规范障碍定理）**；末端执行器控制是计量被消费与生产的交汇，必须在对偶约束下同时保任务与保证据。

## 0. 直觉与动机

**灵感 1（本体感知 → 本体是相对量测，不是真值）**
直觉：编码器测的是关节角，不是世界坐标；IMU 测的是比力与角速度，有偏置且不直接给偏航；力矩传感器有零漂与耦合。把本体当 ground truth，相当于把「一把没有刻度的尺」当基准。本体真正擅长的是**相对、增量、高带宽**：它给出关节运动与接触反作用，却无法独自回答「基座在世界哪里」「TCP 离工件几毫米」「真实尺度是多少」。因此本体的正确角色不是 truth，而是 **anchor chain 中一条需要被计量、且必须被外部见证收口**的证据链。这与 DPEM 把深度从「场景几何」降为「距离/材质/视角条件证据」是同一种降级。

**灵感 2（末端执行器控制 → 计量在末端被消费，也在末端被生产）**
直觉：末端控制把证据变成动作：TCP 证书决定能走多快、能给多大力、能抱多紧。反过来，动作在末端留下痕迹：命令位姿与实测位姿的残差 r 携带负载/柔顺/回差信息。自由空间慢速运动时 r 主要测运动学参数与回差；负载接触时 r 主要测柔顺与外载。**同一个信号，在控制里是要消灭的误差，在计量里是要保留的信息。** 由此得到一个工程悖论：跟踪越好，越难辨识柔顺；要辨识，就得故意「抖一下」（持续激励）。这不是缺陷，而是 dual control 的本质，必须写进契约与预算，而不是留给运气。

**灵感 3（信任根 → 内部一致性对规范群不变）**
直觉：假设所有传感器互相标定、所有残差都很小、conformal 覆盖率也达标。把整个世界坐标系做一个刚体变换（或者把全局尺度放大 2%，同时把标定一起放大），所有**相对**测量与残差完全不变。R73 的审计全是「内部残差 + 覆盖率」，因此对这类**规范扰动**天生失明。要固定规范，必须有**不被同一变换影响**的外部见证：硬限位（固定某个方向的位置）、重力（固定 roll/pitch）、已知尺寸标定件（固定尺度）、已知位姿工装或激光跟踪仪（固定全 SE(3)）。**定理（规范障碍）**：T-DAG 中某个强连通分量若不含见证边，则存在规范轨道，使物理误差任意大而所有内部审计通过。R73 的「隐共享物理耦合」只是它的特例：共享物理过程 = 未被见证覆盖的共模规范方向。

**灵感 4（工具更换 → 重规范而非重实现）**
直觉：换夹爪不是换一段代码，而是把工具坐标系（TCP 在手腕坐标系中的变换）重新定义。旧证书在物理上失效，不是因为实现变了，而是因为**规范锚点移动了**。正确做法：工具更换触发 T-DAG 在 TCP 节点的**局部重锚定**（碰已知工装、用重力辨识工具质量/质心、用已知尺寸件定 TCP），重锚定完成前系统退入**保守工具先验 stub**（精度主张暂停、安全主张保留）。这把 R73 的热替换从「实现同级替换」扩展为「规范可重固定」，认证成本仍是 O(模块) 而非 O(系统)。

**灵感 5（对偶预算 → 控制抑制残差 = 消耗证据）**
直觉：自适应控制/dual control 早已知道「控制既调节又探测」。本方案把它计量化：定义**证据信息量** I(Φ) = ½ log det(I + σ⁻² Σ ΦᵀΦ)，控制动作同时消耗任务代价与证据预算；AACE 在包络内注入最小持续激励（dither/冗余自由度/轨迹微扰），并对残差抑制设上限：**不允许把用于计量频段的残差压到无法辨识的功率以下**。这把「控制越准越好」变成「控制不能以抹除自身计量能力为代价」，是本轮最反直觉、也最可证伪的一点。

## 1. 形式化定义（增量：定义 383–399）

**定义 383（PROGAUGE-RAS 总览）** PROGAUGE-RAS = (MODGAUGE-RAS†, PEM, EEC, SRM, T-DAG, χ_T, AACE, TCC, CPB†)。六不变式：
(i) **见证完备**：任何进入证书的数量，其 T-DAG 必须终止于至少一个外部见证（定义 387）；
(ii) **规范覆盖**：未被见证固定的规范方向必须以显式先验上界进入证书，否则证书无效（定义 388/393）；
(iii) **计量诚实**：控制不得把用于辨识频段的残差功率压到 PE 门槛以下（定义 386/392）；
(iv) **锚定侵蚀记账**：动作与时间对本体/TCP 不确定度及见证有效性的影响进入预算（定义 389/390）；
(v) **契约完整与组合单调**（继承 R73 五不变式 i/ii）；
(vi) **严格退化**：模块失效 → stub；**见证节点失效 → 规范自由度扩张 → 退为保守规范先验**，不得静默继续高精度主张。

**定义 384（PEM 本体感知证据计量）** 观测量 y_p = (关节角 q, 力矩 τ, IMU 比力/角速度, 指令 u, 时间戳)。条件似然 p_prop(y_p | x, load) = 𝒩(y_p; h_p(x), Σ_p)，六分量：
u_prop² = u_enc²(q_res) + u_trans²(θ, sign τ̇, ‖τ‖) + u_comp²(‖τ‖) + u_therm²(ΔT, t) + u_sync²(‖q̇‖, Δt_skew) + u_kin²(κ)。
- u_enc：编码器量化/插值误差（q_res/√12 量级）；
- u_trans：谐波减速器运动误差 + 回差滞环（依赖转向与负载，含死区）；
- u_comp：关节/连杆柔顺 C(τ)·‖τ‖（负载相关，非线性）；
- u_therm：热膨胀 αLΔT 与轴承预紧漂移（慢时变）；
- u_sync：采样-指令-视觉时间戳偏斜 × 关节速度；
- u_kin：连杆长度/关节零位/TCP 参数标定误差经雅可比导数传播。
有效域 D_prop = {编码器无故障 ∧ 无饱和 ∧ ΔT∈范围 ∧ load∈标定域}。每分量独立追溯链 τ_p,i。**PEM 是相对量测：q 给相对关节，IMU 给比力方向，二者都不独自给出世界位姿。**

**定义 385（EEC 末端执行器证据契约与 TCP 证书）** TCP 位姿 x_e = FK(q; κ, κ_tool)。协方差沿 CCA 串联传播：
Σ_TCP = J_q Σ_q J_qᵀ + J_κ Σ_κ J_κᵀ + u_tool² I + u_comp²(τ) I + u_sync² I。
EEC 契约声明：(命令证书, 实测证书, 包络 E=(v_max, f_max, K_imp), 重锚定触发条件, 工具身份)。**TCP 证书是「关节证据 + 运动学参数 + 工具变换」的显式组合，而不是一个常数偏置。**

**定义 386（SRM 伺服残差计量）** 残差 r_t = x_meas − x_cmd（关节或笛卡尔空间）。观测模型 r_t = Φ_t(κ, C, b, τ_ext) + ε_t，其中 b 为回差、C 为柔顺、τ_ext 为外载。辨识要求回归矩阵在窗口内满列秩（**持续激励 PE**）：λ_min(Σ_{t∈W} Φ_tᵀΦ_t) ≥ ε_pe。**残差诚实约束**：控制策略必须保证计量频段内上式成立，或显式注入最小 dither；当控制把 r 在该频段压低到 PE 门槛以下时，SRM 必须声明「证据枯竭」并回退到先验（不得伪造辨识）。
**对偶性**：r 同时是控制误差与计量观测；AACE 的最优控制是 min J_task + λ_m·I(Φ)⁻¹，s.t. PE。

**定义 387（T-DAG 信任有向无环图与见证）** T-DAG = (V_T, E_T, W, γ)。节点 = 数量/模块/坐标系；边 = 「以…为参考/由…标定」；W = 外部见证集（机械硬限位、重力/铅垂、已知尺寸标定件、已知几何工装、基准球/激光跟踪仪、温度基准）；γ: E_T ∪ W → 2^{gauge dirs} 给出每条边能固定的规范方向。要求：
(a) 无环（无自证）；
(b) 每个进入证书的节点存在通向 W 的有向路径；
(c) 任一强连通分量若不含见证边，标记为**规范漂浮（gauge-floating）**，其证书只能是条件证书（给定规范先验）。
**J_root 根证书** = 见证证书 ⊗ T-DAG 覆盖检查 ⊗ 规范先验上界。

**定义 388（计量规范群 G_met 与规范自由度）** 令内部相对量测为 {y_ij = g(x_i, x_j) + ε}。存在群 G_met（位姿用 SE(3)；尺度用 ℝ_+；零位/偏置用 ℝ^k）作用在全局解上，使所有残差不变：∀h∈G_met, y_ij(h·x) = y_ij(x)。**规范轨道** = G_met·x。一个数量是**规范固定**的，当其被主张方向的稳定子平凡；否则其误差沿轨道方向不可由内部数据辨识。**G_free(x)** = 未被见证固定的子群。物理误差 e = e_∥（可辨识）+ e_⊥（规范方向，只能由先验/见证约束）。

**定义 389（锚定侵蚀通道 χ_T）** χ_T: (g, Δt) → (Δu_prop, Δu_TCP, validity(W))。动作 g = (加速度 a, 负载 τ, 热功率 P, 锚龄 s) 使：
∂u_trans/∂‖τ‖ > 0（回差磨损与负载相关）、∂u_comp/∂‖τ‖ > 0、∂u_therm/∂s > 0、∂u_sync/∂(‖q̇‖·‖a‖) > 0，且见证有效性 validity(W) 随 s 与热循环单调下降。χ_T 是 EC 的通道字段（与 χ_v/χ_c 同构），**信任根因此是动作条件化的，而不是常数**。

**定义 390（信任预算 B_trust 与 T_safe）** 信任成本 c_trust^i = α·Δu_prop^i + β·Δu_TCP^i + ρ·(1 − validity(W_i)) + γ·re_anchor_cost。预算 Σ_t Σ_i c_trust^i ≤ B_trust。稳态集 T_safe = { E[u_TCP^{t+1}] ≤ τ_TCP ∧ dim G_free 的每个方向先验 ≤ τ_g ∧ min_i validity(W_i) ≥ 1−δ }。ΣREFLEX 扩展为五层（ψ/z/c/v/T），任一层越界即拒绝动作（非补偿）。**有限停止**沿用引理 36：各层边际成本正下界 + 总边际收益非增。

**定义 391（重锚定与最小见证集）** Re-anchor(W_min)：选择能固定任务所需规范方向的最小子集，使 rank[γ(W_min)] = dim(G_claim)。程序：碰已知工装定位置、重力辨识定姿态与工具质量/质心、已知尺寸件定尺度/TCP。重锚定前，相关模块降为**规范先验 stub**（用保守先验 u_TCP^prior，且不参与 PAR 缩窄）。完成后写回 J_reanchor 并更新 χ_T 锚龄。

**定义 392（锚定感知末端控制 AACE）** 控制律在包络内调度：
v_max = min(v_nom, κ_v·m_stop/u_TCP)，f_max = min(f_nom, κ_f·τ_TCP/u_TCP)，K_imp = K_0 + κ_K·u_TCP；
约束：(a) 停止距离 ≤ 安全裕度；(b) λ_min(Σ ΦᵀΦ) ≥ ε_pe（计量频段）；(c) 预测时域内 u_TCP(t) ≤ τ_TCP 且 validity(W) 不越界。
轨迹证书 J_traj：∀t∈[0,H]，(a)(b)(c) 成立。**当 (b) 与任务冲突时，AACE 优先保证据（降速/用冗余自由度激励），而不是关闭计量。**

**定义 393（见证感知组合 CCA† / COMP-WITNESS）** 在 R73 CCA 上增加规范标注：
- 每个组合节点携带 (used gauge dirs, witness support, G_free)；
- SER/PAR/VETO 仅当 `witness_connected(subgraph, used dirs)` 且 `rank γ ≥ |used dirs|` 时可给出**无条件证书**；
- 否则输出**条件证书**：u_out 附加规范先验项 u_gauge(G_free)，且 **PAR 禁止缩窄**（未知共模方向不能被两模态的统计一致性抵消）；
- **COMP-WITNESS**：把见证作为第三方输入参与 VETO；见证缺失 = 该方向否决。
J_comp 增加 gauge check。

**定义 394（工具更换契约 TCC）** 工具更换 = TCP 节点重规范：ToolID → 所需见证子空间 → Re-anchor(W_min^tool)。过渡期：EEC 证书置为「规范未定」，AACE 进入保守模式（v_max↓、f_max↓、禁高精度接触），**安全侧不降**。完成后只需重认证工具模块与 TCP 边，成本 O(工具模块)，非 O(系统)。**这是 R73 引理 35 的必要补充：同 EC 替换不足以保证物理等价，规范锚点也必须保持或重建。**

**定义 395（本体感知威胁面 ℰ_prop）** {编码器欺骗/重放、回差死区利用、负载柔顺失配、热漂移诱导、时间戳重放/偏斜、运动学参数投毒、伺服残差投毒}。防线：见证交叉核验 + 残差 conformal 审计 + 多源否决（继承 E356/E357 单源不定案）+ 锚龄上限。

**定义 396（CPB† 与主张 C4）** 新增 **C4（信任根可靠性）**：无外部见证的自指校准不可认证；见证连接 + 规范覆盖使证书可证。绑定：
- C4 ← (T-DAG, G_met, Re-anchor, TCC) ← MB4 ← AB4（自指 vs 见证 vs 见证+重锚定）← (规范扰动检出率, 证书-物理误差间隙, 重锚定后残差)；
- C2† 纳入 χ_T 信任预算；C3† 纳入工具更换重认证。
非绑定组件仍为工程附件。

**定义 397（PEMBench：MB4/MB5/MB6）** MB4 本体计量（关节扫掠 × 负载 × 温度 × 速度矩阵）；MB5 工具更换重锚定（夹爪↔灵巧手↔焊枪）；MB6 规范扰动注入（全局 SE(3)/尺度/零位扰动，检查内部审计是否失明）。各 ≤3h 单卡可复现，预注册 + 固定种子 + 密封集 SEAL-PB。

**定义 398（模块级退化更新）** PEM/EEC/SRM 失效 → 各自 stub（u=∞、D=∅）。**见证节点失效 → 不得普通 stub**：其固定的规范方向转入 G_free，证书降为条件证书并扩大 u_gauge；若任务需要该方向精度，则必须重锚定或拒绝高精度动作。区分「证据缺失（可 stub）」与「规范未定（证书空洞，必须停精度）」——这是 R73 stub 语义遗漏的第二种失效。

def residual_metrology(r, Phi, window, eps_pe):

    info = 0.5*math.logdet(I + M/self.sigma2)
    if lmin(M) < eps_pe:

def trust_audit(tdag, claim_dirs):

        paths = witness_paths(tdag, v)
        if not paths: return Fail('GAUGE_FLOATING', node=v)
        support |= union(tdag.gamma[e] for p in paths for e in p)
    if not claim_dirs <= support:

                           free=claim_dirs - support)
    return Certified()

## 3. 推导

**引理 38（PEM 六分量的条件正交性）** 给定 (转向与负载、温度历史、采样偏斜、运动学参数) 条件下，六分量由独立物理机制产生（量化、齿轮啮合/回差、弹性变形、热膨胀、时序、参数访存），条件近似不相关；遗漏任一 ⇒ 系统性低估。系：**本体与深度、接触三者的计量结构同构，都是「(动作, 场景) 条件」的证据链。**

**引理 39（TCP 证书的单调传播）** Σ_TCP 的每一项半正定且随 Σ_q、Σ_κ、u_tool、u_comp 单调不减；J_q 在有效域内 Lipschitz ⇒ 上游任何不确定度增加都不会使 u_TCP 减小。系：**TCP 证书是 CCA 串联的实例，不是新的组合规则——工具/关节/参数在同一代数里。**

**引理 40（SRM 可辨识性与残差诚实）** 残差辨识有界解当且仅当 λ_min(Σ ΦᵀΦ) ≥ ε_pe；控制 u_t 若使计量频段残差功率 → 0，则回归矩阵秩退化，信息量 I(Φ) → 0，辨识协方差 → ∞。⇒ **存在控制-计量对偶：任务最优控制与证据最优控制在无约束下冲突。** AACE 的 PE 约束给出 Pareto 前沿；系：**「跟踪误差越小越好」在计量意义上是错的。**

**引理 41（内部残差的规范不变性）** 对任意 h∈G_met，所有内部相对残差 r_ij 满足 r_ij(h·x) = r_ij(x)（相对位姿、相对距离、零位差在一致变换下不变）⇒ 任何仅依赖内部残差的审计（含 R73 conformal 覆盖率）对 h 的方向不可辨识。系：**R73 的审计不是错的，而是不完整的——它审计了「内部一致性」，没有审计「规范固定」。**

**定理 30（规范障碍）** 若某规范方向 d 不被 T-DAG 的任何见证路径覆盖，则 ∀ε>0，存在 h_d∈G_met 与配置 x，使 |h_d·x − x| > ε（物理误差任意大），而所有内部残差、conformal 覆盖率、组合单调性检查与 R73 J_MOD 全部通过。**证明**：由引理 41，内部残差对 h_d 不变；取 h_d 沿 d 方向平移/缩放/加零位，残差不变；J_MOD 只引用内部残差与契约，故不变；而物理误差随 h_d 幅值线性增长。∎ 系：**「所有模块证书有效 + 所有组合校验通过」不能推出有界物理误差——除非补上见证覆盖。这是 R73 最大风险的严格形式。**

**定理 31（见证连接 + 先验有界 ⇒ 证书可靠）** 若任务所需规范方向被见证集 W 以满秩固定，且未被固定的方向有先验上界 τ_g，则证书给出的物理误差界 u_cert = u_internal ⊕ τ_g 成立。**证明**：误差分解 e = e_∥ + e_⊥（定义 388）；e_∥ 由内部证据与 conformal 覆盖约束，e_⊥ 由见证/先验约束；两者正交分解，界相加（⊕）。∎ 系：**证书必须显式写出它「没有证明什么」（G_free 与先验），否则是伪证书。**

**引理 42（锚定侵蚀的 Lipschitz 性与预算吸收）** χ_T 对 (‖τ‖, ‖q̇‖, s, 热循环) Lipschitz；见证有效性单调下降 ⇒ 信任成本有正下界且对动作 Lipschitz；结合各层边际成本正下界与总收益非增 ⇒ 信任预算存在有限重锚定步数 n*。系：**信任不是一次性建立的，而是会衰减、必须补充的预算项。**

**定理 32（工具更换 = 重规范；最小见证恢复）** 设新旧工具所需规范子空间为 G^tool，若 W_min 使 rank γ(W_min)=dim G^tool，则重锚定后 TCP 证书与「从未换工具且已锚定」的系统在 EEC 层逐指令等价（同 EC + 规范固定）；重认证只涉及工具模块与 TCP 边，成本 O(模块)。**证明**：由定义 394 与引理 35，同 EC 替换保持系统性质；剩余差异仅为规范锚点，W_min 满秩消除 G_free；证书依赖仅经 EC 与 J_root。∎ 系：**R73 热替换定理的正确边界是「实现 + 规范」双保持。**

**定理 33（PROGAUGE 严格包含）** 在 A114–A116（PEM 物理模型覆盖、见证集物理独立、PE 约束可满足）下：MODGAUGE（R73）是 PROGAUGE 的「PEM 置平凡、SRM 关闭、T-DAG 全见证」实例；退化链 PROGAUGE → MODGAUGE → EMBODIED → R71 → R68 逐指令等价，安全侧只增不减。**新增的 C4 不是替代旧保证，而是把旧保证的隐含前提显式化。**

**定理 34（AACE 的安全包络）** 在包络 (v_max, f_max, K_imp) 与 PE 约束下，对预测时域内任意可达轨迹，u_TCP(t) ≤ τ_TCP 且停止距离 ≤ 安全裕度；若 PE 约束不可满足（任务不允许激励），AACE 必须降级为「保守控制 + 证书降级（u_gauge 增大）」，而不是维持伪精度。∎ 系：**安全与精度在证据不足时被显式分离：安全可保，精度必须诚实撤回。**

## 6. 本轮最大风险

**一句话**：PROGAUGE 把信任根从「本体感知」搬到了「**外部见证**」，但见证本身可能与被计量误差**共享共模物理过程**——标定件和工件在同一条热膨胀链上、硬限位在负载下同样变形、基准球与相机共享同一温度场、激光跟踪仪与机器人共享同一地基振动。此时规范在方程上被「满秩固定」，在物理上却锚在同一个漂移上：这是**伪见证**，它让证书从「循环认证」升级为「看起来有外部锚点的循环认证」，审计日志会比 R73 更完备、也更有说服力地错。

次级风险与缓解：
1. **伪见证/共模耦合** → 见证独立性审计：见证必须与被测量物理通道不同（不同材料/不同支撑/不同原理），并引入环境共模传感器作为 VETO 第三方；怀疑相关时增大 u_gauge，禁 PAR。
2. **PE 约束与任务冲突** → 允许「任务优先级 + 证据欠账」记账：暂不激励则记录 u_gauge 增长，后续强制补偿或降精度；不静默。
3. **PEM 模型在极端负载/温度漂移** → 有效域硬边界 + 在线查表回退 + 断链即 stub。
4. **规范群建模不全（非线性/非群结构误差）** → 以局部李代数近似 + 有效域；超域即条件证书。
5. **工具更换物理程序失败** → 保守 stub + 拒绝高精度接触，安全侧不变。
6. **T-DAG 增长失控** → 深度 ≤6、见证 ≤3、|V_T|≤32 的图性质审计（定义 399）。
7. **C4 主张被误读为「只要有见证就安全」** → 明确 C4 是**必要条件**（无见证不可认证），不是充分条件；充分性仍需 C1–C3。

## 2. 形式化定义（要点版）

**定义 383（PROGAUGE 总览与六不变式）** 见证完备 / 规范覆盖 / 计量诚实 / 锚定侵蚀记账 / 契约完整与组合单调（继承 R73）/ 严格退化（见证失效 ⇒ 规范先验，不得静默高精度）。

**定义 384（PEM）** p_prop(y_p|x,load)=𝒩(h_p(x),Σ_p)；六分量各有独立追溯链；D_prop 为有效域；**本体是相对量测**：单独不能定世界位姿/尺度。

**定义 385（EEC）** TCP 位姿 x_e=FK(q;κ,κ_tool)；Σ_TCP 由关节、运动学参数、工具变换、柔顺、同步五项串联；EEC 声明命令证书、实测证书、包络、重锚触发、工具身份。

**定义 386（SRM）** r_t=Φ_t(κ,C,b,τ_ext)+ε_t；可辨识 ⇔ λ_min(ΣΦᵀΦ)≥ε_pe；**残差诚实**：控制不得把计量频段残差压到 PE 门槛下；否则 SRM 声明证据枯竭并回退先验。

**定义 387（T-DAG）** 信任 DAG + 外部见证 + 规范固定映射 γ；无环、每节点通向见证；无见证边的 SCC = 规范漂浮；根证书 J_root。

**定义 388（G_met）** 内部相对残差对 G_met 不变；规范轨道；规范固定 ⇔ 稳定子平凡；误差分解 e=e_∥+e_⊥；e_⊥ 只能由见证/先验约束。

**定义 389（χ_T）** χ_T(g,Δt) 给出动作与时间对 u_prop、u_TCP、见证有效性的侵蚀；χ_T 是 EC 通道字段（与 χ_v/χ_c 同构）。

**定义 390（B_trust 与 T_safe）** 信任成本 c_trust=αΔu_prop+βΔu_TCP+ρ(1−validity)+γ·reanchor；预算闭合；T_safe 为第五层稳态集；越界拒绝动作；有限重锚定（引理 42）。

**定义 391（重锚定）** 最小见证集 W_min 使 rank γ(W_min)=dim G_claim；程序（碰工装/重力辨识/尺寸件）；重锚前规范先验 stub。

**定义 392（AACE）** v_max/f_max/K_imp 由 u_TCP 与锚龄调度；约束停止距离、TCP 包络、PE；冲突时优先保证据（降速/冗余激励）。

**定义 393（CCA† / COMP-WITNESS）** 组合节点携带 (used dirs, witness support, G_free)；仅有见证满覆盖给无条件证书；否则条件证书 + u_gauge + 禁 PAR 缩窄；见证作为 VETO 第三方输入；J_comp 增加 gauge check。

**定义 394（TCC）** 工具更换=TCP 节点重规范；ToolID→所需见证子空间→Re-anchor；过渡期保守模式且安全侧不降；重认证 O(工具模块)。

**定义 395（ℰ_prop）** 编码器欺骗/回差死区/柔顺失配/热漂移/时间戳重放/运动学投毒/残差投毒；防线=见证交叉核验+conformal+多源否决+锚龄上限。

**定义 396（CPB† 与 C4）** 新增 C4（信任根可靠性）：无见证自指不可认证；绑定 C4←(T-DAG,G_met,Re-anchor,TCC)←MB4←AB4←(规范扰动检出率,证书-物理误差间隙,重锚残差)。C2† 纳入 χ_T，C3† 纳入工具重认证。

**定义 397（PEMBench）** MB4 本体计量 / MB5 工具更换 / MB6 规范扰动；各 ≤3h 单卡，预注册 + 固定种子 + SEAL-PB。

**定义 398（模块级退化更新）** 证据缺失 → 普通 stub（u=∞,D=∅）；**规范失效 → 条件证书 + 扩大 u_gauge，必要时拒绝高精度动作**。两种失效语义必须分开。

**定义 399（复杂度上限更新）** T-DAG 深度 ≤6、每主张见证 ≤3、dim G_met ≤9、PE 窗口 ≤500、见证寿命 ≤24h（按热循环）、|V_T|≤32；均可审计。

```python
# IP-302 PEM：本体感知六分量（感知域 100Hz）
class ProprioceptiveMetrology:
    def update(self, q, dq, tau, imu, cmd, ts, kappa, anchors):
        u_enc  = self.cal.enc_quant(q)                    # 量化/插值
        u_trans= self.cal.trans_error(q, tau, dq)         # 回差 + 谐波传动误差
        u_comp = self.cal.compliance_unc(tau)             # C(τ)·‖τ‖
        u_therm= self.cal.thermal_unc(self.temp_hist, ts) # αLΔT
        u_sync = self.cal.sync_unc(dq, self.skew(ts))     # 速度 × 时间偏斜
        u_kin  = self.cal.kin_unc(kappa, q)               # J_κ Σ_κ J_κᵀ
        u = math.sqrt(u_enc**2 + u_trans**2 + u_comp**2 +
                      u_therm**2 + u_sync**2 + u_kin**2)
        return PropEvidence(u=u, breakdown=(u_enc,u_trans,u_comp,u_therm,u_sync,u_kin),
                            valid=self.domain_ok(q, tau, imu),
                            chi_T=self.chi_T_tau(tau, dq, ts),   # 锚定侵蚀通道
                            tau_chain=self.tchain.merge(...))

# IP-303 EEC：TCP 证书（CCA 串联在关节链上）
def tcp_certificate(q_ev, kappa_ev, tool_ev, load):
    Jq = jacobian_q(q_ev.q)
    Jk = jacobian_kappa(q_ev.q, kappa_ev.kappa)
    Sigma = Jq @ q_ev.Sigma_q @ Jq.T + Jk @ kappa_ev.Sigma_k @ Jk.T
    Sigma += (tool_ev.u_tool**2 + load.u_comp**2 + q_ev.u_sync**2) * I
    return TCPCert(x=FK(q_ev.q, kappa_ev.kappa, tool_ev.kappa_tool),
                   Sigma=Sigma, u=math.sqrt(trace(Sigma)), tool=tool_ev.id,
                   valid=q_ev.valid and tool_ev.anchored)

# IP-304 SRM：伺服残差辨识 + 持续激励约束
def residual_metrology(r, Phi, window, eps_pe):
    M = sum(Phi[t].T @ Phi[t] for t in window)
    info = 0.5 * math.logdet(I + M / self.sigma2)
    if lmin(M) < eps_pe:
        return SREv(identifiable=False, info=info, veto={'EVIDENCE_STARVED'})
    theta_hat = solve(M, sum(Phi[t].T @ r[t] for t in window))   # κ,C,b,τ_ext
    return SREv(theta=theta_hat, info=info, identifiable=True,
                u=cov_from_inverse(M) * self.sigma2)

# IP-305 T-DAG：见证连接与规范覆盖审计
def trust_audit(tdag, claim_dirs):
    if not acyclic(tdag.V, tdag.E):
        return Fail('CYCLE')
    support = set()
    for v in claim_nodes(tdag, claim_dirs):
        paths = witness_paths(tdag, v)
        if not paths:
            return Fail('GAUGE_FLOATING', node=v)
        support |= union(tdag.gamma[e] for p in paths for e in p)
    if not claim_dirs <= support:
        return Conditional(u_gauge=prior_bound(claim_dirs - support),
                           free=claim_dirs - support)
    return Certified()

# IP-306 信任预算 + 重锚定调度
def trust_budget_step(mods, W, g, dt, budget):
    total = 0.0
    for i, m in mods.items():
        c = m.chi_T(g, dt)                            # 侵蚀增量
        if W.validity[i] < 1 - DELTA:
            return 'REANCHOR', i
        total += c
    if budget.spent + total > budget.B:
        return 'REJECT', None
    return 'OK', total

# IP-307 AACE：锚定感知末端控制
def aace_control(ev, cert, task, W, risk):
    u = cert.u
    v_max = min(task.v_nom, risk.kv * risk.m_stop / max(u, 1e-9))
    f_max = min(task.f_nom, risk.kf * risk.tau_TCP / max(u, 1e-9))
    K = task.K0 + risk.kK * u
    return solve_mpc(task, v_max=v_max, f_max=f_max, K_imp=K,
                     pe_floor=risk.eps_pe, horizon=task.H)   # 含停止距离/包络/PE

# IP-308 TCC：工具更换 → 局部重锚定
def tool_change(new_tool, tdag):
    req = witness_requirements(new_tool)      # 需要固定的 gauge 子空间
    invalidate_tcp_edge(tdag, new_tool)
    W_min = minimal_witness_set(req)           # 最小见证集（定义 391）
    plan = reanchor_plan(W_min)                # 碰工装/重力辨识/尺寸件
    return ToolTransition(stub_prior=new_tool.prior, plan=plan,
                          mode='CONSERVATIVE', safety_unchanged=True)

# IP-309 PROGAUGE 主闭环（在 R73 MODGAUGE 上插入 PEM/EEC/SRM/T-DAG/AACE）
def PROGAUGE_round(M, q, dq, tau, imu, depth_img, tac_frame, cmd):
    # === 感知域 100Hz ===
    p_ev = M.pem.update(q, dq, tau, imu, cmd, M.ts, M.kappa, M.tdag.witnesses)
    d_ev = M.dpe.update(depth_img, M.rgb, M.cam_state, M.motion, M.peers)  # R73
    t_ev = M.dmem.update(tac_frame, M.last_action)                          # R72
    if not p_ev.valid: p_ev = self.stub(M.pem)

    # === 计量域 50Hz ===
    if M.clock.due_metric():
        eec = tcp_certificate(p_ev, M.kappa, M.tool, M.load)               # IP-303
        sr  = residual_metrology(M.r[-M.W:], M.Phi[-M.W:], M.W, M.eps_pe)  # IP-304
        ga  = trust_audit(M.tdag, M.claim_dirs)                            # IP-305
        b_t = M.bse.step_full(..., p_ev=p_ev, d_ev=d_ev, t_ev=t_ev)
        g   = M.ervoi.choose(b_t, M.psi, M.z_dist, t_ev.c_dist, M.budget, M.fmp, M.bse)
        if g:
            status, i = trust_budget_step(M.mods, M.tdag.witnesses, g, M.dt, M.budget)
            if status == 'REANCHOR': M.tcc.reanchor(i)                     # IP-308
            elif status == 'OK':     M.state = sigmareflex_step(M.mods, g, M.state, M.budget)[0]
        M.aace = aace_control(eec, eec, M.task, M.tdag.witnesses, M.risk)  # IP-307
        M.snapshot.write(b_t, eec, sr, ga, M.state)

    # === 控制域 1kHz（继承 R73，只读快照）===
    snap = M.snapshot.read_latest()
    lam = embodied_risk_scale(snap.U_ale, snap.U_epi, snap.H_z,
                              max(snap.d_ev.u, snap.p_ev.u), M.risk_params)
    k = M.c_ras_wm.certified_prefix(M.ach.propose_ctrl(..., aace=snap.aace), lam)
    M.ctrl_out.publish(k, lam)
    return k, lam, J_MOD(M.mreg) | J_root(M.tdag, M.claim_dirs)            # 组合+根证书
```

## 4. 推导

**引理 38（PEM 六分量的条件正交性）** 给定 (转向与负载、温度历史、采样偏斜、运动学参数) 条件下，六分量由独立物理机制产生（量化、齿轮啮合/回差、弹性变形、热膨胀、时序、参数访存），条件近似不相关；遗漏任一 ⇒ 系统性低估。系：**本体与深度、接触三者的计量结构同构，都是「(动作, 场景) 条件」的证据链。**

**引理 39（TCP 证书的单调传播）** Σ_TCP 每项半正定且随 Σ_q、Σ_κ、u_tool、u_comp 单调不减；J_q 在有效域内 Lipschitz ⇒ 上游任何不确定度增加都不会使 u_TCP 减小。系：**TCP 证书是 CCA 串联的实例，不是新组合规则——工具/关节/参数在同一代数里。**

**引理 40（SRM 可辨识性与残差诚实）** 残差辨识有界解 ⇔ λ_min(ΣΦᵀΦ)≥ε_pe；控制若使计量频段残差功率→0，则回归矩阵秩退化，I(Φ)→0，辨识协方差→∞。⇒ **控制-计量对偶：任务最优控制与证据最优控制在无约束下冲突。** AACE 的 PE 约束给出 Pareto 前沿。系：**「跟踪误差越小越好」在计量意义上是错的。**

**引理 41（内部残差的规范不变性）** ∀h∈G_met，所有内部相对残差满足 r_ij(h·x)=r_ij(x) ⇒ 任何仅依赖内部残差的审计（含 R73 conformal 覆盖率）对 h 的方向不可辨识。系：**R73 的审计不是错的，而是不完整的——它审计了「内部一致性」，没审计「规范固定」。**

**定理 30（规范障碍）** 若规范方向 d 不被 T-DAG 任何见证路径覆盖，则 ∀ε>0，存在 h_d∈G_met 与配置 x，使物理误差 |h_d·x−x|>ε，而所有内部残差、conformal 覆盖率、组合单调性与 R73 J_MOD 全部通过。**证明**：由引理 41，内部残差对 h_d 不变；取 h_d 沿 d 平移/缩放/加零位，残差不变；J_MOD 只引用内部残差与契约，故不变；物理误差随 h_d 幅值线性增长。∎ 系：**「所有模块证书有效 + 所有组合校验通过」不能推出有界物理误差——除非补上见证覆盖。这是 R73 最大风险的严格形式。**

**定理 31（见证连接 + 先验有界 ⇒ 证书可靠）** 若任务所需规范方向被 W 满秩固定，未固定方向有先验上界 τ_g，则物理误差界 u_cert = u_internal ⊕ τ_g 成立。**证明**：e=e_∥+e_⊥；e_∥ 由内部证据与 conformal 覆盖约束，e_⊥ 由见证/先验约束；正交分解界相加。∎ 系：**证书必须显式写出它「没有证明什么」（G_free 与先验），否则是伪证书。**

**引理 42（锚定侵蚀的 Lipschitz 与预算吸收）** χ_T 对 (‖τ‖,‖q̇‖,s,热循环) Lipschitz；见证有效性单调下降 ⇒ 信任成本正下界且对动作 Lipschitz；结合各层边际成本正下界与总收益非增 ⇒ 信任预算存在有限重锚定步数 n*。系：**信任不是一次性建立的，而是会衰减、必须补充的预算项。**

**定理 32（工具更换 = 重规范；最小见证恢复）** 设工具所需规范子空间 G^tool，若 rank γ(W_min)=dim G^tool，则重锚定后 TCP 证书与「从未换工具且已锚定」系统在 EEC 层逐指令等价（同 EC + 规范固定）；重认证只涉及工具模块与 TCP 边，成本 O(模块)。**证明**：由定义 394 与引理 35，同 EC 替换保持系统性质；差异仅为规范锚点，W_min 满秩消除 G_free；证书仅经 EC 与 J_root。∎ 系：**R73 热替换定理的正确边界是「实现 + 规范」双保持。**

**定理 33（PROGAUGE 严格包含）** 在 A114–A116（PEM 物理模型覆盖、见证集物理独立、PE 约束可满足）下：MODGAUGE 是 PROGAUGE 的「PEM 置平凡、SRM 关闭、T-DAG 全见证」实例；退化链 PROGAUGE → MODGAUGE → EMBODIED → R71 → R68 逐指令等价，安全侧只增不减。**C4 不是替代旧保证，而是把旧保证的隐含前提显式化。**

**定理 34（AACE 安全包络）** 在包络 (v_max,f_max,K_imp) 与 PE 约束下，预测时域内任意可达轨迹满足 u_TCP(t)≤τ_TCP 且停止距离≤安全裕度；若 PE 不可满足（任务不允许激励），AACE 必须降级为「保守控制 + 证书降级（u_gauge 增大）」，而非维持伪精度。∎ 系：**安全与精度在证据不足时被显式分离：安全可保，精度必须诚实撤回。**

## 7. 本轮最大风险

**一句话**：PROGAUGE 把信任根从「本体感知」搬到「**外部见证**」，但见证本身可能与被计量误差**共享共模物理过程**（标定件与工件在同一条热膨胀链上、硬限位在负载下同样变形、基准球与相机共享温度场、激光跟踪仪与机器人共享地基振动）——此时规范在方程上被「满秩固定」，物理上却锚在同一个漂移上：**伪见证**让证书从「循环认证」升级为「看起来有外部锚点的循环认证」，审计日志比 R73 更完备、也更有说服力地错。

次级风险与缓解：
1. **伪见证/共模耦合** → 见证独立性审计（不同材料/支撑/原理），环境共模传感器作 VETO 第三方；怀疑相关时增大 u_gauge、禁 PAR。
2. **PE 约束与任务冲突** → 「任务优先级 + 证据欠账」记账：暂不激励则记录 u_gauge 增长，后续强制补偿或降精度，不静默。
3. **PEM 极端负载/温度漂移** → 有效域硬边界 + 在线查表回退 + 断链即 stub。
4. **规范群建模不全（非线性/非群结构）** → 局部李代数近似 + 有效域；超域即条件证书。
5. **工具更换物理程序失败** → 保守 stub + 拒绝高精度接触，安全侧不变。
6. **T-DAG 增长失控** → 深度 ≤6、见证 ≤3、|V_T|≤32 图性质审计（定义 399）。
7. **C4 被误读为「有见证就安全」** → C4 只是**必要条件**（无见证不可认证），不是充分条件；充分性仍需 C1–C3。
