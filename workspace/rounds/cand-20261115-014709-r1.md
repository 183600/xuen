# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「轮足机器人」×「论文发表」）

> R69 把不确定性一分为二：aleatoric 交给 R68 的保守铁律，epistemic 交给「流匹配多模态策略 + 主动多模态交互」去消解，并用「消解成功就发 resolution bonus、把 λ 降下来」奖励去问。但这条奖励通道是一次**自评自证**：回答被并入后验时，隐含假设「回答的似然模型是对的」；一旦模态被「消解」，它就直接驱动策略、甚至进入训练，而 R69 没有任何机制在事后说「这条结论撤回来」。R69 自陈的最大风险（问错比不问更危险）只是被「k 源一致」挡了一下，而 k 源一致本身仍由同一个模型、同一批数据、同一套盲区来判定。于是 R69 最深的漏洞不是「问得不够多」，而是**它没有办法区分「被验证的相信」与「被确认的偏见」**。
>
> 本轮两个灵感正好补上这块：
> - **轮足机器人**给出「两种速度 + 一条信任边界」的结构：轮子高效但只在地形假设成立时安全，腿鲁棒但贵、慢、耗能；系统真正的难点是**何时敢用轮子**，以及**换挡本身是否安全**。
> - **论文发表**给出「知识如何变成可信知识」的制度：预注册、独立复现、artifact 复现、撤稿与连坐、阴性结果登记、以及对发表偏倚与 salami slicing 的防御。它的保证是**错误发现率（FDR）**，不是后验概率——因为审稿人是**对抗的**，不是合作的。
>
> 核心命题：**把「执行速度」与「知识可信度」解耦。只有通过发表门（公开、可复现、抗审稿人、FDR 受控）的知识才能进入快档（轮）；候选知识只能在慢档（腿）的沙盒里使用；撤稿永远允许且必须传播。** R69 恰是「把所有消解结果都直接发表（q=1）」的退化，R68 是「不交互 + 全发表」的退化。命名 **PEDAL-RAS**（Publication-gated Epistemic Dual-regime Adaptive Loop）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**哪些答案配被相信、被记住、被拿来跑快档**」——提问之后是发表，相信之后是撤稿。

## 0. 直觉与动机

**灵感 1（轮足机器人 → 两种速度，一条信任边界）**
轮足机器人最反直觉的地方不是「既能滚又能走」，而是：轮子模式高效，却**只在「地面足够平」这个假设成立时才安全**；腿模式鲁棒，却**贵、慢、耗能**。决定系统好坏的往往不是两种步态各自多强，而是三件更细的事：(a) 一个「我还在认证包络内吗」的判断器是否可信；(b) 换挡本身是否安全（不能悬空换挡、不能在临界相位抖振）；(c) 一旦轮子模式出事，能否快速降级到腿。把这三件事搬到认知系统：**快档（轮）只允许执行已「发表」（被独立验证过）的知识；慢档（腿）在沙盒里探索、验证、处理 OOD；换挡要有迟滞与转换认证；出错永远先降级到慢档。** R69 的 FLUID 层恰恰没有这条信任边界——它一「交互消解」就立刻把 λ 降下来（resolution bonus），相当于**把轮子模式开到了未经认证的地形上**。

**灵感 2（论文发表 → 验证是对抗博弈，不是贝叶斯更新）**
R69 把回答并入后验时，隐含假设回答的似然模型是对的；但科学共同体的经验相反：**同行评审的价值不在于确认，而在于尽力证伪**。真正让知识可信的是一整套制度：预注册（防止看完数据再编假设）、独立复现（held-out 数据）、artifact 复现（种子/环境/代码可重跑）、撤稿与传播（错误要能低成本收回并连坐）、以及对发表偏倚的阴性结果登记（否则知识库只记得成功，系统性高估自己）。最关键的是，这套制度的保证是**错误发现率（FDR）**，不是后验概率——因为审稿人也在读你的方法，会针对你的检验去找反例。

**灵感 3（合起来 → 快慢分离 = 可发表知识 × 可切换执行）**
把两个灵感叠起来，得到一个清晰的分层：**知识分两级（K_cand 候选 / K_pub 已发表），执行分两档（L 腿 / W 轮）**。W 档只能调用 K_pub；K_cand 只能在 L 档的沙盒里执行、且可逆。发表门把 K_cand 提升到 K_pub，撤稿与传播把 K_pub 打回 K_cand 并收缩依赖它的包络。这样「不确定性」之后的下一层不是「再问一次」，而是「**这次相信要不要被制度化地固定下来**」。R69 的交互是瞬时的；R70 的发表是有状态的、可审计的、可撤销的。

**灵感 4（对 R69 的正面回应：可撤稿的证书）**
R69 的 J_FLUID 是一张快照证书，只能证明「当时看起来没问题」，不能证明「现在还成立」，更不能证明「当初的结论没被后来的数据推翻」。PEDAL 给每条进入 K_pub 的知识一个依赖 DAG：一旦新数据上复现失败或审稿人给出反例，撤销 φ，把所有依赖 φ 的策略降级、收缩包络。核心不对称：**收缩永远允许（fail-safe），扩张必须过审（fail-slow）**。这正是 R69 缺的那半条回路。

**灵感 5（对本研究循环自身的同行评审：反 salami slicing）**
每一轮「加一层、发一批 IP」本身就是 salami slicing 的温床：把一个大假设切成很多可发表的小块，逐块重置显著性预算，于是「论文数」涨了，「真知识」没涨。R70 因此引入 **novelty-per-cost + MERGE**：若新主张与已发表主张统计上不可区分，就**合并而不是发表**；被切分的主张在 FDR 记账时只算一次检验。**本轮刻意不以 IP 数量为目标，而以「能被后续轮次安全撤稿」为目标**——一个不能被撤稿的框架，才最可疑。

**灵感 6（新攻击面：制度也会被优化压力腐蚀）**
一旦「发表」能换来 resolution bonus（更快、更省、更少交互），系统就有动机去**讨好审稿人**：只报显著结果、藏阴性结果、把一次实验切成多次、在审稿人分布上过拟合、用「看起来可复现」的 artifact 蒙混。所以威胁模型必须包含 **gate gaming**，而不只是外部投毒。R70 的敌人不只是「撒谎的人类」，还有「被优化压力腐蚀的科学家」。

## 1. 形式化定义（增量：定义 310–323）

**定义 310（PEDAL-RAS 总览）** PEDAL-RAS = (WLA, CE, PG, R2, ARC, RRP, NM, RAS-WM†)。三条不变式：
(i) **快档只读已发表知识**：W 档只允许执行 K_pub 中的策略/主张；K_cand 只能在 L 档沙盒中使用且可逆；
(ii) **发表门单向阀**：K_pub ⊆ … 只能经 PG 提升，且任一时刻其 FDR ≤ q；提升必须过审，撤销永远允许；
(iii) **换挡需认证**：W↔L 切换满足迟滞与驻留时间，并通过 C-RAS-WM 的转换安全检查；失败默认落 L。

**定义 311（双档执行 regime）** r_t ∈ {W, L}。W（轮）：快、低能耗、低方差、要求处于认证包络内；L（腿）：慢、高能耗、高方差、允许探索与候选知识。两档共享 R68 的安全包络，但**可用知识集不同**。

**定义 312（认证包络 certified envelope）** 对已发表策略 π ∈ K_pub，包络 ℰ_π ⊆ 𝒪 是其在 held-out 复现上成功率满足 P(success | o ∈ ℰ_π, π) ≥ 1 − δ_env 的观测子集。o ∉ ℰ_π 称为「出界」；出界时 W 档禁用 π。

**定义 313（可信胜任判断器 CE / 共形校准）** g_ψ(o) → [0,1] 预测「在包络内」。用 split-conformal 的非一致性分数在标定集上取阈值 τ_α，使 **P(o ∉ ℰ_π | g_ψ(o) ≥ τ_α) ≤ α**（A100：同一地形族内可交换）。仅在 g_ψ(o) ≥ τ_α 时允许 W 档。分布漂移会破坏可交换性——因此需要 L 档与在线监控（见定义 320），而不是假设它永远成立。

**定义 314（换挡与迟滞 WLA）** 切换势 Φ(s)（风险/出界概率的融合）。W→L：Φ > θ_hi 持续 τ_w；L→W：Φ < θ_lo 持续 τ_l，且 θ_lo < θ_hi（Schmitt 触发）。驻留时间 τ_min、切换成本 c_sw；临界相位（接触/机动中）禁止换挡。

**定义 315（主张与预注册）** 主张 φ = (S_φ, h_φ, T_φ, δ_φ, plan_φ)：作用域、可证伪假设、检验统计量、决策规则、分析计划。**在见到确证数据前**登记进 prereg 台账；未预注册者一律标为 exploratory，**不得发表**（只能留在 K_cand）。这是对 HARKing 的形式化禁令。

**定义 316（Claim–Evidence–Commit 发表协议）** 证据 E_φ = {replication splits, seeds, env_hash, negative_controls}。Commit(φ) 当且仅当：(a) 已预注册；(b) 在 held-out 复现分割上给出**有效 p 值/e 值**并拒绝零假设；(c) R2 在预算内未找到反例；(d) ARC 复现通过；(e) 通过在线 FDR 门（定义 317）；(f) 通过 NM 的切分合并检查（定义 321）。

**定义 317（在线 FDR 发表门 PG）** 主张流 φ_1, φ_2, …，维护 alpha-wealth：初始 w_0 = q（或按 q 设定），第 i 次检验在 α_i ≤ w_{i−1} 下进行；拒绝（发表）则 w_i = w_{i−1} − α_i + ω，否则 w_i = w_{i−1} − α_i（alpha-investing / LORD 族；按独立或任意依赖版本选择，A101）。保证 **FDR(K_pub) ≤ q**。许可的阴性检验会「赚回」部分 wealth，直接对抗发表偏倚。

**定义 318（对抗审稿人 R2 与有效独立性）** 审稿人是**另一组**架构/数据视图/归纳偏置不同的 agent，目标函数是「在预算内最大化反例发现率」，并保留人工升级通道。独立性不假设、只测量：两两错误相关 ρ_ij 给出有效独立审稿人数 k_eff = 1 + (n−1)(1−ρ̄)。只有 k_eff ≥ k_min 的审稿团才可为高代价主张背书；ρ̄ 过高时**必须升级到外部验证或直接降级**（A102）。

**定义 319（artifact 复现证书 ARC）** 证书 = hash(code, data, seeds, env, hardware)；要求同一 artifact 在容差 ε_rep 内**确定性重跑**并通过。无 ARC 的主张不可发表；ARC 过期（依赖/环境漂移）自动降级。

**定义 320（撤稿与传播 RRP）** 发布后监控：新数据上复现失败（有效检验）或 R2 给出可复现反例，则 Retract(φ)。依赖 DAG（A104 无环）上所有后代降级为 K_cand，并**单调收缩**相关包络：ℰ_π ← ℰ_π ∩ {o : π 未使用任何已撤稿依赖}。撤稿立即、传播在同一步内完成，禁止「先解释后撤稿」。

**定义 321（novelty-per-cost 与反 salami MERGE）** 每条主张记 (novelty, cost)。一组仅为一个预注册假设的子集、或在同一数据集上重复切分的主张，在 FDR 记账时**合并为一次检验**。若新主张与某条 K_pub 主张在效应量上不可区分，则 MERGE（更新置信/样本量）而非新增发表。目标函数是「单位成本的真知识增量」，不是 IP 数。

**定义 322（两级知识库与证书）** K_pub（可驱动 W）、K_cand（仅 L 沙盒）。J_PEDAL = (J_FLUID, regime_trace, envelope_coverage, fdr_q, fdr_realized, arc_hash, retraction_count, novelty_per_cost, pedal_ver)。Valid ⇔ Valid(J_FLUID) ∧ 换挡全认证 ∧ 被执行策略无未决撤稿 ∧ FDR_realized ≤ q。

**定义 323（激进度的包络缩放与认知负债）** W 档激进度 ρ_t = ρ_max · m(o)，m 为包络余量（离边界的标准化距离）；出界或负债高则 ρ 自动降。**认知负债** D_epi = Σ_{φ∈K_cand} 使用风险权重：未发表却被反复间接引用的候选主张累积负债；负债超阈值即**封顶 W 档包络**，迫使系统先「还债」（检验或丢弃）。这防止候选知识靠「反正没人查」悄悄变成事实标准。

**定义 324（AIC-PEDAL 威胁模型）** ℰ_PEDAL = ℰ_FLUID × ℰ_gate × ℰ_review：gate gaming（只报显著、藏阴性、切分实验、alpha-wealth 重置、审稿人分布过拟合）、审稿人共谋/同源（伪独立）、artifact 造假（种子挑选、环境特判）、撤稿阻塞（拒绝传播）、以及「用发表换速度」的策略性腐败。

```python
# IP-264 WLA：双档裁决（迟滞 + 转换认证）
class WheelLegArbiter:
    def step(self, o, Phi, r_prev, dwell):
        if r_prev == 'W':
            want_L = (Phi > self.theta_hi) and (dwell >= self.tau_w)
            if want_L and self.c_ras_wm.transition_ok('W->L', o):
                return 'L'
            return 'W'
        else:
            want_W = (Phi < self.theta_lo) and (dwell >= self.tau_l)
            # 额外闸门：包络内有已发表策略，且 CE 判定在界内
            if want_W and self.ce.in_envelope(o) and self.kb.has_published(o):
                return 'W'
            return 'L'

# IP-265 CE：共形胜任判断（分布无关覆盖）
def calibrate_ce(scores_calib, alpha):
    return conformal_quantile(scores_calib, 1 - alpha)   # 阈值 tau_alpha

def in_envelope(o, g_psi, tau_alpha):
    return g_psi(o) >= tau_alpha

# IP-266 PGR：发表门（预注册 + 在线 FDR + 阳性/阴性都入账）
class PublicationGate:
    def __init__(self, q, w0=None):
        self.q, self.wealth, self.pub = q, (w0 or q), []   # alpha-wealth

    def submit(self, phi, evidence):
        if not phi.preregistered:                 return 'exploratory'  # 不发表
        if not self.nm.merge_or_new(phi):         return 'merge'
        alpha_i = min(self.wealth, self.q)        # 本步可投的检验水平
        p = valid_pvalue(phi, evidence)           # held-out 复现分割
        if p <= alpha_i:
            self.wealth += self.omega - alpha_i   # 拒绝：赚回部分 wealth
            self.pub.append(phi); return 'publish'
        self.wealth -= alpha_i                    # 未拒绝：花掉
        return 'reject'                           # 阴性结果照常登记

# IP-267 R2：对抗审稿（不同架构/数据视图的审稿团）
def review(phi, budget):
    findings = []
    for rv in independent_reviewers(phi):        # 按 k_eff 选择，不按数量
        findings += rv.search_counterexample(phi, budget // len(reviewers))
    return findings, effective_independence(reviewers)

# IP-268 ARC：artifact 复现证书
def artifact_certificate(phi):
    h = hash(code(phi), data(phi), seeds(phi), env(phi))
    ok = deterministic_rerun(phi, tol=EPS_REP)
    return (h, ok) if ok else None

# IP-269 RRP：撤稿与连坐（收缩永远允许）
def retract(phi, reason):
    phi.status = 'retracted'
    for dep in dependency_dag.descendants(phi):
        demote(dep)                               # K_pub -> K_cand
    for pi in policies_using(phi):
        pi.envelope = pi.envelope.shrink(phi)     # 单调收缩
    audit.log_retraction(phi, reason)

# IP-274 PEDAL 主闭环（继承 R69，只在「消解」与「执行」之间插入发表/换挡）
def PEDAL_RAS_round(M, obs):
    # 1) R69 的交互消解（慢档，允许候选知识）
    z, o = M.mtm.forward(obs); c, U_cal, _ = M.cof.step(o)
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K=4), z, M.fmp.mode_head)
    g = M.mint.choose_interaction(modes, o, M.budget) if U_epi > TAU_EPI else None
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    # 2) 把「消解结果」当作一条待发表主张，而不是立即兑现
    phi = candidate_claim(modes, U_ale, U_epi, o)
    status = M.pg.submit(phi, M.r2.review(phi, M.budget.review)) if M.pg else 'publish'
    # 3) 只有 publish 才能进 K_pub 并解锁 W；否则留在 K_cand（L 沙盒）
    if status == 'publish' and M.arc.verify(phi):
        M.kb.publish(phi)
    # 4) 双档裁决：包络内 + 已发表 -> W；否则 L；换挡需认证 + 迟滞
    Phi  = M.ce.out_of_envelope_prob(o, U_ale, U_epi)
    r    = M.wla.step(o, Phi, M.r_prev, M.dwell)
    # 5) 执行：W 用已发表策略并按包络余量缩放激进度；L 用候选策略、可逆、可探索
    if r == 'W':
        pi   = M.kb.select_published(o)
        rho  = RHO_MAX * M.ce.margin(o)
        tau  = M.pi_sigma.prefix_dispatch(pi.a[:k], rho)
    else:
        pi   = M.kb.select_candidate(o)           # 沙盒，可回滚
        tau  = M.pi_sigma.prefix_dispatch(pi.a[:k], RHO_L)
    # 6) 发布后监控：新数据复现失败 -> 撤稿 + 连坐 + 包络收缩（fail-safe）
    M.rrp.monitor(obs, M.kb)
    M.vqa_i2.submit_async(status, phi, r, M.ce.margin(o))
    return r, tau, phi, (U_ale, U_epi)
```

## 3. 推导

**引理 19（共形包络 ⇒ 快档安全，含漂移的诚实边界）** 若 CE 在标定集上与部署数据可交换（A100），则 split-conformal 阈值满足 P(出界 | 被 W 档接受) ≤ α，分布无关。故 W 档灾难错误 ≤ α·L_cat + (1−α)·ε_small。**但**：分布漂移破坏可交换性后该界失效——这不是 bug 而是设计前提，故必须由 L 档与撤稿传播兜底（定义 320），并由在线监控检测漂移。系：**快档的安全性是「条件性」的，条件本身必须被监控。**

**引理 20（迟滞 ⇒ 有界换挡、无抖振）** 在 θ_lo < θ_hi 与驻留时间 τ_min 下，任意长度 T 内换挡次数 ≤ T/τ_min；若 Φ 的变化率有界，则抖振（chattering）被消除。总换挡成本 ≤ c_sw·T/τ_min。系：迟滞间隙应按 c_sw 与噪声尺度设定，间隙过小则抖振、过大则反应迟钝。

**引理 21（撤稿传播的单调性与有界连坐）** 在无环依赖 DAG（A104）上，一次撤稿影响的节点数 ≤ 其后代闭包大小；包络缩放在集合包含意义下单调（只会变小）。因此撤稿不会触发「撤销—再发表」振荡，且任意时刻 W 档可用包络 ⊆ 撤稿前包络。系：fail-safe 的代价是能力下降而非安全下降。

**定理 18（在线 FDR 与 R69 的严格包含）** 在 A101（有效 p/e 值、非自适应）、定义 321 的切分合并、以及 R2/ARC 的独立证据下，发表门满足 FDR(K_pub) ≤ q。进一步：(a) 若 q=1 且关闭 R2/ARC/合并检查（即「全部发表」），PEDAL 逐指令退化为 R69（把每个 resolution 立即兑现）；(b) 若再关闭交互（VoI≤0），退化为 R68。因此 **R70 ⊃ R69 ⊃ R68**，且 R69 的 resolution bonus 是「未审稿发表」这一边界情形。安全侧：W 档执行的每条策略都在 K_pub 内，故同状态风险 ≤ R69；效率侧：多付发表/审稿成本，但以包络缩放的激进度换回，且避免 R69「把确认错误当事实」的灾难尾部。

**定理 19（换挡的近最优性与无免费午餐）** 在两档具有不同 (风险, 成本) 剖面、切换成本 c_sw > 0 的设定下，最优策略是「认证余量」上的阈值策略；迟滞间隙随 c_sw 与噪声单调增（A103）。故 Schmitt 触发在阈值策略族内近最优。但**不存在**同时最大化 W 档速度与最小化 L 档验证成本的免费午餐：q 越小越可信、越慢；q 越大越快、越易被污染。PEDAL 的价值是把这条权衡**显式化、可审计化**，而不是消除它。

**推论（反 salami 的必要性）** 若不执行定义 321 的切分合并，攻击者可用「把一次实验切成 n 次」反复重置 alpha-wealth，使实际 FDR 随 n 增长而突破 q——**在有限预算下，发表门会被切分策略击穿**。故 NM 不是可选项，而是 FDR 保证的前提。

## 6. 本轮最大风险

**一句话**：PEDAL-RAS 的全部保证押在「审稿人是真独立」这一前提上——**若 R2 与被告共用同一模型、同一批数据、同一套盲区（同源伪独立），发表门就退化成「自己给自己发录用通知」，系统会带着 FDR 证书自信地把自己的偏见开进快档；更糟的是，一旦「发表」能换来速度，优化压力本身就会去腐蚀制度（切分实验、藏阴性、挑种子、讨好审稿分布），使 q 只是一张被自己人签发的空头支票**——**被制度确认的错误，比没有被确认的错误更难纠正。**

**次级风险与缓解**：审稿人同源（k_eff 实测 + 外部/人工升级 + 异架构审稿团）；salami 击穿 FDR（NM 切分合并 + 阴性登记）；快档包络漂移失效（共形假设显式化 + 在线监控 + L 档兜底）；撤稿阻塞/迟滞（fail-safe 不对称 + 传播原子化）；高频换挡抖振（迟滞 + 驻留 + 转换认证）；实时预算被拖累（发表/审稿全部离线在慢档）。

## 2. 形式化定义（要点版）

**定义 310（总览与三不变式）** 快档只读 K_pub；发表门单向阀（提升必须过审、FDR≤q；撤销永远允许）；换挡需迟滞 + 转换认证，失败默认落 L。

**定义 311–312（双档与认证包络）** W 快/省/低方差、要求包络内；L 慢/贵/高方差、允许探索。ℰ_π 为 held-out 复现上成功率 ≥ 1−δ_env 的观测子集。

**定义 314（换挡迟滞）** Φ>θ_hi 持续 τ_w 才 W→L；Φ<θ_lo 持续 τ_l 才 L→W，θ_lo<θ_hi；临界相位禁换挡。

**定义 315–316（预注册与 CEC 协议）** 先登记分析计划再做确证；Commit 需：预注册 + held-out 有效检验 + R2 无预算内反例 + ARC 通过 + FDR 门 + NM 合并检查。

**定义 317（在线 FDR 门）** alpha-investing/LORD：α_i ≤ w_{i−1}；拒绝则 w 回补 ω，否则花掉。FDR(K_pub) ≤ q；阴性检验回补 wealth，直接对抗发表偏倚。

**定义 318（R2 与有效独立性）** 异架构/异数据审稿团，目标最大化反例发现率；独立性强制度量：`k_eff = 1+(n−1)(1−ρ̄)`，不足则外部/人工升级。

**定义 319（ARC）** 确定性重跑 + 环境/种子/数据 hash；无证书不发表，过期自动降级。

**定义 320（撤稿与传播）** 复现失败或反例成立即撤稿；依赖 DAG 后代降级为 K_cand，包络单调收缩；撤稿与传播原子完成。

**定义 321（NM 与反 salami）** 同一预注册假设的切分、同数据重复切分，在 FDR 记账中合并为一次检验；与已有 K_pub 不可区分则 MERGE。

**定义 322–323（两级知识库/激进度/认知负债）** K_pub 驱动 W、K_cand 仅 L；W 激进度按包络余量缩放；未发表却频被间接引用的候选主张累积 D_epi，超阈封顶 W 包络，逼迫「还债」。

**定义 324（AIC-PEDAL）** 新增 ℰ_gate（只报显著/藏阴性/切分/挑种子/讨好审稿分布）与 ℰ_review（伪独立、共谋、撤稿阻塞）。

```python
# IP-264 WLA：双档裁决（迟滞 + 转换认证）
class WheelLegArbiter:
    def step(self, o, Phi, r_prev, dwell):
        if r_prev == 'W':
            if Phi > self.theta_hi and dwell >= self.tau_w \
               and self.c_ras_wm.transition_ok('W->L', o):
                return 'L'
            return 'W'
        if Phi < self.theta_lo and dwell >= self.tau_l \
           and self.ce.in_envelope(o) and self.kb.has_published(o):
            return 'W'
        return 'L'

# IP-265 CE：共形胜任判断
def calibrate_ce(scores_calib, alpha):
    return conformal_quantile(scores_calib, 1 - alpha)

def in_envelope(o, g_psi, tau_alpha):
    return g_psi(o) >= tau_alpha

# IP-266 PG：发表门（预注册 + 在线 FDR + 阴性登记）
class PublicationGate:
    def __init__(self, q):
        self.q, self.wealth, self.pub = q, q, []
    def submit(self, phi, evidence):
        if not phi.preregistered:          return 'exploratory'
        if not self.nm.merge_or_new(phi):  return 'merge'
        alpha_i = min(self.wealth, self.q)
        if valid_pvalue(phi, evidence) <= alpha_i:
            self.wealth += self.omega - alpha_i
            self.pub.append(phi); return 'publish'
        self.wealth -= alpha_i
        return 'reject'                    # 阴性结果照常登记

# IP-267 R2：对抗审稿（按 k_eff 选审稿团）
def review(phi, budget):
    rvs = independent_reviewers(phi)
    findings = [f for rv in rvs
                for f in rv.search_counterexample(phi, budget // len(rvs))]
    return findings, effective_independence(rvs)

# IP-268 ARC：artifact 复现证书
def artifact_certificate(phi):
    h  = hash(code(phi), data(phi), seeds(phi), env(phi), hw(phi))
    return (h, True) if deterministic_rerun(phi, tol=EPS_REP) else None

# IP-269 RRP：撤稿与连坐（收缩永远允许）
def retract(phi, reason):
    phi.status = 'retracted'
    for dep in dependency_dag.descendants(phi): demote(dep)
    for pi in policies_using(phi):
        pi.envelope = pi.envelope.shrink(phi)
    audit.log_retraction(phi, reason)

def PEDAL_RAS_round(M, obs):

    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K=4), z, M.fmp.mode_head)
    g = M.mint.choose_interaction(modes, o, M.budget) if U_epi > TAU_EPI else None
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    phi = candidate_claim(modes, U_ale, U_epi, o)
    status = M.pg.submit(phi, M.r2.review(phi, M.budget.review)) if M.pg else 'publish'
    if status == 'publish' and M.arc.verify(phi): M.kb.publish(phi)
    Phi  = M.ce.out_of_envelope_prob(o, U_ale, U_epi)
    r    = M.wla.step(o, Phi, M.r_prev, M.dwell)
    if r == 'W':

        tau = M.pi_sigma.prefix_dispatch(pi.a[:k], RHO_MAX * M.ce.margin(o))

    M.rrp.monitor(obs, M.kb)
    M.vqa_i2.submit_async(status, phi, r, M.ce.margin(o))

```

## 4. 推导

**引理 19（共形包络 ⇒ 快档安全）** A100 可交换下，`P(出界 | 被 W 接受) ≤ α`，故 W 档灾难错误 `≤ α·L_cat + (1−α)·ε_small`。漂移破坏可交换性后界失效——这是设计前提，必须由 L 档 + 撤稿传播 + 在线监控兜底。

**引理 20（迟滞 ⇒ 有界换挡）** `θ_lo<θ_hi` 与驻留 `τ_min` 下，任意 T 内换挡 ≤ `T/τ_min`；Φ 变化率有界时抖振消除，总换挡成本 ≤ `c_sw·T/τ_min`。

**引理 21（撤稿传播单调）** 无环 DAG 上，撤稿影响 ≤ 后代闭包；包络在集合包含下单调收缩；故无撤稿—再发表振荡，任意时刻可用包络 ⊆ 撤稿前。

**定理 18（在线 FDR 与严格包含）** A101 + 切分合并（定义 321）+ 独立 R2/ARC 下，`FDR(K_pub) ≤ q`。边界：q=1 且关闭 R2/ARC/合并 ⇒ 逐指令退化为 R69（每个 resolution 立即兑现）；再关闭交互 ⇒ R68。故 R70 ⊃ R69 ⊃ R68；R69 的 resolution bonus = 「未审稿发表」。安全侧 W 只执行 K_pub ⇒ 同状态风险 ≤ R69；效率侧多付验证成本，用包络缩放激进度偿还，并避免「确认错误」的灾难尾部。

**定理 19（换挡近最优与无免费午餐）** 两档不同 (风险,成本)、`c_sw>0` 时，最优策略是认证余量上的阈值策略；迟滞间隙随 `c_sw` 与噪声单调增。故 Schmitt 触发在阈值族内近最优。但不存在同时最大化 W 速度与最小化 L 验证成本的免费午餐：q 小更可信更慢，q 大更快更易污染；PEDAL 的价值是把权衡显式化、可审计化。

**推论（反 salami 是 FDR 的前提）** 不执行切分合并时，攻击者把一次实验切成 n 次即可反复重置 alpha-wealth，实际 FDR 随 n 突破 q。故 NM 不是可选项，而是发表门成立的必要条件。

## 7. 本轮最大风险

**一句话**：PEDAL-RAS 的全部保证押在「审稿人是真独立」这一前提上——**若 R2 与被告共用同一模型、同一批数据、同一套盲区（同源伪独立），发表门就退化成「自己给自己发录用通知」，系统会带着 FDR 证书自信地把自己的偏见开进快档；更糟的是，一旦「发表」能换来速度，优化压力本身就会去腐蚀制度（切分实验、藏阴性、挑种子、讨好审稿分布），使 q 只是一张被自己人签发的空头支票**——**被制度确认的错误，比没有被确认的错误更难纠正。**

**次级风险与缓解**：审稿人同源（k_eff 实测 + 异架构审稿团 + 外部/人工升级）；salami 击穿 FDR（NM 切分合并 + 阴性登记）；包络漂移失效（共形假设显式化 + 在线监控 + L 档兜底）；撤稿阻塞（fail-safe 不对称 + 传播原子化）；高频换挡抖振（迟滞 + 驻留 + 转换认证）；实时预算被拖累（发表/审稿全部离线在慢档）。
