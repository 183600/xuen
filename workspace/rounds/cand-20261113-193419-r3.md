# 第 69 轮（承接第 68 轮「CALM-RAS 自标定·自监督·单模型多任务」IP-243~252；灵感循环第 3 轮；本轮灵感：「低成本方案」×「并发推理」）

> 第 68 轮把「测量可信度」纳入闭环后，暴露了一个 R65–R68 一以贯之、却从未被点名的**第二条元失败**：整个架构是**安全富裕但成本失明（safety-rich, cost-blind）**的。R65 的假设后验、R66 的情绪环、R67 的世界模型 + VQA 审计、R68 的自标定 + 影子训练 + 五关认证，每一层都在「再加一道验证」上做加法，于是实时环路从 2ms 涨到 2.6ms、影子从 0 涨到 500MB、离线从 0 涨到 10⁶ 轨迹——**但这些成本是均匀地付在每一帧上的，而风险是稀疏且重尾的**。更尖锐的是部署事实：这套安全架构只有在贵硬件、贵算力、贵仿真上才跑得起，而最需要它的廉价机器人反而装不上——**安全系统的可达性失败，本身就是一个安全问题**。
>
> 本轮两个灵感恰好是同一问题的两面：
>
> - **低成本方案**问：安全验证的**信息经济学**是什么？哪些验证在 benign 的多数帧上纯属浪费？答案不是「把大模型蒸馏小」（那只是同一件事更便宜地做），而是**不对称验证**——用一条**可证保守的廉价盾**常开兜底，把昂贵的语义验证降级为**只在边际上起作用、其成本按升格率摊销**的旁路；
> - **并发推理**问：验证必须串行地挡在执行之前吗？答案是不是。**把昂贵验证与本体执行并发**，用物理停稳地平线 H 覆盖验证延迟，**投机执行 + 延迟提交 + 到达即否决**，就能把「等验证 → 迟钝 / 不等 → 不安全」的串行两难，变成「盾保证硬安全、并发验证只管语义风险、最坏退回盾」的可分解结构。
>
> 合流命题：
>
> **把安全从「每帧全量验证」重构为「投机—摊销—可证」的调度问题：廉价保形绊线（TSM）做三区决策，昂贵语义验证器与本体并发投机提交（ASC），世界模型走批量投机前瞻（SBR），用物理不变的廉价锚通道（CAX）打破 R68 的慢故障盲带，用算力预算治理器（CBG）在（风险, 期望成本）Pareto 前沿上选工作点——SPARC-RAS（Speculative, Parallel, Amortized, Risk-Certified RAS）。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「测量还准吗」，R69 问「**我付得起多少次验证，又能否一边行动一边验证**」——安全不再是每帧的固定税，而是按风险征收的、带最坏情况保底的可摊销预算。

## 0. 直觉与动机

**灵感 1（低成本方案 → 安全不是每帧的固定税，而是按风险征收的税）**
直觉：R65–R68 的验证成本是**均匀税率**：无论眼前是一个静止的、远离人的、一切正常的场景，还是一个有人快速靠近、力信号可疑、标定在漂移的场景，系统都付出同样的 2.6ms + 影子 + 审计。但风险密度极不均匀：绝大多数帧在廉价监测器看来毫无歧义。于是正确的经济结构是**累进税率**——廉价绊线常开（成本 c_m，极低），只在「有歧义」的少数帧上征收昂贵验证（成本 c_V），期望成本 E[C] = c_m + q·c_V，q 是升格率。关键洞见：**低成本的瓶颈不在系统优化，而在廉价监测器的「风险—覆盖曲线」**——想在零成本档位安全地自动放行足够多的帧，就需要一个在低风险区覆盖极高的廉价表示。这把「低成本」从工程口号变成一条**可证明的成本下界**（引理 19）：给定安全规格 α，任何架构的升格率都不可能低于 1 − cov*(α)。

**灵感 2（并发推理 → 并发不是加速，而是改变了决策结构）**
直觉：串行验证强加一个两难——等 V 再动则响应迟钝，不等则可能不安全。并发推理把这个问题**解耦**：本体按廉价盾的许可**投机执行**，昂贵验证同时在另一个流里跑，结果以「到达即否决（veto-on-arrival）」的方式在物理停稳地平线 H 内生效。于是延迟要求从「验证必须快于控制周期」松绑为「验证只需快于 H」，而 H 由机器人动力学决定（通常 ≫ 控制周期）。这本质上是把**推测执行（speculative execution）/ 投机解码**搬到安全域：draft 是廉价策略，verifier 是 R68 全环，acceptance 是安全证书。并发因此**帕累托改进**：硬安全不变（盾与 V 无关），语义安全更好（V 只删不加），快路径延迟不变（引理 17）。

**灵感 3（并发推理 → 验证是一种排队系统，不是一次函数调用）**
直觉：一旦允许「提前发起验证、稍后取用」，验证就变成**带截止期的排队问题**：升格请求以率 q 到达，验证服务时间 δ_V 有尾部，H 是硬截止期。要保证「截止期前拿到判决」的概率 ≥ 1−γ，需要预取率 p 让验证队列稳定（p·δ̄_V < 1），并由尾部界约束排队长度。**并发把延迟约束翻译成吞吐/利用率约束**——这正是实时系统里 admission control 的标准结论，却从未被安全架构利用。若到达率超过服务能力，唯一正确的动作是**退回盾/安全停机**，绝不是「跳过验证直接放行」。

**灵感 4（低成本方案 ⟂ R68 盲带 → 最便宜的修法不是更强的学习，而是一个「不可标定证人」）**
直觉：R68 的原罪是「标定越强，缓变故障越隐形」。修它不需要更贵的学习器，只需要**一个标定被禁止吸收的独立见证**：重力方向（IMU）、长基线轮/腿里程、已知几何基准——这些物理不变量对相机外参、力零偏等标定量**不可观测**（∂r^anchor/∂c = 0）。于是同一份慢漂移在「标定通道」和「锚通道」上的投影不同：只有标定通道漂 → 是标定；两者同漂 → 是世界/故障。这就是**差分计量**，成本近乎为零，却直接击穿 R68 的盲带（引理 20）。它把「标定是故障之母」改写为「**标定必须有一个不可被它解释的证人**」。

**灵感 5（对 R68 风险对症 + 对历史成本债还账）**
- R68 缓变故障盲带 → CAX 锚通道做**始终在线**的差分见证，盲带收缩为「零锚投影 ∪ ω_f≤ω_cal」的残余（定义 300）；
- R65–R68 的成本债 → TSM 三区 + ASC 投机 + SBR 批量 + CBG 预算治理，把每帧固定税改为按 q 摊销；
- R67 的 VQA 审计成本 → VQA-S 只在升格帧 + 低采样率随机帧上审计，用**保形有效性监控**替代全量审计；
- 与 R68 的保守纪律兼容 → 预算枯竭时 ESCALATE 转 STOP（定义 303），**永远不用「省验证」换「放宽」**。

**灵感 6（本轮七组件 + 继承核）**
1. **TSM Tiered Safety Monitor**：廉价保形绊线，三区决策（ACCEPT / ESCALATE / STOP），风险预算显式分配；
2. **ASC Amortized Speculative Commit**：廉价盾投机执行 + 昂贵验证并发 + 延迟提交 + 到达即否决 + H 内可回滚；
3. **SBR Speculative Batch Rollout**：廉价 draft 轨迹 + 仅边界点批量调用昂贵 WM（并发 batching），误差有界；
4. **CAX Calibration-Excluded Anchor**：物理不变锚通道，COF 对其零增益投影，直接供给故障归因；
5. **CBG Compute Budget Governor**：在线估 q、解（风险,期望成本）约束优化，选择工作点，输出 Pareto 点；
6. **VQA-S Sampling Auditor**：只在 ESCALATE + 低率随机样本上审计，兼作保形有效性与漂移监控；
7. **RAS-WM§ 继承核**：CALM-RAS 全保留，只是昂贵部件（V、全量校准、全量审计）变为事件触发/并发旁路。

## 1. 形式化定义（增量：定义 293–307）

**定义 293（SPARC-RAS 总览与三不变式）** SPARC-RAS = (TSM, ASC, SBR, CAX, CBG, VQA-S, RAS-WM§)。三不变式：
(i) **盾不变式**：快路径上执行的任何动作 a_t 都必须由廉价确定性模型证明其在停稳地平线 H 内可恢复（a_t ∈ 𝒮_H）；昂贵验证只能**否决**，绝不能授权超出盾已许可的动作；
(ii) **摊销成本不变式**：昂贵验证只在歧义区（或预取触发）发起；最坏单帧墙钟仍 ≤ max(c_m, c_V)+提交开销，期望成本 E[C] ≤ c_m + p·c_V + c_SBR，且 p、q 在线可测；
(iii) **锚排除不变式**：COF 对锚通道零增益（∂r^a/∂c ≡ 0），锚残差绕过标定直接进入故障归因——标定永远无权「解释掉」一个物理证人。

**定义 294（廉价绊线与保形风险界 TSM）** 廉价监测器 m: 𝒳 → [0,1]（单次成本 c_m ≪ c_V，可蒸馏/线性/物理残差混合）。在校准集 D_cal（|D_cal| = n，与部署可交换，假设 A95）上按 split-conformal 构造风险上界
`U_m(x) = Q_{1−α_acc}( {s(z) : z ∈ D_cal} ∪ {s(x)} )`，
满足 `P(risk(x) > U_m(x)) ≤ α_acc + 1/(n+1)`；下界 L_m(x) 对偶构造用于停止区。**注意这是边际（marginal）保证**，条件化/分布偏移见 E287 与引理 16 的注记。

**定义 295（三区决策与风险预算分配）** 给定 (τ_acc, τ_esc)：
- **ACCEPT**：U_m(x) ≤ τ_acc（廉价自动放行）；
- **STOP**：L_m(x) > τ_esc 或锚告警（安全停机/强降级，零自主风险）；
- **ESCALATE**：其余（升起昂贵验证 V）。
总风险预算分解 `α_spec ≥ α_acc + q·α_V + α_hero`，其中 q = P(ESCALATE)，α_V 为 V 的误差（即 R68 的 α_chunk+δ_fi+…+α_cal 之和），α_hero 为罕见英雄动作/人工接管项的界。三区把「安全」与「成本」显式地拆成可分配的两个旋钮。

**定义 296（盾与停稳地平线）** 硬安全集 𝒮_hard（关节/力/人机距离/急停可达）。`𝒮_H = { a : 执行 a 并在其后施加应急安全策略，可在 H 内使状态保持于 𝒮_hard }`。H ≥ p99 验证延迟 δ_V^p99（必须由 CBG 在线核验）。𝒮_H 由廉价确定性运动学 + 力限模型给出，**不依赖任何学习模型**——这是硬安全与语义安全的解耦点。

**定义 297（并发投机提交 ASC）** 时刻 t：廉价策略给出 a_t，异步发起 V(obs_t)。若 `a_t ∈ 𝒮_H` 且 `U_m ≤ τ_acc`，则**暂定执行**（PROVISIONAL）；否则转 ESCALATE/STOP 路径。状态机：PROVISIONAL →（V 在 t+δ < H 返回 APPROVE）COMMITTED；→（V 返回 VETO）执行应急安全策略并**回滚未提交的动作块**；→（δ ≥ H 仍未返回）丢弃暂定动作、执行盾安全动作。**不变式：硬安全从不依赖 V 是否返回；V 只决定语义风险是否被接受。**

**定义 298（投机批量前瞻 SBR）** k 步前瞻：廉价 draft 轨迹 `(ŝ^d_1, …, ŝ^d_k)`，逐点 draft 不确定度 U^d_i 与残差界 ε^d_i。仅对边界集 `B_k = { i : U^d_i > ε_accept }` 调用昂贵 WM，并把 `{B_k}` 的所有查询**一次批量前向**（并发 batching）。接受规则：`|s_i − ŝ^d_i| ≤ ε_accept, ∀ i ≤ k` 才接受 draft 前缀；否则对首个越界前缀做精确修正。成本 `c_SBR = c_draft·k + c_WM·|B_k|`，误差由 draft 的 Lipschitz 常数与 batch 校验界共同控制。

**定义 299（标定排除锚 CAX）** 锚通道集 𝒜（IMU 重力方向、长基线里程、已知基准几何）满足物理不变性 `A96: ∂r^a/∂c ≡ 0`（对 R68 的标定参数 c 不可观测）。COF 观测模型分块 `y = [r^cal; r^a]`，测量矩阵约束为 `H = [H^cal; 0]`，即 `H^a = 0`。于是后验更新对锚残差零增益，锚残差**原样**送入 CFA 的故障似然。差分判别：`d_t = r^a_t − Π_cal(r^a_t)`（Π_cal 为锚残差在标定可达子空间的投影）——`‖d_t‖` 大而 `‖r^cal_t‖` 可被 ĉ 解释 ⇒ 标定漂移；两者同向 ⇒ 真实世界/故障。

**定义 300（盲带收缩）** R68 慢故障盲带 `Ω_blind = {ω_f ≤ ω_cal, severity ≥ τ_det}`。引入锚覆盖 `κ_A(f) = ‖f 在锚通道的投影‖ / ‖f‖` 后，收缩为
`Ω_blind' = { f ∈ Ω_blind : κ_A(f) < κ_min } ∪ { f : 锚自身漂移 }`。
语义：只要一条缓变故障在某个廉价物理见证上有非零投影，它就**不再可被标定吸收**；残余盲带只剩「对所有锚都不可见」的故障与「锚自身失效」——后者由锚健康度（定义 305）显式监控。

**定义 301（算力预算治理 CBG）** 预算 B（ms/帧 或 FLOPs/帧）。决策变量：α_acc、τ_esc、ε_accept、V 深度、预取率 p。在线估计 (q, δ̄_V, 尾部)。两种等价形式：
(a) `min 风险 s.t. E[C] ≤ B`；(b) `min E[C] s.t. risk ≤ α_spec`。用拉格朗日/水位法求解，输出工作点与局部 Pareto 斜率 `∂risk/∂E[C]`。**只有 CIV/保形有效性校验通过的工作点才可上线**（沿用 R69 数据轮思想的指标可优化性纪律）。

**定义 302（摊销成本证书与预取可行性）** `E[C] ≤ c_m + p·c_V + E[c_SBR]`，`p ≥ q` 为预取率，q̄ 用 anytime-valid 置信区间给上界。并发可行性：验证队列利用率 `ρ = p·δ̄_V` 必须 < 1，且「H 前拿到判决」的概率由排队尾部界 `P(wait > H−δ̄_V) ≤ γ` 约束。若 `p·δ̄_V ≥ 1`，并发方案不可行，必须退回盾式 STOP。

**定义 303（预算枯竭的反向保守）** 预算告急时**绝不抬高 τ_acc 去多放行**；唯一允许的动作是把 ESCALATE 区并入 STOP（τ_esc 下调，使更多点满足 L_m > τ_esc）。形式化：保持 τ_acc 不变，令 τ_esc ← τ_esc − Δ；则 E[C] 单调下降（每转移一帧省 c_V），P(unsafe) 单调不增（STOP 自主风险为零）。**省钱只能靠多做安全停机，不能靠少看证据。**

**定义 304（AIC-SPARC 干扰集）** `ℰ_SPARC = ℰ_CALM × ℰ_low × ℰ_conc`；
`ℰ_low = {廉价监测器失准, 锚盲/锚串谋, 预算饥饿, 保形可交换性破裂, 预取误触发}`；
`ℰ_conc = {迟到的否决（δ>H）, 陈旧验证器, 提交/回滚竞态, batch 边界泄漏, 排队溢出}`。

**定义 305（J_SPARC 证书）** `J_SPARC = (J_CALM, α_m, q̄, κ_A, anchor_health, δ_V^p99, ρ_util, budget_used, pareto_point, sparc_ver)`。
`Valid ⇔ Valid(J_CALM) ∧ anchor_health > τ_A ∧ q̄·c_V + c_m ≤ B ∧ ρ_util < 1 ∧ δ_V^p99 ≤ H ∧` 全部关键指标保形有效性校验通过。

**定义 306（部署工作点与算力分层）** 同一架构按硬件分层：**Tier-0**（廉价 MCU，仅盾 + TSM，无 V，ESCALATE→STOP）；**Tier-1**（边缘 SoC，并发 V + SBR）；**Tier-2**（全量 CALM + VQA-S）。三档共享同一 `(α_spec, B) → (τ_acc, τ_esc, ε_accept)` 映射；低档不是「阉割安全」，而是**在更小 B 下沿同一 Pareto 前沿取更保守的工作点**（这正是低成本可部署性的形式化含义）。

**定义 307（管线）** 离线：蒸馏廉价 m + 保形校准 → 拟合 draft WM → 标定锚健康基线 → 建立 Pareto 前沿。在线：m 三区决策 → 并发发起/预取 V → SBR 批量前瞻 → CAX 始终在线 → CBG 调工作点；VQA-S 只审计 ESCALATE 与低率随机样本；预算枯竭触发定义 303。

## 2. 关键算法骨架

```python
# IP-253 TSM：廉价保形绊线 + 三区决策
class TieredSafetyMonitor:
    def __init__(self, cheap_model, cal_scores, tau_acc, tau_esc):
        self.m, self.scores = cheap_model, sorted(cal_scores)
        self.tau_acc, self.tau_esc = tau_acc, tau_esc

    def zone(self, x, alpha_acc):
        s = self.m(x)
        U = self._quantile(1 - alpha_acc, s)      # split-conformal 上界
        L = self._quantile(alpha_acc, s)
        if U <= self.tau_acc:            return 'ACCEPT', U
        if L >  self.tau_esc:            return 'STOP', L
        return 'ESCALATE', U


# IP-254 ASC：并发投机提交（到达即否决，H 内可回滚）
class AmortizedSpeculativeCommit:
    def __init__(self, shield, verifier, H, causal_buffer):
        self.shield, self.V, self.H = shield, verifier, H
        self.buf = causal_buffer                  # 可回滚的动作块缓冲

    def step(self, obs, cheap_policy, zone, U):
        a = cheap_policy(obs)
        if not self.shield.h_recoverable(a, self.H):   # 盾不变式
            return self.shield.safe_action(obs), 'SHIELD'
        if zone == 'ACCEPT':
            return a, 'FAST'                            # 自动放行
        future = self.V.submit_async(obs)               # 与执行并发
        self.buf.push(a)
        verdict, dt = self.V.poll(future, deadline=self.H)
        if verdict is None:                             # δ ≥ H，退回盾
            return self.shield.safe_action(obs), 'TIMEOUT'
        if verdict == 'VETO':                           # 到达即否决
            self.buf.rollback()
            return self.shield.safe_action(obs), 'VETO'
        return a, 'COMMITTED'


# IP-255 SBR：draft 轨迹 + 边界点批量验证
def speculative_batch_rollout(draft_wm, exact_wm, z, act_seq, eps_accept):
    traj, U = draft_wm.rollout(z, act_seq)              # 廉价 draft
    boundary = [i for i in range(len(traj)) if U[i] > eps_accept]
    if boundary:                                        # 一次批量并发前向
        corr = exact_wm.batch_forward([traj[i] for i in boundary])
        for i, c in zip(boundary, corr):
            if norm(c - traj[i]) > eps_accept: traj[i] = c
    return traj


# IP-256 CAX：标定排除锚（H^a = 0，零增益投影）
class CalibrationExcludedAnchor:
    def __init__(self, imu, odom, fiducial):
        self.refs = (imu, odom, fiducial)

    def residual(self, obs, c_hat):
        r_a = [ref.residual(obs) for ref in self.refs]      # 物理不变残差
        d   = r_a - project_to_cal_span(r_a, c_hat)         # 差分判别
        health = anchor_consistency(r_a)                    # 锚自身健康
        return r_a, d, health


# IP-257 CBG：预算治理 + 工作点选择
class ComputeBudgetGovernor:
    def __init__(self, B, alpha_spec):
        self.B, self.alpha_spec = B, alpha_spec

    def select(self, q_hat, q_ucb, dV, tail):
        pareto = self._frontier(q_hat, q_ucb, dV, tail)     # (risk, E[C])
        feasible = [(r, c) for r, c in pareto
                    if c <= self.B and r <= self.alpha_spec]
        if not feasible:                                    # 预算枯竭
            return self._reverse_conservative(dV)           # ESCALATE -> STOP
        return min(feasible, key=lambda rc: rc[1])          # 最便宜的可行点


# IP-259 SPARC 主闭环（继承 R68，昂贵部件事件触发/并发旁路）
def SPARC_RAS_round(M, obs):
    x_prime = M.lsf.fuse(M.usr.fuse(*obs[:4]))
    z, o    = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)   # 廉价共享前向

    # 1) 锚见证（始终在线，绕过标定）
    r_a, d_anchor, anchor_health = M.cax.residual(obs, M.cof.c)
    r = residuals(x_prime, o, M.wm_residual_cache)

    # 2) 三区决策（廉价保形绊线）
    zone, U_m = M.tsm.zone(obs_pack, M.cbg.alpha_acc)
    if anchor_health < TAU_A: zone = 'STOP'

    # 3) 昂贵件按需：只有歧义/锚异常才升起
    if zone == 'ESCALATE':
        c, U, thr = M.cof.step(o['cal'], r, sigma_stat(M))     # 全量标定
        wm_preds  = M.sbr.rollout(M.mtm, z, M.ach.propose(x_prime, 5))
        joint     = M.cfa(rho=M.fir_signature(z, M.residual_log),
                          face=o['pi'], c=c, U=U, anchor=d_anchor)
        lam = max(M.efs.risk_scale(joint), thr['lam_floor'],
                  0.8 if (o['qual']['face'] < 0.8) else 0.6)
    elif zone == 'ACCEPT':
        lam = 0.6 if anchor_health > TAU_A else 0.8            # 廉价放行档
        joint, wm_preds = None, None
    else:                                                       # STOP
        return 0, 1.0, None, None

    # 4) 并发投机执行 + 到达即否决
    a = M.pi_sigma.prefix_dispatch(M.ach.propose(x_prime, H=M.vista.H)[:M.k])
    tau, mode = M.asc.step(obs, lambda _o: a * lam, zone, U_m)

    # 5) 预算治理 + 采样审计（只审升格/低率随机）
    M.cbg.update(q=zone == 'ESCALATE', dV=M.V.last_latency)
    M.vqa_s.audit_async(zone, wm_preds, joint, anchor=(r_a, anchor_health))
    return M.k, lam, joint, (M.cof.c, U_m)
```

## 3. 推导

**引理 16（保形三区有效性）** 在可交换性 A95 下，ACCEPT 区的边际风险 `P(unsafe(x) ∧ x∈ACCEPT) ≤ α_acc + 1/(n+1)`；STOP 区自主风险为 0；ESCALATE 区风险由 V 界 α_V 控制。故总风险 ≤ α_acc + q·α_V + α_hero。**注记**：保形是边际保证；条件化（对每个工况/尾部格子分别成立）需 Mondrian/条件保形，且分布偏移会使 α_acc 失效——这正是 E287 与本章最大风险的来源。

**引理 17（投机安全支配）** 若每个暂定动作 `a ∈ 𝒮_H`（H-可恢复）且 H ≥ δ_V（验证延迟上界），则 ASC 的硬安全违规概率 ≤ 纯盾方案；且语义风险 ≤ 纯廉价方案（V 只否决、不授权）。证明要点：H-可恢复性使「迟到的否决」总能在进入不可恢复集前生效；VETO/TIMEOUT 都映射到盾安全动作；盾不读 V 的输出，故硬安全与 V 是否存在无关。**并发是帕累托改进：硬安全不变、语义安全更好、快路径延迟不变。**

**引理 18（摊销成本下界）** 设廉价分数在安全规格 α_max 下的最大可自动放行覆盖为 `cov*(α_max) = sup{ cov : 该覆盖集上的风险 ≤ α_max }`。则任何满足 `P(unsafe) ≤ α_max` 的架构都有 `q ≥ 1 − cov*(α_max)`，从而
`E[C] ≥ c_m + (1 − cov*(α_max))·c_V`。
**推论**：低成本的天花板由廉价表示的质量决定，不能靠系统调度突破；想把 E[C] 压一个数量级，必须把 cov* 逼近 1——这是**表示学习问题**，不是工程问题。

**引理 19（并发 = 带截止期的排队）** 设升格到达率为 q、验证服务时间均值 δ̄_V、截止期 H。要保证 `P(判决在 H 前就绪) ≥ 1−γ`，预取率 p 需满足利用率 `ρ = p·δ̄_V < 1` 及尾部界 `P(W_{H} > H−δ̄_V) ≤ γ`（W 为排队等待）。当 `ρ ≥ 1` 时系统不可稳定，**必须执行定义 303 的反向保守（STOP）**。语义：并发把「验证要多快」的延迟约束，转成「验证容量要多大」的吞吐约束——这是实时系统 admission control 的标准结论在安全域的落地。

**引理 20（锚可识别性与盲带收缩）** 在 A96（∂r^a/∂c ≡ 0）与锚噪声方差 σ_a² 下，故障 f 的锚残差 SNR ≥ κ_A(f)·‖f‖/σ_a。若 `κ_A(f) > τ_det·σ_a/‖f‖`，则 f 的可检出性**与 ω_f 无关**——即使 ω_f ≤ ω_cal（落在 R68 盲带），它仍被锚见证检出。故 `Ω_blind' ⊆ {κ_A(f) < κ_min} ∪ {锚自身漂移}`。**系**：R68 的「标定越强、缓变故障越隐形」在存在廉价物理见证时被打破，且无需更强学习器。

**引理 21（预算可行性与单调保守）** 若 `E[C] > B`，定义 303 的策略（固定 τ_acc、下调 τ_esc 把 ESCALATE 并入 STOP）给出 `E[C] ≤ B` 且 `P(unsafe)` 非增。证明：STOP 帧省去 c_V 且自主风险为 0；转移不触碰 ACCEPT 区，故不放宽任何自主放行。**系**：预算压力永远只能把系统推向更保守，不能推向更冒险。

**定理 16（SPARC 端到端一致性与成本界）** 在 A87–A96 下：
1. `P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + α_m + q·α_V + α_hero`；
2. 硬安全违规概率由盾单独界定，**与 V 的可用性、及时性无关**（引理 17）；
3. `E[C] ≤ c_m + p·c_V + c_SBR ≤ B`，且 `p ≥ q` 由引理 19 的容量条件约束；
4. 预算枯竭 ⇒ 转 STOP，风险单调不增（引理 21）；
5. 所有 R68 保证在 ESCALATE 子集上原样成立（因为该子集跑的就是 R68 全环）。

**定理 17（低成本等价）** 固定安全规格 α_spec 与预算 B。若廉价监测器满足 `cov*(α_acc) ≥ 1 − q_max`，则存在工作点使 `P(unsafe) ≤ α_spec` 且 `E[C] = c_m + q*c_V + c_SBR`，相对 R68 的每帧成本 `c_R68 ≈ c_V` 的节省比为 `r = c_R68/E[C]`。当 `cov* → 1`、`q* → 1/r` 时 `r → 1/(c_V 项系数)`，可达数量级；**但最坏单帧成本与延迟不降**（并发只是隐藏延迟，不消除单次验证成本）——低成本是**期望意义**的陈述，不是最坏情况陈述。

## 6. 本轮最大风险

**一句话**：低成本的本质是「在最需要昂贵证据的分布外样本上把它省掉了」——ACCEPT 区的授信完全来自廉价绊线的**保形边际保证**，而保形恰恰在分布偏移（缓变故障、新工况、锚串谋）时失效，于是系统会在它最自信、也最不该自信的地方静默放行；**省钱与安全失效，重叠在同一个「可交换性破裂」的点上**。

**次级风险与缓解**：
1. **锚串谋/锚自身漂移**：锚并非绝对真理 → anchor_health 显式监控 + 多锚冗余 + 锚失效即降 Tier；
2. **并发竞态（迟到否决、陈旧验证、提交/回滚）**：H 覆盖 + 双缓冲 + 回滚失败即全局 STOP；
3. **排队不可稳定（ρ≥1）**：CBG 提前检测并强制 STOP，绝不「跳过验证」；
4. **保形条件化失效**：Mondrian/条件保形 + E287 漂移监控 + OOD 触发保守档；
5. **CBG 被优化压力玩坏（Goodhart）**：只允许「更保守」方向调参，降 q 不能提高 τ_acc，E300 审计；
6. **成本—安全权衡被误读**：定理 17 只保证期望成本，最坏延迟/成本不降 → 安全规格必须同时写「期望」与「最坏」两条约束。

## 2. 形式化定义（要点版）

**定义 293（总览与三不变式）** 盾不变式（快路径动作必须 H-可恢复，V 只能否决不能授权）；摊销成本不变式（昂贵验证按歧义/预取发起，`E[C] ≤ c_m+p·c_V+c_SBR`）；锚排除不变式（COF 对锚通道零增益，标定无权解释掉物理证人）。

**定义 295（三区决策）** ACCEPT `U_m ≤ τ_acc`；STOP `L_m > τ_esc` 或锚告警；ESCALATE 其余；`α_spec ≥ α_acc + q·α_V + α_hero`。

**定义 296（盾与停稳地平线）** `𝒮_H = {a : 执行 a 及应急策略后在 H 内保持 𝒮_hard}`，H ≥ δ_V^p99，由廉价确定性运动学/力限给出，不依赖学习模型。

**定义 297（ASC 并发投机提交）** 暂定执行 PROVISIONAL → APPROVE 提交 / VETO 回滚并执行安全策略 / δ≥H 丢弃暂定、执行盾动作。硬安全从不依赖 V。

**定义 298（SBR 投机批量前瞻）** draft 轨迹 + 边界集 `B_k = {i : U^d_i > ε_accept}` 一次批量精确修正；接受条件 `|s_i−ŝ^d_i| ≤ ε_accept`；成本 `c_draft·k + c_WM·|B_k|`。

**定义 299（CAX 标定排除锚）** A96：`∂r^a/∂c ≡ 0`；COF 测量矩阵 `H=[H^cal; 0]`；差分残差 `d_t = r^a_t − Π_cal(r^a_t)`；锚残差绕过标定直接进 CFA。

**定义 300（盲带收缩）** `Ω_blind' = {κ_A(f) < κ_min} ∪ {锚自身漂移}`；任何有非零锚投影的缓变故障不再可被标定吸收。

**定义 301（CBG 预算治理）** `min risk s.t. E[C]≤B`（或对偶）；水位/拉格朗日求工作点；仅通过保形有效性/CIV 校验的工作点可上线。

**定义 302（摊销成本证书与预取可行性）** `ρ=p·δ̄_V<1` 且 `P(wait>H−δ̄_V)≤γ`；`ρ≥1` 即不可稳定，必须 STOP。

**定义 303（预算枯竭反向保守）** 固定 τ_acc，下调 τ_esc 把 ESCALATE 并入 STOP；省钱只能靠多做安全停机，不能靠少看证据。

**定义 304（AIC-SPARC）** `ℰ_SPARC = ℰ_CALM × ℰ_low × ℰ_conc`；`ℰ_low={廉价失准,锚盲/串谋,预算饥饿,可交换性破裂,预取误触发}`；`ℰ_conc={迟到否决,陈旧验证器,提交/回滚竞态,batch 边界泄漏,排队溢出}`。

**定义 305（J_SPARC）** Valid ⇔ Valid(J_CALM) ∧ anchor_health>τ_A ∧ `q̄·c_V+c_m ≤ B` ∧ ρ_util<1 ∧ δ_V^p99 ≤ H ∧ 关键指标保形校验通过。

**定义 306（部署工作点与算力分层）** `(α_spec,B) → (τ_acc,τ_esc,ε_accept)`；Tier-0 仅盾+TSM（无 V，ESCALATE→STOP）；Tier-1 并发 V+SBR；Tier-2 全量。低档不是阉割安全，而是同一前沿上更保守的工作点。

**定义 307（管线）** 离线蒸馏/保形/锚基线/Pareto；在线三区→并发/预取 V→SBR→CAX 常开→CBG 调点；VQA-S 只审升格+低率随机；预算枯竭触发定义 303。

```python
# IP-253 TSM：保形三区
class TieredSafetyMonitor:
    def zone(self, x, alpha_acc):
        s = self.m(x)
        U = self._quantile(1 - alpha_acc, s)   # split-conformal 上界
        L = self._quantile(alpha_acc, s)
        if U <= self.tau_acc: return 'ACCEPT', U
        if L >  self.tau_esc: return 'STOP', L
        return 'ESCALATE', U

# IP-254 ASC：并发投机提交（到达即否决，H 内可回滚）
class AmortizedSpeculativeCommit:
    def step(self, obs, cheap_policy, zone, U):
        a = cheap_policy(obs)
        if not self.shield.h_recoverable(a, self.H):
            return self.shield.safe_action(obs), 'SHIELD'
        if zone == 'ACCEPT':
            return a, 'FAST'
        future = self.V.submit_async(obs)            # 与执行并发
        self.buf.push(a)
        verdict, dt = self.V.poll(future, deadline=self.H)
        if verdict is None:  return self.shield.safe_action(obs), 'TIMEOUT'
        if verdict == 'VETO':
            self.buf.rollback(); return self.shield.safe_action(obs), 'VETO'
        return a, 'COMMITTED'

# IP-255 SBR：draft + 边界批量验证
def speculative_batch_rollout(draft_wm, exact_wm, z, act_seq, eps_accept):
    traj, U = draft_wm.rollout(z, act_seq)
    boundary = [i for i, u in enumerate(U) if u > eps_accept]
    if boundary:
        for i, c in zip(boundary, exact_wm.batch_forward([traj[i] for i in boundary])):
            if norm(c - traj[i]) > eps_accept: traj[i] = c
    return traj

# IP-256 CAX：零增益锚
class CalibrationExcludedAnchor:
    def residual(self, obs, c_hat):
        r_a = [ref.residual(obs) for ref in self.refs]   # 物理不变
        d   = r_a - project_to_cal_span(r_a, c_hat)       # 差分判别
        return r_a, d, anchor_consistency(r_a)

# IP-257 CBG：预算治理
class ComputeBudgetGovernor:
    def select(self, q_hat, q_ucb, dV, tail):
        pareto = self._frontier(q_hat, q_ucb, dV, tail)
        feasible = [(r, c) for r, c in pareto if c <= self.B and r <= self.alpha_spec]
        if not feasible:
            return self._reverse_conservative(dV)          # ESCALATE -> STOP
        return min(feasible, key=lambda rc: rc[1])

# IP-259 主闭环
def SPARC_RAS_round(M, obs):
    x_prime = M.lsf.fuse(M.usr.fuse(*obs[:4]))
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)
    r_a, d_anchor, anchor_health = M.cax.residual(obs, M.cof.c)   # 锚常开
    r = residuals(x_prime, o, M.wm_residual_cache)
    zone, U_m = M.tsm.zone(obs_pack, M.cbg.alpha_acc)
    if anchor_health < TAU_A: zone = 'STOP'
    if zone == 'ESCALATE':
        c, U, thr = M.cof.step(o['cal'], r, sigma_stat(M))
        wm_preds  = M.sbr.rollout(M.mtm, z, M.ach.propose(x_prime, 5))
        joint     = M.cfa(M.fir_signature(z, M.residual_log),
                          o['pi'], c, U, anchor=d_anchor)
        lam = max(M.efs.risk_scale(joint), thr['lam_floor'],
                  0.8 if o['qual']['face'] < 0.8 else 0.6)
    elif zone == 'ACCEPT':
        lam = 0.6 if anchor_health > TAU_A else 0.8
        joint, wm_preds = None, None
    else:
        return 0, 1.0, None, None
    a = M.pi_sigma.prefix_dispatch(M.ach.propose(x_prime, H=M.vista.H)[:M.k])
    tau, mode = M.asc.step(obs, lambda _o: a * lam, zone, U_m)
    M.cbg.update(q=zone == 'ESCALATE', dV=M.V.last_latency)
    M.vqa_s.audit_async(zone, wm_preds, joint, anchor=(r_a, anchor_health))
```

## 4. 推导

**引理 16（保形三区有效性）** A95 下 `P(unsafe ∧ ACCEPT) ≤ α_acc + 1/(n+1)`；STOP 自主风险 0；ESCALATE 由 α_V 界定 ⇒ 总风险 ≤ α_acc + q·α_V + α_hero。注：边际保证，条件化需 Mondrian/条件保形，漂移下失效（E287）。

**引理 17（投机安全支配）** `a ∈ 𝒮_H` 且 H ≥ δ_V ⇒ ASC 硬安全违规 ≤ 纯盾；语义风险 ≤ 纯廉价（V 只否决）。并发是帕累托改进：硬安全不变、语义安全更好、快路径延迟不变。

**引理 18（摊销成本下界）** `q ≥ 1 − cov*(α_max)` ⇒ `E[C] ≥ c_m + (1−cov*)·c_V`。低成本天花板由廉价表示质量决定，不能靠调度突破（是表示学习问题）。

**引理 19（并发 = 带截止期排队）** `P(判决 H 前就绪) ≥ 1−γ` 需 `ρ=p·δ̄_V<1` 及排队尾部界；`ρ≥1` 不可稳定 ⇒ 必须 STOP。并发把延迟约束转成吞吐约束（admission control）。

**引理 20（锚可识别性与盲带收缩）** A96 下锚残差 `SNR ≥ κ_A(f)·‖f‖/σ_a`；`κ_A > τ_det σ_a/‖f‖` ⇒ 检出性与 ω_f 无关 ⇒ R68 慢故障盲带被廉价见证击穿，无需更强学习器。

**引理 21（预算可行性与单调保守）** `E[C]>B` 时固定 τ_acc、下调 τ_esc 把 ESCALATE 并入 STOP ⇒ `E[C]≤B` 且 P(unsafe) 非增。预算压力只能推向更保守。

**定理 16（SPARC 端到端）** A87–A96 下：(1) 风险 ≤ R68 各项和 + α_m + q·α_V + α_hero；(2) 硬安全由盾单独界定，与 V 可用/及时无关；(3) `E[C]≤c_m+p·c_V+c_SBR≤B`，p 由引理 19 容量约束；(4) 预算枯竭转 STOP，风险非增；(5) R68 保证在 ESCALATE 子集原样成立。

**定理 17（低成本等价）** 固定 (α_spec,B)，若 `cov*(α_acc) ≥ 1−q_max`，则存在工作点使风险 ≤ α_spec 且 `E[C]=c_m+q*c_V+c_SBR`，节省比 `r=c_R68/E[C]`，`cov*→1` 时可达数量级；**但最坏单帧成本与延迟不降**——低成本是期望意义陈述，安全规格必须同时写期望与最坏两条约束。

## 7. 本轮最大风险

**一句话**：低成本的本质是「在最需要昂贵证据的分布外样本上把它省掉了」——ACCEPT 区的授信完全来自廉价绊线的保形边际保证，而保形恰在分布偏移（缓变故障、新工况、锚串谋）时失效，于是系统会在它最自信、也最不该自信的地方静默放行；**省钱与安全失效，重叠在同一个「可交换性破裂」的点上**。

**次级风险与缓解**：锚串谋/锚漂移（anchor_health + 多锚冗余 + 失效降 Tier）；并发竞态（H 覆盖 + 双缓冲 + 回滚失败即 STOP）；排队不可稳定 ρ≥1（CBG 提前 STOP，绝不跳过验证）；保形条件化失效（Mondrian/条件保形 + 漂移监控 + OOD 保守档）；CBG 被 Goodhart 玩坏（只许更保守方向，降 q 不得抬高 τ_acc，E300 审计）；成本—安全被误读（定理 17 只保证期望，安全规格须同时写期望与最坏约束）。
