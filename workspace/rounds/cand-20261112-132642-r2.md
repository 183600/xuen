# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感驱动研究循环第 2 轮／全局第 61 轮；本轮灵感：「开源软件」×「数据集」）

> 第 60 轮实现了「认知驱动的场景-执行闭环」：场景语义建模 SSM、认知意图约束 CIEC、ROS 因果隔离 EPIR、场景感知闭环 SERC、四维认知预算 PCE++++。但它是一个**闭源单体栈**——所有模块、证据契约、量纲都默认由同一团队共同设计。当系统真正走进「开源软件」与「数据集」构成的开放生态时，暴露出**三个根本局限**：
> 1. **安全不可组合（Composition Failure）**：SGEC 的证书只对「整机、整栈、整场景」有效。开源模块各自「在我自己的数据上安全」，但把 A 的输出接给 B 时，接口类型兼容不等于**定义域兼容**——一个室内训练的感受器喂给只在室内认证过的控制器，类型检查全过、部署即失效。
> 2. **证据不可溯源（Provenance Gap）**：EV-exec 没有绑定代码哈希、构建环境、数据集哈希、硬件描述符。同一句「K_safe 安全」无法复现、无法审计，证书退化为「信我」而非「验我」；依赖升级后也无法判断哪些下游证书应失效。
> 3. **数据集是活体（Living Dataset）**：证书隐含假设「验证集覆盖部署域」。开源数据集会版本漂移、会与训练集污染（benchmark contamination）、会带不兼容许可证、甚至会被投毒；无覆盖支撑的安全声明却仍被外推，这是第 60 轮「证据层高度确定、执行层灾难性失效」在**数据层**的放大。

## 0. 直觉与动机

**灵感 1（开源软件 → 能力供应链溯源 CSC）**
直觉：机器人不是单体，而是一张「开源能力包」的依赖图（感知、规划、阻抗控制、状态估计）。开源软件真正成熟的不是「免费」，而是 **SBOM + 可复现构建 + 签名来源证明（SLSA / in-toto）**。把每个能力包当作带「能力物料清单 CBOM」的供应链节点：代码哈希、构建环境、依赖闭包、许可证、数据集、接口契约、证书。关键洞见：**安全证书必须像软件构建一样可溯源、可复现、可组合**；改一个依赖版本，应按依赖图**增量失效**所有下游证书，而不是整栈重来。

**灵感 2（开源软件 → 域类型证书 DTC）**
直觉：开源集成事故的主因不是「类型不兼容」，而是「**类型兼容但语义不兼容**」。类型系统能检查 shape，却检查不了 domain。关键洞见：**把证书做成精化类型**——证书 J 的载体是一个定义域 D（工况 z、意图 I、平台 E 的集合），组合 A∘B 合法当且仅当 **Out(A) ⊆ In(B)**；不满足就在编译期报 ⊥，而不是在部署时摔跤。

**灵感 3（数据集 → 证据数据集契约 EDC）**
直觉：数据集不是静态 benchmark，而是带 schema、带版本、带许可证、带「数据说明书」的活体。安全声明「K_safe 在工作域 U 安全」只有在证据数据集 D 对 U 的**覆盖 cov_D(U) ≥ τ_cov**、**污染 κ(D, M_train) ≤ τ_cont**、许可证兼容且来源可验时才成立。关键洞见：**证书的有效性 = 声明域被证据支撑的程度**；无支撑的声明自动降级为「待探索」，而不是「默认成立」。

**灵感 4（两灵感合流 → 可组合安全代数 CSA + 联邦证据聚合 FEA）**
直觉：既然证书带域、带证据，它们就能像代数一样组合：串行 ∘、证据/域并 ⊔、精化 ⊑、失效 ⊥，并满足结合律与单调性。开源社区贡献的证据通过**联邦证据聚合**进入数据池，但贡献者不能全信——用可复现性、硬件匹配、审计结果给样本加权，并用 Byzantine 鲁棒聚合抗投毒。关键洞见：**信任是会衰减的资源而不是布尔值；奖励贡献要看「覆盖/新颖度」而不是「准确率」，否则必然 Goodhart（只交简单样本刷分）**。

**灵感 5（预算 → PCE+++++ 开放供应链/数据预算 OSB）**
直觉：验证、采数、审计都要花预算。B_open = (B_verify, B_data, B_trust)。预算耗尽时必须能**优雅退回封闭安全核**：冻结版本只用缓存证书 / 收缩到已证明域 / 拒绝第三方模块。关键洞见：**开放是一种可撤销的能力，而不是默认状态**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（能力供应链 CSC）** 能力包
```
p = (id, ver, (In_p, Out_p, D_p), ℓ_p, h_code, h_build, Dep_p, Dset_p, J_p, π_p)
```
其中 `D_p ⊆ 工作域` 为接口定义域，`ℓ_p` 为许可证，`J_p` 为随包证书，`π_p` 为生产者签名的来源证明（绑定 h_code、h_build、数据集哈希、硬件描述符 E）。**可复现哈希** `h_rep = H(h_code, h_build, {h(d) : d∈Dset_p}, E)`。
- 供应链图 `G_SC = (V, E)`，`(p,q)∈E` 表示 p 的输出被 q 消费（依赖/组合边）。
- `CBOM(p) = ⋃_{q∈Dep*_p} q` 为传递闭包及其许可证集合。
- **许可证相容** `ℓ_p ⊗ ℓ_q ≠ ⊥`（copyleft 传染 / 专有冲突 ⇒ 非法组合）。
- **溯源验证** `Verify(p) = SigOK(π_p) ∧ h_rep^actual = h_rep^attested`。
- **组合前置** `ComposeOK(p,q) = Verify(p) ∧ Verify(q) ∧ ℓ_p⊗ℓ_q≠⊥ ∧ Out_p ⊆ In_q ∧ D_p ∩ D_q ≠ ∅`。

**定义 162（域类型证书 DTC）** 证书 `J = (φ, D, A, Eset, sig, prov)`：φ 为安全断言（如 `|F| ≤ F_max ∧ |Δx| ≤ ε`），D 为声明定义域（工况 (z,I,E) 的可测集或凸集），A 为假设集，Eset 为支撑证据数据集 ID，prov 为签名溯源。
- **类型** `type(J) = D`，**效果** `effect(J) = φ`。
- **限制规则**：若 `D' ⊆ D`，则 `J|D'` 仍然有效（子域上更强的确定性）。
- **精化序** `J₁ ⊑ J₂ ⇔ D₁ ⊆ D₂ ∧ φ₁ ⇒ φ₂`（J₁ 可替代 J₂ 使用）。
- **串行组合**：若 `J_A : In_A → Out_A`、`J_B : In_B → Out_B` 且 `Out_A ⊆ In_B`、`A_A ∪ A_B` 一致，则
```
J_{B∘A} : In_A → Out_B,  φ_{B∘A} = φ_A ∧ φ_B
```
否则 `J_{B∘A} = ⊥`（**组合失败必须在编译期报出**）。
- **证据门控**：`Valid(J) ⇔ type(J) 被 UseOK(Eset, D) 支撑 ∧ SigOK(prov)`。

**定义 163（证书依赖图 CDG 与增量再认证 IRC）** CDG 节点为 `(包, ver, h_contract, J)`，边为组合依赖，其中**契约哈希** `h_contract = H(In, Out, D, A)`（**只信语义接口，不信 semver**）。
- **版本变更算子** `Δ(v→v')`：
  - 若 `h_contract` 改变 ⇒ 失效 v 及其全部下游；
  - 若 `h_contract` 不变 ⇒ 仅运行**一致性差分测试**（conformance suite，来自 EDC 的回放样本）；通过则下游保留，否则失效。
- **失效闭包** `Inv(v) = {u : v ⇝ u 沿反向依赖可达}`。
- **局部性引理**：若所有受影响组合边的契约哈希不变且差分测试通过，则未受影响子树的证书保持有效；**正确失效要求 Inv 覆盖全部下游**（只可多不可少）。
- **增量代价** `Cost_IRC = O(|Inv(v)| · T_cert)`，对比全栈 `O(|V| · T_cert)`。

**定义 164（证据数据集契约 EDC）** 数据集 `D = (S, schema, sheet, ver, ℓ_D, prov, cov_D, κ_D)`，样本
```
s = (x, z, I, E, K, EV-exec, h_code, ts, hash, src)
```
- **覆盖** `cov_D(U) = measure({x∈U : dist(x, supp(D)) ≤ δ}) / measure(U)`（ε-net / KDE / Voronoi 估计）。
- **污染** `κ(D, M_train) = |{s∈D : near_dup(s, M_train)}| / |D|`（MinHash / 嵌入近邻 / 成员推断）。
- **可用性** `UseOK(D,U) = cov_D(U) ≥ τ_cov ∧ κ(D,M_train) ≤ τ_cont ∧ ℓ_D 相容 ∧ Verify(prov)`。
- **数据说明书 sheet**：动机、构成、采集流程、预处理、适用/禁用用途、分布、维护方式、已知偏差（datasheets for datasets）。

**定义 165（可组合安全代数 CSA）** 载体为证书集合 `Cert`，运算 `∘`（串行）、`⊔`（并集/证据聚合）、`⊑`（精化）、`⊥`（失效）。
- **公理**：`(Cert, ∘, id)` 构成幺半群（结合律 + 直通单位元）；`⊔` 幂等、交换、结合；`∘` 对 `⊑` 单调；域不包含时结果为 `⊥` 且 `⊥` 吸收。
- **闭包** `Cert* = lfp(∘, ⊔)`，只保留有效组合。
- **可靠性**：若所有叶子证书 `Valid`、每条组合边满足 `Out ⊆ In`、每次 `⊔` 满足 `UseOK`，则闭包中任一组合证书 `Valid`；反之任一组合失效必可归因到 (a) 域不包含 (b) 证据覆盖不足 (c) 溯源/许可失败——**三类失败均可定位**。

**定义 166（联邦证据聚合 FEA）** 贡献者 `c∈C` 提交批次 `B_c`（带 prov、h_code、平台描述符 E_c）。信任 `τ_c ∈ (0,1]`：
```
τ_c ← τ_c · e^{−λ·fail_c}     （审计失败衰减）
τ_c ← min(1, τ_c + μ)          （复现成功回补）
```
- **样本权重** `w(s) = τ_{c(s)} · repro(s) · hw_match(E_s, E_target) · novelty(s)`。
- **鲁棒聚合**：加权 trimmed median / Byzantine-resilient 聚合；当恶意贡献者 `< f` 时，证书误差有界。
- **防 Goodhart**：接受准则按**覆盖增益/新颖度** `Δcov_D(U)`，不按「准确率」——否则社区只交简单样本刷分。
- **投毒检测**：来源多样性 + 分布偏移检验 + canary 样本。

**定义 167（开放生态闭环 OEL）** 算子 `OEL(M, G_SC, D_pool, task, U)`：
```
① Resolve(G_SC) → CBOM；Verify ∘ license-check
② DTC：组装叶子证书；CSA.compose 检查 Out⊆In，失败则返回不匹配边集合
③ EDC：UseOK(D_pool, U)? 不足 → 请求补证（主动采数 / 社区查询）
④ IRC：检测版本变更 → 仅重认证 Inv(v)
⑤ FEA：采纳社区证据（信任加权 + 鲁棒聚合）
⑥ Budget：B_open 检查 → 必要时保守回退
⑦ Execute → EV-exec 写入 EDC（可选 opt-in 发布）
⑧ 更新 τ_c、cov_D、CDG
⑨ Return (composite_cert, gaps, used_modules)
```

**定义 168（PCE+++++ / 开放预算 OSB）** `B_open = (B_verify, B_data, B_trust)`：
- `B_verify`：重认证计算预算（证书数 × 差分测试数）；
- `B_data`：覆盖采集预算（每单位 cov 的成本）；
- `B_trust`：审计/信任预算（审计次数、最低信任阈值）。

```
voi_open(π) = VOI_meta(π) − cost_verify(π) − cost_data(π) − cost_trust(π)
```
**降级策略**：`B_verify` 耗尽 ⇒ 冻结版本、只用缓存证书；`B_data` 耗尽 ⇒ 收缩到已证明域 `D_cert`、拒绝域外任务；`B_trust` 低于阈值 ⇒ 拒绝第三方模块、回退闭源核心。

```python
class CapabilityPackage:
    def __init__(self, pid, ver, in_dom, out_dom, license, deps, datasets):
        self.pid, self.ver = pid, ver
        self.in_dom, self.out_dom = in_dom, out_dom
        self.license, self.deps = license, deps
        self.datasets = datasets
        self.assumptions = set()

    def contract_hash(self):
        return sha256(canonical_json({
            "in": self.in_dom, "out": self.out_dom,
            "assumptions": sorted(self.assumptions)}))

    def verify_provenance(self):
        rep = sha256(self.code_hash + self.build_env_hash +
                     tuple(sorted(h(d) for d in self.datasets)) +
                     self.hardware_desc)
        return self.sig_ok() and rep == self.attested_rep_hash


class SupplyChain:
    def resolve(self, root):
        seen, stack = {}, [root]
        while stack:                       # O(|V|+|E|) 传递闭包 + 环检测
            p = stack.pop()
            if p.pid in seen:
                continue
            seen[p.pid] = p
            stack.extend(p.deps)
        return seen

    def license_compatible(self, closure):
        pkgs = list(closure.values())
        return all(pairwise_ok(a.license, b.license)
                   for i, a in enumerate(pkgs) for b in pkgs[i+1:])

    def compose_check(self, p, q):         # p 的输出喂给 q
        return (p.verify_provenance() and q.verify_provenance()
                and set_subset(p.out_dom, q.in_dom)
                and domains_overlap(p.in_dom, q.in_dom))
```

### IP-162 DTC（域类型证书）

```python
class DomainTypedCertificate:
    def __init__(self, claim, domain, out_domain, assumptions, evidence_ids, sig):
        self.claim, self.domain, self.out_domain = claim, domain, out_domain
        self.assumptions = assumptions
        self.evidence_ids = set(evidence_ids)
        self.sig = sig

    def restrict(self, sub_domain):
        assert set_subset(sub_domain, self.domain)
        return DomainTypedCertificate(self.claim, sub_domain, self.out_domain,
                                      self.assumptions, self.evidence_ids, self.sig)

    def compose(self, other):              # self 在前、other 在后
        if not set_subset(self.out_domain, other.domain):
            return BOTTOM(reason="output_domain_not_subset", edge=(self, other))
        if not assumptions_consistent(self.assumptions, other.assumptions):
            return BOTTOM(reason="assumption_conflict", edge=(self, other))
        return DomainTypedCertificate(
            claim=Conj(self.claim, other.claim),
            domain=self.domain, out_domain=other.out_domain,
            assumptions=merge_assumptions(self.assumptions, other.assumptions),
            evidence_ids=self.evidence_ids | other.evidence_ids,
            sig=sign_composition(self.sig, other.sig))
```

### IP-163 CDG/IRC（证书依赖图与增量再认证）

```python
class CertificateDependencyGraph:
    def __init__(self):
        self.nodes = {}                    # id -> (pkg, valid, contract_hash)
        self.rev = defaultdict(set)        # 下游 -> 上游（反向边）

    def on_version_change(self, node_id, new_pkg, conformance_suite):
        old_hash = self.nodes[node_id].contract_hash
        if old_hash == new_pkg.contract_hash():
            if behavioral_conformance(new_pkg, conformance_suite):
                self.nodes[node_id] = Node(new_pkg, valid=True,
                                           contract_hash=old_hash)
                return set()
        return self.invalidate(node_id)

    def invalidate(self, node_id):
        affected, stack = set(), [node_id]
        while stack:                       # 反向可达闭包 Inv(v)
            u = stack.pop()
            if u in affected:
                continue
            affected.add(u)
            stack.extend(self.rev[u])
        for u in affected:
            self.nodes[u].valid = False
        return affected
```

### IP-164 EDC（证据数据集契约）

```python
class EvidenceDataset:
    def coverage(self, region, delta=0.05):
        cover = epsilon_cover(self.samples, delta)     # ε-net / KDE
        return measure(cover & region) / measure(region)

    def contamination(self, train_fingerprints):
        hits = sum(near_dup(s, train_fingerprints) for s in self.samples)
        return hits / max(1, len(self.samples))

    def use_ok(self, region):
        return (self.coverage(region) >= 0.90
                and self.contamination(self.train_fps) <= 0.01
                and license_ok(self.license)
                and verify(self.provenance))
```

### IP-165 CSA + IP-166 FEA（组合代数与联邦证据）

```python
def compose_closure(certificates):
    frontier, valid, failures = list(certificates), set(), []
    while frontier:
        a = frontier.pop()
        for b in certificates:
            if interface_edge(a, b):
                j = a.compose(b)
                if j is BOTTOM:
                    failures.append(j)
                elif j.key not in valid:
                    valid.add(j.key)
                    frontier.append(j)
    return (valid, failures) if not failures else (BOTTOM, failures)


class FederatedEvidencePool:
    def __init__(self, tau0=0.5):
        self.trust = defaultdict(lambda: tau0)

    def audit(self, contributor, outcome):
        if outcome == "fail":
            self.trust[contributor] *= np.exp(-0.5)
        else:
            self.trust[contributor] = min(1.0, self.trust[contributor] + 0.1)

    def sample_weight(self, s, target_hw):
        return (self.trust[s.contributor] * s.repro_score
                * hw_match(s.platform, target_hw)
                * novelty(s, self.pool))

    def robust_aggregate(self, batches, f):
        return weighted_trimmed_median(batches, f)     # 容忍 < f 恶意贡献者
```

### IP-167 OEL（开放生态闭环）

```python
def open_ecosystem_loop(M, root_pkg, region, task):
    closure = M.supply_chain.resolve(root_pkg)
    if not M.supply_chain.license_compatible(closure):
        return FALLBACK_CLOSED_CORE
    if not all(p.verify_provenance() for p in closure.values()):
        return FALLBACK_CLOSED_CORE

    J, mismatch = compose_closure([p.cert for p in closure.values()])
    if J is BOTTOM:
        return REPORT_INCOMPATIBLE(mismatch)           # 编译期拒绝

    if not M.edc.use_ok(region):
        M.budget.spend("B_data", request_evidence(region, M.edc))

    for v, new_pkg in detect_version_changes(closure):
        M.cdg.on_version_change(v, new_pkg, M.conformance_suite)

    J = revalidate(J, M.cdg, region)
    if M.budget.exhausted("B_verify"):
        J = use_cached_certificates(closure, region)
    if M.budget.trust_below_threshold(closure):
        return FALLBACK_CLOSED_CORE

    ev = execute_and_log(M, J, region, task)
    M.edc.append(ev)                                   # opt-in 后可发布到 FEA
    return J, ev
```

### IP-168 OSB（开放预算）

```python
class OpenBudget:
    def __init__(self, verify=50, data=100, min_trust=0.6):
        self.B = {"B_verify": verify, "B_data": data}
        self.min_trust = min_trust

    def spend(self, name, cost):
        self.B[name] -= cost

    def exhausted(self, name):
        return self.B[name] <= 0

    def trust_below_threshold(self, closure, trust):
        return any(trust.get(p.pid, 0.0) < self.min_trust
                   for p in closure.values())

    def fallback(self, name):
        return {"B_verify": "freeze_versions_cached_cert",
                "B_data":   "restrict_to_certified_domain",
                "B_trust":  "reject_third_party_closed_core"}[name]
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CSC | O(\|V\|+\|E\|) 解析；O(\|V\|) 溯源 | O(\|V\|+\|E\|) | 溯源/许可非法组合 100% 拦截 |
| DTC | O(1)/边（域包含 O(d)） | O(证书大小) | 域不包含 ⇒ 组合期 ⊥ |
| CDG/IRC | O(\|Inv(v)\|+\|E_inv\|) | O(\|V\|+\|E\|) | 失效闭包不漏（只可多不可少） |
| EDC | 覆盖 O(n log n)，查询 O(log n+k)；污染 O(n·m) | O(n) | 覆盖/污染门控，域外声明降级 |
| CSA | 每条边 O(1)，闭包 O(\|E\|·k) | O(\|Cert*\|) | 组合可靠性定理 |
| FEA | O(n log n) 聚合 | O(n) | \<f 恶意贡献者时误差有界 |
| OEL | 每闭环一次，主耗时在执行 | 复用 | 预算耗尽触发保守回退 |

**正确性定理（OECS）**：假设 A66–A70 成立——**(A66)** CSC 来源签名不可伪造、可复现构建确定；**(A67)** 叶子证书在其声明域上可靠；**(A68)** 契约哈希捕获接口语义，一致性差分测试以概率 ≥ 1−δ 检出行为漂移；**(A69)** 覆盖估计保守、污染估计假阴性 ≤ β；**(A70)** 恶意贡献者 \< f 且审计以概率 ≥ 1−ε 识别。则：
1. **组合可靠性**：叶子证书有效 + 每条边 `Out⊆In` + 证据 `UseOK` ⇒ 闭包中组合证书有效。
2. **失效可靠性**：任何语义破坏性变更，要么契约哈希改变、要么差分测试失败（概率 ≥ 1−δ），故 Inv(v) 不被低估。
3. **覆盖条件有效性**：`cov_D(U) ≥ τ_cov ∧ κ ≤ τ_cont` 时，声明在 U 上有效；否则证书自动降级为「待探索」。
4. **鲁棒聚合有界性**：恶意贡献者 \< f 时，FEA 证书误差 ≤ ε_FEA(f)。
5. **预算安全性**：任一 `B_open` 耗尽必触发对应保守回退，绝不无声外推。

```python
class CapabilityPackage:
    def __init__(self, pid, ver, in_dom, out_dom, license, deps, datasets):
        self.pid, self.ver = pid, ver
        self.in_dom, self.out_dom = in_dom, out_dom
        self.license, self.deps = license, deps
        self.datasets = datasets
        self.assumptions = set()

    def contract_hash(self):
        return sha256(canonical_json({"in": self.in_dom, "out": self.out_dom,
                                      "assumptions": sorted(self.assumptions)}))

    def verify_provenance(self):
        rep = sha256(self.code_hash + self.build_env_hash +
                     tuple(sorted(h(d) for d in self.datasets)) + self.hardware_desc)
        return self.sig_ok() and rep == self.attested_rep_hash


class SupplyChain:
    def resolve(self, root):                       # O(|V|+|E|) 传递闭包 + 环检测
        seen, stack = {}, [root]
        while stack:
            p = stack.pop()
            if p.pid in seen:
                continue
            seen[p.pid] = p
            stack.extend(p.deps)
        return seen

    def license_compatible(self, closure):
        pkgs = list(closure.values())
        return all(pairwise_ok(a.license, b.license)
                   for i, a in enumerate(pkgs) for b in pkgs[i+1:])

    def compose_check(self, p, q):
        return (p.verify_provenance() and q.verify_provenance()
                and set_subset(p.out_dom, q.in_dom)
                and domains_overlap(p.in_dom, q.in_dom))
```

### IP-162 DTC（域类型证书）

```python
class DomainTypedCertificate:
    def __init__(self, claim, domain, out_domain, assumptions, evidence_ids, sig):
        self.claim, self.domain, self.out_domain = claim, domain, out_domain
        self.assumptions, self.evidence_ids, self.sig = assumptions, set(evidence_ids), sig

    def restrict(self, sub_domain):
        assert set_subset(sub_domain, self.domain)
        return DomainTypedCertificate(self.claim, sub_domain, self.out_domain,
                                      self.assumptions, self.evidence_ids, self.sig)

    def compose(self, other):
        if not set_subset(self.out_domain, other.domain):
            return BOTTOM("output_domain_not_subset", (self, other))
        if not assumptions_consistent(self.assumptions, other.assumptions):
            return BOTTOM("assumption_conflict", (self, other))
        return DomainTypedCertificate(
            claim=Conj(self.claim, other.claim),
            domain=self.domain, out_domain=other.out_domain,
            assumptions=merge_assumptions(self.assumptions, other.assumptions),
            evidence_ids=self.evidence_ids | other.evidence_ids,
            sig=sign_composition(self.sig, other.sig))
```

### IP-163 CDG/IRC（增量再认证）

```python
class CertificateDependencyGraph:
    def __init__(self):
        self.nodes = {}
        self.rev = defaultdict(set)

    def on_version_change(self, node_id, new_pkg, conformance_suite):
        old_hash = self.nodes[node_id].contract_hash
        if old_hash == new_pkg.contract_hash():
            if behavioral_conformance(new_pkg, conformance_suite):
                self.nodes[node_id] = Node(new_pkg, True, old_hash)
                return set()
        return self.invalidate(node_id)

    def invalidate(self, node_id):
        affected, stack = set(), [node_id]
        while stack:
            u = stack.pop()
            if u in affected:
                continue
            affected.add(u)
            stack.extend(self.rev[u])
        for u in affected:
            self.nodes[u].valid = False
        return affected
```

```python
class EvidenceDataset:
    def coverage(self, region, delta=0.05):
        cover = epsilon_cover(self.samples, delta)
        return measure(cover & region) / measure(region)

    def contamination(self, train_fingerprints):
        hits = sum(near_dup(s, train_fingerprints) for s in self.samples)
        return hits / max(1, len(self.samples))

    def use_ok(self, region):
        return (self.coverage(region) >= 0.90
                and self.contamination(self.train_fps) <= 0.01
```

```python
def compose_closure(certificates):
    frontier, valid, failures = list(certificates), set(), []
    while frontier:
        a = frontier.pop()
        for b in certificates:
            if interface_edge(a, b):
                j = a.compose(b)
                if j is BOTTOM:
                    failures.append(j)
                elif j.key not in valid:
                    valid.add(j.key)
                    frontier.append(j)
    return (valid, failures) if not failures else (BOTTOM, failures)


class FederatedEvidencePool:
    def __init__(self, tau0=0.5):
        self.trust = defaultdict(lambda: tau0)

    def audit(self, contributor, outcome):
        if outcome == "fail":
            self.trust[contributor] *= np.exp(-0.5)
        else:
            self.trust[contributor] = min(1.0, self.trust[contributor] + 0.1)

    def sample_weight(self, s, target_hw):

                * hw_match(s.platform, target_hw) * novelty(s, self.pool))
```

```python
def open_ecosystem_loop(M, root_pkg, region, task):
    closure = M.supply_chain.resolve(root_pkg)
    if not M.supply_chain.license_compatible(closure):
        return FALLBACK_CLOSED_CORE
    if not all(p.verify_provenance() for p in closure.values()):
        return FALLBACK_CLOSED_CORE

    J, mismatch = compose_closure([p.cert for p in closure.values()])
    if J is BOTTOM:

    if not M.edc.use_ok(region):
        M.budget.spend("B_data", request_evidence(region, M.edc))

    for v, new_pkg in detect_version_changes(closure):
        M.cdg.on_version_change(v, new_pkg, M.conformance_suite)

    J = revalidate(J, M.cdg, region)
    if M.budget.exhausted("B_verify"):
        J = use_cached_certificates(closure, region)
    if M.budget.trust_below_threshold(closure):
        return FALLBACK_CLOSED_CORE

    ev = execute_and_log(M, J, region, task)
    M.edc.append(ev)
    return J, ev
```
