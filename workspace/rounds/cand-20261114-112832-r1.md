# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「通用机器人平台」×「运动规划」）

> R69 把不确定性一分为二，并给 epistemic 歧义配上了主动动作：看、问、触。它问「我该向谁求证、还能问什么」。但那套保证有一个被悄悄默认的前提：**它只在一个技能、一套本体、一次策略调用内成立**。R69 的流匹配策略是一个扁平的动作块生成器，模态分解、VoI、似然第二意见全部以「这一次前向」为单位；它没有说，当机器人从「抓杯子」切到「拧阀门」、从夹爪换成吸盘、把一个技能的输出接到另一个技能的输入上时，这些保证还剩多少。
>
> 两个被理想化的地方：
> 1. **通用平台不是「一个更大的策略」，而是「一个共享本体 + 一个技能库 + 一个任务规划器」**。新任务绝大多数不是从零学会的，而是已有技能/工具的组合。R69 的所有不确定性度量与安全证书都是**局部**的；组合是它们最容易悄悄失效、又最不容易被察觉的地方。
> 2. **运动规划不是「把策略采样出来的动作块执行掉」，而是组合真正发生的地方**。长程任务要在任务层选技能、在连续层解运动；「选哪个技能」「用哪条轨迹去顺便看清一个歧义」本身就是一个规划问题，而不是一次采样问题。
>
> 核心命题：**在通用平台上，把「不确定性守恒 + 安全」从单策略内提升到技能组合层：每个技能携带可机器检验的能力契约（前置/效果/不确定性预算/安全包络/有效域/形态指纹），任务-运动规划在契约类型系统上搜索，只允许契约可链接的边；不确定性沿计划按一条显式的传播代数演化（aleatoric 只能累积、epistemic 只能被有认证的观测边消解），接缝处的涌现风险由接口守卫拦截；任何契约过期、域膨胀或规划不可认证，就逐边退化回 R69 的 FLUID。** R69 的 FLUID 是本方案在「单技能、零组合、零换装」边界上的严格退化。命名 **COMPASS-RAS**（Compositional Motion Planning with Assured Skill Substrate）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我如何把会做的事安全地拼成该做的事，而不让保证在接缝处漏掉**」——不确定性不只是刹车踏板、一句提问，也可以是技能之间那条必须被类型检查过的边。

## 0. 直觉与动机

**灵感 1（通用机器人平台 → 组合才是新的基本单位）**
直觉：一台通用机器人今天抓杯、明天拧阀、后天推车，它不可能为每个任务训练一条端到端流策略；它靠的是一套**技能库**（抓、放、推、拧、插、递……）加一套**任务规划器**把这些技能按前置/效果串起来，中间还可能换工具。问题在于：R69 的每一个保证都写在「单次策略调用」上。技能 A 的 epistemic 不确定性，可能被技能 B 的观测**消解**（A 不确定物体位姿，B 的抓取接触恰好把它测清楚），也可能被 B **放大**（B 在 A 的误差上再叠一层）。若把各技能的不确定性简单相加，要么过度保守，要么在真正危险的方向上漏算。**通用平台的第一性问题不是「策略够不够大」，而是「保证能不能沿着组合传播」。**

**灵感 2（运动规划 → 规划是组合落地的地方，也是主动消歧真正该发生的地方）**
直觉：连续层不是被动执行。任务-运动规划（TAMP）要在离散技能序列与连续可行轨迹之间同时求解。R69 的「看/问/触」是插进一段动作块里的离散查询；放到长程任务里，更自然的形态是**计划中的一条信息边**：先做一次「只为看清」的运动（探身、绕到可视侧、轻触试探），再根据观测决定后续接哪条技能边。信息动作于是从「打断执行」升级为「计划的一部分」，VoI 也应当按**整条计划的失败风险与残余熵**来算，而不是按下一步的熵来算。

**灵感 3（组合的不确定性代数 → 既不能简单相加，也不能简单忽略）**
直觉：设技能 A 的模态是「绕左/绕右」，技能 B 需要知道物体在左还是右。若 B 的前置条件依赖 A 已消解的模态，则组合后的 epistemic 不应再计一次；反过来，若 B 的观测与 A 的模态无关，则两段歧义在联合空间里相乘，简单相加会低估最坏情形。所以需要两条运算：**噪声累积 ⊕**（aleatoric，保守取上界，含跨技能相关项）与**信息抵消 ⊖**（epistemic，只在存在已认证观测边、且互信息可估时扣减，否则不扣）。这是 R69 两级保守退避在计划层的镜像：**能证明消解才扣，不能证明就当作未消解。**

**灵感 4（形态/工具变化 → 证书必须带指纹，换装即失效）**
直觉：通用平台会换夹爪、加负载、改传感器、在不同地面上跑。R69 的标定、流策略、似然基线全都绑定在某个「本体-工具-传感」配置上；换了工具，昨天的证书凭什么今天还算数？所以每个能力契约要携带一个**形态指纹**（运动链、自由度、工具几何、负载惯量、传感配置、标定版本）与一个**有效域**；指纹距离超阈值或标定/残差报警，就触发**最小重认证集**，未重认证的边一律不可执行。这把 R68 的换装不变式从「控制连续」提升为「证书可追溯地失效与重建」。

**灵感 5（新攻击面 → 契约伪造与接缝涌现风险）**
直觉：组合带来两类独有的危险。其一是**域膨胀**：一个只在窄分布上训练过的技能，在契约里声明了很宽的有效域，规划器就会把它用到没被验证过的地方——这比单技能失效更隐蔽，因为每一步看起来都「在域内」。其二是**接口涌现风险**：两条各自安全的运动，在交接处可能产生夹挤、动量突变或把人逼到墙角，而没有任何一个单技能的安全包络能看见它。**局部安全的并集不等于全局安全**。所以必须有一个显式的接口守卫和一个会审计契约链的审计器，否则「组合证书」只是给不安全计划盖的章。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（COMPASS-RAS 总览）** COMPASS-RAS = (SKL, CC, EFG, UPA, TAMP†, IVX, IHG, J_COMPASS)。三不变式：
(i) **实时控制层零学习写操作**（继承 R68 定义 276-i、R69 定义 293-i）；
(ii) **契约闭合**：任何被执行的计划边 σ 必须携带一个在当前形态指纹 Φ 与环境 regime 下有效的契约 C_σ；未知、过期或域不覆盖的边不得执行；
(iii) **组合单调安全**：计划证书只在 UPA 上界与接口风险都被检验通过时有效；否则逐边退化到 R69 的 FLUID，安全侧永不弱于 R69。

**定义 311（形态指纹 EFG）** Φ = (K, dof, tool_id, tool_geom, payload_inertia, sensor_rig, calib_ver)，其中 K 为运动链。距离 d_Φ(Φ, Φ') 由各分量归一化加权得到；契约有效域 Dom_Φ ⊆ Φ-space。指纹漂移 d_Φ > τ_Φ 或 R68 的 r_res/ECE 越界 ⇒ 相关契约标记为 stale。

**定义 312（技能与能力契约）** 技能 σ = (π_σ, M_σ)，π_σ 为某任务的流匹配策略/运动原语族，M_σ 为其可解的运动规划族。契约 C_σ = (Pre_σ, Eff_σ, U_ale_σ, U_epi_σ, Safe_σ, Dom_σ, Cost_σ, Φ_σ)：
- Pre_σ、Eff_σ 为混合约束集（符号谓词 + 几何/构型约束）；
- U_ale_σ、U_epi_σ 为 R69 定义 297 在技能内的估计；
- Safe_σ ⊆ 𝒳 为安全包络，Dom_σ ⊆ Φ-space × 环境 regime；
- Φ_σ 为签发证书时的指纹。

**定义 313（技能实例化）** 给定当前状态 x_t 与目标约束，实例化 σ 即求一条构型空间轨迹 ξ_σ ∈ M_σ 满足 Pre_σ 并优化代价，且附带 R69 的单边证书 (k, λ, mode)。实例化失败或单边证书无效 ⇒ 该边不可用。

**定义 314（契约链式组合）** 对 σ1, σ2，组合 C_{σ1} ∘ C_{σ2} 有定义当且仅当 Eff_{σ1} ⊨ Pre_{σ2}（效果蕴含前置）、Dom_{σ1} ∩ Dom_{σ2} ∩ {(Φ,regime)} ≠ ∅，且运动层存在接口构型 x_int 同时可行。结果契约的不确定性由定义 316 给出；链不闭合的序列在类型上非法，规划器不得搜索。

**定义 315（组合后信念）** 令 M_σ 为技能 σ 的模态身份，计划 P = (σ1,…,σn)。组合信念 b_P 定义在联合模态 M_P = (M_{σ1},…,M_{σn}) 与效果残差上；其熵 H(M_P) 与各边观测 Y_i 的互信息决定残余 epistemic。

**定义 316（不确定性传播代数 UPA）** 对顺序组合定义
- **噪声累积**：U_ale(C1 ∘ C2) = U_ale(C1) + U_ale(C2) + 2·c_cross，安全侧取 c_cross 的上界 c⁺ = Σ_{j,k} max(0, Cov_jk)（共享潜在噪声相关项）；
- **信息抵消**：U_epi(C1 ∘ C2) = max(0, U_epi(C1) + U_epi(C2) − I_cert(M_1; Y_2))，其中 I_cert 只在 C2 含**已认证观测边**（定义 317）且其观测模型通过标定门（R69 定义 306）时记为正值，否则为 0。
两条运算合记 ⊗。**性质**：朴素相加是 U_epi 的上界、是 U_ale 在 c_cross≥0 时的特例；而「忽略交接」是两者的下界——前者过保守，后者不安全。

**定义 317（计划级信息边 IVX）** 把 R69 的信息动作 g（注视/探针/问句）提升为计划中的一条边 E_info，携带 Pre/Eff（执行后对某模态的观测模型）与契约。其信息价值在计划层计算：VoI_plan(E) = R_risk(P) − E_y[R_risk(P | y)] + κ·(U_epi(P) − E_y[U_epi(P|y)])，其中 R_risk 为整条计划的失败风险上界。选择插入位置使净增益最大；VoI_plan ≤ 成本则不插，退回纯执行。

**定义 318（TAMP† 契约类型化任务-运动规划）** 在技能 AND/OR 图上搜索计划 P，目标
J(P) = E[Σ_σ Cost_σ + Σ_E Cost_info(E)] + ρ·R_risk(P) + κ·U_epi(P)，
s.t. 定义 314 的链闭合、定义 319 的接口无未拦截风险、定义 310-ii 的契约有效。采用分层搜索：任务层在契约前置/效果上做启发式搜索；运动层用采样式规划器惰性验证边的可行性与接口存在性。给出有界次优性 ε_plan。

**定义 319（接口涌现风险 IHG）** 设两技能交接的接口状态集 S_int。接口风险
R_int(σi, σj) = μ( Reach(S_int) ∩ (𝒳_hazard \ (Safe_{σi} ∪ Safe_{σj})) )，
即「任一单技能都看不见、但交接可达」的危险。R_int > 0 ⇒ 必须插入**接口守卫**（降速/限力/中间构型/让权），否则该组合边不可执行。

**定义 320（计划级风险退避 PLR）** 每条边 λ_σ = max(λ_floor(U_ale_σ + U_epi_σ^未消解), λ_plan(propagated))，其中 λ_plan 由计划层残余风险给出。若任何契约 stale、域不覆盖、UPA 无法上界或接口守卫缺失，则该边回退到 R69 的 FLUID 保守路径（U_epi 未消解视同 aleatoric），必要时整计划中止。λ 沿组合单调不降。

**定义 321（重认证触发 RTR）** 指纹漂移、标定漂移或 regime 改变触发最小重认证集 R(Φ→Φ')：只重验受影响技能的前置/效果/安全包络与流似然基线。重认证完成前，受影响契约视为 stale；重认证成本计入 E299/E315 的 Pareto。

**定义 322（组合证书 J_COMPASS）** J_COMPASS = (J_FLUID^{σ1..σn}, contract_chain_hash, Φ, regime, R_int_clearance, UPA_bound, U_epi_residual, plan_voi_ratio, suboptimality, compass_ver)。Valid ⇔ 每条边 J_FLUID 有效 ∧ 链闭合 ∧ 无未拦截接口风险 ∧ UPA 上界成立 ∧ 预算/重认证状态合法。

**定义 323（契约投毒威胁模型）** ℰ_COMPASS = ℰ_FLUID × ℰ_domain（域膨胀/前置虚报）× ℰ_emergent（接口涌现风险/顺序攻击）× ℰ_revalidate（伪造重认证）。对手可污染技能库声明或观测模型。证据纪律继承 R69：契约声明必须在留出 regime 上可复现，且关键前置至少两个正交来源一致。

**定义 324（组合审计 VQAuditor-II）** 审计对象：契约链是否真闭合、技能是否被用在验证域外、接口守卫是否被触发/绕过、计划级 VoI 是否事后兑现、重认证是否真实执行。结论回灌 AuditBuf，成为下一轮 TAMP† 的边成本与域先验。

**定义 325（通才技能路由 GSR）** 当多个技能的 Pre 同时被满足（如夹爪抓 vs 吸盘吸），按**认证后**期望代价与域覆盖选择，而非按原始成功率：σ* = argmin_{σ: C_σ valid} [Cost_σ + ρ·risk_σ + κ·U_σ]，禁止「挑不确定性最低但域最窄」的不确定性套利。

**定义 326（退化到 FLUID）** 当计划长度 n=1、无换装、无接口、且 I_cert=c_cross=0 时，UPA 恒等退化为 R69 的 (U_ale, U_epi)，TAMP† 退化为 FMP 采样，J_COMPASS 退化为 J_FLUID。因此 R69 是 COMPASS 在「单技能、零组合、零换装」边界上的严格退化。

## 2. 关键算法骨架

```python
# IP-264/266：能力契约与不确定性传播代数
class SkillContract:
    def __init__(self, pre, eff, u_ale, u_epi, safe, dom_phi, cost, phi):
        self.pre, self.eff = pre, eff
        self.u_ale, self.u_epi = u_ale, u_epi
        self.safe, self.dom, self.cost, self.phi = safe, dom_phi, cost, phi

    def valid_under(self, phi, regime):
        return self.dom.covers(phi, regime) and not self.is_stale(phi)

def chain(C1, C2, phi, regime, I_cert=0.0, c_cross=0.0):
    if not (C1.valid_under(phi, regime) and C2.valid_under(phi, regime)): return None
    if not implies(C1.eff, C2.pre):                 # 定义 314：效果 ⊨ 前置
        return None
    u_ale = C1.u_ale + C2.u_ale + 2.0 * max(0.0, c_cross)   # 噪声累积（安全上界）
    u_epi = max(0.0, C1.u_epi + C2.u_epi - I_cert)          # 只在认证观测边扣减
    return SkillContract(merge_pre(C1, C2), C2.eff, u_ale, u_epi,
                         safe_interface(C1.safe, C2.safe),
                         C1.dom & C2.dom, C1.cost + C2.cost, phi)

# IP-267/268：契约类型化 TAMP†（任务层搜索 + 运动层惰性验证 + 计划级 VoI）
def tamp_plan(x0, goal, skills, phi, regime, budget):
    frontier = [(0.0, x0, [])]                       # 代价, 状态, 计划
    while frontier:
        c, x, P = heappop(frontier)
        for sigma in skills:
            C = sigma.contract
            if not C.valid_under(phi, regime):        continue
            if not implies(state_facts(x), C.pre):    continue
            xi = motion_plan(sigma, x, C)             # 惰性：只展开可行边
            if xi is None:                            continue
            r_int = interface_risk(P[-1] if P else None, sigma)
            if r_int > EPS_INT:
                if not interface_guard_feasible(C, r_int): continue
                xi = add_guard(xi, r_int)             # IP-269 接口守卫
            P2 = P + [SigmaEdge(sigma, xi, chain_contract(P, C))]
            if C.eff.satisfies(goal):                 # 候选计划，做计划级 VoI 精修
                P2 = maybe_insert_info_edge(P2, budget)
                heappush(frontier, (plan_cost(P2), C.eff.state, P2))
    return best_plan_with_valid_certificate()

# IP-268：计划级信息边（VoI 按整条计划风险与残余熵算）
def maybe_insert_info_edge(P, budget):
    best = None
    for pos in range(len(P) + 1):
        for g in info_candidates(P, pos):
            if not budget.allow(g): continue
            if not c_ras_wm.certify_info(g, P[pos].state): continue
            voi = risk_reduction(P, g, pos) + KAPPA * entropy_reduction(P, g, pos)
            score = voi - social_physical_cost(g)
            if best is None or score > best.score: best = (pos, g, score)
    return best and insert(P, best[0], best[1]) or P

# IP-269/270：接口守卫 + 计划级风险退避
def plan_risk_backoff(P, phi, regime):
    lam = {}
    for i, e in enumerate(P):
        C = e.contract
        if C.stale or not C.dom.covers(phi, regime):
            lam[i] = FLUID_backoff(e)                 # 定义 320：逐边退 R69
        else:
            lam[i] = max(lam_floor(C.u_ale + C.u_epi),
                         lam_plan(P, i, phi, regime))
    return lam

# IP-276：COMPASS 主闭环（R69 闭环 + 契约组合层）
def COMPASS_round(M, x0, goal):
    phi, regime = M.efg.fingerprint(), M.efg.regime()
    M.rtr.check_and_revalidate(phi, regime)            # IP-271：换装/漂移触发重认证
    P = M.tamp.plan(x0, goal, M.skl.active(phi), phi, regime, M.budget)
    if P is None or not M.compass_cert.valid(P, phi, regime):
        return M.fluid.fallback(x0)                    # 定义 326：退回 R69 单技能
    lam = plan_risk_backoff(P, phi, regime)
    for i, e in enumerate(P):
        k, tau = M.fluid.execute_edge(e, lam[i])       # 每条边仍是 R69 的认证执行
        M.vqa_ii.submit_async(P, e, phi, lam[i])       # IP-274：组合审计
    return P, lam
```

## 3. 推导

**引理 19（契约闭合的可执行性）** 若计划 P 的每条边在当前 (Φ, regime) 下契约有效、相邻边链闭合且接口守卫可插入，则存在一条执行轨迹使每步都落在对应 Safe_σ 内；除接口守卫覆盖的状态外，越界集合为空。要点：链闭合保证运动层接口构型存在，定义 313 的实例化把每段轨迹钉在各自包络内；唯一可能的缝隙正是 S_int，由 IHG 显式处理。

**引理 20（UPA 的保守性）** 对任意组合，定义 316 的 U_ale^+ 不小于真实 aleatoric 方差（因保留非负跨相关项上界），U_epi^- 不小于真实残余 epistemic（因只在认证观测下扣减互信息，且互信息估计误差由标定门吸收）。故按 UPA 结果做 λ 缩放不会低估风险；朴素相加只在其上再加保守量，忽略交接则可能低估。系：**安全的组合必须是「能证明才扣、不能证明就加」的代数**。

**引理 21（计划级 VoI 的近似保证）** 在模态观测条件独立、信息边收益随已观测证据单调递减的假设下，计划级熵减函数是自适应子模的；对信息边位置与类型的贪心插入给出至少 (1−1/e) 的最优熵减，且在风险项线性时可加时保持同一近似比。系：R69 的单步贪心 VoI 是「计划长度 1」的特例。

**引理 22（域膨胀的可检测性）** 设技能真实有效域 D ⊂ D̂（声明域）。若重认证/留出集在 D̂ \ D 上的采样覆盖率为 q，则检测到域外失效的概率随 q 单调上升；当 q→0（伪装域只覆盖训练分布）时任何黑箱审计都不可保证——因此必须把「域声明」本身当作需第二证据源交叉验证的断言（定义 323 证据纪律）。系：**审计能查行为，查不了沉默；未验证的宽域必须按窄域使用。**

**引理 23（接缝风险的不可加性）** 存在两个技能使 R_int(σ1,σ2) > 0 而 Safe_{σ1}、Safe_{σ2} 各自内部风险为 0。构造：两条在各自包络内合法的运动在交接构型附近共同挤压一个未建模的软约束区域。故组合风险不是单边风险的函数，接口守卫不可由单边校验替代。

**定理 18（COMPASS 严格包含 FLUID/R68）** 在 A95–A99 下，COMPASS 在任意状态上的期望风险 ≤ R69 FLUID ≤ R68；且当 n=1、无换装、无接口、VoI_plan≤成本、契约 stale 或审计失败时，两者逐指令相同（定义 326、320）。R69/R68 是 COMPASS 在「单技能、零组合」边界上的退化；安全侧不让步，效率侧获得长程组合与信息边收益。

**定理 19（组合安全与接缝无突变）** 契约闭合 + 接口守卫 + 计划级退避下，计划风险 ≤ ε_plan；任一边退化到 FLUID 只改变该边的 λ 与模态选择，不改变已验证的安全包络；技能切换处由守卫提供连续过渡，继承 R68 定理 15 的换装不变式 ⇒ 控制连续、无突变。换装/漂移触发 RTR，未重认证边不执行，故安全不依赖过期的旧证书。

**一句话**：COMPASS 的全部组合保证都押在「能力契约是诚实且完整」这一前提上——通用平台的技能库会持续增长，而最危险的失败不是某个技能出错，而是一个技能的**有效域被静默高报**、或两条各自安全的运动在**接缝处产生无人声明的涌现风险**；这时组合证书不再是安全的证明，而只是给一个「每一步看起来都合法」的不安全计划盖章——**组合能证明的，只是它被告知的；平台越通用，没被告知的就越多**。

```python
class SkillContract:
    def __init__(self, pre, eff, u_ale, u_epi, safe, dom_phi, cost, phi):
        self.pre, self.eff, self.u_ale, self.u_epi = pre, eff, u_ale, u_epi
        self.safe, self.dom, self.cost, self.phi = safe, dom_phi, cost, phi

    def valid_under(self, phi, regime):
        return self.dom.covers(phi, regime) and not self.is_stale(phi)

def chain(C1, C2, phi, regime, I_cert=0.0, c_cross=0.0):
    if not (C1.valid_under(phi, regime) and C2.valid_under(phi, regime)): return None
    if not implies(C1.eff, C2.pre): return None                       # 类型检查

                         safe_interface(C1.safe, C2.safe),
                         C1.dom & C2.dom, C1.cost + C2.cost, phi)

                xi = add_guard(xi, r_int)                            # IP-269
            P2 = P + [SigmaEdge(sigma, xi, chain_contract(P, C))]
            if C.eff.satisfies(goal): P2 = maybe_insert_info_edge(P2, budget)
            heappush(frontier, (plan_cost(P2), C.eff.state, P2))
    return best_plan_with_valid_certificate()

def maybe_insert_info_edge(P, budget):
    best = None
    for pos in range(len(P) + 1):
        for g in info_candidates(P, pos):
            if not budget.allow(g) or not c_ras_wm.certify_info(g, P[pos].state): continue
            vois = risk_reduction(P, g, pos) + KAPPA * entropy_reduction(P, g, pos)
            score = vois - social_physical_cost(g)
            if best is None or score > best.score: best = (pos, g, score)
    return insert(P, best[0], best[1]) if best and best[2] > 0 else P

# IP-269/270/271：接口守卫 + 计划级退避 + 重认证
def plan_risk_backoff(P, phi, regime):
    lam = {}
    for i, e in enumerate(P):
        C = e.contract
        lam[i] = (FLUID_backoff(e) if C.stale or not C.dom.covers(phi, regime)
                  else max(lam_floor(C.u_ale + C.u_epi), lam_plan(P, i, phi, regime)))
    return lam

def COMPASS_round(M, x0, goal):
    phi, regime = M.efg.fingerprint(), M.efg.regime()
    M.rtr.check_and_revalidate(phi, regime)                          # 换装/漂移重认证
    P = M.tamp.plan(x0, goal, M.skl.active(phi), phi, regime, M.budget)
    if P is None or not M.compass_cert.valid(P, phi, regime):
        return M.fluid.fallback(x0)                                  # 定义 326
    lam = plan_risk_backoff(P, phi, regime)
    for i, e in enumerate(P):
        k, tau = M.fluid.execute_edge(e, lam[i])                     # 每条边仍是 R69 认证执行
        M.vqa_ii.submit_async(P, e, phi, lam[i])                     # IP-274
    return P, lam
```

## 4. 推导

**引理 19（契约闭合的可执行性）** 计划每边在当前 (Φ,regime) 契约有效、相邻边链闭合、接口守卫可插，则存在执行轨迹使每步落在对应 `Safe_σ` 内；除守卫覆盖的 `S_int` 外越界集为空。链闭包保证运动层接口构型存在，实例化把每段轨迹钉在各自包络内，唯一缝隙正是 `S_int`，由 IHG 显式处理。

**引理 20（UPA 保守性）** `U_ale^+` 不小于真实组合方差（保留非负跨相关上界），`U_epi^-` 不小于真实残余 epistemic（只在认证观测下扣互信息，估计误差被标定门吸收）。故按 UPA 做 λ 缩放不低估风险；朴素相加更保守，忽略交接可能低估。系：安全的组合必须「能证明才扣、不能证明就加」。

**引理 21（计划级 VoI 近似）** 观测条件独立、信息收益随证据单调递减时，计划级熵减为自适应子模；对信息边位置/类型贪心插入达 `(1−1/e)` 最优熵减；风险项线性可加时近似比保持。系：R69 单步 VoI 是计划长度为 1 的特例。

**引理 22（域膨胀可检测性）** 真实域 `D⊂D̂`，留出集在 `D̂\D` 覆盖率 q 越大检测概率越高；`q→0`（伪装域只覆盖训练分布）时任何黑箱审计不可保证——故域声明本身需第二证据源交叉验证。系：审计能查行为，查不了沉默；未验证的宽域按窄域使用。

**引理 23（接缝风险不可加性）** 存在两技能使 `R_int>0` 而各自内部风险为 0：两条各自包络内合法的运动在交接构型附近共同挤压未建模软约束区。故组合风险不是单边风险的函数，接口守卫不可由单边校验替代。

**定理 18（COMPASS 严格包含 FLUID/R68）** A95–A99 下，COMPASS 任意状态期望风险 ≤ R69 ≤ R68；当 `n=1`、无换装、无接口、`VoI_plan≤成本`、契约 stale 或审计失败时逐指令相同（定义 326/320）。R69/R68 是「单技能、零组合」边界；安全不让步，效率获得长程组合与信息边收益。

**定理 19（组合安全与接缝无突变）** 契约闭合 + 接口守卫 + 计划退避下计划风险 ≤ `ε_plan`；某边退化只改该边 λ 与模态选择、不改已验证包络；切换处由守卫连续过渡，继承 R68 定理 15 换装不变式 ⇒ 控制连续无突变；RTR 保证不依赖过期旧证书。

## 7. 本轮最大风险

**一句话**：COMPASS 的全部组合保证都押在「能力契约是诚实且完整」这一前提上——通用平台技能库会持续增长，最危险的失败不是某技能出错，而是一个技能的**有效域被静默高报**、或两条各自安全的运动在**接缝处产生无人声明的涌现风险**；此时组合证书不再是安全证明，而只是给一个「每步看起来都合法」的不安全计划盖章——**组合能证明的，只是它被告知的；平台越通用，没被告知的就越多**。

**次级风险与缓解**：组合爆炸拖垮规划节拍（契约类型剪枝 + 惰性运动验证 + 有界次优 + E307/E310）；换装后旧证书误用（EFG 指纹 + RTR，未认证边不执行，E305）；域膨胀审计无能（留出 regime 覆盖 + 第二证据源，引理 22、E308）；接缝涌现风险漏检（IHG 显式 `Reach(S_int)` + 守卫，引理 23、E304/E312）；计划级 VoI 低估长程耦合（自适应子模贪心 + 与单步基线消融，E303）；技能库被投毒（`ℰ_COMPASS` + VQAuditor-II，定义 323–324）。
