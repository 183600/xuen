## 0. 直觉与动机

**灵感 1（多端口部署 → 舰队是免费的对照实验）**
直觉：R68 反吸收界（引理 13）只保证 ω_f ≥ 3ω_cal 的快故障可检出；ω_f < ω_cal 的慢故障会被 COF 当漂移吸收——这是**时间通道**的固有盲区。但若同一模型部署在 P 个端口，每个端口的温漂/磨损/安装各不相同，则「世界/模型」是共模的，「本单元故障」是差模的。差分掉舰队共模后，一个只在本端口出现的慢故障会变成持续、技能可匹配的离群信号——**空间通道与时间通道正交**，慢故障第一次有了可检出的维度。多端口不是运维负担，而是计量学意义上的**参照系阵列**。

**灵感 2（技能学习 → 技能是跨端口可比的坐标框架）**
直觉：跨端口比较的前提是「做得是同一件事」。逐帧动作提案没有可比性（各端口状态流不同）；但技能是离散、可命名、可重复的行为原语 σ_k。只有在「同一技能 σ_k、同一标定归一化语境 ẑ」下，跨端口残差才可比。于是技能不只是控制手段，更是**让舰队差分诊断成立的公共坐标**。反过来，技能又是危险的：技能的隐含前提（几何对齐、力零偏为零、时间同步）恰恰是 R68 标定层在维护的量；标定失准时执行该技能，等于在错误坐标系里做正确的事。

**灵感 3（合流 → 可移植语义 × 本地化接地）**
直觉：技能语义应当**可移植**（在哪台机器上都表示「轻放」），但技能的**接地**必须**本地化**（每台机器的标定、阈值、安全裕度不同）。这给出干净的因子分解：在标定归一化状态 ẑ = N(z; ĉ^(p)) 上定义技能（共享、可迁移），在端口本地 (ĉ^(p), U^(p)) 上校验前置条件与安全裕度（不可迁移）。一架模型、一套技能语义、P 份接地证。

**灵感 4（组件合流 → SKILLPORT-RAS 七组件）**
1. **SKL Skill Library**：可组合技能库，每个技能带 π_k（option 策略）/ Pre_k（含计量前提）/ Post_k（效果保证）/ J_k（安全对 c 的敏感度雅可比）/ e_k（描述子）；
2. **PG-COF Port-Grounded COF**：分层标定 c^(p)=c̄+δ^(p)，舰队共享 c̄ 与端口特异 δ^(p) 部分池化；
3. **XPD Cross-Port Differential**：技能匹配的跨端口残差差分，CUSUM 检出端口孤立慢故障；
4. **SCG Skill-Commitment Gate**：前置条件 ∧ 安全裕度 m_k ≥ 0，否则退化为安全原语 σ_0；
5. **FSD Federated Skill Distillation**：只在标定归一化统计上做联邦聚合，稳健中位数抗投毒；
6. **FLEET-CAC**：分层 canary 晋升，本地 CAC（继承 R68）+ 舰队一致性门；
7. **RVG Reference-Validity Guard**：检测「参照系本身坏了」（共模盲区），失效即降级回 R68 时间通道 + 外部计量标准。

**灵感 5（对 R68 风险的对症下药）**
- R68「缓变故障被标定吸收」：XPD 用空间差分补时间盲区（对非共模慢故障），定理 16；
- R68「表征坍缩/负迁移」：技能库把单一大策略切成小策略，容量压力分散；FSD 只在归一化坐标聚合降低负迁移；
- R68「CAC 坏适配器」：FLEET-CAC 把单端口 canary 扩成分层舰队 canary，一个端口过不算过；
- 新纪律：**任何技能，若其安全裕度无法在当前 (ĉ,U) 下证明非负，就必须退化为 σ_0**——技能门控只收紧不放宽。

m_k^0 为标定理想时的标称裕度，z_β 为置信分位。U=tr(Σ_c) 增大 ⇒ m_k 单调下降 ⇒ 前置条件更难过——**门控只会收紧**。

**定义 300（SCG 技能承诺门）** 每决策步在候选技能上求解

若无可行 k，k*=0（σ_0）。SCG 是「安全屏蔽（shield）」：它在策略外层做可证明的可行性过滤，而非事后裁剪。

# IP-253/254 端口分层标定 + 技能库
class PortSkillStack:
    def __init__(self, model, skill_lib, port_id, P):
        self.mtm, self.K, self.p = model, skill_lib, port_id
        self.cof = PortGroundedCOF(d_c=12)
        self.xpd = CrossPortDifferential(window=200)

    def normalized_state(self, z):
        return calibrate(z, self.cof.c_hat)          # ẑ = N(z; ĉ^(p))

    # IP-256/257 SCG：技能承诺门（shield），前置条件 ∧ 裕度
    def select_skill(self, z, U, task_ctx):
        z_hat = self.normalized_state(z)
        feasible = []
        for k, sk in self.K.items():
            m = sk.margin(z_hat, self.cof.c_hat, U)  # m^0 − z_β‖J_k Σ^{1/2}‖
            if sk.precondition(z_hat, self.cof.c_hat, U) and m >= 0:
                feasible.append((sk.progress(z_hat, task_ctx), k, m))
        if not feasible:
            return self.K.safe_primitive, 0.0       # σ_0 兜底，只收紧
        _, k, m = max(feasible)
        return self.K[k], m


# IP-255 XPD：跨端口技能匹配差分 + CUSUM（舰队侧异步）
class CrossPortDifferential:
    def observe(self, port_id, skill_id, z_hat, r):
        ref = self.robust_agg(skill_id, z_hat, exclude=port_id)
        d = r - ref
        self.cusum[port_id] = max(0, self.cusum[port_id] + d - self.nu)
        if self.cusum[port_id] > self.h * self.sigma_x:
            return self.attribute(d, skill_id)       # 方向判 cal / fault
        return None

    def attribute(self, d, skill_id):
        if self.in_calibration_manifold(d, skill_id):  # 落在 span{∂r/∂c}
            return ('H_cal', self.p)                    # 端口漂移
        return ('H_fault', self.p)                      # 标定零空间 → 真故障

def SKILLPORT_round(M, obs, p):

## 3. 推导

**引理 16（标定不可移植 / 端口证书必要性）** 同模型 θ 在两端口 p、q，真标定 c^{*(p)} ≠ c^{*(q)}，技能安全裕度 m_k(c) 对 c 光滑、J_k=∂m_k/∂c。则 |m_k(c^{*(p)}) − m_k(c^{*(q)})| ≥ L_k‖c^{*(p)} − c^{*(q)}‖，其中 L_k 为最小奇异值下界。故在 p 成立（m_k≥0）的证书不保证在 q 成立——**一张证书无法覆盖两个端口**，J_FLEET 必须逐端口。这不是保守，而是 R68「单证书」假设在多端口下的第一次破碎。

**引理 17（裕度单调性 / SCG 只会收紧）** 由定义 298，m_k(ĉ,U)=m_k^0 − z_β‖J_kΣ_c^{1/2}‖，Σ_c 半正定且随 U=tr(Σ_c) 增长；故 ∂m_k/∂U ≤ 0，U 增大只减少可行技能集。σ_0 的 J_0≈0 使其裕度几乎不随 U 变。因此 SCG 门控在标定失准/不确定时只会退向更安全原语，**任何 (ĉ,U) 扰动都不会因门控而被放宽**。

**引理 18（标定不变技能迁移界）** 技能在 ẑ 上训练。若归一化满足 ‖N(z;ĉ) − N(z;c^*)‖ ≤ ε_N 且策略对输入 L_π-Lipschitz，则端口间迁移 excess risk ≤ L_π·ε_N + C/√n_k（n_k 为该技能样本数）。当 ε_N→0（标定收敛）技能严格可移植；这正是「语义可移植、接地本地化」的定量表述。

**引理 19（差分通道的慢故障可检性）** 技能匹配后，端口 p 的局部故障在差分序 d_t^(p) 上表现为漂移率 b。CUSUM 平均检出延迟 τ_det ≈ hσ_x/b。故只要 b ≥ b_min = hσ_x/τ_max，任意频率（含 ω_f ≪ ω_cal）的端口特异故障都能在 τ_max 内被检出——与 R68 的 ω_f 门槛无关。对照：同一慢故障在 R68 时间通道内的检出概率 ≈ 虚警率（被 COF 吸收，引理 13 的补集）。

**定理 16（双通道覆盖：封堵 R68 慢故障盲区）** 将故障空间按（时间频率 ω_f，空间共模度 κ_cm）划分。
- R68 通道（时间）：ω_f ≥ 3ω_cal 时以引理 13 检出；
- XPD 通道（空间）：κ_cm < κ*（端口特异）且幅度 ≥ b_min 时，由引理 19 以概率 ≥ 1−α 检出，**与 ω_f 无关**；
因此对一切**非共模**故障（无论快慢），至少一条通道可检。R68 曾自陈的「缓变故障隐形」盲区，在非共模情形下被空间通道精确封堵。α 由 CUSUM 的 ARL 设计控制。

**定理 17（共模盲区的信息论下界）** 若故障同时满足 ω_f < ω_cal（时间通道吸收）与 κ_cm ≥ κ*（空间通道差分为零），则对任意基于「端口间比较」的检测器，P_d 相对无故障分布 ≤ α + δ(κ_cm)，δ 随 κ_cm→1 单调上升、κ_cm=1 时 δ=0。**证明要点**：此时各端口残差同分布，差分 d^(p) 的分布与无故障不可区分，任何检定统计量的功效不高于虚警水平。故「慢且共模」是两通道盲区的精确交集，不是实现缺陷而是**自参照舰队的信息论极限**——只能靠 RVG + 外部计量标准（标准件/独立审计端口）打破，这正是定义 303 的动机。**这是 R69 相比 R68 唯一没有缩小、只是被显式定位的残余盲区。**

**定理 18（屏蔽式技能组合安全）** 若每一步提交的技能满足 Pre_k ∧ m_k≥0，且相邻技能满足 Post_{k_i}⊨Pre_{k_{i+1}}（在冻结 (ĉ,U) 下），则组合轨迹始终停留在各技能的证书安全集 S_k 内；唯一逃逸路径是「前置条件在冻结窗口内被违反」的事件，SCG 要么当场退 σ_0，要么其未被拦截的概率被 σ_x 与冻结时长的乘积上界约束。故**技能组合不放大风险**：组合安全性由单技能安全性与转移相容性相乘给出，而非指数级复合。

**定理 19（舰队晋升安全）** 设各 canary 端口本地误接受率 ≤ ε_p、端口失效相关性 ≤ ρ，则舰队误晋升概率 ≤ Σ_{p∈𝒫_can} ε_p·(1+ρ)；FSD 采用截尾平均时，投毒端口对聚合梯度的最大偏移 ≤ 截尾比例 f_trim（引理 19 的直接推论）。再叠加 RVG 的参照失效否决与逐端口回滚隔离，**单端口污染不能晋升为舰队级共享技能，也无法通过回滚扩散**。

## 6. 本轮最大风险

**一句话**：SKILLPORT-RAS 的第二条检出通道（XPD）完全依赖「端口之间互为参照」，一旦真实故障是**慢且共模**的（同批次传感器同步老化、同版本固件缺陷、同一环境长期漂移使全部端口一起偏），各端口会「一致地错」，差分 d^(p) 归零，RVG 也只会看到一堆「互相印证」的端口——时间通道（R68）吸收慢故障、空间通道（XPD）差分为零，**两条通道的盲区在「慢 + 共模」这一点精确重叠**，全舰队会在「端口间高度一致、测量越来越准」的假象下同步失去对最隐蔽故障的检出能力；这是自参照舰队的原罪：参照系越一致，共模故障越隐形。

**次级风险与缓解**：
1. **小 P 统计不可靠**：P<5 时差分噪声大 → 自动退回 R68 时间通道（诚实降级，不假装有空间信息）；
2. **端口偏斜/技能不可比**：匹配集为空或 ẑ 分布不重叠 → 该技能禁用 XPD，只做本地门控；
3. **投毒端口**：恶意/故障端口污染 c̄ 与 FSD 梯度 → 稳健截尾聚合 + 本地 CAC 前置过滤 + 逐端口回滚隔离；
4. **参照失效误判**：RVG 误触发导致过度降级 → κ* 用外部标准件校准，RVG 触发只降级不锁死，恢复需外部计量复核；
5. **技能组合爆炸**：K 大时组合搜索不可行 → 分层技能图 + 只在线验证已提交链（定理 18 保证局部验证充分）。

class PortSkillStack:
    def normalized_state(self, z):
        return calibrate(z, self.cof.c_hat)            # ẑ = N(z; ĉ^(p))

        self.cusum[port_id] = max(0, self.cusum[port_id] + d - self.nu)
        if self.cusum[port_id] > self.h * self.sigma_x:
            return self.attribute(d, skill_id)
        return None

    def attribute(self, d, skill_id):
        if self.in_calibration_manifold(d, skill_id):  # 落在 span{∂r/∂c}
            return ('H_cal', self.p)                    # 端口漂移
        return ('H_fault', self.p)                      # 标定零空间 → 真故障

# IP-259/260 FLEET-CAC + RVG：分层 canary 晋升 + 参照有效性
class FleetCAC:
    def promote(self, cand, canary_ports):
        if not all(R68_CAC.five_gates(cand, p) for p in canary_ports):
            return 'REJECT_LOCAL'
        if RVG.common_mode_ratio(cand, canary_ports) >= KAPPA_STAR:
            RVG.degrade_to_temporal_only(); return 'REJECT_REFERENCE'
        if not self.cross_port_consistency(cand, canary_ports):
            return 'REJECT_INCONSISTENT'
        for p in wave_order(canary_ports):             # 端口波次蓝绿
            atomic_swap(cand.live_ptr[p], cand)        # 单端口回滚隔离
        return 'PASS'

# IP-263/264 端口 p 主闭环
def SKILLPORT_round(M, obs, p):
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)              # 共享 trunk

    lam = max(M.efs.risk_scale(M.cfa(o, c, U)), thr['lam_floor'],
              1 - m / sk.m_max,                                        # 技能裕度项
              0.8 if (o['qual']['face'] < 0.8 or wm_drift(o, wm_preds)) else 0.6)
    tau = M.pi_sigma.prefix_dispatch(sk.plan(z_hat)) * lam
    M.fleet.report(p, sk.id, z_hat, d, (c, U))                         # 异步舰队侧
    return sk.id, m, lam, (c, U, d)

## 4. 推导

**引理 16（标定不可移植 / 端口证书必要性）** m_k(c) 光滑、J_k=∂m_k/∂c，则 |m_k(c^{*(p)})−m_k(c^{*(q)})| ≥ L_k‖c^{*(p)}−c^{*(q)}‖。p 上成立的证书不保证 q 上成立——单一证书无法覆盖两端口，J_FLEET 必须逐端口。

**引理 17（裕度单调性 / SCG 只收紧）** m_k=m_k^0−z_β‖J_kΣ_c^{1/2}‖₂，Σ_c 半正定且随 U 增长，故 ∂m_k/∂U≤0；U 增大只缩小可行技能集，门控永不因不确定而放宽；J_0≈0 使 σ_0 几乎不受 U 影响。

**引理 18（标定不变技能迁移界）** ‖N(z;ĉ)−N(z;c^*)‖≤ε_N、策略 L_π-Lipschitz，则跨端口迁移 excess risk ≤ L_π·ε_N + C/√n_k；ε_N→0 时技能严格可移植——语义可移植、接地本地化。

**引理 19（差分通道慢故障可检性）** 技能匹配后端口 p 局部故障在 d_t^(p) 上漂移率 b，CUSUM 平均检出延迟 ≈ hσ_x/b；b ≥ b_min=hσ_x/τ_max 时任意频率（含 ω_f≪ω_cal）都可检，与 R68 的 ω_f 门槛无关。

**定理 16（双通道覆盖 / 封堵 R68 慢故障盲区）** 按（ω_f, κ_cm）划分故障空间：R68 时间通道覆盖 ω_f≥3ω_cal（引理 13）；XPD 空间通道覆盖 κ_cm<κ* 且幅度≥b_min 的端口特异故障（引理 19），**与 ω_f 无关**。故一切**非共模**故障无论快慢至少一条通道可检；R68「缓变故障隐形」盲区在非共模情形被精确封堵。

**定理 17（共模盲区信息论下界）** 若 ω_f<ω_cal（时间吸收）且 κ_cm≥κ*（差分为零），各端口残差同分布，d^(p) 与无故障不可区分，任意端口间比较检测器的 P_d ≤ α+δ(κ_cm)，δ(1)=0。故「慢+共模」是两通道盲区的精确交集，属自参照舰队的信息论极限，只能由 RVG + 外部计量标准打破——这是唯一未缩小、仅被显式定位的残余盲区。

**定理 18（屏蔽式技能组合安全）** 若每步 Pre_k∧m_k≥0 且 Post_{k_i}⊨Pre_{k_{i+1}}（冻结 (ĉ,U)），组合轨迹恒在证书安全集内；唯一逃逸是冻结窗内前置条件被违反，SCG 当场退 σ_0 或由 σ_x×冻结时长上界约束。组合安全 = 单技能安全 × 转移相容，非线性复合放大。

**定理 19（舰队晋升安全）** 各 canary 本地误接受 ≤ε_p、相关性 ≤ρ，则舰队误晋升 ≤ Σ_{p∈𝒫_can}ε_p(1+ρ)；FSD 截尾均值使投毒端口对聚合梯度偏移 ≤ 截尾比例 f_trim。叠加 RVG 否决与逐端口回滚隔离，单端口污染无法晋升为共享技能，也无法经回滚扩散。

## 7. 本轮最大风险

**一句话**：SKILLPORT-RAS 的第二条检出通道（XPD）完全依赖「端口之间互为参照」，一旦真实故障是**慢且共模**的（同批次传感器同步老化、同版本固件缺陷、同一环境长期漂移使全部端口一起偏），各端口会「一致地错」，差分 d^(p) 归零，RVG 也只看到一堆互相印证的端口——时间通道吸收慢故障、空间通道差分为零，**两条通道的盲区在「慢 + 共模」这点精确重叠**，全舰队会在「端口间高度一致、测量越来越准」的假象下同步失去对最隐蔽故障的检出能力；这是自参照舰队的原罪：参照系越一致，共模故障越隐形。

**次级风险与缓解**：小 P 统计不可靠（P<5 退回时间通道，诚实降级）；端口偏斜/技能不可比（匹配集空即禁用 XPD，只做本地门控）；投毒端口（截尾聚合 + 本地 CAC 前置 + 逐端口回滚隔离）；RVG 误判（κ* 用外部标准件校准，触发只降级不锁死）；技能组合爆炸（分层技能图 + 仅在线验证已提交链，定理 18 保证局部验证充分）。
