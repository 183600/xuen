# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS」IP-287~294；灵感循环第 3 轮；本轮灵感：「可重构机构」×「实例分割」）

> R72 把 GAUGE 从「认知层审计」推进到「具身实时审计」：REG 调度契约、意图隐变量 z、灵巧接触模式 c、三层反作用、sim2real 桥接，确立了**三域分离 + 严格逐指令退化 + 运行时监控（RTM）**。但 R72 仍然默认了两件「不动的东西」：
> - **本体不动**：REG 拓扑、运动学模型 θ_kin、触觉标定、接触几何、RTA 余量全部建立在「固定形态 m」之上。可重构机构（模块化关节、变刚度关节、可重构末端/灵巧手、伸缩/折叠连杆、变形机械臂）让**本体本身成为一个可切换的隐变量**。重新构形会**静默地**让上一形态签发的所有证书失效——而 R72 没有任何机制知道「本体已经换了」。
> - **物体清单不动**：R72 的 s 默认「世界里的物件是给定的」。实例分割给出逐物件的掩码与身份 k，但掩码有**边界不确定度**、身份有**切换（ID switch）**、遮挡有**amodal 空缺**、场景有**合并/分裂**。把「实例 k 的证据」错绑到「实例 k′」上，会**污染后验**，而 R72 的追溯链只追到「观测 y」，追不到「y 属于谁」。
>
> 本轮两个灵感正好补两块：
> - **可重构机构**：把形态 m 提升为一等状态，建立**形态证书 J_morph**、**形态条件 REG（M-REG）**、**重构形瞬态黑障**与**形态不确定度 u_m 进风险分母**；重构形不是「换个参数」，是**换一个测量坐标系**。
> - **实例分割**：把实例身份 k 提升为一等隐变量，建立**实例级证据接地**、**边界/遮挡/身份切换/跨实例污染四分量不确定度 u_inst**、**实例证书 J_inst**；触发动作前先问「我看清的是哪一个，而不是哪一类」。
> - **统一形式核心（FGA，Frame Gauge Algebra）**：所有测量与证书都只相对于**坐标帧 f = (m, k)** 有效；帧变（重构形 / 身份重关联）是一次**必须被审计的事件**，需要**帧变证书 J_frame**、**信仰传输 FT**、**不变量校验**与**静默帧漂移检测**。
>
> 核心命题：**从「我的测量链在具身实时下可信吗」再进化为「我的测量链在 **本体可重构、物体身份可切换** 的坐标系里还成立吗？当本体或身份变了，这次坐标系切换本身被审计了吗？」** ——**形态-实例计量审计闭环**（MORPHO-INSTANCE-GAUGE-RAS, MIG-RAS）。

## 0. 直觉与动机

**灵感 1（可重构机构 → 本体是一个隐变量，证书是本体的函数）**
直觉：固定机械臂出厂标定一次，R72 的证书可以「贴上去」。但可重构机构（如模块化机械臂换一个关节、灵巧手换一种手指布局、末端换成吸盘、连杆伸缩改变臂展）意味着：**运动学正解、雅可比、动力学、触觉阵列位置、相机外参、最坏执行时间 WCET 全部随 m 改变**。你以为只是「换了个抓取模式」，实际上是**换了一套测量系统**。R72 的 REG 契约哈希只对某一 m 成立；一旦重构形，控制域仍在用旧哈希的证书，计量域却已换了物理——这就是**静默帧漂移**。**可重构机构的第一性矛盾：自由度越高、任务适应越强，证书的可复用性越差。**

**灵感 2（实例分割 → 身份是隐变量，证据要先接地到「哪一个」）**
直觉：检测框只说「这里有一个杯子」，实例分割还告诉你「这是 3 号杯、那是 4 号杯」，并且给出像素级掩码。但掩码不是免费的真值：**边界有带宽（boundary band）**、**同类多实例会粘连/交换（ID switch）**、**被遮挡部分是 amodal 猜测**、**两个物体可能碰撞合并成一个连通域**。若把 4 号杯的触觉/力证据误绑到 3 号杯的后验上，BSE 会被**跨实例污染（contamination）**：不是「噪声变大」，而是**证据指向了错误的状态变量**。R72 的 u_tac 四分量里没有「你摸错对象」这一项。**实例分割的第一性矛盾：像素越细、身份越具体，错误的代价从「分类错」升级为「作用到错的东西上」。**

**灵感 3（两个灵感的耦合 → 本体改变视角，视角改变分割，分割改变接触对象）**
直觉：可重构机构与实例分割不是两块拼图，而是**闭环耦合**：
- 重构形 m→m′ 改变相机外参/臂展/视角 ⇒ **实例分割的输入分布变**（同一物体在不同视角下边界/遮挡完全不同）；
- 选择接触实例 k ⇒ 决定需要什么末端/刚度/臂展 ⇒ **驱动形态选择 r（重构形）**；
- 重构形瞬态期间不能抓取 ⇒ **身份跟踪可能丢失** ⇒ 重关联风险上升。
所以「选哪个身体」与「认哪个物体」必须**联合决策**，不能先定身体再认物体，也不能先认物体再定身体。**耦合的核心：形态决定可观测性，实例决定作用目标，二者共同定义了一个坐标系 f=(m,k)。**

**灵感 4（帧变审计 → 重构形不是换参数，是换坐标系）**
直觉：连续的小改动（关节零点偏一点、相机外参微调、掩码边缘抖动）可以看作**规范变换（gauge transformation）**：物理不变量（物体尺寸、抓取力、质心）应保持不变，只有表示与不确定度在变换。但**拓扑性改变**（加/减一根手指、两个实例合并/分裂、物体进入/离开视野）**没有可逆微分同胚**，状态空间维度都变了——此时「传输信仰」在数学上是**病态的**，正确做法是**声明黑障并重新接地（re-grounding）**，而不是偷偷沿用旧证书。R72 的连续退化链假设「同一状态空间内降级」；R73 必须区分**连续帧变（可传输）**与**拓扑帧变（必须重初始化）**。

**灵感 5（帧承诺 → 过早绑定坐标系本身就是风险）**
直觉：在任务/意图还没辨清时，过早重构成「精细抓取形态」或过早把某团像素钉成「目标实例」，都会在证据反转时付出高昂的**帧切换成本**（重新标定、重新跟踪、重新规划）。可以像主动感知一样**延迟帧承诺**：先把相机挪一挪（改变 m 的观测子配置）、先轻触一下（实例消歧）、先问一句（意图消歧），等到 `H[b_t(m)]` 与 `H[b_t(k)]` 都低于阈值再承诺。**帧承诺是一个决策，不是初始化步骤。**

**灵感 6（静默帧漂移 → 最危险的不是错，是「拿着旧帧的章盖新帧的账」）**
直觉：R72 的最大风险是「自信地错自己的可执行性」。R73 新增一种更隐蔽的错误：**数值全都对、证书全都有效，但证书是为旧本体/旧实例签发的**。就像用去年的体检报告证明今年的健康。必须在每个快照里携带**帧标签 (m_hash, k_hash, cert_id)**，控制域每次读快照都做**帧一致性比对**；不一致立即降级。**追溯链必须追「在哪个帧下测的」，而不只是「测了什么」。**

## 1. 形式化定义（增量：定义 366–386）

**定义 366（MORPHO-INSTANCE-GAUGE-RAS 总览）** MIG-RAS = (MRL, ISM, FGA, M-REG, MI-RISK, MIG†)。五不变式：
(i) **帧优先**：任何动作/证据/参数必须携带已认证的坐标帧 f=(m,k)，无帧不入控制/计量环；
(ii) **帧变可审计**：重构形 r 与实例重关联 a_k 必须通过帧变证书 J_frame；拓扑帧变必须声明黑障并重接地，禁止「静默传输」；
(iii) **传输可靠**：连续帧变的信仰/参数传输误差 ε_T 有界且可复算；超界即禁用复用；
(iv) **耦合预算**：帧变成本 c_frame（重构形成本 + 传输误差代价 + 重跟踪成本）与交互成本合计 ≤ B_frame_total；
(v) **严格退化链**：形态未认证 ⇒ 锁定上一认证形态 + R72；实例歧义 ⇒ 区域级 + R72；帧漂移 ⇒ 立即 R72/R71；硬件/实时失效 ⇒ R68。**安全侧只增不减。**

**定义 367（可重构机构与形态状态）** 形态 m ∈ ℳ = ℳ_disc × ℳ_cont：离散族（关节数、手指布局、末端类型、连杆构型）× 连续参数（零位、刚度、臂展）。形态转移
p(m_{t+1} | m_t, r_t)，r_t ∈ ℛ 为重构形动作。每个 m 绑定**计量包** B(m) = (θ_kin(m)±u_kin, θ_dyn(m), 接触几何 G_c(m), 触觉标定 τ_tac(m), 相机外参 E_cam(m), REG 拓扑 𝒢(m), WCET(m))。重构形有**成本、时延、以及瞬态失效窗** T_reconf(m→m′)。

**定义 368（形态证书 J_morph）** J_morph(m) = (kin_calib_hash, reg_contract_hash(𝒢(m)), rta_proof(m), tac_calib_hash(m), s2r_hash(m), valid_workspace, expiry)。m **已认证** ⇔ 所有字段有效、未过期、且工作空间约束满足。**认证是逐形态的，不可跨形态复用**（引理 36）。

**定义 369（实例分割证据与身份后验）** 实例集 𝒦_t，掩码 {M_k}，逐像素 logit，边界带 ∂M_k。分割观测 y_seg 服从
p(y_seg | s, m, viewpoint(m))——**注意分割模型以形态为条件**（视角/臂展/相机外参是 m 的函数）。输出 (masks, b_t(k), Σ_∂k, occlusion/amodal 指标, ECE_seg, ID-switch risk ρ_switch)。

**定义 370（实例级证据接地与四分量不确定度）** 接地算子 β: 观测 → 实例 k。证据似然写作 p(y | s_k, c, m, k)。实例不确定度分解：
u_inst² = u_bound² + u_idswitch² + u_occlusion² + u_contam²，
分别对应边界带几何不确定、身份切换风险、遮挡/amodal 空缺、跨实例污染；每项独立追溯链 τ_inst_i。

**定义 371（计量坐标帧 Frame）** 坐标帧 f = (m, k)：本体形态 + 物体实例。一次测量是三元组 (value, uncertainty, frame)。**离开帧谈「值」与「不确定度」都是无意义的**。记 𝒻_t 为当前帧，帧标签 H(f) = (m_hash, k_hash, cert_id)。

**定义 372（连续帧变与信仰传输 FT）** 连续帧变 f→f′ 由可微规范映射 T_{f→f′} 给出（关节零点/外参/刚度等连续参数变化）。信仰传输
b′(s′) = b(T^{-1}s′)·|det J_T^{-1}|，不确定度传输 u′² = J_T Σ_u J_Tᵀ + u_T²。
**物理不变量** I（物体尺寸、质心、抓取力）须满足 ‖I(f) − I(f′)‖ ≤ τ_I；传输误差 ε_T 超阈 τ_T ⇒ **禁止复用，必须重接地**。

**定义 373（拓扑帧变与黑障）** 若 f→f′ 改变状态空间维度或拓扑（增删手指、实例合并/分裂、目标进入/离开视野），则**不存在有界 Jacobian 的 T**。此时系统必须：(a) 进入**声明式黑障** T_blackout；(b) 执行**重接地**（重新初始化 b(k)、重新标定受影响自由度）；(c) 签发新帧证书。**黑障期间控制域只允许安全保持（hold），任何运动指令与证据一律无效。**

**定义 374（帧变证书 J_frame）** J_frame(f→f′) = (T_hash 或 重接地证明, 不变量校验, ε_T 上界, 重标定完成位, 黑障已闭合位, τ_frame)。Valid ⇔ 不变量保持 ∧ ε_T ≤ τ_T ∧ 黑障闭合 ∧ 重标定完成。**拓扑帧变 Valid 的必要条件是「重接地证明」，而不是「传输误差小」。**

**定义 375（静默帧漂移）** 控制域当前使用的帧 f_active 与证据/参数签发时的帧 f_cert 不一致（H(f_active) ≠ H(f_cert)），且未触发显式帧变流程。**静默帧漂移是 R73 的头号安全威胁**：数值合法、证书合法，但账目错位。检测方式：快照携带帧标签 + 控制域逐周期比对 + RTM 记录。

**定义 376（形态条件 REG：M-REG）** 对每个可部署形态 m，维护独立执行图 𝒢(m) 与独立 RTA 证明 rta_proof(m)。部署期验证 ∀m ∈ ℳ_cert：WCET(m) + L_T·u_m ≤ δ_ctrl(m)。运行时当前 m_hash 必须匹配激活证书。**重构形是一次「调度模式切换」**，必须原子化：旧配置 quiesce → 安全保持 → 重构 → 黑障 → 新配置自检 → 激活。

**定义 377（形态不确定度进风险分母）** u_m² = u_kin² + u_T² + u_drift² + u_transient²（运动学标定、帧传输、漂移、瞬态）。λ 分母纳入 u_m：**本体越不确定，动作越软化。**

**定义 378（实例不确定度进风险分母）** λ 分母同时纳入 H[b_t(k)] 与 u_inst。**实例不辨，不动手**：`H[b_t(k)] > τ_Hk` 或 `ρ_switch > τ_switch` 或 `χ(k,k′) > τ_χ` 时，禁止实例级动作，降为区域级/停手。

**定义 380（形态-实例耦合动力学）** 耦合转移：

# IP-295 MRL：形态管理器（部署期认证 + 运行时原子切换）
@dataclass
class MorphologyCert:
    m_hash: bytes; reg_contract_hash: bytes; rta_proof: bytes
    tac_calib_hash: bytes; s2r_hash: bytes
    valid_workspace: Workspace; expiry: float; u_m: float

class MorphologyManager:
    def __init__(self, certs: Dict[bytes, MorphologyCert], reg: dict):
        self.certs, self.reg = certs, reg
    def certified(self, m) -> bool:
        c = self.certs.get(hash_m(m))
        return bool(c) and not expired(c) and workspace_ok(c)
    def atomic_reconfigure(self, m_cur, m_new):
        # 1) 旧配置 quiesce 2) 安全保持 3) 重构 4) 声明黑障
        self._quiesce(m_cur); self._hold()
        self._reconfigure(m_cur, m_new)
        with self.blackout(T_reconf(m_cur, m_new)):   # 期间证据/指令全无效
            self._recalibrate_affected(m_new)          # 受影响自由度重标定
        # 5) 新配置自检 + 帧变证书
        if not self.certified(m_new): return None
        return FrameChangeCert(f_old=(m_cur, None), f_new=(m_new, None),
                               topo=is_topological(m_cur, m_new),
                               regrounded=self._regrounded, tau=hash_calib())

# IP-297 FGA：坐标帧代数与帧变审计
def frame_change(f_old, f_new, b_old, u_old, invariants):
    topo = is_topological(f_old, f_new)        # 状态空间维度/拓扑是否改变
    if topo:
        # 拓扑帧变：禁止传输，声明黑障 + 重接地
        return FrameChangeCert(f_old, f_new, topo=True,
                               regrounded=False, eps_T=float('inf'))
    T, J = gauge_map(f_old, f_new)              # 连续规范映射及其雅可比
    b_new = transport_belief(b_old, T, J)       # b'(s') = b(T^{-1}s')|det J^{-1}|
    u_new = sqrt(J @ u_old @ J.T + u_transform(f_old, f_new)**2)
    inv_ok = all(norm(invariants[i](f_old) - invariants[i](f_new)) <= TAU_I
                 for i in invariants)
    eps_T = bound_transport_error(f_old, f_new, b_old)
    valid = inv_ok and eps_T <= TAU_T and quiesced(f_old)
    return FrameChangeCert(f_old, f_new, topo=False, regrounded=True,
                           eps_T=eps_T, invariant_ok=inv_ok, valid=valid,
                           tau=hash_calib())

# IP-299 MI-RISK：形态 + 实例不确定度同权入分母
def mi_risk_scale(U_ale, U_epi, H_z, u_tac, H_k, u_inst, u_m, params):

# IP-300 MIG-VoI：联合形态-实例决策 + 帧承诺 + 主动消歧
def mig_voi(b_s, z_dist, k_dist, m_dist, tac, budget, fmp):
    best = None
    for (r, g) in joint_candidates(b_s, z_dist, k_dist, m_dist, top_k=3):
        if not budget.allow(r, g): continue
        fcc = frame_change(current_frame(), target_frame(r, g), b_s, u_of(b_s), INVARIANTS)
        if not fcc.valid and not fcc.topo: continue
        if fcc.topo and not fcc.regrounded: continue          # 拓扑帧变必须重接地
        ig_s = credibility()*(entropy(b_s) - E_post_entropy_s(b_s, g, fmp))
        ig_k = ETA_K*(k_dist.entropy() - k_dist_after(g).entropy())
        ig_m = ETA_M*(m_dist.entropy() - m_dist_after(r).entropy())
        cost = c_reconf(r) + c_frame(fcc) + reflex_cost(r, g) \
               + GAMMA*expected_future_loss(b_s, k_dist, m_dist, r, g)
        score = ig_s + ig_k + ig_m - cost
        if best is None or score > best.score: best = (r, g, score)
    # 帧承诺门控：熵太高不承诺，转主动消歧
    if best and (m_dist.entropy() > TAU_HM or k_dist.entropy() > TAU_HK):

    return best if best and best.score > 0 else None

## 3. 推导

**引理 33（连续帧变的传输风险界）** 设 T_{f→f′} 为 C¹ 微分同胚，Jacobian J_T 谱范数有界，且 u_T 为映射自身不确定度。则传输后后验的相对熵满足
D_KL(b′ ‖ b′_true) ≤ L_T·ε_T + ½·tr(J_T Σ_u J_Tᵀ)·κ，
其中 ε_T 为传输误差、L_T 为似然 Lipschitz 常数。**系：连续帧变只有在 ε_T ≤ τ_T 时才允许复用证据；否则证书必须作废。**

**引理 34（静默帧漂移对数值检查不可见）** 若控制/计量仅校验数值范围与置信区间（不含帧标签），则存在一个帧错配执行序列，其所有数值检查通过、所有区间覆盖真值，但物理动作作用在错误本体/错误实例上。证明：构造两帧 f≠f′ 使某一数值 v 在两者下均在合法区间内，但语义不同（如"3 号杯的位置"在交换身份后 v 仍合法）。**系：帧标签与证书绑定是充分必要条件，不能靠「数值看起来对」来兜底。**

**引理 35（实例身份切换导致的后验跳变下界）** 设真实身份 k*，关联后验 b_t(k)。若发生一次未被检出的 ID switch（k*→k′），则至少有一个被作用实例的后验满足
D_KL(b_t(·|k′) ‖ b_t^true(·)) ≥ Δ_min > 0，
其中 Δ_min 由两实例的物理可分性（马氏距离）下界决定。**系：单掩码证据无法定案；必须跨模态（深度/触觉/力）一致性校验，否则污染无下界。**

**引理 36（形态证书不可跨形态复用）** 若 m ≠ m′ 且 B(m) ≠ B(m′)（运动学/标定/REG 任一不同），则 J_morph(m) 对 m′ 无效；存在一个动作在 m 下安全、在 m′ 下越界。证明：由 θ_kin(m)≠θ_kin(m′) 直接构造同一关节指令导致不同末端位姿，越过工作空间/碰撞边界。**系：重构形必须重新签发证书，R72 的「一次认证、长期使用」在可重构本体上不成立。**

**引理 37（拓扑帧变不可传输）** 若 f→f′ 改变状态空间维度 dim(𝒮)（增删手指、实例合并/分裂），则不存在满秩有界 Jacobian 的微分同胚 T；任何"信仰传输"要么维度不匹配，要么误差无界。**系：拓扑帧变的唯一正确语义是「声明黑障 + 重接地」，传输是伪解。**

**定理 27（MIG 严格包含与风险单调）** 在 A111–A116（M-REG 全形态 RTA 通过、帧传输有界、实例校准有效、耦合 Lipschitz、黑障原子性、FDM 可靠）下：MIG 在退化条件下逐指令等于 EMBODIED/R71/R68（定义 385）；且对任意有效执行，风险界 ≤ R72 风险界。**安全单调不减；效率增益只在「形态已认证、实例已辨明、帧变已审计」时取得。**

**定理 28（J_MIG 有效性 ⇒ 帧相对物理安全）** 若一次执行通过 J_MIG，则：(i) J_morph/J_frame 与当前帧一致 ⇒ 无静默帧漂移；(ii) MI-IVG 全过 ⇒ 形态/实例不确定度在有效域；(iii) 拓扑帧变已重接地 ⇒ 黑障闭合；(iv) J_EMB 有效 ⇒ 具身认知风险界成立。综上，**物理执行风险 ≤ ε_mig（相对于认证帧 f）**。**证明重量落在「帧标签未被伪造」与「重接地真实完成」上。**

**定理 29（原子重构形无半态）** 若重构形严格按 quiesce→hold→reconfigure→blackout→recalibrate→verify→activate 执行，且 FDM 检测黑障期间运动指令，则不存在「旧证书 + 新物理」共存的半态；任意时刻至多一个形态处于激活态。**系：可重构机构的安全性依赖切换协议的原子性，而非控制律本身。**

## 6. 本轮最大风险

**一句话**：MIG-RAS 把安全从「相信具身证书」再次转移到「相信**每一帧 (m,k) 的证书都真实对应当前物理、相信帧标签未被伪造、相信拓扑帧变的重接地真的完成了**」——而最深的裂缝在于：**拓扑帧变（加/减一根手指、实例合并/分裂、目标进出视野）根本不是规范变换，状态空间维度都变了，任何"信仰传输"都是伪解；若系统为了保持活性而偷偷把拓扑帧变当成连续帧变处理，或在黑障未闭合时就提前复用旧证书，它就会拿着一套"帧哈希匹配、MI-IVG 全过、证书盖章"的执行，在重构形瞬态里用了旧运动学去驱动新本体、把 A 物体的触觉绑到 B 物体、并用旧视角的掩码去抓已经移位的目标，事后审计发现"每一帧的账都对，只是账本被换过"——这正是坐标帧层面的「自信地错自己的可执行性」。**

次级风险与缓解：
1. **拓扑帧变被误当连续传输** → **帧变分类器强制二分**（维度/连通性/实例基数变化 ⇒ 拓扑），拓扑分支只允许「黑障 + 重接地」；FDM 校验黑障闭合位。
2. **频繁重构形导致活性崩溃** → **形态组合缓存 + 认证形态上限 |ℳ_cert|≤12**；常用切换路径预认证；非认证形态一律锁定回退。
3. **实例分割在遮挡/同类混淆下高置信错误** → **跨模态一致性（深度/触觉/力/运动视差）+ 单源掩码不定案 + SEAL-Seg 密封审计集**。
4. **帧标签伪造 / 传输映射投毒** → **帧标签纳入 TCHAIN 哈希链**，帧变证书由 FDM 独立复算；伪造即断链降级。
5. **M-REG 组合爆炸** → 只对**可达形态图**做 RTA（非全 ℳ×𝒦 笛卡尔积）；惰性认证 + 依赖缓存；复杂度本身入审计指标。
6. **重接地期间跟踪丢失** → 黑障前保存实例指纹（几何/外观/触觉签名），重接地后用**多模态重识别**恢复 k，恢复失败则区域级。
7. **证书生成吃实时预算** → 控制域只写最小帧标签片段，完整 J_MIG 由计量域异步组装；拓扑帧变证书允许在安全保持期内生成。

> - **MRL**：形态 m 一等化，逐形态计量包 B(m) 与证书 J_morph，原子重构形协议与声明式黑障；
> - **ISM**：实例级证据接地，四分量 u_inst = √(u_bound²+u_idswitch²+u_occlusion²+u_contam²)，身份后验 b_t(k) 与 ID-switch 风险；
> - **FGA**：统一坐标帧 f=(m,k)，连续帧变的可微传输与拓扑帧变的重接地二分，帧变证书 J_frame；
> - **M-REG**：形态条件调度契约（逐 m RTA），重构形 = 调度模式原子切换；
> - **MI-RISK**：H[b(k)]、u_inst、u_m 与物理/意图/接触不确定度**同权入风险分母**；
> - **MIG-VoI**：联合 (重构形 r, 交互 g) 决策 + 帧承诺门控 + 主动消歧；
> - **FDM**：帧漂移监控器，检测静默帧漂移与半态，是 R73 的信任锚点。
>
> 核心命题：**从「测量链在具身实时下可信吗」进化为「测量链在 **本体可重构、身份可切换** 的坐标系里还成立吗？坐标帧切换本身被审计了吗？」**
>
> IP 编号：IP-295~302（共 8 个）+ R72 组件的 † 化。理论姿态延续：**新层是旧层的严格泛化，安全侧只增不减，退化链逐指令等价，拓扑帧变必须显式声明而非静默传输。**

# IP-295 MRL：形态管理器（部署期认证 + 运行时原子切换）
@dataclass
class MorphologyCert:
    m_hash: bytes; reg_contract_hash: bytes; rta_proof: bytes
    tac_calib_hash: bytes; s2r_hash: bytes
    valid_workspace: Workspace; expiry: float; u_m: float

class MorphologyManager:
    def __init__(self, certs, reg):
        self.certs, self.reg = certs, reg
    def certified(self, m) -> bool:
        c = self.certs.get(hash_m(m))
        return bool(c) and not expired(c) and workspace_ok(c)
    def atomic_reconfigure(self, m_cur, m_new):
        self._quiesce(m_cur); self._hold()                    # 1) 2)
        self._reconfigure(m_cur, m_new)                       # 3)
        topo = is_topological(m_cur, m_new)
        with self.blackout(T_reconf(m_cur, m_new)):           # 4) 声明黑障
            self._recalibrate_affected(m_new)                 #    受影响自由度重标定
        if not self.certified(m_new): return None             # 5) 自检
        return FrameChangeCert(f_old=(m_cur,None), f_new=(m_new,None),
                               topo=topo, regrounded=self._regrounded,
                               tau=hash_calib())

# IP-296 ISM：实例分割计量（边界/身份/遮挡/污染）
class InstanceSegMetrology:
    def __init__(self, seg_net, assoc_hmm, calib):
        self.seg, self.assoc, self.calib = seg_net, assoc_hmm, calib
    def update(self, image, view_cfg, k_prev, psi_hat):
        masks, logits = self.seg(image, view_cfg)            # view_cfg = f(m)
        k_post, rho = self.assoc.step(masks, k_prev)         # b_t(k), ρ_switch
        u_bound = self.calib.boundary_band(logits)           # 边界带
        u_occl  = self.calib.occlusion_amodal(masks)         # 遮挡/amodal
        chi     = self.calib.contamination(masks)            # χ(k,k')
        u_idsw  = self.calib.idswitch_latency(k_post, rho)   # ID-switch 延迟
        u_inst  = sqrt(u_bound**2 + u_idsw**2 + u_occl**2 + chi**2)
        return InstanceEvidence(masks=masks, b_k=k_post, rho=rho,
                                u_inst=u_inst,
                                u_breakdown=(u_bound,u_idsw,u_occl,chi),
                                ece=self.calib.ece_seg, tau=self.calib.tchain)

# IP-297 FGA：坐标帧代数与帧变审计
def frame_change(f_old, f_new, b_old, u_old, invariants):
    if is_topological(f_old, f_new):                         # 维度/拓扑改变
        return FrameChangeCert(f_old, f_new, topo=True,
                               regrounded=False, eps_T=float('inf'))
    T, J = gauge_map(f_old, f_new)                           # 连续规范映射
    b_new = transport_belief(b_old, T, J)
    u_new = sqrt(J @ u_old @ J.T + u_transform(f_old, f_new)**2)
    inv_ok = all(norm(invariants[i](f_old) - invariants[i](f_new)) <= TAU_I
                 for i in invariants)
    eps_T = bound_transport_error(f_old, f_new, b_old)
    valid = inv_ok and eps_T <= TAU_T and quiesced(f_old)
    return FrameChangeCert(f_old, f_new, topo=False, regrounded=True,
                           eps_T=eps_T, invariant_ok=inv_ok, valid=valid,
                           tau=hash_calib())

# IP-298 M-REG：形态条件实时执行图
class MorphoREG:
    def verify_all(self, m_set, L_T):
        return all(rta.verify(self.reg[m]) and
                   wcet(m) + L_T*u_m(m) <= delta_ctrl(m) for m in m_set)
    def switch(self, m_cur, m_new):
        if not self.verify_runtime(m_new): return None
        return self.morph_manager.atomic_reconfigure(m_cur, m_new)

# IP-299 MI-RISK：形态 + 实例不确定度同权入分母
def mi_risk_scale(U_ale, U_epi, H_z, u_tac, H_k, u_inst, u_m, params):
    denom = U_ale + U_epi + H_z + u_tac + H_k + u_inst + u_m
    lam = params.lam_base * (1 + denom / params.lam_scale)
    return max(lam, params.lam_floor * (1 + denom))

# IP-300 MIG-VoI：联合形态-实例决策 + 帧承诺 + 主动消歧
def mig_voi(b_s, z_dist, k_dist, m_dist, tac, budget, fmp):
    best = None
    for (r, g) in joint_candidates(b_s, z_dist, k_dist, m_dist, top_k=3):
        if not budget.allow(r, g): continue
        fcc = frame_change(current_frame(), target_frame(r, g), b_s, u_of(b_s), INVARIANTS)
        if fcc.topo and not fcc.regrounded: continue        # 拓扑帧变必须重接地
        if not fcc.topo and not fcc.valid: continue
        ig_s = credibility()*(entropy(b_s) - E_post_entropy_s(b_s, g, fmp))
        ig_k = ETA_K*(k_dist.entropy() - k_dist_after(g).entropy())
        ig_m = ETA_M*(m_dist.entropy() - m_dist_after(r).entropy())
        score = ig_s + ig_k + ig_m \
                - c_reconf(r) - c_frame(fcc) - reflex_cost(r, g) \
                - GAMMA*expected_future_loss(b_s, k_dist, m_dist, r, g)
        if best is None or score > best.score: best = (r, g, score)
    if best and (m_dist.entropy() > TAU_HM or k_dist.entropy() > TAU_HK):
        return ('active_disambiguate', best)                # 帧承诺门控
    return best if best and best.score > 0 else None

# IP-301 FDM：帧漂移监控器（最高优先级，零依赖，形式化验证）
def fdm_step(snapshot, cert_registry, mode):
    if hash_frame(snapshot.frame) != hash_frame(cert_registry.active_frame()):
        return FUSE('silent_frame_drift', downgrade='R72')
    if mode == 'RECONFIG' and snapshot.ctrl_cmd is not None:
        return FUSE('half_state_motion', downgrade='R68')
    if cert_registry.expired():
        return FUSE('cert_expired', downgrade='R71')
    return OK

    if M.clock.due_metric():

## 4. 推导

**引理 33（连续帧变的传输风险界）** T 为 C¹ 微分同胚、J_T 谱范数有界、u_T 为映射不确定度，则 D_KL(b′‖b′_true) ≤ L_T·ε_T + ½·tr(J_TΣ_uJ_Tᵀ)·κ。**系：连续帧变仅当 ε_T≤τ_T 才允许复用证据。**

**引理 34（静默帧漂移对数值检查不可见）** 仅校验数值范围/置信区间（不含帧标签）时，存在帧错配执行序列使所有数值检查通过、所有区间覆盖真值，但动作作用在错误本体/错误实例上。**系：帧标签与证书绑定是充要条件，不能靠「数值看起来对」兜底。**

**引理 35（ID switch 导致的后验跳变下界）** 未被检出的身份切换 k*→k′ 至少使一个被作用实例满足 D_KL ≥ Δ_min>0（由两实例物理可分性/马氏距离下界决定）。**系：单掩码证据无法定案，须跨模态一致性。**

**引理 36（形态证书不可跨形态复用）** m≠m′ 且 B(m)≠B(m′) ⇒ J_morph(m) 对 m′ 无效；存在动作在 m 下安全、在 m′ 下越界。证明：θ_kin(m)≠θ_kin(m′) ⇒ 同一关节指令末端位姿不同，越过工作空间/碰撞边界。**系：「一次认证、长期使用」在可重构本体上不成立。**

**引理 37（拓扑帧变不可传输）** 若 dim(𝒮) 改变（增删手指、实例合并/分裂），不存在满秩有界 Jacobian 的微分同胚 T；任何"传输"维度不匹配或误差无界。**系：拓扑帧变的唯一正确语义是「声明黑障 + 重接地」。**

**定理 27（MIG 严格包含与风险单调）** 在 A111–A116（M-REG 全形态 RTA、帧传输有界、实例校准有效、耦合 Lipschitz、黑障原子性、FDM 可靠）下：MIG 在退化条件下逐指令等于 EMBODIED/R71/R68；任意有效执行风险界 ≤ R72。**安全单调不减；效率增益仅在帧可信时取得。**

**定理 28（J_MIG ⇒ 帧相对物理安全）** 通过 J_MIG ⇒ (i) 无静默帧漂移；(ii) 形态/实例不确定度在有效域；(iii) 拓扑帧变已重接地、黑障闭合；(iv) 具身认知风险界成立。**物理风险 ≤ ε_mig（相对认证帧 f）。证明重量落在「帧标签未伪造」与「重接地真实完成」。**

**定理 29（原子重构形无半态）** 按 quiesce→hold→reconfigure→blackout→recalibrate→verify→activate 执行且 FDM 检测黑障期运动 ⇒ 不存在「旧证书+新物理」半态；任意时刻至多一个激活形态。**系：可重构安全性依赖切换协议原子性，而非控制律本身。**

## 7. 本轮最大风险

**一句话**：MIG-RAS 把安全再次转移到「**每一帧 (m,k) 的证书都真实对应当前物理、帧标签未被伪造、拓扑帧变的重接地真的完成**」——而最深裂缝是：**拓扑帧变（加/减一根手指、实例合并/分裂、目标进出视野）根本不是规范变换，状态空间维度都变了，任何"信仰传输"都是伪解；若系统为保活性而把拓扑帧变偷偷当连续帧变处理，或在黑障未闭合时就提前复用旧证书，它就会拿着"帧哈希匹配、MI-IVG 全过、证书盖章"的执行，在重构形瞬态里用旧运动学驱动新本体、把 A 物体触觉绑到 B 物体、用旧视角掩码抓已移位目标，事后审计发现"每帧的账都对，只是账本被换过"——这正是坐标帧层面的「自信地错自己的可执行性」。**

次级风险与缓解：
1. **拓扑帧变被误当连续传输** → 帧变分类器强制二分（维度/连通性/实例基数变化⇒拓扑）；拓扑分支只允许黑障+重接地；FDM 校验黑障闭合位。
2. **频繁重构形致活性崩溃** → 形态组合缓存 + 认证形态上限 |ℳ_cert|≤12；常用切换路径预认证；非认证形态一律锁定回退。
3. **遮挡/同类混淆下高置信错误** → 跨模态一致性（深度/触觉/力/运动视差）+ 单源掩码不定案 + SEAL-Seg 密封审计集。
4. **帧标签伪造/传输映射投毒** → 帧标签纳入 TCHAIN 哈希链，帧变证书由 FDM 独立复算；伪造即断链降级。
5. **M-REG 组合爆炸** → 只对可达形态图（非 ℳ×𝒦 笛卡尔积）做 RTA；惰性认证 + 依赖缓存；复杂度入审计指标。
6. **重接地期间跟踪丢失** → 黑障前保存实例指纹（几何/外观/触觉签名），重接地后多模态重识别；失败则区域级。
7. **证书生成吃实时预算** → 控制域只写最小帧标签片段，完整 J_MIG 由计量域异步组装；拓扑帧变证书允许在安全保持期内生成。
