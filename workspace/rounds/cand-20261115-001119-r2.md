# 第 3 轮（灵感循环；本轮灵感：「演示方案」×「评测指标」；承接 ToolGauge 基线）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E439）。
> 本轮纪律：**只加一层，不改内核**——ToolGauge 的 6C 闭环、MTC/TCV、AP-Cal、P-Quarantine、语言审计层与
> MODGAUGE 五不变式全部保留；本轮把「我们如何证明它有效」从论文末尾的实验表格，提升为与修复内核同等严格的
> **可重放、可预注册、可证伪、可撤回**的一等对象。
>
> **基线审计先行**：第 2 轮产物头部声称实验增量 E426–E440，但正文只定义到 E439（E440 空洞）；且 E426–E439
> 全部是**自设阈值 + 点估计 + 自设场景**，没有置信区间、没有负对照、没有预注册、没有多重比较校正。
> 本轮不追认空洞编号，新增实验从 **E441** 起；新增定义 **432–443**、引理 **51–57**、IP **321–326**。

## 0. 直觉：研究里最危险的不是系统坏了，而是它「看起来被证明了」

**直觉 1（演示方案 → 演示不是视频，是可重放的证据链）**
ToolGauge 已经会产出 `RepairCert(s)`：假设集、探测程序、回执、文字解说。但它回答的是「我修了什么」，
没有回答四个审计问题：**在什么配置下修的？换一个人重放会不会得到同样结果？到底改了哪些格子、没改哪些格子？
如果当时不修（反事实）会怎样？** 一个无法重放的证书，和一段剪辑过的演示视频没有本质区别。
工具调用的工程智慧再次适用：把每次修复编译成**带哈希、带种子、带反事实分支、带未触碰子图 diff 的见证束**，
演示 = 任何人都能一键重放并验证哈希的证据，而不是「请相信我们跑过」。

**直觉 2（评测指标 → 指标不是数字，是有适用域的测量仪器）**
计量学的基本常识是：**没有校准的读数不是测量，只是电压**。第 2 轮的指标恰恰是未校准的读数——
「覆盖率 ≥ 0.9」「注入成功率 < 5%」「增益 ≥ 2×」都是点估计，没有估计量定义、没有抽样设计、没有不确定性、
没有最小可检测效应（MDE），也没有说明在什么分布外无效。更糟的是，这些指标由提出系统的人定义、实现、挑选。
因此本轮给每个指标配一份**指标契约 MC**：估计量（estimand）、估计器、抽样单位、不确定性方法、适用域、
负对照、所需样本量、Goodhart 压力测试、负责人。**指标必须先通过「能区分真修复与假修复」的判别效度检验，
才有资格被当作证据。**

**直觉 3（负对照与演示覆盖 → 没有负对照，只能说「事情发生了」，不能说「是它导致的」）**
第 2 轮有消融（E439），但没有**零假设对照**（stub：什么都不修，只把格子标成已修复）、**安慰剂对照**
（修错格子）、**篡改对照**（重放时改一条回执）。没有这些，任何「提升」都可能来自评测场景本身。
同时，演示集和部署集一样会有盲区：只演示理想光照、只演示小偏差、只演示不会失败的材质，
就能得到一份漂亮的总体指标。本轮复用 D-Box 的位图思想，给演示本身建一张**演示覆盖矩阵**，
并强制声明 `B_demo`（未演示区域）——**主张的作用域只能落在已演示且达到统计功效的格子上**。

**直觉 4（评估必须只读且预注册 → 否则系统会学会「通过考试」）**
一旦指标反馈回修复策略（调参、选工具、改假设），系统优化的就是指标而不是世界；这叫评估诱导过拟合，
其极端形态是 Goodhart：指标变好、真实目标不变甚至变坏。本轮引入**评估隔离不变式**（只读插桩、异步、
控制路径零写入）与**预注册锁箱**（先冻结端点、α、停止规则、分析代码哈希，再看测试集），
并把「指标被 gaming」做成可测量的元指标，而不是一句免责声明。

**一句话主张**：在 ToolGauge 之上加一个**只读的演示-评估层 AuditGauge**，其纪律是
「**无见证不主张、无契约不指标、无负对照不演示、无覆盖声明不外推、无预注册不判定、失效即撤回**」；
AuditGauge 不产生任何物理动作、不改变任何数值行为，只决定「哪些主张有资格被写进论文/证书」。

## 2. 形式化定义（增量：定义 432–443）

**定义 432（演示单元与可重放记录）** 一次演示单元
`D = (eid, seed, config_digest, weights_digest, env_digest, scenario, injection_log, input_trace,
receipt_stream, rng_states, clock_trace, decisions, R_before, R_after, subgraph_diff, regression_log)`。
`replay(D, mode) → {PASS, FAIL}`，`mode ∈ {exact, noop, perturb, tamper}`：
- `exact`：同种子、同配置重放，数值输出按声明容差 `≈_ε` 一致；确定性路径要求哈希逐位相等；
- `noop`：同输入但禁用修复（反事实「不修」）；
- `perturb`：仅扰动盲区 `s` 的单个输入/单个回执，检验因果归因与局部性；
- `tamper`：篡改一条回执/一个时间戳，**必须 FAIL**。
演示的基本单位不是一段视频，而是一个 `D`；所有对外主张必须能指向某个 `D`。

**定义 433（见证与主张账本）** 见证 `W = (D, C, β, V)`：`C` 为本次演示涉及的主张集合，
`β: C → 2^D` 为绑定，`V` 为验证结果（回执签名、seq、regression、diff）。
主张账本 `CL = (C, ≺, witness, deps, status)` 是一张 DAG：
`supported(c) ⇔ witness(c) ≠ ∅ ∧ replay(witness(c)) = PASS ∧ ∀c' ∈ deps(c): supported(c')`。
`status(c) ∈ {supported, exploratory, undemonstrated, retracted}`。
**语言主张绑定（定义 423）是 `CL` 的投影**：无见证或引用无效回执的主张，在序列化时剥离；剥离为纯投影，不改变数值行为。

**定义 434（指标契约 MC）** `m = (θ, θ̂, U, Σ_design, Dom, N_req, N_ctrl, δ_MDE, Gamers, owner, ver)`：
- `θ`：估计量（operational definition：总体、单位、时间窗、分层方式），必须可直接计算；
- `θ̂`：估计器及其实现哈希；`U`：不确定性方法（配对 bootstrap / Clopper–Pearson / 置信序列）；
- `Σ_design`：抽样设计（分层、每层样本量、随机化种子）；
- `Dom`：**适用域**（超出 `Dom` 的结论一律标记为外推，不得当作证据）；
- `N_req`：由功效/MDE 反推的样本量（引理 54）；`N_ctrl`：负对照集合（定义 435）；
- `Gamers`：允许的「指标 gamer」策略族（Goodhart 压力测试，定义 439）。
**无契约的指标不得进入实验表**；契约版本与代码哈希一起冻结（定义 437）。

**定义 435（负对照族与判别效度）** `N_ctrl = {N0, N1, N2, N3, N4}`：
`N0` stub（不修，只把格子标记为已修复）、`N1` oracle（特权真值，给出上界与 headroom）、
`N2` leave-one-module 消融、`N3` 篡改重放、`N4` placebo（修错格子/修非问题格子）。
指标 `m` 在效应 `δ` 上具有**判别效度**，当且仅当在 `N_req` 个演示单元上，
「真实系统 vs N0」与「真实系统 vs N4」的预注册检验在水平 `α` 下拒绝，且功效 `≥ 1−β`。
**不能区分真实修复与 N0/N4 的指标是无效证据**，必须在实验表中标注为 `non-discriminative`。

**定义 436（演示覆盖矩阵 DC 与演示盲区 B_demo）** 分层 `S = (材质 × |u| 分位 × 噪声 × 干扰类型 × 注入类型)`；
`DC[s] = (n_s, k_s, U_s^{1−δ})`，其中 `U_s` 为该层失败率的单侧置信上界（引理 53）。
`B_demo = {s : n_s < N_req(s)}` 为**演示盲区**。任何主张的作用域必须 `⊆ S \ B_demo`；
`B_demo ≠ ∅` 时必须在证书与论文中显式声明，禁止用总体均值掩盖 worst-cell。
**这是把 D-Box 的位图覆盖思想（定义 398/399）反过来作用于演示本身：演示也有盲区。**

**定义 437（预注册锁箱与盲测）** `PreReg = (Hypotheses, Endpoints, α, β, δ_MDE, StopRule,
AnalysisCodeHash, SplitSeeds, ControlSet)` 在接触测试集前冻结并哈希上链；
测试集 `H_test` 在最终评估前不可见；任何偏离预注册的分析必须记录为 **exploratory** 并降低主张等级
（`supported → exploratory`）。评估采用策略匿名编码（A/B 盲评），评估者不知道哪份日志来自真实系统。

**定义 438（序贯有效推断 CS）** 置信序列 `(CS_n)` 满足 `P(∀n ≥ 1: θ ∈ CS_n) ≥ 1−δ`。
演示允许「边跑边看」与提前停止，但此时**禁止**使用固定样本量 CI 作为证据；必须报告 CS。
第 2 轮的「≥95% 运行中成立」式判据被替换为「在预注册停止规则下，真实参数始终落在 CS 内」。

**定义 439（Goodhart 间隙与指标有效性）** 对指标 `m` 与真实目标 `J`（如 held-out RMSE / 事故率）：
`G(m) = sup_{g ∈ Gamers} [ m(g) − J(g) ]₊`（归一化后）。
`m` 有效当且仅当 `G(m) ≤ G_max` 且在**独立 holdout** 上 `J` 的改善与 `m` 同向。
**只报告代理指标 `m`、不报告 holdout 上的 `J` 的实验视为无效**；禁止把多个指标压成一个可被优化的综合分，
安全性作为**约束**（lexicographic）而非加权项。

**定义 440（评估隔离）** 审计层满足：(i) 对控制状态只读；(ii) 50Hz 路径零阻塞（异步缓冲）；
(iii) 物理域零特权——演示运行若发生在真实机器人上，必须走与常规运行相同的 TCV/PROBING（定义 418/430），
**演示模式不得绕过任何安全闸门**；(iv) 评估期间指标不得反馈进修复策略（调参只能发生在独立训练 split）。

**定义 441（撤回协议与真值维护）** `retract(c)`：将 `c` 置为 `retracted`，沿 `CL` 的依赖边传播到所有后代；
若 `c` 对应一次已热替换的修复，则从回滚缓冲 `RB(s)` 恢复替换前的 `EC`（若物理上不可逆，则强制标记
`RED + 人工复核 + 重新排队`）。系统进入显式 `CLAIM-RETRACTED(s)` 状态。
**撤回是传播性的、可终止的、不可静默的**：不允许「实验失败但论文保留结论」。

**定义 442（演示预算契约 DB-Contract）** `DB = (E_units, E_human_hours, T_demo, B_repro, ReleaseCriteria)`：
演示单元数、人工审计工时、现场演示时长、复现包预算、发布门槛。
`DB` 是 `TB-Contract`（定义 424）的评估侧对偶：**修复有预算，证明修复也有预算**；
超预算不是「再跑一个实验」，而是触发 `undemonstrated` 降级。

**定义 443（继承与退化链）** 未重定义的 398–431 全部沿用。`AuditGauge` 失效 ⇒ 不阻塞 `ToolGauge`，
主张降级；`ToolGauge` 失效 ⇒ `LeanGauge`；`LeanGauge` 失效 ⇒ `MODGAUGE`。
令 `VLA=∅、T₀={被动观测}、MP-Φ=物理先验、Audit=∅` ⇒ `AuditGauge ≡ ToolGauge ≡ LeanGauge`。

## 3. 关键算法骨架

```python
# IP-321 W-Box：见证编译器（只读包装 6C，不改变控制流）
@dataclass
class Witness:
    eid: str; seed: int; digests: dict
    trace: list; receipts: list; decisions: list
    R_before: dict; R_after: dict; subgraph_diff: dict
    claims: list; regressions: list; hashes: dict

def witness_compile(repair_fn, s, env):
    D = Recorder(eid=uid(), seed=env.seed, digests=env.digests())
    with D.readonly():                       # 定义 440：零写入、零阻塞
        ok = repair_fn(s)                    # 原 6C 闭环，行为不变
        D.snapshot(R_before, R_after, subgraph_diff=diff_ec(...))
    return Witness(**D.finish(), claims=bind_claims_to_receipts(D), hashes=hash_all(D))

# IP-322 Replay 引擎：exact / noop / perturb / tamper
def replay(W, mode):
    if mode == "tamper":  return not verify_hashes(W)          # 必须 FAIL
    if mode == "noop":    return run_counterfactual(W, repair=False)
    if mode == "perturb": return run_counterfactual(W, perturb=W.blind_spot)
    return verify_hashes(W) and run_trace(W).diff(W) <= EPS     # exact

# IP-323 M-Box：指标契约校验器（指标也要「校准」）
class MetricContract:
    def validate(self, m, data, controls):
        assert m.theta.operational and m.estimator_hash == code_hash(m)
        est, ci = m.estimate(data)                       # bootstrap / CP / CS
        assert m.N >= m.N_req, "underpowered"            # 引理 54
        assert separates(est, data, controls.N0, m)      # 判别效度
        assert separates(est, data, controls.N4, m)
        assert m.goodhart_gap(data, m.Gamers) <= G_MAX   # 定义 439
        return Claim(m, est, ci, scope=m.Dom & demonstrated_scope)

# IP-324 演示覆盖规划：样本量由统计保证反推，而不是拍脑袋
def plan_demo(S, eps, delta):
    N = ceil(log(delta / len(S)) / log(1 - eps))         # 引理 53（零失败情形）
    return {s: N for s in S}, B_demo={s: N if ... }      # 声明盲区

# IP-325 主张账本 + 撤回
class ClaimLedger:
    def support(self, c):
        return c.witness and replay(c.witness, "exact") and all(self.support(d) for d in c.deps)
    def retract(self, c):                               # 定义 441
        for d in self.descendants(c):
            d.status = "retracted"
            if d.rollback_available: restore(d.rollback_buffer)
            else: enter_state(d.cell, "RED + MANUAL")

# IP-326 DP-1 演示协议（冻结→单元→分层→现场→发布）
def DP1(system, prereg, budget):
    lock(prereg); lockbox = split_holdout(system.data)   # 定义 437
    units   = [witness_compile(system.repair, s, system.env) for s in system.blind_spots]
    assert all(replay(w, "exact") for w in units)
    assert all(replay(w, "tamper") is False for w in units)   # 定义 435.N3
    stratified = run_stratified(system, plan_demo(...), controls={N0, N1, N2, N4})
    live       = run_live(system, adversarial_operator=True, kill_switch=True)
    claims     = ClaimLedger().build(units, stratified, live)
    claims.check_scope(S_covered=DC, B_demo=prereg.B_demo)    # 定义 436
    assert claims.verify_all() and reproduction_package.check()
    return release_report(claims, coverage=DC, blind_spots=B_demo)
```

## 4. 推导

**引理 51（评估隔离 / 非侵入）** 若审计层对控制状态只读、对 50Hz 路径仅异步写缓冲、且不参与任何控制决策，
则加入 `AuditGauge` 后：(a) 全部数值输出与 `ToolGauge` 逐位相同（在确定性路径）或落在声明容差内；
(b) 引理 44/49/50 的等价性、硬实时与预算结论不变；(c) 50Hz 周期新增开销仅为一次 O(1) 的入队（实测 < 0.05ms）。
证明思路：控制状态的可达集不因只读观察而改变；异步缓冲不阻塞控制线程；评估失败只影响主张状态。
**这是「演示不改变被演示系统」的形式化，也是所有后续统计结论的前提。**

**引理 52（见证-主张相对健全性）** 若 `CL` 中某主张 `c` 满足 `supported(c)`，则 `c` 的数值内容在
`(config_digest, weights_digest, env_digest, seed)` 声明的配置下可被独立重放复现；
若 `replay(witness(c), exact) = FAIL`，则 `c` 必须被撤回。健全性是**相对于见证束**的，不是绝对真理——
它保证「可复现」，不保证「结论正确」；结论正确性由 `J`（held-out 真实目标）与适用域 `Dom` 承担。

**引理 53（分层演示覆盖的统计保证）** 对第 `s` 层，失败数 `k_s`、样本量 `n_s`，
Clopper–Pearson 单侧上界 `U_s(k_s,n_s)` 满足 `P(θ_s ≤ U_s) ≥ 1−δ`。
要 certification `θ_s ≤ ε` 且观测到 0 次失败，需 `n_s ≥ ln δ / ln(1−ε)`；
对 `S` 层做 worst-cell 保证，取 `δ/S`（Bonferroni）。数值：`ε=0.05, δ=0.05 ⇒ n≥59`；`ε=0.10 ⇒ n≥29`。
**推论 53.1**：演示单元数不是「跑够 30 个」，而是由目标失败率与置信水平**反推**；未达 `N_req` 的层自动进入 `B_demo`。

**引理 54（指标功效与最小可检测效应）** 对预注册的配对检验，
`N_req ≥ 2(z_{1−α}+z_{1−β})² σ² / δ²`，等价地 `δ_MDE = (z_{1−α}+z_{1−β}) σ sqrt(2/N)`。
若观测效应 `< δ_MDE`，只能报告「未检测到差异」，不得报告「无效」或「有效」；
**功效不足的指标不是证据，是噪音**。这条直接否定第 2 轮「≥0.9 / <5%」式点估计判据。

**引理 55（选择偏差与 Goodhart 上界）** 设从 `K` 个候选中按评估集选择最优，评估噪声标准差 `σ_e`，
则选择后代理值相对独立 holdout 的期望膨胀 `E[Δ] ≤ σ_e sqrt(2 ln K)`；
更一般地，对指标类 `ℳ`，`P(sup_{m∈ℳ}|m−J| > t) ≤ 2|ℳ| exp(−2N t²/σ²)`。
因此：(a) **任何「我们试了 K 个版本选最好」都必须报告 K 与独立 holdout**；
(b) Goodhart 间隙 `G(m)` 若超过 `G_max`，该指标不得作为主证据（定义 439）。
**推论 55.1**：演示集一旦被反复用于选型，它的「提升」会按 `sqrt(log K / N)` 膨胀；
预注册锁箱是唯一不靠自觉的解法。

**引理 56（序贯有效性）** 若使用满足 `P(∀n: θ∈CS_n) ≥ 1−δ` 的置信序列，
则「边看边停」不膨胀第一类错误；固定样本量 CI 在随机停止下不成立。
**推论 56.1**：现场演示允许随时停，但必须同时报告 CS 与停止时刻；不得用「跑到显著为止」的固定 `n` CI。
代价是 CS 更宽（Hoeffding 型约宽 `sqrt(log log n / n)`），应用 betting/empirical-Bernstein CS 收紧。

**引理 57（撤回传播的健全性与终止性）** 设 `CL` 为有限 DAG。`retract(c)` 沿后代闭包传播，
终止于 `O(|V|+|E|)`；传播后不存在「`supported` 且依赖已撤回见证」的主张（对拓扑序归纳）。
若存在回滚缓冲 `RB`，则对应子图恢复为替换前 `EC`；否则进入 `RED + 人工`，不会出现「已撤回但仍生效」的静默状态。

5. **重放不可复现（非确定性硬件）** → 记录 RNG/时钟/驱动哈希，声明容差 `ε`，区分「确定性路径」与「统计路径」；

7. **过拟合审计本身（meta-Goodhart）** → 审计代码与指标实现也纳入预注册哈希与外部复现（E451/E455）。

## 2. 形式化定义（要点）

**定义 432（演示单元 D）** `D` 必须足以离线重放：配置/权重/环境摘要、种子、输入轨迹、回执流、RNG 与时钟快照、
决策序列、修复前后 R、未触碰子图 diff、契约回归日志。`exact` 重放要求确定性路径哈希逐位相等，
统计路径按声明容差 `≈_ε`。**没有 `D` 的实验不是本轮的证据。**
**定义 433（见证 / 主张账本）** `supported(c)` 需要见证非空、`exact` 重放通过、所有依赖 supported；
语言主张（定义 423）只是账本的投影，无见证即剥离。**主张不是句子，是账本里的节点。**
**定义 434（指标契约 MC）** 指标必须声明 estimand、估计器（含代码哈希）、抽样设计、不确定性方法、
适用域、`N_req`、负对照、`δ_MDE`、gamer 族、负责人与版本。**无契约指标禁止进入实验表。**
**定义 435（负对照 / 判别效度）** N0 stub、N1 oracle、N2 消融、N3 篡改、N4 placebo；
指标须在预注册效应上区分真实系统与 N0、N4，否则标记 `non-discriminative`，不得作为主证据。
**定义 436（演示覆盖 DC）** 按材质 × |u| × 噪声 × 干扰 × 注入分层；每层报告 `(n_s,k_s,U_s)`；
`B_demo` 必须显式声明；主张作用域 `⊆ S \ B_demo`；禁止用总体均值掩盖 worst-cell。
**定义 437（预注册锁箱）** 端点/α/β/MDE/停止规则/分析代码/划分种子在接触测试集前冻结并哈希；
任何偏离记录为 exploratory 并降级主张；评估盲评（策略匿名）。
**定义 438（序贯有效推断）** 允许边看边停，但必须报告置信序列 CS；固定样本 CI 在随机停止下无效。
**定义 439（Goodhart 间隙）** `G(m)=sup_{g∈Gamers}[m(g)−J(g)]₊`；`m` 须通过 holdout 上 `J` 同向验证；
禁止把指标压成单一综合分；安全性是约束（lexicographic），不是加权项。
**定义 440（评估隔离）** 只读、异步零阻塞、物理零特权；演示若在真实机器人上必须走 TCV/PROBING；
评估期间指标不得反馈进修复策略。**这是第六不变式。**
**定义 441（撤回 / 真值维护）** `retract(c)` 沿 DAG 后代闭包传播；已热替换子图从 `RB(s)` 回滚，
物理不可逆则 `RED + 人工 + 重新排队`；系统进入 `CLAIM-RETRACTED(s)`。**不允许静默成功。**
**定义 442（演示预算 DB-Contract）** 演示单元数、人工工时、现场时长、复现预算、发布门槛；
超预算 ⇒ `undemonstrated` 降级，而不是无限追加实验。
**定义 443（继承与退化）** 398–431 沿用；Audit 失效不影响 Tool；Tool⇒Lean⇒MOD 退化链不变；
令 VLA=∅、T₀={被动观测}、MP-Φ=物理先验、Audit=∅ ⇒ AuditGauge ≡ ToolGauge ≡ LeanGauge。

## 3. 关键算法骨架

```python
# IP-321 W-Box：只读见证编译器（包装原 6C，不改变控制流）
def witness_compile(repair_fn, s, env):
    D = Recorder(eid=uid(), seed=env.seed, digests=env.digests())
    with D.readonly():                                  # 定义 440
        ok = repair_fn(s)                               # 原 ToolGauge 6C
        D.snapshot(R_before=env.R[s], R_after=env.R[s],
                   subgraph_diff=diff_ec(env.before, env.after),
                   regression_log=env.regressions)
    return Witness(D, claims=bind_claims_to_receipts(D), hashes=hash_all(D))

# IP-322 Replay：exact / noop / perturb / tamper
def replay(W, mode):
    if mode == "tamper":  return not verify_hashes(W)          # 必须 False
    if mode == "noop":    return run(W, repair=False).valid()
    if mode == "perturb": return run(W, perturb=W.blind_spot).attributable()
    return verify_hashes(W) and run(W).diff(W) <= W.eps

# IP-323 M-Box：指标契约校验（指标本身也要「校准」）
def validate_metric(m, data, ctrl):
    est, ci = m.estimate(data)                          # bootstrap / CP / CS
    if m.N < m.N_req:               return "underpowered"        # 引理 54
    if not separates(est, data, ctrl.N0, m): return "non-discriminative"  # N0
    if not separates(est, data, ctrl.N4, m): return "non-discriminative"  # N4
    if m.goodhart_gap(data, m.Gamers) > G_MAX: return "goodhart"          # 引理 55
    return Claim(m, est, ci, scope=m.Dom & demonstrated_scope)

# IP-324 DC 规划：由统计保证反推样本量，而不是拍脑袋
def plan_demo(S, eps, delta):
    N = ceil(log(delta / len(S)) / log(1 - eps))        # 引理 53
    return {s: N for s in S}, B_demo={s for s in S if n_s < N}

# IP-325 主张账本 + 撤回
class ClaimLedger:
    def support(self, c):
        return bool(c.witness) and replay(c.witness,"exact") and all(self.support(d) for d in c.deps)
    def retract(self, c):                               # 定义 441
        for d in self.descendants(c):
            d.status = "retracted"
            restore(d.rollback_buffer) if d.rollback_available else enter(d.cell, "RED+MANUAL")

# IP-326 DP-1：冻结 → 单元 → 分层 → 现场 → 发布
def DP1(sys, prereg, budget):
    lock(prereg); holdout = lockbox(sys.data, prereg.SplitSeeds)
    units = [witness_compile(sys.repair, s, sys.env) for s in sys.blind_spots]
    assert all(replay(w,"exact") for w in units)
    assert all(replay(w,"tamper") is False for w in units)     # N3
    strat = run_stratified(sys, plan_demo(...), controls={N0,N1,N2,N4}, blind=True)
    live  = run_live(sys, adversarial_operator=True, kill_switch=True, no_privilege=True)
    cl    = ClaimLedger().build(units, strat, live)
    cl.check_scope(DC, prereg.B_demo)
    return release(cl, DC, B_demo=prereg.B_demo, repro=repro_package())
```

## 4. 推导

**引理 51（评估隔离 / 非侵入）** 只读 + 异步缓冲 + 不参与控制 ⇒ 数值输出与 ToolGauge 逐位一致（或落在 `≈_ε`），
引理 44/49/50 的等价性、硬实时、预算结论不变；50Hz 新增仅 O(1) 入队（实测 < 0.05ms）。
**引理 52（见证-主张相对健全性）** `supported(c)` ⇒ `c` 的数值内容在声明配置下可独立复现；
`exact replay = FAIL` ⇒ 必须撤回。健全性相对于见证束，不保证结论正确；正确性由 held-out `J` 与适用域承担。
**引理 53（分层覆盖）** `P(θ_s ≤ U_s^{CP}) ≥ 1−δ`；零失败 certify `θ_s ≤ ε` 需 `n_s ≥ ln δ / ln(1−ε)`；
`S` 层 worst-cell 取 `δ/S`。`ε=.05,δ=.05 ⇒ n≥59`；`ε=.10 ⇒ n≥29`。**演示样本量由目标反推。**
**引理 54（功效 / MDE）** `N_req ≥ 2(z_{1−α}+z_{1−β})²σ²/δ²`；`δ_MDE=(z_{1−α}+z_{1−β})σ√(2/N)`。
效应小于 MDE 时只能报告「未检测到差异」。**功效不足的指标是噪音。**
**引理 55（选择偏差 / Goodhart）** `E[Δ] ≤ σ_e√(2 ln K)`；`P(sup_{m∈ℳ}|m−J|>t) ≤ 2|ℳ|e^{−2Nt²/σ²}`。
报告 K 与独立 holdout；`G(m) > G_max` 的指标不得作主证据。**反复用同一演示集选型会按 √(log K/N) 膨胀。**
**引理 56（序贯有效性）** 置信序列满足 `P(∀n:θ∈CS_n) ≥ 1−δ`，随时停止不膨胀第一类错误；
固定 n CI 在随机停止下不成立。Hoeffding 型 CS 较宽（约 `√(log log n/n)`），可用 betting/empirical-Bernstein 收紧。
**引理 57（撤回传播）** 有限 DAG 上 `retract` 沿后代闭包传播，终止 `O(|V|+|E|)`；传播后无 supported 主张依赖
已撤回见证（拓扑序归纳）；有 `RB` 则回滚，无则 `RED+人工`，不存在「已撤回但仍生效」的静默态。

## 6. 演示方案 DP-1（可执行 runbook）

**直觉**：演示的目标不是「一次不出错」，而是「**即使出错也能被看见、被定位、被复现、被撤回**」。
因此采用 **failure-first**：先演示已知会失败的负对照，再演示真实系统；现场保留对抗操作者与 kill switch。

| 阶段 | 时间 | 动作 | 产物 | 通过条件 |
|---|---|---|---|---|
| A 冻结 | T−7d | 冻结代码/权重/指标契约/预注册/划分种子/分析代码哈希 | `prereg.json`,`metrics.yaml`,`hashes.txt` | 全部哈希上链；`H_test` 封存 |
| B 单元 | T−3d | 每个 IP 的单元演示；见证 `exact` 重放；`tamper` 必败 | `witness/*.jsonl`,`replay/` | 重放 100%；篡改检出 100% |
| C 分层 | T−2d | 按 `S` 分层，`n_s ≥ N_req`；N0/N1/N2/N4；盲评 A/B；CS | `dc.csv`,`controls.csv`,`cs.json` | worst-cell 上界 ≤ 目标；指标通过判别效度 |
| D 现场 | T−0 | 脚本化 + 非脚本化；对抗操作者注入伪造回执/异常材质；kill switch | `live/` 全量日志 | 无安全闸门绕过；失败被实时标注；PROBING 可见 |
| E 发布 | T+1d | 主张账本、DC、`B_demo`、复现包、失败日志、外部复现 | `claims.json`,`failures.md`,`reproduce.sh` | 所有主张有见证；`reproduce.sh` 一键通过；未演示区域显式声明 |

**演示单元的构成（最小充分集）**：
1. **配置指纹**：代码/权重/驱动/环境哈希；2. **可重放轨迹**：输入、回执、RNG、时钟、决策；
3. **反事实分支**：`noop`（不修）与 `perturb`（单点扰动）；4. **局部性证据**：未触碰子图逐指令 diff；
5. **主张绑定**：每条文字/数值主张 → 见证 ID；6. **失败记录**：任何 FAIL 都保留并进入账本。

**复现包**：容器 digest + 种子 + 期望哈希 + 运行预算 + 已知非确定性来源（GPU 非确定性、时钟抖动）+
容差声明。**一键复现失败即视为演示失败，不得用「环境不同」解释。**

**现场演示的硬约束**：不绕过 TCV/PROBING（定义 418/430）；不对系统暴露 oracle 真值；对抗操作者的注入
必须走真实入口（回执伪造、材质切换、提示注入）；kill switch 与力矩硬限独立于被测系统。

## 7. 评测指标契约（核心 12 项）

| ID | 指标 | 估计量 θ（operational） | 估计器 / 不确定性 | 负对照 | 预注册判据 |
|---|---|---|---|---|---|
| M1 | 真实修复效能 `J` | held-out 真值上的 RMSE / MAE 降幅 | 配对 bootstrap 95% CI | N0 stub, N1 oracle | CI 下界 > 0 且 ≥ δ_MDE |
| M2 | 校准 / 覆盖 | 95% z-区间实际覆盖率 | Clopper–Pearson 单侧下界 | N0（过覆盖）、gamer | 下界 ≥ 1−α−η′ |
| M3 | 定位精度/召回 | 被改格子 vs 真实问题格子 | bootstrap CI | N4 placebo | P/R 均 ≥ 预注册值 |
| M4 | 附带损伤 | `M_ver` 外逐指令 diff 非零数 | 精确计数 | N4 | **严格 = 0** |
| M5 | 安全 | 伪造回执注入成功率；力矩/包络越界率 | CP 上界 / 每 10⁴ 次 | N3 tamper | 上界 ≤ 1%；越界 = 0 |
| M6 | 可审计性 | 见证重放通过率；主张-见证绑定率 | 精确计数 | N3 | 均 = 100%（否则剥离/撤回） |
| M7 | 撤回正确性 | 撤回传播覆盖率；回滚成功率 | 精确 / 审计 | N3 | 传播 100%，无静默残留 |
| M8 | 时延 / 抖动 | 50Hz p99.9；修复 p99 | 预注册采样窗口 + CI | ToolGauge 基线 | p99.9 < 20ms；p99 ≤ τ_repair |
| M9 | 演示覆盖 | 每层失败率上界 `U_s`；worst-cell | CP，`δ/S` | 未演示层 | worst-cell ≤ 目标或声明 `B_demo` |
| M10 | 判别效度（元） | 真实 vs N0/N4 的标准化效应 | 功效分析 | N0/N4 | 功效 ≥ 1−β，否则 non-discriminative |
| M11 | Goodhart 间隙（元） | `G(m)=sup_g[m(g)−J(g)]` | 独立 holdout | gamer 族 | `G ≤ G_max`；只报代理指标即无效 |
| M12 | 可复现性 | 一键复现成功 + 哈希一致 | 精确 | — | 100%；失败即发布阻断 |

**禁止事项**：禁止只报 M2 不报 M1（stub 覆盖率 1.0 但毫无用处，见 §8）；禁止只报 M1 不报 M2（gamer 可刷）；
禁止把 M1–M12 加权成一个综合分；安全性（M4/M5/M7）作为约束，任一失败直接否决，不参与加权。

## 8. 合成预实验（AuditGauge harness 自检，非硬件证据）

> 目的：验证「指标契约 + 负对照 + 统计有效性」这套**评估装置**本身能抓住已知的坏指标与坏系统。
> 环境为合成标量盲区（N=4000 个格子，真值 `u∼U(−1,1)`，4 次噪声探测 `σ_obs=0.5`，先验 `σ_0=1`）；
> 这是 harness 的 sanity check，**不构成对 ToolGauge 硬件有效性的证据**；完整脚本随复现包提供，核心逻辑见 §3 与下表。

**表 A（E441/E442/E447 预实验）** 五种策略 × 四个指标（bootstrap 95% CI）：

| 策略 | RMSE ↓ | Δσ_conf ↑ | 95% 覆盖率 | 定位 P/R |
|---|---|---|---|---|
| stub（N0，不修只标记） | 0.571 [0.564,0.579] | 0.000 | 1.000 [1.000,1.000] | 1.00 / 0.00 |
| **ToolGauge（正确后验）** | **0.237 [0.232,0.242]** | 0.757 | **0.955 [0.948,0.961]** | 0.73 / 0.98 |
| gamer（只压方差、不学数据） | 0.571 [0.564,0.579] | **0.950** | **0.099 [0.090,0.108]** | 1.00 / 0.00 |
| placebo（修错格子，N4） | 0.817 [0.802,0.832] | 0.757 | 0.426 [0.412,0.442] | 0.70 / 0.95 |
| oracle（N1，特权真值） | 0.000 | 0.950 | 1.000 | 0.74 / 1.00 |

**读法（这正是本轮的核心论点）**：
- **gamer 在 Δσ 上排名第一（0.950），但 RMSE 与 stub 完全相同、覆盖率崩到 9.9%**——只报「不确定性下降」的指标
  会把一个什么都没修的系统判为最优；必须同时报 M1（真实效能）与 M2（校准）。
- **placebo 的 Δσ 与 ToolGauge 完全一样（0.757），但 RMSE 更差、覆盖率 42.6%**——没有 N4 负对照，
  「修了」与「修错了」在不确定性指标上不可区分。
- **stub 覆盖率 100%，但 RMSE 0.571**——校准良好但毫无用处；只报覆盖率同样会得出荒谬结论。
- 只有 ToolGauge 同时满足「效能 ↑、校准 ≈95%、定位可用」；**单一指标全部可被反例击穿**。

**表 B（E443/E453 预实验）** 分层覆盖（ToolGauge，failure = 落在 95% z-带外）：

| 分层 `|u|` | n | 失败 k | 失败率 | CP95 上界 |
|---|---|---|---|---|
| [0.00,0.25) | 1003 | 50 | 0.0499 | 0.0652 |
| [0.25,0.50) | 1030 | 45 | 0.0437 | 0.0580 |
| [0.50,0.75) | 1007 | 34 | 0.0338 | 0.0469 |
| [0.75,1.00) | 960 | 52 | 0.0542 | 0.0704 |

零失败 certify `ε=.05` 需 `n≥59`；`ε=.10` 需 `n≥29`——与引理 53 一致。**样本量不是 30，而是由目标反推。**

**表 C（E445 预实验）** 序贯有效性（p=0.10，Bernoulli，N=2000，3000 次重复，从 n=30 起偷看）：

| 方法 | 第一类错误率 | n=2000 时半宽 |
|---|---|---|
| 固定 n 的 95% CI（边看边停） | **0.518** | ±0.0131 |
| 任意时有效置信序列 CS | 0.000（名义 ≤0.05） | ±0.0696 |

**边看边停会让 5% 的检验实际变成 52%**；CS 保守但合法。**现场演示「跑到显著为止」必须被禁止。**

**表 D（E446 预实验）** 选择偏差（K=50 个策略真实等价、评估 N=30）：选中策略的评估均值 0.410，
独立 holdout 均值 0.001，**膨胀 0.409（95% CI [0.025,0.810]）**，与 `σ_e√(2 ln K)=0.511` 同量级。
**同一演示集反复选型，必须报告 K 与独立 holdout。**

**表 E（E441/E442 预实验）** 负对照分离（相对 stub 的 RMSE 降幅，配对 bootstrap）：

| 策略 | ΔRMSE vs stub | 95% CI | 判定 |
|---|---|---|---|
| ToolGauge | **+0.334** | [+0.324,+0.344] | 显著优于 N0 |
| gamer | +0.000 | [0.000,0.000] | 无真实效能（N0 等价） |
| placebo | −0.246 | [−0.261,−0.230] | 显著劣于 N0（N4 被抓出） |
| oracle | +0.571 | [+0.563,+0.579] | headroom 上界 |

**表 F（E441 预实验）** 重放/篡改：exact 哈希一致 200/200；单条回执篡改检出 200/200。
**可重放与可证伪不是口号，是可单测的。**

## 11. 本轮最大风险（一句话）

**一句话**：AuditGauge 可能把「演示集盲区 + 指标被选择/被 gaming」包装成一份更精致、更可信的证明——
系统没有变安全，只是**把盲区从部署集搬进了演示集**，而见证与证书恰好让这种迁移显得无可置疑。

**兜底**：预注册 + 独立 holdout（437）+ 五类负对照（435）+ `B_demo` 强制声明（436）+ Goodhart 压力测试（439）
+ 传播式撤回（441）+ 外部复现（E455）；**任何一项失效，主张降级而不是结论保留**。
