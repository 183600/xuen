# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配×主动交互的不确定性二分」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「末端位姿」×「低成本方案」）

> R69 把不确定性做成了有形状的对象（多模态 + 权重 + 间距），也把「问」变成了动作（看/问/触）。但它仍站在一个昂贵的隐含前提上：**我知道我的动作在世界里到底落在哪，而且我有足够的计量手段把这件事测准**。R69 的 Δ_min、U_ale、U_epi 全都在**动作坐标**里度量；它默认「动作空间里的距离」就等于「世界里的危险」。这在计量级设备上近似成立，在低成本部署上立刻失效：
> - **末端位姿**说：一切任务风险最终都要在**末端位姿（TCP）相对世界/工件的位姿关系**上结算——间隙、对中、插入轴、抓取裕度、接触力臂。动作协方差必须经正运动学与任务泛函拉回，才知道「这点不确定到底危不危险」。
> - **低成本方案**说：便宜不是「均匀地差」，而是**选择性失明**——六维位姿里你只买得起两三维修得准，其余靠推断；更糟的是便宜器件的失效是**相关的**（同一束光、同一阵振动、同一批标定），R69「k 个正交证据一致」的纪律在这里会被同一次共因失效一起骗过。
>
> 核心命题：**把「末端位姿」提升为不确定性的结算货币，把「低成本」形式化为一个有预算约束的证据组合问题；不确定性不再只问「多大 / 可约吗」，还要问「在哪个方向、由谁观测、值多少钱」。** 只在**任务敏感且不可观测**的那几个方向花钱（探询/标定/降额），对任务无害的方向保持速度。命名 **COIN-RAS**（Certified pOse-Envelope, Information-budgeted, Non-degrading Risk-Adaptive System）——pose 是结算用的硬币，低成本是预算分配。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我只买得起几维的准，凭什么敢在剩下几维上快跑**」——低成本不是把精度砍掉，而是把精度**按任务方向重新分配**，并诚实地承认买不起的那一块。

## 0. 直觉与动机

**灵感 1（末端位姿 → 不确定性最终都在 TCP 上"结算"）**
直觉：策略吐出的动作再花哨，真正决定撞不撞、插不插得进、抓不抓得住的，是末端执行器相对世界/工件的那个位姿 `T ∈ SE(3)`，以及由它派生的任务量 `Φ(T)`：沿插入轴的有符号距离、横向偏差、姿态倾角、抓取裕度。同一个「动作不确定度」，在远离接触时无害，在 0.2mm 的插入间隙里致命；在绕工具轴旋转方向上无害，在接近轴方向致命。所以第一性对象不是动作协方差，而是**被任务泛函加权的位姿协方差**：`G_task = J_Φᵀ W J_Φ`，风险 `R_task ≈ ½ tr(G_task Σ_T)`。R69 相当于默认 `G_task = I` 且 Σ 在动作坐标里——用一把会被身体和任务拉伸的尺子量距离。

**灵感 2（低成本 → 便宜是"选择性失明"，不是均匀变差）**
直觉：一套计量级六维跟踪器能把六维都测到亚毫米；一套低成本组合（单目 + IMU + 码盘 + 标靶 + 力觉）通常只在少数方向准，其余方向欠定：单目有尺度歧义、IMU 会漂、码盘有回差、标靶会遮挡、力觉没有力矩。于是真正的结构是 6 维空间里的**可观测性子空间**：少数方向误差小（可估），其余方向误差大甚至无界（不可估）。关键推论：**不可估方向不能靠"多滤波一会儿"救回来，只能靠"激励"**——移动产生视差、旋转破对称、轻触夹具定位。便宜系统的正确动作不是"更慢地融合"，而是"到能看清的地方动一下"。

**灵感 3（两者交汇 → 一张 2×2 表就决定了钱花在哪）**
直觉：把每个位姿方向的误差同时按两个轴分类——**任务是否敏感** × **是否可观测**。
- 敏感 × 可观测 ⇒ `U_obs`：用滤波/在线标定压低，几乎免费；
- 敏感 × 不可观测 ⇒ `U_blind`：唯一的真问题，必须**探询/换传感器/降额**；
- 不敏感 × 任何 ⇒ `U_harmless`：噪声再大也别为它减速；
- 不敏感 × 不可观测 ⇒ 直接忽略。
R69 的 `(U_ale, U_epi)` 只切了一个轴（可约/不可约）；R70 补上**方向**这个轴。于是「aleatoric」被相对化：在给定传感器配置与激励集下不可约，才叫 aleatoric；换配置、加激励即可约。这把 R69 的二分升级成 `(U_obs, U_blind, U_harmless)`，且 R69 是各向同性特例。

**灵感 4（对偶通道 → 第三条标定不可吸收的证据：位姿闭合）**
直觉：R68 用传感器残差 `r_res` 测「测量自洽」，R69 用动作似然 `Δa` 测「行为自洽」。低成本系统还多一条：**传出的指令穿过身体后，真的到达了预期的末端位姿吗？** 比较 `FK(q) ⊕ T_tool` 与多源融合位姿 `T̂`，得位姿闭合残差 `r_pose`。它能抓前两条都抓不到的：运动学标定错、工具磨损、接触滑移、末端工具被换掉。三条通道盲区不同：`(r_res↓, Δa↑, r_pose↑)` 是低成本身体故障的判别性三联模式。

**灵感 5（暗面 → 便宜的真正代价是相关失效与"认证洗白"）**
直觉：便宜器件不是独立随机地坏。同一束强光让所有视觉一起失效，同一阵振动让所有惯性一起偏，同一批工厂标定让整支车队的误差高度相关。R69「k 个正交源多数一致」在相关误差下会给出虚假的安全感：`k` 个源可能只是**同一个错误的 k 次重复**。更隐蔽的是「认证洗白」：把噪声规格写小、把标定报告复用、把 ODD 写宽、把包络算窄，证书就变成市场材料。对策必须是结构性的：相关折扣 `k_eff`、标定溯源与新鲜度、包络覆盖的独立检验、以及「买不起就不自主」的部署间隙。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（COIN-RAS 总览与五不变式）** COIN-RAS = (TPM, EGO, CPP, PEP, VIN, KEF, PCR, ALB, RAS-WM‡)。五不变式：
(i) **实时流零学习写操作**（继承 R69 定义 276-i）；
(ii) **位姿诚实**：任何自主动作必须携带认证位姿包络 `E_δ`，且 `E_δ` 在声明的 ODD 内以概率 ≥ 1−δ 覆盖真实 TCP 位姿；无包络不得自主；
(iii) **各向异性退避**：保守只沿任务敏感方向施加，不得把不敏感方向的噪声放大成全局减速；
(iv) **证据相关折扣**：多源一致必须先扣除相关性（`k_eff`），相关源不得冒充独立证据；
(v) **成本可审计**：每一分精度提升都记录其成本（硬件/标定/在线探询），证书含成本账本与传感器溯源。

**定义 311（任务位姿泛函与度量）** 末端位姿 `T ∈ SE(3)`。任务只关心 `Φ(T) = (φ_1,…,φ_m)`（如插入轴有符号距离、横向偏差、姿态倾角、抓取裕度），安全集 `𝒮 ⊂ ℝ^m`。在 `se(3)` 上定义任务度量 `G_task(T) = J_Φ(T)ᵀ W J_Φ(T)`，`W ≻ 0`。一阶任务风险 `R_task ≈ ½ tr(G_task Σ_T)`。**关键：R69 的 Δ_min / U 在动作坐标；R70 必须经 `G_task` 拉回才能说「这个不确定危不危险」。**

**定义 312（各向异性分解）** 对 `A = G_task^{1/2} Σ_T G_task^{1/2}` 特征分解得 `{λ_i, u_i}`：
- `U_harmless = Σ_{λ_i ≤ ε} λ_i`（任务不敏感，可忽略）；
- `U_critical = Σ_{λ_i > ε} λ_i`（任务敏感）；
再按 Fisher 信息 `I(g)` 的零空间把 critical 分为 `U_obs`（`uᵀ I u > 0`，可估、可由滤波/标定压低）与 `U_blind`（`uᵀ I u ≈ 0`，不可估，必须激励）。R69 的 `(U_ale, U_epi)` 被细化为 `(U_obs, U_blind, U_harmless)`。

**定义 313（低成本传感器组合与观测性）** 传感器目录 `𝒞`（单目、IMU、码盘、标靶、力/力矩、触觉皮肤…），每个 `s` 有采购成本 `c_s`、标定成本、更新率、噪声模型。组合 `S ⊆ 𝒞` 在配置 `g`（含探询）下的 Fisher 信息 `I_S(g)`（`se(3)`）。CRLB：`Σ_T ⪰ I_S(g)^{-1}`；沿 `u` 若 `uᵀ I_S(g) u = 0` 则方差无界。**低成本 = 六维里只买得起几维的准，其余靠推断。**

**定义 314（证据债务 D_evid）** 任务所需信息 `I_req = G_task/ε_task`，当前可得 `I_avail = I_S(g)`。证据债务 `D_evid = logdet(I_req + I_avail) − logdet(I_avail)`（信息缺口对数体积），价格 `C(D_evid) = min_{S,g}[Σ c_s + c_cal(S) + c_probe(g)]` s.t. 缺口 ≤ `D_evid`。低成本不是「零成本」，而是「把成本花在缺口最大的方向上」。

**定义 315（认证位姿包络 E_δ）** `E_δ(S,g,ODD) = {δξ ∈ se(3) : δξᵀ Σ_T(S,g)^{-1} δξ ≤ χ²_6(1−δ)}`（保守版用无分布 Minkowski/区间包络）。任务级包络 `Φ(E_δ)`。认证 Valid ⇔ `Φ(T̂ ⊕ E_δ) ⊆ 𝒮` 且 `P(真值 ∈ E_δ) ≥ 1−δ` 在 ODD 上经独立校准检验。**点估计无意义；交付的是包络。**

**定义 316（位姿探询动作 PEP）** `𝒜_pose = {g_view(b), g_rotate(ω), g_contact(n,f), g_wait(τ)}`：基线视差、绕轴旋转破对称、接触夹具定位、等待低频传感器收敛。增广 `𝒜_info† = 𝒜_info × 𝒜_pose`。探询须过 C-RAS-WM 认证，位移/接触力 ≤ 包络。

**定义 317（任务加权 VoI 与每成本增益）** `VoI_pose(g) = tr(G_task (Σ_T^before − Σ_T^after(g)))`（即风险下降的一阶量）；`g* = argmax_g [VoI_pose(g) − c(g)]` s.t. 认证与预算。**若 `g` 不激励所需盲方向（该方向 `uᵀ I(g) u = 0`），则 `VoI_pose(g) = 0`——问错方向等于没问。**

**定义 318（传感器组合优化与保证-成本前沿）** 给定 ODD、风险上界 `ε_task`、预算 `B`：`S* = argmin_{S,g-policy} TCO(S)` s.t. `sup_{ODD} R_task(E_δ(S)) ≤ ε_task`，对偶为 `max Assurance s.t. TCO ≤ B`。信息函数次模 ⇒ 贪心 `(1−1/e)` 近似。定义 `APC = ΔAssurance/ΔTCO`（每元保证增益）。

**定义 319（相关感知证据与有效证据数）** 多源误差相关矩阵 `R`，等相 `ρ` 近似下 `k_eff = k/(1 + (k−1)ρ)`；`k→∞` 时 `k_eff → 1/ρ`。证据纪律升级为 `k_eff ≥ k_min`。**同批硬件、同次标定、同一光照/振动下的「多源一致」可能只是同一错误的重复。**

**定义 320（位姿闭合残差 PCR）** `r_pose = d_{SE(3)}(FK(q) ⊕ T_tool_model, T̂_fused)`，以及「指令预测位姿 vs 实测位姿」之差。抓运动学标定错、工具磨损、接触滑移、末端工具被换。与 `r_res`、`Δa` 构成三联通道。

**定义 321（证书 J_COIN）** `J_COIN = (J_FLUID, G_task_hash, E_δ_coverage, observability_hash, k_eff, r_pose_p95, cost_ledger_hash, sensor_provenance, coin_ver)`。Valid ⇔ `Valid(J_FLUID)` ∧ 包络覆盖检验通过 ∧ `k_eff ≥ k_min` ∧ 成本账本闭合 ∧ 溯源完整 ∧ `E_δ` 在 ODD 内任务安全。

**定义 322（低成本威胁模型 ℰ_lowcost）** 遮挡/致盲、假标靶/镜面反射欺骗、山寨传感器噪声规格造假、共因退化（光照/温度/振动/同批）、标定溯源丢失、尺度歧义被利用。`ℰ_COIN = ℰ_FLUID × ℰ_lowcost`。

**定义 323（各向异性退避 ALB）** 任务方向增益 `Λ = diag(λ_1,…,λ_m)`：对任务敏感且包络宽的 DoF 取更小增益（更慢/更柔），对无害 DoF 保持原速；`λ_i = max(λ_floor(·), f(E_δ,i))`。R69 的标量 `λ` 是 `Λ = λ·I` 的各向同性特例。探询消解后只对剩余方向退避（resolution bonus 的方向版）。

**定义 324（校准溯源与新鲜度）** 每个传感器/工具携带 `(cal_id, cal_time, cal_operator, cal_fixture, cal_temp)`；证书要求包络所用标定未过期且溯源链完整；过期触发「陈旧包络」降级。防止「永不过期的认证」。

**定义 325（ODD 与降级/交接）** 证书绑定 ODD；出 ODD 或包络无法在预算内达到 ⇒ 不自主：降级（缓慢/停止/求人）或交接人工。**低成本也意味着「必须承认买不起的场景」。**

**定义 326（异步融合时序）** 便宜传感器频率低且不同步；用时间戳对齐 + 运动补偿；对过期观测按陈旧度膨胀 `Σ_T`。实时环路只在位姿包络变化超阈值时重算 ALB。

```python
# IP-264 TPM：任务位姿度量与风险
def task_metric(phi, T):
    J = jacobian_se3(phi, T)            # m x 6
    return J.T @ W @ J

def task_risk(G, Sigma_T):
    return 0.5 * trace(G @ Sigma_T)     # 一阶；高阶项见引理 19

# IP-265 EGO：各向异性 + 可观测性分解
def decompose_pose(G, Sigma_T, I):
    A = sqrtm(G) @ Sigma_T @ sqrtm(G)
    lam, U = eigh(A)
    harmless = sum(l for l in lam if l <= EPS_TASK)
    crit = [u for l, u in zip(lam, U) if l > EPS_TASK]
    blind = [u for u in crit if u.T @ I @ u <= EPS_OBS]
    obs   = [u for u in crit if u.T @ I @ u >  EPS_OBS]
    return harmless, obs, blind

# IP-266/268：位姿探询（只在盲且敏感时）+ 认证包络
def choose_pose_probe(G, Sigma_T, I, budget):
    best = None
    for g in pose_candidates(Sigma_T):            # view / rotate / contact / wait
        if not budget.allow(g):                  continue
        if not c_ras_wm.certify_pose_probe(g):   continue
        Sig2 = fuse_information(Sigma_T, I, g)   # 激励后后验
        voi  = trace(G @ (Sigma_T - Sig2))
        score = voi - cost(g)
        if best is None or score > best.score:
            best = (g, Sig2, score)
    return best if best and best.score > 0 else None   # 问错方向 → 不问

def certify_envelope(S, g, odd, delta):
    Sigma_T = crlb(S, g)
    E = chi2_ellipsoid(Sigma_T, delta)
    ok = covers(E, odd) and subset(task_phi(E), SAFE_SET)
    return E, ok

# IP-269 KEF：相关感知有效证据数
def effective_k(corr, k):
    rho = mean_offdiag(corr)
    return k / (1 + (k - 1) * rho)

# IP-270 PCR：位姿闭合第二意见
def pose_closure(q, T_tool_model, T_fused):
    return se3_distance(fk(q) @ T_tool_model, T_fused)

# IP-274 主闭环（继承 R69，只在"不确定性结算"处插入 COIN 层）
def COIN_RAS_round(M, obs):
    z, o = M.mtm.forward(...)                      # R69 一次前向
    c, U_cal, thr = M.cof.step(...)                # R68/R69 标定
    # 1) R69 流策略 + 不确定性
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    # 2) 结算到任务位姿：拉回 + 各向异性 + 可观测性
    T_hat, Sigma_T = M.fuse.estimate(o)            # 低成本多源融合
    G = M.tpm.task_metric(M.task.phi, T_hat)
    U_h, U_obs, U_blind = M.ego.decompose(G, Sigma_T, M.fuse.fisher(o))
    # 3) 三联第二意见
    r_pose = M.pcr.pose_closure(M.q, M.tool, T_hat)
    a_hat  = M.fma.flow_anomaly(M.fmp, M.last_action, o, M.cof.calibrate(o))
    slow   = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    # 4) 只在"敏感且盲"时探询
    g = None
    if U_blind > TAU_BLIND and not slow:
        g = M.vin.choose_pose_probe(G, Sigma_T, M.fuse.fisher(o), M.budget)
    if g is not None:
        T_hat, Sigma_T = M.vin.execute(g, o)       # 看/转/触/等
    E, ok = M.cpp.certify(M.sensors, g, M.odd, M.delta)
    # 5) 各向异性退避：危险方向慢，无害方向快
    if ok and U_blind <= TAU_BLIND:
        Lam = M.alb.gain(G, E, bonus=True)
        lam = max(M.efs.risk_scale(...), lam_floor(U_ale))
    else:
        Lam = M.alb.gain(G, E, bonus=False)
        lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi + U_blind))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if slow or r_pose > TAU_POSE:
        Lam, lam = M.alb.max_derate(G), max(lam, 0.8)   # 回 R68 最保守
    # 6) 选模态 + 方向性降额
    mode = select_mode(modes, U_epi, lam)
    tau  = M.alb.apply(Lam, M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam)
    # 7) 参与式审计 + 证书
    M.vqa_p.submit_async(g, E, M.kef.k_eff, r_pose, a_hat, M.cost_ledger)
    return k, Lam, mode, (U_obs, U_blind), E
```

## 3. 推导

**引理 19（任务加权位姿风险的各向异性界）** 设 Φ 在 ODD 上局部 Lipschitz、Hessian 有界（A99），则 `R_task = ½ tr(G_task Σ_T) + O(‖Σ_T‖^{3/2})`。若仅做各向同性收紧（把 Σ_T 整体缩放 α<1），其风险下降为 `½(1−α) tr(G_task Σ_T)`；而各向异性收紧只压任务敏感方向可达 `½(1−α) tr(G_task Σ_T)` 的同时保持无害方向不变，二者在 `κ = cond(G_task^{1/2} Σ_T G_task^{1/2})` 上可差任意倍。系：**便宜的噪声若落在无害方向，不该让机器人减速**；R69 的标量 λ 是 `Λ = λI` 特例。

**引理 20（低成本的可观测性下界与激励必要性）** 若某任务敏感方向 `u` 满足 `uᵀ I_S(g) u = 0`，则任何无偏估计在该方向方差无界（CRLB），**再多滤波也无法压低**；只有选择 `g` 使 `uᵀ I_S(g) u > 0`（视差/旋转/接触）才能获得有限方差。系：低成本的正确动作是「激励」，不是「更慢地融合」。

**引理 21（方向性 VoI）** 在块对角近似下，`VoI_pose(g) = tr(G_task(Σ_T − Σ_T^{(g)}))`。若 `g` 的信息增量正交于任务盲子空间（`P_blind ΔI(g) P_blind = 0`），则 `VoI_pose(g) = 0`。系：**歧义大、但探询激励的是错误方向时，交互一文不值**——这是对 R69 引理 16 的方向版修正。

**引理 22（相关证据有效数）** 等相 `ρ` 下 `k_eff = k/(1+(k−1)ρ)`；`k→∞` 时 `k_eff→1/ρ`。故 R69 的「k 个正交源一致」在共因失效下退化为「一个源的 k 次重复」，错误率上界由 `δ_p·ρ^{k−1}` 恶化为 `δ_p·ρ^{k_eff−1}`。系：低成本必须先买**独立性**（不同物理原理、不同标定路径、不同供应商批次），再谈冗余。

**定理 18（COIN 严格包含 R69/FLUID）** 在 A99–A102 下，当传感器为计量级且各向同性（`Σ_T → 0`、`G_task = cI`、`I` 满秩、`k_eff = k`）时，`U_blind = 0`、探询 `VoI_pose ≤ 0`、`Λ = λI`，COIN 与 R69 **逐指令相同**；且 COIN 在任意状态先认证包络再自主，安全侧不弱于 R69。R69 = COIN 在「无盲向、无预算压力」边界上的退化。

**定理 19（保证-成本前沿与部署间隙）** 若信息函数关于传感器子集次模、成本模加，则贪心传感器组合达到最优保证的 `(1−1/e)`；且若 `min_{TCO ≤ B} sup_{ODD} R_task(E_δ) > ε_task`，则不存在可认证的自主部署——系统必须降级/交接（部署间隙）。系：**低成本方案的价值不是「更便宜地做同一件事」，而是明确画出「这个预算下哪些场景根本不该自主」。**

**定理 20（包络安全与无突变）** 若 `Φ(T̂ ⊕ E_δ) ⊆ 𝒮` 以概率 1−δ 成立，则自主动作的任务风险 ≤ `ε_task`；当 `E_δ` 变宽时 `Λ` 的各增益单调不增、`λ` 单调不减；`r_pose` 越界触发保守回退；C-RAS-WM 前缀认证与换装不变式（R69 定理 17）保持 ⇒ 控制连续、无突变。

## 6. 本轮最大风险

**一句话**：COIN-RAS 的全部安全论证押在「认证位姿包络 `E_δ` 是诚实的」这一前提上——但**廉价传感器的噪声、相关性与漂移模型本身就是在同一批欠定、相关、漂移的数据上估出来的**，认证会系统性地低估真实误差（"包络自欺"）；一旦 `E_δ` 偏窄，系统就会**沿着它最看不见、却最致命的方向自信地快跑**——低成本的真正敌人不是便宜，而是把「买不起的精度」写成「已经买到的精度」。

**次级风险与缓解**：
1. **相关失效伪装成多数一致** → `k_eff` 折扣 + 物理/标定路径多样性 + E307 共因攻击；
2. **探询本身不安全/无效** → C-RAS-WM 认证 + 方向性 VoI 为零则不探询（引理 21）+ E311；
3. **低观测方向被滤波"平滑"成假自信** → CRLB 零空间显式检测 + 探询必要性（引理 20）；
4. **标定溯源缺失/复用** → 溯源与新鲜度门（定义 324）+ 过期即降级；
5. **认证洗白（写窄包络、写宽 ODD）** → 独立覆盖检验 + 成本账本 + 部署间隙（定理 19）不签不自主。

```python
# IP-264 TPM：把动作不确定拉回任务位姿结算
def task_metric(phi, T):
    J = jacobian_se3(phi, T); return J.T @ W @ J

def task_risk(G, Sigma_T):
    return 0.5 * trace(G @ Sigma_T)

# IP-265 EGO：各向异性 + 可观测性二分
def decompose_pose(G, Sigma_T, I):
    lam, U = eigh(sqrtm(G) @ Sigma_T @ sqrtm(G))
    harmless = sum(l for l in lam if l <= EPS_TASK)
    crit = [u for l, u in zip(lam, U) if l > EPS_TASK]
    blind = [u for u in crit if u.T @ I @ u <= EPS_OBS]
    obs   = [u for u in crit if u.T @ I @ u >  EPS_OBS]
    return harmless, obs, blind

# IP-266/268：位姿探询只在"敏感且盲"时发生，且方向要对
def choose_pose_probe(G, Sigma_T, I, budget):
    best = None
    for g in pose_candidates(Sigma_T):                 # view/rotate/contact/wait
        if not budget.allow(g) or not c_ras_wm.certify_pose_probe(g): continue

        score = trace(G @ (Sigma_T - Sig2)) - cost(g)  # 方向性 VoI − 成本

    return best if best and best.score > 0 else None

        Lam = M.alb.gain(G, E, bonus=False)
        lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi + U_blind))
    A = M.ach.propose(x_prime, M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if slow or r_pose > TAU_POSE:
        Lam, lam = M.alb.max_derate(G), max(lam, 0.8)   # 回 R68 最保守
    mode = select_mode(modes, U_epi, lam)
    tau  = M.alb.apply(Lam, M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam)
    M.vqa_p.submit_async(g, E, M.kef.k_eff, r_pose, a_hat, M.cost_ledger)
    return k, Lam, mode, (U_obs, U_blind), E
```

## 4. 推导

**引理 19（各向异性任务风险界）** A99（Φ 局部 Lipschitz、Hessian 有界）下 `R_task = ½tr(G_task Σ_T) + O(‖Σ_T‖^{3/2})`；各向同性收紧与方向性收紧的最优性差距由 `κ = cond(G_task^{1/2}Σ_TG_task^{1/2})` 控制，可任意大。系：**无害方向的大噪声不该让机器人减速**。

**引理 20（可观测性下界与激励必要性）** 若任务敏感方向 `u` 满足 `uᵀI_S(g)u=0`，任何无偏估计在该方向方差无界；只有选 `g` 使 `uᵀI_S(g)u>0`（视差/旋转/接触）才能获得有限方差。系：低成本需要「激励」，不是「更慢地融合」。

**引理 21（方向性 VoI）** `VoI_pose(g)=tr(G_task(Σ_T−Σ_T^{(g)}))`；若 `g` 的信息增量正交于任务盲子空间，则 `VoI_pose=0`。系：歧义大但探询方向错时，交互一文不值——修正 R69 引理 16 的各向同性假设。

**引理 22（相关证据有效数）** 等相 `ρ` 下 `k_eff=k/(1+(k−1)ρ)→1/ρ`；错误率上界由 `δ_pρ^{k−1}` 恶化为 `δ_pρ^{k_eff−1}`。系：低成本必须先买**独立性**（不同物理原理/标定路径/批次），再谈冗余。

**定理 18（COIN 严格包含 R69/FLUID）** A99–A102 下，计量级各向同性（`Σ_T→0`、`G_task=cI`、`I` 满秩、`k_eff=k`）时 `U_blind=0`、探询 `VoI_pose≤0`、`Λ=λI`，与 R69 逐指令相同；且 COIN 先认证包络再自主，安全侧不弱。R69 = COIN 在「无盲向、无预算压力」边界的退化。

**定理 19（保证-成本前沿与部署间隙）** 信息次模、成本模加时贪心达到最优保证的 `(1−1/e)`；若 `min_{TCO≤B} sup_{ODD} R_task(E_δ) > ε_task`，则无认证自主部署，必须降级/交接。系：低成本的价值是明确画出「此预算下哪些场景不该自主」。

**定理 20（包络安全与无突变）** `Φ(T̂⊕E_δ)⊆𝒮` 以概率 1−δ 成立 ⇒ 自主任务风险 ≤ `ε_task`；`E_δ` 变宽时 `Λ` 增益单调不增、`λ` 单调不减；`r_pose` 越界触发保守回退；前缀认证与换装不变式保持 ⇒ 控制连续、无突变。

## 7. 本轮最大风险

**一句话**：COIN-RAS 的全部安全论证押在「认证位姿包络 `E_δ` 诚实」这一前提上——但**廉价传感器的噪声、相关性与漂移模型本身就是在同一批欠定、相关、漂移的数据上估出来的**，认证会系统性低估真实误差（包络自欺）；一旦 `E_δ` 偏窄，系统就会**沿着它最看不见、却最致命的方向自信地快跑**——低成本的真正敌人不是便宜，而是把「买不起的精度」写成「已经买到的精度」。

**次级风险与缓解**：相关失效伪装多数一致（`k_eff` 折扣 + 路径多样性 + E307）；探询不安全/无效（C-RAS-WM 认证 + 方向性 VoI 为零则不探询 + E311）；低观测被滤波平滑成假自信（CRLB 零空间显式检测 + 引理 20）；标定溯源缺失/复用（溯源与新鲜度门 + 过期降级）；认证洗白（独立覆盖检验 + 成本账本 + 定理 19 部署间隙，不签不自主）。
