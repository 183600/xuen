# 第 4 轮（灵感循环第 4 轮；本轮灵感：「用户画像」×「ROS2」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。两个新灵感各沿一条轴升级 InstructGauge，且任一环节不可用都必须能一键退回；画像与分布式部署是增强项、不是依赖项。

## 0. 直觉与动机

**灵感 1（用户画像 → 从「给谁看」到「挣得的授权」）**
直觉：同一台测量机器人，资深计量工程师只需要一句结论和一个证书编号；新手则需要逐步确认、术语解释与"这一步为什么安全"的说明。因此画像的第一价值不在控制，而在**人机接口的适配**：解释粒度、确认频率、自主等级、异常升级路径。但画像天然是危险的：它容易退化成刻板印象，容易变成"个性化说服"的操纵入口，也容易制造自动化自满（operator over-trust）。正确的建模不是给人贴标签，而是维护一个**对操作者状态的后验** `π_t(θ)`：自报画像只是先验，真正的能力必须从**已验证回执**中"挣得"。由此得到与第 3 轮"能力闭包"对偶的第一原则——**画像闭包**：画像只能在预注册的交互拓扑里做选择，不能创造新能力；且个性化是**单向**的——只能收紧监督、不能放宽物理包线。

**灵感 2（ROS2 → 把「降级链」变成「可审计的分布式生命周期」）**
直觉：ROS2 的 lifecycle 节点、DDS QoS、action 的 goal/feedback/result/cancel、以及独立 executor，恰好把前几轮里抽象的"热替换、降级链、回执、硬实时"变成可落地的工程对象：50Hz 控制回路走专用实时 executor 与零拷贝组合；规划/VLA/LLM 走异步非实时节点；块执行用 action（feedback 即逐步回执，result 即块证书，cancel 即前缀截断）；降级链就是 lifecycle 的 deactivate/activate 迁移。但分布式引入了一个新敌人：**没有全局时钟**、默认 best-effort、QoS 不匹配会静默丢证据、网络分区会产生"本地看着新、因果上却缺依赖"的证据。于是第 3 轮的"证据陈旧"升级为**因果不完整**——块证书必须证明证据集在因果上覆盖了动作的全部依赖，而不能只证明它"时间戳较新"。

**灵感 3（两者耦合 → 画像条件化的部署会「自我确认」）**
直觉：画像选择交互拓扑 `τ`；拓扑决定采证频率、确认门槛与解释通道；而这些又反过来生成用于更新画像与校准覆盖的证据。这是一个**策略诱导的闭环选择**：系统可能"自信地把自己个性化到监督不足"，且因为每一步都有证书，表面上完全可审计。解法不是弃用画像或 ROS2，而是三根结构支柱：**拓扑闭包**（只能从有限、离线验证过的拓扑集中选，且物理包线对所有拓扑不变）、**因果完整证据**（HLC + 因果屏障 + QoS 安全契约）、**反操纵与可争辩画像**（显示风险不得低于校准风险；画像可被操作者检视、质疑、纠正，纠正不能直接提权），再叠加**画像分层共形 + ACI 覆盖债**与**两阶段全局静默**。

## 1. 研究问题（本轮要回答什么）

- **Q1（画像的安全性）**：用户画像能否成为"安全、非操纵、可争辩"的接口，而不是刻板印象与自动化自满的放大器？
- **Q2（分布式证据的正确性）**：在没有全局时钟的 ROS2/DDS 图里，"证据新鲜"的正确形式化是什么？如何在不引入集中时钟的前提下签发块有效性证书？
- **Q3（闭环的稳定性）**：当画像选择拓扑、拓扑又生成更新画像的证据时，这个反馈环在什么结构约束下保持校准与保守，而不是自我确认地滑向监督不足？

## 2. 三条设计原则（雏形，正式化见产物区定义 448–465）

**P1 拓扑闭包与单向授权（Topology Closure + One-sided Authority）**
运行时**绝不构造新节点图**；只能从有限、离线验证过的拓扑登记表 `𝕋` 中选择。选择映射对"能力证据"与"风险"是**单调**的：证据不足或风险升高只会选到更保守（监督更强、自主更低）的拓扑；物理包线与测量语义对所有 `τ ∈ 𝕋` 恒等。授权来自"挣得能力"的下置信界 `E_t`，自报画像与画像编辑都不能直接提升 `E_t`。

**P2 因果完整证据（Causal-Complete Evidence）**
回执携带混合逻辑时钟（HLC）/向量时钟；块证书只在证据集**因果覆盖**动作依赖 DAG、且相关主题满足 `Q_safe`（可靠、deadline、liveliness、持久化）时有效。跨节点切换前必须过**因果屏障**：所有节点确认已排空且 HLC 越过屏障。这把"时间上的新"替换为"因果上的全"。

**P3 反操纵与可争辩画像（Manipulation-free + Contestable Profile）**
显示给操作者的风险 `r̂` 必须不低于校准风险（禁止乐观框定）；解释映射对证据强度单调，画像只能改变语言/格式/详略，不能改变数值风险与建议阈值。画像证书（ProfileCert）签名、版本化、人类可读；操作者可检视、质疑、纠正事实字段，但纠正只能触发保守回退，不能直接提权。

## 3. 与基线的接口（如何退化）

- 画像缺失 / 损坏 / 有未决质疑 ⇒ 使用中性保守画像 `π₀*`，选择**无画像特化节点**的拓扑，语义等价于 InstructGauge 7C；
- ROS2 图不可用 / 时钟不可信 / 因果屏障超时 ⇒ 退回单进程模式与第 3 轮的本地静默点热替换（InstructGauge）；
- QoS 违约 / 分区 / 因果完整无法建立 ⇒ 冻结准入 ⇒ 回退最保守拓扑 ⇒ 必要时退回 ToolGauge 逐步执行；
- 画像分层样本不足 ⇒ 回退全局共形（InstructGauge SC-Cal）；
- PersonaGauge 失效 ⇒ InstructGauge；InstructGauge 失效 ⇒ ToolGauge；ToolGauge 失效 ⇒ LeanGauge；LeanGauge 失效 ⇒ MODGAUGE 原样。

画像与分布式部署都是增强项，不是依赖项（引理 59–66）。

## 4. 预期贡献

1. 一个"画像只选拓扑、不造能力"的**拓扑闭包**口径，把个性化注入面压到有限、可离线验证、可类型检查的范围内；
2. 一个"授权靠挣得"的**能力后验 + 下置信界**机制，给出误授权概率的可证明上界，直接对抗自动化自满与自报画像；
3. 一个**分布式因果块证书**：用 HLC、依赖 DAG 覆盖与 `Q_safe` 把"证据陈旧"升级为"因果不完整"，并给出含 deadline 与时钟偏斜的检测缺口界；
4. 一个**两阶段全局静默**协议，证明跨拓扑切换不产生"混合契约"，且降级时延有界；
5. 一个**反操纵投影 + 可争辩画像 + 注意力预算同意调度**的人因安全层，把"个性化"限制在只能更保守的方向；
6. 一条完整可证伪路径：E457–E472 覆盖拓扑闭包、误授权、因果完整性、QoS 违约、全局静默、有界降级、政策诱导覆盖、反操纵、注意力预算、可争辩性、实时性、分区注入与多人现场研究。

## 5. 本轮最大风险

**一句话**：画像条件化的部署会与分布式证据形成**自我确认闭环**——拓扑决定采什么证据，证据又反过来证明"当前画像与当前拓扑是对的"；一旦信任域或因果屏障设错，系统就可能以完全可审计的表象，把置信度沿"监督不足"的方向个性化错，而单看任何一块证书都发现不了。

## 2. 形式化定义（要点）

**定义 448（操作者状态与画像后验）** `θ = (skill, trust_cal, risk_tol, channel, fatigue) ∈ Θ`。画像为后验 `π_t(θ) ∝ L(receipts_{1:t} | θ)·π₀(θ)`，其中似然只由**已验证回执**（含成功/失败、纠错次数、复核命中）构成，不使用自报能力。`π₀` 仅来自声明画像或群体先验，并记录其熵 `H(π₀)`；熵高则自动偏向保守拓扑。

**定义 449（挣得能力与自主门）** 能力标量按验证结果维护 Beta 后验 `Beta(a_t,b_t)`；`E_t = LCB_β(Beta(a_t,b_t))`（`β` 分位下界）。自主升级仅当 `E_t ≥ e_hi ∧ n_t ≥ n_min ∧ H(π_t) ≤ H_max`；降级无条件允许。关键：**自报画像、画像编辑、重复确认都不能增大 `a_t`**——只有带独立证据的结果能。这给出"信任必须挣得"的可证伪形式。

**定义 450（画像证书与可争辩性）** `ProfileCert = (pid, ver, θ̂, U, evidence_ids, sig)`，`U` 为不确定度，`sig` 由 SROS2 密钥签发。`Contest` 允许操作者对事实字段提出质疑；质疑期间画像按 **保守化** 处理（`π ← conservative(π)`），且任何质疑/纠正都**不能**直接提升 `E_t`。纠正闭环与审计日志使画像可回溯、可复原、可反驳。

**定义 451（已验证拓扑）** `τ = (N, E, QoS, Λ, Π)`: `N` 为 ROS2 lifecycle 节点集，`E` 为 topic/action 边，`QoS` 为逐边策略，`Λ` 为 lifecycle 迁移表，`Π` 为离线证明义务（安全不变量、WCET、降级目标、物理包线恒等）。`𝕋` 有限且在部署前整体验证；运行时**禁止**动态建图。

**定义 452（拓扑闭包与单向选择）** `Sel: Θ × I × Risk → 𝕋 ∪ {⊥}`。公理：(i) **闭包**：`Sel` 值域 ⊆ `𝕋`，不存在"运行时新图"路径；(ii) **物理恒等**：`∀τ ∈ 𝕋, envelope(τ) = M_phys`，画像永远不能扩张可达动作集；(iii) **单调性**：若 `risk↑` 或 `E_t↓`，则 `Sel(·) ⊑_aut Sel_old`（新拓扑不更自主）；(iv) 声明画像只经 `π` 影响 `Sel`，不绕过 `E_t`。

**定义 453（两阶段全局静默 `q_quiesce^G`）** 切换拓扑前依次执行：①**冻结准入**（拒绝新 goal，置 epoch 屏障）；②**排空**（在途块 drain 到边界或按 CVC 前缀截断+补偿）；③**因果屏障**（所有节点 ack 且 HLC ≥ 屏障值，发布 `barrier_epoch`）；④**原子切换**（lifecycle deactivate/activate）；⑤**解冻**（携带新 epoch 恢复准入）。任一阶段超时 ⇒ 放弃切换并回退（定义 464）。

**定义 454（混合逻辑时钟与证据前沿）** 回执时间戳 `h = (l, c)`，更新 `l' = max(l, l_msg, l_recv)`、`c' = ...`（标准 HLC）。因果序 `a ≺ b` 由 HLC 字典序与因果投递共同判定；证据前沿 `F_t = max_{r∈R} h(r)`。**关键**：`F_t` 新只说明"收到的最大时间戳新"，不说明依赖 DAG 被覆盖——这正是要单独定义因果完整的原因。

**定义 455（因果完整证据集）** `R ⊨_c a` 当且仅当：对动作 `a` 依赖 DAG 中每个节点（前置状态、被影响量、契约版本、接地证据），存在 `r ∈ R` 因果后于该依赖的观测窗口；且不存在与 `r` 并发且被 `Q_safe` 视为冲突的回执；且所需主题全部满足 `Q_safe` 的 deadline/liveliness。**只有** `R ⊨_c a` 才允许该步进入证书的 `verified_prefix`。

**定义 456（分布式块证书）** `ChunkCert^D = (C, verified_prefix, R, F, qos_trace, d_slack, epoch)`；有效性谓词要求 `R ⊨_c a_{1:k}`（`k=verified_prefix`）、`d_slack ≥ 0`、`epoch` 与当前部署 epoch 一致、`qos_trace` 无违约。证书本身走 **TRANSIENT_LOCAL** 持久化，保证切换后可审计。

**定义 457（QoS 安全契约 Q_safe）** 安全相关主题（契约、块证书、接地证据、回执）必须 `RELIABLE + TRANSIENT_LOCAL(depth≥1) + LIFESPAN`；50Hz 控制链 `RELIABLE + DEADLINE(20ms) + LIVELINESS(automatic, lease)`；非安全遥测可 `BEST_EFFORT`。QoS 兼容性在拓扑装载时**静态检查**，不匹配即拒绝装载（与能力闭包同构的"契约闭包"）。镜像/分区时 `Q_safe` 违约 ⇒ 证书失效，绝不静默降级为"看起来成功"。

**定义 458（画像-指令分层）** `stratum(π,ι) = (autonomy(τ), goal_class(ι), #refs(ι), has_condition(ι))`。因 `τ` 依赖 `π`，采到的动作分布满足 `P(action|π) ≠ P(action)`——这是**策略诱导的协变量偏移**，比第 3 轮的指令分层选择偏差更强，必须单独记账。

**定义 459（覆盖债与自适应共形）** 顺序校准下维护 `α_t = α + γ(α − err_t)`（ACI 更新）与 `debt_cov = Σ_t (α − miss_t)_+`。保证长期平均覆盖 `(1/T)Σ_t cover_t ≥ 1−α−debt_cov/T`；拓扑切换或画像漂移触发 `debt_cov` 重置并重新校准。低样本 `s` 回退全局阈值；`debt_cov` 超限 ⇒ 保守化拓扑。

**定义 460（单向个性化偏序）** `θ ⊑_p θ'` 表示 `θ'` 在每一维上"更保守"（监督更强、自主更低、展示更细）。默认要求画像更新只沿 `⊑_p` 向保守方向移动；只有在 `E_t` 相对基线提升至少 `ΔE` 且持续 `m` 轮后，才允许单步向更自主方向移动，且仍受 `K_MAX(ι)` 与不可逆屏障约束（继承定义 440/445）。

**定义 461（无操纵解释投影）** 投影 `M_free: (evidence, π) → (r̂, e)` 受三条约束：(i) **不低报**：`P(r̂ ≥ r_cal) ≥ 1−α`（禁止乐观框定）；(ii) **单调**：`r_cal` 增大 ⇒ `r̂` 不减；(iii) **通道中立**：`π` 只能改变 `e` 的语言/格式/详略与确认通道，不能改变 `r̂` 的数值、建议阈值或"是否推荐执行"。满足三者称**无操纵**。

**定义 462（注意力预算同意调度）** 操作者单位时间可高质量处理的确认数为 `B_att`；式签字率 `ρ` 升高使单位确认的实际校验保真度 `f(ρ)` 下降，且有硬上限 `ρ ≤ ρ_max`。调度 `σ` 在 `Σ cost ≤ B_att`、`ρ ≤ ρ_max` 下最大化 `Σ_i ΔS_i·f(ρ)·x_i`（`ΔS_i` 为该确认的期望安全增益），超预算的请求转异步审批或默认保守执行。

**定义 463（PersonaRepairCert）** `PersonaRepairCert(s) = (ProfileCert, τ, ι, C, ChunkCert^D, receipts, claims, lifecycle_trace, Contest)`，使审计者能沿"画像后验 → 拓扑选择 → 指令 → 块 → 逐步回执 → 主张 → 生命周期"七级链复现一次修复，并检验每一步的单调性与无操纵性。

**定义 464（有界降级映射）** `Fallback(τ, f) = τ'`，`f ∈ {node_crash, deadline_miss, qos_violation, clock_skew>ε, profile_corrupt, partition}`，要求 `τ' ∈ 𝕋`、`τ' ⊑_aut τ`（**绝不更自主**）、且 `τ'` 为热备（已 configure 且可 `activate`）。`Fallback` 对故障类全定义，禁止"无映射"的悬挂状态。

**定义 465（画像信任域与漂移断路器）** 单次更新 `‖π_{t+1}−π_t‖_TV ≤ δ_π`，且 `KL(π_t‖π₀) ≤ D_max`。越界或连续 `q` 次残差超阈（继承定义 446 的分层漂移检测）⇒ 断路器：回退 `π₀`、强制最保守拓扑、要求重新挣得 `E_t`。

# IP-328 PPC：画像后验 + 挣得能力（自报只作先验，授权靠回执）
class ProfilePosterior:
    def __init__(self, declared):
        self.pi = make_prior(declared)        # 可含高熵、可争辩
        self.a, self.b = 1.0, 1.0             # 能力 Beta 后验，从零开始
        self.log = []

    def update(self, receipts, contest=None):
        if contest:                            # 质疑期：只保守化
            self.pi = conservative(self.pi)
        lik = self.likelihood(receipts)        # 只用已验证回执
        new  = normalize(self.pi * lik)
        if tv(new, self.pi) > DELTA_PI or kl(new, self.prior) > D_MAX:
            return self.quarantine()          # 断路器（定义 465）
        self.pi = new
        for r in receipts:                     # 只有独立证据能加 (a,b)
            if r.verified and r.independent:
                self.a += r.success; self.b += (1 - r.success)
        self.log.append((new, receipts))
        return new

    def earned_capability(self):
        return beta_lcb(self.a, self.b, BETA)  # E_t：下置信界

# IP-329 TCC：从已注册拓扑中做单向选择（绝不运行时建图）
class TopologyCompiler:
    def select(self, pi, iota, risk):
        autonomy_ok = (self.ppc.earned_capability() >= E_HI
                       and sample_n(pi) >= N_MIN
                       and entropy(pi) <= H_MAX)
        candidates = [t for t in T_REGISTRY if envelope(t) == M_PHYS]
        if not autonomy_ok:
            candidates = [t for t in candidates if t.autonomy <= AUT_SUPERVISED]
        t = max(candidates, key=lambda t: t.utility(pi, iota))
        return t if monotone_ok(t, pi, risk) else TOPO_SAFEST

# IP-330 LCS：两阶段全局静默 + 有界降级
class LifecycleSupervisor:
    def swap(self, new_tau):
        if not self.freeze_admission(epoch=BARRIER_EPOCH): return FALLBACK
        if not self.drain_blocks(timeout=T_DRAIN): self.abort_all(); return FALLBACK
        if not self.causal_barrier(timeout=T_BARRIER): return self.fallback("clock_skew")
        self.deactivate(self.active); self.activate(new_tau)   # 原子切换
        self.unfreeze(new_tau.epoch)
        return True

    def on_fault(self, f):
        tau2 = Fallback(self.active, f)        # 预注册、绝不更自主、热备
        return self.swap(tau2)

# IP-331 CDC：因果完整的块提交
class DistributedCVC:
    def commit(self, C, env, iota):
        t, R = 0, []
        while t < len(C.actions):
            pre = env.snapshot()
            ok  = (C.joint_pre(pre) and still_grounded(iota, env)
                   and drift(pre, C.pred[t]) <= C.delta_c)
            if not ok: break
            env.apply(C.actions[t])
            r = env.receipt(t)                 # 带 HLC 的回执
            R.append(r)
            if not (causal_complete(R, C.actions[t])   # R ⊨_c a_t
                    and qos_satisfied(r.topic_qos, Q_SAFE)
                    and r.deadline_slack >= 0):
                break                          # 只保留已验证前缀
            t += 1
        return C.truncate(t), ChunkCertD(C, t, R, frontier(R), qos_trace(R), epoch=EPOCH)

# IP-332 PS-Cal：画像分层 + ACI 覆盖债
class ProfileSCCal:
    def threshold(self, pi, iota):
        s = stratum(pi, iota)
        if len(CAL[s]) < N_MIN:
            s = GLOBAL
        q = conformal_quantile(CAL[s], alpha=self.alpha_t)
        self.debt += max(0.0, ALPHA - self.last_covered)
        if self.debt > DEBT_MAX:
            self.demand_conservative_topology()
        return q

    def observe(self, covered, alpha=ALPHA, gamma=GAMMA):
        err = 0.0 if covered else 1.0
        self.alpha_t = min(1.0, max(0.0, self.alpha_t + gamma * (alpha - err)))
        self.last_covered = covered

# IP-333 AMP：无操纵投影（只改通道，不改数值风险）
def free_display(evidence, pi):
    r_cal = calibrated_risk(evidence)          # 来自共形
    r_hat = max(r_cal, conservative_lcb(evidence))   # 不低报
    style = style_for(pi)                      # 语言/格式/详略
    return r_hat, render(evidence, style)     # 数值与建议阈值不变

# IP-334 ABC：注意力预算下的确认调度（贪心，子模下 (1-1/e)）
def schedule_confirmations(requests, B_att, rho_max):
    reqs = sorted(requests, key=lambda q: q.delta_s / q.cost, reverse=True)
    chosen, spent, rho = [], 0.0, 0.0
    for q in reqs:
        if spent + q.cost > B_att or rho + q.rate > rho_max: continue
        chosen.append(q); spent += q.cost; rho += q.rate
    return chosen, [q for q in requests if q not in chosen]   # 其余转异步

# IP-335 8C 闭环：I → P → H → C → E(chunk) → C → V → U
def personagauge_8c(M, s, ell):
    ok, iota = M.nlib.ground(ell, M.scene, M.ontology)
    iota = iota if ok else M.default_iota
    tau  = M.tcc.select(M.ppc.pi, iota, M.risk(s))        # 拓扑闭包选择
    if not M.lcs.ensure_active(tau):                      # 有界降级
        return M.instructgauge_7c(M, s, ell)               # 严格退回 7C
    H = M.lbox.hypothesize(s, M.dbox.R[s], iota)
    C = M.iac.plan_chunk(iota, H, tau.tools, M.budget_left(s), M.drift_bound(s))
    C, cert = M.dcvc.commit(C, M.env, iota)               # 因果完整提交
    if cert.verified_prefix == 0:
        return stub_and_red(s, "causal_incomplete")
    q = M.pscal.threshold(M.ppc.pi, iota)                 # 画像分层阈值
    mu, Sig = M.apcal.calibrate(cert.receipts, H, s)
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
        return stub_and_red(s, "cross_failed")
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s)
    if not contract_regression(new_ec):
        return stub_and_red(s, "regression")
    M.lcs.swap_at_global_quiescence(M.dpe, new_ec)         # 两阶段静默
    M.ppc.update(cert.receipts, M.contest)                # 画像后验更新
    M.amp.free_display(cert, M.ppc.pi)                    # 无操纵解释
    M.abc.schedule(cert.pending_confirmations, B_ATT, RHO_MAX)
    return PersonaRepairCert(M.ppc.cert, tau, iota, C, cert,
                             cert.receipts, bind_claims(cert, iota), M.lcs.trace)

# IP-335 主循环：RT 路径与规划路径隔离（50Hz 不变）
def PersonaGauge_round(M, obs, audio, tac, depth, det, ell=None):

    return MODGAUGE_round(M, obs, audio, tac, depth, det)  # RT executor，零拷贝

## 4. 推导

**引理 59（拓扑闭包的代码级安全）** 若 `Sel` 满足定义 452 的四条公理、`𝕋` 中每个 `τ` 均通过离线证明义务 `Π`，则任意一次部署的可达动作集满足 `Act(τ) ⊆ Act(Plan_ToolGauge)` 且物理包线 `= M_phys`；运行时构造未验证图的概率为 0。*证明*：`Sel` 值域 ⊆ `𝕋`，闭包公理排除动态建图；`envelope(τ)=M_phys` 使画像无法扩张幅值/工具；`Π` 含安全不变量与 WCET，故部署即继承证明。与第 3 轮引理 51 同构，但把"指令不能造能力"提升为"**画像不能造部署**"。

**引理 60（挣得授权的误授上界）** 设 `E_t` 为真实能力 `p` 的 `β` 下置信界，样本独立。若仅在 `E_t ≥ e_hi` 时授予自主，则对真实能力 `p < e_hi` 的操作者，误授权概率 `P(E_t ≥ e_hi) ≤ β`（在门限处取等号上界），且随 `n_t` 增大单调趋 0。相对"自报画像直接授权"，误授权率由 `P(自报高估)` 降为 `≤ β`。*证明*：下置信界的定义直接给出 `P(p < LCB_β) ≤ β`；事件 `{E_t ≥ e_hi}` 且 `p < e_hi` 蕴含 `p < E_t`，故概率受 `β` 夹住。推论：**重复确认、自我声明都不进入 `(a_t,b_t)`**，因此无法通过"刷信任"提权。

**引理 61（分布式因果块证书的安全性）** 若动作语言前缀封闭、逐步安全盾归纳、`δ_c` 不小于单步最大漂移，且每一步进入 `verified_prefix` 前满足 `R ⊨_c a_t` 与 `Q_safe`，则已提交前缀每步保持 `Inv`；分布式检测缺口 ≤ `D_deadline + ε_clock + δ_t`，其中 `D_deadline` 为最坏 QoS deadline、`ε_clock` 为最大时钟偏斜。*证明*：对 `t` 归纳。因果完整保证用于判定 `φ_pre` 与漂移的证据**因果后于**被判定动作的依赖，排除"并发更新导致的前置已被破坏但本地未收到"这一新失效模式；`Q_safe` 排除静默丢证据；超时即停在前缀，前缀封闭保证截断后仍是合法程序。与引理 52 相比，缺口从"一个控制拍"扩为"deadline+偏斜+拍"，但**不随块长 K 增长**。

**引理 62（两阶段全局静默无混合 epoch）** 若切换严格按定义 453 的五阶段执行，则不存在任何节点在 `epoch` 切换期间同时观察到新旧契约；且冻结时长 `≤ T_drain + T_barrier`。*证明*：①冻结后新 goal 被 epoch 屏障拒绝；②排空保证在途块要么到边界、要么按 `verified_prefix` 截断；③因果屏障保证所有节点 HLC 与 ack 覆盖切换点，任何旧 epoch 消息的 HLC 都 `< barrier` 而被丢弃；④切换在屏障之后、解冻之前原子发生。故不存在跨 epoch 的混合观测。这是引理 57 的分布式强化：把"本地静默"升级为"因果全局静默"。

**引理 63（有界降级）** 对任一单故障类 `f`，监督器在 `L_live + T_sw` 内到达 `Fallback(τ,f)`，其中 `L_live` 为 liveliness lease、`T_sw ≤ ε_clock + T_activate`；因 `Fallback` 目标为热备，`Activate` 不含冷启动，故 RT 路径的不可用间隙 `< 20ms`。*证明*：`Q_safe` 的 liveliness/deadline 违约触发有限时延检测；`Fallback` 对全故障类有定义且 `⊑_aut`（定义 464）排除"降级到更自主"；热备已 configure 故只需 activate。结合引理 62，切换不产生混合契约。

**引理 64（政策诱导偏移下的分层覆盖）** 设层 `s` 内可交换、层间因 `τ(π)` 选择而偏移，则分层覆盖 `P(h*∈H_s|s) ≥ 1−α−debt_cov/T`；边缘覆盖 `P(h*∈H_s) ≥ 1−α − Σ_s π_s·TV_s − debt_cov/T`。若**不**分层而池化校准，存在策略构造使某层覆盖任意低（选择效应把该层的残差分布整体搬移）。*证明*：层内可交换给标准共形；ACI 更新使长期平均误差趋于 `α`，累积偏差记账为 `debt_cov`；池化反例由"选择只发生在某层"的构造给出。这是引理 55 的强化：偏移来源从"指令选择"变为"**部署选择**"，故必须按含 `autonomy(τ)` 的 stratum 校准。

**引理 65（无操纵显示与注意力分配）** 若投影满足定义 461 的 (i)(ii)(iii)，则对任意真实证据，`r̂ ≥ r_cal`（以 `1−α` 概率），且操作者基于显示做出的期望损失不低于基于真实风险时的损失（不产生"被乐观框定诱导的额外顺从"）。在 `ΔS_i` 子模、成本可加时，定义 462 的贪心调度达到 `(1−1/e)` 近似最优，且 `ρ ≤ ρ_max` 保证保真度下界 `f(ρ_max)`。*证明*：(i) 直接给出不低报；(ii)(iii) 排除"用画像调低数值风险或建议阈值"的操纵通道，故显示的决策等价于在真实风险上叠加非负保守偏差；贪心的 `(1−1/e)` 来自子模最大化标准结论；速率上限约束保证 `f` 不低于 `f(ρ_max)`。

**引理 66（实时隔离与 50Hz 保全）** 将 50Hz 路径放在专用 RT executor 的 `MutuallyExclusive` 回调组、规划/VLA/LLM 放在独立非 RT executor，且传感路径用 intra-process 零拷贝组合，则 RT 路径 WCET 与第 3 轮引理 50 相同；新增的 HLC 打戳、因果完整性检查与证书序列化开销 `< 0.1ms/周期`；`Q_safe` 的 `DEADLINE(20ms)` 使违约可观测而非静默。*证明*：RT 与规划路径无共享可变状态（快照传递）；HLC 为 O(1) 标量运算，因果检查为 O(|R|) 且 `|R| ≤ K_MAX`（小常数）；零拷贝去除序列化，故新增开销为常数项，不改变硬实时上界。

## 8. 本轮最大风险

**一句话**：`Sel(π,ι)` 让画像选择部署拓扑、拓扑又生成用于更新 `π` 与校准覆盖的证据，形成**自我确认闭环**；加之 ROS2/DDS 的因果不完整证据可能"本地新鲜、因果残缺"，若信任域 `δ_π`、漂移断路器或因果屏障任一处设定过松，系统就会以每一步都可审计的表象，把置信度沿"监督不足"方向个性化错——单看画像、单看证书、单看 QoS 任一视角都无法发现，只有把七级证据链联合审计并主动注入故障（E460/E462/E470/E471）才能证伪。
