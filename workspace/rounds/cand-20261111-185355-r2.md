# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「预训练」×「状态机」）

> 第 54 轮把技能组合提升为动作-鲁棒性双证书（α_S, ρ, A_cert, γ_ce）。但 α_S 与 ρ 都是「无状态」的：它们假设技能在任意时刻只由当前动作决定，既忽略技能内部的时序状态，也忽略技能证书的「出身」。本轮用 **预训练** 引入证据来源与分布偏移，用 **状态机** 引入时序契约，把技能从 `(α_S, ρ_S)` 升级为 `(α_S, ρ_S, M_S, P_cert)`。核心矛盾：H22：动作空间兼容 ≠ 状态兼容，前驱技能的后置状态可能不满足后继技能的前置守卫，组合在动作层可行、在状态层断裂；H23：预训练得到的守卫只在预训练支持集上有校准意义，部署分布偏移会让守卫「看起来通过、实际失效」。

## 0. 直觉与动机

**灵感 1（预训练 → 证书必须带「出身」）**
直觉：一个技能的 ρ 与守卫阈值，本质上是「在预训练分布 D_pre 上校准出来的条件结论」。脱离 D_pre 谈 ρ=0.9 没有意义。因此证书应显式携带 `P_cert = (D_pre, support(γ_pre), Δ_shift, κ_guard)`：`γ_pre` 是支持集覆盖度，`Δ_shift` 是预训练分布与部署分布的散度，`κ_guard` 是守卫的共形覆盖率。预训练既是证据来源，也是最大负债：**分布一漂移，证书不是变差，而是静默失效却仍能通过检查**。

**灵感 2（状态机 → 把动作兼容升级为状态兼容）**
直觉：`compat(S_i,S_j) ≥ θ_a` 只说明两者动作空间有交集，不保证 `S_i` 的后置状态落在 `S_j` 的前置守卫内。技能应建模为带守卫的有限状态机 `M_S = (Q_S, Σ, δ_S, q0, F, G)`，`G` 是守卫裕度。组合不再只是组合图最短路，而是 **乘积自动机的可达性**：`M_{S1} × … × M_{Sk} × A_T` 上是否存在守卫全部通过、鲁棒性全部达标的接受路径。这是对 v31 隐含漏洞的直接修补。

**灵感 3（从预训练网络里「抽」出可验证自动机）**
直觉：预训练策略是黑箱，但它的隐状态编码 `φ_S` 天然给出状态划分。用双模拟（bisimulation）/因果状态构造做抽象，得到有限自动机 `M_S`，并给出抽象误差 `ε_S`（双模拟伪距离）。神经先验与形式验证在此接上：**编码器负责「状态是什么」，自动机负责「状态怎么走、什么时候允许走」**。

**灵感 4（状态别名是最大的隐蔽失败）**
直觉：最危险的不是守卫报错，而是两个隐状态在编码器看来几乎一样、在稀有动作下行为却不同。此时抽象层守卫检查「通过」，真实层语义已错位——这就是 **状态别名（state aliasing）**。必须显式度量 `alias(S,T) = max_q d_b(q, μ(q))` 并设绊线，否则乘积自动机的接受路径只是抽象层的幻觉。

**灵感 5（金字塔再加一层）**
直觉：在 v31 动作-协同层之上加 **L0.6 预训练-状态层**：跨层证书沿自动机转移逐步合成，每一步同时携带来源 `P_cert`、守卫裕度 `τ_guard`、抽象误差 `ε_S` 与别名风险 `alias`，形成「来源—抽象—守卫—鲁棒」四级可追溯链。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（预训练技能状态机 PSSM）**
预训练技能 `S` 由策略 `π_S` 与隐状态编码器 `φ_S: O → Z` 给出。其抽象状态机
`M_S = (Q_S, Σ_S, δ_S, q_S^0, F_S, G_S, ε_S)`：
- `Q_S ⊆ 2^Z` 为 φ_S 诱导的有限状态划分；
- `δ_S: Q_S × Σ_S → Q_S` 为抽象转移；
- `q_S^0` 初始状态，`F_S ⊆ Q_S` 接受状态；
- `G_S: Q_S × Σ_S → [0,1]` 为守卫裕度（转移可执行程度的连续打分）；
- `ε_S = max_{q∈Q_S} d_b(q, φ_S^{-1}(q))` 为抽象的双模拟误差上界。

**定义 122（行为等价与双模拟距离）**
状态 `q, q'` 在阈值 `ε` 下行为等价，记 `q ~_ε q'`，当且仅当对任意长度 ≤ L 的动作序列 `σ`，其观测分布满足 `d_TV(P(o|q,σ), P(o|q',σ)) ≤ ε`。双模拟距离 `d_b` 为该等价关系对应的最大不动点伪度量。跨技能对齐映射 `μ_{S,T}: Q_S → Q_T` 称为 **ε-一致**，当且仅当 `∀q∈Q_S, q ~_ε μ_{S,T}(q)`。

**定义 123（预训练来源证书）**
`P_cert(S) = (D_pre(S), γ_pre, Δ_shift, κ_guard)`：
- `γ_pre = P_{D_pre}(state ∈ support(φ_S))` 支持集覆盖；
- `Δ_shift = d_f(D_pre, D_deploy)` 为 f-散度意义下的分布偏移；
- `κ_guard ∈ [0,1]` 为守卫的共形覆盖率（见定义 125）。
证书只在 `Δ_shift ≤ Δ_max` 且 `γ_pre ≥ γ_min` 时被视为有效。

**定义 124（乘积自动机与组合可行性）**
给定技能 `S_1…S_k` 与任务规约自动机 `A_T`（描述动作/状态时序约束），乘积自动机
`M_⊗ = M_{S_1} × … × M_{S_k} × A_T`，状态为元组 `(q_1,…,q_k,q_T)`，转移守卫取交集：
`G_⊗ = min( min_i G_{S_i}, G_T )`。
组合 **可行** 当且仅当存在从初态到接受态的路径 `π`，使 `∀t: G_⊗(π_t) ≥ θ_g` 且 `∀d: ρ_{π_t}(d) ≥ ρ_min` 且 `∀t: alias_t ≤ ε_alias`。

**定义 125（守卫共形裕度）**
对每条转移，取校准集 `C = {(x_j, y_j)}` 抽自 `D_pre`（带偏移重加权），令 `τ_guard` 为校准非一致性分数的 `⌈(1-α)(|C|+1)⌉/|C|` 分位数。则对部署分布上的新状态，`P(G_S ≥ τ_guard) ≥ 1-α-Δ_shift·Lip(G)`（有限样本、分布偏移修正下成立）。

**定义 126（状态别名风险）**
`alias(S,T) = max_{q∈Q_S} d_b(q, μ_{S,T}(q))`，并在组合路径上取 `alias_π = max_t alias(π_t)`。若 `alias_π > ε_alias`，则判定组合存在状态别名，**无论动作兼容性多高都拒绝部署**。

**定义 127（预训练-状态联合证书 C_PS）**
`C_PS = (M_S, α_S, ρ, P_cert, μ, alias_π, τ_guard, evidence)`，其中 `evidence` 至少含：抽象校准日志、共形校准集摘要、别名审计反例、部署分布偏移估计。部署可接受 当且仅当：
```
Δ_shift ≤ Δ_max ∧ γ_pre ≥ γ_min ∧ alias_π ≤ ε_alias
∧ min_d ρ(d) ≥ ρ_min ∧ τ_guard ≥ θ_guard
```

## 2. 关键算法 伪代码

### IP-121 PSSM（Pretrained Skill State Machine 抽取）

```python
def extract_pssm(policy, encoder, D_pre, n_states, eps_b):
    # 1) 用隐状态划分 + 因果合并得到抽象状态
    Z = [encoder(o) for o in sample(D_pre)]
    Q = bisimulation_partition(Z, n_states, eps_b)      # 双模拟聚类
    # 2) 估计抽象转移与守卫裕度
    delta, guard = {}, {}
    for q in Q:
        for a in Sigma:
            nxt = transition_distribution(policy, q, a)
            q2 = argmin_{q' in Q} d_b(nxt, q')
            delta[(q,a)] = q2
            guard[(q,a)] = margin(policy, q, a)
    eps_S = max(bisim_distance(q, phi_inverse(q)) for q in Q)
    return PSSM(Q, Sigma, delta, q0=Q[0], F=accepting(Q),
                G=guard, eps=eps_S)
```

### IP-122 BISA（Bisimulation Alignment）

```python
def align_states(M_S, M_T, eps_b):
    # 求解跨技能双模拟对齐 μ 与别名风险
    mu, alias = {}, 0.0
    for q in M_S.Q:
        cand = min(M_T.Q, key=lambda q2: d_b(q, q2))
        mu[q] = cand
        alias = max(alias, d_b(q, cand))
    return mu, alias
```

### IP-123 CGUARD（Conformal Guard Calibration under Shift）

```python
def calibrate_guards(M_S, D_pre, D_deploy, alpha, reweight=None):
    scores = []
    for x, y in calibration_stream(D_pre):
        w = 1.0 if reweight is None else reweight(x, D_pre, D_deploy)
        scores.append((w, nonconformity(M_S.G, x, y)))
    # 加权共形分位数（偏移修正）
    tau = weighted_quantile(scores, 1 - alpha)
    delta_shift = f_divergence(D_pre, D_deploy)
    return tau, delta_shift
```

### IP-124 PAS（Product Automaton Search）

```python
def product_search(skills, A_T, theta_g, rho_min, eps_alias):
    M = reduce(product, [s.M for s in skills] + [A_T])
    for (q_tuple, G, rho, alias) in lazy_states(M):
        if G < theta_g or min(rho.values()) < rho_min or alias > eps_alias:
            continue                                    # 守卫/鲁棒/别名剪枝
        if accepting(M, q_tuple):
            return ('feasible', reconstruct_path(M, q_tuple))
    return ('infeasible', None)
```

### IP-125 PSCERT（Pretrain-State Joint Certificate）

```python
def build_certificate(path, M_seq, P_cert_seq, mu_seq):
    rho = compose_robustness_chain([s.rho for s in M_seq], K)
    alias_pi = max(alias(prev, cur) for prev, cur in mu_seq)
    tau = min(tau_guard_of(m) for m in M_seq)
    if alias_pi > eps_alias:
        return ('reject', 'state_aliasing', alias_pi)
    if any(p.delta_shift > DELTA_MAX or p.gamma_pre < GAMMA_MIN
           for p in P_cert_seq):
        return ('reject', 'provenance_shift')
    if min(rho.values()) < rho_min or tau < theta_guard:
        return ('reject', 'robustness_or_guard')
    return ('ok', C_PS(M_seq, rho, P_cert_seq, mu_seq, alias_pi, tau))
```

### IP-126 ALIAS（Aliasing Tripwire / 别名审计）

```python
def alias_audit(M_S, M_T, mu, eps_alias, probe_actions):
    # 用稀有动作做红队探针，检验抽象层"等价"是否在真实层破裂
    for a in probe_actions:
        for q in M_S.Q:
            if d_b(behave(M_S, q, a), behave(M_T, mu[q], a)) > eps_alias:
                return ('tripwire', q, a)     # 立即否决，不进入组合搜索
    return ('ok',)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| PSSM | O(|D_pre|·|Σ|·|Q|·d_b) | O(|Q|·|Σ|) | 双模拟划分收敛、ε_S 有界 |
| BISA | O(|Q_S|·|Q_T|·L) | O(|Q_S|) | μ 一致、d_b 是伪度量 |
| CGUARD | O(|C|·(log|C|+d)) | O(|C|) | 加权共形分位数、偏移有界 |
| PAS | O(|Q_⊗|·|Σ|·log|Q_⊗|) | O(|Q_⊗|) | 守卫剪枝 sound、别名剪枝 sound |
| PSCERT | O(k·|Q| + |𝔇_ρ|) | O(k+|Q|) | 五项预算闭合、证书 sound |

**正确性定理（Pretrain-State Composition Soundness）**
假设 v31 的 (A26)–(A28) 成立；**(A29)** 每个 `M_S` 与真实动力学 `ε_S`-双模拟等价；**(A30)** 守卫共形校准在偏移 `Δ_shift` 下有 `κ_guard ≥ 1-α-Δ_shift·Lip(G)`；**(A31)** 跨技能对齐映射 `μ` 在路径上 `alias_π ≤ ε_alias`。则对长度 k 的组合路径：
```
P_fail ≤ Σ_{t=1..k} [ (1 - ρ_min) + ε_{S_t} + α_t + Δ_shift,t·Lip(G) ]
         + P(alias_π > ε_alias)
```
即 `P_success ≥ 1 - 上式`。关键含义：**失败率可逐转移归因**，每一项都对应一个可测护栏（ρ→鲁棒谱，ε_S→抽象误差，α_t→共形风险，Δ_shift→来源证书，alias→别名审计）。任一护栏失守，证书直接拒绝，而不是继续"乐观组合"。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 抽象状态机非忠实（ε_S 失控） | 高 | 双模拟度量 + 增加状态数 + 反例驱动细化 |

## 6. 本轮最大风险

**一句话**：预训练-状态机方案把技能证书从「动作-鲁棒」升级为「来源-抽象-守卫-鲁棒」四级可追溯，但其 soundness **押在「从预训练网络抽出的 M_S 是真实动力学的忠实抽象」这一前提上**；一旦双模拟抽象把行为可分但观测相似的状态合并（状态别名），抽象层守卫全部通过、真实层却静默违约并触发负迁移，故必须以 **双模拟感知的抽象 + 偏移加权共形守卫 + 别名绊线强制否决** 三重护栏，宁可判为不可部署，也绝不把抽象层的「接受路径」当成现实可执行性。

```python
        w = 1.0 if reweight is None else reweight(x, D_pre, D_deploy)
        scores.append((w, nonconformity(M_S.G, x, y)))
    tau = weighted_quantile(scores, 1 - alpha)
    delta_shift = f_divergence(D_pre, D_deploy)
    return tau, delta_shift
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PSSM | O(|D_pre|·|Σ|·|Q|·d_b) | O(|Q|·|Σ|) | 双模拟划分收敛，ε_S 有界 |
| BISA | O(|Q_S|·|Q_T|·L) | O(|Q_S|) | μ 一致，d_b 伪度量 |
| CGUARD | O(|C|·(log|C|+d)) | O(|C|) | 加权共形覆盖 ≥ 1-α-偏移项 |
| PAS | O(|Q_⊗|·|Σ|·log|Q_⊗|) | O(|Q_⊗|) | 守卫/鲁棒/别名三重剪枝 sound |
| PSCERT | O(k·|Q|+|𝔇_ρ|) | O(k+|Q|) | 五项预算闭合，证书 sound |

**正确性定理（Pretrain-State Composition Soundness）**
假设 v31 的 (A26)–(A28) 成立；**(A29)** `M_S` 与真实动力学 `ε_S`-双模拟等价；**(A30)** 守卫共形覆盖率 `κ_guard ≥ 1-α-Δ_shift·Lip(G)`；**(A31)** 路径别名 `alias_π ≤ ε_alias`。则长度 k 的组合路径：
```
P_fail ≤ Σ_{t=1..k} [ (1 - ρ_min) + ε_{S_t} + α_t + Δ_shift,t·Lip(G) ]
         + P(alias_π > ε_alias)
P_success ≥ 1 - P_fail
```
关键：**失败率逐转移可归因**；ρ→鲁棒谱、ε_S→抽象误差、α_t→共形风险、Δ_shift→来源证书、alias→别名审计。任一护栏失守，证书直接拒绝，禁止乐观组合。
