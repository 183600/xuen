# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「最优控制」×「行为树」）

> 第 54 轮已把技能组合提升为"动作-鲁棒性双证书"（α_S、C_comp、J），并用云边重剖分闭环处理动作对齐。但它没有回答一个更基本的问题：**在每一时刻应当 tick 哪个行为、凭什么是这个而不是另一个**。第 54 轮的 `cost_align` 是手工权重，A* 的启发式是经验函数，只在离散路径上"看起来最优"、缺乏代价语义。本轮用 **最优控制** 提供"硬通货"——代价-to-go 值函数 V；用 **行为树** 提供反应式、可组合、可解释的控制器结构，提出 **OC-BT（Optimal-Control-Backed Behavior Tree）**：节点即 option、tick 即 Bellman 备份、云边即离线策略改进 / 在线策略评估的分离。核心矛盾：H22：图搜索只在离散路径上最优，无法刻画 Running 的时序抽象与反应式切换；H23：行为树的节点选择缺乏代价语义，Fallback 的失败解释与第 53 轮鲁棒性谱 ρ 未打通。

## 0. 直觉与动机

**灵感 1（最优控制给"选择"定价 → 值函数把 BT 从启发式变成策略）**
直觉：第 54 轮 SCOM 的边权 `cost_align` 是手工权重，路径"看起来最优"。若为每个行为节点标注 **代价-to-go `V_n(s)`**，则"选哪个子节点"不再是阈值规则，而是 **Bellman 备份** `n*(s)=argmin_{c∈child(n)} Q_c(s)`，`Q_c(s)=ℓ(s,c)+γ·V_c(s')`。BT 于是成为 **值一致策略 `π_BT`**，其与最优策略的差距可用 **Bellman 残差 `δ_n(s)=|V_n(s)-Backup_n(s)|`** 定量，而不是"经验上更好"。顺带，A* 的 `cost_align` 可替换为 **松弛问题的最优代价-to-go**，把第 54 轮的"路径最优"从经验升级为可证明可采纳（admissible）的启发式。

**灵感 2（行为树的控制流 = 天然的失败解释结构）**
直觉：Sequence/Fallback/Parallel 的返回状态本身就是一棵 **解释树**：Fallback 失败 ⇔ 所有子节点失败且各自保留原因；Sequence 失败 ⇔ 某个前缀成功、某个子节点失败。第 53 轮的 Explain 此前是自由文本根因，现在可被 BT 结构锚定为 `Explain_BT=(node_id, status, child_failures, V_gap)`——**反向解释由控制流结构化生成**，可直接驱动云端重规划与第 54 轮的 `reprofile`。这把"可解释性"从附加物变成 BT 语义的一部分。

**灵感 3（Running = 时序抽象 → BT 是 semi-MDP 的 option 集合）**
直觉：BT 的 `Running` 状态对应一个 **持续执行的行为**（option / SMDP 的 temporally-extended action），其值满足带 **期望驻留时间 `τ_o`** 的 Bellman 方程 `V_o(s)=ℓ_o(s)+E[γ^{τ_o}V_o(s')]`。于是第 54 轮的"技能组合图 `G_S`"被 **option 图 `G_o`** 取代：一条组合路径是一个 option 序列，组合代价是 SMDP 最优代价，`c_trans` 变为驻留时间惩罚。图搜索成为 SMDP 动态规划的特例，组合"可判定性"升级为"Bellman 一致性 + 驻留时间有界"。

**灵感 4（云边 = 策略改进 / 评估的分离 → value-gap 证书）**
直觉：云端算力强，负责 **离线策略改进**（BT 结构搜索、粗值 `V_c`）；边端实时，负责 **在线策略评估与 tick**（细值 `V_e`、守卫判定）。二者用 **值差 `δ_V=|V_c∘φ - V_e|`**（相对值差衡量"抽象税"）联结。若 `δ_V` 超预算 `Θ_V`，说明云端粗抽象在边端失效（对应第 54 轮的 `δ_a` 动作对齐误差，现在是"值对齐误差"）。云边闭环变为 `云端改进 V_c → 边端评估 V_e → 值差回传 → 云端重抽象/重分解`，与"重剖分"同构，但度量从动作空间换成值空间。

**灵感 5（安全装饰器 = 控制不变集 → BT + CBF/MPC 的分层保证）**
直觉：BT 负责离散模式切换，连续底层由 **MPC/最优控制** 跟踪；BT 守卫可绑定 **控制屏障函数 h** 与 **viability kernel**，形成 `Safe(h,γ)` 装饰器：当 `h(s)<-η` 时该子树不可 tick。这样 BT 的"安全"不靠人工条件，而靠 **不变集证书**；并与第 53 轮 ρ 对接：`ρ_S(d)` 可重定义为值函数对维度 d 扰动的敏感度 `sup|∂V/∂d|`——**鲁棒性 = 值函数的光滑性**。安全、鲁棒、最优在同一个 V 上统一。

**灵感 6（图搜索的最优性补贴 → 可采纳启发式的证书化）**
直觉：A* 在 `G_o` 上搜索的启发式 h(n) 若取"松弛系统的最优代价-to-go"，则 h 可采纳且一致（consistent），路径最优性有证书。这把第 54 轮"发现率 ≥ 90%"的经验指标，替换为"最优性 gap ≤ ε_opt"的可证明指标，并可在值差回传时**在线收紧**启发式。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（行为树与 tick 语义）**
行为树 `BT=(N, root, child, type, guard)`，`type∈{Seq, Fall, Par, Dec, Leaf}`。节点返回 `status∈{S, R, F}`（Success / Running / Failure）。tick 递归定义：
```
tick(Seq,[c1..ck],s): 逐个子 tick，遇 F 返回 F，遇 R 返回 R，全 S 返回 S
tick(Fall,[c1..ck],s): 逐个子 tick，遇 S 返回 S，遇 R 返回 R，全 F 返回 F
tick(Dec,c,s): guard(s) 为假则返回 F，否则 tick(c,s)
tick(Leaf,s): 执行动作 a=π_leaf(s)，返回 S/F（瞬态）或 R（持续）
```
BT 是**确定性、反应式**的：每 tick 重新评估 guard 与选择，不缓存未经声明的历史。

**定义 122（值标注行为树与 Bellman 一致性）**
每节点 n 有代价-to-go `V_n:S→R≥0`，叶子 `Q_a(s)=ℓ(s,a)+γE[V_n(s')]`。控制节点按语义合成：`Fall` 取可行子节点上的 `min`；`Seq` 取 `V_left + γ^{τ}V_right`（成功后接续，τ 为切换耗时）。Bellman 残差 `δ_n(s)=|V_n(s)-Backup_n(s)|`，`Backup` 为对应 type 的 Bellman 右端。若 `sup_s δ_n(s) ≤ ε`，称 BT 为 **ε-Bellman 一致**。

**定义 123（BT-Option 与驻留时间）**
`Running` 子树 o 是一个 option `(I_o, π_o, β_o)`：`I_o` 启动集、`π_o` 由子树 tick 诱导、`β_o` 为终止（返回 S/F）。其值满足 `V_o(s)=ℓ_o(s)+E[γ^{τ_o}V_o(s')]`，`τ_o` 为驻留时间。option 图 `G_o=(V_o,E_o)`，边权 `c_o=(E[τ_o], E[cost_o])`。第 54 轮 `G_S` 是 `G_o` 在 `τ_o→1` 的退化。

**定义 124（值差 / 抽象税）**
粗化映射 `φ:S→S_c`。云端粗值 `V_c` 与边端细值 `V_e` 的值差 `δ_V(s)=|V_c(φ(s))-V_e(s)|`，相对值差 `δ_V^rel = E_{s∼d_{π_BT}}[δ_V]/E[V_e]`。若 `δ_V^rel ≤ Θ_V`，称云边**值对齐**。

**定义 125（安全 / viability 装饰器与鲁棒谱统一）**
`Safe(h,γ)` 装饰器使子树仅在 `h(s) ≥ -η` 时 tick，h 为控制屏障函数，超水平集 `K_γ={s:h(s)≥-η}` 在 `π_o` 下前向不变。viability 证书 `V_iab=(h,η,γ)`。第 53 轮鲁棒谱重定义为值敏感度：`ρ_S(d)=1/(1+L_d)`，`L_d=sup_s|∂V/∂d|`（越大越不敏感、越鲁棒），与旧 ρ 通过单调映射对照校准。

**定义 126（OC-BT 联合证书）**
`J_BT=(V, δ_V^rel, ρ, A_cert, V_iab, Explain_BT)`，部署判定：
```
deploy(J_BT) = [δ_V^rel ≤ Θ_V] ∧ [sup_n δ_n ≤ ε] ∧ [V_iab 成立]
               ∧ [ρ ≥ ρ_min] ∧ [dom(A_cert)=in]
```
`Explain_BT=(node_id, status, child_failures, V_gap)` 为结构化失败/次优解释树；`V_gap = V_{n*}-V_{chosen}` 度量"选了次优分支的代价"。

## 2. 关键算法 伪代码

### IP-121 VBT（Value-Backed Behavior Tree：值标注与校准）

```python
def annotate_values(bt, sim, gamma, iters=200):
    V = {n: zero_value for n in bt.nodes}          # 初始化
    for _ in range(iters):                          # fitted value iteration
        for n in postorder(bt.nodes):               # 自底向上
            samples = [(s, sim.step(s, n), sim.reward(s, n)) for s in sim.states]
            target = {s: r + gamma * V_after(bt, n, s2) for s, s2, r in samples}
            V[n] = fit_regressor(samples_states, target, n)
    delta = {n: max(abs(V[n][s] - backup(bt, n, s, V)) for s in sim.states)
             for n in bt.nodes}                     # Bellman 残差
    return V, delta

def bellman_consistent(bt, delta, eps):
    return all(delta[n] <= eps for n in bt.nodes)
```

### IP-122 OBC（Optimal BT Composition over option graph）

```python
def smdp_composition(option_graph, task, V, gamma, tau_max):
    # 在 option 图上做 SMDP 值迭代；驻留时间进入折扣与转移
    Vtask = {o: V.get(o, 0) for o in option_graph.nodes}
    for _ in range(tau_max):
        for o in option_graph.nodes:
            q = []
            for (o2, (tau, cost)) in option_graph.edges[o]:
                q.append(cost + (gamma ** tau) * Vtask[o2])
            Vtask[o] = min(q) if q else float('inf')
    # 回溯得到 option 序列，并用松弛最优值作为可采纳启发式
    plan = backtrack(option_graph, Vtask, task)
    heuristic = relaxed_optimal_cost(task)          # admissible & consistent
    return plan, heuristic, bellman_gap(Vtask, plan)
```

### IP-123 SBD（Safe Behavior Decorator：CBF/MPC + viability）

```python
def safe_decorator(subtree, h, eta, mpc, gamma):
    def tick_safe(s):
        if h(s) < -eta:                              # viability 失守，禁止 tick
            return 'F', Explain_BT(reason='viability_violation', h=h(s))
        a = mpc.solve(s, goal=subtree.goal)          # 底层 tube-MPC 跟踪
        s2 = mpc.predict(s, a)
        if h(s2) < -eta:                             # 一步前瞻失守
            a = mpc.solve_with_cbf(s, h, eta)        # CBF-QP 修正
        return subtree.tick_with(s, a)
    return tick_safe

def tube_invariant(mpc, h, eta, disturbance_bound):
    return mpc.tube_radius(disturbance_bound) <= eta   # 保守性条件
```

### IP-124 CEBO（Cloud-Edge BT Orchestration：改进/评估分离）

```python
def cloud_improve(task, bt_logs, V_c, gamma):
    V_c = policy_evaluation_coarse(bt_logs, V_c, gamma)  # 离线改进
    bt = bt_structure_search(task, V_c)                  # 结构搜索

def edge_tick(bt, V_e, phi, value_gap_budget, depth=0):
    s = observe()
    chosen, qs = None, {}
    for c in active_children(bt, s):
        qs[c] = estimate_Q(c, s, V_e)
    chosen = min(qs, key=qs.get)                          # Bellman 备份
    delta_V = abs(V_coarse(phi(s)) - V_e[s])             # 值差监控
    status = tick(chosen, s)
    if delta_V > value_gap_budget:                        # 抽象税超预算
        return 'reabstract', Explain_BT(node=chosen, V_gap=delta_V, qs=qs)
    return status, chosen, Explain_BT(node=chosen, V_gap=qs[chosen]-min(qs.values()))
```

### IP-125 XBT（eXplainable Behavior Tree：结构化解解释）

```python
def explain_bt(node, status, child_reports, V_gap):
    if status == 'S':
        return {'node': node, 'status': 'S'}
    if node.type == 'Fall':                               # 全失败才失败
        return {'node': node, 'status': status,
                'children': child_reports,                # 各子失败原因并列
                'root_cause': deepest_failure(child_reports)}
    if node.type == 'Seq':                                # 失败在某个前缀
        return {'node': node, 'status': status,
                'failed_at': first_failed(child_reports),
                'prefix_ok': prior_succeeded(child_reports)}
    return {'node': node, 'status': status, 'V_gap': V_gap}
```

### IP-126 BTC（Bellman Transfer Certificate：跨层联合证书）

```python
def bellman_transfer_certify(bt_src, J_src, phi, target, budgets):
    bt_tgt = remap_tree(bt_src, phi)                     # 结构 + 守卫映射
    V_tgt, delta = annotate_values(bt_tgt, target.sim, budgets.gamma)
    delta_V = relative_value_gap(J_src.V, V_tgt, phi)    # 抽象税
    Ld = value_sensitivity(V_tgt, target.dims)           # 鲁棒谱
    rho = {d: 1.0 / (1.0 + Ld[d]) for d in Ld}
    if delta_V > budgets.Theta_V or max(delta.values()) > budgets.eps:
        return ('reject', 'value_mismatch', delta_V, max(delta.values()))
    if not safe_decorator_holds(bt_tgt, target.h, budgets.eta):
        return ('reject', 'viability_fail')
    if min(rho.values()) < budgets.rho_min:
        return ('reject', 'robustness_fail', rho)
    return ('ok', J_BT(V_tgt, delta_V, rho, J_src.A_cert, target.V_iab, Explain_BT))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| VBT | O(Iter·|N|·|S_train|·d_fit) | O(|N|·|S|) | 拟合误差、Bellman 残差可估 |
| OBC | O(τ_max·(|E_o|+|V_o|)) | O(|V_o|) | 启发式可采纳且一致 |
| SBD | O(|N|·T_mpc) | O(|N|+T_mpc) | tube 半径 ≤ η、CBF 可行 |
| CEBO | O(|N|·|child|+评估) | O(|N|) | 值差可观测、回传收敛 |
| XBT | O(depth) | O(depth) | 控制流语义完备、根因唯一 |
| BTC | O(|N|·|S_train|+离线 DP) | O(|N|·|S|) | δ_V 与 ε 预算闭合 |

**正确性定理（OC-BT Performance & Safety Bound）**
假设 (A22)–(A28) 承接第 53–54 轮；新增 **(A29)** BT 是 ε-Bellman 一致；**(A30)** 云边相对值差 `δ_V^rel ≤ Θ_V`；**(A31)** option 驻留时间有界 `τ_o ≤ τ_max`；**(A32)** 底层 tube-MPC 半径 `d_tube` 且 tube 不变条件成立。则对任意初始分布：
```
J(π_BT) ≤ J* + 2ε/(1-γ) + γ^{τ_max}·δ_V^rel·Jmax + L_tube·d_tube
P(约束违反) ≤ P(viability 失效) ≤ 1 - (1-ε_iab)^{T}
```
直觉证明：ε-Bellman 一致 ⇒ 值迭代收缩给出 O(ε/(1-γ)) 的次优界；值差项来自 simulation lemma（抽象税）；驻留时间项来自 SMDP 折扣 `γ^{τ_max}`；tube 项来自 MPC 鲁棒不变集。安全项由 `Safe(h,γ)` 的前向不变性给出。

**推论（可采纳性）**：若启发式取松弛系统最优值，则 A* 在 `G_o` 上返回的 option 序列代价 `≤ J* + 2ε/(1-γ)`，且 `h` 一致（consistent）时无需 reopen。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 值函数在守卫边界附近失真 | 高 | 边界加密采样 + 保守值下界 + 双网络集成不确定度 |
| 离散抽象与连续动力学不可交换 | 高 | 仿真 lemma 界的在线估计 + 守卫裕度 hysteresis |
| option 驻留时间无界导致折扣失效 | 中 | τ_max 硬截断 + 超时转 Fallback |
| 值差回传导致云边震荡 | 中 | 回传速率限制 + 死区 + 双时间尺度 |
| BT 结构搜索组合爆炸 | 中 | 值引导的束搜索 + 子树缓存 + 语法约束 |
| 安全装饰器过度保守使任务不可达 | 中 | η 自适应 + viability 松弛 + 任务级重规划 |

## 6. 本轮最大风险

**一句话**：OC-BT 把"选哪个行为"从经验启发式升级为值函数定价的 Bellman 备份，并把鲁棒性、安全、可解释性统一到同一个 V 上，但整套 soundness **押在值函数在 BT 可能 tick 的每一处都忠实、且离散抽象与连续动力学可交换**之上；一旦 V 在守卫边界附近失真、或抽象税 `δ_V` 被低估，BT 会**自信地**选一个"模型最优、现实次优甚至不安全"的分支，而由于代价被藏进节点值里，这种错误是**静默的**、还会伪装成鲁棒性——故必须以 **保守值下界 + 值差在线监控 + viability 绊线** 三重护栏，宁可让 BT 在不确定处回退到安全子树，也绝不把"值函数看起来收敛"当作部署前提。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim+++OCBT（VBT×OBC×SBD×CEBO×XBT×BTC）

> 承接第 54 轮产物 v31。本轮在"动作-鲁棒性双证书"体系之上，用 **最优控制** 提供代价-to-go 的"硬通货"、用 **行为树** 提供反应式可组合结构，增加 **值标注、option 级 SMDP 组合、安全装饰器、云边值差闭环、结构化解解释、Bellman 迁移证书** 六大算子：
> - **VBT（Value-Backed Behavior Tree）**：节点标注代价-to-go，tick 即 Bellman 备份；
> - **OBC（Optimal BT Composition）**：option 图上的 SMDP 动态规划，取代经验图搜索；
> - **SBD（Safe Behavior Decorator）**：CBF/MPC + viability kernel 的可 tick 守卫；
> - **CEBO（Cloud-Edge BT Orchestration）**：离线策略改进 / 在线策略评估的分离与值差回传；
> - **XBT（eXplainable Behavior Tree）**：由控制流结构化生成失败解释树；
> - **BTC（Bellman Transfer Certificate）**：值、鲁棒、动作、安全四证合一的跨层迁移证书。
>

## 2. 关键算法 伪代码

### IP-121 VBT

```python
def annotate_values(bt, sim, gamma, iters=200):
    V = {n: zero_value for n in bt.nodes}
    for _ in range(iters):
        for n in postorder(bt.nodes):
            samples = [(s, sim.step(s, n), sim.reward(s, n)) for s in sim.states]
            target = {s: r + gamma * V_after(bt, n, s2) for s, s2, r in samples}
            V[n] = fit_regressor(samples_states, target, n)
    delta = {n: max(abs(V[n][s] - backup(bt, n, s, V)) for s in sim.states)
             for n in bt.nodes}
    return V, delta

def bellman_consistent(bt, delta, eps):
    return all(delta[n] <= eps for n in bt.nodes)
```

### IP-122 OBC

```python
def smdp_composition(option_graph, task, V, gamma, tau_max):
    Vtask = {o: V.get(o, 0) for o in option_graph.nodes}
    for _ in range(tau_max):
        for o in option_graph.nodes:
            q = [cost + (gamma ** tau) * Vtask[o2]
                 for (o2, (tau, cost)) in option_graph.edges[o]]
            Vtask[o] = min(q) if q else float('inf')
    plan = backtrack(option_graph, Vtask, task)
    heuristic = relaxed_optimal_cost(task)       # admissible & consistent
    return plan, heuristic, bellman_gap(Vtask, plan)
```

### IP-123 SBD

```python
def safe_decorator(subtree, h, eta, mpc, gamma):
    def tick_safe(s):
        if h(s) < -eta:
            return 'F', Explain_BT(reason='viability_violation', h=h(s))
        a = mpc.solve(s, goal=subtree.goal)
        s2 = mpc.predict(s, a)
        if h(s2) < -eta:
            a = mpc.solve_with_cbf(s, h, eta)
        return subtree.tick_with(s, a)
    return tick_safe

def tube_invariant(mpc, h, eta, disturbance_bound):
    return mpc.tube_radius(disturbance_bound) <= eta
```

### IP-124 CEBO

```python
def cloud_improve(task, bt_logs, V_c, gamma):
    V_c = policy_evaluation_coarse(bt_logs, V_c, gamma)
    bt = bt_structure_search(task, V_c)
    return bt, V_c

def edge_tick(bt, V_e, phi, value_gap_budget):
    s = observe()
    qs = {c: estimate_Q(c, s, V_e) for c in active_children(bt, s)}
    chosen = min(qs, key=qs.get)
    delta_V = abs(V_coarse(phi(s)) - V_e[s])
    status = tick(chosen, s)
    if delta_V > value_gap_budget:
        return 'reabstract', Explain_BT(node=chosen, V_gap=delta_V, qs=qs)
    return status, chosen, Explain_BT(node=chosen,
                                      V_gap=qs[chosen] - min(qs.values()))
```

### IP-125 XBT

```python
def explain_bt(node, status, child_reports, V_gap):
    if status == 'S':
        return {'node': node, 'status': 'S'}
    if node.type == 'Fall':
        return {'node': node, 'status': status,
                'children': child_reports,
                'root_cause': deepest_failure(child_reports)}
    if node.type == 'Seq':
        return {'node': node, 'status': status,
                'failed_at': first_failed(child_reports),
                'prefix_ok': prior_succeeded(child_reports)}
    return {'node': node, 'status': status, 'V_gap': V_gap}
```

### IP-126 BTC

```python
def bellman_transfer_certify(bt_src, J_src, phi, target, budgets):
    bt_tgt = remap_tree(bt_src, phi)
    V_tgt, delta = annotate_values(bt_tgt, target.sim, budgets.gamma)
    delta_V = relative_value_gap(J_src.V, V_tgt, phi)
    Ld = value_sensitivity(V_tgt, target.dims)
    rho = {d: 1.0 / (1.0 + Ld[d]) for d in Ld}
    if delta_V > budgets.Theta_V or max(delta.values()) > budgets.eps:
        return ('reject', 'value_mismatch', delta_V, max(delta.values()))
    if not safe_decorator_holds(bt_tgt, target.h, budgets.eta):
        return ('reject', 'viability_fail')
    if min(rho.values()) < budgets.rho_min:
        return ('reject', 'robustness_fail', rho)
    return ('ok', J_BT(V_tgt, delta_V, rho, J_src.A_cert,
                       target.V_iab, Explain_BT))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| VBT | O(Iter·|N|·|S_train|·d_fit) | O(|N|·|S|) | 拟合误差可估、δ_n 上界 |
| OBC | O(τ_max·(|E_o|+|V_o|)) | O(|V_o|) | 启发式可采纳且一致、SMDP 最优 |
| SBD | O(|N|·T_mpc) | O(|N|+T_mpc) | tube 半径 ≤ η、CBF 可行 |
| CEBO | O(|N|·|child|+评估) | O(|N|) | δ_V 可观测、双时间尺度收敛 |
| XBT | O(depth) | O(depth) | 控制流语义完备、根因唯一 |
| BTC | O(|N|·|S_train|+离线 DP) | O(|N|·|S|) | δ_V、ε、ρ、V_iab 预算闭合 |

**正确性定理（OC-BT Performance & Safety Bound）**
假设第 53–54 轮 (A22)–(A28) 成立；新增 **(A29)** BT 是 ε-Bellman 一致；**(A30)** 云边相对值差 `δ_V^rel ≤ Θ_V`；**(A31)** `τ_o ≤ τ_max`；**(A32)** tube-MPC 半径 `d_tube` 且 tube 不变条件成立。则：
```
J(π_BT) ≤ J* + 2ε/(1-γ) + γ^{τ_max}·δ_V^rel·Jmax + L_tube·d_tube
P(约束违反) ≤ 1 - (1-ε_iab)^{T}
```
证明结构：ε-Bellman 一致 ⇒ 值迭代收缩给出 `O(ε/(1-γ))` 次优界；`δ_V` 项来自 simulation lemma（抽象税）；`γ^{τ_max}` 来自 SMDP 折扣；tube 项来自鲁棒不变集；安全项来自 `Safe(h,γ)` 前向不变性。
**推论**：启发式取松弛系统最优值时 A* 在 `G_o` 上返回的 option 序列代价 `≤ J* + 2ε/(1-γ)`，且一致启发式下无需 reopen。

## 6. 本轮最大风险

**一句话**：OC-BT 把"选哪个行为"从经验启发式升级为值函数定价的 Bellman 备份，并把鲁棒、安全、可解释性统一到同一个 V 上，但整套 soundness **押在值函数在 BT 可能 tick 的每一处都忠实、且离散抽象与连续动力学可交换**之上；一旦 V 在守卫边界附近失真、或抽象税 `δ_V` 被低估，BT 会**自信地**选一个"模型最优、现实次优甚至不安全"的分支，而由于代价被藏进节点值里，这种错误是**静默的**、还会伪装成鲁棒性——故必须以 **保守值下界 + 值差在线监控 + viability 绊线** 三重护栏，宁可让 BT 在不确定处回退到安全子树，也绝不把"值函数看起来收敛"当作部署前提。
