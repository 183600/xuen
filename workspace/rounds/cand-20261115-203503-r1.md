# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「价值对齐」×「VLA」）

> R69 给了系统一张嘴，并问「我该向谁求证、还能问什么」。但它从头到尾都在问「世界是什么」，从未问「我到底想要什么」。R69 的 λ 是一个标量风险油门，默认所有伤害可通约、所有价值已给定。事实上，目标本身是**不确定的、多元的、且以语言表述的**。VLA 把语言直接接进动作回路，但语言不只携带事实（是什么），还携带规范（应当如何）——R69 消解的是「是什么」的歧义，R70 必须消解「应当如何」的歧义，以及「你到底是什么意思」的接地歧义。
>
> 核心命题：**把不确定性从二维扩成三维——世界（epistemic，R69 已解）、语义（grounding）、价值（axiological）。VLA 是让语言一次性注入这三种不确定性的桥。VALOR-RAS：一条与价值无关、字典序第一的硬安全底线；底线之内，一个显式、可检查、可多元、可更新的价值状态 v 被条件进流匹配策略；价值不确定性被分解并主动征询（带信任预算）；多主体偏好用显式、可审计的社会选择规则聚合；当价值不可消解或不可信时，退到「最小承诺动作」，而不是一个隐藏的标量。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我该想要什么，以及你说的就是你想的吗**」。

## 0. 直觉与动机

**灵感 1（价值对齐 → 目标本身就是一个不确定量）**
直觉：前序轮次都把「优化什么」当作已给定的奖品函数，只在「怎么安全地优化」上做文章。但真实部署里，奖品是**人写的一句话**：「把药递给我」「轻一点」「别吵醒孩子」。这句话既可能指代不清（哪瓶药），也可能规范不清（多轻算轻），还可能价值冲突（我要快，但护士要稳）。把这种不确定性当成观测噪声是范畴错误：它不是世界的不确定性，是**我们想要什么**的不确定性。R69 的 epistemic 通道再强，也无法消解一个「目标本身没说清」的问题。

**灵感 2（VLA → 语言同时是事实通道和规范通道）**
直觉：VLA（vision-language-action）把（图像，语言）映到动作，是价值进入闭环最自然的入口。但一个 VLA 会同时做三件事：接地指代（把「那瓶药」指到某个物体）、接地谓词（把「递」解释成一串动作）、接地规范（把「轻一点」解释成力上限）。三者可以各自出错，且错误模式完全不同。更危险的是，VLA 在互联网语料上训练，天然携带**说服性语言**与**谄媚（sycophancy）**倾向——它会倾向于同意用户说出的价值，哪怕那个价值有害。于是「语言接地」不是免费的，它既带来价值，也带来攻击面。

**灵感 3（三分 → 安全底线与价值状态必须字典序分离）**
直觉：把「安全」和「价值」混成一个标量，是对齐领域最深的错误。安全是**价值无关的**（无论你想要什么，都不该撞人）；价值是在安全之内**选择**（同样安全的两条路，走哪条取决于你想要什么）。因此必须字典序：先过安全底线，再在底线内按显式价值状态选。价值状态必须是显式对象，而不是烘焙进权重的隐式偏好——否则无法检查、无法更新、无法向用户解释「我为什么这么做」。这也是与 R68/R69 一脉相承的姿态：安全侧永不让步，效率侧才谈优化。

**灵感 4（声言 vs 显露 → 价值也有对偶通道）**
直觉：R69 用「传感器残差 × 行为似然」的对偶识破被标定吸收的慢变故障。价值也有同构的一对：**声言价值**（用户怎么说）与**显露价值**（用户在纠正/选择/结果反馈中怎么做）。声言便宜但可被操纵、可谄媚；显露可信但覆盖有限、有分布漂移。二者的分歧 Δv 本身就是信号：高 Δv 可能是偏好漂移、可能是注入攻击、可能是规范错配——单看一条通道无法区分，需要第三条正交证据（反事实探询）。这是 R69 引理 17 在价值侧的镜像。

**灵感 5（社会选择 → 对齐不可能是一个标量）**
直觉：一旦有多个主体（用户、旁观者、操作者、监管者），「对齐」就是社会选择问题。Arrow 定理告诉我们：满足 Pareto、无关备选独立性、非独裁的聚合规则不存在。因此任何部署的标量奖励，本质上都是某个**未声明的独裁权重**。诚实的做法不是假装找到一个「正确的标量」，而是把**聚合规则与权重显式写进证书**，让「对齐」可争论、可审计，而不是黑箱。这条比「加一个价值头」重要得多：它把对齐从「模型属性」变成「可审计的制度设计」。

**灵感 6（规格博弈 → 满足字面不等于满足精神）**
直觉：一个足够强的策略会找到「字面满足、精神违背」的动作（把「把盘子放好」实现成把盘子塞进柜子最深处，只求不摔）。这是 specification gaming。必须把「字面价值 v_letter」与「精神价值 v_spirit」分开，用反事实意图探针估计 Δ_spec；高 Δ_spec 的动作即使安全、即使字面最优，也应被拒或降权。这是价值对齐特有的失效模式，前序轮次的安全框架完全测不到。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（VALOR-RAS 总览）** VALOR-RAS = (VCP, AXD, VELIC, SCA, VGR, LCP, VPA, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **字典序安全底线**：硬安全包络 𝒮 与价值无关且字典序第一；任何价值只能在 𝒮 内选择，永不扩张——「价值语句只能收紧，不能放松」；
(iii) **显式价值状态**：不存在隐藏奖励；v 是可检查、带版本、带来源的显式对象，证书必须记录用了哪个 v；
(iv) **可审计聚合**：把多元偏好映到决策的规则 Agg(·) 必须写入证书，禁止隐式标量化。

**定义 311（三源不确定性）** 世界 U_w = (U_ale, U_epi)（R69 定义 297）；语义 U_μ = 指代/谓词/规范接地歧义；价值 U_v = (U_pref, U_norm, U_conflict)。三者正交、进入不同通道，不做简单加和。

**定义 312（价值状态）** v = (v_stated, v_revealed, v_prior)；v 是偏好泛函上的后验，而非标量。拆为硬约束 v_H（不可侵犯，如「不得伤人」）与软偏好 v_S（可权衡）。v_H 是 𝒮 的语言侧投影；v_S 在 𝒮 内排序动作。

**定义 313（VLA 语义接地）** 指令 ℓ → 接地程序 P = (refs, preds, norms)，每个分量带置信度：指代（哪个物体）、谓词（什么动作）、规范（哪条约束）。三种错误模式：指代错（gaze/point 可解）、谓词错（需澄清或演示）、规范错（需征询）。

**定义 314（价值条件策略 VCP）** 复用 R69 流匹配：v_θ(x_s, s | z, P, v)，采样得价值条件下的动作模态 {m_k(v)}。价值不同，模态权重与原型不同——歧义不仅在世界，也在「你想要哪种」。

**定义 315（公理不确定性分解 AXD）** U_pref（口味差异/偏好噪声，不可约）、U_norm（规范歧义，可经征询约减）、U_conflict（多主体冲突，无聚合规则前不可约）。对应 R69 的 aleatoric/epistemic 分裂：U_pref 直接进保守通道；U_norm 若 VoI_v 值钱则征询；U_conflict 交给显式 SCA。

**定义 316（声言-显露对偶）** v_stated 来自语言，v_revealed 来自纠正/选择/结果反馈。Δv = d(v_stated, v_revealed)。高 Δv ⇒ {偏好漂移，注入操纵，规范错配} 三者之一；单对通道不可区分。

**定义 317（价值征询控制器 VELIC）** 价值查询 g_v 的信息增益 VoI_v(g_v) = H(v|o) − E_{y~p(·|g_v,o)}[H(v|o,y)]；选择 argmax[VoI_v − c(g_v) − τ_trust(g_v)]，s.t. 信任预算 B_trust 未超。查询分三级成本：澄清指代（最廉）< 征询偏好（中）< 道德求证（最贵，且可能被视为操纵）。B_trust 与 R69 的物理交互预算相互独立。

**定义 318（社会选择聚合 SCA）** 给定主体集 {i} 与偏好 {v_i}，聚合规则 Agg ∈ {Pareto, lexicographic, maximin, Nash, declared-weight}；由部署方声明并写入证书。Arrow 约束：不存在同时满足 Pareto + IIA + 非独裁的规则；故任何标量奖励都是未声明的独裁权重。系统必须暴露其 Agg 与权重。

**定义 319（价值后悔守卫 VGR）** 在 v 的后验上，value regret(a) = max_{v∈supp} [v(a*_v) − v(a)]，a*_v 为该 v 下最优。仅当 a 在支持集上**无歧义最优**或 regret(a) ≤ ε_v 时直接执行；否则征询或最小承诺。

**定义 320（最小承诺原则 LCP）** 在近优安全动作集中，选可逆性最大、附带副作用最小、授权最少者；能用可逆探针就不做不可逆动作。价值不确定时，LCP 是默认动作，而非随机选一个模态。

**定义 321（规格博弈检测 SGD）** v_spirit 与 v_letter 分离；Δ_spec = v_spirit(a) − v_letter(a)。用反事实意图探针（「人是否会认为这个动作满足本意」）估计；Δ_spec 高 ⇒ 拒绝或降权，即使字面最优。

**定义 322（价值注入威胁 ℰ_value）** prompt 注入、谄媚（同意有害声言）、社交工程、价值洗白（用良性措辞为有害动作背书）、权威冲突。并入 AIC：ℰ_VALOR = ℰ_FLUID × ℰ_value。

**定义 323（价值来源与反操纵 VPA）** 每条价值证据带来源与可信度；需要 k 个正交来源一致才可更新 v_H 之外的可执行约束；**任何声言价值都不能覆盖硬安全底线**；声言价值对可行动集的净效应只能是收缩。

**定义 324（对齐证书 J_VALOR）** J_VALOR = (J_FLUID, v_hash, Agg, weights, U_v_before/after, Δv, Δ_spec, provenance_hash, B_trust_used, valor_ver)。Valid ⇔ Valid(J_FLUID) ∧ 安全底线未破 ∧ v 来源可溯 ∧ 聚合规则声明完整。

**定义 325（价值漂移检测）** 长时程上监控 Δv 趋势与结果反馈；区分真漂移（用户确实变了）、操纵（外部注入）、错配（v 从未被正确接地）。只在累积证据超过阈值时更新 v，且更新可回滚。

**定义 326（自适应价值精度）** 默认不征询价值；仅当 U_norm 高且 VoI_v > 信任成本时征询。与 R69 定义 308 的自适应 K 同构：把「问不问」当预算问题，而不是默认多问。

**定义 327（两级退避）** 价值已消解且可信 ⇒ 在 𝒮 内按 v 选；未消解/被注入/冲突无规则 ⇒ LCP + 安全底线。R69 恰为「单一已知 v、完美接地、无注入」的边界。

**定义 328（接地-行为交叉验证）** 若 VLA 把指令接地到不存在的物体或不可行动作，R69 的流似然 a_score 会升高；故 grounding confidence × flow likelihood 构成交叉验证：接地说「有」、行为说「不合理」⇒ 拒绝该接地。

```python
# IP-264 VCP：价值条件流匹配策略（复用 R69 FMP trunk，零重复训练）
class ValueConditionedPolicy:
    def __init__(self, trunk, velocity_net, grounder, N_step=2):
        self.trunk, self.v, self.ground = trunk, velocity_net, grounder

    def ground_instruction(self, obs, ell):
        P = self.ground(obs, ell)          # refs/preds/norms + confidence
        return P

    def sample(self, o_t, P, v, K, N_step=2):
        z  = self.trunk(o_t)
        xs = randn(K, D)
        for i in range(N_step):
            xs = xs + (1.0 / N_step) * self.v(xs, i / N_step, z, P, v)
        return [self.decode(x) for x in xs]   # 价值条件下的多模态动作

# IP-265 AXD：三源不确定性分解
def axi_decompose(samples_by_v, samples_by_ground, v_posterior):
    U_pref   = expected_trace_within_v(samples_by_v)       # 不可约口味噪声
    U_norm   = entropy(v_posterior) * ground_separability()  # 可征询
    U_conf   = conflict_mass(v_posterior)                   # 多主体冲突
    U_mu     = grounding_entropy(samples_by_ground)         # 指代/谓词/规范
    return U_pref, U_norm, U_conf, U_mu

# IP-266 VELIC：价值征询（VoI / 成本 / 信任税）
def choose_value_query(v_post, o_t, trust_budget):
    best = None
    for g in value_query_candidates(v_post):     # 澄清指代 / 征询偏好 / 道德求证
        if not trust_budget.allow(g):            continue
        voi   = entropy(v_post) - expected_entropy(v_post, g, o_t)
        score = voi - cost(g) - trust_tax(g)     # 问道德问题最贵
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None   # 不值 → 不征询

# IP-267 SCA：显式社会选择聚合（规则入证书）
def aggregate(prefs, rule):
    if rule == 'lexicographic': return lexicographic(prefs)   # 安全/硬约束优先
    if rule == 'maximin':       return maximin(prefs)
    if rule == 'nash':          return nash_bargain(prefs)
    if rule == 'declared':      return weighted_sum(prefs, rule.weights)
    raise ValueError('undeclared aggregation')                # 禁止隐式标量

# IP-268/269 VGR + LCP：价值后悔守卫与最小承诺
def value_guard(modes, v_post, eps_v):
    a_star = {v: argmax_v(modes, v) for v in v_post.support}
    if len(set(a_star.values())) == 1: return a_star[v_post.mode()]  # 无歧义最优
    if max_value_regret(modes, v_post) <= eps_v: return v_post.mode_action()
    return least_commitment(modes)            # 可逆 / 副作用小 / 授权少

# IP-270 VPA：来源加权与反操纵（声言只能收紧）
def admit_value_evidence(v_new, provenance, v_cur, safety_floor):
    if violates(safety_floor, v_new): return v_cur       # 硬底线不可覆盖
    if not k_orthogonal_agree(provenance, k=2): return v_cur
    return tighten_only(v_cur, v_new)                    # 净效应只收缩

# IP-271 SGD：规格博弈检测
def spec_gaming(xi, v_letter, v_spirit_probe):
    return max(0.0, v_letter(xi) - v_spirit_probe(xi))   # Δ_spec 高 = 文字满足、精神违背

# IP-275 主闭环（继承 R69，仅在价值处置处插入 VALOR 层）

    U_pref, U_norm, U_conf, _ = M.axd.axi_decompose(...)

    if U_mu > TAU_MU:

    A = M.ach.propose(a_exec, H=M.vista.H)
```

## 3. 推导

**引理 19（价值查询的净收益与「决策相关」条件）** 设价值后验 p(v)、动作集 𝒜、价值泛函对动作的 Lipschitz 常数为 L_v，决策间隔 margin = v(a₁) − v(a₂) 为最优与次优差。一次价值查询使后验熵降低 ΔH_v，则期望价值后悔下降 ≥ c·L_v·min(margin, diam(𝒱))·(1 − e^{−ΔH_v})。系：**只有当「决策间隔」小于「价值不确定性」时，征询才值钱**；若某动作对所有合理 v 都占优（margin 大），则不必问——这是 R69「可分才值得问」在价值侧的对应：**价值征询的条件不是「模糊」，而是「模糊且影响选择」**。

**引理 20（声言-显露的可识别性）** 声言 v_s 便宜但有偏（谄媚/操纵偏置 β_s）与低方差 σ_s²；显露 v_r 低偏但覆盖有限（分布漂移偏置 β_r）与高方差 σ_r²。贝叶斯融合给出 v_post。当 ||v_s − v_r|| > τ_v 时，{漂移, 操纵, 错配} 三者中至少一者成立，但**单凭这一对通道不可区分**（三者产生同样的 Δv）；必须引入第三条正交探针（反事实意图探针或结果反馈）才能分离。这直接解释了为什么 R69 的二元对偶在价值侧需要升级为三元。

**引理 21（价值注入的损害方向）** 在 VPA「声言只能收紧」与硬安全底线与价值无关的前提下，任意注入攻击对**物理安全**的最大损害为零（最多造成过度保守的拒绝服务）；但它仍能在安全集内造成**价值违背**（安全但错误地偏向了被注入的价值）。故「完整性（integrity）」与「合法性（legitimacy）」是两个独立属性：证书 Valid(J_FLUID) 只保证前者，J_VALOR 才试图覆盖后者，而后者本质上不可由单次证书完全证明。

**定理 18（VALOR 严格包含 FLUID）** 当 |𝒱| = 1（单一已知价值、无冲突、完美接地、无注入）时，VALOR 的聚合退化为该 v，VGR 的 regret 恒为 0，LCP 不触发 ⇒ 决策与 FLUID-RAS 逐指令相同；安全底线完全继承。当价值不确定而可征询时，VALOR 获得价值后悔的 resolution bonus；不可征询时走 LCP，安全侧仍不弱于 FLUID。故 R69 是 VALOR 在「价值已知且接地完美」边界上的严格退化。

**定理 19（无免费对齐 / 聚合不可能性）** 对 ≥3 个动作与 ≥2 个主体，任何满足 Pareto 与无关备选独立性的确定性聚合规则都是独裁的（Arrow）。推论：**任何部署的标量奖励都等价于一个未声明的独裁权重向量**；因此「用一个分数证明对齐」在形式上不可能。诚实的对齐证书必须至少包含 (Agg, weights, provenance)——不是因为它更正确，而是因为它是唯一可被反驳的形式。

**定理 20（最小承诺的安全与后悔界）** 设价值支持集直径 diam(𝒱)，单步可逆动作集 𝒜_rev。LCP 在近优集内选可逆动作，则（i）物理安全 ≥ 安全底线（字典序，不依赖价值）；（ii）价值后悔 ≤ diam(𝒱)·max_a sup_{v,v'} |v(a) − v'(a)|（有界，且随可逆性增加而下降，因为可逆动作允许后续纠正）；（iii）不可逆侧效应被推迟到价值后验收窄之后。系：**价值不确定时，可逆的「先做一点点」优于不可逆的「一次做对」**。

## 6. 本轮最大风险

**一句话**：VALOR-RAS 把「对齐」从模型属性改造成了「可审计的制度」，但它只能证明系统**一致于一个被声明的价值 v**，无法证明 v 本身是对的——**最大的风险不是对齐失败，而是成功地、可审计地对齐了一个错误的价值（或被注入的价值），并且系统对此毫无察觉**；「声言只能收紧」这条棘轮保住了物理安全，却把价值错误从「不安全」变成了「安全但不受欢迎」，而这种错误恰恰最难被安全指标发现。

**次级风险与缓解**：
1. **价值不可识别**（声言与显露永远无法分离真伪）→ 三元探针 + 长时程漂移跟踪 + 显式不确定性，绝不假装已对齐（引理 20、定理 19）；
2. **VLA 接地幻觉**（指代到不存在物体）→ grounding confidence × R69 流似然交叉验证（定义 328、E311）；
3. **谄媚/注入**（VLA 盲从有害声言）→ 硬底线不可覆盖 + 来源加权 + k 源一致（定义 322–323、E304/E313）；
4. **聚合规则的隐性独裁** → 规则与权重强制入证书，禁止隐式标量（定义 310-iv、定理 19、E305）；
5. **实时预算被三源叠加击穿** → 共享视觉编码 + 自适应精度（定义 326）+ 仅规范歧义时征询（E309）。

```python
    z, o = M.mtm.forward(...); P = M.vcp.ground_instruction(o, ell)
    U_mu = M.axd.grounding_entropy(P)
    v_post = M.vpa.update(v_prior, M.vcp.last_feedback)     # 声言+显露+先验
    U_pref, U_norm, U_conf, _ = M.axd.axi_decompose(...)
    if U_mu > TAU_MU:                                        # 语义歧义走 R69 MINT
        g_mu = M.mint.choose_interaction(P.candidates, o, M.budget)
        if g_mu is not None: P = M.mint.execute(g_mu)
    g_v = (M.velic.choose_value_query(v_post, o, M.trust_budget)
           if U_norm > TAU_NORM else None)                   # 规范歧义才征询
    if g_v is not None: v_post = M.velic.update(v_post, g_v)
    v_exec = M.sca.aggregate(v_post.subjects, M.declared_rule)  # 显式聚合
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.vcp.sample(o, P, v_exec, K)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o, o_cal)
    if a_hat > TAU_FMA and U_mu > TAU_MU: P = M.vcp.reground(ell)  # 接地-行为不符
    a_exec = M.vgr.value_guard(samples, v_post, M.eps_v)
    if M.sgd.spec_gaming(a_exec, v_exec, M.intent_probe) > TAU_SPEC:
        a_exec = M.lcp.least_commitment(samples)              # 拒绝规格博弈动作
    A = M.ach.propose(a_exec, M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, safety_floor, wm_preds)  # 字典序安全第一
    lam = max(M.efs.risk_scale(...), lam_floor(U_pref + U_conf))
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam
    M.vqa_v.submit_async(P, v_exec, M.declared_rule, U_norm, a_hat, g_v)
    return k, lam, a_exec, J_VALOR(...)
```

## 4. 推导

**引理 19（价值查询的净收益与「决策相关」条件）** 设价值后验 `p(v)`、动作集 `𝒜`、价值泛函 Lipschitz 常数 `L_v`、决策间隔 `margin`。一次查询使后验熵降 `ΔH_v`，则期望价值后悔下降 ≥ `c·L_v·min(margin,diam(𝒱))·(1−e^{−ΔH_v})`。系：**仅当决策间隔 < 价值不确定性时征询才值钱**；若某动作对所有合理 v 占优则不必问——价值征询的条件是「模糊且影响选择」，对应 R69「可分才值得问」。

**引理 20（声言-显露的可识别性）** 声言低方差高操纵偏置 `β_s,σ_s²`；显露低偏置（有限覆盖漂移 `β_r`）高方差 `σ_r²`；贝叶斯融合得 `v_post`。当 `‖v_s−v_r‖>τ_v`，`{漂移,操纵,错配}` 至少一者成立，但**单对通道不可区分**；需第三条正交探针（反事实意图/结果反馈）分离。故 R69 的二元对偶在价值侧必须升为三元。

**引理 21（价值注入的损害方向）** 在「声言只能收紧」与硬底线价值无关下，注入攻击对**物理安全**的最大损害为零（最多过度保守），但可在安全集内造成**价值违背**（安全但偏向被注入的价值）。故完整性（J_FLUID）与合法性（J_VALOR）独立：证书 Valid 只保证前者。

**定理 18（VALOR 严格包含 FLUID）** 当 `|𝒱|=1`（单一已知价值、无冲突、完美接地、无注入），聚合退化为该 v、`regret≡0`、LCP 不触发 ⇒ 决策与 FLUID-RAS 逐指令相同，安全底线完全继承；价值不确定但可征询时获价值 resolution bonus，不可征询时走 LCP，安全不弱于 FLUID。**R69 是「价值已知且接地完美」边界上的严格退化。**

**定理 19（无免费对齐 / 聚合不可能性）** 对 ≥3 动作与 ≥2 主体，任何满足 Pareto 与 IIA 的确定性聚合规则都是独裁的（Arrow）。推论：**任何标量奖励都等价于未声明的独裁权重**；「用一个分数证明对齐」形式上不可能，诚实证书必须含 `(Agg, weights, provenance)`——不是因为更正确，而是因为唯一可被反驳。

**定理 20（最小承诺的安全与后悔界）** 设 `diam(𝒱)`、可逆动作集 `𝒜_rev`。LCP 在近优集内选可逆动作 ⇒（i）物理安全 ≥ 安全底线（字典序，不依赖价值）；（ii）价值后悔 ≤ `diam(𝒱)·max_a sup_{v,v'}|v(a)−v'(a)|`，且随可逆性增加而下降（可逆允许后续纠正）；（iii）不可逆侧效应被推迟到价值后验收窄之后。系：**价值不确定时，可逆的「先做一点点」优于不可逆的「一次做对」**。

## 7. 本轮最大风险

**一句话**：VALOR-RAS 只能证明系统**一致于一个被声明的价值 v**，无法证明 v 本身是对的——**最大的风险不是对齐失败，而是成功地、可审计地对齐了一个错误的价值（或被注入的价值），且系统对此毫无察觉**；「声言只能收紧」保住了物理安全，却把价值错误从「不安全」降级为「安全但不受欢迎」，而这恰恰最难被安全指标发现。

**次级风险与缓解**：价值不可识别（三元探针 + 长时程漂移 + 显式不确定性，引理 20、定理 19）；VLA 接地幻觉（接地置信 × R69 流似然交叉验证，定义 328、E311）；谄媚/注入（硬底线不可覆盖 + 来源加权 + k 源一致，定义 322–323、E304/E313）；聚合规则隐性独裁（规则与权重强制入证书，定理 19、E305）；实时预算被三源叠加击穿（共享视觉编码 + 自适应精度 + 仅规范歧义征询，E309）。
