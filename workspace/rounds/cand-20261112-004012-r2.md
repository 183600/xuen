# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 2 轮；本轮灵感：「迭代验证」×「腕部相机」）

> 第 54 轮把技能组合提升为动作-鲁棒性双证书（ACS×SCOM×CEC×AEC×JTC），但证书本质上是**部署前一次性签发的静态对象**：一旦签发，执行期不再被质疑。本轮引入两个新变量——**腕部相机**提供执行期的高分辨局部证据通道，**迭代验证**把"签发即信任"改为"执行中持续验证"。核心矛盾：H22：腕部相机的强局部性使其在遮挡/运动模糊/手眼标定漂移下产生"看似收敛的假证据"；H23：迭代验证若只最小化视觉残差，会优化代理指标而非任务成功，形成"验证过拟合"（validation overfitting）。本轮主张：**腕部相机是动作空间的示波器，迭代验证是证书的续期机制，二者必须由压缩性（contraction）与联合可观测性（joint observability）共同担保。**

## 0. 直觉与动机

**灵感 1（腕部相机 → 把动作空间从"离线标定"变为"在线可测"）**
直觉：腕部相机与末端执行器刚性连接，它看到的不是"世界长什么样"，而是"我的动作正在如何被实现"——接触点、滑移、末端落点、工具姿态。上一轮的 `α_S(a)` 只能靠离线结构化仿真校准；腕部相机让 `α_S(a)` 在执行期被逐帧测量。因此腕部相机不是新增感知通道，而是**动作空间的示波器**：`o_w(t)` 是动作 `a(t)` 的时域响应。推论：验证的对象从"技能是否成功"下沉到"动作是否按承诺被执行"。

**灵感 2（迭代验证 → 从一次性验收变为逐周期证伪）**
直觉：科学实验不是跑完整个流程再判断，而是每一小步都问"证据是否支持我继续"。把技能执行切成控制周期，每个周期用腕部观测估计**执行残差** `r_t`：若 `r_t` 小则继续，若超阈值则就地修正/换视角/中止。这把"验收"从技能级降到动作级，使失败在造成不可逆后果前被截获。

**灵感 3（压缩性 → 好的验证循环应让误差单调收缩）**
直觉：一个健康的"观测-修正"循环，误差应像 `e_{t+1} ≤ κ·e_t` 一样收缩，而不是来回震荡。定义收缩率 `κ`，则 `N` 轮后残差 `≤ κ^N r_0 + 噪声地板`。`κ` 可以**在线估计**（对残差序列做对数线性拟合），并作为证书的一部分：`κ≥1` 说明该技能在当前条件下不可验证，应拒绝而非硬迭代。

**灵感 4（校准与验证是同一个问题的两面 → 验证驱动校准）**
直觉：手眼标定 `T_wc` 的漂移会让残差估计产生系统偏差，看起来"怎么修都修不干净"。但反过来，迭代验证天然产生海量 `(动作指令, 腕部观测)` 配对，这正是标定的监督信号。于是 **validation-driven calibration**：用验证残差反哺 `T_wc`，形成自愈闭环。关键约束是**可观测性**——绕光轴纯旋转、静止等运动对 `T_wc` 不可观测，必须主动激励，否则会把"标定不可观"误判为"技能不可控"。

**灵感 5（主动迭代验证 → 花预算买信息）**
直觉：迭代不是免费的（时延、能耗、磨损）。每个周期应做四选一决策：`continue`（继续迭代）/`reprobe`（移动腕部换视角获取新证据）/`commit`（残差已足够小，交付）/`abort`（不可收敛，中止）。用**期望信息增益 vs 成本**做调度，把第 54 轮的云边闭环 `CEC` 下沉到边端控制频率，形成"边端高频验证、云端低频重规划"的双时间尺度结构。

**灵感 6（证书有保质期 → 从"签发"到"维护"）**
直觉：真实世界的标定、光照、工具磨损都在漂移，静态证书会过期。给联合证书 `J` 加 **TTL 与新鲜度** `fresh_until`，由迭代验证持续续期；过期证书自动降级为"待验证"，禁止直接部署。这把信任模型从"签名时刻"变为"持续维护"，与安全领域的短期凭证（short-lived credential）同构。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（腕部观测算子）**
腕部相机 `W` 经手眼变换 `T_wc ∈ SE(3)` 与末端刚性连接。腕部观测
```
o_w = W(s, a; T_wc) + η,   η ~ N(0, Σ_o)
```
动作 `a` 在状态 `s` 下的**可观测度** `obs(a) = σ_min(J_w(a))`，其中 `J_w(a) = ∂o_w/∂T_wc` 为腕部观测对手眼参数的雅可比，`σ_min` 为最小奇异值。当 `obs(a) < o_min` 时称该动作对 `T_wc` **不可观测**（如绕光轴纯旋转、静止）。

**定义 122（执行残差）**
从腕部观测提取任务相关特征 `φ(o_w)`（接触点、末端位姿、滑移量），执行残差
```
r_t = || φ(o_w,t) - φ*(a_t) ||_{Σ_o^{-1}},   ρ_t = r_t / r_max ∈ [0,1]
```
其中 `φ*(a_t)` 为动作 `a_t` 的期望特征。`r_t` 度量"动作被实现的程度"，而非"世界状态是否正确"。

**定义 123（迭代验证算子与压缩性）**
验证-修正算子 `V_κ : (a_t, J_t, o_w,t) → (a_{t+1}, J_{t+1}, r_t)`。若在可达集 `Ω` 上存在 `κ<1` 使
```
|| a_{t+1} - a* || ≤ κ·|| a_t - a* || + β·||η||
```
则称 `V_κ` 为 **κ-压缩**。`κ` 由残差序列在线估计：`κ̂ = exp(slope(ln r_t))`。`κ̂ ≥ 1` 表示不收缩，该技能在当前证据条件下**不可验证**。

**定义 124（校准-验证联合可观测性）**
联合状态 `x = (a, T_wc)`，联合观测矩阵
```
O_J = [ ∂o_w/∂a ; ∂o_w/∂T_wc ]
```
当 `cond(O_J) ≤ κ_obs` 时，动作与手眼标定可**联合估计并收敛**；否则标定漂移会污染残差，触发"假证据"。

**定义 125（验证预算）**
验证预算 `B_V = (N_max, τ_V, e_V)`：最大迭代轮数、时延预算、能量预算。调度策略 `π_V` 在每个周期决定是否继续。预算耗尽仍未收敛则进入**降级执行**（保守动作/请求云端重规划），而非静默交付。

**定义 126（主动验证决策）**
控制选择 `u ∈ {continue, reprobe, commit, abort}`，目标
```
u* = argmax_u  E[IG(r | u, belief)] - λ_c·cost(u, B_V)
```
其中 `IG` 为残差的期望信息增益，`reprobe` 通过移动腕部视角最大化新证据，`commit` 仅在残差置信上界 `r_t + z_α·σ_r ≤ ε_max` 时可选。

**定义 127（迭代验证证书 IVC）**
在上一轮联合证书 `J` 之上扩展为
```
J^V = (J, κ̂, N_used, ε_N, T_wc, Σ_T, fresh_until, trace)
```
- `κ̂` 在线估计收缩率；`ε_N = κ̂^N·r_0 + b/(1-κ̂) + σ·sqrt((1-κ̂^{2N})/(1-κ̂²))` 为残差上界；
- `Σ_T` 为手眼标定协方差；`fresh_until` 为证书新鲜期；
- `trace` 为可审计的验证证据链（每轮动作、残差、观测哈希）。
**可部署条件**：`fresh_until > now ∧ ε_N ≤ ε_max ∧ cond(O_J) ≤ κ_obs ∧ κ̂ < 1`。

## 2. 关键算法 伪代码

### IP-121 WVC（Wrist Visual Calibration：验证驱动的手眼标定）

```python
def wrist_calibrate(T_wc, wrist_stream, kappa_obs, o_min):
    Sigma_T = eye(6)
    for o_w, a_cmd, a_meas in wrist_stream:
        if observability(a_cmd) < o_min:      # 不可观测运动不更新
            continue
        J = wrist_jacobian(o_w, T_wc)
        if cond(J) > kappa_obs:               # 病态，跳过以防污染
            continue
        dx, Sigma_T = robust_update(J, residual(o_w, a_cmd), Sigma_T)
        T_wc = compose(T_wc, exp(dx))
    return T_wc, Sigma_T
```

### IP-122 IVL（Iterative Validation Loop）

```python
def iterative_validate(skill, a0, J, wrist, B_V, kappa_max, eps_max):
    a, trace = a0, []
    for t in range(B_V.N_max):
        o_w = wrist.capture()
        r = execution_residual(o_w, a)
        trace.append((t, a, r, hash(o_w), o_w.meta))
        if r <= eps_max:
            return ('commit', a, refresh_certificate(J, trace), trace)
        if estimate_kappa(trace) >= kappa_max:   # 不收缩 -> 不可验证
            return ('abort', a, 'non_contractive', trace)
        u = active_validation_policy(trace, B_V)
        if u == 'reprobe':
            wrist.reprobe()                      # 主动换视角买信息
            continue
        if u == 'abort' or budget_exhausted(B_V, t):
            return ('degrade', a, 'budget_or_risk', trace)
        a = validation_step(a, r, J)             # a_{t+1}
    return ('degrade', a, 'budget', trace)
```

### IP-123 AVS（Active Validation Scheduling）

```python
def active_validation_policy(trace, B_V):
    belief = posterior_residual(trace)
    cands = ['continue', 'reprobe', 'commit', 'abort']
    def score(u):
        if u == 'commit' and not confident(belief):   # 未达置信上界不许 commit
            return -inf
        return expected_info_gain(u, belief) - lam_c * cost(u, B_V)
    return max(cands, key=score)
```

### IP-124 CFR（Certificate Freshness Refresh）

```python
def refresh_certificate(J, trace):
    kappa_hat = estimate_kappa(trace)
    N = len(trace)
    eps_N = (kappa_hat**N * trace[0][2]
             + bias_bound(trace) / (1 - kappa_hat)
             + noise_floor(kappa_hat, J.Sigma_T))
    fresh_until = now() + ttl(kappa_hat, eps_N, J.Sigma_T)
    if kappa_hat >= 1 or eps_N > eps_max or cond(J.O_J) > kappa_obs:
        return downgrade(J, 'needs_revalidation')      # 降级而非删除
    return IVC(J, kappa_hat, N, eps_N, J.T_wc, J.Sigma_T, fresh_until, trace)
```

### IP-125 RCD（Residual-Coupled Drift Detection）

```python
def residual_drift_detect(r_seq, window=20, h=5.0):
    # 对归一化残差做双侧 CUSUM，检出"缓慢漂移"而非单帧异常
    mu0 = median(r_seq[:window])
    s_hi = s_lo = 0.0
    for r in r_seq[window:]:
        s_hi = max(0.0, s_hi + (r - mu0) - 0.5)
        s_lo = max(0.0, s_lo + (mu0 - r) - 0.5)
        if s_hi > h:
            return ('drift_up', 'calibration_or_load')   # 标定漂移/负载变化
        if s_lo > h:
            return ('drift_down', 'sensor_occlusion')     # 遮挡/镜头污染
    return ('stable', None)
```

### IP-126 TCE（Trace Certificate Evidence chain）

```python
def evidence_chain(trace):
    # 每轮证据哈希成链，任何事后篡改可被检出；供跨轮/跨体复用审计
    prev = b'\x00' * 32
    chain = []
    for (t, a, r, oh, meta) in trace:
        node = sha256(prev + serialize(t, a, r, oh))
        chain.append(node); prev = node
    return MerkleRoot(chain)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| WVC | O(N·(d_o·d_T + d_T³)) | O(d_T²) | 可观测性门控、病态跳过 |
| IVL | O(N_max·(d_o + d_a)) | O(N_max) | κ̂<1、预算闭合 |
| AVS | O(|U|·N_max) | O(N_max) | 信息增益估计无偏、commit 置信门 |
| CFR | O(N_max + d_T³) | O(N_max) | 残差上界 sound、TTL 下界 |
| RCD | O(N·window) | O(window) | 漂移与单帧异常可区分 |
| TCE | O(N) | O(N) | 哈希链抗篡改 |

**正确性定理（Contraction-Bounded Iterative Validation Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增：**(A29)** 腕部观测噪声零均值、协方差有界 `Σ_o`；**(A30)** 验证算子 `V_κ` 在可达集 `Ω` 上 `κ`-压缩（`κ<1`）；**(A31)** 在激励轨迹上 `cond(O_J) ≤ κ_obs`，手眼标定可联合观测；**(A32)** 视觉残差与任务成功 `δ_proxy`-一致：`|1{task success} - 1{r ≤ ε_max}| ≤ δ_proxy`。
则经 `N` 轮迭代验证后，残差期望满足
```
E[r_N] ≤ κ^N·r_0 + b/(1-κ) + σ·sqrt((1-κ^{2N})/(1-κ²))
```
且部署成功概率
```
P_success ≥ 1 - P(ε_N > ε_max) - P(cond(O_J) > κ_obs) - δ_proxy - P(fresh_until < now)
```
**证明要点**：(A30) 给出残差递推 `r_{t+1} ≤ κ r_t + b + σξ`，展开得几何级数上界；(A31) 保证 `b` 不随标定漂移无界增长；(A32) 把"残差达标"桥接到"任务成功"，`δ_proxy` 即桥接损失。**关键**：`κ≥1` 时上界失效，系统必须 `abort`，这正是 IP-122 中 `estimate_kappa ≥ kappa_max` 立即中止的理论依据——**不可压缩的验证循环不是验证，而是自我安慰**。

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 手眼标定漂移 vs 验证准确率 | 漂移量 `||ΔT_wc||` × 残差 MAE | 漂移 < 2mm 时 MAE ≤ 0.03；可观测性门控使假阳性 ↓50% |
| E163 迭代预算 Pareto | `N_max` × (成功率, P95 时延) | 在 P95 ≤ 80ms 下成功率 ≥ 92% |
| E164 收缩率可估计性 | `|κ̂ - κ_true|` 与残差上界覆盖率 | κ̂ 误差 ≤ 0.05，上界覆盖 ≥ 95% |
| E165 腕部残差驱动的负迁移检测 | 漂移检出延迟 / 误报 | 检出 ≤ 5 周期，误报 ≤ 3% |
| E166 主动 vs 被动验证 | 单位时延成功率提升 | 主动 `reprobe` 提升 ≥ 10% |
| E167 验证过拟合红队 | 视觉残差达标但任务失败率 | `δ_proxy` 暴露并 ≤ 5% |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 手眼标定在退化运动下不可观测 | 高 | 主动激励轨迹 + `cond(O_J)` 监控 + 不可观时冻结标定 |
| 视觉残差与任务成功不一致（验证过拟合） | 高 | 多模态证据 + 任务级终检 + 红队构造 `δ_proxy` |
| 运动模糊/遮挡造成"假收敛" | 高 | 多帧曝光融合 + 不确定性门控 + 残差置信上界 |
| 迭代延迟超预算 | 中 | 早停 + `AVS` 预算调度 + 云端卸载低频重规划 |
| 证书频繁续期导致策略抖动 | 中 | TTL 下界 + hysteresis + 降级而非删除 |
| 腕部相机污染/碰撞 | 中 | 视窗自检 + 回退外部相机 + `RCD` 漂移告警 |

## 6. 本轮最大风险

**一句话**：腕部相机 + 迭代验证把静态证书升级为可续期的执行期证据链，但其 soundness **同时依赖验证算子的压缩性 κ<1、手眼标定的联合可观测性、以及视觉残差与任务成功的代理一致性 δ_proxy**；一旦退化运动使标定不可观、或迭代只优化视觉残差而偏离任务目标，"持续验证"会退化为**高置信度的自我欺骗**，故必须以 **主动激励 + 压缩性熔断 + 代理一致性红队** 三重护栏，宁可中止并降级，绝不把"残差收敛"当作"任务成功"。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim+++（WVC×IVL×AVS×CFR×RCD×TCE）

> 承接第 54 轮产物 v31（GroundEdge-GenSim+++，ACS×SCOM×CEC×AEC×JTC）。上一轮解决"技能如何在动作空间上可组合、云边如何对齐"，但证书是**一次性签发的静态对象**。本轮增加 **执行期迭代验证** 与 **腕部相机证据通道**，把"签发即信任"升级为"持续验证 + 证书续期"：
> - **WVC（Wrist Visual Calibration）**：用验证残差在线校准手眼标定，验证驱动校准；
> - **IVL（Iterative Validation Loop）**：逐控制周期的"观测-残差-修正"压缩闭环；
> - **AVS（Active Validation Scheduling）**：`continue/reprobe/commit/abort` 四选一的预算调度；
> - **CFR（Certificate Freshness Refresh）**：给联合证书加 TTL 与新鲜度，持续续期/降级；
> - **RCD（Residual-Coupled Drift Detection）**：残差 CUSUM 检出标定漂移/遮挡；
> - **TCE（Trace Certificate Evidence chain）**：哈希链证据，保证验证过程可审计、抗篡改。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/117/118 以纳入执行期验证维度。

### IP-121 WVC

```python
def wrist_calibrate(T_wc, wrist_stream, kappa_obs, o_min):
    Sigma_T = eye(6)
    for o_w, a_cmd, a_meas in wrist_stream:
        if observability(a_cmd) < o_min or cond(wrist_jacobian(o_w, T_wc)) > kappa_obs:
            continue                      # 不可观测/病态：冻结标定
        J = wrist_jacobian(o_w, T_wc)
        dx, Sigma_T = robust_update(J, residual(o_w, a_cmd), Sigma_T)
        T_wc = compose(T_wc, exp(dx))
    return T_wc, Sigma_T
```

### IP-122 IVL

```python
def iterative_validate(skill, a0, J, wrist, B_V, kappa_max, eps_max):
    a, trace = a0, []
    for t in range(B_V.N_max):
        o_w = wrist.capture()
        r = execution_residual(o_w, a)
        trace.append((t, a, r, hash(o_w), o_w.meta))
        if r <= eps_max:
            return ('commit', a, refresh_certificate(J, trace), trace)
        if estimate_kappa(trace) >= kappa_max:
            return ('abort', a, 'non_contractive', trace)   # 压缩性熔断
        u = active_validation_policy(trace, B_V)
        if u == 'reprobe':
            wrist.reprobe(); continue
        if u == 'abort' or budget_exhausted(B_V, t):
            return ('degrade', a, 'budget_or_risk', trace)
        a = validation_step(a, r, J)
    return ('degrade', a, 'budget', trace)
```

### IP-123 AVS

```python
def active_validation_policy(trace, B_V):
    belief = posterior_residual(trace)
    cands = ['continue', 'reprobe', 'commit', 'abort']
    def score(u):
        if u == 'commit' and not confident(belief):   # 需残差置信上界达标
            return -inf
        return expected_info_gain(u, belief) - lam_c * cost(u, B_V)
    return max(cands, key=score)
```

### IP-124 CFR

```python
def refresh_certificate(J, trace):
    kappa_hat = estimate_kappa(trace); N = len(trace)
    eps_N = (kappa_hat**N * trace[0][2]
             + bias_bound(trace) / (1 - kappa_hat)
             + noise_floor(kappa_hat, J.Sigma_T))
    fresh_until = now() + ttl(kappa_hat, eps_N, J.Sigma_T)
    if kappa_hat >= 1 or eps_N > eps_max or cond(J.O_J) > kappa_obs:
        return downgrade(J, 'needs_revalidation')      # 降级，不静默删除
    return IVC(J, kappa_hat, N, eps_N, J.T_wc, J.Sigma_T, fresh_until, trace)
```

### IP-125 RCD

```python
def residual_drift_detect(r_seq, window=20, h=5.0):
    mu0 = median(r_seq[:window]); s_hi = s_lo = 0.0
    for r in r_seq[window:]:
        s_hi = max(0.0, s_hi + (r - mu0) - 0.5)
        s_lo = max(0.0, s_lo + (mu0 - r) - 0.5)
        if s_hi > h: return ('drift_up', 'calibration_or_load')
        if s_lo > h: return ('drift_down', 'sensor_occlusion')
    return ('stable', None)
```

### IP-126 TCE

```python
def evidence_chain(trace):
    prev = b'\x00' * 32; chain = []
    for (t, a, r, oh, meta) in trace:
        node = sha256(prev + serialize(t, a, r, oh)); chain.append(node); prev = node
    return MerkleRoot(chain)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| WVC | O(N·(d_o·d_T + d_T³)) | O(d_T²) | 可观测性门控，病态跳过 |
| IVL | O(N_max·(d_o + d_a)) | O(N_max) | κ̂<1，预算闭合，熔断 |
| AVS | O(|U|·N_max) | O(N_max) | commit 置信门，信息增益无偏 |
| CFR | O(N_max + d_T³) | O(N_max) | `ε_N` sound，TTL 下界 |
| RCD | O(N·window) | O(window) | 漂移/单帧异常可区分 |
| TCE | O(N) | O(N) | 哈希链抗篡改 |

**正确性定理（Contraction-Bounded Iterative Validation Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增 **(A29)** 腕部噪声零均值有界；**(A30)** `V_κ` 在 `Ω` 上 κ-压缩（κ<1）；**(A31)** 激励轨迹上 `cond(O_J)≤κ_obs`；**(A32)** 残差与任务成功 `δ_proxy`-一致。则
```
E[r_N] ≤ κ^N·r_0 + b/(1-κ) + σ·sqrt((1-κ^{2N})/(1-κ²))
P_success ≥ 1 - P(ε_N>ε_max) - P(cond(O_J)>κ_obs) - δ_proxy - P(fresh_until<now)
```
关键：**压缩性保证残差收敛，联合可观测性保证偏置有界，代理一致性把残差桥接到任务成功**；三者任一失效，验证即退化为自我安慰。

## 5. 本轮最大风险

**一句话**：腕部相机 + 迭代验证把静态证书升级为可续期的执行期证据链，但其 soundness **同时依赖验证算子的压缩性 κ<1、手眼标定的联合可观测性、以及视觉残差与任务成功的代理一致性 δ_proxy**；一旦退化运动使标定不可观、或迭代只优化视觉残差而偏离任务目标，"持续验证"会退化为**高置信度的自我欺骗**，故必须以 **主动激励 + 压缩性熔断 + 代理一致性红队** 三重护栏，宁可中止并降级，绝不把"残差收敛"当作"任务成功"。
