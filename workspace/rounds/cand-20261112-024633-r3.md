# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 3 轮；本轮灵感：「数据采集」×「安全交互」）

> 第 57 轮把安全赌注从"模型置信"移到"证据质量"，再用元先验摊销 + 共形保底把先验质量兜住，似乎让"看不到的世界"也有了退路。但它把元训练语料 𝓓_meta={(R_j,O_j,θ̂_j)} 当成天上掉下来的、诚实且无偏的样本——从未追问：**这份语料是怎么被采集出来的？采集它本身冒了什么险？谁同意它被用于此？** 本轮两个灵感恰好从两侧戳中同一件事：**数据采集不是先验的中立来源，而是一次被安全策略筛选、带物理风险、带同意边界的安全交互**。**(a)** 机器人只在"觉得够安全"的区域探针，危险区域在语料里系统性缺席，元先验于是在最危险处被喂了最少、且经幸存者筛选的数据——不是"样本少"，而是"样本偏"，更糟的是最危险处 π_sel=0，是统计上还不清的支撑缺口（positivity 失效）；**(b)** 要消盲就必须与盲区交互，而交互可能不可逆，"采集"与"承诺"抢同一份安全预算，若允许用未来信息为当下冒险背书，就是证据双花；**(c)** 开放采集（人类示教、云端增量、众包标注）使来源、同意范围、完整性都成为攻击面，一条被撤回同意或来源可疑的数据能否决整条证据链。本轮把数据采集提升为一等安全对象：**偏置校正元学习**先给语料去偏并显式核算**数据债务**；**风险预算主动采集**让"为信息冒的险"成为不可挪用的账；**来源-同意账本**让每条数据可追溯、可撤回、可隔离；**人类在环采集契约**把示教/遥操作/标注本身当作安全交互。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"采集可去偏、探索有预算、来源可追溯且经同意的证据说可信"**。

核心矛盾：
- **H29（采样偏置 vs 校准）**：𝓓_meta 由部署安全策略的选择性采样生成，p_obs ∝ p_dep·π_sel；危险区域 π_sel 低甚至为 0，元先验因此在最危险处最乐观。样本少只是表象，样本"偏"才是病根；而脱偏需要重叠性（positivity），最危险区域恰恰是 π_sel=0 的支撑缺口——统计上不可还的债。
- **H30（信息增益 vs 不可逆风险）**：要消除盲区必须与盲区交互，而交互本身可能造成不可逆后果；"采集"与"承诺"抢同一份安全预算。若允许用未来信息为当下的冒险背书，就是证据双花：先花风险买数据，再用数据证明当初冒险值得。
- **H31（来源/同意 vs 可用性）**：开放采集使来源、同意范围、完整性都成为攻击面；投毒数据、超范围使用、撤回同意都会让证据链失效。安全交互不仅是"机器人别伤人"，还是"别用未经同意/来路不明的数据去冒险"；把"数据多"当成"证据强"，是又一种信任通胀。

## 0. 直觉与动机

**灵感 1（数据采集 → 偏置校正 + 数据债务）**
直觉：元语料像"只调查了富人区的普查"——不是样本少，而是采样机制本身把危险区筛掉了，不能直接把普查均值当全国均值。先记账：每条数据带它的"被采概率"π_sel，用逆概率加权/删失似然把观测分布拉回部署分布；再记债：哪些区域类根本没人采过、去偏后的有效样本量还剩多少，未覆盖部分记为**数据债务**，只能靠有界安全探针偿还，还不清就自动退回共形宽区间。校准证书只在"去偏后有效样本量够"的区域类上生效——**先证明样本能代表世界，再谈样本能校准信念**。

**灵感 2（安全交互 → 风险预算主动采集 + 证据不可双花）**
直觉：采集是"花钱买信息"，而这钱是不可逆风险。给探索设一张**风险信用卡**：每次采集的期望信息增益按单位风险计价（EIG/R），总额受 CVaR 预算约束；不可逆动作永远不能纯为信息而做，只能用可逆代理（轻触/仿真/迁移）换信息。最关键的一条：采集花掉的风险记在部署安全账上，**不能**因为"后来学到了"就销账——否则系统会学会"先冒险、再用冒险得来的数据证明冒险合理"。

**灵感 3（数据采集 → 来源-同意账本，可追溯可撤回可隔离）**
直觉：第 57 轮让"判定器走隔离"，本轮让"数据本身走隔离"。每条数据携带来源链（谁采、何时、何上下文、同意范围、哈希指纹、有效期）；用途超出同意格直接隔离；来源可疑（跨源不一致/投毒特征）进隔离区且不参与元训练；一旦同意撤回，用影响函数定位"哪些信念/承诺用过它"，回滚并重认证。数据不是资产，是**带授权与保质期的证据**。

**灵感 4（安全交互 → 人类在环采集契约，示教也是安全交互）**
直觉：示教、遥操作、众包标注都是"人为了给机器人数据而进入危险回路"。三重安全：**物理安全包络**（力/速度/功率/人机距离/看门狗）、**隐私差分预算**（采集人类数据要加噪、限用途）、**示教有效性**（被人接管/纠正过的片段标为 recovery 负样本，绝不当模仿目标——学坏示范比没数据更危险）。安全交互的第一性原理：不应为了获得能力而让提供数据的人承担未同意的风险。

**灵感 5（合流 → 证据门加"数据维度"，从五层到六层）**
直觉：第 57 轮五类证据各长出"来源维度"：EV-probe* 必须挂**去偏后覆盖率与 ESS 证书**；EV-human 必须挂**同意范围与来源完整**；新增 **EV-support**（某区域类的支撑与偏置已核算）作为"敢用元先验"的前置。击穿安全需要：选择偏置没校正 ∧ 支撑缺口被误判为已覆盖 ∧ 采集预算被双花 ∧ 来源/同意失效 ∧ 元先验错 ∧ 模态共谋 ∧ 人也错——纵深从五层到六层。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（选择性采集与偏置校正元学习 BCML）** 部署分布 p_dep(z)，采集策略 π_sel(z)=P(区域被探|z, 部署安全策略)，观测语料 z_i∼p_obs(z)∝p_dep(z)·π_sel(z)。逆概率权 w_i=min(1/π_sel(z_i), w_max)（截断控方差），去偏经验分布 p̂_dep=Σ_i w_i δ_{z_i}/Σ_i w_i，有效样本量 ESS(c)=(Σ_{i∈c}w_i)²/Σ_{i∈c}w_i²。对"到访但未探"的区域用删失似然 ℓ_cens(θ)=Σ_i log p(sel_i|z_i,θ)+Σ_{unprobed} log P(unprobed|z,θ)。元推断 q_φ 以去偏语料训练，校准契约只在 ESS(c)≥n_min 的区域类 c 上声明 ECE≤ε_meta。**数据债务** Debt(c)=max(0, n_req(c)−ESS(c))；若 positivity 在 c 上失效（p_dep 支撑内存在 π_sel=0）则 Debt(c)=∞。仅当所有相关类 positivity 成立时，才可声称"已去偏"；否则只能给保守界。

**定义 140（风险预算主动采集 RBAD）** 采集动作 a（探针/轻触/示教请求/仿真查询），信息增益 EIG(a)=H[θ|o]−E_{o'}[H[θ|o,a]]，风险 R(a,r)=CVaR_α[Loss|a,r]，irr(a) 为不可逆指示。部署期探索预算 B_safe(t)（按风险分配、跨检查点不可透支）。采集策略：a\*=argmax_a EIG(a)/max(R(a),ε) s.t. R(a,r)≤B_safe(t) ∧ (¬irr(a) ∨ a∈已认证可逆包络)。**证据不可双花律**：R(a,r) 一经支出即计入部署安全账，不得以"采集所得信息"抵消，更不得用信息为不可逆动作背书。数据债务只能用非不可逆采集、或已声明 sim-to-real 差距的仿真/跨区迁移代理偿还。

**定义 141（来源-同意账本 CPL）** 数据项 x 携带来源证明 p_x=(collector, t, ctx, consent_scope, chain_hash, expiry, DP_budget)。同意格 𝒞 为偏序集（train⊑eval⊑explain⊑audit），用途 u 合法 ⇔ u∈consent_scope(x)。来源可信度 rep(x) 由跨源一致性、链完整、历史证伪更新；投毒检测：同源批内异常 ∧ 跨源矛盾 ⇒ 进隔离。撤回/过期：以影响函数 I(x,θ̂) 定位受影响信念与承诺，回滚到不含 x 的检查点并重认证；无法回滚的承诺登记为"数据依赖负债"。CPL 输出可用集 𝓓_use 与隔离集 𝓓_quar，只有 𝓓_use 可进元训练与证据链。

**定义 142（人类在环采集安全契约 HIDC）** 采集会话 s∈{teleop, demo, label}，物理包络 ℰ_phys=(F_max, v_max, P_max, d_safe^human, τ_watchdog)，任一越界 ⇒ 安全接管并终止会话。隐私：每次人类数据采集有差分预算 ε_dp，跨会话总预算 ε_dp^tot，超预算即停采或仅保留聚合统计。示教有效性：片段内发生人类接管/纠正即标为 recovery 负样本（不进模仿目标），并校验演示本身在其包络内。同意级 consent_h 决定数据可用于训练/评测/解释/审计。

**定义 143（数据覆盖证据门 DCG 与证书 J_d，升级 FSE）** 元证据 EV-probe* 除第 57 轮条件外，须挂**覆盖率证书** (ESS(c), Debt(c), positivity[c])：Debt(c)>θ_debt 或 positivity 失效 ⇒ 该类禁用元先验，强制共形宽区间，且宽度随 Debt 单调外扩。EV-human 须挂来源完整与同意范围。新增证据类 **EV-support**（某区域类支撑/偏置已核算且 Debt≤θ_debt）作为元先验可用性的前置；EV-support 不得单独支撑不可逆接触。数据来源/同意失效 ⇒ 相关证据整体隔离。J_d=J_p∪(selection_log, π_sel_est, ESS_report, debt_ledger, provenance, consent_scope, dp_budget, retraction_log, poison_flags)。

**定义 144（探-诺-演×采 PCED，升级 PCX）** 每检查点在第 57 轮之上插入采集决策：①若目标区类 Debt>θ_debt 且存在非不可逆采集 a 满足风险预算 ⇒ 先采集偿债（按 EIG/R 排序），否则信念按 Debt 外扩；②来源/同意检查：𝓓_use 不足 ⇒ 拒用元先验、退共形；③承诺/绕行/降档/协商同第 57 轮。单调律：采集只能 (i) 扩大有效样本使信念更准（且须经独立证据复核），或 (ii) 在预算不足时使动作更保守；采集所得"更准"**不得**直接降低接触等级或升级授权。终止界 k_probes+k_cons+k_acq。

## 2. 关键算法伪代码（完整版见产物区）

```python
def debias_corpus(corpus, pi_sel, classes):        # IP-139
    use = []
    for x in corpus:
        if not consent_ok(x) or poisoned(x): quarantine(x); continue
        use.append((x, min(1.0 / pi_sel[x.z], W_TRUNC)))
    debt = {}
    for c in classes:
        ws = [w for x, w in use if class_of(x) == c]
        ess = sum(ws) ** 2 / max(sum(w * w for w in ws), EPS)
        debt[c] = INF if not pi_sel.positivity(c) else max(0, N_REQ[c] - ess)
    return reweight(use), debt

def risk_budgeted_acquire(M, r, budget):           # IP-140
    cands = [a for a in admissible_acquisitions(r) if not a.irreversible]
    a = max(cands, key=lambda a: eig(a, M) / max(cvar(a, r), EPS))
    if cvar(a, r) > budget.left: return None
    budget.charge(cvar(a, r))                      # 不可双花：计入部署安全账
    return a

def data_gate(ev, debt, prov, consent):            # IP-143
    if ev.kind == 'EV-probe*':
        if debt[ev.cls] > THETA_DEBT or not prov.positivity[ev.cls]:
            return ('reject', 'data_debt_or_no_overlap', ev.cls)
        if ev.ess < N_MIN[ev.cls] or ev.ece > eps_meta(ev.k):
            return ('widen', 'meta_uncertified', debt[ev.cls])
    if ev.kind == 'EV-human' and not consent.covers(ev.use, ev.scope):
        return ('reject', 'consent_scope', ev.use)
    return ('ok', None, 0)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| BCML | O(N·d) 去偏 + O(d_φ)/探针 | O(\|𝓓_use\|) | positivity 声明、ESS/Debt 诚实（A41） |
| RBAD | O(\|A\|·(EIG+CVaR)) | O(\|A\|) | 不可双花、不可逆禁采集（A42） |
| CPL | O(log N)/项；撤回 O(N·d) | O(N·d) | 来源链、同意格、撤回完整（A43） |
| HIDC | O(1)/会话 | O(H) | 包络、DP 预算、示教有效性（A44） |
| DCG | O(\|σ\|+N) | O(\|σ\|) | Debt≤θ_debt、来源合格、EV-support 不单独 |
| PCED | O(\|CP\|·(k_p+k_c+k_acq)·(C_VOI+d_φ)) | O(\|V\|+\|σ\|) | 采集单调、k_p+k_c+k_acq 终止 |

**正确性定理（Data-Interaction Calibrated Soundness, DICS 概要）**：在 A33–A40 上加 (A41) positivity 与 π_sel 估计诚实：参与元先验的区域类满足 π_sel≥π_min 且声明真实，ESS/Debt 报告不虚报；(A42) 风险预算不可双花：采集风险即时计入部署账、不可逆禁采集、CVaR 估计保守；(A43) 来源与同意：来源链完整、同意格可验证、影响函数撤回覆盖全部受影响承诺；(A44) 人类在环契约：物理包络与 DP 预算真实执行、示教有效性标注诚实。则：(i) **去偏承诺健全性**：在 positivity 成立的区域类，ID 路径 P(fail) ≤ δ_f+ε_meta(k)+δ_probe+ε_h+δ_sel（δ_sel 为 π_sel 估计误差）；positivity 失效处不存在该界，只能走共形宽区间，其宽度按 Debt 单调外扩。(ii) **采集单调性**：RBAD/DCG 只能增加采集、加宽信念或拒用元先验；证据不可双花 ⇒ 探索不产生"安全信用"，不得据此降低接触等级或升级授权。(iii) **撤回正确性**：撤回后受影响承诺要么回滚、要么登记为数据依赖负债，不留"用过脏数据却无标记"的承诺。(iv) **终止性**：PCED 在 k_probes+k_cons+k_acq 内终止于 {承诺, 绕行, L2 协商, 安全停}。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| positivity 失效被误当"已去偏" | 高 | Debt=∞ 显式登记、拒用元先验、共形宽区间、仿真/迁移代理并声明 sim-real gap |
| π_sel 估计不准 → 去偏反而放大偏差 | 高 | 权重截断、ESS 监控、π_sel 变点检测、回退无权重悲观界 |

| 来源/同意/投毒 | 中高 | 来源链 + 跨源一致性 + 隔离区 + 影响函数撤回 |

| 采集成本拖慢任务 | 中 | 预算上限、EIG/R 排序、仿真/迁移代理 |

## 6. 本轮最大风险

**一句话**：本轮最大风险是**不可偿还的数据债务被统计学伪装成"已校正"**——当 positivity 在危险区域类上失效时，任何逆概率加权都只是对"从未被安全探过的世界"的虚构外推；若系统把"去偏后的高置信"当成真的，它就会在语料支撑之外给出比第 57 轮更硬、也更危险的安全承诺，因此必须以 Debt=∞、拒用元先验与共形宽区间，把"没采过的世界"永远当未知，而不是当已被校正。

### IP-139 BCML（偏置校正元学习 + 数据债务）

```python
def debias_corpus(corpus, pi_sel, classes):
    """把被安全策略筛选过的语料拉回部署分布，并核算债务。"""
    use, quar = [], []
    for x in corpus:
        if not consent_ok(x) or poisoned(x):
            quar.append(x); continue                 # 来源/同意不合格 → 隔离
        w = min(1.0 / pi_sel[x.z], W_TRUNC)           # 截断逆概率权
        use.append((x, w))
    debt = {}
    for c in classes:
        ws = [w for x, w in use if class_of(x) == c]
        if not pi_sel.positivity(c):                  # π_sel=0 的支撑缺口
            debt[c] = INF                             # 统计上不可还的债
        else:
            ess = sum(ws) ** 2 / max(sum(w * w for w in ws), EPS)
            debt[c] = max(0, N_REQ[c] - ess)
    return reweight(use), debt, quar

def meta_few_shot_infer_d(M, r, obs, meta, debt):
    c = class_of_region(r)
    if debt[c] > THETA_DEBT or not meta.positivity(c):
        return Inf(cls='OOD', belt=conformal_belt(meta.res, sim=ctx(r),
                                                  alpha=alpha_conf,
                                                  inflate=debt[c]))  # 宽区间
    inf = meta_few_shot_infer(M, r, obs, meta)        # 第 57 轮摊销推断
    inf.ece_k = meta.ece_decl[len(obs)] if inf.ess >= N_MIN[c] else INF
    return inf
```

### IP-140 RBAD（风险预算主动采集 + 证据不可双花）

```python
def risk_budgeted_acquire(M, r, budget, acq_log):
    """只允许非不可逆采集；风险即时入账，不能被信息抵消。"""
    cands = [a for a in admissible_acquisitions(r) if not a.irreversible]
    if not cands: return None
    a = max(cands, key=lambda a: eig(a, M) / max(cvar(a, r), EPS))  # EIG/R
    cost = cvar(a, r)
    if cost > budget.left:
        return None                                   # 预算不足 → 不采集
    budget.charge(cost)                               # 记入部署安全账
    acq_log.record(a, cost, irreversibility=False)    # 不可双花审计依据
    return a

def pay_debt(M, region, debt, budget, acq_log):
    if debt[class_of_region(region)] <= THETA_DEBT:
        return M, False
    a = risk_budgeted_acquire(M, region, budget, acq_log)
    if a is None:
        return widen_by_debt(M, region, debt), False  # 还不起 → 保守加宽
    return execute_and_fuse(M, region, a), True       # 采集后需独立证据复核
```

```python
def data_coverage_gate(c, M, debt, prov, consent):
    if c.ev == 'EV-probe*':
        if debt[c.cls] > THETA_DEBT or not prov.positivity[c.cls]:
            return ('reject', 'data_debt_or_no_overlap', c.cls)
        if c.inf.ess < N_MIN[c.cls]:
            return ('widen', 'ess_insufficient', c.inf.ess)
        if c.inf.cls == 'ID' and c.inf.ece_k > eps_meta(c.k):
            return ('widen', 'meta_uncertified', c.inf.ece_k)
    elif c.ev == 'EV-support':
        if not (debt[c.cls] <= THETA_DEBT and prov.positivity[c.cls]):
            return ('reject', 'support_unverified', c.cls)
        if c.irreversible:
            return ('reject', 'ev_support_not_standalone', None)
    elif c.ev == 'EV-human':
        if not consent.covers(c.use, c.scope):
            return ('reject', 'consent_scope', c.use)
        if not provenance_complete(c):
            return ('reject', 'provenance_incomplete', None)
    elif c.ev in ('EV-xmodal', 'EV-visit', 'EV-margin'):
        ok = round57_checks(c, M)                     # 继承第 57 轮
        if not ok: return ('reject', 'round57_gate', None)
    else:
        return ('reject', 'no_evidence_class', None)
    return ('ok', None, 0)

def certificate_d(sched, M, debt, prov, consent, logs):
    for c in contacts(sched):
        st = data_coverage_gate(c, M, debt, prov, consent)
        if st[0] != 'ok': return st
    if any(debt[class_of_region(r)] > THETA_DEBT for r in reachable(sched)):
        return ('reject', 'unpaid_data_debt')
    return ('ok', Jd(M.core, sched, debt, prov, consent, logs))
```

def probe_commit_evolve_collect(x0, M, task, budget, consent, personas, debt):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| BCML | O(N·d) 去偏 + O(d_φ)/探针 | O(\|𝓓_use\|) | positivity/ESS/Debt 诚实（A41） |
| RBAD | O(\|A\|·(EIG+CVaR)) | O(\|A\|) | 不可双花、不可逆禁采集（A42） |
| CPL | O(log N)/项；撤回 O(N·d) | O(N·d) | 来源链、同意格、撤回完整（A43） |
| HIDC | O(1)/会话 | O(H) | 包络/DP/示教有效性（A44） |
| DCG | O(\|σ\|+N) | O(\|σ\|) | Debt≤θ_debt、EV-support 不单独 |
| PCED | O(\|CP\|·(k_p+k_c+k_acq)·(C_VOI+d_φ)) | O(\|V\|+\|σ\|) | 采集单调、k_acq 终止、四态完备 |

**正确性定理（Data-Interaction Calibrated Soundness, DICS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** positivity 与 π_sel 估计诚实：参与元先验的区域类满足 π_sel≥π_min 且声明真实，ESS/Debt 不虚报；**(A42)** 风险预算不可双花：采集风险即时计入部署账、不可逆禁采集、CVaR 估计保守；**(A43)** 来源与同意：来源链完整、同意格可验证、影响函数撤回覆盖全部受影响信念与承诺；**(A44)** 人类在环契约：物理包络与 DP 预算真实执行、示教有效性（recovery）标注诚实。则：

1. **去偏承诺健全性**：在 positivity 成立的区域类，ID 路径 `P(fail) ≤ δ_f + ε_meta(k) + δ_probe + ε_h + δ_sel`，其中 δ_sel 为 π_sel 估计误差；positivity 失效处**不存在**该界，只能走共形宽区间，宽度按 Debt 单调外扩。
2. **采集单调性**：RBAD/DCG 只能增加采集、加宽信念或拒用元先验；证据不可双花 ⇒ 探索不产生"安全信用"，不得据此降低接触等级或升级授权。
3. **撤回正确性**：撤回后受影响承诺要么回滚、要么登记为数据依赖负债，不留"用过脏数据却无标记"的承诺；来源/同意失效的证据整体隔离。
4. **终止性**：每检查点采集 ≤k_acq，PCED 在 k_probes+k_cons+k_acq 内终止于 {承诺, 绕行, L2 协商, 安全停}。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_sel + δ_ood·α_conf + δ_xm·1[L1])
             − P(positivity 失效未被识别) − P(采集预算双花未被审计)
             − P(来源/同意失效未隔离) − P(人类在环包络/DP 失效)
```

关键：**先证明样本能代表世界，再谈样本能校准信念**（去偏与债务核算先于元推断）；**探索花的是不可逆风险、不是免费信息**（风险即时入账、证据不可双花）；**数据是带授权与保质期的证据**（来源链、同意格、可撤回隔离）；**示教也是安全交互**（物理包络 + 隐私预算 + recovery 标注）。四者全部经"信念更准（且经独立复核）或动作更保守"两个安全通道起作用。

云边协议 CEB++ → **CEB-D**：云端可下发元模型增量与语料补盲包，但**数据也要过隔离区**——先验证来源链、同意范围、投毒检疫与去偏后 ESS/Debt，再以影子模式在边端探针流上运行；校准回归测试（ECE 不劣化 ∧ positivity 声明一致 ∧ Debt 不增加 ∧ OOD 检出率不降）通过后才接管承诺判定。边端回传去偏残差、证伪事件、撤回事件与采集风险账，作为云端补盲与审计依据。第 57 轮"一切判定器走隔离"在本轮推广为 **"数据与判定器都走隔离"**。

## 6. 本轮最大风险

**一句话**：本轮最大风险是**不可偿还的数据债务被统计学伪装成"已校正"**——当 positivity 在危险区域类上失效时，任何逆概率加权都只是对"从未被安全探过的世界"的虚构外推；若系统把"去偏后的高置信"当成真的，它就会在语料支撑之外给出比第 57 轮更硬、也更危险的安全承诺，因此必须以 Debt=∞、拒用元先验与共形宽区间，把"没采过的世界"永远当未知，而不是当已被校正。
