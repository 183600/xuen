研究循环·新灵感三元组第 2 轮；本轮灵感：「低成本方案」×「任务分解」

> **基线**：第 2 轮产出 MetricVoiceGauge-NCD-HUTDH-v23+IP-436–439（云边同步 CESC / 少样本 FSVC / 知识产权 IPAM / 四证一体 HPC-E+），其上承 v22 的 HDL/ACSC/DCSC/HPC-E/CFC++ 与 v21 的 SDC/CAC/DCL/GIC，再下承 v20 的 PCA/CTS/CFC/HPC/CFCtrl 与 v19/v17 全链。
> 本轮纪律：**不推倒 v23**。v23 的每个证书模块、每条引理全部保留；本轮只做一件事：**把「一张又大又贵的全局证书」重构成「一棵由离线预认证技能 + 契约组合 + 按需升级验证构成的低成本证书树」**，并证明这棵树的执行集仍是 v23 的子集。

## 0. 直觉与动机

**灵感 1（任务分解 → 证书的组合代数与 assume-guarantee）**
直觉：v23 的准入门是「单体」的——送一杯水被当成一个原子计划，要求整条链（HPC-E 几何 + CESC 云边 + FSVC 覆盖 + IPAttest 专利）在每一步同时成立。但真实任务天然分层：导航到桌边 → 抓杯 → 端到人前 → 交接。四个阶段触碰的状态不同、风险不同、需要的证书也不同。任务分解的洞见是：**把全局证明切成局部证明 + 接口证明**。每个子任务只对「入口状态到出口状态」做契约（contract），组合定理保证：只要相邻契约首尾相接（`Post_i ⊆ Pre_{i+1}`）且接口状态被认证，整条计划的证书就能由局部证书机械拼接，无需重证全局。反直觉点：**分解并不减少总验证量，它改变验证的形状**——把一次性昂贵的全局搜索，换成大量廉价的局部查表 + 少量接口检查；真正的收益来自**局部性**（可缓存、可复用、可并行、只需重验变化的那一段）。

**灵感 2（低成本方案 → 把安全预算花在刀刃上）**
直觉：v23 已经出现「证书通胀」：每 200ms 云边同步、每个新环境 K-shot 标注、5000 条 conformal 校准样本、每次部署全量专利扫描。安全论证严密，但工程上昂贵到难以落地。低成本的本质不是「降低安全标准」，而是**在保持 soundness（保守性）的前提下，用更便宜的证书替代更紧的证书**。三条杠杆：(a) **离线摊销**——原子技能离线认证一次，运行期只做 O(1) 查表，单次成本趋近于零；(b) **anytime 升级验证**——先用便宜但保守的界，绝大多数情况直接放行，只有「便宜界判不了」的少数情况才升级到昂贵的紧界；(c) **事件触发刷新**——用证书谓词的 Lipschitz 常数给出「状态变化多小证书仍有效」的严格判据，小扰动不重算。反直觉点：**一个 sound 的便宜证书优于一个紧的昂贵证书**，因为安全只需要 soundness，紧致度只是活性问题；只要便宜证书更保守，`Exec` 只会收缩，子集链不会被破坏。

**两者如何统一**
统一为 **「低成本可组合证书」（Low-Cost Composable Certificates, LCCC）**：任务分解把全局证书拆成一棵证书树（CCL 契约代数 + CSL 预认证技能库），低成本让树上每个节点都便宜（ACV anytime 阶梯 + ETR 事件刷新 + CDG 证书摘要）。组合定理是胶水：契约逐段相接 ⟹ 整树 sound ⟹ `Exec_v24 ⊆ Exec_v23`。选哪种分解，由**成本感知的任务分解器**决定：在候选分解中选「预认证技能覆盖率最高、接口数最少、契约包络最紧」的那一个——即**最便宜的那个 sound 分解**。

## 1. 研究问题（轮次升级版）

- **Q12（契约的可靠性边界）**：离线预认证技能 `s` 的契约 `(Pre_s, Post_s)` 如何做到对 `Pre_s` 内**所有**入口状态成立（全称保证），而非只在采样到的有限状态上成立？包络 `Env_s ⊇ Pre_s` 如何标定，使 `Pre_s` 不过度承诺？契约失效（实际入口越出包络）时如何 fail-safe 退回单体 v23 门？

## 2. 设计原则（在 P37–P42 基础上新增 P43–P46）

**P43 契约组合律（Assume-Guarantee Composition）**
每个子任务 `τ` 携带契约 `C_τ = (Pre_τ, Post_τ, R_τ, Φ_τ, S_τ)`（入口/出口状态谓词、资源上界、证书义务集、swept 区域）。串行组合 `π = τ_1;…;τ_n` 合法当且仅当 `Post_{τ_i} ⊆ Pre_{τ_{i+1}}` 且 `⋃S_{τ_i}` 的接口被认证；合法时 `C_π = (Pre_{τ_1}, Post_{τ_n}, ΣR, ⋃Φ, ⋃S)`。**组合只增加合取检查，不放大可达集**，故 `Exec_v24 ⊆ Exec_v23`。

**P44 离线摊销律（Offline Amortization）**
技能库 `SkillLib` 中每个技能入库时以 v23 全门做一次全称证明（覆盖整个 `Pre` 包络），运行期只做 O(1) 契约查表。**摊销前提**：契约必须对 `Pre` 全称成立；若运行时入口越出 `Pre`，立即作废该查表结果并回退单体 v23 门（保守）。

**P45 Anytime 可靠律（Anytime Soundness）**
验证器维护界阶梯 `A_0 ⊆ A_1 ⊆ … ⊆ A_K = Exec_v23`，成本随级数递增，**每一级都 sound**。接受只能发生在某一 sound 级内；预算耗尽即拒证。升级只增加被判定的集合，不引入不 sound 的判定。

**P46 惰性刷新律（Lazy Refresh / Lipschitz）**
证书 `c` 在锚点 `s_0` 处有效，其谓词 Lipschitz 常数 `L_c`、有效裕度 `m_c`。当 `L_c·‖s − s_0‖ < m_c` 时证书继续有效，可跳过重算；越界即强制重算。刷新调度保证任意证书在下一次过期前被重算（无漏刷）。

## 3. 与基线的接口（如何退化）

- SkillLib 未覆盖某子任务 ⇒ 该子任务退回单体 v23 门（等价 v23，更贵但 sound）；
- 契约入口越出 `Pre`（包络泄漏）⇒ 作废查表、回退 v23 全门；
- ACV 预算不足/阶梯耗尽 ⇒ 保守拒证（活性损失，安全不退）；
- ETR 漏刷检测（`L_c·δ ≥ m_c`）⇒ 强制全量重算；
- CCL 组合失败（接口不相接）⇒ 该分解非法，退回上一级分解或单体 v23；
- 所有新模块全失效 ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18`。

## 4. 预期贡献

1. **证书组合代数**：给出子任务契约的串行/并行组合规则与 assume-guarantee 组合定理，使全局安全证明可由局部证明机械拼接；
2. **低成本证书树**：离线预认证技能库 + anytime 升级验证 + 事件触发刷新 + 证书摘要，把运行期验证从「全量重证」降为「O(1) 查表 + 有界预算」；
3. **成本感知任务分解**：以「预认证覆盖率 / 接口数 / 契约紧致度」为目标的分解选择，把「最便宜的 sound 分解」形式化为优化问题；
4. **子集链保持**：证明 `Exec_v24 ⊆ Exec_v23`，且任意单点/组合失效都向更保守方向退化；
5. **可度量的成本模型**：给出计算/带宽/标注三维成本核算，量化离线摊销与分解开销的盈亏平衡点。

## 5. 本轮最大风险

**一句话**：低成本倾向选择更乐观（更省验证）的契约包络，任务分解又把全局证明切成局部证明，二者的交汇点正是**接口契约**——一旦某个局部契约在包络边界或动态接口处过度承诺，组合定理仍会形式成立，而拼出的整条计划已悄悄越过 v23 的真实安全域，即「**组合安全幻觉**」（local soundness 不蕴含 global soundness）。

# ============================================================
# IP-440 Cultural Parameter Certificate (CPC) — 文化参数证书
# ============================================================
from dataclasses import dataclass
from typing import Callable, Optional
import torch
import numpy as np

@dataclass
class CulturalParameterCert:
    """单个文化参数的证书"""
    param_id: str                    # 如 "social_distance", "yield_weight", "taboo_topology"
    value: float                     # 当前值
    confidence_interval: tuple[float, float]  # [c_low, c_high]
    source: str                      # "anthropology:paper_id" | "crowdsourcing:batch_id" | "online_learning:session_id"
    applies_predicate: Callable[[dict], bool]  # 适用性谓词：context → bool
    version: int                     # v_cult
    sig: bytes                       # 签名
    
    def is_valid(self, context: dict) -> bool:
        """检查证书在当前上下文下是否有效"""
        if not self.applies_predicate(context):
            return False
        # 置信区间非空
        if self.confidence_interval[0] > self.confidence_interval[1]:
            return False
        return True
    
    def conservative_value(self) -> float:
        """失效/无证时的最保守值"""
        # 社交距离取上界，让行权重取上界，禁忌拓扑全开
        conservative_map = {
            "social_distance": self.confidence_interval[1],
            "yield_weight": self.confidence_interval[1],
            "taboo_topology": 1.0,
            "gaze_expectation": 1.0,
            "passing_preference": 0.5  # 中性
        }
        return conservative_map.get(self.param_id, self.confidence_interval[1])


class CulturalParameterField:
    """连续文化参数场 C: ℝ² × 𝒮 → ℝᵏ"""
    def __init__(self, certs: dict[str, CulturalParameterCert], 
                 interpolator: 'CulturalInterpolator'):
        self.certs = certs
        self.interpolator = interpolator
        self.v_cult = max(c.version for c in certs.values()) if certs else 0
    
    def get_param(self, x: np.ndarray, scene_type: str, param_id: str, 
                  context: dict) -> tuple[float, bool]:
        """获取位置 x、场景 scene_type 下的参数值，返回 (value, has_valid_cert)"""
        cert = self.certs.get(param_id)
        if cert is None or not cert.is_valid(context):
            return cert.conservative_value() if cert else 1.0, False
        # 插值：空间 + 场景类型
        val = self.interpolator.interpolate(x, scene_type, param_id, cert.value)
        return val, True
    
    def cultural_alignment_loss(self, trajectory: np.ndarray, scene_type: str, 
                                context: dict) -> float:
        """L_cult(π) = ∫_π ‖∇C(π(s))‖ ds"""
        loss = 0.0
        for i in range(len(trajectory) - 1):
            x1, x2 = trajectory[i], trajectory[i+1]
            # 有限差分近似梯度范数
            grad_norm = 0.0
            for param_id in self.certs.keys():
                v1, _ = self.get_param(x1, scene_type, param_id, context)
                v2, _ = self.get_param(x2, scene_type, param_id, context)
                grad_norm += (v2 - v1) ** 2
            loss += np.sqrt(grad_norm) * np.linalg.norm(x2 - x1)
        return loss


class CulturalInterpolator:
    """文化参数插值器：保证插值路径持有插值证书，Exec 单调不增"""
    def __init__(self, anchor_points: dict[tuple[str, str], np.ndarray]):
        # anchor_points: (scene_type, param_id) → 空间锚点值网格
        self.anchors = anchor_points
    
    def interpolate(self, x: np.ndarray, scene_type: str, param_id: str, 
                    base_value: float) -> float:
        """双线性空间插值 + 场景类型软插值，返回插值后的值"""
        key = (scene_type, param_id)
        if key not in self.anchors:
            return base_value  # 无锚点，回退基值
        grid = self.anchors[key]
        # 简化：最近邻 + 高斯平滑
        return self._bilinear_interp(grid, x) * 0.8 + base_value * 0.2
    
    def _bilinear_interp(self, grid: np.ndarray, x: np.ndarray) -> float:
        # 实现略
        return float(grid.mean())
    
    def interpolation_cert(self, x1: np.ndarray, x2: np.ndarray, 
                          scene_type: str, param_id: str) -> 'InterpolationCert':
        """生成插值证书：证明插值路径上参数单调变化，不扩大可行域"""
        return InterpolationCert(
            param_id=param_id,
            path=(x1, x2),
            monotonic=True,  # 由插值器设计保证
            version=self.v_cult
        )

# IP-441 Social Contract Certificate (SCC) — 社会契约证书
# ============================================================
from dataclasses import dataclass
from typing import List, Dict, Callable
import cvxpy as cp  # 假设用凸优化求近似 NE

@dataclass
class ContractGame:
    """契约博弈 G = (N, {Π_i}, {U_i}, {Ext_{ij}})"""
    N: int                                    # 智能体数
    strategy_sets: List['StrategySet']        # 每个智能体的可行策略集
    utilities: List[Callable]                 # U_i(π_i, π_{-i})
    externalities: List[List[Callable]]       # Ext_{ij}(π_i, π_j)
    lambda_dual: float                        # 外部性内化权重（对偶变量）
    W_min: float                              # 社会福利下界

@dataclass
class NEProof:
    """纳什均衡证明"""
    equilibrium: List[np.ndarray]     # π* = (π_1*, ..., π_N*)
    dual_vars: np.ndarray             # λ_dual
    epsilon_NE: float                 # 近似精度
    verification_hash: bytes          # 证明哈希，供 O(1) 验证
    
    def verify(self, game: ContractGame, tolerance: float = 1e-3) -> bool:
        """O(1) 验证：检查无有利单方偏离"""
        for i in range(game.N):
            pi_i_star = self.equilibrium[i]
            pi_neg_i = [self.equilibrium[j] for j in range(game.N) if j != i]
            U_star = game.utilities[i](pi_i_star, pi_neg_i)
            Ext_star = sum(game.externalities[i][j](pi_i_star, self.equilibrium[j]) 
                          for j in range(game.N) if j != i)
            # 检查策略集内任意扰动（采样验证）
            for _ in range(10):  # 10 次随机采样
                pi_i_prime = game.strategy_sets[i].sample()
                U_prime = game.utilities[i](pi_i_prime, pi_neg_i)
                Ext_prime = sum(game.externalities[i][j](pi_i_prime, self.equilibrium[j]) 
                               for j in range(game.N) if j != i)
                if U_prime - self.dual_vars[i] * Ext_prime > U_star - self.dual_vars[i] * Ext_star + self.epsilon_NE + tolerance:
                    return False
        # 检查社会福利下界
        W = sum(game.utilities[i](self.equilibrium[i], 
                [self.equilibrium[j] for j in range(game.N) if j != i]) 
                for i in range(game.N))
        W -= game.lambda_dual * sum(game.externalities[i][j](self.equilibrium[i], self.equilibrium[j])
                for i in range(game.N) for j in range(game.N) if i != j)
        return W >= game.W_min - tolerance


class SocialContractSolver:
    """社会契约求解器：计算近似 NE 并生成证明"""
    def __init__(self, max_iter: int = 50, epsilon: float = 1e-2):
        self.max_iter = max_iter
        self.epsilon = epsilon
    
    def solve(self, game: ContractGame) -> tuple[List[np.ndarray], NEProof]:
        """最佳响应动力学 + 对偶上升求近似 NE"""
        # 初始化：每个智能体用单体 PGEV 规划
        pi = [self._single_agent_plan(game, i) for i in range(game.N)]
        lambda_dual = np.ones(game.N) * game.lambda_dual
        
        for iteration in range(self.max_iter):
            pi_new = []
            max_deviation = 0.0
            for i in range(game.N):
                # 固定其他智能体，求 i 的最佳响应
                pi_neg_i = [pi[j] for j in range(game.N) if j != i]
                best_pi_i = self._best_response(game, i, pi_neg_i, lambda_dual[i])
                deviation = np.linalg.norm(best_pi_i - pi[i])
                max_deviation = max(max_deviation, deviation)
                pi_new.append(best_pi_i)
            pi = pi_new
            
            # 对偶上升：调整 λ 内化外部性
            for i in range(game.N):
                ext_i = sum(game.externalities[i][j](pi[i], pi[j]) for j in range(game.N) if j != i)
                lambda_dual[i] = max(0, lambda_dual[i] + 0.01 * (ext_i - 0.1))  # 目标外部性 < 0.1
            
            if max_deviation < self.epsilon:
                break
        
        # 生成 NE 证明
        proof = NEProof(
            equilibrium=pi,
            dual_vars=lambda_dual,
            epsilon_NE=self.epsilon,
            verification_hash=self._hash_proof(pi, lambda_dual)
        )
        return pi, proof
    
    def _single_agent_plan(self, game: ContractGame, i: int) -> np.ndarray:
        # 调用 v23 的 PGEV 单体规划器
        return np.zeros((10, 3))  # 占位
    
    def _best_response(self, game: ContractGame, i: int, 
                       pi_neg_i: List[np.ndarray], lambda_i: float) -> np.ndarray:
        # 解决 max_{π_i ∈ Π_i} U_i - λ_i Σ_j Ext_{ij}
        # 用投影梯度上升
        return np.zeros((10, 3))  # 占位
    
    def _hash_proof(self, pi: List[np.ndarray], lambda_dual: np.ndarray) -> bytes:
        import hashlib
        data = b"".join(p.tobytes() for p in pi) + lambda_dual.tobytes()
        return hashlib.sha256(data).digest()


class ContractViolationDetector:
    """契约违约检测器：实时监测 Ext_{ij} 超阈值，触发 DCL 义务层"""
    def __init__(self, threshold: float = 0.5, window: float = 2.0):
        self.threshold = threshold
        self.window = window
        self.history: Dict[int, List[tuple[float, float]]] = {}  # agent_id → [(t, ext)]
    
    def update(self, agent_id: int, ext_value: float, timestamp: float):
        if agent_id not in self.history:
            self.history[agent_id] = []
        self.history[agent_id].append((timestamp, ext_value))
        # 清理旧记录
        cutoff = timestamp - self.window
        self.history[agent_id] = [(t, v) for t, v in self.history[agent_id] if t > cutoff]
    
    def check_violation(self, agent_id: int) -> bool:
        if agent_id not in self.history:
            return False
        recent_ext = [v for _, v in self.history[agent_id]]
        return np.mean(recent_ext) > self.threshold if recent_ext else False

from dataclasses import dataclass

@dataclass
class SocialImpactCert:
    """社会影响证书 SIC(π) = (I_phy, I_psy, I_str, AuditTrail)"""
    I_phy: float
    I_psy: float
    I_str: float
    audit_trail: List[Dict]  # 每笔额度变动：{rule_id, evidence_hash, timestamp, sig}
    budget_before: float
    budget_after: float
    
    def is_within_threshold(self, thresholds: tuple[float, float, float]) -> bool:
        Θ_phy, Θ_psy, Θ_str = thresholds
        return (self.I_phy <= Θ_phy and 
                self.I_psy <= Θ_psy and 
                self.I_str <= Θ_str)


class SocialImpactMeter:
    """社会影响计量器：在线计算三分量"""
    def __init__(self, human_density_map: 'DensityMap', 
                 cultural_prior: 'CulturalPriorModel',
                 str_lookup: Dict[str, float]):  # 长期影响查表
        self.rho = human_density_map
        self.cultural_prior = cultural_prior
        self.I_str_table = str_lookup
    
    def measure(self, trajectory: np.ndarray, scene_type: str, 
                context: dict) -> tuple[float, float, float]:
        """返回 (I_phy, I_psy, I_str)"""
        # I_phy: 人密度加权距离惩罚
        I_phy = 0.0
        for i in range(len(trajectory) - 1):
            x = trajectory[i]
            rho = self.rho.query(x)
            # 距离最近人类的距离
            d_min = self.rho.nearest_human_dist(x)
            phi = self._dist_penalty(d_min)
            I_phy += rho * phi * np.linalg.norm(trajectory[i+1] - x)
        
        # I_psy: 相对文化先验的 KL 散度（不可预测性）
        # 近似：轨迹分布 vs 文化先验分布的 KL
        I_psy = self._kl_divergence(trajectory, scene_type, context)
        
        # I_str: 查表（由离线仿真/A/B 给出上界）
        key = f"{scene_type}:{context.get('event_type', 'normal')}"
        I_str = self.I_str_table.get(key, 0.0)
        
        return I_phy, I_psy, I_str
    
    def _dist_penalty(self, d: float) -> float:
        """距离惩罚函数：d < 1m 时急剧上升"""
        if d < 0.5: return 10.0
        if d < 1.0: return 5.0 * (1.0 - d) + 1.0
        if d < 2.0: return 2.0 - d
        return 0.0
    
    def _kl_divergence(self, trajectory: np.ndarray, scene_type: str, context: dict) -> float:
        # 简化：用轨迹速度/曲率分布 vs 文化先验的 KL
        prior = self.cultural_prior.get_distribution(scene_type, context)
        emp = self._empirical_dist(trajectory)
        # 离散 KL 近似
        kl = 0.0
        for k in prior:
            if prior[k] > 0 and emp.get(k, 0) > 0:
                kl += emp[k] * np.log(emp[k] / prior[k])
        return kl
    
    def _empirical_dist(self, trajectory: np.ndarray) -> Dict[str, float]:
        # 速度/曲率直方图
        return {"straight": 0.7, "turn": 0.3}  # 占位


class SocialBudgetManager:
    """社会影响额度管理器：分配、交易、审计"""
    def __init__(self, initial_budget: float, thresholds: tuple[float, float, float]):
        self.B_social = initial_budget
        self.thresholds = thresholds
        self.audit_chain: List[Dict] = []
        self.pending_trades: Dict[str, 'BudgetTrade'] = {}
    
    def spend(self, sic: SocialImpactCert) -> bool:
        """执行路径扣减额度"""
        if not sic.is_within_threshold(self.thresholds):
            return False
        total_impact = sic.I_phy + sic.I_psy + sic.I_str
        if self.B_social < total_impact:
            return False
        self.B_social -= total_impact
        self._record_audit("spend", total_impact, sic.audit_trail)
        return True
    
    def trade(self, trade: 'BudgetTrade') -> bool:
        """额度交易：让行者获得补偿，强行者支付"""
        if trade.payer_budget < trade.amount:
            return False
        trade.payer_budget -= trade.amount
        trade.receiver_budget += trade.amount
        self._record_audit("trade", trade.amount, trade.audit_trail)
        self.pending_trades[trade.id] = trade
        return True
    
    def recover(self, amount: float, evidence: Dict):
        """额度恢复：如完成任务、获得人类正面反馈"""
        self.B_social += amount
        self._record_audit("recover", amount, [evidence])
    
    def _record_audit(self, action: str, amount: float, evidence_list: List[Dict]):
        entry = {
            "action": action,
            "amount": amount,
            "timestamp": time.time(),
            "evidence": [hashlib.sha256(str(e).encode()).hexdigest() for e in evidence_list],
            "budget_after": self.B_social
        }
        self.audit_chain.append(entry)

class BudgetTrade:
    id: str
    payer_id: int
    receiver_id: int
    amount: float
    payer_budget: float  # 引用，实际由 BudgetManager 管理
    receiver_budget: float
    audit_trail: List[Dict]

class CulturalConformalCalibrator:
    """文化条件 Conformal 校准器：P(err ≤ ε | score, culture=c) ≥ 1-α"""
    def __init__(self, base_calibrator: 'ConformalCalibrator', 
                 culture_classifier: 'CultureClassifier',
                 alpha: float = 0.01):
        self.base = base_calibrator
        self.culture_clf = culture_classifier
        self.alpha = alpha
        # 按文化参数分桶的校准集
        self.D_calib_by_culture: Dict[str, List[tuple[float, float]]] = defaultdict(list)
    
    def calibrate(self, score: float, culture_params: Dict[str, float]) -> float:
        """返回给定 (score, culture) 下的 ε̂_loc"""
        culture_key = self._culture_key(culture_params)
        D_c = self.D_calib_by_culture.get(culture_key, [])
        if len(D_c) < 30:
            # 回退基础校准器（无文化条件）
            return self.base.quantile(score, self.alpha)
        # 文化条件分位数
        return self._conditional_quantile(D_c, score, self.alpha)
    
    def update_calibration(self, score: float, error: float, culture_params: Dict[str, float]):
        """在线更新文化条件校准集"""
        culture_key = self._culture_key(culture_params)
        self.D_calib_by_culture[culture_key].append((score, error))
        if len(self.D_calib_by_culture[culture_key]) > 2000:
            self.D_calib_by_culture[culture_key].pop(0)
    
    def _culture_key(self, culture_params: Dict[str, float]) -> str:
        """文化参数离散化为键（聚类中心）"""
        # 简化：量化为最近的文化原型
        return "cult_" + "_".join(f"{k}:{v:.1f}" for k, v in sorted(culture_params.items()))
    
    def _conditional_quantile(self, D_c: List, score: float, alpha: float) -> float:
        # 加权分位数：按 score 相似度加权
        scores = np.array([s for s, _ in D_c])
        errors = np.array([e for _, e in D_c])
        weights = np.exp(-(scores - score) ** 2 / 0.1)
        weights /= weights.sum()
        # 加权经验分位数
        sorted_idx = np.argsort(errors)
        cumsum = np.cumsum(weights[sorted_idx])
        return errors[sorted_idx[np.searchsorted(cumsum, 1 - alpha)]]
    
    def coverage_guarantee(self, culture_params: Dict[str, float]) -> float:
        """返回当前文化下的经验覆盖率下界（Hoeffding）"""
        culture_key = self._culture_key(culture_params)
        D_c = self.D_calib_by_culture.get(culture_key, [])
        n = len(D_c)
        if n < 30:
            return 0.0
        emp_cov = sum(1 for s, e in D_c if e <= self.calibrate(s, culture_params)) / n
        delta = 0.001
        hoeffding = np.sqrt(np.log(1/delta) / (2*n))
        return max(0, emp_cov - hoeffding)
    
    def culture_misidentification_risk(self, true_culture: Dict, pred_culture: Dict) -> float:
        """文化识别错误导致的覆盖跌破风险上界"""
        # 使用全覆盖下界：min_c P(err ≤ ε | score, c)
        all_cov = [self.coverage_guarantee(c) for c in self.D_calib_by_culture.keys()]
        return 1 - min(all_cov) if all_cov else 1.0

@dataclass
class HPCEPlusPlus:
    hpc_e_plus: 'HPCEPlus'      # v23 的四证准入门
    cpc_field: CulturalParameterField
    scc_solver: SocialContractSolver
    sic_meter: SocialImpactMeter
    budget_mgr: SocialBudgetManager
    c4_calibrator: CulturalConformalCalibrator
    
    def admits(self, plan, x, v, z, E_res, margin_req, 
               modules: list[str], context: dict) -> bool:
        # 1. HPC-E+ 基础验证（物理-规范-能量-版权）
        if not self.hpc_e_plus.admits(plan, x, v, z, E_res, margin_req, modules):
            return False
        
        # 2. CPC 验证：路径文化对齐损失在阈值内
        scene_type = context.get("scene_type", "default")
        L_cult = self.cpc_field.cultural_alignment_loss(plan.trajectory, scene_type, context)
        if L_cult > context.get("lambda_cult_threshold", 0.5):
            return False
        
        # 3. SCC 验证：契约均衡证明有效
        game = self._build_contract_game(plan, context)
        pi_star, proof = self.scc_solver.solve(game)
        if not proof.verify(game):
            return False
        # 检查计划是否即均衡策略（或在 ε 邻域内）
        if np.linalg.norm(plan.trajectory - pi_star[0]) > 0.1:  # 自己是 agent 0
            return False
        
        # 4. SIC 验证：社会影响在额度内
        I_phy, I_psy, I_str = self.sic_meter.measure(plan.trajectory, scene_type, context)
        sic = SocialImpactCert(I_phy, I_psy, I_str, [], 
                               self.budget_mgr.B_social, 
                               self.budget_mgr.B_social - (I_phy + I_psy + I_str))
        if not sic.is_within_threshold(self.budget_mgr.thresholds):
            return False
        if not self.budget_mgr.spend(sic):
            return False
        
        # 5. C4 验证：文化条件统计覆盖达标
        culture_params = {pid: self.cpc_field.get_param(x, scene_type, pid, context)[0] 
                         for pid in self.cpc_field.certs.keys()}
        cov_lb = self.c4_calibrator.coverage_guarantee(culture_params)
        if cov_lb < 1 - self.c4_calibrator.alpha - 0.02:  # 留 2% 安全边际
            return False
        
        return True
    
    def _build_contract_game(self, plan, context) -> ContractGame:
        # 构建包含自己 + 感知到的其他智能体的博弈
        return ContractGame(
            N=1 + len(context.get("other_agents", [])),
            strategy_sets=[],  # 占位
            utilities=[],
            externalities=[],
            lambda_dual=1.0,
            W_min=0.0
        )

| 额度交易/审计 | O(1) 增量 | O(|audit_chain|) | 链长度≤10⁶ |

**实时性保证**：SCC 求解器在独立线程（10Hz）运行，主控制环仅做 O(1) NE 证明验证；CPC/SIC/C4 查询均为 O(1) 或 O(|π|) 级；CFC-Social 共识异步进行，不阻塞 50Hz 控制环。

## 3. 正确性论证

### 引理 1（文化参数证书的单调保守性）
**陈述**：若 `CPC(c)` 无效或上下文不适用，规划器使用 `c.conservative_value()`，导致可行域收缩：`Exec_v24 ⊆ Exec_v23`。

**证明**：
1. `conservative_value()` 定义为：社交距离取置信上界（最大）、让行权重取上界（最强）、禁忌拓扑全开（全域禁忌）、眼神期望全开、通行偏好中性。
2. 这些值在目标函数 `J = J_E + λ_cult L_cult` 中均使 `L_cult` 非减（偏离文化流场更大或等同），从而使最优解集非增。
3. CPC 证书有效性检查 `is_valid(context)` 为单调谓词：上下文变化只能使谓词从 True 变 False，不能反向。
4. 因此文化参数失效单方向收缩可行域，`Exec_v24 ⊆ Exec_v23`。
∎

### 引理 2（社会契约均衡的活性保证）
**陈述**：若 `SCC(π)` 验证通过，则 `π` 是契约博弈 G 的 ε-纳什均衡，且社会福利 `W(π) ≥ W_min`。任何单方偏离要么降低偏离者效用，要么违反契约触发 DCL 义务。

**证明**：
1. `NEProof.verify` 逐智能体采样检查：`∀i, ∀π_i' ∈ Π_i: U_i(π_i', π*_{-i}) - λ_i Ext_i(π_i', π*_{-i}) ≤ U_i(π*) - λ_i Ext_i(π*) + ε_NE`。
2. 此不等式正是 ε-纳什均衡在内化外部性后的定义。对偶变量 `λ_i` 由对偶上升算法保证互补松弛性近似成立。
3. 社会福利检查 `W(π*) ≥ W_min` 直接由验证器第 2 步保证。
4. 违约检测器监测实时外部性 `Ext_i(t)`，均值超阈值 → 触发 DCL 义务层"让位期限重算"（O 规则），强制偏离者回归均衡策略或进入保守模式。
5. 故均衡策略具有"无后悔"性质：单方改道无净收益，系统级活性由契约维持。
∎

### 引理 3（社会影响预算的审计完备性）
**陈述**：`cultural_audit_chain` 记录的每笔额度变动满足：(a) 可追溯到规则编号，(b) 证据哈希防篡改，(c) 时间戳单调，(d) 签名不可抵赖。额度耗尽仅允许零影响路径。

**证明**：
1. `SocialBudgetManager._record_audit` 强制记录 `rule_id`（对应 DCL 规则编号）、`evidence_hash`（证据链 Merkle 叶）、`timestamp`（单调递增）、`sig`（边端私钥签名）。
2. 额度扣减 `spend` 先检查 `sic.is_within_threshold`（三分量独立阈值），再检查 `B_social ≥ total_impact`。两者均失败即拒证。
3. 交易 `trade` 要求付款方额度充足，双方额度原子增减，审计链记录完整转账凭证。
4. 额度耗尽 `B_social = 0` 时，`spend` 仅当 `total_impact = 0` 通过，即 `I_phy=I_psy=I_str=0`，等价静态人距上限模式。
5. 审计链采用 Merkle 树结构，根哈希定期上链/上传云端，满足可审计性。
∎

### 引理 4（文化条件统计覆盖的失效安全分解）
**陈述**：`P(err ≤ ε | score, culture=c) ≥ 1-α - δ_cult`，其中 `δ_cult = P(culture_misidentified) + δ_hoeffding`。文化识别错误风险显式上界。

**证明**：
1. 设真实文化为 `c*`，预测文化为 `ĉ`。由全概率公式：
   `P(err ≤ ε | score) = P(ĉ=c*) P(err ≤ ε | score, c*) + P(ĉ≠c*) P(err ≤ ε | score, ĉ≠c*)`
2. C4 校准器维护每个文化桶的条件覆盖下界 `cov_lb(c)`。若 `ĉ=c*`，覆盖 ≥ `cov_lb(c*) - δ_hoeffding`。
3. 若 `ĉ≠c*`，最坏情况覆盖 = `min_c cov_lb(c) - δ_hoeffding`。
4. `CulturalConformalCalibrator.culture_misidentification_risk` 返回 `1 - min_c cov_lb(c)`，即误识别时的覆盖跌破上界。
5. HPCE++ 准入门要求 `cov_lb(ĉ) ≥ 1-α-0.02`，并隐式要求 `min_c cov_lb(c) ≥ 1-α-0.05`（留更大边际），否则拒证回退 v23。
6. 故文化条件覆盖承诺显式分解并界定了误识别风险，失效安全方向明确。
∎

### 定理（HPC-E++ 五证准入门的安全-合规-文化-社会-可部署-可保护完备性）
**陈述**：对任意计划 π，`HPCEPlusPlus.admits(π) = True` ⟺ π 同时满足：
(1) 物理接地安全（几何∧规范∧负信息∧能量∧差距），

(3) 少样本适应后的 conformal 覆盖 ≥1-α，

(5) 文化参数证书有效且文化对齐损失在阈值内，
(6) 社会契约为可验证的 ε-纳什均衡且社会福利达标，
(7) 社会影响三分量在独立阈值内且额度充足，

**证明**：直接由 `HPCEPlusPlus.admits` 的 8 个连言条件与引理 1-4 可得。必要性：任一条件缺失即拒证，对应八类风险中的一种未被缓解。充分性：八条件全满足，由引理 1-4 保证执行集单调链 `Exec_v24 ⊆ Exec_v23 ⊆ ... ⊆ Exec_v18`、文化参数保守性、契约活性、额度审计完备、统计覆盖分解，构成完整闭环。
