### 第 4 轮灵感驱动研究记录

**灵感词**：灵巧操作、创新点提炼

**直觉与动机**：

先给直觉。v29 把安全外包给「学生先行-证书裁决-教师兜底」，其所有证书都默认动力学在动作空间上「足够光滑」——Lipschitz 常数 L、价值下界 V_min、覆盖密度比 ρ_max 都是全局量。但灵巧操作的本质恰恰是**接触切换**：手指接触/脱离、粘着/滑移，使动力学成为分段光滑、在切换面处不连续的分段系统。于是 v29 的引理 26（γ_m = L·ε）在切换面附近直接失效：跨切换面的两个动作可以任意接近却对应不同的接触模式，V 的差不为 L·ε 所界定，**全局 L 事实上是无穷大**。这不是调参问题，而是建模层面的范畴错误。

第二个直觉来自「创新点提炼」。v28→v29 证书从九张膨胀到十二张，v30 若再加接触证书会到十四张，证书套件本身开始出现**创新冗余**——很多证书只覆盖同一批失效原子，真正承重的可能只有少数几张。研究工作的「创新点提炼」不应只是写作层面的摘要，而应是一个可计算的算子：在验证语料上做反事实消融，度量每张证书的**边际拦截贡献（创新显著度 s_i）**，求出最小承重证书基 B*，并给出「裁剪后不安全率不显著上升」的统计证书。这样既压缩在线开销，也让「到底哪一条创新在起作用」变成可证伪的问题。

**关键洞见**：两者合流。灵巧操作提供「接触模式 σ」这一新的证书条件变量，把 v29 的全局证书改为**分片（piecewise）证书**，并在切换处引入独立的**切换守卫证书 CTC**，用「切换预算 m·Δ_trans」把分片证书沿轨迹复合起来；创新点提炼提供「证书基 B*」这一新的**元证书 CBC**，回答这套分片证书里哪些不可替代。二者共同把 v29 的「十二证」升级为 v30 的「十四证 + 一个最小基」，且 Exec_v30 ⊆ Exec_v29 仍成立。

**形式化目标（增量）**：
1. 定义接触模式 σ = (C, s)，C 为接触点集、s ∈ {stick, slip}；轨迹分段产生切换时刻 𝒯 = {t_1,…,t_m}。
2. 定义模式条件价值 V_ψ(x,u,σ) 与分片 Lipschitz L_σ、分片下界 V_min^σ；用一维构造证明「全局 L = ∞」（引理 30）。
3. 定义切换守卫证书 CTC：摩擦锥、冲量上界、穿透深度、后继模式可达四条件。
4. 定义切换预算复合引理（引理 29）：m 次切换后价值裕度至少为 min_σ V_min^σ − max_σ L_σ ε_σ − m·Δ_trans。
5. 定义创新显著度 s_i 与最小证书基 B*（引理 31）：最大覆盖 + Hoeffding 尾部界 + 贪心 (1−1/e)。
6. 证明 Exec_v30 = (v29 十二证按模式重放 ∧ 模式 VAC ∧ CTC ∧ CBC) 的子集，且 CBD 在验证分布上以 1−δ 保证裁剪前后未拦截不安全质量差 ≤ δ_abl。

**本轮最大风险**：**接触模式错分（mode aliasing）**——若滑移被误判为粘着、或接触点集漏检，则 CCVM 与 CTC 都会在「错误但自洽」的模式下给出绿灯，而 CBD 又恰好在不含此类错分的验证语料上把冗余证书裁掉，导致十四证一致放行一个实际已失稳的抓取；这比 v29 的多组件共因失效更根本，因为错误发生在所有证书共同的输入——模式标签——上。

## 2. 关键算法骨架（在 IP-467~472 骨架上扩展）

### IP-476 Tactile Contact Abstraction (TCA)

```python
@dataclass
class TactileContactAbstraction:
    """TCA：把高维触觉阵列压成接触原语，供 CMS/CTC/OOD 共用"""
    n_taxels: int
    f_thresh: float = 0.5          # 接触判定法向力阈值 (N)
    cluster_radius: float = 0.02   # 接触点聚类半径 (m)

    def abstract(self, w_tactile: np.ndarray) -> ContactPrimitives:
        active = np.where(w_tactile > self.f_thresh)[0]
        clusters = self._cluster(active, w_tactile, self.cluster_radius)
        f_n = np.array([w_tactile[c].sum() for c in clusters])
        f_t = np.array([self._shear_norm(c) for c in clusters])
        slip = np.array([self._slip_ratio(c) for c in clusters])
        return ContactPrimitives(points=[self._centroid(c) for c in clusters],
                                 f_n=f_n, f_t=f_t, slip_ratio=slip)
```

### IP-473 Contact-Mode Segmenter (CMS)

```python
@dataclass
class ContactModeSegmenter:
    """CMS：轨迹 → 接触模式序列 + 切换时刻；单帧噪声用去抖抑制"""
    tca: TactileContactAbstraction
    slip_thresh: float = 0.3
    debounce: int = 3

    def segment(self, traj) -> tuple[list[ContactMode], list[int]]:
        raw = []
        for (q, qdot, w_tac) in traj:
            prim = self.tca.abstract(w_tac)
            C = frozenset(self._contact_ids(prim))
            s = "slip" if prim.slip_ratio.max(initial=0.0) > self.slip_thresh else "stick"
            raw.append(ContactMode(C=C, s=s))
        modes = self._debounce(raw, self.debounce)   # 抑制单帧伪切换
        trans = [t for t in range(1, len(modes)) if modes[t] != modes[t - 1]]
        return modes, trans
```

### IP-474 Contact-Conditioned Value Model (CCVM)

```python
@dataclass
class ContactConditionedValueModel:
    """CCVM：按接触模式分片的价值模型；未见模式一律拒证，不猜"""
    ensembles: dict               # σ -> list[value_net]，K_v 个成员
    beta_bt: float = 4.0
    z_conf: float = 1.96
    v_min: dict = field(default_factory=dict)
    L: dict = field(default_factory=dict)

    def lcb(self, x, u, sigma) -> float:
        nets = self.ensembles.get(sigma)
        if nets is None:          # 未见模式：返回 -inf，使 VAC 必然失败
            return -np.inf
        with torch.no_grad():
            vals = torch.stack([n(x, u) for n in nets])
        return float(vals.mean() - self.z_conf * vals.std(unbiased=False))

    def calibrate_mode(self, sigma, teacher_samples, calib_states, eps=1e-2):
        """逐模式校准 V_min^σ 与 L_σ（保守值 L̂+2·SE）"""
        vals = sorted(teacher_samples)
        self.v_min[sigma] = vals[max(0, int(0.1 * len(vals)))]
        ratios = []
        for (x, u1, u2) in calib_states:
            d = abs(self.lcb(x, u1, sigma) - self.lcb(x, u2, sigma))
            n = max(np.linalg.norm(u1 - u2), eps)
            ratios.append(d / n)
        self.L[sigma] = float(np.mean(ratios) + 2.0 * np.std(ratios) / np.sqrt(len(ratios)))
```

### IP-475 Contact-Transition Guard Certificate (CTGC)

```python
@dataclass
class ContactTransitionGuardCertificate:
    """CTGC：切换守卫——接触切换本身也要被证明安全"""
    tca: TactileContactAbstraction
    mu_f: float = 0.8
    J_max: float = 5.0             # N·s
    pen_max: float = 0.002         # m

    def certify(self, x_t, sigma_old, sigma_new, u,
                successor_certified: bool) -> bool:
        prim = self.tca.abstract(x_t.w_tactile)
        if prim.f_n.size == 0:
            return False
        # 1) 摩擦锥：切向不得超过 μ_f·法向
        if np.any(prim.f_t > self.mu_f * prim.f_n + 1e-9):
            return False
        # 2) 冲量上界：防止切换瞬间的冲击失稳
        if self._impulse(prim, u) > self.J_max:
            return False
        # 3) 穿透深度：几何可行性
        if self._penetration(x_t, u) > self.pen_max:
            return False
        # 4) 后继模式必须已有已认证控制器（避免「切换进无人区」）
        return successor_certified
```

### IP-477 Certificate Basis Distiller (CBD)

```python
@dataclass
class CertificateBasisDistiller:
    """CBD：反事实消融提炼最小承重证书基（创新点提炼的可计算版本）"""
    cert_names: list
    delta_abl: float = 0.01
    conf_delta: float = 0.05

    def distill(self, D_val) -> tuple[list[int], float, bool]:
        # D_val: [(traj, unsafe_atoms, cert_pass_mask)]
        #   unsafe_atoms 为仿真/人工标注的真实不安全原子
        #   cert_pass_mask[i] = 证书 i 是否拦截该原子
        A = self._coverage_matrix(D_val)          # shape (k, N_atoms)
        basis = self._greedy_max_coverage(A)      # (1-1/e) 近似
        tail = self._uncovered_mass_upper(D_val, basis)
        self.cbc_pass = tail <= self.delta_abl
        return basis, tail, self.cbc_pass

    def innovation_salience(self, A) -> np.ndarray:
        """s_i：移除证书 i 后新增的未拦截不安全原子数（归一到 [0,1]）"""
        full = A.any(axis=0).sum()
        s = np.array([full - np.delete(A, i, axis=0).any(axis=0).sum()
                      for i in range(A.shape[0])], dtype=float)
        return s / max(full, 1)

    def _uncovered_mass_upper(self, D_val, basis):
        uncovered = [j for j in range(len(D_val)) if not self._covered(D_val[j], basis)]
        r_hat = len(uncovered) / max(len(D_val), 1)
        return r_hat + math.sqrt(math.log(1.0 / self.conf_delta) / (2 * len(D_val)))
```

### IP-478 Contact-Certified Distillation Gate (CDM-KTCG)

```python
@dataclass
class ContactCertifiedDistillationGate:
    """CDM-KTCG：v29 十二证按模式重放 + 模式 VAC + CTC + CBC = 十四证"""
    v29: 'ValueAlignedDistillationCertGate'
    cms: ContactModeSegmenter
    ccvm: ContactConditionedValueModel
    ctgc: ContactTransitionGuardCertificate
    cbd: CertificateBasisDistiller

    def admits(self, robot_plan, sensor_data):
        # 0) CBC：证书基已蒸馏且尾部界达标，否则不启用学生路径
        if not self.cbd.cbc_pass:
            return self._teacher_path(robot_plan, sensor_data)

        modes, trans = self.cms.segment(robot_plan.predicted_states)
        s0, sigma0 = robot_plan.init_state, modes[0]
        u_stu, u_ens, ood = self.v29.vadp.propose(s0)

        # 1) 模式条件 VAC：只在当前模式下评估价值下界
        if self.ccvm.lcb(s0, u_stu, sigma0) < self.ccvm.v_min.get(sigma0, np.inf):
            return self._teacher_path(robot_plan, sensor_data)

        # 2) CTC：每个切换点都要过摩擦锥/冲量/穿透/后继可达
        for t in trans:
            succ = modes[t]
            if not self.ctgc.certify(
                    robot_plan.predicted_states[t], modes[t - 1], succ, u_stu,
                    successor_certified=(succ in self.ccvm.ensembles)):
                return self._teacher_path(robot_plan, sensor_data)

        # 3) v29 十二证按模式分段重放（证书语义不变，仅轨迹按 σ 切段）
        for seg in self._split_by_mode(modes):
            if not self.v29.admits_rollout(robot_plan, sensor_data, seg, u_stu):
                return self._teacher_path(robot_plan, sensor_data)

        # 4) 学生自评：继承 v29 的否决器语义（非安全证明）
        if u_ens > self.v29.vadp.u_ens_max or ood > self.v29.vadp.ood_max:
            return self._teacher_path(robot_plan, sensor_data)

        return True, u_stu, "student"

    def _teacher_path(self, robot_plan, sensor_data):
        """教师路径 = v29 语义 + 接触调度（按模式序列求解接触序列 MPC）"""
        return self.v29.teacher_with_contact_schedule(
            robot_plan, sensor_data, self.cms)
```

**与 v29 的接口约定**：v29 的 `ValueAlignedDistillationCertGate` 原样复用，仅新增 `teacher_with_contact_schedule(plan, sensor, cms)` 一个只读增量接口；`admits_rollout` 的语义不变，只是被按模式分段调用。TCA/CMS/CTC/CBC 全部为 v30 新增。

## 4. 正确性论证（增量更新）

### 引理 30（全局 Lipschitz 失效 / 模式条件化的必要性）

**陈述**：不存在有限全局 L 使 v29 的 `γ_m = L·ε` 在接触切换面附近成立。

**构造**：取一维动作 u∈ℝ，接触在 u>0 时激活，其余因素固定，令 V(x,u,σ)=1[u>0]。取 u₁=−δ、u₂=+δ，则 |V(u₁)−V(u₂)|=1，而 |u₁−u₂|=2δ，比值 1/(2δ)→∞（δ→0）。故任何有限 L 都无法覆盖跨模式的价值差。

**推论**：v29 在接触切换面附近会**高估**证书强度（把实际不连续的价值当成 L-Lipschitz），从而放行不安全切换。必须把证书条件在 σ 上，并为切换单独发证（CTC）。

### 引理 29（切换预算复合）

**陈述**：设轨迹被切成模式段 σ₀,…,σ_{m}，段内 CCVM 给出 `V_LCB ≥ V_min^σ − L_σ·ε_σ`；每次切换由 CTC 保证价值跌落 ≤ Δ_trans。则轨迹上任一点
`V_LCB ≥ V_min^* − max_σ L_σ·ε_σ − m·Δ_trans`。
若 `m·Δ_trans ≤ γ_ct`，则整条轨迹以余量 γ_ct 通过模式条件 VAC。

**证明**：对「段内 + 切换」交替做归纳。段内用分片版引理 26（Lipschitz 只在段内成立）；跨越切换时价值最多跌落 Δ_trans，累加 m 次；最后取所有模式的最小下界与最大 Lipschitz 项。∎

**工程含义**：γ_ct 把「接触几何质量」与「模式切换次数」绑成一个可调预算。切换越频繁，对单次切换的 Δ_trans 要求越严——这正是灵巧操作（频繁接触切换）必须显式付出的安全成本。

### 引理 31（证书基蒸馏 / 最大覆盖 + 统计尾部界）

**陈述**：设验证集不安全原子集为 A，证书 i 拦截子集 A_i⊆A。选择基 B 最大化被拦截原子数是最大覆盖问题，贪心算法达到 ≥(1−1/e)·OPT。设 r̂ 为验证集上未被 B 拦截的不安全质量比例，则以概率 ≥1−δ 有真实未拦截质量 `r ≤ r̂ + √(ln(1/δ)/(2N))`。CBD 仅当该上界 ≤ δ_abl 时发 CBC。

**证明**：覆盖函数 `B ↦ |∪_{i∈B} A_i|` 单调且子模，贪心近似比为经典结论；对指示变量用 Hoeffding 不等式得尾部界。∎

**诚实声明**：CBC 只保证「在验证分布上裁剪不显著变差」，对分布外的新型失效原子无保证——这正是 R29 的根源，需用对抗性切换语料与分布漂移重认证缓解。

### 定理（CDM-KTCG 十四证准入门的执行集收缩）

**陈述**：
`Exec_v30 = (Exec_v29 ∩ {π: 模式VAC(π) ∧ CTC(π) ∧ CBC} ∩ student-path) ∪ (Exec_v29 ∩ teacher-path) ⊆ Exec_v29`，
且该包含可以是严格的。

**证明**：学生路径第 3 步逐段重放 v29 的十二证（证书轨迹语义不变，仅轨迹生成器按模式切段），再合取模式 VAC（第 1 步）、CTC（第 2 步）、CBC（第 0 步）三个新增项；教师路径复用 v29 的教师语义并加入接触调度，其输出仍属 v29 准入集。两路并集仍 ⊆ Exec_v29。严格性：存在一条在 slip 切换处切向力超摩擦锥、但 v29 的全局价值/知识证书均通过的轨迹——v29 未检查接触几何，故放行；v30 的 CTC 拒绝。∎

## 5. 创新点提炼（元层交付物）

把整条 v27→v30 研究线当作待蒸馏对象，用 CBD 的创新显著度 s_i 做一次「研究层面的证书基」提炼：

| 创新点 | 承重证书/模块 | 显著度（定性） | 可否裁剪 |
|---|---|---|---|
| 证书驱动的学生蒸馏（v29） | VAC / DGC / CCC | 高（尾部失效原子） | 否 |
| 接触模式条件化（v30） | CMS + CCVM | 高（滑移切换原子） | 否 |
| 切换守卫（v30） | CTC | 中-高（切换瞬态） | 否（语料含瞬态失效时） |
| 数据覆盖审计（v29） | DSC | 中（未覆盖尾部） | 部署分布稳定时可降频 |
| 可解释性元数据（v27/v28） | IEKC | 低（对安全拦截） | 可作为人机信任证书，而非安全证书 |
| 自适应权重（v27） | AKWA | 中（长时漂移） | 短任务可降频 |

**结论**：真正的「创新承重集」是 {证书门控蒸馏, 模式条件化, 切换守卫} 三项；其余多为支撑性或信任性模块。这一提炼本身可被 CBD 的 s_i 持续复核，避免研究叙事与实际拦截贡献脱节。

## 6. 实验设计（灵巧操作基准）

**任务**：① 五指手内立方体再定向（Allegro，接触频繁切换）；② 间隙 peg-in-hole 插入（接触点集变化）；③ 变摩擦抓取-抬升（slip/stick 切换）；④ 可形变物抓取（补充压力分布）。

**平台**：MuJoCo/Isaac 仿真 + 触觉阵列（每指 4×4 taxel），一组 sim-to-real 迁移（若可用真机手）。

**对照**：v29（全局 L）、v30 去掉 CTC、v30 去掉 CBD（完整十四证）、v30 完整。

**指标**：不安全率（穿透 > pen_max、掉落、滑移超阈）、假证书率（证书通过但实际失效）、学生路径占比、p99 单步延迟、证书基大小 |B*|。

**消融与假设**：
1. 去掉 CTC → 切换瞬态失效显著上升（预期不安全率 +≥2×）；
2. 全局 L vs 分片 L_σ → 全局 L 在切换面附近假证书率显著更高（验证引理 30）；
3. CBD vs 完整十四证 → 不安全率差 ≤ δ_abl（1%），同时 |B*| 至少减少 30%；
4. 注入 5% 模式错分语料 → 观察 CBC 自动拒绝裁剪（验证 R28 的可检测性）。

## 7. 已知风险与缓解（增量更新）

| 风险编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| R19–R27 | v28/v29 全部既有风险 | — | 随 v29 原样继承 | 不变 |
| R28 | 接触模式错分（mode aliasing）：slip 误判为 stick、接触点漏检，使 CCVM 与 CTC 在错误模式下自洽放行 | 高 | 1) 滑移用「触觉剪切 + 运动学残差」双通道独立估计；2) 迟滞 + 去抖；3) 定义模式不确定度，超过阈值即升级教师；4) 把错分样本注入验证语料供 CBD 复核 | 双通道共享同一触觉硬件故障时会共因失效 |
| R29 | 证书基过拟合：CBD 在验证分布上裁掉「只在分布外才承重」的证书 | 高 | 1) Hoeffding 尾部界 + 对抗性切换留出集；2) 限制单次裁剪比例上限；3) 分布漂移触发 CBC 重认证 | 新型失效原子不在任何留出集中，无法被统计界覆盖 |
| R30 | 触觉 sim-to-real gap：TCA 阈值漂移使接触原语与模式判定偏移 | 中 | 1) 触觉域随机化；2) 真机重标定 f_thresh/slip_thresh 并给出置信区间；3) gap 过大时 CTC 失败关闭（升级教师） | 重标定滞后窗口内模式判定可能失准 |

## 8. 本轮最大风险（最终确认）

**一句话**：**接触模式错分**——所有十四张证书都以模式标签 σ 为共同输入，一旦滑移/接触被误判，CCVM、CTC 与 CBD 会在「错误但自洽」的世界里一致放行一个实际已失稳的抓取，而这类错误发生在证书链的最上游，下游任何统计证书都无法察觉。
