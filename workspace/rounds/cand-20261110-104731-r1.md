# 第 43 轮（新循环第 3 轮） · 配准即安全：把点云配准不确定性升级为「可证明无碰撞」的双向证书（RegCert × RCC × CDAR，四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR 飞轮）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉」，本质是**验证链路的可信度**。本轮灵感词「碰撞避免」「点云配准」正好补上前 42 轮最大的结构性缺口：**所有证书都默认「用来判撞的几何/地图是给定的」，却从未认证这个几何本身是否正确**。真实机器人上，碰撞判断依赖点云配准——扫描配到地图、位姿带误差、退化场景（长廊/隧道/玻璃/对称房间）会让误差沿不可观方向暴涨。本轮核心主张：**把点云配准从「位姿估计黑箱」升格为「几何证书的签发者」，并让碰撞避免反过来告诉配准「哪个方向值得多花算力」——形成 perception→safety→perception 的双向证书闭环**。

## 0. 直觉与动机

**灵感 1（点云配准 → 不是给一个位姿，而是给一个「位姿集合」）**：ICP/NDT/GICP 的输出通常是一个 T̂，协方差是事后估计。直觉上这不够安全：真正需要的是「所有与观测相容的 T」构成的集合 R。若 R 有界，则对任意 T∈R 判撞都安全；若 R 在某方向无界（退化），就必须用先验/运动模型把它夹住，或判定证书无效。点云配准天然提供了这个集合：每个对应点的点到面残差 |n^T(Tp−q)| ≤ ε 就是一条对 T 的线性约束。把 T 在 se(3) 上线性化，R 的外近似就是一个**多面体** Ξ——退化方向不是「协方差很大」，而是「多面体在该方向没有边界面」，这正是几何上的不可观。

**灵感 2（碰撞避免 → 把配准不确定性传播成「膨胀障碍 + 鲁棒 CBF」）**：碰撞避免的直觉是「离障碍越远越安全」。配准误差是刚体误差，点 p 的位移 ≤ ||ω||·r_p + ||v||，其中 r_p 是相对传感器光心的力臂，因此**离传感器越远的障碍，其位置不确定性越大**——这给出一个随空间变化、各向异性的障碍膨胀半径 r_reg(q)。把地图按 r_reg 膨胀后，普通 ESDF/碰撞检测直接可用；再把膨胀后的 ESDF 作为 CBF 的 h(x)，就得到对任意相容配准都成立的鲁棒安全约束。关键：膨胀必须**保守但不过度**，否则自由空间被吞掉、机器人只会 SafeStop。

**灵感 3（双向证书 → 让碰撞灵敏度决定配准算力）**：第 42 轮是 Sim→RAG→Edge 的单向飞轮；本轮补上 safety→perception 的反向箭头。碰撞边际对配准不确定性的敏感度可解析给出：旋转方向约 L_Q·r（力臂），平移方向约 L_Q。于是「哪些方向的不确定性值得消除」由碰撞证书直接回答：只对敏感方向加扫描/加迭代/换视角，不敏感方向保持低算力。这把 anytime 配准从「均匀降采样」升级为**证书导向的主动配准（CDAR）**：用安全边际的敏感度做算力分配的梯度。更妙的是，它把「感知该多努力」从工程超参变成安全证书的内生变量。

**耦合升级**：RegCert 签发几何不确定性证书 → RCC 把它传播为碰撞证书 → CAR/规划消费碰撞证书 → CDAR 用碰撞敏感度反控配准 → SCV 在 Isaac Sim 里生成退化/对称/动态场景做压力测试 → CKB 存「退化指纹→失败模式→碰撞后果」→ ECR 用 INT8 质量监控器在边缘闸门化。证书从「几何给定下的控制证书」升级为「几何自身也被认证」的全栈证书。

## 1. 形式化定义（增量：定义 38–44）

**定义 38（集合值配准与线性化多面体证书）**：给定源点云 P、目标地图 Q、噪声界 ε，相容变换集
R(P,Q;ε) = { T∈SE(3) : ∀p∈P, dist(Tp,Q) ≤ ε }。
在初值 T̂ 处令 T = exp(ξ^)T̂，ξ=(ω,v)∈R^6，对每个对应 (p_i,q_i,n_i) 有点到面残差 d_i + a_i^T ξ，其中
d_i = n_i^T(T̂p_i − q_i)，a_i = [ (T̂p_i)×n_i ; n_i ]。
定义**配准证书多面体**
Ξ(P,Q;ε;T̂) = { ξ : |d_i + a_i^T ξ| ≤ ε, i=1..m } ∩ Ξ_prior ∩ {||ξ||∞ ≤ ξ_max}，
Ξ_prior 为运动/IMU 先验盒。**命题 1（外近似 soundness）**：exp 的余项满足 ||exp(ξ^)−(I+ξ^)|| ≤ ½||ξ||²，故在 ||ξ||∞ ≤ ξ_max 内，R ⊆ exp(Ξ)T̂ 至多差一个 O(ξ_max²) 的余项；实现上把余项折进 ε（ε' = ε − ½L_Q ξ_max²），超出 ξ_max 即判证书无效并触发迭代细化。

**定义 39（退化谱与空间变化的膨胀半径）**：对归一化 Hessian H = Σ_i a_i a_i^T 做特征分解 H = Σ_k λ_k u_k u_k^T。定义退化度 deg = λ_min/λ_max 与不可观方向集 U = {k : λ_k < λ_min}。由 Ξ 的盒包络 B=(B_ω,B_v)（6 个 LP 或区间界求得），对世界点 q（相对传感器光心 o_s）：
ρ_reg(q) = max_{ξ∈Ξ} ||ω×(q−o_s) + v|| ≤ ||B_ω||₂·||q−o_s|| + ||B_v||₂。
ρ_reg 随力臂线性增长、各向异性由 Ξ 的形状（而非各向同性球）决定。**命题 2**：ρ_reg(q) 是点 q 在任意相容配准下位移的严格上界。

**定义 40（配准条件下的碰撞边际）**：设机器人构型 x 占据集 R(x)，地图 SDF 为 d_Q，L_Q 为其 Lipschitz 常数（真 SDF 取 1），δ_model 为机器人模型误差：
m_col(x;Ξ) = min_{p∈R(x)} [ d_Q(T̂p) − L_Q·ρ_reg(T̂p) ] − δ_model。
**命题 3（鲁棒 soundness）**：对任意 T∈R，dist(T·R(x), Q) ≥ m_col(x;Ξ)。故 m_col>0 ⟹ 在全部相容配准下无碰撞。

**定义 41（配准条件 C-障碍与认证走廊）**：C_obs(Ξ) = { x : m_col(x;Ξ) ≤ 0 }，有 C_obs(Ξ) ⊇ C_obs(true)。等价的障碍膨胀实现：Q_infl = { q+δ : q∈Q, ||δ|| ≤ ρ_reg(q) }。一条凸走廊 K 被认证当且仅当 K ∩ C_obs(Ξ) = ∅；K 的保守收缩量由 Ξ 决定，并随场景退化程度自适应。

**定义 42（动态碰撞证书与认证 TTC）**：对动态障碍 o，跟踪给出速度/加速度界 (v_max,a_max)，配准不确定性 Ξ_t 与预测不确定性随视界 H 增长：
r_pred^o(H) = v_max H + ½ a_max H² + ρ_reg(q_o) + σ_track。
认证碰撞时间 TTC_cert = sup{ H : m_col(x(s);Ξ_s)>0, ∀s∈[0,H] }，鲁棒速度障碍 VO_cert = { v : ∃H, 认证 TTC ≤ H }。CBF 只需避开 VO_cert 的补集。

**定义 43（证书敏感度与主动配准收益）**：碰撞边际对第 k 个不确定性方向半宽 u_k 的敏感度
s_k(x) = ∂m_col/∂u_k ≈ L_Q·(∂ρ_reg/∂u_k)。
对旋转方向力臂 r 有 s_k ≈ L_Q·r，对平移方向 s_k ≈ L_Q。给定新增观测/迭代带来的信息矩阵增量 ΔH，Fisher/Cramér–Rao 给出 u_k' ≥ [(H+ΔH)^{-1}]_{kk}。**证书导向主动配准（CDAR）**的算力分配问题：
max_{scan,iter} Σ_k s_k·(u_k − u_k')  s.t.  Σ compute ≤ Γ_reg,  m_col ≥ m_target。
即：只在碰撞敏感方向购买不确定性下降；不敏感方向允许保持退化。

**定义 44（配准质量证书与 conformal 闸门）**：质量分 q_reg = g_θ(eig(H), 残差分位, 重叠率, 动态点比, 场景指纹距离)∈[0,1]。用 split conformal 校准非一致性分数，得到分布无关覆盖：P( T_true∈exp(Ξ_{q_reg})T̂ ) ≥ 1−α。运行时若 q_reg < q_min（等价于 Ξ 的膨胀超过证书预算），CAR 判「几何证书无效」，进入 Degraded/SafeStop；该闸门把「不撞」与「能走」的权衡显式化。

## 2. 四大产出设计（新增 IP-57/58/59 + 升级 IP-49/39/51/52/53/54/55/56/45/47）

### 2.1 IP-57 REG-CERT（配准证书引擎 RC）
1. **对应与鲁棒性**：kd-tree 精确最近邻 + 截断最小二乘（TLS）；离群点不入约束，但**未匹配点全部当作潜在障碍**进入 Q（宁可保守），动态点单独走跟踪。
2. **多面体构造与盒包络**：对每条残差建线性约束；用 6 个 LP（或 Gershgorin/区间快速界）求 B_ω,B_v；LP 太慢时退化为「Hessian 对角 + 先验」的区间界，保证 anytime 单调收紧。
3. **退化检测**：λ_min/λ_max、不可观方向 U、与场景指纹库比对的先验退化方向；输出 deg 与 U 供 CDAR 使用。
4. **conformal 校准**：仿真 + 少量实机标定，按场景族分组校准 q_reg→膨胀系数的映射，保证覆盖率 ≥ 1−α。

### 2.2 IP-58 RCC（配准条件碰撞证书）
1. **膨胀障碍地图**：按 ρ_reg(q) 分壳膨胀，八叉树/ESDF 增量更新；远点大膨胀、近点小膨胀。
2. **鲁棒碰撞边际与 CBF**：h(x)=m_col(x;Ξ)−m_safe；CBF-QP 用膨胀 ESDF 的梯度，保证对全部相容配准的前向不变性。
3. **认证走廊/规划**：SFC/凸分解在膨胀地图上生成；边有效性用保守推进（conservative advancement）保证整段 m_col>0。
4. **动态扩展**：鲁棒 VO + 认证 TTC；对每个动态障碍维护不确定性管（tube），配准误差与预测误差分别入管。

### 2.3 IP-59 CDAR（证书导向主动配准）
1. **敏感度图**：按 s_k 给 6 个方向排序；旋转方向对远处障碍最敏感。
2. **算力/视角分配**：多尺度 ICP 迭代、增采扫描、转向/减速（感知机动）；预算 Γ_reg 由安全边际缺口驱动。
3. **停止准则**：m_col ≥ m_target 或预算耗尽；耗尽仍不足 → 感知机动或降级，而不是盲目加算力。
4. **回退**：不可观方向无法通过任何视角消除（如纯长廊轴向）→ 用先验/减速/贴边策略，并把该退化指纹写入 CKB。

## 5. 本轮最大风险

**一句话**：配准证书在「对应关系歧义/离群点」下可能失去 soundness（把真实变换排除在 Ξ 之外，静默撞墙），而在强退化场景下 Ξ 又可能膨胀到吞掉整个自由空间（永久 SafeStop）——因此 E87（集合覆盖率红线）与 E89（退化检测/conformal 覆盖）必须同时守住「不撞」与「能走」两端，任一失守即熔断回退。

|---|---|---|
| R(P,Q;ε) = {T : ∀p, dist(Tp,Q) ≤ ε} | 相容变换集 | 集合值配准的输出，非单点 T̂ |
| Ξ = {ξ : \|d_i+a_i^Tξ\| ≤ ε} ∩ Ξ_prior ∩ {‖ξ‖∞≤ξ_max} | 配准证书多面体 | se(3) 线性化外近似；退化=无界面方向 |
| d_i = n_i^T(T̂p_i−q_i) | 点到面残差 | 对应 (p_i,q_i,n_i) 的初始残差 |
| a_i = [(T̂p_i)×n_i ; n_i] | 残差对 ξ 的梯度 | ξ=(ω,v)，旋转在前、平移在后 |
| H = Σ_i a_i a_i^T；λ_k,u_k | 配准 Hessian 与谱 | 退化度 deg=λ_min/λ_max，不可观方向 U |
| B=(B_ω,B_v) | Ξ 的盒包络 | 6 个 LP/区间界求出的各轴半宽 |
| ρ_reg(q) ≤ ‖B_ω‖₂‖q−o_s‖+‖B_v‖₂ | 空间变化膨胀半径 | 刚体误差位移上界，力臂越远越大 |
| m_col(x;Ξ)=min_{p∈R(x)}[d_Q(T̂p)−L_Qρ_reg(T̂p)]−δ_model | 配准条件碰撞边际 | m_col>0 ⟹ 全部相容配准下无碰撞 |
| Q_infl = {q+δ : ‖δ‖ ≤ ρ_reg(q)} | 膨胀障碍地图 | RCC 的高效实现 |
| TTC_cert / VO_cert | 认证碰撞时间/速度障碍 | 含 ρ_reg、预测误差、跟踪误差的鲁棒版 |
| s_k = ∂m_col/∂u_k ≈ L_Q·(∂ρ_reg/∂u_k) | 证书敏感度 | 旋转≈L_Q·r，平移≈L_Q |
| q_reg = g_θ(谱,残差,重叠,动态比,指纹距) | 配准质量证书 | conformal 校准：P(T_true∈Ξ) ≥ 1−α |
| CDAR: max Σ s_k(u_k−u_k') s.t. Σcompute≤Γ_reg | 证书导向主动配准 | 只在敏感方向购买不确定性下降 |

## 2. 关键算法（伪代码）

### IP-57 RegCert：多面体配准证书与退化谱
```
def build_registration_certificate(P, Q, T_hat, eps, Xi_prior, xi_max=0.1):
    # 1. 精确最近邻对应 + 截断最小二乘（TLS）去离群
    corr = nearest_neighbors(apply(T_hat, P), Q)          # kd-tree
    inliers = tls_filter(corr, eps)                        # 残差 > eps 视为离群
    # 2. 线性化约束：|d_i + a_i^T xi| <= eps
    A, d = [], []
    for (p_i, q_i, n_i) in inliers:
        tp = apply(T_hat, p_i)
        d.append(dot(n_i, tp - q_i))
        A.append(concat(cross(tp, n_i), n_i))              # xi = (omega, v)
    # 3. Hessian 谱 / 退化方向
    H = sum(outer(a, a) for a in A)
    lam, U = eigh(H)
    deg = lam.min() / max(lam.max(), 1e-9)
    U_null = [U[:, k] for k in range(6) if lam[k] < lam_min]
    # 4. 盒包络：6 个 LP；超时则退化为区间界（anytime 单调收紧）
    B_omega, B_v = lp_box_bounds(A, d, eps, Xi_prior, xi_max)
    # 5. 质量分 + conformal 膨胀系数
    q_reg = quality_score(H, residual_quantiles(inliers),
                          overlap(P, Q, T_hat), dynamic_ratio(P),
                          scene_fp_distance(P))
    kappa = conformal_inflation(q_reg)                     # sim+real 校准集
    return Certificate(T_hat=T_hat, A=A, d=d, eps=eps,
                       B=(B_omega, B_v), deg=deg, U_null=U_null,
                       q_reg=q_reg, kappa=kappa, xi_max=xi_max)

def lp_box_bounds(A, d, eps, Xi_prior, xi_max):
    B = []
    for k in range(6):
        lo = solve_lp(minimize=A[:, k], cons=[abs(d + A @ xi) <= eps],
                      bounds=[Xi_prior, abs(xi) <= xi_max])
        hi = solve_lp(maximize=A[:, k], cons=[abs(d + A @ xi) <= eps],
                      bounds=[Xi_prior, abs(xi) <= xi_max])
        B.append(max(abs(lo), abs(hi)))
    return B[:3], B[3:]

def rho_reg(q, cert, o_s):
    return norm(cert.B[0]) * norm(q - o_s) + norm(cert.B[1])
```

### IP-58 RCC：膨胀障碍、鲁棒碰撞边际与 CBF
```
def build_inflated_map(Q, cert, o_s, delta_model):
    # 分壳膨胀：同一距离壳共享半径，八叉树增量更新
    r_of = lambda q: rho_reg(q, cert, o_s) + delta_model
    return OctreeInflation(Q, r_of)

def collision_margin(x, cert, infl_map, L_Q=1.0, delta_model=0.0):
    # 等价实现：infl_map.signed_distance(apply(cert.T_hat, p))
    best = +inf
    for p in robot_occupied_points(x):
        tp = apply(cert.T_hat, p)
        best = min(best, infl_map.signed_distance(tp))
    return best - delta_model

def robust_cbf_qp(x, u_ref, cert, infl_map, alpha, m_safe):
    h = collision_margin(x, cert, infl_map) - m_safe
    dh = infl_map.gradient(x)                 # 膨胀 ESDF 梯度（Lipschitz）
    # min ||u-u_ref||^2  s.t.  dh·(f(x)+g(x)u) + alpha(h) >= 0
    return solve_qp(u_ref, dh, h, alpha)

def certified_corridor(x0, x_goal, cert, infl_map):
    # 在膨胀地图上做凸分解/SFC；每条边用保守推进验证整段 m_col > 0
    K = convex_decompose(x0, x_goal, infl_map)
    assert all(edge_certified(e, infl_map) for e in K.edges)
    return K

def certified_ttc(x, v, obs_tracks, cert, H_max, dt=0.05):
    for H in arange(0, H_max, dt):
        for o in obs_tracks:
            r = rho_reg(o.q, cert, o_s) + o.v_max*H + 0.5*o.a_max*H*H + o.sigma_track
            if infl_map.signed_distance(o.q + o.v*H) <= r + m_safe:
                return H
    return H_max
```

### IP-59 CDAR：证书敏感度驱动的主动配准
```
def certificate_sensitivity(cert, x):
    lever = max(norm(apply(cert.T_hat, p) - o_s) for p in robot_occupied_points(x))
    s_rot = [L_Q * lever] * 3          # 旋转：力臂越大越敏感
    s_trans = [L_Q] * 3                # 平移：与力臂无关
    return concat(s_rot, s_trans)

def cdar_allocate(cert, x, budget, m_target):
    s = certificate_sensitivity(cert, x)
    order = argsort(s, descending=True)
    while budget.remaining > 0 and collision_margin(x, cert) < m_target:
        # 只对敏感方向选择「每单位算力降不确定最多」的动作
        best = argmax(actions,
                      key=lambda a: s[order[0]] *
                          (u(cert, order[0]) - u(apply(a, cert), order[0]))
                          / cost(a))
        cert = apply(best, cert)
        budget.consume(best)
        order = argsort(certificate_sensitivity(cert, x), descending=True)
    if collision_margin(x, cert) < m_target:
        # 预算耗尽仍不足：感知机动（减速/转向）或降级，而非盲目加算力
        return PerceptionManeuver(slow=True, turn=True), cert
    return cert

def lookup_degeneracy_prior(scene_fp):
    # L0：场景指纹 → (先验退化方向, 所需额外扫描数, 历史碰撞后果)
    return kb_l0_table.get(scene_fp, default=(None, 0, None))
```

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 对应关系歧义/离群点使真值变换落在 Ξ 外（静默撞墙） | 高 | TLS 去离群；未匹配点全当障碍；E87 集合覆盖率红线；必要时用多假设配准并取 Ξ 并集 |
| 强退化使 Ξ 膨胀吞掉自由空间（永久 SafeStop） | 高 | CDAR 主动降不确定性 + 感知机动（减速/转向）；E88/E90 守可用性；不可解则显式 SafeStop 并重规划 |
| 线性化在 ξ_max 外失效 | 中 | ξ_max 截断 + 二阶余项折进 ε；超界即迭代细化或判无效 |
| conformal 在分布偏移下失效 | 中 | 按场景族分组校准；与第 42 轮漂移监控联动，超阈值重校准 |
| LP 盒包络实时性不足 | 中 | 区间/Gershgorin fallback + anytime 单调收紧；L0 预存先验退化方向 |
| 动态点污染配准（把行人当墙或反之） | 中 | 动静态分离；动态点走跟踪管；动态障碍单独膨胀 r_pred |
| 组合技能配准不确定性累积 | 低-中 | 按技能序列传播 Ξ；守卫取合取；关键切换点强制重新签发证书 |

## 6. 本轮最大风险

**一句话**：配准证书在「对应关系歧义/离群点」下可能失去 soundness（把真实变换排除在 Ξ 之外，静默撞墙），而在强退化场景下 Ξ 又可能膨胀到吞掉整个自由空间（永久 SafeStop）——因此 E87（集合覆盖率红线）与 E89（退化检测/conformal 覆盖）必须同时守住「不撞」与「能走」两端，任一失守即熔断回退。
