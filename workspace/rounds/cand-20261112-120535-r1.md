# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC/IP-153~160；灵感循环第 1 轮；本轮灵感：「情感语音」×「小样本学习」）

> 第 60 轮 SGEC 把「场景」升级为可预测的阻抗先验 π_scene(K|z)，用 SSM×CIEC×EPIR×SERC 实现了「场景先验提前收敛 K_safe、意图即时锁定约束、证据链防消息丢失」。但整条人机接口仍隐含两个未经检验的假设：
> 1. **意图是"干净的符号"**：CIEC 的意图集 I={'慢点','轻触','加紧','稳定','危险'} 与映射 ϕ 假设用户把意图编码成离散词、且语义即全部。真实用户用**情感语音**传意：颤抖的"轻一点"、急促的"快点"、犹豫的"要不…停一下"。音高、能量、语速、停顿、嗓音质量携带**紧迫度/恐惧/信任**，这些是安全元信号，却完全没有进入约束。
> 2. **映射是"手工常数"**：ϕ 是写死的 (v_max, F_max, K_p, K_d)。每个用户对"轻"的物理刻度不同、每种技能/工具不同、每种语言/口音不同，重标一遍成本极高。**小样本学习**能做 few-shot 校准，但 few-shot 恰恰在安全关键处泛化最不可靠——需要一个**分布无关的保证**，而不是一个点估计。
> 3. **两类信号的冲突没有仲裁**：语义说"快"、声音在发抖；语义说"没事"、语气在迟疑。谁说了算？保守方向必须自动占优，同时又不能因一次误判把机器人永久冻结——这需要**可证明的保守性**，而非经验性的"取更小值"。

## 0. 直觉与动机

**灵感 1（情感语音 → 韵律-语义双通道意图 APR）**
直觉：一句话同时有两条通道——**语义**（说了什么）和**韵律**（怎么说的）。"轻一点"在平静语气下是偏好，在发抖语气下是**恐惧**；"快点"在兴奋语气下是性能需求，在急促断句下是**危险临近**。关键洞见：**情感不是偏好，而是安全元信号**——高紧迫/高恐惧/低支配应无条件收紧约束，而不是与语义做平均。把通道建模为：语义给约束箱 C_sem，情感给约束箱 C_aff，最终约束取**交集**——"语义要快、语气在怕"时交集自动偏保守，不需要玄学投票。

**灵感 2（小样本学习 → 用户/任务特定的意图-约束校准 FSIC）**
直觉：few-shot 学习的价值不是"少样本也能猜准"，而是"少样本 + 元先验 → 残差更小，于是保形区间更窄"。关键洞见：安全关键场景**不能输出点估计**，必须输出**带覆盖保证的保守界**——对"越小越安全"的维度（F_max、v_max、ε_traj）用单侧保形上界，对"越大越安全"的维度（K_d）用单侧保形下界。执行值取这个界，则"执行约束不松于用户真实意图"的概率 ≥ 1−α，且不依赖模型正确。few-shot 元学习在这里的作用是**把区间压窄**，保形负责**把区间变可信**——两者缺一不可。

**灵感 3（分布外 → 保形证书的前置闸门 FSOOD）**
直觉：保形覆盖的合法性依赖**可交换性**（校准样本与测试样本同分布）。而情感语音天生是**长尾、非平稳、说话人特异**的：新用户、方言、罕见情绪正是分布外。关键洞见：**保形保证在 OOD 上不是"变弱"，而是"失效"**——此时任何 1−α 都是假的。因此 OOD 检测不是锦上添花，而是**必须前置的合法性检查**：判定 OOD 就不许用该证书，只能澄清或退回通用先验。这一条把"能保证"与"不能保证"划出了明确的边界。

**灵感 4（情感漂移 → 带安全锚的情感证据库 AEKB）**
直觉：情绪是时变的，用户对"轻"的刻度也会漂移（疲劳、压力、换工具）。few-shot 增量适应是必要的，但一次误标的情感样本可能永久污染映射。关键洞见：**适应必须过安全锚**——新增原型只有在与高置信历史证据的一致度不低于阈值时才被吸收；残差出现结构性漂移时（Page-Hinkley/ADWIN），**不是偷偷适应，而是宣布旧校准失效并强制重校准**，在重校准完成前退回保守先验。

**灵感 5（合流 → 情感小样本意图接地闭环 AFIGL）**
直觉：把上述串成闭环：语音→双通道（语义/情感）→元先验 few-shot→单侧保形界→OOD 闸门→认知安全仲裁→ERTC/EEIS 下发→执行→EV-exec + 意图证据→AEKB 更新/漂移检测→重校准。核心原则一句话：**「学用户话里的物理刻度，但只信到分布无关证书允许的那一步」**。与第 60 轮的关系是正交扩展：SERC 管「场景怎么安全落地」，AFIGL 管「话怎么被安全地听懂」。

**灵感 6（预算 → PCE++++++ 语义-情感-校准预算）**
直觉：第 60 轮的 B_scene/B_intent/B_ros/B_exec 没有为"情感推理"与"few-shot 重校准"留位置。新增 B_sem（ASR/NLU 算力与延迟）、B_aff（韵律/情感推理）、B_fs（few-shot 适应与保形重标定）、B_cal（校准验证与漂移检测）。耗尽策略：B_aff 耗尽⇒仅语义 + 保守默认；B_fs 耗尽⇒只用元先验且区间加宽；B_cal 耗尽⇒不得宣称覆盖保证，只能走澄清/回退。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（情感韵律表征与双通道意图 APR）** 设语音信号 x_{1:T}，双通道输出 y = (i_s, a, ρ)：
- **语义通道**：i_s = NLU(ASR(x))，经第 60 轮 CIEC 的 ϕ 得到约束箱 C_sem ⊆ R^5（分量 v_max, F_max, K_p, K_d, ε_traj）。
- **情感通道**：由韵律特征 f_pros = (F0 均值/范围/斜率, 能量, 语速, 停顿比, jitter, shimmer, HNR) 估计分类后验 p(e|x)（calm/urgent/fearful/hesitant/neutral）与维度情感 a=(valence, arousal, dominance, urgency) ∈ [-1,1]²×[0,1]²。
- **情感→约束**：ϕ_aff(a) → C_aff，且满足**单调性**：urgency 或 arousal 上升 ⇒ 上界维（v_max,F_max,ε_traj）单调不增、下界维（K_d）单调不减，即 C_aff 只会变紧。
- **可靠性**：ρ ∈ [0,1] 为情感通道可靠性（由后验熵、语音信噪比、说话人覆盖度联合给出）。
- **箱式交集**：对箱 C=(l,u)，C_sem ∩ C_aff = (max(l), min(u)) 逐维计算，故 C_fused ⊆ C_sem 且 C_fused ⊆ C_aff。**保守性由集合代数自动给出，不依赖权重调参。**

**定义 162（保守语义-情感融合与冲突仲裁 CSAC）** 给定 C_sem, C_aff, 可靠性 ρ_aff, 阈值 τ_rel, 最大收紧量 Δ_max：
- **融合**：C_fused = C_sem ∩ C_aff。
- **冲突指示**：conflict = 1 ⇔ 语义在某上界维要求放松（增大）而情感要求收紧到 Δ_max 以上，或语义与情感在 urgency 方向上符号相反。
- **可靠性门**：若 ρ_aff < τ_rel，则把情感通道造成的收紧截断在 Δ_max（防止一次误判把机器人冻结）：C_exec = Cap(C_fused, C_sem, Δ_max)。
- **硬安全交**：C_safe = C_exec ∩ K_inv ∩ C_rt（K_inv 为跨任务不变安全核，C_rt 为 ERTC 实时契约）；若 C_safe = ∅ 则触发仲裁失败，交定义 166 处理。
- **定理（保守性）**：任何 c ∈ C_safe 都不松于 C_sem 与 C_aff 中的任一约束；即"情感让语义更保守"是有证明的，而不是经验规则。

**定义 163（小样本意图-约束校准 FSIC）** 元先验 ϕ_0 在跨用户/跨任务训练集上学习；用户 u 的支撑集 S_u = {(x_j, c_j)}_{j=1..k}（k≤5），适配得到 ϕ_u = Adapt(ϕ_0, S_u)（岭回归/原型网络/MAML 内循环均可）。
- **非一致性分数**：对每个安全维 d，残差 r_d(x) = c_{true,d} − ϕ_{u,d}(x)（"越小越安全"维）或反向（"越大越安全"维）。
- **单侧保形界**：在校准集 D_cal（与 S_u 不相交）上取 q_d = Quantile_{⌈(n+1)(1−α)⌉/n}({r_d})，执行界为
  - 上界维：b_d(x) = ϕ_{u,d}(x) + q_d，保证 P(c_{true,d} ≤ b_d(x)) ≥ 1−α；
  - 下界维：b_d(x) = ϕ_{u,d}(x) + q_d（q_d 取负尾分位），保证 P(c_{true,d} ≥ b_d(x)) ≥ 1−α。
- **执行约束**：c_exec = b(x)（取保守界而非均值），并交入定义 162 的 C_safe。
- **意义**：few-shot 元先验把残差尺度收缩、区间变窄；保形把"窄"变成"可信"；二者共同把"个性化"约束在"有覆盖保证"的范围内。

**定义 164（分布外情感检测与弃权 FSOOD）** 度量嵌入 ψ，支撑原型 {ψ(x_j)}：
- **OOD 分数**：s_ood(x) = min_j ||ψ(x) − ψ(x_j)||_Σ。
- **合法性判定**：valid(x) = 1 ⇔ s_ood(x) ≤ τ_ood ∧ ρ_aff ≥ τ_rel ∧ n_cal ≥ n_min。
- **弃权策略**：valid=0 时**不得使用任何 1−α 覆盖声明**，只能 (a) 请求澄清（CLARIFY）或 (b) 退回第 60 轮通用先验 π_scene^general 与默认约束（FALLBACK）。
- **声明的意义**：把"能保证"与"不能保证"显式切开——OOD 时证书不是"不精确"，而是"无效"。

**定义 165（情感证据知识库 AEKB）** E_u = {(x_i, c_i, τ_i, ρ_i, source_i)}，含三类操作：
- **吸收（safety anchor）**：新样本仅在 Δ-drift = ||ϕ_u^{new}(x_i) − c_i|| 不超过高置信历史证据的 ε_drift 分位时，才允许更新原型；否则进入**隔离区**而非直接吸收。
- **漂移检测**：对残差序列做 Page-Hinkley/ADWIN；检出漂移 ⇒ 冻结当前 ϕ_u、宣告旧校准失效，进入强制重校准，重校准完成前只用元先验 + 加宽保形界。
- **抗遗忘**：更新时回放高置信锚样本，约束新原型与锚样本的一致度不低于 ε_anchor，防止"学新忘旧"把安全裕度一并遗忘。

**定义 166（认知安全仲裁协议 CSAP）** 动作集 A_csap = {ACCEPT, CLARIFY, FALLBACK}：
```
if not FSOOD.valid(x):                         → CLARIFY（若预算允许）else FALLBACK
if conflict and ρ_aff < τ_rel:                 → CLARIFY
if C_safe == ∅:                                → FALLBACK（默认约束 + K_inv）
if conformal 覆盖未通过（重校准/漂移中）:      → FALLBACK（加宽界或通用先验）
else:                                          → ACCEPT(C_safe, Cert_intent)
```
产出**意图证书** Cert_intent = (i_s, a, ρ_aff, b(x), coverage≥1−α, OOD=false, conflict_resolution, C_safe≠∅)。Cert_intent 与第 60 轮 Cert_eeis 并列，前者证"听懂了且不松于真意"，后者证"执行在安全集内"。

**定义 167（预算 PCE++++++）** B_aff_budget = (B_sem, B_aff, B_fs, B_cal, B_exec)：
- B_sem：ASR/NLU 延迟与算力；B_aff：韵律/情感推理；B_fs：few-shot 适应与保形重标定；B_cal：校准验证与漂移检测；B_exec：原有执行预算。
- **VOI 扩展**：voi_aff(π) = VOI_meta(π) − cost_sem − cost_aff − cost_fs − cost_cal − cost_exec。
- **耗尽策略**：B_aff 耗尽 ⇒ 语义-only + 保守默认；B_fs 耗尽 ⇒ 元先验 + 加宽界（α 上调）；B_cal 耗尽 ⇒ 禁用覆盖声明、强制 CLARIFY/FALLBACK；任一耗尽都不得绕过 K_inv。

**定义 168（情感小样本意图接地闭环 AFIGL）** 算子 AFIGL(M, x_audio, scene)：
```
① APR:      (i_s, a, ρ_aff) ← DualChannel(x_audio)
② SERC:     z_scene, π_scene ← M.scene_model.update(...)      # 接第 60 轮
③ FSIC:     ϕ_u ← Adapt(ϕ_0, S_u); b(x) ← OneSidedConformal(ϕ_u, D_cal, α)
④ FSOOD:    valid ← ood_gate(x_audio) ∧ ρ_aff ≥ τ_rel
⑤ CSAC:     C_fused ← C_sem ∩ C_aff; C_safe ← Cap(C_fused)∩K_inv∩C_rt
⑥ CSAP:     action ← arbitrate(valid, conflict, C_safe, coverage)
⑦ Dispatch: ERTC.lock_constraints(C_safe); EEIS.compile(K_safe^scene, C_safe)
⑧ Execute:  telemetry ← wait_contact()
⑨ Evidence: EV-exec + EV-intent = (i_s, a, b(x), Cert_intent) → EPIR.append
⑩ AEKB:     E_u.append; if drift: invalidate(ϕ_u) → 重校准
⑪ Return:   (action, C_safe, Cert_intent, Cert_eeis, EV-exec, EV-intent)
```

## 2. 关键算法伪代码

### IP-161 APR（双通道情感意图）

```python
class AffectiveProsodyRepresentation:
    def extract(self, audio_stream):
        f0 = pitch_track(audio_stream)
        feats = {
            'f0_mean': mean(f0), 'f0_range': ptp(f0), 'f0_slope': slope(f0),
            'energy': rms(audio_stream), 'rate': syllable_rate(audio_stream),
            'pause_ratio': pause_ratio(audio_stream),
            'jitter': jitter(f0), 'shimmer': shimmer(audio_stream), 'hnr': hnr(audio_stream)
        }
        return feats

    def infer(self, feats):
        p_e = self.emotion_head(feats)                 # 分类后验
        a = self.dim_head(feats)                       # (valence, arousal, dominance, urgency)
        rho = confidence(p_e) * snr_factor(feats)      # 通道可靠性
        return p_e, a, rho

    def to_constraint(self, a, p_e):
        u = clip(a.urgency, 0, 1)
        upper = lambda hi: hi * (1 - self.k_u * u)     # 上界维单调降
        lower = lambda lo: lo * (1 + self.k_u * u)     # 下界维单调升
        return Box(v_max=upper(V0), F_max=upper(F0),
                   K_d=lower(Kd0), eps=upper(E0))
```

### IP-162 CSAC（保守融合与仲裁）

```python
def fuse_and_arbitrate(c_sem, c_aff, rho_aff, tau_rel, delta_max, K_inv, C_rt):
    c = intersect_box(c_sem, c_aff)                    # 逐维 max(l)/min(u)，只会变紧
    if rho_aff < tau_rel:
        c = cap_tightening(c, c_sem, delta_max)        # 防误判冻结
    c_safe = intersect_box(c, K_inv, C_rt)
    return c_safe if c_safe.nonempty else None
```

### IP-163 FSIC（小样本保形界）

```python
class FewShotIntentCalibration:
    def __init__(self, phi0, alpha=0.1):
        self.phi0, self.alpha = phi0, alpha

    def adapt(self, support):
        return ridge_adapt(self.phi0, support)         # 也可原型/MAML 内循环

    def calibrate(self, phi_u, calib):
        q = {}
        for d in SAFETY_DIMS:
            r = [true_d(x) - phi_u(x)[d] for x, true_d in calib]
            r.sort()
            n = len(r)
            k = min(n, int(np.ceil((n + 1) * (1 - self.alpha))))
            q[d] = r[k - 1]                            # 单侧分位
        return q

    def bound(self, phi_u, q, x):
        return {d: phi_u(x)[d] + q[d] for d in SAFETY_DIMS}   # 保守界，非均值
```

### IP-164 FSOOD（分布外闸门）

```python
class OODGate:
    def __init__(self, tau_ood, tau_rel, n_min):
        self.tau_ood, self.tau_rel, self.n_min = tau_ood, tau_rel, n_min

    def valid(self, x, psi, support, rho_aff, n_cal):
        d = min(norm(psi(x) - psi(xj)) for xj in support)
        return (d <= self.tau_ood) and (rho_aff >= self.tau_rel) \
               and (n_cal >= self.n_min)
```

### IP-165 AEKB（安全锚 + 漂移 + 抗遗忘）

```python
class AffectiveEvidenceKnowledgeBase:
    def append(self, x, c, rho, source):
        self.evidence.append(dict(x=x, c=c, rho=rho, source=source, t=now()))

    def try_absorb(self, x, c, phi_u, eps_drift):
        if distance(phi_u(x), c) <= eps_drift:
            self.anchors.append((x, c)); return 'absorbed'
        self.quarantine.append((x, c)); return 'quarantined'

    def drift(self):
        return page_hinkley(self.residual_stream) > self.lambda_ph
```

### IP-166 CSAP（仲裁）

```python
def arbitrate(valid, conflict, c_safe, coverage_ok, rho_aff, tau_rel, budget):
    if not valid:
        return 'CLARIFY' if budget.allow_clarify else 'FALLBACK'
    if conflict and rho_aff < tau_rel:
        return 'CLARIFY'
    if c_safe is None or not coverage_ok:
        return 'FALLBACK'
    return 'ACCEPT'
```

### IP-168 AFIGL（闭环）

```python
def affective_few_shot_intent_grounding_loop(M, audio, scene):
    i_s, a, rho = M.apr.infer(M.apr.extract(audio))
    c_sem = M.ciec.map_intent(i_s)
    c_aff = M.apr.to_constraint(a)
    M.scene_model.update(M.telem_force, M.telem_pos)

    phi_u = M.fsic.adapt(M.support[scene.user])
    q = M.fsic.calibrate(phi_u, M.calib[scene.user])
    b = M.fsic.bound(phi_u, q, audio)
    valid = M.ood.valid(audio, M.psi, M.support[scene.user], rho, len(M.calib))

    c_safe = fuse_and_arbitrate(c_sem, c_aff, rho, M.tau_rel, M.delta_max,
                                M.K_inv, M.C_rt)
    action = arbitrate(valid, M.conflict(i_s, a), c_safe, valid, rho,
                       M.tau_rel, M.budget_aff)

    if action == 'ACCEPT':
        M.ertc.lock_constraints(c_safe)
        K_safe = M.eeis.compile_with_constraint(b, c_safe, scene)
        dispatch_impedance_params(K_safe.best, M.cert_eeis)
        tele = wait_contact()
        evx, evi = build_exec_evidence(tele), build_intent_evidence(i_s, a, b)
        M.epir.append(evx); M.epir.append(evi)
        M.aekb.try_absorb(audio, b, phi_u, M.eps_drift)
        if M.aekb.drift():
            M.fsic.invalidate(scene.user)              # 强制重校准
            action = 'FALLBACK'
    return action, c_safe, M.cert_intent(), M.cert_eeis
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| APR | O(T·d_pros) 流式 | O(d_pros) | 情感分类 F1 ≥ 0.85；可靠性与误差单调相关 |
| CSAC | O(d) 箱交集 | O(d) | 融合约束 C_safe ⊆ C_sem 且 ⊆ C_aff（可证保守） |
| FSIC | O(k·d) 适配 + O(n_cal log n_cal) 标定 | O(n_cal) | 单侧覆盖 P(不松于真意) ≥ 1−α（可交换时） |
| FSOOD | O(\|S_u\|·d) 最近邻 | O(\|S_u\|·d) | OOD 时禁止覆盖声明，杜绝虚假证书 |
| AEKB | O(1) 追加 / O(log n) 漂移 | O(n) | 吸收过安全锚；漂移即失效旧校准 |
| CSAP | O(d) 判决 | O(1) | ACCEPT 蕴含 valid ∧ coverage ∧ C_safe≠∅ |
| AFIGL | 主导于语音推理延迟 | 复用 | 端到端不绕过 K_inv |

**正确性定理（AFIG）**：假设 A71–A75 成立。
**(A71) APR**：韵律特征是安全相关情感的充分统计量，ρ_aff 与实际误差单调相关。**(A72) CSAC**：约束为箱式集合，交集逐维精确实现，ϕ_aff 单调（urgency↑ ⇒ 更紧）。**(A73) FSIC**：用户内校准样本与测试样本可交换，残差有界，单侧分位计算正确。**(A74) FSOOD**：OOD 分数对破坏可交换性的输入有检出功效，弃权率有界。**(A75) AEKB**：漂移检测延迟有界，高置信锚样本正确。

则：
1. **保守性**：任意 c ∈ C_safe 不松于 C_sem 与 C_aff；情感通道只能让约束更紧，绝不更松（由箱式交集 + 单调映射直接得出）。
2. **覆盖性**：若 valid(x)=1 且可交换成立，则 P(c_exec 不松于用户真实约束) ≥ 1−α；few-shot 元先验只影响区间宽度，不影响覆盖名义值。
3. **硬安全性**：c_exec ∈ K_inv 恒成立；C_safe=∅ 时 CSAP 只允许 FALLBACK/CLARIFY，绝不执行越界约束。
4. **OOD 可靠性**：valid(x)=0 时不产生任何覆盖声明——证书"无效"而非"不准"，杜绝虚假安全。
5. **漂移可靠性**：检出漂移即宣告旧校准失效并强制重校准，重校准前只用保守先验，旧证书不复用。
6. **退化一致**：令 α→1，保形界退化为点估计；令情感通道关闭（ρ_aff→0 且 Cap 截断），AFIGL 逐字退化回第 60 轮 CIEC，说明本轮是严格增量。

### IP-161 APR（双通道情感意图）

```python
class AffectiveProsodyRepresentation:
    def __init__(self, k_u=0.6, V0=0.5, F0=20.0, Kd0=50.0, E0=0.01):
        self.k_u, self.V0, self.F0, self.Kd0, self.E0 = k_u, V0, F0, Kd0, E0
        self.emotion_head = EmoHead()
        self.dim_head = DimHead()

    def extract(self, audio_stream):
        f0 = pitch_track(audio_stream)
        return {
            'f0_mean': mean(f0), 'f0_range': ptp(f0), 'f0_slope': slope(f0),
            'energy': rms(audio_stream), 'rate': syllable_rate(audio_stream),
            'pause_ratio': pause_ratio(audio_stream),
            'jitter': jitter(f0), 'shimmer': shimmer(audio_stream),
            'hnr': hnr(audio_stream),
        }

    def infer(self, feats):
        p_e = self.emotion_head(feats)
        a = self.dim_head(feats)                       # (v, ar, d, u)
        rho = confidence(p_e) * snr_factor(feats)      # 可靠性
        return p_e, a, rho

    def to_constraint(self, a, p_e):
        u = clip(a[3], 0.0, 1.0)                       # urgency
        upper = lambda hi: hi * (1 - self.k_u * u)     # 上界维单调降
        lower = lambda lo: lo * (1 + self.k_u * u)     # 下界维单调升
        return Box(v_max=upper(self.V0), F_max=upper(self.F0),
                   K_d=lower(self.Kd0), eps=upper(self.E0))
```

### IP-162 CSAC（保守融合与硬安全）

```python
def intersect_box(*boxes):
    lo = [max(b.l[i] for b in boxes) for i in range(DIM)]
    hi = [min(b.u[i] for b in boxes) for i in range(DIM)]
    return Box(lo, hi)                                 # 交集只会变紧

def cap_tightening(c, c_sem, delta_max):
    lo = [max(c.l[i], c_sem.l[i] - delta_max) for i in range(DIM)]
    hi = [min(c.u[i], c_sem.u[i]) for i in range(DIM)]
    return Box(lo, hi)

def fuse_and_arbitrate(c_sem, c_aff, rho_aff, tau_rel, delta_max, K_inv, C_rt):
    c = intersect_box(c_sem, c_aff)
    if rho_aff < tau_rel:
        c = cap_tightening(c, c_sem, delta_max)        # 防误判冻结
    c_safe = intersect_box(c, K_inv, C_rt)
    return c_safe if c_safe.nonempty else None
```

### IP-163 FSIC（小样本保形界）

```python
SAFETY_DIMS = ['v_max_upper', 'F_max_upper', 'K_d_lower', 'eps_upper']

class FewShotIntentCalibration:
    def __init__(self, phi0, alpha=0.1):
        self.phi0, self.alpha = phi0, alpha
        self.invalid = set()

    def adapt(self, support):
        return ridge_adapt(self.phi0, support)          # 或原型/MAML 内循环

    def calibrate(self, phi_u, calib):
        q = {}
        for d in SAFETY_DIMS:
            r = sorted(true_d(x) - phi_u(x)[d] for x, true_d in calib)
            n = len(r)
            k = min(n, int(np.ceil((n + 1) * (1 - self.alpha))))
            q[d] = r[k - 1]                              # 单侧分位
        return q

    def bound(self, phi_u, q, x):
        return {d: phi_u(x)[d] + q[d] for d in SAFETY_DIMS}

    def invalidate(self, user):
        self.invalid.add(user)                           # 漂移后强制重校准
```

### IP-164 FSOOD（分布外闸门）

```python
class OODGate:
    def __init__(self, tau_ood, tau_rel, n_min):
        self.tau_ood, self.tau_rel, self.n_min = tau_ood, tau_rel, n_min

    def valid(self, x, psi, support, rho_aff, n_cal):

            return False
        d = min(norm(psi(x) - psi(xj), ord=2) for xj in support)
        return d <= self.tau_ood                         # OOD ⇒ 覆盖声明无效
```

### IP-165 AEKB（安全锚 + 漂移 + 抗遗忘）

```python
class AffectiveEvidenceKnowledgeBase:
    def __init__(self, eps_drift, eps_anchor, lambda_ph):
        self.evidence, self.anchors, self.quarantine = [], [], []
        self.eps_drift, self.eps_anchor, self.lambda_ph = eps_drift, eps_anchor, lambda_ph
        self.residual_stream = []

    def try_absorb(self, x, c, phi_u):
        delta = distance(phi_u(x), c)
        self.residual_stream.append(delta)
        if delta <= self.eps_drift and self.consistent_with_anchors(x, c):
            self.anchors.append((x, c)); return 'absorbed'
        self.quarantine.append((x, c)); return 'quarantined'

    def consistent_with_anchors(self, x, c):
        return all(distance(c, ca) <= self.eps_anchor for _, ca in self.anchors[-K_ANCHOR:])

    def drift(self):
        return page_hinkley(self.residual_stream) > self.lambda_ph
```

```python
def arbitrate(valid, conflict, c_safe, coverage_ok, rho_aff, tau_rel, budget):
    if not valid:
        return 'CLARIFY' if budget.allow_clarify else 'FALLBACK'
    if conflict and rho_aff < tau_rel:
        return 'CLARIFY'
```

### IP-168 AFIGL（闭环）

```python
def affective_few_shot_intent_grounding_loop(M, audio, scene):
    i_s, a, rho = M.apr.infer(M.apr.extract(audio))
    c_sem = M.ciec.map_intent(i_s)
    c_aff = M.apr.to_constraint(a)
    M.scene_model.update(M.telem_force, M.telem_pos)

    if scene.user in M.fsic.invalid:
        return 'FALLBACK', None, M.general_prior()

    phi_u = M.fsic.adapt(M.support[scene.user])
    q = M.fsic.calibrate(phi_u, M.calib[scene.user])
    b = M.fsic.bound(phi_u, q, audio)
    valid = M.ood.valid(audio, M.psi, M.support[scene.user], rho, len(M.calib))

    c_safe = fuse_and_arbitrate(c_sem, c_aff, rho, M.tau_rel, M.delta_max,
                                M.K_inv, M.C_rt)
    action = arbitrate(valid, M.conflict(i_s, a), c_safe, valid, rho,
                       M.tau_rel, M.budget_aff)

    if action == 'ACCEPT':
        M.ertc.lock_constraints(c_safe)
        K_safe = M.eeis.compile_with_constraint(b, c_safe, scene)
        dispatch_impedance_params(K_safe.best, M.cert_eeis)
        tele = wait_contact()
        evx = build_exec_evidence(tele)
        evi = build_intent_evidence(i_s, a, b, M.cert_intent())
        M.epir.append(evx); M.epir.append(evi)
        M.aekb.try_absorb(audio, b, phi_u)
        if M.aekb.drift():
            M.fsic.invalidate(scene.user)                # 旧校准作废
            action = 'FALLBACK'

    return action, c_safe, M.cert_intent(), M.cert_eeis
```

**数据与协议**：情感语音公开集（IEMOCAP/RAVDESS 等，仅取韵律与情感标签，不复用其语义任务）+ 自采中文家庭指令集；约束真值由动觉示教/问卷标定得到；用户级切分（同一说话人不同时出现在元训练与校准），严格模拟 few-shot 与 OOD。隐私：语音特征本地提取，仅上传 Cert_intent 与统计量，不上传原始音频。

## 5. 本轮最大风险

**一句话**：保形覆盖的合法性依赖可交换性，而情感语音恰恰是长尾、非平稳、说话人特异的——最需要它的那一次"恐惧喊停"最可能落在校准分布之外；一旦 OOD 漏报或用旧校准覆盖新用户，1−α 的统计证书就会在最关键时刻退化为"虚假安全证书"，因此必须以「OOD 弃权 + 硬 K_inv + 漂移即失效 + 人机澄清」四重护栏兜底，宁可让机器人"听不懂就停下"，也绝不允许保形覆盖声明越过物理安全约束。
