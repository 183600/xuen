# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「痛点分析」×「低成本方案」）

> 第 54 轮完成了动作空间剖面、技能组合图、云边协同与动作-鲁棒性联合证书，把「能不能组合」做成了可判定命题。但该体系隐含一个部署前提：**评测预算充足、动作空间可被均匀扫过**。真实部署的痛恰好相反：预算有限，而失败代价极不均匀。本轮把重心从「更强的证书」转向「**证书的部署经济学**」：用痛点图决定测什么，用预算约束决定测多少，用迁移与运行时围栏把测不起的部分低成本兜住。核心矛盾：H22 完备证书的成本随 `|动作空间|×|维度|` 膨胀，而绝大部分成本花在低痛点区域，导致「证书很严谨、却没人用得起」；H23 痛点加权与低成本近似会系统性饿死低频灾难尾巴，若痛点图低估罕见致命模式，越省钱的方案越危险。

## 0. 直觉与动机

**灵感 1（痛点分析 → 把「均匀重要」改成「按痛点加权」）**
直觉：第 54 轮默认动作空间与鲁棒性维度同等重要，于是按 `|A|×|𝔇_ρ|` 均匀评测。但真实失败高度不均匀：90% 的时间只落在 10% 的动作子空间里，且不同失败的代价相差几个数量级（夹爪空抓 vs 近人碰撞）。定义**痛点** `π(e)=f(e)·sev(e)`（发生频率 × 归一化严重度）。评测预算应买「痛点质量」，而不是买「动作空间体积」。这是把成本从「覆盖面」转向「风险削减」的第一性重排。

**灵感 2（低成本方案 → 预算约束的主动取证，而非全量扫描）**
直觉：给定预算 `B`（真机时间/磨损/风险当量），认证是一个带硬地板的 0/1 背包或集合覆盖：每个探针买到一块「已认证痛点质量」。按 `π(e)·ρ_cert(e)/c(e)` 贪心，当目标对事件子集次模时可得 `(1-1/e)` 近似。这把「要不要测」变成「每块钱买多少风险下降」的可计算问题，也让「不测」变成一个有账可查的显式决策。

**灵感 3（低成本方案 → 技能剖面迁移，用相似性换采样）**
直觉：不必给每个新技能从零扫动作空间。若技能在表征上相近（同一夹爪、相近轨迹族、相近接触模式），则 `α_S ≈ T_{S'→S}(α_{S'})`，只需少量校准点修正偏差 `ε_tr`。这把 `O(|S|·|A|)` 降到 `O(|S_lib|·m + |A_calib|)`，代价是引入迁移不确定性 `u_tr`；一旦 `ε_tr` 超阈值，必须回退全扫，绝不能让迁移「免费」地制造虚假兼容。

**灵感 4（任何时刻证书 → 允许「认证债」，但债务可见、单调、有上限）**
直觉：全量证书是奢侈品。低成本方案应输出 **anytime 证书**：随预算增加，已认证集 `X` 单调扩张、认证债 `debt=Π(E\X)` 单调下降。部署不必等到 `debt=0`，而是要求 `debt_eff ≤ R_max`。证书从「证明无风险」降级为「如实申报剩余风险」，并允许后续预算或运行时围栏「还债」。

**灵感 5（痛点分析的反面 → 灾难地板不能被优化器触碰）**
直觉：一旦用痛点权重驱动预算，优化器会本能地砍掉「低频但致命」的项，因为它们的期望痛点低。因此必须先划出 **强制认证地板 `E_floor`**（碰撞、跌落、力矩超限、近人交互、急停失效等），它在任何预算下被优先锁死、不可被剪枝；优化只作用于地板之外的「弹性痛点」。这是一条与预算无关的安全约束，而不是可交易的成本项。

**灵感 6（低成本方案 → 分层部署与运行时兜底，把离线证明换成在线围栏）**
直觉：对无法离线证明的残余风险，用低成本运行时机制承接：看门狗谓词 `Φ`、安全回退技能 `Ψ`、回滚与限时 `τ_trip`。分层 `T0`（全证）/`T1`（部分证 + 围栏）/`T2`（探针 + 纯回退）。用承接概率 `p_cont` 与 `τ_trip` 量化兜底能力，把「先证后跑」变成「边跑边兜」。但兜底本身有成本与失效概率，必须计入 `R_eff`，不能当成免费的保险。

**灵感 7（评测金字塔扩展 → ℙ 层：痛点-预算层）**
直觉：在 `𝕃`（鲁棒性）、`𝔸`（动作协同）、`𝕄`（机群）之外增加 **痛点-预算层 `ℙ`**：`ℙ_0` 失败事件与代价，`ℙ_1` 痛点图与地板，`ℙ_2` 预算取证与剖面迁移，`ℙ_3` 分层部署与残余风险申报。跨层证书需同时携带 `pain_coverage`、`debt`、`tier`、`p_cont`、`u_tr`、`fn_cat`。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（失败事件与痛点图）**
设部署分布为 `D`。失败事件 `e=(a,d,s_ctx)∈E`，其中 `a∈A` 为动作、`d∈𝔇_ρ` 为鲁棒性维度、`s_ctx` 为共享上下文。事件频率 `f(e)∈[0,1]`，严重度 `sev(e)∈[0,1]`（以最大可接受损失 `L_max` 归一化）。**痛点** `π(e)=f(e)·sev(e)`。痛点图 `P=(E,π,c)`，`c(e)>0` 为单事件认证成本。**痛点质量** `Π(X)=Σ_{e∈X}π(e)`。**灾难地板** `E_floor={e: sev(e)≥sev_crit}`，`sev_crit` 由安全规范给定，任何预算方案必须满足 `E_floor⊆X`。

**定义 122（预算取证问题）**
给定预算 `B` 与认证集 `X⊆E`，残余风险
```
R(X) = Σ_{e∈E\X} π(e) + Σ_{e∈X} (1-ρ_cert(e))·π(e) + r_floor(X),
r_floor(X) = +∞  若 E_floor ⊄ X，否则 0.
```
预算取证：`min_X R(X)  s.t.  C(X)=Σ_{e∈X} c(e) ≤ B`。当 `ρ_cert≡1` 时退化为带硬地板的预算覆盖/背包；当同一探针同时认证多个 `d` 时，收益对事件子集**次模**（边际递减）。

**定义 123（anytime 证书与认证债）**
`J_any=(B_used, X, debt, ρ_cert, u_tr, tier, evidence)`，其中 `debt=Π(E\X)` 为认证债。要求单调性 `B↑ ⇒ X↑ ⇒ debt↓`。有效认证债
```
debt_eff(X,τ) = debt(X) + (1-p_cont(τ))·R_intrinsic + u_tr_weighted(X).
```
可部署弱条件：`debt_eff ≤ R_max ∧ E_floor⊆X`。它不承诺零风险，只承诺**剩余风险被显式申报且不超预算**。

**定义 124（剖面迁移与迁移不确定性）**
技能表征 `φ(S)∈ℝ^m`。迁移算子 `T_{S'→S}` 给出 `α̂_S=T_{S'→S}(α_{S'})`，迁移误差
```
ε_tr(S,S') = sup_{a∈A} |α̂_S(a) - α_S(a)|.
```
准入条件 `ε_tr≤ε_max`。迁移不确定性 `u_tr(S)=ε_tr+κ·dist(φ(S),φ(S'))`，并入 `J_any`；不满足准入则必须回退全量扫描。

**定义 125（分层部署与围栏承接）**
部署层 `τ∈{T0,T1,T2}`（全证 / 部分证+围栏 / 探针+纯回退）。围栏 `G=(Φ,Ψ,τ_trip)`：`Φ` 为监控谓词集，`Ψ` 为安全回退技能，`τ_trip` 为触发到完成的限时。承接概率 `p_cont(τ)=P(Φ 在 τ_trip 内触发 ∧ Ψ 成功)`。有效残余风险
```
R_eff(X,τ) = (1-p_cont(τ))·R(X) + p_cont(τ)·R(Ψ).
```

**定义 126（成本-收益部署判据）**
任务价值 `V`、灾难损失上界 `L`、认证成本 `C_cert`、运行成本 `C_ops`。期望效用
```
E[U] = (1-R_eff)·V - R_eff·L - C_cert - C_ops.
```
部署当且仅当 `E[U]≥0 ∧ P(loss>L_max)≤δ`；否则 `abstain`。这把「能否证明」转为「是否值得证明/运行」，并允许「不部署」成为一等公民。

**定义 127（痛点加权组合与地板穿越）**
组合边 `e=(S_i,S_j)` 的痛点成本
```
cost_pain(e) = Σ_{(a,d)∈(A_i∩A_j)×𝔇_ρ} π(a,d)·(1-ρ_comp(a,d)) + λ·c_trans(A_i,A_j).
```
组合搜索最小化 `Σ cost_pain`。若路径的动作覆盖 `A(P)` 与 `E_floor` 相交、且该段未被认证，则必须把该段降级到 `T1/T2`（围栏承接），否则整条路径不可部署。

**定义 128（痛点-预算评测协议）**
`Π_PB=(D,B,E_floor,𝒮,Agg)` 输出 Pareto 曲线 `{(B_i, R_eff,i, Π(X_i))}`，并额外报告**灾难漏检率** `FN_cat=|{e∈E_floor: e∉X}|/|E_floor|` 与 `pain_coverage@B=Π(X(B))/Π(E)`。评测不允许只报平均成功率，必须同时给出 `(q,1-α)` 尾部分位与 `debt_eff`。

## 2. 关键算法 伪代码

### IP-121 PPA（Pain-Point Atlas）

```python
def build_pain_atlas(failure_logs, task_dist, sev_norm, probe_cost):
    pain = {}
    for e in enumerate_events(failure_logs):
        f = smoothed_failure_rate(failure_logs, e)   # 去零频、按上下文分层平滑
        pain[e] = f * sev_norm(e)
    E_floor = {e for e in pain if sev_norm(e) >= SEV_CRIT}
    return PainAtlas(pain, cost=probe_cost, E_floor=E_floor)
```

### IP-122 BCA（Budgeted Certification Allocation）

```python
def budgeted_certify(atlas, B, rho_cert):
    X = set(atlas.E_floor)                      # 地板先锁死，不可交易
    spent = sum(atlas.cost[e] for e in X)
    if spent > B:
        return ('infeasible', 'floor_exceeds_budget', X)
    rem = B - spent
    cand = [e for e in atlas.E if e not in X]
    while cand:
        e = max(cand, key=lambda x: atlas.pain[x]*rho_cert[x]/atlas.cost[x])
        if atlas.cost[e] > rem:
            cand.remove(e); continue
        X.add(e); rem -= atlas.cost[e]; cand.remove(e)
        if rem <= 0:
            break
    return ('ok', X, rem)                       # 次模时用 lazy greedy 保 (1-1/e)
```

### IP-123 ALC（Anytime Low-cost Certificate）

```python
def anytime_certificate(atlas, budget_levels, rho_cert, p_cont, R_intrinsic):
    trace = []
    prev_debt = float('inf')
    for B in budget_levels:
        status, X, rem = budgeted_certify(atlas, B, rho_cert)
        if status != 'ok':
            trace.append((B, 'infeasible', None)); continue
        debt = sum(atlas.pain[e] for e in atlas.E - X)
        debt_eff = debt + (1-p_cont)*R_intrinsic
        assert debt <= prev_debt + 1e-12          # 单调性自检
        prev_debt = debt
        trace.append((B, X, debt, debt_eff, rem))
    return trace
```

### IP-124 TPT（Transfer Profile Transfer）

```python
def transfer_profile(S, library, phi, eps_max, calib_pts):
    S_src = min(library, key=lambda s: dist(phi(S), phi(s)))
    if dist(phi(S), phi(S_src)) > eps_max:
        return full_scan(S)                       # 迁移不可信，回退全扫
    alpha_hat = dict(S_src.alpha)
    for a in calib_pts:
        alpha_hat[a] = query(S, a)                # 少量校准点修正偏差
    eps_tr = estimate_sup_error(alpha_hat, S, calib_pts)
    if eps_tr > eps_max:
        return full_scan(S)
    u_tr = eps_tr + KAPPA * dist(phi(S), phi(S_src))
    return alpha_hat, u_tr
```

### IP-125 TDR（Tiered Deployment with guardrail）

```python
def choose_tier(cert, atlas, guardrail, p_cont, V, L, L_max, delta):
    for tau in ('T0', 'T1', 'T2'):
        if not atlas.E_floor <= cert.X:            # 灾难地板硬闸门
            continue
        R = residual_risk(cert.X, atlas)
        R_eff = (1-p_cont[tau])*R + p_cont[tau]*R_fallback(tau)
        U = (1-R_eff)*V - R_eff*L - cost_cert(cert, tau) - cost_ops(tau)
        if U >= 0 and tail_ok(R_eff, L_max, delta):
            return (tau, R_eff, U)
    return ('abstain', 'residual_risk_too_high')
```

### IP-126 PCG（Pain-aware Composition Graph）

```python
def pain_aware_composition(G, atlas, T, cert, lam=1.0):
    Gp = G.copy()
    for (i, j) in G.edges:
        overlap = G[i][j]['A_overlap']
        Gp[i][j]['cost_pain'] = (
            sum(atlas.pain[(a, d)] * (1 - G[i][j]['rho_comp'][d])
                for a in overlap for d in DIMS)
            + lam * G[i][j]['cost'])
        Gp[i][j]['floor_cross'] = crosses_floor(overlap, atlas.E_floor, cert.X)
    path = a_star(Gp, start='root', goal=T, weight='cost_pain')
    if any(Gp[u][v]['floor_cross'] for u, v in path_edges(path)):
        return ('degrade', path, 'T1/T2')          # 需运行时围栏承接
    return ('ok', path)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| PPA | O(|E_log|) | O(|E|) | 频率平滑无偏、严重度归一一致 |
| BCA | O(|E| log |E|)（lazy greedy） | O(|E|) | 地板硬约束、次模收益 (1-1/e) |
| ALC | O(K·|E| log |E|) | O(K·|E|) | 债务单调不增、自检门 |
| TPT | O(|S_lib|·m + |A_calib|) | O(|A|) | ε_tr 准入门、校准集覆核 |
| TDR | O(|Φ|) 运行时 | O(|G|) | p_cont 置信下界、τ_trip 预算 |
| PCG | O(|E_G|·|A_overlap|·|𝔇_ρ|) | O(|E_G|) | 痛点权重非负、地板穿越可检 |

**正确性定理（Pain-Budgeted Deployment Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 痛点估计有界误差 `||π̂-π||_1≤ε_π`；**(A30)** 灾难地板被强制认证 `E_floor⊆X`；**(A31)** 承接概率有置信下界且 `τ_trip<τ_safe`。
则
```
P(catastrophic) ≤ FN_cat·ε_π + (1-p_cont(τ))·R_intrinsic + β_E,
P(success)      ≥ 1 - debt_eff - β_E - P(δ_a>Θ_a) - ε_π,
```
其中 `FN_cat` 为未认证灾难事件占比。由 (A30) 直接得 `FN_cat|_{E_floor}=0`，因此**灾难泄漏只能来自非地板的痛点估计误差与围栏失效**，而不会被预算优化器通过「砍地板」放大。

**命题（预算单调性与近似比）** `debt(B)` 关于 `B` 单调不增；当认证收益对事件子集次模时，lazy greedy 取得 `Π(X) ≥ (1-1/e)·OPT`。注意近似比只作用于**弹性痛点质量**，不作用于灾难地板——地板是约束，不是目标项。

## 6. 本轮最大风险

**一句话**：痛点加权 + 预算取证把证书从「全量证明」改造成「按钱买风险削减」，但它的 soundness **同时依赖痛点图的尾部准确性与运行时围栏的承接概率**；一旦 `π̂` 系统性地低估某个低频致命模式，优化器会精准地把预算搬离恰恰最该测的尾巴，而 anytime 证书仍会显示「债务合规」，形成**合规的假安全**，故必须以 **不可交易的灾难地板 + 痛点误差上界 ε_π + 围栏承接置信下界** 三重护栏，宁可 abstain，也绝不把「账面债务低」当成「真实风险低」。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（PPA×BCA×ALC×TPT×TDR×PCG）

> 承接第 54 轮产物 v31。本轮不增加「更强的证明」，而是给整套证书体系补上 **部署经济学**：用痛点图决定测什么，用预算约束决定测多少，用剖面迁移与运行时围栏把测不起的部分低成本兜住，并把剩余风险显式记账。
>
> - **PPA（Pain-Point Atlas）**：失败频率 × 严重度的痛点图，定义不可交易的灾难地板 `E_floor`；
> - **BCA（Budgeted Certification Allocation）**：带硬地板的预算取证，按单位成本痛点质量贪心；
> - **ALC（Anytime Low-cost Certificate）**：认证债可见、单调、有上限的 anytime 证书；
> - **TPT（Transfer Profile Transfer）**：技能剖面迁移 + 迁移不确定性，用相似性换采样；
> - **TDR（Tiered Deployment with guardrail）**：T0/T1/T2 分层部署，运行时围栏承接残余风险；
> - **PCG（Pain-aware Composition Graph）**：痛点加权组合 + 地板穿越检测与降级。
>
> IP 编号：IP-121~IP-126（共 6 个新增）。升级 IP-115/116/117/118，使其输出同时携带 `debt`、`tier`、`p_cont`、`u_tr`。

## 2. 关键算法 伪代码

### IP-121 PPA

```python
def build_pain_atlas(failure_logs, task_dist, sev_norm, probe_cost):
    pain = {}
    for e in enumerate_events(failure_logs):
        f = smoothed_failure_rate(failure_logs, e)
        pain[e] = f * sev_norm(e)
    E_floor = {e for e in pain if sev_norm(e) >= SEV_CRIT}
    return PainAtlas(pain, cost=probe_cost, E_floor=E_floor)
```

### IP-122 BCA

```python
def budgeted_certify(atlas, B, rho_cert):
    X = set(atlas.E_floor)
    spent = sum(atlas.cost[e] for e in X)
    if spent > B:
        return ('infeasible', 'floor_exceeds_budget', X)
    rem = B - spent
    cand = [e for e in atlas.E if e not in X]
    while cand:
        e = max(cand, key=lambda x: atlas.pain[x]*rho_cert[x]/atlas.cost[x])
        if atlas.cost[e] > rem:
            cand.remove(e); continue
        X.add(e); rem -= atlas.cost[e]; cand.remove(e)
        if rem <= 0:
            break
    return ('ok', X, rem)
```

### IP-123 ALC

```python
def anytime_certificate(atlas, budget_levels, rho_cert, p_cont, R_intrinsic):
    trace, prev_debt = [], float('inf')
    for B in budget_levels:
        status, X, rem = budgeted_certify(atlas, B, rho_cert)
        if status != 'ok':
            trace.append((B, 'infeasible', None)); continue
        debt = sum(atlas.pain[e] for e in atlas.E - X)
        debt_eff = debt + (1 - p_cont)*R_intrinsic
        assert debt <= prev_debt + 1e-12
        prev_debt = debt
        trace.append((B, X, debt, debt_eff, rem))
    return trace
```

### IP-124 TPT

```python
def transfer_profile(S, library, phi, eps_max, calib_pts):
    S_src = min(library, key=lambda s: dist(phi(S), phi(s)))
    if dist(phi(S), phi(S_src)) > eps_max:
        return full_scan(S)
    alpha_hat = dict(S_src.alpha)
    for a in calib_pts:
        alpha_hat[a] = query(S, a)
    eps_tr = estimate_sup_error(alpha_hat, S, calib_pts)
    if eps_tr > eps_max:
        return full_scan(S)
    u_tr = eps_tr + KAPPA * dist(phi(S), phi(S_src))
    return alpha_hat, u_tr
```

### IP-125 TDR

```python
def choose_tier(cert, atlas, guardrail, p_cont, V, L, L_max, delta):
    for tau in ('T0', 'T1', 'T2'):
        if not atlas.E_floor <= cert.X:
            continue
        R = residual_risk(cert.X, atlas)
        R_eff = (1 - p_cont[tau])*R + p_cont[tau]*R_fallback(tau)
        U = (1 - R_eff)*V - R_eff*L - cost_cert(cert, tau) - cost_ops(tau)
        if U >= 0 and tail_ok(R_eff, L_max, delta):
            return (tau, R_eff, U)
    return ('abstain', 'residual_risk_too_high')
```

### IP-126 PCG

```python
def pain_aware_composition(G, atlas, T, cert, lam=1.0):
    Gp = G.copy()
    for (i, j) in G.edges:
        overlap = G[i][j]['A_overlap']
        Gp[i][j]['cost_pain'] = (
            sum(atlas.pain[(a, d)] * (1 - G[i][j]['rho_comp'][d])
                for a in overlap for d in DIMS)
            + lam * G[i][j]['cost'])
        Gp[i][j]['floor_cross'] = crosses_floor(overlap, atlas.E_floor, cert.X)
    path = a_star(Gp, start='root', goal=T, weight='cost_pain')
    if any(Gp[u][v]['floor_cross'] for u, v in path_edges(path)):
        return ('degrade', path, 'T1/T2')
    return ('ok', path)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PPA | O(|E_log|) | O(|E|) | 频率平滑、严重度归一一致 |
| BCA | O(|E| log |E|) | O(|E|) | 地板硬约束、次模 (1-1/e) |
| ALC | O(K·|E| log |E|) | O(K·|E|) | 债务单调不增、自检门 |
| TPT | O(|S_lib|·m + |A_calib|) | O(|A|) | ε_tr 准入门、失败全扫 |
| TDR | O(|Φ|) 运行时 | O(|G|) | p_cont 置信下界、τ_trip 预算 |
| PCG | O(|E_G|·|A_overlap|·|𝔇_ρ|) | O(|E_G|) | 权重非负、地板穿越可检 |

**正确性定理（Pain-Budgeted Deployment Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** `||π̂-π||_1≤ε_π`；**(A30)** `E_floor⊆X`；**(A31)** 承接概率有置信下界且 `τ_trip<τ_safe`。则
```
P(catastrophic) ≤ FN_cat·ε_π + (1-p_cont(τ))·R_intrinsic + β_E,
P(success)      ≥ 1 - debt_eff - β_E - P(δ_a>Θ_a) - ε_π.
```
由 (A30) 得 `FN_cat|_{E_floor}=0`：灾难泄漏只来自非地板痛点误差与围栏失效，预算优化器无法通过剪掉地板来「伪造」安全。

**命题（单调性与近似比）** `debt(B)` 单调不增；认证收益次模时 lazy greedy `Π(X)≥(1-1/e)OPT`。近似比只覆盖弹性痛点质量，不覆盖灾难地板。

**解析微算例（假设分布，非实测，用于量级说明）**
设 `|E|=10,000`，其中 5% 热点事件承载 80% 痛点质量，灾难地板 30 项承载 15% 痛点；总预算 `B=2,000` 成本单位（总成本的 20%）。
- 均匀评测：约覆盖 20% 痛点，`debt≈0.80`；
- 痛点+地板贪心：先用 30 单位锁死地板，再用其余预算命中全部热点，累计覆盖约 92% 痛点，`debt≈0.08`；
- 若要求均匀方案也达到 `debt≤0.08`，需约 9,200 单位，成本约为贪心的 4.6 倍（≈78% 降本）。
- 两边 `FN_cat|_{E_floor}=0`，差异只在非地板尾部。该算例仅说明量级，真实比率需 E163 校准。

## 5. 本轮最大风险

**一句话**：痛点加权 + 预算取证把证书从「全量证明」改造成「按钱买风险削减」，但它的 soundness **同时依赖痛点图的尾部准确性与运行时围栏的承接概率**；一旦 `π̂` 系统性地低估某个低频致命模式，优化器会精准地把预算搬离恰恰最该测的尾巴，而 anytime 证书仍会显示「债务合规」，形成**合规的假安全**，故必须以 **不可交易的灾难地板 + 痛点误差上界 ε_π + 围栏承接置信下界** 三重护栏，宁可 abstain，也绝不把「账面债务低」当成「真实风险低」。
