# 第 69 轮（承接第 68 轮「CALM-RAS 自标定风险自适应闭环」IP-243~252；灵感循环第 2 轮；本轮灵感：「触觉感知」×「对比实验」）

> 第 68 轮把「标定」升级为在线潜变量，靠的是**被动观测 + 频率分离**：慢漂移被 COF 吸收，快故障靠 ω_f ≥ 3ω_cal 的残余被检出。它的自陈风险恰好击中了这条范式的死穴：**若真实故障落在标定带宽之内（渐进老化、慢泄漏、缓慢松动），COF 会把它「标好」，CFA 推高 H_cal，系统在「测量越来越准」的假象中失去最后一道检出能力。** 这是结构性缺陷，不是调参问题——只要仍用「时间尺度」区分漂移与故障，慢故障就永远隐身。
>
> 本轮的两个灵感给出了**换维度**的出路：
>
> - 「触觉感知」：触觉是唯一能**物理接触、主动施加已知激励**的通道。它测的不是外部世界的一次成像，而是接触**传递函数**（刚度 k、阻尼 b、摩擦 μ、几何）。标定漂移是测量模型上的偏置/外参变换（参数 c），慢故障是物理属性漂移（参数 κ）——**漂移在标定流形内，故障在流形外**，这是与频率无关的结构可分性。
> - 「对比实验」：区分「仪器偏了」与「世界变了」，科学上靠受控对照——固定其它因素、只动一个因子，做配对实验，让共模漂移在差分中抵消；再把它升级为**主动实验设计**，选使 H_cal 与 H_fault 预测分布差异最大的探针动作，用最小扰动换最大可辨识性。
>
> 核心命题：
>
> **把「标定 vs 故障」的判别从被动频域分离，升级为主动触觉对照实验 + 流形外残差累积——TACT-RAS（Tactile-Active Comparative Testing RAS）。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我能不能做一个实验，把『仪器歪了』和『世界坏了』分开**」——用干预换可辨识性，用对照抵消共模，用安全包络约束干预。

## 0. 直觉与动机

**灵感 1（触觉感知 → 从「被动观测」到「主动系统辨识」）**
直觉：视觉、力传感都是被动接收，漂移与故障会混在同一个残差里；触觉可以主动去碰。主动碰一个**已知参照**（自接触基座、标定工装、已知质量/刚度块）就建立了绝对溯源链，直接破解 R68 的「标定红线悖论」（红线参数本身也需溯源）。碰一个未知物体时，收回的是「力—位移—时间」响应曲线，可辨识 k、b、μ、接触几何——这些是**物理属性 κ**，不是测量偏置 c。关键区分：
- 标定漂移 c：改变的是「同一物理量被读成多少」（零偏、外参、焦距、时延），是可加的、坐标性的、位于标定流形 M_cal 内；
- 慢故障 κ：改变的是「物理系统本身的响应」（接触变软/变硬、摩擦变大、结构松动、慢性泄漏），是乘性/结构性的，**离开 M_cal**。
因此慢故障即使再慢，只要 κ 的漂移向量有流形外分量，就会被结构性地识别——**不看频率看方向**。

**灵感 2（对比实验 → 配对差分与主动实验设计）**
直觉：单次测量永远说不清「是仪器偏了还是世界变了」；但配对对照可以。对同一对象做 A/A′ 两次探针（推出 vs 拉回、加载 vs 卸载、两个已知参照点、正反两个方向），若两次之间只有「待检验因子」不同，则共同的标定漂移 c 在差分 Δy = y(A) − y(A′) 中一阶抵消，剩下的只有 κ 变化与配对误差。把「对哪个动作做对照」交给最优实验设计（OED）：选使两假设预测分布 KL 最大、或 Fisher 信息 det 最大的安全探针 a*——**这就是把科学实验的「控制变量法」变成闭环里的一次动作选择**。进一步的「反事实对照」：同一探针下 H_cal 预测「响应形状不变、仅读数平移」，H_fault 预测「响应形状改变」，一次探针即可分开两类假设。

**灵感 3（合流 → TACT-RAS 六组件）**
1. **TPG Tactile Probe Generator**：在安全动作集内用 OED 生成主动探针（压/点/滑/抓 + 配对方向），目标是最大化 κ 与 c 的可辨识性；
2. **CEB Comparative Experiment Buffer**：配对/孪生对照实验的缓冲与差分器，输出共模抵消后的 Δy，附带配对可交换性检验；
3. **OMD On-Manifold Decomposition**：把残差投影到标定流形切空间，拆成 r_on（可被 c 解释）与 r_off（流形外，故障证据）；
4. **SFA Slow-Fault Accumulator**：对 r_off 做长时程 GLR/CUSUM 序贯累积——慢故障不靠高频，靠方向一致性随 √T 累积；
5. **TID Tactile Identifiability Discriminator**：融合 OMD、CEB、SFA 与力/几何证据，输出 H_cal / H_fault^slow / H_fault^fast / H_env 的后验；
6. **PSE Probe Safety Envelope + CAC†**：探针力/速度/能量/接触对象白名单的硬包络；CAC 增加「慢故障 canary」与「对照可复现性」两关。
继承核：CALM-RAS†（MTM/SSG/COF/CFA/CAC/RAS-WM†）全部保留，TACT 只在其上增加一个**慢监督实验层**，实时控制回路完全不动。

**灵感 4（对 R68 风险的对症下药）**
- R68「慢故障被标定吸收」：新增流形外分解 + SFA。标定只能解释 r_on；r_off 不被吸收，且在慢故障下方向一致、随 T 累积 → 检出概率随时长上升，**不受 ω_cal 限制**（引理 16）。
- R68「标定红线悖论」：主动碰已知参照建立绝对溯源，红线参数由物理参照标定而非自证（定义 295）。
- R68「canary 只覆盖快故障」：CAC† 增加慢退化 canary 与配对可复现性关，坏适配器不能靠「把慢故障标定掉」通过（定理 17）。
- 探针本身的风险：PSE 硬包络 + 无探针回退（退化为 CALM-RAS，R68 全部保证仍在），且探针只在低风险窗口触发（定义 302）。

## 1. 形式化定义（增量：定义 293–307）

**定义 293（TACT-RAS 总览与四不变式）** TACT-RAS = (CALM-RAS†, TPG, CEB, OMD, SFA, TID, PSE, CAC†)。在 R68 三不变式之上新增：
(i) **探针安全包络**：任何主动探针必须满足 F ≤ F_max、v ≤ v_max、接触对象 ∈ 白名单、单次能量 ≤ E_max；越界即中止；
(ii) **探针预算与低风险窗口**：探针仅在 σ_risk(t) < τ_probe 且远离人/不可逆对象时触发，预算 ≤ B_probe（默认 20 次/h、占空比 < 2%）；
(iii) **无探针回退**：探针禁用/失败/预算耗尽时，系统完全退化为 CALM-RAS，风险保证不回退；
(iv) **实时流不变**：实时控制回路仍只做 MTM 前向 + COF 滤波；TACT 是 0.1–1 Hz 的慢监督层，不进入 2.6ms 预算。

**定义 294（触觉接触观测模型与结构拆分）** 接触观测 y_t = h(q_t; c, κ) + n_t，其中 q_t 为探针位姿/速度/加载轨迹，c ∈ ℝ^{12} 为 R68 标定潜变量，κ ∈ ℝ^{d_κ} 为物理接触参数（k、b、μ、接触几何、结构预紧力等）。关键结构假设 A95：**标定漂移只改变 c，慢故障只改变 κ**；二者作用在测量模型的不同参数上。

**定义 295（标定流形与流形内外分解）** 标定流形 M_cal = {h(·; c, κ₀) : c ∈ 𝒞}。在名义点 c₀ 处的切空间 T_c = span{∂h/∂c_i}。残差分解：
r = r_on + r_off，r_on = P_c r，r_off = (I − P_c) r，
其中 P_c 为到 T_c 的正交投影。**语义：r_on 是可被标定解释的部分（漂移），r_off 是标定无论如何都解释不了的部分（故障证据）。** 已知参照探针（碰基座/工装/已知质量块）提供绝对锚点，使 c₀ 本身可溯源，缓解标定红线悖论。

**定义 296（漂移—故障结构可分角）** 定义故障参数漂移方向 u_κ = Δκ/‖Δκ‖ 与标定流形的夹角 θ = arccos(‖P_c J_κ u_κ‖ / ‖J_κ u_κ‖)，J_κ = ∂h/∂κ。则流形外分量 ≥ sin θ · ‖J_κ Δκ‖。**θ 越大，慢故障越不可被标定吸收；θ = 0 是退化场景（故障恰好只改变一个可被 c 重参数化的自由度），此时退回 R68 频域防线并显式标记为不可辨识区。**

**定义 297（探针动作集与安全包络 PSE）** a_probe ∈ 𝒜_probe（压入深度、法向力、滑动速度、方向、持续时间、配对方式）。安全包络：
𝒜_safe = {a : F_n ≤ F_max(m̂), v ≤ v_max, E ≤ E_max, obj ∈ Whitelist, d_human > d_min}。
F_max 随物体脆弱度估计 m̂（视觉/触觉刚度在线估计）自适应收缩；**包络外动作在生成阶段即被裁剪，不存在「先生成后限幅」的越界路径。**

**定义 298（配对对照实验与可交换性）** 对照对 (a, a′) ∈ 𝒜_safe² 满足：除待检验因子外其余条件相同（同一对象、同一位姿邻域、相近时刻）。差分观测：
Δy = y(a) − y(a′) = [h(q; c, κ) − h(q′; c, κ)] + 配对误差。
一阶上 c 抵消（引理 17）。**A96（配对可交换性）**：两次探针之间环境状态与 c 的变化量 ‖Δc‖、‖Δenv‖ 有界。可交换性由 CEB 在线检验（前后静态段一致性 + 位姿回归残差），违反则标记 Δy 不可用并回退到单次探针。

**定义 299（OED 主动探针选择）** 给定候选对 𝒜_safe²，选
a* = argmax_{a} I(κ; y | a) ≈ argmax_{a} (1/2) log det(I + J_κᵀ Σ_n^{-1} J_κ)（D-最优），或等价的 KL(H_cal ‖ H_fault | a)。
约束：F、E、时长、与当前任务的动作冲突最小。**主动实验的含义：不等待自然出现的静态段，而是主动制造一个「两类假设预测不同」的实验。**

**定义 300（慢故障累积器 SFA）** 对流形外残差序列 {r_off,t}，构造 GLR/CUSUM：
g_t = max(0, g_{t−1} + (‖r_off,t‖² − ν)/σ_off²)，报警当 g_t > h_g。
零假设 H0：r_off 为噪声（ν 为其期望）；备择 H1：存在持续流形外偏移。**慢故障的偏移虽小，但方向一致，g_t 的漂移项随时间线性累积，检出时延 T* ∝ σ²/(Δ_off²)。**

**定义 301（TID 触觉可辨识判别器）** 先验为 R68 的 P(H,E)，假设集扩展为 {H_cal, H_fault^slow, H_fault^fast, H_env}。似然融合三源证据：
P(H | r_off, Δy, g_t, θ) ∝ P(H) · p(r_off | H, θ) · p(Δy | H) · p(g_t | H)。
- H_cal：要求 r_off ≈ 0 且 Δy 的响应形状不变（仅平移）；
- H_fault^slow：r_off 持续、Δκ 方向稳定、Δy 响应形状改变（k/b/μ 变化）；
- H_fault^fast：高频大残差，沿用 R68 引理 13；
- H_env：配对可交换性检验失败或外部场景变化（防止把环境漂移误判为故障）。
U_cal 高或 θ 近 0（不可辨识）时，TID 输出「不可辨识」并强制最坏情况处置（λ ≥ 0.8、k 收缩），禁止默认归 cal。

**定义 302（探针调度器）** 触发条件：TID 后验熵 > h_H，或 SFA 统计量进入灰区，或上线新适配器前的强制对照。抑制条件：σ_risk 高、人近、对象脆弱、任务不可中断、预算耗尽。**调度器的目标函数含风险项：只有在「期望信息增益 / 引入风险」比超过阈值时才探。**

**定义 303（CAC† 认证提交，六关）** 在 R68 五关基础上新增：**慢故障 canary 关**——注入 κ 以 ε 缓慢漂移的 canary，若适配器/标定头把它吸收（r_off 被压到阈值下且 Δy 判为形状不变），一票否决；并把「对照可复现性」并入金标回归关：同一 canary 在配对探针下两次结果须一致。

**定义 304（TACT 干扰集）** ℰ_TACT = ℰ_CALM × ℰ_probe × ℰ_pair，其中 ℰ_probe = {探针致损、探针过度扰动、探针被故障规避}，ℰ_pair = {可交换性违反、配对选择偏差、环境漂移混淆}。

**定义 305（J_TACT 证书）** J_TACT = (J_CALM, probe_log, off_manifold_residual, θ_hat, g_t, probe_safety_record, comparative_reproducibility, tact_ver)。Valid ⇔ Valid(J_CALM) ∧ 无包络越界 ∧ (θ > θ_min 或已判不可辨识并保守处置) ∧ 对照可复现性通过。

**定义 306（管线）** 离线：在仿真 + 真机触觉数据上辨识 h(·; c, κ)，标定 T_c 与 θ 分布，训练 TID 与 OED 代理。在线：CALM 实时回路不变；慢监督层每 0.5–10 s 评估触发条件 → 生成安全对照探针 → OMD/SFA/TID 更新 → 证据回灌 CFA/风险缩放 → CAC† 周期性认证。

**定义 307（对照效度与干预语义）** 探针是对系统的干预 do(a)，非单纯观测。TACT 的因果假设：A96（配对可交换）+ A97（探针不改变 κ 本身，仅在弹性/可逆范围内加载）+ A98（持久激励：探针方向集合张成 κ 的可辨识子空间）。**任一假设违反时，TID 必须降级为「不可辨识」而非强行归因。**

```python
# IP-253/254 TPG+CEB：OED 生成配对探针，差分抵消共模标定
class TactileProbeGenerator:
    def __init__(self, model_h, c0, Asafe, budget):
        self.h, self.c0, self.Asafe, self.budget = model_h, c0, Asafe, budget

    def propose_pair(self, ctx, kappa_hat):
        cands = self.pair_candidates(ctx)                 # (a, a') 配对候选
        best = max(cands, key=lambda p: self.oed_info(p, kappa_hat))
        if self.risk(p=best, ctx) * best.cost > self.budget.info_ratio:
            return None                                   # 不值当 → 不探
        return best

    def oed_info(self, pair, kappa_hat):                  # D-最优 / KL 散度
        Jk = self.h.jacobian_kappa(pair, self.c0, kappa_hat)
        return 0.5 * np.log(np.linalg.det(np.eye(len(Jk)) + Jk.T @ Jk / SIGMA2))

    def risk(self, p, ctx):
        return ctx.risk * p.perturbation + ctx.fragility * p.F_peak


class ComparativeExperimentBuffer:
    def run(self, pair, robot):
        if not self.safe(pair): return None               # PSE 硬包络
        y1 = robot.probe(pair.a)
        y2 = robot.probe(pair.a_prime)
        dy = y1 - y2                                      # c 一阶抵消
        if not self.exchangeability_ok(y1, y2):           # A96 检验
            return {'dy': None, 'unusable': True}
        return {'dy': dy, 'shape_change': shape_distance(y1, y2)}


# IP-255 OMD：残差流形内外分解
def on_manifold_decompose(r, c, model_h, eps=1e-6):
    Jc = model_h.jacobian_c(c)                             # ∂h/∂c
    Pc = Jc @ np.linalg.pinv(Jc)                           # 到 T_c 的投影
    r_on, r_off = Pc @ r, (np.eye(len(r)) - Pc) @ r
    theta = np.arccos(np.clip(np.linalg.norm(Pc @ model_h.jacobian_kappa(c) @ U_DIR)
                              / (np.linalg.norm(model_h.jacobian_kappa(c) @ U_DIR) + eps),
                              -1, 1))
    return r_on, r_off, theta


# IP-257 SFA：慢故障 GLR/CUSUM 累积
class SlowFaultAccumulator:
    def __init__(self, nu, sigma2, h_g):
        self.g, self.nu, self.s2, self.h_g = 0.0, nu, sigma2, h_g

    def update(self, r_off):
        self.g = max(0.0, self.g + (np.sum(r_off**2) - self.nu) / self.s2)
        return self.g > self.h_g


# IP-256 TID：触觉可辨识判别器
def tactile_discriminator(r_off, dy, g, theta, U, prior):
    if theta < THETA_MIN or U > TAU_CAL:
        return {'post': worst_case(prior), 'identifiable': False}
    lik = {'H_cal':       gauss(r_off, 0, S_OFF) * shape_inv(dy),
           'H_fault_slow': cf(r_off, theta) * shape_change(dy) * cusum_lik(g),
           'H_fault_fast': fast_lik(r_off),
           'H_env':        0.0 if dy is None else env_lik(dy)}
    return {'post': normalize(mul(prior, lik)), 'identifiable': True}


# IP-258/259/262 主闭环：慢监督层（实时回路不变）
def TACT_slow_loop(M, obs):
    # 0) 实时回路照旧（CALM_RAS_round 不变，<2.6ms）
    k, lam, post, (c, U) = CALM_RAS_round(M, obs)
    if not M.probe_scheduler.due(post, M.ctx):            # 低风险 + 高信息才探
        return k, lam, post, (c, U)

    # 1) OED 生成配对探针 → 安全包络裁剪 → 对照执行
    pair = M.tpg.propose_pair(M.ctx, M.kappa_hat)
    if pair is None: return k, lam, post, (c, U)
    exp  = M.ceb.run(pair, M.robot)
    if exp is None or exp.get('unusable'): return k, lam, post, (c, U)

    # 2) 残差流形内外分解 + 慢故障累积
    r_on, r_off, theta = on_manifold_decompose(M.residual, c, M.h)
    alarm = M.sfa.update(r_off)

    # 3) TID 融合 → 回灌归因与风险缩放（只许更保守）
    tid = tactile_discriminator(r_off, exp['dy'], M.sfa.g, theta, U, post)
    if not tid['identifiable']:
        M.efs.force_conservative(); k = min(k, k_cal_shrink(M.ctx, np.inf))
    post = fuse(post, tid['post'])
    lam  = max(lam, 0.8 if (alarm or tid['post'].get('H_fault_slow', 0) > 0.5) else 0.6)

    # 4) 证据入审计缓冲；CAC† 周期认证（含慢故障 canary）
    M.audit_buf.push({'probe': pair.id, 'r_off': r_off, 'theta': theta,
                      'g': M.sfa.g, 'tid': tid})
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)
    return k, lam, post, (c, U)
```

## 3. 推导

**引理 16（慢故障流形外可检出——对 R68 风险的正面反驳）** 设慢故障使 κ 以速率 ε 漂移，J_κ u_κ 的流形外分量 ≥ sin θ·‖J_κ‖ε。则 r_off(t) 的期望沿固定方向线性增长，SFA 漂移项 ≈ (sin θ·‖J_κ‖ε)²/σ_off² 每步，累积到阈值 h_g 的时延
T* ≈ h_g·σ_off² / (sin²θ·‖J_κ‖²ε²)。
**关键：T* 与 ω_cal 无关**——检出只依赖流形外分量的大小与方向的持续性，而不依赖故障频率。只要 sin θ 有正下界，再慢的故障最终都会穿过阈值；而 R68 的频域防线在 ω_f < ω_cal 时检出时延为 ∞。系：**这恰是 R68 最大风险的补丁——慢故障不再被「吸收」，而是被「积攒」。**

**引理 17（配对差分共模抵消）** 在 A96 下，同一对象同一 c 的配对观测差分 Δy = [h(q;c,κ) − h(q′;c,κ)] + n_Δ。对 c 在 c₀ 处一阶展开，∂h/∂c 项因 q 与 q′ 共享同一 c 而相消；残余为 O(‖Δc‖·‖q − q′‖) 的二阶项加配对误差。故 **Δy 是 c-无关的 κ 观测量**，其信噪比高于直接残差，且偏置不随温漂缓慢移动。系：对照实验把「绝对测量」问题转成「差分测量」问题，这是计量学中消除系统误差的标准手段。

**引理 18（主动探针的持久激励与可辨识性）** Fisher 信息 J(a) = J_κ(a)ᵀ Σ_n^{-1} J_κ(a)。若探针方向集合 D = {a_1,…,a_P} 使 Σ_p J_κ(a_p)ᵀ Σ_n^{-1} J_κ(a_p) 满秩（A98），则 κ 在该子空间内可辨识，且 log det 随独立探针模式数 P 线性增长。被动观测只提供环境自然激励的方向，通常秩亏；**主动 OED 通过选择方向补齐秩，这是「干预」相对「观测」的本质增益**。

**定理 16（TACT 端到端风险一致性）** 在 A87–A98 下：
1. 输出 τ_cmd 的误差界在 R68 定理 14 基础上增加 α_probe（探针扰动引入）与 α_tact（TID 误判），且 **α_probe ≤ P(PSE 越界) = 0**（包络在生成阶段硬裁剪）；
2. 当 sin θ ≥ s₀ > 0 且故障持续，P(慢故障被误归 H_cal) ≤ exp(−c·T·s₀²ε²/σ_off²) → 0（T 增），**R68 的慢故障吸收风险被消除**；
3. 当 θ < θ_min 或 U > τ_cal（不可辨识区），系统显式输出「不可辨识」并强制 λ ≥ 0.8、k 收缩，**绝不默认归 cal**；
4. 探针禁用/预算耗尽 ⇒ 行为退回 CALM-RAS，R68 全部保证原样成立（无探针回退）。
5. 慢故障检出概率随观测时长 T 单调上升，而误报率由 SFA 阈值 h_g 与配对可交换性检验共同控制。

**定理 17（探针安全与认证不可吸收）** PSE 保证单次探针的力/能量/接触对象在认证包络内，故探针引入的最坏额外风险有界且可预算（≤ B_probe·E_max 的期望损伤上界）。CAC† 的慢故障 canary 关使「通过把慢故障标定掉来通过认证」的适配器被一票否决：若适配器把 canary 的 r_off 压到阈值下且 Δy 判为形状不变，则违反「响应形状必须改变」的一致性，检出率 r_canary_slow ≥ 0.9。系：**认证不再只看「指标不降」，还看「是否以吸收故障的方式取得指标」。**

## 6. 本轮最大风险

**一句话**：TACT-RAS 用「主动干预」换取对慢故障的可辨识性，但主动探针会真实地扰动世界——**在脆弱、不可逆或人近的场景里，探针本身的力/能量可能造成伤害；而配对差分的安全性完全押在 A96「两次实验间环境可交换」上，一旦环境在配对之间变化（物体移动、光照/温度漂移、人的介入），差分会把环境变化误判为故障，或把真实故障误判为环境——即「用实验消灭了一类盲区，却引入了『实验效度』这个新的、更难在线验证的盲区」。**

**次级风险与缓解**：
1. **探针致损**：PSE 生成阶段硬裁剪 + 物体脆弱度自适应 F_max + 人近/不可逆场景 100% 抑制；
2. **可交换性违反**：CEB 在线检验 + 违反即标记 Δy 不可用并回退单探针 + TID 显式 H_env 假设；
3. **不可辨识区（θ≈0）**：显式输出「不可辨识」并强制最坏情况处置，禁止默认归 cal；
4. **触觉 Sim2Real 偏移**：流形/夹角估计带不确定度，θ 近阈值时保守化；
5. **探针被故障规避**：随机化探针方向 + 审计探针方向覆盖度（VQAuditor-T），覆盖不足即降级；
6. **探针成本/节拍**：预算约束 + OED 只在高信息增益时触发 + 无探针回退保持 CALM 全部保证。

```python
# IP-253/254 TPG+CEB：OED 配对探针 + 差分抵消共模标定
class TactileProbeGenerator:
    def propose_pair(self, ctx, kappa_hat):
        pair = max(self.pair_candidates(ctx), key=lambda p: self.oed_info(p, kappa_hat))
        if self.risk(pair, ctx) * pair.cost > self.budget.info_ratio: return None
        return pair                                   # 不值当就不探

    def oed_info(self, pair, kappa_hat):               # D-最优 / 最大 KL
        Jk = self.h.jacobian_kappa(pair, self.c0, kappa_hat)
        return 0.5*np.log(np.linalg.det(np.eye(len(Jk)) + Jk.T@Jk/SIGMA2))


class ComparativeExperimentBuffer:
    def run(self, pair, robot):
        if not self.safe(pair): return None            # PSE 硬包络
        y1, y2 = robot.probe(pair.a), robot.probe(pair.a_prime)
        if not self.exchangeability_ok(y1, y2):        # A96 检验
            return {'dy': None, 'unusable': True}
        return {'dy': y1 - y2, 'shape_change': shape_distance(y1, y2)}  # c 一阶抵消


# IP-255 OMD：残差流形内外分解 + 结构可分角
def on_manifold_decompose(r, c, model_h, u_dir):
    Jc = model_h.jacobian_c(c); Pc = Jc @ np.linalg.pinv(Jc)
    r_on, r_off = Pc @ r, (np.eye(len(r)) - Pc) @ r
    Jk = model_h.jacobian_kappa(c) @ u_dir
    theta = np.arccos(np.clip(np.linalg.norm(Pc @ Jk)/(np.linalg.norm(Jk)+1e-9), -1, 1))
    return r_on, r_off, theta


# IP-257 SFA：慢故障累积器
class SlowFaultAccumulator:
    def __init__(self, nu, s2, h_g): self.g, self.nu, self.s2, self.h_g = 0., nu, s2, h_g
    def update(self, r_off):
        self.g = max(0., self.g + (np.sum(r_off**2) - self.nu)/self.s2)
        return self.g > self.h_g

           'H_fault_fast': fast_lik(r_off),

    return {'post': normalize(mul(prior, lik)), 'identifiable': True}

    pair = M.tpg.propose_pair(M.ctx, M.kappa_hat)          # 1) OED 安全探针
    if pair is None: return k, lam, post, (c, U)
    exp = M.ceb.run(pair, M.robot)                         # 2) 配对对照
    if exp is None or exp.get('unusable'): return k, lam, post, (c, U)
    r_on, r_off, theta = on_manifold_decompose(M.residual, c, M.h, M.u_dir)  # 3) OMD
    alarm = M.sfa.update(r_off)                            #    慢故障累积
    tid = tactile_discriminator(r_off, exp['dy'], M.sfa.g, theta, U, post)   # 4) TID
    if not tid['identifiable']:
        M.efs.force_conservative(); k = min(k, k_cal_shrink(M.ctx, np.inf))
    post = fuse(post, tid['post'])
    lam  = max(lam, 0.8 if (alarm or tid['post'].get('H_fault_slow',0) > .5) else .6)
    M.audit_buf.push({'probe': pair.id, 'r_off': r_off, 'theta': theta,
                      'g': M.sfa.g, 'tid': tid})           # 5) 审计
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit) # 6) CAC† 认证
    return k, lam, post, (c, U)
```

## 4. 推导

**引理 16（慢故障流形外可检出——对 R68 风险的正面反驳）** 慢故障使 κ 以速率 ε 漂移，J_κu_κ 的流形外分量 ≥ sinθ·‖J_κ‖ε；r_off 沿固定方向线性增长，SFA 漂移项 ≈ (sinθ‖J_κ‖ε)²/σ_off² 每步，累积到 h_g 的时延 `T* ≈ h_g σ_off²/(sin²θ‖J_κ‖²ε²)`。**T* 与 ω_cal 无关**——只要 sinθ 有正下界，再慢的故障最终穿过阈值；R68 频域防线在 ω_f<ω_cal 时时延为 ∞。系：慢故障不再被「吸收」，而被「积攒」。

**引理 17（配对差分共模抵消）** A96 下 `Δy = [h(q;c,κ)−h(q′;c,κ)] + n_Δ`；对 c 一阶展开，∂h/∂c 项因 q、q′ 共享同一 c 相消，残余为 O(‖Δc‖‖q−q′‖) 二阶项。故 **Δy 是 c-无关的 κ 观测量**，把绝对测量问题转为差分测量问题。

**引理 18（主动探针持久激励）** Fisher 信息 `J(a)=J_κ(a)ᵀΣ_n^{-1}J_κ(a)`；若探针方向集使 Σ_p J(a_p) 满秩（A98），κ 可辨识且 logdet 随独立探针模式数线性增长。被动观测通常秩亏，主动 OED 补秩——这是「干预」相对「观测」的本质增益。

**定理 16（TACT 端到端风险一致性）** A87–A98 下：
1. R68 误差界加 α_probe、α_tact，且 α_probe = P(PSE 越界) = 0（生成阶段硬裁剪）；
2. `sinθ ≥ s₀>0` 且故障持续 ⇒ P(慢故障误归 H_cal) ≤ exp(−c·T·s₀²ε²/σ_off²) → 0，**R68 慢故障吸收风险被消除**；
3. `θ<θ_min 或 U>τ_cal` ⇒ 显式「不可辨识」并强制 λ≥0.8、k 收缩，绝不默认归 cal；
4. 探针禁用/预算耗尽 ⇒ 退回 CALM-RAS，R68 全部保证成立（无探针回退）；
5. 慢故障检出概率随 T 单调上升，误报由 SFA 阈值与可交换性检验共同控制。

**定理 17（探针安全与认证不可吸收）** PSE 使单次探针最坏额外风险有界且可预算（≤ B_probe·E_max 期望损伤上界）。CAC† 慢故障 canary 关使「靠把慢故障标定掉来通过认证」的适配器被一票否决：若它把 canary 的 r_off 压到阈值下且 Δy 判为形状不变，即违反「响应形状必须改变」，检出率 r_canary_slow ≥ 0.9。系：认证不只看「指标不降」，还看「是否以吸收故障的方式取得指标」。

## 7. 本轮最大风险

**一句话**：TACT-RAS 用「主动干预」换取慢故障可辨识性，但探针会真实扰动世界——**在脆弱/不可逆/人近场景中，探针的力与能量可能造成伤害；且配对差分的安全性完全押在 A96「两次实验间环境可交换」上，一旦环境在配对之间变化（物体移动、温/光漂移、人介入），差分会把环境变化误判为故障、或把真实故障误判为环境——即「消灭了一类盲区，却引入『实验效度』这个更难在线验证的新盲区」。**

**次级风险与缓解**：探针致损（PSE 生成阶段硬裁剪 + 脆弱度自适应 F_max + 人近/不可逆 100% 抑制）；可交换性违反（CEB 在线检验 + Δy 弃用回退 + H_env 假设）；不可辨识区 θ≈0（显式报警 + 最坏情况处置，禁止默认归 cal）；触觉 Sim2Real 偏移（θ 近阈值保守化）；探针被规避（随机化方向 + 覆盖度审计 VQAuditor-T）；探针成本（预算约束 + 仅高信息增益触发 + 无探针回退保持 CALM 全部保证）。
