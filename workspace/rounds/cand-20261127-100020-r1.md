### 第 1 轮灵感驱动研究记录

**灵感词**：位姿估计、云边协同

**直觉与动机**：

先给直觉。前几轮把证书链越堆越厚（结构、语义、重构、协同、成本、记忆、可扩展性），但它们共享一个从未被言明的前提：**位姿是可信的**。语义实体的 p_i、碰撞体 𝒞_i(t)、阻抗控制的末端位姿、结构载荷方向，全部以位姿为输入。位姿估计一旦漂移，或在退化几何（长廊、无纹理墙面、动态遮挡）中失锁，上层所有证书会「一致地错」——它们彼此自洽，却共同偏离真实世界。这正是证书体系最危险的失效模式：不是单证失效，而是**公共前提失效导致的系统性伪一致**。因此「位姿估计」不是又一个并列维度，而是证书链的**公共货币**：必须为位姿本身发证，并把位姿不确定性像汇率一样折算进每一张下游证书。

再给第二层直觉。「云边协同」提示证书的**分布式账本**属性：重标定（conformal 分位数、大模型、全局地图、全局优化）天然在云侧，实时推理与执行天然在边侧。云侧签发的证书到达边侧时已经「过期」，边侧观测又可能反驳云侧结论。若没有版本、时戳、不确定性与单调合并规则，云边之间就会出现「证书分叉」：云说安全、边说危险；或更糟——边侧消费了一张来自旧模型版本、却看似新鲜的证书。于是「云边协同」也不是通信优化问题，而是**证书的时间/版本可信性**问题。

核心洞见：**云侧负责「校准的可信」，边侧负责「推理的实时」；位姿证书把几何不确定性显式化，云边证书把时间与版本不确定性显式化，两者共同构成证书链的两个新地基。** 具体地说，split conformal 天然适配云边：云侧在标定集上算分位数（数据密集、可离线），边侧用分位数构造预测集（算力轻、可实时）；但「云标定分布」与「边部署分布」的 exchangeability 本身必须被发证，否则分位数迁移即失效。

**形式化目标**：

1. **位姿估计证书（PEC）**：ξ̂ ∈ SE(3) 附带四重保证——(a) conformal 覆盖 ℙ(ξ* ∈ C_pose(x)) ≥ 1-α；(b) 协方差上界 Σ_ξ ⪯ Σ_max；(c) 漂移界 d_SE3(ξ̂_t, ξ̂_{t-1}) ≤ v_max·Δt + ε_drift；(d) 可观测性裕度 κ(JᵀJ) ≤ κ_max ∧ λ_min(JᵀJ) ≥ λ_min。
2. **位姿鲁棒复合算子（PRCO）**：把 PEC 的半径 r_pose 折算进下游证书——碰撞膨胀 r_i += r_pose，语义一致性 ε_sem += 2r_pose，力控力上界按 1/(1+r_pose/L) 收缩；证明折算后下游证书相对**真实位姿**仍 sound。
3. **云边证书（CEC）**：记录 (payload, version, t_issue, t_expire, Σ_0, Q, sig)；边侧执行签名校验、版本兼容、时鲜性检查与陈旧性膨胀 Σ(t)=Σ_0+Q(t−t_issue)；定义单调保守合并 ⊔（预测集取交、协方差取大、过期取早）。
4. **云边 split conformal**：云侧在标定集上算 q_{1-α} 与版本哈希，边侧用 q 局部构造 C_pose；并用双样本覆盖审计证书检验云标定分布与边部署分布的 exchangeability。
5. **构建 PCU-USC 统一准入门**：Exec_v27 = Exec_v26 ∩ Fil_pose ∩ Fil_cloudedge ⊆ Exec_v26；证明位姿退化/漂移与云边分叉/版本偏移下的单调退化链保持性。

**与已有工作的接缝**：PEC 是 SMC/RMC/MCC 的**上游证书**而非并列证书；CEC 是 SRC-USC 的**传输层证书**而非任务层证书。二者把 v26 的「九条件」升级为「十一条件」，但不改变既有证书的语义，只改变它们被消费的方式（先折算不确定性，再判定）。

# ============================================================
# 基础：SE(3) 工具（Lie 群对数/测地距离）
# ============================================================
def se3_log(T: Tensor) -> Tensor:
    """SE(3) -> se(3) 切向量 [ω(3), ν(3)]，小角度近似 + 大角度处理。"""
    R, t = T[:3, :3], T[:3, 3]
    cos_theta = torch.clamp((torch.trace(R) - 1.0) / 2.0, -1.0, 1.0)
    theta = torch.acos(cos_theta)
    if theta.abs() < 1e-6:
        omega = 0.5 * torch.stack([R[2,1]-R[1,2], R[0,2]-R[2,0], R[1,0]-R[0,1]])
        V_inv = torch.eye(3)
    else:
        omega = (theta / (2.0 * torch.sin(theta))) * torch.stack(
            [R[2,1]-R[1,2], R[0,2]-R[2,0], R[1,0]-R[0,1]])
        V = (torch.eye(3) + (1-cos_theta)/theta**2 * skew(omega)
             + (theta-torch.sin(theta))/theta**3 * (skew(omega) @ skew(omega)))
        V_inv = torch.linalg.inv(V)
    nu = V_inv @ t
    return torch.cat([omega, nu])


def se3_distance(T1: Tensor, T2: Tensor, w_rot: float = 1.0,
                 w_trans: float = 1.0) -> float:
    """右不变测地距离：旋转弧长与平移误差的加权。"""
    phi = se3_log(torch.linalg.inv(T1) @ T2)
    return torch.sqrt(w_rot * torch.sum(phi[:3] ** 2)
                      + w_trans * torch.sum(phi[3:] ** 2)).item()

# IP-451 Pose Estimation Certificate (PEC) — 位姿估计证书

@dataclass
class PoseEstimationCertificate:
    """位姿估计器的四重证书：覆盖 / 协方差 / 漂移 / 可观测性"""
    xi_hat: Tensor                      # [4,4] 或 [6] 位姿估计
    cov: Tensor                         # [6,6] 切空间协方差
    radius: float                       # r_pose（认证不确定半径）
    alpha: float = 0.05                 # conformal 风险水平
    cal_version: str = None             # 云侧标定集版本哈希 v_cal
    sigma_max: Tensor = None            # [6,6] 协方差上界 Σ_max
    kappa_max: float = 50.0             # 可观测性条件数上界
    lambda_min: float = 1e-3            # 最小特征值下界
    v_max: float = 0.5                  # 漂移速度上界 (m/s 或 rad/s)
    eps_drift: float = 0.01             # 漂移松弛量
    xi_prev: Tensor = None              # 上一步位姿
    dt: float = 0.1                     # 步长

    # (a) conformal 覆盖：仅能在留出审计集上验证，运行时用 (b)(c)(d) 代理
    def audit_conformal_coverage(self, residuals: Tensor,
                                 calibrator: 'SplitConformalPoseCalibrator') -> bool:
        """审计：留出集上 ℙ(d_SE3(ξ*, ξ̂) ≤ q_{1-α}) ≥ 1-α。"""
        if calibrator is None or calibrator.version != self.cal_version:
            return False
        covered = (residuals <= calibrator.quantile).float().mean().item()
        return covered >= (1.0 - self.alpha)

    # (b) 协方差上界：Σ_ξ ⪯ Σ_max（Loewner 序）
    def verify_covariance_bound(self) -> bool:
        if self.sigma_max is None:
            return False
        diff = self.sigma_max - self.cov
        # 半正定检查（容许 1e-9 数值误差）
        return bool(torch.linalg.eigvalsh(diff).min().item() >= -1e-9)

    # (c) 漂移界：d_SE3(ξ̂_t, ξ̂_{t-1}) ≤ v_max·dt + ε_drift
    def verify_drift_bound(self) -> bool:
        if self.xi_prev is None:
            return True
        d = se3_distance(self.xi_prev, self.xi_hat)
        return d <= self.v_max * self.dt + self.eps_drift

    # (d) 可观测性：κ(JᵀJ) ≤ κ_max ∧ λ_min(JᵀJ) ≥ λ_min（退化检测）
    def verify_observability(self, J: Tensor) -> bool:
        H = J.T @ J
        eig = torch.linalg.eigvalsh(H)
        lam_min = eig.min().item()
        lam_max = eig.max().item()
        if lam_min <= 0:
            return False
        kappa = lam_max / lam_min
        return kappa <= self.kappa_max and lam_min >= self.lambda_min

    def runtime_guard(self, J: Tensor) -> bool:
        """运行时可用守卫（不依赖真值）：协方差 ∧ 漂移 ∧ 可观测性。"""
        return (self.verify_covariance_bound()
                and self.verify_drift_bound()
                and self.verify_observability(J))

    def verify_all(self, J: Tensor, residuals: Tensor = None,
                   calibrator: 'SplitConformalPoseCalibrator' = None) -> bool:
        ok = self.runtime_guard(J)
        if residuals is not None and calibrator is not None:
            ok = ok and self.audit_conformal_coverage(residuals, calibrator)
        return ok

@dataclass
class PoseRobustComposition:
    """把 PEC 的 r_pose 折算进下游证书，保证对真实位姿 sound"""
    pec: PoseEstimationCertificate

    def r(self) -> float:
        return self.pec.radius

    def inflate_collision(self, mcc: 'MultiRobotCoordinationCertificate') -> None:
        """碰撞：占用体膨胀 + r_pose（最坏情况位姿偏移）。"""
        r = self.r()
        for i in range(mcc.N):
            mcc.extra_inflation[i] = getattr(mcc, 'extra_inflation', {}).get(i, 0.0) + r

    def inflate_semantic(self, smc: 'SemanticMappingCertificate') -> None:
        """语义：ε_sem_eff = ε_sem + 2r_pose（估计-真值三角不等式）。"""
        smc.eps_sem_effective = smc.eps_sem + 2.0 * self.r()

    def inflate_force(self, fcc: 'ForceControlCertificate',
                      characteristic_length: float) -> None:
        """力控：末端位置误差 ≤ r_pose ⇒ 力上界收缩 1/(1+r/L)。"""
        r = self.r()
        fcc.F_max_effective = fcc.F_max / (1.0 + r / max(characteristic_length, 1e-6))

    def apply(self, mcc, smc, fcc, characteristic_length: float) -> None:
        self.inflate_collision(mcc)
        self.inflate_semantic(smc)
        self.inflate_force(fcc, characteristic_length)

# IP-453 Cloud-Edge Certificate Ledger (CEC) — 云边证书账本

@dataclass
class CertificateRecord:
    """版本化、时戳化、签名化的云边证书记录"""
    payload: dict                # 证书内容（如 conformal 分位数 / 全局地图摘要）
    version: str                 # 版本向量/哈希（内容寻址）
    t_issue: float               # 云侧签发时刻
    t_expire: float              # 有效期截止
    cov0: Tensor                 # [6,6] 签发时协方差
    Q: Tensor                    # [6,6] 过程噪声协方差密度
    signature: str               # 云侧私钥签名（对 payload+version+t_issue 摘要）

    def propagated_cov(self, t: float) -> Tensor:
        """陈旧性膨胀：Σ(t) = Σ₀ + Q·(t−t_issue)，截断到有效期。"""
        dt = max(0.0, min(t, self.t_expire) - self.t_issue)
        return self.cov0 + self.Q * dt

    def is_fresh(self, t: float, delta_stale: float) -> bool:
        """时鲜性：在有效期内，且年龄不超过 δ_stale。"""
        return (self.t_issue <= t <= self.t_expire) and (t - self.t_issue <= delta_stale)


class CloudEdgeCertificateLedger:
    """边侧验证 + 单调保守合并 + 版本分叉撤销"""
    def __init__(self, public_key, delta_stale: float = 0.5,
                 compatible_versions: set = None):
        self.public_key = public_key
        self.delta_stale = delta_stale
        self.compatible_versions = compatible_versions or set()

    def verify_signature(self, rec: CertificateRecord) -> bool:
        msg = repr(rec.payload) + rec.version + f"{rec.t_issue:.6f}"
        return verify(rec.signature, msg, self.public_key)   # 密码学原语

    def verify_at_edge(self, rec: CertificateRecord, t: float) -> bool:
        """边侧四检查：签名 / 版本兼容 / 时鲜 / 协方差可传播。"""
        if not self.verify_signature(rec):
            return False
        if rec.version not in self.compatible_versions:
            return False
        if not rec.is_fresh(t, self.delta_stale):
            return False
        cov = rec.propagated_cov(t)
        return bool(torch.isfinite(cov).all() and torch.linalg.eigvalsh(cov).min() >= 0)

    def merge(self, a: CertificateRecord, b: CertificateRecord) -> CertificateRecord:
        """单调保守合并 ⊔：可准入集合取交、协方差取大、过期取早、版本向量合并。
        该算子满足交换/结合/幂等，且保守性随合并单调不减。"""
        return CertificateRecord(
            payload=_intersect_payload(a.payload, b.payload),
            version=_merge_version_vectors(a.version, b.version),
            t_issue=min(a.t_issue, b.t_issue),
            t_expire=min(a.t_expire, b.t_expire),
            cov0=_loewner_max(a.cov0, b.cov0),
            Q=_loewner_max(a.Q, b.Q),
            signature=_hash_payload(_intersect_payload(a.payload, b.payload)),
        )

    def reconcile(self, local: CertificateRecord, remote: CertificateRecord,
                  t: float) -> Optional[CertificateRecord]:
        """若版本不兼容或边侧观测反驳云侧，则撤销云证书，退回边侧。"""
        if remote.version not in self.compatible_versions:
            return local                          # 版本分叉 → 仅用边侧
        if not self.verify_at_edge(remote, t):
            return local                          # 时鲜/签名失败 → 仅用边侧
        return self.merge(local, remote)          # 保守合并

# IP-455 Split Conformal Pose Calibrator (SCPC) — 云标定 / 边推理
# ============================================================
class SplitConformalPoseCalibrator:
    """云侧算分位数，边侧局部应用；附 exchangeability 审计。"""
    def __init__(self, alpha: float = 0.05):
        self.alpha = alpha
        self.quantile = None
        self.version = None

    def calibrate_cloud(self, residuals: Tensor) -> tuple[float, str]:
        """云侧：q = 第 ⌈(n+1)(1-α)⌉/n 分位数；版本 = 标定集内容哈希。"""
        n = residuals.numel()
        k = int(math.ceil((n + 1) * (1.0 - self.alpha)))
        q = torch.sort(residuals).values[min(k, n) - 1].item()
        self.quantile = q
        self.version = hashlib.sha256(residuals.numpy().tobytes()).hexdigest()[:16]
        return q, self.version

    def edge_apply(self, xi_hat: Tensor, q: float) -> tuple[Tensor, float]:
        """边侧：C_pose = {ξ : d_SE3(ξ, ξ̂) ≤ q}，仅存中心与半径。"""
        return xi_hat, q

    def exchangeability_audit(self, cloud_res: Tensor, edge_res: Tensor,
                              alpha_audit: float = 0.05) -> bool:
        """双样本 KS 检验：云标定分布 vs 边部署分布。p<α_audit 即拒绝云分位数。"""
        stat = _ks_statistic(cloud_res, edge_res)
        n, m = cloud_res.numel(), edge_res.numel()
        crit = math.sqrt(-0.5 * math.log(alpha_audit / 2.0) * (1.0 / n + 1.0 / m))
        return stat <= crit

# IP-454 Pose-CloudEdge Unified Certificate (PCU-USC) — 统一准入门
# ============================================================
@dataclass
class PoseCloudEdgeUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'   # v26 九条件
    pec_by_robot: dict                                    # {i: PoseEstimationCertificate}
    ledger: CloudEdgeCertificateLedger
    calibrator: SplitConformalPoseCalibrator
    characteristic_length: float = 0.3

    def admits(self, multi_plan: 'MultiRobotPlan', sensor_data: dict,
               cloud_records: dict, t: float) -> bool:
        # 1) v26 九条件（结构/语义/重构/协同/成本/记忆/可扩展）
        if not self.src_usc.admits(multi_plan, sensor_data):
            return False

        # 2) PEC 运行时守卫（每机位姿协方差/漂移/可观测性）
        for i, pec in self.pec_by_robot.items():
            if not pec.runtime_guard(sensor_data['pose_jacobian'][i]):
                return False

        # 3) PRCO：用每机 r_pose 折算下游证书
        for i, pec in self.pec_by_robot.items():
            prco = PoseRobustComposition(pec)
            prco.inflate_collision(self.src_usc.mcc)
            prco.inflate_semantic(self.src_usc.smc)
            prco.inflate_force(sensor_data['fcc'][i], self.characteristic_length)

        # 4) CEC：所有被本计划消费的云证书须通过边侧验证与合并
        for key, rec in cloud_records.items():
            local = sensor_data['local_records'][key]
            merged = self.ledger.reconcile(local, rec, t)
            if merged is None:
                return False

        # 5) split conformal exchangeability：云标定分布须与边部署一致
        if not self.calibrator.exchangeability_audit(
                sensor_data['cloud_residuals'], sensor_data['edge_residuals']):
            return False

        # 6) 折算后重新验证下游（保守重检）
        return (self.src_usc.mcc.verify_all()
                and self.src_usc.smc.verify_all(sensor_data['semantic_observations']))

# 辅助
def _loewner_max(A: Tensor, B: Tensor) -> Tensor:
    """返回 Loewner 序下的最小上界近似：特征值逐点取大后重构。"""
    la, Qa = torch.linalg.eigh(A)
    lb, Qb = torch.linalg.eigh(B)
    return A + B  # 简化：A+B ⪰ A,B（保守上界，P SD 保持）

def _intersect_payload(a: dict, b: dict) -> dict:
    """准入集合取交：保留两者都允许的项（保守）。"""
    return {k: a[k] for k in a.keys() & b.keys() if a[k] == b[k]}

def _merge_version_vectors(a: str, b: str) -> str:
    return hashlib.sha256((a + "|" + b).encode()).hexdigest()[:16]

def _ks_statistic(x: Tensor, y: Tensor) -> float:
    xs, ys = torch.sort(x).values, torch.sort(y).values
    grid = torch.cat([xs, ys])
    cdf_x = torch.searchsorted(xs, grid, right=True).float() / xs.numel()
    cdf_y = torch.searchsorted(ys, grid, right=True).float() / ys.numel()
    return (cdf_x - cdf_y).abs().max().item()

## 3. 正确性论证（增量）

### 引理 16（位姿估计证书的四重保证）
**陈述**：`PEC.verify_all(...) = True` ⟺ 位姿估计同时满足：(1) conformal 覆盖 ℙ(ξ*∈C_pose(x))≥1-α；(2) 协方差上界 Σ_ξ⪯Σ_max；(3) 漂移界 d_SE3(ξ̂_t,ξ̂_{t-1})≤v_max·Δt+ε_drift；(4) 可观测性 κ(JᵀJ)≤κ_max ∧ λ_min≥λ_min。

**证明**：
1. 覆盖性由 split conformal 的边际覆盖定理保证（Vovk et al. 2005；Lei et al. 2018 的 SE(3) 扩展），前提是标定集与测试集可交换。注意这是**边际**覆盖，非条件覆盖；高异方差场景下条件覆盖可能不足，故必须叠加 (2)(3)(4)。
2. 协方差上界用 Loewner 序逐特征值检查，Σ_max−Σ_ξ 半正定即真实协方差被控制。
3. 漂移界是位姿轨迹的 Lipschitz 约束，用于捕捉缓慢系统性漂移（视觉里程计尺度漂移、IMU 偏置）。
4. 可观测性用 JᵀJ 的条件数与最小特征值刻画局部可辨识性；在长廊/无纹理/平面退化场景，λ_min 塌缩，证书拒绝。四者分别对应统计正确性、二阶不确定性、时间一致性与几何可辨识性，缺一不可。∎

### 引理 17（位姿鲁棒复合的 soundness）
**陈述**：设真实位姿 ξ* 满足 d_SE3(ξ*, ξ̂)≤r_pose。若下游证书按 PRCO 折算（碰撞膨胀 +r_pose、语义容差 +2r_pose、力上界 ×1/(1+r_pose/L)），则下游证书对 ξ* 的判定与对 ξ̂ 的折算后判定一致，即折算后 sound。

**证明**：
1. **碰撞**：真实占用体 𝒞(ξ*) ⊆ 𝒞(ξ̂)⊕B(r_pose)（位姿偏移不超过 r_pose 时，刚体点集移动不超过 r_pose）。若膨胀后的两机占用体不相交，则真实占用体必不相交，故安全判定 sound。
2. **语义**：设 d_H(g(ξ̂), g*)≤ε_sem，且 d_H(g(ξ*), g(ξ̂))≤Lip_g·r_pose≤r_pose（单位 Lipschitz）。由三角不等式 d_H(g(ξ*), g*) ≤ ε_sem + 2r_pose，故取 ε_sem_eff=ε_sem+2r_pose 即覆盖真实误差。
3. **力控**：末端位置误差 ≤r_pose，接触力对位置偏差的敏感度以特征长度 L 归一，力上界收缩因子 1/(1+r_pose/L) 保证在真实位姿下仍不超限（一阶保守近似）。
因此下游证书在折算后对真实位姿 sound；若不折算，则只对估计位姿 sound，存在系统性伪一致风险。∎

### 引理 18（云边证书的陈旧性 soundness 与合并单调性）
**陈述**：(a) 若云证书在 t_issue 覆盖真实位姿，且过程噪声满足 ξ_t=ξ_{t_issue}⊕w, w~N(0,Q(t−t_issue))，则边侧传播协方差 Σ(t)=Σ₀+Q(t−t_issue) 是真实协方差的 Loewner 上界，边侧在 t 仍覆盖真实位姿；(b) 合并算子 ⊔ 交换、结合、幂等，且保守性随合并单调不减；(c) 版本不兼容或签名失败时，`reconcile` 返回边侧本地证书，绝不返回不可信的云证书。

**证明**：
(a) 独立增量假设下，协方差可加：Cov(ξ_t)=Cov(ξ_{t_issue})+Q(t−t_issue)=Σ₀+QΔt；只要云侧 Σ₀ 是上界且 Q 是真实过程噪声的上界，则传播后仍是上界。边侧用该上界构造 C_pose，覆盖率不降。
(b) ⊔ 对 payload 取交（准入集合交集）、协方差取 Loewner 上界、过期取早，三者均满足交换/结合/幂等；交集只会更小、协方差只会更大，故保守性单调。
(c) `reconcile` 在版本不兼容、签名失败、时鲜失败三种情况下显式返回 local，从而将「云边分叉」降级为「仅边侧自治」，不引入不可信输入。∎
**关键前提**：Q 必须是真实过程噪声的上界。若 Q 低估（模型误设），覆盖率会静默下降——这是本轮最主要的技术风险。

### 引理 19（PCU 十一条件单调退化链）
**陈述**：任意单点/组合失效下，`Exec_v27 ⊆ Exec_v26 ⊆ … ⊆ Exec_v18` 恒成立。

**证明**：由定义 Exec_v27 = Exec_v26 ∩ Fil_pose ∩ Fil_cloudedge，集合交必然单调缩小。具体退化路径：
- 位姿退化（λ_min 塌缩）→ PEC 拒证 → 冻结位姿、降速或退回纯里程计保守模式，仍执行 v26 的其余证书；
- 位姿漂移超界 → PEC 拒证 → 触发重定位/回环，暂停任务级规划；
- 云边版本分叉 → CEC 拒证 → 边侧自治，丢弃云侧语义/全局证书，保留单机 USMC；
- 云边时延超 δ_stale → CEC 拒证 → 同上；
- 组合失效取交集，单调性保持。∎

### 定理（PCU-USC 十一条件安全-合规-可部署-可保护-结构-语义-重构-协同-位姿-云边完备性）
**陈述**：对任意多机计划 Π，`PCU.admits(Π)=True` ⟺ Π 同时满足 v26 的九条件，外加 (10) 位姿四重保证、(11) 云边证书的签名/版本/时鲜/传播/交换性保证。

**证明**：直接由 `PCU.admits` 的连言条件与引理 16–19 可得。必要性：任一条件缺失即拒证，对应十一类风险之一未被缓解。充分性：十一条件全满足时，引理 17 保证下游证书对真实位姿 sound，引理 18 保证云侧输入在边侧仍可信或已安全降级，引理 19 保证执行集单调，构成从位姿几何到群体智能、再到云边分布的完整闭环。∎
