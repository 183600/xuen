# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「主动交互」×「故障诊断」）

> R69 把不确定性一分为二：aleatoric 收紧、epistemic 去问；并给了系统「看/问/触」三种可认证、可审计的信息动作。但它对「问」这件事有一个从未被检验的假设——**被问的世界和用来提问的仪器，都是好的**。R69 的 `VoI(g)=H(M|o)−E[H(M|o,y)]` 是在「传感器、流模型、标定器、执行器全部正常」这条基线上计算信息增益的；它对「机器本身坏了」只交付了一个标量 `a_score`（FMA）和一条铁律「疑似慢变故障 → 退回 R68 最保守」。
>
> 于是 R69 在真正的故障面前只有两个动作：**装作没看见**（继续用被污染的感觉去交互，去问一个错误的问题），或**永远收紧**（`λ=0.8`、`k` 收缩，直到系统变成一具只会刹车的尸体）。**检测（detection）被误当成了诊断（diagnosis）**：FMA 说「有东西不对」，却从不回答「哪里不对、能不能补偿、要不要停下来修」。而 R69 自陈的最大风险——「问错，比不问更危险」——恰恰就是「仪器坏了却还在提问」的症状。
>
> 本轮两个灵感各自补上一半：
> - **故障诊断**提供一套成熟的**鉴别诊断**结构：假设空间、故障签名、**可分辨性（distinguishability）**、序贯检验与停止规则，以及最重要的——诊断的产物不是「更保守一点」，而是一个**与故障相匹配的处置**（重构、降级、安全停、求援）。
> - **主动交互**在故障语境下获得第二重、更锋利的含义：不只是「问世界/问人」，而是**主动对 plant（甚至对自己的仪表链）施加一次经过认证的试探/激励，把原本结构上不可观测的故障变成可观测的**——这正是控制理论里的 active fault diagnosis。**不主动激一下，有些故障永远不会露出签名；但激一下，也可能把潜伏的故障激成现实的故障。**
>
> 核心命题：**把「关于世界的不确定性」与「关于我自身机构的不确定性」分开；后者不靠更大声地问，而靠鉴别诊断——维护故障假设后验，主动设计最便宜且最安全的试探来最大化「处置相关」的区分度，在诊断价值低于成本、或故障结构上不可分辨时诚实地弃权，然后执行一个故障条件化的处置，而不是一个标量 λ。R69 在本轮被恢复为「仪器健康」这一边界上的特例。** 命名 **TRIAGE-RAS**（Trustworthy Risk-aware Interactive Active diaGnosis & Escalation：可信的分诊式主动交互诊断与升级闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**是我的世界错了，还是我的感官错了；为了分清这一点，我该做哪一次最便宜、最安全的试探**」——R69 学会提问，R70 学会**分诊**。

## 0. 直觉与动机

**灵感 1（故障诊断 → 检测不是诊断，异常分不是一个诊断）**
直觉：医生不会因为「体温 38.5」就开药；他要问「感染、炎症，还是中暑」。R69 的 FMA 只给了体温。一个标量异常分把所有故障压到一根轴上，导致两个不可接受的后果：**（a）不可分辨的故障被当成同一个**——传感器偏置、执行器增益误差、流模型漂移，都可能抬高 `a_score`；**（b）诊断价值被错误地等同于「异常分降下来」**。故障诊断的第一课是：**诊断 = 在假设空间上做划分，而不是在标量上设阈值**。签名必须多维、有方向、有时标：残差往哪偏、行为似然往哪移、哪些模态同时异常、以什么时间常数演化（缓变/间歇/瞬发）。没有签名的「异常」只能触发保守，不能触发正确的处置。

**灵感 2（主动交互 → 有些故障只在被激励时才可观测）**
直觉：一个卡滞的关节在静止时完全正常；一个增益漂移的执行器在空载时看不出来；一个只在特定姿态下才失真的深度传感器，你不动就永远不知道它坏了。控制理论把这叫 **active fault diagnosis**：被动残差在当前工作点可能**结构上不可观测**，必须注入一个（有界的、安全的）辅助激励，让不同故障假设产生可区分的响应。这是「主动交互」在故障语境下最严格的含义：**交互不是为了获取关于世界的答案，而是为了制造一个能让故障自我暴露的实验**。代价是它同时是一次对可能已损坏系统的扰动——**试探本身就是风险**。

**灵感 3（仪表也会坏 → 诊断的无限回归与可信基）**
直觉：如果 `a_score` 高，可能是世界异常，也可能是**算 `a_score` 的流模型坏了**、是**标定器把故障吸收了**、是**传感器死了**、甚至是**探针执行器根本没动**。用可能坏掉的仪器去诊断仪器，是一个循环。R69 没有处理这个循环，它默认「FMA 这条第二意见」是干净的——而 R69 自陈的最大风险恰恰是这条意见本身不可信。解法不是宣称「我的诊断永远正确」，而是（a）定义一个**不可再疑的可信基**（硬件看门狗、能量/动量/连续性等物理不变量、独立冗余通道、带外的人类）；（b）**只允许用不在嫌疑集合里的通道去诊断嫌疑通道**；（c）把回归**限深**（通常深度 1），超出即弃权并求援。**能诊断到什么程度，必须由「还剩下哪些可信的东西」决定，而不是由「我想知道多少」决定。**

**灵感 4（诊断的产物是处置，不是刹车 → 响应格）**
直觉：R68/R69 的处置只有一个方向：把 λ 调大。可真实的故障处置是一个**格（lattice）**：健康 → 照常（R69）；可补偿 → 重构（换估计器/控制器/切冗余/反向标定）；不可补偿但可受限 → 降级运行（缩小包络）；危险且不可控 → 安全停；无法判断 → 求援/弃权。诊断只有在**能改变处置**时才有价值。由此得到一个极干净的停止规则：**如果所有仍在怀疑的故障假设都映射到同一个处置，那么继续诊断的价值精确为零**——你不需要知道是哪一种病，如果治法是同一种。这把 R69 的「为消歧而消歧」升级成「为处置而消歧」。

**灵感 5（诊断的经济学：区分度/代价比与不对称错误）**
直觉：医学诊断不会对每个人都做全身 CT。每一次试探都有**风险成本、时间成本、社交成本、以及「惊扰病人」的成本**；而漏诊与误诊的代价天然不对称（漏掉一个会致命的故障 ≫ 误报一次）。所以目标函数不该是「最大化信息增益/最小化熵」，而应是「最小化**期望处置后悔（regret）**」，阈值由代价比决定，而不是 0.5。并且故障有时间尺度：缓变的需要驻留观察，间歇的需要重复探询，瞬发的一旦错过就再无证据。诊断必须是一个**带预算与截止时间的序贯决策**，不是一次性分类。

**灵感 6（严格姿态 + 新攻击面 → 边界退化与「诊断可被武器化」）**
直觉：TRIAGE 必须像前几轮一样**包含** R69/R68，而不是替代它们：当故障后验集中在「健康」、且不存在处置相关的区分时，TRIAGE 与 FLUID **逐指令相同**；当诊断不可分辨、预算耗尽或可信基不足时，TRIAGE **逐指令**退化为 R68 的纯保守。另一方面，一旦系统「会诊断」，就有了新的攻击面：**诱导一个良性故障签名，让系统自愿进入降级/安全停（把诊断变成拒绝服务）**；**用可信的良性假设掩盖真故障（误导）**；**污染诊断历史/标签**；**让系统把预算耗在无价值的试探上（诊断疲劳）**。**一个会自我诊断的系统，也会被诱导着自我伤害。**

## 1. 形式化定义（增量：定义 310–325）

**定义 310（TRIAGE-RAS 总览）** TRIAGE-RAS = (FHS, DSA, AFD, DSE, PEC, MDG, RSP, DSS, CGK, RAS-WM‡)。五不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **诊断包络安全**：任何试探/激励 g 必须在「当前故障后验支撑集内所有假定的最坏情形」下保持鲁棒正不变安全集，风险 ≤ ε_diag；认证失败则不允许激励；
(iii) **限深可信基**：诊断只能用不在嫌疑集合内的通道；元诊断深度 ≤ D_md（默认 1）；可信基不足 ⇒ 弃权；
(iv) **处置单调性**：诊断失败/超时/被污染时，处置只能沿响应格向更保守方向移动，且跳变必须经过认证过渡；
(v) **边界退化**：健康后验占优且诊断无处置价值时，TRIAGE 逐指令退化为 FLUID-RAS；不可分辨/预算耗尽/可信基不足时逐指令退化为 CALM-RAS。

**定义 311（故障假设空间与签名 FHS）** 故障假设 `ℱ = {f_0 (健康), f_1,…,f_m, f_unk}`，其中 `f_unk` 表示「未枚举故障」，**永远保留非零质量**。每个 `f` 带签名
`s_f = (μ_f, dir_f, Γ_f, τ_f, sev_f)`：`μ_f` 期望残差偏移、`dir_f` 行为似然偏移方向、`Γ_f` 受影响模态集、`τ_f` 时间常数（缓变/间歇/瞬发）、`sev_f` 严重度与可补偿性。后验 `b_t(f)` 由残差、流似然与「对试探的响应」联合更新；`b_t(f_unk)` 用开集/失配缓冲维护（不允许被其他假设吸干）。

**定义 312（可分辨性与可诊断性 DSA）** 对试探 `g` 与假设对 `(i,j)`，`D_ij(g) = E_{f_i}[log p(o|g,f_i)/p(o|g,f_j)]`（KL），对称版本用 Chernoff 系数。单探针可分辨性 `δ_i = min_{j≠i} max_{g∈𝒢_safe} D_ij(g)`。若 `δ_i ≤ τ_dis`：`f_i` 在当前工作点**结构上不可分辨**，对它的进一步试探**无价值**，记为 `U_iso`（unisolable），直接进入弃权/降级路径。**这是本轮「没有免费诊断」引理的入口。**

**定义 313（主动诊断探针 AFD）** 试探集合 `𝒢 = 𝒢_read ∪ 𝒢_exc`：`𝒢_read` 是 R69 的看/问/触（读）；`𝒢_exc` 是对 plant 的认证激励（测试动作、负载/姿态激励、子系统自检、对某一模态的定向查询）。选择
`g* = argmax_{g∈𝒢_safe} VoD(g)/(c_phys(g)+c_social(g)+c_time(g))`，
其中 `VoD` 见定义 317。约束：诊断包络（定义 314）、时序可行（`L(g)+L_act ≤ T_dec`）、预算（定义 319）。R69 的 `VoI(g)` 是 `ℱ = {动作模态}` 时的特例。

**定义 314（诊断安全包络 DSE）** 对后验支撑 `supp_ε(b) = {f : b(f) ≥ ε}`，要求存在鲁棒正不变集 `Ω_diag`，使对 `∀f ∈ supp_ε(b)`（`f_unk` 用最坏可容许模型）与 `∀g ∈ 𝒢_exc`：
`x_{t+H} ∈ Ω_diag` 且 `P(violation) ≤ ε_diag`。
激励幅度受 `margin(Ω_diag)` 约束。**若连最坏可容许模型都无法认证，则禁止激励**（只能被动读或弃权）。注意：该保证是对**假设支撑集**的，对支撑集之外的真实故障**不提供保证**——这一条被显式写进证书，而不是藏在假设里（见第 6 节）。

**定义 315（探针有效性自检 PEC）** 对试探 `g` 预测可观测变化 `ŷ(g)`；执行后计算一致度 `κ_g = sim(ŷ(g), Δo)`。若 `κ_g < τ_probe`：**不是**「世界没变」，而是「探针通道可能坏了」（执行器没动/传感器没采到/模型预测错），该证据计入元诊断（定义 316），不得作为 plant 的诊断证据。**不能用一个可能坏掉的探针去证明世界正常。**

**定义 316（限深元诊断 MDG）** 可信基 `𝒯`（硬件看门狗、物理不变量、独立冗余模态、带外人类）。规则：诊断 `f` 只能用 `𝒯 ∪ (ℱ \ suspect)` 中的通道；`suspect = {f : b(f) ≥ τ_sus}`；元诊断深度 `≤ D_md`（默认 1）。若 `suspect` 与全部可用通道相交（没有干净通道）⇒ **不可自证**，进入 `r_ask`/`r_stop`，并把 `J_TRIAGE.meta_flag = unverified` 写入证书。**可信基是有限的，因此可诊断性是有限的——诚实标注比假装全知更重要。**

**定义 317（诊断价值 VoD 与停止规则 DSS）** 处置代价矩阵 `C(r,f)`（漏诊、误诊、保守代价、切换代价，含严重度与不对称权重）。定义
`VoD(g) = E_{y|g}[ min_r E_{f|y} C(r,f) ] − min_r E_{f} C(r,f)`，
即「做这次试探后，最优处置的期望后悔能降多少」。停止规则：
(a) `max_g [VoD(g) − c(g)] ≤ 0`；
(b) **处置同格**：`supp_ε(b)` 内所有假设的最优处置相同 ⇒ `VoD ≡ 0`（定理 19）；
(c) 预算/截止时间耗尽；
(d) `U_iso` 非空且主导。
满足任一条即停止；若无有效诊断而被迫决策，输出**弃权**（`r_ask` 或 R68 兜底），而不是伪造一个诊断。

**定义 318（故障条件化响应格 RSP）** 响应集 `ℛ = {r_nom, r_comp, r_deg, r_stop, r_ask}`，按「许可性」偏序：`r_nom ≻ r_comp ≻ r_deg ≻ r_stop`，`r_ask` 与 `r_stop` 并列保守。策略 `π_R(b) = argmin_r E_{f~b} C(r,f) + c_switch(r, r_prev)`，带迟滞（防止抖动）与**认证过渡**（`r_prev → r` 的切换本身要过 C-RAS-WM，且满足定义 310-iv 的单调性）。`r_nom` 内部调用 R69 的 FLUID 闭环；`r_comp` 切换估计器/控制器/标定（定义 320）；`r_deg` 收紧包络但仍执行受限任务；`r_stop` 安全停；`r_ask` 升级到人类/外部诊断。

**定义 319（诊断预算与调度）** 单位时间试探 ≤ 1、累计激励风险 ≤ ε_diag^tot、社交打扰 ≤ c_max、诊断截止时间 `T_dec`（由任务/安全窗口导出）。预算耗尽 ⇒ 停止诊断、按当前后验处置；若后验仍分散 ⇒ 取 `r_deg`/`r_stop`（保守侧的最优处置），并记录 `budget_exhausted`。

**定义 320（诊断门控的标定冻结 CGK）** 当某模态 `c` 进入 `suspect`：**冻结该通道的 COF 标定**（禁止把故障当漂移吸收）。标定更新只能吸收与「健康假设」一致的缓变分量；被诊断门控拒绝的残差进入诊断证据，而不是被标定吃掉。这是对 R68「标定吸收缓变故障」风险的正面封堵，也是 R69 FMA 的上游修复——**先别把病灶缝进正常组织，再谈怎么发现它。**

**定义 321（诊断证书 J_TRIAGE）** `J_TRIAGE = (J_FLUID, b_hat, δ_min, probe_log_hash, response, C_expected, trusted_base_hash, meta_flag, budget_state, diag_latency, triage_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ 包络满足 ∧ (meta_flag ≠ unverified 或 response ∈ {r_ask, r_stop}) ∧ 处置过渡认证 ∧ 预算未越界`。

**定义 322（诊断攻击面 ℰ_diag）** 故障掩蔽（诱导良性签名）、响应劫持（逼出安全停 = 拒绝服务）、诊断投毒（污染历史/标签/签名库）、试探武器化（诱导无价值试探耗尽预算/损伤 plant）、狼来了（反复误报侵蚀信任）。并入 AIC：`ℰ_TRIAGE = ℰ_FLUID × ℰ_diag`。审计对象新增诊断决策（VQAuditor-D）：试探是否有处置价值、是否越过包络、是否单源定诊、是否该弃权而没弃权。

**定义 323（间歇/瞬发故障的驻留策略）** 对 `τ_f` 为间歇/瞬发的故障，单次观测不足以定诊；需要**驻留窗口 `W_dwell`** 与**重复探询次数上限 `N_rep`**，并用序贯似然比（SPRT）累计证据。驻留期间若处置必须改变，按当前后验的保守侧处置（`r_deg`），不等待完整诊断——**诊断可以等，安全不能等。**

**定义 324（弃权 ABSTAIN）** 弃权是一等公民：当 `U_iso` 主导、可信基不足、预算耗尽或 `b(f_unk)` 过高时，输出 `abstain = (no_excitation, r ∈ {r_deg, r_stop, r_ask}, 标注 unknown_fault)`。弃权不声称知道故障，只声称**在给定证据与预算下无法可靠定诊**，并显式把这一无知写进证书。**不知道就说不知道，是比错误诊断更强的安全属性。**

**定义 325（健康—诊断中性边界）** 定义边界条件 `H0`：`b(f_0) ≥ 1−ε`、`U_iso = ∅`、`max_g VoD(g) ≤ 0`、`meta_flag = verified`。在 `H0` 下 TRIAGE 必须与 FLUID **逐指令相同**；当进一步 `U_epi ≤ τ_epi` 时与 CALM **逐指令相同**。这是定理 18 的前提，也是「新层严格泛化旧层」的可检验断言（实验 E313）。

## 2. 关键算法骨架

```python
# IP-264~266 FHS/DSA：故障后验与可分辨性
class FaultDiagnoser:
    def update(self, b, obs):                    # 定义 311/312
        for f in b:
            b[f] *= self.signature_likelihood(f, obs)   # 残差+流似然+探针响应
        b = renormalize_with_unknown_buffer(b, floor_unk)  # f_unk 永不为 0
        return b

    def distinguishability(self, b, probes):
        # D_ij(g)：签名分布间的 KL/Chernoff；返回不可分辨集与 δ_min
        D = {(i, j, g): kl(self.pred(i, g), self.pred(j, g))
             for i in top(b, k=4) for j in top(b, k=4) if i < j for g in probes}
        delta = {i: min(D[(i, j, g)] for (j, g) in pairs(i)) for i in top(b, k=4)}
        return D, delta, {i for i, d in delta.items() if d <= TAU_DIS}

    # 定义 313/317：只选有处置价值的试探（VoD/成本），并过包络
    def choose_probe(self, b, probes, budget):
        best = None
        for g in probes:
            if not budget.allow(g): continue
            if not dse.certify(g, b): continue          # 定义 314：包络认证
            if response_partition(b) is all_same(b):    # 定理 19：同格停
                break
            score = (self.value_of_diagnosis(b, g) - self.cost(g))
            if best is None or score > best.score: best = (g, score)
        return best if best and best.score > 0 else None   # 无价值→停止/弃权

    # 定义 315/316：探针有效性自检 → 元诊断
    def probe_check(self, g, y_hat, delta_o, b):
        kappa = similarity(y_hat, delta_o)
        if kappa < TAU_PROBE:
            return b, meta='probe_channel_suspect'       # 不是世界没变，是探针可能坏了
        return b, meta='ok'

    # 定义 318/320：后验 → 处置（带迟滞与认证过渡）
    def response(self, b, prev):
        r = argmin_r (expected_cost(r, b) + switch_cost(r, prev))
        return certified_transition(prev, r, b)          # 单调保守 + C-RAS-WM 过渡

# IP-276 主闭环（继承 R69/R68，仅在「机器是否可信」处插入 TRIAGE 层）
def TRIAGE_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    # 0) 先诊断「我的仪器」，再决定是否相信 R69 的提问
    b = M.fhs.update(M.fhs.b, (M.last_r_res, M.last_a_hat, o))
    b, meta = M.pec.check_probe(M.last_probe, M.last_y_hat, M.last_delta_o, b) \
              if M.last_probe else (b, 'none')
    D, delta, unisolable = M.dsa.distinguishability(b, M.probes)
    # 1) 只做有处置价值的试探；同格/不可分辨/无预算 ⇒ 停止
    g = None
    if M.dss.should_continue(b, unisolable, M.budget):
        g = M.afd.choose_probe(b, M.probes, M.budget)
    if g is not None:
        y = M.afd.execute(g)                       # 过 DSE 包络 + C-RAS-WM
        b = M.fhs.update(b, y)
    # 2) 诊断 → 处置，而不是诊断 → 标量 λ
    r = M.rsp.response(b, M.prev_response)
    if r == 'r_comp':
        M.reconfigure(b); r = 'r_nom'              # 重构后重评，不假设已修好
    if r in ('r_deg', 'r_stop', 'r_ask'):
        M.cgk.freeze(M.dsa.suspect_channels(b))    # 定义 320：别把病灶标定掉
        return M.rsp.enact(r, b, M.vqa_d)          # 受限/停/求援，附 J_TRIAGE
    # 3) 健康边界：逐指令走 R69（定理 18）
    k, lam, mode, U = M.fluid_round(o)             # = R69 的 FLUID_RAS_round
    M.vqa_d.submit_async(b, r, g, meta, M.budget)
    return k, lam, mode, U, r
```

## 3. 推导

**引理 19（没有免费诊断 / 不可分辨下界）** 若某假设 `f_i` 的可分辨性 `δ_i = 0`（所有安全试探下它与某 `f_j` 的观测分布相同），则任何序贯检验在误报率 ≤ α 下的漏诊率 ≥ 先验质量 `b(f_j)/(b(f_i)+b(f_j))`，且期望试探次数无界。要点：这不是算法不够好，而是**信息论上的零信道容量**——`D_ij = 0 ⇒` 两个假设在可执行实验下不可区分。因此 `U_iso` 必须被显式识别并弃权，而不是让系统无限试探。

**引理 20（主动激励的分辨率—风险权衡）** 在 A99（包络内局部线性化、Fisher 信息有界）下，探针 `g` 的期望对数似然比在 `f_i` 下以 `n·D_ij(g)` 增长；达到误报 α/漏诊 β 所需重复次数 `n* ≈ log(1/β)/D_ij(g)`。主动激励把当前工作点的 `D_ij` 从（可能为 0 的）被动态提升到包络内可达上界，因此**缩短诊断延迟**；但包络约束 `‖g‖ ≤ margin(Ω_diag)` 与故障不确定度共同给出 `D_ij` 的上界——**分辨率是用风险额度买来的**。

**引理 21（诊断包络的条件安全）** 若 `Ω_diag` 对 `∀f ∈ supp_ε(b)` 鲁棒正不变且激励幅度 ≤ `margin`，则单步违约概率 ≤ `ε_diag`；对 `f_unk` 的最坏可容许模型同样成立。**但该界对 `f ∉ supp_ε(b)` 不成立**：支撑集外的故障不受任何保证。系：证书必须显式记录「包络是对假设集认证的」，否则安全主张越界。

**引理 22（处置单调与无突变）** 响应格上的 `π_R` 在 `C(r,f)` 满足单调代价（越保守对越严重的故障代价越低、对健康代价越高）时，后验向严重故障移动会使最优响应向保守侧单调移动；带迟滞的认证过渡保证 `r_prev → r` 不跳变。诊断失败/超时/污染时强制向保守侧移动，故安全侧不弱于「一直保守」。

**定理 18（TRIAGE 严格包含 FLUID 与 CALM）** 在 A99–A101 与定义 325 的 `H0` 下，TRIAGE 与 FLUID 逐指令相同；当诊断不可分辨、预算耗尽、可信基不足或 `f_unk` 主导时，TRIAGE 逐指令退化为 CALM-RAS 的保守路径。因此安全侧不做让步，效率与可用性只来自「可认证、可回退、有处置价值」的诊断。

**定理 19（诊断只对处置边界有价值）** 设 `supp_ε(b)` 被响应分区 `{A_r}` 划分（同一 `A_r` 内所有 `f` 的最优处置相同）。则任意只在单个 `A_r` 内部区分假设的试探 `g` 满足 `VoD(g) = 0`。故最优诊断策略只需跨分区边界采样；当 `supp_ε(b)` 完全落在一个分区内时，**继续诊断严格无价值**。系：R69 的 `VoI` 正是 `ℱ={动作模态}` 且响应=选择动作时的特例；本轮把「为消歧而消歧」替换为「为处置而消歧」。

**定理 20（试探诱发故障的条件界）** 设真实故障 `f*`，探针 `g` 在 `f*` 下的条件诱发风险为 `h_exc(g,f*)`。则
`P(试探诱发故障) ≤ P(f* ∉ supp_ε(b)) + max_{f∈supp_ε(b)} h_exc(g,f)`。
包络认证只能压住第二项；**第一项恰是「我们没想到的那种故障」的概率，而它正是诊断要寻找的东西**。因此在 `b(f_unk)` 高时，唯一安全的动作是弃权/降级——这从形式上证明了「主动诊断不能无条件进行」。

## 6. 本轮最大风险

**一句话**：TRIAGE 的全部安全性都建立在「诊断包络是对**假设集**认证的」这一点上，而它要寻找的故障**按定义就是假设集之外的那个**——于是经过认证的主动激励，恰恰是能把潜伏的未知故障兑现成现实故障的那个动作；诊断越积极、包络越紧，系统就越可能自信地把病人推进那间它以为安全的检查室。

**次级风险与缓解**：
1. **不要相信这个诊断**：诊断本身是一个测量，测量会被仪器误差与共模相关污染；用 `J_TRIAGE` 把 b_hat、δ_min、meta_flag 全写进证书，让下游可以选择不信。
2. **诊断动作不安全**：任何激励都可能越界或诱发故障 → 定义 314 的 DSE 包络 + 定理 20 的条件界 + 弃权。
3. **可信基/回归**：元诊断必须是有限深、只用非嫌疑通道，且 `unverified` 时强制升级求援（定义 316）。
4. **诊断疲劳与拒绝服务**：只做有处置价值的试探（定理 19），并设硬预算（定义 319）；攻击者诱导的无效试探由 VQAuditor-D 审计。
5. **单次误诊被当成定论**：诊断证据同样受 R69 的「k 个正交证据源一致」纪律约束，单探针不得定诊（定义 312/323）。

**定义 310（总览与五不变式）** 零学习写操作继承；诊断包络安全（对支撑集最坏情形认证，失败禁激励）；限深可信基（非嫌疑通道 + 深度 ≤ 1 + 不足即弃权）；处置单调性（失败只能更保守，跳变需认证过渡）；边界退化（`H0`→FLUID，不可分辨/预算尽/可信基不足→CALM）。

**定义 311–312（故障后验与可分辨性）** `b_t(f)` 用残差 + 流似然 + 探针响应更新，`f_unk` 保留失配缓冲；`D_ij(g)=KL`，`δ_i = min_j max_g D_ij(g)`；`δ_i ≤ τ_dis` ⇒ `U_iso`，试探无价值。

**定义 313–314（AFD 与 DSE）** 试探集 `𝒢 = 𝒢_read ∪ 𝒢_exc`；`g* = argmax VoD/成本`，受包络、时序、预算约束；`Ω_diag` 对 `∀f ∈ supp_ε(b)`（`f_unk` 取最坏可容许模型）鲁棒正不变，激励幅度 ≤ `margin`；认证失败禁激励。**保证只对支撑集成立，支撑集外不保证。**

**定义 315–316（PEC 与 MDG）** `κ_g < τ_probe` ⇒ 「探针通道可疑」，证据不进 plant 诊断；元诊断只用 `𝒯 ∪ (ℱ\suspect)`，深度 ≤ `D_md`；无可信通道 ⇒ `unverified` + 弃权/求援。

**定义 317–319（VoD/响应格/预算）** `VoD(g)=E_y[min_r E_{f|y}C]−min_r E_f C`；停止条件：`VoD−c≤0`、处置同格、预算/截止耗尽、`U_iso` 主导；`π_R(b)=argmin_r E_{f~b}C+c_switch`，带迟滞与认证过渡；预算含频率/累计风险/社交成本/`T_dec`。

**定义 320–322（CGK/证书/攻击面）** 嫌疑通道冻结 COF 标定，被拒残差进诊断而非被吸收；`J_TRIAGE` 并入 `b_hat,δ_min,probe_log_hash,response,C_expected,trusted_base_hash,meta_flag`；`ℰ_TRIAGE=ℰ_FLUID×ℰ_diag`（掩蔽/劫持/投毒/试探武器化/狼来了）。

**定义 323–325（驻留/弃权/边界）** 间歇/瞬发故障用 `W_dwell + N_rep + SPRT`，安全不等诊断；弃权是一等输出（`unknown_fault` 写入证书）；`H0`：`b(f_0)≥1−ε ∧ U_iso=∅ ∧ max VoD≤0 ∧ meta=verified` ⇒ 与 FLUID 逐指令相同。

## 3. 关键算法伪代码

```python
# IP-264~266 FHS/DSA
class FaultDiagnoser:
    def update(self, b, obs):
        for f in b: b[f] *= self.signature_likelihood(f, obs)   # 残差+流似然+探针响应
        return renormalize_with_unknown_buffer(b, floor_unk)     # f_unk 永不为 0

    def distinguishability(self, b, probes):
        D = {(i,j,g): kl(self.pred(i,g), self.pred(j,g))
             for i in top(b,4) for j in top(b,4) if i<j for g in probes}
        delta = {i: min(D[(i,j,g)] for (j,g) in pairs(i)) for i in top(b,4)}
        return D, delta, {i for i,d in delta.items() if d <= TAU_DIS}  # U_iso

    def choose_probe(self, b, probes, budget):                  # IP-266
        best = None
        for g in probes:
            if not budget.allow(g) or not dse.certify(g, b): continue
            if response_partition(b) is all_same(b): break       # 定理 19
            score = self.value_of_diagnosis(b, g) - self.cost(g)
            if best is None or score > best.score: best = (g, score)
        return best if best and best.score > 0 else None          # 无价值→停/弃权

    def probe_check(self, g, y_hat, delta_o, b):                  # IP-268
        return (b, 'probe_channel_suspect') if similarity(y_hat, delta_o) < TAU_PROBE else (b, 'ok')

    def response(self, b, prev):                                  # IP-270
        r = argmin_r (expected_cost(r, b) + switch_cost(r, prev))
        return certified_transition(prev, r, b)                   # 单调保守 + C-RAS-WM

# IP-276 主闭环（继承 R69/R68）
def TRIAGE_RAS_round(M, obs):

              if M.last_probe else (b, 'none')

    g = (M.afd.choose_probe(b, M.probes, M.budget)
         if M.dss.should_continue(b, unisolable, M.budget) else None)
    if g is not None: b = M.fhs.update(b, M.afd.execute(g))        # DSE + C-RAS-WM
    r = M.rsp.response(b, M.prev_response)                        # 诊断→处置
    if r == 'r_comp':
        M.reconfigure(b); r = 'r_nom'                              # 重构后重评
    if r in ('r_deg', 'r_stop', 'r_ask'):
        M.cgk.freeze(M.dsa.suspect_channels(b))                    # 别把病灶标定掉
        return M.rsp.enact(r, b, M.vqa_d)                          # 附 J_TRIAGE
    k, lam, mode, U = M.fluid_round(o)                             # H0 → 逐指令 R69
```

## 4. 推导

**引理 19（没有免费诊断）** 若 `δ_i = 0`（所有安全试探下 `f_i` 与某 `f_j` 观测同分布），则任何误报率 ≤ α 的序贯检验漏诊率 ≥ `b(f_j)/(b(f_i)+b(f_j))`，期望试探次数无界。信息论零信道容量：`D_ij=0` 下两个假设在可执行实验下不可区分。故 `U_iso` 必须显式弃权。

**引理 20（分辨率—风险权衡）** 包络内局部线性化、Fisher 信息有界时，期望对数似然比以 `n·D_ij(g)` 增长，达到 `(α,β)` 需 `n*≈log(1/β)/D_ij(g)`；主动激励把当前工作点的 `D_ij` 提升到包络内上界，缩短诊断延迟；但 `‖g‖ ≤ margin(Ω_diag)` 给出分辨率上界——**分辨率是用风险额度买来的**。

**引理 21（诊断包络的条件安全）** `Ω_diag` 对 `∀f ∈ supp_ε(b)`（含 `f_unk` 最坏模型）鲁棒正不变且激励 ≤ `margin` ⇒ 单步违约 ≤ `ε_diag`；**对 `f ∉ supp_ε(b)` 不成立**。系：证书必须显式记录「包络是对假设集认证的」。

**引理 22（处置单调与无突变）** 单调代价下，后验向严重故障移动使最优响应向保守侧单调移动；迟滞 + 认证过渡保证 `r_prev→r` 不跳变；失败/超时/污染强制更保守 ⇒ 安全侧不弱于「一直保守」。

**定理 18（TRIAGE 严格包含 FLUID 与 CALM）** `H0` 下与 FLUID 逐指令相同；不可分辨/预算尽/可信基不足/`f_unk` 主导时逐指令退化为 CALM 的保守路径。安全不让步，可用性只来自「可认证、可回退、有处置价值」的诊断。

**定理 19（诊断只对处置边界有价值）** `supp_ε(b)` 按响应分区 `{A_r}`；只在单个 `A_r` 内部区分的试探满足 `VoD=0`；`supp_ε(b)` 落在一个分区内 ⇒ 继续诊断严格无价值。系：R69 的 `VoI` 是 `ℱ={动作模态}` 且响应=选动作的特例——「为处置而消歧」严格包含「为消歧而消歧」。

**定理 20（试探诱发故障的条件界）** `P(诱发) ≤ P(f* ∉ supp_ε(b)) + max_{f∈supp_ε(b)} h_exc(g,f)`。包络只压住第二项；第一项正是「没想到的故障」的概率，而它恰是诊断要寻找的东西 ⇒ `b(f_unk)` 高时唯一安全动作是弃权/降级：**主动诊断不能无条件进行**。

## 7. 本轮最大风险

**一句话**：TRIAGE 的全部安全性都建立在「诊断包络是对**假设集**认证的」这一点上，而它要寻找的故障**按定义就是假设集之外的那个**——于是经过认证的主动激励，恰恰是能把潜伏的未知故障兑现成现实故障的那个动作；诊断越积极、包络越紧，系统就越可能自信地把病人推进那间它以为安全的检查室。

**次级风险与缓解**：诊断本身是一个会被共模误差污染的测量（`J_TRIAGE` 暴露 `b_hat/δ_min/meta_flag`，下游可选择不信）；激励越界/诱发故障（DSE 包络 + 定理 20 条件界 + 弃权）；元诊断回归（限深 + 非嫌疑通道 + `unverified` 强制求援）；诊断疲劳/拒绝服务（只做有处置价值的试探 + 硬预算 + VQAuditor-D）；单探针误诊（沿用「k 个正交证据源一致」纪律）。
