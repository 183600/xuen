# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~302；新一轮灵感循环第 1 轮；本轮灵感：「Gazebo」×「云端协同」）

> R73 把证据从「传感器读数」推进为「可组合的计量契约」：EC 带类型、预算、反作用通道、有效域与否决语义；CCA 给出串联/并联/否决的组合单调性；热替换定理让「换本体零改核心」成为结构性质。但 R73 的契约仍然活在一个**单进程、单机器、单时间点、单一世界模型**里，三个隐含假设从未被契约化：
> - **世界模型无契约（Gazebo / 孪生）**：R73 的 DPEM 把「场景/动力学/接触/光照」当作真实世界自行处理，却从未声明「仿真证据」是什么。Gazebo 是 ROS 生态最常用的物理与渲染仿真器：它提供真值、反事实与稀有事件，但 sim-real gap 从未被显式度量，只被领域随机化（DR）当作参数去赌覆盖。更危险的是**仿真洗白（sim-washing）**：用仿真里的一致性掩盖真实世界的不一致；孪生被当成「法官」而不是「证人」。
> - **部署拓扑无契约（云端协同）**：R73 的 CCA 默认证据同地、同步、独立。云端协同把计量/审计/标定搬到云-雾-边，引入**时延、陈旧、分区、拜占庭与共因**。最隐蔽的错误是「多机一致 = 更确定」：共享同一预训练骨干、同一云端标定、同一光照/IR 的 N 个机器人，只是**同一误差的 N 个副本**；朴素贝叶斯融合把方差除以 N，实际是共因误差的 N 倍放大。
> - **时间与信任无契约（证书无有效期、审计无根）**：R73 的证书是全局、开环、无保质期的；云审计天然把信任根移出机器人。若审计日志可被云端重写，「每一步都合规」可以是被伪造的合规——一份密码学上完美、统计学上错误的证书。
>
> 本轮三个灵感各补一块：
> - **Gazebo → GTE（孪生证据契约）+ DTA（孪生差分审计）+ 证人-法官不对称**：孪生只能作证或否决，不能越界替代；它擅长**证伪**（搜索反例），不擅长**证明**。
> - **云端协同 → TEC + CFE + FCA + RoT/VFA**：时间化证据契约（陈旧预算与有效期）、云-雾-边证据分片与降级阶梯、联邦组合代数（COMP-FED / COMP-PART / COMP-TWIN）、**证据计量 CAP 三元悖论**、溯源多样性与共因审计、边缘根信任 + 可验证联邦审计。
> - **蒸馏第二次 → CPB†（主张-证明-证伪三元绑定 + 有效期）**：没有证伪器与有效期的证书视为无效；主张上限 5 条，新增 C4（孪生证人不对称）与 C5（联邦证据的时间/溯源可靠）。
>
> 核心命题：**不问「仿真或云能否让系统更可信」，而问「跨世界（真实-孪生）与跨节点（机-边-云）的证据，能否在时间、分区与共因下保持可靠——并且审计本身是可验证而非仅被信任的？」** 把 R73 的 MODGAUGE-RAS 重构为 **FLEETGAUGE-RAS**（Federated, Latency- and twin-aware Evidence metrology with GAUGE audits for RAS）——**可信联邦孪生计量**。

## 0. 直觉与动机

**灵感 1（Gazebo → 孪生是证人，不是法官）**
直觉：Gazebo 的价值不是「真值」，而是**可反事实**：它能回答「如果我这样动，我本应看到什么」。这让它天然适合做**差分审计**——把真实观测 y 与孪生预测 ŷ = h_sim(S_twin, g) 的残差 r 拿来检验证据链是否自洽。但孪生有两个致命弱点：其一，**sim-real gap 有结构**（接触模型、摩擦、延迟、渲染材质、传感器噪声模型），不是随机噪声；其二，**孪生自身会漂移**——S_twin 必须由真实证据锚定，否则残差测的是孪生自己的错，而不是真实世界的错。因此正确的抽象是**孪生证据契约（GTE）**：孪生状态带自己的不确定度 u_twin，预测经 gap 包络 G 校准（conformal/robust），只在认证域 D_gap 内有效。孪生证据可以**支持**（在 gap 上界内有限缩窄）或**否决**（残差出包络），但绝不能**替代**真实测量。这给出一条不对称律：**仿真只能让世界变得更可疑，不能单方面让世界变得更确定**。极端地说，仿真器是好的**证伪器**，是坏的**证明器**。

**灵感 2（云端协同 → 证据计量的 CAP 三重约束）**
直觉：云端协同听起来像「更多算力、更多数据、更多确定」。但跨节点的不确定度计量有一个分布式系统式的三重约束：在分区下，**可用性（A）**、**跨机一致性（C）**与**不确定度的紧致性（U）**不可兼得。安全性要求「永不低估不确定度」（soundness）是硬约束，于是链路一断，你只能二选一：要么停（牺牲 A），要么把不确定度按陈旧度**膨胀**（牺牲 U）。本方案选择「膨胀 + 收紧操作降级」——牺牲效率，守住安全。这就是**证据计量 CAP（EM-CAP）**：分区下不产生免费的确定性。

随之而来的是第二个直觉：**共识不是证据**。N 个机器人说同一件事，可能只是 N 个副本共享同一光源、同一模型、同一标定服务、同一攻击注入。融合要成立，必须审计**溯源多样性**（独立硬件/模型/标定谱系）与**共因**，否则方差按 1/N 缩小只是统计幻觉。极端情形下，「机器人越多，系统越自信地错」。

**灵感 3（合成：可验证审计 + 根信任 + 证伪优先）**
直觉：云端跑一群 Gazebo 孪生来审计整个机队，是最自然的协同，也是最大的陷阱：审计者离开了机器人，可以被入侵、可以被重写、可以被仿真洗白。因此架构必须满足两点：(i) **信任根在边缘**——每条证据带边缘安全元件签名的溯源令牌，哈希链只可追加；(ii) **云端审计可验证而非被信任**——审计结论 J_FED 必须能被任何第三方在边缘重放复算，云端造不出一条没有边缘根的合法证据路径。再加第三条纪律：**任何主张必须绑定一个独立的证伪器与有效期**。证伪器主动搜索最大 sim-real 差距、分区攻击与溯源伪造；证伪器找不到反例不等于证明成立，但没有证伪器与有效期的「已认证」在本文中直接判为无效。

**灵感 4（CPB 的第二次蒸馏 → 五条主张，每条带证伪器）**
直觉：R73 用三条可证伪主张（C1 物理感知计量 / C2 反作用预算 / C3 契约模块化）挡住了「工程堆叠」的质疑。本轮新增两个维度无法塞进原有三条而不失真，故扩展到 **C1–C5**，但同时立下**反膨胀纪律**：主张总数硬上限 5；每条必须同时绑定（证明，证伪器，最小基准，隔离消融，预注册指标，有效期）；无证伪器或过期证书一律视为无效。新增：
- **C4（孪生证人不对称）**：在 gap 包络认证域内，孪生作证的方案相对「孪生当法官」与「仅 DR」能同时降低真实校准误差且**零假安全证书**；指标（gap 覆盖率、假证书率、真实增益）。
- **C5（联邦证据可靠）**：带时间化契约 + 溯源多样性 + 拜占庭法定人数的联邦融合，在分区/共因/拜占庭下保持不低估；相对朴素贝叶斯融合，指标（低估率、过期证书接受率、分区恢复时间）。

## 1. 形式化定义（增量：定义 383–398）

**定义 383（FLEETGAUGE-RAS 总览与扩展不变式）** FLEETGAUGE-RAS = (MODGAUGE-RAS†, TEC, CFE, GTE, FCA, RoT, VFA, CPB†)。在 R73 五不变式之上扩展为：
(i) **契约完整性**：每个模块契约额外携带时间字段（定义 384）与溯源字段（定义 389），缺一不可入图；
(ii) **组合单调性**：所有组合路径（含 COMP-FED/PART/TWIN，定义 388）满足组合下界定理（引理 34†）——联邦、分区、孪生三条新路径都不得凭空变好；
(iii) **反作用通道完备**：孪生通道 χ_R^tw 同样是必填契约字段（可为平凡）；
(iv) **主张-证伪绑定**：每个组件 ∈ {C1..C5, 工程附件}，且每条主张必须绑定独立证伪器与有效期（定义 394）；
(v) **严格退化链扩展**：模块失效 → stub；网络分区 → 降级阶梯（定义 385）；孪生失配 → 孪生静默；安全侧只增不减。

**定义 384（时间化证据契约 TEC）** TEC = (EC, τ_birth, h_stale, T_valid, clock_domain, xfer)：
- τ_birth = (t_mono, domain, ε_skew)：证据诞生时刻、时钟域与有界偏斜（跨域用区间时钟，不用单一 wall clock）；
- h_stale: ℝ≥0 → ℝ≥0，**单调非减**、h_stale(0)=0、Lipschitz；表示「年龄 Δt 带来的不确定度膨胀」；
- T_valid：有效期上界；Δt > T_valid ⇒ 证据等价于 stub（不是「大概还行」）；
- clock_domain：本地单调时钟 / 同步时钟 / 区间时钟；
- xfer：云→边→机 的降级顺序（与定义 385 对应）。
**有效不确定度** u_eff(t)² = u_meas² + h_stale(Δt)² + u_sync(ε_skew)²；其中 u_sync 由时钟偏斜上界给出（保守项）。
**不变量 T**：u_eff 对 Δt 单调非减；任何组合 u_out ≥ 组合输入 u_eff。

**定义 385（云-雾-边证据分片 CFE）** 每个模块声明 exec_domain ∈ {ctrl, edge, cloud} 与**降级阶梯** L = (cloud → edge → onboard → stub)。**证据搬运令牌** Xfer = (payload, u, provenance, deadline, hash)。**分片调度**在满足 deadline 的前提下选择阶梯最高可用实例；任一域不可用（网络分区/超时/容量）则下移一级；阶梯末端为 stub（定义 381†）。**迟滞**：仅在超过 deadline 的宽限期后才降级，避免抖动；恢复需通过组合校验再升级。
**安全单调**：降级只允许 u 增大、D 收缩、I⊥ 增大，禁止反向。

**定义 386（孪生证据契约 GTE）** GTE = (S_twin, h_sim, G, D_gap, anchor, χ_R^tw, seal_ref)：
- S_twin：孪生状态后验，携带**自身**不确定度 u_twin（孪生不是真值）；
- h_sim：孪生前向模型（物理 + 渲染 + 传感器模型）；
- G：sim-real **差距包络**，在成对真实/仿真数据上以 conformal 或 robust 集校准到覆盖率 1−α_gap；
- D_gap：差距校准有效的认证域（材质/光照/动力学/时延区间）；
- anchor：真实证据到孪生状态的锚定映射（与真实估计器共享同一证据链，禁止开环孪生）；
- χ_R^tw：动作如何改变孪生预测（反事实通道）。
**孪生证据** e_T：残差 r = y_real − h_sim(S_twin, g)；若 r ∈ G(D_gap) 则**支持**；若 r ∉ G(D_gap) 则**否决**；若在 D_gap 外则**静默**（既不作证也不否决）。u_T = u_gap + u_twin + u_anchor。

**定义 387（证人-法官不对称 / 不可仿真洗白）** 对任意真实证据 e_R 与孪生证据 e_T：
- r ∉ G(D_gap) ⇒ e_T 只能投非补偿否决（VETO），不得缩窄；
- r ∈ G(D_gap) ⇒ COMP-TWIN 允许缩窄 δ，但 δ ≤ q_{1−α_gap}(G)（gap 的 conformal 上分位），且结果满足 **u_combined ≥ u_R − δ** 与 **u_combined ≥ u_R·γ_min**（γ_min 为最小可信保留比，防止一次性归零）；
- D_gap 外 ⇒ e_T = 静默 stub（u=∞ 作为测量，I⊥ 为空，不得影响真实证据）。
**推论**：孪生永远不能把真实不确定度降到「gap 校准所能支持」以下——仿真只能证伪或有限支持，不能证明。**不可仿真洗白定理**见定理 33。

**定义 388（联邦组合代数 FCA）** 在 CCA（定义 370）上新增三算子：
- **COMP-FED**（联邦并联）：融合 N 个智能体证据，当且仅当 (a) 两两 conformal 一致性审计通过；(b) **溯源多样性** d(prov) ≥ D_min（独立硬件/模型/标定谱系）；(c) 拜占庭法定人数 |H| ≥ ⌈2N/3⌉+1 且签名可验。任一不满足 ⇒ u_out = max_i u_i（保守并集），并置否决标记。相关性 ρ 由共享溯源标签估计；**有效样本量** n_eff ≤ 独立谱系数（共因标签折叠）。
- **COMP-PART**（分区）：通信不可用或超过 deadline ⇒ 只允许「本地证据 ⊕ 陈旧远端证据」，u_out² = u_local² + h_stale(Δt)²；Δt > T_valid 的远端证据直接丢弃；不得使用任何未过组合校验的远端证据。
- **COMP-TWIN**（孪生）：按定义 387 的「支持/否决/静默」三态组合。
**组合下界定理†**：对 {SER, PAR, VETO, FED, PART, TWIN} 任意组合路径，u_out ≥ 路径上所有**独立**输入贡献的单调函数；「一致性」只有在多样性审计通过时才算独立证据。

**定义 389（溯源令牌与根信任 RoT）** 溯源令牌 P = (id, parents, module_hash, cert_hash, clock, sig_edge, merkle_root)。**边缘安全元件**对本地证据批的 Merkle 根签名，形成只可追加的哈希链；跨节点仅搬运令牌与 Merkle 路径。**云端无权铸造溯源**，只能对已有叶子做带签名的变换（变换本身也留痕）。**等价分叉检测**：通过签名的检查点（checkpoint）与邻机 gossip 检出同一 id 的两条不同链。
**根信任不变量**：任何合法证据的祖先链必须终止于至少一个未被撤销的边缘根。

**定义 390（可验证联邦审计 VFA）** 云端审计结论 J_FED = (inputs_hash, rule_set_hash, verdict, replay_trace, merkle_paths)。**可验证** = 边缘或第三方在 O(模块数) 内可重放复算并核对所有叶子回连边缘根；**不可伪造**依赖签名与哈希假设（A117）。云端可以算得慢、算得贵，但**不能说一套做一套而不被发现**；审计从「被信任」变为「可验证」。

**定义 391（证据计量 CAP 三元悖论 EM-CAP）** 对联邦证据系统，在分区时长 > T_valid 时，不可能同时保证：(A) 刚性 deadline 操作的可用性；(C) 跨节点后验一致；(U) 不膨胀的紧致不确定度。Soundness（不低估 u）为硬约束。因此任何 sound 协议必须至少牺牲 A 或 U；FLEETGAUGE 选择「U 膨胀 + (A) 保留但仅限保守操作」。
**推论**：分区下「既要一致、又要准时、又要紧」的融合器必然不 sound。

**定义 392（共因与溯源多样性 CMA）** 每条证据声明共享资源标签 SharedTags ⊆ {lighting, IR, calibration_service, model_weights, clock, network, physics_engine, training_data}。**独立谱系** = 两条证据的 SharedTags 交集为空。**共因审计**引入独立于模块的第三方观测（单独的温度/振动/光照/时钟源）作为 VETO 输入；怀疑相关时**禁止** PAR/FED 缩窄。
**多样性不变量**：任何依赖独立性的缩窄，n_eff 必须 ≤ 独立谱系数；标签不可信时 n_eff 退化为 1。

**定义 393（双时间证书与有效期）** 证书 J = (issue_time, valid_until, domain, falsifier_ref, claim_id)。**新鲜度不变量**：now > valid_until ⇒ J 等价于「无证书」（触发降级），而不是「大概率仍然成立」。**双时间**：事件时间（证据诞生）与签发时间分别记录，跨时区/时钟域以区间时钟解释。

**定义 394（CPB†：主张-证明-证伪三元绑定）** 主张 C 绑定六元组 (Proof, Falsifier, Bench, Ablation, Metrics, TTL)：
- **Proof**：支撑主张的模块集；
- **Falsifier**：独立于生成者的主动证伪器（搜索最大 sim-real 差距 / 分区 / 共因 / 溯源伪造 / 拜占庭），有计算预算与停止准则；
- **Bench/Ablation/Metrics**：最小基准、隔离消融、预注册指标；
- **TTL**：有效期，过期自动失效。
**职责分离**：证伪器不得与证明器共享模型权重或数据划分（防止「自己认证自己」）。**主张上限** |{C1..C5}| ≤ 5；无绑定项 = 工程附件，不进 MReg、不进正文。

**定义 395（差距包络在线更新 / 防 Goodhart）** G 可在线更新：仅接受**边缘签名**的成对样本，且需通过域检查；漂移检测只允许 G **加宽**（安全侧），收窄必须重新认证。**防 Goodhart**：用于拟合 G 的孪生/增强数据不得同时作为唯一测试集；必须保留密封保持集 SEAL-GAP。

**定义 396（云端孪生差分审计 DTA）** 云端运行孪生**种群** {T_1..T_k}，参数随机但全部**留痕**（可复现），对每个真实证据计算残差分布，取**最坏残差** r_worst；若 r_worst ∉ G ⇒ 触发否决/调查。**认识论定位**：DTA 是**证伪器**，只能发现反例，不能证明 soundness——因为种群共享同一物理引擎与传感器模型，不构成独立证据。

**定义 397（联邦降级阶梯与安全单调）** 阶梯：J_FED（云联邦）→ J_MOD（边缘本地）→ J_stub（机载保守）。到期、分区、证书失效或审计失败触发下移；每下移一级 u 增大、D 收缩。恢复须重新通过组合校验与新鲜度检查。**零级联**：单模块失效不触发全局降级，只有其所在汇聚点降级。

**定义 398（FLEETGAUGE 复杂度与预算结构上限）** |V_M^local| ≤ 24、组合深度 ≤ 4（继承 R73）；新增：联邦宽度 N_fed ≤ 16、独立谱系要求 D_min ≥ 2、Merkle 批大小 B ≤ 4096、溯源图深度 ≤ 64、陈旧预算向量 B_stale（各模块 T_valid 之和有界）、孪生种群 k ≤ 8。全部为**可审计的图/预算性质**，部署期与运行时增量校验。

```python
# IP-303 TEC：时间化证据契约（陈旧预算 + 有效期 + 时钟域）
@dataclass(frozen=True)
class TemporalEC:
    ec: EvidenceContract
    tau_birth: ClockStamp                 # (t_mono, domain, eps_skew)
    h_stale: Callable[[float], float]     # Δt -> u_stale，单调非减，h(0)=0
    T_valid: float                        # 秒；过期即 stub
    xfer: Tuple[str, ...]                 # ('cloud','edge','onboard')
    def u_eff(self, now: ClockStamp) -> float:
        dt = max(0.0, now.t_mono - self.tau_birth.t_mono)
        if dt > self.T_valid:             # 新鲜度不变量：过期 == 无证据
            return float('inf')
        return math.hypot(self.ec.u, self.h_stale(dt),
                          self.sync_unc(now.eps_skew))

# IP-304 CFE：云-雾-边分片调度器（降级阶梯 + 迟滞 + 安全单调）
class EvidenceFabric:
    def schedule(self, mods, deadline, net):
        for m in sorted(mods, key=lambda x: x.priority):   # ctrl > edge > cloud
            for dom in m.tec.xfer:                          # 只允许向下移动
                if dom == 'cloud' and net.partitioned():    continue
                if dom == 'edge'  and deadline < net.rtt_edge(): continue
                if self.capacity(dom, m):
                    return self.exec(dom, m)
        return stub(m)                                      # 全不可用 -> 保守 stub
    # 迟滞：仅当 now > deadline + grace 才真正降级，防止分区抖动

# IP-305 GTE：孪生证据（证人，不是法官；支持/否决/静默三态）
class TwinEvidence:

        r      = residual(y_real, pred)                   # 差分残差

        in_env = self.G.covers(r)                          # 1-alpha_gap 校准
        u_tw   = self.u_gap + self.u_twin + self.anchor.u(s_twin)
        state  = ('support' if (in_dom and in_env) else
                  'veto'    if (in_dom and not in_env) else
                  'silent')                                # 域外：静默
        return TwinEv(pred=pred, r=r, u=u_tw, state=state,
                      q_gap=self.G.quantile(1 - ALPHA_GAP),
                      tau=self.anchor.tau(s_twin), chi_R=self.chi_tw(g))

# IP-306 FCA：联邦组合代数（FED / PART / TWIN）
def compose_fed(agents, audit, prov, net):
    if net.partitioned():
        return compose_part(agents, net.staleness)         # 分区：陈旧预算
    if not audit.pairwise_consistent(agents):              # 跨机 conformal 审计
        return conservative_union(agents, veto='FED_AUDIT_FAIL')
    n_eff = prov.independent_lineages(agents)              # 共因标签折叠
    if n_eff < D_MIN:
        return conservative_union(agents, veto='CM_DIVERSITY_FAIL')
    if not prov.byzantine_quorum(agents):                  # |H| >= 2N/3+1
        return conservative_union(agents, veto='BYZ_QUORUM_FAIL')
    return fuse(agents, n_eff=n_eff, rho=audit.corr(agents))

def compose_part(agents, staleness):
    live = [a for a in agents if a.tec.u_eff(now) < INF]   # 过期直接丢
    return Ev(u=math.hypot(max(a.u for a in live), staleness.u),
              D=intersect(a.D for a in live),
              veto=union(a.veto for a in live) | {'PARTITION'})

def compose_twin(e_R, e_T):
    if e_T.state == 'silent': return e_R                  # 域外：孪生静默
    if e_T.state == 'veto':   return Ev(valid=False, veto={'TWIN_GAP'})
    delta = min(e_T.q_gap, e_T.u)                          # 支持：缩窄有上界
    return Ev(u=max(e_R.u - delta, U_FLOOR), D=e_R.D & e_T.D,
              tau=merge(e_R.tau, e_T.tau), veto=e_R.veto)

# IP-307 RoT + VFA：边缘签名溯源 + 云端可验证审计

    return (J_fed.rule_hash == RULE_SET_HASH
            and all(leaf.verify_path(J_fed.merkle_paths[i], r)
```

## 3. 推导

**引理 38（时间化单调性与过期即 stub）** 对任意证据 e，u_eff(t) 对 t 单调非减；当 Δt → T_valid⁺ 时 u_eff → ∞。任何组合算子（SER/PAR/VETO/FED/PART/TWIN）的输出 u 不小于各输入的 u_eff。**证明**：h_stale 单调非减、u_sync ≥ 0，故 u_eff 单调；过期置 ∞ 由定义 384 直接得；组合单调性继承引理 34，并在 COMP-PART 中显式加入 h_stale(Δt)。**系**：**证书有保质期，且时间只能让证据变差**——这把「陈旧」从工程 bug 升为类型级性质。

**引理 39（证人-法官不对称）** 对 COMP-TWIN：若 e_T 支持，则 u_out ≥ max(u_R − q_{1−α_gap}(G), u_R·γ_min)；若 e_T 否决，则输出无效；若静默，则 u_out = u_R。**证明**：由定义 387 的缩窄上界直接构造；conformal 覆盖率保证 r ∈ G 时真实差距以 1−α_gap 被覆盖，故缩窄量不可能超过校准支持。**系**：**孪生不能把真实不确定度降到 gap 校准之下——仿真无法「证明」它没有校准过的世界**。

**引理 40（溯源多样性与「机器人越多越自信地错」）** 设 N 个证据误差 e_i = s_i + c + ν_i，其中 c 为共享共因（同模型/同标定/同光照），ν_i 独立、方差 σ²，s_i 为信号。朴素独立融合的方差估计为 σ²/N，但真实 MSE = σ²/N + c²。因此低估比为 u_hat/u_true = 1/√(1 + N·c²/σ²)，随 N **单调下降**。**证明**：均值误差含 c，共因不被平均消除；代入方差分解即得。**系**：**联邦融合前必须做溯源多样性审计；否则 n_eff 必须按共因折叠为 1，绝不允许「按机器数除方差」**。

**引理 41（证据计量 CAP）** 在分区时长 Δt > T_valid 下，任何 sound 协议若同时保证 (A) 刚性 deadline 可用、(C) 跨节点一致、(U) 不膨胀紧致，则存在重放攻击使其低估 u。**证明**：攻击者缓存旧证据并在分区期重放；若协议拒膨胀（¬U）且保持可用（A），则旧证据的新鲜度未被计入；若又要求一致（C），则所有节点接受同一旧证据，u 被系统性低估，与 soundness 矛盾。故 sound 协议必须牺牲 A 或 U。**系**：**分区下没有免费确定性；本方案牺牲 U（膨胀）保留 A（仅保守操作）**。

**引理 42（可验证审计的不可伪造性）** 在 A117（EUF-CMA 签名、抗碰撞哈希、边缘根未泄露）下，云无法伪造一个被边缘验证器接受的 J_FED 而不拥有合法边缘根签名的祖先链；等价分叉通过签名检查点检出。**证明**：Merkle 路径绑定叶子到根，签名绑定根；伪造需伪造签名或找哈希碰撞。**注意**：这是**密码学**保证，不是**统计**保证——它只保证「没被篡改」，不保证「内容正确」。后者由引理 39/40/41 与 gap 包络承担。

**定理 30（FLEETGAUGE 严格包含 MODGAUGE）** 把云域置空、孪生置静默、联邦宽度置 1、TEC 的 h_stale≡0 且 T_valid=∞，则 FLEETGAUGE 逐指令等于 R73 MODGAUGE；再退化等于 R71/R68。**证明**：定义 383(v)、388 的退化设置与引理 35（同契约实现替换）直接给出；安全单调由引理 38–41 保证。**系**：**新维度是旧维度的严格泛化，安全侧只增不减，退化链逐指令等价**。

**定理 31（联邦组合证书 ⇒ 系统安全）** 在 A114–A118 下：Valid(J_FED) ⇒ (i) 各模块 TEC 有效且未过期；(ii) 组合校验通过（预算闭合、域交非空、通道完备、FED 多样性/法定人数、PART 陈旧预算、TWIN 不对称）；(iii) 风险 ≤ ε_fed（相对孪生 gap 包络、溯源多样性与新鲜度上界）。**证明重量**落在 A114（gap 包络在域漂移下仍覆盖）、A115（溯源标签诚实反映共享资源）、A116（时钟偏斜有界）、A117（密码学）、A118（拜占庭比例 < 1/3）。**注意**：证书的统计正确性不由密码学提供，这正与本轮最大风险对应。

**定理 32（分区零级联与安全单调）** 任一分区/模块失效 ⇒ 按定义 385/397 的阶梯确定性下移；每步 u 不减、D 不增；单模块失效不触发无关模块降级。**证明**：阶梯是静态偏序 + 迟滞，COMP-PART 只允许本地 ⊕ 陈旧远端；引理 38 给出单调性；定义 397 的汇聚点局部性给出零级联。**系**：**失效的传染路径只有一条（证据缺失或变旧），无级联**。

**定理 33（证伪优先 / 不可仿真洗白）** (i) 没有绑定独立证伪器或超过 TTL 的证书，按定义 394 判为无效，不得进入核心认证路径；(ii) 孪生作为**证伪器**（DTA）可以合法地否决，但作为**证明器**不能单独认证（引理 39）；(iii) 若证伪器在预算内发现任一 gap 反例，则相关主张的证书立即撤销并触发域收缩。**证明**：由定义 394/396 与引理 39 直接组合；「仿真器是好的证伪器、坏的证明器」由此形式化为「否决合法、证明非法」。**系**：**审计的价值在于它能被证伪，而不在于它能自洽**。

**定义 393（双时间证书）** J 带 issue_time/valid_until/domain/falsifier_ref；过期即无证书，不降级为「大概成立」。

**定义 394（CPB†）** 六元绑定 (Proof, Falsifier, Bench, Ablation, Metrics, TTL)；证伪器与证明器职责分离；主张上限 5；无绑定 = 工程附件。

```python
@dataclass(frozen=True)
class TemporalEC:
    ec: EvidenceContract
    tau_birth: ClockStamp                 # (t_mono, domain, eps_skew)
    h_stale: Callable[[float], float]     # Δt -> u_stale，单调非减，h(0)=0
    T_valid: float                        # 秒；过期即 stub
    xfer: Tuple[str, ...]                 # ('cloud','edge','onboard')
    def u_eff(self, now):
        dt = max(0.0, now.t_mono - self.tau_birth.t_mono)
        if dt > self.T_valid:             # 新鲜度不变量：过期 == 无证据
            return float('inf')
        return math.hypot(self.ec.u, self.h_stale(dt), self.sync_unc(now.eps_skew))

    M.ctrl_out.publish(k, lam)
    return k, lam, (J_fed if net.available('cloud') else M.ladder.current())
```

## 4. 推导

**引理 38（时间化单调性与过期即 stub）** u_eff(t) 对 t 单调非减，Δt→T_valid⁺ 时 →∞；所有组合算子输出 u ≥ 输入 u_eff。系：**证书有保质期，时间只能让证据变差**。

**引理 39（证人-法官不对称）** COMP-TWIN 支持时 u_out ≥ max(u_R − q_{1−α_gap}(G), u_R·γ_min)；否决则无效；静默则 u_out = u_R。系：**孪生无法把真实不确定度降到 gap 校准之下**。

**引理 40（溯源多样性 / 越多越自信地错）** 误差 e_i = s_i + c + ν_i ⇒ 朴素融合低估比 = 1/√(1+N·c²/σ²)，随 N 单调下降。系：**共识≠证据，融合前必须按共因折叠 n_eff**。

**引理 41（EM-CAP）** 分区 Δt>T_valid 下，sound 协议不能同时保证 A/C/U；否则重放旧证据即可系统性低估。系：**分区下牺牲 U（膨胀）保留保守可用性**。

**引理 42（可验证审计不可伪造）** 在 A117 下，云无法伪造被边缘接受的 J_FED；等价分叉由签名检查点检出。**密码学保证「未篡改」，不保证「内容正确」**。

**定理 30（FLEETGAUGE 严格包含 MODGAUGE）** 云置空、孪生静默、N_fed=1、h_stale≡0 且 T_valid=∞ ⇒ 逐指令等于 R73，再退化等于 R71/R68；安全单调不减。

**定理 31（联邦组合证书 ⇒ 系统安全）** 在 A114–A118 下，Valid(J_FED) ⇒ 模块 TEC 未过期 ∧ 组合校验通过（预算/域/通道/FED 多样性/法定人数/PART 陈旧/TWIN 不对称）∧ 风险 ≤ ε_fed。证明重量落在 **gap 包络覆盖、溯源标签诚实、时钟有界、密码学、拜占庭比例**。

**定理 32（分区零级联与安全单调）** 分区/失效 ⇒ 阶梯确定性下移；每步 u 不减、D 不增；单模块失效只降其汇聚点。系：**失效传染路径唯一，无级联**。

**定理 33（证伪优先 / 不可仿真洗白）** 无独立证伪器或超 TTL 的证书无效；孪生作为证伪器可合法否决但不可单独认证；证伪器发现反例即撤销证书并收缩域。系：**仿真器是好的证伪器、坏的证明器**。

**假设集（A114–A118）**：A114 gap 包络在域漂移下有覆盖保证；A115 溯源标签诚实反映共享资源；A116 时钟偏斜有界；A117 签名/哈希/边缘根安全；A118 拜占庭比例 < 1/3。

## 7. 本轮最大风险

**一句话**：FLEETGAUGE 把证明负担从「契约表达力」转到「**溯源独立性与孪生 gap 包络的真实性**」——若机器人共享同一 Gazebo 物理/预训练骨干/云端标定（「独立谱系」只是标签）、gap 包络在域漂移下失效、或边缘根被攻破，则「多机一致」只是同一错误的多个副本，「可验证审计」只是密码学上完美、统计学上错误的证书；系统会在分区、共因与孪生漂移下**自信地认证一个错误的世界**，而日志证明「每一步都合规且可重放」。

次级风险与缓解：
1. **溯源标签不可验证（A115）** → 硬件指纹 + 独立审计源 + 标签不可信则 n_eff=1。
2. **gap 域漂移/Goodhart** → SEAL-GAP + 只加宽不收窄 + DTA 独立种群证伪。
3. **边缘根被攻破** → 安全元件 + 远程证明 + 检查点 gossip；根失效即全队降级告警。
4. **CAP 下可用性塌缩** → 保守操作集 + 迟滞 + 渐进恢复；紧致操作列为可牺牲项。
5. **联邦共因放大** → N_fed≤16 + 独立谱系门槛 + 「越多越保守」。
6. **时钟域混淆** → 区间时钟 + ε_skew 保守项，禁止跨域 wall clock。
7. **CPB 主张膨胀** → 硬上限 5 + 反膨胀审计（E415），新维度必须挤掉或合并旧主张。
