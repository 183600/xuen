# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「自适应控制」×「状态隔离」）

> R69 让系统学会「问」，并把不确定性一分为二。但它有一个没被点破的**结构性幻觉**：它把 R68/R69 的标定、流策略、模态头、VoI、FMA 当成互相独立的「第二意见」，可它们全都读同一个 trunk 的 `z_t`、写同一个控制状态。于是：
> - **共模失效**：一次投毒观测或一个漂移的 trunk 会同时骗过所有监视器——它们不是多个证人，而是同一个人换了五顶帽子；
> - **状态污染**：注入共享潜状态的误差会持续存在，污染下一轮标定与模态权重，形成「一次错、轮轮错」的复利；
> - **伪正交**：R69 的证据纪律要求「k 个正交证据源一致」，但它们共享底座，欺骗相关系数 ρ 实际接近 1，引理 18 的上界形同虚设；
> - **吸收问题没被真正解决**：R69 每来一个观测就更新置信，没有激励检查、没有死区，于是「从交互中学习」的同一机制，也是把缓变故障与投毒答案吸收进信念的机制——**R69 没有消灭 R68 的吸收，而是给它装了一个更聪明的吸收器。**
>
> 本轮两个灵感各补一刀：
> - **自适应控制**告诉我们：自适应的正确问题不是「如何更新」，而是「**此刻到底该不该更新、更新量能被证明有界吗**」——需要持续激励（PE）、死区、投影/σ-修正、以及快慢分离（L1）把「适应速率」与「鲁棒裕度」解耦；
> - **状态隔离**告诉我们：可信的最小单位不是算法，而是**状态边界**——把单一状态切成若干隔离舱，用带类型、单向、能力受控的接口与验证过的晋升门连接，故障无法横向传播，污染半衰期可以被界定。
>
> 核心命题：**先隔离状态，再自适应；每一次自适应更新都只是「提案」，必须通过由激励与完整性共同门控的晋升门，才允许进入安全内核。** 命名 **AEGIS-RAS**（Adaptive Excitation-Gated Isolated-State risk-adaptive system）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**谁有资格改我的状态**」。

## 0. 直觉与动机

**灵感 1（自适应控制 → 「更新」是症状，「可辨识与有界」才是病根）**
直觉：R69 把「学会消歧」等同于「每个观测都更新信念」。但自适应控制的教科书教训恰恰相反——**无激励的适应等于漂移**。当输入对该参数方向不持续激励（PE 失败）时，数据根本不约束这个方向，任何非零更新都只是把噪声/故障积分进参数，最终表现为参数漂移与爆发（bursting）。再叠加 R69 没有死区：标定残差 r_res 级别的慢变分量会跨过噪声底、被当成「新信息」吸收——这正是 R68 自陈的最大风险，在 R69 里以另一条路径复现。因此正确的自适应不是「更快地学」，而是：**PE 度量决定该不该学，死区决定误差值不值得学，投影 + σ-修正决定学完不许跑出安全集**。

**灵感 2（状态隔离 → 可信来自边界，不来自算法）**
直觉：与其问「哪个监视器更可信」，不如问「一个监视器坏掉时，它能污染到哪」。单体状态里，答案处处都是「全部」。状态隔离把状态切成四个舱：安全内核态 `S_K`、估计态 `S_E`、适应态 `S_A`、证明态 `S_P`；边是带类型、单向、持能力令牌（capability）的。唯一能写内核的通道是**晋升门 PGU**。这给出一条可检查的安全性质——**信息流非干扰**：没有晋升事件时，任意篡改 `S_A` 都不会改变 `S_K` 的轨迹。于是「一次错、轮轮错」的复利被压成「一次错、一次限幅」。

**灵感 3（快慢分离 → 让适应可以激进，而控制保持平滑）**
直觉：L1 自适应控制的精髓是「快速估计 + 低通后使用」，把适应速率与鲁棒裕度解耦：估计器可以很激进（快速捕捉变化），但进入控制的是滤波后的慢提交量，于是瞬态有上界、不会因一次异常答案造成大步长跳变。这同时回答 R69 的两个遗留问题——投毒答案不再能「一次定案」，回滚也不再破坏 R68 的无突变定理。

**灵感 4（真冗余 → 把「正交」从命名变成度量）**
直觉：R69 的 k 源一致是**共享底座的伪正交**。真正的第二意见必须不共享编码器、不共享时钟、不共享写路径（`z^(1)`、`z^(2)`）。隔离图上的泄漏 `ℓ` 才是真实的「相关性」：`ρ ≈ ℓ`，而不是假设出来的 `ρ<1`。这样引理 18 的上界才第一次有可测的依据，FMA 也才真正独立于标定通道。

**灵感 5（隔离是双刃剑 → 会漏的隔离比不隔离更危险）**
直觉：隔离不是免费的：真冗余要双编码器（+延迟/+功耗），分区要跨舱复制与序列化，快照要存储，晋升门可能成为单点瓶颈。更隐蔽的是——**隔离证书本身会授权信任**：系统因为「我有 ℓ≤τ 的证书」而给出更高的自适应权限 α；若隔离实际泄漏（共享内存、共享时钟侧信道、过宽的 PGU 白名单），一次真实泄漏会被系统自己的信心放大。隔离不能只是架构图，必须是可证伪的运行时断言。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（AEGIS-RAS 总览）** AEGIS-RAS = (SPI, EGA, PGU, FSC, SDR, AAL, SNAP, RAS-WM‡)。五不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **状态分区与非干扰**：内核态 `S_K` 只能经 PGU 被写；无晋升事件时 `S_A` 的任何变化不得改变 `S_K` 轨迹；
(iii) **激励门控**：无持续激励或无完整性证据时，适应增益为 0（冻结，而非漂移）；
(iv) **有界性**：参数估计始终位于投影集 `Ω_θ` 内，并带 σ-修正泄漏项；
(v) **包含性**：当 PE 饱和、`ℓ=0`、无晋升需求时，逐指令退化为 R69；当权限 `α=0` 时逐指令退化为 R68。

**定义 311（状态分区）** `S = (S_K, S_E, S_A, S_P)`：`S_K` 安全内核态（安全包络、认证后的 λ/k、硬件约束镜像；对任务层只读）；`S_E` 估计态（标定参数 `ĉ`、模态信念 `w`、世界模型预测）；`S_A` 适应态（在线梯度缓冲、提案参数、交互答案原文）；`S_P` 证明态（证书、provenance、快照指针、晋升日志）。每舱有类型化端口，边有向且需能力令牌 `cap`。

**定义 312（能力接口与晋升门 PGU）** 写关系 `W ⊆ 舱×舱` 受能力约束；唯一进入 `S_K` 的边是 PGU：`(proposal p ∈ S_A, witness w ∈ S_P) → accept/reject`。accept 需四重校验：(a) `p ∈ Ω_θ`；(b) 证据纪律（k 源一致或双通道一致）；(c) 非干扰检查（对内核的差分只在白名单变量上）；(d) 速率限制（单次晋升 `‖Δ‖ ≤ Δ_max`）。任一失败则 p 留在 `S_A` 并被衰减或回滚。

**定义 313（隔离图与泄漏 ℓ）** 隔离图 `G_iso`，节点为舱，边权为可观测的跨舱影响（读写字节、共享缓存命中、时钟耦合）。`ℓ(t) = Σ_{非授权边} 归一化传输容量 ∈ [0,1]`。`ℓ=0` 为理想隔离；`ℓ` 是运行时测量量，不是设计声明。

**定义 314（污染半衰期）** 向舱 i 注入扰动 δ，其范数期望按 `e^{−γ_i t}` 衰减（σ-修正 + 快照重置保证 `γ_i>0`），半衰期 `t_{1/2}=ln2/γ_i`。跨舱污染只能经 PGU 传播，故总污染包络 `≤ Σ_i ‖δ_i‖e^{−γ_i t} + ℓ·(传播项)`。

**定义 315（持续激励度量）** 滑窗回归矩阵 `Φ`（各参数方向的敏感度），`μ_PE = λ_min(ΦᵀΦ/N)`。仅当 `μ_PE ≥ μ_0` 时该参数方向可辨识。

**定义 316（激励-死区门 EGA）** 有效增益 `η_eff = η · 1[μ_PE ≥ μ_0] · 1[‖e‖ > d_0]`，死区 `d_0` 覆盖噪声与标定残差底。要点：死区把 `r_res` 量级的慢变分量挡在适应环外，使「被标定解释掉的故障」无法进入参数。

**定义 317（投影与 σ-修正）** `θ ← Proj_{Ω_θ}(θ + η_eff·update − σ(θ−θ_0))`，`σ>0`。无激励时向名义 `θ_0` 回拉，杜绝漂移与爆发；`Ω_θ` 由硬件约束与经验安全集给出。

**定义 318（快慢分离 FSC，L1 式）** 快估计器 `θ̂_fast` 允许激进（每步更新，服务似然异常检测）；慢提交 `θ_slow = LP_ωc(θ̂_fast)`（低通，截止 `ω_c`），只有 `θ_slow` 能进 PGU。瞬态上界 `‖θ_slow − θ*‖ ≤ (1/ω_c)·sup‖θ̇_fast‖`，把适应速率与鲁棒裕度解耦。

**定义 319（自适应权限分配 AAL）** `α = clip(μ_PE/μ_0,0,1) · (1−ℓ) · integrity`。λ_floor 只有在 `α` 高时才允许 R69 的 resolution bonus；`α` 低则回退保守。`α` 经 FSC 滤波，不因单次交互跳变。

**定义 320（状态多样性冗余 SDR）** 至少两条**不共享编码器、不共享时钟、不共享写路径**的观测通道 `(z^(1), z^(2))`；`agree = 1[‖z^(1)−z^(2)‖ ≤ τ_agree]`。这是 R69「k 正交源」的真实版本：正交性由状态隔离保证，而非由命名保证。

**定义 321（验证快照与回滚 SNAP）** 周期性对 `S_K/S_E` 生成签名快照；任一舱完整性校验失败 ⇒ 冻结该舱并恢复最近快照；恢复须满足 bumpless 条件（λ、k 连续），以保持 R68 定理 15 的无突变。

**定义 322（适应诱发风险界）** 隔离 + 门控下跟踪误差最终有界：`limsup‖e‖ ≤ (d_0 + b_dist)/(1−ρ) + c·ℓ`，`b_dist` 为未建模动态/泄漏扰动界，`ρ<1`；`ℓ→0` 且 PE 满足时退化为名义界。安全侧：内核轨迹只在晋升事件处改变，且每次改变 `≤ Δ_max`。

**定义 323（隔离感知审计 VQAuditor-Σ）** 审计新增：每次晋升的 provenance、被拒提案、`ℓ` 轨迹、快照根、权限 `α` 轨迹；要求「内核轨迹可由晋升日志复现」。

**定义 324（威胁模型 ℰ_isolate）** 状态污染注入、跨舱横向移动、晋升门重放、回滚重放、快照陈旧、隔离旁路（共享内存/时钟侧信道、过宽白名单）。并入 AIC：`ℰ_AEGIS = ℰ_FLUID × ℰ_isolate`。

**定义 325（证书 J_AEGIS）** `J_AEGIS = (J_FLUID, ℓ_p95, μ_PE_min, deadzone_ratio, reject_rate, authority_trace_hash, snapshot_root, promote_log_hash, isol_ver)`。Valid ⇔ `Valid(J_FLUID)` ∧ `ℓ_p95 ≤ τ_ℓ` ∧ 投影集未越界 ∧ 晋升日志可复现内核轨迹。

**定义 326（对 R69/R68 的包含边界）** `α=1`（PE 饱和、`ℓ=0`、完整性全通过）且无晋升需求 ⇒ 与 FLUID 逐指令相同；`α=0` ⇒ 与 R68 逐指令相同；中间为 FSC 保证的连续过渡（无跳变）。

## 2. 关键算法骨架

```python
# IP-264 SPI：状态隔离舱 + 能力令牌（单向、带类型）
class Cell:
    def __init__(self, name, integrity_fn):
        self.name, self.s, self.integrity = name, {}, integrity_fn
    def read(self, cap):
        assert cap.allows(self.name, 'r'); return copy(self.s)
    def propose(self, delta, cap):
        assert cap.allows(self.name, 'w'); self.staged = delta

# IP-266 PGU：唯一进入安全内核的晋升门（四重校验）
def promote(p, witness, cap, theta_slow):
    if not in_projection_set(p, OMEGA):      return REJECT
    if not evidence_discipline(witness):     return REJECT   # k-源 / 双通道
    if not noninterference_ok(p):            return REJECT   # 仅白名单变量
    if norm(p - last_kernel) > DELTA_MAX:    return REJECT   # 速率限制
    return ACCEPT

# IP-265 EGA：激励 + 死区门控的适应（冻结优于漂移）
def adapt(theta, phi_win, err, noise_floor, eta, sigma):
    mu = lambda_min(phi_win.T @ phi_win / len(phi_win))     # μ_PE
    if mu < MU0 or norm(err) <= noise_floor:                # 不可辨识 / 在死区
        return theta                                        # 冻结
    return project(theta + eta*update(err) - sigma*(theta - THETA0), OMEGA)

# IP-267 FSC：快估计 / 慢提交（L1 式，解耦速率与鲁棒）
theta_fast = adapt(theta_slow, ...)                          # 每步
theta_slow = lowpass(theta_slow, theta_fast, W_C)            # 只有它可进 PGU

# IP-268 ILM：隔离泄漏（可测的相关性，替代假设的 ρ）
def leakage(graph): return sum(norm_capacity(e) for e in graph.unauthorized_edges)

# IP-269 SDR：真独立第二意见（不共享底座）
def diverse_agree(z1, z2): return norm(z1 - z2) <= TAU_AGREE

# IP-274 主闭环（继承 FLUID-RAS，改为「提案 → 晋升 → 授权」三段式）
def AEGIS_round(M, obs):
    # 1) 各舱在隔离下独立更新，不写内核
    z1, z2 = M.enc1(obs), M.enc2(obs)                        # 不共享底座
    if not diverse_agree(z1, z2):
        M.snap.freeze('S_E'); M.snap.rollback('S_E'); alpha = 0.0
    else:
        alpha = M.aal.authority(M.ega.mu(), M.ilm.est(), M.sdr.integrity)
    # 2) 快估计 → 慢提交（有界瞬态）
    theta_f = M.ega.adapt(M.s_e.calib, M.ega.window(), M.err)
    theta_s = M.fsc.commit(theta_f)
    # 3) 适应只是提案；进内核必须过晋升门
    p = M.spi.propose(theta_s, cap=M.cap_task)
    if not M.pgu.promote(p, M.sdr.witness, M.cap_task, theta_s):
        M.snap.rollback('S_A'); alpha = 0.0
    # 4) 权限决定是否允许 R69 的交互消歧，否则逐指令退化
    if alpha < TAU_ALPHA:
        return R69_conservative(M, obs)                      # 安全侧不变
    k, lam, mode, u = FLUID_core(M, obs, theta_slow=theta_s) # R69 主体
    # 5) 隔离感知审计：晋升日志 + 快照根 + 泄漏轨迹
    M.audit_sigma.submit(p, M.pgu.witness, M.ilm.trace, M.snap.root(), alpha)
    return k, lam, mode, u
```

## 3. 推导

**引理 19（无激励的适应即漂移）** 若 `μ_PE < μ_0`，参数方向不可辨识，非零更新在该方向的期望改变与输入能量同向但方向不受数据约束；故无门控的自适应在误差落入死区后仍持续累积，漂移量 `≥ η·T·‖未激励分量‖`。加入死区与 σ-修正后 `limsup‖θ−θ_0‖ ≤ (d_0 + sup‖update‖)/σ`。系：R69 的「每观测必更新」在缓变故障下等价于把故障写进参数——这是 R68 吸收问题的第二条路径，也是本轮必须堵住的洞。

**引理 20（隔离抑制共模失效）** 设 m 个监视器。单体架构下欺骗相关 `ρ_mono≈1`，故 k 源一致的错误率≈`δ_p`。隔离 + 独立底座下，同时欺骗 k 源需要「k 个舱各自被独立攻破」或「存在泄漏路径」，故错误率 `≤ ∏_i δ_i + ℓ·δ_p`；当 `δ_i<1` 时 `∏δ_i ≪ δ_p`。系：引理 18 的上界第一次有了真实依据——`ρ = ℓ^{1/(k−1)}`，`ℓ` 可测。

**引理 21（污染半衰期与回滚限幅）** 在 σ-修正 + 快照重置下，舱内注入误差按 `γ ≥ σ/2` 指数衰减；跨舱只经 PGU 且被速率限制 `Δ_max`，故对内核的最大瞬时影响 `≤ Δ_max`，总污染包络 `≤ Δ_max/(1−e^{−γΔt})`。系：状态隔离把「一次错、轮轮错」的复利变成「一次错、一次限幅」。

**定理 18（隔离自适应闭环的最终有界性）** 在 A99–A102 下闭环跟踪误差最终有界，界为 `(d_0+b_dist)/(1−ρ)+c·ℓ_ss`；`ℓ_ss→0` 且 `μ_PE≥μ_0` 时收敛到名义界，瞬态由 FSC 给出 `‖e(t)‖ ≤ k_1‖δ‖/ω_c`。安全侧：内核只在晋升事件处改变，每次 `≤ Δ_max`。

**定理 19（AEGIS 严格包含 FLUID 与 R68）** `α=1` 且无晋升 ⇒ 逐指令等同 FLUID；`α=0` ⇒ 逐指令等同 R68；FSC 保证切换连续。故本轮只增加「有资格才适应」的资格判定，不引入新的安全退化路径。

**定理 20（非干扰与可审计性）** 若无晋升事件，则改变 `S_A` 任意内容不改变 `S_K` 轨迹（由能力接口单向性与 PGU 唯一性直接得证）。系：审计可用晋升日志复现内核轨迹——**把「信任算法」换成「审计边界」**。

## 4. 复杂度分析

## 6. 本轮最大风险

**一句话**：AEGIS 的全部主张押在「隔离边界真的不泄漏」上——若两舱共享内存、时钟或编码器，或晋升门白名单过宽，隔离就只是剧场；**更危险的是，系统会因为「我持有 ℓ≤τ 的隔离证书」而授予更高的自适应权限 α，于是一次真实泄漏被系统自身的信心放大——会漏的隔离，比不隔离更危险，因为它替信任签了字。**

**次级风险与缓解**：
1. **隔离开销击穿实时预算**（SDR 双编码器 +0.6ms）→ 分级隔离：常规路径单编码器 + 廉价一致性代理，仅异常时开双通道；
2. **适应饥饿**（平静/低激励场景永远不学）→ 最小探索预算 + 离线重放，明确区分「线上冻结」与「线下学习」；
3. **回滚引发突变** → bumpless 条件（λ/k 连续）+ FSC 低通，保持 R68 无突变定理；
4. **晋升门成为单点瓶颈** → 门本身用与内核同样的验证等级实现，且晋升日志可复现以备独立审计；
5. **快照陈旧** → 快照新鲜度纳入 `J_AEGIS`，过期快照只允许恢复估计态、不允许恢复内核态。

## 3. 关键算法伪代码

```python
# IP-264 SPI：隔离舱 + 能力令牌
class Cell:
    def __init__(self, name, integrity_fn): self.name, self.s, self.integrity = name, {}, integrity_fn
    def read(self, cap):    assert cap.allows(self.name, 'r'); return copy(self.s)
    def propose(self, d, cap): assert cap.allows(self.name, 'w'); self.staged = d

# IP-266 PGU：唯一进入内核的晋升门（四重校验）
def promote(p, witness, cap):
    if not in_projection_set(p, OMEGA):   return REJECT
    if not evidence_discipline(witness):  return REJECT      # k-源一致 / 双通道
    if not noninterference_ok(p):         return REJECT      # 仅白名单变量
    if norm(p - last_kernel) > DELTA_MAX: return REJECT      # 速率限制
    return ACCEPT

# IP-265 EGA：激励 + 死区门控（冻结优于漂移）
def adapt(theta, phi_win, err, noise_floor):
    mu = lambda_min(phi_win.T @ phi_win / len(phi_win))
    if mu < MU0 or norm(err) <= noise_floor: return theta    # 不可辨识 / 在死区
    return project(theta + ETA*update(err) - SIGMA*(theta - THETA0), OMEGA)

# IP-267 FSC：快估计 / 慢提交（L1 式）
theta_fast = adapt(theta_slow, ...)                          # 每步，服务异常检测
theta_slow = lowpass(theta_slow, theta_fast, W_C)            # 唯一可进 PGU 的量

# IP-268/269 ILM + SDR：把「独立」变成可测量
def leakage(graph):        return sum(norm_capacity(e) for e in graph.unauthorized_edges)
def diverse_agree(z1, z2): return norm(z1 - z2) <= TAU_AGREE

# IP-274 主闭环（提案 → 晋升 → 授权）
def AEGIS_round(M, obs):
    z1, z2 = M.enc1(obs), M.enc2(obs)                        # 不共享底座
    if not diverse_agree(z1, z2):
        M.snap.freeze('S_E'); M.snap.rollback('S_E'); alpha = 0.0
    else:
        alpha = M.aal.authority(M.ega.mu(), M.ilm.est(), M.sdr.integrity)
    theta_f = M.ega.adapt(M.s_e.calib, M.ega.window(), M.err)
    theta_s = M.fsc.commit(theta_f)                          # 有界瞬态
    p = M.spi.propose(theta_s, cap=M.cap_task)
    if not M.pgu.promote(p, M.sdr.witness, M.cap_task):
        M.snap.rollback('S_A'); alpha = 0.0
    if alpha < TAU_ALPHA:
        return R69_conservative(M, obs)                      # 逐指令退化
    k, lam, mode, u = FLUID_core(M, obs, theta_slow=theta_s) # R69 主体
    M.audit_sigma.submit(p, M.pgu.witness, M.ilm.trace, M.snap.root(), alpha)
    return k, lam, mode, u
```

## 4. 推导

**引理 19（无激励的适应即漂移）** `μ_PE<μ_0` 时该参数方向不可辨识，非零更新只把噪声/故障积分进参数；加入死区 + σ-修正后 `limsup‖θ−θ_0‖ ≤ (d_0+sup‖update‖)/σ`。系：R69 的「每观测必更新」在缓变故障下等价于把故障写进参数——吸收问题的第二条路径。

**引理 20（隔离抑制共模失效）** 单体下 `ρ≈1`、k 源错误率≈`δ_p`；隔离下同时欺骗 k 源需「各自独立攻破」或「泄漏路径」，故错误率 `≤ ∏δ_i + ℓ·δ_p`，真实相关 `ρ=ℓ^{1/(k−1)}`。系：引理 18 的上界第一次有可测依据。

**引理 21（污染半衰期与限幅）** 舱内注入误差 `γ≥σ/2` 指数衰减；跨舱仅经 PGU 且 `≤Δ_max`，总污染 `≤ Δ_max/(1−e^{−γΔt})`。系：「一次错、轮轮错」变「一次错、一次限幅」。

**定理 18（最终有界性）** `limsup‖e‖ ≤ (d_0+b_dist)/(1−ρ)+c·ℓ_ss`；`ℓ_ss→0` 且 PE 满足时收敛名义界，瞬态 `≤ k_1‖δ‖/ω_c`；内核每次改变 `≤Δ_max`。

**定理 19（严格包含 FLUID 与 R68）** `α=1` 且无晋升 ⇒ 等同 FLUID；`α=0` ⇒ 等同 R68；FSC 保证连续切换。只增加「有资格才适应」，不新增安全退化路径。

**定理 20（非干扰与可审计）** 无晋升事件时改写 `S_A` 不改变 `S_K` 轨迹；故内核轨迹可由晋升日志复现——把「信任算法」换成「审计边界」。

## 7. 本轮最大风险

**一句话**：AEGIS 的全部主张押在「隔离边界真的不泄漏」上——若两舱共享内存、时钟或编码器，或晋升门白名单过宽，隔离就只是剧场；**更危险的是，系统会因为「我持有 ℓ≤τ 的隔离证书」而授予更高的自适应权限 α，于是一次真实泄漏被系统自身的信心放大——会漏的隔离，比不隔离更危险，因为它替信任签了字。**

**次级风险与缓解**：开销击穿实时预算（分级隔离，异常才开双通道）；适应饥饿（最小探索预算 + 离线重放，线上冻结与线下学习分离）；回滚突变（bumpless + FSC 低通）；晋升门单点瓶颈（同验证等级实现 + 可复现日志）；快照陈旧（新鲜度入证书，过期快照只恢复估计态）。
