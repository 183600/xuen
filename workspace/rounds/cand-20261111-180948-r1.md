# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「续航能力」×「任务规划」）

> 第 54 轮把技能组合推进到动作空间剖面 α_S、组合图 G_S 与云边联合证书 J，解决了"动作对不对得上"的问题。本轮引入 **续航（能量）作为一等资源维度** 与 **资源约束下的任务规划**，回答"电够不够、回不回得来"。核心矛盾：H22：现有组合把所有鲁棒性维度都当作可由 meet 组合的质量，但续航是 **加性、不可逆、路径相关** 的资源，质量代数与资源代数混用会系统性高估可行性（续航幻觉）；H23：任务规划若不把返航/充电/电量储备当作一等任务节点，云端标称能耗与边端真实 SoC 的偏差会在执行后段集中爆发，形成"纸面可达、途中搁浅"。

## 0. 直觉与动机

**灵感 1（续航是轨迹泛函，不是标量属性）**
直觉：不能说"这个技能续航 30 分钟"，因为能耗取决于动作 `a`、负载、地形、温度。技能 `S` 应带有 **能量-动作剖面** `e_S(a)` 与 **再生剖面** `r_S(a)`。给定剩余电量 `B` 与安全储备 `B_res`，动作 `a` 可达当且仅当 `e_S^+(a)=max(0,e_S(a)-r_S(a)) ≤ B-B_res`。续航是沿动作轨迹积分出来的泛函，不是节点属性。

**灵感 2（质量代数与资源代数必须分离）**
直觉：第 54 轮的 `ρ` 组合用 `min`/meet，是"短板决定质量"；但能量是"累加决定余量"。把能量塞进 `ρ` 做 `min`，会得到"看起来很鲁棒、其实没电"的证书。正确做法：组合证书必须同时通过 **质量代数 `(𝔇,∧)`** 与 **资源代数 `(ℝ≥0,+)`**，任一失败即否决。这给出一个 **双代数分离原则**：质量维度可交换、可重试、按 meet 组合；资源维度单调、路径相关、按 sum 累积。

**灵感 3（任务规划 = 带资源的路径规划 + 返航/充电节点）**
直觉：续航把任务规划从最短路变成 **资源约束最短路（RCSP）**。把充电站/返航锚点作为一等节点，状态扩展为 `(技能, SoC 桶, 位置)`。规划不只问"能否完成任务"，还问"任一前缀失败时能否安全返航"。这就是 **reserve-aware planning**：任务目标从"抵达终点"升级为"全程可中止、可返航"。

**灵感 4（云标称、边真实：能量对账闭环）**
直觉：云端用期望能耗做全局规划，边端用 BMS 实时 SoC。二者偏差 `δ_e` 就是第 54 轮 `δ_a` 的能量类比。当 `δ_e` 超阈值或 `ρ_E` 跌破储备线，边端触发重规划，云端重解 RCSP。形成 **规划 - 对账 - 重规划** 的能量闭环，与第 54 轮的动作闭环正交叠加。

**灵感 5（续航是带不可逆公理的正交鲁棒维）**
直觉：把剩余续航比 `ρ_E=B/B_rated` 作为新维度，但它与其它维度不同：`ρ_E` 单调不增（除非充电），误差随步数累积，不能靠"重试/切换技能"恢复。因此迁移证书要区分 **可恢复维度**（多数质量鲁棒维）与 **不可恢复维度**（能量、时间、磨损），对后者采用保守资源预算而非概率 meet。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（能量-动作剖面）**
技能 `S` 在动作 `a∈A` 上的能耗 `e_S(a)≥0`、再生 `r_S(a)≥0`、时长 `τ_S(a)>0`，净能耗 `e_S^+(a)=max(0,e_S(a)-r_S(a))`，能耗方差 `σ_S²(a)`。能量-动作剖面 `ε_S = {(e_S,r_S,τ_S,σ_S²)(a) : a∈A}`。

**定义 122（续航可行域与续航包络）**
给定 SoC `B` 与安全储备 `B_res`：`Acct_E(S,B) = {a∈A : e_S^+(a) ≤ B - B_res}`。技能续航包络 `E_S(θ) = sup{E≥0 : P(success(S) | 能量预算 E) ≥ 1-θ}`。续航可行域是动作可行域 `Acct(S)` 在能量维上的切片：`Acct_E(S,B) ⊆ Acct(S)`。

**定义 123（双代数组合与组合 soundness）**
质量代数 `(𝔇,∧)`：`ρ_{S1⊗S2}(d)=ρ_{S1}(d)∧ρ_{S2}(d)`，逐维 meet。资源代数 `(ℝ≥0,+)`：`e^+(P)=Σ_i e^+_{S_i}(a_i) - Σ_i r_i`。技能序列 `P=⟨(S_1,a_1),...,(S_k,a_k)⟩` 的 **双代数组合 sound** 当且仅当：
```
(质量)  ρ(P) ⪰ ρ_min
(资源)  B_0 - Σ_i e^+_{S_i}(a_i) + Σ_i r_i ≥ B_res
(全程)  ∀k: B_k = B_0 - Σ_{i≤k} e^+ + Σ_{i≤k} r_i ≥ B_res
```
关键：质量条件可局部逐边检查，资源条件必须 **整链前缀检查**，二者不可互相替代。

**定义 124（能量增广状态图）**
`G_S^E = (V × 𝔅 × L, E_E)`，`𝔅` 为 SoC 离散桶，`L` 为位置/锚点集合（含充电站与安全返航点）。边 `(S_i,B,l) → (S_j,B',l')` 存在当 `B' = B - e^+_{S_i}(a) + r_i` 且 `B' ≥ B_res`；充电为锚点处的加电边 `B' = min(B_rated, B + charge(l,Δt))`。任务规划 = 在 `G_S^E` 上求满足任务动作序列的 RCSP 路径。

**定义 125（续航储备证书 ERC）**
`ERC(P) = (B_min, {M_abort(k)}, ε_e, ε_b, δ)`：
- `B_min = min_k B_k` 为全程最低 SoC；
- `M_abort(k)` 为从第 `k` 步位置返航到最近安全锚点的能量上界；
- `ε_e` 为单步能耗模型误差界，`ε_b` 为 SoC 估计误差界；
- `δ` 为允许搁浅概率。
`ERC` valid 当且仅当 `∀k: B_k - M_abort(k) ≥ B_res + m_k`，其中自适应余量 `m_k = ε_b + ε_e·√(2 n_k ln(2/δ))`。

**定义 126（能量对账契约 ERL）**
`ERL = (B_cloud, B_edge, δ_e, τ_replan)`，其中 `δ_e(t) = |B_cloud(t)-B_edge(t)| / B_rated`。当 `δ_e > Θ_e` 或 `ρ_E(t) < ρ_{E,min}` 或 `ERC` 余量告警时，触发 `replan(P) → P'`，并要求 `τ_replan ≤ τ_loop`。

**定义 127（续航鲁棒维与不可逆公理）**
`ρ_E(t) = B(t)/B_rated ∈ [0,1]`。不可逆公理：(i) 无充电时 `dρ_E/dt ≤ 0`；(ii) 估计误差单调累积 `|ρ̂_E-ρ_E| ≤ ε_b/B_rated + Σ_k |ε_e(a_k)|/B_rated`；(iii) 不存在"重试"算子可恢复 `ρ_E`（只能充电）。称满足 (i)-(iii) 的维度为 **不可逆资源维**，其余为 **可恢复质量维**。

**定义 128（任务规划能量闭环）**
任务 `T` 的规划问题为：
```
P* = argmin_{P∈Paths(G_S^E)} cost(P)
     s.t. 质量 sound(定义123) ∧ 资源 sound(定义123) ∧ ERC(P) valid(定义125)
```
解 `P*` 含技能序列、动作序列以及插入的充电/返航锚点序列。

## 2. 关键算法 伪代码

### IP-121 EAP（Energy-Action Profile）

```python
def energy_action_profile(skill, A, sim, n=64):
    prof = {}
    for a in A:
        samples = [sim.energy(skill, a) for _ in range(n)]
        prof[a] = EnergyEntry(
            e=mean(samples),
            r=mean(sim.regen(skill, a) for _ in range(n)),
            tau=mean(sim.time(skill, a) for _ in range(n)),
            var=variance(samples))
    return prof

def endurance_feasible(entry, B, B_res, k_sigma=2.0):
    return entry.e_net + k_sigma*sqrt(entry.var) <= B - B_res
```

### IP-122 EACG/RCSP（Energy-Aware Composition Graph + Resource-Constrained Shortest Path）

```python
def plan_endurance(task, G_E, B0, B_res, anchors, cfg):
    # 节点: (skill_id, soc_bucket, loc); 标签: (cost, soc, path)
    start = (task.start_skill, bucket(B0), task.start_loc)
    labels = {start: Label(cost=0.0, soc=B0, path=[])}
    pq = PriorityQueue([(0.0, start)])
    best = None
    while pq:
        cost, node = pq.pop()
        lbl = labels[node]
        if task.satisfied(lbl.path):
            if reserve_certificate(lbl.path, B0, cfg.eps_e, cfg.eps_b, cfg.delta).ok:
                best = lbl; break
            continue
        for e in G_E.out_edges(node):
            soc2 = lbl.soc - e.e_net + e.regen
            if soc2 < B_res:
                continue
            if e.is_charge:                       # 充电锚点
                soc2 = min(cfg.B_rated, soc2 + e.charge_amount)
            if not abort_reachable(e.to_loc, soc2, anchors, B_res):
                continue                           # 关键: 任一前缀可返航
            child = relax(lbl, e, soc2)
            if not dominated(child, labels.get(child.node)):
                labels[child.node] = child
                pq.push((child.cost, child.node))
    return best
```

### IP-123 ERC（Endurance Reserve Certificate）

```python
def reserve_certificate(P, B0, eps_e, eps_b, delta, B_res, anchors):
    B, Bmin, n = B0, B0, 0
    traces = []
    for step in P:
        n += 1
        B = B - step.e_net + step.regen
        m = eps_b + eps_e * sqrt(2.0 * n * log(2.0 / delta))   # Hoeffding 余量
        M_abort = abort_energy(step.loc, anchors)
        ok = (B - M_abort >= B_res + m)
        traces.append(Trace(n, B, M_abort, m, ok))
        if not ok:
            return CertResult('reject', 'reserve_violation', traces)
        Bmin = min(Bmin, B)
    return CertResult('ok', ERC(Bmin, traces, eps_e, eps_b, delta))
```

### IP-124 ERL（Energy Reconciliation Loop）

```python
def energy_reconcile(cloud_state, edge_state, cfg):
    delta_e = abs(cloud_state.soc - edge_state.soc) / cfg.B_rated
    rho_E = edge_state.soc / cfg.B_rated
    margin = edge_state.soc - abort_energy(edge_state.loc, cfg.anchors)
    if margin < cfg.B_res + cfg.margin_hard:
        return ('abort_to_safe', ERL(delta_e, rho_E, reason='hard_reserve'))
    if delta_e > cfg.Theta_e or rho_E < cfg.rho_E_min:
        return ('replan', ERL(delta_e, rho_E, reason='drift'))
    return ('ok', ERL(delta_e, rho_E))
```

### IP-125 ESA（Energy Separation Algebra）

```python
def compose_dual_algebra(seq, K, rho_min, B0, B_res):
    rho = reduce(meet, [s.rho for s in seq])
    e_net = sum(s.e_net for s in seq) - sum(s.regen for s in seq)
    if not all(rho[d] >= rho_min[d] for d in rho):
        return Reject('quality_fail', rho)          # 质量代数失败
    if B0 - e_net < B_res:
        return Reject('resource_fail', e_net)        # 资源代数失败
    return Accept(DualCert(rho=rho, e_net=e_net))
    # 不使用 min(rho_E): 资源维度必须走加法
```

### IP-126 ERT（Endurance-Robustness Transfer Certificate）

```python
def endurance_transfer(J_src, target_env, phi, delta_E_budget):
    soc_traj = predict_soc_trajectory(J_src, target_env, phi)
    if not monotone_nonincreasing(soc_traj):        # 不可逆公理校验
        return Reject('irreversibility_violation')
    delta_E = max(0.0, J_src.e_net - soc_traj.available)
    if delta_E > delta_E_budget:
        return Reject('energy_budget_exceeded', delta_E)
    return Accept(ERT(J_src, target_env, soc_traj, delta_E, phi))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| EAP | O(|S|·|A|·N_sim) | O(|S|·|A|) | 能耗采样无偏、方差收敛 |
| EACG/RCSP | O(|V|·|𝔅|·|L|·log(...)) 实践受 Pareto 支配剪枝 | O(|V|·|𝔅|·|L|) | 资源单调、标签支配 sound |
| ERC | O(|P|·|anchors|) | O(|P|) | 余量覆盖误差、前缀检查完备 |
| ERL | O(1)/tick，重规划 O(RCSP) | O(1) | δ_e 阈值、重规划收敛 |
| ESA | O(|S|·|𝔇|) | O(|𝔇|) | 两套代数都不被绕过 |
| ERT | O(|S|·|A|) | O(|S|) | 不可逆公理、预算闭合 |

**正确性定理（Endurance-Aware Planning Soundness）**
假设第 54 轮 (A22)-(A28) 成立；**(A29)** 单步能耗模型误差 `X_k = e_real - ê` 独立、零均值、`|X_k| ≤ ε_e`；**(A30)** BMS SoC 估计误差 `|X_b| ≤ ε_b`；**(A31)** 返航能量上界 `M_abort` 计算 sound。
若 `ERC` 采用自适应余量 `m_k = ε_b + ε_e√(2 n_k ln(2/δ))`，则对任意通过 `ERC` 的计划 `P`：
```
P(strand(P)) ≤ δ
```
证明：对每个前缀 `k`，能耗累积误差 `Σ_{i≤k} X_i` 是独立有界零均值变量之和。由 Hoeffding 不等式，
`P(|Σ_{i≤k} X_i| ≥ m_k) ≤ 2 exp(-m_k²/(2 n_k ε_e²)) = δ/n_k`。对全部 `n` 个前缀做 union bound，再用 (A30) 吸收 BMS 误差，得 `P(strand) ≤ δ`。∎
同时继承第 54 轮动作-鲁棒 soundness：只有当质量代数与资源代数 **同时** 通过时，组合才可部署。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 能耗模型有偏/分布漂移（温度、载荷、地形） | 高 | 在线能耗辨识 + 分层模型 + 分布鲁棒预算 |
| SoC 估计误差与电池老化（SOH 未知） | 高 | BMS 校准 + SOH 建模 + 硬阈值返航 |
| 自适应余量过度保守，任务成功率下降 | 中 | δ 可调 + 余量回收 + 任务价值加权 |
| 加性误差随任务链长度累积 | 高 | 分段返航锚点 + 最长链约束 + 中途对账 |
| 重规划震荡/频繁 abort | 中 | hysteresis + 最小提交间隔 + 冷启动锚点 |
| 充电节点排队/占用未建模 | 中 | 随机充电模型 + 保守服务时间上界 |

## 6. 本轮最大风险

**一句话**：续航方案的 soundness 完全压在"能耗模型无偏 + BMS SoC 可信"上；一旦温度、载荷、电池老化导致能耗模型系统性偏移，储备证书会同时产生"搁浅"与"过度保守"两类错误，且加性误差随任务链长度累积，故必须以 **在线能耗辨识 + 硬返航触发 + 分布鲁棒储备** 三重护栏，宁可少派任务，也绝不把标称能耗当成真实续航。

def energy_action_profile(skill, A, sim, n=64):
    prof = {}
    for a in A:
        samples = [sim.energy(skill, a) for _ in range(n)]
        prof[a] = EnergyEntry(
            e=mean(samples),
            r=mean(sim.regen(skill, a) for _ in range(n)),

            var=variance(samples))

def endurance_feasible(entry, B, B_res, k_sigma=2.0):
    return entry.e_net + k_sigma*sqrt(entry.var) <= B - B_res

### IP-122 EACG / RCSP

```python
def plan_endurance(task, G_E, B0, B_res, anchors, cfg):
    start = (task.start_skill, bucket(B0), task.start_loc)
    labels = {start: Label(cost=0.0, soc=B0, path=[])}
    pq = PriorityQueue([(0.0, start)])
    best = None
    while pq:
        cost, node = pq.pop()
        lbl = labels[node]
        if task.satisfied(lbl.path):
            if reserve_certificate(lbl.path, B0, cfg.eps_e, cfg.eps_b, cfg.delta).ok:
                best = lbl; break
            continue
        for e in G_E.out_edges(node):
            soc2 = lbl.soc - e.e_net + e.regen
            if soc2 < B_res: continue
            if e.is_charge:
                soc2 = min(cfg.B_rated, soc2 + e.charge_amount)
            if not abort_reachable(e.to_loc, soc2, anchors, B_res):
                continue                       # 任一前缀必须可安全返航
            child = relax(lbl, e, soc2)
            if not dominated(child, labels.get(child.node)):
                labels[child.node] = child
                pq.push((child.cost, child.node))
    return best
```

### IP-123 ERC

```python
def reserve_certificate(P, B0, eps_e, eps_b, delta, B_res, anchors):
    B, Bmin, n = B0, B0, 0
    traces = []
    for step in P:
        n += 1
        B = B - step.e_net + step.regen
        m = eps_b + eps_e * sqrt(2.0 * n * log(2.0 / delta))
        M_abort = abort_energy(step.loc, anchors)
        ok = (B - M_abort >= B_res + m)
        traces.append(Trace(n, B, M_abort, m, ok))
        if not ok:
            return CertResult('reject', 'reserve_violation', traces)
        Bmin = min(Bmin, B)
    return CertResult('ok', ERC(Bmin, traces, eps_e, eps_b, delta))
```

### IP-124 ERL

```python
def energy_reconcile(cloud_state, edge_state, cfg):
    delta_e = abs(cloud_state.soc - edge_state.soc) / cfg.B_rated
    rho_E = edge_state.soc / cfg.B_rated
    margin = edge_state.soc - abort_energy(edge_state.loc, cfg.anchors)
    if margin < cfg.B_res + cfg.margin_hard:
        return ('abort_to_safe', ERL(delta_e, rho_E, reason='hard_reserve'))
    if delta_e > cfg.Theta_e or rho_E < cfg.rho_E_min:
        return ('replan', ERL(delta_e, rho_E, reason='drift'))
    return ('ok', ERL(delta_e, rho_E))
```

### IP-125 ESA

```python
def compose_dual_algebra(seq, K, rho_min, B0, B_res):
    rho = reduce(meet, [s.rho for s in seq])                  # 质量代数
    e_net = sum(s.e_net for s in seq) - sum(s.regen for s in seq)  # 资源代数
    if not all(rho[d] >= rho_min[d] for d in rho):
        return Reject('quality_fail', rho)
    if B0 - e_net < B_res:
        return Reject('resource_fail', e_net)
    return Accept(DualCert(rho=rho, e_net=e_net))
```

### IP-126 ERT

```python
def endurance_transfer(J_src, target_env, phi, delta_E_budget):
    soc_traj = predict_soc_trajectory(J_src, target_env, phi)
    if not monotone_nonincreasing(soc_traj):
        return Reject('irreversibility_violation')
    delta_E = max(0.0, J_src.e_net - soc_traj.available)
    if delta_E > delta_E_budget:
        return Reject('energy_budget_exceeded', delta_E)
    return Accept(ERT(J_src, target_env, soc_traj, delta_E, phi))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| EAP | O(|S|·|A|·N_sim) | O(|S|·|A|) | 采样无偏、方差收敛 |
| EACG/RCSP | O(|V|·|𝔅|·|L|·log(...)) 实践经 Pareto 剪枝 | O(|V|·|𝔅|·|L|) | 资源单调、标签支配 sound |
| ERC | O(|P|·|anchors|) | O(|P|) | 余量覆盖误差、前缀检查完备 |
| ERL | O(1)/tick，重规划 O(RCSP) | O(1) | δ_e 阈值、重规划收敛 |
| ESA | O(|S|·|𝔇|) | O(|𝔇|) | 两套代数均不可绕过 |
| ERT | O(|S|·|A|) | O(|S|) | 不可逆公理、预算闭合 |

**正确性定理（Endurance-Aware Planning Soundness）**
假设第 54 轮 (A22)-(A28) 成立；**(A29)** 单步能耗误差 `X_k=e_real-ê` 独立、零均值、`|X_k|≤ε_e`；**(A30)** BMS SoC 误差 `|X_b|≤ε_b`；**(A31)** 返航能量上界 sound。
若 `ERC` 采用 `m_k=ε_b+ε_e√(2n_k ln(2/δ))`，则任意通过 `ERC` 的计划 `P` 满足：
```
P(strand(P)) ≤ δ
```
证明：对前缀 `k`，`Σ_{i≤k}X_i` 为独立有界零均值之和。Hoeffding 给出 `P(|Σ_{i≤k}X_i|≥m_k) ≤ 2exp(-m_k²/(2n_kε_e²)) = δ/n_k`。对全部前缀 union bound，再用 (A30) 吸收 BMS 误差即得。∎
并且只有当质量代数与资源代数 **同时** 通过时组合才可部署，杜绝"鲁棒但没电"的证书。

**推论（双代数分离必要性）**：存在技能序列使 `ρ(P)⪰ρ_min` 但 `e^+(P)>B_0-B_res`，因此仅用 `min` 组合的证书体系不可能 sound。

## 6. 本轮最大风险

**一句话**：续航方案的 soundness 完全压在"能耗模型无偏 + BMS SoC 可信"上；一旦温度、载荷、电池老化导致能耗模型系统性偏移，储备证书会同时产生"搁浅"与"过度保守"两类错误，且加性误差随任务链长度累积，故必须以 **在线能耗辨识 + 硬返航触发 + 分布鲁棒储备** 三重护栏，宁可少派任务，也绝不把标称能耗当成真实续航。
