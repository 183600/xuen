# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「视觉定位」×「视觉伺服」）

> R69 把不确定性一分为二（aleatoric / epistemic），用流匹配策略显式呈现模态、用主动交互消解歧义。但它自己点破的最大风险暴露了一个更深的结构问题：**R69 的所有"第二意见"仍然是学习出来的**——流密度是学的、模态权重是学的、问句来自冻结 LLM。当一个学习系统用另一个学习系统给自己作证，**同源偏差会一起错**，而"诚实的不知道"就被升级成"被证实的错误"。
>
> 本轮两个灵感补上的不是又一个学习模块，而是一条**非学习的度量锚**：
> - **视觉定位**给出 SE(3) 位姿与协方差，是独立于策略密度的"几何第二意见"；它的失效模式（感知混叠）与前两条通道（光度残差、行为似然）**正交**；
> - **视觉伺服**把 R69 抽象的"看/问/触"编译成**有 Lyapunov 证书的可执行过程**，并把"歧义是否可观测"变成交互矩阵条件数这一连续量。
>
> 核心命题：**在 R69 之上加一层"几何脊柱"——几何锚用于交叉校验与故障隔离，伺服用于认证地执行信息动作；但必须显式承认：伺服证书证明收敛，不证明正确。** 因此把风险拆成 R_safe（可证明不劣）与 R_task（不可证明，只能压低概率），并让层间退避成为严格塔。命名 **ANCHOR-RAS**（Active-localization, image-space-servoing, Certified-Homing, Observation-grounded Risk）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我到底在哪里、我的相对几何可不可信**」——不确定性不只是一句提问，也可以是一次有证书的注视与靠近；但**看得稳，不等于看得对**。

## 0. 直觉与动机

**灵感 1（视觉定位 → 一条不会"一起错"的度量通道）**
直觉：R69 的 FMA（流似然）是"行为自洽"检查，但行为自洽仍可能建立在错误的世界模型上——只要策略与观测被同一种偏差一致地污染，似然就不会报警。视觉定位提供的是**度量自洽**：地图、特征、PnP 几何验证构成一个与策略无关的约束系统。它的价值不在于"更准"，而在于**失效机制不同**：光度偏置能让残差归零，却很难让特征预测运动与实测运动的差分一致。这正是 R69 最需要的"第三种意见"。

**灵感 2（视觉伺服 → 信息动作从"选择"变成"可认证的收敛过程"）**
直觉：R69 的 MINT 只在**抽象层面**选一个信息动作 g，然后假设它安全被执行。但"凑近看"是一次真实的运动：可能越界、可能丢失特征、可能在不可观测方向上把噪声放大。IBVS 给了现成的严格工具——误差 e=s−s*，V=½‖e‖²，V̇=−λeᵀL_eL̂_e⁺e，只要 L_eL̂_e⁺ 正定就有指数收敛；条件数 κ(L_e) 直接量化"这个方向上到底能不能看清"。于是信息动作第一次可以带**运行时证书**，而不是只靠离线训练。

**灵感 3（条件数 ↔ 模态间距：同一个"可约性"的两种度量）**
直觉：R69 说"歧义越大、模态越分得开，交互越值钱"（引理 16），并用 Δ_min/σ_in 度量可分性。视觉伺服里完全同构：交互矩阵条件数 κ 越大，该方向上"移动一点产生的图像变化"越小，可观测性越差。把两者对齐，就得到一个统一的 **VoI_geo = 预期模态熵降 × 几何可观测性增益**：**不可观测的歧义不要动**——动只会用噪声驱动伺服，甚至漂到错误吸引域。这把 R69 的"值不值得问"精化为"**问得出来吗**"。

**灵感 4（三方残差 → 把"标定吸收"从两通道升级为可分离故障表）**
直觉：R68 有 r_res（传感器自洽），R69 有 Δa（行为自洽），R70 加 r_servo（差分几何自洽）。三者失效机制不同，于是可以列表分离：缓变标定故障被 COF 吸收 ⇒ r_res↓ 而 Δa↑；地图/特征几何错位 ⇒ r_servo↑ 而光度可正常；目标被换掉 ⇒ 三者可能都"正常"（**这正是 R70 唯一的新失败模式**）。故障隔离因此从"一个判据"升级为"一张判别表"。

**灵感 5（混叠是新的投毒面 → 证书会为错误背书）**
直觉：一旦系统相信视觉定位，就出现了新的攻击面：对抗性贴片让两个地点"看起来一样"、地图投毒、特征重放、动态目标冒充静态地标、伺服目标被替换。最危险的不是伺服发散——发散会被证书拦下；最危险的是**伺服完美收敛到一个假目标**。此时 Lyapunov 证书、视场约束、限幅全部为真，系统却自信地抵达错误的地方。**证书证明稳定，不证明正确；这正是 ANCHOR-RAS 必须把 R_task 与 R_safe 分开、并诚实承认 R_task 不可单调证明的原因。**

## 1. 形式化定义（增量：定义 310–324）

**定义 310（ANCHOR-RAS 总览）** ANCHOR-RAS = (VLoc, PAI, GUA, ISC, IAR, GCC, ACG, ALH, TGS, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i、R69 定义 293-i）；
(ii) **几何双源纪律**：任何用于任务级决策的锚必须由 ≥2 个独立几何源一致（地图检索验证、里程计/IMU 预测、伺服差分）；单源锚只允许驱动可逆、非安全关键动作；
(iii) **伺服纪律**：凡经 ISC 执行的信息动作必须携带 J_servo（Lyapunov 单调、κ 有界、视场/限幅/时窗满足），否则中止并降级；**J_servo 只证明稳定与约束，不证明目标身份**（显式写为限制，不伪装成不变式）；
(iv) **溯源纪律**：锚绑定地图/标定/时间戳版本（定义 324），版本不一致即作废。

**定义 311（VLoc 多假设定位）** 地图 ℳ、观测 o_t。外观检索返回候选 {(kf_i, s_i)}；对每个候选做 PnP/RANSAC 得位姿 ξ_i、内点数 inl_i、协方差 Σ_i。假设集 ℋ_t = {(ξ_i, w_i, Σ_i)}，w_i ∝ s_i·inl_i，归一化。若首位边际 (s_(1)−s_(2))/s_(1) 足够大且内点占比高，退化为点估计；否则保留多假设。定位异步运行（10–20Hz），发布带时间戳的锚，**不进入 R69 的 2.6ms 快环**。

**定义 312（感知混叠指数 PAI）** PAI = clip(1 − (s_(1)−s_(2))/τ_m, 0, 1) 与内点边际的合取度量。PAI 高 ⇒ **协方差不可信**：真实误差是 epi 的（可能整栋楼都错），却表现为小的 ale 协方差——这是"epistemic 藏在 aleatoric 里"的度量版。

**定义 313（几何不确定性二分 GUA）** U_geo,ale = Σ_i w_i tr(Π_task Σ_i Π_taskᵀ)（任务相关子空间内的不可约噪声）；U_geo,epi = H(w)·sep_Maha(ℋ)（假设间马氏可分性，越大越可约，可由移动/换视角消解）。**交叉一致性**：R69 的 U_epi（动作模态）与 U_geo,epi（位姿假设）应同向变化；持续背离即为故障信号（定义 318）。

**定义 314（IBVS 伺服 ISC）** 图像特征 s(o)∈ℝ^k，期望 s*。ṡ = L_e v，L_e 为交互矩阵。控制 v = −λ L̂_e⁺ e，e = s − s*，V = ½eᵀe。若 L_eL̂_e⁺ ⪰ μI，则 V̇ ≤ −λμ V（指数下降）。κ(L_e) 为可观测性度量。κ 超阈时切换同构/单应（homography）或降自由度（如先对准再测深），避免在不可观测方向上放大噪声。

**定义 315（伺服证书 J_servo）** J_servo = (下降率下界 μ_min, κ_max, 稳态残差上界 ε_servo, 视场裕度, 速度/加速度限幅, 时窗, feature_id, target_hash)。Certified ⇔ 执行期间逐步满足全部条目；任一违反 ⇒ ABORT。**注意：target_hash 只绑定"我瞄准的是哪个图像目标"，不绑定"它是世界里的哪个东西"。**

**定义 316（信息动作编译 IAR）** R69 的 g = (g_gaze, g_probe, g_ask) 被编译为可执行伺服：g_gaze → 期望特征 s*_gaze（把 ROI 移到图像中心并达到目标尺度/清晰度）；g_probe → 沿指定方向的 s* 序列 + 力/位限幅；g_ask 保持冻结 LLM 解码不变。编译产物 = (s* 轨迹, J_servo 模板)。

**定义 317（几何交叉校验 GCC 与三方故障隔离）** r_servo = s_obs(t+1) − ŝ_pred(ξ_t, v_t)，预测用交互矩阵。三方残差向量 (r_res, Δa, r_servo)。隔离表：
- (↓, ↑, →)：缓变标定被吸收（R68/R69 已覆盖）；
- (→, →, ↑)：地图/几何错位或特征关联错（R70 新检出）；
- (→, →, →) 但任务失败：**目标身份错误**（R70 唯一新失败模式，必须靠双源纪律与时间一致性拦截）；
- (↑, →, →)：纯传感器噪声，走 R68。

**定义 318（锚一致性门 ACG）** 若 PAI > τ_pai、首位边际 < τ_m、或 (VLoc 自称高置信 ∧ r_servo > τ_s)，判定为 **confident-but-wrong 疑似**：锚作废、任务级决策退回 R69；若交互预算允许，触发定义 319。

**定义 319（混叠感知归位 ALH）** 在可达视点集合中选 g 使期望 \u0394H(ℋ) − c(g) 最大，且 g 必须可由定义 314 认证执行。**关键限制**：若所有候选视点在图像上投影相同（如对称走廊、重复纹理），则该混叠**由看不可解**——声明"几何不可观测"，不得用更多伺服硬凑，必须转语义/交互通道（R69）或直接保守。

**定义 320（多假设几何状态估计 TGS）** SE(3) 上的可切换多假设滤波（多假设 EKF/粒子）。假设出生/消亡由新息跳变驱动；绑架检测用 χ² 新息检验；回环闭合作为全局约束。输出供 GCC/ACG 使用，并维护假设级溯源。

**定义 321（威胁模型 ℰ_geo）** 对抗性混叠贴片、地图投毒与版本回滚、视觉特征重放/重演攻击、动态物体冒充静态地标、**伺服目标替换**（把 s* 对应的世界目标换掉）、特征遮挡/丢失。并入 AIC：ℰ_ANCHOR = ℰ_FLUID × ℰ_geo。

**定义 322（证书 J_ANCHOR）** J_ANCHOR = (J_FLUID, PAI_p95, κ_servo_p95, μ_min, r_servo_p95, anchor_sources, H_geo, aliasing_events, map_ver, geo_ver)。Valid ⇔ Valid(J_FLUID) ∧ 双源纪律满足 ∧ 所用伺服均 Certified ∧ 溯源一致。

**定义 323（三层退避塔）** L0 ANCHOR：锚一致 ∧ 伺服认证 → 沿用 R69 的 resolution bonus（λ = λ_floor(U_ale)），并用几何证据选模态；L1 FLUID：几何层缺失/不可信 → 逐指令退化为 R69；L2 R68：R69 的 VoI/ECE 也失败 → 纯保守 λ_floor(U_ale+U_epi)。**安全包络全程由 C-RAS-WM 独立把关，不因进入 L0 而放宽。**

**定义 324（几何锚版本与溯源）** anchor = (ξ, Σ, map_ver, calib_ver, t, source_ids, target_hash)。map/calib 版本不匹配、时间戳过期、source_ids 少于 2 且动作为不可逆 ⇒ 锚作废。

## 2. 关键算法骨架

```python
# IP-264 VLoc：多假设视觉定位（异步 10–20Hz，不进 R69 快环）
class VisualLocalizer:
    def __init__(self, map_db, pnp, verifier):
        self.db, self.pnp, self.verifier = map_db, pnp, verifier

    def localize(self, o_t):
        hyps = []
        for kf, s in self.db.retrieve(o_t, topk=5):        # 外观检索
            xi, inl, cov = self.pnp(o_t, kf)               # PnP + RANSAC
            if inl > TAU_INL:
                hyps.append(Hyp(xi, w=s * inl, Sigma=cov, kf=kf))
        return normalize_weights(hyps)                     # ℋ_t

# IP-265/266 PAI + GUA：混叠指数与几何二分
def geometric_ambiguity(hyps, task_proj):
    ws = sorted([h.w for h in hyps], reverse=True)
    margin = (ws[0] - ws[1]) / max(ws[0], 1e-9) if len(ws) > 1 else 1.0
    pai = clip(1.0 - margin / TAU_M, 0.0, 1.0)
    U_ale = sum(h.w * trace(task_proj @ h.Sigma @ task_proj.T) for h in hyps)
    U_epi = entropy([h.w for h in hyps]) * sep_maha(hyps)
    return pai, U_ale, U_epi

# IP-267/268 ISC：IBVS + 运行时证书（每个控制步都验证）
def servo_to(s_star, o, lim, target_hash):
    for step in range(MAX_STEPS):
        s = feature(o); e = s - s_star
        L = interaction_matrix(s); kappa = cond(L)
        if kappa > KAPPA_MAX:            return ABORT_ILL_CONDITIONED
        v = clip_limits(-LAM * pinv(L) @ e, lim)
        before = 0.5 * e @ e
        o = execute(v)                                   # 物理执行一步
        e2 = feature(o) - s_star
        if 0.5 * e2 @ e2 > before * (1 - MU_MIN * DT):   return ABORT_NO_DESCENT
        if not in_fov(o):                return ABORT_FOV
    ok = norm(e2) < EPS_SERVO
    return Cert(ok, kappa, target_hash, mu=MU_MIN)

# IP-269 IAR：把 R69 的抽象信息动作编译为认证伺服
def compile_info_action(g, hyps):
    if g.kind == 'gaze':  s_star = roi_to_center_scale(hyps, g.g_gaze)
    if g.kind == 'probe': s_star = probe_waypoints(g.g_probe)
    if g.kind == 'ask':   return DecodeLLM(g.g_ask)      # 语义通道不变
    return ServoTarget(s_star, J_servo_template(g))

# IP-270/271 GCC + ACG + ALH
def geometric_guard(M, obs, r_res, a_hat):
    hyps = M.vloc.latest(obs.t)
    pai, U_gae, U_gep = geometric_ambiguity(hyps, M.task_proj)
    r_servo = obs.s_next - predict_features(M.last_anchor, M.last_cmd)
    fault = isolate_table(r_res, a_hat, r_servo)          # 定义 317
    confident_wrong = (pai > TAU_PAI) or (fault == 'IDENTITY_SUSPECT')
    return dict(hyps=hyps, pai=pai, r_servo=r_servo,
                anchor_ok=(not confident_wrong and two_source(hyps, obs)),
                fault=fault)

# IP-274 主闭环：三层退避塔（L0 ANCHOR / L1 FLUID / L2 R68）
def ANCHOR_RAS_round(M, obs):
    G = geometric_guard(M, obs, M.last_r_res, M.last_a_score)
    # 1) 继承 R69：流匹配 → 模态二分
    z, o = M.mtm.forward(obs)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    # 2) 是否值得交互（VoI 并入几何可观测性）
    g = M.mint.choose_interaction(modes, o, M.budget,
                                  geo_gain=G['U_gep'] if G['anchor_ok'] else 0.0)
    cert_ok = False
    if g is not None and G['anchor_ok'] and g.kind != 'ask':
        st = M.iar.compile(g, G['hyps'])                 # 信息动作 → 图像目标
        c  = M.isc.execute_certified(st)                 # 物理执行 + J_servo
        cert_ok = c.ok
        if not cert_ok: g = None                         # 伺服不过 ⇒ 不交互
    elif g is not None and not G['anchor_ok']:
        g = M.alh.maybe_homing(G['hyps'], M.budget)      # 混叠归位；不可观测则 None
    # 3) 三层退避
    if G['anchor_ok'] and (g is None or cert_ok):
        level = 0                                        # ANCHOR：几何证据助选模态
        U_floor = U_ale + (U_epi if g is None else 0.0)
    elif not G['anchor_ok'] or G['fault'] in ('FLUID_OK',):
        level = 1                                        # FLUID：逐指令退 R69
        U_floor = U_ale + (U_epi if g is None else 0.0)
    else:
        level = 2                                        # R68：纯保守
        U_floor = U_ale + U_epi
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if level == 2: lam = max(lam, 0.8)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., M.wm_preds)  # 安全包络不变
    mode = select_mode(modes, U_epi, lam, geo_hint=G['hyps'] if level == 0 else None)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_i.submit_async(g, G, level, cert_ok)
    return k, lam, mode, (U_ale, U_epi, level)
```

## 3. 推导

**引理 19（伺服稳定与有界收敛）** 设 L̂_e 为交互矩阵估计，若存在 μ>0 使 L_eL̂_e⁺ ⪰ μI 且 ‖L̂_e⁺‖ 有界，则 V̇ ≤ −λμV，故 ‖e(t)‖ ≤ ‖e(0)‖e^{−λμt/2}；含测量噪声 η 时稳态残差 ‖e‖_∞ ≤ ‖L̂_e⁺‖‖η‖/(λμ)+O(η²)。系：**κ(L_e) 大 ⇒ μ 小 ⇒ 收敛慢且残差放大**，故高 κ 时"多看"是劣性投入，应降自由度或换观测构型。

**引理 20（混叠条件下的协方差失信）** 设候选地点外观分 s_(1),s_(2)，几何验证内点率足够高使错误候选仍可"通过"验证（对抗或重复结构），则 PAI 高时真实位姿误差不以其协方差为上界：E[‖ξ̂−ξ*‖²] ≥ c·(1−PAI)·tr(Σ) + PAI·D_geo²，其中 D_geo 为错误假设与真值的度量距离。系：**在多假设场景把多峰后验压成单高斯，就是把 U_geo,epi 伪装成 U_geo,ale**——与 R68 "缓变故障被标定吸收"结构同源。

**引理 21（几何通道的标定不可吸收性）** 设光度标定可吸收偏置 b_photo 使 r_res→0，但差分几何残差 r_servo = J_geo δξ + η_geo 只依赖相对位姿误差 δξ 与特征关联，不被 b_photo 吸收。若地图/关联正确，E[r_servo] ≥ c‖δξ‖ − √(trΣ_feat)；故 **(r_res↓, Δa↑, r_servo↑) 是"标定吸收 + 几何错位"的可分签名**，把 R69 引理 17 的两通道判据升级为三通道可分离表。

**引理 22（退避塔的 R_safe 单调性）** 定义 R_safe 为约束违反率。三层塔中安全包络始终由 C-RAS-WM 的 certified_prefix 独立把关，且 L0→L1→L2 只单调收紧 λ、不放松 k，故对任意状态 R_safe(L0) ≤ R_safe(L1) ≤ R_safe(L2)。**但 R_task 不满足该链**：L0 多出的几何证据与认证伺服可提升任务成功率，**也可能在错误锚下自信地降低它**（见定理 19）。

**定理 18（ANCHOR 严格包含 FLUID）** 在 A95–A100 下，当 PAI>τ_pai、伺服证书失败、双源不满足或溯源不一致时，ANCHOR 逐指令退化为 FLUID（定义 318、323），故 R_safe(ANCHOR) ≤ R_safe(FLUID) ≤ R_safe(R68)，且退化边界上行为差 = 0；安全侧不做任何让步。

**定理 19（confident-but-wrong 的不可消除性与可压低性）** 存在对抗性混叠使 J_servo 全部为真、J_ANCHOR 的双源纪律仍被满足（若攻击者同时伪造地图检索与差分几何），此时 ANCHOR 以高概率收敛到错误目标，R_task 可劣于 R69。采用"各源欺骗相关 ρ<1 + 单帧不建全局锚 + 时间一致性 χ² 检验"后，错误锚通过率 ≤ δ_geo·ρ^{k−1}+ε_map（k=几何源数）。**结论：R_safe 可证、R_task 不可证，只能定量压低——这是本层的诚实边界。**

5. **俯瞰式过度自信**（把覆盖误当认知）→ J_ANCHOR 记录 aliasing_events 与 anchor_sources，审计可回放，不允许单源锚驱动不可逆动作。

```python
# IP-264 VLoc：多假设定位（异步 10–20Hz）
def localize(o, db, pnp):
    hyps = []
    for kf, s in db.retrieve(o, topk=5):
        xi, inl, cov = pnp(o, kf)                  # PnP + RANSAC
        if inl > TAU_INL: hyps.append(Hyp(xi, s*inl, cov))
    return normalize_weights(hyps)                 # ℋ_t

# IP-265/266 PAI + GUA
def g_ambiguity(hyps, P):
    ws = sorted([h.w for h in hyps], reverse=True)
    m  = (ws[0]-ws[1])/max(ws[0],1e-9) if len(ws) > 1 else 1.0
    pai   = clip(1 - m/TAU_M, 0, 1)
    U_ale = sum(h.w*trace(P@h.Sigma@P.T) for h in hyps)
    U_epi = entropy([h.w for h in hyps]) * sep_maha(hyps)
    return pai, U_ale, U_epi

# IP-267/268 ISC：IBVS + 逐步证书
def servo_to(s_star, o, lim, th):
    for _ in range(MAX_STEPS):
        e = feature(o) - s_star; L = interaction_matrix(feature(o))
        if cond(L) > KAPPA_MAX: return ABORT_ILL_CONDITIONED
        v = clip_limits(-LAM * pinv(L) @ e, lim)
        b = 0.5*e@e; o = execute(v); e2 = feature(o)-s_star
        if 0.5*e2@e2 > b*(1 - MU_MIN*DT): return ABORT_NO_DESCENT
        if not in_fov(o): return ABORT_FOV
    return Cert(norm(e2) < EPS_SERVO, cond(L), th)
```

## 4. 推导

**引理 19（伺服稳定与有界收敛）** 若 `L_eL̂_e⁺ ⪰ μI` 且 `‖L̂_e⁺‖` 有界，则 `V̇ ≤ −λμV`，`‖e(t)‖ ≤ ‖e(0)‖e^{−λμt/2}`；含噪声 η 时稳态残差 `≤ ‖L̂_e⁺‖‖η‖/(λμ)+O(η²)`。系：高 κ ⇒ μ 小 ⇒ 收敛慢、残差放大，"多看"成为劣性投入。

**引理 20（混叠下协方差失信）** PAI 高时 `E‖ξ̂−ξ*‖² ≥ c(1−PAI)tr(Σ)+PAI·D_geo²`；把多峰后验压成单高斯，等于把 `U_geo,epi` 伪装成 `U_geo,ale`（与 R68 的"标定吸收"同构）。

**引理 21（几何通道标定不可吸收）** 光度偏置使 `r_res→0` 不改变 `r_servo=J_geoδξ+η_geo`；若地图/关联正确，`E[r_servo] ≥ c‖δξ‖−√(trΣ_feat)`。故 `(r_res↓, Δa↑, r_servo↑)` 是"标定吸收 + 几何错位"的可分签名，把 R69 两通道判据升级为三通道隔离表。

**引理 22（塔的 R_safe 单调性）** 安全包络始终由 `certified_prefix` 独立把关，L0→L1→L2 只单调收紧 λ、不放松 k，故 `R_safe(L0) ≤ R_safe(L1) ≤ R_safe(L2)`。**但 R_task 不满足该链**。

**定理 18（ANCHOR 严格包含 FLUID）** 当 `PAI>τ_pai`、伺服证书失败、双源不满足或溯源不一致时，ANCHOR 逐指令退化为 FLUID；故 `R_safe(ANCHOR) ≤ R_safe(FLUID) ≤ R_safe(R68)`，退化边界行为差 = 0。

**定理 19（confident-but-wrong 不可消除、可压低）** 存在对抗性混叠使 J_servo 全真、双源亦被同时伪造，则 ANCHOR 可稳定抵达错误目标，`R_task` 可劣于 R69；采用 `ρ<1` 的多源 + 单帧不建全局锚 + 时间一致性 χ² 后，错误锚通过率 `≤ δ_geo·ρ^{k−1}+ε_map`。**R_safe 可证、R_task 不可证，只能定量压低——本层的诚实边界。**

## 7. 本轮最大风险

**一句话**：ANCHOR-RAS 新增的失败模式不是碰撞，而是 **confident-but-wrong**——**感知混叠/地图投毒会给出协方差很小、几何验证通过、伺服证书全真的错误锚，系统于是"可证明地、平滑地、稳定地"抵达错误的地方；伺服证书证明收敛而非正确，证书本身会为错误背书**——看不准并稳稳抵达，比不看更危险。

**次级风险与缓解**：不可观测方向被放大（高 κ ⇒ 降自由度/切同构 + "不可观测就不动"）；地图/标定版本错配（定义 324 溯源）；对抗混叠与重放（双源 + 时间 χ² + ℰ_geo 训练，定理 19）；几何层拖垮实时（异步多速率、锚带时间戳、快环不变）；俯瞰式过度自信（J_ANCHOR 记录 aliasing_events/anchor_sources，单源锚不得驱动不可逆动作）。
