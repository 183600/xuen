# 第 4 轮（灵感循环第 4 轮；本轮灵感：「用户体验」×「状态机」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**可观测性升级 + 严格退化**。用户体验与状态机都只增加「人类可理解性」与「运行时可验证性」，不改变物理可行域、不改变 50Hz 主路径；任一 UX/状态机组件不可用都必须退回 InstructGauge 的结构化事件日志。

## 0. 直觉与动机

**灵感 1（用户体验 = 可预测的交互契约，而不是界面美化）**
直觉：操作员真正“体验”到的不是内部证书、共形分位数或 VLA 前向，而是三件事：**现在能不能动**、**刚才为什么动**、**出问题时我能不能立刻停下**。所以 UX 的正确研究对象不是视觉样式，而是“内部状态 → 用户可见状态”的**投影是否诚实**。一个漂亮的界面如果让用户在长块执行期间误以为系统空闲，就是负 UX；反过来，一个朴素但把「不可逆动作进行中 / 证据已陈旧 / 已进入隔离」实时说清楚的界面，才是安全 UX。UX 因此不是末端皮肤，而是控制闭环里一条**可审计的证据通道**。

**灵感 2（状态机 = 把“模式混淆”变成可验证对象）**
直觉：机器人在接地、规划、执行块、复核、校准、隔离、排空之间切换；用户脑中也有一台“我以为它在干什么”的状态机。事故往往不是某个组件坏，而是**两台状态机不同步**——用户按下“开始”时系统其实还在 drain 上一块，或者用户以为可以撤销，实际已跨过不可逆屏障。把内部控制器显式写成层次状态机，再把用户界面写成它的一个**商状态机（quotient）**，就能把“模式混淆”从主观抱怨变成可模型检查、可运行时监视、可实验证伪的性质。

**灵感 3（两者耦合 = 可见状态必须是安全相关状态的忠实投影）**
直觉：状态机不是为了给用户看全部细节，而是为了**该藏的藏、该露的必须露**。耦合原则是“安全相关不可隐藏，认知负担可折叠”：不可逆动作、故障、隔离、证据过期、权限不足这些标签在投影中必须保留（否则就是“说谎的界面”）；而证书编号、共形分位、漂移数值可以折叠进“详情”。于是 UX 层的核心命题应是：**用户看到的每一条状态迁移都由内部真实迁移支撑，且每一条安全警报都不会被折叠掉**。这正是把“用户信任”从主观感受变成可证明契约的地方。

## 1. 研究问题（本轮要回答什么）

- **Q1（投影诚实性）**：能否用状态机商/抽象严格定义“界面不撒谎”，并把模式混淆变成可测指标，而不是问卷里的一句“感觉有点难用”？
- **Q2（可供性正确性）**：用户界面上“可点的按钮”是否恰好等于当前守卫允许的动作？如何做到既不展示“死按钮”（点了必失败），又不隐藏“逃生按钮”（停止/中止/暂停）？
- **Q3（非干扰与退化）**：增加 UX/状态机层是否改变控制行为与实时性？在 UX 组件失效时能否逐级退回，且退回过程中界面仍诚实报告“已降级”？

## 2. 三条设计原则（雏形，正式化见产物区定义 448–462）

**P1 安全相关投影不可隐藏（Safety-Relevant Projection）**
用户可见状态是内部状态的一个商，但 `不可逆动作在途`、`故障`、`隔离`、`证据过期`、`权限不足`、`已降级` 这些标签在投影中必须保留。可以合并“接地中/规划中”为“准备中”，但绝不可以把“不可逆执行中”合并进“就绪”。这条给出“界面不撒谎”的类型级约束。

**P2 诚实可供性（Honest Affordance）**
界面上展示的可用动作集 `Shown(q)` 必须满足两条非对称条件：`Shown ⊆ Exec`（只要展示就真能执行，杜绝死按钮）；对逃生动作集 `Escape`（停止/中止/暂停），`Exec ∩ Escape ⊆ Shown`（只要真能停，就必须让用户看得到停）。允许隐藏无关紧要的动作，绝不允许隐藏逃生通道。

**P3 唯一权威 + 纯观察（Single Source of Truth + Read-Only UX）**
内部状态机是唯一权威；UX 层只读取带序号的状态快照，并通过受限命令网关提交请求。UX 不能直接改控制器内部变量，不能绕过守卫，不能“乐观地”先显示成功。撤销只对可逆类开放；不可逆类只提供“执行前确认”和“执行中停止”，不提供任何事后 undo 幻觉。

## 3. 与基线的接口（如何退化）

- UX 状态机不可用 ⇒ 退回 InstructGauge 的结构化事件日志（仍逐事件可审计）；
- 模式混淆监视器不可用 ⇒ 使用静态投影（P1 的标签不可隐藏仍然生效）；
- 撤销/补偿组件不可用 ⇒ 一律不提供撤销（安全默认，绝不假装可撤销）；
- 多操作者仲裁不可用 ⇒ 单操作者 + 全局互斥锁；
- 显示层不可用 ⇒ 控制继续运行，但所有用户命令一律需要显式回执确认；
- InstructGauge 失效 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个「UX = 控制状态机的安全相关商」的形式化，使模式混淆可模型检查、可运行时监视；
2. 一个诚实可供性代数与逃生完备性判据，系统性消除死按钮与“隐藏的停止”；
3. 一个证据新鲜度/覆盖率的诚实显示契约，把“看起来可信”与“实际可信”对齐；
4. 一个与可逆类绑定的撤销/补偿/确认门控交互安全层，以及带 lease/epoch 的多操作者命令仲裁；
5. 一条完整可证伪路径：E457–E474 覆盖投影等价、可供性、模式混淆、用户研究、撤销正确性、时序、非干扰、降级与对抗 UI 注入。

## 5. 本轮最大风险

**一句话**：如果投影 `π` 把某个安全相关状态错误地折叠进“就绪”，系统会得到一个“看起来完全可信、实际在撒谎”的界面——这比没有界面更危险，因为它会把人的判断变成对错误的背书。

## 2. 形式化定义（要点）

**定义 448（内部控制器状态机 M）** `M = (Q, q₀, Σ, →, AP, L)`，其中 `Σ = Σ_int ⊎ Σ_cmd` 分别表示内部自动迁移与外部命令；`L: Q → 2^AP` 给出状态标签，`AP ⊇ AP_safe`。安全盾、CVC、Barrier、P-Quarantine 均实现为 `→` 上的守卫，任何迁移都不绕过它们。

**定义 449（用户可见状态机 U）** `U = (Q_U, q₀ᵁ, Σ_U, →_U, Aff, msg)`，`Aff: Q_U → 2^{Σ_U}` 为界面上展示的可用动作，`msg` 为每个可见状态附带的解释模板（目标、证据年龄、覆盖、下一步）。

**定义 450（安全相关投影 π）** 满射 `π: Q ↠ Q_U`，动作映射 `vis: Σ → Σ_U ∪ {τ}`，标签映射 `λ: AP → AP_U ∪ {τ}`，满足：
- (C1) `π(q₀) = q₀ᵁ`；
- (C2) 对任一内部迁移 `q --σ--> q'`：若 `vis(σ) = τ` 则 `π(q) = π(q')`；否则 `π(q) --vis(σ)-->_U π(q')` 必须存在；
- (C3) 标签保持：`∀ ℓ ∈ AP_safe, λ(ℓ) ≠ τ`，且 `ℓ ∈ L(q) ⇒ λ(ℓ) ∈ L_U(π(q))`；
- (C4) 无幻影迁移：每条 `q_U --a-->_U q_U'` 至少有一个内部迁移见证；
- (C5) 静默点与排空显式可见：`q_quiesce` 不折叠进 `Ready`，`Draining` 不被折叠进 `Executing`。

满足 (C1)–(C5) 的 `π` 称为**诚实商（honest quotient）**。

**定义 451（投影诚实性 / no-lying）** 对任意内部轨迹 `ρ = q₀ --σ₁--> q₁ --σ₂--> …`，其像 `π(ρ)` 是 `U` 的合法轨迹，且 `L` 中每个安全标签都在 `π(ρ)` 的对应位置出现。等价说法：内部轨迹集合的像包含于 `U` 的轨迹集合，且安全标签序列被逐点保持。违反任一条件即“界面撒谎”。

**定义 452（模式混淆事件与指标）** 给定观测历史 `o_{0:t}`，信念集 `B_t = { q ∈ Q : q 与 o_{0:t} 一致 }`。用户假设状态 `h_t ∈ Q_U`（由其操作序列与界面读数推断）。若 `h_t ∉ π(B_t)`，记一次模式混淆。回合指标：
`D_MC = (1/T) Σ_{t=1}^{T} 1[h_t ∉ π(B_t)]`，
消歧时延 `τ_dis = t_{disambiguate} − t_{confusion}`；另记“意外率” `Surprise = 1[可见轨迹 ∉ traces(H_hat)]`。

**定义 453（诚实可供性与逃生完备性）** `Exec(q) = { a ∈ Σ_cmd : ∃ q', q --a--> q' }`；`Shown(q) = Aff(π(q))`。要求：
- **可靠性（无死按钮）**：`Shown(q) ⊆ Exec(q)`；
- **逃生完备性**：`Escape = {stop, abort, pause}`，`Exec(q) ∩ Escape ⊆ Shown(q)`；
- **可解释性**：每个 `a ∈ Shown(q)` 附 `explain(a,q)`，返回使其使能的最小前置条件。
`Shown ⊄ Exec` 的部分称为死按钮（dead affordance），必须为 0。

**定义 454（证据年龄 / 覆盖 / 漂移的诚实显示）** 显示时刻 `t` 的信念 `b` 对应 `τ = t − t_last_receipt(b)`、共形覆盖 `1−α`、漂移残差 `δ`。显示元组 `D(t) = (τ̂, α̂, δ̂)` 诚实当且仅当 `τ̂ = τ`、`α̂ = α`、`δ̂ = δ`（允许量化误差）；任一量暂不可得时显示 `unknown`，**禁止用 0 或旧值冒充**。

**定义 455（可逆类与撤销契约）** `class: A → {R0, R1, R2}`。`Undo(a)` 仅对 `R0` 定义；`R1` 提供 `Compensate(a)` 并显式给出补偿代价 `c_comp`；`R2` 只提供 `StopBefore(a)` 与同意门控，**禁止**在界面出现“撤销”字样。形式化约束：`undo offered ⇒ class(a)=R0`。

**定义 456（时间到真值与可见延迟）** 对安全相关事件 `e`，`T_truth(e) = t_visible(e) − t_occur(e)`。要求 `p99(T_truth) ≤ T_budget`（默认 100ms，硬上限一个 UI 刷新周期加一次调度抖动）。状态快照带单调递增 `seq`，显示端拒绝乱序与撕裂快照。

**定义 457（用户心智模型与轨迹包含）** 心智模型 `H` 为 `Q_U` 上的状态机；若 `traces(U) ⊆ traces(H)`（允许 stutter），称 `H` 对 `U` **充分**。在线用命令序列估计 `H_hat`；`Surprise` 即观测到 `H_hat` 未预测的可见迁移。

**定义 458（注意力预算与通知分级）** 每条非安全通知有代价 `c_n`；单位时间非安全通知总量受 `B_attn` 限制。安全相关通知（`AP_safe` 标签变化）**不占用**该预算且不得被限流。目标：在保持安全通知零遗漏的前提下最小化 `Σ c_n`。

**定义 459（同意令牌与租约）** `κ = (a, chunk_id, epoch, expiry)`。`κ` 有效当且仅当 `epoch = current_epoch ∧ now ≤ expiry ∧ chunk_id` 与在途块一致。旧 epoch 的同意一律丢弃，防止“用户同意的是上一块”的陈旧授权。

**定义 460（非干扰 / UX 纯观察）** 设 `M` 为无 UX 观察者的控制器，`M^UX` 为带 UX 观察者的同一控制器。要求控制标签上的轨迹逐点相等：`trace_ctrl(M^UX) = trace_ctrl(M)`。UX 命令网关只能**限制**命令集（`Exec^UX ⊆ Exec`），不能新增动作；因此 `M^UX` 是 `M` 的精化（refinement），不是替代。

**定义 461（UXGauge-8C 闭环）** `U→I→H→C→E→C→V→U`：前一个 `U` 表示用户意图/心智假设进入接地，后一个 `U` 表示可见状态/证据更新回到用户；`I/H/C/E/C/V` 完全复用 InstructGauge 的接地、假设、分块、执行、块证书、校准。

**定义 462（交互审计证书 UXCert）** `UXCert = (visible_trace, projection_witness, affordance_log, confusion_events, latency_hist, consent_tokens)`，使审计者能沿“用户看到什么 → 内部发生了什么 → 为什么允许”三级链条复现一次交互。

TRANS = {

# IP-329 SRP：安全相关投影
class Projector:
    SAFE_LABELS = {"irr_inflight", "fault", "quarantined", "stale",
                   "degraded", "consent_required", "barrier"}
    def project(self, q):
        q_u = self.fold(q)                       # Grounding/Planning → Preparing 等
        labels = {l for l in q.labels if l in self.SAFE_LABELS}
        if q.evidence_age > q.tau_max:
            labels.add("stale")                  # 安全标签：由投影现场重新计算
        if q.irreversible_inflight:
            labels.add("irr_inflight")
            q_u = "Executing"                    # 绝不折叠进 Ready
        return UState(q_u, labels, msg=self.explain(q), seq=q.seq)

    def fold(self, q):
        if q.phase in ("Grounding", "Planning"): return "Preparing"
        if q.phase in ("Verifying", "Calibrating"): return "Validating"
        return q.phase                           # Draining/Fault/Quarantined 不折叠

def uxgauge_8c(M, s, ell, user_hyp):

    M.mreg.hot_replace_at_quiescence(M.dpe, new_ec, cert.boundary)

## 4. 推导

**引理 59（诚实投影 ⇒ 无静默不可逆动作）** 若 `π` 是诚实商（定义 450），则任一携带 `irr_inflight` 或 `fault` 标签的内部迁移，在 `π(ρ)` 中都有可见见证；用户不可能观察到“静默跨过不可逆屏障”的轨迹。*证明*：由 (C2)，非 τ 迁移必有 `U` 迁移见证；由 (C3)，`AP_safe` 标签不被隐藏且逐点保留；若某不可逆迁移被映射为 τ，则 (C2) 要求 `π` 前后状态相同，但 (C3) 要求标签变化可见，矛盾。故不可逆迁移必可见。证毕。

**引理 60（诚实可供性：无死按钮 + 逃生完备）** 在定义 453 下，`Shown(q) ⊆ Exec(q)` 且 `Exec(q) ∩ Escape ⊆ Shown(q)`；若守卫单调且投影保持守卫谓词，则 `Shown` 不会引入任何新动作，用户点击“可点”动作不会被守卫拒绝，用户永远看得到当前可用的停止/中止/暂停。*证明*：第一条由集合包含直接得；第二条对 `Escape` 逐元素检查；新动作不可能出现，因为 `Aff` 的取值域是 `Σ_U`，且 `Shown` 仅从 `Exec` 过滤，不做并集扩张。证毕。

**引理 61（模式混淆检测界）** 若监视器观测到全部可见迁移且观测延迟 `≤ Δ_o`，用户操作延迟 `≤ Δ_u`，则任一由可见迁移引起的混淆在 `Δ_o + Δ_u` 内被检测；只有当混淆仅由 τ-隐藏的内部迁移引起时才可能漏检，而 (C2) 保证 τ 迁移不改变 `π(q)`，因此不改变用户可见假设空间。故 `τ_dis ≤ Δ_o + Δ_u`，且 `D_MC ≤ λ_vis · (Δ_o + Δ_u)`（`λ_vis` 为可见迁移率）。*证明*：信念集在每次观测后收缩到观测一致类；若 `h_t` 与真实投影不一致，则至少有一条可见迁移未被用户模型预测，监视器在同一观测周期即可发现。证毕。

**引理 62（撤销契约可靠性）** 若 `undo` 仅在 `R0` 上提供，则任何被承诺的 undo 都存在真实逆动作；`R1` 的补偿代价被 `c_comp` 显式界住；`R2` 不提供 undo，因而不会出现“承诺撤销但物理上无法撤销”的欺骗。期望事后损失 `E[L_undo] ≤ p_err·(1_{R0}·c_inv + 1_{R1}·c_comp) + 1_{R2}·c_no_undo`，其中 `c_no_undo` 由执行前确认与执行中停止降低。*证明*：按可逆类分情况；`R0` 由定义存在逆；`R1` 由补偿动作定义；`R2` 无 undo 项，故无虚假承诺。证毕。

**引理 63（显示陈旧不越权）** 即使显示年龄 `τ > τ_max`，用户基于陈旧显示发出的任何命令仍须通过内部守卫与 CVC 复核，因此“陈旧显示”不能授权一个当前不被允许的动作；界面的作用是提示而非授权。若 `p99(T_truth) ≤ T_budget` 且 `τ_max` 不超过人类反应预算，则“基于显示的安全行动窗口”被 `τ_max + T_budget` 界住。*证明*：命令网关只提交请求，执行前必经 `guarded(q,a)` 与 CVC；由定义 460，UX 不能新增动作。证毕。

**引理 64（UX 非干扰与严格退化）** UX 观察者不修改控制变量，`trace_ctrl(M^UX) = trace_ctrl(M)`；移除 UX 层得到 InstructGauge 原轨迹。命令网关只做集合限制，故 `M^UX` 是 `M` 的精化；任一 UX 子组件失效时，按退化链替换为更弱的观察器（静态投影、日志、无撤销），控制安全性与 50Hz 时序均不变。*证明*：观察者只读快照（定义 460）；限制命令不新增迁移；退化链每一步都是删除增强组件而非替换控制器。证毕。

**引理 65（状态机规模与模型检查可行性）** 层次分解后，可见状态数 `|Q_U| ≤ Σ_i |Q_i|`（各子机独立，不取笛卡尔积），迁移数 `|→_U| ≤ Σ_i |→_i|`；安全性质（无死锁、无活锁、`AP_safe` 不丢失、逃生完备）可在 `O(|Q_U|·|Σ_U|)` 内做显式模型检查。若需组合验证，采用 assume-guarantee 将子机契约分离，复杂度对子机数线性。*证明*：层次状态机的语义是子机按进入/退出组合，状态空间是各层状态之和而非乘积；安全性质是局部迁移上的不变量，可逐子机检查后组合。证毕。

**引理 66（确认门控与注意力预算的权衡）** 对 `R2` 动作引入确认门控后，若确认能拦截比例 `c` 的接地错误，则不可逆错误期望损失降为 `(1−c)·p_g·c_irr`；但每次确认消耗注意力，若确认频率超过 `B_attn` 则漏看率上升。存在最优门控阈值使 `总损失 = (1−c(θ))·p_g·c_irr + λ·max(0, f(θ)−B_attn)` 最小；安全通知不受预算限制，故停止/中止通道不因注意力饱和而丢失。*证明*：对 `θ` 求一阶条件；安全通知优先级高于非安全通知，由定义 458 的限流豁免直接得。证毕。

**引理 67（多操作者仲裁线性化）** 带 lease/epoch 的优先级仲裁把并发命令序列化为一个全序：`stop ≻ abort ≻ pause ≻ start`；同一时刻至多一个 `R2` 同意令牌有效，故任意两条不可逆命令不会交错执行。若两个命令优先级相同，按令牌 `epoch` 与到达序做确定性 tie-break，结果可复现。*证明*：优先级构成全序；lease 将令牌绑定到唯一 `(chunk_id, epoch)`，有效令牌集合是单元素；串行化后的执行等价于某个顺序执行。证毕。

**引理 68（UX 审计可复现性）** `UXCert` 中的 `visible_trace`、`projection_witness`、`affordance_log` 与 `consent_tokens` 足以复现“用户看到什么、系统做了什么、为什么允许”；对任一交互事件，审计者可沿证书链定位到对应的内部迁移与守卫。*证明*：由定义 462，四类记录覆盖可见层、投影层、命令层与授权层；`seq` 提供全序，`projection_witness` 提供每条可见迁移的内部见证。证毕。
