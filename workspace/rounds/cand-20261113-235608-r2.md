# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；本轮灵感：「数字孪生」×「视觉编码器」）

> R69 给 epistemic 不确定性装上了嘴：看、问、触、等。但它有一个未言明的前提——**用来计算 VoI 的模态分布，本身就是对世界的忠实描述**。R69 自陈的最大风险正在此处：若流模型幻觉出模态或坍缩掉真模态，系统会自信地追问一个幻影，或把人类的误导性回答盖上「已验证」的章。**问错，比不问更危险。**
>
> 更深一层：R69 的所有证据通道（传感器残差、策略似然、交互回答）都来自**同一个被训练的系统**。它们可以互相一致，却一起偏离世界。要跳出这个闭环，需要一面**来自系统外部、且能被现实否证的镜子**。
>
> 本轮两个灵感正好补上这块：
> - **数字孪生**提供平行世界。在花掉真实交互预算之前，先在孪生中把「问/不问」「做/不做」的反事实跑一遍；更重要的是，孪生能**否证**一个模态：它在动力学上不可达，或在视觉上没有任何现实对应物。
> - **视觉编码器**提供现实与孪生之间的脐带。真实帧与孪生渲染帧进入同一潜空间，**潜空间差**成为可标定的 sim-real gap；它既是孪生的信任计量，也是模态假设的现实锚。
>
> 核心命题：**把数字孪生从「训练用仿真器」升级为「可证伪的认知实验室」，把视觉编码器从「感知前端」升级为「现实锚」；孪生对 R69 的信念只拥有否决权（veto-only），不拥有执行权（no-actuation）。** 命名 **TWIN-RAS**（Twin-World Interactive Negotiation RAS）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我凭什么相信自己的相信——能否先用一个平行世界把它证伪**」。

## 0. 直觉与动机

**灵感 1（数字孪生 → 从「仿真环境」到「可证伪的认知实验室」）**
直觉：过去孪生只被当作训练数据的来源（域随机化、Isaac Sim），训练完就丢掉。但孪生真正的价值不在「更逼真」，而在「**可以安全地跑反事实**」：真实世界不能重来，孪生可以。R69 的主动交互是有成本的（时间、社交、物理风险），而孪生允许在**花掉预算之前**先问「如果我问这一句，后验会怎么变」「如果我碰这一下，会不会进不可恢复区」。更关键的是波普尔式的一步：孪生不必证明一个模态是对的，它只要能**否证**它——动力学不可达、视觉上无对应物、与当前证据矛盾——就足以把幻觉模态从支撑集里剔掉。证伪远比证实便宜，也远比证实可靠。

**灵感 2（视觉编码器 → 现实锚与可标定的 sim-real gap）**
直觉：孪生最大的软肋是「它说的不算」。要让它与世界对齐，需要一个共享的坐标系。现代视觉编码器天然提供这种东西：真实帧 o 与孪生渲染帧 ô 进入同一个潜空间 Φ_V，`δ_vis = d(Φ_V(o), Φ_V(ô))` 就是一个便宜的、可在线计算的 sim-real 差。它有三个用途：(a) 作为孪生**保真度的计量**；(b) 作为模态的**现实锚**——模态在孪生中推出的预测观测，若落不进真实演示/观测流形，就不可信；(c) 作为感知前端的**异常探测器**——OOD 或对抗纹理会让 δ_vis 与下游行为同时异常。但视觉编码器也会被别名欺骗（两个不同世界映射到同一点），所以它必须配一个别名检测器，而不是被当成真理。

**灵感 3（否决权而非执行权 → 新层不进入执行通道）**
直觉：每加一层黑箱，就多一个需要独立信任的部件。R70 的安全姿态必须比 R69 更强：**孪生永远不产生动作、不放大动作、不放宽安全包络**。它只能做三件事：删模态、降 λ 的上限、阻止一个信息动作。把所有输出方向都设计成「单向棘轮」，那么无论孪生多离谱，最坏结果也只是退化成 R69（甚至 R68），而不会产生新的执行风险。这是本轮最重要的工程—理论选择：**让新层在架构上「只能帮倒忙不能闯祸」**。

**灵感 4（三通道冗余 → 从「第二意见」到「可分离的故障字典」）**
直觉：R69 已有两条通道：传感器残差 `r_res`（测量自洽）与策略似然 `Δa`（行为自洽）。R70 加入第三条：孪生似然差 `δ_twin`（模型—世界自洽）。单看任意一条都会误判，但三者的**符号模式**可以分离故障类型：真漂移、被标定吸收的缓变故障、策略幻觉、孪生错误，以及最危险的「三者一起错」（共模失败）。R69 的 `(r_res↓, Δa↑)` 只是这张表里的一行；R70 把它升级成一张可查询的**故障字典**。

**灵感 5（新能力 = 新攻击面 → 孪生投毒与感知别名）**
直觉：会「问」的系统会被骗回答（R69 已建模）；会「照镜子」的系统会被骗镜子。孪生可能被投毒（错误的动力学参数、被污染的 gap 校准集）、被同步欺骗（喂一个错的 ŝ_t）、被对抗渲染纹理误导；视觉编码器可能发生感知别名，让 δ_vis 在错误状态下仍然很小。于是「孪生说没问题」本身也变成一个可被攻击的证书。R70 必须把孪生当作**不可信证人**：它的证词只有在与至少一个异源证据（本体感知、接触几何、多视角三角化、R69 的真实交互回答）交叉后才被采信；且当孪生与策略同源训练时，它们的「一致」不算证据，只算**共模嫌疑**。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（TWIN-RAS 总览与三不变式）** TWIN-RAS = (DTB, VERA, TGR, CFI, TFP, TFL, PAD, TPA, RAS-WM††)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i、R69 定义 293-i）；
(ii) **否决权**：孪生输出只能删模态、降低 λ 或阻止信息动作，**不得产生/放大动作、不得放宽认证包络、不得提升执行速度**；
(iii) **异源交叉**：任何被采信的孪生结论必须至少与一个非孪生证据源（真实视觉残差 / 本体感知 / 接触几何 / R69 交互回答）一致，禁止孪生自证。

**定义 311（数字孪生体 DTB）** 孪生状态 `ŝ_t ∈ Ŝ`，转移 `f̂`，观测/渲染模型 `ĥ, R`，由物理先验 + 学习残差构成。同步算子 `Sync: (o_t, proprio_t) → ŝ_t`；短时域 rollout `ŝ_{t+1} = f̂(ŝ_t, ξ_t)`。关键约束：孪生是**条件于当前同步状态**的局部反事实生成器，不是全局世界模型；时域 `Ĥ` 与精度受定义 323 预算约束。

**定义 312（视觉编码器现实锚 VERA）** 视觉编码器 `Φ_V: 𝒪 → 𝒵` 同时编码真实帧 `o_t` 与孪生渲染帧 `ô_t = R(ŝ_t)`：
- 潜空间现实差 `δ_vis(t) = d_Z(Φ_V(o_t), Φ_V(ô_t))`；
- 跨视角锚 `A_t = {Φ_V(o_t^{(v)})}_{v=1}^{V}`；
- 模态锚定率 `ρ_anchor(ξ) = 1[ d_Z(Φ_V(ô^{ξ}), A_real) ≤ κ ]`，其中 `ô^{ξ}` 为模态 `ξ` 在孪生中的预测渲染，`A_real` 为真实演示/观测流形。
注意：`δ_vis` 小仅是**必要不充分**条件（见定义 318 的别名）。

**定义 313（孪生保真门 TGR）** 在已知真值的 sim-real 配对回放集上计算 `δ_vis` 分数，用 conformal 分位数得 gap 上界 `ε_twin`（覆盖度 `1−α`）；信任度 `τ_twin = σ((ε_twin − δ_vis)/T)`。若 `τ_twin < τ_min` 或快照过期，令 `τ_twin = 0`，TWIN 层整体退化为 R69。

**定义 314（反事实信息 rollout CFI）** 给定 R69 的模态集 `{m_k}` 与候选信息动作 `g`，在孪生中并行 rollout 两支 `b ∈ {execute g, no-op}`，得预测观测分布 `p̂(y | g, o)` 与孪生 VoI：
`VoI_twin(g) = H(M|o) − Ê_{y∼p̂}[H(M | o, y)]`。
由于 gap，孪生 VoI 只取**下置信界** `VoI_LCB(g) = VoI_twin(g) − L_V·ε_twin`。孪生对 `g` 的权力是：当 `VoI_LCB ≤ c(g)` 或 `risk_twin(g) > ε_int` 时**否决**；它无权强行发起 R69 未提出的交互。

**定义 315（孪生否证模态剪枝 TFP）** 对每个模态 `m_k`，在孪生中沿其动作轨迹 rollout `Ĥ` 步，定义三个否证谓词：
- `dyn(m_k) = 1[rollout 不违反硬约束且不进入不可恢复集]`；
- `anchor(m_k) = ρ_anchor(m_k)`（定义 312）；
- `cf(m_k) = 1[执行 m_k 后的预测观测与真实当前证据不矛盾]`。
若 `dyn=0` 或 `anchor=0` ⇒ **否决** `w_k ← 0`，记入剪枝质量 `μ_prune`；若 `cf=0` ⇒ 降权 `w_k ← w_k·λ_cf`。剪枝**只能删/降，不能加/升**；被删质量按定义 321 进入风险储备。

**定义 316（孪生似然第三通道 TFL）** 由孪生动力学生成模型估计 `ℓ_twin(ξ|o) = log p̂(ξ|o)`；与 R69 的流似然 `ℓ_flow(ξ|o)` 比较，定义 `δ_twin = |ℓ_twin(ξ_obs|o) − ℓ_flow(ξ_obs|o)|`。三通道 `χ_t = (r_res, Δa, δ_twin)` 的故障字典：
- `(r_res↑, Δa↑, δ_twin↑)`：真实漂移/故障；
- `(r_res↓, Δa↑, δ_twin↑)`：缓变故障被标定吸收（R68 盲区）；
- `(r_res↓, Δa↓, δ_twin↑)`：策略幻觉或孪生错误，交现实锚裁决；
- `(r_res↓, Δa↓, δ_twin↓)`：**共模失败嫌疑**——三者一致地错，必须引入异源证据（引理 22）。

**定义 317（异源证据纪律）** 证据源分两类：**同源** `S_src = {Φ_V 编码、孪生似然、流策略似然、标定残差}`（共享训练/数据路径）与**异源** `S_exo = {本体感知不变量、多视角三角化、接触/摩擦几何约束、R69 的真实交互回答}`。产生「高置信」结论需同时满足：至少一个 `S_src` 与至少一个 `S_exo` 一致；单源（尤其单孪生源）结论一律只作似然、不作定案。

**定义 318（感知别名检测 PAD）** 别名指数 `α_t = 1 − max_v I(o^{(v)}; ŝ_t | o^{(-v)}) / H(o^{(v)})`，用留一视角预测残差估计。若 `α_t > τ_alias`，说明 `Φ_V` 可能把不同世界折叠，`δ_vis` 不可辨识；令 `τ_twin = 0` 并强制回到 R69 主动交互（用第 `V+1` 视角或一次接触打破别名），同时把该事件记入 `ℰ_alias`。

**定义 319（孪生投毒与对抗集 ℰ_twin）** 涵盖孪生漂移、同步欺骗（错误的 `ŝ_t`）、对抗渲染纹理、仿真参数投毒、gap 校准集污染、同源共模偏差。并入 AIC：`ℰ_TWIN = ℰ_FLUID × ℰ_twin × ℰ_alias`。

**定义 320（孪生溯源审计 TPA）** 每次孪生否决/采信记录 provenance：孪生版本哈希、同步来源、`δ_vis/ε_twin`、校准集哈希、渲染参数、被影响的模态与 λ、当时 `τ_twin`。审计结论回灌 TGR 校准与 CFI 成本先验；审计本身异步，不阻塞控制。

**定义 321（缺口感知的单调风险缩放与风险储备）** 剪枝后 `U_epi' = H_mode(w')·g(Δ_min)`；被剪枝质量的风险储备
`U_reserve = μ_prune · L_veto · (1 − τ_twin)`，其中 `L_veto` 为「被删的其实是真模态」时的损失上界。于是
`λ = max(λ_task, λ_floor(U_ale + U_reserve + U_epi_unresolved))`。
性质：`τ_twin = 1` 且孪生 sound 时 `U_reserve = 0`，可得合理的剪枝收益；`τ_twin = 0` 时不剪枝、储备为 0，逐指令退回 R69；**任何情况下 λ 不低于由「未消解不确定性 + 储备」算出的下界，安全侧不劣于 R68**。孪生不能创造超出 R69 的 resolution bonus，只能防止虚假 bonus 被使用。

**定义 322（孪生增强的信息动作安全）** 信息动作 `g` 除 R69 的 C-RAS-WM 认证外，还须经孪生预演 `risk_twin(g) ≤ ε_int`；孪生预演失败、超时、或快照过期 ⇒ **fail-closed，禁止执行**（与否决权一致：孪生只能阻止，不能放行）。

**定义 323（孪生分辨率与计算预算）** 孪生 rollout 仅在歧义/异常时触发，默认**异步、低频、短时域**；主实时回路只读带时间戳的孪生缓存，从不等待。缓存过期（`age > TTL`）视同 `τ_twin = 0`。主环路 P99 不劣于 R69。

**定义 324（证书 J_TWIN）** `J_TWIN = (J_FLUID, twin_ver_hash, gap_p95, tau_twin_min, cf_gain, prune_count, mu_prune, alias_flag, co_modality_flag, twin_authority, twin_log_hash)`。`Valid ⇔ Valid(J_FLUID) ∧ 快照未过期 ∧ TPA 通过 ∧ 至少一个异源证据一致 ∧ authority ∈ {0,1} 明确`。

**定义 325（模态权重与孪生先验的合法融合）** R69 权重 `ŵ_k` 与孪生似然 `q_k ∝ exp(−ℓ_twin(m_k))` 的融合为
`ŵ'_k ∝ ŵ_k · q_k^{η·τ_twin}`，`η ∈ [0,1]` 为可审计耦合系数。`τ_twin = 0 ⇒ q_k^0 = 1`，恢复 R69。禁止用孪生直接替换 `ŵ_k`（防止孪生成为新的黑箱后门）。

**定义 326（共模失败与可证伪性条件）** 同源相关 `ρ_src = corr(ε_policy, ε_twin)`。可证伪性假设 A102：存在至少一个异源通道 `h ∈ S_exo` 使 `corr(ε_policy, ε_h) < ρ_max`，且 `|∂δ_twin/∂ε|` 有界。若 `ρ_src → 1` 且无可用异源通道，则孪生与策略无法互相证伪，TWIN 的收益不可验证，必须降级到 R69。

**定义 327（失败安全的孪生降级序列）** `twin_authority` 取值 `full → veto-only → off`，转移由 `(δ_vis, α_t, 投毒告警, 快照 age)` 单调驱动：任一指标越界只能降低 authority，不能提升；恢复需连续 `N_rec` 个周期通过且带迟滞，避免抖动引入控制突变。

    if M.cmd.common_mode_suspect(a_hat, d_twin):    # 共模：退回 R68 最保守
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    mode = select_mode(modes, U_epi_after, lam)
    M.tpa.submit_async(snap, g, mu_prune, tau, a_hat, d_twin)
    return k, lam, mode, (U_ale, U_reserve, U_epi_after)
```

## 3. 推导

**引理 19（带风险储备的剪枝保守性）** 设剪枝质量 `μ_prune`，且「被删模态其实正确」时任务损失 ≤ `L_veto`。在 A99（孪生 sound 率 ≥ 1−η）下，把 `U_reserve = μ_prune·L_veto·(1−τ_twin)` 计入 `λ_floor` 后，剪枝相对不剪枝的期望风险增量 ≤ `η·μ_prune·L_veto − (1−η)·Δ_resolve`。要点：`τ_twin` 越低，储备越接近「把整块被删质量当作不可约噪声」，于是剪枝自动失去乐观性；只有 `τ_twin→1` 且孪生 sound 时才允许真正的分辨率收益。这把「删模态」这个危险操作变成了一个**带保证金的下注**。

**引理 20（gap 感知 VoI 的偏差界）** 设熵对观测分布在潜空间 gap 下 Lipschitz 常数为 `L_V`。则 `|VoI_twin(g) − VoI_real(g)| ≤ L_V·ε_twin + O(ε_twin²)`。因此只用下界 `VoI_LCB = VoI_twin − L_V·ε_twin` 做否决是 sound 的：它不会因为孪生的乐观而多问一句；最坏只是漏掉一些本可获益的交互，退化为 R69 的保守。这正是「否决权」在统计上的对应物。

**引理 21（视觉别名的 gap 盲区）** 存在真实状态 `s_1 ≠ s_2` 使 `Φ_V(o_1) = Φ_V(o_2)`（对称走廊、透明/反光物体、重复纹理）。此时 `δ_vis = 0` 而 `ŝ_t` 可能完全错误，故 **`δ_vis` 小不能证明孪生对齐**。要获得可辨识性，必须有条件于动作/多视角的额外观测：`α_t`（定义 318）正是这一不可辨识性的在线代理。系：任何声称「仅凭视觉编码器即可保证 sim-real 一致」的设计都在别名场景下失效。

**引理 22（共模失败的不可检测性）** 若策略与孪生的误差完全同源（`ρ_src = 1`），且二者的联合误差落在异源通道的零空间（`corr(ε_policy, ε_h) = 1` 或 `ε_h` 不可观测），则任意只依赖 `(r_res, Δa, δ_twin)` 的检验统计量在「正确」与「共模错误」两假设下同分布，**不可区分**。故可检测性的充要条件是存在一个与训练路径解耦的异源锚。系：R70 的 `S_exo` 不是锦上添花，而是整套「外部校验」成立的**前提**。

**定理 18（可证伪包含链）** 在 A99–A103 下：
(i) `τ_twin = 0` ⇒ TWIN 与 R69 逐指令相同（定义 313/321/323）；
(ii) 孪生 sound 且 `τ_twin = 1` ⇒ TWIN 的期望风险 ≤ R69（引理 19–20），且当 R69 交互收益为正时严格更优；
(iii) 任意孪生状态 ⇒ TWIN 的 λ 不低于以 `U_ale + U_reserve + 未消解 U_epi` 计算的下界，故相对 R68 的安全下界保持。
因此 R70 不是替代 R69，而是给 R69 加了一个**可关闭、可审计、只会向保守方向出错**的外部证伪器。

**定理 19（否决权的控制不变性）** 孪生不在执行通道上（定义 310-ii）：它只修改模态支撑集、λ 下界与信息动作许可集，不修改任何已认证动作的前缀或安全包络。结合定义 322 的 fail-closed、定义 327 的单调降级与迟滞，authority 切换不引入控制突变；R68 定理 15 的换装不变式保持 ⇒ 控制连续。

## 6. 本轮最大风险

**一句话**：TWIN-RAS 把「外部校验」押在孪生与视觉编码器上，但二者若同源训练、同源数据、共享编码器，就可能**一起错且彼此一致**——`δ_twin` 反而很低，现实锚又被感知别名欺骗；此时否决权形同虚设，系统会以「已交叉验证」的姿态执行一个共模幻觉。**最危险的不是孪生不准，而是孪生与策略「一致地不准」，让错误获得了第二个签名。**

**次级风险与缓解**：
1. **视觉别名使 gap 归零** → PAD（定义 318）+ 多视角/动作条件可辨识性 + 别名时强制回 R69 交互；
2. **孪生投毒/同步欺骗** → `ℰ_twin` 对抗训练 + TPA 溯源 + 异源交叉（定义 317/319/320）；
3. **剪枝误删真模态** → 风险储备 `U_reserve`（定义 321）+ 引理 19 的保证金机制 + 误删率门限；
4. **异步孪生缓存过期仍被使用** → TTL + 过期即 `τ_twin=0` + fail-closed（定义 322/323）；
5. **共模失败不可检测** → 引理 22 明确其为体系边界；唯一解是保留不经过学习编码的物理不变量（本体/接触/几何）作为硬锚，并在证书中显式标注 `co_modality_flag`。

def TWIN_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, _ = M.cof.step(...)
    snap = M.dtb.cached_snapshot()                            # 只读缓存，不阻塞
    tau, eps = (M.tgr.trust(snap) if snap.fresh and not M.pad.alias(snap) else (0.0, 0.0))
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    mu_prune = 0.0
    if tau > 0:                                               # 否证剪枝（单向）
        modes, mu_prune = M.tfp.falsify(modes, M.aud.weights, M.dtb, M.vera, snap.s)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o, o_calibrated)   # R69 通道
    d_twin = M.tfl.disagreement(M.dtb, M.fmp, M.last_action, o, snap)   # 新通道
    g = M.mint.choose_interaction(modes, M.aud.weights, o, M.budget)
    if g is not None and tau > 0 and g in M.cfi.veto(...): g = None     # 预筛否决
    U_epi_after = M.cia.update_belief(modes, M.cia.execute(g)) if g else U_epi
    U_reserve = mu_prune * L_veto * (1.0 - tau)               # 删了也可能删错
    lam = max(M.efs.risk_scale(...),
              lam_floor(U_ale + U_reserve + (U_epi_after if g is None else 0.0)))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if M.cmd.common_mode_suspect(a_hat, d_twin):              # 共模：回 R68 最保守
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    mode = select_mode(modes, U_epi_after, lam)
    M.tpa.submit_async(snap, g, mu_prune, tau, a_hat, d_twin)
    return k, lam, mode, (U_ale, U_reserve, U_epi_after)
```

## 4. 推导

**引理 19（带风险储备的剪枝保守性）** 剪枝质量 `μ_prune`、「被删模态其实正确」损失 ≤ `L_veto`；把 `U_reserve=μ_prune·L_veto·(1−τ_twin)` 计入 `λ_floor` 后，相对不剪枝的期望风险增量 ≤ `η·μ_prune·L_veto − (1−η)·Δ_resolve`（A99：孪生 sound 率 ≥ 1−η）。系：`τ_twin` 越低，储备越接近「把被删质量全当作不可约噪声」，剪枝自动失去乐观性；「删模态」由此变成带保证金的下注。

**引理 20（gap 感知 VoI 的偏差界）** `|VoI_twin − VoI_real| ≤ L_V·ε_twin + O(ε_twin²)`（A100：熵在潜空间 gap 下 Lipschitz）。故只用 `VoI_LCB = VoI_twin − L_V·ε_twin` 做否决是 sound 的：不会因孪生乐观而多问一句，最坏退化为 R69 的保守。

**引理 21（视觉别名的 gap 盲区）** 存在 `s_1≠s_2` 使 `Φ_V(o_1)=Φ_V(o_2)`（对称走廊/反光/重复纹理），此时 `δ_vis=0` 而 `ŝ_t` 可能完全错误；故 `δ_vis` 小不能证明孪生对齐，必须用 `α_t`（多视角/动作条件可辨识性）补盲。

**引理 22（共模失败的不可检测性）** 若 `ρ_src=1` 且联合误差落在异源通道零空间，则任何仅依赖 `(r_res, Δa, δ_twin)` 的统计量在「正确」与「共模错误」下同分布，不可区分。可检测性的前提是存在与训练路径解耦的异源锚。系：`S_exo` 不是可选模块，而是外部校验成立的前提。

**定理 18（可证伪包含链）** A99–A103 下：(i) `τ_twin=0 ⇒ TWIN ≡ R69` 逐指令相同；(ii) 孪生 sound 且 `τ_twin=1 ⇒` 期望风险 ≤ R69，R69 交互收益为正时严格更优；(iii) 任意孪生状态 ⇒ λ 不低于以 `U_ale+U_reserve+未消解 U_epi` 计算的下界，相对 R68 安全下界保持。R70 是 R69 的**可关闭、可审计、只会向保守方向出错**的外部证伪器。

**定理 19（否决权的控制不变性）** 孪生不在执行通道：只改模态支撑集、λ 下界与信息动作许可集，不改已认证动作前缀或安全包络；结合 fail-closed（定义 322）、单向降级与迟滞（定义 327），authority 切换不引入控制突变；R68 定理 15 换装不变式保持 ⇒ 控制连续。

## 7. 本轮最大风险

**一句话**：TWIN-RAS 把「外部校验」押在孪生与视觉编码器上，但二者若同源训练、同源数据、共享编码器，就可能**一起错且彼此一致**——`δ_twin` 反而很低，现实锚又被感知别名欺骗；此时否决权形同虚设，系统会以「已交叉验证」的姿态执行一个共模幻觉。**最危险的不是孪生不准，而是孪生与策略「一致地不准」，让错误获得了第二个签名。**

**次级风险与缓解**：视觉别名使 gap 归零（PAD + 多视角/动作条件可辨识性 + 回 R69 交互）；孪生投毒/同步欺骗（`ℰ_twin` + TPA + 异源交叉）；剪枝误删真模态（`U_reserve` 保证金 + 误删门限）；缓存过期仍被使用（TTL + fail-closed）；共模失败不可检测（引理 22 明示边界，保留不经过学习编码的物理不变量作硬锚，并在 `J_TWIN` 显式标注 `co_modality_flag`）。
