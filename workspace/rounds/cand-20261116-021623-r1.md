# 第 12 轮（新灵感循环第 3 轮；本轮灵感：「数据配比」×「原型验证」）

> **基线**：第 11 轮 MetricVoiceGauge-GSCF-SRA-JSSE（定义 549–561；引理 92–96；实验 E591–E610）。
> 本轮纪律：**数据即证据 + 原型即门槛**。v11 的三重守护在"平均场景"下自洽，但它把 τ_sem、γ_min、τ_sra 当作已校准常数；这三个常数的有效性其实是一个**未声明的数据配比假设**——标定集与部署分布同分布。v11 自认的最大风险（透明/强遮挡/动态下 γ 虚假低、SRA 虚假高置信、JSSE 标定漂移同时触发）本质是两笔债：**覆盖债**（证据的配方没写清）与**晋升债**（候选版本没有统计上站得住的上岗考试）。本轮用「数据配比」治理覆盖债、用「原型验证」治理晋升债。铁律不变：任一新模块失效 ⇒ 行为严格等价或支配于 v11。

## 0. 直觉与动机

**灵感 1（数据配比 → 从"全局阈值"到"域条件覆盖 + 配比间隙税"）**
直觉：v11 的 γ_min 是把透明物体、强遮挡、动态人、普通桌面统统边缘化进一个数里。它对"标定配比 = 部署配比"这一前提做承诺，却从不记录配比本身。数据配比的第一层直觉是"多拍缺的场景"，但真正严谨的版本更进一步：**配比的目的不是拟合部署端的边缘比例，而是保证每个场景域有足够样本，从而能做条件（Mondrian）覆盖**。一旦每个域的条件覆盖成立，部署端域比例的漂移**不会**破坏覆盖保证（这正是条件共形相比边缘共形的价值）；因此风险只剩两项——**域内漂移**与**域识别错误**。于是"数据配比"被精确地拆成：在采集预算 B 下分配各域样本数 n_d（方差最小端点是 Neyman 型分配 n_d∝π_dσ_d/√c_d），并给域内漂移与域误判付一笔显式**间隙税**。v11 的静态 γ_min 由此升级为**域条件共形阈值** γ_min(d)：透明物体的"低 γ"不再是异常，而是它自己的零分布。这正面回应 v11 最大风险的第一条（虚假低 γ 导致 K_eff 长期塌缩）。

**灵感 2（原型验证 → 把"上岗考试"做成任意时有效的门）**
直觉：v11 的模块一旦上线就默认"已验证"，但真实变更（新 VQA 权重、重标定的 γ_min、新配比、甚至一行代码）需要一次原型验证：先离线回放、再影子跑、再受限权限 canary、最后全量。危险在于考试过程本身——研究员会反复看指标、提前停、按结果调参，经典显著性检验在这种"偷看"下失效。原型验证的严格版本是**时序 e-process**：非负上鞅 + Ville 不等式，无论看多少次、何时停，误晋升率 ≤α。还要考 v11 只靠并集界假设的东西：**三守护的联合失效**。原型验证必须主动"合谋注入"（对抗纹理 + 强遮挡 + 标定漂移），用 Clopper–Pearson 上界实测 ρ_joint，超阈就拒绝晋升、维持 v11。

**灵感 3（合流：证据受配比约束，晋升受原型约束）**
直觉：v11 把"证据够不够"与"能不能上岗"混成一个动作。v12 拆成两条正交纪律：DMC 保证证据的**配方是声明的、覆盖是可测的**；PVG 保证从证据到部署的跳跃**被统计地批准**。二者共同把 v11 的三个经验常数升级为配比索引、域条件化的证书量：γ_min(d)、τ_sra(d)、ε_fk(d)，并把每次晋升的候选版本 θ_version 绑进证书。

三者咬合：**数据配比调度器（DMC）** 产出配比证书 μ_t 与间隙税；**覆盖证书监视器（CCM）** 在运行期用域条件共形 p 值检测"来料是否超出配方"，越界即收缩并反向点单补数；**原型验证门（PVG）** 用离线→影子→canary→全量四级门 + e-process 决定任何新配方/阈值/模型能否晋升，并用合谋注入检验 v11 的正交假设。块证书升级为 **Ĉ⁺⁺⁺ = (ĝ_min, ê_max, γ̂_grasp, β⁺, n_t, n_t^reason, Q_abort, μ_t, pval_t, θ_version)**。

## 1. 研究问题（轮次升级版）

- **Q1（配比证书）**：如何把标定数据配比 w 与部署分布 p_t 的差异显式计入证书余量，使覆盖保证从"同分布假设"降级为"域条件覆盖 + 可测间隙税"，且间隙税在在线可估？
- **Q2（配比调度）**：在采集预算 B 与有效样本量 N_eff 约束下，如何在线求解 w_t（哪些域多拍）使总体证书余量最小，并能对 OOD 观测反向"点单"补数据？
- **Q3（原型验证）**：如何设计一个任意时有效、防偷看、含联合失效合谋注入的晋升门，使误晋升 ≤α、影子阶段零致动、canary 阶段物理行为支配于 v11？
- **Q4（可信度复核）**：这套机制能否把 v11 的经验阈值债务转化为可审计的"配比—原型"证据链，并在透明/遮挡/动态三类最难域上把 v11 的最大风险显著降低？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 配比显式律（Mixture-Explicit, DMC）**
任何误差界或阈值必须携带其生效的场景域、配比 w 与支持集；界只能在其配比的（域条件）支持集上被引用，跨分布引用必须支付可测间隙税，不得默认同分布。

**P17 覆盖即收缩律（Coverage-Shrink, CCM）**
运行期一旦观测落在已证支持集之外（域条件共形 p 值 ≤α_mix，或域后验熵过高/域无标定样本），立即按"未证"处理——β 抬升、K_eff≤2、发出定向采集请求；绝不沿用旧阈值的乐观值。

**P18 原型晋升律（Prototype-Promotion, PVG）**
任何会改变物理行为的版本（模型/阈值/配比/代码）必须通过离线→影子→canary→全量四级门与任意时有效 e-process；证据不足即维持旧版；影子阶段不得致动；联合失效必须被主动检验而非假设。

## 3. 与基线的接口（如何退化）

- DMC 失效（域目录损坏/求解超时）⇒ w←w0（v11 标定配比）、gap 取保守上界 ⇒ β⁺←β_GSCF+Δ_gap（比 v11 更保守，**支配**）；
- CCM 失效（分数集损坏/域后验不可得）⇒ U_t^mix≡false ⇒ K_eff≤2、β 抬升（**支配** v11）；
- PVG 失效（e-process 状态损坏/台账缺口）⇒ 冻结晋升、维持已签名 v11 版本（**等价** v11）；
- GSCF 失效 ⇒ v11 Level-1；SRA ⇒ v11 Level-2；JSSE ⇒ v11 Level-3；STF ⇒ Level-4；NRB ⇒ Level-5；AC ⇒ Level-6；ID ⇒ Level-7；MW ⇒ Level-8；v8 ⇒ Level-9。

## 4. 预期贡献

1. **配比证书与间隙税**：把"同分布"从隐含假设变成显式、可测、可优化的项；静态 γ_min 升级为域条件共形阈值（引理 97–98）；
2. **覆盖监视 + 反向点单**：OOD 从"事后惊讶"变成"事前收缩 + 定向补数"，配比本身成为可调度资源（引理 99）；
3. **任意时有效原型门**：误晋升 ≤α、影子零物理风险、canary 支配 v11，且支持原子回滚（引理 100–101）；
4. **把 v11 的正交假设从纸面升级为实测**：合谋注入估计 ρ_joint，超阈回退 v11，不再默认并集界（引理 102）；
5. **E611–E630** 覆盖配比标定、间隙税、OOD、e-process、联合注入、回滚、长跑与竞赛。

## 5. 本轮最大风险

**一句话**：间隙税与域条件共形 p 值都是用**同一批有盲区的数据**估出来的——若部署漂移恰好落在标定集从未见过的方向（自指盲区），估出的 gap 会系统性偏小、p 值会偏大，于是证书"自证清白"，而 PVG 也会因原型未注入该失效模式而放行，v12 的失败比 v11 更安静、更难在事后审计中发现。

**新增定义 562（场景域与数据配比）** 域集合 D 为部署场景的可观测划分；域 d 的标定样本 i.i.d. ~ q_d。配比 w_t∈Δ^{m−1} 决定各域采集/重加权比例。**关键约定**：q_w 的域条件分布满足 q_w(·|d)=q_d，与 w 无关——w 只决定每域样本数 n_d 与有效样本量，不改变域内零分布。这是"配比"精确化的第一步。

**新增定义 563（域条件/Mondrian 共形与有效样本量）** 对域 d，标定非一致性分数集 S_d={s_i}_{i∈I_d}。对观测 x 的分数 s(x)，定义
```
pval(x;d) = (1 + #{i∈I_d : s_i ≥ s(x)}) / (n_d + 1).
```
在域内可交换假设下，pval(x;d) 超均匀：P(pval≤α)≤α。有效样本量 N_eff(w) = 1/Σ_d (w_d²/n_d)；当 w_d∝n_d 时 N_eff=Σn_d。

**新增定义 564（配比证书与间隙税）** 定义
```
gap_t   = Σ_d π_t(d) · TV̂(p_t(·|d), q_d)          # 域内漂移，可观测域特征上估计
gap_t  ≤ gap_max（预注册上界）
β_mix   = Q_w^{d}(1−ε) + L_r·gap_t + L_r·diam·δ_dom + Δ_n(n_{d_t})
β⁺      = max(β_GSCF, β_mix)                       # 永不小于 v11，保证支配性
μ_t     = (w_t,{n_d},N_eff,gap_t,δ_dom,Δ_n,β⁺,ε_mix,θ_version)
```
其中 Q_w^{d}(1−ε) 为域 d 上残差的共形分位数，Δ_n(n_d) 为有限样本分位松弛（定义 565）。μ_t 仅在"域 d 已被识别且 x 落在其支持集"时有意义。

**新增定义 565（分位数的有限样本松弛）** 由 DKW 不等式，对 n_d 个 i.i.d. 分数，
```
Δ_n(n_d) = sqrt( log(2/δ_q) / (2·n_d) ) · R_max,
```
以概率 ≥1−δ_q 覆盖真实分位与经验分位之差；或用次序统计量精确界。**这是"数据配比"影响安全余量的唯一数学通道**：n_d 越大，Δ_n 越小。

**新增定义 566（配比优化：分位松弛下的 2/3 次幂分配）** 给定部署域比例 π、每样本成本 c_d、预算 Σ c_d n_d ≤ B，最小化期望分位松弛
```
min_{n≥0}  Σ_d π(d)·Δ_n(n_d)   s.t.  Σ_d c_d n_d ≤ B,  n_d ≥ n_min（安全关键域）
```
取 Δ_n(n_d)=k/√n_d，Lagrange 得
```
n_d ∝ ( π(d) / c_d )^{2/3}      （分位松弛最优分配）
```
作为对照：若目标是最小化均值估计方差且域内方差 σ_d²，则经典 Neyman 分配 n_d ∝ π(d)·σ_d/√c_d。**两种分配不同**——安全证书关心分位数而非均值，故应用 2/3 次幂律；这纠正了"数据配比就是按部署比例采样"的直觉错误。

**新增定义 567（覆盖证书监视器 CCM）** 每周期由可观测域特征得后验 π_t；取 d_t=argmax_d π_t(d)，后验熵 H_t。覆盖标志
```
U_t^mix = (pval_t(x) > α_mix) ∧ (n_{d_t} ≥ n_min) ∧ (H_t ≤ H_max) ∧ (d_t ∈ D).
```
若 ¬U_t^mix：β⁺←β⁺+Δ_ood（Δ_ood 取"未知域相对已识别域"的最坏分位差，R_max 为上界），K_eff←min(K_eff,2)，并向 DMC 发出点单 request=(d_t,k,reason)。**先收缩后补数，绝不沿用乐观阈值。**

**新增定义 568（配比索引/域条件阈值）** v11 的 γ_min、τ_sra、ε_fk 升级为域条件阈值：
```
γ_min(d)  = 域 d 上 γ 的 (1−α_geo) 条件分位数；
τ_sra(d)  = 域 d 上 SRA 置信度的 (1−α_sra) 条件分位数；
ε_fk(d)   = 域 d 上运动学残差的 (1−α_fk) 条件分位数。
```
运行期使用 γ_min(d_t)、τ_sra(d_t)、ε_fk(d_t)；域未知时取全局**最大**（最保守）值。**透明物体的低 γ 不再被判为几何异常，而是与透明域自身零分布比较**——这是对 v11"虚假低 γ"风险的正面拆除。

**新增定义 569（原型验证四级门 PVG）**
- **S0 离线回放**：候选 θ' 与在役 θ 在 held-out 混合集（从不参与标定）上配对比较；不过即拒。
- **S1 影子**：候选在真实数据流上计算，但**不接管执行**（零致动）；记录配对损失 Δ_t 与反事实动作散度 D_shadow。**物理风险增量为 0**。
- **S2 canary**：候选以限制性剖面 Π_r 接管（K_eff≤2、v≤v_max/2、禁触注册个人物品、强制语音披露），持续 N_c 个 episode；物理行为 ⊆ v11 可行集。
- **S3 全量**：仅当 e-process 拒绝 H0 且 ρ_joint 上界≤ρ_max 且签名一致时进入。

**新增定义 570（时序 e-process）** 在 S0–S2 上取配对有界损失 Δ_t=ℓ(θ,o_t)−ℓ(θ',o_t)∈[−c,c]（正=候选更好）。检验 H0：R(θ')≥R(θ)+δ_ni（候选不够好）。令
```
E_t = Π_{s=1}^{t} exp( λ_s(Δ_s + δ_ni) − λ_s²c²/2 ),   λ_s 可预测且 ∈[0,1/c]
```
在 H0 下 E_t 为非负上鞅且 E_0=1；由 Ville 不等式，P(∃t: E_t≥1/α_pvg)≤α_pvg。**无论看多少次、何时停，误晋升 ≤α_pvg**。拒绝 H0（晋升）⇔ E_t ≥ 1/α_pvg。

**新增定义 571（原型保真度）** φ_proto=TV(p_real,p_sim)，由成对真实/仿真留出集估计。若 φ_proto≤φ_max，则 S0/S1 的非劣效结论可迁移到真实分布，附加松弛 ≤L·φ_proto；若 φ_proto 无法证 ≤φ_max，则仿真证据不足，**必须**进入 S2 物理 canary。**禁止"仿真里过了就上线"。**

**新增定义 572（联合失效合谋注入）** 设计同时注入协议：(i) 对抗纹理（打 ν 通道）；(ii) 强遮挡/透明（打 γ 通道）；(iii) 标定漂移（打 ε_fk 通道）。在 S1/S2 记录三守护同时失效的样本数，用 Clopper–Pearson 得 ρ_joint 的 (1−α_pvg) 上界。若 UCB>ρ_max 则拒绝晋升、维持 v11（v11 自身安全界仍成立）；若某失效模式**无法构造原型**，则 ρ_joint 视为未知，**不得晋升**。

**新增定义 573（原子晋升与回滚台账）** 采用 A/B 双签名槽：晋升=原子切换活动槽；回滚=原子切回。每次事件写 Λ：H(prev‖θ‖μ_t‖stage‖max E_t‖ρ_joint UCB‖decision)。**台账缺口或签名不匹配 ⇒ PVG 冻结（fail-closed）。**

**新增定义 574（升级块证书）** Ĉ_t⁺⁺⁺ = (ĝ_min, ê_max, γ̂_grasp, β⁺, n_t, n_t^reason, Q_abort, μ_t, pval_t, θ_version)。有效 ⇔ v11 定义 552 全部条件 ∧ U_t^mix ∧ θ_version=当前已批准版本。

**新增定义 575（覆盖门控的 K_eff）** 在 v11 定义 553 基础上把覆盖并入门控（四重门取 max）：
```
K_eff(t) = 1                     若 ¬U_t^sem ∨ ¬U_t^geo ∨ ¬U_t^mix ∨ Ĉ_t⁺⁺⁺ 不可得
         = 2                     若 NRB 失效 ∨ SRA 失效 ∨ 域未知
         = max(1, ⌊K_max·(1−min(1, max(Δ_dom/τ_dom,
                    sup_走廊 T/τ_sem, sup_走廊 (1−Γ)/τ_sem,
                    (1−pval_t)/α_mix)))⌋)      否则
```

**新增定义 576（数据点单）** 采集请求 r_t=(d_t,k,reason)。优先级按"每单位成本的期望 β⁺ 降幅"排序：priority(d) ∝ (∂β⁺/∂n_d)/c_d ∝ π(d)·Δ_n(n_d)/(2n_d·c_d)；k 由剩余预算与 n_min 缺口确定。DMC 执行点单并更新 μ_t，CCM 在覆盖恢复后解除收缩。

**新增定义 577（版本签名与 fail-closed）** θ_version=H(code_hash‖model_hashes‖threshold_table_hash‖μ_t_hash)。控制侧在每个块开始校验；不匹配 ⇒ 视为 Ĉ⁺⁺⁺ 不可得 ⇒ K_eff=1 / 急停保持。**版本卫生是安全属性，不是运维细节。**

# IP-365 DataMixtureConductor：数据配比调度器（配比证书 + 采集预算 + 反向点单）
class DataMixtureConductor:
    def __init__(self, domains, cost, n_min=200, N_min=2000, L_r=1.0,
                 diam=1.0, kappa=0.1, eps_mix=0.01, delta_q=0.01):
        self.domains = list(domains)
        self.cost, self.n_min, self.N_min = cost, n_min, N_min
        self.L_r, self.diam, self.kappa = L_r, diam, kappa
        self.eps_mix, self.delta_q = eps_mix, delta_q
        self.n = {d: 0 for d in self.domains}
        self.w = {d: 1.0 / len(self.domains) for d in self.domains}
        self.pending = {d: 0 for d in self.domains}

    def n_eff(self, w=None):
        w = w or self.w
        return 1.0 / sum(w[d] ** 2 / max(self.n[d], 1) for d in self.domains)

    def finite_sample_slack(self, d, R_max=1.0):
        # 定义 565：DKW 型分位松弛
        return math.sqrt(math.log(2.0 / self.delta_q) / (2.0 * max(self.n[d], 1))) * R_max

    def gap_within(self, pi, p_within, q_within):
        # 定义 564：域内 TV 漂移税（域比例漂移不进入；Mondrian 已免疫）
        return sum(pi.get(d, 0.0) * total_variation(p_within[d], q_within[d])
                   for d in self.domains)

    def beta_mix(self, d, q_quantile_d, pi, p_within, q_within, delta_dom):
        return (q_quantile_d
                + self.L_r * self.gap_within(pi, p_within, q_within)
                + self.L_r * self.diam * delta_dom
                + self.finite_sample_slack(d))

    def optimize_allocation(self, pi, budget):
        # 定义 566：min Σ π(d)·k/√n_d s.t. Σ c_d n_d ≤ B  ⇒ n_d ∝ (π(d)/c_d)^{2/3}
        total = 0.0
        for d in self.domains:
            raw = (max(pi.get(d, 1e-6), 1e-9) / self.cost[d]) ** (2.0 / 3.0)
            self.n[d] = max(self.n_min, int(raw))
            total += self.cost[d] * self.n[d]
        scale = min(1.0, budget / max(total, 1e-9))
        if scale < 1.0:                      # 预算不足：按安全关键域保留 n_min
            for d in self.domains:
                self.n[d] = self.n_min
        # 更新配比 w_d ∝ n_d
        N = sum(self.n.values())
        self.w = {d: self.n[d] / N for d in self.domains}
        return self.w

    def certify(self, d, q_quantile_d, pi, p_within, q_within,
                delta_dom, beta_gscf, version_sig):
        b = self.beta_mix(d, q_quantile_d, pi, p_within, q_within, delta_dom)
        beta_plus = max(beta_gscf, b)        # 定义 564：永不小于 v11
        return MixtureCert(self.w, dict(self.n), self.n_eff(), b, beta_plus,
                           self.eps_mix, version_sig)

    def request(self, d, k, reason):
        self.pending[d] += k                # 定义 576：数据点单
        return AcquisitionRequest(d, k, reason)


# IP-366 CoverageCertificateMonitor：覆盖证书监视器（Mondrian 共形）
class CoverageCertificateMonitor:
    def __init__(self, scores_by_domain, alpha_mix=0.01, n_min=200, H_max=0.5):
        self.scores = {d: np.sort(np.asarray(s)) for d, s in scores_by_domain.items()}
        self.alpha_mix, self.n_min, self.H_max = alpha_mix, n_min, H_max

    def score(self, x):
        return self.nonconformity(x)

    def p_value(self, x, d):
        arr = self.scores.get(d)
        if arr is None or len(arr) < self.n_min:
            return 0.0                       # 无标定样本 ⇒ 视为不可证
        s = self.score(x)
        return (1.0 + float(np.sum(arr >= s))) / (len(arr) + 1.0)

    def check(self, x, domain_posterior):
        d = max(domain_posterior, key=domain_posterior.get)
        H = -sum(p * math.log(p + 1e-12) for p in domain_posterior.values())
        if d not in self.scores or len(self.scores[d]) < self.n_min:
            return CoverageVerdict(False, 0.0, d, 'unknown_domain')
        if H > self.H_max:
            return CoverageVerdict(False, 0.0, d, 'ambiguous_domain')
        p = self.p_value(x, d)
        return CoverageVerdict(p > self.alpha_mix, p, d, 'ok')

    def inflate(self, beta_plus, R_max):
        # 定义 567：越界即按最坏情形抬升（保守）
        return beta_plus + R_max


# IP-367 PrototypeValidationGate：原型验证门（任意时有效 + 合谋注入 + 原子回滚）
class PrototypeValidationGate:
    def __init__(self, alpha=0.05, delta_ni=0.02, c_bound=1.0,
                 rho_max=0.01, phi_max=0.1, N_c=200):
        self.alpha, self.delta_ni, self.c = alpha, delta_ni, c_bound
        self.rho_max, self.phi_max, self.N_c = rho_max, phi_max, N_c
        self.log_E = 0.0
        self.stage = 'S0'
        self.active_slot = 'A'

    def update_e(self, loss_incumbent, loss_candidate, lam=0.5):
        # 定义 570：H0: E[Δ] ≤ −δ_ni，Δ = ℓ_inc − ℓ_cand
        delta = loss_incumbent - loss_candidate
        self.log_E += lam * (delta + self.delta_ni) - 0.5 * (lam * self.c) ** 2
        return math.exp(self.log_E)

    def s0_offline(self, cand):
        return self.replay_noninferior(cand, heldout='mixture_holdout')

    def s1_shadow(self, cand, live_stream):
        self.stage = 'S1'
        for obs in live_stream:             # 候选只算不执行：零致动
            delta = self.loss_incumbent(obs) - self.loss_candidate(obs)
            self.update_e(*delta)
            if self.counterfactual_divergence(obs) > self.shadow_div_max:
                return False
        return True

    def joint_failure_ucb(self, samples, n):
        # 定义 572：Clopper–Pearson 上界
        return clopper_pearson_upper(samples, n, 1.0 - self.alpha)

    def s2_canary(self, cand, env):
        self.stage = 'S2'
        for _ in range(self.N_c):           # Π_r 受限权限，物理行为 ⊆ v11
            obs, done = env.step_restricted(cand, profile='Pi_r')
            self.update_e(*self.paired_losses(obs))
            if done:
                break
        return True

    def consider(self, cand):
        if not self.s0_offline(cand):
            return 'reject'
        if not self.s1_shadow(cand, self.live_stream):
            return 'reject'
        rho_ucb = self.joint_failure_ucb(self.injected_joint_failures,
                                         self.injected_trials)
        if rho_ucb > self.rho_max:
            return 'reject_v11'             # 联合失效不可接受：留在 v11
        if not self.s2_canary(cand, self.env):
            return 'rollback'
        if self.log_E < math.log(1.0 / self.alpha):
            return 'hold'                   # 证据不足：维持旧版
        if not self.signatures_match(cand):
            return 'reject'
        self.atomic_switch(cand)            # 定义 573：A/B 槽原子切换
        self.ledger.append_promotion(cand, self.stage, self.log_E, rho_ucb)
        return 'promote'


# IP-354（二次升级）：配比证书 + 覆盖门控的分块执行器
class MixtureCertifiedChunkCertifier(TriGuardChunkCertifier):
    def __init__(self, *a, dmc=None, ccm=None, pvg=None, **kw):
        super().__init__(*a, **kw)
        self.dmc, self.ccm, self.pvg = dmc, ccm, pvg

    def effective_K(self, ctx, stf, gscf, cov_ok):
        # 定义 575：四重门
        if not (stf.trust_ok(ctx) and gscf.geo_ok(ctx) and cov_ok):
            return 1
        return super().effective_K(ctx.delta_dom, ctx.tau_dom,
                                   trust_ok=True)

    def generate_chunk(self, state, ctx, stf, gscf, sra, nrb, cov):
        K = self.effective_K(ctx, stf, gscf, cov.ok)
        if K == 1:
            return self._single_step_fallback(state)
        best = None
        for cand in self.policy.sample_sequences(state, K, n=64):
            pred = self.Fq.rollout(state, cand)
            beta_gscf = (self.beta_base + self.lam
                         * gscf.field_on_footprint(pred.corridor))
            beta_plus = (beta_gscf if cov.ok else
                         self.ccm.inflate(beta_gscf, self.R_max))
            g_min = pred.min_clearance - beta_plus
            e_max = pred.max_effort + beta_plus
            if g_min < self.d_safe or e_max > state.tau_eff:
                continue
            pts = self._abort_points(state, cand, pred)
            if not pts:
                continue
            chunk = Chunk(cand, TriGuardCert(g_min, e_max, beta_plus, pts), pts)
            chunk, _ = nrb.review_chunk(chunk, stf, ctx)
            if chunk is None:
                continue
            n_reason, _ = sra.reason_on_chunk(chunk, stf, gscf, ctx)
            chunk.cert.n_reason = n_reason
            if not all(n_reason):
                continue
            chunk.cert.mu_t = self.dmc.certify(
                cov.domain, cov.quantile_d, cov.pi, cov.p_within,
                cov.q_within, cov.delta_dom, beta_gscf, self.version_sig)
            chunk.cert.pval_t = cov.pval
            chunk.cert.theta_version = self.version_sig
            if not chunk.cert.valid_v12(version_sig=self.version_sig):
                continue
            chunk.cert.Q_abort = {p: self.jsse.map_abort(p) for p in pts}
            score = self.policy.score(chunk, pred)
            if best is None or score > best.score:
                best = chunk
        return best or self._single_step_fallback(state)

    def midchunk_guard(self, chunk, k_exec, live_obs, stf, gscf, nrb, jsse, cov):
        """50Hz 五检 ≤0.6ms（覆盖检并入检 (i) 证书有效性 + 版本签名）"""
        if not chunk.cert_still_valid(live_obs) or not cov.ok:
            return self._abort_to_jsse(chunk, k_exec, jsse)
        if chunk.cert.theta_version != self.version_sig:
            return self._abort_to_jsse(chunk, k_exec, jsse)
        stop_inv = (live_obs.nearest_clearance
                    - self.d_brake(live_obs.speed) - self.d_safe)
        if stop_inv < chunk.remaining_len(k_exec):
            return self._abort_to_jsse(chunk, k_exec, jsse)
        if stf.surprise_near(live_obs.pose) > stf.tau_sem:
            return self._abort_to_jsse(chunk, k_exec, jsse)
        if nrb.fast_norms(live_obs).violated:
            return self._abort_to_jsse(chunk, k_exec, jsse)
        if not gscf.geo_ok_near(live_obs.pose):
            return self._abort_to_jsse(chunk, k_exec, jsse)
        return ('continue', k_exec + 1)

## 4. 推导

**引理 97（域条件覆盖对配比漂移免疫，仅付域内间隙税）**
设 (A1) 每个域 d 内，标定分数与部署分数在给定 d 时可交换（Mondrian 假设）；(A2) 域内漂移 gap_t^d = TV(p_t(·|d), q_d) ≤ gap_max；(A3) 残差 r∈[0,R_max]。则对 X~p_t，取域 d 的共形分位 Q_w^d(1−ε)，有
```
P( r(X) ≤ Q_w^d(1−ε) + R_max·gap_t^d | d_t=d ) ≥ 1 − ε − gap_t^d.
```
证明：在域 d 内以 TV 耦合构造 (X,Y)，P(X≠Y)=gap_t^d，X~p_t(·|d)、Y~q_d。事件 {r(Y)≤Q_w^d} 的概率 ≥1−ε；在 {X=Y} 上 r(X)=r(Y)。并集界得 ≥1−ε−gap_t^d。对任意域比例 π_t 边缘化，条件保证保持不变。**因此部署端域比例与标定配比 w 不一致本身不消耗安全界**——w 只通过 n_d 影响 Δ_n。∎
（推论：把"配比"当成拟合部署边缘比例是错的目标；正确目标是每域样本充分 + 域内漂移可测。）

**引理 98（分位松弛的最优配比是 2/3 次幂律）**
在定义 566 的目标下，取 Δ_n(n_d)=k/√n_d，Lagrange 乘子给出
```
n_d* ∝ (π(d)/c_d)^{2/3},
```
即部署更常见、采集更便宜的域获得超线性更多样本，但**不是**按 π(d) 线性分配。若改用均值方差目标则退回 Neyman 分配 n_d∝π(d)σ_d/√c_d。证明：对 Σπ_d k n_d^{-1/2} 求导并令其等于 λc_d，解出 n_d^{3/2}∝π_d/c_d。∎
（实践含义：安全证书的"数据配比"应比直觉更偏向高频/廉价域，因为分位估计误差按 n^{-1/2} 收缩。）

**引理 99（CCM 的有限样本有效性与保守性）**
(i) 域内可交换下，Mondrian 共形 p 值超均匀：P_{q_d}(pval≤α_mix)≤α_mix，故对在支持集内的正常观测误报收缩的概率 ≤α_mix；
(ii) 在域内漂移下，P_{p_t}(pval≤α_mix)≤α_mix+gap_t^d（TV 耦合+并集界）；
(iii) 一旦 ¬U_t^mix，系统把 β 抬升 R_max 并令 K_eff≤2，动作集合只收缩不扩张（定义 567、575）；
(iv) 点单后覆盖恢复需 μ_t 重新签发，**不会自动恢复乐观阈值**。∎

**引理 100（原型门的任意时有效误晋升界与影子零风险）**
(i) 定义 570 的 E_t 在 H0 下为非负上鞅（Hoeffding 引理：有界 Δ_t+δ_ni∈[−c,c'] 时 exp(λD−λ²c²/2) 期望 ≤1）；由 Ville 不等式，P(∃t:E_t≥1/α_pvg)≤α_pvg。无论研究员如何偷看、提前停、按结果调参，误晋升率 ≤α_pvg。
(ii) S1 影子阶段候选只计算不执行，物理致动为零，故新增物理风险为 0；其唯一产出是日志与 e-process 更新。
(iii) S2 canary 使用 Π_r，物理行为集合 ⊆ v11 可行集（支配性由 v11 引理 89 保证）。
(iv) 'hold' 分支在证据不足时维持旧版，不产生行为漂移。∎

**引理 101（原型保真度的可迁移性）**
若 φ_proto=TV(p_real,p_sim)≤φ_max，且候选在仿真上以裕度 δ_ni 非劣，则真实分布上非劣裕度至少 δ_ni−L·φ_max；因此选择 δ_ni>L·φ_max 可保证迁移后仍非劣。若 φ_proto 无法证 ≤φ_max，则 S0/S1 结论不迁移，**必须**执行 S2 物理 canary；禁止仅凭仿真晋升。证明：TV 耦合下期望损失差 ≤L·TV；三角不等式。∎

**引理 102（联合失效从"并集界假设"升级为"实测约束"）**
v11 引理 96 用并集界 Σ ε_i 近似联合失效，隐含三守护失效事件近似不交或独立。v12 的 PVG 在 S1/S2 合谋注入三通道，得 ρ̂_joint 的 Clopper–Pearson 上界 ρ_ucb。若 ρ_ucb>ρ_max，候选被拒、系统留 v11（其自身安全界不依赖正交假设）；若 ρ_ucb≤ρ_max，则晋升后联合失效概率以 ≥1−α_pvg 被 ρ_max 约束。**若某失效模式无法构造注入原型，则 ρ_joint 视为未知，禁止晋升**（保守完备性）。∎

**引理 103（v12 联合保守性与对 v11 的支配性）**
在 DMC/CCM/PVG 均正常时，Ĉ⁺⁺⁺ 有效 ⇒ v11 证书条件 ∧ U_t^mix ∧ 版本一致；各失效路径为：DMC→默认配比+保守 gap（β⁺≥β_GSCF）；CCM→U=false（β↑、K_eff≤2）；PVG→冻结（留在已签名 v11）。故任意时刻物理动作集合 ⊆ v11 安全动作集合（支配性），且安全失效概率满足
```
P(危险事件未被捕获) ≤ ε_geo + ε_sra + ε_jsse + ε_β + ε_mix + α_pvg + ρ_max.
```
证明：逐失效路径比较 + 并集界；支配性由"只收缩、不扩权"与"β⁺≥β_GSCF"直接得到。∎

## 8. 本轮最大风险

**一句话**：间隙税 gap_t、域条件共形 p 值 pval_t、以及 PVG 的合谋注入集，全部由**同一批带盲区的数据**估计——若真实漂移恰好发生在标定域从未覆盖的方向（自指盲区：新材质既不被域目录识别、也不在注入原型里），则 gap 系统性偏小、pval 偏大、ρ_joint 偏低，证书会"自证清白"地通过覆盖门与晋升门，v12 的失效因此比 v11 更安静、也更难在事后台账中被归因。
