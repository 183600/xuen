研究循环·灵感三元组（承接 v23；本轮灵感：「放置」×「多传感器融合」）

> **基线**：承接 MetricVoiceGauge-NCD-HUTDH-v23 + IP-431–439（HDL/ACSC/DCSC/HPC-E/CFC++/CESC/FSVC/IPAM/HPC-E+），其上承 v20 联邦感知证书（PCA/CTS/CFC/HPC/CFCtrl）、v19 的 DCM/OGCC/CCV/DRS/OGC 与 v17 的 CLP/S2C/HCG/PSV/APS/AMC。
> 本轮纪律：**放置是"世界状态的不可逆写入"，融合是"独立性图上的证据代数"；二者互为对偶——放置决定融合的信息上限，融合决定放置的验证质量**。不推倒 v23：全部既有证书与单调链 `Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18` 保留。本轮只做一件事：**把"证据的计数共识"升级为"证据的代数共识"，并把机械臂的抓取终点扩展为带不可逆承诺的放置动作**。

## 0. 直觉与动机

**灵感 1（放置 → 不可逆的世界状态提交，而非轨迹终点）**
直觉：v23 的机械臂证书 ACSC 只回答"臂在配空间里怎么动不碰撞、能耗够不够"，但机械臂真正的任务终点是**放下**——一个物体从"机器人身体的一部分"变成"环境的一部分"的瞬间。这一瞬间有三件被 v23 忽略的事：(a) **拓扑切换**：夹持中的物体属于机器人的碰撞体，松开的一刻被写入环境障碍集合，碰撞模型在 release 时刻发生不连续切换；(b) **不可逆性**：放置与抓取不同，松手基本不可撤销——它是一次对世界状态的提交，提交前必须预验证提交后的世界仍然安全；(c) **后置稳定性**：物体会不会倒、会不会滚、会不会堵住人的逃生通道、会不会让机器人再也够不回来。核心创新：**放置承诺证书 (Placement Commitment Certificate, PCC)**：在松手前把后置世界 `W' = W ⊕ (o@p)` 当作一张待验证证书，验证 `Stab ∧ EgressOK ∧ EnergyOK ∧ FreedomOK ∧ Recoverable` 后才允许 release；不可恢复的放置被标记为**吸收态提交**，必须显式人工授权。反直觉点：**放置不是"轨迹的最后一个点"，而是一次不可逆的 commit——证书必须覆盖提交后的世界，而不是提交前的轨迹**。这与 v20 的"障碍只增、自由有偿赎回"同构，但写入主体从"检测证据"变成了"物理放置"。

**灵感 2（多传感器融合 → 从"计数共识"到"独立性代数"）**
直觉：v23 的 CFC+++ 用"计数 ≥ N-F ∧ 模态数 ≥ 2 ∧ 层级一致"仲裁，这是**基数（counting）视角**——只要票数够、模态够多，就默认证据独立可加。但这是错的：10 个摄像头若共用同一镜头镀膜、同一电源、同一训练集、同一安装位置，它们在**共模故障**面前只是 1 个证据源。融合的真正难点不是"怎么把票加起来"，而是"**这些票在统计上是否可加**"——即独立性。核心创新：**融合独立性代数 (Fusion Independence Algebra, FIA)**：每条证据带 `(来源根, 故障模式标签, 覆盖区域, 时间戳)`，用**故障模式超图 H_fail** 诱导**独立性拟阵 M_ind**，定义有效证据数 `N_eff = rank(M_ind)`；连续量用**协方差交集 (Covariance Intersection, CI)** 融合（对未知相关鲁棒、绝不虚高置信），离散量用 **Dempster–Shafer** 融合并以冲突质量 K 作为"拒绝融合"闸门（Zadeh 悖论）。反直觉点：**融合不凭空制造信息；对相关源做朴素乘积，会把"同一句话重复十遍"当成"十个独立证人"**——独立性的真正敌人是共享故障模式，而不是缺少模态。副产品：**回声室**被形式化——若所有机器人订阅同一云端检测器，溯源图塌缩为单根，`N_eff=1`。

**二者如何统一（配置—证据对偶）**
- 放置（物体/传感器/机器人）是对世界/观测配置的不可逆提交，**决定融合的信息上限**：传感器放在哪，决定覆盖 `Cov_t` 与视角多样性；
- 融合是对已放置配置下多源证据的代数合成，**决定放置的验证质量**：能否证明"覆盖区内无人"，从而安全地把物体放下。
共享状态扩展为 `ζ_fuse = ζ_v23 ∪ (M_t, H_fail, M_ind, {(μ_i,Σ_i)}, {m_i}, W_post, F(W))`。统一准入门 **HPC-F = HPC-E+ ∧ PCC ∧ SPOC ∧ NEFC ∧ (N_eff ≥ N_req) ∧ (K ≤ κ_conflict)**。关键统一：缺席证书的可靠性不再只押在单检测器召回 `κ_c` 上，而是 `AbsConf = 1 - ∏_{i∈MIS}(1-κ_i) - ε_cm`，其中 MIS 为最大独立传感器集、`ε_cm` 为未建模共模的鲁棒裕度——**把"缺席幻觉"从单点假设升级为可量化的独立性核算**。

## 2. 设计原则（在 P37–P42 基础上新增 P43–P45）

**P43 放置不可逆承诺律（Placement Irreversibility）**
放置动作 `a: (W,o,p) ↦ W' = W ⊕ (o@p)` 仅当后置证书 `Stab ∧ EgressOK ∧ EnergyOK ∧ FreedomOK` 成立才可执行；`FreedomOK ≜ F(W') ⪰ F(W) - Δ_allowed`（按 `(#逃生通道, 可达自由体积, 能量余量)` 字典序）。无可恢复路径的放置标记为吸收态，须显式人工授权。放置只增障碍、只收缩自由度，故 `Exec_v24 ⊆ Exec_v23`。release 必须走状态机 `HELD→PRE_PLACE→STABLE_CHECK→RELEASED→SETTLED`，任一环节失败即中止并回抓，绝不带病松手。

**P44 融合独立性核算律（Fusion Independence Accounting）**
融合置信只能由**独立性修正后的有效证据数**与**一致性（非冲突）**决定：`N_eff = rank(M_ind)`，原始票数不得提升置信。连续量用 CI（对未知相关鲁棒），离散量用 DS 且 `K > κ_conflict` 时**拒绝融合**。**不得假设独立**：未知故障模式一律视为相关（`N_eff` 取最保守）。隐藏共模只能被"更保守的 ε_cm"部分吸收，不能被证明消除。

**P45 放置-观测对偶律（Placement-Observability Duality）**
覆盖是放置的函数：`Cov_t = ⋃_i Cov(mount_i, occlusion_t)`。缺席证书仅在 `SPOC(M_t, R) ∧ NEFC(R)` 成立时可签发，且 `AbsCert(R) ⇒ SPOC(M_t,R)`。主动重放置是放置动作，受 P43（能量、时间、不可逆）约束；覆盖之外一律保守，不得以"移动后会更清楚"为由在当下签发无覆盖的缺席证书。

## 3. 与基线的接口（如何退化）

- PCC 失效（稳定性/通道验证不可用）⇒ 禁止 release，保持夹持或退回搬运前安全位 ⇒ 比 v23 更保守；
- FIA 失效（故障模式未知）⇒ 一律视为相关，`N_eff=1`，退化为最保守单源融合（绝不更乐观）；
- FPL 失效（溯源丢失）⇒ 无法证明独立 ⇒ 同上 `N_eff=1`；
- SPOC 失效（覆盖不可证）⇒ 全域"可能有人"、无缺席证书，退回 v23 人距上限；
- NEFC 失效 ⇒ 弃用负信息、只保留正证据，退回 v23 单 `κ_c` 缺席证书（更保守）；
- APP 失效 ⇒ 不主动移动，静态放置，退回 v23；
- 全失效 ⇒ 回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18`。
- **安全继承**：PCC 只增障碍、只收缩自由度；FIA 只降置信不升；SPOC 只给覆盖证明、缺失即保守；NEFC 只赎有证自由；APP 受 P43 约束。任意失效都向更保守方向退化。

## 4. 预期贡献

1. **放置承诺证书**：首次把"松手"建模为不可逆的世界状态提交，给出后置稳定性/逃生通道/能量/自由度/可恢复性的联合预验证，并区分可恢复放置与吸收态放置；
2. **融合独立性代数**：把 CFC+++ 的"计数共识"升级为"独立性拟阵上的代数共识"（CI + DS + 冲突闸门），使"相关源重复投票"在结构上无法提升置信；
3. **独立性修正的缺席证书**：给出 `AbsConf = 1 - ∏_{MIS}(1-κ_i) - ε_cm`，把回声室/共模失效显式量化为 `N_eff` 塌缩，并给出数值对照；
4. **放置-可观测对偶**：SPOC + 主动重放置，把"传感器放哪儿"纳入证书体系，使缺席证书的可靠性可追溯到放置；
5. **HPC-F 统一准入门**：`Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18` 闭环，任意失效向保守退化；
6. **封堵更底层的风险**：把 v23 遗留的"缺席幻觉"从单点召回假设，升级为对独立性误设的显式鲁棒裕度 `ε_cm`。

## 5. 本轮最大风险

**一句话**：独立性模型本身不可证伪——把"已知故障模式不共享"误当作"统计独立"，一旦存在未建模的隐藏共模（同频干扰、同一反光面、同一对抗光照），独立性加权融合会给出虚假的高置信缺席证书，并驱动一次不可逆的放置，使系统**自信地、可审计地、不可撤销地**制造一个事后无法挽回的错误世界状态。

## 1. 关键算法骨架（在 IP-431–439 骨架上扩展）

```python
# ============================================================
# IP-440 Placement Commitment Certificate (PCC) — 放置承诺证书
# ============================================================
class PlaceDecision(Enum):
    ADMIT = "admit"
    NEED_HUMAN_ACK = "need_human_ack"   # 吸收态：不可恢复，须人工授权
    ABORT = "abort"

@dataclass
class PlacementGoal:
    obj_id: str
    pose: Pose                 # SE(3)
    support: "SupportSurface"

class PlacementCommitmentCertificate:
    def __init__(self, delta_freedom, n_egress_min=2, w_min=0.9,
                 tau_rev=5.0, eps_contact=0.01):
        self.delta_freedom = delta_freedom     # Δ_allowed（字典序三元组）
        self.n_egress_min = n_egress_min
        self.w_min = w_min
        self.tau_rev = tau_rev
        self.eps_contact = eps_contact         # 接触点不确定性膨胀

    def post_state(self, W, goal) -> "World":
        """后置世界：把带不确定性的物体写入环境障碍集"""
        return W.insert_obstacle(goal.obj_id,
                                 inflate(goal.pose, self.eps_contact))

    def stable(self, W, goal) -> bool:
        """质心投影 ∈ 接触点凸包 ∧ 摩擦锥"""
        contacts = self.contact_points(W, goal)
        if not contacts:
            return False
        com = center_of_mass(goal.obj_id, goal.pose)
        if not point_in_convex_hull(com, contacts):
            return False
        return friction_cone_ok(goal, contacts, mu_min=0.4)

    def egress_ok(self, W_post) -> bool:
        for h in W_post.humans:
            corridors = escape_corridors(W_post, h)
            if len(corridors) < self.n_egress_min:
                return False
            if min(c.width for c in corridors) < self.w_min:
                return False
        return True

    def freedom(self, W, E_res) -> tuple:
        """字典序自由度：逃生数 / 可达自由体积 / 能量余量"""
        return (self.num_escape(W), self.reachable_volume(W), E_res)

    def freedom_ok(self, W, W_post, E_res) -> bool:
        f0 = self.freedom(W, E_res)
        f1 = self.freedom(W_post, E_res)
        return all(b >= a - d for a, b, d in zip(f0, f1, self.delta_freedom))

    def recoverable(self, W_post, goal, E_res) -> bool:
        """能否再抓回或撤离（增量可达性查询，不做全规划）"""
        can_regrasp = reach_test(W_post, goal) and E_res >= self.E_regrasp()
        can_retreat = reach_test(W_post, self.retreat_pose(W_post))
        return can_regrasp or can_retreat

    def pre_check(self, W, goal, E_res) -> PlaceDecision:
        if not self.stable(W, goal):
            return PlaceDecision.ABORT
        W_post = self.post_state(W, goal)
        if not self.egress_ok(W_post):
            return PlaceDecision.ABORT
        if E_res < self.E_release() + self.E_retreat() + self.E_margin:
            return PlaceDecision.ABORT
        if not self.freedom_ok(W, W_post, E_res):
            return PlaceDecision.ABORT
        if not self.recoverable(W_post, goal, E_res):
            return PlaceDecision.NEED_HUMAN_ACK      # 吸收态
        return PlaceDecision.ADMIT

    def release(self, W, goal, manip, E_res):
        """release 五态状态机：拓扑切换严格发生在 RELEASED 之后"""
        assert self.pre_check(W, goal, E_res) == PlaceDecision.ADMIT
        self._enter("PRE_PLACE", goal)
        if not self._settle_contact(goal):
            return self._abort_regrasp()             # 支撑未建立，回抓
        self._enter("STABLE_CHECK")
        if not self.stable(W, goal):
            return self._abort_regrasp()
        manip.open_gripper()                          # 松手
        self._enter("RELEASED")
        W.remove_from_body(goal.obj_id)               # 拓扑切换：移出机器人碰撞体
        W_post = self.post_state(W, goal)             # 写入环境障碍集
        if not self._settled(W_post, goal):
            return self._fall_recovery()              # 未静止，进入跌落恢复
        self._enter("SETTLED")
        return W_post

# IP-441 Fusion Independence Algebra (FIA) — 融合独立性代数
# ============================================================
class FusionIndependenceAlgebra:
    def __init__(self, H_fail, kappa_conflict=0.5):
        self.H_fail = [frozenset(h) for h in H_fail]   # 故障模式超图
        self.kappa_conflict = kappa_conflict

    def is_independent(self, S) -> bool:
        """S 独立 ⇔ 没有任何故障模式超边被 S 完整包含"""
        S = frozenset(S)
        return all(not (h <= S) for h in self.H_fail)

    def max_independent(self, S):
        """N_eff = 最大独立子集（N 小，穷举；partition 情形 O(N)）"""
        S = list(S)
        for r in range(len(S), 0, -1):
            for subset in combinations(S, r):
                if self.is_independent(subset):
                    return list(subset)
        return []

    def effective_count(self, S) -> int:
        return len(self.max_independent(S))

    def ci_fuse(self, ests):
        """连续量：协方差交集，对未知相关一致、绝不虚高置信
        ests: [(mu_i, Sigma_i)]，求 ω 最小化 det(Σ_CI)"""
        omega = solve_ci_weights(ests)                 # Σω=1, ω≥0
        Sinv = sum(w * inv(S) for w, (_, S) in zip(omega, ests))
        Sigma = inv(Sinv)
        mu = Sigma @ sum(w * inv(S) @ m for w, (m, S) in zip(omega, ests))
        return mu, Sigma

    def ds_fuse(self, masses):
        """离散量：Dempster–Shafer + 冲突闸门（Zadeh 悖论拒绝融合）"""
        m = masses[0]
        for m2 in masses[1:]:
            K = sum(m[B] * m2[C] for B in m for C in m2 if B & C == set())
            if K > self.kappa_conflict:
                raise FusionRefused(f"Zadeh conflict K={K:.3f}")
            m = self._combine(m, m2, K)
        return m

    def _combine(self, m1, m2, K):
        out = defaultdict(float)
        for B, mb in m1.items():
            for C, mc in m2.items():
                out[B & C] += mb * mc
        return {k: v / (1 - K) for k, v in out.items()}

# IP-442 Fusion Provenance Ledger (FPL) — 回声室检测与 H_fail 推断
# ============================================================
class FusionProvenanceLedger:
    def __init__(self):
        self.records = {}   # eid -> (root, failure_tags, coverage, ts)

    def record(self, eid, root, failure_tags, coverage, ts):
        self.records[eid] = (root, set(failure_tags), coverage, ts)

    def echo_chamber(self, eids) -> bool:
        """所有证据溯源到同一根 ⇒ 回声室 ⇒ N_eff=1"""
        return len({self.records[e][0] for e in eids}) == 1

    def infer_failure_modes(self, eids) -> list:
        """按共享故障标签聚类，生成 H_fail 超边"""
        groups = defaultdict(set)
        for e in eids:
            for tag in self.records[e][1]:
                groups[tag].add(e)
        return [frozenset(g) for g in groups.values() if len(g) > 1]

# IP-443 Sensor Placement Observability Certificate (SPOC)
# ============================================================
class SensorPlacementObservability:
    def __init__(self, delta_obs=0.01):
        self.delta_obs = delta_obs

    def coverage(self, mounts, occ):
        cov = CoverageGrid()
        for sensor, pose in mounts:
            cov |= (fov_projection(sensor, pose)
                    & ~occlusion_mask(occ, pose, sensor))
        return cov

    def certify(self, mounts, R_crit, occ) -> "ObservabilityCert":
        cov = self.coverage(mounts, occ)
        blind = {r for r in R_crit if cov.prob(r) < 1 - self.delta_obs}
        return ObservabilityCert(ok=(len(blind) == 0), blind=blind, cov=cov)


# ============================================================
# IP-444 Negative Evidence Fusion Certificate (NEFC)
# ============================================================
class NegativeEvidenceFusion:
    def __init__(self, fia: FusionIndependenceAlgebra, eps_cm: float):
        self.fia = fia
        self.eps_cm = eps_cm        # 未建模共模鲁棒裕度

    def abs_conf(self, R, sensors, recalls, presence) -> float:
        # 任一在场证据 → 缺席置信归零（在场一票否决）
        if any(presence(i, R) for i in sensors):
            return 0.0
        I_R = [i for i in sensors if covers(i, R)]
        MIS = self.fia.max_independent(I_R)   # 只对独立子集做乘积
        prod = 1.0
        for i in MIS:
            prod *= (1 - recalls[i])
        return max(0.0, 1 - prod - self.eps_cm)


# ============================================================
# IP-445 Active Placement Planner (APP) — 主动重放置消歧
# ============================================================
class ActivePlacementPlanner:
    def __init__(self, spoc, pcc, gain_threshold=0.1, hysteresis=0.05):
        self.spoc, self.pcc = spoc, pcc
        self.gain_threshold = gain_threshold
        self.hysteresis = hysteresis

    def propose(self, mounts, R_uncertain, occ, E_res):
        base = self.spoc.coverage(mounts, occ)
        best, best_gain = None, 0.0
        for cand in self._candidate_repositions(mounts, R_uncertain):
            # 重放置本身是放置动作，受 P43 能量/不可逆约束
            if self.pcc.energy_for_move(cand) > 0.3 * E_res:
                continue
            gain = (self.spoc.coverage(cand, occ) - base).measure(R_uncertain)
            if gain > best_gain + self.hysteresis:      # 滞回防振荡
                best, best_gain = cand, gain
        return best if best_gain >= self.gain_threshold else None


# ============================================================
# IP-446 HPC-F 统一融合-承诺准入门
# ============================================================
@dataclass
class HPCF:
    hpc_e_plus: HPCEPlus
    pcc: PlacementCommitmentCertificate
    spoc: SensorPlacementObservability
    nefc: NegativeEvidenceFusion
    fia: FusionIndependenceAlgebra
    N_req: int = 2
    kappa_conflict: float = 0.5
    alpha: float = 0.01

    def admits(self, plan, W, goal, mounts, R_crit, evidence, E_res, modules) -> bool:
        # 1. v23 四证
        if not self.hpc_e_plus.admits(plan, W.x, W.v, W.z, E_res,
                                      W.margin_req, modules):
            return False
        # 2. 放置承诺（若有放置动作）
        if goal is not None and \
           self.pcc.pre_check(W, goal, E_res) != PlaceDecision.ADMIT:
            return False
        # 3. 可观测性（缺席证书的前提）
        if not self.spoc.certify(mounts, R_crit, W.occlusion).ok:
            return False
        # 4. 负证据独立性修正
        if self.nefc.abs_conf(R_crit, evidence.sensors,
                              evidence.recalls, evidence.presence) < 1 - self.alpha:
            return False
        # 5. 融合独立性与冲突
        if self.fia.effective_count(evidence.sensors) < self.N_req:
            return False
        if evidence.conflict > self.kappa_conflict:
            return False
        return True
```

## 3. 正确性论证

### 引理 1（放置单调性 ⇒ 执行集单调收缩）
**陈述**：任一 PCC-admissible 的 release 只增障碍、只收缩可达集，故 `Exec_v24 ⊆ Exec_v23`。

**证明**：`post_state` 将膨胀后的物体写入 `Obs`，自由空间 `Free(W') ⊆ Free(W)`；`freedom_ok` 要求 `F(W') ⪰ F(W) − Δ_allowed`。任意在 `W'` 上可行的计划（须避开新增障碍）在 `W` 上亦可行，故 `Exec(W') ⊆ Exec(W)`。与 v23 四证取交后单调性保持。∎

### 引理 2（协方差交集的一致性）
**陈述**：CI 融合给出的 `Σ_CI` 对任意未知互相关都是**保守**的（PSD 意义下不小于真实后验协方差），因此融合置信绝不超过独立证据所能支持的程度。

**证明**：由 Julier–Uhlmann（1997），取 `Σ_CI^{-1}=Σ_i ω_i Σ_i^{-1}`、`Σω_i=1` 的 CI 估计对任意相关结构均一致（consistent）。故不存在"因假设独立而虚高"的置信；融合只会低估信息、不会高估。∎

### 引理 3（独立性修正缺席 + 回声室塌缩）
**陈述**：在 MIS 相互独立假设下 `P(若有人则被检出) = 1 - ∏_{i∈MIS}(1-κ_i)`，故 `AbsConf = 1 - ∏_{MIS}(1-κ_i) - ε_cm`；若多源共享同一故障类，则 `|MIS|=1`，`AbsConf = 1-κ_max`，而非朴素乘积。

**证明**：独立源同时沉默的概率为 `∏(1-κ_i)`；拟阵 `rank` 恰为最大独立子集大小，相关源被超边归并、只计一份。**数值对照**：8 个同故障类相机 `κ=0.95` ⇒ `N_eff=1`、`AbsConf=0.95`，而朴素乘积给出 `1-0.05^8 ≈ 1-3.9×10^{-11}`（灾难性虚高）；3 个独立模态 `κ=(0.95,0.9,0.85)` ⇒ `AbsConf=1-0.05·0.1·0.15=0.99925`。∎

### 引理 4（放置-观测必要性）
**陈述**：若对区域 R 签发了缺席证书，则签发时刻 `SPOC(M_t,R)` 成立且 `NEFC(R)>0`。逆否：覆盖未认证的区域不得签发缺席证书。

**证明**：由 `HPCF.admits` 的判定次序，第 3 步要求 `SPOC.certify(...).ok`、第 4 步要求 `NEFC.abs_conf ≥ 1-α`，任一不满足即拒证；`AbsCert` 是这两步的合取结果。∎

### 引理 5（隐藏共模的条件性保证）
**陈述**：`AbsConf` 的可靠性以 `H_fail` 的完备性为前提；`ε_cm` 只吸收已知故障类的统计波动，**不覆盖完全未建模的共模**。因此这是一个**条件性**保证，而非绝对保证。

**证明**：若存在未进入 `H_fail` 的共模故障，受影响源的真实检出率可低至其共同失效模式所决定的值，而 `MIS` 仍把它们当作独立，故 `AbsConf` 对真实安全概率构成**上界的高估**。任何有限 `ε_cm` 都不能消除任意未建模共模（极端情形下全体同时失效、真实检出率≈0）。这正是本轮最大风险的形式化表述。∎

### 定理（HPC-F 双律完备性与单调链）
**陈述**：对任意计划 π，`HPCF.admits(π)=True` ⟺ π 同时满足：(1) v23 四证（物理接地∧云边一致∧少样本覆盖∧IP 完备）；(2) 放置承诺 `PCC`；(3) 可观测性 `SPOC`；(4) 独立性修正缺席 `NEFC`；(5) 有效独立性 `N_eff ≥ N_req` 且 `K ≤ κ_conflict`。且任意失效下 `Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18`。

**证明**：充分性/必要性直接由 `admits` 五个连言条件与引理 1–4 得到。单调链：PCC 只增障碍、FIA 只降置信、SPOC 缺失即保守、NEFC 只赎有证自由、APP 受 P43 约束，逐项失效均向更保守退化（见想法区第 3 节），取交后单调性保持。∎
