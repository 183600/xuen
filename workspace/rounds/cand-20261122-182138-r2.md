# 第 2 轮（UniBot 线 · 第 2 轮；本轮灵感：「移动操作」×「情感计算」）

> **承接声明**：承接第 1 轮 `UniBot-SAGE`。赛题基线不变（UniBot-V1 / Unitree G1 / 32 桌面任务 / 单通才 checkpoint / 5 类泛化 / 选手自部署 + 标准 API 远程接入）。本轮**不推倒重来，只补第 1 轮暴露的两个缺口**：**身体可达性（移动）** 与 **带校准的自我状态（情感计算的可迁移内核）**。新增编号：定义 U13–U22、引理 L8–L13、实验 E619–E634；U1–U12 / L1–L7 / E601–E618 继续有效。

## 0. 先把两个灵感拆到"可迁移内核"（防止伪跨学科）

### 0.1 「移动操作」→ 可达性不是常量，而是身体状态的函数
**直觉**：桌面任务看起来是"手臂问题"，但 G1 是**移动人形**，接口同时暴露 `action.pivot`(7) 与 `observation.state.lower_body`(15)。同一只手去够同一个杯子，躯干前倾 10° 与原地不动，末端的**可操作度**和插入相位的手感完全不同。第 1 轮把 pivot 当 P1 附加项（IP-05），这是**定位错误**：对"最后一环"的插入/旋转，身体是预条件化变量，不是装饰。

**严谨定义**：给定含 base/torso 的身体构型 `q`，末端可操作度 `w(q)=sqrt(det(J(q)J(q)^T))`（Yoshikawa 1985）；目标位姿的**插入就绪区** `R* = { q : w(q) ≥ w_min 且 target ∈ reach(q) }`。移动操作的可迁移内核 = **把 `q` 当作可主动选择的变量，让高精度相位落在 `R*` 内**，而不是"够不到了才挪"。

**第二内核（常被忽略）**：**自运动噪声**。基座一动，头/腕相机会产生运动模糊与帧间错位，感知不确定性随 `‖v_base‖`、`‖ω_base‖` 上升——**移动会污染自己的观测**。所以"移动"既是能力，也是噪声源，必须进入不确定度预算。

### 0.2 「情感计算」→ 可迁移内核不是情绪标签，而是"内部状态估计 + 校准 + 据此改变行为"
**直觉**：情感计算真正成熟的部分，不是"识别开心/生气"，而是一整套方法论：从**弱、噪、多模态**信号估计**不可直接观测**的内部状态；给状态配**可解释的置信度并做校准**；再据此做 **meta-control**（继续 / 退缩 / 求助 / 重新投入）。这恰好是第 1 轮 IP-02「抓握隐变量」缺失的上半身——第 1 轮只会判"抓没抓住"，不会判"还要不要继续"。

**严谨定义（三大构件 → 操作任务的同构物）**：

| 情感计算构件 | 经典表述 | 操作任务中的同构物 |
|---|---|---|
| 构念 construct | valence–arousal 二维环状模型（Russell 1980） | **进展–紧迫** `(ρ, υ)` 二维自我状态 |
| 评价 appraisal | 事件相对目标的评价决定反应（Lazarus 1991；Scherer 2001） | 相对任务目标的**进度/风险评价**，驱动 persist/retry/switch |
| 校准 calibration | 置信度必须有意义（可靠性图、ECE；Guo et al. 2017） | 干预决策的**分布无关风险界**（conformal / RCPS） |
| 调节 regulation | 情绪调节行为 | 元动作集 `{PERSIST, SLOW, RETRY_GRASP, SWITCH_PRIMITIVE, REPOSITION, SAFE_STOP}` |

> **明确不做**：不预测"机器人情绪"，不把人类情绪标签硬套到操作上（那是伪跨学科）。"情感"在此是**内部状态与元控制的工程同构**，可被形式化、可被证伪。

### 0.3 合成
移动操作提供**空间/身体轴**（可达性、可操作度、自运动噪声）；情感计算提供**时间/状态轴**（带校准的进展-紧迫估计与元控制）。二者交于一句：
**在时间与身体两个尺度上，把"是否 / 如何继续尝试"变成一个带风险保证的决策。**
代号 **UniBot-EMPA**（**E**mbodied **M**obility & **P**rogress **A**ppraisal）。

## 1. 第 1 轮遗留的五个缺口（本轮只补这些）

1. **抓握是瞬时二值**：缺整段 episode 的连续自我状态 → 只会"抓没抓住"，不会"还要不要继续"。
2. **U6 的手工阈值 + L3 的 `α≤0.02` 是假设而非保证**：第 1 轮最大风险（误判不对称）没有被真正消除，只是被"高阈值"缓冲。
3. **IP-05 把 pivot 当附加项**：可达性未被当一等变量；且移动带来的自运动噪声完全未建模。
4. **六因子的 transport 只指"搬物体"**：没区分"**移动身体换取可操作度**"这一主动动作，导致机动策略无位置。
5. **第 5 类泛化是人为干扰**：第 1 轮没有任何"读人"的能力——这恰是情感计算方法论唯一名正言顺的**外部**应用（读**行为意图**，不读情绪标签）。

## 2. 研究问题（Q6–Q10）

- **Q6（自我状态可估性）**：只用官方观测（腕/头帧、抓手、EE、lower_body）能否估出连续的 `(ρ,υ)`，并在 OOD 上保持校准（ECE ≤ 0.05）？
- **Q7（干预的风险界）**：能否把"只在确该介入时介入"做成**分布无关**的风险控制（假干预率 ≤ α），并在 OOD 偏移下用**只调阈值不调权重**的在线校准维持？
- **Q8（可达性预测失败）**：从数据重建的末端可操作度 `w(q)` 在插入时刻是否预测"最后一环"失败？若 `w` 与失败无关，则整个移动轴砍掉（预注册）。
- **Q9（主动预置身体）**：在 transport 相位把 base/torso 预置到最大化插入点 `w` 的位置，是否比"够不到才挪"更涨点？代价是关节运动与潜在场景碰撞。
- **Q10（外部意图）**：在"人为干扰"场景，用**行为**（接近速度、手轨迹、朝向）而非情绪标签推断 `{忽略, 让行, 等待, 恢复}`，是否安全且有效？

## 3. 设计原则（在 P1–P6 之上追加）

- **P7 无风险界不干预**：任何 meta-action 必须满足可校准的风险上界；否则退化为 `PERSIST`（保守）。把第 1 轮的"高阈值启发式"升级为"可证的风险预算"。
- **P8 移动是预条件化**：主动 reposition 只在 transport 相位、且以"提升终态可操作度"为目标，不做无目标的反应式追物。
- **P9 内外分离**：内部自我状态 `(ρ,υ)` 与外部人类意图 `h` 分开建模、分开校验，不互相冒充、不拟人。
- **P10 在线校准只动阈值**：跨 episode 的阈值自适应属于**输出统计**、不改权重（合规安全）；权重级适配仍受第 1 轮 Q4 约束。

## 4. 本轮的核心机制（一句话版本）

第 1 轮是"抓握确认 + 手工重试规则"；本轮把它升级为 **`(进展, 紧迫, 可达性风险)` 三元状态 → 带分布无关风险界的元控制**：
- 状态层：`AppraisalCore` 估 `(ρ,υ)`，`ReachModel` 估插入点 `w` 与余量；
- 保证层：`ConformalGuard` 用 RCPS 标定干预阈值、用 ACI 在 episode 流上只调阈值；
- 行为层：`MetaController` 在四个象限里选 `PERSIST / SLOW / RETRY / SWITCH / REPOSITION / SAFE_STOP`；
- 噪声层：`EgoMotionUncertainty` 把基座运动变成感知不确定度，进入 chunk 调度与干预门槛。

## 5. 本轮最大风险（一句话）

本轮把收益押在"**校准后的干预**"上，但分布无关保证以**可交换性**为前提，而 UniBot 的 5 类泛化恰是破坏可交换性的地方——于是最安全的策略可能退化为"**永不干预**"（无收益），最激进的策略又回到第 1 轮的误判风险；方案的命门是**保证与收益在分布偏移下是否可兼得**，而非模型本身不够强。

## 0. 本轮结论摘要

**一句话路线**：给单通才策略加两层第 1 轮没有的"元能力"——**能感知自己的身体够不够得着（移动）** + **能校准地判断该不该继续（评价）**；二者合成一个**带分布无关风险界的元控制器**，专守"最后一环"。

**与 v1 的差别（四条）**：

| 维度 | v1（SAGE） | v2（EMPA） |
|---|---|---|
| 抓握/失败判定 | 二值抓握隐变量 + 手工阈值 U6 | 连续 `(ρ,υ)` 评价态 + **RCPS 风险界** |
| 干预安全 | 假设 `α≤0.02`（L3） | **保证**假干预率 ≤ α（L9/L10），ACI 抗偏移 |
| 身体 | pivot 为 P1 附加项 | 可操作度 `w(q)` 为**一等风险因子**，transport 主动预置 |
| 人的因素 | 完全未处理 | 人为干扰场景做**行为意图**推断（P2，非情绪标签） |

**保留红线（P5/P6/P9）**：单一 checkpoint、单一 API；不读评测侧私有信息；不拟人、不做情绪分类；所有新增模块都在策略服务内部，不改变对外接口。

## 2. 创新点详述（只写新增与实质修改）

### A1 · AppraisalCore：连续评价态 `(ρ,υ)`（P0，新）

- **动机**：第 1 轮 IP-02 只判"抓住没有"，但真机失败更多是"还在推进、但方向已错"或"看似正常、其实即将不可逆失败"。需要整段 episode 的**连续自我状态**。
- **与现有方案的差异**：情感计算里 valence–arousal 用一个二维连续空间刻画内部状态；我们把它工程化为 `(进展 ρ, 紧迫 υ)`：`ρ` = 当前尝试将成功的概率；`υ` = 不干预时进展的**预期衰减率**（越接近不可逆失败越紧迫）。这不是情绪，而是**可由数据定义、可校准、可证伪**的状态量。
- **技术可行性**：高。输入全在观测里（腕/头帧特征 + 抓手 + EE + lower_body），小骨干（ViT-S/ResNet18 级）即可；标签用两类**弱监督**：①episode 末成功/失败做终局标签；②时序上的"物体相对腕位移、夹爪开合、EE 速度"做过程伪标签。`υ` 用"未来 k 步内 `ρ` 的下降量"回归（无需人工）。
- **落地步骤**：①固定特征与融合；②训练 `ρ` 头（终局+过程标签）+ 校准（温度/isotonic）；③训练 `υ` 头（未来衰减回归）；④可靠性图与 ECE；⑤在 OOD 切分上测退化并交给 A2 处理。
- **风险**：弱标签在未见物品漂移（第 1 轮同源风险），但本轮**不再靠"提高阈值"硬扛**，而是交给 A2 的分布无关风险控制 + ACI。

### A2 · ConformalGuard：分布无关的干预风险界（P0，新，本轮理论核心）

- **动机**：第 1 轮 L3 说"取 `τ_conf` 使 `α≤0.02`"，但**没有任何机制保证**它真的成立；且"漏判把可救失败变硬失败"的成本不对称。这是第 1 轮最大风险的技术根。
- **做法**：把"是否干预"定义为一个**选择性风险控制**问题。对一次干预定义**伤害事件** `ℓ=1[干预 ∧ 基线本会成功]`（反事实用离线回放 + 少量随机 A/B 估计）。用 **Learn-then-Test / RCPS** 在标定集上选择干预阈值，使 `P(ℓ=1) ≤ α` 以概率 `1−δ` 成立；再用 **Adaptive Conformal Inference (ACI)** 在 episode 流上更新阈值：
  `τ_{n+1} = τ_n + γ(α − ℓ_n)`。
  关键：ACI **只改阈值、不改任何模型权重** ⇒ 属于输出级统计，天然规避第 1 轮 Q4 的"在线权重更新"合规问题（P10）。
- **与现有方案的差异**：多数"失败检测→重试"用的是固定阈值或拍脑袋门控；我们把"不误伤基线"从**经验**升级为**有限样本保证**，并显式处理 OOD。
- **技术可行性**：中–高。RCPS 是成熟方法；难点是**伤害事件的反事实**——用"同分布基线回放"近似，并在真机小样本上做 A/B 校正。若反事实不可估，则退化为 **Neyman–Pearson 式受控策略**（给定误报预算最大化检出）。
- **落地步骤**：①定义 score 与伤害事件；②离线标定 τ；③OOD 分域标定 + ACI；④真机 A/B 验 harm 与净收益；⑤把 τ 与降级计数写入 IP-08 审计。
- **风险**：①反事实估计偏；②若 OOD 极端，ACI 会把 τ 推高到"永不干预"（见 §9 与 §12 的最大风险）——需用"**最小干预率下限 + 收益监控**"检测这种退化，并回退到"仅 episode 内调制"。

### M1 · ReachPreposition：可达性预置（P0′，升格自 IP-05）

- **动机**：移动操作的可迁移内核是"身体决定可达性"。插入/旋转类（teaser 榜最难档）对手腕姿态与力方向极敏感，若末端处于**低可操作度**构型，最后几厘米必然抖、必然对不准。
- **做法**：从数据/URDF 估雅可比，算 `w(q)`；预测目标插入位姿；在 **transport 相位**选 `q* = argmax_q w(q)`，约束"目标在 `R*` 内、运动平滑、无碰撞、不扰动场景"。用 `action.pivot`/lower_body 输出。
- **与现有方案的差异**：v1 的 IP-05 是"从 WBT 人体数据蒸馏姿态先验"，偏数据驱动且是附加项；本轮改为**几何目标驱动**（可操作度），并用零成本探测先行，避免在 pivot 语义未明时瞎投入。
- **可行性**：中。**前提是先做 E619**：确认官方数据里 pivot/lower_body 是否非恒定、是否被跟踪。若是常量或不被跟踪，M1 立即降为 P2（或封存）。
- **风险**：①pivot 语义/跟踪未知；②主动移动可能撞击场景或延长 transport；③可操作度是局部几何量，未必等于成功率——必须由 E620 的**相关性**先验决定去留。

### M2 · EgoMotionUncertainty：自运动不确定度（P1，新）

- **动机**：基座运动 = 相机运动 = 运动模糊 + 帧间错位。用运动中的模糊帧做精细判定（尤其插入前）会**系统性高估把握**。
- **做法**：`σ_perc(t) = σ0·(1 + κ_v‖v_base‖ + κ_ω‖ω_base‖ + κ_b·blur_t)`；把 `σ_perc` 注入 A1 的不确定度并调高干预门槛、缩短 chunk（高运动相位用短 chunk + 低频反馈）。
- **可行性**：高（无需训练，规则 + 在线量）；风险是噪声模型不准 ⇒ 只作为"上调不确定度"的单向安全阀（宁保守）。

### H1 · InterferenceIntent：干扰意图推断（P2，新，外部应用）

- **动机**：第 5 类泛化是"人为干扰"。这不是要机器人理解情绪，而是要判断**人的行为意图**：靠近是想接管、旁观、还是路过？据此选择 `IGNORE / YIELD / WAIT / RESUME`。
- **做法**：头相机检测人体/手部轨迹 + 接近速度 + 朝向；输出离散意图与置信度；高置信才让行，低置信保持原策略（同 A2 的保守原则）。**明确禁止**使用面部情绪分类。
- **定位**：P2，仅在第 1–2 项 P0 稳定后做；价值在"人为干扰"场景的**安全与恢复**，不在主线成功率。

### 对 IP-02 / IP-03 / IP-06 的实质修改

- **IP-02**：抓握隐变量 `g_t` 成为 A1 中 `ρ` 的一个特例（夹爪相位下的 `ρ`），不再单独维护一套阈值。
- **IP-03**：chunk 长度不再只看相位，而看 `T_a = f(υ_t, σ_perc)`——紧迫或观测不确定时用短 chunk。
- **IP-06**：六因子把 `transport` 拆成 `carry`（搬物体）与 `reposition`（移动身体），否则 M1 的收益在分解里不可见。

## 3. 符号与定义（U13–U22）

| 符号 | 含义 |
|---|---|
| `q` | 身体构型（base + torso + arm + gripper） |
| `w(q)` | 末端可操作度 `sqrt(det(J J^T))` |
| `R*` | 插入就绪区：`w(q) ≥ w_min` 且目标在可达域内 |
| `σ_perc` | 自运动导致的感知不确定度 |
| `s^A` | 评价态 `(ρ, υ)` |
| `ρ` | 进展置信：当前尝试将成功的概率 |
| `υ` | 紧迫度：不干预时进展的预期衰减率 |
| `M` | 元动作集 `{PERSIST, SLOW, RETRY_GRASP, SWITCH_PRIMITIVE, REPOSITION, SAFE_STOP}` |
| `π_meta` | 元控制策略：`(s^A, risk_reach, h) → m` |
| `ℓ` | 伤害事件：`1[干预 ∧ 基线本会成功]` |
| `τ` | 干预阈值（由 RCPS 标定、ACI 在线更新） |

**定义 U13（可操作度）** `w(q) = sqrt(det(J(q)J(q)^T))`，`J` 为末端对关节的雅可比；按任务尺度归一化。
**定义 U14（插入就绪区）** `R* = { q : w(q) ≥ w_min, dist(target, ∂reach(q)) ≥ ε }`。
**定义 U15（自运动不确定度）** `σ_perc(t) = σ0·(1 + κ_v‖v_base,t‖ + κ_ω‖ω_base,t‖ + κ_b·blur_t)`。
**定义 U16（评价态）** `s^A_t = (ρ_t, υ_t) ∈ [0,1]²`。
**定义 U17（进展置信）** `ρ_t = P(episode 成功 | o_{≤t}, a_{<t})`，由分类器 + 校准给出。
**定义 U18（紧迫度）** `υ_t = E[ (ρ_t − ρ_{t+k})_+ / k | 不干预 ]`，即进展的预期衰减率；衰减越快越紧迫。
**定义 U19（元动作集）** `M = {PERSIST, SLOW, RETRY_GRASP, SWITCH_PRIMITIVE, REPOSITION, SAFE_STOP}`。
**定义 U20（元控制）** `π_meta(s^A, risk_reach, h) = argmax_{m∈M} Q_meta(s^A, m) ⋅ 1[risk(m) ≤ α]`（风险约束优先于收益）。
**定义 U21（伤害事件）** `ℓ_t = 1[ m_t ≠ PERSIST ∧ S^cf_t = 1 ]`，`S^cf` 为"基线本会成功"的反事实标签。
**定义 U22（风险控制阈值）** `τ` 由 RCPS 选择，使 `P(ℓ=1 | τ) ≤ α` 以概率 `1−δ`；线上 `τ_{n+1}=τ_n+γ(α−ℓ_n)`（ACI）。

## 4. 关键算法骨架

```python
# ===== 第2轮统一策略服务（在 v1 骨架上增量；仍是单 checkpoint / 单 API）=====
class UniBotEMPA(UniBotSAGEPolicy):
    def __init__(self, *a, alpha=0.05, delta=0.1, gamma=0.01, **kw):
        super().__init__(*a, **kw)
        self.mob   = ReachModel(w_min=..., eps=...)   # M1: w(q), R*
        self.ego   = EgoMotionUncertainty()           # M2
        self.app   = AppraisalCore()                  # A1: (rho, ups)
        self.guard = ConformalGuard(alpha, delta, gamma)  # A2
        self.human = InterferenceIntent()             # H1 (可选)

    def get_action(self, obs, port):
        s = self.sessions[port]
        t0 = time.perf_counter()

        sig   = self.ego.sigma(obs)                        # U15
        rho, ups = self.app.estimate(obs, sigma=sig)       # U16-U18（带不确定度）
        w_ins = self.mob.predict_w(obs)                    # U13
        rrisk = self.mob.margin_risk(obs, w_ins)           # U14 余量风险

        # ---- A2：分布无关干预判定（保守：不满足风险界就 PERSIST）----
        dec = self.guard.decide(rho, ups, rrisk)           # U19-U22
        m   = self.meta_policy(dec)                        # U20

        if m == "REPOSITION" and self.phase(obs) == "transport":
            a = self.mob.reposition_action(obs)            # M1：预置 body 到 R*
            return self.pack(a, self.chunk_len(ups, sig), obs)
        if m in ("RETRY_GRASP", "SWITCH_PRIMITIVE"):
            a = self.recover(m, obs)                       # 复用 v1 原语库
            return self.pack(a, self.chunk_len(ups, sig), obs)

        # ---- 默认：原策略；chunk 由紧迫度与自运动不确定度驱动（改 IP-03）----
        T_a = self.chunk_len(ups, sig)                     # 高 ups / 高 sig ⇒ 短 chunk
        a = self.model.act(obs, self.task_router(obs["observation.language"]),
                           self.phase(obs), self.ca.encode(obs), T_a)
        a = self.st.stitch(a, s.last_action)
        a = self.audit.clamp_and_log(a, obs, t0, self.tau_budget_ms)
        s.last_action = a[-1]
        return self.pack(a, T_a, obs)

    def meta_policy(self, dec):
        # 四象限：进展/紧迫；风险约束优先（P7）
        if dec.rho_hi and dec.ups_lo: return "PERSIST"
        if dec.rho_hi and dec.ups_hi: return "SLOW"
        if dec.rho_lo and dec.ups_lo: return "PERSIST"   # 早期不确定，继续观察
        if dec.rho_lo and dec.ups_hi: return dec.fallback  # RETRY / SWITCH / SAFE_STOP
        return "PERSIST"
```

```python
# ===== A1：评价态（弱监督 + 校准）=====
class AppraisalCore:
    def estimate(self, obs, sigma):
        z   = self.fuse(wrist_frames(obs), head_frames(obs), prop(obs))  # 多模态
        rho = self.calib_rho(self.head_rho(z))            # 终局/过程弱标签训练
        decay = self.head_decay(z)                        # 未来 k 步 rho 下降回归
        ups = clamp(relu(decay) * (1.0 - rho), 0, 1)      # U18
        # 自运动把置信度向 0.5 收缩（不确定时不冒进）
        rho = shrink_toward(rho, 0.5, k=sigma)
        return rho, ups

# ===== A2：RCPS 标定 + ACI 在线阈值 =====
class ConformalGuard:
    def calibrate(self, cal_loader):
        # 在标定集上选最大干预集 G，使 P(干预 ∧ 基线本会成功) <= alpha
        self.tau = learn_then_test(self.score, cal_loader, alpha=self.alpha,
                                   delta=self.delta)
    def decide(self, rho, ups, rrisk):
        score = self.score(rho, ups, rrisk)               # 越大概率"该干预"
        return Decision(intervene=(score >= self.tau))
    def update_aci(self, harm: bool):                     # 只动阈值，不动权重（P10）
        self.tau += self.gamma * (self.alpha - float(harm))

# ===== M1：可操作度与预置 =====
class ReachModel:
    def predict_w(self, obs):
        q = body_config(obs)                              # base/torso/arm
        target = self.target_pose(obs)                    # 语言+视觉估计
        return manipulability(self.jacobian(q), target)
    def margin_risk(self, obs, w):
        return clamp((self.w_min - w) / self.w_min, 0, 1) # 低于阈值即高险
    def reposition_action(self, obs):
        q_star = argmax_q self.predict_w_given(q, self.target_pose(obs))
        # 约束：目标∈R*、平滑、无碰撞、不扰动场景（P8）
        return interpolate(body_config(obs), q_star, horizon=self.rep_h)
```

## 5. 推导（引理 L8–L13）

**引理 L8（评价态可校准但 OOD 会退化）** 若 `ρ` 由有限容量分类器估计并按温度/isotonic 校准，则同分布下 `ECE → 0`（样本量增大），但校准映射依赖输入分布；当边缘分布漂移（常见于 5 类泛化）而条件关系不变时，`ρ` 的**排序**可能保持而**校准**失效，即 ECE 上升而 AUROC 近似不变。⇒ 状态估计必须交给带域内标定的 A2，不能直接用离线 `τ`。∎

**引理 L9（有保证的干预净收益）** 设干预在"确失败"上的检出率为 `r`、在"本会成功"上的伤害率为 `α`，救回增益 `G`、误伤损失 `L`、干预开销 `c`。净增益 `Δ = r·G − α·L − c`。A2 保证 `α ≤ α0`（以 `1−δ` 概率），故只需 `r·G > α0·L + c` 即可确保 `Δ>0`。这把 v1 的 L3 从"假设 α"升级为"**受控 α**"。∎

**引理 L10（ACI 在偏移下的长期风险界）** 令 `τ_{n+1}=τ_n+γ(α−ℓ_n)`，`ℓ_n∈{0,1}`。则对任意序列，长期平均伤害率满足
`(1/N)Σℓ_n ≤ α + (τ_1 − τ_{N+1})/(γN) + O(γ)`。
当 `τ` 取有界区间时，第二项 `O(1/(γN))`，故平均伤害率以 `O(γ)` 收敛到 `α` 附近——**无需可交换性**。代价是 `γ` 大则波动大、小则收敛慢；需按 episode 数设 `γ`。∎

**引理 L11（可操作度与失败的关联可证伪）** 若在插入时刻 `w(q)` 与任务成功独立，则 `Spearman(w, success)=0`；以 `n` 个插入样本估之，标准误 `≈1/sqrt(n−1)`。取 `n≥200`，若 `|ρ_s| < 0.2` 则以约 95% 置信认为效应量小于"小效应"，M1/M2 应剪枝。∎

**引理 L12（预置身体的收益-代价条件）** 设预置把插入点可操作度从 `w0` 提到 `w*`，成功率对 `w` 的边际为 `∂S/∂w`，移动代价 `c_m`（时间+碰撞风险）。则预置净收益 `≈ (w*−w0)·∂S/∂w − c_m`，为正需 `∂S/∂w > c_m/(w*−w0)`；若 E620 测不出 `∂S/∂w>0`，则预置无效。∎

**引理 L13（自运动不确定度的单向安全阀）** 若 `σ_perc` 只用于**上调**干预门槛与**缩短** chunk（不改变动作均值），则它只会降低"在噪声帧上做激进判定"的概率，不会系统性改变基线动作分布；因此其最坏影响是"响应变慢"，而非"行为漂移"。∎
