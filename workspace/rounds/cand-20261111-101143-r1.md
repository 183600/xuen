# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「实时控制」×「避障控制」）

> 第 54 轮把技能从"能力黑箱"拆成动作占用剖面 `α_S`，并用组合图 `G_S` 与云边联合证书 `J` 把"能否组合"变成"动作空间是否相容"。但该体系有两个隐含的物理盲点：**(i)** 它只问动作**是否落在**技能的动作集里，没问这个动作**能否在控制周期内算完并执行**；**(ii)** 它只保证单步动作可执行，没保证整条轨迹**始终**满足避障安全裕度。本轮引入实时剖面与屏障证书，核心矛盾：**H22** 动作相容 ≠ 时序可行——空间上兼容的技能组合可能在边端因 WCET + 动作转换 + 避障计算超期而错过截止期；**H23** 离线避障证书 ≠ 在线安全——云边时延使边端执行的动作已"过期"，静态 CBF 证书在延迟下失效。

## 0. 直觉与动机

**灵感 1（实时控制 → 给动作空间再加一个时间剖面 τ_S）**
直觉：第 54 轮的 `α_S` 是"空间占用"，实时控制要求同时给出"时间占用"：每个技能 `S` 有 `τ_S = (C_S, T_S, J_S, D_S)`（最坏执行时间、周期、释放抖动、相对截止期）。一个动作不只问 `α_S(a) ≥ θ_cov`，还要问其最坏响应时间 `R_S(a) ≤ D_S`。**时间成为与动作并列的第一性资源**：组合图 `G_S` 的每条边不再只有动作兼容度，还必须携带一个可调度性判定。

**灵感 2（避障控制 → 从"动作可执行"到"轨迹前向不变"）**
直觉：避障不是选一个此刻不撞的动作，而是保证未来整段轨迹都在安全集内。用离散控制屏障函数（CBF）定义**安全动作集** `A_safe(x) = {a : h(f(x,a)) ≥ (1-γ)h(x)}`，把 `α_S` 细化为 `α_S^safe(a;x) = α_S(a)·1[a∈A_safe(x)]`。**安全是轨迹性质，不是单点性质**；一个动作"此刻可执行"完全可能把状态推入不可恢复的危险区。

**灵感 3（时延 → 安全裕度是延迟的函数，而非常数）**
直觉：真实避障裕度不是常数，而是"刹车距离"：速度 `v`、最大减速度 `a_max` 下，回路延迟 `τ` 需要的最小裕度 `h_min(τ) = vτ + v²/(2a_max)`。云端越慢，边端必须预留越大安全距离。这把第 54 轮的 `δ_a`（动作对齐误差）从纯几何量升级为**时延-安全预算**：动作对齐再多，只要 `h_cert < h_min(τ)` 仍不可部署。

**灵感 4（实时×避障的张力 → 时延-安全前沿）**
直觉：更保守的避障需要更长预测时域 → 更大计算量 → 更大延迟 → 又需要更大安全裕度，形成正反馈。存在一条**时延-安全前沿** `F = {(τ,h) : h ≥ h_min(τ)}`，只有 `(τ, h_cert)` 落在前沿内才可部署。组合优化目标从 `cost_align` 变为 `cost_rt = cost_align + w_t·R + w_s·h_min(τ)/h_cert`，即**同时惩罚超期与安全余量不足**。

**灵感 5（冻结悖论 → 安全必须与活性联合证明）**
直觉：鲁棒 CBF + 最坏 WCET 的交集会收缩 `A_safe`，在狭窄或动态场景中可能为空。此时"最安全"的动作是停车，但在人流/车流中停车本身就成为障碍、并可能被后车追尾——**僵死不是安全**。因此安全证书必须与**活性证书**成对：要么 `A_safe(x) ≠ ∅`，要么存在预先认证的救援机动 `ρ_res`（如沿已证书化轨迹的最小制动/让行），否则组合应被**显式拒绝**，而不是默默冻结。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（实时剖面）**
技能 `S` 的实时剖面 `τ_S = (C_S, T_S, J_S, D_S)`，其中 `C_S` 为单控制步最坏执行时间（WCET），`T_S` 为周期，`J_S` 为释放抖动，`D_S` 为相对截止期。动作 `a` 的**实时可执行**判定为
```
rt_exec(S,a) ⇔ R_S(a) ≤ D_S  且  slack_S(a) = D_S - R_S(a) ≥ 0
```
其中 `R_S(a)` 由定义 122 的响应时间分析给出。实时剖面与第 54 轮动作剖面构成**时空双剖面** `(α_S, τ_S)`。

**定义 122（调度可行的技能组合）**
组合 `S_1⊗...⊗S_k` 中，边 `(i,j)` 的最坏响应时间满足固定优先级递推
```
R_{ij} = C_i + C_trans(i,j) + B_i + Σ_{h ∈ hp(i)} ⌈R_{ij}/T_h⌉·C_h
```
其中 `C_trans(i,j)` 为动作转换开销，`B_i` 为高优先级阻塞时间。**调度可行**当且仅当
```
compat(S_i,S_j) ≥ θ_a
  ∧ c_trans(A_i,A_j) ≤ τ_e
  ∧ R_{ij} ≤ min(D_i, T_j)              （硬实时）
  ∧ P(R_{ij} > min(D_i,T_j)) ≤ ε_d      （软实时兜底）
```
即在第 54 轮几何相容之上叠加**时序可行**，两者缺一不可。

**定义 123（CBF 安全动作集）**
状态 `x ∈ X`，离散动力学 `x_{k+1} = f(x_k,a_k) + w_k`，障碍集 `O` 的符号距离 `h_O(x) ≥ 0` 表示安全。对候选屏障函数 `h`（可取 `h(x)=min_{o∈O} dist(x,o) - r_safe`），安全动作集
```
A_safe(x) = { a ∈ A_S : h(f(x,a)) ≥ (1-γ)h(x),  γ ∈ (0,1] }
```
`A_safe` 对闭环诱导的集合 `{x : h(x) ≥ 0}` 前向不变。动作剖面细化为 `α_S^safe(a;x) = α_S(a)·1[a∈A_safe(x)]`。

**定义 124（时延鲁棒屏障证书）**
云边回路延迟 `d ≤ d_max`，状态估计误差 `‖ε_x‖ ≤ ε_x`，扰动 `‖w‖ ≤ ε_w`，`f` 的 Lipschitz 常数 `L_f`。**时延鲁棒屏障证书**
```
B_cert = (h, γ, d_max, ε_x, ε_w, β),   β(d) = L_f^d·ε_x + ((L_f^d - 1)/(L_f - 1))·ε_w
```
其认证条件为对任意 `d ≤ d_max`
```
h(f^d(x,a)) ≥ (1-γ)h(x) + β(d)
```
直观：`β(d)` 是把"延迟期间状态会漂多远"折算进屏障条件的**安全税**。`d` 越大，条件越严，可行动作越少——这正是灵感 4 中前沿的来源。

**定义 125（实时安全契约）**
`C_rts = (S, B_cert, D, ρ_res, ε_d)`：
- `S` 为技能/组合及其调度表；
- `B_cert` 为定义 124 的屏障证书；
- `D` 为控制截止期；
- `ρ_res` 为**预认证救援机动**，要求其 `A_safe^{ρ_res}(x) ≠ ∅` 且响应时间 `R_{ρ_res} ≤ D_res`；
- `ε_d` 为允许的截止期错失概率。
部署条件：`schedulable(S) ∧ B_cert valid ∧ (A_safe(x)≠∅ ∨ ρ_res available)`。第三项即**安全-活性联合条件**。

**定义 126（时延-安全前沿与实时成本）**
速度 `v`、最大减速度 `a_max` 下，延迟 `τ` 所需最小安全裕度 `h_min(τ) = vτ + v²/(2a_max)`。**时延-安全前沿**
```
F = { (τ,h) : h ≥ h_min(τ) }
```
技能/组合在延迟 `τ` 下**时延安全**当且仅当 `(τ, h_cert) ∈ F`。实时组合成本
```
cost_rt = cost_align + w_t·R/D + w_s·h_min(τ)/h_cert + w_f·1[ρ_res used]
```
搜索目标为在 `F` 约束下最小化路径总 `cost_rt`。

## 2. 关键算法 伪代码

### IP-121 RTP（Real-Time Profiling）

```python
def realtime_profile(skill, runs, delta_c=1e-3):
    C = pwcet_upper(runs, delta_c)        # 测量式概率 WCET 上界
    T, D = skill.period, skill.deadline
    J = max_jitter(runs)
    return TimingProfile(C=C, T=T, J=J, D=D, slack=D-C)

def rt_exec(profile, a, rta_fn):
    R = rta_fn(profile, a)
    return R <= profile.D, profile.D - R
```

### IP-122 SSA（Schedulability-Aware Skill composition）

```python
def response_time(task, hp_tasks):
    R = task.C + task.B
    while True:
        R_new = task.C + task.B + sum(ceil(R/t.T) * t.C for t in hp_tasks)
        if R_new == R:            return R
        if R_new > task.D:        return R_new
        R = R_new

def schedulable_edges(path, skills, eps_d):
    ok = []
    for u, v in zip(path, path[1:]):
        task = edge_task(skills[u], skills[v])      # C_u + C_trans + B
        R = response_time(task, hp_edges(skills, task))
        if R > min(skills[u].D, skills[v].T):        return False, ('deadline', R)
        if p_miss(task, R) > eps_d:                  return False, ('p_miss', p_miss(task, R))
        ok.append((u, v, R))
    return True, ok
```

### IP-123 CBF（Safe Action Set）

```python
def signed_distance(x, obstacle):
    return obstacle.sdf(x) - obstacle.safe_radius

def h(x, obstacles):
    return min(signed_distance(x, o) for o in obstacles)

def safe_action_set(skill, x, obstacles, gamma=0.2):
    A_safe = set()
    h_now = h(x, obstacles)
    for a in skill.action_space(x):
        x_next = skill.dynamics(x, a)
        if h(x_next, obstacles) >= (1 - gamma) * h_now:
            A_safe.add(a)
    return A_safe

def refine_profile(alpha, A_safe):
    return {a: v if a in A_safe else 0.0 for a, v in alpha.items()}
```

### IP-124 DRC（Delay-Robust Barrier Certificate）

```python
def delay_robust_barrier(h, f, gamma, d_max, eps_x, eps_w, L_f):
    def beta(d):
        geom = (L_f ** d - 1) / (L_f - 1) if L_f != 1 else d
        return (L_f ** d) * eps_x + geom * eps_w

    def certified(x, a):
        for d in range(1, d_max + 1):
            x_d = rollout(f, x, a, d)
            if h(x_d) < (1 - gamma) * h(x) + beta(d):
                return False
        return True
    return certified
```

### IP-125 RTSC（Real-Time Safety Contract）

```python
def realtime_safety_certificate(path, skills, x, obstacles, D, eps_d):
    ok, sched = schedulable_edges(path, skills, eps_d)
    if not ok:
        return ('reject', 'unschedulable', sched)

    cert = delay_robust_barrier(h, f, gamma, d_max, eps_x, eps_w, L_f)
    last_skill = skills[path[-1]]
    A_safe = {a for a in last_skill.action_space(x) if cert(x, a)}

    if not A_safe:                                  # 活性分支
        rescue = find_precertified_rescue(x, obstacles)
        if rescue is None or rescue.R > rescue.D:
            return ('reject', 'deadlock_no_rescue')
        return ('degrade', 'rescue', rescue)

    A_plan = A_safe & set(last_skill.planned_actions)
    if not A_plan:
        return ('reject', 'plan_not_in_safe_set')
    return ('ok', RTS_Cert(sched, cert, D, A_plan))
```

### IP-126 LSF（Latency-Safety Frontier）

```python
def latency_safety_frontier(v, a_max, taus, h_cert):
    return [(tau,
             v * tau + v * v / (2 * a_max),
             h_cert,
             h_cert >= v * tau + v * v / (2 * a_max))
            for tau in taus]

def cost_rt(path, R, D, tau, h_cert, h_min, used_rescue):
    base = sum(cost_align(u, v) for u, v in zip(path, path[1:]))
    return (base + w_t * R / D + w_s * h_min / max(h_cert, 1e-9)
            + w_f * int(used_rescue))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| RTP | O(N_runs) | O(1) | pWCET 上界在置信度 `1-δ_C` 下成立 |
| SSA | O(|E|·k·n)（RTA 不动点 k 轮） | O(|S|²) | 响应时间递推单调、优先级假设成立 |
| CBF | O(|A|·|O|) | O(|A|) | 动力学模型准确、`h` 前向不变 |
| DRC | O(d_max·|A|·|O|) | O(|A|) | Lipschitz 界与扰动界有效 |
| RTSC | O(SSA + DRC) | O(|A|+|E|) | 安全-活性联合、救援机动预认证 |
| LSF | O(|τ|) | O(|τ|) | 制动距离模型与实际执行器一致 |

**正确性定理（Real-Time Safety Composition Soundness, RTSC-Sound）**
承接第 54 轮 (A26)–(A28)，并新增：**(A29)** WCET 上界在置信度 `1-δ_C` 下成立（测量式 pWCET）；**(A30)** `f` 的 Lipschitz 常数 `L_f` 有限、`‖w‖≤ε_w`、`‖ε_x‖≤ε_x`，且定义 124 的鲁棒 CBF 在 `d≤d_max` 下成立；**(A31)** 救援机动 `ρ_res` 已预认证且 `R_{ρ_res} ≤ D_res`。
则对部署的边端计划 `P_e`：
```
P(无碰撞 ∧ 满足截止期) ≥ (1 - δ_C)(1 - ε_d) - δ_m
```
其中 `δ_m` 为模型失配概率（仅当 A30 被违反时非零）。安全部分（无碰撞）在 A30 成立时是**条件硬保证**（前向不变），不是概率保证；实时部分给出 `P(R>D) ≤ ε_d`；活性部分由 `A_safe≠∅ ∨ ρ_res` 保证，故不存在"既不可动又无救援"的死区。

## 4. 实验设计 E162–E166

|---|---|---|

| E166 救援机动有效性 | 强制 deadline miss 下的成功率 | 无碰撞成功率 ≥ 95%，僵死率 ≤ 1% |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| CBF 动力学模型失配导致虚假安全 | 高 | 鲁棒 CBF + 在线辨识 + 模型失配预算 `δ_m` 显式计入证书 |
| WCET 欠估导致截止期系统性错过 | 高 | 测量式概率 WCET + 硬件在环压力测试 + 保守 padding |
| 鲁棒裕度过大导致 `A_safe=∅` 僵死 | 高 | 安全-活性联合证书 + 预认证救援机动 + 僵死单独计为失败 |
| 云边延迟尖峰击穿 `d_max` | 高 | 延迟准入控制 + 边端本地降级 + `d_max` 在线标定 |
| 安全与实时目标互斥 | 中 | 显式时延-安全前沿 + 多目标 Pareto 搜索 |
| 救援机动本身不满足实时性 | 中 | 救援机动独立 RTA + 更短执行路径 + 硬优先级 |

## 6. 本轮最大风险

**一句话**：把实时剖面、时延鲁棒屏障证书与安全-活性联合契约叠加后，最危险的失效不是"撞上"，而是**参数保守化把 `A_safe` 压成空集、机器人"安全地"僵死在动态人流/车流中**——这在他人视角下等同于一个新的静态障碍，反而制造碰撞与拥堵；因此必须把"僵死"与"碰撞"并列为一级失败模式，用预认证救援机动 + 活性证书共同兜底，绝不允许用"停车即安全"掩盖实时与避障耦合下的不可行性。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（RTP×SSA×CBF×DRC×RTSC×LSF）

> 承接第 54 轮产物 v31。v31 用 ACS/SCOM/CEC/AEC/JTC 把技能组合从"能力匹配"推进到"动作空间相容 + 云边联合证书"。本轮在此基础上补齐两个物理维度：
> - **时间维度**：动作不仅要在动作集里，还要在截止期内可算完、可执行；
> - **轨迹维度**：单步安全不等于整段安全，避障必须由屏障函数保证前向不变；
> - **两者耦合**：延迟越大，避障所需安全裕度越大，可行动作集越小，可能触发僵死。
>
> 新增算子：**RTP**（实时剖面）、**SSA**（可调度性感知组合）、**CBF**（安全动作集）、**DRC**（时延鲁棒屏障证书）、**RTSC**（实时安全契约）、**LSF**（时延-安全前沿）。
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-116/117/118 以纳入实时与安全维度。

| `h_min(τ)` / `F` | 延迟 τ 的最小安全裕度 / 时延-安全前沿 |
| `cost_rt` | 实时组合成本（对齐+超期+安全余量+救援） |

## 2. 关键算法 伪代码

### IP-121 RTP

```python
def realtime_profile(skill, runs, delta_c=1e-3):
    C = pwcet_upper(runs, delta_c)
    T, D = skill.period, skill.deadline
    J = max_jitter(runs)
    return TimingProfile(C=C, T=T, J=J, D=D, slack=D-C)

def rt_exec(profile, a, rta_fn):
    R = rta_fn(profile, a)
    return R <= profile.D, profile.D - R
```

### IP-122 SSA

```python
def response_time(task, hp_tasks):
    R = task.C + task.B
    while True:
        R_new = task.C + task.B + sum(ceil(R/t.T) * t.C for t in hp_tasks)
        if R_new == R:        return R
        if R_new > task.D:    return R_new
        R = R_new

def schedulable_edges(path, skills, eps_d):
    out = []
    for u, v in zip(path, path[1:]):
        task = edge_task(skills[u], skills[v])
        R = response_time(task, hp_edges(skills, task))
        if R > min(skills[u].D, skills[v].T):
            return False, ('deadline', R)
        if p_miss(task, R) > eps_d:
            return False, ('p_miss', p_miss(task, R))
        out.append((u, v, R))
    return True, out
```

### IP-123 CBF

```python
def h(x, obstacles):
    return min(o.sdf(x) - o.safe_radius for o in obstacles)

def safe_action_set(skill, x, obstacles, gamma=0.2):
    A_safe, h_now = set(), h(x, obstacles)
    for a in skill.action_space(x):
        if h(skill.dynamics(x, a), obstacles) >= (1 - gamma) * h_now:
            A_safe.add(a)
    return A_safe

def refine_profile(alpha, A_safe):
    return {a: (v if a in A_safe else 0.0) for a, v in alpha.items()}
```

### IP-124 DRC

```python
def delay_robust_barrier(h, f, gamma, d_max, eps_x, eps_w, L_f):
    def beta(d):
        geom = (L_f ** d - 1) / (L_f - 1) if L_f != 1 else d
        return (L_f ** d) * eps_x + geom * eps_w

    def certified(x, a):
        for d in range(1, d_max + 1):
            x_d = rollout(f, x, a, d)
            if h(x_d) < (1 - gamma) * h(x) + beta(d):
                return False
        return True
    return certified
```

### IP-125 RTSC

```python
def realtime_safety_certificate(path, skills, x, obstacles, D, eps_d):
    ok, sched = schedulable_edges(path, skills, eps_d)
    if not ok:
        return ('reject', 'unschedulable', sched)

    cert = delay_robust_barrier(h, f, gamma, d_max, eps_x, eps_w, L_f)
    last = skills[path[-1]]
    A_safe = {a for a in last.action_space(x) if cert(x, a)}

    if not A_safe:
        rescue = find_precertified_rescue(x, obstacles)
        if rescue is None or rescue.R > rescue.D:
            return ('reject', 'deadlock_no_rescue')
        return ('degrade', 'rescue', rescue)

    if not (A_safe & set(last.planned_actions)):
        return ('reject', 'plan_not_in_safe_set')
    return ('ok', RTS_Cert(sched, cert, D, A_safe))
```

### IP-126 LSF

```python
def latency_safety_frontier(v, a_max, taus, h_cert):
    out = []
    for tau in taus:
        h_min = v * tau + v * v / (2 * a_max)
        out.append((tau, h_min, h_cert, h_cert >= h_min))
    return out

def cost_rt(path, R, D, tau, h_cert, h_min, used_rescue):
    base = sum(cost_align(u, v) for u, v in zip(path, path[1:]))
    return (base + w_t * R / D + w_s * h_min / max(h_cert, 1e-9)
            + w_f * int(used_rescue))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| RTP | O(N_runs) | O(1) | pWCET 上界置信度 `1-δ_C` |
| SSA | O(|E|·k·n) | O(|S|²+|E|) | RTA 单调收敛、优先级/阻塞假设成立 |
| CBF | O(|A|·|O|) | O(|A|) | 模型准确、`h` 前向不变 |
| DRC | O(d_max·|A|·|O|) | O(|A|) | Lipschitz 与扰动界有效 |
| RTSC | O(SSA + DRC) | O(|A|+|E|) | 安全-活性联合、救援预认证 |
| LSF | O(|τ|) | O(|τ|) | 制动距离模型与执行器一致 |

**正确性定理（RTSC-Sound）**
承接第 54 轮 (A26)–(A28)，新增：**(A29)** pWCET 上界在置信度 `1-δ_C` 下成立；**(A30)** `L_f` 有限、`‖w‖≤ε_w`、`‖ε_x‖≤ε_x`，定义 124 鲁棒 CBF 在 `d≤d_max` 下成立；**(A31)** 救援机动 `ρ_res` 已预认证且 `R_{ρ_res}≤D_res`。
则对部署计划 `P_e`：
```
P(无碰撞 ∧ 满足截止期) ≥ (1 - δ_C)(1 - ε_d) - δ_m
```
其中 `δ_m` 为模型失配概率（A30 被违反时非零）。无碰撞部分在 A30 成立时为**条件硬保证**（前向不变），实时部分保证 `P(R>D)≤ε_d`，活性部分由 `A_safe≠∅ ∨ ρ_res` 排除"既不可动又无救援"的死区。**关键：安全是条件保证而非无条件保证，必须把 `δ_m` 显式暴露在证书里。**

## 5. 本轮最大风险

**一句话**：RTP/SSA/CBF/DRC/RTSC/LSF 六件套让技能组合第一次同时受"截止期 + 轨迹安全 + 云边延迟"三重约束，但最危险的失效不是撞上，而是**参数保守化把 `A_safe` 压成空集、机器人"安全地"僵死在动态人流/车流中**——在他人视角下这等同于新增一个静态障碍，反而制造碰撞与拥堵；因此必须把"僵死"与"碰撞"并列为一级失败模式，用预认证救援机动 + 活性证书共同兜底，绝不允许用"停车即安全"掩盖实时与避障耦合下的不可行性。
