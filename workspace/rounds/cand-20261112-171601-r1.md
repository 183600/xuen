# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮·第 1 轮；本轮灵感：「意图识别」×「真实世界泛化」）

> 第 60 轮把「执行层→证据层」升级为「场景→意图→约束→阻抗→执行」的认知驱动闭环（SSM×CIEC×EPIR×SERC）。但它在**识别层**留下了三个根本性缺口：
> 1. **意图是「神谕输入」而非「识别结果」**：CIEC 的 ϕ_intent→constraint 依赖一张手写查表，隐含假设「意图已被完美识别、且标签有限」。真实意图来自语音、手势、视线、触觉引导与任务阶段的多模态噪声证据，且同一句「轻点」在不同场景下约束不同。当 CIEC 以 φ_lock **锁定**约束时，一次误识别会被放大为「锁定的错误约束」，比不锁定更危险。
> 2. **场景世界是「闭集且已校准」的**：Z_scene 是手工枚举的 10 个场景，π_scene 是手工先验；「识别准确率 ≥ 85%」只是平均意义，不是部署保证。真实世界是**开放集、长尾、持续漂移**的（光照、地面材质、传感器老化、不同用户），新场景会在不报警的情况下让识别器静默失效。
> 3. **点识别 ≠ 决策风险**：SSM/CIEC 优化的是分类精度，而不是**下游动作的风险**。系统无法回答「我是否在分布外」「我的置信度是否可信」「在不确定时该锁定、预收敛还是弃权」，缺乏「知道自己不知道」的可校准机制。

## 0. 直觉与动机

**灵感 1（意图识别 → 意图是约束的后验，而不是标签）**
直觉：把「轻触」当成一个标签、再用查表映射到 (K_p, F_max) 是把一个高熵后验**过早塌缩成点**。更合理的对象是意图参数 θ=(v_scale, F_target, K_p_scale, K_d_scale) 上的后验 b_t(θ)=P(θ|o_{1:t})；离散词只是 θ 空间中的区域。关键洞见：**只有当后验诱导的约束集合仍安全且足够窄时才执行锁定**；歧义时应先探测/澄清，而不是 argmax 后硬锁。

**灵感 2（真实世界泛化 → 集合值识别 + 分布无关覆盖）**
直觉：真实世界泛化不能靠「在一批训练场景上准确率高」来声称。共形预测（Conformal Prediction）只用「校准集与测试样本可交换」这一弱假设，就给出有限样本、分布无关的覆盖保证 P((z*,θ*) ∈ C_α(x)) ≥ 1−α。于是「开放集场景」不再表现为静默误判，而表现为**预测集变宽**——宽到不可执行时就自动弃权。这把「泛化」从模型属性变成**可审计的集合值输出**。

**灵感 3（两灵感合流 → 风险敏感而非置信度敏感）**
直觉：覆盖率 90% 不等于安全，因为「把轻触误判为加紧」和「把加紧误判为轻触」的代价不对称。**共形风险控制（CRC）**把决策改成「在最激进的候选动作中，选期望损失有 1−δ 上界 ≤ β 的那一个」，候选按激进度排序：abstain < conservative < neutral < preconverge < lock。于是「能不能预收敛 K_safe / 能不能锁定约束」成为**带风险上界的序贯决策**，而不是 if 阈值。

**灵感 4（漂移 → 共形鞅 + 自适应共形）**
直觉：可交换性在真实世界终将破裂，静态共形保证会**无声失效**。用**共形鞅**在线检验非一致性分数序列的可交换性，检测到漂移即报警；用**自适应共形推断（ACI）**在线调整 α_t 以维持长期覆盖率，并切换泛化状态机 IN_DIST → SHIFT → NOVEL；NOVEL 时弃权并主动采集标签，而不是继续信任失效模型。

**灵感 5（意图-场景混淆 → 反事实主动辨识）**
直觉：同一条力曲线可能是「软桌面 + 用力」也可能是「硬桌面 + 轻触」，场景与意图在观测上**互相混淆**。需要在安全力/速度包络内做**微小探针（safe dithering）**，选信息增益最大的探针打破混淆；若探针预算内仍不可辨识，则升级为对话澄清。这把第 59 轮 BUQ 的「主动辨识电机参数」推广到「主动辨识人类意图」。

**灵感 6（泛化契约 → 组合式安全证书）**
直觉：识别层给「覆盖保证」，执行层给「集合内安全」，二者必须通过一个**组合定理**拼接成端到端保证，并写入部署证书 J_gen。没有组合契约，识别与执行各说各话，「证据层确定、执行层崩溃」的抽象泄漏会再次出现。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（意图信念后验 IBP, Intent-as-Belief Posterior）** 意图信念 B = (Θ, b_t, C(·), ρ)。其中：
- **意图参数空间**：Θ ⊆ R⁴，θ = (v_scale, F_target, K_p_scale, K_d_scale)；离散词（「慢点」「轻触」「加紧」「稳定」「危险」）是 Θ 上的区域 π_word(θ)，而非点。
- **多模态观测**：o_t = (u_t^speech, c_t^utt, g_t^gesture, e_t^gaze, f_t^haptic, p_t^phase)。
- **贝叶斯更新**：b_t(θ) ∝ P(o_t | θ) · b_{t−1}(θ)，由粒子滤波/高斯混合实现，保留多峰而非 argmax。
- **约束投影**：C(θ) = (v_max, F_max, K_p, K_d) 为 θ 的单调（逐分量）映射。
- **退化关系**：第 60 轮的离散查表 ϕ 是「b_t 为单点 δ 分布」时的特例：ϕ(I) = C(argmax_θ π_word(θ))。

**定义 162（共形场景-意图预测集 C-SIP）** 给定校准集 D_cal = {(x_i, y_i)}_{i=1}^{n}（y_i = (z_i, θ_i)），非一致性分数 s(x, y)，显著性 α：
- **阈值**：q̂ = ⌈(n+1)(1−α)⌉/n 阶经验分位数（⌈·⌉ 取上整，超出 n 时取 +∞）。
- **预测集**：C_α(x) = {y : s(x, y) ≤ q̂}，满足 **P(y* ∈ C_α(x)) ≥ 1−α**（仅需可交换性）。
- **投影与可执行集**：Z_α = proj_Z C_α，Θ_α = proj_Θ C_α；C_exec(x) = ⋂_{(z,θ)∈C_α(x)} C(z,θ)。
- **可执行判据**：Actionable(x) ⇔ C_exec(x) ≠ ∅ ∧ diam(C_exec(x)) ≤ δ_action；否则强制进入 CRC 的 lower 动作（clarify/conservative）。
- **分层/加权共形**：对长尾场景按 z 分层各给 α_z；对已知域偏移用重要性权重 w(x) 做加权共形，使覆盖在目标域成立。

**定义 163（共形风险控制执行决策 CRC）** 候选动作集 A = {abstain < conservative < neutral < preconverge < lock} 按**激进度**全序排列；损失 L(a, (z,θ)) ∈ [0, B] 关于 a 单调不减（越激进，错时代价越大）。经验风险 R̂_n(a) = (1/n)Σ_i L(a, y_i)。选择：
```
Â = max { a ∈ A : (n/(n+1))·R̂_n(a) + B/(n+1) ≤ β }
```
则**以概率 ≥ 1−δ 于校准集抽样**有 E[L(Â, y*)] ≤ β（共形风险控制界）。若无任何 a 满足，则 Â = abstain。

**定义 164（共形漂移检测与自适应校准 CDAA）** 泛化状态机 G_t ∈ {IN_DIST, SHIFT, NOVEL}，校准器 D = (M_t, α_t, δ_drift, γ, W)：
- **共形鞅**：对在线非一致性分数 s_t，以「s_t 在 {校准分数 ∪ 历史分数} 中的秩」构造 e-value e_t ∈ [0, ∞)，M_t = ∏_{s≤t} e_s；当 M_t ≥ 1/δ_drift 时判定**可交换性破裂**，报警并置 G_t = SHIFT。
- **自适应共形（ACI）**：err_t = 1[y_t ∉ C_{α_t}(x_t)]；α_{t+1} = clip(α_t + γ(α_target − err_t), [α_min, α_max])，保证长期平均覆盖率收敛到 1−α_target − O(γ)。
- **开放集判定**：若在 SHIFT 下 |Z_α| = 0 或 |Θ_α| = 0，置 G_t = NOVEL，执行 λ_open：弃权 + 请求标签/人工澄清，并把新样本加入 replay 缓冲 W。

**定义 165（场景-意图联合反事实辨识 CII）** 观测生成模型 o ~ g(z, θ) + ε（场景与意图共享观测通道，存在混淆）：
- **可辨识裕度**：δ_id > 0；(z, θ) 可辨识 ⇔ ∀(z′,θ′) ≠ (z,θ): D(g(z,θ) ‖ g(z′,θ′)) > δ_id。
- **歧义集**：A_amb(x) = {(z′,θ′) : D(g(z*,θ*) ‖ g(z′,θ′)) ≤ δ_id}。
- **主动探针**：在安全包络 U_safe = {u : ‖u‖_F ≤ F_safe, ‖u‖_v ≤ v_safe} 内选
  `u* = argmax_{u∈U_safe} [ I(θ; o_new | u, b_t) − λ_probe·cost(u) ]`；
  若 max 信息增益 ≤ θ_id，则升级为**对话澄清**（复用 CIEC，但以「问」替代「锁」）。
- **单调安全**：任何探针都不得使 C_exec(u) 逃逸安全包络，即探针本身受定义 162 的可执行判据约束（「为了辨识而越界」被禁止）。

**定义 166（泛化感知执行闭环 GEL）** 算子 GEL(M, o_t, δ_f_req)：

### IP-161 IBP（意图信念后验）

```python
class IntentBelief:
    def __init__(self, particles=256, theta_dim=4):
        self.particles = sample_prior(particles, theta_dim)   # theta=(v,F,Kp,Kd)
        self.weights = np.ones(particles) / particles
        self.obs_log = deque(maxlen=32)

    def update(self, obs):
        self.obs_log.append(obs)
        lik = np.array([self._multimodal_likelihood(o, obs) for o in self.particles])
        self.weights = normalize(self.weights * lik)
        self._resample_if_degenerate()
        return self.weights

    def constraint_posterior(self):
        cons = [project_constraint(o) for o in self.particles]
        return ConstraintDistribution(cons, self.weights)   # 保留分布，不取 argmax

    def _multimodal_likelihood(self, theta, obs):
        return (self._speech_lik(theta, obs) * self._gesture_lik(theta, obs)
                * self._haptic_lik(theta, obs) * self._phase_lik(theta, obs))
```

### IP-162 C-SIP（共形场景-意图预测集）

```python
class ConformalSceneIntentSet:
    def __init__(self, calib, alpha=0.1, delta_action=0.2):
        self.alpha = alpha
        self.delta_action = delta_action
        self.calib_scores = sorted(self._score(x, y) for x, y in calib)
        self.qhat = self._quantile(self.calib_scores, 1 - alpha)

    def _quantile(self, scores, level):
        n = len(scores)
        k = math.ceil((n + 1) * level)
        return math.inf if k > n else scores[k - 1]

    def predict_set(self, x):
        return {y for y in self._candidates(x) if self._score(x, y) <= self.qhat}

    def executable_set(self, C_alpha):
        cons = [project_constraint(z, theta) for (z, theta) in C_alpha]
        C_exec = intersect_all(cons)
        ok = C_exec is not None and C_exec.diameter() <= self.delta_action
        return C_exec if ok else None
```

### IP-163 CRC（共形风险控制决策）

```python
ACTIONS = ['abstain', 'conservative', 'neutral', 'preconverge', 'lock']  # 激进度递增

def conformal_risk_control(calib, candidate_set, beta, B_bound, delta):
    n = len(calib)
    chosen = 'abstain'
    for a in ACTIONS:
        losses = [L(a, y) for y in calib if y in candidate_set]
        if not losses:
            continue
        r_hat = np.mean(losses)
        bound = (n / (n + 1)) * r_hat + B_bound / (n + 1)
        if bound <= beta:
            chosen = a          # 单调损失 ⇒ 可安全地取更激进者
    return chosen
```

### IP-164 CDAA（漂移检测 + 自适应共形）

```python
class DriftAdaptiveCalibrator:
    def __init__(self, alpha_target=0.1, gamma=0.01,
                 delta_drift=0.01, alpha_min=0.02, alpha_max=0.4):
        self.alpha_target, self.gamma = alpha_target, gamma
        self.delta_drift = delta_drift
        self.alpha_t = alpha_target
        self.alpha_min, self.alpha_max = alpha_min, alpha_max
        self.martingale = 1.0
        self.state = 'IN_DIST'

    def update(self, score_t, covered_t):
        self.martingale *= self._e_value(score_t)
        if self.martingale >= 1.0 / self.delta_drift:
            self.state = 'SHIFT'
            self.martingale = 1.0
        err = 0.0 if covered_t else 1.0
        self.alpha_t = np.clip(self.alpha_t + self.gamma * (self.alpha_target - err),
                               self.alpha_min, self.alpha_max)
        return self.state, self.alpha_t

    def mark_open_set(self):
        self.state = 'NOVEL'
        return 'abstain_and_request_label'
```

### IP-165 CII（反事实主动辨识）

```python
def counterfactual_disambiguate(belief, gen_model, U_safe, theta_id):
    best_u, best_gain = None, -np.inf
    for u in safe_probes(U_safe):
        gain = mutual_information(belief, gen_model, u)   # I(theta; o_new | u)
        if gain - probe_cost(u) > best_gain:
            best_u, best_gain = u, gain - probe_cost(u)
    if best_gain <= theta_id:
        return ASK_HUMAN            # 探针无法打破混淆 → 对话澄清
    assert safe_under(C_exec(best_u), ENVELOPE)   # 探针本身不得越界
    return best_u
```

### IP-166 GEL（泛化感知闭环）

```python
def generalization_grounded_loop(M, obs_t, delta_f_req, beta=0.05, alpha=0.1):
    M.belief.update(obs_t)
    C_alpha = M.csp.predict_set(M.feature(obs_t))
    if ambiguous(C_alpha):
        u = counterfactual_disambiguate(M.belief, M.gen_model, M.U_safe, M.theta_id)
        if u is not ASK_HUMAN:
            obs_t = M.execute_safe_probe(u)
            C_alpha = M.csp.predict_set(M.feature(obs_t))
    state, alpha_t = M.calibrator.update(M.last_score, covered_t=M.last_covered)
    action = conformal_risk_control(M.calib, C_alpha, beta, M.B_loss, M.delta)
    C_exec = M.csp.executable_set(C_alpha)
    if action == 'lock' and C_exec is not None:
        M.ertc.lock_constraints(C_exec)
    elif action == 'preconverge':

    M, fused, D_plus, EV_exec, cert = closed_loop_exec_probe(M, M.current_cp, delta_f_req, M.budget)
    M.epir.append(EV_exec.__dict__)
    if state in ('SHIFT', 'NOVEL'):
        M.calib.extend(M.replay.sample(M.B_replay))
        M.csp.refit(M.calib)
    return M, C_alpha, action, fused, D_plus, M.contract.audit()
```

### IP-167 PCE+++++（泛化预算耦合）

```python
class GeneralizationBudget:
    def __init__(self, calib_n=200, drift_rate=10, replay=64,
                 width_cap=0.2, clarify_cap=2):
        self.B_calib, self.B_drift, self.B_replay = calib_n, drift_rate, replay
        self.B_width, self.B_clarify = width_cap, clarify_cap

    def allowed_actions(self, mean_width, state):
        acts = ['abstain', 'conservative']
        if state == 'IN_DIST' and self.B_clarify > 0:
            acts += ['neutral', 'clarify']
        if mean_width <= self.B_width:
            acts += ['preconverge', 'lock']
        if self.B_calib < 50:          # 校准不足：禁止伪造覆盖
            acts = ['abstain', 'conservative']
        return acts
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| IBP | O(K·d)/更新 | O(K·d) | 后验经重采样收敛；约束投影逐分量单调 |
| C-SIP | O(n log n) 校准 / O(\|Y\|) 预测 | O(n) | 有限样本覆盖 P(y*∈C_α) ≥ 1−α |
| CRC | O(\|A\|·n) 选择 | O(n) | E[L(Â,y*)] ≤ β，w.p. ≥ 1−δ |
| CDAA | O(1)/样本 | O(W) | 漂移报警延迟有界；ACI 长期覆盖 |
| CII | O(\|U_safe\|·K²) | O(K) | 可辨识时误判率 ≤ α |
| GEL | O(闭环) | 复用 | 组合不安全概率 ≤ α + P(miss) |

**正确性定理（CAGI-Safe）**：假设 **A66** 校准集与测试样本可交换（漂移报警前）；**A67** C-SIP 满足边际覆盖 ≥ 1−α；**A68** ∀(z,θ)∈C_α，C(z,θ) 落在执行安全包络内（集合内安全）；**A69** CRC 在单调损失下给期望损失 ≤β（w.p. ≥1−δ）；**A70** 共形鞅的漏报率/误报率有界（≤ p_miss、≤ δ_drift）；**A71** 所有探针 u∈U_safe 使 C_exec 不逃逸包络；**A72** replay 重校准保持 (分层) 覆盖不退化。则：

1. **点安全**：P(执行了不安全的约束) ≤ α + P(miss)。
   *证*：不安全执行 ⊆ {y* ∉ C_α} ∪ {y* ∈ C_α 但 C_exec 评估错误}；前者 ≤α，后者由精确交集为 0，故 ≤α（含漂移漏报的 P(miss)）。
2. **风险有界激进度**：所选的 Â 满足 E[L(Â,y*)] ≤ β，w.p. ≥ 1−δ（Angelopoulos 型 CRC 界，损失单调故可取最大可行 a）。
3. **漂移鲁棒**：报警后 ACI 使长期平均覆盖 ≥ 1−α_target−O(γ)；NOVEL 时弃权，**安全由弃权保证**（不执行 ⟹ 不越界）。
4. **混淆可控**：若观测可辨识，CII 的单次探针把歧义集缩小的信息增益 > θ_id；否则澄清把「错误锁定」转成「显式提问」，不安全概率回落到 α。

**推导（组合覆盖-安全）**：令 E_cov={y*∉C_α}，E_unsafe={执行不安全}。当 ¬E_cov 时 y*∈C_α，由 A68 所有候选 (z,θ) 的约束都在包络内，故 C_exec=⋂C(z,θ) 的任何一致执行都安全；C_exec=∅ 时 CRC 强制 abstain。因此 E_unsafe ⊆ E_cov，P(E_unsafe) ≤ α。漂移下以 A70 的 p_miss 修正，并因 NOVEL 弃权而不放大。

```python
class IntentBelief:
    def __init__(self, particles=256, theta_dim=4):
        self.particles = sample_prior(particles, theta_dim)
        self.weights = np.ones(particles) / particles

    def update(self, obs):
        lik = np.array([self._multimodal_likelihood(o, obs) for o in self.particles])
        self.weights = normalize(self.weights * lik)
        self._resample_if_degenerate()
        return self.weights

    def constraint_posterior(self):
        return ConstraintDistribution(
            [project_constraint(o) for o in self.particles], self.weights)

    def _multimodal_likelihood(self, theta, obs):
        return (self._speech_lik(theta, obs) * self._gesture_lik(theta, obs)
                * self._haptic_lik(theta, obs) * self._phase_lik(theta, obs))
```

### IP-162 C-SIP（共形场景-意图预测集）

```python
class ConformalSceneIntentSet:
    def __init__(self, calib, alpha=0.1, delta_action=0.2):
        self.alpha, self.delta_action = alpha, delta_action
        self.calib_scores = sorted(self._score(x, y) for x, y in calib)
        self.qhat = self._quantile(self.calib_scores, 1 - alpha)

    def _quantile(self, scores, level):
        n = len(scores)
        k = math.ceil((n + 1) * level)
        return math.inf if k > n else scores[k - 1]

    def predict_set(self, x):
        return {y for y in self._candidates(x) if self._score(x, y) <= self.qhat}

    def executable_set(self, C_alpha):
        C_exec = intersect_all([project_constraint(z, t) for z, t in C_alpha])
        if C_exec is None or C_exec.diameter() > self.delta_action:
            return None
        return C_exec
```

### IP-163 CRC（共形风险控制决策）

```python
ACTIONS = ['abstain', 'conservative', 'neutral', 'preconverge', 'lock']

def conformal_risk_control(calib, candidate_set, beta, B_bound):
    n = len(calib)
    chosen = 'abstain'
    for a in ACTIONS:
        losses = [L(a, y) for y in calib if y in candidate_set]
        if not losses:
            continue
        bound = (n / (n + 1)) * np.mean(losses) + B_bound / (n + 1)
        if bound <= beta:
            chosen = a          # 损失单调 ⇒ 取最大可行激进度
    return chosen
```

```python
class DriftAdaptiveCalibrator:
    def __init__(self, alpha_target=0.1, gamma=0.01, delta_drift=0.01):
        self.alpha_target, self.gamma, self.delta_drift = alpha_target, gamma, delta_drift
        self.alpha_t, self.martingale, self.state = alpha_target, 1.0, 'IN_DIST'

    def update(self, score_t, covered_t):
        self.martingale *= self._e_value(score_t)
        if self.martingale >= 1.0 / self.delta_drift:
            self.state, self.martingale = 'SHIFT', 1.0
        err = 0.0 if covered_t else 1.0
        self.alpha_t = np.clip(self.alpha_t + self.gamma * (self.alpha_target - err),
                               self.alpha_min, self.alpha_max)
        return self.state, self.alpha_t

    def mark_open_set(self):
        self.state = 'NOVEL'
        return 'abstain_and_request_label'
```
