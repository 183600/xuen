# 第 44 轮（新循环第 4 轮） · Thermo-SLAM-Cert：把「位姿不确定性」与「热-算力-权限衰减」纳入同一证书闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形只保边际覆盖 + 多用户契约空集」，但它仍压着两个更底层的单点假设：**(H1) 几何证书查询的位姿 x 是可信的**——SLAM 只被当作一个永远收敛的定位黑箱，协方差是否过自信、回环是否误闭合、退化环境是否可观测，都没有进入证书；**(H2) 算力与执行权限是恒定的**——INT8 监控的 WCET、制动/力矩上限、推理帧率被当作名义常数，而真实机器人会热降频、电机/电池会热降额。本轮灵感词「同步定位与建图」「热管理」精确命中：SLAM 决定**证书看得准不准**（观测通道），热管理决定**证书算不算得动、机器人刹不刹得住**（计算通道 + 执行通道）。更关键的是二者互相喂养——算得越多越热，越热越算不动也越刹不住；而算得越少，SLAM 越漂、证书越旧。本轮把这条**安全-热反馈环**显式建模，并给出可认证不动点的存在性判据。

## 0. 直觉与动机

**灵感 1（SLAM → 「先证明你看见的是真的」）**：几何证书一直默认 x̂ 就是 x。但 SLAM 给的是 (x̂, Σ, M)，而 Σ 可能过自信（NEES 不一致）、M 可能被一次错误回环整段带偏、走廊/隧道/白墙会让某个方向根本不可观测。直觉：证书不该消费一个点，而该消费一个**可信位姿集合** S_δ；环境退化时集合膨胀，证书要么更保守、要么降速、要么停。更进一步，回环闭合不是普通的「数据更新」，而是**地图语义的跳变**——它必须使旧的几何租约整体作废（map epoch bump），否则就是在用一张已被推翻的地图继续放行。

**灵感 2（热管理 → 「算力与刹车力都是会衰减的资源」）**：机器人不是插着无限电、恒温运行的服务器。持续跑 VLM/INT8 监控会积热→降频→WCET 变长→租约变旧→监控失效；电机/电池过热→最大制动力/力矩降额→真实制动距离变长→原本安全的 margin 不再安全。所以「热」不是运维指标，而是**证书里的两个一阶变量**：热态 Θ 决定可用的计算预算 π(Θ) 与可用执行权限 α(Θ)。证书边界必须随 Θ 单调收缩，而非假设名义值。

**灵感 3（耦合 → 安全-热反馈环与联合退化）**：越想要安全（更频繁认证、更密地图、更高监控帧率），就越耗算力、越热；越热，算力与刹车力越弱，越不安全。这不是线性资源权衡，而是一个可能自激的反馈环。再叠加「热 + 退化」的联合最坏情形（又热、又在走廊、又刚误闭合回环），单轴都 sound 的证书可以联合失效。本轮要求**联合证书**在联合最坏情形下仍下界真实安全域，并给出热-安全不动点判据与单调降级链。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（可信位姿集与协方差一致性）**：SLAM 输出证书状态 (x̂_t, Σ_t, M_v, v)，v 为地图版本/epoch。定义**可信位姿集** S_δ(t) 满足 P(x_t ∈ S_δ(t)) ≥ 1−δ。一致性用 NEES：ε_t=(x_t−x̂_t)^T Σ_t^{-1}(x_t−x̂_t)，若 E[ε_t]>d 或分位超过 χ²_{d,1−δ}，则 Σ_t **过自信**。几何证书只允许在对 S_δ 的**最坏位姿**上取交：**G_δ(t)=⋂_{x∈S_δ(t)} C_geom(x)**（求交而非取中心）。**命题**：若 S_δ 覆盖有效，则 G_δ(t) 内的动作对真实位姿 sound；用 x̂ 单点计算会系统性高估安全域。

**定义 45（退化度与保守性膨胀）**：设观测信息矩阵（点-面 Hessian）为 Λ_t，λ_min(Λ_t) 为其最小特征值，退化判据 λ_min<ε_deg。定义保守性膨胀 ρ(Λ_t)=c·σ_max/λ_min（或分位形式），守卫裕度修正为 **m_eff = m_raw − ρ(Λ_t)**；当 λ_min<ε_deg 时禁止提速，速度上限取 v_max·g(λ_min), g∈(0,1]。**命题**：ρ 关于 λ_min 单调不增，故退化只会让证书更保守，不会更激进。

**定义 46（热-执行权限包络）**：热态 Θ_t=(T_motor, T_bat, SoC, …)，降额映射 α:Θ→(0,1]，实际最大制动力/力矩 u_max(Θ)=α(Θ)·u_nom。制动距离 d_brake(v,Θ)=v²/(2·a_max(Θ))+v·τ_react，随 α 单调不增。定义**权限包络** A_Θ={u:|u|≤u_max(Θ)}，并做**热前视**：在证书时域 h 上用热模型上界预测 Θ(t+h)，取 α_min=min_{s∈[0,h]} α(Θ(t+s))。**命题（单调收缩）**：Θ1≥Θ2（逐分量更热）⇒ u_max(Θ1)≤u_max(Θ2) ⇒ S_safe(Θ1)⊆S_safe(Θ2)。证书恒用 α_min，绝不用瞬时 α。

**定义 47（热-计算预算与 WCET 漂移）**：计算性能 π(Θ)（相对名义的时钟/吞吐比例），任务 WCET_i(Θ)=WCET_i^nom/π(Θ)。最坏测量间隔 Δ_max(Θ)=WCET_cert(Θ)+Jitter(Θ)。**sound 租约判据**：m − L_m·v_max·Δ_max(Θ) ≥ θ。**推论**：热降频等价于**放大租约衰减率**；若仍用名义 Δ，就会在降频时误用陈旧边际。

**定义 48（安全-热反馈不动点）**：设维持证书裕度 m 所需工作负载 W(m)（认证频率、地图维护率、监控帧率），稳态温度 T_ss=g(W(m))（热 RC 模型，单调增），可用裕度 m_avail(Θ)=min(m_geom, m_authority(Θ), m_fresh(Θ))。**热-安全不动点**是满足 m* ≤ m_avail(g(W(m*))) 的 m*。**命题（存在性）**：若 m_avail∘g∘W 连续、单调不增且有界，则存在最小不动点 m*（Knaster–Tarski）；若 m*<θ，则不存在同时满足温度约束与安全阈值的常驻模式，必须进入限速/间歇认证的降级模式。**安全-热悖论**：W 随 m 增大而增大，m_avail 随 W 增大而减小，故「为了更安全而更用力认证」可能把系统推入更不安全的热区。

**定义 49（热-几何联合证书与联合不变式）**：联合守卫裕度
m_joint(t)=min( m_geom(S_δ(t))−ρ(Λ_t), m_authority(α_min(t)), m_fresh(Δ_max(Θ_t)) )。
**联合证书** valid 当且仅当 m_joint≥θ、S_δ 覆盖有效、λ_min≥ε_deg 或已按 g 降速、且租约绑定当前 (map_epoch v, thermal_epoch)。**定理（联合 sound）**：若 (i) S_δ 覆盖真实位姿，(ii) α_min 是热前视下的真实权限上界，(iii) Δ_max 是真实最坏延迟上界，则 m_joint≥θ ⟹ 真实系统在时域 h 内不越界。**注**：三项必须同时成立——任一轴的名义化都会让联合证书失效，这正是 E101 要打的「联合退化」。

## 2. 新增产出与既有 IP 升级

### 2.1 IP-60 UNCERTAINTY-CONSISTENT-GEOMETRY（可信几何层 UCG）
1. **可信位姿集**：按环境类型/退化度分层共形标定 S_δ；在线 NEES/χ² 一致性监测，过自信即膨胀 Σ 或提高 δ。
2. **退化检测**：Λ 最小特征值 + 点-面残差 + 纹理/几何特征计数，输出 λ_min 与膨胀量 ρ，触发降速。
3. **回环准入证书**：几何 + 外观 + 时序三重一致（inlier 比、switchable constraints）才允许 commit；失败则保持旧地图并报警。
4. **地图纪元与回滚**：地图按子图 append-only + 版本号 v；回环/误闭合导致 v bump，受影响子图的几何租约作废，支持子图级回滚而非全局清空。

### 2.2 IP-61 THERMAL-AUTHORITY-ENVELOPE（热权限包络 TAE）
1. **热 RC 模型 + 传感器**：电机/电池/SoC 温度估计，输出 Θ 及其不确定度。
2. **降额映射**：α(Θ)→u_max、a_max，写入制动/力矩/速度上限，带保守上界。
3. **热前视**：在证书时域上用上界预测最坏 α_min，绝不用瞬时 α。
4. **权限证书**：把执行权限变成可查询的证书字段（带 thermal_epoch），供 CAR/规划/监控共同消费。

### 2.3 IP-62 THERMO-COMPUTE-GOVERNOR（热-算力治理器 TCG）
1. **热条件 WCET/RTA**：把 WCET(Θ) 纳入响应时间分析，保证监控器在降频下仍满足 deadline。
2. **热预算隔离**：为安全监控保留不可被个性化/投机挤占的计算与散热预算。
3. **反馈环治理**：在线估计 W→T_ss→m_avail 映射并求最小不动点；不可行则进入限速/间歇认证。
4. **单调降级链**：先降个性化/投机 → 降 VLM 帧率 → 降地图维护率 → 限速 → 安全停机；每步都可认证。

### 2.4 IP-63 THERMO-SLAM-VALIDATOR（热-几何联合验证器 TSV）
1. **热箱 + 退化场景联合注入**：温度扫掠 × 走廊/隧道/动态人群 × 负载曲线。
2. **回环攻击与地图投毒**：错误回环、动态物体入图、地图版本撕裂。
3. **反馈环压力**：长时满负载，观测降频-陈旧-更热-更陈旧的自激。
4. **联合最坏情形**：热 + 退化 + 高负载 + 人群并发，检验 E101 红线。

## 4. 实验设计（E95–E102 硬门槛，承接 E87–E94）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E95 位姿可信集 | S_δ 覆盖真实位姿；NEES 一致性；过自信事件 | ≥1−δ；不超 χ² 上界；0 |
| E96 退化环境 | λ_min 检测召/准；退化下证书违例；降速代价 | ≥95%/≥90%；0；<20% |
| E97 回环/地图攻击 | 误闭合检出；回滚正确性；旧租约误用；不安全事件 | ≥99%；100%；0；0 |
| E98 热-权限包络 | α_min 上界 sound 率；制动距离界违例；温度扫掠 0–80°C | 100%；0；0 |
| E99 热-计算 WCET | WCET(Θ) 预测误差；deadline miss；租约过期率 | <20%；0；<5% |
| E100 安全-热反馈环 | 满负载稳态温度；是否热失控；不动点存在率；恢复时延 | ≤T_max；否；≥99%；<120s |
| E101 联合退化(热+SLAM) | 联合证书违例；联合最坏情形可用性；降级正确率 | 0；≥90%；100% |
| E102 长时程耐久 | 100h 不安全事件；热循环；地图增长/漂移；可用率 | 0；≥500 次；有界；≥95% |

回退：E95 覆盖失效 → 退回 bounded-error/区间 SLAM 并把速度砍到证书可证水平；E96 退化误判 → 固定保守 ρ 且全场景降速；E97 误闭合不可控 → 关闭自动回环、仅人工确认；E98/E99 模型失真 → 用实测最坏上界并缩短时域 h；E100 不动点不存在 → 进入间歇认证 + 限速；E101 联合失效 → 分轴熔断，任一轴不确定即取最保守轴；E102 不达标 → 全链路回退 v20。

## 5. 本轮最大风险

**一句话**：位姿可信集与热降额映射都是**在名义工况下标定的模型**，当「又热 + 又退化 + 又高负载」同时发生且相互放大（热使传感器漂移、漂移迫使更多算力、算力又生热）时，两轴各自 sound 的证书可能联合过自信；因此 E98/E99/E101 必须设为红线，默认回退到「有界误差几何 + 实测最坏热上界 + 限速」这条不依赖协方差与热模型外推的底线。

# 第 44 轮产物 · 创新点清单 v21：Thermo-SLAM-Cert（UCG × TAE × TCG × TSV）× 观测通道与执行通道的联合证书闭环（四层架构 v9）

> 承接第 43 轮产物 v20。本轮**增量插入** IP-60/61/62/63，并升级 IP-39/44/45/47/49/50/51/52/53/54/55/56/58/59；不推倒任何既有层级。核心是把 v20 的「人格契约 + 并发证书」，升级为同时约束 **观测可信性（SLAM 位姿不确定/退化/回环）** 与 **资源真实性（热降频/热降额/反馈环）** 的联合证书闭环：证书不再消费一个位姿点和一个名义算力，而消费一个可信位姿集与一个热条件权限包络。

## 2. 关键算法（伪代码）

### IP-60 UCG：可信位姿集、一致性、退化与回环准入
```
def credible_pose_set(x_hat, Sigma, env_class, delta):
    # 按环境类型/退化度分层的共形标定，避免协方差过自信被直接信任
    q = conformal_quantile(env_class, delta)          # 每层各自的秩统计阈值
    return ellipsoid_or_hull(x_hat, Sigma, q)         # 保证 P(x in S_delta) >= 1-delta

def nees_consistent(x_hat, Sigma, x_ref, d, delta):
    eps = (x_ref - x_hat).T @ inv(Sigma) @ (x_ref - x_hat)
    return eps <= chi2_quantile(d, 1 - delta)         # False => 过自信

def degeneracy_inflate(Lambda):
    lam_min = eigmin(Lambda)
    rho = C_RHO * (eigmax(Lambda) / max(lam_min, EPS))
    speed_gain = 1.0 if lam_min >= EPS_DEG else clamp(lam_min / EPS_DEG, G_MIN, 1.0)
    return rho, speed_gain                           # 只增保守性、只降速度

def loop_closure_commit(staged, M):
    # 几何 + 外观 + 时序三重一致才允许改图
    if not (staged.inlier_ratio >= TAU_INL
            and appearance_consistent(staged)
            and temporal_consistent(staged, M)):
        return M, Reject("loop_closure_unverified")
    M_new = append_submap(M, staged); M_new.epoch = M.epoch + 1
    # 只作废受影响子图的几何租约，支持子图级回滚
    invalidate_leases_where(lambda l: l.map_epoch == M.epoch and affects(l, staged))
    return M_new, Commit(map_epoch=M_new.epoch)
```

### IP-61/62 TAE + TCG：热前视、热条件租约与不动点
```
def authority_bounds(Theta):
    alpha = derate_map(Theta)                         # 电机/电池降额曲线（保守上界）
    return alpha, alpha * U_NOM, alpha * A_NOM

def thermal_lookahead(Theta0, horizon, workload, rc_model):
    # 用热 RC 模型上界外推，取时域内最坏权限，绝不用瞬时 alpha
    traj = rc_model.predict_upper(Theta0, workload, horizon)
    return min(derate_map(Theta) for Theta in traj)   # alpha_min

def thermal_wcet(Theta, wcet_nom):
    return wcet_nom / perf_ratio(Theta)               # 降频 => WCET 变长

def lease_valid_thermal(lease, theta, Theta, t):
    delta_max = thermal_wcet(Theta, lease.wcet_nom) + jitter_bound(Theta)
    return (lease.m - L_m * v_max * delta_max) >= theta   # 用最坏间隔，而非名义间隔

def thermo_safety_fixed_point(m_need, T_max, workload_fn, rc_model):
    lo, hi = 0.0, m_need
    for _ in range(BISECT_ITERS):                     # 单调不增映射，二分求最小不动点
        m = 0.5 * (lo + hi)
        Theta_ss = rc_model.steady_state(workload_fn(m))
        if Theta_ss <= T_max and m <= min_available_margin(Theta_ss):
            lo = m
        else:
            hi = m
    return lo if lo >= THETA_SAFE else None            # None => 进入间歇认证/限速
```

### IP-51/58 升级：联合守卫与热-退化感知降级
```
def joint_guard(e, x_hat, Sigma, Lambda, M, Theta, lease, t, h):
    S = credible_pose_set(x_hat, Sigma, env_class(M), DELTA)
    m_geom = min_margin_over(C_geom, S) - degeneracy_inflate(Lambda)[0]
    alpha_min = thermal_lookahead(Theta, h, current_workload(), RC_MODEL)
    m_auth = margin_from_authority(alpha_min, e)
    delta_max = thermal_wcet(Theta, lease.wcet_nom) + jitter_bound(Theta)
    m_fresh = lease.m - L_m * v_max * delta_max
    m_joint = min(m_geom, m_auth, m_fresh)
    epochs_ok = (lease.map_epoch == M.epoch and lease.thermal_epoch == thermal_epoch(Theta))
    return m_joint >= THETA_GUARD[e] and epochs_ok

def degrade_chain(Theta, m_star, tasks):
    if m_star is not None:
        return tasks                                   # 不动点可行，保持当前模式
    tasks = drop(tasks, K_DIALOGUE)                    # 1) 砍个性化
    tasks = throttle(tasks, K_SEMANTIC)                # 2) 降 VLM 帧率
    tasks = reduce_map_maintenance(tasks)              # 3) 降地图维护率
    if not certify_limited_speed(Theta):               # 4) 限速到可证水平
        return safe_stop()                             # 5) 安全停机
    return tasks
```

def acquire_lease_epoch(task, x, theta, Theta, M):
    b = cert_lookup_L0(x)
    lam = L_m * v_max_bound(x)
    return Lease(m=b.m_lo, tau=monotonic_now(), lam=lam, kappa=task.kappa,
                 map_epoch=M.epoch, thermal_epoch=thermal_epoch(Theta),

def monitor_step_thermal(x, Theta, budget_us):

## 6. 本轮最大风险

**一句话**：位姿可信集与热降额映射都是**在名义工况下标定的模型**，当「又热 + 又退化 + 又高负载」同时发生且相互放大（热使传感器漂移、漂移迫使更多算力、算力又生热）时，两轴各自 sound 的证书可能联合过自信；因此 E98/E99/E101 必须设为红线，默认回退到「有界误差几何 + 实测最坏热上界 + 限速」这条不依赖协方差与热模型外推的底线。
