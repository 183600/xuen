## 1. 直觉与动机（两个灵感的碰撞）

**灵感 1（语音识别 → VLA 只造了「声学模型」，缺了「解码器」）**
- 直觉：ASR 的胜负从来不只由声学模型决定：声学模型只给出每帧音素后验，真正把后验变成可靠文本的是解码器——语言模型先验、beam search、n-best 重打分、置信度、端点检测（endpointing）、ROVER 多系统投票。映射到今天：VLA 动作头就是「声学模型」，给出一个模糊的动作 chunk 分布；而大多数实现只做「取第一次采样、整段执行」——**没有解码器**。动作世界的「同音词」是：同一场景下多种都算合理的抓取/放置轨迹（不同接近方向、不同抓取点、夹爪开合细节）。第一次采样可能落在低质量模式上，却没有任何机制把它与高质量模式区分开。
- 反直觉点：**不改权重，补一个解码器，可能是本轮最高性价比的鲁棒性来源**——它利用的是模型已经会、但没被选出来的好动作，而不是要求模型学会新能力。

**灵感 2（真机评测 → 评测本身是仪器，仪器会漂移）**
- 直觉：真机评测稀缺、方差大，不能靠「多跑几次看均值」。ASR/统计学的成熟答案是：序贯检验、置信序列、配对设计、预注册、最小可检测效应（MDE）、评分者一致性。更关键的是 F21：评测记录**延迟波动与动作统计规律性**并与结果一同展示——评测不只在测「会不会做」，还在测「这台仪器是否稳定可信」。若策略延迟忽高忽低、动作偶发跳变，即使平均成功率不差，也可能在可信度维度吃亏；反过来，一个高方差 bug 会污染我们自己的 A/B，使增益不可归因。
- 反直觉点：**先把评测仪器校到可证伪，再谈策略更强；且仪器健康度（延迟/规律性）应进入解码器的目标函数，而不是事后补救。**

**两者的咬合**：解码器需要置信度决定「选哪个/是否弃权」，评测仪器需要置信区间决定「这次增益是不是噪声」。ASR 给了前者语言模型式先验与 conformal 置信校准，统计给了后者 anytime-valid 的停工规则。于是本轮把「动作解码」与「真机评测」做成闭环：**解码器产生可校准置信度 → 评测按置信度分配稀缺真机预算 → 评测同时监控仪器漂移 → 漂移反馈回解码器的可信度约束**。

- PR1–PR5 保留。PR2 单模型边界在本轮细化：解码器只允许复用同一权重、缓存嵌入与非学习先验；学习型 verifier 只能是同一 checkpoint 的辅助头。

# UniBot-V1 参赛创新点清单（v1.2）

> 承接 v1.1：新增 I10/I11/I12，深化 I4/I5/I6/I9，I8 并入 I12，I7 降级。检索：2026-11-26（第 1 轮）、2026-11-27（本轮；官网不可达，GitHub 官方模板可达）。新增事实 F20–F26 见想法区 §0。清单只增改不重置。

## 0. 本轮新增/深化点（每点：动机 / 与现有方案差异 / 技术可行性 / 所需资源 / 落地步骤 / 风险）

### I10 动作 n-best 解码器：ROVER 共识 + 物理先验 + 可校准弃权 ★★★★★

- **动机**：动作头只产生分布，当前实现取第一次采样整段执行（P11）；真机又按延迟与动作规律性评估可信度（F21）。同一场景存在多个「动作同音词」，不比较就无法排除低质量模式。
- **与现有方案差异**：直接 SFT/流匹配队伍把「采样」当「决策」；本点在**同一权重**上做一次批量候选生成，用 ROVER 式共识、非学习物理先验和可校准置信度完成「解码」，并提供弃权路径。它不是第二个模型，也不做在线学习。
- **核心机制**（细节见 §1.1）：
  1. **批量候选**：一次 batched forward 用 K 个不同噪声种子生成 K 个动作 chunk（同 T_a），GPU 批并行使 wall-time 次线性增长；成本按 chunk 摊销（F24）。
  2. **ROVER 共识**：对 K 个候选算成对距离（EE/关节轨迹 + 夹爪 Hamming），取 medoid 为主候选；夹爪按簇内多数投票；连续量取簇内鲁棒加权中位数。
  3. **物理先验否决**：用评测提供的关节/EE 状态（F22）检查速度/加速度上界、EE 路径与估计桌面平面的穿透裕度、夹爪抖动；硬违规候选直接出局（非学习规则，PR2 合规）。
  4. **置信与弃权**：置信度 = 共识簇占比 × top-1/top-2 间隔；用留出集做 conformal 阈值校准，使「接受子集」的成功率下界 ≥ 1−α；低置信时输出安全保持动作并请求重观测，连续弃权则交给 I5 恢复。
  5. **可信度项**：打分函数含延迟与动作跳变惩罚，优先选「同样好但更规律」的 chunk（对齐 F21）。
- **技术可行性**：高。候选生成/共识/几何校验均为纯推理期计算，无新训练；conformal 校准只需数百条留出 episode 的成功标签。
- **所需资源**：0 额外 GPU（复用现有后端，K 使显存/算力按 K 增长，K=4–5）；工程 1 人周；L0 回放算力 1 GPU 日。
- **落地步骤**：①实现批量 K 采样与 ROVER；②接入关节/EE 物理否决；③日志多候选离线回放，扫 K、温度、共识阈值；④conformal 弃权阈值校准；⑤门禁回归 p99/动作规律性；⑥单任务通道 A/B（decode on/off）。
- **风险**：代理失相关导致「高置信度选错」（见本轮最大风险）；流匹配/扩散头若无法批量采样需改接口（缓解：先验证 batched sampling）；K 增大可能抬高 p99（缓解：chunk 摊销 + K 自适应剩余时间预算）。

### I11 得分点相位端点检测（phase-VAD）★★★★

- **动机**：长程任务需要知道「一个子技能何时结束、下一个何时开始」。固定 chunk 会在相位边界处盲目续做；而 ASR 的 endpointing 正是解决「何时提交」的成熟范式。官方得分点（F17）天然给出相位里程碑。
- **与现有方案差异**：现有方案用固定 horizon 或人工规则切换；本点从示教中学习相位后验，用「相位置信 + 熵 + 驻留时间」做端点检测，驱动 chunk 长度（I4）、重观测与恢复触发（I5）。
- **核心机制**（§1.2）：相位标签由得分点经单调强制对齐（类似 CTC 对齐，允许跳过缺失里程碑）自动生成；推理期维护相位后验 p(φ_t)，当 argmax 稳定 h 步且熵 < ε、或进度导数 ≈0 时判端点；双侧阈值 + 滞回 + 最小驻留防止 chatter；稳定相位用长 chunk（约 16–30），接近端点或高熵用短 chunk（4–8）。
- **技术可行性**：中-高。相位头可复用进度头骨干，作为同 checkpoint 的辅助头（PR2）；对齐是纯数据处理。
- **所需资源**：1×24GB GPU 训练辅助头；数据工程 1 人周；标签逆向 1 人周。
- **落地步骤**：①逆向每任务得分点清单；②强制对齐生成相位标签；③训练/挂载相位头；④端点规则与 chunk 联动；⑤L0 相位切换准确率 + 真机抽测。
- **风险**：误端点（过早提交/卡死）——缓解：双侧阈值、滞回、最小驻留、低置信回退长 chunk；得分点标签噪声——缓解：人工抽检 5% + 置信门控。

### I12 真机评测仪器：anytime-valid + 配对分层 + 漂移监控 ★★★★★

- **动机**：真机预算稀缺（P7），且官方把延迟波动/动作规律性纳入可信度（F21）。若无预注册与不确定区间，任何「提升」都可能是噪声或仪器漂移；这正是把 I8 从「记录表」升级为「测量仪器」的时刻。
- **与现有方案差异**：常见做法是「跑几组看均值」/边跑边看边停（optional stopping 偏差）；本点用预注册 + 配对分层 + anytime-valid e-process 做可证伪判决，并把仪器健康度做成一等公民。
- **核心机制**（§1.3）：
  1. **预注册**：先固定主指标、假设（A 轴优效 / C 轴非劣 margin δ）、分层（任务×泛化轴×seen/unseen）、最大 episode 数、停止规则、排除项（仪器漂移、token/形状失败）。
  2. **配对分层**：同任务同初始种子成对跑 A/B，交替顺序抵消预热/学习；无法配对时按层加权并用协变量调整。
  3. **anytime-valid 停工**：对配对差 d_i∈[−1,1] 构造 betting e-process K_t=∏(1+λ d_i) 或置信序列；K_t≥1/α 即拒绝「A 不大于 B」，允许中途查看而不膨胀 α。
  4. **MDE/功效**：实验前算最小可检测效应；若所需 episode 超预算，则缩小分层范围或改非劣检验，而不是硬跑。
  5. **可靠性与漂移**：自动里程碑检测器 vs 人工标注的 Cohen's κ（≥0.8 才准入训练标签）；重复 episode 的 test-retest ICC；延迟/动作跳变分布对冻结参考做 KS 检验，p<0.01 或 p99 超预算则整批作废。
  6. **离线-在线注册表（承 I8）**：每条记录增加仪器状态列，滚动估计「离线代理 → 真机增益」的校准与预测区间，达到相关阈值才允许离线代理单独准入 L2。
- **技术可行性**：高（统计脚本 + 预注册模板，几乎零 GPU）。
- **所需资源**：统计/评测工程 1 人周；首个用例复用现有单任务通道。
- **落地步骤**：①预注册模板；②配对与分层采集；③e-process/CS 实现与单测（覆盖 optional stopping 场景）；④仪器面板（p99/跳变/拒绝率）；⑤首用 I2 孪生迁移；⑥月度相关性复盘。
- **风险**：真机初始条件不可重复导致配对假设破裂——缓解：分层 + 协变量调整 + 报告配对比例；样本过少使 CS 过宽——缓解：预注册时先算 MDE，必要时只做非劣或缩小问题。

### 对既有创新点的增量（不展开六要素的维持项）

- **I4**：chunk 长度从固定档改为由 I11 相位后验驱动；干预态仍走短 chunk + 停持。
- **I5**：得分点逆向 + 单调强制对齐，把「合成恢复示教」的里程碑检测器从自监督升级为对齐监督；恢复后必须重新通过相位端点才算成功段。
- **I6**：共享后端改为「批量 K 候选 + N 端口并发」共同压测；每端口状态隔离 + p99 与动作规律性并入 I12 仪器门禁。
- **I9**：在 reset 检索之外，离线构造「易混对象最小对」（同类别不同外观/颜色/尺寸），做指令-物体对比学习与硬负样本；推理期把指令关键词作 ASR 式 hotword 偏置，检索距离阈值用 I12 校准。
- **I2/I1**：质量分增加「动作规律性」；I1 新增「时间扭曲/段丢弃」轨迹级增广，但必须先过 L0（可能破坏接触相位，默认小剂量）。
- **I7**：降为上限对照（用世界模型 rollout 做离线上限），不再占默认推理路径；资产转 I5 数据引擎。
- **I8**：并入 I12，保留原 L0/L1/L2 分级与注册表字段。

## 1. 严谨定义与关键伪代码

### 1.1 动作解码：候选、共识、置信、弃权

设一次 `get_action` 的动作 chunk 为 $c=(a_1,\dots,a_{T_a})$，$a_t\in\mathbb{R}^{d}$（joint 或 ee）。用 K 个噪声种子得到候选集 $C=\{c^{(1)},\dots,c^{(K)}\}$。

**成对距离**（分量加权）：
$$
D_{ij}=w_p\,\overline{\lVert p^{(i)}_t-p^{(j)}_t\rVert_2}+w_r\,\overline{\angle(R^{(i)}_t,R^{(j)}_t)}+w_g\,\frac1{T_a}\sum_t \mathbb{1}[g^{(i)}_t\neq g^{(j)}_t],
$$
其中 $p,R,g$ 分别为位置、姿态、二值夹爪。

**ROVER 主候选（medoid）**：$c^\star=c^{(\arg\min_i \operatorname{median}_j D_{ij})}$。

**共识簇**：$\mathcal{S}=\{j: D_{\star j}\le \tau_R\}$，共识度 $\rho=|\mathcal{S}|/K$。

**融合**：连续量取 $\mathcal{S}$ 内按 $1/D_{\star j}$ 加权的鲁棒中位数；夹爪取 $\mathcal{S}$ 内逐帧多数票。

**物理否决** $F(c)\in\{0,1\}$：由观测关节/EE 状态（F22）与 $T_a$ 推出允许的最大速度/加速度，检查轨迹差分；用 EE 高度估计桌面平面，要求路径穿透裕度 $>m$；夹爪不得在接触前抖动翻转。任一硬违规则 $F=0$。

**可信度项** $Q(c)$：$Q=-\big(\beta_1\,\widehat{\text{lat}}(c)+\beta_2\,\text{jerk}(c)+\beta_3\,\text{outlier}(c)\big)$，对齐 F21。

**选择**：$c^\ast=\arg\max_{c\in C,\,F(c)=1}\big(\rho(c)+\gamma Q(c)\big)$；若 $\rho<\tau_c$ 或全部 $F=0$，**弃权**。

**置信度**：$\kappa=\rho\cdot\big(1-\frac{s_2}{s_1+s_2}\big)$，其中 $s_1,s_2$ 为簇得分前二（top-1/top-2 间隔），$\kappa\in[0,1]$。

**conformal 弃权阈值**：在留出集上收集 $(\kappa_i,\text{succ}_i)$，取
$$
\tau_c=\sup\{\tau: \widehat{\Pr}(\text{succ}\mid \kappa\ge\tau)\ge 1-\alpha\}
$$
（用分批 conformal / Clopper–Pearson 下界实现）。接受集的经验成功率下界即为可报告保证。

```python
class ActionDecoder:                       # 同一 PolicyService 内的推理组件，无第二模型
    def decode(self, obs, K=5, budget_ms=40):
        seeds = self.rng.spawn(K)
        cands = self.vla.sample_chunks(obs, seeds, batch=True)      # 一次批量前向
        D = pairwise_chunk_distance(cands, weights=(1, .5, 1))
        star = medoid(D)
        S = [j for j in range(K) if D[star][j] <= self.tau_R]
        fused = fuse(cands, S, D[star], grippers="majority")
        if not all(physical_ok(cands[j], obs) for j in S):
            S = [j for j in S if physical_ok(cands[j], obs)]
        if not S:
            return self.abstain(obs, reason="no_feasible")
        rho = len(S) / K
        kappa = rho * top2_margin(cands, S)
        if kappa < self.tau_c:
            return self.abstain(obs, reason="low_conf")
        return fuse(cands, S, D[star]), kappa

    def abstain(self, obs, reason):
        self.consecutive_abstain += 1
        if self.consecutive_abstain >= 2:
            return self.recovery_prior(obs)    # 交给 I5 / I9 先验，不无脑停
        return safe_hold(obs)                  # 保持 + 请求重观测
```

**预算**：批量 K 的一次前向 + $O(K^2T_a)$ 打分；以 $T_a=16\text{–}30$ 摊销，目标 p99 < 40ms（以 15Hz≈66ms 为参照，F12；真实节拍待复现标定）。

### 1.2 相位端点：从得分点到 chunk 与恢复

设每任务得分点序列 $m_0\prec m_1\prec\cdots\prec m_M$（满分 100，F17）。对示教轨迹特征 $x_{1:T}$ 做**单调强制对齐**（允许跳过未出现的里程碑），得到相位标签 $\phi_t\in\{0,\dots,M\}$：

$$
\hat\phi_{1:T}=\arg\max_{\phi\ \text{monotone}}\sum_t \log p(m_{\phi_t}\mid x_t),\qquad \phi_t-\phi_{t-1}\in\{0,1,\dots,\text{skip}\}.
$$

训练相位头 $p(\phi_t\mid o_{\le t})$（与进度头共享骨干，同 checkpoint 辅助头）。端点判据：

$$
\text{endpoint}(t)=\Big[\arg\max_\phi p(\phi\mid o_{\le t})=\phi_{\text{next}}\Big]\wedge\big[H(p)<\varepsilon\big]\wedge[\text{dwell}\ge d_{\min}],
$$

并对「进入下一相位」与「退回上一相位」用不同阈值（滞回），防止 chatter。判决后：稳定态 $T_a\leftarrow T_a^{\text{long}}$（16–30）；近端点/高熵 $T_a\leftarrow T_a^{\text{short}}$（4–8）并请求重观测；若 $\Delta\text{progress}<\epsilon$ 持续窗口，触发 I5 恢复。

### 1.3 真机评测仪器

**分层与配对**：层 $s=(\text{task},\text{axis},\text{seen/unseen})$；在第 $s$ 层内对候选 A/B 使用同一初始条件（可行时）成对，顺序交替。配对差 $d_i=(\text{score}^A_i-\text{score}^B_i)/100\in[-1,1]$。

**anytime-valid 判决（betting e-process）**：对 $H_0:\mathbb{E}[d]\le 0$，取 $\lambda\in(0,1)$，
$$
K_t=\prod_{i=1}^{t}(1+\lambda d_i),\qquad \text{若 }\exists t,\ K_t\ge 1/\alpha\ \Rightarrow\ \text{拒绝 }H_0.
$$
由 Ville 不等式，在 $H_0$ 下 $\Pr(\sup_t K_t\ge 1/\alpha)\le\alpha$，故可任意时刻查看与停止（避免 optional stopping 偏差）。连续分数且尺度未知时，用 sub-Gaussian 置信序列或按 $\alpha_t=\alpha/(t(t+1))$ 的 spending 做保守版。

**MDE / 功效**：配对二值时，设不一致对比例为 $\psi$，检出效应 $\delta$ 约需
$$
n\approx\frac{(z_{1-\alpha}+z_{1-\beta})^2\,\psi}{\delta^2}.
$$
实验前用该式判定预算是否足以回答当前问题。

**可靠性**：里程碑检测器与人工标注的 Cohen's $\kappa$（每任务每得分点），$\kappa\ge0.8$ 才允许其标签进入 I5 训练；重复 episode 用 ICC 衡量 test-retest。

**仪器漂移**：维护冻结参考分布 $\mathcal{R}$（延迟、jerk、动作越界率），对当前批次做双样本 KS；若 $p<0.01$ 或 $\text{p99}>B_{\text{lat}}$ 或拒绝率 $>0$，整批标记 `INVALID`，不进入主分析。

```python
PREREG = {
  "primary": "paired_score_delta",
  "hypotheses": {"A_axis": ("superior", 0.0), "C_axis": ("noninferior", 0.02)},
  "strata": ["task", "axis", "seen_unseen"],
  "alpha": 0.05, "max_n": 240, "stop": "e_process", "exclude": ["instrument_drift"],
}

def run_trial(cand_A, cand_B, prereg):
    log = []
    for s, i in paired_strata_stream(prereg):
        d = execute_pair(cand_A, cand_B, s, i)        # 同初态，顺序交替
        if instrument_drifted(log):
            mark_invalid(); continue
        log.append(d)
        if e_process(log, lam=0.5) >= 1 / prereg["alpha"]:
            return verdict("reject_H0_anytime_valid", log)
    return verdict("inconclusive", log)

def e_process(ds, lam):
    k = 1.0
    for d in ds:
        k *= (1 + lam * d)
    return k
```

## 2. 实验设计（v1.2 分级协议）

| 级别 | 内容 | 通道/成本 | 通过判据 |
|---|---|---|---|
| L0 | I10 多候选离线重打分（日志回放）；I11 相位切换准确率；I9 最小对检索；I2 孪生家族迁移 | 离线/免费 | I10 动作方差↓≥10% 且标称代理不降；I11 端点 F1≥0.85；I9 标称不伤 |

| L2 | 预注册配对真机：decode on/off、phase on/off、I2 共训；A 轴优效 / C 轴非劣 | 单任务通道 | e-process ≥1/α；仪器无漂移；报告 anytime 置信区间 |
| 门禁 | run_client 全流程 + N 端口隔离 + 动作健康度 + token | 本地 stub + 并发 | 0 拒绝、p99<40ms、状态隔离无串扰 |

**首批 L2 排队**：①I12 预注册跑通（用已知无差异的 A/A 对照验证假阳性率 ≤α）→ ②I2 孪生迁移 → ③I10 decode on/off → ④I11 phase on/off。

> A/A 对照是仪器的「零点校准」：若 A/A 都报出显著增益，说明评测仪器本身有偏，先修仪器再测创新。

## 7. 当前方案最大风险

**一句话**：解码器的置信度/共识是离线代理的函数，一旦代理与真机成功在未见轴上失相关，系统会稳定地、高置信地做错——评测仪器只能证明错得稳定，不能替你选对。
