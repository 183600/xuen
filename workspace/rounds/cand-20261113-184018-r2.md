# 第 67 轮（新灵感驱动研究循环 第 2 轮；本轮灵感词：「末端位姿」×「多模态交互」）

> 承接声明：第 66 轮已把赛题切到 UniBot（产物 v1，IP-C01~C10），核心是「把五类泛化编译成场景轴的仿真预算」。本轮不重开清单，而是沿两个新灵感补上 v1 最大的两块空白：①策略与数据仍停留在绝对基座坐标，未利用接口自带的 SE(3) 结构；②v1 明确承认「接触精密/柔性轴仿真帮不上」，却没有给出真机侧的替代信号。产物升级为 v2（C01~C15）：新增 C11 EEFrame、C12 GroupBudget、C13 ContactSense、C14 CrossView、C15 ContactSkill，并改写 C02/C04/C05/C08/C10 的接口。最关键的事实核验：提交 README 与官方数据都原生提供末端位姿动作/观测（base 与 torso 两套坐标系），因此 EE 空间不是权宜之计，而是赛题的主坐标。

## 0. 本轮检索核实（检索日期 2026-11-13）

1. **提交接口（重新抓取 README，逐条核对）**：`control_space ∈ {joint, ee}` 互斥；`ee` 模式的动作键为 `action.left/right_ee_pose_gripper_base`，形状 `[6] = xyz(3)+rpy(3)`，语义是**基座系下的绝对目标位姿**；观测同键 `observation.state.*_ee_pose_gripper_base` 也是基座系绝对位姿。另有 4 路 RGB、语言、双臂 7 维关节、夹爪、15 维下肢、`action_chunk_size`、N 个连续端口、逐步延迟与动作统计的可信度条款。
2. **官方数据（HF datasets-server 结构化核对，绕开 401）**：集合恰好 32 个 `G1_Dex1_*`；每个约 1000 episodes、30 fps、4 路 AV1 480×640（head_stereo_left/right、wrist_left/right）。Parquet 特征不仅含 `action.left/right_arm`（关节目标），还**原生含 `action.left/right_ee_pose_gripper_base`、同名 torso 系位姿、`observation.state.*_ee_pose_gripper_{base,torso}`、`state_torso`、`waist_state_joint`、`recomputed_ee_valid`**。→ EE 监督信号无需自己反解 IK，官方数据已经给出；这直接支持 C11。
3. **数据中的命令-状态残差（本轮新做的取证）**：用 datasets-server 的 rows 接口抽取 PlugCharger / FoldTowel 的多个 100 帧窗口，比较 `action.*_ee_pose_gripper_base` 与 `observation.state.*_ee_pose_gripper_base`。在最优帧滞后（0–5 帧，约 0–167 ms）下，位置残差中位数：PlugCharger 0.0083–0.0136 m，FoldTowel 0.0109–0.0227 m，且随任务阶段明显变化。**注意**：EE 位姿可能由关节重算（`recomputed_ee_valid`），所以这更像「命令-状态在 EE 空间的映射差」，不能直接当作标定过的力；但足以证明残差通道存在、且是相位相关的，值得用 C13 正式检验。
4. **文献（本轮检索，用于定位差异）**：Equivariant Diffusion Policy（arXiv:2407.01812）证明桌面 6-DoF 控制的 SO(2) 对称性；Spherical Diffusion Policy（2507.01723）把对称性扩到 SE(3)，但要求任务/场景整体变换。GEAR-VLA（2606.08530）与 VLA scaling 研究（2602.09722）都报告 **EEF-relative 动作表示**是跨场景/跨本体最稳的选择；UMR（2609.34256）、OASIS（2605.25829）把世界流与自车轨迹用 SE(3) 共轭联系起来。接触侧：CoPRE（2609.27381）在 Unitree G1 上用**无接触数据**学关节力矩残差做接触检测；Beyond Implicit Force（2607.14578）指出遥操作的 leader-follower 跟踪误差本身就是隐式力线索。多视图侧：MVUCF（2608.01826）用「训练期跨视图几何一致性」把深度/对应关系注入 VLA 且推理零开销；WARP-VLA（2610.11508）与头视图边际效用研究（2610.14075）说明腕部视角既关键又不稳定。
5. **未核实（下轮首查）**：低层 EE 控制器是纯位置、阻抗还是导纳（决定 C13 的残差是否可观测/是否饱和）；`action.*_ee_pose` 是遥操作目标还是后处理重算；接口 `cam_*_high` 与数据集 rectified 立体对是否严格同参；规则手册的步骤分定义；N 与评测槽数量；排行榜仍未公开（沿用工作假设 A0）。

## 1. 直觉（先讲人话）

**灵感 1（末端位姿）：接口其实是一本 SE(3) 代数，而不是一串 6 维向量。** 现在多数队伍会把 `ee` 动作当成「6 个数回归」：基座系下的 xyz+rpy 绝对目标。这样做的代价是，网络必须同时学「任务怎么做」和「物体/基座在世界里的绝对位置」。但赛题五类泛化里的「位置变化」恰恰是在动物体；只要把动作改写成**相对当前末端位姿的变换** Δ = T_obs^{-1} T_target，绝对坐标这个 nuisance 就被代数消掉了——这正是 GEAR-VLA、VLA scaling、UMR 在 2026 年反复验证的 EEF-relative 表示。更妙的是，官方数据本来就同时存了关节与末端两套动作，等于把这条路的监督成本降到了零。相对表示还顺带对 `action.pivot` 引起的基座/躯干微漂移免疫，因为 Δ 只依赖局部观测，不依赖全局基座坐标。

**灵感 2（末端位姿 → 对称性预算）：位置泛化不是「多采数据」，而是「在群的哪些元素上，任务真的不变」。** 桌面任务的物理在绕竖直轴旋转与水平平移下近似不变（重力仍竖直、相对几何保持），所以可以把一条成功轨迹和整个场景一起做 g∈SE(2) 变换，得到一条新的合法演示；理想情况下不用重解接触物理，只需重渲染。但机器人基座固定、手臂工作空间有限、相机固定、任务可能依赖桌面边界——所以对称性不是布尔值，而是**随 g 衰减的预算**。把「TwinCal 的任务信任度」扩展成「任务 × 群元素」的信任度，是对 v1 最自然的深化。

**灵感 3（多模态交互）：接口没给力传感器，但给了三种可以互相校验的弱信号。** ①**本体感觉**：命令的 EE 位姿与实际观测的 EE 位姿之差，在阻抗/导纳控制器下近似等于外力除以刚度；即使是纯位置控制，接触瞬间的残差突变与方向仍然可读。②**视觉**：头部是已矫正双目（C06 的免费深度），腕部是接触近景；两路对同一物理点的重投影一致性，可以做遮挡/人手的检测器。③**语言**：告诉策略当前处于「插入/折叠/放置」哪一类阶段，从而给残差与视觉设不同先验。多模态交互在这里不是「把特征拼起来」，而是**证据路由**：正常态信视觉，接触态信本体残差，遮挡态降权腕部、切头视图，检测到人手则切恢复技能。它正好补上 v1 承认的接触轴空白——而且完全在接口合法信号内实现。

**合流 → 本轮核心命题：**
> **把「末端位姿」当作策略、数据增广、仿真标定与接触感知的共同货币：动作用相对 EE 变换表示（C11），位置泛化用「测得缺陷的 SE(2) 群预算」增广（C12），接触轴用「命令-观测残差」这个免费力方向通道（C13），并用跨视图一致性 + 语言先验做多模态证据路由（C14/C15）。一句话：一个坐标，三种用途。**

## 2. 严谨定义

**定义 1（EEFrame 动作算子）** 设观测末端位姿 T_o∈SE(3)，接口要求的绝对目标 T_a∈SE(3)。策略内部预测 Δ=T_o^{-1}T_a，部署时组合 T_a=T_o·Δ。性质：(i) 对任意左乘重基 g∈SE(3)（T_o→gT_o, T_a→gT_a），Δ→(gT_o)^{-1}(gT_a)=Δ，**严格不变**；(ii) 块内所有步都以块起点 T_o 为参考（非逐步 delta），避免逐步复合的误差累积；(iii) 接口不变：外部仍看到绝对基座系动作。夹爪维度不参与 SE(3)，单独回归。

**定义 2（桌面场景群作用）** 固定基座、桌面水平、重力沿 −z。取 G = {g=(R_z(θ), t_x, t_y)} ≅ SE(2) 嵌入 SE(3)，作用于场景 S 中所有物体位姿与整条末端轨迹 τ（左乘）。若 τ 在 S 上成功，则 g·τ 在 g·S 上成功，前提是：(D1) g·τ 满足关节限位/可达性；(D2) 不碰固定基座/躯干；(D3) 任务不依赖绝对桌面边界、液体/重力方向（SE(2) 绕 z 旋转与水平平移保持重力，故这一项通常满足，但倾倒/流动类除外）；(D4) 观测需按新场景与新手位姿重渲染。

**定义 3（对称性预算 / 群缺陷）** 对任务 k 与 g∈G，定义 ε_k(g) = E_{ep} ℓ( replay(g·τ_ep; g·S), g·τ_ep )（可用 TwinCal 的物体/末端重放误差，或 DryRun 成功率下降）。信任集 G_ε(k)={g: ε_k(g)≤ε_max}。训练增广只从 G_ε(k) 采样；这等价于把 v1 的「任务信任度」细化为「任务 × 群元素信任度」。

**定义 4（命令-观测残差与接触分数）** 在 t 时刻发送绝对目标 u_t，经执行延迟 δ 后观测到 y_{t+δ}。残差 twist ξ_t = log( u_t^{-1} y_{t+δ} ) ∈ se(3)（平移部 ξ^p∈R^3，旋转部 ξ^ω∈so(3)）。用只用无接触段的标定数据训练名义残差 ξ̂_t=f_φ(历史,u)，定义接触分数 s_t=‖W(ξ_t−ξ̂_t)‖₂，方向 d_t=normalize(ξ_t^p−ξ̂_t^p)。若低层为线性阻抗，稳态 ξ^p≈K^{-1}F，故 F̂=Kξ^p 给出力的大小与方向；若为高刚度纯位置控制，|ξ| 会被饱和/截断，此时 s_t 只作**接触指示**，d_t 仍可作**方向先验**——这是必须写进使用条件的诚实边界。

**定义 5（跨视图一致性）** 头部双目给出度量深度 D_t（C06），腕部给出近景。对同一物理点 x，头部点云经外参 T_{w←h} 投到腕部：e_t=‖π_w(T_{w←h}x)−x_w‖；或分别估计物体 6D 位姿，c_t=d_SE3(T_obj^head,T_obj^wrist)。一致性低 ⇒ 遮挡、资产变化或人手入镜。训练期可把 e_t 作为几何一致性损失（MVUCF 路线），推理期只保留轻量检测头，零额外传感器。

**定义 6（多模态证据路由）** 证据向量 e_t=(s_t^contact, c_t^view, u_t^unc, l)。用带迟滞的有限状态机映射到模式 m_t∈{nominal, compliant, recover, stop}：nominal 走 VLA 快头；compliant 在名义目标上叠加由 d_t 引导的小幅导纳/螺旋搜索；recover 调 C04/C15 的后撤-重抓-重放；stop 仅在连续冲突时触发（保护硬件）。模式切换有最小驻留时间，避免振荡。

**命题 1（EEFrame 的方差消去）** 若基座/场景存在未观测偏移 b（例如重定位误差、桌面摆放），绝对目标 T_a 的分布方差为 Var(任务)+Var(b)，而 Δ=T_o^{-1}T_a 在「T_o 与 T_a 同受 b 影响」时严格消去 b。故在同一样本量下，相对表示的回归目标熵更低，有限容量网络的有效样本效率更高。这正是 2602.09722 报告 EEF-relative 优于 World-Relative/Delta 的几何解释。

**命题 2（群增广的覆盖-偏差权衡）** 设训练分布 p，评测分布 q 是 p 经 G_ε 推前（q=(g·)_#p）。若对 g∈G_ε 有 ℓ≤ε，则由第 66 轮命题 1 的 TV 界，评测成功率 ≥ 1−δ−ε（δ 为 p 上的失败率）。所以「有门控的群增广」不是数据技巧，而是**用可测缺陷换覆盖**：ε 越小，可用的群元素越多；ε 随 |g| 增大时，G_ε 自动收缩。粗略地，若 ε(g) 在工作空间边界附近快速上升，则有效增广体积随平移幅度先线性后饱和——这解释了为什么「全空间随机平移」既浪费又可能有害。

**命题 3（残差力代理的可辨识性）** 线性阻抗下 ξ^p=K^{-1}F+η，η 为模型/噪声；K 已知或标定时 F 可辨识到 ‖δK‖/‖K‖ 的相对误差。纯位置控制下 K→∞，ξ^p 被控制器饱和截断为 ξ_sat，只能可靠读出 1[接触] 与方向 sign(F)，不能读大小；若观测噪声为 σ，则方向可辨识要求 ‖ξ^p‖≫σ。故 C13 的正确用法是「方向 + 事件」，而不是「力幅闭环」。

**命题 4（多模态检测的互补性）** 设接触事件与遮挡事件在 (s,c) 平面上的条件分布可分（接触：s 高、c 低但稳定；人手/资产变化：c 低且伴随大范围视觉变化）。则联合检测的贝叶斯错误率低于任一单模态，只要两条件分布不共线。语言先验 l 通过给先验 p(s,c|l) 加权进一步降低错误率；这也是「多模态交互」比「多模态拼接」多出来的那一点。

## 3. 对 v1 的继承与修剪

- **继承**：C01 场景编译器、C02 TwinCal、C03 课程、C06 立体深度、C07 CrossPhys、C10 DryRun 全部保留；C02 的 trust 升级为「任务 × 群元素」双索引。
- **深化**：C05 的动作头改为 EEFrame 相对表示；C04 的扰动原语增加「残差签名」与「跨视图签名」；C08 的残差触发门直接复用 C13 的 s_t，不再另造 conformal 门；C10 的 DryRun 增加 EEFrame/ContactSense 两项接口级回归。
- **新增**：C11 EEFrame（表示层）、C12 GroupBudget（数据层）、C13 ContactSense（接触感知）、C14 CrossView（多模态几何）、C15 ContactSkill（控制/恢复技能）。
- **修剪**：不再把「EE 位姿当 6 维向量直接回归」作为默认；不再假设「接触轴只能靠真机采数据」——C13 提供了一个不用额外硬件的方向信号，但仍需真机验证，不能替代真机数据。
- **不变**：不发明新 VLA 架构；创新集中在接口代数、数据分布与接触控制层。

## 4. 本轮最大风险

**次级风险**：官方数据里的 `action.*_ee_pose` 可能是重算而非真实命令，导致离线标定的残差与线上不一致；群缺陷 ε(g) 只能在小样本上估计；语言先验在 32 个任务上可能退化为任务名记忆；腕部外参随装配/关节变化，跨视图一致性可能假报警。

**一句话最大风险**：整轮押在「低层 EE 控制器足够柔顺、命令-观测残差里真有力/接触信息」这一可观测性假设上——若真实控制器是近刚性位置控制，或接口回传的 EE 位姿是后处理平滑/重算值，那么 C13 只剩噪声级残差（玩具实验里刚度从 400 升到 10000 N/m，残差从 2.5 cm 掉到 0.5 cm，已逼近编码器噪声），接触轴又会退回 v1 的真机数据依赖，而 C11/C12/C13 增加的训练与调度复杂度将成为沉没成本。

## 1. 创新点清单 v2

### 1.1 v1 条目的 v2 摘要（保持原编号）

- **C01 ScenarioForge（场景编译器）**：一份 SceneSpec 双后端（Gazebo 系统在环 / MuJoCo 数据工厂）不变；新增输出 **EE 轨迹**与物体位姿，供 C11/C12 直接消费；每任务 × 五轴网格仍是 C10 预演套件。

- **C04 HumanPerturber（人为扰动）**：扰动原语库不变（推物/抽物/挡相机/碰手臂/换目标位）；新增每条恢复数据同步记录 `(s_t, c_t, 语言阶段)`，供 C15 的 FSM 训练/调参；扰动检测不再只看视觉残差，而是 C13+C14 的联合证据。
- **C05 SimDistill（特权教师 → 接口学生）**：学生动作头改为 C11 的 Δ 输出；教师仍用特权物体位姿；蒸馏损失在 SE(3) 上分解为平移/旋转两项，避免 rpy 直接回归的万向锁。
- **C06 StereoPrior（双目免费深度）**：保持；新增用途——为 C14 提供头部度量深度，并在训练期为跨视图一致性损失提供 GT。
- **C07 CrossPhys（多引擎分歧）**：保持；新增「EE 轨迹分歧」作为分歧度量，和 C11 的表示天然对齐。
- **C08 SalvageChunk（自适应分块/抢救）**：块长逻辑不变（k_long≈24 / k_short≈6，迟滞 8 步）；删除独立 conformal 门，直接复用 C13 的 `s_t` 作为截断触发器；接触态由 C15 接管动作修正。
- **C09 PortFleet（N 端口并发）**：保持；新增「每端口独立的命令环形缓冲」，因为 C13 需要按端口对齐 `u_{t−δ}` 与 `y_t`，状态隔离的要求更强。
- **C10 SimDryRun（预演门）**：三项门扩为五项：接口合法性、延迟、成功率、EEFrame 组合误差、C13 假阳性率；柔性物仍走视频级反事实增广兜底。

### 1.2 IP-C11 EEFrame：接口合法的相对末端位姿代数（★ 本轮押注之一）

- **动机**：接口给的是基座系绝对 EE 目标，但泛化轴在动物体；绝对坐标把「任务」和「物体绝对位置」混在一个回归目标里。官方数据同时有 joint/EE 两套 action，EE 监督免费。
- **差异**：不发明新网络，而是在策略与接口之间加一层严格的 SE(3) 包装：内部预测 `Δ = T_o^{-1} T_a`，外部组合成绝对值；块内以块起点为共同参考，避免逐步 delta 累积；对 `action.pivot` 引起的基座/躯干微漂移天然免疫。与 GEAR-VLA/UMR 的 EEF-relative 思路一致，但针对 UniBot 的「绝对位姿接口」给出合法性证明（左重基不变、块内无累积、接口零改动）。
- **可行性**：高。数据原生有 `action.*_ee_pose_gripper_base`；训练只需换标签；部署 wrapper <20 行。
- **资源**：0 额外数据；训练成本不变；1 人天工程。
- **步骤**：①从 32 个数据集加载 EE 动作/观测；②统一 6D 旋转表示（rpy→旋转矩阵或 6D 连续表示），避免万向锁；③策略输出 Δ chunk；④部署组合并做限幅/平滑；⑤与绝对动作头 A/B（E-C09）。
- **风险**：EE 位姿若是 FK 重算，动作标签含 FK 误差；需与 joint 标签交叉校验（用 `recomputed_ee_valid`）。

### 1.3 IP-C12 GroupBudget：带实测缺陷的 SE(2) 群增广（★ 本轮押注之二）

- **动机**：位置变化是五轴中仿真可解决度最高的一轴；与其随机采物体位姿，不如利用桌面任务的近似对称性，把已有演示整体变换，零接触物理重解。
- **差异**：现有 equivariant policy 直接假设 SO(2)/SE(3) 对称；本方案把「对称性是否成立」变成可测的 `ε_k(g)`，只在 `G_ε` 内增广——**对称性是预算，不是公理**。这直接复用 C02 的重放验收，不另建一套；同时把「位置轴」从「重跑物理仿真」降级为「变换 + 重渲染」。
- **可行性**：中高。需要物体/末端轨迹与可渲染资产（C02 已有）；SE(2) 变换 + 固定相机重渲染即可；无需物理引擎。
- **资源**：渲染 GPU 单卡；每条演示可生成 `N_aug` 条；无真机。
- **步骤**：①对每任务抽 20–50 条演示；②在 g 网格上算 `ε_k(g)`（TwinCal 重放/物体位姿误差或 DryRun 成功率）；③拟合 `G_ε` 边界（可达性 + 缺陷阈值）；④采样 g，变换场景与轨迹、固定相机重渲染；⑤标签用变换后的 Δ，保持 C11 一致。
- **风险**：变换后腕部视角分布变化大；用 ε 门 + 真机 dry-run 校准。

### 1.4 IP-C13 ContactSense：命令-观测残差作为免费接触/力方向通道（★ 本轮押注之三）

- **动机**：v1 承认接触精密/柔性轴仿真帮不上，而接口没有力/触觉。但 `action.ee_pose` 与 `observation.ee_pose` 的差，就是低层跟踪误差；在阻抗控制下它近似 `F/K`，在位置控制下至少是接触事件与方向。
- **差异**：把「传感器缺失」转成「控制器残差可观测」。与 CoPRE 在 G1 上用无接触数据学力矩残差同源，但**只用接口已经回传的 EE 位姿**，不需要读 `tau_est`；与 Beyond Implicit Force 的隐式力线索一致，但用于在线插入/恢复而非离线分析。它不替代真机数据，只替代「力传感器」这一项。
- **可行性**：中高。先用官方 32k 演示离线标定残差分布（本轮已做初步取证：中位 0.8–2.3 cm，随阶段变化）；再用仿真接触标签训 `s_t` 的阈值；真机槽验证。
- **资源**：无额外硬件；离线统计 + 轻量名义残差模型（MLP/线性 AR）。
- **步骤**：①离线对齐 action/observation 帧滞后 δ，计算 `ξ_t`；②只用无接触段训 `ξ̂`（CoPRE 式状态排除）；③定义 `s_t`、`d_t` 与迟滞阈值；④接入 C15；⑤用插入类任务（PlugCharger/PlugInEthernet/SyringeWaterTransfer/Unlock）做消融（E-C11/E-C12）。
- **风险**：纯位置控制下残差饱和/噪声主导；EE 位姿可能重算；帧延迟未知。

### 1.5 IP-C14 CrossView：训练期跨视图几何一致性 + 推理期轻量一致性检测

- **动机**：头部双目与腕部对同一物理点有多视角冗余；但多数队伍把 4 路图直接拼 token，没显式约束几何一致。人手/遮挡/资产变化恰好破坏这种一致性。
- **差异**：训练期用重投影/深度一致性损失把几何注入特征（MVUCF 路线，推理零开销）；推理期只保留一个轻量一致性分数 `c_t`，作为 C13 的互补证据；不新增传感器。与单纯「多相机拼接」相比，它显式定义了模态间的**物理点同一性**。
- **可行性**：高。头部是已矫正立体对（C06），腕部外参可由 C02 标定；一致性损失只需训练期。
- **资源**：训练期加一路辅助损失；推理 <1 ms。
- **步骤**：①用 C02 估计/标定 4 相机内外参；②训练期加头-腕重投影/深度一致性；③推理期算 `c_t` 与阈值；④与 `s_t`、语言 `l` 合成模式路由（C15）；⑤消融：无一致性 vs 有（E-C13）。
- **风险**：腕部外参随关节变化/装配误差；弱纹理/高光导致假不一致。

### 1.6 IP-C15 ContactSkill：接触感知的插入/后撤/重试技能层

- **动机**：有了 C13 的方向与 C14 的遮挡证据，才能真正做「接触时柔顺、失败时抢救」；v1 的 C08 只有块长切换，没有接触级动作。
- **差异**：把恢复从「重抓/后撤」扩展到**方向引导的微搜索**：接触时沿 `−d_t` 退一点、再沿插入轴做小螺旋/锯齿；遮挡时切头视图/换手；人手时先停后撤。所有技能都不改 VLA 主干，只改执行层。
- **可行性**：高（控制层脚本 + 少量参数）；与 C04/C08 合流。
- **资源**：1–2 人周；真机槽验证。
- **步骤**：①技能库（admittance/search/retreat/regrasp/replace）；②FSM 与迟滞（最小驻留 8 步）；③与 C11 的绝对动作组合；④插入类任务 A/B；⑤步骤分评估（E-C12）。
- **风险**：微搜索在窄公差任务上可能卡死；需要超时与退避。

class ContactSense:
    def update(self, obs, cmd_ring, delta):
        y  = se3(obs.ee_pose)
        u  = cmd_ring.at(t - delta)                # 实际执行过的命令，按端口隔离
        xi = log_se3(inv(u) @ y)
        xi_hat = self.nominal(self.hist)           # 只用无接触段训练

        return s, d

class Router:
    def step(self, obs, s, d, c, lang, last_action):
        if self.mode == "nominal" and s > TAU_C:

        elif s > TAU_R and self.stuck(obs):

## 3. 推导与命题（要点）

**命题 A（EEFrame 的严格不变性与零累积）**
对任意 g∈SE(3)，`(gT_o)^{-1}(gT_a)=T_o^{-1}T_a`，故 Δ 对左重基严格不变。块内若每步用 `Δ_i = T_o^{-1}T_{a,i}`（共同参考），则第 i 步的绝对目标为 `T_o Δ_i`，误差不随 i 累积；若用逐步 delta `T_{a,i}=T_{a,i-1}δ_i`，则误差按 i 线性累积。于是 EEFrame 同时获得「基座无关」与「块内稳定」两个性质。

**命题 B（群预算的覆盖-偏差）**
设训练分布 p，评测分布 `q=(g·)_#p`，`g∈G_ε`，且对每个 g 的重放缺陷 ≤ε。由第 66 轮命题 1 的 TV 界，评测成功率 ≥ `1−δ−ε`。因此增广的价值 = 覆盖体积 `|G_ε|` 与缺陷 ε 的乘积效应；当 |g| 增大使 ε 快速上升时，G_ε 收缩，最优增广半径在 `dε/d|g| = ε/|G|` 处。实践含义：**先测 ε(g)，再决定采多大**，不要全局均匀随机。

**命题 C（残差力代理）**
线性阻抗 `F = K e`（e 为末端位移残差），故 `F̂=K e`；`K` 的标定误差按 `‖δK‖/‖K‖` 传播。纯位置控制 `K→∞` 时 e 饱和，只能读出接触事件与方向；若噪声 σ 与残差同量级，则方向也不可靠。由此得到 C13 的使用条件：**只在阻抗/导纳或至少有一定柔顺的控制器上读力幅；纯刚性控制只读事件与方向。**

**命题 D（多模态互补）**
接触事件（s 高、c 稳定）与遮挡/人手事件（c 低、s 未必高）在 (s,c) 上条件分布不同；若两者不共线，联合判决的错误率低于任一单模态。语言先验 l 只改变先验，不改变似然，故只在两模态接近时起作用——这也解释了为什么语言不能替代物理信号，只能做阶段先验。

## 8. 一句话押注

**当前最值得押注：IP-C11 + IP-C13 的「EEFrame + ContactSense」组合——它把接口自带的末端位姿从「6 个回归数」变成「表示代数 + 免费接触通道」，同时命中位置泛化（相对表示）、接触轴（残差方向）与步骤分（接触感知抢救），且官方数据已原生提供 EE 动作/观测，离线即可验证大半；C12 则是把这一表示红利放大到位置轴的数据杠杆。**
