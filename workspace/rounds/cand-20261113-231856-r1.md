# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「UniBot-V1」×「动力学」）

> R69 把不确定性一分为二：aleatoric 走 R68 的 λ_floor，epistemic 交给「流匹配多模态策略 + 看/问/触」主动消解。它默认了三件事：**有对话者**（问句有人回答）、**信息动作是额外的**（可以停下来看/问/触）、**本体动力学是已知且单一的**（流策略只被观测条件化，不被身体条件化）。这三条在 R69 的抽象设定里成立，但在一个真实的单模型多机部署里同时失效。
>
> 本轮灵感 **UniBot-V1** 正好是这样一个真实约束的集合：宇树 UniBot 世界挑战赛的真机桌面操作赛道，单模型完成抓取/放置/双手协调等多任务，评测在 **N 台真实机器人**上随机顺序进行、每台机器人一个固定端口、端口数必须精确等于 N；官方还会记录每一步的**响应延迟及其波动**、以及返回动作的**统计规律性**。也就是说：**没有对话者**；**额外交互会被延迟与动作正则性审计惩罚**；**每台机器人的本体/工位/磨损是一个未被写进任务说明的隐变量**。再叠加官方显式的泛化轴（位置、干扰物、背景、未见物品、人为干扰），真正的「第六轴」是**部署分布/本体动力学**。
>
> 「动力学」则给出本轮的核心判断：**R69 把「多峰」当作任务歧义，但在 UniBot-V1 里，多峰里有一大部分其实是「不同身体/不同动力学」被同一个观测混在了一起**。R69 会去问一个不存在的人；正确的动作是**一边做任务，一边把这台身体的动力学认出来**。
>
> 核心命题：**把不确定性三分（aleatoric / semantic-epistemic / dynamical-epistemic）；在没有对话者、且额外探询被审计的设定下，用「任务等价模态中的双用途动作」——同一个任务动作既完成任务，又最大化对动力学的决策相关信息——来被动辨识本体；用 (r_res, Δa, r_dyn) 三通道做鉴别诊断；用延迟/动作正则化治理保证实时流恒定计算；只有在安全窗口内、且信息价值超过风险时，才允许最小的定向激励。** 命名 **SHIFT-RAS**（System/Hardware Identification for Fleet Transfer — Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我站的这台身体，到底是哪一台？我能不能一边干活一边把它认出来？**」

## 0. 直觉与动机

**灵感 1（UniBot-V1 → 单模型，多身体；最大的隐变量是「我站在哪台机器人上」）**
直觉：UniBot-V1 评测的不是一个模型在一台机器人上的表现，而是**同一个模型在一支机器人舰队上的泛化**。N 台机器人随机顺序评测、每台一个固定端口、每台可能有关节零点/减速器背隙/夹爪摩擦/相机外参/桌面高度/负载的细微差异。训练数据来自少数几台采集机器人，评测却横跨一条**本体与工位分布**。这不是「噪声」，而是一个连续的、可辨识的隐变量。R69 的流策略只被观测条件化；当观测相同而身体不同，它会把两种动力学生成的动作混成一个多峰分布，并把「身体的差异」误读成「任务的歧义」。**误诊是本轮的第一性问题。**

**灵感 2（动力学 → 本体不是噪声，是可辨识的连续隐变量）**
直觉：语义歧义可以「问」掉；动力学歧义只能「试」出来。质量、质心、摩擦、夹爪柔顺、执行器延迟、负载，都会在机器人自己的动作—响应中留下痕迹。关键是：**不需要额外动作**——任务本身的 rollout 就是一次系统辨识实验，只是它的激励方向由任务决定。能辨识的是任务激励张成的子空间；不能辨识的方向必须用鲁棒策略覆盖，而不是假装知道。这是本轮与 R69 最本质的区别：**R69 的信息动作是「额外的」，R70 的信息动作是「任务自带的」。**

**灵感 3（无对话者 + 延迟审计 → R69 的「问」在赛场上失效）**
直觉：UniBot-V1 的接口是 `get_action(obs)` 的单向策略服务，`observation.language` 是整段不变的任务指令，没有人会回答你的问句；评测还会记录每一步的延迟和动作统计规律，任何 K=4 的突发采样、模态切换抖动、异常动作都会进入可信度评估。R69 的 MINT（看/问/触）在这里要么不可用，要么昂贵且危险。**所以 epistemic 的消解通道必须从「主动提问」改为「被动辨识 + 任务内探询」；实时路径必须是恒定计算，而不是按歧义自适应扩张。**

**灵感 4（双用途动作 → 唯一负担得起的信息动作就是任务动作本身）**
直觉：R69 把任务动作 a 与信息动作 g 分开，默认 g 不改变任务状态、只消耗预算。但在真机上，任何「为了看清楚而停一下/转一下/碰一下」都改变世界、消耗时间、可能违规。更聪明的做法是：**在任务等价的多个模态里，挑一个既完成任务、又最能暴露身体动力学的模态。** 例如「从左侧绕」和「从右侧绕」任务价值几乎相同，但对某一侧关节的负载/摩擦激励不同；选择信息量更大的那一侧，等于**把辨识实验藏在任务里**。这不是额外的探索，而是**双用途动作**（dual-purpose action）。

**灵感 5（三通道 → 标定、策略似然、动力学残差；错诊比不确定更危险）**
直觉：R68 只测传感器残差 r_res，会被慢变标定吸收；R69 加了动作似然 Δa，能测「策略是否被条件在错的世界」，但一个动力学不可行的动作完全可以又平滑、又高似然。于是需要第三条独立通道：**执行动作后的动力学预测误差 r_dyn**（含能量一致性/约束残差）。三元组 (r_res, Δa, r_dyn) 做**鉴别诊断**：传感器漂移、策略/模型漂移、本体动力学漂移是三种不同的病，不能用同一个 λ 糊过去。R70 的第二意见不是「再来一条」，而是**让三条通道各自指向不同的病因**。

**灵感 6（严格包含 → R69 是「同质舰队 + 动力学已知」的边界）**
直觉：如果舰队同质、d 已知、U_dyn=0，SHIFT 必须逐指令退化为 R69（MINT 因无对话者而退化为「不交互」），再进一步退化为 R68 的纯保守。这是本轮的理论纪律：**新层必须是旧层的严格泛化，而不是并列替代**。否则每加一层就多一个需要独立信任的黑箱——而本轮的风险恰恰是「自信地辨识出错误的物理」。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（SHIFT-RAS 总览）** SHIFT-RAS = (LEC, PSID, TED, DDA, SDX, DPE, LRG, MEG, FHP, RAS-WM‡)。五不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **端口隔离**：每个端口 i 维护独立的动力学后验 q_i(d)，共享先验 p_0(d) 只读；跨端口不得写共享状态；`reset()` 清空 episode 内任务状态，但同一端口对应的同一台机器人的长期动力学后验可以保留（若观测显示端口换了机器人，则强制重置 q_i）；
(iii) **延迟/正则化不变**：单位 `get_action` 的计算量有硬上界，默认 K=1、不做自适应 K 突发；模态只在 chunk 边界切换；动作块满足平滑性约束；
(iv) **证据纪律**：单窗口/单源不得认证动力学更新；需 k 个正交证据一致或高置信先验主导；
(v) **严格包含**：U_dyn=0、舰队同质或 β=0 时，逐指令退化为 FLUID-RAS（其无对话者分支）；MEG=0 时退化为 R69 保守分支，再退化为 R68。

**定义 311（舰队隐动力学与层级先验 FHP）** 舰队含 N 台机器人，机器人 i 的动力学参数 d_i ∈ 𝒟 ⊂ ℝ^{n_d}（连杆质量/质心、关节摩擦/背隙、夹爪柔顺、执行器增益/延迟、负载、接触参数等）。共享先验 p_0(d) 在离线阶段由多机数据/物理目录学习，运行时只读；每端口维护后验 q_{i,t}(d) ∝ p_0(d) · Π_{τ≤t} p(y_{i,τ} | d, data_{i,τ})。层级结构：p_0 提供冷启动与跨机迁移，q_i 只吸收本端口数据。**跨端口可写状态为零**。

**定义 312（潜在本体上下文 LEC）** 从本端口观测历史提取廉价上下文 e_i = E_ψ(o_{i,0:t})（关节状态、末端位姿、夹爪开度、下身 15 维、腕部图像、语言指令），作为统一流策略的动力学条件嵌入；同时用 PSID 维护结构化后验 q_i(d)。e_i 是 q_i 的摊销充分统计近似，二者共同进入 UDF（定义 313）。端口隔离：e_i 只由端口 i 的观测更新。

**定义 313（统一动力学条件流 UDF）** 在 R69 的 FMP 上增加动力学条件：x_1 = ξ_{t:t+H}，x_0 ~ 𝒩(0,I)，x_s=(1−s)x_0+s x_1，速度场 v_θ(x_s,s | z_t, e_i)。训练目标 L_UDF = E_{d~p_0, s, x_0, x_1}‖v_θ(x_s,s|z_t,E_ψ(d)) − (x_1−x_0)‖²。推理时用 q_i 采样/鲁棒边际化；**不重训 trunk，只加 FiLM 适配器与动力学编码器**，保持 R68/R69 的零重复训练。

**定义 314（被动结构化系统辨识 PSID）** 结构化动力学模型 M_d：x_{t+1} = f(x_t,u_t;d) + r_φ(x_t,u_t) + ε，其中 f 为刚体/拉格朗日已知结构，d 为未知参数，r_φ 为小幅学习残差。给定任务自然 rollout D_i={(x,u,x',τ,contact)}，用递归贝叶斯/集合卡尔曼更新 q_i。计算 Fisher 信息 F_i = E[∇_d log p(y|d) ∇_dᵀ log p(y|d)] 与有效秩 r_i；**任务激励子空间** S_i = range(F_i)。S_i 之外的方向被动不可辨识；支持分 s_i = p_0(d̂_i)/p_0,max。

**定义 315（三分不确定性 TED）**
- **U_ale** = Σ_k ŵ_k tr(Σ_k)（R69 模态内、不可约噪声）；
- **U_sem** = H_mode · g(Δ_min)（R69 模态间、任务/动作歧义；无对话者时只能靠观测被动降低）；
- **U_dyn** = 决策相关的动力学不确定性，定义为 EVPI：
  U_dyn = min_a E_{q_i(d)}[L(a,d)] − E_{q_i(d)}[min_a L(a,d)] ≥ 0；
  廉价代理：U_dyn ≈ tr(Cov_{q_i}[a^*(d)]) / scale，或 E[‖J_d a^*(d)‖²]。
**关键**：U_dyn ≠ H(q_i(d))。参数熵大但决策无关（例如不可观测的连杆惯量）不应触发探询；三分量不做简单加和，各自进入不同通道（定义 322）。

**定义 316（任务等价模态与双用途动作 DDA）** 设 R69 流采样得到模态 {m_k}，任务价值 V_k = −E[L_task | m_k]。定义 ε-等价集 ℳ_ε = {k : V_k ≥ max_j V_j − ε}。对每个候选模态估计其**动力学信息价值** DVoI_k（定义 317）与风险 R_k。选择
  k* = argmax_{k∈ℳ_ε} [ V_k + β·DVoI_k − γ·R_k ]，
  s.t. 安全认证、延迟/正则化预算、动作块平滑。β=0 时退化为 R69 的任务最优模态选择。**信息不是来自额外的 g，而是来自被选中的任务动作 a 本身。**

**定义 317（决策相关动力学 VoI，DVoI）** 对候选轨迹/模态 ξ（不是额外信息动作），
  DVoI(ξ) = E_{y~p(·|ξ,q_i)}[ min_a E_{q_i(d|y)} L(a,d) ] − min_a E_{q_i(d)} L(a,d)，
即**期望贝叶斯风险下降**（EVSI）。可选信息量而非参数熵：只有会改变未来最优动作的 d 方向才值钱。若 DVoI ≤ 0，则无信息偏好。特例：当隐变量退化为离散模态 M、观测退化为一次语义回答 y 时，DVoI 与 R69 的 MINT 熵型 VoI 在 log-loss 下同构；因此 R69 的 MINT 是本定义在「有对话者」边界上的特例。

**定义 318（可选安全定向激励 SDX）** 仅当被动 DVoI < τ_info、且存在**安全窗口**（准静态/稳定接触、安全集裕度 ≥ m_0、任务允许、预算未超）时，才允许一个最小的定向激励 g_dyn。约束：
(i) 过 C-RAS-WM 前缀认证；
(ii) 轨迹在不变安全集 𝒮_safe 内，T 步内回到基线；
(iii) 能量/无源性预算 ∫uᵀẋ dt ≤ E_probe；
(iv) 接触力 ≤ f_max、摩擦锥裕度、无滑移；
(v) 动作 jerk/TV 不越 LRG 界。
在约束下最大化 DVoI(g_dyn)；无可行解则**不探询**。SDX 是最后手段，不是主通道。

**定义 319（动力学预测误差 DPE）** 对已执行动作与观测到的下一步：
  r_dyn = ‖x_{t+1} − f(x_t,u_t;d̂_i) − r_φ‖²_{Σ^{-1}}，
  能量一致性 e_E = |ΔE − W_ext| / E_scale，
  约束残差 c_dyn（关节限位、接触非穿透、摩擦锥）。
  z_dyn = normalize(max(r_dyn, e_E, c_dyn))；Δ_dyn = z_dyn(d̂_i) − z_dyn(d_nom)。
**三通道鉴别诊断表**：

| r_res | Δa（FMA） | z_dyn（DPE） | 诊断 |
|---|---|---|---|
| ↑ | ≈ | ≈ | 传感器/标定漂移（R68 通道） |
| ≈ | ↑ | ≈ | 策略 OOD / 动作分布漂移（R69 通道） |
| ≈ | ≈ | ↑ | 本体动力学/工位漂移（R70 通道） |
| ↑ | ↑ | ↑ | 复合故障：退最保守 |

**定义 320（延迟与动作正则化治理 LRG）** 每个 `get_action` 的固定计算预算 B_c：默认 K=1、模态枚举 ≤4、SID 更新按固定周期摊销（异步、非关键路径）；不做自适应 K 突发。动作块在 chunk 边界做线性/样条混合，满足 ‖a_{t+1}−a_t‖ ≤ δ_a、TV(a) ≤ δ_TV、jerk ≤ δ_j；模态切换只在 chunk 边界发生。定义**延迟不变性**：p99 延迟 ≤ p99_nominal + δ_lat；**正则性**：动作统计量（均值/方差/极值/自相关）在 nominal 包络内。LRG 直接回应 UniBot-V1 对延迟与动作规律的审计。

**定义 321（模型证据与支持门 MEG）** 支持分 s_i（d̂_i 在先验支持集内的密度）、模型证据差 ΔM = log p(D_i|M_struct) − log p(D_i|M_res)（结构化物理模型 vs 残差/非参数模型）、留出增益 HG = z_dyn^{holdout}(d̂_i) − z_dyn^{holdout}(d_nom)。门控 MEG_i = 1 ⇔ s_i ≥ s_min ∧ ΔM ≥ 0 ∧ HG > 0。MEG=0 ⇒ **禁止自适应与保守解除**：U_dyn 视为模型类不确定性，直接走 R69/R68 保守。

**定义 322（候选更新与证据纪律）** 接受一次动力学更新/消解需同时满足：
(i) 留出 DPE 改善；
(ii) 能量一致性通过；
(iii) MEG=1；
(iv) 至少两个时间窗或两个任务激励方向一致（有效秩 ≥ 2），或校准良好的先验占主导。
单窗口/单源永不认证。该纪律把 R69 的「k 个正交回答一致」替换为「k 个正交物理证据一致」。

**定义 323（三级退避与分辨率红利）**
- **Level 0（已辨识且可信）**：q_i 在任务相关子空间集中，使用 d̂_i/小鲁棒集；λ = λ_floor(U_ale)（获得**动力学分辨率红利**）；DDA 用 β>0。
- **Level 1（支持内但不可辨识/预算不足）**：对 q_i 做 CVaR/Wasserstein 鲁棒动作选择；λ = λ_floor(U_ale + 未消解 U_sem + κ·U_dyn)（κ 计入模型风险）；DDA 仍可用 DVoI，但**不解除** R69 的保守下界。
- **Level 2（MEG=0/支持外/探询不安全/端口疑似换机）**：**关闭 SHIFT 层**，逐指令等于 R69 的无对话者分支（MINT 退化为不交互），U_dyn 并入 λ floor；再退化为 R68。
严格包含：U_dyn=0 或 Level 2 时，动作与 R69 边界逐指令一致；安全侧永不弱于 R69。

**定义 324（统一证书 J_SHIFT）** J_SHIFT = (J_FLUID, port_id_hash, q_i_cov/effective_rank, support_score, model_evidence_gap, dpe_holdout, energy_ledger, latency_p99, action_regularity, isolation_hash, shift_ver)。Valid ⇔ Valid(J_FLUID) ∧ 端口隔离成立 ∧ 任何保守解除都有 MEG=1 ∧ 证据纪律满足 ∧ 延迟/正则化在包络内。

**定义 325（参与式审计 VQAuditor-F）** 审计：端口是否泄漏、动力学更新是否单源、DDA 是否为了信息牺牲了过多任务价值、SDX 是否越界、延迟/动作是否异常、MEG 是否被绕过。结论回灌 AuditBuf，作为下一轮 β/γ/探询成本的先验。

**定义 326（干扰集与「第六轴」契约 AIC-SHIFT）** ℰ_SHIFT = ℰ_FLUID × ℰ_fleet，ℰ_fleet = {本体硬件差异、关节零点/背隙、夹爪摩擦、相机外参、负载/摩擦变化、执行器延迟/退化、端口并发/串扰、延迟尖峰、舰队数据投毒、对抗性扰动}。定义**第六轴** s_shift 为留出机器人/工位上的成功率与步骤分，并定义 SHIFT 的净收益 ΔS_shift = S(SHIFT) − S(base)，扣除延迟/正则化惩罚；所有实验围绕这个可审计的量报告。

## 2. 关键算法骨架

```python
# IP-264/265 FHP + LEC + PSID：每端口独立，共享先验只读
class FleetPortState:
    def __init__(self, prior_p0):
        self.q_d   = prior_p0.copy()      # 每端口动力学后验
        self.e     = None                 # 潜在本体上下文
        self.buf   = []                   # 本端口自然 rollout
        self.reset_episode()

    def reset_episode(self):
        self.ep_task = []                 # 只清 episode 任务状态
        # 长期 q_d 保留；若端口换机检测触发则整体重置

    def absorb(self, o, a, o_next):
        self.buf.append((o, a, o_next))
        self.q_d = psid.update(self.q_d, self.buf[-1])     # 异步/摊销
        self.e   = lec.encode(self.buf)                    # 廉价上下文

# IP-266/267 TED + DDA：没有额外 g，信息藏在任务模态里
def select_dual_purpose_mode(modes, q_d, beta, gamma):
    V = [task_value(m) for m in modes]
    eps_set = [k for k in range(len(modes)) if V[k] >= max(V) - EPS]
    best = None
    for k in eps_set:
        dvoi = expected_bayes_risk_reduction(modes[k], q_d)   # 定义 317
        risk = certified_risk(modes[k])
        score = V[k] + beta * dvoi - gamma * risk
        if best is None or score > best.score:
            best = (k, score, dvoi, risk)
    return best

# IP-268 SDX：只在安全窗口、且被动信息不足时使用
def maybe_excite(q_d, obs, budget):
    if passive_dvoi(q_d) >= TAU_INFO: return None
    if not safe_window(obs):          return None
    g = argmax_dvoi(safe_excitation_candidates(obs), q_d)
    return g if sdx_certify(g, obs, budget) else None

# IP-269 DPE：三通道鉴别诊断
def diagnose(r_res, delta_a, dpe_score):
    if dpe_score > TAU_DYN and r_res < TAU_RES and delta_a < TAU_A:
        return "dynamics_shift"       # R70 通道
    if delta_a > TAU_A and dpe_score < TAU_DYN:
        return "policy_ood"           # R69 通道
    if r_res > TAU_RES and dpe_score < TAU_DYN:
        return "calibration"          # R68 通道
    return "compound"                 # 退最保守

# IP-270-274 主闭环：恒定计算，异步辨识，chunk 边界决策
def SHIFT_round(M, obs, port):
    s = M.ports[port]                                  # 严格端口隔离
    z = M.trunk(obs); e = s.e                          # R69 trunk + 本体上下文
    # 1) 固定 K=1 的流采样（不做 K=4 突发）
    samples = M.udf.sample(obs, K=1, q_d=s.q_d)
    U_ale, U_sem, modes = M.ted.decompose(samples, s.q_d)
    # 2) 决策相关动力学不确定性（不是参数熵）
    U_dyn = M.ted.dynamics_uncertainty(s.q_d, modes)
    # 3) 双用途模态选择：任务 + 信息 − 风险
    k, _, dvoi, risk = select_dual_purpose_mode(modes, s.q_d, M.beta, M.gamma)
    a = modes[k].a
    # 4) 仅安全窗口内的可选定向激励；默认 None
    g = maybe_excite(s.q_d, obs, M.budget)
    if g is not None: a = s.sdx.merge(a, g)
    # 5) 延迟/正则化治理：chunk 边界平滑，恒定计算
    a = M.lrg.shape(a, s.last_a)
    # 6) 证书与异步审计（非关键路径）
    M.vqa_f.submit_async(port, k, dvoi, risk, U_dyn, M.last_latency)
    return a

def SHIFT_absorb_async(M, port, o, a, o_next):
    s = M.ports[port]
    s.absorb(o, a, o_next)
    z_dyn = M.dpe.score(s.q_d.map, o, a, o_next)
    diag  = diagnose(M.last_r_res, M.last_delta_a, z_dyn)
    trusted = M.meg.trust(s.q_d, s.buf)
    if diag == "dynamics_shift" and trusted and M.evidence.ok(s.buf):
        s.q_d = M.psid.update(s.q_d, s.buf[-1])        # Level 0 才允许解除
    elif not trusted:
        s.q_d = M.fhp.reset_to_prior(s.q_d)            # Level 2：不许自信错配
```

## 3. 推导

**引理 19（无对话者下的信息预算坍缩）** 在 UniBot-V1 的接口下，语义信息动作集 𝒜_info^sem = ∅（language 是单向指令，没有回答通道），任何额外的看/停/碰都要计入延迟、位移、接触与正则化成本，且不产生 R69 意义上的「回答」观测。因此 R69 的 MINT 在该设定下退化为「不交互」，其熵型 VoI 对 U_sem 的期望增益 ≤ 0（除非该动作同时是任务动作）。**系：唯一还有正 VoI 的通道是动力学；而动力学信息必须依附于任务动作。** 这就把 R69 的「额外探询」逼成了 R70 的「任务内探询」。

**引理 20（双用途动作的 Pareto 条件）** 设模态 k 相对任务最优模态的任务损失为 ΔV_k = max_j V_j − V_k ≥ 0，其信息增益为 DVoI_k。选择 k 而非任务最优的净收益为
  ΔNet(k) = DVoI_k − ΔV_k − γ(R_k − R_0)。
故只有在 **DVoI_k > ΔV_k + γΔR_k** 时才值得选信息量更大的模态。因 DVoI ≤ 决策敏感度×后验可约量，若任务激励子空间 S_i 很小或 d 对最优动作几乎无影响（敏感度低），则 DVoI→0，DDA 自动退回任务最优。**系：双用途动作不是「为了探索而牺牲任务」，而是一个有明确盈亏平衡点的选择；这给出了 β 的可解释标定。**

**引理 21（被动可辨识子空间与不可约方向）** 在结构化模型下，Fisher 信息 F_i 的秩 r_i 等于任务 rollout 能激励的动力学方向数。对任意 u ∉ S_i = range(F_i)，Cramér–Rao 下界不随样本数增加而收紧（该方向无信息），故 q_i 在 S_i^⊥ 上的方差被动不可约。**系：SHIFT 只能声称「辨识了任务相关子空间」；其余方向必须由 Level 1 的鲁棒策略覆盖，或由 SDX 在安全窗口内主动激励。任何「全参数已辨识」的声明在无激励时都是伪自信。** 这是本轮与「在线辨识一切」的乐观叙事划清界限的关键。

**引理 22（三通道的可分离性）** 在非共线条件下，三元组 (r_res, Δa, z_dyn) 的联合分布可分离四类状态（定义 319 表）。存在构造性例子：一个动作在策略密度下高似然（Δa 低）、传感器残差也被标定吸收（r_res 低），但它要求关节输出超过真实力矩上限，故 z_dyn 高。**系：R68+R69 的两通道都存在「自信但物理不可行」的盲区；第三通道不是冗余，而是补一个不可被前两条通道吸收的物理可行性维度。**

**定理 18（SHIFT 严格包含 FLUID-RAS 与 R68）** 在与 R69 相同的可用信息动作集合下（存在对话者），把 β=0、U_dyn=0、舰队同质（d 固定）代入 SHIFT，DDA 退化为 R69 的模态选择，LEC/PSID/DPE/LRG/MEG 只作为不改变动作的被动观测器，故逐指令等于 FLUID-RAS；在 UniBot-V1 无对话者设定下，FLUID 的 MINT 退化为不交互，SHIFT 的 Level 2 与之逐指令相等。U_dyn=0 时 Level 0 与 Level 2 都不解除 R69 的安全下界；再令 MEG≡0 即得 R68 边界。因此**安全侧不做任何让步，效率侧只在可辨识且可信时获得动力学分辨率红利。**

**定理 19（延迟/正则化下的无突变）** LRG 给每个 `get_action` 固定计算上界 B_c，模态切换只在 chunk 边界发生，动作块经平滑混合且满足 TV/jerk 界；q_i 的后验更新是异步、非关键路径的，且其对动作映射的影响被 β/κ 连续调制。因此从任意 Level 切换到 Level 2 时，λ 单调不降、动作在切换点的跳跃 ≤ δ_a，p99 延迟 ≤ p99_nominal + δ_lat，动作统计量留在 nominal 包络内。R68 的提交/换装不变式与 PI-Sigma 前缀调度保持不变，故控制连续、无突变。

**定理 20（误配与跨端口泄漏上界）** 在 MEG 门控、k 源证据纪律与端口隔离下，发生「自信地辨识出错误 d 并据此解除保守」的概率满足
  P(wrong ∧ relaxed) ≤ δ_model · ρ^{k−1} + ε_support，
其中 δ_model 为模型类先验错误率，ρ<1 为各证据源错误的相关性，ε_support 为支持分估计误差。若 s_i < s_min，MEG=0，解除概率为 0；跨端口可写状态为零，故串扰泄漏 = 0。**系：主动辨识的最大危险不是「辨识不出」，而是「在错误模型类里辨识得很自信」；MEG 与留出验证把这种自信关在 Level 2 之外。**

**推论 1（第六轴的净收益上界）** SHIFT 相对基线的期望收益满足
  ΔS_shift ≤ c_1·dim(S_i)/n_d·(1 − e^{−DVoI}) − c_2·(latency/regularity penalty)，
即在任务激励子空间大、动力学对决策敏感、且延迟惩罚小的场景收益最大；当任务几乎不激励动力学（dim(S_i) 小）时，收益趋零但**不会为负**（Level 2 精确回退）。这给出了可证伪的实验预测：收益应随「任务激励秩」与「跨机动力学差异」单调增加。

| `J_SHIFT = (J_FLUID, port_id_hash, q_i_cov/rank, support, ΔM, dpe_holdout, energy, latency_p99, regularity, isolation, shift_ver)` | 证书 |
| `ΔS_shift` | 第六轴净收益（扣延迟/正则惩罚） |

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** SHIFT-RAS = (LEC, PSID, TED, DDA, SDX, DPE, LRG, MEG, FHP, RAS-WM‡)；继承实时流零学习写操作；**端口隔离**（q_i 独立、共享先验只读、跨端口可写状态为零）；**延迟/正则化不变**（固定 K=1、chunk 边界切换、动作平滑）；**证据纪律**（单窗口/单源不认证）；**严格包含**（U_dyn=0/同质/β=0 退 FLUID，MEG=0 退 R69，再退 R68）。

**定义 311–313（舰队先验、本体上下文与统一动力学流）** `d_i` 为机器人 i 的动力学参数；`p_0` 离线学习、运行时只读；`q_i ∝ p_0·Π p(y|d)`。`e_i=E_ψ(o_{i,0:t})` 作为流策略的动力学条件：`v_θ(x_s,s|z_t,e_i)`，只加 FiLM 适配器与动力学编码器，不重训 trunk。

**定义 314（PSID）** `x_{t+1}=f(x_t,u_t;d)+r_φ+ε`；`f` 为刚体/拉格朗日已知结构，`d` 未知，`r_φ` 小幅残差。用任务自然 rollout 递归更新 `q_i`；算 Fisher `F_i` 与有效秩 `r_i`，`S_i=range(F_i)` 为任务激励子空间；S_i 之外被动不可辨识。

**定义 315（TED 三分）** `U_ale=Σŵ trΣ`；`U_sem=H_mode·g(Δ_min)`；`U_dyn=EVPI=min_a E_q[L]−E_q[min_a L]`。关键：`U_dyn ≠ H(q_i(d))`；参数熵大但决策无关的方向不应触发探询；三分量分通道处置。

**定义 316–317（DDA 与 DVoI）** 在 `ℳ_ε` 中选 `k*=argmax[V_k+β·DVoI_k−γ·R_k]`，s.t. 安全/延迟/正则；`β=0` 退 R69。`DVoI(ξ)=E_y[min_a E_{q(d|y)}L]−min_a E_q[L]` 为期望贝叶斯风险下降；只有当信息会改变未来最优动作时才值钱。离散模态 + 语义回答的特例与 R69 的 MINT 熵型 VoI 同构。

**定义 318（SDX）** 仅当被动 DVoI<τ 且存在安全窗口时，才允许最小定向激励；约束为 C-RAS-WM 认证、不变安全集、能量/无源预算、接触力/摩擦锥、jerk/TV 界；在约束下最大化 DVoI；无可行解则不探询。

**定义 319（DPE 三通道）** `r_dyn=‖x'−f(x,u;d̂)−r_φ‖²`，`e_E=|ΔE−W_ext|/E_scale`，`c_dyn` 为约束残差；`z_dyn=normalize(max(...))`。诊断表：`(r_res↑,Δa≈,z_dyn≈)`=标定；`(≈,Δa↑,≈)`=策略 OOD；`(≈,≈,z_dyn↑)`=本体动力学；全↑=复合故障，退最保守。

**定义 320（LRG）** 固定计算预算 B_c，默认 K=1、模态枚举 ≤4、SID 更新异步摊销；模态只在 chunk 边界切换；`‖a_{t+1}−a_t‖≤δ_a`、`TV≤δ_TV`、`jerk≤δ_j`；p99 延迟 ≤ nominal + δ_lat；动作统计量留在 nominal 包络。

**定义 321–322（MEG 与证据纪律）** `MEG=1 ⇔ s_i≥s_min ∧ ΔM≥0 ∧ HG>0`；MEG=0 ⇒ 禁止自适应与保守解除。接受动力学更新需：留出 DPE 改善 ∧ 能量一致性 ∧ MEG=1 ∧ 至少两时间窗/两激励方向一致（或校准先验主导）。

**定义 323（三级退避）** Level 0：q_i 集中在任务相关子空间，`λ=λ_floor(U_ale)`（动力学分辨率红利），DDA 用 β>0；Level 1：支持内但不可辨识/预算不足，CVaR/Wasserstein 鲁棒，`λ=λ_floor(U_ale+U_sem+κU_dyn)`；Level 2：MEG=0/支持外/探询不安全/疑似换机，关闭 SHIFT 层，逐指令等于 R69 无对话者分支，再退 R68。

**定义 324–326（证书、审计、干扰集与第六轴）** `J_SHIFT` 并入端口哈希、q_i 协方差/秩、支持分、模型证据差、留出 DPE、能量账本、p99 延迟、动作正则性、隔离哈希。VQAuditor-F 审端口泄漏/单源自适应/DDA 权衡/SDX 越界/延迟异常。`ℰ_SHIFT=ℰ_FLUID×ℰ_fleet`（硬件差异、零点/背隙、夹爪摩擦、外参、负载/摩擦、执行器退化、端口并发、延迟尖峰、舰队数据投毒、对抗扰动）。定义第六轴 `s_shift` 与 `ΔS_shift` 为可审计目标。

## 3. 关键算法伪代码

```python
# IP-264/265 FHP + LEC + PSID：每端口独立，共享先验只读
class FleetPortState:
    def __init__(self, prior_p0):
        self.q_d = prior_p0.copy(); self.e = None; self.buf = []
        self.reset_episode()
    def reset_episode(self):
        self.ep_task = []                  # 只清 episode 任务态；长期 q_d 保留
        # 若端口换机检测触发，则整体重置 q_d
    def absorb(self, o, a, o_next):
        self.buf.append((o, a, o_next))
        self.q_d = psid.update(self.q_d, self.buf[-1])   # 异步/摊销
        self.e   = lec.encode(self.buf)

# IP-267/268 TED + DDA：没有额外 g，信息藏在任务模态里
def select_dual_purpose_mode(modes, q_d, beta, gamma):
    V = [task_value(m) for m in modes]
    eps_set = [k for k in range(len(modes)) if V[k] >= max(V) - EPS]
    best = None
    for k in eps_set:
        dvoi = expected_bayes_risk_reduction(modes[k], q_d)   # EVSI
        risk = certified_risk(modes[k])
        score = V[k] + beta * dvoi - gamma * risk
        if best is None or score > best.score: best = (k, score, dvoi, risk)
    return best

# IP-269 SDX：只在安全窗口、被动信息不足时使用
def maybe_excite(q_d, obs, budget):
    if passive_dvoi(q_d) >= TAU_INFO: return None
    if not safe_window(obs):          return None
    g = argmax_dvoi(safe_excitation_candidates(obs), q_d)
    return g if sdx_certify(g, obs, budget) else None

# IP-270 DPE：三通道鉴别诊断
def diagnose(r_res, delta_a, dpe_score):
    if dpe_score > TAU_DYN and r_res < TAU_RES and delta_a < TAU_A: return "dynamics_shift"
    if delta_a  > TAU_A  and dpe_score < TAU_DYN:                  return "policy_ood"
    if r_res     > TAU_RES and dpe_score < TAU_DYN:                return "calibration"
    return "compound"

# IP-271-274 主闭环：恒定计算，异步辨识，chunk 边界决策
def SHIFT_round(M, obs, port):
    s = M.ports[port]                                  # 严格端口隔离
    z = M.trunk(obs); e = s.e
    samples = M.udf.sample(obs, K=1, q_d=s.q_d)        # 固定 K=1，无 K=4 突发
    U_ale, U_sem, modes = M.ted.decompose(samples, s.q_d)
    U_dyn = M.ted.dynamics_uncertainty(s.q_d, modes)   # EVPI，不是参数熵
    k, _, dvoi, risk = select_dual_purpose_mode(modes, s.q_d, M.beta, M.gamma)
    a = modes[k].a
    g = maybe_excite(s.q_d, obs, M.budget)             # 默认 None
    if g is not None: a = s.sdx.merge(a, g)
    a = M.lrg.shape(a, s.last_a)                       # chunk 边界平滑
    M.vqa_f.submit_async(port, k, dvoi, risk, U_dyn, M.last_latency)
    return a

def SHIFT_absorb_async(M, port, o, a, o_next):
    s = M.ports[port]; s.absorb(o, a, o_next)
    z_dyn = M.dpe.score(s.q_d.map, o, a, o_next)
    diag  = diagnose(M.last_r_res, M.last_delta_a, z_dyn)
    trusted = M.meg.trust(s.q_d, s.buf)
    if diag == "dynamics_shift" and trusted and M.evidence.ok(s.buf):
        s.q_d = M.psid.update(s.q_d, s.buf[-1])        # Level 0 才允许解除
    elif not trusted:
        s.q_d = M.fhp.reset_to_prior(s.q_d)            # Level 2：不许自信错配
```

## 4. 推导

**引理 19（无对话者下的信息预算坍缩）** UniBot-V1 的 language 是单向指令，语义信息动作集为空；额外动作要计入延迟/位移/接触/正则化成本且不产生 R69 意义上的回答观测。故 MINT 退化为不交互，唯一正 VoI 通道是动力学，且必须依附任务动作。

**引理 20（双用途动作的 Pareto 条件）** 相对任务最优的损失 `ΔV_k`、信息增益 `DVoI_k`、风险差 `ΔR_k`，选信息模态的净收益 `ΔNet=DVoI_k−ΔV_k−γΔR_k`；仅当 `DVoI_k>ΔV_k+γΔR_k` 才值得。`DVoI` 随任务激励秩与决策敏感度下降而趋零，DDA 自动退回任务最优。

**引理 21（被动可辨识子空间）** Fisher 信息 `F_i` 的秩 `r_i` 等于任务 rollout 能激励的动力学方向数；对 `u∉S_i=range(F_i)`，Cramér–Rao 下界不随样本收紧，方差被动不可约。故 SHIFT 只能声称辨识了任务相关子空间，其余必须鲁棒覆盖或由 SDX 主动激励。

**引理 22（三通道可分离性）** 非共线条件下 `(r_res,Δa,z_dyn)` 可分离四类状态。存在构造性例子：动作在策略密度下高似然、标定残差也被吸收，但其力矩需求超过真实上限，故 `z_dyn` 高——R68+R69 两通道存在「自信但物理不可行」的盲区。

**定理 18（严格包含 FLUID-RAS 与 R68）** 相同信息动作集合下令 `β=0, U_dyn=0, d` 固定，DDA 退 R69；LEC/PSID/DPE/LRG/MEG 只作不改变动作的被动观测器 ⇒ 逐指令等于 FLUID。无对话者设定下 FLUID 的 MINT 退化为不交互，SHIFT 的 Level 2 与之相等；`MEG≡0` 即 R68 边界。安全侧不让步。

**定理 19（延迟/正则化无突变）** LRG 给每步固定计算上界，模态只在 chunk 边界切换，动作块满足 TV/jerk 界；q_i 异步更新且对动作映射连续调制。切换到 Level 2 时 λ 单调不降、跳跃 ≤δ_a、p99 延迟 ≤ nominal+δ_lat、动作统计量在 nominal 包络内；R68 的提交/换装与 PI-Sigma 不变式保持。

**定理 20（误配与跨端口泄漏上界）** MEG 门控 + k 源证据 + 端口隔离下，
`P(wrong ∧ relaxed) ≤ δ_model·ρ^{k−1}+ε_support`；`s_i<s_min ⇒ MEG=0 ⇒ 解除概率=0`；跨端口可写状态为零 ⇒ 串扰泄漏=0。

**推论 1（第六轴净收益上界）** `ΔS_shift ≤ c_1·dim(S_i)/n_d·(1−e^{−DVoI}) − c_2·(延迟/正则惩罚)`；收益随任务激励秩与跨机动力学差异单调增加；激励不足时收益趋零但不为负（Level 2 精确回退）。

## 7. 本轮最大风险

**一句话**：SHIFT-RAS 的全部收益押在「任务自身的 rollout 足以辨识出对决策有用的动力学子空间，且 UniBot-V1 的动力学先验没有把真实本体排除在支持集之外」这一前提上——**若任务激励不足，收益归零（但可安全回退）；若模型类错了，系统会在错误的物理里自信地拟合出一个 d̂，并据此解除保守，把 R69 的「诚实的歧义」升级成「被错误的物理验证过的错误」，再经由单模型舰队把同一个错误复制到 N 台机器人上**。
