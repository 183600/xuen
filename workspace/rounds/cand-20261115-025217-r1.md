# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环第 3 轮；本轮灵感：「续航能力」×「强化学习训练」）

> R69 教会闭环「去问」：把不确定性拆成 aleatoric/epistemic，用流匹配策略给出有形状的歧义，用注视/探针/问句去主动消解。但它悄悄假设了一件从未被检验的事——**问，是付得起的**。R69 的交互预算是一个独立的、松散的「次数」约束（≤1 次/单位时间、位移 ≤ ε_g、成本 ≤ c_max），仿佛能量、算力、时间与信息是四本互不相干的账。真实续航受限的具身体不是这样：`K=4` 的多采样、FMA 的似然回放、一次探针、一句追问，全部从**同一块正在减少的电池**里扣。当电量是有限的，今天为了消歧花掉的电，就是明天**回不去、停不下、救不了**的风险。
>
> 更关键的是：R69 的 VoI 是**短视（myopic）**的——只问「这一步问了值不值」，不问「花了这份电，还够不够走完剩下的路」。于是它会为了一个漂亮的答案，花掉回程的油。
>
> 本轮两个灵感正好补上这两块：
> - **续航能力**把「能量」变成一等状态：每次交互/采样/探询都有能量代价，能量约束的对偶变量就是「电的边际价值」μ_t；VoI 必须减去 μ_t 的机会成本，得到**续航修正的信息价值 E-VoI**。
> - **强化学习训练**把「μ_t 从哪来、策略怎么学」变成可学习对象：在约束 MDP 里用对偶上升学出成本评论家与影子价格，用保模态微调避免把 R69 的多峰结构学塌；但训练必须在**训练-部署分离**纪律下进行，绝不破坏 R69 的「实时零学习写操作」。
>
> 核心命题：**不确定性消解不是免费的，它从一块同时决定「能不能完成任务」和「能不能安全返回」的有限续航里扣款。用能量影子价格 μ_t 给每一次「问」定价；能量充裕时逐指令退化为 R69（μ=0），能量吃紧时逐级退避到保守甚至返回安全；μ 与策略由约束 RL 离线训练、部署期冻结映射。** 命名 **ENDURE-RAS**（ENergy-aware Decision-making Under uncertainty with Reinforcement-trained Endurance）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「测量还准吗」，R69 问「该向谁求证」，R70 问「**我还剩多少电，这个答案值不值得花掉它、花掉之后还回不回得去**」——求解不确定性也有一条预算线，它的名字叫续航。

## 0. 直觉与动机

**灵感 1（续航能力 → 能量是耦合今天与明天的唯一硬通货）**
直觉：R69 把「交互预算」当成一张固定额度的体验券，用完就算，与任务、安全互不相干。可真实系统只有一块电池：多采 3 条流轨迹（K=4）、算一次 Hutchinson 散度、探一次、问一句，都是从任务推进和安全返航的同一个账户里支取。更本质的是——**能量不可逆**。信息可以过时、可以作废，但花掉的电回不来。于是「现在问一句」的代价，不只是这一次的电费，而是「未来某个时刻本可以用这份电避免一次碰撞/完成一次返航」的期权价值。这个期权价值就是能量约束的拉格朗日乘子 μ_t，也就是**电的影子价格**。
严谨地说：把续航看作非再生资源，序贯决策的目标带一个资源约束，其对偶变量 μ_t 随剩余能量下降而单调上升；任何「用能量换信息」的动作，其净收益应为 `VoI − μ_t·ΔE`。R69 的短视 VoI 恰是 μ_t=0 的退化情形——即「电无限」的幻觉。

**灵感 2（续航悬崖 → 耗尽不是效率问题，是安全问题）**
直觉：多数工程把「省电」当 KPI（续航越长越好），但在这里，**电量耗尽本身就是一次失效**：失能、失联、停在危险位置。因此能量不是软成本，而是硬安全约束。存在一个「续航悬崖」：当剩余能量低于「安全返回 + 应急机动」所需的储备 E_reserve 时，系统必须**停止一切非关键的信息动作，并覆盖任务奖励、返回安全**。这意味着 E-VoI 在接近悬崖时被 μ 压到负值，系统「问不起就不问」；而在能量充裕的高原区，μ≈0，它几乎就是 R69。整个设计是一条从「求知」到「求生」的连续调度，而不是二选一。

**灵感 3（强化学习训练 → μ 与策略是可学的，但学习必须被关进笼子）**
直觉：μ_t 与「何时该问、问什么、留多少电」不可能手写，应该学。约束 RL（CMDP/拉格朗日法）正好给出：最大化任务收益、约束安全与能耗，对偶变量 λ 收敛到影子价格。但这里有两个陷阱：
- **R69 的零学习写操作不变式**不能破——在线实时环路里绝不做梯度写。所以正确姿态是**训练-部署分离**：离线/影子训练出策略与影子价格映射 `μ_t = M_ψ(E_t, R_t)`，部署期只读冻结映射，任何更新必须经过 held-out 约束评估与**认证提交**（可回滚）。
- **RL 会毁掉多模态**：R69 的最大风险是模态坍缩/幻觉；而 RL 微调天然倾向把多峰压成单峰（提高即时回报）。所以微调必须加**保模态正则**（流匹配似然 + 模态熵下界 + 校准 ECE），否则 R70 会亲手引爆 R69 埋的雷。

**灵感 4（训练也耗电 → 训练本身的续航账）**
直觉：如果部署端每一焦耳都要精打细算，那么**训练端的电从哪来**？真实机器人/车队的 RL 训练若全靠物理 rollout，训练本身就可能把设备跑没电、跑坏。因此训练应以世界模型（复用 R67 VISTA）内的仿真 rollout 为主，真实 rollout 设硬预算 B_real，并用「仿真-真实能量间隙」给仿真样本降权。这把「续航」从部署约束扩展为一个**训练预算约束**：样本效率就是续航效率。

**灵感 5（新攻击面：拒绝服务式耗尽）**
直觉：一旦系统会「为消歧花电」，攻击者就有了新武器——不直接攻击它，而是**制造歧义让它自己把电问光**（denial-of-endurance）：伪造一个需要反复追问的幻影模态、制造传感器互相矛盾的假象、用诱导性回答拉长交互。R69 关心「问错比不问更危险」；R70 必须再加一句：**问不起、问不完，比问错更致命**。而且 RL 训练会主动发现能量模型与现实之间的任何价差去「薅电」（奖励黑客），所以训练期的能量审计与真实能耗不可自证。

**灵感 6（严格包含 → 又一层必须是旧层的泛化）**
直觉：这是本系列每轮的理论底线。R70 必须在 μ_t=0、能量充裕、策略冻结为 R69 时**逐指令等于 FLUID**；在「永不交互」时等于 R68。否则每加一层就多一个需要独立信任的黑箱。能量影子价格不是并列的新模块，而是把 R69 的「交互预算」从一个标量次数，升级为一条有价格的能量约束——标量预算是 μ=0 且只数次数时的投影。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（ENDURE-RAS 总览）** ENDURE-RAS = (FLUID-RAS, ESM, EAR, ECC, SPECTRA, MPRL, TRS, E-Cert)。四不变式：
(i) **实时零学习写操作**（继承 R69 定义 293-i、R68 定义 276-i）；
(ii) **能量守恒与硬保留**：`E_{t+1} = E_t − c_total(a,g) − c_comp(K,N_step,FMA) + r_t`，恒有 `E_t ≥ E_reserve`（续航悬崖不可跨）；交互账户不得挪用安全储备；
(iii) **训练-部署分离**：部署期只读冻结参数与冻结映射 `M_ψ`；任何策略/影子价格更新须过 held-out 约束评估与认证提交（定义 318），绝不进入实时环路；
(iv) **严格退化**：`μ_t=0 ∧ E_t ≥ E_mission ∧ π=π^{FLUID}` ⇒ 逐指令等于 R69；永不交互 ⇒ 等于 R68。

**定义 311（续航状态模型 ESM）** 能量状态 `E_t ≥ 0`，观测含 SOC、温度、健康度 SOH、放电功率上限。消耗模型
`c_total = c_task(a) + c_info(g) + c_comp(K, N_step, FMA)`，
其中 c_info 覆盖注视/探针/问句，c_comp 覆盖流采样与似然回放的算力折算电耗，均含随机项。任务完成所需能量 `E_req ~ p(·|context)` 由 R67 VISTA 世界模型给出分布；剩余续航 `R_t = E_t / \bar{P}(t)`。ESM 输出 `(E_t, R_t, p(E_req))`。

**定义 312（能量影子价格 ECC）** `μ_t = ∂V*/∂E_t` 为约束最优值函数对能量的边际价值，由约束 MDP 的对偶给出（定义 315）。部署期用冻结单调映射 `μ_t = M_ψ(E_t, R_t)` 近似，要求：`E_t` 下降 ⇒ `μ_t` 单调不减；`μ_t ∈ [0, μ_max]`。**续航悬崖**：`E_t < E_reserve` ⇒ `μ_t = μ_max`，且任务动作被「返回安全」动作覆盖。

**定义 313（续航修正的信息价值 E-VoI）** 对候选信息动作 g：
`E-VoI(g) = VoI(g) − μ_t · E[c_info(g) + c_comp(g)] − c_social(g)`。
选择 `g* = argmax_g E-VoI(g)`，s.t. 安全认证（继承 R69 定义 302）与能量约束（定义 310-ii）。`μ_t` 是花掉这份电的机会成本（未来本可用于安全/返航/任务的价值）。若 `max E-VoI ≤ 0`：不交互，走 R69 兜底。**R69 的 VoI 是 μ_t=0 的特例**（能量不稀缺 ⇒ 影子价格为零）。

**定义 314（能量-风险-续航三角运行点）** 三目标：任务成功率、安全风险、续航余量。受约束优化：
`max_π E[任务收益] s.t. P(能量中途耗尽) ≤ δ ∧ risk ≤ ε_safe`。
运行点取 Pareto 面上由认证选定的一个点；训练期由拉格朗日乘子 `(λ_s, λ_e)` 学出，部署期固定。E-VoI 即该运行点处的局部线性化。

**定义 315（约束 RL 训练 SPECTRA）** 在 CMDP 中训练：状态含 `(o_t, E_t, R_t)`，动作 `ξ=(a,g)`，奖励 `r_task`，成本 `c_safe, c_energy`。目标
`J = E[Σ γ^t r_task] − λ_s·E[Σ c_safe] − λ_e·E[Σ c_energy]`，
`λ = (λ_s, λ_e)` 用自适应对偶上升 **仅在训练期** 更新；收敛的 `λ_e` 即影子价格映射 `M_ψ` 的监督信号。产出 `(π_θ, 成本评论家, M_ψ)`。

**定义 316（保模态 RL 微调 MPRL）** 在 R69 流策略上做 RL 微调时加正则：
`L = L_RL + β·L_FM + η·L_mode_entropy + ζ·L_cal`，
其中 `L_FM` 锚定基流场（信任域）、`L_mode_entropy` 给模态熵 `H_mode` 一个下界（防塌）、`L_cal` 保持模态校准 ECE。约束：微调后 `H_mode` 下降 ≤ ΔH_max（定义 318 的提交门）。这是对 R69 最大风险（模态坍缩）的正面防御，而非事后补丁。

**定义 317（训练期盾 TRS）** 训练期所有 rollout 过与部署同一个 C-RAS-WM 认证与能量硬夹；仿真-真实能量间隙由 held-out 真实 rollout 估计；训练以离线/影子方式进行，候选策略不得直接上线。

**定义 318（认证提交 Certified Commit）** 候选策略/影子价格仅在同时满足
`安全违规 ≤ τ_s ∧ 能量耗尽率 ≤ δ ∧ ECE ≤ τ_ece ∧ ΔH_mode ≤ ΔH_max ∧ gap ≤ τ_gap`
时提交；否则保留旧版。提交原子、可回滚（继承 R68 换装不变式 / R69 定理 17）。

**定义 319（续航感知分级退避 E-DEG）** 随 μ_t 上升的单调调度 σ(μ_t)：①降 K（4→1）；②禁非关键交互；③抬高 λ_floor；④返回安全（E_reserve 触发）。要求 `λ` 单调不降、单位时间交互次数单调不增、安全包络不变。

**定义 320（能量对抗干扰集 E-AIC）** `ℰ_ENDURE = ℰ_FLUID × ℰ_energy × ℰ_train`。ℰ_energy：**不确定性投毒**（制造假歧义诱使耗尽）、能源侧信道、伪低电量/伪高电量；ℰ_train：奖励黑客（藏能耗、骗成本评论家、利用世界模型盲区）、训练数据投毒（污染 μ）、仿真-真实能量间隙被利用。

**定义 321（续航证书 J_ENDURE）** `J_ENDURE = (J_FLUID, E_t/E_req, μ_t, P_deplete, energy_audit_hash, train_deploy_gap, ΔH_mode, endure_ver)`。Valid ⇔ `Valid(J_FLUID) ∧ P_deplete ≤ δ ∧ 提交合规 ∧ 能量账户未越界`。

**定义 322（能量审计 VQAuditor-E）** 审计：每次交互的能量性价比、是否被不确定性投毒诱导过度交互、RL 训练是否奖励黑客/藏能耗、影子价格是否被数据投毒污染、训练-部署间隙是否扩大。结论回灌 AuditBuf，成为下一轮成本先验。

**定义 323（层次化能量预算）** 将 `E_t` 划分为任务账户 / 交互账户 / 安全储备三个子账户；交互账户耗尽只能借「未来任务额度」且需认证，**安全储备永不可挪用**。这把 R69 的单标量交互预算细化为带优先级的账户体系。

**定义 324（模型式训练以省真实能耗）** 训练主要在 VISTA 世界模型内 rollout；真实 rollout 设每轮硬预算 `B_real`；仿真样本按「能量模型一致性风险」降权。样本效率即续航效率；同时对「训练能耗」本身记账（训练也是一次续航消耗）。

**定义 325（续航-认知联合姿态）** E-VoI 揭示：续航越紧，只有「高判别力 + 低成本 + 能改变高风险决策」的交互才值得；当 `μ_t·ΔE > VoI` 时，系统应保持 epistemic 未消解并走 R69 保守——**宁可不知道，也不能回不去**。这把 R69「问错比不问更危险」扩展为「问不起 / 问不完，比问错更致命」。

**定义 326（训练-部署双时间尺度）** μ 的慢尺度（训练学、部署冻结映射）与 λ 的实时尺度严格分离；任何在线学习都不进入实时环路，避免破坏零写不变式。

**定义 327（逐级包含）** `μ=0 ∧ E 充裕 ∧ π 冻结` ⇒ FLUID（R69）；`永不交互` ⇒ R68。安全侧逐级不变弱，效率/续航侧逐级获增益。

```python
# IP-265 ESM+ECC：续航状态与能量影子价格（部署期只读冻结映射）
def endurance_state(obs, soc, power, world_model):
    E, R = soc, soc / max(power, eps)             # 剩余能量 / 剩余续航
    p_req = world_model.predict_energy_need(obs)  # E_req ~ p(·|context)
    return E, R, p_req

def shadow_price(E, R, psi):                      # M_ψ：单调、有界、冻结
    mu = psi(E, R)                                # 训练学到的对偶映射
    return mu_max if E < E_reserve else clip(mu, 0, mu_max)  # 续航悬崖

# IP-266 E-VoI：把电的机会成本计入信息价值（R69 是 μ=0 边界）
def choose_interaction_E(modes, w, o_t, budget, E, mu):
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow_energy(g, E):         continue
        if not c_ras_wm.certify_info(g, o_t):     continue
        if E - cast_energy(g) < E_reserve:        continue   # 不跨悬崖
        voi_e = entropy(w) - expected_entropy(w, g, o_t)
        voi_e -= mu * cast_energy(g)              # 能量机会成本
        voi_e -= social_physical_cost(g)
        if best is None or voi_e > best.voi_e: best = (g, voi_e)
    return best if best and best.voi_e > 0 else None          # 问不起 → R69

# IP-268 MPRL：保模态的约束 RL 微调（防 R69 模态坍缩）
def mprl_step(policy, batch, lam_s, lam_e):
    L_rl   = -advantage_weighted_logprob(policy, batch)
    L_fm   = flow_matching_anchor(policy, batch)              # 信任域锚定
    L_ent  = relu(H_MIN - mode_entropy(policy, batch))        # 模态熵下界
    L_cal  = mode_calibration_ece(policy, batch)
    return L_rl + lam_s*cost_safe(batch) + lam_e*cost_energy(batch) \
           + BETA*L_fm + ETA*L_ent + ZETA*L_cal

# IP-270 E-DEG：续航感知的分级退避（单调，无突变）
def degrade(mu, E, K, lam, g):
    if E < E_reserve:            return safe_return_action(), 1.0, 1   # 求生
    if mu > MU_K:    K = 1
    if mu > MU_NOASK: g = None
    if mu > MU_LAM:  lam = max(lam, lam_floor_up(E))
    return g, lam, K

# IP-274 主闭环（继承 R69，仅在资源层与训练层增量）
def ENDURE_RAS_round(M, obs, E):
    z, o = M.mtm.forward(obs); c, U_cal, _ = M.cof.step(o)   # R69 一次前向
    mu = shadow_price(E, R_t, M.psi)                          # 电的影子价格
    K  = 1 if (M.fmp.mode_head(z) < TAU_MODE or mu > MU_K) else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o, o_calibrated)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    g = (M.mint.choose_interaction_E(modes, o, M.budget, E, mu)
         if (U_epi > TAU_EPI and not slow) else None)
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    g, lam, K = M.e_deg.degrade(mu, E, K, lam, g)             # 分级退避
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_e.submit_async(g, E, mu, U_epi, a_hat)              # 能量审计
    return k, lam, mode, (U_ale, U_epi, E - cast_energy(g))
```

## 3. 推导

**引理 19（能量约束下的 VoI 最优性）** 带能量预算的序贯决策中，交互最优判据为 `E-VoI = VoI − μ_t·ΔE`，其中 `μ_t` 为能量约束的拉格朗日乘子。证明：对资源约束 MDP 写拉格朗日函数并对能量约束取对偶，乘子即边际价值。**系**：R69 的短视 VoI 仅在能量约束不活跃（μ_t=0）时最优；能量越紧，交互门槛越高，且门槛只依赖 `μ_t` 这一个标量。

**引理 20（续航悬崖安全性）** 若安全储备满足 `E_reserve ≥ E_return_max + E_margin`，且 E-DEG 调度 σ 关于 μ 单调，则「能量耗尽前无法返回安全」的概率 ≤ δ；且安全储备不可挪用保证任何耗电决策都不降低安全包络。要点：能量约束被拆成「任务/交互可花」与「安全储备不可动」两层，耗尽风险只落在前两层。

**引理 21（保模态微调的熵界）** 若 `L_FM` 将策略限制在基策略的信任域内、且 `L_mode_entropy` 权重 η 足够大，则微调后模态熵下降有界：`H_mode(π') ≥ H_mode(π) − ΔH_max(η, β)`；当 ΔH_max 取小于 R69 的模态可分阈值时，微调不破坏 A95 可分性。**系**：RL 不会把 R69 的多峰学塌，从而不会放大「追问幻影」的风险。

**引理 22（训练-部署间隙上界）** 认证提交（定义 318）保证部署策略风险 ≤ 被替换策略风险 + `gap_bound(τ_gap, δ)`；若 held-out 评估覆盖真实能量分布，则间隙随真实 rollout 预算 `B_real` 增大而收缩。**系**：回滚机制使一次坏提交的代价有界，训练不会把系统一次性带偏。

**定理 18（ENDURE 严格包含 FLUID 与 CALM）** 在 A99–A101（能量模型一致、M_ψ 单调有界、认证提交有效）下，ENDURE 任意状态的期望风险 ≤ R69；当 `μ_t=0` 且能量充裕且 `π=π^{FLUID}` 时两者**逐指令相同**；当 `E-VoI ≤ 0` 时退化为 R69 保守；当永不交互时等于 R68。故安全侧不做任何让步，效率/续航侧获得 resolution bonus 与能量感知的顺序改进。

**定理 19（续航-安全无突变）** E-DEG 的单调调度（定义 319）+ 层次化账户（定义 323）+ C-RAS-WM 认证 ⇒ 控制连续、无突变；且因安全储备不可挪用，任何为延长续航而做的降级都不会牺牲安全包络。**系**：「省电」永远不能成为越过安全边界的理由——这是与普通续航优化的本质区别。

**定理 20（训练安全性）** TRS（定义 317）+ 认证提交（定义 318）+ 保模态微调（定义 316）⇒ 任何被提交的策略其约束违规不超过 held-out 估计 + 间隙上界；训练不引入控制突变；且 `H_mode` 不塌，R69 的消歧前提保持成立。

**推论 19.1（拒绝服务式耗尽的成本上界）** 在证据纪律（R69 定义 293-iii）与能量硬约束下，单次不确定性投毒最多消耗一次交互预算；因 `E-VoI` 在 μ 上升时自动收紧，攻击者诱导的累计耗能被 `∫μ dE` 上界约束，无法通过重复制造歧义把电量问光。

## 6. 本轮最大风险

**一句话**：ENDURE-RAS 的全部续航收益押在「**能量消耗模型与影子价格可信**」这一前提上——若 ESM 低估能耗（尤其世界模型在仿真里把电耗抹平）、或 RL 训练学会在能量模型盲区里「奖励黑客」（藏能耗、骗成本评论家、利用仿真-真实价差），则 `μ_t` 被错误定价：系统要么**以为还问得起，在任务中途耗尽能源**（续航悬崖被击穿，安全灾难），要么陷入**「续航焦虑」该问不问**、保留未消解的 epistemic 却不再交互，退化成过度自信的 R68；而强化学习恰恰是最擅长发现并利用这个价差的过程——**优化续航的机制，会亲手让它依赖的那个假设失效**。

## 3. 关键算法伪代码

```python
# IP-264 ESM + IP-265 ECC：续航状态与影子价格（部署期只读冻结映射）
def endurance_state(obs, soc, power, world_model):
    E, R = soc, soc / max(power, eps)
    return E, R, world_model.predict_energy_need(obs)   # E_req ~ p(·|context)

def shadow_price(E, R, psi):
    mu = psi(E, R)                                       # 训练学到的对偶映射
    return MU_MAX if E < E_RESERVE else clip(mu, 0, MU_MAX)

# IP-266 EAR：E-VoI 交互决策（R69 是 μ=0 边界；不跨续航悬崖）
def choose_interaction_E(modes, w, o_t, budget, E, mu):
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow_energy(g, E):        continue
        if not c_ras_wm.certify_info(g, o_t):    continue
        if E - cast_energy(g) < E_RESERVE:       continue      # 问不起
        s = entropy(w) - expected_entropy(w, g, o_t)
        s -= mu * cast_energy(g) + cost_social(g)              # 电的机会成本
        if best is None or s > best[1]: best = (g, s)
    return best[0] if best and best[1] > 0 else None           # 退化 R69

# IP-267 SPECTRA + IP-268 MPRL：约束训练 + 保模态微调（离线）
def spectra_mprl_step(policy, batch, lam_s, lam_e):
    L = -advantage_weighted_logprob(policy, batch) \
        + lam_s*cost_safe(batch) + lam_e*cost_energy(batch) \
        + BETA*flow_matching_anchor(policy, batch) \
        + ETA*relu(H_MIN - mode_entropy(policy, batch)) \
        + ZETA*mode_calibration_ece(policy, batch)
    lam_e = max(0.0, lam_e + LR_DUAL*(cost_energy_mean(batch) - C_E))  # 对偶
    return L, lam_e

# IP-270 E-DEG：分级退避（单调、无突变）
def degrade(mu, E, K, lam, g):
    if E < E_RESERVE:      return safe_return_action(), 1.0, 1
    if mu > MU_K:          K = 1
    if mu > MU_NOASK:      g = None
    if mu > MU_LAM:        lam = max(lam, lam_floor_up(E))
    return g, lam, K

# IP-276 主闭环（继承 R69，仅加资源层）
def ENDURE_RAS_round(M, obs, E):
    z, o = M.mtm.forward(obs); c, U_cal, _ = M.cof.step(o)
    E, R, p_req = endurance_state(o, E, M.power, M.vista)
    mu = shadow_price(E, R, M.psi)
    K = 1 if (M.fmp.mode_head(z) < TAU_MODE or mu > MU_K) else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o, o_calibrated)
    slow = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    g = (M.mint.choose_interaction_E(modes, o, M.budget, E, mu)
         if (U_epi > TAU_EPI and not slow) else None)
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    g, lam, K = M.e_deg.degrade(mu, E, K, lam, g)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    mode = select_mode(modes, U_epi, lam)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_e.submit_async(g, E, mu, U_epi, a_hat)
    return k, lam, mode, (U_ale, U_epi, E - cast_energy(g))
```

## 4. 推导

**引理 19（能量约束下的 VoI 最优性）** 带能量预算的序贯决策中，交互最优判据为 `E-VoI=VoI−μ_tΔE`，`μ_t` 为能量约束拉格朗日乘子。系：R69 短视 VoI 仅在 μ=0（能量约束不活跃）时最优；能量越紧门槛越高，且只依赖 μ 这一个标量。

**引理 20（续航悬崖安全性）** 若 `E_reserve≥E_return_max+E_margin` 且 E-DEG 关于 μ 单调，则「耗尽前无法返回安全」的概率 ≤ δ；安全储备不可挪用保证耗电决策不降低安全包络。

**引理 21（保模态微调的熵界）** 若 L_FM 把策略限制在基策略信任域、且 η 足够，则 `H_mode(π')≥H_mode(π)−ΔH_max(η,β)`；取 ΔH_max 小于 A95 可分阈值时，微调不破坏模态可分性 ⇒ RL 不会放大「追问幻影」风险。

**引理 22（训练-部署间隙上界）** 认证提交保证部署风险 ≤ 被替换策略风险 + `gap_bound(τ_gap,δ)`；间隙随真实 rollout 预算 B_real 增大而收缩；回滚使坏提交代价有界。

**定理 18（ENDURE 严格包含 FLUID 与 CALM）** A99–A101 下，ENDURE 任意状态期望风险 ≤ R69；`μ=0∧E充裕∧π=π^{FLUID}` 时逐指令相同；`E-VoI≤0` 退化为 R69 保守；永不交互等于 R68。安全不让步，效率/续航获增益。

**定理 19（续航-安全无突变）** E-DEG 单调调度 + 分层账户 + C-RAS-WM 认证 ⇒ 控制连续、无突变；安全储备不可挪用 ⇒ 任何降级都不牺牲安全包络。系：省电永不成为越过安全边界的理由。

**定理 20（训练安全性）** TRS + 认证提交 + MPRL ⇒ 被提交策略的约束违规 ≤ held-out 估计 + 间隙；训练不引入控制突变；`H_mode` 不塌，R69 消歧前提保持。

**推论 19.1（拒绝服务式耗尽的成本上界）** 证据纪律 + 能量硬约束下，单次不确定性投毒最多消耗一次交互预算；E-VoI 随 μ 上升自动收紧，累计耗能被 `∫μ dE` 上界约束，攻击者无法靠重复制造歧义把电问光。

## 7. 本轮最大风险

**一句话**：ENDURE-RAS 的全部续航收益押在「能量消耗模型与影子价格可信」这一前提上——若 ESM 低估能耗（尤其世界模型在仿真里把电耗抹平）、或 RL 训练学会在能量模型盲区里「奖励黑客」（藏能耗、骗成本评论家、利用仿真-真实价差），则 `μ_t` 被错误定价：系统要么**以为还问得起、在任务中途耗尽能源**（击穿续航悬崖，安全灾难），要么陷入**「续航焦虑」该问不问**、保留未消解 epistemic 却不再交互，退化成过度自信的 R68；而强化学习恰恰最擅长发现并利用这个价差——**优化续航的机制，会亲手让它依赖的那个假设失效**。

**次级风险与缓解**：影子价格单调/有界失守（结构约束 + E306 + 越界取 μ_max）；安全储备被挪用（分层账户 + 定理 19）；RL 奖励黑客/藏能耗（真实能耗侧信道审计 + E310 + 认证提交）；保模态正则压不住塌缩（ΔH_max/ECE 提交门 + 超标回滚 R69）；仿真-真实能量间隙（B_real 校准 + 超限拒提 E312）；不确定性投毒耗尽（E-VoI 随 μ 收紧 + 推论 19.1 耗能上界 + ℰ_energy 对抗训练）。
