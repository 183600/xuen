# 第 1 轮迭代（灵感循环 v3：「技术路线图」×「比赛策略」）——把 v2 清单收敛为“证据闸门”与“排名博弈”

> 承接保留区 v2（UIP-01′~15）；本轮按新循环从第 1 轮计数，编号继续沿用。**本轮刻意不再增加新点子**，而是做两件在“点子过剩”时更稀缺的事：① 用**技术路线图**给每个点子加上“证据闸门 + 转向/终止条件”；② 用**比赛策略**把有限算力、真机时段和风险预算分配到“最大化排名”而非“最大化单任务分数”。
>
> 本轮最重要的结论不是新 UIP，而是一次**由接口闸门直接判定的 v2 技术性否决**：README §3 规定 `get_action` 每次返回形状 `(T_a, …)` 的动作块、评测端整块执行后才再次调用，因此 v2 的“逐动作返回 + 运行期自适应块长（ACS）”不可实现；必须改写为**块边界验证 + 一次性选定 `T_a`**。这正好说明：路线图的第一道闸门应放在接口，而不是模型。

## 0. 直觉解释（先讲人话）

- **技术路线图**不是甘特图，而是一串“在什么证据出现前不许开下一个工”的承诺。研究者最大的浪费不是 GPU，而是把几个月投进一个没有真实反馈回路的子系统；真机时段才是唯一硬通货。
- **比赛策略**不是“每个任务都做到最好”，而是在对手分布未知时选择分数的**均值与方差**。领先时方差是敌人，落后时方差是朋友。
- 同理，末步也不是无条件要“搏”：如果末步会**破坏已经锁定的前缀**（拉链拉开、毛巾翻开、盒盖打开），盲目搏末步等于把到手的步骤分再赌回去；如果末步是加性/不可逆的（放上、插入），搏它几乎免费。
- 官方计分步本身就是赛方发给你的“技术路线图”：有序、后置权重更大。我们真正要创新的是**执行、恢复与资源编排**，不是重新发明任务分解。
- 最危险的不是点子不够，而是路线图把“过闸”当成“进步”：如果闸门指标与排行榜不相关，越自律越偏航。

## 2. 严谨定义

**D1（计分结构与前缀地板）** 任务 $i$ 有 $n_i$ 个有序计分步，权重 $w_{i,k}\ge 0$，$\sum_k w_{i,k}=100$。定义前缀地板
$$\Pi_i(m)=\sum_{k=1}^{m} w_{i,k},\qquad \Pi_i(0)=0,$$
步分 $P_i=\sum_k w_{i,k}\mathbf 1[A_k]$，成功率 $S_i=\mathbf 1[\forall k,\,A_k]$。榜单汇总为 $C=\frac1{|I|}\sum_i F(S_i,P_i)$，$F$ 对两个自变量单调不减；$F$ 的具体形式未知（加性 / 字典序 / 门槛）。

**D2（技术路线图）** 路线图是带闸门的偏序集 $R=(M,\prec,G,K)$：$M=\{M_0,\dots,M_7\}$；$G_j:\text{Evidence}\to\{\text{pass},\text{fail},\text{pending}\}$ 是**预注册**的闸门谓词；$K_j$ 是失败时的转向/终止动作。硬约束：$G_j\ne\text{pass}$ 时，禁止把超过 $\epsilon$ 的预算投入 $M_j$ 的后继。

**D3（比赛策略）** 策略是映射 $\sigma:H_t\mapsto(a_t,\rho_t)$，$H_t$ 包含榜单、自己的分数、剩余时段与已花预算；$a_t$ 是任务/里程碑间的资源分配，$\rho_t$ 是风险参数（如高方差任务预算占比或分数标准差乘子）。目标是最大化 $\mathbb E[U(\text{rank})]$ 或 $\Pr(\text{rank}\le r^\*)$，**不必**最大化 $\mathbb E[\text{score}]$。

**D4（可逆性与回归损失）** 计分步 $k$ 在预算 $B$ 下若存在恢复动作序列，以至少 $1-\varepsilon$ 的概率把状态恢复到前缀 $m$，则称其可逆。记尝试 $k$ 或人为干扰导致前缀被撤回的概率为 $r_k$，被撤回后仍保留的最长前缀为 $m'$，回归损失 $L_k=\Pi_i(m)-\Pi_i(m')$。

**D5（风险参数）** $\rho$ 可取为策略在任务集合上实现分数的标准差，或“高方差/高难度任务”的预算占比。

**D6（真机时段的信息价值）** 对任务簇 $c$，一次额外评测时段的信息价值近似
$$\mathrm{VOI}_c\approx\left|\frac{\partial \mathbb E[U]}{\partial \mu_c}\right|\cdot\frac{\sigma_c}{\sqrt{K_c}}\Big/\text{cost}_c,$$
其中 $\mu_c,\sigma_c$ 是当前分数估计的均值与标准差，$K_c$ 是已测 episode 数。

## 3. 三个可推导命题与一个接口纠正

### 命题 1（可逆性感知的末步博弈，RA-LSG）
设在某个计分步之后已锁定前缀地板 $F=\Pi(m)$，剩余总分 $M=100-F$（先考虑只差最后一步）。尝试末步：以 $1-r$ 不触发回归，此时以概率 $q$ 成功得 $F+M$，否则得 $F$；以 $r$ 触发回归，得 $F-L$。则
$$\mathbb E[\text{gamble}]=F+(1-r)qM-rL,\qquad \mathbb E[\text{secure}]=F.$$
**搏末步当且仅当**
$$(1-r)qM>rL.$$
工程上再加安全系数 $\kappa$：只有 $(1-r)qM\ge(1+\kappa)rL$ 才搏，以吸收 $q,r,L$ 的估计误差。

**推论 1.1**：不可逆/加性末步 $r\approx0$ ⇒ 只要 $q>0$ 就应尝试；可逆/破坏性末步 $rL$ 大 ⇒ 需要更高的 $q$ 或更小的 $L$ 才值得搏。

**推论 1.2**：官方“末步权重恒 ≥ 前序步”使奖励对进度呈**凸性**；$r=0$ 时理性策略本就偏风险寻求，但 $r>0$ 的回归风险会把最优策略拉回保守。这解释了同一句“搏末步”不能套用到所有任务。

### 命题 2（排名自适应风险，RAR）
设你与领先者的剩余增量之差为 $\Delta\sim$ 对称位置-尺度分布，均值 $\mu$、尺度 $\sigma$；记差距 $d=\text{leader}-\text{you}$（$d>0$ 表示落后）。则
$$\Pr(\text{win})=\Pr(\Delta>d)=1-F_\sigma(d-\mu).$$
对 $X=\mu+\sigma Z$ 求导，
$$\frac{\partial}{\partial\sigma}\Pr(X>d)=\varphi(z)\cdot\frac{d-\mu}{\sigma^2},\qquad z=\frac{d-\mu}{\sigma}.$$
**符号只取决于 $d-\mu$**：落后（$d>\mu$）时增大方差提高胜率；领先（$d<\mu$）时减小方差提高胜率；差距在噪声内时方差近似中性。

**推论 2.1**：追赶者应把预算转向高权重、高难度、对手可能放弃的任务；领先者应冻结模型、压低方差、只做验证性提测。

### 命题 3（`T_a` 的一次性最优选择）
设 episode 长 $N$ 步，单次往返延迟 $L$，控制周期 $\Delta t$，块长 $T$。同步开环执行下墙钟时间约
$$T_{\text{wall}}\approx\frac{N}{T}(L+T\Delta t)=N\Delta t+\frac{NL}{T},$$
对 $T$ 单调下降；但反应延迟约 $L+T\Delta t$，接触密集任务的失败概率 $p(L+T\Delta t)$ 随 $T$ 上升。若 $p(s)\approx p_0+\lambda s$，则
$$J(T)=c\frac{NL}{T}+W\lambda T\Delta t+\text{const}\ \Longrightarrow\ T^\*\approx\sqrt{\frac{cNL}{W\lambda\Delta t}}.$$
由于 `T_a` 在握手后固定，实际只能对 32 任务分布求加权最优 $\min_T\sum_i\pi_i J_i(T)$；**不能在运行期按阶段切块长**。v2 的 ACS 应降级为“一次性 TAS（T_a Selection）”。

### 接口纠正（v2 的直接否决）
v2 的 `RHPVD_Policy.get_action` 每次 `return self.buf.pop(0)`，只返回一步；但 README §3 要求每次返回完整 `(T_a,…)` 动作字典（含共享键与 `meta.token`）。因此：
- **块内不能“每 k 步核验”**；只能把 `T_a` 设成希望的重观测周期，且该值全局固定。
- v2 所说“返回 ≤k 步的块”属于未文档化行为，默认视为会被拒；只有 M0 闸门实测接受后才能复活 ACS。
- 正确写法是 **B-RHPVD（Block-boundary RHPVD）**：在每个块边界用验证器决定“推进 / 重做 / 回退”，块内只执行预先承诺的动作。

## 5. 比赛策略总览

### 5.1 评分规则不确定时的稳健动作
- **加性规则**（$C=\alpha S+\beta P$）：前缀地板直接计分，“保前置”有效。
- **字典序/门槛规则**（先比 $S$，或 $P$ 仅在 $S=1$ 时计）：前缀地板只是通向全成功的中间态，必须追全成功。
- **共同支配动作**：任何“降低已锁定前缀且不提升成功率”的动作，在所有单调规则下都是被支配的。因此**不破坏前缀**是规则无关的稳健策略；RA-LSG 正是它的执行器。

### 5.2 阶段状态机
- **P0 开榜前 / 信息投资期**：只做 M0–M2，最大化“证据产出率”，不追分数。
- **P1 落后（$d$ 显著大于噪声）**：提高方差，转向高权重/高难度/人扰任务，启用 RA-LSG 的 Type-I 激进分支。
- **P2 接近榜首/领先**：降低方差，冻结模型，锁前缀，Type-II 末步只在 $\kappa$ 满足时搏。
- **P3 截止前**：只花最高 VOI 的时段；禁止冻结后再训练；保留回滚。

## 6. 本轮最大风险

**一句话**：最大的风险是把代理指标（GSO 分数、离线消融、恢复成功率）误当成排行榜分数，导致整条路线图以极高纪律走向错误方向；因此 M2/M6 必须保留真机/榜单校准闸门，并允许一次“路线图否决权”。

## 1. 计分结构：锁分阶梯与规则不确定性

### 1.1 四种计分模式的前缀地板 [事实 + 推导]

| 模式 | 各步分值 | $\Pi(1)$ | $\Pi(2)$ | $\Pi(3)$ | $\Pi(4)$ | $\Pi(5)$ |
|---|---|---|---|---|---|---|
| 2 步 | 50/50 | 50 | 100 | — | — | — |
| 3 步 | 30/30/40 | 30 | 60 | 100 | — | — |
| 4 步 | 25/25/25/25 | 25 | 50 | 75 | 100 | — |
| 5 步 | 20/20/20/20/20 | 20 | 40 | 60 | 80 | 100 |

**读法**：每完成一步，就把对应分值“锁进保险箱”；失败只会让剩余分拿不到，通常不会清零（除非发生回归）。因此策略的第一目标不是“平均分最高”，而是**在有限时间内把前缀推进到尽可能高，同时避免把已锁分打回去**。

### 1.2 末步权重的凸性 [推导]

由于官方规定末步权重 $w_{i,n_i}\ge w_{i,k}$（$k<n_i$），前缀地板的增量 $w_{i,k}$ 在最后一步最大。故奖励 $R(m)=\Pi_i(m)$ 对进度 $m$ 是**凸函数**：

$$\Pi_i(m+1)-\Pi_i(m)=w_{i,m+1}\ \text{非递减}.$$

**含义**：在**没有回归风险**（$r=0$）时，奖励凸性使“搏最后一步”成为理性选择；但一旦 $r>0$，末步的期望增益被 $rL$ 抵消（命题 1）。这解释了为什么“末步权重更大”不等于“所有任务都该无脑搏末步”。

### 1.3 评分规则不确定下的稳健动作 [推导]

| 候选规则 | 数学形式 | 对“前缀地板”的含义 | 若规则未知时的稳健动作 |
|---|---|---|---|
| 加性 | $C=\alpha S+\beta P$ | 前缀分直接计分，“保前置”有效 | 保留前缀，按边际收益搏末步 |
| 字典序 | 先比 $S$，再比 $P$ | 前缀只是通向全成功的中间态 | 必须追全成功；前缀是必要不充分 |
| 门槛 | $P$ 仅在 $S=1$ 时计 | 失败 episode 的步分可能作废 | 近似字典序，优先成功率 |
| 乘积 | $C=S\cdot P$ | 与门槛等价 | 同上 |

**命题 4（规则无关的支配关系）** 若某动作使 $P$ 不增、$S$ 不增，且至少一个严格下降，则它在所有“对 $S,P$ 单调不减”的规则下都被支配。**证明**：逐项比较 $F(S,P)$ 的单调性即可。$\square$

**推论 4.1**：**“不破坏已锁定前缀”是唯一在所有候选规则下都正确的策略成分**。RA-LSG 的价值不在于最大化某一种规则下的分数，而在于保证策略不因规则误判而自毁。

## 3. 命题、推导与工程阈值

### 3.1 命题 1：RA-LSG 的期望收益

设已锁定前缀 $F$，剩余总分 $M=100-F$，末步成功概率 $q$，回归概率 $r$，回归损失 $L$。两种策略：

- **Secure**：停止在 $F$。
- **Gamble**：尝试末步。以 $1-r$ 不回归：成功得 $F+M$，失败得 $F$；以 $r$ 回归：得 $F-L$。

$$\mathbb E[\text{gamble}]=(1-r)(F+qM)+r(F-L)=F+(1-r)qM-rL.$$

因此

$$\boxed{\ \text{Gamble}\iff (1-r)qM>rL\ }$$

工程上使用带安全系数的版本：

$$\text{Gamble}\iff (1-r)qM\ge(1+\kappa)rL,\qquad \kappa\in[0.25,1].$$

$\kappa$ 由 $q,r,L$ 的估计不确定性决定；M3 用 bootstrap 给出置信区间后再定。

**边界情形**：
- $r=0$：条件退化为 $qM>0$，只要 $q>0$ 就搏；这覆盖 Type I。
- $L=M$（回归把刚做的全部打回）：条件变为 $(1-r)q>r$，即 $q>r/(1-r)$；当 $r=0.4$ 时需要 $q>0.67$，非常苛刻。
- “Secure” 并不总是零风险：若人扰会在你停止时继续发生，则 $F$ 也不是保证值；此时把 $r_0L$ 加到两边，条件近似变为 $(1-r)qM>rL+r_0L$。

### 3.2 命题 2：RAR 的符号

设剩余增量差 $\Delta=\mu+\sigma Z$，$Z$ 对称、单峰、密度 $\varphi$，$d=\text{leader}-\text{you}$。则

$$\Pr(\text{win})=\Pr(\Delta>d)=1-F_\sigma(d-\mu).$$

对 $\sigma$ 求导：

$$\frac{\partial}{\partial\sigma}\Pr(\text{win}) =\varphi\!\left(\frac{d-\mu}{\sigma}\right)\cdot\frac{d-\mu}{\sigma^2}.$$

因为 $\varphi>0$，符号由 $d-\mu$ 决定：

- **落后**（$d>\mu$）：$\partial/\partial\sigma>0$ ⇒ **提高方差**。
- **领先**（$d<\mu$）：$\partial/\partial\sigma<0$ ⇒ **降低方差**。
- **持平**：方差近似中性；此时优先降低“毁灭性风险”（违规、超时、端口故障），而不是追求分布形状。

### 3.3 命题 3：`T_a` 的一次性最优选择（对 v2 ACS 的纠正）

设 episode $N$ 步、单次往返 $L$、控制周期 $\Delta t$、块长 $T$。同步执行下：

$$T_{\text{wall}}\approx\frac{N}{T}(L+T\Delta t)=N\Delta t+\frac{NL}{T}.$$

反应延迟（从观测到下一块生效）约 $L+T\Delta t$。令接触密集任务的失败概率 $p(s)\approx p_0+\lambda s$，则

$$J(T)=c\frac{NL}{T}+W\lambda T\Delta t+\text{const} \ \Longrightarrow\ T^\*\approx\sqrt{\frac{cNL}{W\lambda\Delta t}}.$$

**推论 3.1**：`T_a` 是**一次性超参数**，不是阶段性旋钮。由于所有任务共享同一份 `metadata`，实际选择是

$$T_a^\*=\arg\min_T\sum_i\pi_i J_i(T),$$

其中 $\pi_i$ 是任务权重（若 A1 成立则均匀）。若评分规则偏字典序，则高失败率任务的 $W_i$ 更大，最优 `T_a` 更小。

**推论 3.2**：v2 的“全局最大 k + 每次返回 ≤k”没有文档支持；默认视为会被拒。M0 必须实测“短块是否被接受”，否则 ACS 不能作为运行期机制。

### 3.4 命题 5：时段分配的信息价值与停止规则

对任务簇 $c$，一次额外 episode 把均值估计的标准误从 $\sigma_c/\sqrt{K_c}$ 降为 $\sigma_c/\sqrt{K_c+1}$。若排名效用对 $\mu_c$ 的敏感度为 $g_c=|\partial \mathbb E[U]/\partial\mu_c|$，则边际信息价值近似

$$\mathrm{VOI}_c\approx g_c\cdot\sigma_c\left(\frac{1}{\sqrt{K_c}}-\frac{1}{\sqrt{K_c+1}}\right)\Big/\text{cost}_c.$$

**贪心分配**：每时段选当前 $\mathrm{VOI}_c$ 最大的簇；当 $\max_c \mathrm{VOI}_c<\lambda$（$\lambda$ 为时段的机会成本，如保留给最终验证的价值）时停止。该贪心在 VOI 近似子模时接近最优；若存在强互补（如必须成对测 A/B），则升级为成对分配。

## 6. 伪代码

### 6.1 RA-LSG 决策器

```python
def ra_lsg_step(F, M, q, r, L, kappa=0.5, eps=1e-9):
    """返回 'gamble' 或 'secure'。
    F: 已锁定前缀地板; M: 剩余总分; q: 末步成功概率;
    r: 回归概率; L: 回归损失; kappa: 安全系数。
    依据: E[gamble] = F + (1-r)qM - rL; gamble iff (1-r)qM > rL.
    """
    gain = (1.0 - r) * q * M
    risk = r * L
    if gain >= (1.0 + kappa) * risk + eps:
        return "gamble"
    return "secure"
```

### 6.2 RAR 风险乘子

```python
def risk_multiplier(gap, mu=0.0, sigma_rank=1.0):
    """gap = leader - you (正=落后)。返回风险乘子 rho。
    落后: rho>1; 领先: rho<1; 差距在噪声内: rho≈1.
    """
    z = (gap - mu) / max(sigma_rank, 1e-9)
    if z > 2.0:
        return min(2.0, 1.0 + 0.5 * z)      # 远落后
    if z > 0.5:
        return 1.2
    if z < -2.0:
        return 0.4                          # 远领先
    if z < -0.5:
        return 0.7
    return 1.0
```

### 6.3 ESOS 时段分配

```python
def esos_allocate(clusters, budget, lam=0.0):
    """clusters: list of dict(g=敏感度, sigma=分数std, K=已测数, cost=成本)
    每轮把 1 个时段分给 VOI 最大的簇，直到 VOI < lam 或预算耗尽。"""
    alloc = {c["name"]: 0 for c in clusters}
    remaining = budget
    while remaining > 0:
        best, best_voi = None, -1.0
        for c in clusters:
            k = c["K"] + alloc[c["name"]]
            voi = c["g"] * c["sigma"] * (1/k**0.5 - 1/(k+1)**0.5) / c["cost"]
            if voi > best_voi:
                best, best_voi = c["name"], voi
        if best is None or best_voi < lam:
            break
        alloc[best] += 1
        remaining -= 1
    return alloc
```

### 6.4 块边界 B-RHPVD（修正 v2 的接口错误）

```python
class BlockRHPVD:
    """T_a 固定；只在块边界验证/重做；每次返回完整 (T_a,...) 动作块。"""
    def __init__(self, policy, verifier, T_a, K_MAX=2):
        self.policy, self.verifier = policy, verifier
        self.T_a, self.K_MAX = T_a, K_MAX

    def reset(self):
        self.policy.reset()
        self.g = 0
        self.redo = 0

    def get_action(self, obs):
        # 块边界：先判定上一块之后的状态
        state, conf = self.verifier(obs, self.g)
        if conf >= 0.6:
            if state == "done":
                self.g += 1; self.redo = 0
            elif state == "regressed" and self.redo < self.K_MAX:
                self.redo += 1
            elif state == "fail" and self.redo < self.K_MAX:
                self.redo += 1
        chunk = self.policy.get_action(obs, self.T_a)  # 必须返回完整 T_a 步
        # chunk 必须包含所有共享键与 meta.token，形状 (T_a, ...)
        return chunk
```

### 8.1 命题 2 的数值检查（正态、$\mu=0$）

表中为 $\Pr(\text{win})$，$d=\text{leader}-\text{you}$，$\sigma$ 为你的分数尺度：

| $d$ \ $\sigma$ | 2 | 5 | 10 | 20 |
|---|---|---|---|---|
| **+10（落后）** | 0.000 | 0.023 | 0.159 | **0.309** |
| **+5** | 0.006 | 0.159 | 0.309 | 0.401 |
| **0** | 0.500 | 0.500 | 0.500 | 0.500 |

**读法**：落后 10 分时，把方差从 2 提到 20，胜率从 0% 提到 30.9%；领先 10 分时，同样操作把胜率从 100% 降到 69.1%。**方向与命题 2 一致**：追赶者加方差，领先者减方差。

## 10. 结论与最大风险

**本轮押注**：M0 → M2 → M3 的**证据链**，加上 RA-LSG/RAR/ESOS 的**策略层**；UIP-14 模块化保持条件性，UIP-13 ACS 降级为一次性 TAS。这样即便人扰或 GSO 假设落空，策略仍然“不破坏前缀、不误判规则、不烧穿时段”。
