# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「Isaac Sim」×「同步定位与建图」）

> R69 给闭环装上了一张嘴和一双会主动看的眼睛：系统终于会**问**（看/问/触），用 value-of-information 把「歧义」当作可以花预算消解的题。但 R69 只做了半件事：
> 1. 它只消解**未来**的歧义（下一步选哪个模态），从不重新审视**过去**的信念（我脚下这块地、我记忆里的这张图，还是我以为的那个样子吗？）；
> 2. 它的证据纪律是「k 个正交源一致」，却从未说明「正交」以什么为**锚**——正交性是被假设的，不是被测量的；
> 3. 它自陈的最大风险是：流模型的模态分布若不可信，系统会自信地追问一个幻影，把「诚实的不知道」升级成「被证实的错误」。
>
> 本轮两个灵感正好补上这三处：
> - **Isaac Sim** 给出一个物理与渲染都足够真实的**数字孪生**——反事实 rollout 的物理成本近零，于是「**想象**」成了一种信息动作；但它带 sim2real gap，会**自信地错**。
> - **同步定位与建图（SLAM）** 给出一张**可以回去重访**的地图——回环（loop closure）会**追溯改写过去**，漂移（drift）则是记忆的谎言。于是「**回访**」也成了一种信息动作，而锚点成了信任的地基。
>
> 核心命题：**信息动作有三种时态——问（面向未来，社交、便宜、会说谎）、演（反事实，便宜、有间隙）、回（面向过去，昂贵、可锚定）。R70 的关键不是再加一个源，而是给「源」定一个地基：模拟只有在锚定到最近物理回环过的地点后才允许投票；回答只有在能追溯到异质锚点后才算「确认」。信任的单位从「一致」升级为「可锚定的一致」。** 命名 **ECHO-RAS**（Epistemic Closure via Hypotheses, Observations & Revisits；回响）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我凭什么相信我记住的那个世界**」——不确定性不只是刹车、提问，也可以是一次「**回去看看**」。

## 0. 直觉与动机

**灵感 1（Isaac Sim → 想象是零物理成本的信息动作）**
直觉：R69 的信息动作都要在真实世界付出代价——看要转头、触要伸臂、问要打扰人。Isaac Sim 提供一条新通道：在孪生里把同一个决策**跑一千遍**，几乎不花物理成本。于是「我如果往左会怎样」可以在不冒任何真实风险的前提下先被检查。但孪生的真实性来自一个从未被彻底关闭的缺口（sim2real gap）：照片级渲染不等于照片级物理，域随机化覆盖不到的地方，孪生会给出**看起来很确定**的错误答案。所以虚拟证据只能当「假设生成器」和「风险预筛」，不能当「世界的确认」。

**灵感 2（SLAM → 记忆是可回访的，回环是对过去的追溯修正）**
直觉：R69 的信念只有「向前」的更新——观测来了，调动作。可是人类解决「我到底在哪」靠的是**回头**：走到熟悉的路口，发现「这里我来过」，于是整条路径的位姿被一次性重排。这正是 SLAM 的回环：它不只修正当前位置，还**追溯修正**过去所有位姿与地图。R69 缺少的正是一个「过去时」的贝叶斯更新通道。把回访当作信息动作，就把「我记忆里的世界是否仍然为真」变成了一道可以用 VoI 计算的题。

**灵感 3（锚定 → 正交性必须落地到「能回到同一处重测」）**
直觉：R69 说「k 个正交源一致就定案」，但「正交」是它自己声明的。两个源为什么算独立？因为它们用了不同传感器、不同会话、不同先验——而这些差异最终只有一种可操作的定义：**它们能否各自回到同一处、独立地重新测量**。能回到同一处（回环），才有资格当锚；锚之间的传感器/会话/先验越异质，才越接近正交。R70 因此把「正交」从一句假设变成一个**可测的量**（有效独立数 k_eff）。

**灵感 4（漂移-间隙对偶 → 同一件事的两个时间方向）**
直觉：SLAM 的漂移和 sim2real 的间隙，看似一个在感知、一个在仿真，其实是同一枚硬币：都是「世界模型与真实世界之间、因无法回到同一处重新测量而累积的偏差」。漂移是**记忆向后**的偏差，间隙是**想象向前**的偏差。若系统能定期回访，两者会同时被压低；若从不回访，两者会同时膨胀并**互相掩盖**——你以为是地图旧了，其实是孪生错了，反之亦然。定义 (D, ε_gap) 的联合可观测量，就能把这两种错觉分开。

**灵感 5（感知别名 → 回环可能是假的，锚点会共谋）**
直觉：这是本轮最需要正视的黑暗面。回环依赖「我认出这里」，而识别会**感知别名**——两条几乎一样的走廊、两片几乎一样的货架。一次错误的回环会把「错误的过去」锁成「确认过的真值」；更糟的是，如果孪生和地图用的是同一个有偏传感器、同一个建图先验，它们会**互相作证**：孪生说「应该是这样」，地图说「我记得就是这样」，于是系统以最高置信度进入一个错误的世界模型。R69 怕「被证实的错误」，R70 必须更怕「**被历史反复证实的错误**」——因为后者的证据看起来无懈可击。所以本轮必须同时交付：锚点异质性与有效独立数、感知别名检测、负锚点（可证伪的缺席证据）、以及「孪生与地图不得互为独立源」的共线禁忌。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（ECHO-RAS 总览）** ECHO-RAS = (DTM, VPA, TSLAM, ARB, RGG, AD, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **证据必须有锚**：任何非物理观测的证据（模拟/他人回答/先验）必须绑定至少一个锚点或显式标注「未锚定」；未锚定证据不得单独定案；
(iii) **锚点会过期**：锚点有保鲜期与漂移率，过期锚点自动降级为未锚定，必须由回访续期。

**定义 311（数字孪生 DTM）** 孪生 T = (𝒢, Θ_phys, ℛ, Δ_gap)：几何/语义场景 𝒢、物理参数 Θ_phys、渲染/传感模型 ℛ、间隙模型 Δ_gap。给定真实观测 o 与地图 M，对齐残差 e_T = d(o, ℛ(T(s_T)))。**T 是世界的条件生成模型，不是真值**；Isaac Sim 只是它的一个可并行 rollout 的实现。

**定义 312（虚拟信息动作 VPA）** g_T = (intervention, horizon)，在孪生中执行反事实 rollout，得虚拟证据 y_T = T(s_T, g_T)。物理成本 ≈ 0，但携带 sim2real gap。虚拟证据的合法用途只有两个：**生成候选假设**（供 R69 的 MINT 排序）与**预筛风险**（在真做之前淘汰明显危险的动作）；**它不能授权动作**（定义 323）。

**定义 313（锚点 Anchor）** 锚点 v = (place, sig, t_v, D_v, h_v)：地点标识、多模态签名、最近一次物理到访时刻、当前漂移估计、异质性评分。锚点的可信度由三件事决定：多模态签名（同一处被几种传感模态确认）、跨会话一致性（不同建图会话是否一致）、异质传感器（是否来自不同物理原理）。

**定义 314（TSLAM 记忆与回环修正）** 位姿图 𝒫、地图 M、回环事件 L = (i, j) 表示「位姿 i 与 j 在同一坐标系下重合」。回环触发**过去时贝叶斯修正**：对历史位姿与地图做全局优化（pose graph optimization），旧信念被追溯改写；修正量 ΔL = ‖M_after − M_before‖_Σ。R69 的更新只作用于未来动作，定义 314 补上了作用于过去的通道。

**定义 315（锚定可迁移性 AT）** ρ(T, v) = 在锚点 v 处孪生预测与真实观测的一致性（gap 的负值）。只有 ρ(T, v) ≥ τ_sim 的锚点，才允许为其邻域内的虚拟证据**担保**；担保半径 r(v) 随锚点密度与 gap 梯度收缩。

**定义 316（回响三角 / 三源证据）** 真实观测 o、虚拟证据 y_T、回访证据 y_R（在锚点重新测得）构成三角。定案规则：任意单源不足以定案；**两源一致且第三源不矛盾**才升级为「锚定确认」；三源互不一致则标记为「结构性分歧」，交审计并禁止自动定案。

**定义 317（漂移-间隙对偶 DG-Dual）** SLAM 漂移 D(t) 与 sim2real gap ε_gap 是同一偏差在两个时间方向上的投影：D 是记忆向后的偏差，ε_gap 是想象向前的偏差。二者都由「无法回到同一处重测」造成。定义联合可观测量 (D, ε_gap)：D↑ 而 ε_gap 稳定 ⇒ 记忆/里程计问题；ε_gap↑ 而 D 稳定 ⇒ 孪生/物理参数问题；同时↑ ⇒ 高概率同源退化（传感器或标定），应直接退避。

**定义 318（双预算经济 AB）** 三类预算：物理交互预算 B_phys（R69 的问/看/触）、回访预算 B_rev（重访锚点）、虚拟探测预算 B_sim。**汇率**：一次有效回访可为 N_sim 次虚拟探测「兑现」信任额度；锚点按半衰期 λ_a 衰减，额度随 t − t_v 指数缩水。这让「想象」不是免费的——它由「回去看」来付账。

**定义 319（回访 VoI / retro-VoI）** RVoI(v) = H(B_past | M) − E_{y_R}[H(B_past | M, y_R(v))]，即重访 v 对**过去地图信念**的期望熵减。选择 v* = argmax_v [RVoI(v) − c_rev(v)]，s.t. 可达、安全、预算未超。R69 的 VoI 面向未来模态 M_future，R70 的 RVoI 面向过去地图 M_past；两者共享预算框架但作用在不同的时间片上。

**定义 320（孪生-回环互校 RGG）** 孪生与地图互相校验：用地图几何约束孪生（孪生必须解释地图），用孪生反事实生成地图的**负证据**（哪里「不该有」障碍）。但**禁止二者作为锚定确认的两个独立源**——它们共享传感器与建图先验时高度共线（定义 325）。

**定义 321（锚定纪律 AD）** 定案规则从 R69 的「k 源一致」升级为「k 源一致**且**至少一个源可追溯到异质锚点」。锚点异质性 h(v) = (传感模态数, 建图会话数, 人类确认数)。达不到 h_min ⇒ 证据降级为「候选」而非「确认」。

**定义 322（负锚点 Negative Anchor）** 在锚点 v 处定义「预期的否定证据」：某类观测应当缺席（如「这堵墙应该还在」「这条通道不该有反光」）。负锚点是**可证伪性**的物理实例：模拟若预测某负锚点被违反，则孪生失配；真实观测若违反负锚点，则地图过期。它为「证明我错了」提供了廉价入口。

**定义 323（孪生想象的安全边界）** 反事实 rollout 只在安全子空间内进行；虚拟证据可以**提议**但不可以**授权**动作，且不得绕过 C-RAS-WM 前缀认证。任何由 y_T 触发的动作仍须走 R69 的认证与预算。

**定义 324（三级退避）** 若回响三角锚定确认成功 ⇒ 使用 resolution bonus（比 R69 更敢）；若未锚定/孪生失配/锚点过期/共线 ⇒ 退回 R69；若 R69 也消解不了 ⇒ 退回 R68 纯保守。⇒ 严格包含链 **R68 ⊂ R69 ⊂ R70**，安全侧永不弱于 R69。

**定义 325（共线锚点风险 / Collinear Anchor）** 若锚点 v_i, v_j 的观测来自同一传感器、同一建图会话、同一先验，则其误差相关 ρ_ij → 1，联合证据的独立信息趋于零。定义锚点信息矩阵的特征值 λ_k，有效独立数 k_eff = (Σ_k λ_k)² / Σ_k λ_k²。定案要求 k_eff ≥ 2；k_eff < 2 时，任何「多源一致」都只是**一场独白**。

**定义 326（证书 J_ECHO）** J_ECHO = (J_FLUID, anchor_ids, k_eff, AT_min, D_p95, ε_gap_p95, revisit_count, echo_ver)。Valid ⇔ Valid(J_FLUID) ∧ k_eff ≥ 2 ∧ AT_min ≥ τ_sim ∧ 锚定纪律满足 ∧ 回访/虚拟预算未越界。

# IP-264 DTM：Isaac Sim 数字孪生适配器（并行反事实 rollout，离线/异步）
class DigitalTwin:
    def __init__(self, scene, phys_params, renderer, gap_model):
        self.scene, self.theta, self.R, self.gap = scene, phys_params, renderer, gap_model
    def rollout(self, s_T, intervention, H, n_parallel):
        # 在孪生中并行跑 n_parallel 条反事实轨迹；不进入实时控制环
        return self.sim.rollout_batch(s_T, intervention, H, n_parallel)

# IP-265 VPA：虚拟探测（只产生假设与风险预筛，不授权动作）
def virtual_probe(twin, s_T, candidates, budget):
    out = []
    for g in candidates:
        if not budget.allow_sim(g): continue
        ys = twin.rollout(s_T, g, H=budget.H, n_parallel=budget.n)
        out.append((g, summarize(ys), risk_stats(ys)))
    return out                                     # 交给 MINT 排序，非授权

# IP-266 TSLAM：位姿图 + 回环 + 多会话地图 + 负锚点
class TSLAM:
    def __init__(self): self.graph, self.map, self.anchors = PoseGraph(), Map(), []
    def on_loop(self, i, j, rel_pose):
        if not self._plausible(i, j, rel_pose): return False   # 感知别名门
        self.graph.add_loop(i, j, rel_pose)
        delta = self.graph.optimize()              # 追溯改写过去
        self.map.apply(delta); self._refresh_anchors(delta)
        return True
    def negative_anchor_check(self, v, obs):       # 可证伪的缺席证据
        return all(pred(obs) for pred in v.negative_predicates)

# IP-267 ARB：锚点银行（保鲜期、异质性、有效独立数）
class AnchorBank:
    def register(self, v): self.bank.append(v)
    def freshness(self, v, t): return exp(-(t - v.t_v) / TAU_A)
    def k_eff(self, vs):                           # Σλ² 的倒数形式
        lam = eigvals(information_matrix(vs))
        return (sum(lam) ** 2) / sum(l * l for l in lam) if lam else 0.0
    def eligible(self, v, t): return self.freshness(v, t) >= TAU_FRESH and v.h_v >= H_MIN

# IP-268 RGG：现实间隙治理（AT 估计 + 担保半径）
def anchored_transferability(twin, anchor, o_real):
    y_T = twin.render_at(anchor.pose)
    return -gap_distance(y_T, o_real)              # ρ(T, v)

def trust_radius(rho, grad_gap):                   # gap 越大，担保半径越小
    return max(0.0, (rho - TAU_SIM) / (grad_gap + EPS))

# IP-269 RVOI：回访规划（过去时 VoI）
def choose_revisit(map_belief, anchors, budget):
    best = None
    for v in anchors:
        if not budget.allow_rev(v): continue
        if not c_ras_wm.certify_revisit(v): continue
        rvoi = entropy(map_belief) - expected_map_entropy(map_belief, v)
        score = rvoi - revisit_cost(v)
        if best is None or score > best.score: best = (v, score)
    return best if best and best.score > 0 else None

# IP-270 AD：锚定证据融合（k_eff 门 + 回响三角）
def anchored_fusion(o, y_T, y_R, anchors, t):
    vs = [v for v in anchors if bank.eligible(v, t)]
    if bank.k_eff(vs) < 2: return "candidate", 0.0          # 独白不算确认
    if agree(o, y_T) and not conflict(o, y_R): return "confirmed", 1.0
    if agree(o, y_R) and not conflict(o, y_T): return "confirmed", 1.0
    if not agree(y_T, y_R): return "structural_disagreement", 0.0
    return "candidate", 0.0

# IP-271 DGD：漂移-间隙对偶监控
def drift_gap_dual(D_hat, gap_hat, dD, dgap):

    if dgap > TAU_G and abs(dD) < TAU_D:   return "twin_physics"
    if dD > TAU_D and dgap > TAU_G:        return "common_cause_sensor"

# IP-273 ECHO-RAS 双时间尺度主闭环
def ECHO_RAS_round(M, obs):

    y_T = M.vpa.latest_evidence()                  # 上一慢环的虚拟证据（已过期则弃）

    # —— 快环（与 R69 同频）：实时控制不变 ——

    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4

    return k, lam, mode, (U_ale, U_epi, status)

# 慢环调度器：在预算内决定「演」还是「回」
def epistemic_scheduler(M):

## 3. 推导

**引理 19（回访的过去时信息增益）** 设地图误差 E 与回访观测 y_R(v) 的互信息为 I(E; y_R | v)。则 RVoI(v) = I(E; y_R | v)（在熵减意义下）。若 v 的观测与建图时同传感器、同会话，则 I(E; y_R|v) → 0：**同一只眼睛再看一次，不会看见新东西**。系：回访的价值来自异质性，而非次数；重复同一回环只延长保鲜期，不增加信息。

**引理 20（锚定独立数对确认错误率的抑制）** 设每个锚点被欺骗的概率为 δ_a、锚点误差相关 ρ，则 k 个锚点多数一致时的错误确认率 ≤ δ_a · ρ^{k_eff−1} + ε_σ，其中 k_eff 由定义 325 给出。与 R69 的 ρ^{k−1} 相比，R70 用**可测的 k_eff** 替换了**声明的 k**：当锚点共线时 k_eff → 1，上界退化为 δ_a（等于单源），「多源一致」不再提供任何保护。

**引理 21（孪生证据的可迁移界）** 若锚点 v 满足 ρ(T, v) ≥ τ_sim，则孪生在 v 的担保半径 r(v) 内产生的虚拟证据，其诱导的策略误差 ≤ ε_gap(v) + L_T · dist(x, v)，其中 L_T 为孪生 gap 的空间 Lipschitz 常数。系：**锚点是孪生的「保险单」**——离锚越远、锚越稀，虚拟证据越不可信；无锚区域的仿真应默认视为未锚定。

**定理 18（ECHO 严格包含 FLUID 与 CALM）** A99–A101 下，ECHO 的期望风险 ≤ FLUID ≤ CALM；且当无可用锚点、k_eff < 2、孪生失配或感知别名门拒绝时，ECHO 与 FLUID **逐指令相同**；当 FLUID 也判定 VoI ≤ 成本时，进一步与 CALM 逐指令相同。故 R68 ⊂ R69 ⊂ R70，安全侧单调不弱。

**定理 19（回环修正的局部收敛与感知别名发散）** 在回环为真且相对位姿无偏的假设下，pose graph 优化使地图误差单调下降并局部收敛；但若存在感知别名导致的**假回环**（两个不同地点被判为同一处），优化会把地图沿该约束拉伸，误差不降反升，且**错误会被写进锚点**，使后续所有「确认」建立在错误历史上。故回环必须先过感知别名门（多模态签名 + 负锚点 + 会话一致性）。

**定理 20（共线锚点不可分辨性）** 若所有锚点共享同一传感器、同一建图会话、同一先验（k_eff = 1），则「世界模型正确」与「世界模型一致地错误」在观测分布上不可分辨：不存在有限证据能把二者分开。系：**R70 的信任不能来自「更多证据」，只能来自「更异质的证据」**——这直接把「锚点异质性」从工程细节提升为可辨识性的前提。

## 4. 推导

**引理 19（回访的过去时信息增益）** `RVoI(v)=I(E;y_R|v)`。若回访与建图同传感器、同会话，则 `I→0`：同一只眼睛再看一次看不到新东西。系：回访价值来自异质性而非次数。

**引理 20（锚定独立数对确认错误率的抑制）** 每锚点被欺骗率 `δ_a`、相关 `ρ` 时，`k` 锚点多数的错误确认率 `≤ δ_a·ρ^{k_eff−1}+ε_σ`。与 R69 的 `ρ^{k−1}` 相比，R70 用**可测的 k_eff** 替换**声明的 k**；共线时 `k_eff→1`，上界退化为单源 `δ_a`。

**引理 21（孪生证据的可迁移界）** 若 `ρ(T,v)≥τ_sim`，则担保半径 `r(v)` 内虚拟证据诱导的策略误差 `≤ ε_gap(v)+L_T·dist(x,v)`。系：锚点是孪生的保险单；离锚越远越不可信，无锚区域默认未锚定。

**定理 18（ECHO 严格包含 FLUID 与 CALM）** A99–A101 下 `risk(ECHO) ≤ risk(FLUID) ≤ risk(CALM)`；无锚/k_eff<2/孪生失配/别名拒绝时 ECHO 与 FLUID **逐指令相同**；FLUID 判 `VoI≤成本` 时进一步与 CALM 相同。故 **R68 ⊂ R69 ⊂ R70**。

**定理 19（回环修正的局部收敛与感知别名发散）** 真回环且相对位姿无偏时，pose graph 优化使地图误差单调下降并局部收敛；假回环（感知别名）会把地图沿错误约束拉伸，误差反升，且错误被写进锚点，污染后续所有确认。故回环须先过别名门（多模态签名 + 负锚点 + 会话一致性）。

**定理 20（共线锚点不可分辨性）** 若所有锚点同传感器、同会话、同先验（`k_eff=1`），则「模型正确」与「模型一致地错误」在观测分布上不可分辨，不存在有限证据能分开。系：**信任不能来自更多证据，只能来自更异质的证据**。

## 7. 本轮最大风险

**一句话**：ECHO-RAS 把信任押在「锚点是真的」上，而锚点本身可能来自一次**感知别名**造成的假回环——于是孪生与地图用同一双有偏的眼睛互相作证，把 R69 的「被证实的错误」升级为「**被历史反复证实的错误**」：最危险的错误，正是一个拥有一致证据的错误。

**次级风险与缓解**：
1. **感知别名 / 假回环** → 多模态签名 + 负锚点 + 跨会话一致性门（定理 19、E304）；
2. **锚点共线（同传感器多锚点作弊）** → 有效独立数 `k_eff≥2` 硬门 + 异质性评分（定义 325、E310）；
3. **sim2real gap 被高估** → AT 估计 + 担保半径 + 虚拟证据不授权（定义 315、323、E301/E311）；
4. **慢环拖累快环** → 双时间尺度解耦，快环只读缓存（定义 318、E313）；
5. **锚点过期未察觉** → 半衰期衰减 + 漂移率记账，过期自动降级为未锚定（定义 310-iii、E306）。
