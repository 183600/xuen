# 第 69 轮（承接第 68 轮「CALM-RAS 标定感知风险自适应闭环」IP-243~252；灵感循环新循环第 2 轮；本轮灵感：「语义分割」×「传感器融合」）

> 第 68 轮把「标定」升级为在线潜变量，用自监督与单模型多任务补齐了计量层。但它自陈的最大风险是一句判决书：**若真实故障落在标定带宽之内，COF 会把它当漂移「标好」——标定能力越强，缓变故障越隐形。** 这不是实现缺陷，而是「被动残差 + 频率分离」范式的结构性盲区：只靠一条全局残差流，参数漂移与缓变故障在数学上是同一个东西（ρ = YΔθ + w），时间越长越不可分。
>
> 本轮两个灵感恰好给出破局的两种「额外维度」：
> 1. **语义分割**：它把「一个全局残差」变成「一组按物理部件组织的残差」。同一个传感器偏差会**横跨所有部件**（低秩、行结构），真实世界变化只**局域在某个部件**（稀疏、物理自洽）。语义部件不是标签，而是**测量设计矩阵的新基**。
> 2. **传感器融合**：融合的价值不是把多个读数平均成更准的一个，而是**保留它们之间的分歧**——同一物理量被 ≥2 个失效模式不同的模态独立测量时，单传感器偏差无法被共享标定参数解释。融合若只输出均值，就会成为继标定之后的**第二个吸收器**。
>
> 核心命题：
>
> **把「标定」从「用残差拟合慢变量」升级为「只在可辨识子空间内、且能跨语义锚点泛化时才允许的受权更新」；把「融合」从「加权平均」升级为「带冲突证书的、按语义部件局部的可靠性融合」——SAFE-RAS（Semantic-Anchored Fusion & identifiability-Enhanced Risk-Adaptive System）。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我的测量里，哪一部分是可辨识的？融合能否为它作证？**」

## 0. 直觉与动机

**灵感 1（语义分割 → 静止不是标定的充分条件，语义丰富才是）**
R68 用「静态段」作为自标定门控 σ_stat，直觉是「静止时各模态应给出同一答案」。但静止恰恰是缓变故障最像漂移的时刻——世界没动，残差只能被解释成「传感器歪了」。语义分割换了一个激励源：**空间语义多样性**。一个静止场景里仍有机器人连杆、末端执行器、已知几何的被操作物体、支撑面、人手等多个物理部件；它们的几何、材质、运动学约束彼此独立。同一传感器的慢偏差会同时污染所有部件（共享行），真实世界变化只污染某个部件（稀疏列）。**标定所需的不是时间上的变化，而是测量方程在部件维度上的非共线性。** 这直接把 R68 的「时间可辨识」替换为「语义可辨识」。
更关键的是，机器人自身连杆与已知物体是**物理精确锚点**：前向运动学给出了无需学习的几何真值，已知物体的 CAD 给出了形状真值。标定可以锚在「可验证」的部件上，而不是锚在「看起来静止」的整幅图上。

**灵感 2（传感器融合 → 融合既可以定位分歧，也可以吸收分歧）**
R68 的 ESO 式教训是「扰动观测器会把慢故障一起吞掉」。融合有完全同构的陷阱：等权平均把单传感器偏差摊薄成 1/K，看起来更平滑，实则把故障抹平。正确做法是**分层融合 + 显式冲突**：数据级保留各模态原始估计，特征级按语义部件对齐，决策级输出「融合值 + 冲突能量 + 参与模态」。融合的第一职责是**报告不一致**，第二职责才是给出一致估计。由此得到一条与 R68「先标定后归因」并列的新不变式：**「融合报告分歧，不吸收分歧」**。

**灵感 3（标定的真正判据是泛化，不是拟合）**
一个慢偏差究竟该叫「标定漂移」还是「传感器故障」，在单条轨迹上没有答案。差别在**泛化**：真正的标定改变（外参、焦距、时钟）会在**留出的部件/模态/工况**上同样降低残差；而局部的、条件相关的故障只能在训练锚点上被拟合，留出集上不降反升。这把 R68 的「canary 不可修复性」从一次性注入升级为**语义留出验证**：用一组部件标定，用另一组部件验收。语义分割恰好提供了天然的、稠密的分组。

**灵感 4（可辨识性 → 「不知道」必须保持不知道）**
R68 的 COF 在任何静态段都会让 Σ_c 收缩，等价于宣称「我已经标好了」。SAFE-RAS 改为：先算当前锚点集对共享标定参数的**可辨识矩阵**，只沿可辨识方向更新；不可辨识方向**保持先验方差不收缩**，并记为「可辨识性债务」I_debt。债务高 → 标定冻结、λ 下限抬升、前缀收缩、必要时主动探测。**「不知道」不是要尽快消掉的噪声，而是要原样上报的状态。**

**灵感 5（合流 → SAFE-RAS 六组件）**
1. **SAG Semantic Anchor Graph**：持久语义部件 + 跨模态对应 + 物理锚点；
2. **SRD Structured Residual Decomposition**：把残差张量分解为低秩慢偏差 / 稀疏世界变化 / 头相关模型漂移；
3. **IOF Identifiability-gated Observation Filter**：COF 的继任者，投影卡尔曼 + 可辨识性门控 + 留出验证；
4. **SRF Semantic Reliability Fusion**：按部件/模态的可靠性融合 + 冲突证书；
5. **SDC Semantic Discrepancy Certificate**：跨模态语义一致性自监督（零标签）；
6. **RAS-WM†† 继承核**：R68 的 MTM/SSG/CAC/EFS/C-RAS-WM 全部保留，仅 COF→IOF、CFA→ICA、融合层被替换。

## 1. 形式化定义（增量：定义 293–310）

**定义 293（SAFE-RAS 总览与四不变式）** SAFE-RAS = (SAG, SRD, IOF, SRF, SDC, ICA, CAS, ASP, RAS-WM††)。四不变式：
(i) **实时流零学习写操作**（继承 R68）；
(ii) **无辨识不标定**：仅当方向 v 的可辨识边界 μ_c(v) ≥ μ_0 且通过留出锚定验证与慢故障 canary 时，才允许更新 ĉ 的 v 分量；否则冻结并计入 I_debt；
(iii) **融合报告分歧**：融合输出必须携带逐部件冲突能量 E_conf，冲突超阈时禁止静默平均；
(iv) **不确定只收紧**：任何来源（标定、辨识、语义、融合）的不确定性都只抬高 λ 下限、收缩前缀，绝不放宽。

**定义 294（语义锚定图 SAG）** SAG_t = (V_t, E_t, W_t, Φ)。节点 v=(part_id, modality) 是持久跟踪的语义部件；边 e 是跨模态对应（视觉像素 ↔ 触觉接触区 ↔ 力作用点 ↔ 深度面片）；权重 w_{p,i} ∈ [0,1] 是锚点信任；Φ ⊆ V 是**物理锚点集**：机器人连杆（前向运动学真值）、已知 CAD 物体、支撑平面。每个锚点带测量设计矩阵 A_v = [H_v | J_v | I]。SAG 同时提供三类留出划分：留一部件、留一模态、留一工况。

**定义 295（跨模态语义头与对应）** 对模态 i ∈ {rgb, depth, tactile, force-onset, proprio-render}，s_i = seg_i(obs_i) ∈ Δ^{|L|}，L = {robot_link, end_effector, object_k, support, human, void, unknown}。对应算子 corr: (s_i, s_j) → 部件级匹配。`void/unknown` 是一等公民：**允许弃权，禁止强制稠密解释**。锚点信任 w_{p,i} = g(分割置信, 跨模态一致, SRD 偏差分)。

**定义 296（结构化残差张量）** R ∈ ℝ^{|P|×M×K}，K=3 族：
- 几何族：同一部件在不同模态下的位姿/形状残差；
- 语义边界族：R_sem = divergence(∂s_i, ∂s_j)（边界对齐）；
- 物理族：接触/力/运动学可行性残差。
R_{p,i,k}(t) = 该部件该模态该族的标定后残差。

**定义 297（SRD 结构化残差分解）** 求解
min_{L,S,E} ‖L‖_* + λ₁‖S‖₁ + λ₂‖D_t L‖₁ + λ₃‖E‖_F²
s.t. R = L + S + E，S ∈ 𝒮_phys（稀疏于部件、且每个非零部件满足刚体/接触物理一致性），L 在部件维低秩、在时间维平滑。
语义：L 的列（按传感器）是**共享于所有部件的慢偏差签名**；S 的非零支撑是**局域世界变化**；残差中与 MTM 头相关、跨部件共模的部分记为模型漂移 M_h。输出 (L̂, Ŝ, M̂_h)。

**定义 298（可辨识性矩阵、边界与债务）** 线性化测量：δy_{a,i} = J_{a,i}δx_a + H_{a,i}δc + δb_i + ε。令 N = span{J} ⊕ span{I_i} 为「世界变化 + 单传感器偏差」张成的 nuisance 子空间，P_N 为其正交投影。可辨识矩阵 M_id = P_{N^⊥}H（对锚点与模态堆叠），μ_c = σ_min(M_id)。可辨识子空间 V_id = 奇异值 ≥ μ_0 的右奇异子空间；**可辨识性债务** I_debt = 1 − tr(P_{V_id}Σ_c^0P_{V_id}) / tr(Σ_c^0) ∈ [0,1]，即先验方差中**不被任何当前锚点约束**的比例。

**定义 299（IOF 投影卡尔曼）** 预测 c⁻=ĉ, Σ⁻=Σ+Q_cal；增益 K = Σ⁻Hᵀ(HΣ⁻Hᵀ+R)⁻¹；**投影增益** K_id = P_{V_id}K；更新 ĉ ← ĉ + K_id ν；协方差协方差先沿 V_id 更新，再把 V_id^⊥ 块**恢复为先验**（保证债务方向的方差永不收缩）。若 μ_c < μ_0：整步冻结，输出 freeze=True。另设留出闸门：在 A_train 上拟合、在 A_test 上验证，泛化比 η = Δres_test / Δres_train ≥ η_0 才授权。

**定义 300（语义可靠性融合 SRF）** 逐部件、逐模态权重 w_{p,i} 来自 SRD 偏差分与锚点信任；ŷ_p = (Σ_i w_{p,i}R_{p,i}⁻¹)⁻¹ Σ_i w_{p,i}R_{p,i}⁻¹ŷ_{p,i}。融合输出三元组 (ŷ_p, E_conf,p, 参与模态集)。可靠性是**局部**的：同一传感器可对近物可信、对远物不可信。

**定义 301（冲突能量与防掩蔽不变式）** E_conf,p = [Σ_{i<j} w_{p,i}w_{p,j}(ŷ_{p,i}−ŷ_{p,j})ᵀ(R_{p,i}+R_{p,j})⁻¹(ŷ_{p,i}−ŷ_{p,j})] / [Σ_{i<j} w_{p,i}w_{p,j}]。E_conf,p > τ_conf ⇒ 该部件标记 ambiguous，禁止静默平均，冲突上报并在 ICA 中作为「不可归因」证据。

**定义 302（跨模态语义一致性自监督 L_sem）** L_sem = λ_b·Σ_{i<j} divergence(∂s_i, ∂s_j) + λ_p·Σ_p 1[E_conf,p>τ]·‖ŷ_p − ŷ_p^pred‖² + λ_v·L_VICReg(z)。全部零人工标签；视觉失焦/曝光漂移会破坏边界一致性，而触觉/深度分割不受该失效模式影响——这是一次**独立的物理投票**。

**定义 303（CAS 标定授权封条）** 方向 v 的更新需同时满足：
1. μ_c(v) ≥ μ_0；2. 留出泛化比 η(v) ≥ η_0；3. **慢故障 canary**：数字孪生回放中向单模态注入频率 ≤ ω_cal 的慢偏差，要求吸收率 < ε_abs（若把 canary 当标定「修好」则一票否决）；4. 红线（继承 R68：|b_F|≤5%FS、‖δR‖≤2°、|Δt|≤20ms）未越界。任一不过 → 该方向冻结、I_debt 上升。

**定义 304（红线的可辨识性版本）** 红线本身只在 V_id 上有意义：不可辨识方向上无法判定是否越界，故一律按「疑似越界」处理（冻结 + λ 抬升），直到主动探测或绝对参考补足可辨识性。

**定义 305（CAR† 阈值重参数化）** 区分两类不确定：
τ_wm = τ⁰_wm·(1 + κ_w·U_cal)·1[I_debt ≤ τ_id]（仅标定残差不确定时适度放宽一致性检验，防误报；债务高时不放宽）；
τ_temporal 同理；
τ_risk = τ⁰_risk·(1 − κ_r·U_cal − κ_id·I_debt)（两类都收紧风险）。
关键：**I_debt 绝不放宽检测**，只收紧风险并冻结标定。

**定义 306（λ_floor†）** λ_floor = max(0.6, 0.8·1[U_cal>τ_cal ∨ I_debt>τ_id ∨ E_conf>τ_conf ∨ U_sem>τ_sem])，并承接 R66/R67 的 face_unobservable / wm_drift 纪律。

**定义 307（ASP 主动语义探测）** 仅当 I_debt > τ_id 且风险预算允许时，从受限动作集（转头、转腕、轻触、移动已知物体、改变视角）中选
a* = argmax_a E[ΔI_debt(a)] / (risk(a)+ε)，
且 k*RAS 先行收缩；探测失败立即回退 k=0。**用少量安全的主动信息换取可辨识性，而不是用更多被动时间去赌。**

**定义 308（ICA 可辨识性感知归因）** H_sensor 拆为 H_cal^id（已授权可辨识）、H_cal^unid（冻结不可辨识）、H_sensor^trans（真实故障）：
P(H,E | ρ, face, ĉ, U_cal, I_debt, E_conf, V_id) ∝ p(ρ | H, ĉ, V_id)·p(face | E, ĉ_face)·P(H)·P(E|H)。
p(ρ|H_cal^id,·) 用投影后残差；p(ρ|H_cal^unid,·) 用「未知」先验且不允许吸收；p(ρ|H_sensor^trans,·) 用 SRD 的 Ŝ 与冲突。I_debt 高时不做 argmax，而输出最坏情况集合。

**定义 309（AIC-SAFE 干扰集）** ℰ_SAFE = ℰ_CALM × ℰ_sem × ℰ_id × ℰ_fuse；
ℰ_sem = {分割漂移、对抗贴片、域外物体、锚点陈旧}；
ℰ_id = {语义多样性不足、共模慢故障、留出泄漏}；
ℰ_fuse = {冲突掩蔽、权重投毒、伪对应}。

**定义 310（J_SAFE 证书与管线）** J_SAFE = (J_CALM, sag_hash, V_id_hash, μ_c, I_debt, anchor_trust_vec, heldout_verdict, canary_verdict, conflict_vec, safe_ver)。Valid ⇔ Valid(J_CALM) ∧ μ_c/η/Canary 全过 ∧ 红线未越界。离线：语义预训练 → SRD 预训练 → 锚点标定 → CAS 首次授权；在线：每帧 IOF/SRF/SRD，每 60s 影子训练 + CAC 五关 + 语义留出复核。

```python
# IP-253 SAG：语义锚定图（物理锚点 + 跨模态对应 + 留出划分）
class SemanticAnchorGraph:
    def update(self, obs, z):
        s = {m: self.seg[m](obs[m]) for m in self.modalities}   # 各模态分割
        corr = self.match(s)                                    # 像素/接触/力点对应
        trust = self.trust(s, corr, self.srd.bias_score)        # 锚点信任
        splits = self.leave_one_out(corr)                       # 留部件/留模态/留工况
        return SAG(s, corr, trust, self.physical_anchors, splits)

# IP-254 SRD：结构化残差分解（低秩慢偏差 + 稀疏世界变化 + 头漂移）
class StructuredResidualDecomposition:
    def decompose(self, R):                      # R[p,i,k] over window
        L, S, E = robust_pca_tv(R, lam=[1, 0.1, 0.1])
        S = self.physical_project(S)             # 投影到刚体/接触可行集
        M = self.head_drift(R - L - S)           # 与 MTM 头相关的共模
        return L, S, M

# IP-255 IOF：可辨识性门控投影卡尔曼（COF 继任者）
class IdentifiabilityObservationFilter:
    def step(self, z_cal, R, S, sag):
        self.predict()
        M_id, V_id, mu_c = identifiability(sag, self.c)      # 定义 298
        I_debt = self.debt(V_id)
        if mu_c < MU0:
            return self.freeze(), I_debt, {'authorized': False}
        K = self.kalman_gain(R)
        K_id = project(K, V_id)                              # 只沿可辨识方向
        self.update_projected(K_id)
        self.restore_nullspace_prior(V_id)                   # 债务方向永不收缩
        if not self.heldout_pass(V_id):                       # 留出泛化闸门
            self.freeze(V_id); I_debt = self.debt(V_id)
        return self.c, I_debt, {'authorized': True, 'mu_c': mu_c}

# IP-256/257 SRF + SDC：可靠性融合 + 冲突证书
class SemanticReliabilityFusion:
    def fuse(self, sag, o, L):
        out = {}
        for p in sag.parts:
            w = {i: self.weight(sag, p, i, L) for i in sag.modalities_of(p)}
            y = self.weighted_fuse(w, o, p)
            conf = self.conflict_energy(w, o, p)             # 定义 301
            out[p] = (y, conf, w.keys())
        return out

# IP-258 CAS：留出验证 + 慢故障 canary + 授权封条
class CalibrationAuthorizationSeal:
    def authorize(self, v, iof, sag, twin):
        if not iof.mu_c(v) >= MU0: return False
        if not iof.heldout_pass(v): return False
        if twin.absorbed_slow_fault(v) >= EPS_ABS: return False   # 一票否决
        if not red_lines_ok(v): return False
        return True

# IP-263 主闭环：SAFE-RAS round
def SAFE_RAS_round(M, obs):
    x_prime = M.lsf.fuse(M.usr.fuse(*obs[:4]))
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)
    sag = M.sag.update(obs, z)                             # 1) 语义锚定
    R = M.residual_tensor(x_prime, o, sag)                 # 2) 残差张量
    L, S, Mh = M.srd.decompose(R)                          # 3) 结构分离
    c, I_debt, auth = M.iof.step(o['cal'], R, S, sag)      # 4) 可辨识标定
    fused = M.srf.fuse(sag, o, L)                          # 5) 融合 + 冲突
    wm_preds = M.mtm.rollout(z, M.ach.propose_actions(x_prime, 5))
    wm_drift = kl_div(o['pi'], wm_preds[0]['pi']) > thr_wm(I_debt)
    rho = M.fir_signature(z, M.residual_log)
    joint = M.ica(rho, o['pi'], c, I_debt, fused)          # 6) 可辨识归因
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, joint, min(M.vista.m, M.m_emo),
                                    M.alpha_chunk, wm_preds)
    if I_debt > TAU_ID: k = min(k, k_id_shrink(A, I_debt))
    lam = max(M.efs.risk_scale(joint),
              lam_floor(I_debt, fused, wm_drift, o['qual']['face']),
              0.8 if (o['qual']['face'] < 0.8 or wm_drift) else 0.6)
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam
    tau = emotion_response_shaping_wm(tau, joint, wm_preds)
    if I_debt > TAU_ID and M.asp.allowed(k, lam):
        M.asp.request_probe(sag, I_debt, risk=1-lam)       # 7) 主动探测
    M.vqa_c.submit_async(wm_preds, {'id': (I_debt, auth), 'conflict': fused})
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)
    return k, lam, joint, (c, I_debt, fused)
```

## 3. 推导

**引理 16（语义可辨识性维数界）** 设每个锚点 a 的 nuisance 投影为 P_{N_a^⊥}，共享标定回归为 H_a。令 G = (1/|P|)Σ_a P_{N_a^⊥}H_aH_aᵀP_{N_a^⊥}。在锚点非相干假设 A96（‖H_a‖≤h_max，锚点对间夹角余弦 ≤ cosθ）下：
μ_c² = λ_min(G) ≥ c_h·h_max²·(1 − (|P|−1)cosθ)。
故 **μ_c 随语义锚点的几何/运动多样性增长，随锚点共线性衰减**；|P|=1 或所有锚点同构时 μ_c=0（R68 的单一全局残差正是此退化情形）。系：可辨识性是**当前语义锚点集的性质**，不是时间的性质；静止但语义丰富的场景优于运动但单一部件的场景。

**引理 17（结构化残差可分离性）** 设 R = L₀+S₀+E，L₀ 秩 r、时间平滑，S₀ 每列支撑 ≤ s 且满足 𝒮_phys，噪声 ‖E‖_F ≤ σ。在标准非相干条件（L₀ 列空间与稀疏支撑基不相干度 μ）与 |P|M ≥ Cμ²r·max(1, log²(|P|M))、s ≤ c|P|M/(μ²r) 下，robust PCA + TV 以概率 ≥ 1−δ 恢复 L₀ 与支撑，误差 ‖L̂−L₀‖_F + ‖Ŝ−S₀‖_F ≤ C'σ√(|P|M)。语义解读：**传感器偏差是跨部件的低秩行，世界变化是部件稀疏列；二者的支撑结构不同，故可分离。** 若语义多样性不足（|P| 小、部件同构），非相干条件退化，分离失败——此时 I_debt 必须升高，而不是硬分。

**引理 18（融合冲突下界与防掩蔽）** 设模态 i 有偏差 b、模态 j 无偏、协方差同量级 σ²。则 E_conf,p ≥ ‖b‖²/(2σ²)。等权均值误差为 b/K（K 为模态数），但**分歧并未消失**；只有当融合器丢弃分歧、只输出均值时才会掩蔽故障。因此定义 301 的「冲突必报」不变式使 P(mask)=0；可靠融合相对单模态的方差降为 (Σ_i R_i⁻¹)⁻¹，且 E_conf 提供独立的故障检验统计量。**融合不是消噪器，而是分布式假设检验器。**

**引理 19（留出锚定的过拟合判别力）** 设 Δ_train、Δ_test 为训练/留出锚点上的残差下降。若真实原因是共享标定 c*，则 E[Δ_test] ≥ E[Δ_train] − O(√(log(1/δ)/n_test))；若真实原因是单传感器偏差 b_i，则任何共享 c 在留出锚点（由其他模态测量）上的下降 ≤ η·Δ_train，其中 η 是 b_i 与共享标定子空间的重叠度。故以 η_0 为阈可判别「标定 vs 故障」；当 η≈1（偏差几乎落在共享子空间）时判别力消失——这正是共模慢故障的边界（命题 1）。

**命题 1（共模慢故障的不可辨识性）** 若存在 δc_eff 使对所有锚点 a、模态 i 有 b_i(t) = H_{a,i}δc_eff(t)，且该关系在所有工况成立，则观测分布与「标定发生 δc_eff 漂移」完全同分布，任何仅依赖观测的估计器都无法区分二者。**结论：共模慢故障必须依赖绝对外部计量参考（固定 fiducial、外部时钟、已知环境基准）或跨工况不变性先验，不能靠更多残差或更强模型解决。** 这是本轮方案的能力边界，必须写进证书。

**定理 16（SAFE-RAS 端到端风险一致性）** 在 A87–A96 下：
1. P(|τ_cmd−τ*|>ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal^id + α_id + α_sem + α_fuse；
2. α_id = 0（授权不变式 ii 使不可辨识方向绝不更新）；α_fuse = 0（冲突必报不变式 iii）；但 **α_sem = P(锚点/分割错误导致错误的可辨识性/归因) ≤ δ_seg + δ_corr** 不可消去；
3. I_debt > τ_id ⇒ 标定冻结 ∧ λ_risk ≥ 0.8 ∧ k 收缩 ∧ 触发 ASP，测量不可信永远导向收缩；
4. 风险并未消失，而是**从 α_cal 守恒地转移到 α_sem**——这是本轮范式的真实代价（见第 6 节）。

**定理 17（慢故障不可吸收二分）** 在 A92（故障频率 ≤ ω_cal）与 A96 下，对**单传感器**慢故障 b_i：
- 若 μ_c ≥ μ_0：b_i 位于 nuisance 子空间，被 P_{V_id} 投影剔除，不进入 ĉ；同时 SRD 的 L̂_{·,i}≠0 给出检出；
- 若 μ_c < μ_0：IOF 冻结，I_debt 高企，λ≥0.8、k 收缩，故障以残差形式保留而非被吸收。
故 P(b_i 被静默吸收) ≤ P(分割/对应错误) + P(共模)，即 R68 的「标定吸收」通道在单传感器故障上被关闭；剩余通道是 α_sem 与命题 1 的共模边界。

## 6. 本轮最大风险

**一句话**：SAFE-RAS 把「标定吸收」换成了「语义吸收」——**若语义分割本身漂移或幻觉（域外物体、遮挡、对抗贴片），它给出的稠密锚定会「自信地错」：错误对应可让共享慢故障落进校准、或让真实世界变化被误判为传感器偏差；更致命的是分割头与标定头共享 R68 的 MTM trunk，使「可辨识性证书」自我认证（分割与标定误差同源相关），系统将以「语义已解释」为名重新获得吸收能力，且这次连残差都不再剩下。**

**次级风险与缓解**：
1. **共模慢故障不可辨识**（命题 1）→ 绝对计量参考（外部时钟/固定 fiducial）+ 跨工况不变性先验，并在 J_SAFE 中显式标注「无绝对参考」；
2. **语义-标定同源相关** → 分割与标定走不同 adapter、对分割做 stop-gradient、锚点信任仅由跨模态物理一致给；
3. **锚点陈旧/域移** → void 弃权 + 信任衰减 + 留一部件验证，禁止在 `unknown/void` 上授权；
4. **SRD 在低多样性场景失效** → I_debt 升高即冻结，绝不硬分；
5. **延迟超预算** → 关键帧 + 掩码传播 + 显式 U_sem 计入，不隐藏成本；
6. **对抗语义贴片** → 多模态独立投票 + 物理锚点优先（连杆/CAD）+ 慢故障 canary 一票否决。

**定义 299（IOF）** 投影增益 K_id=P_{V_id}K；协方差沿 V_id 更新、V_id^⊥ 块恢复先验（债务方向永不收缩）；μ_c<μ_0 冻结；留出泛化比 η≥η_0 才授权。

**定义 300–301（SRF 与冲突）** 逐部件局部权重 w_{p,i}；融合输出 (ŷ_p, E_conf,p, 参与模态)；E_conf,p>τ_conf ⇒ ambiguous、禁止静默平均、冲突上报 ICA。意义：**融合是分布式假设检验器，不是消噪器**。

**定义 302（L_sem）** 跨模态边界一致性 + 冲突部件一致性预测 + VICReg；零标签。视觉失焦/曝光漂移破坏边界一致性，触觉/深度不受该失效模式影响——独立物理投票。

**定义 303（CAS 授权封条）** 四关：μ_c(v)≥μ_0；η(v)≥η_0；慢故障 canary 吸收率<ε_abs（被「修好」即一票否决）；红线未越界。任一不过 → 冻结 + I_debt 上升。

**定义 304（红线可辨识版）** 不可辨识方向上无法判定红线，按「疑似越界」处理（冻结 + λ 抬升），直到 ASP 或绝对参考补足。

**定义 305–306（CAR†/λ_floor†）** τ_wm=τ⁰_wm(1+κ_wU_cal)·1[I_debt≤τ_id]；τ_risk=τ⁰_risk(1−κ_rU_cal−κ_idI_debt)；λ_floor=max(0.6,0.8·1[U_cal>τ_cal ∨ I_debt>τ_id ∨ E_conf>τ_conf ∨ U_sem>τ_sem])。**I_debt 绝不放宽检测。**

**定义 307（ASP）** I_debt>τ_id 且风险预算允许时，a*=argmax E[ΔI_debt]/(risk+ε)，动作集受限，失败回退 k=0。

**定义 308（ICA）** H_sensor 拆 H_cal^id / H_cal^unid / H_sensor^trans；p(ρ|H_cal^unid,·) 用未知先验且禁止吸收；I_debt 高时输出最坏情况集合而非 argmax。

**定义 309–310（AIC-SAFE / J_SAFE）** ℰ_SAFE=ℰ_CALM×ℰ_sem×ℰ_id×ℰ_fuse；J_SAFE 含 sag/V_id/μ_c/I_debt/anchor_trust/heldout/canary/conflict；Valid ⇔ J_CALM 有效 ∧ 四关全过 ∧ 红线未越界。

## 3. 关键算法伪代码

```python
# IP-253/254 SAG + SRD
def semantic_structure(obs, z, srd):
    s = {m: seg[m](obs[m]) for m in modalities}         # 含 void/unknown 弃权
    corr = match(s)                                      # 像素/接触/力点对应
    trust = g(conf(s), cross_modal_agree(corr), srd.bias)
    splits = leave_one_out(corr)                         # 留部件/留模态/留工况
    return SAG(s, corr, trust, physical_anchors, splits)

def srd(R):
    L, S, E = robust_pca_tv(R, lam=(1, 0.1, 0.1))
    S = project_physical(S)                              # 刚体/接触可行集
    Mh = head_drift(R - L - S)
    return L, S, Mh

# IP-255 IOF：投影卡尔曼 + 门控 + 留出
def iof_step(cof, z_cal, R, S, sag):
    cof.predict()
    M_id, V_id, mu_c = identifiability(sag, cof.c)
    I_debt = debt(V_id, cof.S0)
    if mu_c < MU0: return cof.freeze(), I_debt, False
    K_id = project(cof.gain(R), V_id)
    cof.update(K_id); cof.restore_nullspace_prior(V_id)
    if not heldout_pass(V_id): cof.freeze(V_id); I_debt = debt(V_id, cof.S0)
    return cof.c, I_debt, True

# IP-256/257 SRF + SDC
def reliability_fusion(sag, o, L):
    out = {}
    for p in sag.parts:
        w = {i: weight(sag, p, i, L) for i in sag.mods(p)}
        y = weighted_fuse(w, o, p)
        out[p] = (y, conflict_energy(w, o, p), set(w))
    return out

# IP-258 CAS：四关授权
def authorize(v, iof, sag, twin):
    return (iof.mu_c(v) >= MU0 and iof.heldout_pass(v)
            and twin.absorbed_slow_fault(v) < EPS_ABS and red_lines_ok(v))

# IP-263 主闭环
def SAFE_RAS_round(M, obs):
    x_prime = M.lsf.fuse(M.usr.fuse(*obs[:4]))
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)
    sag = semantic_structure(obs, z, M.srd)
    R = M.residual_tensor(x_prime, o, sag)
    L, S, Mh = srd(R)
    c, I_debt, auth = iof_step(M.iof, o['cal'], R, S, sag)
    fused = reliability_fusion(sag, o, L)                # 冲突随输出上报
    wm_preds = M.mtm.rollout(z, M.ach.propose_actions(x_prime, 5))
    wm_drift = kl_div(o['pi'], wm_preds[0]['pi']) > tau_wm(I_debt)
    joint = M.ica(M.fir_signature(z, M.residual_log), o['pi'], c, I_debt, fused)
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, joint, min(M.vista.m, M.m_emo),
                                    M.alpha_chunk, wm_preds)
    if I_debt > TAU_ID: k = min(k, k_id_shrink(A, I_debt))
    lam = max(M.efs.risk_scale(joint),
              lam_floor(I_debt, fused, wm_drift, o['qual']['face']),
              0.8 if (o['qual']['face'] < 0.8 or wm_drift) else 0.6)
    tau = emotion_response_shaping_wm(
        M.pi_sigma.prefix_dispatch(A[:k]) * lam, joint, wm_preds)
    if I_debt > TAU_ID and M.asp.allowed(k, lam):
        M.asp.request_probe(sag, I_debt, risk=1-lam)
    M.vqa_c.submit_async(wm_preds, {'id': (I_debt, auth), 'conflict': fused})
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)
    return k, lam, joint, (c, I_debt, fused)
```

## 4. 推导

**引理 16（语义可辨识性维数界）** G=(1/|P|)Σ_a P_{N_a^⊥}H_aH_aᵀP_{N_a^⊥}；A96（‖H_a‖≤h_max、锚点夹角余弦≤cosθ）下 μ_c²=λ_min(G)≥c_h h_max²(1−(|P|−1)cosθ)。故 μ_c 随语义多样性增长、随锚点共线性衰减；|P|=1 或同构锚点时 μ_c=0。**可辨识性是当前锚点集的性质，不是时间的性质**：静止而语义丰富的场景优于运动而单一部件的场景。

**引理 17（结构化残差可分离性）** R=L₀+S₀+E，L₀ 秩 r 且时间平滑，S₀ 每列支撑 ≤s 且 ∈𝒮_phys。在非相干度 μ、|P|M≥Cμ²r·max(1,log²(|P|M))、s≤c|P|M/(μ²r) 下，robust PCA+TV 以概率 ≥1−δ 恢复 L₀ 与支撑，误差 ≤C'σ√(|P|M)。语义解读：**慢偏差是跨部件低秩行，世界变化是部件稀疏列，支撑结构不同故可分**；语义多样性不足时非相干条件退化，必须由 I_debt 上报而非硬分。

**引理 18（融合冲突下界与防掩蔽）** 单模态偏差 b、另一模态无偏、协方差同量级 σ² ⇒ E_conf,p≥‖b‖²/(2σ²)。等权均值误差 b/K，但分歧仍在；只有丢弃分歧才会掩蔽。故「冲突必报」不变式使 P(mask)=0。可靠融合方差降为 (Σ_iR_i⁻¹)⁻¹，E_conf 是独立检验统计量。

**引理 19（留出锚定判别力）** 若真因是共享标定 c*：E[Δ_test]≥E[Δ_train]−O(√(log(1/δ)/n_test))；若真因是单传感器偏差 b_i：留出下降 ≤η·Δ_train，η=偏差与共享子空间重叠度。以 η_0 为阈判别标定/故障；η≈1 时判别力消失 = 共模边界。

**命题 1（共模慢故障不可辨识性）** 若存在 δc_eff 使 b_i(t)=H_{a,i}δc_eff(t) 且所有工况成立，则观测分布与「标定漂移 δc_eff」完全同分布，任何仅依赖观测的估计器无法区分。**共模慢故障必须依赖绝对外部计量参考或跨工况不变性先验**；这是本方案的能力边界，须写入 J_SAFE。

**定理 16（端到端风险一致性）** A87–A96 下：
1. P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal^id+α_id+α_sem+α_fuse；
2. α_id=0（授权不变式）、α_fuse=0（冲突必报），但 **α_sem≤δ_seg+δ_corr 不可消去**；
3. I_debt>τ_id ⇒ 冻结 ∧ λ≥0.8 ∧ k 收缩 ∧ 触发 ASP；
4. 风险守恒：**从 α_cal 转移到 α_sem**，这是本范式的真实代价。

**定理 17（慢故障不可吸收二分）** 对单传感器慢故障 b_i：μ_c≥μ_0 时 b_i∈N，被 P_{V_id} 剔除且 SRD 检出 L̂_{·,i}≠0；μ_c<μ_0 时 IOF 冻结、债务高企、λ≥0.8、故障保留为残差。故 P(静默吸收)≤P(分割/对应错误)+P(共模)。R68 的单传感器吸收通道被关闭，剩余通道是 α_sem 与命题 1。

## 7. 本轮最大风险

**一句话**：SAFE-RAS 把「标定吸收」换成了「语义吸收」——**若语义分割本身漂移或幻觉（域外物体、遮挡、对抗贴片），其稠密锚定会「自信地错」：错误对应可让共享慢故障落进校准、或让真实世界变化被误判为传感器偏差；更致命的是分割头与标定头共享 R68 的 MTM trunk，使「可辨识性证书」自我认证（分割与标定误差同源相关），系统将以「语义已解释」为名重新获得吸收能力，且这次连残差都不再剩下。**

**次级风险与缓解**：共模慢故障不可辨识（命题 1）→ 绝对计量参考 + 跨工况不变性先验，J_SAFE 显式标注；语义-标定同源 → 独立 adapter + stop-gradient + 锚点信任只由跨模态物理一致给；锚点陈旧/域移 → void 弃权 + 信任衰减 + 留一部件验证；低多样性下 SRD 失效 → I_debt 上报即冻结；延迟超预算 → 关键帧 + 传播 + U_sem 计费，不隐藏成本；对抗贴片 → 多模态独立投票 + 物理锚点优先 + 慢故障 canary 一票否决。
