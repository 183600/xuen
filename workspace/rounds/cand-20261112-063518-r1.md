# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「数据标注」×「移动底盘」）

> 第 57 轮把安全的赌注从"模型置信"换到"证据质量"，用 MFSL 摊销先验、XMC 分账对账、PTM 单向有界信任补上三条腿，却在自陈风险里把矛头指向**语料本身**：元训练集 𝒟_meta={(R_j,O_j,θ̂_j)} 被当成给定的真值，可 θ̂_j 从何而来、谁标的、标得准不准、有没有标到真正危险的区域，全程未审。本轮两个灵感正面拆这个黑箱：**数据标注**指出 θ̂ 不是真值，而是带来源、歧义、噪声与覆盖的标注——元先验的质量上限由标注质量与覆盖决定，且任何自动标注都会自我确认；**移动底盘**指出这些标注根本不是"外部廉价数据"，而是底盘用自己在危险中"跑出来"的自标注——"可通行"是"地形×底盘构型×载荷×步态"的联合谓词，而语料被幸存者偏差系统性截断：危险的区域要么没敢标，要么标它的机器人没回来。于是第 57 轮的"坏先验普遍"获得了一个可操作的具体病因：**坏语料 = 坏标签 + 有偏覆盖 + 自证闭环**。本轮把安全赌注由"元先验质量"改押在 **"标注可溯源、覆盖可审计、语义随底盘而变、伪标签不自我确认"** 上，核心命题升级为 **"标签说得清、危险没被幸存者藏起来、承诺只对本构型成立的证据说可信"**。

核心矛盾：
- **H29（标注 vs 真值）**：元先验的校准是对"标签"校准，不是对"物理世界"校准；标注含噪声、歧义、协议偏差与来源偏差，标签噪声给校准能力设了一个**地板**。把标签当标签、把分歧当区间，会牺牲效率；把标签当真值，则共形覆盖再漂亮也只是"对错的答案很一致"。
- **H30（覆盖 vs 幸存者偏差）**：语料由"跑过并安全返回"的经历累积而成，正好系统性缺少最危险的地形——模型在"看起来熟悉却没被标过"的区域最自信，而这种缺失既不在 OOD 门的分布外检测里，也不在共形残差里，因为**危险被删失（censored）了**，不是被观测到了。
- **H31（标签语义 vs 底盘构型）**："可通行"不是地形的单变量属性：同一片碎石对轮式底盘是陷阱、对高离地四足是走廊；同一四足空载能过、满载会陷。点探针与区域级 b_r 都把一个"足迹×载荷×步态"的联合谓词压缩成标量，跨平台迁移标签就是无声的语义偷换。
- **H32（自标注 vs 自证）**：底盘的滑移/俯仰/电流既是标注通道，也是被控制器选择出来的结果；自动驾驶式"模型预标注 + 人工确认"还会让元模型训练在自己的输出上。标注者与被告是同一套策略，标注行为本身又是带风险的动作——不能靠"亲身体验"去标注不可逆危险。

## 0. 直觉与动机

**灵感 1（数据标注 → 标注契约、噪声校准、分歧即区间）**
直觉：元学习把先验从"老师划重点"换成了"从历年真题里摊销"，可没人检查真题的答案是谁写的、有没有印错。数据标注的第一课是：**标签是测量，不是真值**。每一条 θ̂ 都应带标注契约——谁标的（人/仿真/本体自标注）、按什么协议、用什么仪器与底盘构型、何时标、以及与谁分歧。于是 MFSL 的校准契约要从"对 θ̂ 校准"改成"在已知/有界标签噪声 T_p(y'|y) 下对隐变量 y 的鲁棒共形校准"；标注者的分歧不被平均掉，而是保留成**歧义区间**，下游用区间而不是用单点。安全的赌注因此从"元模型多准"挪到"标签噪声是否被诚实建模"。

**灵感 2（数据标注 → 覆盖审计与幸存偏差校正）**
直觉：真正让元先验"普遍地坏"的不是随机噪声，而是**删失**——最该被标注的危险样本，恰恰因为危险而没有进入数据集。这在标注学里叫覆盖偏差/幸存者偏差。对策不是再训一个更强的 OOD 门（它只认"没见过的新模式"，认不出"见过却没标过的空格"），而是把**覆盖本身变成一等公民**：为"地形×底盘×载荷"分层维护覆盖证书与覆盖债务，用标注倾向的逆概率加权（IPW）校正校准集，把"在支撑集内但未被标注/被删失"单列为 **coverage-OOD**。覆盖未认证的分层，元先验只能用于保守动作，不能进入不可逆承诺。

**灵感 3（移动底盘 → 构型相对可通行性、足迹/路径提升、包络证书）**
直觉：底盘不是"长着相机的点"，而是有足迹、离地间隙、质心、悬挂、轮胎与步态的身体。"可通行"真正的自变量是 (地形, 构型 c, 载荷 m, 步态 g)，所以标签必须写成 p(x,y;c,m,g)，信念原子也要从"区域 b_r"下沉到"路径能在该构型包络内通过"。点探针只能证明"这一点可承重"，不能证明整只脚掌扫过的条带都安全；本轮的证据提升规则是**足迹最坏值提升**：EP(π)=max_{x∈sweep(π)}风险(x)。跨底盘迁移标签时，必须携带**迁移债务**并显式加宽包络，否则就是拿轮式的"可通行"给四足签字。

**灵感 4（移动底盘×数据标注 → 伪标签隔离与标注干预）**
直觉：当底盘自己给自己打标签，标注就成了一种**由策略选择的干预实验**：开得猛则滑移大，滑移大就给地形贴"滑"的标签——标签里混进了驾驶风格。更危险的是"模型预标注—人工盖章—回灌训练"的闭环，会让元模型把自己的高置信错误固化成"真值"。因此需要两条硬规矩：其一，**伪标签隔离区**——模型/仿真/RFM 的预测不得直接进入 𝒟_meta，只能在影子模式与独立接地后入账；其二，**标注干预**——用随机化的微机动/保持架动作把"地形效应"从"策略效应"里解耦，并把标注预算按信息增益、覆盖债务与删失风险分配。标注动作本身也必须过证据门：**不可逆危险只能靠仿真/代理标注，绝不用亲历标注**。

**灵感 5（合流 → 证据门七类与标注-移动探-诺-演）**
直觉：第 57 轮五类证据门在本轮获得两个"来源维度"：**EV-ann**（认证标注，仅用于划界与提议，限 L1）与 **EV-env**（构型包络证书，限 L1 及以下）；而 EV-probe\*/EV-margin 获得"覆盖已认证 ∧ 构型已条件化 ∧ 标签噪声已声明"三个前置。不可逆接触的必要证据集仍是 `{真实 EV-probe* ∨ EV-margin} ∪ 佐证 ∧ 覆盖证书 ∧ 包络证书`，**EV-ann / EV-env / EV-xmodal 一律不得入集**。这样"数据说行"与"我这种底盘应该行"永远只能省探针，不能免探针。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（标注契约与标签噪声校准 ALR）** 每条元标签 ℓ=(y, annotator, protocol, instrument, chassis_cfg, time, prov) 进入标注账本 `Ledger`。标签噪声转移 `T_p(y'|y)=P(ℓ=y'|真值=y)`，按谓词/构型分层估计并有界声明 `T_p∈𝕋_p`。有效标注可靠性 `ρ_ℓ∈[0,1]` 由标注者资质、事后核验、来源独立度与歧义度共同决定。**分歧即区间**：多名标注者不一致时保留歧义区间 `[y_lo,y_hi]`，下游以区间参与计算，禁止取均值冒充真值。**鲁棒共形校准契约**：对每个谓词 p，`P(y∉C_p^T(x))≤α_sem` 仅在 𝒯∈𝕋_p 且校准集覆盖已认证时成立；若 T_p 未知，则退化为**标签条件覆盖**并显式标注"不可用于不可逆承诺"。标签噪声地板 `L(ρ_ℓ)` 计入任何下游失效率，不允许被 `ε_meta(k)` 掩盖。

**定义 140（覆盖证书与幸存偏差校正 CSC）** 在分层空间 𝒳=(地形簇 × 构型族 × 载荷带 × 季节) 上维护覆盖计数与**标注倾向** `e(x)=P(x 被标注 ∧ 本轮安全返回)`。覆盖债务 `D_cov=Σ_s w_s·max(0, n_req(s)−n_obs(s))/n_req(s)`；`D_cov>θ_cov` 的分层称**未认证层**。校准使用逆倾向加权 `w_ipw(x)∝1/ê(x)`（截断到 `[w_min,w_max]` 以防方差爆炸），得到**去删失校准集**。OOD 分两类：**support-OOD**（分布外新模式，沿用第 57 轮 n(o) 门）与 **coverage-OOD**（支撑集内但未标注/被删失）。coverage-OOD 区域：元先验只可产生保守动作，`EV-probe*` 不得作为不可逆证据；必须先补标注或退非参逐构型包络。

**定义 141（构型相对可通行性与包络证书 EMC）** 构型 `c=(足迹, 离地间隙, 质心/载荷包络, 轮胎/足端, 悬挂, 可用步态集 G)`。可通行性为联合谓词 `p(x,y;c,m,g)`；**移动包络** `E(c,x,m)={(g,v): 稳定裕度≥0 ∧ 牵引≥需求 ∧ 间隙≥需求}`。**足迹/路径提升**：`EP(π)=agg_{x∈sweep(π)} r(x)` 取最坏值，点证据只有在 `sweep(π)⊆tested_tube` 时才能提升为路径证据。跨构型迁移带**迁移债务** `Td(c→c')`：标签只在 `E(c')` 被显式收窄且 `Td≤θ_td` 时可用，否则必须重新标注；`EV-env` 仅证明"本构型在本包络内可走"，不证明地形本身安全。

**定义 142（标注血缘、伪标签隔离与标注干预 ALQ）** 标注血缘 `𝓛_ann(ℓ)=(annotator_id, protocol_ver, instrument, chassis_cfg, sim_seed, model_ver, parent_labels)`；标注者有效独立度 `κ_ann` 由血缘估计。**伪标签隔离**：任何模型/仿真/RFM 产生的预测默认 `quarantined`，只有在独立接地（真实观测或已验证人工标注）且 `κ_ann≥κ_0` 后才可转正；自训练仅在影子模式进行，转正率受审计。**标注干预**：以随机化微机动/保持架动作 `a_int` 打破"策略→标签"的混杂，`ℓ` 只有在 `a_int` 记录存在时才算去混杂标签；`a_int` 本身必须过局部证据门（不可逆危险不得亲历标注，只可仿真/代理标注）。**主动标注 VOI**：`VOI_ann(x)=I(y;ℓ|观测)·1[覆盖债务或删失风险] − λ·cost_risk(a_int) − μ·D_cov(x)`。

**定义 143（标注-移动证据门 AMG 与证书 J_a）** 证据类七类：`EV-probe*/EV-visit/EV-margin/EV-xmodal/EV-human`（第 57 轮）+ **EV-ann**（认证标注，`ρ_ℓ≥ρ_0 ∧ coverage-certified ∧ 非不可逆`，仅供划界/提议）+ **EV-env**（`E(c,x,m)` 证书，限 L1 及以下）。不可逆接触必要证据集 `={真实 EV-probe* ∨ EV-margin} ∪ 佐证 ∧ coverage-certified ∧ chassis-envelope`；**EV-ann/EV-env/EV-xmodal 一律不得入集**。证书 `J_a=(Ledger, T_p/ρ_ℓ, CoverageCert, CensoringFlags, chassis_cfg, E(c,x,m), Td, κ_ann, PseudoLabelQuarantine, InterventionLog)`，继承 J_p 全检。

**定义 144（标注-移动探-诺-演 AM-PCE）** 每检查点：①按当前构型选条件化元先验；②覆盖与删失审计（未认证层 ⇒ 强制保守 + 触发主动标注/换构型）；③标签噪声加权与歧义区间传播；④足迹/路径提升（点证据不得越级）；⑤证据门 AMG + 证书 J_a；⑥承诺 ⇔ 构建包络内 R≤δ_f ∧ 证据门过；否则 `argmax[VOI_元悲观 − cost]` 选自探/主动标注 → 换独立血缘 → 绕行 → 降档 → L2 协商（τ_int(auth)）→ 安全停。**预算隔离**：标注预算 `B_ann` 与安全探针预算 `B_probe` 分账，禁止挪用安全探针预算去买标签；`B_ann` 用尽即转保守。

## 2. 关键算法伪代码（完整版见产物区）

```python
def meta_infer_annotated(M, r, obs, meta, chassis):     # IP-139/140
    labels = ledger.labels(r, chassis.c, load=chassis.m)
    if coverage_debt(r, chassis.c) > theta_cov:          # 未认证层
        return Inf(cls='coverage-OOD', prior=nonparam_envelope(chassis))
    if ood_score(obs) > theta_ood:                        # support-OOD
        return Inf(cls='support-OOD', belt=conformal_belt(meta.res, r))
    post = robust_update(meta.q_phi(obs, ctx(r)),
                         noise=meta.T[r.p], interval=ambiguity(labels))
    return Inf(cls='ID', post=post,
               label_floor=noise_floor(meta.rho[labels]),
               coverage=coverage_cert(r, chassis.c))

def label_quality_gate(ell, ledger):                      # IP-142
    if ell.origin in {'model', 'sim', 'rfm'} and not ell.grounded:
        return False                                     # 伪标签隔离
    if ell.intervention_missing and policy_confounded(ell):
        return False                                     # 未去混杂
    return ell.rho >= rho0 and ell.coverage_ok

def commit_annotated(c, M, chassis, t_now):               # IP-143/144
    env = mobility_envelope(chassis.c, c.region, chassis.m)
    if c.level == 'L2' and not envelope_covers(env, c.path):
        return ('reject', 'outside_envelope', c)
    if c.irreversible and not coverage_certified(c.region, chassis.c):
        return ('reject', 'coverage_ood', c)             # 危险不许被幸存者藏起
    if c.ev in ('EV-ann', 'EV-env') and c.irreversible:
        return ('reject', 'annotation_cannot_authorize', c)
    if not local_gate(c, M, chassis): return ('reject', 'local', c)
    return ('ok', Ja(c, M, env))
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| ALR | O(d_φ + \|Ledger_r\|) | O(\|Ledger\|) | T_p 有界、歧义区间不被均值吞掉 |
| CSC | O(\|S\|) 分层 | O(\|S\|) | ê(x) 有界、IPW 截断、删失不被当安全 |
| EMC | O(\|sweep(π)\|) | O(\|V\|·\|c\|) | 足迹最坏值提升、Td 显式 |
| ALQ | O(1)+O(H_ann) | O(\|Ledger\|) | 伪标签不放行、干预记录完备 |
| AMG | O(\|σ\|) | O(\|σ\|) | 无认证不承诺、EV-ann 限 L1 |
| AM-PCE | O(\|CP\|·(k_p+k_a)·(C_VOI+d_φ)) | O(\|V\|+\|σ\|) | B_ann/B_probe 隔离、终止 |

**正确性定理（Annotated-Mobility Calibrated Soundness, AMCS 概要）**：在第 57 轮 A33–A40 上加 (A41) 标签噪声有界且声明诚实、鲁棒共形在 𝒯∈𝕋_p 下覆盖 ≥1−α_sem；(A42) 覆盖审计诚实：ê(x) 有界、覆盖证书有效、删失/未标注层不被当作安全；(A43) 构型包络保守：足迹提升取最坏值、跨构型迁移债务计入且未认证不得迁移；(A44) 伪标签隔离与标注干预诚实、标注动作本身过安全门。则：(i) ID 且覆盖认证层的承诺失效率 `≤δ_f+ε_meta(k)+L(ρ_ℓ)+δ_cov+δ_probe+ε_h`；coverage-OOD 路径的删失风险以 `D_cov·widening` 计入而非归零；(ii) 交互/标注单调性：标注与构型机制只能经"信念更准（含加宽）"或"动作更保守"影响系统，伪标签不得降低佐证要求；(iii) AM-PCE 在 `k_probe+k_ann` 内终止于 {承诺, 绕行, 主动标注, L2 协商, 安全停}。

```python
def robust_conformal(ledger, p, alpha_sem):
    # 分歧不平均，保留区间；噪声有界时做去噪非一致性分数
    cal = [(x, y_lo, y_hi, T_p) for x, y_lo, y_hi, T_p in ledger.calibration(p)]
    for T in T_p_vertices(cal):                  # 𝕋_p 的顶点枚举
        scores = [nonconformity_under_noise(x, y, T) for x, y, T in cal]
        tau[T] = quantile(scores, 1 - alpha_sem)
    return ConformalSet(tau=max(tau.values()))   # 取最保守，覆盖对真值 y

def label_reliability(ell, ledger):
    base = annotator_skill(ell.annotator)
    verified = ledger.post_hoc_correct(ell)       # 事后实测核验
    indep = 1 - max(lineage_corr(ell, o) for o in ledger.others(ell))
    ambig = 1 - ambiguity_mass(ell)
    return clip(base * verified * indep * ambig, 0, 1)
```

### IP-140 CSC（覆盖证书与幸存偏差校正）

```python
def coverage_certificate(ledger, strata):
    out = {}
    for s in strata:                                    # 地形×构型×载荷×季节
        n_obs = ledger.count(s)
        e_hat = clip(ledger.annotated_and_returned(s) / max(ledger.reached(s), 1),
                     e_min, e_max)
        w = clip(1.0 / e_hat, w_min, w_max)             # IPW 去删失
        debt = max(0, N_REQ[s] - n_obs) / N_REQ[s]
        out[s] = Cert(n_obs=n_obs, debt=debt, ipw=w,
                      censored=ledger.censored(s),          # 到过却没敢标
                      certified=(debt <= theta_cov and not ledger.censored(s)))
    return CoverageCert(out)

def coverage_gate(region, chassis, cert):
    s = stratum(region, chassis)
    if cert[s].censored: return ('coverage-OOD', cert[s])  # 危险被删失
    if cert[s].debt > theta_cov: return ('uncovered', cert[s])
    return ('certified', cert[s])
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ALR | O(d_φ+\|Ledger_r\|)/推断；顶点枚举 O(\|𝕋_p\|) | O(\|Ledger\|) | T_p 有界、鲁棒覆盖对真值（A41） |
| CSC | O(\|S\|) | O(\|S\|) | ê 有界、IPW 截断、删失不归零（A42） |
| EMC | O(\|sweep(π)\|·\|G×V\|) | O(\|V\|·\|c\|) | 最坏值提升、Td 显式（A43） |
| ALQ | O(1)+O(H_ann) | O(\|Ledger\|) | 伪标签不放行、干预完备（A44） |
| AMG | O(\|σ\|·log\|Ledger\|) | O(\|σ\|) | 无认证不承诺、派生证据不入不可逆集 |
| AM-PCE | O(\|CP\|·(k_p+k_a)·(C_VOI+d_φ)) | O(\|V\|+\|σ\|) | B 分账、`k_p+k_a` 终止、四态完备 |

**正确性定理（Annotated-Mobility Calibrated Soundness, AMCS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 标签噪声与校准：每个谓词 `T_p∈𝕋_p` 有界且声明诚实，鲁棒共形在 `𝒯∈𝕋_p` 下满足对真值覆盖 ≥1−α_sem，标签噪声地板 `L(ρ_ℓ)` 显式计入；**(A42)** 覆盖审计诚实：标注倾向估计 `ê∈[e_min,e_max]`，IPW 截断，覆盖证书有效，删失/未标注层不被当作安全；**(A43)** 构型包络保守：足迹/路径提升取最坏值，跨构型迁移仅在 `Td≤θ_td` 且包络收窄时成立；**(A44)** 伪标签隔离与标注干预诚实，标注动作本身过局部证据门、不可逆危险只用仿真/代理标注。则：

1. **标注-移动承诺健全性**：认证覆盖层上的 ID 承诺
   `P(fail) ≤ δ_f + ε_meta(k) + L(ρ_ℓ) + δ_cov + δ_probe + ε_h(w_max)`；
   coverage-OOD 路径以 `D_cov·widening` 计入而非归零；EV-ann/EV-env 仅在 L1 贡献 ≤δ_ann/δ_env。
2. **来源单调性**：标注、覆盖、构型三个新机制只能经 (a) 更宽/更准的信念（强制歧义区间、噪声加权、包络加宽）或 (b) 更保守的动作（未认证即降档、包络外即拒、伪标签即拒）影响系统；不存在升险路径，且伪标签不得降低佐证要求。
3. **终止性**：每检查点探针 ≤k_p、标注 ≤k_a，AM-PCE 在 `k_p+k_a` 内终止于 {承诺, 绕行, 主动标注, L2 协商, 安全停}；`B_ann` 与 `B_probe` 分账，标注不得挤占安全探针。
4. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + L(ρ_ℓ) + δ_cov + δ_probe + ε_h + δ_ood·α_conf)
             − P(覆盖证书失效) − P(包络模型漏界) − P(伪标签隔离击穿)
             − P(标签噪声假设被违反) − P(安全停失效)
```

关键：**标签给效率、覆盖给底、包络给界**——效率与安全解耦，赌注不押在"元模型多聪明"而押在"标注多诚实、覆盖多完整、构型多保守"；**EV-ann/EV-env 把"数据说行"与"我这种底盘应该行"变成只能省探针的提议**，不可逆承诺仍必须由真实探针/裕度兑现；**伪标签隔离把持续学习的自证闭环关掉**，让语料不能自己给自己发合格证。

云边协议 CEB++ → **CEB-A**：云端可下发"补盲标注任务/仿真反事实标注"，但**补盲标签同样走隔离区**——先影子落账、经独立接地与覆盖审计后才转正；边端回传标注倾向 `ê(x)`、删失事件与构型包络失配残差，作为云端覆盖审计与迁移债务的校准输入。第 57 轮"一切判定器走隔离"在本轮推广为"**一切标签来源（自标注/仿真/模型预标注/人）走隔离，先标注来源，后相信标签**"。

## 6. 本轮最大风险

**一句话**：本轮把安全从"元先验质量"挪到"标注质量与覆盖审计"，但审计者正是被审计的部署闭环本身——一旦危险区域被幸存者偏差系统性删失、且模型预标注又绕开隔离回灌训练，系统就会在自己从未真正经历过的地方最自信，而包络证书与认证标注会让这种自信更快通过证据门；必须以"未标注/被删失 = 一等不安全状态"、伪标签隔离、构型包络最坏值提升三重护栏，并接受"覆盖补不上就退保守"这一不体面的结局。
