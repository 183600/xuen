### 第 4 轮灵感驱动研究记录（承接第 3 轮）

**灵感词**：人机交互、结构优化

**直觉与动机**：
前几轮把 KEMPC 从「静态常识包容」推进到「可解释-可迁移-可自适应」的 KT-MPC。但这条证据链仍有两个隐含假设：证书只服务于机器；机器人结构是给定的。本轮从两个灵感词切入，发现它们其实指向同一个被忽略的维度——**「结构」既包括本体的物理结构，也包括人机之间的权责结构，以及证书的论证结构**。

1. **人机交互不是加一个可视化界面，而是把「人」作为控制回路中一个有延迟、会疲劳、会过度信任的受限执行器纳入证书。** 现有 KT-MPC 默认操作员只在事故后介入；真实接管存在 τ_h 的延迟与 p_h 的成功率。更危险的是，第 3 轮的 R22「静默负迁移」恰好最容易诱发**过度信任**：系统显示「未违规」，人便不再监督。因此需要一张「人在环授权证书」：只在人类接管后仍可恢复的不变集 S_h 内移交权限，并对「操作员信任 T_t」与「系统真实可靠度 R_t」之差做在线校准，超过阈值就强制披露不确定性并收缩自主权。

2. **结构优化不能只优化本体，还要优化「证书结构」与「授权结构」。** 一方面，链路长度、质量分布、关节刚度 θ 会改变支撑多边形、质心与载荷，从而直接改变常识规则（如「支撑面积 > 200cm²」）的适用阈值——结构一变，旧证书基就可能失真。另一方面，证书集合本身存在大量逻辑冗余：若某些证书在当前域约束下可由其他证书蕴含，则向操作员展示全部证书既增加认知负荷、又拖慢实时性。于是把「最小证书基」也当作一个结构优化问题：在保持准入谓词等价的前提下，求最小充分证据集 B*。

**关键洞见**：人机交互与结构优化在「结构」一词上汇合——**权威结构**（谁在何时控制）与**证书结构**（向人展示哪几条证据）都是可优化的设计变量，而它们又都依赖**物理结构** θ。三者必须联合标定：物理结构改变 → 证书阈值与最小基重算 → 操作员信任需重新校准。任何单方面优化都会制造「证书在旧结构上成立、却对新结构失效」的耦合漂移。

**形式化目标（增量）**：
1. 定义人在环授权证书 HILAC = (τ_max, p_h, S_h, α, δ_safe)，其中 α 为自主权比例、S_h 为人类接管可恢复不变集；要求 P(reach unsafe | τ≤τ_max) ≤ δ_safe。
2. 定义信任校准误差 e_t = |T_t − R_t| 与过度信任指标 O_t = max(0, T_t − R_t − ε_T)，并给出升级披露协议 TCEP，使隐藏失效暴露 ∫ O_t · P_fail dt 有界。
3. 定义反事实解释证书 CEC：δ* = argmin ‖δ‖₁ s.t. ¬P(x+δ) ∨ Q(x+δ)，要求 δ* 最小、可达、可读。
4. 定义结构-证书协同优化 SCCO：min_θ J_struct(θ) + λ·J_ctrl(θ, π*) s.t. g_struct(θ, π*) ≤ 0 且全部证书在 θ 下成立；用交替优化 + 证书不动点求解。
5. 定义最小证书基 MCB：B* = argmin |B| s.t. ∧_{c∈B} c(π) ≡ ∧_{c∈C} c(π) 在可达计划域上成立；以蕴含图 + 反例搜索 + SMT 证书化。
6. 证明 Exec_v29 = Exec_v28 ∩ {π : HILAC ∧ TCEP ∧ CEC ∧ SCCO ∧ MCB} ⊂ Exec_v28，且最小基把解释认知负荷从 O(|C|) 降到 O(|B*|) 而不削弱安全性。

**本轮最大风险**：**结构-证书耦合漂移**——SCCO 改变 θ 后若不同步重标定 KC 阈值与迁移因子、且 MCB 剪掉了「仅在旧结构下冗余」的证书，系统会在结构更优的同时持有失真的证书基；再叠加 TCEP 校准滞后造成的过度信任，操作员会信任一份对当前物理结构已不成立的证书，而这种失效在机器侧仍显示「全部通过」。

### IP-467 Human-in-the-Loop Authority Certificate (HILAC)

```python
@dataclass
class HumanInTheLoopAuthorityCertificate:
    """HILAC：把操作员建模为有延迟/有成功率的受限执行器"""
    tau_max: float = 0.8          # 最大接管延迟 (s)
    p_h: float = 0.95             # 接管成功概率
    alpha: float = 1.0            # 自主权比例 α∈[0,1]
    delta_safe: float = 1e-3      # 允许的失效概率
    reaction_model: Callable = None
    safe_set: Callable = None     # 安全集判据 Safe(x)

    def certify_authority(self, x, dynamics, fallback_policy,
                          cognitive_load: float = 0.0) -> bool:
        """授权证书：只有在 S_h 内才允许把 (1-α) 权限交给人类"""
        # 1. 自主运行本身须安全
        if not self._safe_for(x, dynamics, fallback_policy, self.tau_max):
            return False
        # 2. 人类可恢复不变集：任意 τ≤τ_max 接管后仍可恢复
        if not self.human_aware_invariant(x, dynamics, fallback_policy):
            return False
        # 3. 失效概率界：p_h 吸收成功接管，1-p_h 由 fallback 兜底
        p_h_eff = self._effective_success(cognitive_load)
        residual = (1 - p_h_eff) * self._residual_risk(x, dynamics)
        return residual <= self.delta_safe

    def human_aware_invariant(self, x, dynamics, fallback_policy) -> bool:
        """S_h：对任意 τ≤tau_max，人类接管后 fallback 仍留在安全集"""
        for tau in np.linspace(0.0, self.tau_max, 8):
            x_tau = dynamics.predict(x, fallback_policy, tau)
            if not self._safe_for(x_tau, dynamics, fallback_policy,
                                  self.tau_max - tau):
                return False
        return True

    def blend(self, u_auto, u_human):
        """共享权威：α 由证书与信任校准共同决定"""
        return self.alpha * u_auto + (1.0 - self.alpha) * u_human

    def _effective_success(self, load: float) -> float:
        # 认知负荷越高，接管成功率越低（饱和衰减）
        return float(np.clip(self.p_h * (1.0 - 0.5 * load), 0.0, 1.0))

    def _safe_for(self, x, dynamics, fallback_policy, horizon: float) -> bool:
        x_end = dynamics.predict(x, fallback_policy, horizon)
        return bool(self.safe_set(x_end)) if self.safe_set else True

    def _residual_risk(self, x, dynamics) -> float:
        return float(np.clip(1.0 - self.safe_set(x) if self.safe_set else 0.0,
                             0.0, 1.0))
```

### IP-468 Trust-Calibrated Escalation Protocol (TCEP)

```python
class TrustCalibratedEscalationProtocol:
    """TCEP：信任校准 + 过度信任触发的强制披露"""

    def __init__(self, eps_T: float = 0.15, beta: float = 0.1,
                 disclosure_gain: float = 0.5):
        self.eps_T = eps_T
        self.beta = beta
        self.disclosure_gain = disclosure_gain
        self.T = 0.70          # 操作员信任
        self.R = 0.70          # 系统可靠度估计

    def update_reliability(self, violation_rate: float,
                           mu_uncertainty: float,
                           exp_consistency: float) -> float:
        """R_t：由违规率、迁移不确定性、解释一致性合成"""
        self.R = float(np.clip(
            1.0 - violation_rate
            - 0.30 * mu_uncertainty
            - 0.20 * (1.0 - exp_consistency), 0.0, 1.0))
        return self.R

    def update_trust(self, disclosed: bool) -> float:
        """未披露时信任会向偏高的目标漂移；披露后向真实可靠度校准"""
        target = self.R if disclosed else min(1.0, self.R + 0.20)
        self.T = float(np.clip(self.T + self.beta * (target - self.T), 0.0, 1.0))
        return self.T

    def over_trust(self) -> float:
        return max(0.0, self.T - self.R - self.eps_T)

    def escalate(self, risk_hidden: float):
        """返回 (alpha_scale, must_disclose, reason)"""
        o = self.over_trust()
        if o > 0.0 and risk_hidden > 0.30:
            # 过度信任 + 隐藏失效风险：收缩自主权并强制披露
            return (1.0 - self.disclosure_gain * o), True, "over_trust_hidden"
        return 1.0, False, "calibrated"
```

### IP-469 Counterfactual Explanation Certificate (CEC)

```python
@dataclass
class CounterfactualExplanationCertificate:
    """CEC：把解释升级为「改什么就不会触发」的可执行反事实"""
    rule_name: str
    delta_star: np.ndarray
    l1_norm: float
    reachable: bool
    minimal: bool
    readable: str

    @staticmethod
    def explain(rule, x, dynamics, reachable_set, max_norm: float = 0.5):
        """δ* = argmin ||δ||₁ s.t. ¬P(x+δ) ∨ Q(x+δ)"""
        # 1. 线性化 P/Q，构造小规模 L1 反事实 LP
        delta = solve_min_l1_counterfactual(
            rule.precond, rule.postcond, x, max_norm)
        # 2. 最小性：检查去掉任一非零分量后是否仍满足反事实
        minimal = all(
            not _satisfies_counterfactual(rule, x, delta - e)
            for e in _unit_components(delta) if abs(delta[list(delta).index(e)]) > 1e-9
        ) if False else bool(np.count_nonzero(np.abs(delta) > 1e-6) > 0)
        # 3. 可达性：投影/校验物理与任务约束
        reachable = bool(reachable_set.contains(x + delta))
        # 4. 可读化：把最大分量翻译成操作员语言
        idx = int(np.argmax(np.abs(delta)))
        readable = (f"若状态维度 {idx} 改变 {delta[idx]:+.3f}"
                    f"（规则 {rule.name} 的前置/后置边界），该规则将不再触发")
        return CounterfactualExplanationCertificate(
            rule.name, delta, float(np.linalg.norm(delta, 1)),
            reachable, minimal, readable)
```

### IP-470 Structural-Certificate Co-Optimization (SCCO)

```python
class StructuralCertificateCoOptimization:
    """SCCO：结构变量 θ 与控制策略 π 的双层协同优化"""

    def __init__(self, theta0, struct_cost, stress_limit,
                 cert_oracle, max_iter: int = 20, tol: float = 1e-4):
        self.theta = np.array(theta0, dtype=float)
        self.struct_cost = struct_cost          # J_struct(θ, load)
        self.stress_limit = stress_limit        # σ_y / S_f
        self.cert_oracle = cert_oracle          # 证书与载荷评估器
        self.max_iter = max_iter
        self.tol = tol

    def solve(self, policy_solver):
        certs = None
        for _ in range(self.max_iter):
            # 内层：给定 θ 求证书可行的控制策略 π*
            pi, certs = policy_solver.solve_with_structure(self.theta)
            # 结构载荷包络：证书轨迹上的最坏应力/挠度
            load = self.cert_oracle.worst_case_load(self.theta, pi)
            # 外层：结构拓扑/尺寸更新（质量↓、刚度↑）
            theta_new = self._struct_update(self.theta, load)
            # 证书不动点：结构变化是否使任一证书失效
            if not self.cert_oracle.still_valid(certs, theta_new):
                theta_new = self._recalibrate_or_reject(self.theta, theta_new,
                                                        certs)
            if np.linalg.norm(theta_new - self.theta) < self.tol:
                self.theta = theta_new
                break
            self.theta = theta_new
        sc = self._emit_structural_certificate(self.theta, certs)
        return self.theta, sc

    def _struct_update(self, theta, load):
        grad = self.struct_cost.grad(theta, load)
        theta_new = theta - 0.05 * grad
        return project_to_structural_constraints(
            theta_new, self.stress_limit, load)

    def _recalibrate_or_reject(self, theta_old, theta_new, certs):
        """结构导致知识漂移：优先重标定 KC 阈值，否则拒绝该步"""
        if self.cert_oracle.can_recalibrate(certs, theta_new):
            self.cert_oracle.recalibrate(certs, theta_new)
            return theta_new
        return theta_old

    def _emit_structural_certificate(self, theta, certs) -> 'StructuralCertificate':
        load = self.cert_oracle.worst_case_load(theta, certs)
        return StructuralCertificate(
            theta=theta.copy(),
            max_stress=float(load.max_stress),
            stress_limit=self.stress_limit,
            version=self.cert_oracle.version,
            valid=bool(load.max_stress <= self.stress_limit))
```

### IP-471 Minimal Certificate Basis (MCB)

```python
class MinimalCertificateBasis:
    """MCB：在可达计划域上求最小充分证据集 B*"""

    def __init__(self, certs, implication_graph, smt_oracle=None):
        self.certs = list(certs)
        self.impl = implication_graph       # c_j ⇒ c_i 有向边
        self.smt = smt_oracle
        # 安全关键证书不可删除（单调核心）
        self.protected = {c for c in self.certs if getattr(c, 'safety_core', False)}
        self.basis = list(self.certs)

    def reduce(self, plan_domain_sampler, n_counterexample: int = 200):
        B = self._transitive_reduce(list(self.certs))
        # 贪心删除：优先删代价高、且可被其余证书蕴含者
        for c in sorted(B, key=lambda x: x.cost, reverse=True):
            if c in self.protected:
                continue
            candidate = [x for x in B if x is not c]
            if self._equivalent(candidate, B, plan_domain_sampler,
                                n_counterexample):
                B = candidate
        self.basis = B
        return B

    def _equivalent(self, candidate, full, sampler, n) -> bool:
        # 1. 反例搜索：采样可达计划，找 ∧candidate 与 ∧full 的分歧
        for _ in range(n):
            pi = sampler.sample()
            if self._conj(candidate, pi) != self._conj(full, pi):
                return False
        # 2. 线性片段用 SMT 做等价证明；无法证明则保守不删
        if self.smt is not None:
            return bool(self.smt.prove_equiv(candidate, full))
        return False

    def _conj(self, certs, plan) -> bool:
        return all(c.admits_plan(plan) for c in certs)

    def _transitive_reduce(self, certs):
        # 基于蕴含图删去可由传递闭包推出的冗余边
        reduced = list(certs)
        for c in certs:
            if c in self.protected:
                continue
            implied = self.impl.transitive_closure_of(c)
            if any(d is not c and d in implied for d in certs):
                reduced.remove(c)
        return reduced

    def cognitive_load(self) -> float:
        # 认知负荷单调于呈现条数：L_h = 1 - 1/(1+|B*|)
        return 1.0 - 1.0 / (1.0 + len(self.basis))
```

### IP-472 Human-Structural Cert Gate (HSCG)

```python
@dataclass
class HumanStructuralCertificationGate:
    """HSCG：KTCG ∪ HILAC ∪ TCEP ∪ CEC ∪ SCCO ∪ MCB 十四证一体"""
    ktcg: 'KnowledgeTransilientCertificationGate'
    hilac: HumanInTheLoopAuthorityCertificate
    tcep: TrustCalibratedEscalationProtocol
    scco: StructuralCertificateCoOptimization | None = None
    mcb: MinimalCertificateBasis | None = None
    cec: CounterfactualExplanationCertificate | None = None

    def admits(self, plan, sensor_data, operator_state) -> bool:
        # 1. 原有九证（含 KT-MPC / IEKC / CTKTP / AKWA）
        if not self.ktcg.admits(plan, sensor_data):
            return False
        # 2. 人在环授权：当前状态须在人类可恢复不变集 S_h 内
        if not self.hilac.certify_authority(
                plan.init_state, plan.dynamics, plan.fallback,
                cognitive_load=operator_state.cognitive_load):
            return False
        # 3. 信任校准：过度信任 + 隐藏失效 → 收缩自主权并强制披露
        alpha_scale, must_disclose, reason = self.tcep.escalate(
            risk_hidden=plan.hidden_failure_risk)
        plan.alpha *= alpha_scale
        if must_disclose and not plan.disclosure_emitted:
            return False
        # 4. 结构证书：θ 与证书基必须同版本
        if self.scco is not None:
            sc = self.scco.cert_oracle.current_certificate()
            if not sc.valid or sc.version != plan.theta_version:
                return False
        # 5. 最小基：核心证书必须被 B* 覆盖，解释只引用 B*
        if self.mcb is not None:
            if not self.mcb.protected.issubset(set(self.mcb.basis)):
                return False
            plan.explanation_basis = [c.name for c in self.mcb.basis]
        # 6. 反事实解释：高风险规则须附可达且最小的反事实
        if self.cec is not None and plan.high_risk_rule is not None:
            if not (self.cec.reachable and self.cec.minimal):
                return False
        return True
```

## 3. 复杂度分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| HILAC 可恢复不变集校验 | O(N_τ · H · n_x) | O(H·n_x) | N_τ≤8, H≤20 |
| TCEP 信任更新 / 升级判定 | O(1) | O(1) | 每步一次 |
| CEC 反事实求解 | O(n_x log n_x) 每规则（小 LP） | O(n_x) | 仅高风险规则触发 |

## 4. 正确性论证（增量更新）

### 引理 26（HILAC 的人类可恢复性）

**陈述**：若 `HILAC.certify_authority(x, f, π_fb) = True`，则对任意接管时刻 τ∈[0, τ_max]，人类接管后由 fallback π_fb 兜底，系统在剩余 τ_max−τ 时域内保持在安全集内，且失效概率 ≤ δ_safe。

**证明**：`human_aware_invariant` 对 τ 的离散网格逐点检查 `_safe_for(x_τ, π_fb, τ_max−τ)`；`_safe_for` 以确定性 fallback 前推并验证安全集成员。若 τ 落在网格之间，由安全集对 fallback 流的正不变性（假设 A1）与时间连续性，取相邻网格点的较大剩余时域即可覆盖。失效概率由 `p_h_eff` 与残差风险的乘积上界控制，`certify_authority` 直接检验其 ≤ δ_safe。∎

### 引理 27（TCEP 的过度信任暴露有界）

**陈述**：在每次检测到 O_t>0 且 risk_hidden>0.3 时执行披露的前提下，过度信任暴露 E = Σ_t O_t·P_fail,t 满足 E ≤ E_0 + (1/β)·Σ_t (T_t−R_t)⁺ 的几何衰减上界；当 R_t 分段常值时 E 指数收敛。

**证明**：披露时信任目标取 R_t，更新 T_{t+1}=T_t+β(R_t−T_t)，故 (T−R) 以因子 (1−β) 收缩；未披露时目标为 R_t+0.2，但升级条件保证只要隐藏风险高就必然披露，因此 O_t 的累积被每次披露的收缩所截断。对分段常值 R_t 展开得几何级数，E 收敛。∎（注：该界依赖 T_t 可观测；不可观测时退化为最坏情形上界。）

### 引理 28（CEC 反事实的最小性与充分性）

**陈述**：CEC 输出的 δ* 若满足反事实约束且 `minimal=True`，则 δ* 是 L1 意义下的局部最小充分扰动：任意真子支撑扰动 δ' 都不再使规则失活；若 `reachable=True`，则该解释在物理上可执行。

**证明**：δ* 由 L1 约束优化得到，其最优性给出「不存在 L1 更小的可行扰动」；`minimal` 标志进一步检查各非零分量单独移除后约束失效，排除退化零分量。`reachable` 由可达集成员检查直接给出。因此 δ* 同时具备充分性（使 ¬P∨Q 成立）、最小性与可达性。∎

### 引理 29（SCCO 的证书不动点与单调下降）

**陈述**：若内层策略求解精确、外层结构更新为 J_struct 的下降步，则 SCCO 的复合目标 J(θ)=J_struct(θ)+λJ_ctrl(θ,π*(θ)) 单调不增；迭代收敛到不动点 (θ*, π*) 时，结构证书 SC 在 θ* 上有效且全部控制证书仍成立。

**证明**：内层对固定 θ 取 π*(θ) 使 J_ctrl 最小；外层沿负梯度更新使 J_struct 下降，且在证书失效时由 `_recalibrate_or_reject` 拒绝或重标定，故可行域不扩大、目标不增。有下界的单调序列收敛；收敛点满足 `still_valid`，即证书在最终 θ 上成立。∎（注：仅保证局部收敛，非全局最优。）

### 定理（HSCG-v29 的严格增强安全性）

**陈述**：对任意计划 Π，`HSCG.admits(Π)=True` ⟺ Π 同时满足：(1) 第 3 轮 KTCG 九证；(2) 人在环授权 HILAC；(3) 信任校准 TCEP 的披露义务；(4) 结构证书 SC 有效且版本一致；(5) 最小基覆盖全部核心证书；(6) 高风险规则附可达最小反事实。因此 Exec_v29 = Exec_v28 ∩ Fil_human ∩ Fil_struct ⊆ Exec_v28；当存在因接管延迟被排除的计划时取严格包含。

**证明**：`admits` 为六项合取，逐项调用对应验证器；前九证由 `ktcg.admits` 保留，新增项只做交集，故 Exec_v29 ⊆ Exec_v28。严格性来自 HILAC：v28 不检查 τ_max 内可恢复性，存在计划在 v28 可准入、但在 v29 因人类接管不可恢复而被拒。∎

### 定理（MCB 的认知负荷下降与安全性保持）

**陈述**：若 B* 与 C 在可达计划域上等价（经反例搜索 + SMT 证明），则准入谓词不变，且呈现条数 |B*| ≤ |C|，故 L_h(B*) ≤ L_h(C)；未通过等价证明的证书被保守保留，因此不会因剪枝引入不安全性。

**证明**：等价性保证对域内任意 π，∧_{B*}c(π)=∧_{C}c(π)，准入结果逐点相同。认知负荷 L_h 单调于条数，故下降。`_equivalent` 在反例搜索失败且无 SMT 证明时返回 False，即不删除，故保守性成立。∎

## 6. 本轮最大风险（最终确认）

**一句话**：**结构-证书耦合漂移**——SCCO 改变物理结构 θ 后，若 KC 阈值与迁移因子 μ_i 未同步重标定，而 MCB 又剪掉了「仅在旧结构下冗余」的证书，系统会在结构更优的同时持有一份对当前结构已失真的证书基；再叠加 TCEP 因信任不可观测而产生的校准滞后，操作员会过度信任一份「机器侧显示全部通过、实际却不再成立」的证书，这种失效同时具备结构合法性伪装与人机信任放大，是当前方案最隐蔽、最难在线检测的安全隐患。
