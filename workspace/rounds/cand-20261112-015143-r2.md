# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 2 轮·移动操作×力矩传感；本轮灵感：「移动操作」×「力矩传感」）

> 第 57 轮把安全的赌注押在"证据质量"上，但它仍默认了两件从未被检验的事：**(i) 证据总在承诺之前、由外部探针采集**——先看后动，探针与承诺分离；**(ii) 机器人身体是透明观察者**——它自己的动作不会污染它所读到的证据。移动操作 + 力矩传感同时击穿这两条：机械臂每一次接触都由本体力矩读出，**证据在动作之中产生**；而移动底盘与机械臂通过力路耦合成一个闭环，**动作与观察不再可分离**。第 57 轮辛苦建立的"条件独立""跨模态对账""证据分账"在这里被推到极限：最诚实的那一路证据，恰恰是被动作自己制造出来的。于是本轮把命题从"证据说可信"推进为 **"动作即证据、力即契约、身即传感器——但动作证据只能证伪、力路必须分账、承诺只是租约"**。核心增量不是再加一层校验，而是承认**证据与动作同源**，并据此把安全设计从"证明它可信"改写为"只允许它否决、不允许它放行"。

核心矛盾：
- **H29（自证循环 / self-witnessing）**：力矩回执由被它评价的那个动作产生。控制器越刚性、模型越自信，力矩读数越"符合预期"——系统会把"我按我的模型压下去，果然感到我预期的力"当成确认。第 57 轮 XMC 要求的通道独立性，在最根本的"动作—证据"层面已经失效。
- **H30（基座-臂耦合 / base-arm coupling）**：移动操作让底盘与机械臂共享同一条力路。臂的反作用可推翻基座，基座的加减速又会污染臂的力矩读数；风险不是相加而是相乘，跨身体佐证可能被耦合伪造。
- **H31（力预算 vs 二元承诺 / force budget vs binary commit）**：真实操作需要分级用力，"轻轻推"与"猛推"是两件事，而现行承诺只有"做/不做"。单一力矩阈值要么浪费能力（过保守），要么压碎易碎物（过自信）；同意必须是一个带范围、带时限、带作用域的**预算**，而不是一个开关。

## 0. 直觉与动机

**灵感 1（力矩传感 → 动作即探针，但只能证伪）**
直觉：视觉探针是"我先看一眼再决定"；力矩回执是"我动了一下，身体把收据递回来"。这是免费证据——不需要额外的探针预算，每个动作都附带一张收据。但正因为它由动作自己开出，它天然可疑：一个错的动力学模型会让机器人"感到"它以为会感到的力。破解办法不是更相信它，而是**给它一张单向许可证**：力矩证据可以喊停、可以否决、可以要求复查，但永远不能充当放行的正证据。**摸到不对劲必须停，摸到"手感对"不算数**。这在数学上把自证循环的伤害压成单边——错误只能让系统更保守，不能让它更敢赌。

**灵感 2（力矩传感 → 全身力路归因，歧义即安全量）**
直觉：脚踩实了不等于脚在承重；手摸到了不等于手在托举。真正的安全问题是"此刻到底是谁在扛这个负载"。全身关节力矩 + 已知雅可比给了我们一组欠定方程，可以反解外部接触 wrench，但解不唯一——于是**归因歧义本身必须成为一等安全量**，像第 57 轮的跨模态分歧一样被显式携带进失效概率。定义每接触的负载份额与负载裕度，并要求"没有静默负载"（某个没申报的膝盖/肘部在偷偷承重）。**力路分歧即负载不确定性下限**。

**灵感 3（移动操作 → 耦合感知，独立性要现场检验）**
直觉：站着不动时，脚与手是两个相对独立的传感器；走起来时，身体是一个回路，臂的力会流到脚、脚的冲击会流回臂。第 57 轮"两个模态同侧即可佐证"在这里会造假：同一个动作通过耦合同时驱动两条通道，它们的"一致"只是回声。因此独立性不能声明，必须**在每次佐证前现场检验耦合强度与基座稳定域**——移动中跨身体佐证一律降级为仅否决，只有在静态支撑域才允许它顶一次佐证。**移动时身体是一个回路，站立时才是两个传感器。**

**灵感 4（移动操作 → 力预算与滚动承诺租约）**
直觉：承诺不该是"买断"，而该是"租约"——每一步都要靠新的力矩回执续租，一旦续不上就体面退出（柔顺撤退、换支撑、重探、重规划），而不是硬停。同意也不该是"是/否"，而是"在多大力量、多长时间、对什么对象"的**力契约**。授权越高的人可以批准越大的预算，但永远不能把硬投影线抬高。**承诺是租约不是买断，力是契约不是开关。**

**灵感 5（合流 → PCE++：探针与动作的边界消融）**
直觉：当动作本身产出证据，第 56/57 轮"探-诺-演"里的"探"就不再是独立阶段。每个可行动作都有两个价值：推进任务 + 提供一次带证伪价值的力矩回执。于是 VOI 多出一项**期望证伪价值 EFV**：优先执行"即使失败也能学到最多、且失败代价在软预算内"的动作。四态终止扩为 {签发租约、绕行、L2 力协商、柔顺撤退}。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（力矩回执 TRR，单向证据许可证）** 全身动力学残差 `r_τ = τ_meas − [M(q)q̈ + C(q,q̇)q̇ + g(q) + Jᵀ(q)ŵ_prev]`，`ŵ_prev` 为上一纪元力路先验。归一化惊奇 `s_τ = √(r_τᵀ Σ_τ(q,q̇)⁻¹ r_τ)`，`Σ_τ` 由标定 + 分层共形残差带给出。回执 `R_e=(r_τ,s_τ,Δκ̂,t)`，其中 `Δκ̂` 为接触刚度/柔顺度估计的跳变。**许可证**：`𝔏(EV-torque)={veto}`，仅当 `s_τ>θ_τ ∨ |Δκ̂|>θ_κ ∨ 残差方向与模型预测显著背离` 时产生**负证据**；`s_τ≤θ_τ` 不产生任何正证据，不得进入任何"必要证据集"。校准契约：假否决率 `P(s_τ>θ_τ | 正常接触) ≤ α_τ`（分层共形保底）。载荷/摩擦估计 `(m̂_p,μ̂)` 的在线更新亦走影子隔离，不得即时改写回执阈值。

**定义 140（全身力路归因 WFA）** 外力估计集 `Ŵ={w : Jᵀ(q)w = τ − τ_dyn, w∈𝒲}`，欠定时用稀疏/时序先验取点估计，但必须输出**归因证书** `(ŵ,U_w)`，`U_w` 为歧义集半径且以 `1−α_att` 覆盖真值。每接触负载份额 `ℓ_c = ‖w_c‖ / Σ_{c'}‖w_{c'}‖`，负载裕度 `K_load = min_c (w_c^max(θ̂_c) − ‖w_c‖)/scale`，力路分歧 `D_f = diam{ℓ(ŵ) : ŵ∈Ŵ}`，静默负载判据 `∃c∉C_decl, ℓ_c>θ_silent`。规则：**承诺需要** `K_load≥θ_Kload ∧ D_f≤θ_Df ∧ ¬静默负载`；否则触发换支撑/专用探针/降力。归因歧义按 `U_w` 上界计入 `P_fail`。

**定义 141（力矩预算同意阶梯 TCL）** 同意对象是**力契约** `B=(F_max,M_max,E_max=∫‖w‖dt,Z_envelope,scope,ttl)`。阶梯：L0 `‖w‖∞≤B_soft` 自主；L1 `B_soft<‖w‖∞≤B_hard` 异步通知；L2 `>B_hard` 或不可逆（易碎/近人）需人工确认——**确认的是预算 B，不是单次动作**。护盾在力矩层做硬投影 `w_safe=Π_{B_hard}(w)`，投影后立即服从，绝不被 L2 超时阻塞；超时即保守拒绝 = 柔顺撤退。授权 `auth` 只参数化"可授权预算上限" `B_max(auth)`，不改变投影算子与决策规则本体。

**定义 142（耦合感知证据门 CAG）** 基座-臂耦合矩阵 `C(q)`（臂接触 wrench 对基座/足端力路的传递）与残差相关 `ρ_r(m,m')`。通道 `(m,m')` **独立可佐证** `⇔ |C_{mm'}|≤θ_c ∧ ρ_r≤θ_ρ ∧ 基座处于静态稳定域（无负载转移）`。**EV-torque-xbody**（跨身体力矩佐证）仅在此条件下可顶替一次 L1 佐证；移动/负载转移时降级为仅否决。此规则直接修复 H29：同一动作直接驱动的通道不得自我确认，佐证必须来自动作未直接驱动、且耦合被实测证弱的通道。

**定义 143（滚动承诺租约 RCL）** 承诺是租约 `L=(σ,B,ttl,renew)`。每控制纪元续租：`renew ⇔ s_τ≤θ_τ ∧ K_load≥θ_Kload ∧ D_f≤θ_Df ∧ ¬静默负载 ∧ ‖w‖≤B_hard`。续租失败 ⇒ 撤销 `revoke`，进入恢复策略 `recover∈{compliant_retreat, re_support, re_probe, re_plan}`。**撤销单调**：未经新的正证据不得自动恢复。定义承诺存活率 `P(连续续租至时域 H)`。承诺是租约，不是买断。

**定义 144（探-诺-演++ 算子 PCE++/MMP）** 每检查点：① 在可行动作集选"动作即探针"——`EFV(a)=E[ΔInfo(s_τ 异常)]−λ·risk(a)`，取 `risk(a)≤B_soft` 中 EFV 最大者先执行；② 收力矩回执，更新 `Ŵ,ℓ,K_load,D_f` 与租约；③ 异常或 `D_f` 大 ⇒ 换支撑/发专用探针/降力；④ 承诺 ⇔ 签发租约；否则绕行 → 降力 → L2 力协商（`B_max(auth)`）→ 柔顺撤退。VOI 现含两项：主动探针的 `VOI` 与动作回执的免费 `EFV`，探针/动作边界消融。

## 2. 关键算法伪代码（完整版见产物区）

```python
def torque_receipt(M, q, qd, qdd, tau_meas, w_prev):        # IP-139
    r = tau_meas - (M.A(q,qd,qdd) + g(q) + J(q).T @ w_prev)
    s = sqrt(r @ inv(Sigma(q,qd)) @ r)
    pol = 'veto' if s > theta_tau or compliance_jump(r) else 'none'  # 无正证据
    return Receipt(r, s, pol)                              # 只进否决通道

def force_path_attribution(q, tau, C_decl):                 # IP-140
    W_hat, U = solve_wrench_set(q, tau, prior=w_prev)      # 欠定 → 证书
    share = load_shares(W_hat); K = load_margin(W_hat, cap)
    Df = spread(share, U); silent = undeclared_load(W_hat, C_decl)
    ok = K >= theta_Kload and Df <= theta_Df and not silent
    return Attribution(W_hat, U, share, K, Df, ok)

def rolling_lease(L, rec, att, B, epoch):                  # IP-143
    if rec.pol == 'veto' or not att.ok or norm(att.w) > B.hard:
        return revoke(L, recover=choose_recovery(rec, att))  # 撤销单调
    return renew(L, ttl=B.ttl)

def coupling_gate(C, rho_r, base_regime):                   # IP-142
    return abs(C) <= theta_c and rho_r <= theta_rho and base_regime == 'static'

def pce_pp(cp, M, budget, B, persona):                      # IP-144
    a = argmax(admissible(cp), key=lambda x: EFV(x) if risk(x) <= B.soft else -inf)
    rec = torque_receipt(*execute(a)); att = force_path_attribution(*sense())
    if rec.pol == 'veto' or att.Df > theta_Df:
        return recover_or_probe(cp, rec, att, budget)
    return rolling_lease(new_lease(cp, B), rec, att, B, epoch=now())
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| TRR | O(dof) 残差 + O(dof³) 标定离线 | O(dof²) Σ_τ | 假否决 ≤α_τ、单向许可证 |
| WFA | O(|C|·dof²) 逆解 | O(|C|·6) 证书 | 归因证书覆盖 ≥1−α_att |
| TCL | O(dof) 投影/控制周期 | O(1) | 硬投影不可绕过、超时不阻塞撤退 |
| CAG | O(|C|²) 耦合检验 | O(|C|²) | 静态域门控、耦合诚实 |
| RCL | O(1)/纪元 | O(1) | 撤销单调、恢复策略完备 |
| PCE++ | O(|CP|·(|A|+dof³)) | O(|V|+|C|) | EFV 有界、四态终止 |

**正确性定理（Torque-grounded Monotone Soundness, TMS 概要）**：在 A22–A40 上加 (A41) 力矩回执校准诚实、假否决 ≤α_τ；(A42) 力路归因证书 `(ŵ,U_w)` 以 ≥1−α_att 覆盖真值；(A43) 耦合矩阵与残差相关诚实估计，`EV-torque-xbody` 仅在静态支撑域使用；(A44) 力预算在控制周期内被硬投影执行、超时不得阻塞撤退；(A45) 租约撤销单调、未经新正证据不自动恢复。则：(i) **单向性**：力矩证据只能降低承诺概率，`P_fail(含力矩) ≤ P_fail(不含力矩)+α_τ`，自证循环无法升险；(ii) **负载健全**：`K_load≥θ ∧ D_f≤θ ∧ ¬静默` 且证书成立 ⇒ 声明接触确实承担其份额，力路失效概率 ≤α_att+δ_model；(iii) **力契约**：`‖w‖≤B_hard` 由投影保证，违约概率 ≤控制周期离散误差；(iv) **租约单调**：`P(不安全延续) ≤ Σ_epochs(α_τ+α_att+δ_probe)` 且撤销不回弹；(v) 交互单调性保持：所有新机制只经"更保守动作"或"撤销"起作用。

## 6. 本轮最大风险

**一句话**：力矩回执终究是"被自己的模型过滤过的触觉"——若动力学模型系统性错误（例如坚信物体刚性而用高刚度去压），控制器会从自己施加的力里"读出"预期的安全，从而在自我确认中压碎易碎物；因此必须坚持力矩证据只许否决不许放行、力硬上限独立于模型、并保留视觉/声学等未被动作直接驱动的外部见证作为最后仲裁。

### IP-139 TRR（力矩回执，单向许可证）

```python
def torque_receipt(q, qd, qdd, tau_meas, w_prev, cal):
    tau_pred = cal.M(q, qd, qdd) + cal.C(q, qd) @ qd + cal.g(q) \
               + cal.J(q).T @ w_prev
    r = tau_meas - tau_pred
    s = sqrt(r @ inv(cal.Sigma(q, qd)) @ r)             # 共形标定残差带
    kappa = estimate_compliance(q, qd, tau_meas, cal)
    jump = abs(kappa - cal.kappa_prev) > cal.theta_k
    veto = (s > cal.theta_tau) or jump or \
           (cosine(r, cal.pred_resid) < cal.theta_dir)  # 方向背离
    # 关键：s <= theta_tau 不产生正证据
    return Receipt(r=r, s=s, kappa=kappa, polarity=('veto' if veto else 'none'),
                   tau=tau_meas)

def update_model_quarantined(cal, payload_hat, friction_hat):
    shadow = run_shadow(cal, payload_hat, friction_hat)  # 影子模式
    if shadow.false_veto <= cal.alpha_tau and \
       shadow.detect_delay <= cal.delay_max:             # 回归测试通过
        cal.adopt(shadow); cal.audit.log('model_adopt')
    return cal
```

### IP-140 WFA（全身力路归因与负载分摊证书）

```python
def force_path_attribution(q, tau, dyn, C_decl, prior):
    # 欠定方程：J^T w = tau - tau_dyn，解集而非单点
    W_set = solve_wrench_set(J(q), tau - dyn, W=feasible_wrenches,
                             prior=prior, sparsity=True)
    W_hat, U_w = point_and_radius(W_set, alpha=alpha_att)  # 证书
    shares = {c: norm(W_hat[c]) / sum(norm(W_hat[cc]) for cc in W_hat)
              for c in W_hat}
    K_load = min((cap[c](theta_hat[c]) - norm(W_hat[c])) / scale
                 for c in critical(C_decl))
    D_f = spread(shares, W_set)                        # 力路分歧
    silent = any(c not in C_decl and shares.get(c, 0) > theta_silent
                 for c in W_hat)
    ok = K_load >= theta_Kload and D_f <= theta_Df and not silent
    return Attribution(W_hat, U_w, shares, K_load, D_f, silent, ok)

def force_path_risk(att, delta_model):
    # 归因歧义按上界进 P_fail
    return att.U_w / att.scale + delta_model + (att.D_f if not att.ok else 0)
```

### IP-141 TCL（力矩预算同意阶梯 + 硬投影）

```python
def make_force_contract(cp, persona, object_class):
    b_soft = budget_soft(cp, object_class)
    b_hard = min(budget_hard(cp, object_class), B_max(persona.auth))
    return Contract(F_max=b_hard, M_max=b_hard, E_max=energy_cap(cp),
                    Z_envelope=impedance_envelope(object_class),
                    scope=cp.region, ttl=cp.ttl, soft=b_soft, hard=b_hard)

def enforce_force_contract(w_cmd, B):
    w_safe = project(w_cmd, B.hard)                    # 力矩层硬投影，不可绕过
    level = 'L0' if norm(w_safe) <= B.soft else \
            ('L1' if norm(w_safe) <= B.hard else 'L2')
    return w_safe, level

def l2_force_consent(B, persona, exp):
    if norm(B.hard) > B_max(persona.auth):
        return 'reject_budget_exceeds_auth'            # 授权不能抬高硬线
    ok = await_input(exp, modality(persona),
                     timeout=tau_int(persona.auth))    # 超时=保守拒绝
    return 'granted' if ok else 'compliant_retreat'    # 超时不阻塞撤退
```

### IP-142 CAG（耦合感知证据门，修复自证循环）

```python
def coupling_independent(C, rho_r, base_regime, m, mp, theta_c, theta_rho):
    return abs(C[m][mp]) <= theta_c and rho_r[m][mp] <= theta_rho \
           and base_regime == 'static'                 # 静态支撑域

def torque_evidence_gate(rec, att, C, rho_r, base_regime, level):
    if rec.polarity == 'veto':
        return ('veto', 'torque_receipt_veto')         # 永远可用
    # 正证据只可能来自跨身体佐证，且必须过耦合门
    if level == 'L1' and coupling_independent(C, rho_r, base_regime, 'arm', 'base',
                                              theta_c, theta_rho) \
       and att.ok and not att.silent:
        return ('ok', 'EV-torque-xbody')
    return ('reject', 'self_witnessing_or_coupled')    # 同源动作不得自我确认
```

### IP-143 RCL（滚动承诺租约）

```python
def renew_lease(L, rec, att, B, now):
    ok = (rec.polarity != 'veto' and att.ok and
          norm(att.W_hat) <= B.hard and now < L.issue + L.ttl)
    if ok:
        return renew(L, until=now + L.epoch)
    return revoke(L, monotone=True)                    # 撤销不回弹

def choose_recovery(rec, att, cp, budget):
    if rec.polarity == 'veto' and att.silent:
        return 're_support'                            # 静默负载 → 换支撑
    if rec.polarity == 'veto' and att.D_f > theta_Df:
        return 're_probe'                              # 力路分歧 → 专用探针
    if not att.ok and budget.probes_left > 0:
        return 're_probe'
    if rec.kappa < cp.min_stiffness:
        return 'compliant_retreat'                     # 柔顺撤退
    return 're_plan'

def reinstatement_requires_new_positive(L):
    return L.revoked and has_new_positive_evidence(L)  # 否则永久保守
```

### IP-144 PCE++（探-诺-演++：动作即探针 × 力预算 × 滚动租约）

```python
def pce_pp(x0, M, task, budget, B, personas):
    route = plan_on_map(M, task, risk_model)
    sched = []
    for cp in route.checkpoints:
        B = make_force_contract(cp, personas.active, cp.object_class)
        while budget.actions_left > 0:
            acts = admissible_actions(cp, M, B.soft)   # 非破坏性 + 软预算内
            if not acts:
                break
            a = argmax(acts, key=lambda x: EFV(x, M) - cost(x))
            rec, att = execute_and_sense(a, M, B)      # 动作即探针
            M = update_force_map(M, cp.region, rec, att)
            ev = torque_evidence_gate(rec, att, M.C, M.rho_r,
                                      base_regime(M), cp.level)
            if ev[0] == 'veto' or att.Df > theta_Df or att.silent:
                act = choose_recovery(rec, att, cp, budget)
                if act == 're_probe':
                    execute_probe(most_disambiguating(M, cp.region), B)
                    continue
                if act == 're_support':
                    cp = resupport(cp, M); continue
                if act == 'compliant_retreat':
                    return retreat(x0, cp, M)
            if ev[0] == 'ok' and att.ok:
                L = new_lease(cp, B)
                if renew_lease(L, rec, att, B, now())[0] == 'renew':
                    sched.append(commit(cp, L)); break
            budget.spend(a)
        else:
            alt = reroute(M, cp, risk_model)
            if alt: route = alt; continue
            return negotiate_or_stop(cp, M, B, personas.active,
                                     tau_int=tau_int(personas.active.auth))
    return sched, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TRR | O(dof) 残差；O(dof³) 离线标定 | O(dof²) | 假否决 ≤α_τ、单向许可证（A41） |
| WFA | O(\|C\|·dof²) 逆解 + O(\|C\|²) 歧义 | O(\|C\|·6) 证书 | 归因证书覆盖 ≥1−α_att（A42） |
| TCL | O(dof)/控制周期 | O(1) | 硬投影不可绕过、超时不阻塞撤退（A44） |
| CAG | O(\|C\|²)/佐证 | O(\|C\|²) | 静态域门控、耦合诚实（A43） |
| RCL | O(1)/纪元 | O(1) | 撤销单调、恢复策略完备（A45） |
| PCE++ | O(\|CP\|·(\|A\|+dof³)) | O(\|V\|+\|C\|) | EFV 有界、四态终止 |

**正确性定理（Torque-grounded Monotone Soundness, TMS）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；**(A41)** 力矩回执校准诚实：正常接触下 `P(s_τ>θ_τ)≤α_τ`，且回执仅具否决权（不进入任何正证据必要集）；**(A42)** 力路归因证书 `(ŵ,U_w)` 以概率 ≥1−α_att 覆盖真实外力集，`ℓ_c,K_load,D_f` 由证书导出；**(A43)** 耦合矩阵 `C(q)` 与残差相关 `ρ_r` 诚实估计，`EV-torque-xbody` 仅在静态支撑域且耦合弱时使用；**(A44)** 力预算 `B_hard` 在控制周期内由力矩层硬投影执行，L2 超时不得阻塞柔顺撤退；**(A45)** 租约撤销单调，未经新正证据不自动恢复。则：

1. **证据单向性（自证循环的隔离）**：对任意动作序列，`P_fail(使用力矩回执) ≤ P_fail(不使用)+α_τ`。因力矩证据只进入否决分支，自证循环最多导致保守停机，永不导致更冒险的承诺。
2. **力路负载健全性**：若 `K_load≥θ_Kload ∧ D_f≤θ_Df ∧ ¬静默负载` 且证书成立，则每个关键接触承担其声明份额；`P(力路失效) ≤ α_att + δ_model + δ_probe`。
3. **力契约执行**：`‖w‖∞≤B_hard` 由 `Π_{B_hard}` 保证；接触力违约概率 ≤ 控制周期离散化误差 `δ_ctrl`，且 `B_hard≤B_max(auth)` 使个性化不能抬高硬线。
4. **租约单调性**：`P(不安全延续) ≤ Σ_{epochs}(α_τ+α_att+δ_probe+δ_model)`，撤销后不回弹（除非新正证据），故风险不在时间上复合。
5. **交互单调性保持**：TRR/WFA/TCL/CAG/RCL 只能经 (a) 更保守的动作参数（降力、换支撑、缩短 ttl）或 (b) 撤销/否决影响系统，不存在升险路径。
6. **终止性**：每检查点动作/探针预算有限，PCE++ 终止于 {签发租约、绕行、L2 力协商、柔顺撤退}。

**部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + α_τ + α_att + δ_probe + δ_model + δ_couple·1[xbody])
             − P(𝓜 陈旧未检出) − P(硬投影失效) − P(恢复策略失败)
             − P(τ_int ∧ τ_mm 超时 ∧ 柔顺撤退失效)
```

关键：**动作自产的证据只许否决**（把 H29 自证循环压成单边，错误只能更保守）；**力路归因把"踩实/摸到"升级为"谁在承重"，并把歧义显式计入风险**（H30 的耦合与 H31 的分级用力同时被覆盖）；**力预算是契约、硬投影独立于模型**（即使模型错，也不会压碎物体）；**承诺是租约**（安全在时间上被持续再赚取，而非一次性买断）。

## 6. 本轮最大风险

**一句话**：力矩回执终究是"被自己的模型过滤过的触觉"——若动力学模型系统性错误（例如坚信物体刚性而用高刚度去压），控制器会从自己施加的力里"读出"预期的安全，从而在自我确认中压碎易碎物；因此必须坚持力矩证据只许否决不许放行、力硬上限独立于模型、并保留视觉/声学等未被动作直接驱动的外部见证作为最后仲裁。
