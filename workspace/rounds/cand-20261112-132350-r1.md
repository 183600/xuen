# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「可靠性」×「流匹配策略」）

> 第 57 轮把承诺的赌注从"模型置信"依次搬到"证据质量"，再用摊销先验、跨模态对账、个性化信任三层护栏兜底；但它的风险自陈已经点破下一个软肋：无论证据多好，**最终落到地面的是策略生成的那一条动作轨迹**——证据只能事后否掉它，却不能保证它"生而可靠"。本轮两个灵感正面回应这一点。**可靠性**要求把"不出事"从部署后的统计量（平均成功率）提升为**逐样本、可声明、可审计的证书**；**流匹配策略**（flow matching policy）把策略建模为从先验到动作分布的连续流 v_θ，使"生成"本身成为一个可微、可似然、可截断、可投影的过程。两者合流得到一个此前框架没有的自由度：**积分到哪一步（截断 t\*）本身就是保守度旋钮**；而整流流的 W2 界与连续流的精确似然，让可靠性第一次能从生成过程内部推导，而不是从外部贴标签。核心命题由"证据说可信"升级为 **"生成即保证：策略吐出的每个动作都自带可靠性证书，证书只由『流 × 共形 × 守恒账本』三者共同签发，策略自己无权铸币"**。

核心矛盾：
- **H29（平均可靠 vs 逐样本可靠）**：流匹配给的是分布层面的好（W2 小、似然高），但一次不可逆接触只抽一个样本；"生成模型的平均可靠"与"这一次可靠"之间隔着一个未被任何定理自动覆盖的随机性缺口。用分布指标替代逐样本保证，等于把安全重新押在期望上。
- **H30（多模态 vs 可审计）**：FM 的多模态是优点（多条可行策略），也是隐患（同一状态两次采样风险不同、事故不可复现、责任不可回溯）；把采样固定成单一模式又损失柔性。需要在"模式路由的可靠性下界"与"锚定的可复现性"之间取舍——而不是假装二者自动兼得。
- **H31（插值的自信 vs 支撑的空白）**：流的连续插值会在两个安全模式之间平滑地"编造"一条从未见过的轨迹；恰恰在训练支撑的缝隙里，速度场最光滑、似然最自信、而可靠性最不可知。流的优雅正是**可靠性幻觉**的温床。

## 0. 直觉与动机

**灵感 1（可靠性 → 从后验统计到逐样本证书）**
直觉：传统机器人把可靠性当成"跑一万次坏几次"的期望值，用于选型，却无法回答"这一步能不能迈"。本轮的可靠性是**逐样本、带预算、可声明**的三件套：每个动作 a 附带证书 (δ, α, t\*, mode, cost)，含义是"在置信 1−α 下，这条轨迹的违反度 φ(a) ≤ δ"。可靠性不是单一数字，而是**在全局预算 R_tot 内可分配、可消耗、可被证据有限回补**的守恒量。这样"可靠"第一次成为一个能和决策规则直接对话的对象，而不是一段离线 PPT。

**灵感 2（流匹配策略 → 生成过程自带旋钮与似然）**
直觉：把策略写成速度场 v_θ(a_t,t;x,z)，从先验 ODE 积分到 t=1 得到动作。它有三个别的策略没有的性质：(i) **精确似然**——连续流可用瞬时变量变换算 log p(a)，于是能算协变量偏移下的重要性权重；(ii) **W2 可控**——整流流用线性插值，条件流匹配损失直接上界生成分布到数据分布的 W2，可靠性误差第一次能从训练损失推导；(iii) **可在任意 t 截断**——整流流的轨迹是安全锚点与名义动作之间的直线行程，截断在 t\* 就得到"离锚点还差多少"的凸混合，于是 **t\* 越小越保守、越大越激进**，一个连续旋钮天然对应第 56 轮的同意阶梯与第 57 轮的证据门。

**灵感 3（合流一：截断即证书 FTRC）**
直觉：既然 a_{t\*}=(1−t\*)a_anc+t\*a_1，而风险函数 φ 是 L_φ-Lipschitz，那么"把流少积分一点"就直接换来一个可计算的可靠性增益 L_φ(1−t\*)·||a_1−a_anc||。于是不必重训一个"保守策略"，只需在部署时**二分搜索最大的 t\* 使证书满足当前预算**——性能与可靠性沿同一条 ODE 连续可调，且每退一步都朝已认证的安全锚点收缩。这是"可靠性优先"的最廉价实现：不增加参数，只增加一个可验证的截断证书。

**灵感 4（合流二：投影流 RPF/SBRP → 把安全过滤器写成流）**
直觉：若证书在可达的 t\* 内仍不达标，就把动作**投影**回安全集。硬投影在非凸安全集上会跳变、破坏平滑性；本轮改用一条**从名义分布到安全分布的最小传输流**（Schrödinger 桥视角），目标分布 π_safe ∝ π_1·exp(−β h)，h 为控制屏障函数（CBF）。该流把"不安全样本"沿最小代价路径推回 h≥0，控制代价 ∫||u_t||² 被显式记账并从可靠性预算中扣除。于是"安全过滤器"从外挂补丁变成与生成策略同构、同样可训练可认证的流。

**灵感 5（合流三：可靠性账本 RBA → 一个不可自铸的守恒量）**
直觉：可靠性若可被策略自己"声明"就毫无意义。账本规则：全局预算 R_tot 只能被**证据**（探针/跨模态/人工事后证实）有限回补，且回补速率与幅度有界；策略生成、投影、人工佐证、绕行全部从中扣费；每次承诺要求"该接触分配到的份额 ≥ 其证书风险"。策略永远不能给自己铸币——这一条把第 57 轮"授权单向有界"从人的维度推广到**策略自身的可靠性声明**维度，也是整套方案最后的安全底线。

**灵感 6（合流四：模式路由 MRR → 多模态变成可审计的资产）**
直觉：从流里采 K 条样本、聚类成模式，对每个模式用共形下界估计可靠性，只在"可靠性 LCB 满足预算且任务可行"的模式里选；一旦选中，就用 (mode, seed, t\*, policy_hash) 固定整条 ODE，使事故可复现、可回溯、可审计。多模态由此从"风险来源"转为"候选策略池"：模式越多，越可能找到既高可靠又高收益的策略，但每个模式都必须先过证书。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（可靠性画像流匹配策略 RPFM）** 状态 x、上下文 z（继承 𝓜 的地图/材质/季节），可靠性画像 r∈(0,1]。策略隐式定义为 π_θ(·|x,z,r)=(T_θ^{x,z,r})_#π_0，先验 π_0=N(0,I)，速度场 v_θ 以**锚定条件流匹配**训练：

L_RCFM(θ)=E_{t∼U[0,1], x_0∼π_0, x_1∼𝒟, r}[ w(r)·‖v_θ((1−t)a_anc+t x_1+σ_t x_0, t; x, z, r) − ((x_1−a_anc)+σ̇_t x_0)‖² ]，

其中 a_anc=a_anc(x,z) 为已认证安全锚点，σ_t 为锚定噪声调度（σ_1=0 保证终点是数据点），w(r) 为画像核权重。画像契约：∀r、∀x∈supp，P_{a∼π_θ(·|x,z,r)}[φ(a)>δ(r)]≤r+ε_cal，ε_cal 为共形修正项。**画像 r 不是超参，而是可被承诺门查询的服务等级**。

**定义 140（流截断可靠性证书 FTRC）** 设整流路径精确成立：a_{t\*}=(1−t\*)a_anc+t\*a_1（锚定噪声下为凸混合）。风险函数 φ 对 sup 范数 L_φ-Lipschitz，速度上界 V_max=sup‖v_θ‖。截断证书

δ_cert(t\*)=φ̂(a_1)+L_φ(1−t\*)·V_max+q_α，

φ̂ 为名义风险估计，q_α 为 φ 残差的（加权）共形分位。可采纳截断 t\*(x,z,B)=max{t∈[0,1]:δ_cert(t)≤B}，二分 O(log(1/ε_t))。**单调性**：t\*↓ ⇒ δ_cert 单调不增、任务收益单调不增，给出可证明的"可靠性–性能"Pareto 前沿；部署只需沿这条前沿选点。

**定义 141（可靠性投影流 SBRP）** 安全集 S={a:h(a)≥0}，h 为 CBF。目标分布 π_safe(x,z)∝π_1(x,z)·exp(−β h(a))·1[task-feasible]。投影流 T_φ 为从 π_1 到 π_safe 的熵正则 Schrödinger 桥，控制代价 C_proj=E[∫_0^1‖u_t‖²dt]。证书：P[h(T_φ(a))≥0]≥1−α_proj（对 h∘T_φ 取共形下界），且 C_proj≤C_max(β)。β 越大越安全、代价越高：**β 是投影侧的第二个保守度旋钮**。共形失效或非凸病态时退回第 55 轮硬护盾 SSF 并标记降级。

**定义 142（模式路由与可复现承诺 MRR）** 对 π_θ 采 K 条 ODE 样本并按轨迹聚类为模式 {M_j}。模式可靠性下界 R_j^{LCB}=1−(共形上界(φ|M_j)+Hoeffding 修正)。路由 j\*=argmax_{j: task-feasible(M_j), R_j^{LCB}≥B_alloc} [R_j^{LCB}−λ·cost(M_j)]；无可行模式→投影流→锚点→L2。**可复现承诺**：执行记录 (policy_hash, x, z, j\*, seed, t\*, K) 必须能逐位重放；模式间不一致度 V_mode=Σ_{j<j'}TV(M_j,M_{j'}) 作为额外不确定度，V_mode>θ_V 触发降档或再次路由。

**定义 143（可靠性账本 RBA）** 账本状态 L_R=(R_tot, R_free, reserve)。**消耗**：生成、截断、投影、人工、绕行各按 cost 计费；**回补**：仅由证据事件按 r_back≤r_max 有限回补，且 r_back 不得超过该证据证书自身的可靠性增益（防止"用假证据铸币"）。守恒约束 R_free=R_tot+Σr_back−Σcost≥0。**承诺门**：∀接触 c，R_alloc(c)≥δ_cert(c) 且 Σ_c R_alloc(c)≤R_free；否则拒。健全性（联合界）：P(∪_c fail_c)≤Σ_c δ_cert(c)≤R_tot+Σr_back，且 **策略自身对 R_tot/r_back 无写权限**。

**定义 144（可靠性生成证据门 FME 与证书 J_f）** 新增证据类 **EV-flow**：要求 EV-flow ⇔ 可复现（policy_hash/seed/mode 记录完整）∧ 证书 δ_cert≤B_alloc∧α 有效 ∧ 区域非 OOD（继承第 57 轮 OOD 注册）∧ 账本未透支。准入层级：L1 可单用 EV-flow；**不可逆接触（L2）必要证据集={EV-flow}∪(EV-probe\*∨EV-margin)∪人工佐证**，且投影代价 C_proj 必须已记账。证书

J_f=(policy_hash, mode, seed, t\*, δ_cert, α, C_proj, ledger_snapshot, conformal_set, ood_state, audit_replay)，

继承 J_p 全检，并新增"账本不可自铸"与"重放确定性"两项硬检查。

## 2. 关键算法伪代码（完整版见产物区）

```python
def reliability_profiled_rollout(x, z, budget, policy, ledger):
    a1, mode, logp = policy.flow_sample(x, z, r=budget.r_profile)   # 名义流
    t_star, cert = truncation_certificate(policy, a1, x, z, budget.alloc)
    if cert.ok:                                                     # 截断即保守
        a = (1 - t_star) * anchor(x, z) + t_star * a1
        return Action(a, cert, mode), ledger.spend(cert.cost)
    a_safe, c_proj = policy.projection_flow(a1, x, z)               # 投影流兜底
    cert = conformal_safe_cert(policy.h, a_safe, alpha=budget.alpha)
    if cert.ok and ledger.can_spend(c_proj):
        return Action(a_safe, cert, mode), ledger.spend(c_proj)
    return consult_or_anchor(x, z, budget, ledger)                  # 锚点/降档/协商

def truncation_certificate(policy, a1, x, z, alloc):                # IP-140
    lo, hi = 0.0, 1.0
    for _ in range(policy.iters):                                   # 二分最大 t*
        mid = 0.5 * (lo + hi)
        d = policy.risk_hat(a1) + policy.L_phi * (1 - mid) * policy.V_max \
            + policy.conformal_q(alpha)
        if d <= alloc: lo = mid
        else:          hi = mid
    return lo, Cert(delta=d_at(lo), feasible=(d_at(lo) <= alloc))

def reliability_ledger_commit(contacts, ledger, evidence):          # IP-143
    ledger = ledger.replenish(evidence, cap=r_max)                  # 只由证据回补
    for c in contacts:
        if not ledger.allocate(c) >= c.cert.delta:                  # 份额≥风险
            return ('reject', 'budget_insufficient', c)
    if ledger.free_after(contacts) < 0:
        return ('reject', 'ledger_overdrawn')
    return ('ok', J_f(contacts, ledger))                            # 不可自铸
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| RPFM | O(N_steps·d_a)/样本 | O(d_θ) 静态 | W2 界诚实、画像契约成立 |
| FTRC | O(log(1/ε_t))（证书）；O(N_steps·t\*)（积分） | O(1) | 路径直线性、φ Lipschitz |
| SBRP | O(N_steps·d_a)（推理）；训练 O(N_bridge) | O(d_φ) | 终点覆盖≥1−α_proj、C_proj≤C_max |
| MRR | O(K·N_steps·d_a) | O(K·d_a) | LCB 有效、重放确定性 |
| RBA | O(\|接触\|) | O(\|接触\|) | 守恒、不可自铸、联合界 |
| FME | O(\|σ\|) | O(\|σ\|) | 无证书即拒、L2 必要证据集完整 |

**正确性定理（Flow-Certified Reliability Soundness, FCRS 概要）**：在 A41–A45 下：(i) 逐样本可靠性 P(φ(a)≤δ_cert)≥1−α（加权共形覆盖）；(ii) 期望风险 ≤ 目标风险 + L_φ·√(C·L_RCFM) + C_proj 项（由整流流 W2 界与投影代价给出）；(iii) 单调性：t\*↓ 或 β↑ 只降不升证书风险（存在升险路径即证伪）；(iv) 终止/时延：ODE 步数 O(t\*/Δ)；截断越保守越快，**保守性顺带降低控制回路时延**；(v) 部署界：P_safe≥1−R_tot−P(重放失败)−P(共形失效)。

## 6. 本轮最大风险

**一句话**：可靠性画像让策略在训练过的模式上"看起来很校准"，但流会在支撑缝隙里平滑而自信地插值出一条从未被验证的轨迹，而模式路由又恰好偏爱最自信的模式——于是失败会**集中发生在数据最稀疏、似然最高的地方**（可靠性幻觉）；必须用逐样本共形证书、截断收缩到已认证锚点、投影流兜底与不可自铸的可靠性账本四重护栏，把"自信"与"可靠"重新拆开，宁可退回又慢又保守的锚点，也不让策略为自己的可靠性签字。

# 第 58 轮产物 · 创新点清单 v34：Reliable-Flow（可靠性画像流匹配策略×截断证书×投影流×模式路由×可靠性账本，RPFM×FTRC×SBRP×MRR×RBA×FME）

> 承接第 57 轮 IP-133~138（MFSL/XMC/PTM/MXI/FSE/PCE+）与第 56 轮 IP-127~132（SMM/PCE/BVK/ISE/TAF/MEC）。本轮把部署前提从"证据承诺"再推进一步到 **"生成即保证"**：策略不再先吐动作再事后判安全，而是**在生成过程内部**携带可靠性——可靠性画像给出服务等级，整流流截断给出保守度旋钮，投影流给出安全兜底，模式路由给出可审计的多模态选择，可靠性账本给出不可自铸的守恒预算。第 57 轮"一切判定器走隔离"在本轮推广为 **"一切生成器（含策略本体）也要走可靠性隔离与账本审计"**。

### IP-139 RPFM（可靠性画像流匹配策略）

```python
def rpfm_train(stream, policy, meta):
    # 锚定条件流匹配：x_0 ~ N(0,I)，x_1 ~ 动作数据，路径 = 锚点→数据 的直线
    for (x, z, x1, r) in stream:
        t   = rand_uniform(0, 1)
        x0  = randn_like(x1)
        sig = policy.sigma_schedule(t)                 # σ_1 = 0
        at  = (1 - t) * policy.anchor(x, z) + t * x1 + sig * x0
        vt  = (x1 - policy.anchor(x, z)) + policy.dsigma(t) * x0
        loss = policy.w(r) * ||policy.v(at, t, x, z, r) - vt||**2
        policy.step(grad(loss))
    return policy

def rpfm_sample(policy, x, z, r, seed):
    a0 = policy.anchor(x, z)                           # 已认证锚点
    traj = ode_integrate(policy.v, a0, t0=0.0, t1=1.0,
                         ctx=(x, z, r), seed=seed)     # 可复现（固定 seed）
    a1, logp = traj.x1, exact_loglik(policy, traj)     # CNF 精确似然
    return a1, mode_of(traj), logp
```

### IP-140 FTRC（流截断可靠性证书）

```python
def truncation_certificate(policy, a1, x, z, alloc):
    lo, hi = 0.0, 1.0
    q  = policy.weighted_conformal_q(alpha)            # 协变量偏移下加权共形
    for _ in range(policy.iters):                      # O(log(1/eps_t)) 二分
        mid = 0.5 * (lo + hi)
        delta = policy.risk_hat(a1) \
              + policy.L_phi * (1 - mid) * policy.V_max \
              + q
        if delta <= alloc: lo = mid                    # 小 t 可行 → 试更激进
        else:              hi = mid
    t_star = lo
    delta  = policy.risk_hat(a1) + policy.L_phi * (1 - t_star) * policy.V_max + q
    return t_star, Cert(t_star=t_star, delta=delta, alpha=alpha,
                        feasible=(delta <= alloc))

def truncate_act(policy, a1, t_star, x, z):
    return (1 - t_star) * policy.anchor(x, z) + t_star * a1   # 朝锚点收缩
```

### IP-141 SBRP（Schrödinger 桥可靠性投影流）

```python
def sbrp_train(nominal_policy, cbf, beta, bridge):
    # 目标分布 π_safe ∝ π_1 · exp(-beta * h)；熵正则 SB 求最小传输
    for (x, z, a) in nominal_stream(nominal_policy):
        u = bridge.control(a, x, z)                    # 当前桥控制
        cost = ||u||**2
        viol = cbf.relu_neg(h(a, x, z))                # h<0 的违反量
        loss = cost + beta * viol + bridge.entropy_reg()
        bridge.step(grad(loss))
    return bridge

def sbrp_project(bridge, policy, a, x, z, alpha):
    a_safe, c_proj = bridge.transport(a, x, z)          # 最小传输到安全分布
    cert = conformal_safe_cert(policy.h, a_safe, alpha) # h∘T_φ 的共形下界
    if not cert.ok:                                     # 非凸病态/共形失效
        return hard_shield(a, x, z), INF_COST, 'fallback_ssf'
    return a_safe, c_proj, cert
```

### IP-142 MRR（模式路由与可复现承诺）

```python
def mode_route(policy, x, z, budget):
    samples = [rpfm_sample(policy, x, z, budget.r_profile, seed=s)
               for s in range(budget.K)]
    modes = cluster([s.a1 for s in samples], key=trajectory_signature)
    cands = []
    for j, m in enumerate(modes):
        R_lcb = 1 - (conformal_upper(budget.phi, m, budget.alpha)
                     + hoeffding_correction(len(m), budget.alpha))
        if task_feasible(m, x) and R_lcb >= budget.alloc:
            cands.append((j, R_lcb, cost(m)))
    if not cands:
        return None                                     # → 投影流 → 锚点 → L2
    j, R_lcb, c = max(cands, key=lambda t: t[1] - budget.lam * t[2])
    replay_key = (policy.hash, x, z, j, budget.seed, budget.t_star, budget.K)
    return modes[j], ReplayKey(replay_key)              # 逐位可重放

def mode_disagreement(modes):
    return sum(tv(modes[i], modes[j]) for i, j in pairs(len(modes)))
    # V_mode > theta_V ⇒ 降档或重新路由（继承第 57 轮 D(r) 的"分歧即下限"）
```

### IP-143 RBA（可靠性账本）

```python
class ReliabilityLedger:
    def replenish(self, evidence, cap):
        # 只由证据回补，且不得超过证据自身的可靠性增益（防铸币）
        self.free += min(cap, evidence.certified_gain)
        self.audit.log(('replenish', evidence.id, self.free))
        return self

    def allocate(self, contact):
        share = contact.cert.delta                      # 份额=风险（联合界）
        if share > self.free: return -1
        self.free -= share; contact.alloc = share
        self.audit.log(('alloc', contact.id, share))
        return share

    def spend(self, cost):
        self.free -= cost; self.audit.log(('spend', cost)); return self

    def free_after(self, contacts):
        return self.free - sum(c.cert.delta for c in contacts if c.alloc is None)
```

### IP-144 FME（流生成证据门 + J_f 证书）

```python
def flow_evidence_gate(c, M, policy, ledger, ood_reg):
    if c.ev == 'EV-flow':
        ok = (c.replay_key is not None                      # 可复现
              and c.replay_key == replay_key_of(c)          # 逐位一致
              and c.cert.delta <= c.alloc
              and c.cert.alpha <= budgets.alpha
              and c.region not in ood_reg.uncertified       # OOD 不采信
              and c.c_proj <= budgets.C_max)
        if not ok: return ('reject', 'flow_cert_invalid', c)
    elif c.ev in ('EV-probe*', 'EV-visit', 'EV-margin',
                  'EV-xmodal', 'EV-human'):
        ok = round57_checks(c, M)                           # 继承第 57 轮
        if not ok: return ('reject', 'evidence_insufficient', c)
    else:
        return ('reject', 'no_evidence_class', c)

    if c.level == 'L2':                                     # 不可逆接触必要集
        need = {c.ev_flow, c.probe_or_margin, c.human_corrob}
        if not all(need): return ('reject', 'L2_evidence_incomplete', c)
    if not ledger.audit.consistent():
        return ('reject', 'ledger_inconsistent', c)         # 不可自铸硬检
    return ('ok', c)

def flow_certificate_f(sched, log, M, policy, ledger, ood_reg):
    for c in contacts(sched):
        st = flow_evidence_gate(c, M, policy, ledger, ood_reg)
        if st[0] != 'ok': return st
    if not all(replayable(c) for c in contacts(sched)):
        return ('reject', 'replay_nondeterministic')
    if ledger.free_after(contacts(sched)) < 0:
        return ('reject', 'ledger_overdrawn')
    return ('ok', Jf(policy.hash, modes=sched.modes, seeds=sched.seeds,
                     trunc=sched.t_stars, deltas=sched.deltas,
                     c_proj=sched.c_proj, ledger=ledger.snapshot(),
                     conformal=sched.conformal_set, ood=ood_reg,
                     replay=sched.replay_keys))
```

### IP-128→PCE++（探-诺-演++：可靠性画像 × 截断 × 投影 × 账本）

```python
def probe_commit_evolve_plusplus(x0, M, task, budget, consent, personas):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    ledger = ReliabilityLedger(R_tot=budget.R_tot)
    for cp in route.checkpoints:
        inf   = meta_few_shot_infer(M, cp.region, M.obs[cp.region], meta)  # 第57轮
        alloc = ledger.allocate_cp(cp)                     # 账本先定额度
        route_m = mode_route(policy, cp.x, cp.z, budget, alloc)
        if route_m is None:
            return consult_or_stop(cp, M, sigma, R, consent,
                                   tau_int=tau_int(personas.active.auth))
        mode, replay = route_m
        t_star, cert = truncation_certificate(policy, mode.a1, cp.x, cp.z, alloc)
        if cert.ok:
            a = truncate_act(policy, mode.a1, t_star, cp.x, cp.z)
            ledger.spend(cert.cost)
        else:                                              # 截断到锚点仍不达标
            a, c_proj, pst = sbrp_project(bridge, policy, mode.a1, cp.x, cp.z,
                                          budget.alpha)
            if pst == 'fallback_ssf':
                return hard_stop(cp, 'projection_failed')
            ledger.spend(c_proj)
        # 继续第 57 轮探询/对账；证据门换成 FME
        sigma = foothold_schedule(x0, cp, M); R = schedule_risk(sigma, M)
        while select_gait(R) == 'halt' and budget.probes_left > 0:
            p = argmax(admissible_probes(cp, M, F_abs),
                       key=lambda q: voi_meta_pessimistic(q, M, inf) - cost(q))
            if voi_meta_pessimistic(p, M, inf) < theta_voi: break
            M, _, D = xmodal_fuse(M, cp.region, execute_probe(p, cap=F_abs))
            ledger.spend(cost(p)); sigma = reselect_footholds(x0, cp, M)
            R = schedule_risk(sigma, M); budget.spend(p)
        g = select_gait(R)
        if g != 'halt' and flow_evidence_gate(
                flow_contact(cp, a, cert, replay), M, policy, ledger,
                ood_reg)[0] == 'ok':
            sched.append(commit(sigma, g)); log.append(cert); continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt': route = alt; continue
        return negotiate_or_stop(cp, M, sigma, R, consent,
                                 tau_int=tau_int(personas.active.auth))
    return sched, log, M, ledger
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| RPFM | O(N_steps·d_a)/样本 | O(d_θ) 静态 | 画像契约、W2 界（A41） |
| FTRC | O(log(1/ε_t))+O(N_steps·t\*) | O(1) | 路径直线性、φ Lipschitz（A43） |
| SBRP | O(N_steps·d_a)/次投影 | O(d_φ) | 覆盖≥1−α_proj、C_proj≤C_max（A44） |
| MRR | O(K·N_steps·d_a)/检查点 | O(K·d_a) | LCB 有效、重放确定（A42） |
| RBA | O(1)/记账 + O(\|c\|)/提交 | O(\|c\|) | 守恒、不可自铸、联合界（A45） |
| FME | O(\|σ\|) | O(\|σ\|) | 无证书即拒、L2 必要集、重放硬检 |
| PCE++ | O(\|CP\|·(k_p·N_steps·d_a + K·d_a)+A\*) | O(\|V\|+\|σ\|) | k_p 终止、四态完备、账本不透支 |

**正确性定理（Flow-Certified Reliability Soundness, FCRS）**
假设 A22–A40（第 53–57 轮）成立；**(A41)** 流近似与似然：RPFM 的条件流匹配损失 L_RCFM 满足 W2²((T_θ)_#π_0, π_data)≤C·L_RCFM，且 CNF 似然精确、画像声明诚实；**(A42)** 画像覆盖与偏移：逐画像共形在加权分布下有效，密度比（由 log p 给出）≤w_max；模式级 LCB 用有效样本量与 Hoeffding 修正；**(A43)** 风险几何：φ 对 sup 范数 L_φ-Lipschitz，整流路径直线性成立，V_max<∞；**(A44)** 投影覆盖与代价：h∘T_φ 的共形下界覆盖 ≥1−α_proj，C_proj≤C_max，非凸失效时硬护盾 SSF 接管；**(A45)** 账本：R_free 守恒，r_back≤min(r_max, 证据增益)，策略对 R_tot/r_back 无写权限。则：

1. **逐样本可靠性**：对任一承诺样本 a，P(φ(a)≤δ_cert)≥1−α；且 δ_cert 随 t\* 单调不增。
2. **分布级风险界**：E[φ(a_1)] ≤ E_{π_data}[φ] + L_φ·√(C·L_RCFM) + C_proj（投影路径额外计 c_proj 代价）；即训练损失与投影代价直接换算为可靠性上界。
3. **单调性（无升险路径）**：t\*↓、β↑、R_alloc↑、模式 LCB 阈值↑ 均只能让证书风险不升；生成、截断、投影、路由四者只经"更接近已认证锚点"或"更保守的动作参数"影响系统，不存在由策略自信直接放大承诺的路径。
4. **可审计性**：任何承诺记录可由 (policy_hash, mode, seed, t\*, K) 逐位重放；重放失败即拒。
5. **部署界**（对接触取联合界）：

```
P_safe ≥ 1 − Σ_c δ_cert(c) − P(重放失败) − P(共形失效) − P(投影回退失败)
       ≥ 1 − R_tot − P(replay) − P(conformal) − P(projection)
```

关键：**画像给服务等级、截断给连续保守度、投影给安全兜底、账本给不可自铸预算**——四者把"策略自信"与"可靠性声明"彻底解耦；可靠性是**被消耗与回补的资源**，而不是策略可以随口宣称的属性。

## 6. 本轮最大风险

**一句话**：可靠性画像让策略在训练过的模式上"看起来很校准"，但流会在支撑缝隙里平滑而自信地插值出一条从未被验证的轨迹，而模式路由又恰好偏爱最自信的模式——于是失败会**集中发生在数据最稀疏、似然最高的地方**（可靠性幻觉）；必须以逐样本共形证书、截断收缩到已认证锚点、投影流兜底与不可自铸的可靠性账本四重护栏，把"自信"与"可靠"重新拆开，宁可退回又慢又保守的锚点，也绝不让策略为自己的可靠性签字。
