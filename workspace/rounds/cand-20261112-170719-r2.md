# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 2 轮；本轮灵感：「意图识别」×「多机协同」）

> 第 60 轮把单机闭环从「执行接地」推进到「场景语义→认知意图→执行约束→证据回传」，但**面向多机协同**仍有三处结构性缺口：
> 1. **意图是点估计而非信念**：CIEC 假设意图标签已给定且确定（slow/light/…），并把单点意图直接锁定为 ERTC 约束。真实场景中意图需从对话、手势、注视、接触力、任务上下文**推断**，且**时变、分层、可组合、带歧义**；一次点估计错误会被「锁定」放大为执行事故。
> 2. **多机意图无法安全对齐**：多台机器人观测同一个人/同一任务，若各自独立做贝叶斯更新再简单相乘，会**重复计数相关证据**，产生「高置信度的共识错误」；而多机约束若取并集则不安全、取交集又可能不可行，缺少**可判定的合并与协商**机制。
> 3. **执行证据只有单机顺序、没有跨机因果**：EPIR 用局部 seq 保证单机 EV-exec 连续，但多机事件本质是**偏序（happens-before）**；没有向量时钟与一致割，就无法重建「谁先对谁施加了什么」的协同历史，也无法在消息丢包/乱序下判断证据链是否仍全局一致。

## 0. 直觉与动机

**灵感 1（意图识别 → 意图信念状态 IBS）**
直觉：与其问「意图到底是什么」，不如问「**哪些意图仍然可能、各自多可信**」。把意图看成隐变量 i，观测是对话/手势/注视/力剖面/任务上下文 o_t；意图可随交互演化（先「拿起」后「交给」）。于是意图识别 = 在意图空间上的**贝叶斯滤波**，输出分布 p_t(i) 与**可信集** I_τ = {i: p_t(i) ≥ τ}。关键洞见：**执行层应当消费「可信集」而非「最大后验点」**——只要真实意图落在可信集内，鲁棒约束就能保安全。

**灵感 2（意图识别 → 鲁棒意图约束 RIC）**
直觉：意图越模糊，约束越保守。给定可信集 I_τ 与继承自 CIEC 的意图-约束映射 φ，安全可接受域应是**所有可信意图约束的交集** C_robust = ∩_{i∈I_τ} φ(i)。若交集为空（两个可信意图的要求互相排斥），说明「当前证据不足以安全执行」，此时应**冻结执行 + 主动澄清**，而不是赌一个 MAP 意图。关键洞见：**歧义不是噪声，而是需要显式处理的决策变量**。

**灵感 3（多机协同 → 相关性感知意图对齐 CAIA）**
直觉：三台机器人同时看着同一位人类、听着同一句话——它们的证据**高度相关**。若把三个后验直接相乘，等价于把一条证据数了三遍，必然过度自信。正确做法是**先给相关证据打折**：连续信念用**协方差交叉（Covariance Intersection）**，离散意图用带权**对数线性池化（log-linear pool）** p(i) ∝ Π_r p_r(i)^{ω_r}, Σω_r=1。权重 ω_r 反映机器人的可靠性与观测独立性。关键洞见：**多机对齐的目标不是「更自信」，而是「在未知相关结构下仍然保守且一致」**。

**灵感 4（多机协同 → 协同约束格 CCL）**
直觉：每台机器人都有自己的硬安全约束与软性能约束。合并的正确语义是**「安全取交、性能取权衡」**：硬约束不可被共识放宽（安全必须与共识解耦），软约束在可行交集内按优先级做 Pareto 选择；若硬约束交集为空，则触发**契约冲突**，进入任务重分配/协商，而不是让某台机器人「让步到不安全」。关键洞见：**约束集合在包含序下构成格，合并 = meet（更严），冲突 = 空 meet**。

**灵感 5（多机协同 → 协同执行证据图 CEG）**
直觉：单机讲「顺序」（seq+1），多机讲「因果」（happens-before）。给每个 EV-exec 事件打上**向量时钟**，e→f 当且仅当 VC(e) < VC(f) 逐分量。接收方执行**因果投递**：只有因果前驱全部到达才接纳；一致割（down-set）给出可重建的**全局一致快照**。关键洞见：**多机证据链的正确性不是「没有丢包」，而是「任一被接纳的事件，其因果历史都完整」**。

**灵感 6（合流 → 多机意图-场景-执行协同闭环 MISEC 与 PCE+++++）**
直觉：把 SSM（场景信念）与 IBS（意图信念）在机间用 CAIA 对齐，经 CCL 合并出鲁棒约束，执行后用 CEG 回传协同证据，再反哺场景/意图信念——形成 **场景→意图→对齐→约束→执行→协同证据→场景/意图更新** 的多机闭环。预算从第 60 轮四维认知预算扩展为 **B_collab = (B_scene, B_intent, B_align, B_comm, B_negotiate, B_exec)**：通信或协商耗尽时回退到「带陈旧度界的共享信念 + 保守 CCL」，保证**降级仍然安全**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（意图信念状态 IBS）** 意图信念 β_t = (I, p_t, I_τ, T, H_t)：
- **分层意图空间**：I = I_task × I_mode × I_param（如 任务「递杯子」× 模式「轻触/稳定」× 参数「速度档」），|I| = N_I。
- **观测**：o_t = (o_dialog, o_gesture, o_gaze, o_force, o_context)。
- **贝叶斯-隐马尔可夫递归**：
  p_t(i) ∝ p(o_t | i) · Σ_{i'} T(i | i') · p_{t-1}(i')，  T 为意图转移矩阵（允许交互中意图演化）。
- **可信集**：I_τ(β_t) = { i ∈ I : p_t(i) ≥ τ_intent }。
- **歧义度**：H_t = −Σ_i p_t(i) log p_t(i)，用于触发澄清。
- **校准要求**：对任意 α，P(i* ∈ I_τ) ≥ 1−α（可信集覆盖率），作为 A66。

**定义 162（鲁棒意图约束 RIC）** 给定继承自 CIEC 的映射 φ: I → 2^{X}（X 为执行参数空间，如 (v, F, K_p, K_d)）：
- **鲁棒约束**：C_robust(β) = ∩_{i ∈ I_τ(β)} φ(i)。
- **安全主导序**：c ⊑ c' ⟺ Adm(c') ⊆ Adm(c)（c' 更严、更安全）；C_robust 是可信意图约束的**最大下界（meet）**。
- **空交回退**：若 C_robust = ∅，则 C_exec = C_freeze（停/最小速度最小力）并发出**澄清请求**；由 A67 保证 C_freeze 对任意 i∈I 安全。
- **澄清价值**：EVOC(β) = max(0, E[Risk | 直接执行] − (Cost(clarify) + E[Risk | 澄清后执行]))，仅当 EVOC>0 且 B_comm 允许时提问。

**定义 163（相关性感知意图对齐 CAIA）** 设机器人集合 R，各机局部信念 (p_r, P_r)：
- **离散池化**：p_fused(i) ∝ Π_{r∈R} p_r(i)^{ω_r}，Σ_r ω_r = 1，ω_r ≥ 0。
- **连续融合（协方差交叉）**：P_fused^{-1} = Σ_{r∈R} ω_r P_r^{-1}，取 ω = argmin_{Σω=1} det(P_fused)（或 trace）。
- **对齐残差**：d(β_r, β_s) = ½[KL(β_r‖β_s) + KL(β_s‖β_r)]（连续用对称 KL，离散用 TV）。
- **共识终止**：迭代池化直到 max_{r,s} d(β_r, β_s) < ε_align，或轮数达到 B_negotiate.max；否则标记 `ALIGN_INCOMPLETE` 并转降级。
- **性质**：CI 在相关结构未知时仍给出**一致（不乐观）**的融合协方差（Loewner 序意义下 P_fused ⪰ P_true），避免朴素乘积的过度自信（A68）。

**定义 164（协同约束格 CCL）** 约束契约 c = (H, S, π)，H 为硬约束集（安全），S 为软约束集（性能），π 为优先级：
- **格结构**：(C, ⊑) 以包含序为偏序，meet c₁ ⊓ c₂ = (H₁ ∪ H₂, Pareto(S₁ ∩ S₂; π))。
- **可行性**：Feasible(c) ⟺ ∃x ∈ ∩_{h∈H} Adm(h)（线性约束用 LP 判定）。
- **合并规则**：c_merged = ⊓_{r∈R} c_r；硬约束**只增不减**（共识不得放宽 H，安全与共识解耦）。
- **冲突**：若 ¬Feasible(c_merged)，返回 `CONTRACT_CONFLICT`，进入重分配/协商；在冲突解决前所有相关机器人进入 C_freeze。

**定义 165（协同执行证据图 CEG）** 事件 e = (r, l_r, VC(e) ∈ N^{|R|}, payload, hash)：
- **向量时钟更新**：本地事件 VC_r[r] += 1；发送时附带 VC；接收时 VC_r[k] = max(VC_r[k], VC_msg[k])，再 VC_r[r] += 1。
- **因果序**：e → f ⟺ VC(e) < VC(f)（逐分量 ≤ 且至少一维 <）；并发 e ∥ f ⟺ 不可比。
- **因果投递**：只有当 e 的全部因果前驱已在本地 shadow 中被接纳，才接纳 e（跨机 EPIR-C）。
- **一致割**：事件集 D 是 down-set（若 f∈D 且 e→f 则 e∈D）；Snapshot = 极大 down-set。
- **全局一致谓词**：GC(G_CEG) = true ⟺ 快照 D 中不存在「已接纳但因果前驱缺失」的事件（A70）。

**定义 166（多机意图-场景-执行协同闭环 MISEC）** 算子 MISEC({M_r}, task, o_{1:t})：
```
① 各机 r: SSM.update(telem_r) → z_r；IBS.update(o_r) → β_r
② 广播充分统计量：send(z_r, μ_r/Σ_r 或 p_r, VC_r)（按 B_comm 压缩/降采样）
③ CAIA: β_fused ← WeightedPool({β_r}); Z_fused ← XMC×_fuse({z_r})
④ RIC: C_robust ← ∩_{i∈I_τ(β_fused)} φ(i)；若 ∅ → C_freeze + ClarifyRequest
⑤ CCL: c_merged ← ⊓_r c_r；若 CONFLICT → Reallocate + freeze
⑥ ERTC.lock_constraints(c_merged)（硬约束与共识解耦）
⑦ 各机执行：a_r ← π_r(x_r; C_robust, c_merged)；wait_contact()
⑧ EV-exec_r ← build_exec_evidence(...); CEG.append(e_r, VC_r)
⑨ 若 ¬GC(CEG.snapshot)：请求缺失因果前驱（EPIR-C 恢复）
⑩ SIC/场景/意图信念回写：β_r ← Update(β_fused, EV-exec); z_r ← ...
⑪ Return (β_fused, Z_fused, C_robust, c_merged, Snapshot(CEG), J_collab)
```

**定义 167（协同预算 B_collab 与 PCE+++++）** B_collab = (B_scene, B_intent, B_align, B_comm, B_negotiate, B_exec)：
- **B_align** = (ε_align, max_rounds, disagreement_budget)；**B_comm** = (bytes/s, msg_rate, retransmit_limit)；**B_negotiate** = (rounds, reallocate_limit)。
- **PCE+++++ VOI**：
```
voi_collab(π) = VOI_meta_pessimistic(π) − cost_cog(π) − cost_collab(π) − cost_exec(π)
cost_collab = λ_comm·CommCost + λ_align·AlignCost(rounds) + λ_neg·NegotiationCost
```
- **降级阶梯**：B_align 耗尽 → 用「陈旧度界 staleness ≤ δ_shared」的共享信念 + 保守 CLL；B_comm 耗尽 → 本地闭环（复用第 60 轮）；B_negotiate 耗尽 → **安全优先的领导者裁决 + 各机独立安全监视**；B_exec 耗尽 → 原有执行降级。

**定义 168（协同安全证书 J_collab 与全局协同安全定理 GCSC）**
- **证书**：J_collab = (β_fused, C_robust, Snapshot(CEG), rounds, safety_witness, ρ_corr_estimate)。
- **定理（GCSC）**：设 A66–A70 成立：
  - **(A66)** IBS 可信集覆盖率 ≥ 1−α；**(A67)** C_robust 对可信集内任意意图安全，空交时 C_freeze 安全；**(A68)** CAIA 融合在相关结构未知时不乐观；**(A69)** CCL meet 只收紧硬约束、冲突必冻结/重分配；**(A70)** CEG 因果投递保证全局一致快照。
  - 则：(1) **意图鲁棒性**：若真实意图 i*∈I_τ，执行满足 φ(i*)；(2) **对齐一致性**：β_fused 不因相关证据而过度自信；(3) **约束协同性**：任意机器人不会执行违反他机硬约束的动作；(4) **证据因果性**：任何被接纳的协同历史都是 CEG 的一致割；(5) **降级安全性**：任一 B_collab 耗尽均落到已验证的安全模式。

## 2. 关键算法伪代码

### IP-161 IBS（意图信念与可信集）

```python
class IntentBeliefState:
    def __init__(self, intents, trans, tau=0.15):
        self.I = intents
        self.T = trans
        self.p = np.ones(len(intents)) / len(intents)
        self.tau = tau

    def update(self, obs, obs_model):
        prior = self.T.T @ self.p
        lik = np.array([obs_model(obs, i) for i in self.I]) + 1e-12
        self.p = prior * lik
        self.p /= self.p.sum()
        return self.p

    def credible_set(self):
        idx = np.where(self.p >= self.tau)[0]
        return [self.I[i] for i in idx] if len(idx) else [self.I[int(np.argmax(self.p))]]

    def ambiguity(self):
        return float(-(self.p * np.log(self.p + 1e-12)).sum())
```

### IP-162 RIC（可信集 -> 鲁棒约束）

```python
def robust_intent_constraint(beta, phi, freeze):
    credible = beta.credible_set()
    admissible = None
    for i in credible:
        a = phi(i)
        admissible = a if admissible is None else intersect(a, admissible)
    if admissible is None or is_empty(admissible):
        return ConstraintResult(set=freeze, status="FREEZE_CLARIFY")
    return ConstraintResult(set=admissible, status="OK")
```

### IP-163 CAIA（相关性感知对齐）

```python
def correlation_aware_align(beliefs, eps_align=1e-2, max_rounds=5):
    p_list = [b.p for b in beliefs]
    fused = p_list[0]
    for rnd in range(max_rounds):
        w = log_linear_weights(p_list)
        fused = np.exp(sum(w[i] * np.log(p_list[i] + 1e-12)
                          for i in range(len(p_list))))
        fused /= fused.sum()
        if max_pairwise_sym_kl(fused, p_list) < eps_align:
            return fused, rnd + 1, "ALIGNED"
        p_list = [0.5 * (p + fused) for p in p_list]
    return fused, max_rounds, "ALIGN_INCOMPLETE"

def covariance_intersection(covs, grid=21):
    best = None
    for ws in simplex_grid(n=len(covs), step=1.0 / (grid - 1)):
        P_inv = sum(ws[i] * np.linalg.inv(covs[i]) for i in range(len(covs)))
        P = np.linalg.inv(P_inv)
        if best is None or np.linalg.det(P) < best[0]:
            best = (np.linalg.det(P), P)
    return best[1]
```

### IP-164 CCL（协同约束格 / 契约合并）

```python
def merge_contracts(contracts):
    H = union(c.H for c in contracts)
    feasible, x = lp_intersection(H)
    if not feasible:
        return MergeResult(status="CONTRACT_CONFLICT", H=H, S=None)
    S = pareto_select([c.S for c in contracts],
                      priority=[c.pi for c in contracts])
    return MergeResult(status="OK", H=H, S=S, witness=x)
```

### IP-165 CEG（向量时钟与因果投递）

```python
class CollaborativeEvidenceGraph:
    def __init__(self, n_robots):
        self.vc = [0] * n_robots
        self.events = {}

    def local_event(self, r, payload):
        self.vc[r] += 1
        e = Event(robot=r, vc=tuple(self.vc), payload=payload,
                  hash=sha256(payload))
        self._accept(e)
        return e

    def receive(self, msg, r):
        if not self._causal_past_present(msg.vc, msg.robot):
            return "BUFFER"
        self.vc = [max(self.vc[k], msg.vc[k]) for k in range(len(self.vc))]
        self.vc[r] += 1
        self._accept(Event(robot=msg.robot, vc=tuple(msg.vc),
                           payload=msg.payload, hash=msg.hash))
        return "ACCEPT"

    def snapshot(self):
        return {k for k, e in self.events.items()
                if self._causal_past_present(e.vc, e.robot)}
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| IBS | O(N_I²)（稀疏 T 可 O(N_I)） | O(N_I) | 可信集覆盖率 ≥ 1−α |
| RIC | O(|I_τ|·dim) 交集 | O(dim) | 空交必冻结/澄清 |
| CAIA | O(Rnds·|R|·N_I)（离散）/ O(Rnds·|R|·d³)（CI） | O(|R|·d²) | CI 不乐观（Loewner） |
| CCL | O(LP) | O(#H) | 硬约束只紧不松；冲突必冻结 |
| CEG | O(1) 摊还/事件，O(|R|) VC 比较 | O(|E|·|R|) | 因果投递 ⇒ 一致割 |
| MISEC | O(闭环) | 复用 | 全局协同安全（GCSC） |

**正确性定理（GCSC）**：在 A66–A70 下，(1) 真实意图在可信集内时执行满足其约束；(2) 融合信念在未知相关结构下不乐观；(3) 硬约束合并不被共识放宽，冲突冻结；(4) 接纳历史是一致割；(5) 预算耗尽落入安全降级。

### IP-161 IBS（意图信念与可信集）

```python
class IntentBeliefState:
    def __init__(self, intents, trans, tau=0.15):
        self.I = intents
        self.T = trans
        self.p = np.ones(len(intents)) / len(intents)
        self.tau = tau

    def update(self, obs, obs_model):
        prior = self.T.T @ self.p
        lik = np.array([obs_model(obs, i) for i in self.I]) + 1e-12
        self.p = prior * lik
        self.p /= self.p.sum()
        return self.p

    def credible_set(self):
        idx = np.where(self.p >= self.tau)[0]
        return [self.I[i] for i in idx] if len(idx) else [self.I[int(np.argmax(self.p))]]

    def ambiguity(self):
        return float(-(self.p * np.log(self.p + 1e-12)).sum())
```

### IP-162 RIC（可信集 -> 鲁棒约束）

```python
def robust_intent_constraint(beta, phi, freeze):
    admissible = None
    for i in beta.credible_set():
        a = phi(i)
        admissible = a if admissible is None else intersect(a, admissible)
    if admissible is None or is_empty(admissible):
        return ConstraintResult(set=freeze, status="FREEZE_CLARIFY")
    return ConstraintResult(set=admissible, status="OK")
```

### IP-163 CAIA（相关性感知对齐）

```python
def correlation_aware_align(beliefs, eps_align=1e-2, max_rounds=5):
    p_list = [b.p for b in beliefs]
    fused = p_list[0]
    for rnd in range(max_rounds):
        w = log_linear_weights(p_list)
        fused = np.exp(sum(w[i] * np.log(p_list[i] + 1e-12)
                          for i in range(len(p_list))))
        fused /= fused.sum()
        if max_pairwise_sym_kl(fused, p_list) < eps_align:
            return fused, rnd + 1, "ALIGNED"
        p_list = [0.5 * (p + fused) for p in p_list]
    return fused, max_rounds, "ALIGN_INCOMPLETE"

def covariance_intersection(covs, grid=21):
    best = None
    for ws in simplex_grid(n=len(covs), step=1.0 / (grid - 1)):
        P_inv = sum(ws[i] * np.linalg.inv(covs[i]) for i in range(len(covs)))
        P = np.linalg.inv(P_inv)
        if best is None or np.linalg.det(P) < best[0]:
            best = (np.linalg.det(P), P)
    return best[1]
```

def merge_contracts(contracts):

### IP-165 CEG（向量时钟与因果投递）

```python
class CollaborativeEvidenceGraph:
    def __init__(self, n_robots):
        self.vc = [0] * n_robots
        self.events = {}

    def local_event(self, r, payload):
        self.vc[r] += 1
        e = Event(robot=r, vc=tuple(self.vc), payload=payload,
                  hash=sha256(payload))
        self._accept(e)
        return e

    def receive(self, msg, r):
        if not self._causal_past_present(msg.vc, msg.robot):
            return "BUFFER"
        self.vc = [max(self.vc[k], msg.vc[k]) for k in range(len(self.vc))]
        self.vc[r] += 1
        self._accept(Event(robot=msg.robot, vc=tuple(msg.vc),
                           payload=msg.payload, hash=msg.hash))
        return "ACCEPT"

    def snapshot(self):
        return {k for k, e in self.events.items()
                if self._causal_past_present(e.vc, e.robot)}
```
