# 第 3 轮迭代（灵感循环 v3 · 第 1 轮：「灵巧手」×「自然语言指令」）—— 接口真相驱动的 UIP 清单 v3

> 承接上一版 v2（UIP-01′~15）。本轮先做一件比“继续加创新点”更重要的事：**把两个灵感词落回官方接口与数据格式**。结论有点反直觉：**在这场比赛里，“灵巧手”在接口上只有 1 个自由度，“自然语言指令”在训练数据里根本没有对应列**。这不是坏消息，而是两条最硬的约束；谁先把策略设计成“1 维手 + 3 维腕 + 接触探测”和“一次性语言编译 + 视觉反馈”，谁就避开了大量看似聪明、实则不可执行的方案。

## 0. 先给直觉：两个“以为”和两个“其实”

### 0.1 灵巧手：以为是手指，其实是“开口 + 手腕”

- **以为**：Dex1 是灵巧手，应该能控制多根手指，做指内操作（in-hand manipulation）。
- **其实**（F1，2026-11-13 核实）：提交接口的观测里，手只有 `observation.state.left_gripper[1]` / `right_gripper[1]`；动作里也只有 `action.left_gripper[1]` / `right_gripper[1]`。没有任何手指关节通道。
- **数据侧**（F2）：公开数据集同样是 Dex1 的 **1 通道开合**，README 的 Hand Convention 明确写 “Dex1 grippers (`left_gripper` / `right_gripper`, 1 channel each)”，范围 **5.5 → 0.0（open → close）**。数据里另有 `action.gripper_controls[4]`（left/right trigger + squeeze），但**接口不暴露**。
- **直觉结论**：在这场比赛里，手不是“多指灵巧手”，而是一个**位置控制的平行夹爪**。真正的灵巧性预算被转移到：**腕部 3 个旋转自由度**（`left_arm[7]` 的 `wrist_yaw/wrist_roll/wrist_pitch`）、**臂的位姿**、**底盘/腰 `pivot[7]`**，以及**与环境接触时的被动柔顺**。
- **可执行的设计**：不要去“控制手指”，而要做三件事：① 用腕部在接触前把夹爪轴线转到能夹住物体的方向；② 用 1 维开口的**轨迹形状**（快合、慢合、微开、保持）来调节接触力/滑动；③ 用 `pivot` 把物体带到舒适工作空间，避免腕部极限。

### 0.2 自然语言指令：以为是逐步对话，其实是“每 episode 一句常量”

- **以为**：语言会随步骤更新，可以像 VLA 一样“边做边听指令”。
- **其实**（F3）：接口里 `observation.language` 是 **scalar `str`**，描述当前 episode 的任务，**整段不变**，且必须在 `obs_delta_indices` 里声明为 `[0]`（无时间轴）。
- **数据侧**（F4）：公开的 32 个数据集都是 **单任务**（`total_tasks: 1`），特征里**没有 `observation.language`**，只有 `task_index`。也就是说，**训练数据里没有“图像-语言”配对**；语言只在评测时出现。
- **直觉结论**：语言不是反馈通道，而是**任务级先验 + 免费标签空间**。它适合做三件事：① 在 episode 开始时把任务路由到正确的技能/子目标序列；② 提供物体角色与关系（“把红杯挂到架子上”）；③ 把 32 个单任务数据集组织成一个多任务标签空间，让“插入/拉链/折叠/倾倒”这些动词跨任务共享。
- **可执行的设计**：**每 episode 只解析一次**，把语言编译成有序子目标契约；之后所有反馈来自视觉 + 夹爪开合。绝不在每一步调用外部大模型（延迟、可信度、单模型合规三重风险）。

## 1. 严谨定义（先定义，再谈方案）

**定义 1（接口信息集）** 评测可见接口为 `I = (O, A, L)`：
- `O`：4 路 RGB 图像、双臂关节 `[7]×2`、EE 位姿 `[6]×2`、夹爪 `[1]×2`、`lower_body[15]`、`language`；
- `A`：共享 `pivot[7]`、`gripper[1]×2`，加 `joint` 或 `ee` 二选一的双臂动作；
- `L`：episode 常量字符串，无时间轴。

数据可见接口 `I_D` 更富：还有 `gripper_controls[4]`、`base_command[4]`、`left/right_leg[6]`、`state_torso[6]`、`state_d435[6]`、`recomputed_ee_valid[1]`。**`I_D \ I` 是离线特权信息**。

**定义 2（手部自由度瓶颈）** 手部动作维度 `d_hand = 1`（每只手），腕部 `d_wrist = 3`，臂部 `d_arm = 7`。一维闭合意味着：抓取是否可行，主要由**接触前的夹爪轴线方向 `u ∈ S²` 与开口 `g`** 决定。对物体 `o`，定义抓取可行性

`κ(o, u, g) = 1[ w_o(u) ≤ g ≤ g_max ] · 1[接触点落在摩擦锥内]`，

其中 `w_o(u)` 是物体沿 `u` 的宽度。腕部负责选 `u`，开口负责选 `g`，臂/底盘负责把夹爪中心送到位。**“灵巧手”的灵巧在这里被重参数化为“腕部预姿态 + 开口轨迹 + 接触时序”**。

**定义 3（指令契约）** 把语言 `ℓ` 编译为

`C = ⟨task_id, O*, R, S, Φ, Δ⟩`，

其中 `O*` 是带**角色**和**软属性**的物体槽，`R` 是空间/关系约束，`S = ((s_1,w_1),…,(s_K,w_K))` 是与 32 任务计分点对齐的有序子目标（`Σw_k=100`，`w_K≥w_{K-1}`），`Φ={φ_k}` 是可观测成功谓词，`Δ` 是已知人为干扰。编译器 `f: ℓ → C` 采用“规则优先 + 小型文本编码器回退”，**推理期不调用外部 LLM**。

**定义 4（软槽绑定与一致性门）** 对槽 `o*` 的属性 `a`，令 `m(o*) = max_{d∈D_t} sim(a, attr(d))`，`D_t` 为当前帧检测/分割候选。若 `m<τ_attr`，把该槽标为 `relaxed`（丢属性、留角色）；若角色也找不到，标为 `unresolved`，回退到几何目标（如“把可夹持物放到目标区域”）。**语言是先验，不是真值**：`unseen_object` 下指令可能提到不存在的物体（如“红杯”缺失），必须以场景为准。

**定义 5（Aperture-as-Tactile, AAT）** 令 `g_t^c` 为动作里的目标开口，`g_{t+1}^o` 为下一步观测开口，`e_t = g_t^c - g_{t+1}^o`。定义接触状态：
- `FREE`：`|e_t|<δ` 且开口跟随命令；
- `CONTACT`：命令在闭合（`g_t^c<g_{t-1}^c`），但观测开口变化 `<ε`，且 `|e_t|>δ`；
- `SLIP`：`g_{t+1}^o` 在无闭合命令时增大（物体把夹爪撑开），或腕相机中物体相对夹爪位移而 `g^o` 不变；
- `JAM`：`|e_t|>δ` 连续 `m` 步且 EE 位移接近 0。

`δ, ε, m` 由数据集的 Dex1 量程与分任务分位数校准。**这是在没有触觉传感器时，接口内唯一可得的“伪触觉”信号**。

**定义 6（腕中心技能原语）** 原语是函数 `π_p(·; θ) → (Δp, ΔR_wrist, g(·))`，在 `h` 步内生成臂/腕位移、腕旋转与开口轨迹；灵巧性参数化为 `θ=(方向, 螺距, 速度, 开口曲线, 柔顺增益)`。原语集合 `P = {REACH, GRASP, TWIST_INSERT, HELICAL_SEAT, PULL_BACK, ZIP_PULL, PEEL_OPEN, POUR, PLACE, RELEASE}`。**原语是解析轨迹生成器，不是第二个神经网络**；选择与参数由共享骨干输出，满足“单模型”合规。

**定义 7（语言监督的技能共享）** 32 个数据集是单任务的、无语言的。用任务名、计分点、物体槽合成指令集 `L_syn`，把每个 episode 的标签写成 `(ℓ, task_index)`。训练时用一个共享骨干 + 语言条件，学到的不是 32 个孤立策略，而是**以动词为共享维度的技能空间**；`unseen_object`/paraphrase 下仍能靠动词与关系泛化。

## 2. 瓶颈假设（本轮）

- **H1（手）**：1 维手 + 3 维腕 ⇒ 灵巧性增益主要来自**接触前腕部预姿态**与**开口轨迹**，而不是指内操作；把腕部用好，比“假装有多指”更有效。
- **H2（触）**：`g^c` 与 `g^o` 的差是接口内免费的接触/滑动/卡滞信号；AAT 能把“盲插”变成“有接触反馈的插入”。
- **H3（语言）**：语言是 episode 常量 ⇒ 解析一次、缓存；每步调用 LLM 是延迟方差与合规的双重风险。
- **H4（数据）**：公开数据无语言列 ⇒ 语言监督必须合成；32 数据集合并成多任务标签空间后，**动词级跨任务迁移**是主要收益。
- **H5（不一致）**：`unseen_object`/人为干扰下，指令可能指向不存在的物体或已被撤回的状态 ⇒ 必须有软槽 + 一致性门 + 回退，不能把语言当硬约束。

## 3. 本轮修剪与新增

- **升级**：v2 UIP-01′（滚动验证）→ **UIP-23 CVR**（契约条件化验证 + 撤回重做）；v2 UIP-05（语言→可供性）→ **UIP-16 LSC**（语言→计分步契约）；v2 UIP-09′（撤回重做）→ 接入 AAT，形成“接触级 + 进度级”双恢复；v2 UIP-13/14 → 接触相位调度 + 原语图。
- **保留**：v2 UIP-02′（计分步安全网）、UIP-08′（多端口延迟工程）、UIP-15（可信度安全阀）、UIP-11/12（Gazebo 离线判分/造数据，降为“测试床”而非主线）。
- **降级/封存**：任何“多指控制、触觉阵列、逐步语言对话、推理期外部 VLM”的方案——接口或合规不支持。
- **新增（命中两词）**：UIP-16 LSC、UIP-17 SSG-L、UIP-18 AAT、UIP-19 WCD、UIP-20 PDD、UIP-21 IPR、UIP-22 DBR。

## 4. 本轮最大风险

**一句话**：如果把“语言”当成可靠真值、把“1 维夹爪”硬当成灵巧手，`unseen_object` 的指令-场景不一致或 AAT 的接触误判会让策略把错误契约执行到底；所以必须用软槽 + 一致性门 + 接触置信度尽早弃权/回退。

**→ 本轮最值得押注：UIP-16 LSC × UIP-18 AAT × UIP-19 WCD 组成的 L2D（Language-to-Dexterity）闭环**——它同时利用了两个灵感词在接口里的真实形态：语言只解析一次成契约，灵巧性落在腕部与开口，反馈来自免费的伪触觉；全部在选手 API 权限内。

  4 图 + 双臂[7]×2 + EE[6]×2 + 夹爪[1]×2 + lower_body[15]

                    │
        ┌───────────┴────────────┐
        ▼                        ▼
  UIP-16/17/21               UIP-18/19/22/23
  语言 → 契约（一次）        视觉 + 伪触觉 → 执行（每步）

## 3. 旗舰 L2D-Exec 深潜

### 3.1 契约示例：T19 ZipUp（v2 计分 50/50）

```yaml
ell: "zip up the bag"
C:
  task_id: T19
  O*:
    - role: bag
      attrs: {}
      status: bound
    - role: zipper_slider
      attrs: {}
      status: bound
  R:
    - slider on bag
    - pull direction = close
  S:
    - {subgoal: grasp_slider, weight: 50}
    - {subgoal: pull_to_end,  weight: 50}
  Phi:
    - slider_grasped
    - zipper_closed
  Delta:
    - bag moved left
    - "human reopens after zipped"
```

### 3.2 接触相位状态机

```text
APPROACH ──> ALIGN ──> GRASP ──> CONTACT ──> MANIPULATE ──> RELEASE
                │          │          │            │
                │          │          │            └─ JAM/SLIP ─> RECOVER
                │          │          └─ AAT=FREE at g_min ─> GRASP_SEARCH
                │          └─ AAT=CONTACT
                └─ 契约槽未绑定 ─> 几何回退
```

- `GRASP_SEARCH`：夹到 `g_min` 仍 `FREE` ⇒ 物体没夹住/几何未知；开口回 `g_0`，绕接近轴转 `Δψ`，重试；超过 `R_max` 则 DBR 换视角/换基座位。
- `RECOVER`：`JAM` ⇒ 小步回退 + 减小进给；`SLIP` ⇒ 加大闭合量/换夹持轴；`regressed`（人为撤回）⇒ 回到对应子目标重做。

### 3.3 主循环伪代码

```python
class L2DPolicy:
    def __init__(self, backbone, parser, prims, aat, max_redo=2, K_MAX=8):
        self.backbone = backbone      # 唯一学习模型（共享骨干）
        self.parser = parser          # 规则 + 小型文本头（属于共享骨干）
        self.prims = prims            # 解析轨迹生成器
        self.aat = aat                # 算术状态机
        self.max_redo = max_redo
        self.K_MAX = K_MAX

    def reset(self):
        self.C = None
        self.g = 0
        self.phase = "APPROACH"
        self.redo = 0
        self.last_g_cmd = None
        self.last_aat = "FREE"

    def get_action(self, obs):
        if self.C is None:                      # 每 episode 只解析一次
            self.C = self.parser.parse(obs["observation.language"])
            self.C = self.parser.bind_and_gate(self.C, obs)

        self.last_aat = self.aat.update(obs, self.last_g_cmd)
        st = self.verify(obs, self.C.Phi[self.g])

        if st == "done":
            self.g = min(self.g + 1, len(self.C.S) - 1)
            self.redo = 0
            self.phase = "APPROACH"
        elif st == "regressed" and self.redo < self.max_redo:
            self.redo += 1
            self.phase = "APPROACH"
        elif self.last_aat in ("JAM", "SLIP"):
            self.phase = "RECOVER"

        prim, params = self.backbone.select(
            contract=self.C, subgoal=self.g, phase=self.phase,
            aat=self.last_aat, obs=obs)
        if self.phase == "RECOVER":
            prim, params = self.prims.recover(prim, params, self.last_aat)

        k = self.pick_k(self.phase)             # 接触相位用小 k
        chunk = self.prims.rollout(prim, params, obs, T=k)
        self.last_g_cmd = chunk[-1]["gripper"]
        return chunk

    def verify(self, obs, phi):
        # 契约谓词：几何/关系/视觉；返回 done / ongoing / regressed / fail
        ...

    def pick_k(self, phase):
        return {"APPROACH": self.K_MAX, "ALIGN": 4,
                "GRASP": 2, "CONTACT": 1, "MANIPULATE": 2,
                "RELEASE": 2, "RECOVER": 1}.get(phase, 4)
```

> 说明：`k` 的选择受 `metadata.action_chunk_size` 的全局上限约束；每次返回 `≤ K_MAX` 步，评测端每次都会重新调用，符合 README §3。

### 3.4 接口合规清单

## 4. UIP-18 · AAT（Aperture-as-Tactile）

### 4.1 信号定义（把开口归一化到 `g ∈ [0,1]`，0=闭，1=开）

- 跟踪误差：`e_t = g_t^c - g_{t+1}^o`
- 命令闭合：`Δg_t^c = g_t^c - g_{t-1}^c < -ε_c`
- 观测停滞：`|Δg_{t+1}^o| = |g_{t+1}^o - g_t^o| < ε_o`
- 接触：`Δg_t^c < -ε_c` 且 `|Δg_{t+1}^o| < ε_o` 且 `|e_t| > δ`
- 滑动：无开命令时 `Δg_{t+1}^o > ε_o`；或腕相机中物体相对夹爪位移而 `g^o` 不变
- 卡滞：`|e_t| > δ` 连续 `m` 步且 EE 位移 `< ε_p`

### 4.2 校准

- 离线：用数据集中“空夹闭合”片段估计 `e_t` 的 95 分位作为 `δ`；用接触密集任务（T05/T10/T26/T19）估计 `ε_o`。
- 在线：每个 episode 首次闭合若在预期物体处仍 `FREE`，说明阈值偏保守或物体缺失；只调整一次，避免振荡。
- 迟滞：状态进入需要连续 `2` 帧确认，退出需要连续 `2` 帧；防止抖动导致反复重试。

### 4.3 伪代码

```python
def update(self, obs, last_cmd):
    g_cmd = self.last_g_cmd
    g_obs = norm(float(obs["observation.state.left_gripper"][0]))
    e = g_cmd - g_obs
    dg_cmd = g_cmd - self.prev_cmd if self.prev_cmd is not None else 0.0
    dg_obs = g_obs - self.prev_obs

    if dg_cmd < -self.eps_c and abs(dg_obs) < self.eps_o and abs(e) > self.delta:
        cand = "CONTACT"
    elif dg_obs > self.eps_o and dg_cmd >= -self.eps_c:
        cand = "SLIP"
    elif abs(e) > self.delta and self.ee_speed(obs) < self.eps_p:
        cand = "JAM"
    else:
        cand = "FREE"

    self.state = self.hysteresis(self.state, cand)
    self.prev_cmd, self.prev_obs = g_cmd, g_obs
    return self.state
```

### 4.4 失败与护栏

- **误报 CONTACT**：夹爪空行程摩擦/回差也会产生误差。对策：空夹校准、视觉交叉验证（物体是否在指间）、连续帧确认。
- **漏报 SLIP**：物体很轻、开口变化小。对策：用腕相机光流做第二证据；在 `MANIPULATE` 阶段周期性微开-再合（dither）以探测。
- **反复重试**：AAT 进入 `JAM/SLIP` 后最多重试 `R_max` 次，超过则交给 CVR 回退到上一子目标；延迟预算由 v2 UIP-15 约束。

## 5. UIP-19 · WCD（腕中心灵巧原语）

### 5.1 原语表

| `TWIST_INSERT` | `v, ω, r, α` | 螺旋进给 + 腕旋转 + 开口收紧 | T05/T10/T12/T26 |
| `HELICAL_SEAT` | `ω, α` | 小角度旋转就位 | T10/T26 |

### 5.2 螺旋插入（推导）

设插入轴 `u`，正交基 `e_1,e_2`，初始位姿 `p_0,R_0`：

```text
p(t) = p_0 + v·t·u + r(cos(ωt)-1)e_1 + r·sin(ωt)e_2
R(t) = R_0 · R_u(ωt)
g(t) = clamp(g_0 - α·t, g_min, g_0)
```

- 直到 AAT=`CONTACT`：保持进给，`α` 控制夹持力；
- `CONTACT` 后：`g(t)` 保持，`v` 降到 `v_seat`，用小 `ω` 完成就位；
- `JAM`：`v ← -βv` 持续 `τ` 步，再以更小 `r` 重试；
- `SLIP`：`α` 增大或换夹持轴 `u`。

参数 `(v, ω, r, α)` 由共享骨干输出初值，再用 v2 UIP-11 GSO 做离线结构搜索、真机做接触校准。**不把螺旋写死成“万能解”**；它只是一个强先验，残差由策略头修正。

### 5.3 抓取搜索（针对 unseen object）

```python
def grasp_search(self, obs, C, slot):
    for r in range(self.R_max):
        self.prims.close_to(g_min)
        if self.aat.state == "CONTACT":
            return "GRASPED"
        self.prims.open_to(g_0)
        self.prims.rotate_wrist(axis=self.approach_axis, angle=Delta_psi)
    return "NEED_REOBSERVE"   # 交给 DBR 换视角/基座位
```

### 5.4 与 ACS/CSG 的结合

- `APPROACH/ALIGN`：大 `k`（少往返）；
- `GRASP/CONTACT/RECOVER`：小 `k`（高频重观测，快速纠错）；
- 所有重试受 v2 UIP-15 的延迟预算、抖动上限、最大次数约束；
- 动作形态平滑：螺旋/回退都做加速度限幅，避免“统计规律性异常”。

### 6.2 解析算法（每 episode 一次）

```python
def parse(self, ell):
    toks = normalize(ell)                     # 小写、同义词、去冠词
    scores = {t: rule_score(toks, t) for t in TASKS}
    t = argmax(scores)
    if scores[t] < self.tau_rule:             # 规则不够，走文本头
        t = self.text_knn(toks)               # 共享骨干内的小文本头
    C = TEMPLATES[t].instantiate(toks)        # 填角色/属性/关系
    C.S = SCORING[t]                          # 32 任务计分步
    return C
```

### 6.3 合成语言监督（离线）

- 每个任务 10–20 条模板改写：`"zip up the bag"` / `"close the zipper on the backpack"` / `"pull the zipper shut"`；
- 槽替换：颜色、形状、容器、目标位置；
- 干扰句：加入无关从句，训练解析器抓主干；
- 语言 dropout：训练时以概率 `p` 去掉语言，强迫视觉也可路由，避免“只会背任务名”；
- **推理期不使用外部 LLM**；离线若用本地 LLM 生成，只进入训练集，不进入提交物。

### 6.4 一致性门（语言是先验，不是真值）

```python
def bind_and_gate(self, C, obs):
    dets = self.backbone.ground(obs)          # 检测/分割/关系候选
    for slot in C.O:
        cands = [d for d in dets if role_match(slot.role, d)]
        if not cands:
            slot.status = "unresolved"        # 角色都不在
            continue
        best = max(cands, key=lambda d: attr_sim(slot.attrs, d))
        if attr_sim(slot.attrs, best) < self.tau_attr:
            slot.status = "relaxed"           # 属性不匹配，丢属性留角色
            slot.attrs = {}
        else:
            slot.status = "bound"
        slot.target = best
    if any(s.status == "unresolved" for s in C.O):
        C = self.geometric_fallback(C, obs)   # 用 κ(o,u,g) 选最可夹持物
    return C
```

**关键点**：`unseen_object` 下，指令可能说“红杯”但场景没有红杯；此时保留“杯/可挂物”角色，丢“红”属性；若连角色都没有，则用几何可行性 `κ` 选替代物。**绝不让解析失败直接变成执行失败**。

## 8. 支撑组件：PDD / IPR / DBR

### 8.1 UIP-20 · PDD（特权数据蒸馏）

- **教师输入**：`gripper_controls[4]`、`base_command[4]`、`lower_body[15]`、`state_torso[6]`、`state_d435[6]`、`recomputed_ee_valid[1]`；
- **学生输入**：接口子集（4 图、双臂、EE、夹爪、`lower_body`、语言）；
- **损失**：动作模仿（双臂、夹爪、`pivot`）+ 特权通道辅助预测 + 特征蒸馏；
- **收益**：数据里有更细的手部控制与基座指令，可教学生“为什么这样动”，但推理期不偷看；
- **红线**：训练/推理输入白名单硬编码；单元测试确保评测路径永不读取数据独有键；不使用未来帧。

### 8.2 UIP-21 · IPR（指令改写鲁棒性）

- 训练：模板改写 + 槽替换 + 干扰从句 + 语言 dropout；
- 对齐：语言嵌入与首帧场景嵌入做对比学习，硬负例 = 错任务/错物体；
- 评测：留出改写集与未见属性组合，单独报“解析准确率 / 槽绑定准确率 / 任务成功率”；
- 目标：改写不降点，缺物能回退。

### 8.3 UIP-22 · DBR（自由度预算路由）

对每个相位选择自由度家族：

```text
transport : base + arm        （大位移，避免腕极限）
fine      : arm + wrist       （小位移对准）
contact   : wrist + gripper   （冻结臂，减少接触扰动）
release   : gripper + arm     （小回退）
```

代价 `J = w1·距离 + w2·腕饱和 + w3·jerk + w4·延迟`，取 `argmin J`。这不是第二个模型，而是一个带物理约束的小优化；好处是动作更平滑（可信度）、腕不易到极限、物体被移动时可用 `pivot` 重新够到。

## 12. 本轮最大风险 & 押注

**一句话**：L2D 的最大风险不是模型不够大，而是**把“语言契约”与“接触判断”这两个先验同时信错**——语言在 `unseen_object` 下可能指向不存在的物体，AAT 在回差/摩擦下可能把空行程当接触；两者一错，策略会自信地执行错误子目标。因此软槽、一致性门、AAT 置信度与 CVR 回退必须是一等公民，而不是事后补丁。

**→ 押注：UIP-16 LSC × UIP-18 AAT × UIP-19 WCD 的 L2D 闭环**。它不假设多指灵巧手、不假设逐步语言、不依赖外部大模型，完全落在 README 暴露的接口内；同时把“灵巧手”与“自然语言指令”这两个灵感词，翻译成了可执行、可消融、可证伪的三个机制：**一次编译的契约、免费的伪触觉、腕中心的原语**。
