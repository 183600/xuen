# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~301；本轮灵感：「实时性」×「运动规划」）

> R73 把证据计量做成可组合契约（EC / CCA / ΣREFLEX / PVOP / CPB），回答的是「不确定度能否组合」。但它对**时间**只有一个静态 `wcet_us` 字段，留下三个时间盲点：
> - **时间不是证据维度**：契约说「u 是多少」，不说「证据有多旧」。deadline miss、release jitter、响应时间尾部、抢占/卸载造成的延迟全部落在证书之外；一帧 u=0.01 的深度证据若已过期 300ms，在 0.5m/s 运动下其真实位置不确定度远大于 0.01。把「观测时刻的 u」当成「决策时刻的 u」，与 R72/R73 批判的「把接触不确定度误读为位姿不确定度」「把深度不确定度误读为几何不确定度」是**同型错误的时间版**。
> - **「算得快」≠「算得久更安全」**：PVOP 以 20Hz/2ms 求解是吞吐量叙事。真实运动规划中，计算时间、运动时间、传感延迟竞争**同一段墙钟**；机器人无法暂停世界来多算 5ms。R73 没有回答「多算一点值不值、什么时候必须提交」。
> - **规划吃的是过期世界**：运动规划期间障碍物在动、地图在旧。静态碰撞检查隐含「世界在规划期间冻结」；实时性真正的敌人不是平均延迟，而是**证据新鲜度与决策时延的联合违约**。
>
> 本轮两个灵感正好补两块：
> - **实时性** → **TEC（时间证据契约）× FDM（新鲜度衰减计量）× TCA（时间组合代数）**：时间升为一等证据维度；契约从「不确定度预算」扩为「不确定度 × 时延 × 新鲜度」；给出**时间箭头定理**（证据只能变旧，计算不能制造信息）与**时间组合单调性**（端到端时延/陈旧度不可能凭空变好）。
> - **运动规划** → **ACMP（Anytime 认证运动规划）× D-PVOP（Deadline 感知视角规划）× AACC（年龄感知碰撞检查）**：任意时刻可提交且证书有效；时间–运动预算守恒；由地图年龄反推速度上限（「旧地图开慢车，看不见就停」）。
>
> 核心命题：**不再问「证据能否组合」，而问「时间能否成为被审计的证据维度——使端到端 deadline 可行性与证据新鲜度成为可组合性质，并让 anytime 运动规划在任意提交时刻都持有有效安全证书？」** 把 R73 的 MODGAUGE 扩展为 **CHRONO-MODGAUGE-RAS**（CHRONOmetric evidence metrology with anytime Planning and GAUGE audits）——**时空证据经济**。

## 0. 直觉与动机

**灵感 1（实时性 → 时间是一种会「腐烂」的证据维度）**
直觉：证据不是「有/无」，而是「新/旧」。同一帧深度图，t=0 时 u=2cm；t=300ms、机器人以 0.5m/s 运动时，障碍物位置的不确定度至少增加 15cm（速度 × 年龄）。这不是噪声变大了，而是**世界在观测之后继续运动**。因此证据质量必须写成 (u, age) 的联合量：u_eff = ρ_ev(u_0, age, ẋ)。关键洞察：ρ_ev 不是拍脑袋的衰减函数——在 Kalman/贝叶斯框架下它就是**预测步**（过程噪声累积）：线性高斯下精确，非线性下取保守上界。这把 R73 的「模块组合」延伸到「时间推进」：每过一帧，每个证据都在做一次传播，而传播只会增加不确定度。**证据有半衰期，时间有箭头。**

**灵感 2（实时性 → 组合的第二个单调轴：时间组合代数）**
直觉：R73 的 CCA 只保证「空间/模块组合不能凭空变好」。时间也是一条组合轴：串联处理链的输出不可能比最旧输入更新（时间戳取 min），时延相加（L_out = L_A + L_B）；并联融合只在两路时间戳落在**相干窗 W_coh** 内才允许（否则「融合」的是两个不同时刻的世界）；否决必须在有界响应内完成（否则否决迟到 = 没否决）。于是得到**双单调性**：空间组合单调（引理 34）+ 时间组合单调（引理 39）。**没有时间上的免费午餐**：任何组合路径都不可能比其输入更新、也不可能比其输入时延更短。

**灵感 3（实时性 → 响应时间不是数，是分布；WCET 不可组合）**
直觉：R73 的 `W` 是一个静态标量，隐含「各模块执行时间互不干扰」。真实系统里 CPU 缓存、内存带宽、调度器让模块互相拖慢——**良性任务也能造成 deadline miss（timing anomaly）**。因此时间契约必须声明**隔离等级 κ_int** 与**响应时间尾部**（而非单一 WCET）；时间组合只在同一隔离等级内可证，跨等级必须重新推导。这把「实时性」从「平均值/最坏值」升级为「在声明干扰包络下的可证尾部」。

**灵感 4（运动规划 → Anytime 认证：任意时刻都能安全提交）**
直觉：标准 anytime 规划器（RRT*、Anytime A*）在早期阶段往往「还没有可行解」或「解的质量证书无效」——它保证「给的时间越多越好」，却不保证「在任意 deadline 提交都安全」。机器人不会等算法收敛，它在 16ms 控制周期里必须动。正确性质是 **commit-at-any-time**：规划器在每一时刻都持有一个**可行**计划与一个**有效下界证书** Q_t，且 Q_t 单调不降；到点就把当前计划连同证书一起提交，风险 ≤ Q_t。这把 R72 的 `certified_prefix` 从「控制域前缀」推广到「规划域任意时刻」。

**灵感 5（运动规划 → 时间–运动是同一枚硬币；旧地图开慢车）**
直觉：计算花掉的 20ms 和运动花掉的 20ms 是同一段墙钟——多算就不能多动，多动就没有时间重算。更深的是：运动规划吃的是带年龄的地图。障碍物上次被看到是 a 秒前，它以 v_max 运动，则真实位置在以 `v_max·a` 为半径的球内；碰撞检查必须用**年龄膨胀半径** r_safe(a) = r + u_pos(a) + v_max·a + margin。由此自然导出**由地图年龄反推速度上限**：v ≤ (r_clear − r_safe(a))/t_react。这不是「加个安全边距」，而是把时间的物理后果显式写进几何约束——**旧地图开慢车，看不见就停**。

**灵感 6（双单调性 → 「时空证据经济」而非「更快的算法」）**
直觉：R73 关心「组合不产生认知免费午餐」；本轮加上「时间不产生认知免费午餐」。两个资源（证据质量、时间）都被动作消耗：运动改变视角（χ_v）也消耗时间（Λ），计算改善计划（A_any）也消耗时间（C），传感获取证据（S）也要时间。**规划的本质是在同一 deadline 下分配这三类时间去买三类价值**。这把实时性从工程指标（延迟、吞吐）升为一个**计量目标**：可审计的时–空预算配置。

## 1. 形式化定义（增量：定义 383–396）

**定义 383（CHRONO-MODGAUGE-RAS 总览与六不变式）**
CHRONO-MODGAUGE = (MMS†, DPEM†, CCA†, TEC, FDM, TCA, ACMP, D-PVOP, AACC, TIB, CPB†, MODGAUGE†)。六不变式 = R73 五条 + ：
(vi) **时间完备性**：模块图中每个节点声明 TEC（定义 384）；端到端时延与陈旧度经 TCA（定义 386）组合；无干扰感知响应时间界的时间路径不得签发 deadline 证书。

**定义 384（时间证据契约 TEC）**
TEC = EC† ∪ (D_exec, F_R, ρ_ev, W_coh, κ_int, A_any, s_t)：
- D_exec：相对/绝对截止期（含 release jitter J_r）；
- F_R：响应时间分布 / 可证尾界（替代标量 WCET），F_R(τ)=P(R≤τ) 或 (C, I_max) 确定界；
- ρ_ev：新鲜度传播算子 u_eff(a) = ρ_ev(u_0, a, ẋ)（Kalman 预测步或其保守上界）；
- W_coh：并联融合相干窗（时间戳差 ≤ W_coh 才许缩窄）；
- κ_int：隔离等级（核 / Cache 分区 / 内存带宽份额 / 调度类）；
- A_any：anytime 剖面 τ ↦ (u_plan(τ), Q(τ))（质量/证书随分配时间单调改进）；
- s_t：时序追溯模式（单调时钟域、时间戳签名、发布-订阅语义）。
平凡情形 A_any ≡ ⊥（非计算模块）、ρ_ev = id（证据瞬时有效）——**逐指令退化为 R73 的 EC**。

**定义 385（新鲜度衰减计量 FDM）**
证据 e 时间戳 t_s，决策时刻 t，年龄 a = t − t_s。在动力学模型（速度界 v_max、过程噪声 Q）下：
u_pos(a) = u_pos(0) + v_max·a（确定性 Lipschitz 球增长）；
Σ(a) = Σ_0 + ∫_0^a Q dτ（随机情形，即 Kalman 预测步）；
u_eff(a) = ρ_ev(u_0, a, ẋ) ≥ u_0，且 **a_1 ≤ a_2 ⇒ u_eff(a_1) ≤ u_eff(a_2)**（单调非减）。
**新鲜域** D_t = {a ≤ τ_fresh}；**陈旧代价** Λ = E[u_eff(执行时刻的年龄)]。混合新旧证据 = 对旧证据先预测再加权——**旧证据不能靠「和新证据平均」变新**。

**定义 386（时间组合代数 TCA）**
时序证据 e = (u, t_s, D, τ, I⊥, A_any, L)（L 为端到端时延）。三算子：
- **SER**：L_out = L_A + L_B；t_{s,out} = min(t_{s,A}, t_{s,B})（输出不可能比最旧输入新）；u_out 由 CCA 串联给出，但用**执行时刻**而非观测时刻评估 u_eff；D_out = D_A ∩ D_B；D_exec,out = min(D_exec,A, D_exec,B − L_A)。
- **PAR**：仅当 |t_{s,A} − t_{s,B}| ≤ W_coh 且一致性审计通过才允许缩窄；否则 u_out = max(u_eff,A, u_eff,B)、t_{s,out} = min、并发 `COH_WINDOW_FAIL` 否决；L_out = max(L_A, L_B)。
- **VETO**：须在 min(D_exec,A, D_exec,B) 内有界完成；任一否决即否决（非补偿）。
**引理 39（时间组合单调性）**：任何组合路径的 t_{s,out} ≤ min 输入时间戳、L_out ≥ max 输入时延；不存在「更年轻/更快」的组合路径。

**定义 387（时间–运动预算守恒 TB）**
墙钟区间 [t, t+T_D] 被划分为计算 C、运动 M、传感/通信 S 与空闲；约束 C + M + S ≤ T_D（可重叠部分由重叠矩阵 O 给出）。在约束下最大化
V = V_c(C) + V_m(M) + V_s(S) − λ_r·Risk(M, C, S)，
其中 V_c 为计算带来的计划/证书增益（由 A_any 导出）、V_m 为任务进展 + 视角证据增益（由 χ_v 导出）、V_s 为传感增益。最优点处各资源**边际价值相等**（引理 40）。**同一毫秒不能既用于算又用于动**——这是时间版的反作用预算。

**定义 388（Anytime 认证运动规划 ACMP）**
规划器在每时刻 t 维护 (π_t, Q_t, Cert_t)：
(i) π_t 可行（满足运动学/动力学约束，且对年龄膨胀障碍无碰撞，定义 390）；
(ii) Cert_t 是 π_t 的安全/代价有效下界，Q_t = safety_lb(π_t)；
(iii) 迭代只允许在**保持可行性**的修复下改进，Q_t 单调不降；
(iv) 任意 deadline τ 提交 π_τ，实际风险 ≤ Q_τ ≤ ε。
标准 anytime 只要求 (iii) 的代价改进；ACMP 额外要求 (i)(ii)(iv)——**没有「预热不安全期」**。初始种子 π_0 取「刹车到停/当前轨迹延续」，保证 t=0 即合法。

**定义 389（Deadline 感知视角规划 D-PVOP）**
a* = argmax_a [ Progress(a) − λ·E[u_depth^{next}(a)] − Σ_i c_reflex^i(a) − μ·Λ(a) ]
s.t. t_now + L_plan(a) + t_exec(a) ≤ D_external；a ∈ REG 时序契约；Ω_safe；且规划视界内每一步年龄 ≤ τ_fresh（否则必须途中重规划）。
Λ(a) = E[u_eff(执行时的年龄)] 由 ρ_ev **解析**给出（零 rollout，同 R73 χ_v 精神）。

**定义 390（年龄感知碰撞检查 AACC）**
障碍 o 最近观测年龄 a_o、速度界 v_{o,max}、位置不确定度 u_o(a_o)。膨胀半径
r_safe(a_o) = r_o + u_o(a_o) + v_{o,max}·a_o + margin_react。
碰撞检查用膨胀体；未知区域视为最坏障碍。**陈旧速度上限**：
v_max^safe(a_o) = max(0, (r_clear − r_safe(a_o)) / t_react)。
安全包络：速度是地图年龄的**非增**函数——旧地图开慢车。

**定义 391（时间威胁面 AIC-TIME）**
ℰ_time = {算法复杂度攻击（构造输入使规划器超时）、陈旧重放（重放旧帧/旧地图）、时钟攻击（NTP / 时钟域欺骗）、调度干扰（co-runner 制造 deadline miss）、时间侧信道}。防线：有界工作量解析器 + 复杂度预算、单调时钟 + 签名时间戳、隔离等级、尾部压力测试、fail-safe 停车。

**定义 392（时间降级 stub 与时序 E-IVG）**
时间失效分级：(a) 计划超时 → 提交当前证书最优计划（ACMP 保证安全）；(b) 证据陈旧 → ρ_ev 膨胀 + AACC 速度上限；(c) 地图过期到不可膨胀 → 停止 / 仅本体安全动作；(d) 时钟故障 → fail-safe 停车（继承 R71 刹车）。**时间 stub** 与 R73 模块 stub 正交：模块 stub 管「证据有无」，时间 stub 管「证据多旧」。

**定义 393（干扰感知时间隔离 TIB）**
响应时间 R_i = C_i + I_i(κ_int, workload)。契约声明隔离等级；TCA 仅在相同 κ_int 下可组合，跨等级必须重新给出 R_i 界。**禁止「最坏情况相加」跨共享资源模块**（缓存/带宽干扰不可加）。时间证书必须索引隔离等级。

**定义 394（时间证书 J_TIME）**
J_TIME = ⊗_i J_time(module_i) ⊗ J_tcomp(MReg)。校验：∀ 路径 端到端 L ≤ D_exec ∧ 执行时年龄 ≤ τ_fresh ∧ F_R 在声明 κ_int 下成立 ∧ anytime Q_t 单调且有效 ∧ 时间 stub 可达。Valid(J_TIME) ⇒ R73 风险界在 u_eff 下成立。

**定义 395（时间复杂度结构上限）**
端到端路径时延 ≤ T_D、时间组合深度 ≤ 4、时钟域 ≤ 2、anytime 迭代预算 ≤ N_any、规划器单步工作量 ≤ W_bound（有界工作量保证）——全部为可审计图/执行性质。

**定义 396（主张准入测试 CAT 与 C4）**
沿用 R73 CPB 的蒸馏纪律：新主张必须通过**主张准入测试**（预注册隔离 + 击败空模型）。C4（时间证据计量 + anytime 安全）为**候选主张**：
C4 ← (TEC, FDM, TCA, ACMP, D-PVOP, AACC, TIB) ← MB4 ← AB4（CHRONO vs 静态 WCET + 固定安全边距 vs 标准 anytime 规划器）← (deadline 违约率，陈旧致碰撞率，提交时刻风险上界，认证成本)。
若 AB4 不能显著击败空模型，C4 降级为工程附件。**C1–C3 不变，C4 可撤销。**

```python
# IP-302 TEC：时间证据契约（在 EC 上增补时间字段）
@dataclass(frozen=True)
class TemporalContract(EvidenceContract):
    d_exec_us: float                      # 相对截止期（含 jitter 另计）
    jitter_us: float                      # release jitter
    resp_tail: Callable[[float], float]   # F_R(τ)：响应时间 CDF / 可证尾界
    rho_ev: Callable[[float, float, float], float]  # (u0, age, xdot) -> u_eff
    w_coh_us: float                       # 并联相干窗
    kappa_int: int                        # 隔离等级（0=独占，1=分区，...）
    a_any: Callable[[float], Tuple[float, float]]    # τ -> (u_plan, Q)
    ts_schema: str                        # 时序追溯模式

# IP-303 FDM：新鲜度传播（Kalman 预测步 / 保守上界）
def rho_ev(u0, age, xdot, Q, vmax):
    return math.sqrt(u0**2 + (vmax * age)**2) + integrate_q(Q, age)   # 单调非减

# IP-304 TCA：时间组合代数（SER/PAR/VETO 作用于 (u, ts, L)）
def tcompose(a, b, op, now):
    if op == 'SER':
        L, ts = a.L + b.L, min(a.ts, b.ts)          # 时延相加、时间戳取最旧
        ua = rho_ev(a.u, now - a.ts, a.xdot)        # 执行时刻评估，非观测时刻
        ub = rho_ev(b.u, now - b.ts, b.xdot)
        return TE(u=cca_ser(ua, ub), ts=ts, L=L, D=a.D & b.D,
                  veto=a.veto | b.veto,
                  deadline=min(a.d_exec, b.d_exec - a.L))
    if op == 'PAR':
        if abs(a.ts - b.ts) > b.w_coh:               # 相干窗失败 → 禁止缩窄
            return TE(u=max(rho_ev(a.u, now-a.ts, a.xdot),
                            rho_ev(b.u, now-b.ts, b.xdot)),
                      ts=min(a.ts, b.ts), L=max(a.L, b.L),
                      veto=a.veto | b.veto | {'COH_WINDOW_FAIL'})
        return cca_par(a, b)                         # 仅同刻证据允许 conformal 缩窄
    if op == 'VETO':
        return TE(valid=(not a.veto and not b.veto), L=max(a.L, b.L),
                  deadline=min(a.d_exec, b.d_exec), veto=a.veto | b.veto)

# IP-305 ACMP：anytime 认证规划（任意时刻可提交）
class AnytimeCertifiedPlanner:
    def __init__(self):  self.best, self.Q = brake_to_stop(), safety_lb(brake_to_stop())
    def step(self, dt):                              # 每步保持可行性 + 证书有效
        node = self.frontier.pop_best_lower_bound()
        if not self.kinodynamically_feasible(node): return
        if self.aacc.collision_free(node, self.map_age):   # 年龄膨胀碰撞检查
            self.best = min(self.best, node)
        self.Q = max(self.Q, safety_lb(self.best))   # 单调不降
    def commit(self):                                 # 任意 deadline 调用
        return self.best, self.Q                      # 风险 ≤ Q ≤ ε

# IP-306 D-PVOP：时间–运动联合分配（KKT 等边际价值）
def deadline_aware_plan(b_t, mods, T_D, now):
    def J(alloc):                                    # alloc = (C, M, S)
        C, M, S = alloc
        if C + M + S > T_D: return -math.inf
        u_plan, Q = anytime_profile(C)               # A_any(C)
        u_view = sum(m.ec.chi_R(a).expected_u(state[m])
                     for m in depth_mods for a in M)
        stale = rho_ev(..., now)                      # Λ：执行时年龄代价
        return task_progress(M) - lambda_*u_view - mu*stale - kappa*Q
    return argmax(J, feasible_allocs(T_D))            # 引理 40

# IP-307 AACC：年龄感知碰撞检查 + 陈旧速度上限
def age_aware_collision_free(path, obs, now):
    for o in obs:
        a = now - o.ts
        r = o.r + o.u(a) + o.vmax * a + MARGIN        # 年龄膨胀半径
        if path.intersects(Sphere(o.p, r)): return False
    return True
def stale_speed_limit(obs, now, r_clear):
    r = max(o.r + o.u(now-o.ts) + o.vmax*(now-o.ts) for o in obs)
    return max(0.0, (r_clear - r) / T_REACT)          # 旧地图开慢车

# IP-308 CHRONO 主闭环（在 MODGAUGE 三域上增加时间域）
def CHRONO_round(M, obs, audio, tac_frame, depth_img):
    now = M.clock.monotonic()                         # 单调时钟（定义 391）
    # === 感知域（100Hz，Best-effort）===
    d_ev = stamp(M.dpe.update(depth_img, rgb, M.cam_state, M.motion, M.peers), now)
    if not fresh(d_ev, now): d_ev = temporal_stub(d_ev, now)   # 时间 stub（定义 392）
    # === 计量域（50Hz，软实时）===
    if M.clock.due_metric():
        timed = tcompose(d_ev, t_ev, 'PAR', now)      # TCA 组合（相干窗）
        b_t = M.bse.step_full(..., e=timed)
        plan, Q = M.acmp.commit()                     # 任意时刻可提交（定义 388）
        alloc = deadline_aware_plan(b_t, M.mods, M.T_D, now)   # IP-306
        M.pvop = plan
    # === 控制域（1kHz，硬实时，只读快照）===
    snap = M.snapshot.read_latest()
    v_cap = stale_speed_limit(snap.obstacles, now, snap.r_clear)   # AACC
    lam = embodied_risk_scale(snap.U_ale, snap.U_epi, snap.H_z,
                              max(snap.t_ev.u_eff, snap.d_ev.u_eff), M.risk_params)
    k = M.c_ras_wm.certified_prefix(snap.plan, lam, v_cap)         # 速度上限进控制
    M.ctrl_out.publish(k, lam)
    return k, lam, M.acmp.Q, J_TIME(M.mreg)           # 时间证书（定义 394）
```

## 3. 推导

**引理 38（时间箭头：证据只能变旧，计算不能制造信息）**
固定观测 y（时间戳 t_s）。决策时刻 t = t_s + a 的后验由预测核 X_{t_s} → X_t 推出。Markov 核使熵不降（数据处理不等式：H(X_t | y) ≥ H(X_{t_s} | y)）；协方差 Σ(a) = Σ_0 + ∫Q ≥ Σ_0。对固定 y 再做任意确定性计算，不能把 H(X_t | y) 降到后验熵以下（计算不增加信息）。⇒ u_eff(a) 单调非减。系：**ρ_ev 就是「时间的组合算子」——加一层时间就是做一次预测。**

**引理 39（时间组合单调性：不存在时间上的免费午餐）**
由定义 386：SER 的 t_s 取 min、L 相加；PAR 的 t_s 取 min（相干窗失败时甚至禁止缩窄）、L 取 max；VETO 的 L 取 max。对组合树归纳即得任意路径 t_{s,out} ≤ min 输入时间戳、L_out ≥ max 输入时延。系：**R73 的空间单调性 + 本轮的时间单调性 = 时空双单调性。**

**引理 40（时间–运动预算的等边际配置）**
设 V_c、V_m、V_s 在可行域内为凹增函数、Risk 为凸，约束 C+M+S ≤ T_D 为单纯形。KKT 条件给出内点最优点满足 ∂V_c/∂C = ∂V_m/∂M = ∂V_s/∂S = λ（影子价格）。严格凹 ⇒ 唯一。系：**「该多算还是多动」有可审计的判据，而不是调参；A_any 出现相变（非凹）时退化为有界搜索并记录非凹点。**

**引理 41（Anytime 提交安全：无预热不安全期）**
归纳：π_0 = 刹车到停 / 当前轨迹延续，可行且 Q_0 有效；每步只接受可行计划，Q 取 max（单调）。故任意 τ 时刻 (π_τ, Q_τ) 满足定义 388(i)(ii)(iii)，提交风险 ≤ Q_τ ≤ ε。系：**deadline miss 不再等于不安全——它只等于「计划没那么好」，而计划始终可执行、证书始终有效。** 前提是存在一个可行种子（这是标准 anytime 规划器缺的）。

**引理 42（年龄膨胀碰撞检查的保守性）**
若观测时刻 p_true ∈ Ball(p_obs, u_o)，且 |ṗ| ≤ v_{o,max}，则年龄 a 后 p_true ∈ Ball(p_obs, u_o + v_{o,max}·a)。加反应裕度 margin_react 得包含概率 ≥ 1−δ。若规划路径不进入膨胀体，则在反应时域内真实碰撞不发生。速度上限由「膨胀体沿反应视界不侵入路径」直接解出。系：**安全边距不是常数，是地图年龄的函数——「旧地图开慢车」是可证的，不是保守口令。** 失效条件：v_{o,max} 估错、障碍瞬移/对抗。

**引理 43（响应时间不可跨隔离等级相加）**
R_i = C_i + I_i(κ_int, workload)。I_i 依赖共享资源（Cache/带宽/调度）上的协作者，不能被标量 WCET 捕获；跨 κ_int 直接相加会低估 R_i（timing anomaly）。⇒ TCA 必须按 κ_int 索引；跨等级组合需实测干扰包络。系：**时间契约的「类型」不只是单位，还包括隔离等级——和证据模态隔离同构。**

**定理 30（CHRONO 严格包含 MODGAUGE）**
假设 A114（F_R 在声明 κ_int 内有效）、A115（ρ_ev 为保守预测，线性高斯下精确）、A116（ACMP 存在可行种子）。当 T_D → ∞、所有年龄 → 0、κ_int 独占、A_any ≡ ⊥ 时：ρ_ev → id、TCA → CCA、ACMP → PVOP（无限时间）、D-PVOP → PVOP、AACC → 静态检查。由定义 383(vi) 与引理 35 逐指令退化到 MODGAUGE，再退化到 R73/R72/R71/R68。**安全单调不减，效率只在时间契约满足时获益。**

**定理 31（时间证书 ⇒ deadline + 新鲜度感知安全）**
Valid(J_TIME) ⇒ 端到端时延 ≤ D_exec 的概率 ≥ 1−δ（来自 F_R 与 TCA 组合）、每个决策点年龄 ≤ τ_fresh、ACMP 证书有效。由引理 38/42，u_eff 是真实不确定度的保守界 ⇒ R73 定理 28 以 u_eff 代 u 成立 ⇒ 物理执行风险 ≤ ε。**证明分成两半：时间可行性（调度）与证据可靠性（计量），两半都须成立。**

**定理 32（任意时刻提交安全）**
ACMP 不变量（定义 388）+ 引理 41 ⇒ 任意 deadline 提交的 π_τ 可行且风险 ≤ Q_τ ≤ ε；标准 anytime 规划器在早期可能返回不可行/无证书解，故本定理严格强于「给的时间越多越好」。**实时性的正确安全语义是「随时可停、随时可交」，不是「平均够快」。**

**定理 33（时间降级零级联）**
deadline miss / 证据陈旧 → 时间 stub（提交当前证书最优 / AACC 速度上限 / 停车）维持安全不变量；模块 stub（R73 定义 381）与时间 stub 正交：前者管模态缺失，后者管时序违约。两者可同时触发而互不污染 MReg 组合校验。⇒ 时间失效的传染路径唯一（该切片变保守），无级联。

## 6. 本轮最大风险

**一句话**：CHRONO 把安全证明的一部分从「不确定度契约」转移到「**时间模型**」——如果响应时间尾部在真实负载/干扰下被低估、或 ρ_ev 的动力学模型在规划期间被违反（障碍物比假设更快、世界在计算期间发生拓扑变化、时钟域漂移），那么系统会在「**所有证书都有效、所有 deadline 看似满足**」的情况下，**准时地提交一个基于过期世界的安全计划**，而日志会证明「每一步都在预算内」——**实时性证书恰恰在最需要它的负载尖峰时刻最不可信。**

次级风险与缓解：
1. **响应时间尾部估计偏差** → 隔离等级 + 尾部压力测试（E397）+ 保守 F_R 上界 + 超时即 ACMP 提交（引理 41）。
2. **ρ_ev 模型失配（近场/高动态/拓扑突变）** → 有效域硬边界 + 在线残差校准 + 检出即速度上限/停车（AACC）。
3. **anytime 初始种子不可行** → π_0 强制为「刹车到停/当前轨迹延续」，无解也安全；禁止「先算再保证」。
4. **相干窗过宽导致跨时刻融合** → W_coh 由动力学相干时间导出 + 越窗即否决（E393）；对抗分歧触发 PAR_AUDIT_FAIL。
5. **时间–运动分配非凹/相变** → 有界搜索 + 非凹点记录 + 默认保守分配（多留安全时隙）。
6. **时钟/重放攻击** → 单调时钟 + 签名时间戳 + 双时钟域交叉校验；故障即 fail-safe。
7. **C4 主张膨胀** → 主张准入测试（定义 396）强制可撤销；不击败空模型即降为工程附件。

| `C + M + S ≤ T_D` | 时间–运动预算守恒（计算 / 运动 / 传感） |
| `Λ = E[u_eff(执行时年龄)]` | 陈旧代价（D-PVOP 的 μ 项） |
| `(π_t, Q_t, Cert_t)` | ACMP 每时刻的可行计划、有效下界、证书 |
| `r_safe(a) = r + u(a) + v_max·a + margin` | 年龄膨胀半径 |
| `v_max^safe(a) = max(0, (r_clear − r_safe(a))/t_react)` | 陈旧速度上限（旧地图开慢车） |
| `ℰ_time` | 时间威胁面：算法复杂度攻击 / 陈旧重放 / 时钟攻击 / 调度干扰 / 时间侧信道 |
| `J_TIME = ⊗_i J_time(module_i) ⊗ J_tcomp(MReg)` | 时间证书（索引 κ_int） |

## 2. 形式化定义（要点版）

**定义 383（CHRONO-MODGAUGE 总览与六不变式）** R73 五不变式 + (vi) 时间完备性：每个节点声明 TEC，端到端时延/陈旧度经 TCA 组合，无干扰感知响应时间界不得签发 deadline 证书。

**定义 384（TEC）** 见符号表。核心：**时间字段与不确定度字段同属契约**；平凡情形 A_any≡⊥、ρ_ev=id 逐指令退化为 EC。

**定义 385（FDM）** u_pos(a)=u_pos(0)+v_max·a；Σ(a)=Σ_0+∫Q；u_eff 对年龄单调非减；混合新旧证据 = 先预测再加权（旧证据不能靠平均变新）。

**定义 386（TCA）** SER：L 相加、t_s 取 min、执行时刻评估 u_eff、deadline 相减；PAR：相干窗内且审计通过才缩窄，否则保守 max + COH_WINDOW_FAIL；VETO：有界完成、非补偿。

**定义 387（时间–运动预算守恒）** C+M+S ≤ T_D；最大化 V_c(C)+V_m(M)+V_s(S)−λ_r·Risk；最优点等边际价值（引理 40）。

**定义 388（ACMP）** 每时刻可行 π、有效 Q、可行修复下 Q 单调；任意 deadline 提交风险 ≤ Q ≤ ε；初始种子必须可行（刹车到停）——无预热不安全期。

**定义 389（D-PVOP）** 目标含 Progress − λ·E[u_depth^next] − Σc_reflex − μ·Λ；硬约束为 deadline 与时序契约；规划视界内年龄 ≤ τ_fresh。

**定义 390（AACC）** 年龄膨胀碰撞体；未知区域视为最坏；陈旧速度上限由几何解出；速度是地图年龄的非增函数。

**定义 391（AIC-TIME）** 五类时间威胁；防线：有界工作量 + 单调时钟 + 签名时间戳 + 隔离等级 + 尾部压力测试 + fail-safe。

**定义 392（时间 stub / 时序 E-IVG）** 超时 → 提交当前证书最优；陈旧 → 膨胀 + 限速；过期到不可膨胀 → 停；时钟故障 → 停车。与模块 stub 正交（有无 vs 多旧）。

**定义 393（TIB）** R_i=C_i+I_i(κ_int, workload)；TCA 按 κ_int 索引；跨等级禁加（timing anomaly）。

**定义 394（J_TIME）** 路径时延 ≤ D_exec ∧ 年龄 ≤ τ_fresh ∧ F_R 在 κ_int 下成立 ∧ Q_t 单调有效 ∧ 时间 stub 可达；Valid(J_TIME) ⇒ R73 风险界在 u_eff 下成立。

**定义 395（时间复杂度结构上限）** 路径时延 ≤ T_D、时间组合深度 ≤ 4、时钟域 ≤ 2、anytime 迭代 ≤ N_any、单步工作量 ≤ W_bound——可审计图/执行性质。

**定义 396（CAT 与 C4）** 新主张须预注册隔离并击败空模型；C4 候选绑定 TEC/FDM/TCA/ACMP/D-PVOP/AACC/TIB ↔ MB4 ↔ AB4 ↔ (deadline 违约率，陈旧致碰撞率，提交风险上界，认证成本)；不通过则降级附件。C1–C3 不变。

## 3. 关键算法伪代码

```python
# IP-302 TEC：时间证据契约（在 EC 上增补时间字段）
@dataclass(frozen=True)
class TemporalContract(EvidenceContract):
    d_exec_us: float                      # 相对截止期（含 jitter 另计）
    jitter_us: float                      # release jitter
    resp_tail: Callable[[float], float]   # F_R(τ)：响应时间 CDF / 可证尾界
    rho_ev: Callable[[float, float, float], float]  # (u0, age, xdot) -> u_eff
    w_coh_us: float                       # 并联相干窗
    kappa_int: int                        # 隔离等级（0=独占，1=分区，...）
    a_any: Callable[[float], Tuple[float, float]]    # τ -> (u_plan, Q)
    ts_schema: str                        # 时序追溯模式

# IP-303 FDM：新鲜度传播（Kalman 预测步 / 保守上界）
def rho_ev(u0, age, xdot, Q, vmax):
    return math.sqrt(u0**2 + (vmax * age)**2) + integrate_q(Q, age)   # 单调非减

# IP-304 TCA：时间组合代数（SER/PAR/VETO 作用于 (u, ts, L)）
def tcompose(a, b, op, now):
    if op == 'SER':
        L, ts = a.L + b.L, min(a.ts, b.ts)          # 时延相加、时间戳取最旧
        ua = rho_ev(a.u, now - a.ts, a.xdot)        # 执行时刻评估，非观测时刻
        ub = rho_ev(b.u, now - b.ts, b.xdot)
        return TE(u=cca_ser(ua, ub), ts=ts, L=L, D=a.D & b.D,
                  veto=a.veto | b.veto,
                  deadline=min(a.d_exec, b.d_exec - a.L))
    if op == 'PAR':
        if abs(a.ts - b.ts) > b.w_coh:               # 相干窗失败 → 禁止缩窄
            return TE(u=max(rho_ev(a.u, now-a.ts, a.xdot),
                            rho_ev(b.u, now-b.ts, b.xdot)),
                      ts=min(a.ts, b.ts), L=max(a.L, b.L),
                      veto=a.veto | b.veto | {'COH_WINDOW_FAIL'})
        return cca_par(a, b)                         # 仅同刻证据允许 conformal 缩窄
    if op == 'VETO':
        return TE(valid=(not a.veto and not b.veto), L=max(a.L, b.L),
                  deadline=min(a.d_exec, b.d_exec), veto=a.veto | b.veto)

# IP-305 ACMP：anytime 认证规划（任意时刻可提交）
class AnytimeCertifiedPlanner:
    def __init__(self):  self.best, self.Q = brake_to_stop(), safety_lb(brake_to_stop())
    def step(self, dt):                              # 每步保持可行性 + 证书有效
        node = self.frontier.pop_best_lower_bound()
        if not self.kinodynamically_feasible(node): return
        if self.aacc.collision_free(node, self.map_age):   # 年龄膨胀碰撞检查
            self.best = min(self.best, node)
        self.Q = max(self.Q, safety_lb(self.best))   # 单调不降
    def commit(self):                                 # 任意 deadline 调用
        return self.best, self.Q                      # 风险 ≤ Q ≤ ε

# IP-306 D-PVOP：时间–运动联合分配（KKT 等边际价值）
def deadline_aware_plan(b_t, mods, T_D, now):
    def J(alloc):                                    # alloc = (C, M, S)
        C, M, S = alloc
        if C + M + S > T_D: return -math.inf
        u_plan, Q = anytime_profile(C)               # A_any(C)
        u_view = sum(m.ec.chi_R(a).expected_u(state[m])
                     for m in depth_mods for a in M)
        stale = rho_ev(..., now)                      # Λ：执行时年龄代价
        return task_progress(M) - lambda_*u_view - mu*stale - kappa*Q
    return argmax(J, feasible_allocs(T_D))            # 引理 40

# IP-307 AACC：年龄感知碰撞检查 + 陈旧速度上限
def age_aware_collision_free(path, obs, now):
    for o in obs:
        a = now - o.ts
        r = o.r + o.u(a) + o.vmax * a + MARGIN        # 年龄膨胀半径
        if path.intersects(Sphere(o.p, r)): return False
    return True
def stale_speed_limit(obs, now, r_clear):
    r = max(o.r + o.u(now-o.ts) + o.vmax*(now-o.ts) for o in obs)
    return max(0.0, (r_clear - r) / T_REACT)          # 旧地图开慢车

# IP-308 CHRONO 主闭环（在 MODGAUGE 三域上增加时间域）
def CHRONO_round(M, obs, audio, tac_frame, depth_img):
    now = M.clock.monotonic()                         # 单调时钟（定义 391）
    # === 感知域（100Hz，Best-effort）===
    d_ev = stamp(M.dpe.update(depth_img, rgb, M.cam_state, M.motion, M.peers), now)
    if not fresh(d_ev, now): d_ev = temporal_stub(d_ev, now)   # 时间 stub（定义 392）
    # === 计量域（50Hz，软实时）===
    if M.clock.due_metric():
        timed = tcompose(d_ev, t_ev, 'PAR', now)      # TCA 组合（相干窗）
        b_t = M.bse.step_full(..., e=timed)
        plan, Q = M.acmp.commit()                     # 任意时刻可提交（定义 388）
        alloc = deadline_aware_plan(b_t, M.mods, M.T_D, now)   # IP-306
        M.pvop = plan
    # === 控制域（1kHz，硬实时，只读快照）===
    snap = M.snapshot.read_latest()
    v_cap = stale_speed_limit(snap.obstacles, now, snap.r_clear)   # AACC
    lam = embodied_risk_scale(snap.U_ale, snap.U_epi, snap.H_z,
                              max(snap.t_ev.u_eff, snap.d_ev.u_eff), M.risk_params)
    k = M.c_ras_wm.certified_prefix(snap.plan, lam, v_cap)         # 速度上限进控制
    M.ctrl_out.publish(k, lam)
    return k, lam, M.acmp.Q, J_TIME(M.mreg)           # 时间证书（定义 394）
```

## 4. 推导

**引理 38（时间箭头）** 固定观测下后验经预测核传播，熵不降、协方差只增（Σ(a)=Σ_0+∫Q）；对固定数据的确定性计算不增加信息（数据处理不等式）⇒ u_eff(a) 单调非减。系：ρ_ev 就是「时间的组合算子」。

**引理 39（时间组合单调性）** SER 时延相加、时间戳取 min；PAR 取 min/max 且相干窗失败禁缩窄；VETO 取 max。对组合树归纳 ⇒ 任意路径不比输入更新、不比输入更快。系：空间单调（引理 34）+ 时间单调 = 时空双单调。

**引理 40（时间–运动等边际配置）** V_c/V_m/V_s 凹增、Risk 凸、约束为单纯形 ⇒ KKT 给出 ∂V_c=∂V_m=∂V_s=λ；严格凹则唯一。A_any 非凹（相变）时退化为有界搜索并记录非凹点。

**引理 41（Anytime 提交安全）** π_0 可行、Q_0 有效；每步只接受可行计划、Q 取 max ⇒ 任意 τ 提交风险 ≤ Q_τ ≤ ε。系：deadline miss ≠ 不安全，只等于计划没那么好。前提是存在可行种子（标准 anytime 缺）。

**引理 42（年龄膨胀保守性）** p_true∈Ball(p_obs,u_o) 且速度 ≤ v_max ⇒ 年龄 a 后 p_true∈Ball(p_obs,u_o+v_max·a)；路径避开膨胀体 ⇒ 反应时域内无真实碰撞；速度上限由几何直接解出。系：安全边距是地图年龄的函数。失效条件：v_max 估错、障碍瞬移/对抗。

**引理 43（响应时间不可跨隔离等级相加）** R_i=C_i+I_i(κ_int,workload)，干扰依赖共享资源上的协作者，标量 WCET 无法捕获；跨 κ_int 相加会低估（timing anomaly）⇒ TCA 按 κ_int 索引，跨等级需实测干扰包络。系：时间契约的「类型」包含隔离等级，与模态隔离同构。

**定理 30（严格包含 MODGAUGE）** 在 A114–A116（F_R 在 κ_int 内有效 / ρ_ev 保守且线性高斯精确 / ACMP 有可行种子）下，T_D→∞、年龄→0、κ_int 独占、A_any≡⊥ 时 ρ_ev→id、TCA→CCA、ACMP→PVOP、D-PVOP→PVOP、AACC→静态检查；由定义 383(vi) 与引理 35 逐指令退化到 MODGAUGE→R73→R72→R71→R68。安全单调不减。

**定理 31（时间证书 ⇒ deadline + 新鲜度感知安全）** Valid(J_TIME) ⇒ 端到端时延 ≤ D_exec 概率 ≥ 1−δ、每决策点年龄 ≤ τ_fresh、ACMP 证书有效；由引理 38/42，u_eff 为真实不确定度保守界 ⇒ R73 定理 28 以 u_eff 成立 ⇒ 物理风险 ≤ ε。证明分两半：时间可行性（调度）与证据可靠性（计量），两半都须成立。

**定理 32（任意时刻提交安全）** ACMP 不变量 + 引理 41 ⇒ 任意 deadline 提交的 π_τ 可行且风险 ≤ Q_τ ≤ ε；标准 anytime 早期可能返回不可行/无证书解，故本定理严格更强。系：实时性的正确安全语义是「随时可停、随时可交」。

**定理 33（时间降级零级联）** 超时/陈旧/时钟故障 → 时间 stub（提交当前证书最优/限速/停车）维持安全不变量；模块 stub（管有无）与时间 stub（管多旧）正交，可同时触发而不污染 MReg 校验 ⇒ 失效传染路径唯一、无级联。

## 7. 本轮最大风险

**一句话**：CHRONO 把安全证明的一部分从「不确定度契约」转移到「**时间模型**」——如果响应时间尾部在真实负载/干扰下被低估、或 ρ_ev 的动力学模型在规划期间被违反（障碍物比假设更快、世界在计算期间发生拓扑变化、时钟域漂移），那么系统会在「**所有证书都有效、所有 deadline 看似满足**」的情况下，**准时地提交一个基于过期世界的安全计划**，而日志会证明「每一步都在预算内」——**实时性证书恰恰在最需要它的负载尖峰时刻最不可信。**

次级风险与缓解：
1. **响应时间尾部估计偏差** → 隔离等级 + 尾部压力测试（E397）+ 保守 F_R 上界 + 超时即 ACMP 提交（引理 41）。
2. **ρ_ev 模型失配（近场/高动态/拓扑突变）** → 有效域硬边界 + 在线残差校准 + 检出即限速/停车（AACC）。
3. **anytime 初始种子不可行** → π_0 强制刹车到停/当前轨迹延续；禁止「先算再保证」。
4. **相干窗过宽导致跨时刻融合** → W_coh 由动力学相干时间导出 + 越窗即否决（E393）；对抗分歧触发 PAR_AUDIT_FAIL。
5. **时间–运动分配非凹/相变** → 有界搜索 + 非凹点记录 + 默认保守分配（多留安全时隙）。
6. **时钟/重放攻击** → 单调时钟 + 签名时间戳 + 双时钟域交叉校验；故障即 fail-safe。
7. **C4 主张膨胀** → 主张准入测试（定义 396）强制可撤销；不击败空模型即降为工程附件。
