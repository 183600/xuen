# 第 69 轮（承接第 68 轮「CALM-RAS 自标定风险自适应闭环」IP-243~252；灵感循环新循环第 2 轮；本轮灵感：「自主导航」×「面部表情识别」）

> 第 68 轮用「在线标定 + 自监督 + 单模型多任务」补上了计量层，却把安全押在「速率限制 + canary 不可修复性」上，其自陈风险一针见血：**缓变故障一旦落在标定带宽内，就会被当成漂移吸收；标定越强，故障越隐形**。把这句话翻译成本质形式：R68 的标定是**纯里程计（odometry）**——只靠相邻时刻的内部一致性递推，没有闭环、没有绝对参考。SLAM 早已证明：里程计必然漂移，且无法自证漂移；唯一解是**闭环到可信地标 + 主动观测**。与此同时，R68 判定「测量可不可信」的方式，恰好是朴素面部表情识别的原罪：**把表观当成状态**——一份自洽的「我很准」报告，就像一张标准的微笑，内部再合理也可能是被掩盖的坏消息。
>
> 本轮把两个灵感合成一句命题：
>
> **测量可信度不能靠自洽，必须靠可追溯的外部锚点；慢变故障不会消失，它被「搬」进了补偿轨迹，因此要像识别微表情一样审计吸收者本身；系统应主动导航去制造锚点不一致（主动计量），而不是被动等故障露头。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我凭什么相信『我还准』这个判断**」——从内部自洽（internally consistent）升级为外部锚定可追溯（externally traceable）。

## 0. 直觉与动机

**灵感 1（自主导航 → 标定是里程计，缺的是闭环与地标）**
直觉：SLAM 的里程计漂移不是靠更精确的轮速计解决的，而是靠 loop closure——回到曾去过的地方，把位姿图拉回全局一致。R68 的 COF 正是一个没有闭环的里程计：它积分残差、限速更新，于是任何足够慢的东西都会被它「走」进去。修法不是调小 ω_cal（那只是把可吸收故障从「慢」改成「更慢」），而是引入**绝对参考**：由角度/力/几何已知的基准件给出 anchor edge，把标定从「相对递推」变成「全局位姿图」。更关键的是：**漂移是规范（gauge）自由度，故障是规范外的结构不一致**；没有锚点时二者不可分，有锚点后可由「能否被一次合法重标定解释」来分离。
但必须诚实：标定越强，可被重标定解释的故障集合越大（全可观测会吸收一切）。所以真正的防线不是「更会解释」，而是**限制标定能解释什么**——可容许标定流形 + 参数红线 + 动力学先验 + 跨上下文佐证。导航给的是「参考系」，不是「更自由的模型」。

**灵感 2（面部表情识别 → 表观不是状态，审计「掩盖」本身）**
直觉：FER 的核心教训是——脸是**被社会规则调控的显示（display）**，同一个微笑在不同上下文中含义不同；可靠做法是分解到动作单元（AU）、观察时序动力学（onset-apex-offset）、做个体基线、跨模态佐证，并用**微表情**捕捉「被压抑的泄漏」。R68 的系统健康报告就是一张脸；标定吸收故障就是「强颜欢笑」。但故障并未真正消失：它被**搬进了补偿轨迹 c(t)**——为了把残差压回阈值，标定必须沿一条特定轨迹移动。**审计这条轨迹，而不是只盯着被压平的残差**，正是「微表情检测」：合法漂移应落在热/蠕变零模型流形上，故障驱动的补偿会偏离该流形，即使单帧残差完全合法。
同一思想也回灌到人：R66/R68 的假笑风险用 μFER（AU + 微表情 + 个体基线 + 显示规则上下文）再降一档。

**灵感 3（合流 → COMPASS-RAS 六组件）**
1. **MPG 计量位姿图**：上下文索引的标定节点 + 相对残差边 + 绝对锚点边，在可容许流形上做 Gauss-Newton，锚点定规范；
2. **ANC 锚点与可追溯链**：物理基准件/基准位姿/基准力，带不确定度与溯源哈希；
3. **ANP 主动计量规划**：把「回到地标」与「做能分离故障的激励动作」当作主动 SLAM / 下一最佳视角，在风险预算内最大化信息增益；
4. **CIC 上下文索引标定**：用 κ_t（温度/负载/位姿簇/场景）索引多个标定节点，杜绝单一全局 c 把局部故障抹平；
5. **EDD 表达动力学审计（自）+ μFER（人）**：AU 级分解 + 时序相位 + 零模型偏离，抓「被掩盖」的补偿轨迹与假笑；
6. **XCC 跨上下文佐证 + GRG 规范残差守卫**：单一上下文不能定案；与锚点规范正交的残差才可判故障，其余一律「不可验证」→ λ 抬升。

**灵感 4（对 R68 风险的对症下药）**
- R68「缓变故障被吸收」→ 三重独立网：① GRG 规范残差（锚点正交分量，与频率无关）；② 参数红线（标定结果超出物理包络即判故障，且按上下文各自核算）；③ EDD 补偿轨迹偏离零模型。**吸收得越干净，补偿轨迹越可疑**——把 R68 的盲区变成新证据源。
- R68「CAC 金标未覆盖」→ ANP 主动生成「鉴别性动作」与锚点回访，把未见故障模式主动暴露，而非被动等待覆盖。
- 「更会标定 = 更会隐藏」的悖论 → 用**标定自由度预算**（dim ℳ_adm ≪ d）显式收紧可吸收集，并给出灵敏度—适应性权衡（引理 16）。
- 「不确定却放宽」→ 继承 λ_floor，并新增「不可验证」状态：XCC 不连通锚点即视为 U = ∞，λ 抬到 0.8 并收缩前缀。

**灵感 5（为什么这比 R68 更接近可证明的安全）**
R68 的安全性依赖一个未验证的经验假设「故障频率 ω_f ≥ 3ω_cal」。现实中传感器老化、慢泄漏、缓慢松动恰恰违反它。R69 不再假设频率可分，而是把问题换成**结构可分**：故障若落在「合法重标定能解释的切空间」内，就必然同时偏离热/蠕变零模型（除非它精确等于一次真实漂移，此时按定义它不是故障）；若落在该切空间外，锚点正交残差直接暴露。两条路都收敛到可检测，代价是必须付出锚点与主动激励的成本——这是一个可以用信息论量化、而不是用经验阈值担保的安全性。

## 1. 形式化定义（增量：定义 293–308）

**定义 293（COMPASS-RAS 总览）** COMPASS-RAS = (MPG, ANC, ANP, CIC, EDD, μFER, XCC, GRG, RAS-WM‡)。不变式在 R68 三不变式之上加三条：
(iv) **无锚不定案**：任何 H_cal 判定必须附带至少一条 anchor 边的可追溯链，否则标「不可验证」；
(v) **标定自由度预算**：c ∈ ℳ_adm，dim ℳ_adm = m ≤ 6，超出流形的解释一律拒绝（反「万能标定」）；
(vi) **主动计量风险预算**：信息增益动作须满足 Risk(u) ≤ ρ_safe，探索绝不放松任何安全阈值。

**定义 294（计量位姿图 MPG）** 图 G = (V, E, A)：节点 v_k = (κ_k, c_k, Σ_k)（上下文描述子、标定状态、协方差）；相对边 e_ij 由两上下文共同观测的残差给出 r_ij = h(c_i, c_j) + n；锚点边 a_k 由基准件给出绝对约束 r^a_k = h_a(c_k) + n_a。目标
c* = argmin_{c ∈ ℳ_adm} [ Σ_{(i,j)∈E} ‖r_ij − h(c_i,c_j)‖²_{Ω_ij} + Σ_{(k,a)∈A} ‖r^a_k − h_a(c_k)‖²_{Ω_a} ]。
用 Gauss-Newton 求解，锚点固定规范。**关键语义**：漂移是保留锚点约束的规范自由度（可被一次合法重标定吸收）；故障是锚点约束下的不可约残差（结构不一致）。

**定义 295（锚点与可追溯链 ANC）** 锚点集合 𝒜 = {(a, U_a, prov_a)}：a 为物理基准（标定板几何、基准力/质量、已知位姿的接触面），U_a 为锚点不确定度，prov_a 为溯源链哈希（出厂计量 → 现场基准 → 会话）。锚定有效判据：‖r^a_k‖ ≤ 3√(tr(Ω_a^{-1}) + tr(Σ_k))，否则不得声明 H_cal。

**定义 296（可容许标定流形 ℳ_adm）** c = Ψ(η), η ∈ ℝ^m, m ≤ 6，η 为物理慢变量（温度、负载历史、时间的低阶基）；ℳ_adm 只含热漂/蠕变的低维模态与参数红线内点。**这是反吸收的核心**：R68 的 c ∈ ℝ¹² 自由游走等价于 m = 12 的万能解释器；R69 把 m 压到物理自由度。

**定义 297（上下文索引标定 CIC）** κ_t = (温度簇, 负载簇, 位姿簇, 光照/场景簇)；当前标定由 MPG 节点按核权重插值：c(κ) = Σ_k w_k(κ)·c_k / Σ_k w_k(κ)，w_k = exp(−‖κ − κ_k‖²/2ℓ²)。局部故障只能在被污染的那一小片 κ 上抬高残差，无法被全局单点抹平。

**定义 298（主动计量规划 ANP）** 信念 b = (c, f, Σ)；动作 u ∈ 回访锚点 ∪ 鉴别性激励动作（转动激励外参、加载/卸载激励力零偏、静置激励热漂）。目标
u* = argmax_u [ I(c, f; r_{t+1} | u, b) − β·Risk(u) ]，s.t. Risk(u) ≤ ρ_safe。
其中 I 为期望信息增益，Risk(u) 为动作本身的瞬时风险（复用 R68 的 λ_risk 与 C-RAS-WM）。

**定义 299（可观测性激励 D-最优）** 对参数 θ = (c, f)，动作 u 的 Fisher 信息 FIM(u) = J_u^T Ω^{-1} J_u；选 u 使 det(FIM(u)) 最大化（D-optimal）且 Risk(u) ≤ ρ_safe。语义：不问「哪里好看」，问「哪个动作最能让我分清漂移与故障」。

**定义 300（表达动力学审计 EDD，自）** 记补偿轨迹 c(t)。AU 级分解：把 c(t) 逐参数、逐轴拆为低层分量 u_j(t)；检测 onset/apex/offset 相位；零模型 ℳ_null 由热传导与蠕变给出（合法漂移必须落在其上）。检测统计量
D_edd(t) = dist(c(t), ℳ_null) + κ_m·Mask(c(t))，
Mask 为「表观健康」与「低层动力学」的矛盾度（类似假笑时 AU 与自报情绪不符）。**核心论点：标定吸收故障时残差被压平，但 c(t) 被迫离开 ℳ_null；越是完美吸收，偏离越结构化。**

**定义 301（微表情面部情绪识别 μFER，人）** 人类情绪证据升级为
π_face(t) = FER_μ(AU_t, phase_t, baseline_i, display_rule(κ_t))，
其中 AU_t 为动作单元序列、phase 为 onset-apex-offset、baseline_i 为个体基线、display_rule 为场景上下文。微表情（< 200ms、低幅）作为「压抑泄漏」单独通道；r_emo 由「类别一致性」升级为「AU 级跨模态一致性」：
r_emo = KL(π_face ‖ π_ctx) + λ_au·dist(AU_face, AU_ctx)。

**定义 302（规范残差守卫 GRG）** 设锚点雅可比 J_a，可吸收集 𝒮_abs = Tℳ_adm ∩ range(J_a)（能被合法重标定解释的方向）。规范残差守卫取 g_t = ‖P_{𝒮_abs^⊥} r_t‖（锚点正交残差）。**判据**：g_t > τ_g ⇒ 判 H_sensor^trans（真实故障），与故障频率无关——这补上了引理 13 只对 ω_f ≥ 3ω_cal 有效的缺口。

**定义 303（三重网故障判据）** 故障后验由三条独立证据相乘：
P(H^trans | ·) ∝ p(g_t | H^trans) · p(红线越界 | H^trans) · p(D_edd | H^trans) · P(H^trans)，
任一网触发都不得判 H_cal。「吸收得越干净」只降低第一网，升高第三网。

**定义 304（跨上下文佐证 XCC）** 一个 H_cal 标签只有在佐证图 Γ 中存在一条从该上下文节点到锚点集的路径、且路径上 ≥K 个独立上下文的残差一致时才被接受；否则状态置 UNVERIFIABLE，U := ∞，λ_floor := 0.8。

**定义 305（主动计量检测时延界）** 设故障规范外分量幅度 ‖P_⊥ f‖ = s、噪声 σ，锚点回访周期 T、单次激励 Fisher 信息 F。则检测时延 E[τ_det] ≤ C·T·σ²/(m·F·s²)（对数因子略），即**主动计量把「被动等故障变大」变成「有界时延主动暴露」**。

**定义 306（COMPASS 干扰集 AIC-COMPASS）** ℰ_COMPASS = ℰ_CALM × ℰ_anchor × ℰ_explore × ℰ_mask；ℰ_anchor = {锚点被污染/遮挡/伪造、溯源断链}；ℰ_explore = {探索诱发风险、激励动作越界、回访被拒绝}；ℰ_mask = {补偿轨迹伪装成热漂、微表情被平滑、显示规则误读}。

**定义 307（J_COMPASS 证书）** J_COMPASS = (J_CALM, anchor_provenance_hash, gauge_residual_norm, loop_closure_error, context_coverage, cal_dof_budget, edd_masking_score, explore_risk_max, compass_ver)。Valid ⇔ Valid(J_CALM) ∧ 锚定有效（定义 295）∧ XCC 连通（定义 304）∧ 红线未越界 ∧ explore_risk_max ≤ ρ_safe。

**定义 308（实时/非实时划分）** 实时流（<2.6ms）只做 MTM 前向 + c(κ_t) 插值 + GRG 标量投影 + λ 缩放；MPG 优化、EDD 审计、ANP 规划、μFER 微表情、XCC、CAC 全部异步/影子。锚点回访是运动级动作（秒~分钟），由 ANP 在安全预算内排程。

```python
# IP-253 MPG：计量位姿图（上下文节点 + 相对边 + 锚点边），在 ℳ_adm 上求解
class MetrologyPoseGraph:
    def __init__(self, manifold): self.manifold, self.nodes, self.edges = manifold, {}, []
    def add_node(self, kid, kappa, c, Sigma): self.nodes[kid] = (kappa, c, Sigma)
    def add_relative(self, i, j, r_ij, Omega): self.edges.append(('rel', i, j, r_ij, Omega))
    def add_anchor(self, k, a, U_a):        self.edges.append(('abs', k, a, U_a))
    def optimize(self, iters=10):
        for _ in range(iters):
            H, g = self.build_normal_equations(self.manifold)   # 切空间线性化
            self.gauge_fix(self.anchors())                      # 锚点定规范
            self.c = self.manifold.retract(self.c + solve(H, -g))
        return self.c, self.gauge_residual(), self.loop_error()

# IP-255 ANP：主动计量（锚点回访 + D-最优激励，风险预算内）
class ActiveMetrologyPlanner:
    def plan(self, belief, risk_budget):
        cands = self.anchor_visits(belief) + self.excitation_primitives(belief)
        safe  = [u for u in cands if self.risk(u, belief) <= risk_budget]
        return max(safe, key=lambda u: self.info_gain(u, belief) - self.beta*self.risk(u, belief))

# IP-257 EDD：审计补偿轨迹（「微表情」= 偏离热/蠕变零模型）
class ExpressionDynamicsAuditor:
    def score(self, c_traj):
        aus   = [au_decompose(c_traj, p, axis) for p in PARAMS for axis in AXES]
        phase = detect_phases(aus)                       # onset / apex / offset
        dev   = distance_to_null_manifold(c_traj, self.M_null, self.thermal_driver)
        mask  = masking_score(aus, phase, self.self_report)   # 表观 vs 低层矛盾
        return dev + self.kappa_m * mask

# IP-259 XCC + IP-260 GRG：跨上下文佐证 + 规范残差守卫
def corroborate_and_guard(r, ctx_id, mpg, anchors, K=2):
    g = norm(project_orthogonal(r, absorbable_subspace(mpg, anchors)))
    reachable = mpg.reaches_anchor(ctx_id) and mpg.consistent_path(ctx_id, K)
    if not reachable:
        return 'UNVERIFIABLE', np.inf, g        # → λ_floor := 0.8
    return ('FAULT' if g > TAU_G else 'CAL_OK'), mpg.gauge_residual(), g

# IP-262 主闭环：实时热路径 + 异步计量层
def COMPASS_round(M, obs):
    x_prime = M.lsf.fuse(M.usr.fuse(*obs[:4]))
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)          # 实时
    kappa = context_descriptor(M)
    c, U = M.cic.interpolate(kappa)                                 # 上下文索引标定
    r = residuals(x_prime, o, M.wm_residual_cache)
    verdict, U_g, g = corroborate_and_guard(r, M.cic.node_of(kappa), M.mpg, M.anc)
    if verdict == 'UNVERIFIABLE': U = np.inf
    thr = M.car.reparameterize(max(U, U_g))                         # 继承 R68 CAR
    joint_post = M.cfa(r, o['pi'], c, max(U, U_g))                  # 继承 R68 CFA
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, joint_post, min(M.vista.m, M.m_emo),
                                    M.alpha_chunk, M.mtm.rollout(z, A, 5))
    lam = max(M.efs.risk_scale(joint_post), thr['lam_floor'], 0.8 if verdict != 'CAL_OK' else 0.6)
    tau = emotion_response_shaping_wm(M.pi_sigma.prefix_dispatch(A[:k]) * lam,
                                      joint_post, M.mtm.rollout(z, A, 5))
    # 异步/影子：不进实时热路径
    M.async.submit(M.mpg.optimize, M.edd.score, M.anp.plan, M.mufer.analyze,
                   M.xcc.audit, M.cac.maybe_commit)
    return k, lam, joint_post, (c, U_g, g, verdict)
```

## 3. 推导

**引理 16（标定自由度—可吸收集守恒）** 设标定被约束在光滑流形 ℳ_adm（dim m），则合法重标定可吸收的故障方向为 𝒮_abs = Tℳ_adm ∩ range(J_a)，且对任意故障 f，标定后残差下界为 ‖P_{𝒮_abs^⊥} f‖。因此可吸收集维数随 m 单调增；R68 的 m = 12（自由游走）几乎吸收一切，R69 取 m ≤ 6 且限定物理模态，直接缩小盲区。检测灵敏度与标定适应性构成显式权衡：∂P_det/∂m < 0。**推论**：不存在「既无限灵活又零盲区」的标定器；安全来自约束，不来自表达力。

**引理 17（上下文一致性判别）** 若为真实漂移，则 c(κ) 在 ℳ_adm 上关于 κ 满足 Lipschitz 常数 L（热/负载驱动的连续性）；若为局限于上下文子集 𝒦_f 的故障，则 c(κ) 在 𝒦_f 边界出现幅度 ≥ s/L 的跳变。以跨 κ 残差为统计量，可把「局部故障被全局抹平」的概率压到 O(exp(−K·s²/σ²))。CIC + XCC 是该引理的工程实现。

**引理 18（补偿轨迹—微表情检测）** 设故障 f(t) 被标定吸收后残差被压至 ≤ τ_det，则所需补偿满足 c*(t) ≈ J⁺f(t)。合法漂移的 c(t) 落在热/蠕变零模型流形 ℳ_null 上；故障驱动补偿一般不在其上，偏离量 δ(t) = dist(c*(t), ℳ_null) 关于 ‖f‖ 单调增。于是存在 τ_g、τ_edd 使
P(漏检) ≤ P(g_t ≤ τ_g ∧ D_edd ≤ τ_edd | f) → 0（当 ‖f‖ > ε 且 f 不精确等于一次真实漂移）。
**这条引理正面推翻 R68 的「越准越隐形」：残差越平，补偿轨迹越偏离零模型。** 例外的测度零集合（f 精确等于合法漂移）按定义不构成故障，或以参数红线兜底。

**引理 19（主动计量的信息增益与检测时延）** 锚点回访与 D-最优激励使 Fisher 信息 FIM 在故障方向上的最小特征值 λ_min 单调增；由 Cramér-Rao，故障估计方差 ≥ 1/(m·F)，配合周期 T 的采样，检测时延满足定义 305 的界。ANP 的 s.t. Risk(u) ≤ ρ_safe 保证信息增益不越安全边界；若边界内无可增信息动作，则退回保守（λ = 0.8，k 收缩），绝不「为看清而冒险」。

**定理 16（COMPASS 端到端风险一致性，三重网）** 在 A87–A94 与新增 A95（ℳ_adm 正确包含合法漂移）、A96（锚点溯源有效）、A97（ℳ_null 覆盖热/蠕变）下：
1. P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + **α_anchor + α_explore + α_mask**；
2. 对任意缓变故障 f，若 P_{𝒮_abs^⊥}f ≠ 0，则漏检概率随 ‖P_⊥f‖²/σ² 指数下降（GRG，与 ω_f 无关）；
3. 若 f ∈ 𝒮_abs，则漏检概率 ≤ P(D_edd ≤ τ_edd) + P(红线未越界)，由引理 18 与参数包络控制；
4. 若 f 被 XCC 判 UNVERIFIABLE，则 λ_risk ≥ 0.8 ∧ τ_risk 收紧 ∧ k 收缩——**不可验证永远导向收缩**；
5. 主动探索只在 Risk(u) ≤ ρ_safe 内进行，故探索不增加瞬时违规概率上界。

**定理 17（探索—安全 Pareto 与退化解）** 定义安全预算 ρ_safe 与信息增益 I(u)。可行集非空时，存在确定性的 barrier-certified 计划 {u_t} 使累计风险 ≤ ρ_safe 且检测时延满足定义 305；若可行集为空（如现场无任何锚点可达），则 COMPASS 退化为 R68 的 CALM-RAS 并**主动把证书标为「未锚定」**（J_COMPASS 的 anchor_provenance 失效），此时 λ_floor 永久 ≥ 0.8。**即：没有锚点时系统不假装安全，而是显式降级。**

```python
class MetrologyPoseGraph:
    def __init__(self, manifold): self.manifold, self.nodes, self.edges = manifold, {}, []
    def add_node(self, kid, kappa, c, Sigma): self.nodes[kid] = (kappa, c, Sigma)
    def add_relative(self, i, j, r_ij, Omega): self.edges.append(('rel', i, j, r_ij, Omega))
    def add_anchor(self, k, a, U_a):        self.edges.append(('abs', k, a, U_a))
    def optimize(self, iters=10):

            self.gauge_fix(self.anchors())                      # 锚点定规范

    joint_post = M.cfa(r, o['pi'], c, max(U, U_g))                  # 继承 R68 CFA
    A = M.ach.propose(x_prime, H=M.vista.H)
    wm = M.mtm.rollout(z, A, 5)
    k = M.c_ras_wm.certified_prefix(A, joint_post, min(M.vista.m, M.m_emo),
                                    M.alpha_chunk, wm)
    lam = max(M.efs.risk_scale(joint_post), thr['lam_floor'],
              0.8 if verdict != 'CAL_OK' else 0.6)
    tau = emotion_response_shaping_wm(M.pi_sigma.prefix_dispatch(A[:k]) * lam,
                                      joint_post, wm)
    # 异步/影子：不进实时热路径
    M.async.submit(M.mpg.optimize, M.edd.score, M.anp.plan, M.mufer.analyze,
                   M.xcc.audit, M.cac.maybe_commit)
    return k, lam, joint_post, (c, U_g, g, verdict)
```

## 4. 推导

**引理 16（标定自由度—可吸收集守恒）** 标定约束在 dim m 的 ℳ_adm 上，可吸收故障方向 𝒮_abs = Tℳ_adm ∩ range(J_a)，标定后残差下界 `‖P_{𝒮_abs^⊥} f‖`。可吸收集随 m 单调增，R68 的 m=12 接近万能解释器，R69 取 m≤6 并限定物理模态；检测灵敏度与适应性构成显式权衡 `∂P_det/∂m < 0`——**不存在既无限灵活又零盲区的标定器，安全来自约束而非表达力**。

**引理 17（上下文一致性判别）** 真实漂移的 `c(κ)` 在 ℳ_adm 上 Lipschitz（常数 L），局限于 𝒦_f 的故障会在其边界产生 ≥ s/L 的跳变；跨 κ 残差检验把局部故障被全局抹平的概率压到 `O(exp(−K·s²/σ²))`。

**引理 18（补偿轨迹—微表情检测）** 故障被吸收后残差 ≤ τ_det，所需补偿 `c*(t) ≈ J⁺f(t)`；合法漂移落在 ℳ_null，故障补偿偏离量 `δ(t)=dist(c*(t),ℳ_null)` 随 ‖f‖ 单调增。故存在 τ_g、τ_edd 使 `P(漏检) → 0`（当 ‖f‖>ε 且 f 不精确等于一次真实漂移）。**这正面推翻 R68 的「越准越隐形」：残差越平，补偿轨迹越偏离零模型；例外测度零集合按定义非故障或以红线兜底。**

**引理 19（主动计量的信息增益与检测时延）** 锚点回访 + D-最优激励提升故障方向 FIM 的 λ_min；Cramér-Rao 给出故障估计方差 ≥ 1/(mF)，配合周期 T 得定义 305 的检测时延界；`Risk(u) ≤ ρ_safe` 保证不为看清而冒险。

**定理 16（COMPASS 端到端风险一致性，三重网）** A87–A97 下：
1. `P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_anchor+α_explore+α_mask`；
2. `P_{𝒮_abs^⊥}f ≠ 0` 时漏检随 `‖P_⊥f‖²/σ²` 指数下降（GRG，与 ω_f 无关）；
3. `f ∈ 𝒮_abs` 时漏检 ≤ `P(D_edd≤τ_edd) + P(红线未越界)`；
4. XCC 判 UNVERIFIABLE ⇒ `λ_risk ≥ 0.8 ∧ τ_risk 收紧 ∧ k 收缩`；
5. 探索仅在 `Risk ≤ ρ_safe` 内，不增加瞬时违规上界。

**定理 17（探索—安全 Pareto 与退化解）** 可行集非空时存在 barrier-certified 计划使累计风险 ≤ ρ_safe 且检测时延满足定义 305；可行集为空（无锚点可达）时 COMPASS 退化为 CALM-RAS，并**主动把证书标为「未锚定」**，`λ_floor` 永久 ≥ 0.8——**没有锚点时不假装安全，而是显式降级**。

## 7. 本轮最大风险

**一句话**：COMPASS-RAS 把安全性从「频率可分」搬到「锚点可追溯 + 标定流形对称」，却把新的单点依赖压在**锚点本身的可信性与可达性**上——现场无法布置合格基准、或锚点被污染/伪造/溯源断链时，系统只能退化为「未锚定」长期保守运行（不比 R68 更安全却更贵）；更尖锐的是，任何**精确落在 ℳ_adm 与 ℳ_null 交集内**的退化（真实热致零点漂移与老化恰好同向同速），在定义上无法与故障区分，只能等参数红线越界后报警，这段「合法盲区」是锚定范式无法消除的残余风险。

**次级风险与缓解**：锚点污染/伪造（溯源哈希 + 多锚交叉 + 污染检测 E294）；探索诱发风险（硬约束 Risk ≤ ρ_safe + 退化即保守）；MPG 求解一致性漂移（锚点定规范 + 回读校验）；μFER 隐私与个体偏差（端侧 AU 特征、不存原始人脸、个体基线）；自由度预算过紧导致适应不足（m 自适应 + E289 权衡曲线 + 红线兜底）；异步层延迟导致证书滞后（证书版本链 + 未锚定默认降级）。
