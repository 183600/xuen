# 第 4 轮（研究轮次；灵感循环第 2 轮；本轮灵感：「通用机器人」×「长程任务」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge 与第 1 轮 LeanGauge / MODGAUGE 骨架继续继承。
> 本轮纪律：**沿「能力迁移」与「时间复合」两条新轴增量升级，并保持严格退化**。通用技能与长程任务都是增强项；任一证书缺失都必须能退回单本体、单块、单步基线。
> 编号说明：状态文件当前承接第 3 轮 InstructGauge，故本轮按研究轮次记为第 4 轮；在本轮灵感循环中为第 2 轮。

## 0. 直觉与动机

**灵感 1（通用机器人 → 不是「一个模型什么都会」，而是「一个技能组合在多个本体上各自可验证」）**
直觉：通用机器人的真正含义不是把同一个策略原样复制到所有本体，而是拥有一个**跨本体共享的技能先验**：抓取、对准、擦拭、探测等技能在语义上相似，但每个本体的执行器、动力学、传感包线不同。危险在于把「任务语义相同」误当成「安全契约相同」——一个在 A 上标定过的技能，搬到 B 上可能仍然“会做”，却不再满足原来的前置、后置与漂移界。因此正确的接口不是「通用策略直接执行」，而是「通用策略提出候选技能，本体级能力卡负责准入」：**通用性存在于提议分布，而不存在于保证**。

**灵感 2（长程任务 → 误差沿时间复合，而不是沿单步放大）**
直觉：短程任务的安全可以逐块证明；长程任务的失败往往不是某一步明显做错，而是 N 个局部正确的步骤把状态带到校准集之外、把预算耗尽、把可逆动作累积成不可逆后果。更关键的是，若没有重置点，每段失败概率 p 会以 `(1-p)^N` 复合成任务失败；对任意固定 p>0，N 足够大时任务成功率都趋近 0。因此长程任务的核心不是“把块拉得更长”，而是**任务契约 DAG + 里程碑复核 + 可重启性**：把一条长轨迹切成可验证、可恢复、可重新接地的段。

**灵感 3（两者耦合 → 通用先验沿长程任务传播「局部有效契约」，制造伪全局保证）**
直觉：通用机器人提供跨本体的技能先验，长程任务提供跨时间的契约串联；二者相乘时，最危险的不是单个技能失败，而是**证书洗白**：一个只在 A 本体、短任务上有效的技能卡，被通用先验“看起来可迁移”地用到 B 本体；一个只在单块内有效的证书，被任务 DAG“看起来可组合”地串成任务级证书。解法不是禁用通用先验或长程规划，而是引入三根结构支柱：**本体级能力闭包**（未认证技能不可执行）、**迁移证书与不可传递性**（A→B、B→C 不自动给出 A→C）、**任务契约 DAG 与里程碑证书**（每次跨段都必须重新接地并出证），再叠加**可重启性契约**与**任意时间有效的风险会计**。

## 1. 研究问题（本轮要回答什么）

- **Q1（跨本体迁移的安全性）**：一个技能从本体 A 迁移到 B，需要什么证书才能保证「语义可迁移」同时「安全契约也可迁移」？迁移关系是否可传递？
- **Q2（长程误差的复合条件）**：在什么结构条件下，任务风险保持线性/可加，而不是随任务长度指数放大？重置、里程碑验证与风险预算各自贡献多少？
- **Q3（耦合的伪全局保证）**：通用先验与长程规划耦合时，如何避免把局部有效的技能卡/块证书“洗白”为任务级保证？如何让任务级证书可组合、可审计、可一键退化？

## 2. 五条设计原则（雏形，正式化见产物区定义 448–460）

**P1 本体级能力闭包（Capability Closure per Embodiment）**
通用策略只能在当前本体已认证的技能集 `Cap(e)` 内提议与排序；不能因为技能在其它本体上有效就扩大 `Cap(e)`。形式化方向：`route(·, e, ·)` 的值域受限于 `Cap(e)`；缺卡技能一律不可执行。这给出「通用先验不扩权」的类型级保证。

**P2 迁移证书与不可传递性（Transport Certificate, Non-Transitivity）**
跨本体迁移必须携带显式证书 `TC(e→e')`：任务空间映射 `τ`、Lipschitz 常数、残差、包线交集与覆盖。`TC(e→e') ∧ TC(e'→e'')` **不自动**给出 `TC(e→e'')`；必须显式复合，且覆盖交集为空或残差超界时输出 ⊥。

**P3 任务契约 DAG 与里程碑证书（Mission Contract DAG + Milestone）**
长程任务编译为带前置/后置/不变式/预算/截止期/不可逆标记/可重启契约的子目标 DAG。每条边必须有 frame condition；每个完成的节点必须出里程碑证书 `MC(v)` 并追加到只增账本。任务级证书只能是这些局部证书的显式组合，不能是“规划器说它完成了”。

**P4 可重启性优先 / 不可逆屏障（Restartability First）**
每个子目标优先要求可重置契约 `RRC(v)`：检查点、恢复算子、补偿策略、恢复时限。没有 `RRC` 的节点视为**任务级不可逆**，强制 K=1 并要求独立回执交叉验证；不可逆动作绝不被长块或任务级推测捆绑。

**P5 任意时间有效的风险会计（Anytime-Valid Risk Accounting）**
长程任务是非平稳的，经典共形校准的交换性会失效，按步 union bound 又会随 N 爆炸。用 e-process / test martingale 维护时间一致覆盖，并按任务阶段分层；当条件有效性不成立时，退回逐块共形，再退回 ToolGauge 的全局阈值。

## 3. 与基线的接口（如何退化）

- `Cap(e)` 为空或技能卡失效 ⇒ 使用专家策略 / ToolGauge 单本体路径；
- 迁移证书缺失 / 覆盖为空 / 残差超界 ⇒ 禁止跨本体迁移，回到每本体独立校准；
- 任务 DAG 非良构、存在无界环、边缺少 frame condition ⇒ 线性化为 InstructGauge 的子目标序列；
- 节点缺少 `RRC` ⇒ 标记为任务级不可逆，强制 K=1 + 独立验证；若无法独立验证 ⇒ 中止任务；
- 任意时间校准假设失效 ⇒ 逐块共形（InstructGauge）；再失效 ⇒ ToolGauge 全局阈值；
- 任一层失效 ⇒ InstructGauge ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个**技能能力卡 + 迁移证书**的口径，把“通用机器人”的安全性从模型能力问题转成可检查的契约问题，并给出迁移不可传递性的反例与复合条件；
2. 一个**任务契约 DAG + 里程碑账本**，使长程任务的完成、预算、漂移与残余义务可审计、可恢复、可重放；
3. 一个**长程误差复合定理**：无重置时任务成功率随 N 指数衰减，有可重启契约与里程碑验证时任务风险可压回可加/线性，并给出重置阈值；
4. 一个**任意时间有效的分层校准**方案，修正长程非平稳与自适应策略导致的覆盖失效；
5. 一条完整可证伪路径：E457–E472 覆盖迁移证书、任务复合、长程复合、恢复、任意时间覆盖、异构交接、对抗漂移与 50Hz 时序保全。

## 5. 本轮最大风险

**一句话**：通用机器人的技能先验会让能力卡“看起来可迁移”，长程任务的 DAG 会让局部证书“看起来可组合”，真正的风险是产生一种**已被全局认证的错觉**——而迁移映射与分层校准只在局部成立，跨子目标耦合与非平稳性会使任务级保证整体失效。

## 2. 形式化定义（要点）

**定义 448（深度观测与各向异性误差模型）** 深度观测 `D_t = (I_t^rgb, Z_t, I_t^conf, θ_t)`。传感器模型
`Z_t(x) = z*(x) + b_d(x) + ε_t(x)`，`ε_t(x) ~ N(0, σ_z²(z,θ,reflectance))`，横向误差 `σ_xy(z)`。立体深度 `σ_z ≈ (z²/(fB))σ_disp`；ToF 额外含多路径项。逐点协方差 `Σ_d(x)` 在切平面内各向异性。关键点：深度误差**不是**各向同性高斯——把它当各向同性会系统性低估斜视与远距离区域的几何不确定性。

**定义 449（深度有效性证书 DVC）** `DVC(D_t) = (M_t, Σ_d, b̄_d, prov)`。有效性由多模态一致性、左右一致性、时间一致性（经自运动补偿）、法向/入射角、反射率/饱和、标定残差共同判定：`M_t(x) = 1[V_d(x) ≥ τ_v]`。认证条件：对 `x∈M_t`，`|Z_t(x)−z*(x)| ≤ ε_d(x)` 以概率 `≥1−δ_d`，其中 `ε_d(x) = k_{δ_d}·sqrt(λ_max(Σ_d(x))) + b̄_d(x)`。`M_t(x)=0` 表示**未知**，不是「已知为零误差」；未认证区域不得被降权。

**定义 450（认证几何先验 G_d）** `G_d = (Ŝ_d, U_d, M_t, ε_d, b̄_d)`，其中 `Ŝ_d` 仅在 `M_t` 上估计表面/占据，`U_d(x)` 为几何后验不确定度，由 `Σ_d` 与偏置界传播得到。`G_d` 是**先验**，不是回执；其类型标记为 `Speculative`。

**定义 451（深度条件化信息增益与稳健混合先验）**
`IG(a|G_d) = H(h|G_d) − E_{y∼p(·|a,G_d)}[H(h|G_d,y)]`。
高斯近似下标量假设有 `IG ≈ ½ log(1 + σ_prior²/σ_meas²)`：深度认证得越紧（`σ_prior` 小），探测价值越接近零。为防深度偏置，采用稳健混合
`p(h|G_d) = (1−ρ)·p_trust(h|G_d) + ρ·p_biased(h|G_d, b)`，`b ∼ U([−b_max,b_max])`；
规划分数 `IG_robust(a) = IG(a|G_d) + λ_audit·IG_audit(a)`，其中审计项只在审计比例为 `α_audit` 时非零。

**定义 452（状态单元、能力令牌与类型分离）** 状态 `S` 分为五个单元，每个 `S_i = (V_i, ep)`，`V_i` 是 `key → (value, ver)` 的版本化映射。能力令牌 `Tok(m, S_i, mode)` 显式授予模块 `m` 对单元 `S_i` 的 `r/w` 权限，**无环境权限**：
- 深度模块：`r/w S_prior`，对 `S_commit` 无令牌；
- 执行器：`r S_prior, r/w S_exec`，产生签名回执；
- 校准器：`r S_commit, r/w S_cal`；
- 审计器：`r/w S_audit`（原始审计回执只写不改）；
- 提交器：`w S_commit`，且必须出示 `CommitCert`。
类型上 `S_prior` 的值是 `Speculative`，`S_commit` 的值是 `Evidence`；不存在从 `Speculative` 到 `Evidence` 的隐式转换。

**定义 453（隔离不变量 I1–I6）**
- **I1 能力封闭**：任何 `S_commit` 写入都要求 `w` 令牌与 `CommitCert`；
- **I2 猜测/证据类型分离**：`S_prior` 不得被校准或提交逻辑当作证据读取；
- **I3 快照一致**：每个事务在其 `ep` 的同一快照上读；
- **I4 中止无副作用**：`abort` 丢弃写集，不改任何已提交单元；
- **I5 审计分离**：`S_audit` 原始回执只能由审计器写，校准器只能读聚合统计，不能覆盖；
- **I6 单元局部静默**：提交/热替换只要求受影响的单元无在途读写，不要求全局停世界。
非干扰（non-interference）定义为：固定探测时序下，任意改变 `S_prior` 的轨迹不改变 `S_commit` 的历史。

**定义 454（计量事务 MTP 与提交证书）** `Txn = (ep, RS, WS, tok, cert)`。`begin(ep)` 取快照；`read` 记录读集；`stage` 以写时复制暂存写集；`commit` 要求 `CommitCert = (receipts, ChunkCert, DVC, ConflictCert)` 有效，且无写写冲突与危险读写反依赖；`abort` 丢弃写集。物理执行只发生在 `S_exec`，执行结果以签名回执返回；**回执是唯一能把 `Speculative` 提升为 `Evidence` 的凭证**。

**定义 455（可串行化提交与冲突证书）** 采用串行化快照隔离（SSI）：事务在快照上读写，提交时检测 `rw`-反依赖危险结构（读写环）。若检测到，返回 `ConflictCert` 并中止；否则签发 `SerialCert`。性质：所有提交事务的历史存在一个与 `ep` 一致的串行序，逐事务读写等价。`Iso-2` 及以上强制 SSI；`Iso-1` 只保证快照读，不保证可串行化。

**定义 456（隔离级别与优雅降级）** `Iso-0`：单状态（基線，无隔离）；`Iso-1`：`S_exec` 快照隔离；`Iso-2`：`S_commit` SSI；`Iso-3`：SSI + `S_audit` 分离。运行时选择满足预算的最高级别；若超时则 `Iso-2 → Iso-1 → Iso-0` 逐级降级，但**不得**跳过 I1/I2（它们不是性能选项，而是安全类型规则）。

**定义 457（回滚、补偿与物理不可逆性标记）** 未提交事务的回滚是丢弃写集；已提交信念的回滚是**追加**补偿事务 `Txn^c`（携带反证回执），不改写已提交前缀。`CompCert` 必须显式标记：哪些效果是「信念可回滚」，哪些是「物理已发生、不可回滚」。对不可逆动作，回滚只能更新对其后果的估计；`Barrier`（定义 445）仍然强制 `K=1` 与独立回执验证。

**定义 458（深度审计采样与 SPRT 偏置检验）** 审计集 `A` 按已知倾向 `π(a|x)` 采样，且 `π` 与 `G_d` 独立（如均匀或按几何覆盖）；`α_audit = |A|/|probes|`。对审计点计算归一化残差 `r_i = (z_probe − Z_d(x_i))/σ_i`。用 SPRT 检验 `H0: |b| ≤ b0` 对 `H1: |b| ≥ b1`；在检测功效 `≥1−β`、误报 `≤α_sprt` 的约束下确定最小审计数 `N`。若拒绝 `H0` ⇒ `ρ ← ρ·γ`（`γ<1`），并使对应 DVC 分层失效。

**定义 459（采样感知分层共形校准）** 部署分布 `P_dep` 与校准采样分布 `P_samp` 因深度条件化而不同。分层 `s_d = (有效性等级, 区域类型, 距离桶)`。若层内可交换，用层内分位 `q_{s_d}` 保证 `P(h*∈H_{s_d}|s_d) ≥ 1−α`；若跨层混合，用逆倾向权重 `w(x) = dP_dep/dP_samp` 的加权分位。`|C_cal^{s_d}| < n_min` ⇒ 回退全局阈值。未分层、未加权的池化校准在深度选择效应下会**逐层失效**。

**定义 460（深度有效性分层漂移检测）** 逐层跟踪预测收缩与实测收缩的残差；若层内漂移 `> η_{s_d}` 连续 `q` 次，则使该层 DVC 失效、触发重新标定或回退全局；与 ToolGauge `P-Quarantine` 共用断路器。深度域漂移（光照、材质、温度）通常先在某一层出现，分层检测比全局检测更早。

**定义 461（对抗深度模型与纵深防御）** 攻击者控制 `D_t`（欺骗、投影、反射、重放），攻击预算 `R_adv`；目标为 (i) 把探测引向错误区域、(ii) 迫使错误提交、(iii) 耗尽预算。防御链：DVC 多模态一致性 → 审计采样 → 回执绑定 → SSI 冲突检测 → `Barrier` 不可逆闸门。定义攻击成功为「无一致回执却改变 `S_commit`」；在此定义下深度欺骗只能影响采样分布与 `S_prior`，不能直接改变契约。

**定义 462（单元局部隔离屏障与两阶段提交）** 对单元 `S_i` 定义 `q_iso(S_i)`：无在途事务读或写 `S_i`。提交/热替换只需 `q_iso(S_i)`，无需全局 `q_quiesce`，从而降低延迟。跨单元事务（如同时写 `S_commit` 与 `S_audit`）采用两阶段提交：先 prepare 全部单元，再统一 commit；任一 prepare 失败则全局 abort。

**定义 463（深度增强修复解释证书）** `RepairCert″(s) = (ι, C, ChunkCert, DVC, G_d, TxnCert, receipts, claims, audit)`。证据链从四级扩为六级：**指令 → 深度先验 → 分块 → 事务 → 回执 → 主张**，并附审计分支说明「深度信任度 `ρ` 的依据」。审计者可以据此区分「因为深度而没探」与「因为回执而确认」。

# IP-328 DVC：逐区域深度有效性证书
class DVC:
    def certify(self, D):
        M = (cross_modal_consistent(D)
             & left_right_consistent(D)
             & temporal_consistent(D, ego_motion=True)
             & normal_incidence_ok(D)
             & reflectance_ok(D)
             & calibration_residual_ok(D))
        M = M & ~flying_pixels(D)                 # 遮挡边界飞点
        Sig = anisotropic_sigma(D)                # 轴向/横向
        b   = bias_bound(D.calib_residual, D.cross_modal)
        return DVCCert(M, Sig, b, provenance(D))

# IP-329 DGP：认证几何先验（只进先验，不进契约）
class DGP:
    def prior(self, D, dvc):
        S_hat = depth_to_surface(D, mask=dvc.M)
        U     = geom_uncertainty(D, dvc.Sig, dvc.b)
        return GeometricPrior(S_hat, U, dvc.M, dvc.eps, dvc.b)

# IP-330/331 ISA + MTP：隔离单元与事务
class IsoState:
    CELLS = ("prior", "commit", "cal", "exec", "audit")
    def __init__(self):
        self.cells = {c: VersionedMap() for c in self.CELLS}
        self.ep = 0
    def allows(self, tok, cell, mode):
        return tok.cell == cell and mode in tok.modes   # 无环境权限
    def read(self, tok, cell, key):
        assert self.allows(tok, cell, "r") and cell != "commit" or tok.can_read_evidence
        return self.cells[cell].get(key, snapshot=self.ep)
    def stage(self, txn, cell, key, val):
        assert self.allows(txn.tok, cell, "w") and cell != "commit"
        txn.ws[(cell, key)] = (val, txn.ep + 1)          # 写时复制
    def commit(self, txn, cert):
        if not cert.valid or self.detect_rw_cycle(txn):
            return self.abort(txn), ConflictCert(txn)
        for (cell, key), (val, ver) in txn.ws.items():
            self.cells[cell].put(key, val, ver)
        self.ep += 1
        return CommitCert(txn, cert, SerialCert(txn)), None
    def abort(self, txn):
        txn.ws.clear()                                   # I4：中止无副作用
        return Aborted(txn)

# IP-332 DAS：独立审计 + SPRT
class DepthAuditor:
    def sample(self, candidates, alpha_audit):
        n = max(1, floor(alpha_audit * len(candidates)))
        return independent_sample(candidates, n, propensity=UNIFORM)
    def sprt(self, residuals, b0, b1, alpha_sprt, beta):
        # 归一化残差的序贯似然比；返回 reject_H0 / continue
        return sprt_test(residuals, b0=b0, b1=b1, alpha=alpha_sprt, beta=beta)

# IP-333 SWC：采样感知分层共形
class SWC:
    def threshold(self, iota, depth_cert, cal):
        s = stratum_depth(iota, depth_cert)              # 有效性/区域/距离
        if len(cal.get(s, [])) < N_MIN:
            return conformal_quantile(cal[GLOBAL], ALPHA)  # 优雅回退
        w = inverse_propensity_weights(cal[s], depth_cert)
        return weighted_conformal_quantile(cal[s], w, ALPHA)

# IP-334 IsoDepthGauge-8C 闭环
def isodepthgauge_8c(M, s, ell):
    dvc = M.dvc.certify(M.depth)
    G   = M.dgp.prior(M.depth, dvc) if dvc.usable else None
    out  = M.nlib.ground(ell, M.scene, M.ontology)
    iota = out[0] if out else M.default_iota        # 不可接地 ⇒ InstructGauge 默认
    H    = M.lbox.hypothesize(s, M.dbox.R[s], iota)
    if G is not None:
        H = M.reorder_by_prior(H, G, rho=M.rho)      # 只重排，不写入
    C    = M.iac.plan_chunk(iota, H, M.tools, M.budget_left(s), M.drift_bound(s))
    if not M.tcv.verify(C.as_program(), M.budget_left(s))[0]:
        C = M.numeric_fallback(H)
    cert = M.cvc.commit(C, M.env, iota)               # 块级否决点仍在
    receipts = cert.receipts
    if len(receipts) < n_min(s):
        return stub_and_red(s, "insufficient")
    txn = M.iso.begin()                              # 快照
    M.iso.stage(txn, "exec", "last_chunk", cert)
    ok, cc = M.iso.commit(txn, M.mtp.commit_cert(receipts, cert, dvc))
    if not ok:                                        # SSI 冲突 ⇒ 决策不变，重试
        return stub_and_red(s, "conflict")
    mu, Sig = M.apcal.calibrate(receipts, H, s)
    M.iso.commit(M.iso.begin(), M.mtp.cal_cert(mu, Sig), cell="cal")
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s)
    if not contract_regression(new_ec):
        return stub_and_red(s, "regression")
    M.mreg.hot_replace_at_quiescence(M.dpe, new_ec, cert.boundary)  # 单元局部静默
    bind_claims(cert, iota, receipts)
    M.pquar.record(M.apcal.last_gain, realized_gain(receipts))
    return True

# IP-334 主闭环（50Hz 路径不变；DVC/审计异步）
def IsoDepthGauge_round(M, obs, audio, tac, depth, det, ell=None):
    M.depth = depth
    submit_async(M.dvc_task, depth)                   # O(|Z|) 但异步/降采样

            M.inflight.add(s)
            submit_async(isodepthgauge_8c, M, s, ell)
    return InstructGauge_round(M, obs, audio, tac, depth, det, ell)

## 4. 推导

**引理 59（DVC 可靠性）** 若各有效性检验在水平 `δ_j` 下校准，则对认证区域 `R ⊆ M`，`P(∀x∈R: |Z(x)−z*(x)| ≤ ε_d(x)) ≥ 1 − |R|·δ_d`。*证明*：逐点误差界由传感器模型与偏置界给出；对 `R` 取联合界。推论：认证先验的误差有界；未认证区域无误差界，只能按「未知」处理——这正是「未认证不得降权」的形式依据。

**引理 60（深度无直写通道 / 类型分离）** 在能力令牌系统（定义 452）与 I1/I2 下，固定探测时序时，任意仅改变 `S_prior` 的轨迹都不改变 `S_commit` 历史。*证明*：`S_commit` 的写入只能由持有 `w` 令牌的提交器发起，且必须出示含回执与 `SerialCert` 的 `CommitCert`；深度模块对 `S_commit` 无令牌，`Speculative` 到 `Evidence` 无隐式转换。故深度只能通过「改变采样→产生不同回执」间接影响契约。推论：深度损坏的安全性归约为采样/审计设计的鲁棒性，而非契约存储的完整性。

**引理 61（SSI 可串行化与回滚局部性）** 若所有提交事务通过 SSI 危险结构检测，则已提交历史可串行化；中止事务对已提交状态零影响；补偿事务只追加、不改写已提交前缀。*证明*：SSI 的标准可串行化定理；写集写时复制使 abort 无副作用；日志追加保证前缀不可变。推论：信念回滚是局部的、可审计的，但物理效果不在回滚范围内（定义 457）。

**引理 62（故障单元隔离 / 爆炸半径）** 若单元间不共享可变状态且访问均经令牌中介，则单个单元内的故障（异常、NaN、内存腐败）不能写入其他单元；恢复方式是丢弃该单元并从最近提交快照重载。故故障半径 `≤ 1` 个单元。*证明*：I1/I3/I4 给出写入与读取的隔离；对单元集合做归纳。注意：`S_exec` 的**物理**副作用不受隔离保护——这是状态隔离的能力边界。

**引理 63（深度感知信息增益与预算迁移）** 在认证先验下，对深度已把几何假设夹到 `ε_d` 的站点，`IG(a|G_d) → 0`；故最优探测分配把质量迁向 `M` 的补集与高 `U_d` 区域。加入稳健混合后，`IG_robust` 多出 `ρ·IG_audit` 项；当 `ρ>0` 时纯利用分配退化，审计项保证探索。推论：相对无深度基线，探测数的下降量 `≤` 深度认证区域本应消耗的探测数；若深度有偏，审计成本可能抵消节省（由 E458/E460 检验）。

**引理 64（采样感知共形覆盖）** 若按 `s_d` 分层且层内可交换，则 `P(h*∈H_{s_d}|s_d) ≥ 1−α`；边缘覆盖 `P(h*∈H) ≥ 1−α − Σ_{s_d} π_{s_d}·TV_{s_d}`。若用已知倾向的逆权重，加权共形在 `P_dep` 下覆盖 `≥1−α`（权重估计误差带来 `O(E|ŵ−w|)` 的松弛）。未分层池化校准在深度选择效应下覆盖可低至 `1−α−TV(P_dep,P_samp)`，这正是必须分层的理由。低样本层回退全局 ⇒ 按 `−2η_global` 优雅降级。由 E464 检验。

**引理 65（对抗深度包容）** 攻击者控制 `D` 时，在引理 60 下只能改变采样分布与 `S_prior`。要改变 `S_commit`，必须 (i) 通过 DVC 多模态一致性，(ii) 诱导与虚假假设一致的物理回执，(iii) 躲过独立审计与 SSI 冲突检测。若审计在 `N` 次内以 `≥1−β` 检出偏置 `b1`，则虚假提交概率 `≤ (1−β)^N + ε_collision`；不可逆动作仍被 `Barrier` 截为 `K=1` 并要求独立交叉验证。故深度欺骗是「采样/预算攻击」而非「直接安全攻击」，其最坏后果是浪费探测与延迟发现真盲区，而非越权执行不可逆动作。由 E465/E466 检验。

**引理 66（隔离与深度开销 / 50Hz 保全）** DVC 在降采样深度上为 `O(|Z|/s²)`，可异步；事务读为版本化哈希查找 `O(1)`，提交冲突检测 `O(|WS|)`，`|WS|` 为小常数；单元局部静默避免全局停世界。故每探测摊销新增时延 `< 0.2ms`，主 50Hz 周期不变（继承 ToolGauge 引理 50）。若预算不足，按定义 456 降级隔离级别；I1/I2 不可降级。由 E469 检验。

| 采样感知覆盖（E464） | 每层 ≥ 0.9 | 增加分层样本或回退全局 |
| 对抗深度（E465/E466） | 虚假提交 < 1%，不可逆 = 0 | 关闭深度先验，仅保留解释 |
| 时序（E469） | 新增 < 0.2ms | 降级隔离级别（不得降 I1/I2） |
| 端到端（E470） | 探测降 ≥ 20% 且成功率不降 | 弃用深度先验，回到 InstructGauge |

预期：E461/E462/E463 为「结构级」判据，应严格成立；E457/E460/E464 为「统计级」判据，按置信区间验收；E458/E470/E472 为「系统级」判据，给出效应量与置信区间。

## 8. 本轮最大风险

**一句话**：DVC 由深度数据自身估计、审计采样又可能稀疏到恰好漏掉镜面/透明这些「深度最自信也最错误」的区域，于是状态隔离只能保证「错误不跨单元传播」，却保证不了「错误被证伪」——系统可能在局部完全安全、全局却系统性偏离真盲区，且快照/版本/审计的固定税会直接侵蚀 50Hz 时序预算。
