# 第 59 轮（承接第 58 轮「结构化记忆×安全自适应×心智协同」IP-139~144；灵感循环第 1 轮；本轮灵感：「开放词汇」×「末端位姿」）

> 第 58 轮把安全论证压在结构化记忆 𝒢 上，并用「仅证据门通过可写入 + 边级溯源 + 事后证伪回溯 + 多源交叉校验」防止 KG 共模失效；但它的风险自陈仍留下三个未解问题。**(a) 闭词汇**：𝒢 的实体/关系类型固定，真实世界却不断产生没被命名过的表面与材质——地图的边界就是系统的盲区，而「未命名」恰恰最该保守；若为了覆盖而放开词表，语义幻觉会冒充结构化知识。**(b) 区域原子**：𝒢 的原子是区域/表面节点，但不可逆接触真正拍板的是**末端位姿 p∈SE(3) 与力旋量 𝒲**；「这片平面整体安全」推不出「这个带倾角的边缘接触位姿安全」，区域信念只是位姿安全的一个边缘分布，而 SE(3) 连续、逐点探针不可能。**(c) 弱相关先验**：开放词汇模型的标签语义丰富但物理未校准，且与互联网文本强相关、与当前物理场景弱相关；若把「语义-几何一致」当作第 57 轮 EV-xmodal 式的独立加成，就会把自信放大在错误方向。本轮两个灵感恰好是一对反义词：**开放词汇扩大假设空间（语义）**，**末端位姿缩小动作空间（几何）**。核心命题由第 58 轮的「结构化记忆守护」升级为 **「开放词汇只许提案、末端位姿才许裁决；语义越开放，几何越保守的开放-保守对偶」**。

核心矛盾：
- **H29（开放词汇 vs 证据闭包）**：标签假设空间随词表无界增长，证据只能逐点闭合；逐标签校准在长尾、同义、层级漂移下不可能。开放词汇一旦进入断言层，语义幻觉会同时污染 OOD 门、共形校准集、类比证据与心智预测——这正是第 58 轮最怕的共模失效，只是触发源从「缺失的欺骗边」换成「多出来的名词边」。
- **H30（末端位姿 vs 证据稀疏）**：区域级证据太粗（安全平面不担保邻近边缘/悬挑），位姿级证据太稀（SE(3) 连续，每点探一次不可行）。跨位姿泛化不能靠「标签相似」，必须靠显式的几何-力学传递界；没有界的传递，只是把「先验质量」的赌注从区域级挪到位姿级。
- **H31（语义-几何共谋）**：语义先验与几何先验「一致」不是独立证据，而是同源相关性（都受纹理/光照/训练语料影响）。若把一致当加成，会让最容易一起错的两个信号互相背书；反过来，分歧才是强警报。必须让语义只能单向加宽风险，永不能收窄。

## 0. 直觉与动机

**灵感 1（开放词汇 → 提案而非断言：proposal-not-assertion）**
直觉：开放词汇是「想象力」，不是「事实」。视觉-语言模型能命名从未见过的东西，但**命名不是证据**——「这是冰面」是一句假设，「在这里以这个倾角施加这个力不会滑」才是可裁决的命题。于是把 𝒢 拆成双层：**假设层 𝒢_H**（开放词表、带 TTL 与 provenance、安全函数无读权）与**断言层 𝒢_A**（闭类型、仅证据门可写、边带位姿与证书）；只有位姿级接触证书能把假设提升为断言。同时把无界词表压到**有限物理属性商** 𝒜（摩擦等级、柔顺度、脆性、质量级、接触模式），校准在有限的物理轴上做，而不是在无界的标签空间里做。

**灵感 2（末端位姿 → 安全的最小单位是位姿，不是区域）**
直觉：「这块地是安全的」不等于「这个落脚点/抓取位姿是安全的」。滑移、边缘、悬挑、曲率都是**位姿局部**的性质。把证据的原子从「区域」换成「位姿 p + 力旋量 𝒲 + 接触模式 m」；用**位姿图册**（按接触模式与局部几何签名分片）避免在 SE(3) 上盲目撒点；用**传递算子 T** 把一次探针的作用域显式写成测地距离、法向差、曲率差与力旋量锥包含的函数，并附一个 Lipschitz 型风险上界。区域信念降级为位姿安全场的边缘分布，只能用于规划，不能用于承诺。

**灵感 3（两灵感合流 → 开放-保守对偶）**
直觉：语义越陌生，动作自由必须越小；只有在语义被证据锚定之后，才允许更大的位姿集与力帽。形式化：区域开放度 O(r)（校准后的假设熵 / OOD 裕度）与保守度 C(r)（位姿传递半径、力帽、探针预算）在每类风险下满足 **O(r)·C(r) ≤ C_max**。这给出一个漂亮的结论：**部署安全界与词表大小 |ℒ| 无关**——放开词汇不会线性放大风险，因为保守旋钮会同步收紧。语义先验则只走「单向阀」：能加宽 P_fail，不能收窄。

**灵感 4（证据门 → 位姿条件证据门 + 语义非证据硬约束）**
直觉：第 58 轮六类证据门（EV-probe*/visit/margin/xmodal/human/ft/ux）全部隐含「区域」这个原子。本轮把它们挂到位姿上：EV-probe* 必须带**承诺位姿证书 C_p**；EV-margin 必须经**位姿传递链**落到 p；EV-xmodal 仍限 L1；**开放词汇标签、𝒢_H 边、语义-几何一致一律不构成证据类**。不可逆接触的必要证据集里，语义最多贡献「候选位姿」，绝不贡献「可信」。

**灵感 5（PCX+++ → 在 SE(3) 上而不是在区域上探询）**
直觉：过去 VOI 是在「探哪个区域/哪个模态」上算的；本轮探询对象变成**位姿**。OVAG 提案给出候选位姿，PSC 判断哪些已有证书/可传递、哪些必须新探，VOI_pose 在「探这个位姿 vs 移位姿 vs 换接触模式 vs 绕行」之间权衡。开放度上升时自动收缩可接受位姿集与力帽（对偶约束 C≤C_max/O），于是「更开放」在动作层表现为「更慢、更窄、更轻」，而不是「更敢赌」。

## 1. 形式化定义（增量：定义 145–150）

**定义 145（开放词汇可供性提案 OVAG）** 输入多视角观测 o、任务文本 τ、场景上下文 z_r；输出有限提案集 H_r={(ℓ,a,P_ℓ,c_ℓ,src)}，ℓ 为开放词表标签，a∈𝒜 为**有限物理属性商**（摩擦等级 f、柔顺度 κ_c、脆性 b、质量级 m_q、接触模式 m∈{flat,edge,corner,curved,articulated}），P_ℓ⊂SE(3)×𝒲 为满足该属性假设的可达位姿-力旋量提案，c_ℓ 为提案置信，src=(模型版本,prompt,视角数)。硬约束：(i) 安全计算只消费 (a,P)，ℓ 仅作检索键与解释用词；(ii) 属性商 π:ℒ→𝒜 多对一，校准在 𝒜 上做而非 ℒ 上做（有限轴可校准）；(iii) c_ℓ 只准进入风险**加宽**项，永不作似然。提案完备性下界：对真实接触模式 m*，要求 P(m*∈{m(ℓ):ℓ∈H_r})≥1−δ_cov（覆盖契约，独立于语义置信）。

**定义 146（开放词汇双层图 OVKG）** 𝒢=(𝒢_A,𝒢_H)。断言层 𝒢_A：闭类型、仅证据门通过可写、边带 (src,ver,cert_id,pose_at_write)；假设层 𝒢_H：开放节点/边、TTL τ_H、provenance=(模型,prompt,视角集)，**无读权**——OOD 门、共形校准集、证据合成、信任状态一律只读 𝒢_A。提升 Prom:(h∈𝒢_H)→𝒢_A 当且仅当存在位姿证书 C_p 通过位姿条件门且属性 a 与实测一致；证伪则按 src 级联回溯删除，并冻结同源假设（不再提议，直到模型/语境版本更新）。不变量 I-ov：**任何安全判定函数对 𝒢_H 的读权限为空**。

**定义 147（末端位姿条件安全证书 PSC）** 位姿 p=(x,R)∈SE(3)，力旋量锥 𝒲_p，接触模式 m(p)。位姿条件安全 S(p,w)=P(fail|G_p,a,w)，G_p 为局部几何片（法向 n、曲率 κ、边距 e_dist、支撑多边形）。**位姿图册**按 (m, 几何签名) 把可达 SE(3) 分片。**传递算子 T**：证据 e@(p_e,w_e) 可认证 p，当且仅当 d_SE3(p,p_e)≤ρ_p ∧ ∠(n,n_e)≤θ_n ∧ |κ−κ_e|≤κ_max ∧ 𝒲_p⊆𝒲_{p_e}；此时

  R̂(p) ≤ R̂(p_e) + L_g·d_SE3(p,p_e) + L_w·d_𝒲(w,w_e) + L_a‖a−a_e‖ + L_κ·|κ−κ_e|，

其中 L_* 是声明的局部 Lipschitz 常数。任一条件不满足 ⇒ **无证书**、必须新探，禁止外推。证书 C_p=(p,m(p),hash(G_p),𝒲_p,evidence_ids,transfer_chain,bound,ver,expiry)。不可逆接触必须在**承诺位姿 p** 上持有 C_p；区域级信念不得替代。

**定义 148（语义-几何互审 SGC）** 对区域 r，语义属性 a_sem（来自 OVAG）与几何/物理属性 a_geo（来自 PSC 与探针）。互审量 D_sg=dist_𝒜(a_sem,a_geo)+Hausdorff(P_sem^adm,P_cert^adm)/scale。四规则：(R1) **单向阀**：P_fail←max(P_fail, Widen_sem(P_fail))，语义只增不减；(R2) D_sg>θ_sg ⇒ 视作 OOD-类，强制至少一次揭示位姿的探针（优先边界/边缘）或收缩可接受位姿集，并禁止 Prom；(R3) 语义-几何**一致不是证据类**，不产生 EV、不加速授权（防同源相关性背书）；(R4) 语义提案只可**收缩候选位姿搜索集**（省时），永不可**扩张可接受位姿集**（省安全）。

**定义 149（位姿条件证据台账 J_ov）** 证据项 e=(r,p_e,m(p_e),w_e,class,C_p 或 transfer_chain,label_hyp_ids,ts,falsify_links)。不可逆接触 @p 的必要证据集={EV-probe*(p)∧C_p ∨ EV-margin(p) 经有效传递}∪佐证；**显式排除**：原始开放标签、EV-xmodal、𝒢_H 边、语义-几何一致。J_ov 扩展 J_p++：(ov_hypothesis_ids, pose_cert, pose_atlas_chart, sgc_audit, pose_transfer_graph, openness_state)。

**定义 150（探-诺-演+++ 算子 PCX+++）** 每检查点：①OVAG 提案 H_r（ℓ,a,P）；②仅写 𝒢_H；③SGC 互审；D_sg 高或开放度 O 高 ⇒ 收缩可接受位姿集与力帽；④PSC 对候选位姿查证书/传递；无证书则选 VOI_pose 最大的位姿探针（探「位姿」而非「区域」）；⑤承诺 ⇔ ∃p∈可接受位姿集：R̂(p)≤δ_f ∧ 位姿条件门过；⑥否则绕行→降档→L2 协商→安全停。全程施加**开放-保守对偶约束** C(t)≤C_max/O(t)。

## 2. 关键算法伪代码（完整版见产物区）

```python
def ovag_propose(obs, task_text, z):                # IP-145: 只提案
    H = vl_ground(obs, task_text)                   # 开放词表标签
    return [Hyp(l, a=attribute_quotient(l),        # ℓ -> 有限物理属性
                P=pose_force_proposals(l, obs),     # SE(3)×W 候选
                c=calibrated_proposal_conf(l), src=src_of(l))
            for l in H]

def ovkg_write(G, H, cert):                         # IP-146: 双层图
    for h in H:
        if cert is None or not cert.ok:
            G.H.add(h, ttl=TAU_H)                   # 假设层，安全函数不可读
        else:
            G.A.add(promote(h), src=h.src, cert_id=cert.id)  # 证据门通过才提断言

def psc_certify(e, p, w, G_p):                      # IP-147: 位姿传递界
    if not transfer_ok(e.p, p, G_p):                # d_SE3/法向/曲率/力锥
        return None                                 # 无证书 -> 必须新探
    return Cert(p, m=contact_mode(G_p), W=w,
                bound=e.R + Lg*d_SE3(e.p,p) + Lw*dW(w,e.w) + La*da + Lk*dk,
                chain=e.chain + [p])

def sgc_audit(H, G_p, probes):                      # IP-148: 语义-几何互审
    D = dist_attr(H.a_sem, G_p.a_geo) + hausdorff(H.P_adm, G_p.P_cert)/scale
    return D, (widen_only(H), forbid_promote if D > theta_sg else None)

def pcx_ppp(cp, M, budget):                         # IP-150: 在 SE(3) 上探询
    H = ovag_propose(M.obs[cp], cp.task, ctx(cp)); ovkg_write(M.G, H, None)
    D, act = sgc_audit(H, M.geom[cp], M.probes[cp])
    P_adm = shrink_pose_set(M.adm[cp], openness(H)) if (D > theta_sg or O(H) > theta_O) else M.adm[cp]
    while select_gait(risk(M, cp, P_adm)) == 'halt' and budget.probes_left > 0:
        cand = [p for p in P_adm if psc_certify(M.ev, p, cp.w, M.geom[cp]) is None]
        if not cand: break
        p = argmax(cand, key=lambda p: voi_pose(p, M, H) - cost(p))
        M = record(M, p, execute_pose_probe(p, cap=force_cap(O(H))))
        P_adm = shrink_pose_set(P_adm, openness(H))
    return commit_or_degrade(cp, M, P_adm)          # 承诺需 C_p，区域证据不够
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| OVAG | O(C_vl)/检查点 | O(\|H_r\|) | 属性商有限、提案置信只加宽、模式覆盖 ≥1−δ_cov |
| OVKG | O(1) 提升/回溯（src 级联 O(\|E_src\|)） | O(\|𝒢_A\|+\|𝒢_H\|·TTL) | 安全函数对 𝒢_H 零读权、提升需 C_p |
| PSC | O(\|P_adm\|·(d_SE3+\|G_p\|)) | O(\|P_adm\|+\|图册片\|) | 传递条件全满足才外推、Lipschitz 上界诚实 |
| SGC | O(d_𝒜+\|P\|·log\|P\|) | O(\|P_adm\|) | 单向阀、一致非证据、分歧即 OOD-类 |
| J_ov | O(\|e\|) | O(\|σ\|·\|P\|) | 语义不进必要集、证书绑承诺位姿 |
| PCX+++ | O(\|CP\|·|P_adm|·(C_VOI+d_SE3+d_GNN)+A*) | O(\|V\|+\|σ\|+\|𝒢\|+\|P_adm\|) | 对偶预算单调、位姿级终止 |

**正确性定理（Open-vocabulary Pose-Guarded Adaptive Soundness, OPGAS 概要）**：在 A41–A45（第 58 轮）之上加 (A46) OVAG 提案模式覆盖 ≥1−δ_cov、属性商校准 ECE_𝒜≤ε_attr、提案置信仅入加宽项；(A47) OVKG 安全函数对 𝒢_H 零读权、提升必有 C_p、src 级联回溯完备；(A48) PSC 传递条件与 Lipschitz 常数诚实、无证书不外推；(A49) SGC 单向阀成立、分歧触发探针/收缩、一致不产生证据；(A50) 对偶约束 C(t)≤C_max/O(t) 逐检查点执行。则：

(i) **开放-保守对偶界**：ID 路径承诺失效率 ≤ δ_f+ε_meta(k)+ε_attr+δ_probe+δ_pose+ε_h，其中 δ_pose 为位姿传递界误差；**该界不含 |ℒ|**——词表开放度通过 O→C 收紧被吸收，而非线性放大风险。
(ii) **语义非证据性**：移除任一开放词汇提案或翻转其标签，不改变任何已签发证书的 C_p 与必要证据集（因为语义只进加宽项与候选集）。
(iii) **位姿诚实性**：任何不可逆承诺都对应一个承诺位姿上的有效 C_p；区域证据单独不足以承诺。
(iv) **终止性**：PCE+++ 在 k_probes+k_cons+k_pose+k_ft+k_ux 内终止于 {承诺, 绕行, L2 协商, 安全停}；O 上升只会减少可接受位姿集，不会增加探针下界。

## 6. 本轮最大风险

**一句话**：开放-保守对偶只在「保守旋钮真的有效」且「位姿图册覆盖真实接触模式」时成立——若 OVAG 系统性漏掉某类接触模式（例如从不提出「边缘/悬挑/铰接」假设），系统会在错误的模式上**自信地收窄**位姿集，并以「更保守」的假象通过审计；此时风险从第 58 轮的「坏先验普遍」变成「自信地窄且错」，而被漏掉的模式因为从未被提案就永远不会被探、也永远不会被证伪。必须以「接触模式覆盖契约 + 与语义无关的探索配额 + unknown-unknown 位姿集 + 位姿图册覆盖率审计」四重护栏，宁可保留一块语义上说不清、但几何上被随机探针覆盖的位姿，绝不把提案支撑当成真实世界的支撑。

```python
class OpenVocabAffordanceGrounder:
    def __init__(self, vl_model, attr_head, pose_head):
        self.vl, self.attr, self.pose = vl_model, attr_head, pose_head
        self.attr_calibrator = AttributeCalibrator()   # 校准在有限物理轴上

    def propose(self, obs, task_text, z):
        # 1) 开放词表标签（不设闭集）
        labels = self.vl.ground(obs, task_text, z)
        H = []
        for l in labels:
            # 2) 标签 -> 有限物理属性商（多对一，可校准）
            a_raw = self.attr.predict(obs, l)          # (f, kappa_c, b, m_q, m)
            a = self.attr_calibrator.calibrate(a_raw)  # ECE_A <= eps_attr
            # 3) 属性假设 -> 位姿-力旋量提案
            P = self.pose.propose(l, a, obs)           # {(p, w)} subset SE(3)xW
            H.append(Hyp(l, a, P,
                         c=self.attr_calibrator.conf(a),  # 仅入加宽项
                         src=src_of(l)))
        # 4) 覆盖契约：真实接触模式必须在提案模式集合中
        assert mode_coverage(H, obs) >= 1 - delta_cov   # 否则补几何驱动提案
        return self._dedup(H)

    def geometric_fallback(self, obs):
        """与语义无关的兜底提案：保证 edge/corner/悬挑不被系统性漏掉"""
        return [Hyp('__unknown__', a=default_attr(obs),
                    P=all_contact_mode_proposals(obs),
                    c=LOW, src=('geometry_floor',)])

    def openness(self, H):
        """开放度 O：校准后的假设熵 + OOD 裕度倒数"""
        return entropy([h.a for h in H]) + 1.0 / (ood_margin(H) + EPS)
```

### IP-146 OVKG（双层图卫生）

```python
class OpenVocabKG:
    def __init__(self):
        self.A = AssertionLayer()      # 闭类型、仅证据门可写
        self.H = HypothesisLayer()     # 开放词表、TTL、provenance
        self.src_index = defaultdict(set)

    def write_proposals(self, H_r):
        """开放词汇永远先进假设层"""
        for h in H_r:
            node = self.H.add(h.label, attr=h.a, src=h.src, ttl=TAU_H)
            self.src_index[h.src].add(node)

    def promote(self, h, cert, measured_attr):
        """假设 -> 断言：必须有位姿证书且属性一致"""
        if cert is None or not cert.ok: return False
        if not attr_consistent(h.a, measured_attr): return False
        self.A.add(h.label, attr=measured_attr, src=h.src,
                   cert_id=cert.id, pose_at_write=cert.p)
        self.H.freeze(h, reason='promoted')
        return True

    def retract(self, src, reason):
        """事后证伪：src 级联回溯删除，并冻结同源假设"""
        for e in list(self.A.edges_from(src)):
            self.A.retract_edge(e, reason=reason)
        for h in list(self.src_index[src]):
            self.H.freeze(h, reason='falsified')   # 不再提议，直到版本更新
        self.A.bump_ver()

    # 安全函数只暴露 A；H 在接口层不可见（I-ov）
    def safe_view(self):
        return self.A
```

### IP-147 PSC（末端位姿条件证书与传递界）

```python
def psc_certify(e, p, cs, atlas, W_req):
    """证据 e 在 p_e 处，尝试认证位姿 p；不满足条件则返回 None（必须新探）"""
    chart = atlas.chart_of(cs, p)                  # 接触模式图册分片
    if chart is None: return None                   # 无图册覆盖 -> 新探

    G = local_geometry(cs, p)                       # (n, kappa, e_dist, supp)
    d  = se3_distance(p, e.p)
    dn = angle(G.n, e.G.n)
    dk = abs(G.kappa - e.G.kappa)
    # 四条件 + 力旋量锥包含
    if not (d <= rho_p(chart) and dn <= theta_n
            and dk <= kappa_max and force_cone_subset(W_req, e.W)):
        return None

    bound = (e.R
             + L_g * d + L_w * d_w(W_req, e.W)
             + L_a * dist_attr(e.a, current_attr(cs))
             + L_k * dk)
    return Cert(p=p, mode=chart.mode, W=W_req, G_hash=hash(G),
                evidence_ids=e.ids + [e.id],
                chain=e.chain + [p], bound=bound,
                ver=atlas.version, expiry=now() + T_POSE)

def psc_gate(certs, p, delta_f):
    """承诺位姿上必须有证书且界低于阈值"""
    c = certs.at(p)
    return c is not None and c.bound <= delta_f
```

```python
def sgc_audit(H_r, geom, probes, eps):
    a_sem = fuse_attrs([h.a for h in H_r])          # 语义属性
    a_geo = geom_attr(geom, probes)                 # 几何/物理属性
    P_sem = union([h.P for h in H_r])               # 语义可接受位姿集
    P_crt = certified_pose_set(probes, geom)        # 已证书位姿集
    D = dist_attr(a_sem, a_geo) + hausdorff(P_sem, P_crt) / eps
    return D

def apply_sgc(P_fail, H_r, D, theta_sg):
    # R1 单向阀：语义只加宽，永不收窄
    P_fail = max(P_fail, widen_by_semantics(P_fail, H_r))
    # R2 分歧 => OOD-类：强制揭示位姿的探针 + 收缩 + 禁提升
    if D > theta_sg:
        return P_fail, Action(force_pose_probe=True,
                              shrink=True, forbid_promote=True)
    # R3 一致不产生证据：这里显式返回 None（绝不返回 EV）
    # R4 语义只收缩候选搜索集，不扩张可接受集
    return P_fail, Action(gate='advisory_only')

def admissible_poses(H_r, base, D, theta_sg):
    if D > theta_sg:
        return shrink_pose_set(base, openness(H_r))   # 收缩
    return intersect(base, union_pose(H_r))            # 只取交集，不扩张
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| OVAG | O(C_vl + |𝒜|·d_attr + |P|·d_pose)/检查点 | O(|H_r|) | 属性商有限、置信只加宽、模式覆盖 ≥1−δ_cov |

**正确性定理（Open-vocabulary Pose-Guarded Adaptive Soundness, OPGAS）**
假设 A22–A45（第 53–58 轮）成立；新增：
**(A46)** OVAG：提案接触模式覆盖 ≥1−δ_cov；属性商校准 ECE_𝒜≤ε_attr；提案置信 c_ℓ 只进入风险加宽项，从不进入似然。
**(A47)** OVKG：安全判定函数对 𝒢_H 读权限为空（I-ov）；提升 Prom 仅在有效 C_p 且属性一致时发生；src 级联回溯完备；版本单增。
**(A48)** PSC：传递算子四条件（测地距/法向/曲率/力锥包含）与 Lipschitz 常数 L_* 诚实；四条件任一不满足即无证书，禁止外推；证书过期即失效。
**(A49)** SGC：单向阀 P_fail←max(P_fail,Widen_sem) 恒成立；D_sg>θ_sg 触发位姿探针与收缩；语义-几何一致不产生任何证据类。
**(A50)** 对偶约束 C(t)≤C_max/O(t) 在每个检查点执行，且 O 只依赖属性级统计（不随 |ℒ| 增长）。

则：

1. **开放-保守对偶界（核心）**：ID 路径单检查点承诺失效率
   `≤ δ_f + ε_meta(k) + ε_attr + δ_probe + δ_pose + ε_h`，
   其中 δ_pose 为位姿传递界误差（由 A48 控制）。**该界不含 |ℒ|**：开放词汇的增长被 O→C 的保守收紧吸收；对检查点取联合界后仍与词表大小无关。这是本轮相对第 58 轮最重要的结构性改进——第 58 轮的界随「KG 错误概率」增长，而 KG 覆盖随词表扩张而变难；本轮把开放度做成一个**显式、可审计、只影响保守旋钮**的量。

2. **语义非证据性**：对任意已签发证书 C_p，移除或翻转任一开放词汇提案（标签/语义属性/语义位姿）都不改变 C_p 及其证据集；安全结论对语义输入是**常量函数**（除了通过加宽项使风险不减）。推论：语义幻觉无法单独制造承诺。

3. **位姿诚实性**：任何不可逆承诺都存在一个承诺位姿 p* 与有效 C_p*；区域级证据（EV-visit/EV-probe 无 C_p）单独不满足不可逆必要集。推论：第 58 轮「区域安全」不再能越级为「位姿安全」。

4. **图卫生**：𝒢_H 的任意投毒（新增恶意开放词汇边）在提升前对安全函数不可见；证伪后同源假设被冻结，不会二次进入提案。

5. **终止性**：PCX+++ 在 k_probes+k_cons+k_pose+k_ft+k_ux 内终止于 {承诺, 绕行, L2 协商, 安全停}；O 上升只**减少**可接受位姿集、降低力帽，不会增加探针下界；影子微调/UX 升级沿用第 58 轮非阻塞语义。

**部署界（对检查点取联合界）**：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + ε_attr + δ_probe + δ_pose + ε_h
                   + δ_ood·α_conf + δ_xm·1[L1] + δ_ft·1[回滚窗口]
                   + δ_kg·1[检索失败] + δ_ux·1[μ_mis>θ_mis]
                   + δ_sg·1[D_sg>θ_sg]·1[未触发探针])
         − P(位姿图册遗漏真实接触模式) − P(护盾回退失败) − P(τ_int 超时 ∧ 安全停失效)
```

关键：**开放词汇做「想象力」**（只进假设层、只提候选位姿、只加宽风险）；**末端位姿做「裁决」**（证书绑承诺位姿、传递界显式、无证书不外推）；**开放-保守对偶做「税」**（语义越开放，位姿集/力帽/预算越收紧，使安全界与词表大小解耦）。

## 6. 本轮最大风险

**一句话**：开放-保守对偶只在「保守旋钮真的有效」且「位姿图册覆盖真实接触模式」时成立——若 OVAG 系统性漏掉某类接触模式（例如从不提出「边缘/悬挑/铰接」假设），系统会在错误的模式上**自信地收窄**位姿集，并以「更保守」的假象通过审计；此时风险从第 58 轮的「坏先验普遍」变成「自信地窄且错」，而被漏掉的模式因为从未被提案就永远不会被探、也永远不会被证伪。必须以「接触模式覆盖契约 δ_cov + 与语义无关的探索配额 + unknown-unknown 位姿集 + 位姿图册覆盖率审计」四重护栏，宁可保留一块语义上说不清、但几何上被随机探针覆盖的位姿，绝不把提案支撑当成真实世界的支撑。
