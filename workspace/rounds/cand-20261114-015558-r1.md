# 第 71 轮（承接第 70 轮「TEMPO-RAS 时间预算化认知运动闭环」IP-264~274；灵感循环新循环第 4 轮；本轮灵感：「低延迟推理」×「云端协同」）

> R70 把「思考」第一次放进了时间的账本：给认知层一份 deadline slack，用 anytime 采样、物理可行性剪枝、期限感知调度和硬实时内环兜底，避免了「在最该少想的时候想太多」。但它仍默认一个更深的假设——**算力就在本机、可信、且其最坏执行时间可离线测准**；网络是一个不存在的变量，云端是一个更快的本地，低延迟只是一个工程优化。
>
> 本轮两个灵感正好拆掉这个假设：
> - **低延迟推理**告诉我们：速度不是免费的。量化、蒸馏、早退、缓存、投机执行、算子融合，每一种「更快」都是对策略分布的一次近似；**不把近似误差记进不确定性，它就会以「自信地算错」的形式回来**。而且真正致命的是尾延迟，不是平均延迟。
> - **云端协同**告诉我们：云端不是更快的本地，而是**另一个世界线**——它在你发送快照的那一刻与你分叉，用可能不同的模型/地图版本、在别人的负载与信任域里计算；它给你算力与独立视角，也索取隐私、带宽、可用性与一致性。
>
> 核心命题：**把 R70 的「时间预算」升级为「跨计算层的延迟-信任账本」；把「低延迟」从工程旋钮变成必须入账的第三种不确定性 U_apr（计算不确定性）；把「云端协同」从算力搬运变成「在正确的时间地平线上，以最小充分表征，向正确的信任域购买经过本地对账的精化」**。命名 **LATTICE-RAS**（Latency-Aware Tiered Trust & Inference Coordination for Edge-cloud）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「测量还准吗」，R69 问「该向谁求证」，R70 问「还来得及吗」，R71 问「**这件事该在哪台机器上、以多大近似、向谁买、又该在哪个世界线里提交**」——延迟不是免费的加速，云端不是免费的真相。

## 0. 直觉与动机

**灵感 1（低延迟推理 → 速度是借来的，利息是近似误差）**
直觉：R70 用固定步长、量化网络来换 WCET 确定性，这已经是低延迟推理的雏形，但它把速度当成一个标量：算得快 = 好。真实的加速不是免费的：量化位宽、早退阈值、蒸馏、`N_step`、缓存命中，每一种都在把策略从参考分布 `p_∞` 推向近似分布 `p_κ`。R70 的 `λ` 只对 `U_ale/U_epi` 收费，从不对 `p_κ` 与 `p_∞` 的差收费。于是系统可能用一个 4-bit、1-step 的策略在 deadline 内给出一个「确定」的动作，却不知道这份确定性是近似的产物。速度借的是精度，利息必须在 `λ` 里偿还。

**灵感 2（尾延迟 → 平均值是安全叙事里的谎言）**
直觉：R70 的 WCET 是单机、离线、p99 的。云端/边缘的端到端延迟是 `L_comp + L_queue + L_net + L_sync + L_verify`：排队是多租户的、网络是抖动的、冷启动是重尾的。用均值准入会让系统在最需要确定性的时刻被尾部事件击穿——均值可以低于 deadline，而 miss 概率仍然很高。正确对象是尾分位数 `q_k(ε)` 与「剩余 slack」，不是「平均预算」。低延迟推理的第一原则：**先保证 p999 不越过 use-by，再谈平均快多少**。

**灵感 3（云端协同 → 云端不是更快的本地，而是另一条世界线）**
直觉：R70 默认所有计算都发生在当前观测 `o_t` 上。云端协同打破这一点：你发送的是 `t−δ` 的快照，云端用可能不同的模型/地图版本算出 `ξ_R`，返回时本地世界线已经走到 `t`。`ξ_R` 不是「更精确的当前动作」，而是「另一条世界线上的反事实动作」。直接执行它，等于把一个来自过去/异版本的决策插进当前控制回路。因此必须有世界线对账：版本距离、快照年龄、前向预测一致性、安全集投影；对不上就丢弃。云端协同的核心不是搬运算力，而是**时间旅行后的证据是否仍然成立**。

**灵感 4（云端协同 → 算力与隐私/信任的兑换，而非免费扩容）**
直觉：把原始观测发出去会泄露隐私，把模型查询发出去会泄露意图/位置，返回结果可能被替换、重放、缓存投毒。因此「卸载什么」与「卸载到哪」同样重要。最小充分表征（minimal sufficient representation）给出一个原则：只发送对目标任务统计量充分的最少信息——能发特征就不发像素，能发查询就不发场景。低延迟的收益必须扣除隐私与完整性成本；否则系统是在用不可审计的方式购买速度。

**灵感 5（独立性幻觉 → 多一个云不等于多一个真相）**
直觉：R69/R70 用 k 个正交证据源降低 epistemic 风险，并默认「多一个来源 = 多一份独立」。云端第二意见听起来天然独立，但如果它和本地模型同源（同训练数据、同架构、同标注偏差），它的错误与本地高度相关：`ρ_model→1` 时有效独立源数趋于 1，后验方差不会继续下降。**多一个云不等于多一个真相**。因此必须区分两种上云动机：为了算力（capability offload）与为了独立性（diversity offload）；后者在模型同源时是净亏损——付了隐私与延迟，却没买到信息。

**灵感 6（低延迟的捷径 → 缓存是过去世界线的承诺，也是投毒入口）**
直觉：低延迟的另一条捷径是缓存：边缘缓存其他机器人/其他时刻的结果，命中即省一次推理。但缓存是「过去世界线的承诺」：世界变了、地图版本变了、查询主体变了，命中就是陈旧；缓存被对手写入，命中就是投毒。缓存必须带 provenance、版本、TTL、跨主体去标识，并在取出时做世界线对账。**缓存让系统更快地复用过去，也让系统更快地重复过去的错误**。

## 1. 形式化定义（增量：定义 325–339）

**假设**
- **A105（延迟可测但非平稳）**：每层在滑动窗口内的端到端延迟分布可估；尾分位数可用在线 conformal/极值理论重标定，非平稳性有界（否则保守回退）。
- **A106（近似前沿单调）**：对每个加速旋钮 `κ`（位宽、步数、早退阈值、模型规模），存在可标定的延迟-精度前沿；`U_apr(κ)` 可在探针集上估计。
- **A107（验证器有界不可靠）**：本地验证器对远程结果有有界误接受 `δ_fa` 与误拒绝 `δ_fr`；provenance 检查可独立降低替换/重放风险，但不能证明语义正确。
- **A108（信任域非同质）**：不同层有不同完整性/机密性画像；模型之间可能高度相关；没有一层可被无条件信任。
- **A109（世界线可对账）**：本地可把一个来自快照 `o_{t−δ}` 的远程计划前向传播到当前时刻，并给出有界误差；误差过大时必须可拒绝。
- **A110（本地兜底可调度）**：R70 的硬实时本地路径与 M5 兜底独立于网络，任何云端/边缘结果都只是可选精化，不得阻塞内环。

**定义 325（LATTICE-RAS 总览）** LATTICE-RAS = (LTC, TAP, SVR, WRC, TGR, UAP, PAC, RAS-WM¶)。五条不变式：
(i) **实时流零学习写操作**（继承 R70 定义 310-i）；
(ii) **尾延迟准入**：任何层/结果被使用前，其 `(1−ε)` 尾延迟加兜底 WCET 与抖动必须塞进剩余 slack；网络永不进入硬实时内环；
(iii) **世界线提交纪律**：远程/边缘/缓存结果必须通过 provenance、版本与时间对账才可提交，否则视同不存在；
(iv) **保管最小化**：只卸载对目标统计量充分的最小表征；原始数据卸载需显式授权并计入隐私预算；
(v) **安全单调退化**：网络故障、验证失败、超时、投毒只删除精化，不得把安全侧降到 R70 本地路径之下；恢复需滞回。

**定义 326（分层延迟契约 LTC）** 对层 `k ∈ {local, edge, cloud}`：
`L_k(b) = L_comp,k(b) + L_queue,k + L_net,k + L_sync,k + L_verify,k`，
尾分位 `q_k(ε) = inf{ℓ : P(L_k ≤ ℓ) ≥ 1−ε}`。
准入集 `K_adm(σ_t) = {k : q_k(ε) + WCET_fb + J_p99 ≤ σ_t}`。
对跨周期任务，定义到 `use_by(g)` 的剩余松弛 `σ_g = use_by(g) − now − WCET_fb − J_p99`，只用 `q_k(ε) ≤ σ_g` 的层。准入必须用分位数；均值准入不充分（引理 24）。

**定义 327（计算不确定性 U_apr）** 设参考策略 `p_∞(ξ|o)`、加速策略 `p_κ(ξ|o)`，定义
`U_apr(κ) = D_f(p_κ(·|o) ‖ p_∞(·|o))`，
其中 `D_f` 是经标定的决策散度（KL 用于理论界，risk-equivalent divergence 用于工程）。`U_apr` 的特征是：**只能靠更多计算降低，不能靠更多数据或更多交互降低**。它必须经 `ρ_apr` 映射为风险量 `U_comp = ρ_apr(U_apr)` 后进入 `λ`（定义 338）。

**定义 328（延迟-精度前沿）** 加速旋钮 `κ = (bits, N_step, exit_thr, model_size, cache_policy)`；每层给出一条单调前沿
`F_k = {(L, U_apr) : L = L_k(κ), U_apr = U_apr(κ)}`。
选 `κ` 不是「默认最快」，而是在 `q_k(ε) ≤ σ_g` 下最小化 `U_apr + 超时风险` 的约束优化。R70 的固定 `N_step` 只是这条前沿上的一个点。

**定义 329（时间地平线分层）** 三类任务：
`H_hard`：`τ ≤ T_e`，本地执行，硬期限，永不等待网络；
`H_soft`：`T_e < τ ≤ T_s`，边缘执行，结果只能在下一个 use-by 前提交；
`H_plan`：`τ > T_s`，云端执行，只影响规划/语言接地等慢变量。
每个任务带 `use_by(g)` 与 `horizon(g)`；跨地平线提交仅当结果仍在其有效期内。云端**永远不进入 H_hard**——这不是性能选择，而是物理约束（光速与排队）。

**定义 330（计算放置 TAP）** 一个计划是带层/旋钮/起始时刻标注的计算 DAG
`π = (V, E, tier: V→K, κ: V→𝒦, t_start: V→ℝ)`。
价值 `ΔR(π)` 同时包含「消解 `U_epi`」与「降低 `U_apr`」；成本包含尾延迟、能量、隐私泄漏与完整性暴露：
`π* = argmax_π [ ΔR(π) − λ_lat·q(L_π) − λ_priv·Leak(π) − λ_int·Exp(π) ]`
s.t. `q(L_π) ≤ σ_g` 且 DAG 先后约束成立。
阶段数 ≤6、层数 ≤3 时用 DP/价值密度背包求解；渐进精化的停时条件是边际风险下降 / 边际尾延迟 > `λ_lat`，且永不超过 commit 时刻。

**定义 331（投机验证精化 SVR）** 本地在硬期限内产出草案 `ξ_L`；同时对快照发起远程/边缘精化 `ξ_R`，二者并行。提交时刻 `τ_c`：
`commit = ξ_R` 若 `ξ_R` 已到达 ∧ `ProvValid(ξ_R)` ∧ `Ver(ξ_R, ξ_L, ℰ)=1`；否则 `commit = ξ_L`。
远程结果**永不阻塞**。验证器可接受「与本地一致且证据支持」或「不一致但给出可被独立证据验证的解释」；仅凭远程自报不得定案（继承 R69 证据纪律）。

**定义 332（世界线对账与提交 WRC）** 设远程结果基于 `o_{t−δ}` 与版本 `v_R`，本地为 `o_t`、版本 `v_L`、预测状态 `x̂_t`。提交需同时满足：
`dist(v_R, v_L) ≤ η_v`，`δ ≤ TTL_eff(dynamics)`，
`dist(Proj_R(x_R, δ), x̂_t) ≤ η_recon`，且 `Proj_R(x_R, δ) ∈ 𝒮`（安全集）。
任一条失败 ⇒ 丢弃并记录；不得把来自错误世界线的动作「平均」进当前动作。

**定义 333（溯源与版本纪元）** 每个结果携带
`prov = (model_id, model_hash, map_epoch, sensor_epoch, timestamp, nonce, signature, parent_hash)`。
`ProvValid` 要求签名有效、版本落在兼容窗口、nonce 未在重放窗口出现、父链完整。缓存命中同样需要 `prov`；这是反替换、反重放、反缓存投毒的底座。

**定义 334（信任域门控与最小充分表征 TGR）** 层 `k` 有画像 `(I_k, C_k)`（完整性/机密性）。对表征 `r = φ(o)` 与远程阶段所需统计量 `S`：
`r* = argmin_r Leak(r)` s.t. `I(r; S) ≥ (1−η)·I(o; S)` 且 `r` 在该层可处理。
`Leak(r)` 可用敏感属性互信息或差分隐私 `ε_DP` 度量；`Exp(r)` 度量模型抽取/完整性暴露。原始数据卸载需授权。请求时序本身也是侧信道：`Leak_time` 计入总泄漏。

**定义 335（独立性度量与有效冗余）** 设本地与远端模型在探针集上的预测相关为 `ρ_model ∈ [0,1]`。`k` 个等方差、两两相关 `ρ_model` 的估计，其均值方差为 `σ²[ρ_model + (1−ρ_model)/k]`，有效独立源数
`k_eff = k / [1 + (k−1)ρ_model]`。
`ρ_model→1 ⇒ k_eff→1`：同源第二意见不降低 epistemic 风险。区分：
- **capability offload**：需要额外算力，任何可信层都可；
- **diversity offload**：需要独立视角，只有异质模型/异质数据/异质信任域才有价值。
若 `ΔR_diversity ≤ λ_priv·Leak`，不因「多样性」上云。

**定义 336（溯源缓存 PAC）** 缓存键 `key = H(query, context_fp, model_version, map_epoch)`。命中可被采用当且仅当
`ProvValid ∧ age ≤ TTL ∧ version 兼容 ∧ (共享缓存 ⇒ k-匿名/DP) ∧ 取出时通过 WRC`。
命中是对过去世界线的下注；未通过溯源与对账的命中视同 miss。

**定义 337（网络/边缘故障与对手模型）** `ℰ_net = ℰ_delay × ℰ_loss × ℰ_reorder × ℰ_replay × ℰ_substitute × ℰ_cache_poison × ℰ_split_brain × ℰ_congestion_dos`。
并入 AIC：`ℰ_LATTICE = ℰ_TEMPO × ℰ_net`。其中 `ℰ_congestion_dos` 是通过抬高共享边缘负载把你的尾延迟推过 deadline（多租户攻击）；`ℰ_split_brain` 是分区/版本漂移导致各层给出互斥结论，禁止用平均掩盖。

**定义 338（计算不确定性感知的风险缩放）** 令 `U_comp = ρ_apr(U_apr(κ))`，
`λ = max( M.efs.risk_scale(...), λ_floor(U_ale + U_epi_unresolved), λ_comp(U_comp) )`。
性质：计算预算下降 ⇒ `κ` 更激进 ⇒ `U_apr` 不降 ⇒ `λ` 不降。**加速只能买到更早，不能买到更安全**；只有 `U_apr` 与 ECE 都在预算内时，才保留 R69 的 resolution bonus。

**定义 339（证书与退化阶梯）**
`J_LATTICE = (J_TEMPO, q_k(ε), p999_e2e, offload_ratio, apr_ece, recon_reject_rate, prov_fail_count, privacy_leak, net_faults, cache_hit_age, lattice_ver)`。
`Valid ⇔ Valid(J_TEMPO) ∧ 尾准入 ∧ 提交均 provenance/对账通过 ∧ 隐私预算未越界 ∧ U_apr ≤ U_apr_max`。
退化阶梯：`M0` 云端精化 → `M1` 边缘精化 → `M2` R70 本地完整 → `M3` 本地近似（量化/早退）→ `M4` R69 保守 → `M5` R70 内环安全停/保持。只降不升；恢复带滞回与 provenance 校验。

## 2. 关键算法骨架

```python
# IP-275 LTC：尾部延迟准入（拒绝均值叙事）
def tail_admit(tier, slack, eps=1e-3):
    q = tier.latency_quantile(eps)        # comp + queue + net + sync + verify
    return q + WCET_FB + J_P99 <= slack

# IP-276 TAP：跨层放置（≤3 层、≤6 阶段；小规模 DP / 价值密度）
def place(stages, tiers, slack, privacy_budget):
    best = None
    for pi in enumerate_plans(stages, tiers):              # 枚举可行 DAG
        if not deadline_ok(pi, slack):           continue
        if privacy_leak(pi) > privacy_budget:    continue
        val = risk_reduction(pi) - L_LAT * latency(pi) - L_PRI * privacy_leak(pi)
        if best is None or val > best.val: best = (pi, val)
    return best.pi if best and best.val > 0 else LOCAL_ONLY

# IP-277 UAP：把近似误差折算成风险
def approximation_risk(kappa):
    u = divergence_from_reference(kappa)      # 量化/早退/蒸馏/N_step
    return rho_apr(u)                         # 与 lambda 同单位

# IP-278 SVR：本地草案 + 投机远程精化，到期只提交本地
def speculative_commit(xi_local, remote_future, commit_time, evidence):
    if remote_future is None or not remote_future.ready(commit_time):
        return xi_local
    if not remote_future.provenance_ok():
        return xi_local
    if verify(remote_future.xi, xi_local, evidence):
        return remote_future.xi               # 采用精化
    return xi_local                           # 永不阻塞

# IP-279 WRC：世界线对账（版本 / 年龄 / 前向预测 / 安全集）
def worldline_ok(remote, local, delta):
    if version_distance(remote.ver, local.ver) > ETA_V:       return False
    if delta > TTL_eff(local.dynamics):                       return False
    if dist(forward(remote.xi, delta), local.x_hat) > ETA_R:  return False
    return project_in_safety(remote.xi, delta)

# IP-280 TGR：最小充分表征 + 信任域门控
def route_payload(o, stage, tier, privacy_budget):
    r = minimal_sufficient(o, stage.statistic)   # 特征 / 查询，而非原始像素
    if leak(r, tier) > privacy_budget:           return None
    return r if tier.integrity_ok(stage) else None

# IP-281 PAC：缓存命中也要过溯源与对账
def cache_get(key, local_state, ttl):
    e = cache.lookup(key)
    if e is None or not e.provenance_ok():       return None
    if e.age > ttl:                              return None
    if not worldline_ok(e, local_state, e.age):  return None
    return e

# IP-285 主闭环（继承 R70）
def LATTICE_RAS_round(M, obs):
    ts = M.clock.tick()
    z, o = M.mtm.forward(...)
    c, U_cal, _ = M.cof.step(...)
    slack = deadline_slack(ts, WCET_FB, J_P99)
    if M.watchdog.tripped() or slack <= 0:
        return M.mrc.exec_level(M5, o, z)                  # 网络/超时 → 本地兜底
    # 1) 本地草案：R70 anytime 采样，受 slack 约束
    K = min(max_k_within_budget(slack, M.afs.step_wcet),
            1 if M.fmp.mode_head(z) < TAU_MODE else MAX_K)
    xi_L, rho = M.afs.sample(o, budget_for(K, slack), ts.deadline)
    modes, w = M.aud.decompose(xi_L)
    modes_f, phantom = M.dft.trim(modes, o)
    # 2) 计算不确定性：近似越狠，lambda 越高（速度不是免费的）
    u_comp = M.uap.risk(M.current_kappa)
    # 3) 是否需要/能否向边缘或云端买精化（异步、永不阻塞）
    plan = M.tap.place(M.stages(o), M.tiers, slack, M.privacy_budget)
    remote_fut = None
    if plan != LOCAL_ONLY:
        r = M.tgr.route(o, plan.stage, plan.tier, M.privacy_budget)
        if r is not None:
            remote_fut = M.tiers[plan.tier].submit_async(r, o, ts, plan)
    # 4) 本地继续推进；到期只提交本地草案
    g = M.tav.choose(modes_f, w, o, slack, M.tcb.age()) if modes_f else None
    if g is not None and not M.das.can_afford(g, slack):
        g = None
    if g is not None:
        w = M.cia.update_belief(w, M.met.execute(g))
    # 5) 远程若在 commit 前返回：验证 + 世界线对账 + 提交
    if remote_fut is not None and remote_fut.ready(ts.commit):
        if M.wrc.worldline_ok(remote_fut, M.local_state(), remote_fut.delta) \
           and M.svr.verify(remote_fut.xi, xi_L, M.evidence):
            xi_final, w = M.svr.merge(remote_fut, xi_L, w)
        else:
            xi_final = xi_L
    else:
        xi_final = xi_L
    U_ale, U_epi = M.aud.split(modes_f, w, M.tcb.age())
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor), lam_comp(u_comp))
    A = M.ach.propose(...); k = M.c_ras_wm_p.certified_prefix(A, ...)
    if M.tav.authority_loss(ts.elapsed) > TAU_AUTH:
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, U_cal))
    ref = M.pi_sigma.prefix_dispatch(xi_final, k, lam)
    cmd = M.mrc.inner_contract(ref, o, ts)                 # CBF/无源性，永不阻塞
    M.audit.submit_async(plan, remote_fut, U_epi, u_comp, rho, M.privacy_budget)
    return M.mrc.exec(cmd, M.level)
```

## 3. 推导

**引理 24（均值准入的尾部破产）** 设某层延迟 `L ∈ [0,T]`，均值 `E[L] ≤ D < T`。取两点分布 `P(L=T)=p, P(L=0)=1−p`，则 `E[L]=pT ≤ D ⇒ p ≤ D/T`。均值准入允许 miss 概率 `p` 高达 `D/T`；若 `D/T ≫ ε`，`P(L>D)=p` 远大于目标 `ε`。一般地 Markov 只给出 `P(L>D) ≤ E[L]/D`，该界可任意接近 1。反之尾准入 `q(ε) ≤ D` 直接保证 `P(L>D) ≤ ε`。故 LTC 必须以分位数为准，且 `ε` 应由安全证书给定，而非工程拍脑袋。系：多租户排队与冷启动让重尾更重，均值准入在共享边缘上尤其危险。

**引理 25（近似误差的风险传播）** 若 `D_KL(p_κ‖p_∞) ≤ U_apr`，由 Pinsker 有 `TV(p_κ,p_∞) ≤ √(U_apr/2)`。若风险泛函 `R` 对动作分布是 `L_R`-Lipschitz，则
`|R(p_κ) − R(p_∞)| ≤ L_R·√(U_apr/2)`。
因此忽略 `U_apr` 会使证书风险界失效：真实风险可比声称值高一个与 `√U_apr` 同阶的项。推论（速度-风险单调）：计算预算下降 ⇒ `κ` 更激进 ⇒ `U_apr` 不降 ⇒ `λ` 不降。低延迟只能买到「更早」，不能买到「更安全」；为赶 deadline 而加速时，必须把「近似风险」与「超时风险」放进同一个风险泛函比较，二者都不能隐形。

**引理 26（投机提交的风险上界与优于阻塞）** 设本地草案在 deadline 前总可用（A110），远程结果只在到达且通过验证时提交。则 SVR 的 miss 概率 ≤ 本地基线；风险
`R_SVR ≤ R_local + δ_fa·ΔR_max`，
其中 `δ_fa` 为验证器接受「比本地更差且有害」的远程结果的概率，`ΔR_max` 为单次最坏风险差。若 `δ_fa=0` 且远程不劣，则 `R_SVR ≤ R_local`。阻塞式卸载在尾部事件下要么 miss、要么无动作，风险 ≥ 本地基线 + miss 惩罚；故在本地草案可用且 `δ_fa` 足够小时，SVR 弱支配阻塞式卸载。

**引理 27（同源冗余的 epistemic 极限）** 设 `k` 个等方差 `σ²`、两两相关 `ρ_model` 的估计，其均值方差为 `σ²[ρ_model + (1−ρ_model)/k]`，有效独立源数 `k_eff = k/[1+(k−1)ρ_model]`。当 `ρ_model→1` 时 `k_eff→1`，第二意见的方差下降趋于 0；相对增益 `∝ (1−ρ_model)(1−1/k)`。故云端第二意见的 epistemic 价值由模型异质性决定，而不是由「云端」这个标签决定。系：「为了第二意见上云」在模型同源时是净亏损：付出延迟与隐私，换来 `k_eff≈1`。

**定理 20（LATTICE 严格包含 TEMPO/R70）** 在单层、零网络、零近似（`U_apr=0`）、无缓存、无限信任的边界下，TAP 只选本地，UAP 为 0，SVR 退化为本地草案，WRC/TGR/PAC 恒真，`λ` 与 R70 相同，动作分布逐指令一致。一般情形下，本地 R70 路径始终可调度（A110），所有远程/边缘/缓存结果必须经 SVR + WRC + ProvValid 才能提交；因此可行动作集包含 R70 的保守动作集。验证器可靠时风险 ≤ R70 + `δ_fa·ΔR_max`；验证失败/网络故障时退化为 R70。安全侧不弱于 R70（在 `δ_fa` 有界前提下），效率侧仅在尾准入与净价值为正时获得精化。

**定理 21（延迟-隐私-精度三元约束）** 在 A105–A109 与一个抽象信道下，设把 `U_apr` 降到 `u` 需要 `B_req(u)` 比特远端信息；隐私约束 `p` 允许的信道容量为 `C_priv(p)`，期限 `d` 允许送达的比特为 `C_lat(d)`。则可行三元组必须满足
`B_req(u) ≤ min(C_priv(p), C_lat(d))`。
三个目标都单调：`u↓` 需 `B_req↑`；`p↓` 使 `C_priv↓`；`d↓` 使 `C_lat↓`。故三者不能同时取最小值：改善任一维必须以另一维为代价。特别地，若本地计算在 `d` 内无法达到 `u`（`B_req(u)>0`），则必须放宽 `p` 或 `d`，或接受更大的 `u`。**云端协同不是消除三元约束，而是让你选择在哪一维妥协。**

**定理 22（网络故障下的安全单调）** 若所有远程/边缘/缓存结果都经 SVR 验证、WRC 对账、ProvValid 溯源，且本地 R70 路径可调度（A110），则网络延迟、丢包、重放、替换、缓存投毒、分区/脑裂只能导致精化被拒绝，不能直接进入控制回路。因此
`P(违反) ≤ ε_local + δ_fa + δ_recon`，
与网络故障强度无关；故障只降低性能与可用性。退化阶梯只降不升，恢复需滞回与 provenance，故无突变。系：缓存投毒不能直接造成违规，但若验证器与投毒源共享盲点，仍可通过 `δ_fa` 进入——这正是本轮最大风险。

## 6. 本轮最大风险

**一句话**：LATTICE-RAS 把 R70 的「本地时间模型可信」换成了「**远程结果可被本地验证**」这条更弱的假设——一旦验证器与远程模型共享盲点（同源模型、同源数据、被投毒的缓存、或精心构造的替换结果），低延迟就会变成低可信的加速器：系统会以更快的速度、更自信地执行一个来自错误世界线的决定，而 **`δ_fa` 恰恰是所有延迟优化都不会自动降低的那一项**。

**次级风险与缓解**：
1. **尾延迟估计失真**（非平稳、冷启动、拥塞）→ 在线 conformal + 保守分位 + 超时即回退 M2/M5（定义 326、E316/E327）；
2. **U_apr 标定错误**（近似前沿不单调、越界输入）→ 经验风险曲线 + 保守上界 + 越界禁用激进旋钮（定义 327/328、E317）；
3. **验证器相关盲点**（同源模型/同源数据）→ 信任域独立性度量 `k_eff` + 异质验证源 + 外部证据（定义 335、E323）；
4. **缓存投毒/陈旧复用**→ provenance + TTL + WRC + 共享缓存去标识（定义 333/336、E321/E329）；
5. **隐私/时序侧信道**（表征、请求时序、查询模式）→ 最小充分表征 + DP 预算 + 时序混淆（定义 334、E320）；
6. **多租户拥塞攻击**（抬高共享边缘尾延迟）→ 尾隔离/SLO + 预算化卸载 + compute-DoS 检测（定义 337、E330）。

| `k_eff = k/[1+(k−1)ρ_model]` | 有效独立证据源数 |

## 2. 形式化定义（要点版）

**定义 325（总览与五不变式）** LATTICE-RAS 由 LTC/TAP/SVR/WRC/TGR/UAP/PAC/RAS-WM¶ 组成；零学习写操作继承；尾延迟准入（网络永不进硬内环）；世界线提交纪律（provenance+版本+对账，否则视同不存在）；保管最小化（最小充分表征，原始数据需授权）；网络/验证/超时故障只删精化，安全侧不低于 R70 本地路径。

**定义 326（LTC）** `L_k(b)=L_comp,k(b)+L_queue,k+L_net,k+L_sync,k+L_verify,k`，`q_k(ε)` 为尾分位；准入 `q_k(ε)+WCET_fb+J_p99≤σ_t`。均值准入不充分（引理 24）；`ε` 由安全证书给定。

**定义 327–328（U_apr 与前沿）** `U_apr(κ)=D_f(p_κ‖p_∞)`，只能靠更多计算降低，不能靠数据/交互降低；经 `ρ_apr` 映射为风险 `U_comp`。每个旋钮 `κ=(bits,N_step,exit_thr,model_size,cache_policy)` 在每层给出一条单调延迟-精度前沿；选点是约束优化，不是默认最快。

**定义 329（时间地平线）** `H_hard` 本地硬期限；`H_soft` 边缘、结果只在下一 use-by 前提交；`H_plan` 云端、只影响规划/语言接地。每个任务带 `use_by(g)` 与 `horizon(g)`；**云端永不进入 H_hard**。

**定义 330（TAP）** 计算 DAG `π=(V,E,tier,κ,t_start)`；`π*=argmax[ΔR−λ_lat q(L_π)−λ_priv Leak−λ_int Exp]` s.t. `q(L_π)≤σ_g` 与 DAG 约束。渐进精化停时：边际风险下降/边际尾延迟 > `λ_lat`，且不越过 commit。

**定义 331（SVR）** 本地草案 `ξ_L` 硬期限可用；并行请求 `ξ_R`；提交时 `commit=ξ_R` 当且仅当到达 ∧ `ProvValid` ∧ `Ver(ξ_R,ξ_L,ℰ)=1`，否则 `ξ_L`。远程永不阻塞；仅凭远程自报不得定案（继承 R69 证据纪律）。

**定义 332（WRC）** 远程基于 `o_{t−δ}`/版本 `v_R`；提交需 `dist(v_R,v_L)≤η_v`、`δ≤TTL_eff`、`dist(Proj_R(x_R,δ),x̂_t)≤η_recon`、`Proj_R(x_R,δ)∈𝒮`。任一失败即丢弃；不得把异世界线动作平均进当前动作。

**定义 333（溯源）** `prov=(model_id,model_hash,map_epoch,sensor_epoch,timestamp,nonce,signature,parent_hash)`；`ProvValid` 要求签名有效、版本兼容、nonce 未重放、父链完整。缓存命中同样需要 prov。

**定义 334（TGR）** `r*=argmin_r Leak(r)` s.t. `I(r;S)≥(1−η)I(o;S)` 且该层可处理；`Leak` 用敏感属性互信息或 DP `ε_DP`；请求时序亦计入 `Leak_time`。原始数据卸载需显式授权。

**定义 335（独立性）** 两两相关 `ρ_model` 的 k 源，`k_eff=k/[1+(k−1)ρ_model]`；`ρ_model→1 ⇒ k_eff→1`。**capability offload**（要算力）与 **diversity offload**（要独立视角）必须分开；同源第二意见是净亏损。

**定义 336（PAC）** `key=H(query,context_fp,model_version,map_epoch)`；命中采用条件：`ProvValid ∧ age≤TTL ∧ version 兼容 ∧ (共享⇒k-匿名/DP) ∧ WRC 通过`。命中是对过去世界线的下注。

**定义 337–339（故障/风险缩放/证书）** `ℰ_net` 含 delay/loss/reorder/replay/substitute/cache-poison/split-brain/congestion-DoS，并入 `ℰ_LATTICE=ℰ_TEMPO×ℰ_net`。`λ=max(efs, λ_floor(U_ale+U_epi_unresolved), λ_comp(U_comp))`；计算预算↓⇒`λ`不降——**加速只买更早，不买更安全**。`J_LATTICE=(J_TEMPO,q_k(ε),p999_e2e,offload_ratio,apr_ece,recon_reject,prov_fail,privacy_leak,net_faults,cache_hit_age,ver)`；退化阶梯 M0–M5 只降不升。

```python
# IP-275 LTC：尾部延迟准入
def tail_admit(tier, slack, eps=1e-3):
    return tier.latency_quantile(eps) + WCET_FB + J_P99 <= slack

# IP-276 TAP：跨层放置（≤3 层、≤6 阶段）
def place(stages, tiers, slack, privacy_budget):
    best = None
    for pi in enumerate_plans(stages, tiers):
        if not deadline_ok(pi, slack) or privacy_leak(pi) > privacy_budget:
            continue
        val = risk_reduction(pi) - L_LAT*latency(pi) - L_PRI*privacy_leak(pi)
        if best is None or val > best.val: best = (pi, val)
    return best.pi if best and best.val > 0 else LOCAL_ONLY

# IP-277 UAP：近似误差 → 风险
def approximation_risk(kappa):
    return rho_apr(divergence_from_reference(kappa))

# IP-278 SVR：本地草案 + 投机远程精化
def speculative_commit(xi_local, remote_future, commit_time, evidence):
    if remote_future is None or not remote_future.ready(commit_time):
        return xi_local
    if not remote_future.provenance_ok():
        return xi_local
    return remote_future.xi if verify(remote_future.xi, xi_local, evidence) else xi_local

# IP-279 WRC：世界线对账
def worldline_ok(remote, local, delta):
    if version_distance(remote.ver, local.ver) > ETA_V:      return False
    if delta > TTL_eff(local.dynamics):                      return False
    if dist(forward(remote.xi, delta), local.x_hat) > ETA_R: return False
    return project_in_safety(remote.xi, delta)

# IP-280 TGR：最小充分表征路由
def route_payload(o, stage, tier, privacy_budget):
    r = minimal_sufficient(o, stage.statistic)     # 特征/查询，非原始像素
    if leak(r, tier) > privacy_budget:            return None
    return r if tier.integrity_ok(stage) else None

# IP-281 PAC：缓存命中也要过溯源 + 对账
def cache_get(key, local_state, ttl):
    e = cache.lookup(key)
    if e is None or not e.provenance_ok() or e.age > ttl:
        return None
    return e if worldline_ok(e, local_state, e.age) else None

# IP-285 主闭环（继承 R70）
def LATTICE_RAS_round(M, obs):
    ts = M.clock.tick(); z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    slack = deadline_slack(ts, WCET_FB, J_P99)
    if M.watchdog.tripped() or slack <= 0:
        return M.mrc.exec_level(M5, o, z)                    # 网络/超时 → 兜底
    K = min(max_k_within_budget(slack, M.afs.step_wcet),
            1 if M.fmp.mode_head(z) < TAU_MODE else MAX_K)
    xi_L, rho = M.afs.sample(o, budget_for(K, slack), ts.deadline)
    modes, w = M.aud.decompose(xi_L); modes_f, _ = M.dft.trim(modes, o)
    u_comp = M.uap.risk(M.current_kappa)                     # 近似入账
    plan = M.tap.place(M.stages(o), M.tiers, slack, M.privacy_budget)
    remote_fut = None
    if plan != LOCAL_ONLY:
        r = M.tgr.route(o, plan.stage, plan.tier, M.privacy_budget)
        if r is not None:
            remote_fut = M.tiers[plan.tier].submit_async(r, o, ts, plan)
    g = M.tav.choose(modes_f, w, o, slack, M.tcb.age()) if modes_f else None
    if g is not None and not M.das.can_afford(g, slack): g = None
    if g is not None: w = M.cia.update_belief(w, M.met.execute(g))
    xi_final = xi_L
    if remote_fut is not None and remote_fut.ready(ts.commit):
        if M.wrc.worldline_ok(remote_fut, M.local_state(), remote_fut.delta) \
           and M.svr.verify(remote_fut.xi, xi_L, M.evidence):
            xi_final, w = M.svr.merge(remote_fut, xi_L, w)
    U_ale, U_epi = M.aud.split(modes_f, w, M.tcb.age())
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor), lam_comp(u_comp))
    A = M.ach.propose(...); k = M.c_ras_wm_p.certified_prefix(A, ...)
    if M.tav.authority_loss(ts.elapsed) > TAU_AUTH:
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, U_cal))
    ref = M.pi_sigma.prefix_dispatch(xi_final, k, lam)
    cmd = M.mrc.inner_contract(ref, o, ts)                   # CBF，永不阻塞
    M.audit.submit_async(plan, remote_fut, U_epi, u_comp, rho, M.privacy_budget)
    return M.mrc.exec(cmd, M.level)
```

## 4. 推导

**引理 24（均值准入的尾部破产）** 两点分布 `P(L=T)=p, P(L=0)=1−p` 下 `E[L]=pT≤D ⇒ p≤D/T`；均值准入允许 miss 概率高达 `D/T`，Markov 只给 `P(L>D)≤E[L]/D`（可接近 1）。尾准入 `q(ε)≤D` 直接保证 `P(L>D)≤ε`。故 LTC 必须用尾分位；多租户排队与冷启动使重尾更重。

**引理 25（近似误差的风险传播）** `D_KL(p_κ‖p_∞)≤U_apr ⇒ TV≤√(U_apr/2)`（Pinsker）。若风险泛函 `L_R`-Lipschitz，则 `|R(p_κ)−R(p_∞)|≤L_R√(U_apr/2)`。忽略 `U_apr` 使证书风险界失效。系（速度-风险单调）：计算预算↓ ⇒ `U_apr`↑ ⇒ `λ`↑；低延迟只买更早，不买更安全。

**引理 26（投机提交优于阻塞）** 本地草案总可用 ⇒ SVR miss ≤ 本地基线；风险 `R_SVR≤R_local+δ_fa·ΔR_max`。`δ_fa=0` 且远程不劣时 `R_SVR≤R_local`。阻塞式卸载在尾部事件下要么 miss、要么无动作，风险 ≥ 本地 + miss 惩罚；故 SVR 弱支配阻塞式卸载。

**引理 27（同源冗余的 epistemic 极限）** k 个等方差、两两相关 `ρ_model` 的均值方差 `σ²[ρ_model+(1−ρ_model)/k]`，`k_eff=k/[1+(k−1)ρ_model]`；`ρ_model→1 ⇒ k_eff→1`，第二意见增益 ∝ `(1−ρ_model)(1−1/k)`。**多一个云不等于多一个真相。**

**定理 20（LATTICE 严格包含 TEMPO/R70）** 单层/零网络/零近似/无缓存/无限信任时逐项退化为 R70，动作分布相同。一般情形本地 R70 路径始终可调度（A110），远程/边缘/缓存结果必须经 SVR+WRC+ProvValid；可行动作集包含 R70 保守集。验证器可靠时风险 ≤ R70+`δ_fa·ΔR_max`；验证失败/网络故障退化为 R70。安全侧不弱于 R70（`δ_fa` 有界前提下），效率侧仅在尾准入与净价值为正时获益。

**定理 21（延迟-隐私-精度三元约束）** 设降 `U_apr` 到 `u` 需 `B_req(u)` 比特，隐私约束 `p` 的容量 `C_priv(p)`，期限 `d` 的可达比特 `C_lat(d)`；可行当且仅当 `B_req(u)≤min(C_priv(p),C_lat(d))`。三者单调相斥：`u↓` 需更多比特，`p↓` 缩小容量，`d↓` 减少可达比特。故云端协同不是消除三元约束，而是选择在哪一维妥协。

**定理 22（网络故障下的安全单调）** 所有跨层结果经 SVR+WRC+ProvValid，且本地 R70 可调度 ⇒ 网络延迟/丢包/重放/替换/缓存投毒/脑裂只能使精化被拒，不能直接进控制回路。`P(违反)≤ε_local+δ_fa+δ_recon`，与故障强度无关；故障只降低性能。退化只降不升、恢复带滞回与 provenance ⇒ 无突变。系：缓存投毒只有借验证器盲点（`δ_fa`）才能进入——即本轮最大风险。

## 7. 本轮最大风险

**一句话**：LATTICE-RAS 把 R70 的「本地时间模型可信」换成了「**远程结果可被本地验证**」这条更弱的假设——一旦验证器与远程模型共享盲点（同源模型、同源数据、被投毒的缓存、或精心构造的替换结果），低延迟就会变成低可信的加速器：系统会以更快的速度、更自信地执行一个来自错误世界线的决定，而 **`δ_fa` 恰恰是所有延迟优化都不会自动降低的那一项**。

**次级风险与缓解**：尾延迟估计失真（非平稳/冷启动/拥塞）→ 在线 conformal + 保守分位 + 回退 M2/M5（E316/E327）；`U_apr` 标定错误 → 经验风险曲线 + 保守上界 + 越界禁用激进旋钮（E317）；验证器相关盲点 → `k_eff` + 异质验证源 + 外部证据（E323）；缓存投毒/陈旧 → provenance + TTL + WRC + 去标识（E321/E329）；隐私/时序侧信道 → 最小充分表征 + DP + 时序混淆（E320）；多租户拥塞攻击 → 尾隔离/SLO + 预算化卸载 + compute-DoS 检测（E330）。

**与 R70 的关系**：R70 的风险是「WCET 可能撒谎」；R71 用尾分位、投机精化与本地兜底把云端排除在硬实时之外，但引入新的单点故障——**验证器**。这是一次诚实的交换：**用「可丢弃的远端精化」替换「不可证的本地全知」，但验证本身也需要被验证。**
