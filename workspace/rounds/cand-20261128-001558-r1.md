## 1. 直觉与动机（两个灵感的碰撞）

**灵感 1（轮足机器人 → 关键不是多两条腿，而是一个「地形切换律」）**
直觉：轮足机器人真正的智能在**切换**——平地放轮（快、省、开环、长时域），烂地抬腿（慢、稳、闭环、短时域），由地形估计 + 滞回 + 能量预算决定何时切。桌面操作完全同构：自由空间搬运 = 轮式（长 chunk、开环、少算力），接触/遮挡/异常 = 腿式（短视界、闭环、多算力）。第 2 轮把 I3（接触伺服）与 I4（干预门控）当并列模块，缺的正是这个**统一的难度地形估计器 + 算力预算调度器**。反直觉点：**稳健不是「每步都慢」，而是「把稀缺算力预算集中投给少数高险段」；全局降速/全局短 chunk 是最差策略。**

**灵感 2（UniBot → 「Uni」不是一个模型，是三个「一个」）**
直觉：比赛叫 UniBot、规则要求单模型、32 任务共享一套数据——统一性有三个可落地层：(a) **一个模型**：模式是同一模型的条件 token（视界/算力/门控），不是第二个模型，守住 PR2；(b) **一套里程碑**：把 32 任务的得分点映射到共享里程碑本体（approach / grasp / lift / transport / align / contact / actuate / release / verify），一个任务无关进度头，数据跨任务汇聚，弱任务向强任务借同原语示教；(c) **一份契约**：`T_a` 固定，就把模式编码进 chunk 内部（尾部保持 / 提前收束），而不是幻想运行时改 metadata。反直觉点：**统一里程碑让「逆向 32 套得分点」从 32 次重复劳动，变成 1 次本体设计 + 32 次序列标注；I5 的标签、I10 的切换点、I9 的检索目标共用同一套语义。**

**灵感 3（把两者接起来：无触觉的「地形」从哪来）**
直觉：轮足靠轮子电流/打滑估计地形；我们没有力/触觉（F8/P4），但有 **EE 指令与 EE 实测位姿**（F20）。于是可以合成一个「操作地形」信号：`指令 EE 增量 vs 观测 EE 增量` 的失配，叠加夹爪开度变化与腕部视觉流，区分**自由 / 接触 / 卡死 / 抓空 / 滑移**五态。这是免费的、每步可算的、模型无关的「地形感知」，既给 I10 提供 d_t，也给 I5 的恢复触发与 I11 的里程碑边界提供信号。

**三者统一**：轮足切换律 → I10（双模调度）；Uni 的统一性 → I11（统一里程碑）+ 契约内编码；地形感知 → I12（失配代理）。一句话：**第 3 轮从「数据侧」转向「调度侧」——不换模型，先把同一模型的算力与语义按风险重新分配。**

> 检索日期：2026-11-26（第 1 轮）、2026-11-27（第 2 轮）、2026-11-28（本轮）；来源见 §5。承接 v1.1：新增 I10/I11/I12，裁撤 I7 推理路径（并入 I5），硬修正 I4（固定 `T_a` + 尾部保持），深化 I3/I5/I9。清单只增改不重置。

## 0. 创新点清单（每点：动机 / 与现有方案差异 / 技术可行性 / 所需资源 / 落地步骤 / 风险）

### I10 v1 统一双模推理 Uni-Hybrid（新） ★★★★★

- **动机**：算力与风险在 episode 内高度不均匀——自由空间搬运与接触操作对闭环频率的要求差一个量级；第 2 轮的 I3/I4 是并列补丁，缺统一调度。轮足机器人的「轮/腿」切换律正好是这一问题的标准解。
- **核心定义（契约内四态）**：设 `T_a` 为握手固定的 chunk 长度（F21），`h_eff ∈ [1, T_a]` 为「有效视界」，`c ∈ {cheap, full, servo}` 为每调用算力档。策略维护四态：
  - **ROLL（轮）**：`h_eff=T_a, c=cheap`；整段开环执行，少去噪步、不跑伺服。
  - **STEP（腿）**：`h_eff=k<T_a, c=full`；只信前 k 步，`k..T_a−1` 用 **tail-hold**（保持末指令位姿、夹爪维持、pivot 保持）填充，下次调用立即重规划。
  - **CONTACT**：`h_eff=1, c=servo`；首步由 I3 关键点伺服产生，其余 tail-hold。
  - **HOLD（安全）**：`h_eff=1, c=cheap`；人干预/异常时原地保持（I4 状态机的落点）。
- **难度地形 d_t**：由 I12 五态后验、I11 里程碑不确定性、VLM 置信度融合为 `d_t∈[0,1]`；双阈值滞回（`θ_up` 进入高险、`θ_down` 退出）防止模式抖动；预算记账 `B_t`，超支强制回落 ROLL（最省）。
- **与现有方案差异**：现有队伍固定一个 chunk 长度跑到底；本点把「同一模型的算力」当作可分配资源，按风险调度，且**全部编码在固定 `T_a` 契约内**（tail-hold），不改 metadata、不加第二个模型。
- **技术可行性**：中-高。tail-hold 与算力分级是纯推理工程；四态状态机与滞回易实现；唯一真风险是 d_t 标定。
- **所需资源**：1×24GB 推理 GPU 即可做离线回放；L0 无需真机。
- **落地步骤**：①`run_client` 验证评测端是否执行满 `T_a`（F21 实证）；②实现 tail-hold 与四态状态机；③`T_a ∈ {1,2,4,8}` × 算力档的 L0 回放收益曲线；④d_t 用 I12 特征起步、VLM 置信度兜底；⑤L2 真机抽测「误判代价」（把接触判成自由 vs 反之）。
- **风险**：模式误判是主计分路径上的单点故障（缓解：滞回 + 默认偏保守 + 超支回落 ROLL + L2 只测误判代价）；tail-hold 本身消耗 `T_a−k` 步（缓解：`T_a` 取小、把「停顿」计入时间预算的 L0 目标函数）；「一个模型两模式」被裁定为多模型（缓解：模式仅作同一 DiT 的条件 token / 视界 mask，保留单权重、单前向图）。
- **I10-M 主动基座重定位（gated 子项）**：`action.pivot`[7] + `lower_body`[15]（F22）若确认可控且允许，则在「目标超出标称可达域/被遮挡」时用 pivot 改变基座视角与可达域——这是轮足「移动以到达」的字面迁移。**未向组委会/手册确认前不投入、不上计分通道**（PR6）。

### I11 v1 统一里程碑本体 UMO（新） ★★★★

- **动机**：每任务得分点是逐任务文本（F17/F23），32 套各训一个进度头 = 数据碎片化；弱任务（eps 少）无法借用强任务的同原语示教。
- **核心定义**：设计共享本体 `O = {APPROACH, GRASP, LIFT, TRANSPORT, ALIGN, CONTACT, ACTUATE, RELEASE, VERIFY}`（≤9 个）。每个任务 `τ` 的得分点映射为 `O` 上的**有序序列 + 槽位**（object, arm, target），例如 `ZipUp = [APPROACH(zipper), GRASP(pull-tab), ACTUATE(pull), VERIFY(closed)]`。单一任务无关进度头输出 `p_t = P(o_t | vision, proprio, instruction, detections)` 与相内进度；任务专用残差头只补「本体表达不了」的步骤（如 SpellRobot 笔画、PourOutMedicine 剂量）。
- **与现有方案差异**：v1.1 的 I5 进度头按任务/得分点分别监督；本点把监督信号跨任务汇聚——「所有任务的 GRASP 段」共同训练一个原语头，弱任务直接受益。
- **技术可行性**：中。本体设计是 1 次人工劳动；映射可 LLM 初筛 + 人工校对；标签来自「得分点 wiki + 动作变化点 + I12 接触边界」的弱监督。
- **所需资源**：本体与映射 1 人周；进度头训练 1 GPU 日/轮。
- **落地步骤**：①抓取 32 任务得分点 JSON（wiki，本轮 401 待重试）；②设计 `O` 并完成映射与覆盖率统计；③用变化点 + I12 边界自动分段，人工抽检；④训练统一进度头，对比 32 专用头；⑤把 I5 的合成示教标签切到 `O`。
- **风险**：本体过粗导致进度歧义（缓解：保留任务专用残差头 + 只在映射置信度高时共享）；部分任务不可分解（缓解：残差头兜底，不强行统一）。

### I12 v1 无触觉失配地形估计（新） ★★★★

- **动机**：无任何力/触觉通道（F8/P4），但接触/卡死/抓空/滑移正是恢复与调度的触发信号；本体感受（F20）足以做「指令-观测」失配代理。
- **核心定义**：设观测 EE 位姿 `s_t`（base 系），上一步指令 `a_{t−1}`。用滞后对齐后的增量比
  `r_t = ||Δs_t|| / (||Δa_{t−ℓ*}|| + ε)`（位置；姿态同理用角增量），`ℓ*` 由历史互相关选出以吸收控制滞后。叠加夹爪开度变化 `Δg_t`、腕部相机光流幅值、目标 bbox 位移，得到五态：
  - **FREE**：`r≈1` 且 `|Δa|` 正常；
  - **CONTACT**：`0<r<1` 持续且方向一致；
  - **STUCK**：`r≈0` 且 `|Δa|>0` 连续 m 步；
  - **MISS**：夹爪闭合到最小开度但目标未随动；
  - **SLIP**：抓取后物体相对夹爪位移。
  输出校准后的风险后验 `d_t = P(hazard | features)`，作为 I10 的难度地形；同时给 I5 提供恢复触发。
- **与现有方案差异**：纯视觉置信度对「接触是否发生」不敏感；本点用本体闭环误差直接测「物理上是否动了」，便宜、可解释、模型无关。
- **技术可行性**：高。全部特征可由 `obs` 逐步计算；分类器可先逻辑回归/GBDT 起步，标签来自示教阶段 + I5 合成失败段。
- **所需资源**：CPU 即可在线计算；离线标定 1 人周。
- **落地步骤**：①在 110 语料上离线提取 `r_t, Δg, flow`；②用示教阶段弱标签检验五态可分性；③训练轻量分类器并校准；④接入 I10 作 d_t，L0 对比「失配 d_t vs VLM 置信度」的调度收益；⑤真机抽测卡死/抓空检出率。
- **风险**：`control_space=joint` 时指令需经 FK 转 EE（缓解：优先 `ee` 控制；joint 模式下用观测 EE 与指令关节 FK）；低摩擦滑移被误判为自由（缓解：加腕部视觉流与物体随动特征）。

### 1.1 固定 `T_a` 下的四态调度与尾部保持（I10）

```python
class UniHybridPolicy:                       # 唯一参赛实体：一个 PolicyService / 一套权重
    T = 8                                    # action_chunk_size，握手固定（F21），全局超参
    TH_UP, TH_DOWN = 0.65, 0.45              # 滞回双阈值
    K_STEP = 2                               # 踏步模式有效视界

    def get_action(self, obs):
        d   = self.terrain.d_t(obs)           # I12 失配 + I11 里程碑不确定 + VLM 置信
        mode = self._hysteresis(d)            # ROLL / STEP / CONTACT / HOLD
        if self.budget.exceeded():
            mode = "ROLL"                     # 预算超支强制最省
        if mode == "ROLL":
            chunk = self.vla.propose(obs, horizon=self.T, tier="cheap")
        elif mode == "STEP":
            chunk = self.vla.propose(obs, horizon=self.K_STEP, tier="full")
            chunk = tail_hold(chunk, obs, self.T)          # 只信前 K 步
        elif mode == "CONTACT":
            chunk = self.servo.contact_step(obs)           # I3 原语
            chunk = tail_hold(chunk, obs, self.T)
        else:                                   # HOLD（人干预 / 异常）
            chunk = hold_from(obs, self.T)
        self.budget.spend(mode)
        return self.guard(chunk, obs)           # 动作健康度门禁（PR4）

def tail_hold(chunk, obs, T):
    # chunk 长度 k <= T；后续步保持末指令位姿、夹爪维持、pivot 保持
    last = chunk[-1]
    return concat([chunk, repeat(last, T - len(chunk))])
```

> 关键：`T` 是握手常量，模式切换只改「内部有效视界 + 每调用算力」，不改 metadata。`T=1` 时 tail-hold 退化，四态只剩算力分级（稳健上限最高、无 chunk 吞吐）。
