### 第 1 轮灵感驱动研究记录（v28）

**灵感词**：物体泛化、竞品分析

**直觉与动机**：

v27 的 KEMPC 解决了「如何把常识塞进双足机器人 MPC」：KC 管常识命题、DCC 管动态一致性、WLKB 管 walking 常识库。但它有一个隐含前提——知识库是「按物体/地形手工枚举」的：rigid_flat 上的 50 条规则，到了软垫、湿滑金属、碎石或未知负载上就未必成立。也就是说，v27 拿到了「常识」，却没拿到「常识的搬运能力」。

**物体泛化**要回答的正是：一条在源物体 o 上被证书验证过的常识，能否、以多大代价、在多远的物体邻域内继续成立？直觉上，物体不是离散标签，而是连续签名（质量、摩擦、刚度、几何、可供性）。若两个物体在签名空间足够接近，且动力学对签名 Lipschitz，则常识可以沿签名空间「平移」，并给出一个可验证的泛化半径 ρ。

**竞品分析**则补上另一半：泛化好坏不能自说自话。只有当「我们的泛化半径/代价」与「竞品在同类物体上的表现」放在同一基准上比较，「泛化」才有意义。更进一步，竞品分析不应只是论文里的对比表，而应成为搜索泛化缺口的目标函数：哪些物体切片上我们输给竞品，就把知识扩展/半径放大优先投到哪里。

**关键洞见**：把「物体泛化」与「竞品分析」耦合成一个闭环——**竞品驱动泛化（Competitor-Driven Generalization, CDG）**。泛化目标从「最大化平均迁移率」改为「最小化对最强竞品的最坏情况遗憾」：min_Π max_c Regret_c(Π)。这样，OGC（物体泛化证书）给出「能搬多远」，DomC/LossC（支配/落败证书）给出「相对竞品是否值得搬」，RAGO（对手感知泛化目标）把两者合成一个可优化、可准入的准则。

与 v27 的接口：
- **OGC 是 KC 的空间维度扩展**：KC 沿时间 H 步保证，OGC 沿物体签名半径 ρ 保证；
- **DomC/LossC 是 KACG 的竞争维度扩展**：不仅问「安全吗」，还问「比竞品好吗 / 差在哪」；
- **RAGO 是 KEMPC 代价函数的元层**：在任务代价之外加最坏遗憾项与半径正则项；
- **GCCG（Generalization-Competitive Cert Gate）** = KACG ∩ OGC ∩ (DomC ∨ LossC.mitigated)。

**形式化目标**：
1. 定义物体空间 𝒪 与签名映射 σ: 𝒪 → ℝ^d，d_σ 为加权度量；
2. 定义泛化态射 φ_{o'→o} 与证书搬运算子 T_{o→o'}[KC]；
3. 定义泛化半径 ρ(KC,o) = sup{ε : ∀o'∈N_ε(o), T_{o→o'}[KC] 在 o' 上可验证}；
4. 定义 OGC：以 Lipschitz 界 L 与搬运误差 e_φ 证明 |Q_o(x) − Q_{o'}(φ(x))| ≤ L·d_σ + e_φ；
5. 定义竞品集合 C、任务分布 𝒯、指标 M，以及遗憾 Reg_c(Π) = E_τ[M(c,τ)] − E_τ[M(Π,τ)]；
6. 定义 DomC（统计支配证书）与 LossC（诚实落败证书 + 缓解），二者必须择一提供；
7. 定义 RAGO：min_Π [ max_c Reg_c(Π) + γ/ρ̄(Π) + λ_s·Safety(Π) ]；
8. 定义 GCCG 准入：Exec_v28 = Exec_v27 ∩ Fil_generalization ∩ Fil_competition ⊆ Exec_v27，并给出 OOD/证书失效/竞品反超下的退化路径。

**本轮最大风险**：竞品过拟合（Goodhart）——泛化半径、知识库与 RAGO 权重都围绕固定竞品集合与基准物体分布调优，机器人在基准上「赢」，却对竞品同样失败的长尾物体产生虚假泛化信心；这种「基准内泛化、基准外崩溃」比单纯的常识闭塞更难在线识别。

## 2. 关键算法骨架

### IP-465 Object Signature & Generalization Morphism (OSGM)

```python
@dataclass
class ObjectSignature:
    mass: float
    friction: float
    height: float
    compliance: float
    affordance: np.ndarray          # [support, graspable, deformable, slippery]
    weights: np.ndarray = None      # W，默认按量纲归一后取等权

    def dist(self, other: 'ObjectSignature') -> float:
        w = self.weights if self.weights is not None else np.ones(4 + len(self.affordance))
        a = np.concatenate([[self.mass, self.friction, self.height, self.compliance], self.affordance])
        b = np.concatenate([[other.mass, other.friction, other.height, other.compliance], other.affordance])
        return float(np.linalg.norm(w * (a - b)))


class GeneralizationMorphism:
    """φ_{o'→o}：把目标物体状态映射回源物体状态，使源常识可复用。"""
    def __init__(self, source: ObjectSignature, target: ObjectSignature,
                 scale: np.ndarray = None, offset: np.ndarray = None,
                 jacobian: np.ndarray = None):
        self.source, self.target = source, target
        self.scale = scale if scale is not None else np.ones(3)
        self.offset = offset if offset is not None else np.zeros(3)
        self.jacobian = jacobian

    def map_state(self, x_target: Tensor) -> Tensor:
        # 位姿按几何相似变换对齐；速度/力按质量-刚度比缩放
        q = (x_target[:3] - self.offset) / self.scale
        v = x_target[3:] * np.sqrt(self.source.mass / max(self.target.mass, 1e-6))
        return torch.cat([q, v])

    def transport(self, kc: 'KnowledgeCertificate') -> 'KnowledgeCertificate':
        """T_{o→o'}[KC]：把前后置条件经 φ 拉回目标物体。"""
        return KnowledgeCertificate(
            name=f"{kc.name}@{self.target}",
            precond=lambda x: kc.precond(self.map_state(x)),
            postcond=lambda x: kc.postcond(self.map_state(x)),
            phi=f"transport({kc.phi}) via φ_{{o'→o}}",
            H=kc.H,
        )
```

### IP-466 Object Generalization Certificate (OGC)

```python
@dataclass
class ObjectGeneralizationCertificate:
    kc: KnowledgeCertificate
    source: ObjectSignature
    radius: float                    # ρ：已证明可搬运的签名半径
    lipschitz: float                 # L：后置条件对签名的 Lipschitz 常数
    transport_error: float           # e_φ
    confidence: float = 0.95

    def verify(self, target: ObjectSignature, dyn_family: dict,
               n_samples: int = 64) -> bool:
        """证书可搬运性：d_σ ≤ ρ 且搬运后 KC 在目标邻域内仍通过。"""
        if self.source.dist(target) > self.radius:
            return False
        # 1) 在目标邻域内采样物体，逐一搬运并验证
        for o_prime in sample_ball(target, self.radius, n=n_samples):
            phi = GeneralizationMorphism(self.source, o_prime)
            kc_t = phi.transport(self.kc)
            if not kc_t.verify(sample_state(o_prime), dyn_family[o_prime]):
                return False
        # 2) Lipschitz 一致性：|Q_o(x) − Q_{o'}(φ(x))| ≤ L·d_σ + e_φ
        worst = max(
            abs(self.kc.postcond(x) - phi.transport(self.kc).postcond(phi.map_state(x)))
            for x in sample_states(n=n_samples)
        )
        return worst <= self.lipschitz * self.source.dist(target) + self.transport_error

    def grow_radius(self, targets: list, dyn_family: dict,
                    step: float = 0.05) -> float:
        """沿签名空间贪心扩张 ρ，直到首次验证失败。"""
        while all(self.verify(o, dyn_family) for o in targets):
            self.radius += step
        self.radius -= step
        return self.radius
```

### IP-467 Competitive Analysis Harness (CAH)

```python
@dataclass
class Competitor:
    name: str
    policy: Callable
    claimed: dict = field(default_factory=dict)   # 竞品论文/产品自报指标（仅作对照）


class CompetitiveAnalysisHarness:
    def __init__(self, objects: list, tasks: list, metrics: list,
                 competitors: list['Competitor']):
        self.objects, self.tasks = objects, tasks
        self.metrics, self.competitors = metrics, competitors

    def run(self, our_policy: Callable, n_episodes: int = 50,
            seed: int = 0) -> 'DataFrame':
        rows = []
        for o in self.objects:
            for tau in self.tasks:
                for name, policy in [("ours", our_policy)] + \
                        [(c.name, c.policy) for c in self.competitors]:
                    vals = [evaluate(policy, o, tau, seed=seed + k)
                            for k in range(n_episodes)]
                    rows.append({"object": o, "task": tau,
                                 "controller": name, **aggregate(vals)})
        return DataFrame(rows)

    def pareto_front(self, df) -> list:
        """成功率↑、代价↓ 的 Pareto 非支配控制器集合。"""
        return [c for c in df.controller.unique()
                if not any(dominates(df, d, c) for d in df.controller.unique() if d != c)]

    def regret_table(self, df) -> 'DataFrame':
        """逐物体/任务：Reg_c = M(竞品) − M(ours)，正值表示我们更优。"""
        out = []
        for (o, tau), g in df.groupby(["object", "task"]):
            ours = g[g.controller == "ours"][["success", "cost"]].iloc[0]
            for _, r in g[g.controller != "ours"].iterrows():
                out.append({"object": o, "task": tau, "competitor": r.controller,
                            "regret_success": r.success - ours.success,
                            "regret_cost": ours.cost - r.cost})
        return DataFrame(out)
```

### IP-468 Dominance / Loss Certificate (DomC / LossC)

```python
@dataclass
class DominanceCertificate:
    competitor: str
    metric: str
    delta: float                      # 观测到的优势
    ci_low: float
    ci_high: float
    alpha: float = 0.05
    n_bootstrap: int = 1000

    def verify(self, ours: np.ndarray, rival: np.ndarray) -> bool:
        """配对 bootstrap：若 delta 的 (1−α) 下界 > 0，则判定支配。"""
        boot = np.array([np.mean(rival[idx] - ours[idx])
                         for idx in bootstrap_indices(len(ours), self.n_bootstrap)])
        self.ci_low, self.ci_high = np.quantile(boot, [self.alpha, 1 - self.alpha])
        self.delta = float(np.mean(rival - ours))
        return self.ci_low > 0.0


@dataclass
class LossCertificate:
    """诚实落败证书：记录竞品更强的物体切片，并绑定缓解动作。"""
    competitor: str
    object_slice: list
    gap: float
    mitigation: str                   # e.g. "add_source_object" / "enlarge_radius"

    def mitigated(self, target: ObjectSignature, ogc: 'ObjectGeneralizationCertificate') -> bool:
        if self.mitigation == "add_source_object":
            return target in ogc.known_sources
        if self.mitigation == "enlarge_radius":
            return target.dist(ogc.source) <= ogc.radius
        return False
```

### IP-469 Rival-Aware Generalization Objective (RAGO)

```python
class RivalAwareGeneralizationObjective:
    def __init__(self, lambda_rag: float = 1.0, gamma: float = 0.5,
                 lambda_s: float = 10.0):
        self.lambda_rag, self.gamma, self.lambda_s = lambda_rag, gamma, lambda_s

    def __call__(self, policy, objects, competitors, cah: 'CompetitiveAnalysisHarness'):
        df = cah.run(policy, n_episodes=30)
        regret = cah.regret_table(df)
        worst_regret = max(regret.groupby("competitor").regret_cost.mean().max(), 0.0)
        radii = [o.ogc.radius for o in objects if o.ogc is not None]
        radius_term = self.gamma / (np.mean(radii) + 1e-6)
        safety = df[df.controller == "ours"].violation_rate.mean()
        return self.lambda_rag * worst_regret + radius_term + self.lambda_s * safety
```

### IP-471 Generalization-Competitive Cert Gate (GCCG)

```python
@dataclass
class GeneralizationCompetitiveCertGate:
    kacg: 'KnowledgeAwareCertificationGate'   # v27 八证门
    ogc: 'ObjectGeneralizationCertificate'
    domc: 'DominanceCertificate'
    lossc: 'LossCertificate'

    def admits(self, plan: 'RobotPlan', object_sig: ObjectSignature,
               competitor_samples: dict) -> bool:
        # 1) v27 安全/常识/动力学全部门禁
        if not self.kacg.admits(plan, plan.sensor_data):
            return False
        # 2) 物体泛化：目标物体必须在证书半径内，且搬运后 KC 可验证
        if not self.ogc.verify(object_sig, plan.dynamics_family):
            return False
        # 3) 竞争维度：要么统计支配，要么提供可执行的落败缓解
        ours, rival = competitor_samples["ours"], competitor_samples["rival"]
        if self.domc.verify(ours, rival):
            return True
        return self.lossc.mitigated(object_sig, self.ogc)

    def degrade(self, plan, object_sig, reason: str):
        """退化路径：OOD / OGC 失效 / 竞品反超 → 保守知识 + 降速 + 人工接管。"""
        if reason in ("ood", "ogc_fail"):
            return plan.with_mode("standing").with_speed(0.3)
        if reason == "rival_dominates":
            return plan.with_controller("conservative").with_speed(0.5)
        return plan.with_mode("safe_stop")
```

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |

## 4. 正确性论证（增量）

### 引理 23（OGC 搬运的可靠性）

**陈述**：设源物体 o 上 `KC.verify = True`；若 (i) 动力学族对签名 L_f-Lipschitz，(ii) 态射误差 sup_x‖φ(x)−φ̂(x)‖ ≤ e_φ，(iii) d_σ(o,o') ≤ ρ，则目标物体 o' 上后置条件满足 |Q_{o'}(x') − Q_o(φ(x'))| ≤ L_f·ρ + e_φ。

**证明**：把后置条件视为 (x,σ) 的复合函数 Q(x,σ)。由 (i) 对 σ 的 Lipschitz 性与 (iii) 得 |Q(x,σ_o)−Q(x,σ_{o'})| ≤ L_f·ρ；由 (ii) 与后置条件对状态的有界性得状态搬运项 ≤ e_φ。三角不等式合并即得。OGC.verify 正是逐点检验该上界（取 L=L_f）。∎

### 引理 24（DomC 的统计有效性）

**陈述**：若配对 bootstrap 的 (1−α) 下界 ci_low > 0，则在可交换性假设下，真实优势 delta > 0 的置信度至少 1−α。

**证明**：配对差分 d_i = M(rival,i) − M(ours,i) 独立同分布；bootstrap 分位数 ci_low 是 delta 的 (1−α) 单侧置信下界，故 P(delta ≤ 0) ≤ α。∎

### 引理 25（RAGO 的最坏遗憾上界）

**陈述**：对有限竞品集合 C，若 RAGO 的代理目标值 ≤ δ，且 Safety(Π)=0、γ/ρ̄(Π) ≥ 0，则 Π 对任意 c∈C 的平均遗憾 ≤ δ/λ_rag。

**证明**：RAGO = λ_rag·max_c Reg_c + γ/ρ̄ + λ_s·Safety ≥ λ_rag·max_c Reg_c。由 RAGO ≤ δ 得 max_c Reg_c ≤ δ/λ_rag，即对一切 c 成立。∎

### 定理（GCCG 的可靠性与完备性）

**陈述**：对任意计划 Π 与目标物体 o，`GCCG.admits(Π,o) = True` ⟺ (1) v27 KACG 通过；(2) o 在 OGC 半径内且搬运后 KC 可验证；(3) DomC 成立或 LossC 已缓解。

**证明**：由 `admits` 的三项合取定义直接展开；每项分别由引理 23/24 保证其证书语义。可靠性来自各项证书的 soundness，完备性来自「DomC ∨ LossC」覆盖了优于/劣于竞品的全部情形。∎

## 5. 实验设计与代理实验结果

**代理基准（隔离泛化机制，非双足实机）**：1D 线性化倒立摆/接触平衡代理，状态 x=[θ, θ̇]，签名 σ(o)=(b,c)，b 为摩擦阻尼、c 为接触刚度/控制增益：
A=[[1,dt],[ω²dt,1−b·dt]]，B=[0, c·dt]ᵀ，ω²=9，dt=0.02，T=400，|θ|max=0.35，u_sat=25，观测噪声 σ=0.003；每物体 40 组随机初值。控制增益由离散 Riccati 方程求解（Q=diag(10,1), R=0.1）。

**物体**：源集 rigid_flat(2.0,1.0)、soft_mat(1.2,0.6)、slippery_metal(0.4,0.9)、gravel(1.0,0.5)；OOD 物体 OOD_marsh(0.3,0.35)。**控制器**：Nominal LQR（仅按 rigid_flat 设计）、Conservative（按最坏签名设计）、Oracle-Adaptive（用真实签名设计，作为竞品上界）、Ours（OGC 最近源 + 半径 0.30 外回退保守，模拟 SCKT）。

|---|---|---|---|---|---|
| Nominal LQR | 1.00 / 0.14 | 1.00 / 0.39 | 1.00 / 0.14 | 1.00 / 0.79 | **0.00 / 171.09** |
| Conservative | 1.00 / 0.59 | 1.00 / 0.85 | 1.00 / 0.61 | 1.00 / 1.00 | 1.00 / 1.42 |

*单元格为「成功率 / 平均控制代价（越小越好）」。OOD_marsh 到最近源 slippery_metal 的签名距离 d=0.559 > ρ=0.30，故触发保守回退。*

**竞品分析结论**：
1. **Nominal LQR** 在分布内几乎零遗憾，但在 OOD 上 0% 成功率、代价爆炸——这是「无泛化」的典型失败模式，验证了 v27 知识库的物体依赖风险。
2. **Conservative** 全物体安全，但在分布内代价高 3–7 倍，最大遗憾约 0.51；它是「用代价换安全」的竞品基线。
3. **Oracle-Adaptive** 是性能上界（需要真实签名），不可直接部署，但可作为 RAGO 的遗憾参照。
4. **Ours** 在分布内达到 Oracle 同等代价（泛化间隙≈0），OOD 上主动降级到保守、保持 100% 成功率；其**最坏遗憾 0.51**，远小于 Nominal 的 ~170。这正是 RAGO 想优化的量：不求平均最优，而求最坏竞品差距有界。

**实验设计（真实双足阶段）**：(a) 物体集覆盖刚性/软性/湿滑/颗粒/未知负载五类，每类 ≥30 试次；(b) 竞品含 Nominal-MPC、ZMP、PPO-RL、Conservative-KEMPC；(c) 指标为成功率、CoT、跌倒率、证书违规率、遗憾；(d) 消融 OGC / DomC / RAGO；(e) 预注册指标与显著性（α=0.05, bootstrap 1000 次）以避免 Goodhart。

**效度威胁**：代理是一维线性系统，不能外推到足式接触动力学；表中数字用于验证机制方向，不作为双足性能声明。

## 7. 本轮最大风险（最终确认）

**一句话**：**泛化半径、知识库与 RAGO 权重都围绕固定竞品集合与基准物体分布调优，机器人在基准上「赢」却对竞品同样失败的长尾物体产生虚假泛化信心——这种「基准内泛化、基准外崩溃」的竞品过拟合（Goodhart）风险，是当前方案最大且最难在线识别的安全隐患。**
