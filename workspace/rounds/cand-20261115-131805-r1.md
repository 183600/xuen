# 第 6 轮（研究循环第 6 轮；本批灵感循环第 1 轮；本轮灵感：「大语言模型」×「视觉语言模型」）

> **基线**：第 5 轮 InstructGauge-RTDI（IP-334–339；定义 468–492；引理 63–68；实验 E473–E492）。此前 v1–v4 的不变式、CVC 闭环、SpatialCert、组合性原语图、严格退化链全部保留。
> 本轮纪律：**增量升级 + 严格退化**。LLM/VLM 在系统里只有两种合法身份——**命题提出者**与**证据提供者**，绝不是执行者；任一环节不可用都必须一键退回 RTDI。

## 0. 直觉与动机

**灵感 1（大语言模型 → 「可证伪命题的分解器」，而不是规划器/执行器）**
直觉：把 LLM 当"会写计划的规划器"最危险——它产出的计划看起来很对，却把语义错误藏进一串物理合法的动作里：机器人准确地抓住了**错的那个杯子**，CVC 全部满足，SpatialCert 全部通过，系统却完成了错误的任务。真正可审计的用法是反过来：让 LLM 把一句指令**分解成一组能被观测证伪的原子命题**——对象是哪个类别、位于何处、与谁是什么空间关系、是否可抓、目标是什么——以及这些命题之间的依赖。LLM 输出的是 **claim，不是 action**。这样幻觉会以"某个命题验证不过"的形式暴露，而不是以"动作已执行、但对象错了"的形式暴露。

**灵感 2（视觉语言模型 → 「区域级证据」，而不是答案）**
直觉：让 VLM 直接回答"能抓吗"既不可靠，也无法审计——你拿不到它凭什么这么说。更好的用法是让 VLM 只输出**区域证据**：像素掩码 / 3D bbox、多视角下的同一指代、逐区域置信度。然后由**几何与物理验证器**判定命题真假。VLM 的价值在于把"语义指代"接到"可测量区域"上，而不是替我们下结论；它给的是证据，不是判决。

**灵感 3（两者耦合 → 语义证书必须成为执行前的第三道门）**
直觉：现有两道门各管一半。CVC 管"物理契约"（执行前条件、后置条件、工具不扩权），SpatialCert 管"时空一致"（TF 残差、视觉漂移）。但对**语义正确性**，两道门都沉默。缺的是一道独立门：任何被用于实例化契约的语义原子，必须在提交前被判为 SUPPORTED，且证据可重放、可追溯、与所用模型版本绑定。物理安全与语义正确必须**独立认证**——因为二者互不蕴含。

**灵感 4（三者叠加后真正的敌人：相关失效）**
直觉：如果"证据提供者"（VLM）和"语义验证器"看的是同一份嵌入、同一个模型、同一条感知链路，那么它们会**一起错**。此时语义证书会漂亮地通过，覆盖率先验也毫无意义——证书变成了循环论证。所以本轮不仅引入语义门，还必须引入**证据独立性**这一可操作判据，并把"模型版本漂移会让共形覆盖失效"写进风险，而不是藏在附录里。

## 1. 研究问题（本轮要回答什么）

- **Q1（语义可审计性）**：能否把 LLM 的语义理解约束为**可证伪命题**，使幻觉以"验证失败/弃权"而非"已执行的错误动作"呈现？
- **Q2（三值弃权的收益与代价）**：把语义判定做成 SUPPORTED / REFUTED / UNDECIDED 三值，并让 UNDECIDED 只触发**可逆主动感知**，能否在不增加物理风险的前提下，用有限探测预算显著降低语义错误？
- **Q3（证据独立性）**：当证据通道与验证器共享感知前端时，语义证书的覆盖保证是否还成立？需要什么样的**非循环性条件**，以及它失效时如何安全退化？
- **Q4（语义陈旧与分块）**：第 3–5 轮的块长 K 放大的是"证据陈旧"；语义层面还存在**语义事件边界**（遮挡变化、接触、物体移动）。语义有效期如何与 K 耦合，才能保证不跨越事件边界盲执行？

## 2. 四条设计原则（雏形，正式化见产物区定义 493–520）

**P1 命题闭包（Claim Closure）**
LLM 只能在预注册的命题语言 `L_C` 的语法内生成原子命题，**不能生成自由文本动作、不能命名新工具、不能直接写参数**。被 `Γ_claim` 产出的每个原子都必须有可测量的接地解释；无解释的原子一律判为 UNDECIDED 并阻断提交。这是第 3 轮「能力闭包」从"工具不扩权"到"主张不越界"的推广。

**P2 三值弃权（Three-Valued Abstention）**
语义判定取值 `{T, F, U}`，采用强 Kleene 语义。**只有 T 能提交动作**；**证据缺失一律是 U，绝不当作 F**（封闭世界假设在部分可观测下是错的）。U 不许"猜一个"继续，只能触发可逆探测或退回默认 ι₀。弃权不是失败，而是把不确定性显式化。

**P3 证据独立性（Evidence Independence）**
语义证书的**证据通道**必须与被验证通道在信息上非循环：提出区域证据的模型，不能同时是判定该命题真假的唯一依据。至少要求一条**异质通道**（如点云配准 / 关节编码器 FK / 多视角几何变换一致性）参与裁决。否则记录"循环证据"标记并降级。

**P4 语义抢占点（Semantic Preemption Points）**
在块执行中，凡发生语义事件（新遮挡、接触、物体位移超过 δ、视角跳变），所有相关原子证书立即失效（置 U），必须在**最近的语义抢占点**重新验证，且该点强制成为动作分块的截断边界。这把"块长=证据陈旧窗口"从时间维度推广到语义维度。

## 3. 与基线的接口（如何退化）

- 语义门关闭 / `Γ_claim` 解析失败 / `L_C` 越界 ⇒ 直接用 `NLI-Box.ground(ℓ)` 的单指令路径，等价于 InstructGauge v3；
- VLM 不可用 / 区域证据超时 ⇒ 所有语义原子置 U，退回 RTDI 的 CVC+SpatialCert 双门（**注意：这是更强的物理安全、更弱的语义语义，必须显式记账**）；
- 语义共形样本不足 ⇒ 回退全局共形阈值；模型哈希与校准集不匹配 ⇒ 强制重标定或退回 RTDI；
- 主动感知预算耗尽 ⇒ 使用默认 ι₀，行为等价于 ToolGauge 目标；
- RTDI 失效 ⇒ InstructGauge-WR ⇒ v3 ⇒ ToolGauge（原退化链原样保留）。

> **一个必须写死的诚实条款**：关闭语义门**不会**让系统更不安全，只会让它更不"语义正确"。因此退化对比实验必须同时报告物理指标（安全/契约）与语义指标（任务正确率），否则会出现"退化了还更好看"的自欺。

## 4. 预期贡献

1. 一个**命题闭包**口径：把 LLM 从"规划器"降级为"可证伪命题分解器"，使语义错误在提交前暴露并可审计；
2. 一个**三值语义证书 + 主动感知**机制：UNDECIDED 只允许可逆探测，把"猜"替换成"看"，并将探测成本显式计入预算；
3. 一个**证据独立性判据与相关失效分析**：指出并量化"VLM 与验证器共因"如何击穿共形覆盖，给出可操作的异质通道要求；
4. 一个**语义-物理双门**执行器与完整可证伪路径：E493–E512 覆盖命题解析、三值覆盖、错对象拦截、谄媚检测、主动感知、语义陈旧、模型漂移、相关失效、退化等价与实机迁移。

## 5. 本轮最大风险

**一句话**：语义证书最大的风险不是 VLM 会错，而是**验证器会用与 VLM 同一套感知前端去"确认" VLM 的错误**——一旦两条证据通道相关，三值门与共形覆盖都会给出虚假的安心感，而这恰恰发生在系统最需要它保持独立的时刻。

# 第 6 轮产物 · 创新点清单 v6：**InstructGauge-EC**（Epistemic Closure，语义闭合）

> 背景：第 5 轮 InstructGauge-RTDI（IP-334–339；定义 468–492；引理 63–68；实验 E473–E492）。
> 本轮灵感：「大语言模型」×「视觉语言模型」
> **继承纪律**：RTDI 实时调度、FaultCert 诊断恢复、PrimitiveGraph 双阶段接地、五不变式、CVC-闭环、SpatialCert、严格退化链全部保留。新组件一律为**可选增强**：任一环节不可用 ⇒ 退回 InstructGauge-RTDI ⇒ 退回 InstructGauge-WR ⇒ 退回 v3 ⇒ 退回 ToolGauge。
> **一句话定位**：RTDI 让系统"物理上可证、故障可恢复"，EC 让系统"**语义上可证**"。语义证书与物理证书**正交**，缺一不可，也互不替代。

## 2. 形式化定义（要点）

**定义 493（命题语言 L_C 与约束解码）**
设原子类型集 `K = {id, loc, rel, aff, goal, feas}`。`L_C` 由 `K` 上的原子经布尔连接词生成。`Γ_claim` 用**语法约束解码**，输出必须能被 `G_C` 解析：
```
Γ_claim(ℓ) = (V_c, E_c, λ_c),  λ_c: V_c → K_atom
约束：每个 v ∈ V_c 的槽位类型 ∈ 预注册类型；无自由文本槽位；越界 ⇒ ⊥
```
关键：`Γ_claim` 的输出**不含任何执行器指令**，只是一组待验证命题及其依赖。

**定义 494（接地解释与强 Kleene 语义）**
对观测历史 `H_t`（RGB-D、点云、本体感受、TF）：
```
⟦c⟧(H_t) = T   若验证器以 ≥1−α 的覆盖判定成立
             F   若证据明确反驳（区域为空、几何矛盾）
             U   其他（遮挡、证据不足、通道冲突）
组合：U∧T=U, U∧F=F, U∨T=T, U∨F=U, ¬U=U
```
健全性目标：**绝不因 U 而误判为 T**；U 只会阻断，不会放行。

**定义 495（语义证书 SemanticCert）**
```
SC(c) = (c, A, v, R, m, τ, h)
  v = ⟦c⟧(H_τ) ∈ {T,F,U}
  R = 该类别 k 的共形覆盖集，要求 P(truth ∈ R) ≥ 1−α
  m = (hash_LLM, hash_VLM, hash_verifier)   # 版本钉死
  h = 有效期（由 claim 类型与场景动态性给出）
Admissible(SC,t) ⇔ v=T ∧ Fresh(SC,t) ∧ Replay(SC) ∧ Indep(A,V) ∧ m=m_current
```

**定义 496（证据独立性 / 非循环性）**
设语义通道 `S`（VLM 嵌入生成区域证据）与裁决通道 `G`（点云配准 / FK / 多视角几何一致性）。称 `A` 与 `V` **独立**，若裁决 `v` 不以 `S` 的隐表示作为唯一证据源，即存在由 `G` 单独给出的可区分信号：
```
Indep(A,V) ⇔ ∃ 判别量 d_G : d_G(A_G) 在 c 真/假下分布可分 且  d_G ⊥ S|truth
```
操作化判据（可测）：在留出集上，仅用 `d_G` 的 AUC ≥ 0.5+ε，且 `d_G` 与 VLM 置信度 `q` 的残差相关不显著（偏相关检验）。不满足 ⇒ 证书标记 `circular`，`v` 降为 U。

**定义 497（命题分解 Γ_claim 与 claim DAG）**
```
Γ_claim(ℓ) = G_c = (V_c, E_c, λ_c)
E_c 编码：依赖（先定位后判定关系）、互斥（同一指代不能既 A 又 B）、优先级（目标命题高于可供性）
类型检查：λ_c(v) ∈ K_atom 且槽位类型匹配；否则 ParseError ⇒ 退化 v3
```

**定义 498（主动感知与语义抢占点）**
```
Perceive(U_set, b) = 选择可逆探测序列 P, |P| ≤ b, 使 E[U_set 缩减] 最大
约束：每个 probe ∈ P 可逆 ∧ 不跨不可逆屏障（复用 v3 P3）
PP_sem(C) = {t | 在 t 发生遮挡变化/接触/位移>δ/视角跳变}
语义块长上界：K_sem = min(原 K, 最近 PP_sem 距离)
```

**定义 499（语义-物理联合门 JointGate）**
提交块 `C` 当且仅当：
```
JointGate(C,t) ⇔ PhysicalGate(C,t) ∧ SemanticGate(C,t)
PhysicalGate ⇔ CVC(C) ∧ PrefixClosed(C) ∧ RTA(τ_C) ∧ SpatialCert_pre(C)
SemanticGate ⇔ ∀ c ∈ atoms(pre(C)) ∪ atoms(post(C)): Admissible(SC(c), t)
```
任一为假：有恢复 ⇒ 恢复；无恢复 ⇒ 弃权 / 默认 ι₀。**二者不可互相替代**（见引理 70）。

**定义 500（谄媚/引导一致性守卫）**
固定证据 `A`，构造中性置换 `ℓ'`（去掉诱导性措辞、保持指代）：
```
Δ_conf(c;ℓ,A) = conf(c | ℓ, A) − conf(c | ℓ', A)
SycophancySuspect(c) ⇔ Δ_conf > δ_s  ∧  VLM 证据后验几乎不变
动作：若怀疑 ⇒ SC.v 降为 U（仅降级，绝不升级）
```

**定义 501（语义分层共形 EpistemicConformal）**
对每类原子 `k`，在标定集 `D_k`（模型哈希一致）上计算非一致性分数 `s(c) = 1 − score(truth|c)`，取 `q_{k,α}`：
```
R_k(c) = { truth : s(c) ≤ q_{k,α} },   P(truth ∈ R_k) ≥ 1−α   若 D_k 可交换
覆盖要求按 k 分层；混层会因类型难度差导致系统性欠覆盖
```

**定义 502（EC-8C 闭环）**
```
W: 感知 (RGB-D / 点云 / 本体感受 / TF)
R: 命题 (Γ_claim：ℓ → claim DAG)
P: 证据 (VLM 区域证据 + 异质通道 + 主动感知)
C: 契约规划 (IAC + Kinematic-Loop + RT-CVC + JointGate)
E: 执行 (rt-chunk，语义抢占点处强制可截断)
D: 诊断 (FaultCert + 语义根因 SEM 细分)
V: 验证 (CVC + SpatialCert + SemanticCert 回放)
U: 更新 (Dbox + 主张绑定 + 共形集 + 原语图统计)
```

**定义 503（语义根因细分，扩展定义 469）**
在 `SEM` 根因下细分：
```
SEM-ID   对象/类别错认      SEM-REL  空间关系错判
SEM-AFF  可供性误判         SEM-GOAL 目标指代错误
SEM-FEAS 可行性误判
```
恢复预案按细分触发：`SEM-ID/REL/AFF` ⇒ 主动感知重验证；`SEM-GOAL` ⇒ 澄清/默认目标；`SEM-FEAS` ⇒ 退回保守规划。

## 3. 关键算法骨架

```python
# IP-340 SemanticCert 与三值裁决
class SemanticCert:
    def __init__(self, atom, evidence, verdict, cover, model_hashes, tau, horizon):
        self.c, self.A, self.v = atom, evidence, verdict
        self.R, self.m, self.tau, self.h = cover, model_hashes, tau, horizon

    def admissible(self, now, current_hashes, indep_ok):
        return (self.v == 'T' and now - self.tau <= self.h
                and self.m == current_hashes and indep_ok
                and replay(self))

# IP-341 命题分解：受语法约束，只产命题
class ClaimDecomposer:
    def __init__(self, grammar, type_checker, llm):
        self.G, self.tc, self.llm = grammar, type_checker, llm

    def decompose(self, ell):
        # 约束解码：输出 token 必须落在 G_C 的原子/连接词上
        raw = self.llm.generate_constrained(ell, grammar=self.G)
        g = self.G.parse(raw)                      # claim DAG
        for v in g.nodes:
            if not self.tc.atom_well_typed(v):     # 槽位越界 / 自由文本
                raise ParseError(f"claim atom out of closure: {v}")
        return g

# IP-342 VLM 只提供区域证据 + 异质通道
class EvidenceBinder:
    def __init__(self, vlm, geometry_channel, multi_view):
        self.vlm, self.geo, self.mv = vlm, geometry_channel, multi_view

    def bind(self, atom, scene):
        regions = self.vlm.propose_regions(atom, scene)      # mask / bbox / q
        # 多视角一致性：同一指代在不同视角须可经已知变换对齐
        consistent = self.mv.cross_view_check(regions, scene.TF)
        # 异质通道：几何/编码器独立信号
        d_geo = self.geo.discriminant(atom, scene)
        return EvidenceBundle(regions, consistent, d_geo)

    def independence_ok(self, bundle):
        # 用偏相关检验 d_geo 与 VLM 置信度的残差相关性
        return not statistically_dependent(bundle.regions, bundle.d_geo)

# IP-343 主动感知：只发可逆探测
class ActivePerception:
    PROBES = ['rotate_wrist', 'move_view', 'change_exposure', 'reestimate_pose']

    def plan(self, undecided, budget):
        plan, used = [], 0
        for atom in sorted(undecided, key=lambda a: a.info_gain, reverse=True):
            if used >= budget: break
            probe = self._best_reversible_probe(atom)
            if probe and probe.reversible and not probe.crosses_irreversibility:
                plan.append(probe); used += probe.cost
        return plan

# IP-344 谄媚守卫（单调降级）
class SycophancyGuard:
    def __init__(self, llm, delta_s=0.2):
        self.llm, self.delta_s = llm, delta_s

    def check(self, atom, ell, neutral_ell, evidence):
        c1 = self.llm.confidence(atom, ell, evidence)
        c2 = self.llm.confidence(atom, neutral_ell, evidence)
        evidence_shift = evidence_posterior_shift(evidence)
        return (c1 - c2 > self.delta_s) and (evidence_shift < 1e-2)

# IP-345 语义分层共形
class EpistemicConformal:
    def __init__(self):
        self.q = {}          # (claim_type, model_hash) -> quantile
        self.calib = {}      # (claim_type, model_hash) -> scores

    def fit(self, claim_type, scores, alpha, model_hash):
        n = len(scores)
        k = min(n, int(np.ceil((n + 1) * (1 - alpha))))
        self.q[(claim_type, model_hash)] = sorted(scores)[k - 1]

    def cover(self, claim_type, score, model_hash, alpha):
        key = (claim_type, model_hash)
        if key not in self.q:
            return None      # 样本不足 ⇒ 退回全局阈值
        return score <= self.q[key]

# IP-346/347 联合门主闭环
def instructgauge_ec(M, s, ell=None):
    # 1. 命题分解（LLM 只产 claim）
    if ell:
        try:
            G_c = M.claimer.decompose(ell)
        except ParseError:
            return instructgauge_rtdi_single(M, s, ell)   # 退化 v3
    else:
        return instructgauge_rtdi(M, s, None)

    # 2. 证据绑定 + 三值裁决
    SCs = {}
    for atom in G_c.topo_order():
        bundle = M.binder.bind(atom, M.scene)
        indep = M.binder.independence_ok(bundle)
        v, cover = M.verifier.verdict(atom, bundle, indep)
        if M.syco.guard and M.syco.check(atom, ell, neutralize(ell), bundle):
            v = 'U'                                    # 只降级
        SCs[atom] = SemanticCert(atom, bundle, v, cover,
                                 M.model_hashes, M.env.time(), atom.horizon)

    # 3. UNDECIDED：只做可逆主动感知，不提交动作
    undecided = [a for a, sc in SCs.items() if sc.v != 'T']
    if undecided:
        plan = M.active.plan(undecided, M.budget_sem)
        if plan:
            for probe in plan:                          # 可逆，安全集内
                M.env.apply_reversible(probe)
                M.scene = M.scene.refresh()
            return instructgauge_ec(M, s, ell)         # 重验证
        else:
            return default_goal_path(M, s)             # 预算耗尽 ⇒ ι₀

    # 4. 语义门通过 ⇒ 进入 RTDI 物理门
    iota_seq = M.pgraph.instantiate(G_c.to_task_graph(), M.scene)
    if not M.pgraph.verify_capability_closure(iota_seq):
        return instructgauge_rtdi(M, s, None)          # 退化
    return instructgauge_rtdi_with_iota(M, s, iota_seq, SCs)

def joint_gate(C, SCs, M, t):
    physical = (M.cvc.check(C) and M.kloop.verify_prefix_closed(C)[0]
                and M.rta.verify({M.rt_model.make_task(C, t)})
                and generate_spatial_cert(C, M.wristcam.get_spatial_trajectory(t), M.eps).is_consistent)
    semantic = all(SCs[a].admissible(t, M.model_hashes, M.binder.last_indep_ok)
                   for a in atoms_of(C.pre) + atoms_of(C.post))
    return physical and semantic
```

## 4. 推导

**引理 69（语义门不扩权）** 若 `Γ_claim` 满足命题闭包且 `SemanticGate` 只接受 `Admissible` 原子，则任何被提交动作的语义前置条件都被支持，且不引入 `T₀` 之外的工具。证明：`Γ_claim` 输出不含执行器指令（定义 493）；`Γ_inst` 仍只从预注册 `Π` 选原语（定义 471）；`SemanticGate` 仅对原子做准入，不改变工具集。∎

**引理 70（语义-物理正交）** 存在场景使 `PhysicalGate` 为真而 `SemanticGate` 为假，反之亦然。证明：构造两同形杯 A/B，目标为 B。抓 A 的块满足 CVC（前置/后置条件对 A 成立）、前缀封闭、可调度、SpatialCert 一致，但 `id(o;B)` 为 F ⇒ 物理真、语义假。反之，语义理解完全正确但存在未建模障碍 ⇒ SpatialCert 假而语义真。故两门互不蕴含。∎

**引理 71（三值健全性）** 在验证器健全且覆盖假设成立时，若 `SC(c).v = T` 则 `c` 为真且概率至少 `1−α`；且强 Kleene 组合不会把 U 传播成 T。证明：T 只在单原子覆盖集包含 truth 时产生；Kleene 表中任何含 U 的组合结果为 U 或 F，不含 T 的虚假提升。∎

**引理 72（弃权安全性）** UNDECIDED 路径不提交任何不可逆动作，只执行可逆探测，故其物理风险不超过基线默认路径。证明：主动感知 `PROBES` 全部满足可逆性且不跨不可逆屏障（P3）；弃权时退回 ι₀，等价 ToolGauge。∎

**引理 73（主动感知的预算终止）** 给定有限预算 `b` 与每个探测的非负信息增益，主动感知在至多 `⌈b / c_min⌉` 次探测后终止；最坏情况退回 ι₀。证明：每步 `used` 单调不减且上界为 `b`。∎（注：信息增益的单调性依赖通道独立性；若通道相关，增益可能为 0，见引理 77。）

**引理 74（谄媚守卫的单调保守性）** `SycophancyGuard` 只能把 T 降为 U，不能把 U 升为 T，故不会引入新的语义提交，只会降低可用性。证明：守卫仅在 `SC.v == T` 时被调用，输出只做 `v := U`。∎

**引理 75（语义陈旧界）** 若块 `C` 不跨越任何 `PP_sem`，则其语义证书在块内保持有效；若跨越，则至少一个相关原子失效，必须在最近抢占点截断并重验。证明：`Fresh` 定义以 `PP_sem` 为失效事件；`K_sem` 取最近事件距离，故块不跨越事件 ⇔ 无失效。∎

**引理 76（模型漂移破坏覆盖）** 若 `hash_VLM`（或 `hash_LLM`）与标定集不一致，则 `D_k` 与新模型输出不再可交换，`P(truth ∈ R_k) ≥ 1−α` 不再成立。证明：共形覆盖依赖可交换性；模型更新改变分数分布，交换性被破坏。∎ 因此证书必须钉死哈希，失配即失效。

**引理 77（相关失效击穿覆盖）** 若证据通道 `S` 与裁决通道 `G` 存在共同原因 `C₀`（如同一 VLM 前端），则 `v = T` 而 truth 为假的概率可超过 `α`，且 `Indep(A,V)` 为假。证明：条件独立被共同原因破坏，`P(false-T) = P(T | ¬truth)` 不再由共形分位数控制；两通道同向误差使该概率随 `C₀` 方差增大。∎ 这是本轮最重要的负面结果。

**引理 78（退化等价性）** 
- `Γ_claim` 失败 ⇒ 单指令 `NLI-Box.ground(ℓ)`（v3 等价）；
- VLM 不可用 ⇒ 原子全 U ⇒ 退回 RTDI 双门（语义能力下降，物理安全不降）；
- 共形样本不足 ⇒ 全局阈值；模型哈希失配 ⇒ 重标定或退回 RTDI；
- 全增强关闭 ⇒ 与 RTDI 行为逐动作 `diff=0`。

## 8. 本轮最大风险

**一句话**：语义门的所有保证都建立在"证据通道独立"之上，而 **VLM 证据生成器与语义验证器共享同一感知前端是最自然的工程实现**——一旦如此，二者会以极高的相关性一起犯错，三值门会稳定输出 T、共形覆盖率会漂亮达标，系统在最需要独立性的地方得到最严重的**循环认证**；缓解只能靠**物理异质通道（点云/FK/多视角几何）作为强制共同裁决者**，并在 `Indep` 失败时把语义门整体降为 advisory 而非继续承诺 SUPPORTED。
