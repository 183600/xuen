**本轮最重要的核实结论**：泛化不是模糊目标，而是一个**精确的实验设计**——32 任务 × 5 轴 × 每轴 2 次 = 320 次运行；每个「任务×轴」细胞恰好 2 次运行，因而在榜单上**等权**。这把第 2 轮的「提升平均泛化」改写成一个可计算的**覆盖/分配问题**。

## 1. 直觉与动机（两个灵感的碰撞）

### 灵感 1（通用机器人 → 通用不是「装下 32 个任务」，而是「共享 + 条件化 + 不互相拖累」）

直觉：赛题是字面意义上的「通才模型赛道」（F23）——一个模型、32 个任务、禁止混用多模型。多数队伍的默认理解是「把所有数据喂进一个大模型 = 通用」。但通用系统失败的主因通常不是数据不够，而是**任务在共享参数里互相竞争**：32 个任务共享同一套动作头与视觉表征，任务 A 的梯度会把任务 B 已学到的技能推走。真正的通用性应表现为**共享技能流形 + 指令条件化**：32 个任务其实共用一套很小的技能词表（接近、抓取、放置、插入、倾倒、折叠、拉拉链……），通才应当学「同一套技能在不同物体/指令下的绑定」，而不是 32 个互不相干的策略。它的可测症状就是**任务干扰**：通才相对「每任务专家」掉了多少。

### 灵感 2（泛化能力 → 泛化不是标量，是 32×5 = 160 个等权分数细胞）

直觉：手册把泛化拆成 5 条正交轴，每轴恰好 2/10（F20）。于是「泛化能力」可以写成一个 32×5 的矩阵，**每个细胞在榜单上权重完全相同（1/160 ≈ 0.625 个百分点）**。这带来两个反直觉结论：(a) 应该优先去填「零细胞」，而不是打磨已经很高的细胞——把一格从 0 翻到 1 的收益，是把一格从 0.9 打磨到 1.0 的 10 倍；(b) 成功率是主排序、步骤分只是平局判据（F20），所以**任何以牺牲成功率为代价换步骤分的优化都是负收益**。第 2 轮的「数据引擎」提供了原料，本轮要回答的是「原料往哪 160 个格子里投」。

### 两者统一

通用机器人回答「模型内部怎么组织」（共享表征 + 指令条件化 + 抑制任务干扰），泛化能力回答「分数长在哪些格子上」（5 轴 160 细胞的等权矩阵）。第 2 轮的数据引擎回答「原料从哪来」。三者合起来：**本轮把「数据量竞赛」升级为「数据在 160 细胞上的定向配置 + 表征对 5 轴结构的对齐」**。这也修正第 2 轮的一个过强论断：榜单是平均分，弱任务只是线性拖累（一个任务全零 = 3.125 个百分点），并非「支配」全局。

## 2. 严谨定义

### 2.1 泛化分数细胞图（Score-Cell Map）

设任务集 \(T\)（|T|=32），泛化轴集 \(A=\{\text{pos},\text{dis},\text{bg},\text{novel},\text{human}\}\)（|A|=5），每格运行次数 \(m=2\)。令 \(X_{t,a,r}\in\{0,1\}\) 为任务 \(t\)、轴 \(a\)、第 \(r\) 次运行的成功指示。则任务 \(t\) 的成功率与榜单主指标为

\[
S_t=\frac{1}{10}\sum_{a\in A}\sum_{r=1}^{2}X_{t,a,r}=\frac{1}{5}\sum_{a\in A}\bar X_{t,a},\qquad
L=\frac{1}{32}\sum_{t\in T}S_t=\frac{1}{160}\sum_{t\in T}\sum_{a\in A}\bar X_{t,a},
\]

其中 \(\bar X_{t,a}=\frac12\sum_r X_{t,a,r}\in\{0,\tfrac12,1\}\)。因此**每个 (t,a) 细胞权重恰为 1/160**。步骤分 \(P_{t,a,r}\in[0,100]\) 仅在 \(L\) 平局时按总平均步骤分比较。推论：(i) 单格成功翻转的榜单增益 = 0.625 个百分点；(ii) 单任务全零 = 5 格 = 3.125 个百分点；(iii) 步骤分优化的价值严格低于成功率，除非不损失成功率。

### 2.2 通用性 = 任务干扰最小化

对任务 \(t\)，令 \(S_t^{\text{spec}}\) 为离线「每任务专家」的成功率（**仅作诊断，绝不提交**，以守住单模型边界），\(S_t^{\text{gen}}\) 为通才的成功率。定义任务干扰

\[
I_t=S_t^{\text{spec}}-S_t^{\text{gen}}\ge 0,\qquad G=\frac{1}{32}\sum_{t\in T}I_t .
\]

\(G\) 是「通用性代价」：通才相对专家的平均掉分。通用机器人的目标不是把 \(G\) 压到 0（不现实），而是**识别 \(I_t\) 大的任务并定向缓解**（共享表征冲突、数据不足、或技能词表缺失）。专家的作用只是给每格一个上界估计，帮助判断「这格是模型不行，还是任务本身难」。

### 2.3 五轴的结构三分：不变 / 等变 / 重规划

把 5 轴按「策略应如何响应」分成三类，而不是一视同仁地做数据增广：

1. ** nuisance 不变（bg, dis）**：背景与干扰物变换不应改变最优动作，\(p(a^\*\!\mid do(\text{nuisance}))=p(a^\*)\)。对应**不变性正则**。
2. **位置等变（pos）**：对「目标可自由平移」的任务子集 \(E\subseteq T\)，场景刚性平移 \(\tau_\Delta\) 应使最优动作平移，\(\pi(\tau_\Delta o)=T_\Delta\pi(o)\)，其中 \(T_\Delta\) 只平移末端位姿的 xyz。**关键洞察：只有选 `ee` 控制空间时这个等变才是精确的**——关节角与笛卡尔平移是非线性关系；`ee` 空间给出一个免费的、无需新标签的等变监督。
3. **语义绑定（novel）与重规划（human）**：未见物品需要把新物体绑定到已会技能（检索/affordance 迁移）；人为干扰会**临时改变物体位置**（F20），因此是 POMDP 的外生状态突变，需要「检测发散 → 重新定位 → 从新状态重规划」，而不是「暂停后继续旧 chunk」。

### 2.4 预算分配是一个子模背包

用离线探针估计 \(\hat p_{t,a}\)，定义空格余量 \(H_{t,a}=1-\hat p_{t,a}\) 与轴杠杆 \(\Lambda_a=\frac1{32}\sum_t H_{t,a}\)。干预 \(e\) 在细胞上的增益为 \(\Delta_{e,t,a}=\hat p'_{t,a}-\hat p_{t,a}\)，期望榜单增益 \(=\frac1{160}\sum_{t,a}\Delta_{e,t,a}\)。在预算 \(B\) 下求解

\[
\max_{E}\ \frac1{160}\sum_{e\in E}\sum_{t,a}\Delta_{e,t,a}\quad\text{s.t.}\ \sum_{e\in E}\text{cost}(e)\le B .
\]

若 \(\Delta\) 边际递减（同一轴/同一任务的干预会重叠），目标近似子模，贪心给出 \(1-1/e\) 近似。这为 I8 的分级消融提供了**明确的排序准则**：先投「高余量 × 高可干预性」的格子。

## 3. 对第 2 轮痛点的增量修订

- **P2（泛化缺口）**：从「单一缺口」细化为 160 个异质细胞；难度不均匀——背景/位置最可离线模拟，人为干扰/未见物品方差最大且最难模拟。新增 **P9（离线可估性偏差）**：我们倾向优化「能模拟的轴」，而非「真正高方差的轴」。
- **P1（最弱任务支配）**：修正第 2 轮的过强表述。榜单是平均分，弱任务是线性拖累（一个任务全零 3.125 个百分点），不是「支配」；真正该盯的是**零细胞**与**整任务塌陷**，而非「最弱任务」这一模糊概念。
- **P3/P5（人为干扰/时间）**：F20 确认每任务 10 次、单次 180s 超时；人为干扰轴占 20% 且包含「临时改变物体位置」——I4 必须从「暂停-续做」升级为「发散检测-重定位-重规划」。
- **P6（部署）**：F22 补充 N 台机器人随机顺序、端口数必须等于 N、每端口状态隔离；I6 的隔离设计得到官方接口背书。
- **P8（示教质量）**：保留；与 I2 v3 的质量加权合并。
- **新增 P9（离线可估性偏差）**：见上，本轮最大风险来源。

## 4. 研究问题（本轮立项 Q9–Q11，Q1–Q8 保留）

- **Q9（细胞级分配）**：如何用离线探针估计 32×5 的成功矩阵，并区分「结构性零细胞」（能力缺失）与「随机性零细胞」（方差）？分配器在估计误差下的鲁棒性如何？
- **Q10（任务干扰）**：在单模型约束下，指令条件化 + 共享技能表征能否把 \(G\) 压到低于朴素多任务 SFT？哪些任务的 \(I_t\) 最大，原因是什么（数据、表征冲突、技能缺失）？
- **Q11（等变有效性）**：对哪些任务子集 \(E\) 任务平移等变在物理上成立？强制等变能否提升位置轴而不损伤固定夹具任务（如插网线/插充电器）？

## 5. 设计原则（新增 PR6，其余保留）

- **PR6 轴结构对齐律**：每个训练干预必须声明它作用于哪条泛化轴、以何种机制（不变/等变/重规划/语义绑定）；无法映射到 5 轴的干预默认降权。与 PR1（决策）、PR5（数据）互补，PR6 管**表征与训练目标**。
- **PR7 成功率优先律**：任何优化若可能降低成功率、只为提升步骤分，默认拒绝——因为步骤分只是平局判据（F20）。

## 0. 创新点清单（每点：动机 / 与现有方案差异 / 技术可行性 / 所需资源 / 落地步骤 / 风险）

### I1 v3 考纲校准五轴增广引擎 ★★★★★
- **动机**：计分的 320 次真机评测每次都在 5 轴上偏离训练分布（P2）；且 5 轴每种恰好 2/10（F20），增广应定向到高余量细胞，而非均匀放量。
- **本轮深化（通用机器人 × 泛化能力）**：
  1. **按细胞余量定向**：由 I10 的 160 细胞图给出每轴平均余量 \(\Lambda_a\)，增广算力按 \(\Lambda_a\) 分配，不再「五轴平均用力」。
  2. **位置轴改为等变标签**：放弃第 2 轮「像素重拼接 + 原始动作」的不一致做法，改为「场景平移 + ee 动作标签同步平移」（与 I11 共用实现），并用 IK 可达性 + 碰撞检查过滤物理不可行的 \(\Delta\)。
  3. **考纲卡 2.0**：每任务维护 5 轴的具体参数区间与官方示例锚点；背景/干扰物按考纲放量，未见物品按「同类不同外观」构造。
- **与现有方案差异**：直接 SFT 用标称数据；盲目增广用无校准随机化；本点用 160 细胞余量 + 5 轴结构（不变/等变/重规划）决定「增什么、增多少」。
- **技术可行性**：高。考纲卡半自动构建（LLM 解析 wiki + 人工校对，约 10 分钟/任务 × 32）；等变增广复用 I11。
- **所需资源**：分割/inpainting 1×24GB GPU（官方单卡即可，F11）；磁盘同 v1.0。
- **落地步骤**：①32 张考纲卡；②I10 首版细胞图 → 定轴预算；③背景/干扰物放量；④位置等变（仅 \(E\) 子集）+ 可达性过滤；⑤剂量-响应 L0 找饱和点；⑥轴间交互 2 档析因。
- **风险**：考纲卡与真实评测仍有偏差（缓解：单任务通道抽测 + 示例截图对齐）；位置等变对固定夹具任务不成立（缓解：\(E\) 掩码，见 I11）；像素增广产生物理不可行场景（缓解：IK/碰撞过滤 + L0 不可行动作占比 >5% 即降级）。

### I2 v3 数据引擎 2.0：细胞驱动的孪生迁移 + 加权共训 ★★★★
- **动机**：单模型平均分受零细胞与弱任务拖累；示教语料与质量双重浪费（P8）。
- **本轮深化（通用机器人）**：
  1. **下载由余量驱动**：不再「孪生子集 ≈1–2TB 全下」，而是只下载能映射到 I10 零/低细胞的孪生对（PR5）；其余远任务不入训。
  2. **官方 loader 加权 patch**：族级权重——32 考题全量 + 定向孪生半权重 + 远任务 ≤5%（修 F11 的 weight 不生效）。
  3. **负迁移哨兵**：每个孪生家族保留小规模 nominal + 对应轴探针；共训后若该家族探针退步，自动降权/裁剪该孪生对。
  4. **质量加权**：进度效率、平滑度、成功裕度三项合成 per-episode 权重，剪最差 10%。
- **与现有方案差异**：均匀混训把容量浪费在已会任务与无关语料；本点先诊断（I10）再定向（孪生）再受控（权重 + 哨兵）。
- **技术可行性**：高（LoRA/frozen-VLM 单卡起步，F11）。
- **所需资源**：定向孪生 ≈0.5–1TB（较 v2 的 1–2TB 下修）+ 32 任务 ≈2TB；训练 1×24GB 起步。
- **落地步骤**：①孪生表 + 细胞映射；②下载定向子集；③loader patch + batch 频率单测；④首轮共训；⑤哨兵探针 → 放量或裁剪。
- **风险**：负迁移（孪生动态相反，如 ZipUp/Unzip）——哨兵 + 低权重起步；相机配置不一致——先抽样核对 4 相机命名/分辨率。

### I3 接触任务族关键点视觉伺服回退 ★★★★（维持）
- 六要素同 v1.0：通用 chunk 策略负责接近段、几何伺服负责接触段，同一策略服务内混合推理（PR2 边界待书面确认，最大前提）；`ee` 控制空间 + per-step 调用天然支持；开放词汇检测零训练起步；触发滞回 + 低置信回退。

### I4 v3 人为干扰感知与重规划 ★★★★★（大升级）
- **动机**：人为干扰轴占 **20%**（F20 每种泛化 2/10），且官方明确包含「临时改变物体位置」——这不是「暂停后继续旧动作」能解决的，而是外生状态突变下的重规划问题。
- **本轮深化（通用机器人 × 泛化能力）**：
  1. **安全层（PR3）**：手部检测触发降速/停持；停持动作在界内平滑。
  2. **状态发散检测**：用「上一 chunk 执行后的预测状态」与「当前观测状态」的加权距离 \(d_t\) 做干预判别；\(d_t>\theta\) 立即作废剩余 chunk。
  3. **重定位 + 重规划**：重新检测任务物体与目标、更新 belief，从**当前真实状态**重新查询策略（清空过期历史），而不是续做旧 chunk。
  4. **恢复滞回**：手离开且状态稳定 k 帧后才恢复，避免抖动。
- **与现有方案差异**：常见做法只做「人手检测 → 停 → 继续」；本点把人为干扰当成状态估计失效，强制重定位与重规划。
- **技术可行性**：高。手部检测 + 距离阈值 + 重定位都是现成视觉组件；无需新模型。
- **所需资源**：视觉检测 + 状态机 1 人周；离线回放测试集（人为扰动片段）1 人周。
- **落地步骤**：①手部安全层；②发散检测阈值标定；③重定位/重规划接线；④离线回放（含物体被移动）；⑤单任务通道 A/B。
- **风险**：误触发（正常运动被判为干扰）→ 频繁重规划反而降成功率（缓解：双阈值 + 滞回 + 只在高置信时作废 chunk）；重定位误差传播（缓解：多相机一致性 + 失败回退到保守重试）。

### I5 非标称示教合成 + 得分点对齐恢复 ★★★★（维持 v2）
- **动机**：步骤分为逐任务得分点制（F17，每任务满分 100）；超时仍计步骤分（F20）；数据集全成功、无失败示教（P8）。

- 技术方案同 v2：扰动重放 / 跨段缝合 / WMA-0 续写（缓）/ 得分点里程碑自动过滤；进度头改得分点监督。
- **风险**：合成示教与真实偏离分布失配（缓解：扰动幅度取自考纲卡）；里程碑检测误差（缓解：置信门控 + 人工抽检 5%）。

### I6 确定性低延迟部署服务 ★★★★（维持）

- **资产去向**：WMA-0 仿真模式（F15）转为 I5 的合成数据引擎（离线、不计延迟）。

### I8 v3 评测运营闭环 + 分级消融注册表 ★★★★★
- **动机**：真机通道稀缺 + 待验证组合爆炸（P7）+ 离线可估性偏差（P9）。
- **本轮深化（消融实验）**：以 **160 细胞矩阵**为唯一中心对象——
  - **L0 in-silico**：对每个 (t,a) 用考纲轴偏移构造探针，输出细胞级成功率估计 \(\hat p_{t,a}\) 与代理指标（Δprog/Δact/Δkp）；免费无限次。
  - **L1 部分析因**：2^(k-p) 筛主效应；排序用 I10 的「期望榜单增益/成本」。
  - **L2 真机确认**：只测 top 2–3 干预；每干预 ≥2 任务 × 各 2 次。
  - **按轴校准注册表**：记录每次「离线预测 vs 真机实测」，**按 5 轴分别**算 Spearman；某轴相关性 >0.6 后，该轴的离线估计才可单独准入 L2。这是对 P9 的直接对冲。
- **技术可行性**：高（L0 纯离线）。
- **所需资源**：探针 + 指标 1 人周；注册表 = 表格 + 脚本。
- **落地步骤**：①探针集构建；②细胞矩阵 + 注册表 schema；③首用例 = I2 孪生家族；④按轴校准复盘。
- **风险**：某些轴（human/novel）真机样本太少，相关性建立慢（缓解：先用历史对齐点回填 + 把这两轴的真机预算优先给 L2）。

### I9 v2 reset 期检索类比迁移 ★★★★
- **动机**：未见物品轴占 20%（F20）；纯参数化泛化对新外观方差大。
- **本轮深化（通用机器人）**：
  1. **干扰物鲁棒的目标 grounding**：先用「指令 × 物体嵌入」对检测到的所有物体打分，取 argmax 并检查 margin；歧义时**不注入先验**，避免干扰物劫持检索。
  2. **affordance 迁移而非动作复制**：检索 k 个近邻物体，聚合其**抓取 affordance**（抓取类型、接近向量、开度），而非直接复制原始动作参数；对同类不同外观更稳健。
  3. **软先验 + 距离门控**：超阈值退回无先验；L0 先验证不伤标称场景。
- **与现有方案差异**：纯通才靠训练分布平均化；本点用 reset 期一次检索（F18）把新物体绑定到已会技能，零权重更新。
- **技术可行性**：中-高。嵌入库离线构建；reset 期 <1s；episode 内零额外每步开销（缓存于 episode 状态）。
- **所需资源**：嵌入 1×GPU 日 + FAISS；1 人周工程。
- **落地步骤**：①目标 grounding；②affordance 库；③索引；④reset 检索 + 软注入；⑤L0 未见轴 + 干扰物测试；⑥真机抽测。
- **风险**：误检索伤原任务（缓解：margin 门控 + 软偏置 + L0）；嵌入对同类不同外观不敏感（缓解：几何描述词 + DINOv2 patch 池化）；合规性书面确认。

### I10 泛化分数细胞图与期望分数分配器（新） ★★★★★
- **直觉**：榜单是 32×5=160 个等权细胞（每格 1/160），所以「往哪投人/算力」可以算出来，而不是靠感觉。
- **严谨定义**：见想法区 §2.1/§2.4；目标为子模背包，贪心 \(1-1/e\)。
- **动机**：第 2 轮的分级消融缺少统一排序准则；本轮用「期望榜单增益/成本」统一 L0/L1/L2。
- **与现有方案差异**：多数队伍按「任务」或「模块」排优先级；本点按**细胞级期望增益**排序，并显式区分成功率（主）与步骤分（平局）。
- **技术可行性**：高。核心是离线探针 + 表格 + 贪心。
- **所需资源**：1 人周；复用 I1 增广器与 I8 注册表。
- **落地步骤**：①定义 160 细胞探针集；②估 \(\hat p_{t,a}\)；③算轴杠杆 \(\Lambda_a\)；④对候选干预估 \(\Delta\)；⑤贪心分配；⑥真机回填校准。
- **风险**：离线估计偏差（P9）导致错配——用 I8 的按轴校准 + 对 human/novel 保留人工判断。

### I11 轴结构不变/等变训练（新） ★★★★
- **直觉**：泛化不是「见更多数据」，而是「对 nuisance 不变、对任务定义量等变」。背景/干扰物是 nuisance（应不变），位置是任务定义量（应等变），而且 `ee` 控制空间让平移等变有精确标签。
- **严谨定义**：nuisance 不变 \(p(a^\*|do(n))\) 恒定；位置等变 \(\pi(\tau_\Delta o)=T_\Delta\pi(o)\)，仅在任务子集 \(E\)（无固定夹具、平移后 IK 可达且无碰撞）上成立。
- **与现有方案差异**：数据增广只改输入分布；本点在**训练目标**里加不变/等变正则，直接塑形表征，成本低、针对性强。
- **技术可行性**：中。需成对视图（显存约 2×，可用 EMA teacher / 梯度累积缓解）；等变需场景平移渲染与可达性过滤。
- **所需资源**：1×24GB（小 batch + EMA）；1–2 人周；复用 I1 增广器。
- **落地步骤**：①确定 \(E\) 子集；②实现 \(\tau_\Delta\) 与 \(T_\Delta\)；③不变正则（VICReg/EMA 防坍缩）；④等变正则（一致性 + 监督）；⑤消融 \(\lambda\)；⑥验证不伤固定夹具任务。
- **风险**：不变正则坍缩（缓解：方差/协方差项 + 非对称 stop-grad）；等变在固定夹具任务上错误（缓解：\(E\) 掩码）；显存超预算（缓解：小 batch/累积）。

### 1.1 160 细胞图与分配器（I10）

```python
AXES = ["pos", "dis", "bg", "novel", "human"]   # 每种 2/10 → 每轴权重 1/5
W_CELL = 1.0 / 160.0                             # 32*5 等权

def cell_matrix(model, probes):
    # probes[(t, a)] = 该 (任务, 轴) 的离线探针 episode 列表
    return {(t, a): estimate_success(model, probes[(t, a)])
            for t in TASKS for a in AXES}

def axis_leverage(P):
    return {a: sum(1.0 - P[(t, a)] for t in TASKS) / len(TASKS) for a in AXES}

def allocate(P, interventions, budget):
    # interventions[e] = {"delta": {(t,a): dp}, "cost": c}
    # delta 非负、边际递减 → 近似子模；贪心 (1-1/e)
    chosen, spent = [], 0.0
    pool = list(interventions)
    while pool:
        best, best_gain = None, 0.0
        for e in pool:
            if spent + interventions[e]["cost"] > budget:
                continue
            gain = W_CELL * sum(interventions[e]["delta"].values())
            if gain / interventions[e]["cost"] > best_gain:
                best, best_gain = e, gain / interventions[e]["cost"]
        if best is None:
            break
        chosen.append(best); spent += interventions[best]["cost"]
        pool.remove(best)
        # 可选：更新剩余干预的 delta（扣除重叠），保持子模性
    return chosen, spent
```

### 1.2 轴结构不变/等变损失（I11）

```python
# 前提：metadata.control_space = "ee"；动作 a = [xyz(3), rpy(3), gripper]
def translate_pair(obs, action_ee, delta):
    obs2 = render_translated(obs, delta)          # 场景刚性平移（仿真/重渲染）
    a2 = action_ee.clone()
    a2[..., 0:3] += delta                          # 仅 xyz 平移；rpy/gripper 不变
    return obs2, a2

def axis_structured_loss(pi, o, a, task_in_E, delta, lam_inv=0.1, lam_eq=0.1):
    # 1) nuisance 不变：背景/干扰物变换不应改变动作
    o_n = nuisance_aug(o)                          # 换背景、插干扰物
    L_inv = mse(pi(o_n), pi(o).detach()) + vicreg(pi.features(o_n))

    # 2) 位置等变：仅 E 子集 + 可达/无碰撞的 delta
    L_eq = 0.0
    if task_in_E:
        o_t, a_t = translate_pair(o, a, delta)
        L_eq = (mse(pi(o_t), a_t)
                + mse(pi(o_t), T_delta(pi(o)).detach())) / 2

    return L_fm(pi, o, a) + lam_inv * L_inv + lam_eq * L_eq
```

class InterferenceGuard:
    def step(self, obs):
        if detect_hand(obs):                       # 安全优先（PR3）
            self.hand_recent = True
            return self.hold_smooth()

        d = self.state_divergence(obs)             # 当前状态 vs 上一 chunk 预测
        if d > THETA or self.hand_recent:
            self.invalidate_chunk()                # 作废剩余动作
            self.belief = relocalize(obs, self.instruction)
            self.hand_recent = detect_hand(obs)

        if not self.hand_recent and self.stable_for(k=3):
            return self.policy.get_action(obs, fresh=True)   # 从新状态重规划
        return self.hold_smooth()

## 2. 实验设计（160 细胞协议 v3）

| 级别 | 内容 | 通道/成本 | 通过判据 |
|---|---|---|---|
| L0 | 每 (t,a) 探针 → \(\hat p_{t,a}\)；I11 不变/等变消融；I4 干扰回放；I9 未见/干扰测试 | 离线（免费） | 细胞矩阵覆盖 160/160；I11 在 \(E\) 上位置轴 Δp>0 且固定夹具任务 Δp≥0；I4 干扰回放成功率↑ |
