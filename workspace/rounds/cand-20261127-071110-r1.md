### 第 1 轮灵感驱动研究记录 · 检索增强生成 × 自主导航（v25 → v26）

**灵感词**：检索增强生成（RAG）、自主导航

**直觉与动机**：
前几轮已把「感知-合规-能量-结构-力控-语义-重构-协同」逐层证书化，形成 SRC-USC v25 七证准入门。但这套链条仍把「知识」当作静态、可信、即时的输入：地图是先验的，法规是离线写入的，历史通行经验从不被质疑。真实自主导航中的知识恰恰来自**检索**——从先验地图、法规库、历史轨迹、操作手册、视觉语言模型常识中取回证据，再生成路线/子目标/可通行判断。RAG 带来能力，也带来四类新失效：**取不到**（漏检）、**取到却不支持结论**（幻觉式接地）、**知识已过期**（动态世界）、**来源被污染/循环引用**（不可信证据）。自主导航的独特优势是：它既是 RAG 的消费者，也是 RAG 的现场裁判——执行轨迹会产生反证，能反向淘汰错误知识。

核心洞见：**检索是知识证书的生成过程，导航是知识证书的消费与现场复核过程；RAG 在具身系统中的可信边界 = 覆盖 × 锚定 × 时效 × 溯源 × 闭环可执行**。这构成相对于文本 RAG「相关性-忠实性」二元的**具身检索五元组**。

**形式化目标**：
1. 定义检索覆盖证书（RCC）：对导航查询 q_t，在可交换性假设下 oracle 相关证据落入检索集的概率 ≥ 1-α；并对「可通行性/合法性/动力学」等任务必需证据面元做分层覆盖；OOD 查询显式拒证而非静默降级。
2. 定义检索锚定证书（RGC）：路线约束集 φ(π) 中每条安全关键约束 c_j 必须有非空支撑集 support(c_j) ⊆ D_t ∪ O_t，且非关键约束的「无支撑率」由 conformal risk control 控制在 γ_g 内；建立 c_j → 证据子集的可审计归因图。
3. 定义知识时效-溯源证书（KFPC）：每条被安全关键推理使用的知识 d_j 满足 TTL(κ_j) 或与当前观测的重合区差异 ≤ ε_fresh；来源图 P 必须是无环、带签名锚点、且路径信任度 ≥ ρ_min 的 DAG，禁止循环引用与未签名注入。
4. 定义导航证据闭环证书（NECC）：安全关键约束要么被机载观测直接验证，要么在承诺点前安排信息增益 IG ≥ IG_min 的主动感知/绕行动作；承诺前已执行前缀必须落在当前观测的保守包络内；执行产生的反证必须回写并退役知识。
5. 构建检索接地导航统一准入门（RGNUC / v26）：RGNUC = SRC-USC ∪ RCC ∪ RGC ∪ KFPC ∪ NECC，五证一体，且 Exec_v26 ⊆ Exec_v25。
6. 证明检索漏检、接地幻觉、知识过期、来源污染、闭环失败五类退化路径下的单调保持性。
7. 把「自主导航」从被验证对象提升为知识验证器：导航轨迹成为带证书的新语料，形成「检索→规划→执行→反证→语料更新」的闭环。

```python
# ============================================================
# IP-448 Retrieval Coverage Certificate (RCC) — 检索覆盖证书
# ============================================================
@dataclass
class RetrievalCoverageCertificate:
    """conformal 证据覆盖 + 任务面元分层覆盖 + OOD 查询拒证"""
    alpha: float = 0.05
    K: int = 10
    required_facets: tuple[str, ...] = ("traversability", "legality", "dynamics")
    calibrator: 'ConformalRetrievalCalibrator' = None
    ood_detector: 'OODDetector' = None
    ood_quantile: float = 0.99

    def verify(self, query: 'NavQuery', corpus: 'KnowledgeCorpus',
               retrieved: list['Doc']) -> tuple[bool, dict]:
        if self.calibrator is None or self.ood_detector is None:
            return False, {'reason': 'missing_calibration'}

        q_emb = query.embedding()
        # 1) OOD 门：查询不在校准流形上时，conformal 可交换性不成立，拒证
        if self.ood_detector.energy(q_emb) > self.ood_quantile:
            return False, {'reason': 'ood_query', 'energy': float(self.ood_detector.energy(q_emb))}

        # 2) conformal 覆盖：oracle 相关证据应落入预测集，且预测集被 Top-K 包含
        qhat = self.calibrator.threshold(self.alpha)
        pred_set = corpus.score_set(query, qhat)          # {d: s(q,d) <= qhat}
        coverage_ok = pred_set.issubset({d.id for d in retrieved[:self.K]})

        # 3) 面元覆盖：导航任务必需的证据类型至少各有一条
        facet_ok = all(
            any(d.facet == f for d in retrieved[:self.K])
            for f in self._required_facets(query)
        )
        return bool(coverage_ok and facet_ok), {
            'coverage_ok': coverage_ok,
            'facet_ok': facet_ok,
            'pred_size': len(pred_set),
            'qhat': float(qhat),
        }

    def _required_facets(self, query: 'NavQuery') -> tuple[str, ...]:
        # 任务可按目标类型追加面元（如搬运需承载/摩擦证据）
        return tuple(set(self.required_facets) | set(query.extra_facets))


# ============================================================
# IP-449 Retrieval Grounding Certificate (RGC) — 检索锚定证书
# ============================================================
@dataclass
class RetrievalGroundingCertificate:
    """路线约束逐条支撑 + 安全关键零容忍 + conformal 接地风险控制 + 归因图"""
    gamma_g: float = 0.10                 # 非关键约束允许无支撑率
    beta_g: float = 0.05                  # 风险控制置信水平
    verifier: 'EntailmentVerifier' = None
    risk_controller: 'ConformalRiskController' = None

    def verify(self, plan: 'NavigationPlan', docs: list['Doc'],
               obs: 'Observation') -> tuple[bool, dict]:
        if self.verifier is None or self.risk_controller is None:
            return False, {'reason': 'missing_verifier'}

        constraints = plan.route_constraints()          # [c_1..c_m]
        critical = [c for c in constraints if c.safety_critical]
        noncritical = [c for c in constraints if not c.safety_critical]

        attribution: dict[str, list[str]] = {}
        for c in constraints:
            attribution[c.id] = [
                d.id for d in docs
                if self.verifier.entails(c, d, obs) >= 0.5
            ]

        # 安全关键约束：必须逐条有支撑（零容忍），否则拒证
        critical_ok = all(len(attribution[c.id]) > 0 for c in critical)

        # 非关键约束：用离线校准的 conformal risk control 控制无支撑率
        unsupported = sum(1 for c in noncritical if not attribution[c.id])
        loss = unsupported / max(1, len(noncritical))
        lam_g = self.risk_controller.threshold(self.gamma_g, self.beta_g)
        noncritical_ok = loss <= lam_g

        return bool(critical_ok and noncritical_ok), {
            'critical_ok': critical_ok,
            'hallucination_rate': loss,
            'lambda_g': float(lam_g),
            'attribution': attribution,
        }


# ============================================================
# IP-450 Knowledge Freshness-Provenance Certificate (KFPC)
# ============================================================
@dataclass
class KnowledgeFreshnessProvenanceCertificate:
    """TTL + 时空重合差异 + 来源 DAG 锚定 + 签名链 + 信任折扣"""
    ttl_by_class: dict[str, float] = field(default_factory=lambda: {
        'dynamic': 10.0, 'semi_static': 3600.0, 'static': 1e9,
    })
    eps_fresh: float = 0.05               # 占体对称差/并集阈值
    rho_min: float = 0.80
    decay_lambda: float = 1e-3
    anchors: set[str] = field(default_factory=set)

    def verify(self, t: float, docs: list['Doc'],
               obs: 'Observation') -> tuple[bool, dict]:
        fresh_ok, quarantined = True, []

        for d in docs:
            # 1) 年龄硬门
            age = t - d.timestamp
            if age > self.ttl_by_class[d.cls]:
                fresh_ok = False
                quarantined.append(d.id)
                continue

            # 2) 重合区变化散度：能观测到的部分必须与知识一致
            overlap = d.spatial_extent.intersection(obs.footprint)
            if overlap.area > 0:
                div = symmetric_difference(
                    d.claim.occupancy.restrict(overlap),
                    obs.occupancy.restrict(overlap),
                )
                if div > self.eps_fresh:
                    fresh_ok = False
                    quarantined.append(d.id)
                    continue

            # 3) 不可观测部分：时效折扣后仍须高于信任门，否则不得用于安全关键推理
            if overlap.area == 0:
                rho_eff = d.trust * math.exp(-self.decay_lambda * age)
                if d.safety_critical and rho_eff < self.rho_min:
                    fresh_ok = False
                    quarantined.append(d.id)

        prov_ok, prov_info = self._provenance_dag_ok(docs)
        return bool(fresh_ok and prov_ok), {
            'fresh_ok': fresh_ok,
            'provenance_ok': prov_ok,
            'quarantined': quarantined,
            **prov_info,
        }

    def _provenance_dag_ok(self, docs: list['Doc']) -> tuple[bool, dict]:
        # 来源图 P 必须无环；每条安全关键证据须有一条到签名锚点的可信路径
        node = {d.id: d for d in docs}
        has_cycle = detect_cycle([(d.id, p) for d in docs for p in d.cites])
        if has_cycle:
            return False, {'reason': 'cyclic_provenance'}

        for d in docs:
            if not d.safety_critical:
                continue
            if not self._has_anchored_path(d, node):
                return False, {'reason': 'unanchored_critical_doc', 'doc': d.id}
            if not verify_signature_chain(d):
                return False, {'reason': 'bad_signature', 'doc': d.id}
        return True, {'reason': 'ok'}

    def _has_anchored_path(self, d: 'Doc', node: dict) -> bool:
        # DFS：路径上所有节点信任度 >= rho_min，终点属于锚点集合
        stack, seen = [(d.id, d.trust)], set()
        while stack:
            cur, path_trust = stack.pop()
            if cur in seen:
                continue
            seen.add(cur)
            if cur in self.anchors:
                return path_trust >= self.rho_min
            for p in node[cur].cites:
                stack.append((p, min(path_trust, node[p].trust)))
        return False

# IP-451 Navigation Evidence Closure Certificate (NECC)
# ============================================================
@dataclass
class NavigationEvidenceClosureCertificate:
    """观测验证 / 主动信息增益 / 承诺前缀包络 / 反证回写"""
    eps_pred: float = 0.10
    ig_min: float = 0.50
    commit_horizon: int = 30

    def verify(self, plan: 'NavigationPlan', docs: list['Doc'],
               obs: 'Observation', info_actions: list['InfoAction']) -> tuple[bool, dict]:
        # 1) 反证回写：已执行段若与知识预测不符，立即退役该知识并拒证
        for d in docs:
            if obs.covers(d.spatial_extent):
                residual = obs.residual(d)
                if residual > self.eps_pred:
                    self._retire(d, reason='counterevidence', residual=residual)
                    return False, {'reason': 'counterevidence', 'doc': d.id,
                                   'residual': float(residual)}

        # 2) 安全关键约束：要么已被观测验证，要么安排承诺前主动验证
        critical = [c for c in plan.route_constraints() if c.safety_critical]
        unresolved = [c for c in critical if not obs.verifies(c)]

        if not unresolved:
            mode = 'observed'
        else:
            feasible = [
                a for a in info_actions
                if a.finishes_before(plan.commit_time(self.commit_horizon))
            ]
            best = max(feasible, key=lambda a: a.expected_info_gain(), default=None)
            if best is None or best.expected_info_gain() < self.ig_min:
                return False, {'reason': 'unresolvable_before_commit',
                               'unresolved': [c.id for c in unresolved]}
            mode = 'active_evidence'

        # 3) 承诺前执行前缀必须落在保守包络内
        prefix_ok = plan.prefix_within(obs.conservative_envelope(), self.commit_horizon)
        return bool(prefix_ok), {'mode': mode, 'prefix_ok': prefix_ok}

    def _retire(self, d: 'Doc', **evidence):
        d.retired = True
        d.retire_evidence = evidence
        # 同时向语料库登记反证，供离线再校准
        self.counterevidence_log.append((d.id, evidence))

# IP-452 RGNUC — 检索接地导航统一准入门 v26
# ============================================================
@dataclass
class RetrievalGroundedNavigationUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'  # v25 七证
    rcc: RetrievalCoverageCertificate
    rgc: RetrievalGroundingCertificate
    kfpc: KnowledgeFreshnessProvenanceCertificate
    necc: NavigationEvidenceClosureCertificate

    def admits(self, plan: 'NavigationPlan', query: 'NavQuery',
               corpus: 'KnowledgeCorpus', retrieved: list['Doc'],
               obs: 'Observation', info_actions: list['InfoAction']) -> tuple[bool, dict]:
        trace: dict[str, bool] = {}

        # 1) v25 七证（单机 USMC + 语义 + 重构 + 协同）
        trace['src_usc'] = self.src_usc.admits_plan(plan)
        if not trace['src_usc']:
            return False, trace

        # 2) 检索覆盖
        trace['rcc'], info_rcc = self.rcc.verify(query, corpus, retrieved)
        if not trace['rcc']:
            return False, {**trace, 'detail': info_rcc}

        # 3) 检索锚定
        trace['rgc'], info_rgc = self.rgc.verify(plan, retrieved, obs)
        if not trace['rgc']:
            return False, {**trace, 'detail': info_rgc}

        # 4) 时效-溯源
        trace['kfpc'], info_kfpc = self.kfpc.verify(query.t, retrieved, obs)
        if not trace['kfpc']:
            return False, {**trace, 'detail': info_kfpc}

        # 5) 导航闭环证据
        trace['necc'], info_necc = self.necc.verify(plan, retrieved, obs, info_actions)
        if not trace['necc']:
            return False, {**trace, 'detail': info_necc}

        return True, {**trace, 'detail': {
            'rcc': info_rcc, 'rgc': info_rgc,
            'kfpc': info_kfpc, 'necc': info_necc,
        }}

# 扩展：端到端「检索-规划-执行-反证」流水线
# ============================================================
class RetrievalGroundedNavigationPipeline:
    def __init__(self, config: dict):
        self.rgnuc = RetrievalGroundedNavigationUnifiedCertificate(
            src_usc=config['src_usc'],
            rcc=RetrievalCoverageCertificate(
                alpha=config['alpha'],
                K=config['K'],
                calibrator=config['retrieval_calibrator'],
                ood_detector=config['ood_detector'],
            ),
            rgc=RetrievalGroundingCertificate(
                gamma_g=config['gamma_g'],
                beta_g=config['beta_g'],
                verifier=config['entailment_verifier'],
                risk_controller=config['risk_controller'],
            ),
            kfpc=KnowledgeFreshnessProvenanceCertificate(
                eps_fresh=config['eps_fresh'],
                rho_min=config['rho_min'],
                anchors=config['anchors'],
            ),
            necc=NavigationEvidenceClosureCertificate(
                eps_pred=config['eps_pred'],
                ig_min=config['ig_min'],
                commit_horizon=config['commit_horizon'],
            ),
        )
        self.ipam.register_module("rcc", ["IP-448"],
            ["conformal_retrieval_coverage", "facet_coverage", "ood_rejection"])
        self.ipam.register_module("rgc", ["IP-449"],
            ["constraint_support", "grounding_risk_control", "evidence_attribution"])
        self.ipam.register_module("kfpc", ["IP-450"],
            ["ttl_divergence_freshness", "anchored_provenance_dag"])
        self.ipam.register_module("necc", ["IP-451"],
            ["observation_verification", "active_evidence_gain", "counterevidence_retirement"])
        self.ipam.register_module("rgnuc", ["IP-452"],
            ["embodied_rag_pentad_gate", "retrieval_grounded_monotonic_chain"])

    def step(self, query: 'NavQuery', corpus: 'KnowledgeCorpus',
             obs: 'Observation', planner: 'Planner',
             info_actions: list['InfoAction']) -> tuple[bool, dict]:
        # 1) 检索（带面元分层与重排）
        retrieved = corpus.retrieve(query, K=self.rgnuc.rcc.K)
        # 2) 生成候选计划（检索增强）
        plan = planner.propose(query, retrieved, obs)
        # 3) 五证准入
        admitted, trace = self.rgnuc.admits(plan, query, corpus, retrieved, obs, info_actions)
        if not admitted:
            return False, {'trace': trace, 'plan': None}

        # 4) 执行承诺前缀；若中途产生反证则回写并重规划
        for seg in plan.prefix_segments(self.rgnuc.necc.commit_horizon):
            obs_new = self.execute(seg)
            if self.detect_counterevidence(retrieved, obs_new):
                self.update_corpus_with_counterevidence(retrieved, obs_new)
                return False, {'trace': trace, 'reason': 'runtime_counterevidence'}
        # 5) 成功执行片段作为带证书的新语料
        self.update_corpus_with_verified_episode(plan, obs, trace)
        return True, {'trace': trace, 'plan': plan}


# 辅助函数
def symmetric_difference(occ_a, occ_b) -> float:
    inter = (occ_a & occ_b).area
    union = (occ_a | occ_b).area
    return 0.0 if union == 0 else 1.0 - inter / union

def detect_cycle(edges: list[tuple[str, str]]) -> bool:
    graph = defaultdict(list)
    for u, v in edges:
        graph[u].append(v)
    WHITE, GRAY, BLACK = 0, 1, 2
    color = defaultdict(int)
    def dfs(u):
        color[u] = GRAY
        for v in graph[u]:
            if color[v] == GRAY:
                return True
            if color[v] == WHITE and dfs(v):
                return True
        color[u] = BLACK
        return False
    return any(color[u] == WHITE and dfs(u) for u in list(graph))
```

## 3. 正确性论证（增量）

### 引理 13（检索覆盖证书的覆盖-面元-OOD 三重保证）
**陈述**：`RCC.verify(q,D)=True` ⟹ (1) 在校准可交换性成立时，oracle 相关证据落入检索集的边际概率 ≥1-α；(2) 任务必需证据面元均被覆盖；(3) 查询未触发 OOD 拒证。

**证明**：
1. 离线校准对相关对 (q_i,d_i) 计算非一致性分数 s(q,d)=1-cos(f(q),h_d)，取 q̂ 为 ⌈(n+1)(1-α)⌉/n 分位数。由 conformal prediction 的边际覆盖定理，P(d*∈C_ret(q))≥1-α。
2. `pred_set ⊆ retrieved[:K]` 强制检索结果包含完整预测集；面元检查保证导航所需的可通行、合法性、动力学证据至少各有一条，排除「只有语义相似但任务无关」的检索。
3. OOD 检测器在校准流形外触发拒证，避免在可交换性被破坏时错误宣称覆盖。因此证书是「条件性承诺」：可交换性成立才有效。
∎

### 引理 14（检索锚定证书的支撑-风险控制-归因三重保证）
**陈述**：`RGC.verify(π,D,O)=True` ⟹ (1) 每条安全关键约束 c_j 的 support(c_j)≠∅；(2) 非关键约束无支撑率 ≤λ_g，且 ℙ(loss≤γ_g)≥1-β_g；(3) 每条约束保留可审计的证据归因。

**证明**：
1. `critical_ok` 直接要求所有 safety_critical 约束的 attribution 非空，安全关键项零容忍。
2. 非关键项用 conformal risk control：在校准集上以无支撑率为损失，选取 λ_g 使测试风险 P(loss>γ_g)≤β_g（Angelopoulos et al., 2021）。证书检查 loss≤λ_g，从而以 1-β_g 置信满足风险上界。
3. attribution 字典逐条记录 c_j → {d.id}，任何被接受的约束都可反查到具体证据，支撑审计与事故复盘。
∎

### 引理 15（时效-溯源证书的 freshness-provenance 联合保证）
**陈述**：`KFPC.verify(t,D,O)=True` ⟹ 每条用于安全关键推理的知识 d 满足：(1) 未超过 TTL 且与可观测世界的占体差异 ≤ε_fresh，或不可观测时有效信任 ρ_eff≥ρ_min；(2) d 位于带签名锚点的无环来源 DAG 上，路径信任 ≥ρ_min。

**证明**：
1. 年龄硬门排除过期知识；对可观测重合区，占体对称差/并集 ≤ε_fresh 意味着知识声称与世界状态的变化有界；对不可观测区，指数时效折扣 ρ_eff 使长期未验证知识的信任单调下降，低于 ρ_min 即不得用于安全关键推理。
2. `_provenance_dag_ok` 先拒绝有环引用（防止「自己证明自己」），再要求每条安全关键证据存在到锚点的路径且路径最小信任 ≥ρ_min，并校验签名链。因此安全关键结论不可能建立在未签名注入或循环引用之上。
3. 不满足者进入 quarantine，而不是静默删除；保留证据以支持离线再校准与责任追踪。
∎

### 引理 16（导航闭环证书的执行验证-主动取证-前缀安全保证）
**陈述**：`NECC.verify(π,D,O,A)=True` ⟹ (1) 已执行段未发现与知识预测显著不符的反证；(2) 每条安全关键约束或被观测直接验证，或在承诺点前存在 IG≥IG_min 的可行信息动作；(3) 承诺前实际执行前缀落在保守包络 V_t 内。

**证明**：
1. 反证循环对任何被观测覆盖且 residual>ε_pred 的知识立即退役并拒证，阻断「带着错误知识继续执行」。
2. 若存在未验证安全关键约束，则必须在 info_actions 中找到一个在 commit_time 前完成且 IG≥IG_min 的动作；否则拒证。这保证机器人不会在关键未知下盲目承诺。
3. `prefix_within` 要求执行前缀的每个状态属于当前观测与已验证新鲜知识诱导的保守包络，避免「信息动作尚未完成就进入未验证区域」。
∎

### 引理 17（v26 单调退化链）
**陈述**：任意单点/组合失效下，`Exec_v26 ⊆ Exec_v25 ⊆ … ⊆ Exec_v18` 恒成立。

**证明**：RGNUC 的准入是 v25 准入与四个新证书过滤器的合取，合取只会缩小集合。逐条退化路径：
- 检索漏检/OOD → RCC 拒证 → 退回 v25：不使用外部知识，仅用机载感知与已验证语义地图做几何规划。
- 接地幻觉/无支撑约束 → RGC 拒证 → 丢弃无支撑约束并按保守包络重规划；安全关键无支撑则安全停机。
- 知识过期/来源污染 → KFPC 拒证 → 隔离文档、降级为 v25；安全关键知识不可替代时停机。
- 闭环失败/反证 → NECC 拒证 → 中止承诺前缀、回写反证、重规划；无法在承诺前取证则放弃当前路线。
- 组合失效取交集，仍为 v25 的子集。∎

### 定理（RGNUC v26 十四项准入门完备性）
**陈述**：对任意导航计划 π，`RGNUC.admits(π)=True` ⟺ π 同时满足：
(1) 物理接地安全（几何∧规范∧负信息∧能量∧差距），
(2) 云边版本一致性与统计覆盖承诺，
(3) 少样本适应后的 conformal 覆盖 ≥1-α，
(4) 核心模块专利保护完备且无侵权风险，
(5) 结构应力/能量/可制造性三重达标，
(6) 力控无源性/带宽/稳定性三重达标，
(7) 轻量化刚度/质量/屈曲三重达标，
(8) 语义覆盖/几何一致/开放词汇检索三重达标，
(9) 重构动力学/接口/证书传递三重达标，
(10) 协同一致/避障/纳什均衡三重达标，
(11) 检索证据覆盖/面元覆盖/OOD 拒证三重达标，
(12) 路线约束支撑/接地风险控制/证据归因三重达标，
(13) 知识时效/来源锚定/签名链三重达标，
(14) 观测验证/主动取证/承诺前缀包络三重达标。

**证明**：必要性由 `admit` 的十四个合取条件直接得到，任一条件失败即拒证，对应十四类风险之一未被缓解。充分性由引理 1–3、5–7、9–11、13–16 提供各层保证；引理 4、8、12、17 保证执行集随证书增加单调收缩，且检索层失效时能退回 v25 的保守规划或安全停机。因此 RGNUC 构成「单机物理 → 群体智能 → 外部知识 → 现场复核」的闭环。∎

## 6. 本轮最大风险（最终确认）

**一句话**：**RCC 的覆盖承诺依赖可交换性、KFPC 的溯源承诺依赖可信锚点，而开放世界中的分布漂移、语料投毒与遮挡区隐藏变化可能让四个证书「相互自洽地错」——机器人在承诺点前既无法在线证明校准分布未变，也无法证明其信任根未被攻破，于是 RGNUC 仍可能为一条语义过期或对抗性误接地的路线签发合格证；这是检索接地导航在本轮方案中无法仅靠自身证书消除的最大风险。**
