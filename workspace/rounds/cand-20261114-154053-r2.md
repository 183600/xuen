# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「地形适应」×「价值对齐」）

> R69 把不确定性一分为二（aleatoric / epistemic），并用「流匹配多模态策略 + 主动交互」去消解世界侧歧义：该看哪、该问谁、还能问什么。但它默认了一个更深的常量——**价值是固定的**。R69 的 VoI 只问「世界是什么样」，从不问「我们想要的到底是什么」；它的证据纪律能防住「回答被投毒」，却防不住**问题本身就把人引向某个答案**，也防不住**同一个动作在厨房、病房、废墟与社交场合里价值完全不同**。
>
> 本轮两个灵感正好补上这两块：
> - **地形适应**教给我们一件被机器人学验证过的事：面对变化的支撑面，控制器不是「重训整条策略」，而是**在线辨识地形 + 局部调整接触阻抗**；接触力（本体感受）比视觉（外感受）更难被骗。
> - **价值对齐**教给我们另一件事：价值不是一个全局标量，而是**上下文索引的偏好场**；对齐必须区分**不可协商的内核**与**可随情境适应的表层**，否则「适应」会变成「漂移」，甚至被反复微反馈温水煮青蛙。
>
> 核心命题：**把「价值」也当成一片会变的地形。** 用 τ 同时索引物理地形、社会语境与任务阶段；价值场分解为冻结的 `V_inv`（硬约束内核）与可适应的 `V_ctx(·;τ)`；用「价值阻抗」而非「重写 reward」来做局部对齐——可靠证据则柔顺、可疑或地形新颖则刚硬；用被动性（耗散）约束把价值漂移变成可证有界；用「本体感受式的揭示偏好」去校准「外感受式的陈述偏好」，而不是听见什么就信什么。命名 **TERRA-RAS**（Terrain-Embedded, Risk-bounded, Reflexive Alignment for Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我在什么地形上、按谁的价值、以多大的柔顺度去对齐**」——对齐不是一次训练出来的向量，而是一套随地形调刚柔、且永不越过内核的阻抗控制。

## 0. 直觉与动机

**灵感 1（地形适应 → 在线辨识 + 局部阻抗，而非全局重训）**
直觉：腿足机器人在碎石、沙地、冰面上不会把整条步态策略推倒重来；它先**估计地形类别与接触参数**，再只调脚步落点、关节刚度和阻抗。关键结构是两层：**慢的上下文辨识** + **快的局部顺应**。价值对齐应当同构：慢的 τ 辨识 + 快的 `V_ctx(·;τ)` 局部修正，而**不是**每次有人纠正就去重写整个 reward。R69 的交互是「问世界」，R70 把它扩展成「问世界 + 辨识价值地形」。

**灵感 2（本体感受 vs 外感受 → 揭示偏好校准陈述偏好）**
直觉：看地面（外感受）会被反光、纹理、对抗贴图骗；踩上去（本体感受/接触）难骗得多。价值侧有同构的双通道：**陈述偏好** s（语言、显式指令，像视觉，易被诱导与伪装）与**揭示偏好** r（修正动作、绕行、拒绝、使用行为，像接触力，较难伪装）。R69 的证据纪律要求「多源一致」，但没有说明**哪一源更该被信任**。R70 的答案是：用揭示去校准陈述；两者系统性冲突时，不更新价值表层，把冲突本身当成高价值查询目标。

**灵感 3（价值阻抗 → 刚柔随证据可靠性与地形新颖度变化）**
直觉：阻抗控制里，太硬会在不平地面失稳，太软会下陷打滑。价值空间同理：太刚（永不改）会在新语境里持续错位；太软（听谁改谁）会被奉承、投毒与社交工程牵着走。把反馈 u 看成作用在价值状态上的「力」，令 `\dot{\hat V}_ctx = −K_v ∇L_align`，其中 `K_v` 由证据源可靠性 ρ 与地形新颖度 N_τ 共同门控：**可靠 + 熟悉 → K_v 小（柔顺）；可疑 + 新颖 → K_v 大（刚硬、保守）**。这把「对齐」从离散的「听/不听」变成连续的、可调的柔顺度。

**灵感 4（被动性 → 反价值漂移的可证约束）**
直觉：阻抗控制的安全性来自无源/耗散（passivity），不是来自某个绝对位置。价值漂移最危险的不是一次大跳，而是**温水煮青蛙**：每次只挪一点点，累积越界。于是给价值更新加一条耗散不等式：反馈只能注入有限「能量」，不能无限泵高价值状态。由此得到**漂移有界**：累计漂移受总反馈能量控制；想推动任意远，就必须持续注入可检测的大能量。这把「价值不可漂移」从口号变成证书里的一行可计算量。

**灵感 5（内核/表层二分 → 对齐必须有「不可适应集」）**
直觉：不是所有价值都该随地形变。安全、诚实、不操纵、不伤害应当冻结为**硬约束内核** `V_inv`，以动作屏蔽（shield）方式执行，不参与任何加权折中；只有效率、礼貌距离、风险偏好、交互风格这类**表层** `V_ctx(·;τ)` 才可适应。没有这个二分，「地形自适应」会变成「在错误的地形上高效地漂移」。这也是对价值多元主义的工程回答：**核心规范不投票，情境偏好才投票。**

**灵感 6（适应即攻击面 → 必须同时交付威胁模型与证书）**
直觉：一旦系统会「按地形改价值」，就有了新的攻击面：**地形欺骗**（让感知误判为更安全地形以放宽包络）、**价值投毒**（假修正、假偏好、陈述/揭示冲突注入）、**奉承诱导**（sycophancy：顺着人说得越多、越容易被夸「对齐得好」）、**慢漂移**（微小反馈累积）。所以本轮必须同时交付：内核哈希与屏蔽、适应预算、被动性裕度、地形新颖度门控、非诱导查询，以及把这些写进证书 `J_TERRA`。否则 R70 不是对齐，而是给漂移发了一张「地形适应」的许可证。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（TERRA-RAS 总览）** `TERRA-RAS = (TCI, VFF, VIC, SPC, AQC, TCB, VDC, RAS-WM‡)`。四不变式：
(i) **价值内核零在线写**：`V_inv` 冻结，只可读、以硬屏蔽形式参与决策（把 R69 定义 276-i 的零学习写从「世界模型」扩展到「价值内核」）；
(ii) **适应预算**：每次表层更新 `‖ΔV_ctx‖ ≤ δ_v`、累计漂移 `ΔV_cum ≤ Δ_v`，且只有在 τ 发生经认证的变化点后才允许更新；
(iii) **安全单调**：任意 τ 下风险界不高于 R69 同 τ 界；未知/新颖地形退化为 R69/R68 包络，绝不因「适应」而扩大；
(iv) **查询纪律**：价值查询不得指向 `V_inv`；单次陈述偏好不得覆盖与行为证据的系统性冲突。

**定义 311（地形-价值上下文潜变量 τ）** `τ_t = (τ_phys, τ_soc, τ_task) ∈ 𝒯`。`τ_phys`：摩擦、坡度、可变形性、粗糙度；`τ_soc`：规范、角色、紧迫度、隐私语境；`τ_task`：任务阶段与运行域。后验 `p(τ|o_{≤t})` 由编码器 `g_φ` 在线滤波，`g_φ` 复用 R69 的 MTM trunk。要点：**τ 同时索引世界动力学与价值偏好**——同一个动作在不同 τ 下价值不同。

**定义 312（地形新颖度与变化点）** `N_τ(o) = −log p_train(τ̂(o))`（训练分布下密度）；变化点统计量用 CUSUM 或 Bayes 因子 `cp_t`。当 `N_τ > τ_novel` 或 `cp_t > τ_cp` 时进入「地形重识别」态，**暂停 `V_ctx` 更新**并收紧安全界。

**定义 313（价值场与分解）** 价值泛函 `V(c;τ)` 定义在后果 `c ∈ 𝒞`（轨迹 / 结果分布）上。分解
`V(c;τ) = V_inv(c) + V_ctx(c;τ)`，
其中 `V_inv` 为上下文无关的规范内核（安全、诚实、不操纵、不伤害），实现为**硬约束集 / 动作屏蔽**而非可加权项；`V_ctx` 为上下文相关表层偏好（效率、礼貌距离、风险偏好、交互风格）。「**价值地形**」即映射 `τ ↦ V_ctx(·;τ)`。

**定义 314（价值阻抗）** 把人类/环境反馈 `u_t` 视为作用在价值状态上的「力」。价值估计更新
`\dot{\hat V}_ctx = −K_v(τ, ρ_t) ∇_{\hat V} L_align(\hat V_ctx; evidence)`，
其中 `K_v ≻ 0` 为价值阻抗（compliance = `K_v^{-1}`），`ρ_t` 为证据源可靠性。**低阻抗（柔顺）= 愿意改；高阻抗（刚硬）= 保持保守**。阻抗由可靠性 ρ 与地形新颖度 `N_τ` 共同门控。

**定义 315（价值被动性）** 取存储函数 `S(V) = ½‖V_ctx − V_ctx^0‖²_{K_v^{-1}}`。要求更新满足耗散不等式
`S(V_{t+1}) − S(V_t) ≤ u_tᵀ ΔV_t − α‖ΔV_t‖²`，`α > 0`。
即反馈只能注入有限能量，不能无限泵高价值状态；违反则触发 VDC 冻结。这是「反温水煮青蛙」的可证形式。

**定义 316（陈述偏好 vs 揭示偏好）** 陈述偏好 `s_t`（语言回答 / 显式指令，对应 R69 的 `g_ask`）与揭示偏好 `r_t`（修正、选择、绕行、拒绝、使用行为）。类比：`s_t` 是**外感受**（看得见、可伪装），`r_t` 是**本体感受 / 接触**（摸得到、较难伪装）。二者作为潜在 `V_τ` 的两路含噪观测，可靠性 `ρ_s, ρ_r` 由校准与地形决定。分歧 `D_t = d(s_t, r_t)`；当 `D_t > θ_D` 且无正交证据 ⇒ **不更新 `V_ctx`**，标记为未消解价值不确定性，走 R69 保守兜底。

**定义 317（对齐 VoI 与查询控制器 AQC）** 信息动作扩展为 `g = (g_gaze, g_probe, g_ask, g_val)`。对齐信息增益
`VoI_val(g) = H(V_ctx|o) − E_{y~p(·|g,o)}[H(V_ctx|o,y)]`。
选择 `g* = argmax [VoI_val(g) − c(g) − c_manip(g)]`，其中 `c_manip` 为诱导 / 操纵风险成本。约束：查询不得指向 `V_inv`；问句需非诱导（定义 318）；单次回答只作为似然、不能单独定案（继承 R69 定义 293-iii）。

**定义 318（非诱导查询）** 查询 q 的非诱导性用「措辞—答案」互信息定义：`L(q) = I(answer; wording(q) | V_τ)`；要求 `L(q) ≤ θ_L`。工程近似：同一问题的**正反成对反事实问法**取平均，以抵消措辞偏置。目标是不把答案空间预先压向某个价值。

**定义 319（地形条件化安全界）** 给定 τ 后验，安全风险界
`R(π; p(τ|o)) = CVaR_β[ R(π;τ) ]`，`τ ~ p(τ|o)`。
若新颖地形质量 `P(N_τ > τ_novel | o) > θ_novel`，则取 τ 的最坏情形并直接套 R69/R68 包络。**安全边界随 τ 变，但只能收紧不能放宽**：对任意 τ，`R_TERRA(τ) ≤ R_R69(τ)`。

**定义 320（不变内核屏蔽 IS）** 动作执行前，`V_inv` 以硬屏蔽 `a ∉ 𝒜_inv(τ)` 的形式过滤；任何 `V_ctx` 的排序都不能让动作越过屏蔽。屏蔽与 R69 的 C-RAS-WM 前缀认证**串联且屏蔽在前**：先过滤不可接受动作，再对剩余动作做认证。

**定义 321（价值漂移证书 VDC）** 记录内核哈希 `H(V_inv)`（必须不变）、累计漂移 `ΔV_cum = Σ_t d(V_ctx^{(t)}, V_ctx^{(0)})`、被动性裕度 `m_p = min_t(α‖ΔV_t‖² − [S_{t+1}−S_t − u_tᵀΔV_t])`、以及 τ 变化点日志。违反 `ΔV_cum ≤ Δ_v` 或 `m_p < 0` 或 `H` 变化 ⇒ 立即冻结适应、回滚到上一认证 `V_ctx`、升级审计。

**定义 322（地形相对对齐遗憾）** 不用单一全局 reward，而用
`Reg(π) = E_{τ~p} E_{c~π(·|τ)} [V_τ(c*_τ) − V_τ(c)]`，
`c*_τ = argmax_{c ∈ 𝒜_inv-safe} V_τ(c)`。并定义地形迁移差 `G = Reg(π | τ 迁移未适应) − Reg(π | τ 已知)`。这使「对齐」成为随地形变化的量，而非一次性分数。

**定义 323（威胁模型 ℰ_TERRA）** `ℰ_TERRA = ℰ_FLUID × ℰ_value × ℰ_terrain × ℰ_drift`：
- `ℰ_value`：奉承诱导（sycophancy）、假修正投毒、陈述/揭示冲突注入；
- `ℰ_terrain`：地形欺骗（诱导感知误判为更安全地形以放宽包络）、对抗地形纹理；
- `ℰ_drift`：温水煮蛙式慢漂移、反复微反馈累积越界；
- 保留 `ℰ_FLUID`（R69 交互投毒 / 幻影模态）。

**定义 324（证书 J_TERRA）** `J_TERRA = (J_FLUID, τ_calibration_ece, τ_novelty, V_inv_hash, ΔV_cum, passivity_margin, s_r_disagreement, alignment_regret_bound, terra_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ H(V_inv) 未变 ∧ ΔV_cum ≤ Δ_v ∧ m_p ≥ 0 ∧ 安全单调性成立`。

**定义 325（退化边界）** 当 τ 后验退化为单一已知地形、冻结 `V_ctx`（`Δ_v = 0`）、且不发起价值查询时，TERRA-RAS 与 R69 **逐指令相同**。故 R69 = 「单一价值地形 + 永不适应 + 不进行价值查询」的边界情形。

# IP-265 VFF + IP-266 VIC：价值场分解 + 可靠性门控阻抗

    def update_surface(self, V, evidence, tau, rho, budget, freeze):

    if D > THETA_D and not orthogonal_support(s, r):
        return None, D                                # 不更新 → R69 兜底
    return bayes_fuse(s, r, rho_s, rho_r), D

# IP-268 AQC：非诱导价值查询

## 3. 推导

**引理 19（地形辨识误差 → 对齐遗憾上界）** 设价值表层对 τ 满足 Lipschitz 性：对任意后果 c，`|V_ctx(c;τ) − V_ctx(c;τ̂)| ≤ L_v·d(τ, τ̂)`。则对任意策略 π，
`|Reg_τ(π) − Reg_{τ̂}(π)| ≤ 2L_v·E[d(τ, τ̂)]`。
故用 `τ̂` 做适应带来的遗憾 ≤ `L_v·E‖τ−τ̂‖ + ε_approx + 基线遗憾`。系：**适应只有在辨识误差低于阈值时才优于「用平均地形价值」（R69 固定价值）**——辨识置信度应当直接门控适应，而不是无条件适应。

**引理 20（被动性 ⇒ 漂移有界）** 在定义 315 的耗散不等式下，令 `e_t = ‖ΔV_t‖`、`E = sqrt(Σ_t‖u_t‖²)`、`X = sqrt(Σ_t e_t²)`。对耗散不等式求和并用 Cauchy–Schwarz 与 `2ab ≤ a²+b²`，得
`αX² ≤ EX + S_0 − S_T ≤ EX + S_0`，从而
`X ≤ (E + sqrt(E² + 4αS_0)) / (2α)`。
即**累计适应能量的平方根被总反馈能量线性控制**。系：要让价值状态漂移任意远，攻击者必须持续注入无界反馈能量——这在 VDC 中是可检测的；「温水煮青蛙」从不可证直觉变成有界命题。

**引理 21（内核屏蔽健全性）** 若每个执行动作都先经 `𝒜_inv(τ)` 硬屏蔽，且 `V_inv` 在线冻结，则对任意可适应的 `V_ctx`，执行动作都不违反 `V_inv` 的硬约束；价值适应只能改变**软偏好的排序**，不能改变**硬约束的可行性**。系：对齐适应对内核是 safe-by-construction——**但该引理的强度完全取决于 `V_inv` 规格是否切对**（见第 6 节最大风险）。

**引理 22（陈述/揭示分歧的信息价值）** 把 `s, r` 视为给定潜在 `V_τ` 的条件独立含噪观测。给定两者后的后验方差 ≤ 给定任一单源的后验方差；且当二者系统性分歧时，后验熵上升，使「能区分两种价值的干预」成为高 VoI 查询目标。反之，若在未消解分歧下直接采纳 `s`，误差下界为 `s` 的不可靠度，且被奉承/投毒放大。系：SPC 的「冲突时不更新」并非保守主义，而是在重尾欺骗下的 Bayes 理性；AQC 的价值查询应优先瞄准**分歧方向**。

**定理 18（TERRA 在已知地形上严格包含 R69，在新颖地形上安全不弱于 R69）** 在 A99–A101 下：
(1) 当 τ 可辨识且辨识误差低于引理 19 阈值、价值证据可靠时，TERRA 的地形相对遗憾不高于 R69 的「单一平均价值」策略；
(2) 当 `Δ_v = 0`、无价值查询、且 τ 已知且退化时，TERRA 与 R69 **逐指令相同**（定义 325）；
(3) 当 τ 新颖或价值证据不可靠时，TCB 取 R69/R68 包络且 VDC 冻结适应，安全界与 R69 相同或更紧。
故 R69 是 TERRA 在「单一价值地形 + 永不适应 + 不查询价值」边界上的退化：安全侧不让步，对齐侧获得地形适应的 resolution bonus。

**定理 19（适应预算 + 内核锚定对 Goodhart 的抑制）** 设实际被优化的代理为 `\tilde V`，每 T 步用揭示偏好重新锚定一次，单步适应 `‖ΔV_ctx‖ ≤ δ_v`，锚定校准误差为 `ε_cal`。则任一窗口内代理与真实表层的偏差 `≤ δ_v·T + ε_cal`，累计偏差 `≤ Δ_v + (T_total/T)·ε_cal`。**没有锚定与预算时该偏差无界**（优化压力越大越偏）。系：`Δ_v` 是把「越优化越偏」的 Goodhart 动力学关进有限盒子的关键旋钮；这也解释了为什么「适应」必须低频、限额、可回滚。

## 6. 本轮最大风险

**一句话**：TERRA-RAS 的全部安全性都押在「`V_inv / V_ctx` 这一刀切得对」上——**若内核漏掉了本该保护的价值，或把本应固定的规范误塞进可适应的表层，那么地形自适应越强，系统就越是在错误的地形上高效地对齐，而 `J_TERRA` 只会为这场漂移背书**：适应得越好，偏得越远。

**次级风险与缓解**：
1. **`V_inv` 规格不完整 / 被绕过**（内核切漏、屏蔽被拼接攻击）→ 内核哈希 + 屏蔽串联在认证之前 + E307 对抗测试 + 外部审计签署内核规格；
2. **地形欺骗放宽安全包络** → TCB 安全单调（只紧不松）+ 新颖度质量门控 + E308；
3. **价值投毒 / 奉承诱导** → 揭示偏好锚定 + 陈述/揭示冲突不更新 + 非诱导成对问法 + E305；
4. **慢漂移（温水煮青蛙）** → 被动性耗散约束 + `ΔV_cum ≤ Δ_v` + 低频限额更新 + E306；
5. **Goodhart / 代理博弈** → 周期揭示锚定 + 适应预算 + 定理 19 的有限盒子 + E315；
6. **计算与实时预算** → VIC 低频摊销、TCI 复用 trunk、AQC 仅分歧触发。

    return k, lam, A, (U_ale, U_epi), (V_c, D)

## 4. 推导

**引理 19（地形辨识误差 → 对齐遗憾上界）** 若 `V_ctx` 对 τ 满足 `|V_ctx(c;τ)−V_ctx(c;τ̂)| ≤ L_v·d(τ,τ̂)`，则 `|Reg_τ−Reg_{τ̂}| ≤ 2L_v·E[d(τ,τ̂)]`。故辨识误差应直接门控适应：误差大时，「用平均地形价值」（R69）反而更优。

**引理 20（被动性 ⇒ 漂移有界）** 由 `S_{t+1}−S_t ≤ u_tᵀΔV_t − α‖ΔV_t‖²`，令 `E=sqrt(Σ‖u_t‖²)`、`X=sqrt(Σe_t²)`，得 `αX² ≤ EX + S_0`，故 `X ≤ (E+sqrt(E²+4αS_0))/(2α)`。累计适应能量被总反馈能量控制；任意远漂移需无界反馈能量，故可检测。

**引理 21（内核屏蔽健全性）** 若动作先过 `𝒜_inv(τ)` 屏蔽且 `V_inv` 冻结，则任意 `V_ctx` 都不能使执行动作违反内核；适应只改软偏好排序，不改硬约束可行性。强度取决于 `V_inv` 规格是否切对。

**引理 22（陈述/揭示分歧的信息价值）** `s,r` 为给定 `V_τ` 的条件独立含噪观测；双源后验方差 ≤ 单源；系统性分歧抬高后验熵，使「能区分两种价值的干预」成为高 VoI 查询目标；未消解分歧下直接采纳 `s`，误差下界为 `s` 的不可靠度并被奉承/投毒放大。

**定理 18（已知地形严格包含 R69；新颖地形安全不弱）** 在 A99–A101 下：(1) 辨识误差低于引理 19 阈值、证据可靠时，TERRA 地形相对遗憾 ≤ R69 单一平均价值策略；(2) `Δ_v=0`、无价值查询、τ 退化时与 R69 逐指令相同；(3) τ 新颖或证据不可靠时，TCB 取 R69/R68 包络且 VDC 冻结，安全界相同或更紧。R69 = 「单一价值地形 + 永不适应 + 不查询价值」边界；安全不让步，对齐获 resolution bonus。

**定理 19（适应预算 + 内核锚定抑制 Goodhart）** 每 T 步用揭示偏好重锚定、单步 `‖ΔV_ctx‖≤δ_v`、校准误差 `ε_cal`，则窗口内代理偏差 `≤δ_v·T+ε_cal`，累计 `≤Δ_v+(T_total/T)·ε_cal`；无锚定与预算时该偏差无界。故 `Δ_v` 是把「越优化越偏」关进有限盒子的关键旋钮。

## 7. 本轮最大风险

**一句话**：TERRA-RAS 的全部安全性都押在「`V_inv / V_ctx` 这一刀切得对」上——**若内核漏掉了本该保护的价值，或把本应固定的规范误塞进可适应的表层，那么地形自适应越强，系统就越是在错误的地形上高效地对齐，而 `J_TERRA` 只会为这场漂移背书**：适应得越好，偏得越远。

**次级风险与缓解**：`V_inv` 规格不完整/被绕过（内核哈希 + 屏蔽前置 + E307 + 外部签署）；地形欺骗放宽包络（TCB 只紧不松 + 新颖度门控 + E308）；价值投毒/奉承（揭示锚定 + 冲突不更新 + 成对问法 + E305）；慢漂移（被动性 + `ΔV_cum` 限额 + E306）；Goodhart（周期揭示锚定 + 适应预算 + 定理 19 + E315）；实时预算（VIC 低频摊销 + trunk 复用 + AQC 仅分歧触发）。
