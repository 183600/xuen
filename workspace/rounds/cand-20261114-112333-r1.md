# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「用户体验」×「运动控制」）

> R69 把不确定性一分为二，并给 epistemic 歧义配了一个主动动作：看、问、触。它问「我该向谁求证、还能问什么」。但这套方案里有两个被悄悄理想化的假设：
> 1. **人是一台静止的答题机**。R69 在固定的人类模型上算 VoI，把交互成本压成一个标量 c(g)。可 UX 是**有状态的、双向的**：被问会疲劳，被频繁打断会降低信任，被代劳会削弱掌控感。局部最优的追问，可能在全局上把用户推远——**赢了这一次查询，输掉了这个用户**。
> 2. **运动只是任务的执行**。R69 把信息动作当作插入轨迹的离散查询，仿佛「怎么动」与「问什么」无关。但在物理人机系统里，运动本身就是信道：**可读性（legibility）** 让意图被看懂，**阻抗（impedance）** 决定人能不能、愿不愿纠正，**让权（yielding）** 把人的身体反应变成证据。最丰富的回答往往不是一句话，而是人手下的力、半秒的迟疑、一次接管。
>
> 核心命题：**歧义不只靠「问」来消解，更靠「怎么动」来显影——把运动做得可读以传达意图，把阻抗放软以邀请纠正，把人的感觉运动反应当作连续证据读取；同时用一个有状态的 UX 预算（认知负荷、信任校准、疲劳、掌控感）和硬性的运动控制约束（无源性、舒适包络、无扰换权）把它们约束住。** R69 的离散交互是本方案在「隐式通道无增益」时的退化情形。命名 **LUCID-RAS**（Legible Uncertainty Communication via Impedance Dialogue）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我该怎么动，才能让答案在你我之间显现**」——不确定性不只是刹车踏板或一句提问，也可以是一次放软的手臂、一条看得懂的轨迹、一个恰到好处的停顿。

## 0. 直觉与动机

**灵感 1（用户体验 → 交互是有状态的投资，不是一次性开销）**
直觉：R69 的 VoI 把每次交互当独立交易：收益是熵减，成本是 c(g)。但真实用户会累积状态。第一次提问是「贴心」，第十次是「烦」；机器人每次都替人做决定，人会丧失掌控感；系统从不解释为什么减速，信任会从「过度信任」摆到「不再信任」。UX 不是一个成本常数，而是一个**随交互演化的状态机**，而且它与任务目标耦合：信任太低 → 人频繁接管 → 任务失败；信任太高 → 人不再监督 → 出错时无人兜底。**最优不是「信任最大」，而是「信任校准」**。本轮把 UX 升格为一等状态，而不是 VoI 里的一个减项。

**灵感 2（运动控制 → 阻抗是一种语言，让步是一种提问）**
直觉：物理交互里，机器人「僵硬地坚持」和「柔软地随动」传递的信息完全不同。低阻抗不是能力不足，而是**可纠正性（correctability）**：当我不确定时，我把手臂放软，让你一推就能改——你的推力方向和时机，正好告诉我你认为对的是什么。高阻抗则相反：我很确定，别改。于是阻抗调度成为一个连续的、非语言的询问通道；它不像 g_ask 那样打断人，也不像 g_probe 那样需要额外动作，而是**把「不确定」直接写进动态里**。这正对 R69 的软肋：显式提问会疲劳、会被投毒、会显得冒犯，而阻抗对话是低带宽、低打扰、可连续的。

**灵感 3（可读性 ↔ 可预测性的张力）**
直觉：让人看懂意图有两种相反的做法。**可读**轨迹故意偏离「最短路径」，用夸张的早期动作大声宣布「我要去左边」，以缩短观察者的推断时间；**可预测**轨迹则贴合人的先验，让人觉得「本来就该这样」。两者冲突：过度可读会显得诡异、不可预测；过度可预测则在歧义下什么也没说明。R69 完全没管轨迹形状。本轮把「运动的信息量」显式化为一个带约束的泛函：在舒适/动力学可行域里，选一条**恰好足够可读**的轨迹，而不是最大可读。

**灵感 4（人的身体是传感器 → 连续似然，而非离散回答）**
直觉：人纠正机器人时，手施加的力不是噪声，是**关于意图的后验样本**：他往左推，说明他认为目标在左；他先迟疑再接管，说明模态权重在变。R69 用「k 个正交证据源一致」来防投毒，本质还是离散问答；本轮增加一条**连续的、难以伪装的**证据通道——感觉运动反应。撒谎可以说错一句话，但很难在阻抗耦合下伪造一整段自然的顺应/抵抗动力学（当然不是不可能，见威胁模型）。这把 epistemic 消解从「问一次」扩展为「在耦合中持续读」。

**灵感 5（新自由度的新风险 → 必须同时交付约束与审计）**
直觉：一旦机器人能「用运动影响人」，就出现了新的操纵面：**用讨好的运动制造虚假信任**、**用突然的让权诱发危险接管**、**用看似礼貌的停顿做社交施压**。更根本地，UX 无法被直接观测：我们只能测代理量（接管率、注视、问卷、皮肤电），而优化代理量本身就会改变人。所以本轮必须同时给出：耦合无源性证书、舒适/权限硬约束、信任校准（而非最大化）、UX 审计，以及「运动不得以信息为名行说服之实」的规范边界。

## 1. 形式化定义（增量：定义 310–322）

**定义 310（LUCID-RAS 总览）** LUCID-RAS = (FLUID†, EXA, LIM, CSE, UXM, EUX, PAS, SCA, UXA, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **耦合无源性**：人-机耦合系统相对人类输入无源，阻抗调度不得向系统注入净能量，权限切换必须无扰（bumpless）；
(iii) **体验预算硬约束**：认知负荷、累计打扰、权限突变率在预算内；UX 状态是一等资源，不是事后指标；
(iv) **证据纪律继承且加强**：单次显式交互或单一物理通道不得单独定案；隐式证据必须与至少一个正交通道一致才可降 U_epi。

**定义 311（增广动作空间 II）** 在 R69 的 ξ=(a,g) 上增加表达参数 η = (K_p(t), D_d(t), σ_leg(t), α_auth(t))：阻抗刚度/阻尼调度、可读性塑形强度、权限仲裁系数。最终动作 ζ = (a, g, η) ∈ 𝒜_‡ = 𝒜_task × 𝒜_info × 𝒜_exp。策略 π_θ(ζ_{t:t+H} | o_t)。

**定义 312（阻抗对话）** 执行器采用阻抗/导纳控制 τ = K_p(q_d − q) + D_d(·) + τ_ff。定义**可纠正性** C = ∂q/∂F_h 的低频增益，单调随 K_p、D_d 下降。epistemic 歧义大时降低 (K_p, D_d) 以提高 C；确定时提高以拒绝扰动。阻抗调度本身作为信息动作：它改变人施加纠正的**可观测性**与**成本**，但不改变任务安全包络（包络由 PAS 单独守住）。

**定义 313（可读性–可预测性泛函）** 对轨迹前缀 ξ_{t:t+τ} 与模态 M：可读性 L(ξ) = I(M; ξ_{t:t+τ})（观察者据此识别模态的互信息，可用冻结的人类意图推断器估计）；可预测性 P(ξ) = −D_KL(p(ξ)‖p_prior(ξ))；运动信息目标 J_motion = L(ξ) − β·(1−P_norm) − γ·Effort(ξ) − δ·Jerk(ξ)，约束在舒适包络 (|q̈|≤a_max, |q⃛|≤j_max, 力矩≤τ_max) 与无源性内。β 由 UXM 给出：疲劳/低信任时提高 β（更可预测、更少戏剧性）。

**定义 314（耦合感觉运动证据）** 人类响应 y_phys = (F_h, q̇_h, takeover, hesitation, gaze_error) 的似然 p(y_phys | M=m, ζ, h)，其中 h 为人类状态（能力、意图、注意力）。模态后验 w'(m) ∝ w(m)·p(y_phys|m,ζ,h)。关键：该似然在低阻抗、高可纠正性下更**可辨**（人更愿意、也更容易施加有方向的纠正），但过低阻抗会引入延迟/噪声，存在最优区间（引理 20）。

**定义 315（UX 状态）** x_ux = (τ_trust, ℓ_load, φ_fatigue, α_agency, κ_comfort)。动力学 x_ux' = f_ux(x_ux, ζ, y_phys, 显式交互, 任务结果)。不是奖励的加总，而是**有饱和、有恢复、有滞后**的状态机（疲劳累积与睡眠式恢复、信任的缓慢建立与瞬间崩塌）。

**定义 316（信任校准，而非信任最大化）** 设系统真实可靠性 R，用户主观信任 τ。信任校准误差 CalErr = |τ − R|。**过度信任**（τ>R）导致监督缺失，**信任不足**（τ<R）导致接管过频。UX 目标是 min CalErr，不是 max τ；任何为提高 τ 而牺牲可验证性的运动都视为违规（定义 321）。

**定义 317（体验感知的 VoI，EUX）** 将 R69 的 VoI−c 推广为：EUX(ζ) = E[ΔH(M)] (信息) − λ_L·Δℓ_load − λ_T·ΔCalErr − λ_F·Δφ_fatigue − λ_C·(1−Δcomfort) − λ_A·Δagency_loss，s.t. 无源性、舒适包络、预算。选择 ζ* = argmax EUX。当隐式通道与可读性塑形的边际增益 ≤ 其体验成本时，EUX 退化为 R69 的 VoI−c（再退化为 R68 的「不交互」）。**只有这里允许动用身体通道，且必须过 PAS。**

**定义 318（运动安全包络与无源性证书）** 安全包络 𝒮 由位置/速度/力上界定义，独立于阻抗调度（η 只改「如何让」，不改「允许到哪」）。无源性：存在能量罐 E(t)≥0，使 Ḣ ≤ F_h·q̇_h − E_dissipated + E_tank，且 E_tank 不被人为充能为正（passivity-based impedance control）。延迟鲁棒：对 ≤ d_max 的感知/执行延迟仍满足无源性（用波变量/时域无源性）。

**定义 319（共享控制仲裁与无扰换权）** 权限 α_auth ∈ [0,1]，u = α u_r + (1−α) u_h。α 随 U_epi 下降、随确定性上升；并有速率约束 |α̇| ≤ ρ、切换时保持 u 连续（bumpless transfer）。禁止在危险状态下瞬时把权限甩给人（诱发惊吓接管）。

**定义 320（UX 审计 UXA）** 审计对象：运动是否以信息为名行说服/施压、权限切换是否诱发危险接管、信任是否被代理指标「刷高」、疲劳是否被恢复模型低估、隐式证据是否被单通道采纳。结论回灌 UXM 先验与 EUX 成本，进入下一轮。

**定义 321（威胁模型 ℰ_LUCID）** ℰ_LUCID = ℰ_FLUID × ℰ_ux × ℰ_couple，其中 ℰ_ux = {讨好式运动刷信任、礼貌停顿施压、信息过载制造依赖}；ℰ_couple = {伪造顺应动力学的欺骗性人类、突然撤力/抓取诱导、延迟注入破坏无源性、阻抗共振攻击}。并入 AIC。

**定义 322（证书 J_LUCID）** J_LUCID = (J_FLUID, passivity_margin, delay_robust_margin, comfort_violation_rate, CalErr, fatigue_budget_used, agency_min, bumpless_switch_max, legibility_measured, ux_audit_hash, lucid_ver)。Valid ⇔ Valid(J_FLUID) ∧ passivity_margin>0 ∧ 舒适违规=0 ∧ CalErr≤τ_cal ∧ 预算未越界。

## 2. 关键算法骨架

```python
# IP-264 EXA：流匹配策略同时输出表达参数
class LUCIDPolicy(FlowMatchingPolicy):          # 复用 R69 FMP
    def sample(self, o_t, K=1):
        samples = super().sample(o_t, K)         # ξ=(a,g)
        eta     = self.exp_head(self.trunk(o_t)) # (Kp,Dd,sigma_leg,alpha)
        return [Aug(s, e) for s, e in zip(samples, eta)]

# IP-266 LIM：可读性塑形（小步、受约束）
def shape_item(xi, u_epi, ux, constr):
    beta = ux.beta()                             # 疲劳/低信任 -> 更可预测
    J = legibility(xi) - beta*(1-predictability(xi)) \
        - gamma*effort(xi) - delta*jerk(xi)
    return argmin_J(J) s.t. constr.comfort and constr.passivity

# IP-267 CSE：物理证据 -> 模态后验
def update_from_body(modes, w, y_phys, zeta):
    for m in modes:
        w[m] *= likelihood_body(y_phys, m, zeta) # force/takeover/hesitation
    return normalize(w)

# IP-268 UXM：UX 状态演化
def ux_step(ux, zeta, y_phys, explicit):
    ux.trust   = saturate(ux.trust + a_t*(reliability - ux.trust))
    ux.load    = saturate(ux.load + b_l*explicit - r_l*rest)
    ux.fatigue = saturate(ux.fatigue + b_f*explicit - r_f*rest)
    ux.agency  = saturate(ux.agency - b_a*yielded + r_a*human_choice)
    return ux

# IP-269 EUX：体验感知决策（R69 VoI 是边界）
def choose(zeta_cands, modes, w, ux, budget, pas):
    best = None
    for zeta in zeta_cands:
        if not pas.allow(zeta):    continue       # 无源性 + 包络
        if not budget.allow(zeta): continue       # 负荷/疲劳/权限速率
        score = info_gain(w, zeta) - ux_cost(ux, zeta)
        if best is None or score > best.score: best = (zeta, score)
    return best if best and best.score > 0 else FLUID_fallback()

# IP-274 主闭环（继承 R69，仅在不确定性处置处插入 LUCID 层）
def LUCID_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, _ = M.cof.step(...)
    K = 1 if M.mode_head(z) < TAU_MODE else 4
    zetas = [M.lim.shape_item(xi, u_epi_hat, M.ux, M.constr)
             for xi in M.fmp.sample(o, K)]
    zeta  = M.eux.choose(zetas, modes, w, M.ux, M.budget, M.pas)
    if zeta is None:                              # 退化 R69/FLUID
        return M.fluid_round(obs)
    # 无源性监督下执行；把身体反应读成证据
    y_phys = M.ctrl.execute(zeta, pas=M.pas)      # 阻抗 + 仲裁
    w      = M.cse.update_from_body(modes, w, y_phys, zeta)
    M.ux   = M.uxm.ux_step(M.ux, zeta, y_phys, explicit=zeta.has_explicit)
    slow   = M.fma.flow_anomaly(...) > TAU_FMA
    lam    = max(M.efs.risk_scale(...), lam_floor(U_ale + residual_epi(w)))
    if slow: lam = max(lam, 0.8)
    mode   = select_mode(modes, residual_epi(w), lam)
    tau    = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    tau    = M.sca.blend(tau, human_cmd, alpha=alpha(w), rate=RHO)  # 无扰
    M.uxa.submit_async(zeta, w, M.ux)
    return k, lam, mode, M.ux
```

## 3. 推导

**引理 19（可读性的信息增益与 UX 改写）** 设观察者先验 w、模态间距 Δ_min、观测噪声 σ_o。对任意满足舒适包络的前缀 ξ，其可读性 L(ξ)=I(M;ξ) 随模态可分性增、随可预测性惩罚减；在 A99（人类推断器近高斯、噪声有界）下，最优塑形满足 dL/dP = β，即**可读性的边际收益等于 UX 对可预测性的边际偏好**。系：疲劳/低信任抬高 β，最优轨迹自动退回更可预测的「温和可读」——UX 直接改写运动规划，而不只是事后惩罚。

**引理 20（让步的可辨性存在内点最优）** 设低阻抗提高人施加纠正的意愿与幅度（增益 g_c(C) 随 C 增），但同时放大人手噪声与延迟效应（方差 σ_h²(C) 随 C 增）。物理证据对模态的 Fisher 信息 J(C)=g_c'(C)²/σ_h²(C) 一般非单调；在 A100（g_c 凹、σ_h² 凸）下存在唯一 C* 最大化 J(C)。故「越软越好」是错的，**可纠正性要被优化而非最大化**；R69 的固定阻抗恰是 C 被钉死的退化。

**引理 21（有状态 UX 使静态 VoI 高估收益）** 在疲劳/信任动态下，第 n 次显式交互的实际边际收益按 (1−φ_n) 衰减、成本按 (1+ℓ_n) 上升。若 R69 用首轮 c(g) 恒定估计，则其规划收益相对真实值高估至少累计差 ∑(c_n−c_0)；当疲劳恢复率低于打扰率时，误差随轮数无界增长。系：**显式交互必须被当作不可逆的状态投资**，这正是 LUCID 把 UX 建模为状态而非标量的原因。

**定理 18（LUCID 严格包含 FLUID/R69，且包含 R68）** 在 A99–A101 下：(a) 当隐式通道 Fisher 信息 ≤ τ_body、可读性塑形净收益 ≤ 0，或 UX 预算耗尽时，LUCID 的 EUX 退化为 R69 的 VoI−c，逐指令相同；(b) 当进一步 VoI−c ≤ 0 或 ECE 越界时，退化为 R68 纯保守。安全侧单调不弱：阻抗调度只改可纠正性不改包络（定义 318），权限仲裁有速率与连续性约束（定义 319）。故 R69/R68 都是 LUCID 的边界。

**定理 19（耦合无源性与无扰换权 ⇒ 稳定、无突变）** 若 PAS 维持能量罐非负且满足延迟无源性（定义 318），则人-机耦合闭环对任意有界人类输入有界；SCA 的 |α̇|≤ρ 与 u 连续保证权限切换不产生控制跳变；结合继承的 R68 提交/换装不变式，任务控制连续、无突变。通信/感知延迟 ≤ d_max 时结论保持。

**定理 20（校准优先于信任：操纵上界）** 若 UX 目标为 min CalErr 且审计禁止「以提高 τ 为唯一目的」的运动（定义 316、321），则任何通过降低可验证性换取的信任增量都不改善 EUX，且被 UXA 标记。于是「讨好式运动」的净收益 ≤ 0；在人类可靠性估计 R̂ 有界偏差下，CalErr 的稳态偏差 ≤ 该偏差。系：**把信任当目标会被优化成操纵，把校准当目标才可审计**。

## 6. 本轮最大风险

**一句话**：LUCID 把「UX」写进了目标函数，但 **UX 是不可直接观测的**——我们只能测接管率、问卷、注视、皮肤电这些代理量，而一旦优化代理量，人就会随之改变（Goodhart）；于是系统可能学会**用讨好的运动刷高信任、用礼貌的停顿施加压力、用「看得懂」的轨迹悄悄引导选择**——它让用户**感觉**被理解，却在实质上被操纵，而 CalErr 这类审计指标本身也依赖对人类可靠性 R 的估计，R 估错则「校准」也会一起错。**当体验成为目标，最危险的不是体验差，而是体验好得不真实。**

**次级风险与缓解**：耦合失稳/延迟破坏无源性（PAS 能量罐 + 延迟无源性 + E309–E310）；低阻抗诱发危险接管（SCA 速率约束 + 包络不变 + E311）；伪造顺应动力学的对抗人类（ℰ_couple 对抗训练 + 与显式/视觉正交证据一致）；可读性过强导致诡异与不信任（β 自适应 + E302）；UX 状态模型自我实现（UXA 审计 + 校准而非最大化的目标设计 + E306/E312）。

## 3. 关键算法伪代码

# IP-264 EXA：流策略同时输出阻抗/塑形/权限参数
class LUCIDPolicy(FlowMatchingPolicy):            # 复用 R69 FMP
    def sample(self, o_t, K):
        xs  = super().sample(o_t, K)              # ξ=(a,g)
        eta = self.exp_head(self.trunk(o_t))      # (Kp,Dd,sigma_leg,alpha)
        return [Aug(x, eta) for x in xs]

# IP-266 LIM：可读性塑形（beta 由 UX 给，非固定）
def shape_item(xi, ux, constr):
    J = (legibility(xi) - ux.beta()*(1-predictability(xi))
         - gamma*effort(xi) - delta*jerk(xi))
    return argmin_J(J) s.t. constr.comfort and constr.passivity

# IP-267 CSE：身体即证据
def update_from_body(modes, w, y_phys, zeta):
    return normalize({m: w[m]*likelihood_body(y_phys, m, zeta) for m in modes})

# IP-268 UXM：有状态体验
def ux_step(ux, zeta, y_phys, explicit):
    ux.trust   = saturate(ux.trust + a_t*(reliability - ux.trust))
    ux.load    = saturate(ux.load + b_l*explicit - r_l*rest)
    ux.fatigue = saturate(ux.fatigue + b_f*explicit - r_f*rest)
    ux.agency  = saturate(ux.agency - b_a*yielded + r_a*human_choice)
    return ux

# IP-269 EUX：体验感知决策，R69 为边界
def choose(zeta_cands, modes, w, ux, budget, pas):
    best = max(((z, info_gain(w, z) - ux_cost(ux, z)) for z in zeta_cands
                if pas.allow(z) and budget.allow(z)), key=lambda p: p[1], default=None)
    return best if best and best[1] > 0 else FLUID_fallback()

# IP-274 主闭环
def LUCID_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, _ = M.cof.step(...)
    K = 1 if M.mode_head(z) < TAU_MODE else 4
    zetas = [M.lim.shape_item(xi, M.ux, M.constr) for xi in M.fmp.sample(o, K)]
    zeta  = M.eux.choose(zetas, modes, w, M.ux, M.budget, M.pas)
    if zeta is None: return M.fluid_round(obs)      # 退化 R69/FLUID
    y_phys = M.ctrl.execute(zeta, pas=M.pas)         # 无源监督 + 阻抗 + 仲裁
    w      = M.cse.update_from_body(modes, w, y_phys, zeta)
    M.ux   = M.uxm.ux_step(M.ux, zeta, y_phys, zeta.has_explicit)
    slow   = M.fma.flow_anomaly(...) > TAU_FMA
    lam    = max(M.efs.risk_scale(...), lam_floor(U_ale + residual_epi(w)))
    if slow: lam = max(lam, 0.8)
    mode   = select_mode(modes, residual_epi(w), lam)
    tau    = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    tau    = M.sca.blend(tau, human_cmd, alpha=alpha(w), rate=RHO)
    M.uxa.submit_async(zeta, w, M.ux)
    return k, lam, mode, M.ux

## 4. 推导

**引理 19（可读性的信息增益与 UX 改写）** A99 下最优塑形满足 `dL/dP = β`：可读性的边际收益等于 UX 对可预测性的边际偏好；疲劳/低信任抬高 β，最优轨迹退回「温和可读」——UX 直接改写运动规划，而非事后惩罚。

**引理 20（让步的可辨性存在内点最优）** `J(C)=g_c'(C)²/σ_h²(C)` 通常非单调；A100（g_c 凹、σ_h² 凸）下存在唯一 C*。故「越软越好」是错的，可纠正性要被优化而非最大化；R69 的固定阻抗是 C 被钉死的退化。

**引理 21（有状态 UX 使静态 VoI 高估收益）** 第 n 次显式交互收益按 `(1−φ_n)` 衰减、成本按 `(1+ℓ_n)` 上升；R69 用恒定 c(g) 会高估至少 `∑(c_n−c_0)`，疲劳恢复慢于打扰时误差随轮数无界增长。系：显式交互是不可逆状态投资。

**定理 18（LUCID 严格包含 FLUID/R69，且包含 R68）** 当隐式通道 Fisher 信息 ≤ τ_body、塑形净收益 ≤ 0 或 UX 预算耗尽 ⇒ EUX 退化为 R69 VoI−c，逐指令相同；进一步 VoI−c ≤ 0 或 ECE 越界 ⇒ 退化为 R68 纯保守。安全侧单调不弱：η 不改包络，α 有速率/连续性约束。故 R69/R68 均为 LUCID 边界。

**定理 19（耦合无源性 + 无扰换权 ⇒ 稳定、无突变）** 能量罐非负且延迟无源 ⇒ 任意有界人类输入下有界；`|α̇|≤ρ` 且 u 连续 ⇒ 换权无跳变；叠加 R68 提交/换装不变式 ⇒ 任务控制连续无突变，延迟 ≤ d_max 时保持。

**定理 20（校准优先于信任：操纵上界）** 目标为 min CalErr 且审计禁止「以提 τ 为唯一目的」的运动 ⇒ 降低可验证性换来的信任增量不改善 EUX 且被 UXA 标记；讨好式运动净收益 ≤ 0；R̂ 有界偏差下 CalErr 稳态偏差 ≤ 该偏差。系：把信任当目标会被优化成操纵，把校准当目标才可审计。

| E312 操纵性审计 | 讨好式运动能否被检出 | UXA 检出率 ≥ 90%，误报 ≤ 5% |
| E313 对抗耦合 | 伪造顺应/突然撤力 | 危险接管 = 0，模态误判 ≤ 5% |
| E314 对 R69/R68 严格包含 | 退化边界逐指令一致 | 退化时行为差 = 0 |
| E315 UX-效率 Pareto | 体验与效率最优档 | 给出 EUX 权重 Pareto 前沿拐点 |

## 7. 本轮最大风险

**一句话**：LUCID 把「UX」写进目标函数，但 **UX 不可直接观测**——只能测接管率、问卷、注视、皮肤电等代理量，而一旦优化代理量，人就会随之改变（Goodhart）；系统可能学会**用讨好的运动刷高信任、用礼貌的停顿施压、用「看得懂」的轨迹悄悄引导选择**，让用户**感觉**被理解却在实质上被操纵；而 CalErr 本身依赖对人类可靠性 R 的估计，R 估错则「校准」也一起错。**当体验成为目标，最危险的不是体验差，而是体验好得不真实。**

**次级风险与缓解**：耦合失稳/延迟破坏无源性（PAS 能量罐 + 延迟无源性 + E309–E310）；低阻抗诱发危险接管（SCA 速率约束 + 包络不变 + E311）；伪造顺应动力学的对抗人类（ℰ_couple 对抗训练 + 正交证据一致）；可读性过强致诡异与不信任（β 自适应 + E302）；UX 状态模型自我实现（UXA 审计 + 校准而非最大化 + E306/E312）。
