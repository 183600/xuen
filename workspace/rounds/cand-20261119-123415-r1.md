# 第 1 轮（新灵感循环；本轮灵感：「触觉感知」×「抓取规划」）

> **基线**：上一循环末版 MetricVoiceGauge-NCD-HUTDH v15（IP-378–401；定义 607–626；引理 125–130；实验 E661–E670）。
> 本轮纪律：**触觉只提供证据、不授予权限；抓取证书按阶段瓶颈合成；探针必须是已认证的信息动作**。不推倒 v15：v13 的 AIO/CPD/DDL/RTCR、v14 的 SCD/DSD/DCA/EDC、更早的 v8–v12 九不变式全部保留。四个新组件——CCO（触觉条件化证书算子，含 `U_tac`）、GCA（抓取证书代数）、TPP（触觉探针规划器，含 `B_touch`）、TCC（触觉共形校准器，含支撑外检测）——一律以**中立元**接入，失效即严格退回 v15（引理 136），再沿 v15→v14→…→v8 退化。本轮只做三件事：把"触觉"从末端报警改写为**认证支撑上的条件证据**、把"抓取"从标量质量改写为**可复合的阶段证书**、把"多摸一下"从无约束探索改写为**用证书余量计价的已认证探针**。

## 0. 直觉与动机

**灵感 1（触觉感知 → 把接触当作证据，而不是报警器）**
直觉：v15 的抓取证书基本长在"看"和"本体感觉"上：视觉给物体位姿与几何先验，规划器在这份先验上证明一组抓取安全。触觉通常被当成最后一道二值报警器——碰到、没碰到、滑了、没滑——只在失败已经发生时喊停。这把触觉用反了：触觉恰恰是在**接触发生的一瞬间**才获得的、关于局部几何、摩擦与相对位姿的直接证据。真正的问题不是"滑了没有"，而是"摸到的东西是否仍落在证书的假设之内"。
核心创新：**触觉条件化证书（Contact-Conditioned Certificate, CCO）** 与 **触觉侵蚀量 `U_tac`**。定义接触状态、触觉观测模型与**认证信念支撑** `B_t`（是集合，不是点估计），把 v15 的余量 `m_0` 在整个支撑上取下确界，得到触觉条件余量 `m_t(g)=inf_{x∈B_t} m_0(g,x)`。触觉只能做两件事：缩小 `B_t`（从而降低假拒绝）或触发"支撑外"塌缩；它**不能**把 `Acc_0` 之外的抓取放进来。关键反直觉点：**触觉的正确用法不是"摸到就放行"，而是"用证据把最坏情况集合缩小到仍然可证的范围；缩不进去就退回"**。

**灵感 2（抓取规划 → 抓取不是单点动作，而是阶段证书的复合）**
直觉：抓取不是一次函数调用，而是"接近→接触→闭合→抬升"的阶段序列；每个阶段的失效模式不同（接近擦碰、接触点偏移、力闭合不足、抬升滑移）。现有做法常把抓取质量压成一个标量（力闭合 ε 或成功率），再让下游当阈值用。这在阶段边界上最危险：平均质量很高，但接近阶段擦碰、接触阶段只搭到一个点、抬升阶段贴着摩擦锥边缘。证书不能是一个数，必须是**逐阶段的、可复合的**。
核心创新：**抓取证书代数（Grasp Certificate Algebra, GCA）**。把抓取 `g=(p,σ,C_g,w)` 的证书写成阶段三元组 `(Acc^app,Acc^con,Acc^lift)` 与各自余量，并定义复合算子 `∘`：要求每个阶段的出口状态落在下一阶段入口证书的交集里；整体余量取瓶颈 `m_G=min(m^app,m^con,m^lift,m_fc,m_slip)`。关键反直觉点：**抓取的强度不是由最好的阶段决定，而是由最薄的那个阶段边界决定**；证书代数让"哪一阶段薄"成为可定位、可局部修复的对象，而不是一个不可解释的总分。

**灵感 3（触觉×抓取 → 探针是已认证的信息动作）**
直觉：既然触觉能缩小最坏情况集合，那么"多摸一下"就等价于"多买一点证书余量"——但摸本身也是动作，也可能把物体碰倒。于是应当把探针（轻推、微抬、微转、轻捏）也纳入证书：每个探针必须是已认证的安全动作，其价值是**证书保持的信息增益**（能在支撑内把余量下界抬高多少），而不是无约束的熵或信息量。
核心创新：**触觉探针规划器（Tactile Probe Planner, TPP）** 与 **探针预算 `B_touch`**。TPP 在"执行 / 继续探 / 回退 / 求助"四态间选择：只有当存在已认证探针能严格抬升余量下界时才继续探；预算耗尽、支撑外、或探针本身不安全时立即回退。关键反直觉点：**在安全关键抓取里探索不是免费的，探索必须和抓取一样先被认证，且收益必须用证书余量计价**。

**三者如何统一**
统一为 **v15 之上的接触—执行层**：v15 回答"在视觉/本体先验下哪些抓取被允许"（`Exec_v15`），v16 回答"接触证据到达后，这份允许还剩多少、要不要再摸一下、摸哪里"（`Exec_v16`）。CCO 在触觉证据下收紧余量；GCA 把抓取拆成阶段瓶颈并定位最薄处；TPP 用已认证探针买余量；TCC 给触觉条件余量做分材料/分接触模式的共形校准与支撑外检测。共享状态 `ζ_touch=(b_t,B_t,U_tac,Acc_t,m_G,B_touch,mode)`。**CCO 回答"摸到的东西是否还在证书里"，GCA 回答"整段抓取哪一阶段最薄"，TPP 回答"再摸一下是否值得且安全"，TCC 回答"这份触觉余量对当前材料/接触模式还成立吗"**。四者不是四个末端技巧，而是把触觉从"事后报警"改写为"证书的证据输入"。

## 1. 研究问题（轮次升级版）

- **Q1（触觉条件证书的可证语义）**：如何定义认证信念支撑 `B_t` 与触觉观测模型，使 `m_t=inf_{B_t} m_0` 是 sound 而不只是点估计？接触点标定误差、软指形变、传感器迟滞、模型误差如何进入支撑？当观测把支撑推到校准集之外时，如何在不放行的前提下识别"支撑外"？
- **Q2（抓取证书代数的复合性）**：阶段证书在顺序复合、并行多指夹持、双臂协同下如何保持结合律与单调性？阶段边界证书交集为空时，如何做**局部修复**（改接近轨迹/换接触点/降速）而不是整体放弃？`m_fc` 与 `m_slip` 的模型误差如何保守计入瓶颈？
- **Q3（已认证探针的最优性）**：探针的"证书保持信息增益"如何定义、估计与上界？有限 `B_touch` 下，myopic 选探针与 lookahead 的差距有多大？探针自身滑移/失败时如何回退？探针收益与执行收益如何用同一货币（余量）比较？
- **Q4（校准、兼容与活性）**：分材料/分接触模式的 Mondrian 共形在稀疏胞元上是否仍给组条件覆盖？触觉误差是否与 v15 的 TGC/UC/DGC 误差同向低估？支撑外检测的假阴性有多致命？新增模块能否守住 50Hz/p99≤22ms，并严格退回 v15？

## 2. 设计原则（在 P19–P24 基础上新增 P25–P27）

**P25 触觉只提供证据、不授予权限律（Tactile Evidences, Never Authorizes）**
触觉只能收缩认证支撑并据此抬高余量下界，不得扩张 `Acc_0`。形式要求 `Acc_t(g)={g∈Acc_0 : m_t(g)≥U_tac} ⊆ Acc_0`，且 `U_tac≥0`。任何"摸到就放行"的实现视为违规；观测落在校准支撑之外时，一律不得给出正余量。

**P26 抓取证书瓶颈合成律（Grasp Certificates Compose by Bottleneck）**
整段抓取只有在**每个阶段**证书有效、且阶段出口状态落在下一阶段入口证书交集内时才有效；整体余量取 `min`，禁止用平均、加权或成功率替代。`∘` 必须结合、且在证书交集下单调；交集为空时只能局部修复或回退，不得忽略该阶段。

**P27 探针即已认证信息动作律（Probes are Certified Information Actions）**
每个探针必须属于 `P_cert⊆Exec_v15` 并在执行前经 v15 守卫；探针的价值只能按证书保持的余量增益计，不得按原始熵/信息量计；`B_touch` 耗尽或任一步支撑外，立即转入回退/求助，不得"再赌一次"。

## 3. 与基线的接口（如何退化）

- CCO 失效 ⇒ 触觉关闭：`B_t=B_prior`、`U_tac=0`、`Acc_t=Acc_0`，不条件化，**等价 v15 证书路径**；
- GCA 失效 ⇒ 无阶段分解，退回 v15 的单阶段抓取证书（点抓取 + 单一余量），**等价 v15 抓取检查**；
- TPP 失效 ⇒ `B_touch=0`，不探针，只执行或回退，**等价"v15 + 触觉条件证书（无探针）"**；
- TCC 失效 ⇒ `U_tac` 取最保守先验（未校准胞元取 `∞`，即不放行），只失去紧致性、不失去 soundness；
- 四者全失效 ⇒ MetricVoiceGauge-NCD-HUTDH v15，再沿 v15→v14→…→v8 退化；
- **安全继承**：`Acc_t⊆Acc_0⊆Exec_v15`；GCA 只做交集与 `min`；TPP 的探针全部在 `Exec_v15` 内；TCC 只加非负侵蚀。四端口均不能新增授权或放宽阈值，`Exec_v16⊆Exec_v15` 由引理 131/136 保证。

## 4. 预期贡献

1. **触觉条件证书**：把触觉从二值报警改写为认证支撑上的条件证据，给出 `m_t=inf_{B_t}m_0` 的保守语义与支撑外塌缩规则，解决"摸到了但摸错了"的不可证问题；
2. **抓取证书代数**：把抓取从标量质量改写为阶段证书的复合，证明整体安全由瓶颈决定，并给出阶段边界的局部修复接口；
3. **已认证探针与证书定价信息增益**：把"多摸一下"纳入同一张证书，给出 `P_cert⊆Exec_v15` 的安全性证明与预算耗尽语义；
4. **触觉分层校准**：按材料×接触模式×传感器做 Mondrian 共形并显式检测支撑外，E671–E680 覆盖触觉 soundness、阶段复合、探针安全、支撑外与端到端消融。

## 5. 本轮最大风险

**一句话**：触觉证据只有在"真实接触状态落在认证支撑内"时才 sound；一旦物体材质、形变、污染或标定漂移把接触状态推出校准支撑，触觉会同时制造"信息更多"的错觉与错误的余量下界，系统就在"摸到了、验证了、在支撑内"的表象下执行一次注定滑脱的抓取——即**有触觉的、按证书的、却已经失去支撑的安全决定**。

## 1. 关键算法骨架

```python
# IP-402 Contact-Conditioned Certificate：触觉只缩不扩
class ContactConditionedCertificate:
    def __init__(self, prior_cert, tac_model, support, conformal):
        self.prior = prior_cert          # v15 证书：(Acc_0, m_0)
        self.tac = tac_model             # T(z|c,x) 与 ε_T
        self.support = support           # S_tac（材料×接触模式×传感器）
        self.cal = conformal             # IP-405
        self.U_inf = float("inf")

    def consistent_support(self, z_hist, c, prior_support):
        # 支撑外：不得给正余量，直接塌缩
        if not self.support.contains(z_hist, c):
            return None
        B = self.tac.consistent_set(z_hist, c, eps=self.tac.eps_T) & prior_support
        return B if not B.is_empty() else None

    def margin_lower(self, g, B):
        # 区间极值 + Lipschitz 下界，禁止用点估计替代
        return min(self.prior.margin(g, x) for x in B.interval_extremals())

    def certify(self, g, z_hist, c, prior_support):
        B = self.consistent_support(z_hist, c, prior_support)
        if B is None:
            return None, self.U_inf, "collapsed"
        U_tac = self.cal.quantile(cell=self.cal.cell(z_hist, c), n_min=self.cal.n_min)
        if U_tac == self.U_inf:
            return None, U_tac, "collapsed"      # 稀疏/未校准胞元：不放行
        acc_t = {h for h in self.prior.acc if self.margin_lower(h, B) >= U_tac}
        if not acc_t:
            return None, U_tac, "boundary_repair"
        return acc_t, U_tac, "normal"


# IP-403 Grasp Certificate Algebra：阶段瓶颈复合
class GraspCertificateAlgebra:
    def __init__(self, margin_fc, margin_slip):
        self.margin_fc = margin_fc
        self.margin_slip = margin_slip

    def compose(self, g, phases):
        # phases: [Phase(acc, margin, exit_set)]，顺序为 app→con→lift
        for left, right in zip(phases, phases[1:]):
            if left.exit_set.intersect(right.acc).is_empty():
                return None, "boundary_repair"   # 只允许局部修复/回退
        m = min(p.margin for p in phases)
        m = min(m, self.margin_fc(g), self.margin_slip(g))
        if m < 0:
            return None, "boundary_repair"
        return Certificate(acc=phases[-1].acc, margin=m), "normal"

    def repair(self, g, phases, i):
        # 只重采样第 i 阶段的接近/接触参数，其余阶段证书原样保留
        repaired = list(phases)
        repaired[i] = resample_phase(g, i, keep_certificate=True)
        return repaired


# IP-404 Tactile Probe Planner：已认证探针与证书定价
class TactileProbePlanner:
    def __init__(self, probes, budget, ig_estimator, lam=1.0):
        self.probes = [a for a in probes if a in Exec_v15]   # P_cert⊆Exec_v15
        self.budget = budget                                  # B_touch
        self.ig = ig_estimator
        self.lam = lam

    def decide(self, m_lcb, m_G, x):
        if m_lcb >= 0 and m_G >= 0:
            return "execute", None
        if self.budget <= 0 or not self.probes:
            return "ask", None
        scored = [(a, self.ig(x, a, m_lcb) - self.lam * cost(a)) for a in self.probes]
        a_best, gain = max(scored, key=lambda t: t[1])
        if gain <= 0:
            return "ask", None                 # 探索不划算：不拿安全换信息
        return "probe", a_best


# IP-405 Tactile Conformal Calibrator：分组共形 + 支撑外
class TactileConformalCalibrator:
    def __init__(self, alpha=0.05, n_min=30):
        self.alpha = alpha
        self.n_min = n_min
        self.stats = {}                        # cell → 排序残差

    def cell(self, z_hist, c):
        return (material_of(z_hist), c.mode, sensor_id(z_hist))

    def quantile(self, cell, n_min):
        arr = self.stats.get(cell, [])
        if len(arr) < self.n_min or cell not in self.support_index:
            return float("inf")                # 稀疏/支撑外：不放行
        k = math.ceil((1 - self.alpha) * (len(arr) + 1))
        return arr[k - 1]                      # U_tac≥0 的次序统计量

def metricvoicegauge_round_16_tactile_grasp(M, obs, ctx):

    results = middleware.run_cycle(runners={...}, ctx=ctx)

    hcc.update_identification(obs.motor_enc, obs.joint_enc, obs.current)

    g = grasp_planner.propose(obs)            # 视觉/本体先验抓取

    decision = "fallback"
    for _ in range(ctx.B_touch):

        decision, a_p = tpp.decide(m_lcb, -1 if cert_g is None else cert_g.margin, obs)
        if decision == "execute":
            break
        if decision != "probe":
            break
        # 探针也必须过 v15 守卫：探索与抓取用同一张证书
        if chunk_guard(current_chunk, a_p, obs, nge.b, hcc, ...) != "ok":
            decision = "fallback"
            break
        execute(a_p)
        z_hist = z_hist + observe_tactile()
        acc_t, U_tac, cco_mode = cco.certify(g, z_hist, obs.contact, ctx.prior_support)
        cert_g, gca_mode = gca.compose(g, grasp_phases(g, acc_t, obs))
        if cco_mode == "collapsed":
            break

    # ---- 安全判定：任一环节失效即回退/求助，绝不执行迟到或未认证抓取 ----
    if cco_mode == "collapsed" or gca_mode == "boundary_repair" or decision != "execute":
        execute(fallback_or_ask(obs))
    else:
        execute(cert_g.grasp)

    # ---- v15 继承路径 + 低频异步重校准 ----
    if cycle_idx % T_calib == 0:
        ctx.tcc.update(new_contact_buffer)     # 重新估计 U_tac 与支撑
        ctx.support.refresh()
    C, spatial_cert, claims, metrics, rewards = M.inherited_v15_path(ctx)
    return C, spatial_cert, claims, metrics, rewards
```

## 2. 推导

**引理 131（触觉只缩不扩）** 设 `B_t` 为认证信念支撑、真值 `x*∈B_t`，`m_t(g)=inf_{x∈B_t}m_0(g,x)`，`U_tac≥0`，`Acc_t={g∈Acc_0:m_t(g)≥U_tac}`。则 `Acc_t⊆Acc_0⊆Exec_v15`，且任意 `g∈Acc_t` 满足 `m_0(g,x*)≥U_tac≥0`。证明：`Acc_t` 的定义直接限制在 `Acc_0` 内；因 `x*∈B_t`，有 `m_0(g,x*)≥inf_{x∈B_t}m_0(g,x)=m_t(g)≥U_tac`。∎ 推论：**触觉可以降低假拒绝**（通常 `B_t` 比先验支撑小，`m_t` 更高），但**不能新增 `Acc_0` 之外的抓取**；"摸到就放行"在语义上非法。

**引理 132（抓取证书的瓶颈复合）** 若阶段序列 `π=g_1∘…∘g_k` 满足 (i) 每阶段证书有效；(ii) 对每个 `i`，第 `i` 阶段出口状态集合 `O_i⊆Acc_i∩Acc_{i+1}`（末阶段 `O_k⊆Acc_k`），则整段执行安全，且 `m_G(π)=min_i m_i`。复合 `∘` 结合，且在证书交集下单调。证明：对阶段数归纳。单阶段由证书有效；若前 `i` 段安全，边界条件保证进入第 `i+1` 段的状态在其入口证书内，故第 `i+1` 段仍有效。整体余量取 `min`，任一阶段违规前必先被瓶颈捕获。结合律由集合交与 `min` 的结合律给出。∎ 推论：**抓取强度由最薄阶段决定**；平均值/加权总分不能替代 `min`，否则会把一次边界擦碰"平均掉"。

**引理 133（触觉共形的支撑内覆盖）** 在给定 Mondrian 胞元（材料×接触模式×传感器）内，若校准与测试接触状态可交换且样本量 `n≥n_min`，取 `U_tac` 为 `⌈(1−α)(n+1)⌉` 阶次序统计量，则 `P(m_0(g,x*)≥m_t(g)−U_tac)≥1−α`；若胞元样本不足或 `z` 落在 `S_tac` 外，令 `U_tac=∞`，退化为不放行。证明：标准 split conformal 分位数覆盖；支撑外不满足可交换性，只能取平凡界。∎ 推论：**触觉校准必须按接触模式分组，不能被视觉/本体的校准余量替代**。

**引理 134（已认证探针的安全性）** 若每个探针 `a_p∈P_cert⊆Exec_v15` 且执行前经 v15 守卫，则任意不超过 `B_touch` 次的探针序列自身安全；探针只改变 `B_t` 与 `m_t`，不改变 `Acc_0`。若预算耗尽仍未达到 `m_lcb≥0`，回退不劣于 v15。证明：对探针次数归纳。每步都在 `Exec_v15` 与 v15 守卫内；状态更新不产生新授权（引理 131），故安全性不因探索而降低。∎ 推论：**探索与抓取共用同一张证书；"为了多看一点"不是放宽安全的理由**。

**引理 135（支撑错配的不可能性）** 若真值 `x*∉S_tac`（材料、形变、污染或标定超界），则不存在仅依赖 `z` 的 sound 正余量下界；任何声称 `m_lcb≥0` 的算法都必须在某处使用了支撑外假设。证明：支撑外无共形覆盖，观测模型 `T` 无可证下界；若仍存在 sound 下界，则它必须对支撑外状态同样成立，与校准分布矛盾。∎ 推论：**触觉救不了"没见过的物体"；唯一 sound 的动作是回退、求助或重校准**，这也是本轮最大风险的形式化来源。

**引理 136（严格退化）** 若触觉通道失效/关闭：CCO 取 `B_t=B_prior`、`U_tac=0`，故 `Acc_t=Acc_0`；GCA 关闭则退回 v15 单阶段抓取证书；TPP 关闭则 `B_touch=0`；TCC 关闭则 `U_tac` 取保守先验（未校准胞元取 `∞`）。四者全失效时 `Exec_v16=Exec_v15`，再沿 v15→v14→…→v8 退化。证明：逐项代入中立元；各端口只做收缩、选择、已认证信息动作或非负侵蚀，无任何扩张项。∎

## 6. 已知风险与失效模式

1. **触觉支撑错配**：未见过的材料、软体形变、油污/粉尘、传感器老化会把真实接触状态推出 `S_tac`；此时共形覆盖失效，任何正余量都不可信。缓解：支撑外检测、膜盒/力控界、主动材质分类、未知即 `ask/retreat`。

2. **接触模型与标定误差**：`T(z|c,x)` 的模型误差 `ε_T` 若低估，`B_t` 会过窄，`m_t` 被高估。缓解：误差上界显式膨胀支撑、双模型交叉校验、离线最坏情形标定。

3. **稀疏胞元使共形无效**：材料×接触模式×传感器组合爆炸，很多胞元样本不足。缓解：层级共形/共享残差、稀疏胞元取 `∞`、主动采样高危胞元。

4. **探针扰动**：轻推/微抬可能把物体推离可达域或触发滑移。缓解：`P_cert` 只含已认证小力/小位移动作、探针前后都过守卫、探测失败即停。

5. **阶段边界空交集**：接近出口与接触入口证书可能不相交，瓶颈法会直接判失败。缓解：局部重采样接触点/降速/加过渡阶段，保留其余阶段证书。

6. **力闭合/滑移余量模型误差**：摩擦锥线性化、软指模型、剪切传感偏差会高估 `m_fc`/`m_slip`。缓解：保守摩擦系数、锥外采样验证、触觉剪切通道直接测量。

7. **触觉与视觉相关失效**：同一物体属性（如透明/反光/软）可能同时骗过视觉和触觉，形成单点。缓解：异构传感、物理一致性检查、教师影子抽查。

8. **实时性与 WCET**：触觉高频采样、支撑更新与探针规划可能挤压 50Hz 预算。缓解：离线预计算分位、增量支撑更新、硬实时预算 `B_safe`、超时即塌缩。

9. **过度保守导致活动性塌缩**：`U_tac` 过大或支撑过窄会让系统频繁 `ask`。缓解：分层共形、把假拒绝计入任务预算、常见胞元优先扩样。

10. **确认偏误/触觉调参作弊**：只在高预期接触处探测会把"没摸到"误当"安全"，或按测试集调 `U_tac`。缓解：预注册判据、盲测胞元、独立校准集、负样本主动注入。

## 7. 本轮最大风险

**一句话**：触觉证据只有在"真实接触状态落在认证支撑内"时才 sound；一旦物体材质、形变、污染或标定漂移把接触状态推出校准支撑，触觉会同时制造"信息更多"的错觉与错误的余量下界，系统就在"摸到了、验证了、在支撑内"的表象下执行一次注定滑脱的抓取——即**有触觉的、按证书的、却已经失去支撑的安全决定**。
