# 第 3 轮（灵感循环第 3 轮；本轮灵感：「路径规划」×「技术融合」）

> **基线继承**：ToolGauge（第 2 轮；IP-315–320；定义 416–431；引理 46–50；实验 E426–E440），其下依次是 LeanGauge、MODGAUGE。
> 本轮纪律：继续在前人基础上改进——ToolGauge 把「发现盲区 → 单点契约化探测 → 摊销校准 → 热替换」闭环做扎实了，
> 但仍把修复当作**彼此独立的原子事件**：按检测顺序修、每条回执当独立样本、每次热替换互不相干。
> 路径规划与传感器/技术融合恰好补上「事件之间」的三层结构：**顺序、路线、证据相关性**。

## 三位一体映射（围绕「事件之间」升级）

| 灵感词 | ToolGauge 现状 | 升级为 | 一句话动机 |
|---|---|---|---|
| 路径规划 | 盲区按检测顺序逐个修复；每个盲区独立选位姿、独立出行 | **R-Box 修复路线图 + RP-Plan**：在「盲区 × 可达位姿」图上规划一条带预算的信息路径，允许一次行程/一次观测服务多个盲区 | 修复的代价不只是工具，还有移动、架设与切换；顺序与路线会改变总收益 |
| 技术融合 | AP-Cal 把回执当 i.i.d. 样本，融合只发生在同质标量上 | **F-Box 融合契约**：显式记录来源图、共享扰动与相关性，用有效样本量 n_eff 融合异质证据 | 多模态不是多证据；同一趟路径的回执强相关，朴素相加必然过度自信 |
| 合题 | 规划与校准各自为政 | **依赖性预算（dependence budget）**：规划器申报路线允许的最大相关性，融合器据此折算 n_eff，在线互相校正 | 效率与统计有效性必须联合设计，否则「越省越自信」 |

**核心命题**：把 ToolGauge 的「原子修复」升级为「**规划 → 执行 → 融合 → 组合**」：
Repair Roadmap 决定「修哪些、按什么顺序、走哪条路、怎样共享一次观测」；
Fusion Contract 决定「这些共享观测到底值多少独立证据」；
Composition Ledger 决定「沿途热替换能否安全组合」。三者共享同一预算契约。

**不变式保持声明**：
- MODGAUGE 五不变式、ToolGauge 的契约完整性/主张绑定/严格退化链全部保留；
- 新增**信用守恒不变式**：任意一条回执被多个盲区共享时，Σ_s credit(r,s) ≤ 1（禁止信息增益双重计数）；
- 新增**相关性诚实不变式**：进入契约的 n_eff 必须不大于由来源图估计的上界；估计不可得时取 n_eff=1；
- 严格退化链再延长：RouteGauge 失效（规划超时/组合冲突/融合证书失败）⇒ ToolGauge 单点修复 ⇒ LeanGauge ⇒ MODGAUGE。

## 0. 直觉与动机

### 灵感 1（路径规划 → 修复是「一条路径」，不是「一个集合」）

ToolGauge 的每个盲区修复都是一次独立的「出行」：选一个位姿、调一个工具、拿一条回执。现实中这些修复共享大量固定成本：移动到工位、架设传感器、调整光照/温度稳定时间、等待热漂移收敛。更重要的是，**一次观测可以同时降低多个盲区的不确定性**（同一视角同时看到镜面区与透明区），而 ToolGauge 会为它们各跑一遍。

直觉上这正是一个**信息路径规划（informative path planning）**问题：节点是「盲区 × 位姿」，边是移动/切换代价，收益是边际信息增益，约束是预算、依赖偏序与运动安全包络。与经典 IPP 不同的是，这里的「地图」会因修复而改变（热替换改变契约子图），所以路径必须是**自适应**的：每走一步，剩余节点的收益与可行性都要重估。

### 灵感 2（技术融合 → 多模态是「有来源的证据」，不是「更多样本」）

ToolGauge 的 AP-Cal 接收回执流，默认它们彼此独立、同分布、可直接相加。但真实的异质证据（IR、双目、敲击、热成像、跨通道互检）有完全不同的噪声结构、量纲与失效模式；更致命的是，**同一条修复路径上的回执共享扰动源**：同一段运动误差、同一盏灯、同一个热场、同一个时间窗。把它们当独立样本，等价于把一份证据复印 n 份。

技术融合的正确姿态不是「加权平均」，而是**来源代数 + 相关性折算 + 不相交验证**：先画出来源图，判断哪些回执共享祖先；再用有效样本量把相关证据折算成「相当于几条独立证据」；最后强制用**来源不相交**的回执做交叉验证。ToolGauge 已有 cross.modal 独立回执的思想，但它没有把「独立」形式化为可检查的来源图条件。

### 灵感 3（合题 → 规划会主动制造相关性）

单独看，路径规划提高效率，融合提高稳健性；合在一起，二者会互相拆台：**规划器为了省行程，倾向于把盲区打包进同一路径、同一光照、同一热状态，而这恰好最大化了回执之间的相关性**。如果融合层低估相关性，n_eff 被高估，后验过度自信，热替换更激进，最终在「最省」的路线上得到「最不可信」的契约。

所以本轮不是简单叠加两个模块，而是引入一条**联合约束**：规划器在申报路线时必须同时申报「依赖性预算」ρ_max；融合器只接受在该预算内成立的融合；执行后实测相关性回写，若超预算则触发重规划或退化。这把「效率—独立性」的权衡第一次写进了契约。

## 1. 形式化定义（增量：定义 432–449）

**定义 432（修复路线图 RR）** RR = (V, E_move, E_couple, g, c, Ω_safe)：
- V ⊆ S × Q：盲区 s 与可达位姿簇 q 的组合节点（q 由运动规划器给出，满足安全包络）；
- E_move：位姿间移动/架设/切换代价，满足三角不等式（同一安全走廊内）；
- E_couple ⊆ V×V：耦合边——两节点共享契约子图、共享物理状态（光照/温度/振动）或共享工具，表示修复顺序不可任意交换；
- g(v | ℰ)：在已有证据 ℰ 下访问 v 的**边际信息增益**（nats），由 MP-Φ 查询并按定义 446 做信用分摊；
- c(v)：时间 + 能量 + 磨损；Ω_safe：允许的运动/力/温包络。

**定义 433（信息修复路径 IRP 与批量）** 路径 P = (v₁,…,v_K) 配批量划分 β₁,…,β_J（β_j ⊆ {v}，同一位姿/时间窗内一次执行可服务的节点）。
效用 U(P) = Σ_j γ^{j−1} Σ_{v∈β_j} credit(r_j,v)·g(v | ℰ_{<j}) − λ·Σ c(v)，其中 γ∈(0,1] 为折扣；
约束：预算、依赖偏序（定义 439）、依赖性预算（定义 443）、运动包络。目标是 argmax U(P)。

**定义 434（路径预算契约 PB-Contract）** PB = (B_tools, B_move, L_path, L_batch, τ_plan, τ_repair, K_replan, recovery)：
在 TB-Contract（定义 424）上增加移动预算、路径节点上限、单批节点上限、规划时延上限与重规划次数上限；
任一超限 ⇒ 规划失败、按退化链处理。PB 是 IV-Contract 的路径级细化。

**定义 435（融合契约 FC）** FC = (M, ⊙, π, Σ_ρ, cal)：
- M：允许的模态集合（数值观测，不含自由文本）；⊙：融合算子（相关感知的 GLS/卡尔曼/加权）；
- π：回执 → 来源集合（传感器 ID、位姿、时间窗、环境通道、工具实例）；
- Σ_ρ：相关性模型，输出相关矩阵估计 C 与上界 ρ̂；
- cal：融合后校准映射（把名义协方差映射为可覆盖的保守协方差）。

**定义 436（来源图与不相交性）** 来源图 G_prov = (R ∪ Src, E_prov)，r 与 source 连边，source 之间按共享物理通道连边。
disjoint(r_i, r_j) ⇔ 在 G_prov 中不存在共享祖先（同一传感器/位姿/时间窗 τ_corr/环境通道）。
**来源不相交集** D ⊆ R 指两两 disjoint。独立回执不再由「不同工具名」定义，而由 G_prov 定义。

**定义 437（有效样本量与相关性折算）** 对协方差 Σ = σ²C（C 单位对角）的回执批，定义
n_eff = 1ᵀ C⁻¹ 1；等相关 ρ 时 n_eff = n / (1 + (n−1)ρ)。
后验更新必须使用 n_eff 而非 n：σ_post² = (σ_0⁻² + n_eff·σ_obs⁻²)⁻¹。
若只有相关性上界 ρ̂（ρ̂ ≥ ρ），则用 n_eff(ρ̂) 作为保守值；ρ 不可估时取 n_eff=1。

**定义 438（融合证书 FusionCert）** FusionCert = (μ_F, Σ_F, receipts, G_prov, ρ̂, n_eff, witness)：
witness 是一条与拟合集来源不相交的回执（或来源不相交的 holdout 子集）。
无 witness 时证书标记 provisional，**不得触发热替换**（只能记入待验证队列）。

**定义 439（路径组合的偏序与交换条件）** 对每个热替换 op_s，定义依赖闭包 D(s) = 被读写契约子图及其上游接口、版本向量 ver(s)。
若 D(s_i) ∩ D(s_j) = ∅ 且版本独立，则 op_i ∘ op_j = op_j ∘ op_i（可交换）。
否则路径必须满足由 D(·) 诱导的偏序（拓扑序）；违反偏序的批量执行被拒绝。

**定义 440（版本化世界锁与修复账本）** EC 携带版本向量 v_EC；每次热替换在账本 ledger 记录 (s, D(s), ver_before, ver_after, residual, credits)。
仅当当前 v_EC 在 D(s) 上与账本一致时才允许写入；不一致 ⇒ 重基（用最新接口重算）或延迟到下一轮，禁止静默覆盖（lost update）。

**定义 441（自适应重规划与遗憾预算）** 触发条件（任一）：实测增益 < (1−δ)·预测增益；融合给出 n_eff < n_min；出现更高价值密度的新盲区；运动路径被阻断。
重规划受 K_replan 与 B_plan 限制；记 R_regret 为相对「事后最优路径」的累计遗憾，要求 R_regret ≤ B_regret（否则降级为顺序修复）。

**定义 442（路径安全包络与可中止性）** 执行期系统处于 PROBING 状态（定义 430），路径点必须落在 Ω_safe 内；
任一航点可零副作用中止并回到安全静止态；中止不改变已提交的契约（只丢弃未执行前缀）。

**定义 443（依赖性预算 DB）** 规划器为路径 P 申报 ρ_max(P)；批量 β 仅当估计相关性上界 ρ̂(β) ≤ ρ_max(P) 时被允许。
执行后实测 ρ̃ 回写；若 ρ̃ > ρ_max，则本批证据按 n_eff(ρ̃) 降权，并触发重规划或退化。
DB 是「效率—独立性」权衡的显式契约，而不是隐含假设。

**定义 444（严格退化链扩展）** 规划超时/不可行 ⇒ ToolGauge 按检测顺序单点修复；
相关性不可估 ⇒ n_eff=1（不享受批量收益）且只接受来源不相交证据；
融合证书失败/组合冲突/重规划超预算 ⇒ defer + stub + RED ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。
RouteGauge 是增强项，不是依赖项。

**定义 445（安全路径与偏序计划）** 若在预算内不存在满足 D(·) 偏序的批量划分，则禁止批量，退化为拓扑序上的顺序修复（每个盲区单独执行）。
「安全路径」定义为存在拓扑序且每步满足 PB/DB/Ω_safe 的路径；否则不执行，避免不可组合的热替换。

**定义 446（观测共享的信用守恒）** 对回执 r 与盲区 s，信用 credit(r,s) ∈ [0,1]；
不变式：∀r，Σ_s credit(r,s) ≤ 1；且 ∀s，Σ_r credit(r,s)·g_s(r) 不得超过联合信息增益 I(U_s; R)。
这条不变式把「一条回执服务多个盲区」从会计作弊变成可审计的分摊。

**定义 447（路径级语义-数值一致性 SNC-P）** 一个批次 β 的联合观测模式必须同时匹配其被记入的每个假设 h_s 的预注册指纹；
若两个盲区的假设要求互相矛盾的指纹（例如同一残差符号既是镜面又是漫反射），则本批只能记入其中一方，另一方信用置零并重新规划。
SNC-P 是定义 425 从单点到路径的推广。

**定义 448（路线修复证书 RouteCert）** RouteCert = (P, β, g 预测, ρ_max, 实测 ρ̃, n_eff, credits, ledger, abort_points)：
供人工审计与事故复盘；数值字段必须逐字绑定到回执或账本，语言解说不得引入新数值（继承定义 423/427）。

**定义 449（继承、退化与编号约定）** 未被重定义的 ToolGauge 记号沿用定义 416–431。
**退化特例**：令路径只含单节点、无批量、C=I（ρ=0）、D(·) 两两不交 ⇒ RouteGauge ≡ ToolGauge；
再令 VLA=∅、MP-Φ=物理先验 GP ⇒ ToolGauge ≡ LeanGauge。

# IP-321 R-Box：修复路线图（盲区 × 位姿 + 耦合边）
class RBox:
    def build(self, spots, coupling, poses, env):
        V = [(s, q) for s in spots for q in poses.reachable(s, env.safe_corridor)]
        E_move = metric_edges(V, env.safe_corridor)      # 三角不等式
        E_couple = coupling.edges(spots)                # 共享子图/物理状态
        return RepairRoadmap(V, E_move, E_couple, g=MPPhiGain(...), c=cost_model)

# IP-324 RP-Plan：预算化信息路径（小规模精确，大规模启发式）
class RPPlanner:
    def plan(self, rr, budget, credit, rho_budget):
        if len(rr.V) <= 12 and budget.is_cardinality():
            P = self.dp_exact(rr, budget)               # 子集 DP，精确
        else:
            P = self.greedy_adaptive(rr, budget)        # 启发式，附质量凭证
        P = self.enforce_precedence(P, rr.E_couple)     # 定义 439/445
        P = self.respect_dependence_budget(P, rho_budget, rr)  # 定义 443
        return P

# IP-322 F-Box：来源图 + 相关感知融合 + 不相交见证
class FBox:
    def fuse(self, receipts):
        prov   = build_provenance(receipts)             # 定义 436
        rho, ub = self.corr.estimate(prov)              # ρ̂ 为上界
        n_eff  = self.effective_n(rho, ub, len(receipts))  # 定义 437
        mu, Sig = self.op.fuse(receipts, rho)           # GLS/卡尔曼
        Sig = conservative_calibrate(Sig, n_eff)
        witness = self.disjoint_holdout(receipts, prov)
        return FusionCert(mu, Sig, receipts, prov, ub, n_eff, witness)

# IP-323 C-Box：依赖偏序 + 版本化世界锁
class CBox:
    def apply(self, ops, ec, ledger):
        for op in topo_sort(ops, key=lambda o: o.dep):
            if not ledger.version_match(op.dep, ec):
                return self.rebase_or_defer(op)         # 定义 440/445
            ec = op(ec)
            ledger.record(op, credits=op.credits, residual=op.residual)
        return ec

# IP-325 RouteGauge-8C：H → P → C → E → F → C → V → U
def routegauge_8c(M, spots):
    H     = M.lbox.hypothesize_batch(spots, M.dbox)          # H
    rr    = M.rbox.build(spots, M.coupling, M.poses, M.env)
    P     = M.rp.plan(rr, M.budget, M.credit, M.rho_budget)  # P
    if not P.safe: return degrade_to_toolgauge(spots)        # 定义 445
    prog  = M.tbox.compile(P, H); ok, why = M.tcv.verify(prog, M.budget)
    if not ok: return degrade_to_toolgauge(spots)            # C
    rcpts = M.tcv.execute(prog, M.env)                       # E
    F     = M.fbox.fuse(rcpts)                               # F
    if F.n_eff < M.n_min_eff(P): return defer_and_degrade(P) # 定义 437
    mu, Sig = M.apcal.calibrate(F, H)                        # C
    if not M.apcal.cross_validate(mu, Sig, F.witness):       # V
        return defer_and_degrade(P)
    if not M.cbox.apply(P.ops, M.ec, M.ledger):              # 组合
        return stub_and_red(P, "composition_conflict")
    M.dbox.update_from_posterior(P, mu, Sig); M.pquar.record(...)
    M.ledger.commit(P); bind_route_cert(M.ec, P, F)          # 定义 448
    return True

# IP-326 主闭环：规划/融合全异步，50Hz 路径不变
def RouteGauge_round(M, obs, audio, tac, depth, det):
    spots = M.dbox.detect_blind_spot()
    if spots and not M.plan_inflight:
        M.plan_inflight = True
        submit_async(routegauge_8c, M, spots)               # 偏离 50Hz 路径
    if M.trigger_replan():                                   # 定义 441
        submit_async(M.rp.replan, M)
    if M.pquar.triggered(): M.apcal.pause(); M.use_bpcal_fallback = True
    return MODGAUGE_round(M, obs, audio, tac, depth, det)

## 3. 推导

**引理 51（信息路径的近似性与相关性下的子模性失效）**
(a) 固定历史下，若 g 自适应子模、移动代价满足三角不等式、预算为基数约束，则 greedy 路径达到 (1−1/e) 近似；
一般预算下问题含定向越野为 NP-hard，仅当 |V|≤12 用子集 DP 求精确解，其余情形不宣称最优。
(b) **负结果**：当批量回执存在路径诱导相关 ρ>0 且 ρ 只能事后观测时，规划器使用的独立增益是乐观估计，
其偏差因子恰为 1+(|β|−1)ρ；此时不存在与 ρ 无关的常数近似比，除非引入依赖性预算（定义 443）或把 n_eff 作为硬约束。
证明思路：(a) 标准自适应子模贪心；(b) 构造两节点同位姿实例：独立估计各增益 ε，联合增益仅 ε，greedy 两节点都选，浪费一半预算；
ρ 未知时任何确定性规划器都无法区分「两次独立观测」与「一次观测的两次拷贝」。∎

**引理 52（相关回执的融合方差与过度自信因子）**
设回执协方差 Σ = σ²C，则最优线性无偏融合均值的方差为 σ²(1ᵀC⁻¹1)⁻¹，故 n_eff = 1ᵀC⁻¹1；
等相关 ρ 时 n_eff = n/(1+(n−1)ρ)。若误用 n，则后验方差被低估因子 n/n_eff = 1+(n−1)ρ，
即过度自信因子；用上界 ρ̂ 计算 n_eff(ρ̂) 可保证后验方差是真实方差的保守上界。
证明：GLS 公式；等相关矩阵特征值为 1+(n−1)ρ（重数 1）与 1−ρ（重数 n−1），代入即得。∎
**系 52.1** n=6、ρ=0.5 时过度自信 3.5 倍；这正是「一趟行程六条回执」的典型场景。

**引理 53（路径组合的交换性与有界分歧）**
记 o_i 为热替换操作、D_i 为其依赖闭包。若 D_i∩D_j=∅ 且版本独立，则 o_i∘o_j=o_j∘o_i；
若路径按 D(·) 的拓扑序执行，最终 EC 与同操作的批量组合逐字段相等。
违反偏序时，版本锁拒绝 stale 写；若强制重基，最终契约与批量结果的偏差满足
‖EC_final − EC_batch‖ ≤ L·Σ_i ‖I_i^stale − I_i^fresh‖，L 为下游契约的 Lipschitz 常数。
证明：对操作序列归纳；闭包不交保证无 read-after-write 冲突，版本锁检测写-写冲突；偏差项由接口误差经 Lipschitz 传播。∎

**引理 54（信用守恒与预算不变式）**
若 ∀r，Σ_s credit(r,s) ≤ 1，则规划器可申报的总增益不超过观测联合信息增益：
Σ_s Σ_r credit(r,s)·g_s(r) ≤ I(U_{1..m}; R)。因此 PB-Contract 下的预算记账不会因共享回执而虚增，
「一条回执服务多个盲区」不会让规划器买到不存在的收益。
证明：信用是对每条回执信息量在盲区间的次随机分摊；由链式法则与数据处理不等式，分摊和不超过联合互信息。∎

**引理 55（时序、安全与退化保持）**
R-Box/RP-Plan/F-Box/C-Box 全部在 50Hz 计量路径之外异步运行；50Hz 周期新增仅为路线查表 O(1)。
路径执行受 Ω_safe 约束且任一航点可中止；重规划受 K_replan/B_plan 限制；
退化链（定义 444）保证任一模块失效时回到 ToolGauge 的已知性质，故硬实时（引理 45）、预算不变式与热替换等价性（引理 49/53）保持。
证明：与引理 50 同构；新增层不改变 50Hz 数据流，只在事件路径上增加可中止的物理动作。∎

**负结果（本轮最重要的「不要做什么」）**：若把「路径规划」理解为「先打包、后校准」的两阶段流水线，
则规划器优化的是一个**已被相关性污染的代理目标**；打包越多，代理越乐观，融合越过度自信。
因此本轮把相关性约束前置到规划阶段（DB，定义 443），而不是留到校准阶段补救。

## 6. 本轮最大风险（一句话）

**一句话**：路径规划为了省行程会把盲区打包进同一段运动、同一光照与同一热状态，
这会让回执共享扰动、n_eff 骤降；若融合层低估相关性，系统会在**效率最高的路线上最过度自信**，
而「路线修复证书」还会让这种过度自信看起来更有据可查——E449/E452 为证伪实验，依赖性预算与来源不相交见证为在线防线。

**次级风险与缓解**：
1. **相关性估计滞后** → 用上界 ρ̂ 而非点估计；ρ 不可估时 n_eff=1（保守退化）；
2. **规划 NP-hard / 超时** → 小规模精确、大规模启发式；超时按 ToolGauge 顺序修复；
3. **非交换热替换** → 依赖闭包拓扑序 + 版本锁 + 有界分歧（引理 53）；
4. **共享回执双重计数** → 信用守恒不变式（定义 446）；
5. **路径运动安全** → Ω_safe + PROBING + 任一航点可中止（定义 442）；
6. **重规划抖动/预算耗尽** → K_replan + 遗憾预算 + 退化链；
7. **路径级假设冲突** → SNC-P（定义 447）：同一批观测不能同时支持矛盾指纹。

## 2. 形式化定义（要点）

**定义 432–434（R-Box / IRP / PB-Contract）** 在「盲区 × 位姿」图上定义移动代价、耦合边与边际信息增益；
路径效用 = 折扣增益 − 路径代价，受预算、依赖偏序、依赖性预算与运动包络约束；
PB 在 TB-Contract 上增加移动预算、路径/批量上限、规划时延与重规划次数。
**定义 435–438（F-Box / 来源图 / n_eff / 融合证书）** 融合必须携带来源图；独立证据由「无共享祖先」定义，而非工具名；
等相关批用 n_eff = n/(1+(n−1)ρ) 折算；witness 必须来源不相交，否则证书 provisional、禁止热替换。
**定义 439–440（组合 / 版本锁）** 依赖闭包不交 ⇒ 热替换可交换；否则按 D(·) 拓扑序执行；
版本化世界锁检测 stale 写，冲突时重基或延迟，禁止静默覆盖。
**定义 441–442（重规划 / 安全）** 预测增益失准、n_eff 不足、新盲区、路径阻断均触发重规划，受 K_replan 与遗憾预算限制；
PROBING 路径受 Ω_safe 约束，任一航点可零副作用中止。
**定义 443–445（依赖性预算 / 退化 / 安全路径）** 规划器申报 ρ_max，融合只接受 ρ̂ ≤ ρ_max 的批量；
规划/融合失效按退化链回退；不存在满足偏序的批量方案时禁止批量、退化为拓扑序顺序修复。
**定义 446–448（信用守恒 / SNC-P / 路线证书）** 一条回执跨盲区共享时信用分摊且总和 ≤1；
同一批观测不得同时支持互相矛盾的假设指纹；路线证书的数值字段必须逐字绑定回执或账本。
**定义 449（退化特例）** 单节点、无批量、C=I、依赖闭包两两不交 ⇒ RouteGauge ≡ ToolGauge。

def routegauge_8c(M, spots):

## 4. 推导

**引理 51（信息路径近似性与子模性失效）**
(a) 自适应子模收益 + 三角不等式代价 + 基数预算 ⇒ greedy 达 (1−1/e)；一般预算为 NP-hard，仅 |V|≤12 用子集 DP 精确。
(b) 路径诱导相关 ρ>0 且只能事后观测时，独立增益是乐观估计，偏差因子 1+(|β|−1)ρ；
不存在与 ρ 无关的常数近似比，除非引入依赖性预算或把 n_eff 作为硬约束。
证明：标准自适应子模贪心；负结果由「两次独立观测 vs 一次观测的两次拷贝」不可区分构造。∎

**引理 52（相关融合与过度自信因子）**
Σ = σ²C ⇒ BLUE 均值方差 σ²(1ᵀC⁻¹1)⁻¹，n_eff = 1ᵀC⁻¹1；等相关 ρ 时 n_eff = n/(1+(n−1)ρ)。
误用 n 会低估方差因子 1+(n−1)ρ；用上界 ρ̂ 的 n_eff(ρ̂) 给保守上界。
系：n=6、ρ=0.5 时过度自信 3.5 倍。∎

**引理 53（路径组合交换性与有界分歧）**
依赖闭包不交且版本独立 ⇒ 热替换可交换；按拓扑序执行 ⇒ 与批量组合逐字段相等。
违反偏序时版本锁拒绝 stale 写；强制重基的偏差 ≤ L·Σ‖I_stale − I_fresh‖。∎

**引理 54（信用守恒）**
∀r，Σ_s credit(r,s) ≤ 1 ⇒ Σ_s Σ_r credit(r,s)·g_s(r) ≤ I(U_{1..m}; R)；
共享回执不会在 PB-Contract 下虚增可申报增益。∎

**引理 55（时序、安全与退化保持）**
规划/融合/组合全异步于 50Hz 路径之外，周期新增 O(1) 查表；
路径受 Ω_safe 约束、可中止；重规划受 K_replan/B_plan 限制；
退化链保证任一模块失效回到 ToolGauge 已知性质 ⇒ 硬实时、预算不变式与热替换等价性保持。∎

**负结果**：把路径规划做成「先打包、后校准」的两阶段流水线，会优化一个被相关性污染的代理目标；
打包越多越乐观，融合越过度自信。故相关性约束必须前置到规划阶段（定义 443）。

## 7. 与 ToolGauge 的差异与继承

- **继承**：D-Box 盲区判定（398/399）、风险门 λ（400）、M_ver（401）、热替换定理（引理 44）、IV-Contract（407，细化为 PB-Contract 434）、6C 闭环（421）、语言主张绑定（423/427）、P-Quarantine（428）、退化链（444）。
- **修复（ToolGauge 缺陷审计）**：按检测顺序逐点修复 → R-Box + RP-Plan；回执 i.i.d. 假设 → F-Box 来源图 + n_eff；工具名即独立 → 来源不相交性；共享回执双重计数 → 信用守恒；乱序热替换 → 依赖闭包 + 版本锁；无运动安全约束 → Ω_safe + 可中止；无重规划 → 触发条件 + 遗憾预算；退化链未覆盖规划/融合 → 扩展。
- **新增**：路径规划层（IP-321/324）、融合与来源层（IP-322）、组合与版本层（IP-323）、8C 闭环（IP-325）、两条新不变式（信用守恒、相关性诚实）。

## 8. 本轮最大风险

**一句话**：路径规划为了省行程会把盲区打包进同一段运动、同一光照与同一热状态，
让回执共享扰动、n_eff 骤降；若融合层低估相关性，系统会在**效率最高的路线上最过度自信**，
而路线修复证书会让这种过度自信显得更可信——以 E449/E452 证伪，
依赖性预算（定义 443）、上界 ρ̂、来源不相交 witness（定义 438）与退化链（定义 444）四重兜底。
