# 第 67 轮（承接第 66 轮「RAS 情绪驱动闭环」IP-224~233；本次灵感循环第 2 轮；本轮灵感：「手眼标定」×「社会影响」）

> 第 66 轮 RAS 把 VISTA 的「被动故障响应」升级为「主动意图感知」：用面部表情估计风险态度 λ_risk，再把情绪当作一类故障维度并入贝叶斯归因。但 RAS 隐含了一个从未被检验的前提：**它假设「主体的风险信号」与「机器人的动作」处在同一个参考系里**——即表情表达的风险、机器人据此执行的动作，天然对齐、可以逐帧相乘。
>
> 这个前提在真实的人-机-群体场景中几乎从不成立。眼睛看到的（传感器系）与手能做的（执行器系）之间差一个**手眼变换**；不同主体对同一风险的「表达尺度」与「基线」又各不相同，而这些差异会被群体互动进一步放大或抹平——这正是**社会影响**。
>
> 本轮的核心命题：
>
> **把「参考系」从一个默认共享的常量，升级为需要被联合估计的变量：用「手眼标定」的 `AX=XB` 结构对齐多主体的几何参考系，用「社会影响」的仿射规范（gauge）结构对齐多主体的风险参考系；二者共享同一个可辨识性条件——激励度（excitation）。**
>
> 新框架 **CHAI（Calibrated Hand-eye And Influence）** 问的不是「故障该去哪儿」，也不是「谁该控制」，而是：**我们是否在看同一个世界、量同一把尺？在证明这件事之前，任何跨主体的风险融合都不具备证书效力。**

## 0. 直觉与动机

**灵感 1（手眼标定：`AX=XB` 本质是「两个参考系之间的一次对齐」）**
直觉：经典手眼标定要解 `A X = X B`：A 是机械臂末端在两个位姿间的相对运动，B 是相机观察到的同一运动的相对表达，X 是「眼到手」的固定变换。它成立的前提是：A 与 B 描述的是**同一个物理事件**，只是分别用两个坐标系表达。求解的难点从来不是方程本身，而是**激励度**——如果所有标定动作都绕同一根轴旋转，X 的旋转部分就不可辨识（退化）。这给了本轮第一个隐喻：**没有足够「差异」的数据，两个参考系就无法对齐**。

**灵感 2（社会影响：风险信号带「尺度」与「基线」，是一层仿射规范）**
直觉：不同人对同一风险的反应并不相同。有人天生紧张（基线偏置 β 高），有人对变化更敏感（尺度 σ 大）。设潜在风险为 r*，主体 a 表达出的风险约为

```
r_a = σ_a · r* + β_a + 噪声
```

这不是「加一点噪声」，而是对风险做了一次**仿射变换**。当多个主体互相观察、互相说服时，改变的不是某一帧的风险值，而是 (σ_a, β_a) 这两个参数本身——群体让尺度趋同（从众），或反向放大（对抗）。所以社会影响的正确数学位置是：**作用在风险参考系的规范（gauge）上**，而不是直接叠加在观测上。

**灵感 3（关键的合流：手眼标定的「激励度」= 社会规范的「风险激励」）**
直觉：把上面两件事并排看，会发现它们是同一个问题：

| 手眼标定 | 社会规范标定 |
|---|---|
| 相机系 vs 机械臂系 | 主体 a 的风险系 vs 主体 b 的风险系 |
| 刚体变换 X | 仿射规范 (σ, β) |
| 相对运动对 (A_i, B_i) | 同一潜在事件的风险对 (r_{a,i}, r_{b,i}) |
| 旋转轴多样 → X 可辨识 | 风险水平多样 → (σ, β) 可辨识 |
| 所有轴平行 → 退化 | 所有事件都「正常」→ 退化 |
| `A X = X B` | `r_a = σ r_b + β` |

于是「手眼标定」与「社会影响」不是两个拼贴的灵感词，而是**同一套可辨识性理论的两个实例**：都用成对观测对齐两个参考系，都因激励不足而退化。这是本轮最想抓住的结构性洞察。

**灵感 4（联合标定 → 拆开「标定漂移」与「从众偏差」的混淆）**
直觉：如果只分开标定，会有一个致命混淆——「机器人的几何标定漂了」和「群体把风险尺子拉偏了」都能解释同一批残差。但二者的**激励方向不同**：几何漂移由运动激励暴露，社会偏差由风险激励暴露。把它们放进同一个 bundle，让几何残差与社会残差各自提供独立约束，就能把 C（标定）、Q（社会）两类假设分开。这直接升级了 RAS 里 `H_emotion` 之后缺失的两维故障来源。

**灵感 5（对 RAS/VISTA 的组件化升级，以及一个反直觉的安全原则）**
直觉：本轮不是推翻 RAS，而是给它补上「参考系前提」：

- **EFS → HSC**：假设集从 `ℋ × E` 扩展为 `ℋ × E × C × Q`；
- **C-RAS → CHAI-Cert**：认证前缀从「情绪认证」升级为「情绪 + 标定 + 社会影响」三重认证；
- **λ_risk 的乘法前提**：只有在规范标定通过后，跨主体风险才允许融合；否则拒绝融合；
- **反直觉安全原则**：当标定退化或社会不可信时，CHAI **收紧**几何球，绝不像 RAS 那样因「看起来安全」而放宽。理由很简单——**在一个不可信的参考系里，「安全」这个判断本身就没有意义**。

## 1. 形式化定义（定义 245–258）

- **定义 245（CHAI 总览）**：`CHAI = (HEC, SGC, JCB, GIF, SEB, ACSP, SIR, HSC, CHAI-Cert)`。定位：把 RAS 的「意图闭环」升级为「参考系闭环」。不变式：几何标定、社会规范、联合优化、证书构建只在语义流；实时流只做残差投影、激励度告警、影响预算早停，零学习写操作。
- **定义 246（多主体相对手眼变换）**：主体 a 的传感器系 S_a 与执行系 E_a 之间的手眼变换 `X_a ∈ SE(3)`。对共同事件 i，a、b 观测同一刚体运动，得到相对运动 A_i（b 执行系）与 B_i（a 传感器系）。相对手眼 `Y_ab = X_a^{-1} X_b` 满足 `A_i Y_ab = Y_ab B_i, ∀i`。Y_ab 把「a 看到的」映到「b 做的」。
- **定义 247（激励度与退化）**：令 `{u_i}` 为相对旋转轴单位向量，`M_rot = Σ_i u_i u_i^T`。激励指数 `κ_exc = σ_2(M_rot)/σ_1(M_rot)`。若 `κ_exc < τ_exc` 或 `rank(M_rot) < 2`，称标定**激励不足**，X 的旋转分量不可辨识。
- **定义 248（风险帧与社会规范变换）**：主体 a 的风险表达参数 `θ_a = (σ_a, β_a), σ_a > 0`。对潜在风险 r*_i：`r_{a,i} = σ_a r*_i + β_a + η_{a,i}`。称 `G_a: r* ↦ σ_a r* + β_a` 为 a 的风险规范（仿射 gauge）；σ_a 为敏感度尺度，β_a 为基线偏置。
- **定义 249（相对社会规范与可辨识性）**：消去 r*_i 得 `r_{a,i} = s_ab r_{b,i} + t_ab`，其中 `s_ab = σ_a/σ_b, t_ab = β_a - s_ab β_b`。称 `g_ab = (s_ab, t_ab)` 为相对社会规范。全局规范固定 `σ_0=1, β_0=0`。设计矩阵 `D = [1, r*]`；当且仅当 `rank(D)=2`（至少两个不同风险水平且 `Var(r*)>0`）时 `(σ_a, β_a)` 可辨识。风险激励指数 `κ_risk = σ_2(D^T D)/σ_1(D^T D)`。
- **定义 250（社会影响算子）**：社会影响体现为规范参数在群体耦合下的动力学：
  `θ_a(t+1) = θ_a(t) + κ_soc Σ_b w_ab (θ_b(t) - θ_a(t)) + ξ_a`。
  `w_ab` 为影响权重（信任/从众），`κ_soc` 为耦合强度。谱半径 ρ(W) 决定从众稳定域。**社会影响作用在尺度与基线上，而非直接作用于风险值。**
- **定义 251（联合标定目标 JCB）**：联合估计 `{X_a, θ_a}`：
  `min Σ_i ρ_kin(||log(A_i^{-1} Y_ab B_i Y_ab^{-1})||²_{Σ_kin}) + λ_s Σ_{a,i} ρ_s((r_{a,i} - σ_a r*_i - β_a)²/ς²)`，
  约束 `X_0 = I, σ_0 = 1, β_0 = 0`；`ρ_kin, ρ_s` 为 Huber 鲁棒核。
- **定义 252（规范不变融合 GIF）**：将各主体风险映到公共规范 `\tilde r_{a,i} = (r_{a,i} - β_a)/σ_a`，融合 `r̂_i = Σ_a w_a \tilde r_{a,i}`（`Σ w_a = 1`）。GIF 要求 r̂ 对锚点主体的选择不变。
- **定义 253（社会激励偏差 SEB）**：若标定动作集合 𝒜 由社会可接受性筛选（如避免别扭关节构型），实际激励度 `E_exc(𝒜)` 低于可达激励度 `E_exc*(𝒜)`。定义 `Δ_SEB = E_exc*(𝒜) - E_exc(𝒜_social)`；`Δ_SEB > τ_SEB` 时判为「社会性欠激励」。
- **定义 254（主动标定社会成本）**：动作 a 的信息增益 `IG(a)` 与社会成本 `c_soc(a)`（不适、尴尬、时间）。ACSP 选择 `a* = argmax IG(a)/c_soc(a)`，约束 `c_soc ≤ C_max`。
- **定义 255（影响函数与影响预算）**：融合估计对主体 a 的影响函数 `IF_a = w_a(\tilde r_a - r̂)`。若至多 m 个主体对抗且 `\tilde r_a ∈ [0, R_max]`，则 `|r̂ - r̂_clean| ≤ 2 R_max Σ_{a∈bad} w_a =: B_inf`，称 B_inf 为社会影响预算。
- **定义 256（扩展假设集）**：在 RAS 的 `ℋ × E` 上新增标定维度 `C = {C0 标定良好, C1 慢漂移, C2 激励不足}` 与社会维度 `Q = {Q0 无影响, Q1 从众偏差, Q2 对抗操纵}`，得 `ℋ_CHAI = ℋ × E × C × Q`。
- **定义 257（CHAI 认证前缀）**：对块 A_t，`k*CHAI` 需满足：1) `k ≤ k_RAS`；2) 标定认证 `∀s≤k: margin(s) - ||Σ_X^{1/2}||·||J_s|| ≥ 0`；3) 社会认证 `∀s≤k: r̂_s + B_inf ≤ R_limit`；4) `k*CHAI ≤ m_CHAI = min(m_RAS, m_calib, m_social)`。
- **定义 258（标定漂移慢故障）**：`X(t), θ(t)` 建模为随机游走；检测器 `D_t = ||log(Y_ab(t)^{-1} \hat Y_ab)||_Σ` 的 CUSUM 统计量，越阈触发 `H_calib = C1` 与主动重标定。

## 2. 关键算法骨架

```python
# HEC：多主体手眼标定（AX = XB）
class HandEyeCalibrator:
    def solve(self, motions):                 # motions = [(A_i, B_i)]
        X0 = closed_form_axxb(motions)        # 对偶四元数 / 李代数闭式初值
        X = gauss_newton(
            lambda X: [log(inv(A_i) @ X @ B_i @ inv(X)) for A_i, B_i in motions], X0)
        M_rot = sum(outer(axis(u), axis(u)) for u in rotation_axes(motions))
        sv = singular_values(M_rot)
        kappa = sv[1] / max(sv[0], 1e-9)
        return {'Y_ab': X, 'cov': gauss_newton_cov(motions, X),
                'kappa_exc': kappa,
                'degenerate': kappa < TAU_EXC or rank(M_rot) < 2}


# SGC：社会规范（风险帧）标定
class SocialGaugeCalibrator:
    def solve(self, paired_risks):            # [(r_a_i, r_b_i)]
        D = design_matrix(paired_risks)       # 两列 [1, r*]
        kappa = cond(D.T @ D)
        if rank(D) < 2 or kappa < TAU_RISK:
            return {'identifiable': False, 'kappa_risk': kappa}
        s_ab, t_ab = robust_lstsq(design(paired_risks), target(paired_risks))
        sigma, beta = recover_global_gauge(s_ab, t_ab)   # 锚点 agent0
        return {'sigma': sigma, 'beta': beta,
                'cov': robust_cov(paired_risks, (sigma, beta)),
                'identifiable': True, 'kappa_risk': kappa}


# JCB：联合标定（规范固定 + 鲁棒核）
def joint_calibration_bundle(agents, motions, paired_risks, ref=0):
    X = {a: X0[a] for a in agents}; theta = {a: theta0[a] for a in agents}
    X[ref], theta[ref] = SE3.identity(), (1.0, 0.0)   # 规范固定
    for _ in range(MAX_ITER):
        X = update_kinematics(X, motions, huber=1.345)
        theta = update_social(theta, paired_risks, huber=1.345)
    return X, theta, fisher_information(X, theta)


# GIF：规范不变融合
def gauge_invariant_fusion(paired_risks, theta, weights):
    r_tilde = {a: [(r - theta[a][1]) / theta[a][0] for r in rs]
               for a, rs in paired_risks.items()}
    return [sum(weights[a] * r_tilde[a][i] for a in r_tilde)
            for i in range(len(next(iter(r_tilde.values()))))]


# SIR：影响预算 + 鲁棒融合
def social_influence_rejection(risks, weights, R_max, m_adv):
    ordered = sorted(weights.values(), reverse=True)
    B_inf = 2.0 * R_max * sum(ordered[:m_adv])
    return {'r_hat': trimmed_weighted_mean(risks, weights),
            'B_inf': B_inf,
            'breakdown': m_adv / (m_adv + len(risks))}


# CHAI 闭环：在 RAS 前向上补「参考系认证」
def CHAI_round(M, obs, motions, paired_risks):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs

    # 1) RAS 原有前向
    face_gate = M.er.gateway.recognize(img)
    A = M.vista.ach.propose(M.lsf.fuse(M.usr.fuse(V, T, P, L)), H=M.vista.H)
    rho = M.vista.fir.signature(M.vista.stage.split(M.vista.residual_log))
    joint_post, _ = M.efs.synthesize(rho, face_gate)

    # 2) HEC + SGC（可辨识性门控）
    hec = M.hec.solve(motions)
    sgc = M.sgc.solve(paired_risks)
    if hec['degenerate'] or not sgc['identifiable']:
        M.vista.geo_ball.shrink(0.5)          # 失效安全：收紧，绝不放宽
        M.trigger_active_recalibration(M.acsp.plan(motions, paired_risks))
        X, theta, fisher = None, None, None
    else:
        X, theta, fisher = M.jcb.optimize(motions, paired_risks)

    # 3) GIF + SIR 融合多主体风险
    r_hat = M.gif.fuse(paired_risks, theta, M.weights)
    sir = M.sir.reject(r_hat, M.weights, R_max=M.R_max, m_adv=M.m_adv)

    # 4) 扩展假设集 C / Q
    joint_post = M.hsc.extend(joint_post, hec, sgc, fisher)

    # 5) 三重认证前缀
    k_ras = M.csc_ras.certified_prefix_ras(A, joint_post, M.m_ras, M.alpha_chunk)
    k_calib = M.cert.calib_prefix(A, hec['cov'], M.m_calib)
    k_social = M.cert.social_prefix(A, sir, M.m_social)
    k_chai = min(k_ras, k_calib, k_social)

    tau_cmd = M.vista.pi_sigma.prefix_dispatch(A[:k_chai])
    tau_cmd *= M.efs.risk_scale(joint_post)
    return k_chai, hec, sgc, sir, joint_post
```

## 3. 推导（引理 11–12，定理 11–13）

**引理 11（GIF 规范不变性）** 对任意锚点主体选择 a0，GIF 输出的 r̂_i 相同。证明要点：规范变换 `(σ_a, β_a) ↦ (σ_a/σ_{a0}, (β_a - β_{a0})/σ_{a0})` 与风险值同步变换，`\tilde r_a` 是商空间元素；加权平均只依赖商空间元素，故与锚点无关。**推论**：不能通过「换一个参考主体」来操纵融合结论——这堵住了社会影响的一条隐蔽通道。

**引理 12（激励度 ⇔ 可辨识性，统一误差界）** 设噪声有界 `||η|| ≤ ε`，则手眼旋转误差 `||δφ|| ≤ C_kin·ε/κ_exc`，社会规范误差 `||δθ|| ≤ C_soc·ε/κ_risk`。当 `κ_exc < τ_exc` 或 `κ_risk < τ_risk` 时误差无界。**这把 `AX=XB` 的运动激励条件与风险规范的激励条件统一为同一句话：激励不足 ⇒ 标定不可辨识。** 它是 CHAI 一切证书的门控条件。

**定理 11（联合标定抑制 C1↔Q1 混淆）** 当存在独立风险激励（`rank(D)=2` 且风险变化不能被位姿单独解释）时，联合 Fisher 信息矩阵满足 `J_joint ⪰ blockdiag(J_kin, J_soc)`，故 `κ(J_joint) ≤ min(κ(J_kin), κ(J_soc))`，C1（标定漂移）与 Q1（从众偏差）后验可分；当风险变化与位姿完全共线时二者不可分，只能给出置信集合，必须由 ACSP 主动激发独立激励。

**定理 12（影响预算的鲁棒保证）** 若信任权重 `Σ w_a = 1` 且至多 m 个主体对抗，采用截尾权重融合可保证 breakdown point `≥ m/(m+n)`，且 `|r̂ - r̂_clean| ≤ B_inf`。因此社会影响对认证前缀的扰动被**证书化**：证书里携带 B_inf，安全员可审计。

**定理 13（CHAI 端到端安全一致性）** 在 A87–A91 与 `κ_exc ≥ τ_exc, κ_risk ≥ τ_risk` 下：
1. `P(|τ_cmd - τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_calib + α_social`；
2. `k*CHAI` 保证执行风险 `≤ R_limit + B_inf`（证书化）；
3. 若 `C = C2` 或 `Q = Q2`，则 `k*CHAI ≤ k_RAS` 且强制触发主动重标定，**绝不放宽几何球**。

## 6. 本轮最大风险

**一句话**：CHAI 的最大风险是把「社会共识」误当成「几何真值」——当标定动作被社会规范限制在低激励区域时，手眼位姿与社会规范 `(σ, β)` 联合欠定，系统却仍可能以高置信度发证，把被群体压力拉偏的风险帧当作共同参考系；**校准越「成功」，群体性误判越隐蔽**。

**次级风险与缓解**：
1. **联合欠定**：κ_exc、κ_risk 双门控，任一不足即拒证并收紧几何球；
2. **共线混淆**：位姿与风险完全共线时 C1/Q1 不可分 → ACSP 主动激发独立风险事件；
3. **社会成本过高**：主动标定可能被用户拒绝 → 用信息增益/社会成本比排序，必要时降级为「部分可辨识 + 保守证书」；
4. **群体操纵**：多数主体协同作假 → SIR 采用截尾/中位数聚合，并显式记录 B_inf，不做点估计承诺；
5. **实时算力**：联合优化只在语义流/离线，实时流仅做残差投影与预算查表，保持 <2ms。

## 2. 形式化定义（完整版）

**定义 245（CHAI 总览）** CHAI 把 RAS 的「意图闭环」升级为「参考系闭环」：
```
CHAI = (HEC, SGC, JCB, GIF, SEB, ACSP, SIR, HSC, CHAI-Cert)
```
不变式：几何标定、社会规范、联合优化、证书构建只在语义流；实时流只做残差投影、激励度告警、影响预算早停，零学习写操作。

**定义 246（多主体相对手眼变换）** 主体 a 的传感器系 S_a 与执行系 E_a 之间的手眼变换为 `X_a ∈ SE(3)`。对共同事件 i，a、b 观测同一刚体运动，得到 A_i（b 执行系相对运动）与 B_i（a 传感器系相对运动）。相对手眼 `Y_ab = X_a^{-1} X_b` 满足：
```
A_i Y_ab = Y_ab B_i,  ∀i
```
Y_ab 把「a 看到的」映到「b 做的」。经典手眼标定是本定义在单主体、固定内参下的特例。

**定义 247（激励度与退化）** 令 `{u_i}` 为相对旋转轴单位向量，旋转散度矩阵 `M_rot = Σ_i u_i u_i^T`。激励指数：
```
κ_exc = σ_2(M_rot) / σ_1(M_rot)
```
若 `κ_exc < τ_exc` 或 `rank(M_rot) < 2`，称标定**激励不足**，X 的旋转分量不可辨识；平移分量还需非平行平移与非零位移，综合激励度记为 E_exc。

**定义 248（风险帧与社会规范变换）** 主体 a 的风险表达参数 `θ_a = (σ_a, β_a), σ_a > 0`。对潜在风险 r*_i：
```
r_{a,i} = σ_a · r*_i + β_a + η_{a,i}
```
称 `G_a: r* ↦ σ_a r* + β_a` 为 a 的风险规范（仿射 gauge）。σ_a 为敏感度尺度（对风险变化的放大/缩小），β_a 为基线偏置（慢性紧张/镇定）。

**定义 249（相对社会规范与可辨识性）** 消去 r*_i 得：
```
r_{a,i} = s_ab · r_{b,i} + t_ab,
s_ab = σ_a/σ_b,  t_ab = β_a - s_ab β_b
```
称 `g_ab = (s_ab, t_ab)` 为相对社会规范。全局规范固定 `σ_0 = 1, β_0 = 0`。设计矩阵 `D = [1, r*] ∈ ℝ^{n×2}`；当且仅当 `rank(D)=2`（至少两个不同风险水平且 `Var(r*)>0`）时 `(σ_a, β_a)` 可辨识。风险激励指数：
```
κ_risk = σ_2(D^T D) / σ_1(D^T D)
```

**定义 250（社会影响算子）** 社会影响体现为规范参数在群体耦合下的动力学：
```
θ_a(t+1) = θ_a(t) + κ_soc Σ_b w_ab (θ_b(t) - θ_a(t)) + ξ_a
```
w_ab 为影响权重（信任/从众），κ_soc 为耦合强度。谱半径 ρ(W) 决定从众稳定域：ρ(W) 小则规范保持多样，ρ(W) 接近 1 则尺度与基线趋同（从众）。**社会影响作用在尺度与基线上，而不是直接叠加在风险观测上。**

**定义 251（联合标定目标 JCB）** 联合估计 `{X_a, θ_a}`：
```
min_{X_a,θ_a}  Σ_i ρ_kin( || log(A_i^{-1} Y_ab B_i Y_ab^{-1}) ||²_{Σ_kin} )
             + λ_s Σ_{a,i} ρ_s( (r_{a,i} - σ_a r*_i - β_a)² / ς² )
s.t.  X_0 = I,  σ_0 = 1,  β_0 = 0
```
ρ_kin、ρ_s 为 Huber 鲁棒核。规范固定消除了「整体平移/缩放」的规范自由度，与手眼标定的全局参考系自由度同构。

**定义 252（规范不变融合 GIF）** 将各主体风险映到公共规范：
```
\tilde r_{a,i} = (r_{a,i} - β_a) / σ_a
r̂_i = Σ_a w_a · \tilde r_{a,i},   Σ_a w_a = 1
```
GIF 要求 r̂ 对锚点主体的选择不变（规范不变性）。

**定义 253（社会激励偏差 SEB）** 若标定动作集合 𝒜 由社会可接受性约束筛选（如避免别扭关节构型、避免频繁请求），实际激励度 `E_exc(𝒜)` 低于可达激励度 `E_exc*(𝒜)`：
```
Δ_SEB = E_exc*(𝒜) - E_exc(𝒜_social)
```
`Δ_SEB > τ_SEB` 时判定为「社会性欠激励」，禁止发证。

**定义 254（主动标定社会成本）** 动作 a 的信息增益 `IG(a)`（对 (X,θ) 的 Fisher 信息或互信息）与社会成本 `c_soc(a)`（不适、尴尬、时间）。ACSP 选择：
```
a* = argmax_a  IG(a) / c_soc(a),   s.t. c_soc(a) ≤ C_max
```

**定义 255（影响函数与影响预算）** 融合估计对主体 a 的影响函数 `IF_a = w_a(\tilde r_a - r̂)`。若至多 m 个主体对抗且 `\tilde r_a ∈ [0, R_max]`，则：
```
|r̂ - r̂_clean| ≤ 2 R_max Σ_{a∈bad} w_a =: B_inf
```
称 B_inf 为社会影响预算。截尾权重聚合的 breakdown point `≥ m/(m+n)`。

**定义 256（扩展假设集）** 在 RAS 的 `ℋ × E` 上新增标定维度与社会维度：
```
ℋ_CHAI = ℋ × E × C × Q,
C = {C0 标定良好, C1 慢漂移, C2 激励不足},
Q = {Q0 无影响, Q1 从众偏差, Q2 对抗操纵}
```
联合后验：
```
P(H,E,C,Q | ρ, face, motions, risks)
  ∝ p(ρ | H) · p(face | E) · p(motions | C) · p(risks | Q) · P(H,E,C,Q)
```

**定义 257（CHAI 认证前缀）** 对块 A_t，`k*CHAI` 需满足：
1. RAS 认证：`k ≤ k_RAS`；
2. 标定认证：`∀s≤k: margin(s) - ||Σ_X^{1/2}||·||J_s|| ≥ 0`；
3. 社会认证：`∀s≤k: r̂_s + B_inf ≤ R_limit`；
4. `k*CHAI ≤ m_CHAI = min(m_RAS, m_calib, m_social)`。

**定义 258（标定漂移慢故障）** `X(t), θ(t)` 建模为随机游走：
```
X(t+1) = X(t) exp(ξ_t),  ξ_t ~ N(0, Σ_ξ)
θ(t+1) = θ(t) + ζ_t,     ζ_t ~ N(0, Σ_ζ)
```
检测器 `D_t = || log(Y_ab(t)^{-1} \hat Y_ab) ||_Σ` 的 CUSUM 统计量越阈，触发 `H_calib = C1` 与主动重标定。

# IP-234 HEC：多主体手眼标定（AX = XB）
class HandEyeCalibrator:
    def solve(self, motions):                 # motions = [(A_i, B_i)]
        X0 = closed_form_axxb(motions)        # 对偶四元数 / 李代数闭式初值
        X = gauss_newton(
            lambda X: [log(inv(A_i) @ X @ B_i @ inv(X)) for A_i, B_i in motions],
            X0)
        M_rot = sum(outer(axis(u), axis(u)) for u in rotation_axes(motions))
        sv = singular_values(M_rot)
        kappa = sv[1] / max(sv[0], 1e-9)
        return {'Y_ab': X, 'cov': gauss_newton_cov(motions, X),
                'kappa_exc': kappa, 'excitation_rank': rank(M_rot),
                'degenerate': kappa < TAU_EXC or rank(M_rot) < 2}


# IP-235 SGC：社会规范（风险帧）标定
class SocialGaugeCalibrator:
    def solve(self, paired_risks):            # [(r_a_i, r_b_i)]
        D = design_matrix(paired_risks)       # 两列 [1, r*]
        kappa = cond(D.T @ D)
        if rank(D) < 2 or kappa < TAU_RISK:
            return {'identifiable': False, 'kappa_risk': kappa}
        s_ab, t_ab = robust_lstsq(design(paired_risks), target(paired_risks))
        sigma, beta = recover_global_gauge(s_ab, t_ab)   # 锚点 agent0
        return {'sigma': sigma, 'beta': beta,
                'cov': robust_cov(paired_risks, (sigma, beta)),
                'identifiable': True, 'kappa_risk': kappa}


# IP-236 JCB：联合标定（规范固定 + 鲁棒核）
def joint_calibration_bundle(agents, motions, paired_risks, ref=0):
    X = {a: X0[a] for a in agents}
    theta = {a: theta0[a] for a in agents}
    X[ref], theta[ref] = SE3.identity(), (1.0, 0.0)   # 规范固定
    for _ in range(MAX_ITER):
        X = update_kinematics(X, motions, huber=1.345)
        theta = update_social(theta, paired_risks, huber=1.345)
    return X, theta, fisher_information(X, theta)


# IP-237 GIF：规范不变融合
def gauge_invariant_fusion(paired_risks, theta, weights):
    r_tilde = {a: [(r - theta[a][1]) / theta[a][0] for r in rs]
               for a, rs in paired_risks.items()}
    n = len(next(iter(r_tilde.values())))
    return [sum(weights[a] * r_tilde[a][i] for a in r_tilde) for i in range(n)]


# IP-240 SIR：影响预算 + 鲁棒融合
def social_influence_rejection(risks, weights, R_max, m_adv):
    ordered = sorted(weights.values(), reverse=True)
    B_inf = 2.0 * R_max * sum(ordered[:m_adv])
    return {'r_hat': trimmed_weighted_mean(risks, weights),
            'B_inf': B_inf,
            'breakdown': m_adv / (m_adv + len(risks))}


# IP-241/242 CHAI 闭环：在 RAS 前向上补「参考系认证」
def CHAI_round(M, obs, motions, paired_risks):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs

    # 1) RAS 原有前向
    face_gate = M.er.gateway.recognize(img)
    A = M.vista.ach.propose(M.lsf.fuse(M.usr.fuse(V, T, P, L)), H=M.vista.H)
    rho = M.vista.fir.signature(M.vista.stage.split(M.vista.residual_log))
    joint_post, _ = M.efs.synthesize(rho, face_gate)

    # 2) HEC + SGC（可辨识性门控）
    hec = M.hec.solve(motions)
    sgc = M.sgc.solve(paired_risks)
    if hec['degenerate'] or not sgc['identifiable']:
        M.vista.geo_ball.shrink(0.5)          # 失效安全：收紧，绝不放宽
        M.trigger_active_recalibration(M.acsp.plan(motions, paired_risks))
        X, theta, fisher = None, None, None
    else:
        X, theta, fisher = M.jcb.optimize(motions, paired_risks)

    # 3) GIF + SIR 融合多主体风险
    r_hat = M.gif.fuse(paired_risks, theta, M.weights)
    sir = M.sir.reject(r_hat, M.weights, R_max=M.R_max, m_adv=M.m_adv)

    # 4) 扩展假设集 C / Q
    joint_post = M.hsc.extend(joint_post, hec, sgc, fisher)

    # 5) 三重认证前缀
    k_ras = M.csc_ras.certified_prefix_ras(A, joint_post, M.m_ras, M.alpha_chunk)
    k_calib = M.cert.calib_prefix(A, hec['cov'], M.m_calib)
    k_social = M.cert.social_prefix(A, sir, M.m_social)
    k_chai = min(k_ras, k_calib, k_social)

    tau_cmd = M.vista.pi_sigma.prefix_dispatch(A[:k_chai])
    tau_cmd *= M.efs.risk_scale(joint_post)
    j_chai = M.cert.issue(joint_post, hec, sgc, sir)
    return k_chai, j_chai, joint_post

## 4. 推导

**引理 11（GIF 规范不变性）** 对任意锚点主体 a0，GIF 的 r̂_i 相同。规范变换 `(σ_a,β_a) ↦ (σ_a/σ_{a0}, (β_a-β_{a0})/σ_{a0})` 与风险值同步变换，`\tilde r_a` 是商空间元素，加权平均只依赖商空间元素，故与锚点无关。**推论**：换参考主体无法操纵融合结论。

**引理 12（激励度 ⇔ 可辨识性，统一误差界）** 设噪声有界 `||η|| ≤ ε`，则手眼旋转误差 `||δφ|| ≤ C_kin·ε/κ_exc`，社会规范误差 `||δθ|| ≤ C_soc·ε/κ_risk`；当 `κ_exc < τ_exc` 或 `κ_risk < τ_risk` 时误差无界。**手眼标定与风险规范标定共享同一可辨识性判据：激励不足 ⇒ 不可辨识。**

**定理 11（联合标定抑制 C1↔Q1 混淆）** 当存在独立风险激励（`rank(D)=2` 且风险变化不能被位姿单独解释）时：
```
J_joint ⪰ blockdiag(J_kin, J_soc)  ⇒  κ(J_joint) ≤ min(κ(J_kin), κ(J_soc))
```
C1（标定漂移）与 Q1（从众偏差）后验可分；若风险变化与位姿完全共线，二者不可分，只能输出置信集合，并由 ACSP 主动激发独立激励。

**定理 12（影响预算的鲁棒保证）** 若 `Σ w_a = 1` 且至多 m 个主体对抗，截尾权重融合的 breakdown point `≥ m/(m+n)`，且 `|r̂ - r̂_clean| ≤ B_inf`。社会影响对认证前缀的扰动被证书化、可审计。

**定理 13（CHAI 端到端安全一致性）** 在 A87–A91 与 `κ_exc ≥ τ_exc, κ_risk ≥ τ_risk` 下：
1. `P(|τ_cmd - τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_calib + α_social`；
2. `k*CHAI` 保证执行风险 `≤ R_limit + B_inf`；
3. 若 `C=C2` 或 `Q=Q2`，则 `k*CHAI ≤ k_RAS` 且强制主动重标定，**绝不放宽几何球**。

## 6. 本轮最大风险

**一句话**：CHAI 的最大风险是把「社会共识」误当成「几何真值」——当标定动作被社会规范限制在低激励区域时，手眼位姿与社会规范 `(σ, β)` 联合欠定，系统却仍可能以高置信度发证，把被群体压力拉偏的风险帧当作共同参考系；**校准越「成功」，群体性误判越隐蔽**。

**次级风险与缓解**：
1. **联合欠定**：κ_exc、κ_risk 双门控，任一不足即拒证并收紧几何球；
2. **共线混淆**：位姿与风险完全共线时 C1/Q1 不可分 → ACSP 主动激发独立风险事件；
3. **社会成本过高**：主动标定可能被用户拒绝 → 按信息增益/社会成本比排序，降级为「部分可辨识 + 保守证书」；
4. **群体操纵**：多数主体协同作假 → SIR 截尾/中位数聚合，显式记录 B_inf，不做点估计承诺；
5. **实时算力**：联合优化只在语义流/离线，实时流仅做残差投影与预算查表，保持 <2ms。
