# 第 44 轮（新循环第 4 轮） · Geo-Cert × Traj-Cert：把「点云配准」与「轨迹优化」纳入可验证证书闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形边际覆盖 + 多用户契约空集」，但它还压着两个更深的地基假设：**(H3) 几何被当作可信输入**——IP-49/56 把 LIO 输出的 C_ms、B_t、L_m 当成近似真值，配准退化、多模态歧义、动态点云这些「静默错误」根本没有进入证书链；**(H4) 轨迹被当作点证书的序列**——守卫只在当前状态或离散节点上判 margin，节点之间（真实连续执行）没有任何证书，而轨迹优化为时间最优会主动走激进机动，恰好加剧 (H3)。本轮灵感词「点云配准」「轨迹优化」精确命中地基：**点云配准**迫使我们承认「位姿不是给定的，而是被证书化的估计」，把退化方向、误差上界、多模态歧义变成显式证书；**轨迹优化**迫使我们把证书从「点」提升为「连续时间上的函数」，并用 rely-guarantee 把两个互相喂饭的子系统闭环。二者耦合处（配准靠运动观测、轨迹靠配准避障）是本轮真正的新问题：**激进轨迹破坏配准可观测性，配准退化又污染轨迹安全证书——两个各自 sound 的证书，组合起来可能静默不 sound。**

## 0. 直觉与动机

**灵感 1（点云配准 → 几何证书的地基必须自身持证）**：直觉上，走廊、隧道、空旷场地里 ICP/NDT 会「很自信地错」——沿走廊方向几乎没有约束、协方差被严重低估，但算法照样吐出一个位姿。所有下游几何证书（碰撞、ESDF、可达集）都是相对于这个错位姿「局部正确、全局错误」。所以要引入**配准证书 R=(T̂,Σ,D,A,ν)**：不只给点估计，还要给 (a) 保守误差上界，(b) **退化方向子空间 D**（Hessian/Fisher 最小特征方向），(c) **多模态歧义集 A**，(d) 有效域 ν（重叠率、动态点比例、来源）。关键原则：**沿退化方向的误差必须被显式膨胀，而不是假装它很小**；膨胀后若与 IMU/先验冲突，则降级而非放行。

**灵感 2（轨迹优化 → 从点证书到连续时间轨迹证书）**：直觉上，「当前这一步安全」推不出「接下来 500ms 这段运动安全」。轨迹优化产出的是连续曲线 ξ(t)，而证书只在离散节点采样，节点间的空隙正是危险藏身处。于是把证书提升为**时间函数**：轨迹证书要求鲁棒无碰撞（对配准不确定集 P_R 的全体成立）、动态可行（速度/加速度/加加速度）、**连续时间边际 m(t) ≥ θ**（用 Lipschitz 常数为节点间背书），以及可观测性约束（见灵感 3）。这把定义 41 的租约衰减从「时间戳」推广为「空间-时间 Lipschitz 包络」，并揭示离散化税：节点安全只是必要不充分，必须给节点 margin 加 L_m·h/2。

**灵感 3（耦合 → 配准-轨迹双向闭环与可观测性交易）**：配准依赖运动激励（静止或匀速在退化方向不可观），轨迹依赖配准做碰撞检查。于是有**可观测性-可证书性权衡**：激进机动利于时间最优，却造成运动畸变、重叠下降、退化加剧；缓慢运动利于配准，却牺牲效率。必须显式建模为**主动配准规划**：在轨迹优化里加观测性约束 O(ξ) ≥ O_min，让运动去「点亮」退化方向；但这造成鸡生蛋——轨迹证书依赖未来配准，未来配准依赖轨迹。用第 43 轮的 rely-guarantee 打破：**先声明运动类契约 M（加速度/加加速度上界），配准在该运动类下给出误差上界 ρ_max(M)，轨迹再在该误差上界内优化**，形成不动点迭代而非循环依赖。多模态歧义要求**假设鲁棒**：轨迹必须在歧义集 A 的**所有**模态下安全；若模态间冲突不可判定，则减速 + 主动消歧，绝不押注 MAP。

**耦合升级**：GRC（配准证书引擎）把点云配准编译成带退化/歧义/误差界的证书；TCO（证书化轨迹优化）在配准不确定集上做连续时间鲁棒优化；OCP（可观测性证书规划器）在退化环境主动规划激励动作，并把配准-轨迹契约做成 rely-guarantee 不动点。四层架构从 v8 的「人格 + 并发」升级到 v9 的「人格 + 并发 + 几何地基 + 连续轨迹」。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（配准证书与退化方向）**：配准 reg(S, M, T_0) 输出证书 R=(T̂, Σ, D, A, ν)：T̂∈SE(3) 为点估计；Σ 为误差协方差/界；D=span{v_k : λ_k < λ_min} 为退化子空间（配准 Hessian/Fisher 的最小特征方向）；A={(T_j, s_j)} 为多模态假设集；ν=(overlap, dynamic_ratio, source) 为有效域。**证书位姿集** P_R = { T : d_SE3(T, T̂) ≤ ρ(Σ, D) }，其中沿 D 的误差用外部先验界膨胀（沿 v_k 的不可观程度越高，ρ 越大）；无外部先验时 ρ=∞ 且 R 判 invalid。**退化判定命题**：若存在未处理退化方向且无外部源背书，则沿该方向的真实误差无上界，必须禁止签发依赖它的下游几何证书。

**定义 45（连续时间轨迹证书）**：轨迹 ξ:[t_0,t_1]→SE(3)×控制，在节点 t_k（间距 h）上采证书。**轨迹证书**要求：
(1) **鲁棒无碰撞**：∀t、∀T∈P_R，clearance(T·ξ(t), M) ≥ θ_geo；
(2) **动态可行**：|v|≤v_max，|a|≤a_max，|jerk|≤j_max；
(3) **连续时间边际**：m(t) ≥ θ，且 m 满足 Lipschitz 界，节点间用 m(t) ≥ m(t_k) − L_m(t−t_k) 保守外推；
(4) **可观测**：O(ξ) ≥ O_min（定义 47）。
**定理（离散-连续无缝）**：若每个节点满足 m(t_k) ≥ θ + L_m·h/2，则 ∀t∈[t_k,t_{k+1}] 有 m(t) ≥ θ。**推论**：节点安全只是必要不充分；不付「离散化税」的优化器会钻节点间的空子。

**定义 46（配准-轨迹 rely-guarantee 契约）**：REG 声明 G_reg：在运动类 M(a_max,j_max) 下，ρ ≤ ρ_max(M) 且退化可检出；TRAJ 声明 G_traj：轨迹属于运动类 M、在 P_R 下鲁棒无碰撞、并保持 overlap ≥ o_min。**契约条件**：(i) **非干扰**：TRAJ 的运动不越出 REG 假设的运动类（G_traj ⇒ R_reg）；(ii) **局部保持**：REG 在 M 下保持 ρ 上界（G_reg ⇒ R_traj）。则由 rely-guarantee 可靠性，**闭环任意交错安全**。**推论（打破循环）**：先固定 M，再解 ρ_max(M)（最坏运动畸变下的配准界），再在 ρ_max 内优化轨迹；若轨迹需越出 M 才可行，则收紧 M 重解——这是唯一不被「鸡生蛋」卡死的顺序。

**定义 47（可观测性与主动配准约束）**：沿轨迹累积 Fisher 信息 J(ξ)=Σ_t F(ξ(t))，观测性 O(ξ)=λ_min(J(ξ))。约束 O(ξ) ≥ O_min 迫使轨迹在不退化方向上提供激励。**命题**：若某方向 v 在当前观测下 λ_v < λ_min 且轨迹沿 v 的位移/旋转激励不足，则沿 v 的位姿误差无界；因此**可观测性是配准证书存在的前提，而非可选项**。

**定义 48（假设鲁棒轨迹证书与歧义不可判定）**：给定歧义集 A，轨迹**假设鲁棒安全**当且仅当 ∀(T_j,s_j)∈A，ξ 在 P_{R_j} 下鲁棒无碰撞且边际达阈。若 |A|>1 且不同模态给出冲突的安全判定（一个可行、一个不可行），判为 **歧义不可判定**，触发减速 + 主动消歧机动（去观测能区分模态的特征），禁止押注单一 MAP。

**定义 49（几何信任预算与漂移检测）**：几何信任 τ_geo∈[0,1]，随退化持续时间、地图陈旧度、动态点比例单调衰减，成功重定位/回环则单调回升（有界）。**退化判据**：τ_geo < τ_min ⟹ 所有几何证书失效，退回反应式安全（限速/停车/仅用局部距离场），与定义 38 的 τ_u 统一为「信任预算族」。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 GEO-REG-CERT ENGINE（配准证书引擎 GRC）
1. **退化方向检测**：对配准 Hessian/Fisher 做特征分解，λ_k<λ_min 判退化，输出 D 与不可观程度。
2. **保守误差界**：位姿集 P_R 沿 D 按外部先验膨胀；无先验则 invalid（不放行）。
3. **多模态歧义集**：多初值/多假设配准，保留分数接近的模态构成 A，供定义 48 做假设鲁棒。
4. **有效域与信任**：维护 overlap/dynamic_ratio/source，驱动 τ_geo 与回退。

### 2.2 IP-61 TRAJ-CERT-OPT（证书化轨迹优化 TCO）
1. **连续时间证书约束**：节点 margin 加 L_m·h/2 离散化税；用 Lipschitz/区间算术保证节点间。
2. **不确定集鲁棒优化**：碰撞约束对 P_R 全体成立（保守膨胀障碍）。
3. **动态可行性**：速度/加速度/加加速度硬约束，避免「证书可行但执行不了」。
4. **证书租约复用**：把 v20 的租约推广到轨迹段，滚动时域内复用未过期证书，过期即重解或降级。

### 2.3 IP-62 OBS-CERT-PLANNER（可观测性证书规划器 OCP）
1. **观测性约束规划**：在退化环境主动规划激励动作（横向/旋转），O(ξ) ≥ O_min。
2. **配准-轨迹不动点契约**：固定运动类→求 ρ_max→优化轨迹→检查越界→收紧，迭代至不动点或降级。
3. **主动消歧**：A 多模态冲突时规划区分性机动，消歧成功再恢复速度。
4. **退化回退**：τ_geo<τ_min 切反应式安全，禁止激进机动。

## 5. 本轮最大风险

**一句话**：配准误差上界 ρ 只在标称运动类 M 下标定，而轨迹优化为了时间指标会贴着 M 的上界甚至越界，一旦越界，配准证书与轨迹证书各自 sound、组合却不 sound——因此 E97（契约违约）与 E96（节点间违约）必须设为红线，并默认回退到「收缩运动类 + 慢速 + 反应式安全」这条组合可证的底线。

## 2. 关键算法（伪代码）

### IP-60 GRC：退化检测、证书位姿集与歧义集
```
def register_with_cert(scan, map, T0, prior):
    T_hat, H = icp_or_ndt(scan, map, T0)          # H = 配准 Hessian/Fisher
    lam, V = eigh(H)
    D = [V[:,k] for k in range(6) if lam[k] < LAMBDA_MIN]   # 退化方向
    # 沿退化方向膨胀误差：有先验用先验界，无先验则无界 => invalid
    rho = base_radius(H)
    for v in D:
        if prior.has_direction(v):
            rho += prior.error_along(v)            # 外部源(IMU/轮速/回环)背书
        else:
            return RegCert(T_hat, D=D, valid=False) # 禁止签发下游几何证书
    A = multi_hypothesis_modes(scan, map, T0)      # 分数接近的模态
    nu = (overlap(scan, map), dynamic_ratio(scan), source_of(T0))
    return RegCert(T_hat, rho=rho, D=D, A=A, nu=nu, valid=True)

def pose_set(cert):
    return SE3Ball(center=cert.T_hat, radius=cert.rho)   # 保守位姿集 P_R
```

### IP-61 TCO：连续时间鲁棒轨迹证书
```
def certify_trajectory(xi, P_R, map, dyn, theta, h, L_m):
    for (t_k, x_k) in xi.nodes(spacing=h):
        # 鲁棒无碰撞：对 P_R 全体，保守膨胀障碍
        if not all(clearance(T @ x_k, map) >= theta for T in P_R):
            return Cert(violation=('collision', t_k))
        # 动态可行
        if not (abs(xi.v(t_k))<=dyn.v_max and abs(xi.a(t_k))<=dyn.a_max
                and abs(xi.jerk(t_k))<=dyn.j_max):
            return Cert(violation=('dyn', t_k))
    # 连续时间：节点 margin 加离散化税
    for (t_k, x_k) in xi.nodes(spacing=h):
        m_k = robust_margin(x_k, P_R, map)          # 对 P_R 的最坏 margin
        if m_k - L_m * h / 2 < theta:               # 定义 45 定理
            return Cert(violation=('between_node', t_k))
    return Cert(ok=True, lease=TrajLease(t0=xi.t0, t1=xi.t1, L_m=L_m))

def traj_lease_valid(lease, t):
    return lease.t0 <= t <= lease.t1 and (lease.m0 - lease.L_m*(t-lease.t0)) >= theta
```

### IP-62 OCP：观测性、不动点契约与消歧
```
def observability(xi):
    J = sum(fisher_info(xi(t)) for t in xi.samples())   # 累积 Fisher
    return min_eig(J)                                   # O(xi)

def fixed_point_contract(goal, C_global, M_init):
    M = M_init
    for it in range(MAX_IT):
        rho_max = reg_error_bound(M)                    # REG 在运动类 M 下的界
        P_R = SE3Ball(radius=rho_max)
        xi = optimize_traj(goal, C_global, P_R,
                           obs_constraint=O_MIN)        # TCO + OCP
        if motion_class_of(xi) <= M and observability(xi) >= O_MIN:
            return xi, reg_cert_for(xi)                 # 不动点达成
        M = tighten(M, xi)                              # 越界 => 收紧运动类
    return fallback_serial_reg_traj(goal)               # 不收敛 => 串行兜底

def disambiguate_or_slow(A, xi):
    safe = [robust_safe(xi, P_R_of(Tj)) for (Tj,sj) in A]
    if all(safe):
        return xi, 'safe'                               # 所有模态都安全
    if not any(safe):
        return slow_stop(xi), 'stop'                    # 全不安全
    return active_disambiguation(xi, A), 'disambiguate' # 冲突 => 去观测区分
```

def car_transition_guard_v2(e, x, cert_obj, persona, lease, regcert, trajcert, t):
    theta   = cert_obj.alpha_e[e] * cert_obj.theta_sim[e]
    m_lookup= cert_lookup_L0(x).m_lo[e]
    m_lease = lease.m - lease.lam * (t - lease.tau)
    m_cap   = persona_cap[e](persona)
    m_reg   = -regcert.rho                          # 配准不确定性扣减
    m_disc  = -trajcert.L_m * trajcert.h / 2        # 节点间离散化税
    if not regcert.valid or tau_geo_below_min():
        return reactive_only_guard(e, x, theta)      # 退化 => 反应式安全
    return min(m_lookup, m_lease, m_cap, m_reg, m_disc) >= theta \
           and lease_valid(lease, theta, t) and traj_lease_valid(trajcert, t)

def certify_light_v4(x, guards, persona, regcert, trajcert, budget_us, crit):
    if not regcert.valid or crit < K_GEOMETRY:
        return reactive_only(x, guards, budget_us)   # 几何地基不可证 => 降级
    b = cert_lookup_L0(x)                            # 仅在 P_R 内有效
    lease = acquire_lease('lcs', x, theta, crit)
    if traj_lease_valid(trajcert, monotonic_now()):
        return b, lease, -1                          # 复用未过期轨迹证书
    status, margin = monitor_step_INT8(quantize_obs(x))

## 6. 本轮最大风险

**一句话**：配准误差上界 ρ 只在标称运动类 M 下标定，而轨迹优化为了时间指标会贴着 M 的上界甚至越界，一旦越界，配准证书与轨迹证书各自 sound、组合却不 sound——因此 E97（契约违约）与 E96（节点间违约）必须设为红线实验，并默认回退到「收缩运动类 + 慢速 + 反应式安全」这条组合可证的底线。
