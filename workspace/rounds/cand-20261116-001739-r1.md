# 第 1 轮（新灵感循环第 1 轮；本轮灵感：「成功率」×「决策规划」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**成功率标定 + 决策论规划**。两个灵感治理 v9 的两笔债：**置信债**（固定 β 的最坏界既可能在标称域过度保守、又可能在域偏移时悄悄失效——"证书的置信度从未被标定"）与**目标债**（v9 只在可行集内按启发式打分，没有把"任务成功率"当成可优化目标与可分配资源）。硬约束：**安全单调**——新模块只能收紧/不扩张 v9 的可行动作集，任一失效注入中立元、严格退回 v9。

## 0. 直觉与动机

**灵感 1（成功率 → 可校准的成功证书与预算）**
直觉：v9 写着"信任域内前向模型误差 ≤ β"，但 β 是手调常数。它既可能是过度保守的（明明安全的块被拒，成功率被无谓牺牲），也可能是乐观的（域偏移一来就失效）。真正该问的不是"误差上界是多少"，而是"这个块成功的概率是多少，这个概率可信吗"。核心创新：**共形成功证书（Conformal Success Certificate, CSC）**——用分裂共形预测把前向模型残差变成无分布假设的有限样本分位数 q̂(α)，给出 P(块安全/成功) ≥ 1−α 的**校准**保证；再用自适应共形推断（ACI）在线更新 α_t，在非交换、域偏移下仍有长期覆盖率保证。**证书从此不依赖 DA 的 20 帧滑窗是否及时**。进一步把"成功率"升级为一等资源：全局成功预算 α_SR 像算力一样按计划分配。

**灵感 2（决策规划 → 成功率驱动的信念规划）**
直觉：v9 的块生成是"采样—过滤—打分"的贪心，没有显式未来、没有信息价值、也不为后续决策留预算。决策论规划的视角是：决策 = 在信念空间里最大化期望成功、受机会约束；当成功概率的下置信界太低时，**花一步去观测**（减速、换视角、驻留）可能比冒险执行更优。核心创新：**成功预算规划器（Success-Budget Planner, SBP）**——在 v9 可行集内做滚动时域规划，用校准后的成功概率 LCB 做 exploit/inform/shrink/stop 四选一，并用一步前瞻的**信息价值（VOI）**决定是否插入观测动作；每块消耗预算，剩余预算结转或按条件重标定。

**灵感 3（两者合成 → 成功率治理闭环）**
直觉：标定给"可信的概率"，规划给"怎么用这个概率"，还需要第三个东西防止"预测很自信、现实很拉胯"。核心创新：**成功率治理器（Success-Rate Governor, SRG）**——滑窗比较预测成功率与经验成功率，用 Hoeffding/Beta 单侧界做"乐观检测"；一旦预测显著乐观，收紧 α_t、冻结长块，持续则退回 v9 确定性证书。

## 1. 研究问题（轮次升级版）

- **Q1（校准保证）**：在可交换/非可交换假设下，共形成功证书能给出怎样的有限样本/长期覆盖保证？ACI 能否在 DA 滞后时仍控制块级违例，而不把风险推给"平均覆盖"？
- **Q2（预算与规划）**：如何把端到端成功率预算 α_SR 可证明地分解到滚动时域各块？VOI 观测动作的收益如何与减速/驻留的时间成本比较？
- **Q3（安全单调）**：如何保证 SBP 只收缩不扩张 v9 可行集、SRG 的收紧不引入抖振，并让任一模块失效时逐位退回 v9？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 校准成功证书律（Conformal Success Certificate, CSC）**
块证书的误差余量由数据决定而非手调：q̂_t(α) 为分裂共形分位数，证书为 ĝ_min^conf = min_k ĝ_k − q̂_t(α)。标称域用 α_target；域偏移由 ACI 按 err_t 在线调整 α_t，并以"残差惊喜"触发即时收紧。**证书的可信度被显式标定，而非假设。**

**P14 成功预算规划律（Success-Budget Decision Planning, SBP）**
把成功率当资源：端到端失败预算 P(fail) ≤ α_SR，按计划分解为 Σ_h α_h ≤ α_SR。滚动时域在 v9 可行集 Π_v9 内最大化期望成功，受机会约束与预算约束；决策四选一 exploit/inform/shrink/stop，由成功概率的 LCB 与 VOI 驱动。观测动作只允许减速/驻留/换视角等**安全动作**。

**P15 治理与安全单调律（Success-Rate Governor & No-Weakening, SRG）**
新模块只能收紧：严格模式取 q̂_eff = max(q̂, β_v9)，SBP 仅在 Π_v9 内选优，SRG 只能降低 α_t 或退回 v9。故 v10 可行动作集 A_v10 ⊆ A_v9，v9 引理 82–86 的安全论证原样继承；任一模块失效 ⇒ 注入中立元、严格等价 v9。

## 3. 与基线的接口（如何退化）

- CSC 失效（校准集缺失/残差溢出/共形失效）⇒ q̂ ← β_v9、α_t ≡ 0（确定性最坏界），等价 v9；
- SBP 失效（规划超时/信念退化）⇒ 选择退回 v9 的 score 贪心、关闭观测动作、K_eff 由 v9 门控，等价 v9；
- SRG 失效 ⇒ 不触发收紧，α 固定在 v9 标定值，等价 v9；
- v9 的 AC/MW/ID 或 v8 的 DA/SPR/Cal 失效 ⇒ 沿用 v9 五级退化；
- 全部失效 ⇒ v9 → v8 → v7 → v6。

## 4. 预期贡献

1. **共形/ACI 成功证书**：把块证书从手调 β 升级为可校准、抗域偏移、有有限样本与长期覆盖保证的概率证书，直接回应 v9"DA 滞后即证书失效"的软肋；
2. **成功率预算规划**：把成功率当资源，信念空间滚动规划 + VOI 观测动作，得到"同等安全下更高成功率"的策略；
3. **成功率治理闭环**：乐观检测、条件覆盖审计与安全单调退化；
4. **E571–E590**：覆盖校准覆盖率、ACI 抗漂移、DA 滞后压力、预算分配紧致度、VOI 增益、LCB 门控、乐观检测、稀有状态覆盖与端到端任务。

## 5. 本轮最大风险

**一句话**：共形/ACI 保证的是**边际或长期平均**覆盖率，而非**逐状态条件覆盖**——在校准集稀疏的安全关键状态，或时间相关的对抗性域偏移下，违例会集中爆发，"平均 99% 覆盖"可能掩盖"最需要安全的那几步没有覆盖"，成功预算被错误地花在名义段、关键段只剩很薄的证书。

## 1. 符号体系增量（定义 540–548）

| 符号 | 含义 |
|---|---|
| α_target | 目标块级误覆盖率（标称域，默认 0.01） |
| α_t | ACI 在块 t 的在线误覆盖率；越小越保守 |
| γ | ACI 步长（默认 0.005） |
| E_i = ĝ_i − g_i | 间隙的乐观残差（非一致性分数，正值表示预测偏乐观） |
| q̂_t(α) | 分裂共形分位数（有限样本、无分布假设） |
| D_cal | 校准集 {(x_i, a_i^{1:K}, y_i)}，独立于部署、标称同分布 |
| Succ_t ∈ {0,1} | 块 t 的成功指示（达成子目标 ∧ 无安全违例 ∧ 未不可恢复中止） |
| SR, α_SR | 任务成功率与端到端失败预算（P(fail) ≤ α_SR） |
| p_t, LCB_t^{1−δ} | 校准后的成功率预测与下置信界（置信度 1−δ） |
| b_t | 对潜在域参数/模型误差尺度的信念 |
| α_h, w_h | 第 h 块的失败预算与关键度权重（Σα_h ≤ α_SR） |
| VOI_t(a_obs) | 观测动作的信息价值（一步前瞻） |
| A_info | 信息动作集：减速驻留、换视角、重新观测、请求确认 |
| Π_v9 | v9 确定性证书下的可行计划集 |
| Δ_SR, τ_SR | 预测-经验成功率偏差与其告警阈 |
| q̂_eff | 严格模式有效余量 max(q̂_t(α_t), β_v9) |
| ε_v9, ε_v10 | v9 / v10 的实测安全违背率 |

**新增定义 540（块成功事件与成功率）** 对块 t，
```
Succ_t = 1[子目标达成 ∧ 全程 M₀ 未违背 ∧ min_k clearance_k ≥ d_safe ∧ 未不可恢复中止]
```
任务成功率 `SR = P(∧_{h=1}^{H} Succ_h)`，端到端失败预算 `α_SR := 1 − SR_target`。注意成功率与安全不是同一量：安全是硬约束（M₀），成功率还包含"及时完成任务"。

**新增定义 541（分裂共形成功证书 Split-Conformal Certificate）** 校准集 D_cal 独立于部署。对间隙用乐观残差 `E_i = ĝ_i − g_i`（预测间隙减真实间隙，正值表示乐观）。取
```
q̂^clear(α) = Quantile_{⌈(n+1)(1−α)⌉/n}({E_i^clear}_{i=1..n})
ĝ_min^conf = min_k ĝ_k − q̂^clear(α)
```
对努力上界用 `E_i^eff = e_i − ê_i`，证书上界 `ê_max^conf = max_k ê_k + q̂^eff(α)`。在可交换性下 `P(g ≥ ĝ_min^conf) ≥ 1−α` 且 `P(e ≤ ê_max^conf) ≥ 1−α`（引理 87）；两界做 Bonferroni 合并到 `1−2α`。q̂ 随 n 增大而收紧。

**新增定义 542（自适应共形推断 ACI）** 每块记录 `err_t = 1[g_t < ĝ_min,t^conf]`（真实间隙跌破证书下界）。在线更新
```
α_{t+1} = Π_{[α_min, α_max]}( α_t + γ(α_target − err_t) )
```
`err_t=1`（证书被击穿）⇒ α_t 下调（更保守、分位数更大）；连续安全 ⇒ α_t 缓慢回升至 α_target。失误后立即置"惊喜"标志，强制下一块 K_eff←1 并重算 q̂。ACI 不要求可交换性，长期平均覆盖满足 `|(1/T)Σ err_t − α_target| = O(1/(γT))`（引理 88）。

**新增定义 543（成功率预算与分解 Success Budget）** 端到端失败预算 α_SR。把剩余计划视作块序列，分配
```
α_h = α_SR · w_h / Σ_{h'∈remaining} w_{h'}
```
`w_h` 为关键度权重（如 1/最小间隙余量、或子目标重要性）。联合界给出 `P(∨_h fail_h) ≤ Σ_h α_h ≤ α_SR`（引理 89，无需独立性）。保守实现不结转已成功块的预算；若结转，须以"成功"为条件重标定（条件共形/条件 ACI），否则条件概率会失真。

**新增定义 544（成功信念与校准成功率）** 信念 b_t 是对潜在域参数 θ（或模型误差尺度）的后验，由残差 E_{1..t} 贝叶斯更新（粒子/共轭）。校准成功率
```
p_t(ζ) = P(Succ_t | b_t, ζ) = E_{b_t}[ 1{证书有效 ∧ 子目标可达} ]
```
用 Beta 后验或 Hoeffding 得 `LCB_t^{1−δ} = p̂_t − √(log(1/δ)/(2m))`（m 为有效样本数）。p_t 是"标定后"的概率：其名义值经 SRG 与共形校准，不直接采用前向模型的原始置信度。

**新增定义 545（成功预算规划器 SBP）** 在重规划边界解滚动时域问题：
```
π* = argmax_{π∈Π_v9} E_{b_t}[ Σ_{h=0}^{H−1} ρ^h · Succ_{t+h} ]
s.t.  Σ_h α_h ≤ α_SR,  ∀h: ζ_h 通过严格证书（q̂_eff）,  a_obs ∈ A_info
```
ρ∈(0,1] 为折扣。决策四选一：`exploit`（LCB_t ≥ p_exec）、`inform`（VOI − c_obs ≥ 执行增益）、`shrink`（K_eff>1 时缩短块）、`stop`（K_eff=1 时安全停驻，等价 v9 abort）。Π_v9 为 v9 确定性证书下的可行集，故 SBP 只在其中选优。

**新增定义 546（信息价值 VOI）** `U(b) = max_{ζ∈Π_v9} E_b[Succ | ζ]`。观测动作 a_obs 的一步信息价值
```
VOI_t(a_obs) = E_{o∼P(·|b_t,a_obs)}[ U(b_{t+1}(o)) ] − U(b_t) − c_obs
```
c_obs 为观测的时间/能耗成本。只有当 VOI_t(a_obs) 大于"以 LCB 冒险执行"的期望增益时才 inform。A_info 只含减速、驻留、换视角、重新观测、请求确认等安全动作。

**新增定义 547（成功率治理器 SRG）** 滑窗 W 内预测成功率 SR_pred 与经验成功率 SR_emp。单侧乐观检测：若 `SR_pred − LCB_{1−δ}(SR_emp) > τ_SR`，判"预测乐观"；触发后 `α_t ← α_t·(1−η)`（收紧）、冻结 K_eff>K_freeze 的块、插入 K=1 复核；若连续 W_s 个窗口仍乐观 ⇒ 退回 v9 确定性证书（CSC 中立元）。检测阈由 Hoeffding/Beta 界给出，保证低误报（引理 91）。

**新增定义 548（v10 中立元表 NeutralElementTable）**

| 模块 | 中立元 | 等价 |
|---|---|---|
| CSC | q̂←β_v9, α_t≡0 | v9 确定性块证书 |
| SBP | v9 policy.score 贪心, A_info=∅, K_eff←v9 门控 | v9 块生成 |
| SRG | 关闭乐观检测, α_t≡α_target | v9 标定值 |
| AC / MW / ID / DA / SPR / Cal | 沿用 v9 表 536 | v9 / v8 / v7 |

## 2. 形式化定义（继承与升级）

**定义 493–539** 全部继承 v9（六层指标层级、MetaWeight/情感、DA-OTL、软证书、AC 分块、MW 契约、ID 状态机）。v10 只改两处：
- **升级定义 533（块证书，v10）**：`β` → `q̂_t(α_t)`；严格模式 `q̂_eff = max(q̂_t, β_v9)`。证书有效 ⇔ `ĝ_min^conf ≥ d_safe ∧ ê_max^conf ≤ τ_eff ∧ γ̂_grasp valid ∧ 中止点集 P_t ≠ ∅`。
- **升级定义 539（有效块长门控，v10）**：在 v9 的 Δ_dom/risk_SLAM 门控之外再与"成功 LCB 门控"取交（只收缩）：
```
K_eff = min( K_eff^{v9}(Δ_dom, risk_SLAM),
             K_max·1[LCB_t^{1−δ} ≥ p_exec] + 1·1[LCB_t < p_exec] )
```
即成功概率下界不足时退到 K=1，与 v9 门控叠加后只会更短。

## 3. 关键算法骨架

```python
# IP-357 ConformalSuccessCertifier：共形成功证书器
class ConformalSuccessCertifier:
    def __init__(self, F, calib_scores, beta_v9=0.02,
                 alpha_target=0.01, gamma=0.005,
                 alpha_min=1e-4, alpha_max=0.1):
        self.F = F
        self.scores = sorted(calib_scores)   # 预排序的乐观残差 E_i
        self.beta_v9 = beta_v9
        self.alpha = self.alpha_target = alpha_target
        self.gamma = gamma
        self.alpha_min, self.alpha_max = alpha_min, alpha_max
        self.surprise = False
        self.last = None

    def quantile(self, alpha):
        n = len(self.scores)
        k = math.ceil((n + 1) * (1 - alpha))
        return self.scores[min(k, n) - 1]

    def certify(self, state, chunk, strict=True):
        pred = self.F.rollout(state, chunk.actions)
        q = self.quantile(self.alpha)
        q_eff = max(q, self.beta_v9) if strict else q   # 安全单调：只可能更保守
        g_lo = pred.min_clearance - q_eff
        e_hi = pred.max_effort + q_eff
        valid = (g_lo >= state.d_safe and e_hi <= state.tau_eff
                 and chunk.has_abort_point())
        self.last = Cert(g_lo, e_hi, q_eff, valid)
        return self.last

    def update(self, realized):
        err = int(realized.min_clearance < self.last.g_lo)
        self.alpha = np.clip(
            self.alpha + self.gamma * (self.alpha_target - err),
            self.alpha_min, self.alpha_max)
        self.surprise = bool(err)              # 立即触发下一块 K=1 + 重算
        return err
```

```python
# IP-358 SuccessBudgetPlanner：成功预算规划器
class SuccessBudgetPlanner:
    def __init__(self, policy, csc, alpha_sr=0.05, delta=0.05,
                 p_exec=0.95, rho=0.9):
        self.policy, self.csc = policy, csc
        self.alpha_sr, self.delta, self.p_exec = alpha_sr, delta, p_exec
        self.rho = rho
        self.remaining_budget = alpha_sr
        self.freeze_long = False

    def allocate(self, remaining_h, w):
        tot = sum(w[h] for h in remaining_h)
        return {h: self.remaining_budget * w[h] / tot for h in remaining_h}

    def success_lcb(self, belief, chunk):
        m = belief.effective_samples(chunk)
        p_hat = belief.mean_success(chunk)
        return p_hat - math.sqrt(math.log(1 / self.delta) / (2 * max(m, 1)))

    def plan(self, belief, state, K_max, trust_ok):
        if not trust_ok:
            return self.policy.single_step_fallback(state)   # v9 语义
        cands = self.policy.sample_sequences(state, K_max, n=64)
        feasible = [z for z in cands
                    if self.csc.certify(state, z, strict=True).valid]
        if not feasible:
            return self.policy.single_step_fallback(state)
        return max(feasible, key=lambda z: self.expected_success(belief, z))

    def voi(self, belief, a_obs):
        u0 = self.best_value(belief)                 # U(b_t)
        u1 = belief.expected_value_after(a_obs)      # E_o[U(b_{t+1})]
        return u1 - u0 - a_obs.cost

    def decide(self, belief, chunk, voi_obs):
        lcb = self.success_lcb(belief, chunk)
        if lcb >= self.p_exec:
            return ('exploit', chunk)
        gain_exec = lcb - self.p_exec                # 冒险执行的期望增益（可负）
        if voi_obs >= gain_exec:
            return ('inform', self.observation_action(belief))
        if chunk.K_eff > 1 and not self.freeze_long:
            return ('shrink', chunk.with_K(1))
        return ('stop', None)                        # 等价 v9 abort

    def freeze_long_chunks(self):
        self.freeze_long = True                      # SRG 收紧指令
```

```python
# IP-359 SuccessRateGovernor：成功率治理器
class SuccessRateGovernor:
    def __init__(self, csc, planner, tau_sr=0.05, W=200, W_s=3, delta=0.05):
        self.csc, self.planner = csc, planner
        self.tau_sr, self.W, self.W_s, self.delta = tau_sr, W, W_s, delta
        self.pred, self.emp = deque(maxlen=W), deque(maxlen=W)
        self.optimistic_windows = 0

    def observe(self, p_pred, succ):
        self.pred.append(p_pred)
        self.emp.append(succ)
        if len(self.emp) < self.W:
            return None
        sr_pred = float(np.mean(self.pred))
        sr_emp = float(np.mean(self.emp))
        lcb = sr_emp - math.sqrt(math.log(1 / self.delta) / (2 * self.W))
        if sr_pred - lcb > self.tau_sr:              # 预测显著乐观
            self.optimistic_windows += 1
            self.csc.alpha = max(self.csc.alpha_min, 0.5 * self.csc.alpha)
            self.planner.freeze_long_chunks()
            if self.optimistic_windows >= self.W_s:
                return 'fallback_v9'                 # CSC 中立元
        else:
            self.optimistic_windows = 0
        return None
```

## 4. 推导

**引理 87（分裂共形覆盖）** 若校准样本与测试样本可交换，且非一致性分数 E_i 独立同分布，则对 α∈(0,1)、n 个校准样本，取 q̂ = 第 ⌈(n+1)(1−α)⌉ 个次序统计量，有 `P(E_{n+1} ≤ q̂) ≥ 1−α`。故 `P(g_{n+1} ≥ ĝ_{n+1} − q̂) ≥ 1−α`。间隙与努力两界对 α/2 分别施加，Bonferroni 合并得联合覆盖 ≥ 1−α。证明：可交换性 ⇒ E_{n+1} 在 {E_1..E_{n+1}} 中的秩均匀，比 q̂ 大的概率受 ⌈(n+1)(1−α)⌉ 的秩计数控制。∎

**引理 88（ACI 非交换长期覆盖）** 对任意（可对抗、时间相关）误差序列 err_t ∈ {0,1}，更新 `α_{t+1} = Π(α_t + γ(α_target − err_t))` 且 α_t 有界，则长期平均误覆盖满足 `|(1/T)Σ_{t=1}^T err_t − α_target| = O(1/(γT))`，与数据分布无关（Gibbs & Candès 2021 型结论）。**推论（对 v9 风险）**：即使 DA 的 Δ_dom 滑窗滞后、K_eff 在失效证书上仍取大值，ACI 的残差惊喜会在击穿发生的下一块把 α_t 压到 α_min 并强制 K_eff=1，故违例暴露被限制在**单块**而非整个滞后窗口；长期看违例率仍被 α_target 约束。∎

**引理 89（成功预算可靠性）** 若每块失败概率 P(fail_h) ≤ α_h 且 Σ_h α_h ≤ α_SR，则端到端 `P(∨_h fail_h) ≤ Σ_h P(fail_h) ≤ α_SR`（联合界，无需独立）。滚动时域下，将剩余预算按定义 543 重新分配、已成功块的预算不结转，则每一步剩余计划的失败界仍 ≤ 剩余 α；归纳得整条计划成功 ≥ 1−α_SR。若采用 e-value/鞅组合可得到更紧的界（E574）。∎

**引理 90（安全单调与 v9 继承）** 严格模式取 q̂_eff = max(q̂_t(α_t), β_v9) ≥ β_v9，故证书只可能比 v9 更保守；SBP 的可行集 `Π_v10 = {ζ ∈ Π_v9 : cert_v10(ζ)} ⊆ Π_v9`；`A_info` 中的观测动作是减速/驻留/换视角/重新观测/请求确认，均为 v9 安全停驻集的子集，不引入新运动授权；SRG 只能降低 α_t 或回退到 v9。因此 `A_v10 ⊆ A_v9`，v9 引理 82–86（块证书可靠性、中立元等价、蒸馏安全、双阈防抖、EDF 守恒）原样成立。CSC/SBP/SRG 失效时按表 548 注入中立元，逐位复现 v9 对应分支。∎

**引理 91（治理器低误报与无抖振）** 在"已校准"的零假设 SR_pred = SR_true 下，Hoeffding 单侧界给出每个窗口的误报概率 ≤ δ；连续 W_s 个窗口才触发回退，使误报率 ≤ δ^{W_s}（窗口近似独立时）或 ≤ δ·W_s（保守并集）。触发后 α_t 单调下调、冻结长块，且最小驻留 W_d 个窗口才允许再评估，故相邻触发间隔 ≥ W_d·W 控制周期，翻转率 ≤ 1/(W_d·W·Δt)，无 Zeno 抖振（与 v9 引理 85 同构）。∎

**命题 1（弱占优，经验命题）** 若校准成功率 p_t 与真实成功率一致、且 v9 的 `policy.score` 是真实成功的含噪代理，则 SBP 在 `Π_v9` 上最大化 p_t 的期望成功不劣于 v9 的 score 贪心。该命题依赖"代理含噪"假设，不作定理使用，交由 E575 检验。

## 8. 本轮最大风险

**一句话**：共形/ACI 保证的是**边际或长期平均**覆盖率，而非**逐状态条件覆盖**——在校准集稀疏的安全关键状态，或时间相关的对抗性域偏移下，违例会集中爆发，"平均 99% 覆盖"可能掩盖"最需要安全的那几步没有覆盖"，成功预算被错误地花在名义段、关键段只剩很薄的证书。
