# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「动态避障」×「人形机器人」）

> R69 给了不确定性一张嘴：看不清就看、拿不准就问、质感不明就触。但它默认世界是**静止的**——你可以先停下来把问题问清楚，再决定怎么走。动态避障把这个前提抽掉了：**世界在你提问的时候继续移动**，一次「问」可能要 300ms，而 300ms 之后你和来者已经越过彼此的不可逆点。于是 R69 的核心判据 `VoI(g) − c(g) > 0` 在动态场景里是不完整的：它没有把**时间**计入成本，也没有问「这个歧义能不能在碰撞之前被消解」。
>
> 人形机器人补上第二个缺口：R69 的安全认证把机器人当成一个可收缩的标量动作，但人形是**高维、浮基、接触丰富、受平衡约束**的。避障不是「横向平移一个点」，而是在 ZMP/质心动力学/摩擦锥约束下的**全身可达集**里选一条轨迹；它的身体还提供一组**动态可负担性**（侧步、下蹲、撑地、抬臂遮挡），既扩大安全集，也引入新的**自模型不确定性**（载荷、地面摩擦、执行器退化、疲劳）。
>
> 核心命题：**给 epistemic 不确定性装一个时钟。** 把 R69 的 `U_epi` 进一步拆成「时限内可消解」与「时限内不可消解」；只有前者值得一次交互，后者直接并入 aleatoric 走保守。时限不是超参数，而由**全身鲁棒可达避让集**反推得到 `τ_epi`；在它之前必须决定「继续观察/询问」还是「现在就承诺一条避让轨迹」——这是带期权价值的**最优停止**问题。同时把「动作即信息」双向化：R69 只会向世界提问，而动态场景里机器人**自己的可读运动**（减速、让行、转身、注视）也在回答别人对它的不确定，从而降低它自己对别人的预测不确定。
>
> 命名 **KAIROS-RAS**（Kairos-aware Anticipatory Interactive Reachability & Opportunity-Sensitive safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我还来得及问吗——而且我的身体还答得出来吗**」。

## 0. 直觉与动机

**灵感 1（动态避障 → 交互有截止时间）**
直觉：静态场景里「先看清再走」几乎总是安全的；动态场景里，「看清」本身会消耗掉你唯一能用来避让的时间。一个在 t 时刻发起、在 t+Δ 才返回的查询，只有落在 `τ_epi`（最后一个仍存在可行避让动作的时刻）之前才有价值；越过它，信息再准也只能用于「撞击后的解释」。所以 R69 的 VoI 要除以时间、并以截止时间做硬约束：**不是所有可解的歧义都值得解，只有「来得及解」的歧义才值得解。**

**灵感 2（人形机器人 → 安全不是走廊，是可达集；身体既是约束也是选项）**
直觉：轮式底盘可近似成一个带膨胀半径的圆盘，人形不行。它的安全取决于重心、支撑多边形、接触点、关节力矩与地面摩擦；同一条「向左 30cm」对双足可能是侧步、可能是受控倾倒、也可能直接摔倒。更重要的是，人形有一组丰富的**动态可负担动作**：下蹲降低高度、撑墙借力、抬臂护住关键部位、跨步让出通道。避障因此变成「在全身可达集里找一条与移动障碍可达集不相交的轨迹」，而不是「在二维平面找一条绕开圆的路」。

**灵感 3（自模型不确定 → 对偶不确定性）**
直觉：R69 把不确定性都放在外部世界（模态、感知、他人）。人形多了一类最容易被忽视的不确定性——**关于自己身体的不确定性**：这一步摩擦够不够？负载让质心偏了多少？执行器退化了多少？跌倒边界还是不是训练时以为的那条？这类不确定性直接决定 `τ_epi` 与可达集大小。若只用外部世界的不确定性算时限，会系统性地**高估自己还能等多久**——这是人形最危险的失效模式。

**灵感 4（动作即信息 → 可读性是一种双向 VoI）**
直觉：R69 的交互是单向的（机器人→世界）。但在人与移动机器人的共享空间里，**你的运动本身就在被别人读取**：减速表示让行、身体朝向表示下一步方向、注视表示「我看到你了」。可读运动让别人预测更准，别人预测更准又让你自己的预测更准——这是闭环的社会信息增益。反过来，一个动作也可以**故意不可读**（突然变向）或**伪装可读**（假让行），这把人形避障从单机规划变成了带信号博弈的协商。

**灵感 5（承诺 vs 期权 → 最优停止）**
直觉：继续观察/询问保留了「以后再选」的期权，但时间在流失、障碍在靠近；尽早承诺一条避让轨迹降低了暴露时间，却放弃了更好的选择。二者之间的最优切换点就是**承诺时刻** `t_c`，满足「再等一单位的期权价值 < 再等一单位的碰撞风险增量」。这解释了为什么人类过马路不是「看清到 100% 才走」，而是「在还可控的最后一刻果断迈步」——KAIROS 要把这个直觉形式化，而不是用一个固定阈值。

## 1. 形式化定义（增量：定义 310–322）

**定义 310（KAIROS-RAS 总览）** KAIROS-RAS = (TED, DPF, WBR, LIS, STV, TCG, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **时限硬约束**：任何信息/观察动作 g 的完成时刻必须 ≤ `τ_epi − ε_margin`，否则 g 作废；
(iii) **全身安全包络**：执行轨迹必须落在经认证的全身可达避让集 `𝒮_wb(t)` 内，且满足 ZMP/接触/摩擦约束；
(iv) **承诺迟滞**：承诺时刻 `t_c` 一经选定，在最小驻留时间内不得反复（无抖动），除非触发紧急重规划 `ℰ_emg`。

**定义 311（动态联合场景）** 机器人全身状态 `q_t = (q_base, q_joint, q̇, contact)`；第 j 个移动智能体状态 `s_j(t)`，其（未知）策略 `π_j`。联合状态 `x_t = (q_t, {s_j(t)})`。区别于 R69：环境非平稳，且**机器人动作进入他人策略**：`s_j(t+1) ~ P_j(· | x_t, a_t)`（闭环预测，见定义 315）。

**定义 312（全身动态可负担性）** 候选全身动作族 `𝒜_wb(q) = {step, side_step, crouch, brace, arm_shield, stop}`，每个 u 由低层全身控制器实例化为轨迹 `ξ_u`。可行性判据：`ZMP(ξ_u) ∈ supp_polygon`、接触力 ∈ 摩擦锥、关节力矩 ≤ τ_max、质心高度 ≥ h_min。可负担集 `A_aff(q) ⊂ 𝒜_wb`。

**定义 313（epistemic 截止时间 τ_epi）** 令 `𝒪(t) = ∪_j O_j(t)` 为移动障碍的预测可达集（定义 315），`R_wb(q; t, H)` 为从 q 出发、时域 H 内的全身可达集。定义
`τ_epi(t) = sup{ t' ≥ t : ∃ u ∈ A_aff, R_wb(q_t; t', H) ∩ 𝒪([t', t'+H]) = ∅ }`。
直觉：τ_epi 是「最后一个还能启动一条无碰撞全身动作的时刻」；越过它，任何查询都太晚。**τ_epi 依赖自模型不确定（定义 316），故是一个区间 `[τ_epi^-, τ_epi^+]` 而非点估计，保守控制用 τ_epi^-。**

**定义 314（时间化不确定性分解 TED）** 继承 R69 的 `U_ale, U_epi`，再按可解时限剖分：
`U_epi = U_epi^res(τ_epi) + U_epi^unres(τ_epi)`，
其中 `U_epi^res = U_epi · P(g* 在 τ_epi 前完成并消解)`，`U_epi^unres` 为时限内无法消解的部分。**关键语义**：`U_epi^res` 才走 R69 的交互通道，`U_epi^unres` 直接并入 aleatoric 走保守——它不是「暂时不知道」，而是「物理上已经来不及知道」。

**定义 315（闭环动态预测 DPF + 保形可达集）** 对每个 j，预测器输出轨迹分布 `p_j(τ | x_t, a_{t:t+H})`，显式以机器人动作为条件（闭环，不假设他人策略冻结）。用保形预测构造 `O_j(t) = { y : p_j(y) ≥ q_δ }`，保证 `P(s_j(t) ∈ O_j(t)) ≥ 1 − δ` 在标定分布下成立。给出闭环漂移告警 `drift = D_KL(p_j^{closed} ‖ p_j^{open})`；高漂移时提高 δ 或退回保守。

**定义 316（自模型不确定与鲁棒可达集 WBR）** 自模型参数 `θ_self`（载荷、摩擦、执行器增益、疲劳）带后验 `p(θ_self)`。鲁棒可达集
`R_wb^rob(q; t, H) = ∩_{θ ∈ Θ_δ} R_wb(q; t, H; θ)`，`Θ_δ` 为 θ 的 1−δ 可信集；自模型不确定度 `U_self = H(p(θ_self))`。**时限必须用 R_wb^rob 反推**：`τ_epi^- = sup{ t' : ∃u, R_wb^rob ∩ 𝒪 = ∅ }`。R69 恰为 `U_self = 0` 的特例。

**定义 317（可读意图信号 LIS 与社会 VoI）** 动作 ξ 对观察者 j 的可读性 `Leg_j(ξ) = I(π_robot ; ξ)`（观察者对机器人意图后验的期望信息增益）。社会信息价值 `VoI_soc(ξ) = H(s_j(t+1) | x_t) − E_{ξ}[H(s_j(t+1) | x_t, ξ)]`：机器人通过可读运动降低**自己对他人的预测熵**（他人因理解而反应更可预测）。总信息价值 `VoI_total = VoI_query + VoI_soc`。

**定义 318（时空价值信息 ST-VoI）** 候选信息动作 g（注视/减速观察/问句/可读让行信号）：
`ST-VoI(g) = [VoI_query(g) + VoI_soc(g)] / max(time(g), ε)`，
约束 `t + time(g) ≤ τ_epi^- − ε_margin`。选 `g* = argmax [ST-VoI(g) − c(g)]`，仅当 > 0 且预算/认证通过。若没有 g 满足时限：不交互，进入承诺（TCG）。**退化**：`τ_epi → ∞` 时 ST-VoI ∝ VoI，回到 R69。

**定义 319（时限承诺控制器 TCG）** 承诺时刻 `t_c` 的最优停止：
`J(t_c) = E[collision risk(t_c)] + E[task cost(t_c)] + λ_o · OptionValue(t_c)`，
其中 `OptionValue(t_c) = E[max_u future utility | 信息到 t_c] − E[utility of commit now]`。最优 `t_c* = argmin J`，等价于「继续等待的边际风险 = 继续等待的边际期权价值」。实现为带迟滞的阈值策略：`risk_rate(t) / option_decay(t) ≥ κ` 时承诺；最小驻留 `d_min` 防抖。定义**不可逆点** `t_pnr`（此后任何动作都无法避免碰撞），TCG 保证 `t_c < t_pnr`。

**定义 320（对偶不确定性融合 DUF）** 世界不确定 `U_world = (U_ale, U_epi)`，自不确定 `U_self`。安全时限用联合保守：`τ_epi^- = τ_epi(U_self 的 1−δ 上界, U_world 的 1−δ 上界)`。两种不确定**不做加和**：`U_self` 只进入时限/可达集，`U_epi` 只进入交互决策，`U_ale` 进入 λ floor（继承 R68/R69）。

**定义 321（运动投毒与 AIC-KAIROS）** 干扰集 `ℰ_motion`：假让行（先减速后突然加速）、诱导性可读（伪装让行）、诱饵障碍、闭环预测投毒。`ℰ_KAIROS = ℰ_FLUID × ℰ_motion × ℰ_closedloop`（闭环漂移 / 保形失效 / 承诺抖振）。

**定义 322（证书与三级退化）** `J_KAIROS = (J_FLUID, conformal_coverage, τ_epi 裕度, WBR 认证, legibility 分, commit_log_hash, U_self_p95, kairos_ver)`。Valid ⇔ Valid(J_FLUID) ∧ coverage ≥ 1−δ ∧ τ_epi 裕度 > ε_margin ∧ 全身约束满足。三级退化：静态/无移动体 → R69（τ_epi=∞）；有时限但无可解交互 → 承诺 + R69 保守；τ_epi≤0 / 自模型失效 / 保形失效 → 认证反应式避让（CBF / 安全停止）。

## 2. 关键算法骨架

```python
# IP-264 TED：时间化不确定性分解（给 R69 的 U_epi 加时钟）
def temporal_decompose(samples, z, tau_epi, feasible_g):
    U_ale, U_epi, modes = r69_decompose(samples, z)          # R69 定义 296–297
    t_best = min((duration(g) for g in feasible_g), default=INF)
    p_res  = resolve_probability(modes, feasible_g) if t_best < tau_epi else 0.0
    return U_ale, U_epi * p_res, U_epi * (1.0 - p_res), modes  # res / unres

# IP-265 DPF：闭环预测 + 保形可达集 + 漂移告警
def closed_loop_reach(predictor, x_t, a_future, delta):
    pj    = [predictor.j(j, x_t, a_future) for j in agents(x_t)]   # 以机器人动作为条件
    O     = [conformal_region(p, 1 - delta) for p in pj]
    drift = mean(kl_closed_open(pj))
    return O, drift

# IP-266 WBR：自模型不确定下的鲁棒全身可达集
def robust_reachable(q_t, theta_ci, t, H):
    return intersect(whole_body_reachable(q_t, theta, t, H) for theta in theta_ci)

# IP-267 由鲁棒可达集反推截止时间（时限不是超参数）
def epistemic_deadline(q_t, O_t, theta_ci, H):
    for t in descending_candidates(H):
        if any(disjoint(robust_reachable(q_t, theta_ci, t, H), O_t)
               for u in affordable(q_t)):
            return t
    return 0.0

# IP-269 ST-VoI：带时限的信息动作选择（含可读信号）
def choose_info_or_commit(modes, q_t, tau_epi, budget):
    best = None
    for g in info_candidates(modes):                 # gaze / slow-observe / ask / legible-yield
        if not budget.allow(g): continue
        if time(g) > tau_epi - EPS_MARGIN: continue  # 来不及 → 直接淘汰（R69 无此条）
        if not c_ras_wm.certify_info(g, q_t): continue
        voi = (query_voi(modes, g) + social_voi(g)) / max(time(g), EPS)
        if best is None or voi - cost(g) > best.score:
            best = (g, voi - cost(g))
    return best if best and best.score > 0 else None

# IP-268 TCG：承诺 vs 期权（最优停止 + 迟滞）
def time_to_commit(risk_rate, option_value, t, state):
    if state.committed:
        return state.t_c if t - state.t_c < D_MIN else None       # 最小驻留防抖
    if risk_rate(t) / max(option_decay(option_value, t), EPS) >= KAPPA:
        return t                                                   # 果断承诺
    return None

# IP-274 KAIROS 主闭环（继承 R69，在不确定性处置前插入「时钟」与「身体」）
def KAIROS_round(M, obs):
    z, o = M.mtm.forward(obs)                                      # R69 一次前向
    O, drift = M.dpf.closed_loop_reach(o, M.planned_action, M.delta)
    theta_ci = M.wbr.self_model_ci(M.U_self, M.delta)
    tau_epi  = M.wbr.epistemic_deadline(o.q, O, theta_ci, M.H)     # 第一条时钟
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_res, U_unres, modes = M.ted.temporal_decompose(
        samples, z, tau_epi, M.info_candidates)
    g = (M.stv.choose_info_or_commit(modes, o.q, tau_epi, M.budget)
         if (U_res > TAU_EPI and drift < TAU_DRIFT) else None)
    if g is not None:
        ans = M.cia.execute(g)                    # 看/问/触/可读让行；带认证 + 证据纪律
        U_res = M.cia.update_belief(modes, ans)
    t_c = M.tcg.time_to_commit(M.risk_rate, M.option_value, obs.t, M.tcg_state)
    u = M.tcg.commit_action(modes, t_c, O) if t_c is not None else M.tcg.hold(modes, O)
    # 第三级退化：自模型/保形失效或已过截止时间
    if drift >= TAU_DRIFT or M.U_self > TAU_SELF or tau_epi <= 0:
        u = M.reactive_cbf.safe_stop(o.q, O)
    k   = M.c_ras_wm.certified_whole_body(u, O, wm_preds)          # 全身安全认证
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_unres))
    M.vqa_k.submit_async(g, tau_epi, t_c, drift, U_res, U_unres)
    return k, lam, u, (tau_epi, U_res, U_unres)
```

## 3. 推导

**引理 19（时限可解性）** 设信息动作 g 耗时 `Δ_g`，其消解收益上界为 `B_g`，碰撞损失为 `L`。若 `t + Δ_g > τ_epi`，则 g 的期望收益 ≤ 0，且承诺动作的期望风险严格小于「先查询再承诺」。故 R69 的 `VoI − c` 应替换为 `ST-VoI` 且带硬时限约束；时间越紧，可交互集合单调收缩。

**引理 20（承诺的期权价值与阈值结构）** 令 `V_t` 为 t 时刻继续等待的期权价值。在障碍接近速率有界、信息收益递减（A99）下，`V_t` 关于 t 单调不增且为凸；因此最优停止集是阈值型：存在 `κ` 使 `risk_rate / option_decay ≥ κ` 时承诺最优，且承诺时刻早于不可逆点 `t_pnr`。

**引理 21（全身可负担性扩展安全集，自模型不确定收缩之）** 对同一 q，`𝒜_wb` 中的 brace/side_step 等动态动作使可达避让集 `𝒮_wb` 严格包含点质量模型的可行集（A100：接触不引入新的失效）；但以 1−δ 可信集取交后 `R_wb^rob ⊆ R_wb`，故 `τ_epi^-(U_self) ≤ τ_epi^-(U_self=0)`。即：身体给你更多选项，也让你更清楚自己不能保证什么。

**引理 22（可读信号的社会信息增益）** 若观察者策略对意图后验 Lipschitz（A101），则可读信号使 `VoI_soc ≥ c_leg · Leg_j(ξ) − ε`；在闭环预测下，社会信息增益进一步降低机器人自身预测熵，改善 `𝒪(t)` 的紧致性。系：可读性不是「礼貌」，而是预测精度的免费来源。

**定理 18（KAIROS 严格包含 R69 与反应式避让）** 在 A99–A101 下：当场景静态（无移动体，τ_epi=∞）时，KAIROS 逐指令等价于 R69；当 τ_epi≤0 时，KAIROS 逐指令退化为认证反应式避让/安全停止；两者之间，KAIROS 的期望碰撞风险不高于、任务代价不高于各自的线性插值。故 R69 与反应式安全都是 KAIROS 的边界情形，安全侧不做让步。

**定理 19（概率安全与承诺无抖动）** 在保形覆盖 1−δ、鲁棒全身可达集认证、TCG 迟滞 `d_min` 下，闭环碰撞概率 ≤ δ + ε_wb + ε_pred；承诺切换次数 ≤ ⌈T/d_min⌉；ZMP/接触/摩擦约束在执行轨迹上保持，控制连续且无抖振。

## 6. 本轮最大风险

**一句话**：KAIROS 的安全性完全押在 `τ_epi` 的估计上，而 `τ_epi` 依赖人形机器人对自身接触动力学（摩擦、载荷、执行器退化）的置信集——**一旦自模型把 `τ_epi` 高估哪怕 200ms，系统就会自信地「再观察一次/再问一句」，把本可避免的碰撞变成一次已经承诺、无法撤回的碰撞**；这是人形与轮式最本质的差别：轮式错估时限只是撞上，人形错估时限还会在错误的支撑上摔倒。

**次级风险与缓解**：
1. **闭环预测的保形覆盖失效**（他人因机器人动作而移出标定分布）→ 定义 315 的 drift 告警 + 提高 δ + E308 闭环验证；
2. **可读信号被伪装利用**（假让行诱导）→ ℰ_motion 对抗训练 + 多源证据 + E309；
3. **承诺抖动/反复变向** → TCG 迟滞 `d_min` + 引理 20 阈值结构 + E310；
4. **全身认证过保守导致无解** → 三级退化到反应式安全停止，安全侧不弱化；
5. **实时预算被全身可达集击穿** → 缓存 + 区间可达 + 优先级预算，复杂场景允许一次性超支。

## 3. 关键算法伪代码

```python
# IP-264 TED：给 R69 的 U_epi 加时钟
def temporal_decompose(samples, z, tau_epi, feasible_g):
    U_ale, U_epi, modes = r69_decompose(samples, z)
    t_best = min((duration(g) for g in feasible_g), default=INF)
    p_res  = resolve_probability(modes, feasible_g) if t_best < tau_epi else 0.0
    return U_ale, U_epi * p_res, U_epi * (1.0 - p_res), modes   # res / unres

# IP-265 DPF：闭环预测 + 保形可达集
def closed_loop_reach(predictor, x_t, a_future, delta):
    pj    = [predictor.j(j, x_t, a_future) for j in agents(x_t)]   # 条件于机器人动作
    O     = [conformal_region(p, 1 - delta) for p in pj]
    drift = mean(kl_closed_open(pj))
    return O, drift

# IP-266 WBR：自模型不确定下的鲁棒全身可达集 + 时限反推
def robust_reachable(q_t, theta_ci, t, H):
    return intersect(whole_body_reachable(q_t, theta, t, H) for theta in theta_ci)

def epistemic_deadline(q_t, O_t, theta_ci, H):
    for t in descending_candidates(H):
        if any(disjoint(robust_reachable(q_t, theta_ci, t, H), O_t)
               for u in affordable(q_t)):
            return t
    return 0.0

# IP-267 STV：带时限的信息动作选择（含可读让行信号）
def choose_info_or_commit(modes, q_t, tau_epi, budget):
    best = None
    for g in info_candidates(modes):                 # gaze / slow-observe / ask / legible-yield
        if not budget.allow(g) or time(g) > tau_epi - EPS_MARGIN: continue
        if not c_ras_wm.certify_info(g, q_t): continue
        voi = (query_voi(modes, g) + social_voi(g)) / max(time(g), EPS)
        if best is None or voi - cost(g) > best.score: best = (g, voi - cost(g))
    return best if best and best.score > 0 else None  # 来不及/无利可图 → 承诺或 R69 保守

# IP-268 TCG：承诺 vs 期权（最优停止 + 迟滞）
def time_to_commit(risk_rate, option_value, t, state):
    if state.committed:
        return state.t_c if t - state.t_c < D_MIN else None
    if risk_rate(t) / max(option_decay(option_value, t), EPS) >= KAPPA:
        return t
    return None

# IP-270 KAIROS 主闭环（继承 R69，在处置不确定性前插入时钟与身体）
def KAIROS_round(M, obs):
    z, o = M.mtm.forward(obs)
    O, drift = M.dpf.closed_loop_reach(o, M.planned_action, M.delta)
    theta_ci = M.wbr.self_model_ci(M.U_self, M.delta)
    tau_epi  = M.wbr.epistemic_deadline(o.q, O, theta_ci, M.H)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_res, U_unres, modes = M.ted.temporal_decompose(
        samples, z, tau_epi, M.info_candidates)
    g = (M.stv.choose_info_or_commit(modes, o.q, tau_epi, M.budget)
         if (U_res > TAU_EPI and drift < TAU_DRIFT) else None)
    if g is not None: U_res = M.cia.update_belief(modes, M.cia.execute(g))
    t_c = M.tcg.time_to_commit(M.risk_rate, M.option_value, obs.t, M.tcg_state)
    u = M.tcg.commit_action(modes, t_c, O) if t_c is not None else M.tcg.hold(modes, O)
    if drift >= TAU_DRIFT or M.U_self > TAU_SELF or tau_epi <= 0:
        u = M.reactive_cbf.safe_stop(o.q, O)                 # 第三级退化
    k   = M.c_ras_wm.certified_whole_body(u, O, wm_preds)
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_unres))
    M.vqa_k.submit_async(g, tau_epi, t_c, drift, U_res, U_unres)
    return k, lam, u, (tau_epi, U_res, U_unres)
```

## 4. 推导

**引理 19（时限可解性）** 若 `t+Δ_g > τ_epi`，信息动作 g 的期望收益 ≤ 0，且此时「先承诺」的期望风险严格小于「先查询再承诺」；可交互集合随时限收紧单调收缩。

**引理 20（承诺的期权价值与阈值结构）** 在障碍接近速率有界、信息收益递减（A99）下，期权价值 `V_t` 单调不增且为凸；最优停止集为阈值型：`risk_rate/option_decay ≥ κ` 时承诺最优，且 `t_c < t_pnr`。

**引理 21（全身可负担性扩展安全集、自模型不确定收缩之）** 动态可负担动作使 `𝒮_wb` 严格包含点质量模型可行集（A100：接触不引入新失效）；但取 1−δ 交后 `R_wb^rob ⊆ R_wb`，故 `τ_epi^-(U_self) ≤ τ_epi^-(U_self=0)`。

**引理 22（可读信号的社会信息增益）** 观察者策略对意图后验 Lipschitz（A101）时，`VoI_soc ≥ c_leg·Leg_j(ξ) − ε`；闭环下社会信息进一步降低机器人自身预测熵，改善 `𝒪(t)` 紧致性。

**定理 18（KAIROS 严格包含 R69 与反应式避让）** 静态（τ_epi=∞）时逐指令等价 R69；τ_epi≤0 时逐指令退化为认证反应式安全停止；中间区间的期望碰撞风险与任务代价均不劣于两端线性插值。安全侧不让步。

**定理 19（概率安全与承诺无抖动）** 保形覆盖 1−δ + 鲁棒全身可达认证 + 迟滞 `d_min` 下，闭环碰撞概率 ≤ `δ+ε_wb+ε_pred`；承诺切换次数 ≤ `⌈T/d_min⌉`；ZMP/接触/摩擦约束保持，控制连续无抖振。

## 7. 本轮最大风险

**一句话**：KAIROS 的安全性完全押在 `τ_epi` 的估计上，而 `τ_epi` 依赖人形机器人对自身接触动力学（摩擦、载荷、执行器退化）的置信集——**一旦自模型把 `τ_epi` 高估哪怕 200ms，系统就会自信地「再观察一次/再问一句」，把本可避免的碰撞变成一次已经承诺、无法撤回的碰撞**；这是人形与轮式最本质的差别：轮式错估时限只是撞上，人形错估时限还会在错误的支撑上摔倒。

**次级风险与缓解**：闭环预测的保形覆盖失效（drift 告警 + 提高 δ + E308）；可读信号被伪装利用（ℰ_motion 对抗训练 + 多源证据 + E309）；承诺抖动（迟滞 `d_min` + 引理 20 + E310）；全身认证过保守导致无解（三级退化到反应式安全停止）；实时预算被全身可达集击穿（缓存 + 区间可达 + 优先级预算）。
