# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS」IP-287~294；灵感循环第 1 轮；本轮灵感：「自主导航」×「状态隔离」）

> R72 把 GAUGE 从「认知层算法」下沉为**具身闭环**：REG 实时执行图、IRL 意图隐变量、DMEM 灵巧接触计量、EREFLEX 三层反作用、S2R-UQ 参数桥接、三域分离。但它仍默认机器人**站在一张桌子前**：世界状态 s 有一个**共享的、局部的、可观测的**参考系，`b_t(s,z)` 是单一后验，安全包络 `λ` 在同一坐标系里定义。R72 的「三域分离」隔离的是**时间频段**，不是**空间状态的所有权**。
> - **自主导航视角**：机器人一旦**移动**，就引入了一类 R72 从未处理的状态——**全局位姿与地图**。这类状态有三个致命性质：(a) **规范自由**：全局位姿只在 SE(n) 刚体变换下可辨识，地图原点与朝向是**任意的规范选择（gauge fix）**，不是物理真相；(b) **非局部累积误差**：里程计漂移、回环、地图陈旧都是**长程、非平稳、多峰**的，一次回环闭合会把整条轨迹「瞬移」，一次绑架（kidnapped robot）会把后验变成多峰；(c) **它定义安全本身**：避障、可达性、证书都写在这个坐标系里——**参考系错了，安全证书错得毫无自觉**。更关键：导航是**主动信息获取**（active SLAM），「走到哪」本身就是一次「问世界」的动作，这与 R72 的 ERVOI「问人」是同一枚硬币的两面。
> - **状态隔离视角**：R72 的 `b_t(s,z)` 是一个**单体后验（monolithic posterior）**，所有子系统读同一份状态。但导航暴露出：接触层需要毫米级局部度量，控制层需要 1kHz 无阻塞局部快照，全局导航层需要米级、低频、可回滚的地图——**把它们塞进一个后验，既算不动，也认识论上错误**。更危险的是：**全局地图的一次投毒/一次错误回环若能直接写进控制安全状态，就会静默重写安全包络**。正确做法借鉴 OS 的**空间/故障隔离（ARINC-653、seL4、微内核）**：状态分单元、跨单元只走**带泄漏预算的膜（membrane）**、全局故障被**检疫（quarantine）**、爆炸半径被隔离边界硬性限制。
>
> 本轮核心命题：**R72 问「我的测量链在调度/人/触觉下还兑现风险界吗」；R73 要问「当定义安全的那个参考系本身在漂移、在犯错、甚至被投毒时，我的安全证书还成立吗？」**。答案不是「把地图做得更准」，而是**让安全不依赖任何单一全局真相**：把状态按所有权与有效域隔离，把证书写成**规范不变的**，把导航动作限制在**认证可导航包络（CNE）**内，把全局故障挡在**膜**外。据此把 EMBODIED-GAUGE-RAS 抬升为 **SIGN-GAUGE-RAS**（State-Isolated, Gauge-iNvariant Navigation GAUGE for RAS）——**隔离状态 × 规范不变 的自主导航计量审计闭环**。

## 0. 直觉与动机

**灵感 1（自主导航 → 地图不是真相，地图是规范场；安全必须规范不变）**
直觉：你在一条对称的走廊里，视觉告诉你「前方 10m 有门」，里程计告诉你「走了 12m」，先验地图说「应该是 11m」——三者没有绝对参照，**只有相对关系是物理的**。SLAM 的全局位姿天然有一个**规范自由度**：把整张地图平移、旋转，所有内部几何关系不变，所有传感器残差不变。这意味着**「地图中的绝对坐标」不是可观测量，是一个规范选择**。R71 的 GAUGE 已经引入「gauge 不变性间隙 ι」来衡量测量链对表示选择的敏感度；R73 把它从「测量表示」推广到**参考系表示**：**一个安全证书若依赖地图原点/朝向的选择，它就不是物理安全，只是某个坐标系的巧合**。真正该被认证的是**规范不变量**：相对距离、碰撞概率、包络裕度、可达性关系。**「自主导航的第一性原理不是定位得更准，而是承认没有绝对定位，并让安全对规范选择免疫。」**

**灵感 2（状态隔离 → 状态不是共享内存，状态是分权联邦；膜而非指针）**
直觉：单体后验 `b_t(s,z)` 相当于「所有子系统共享一块可写内存」：任意一个估计器（哪怕是被投毒的地图节点）写坏一个字段，控制环读到的安全边际就变了。状态隔离把这个「共享内存」换成**分权联邦**：每个单元拥有自己的状态、有效域、不确定度预算、追溯链；跨单元**禁止直接写**，只允许读**带不确定度、经膜审计的导出视图**，或走**可追溯的 merge**。其收益是**爆炸半径受限**：全局地图被污染 ⇒ 只影响导航计划，**不能直接改变接触层/控制层的安全证书**；代价是**一致性与信息损失**（隔离越强，全局信息越难下传），因此必须显式建模**隔离债（isolation debt）**并在合适时机**重审/重定位**来偿还。**「隔离不是免费的，但它是唯一能让局部安全不被全局错误绑架的结构。」**

**灵感 3（二者相乘 → 分层参考系 + 安全相关投影：只让「能伤到我的不确定度」进 λ）**
直觉：导航不确定度有五个来源——里程计、地图、定位跳变、动态障碍、参考系规范。若把**全体** `u_nav` 塞进 λ 分母（R72 的做法），机器人在探索未知区域时会**因远处未观测地图的巨大不确定度而冻结**；若只用位置方差标量，又会**漏掉关键方向**（沿墙方向的 2m 不确定度不危险，垂直墙面的 20cm 才危险）。正确做法是把协方差**投影到当前安全约束的梯度方向**：`u_nav^rel = sqrt(∇h^T Σ_nav ∇h)`。这个投影有两个漂亮性质：(a) **规范不变**——若约束 `h` 是规范不变的，则 ∇h 天然正交于规范轨道，不可观测的全局平移/旋转方向**自动不贡献** `u_nav^rel`；(b) **保守且不冻结**——只惩罚真正能吃进安全边际的那部分不确定度。**「不确定性不是越大越危险，而是越沿危险方向才越危险。」**

**灵感 4（导航反作用 → 移动既改变世界，也改变自己的可观测性；第四层反作用）**
直觉：R72 有三层反作用（ψ 情感、z 意图、c 接触）。导航加入**L4 导航反作用**：机器人移动 → 地图被更新（观测行为改变被观测对象）、可观测性改变（走到死胡同就再也看不到全局标志）、动态障碍被诱发（人会给移动的机器人让路或围观）、人的意图被改变（机器人走开，人可能喊「回来」）。更微妙的是：**移动是一次「查询」，它买来信息，也欠下「隔离债」**——你在未重审的全局图上走得越远，几何上离「最后可信锚点」越久，一旦回环打脸，纠正的代价越大。因此导航 VoI 必须同时计入**信息增益、移动成本、隔离债、以及出包络的风险**。

**灵感 5（空间退化链 → 全局失效退局部，局部失效退接触，永不裸奔）**
直觉：R72 的退化链是「REG/IRL/DMEM 失效 ⇒ R71/R68」。R73 增加**空间维度**：全局导航被检疫 ⇒ 收缩到**局部可认证导航**（局部地图 + 里程计，CNE 缩到传感器视界内）；局部位姿也失效 ⇒ 退 **R72**（无全局定位，只做接触/视觉/意图）；R72 再失效 ⇒ **R68** 开环安全包络 + 急停。**任何一层失效都只收缩「能去哪」，不取消「怎么保命」；安全侧只增不减。**

## 1. 形式化定义（增量：定义 366–383）

**定义 366（SIGN-GAUGE-RAS 总览与六不变式）** SIGN-GAUGE-RAS = (SIA, GINC, CNE, LFI, NSUB, I-NVOI, EMBODIED-GAUGE-RAS†)。六不变式：
(i) **状态隔离不可穿透**：控制域/接触域只读经膜审计的**局部导出视图**；全局导航状态**禁止直接写入**控制安全状态；
(ii) **参考系显式化**：任何证书必须声明所用规范固定 g₀，并报告规范敏感度 ι_frame；安全量必须规范不变或显式披露其规范依赖；
(iii) **空间证书包络**：任何导航计划必须落在 CNE 内；出界只能执行**降不确定度动作（重定位/主动观测/后退）**，不能硬闯；
(iv) **安全相关投影**：进入 λ 的导航不确定度只能是 `u_nav^rel`（安全约束梯度方向投影），不得使用无差别 `u_nav`，也不得只用一个标量；
(v) **故障隔离**：定位跳变/多峰/绑架/恶意回环必须被检疫并局部重建，**不得静默传播**到下游证书；
(vi) **严格空间退化链**：全局失效⇒局部；局部失效⇒R72；R72 失效⇒R68；全失效⇒安全停机。

**定义 367（状态隔离架构 SIA）** 状态被划分为**隔离单元（state cells）** 𝒞 = {c_ctrl, c_local, c_global, c_contact, c_intent, c_map, c_affect, ...}。每个单元 `c` 携带 (变量域 Vars_c, 后验 b_c, 有效域 D_c, 不确定度预算 U_c, 追溯链 τ_c)。定义：
- **所有权** own: Vars → 𝒞（每个状态变量恰属一个单元）；
- **膜** M ⊆ 𝒞×𝒞，每条有向膜 e=(c_i→c_j) 携带 (视图映射 π_e, 泄漏预算 ℓ_e, 审计函数 A_e, 追溯链 τ_e)；
- **读** c_j 读 c_i 只允许 `π_e(b_{c_i})`，且要求 `‖Cov(π_e(b_{c_i}))‖_* ≤ ℓ_e`（`‖·‖_*` 为 operator norm）；
- **写** 禁止；跨单元更新只能走 **merge 算子 ⊔**：`b_{c_j} ← b_{c_j} ⊔ Δ`，须满足 `A_e(Δ)=true`、`τ` 完整、且注入的不确定度 ≤ ℓ_e。
**无泄漏性质**：c_j 的证书只依赖自身状态与上游膜的导出视图；任一单元 c_i 的故障，不能改变 c_j 的证书，除非经一次通过审计且预算内的 merge。

**定义 368（参考系规范与 G-不变证书）** 导航状态 x 定义在参考系 F 上；全局位姿只在规范群 G ⊂ SE(n) 下可辨识（`x ~ g·x, g∈G`）。证书/安全函数 h 是 **G-不变的**，若 `h(g·x)=h(x), ∀g∈G`，等价地 `∇h · ξ_g = 0`，其中 `ξ_g = d/dε(g_ε·x)|₀` 为规范轨道切向。定义**规范敏感度** `ι_frame(h,x) = ‖∇h(x)·ξ_g‖_* / ‖∇h(x)‖`（归一化）。**证书 Valid 要求 ι_frame ≤ τ_frame**；对依赖绝对坐标的目标（如绝对 GPS 航点），必须把该绝对源单独建 cell 并声明其 gauge fix，不得与规范不变量混为一谈。**这把 R71 的 ι（测量表示不变性）升级为参考系不变性。**

**定义 369（认证可导航包络 CNE 与空间证书前缀）** 给定隔离状态与当前不确定度预算，认证可导航包络
CNE_t = { p ∈ SE(n) : ∃ 路径 γ: p₀→p, ∀s∈[0,1], min_k [ h_k(γ(s)) − κ·u_nav^rel(γ(s)) ] ≥ h_min ∧ J_cell 有效 }，
其中 h_k 为第 k 条安全约束（障碍裕度、倾覆裕度、可达边界、动力学可行域），κ 为保守系数。任一导航计划 π 必须满足 `π ⊆ CNE_t`；若目标在包络外，必须先执行**降不确定度动作**（主动重定位、观测已知地标、收缩视界）。**这是 R72「认证动作前缀 k」的空间对偶：从「走几步才安全」变成「能走多远才安全」。**

**定义 370（导航不确定度预算 NSUB）** 
`u_nav² = u_odom² + u_map² + u_loc² + u_dyn² + u_frame²`，
分别对应里程计漂移、地图不确定度（未观测/陈旧/低分辨率）、定位跳变与多峰（绑架、回环、感知歧义）、动态障碍、参考系规范不确定度。每项独立追溯链 τ_nav_i。**NSUB 是全量账本，但绝不整体进入 λ（见定义 371）。**

**定义 371（安全相关投影与方向性不确定度）** 设当前活跃安全约束集为 {h_k}，导航状态协方差为 Σ_nav。定义
`u_nav^rel = max_k sqrt( ∇h_k^T Σ_nav ∇h_k )`（取最危险方向，保守），
以及 **规范不变性推论**：若所有 h_k 是 G-不变的，则 `∇h_k ⊥ ξ_g`，不可观测的规范方向对 u_nav^rel **零贡献**。λ 只消费 u_nav^rel。**「安全相关不确定度 = 沿危险方向的方差」，不是全协方差的范数。**

**定义 372（定位故障隔离 LFI 与检疫）** 定位故障检测器监测四类信号：后验多峰度（mode count / mode gap）、位姿跳变量、回环残差、绑架/可观测性退化（对称走廊、长时间无标志）。任一超阈 ⇒ 触发：
1. `c_global`、`c_map` 置为 **QUARANTINED**（只读、不参与证书、不向下游 merge）；
2. 以**最近可信局部锚点**重建 `c_local`；
3. 导航降级 LOCAL_ONLY；
4. 全局状态须经 **SEAL-NAV 重审**（离线隐藏场景 + 在线一致性）才解除检疫。
**检疫期内，隔离性保证控制/接触证书不依赖被污染全局状态。**

**定义 373（L4 导航反作用与隔离债）** 在 EREFLEX 三层（ψ/z/c）之上加 **L4 导航反作用**：
- 地图反作用：移动改变地图后验，成本 `c_reflex^map = D_KL(b_map^prior ‖ b_map^post)`；
- 可观测性反作用：移动改变未来可观测性（进入遮挡/死胡同的惩罚）；
- 动态反作用：移动诱发/驱散动态障碍，成本 `c_reflex^dyn`；
- **隔离债** `D_iso(t)`：自最后可信全局锚点以来，依赖「未重审全局状态」累积的暴露量，`D_iso(t+1)=ρ·D_iso(t)+w·‖π(LOCAL_ONLY)‖`；债越高，回环打脸时纠正代价越大，触发强制重审。
累计反作用预算 `c_reflex^ψ+c_reflex^z+c_reflex^c+c_reflex^nav ≤ B_reflex_total`，任一层越界 ⇒ IVG 降级。

**定义 374（隔离感知导航 VoI：I-NVOI）** 
`VoI^N(g) = α·IG_map(g) + β·IG_loc(g) + η·IG_intent(g) − c_move(g) − c_reflex^nav(g) − ρ·ΔD_iso(g) − γ·E[Loss(π_g ∉ CNE)]`。
前两项是**主动 SLAM 的探索增益**（地图/定位信息），第三项延续 R72 的意图澄清增益，后三项是移动成本、导航反作用、隔离债与出包络风险。**选择 `g* = argmax VoI^N s.t. π_g ⊆ CNE, 各层预算未超`**；`max VoI^N ≤ 0` 即停在原地或退回。**「探索」不是免费的勇敢，是带预算、带包络、带债务的信息投资。**

**定义 375（导航风险缩放 N-RISK）** 
`λ = max( risk_scale(U_ale, U_epi, H[b_t(z)], u_tac, u_nav^rel), λ_floor(U_ale+U_epi+H[b_t(z)]+u_tac+u_nav^rel) )`。
**关键**：进入分母的是**规范不变的、方向投影后的** `u_nav^rel`。地图远处未观测不冻结机器人（方向正交）；贴近障碍且定位多峰时 λ 急升（方向对齐）。**导航不确定度不是「又一个标量」，是「一个带方向的场」。**

**定义 376（跨尺度重审膜与回环闭合）** 全局回环/地图更新 `Δ` 下传到局部单元必须经 **ReAuditMembrane**：若 `‖Cov(Δ)‖_* ≤ ℓ_loop` 且 `A_e(Δ)` 通过 ⇒ 可追溯 merge；否则**禁止静默 patch**，必须**作废局部证书并重估**（`c_local.invalidate(reason)`）。**「回环不是 bug，但把回环当无事发生的静默更新是 bug。」**

**定义 377（严格空间退化链）** 
- 全有效 ⇒ SIGN-GAUGE-RAS（全局+局部+具身操作）；
- 全局导航检疫/失效 ⇒ **LOCAL_ONLY**（局部地图+里程计，CNE 收缩到可认证视界，航速受限）+ R72；
- 局部位姿也失效 ⇒ **R72**（接触/视觉/意图，无全局定位）；
- R72 失效 ⇒ **R68**（开环安全包络 + 硬急停）；
- 全失效 ⇒ 安全停机。
**每级退化保留所有下层安全机制，安全侧只增不减。**

**定义 378（导航证书 J_NAV）** `J_NAV = (J_EMB, sia_hash, gauge_fix, gauge_invariance_report(ι_frame), cne_proof, nsub_chain, lfi_state, loop_audit_hash, nav_ver)`。Valid ⇔ `Valid(J_EMB) ∧ SIA 膜契约哈希匹配 ∧ ι_frame ≤ τ_frame ∧ CNE 前向不变证明有效 ∧ NSUB 链完整 ∧ LFI 未处于未处理故障态 ∧ 回环重审链完整`。

**定义 379（威胁模型 AIC-NAV）** ℰ_NAV = ℰ_EMB × ℰ_map × ℰ_loc × ℰ_iso：
- ℰ_map = {地图投毒、伪造回环、对抗路标、陈旧地图重放、坐标原点篡改}；
- ℰ_loc = {GPS/传感器欺骗、绑架诱导、对称性利用、多峰注入}；
- ℰ_iso = {膜绕过、检疫逃逸、跨单元污染、回滚攻击、隔离债耗尽诱导}。
**核心安全论证（见定理 27）：只要膜与检疫有效，即使全局地图被完全投毒，控制/接触层的安全证书不受影响——爆炸半径被隔离边界硬性限制。**

**定义 380（多假设隔离）** 在感知歧义/绑架时，不把全局后验塌缩成单一最大后验，而维护**隔离的多假设集** `{H_1,...,H_m}`，每个假设是一个独立 cell，各自带 CNE；只有当某假设在该 CNE 内**单峰占优且跨模态一致**时才提升为「可认证全局状态」。**「对称走廊里不要假装知道自己在哪，要诚实地同时持有两种可能，并只在两者都安全的包络里行动。」**

**定义 381（导航指标族 NAV-MIB）** 新增：`ι_frame`（规范间隙）、`u_nav^rel`（方向不确定度）、CNE 体积/收缩率、LOCAL_ONLY 占比、检疫触发频次/时长、回环重审拒绝率、隔离债 D_iso、爆炸半径实测（单 cell 故障对下游证书的最大扰动）。全部遵循 R71 六元组（φ,m,u,D,τ,I⊥）与 DAG 分层。

**定义 382（隔离完整性 IVG-ISO）** 失效条件：膜泄漏超预算、跨单元未审计写、检疫逃逸、CNE 越界、ι_frame 超阈、NSUB 任一分量断链、回环重审链断裂。任一成立 ⇒ 对应单元失效并收缩退化（定义 377）。

**定义 383（空间-时间联合调度契约）** 在 R72 REG 上新增全局导航域：节点 n_global（π=5–20，δ=100–1000ms，dynamic，可抢占可丢帧），且**全局域绝不在控制域关键路径上**；回环/重定位作为**低优先级批处理**，其输出必须经 ReAuditMembrane 才可进局部快照。**R72 保证「计量不阻塞控制」，R73 保证「全局导航不阻塞计量与控制」。**

```python
# IP-295 SIA：状态隔离架构（膜 + 无泄漏读 + 可追溯 merge）
@dataclass
class StateCell:
    name: str
    vars: set
    posterior: object
    validity: object          # 有效域 D_c
    budget: float             # U_c
    tchain: bytes             # τ_c

@dataclass
class Membrane:
    view_fn: Callable         # π_e: 导出带不确定度的视图
    leak_budget: float        # ℓ_e
    audit_fn: Callable        # A_e(Δ) -> bool
    tchain: bytes

class StateIsolationArch:
    def __init__(self, cells, membranes):
        self.cells, self.membranes = cells, membranes
    def read(self, src, dst):
        e = self.membranes[(src, dst)]
        view = e.view_fn(self.cells[src])
        if cov_norm(view.cov) > e.leak_budget:
            raise IsolationBreach(f"{src}->{dst} leak {cov_norm(view.cov)}>{e.leak_budget}")
        return view                        # 只读导出视图，绝不返回原对象
    def merge(self, src, dst, delta):
        e = self.membranes[(src, dst)]
        if not e.audit_fn(delta):
            raise IsolationBreach("merge audit failed")
        if cov_norm(delta.cov) > e.leak_budget:
            # 超预算 ⇒ 不静默写；作废下游证书并重估
            self.cells[dst].posterior.invalidate("membrane_budget_exceeded")
            return self.cells[dst].posterior.reestimate()
        return self.cells[dst].posterior.update(delta, tchain=e.tchain)

# IP-296 GINC：规范不变导航证书（声明 gauge fix + 报告 ι_frame）
def gauge_invariant_certificate(x, gauge_fix, safety_fns):
    orbit = gauge_orbit(x)                 # ξ_g：规范轨道切向
    report = {}
    for name, h in safety_fns.items():
        g = grad(h, x)
        sens = norm(g @ orbit) / (norm(g) + 1e-12)
        report[name] = (h(x), sens, sens <= TAU_FRAME)
    iota_frame = max(r[1] for r in report.values())
    return Certificate(report, gauge_fix=gauge_fix, iota_frame=iota_frame,
                       valid=all(r[2] for r in report.values()))

# IP-297 CNE：认证可导航包络（空间证书前缀 + 前向不变检查）
def certified_navigable_envelope(x, safety_fns, Sigma_nav, h_min, grid):
    cne = []
    for p in grid.reachable(x.pose):
        margins = [h(p) for h in safety_fns.values()]
        grads   = [grad(h, p) for h in safety_fns.values()]
        u_rel   = max(math.sqrt(g.T @ Sigma_nav @ g) for g in grads)
        if min(margins) - KAPPA * u_rel >= h_min:
            cne.append(p)
    return Envelope(cne, forward_invariant=check_cbf_invariance(cne, safety_fns, Sigma_nav))

# IP-298 NSUB：导航不确定度账本 + 安全相关投影（只 u_nav^rel 进 λ）
def nav_uncertainty_projection(Sigma_nav, active_constraints, x):
    u_full = math.sqrt(Sigma_nav.odom + Sigma_nav.map + Sigma_nav.loc
                       + Sigma_nav.dyn + Sigma_nav.frame)
    u_rel = max(math.sqrt(grad(h, x).T @ Sigma_nav.P @ grad(h, x))
                for h in active_constraints)
    return u_full, u_rel          # 账本用 u_full，λ 只用 u_rel（规范不变量）

# IP-299 LFI：定位故障隔离与检疫
class LocalizationFaultIsolator:
    def monitor(self, pose_post, loop_residual, obs):
        multimodal = pose_post.n_modes > 1 and pose_post.mode_gap < TAU_GAP
        jump       = pose_dist(pose_post.mode, self.last_mode) > TAU_JUMP
        kidnap     = self.detector.kidnapped(obs)
        if multimodal or jump or kidnap:
            self.sia.quarantine(['global', 'map'])      # 只读、不参与证书
            self.reanchor_local(pose_post.nearest_trusted_anchor)

        return Mode.FULL

# IP-300 I-NVOI：隔离感知导航 VoI（探索 = 带预算/包络/债务的投资）
def isolation_aware_nav_voi(cells, budget, cne, candidates):
    best = None
    for g in candidates:
        path = plan(g)
        if not cne.contains(path) or not budget.allow(g):
            continue
        ig_map = info_gain(cells['map'], g)
        ig_loc = info_gain(cells['local'], g)
        ig_int = ETA * info_gain(cells['intent'], g)
        cost   = move_cost(g) + reflex_cost(cells, g) + RHO * debt_rate(cells['local'])
        score  = ALPHA*ig_map + BETA*ig_loc + ig_int - cost \
                 - GAMMA * expected_loss_outside_cne(g, cells)
        if best is None or score > best.score:
            best = (g, score)
    return best if best and best.score > 0 else None

# IP-301 N-RISK：导航风险缩放（方向投影后的规范不变不确定度入分母）
def nav_risk_scale(U_ale, U_epi, H_z, u_tac, u_nav_rel, params):
    denom = U_ale + U_epi + H_z + u_tac + u_nav_rel
    lam   = params.lam_base * (1 + denom / params.lam_scale)
    return max(lam, params.lam_floor * (1 + denom))

# IP-302 SIGN-GAUGE 主闭环（全局域异步；控制域只读隔离视图；CNE 门控）
def SIGN_GAUGE_RAS_round(M, obs, audio, tac_frame, nav_state):
    # ===== 全局导航域（1-10Hz，隔离 cell，绝不在控制关键路径） =====
    if M.clock.due_global():
        mode = M.lfi.monitor(nav_state.pose, nav_state.loop_residual, obs)
        if mode == Mode.LOCAL_ONLY:
            M.mode_global = Mode.LOCAL_ONLY
        # 回环更新只经重审膜下传，禁止直接写局部
        if nav_state.loop_delta is not None:
            M.sia.merge('global', 'local', nav_state.loop_delta)
        M.snapshot.write_global(M.sia.cells['global'], M.sia.cells['map'])

    # ===== 控制域（1kHz，硬实时，只读经膜审计的局部视图） =====
    local = M.sia.read('local', 'ctrl')
    b_t   = M.bse.step_ctrl(local.b_prev, obs, M.last_action, M.last_g, M.last_y)
    U_ale, U_epi = decompose_ctrl(b_t, M.fmp, obs)
    H_z   = local.z_dist.entropy() if local.z_dist else 0.0
    u_tac = local.tac_ev.u_tac if local.tac_ev else 0.0
    u_rel = nav_uncertainty_projection(local.Sigma_nav, M.cne.active_constraints, local.x)
    lam   = nav_risk_scale(U_ale, U_epi, H_z, u_tac, u_rel, M.risk_params)
    A = M.ach.propose_ctrl(...); k = M.c_ras_wm.certified_prefix(A, lam, ...)
    if not M.cne.contains(M.next_pose(k)):
        k = M.cne.backoff_prefix(k)        # 出包络 ⇒ 回退到包络内前缀
    M.ctrl_out.publish(k, lam)
    M.cert_ctrl.write(k=k, lam=lam, u_nav_rel=u_rel, wcet=M.rtm.wcet_us())

    # ===== 计量域（50Hz，软实时，写快照） =====
    if M.clock.due_metric():

        z_dist, ece_z, iota_z = M.irl.update(M.y_intent_buf, M.psi_hat, b_t_full)

    if tac_ev.u_tac > TAU_U_TAC: M.tac_ev = None

                                       or M.cne.shrink_ratio > TAU_SHRINK):

        if g:
            M.execute_nav(g)
    return k, lam, J_NAV(M)

# IP-303 ReAuditMembrane：回环跨尺度重审（超预算 ⇒ 作废重估，绝不静默 patch）
class ReAuditMembrane:
    def __init__(self, budget): self.budget = budget
    def propagate(self, local_cell, delta):
        if cov_norm(delta.cov) > self.budget or not audit_loop(delta):
            local_cell.posterior.invalidate("loop_closure_exceeds_budget")
            return local_cell.posterior.reestimate()      # 重估，而非打补丁
        return local_cell.posterior.update(delta, tchain=hash(delta))
```

## 3. 推导

**引理 33（膜泄漏有界 ⇒ 下游证书扰动有界）** 设膜 e=(i→j) 的泄漏预算为 ℓ_e，下游证书 J_j 对注入状态是 L_j-Lipschitz。则任一上游单元故障经该膜对 J_j 的扰动满足 `|ΔJ_j| ≤ L_j · ℓ_e`。证明：读只经导出视图 π_e，视图协方差被 ℓ_e 截断；J_j 的 Lipschitz 性把状态扰动线性放大。系：**爆炸半径 ≤ L_j·ℓ_e，与上游故障的严重程度无关——这正是「隔离」的可证明含义。**

**引理 34（规范不变性 ⇒ 不可观测方向自动零贡献）** 若安全约束 h 是 G-不变的，则 `∇h·ξ_g=0`；因此对任意含规范不可观测方向的协方差 Σ_nav，方向投影 `∇h^T Σ_nav ∇h` 不感知规范方向的方差。证明：Σ_nav 在规范方向的分解项与 ∇h 正交。系：**`u_nav^rel` 自动忽略「地图整体平移/旋转的不确定度」——这类不确定度物理上无害，因而不该冻结机器人。**

**引理 35（相关性投影的保守性与紧致性）** 记安全边际 `m = min_k h_k`。一阶展开 `m(p+δ) ≈ m(p) + ∇h_{k*}·δ`，故 `P(m<0) ≤ Φ(−m / sqrt(∇h^T Σ ∇h))`。取最危险约束方向给出**保守上界**；仅用位置方差标量 `tr(Σ)` 会高估无害方向、低估危险方向。系：**「越沿危险方向越危险」不是修辞，是风险上界的正确变量。**

**引理 36（检疫期安全单调）** 检疫只**移除**信息（把全局/地图置为只读、不参与证书），不注入任何信息；由隔离性（定义 367），下游证书不读取被检疫单元。故检疫前后下游风险上界满足 `Risk_after ≤ Risk_before`。证明：证书依赖的状态集合在检疫后是检疫前的子集。系：**「不知道」永远比「错误地知道」安全——检疫是信息层面的减法，因而安全侧只增不减。**

**引理 37（导航反作用预算的有限停止）** 扩展引理 31：加入 L4 后，总成本 `C(n)=Σ(c^ψ+c^z+c^c+c^nav)`，隔离债每步有正漂移下界（依赖未重审全局状态），地图/定位信息增益随覆盖饱和而边际递减。故存在有限 n*，第 n*+1 步边际净收益 ≤0，I-NVOI 停止。**「什么时候停止探索并回去重审」仍可证明有限，不是调参。**

**定理 27（状态隔离 ⇒ 爆炸半径受限）** 在定义 367 与引理 33 下，对任意单一单元 c_i 的任意腐败（含全局地图完全投毒），控制/接触层证书的扰动 ≤ 沿最短膜路径的 Lipschitz 乘积上界 `∏ L_e·ℓ_e`；若该路径上的膜预算满足 `∏ L_e·ℓ_e ≤ ε_safe`，则**控制层不产生安全违规**。**即使导航层被完全攻陷，局部安全仍成立——这是「隔离即安全边界」的形式化。**

**定理 28（规范不变的导航安全）** 若所有安全约束 h_k 与证书均 G-不变，则 `CNE_t`、`λ`、`J_NAV` 在任意规范固定 g₀ 下取值相同；回环重参数化（本质是 G 作用）不改变认证安全结果，只改变地图的坐标表示。**「换个原点/转个朝向，安全结论必须一模一样」——这就是自主导航里「客观性」的定义。**

**定理 29（严格空间包含与风险单调）** 在 A111–A116（膜预算有界、ι_frame 有效、CNE 前向不变、NSUB 链完整、LFI 可检出、L4 Lipschitz）下：SIGN-GAUGE 在定义 377 的退化条件下逐指令等于 LOCAL_ONLY/R72/R68；且对任意有效执行，风险界 ≤ R72 风险界 ≤ R71。**安全单调不减；效率只在「全局可信、局部可认证、规范可审计」时获益。**

**定理 30（CNE 的保守前向不变性）** 若 λ 使用 NSUB 的保守上界（取最危险方向 + 分位数），且每条计划都满足 CBF 型条件 `ḣ_k + α(h_k) ≥ 0`，则从 `p₀∈CNE_t` 出发、执行任意 `π⊆CNE_t` 的轨迹，对任意时刻保持 `λ ≤ λ_max`（前向不变）。**「认证包络」不是一次性检查，而是一个前向不变集。**

**定理 31（探索不牺牲硬安全）** I-NVOI 只在 `π_g ⊆ CNE` 且四层反作用预算未超时接受移动 g*；CNE 定义保证最坏情况下安全边际仍 ≥ h_min。故主动探索（active SLAM）不降低硬安全下界，只消耗「效率/时间/隔离债」。**探索是安全的，但可能很贵——这正是它该被建模成「投资」而非「免费午餐」的原因。**

## 6. 本轮最大风险

**一句话**：SIGN-GAUGE-RAS 把安全从「相信具身测量链」进一步转移到「相信**状态隔离膜真的不可穿透**、相信**规范不变性检查覆盖了所有真正进入安全判断的量**、相信**CNE 在分布外仍是保守前向不变集**」——**如果某个安全函数看似规范不变、实则通过一个隐蔽的绝对坐标通道（如绝对航点、地图原点绑定的语义标签、未声明的尺度规范）悄悄依赖了 gauge fix，那么 ι_frame 会漏报，证书会在一张被平移/旋转/投毒的地图上「规范不变地」给出错误的安全结论；或者某条膜因实现细节（共享指针、缓存快照、异常路径）发生了未审计的写，导致全局地图污染绕过隔离直达控制层；或者 CNE 在动态障碍/传感器退化下失去前向不变性，机器人会「拿着通过所有检查的证书」走进一个当时看起来安全、实则已经出界的区域——这就是自主导航层面的「自信地错自己的参考系」**。

次级风险与缓解：
1. **隐蔽规范依赖** → 对所有进入安全判断的量做**符号-数值双重规范审计**（自动微分检查 ∇h⊥ξ_g + 随机规范扰动回归测试），未声明规范依赖即拒绝签发 J_NAV。
2. **膜被实现细节击穿** → 膜只暴露**不可变快照**（copy-on-write / 版本号 + 无指针逃逸），跨单元访问全部经 SIA API；红队 E389 常态化；用类型系统/所有权检查静态阻断。
3. **CNE 失去前向不变** → 在线 **CBF 残差监控**：每周期检查 `ḣ+α(h)≥0`，违反即收缩包络并降速；用分位数上界而非均值。
4. **检疫抖动（反复检疫/解除）** → 检疫加**滞回 + 冷却期 + 隔离债门控**，避免在边界反复横跳。
5. **多假设爆炸** → 假设数上限 m≤8，按 CNE 体积/似然剪枝，保留「两两都安全」的交集包络。
6. **隔离导致信息僵化（该用的全局信息用不上）** → 用**受控 merge + 隔离债偿还计划**显式放行低风险全局信息；把「隔离强度」作为可调 Pareto 参数（E398）。
7. **复杂度/实时性** → 全局域彻底异步且可丢帧；控制域只做 O(1) 的投影与包络内回退；所有重活（CNE、回环重审、多假设）在导航域批处理。

**定义 366（SIGN-GAUGE-RAS 总览与六不变式）** 见想法区。核心：状态隔离不可穿透、参考系显式化、空间证书包络、安全相关投影、故障隔离、严格空间退化链。

## 3. 关键算法伪代码

```python
# IP-295 SIA：状态隔离架构（膜 + 无泄漏读 + 可追溯 merge）
@dataclass
class StateCell:
    name: str; vars: set; posterior: object
    validity: object; budget: float; tchain: bytes

@dataclass
class Membrane:
    view_fn: Callable; leak_budget: float; audit_fn: Callable; tchain: bytes

class StateIsolationArch:
    def __init__(self, cells, membranes):
        self.cells, self.membranes = cells, membranes
    def read(self, src, dst):
        e = self.membranes[(src, dst)]
        view = e.view_fn(self.cells[src])                 # 导出带不确定度视图
        if cov_norm(view.cov) > e.leak_budget:
            raise IsolationBreach(f"{src}->{dst} leak")
        return view                                        # 不返回原对象
    def merge(self, src, dst, delta):
        e = self.membranes[(src, dst)]
        if not e.audit_fn(delta) or cov_norm(delta.cov) > e.leak_budget:
            self.cells[dst].posterior.invalidate("membrane_budget")
            return self.cells[dst].posterior.reestimate()  # 不静默写
        return self.cells[dst].posterior.update(delta, tchain=e.tchain)

# IP-296 GINC：规范不变导航证书
def gauge_invariant_certificate(x, gauge_fix, safety_fns):
    orbit = gauge_orbit(x)                                 # ξ_g
    report = {}
    for name, h in safety_fns.items():
        g = grad(h, x)
        sens = norm(g @ orbit) / (norm(g) + 1e-12)         # ι_frame
        report[name] = (h(x), sens, sens <= TAU_FRAME)
    return Certificate(report, gauge_fix=gauge_fix,
                       iota_frame=max(r[1] for r in report.values()),
                       valid=all(r[2] for r in report.values()))

# IP-297 CNE：认证可导航包络（空间证书前缀 + 前向不变）
def certified_navigable_envelope(x, safety_fns, Sigma_nav, h_min, grid):
    cne = []
    for p in grid.reachable(x.pose):
        margins = [h(p) for h in safety_fns.values()]
        grads   = [grad(h, p) for h in safety_fns.values()]
        u_rel   = max(math.sqrt(g.T @ Sigma_nav @ g) for g in grads)
        if min(margins) - KAPPA * u_rel >= h_min:
            cne.append(p)
    return Envelope(cne, forward_invariant=check_cbf_invariance(cne, safety_fns, Sigma_nav))

# IP-298 NSUB：导航不确定度账本 + 安全相关投影
def nav_uncertainty_projection(Sigma_nav, active_constraints, x):
    u_full = math.sqrt(Sigma_nav.odom + Sigma_nav.map + Sigma_nav.loc
                       + Sigma_nav.dyn + Sigma_nav.frame)
    u_rel = max(math.sqrt(grad(h, x).T @ Sigma_nav.P @ grad(h, x))
                for h in active_constraints)
    return u_full, u_rel          # 账本用 u_full，λ 只用 u_rel

# IP-299 LFI：定位故障隔离与检疫
class LocalizationFaultIsolator:
    def monitor(self, pose_post, loop_residual, obs):
        multimodal = pose_post.n_modes > 1 and pose_post.mode_gap < TAU_GAP
        jump       = pose_dist(pose_post.mode, self.last_mode) > TAU_JUMP
        kidnap     = self.detector.kidnapped(obs)
        if multimodal or jump or kidnap:
            self.sia.quarantine(['global', 'map'])
            self.reanchor_local(pose_post.nearest_trusted_anchor)
            return Mode.LOCAL_ONLY
        return Mode.FULL

# IP-300 I-NVOI：隔离感知导航 VoI
def isolation_aware_nav_voi(cells, budget, cne, candidates):
    best = None
    for g in candidates:
        path = plan(g)
        if not cne.contains(path) or not budget.allow(g): continue
        ig_map = info_gain(cells['map'], g); ig_loc = info_gain(cells['local'], g)
        ig_int = ETA * info_gain(cells['intent'], g)
        cost   = move_cost(g) + reflex_cost(cells, g) + RHO * debt_rate(cells['local'])
        score  = ALPHA*ig_map + BETA*ig_loc + ig_int - cost \
                 - GAMMA * expected_loss_outside_cne(g, cells)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-301 N-RISK：导航风险缩放
def nav_risk_scale(U_ale, U_epi, H_z, u_tac, u_nav_rel, params):
    denom = U_ale + U_epi + H_z + u_tac + u_nav_rel
    lam   = params.lam_base * (1 + denom / params.lam_scale)
    return max(lam, params.lam_floor * (1 + denom))

# IP-302 SIGN-GAUGE 主闭环（全局域异步；控制域只读隔离视图；CNE 门控）
def SIGN_GAUGE_RAS_round(M, obs, audio, tac_frame, nav_state):
    # ===== 全局导航域（1-10Hz，隔离 cell，绝不在控制关键路径） =====
    if M.clock.due_global():
        mode = M.lfi.monitor(nav_state.pose, nav_state.loop_residual, obs)
        if mode == Mode.LOCAL_ONLY: M.mode_global = Mode.LOCAL_ONLY
        if nav_state.loop_delta is not None:
            M.sia.merge('global', 'local', nav_state.loop_delta)
        M.snapshot.write_global(M.sia.cells['global'], M.sia.cells['map'])
    # ===== 控制域（1kHz，硬实时，只读经膜审计的局部视图） =====
    local = M.sia.read('local', 'ctrl')
    b_t   = M.bse.step_ctrl(local.b_prev, obs, M.last_action, M.last_g, M.last_y)
    U_ale, U_epi = decompose_ctrl(b_t, M.fmp, obs)
    H_z   = local.z_dist.entropy() if local.z_dist else 0.0
    u_tac = local.tac_ev.u_tac if local.tac_ev else 0.0
    u_rel = nav_uncertainty_projection(local.Sigma_nav, M.cne.active_constraints, local.x)
    lam   = nav_risk_scale(U_ale, U_epi, H_z, u_tac, u_rel, M.risk_params)
    A = M.ach.propose_ctrl(...); k = M.c_ras_wm.certified_prefix(A, lam, ...)
    if not M.cne.contains(M.next_pose(k)):
        k = M.cne.backoff_prefix(k)          # 出包络 ⇒ 回退到包络内前缀
    M.ctrl_out.publish(k, lam)
    M.cert_ctrl.write(k=k, lam=lam, u_nav_rel=u_rel, wcet=M.rtm.wcet_us())
    # ===== 计量域（50Hz，软实时，写快照） =====
    if M.clock.due_metric():
        b_t_full = M.bse.step_full(local.b_prev, obs, M.last_action, M.last_g, M.last_y)
        z_dist, ece_z, iota_z = M.irl.update(M.y_intent_buf, M.psi_hat, b_t_full)
        gate = M.e_ivg.check(M.registry, b_t_full, z_dist, M.tac_ev, M.seal.latest)
        if not gate.valid: M.mode = gate.fallback
        M.snapshot.write(b_t_full, z_dist, gate, M.psi_hat, M.tac_ev, local)
    # ===== 感知域（异步，Best-effort） =====
    psi_hat, ece_aff = M.aura.update(audio)
    if ece_aff > TAU_AFF: M.psi_hat = None
    tac_ev = M.dmem.update(tac_frame, M.last_action)
    if tac_ev.u_tac > TAU_U_TAC: M.tac_ev = None
    # ===== 导航决策（事件触发） =====
    if M.mode_global == Mode.FULL and (local.z_dist.entropy() > TAU_HZ
                                       or M.cne.shrink_ratio > TAU_SHRINK):
        g = M.invoi.choose(M.sia, M.budget, M.cne, M.candidates)
        if g: M.execute_nav(g)
    return k, lam, J_NAV(M)

# IP-303 ReAuditMembrane：回环跨尺度重审
class ReAuditMembrane:
    def __init__(self, budget): self.budget = budget
    def propagate(self, local_cell, delta):
        if cov_norm(delta.cov) > self.budget or not audit_loop(delta):
            local_cell.posterior.invalidate("loop_closure_exceeds_budget")
            return local_cell.posterior.reestimate()   # 重估，而非打补丁
        return local_cell.posterior.update(delta, tchain=hash(delta))
```

## 4. 推导

**引理 33（膜泄漏有界 ⇒ 下游证书扰动有界）** 膜 e=(i→j) 泄漏预算 ℓ_e、下游证书 J_j 对注入状态 L_j-Lipschitz ⇒ `|ΔJ_j| ≤ L_j·ℓ_e`，与上游故障严重程度无关。系：**爆炸半径 ≤ L_j·ℓ_e，这就是「隔离」的可证明含义。**

**引理 34（规范不变 ⇒ 不可观测方向零贡献）** h 为 G-不变 ⇒ ∇h·ξ_g=0 ⇒ 方向投影 `∇h^T Σ ∇h` 不感知规范方向方差。系：**地图整体平移/旋转的不确定度物理无害，不该冻结机器人。**

**引理 35（方向投影的保守性与紧致性）** 安全边际一阶展开 ⇒ `P(m<0) ≤ Φ(−m/sqrt(∇h^T Σ ∇h))`；取最危险约束方向得保守上界；`tr(Σ)` 会高估无害方向、低估危险方向。系：**「越沿危险方向越危险」是风险上界的正确变量。**

**引理 36（检疫期安全单调）** 检疫只移除信息（全局/地图只读、不参与证书），由隔离性下游不读被检疫单元 ⇒ `Risk_after ≤ Risk_before`。系：**「不知道」永远比「错误地知道」安全。**

**引理 37（导航反作用预算有限停止）** 加入 L4 后总成本 `Σ(c^ψ+c^z+c^c+c^nav)`，隔离债每步正漂移下界、信息增益随覆盖饱和边际递减 ⇒ 存在有限 n*，第 n*+1 步边际净收益 ≤0，I-NVOI 停止。

**定理 27（状态隔离 ⇒ 爆炸半径受限）** 在定义 367、引理 33 下，单一单元任意腐败（含全局地图完全投毒）对控制/接触证书扰动 ≤ 最短膜路径 Lipschitz 乘积 `∏L_e·ℓ_e`；若 ≤ε_safe 则**控制层不产生安全违规**。**导航层被完全攻陷，局部安全仍成立——隔离即安全边界。**

**定理 28（规范不变的导航安全）** 全部 h_k 与证书 G-不变 ⇒ CNE、λ、J_NAV 在任意 gauge fix 下取值相同；回环重参数化（G 作用）不改变认证安全，只改地图坐标表示。**换个原点/转个朝向，安全结论必须一模一样。**

**定理 29（严格空间包含与风险单调）** 在 A111–A116（膜预算有界、ι_frame 有效、CNE 前向不变、NSUB 链完整、LFI 可检出、L4 Lipschitz）下：SIGN-GAUGE 按定义 377 逐指令等于 LOCAL_ONLY/R72/R68；任意有效执行风险界 ≤ R72 ≤ R71。**安全单调不减；效率仅在全局可信、局部可认证、规范可审计时获益。**

**定理 30（CNE 保守前向不变性）** 若 λ 用 NSUB 保守上界（最危险方向 + 分位数）且计划满足 CBF 型 `ḣ_k+α(h_k)≥0`，则从 p₀∈CNE 出发、执行 π⊆CNE 的轨迹恒有 λ≤λ_max。**认证包络是前向不变集，不是一次性检查。**

**定理 31（探索不牺牲硬安全）** I-NVOI 仅在 π_g⊆CNE 且四层预算未超时接受移动；CNE 保证最坏情况安全边际 ≥h_min。故主动 SLAM 不降低硬安全下界，只消耗效率/时间/隔离债。**探索是安全的，但可能很贵——所以它该被建模成投资。**

## 7. 本轮最大风险

**一句话**：SIGN-GAUGE-RAS 把安全从「相信具身测量链」进一步转移到「相信**状态隔离膜真的不可穿透**、相信**规范不变性检查覆盖了所有真正进入安全判断的量**、相信**CNE 在分布外仍是保守前向不变集**」——**如果某个安全函数看似规范不变、实则通过一个隐蔽的绝对坐标通道（绝对航点、地图原点绑定的语义标签、未声明的尺度规范）悄悄依赖了 gauge fix，那么 ι_frame 会漏报，证书会在一张被平移/旋转/投毒的地图上「规范不变地」给出错误的安全结论；或者某条膜因实现细节（共享指针、缓存快照、异常路径）发生未审计写，导致全局地图污染绕过隔离直达控制层；或者 CNE 在动态障碍/传感器退化下失去前向不变性，机器人会「拿着通过所有检查的证书」走进一个当时看起来安全、实则已出界的区域——这就是自主导航层面的「自信地错自己的参考系」。**

次级风险与缓解：
1. **隐蔽规范依赖** → 对进入安全判断的量做**符号-数值双重规范审计**（自动微分检查 ∇h⊥ξ_g + 随机规范扰动回归），未声明依赖即拒绝签发 J_NAV。
2. **膜被实现细节击穿** → 膜只暴露**不可变快照**（copy-on-write + 版本号 + 无指针逃逸），跨单元访问全经 SIA API；E389 红队常态化；类型系统/所有权检查静态阻断。
3. **CNE 失去前向不变** → 在线 **CBF 残差监控**，每周期检查 `ḣ+α(h)≥0`，违反即收缩包络降速；用分位数上界而非均值。
4. **检疫抖动** → 检疫加**滞回 + 冷却期 + 隔离债门控**，避免边界反复横跳。
5. **多假设爆炸** → 假设数上限 m≤8，按 CNE 体积/似然剪枝，保留「两两都安全」的交集包络。
6. **隔离导致信息僵化** → **受控 merge + 隔离债偿还计划**显式放行低风险全局信息；把隔离强度作为 Pareto 参数（E398）。
7. **复杂度/实时性** → 全局域彻底异步可丢帧；控制域只做 O(1) 投影与包络内回退；重活（CNE/回环/多假设）全在导航域批处理。
