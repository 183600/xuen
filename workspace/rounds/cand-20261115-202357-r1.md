# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环第 3 轮；本轮灵感：「避障控制」×「机器人操作系统」）

> R69 教会闭环「提问」：把不确定性拆成 aleatoric / epistemic，用流匹配的多模态动作与主动交互去消解后者。但 R69 把全部效率收益押在一个它自己都不放心的前提上——**流模型的模态分布可信**。它自陈的最大风险正是「问错，比不问更危险」：幻影模态让系统追问一个不存在的东西，投毒回答被盖上「已验证」的章。更深一层，R69 的「k 个正交证据源一致」隐含了一个不真实的图景：证据源是可识别、可同时取到的单体对象。真实的机器人不是单体，而是一张**分布式操作系统图**——感知、定位、规划、避障是不同节点，每条消息有自己的**血缘、时延、覆盖范围、版本**。于是「这条证据可信吗」这个问题，证据本身回答不了；能回答它的是证据**走过的路径**。
>
> 本轮两个灵感正好补两块缺失：
> - **避障控制**给出一个**不会撒谎的几何证人**：CBF/QP 的可行集由原始几何算出，而不是由学习策略算出；把策略的名义动作投影到可行集，安全就与「模态是否可信」解耦。
> - **机器人操作系统**给出**血缘与契约**：消息是一等公民，带截止期、新鲜度、覆盖域、信任类与溯源哈希；信任沿路径单调衰减，下游无法「洗白」上游的污染。
>
> 核心命题：**把安全从学习层里拿出来，交给一个可验证的、模型驱动的几何内核；把信任从「源的性质」改成「路径的合取」。策略只负责提议（propose），几何负责裁决（dispose）；当血缘断裂、数据过期、覆盖不足时，系统沿一条单调的降级阶梯退到最后一个被认证的几何包络——而不是像 R69 那样继续相信一个可能已经错了的模态分布。** 命名 **NOTARY-RAS**（Node-level Obstacle-aware Trust Audit & Routing of uncertaintY）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这个答案在我即将行动的地方还成立吗，谁能证明它没有过期、没有越界、没有被人换掉**」——信任不是某个节点的属性，而是整条证据链的合取。

## 0. 直觉与动机

**灵感 1（避障控制 → 几何是唯一不会撒谎的证人）**
直觉：R69 的安全仍由学习策略的模态经 λ 缩放后来保证——如果模态分布本身错了，缩放只是在错误方向上更慢。避障控制提供了一条完全不同的路：CBF/QP 的可行集由当前障碍几何与动力学直接算出，是**模型驱动、可验证**的；把策略给出的名义动作投影到可行集，得到的是「在几何上不会撞」的动作，无论策略怎么想。安全因此与「模态可信吗」解耦。学习负责**效率**，几何负责**安全**——「learning proposes, geometry disposes」。投影残差 r_proj = ‖a_nom − Π_F(a_nom)‖ 还是一个全新的独立观测：策略自信（r_res 低、Δa 低）却指向不可行方向，正是「自信地瞎了」的签名。

**灵感 2（机器人操作系统 → 信任是路径的合取）**
直觉：R69 的「k 个正交证据源」假设源是可识别、同时可得的单体。真实系统是 ROS 图：感知、定位、融合、避障是不同节点，消息经 topic 流动，可能延迟、丢帧、重放、被旧标定污染。一条在源头正确的消息，与一条过期的定位融合后，在消费者处就是错的。所以信任不能只是源的性质，必须是**整条血缘路径的合取（meet）**：任何一个上游环节失效，下游全部失效，且下游无法用自己的计算把上游「洗白」。这把 R68/R69 的「测量是否准」提升为「**这条测量从哪来、经过谁、是否还在保质期内、覆盖到我将要去的地方吗**」。

**灵感 3（覆盖缺口 → 策略看不见的 epistemic）**
直觉：R69 的 U_epi 来自策略的模态熵——但策略无法对「它从未看见的障碍」产生模态。避障语境里最危险的不知道是**盲区**：传感器覆盖不到的区域，存在一个与所有观测一致、却会导致碰撞的障碍构型。这不是动作歧义，而是世界模型的缺口。处理只有两条路：要么在盲区内按最坏占据做保守（限速/停车），要么派一个信息动作去看（R69 的 gaze）。于是 R69 的主动交互从「可选优化」变成「几何可信的前置条件」：**没有足够覆盖，就没有可信的几何证人**。

**灵感 4（信任域 → 最小可信基）**
直觉：如果安全依赖学习策略，那安全就继承了学习策略的全部攻击面（幻觉、投毒、分布外）。OS 的正常做法是划分信任域：一个极小的 TCB（几何避障核 + 公证器 + 单调时钟）负责「裁决」，一个庞大的非可信插件层（学习策略、LLM、ML 感知）只负责「提议」。任何来自非可信域的消息只能进入「提名」通道，不能直接进入执行通道。这是 R69「安全侧永不让步」在系统架构层的对应物——不是靠一个更大的模型来保证，而是靠一个更小的、可验证的内核。

**灵感 5（新威胁 → 消息层攻击）**
直觉：R69 防的是「人会撒谎」。一旦引入 OS 与血缘，攻击面上移一层：重放一条昨天真实、今天致命的消息；伪造溯源哈希；用时钟偏移让过期消息看起来新鲜；冒充节点；甚至**谎报覆盖**（声称盲区已被看见）。这些攻击的共同点是：它们不改变任何单条消息的「内容合理性」，只改变消息的「身份、时序、范围」。所以 R69 的似然/证据一致性完全挡不住它们——必须由公证器在消息层用签名、单调计数器、TCB 时钟与多传感器覆盖交叉验证来挡。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（NOTARY-RAS 总览）** NOTARY-RAS = (SCG, PROV, GSK, PRA, BSW, NTR, TCB, DGL, RAS-WM†)。四条不变量：
(i) **安全去耦**：执行动作必须属于几何证人认证的可行集，与学习策略的模态可信度无关；
(ii) **信任单调**：沿任何血缘路径，信任不增；下游不得把上游的信任类抬高（不可洗白）；
(iii) **覆盖前提**：几何可行集仅在停止可达集被传感器覆盖（或按最坏占据处理）时 sound；否则必须降级（限速/停车）；
(iv) **单向降级**：信任谓词变假时允许动作集只缩不胀；重新升级需重新认证 + 驻留时间 τ_d。

**定义 311（安全契约 SC）** 每条总线消息 m 携带契约 SC(m) = (src, parents_hash, sig, cnt, t_tcb, horizon, coverage, calib_ver, trust_class)。Valid_SC(m, t) ⇔ SigOK(m) ∧ cnt(m) > last_cnt(src) ∧ (t − t_tcb(m)) ≤ horizon(m) ∧ CoverageSuffices(m, query_region) ∧ CalibOK(m)。trust_class ∈ {T0: TCB 可验证, T1: 模型验证, T2: 学习/数据驱动} 为全序。

**定义 312（溯源 DAG 与信任 meet）** 消息集合配父指针 par(·) 构成有向无环图 𝒢_prov。定义 Trust(m) = min{ class(src(m)), min_{p ∈ par(m)} Trust(p) }，以及 Valid_prov(m,t) = Valid_SC(m,t) ∧ ∧_{p∈par(m)} Valid_prov(p,t)。信任是 meet（幂等、交换、结合），因而沿路径单调不增；上游失效沿 DAG 向下传播且不可逆。

**定义 313（几何安全核 GSK）** 安全集 𝒞 = {x : h_i(x) ≥ 0, i=1..n_c}，动力学 x_{k+1} = f(x_k, a)。由**原始几何**（不经过学习策略）构造离散 CBF 约束 h_i(f(x,a)) ≥ (1−γ_i) h_i(x)。可行集 F(x) = {a ∈ 𝒰 : 全部 CBF 成立}。名义动作 a_nom 的执行动作 a* = Π_F(a_nom) = argmin_{a∈F} ‖a − a_nom‖²（QP）。若 F = ∅，执行认证刹车 a_stop ∈ 𝒰 ∩ Safe。

**定义 314（投影残差与三通道一致性）** r_proj = ‖a_nom − a*‖（F 空时取 +∞ 并置 feasible=False）。三通道证据 ρ = (r_res, Δa, r_proj) 分别测「传感器自洽」「行为自洽」「几何自洽」。判别模式：
- 缓变故障：r_res↓, Δa↑（R69 定义 309）；
- **自信地瞎了**：r_res↓, Δa↓, r_proj↑（策略与似然都自信，但几何否决）；
- **过期几何**：r_proj↓ 但契约不 Valid（几何证人本身用了旧地图）。

**定义 315（覆盖场与盲区）** C_obs(x) = ∪_j Footprint_j(x) 为当前传感器覆盖区域。盲区 B(x,v) = WorkSpace \ C_obs(x) 中与停止可达集相交的部分。覆盖缺口是**关于世界的 epistemic**，不来自策略模态，故 R69 的 H_mode 无法表示它。

**定义 316（几何 soundness 条件 A100）** 令 ρ_stop(v) = v·τ_react + v²/(2 a_max)，d_clear(x) = dist(x, ∂C_obs)。A100：B(x,v) ∩ Ball(x, ρ_stop(v)) = ∅，或盲区按最坏占据处理。等价地：**速度不得超过感知地平线**。只有 A100 成立时，由观测障碍构造的 F 才是真实安全集的可靠外近似。

**定义 317（公证器 NTR 与证书合成）** NTR 对每条消息检查签名、单调计数器（防重放/冒充）、TCB 单调时钟（防时钟偏移）、覆盖交叉验证（防谎报覆盖），输出 Valid_prov。分布式证书 J 沿 𝒢_prov 合成：J_node = ∧ J_parent ∧ J_local，任一父节点失效则该子树全部失效。无需中央信任锚，但需要每节点一个 TCB 根。

**定义 318（信任域与最小可信基 TCB）** TCB = {GSK, NTR, 单调时钟} 为形式化验证/运行时监控的最小集合；其余 {FMP, AUD, MINT, CIA, LLM} 为非可信插件层。跨域规则：**非可信域只能写提议通道，不能写执行通道**；TCB 对提议做投影与契约检查后才允许执行。

**定义 319（QoS 契约语义）** 每条消息带 (deadline, horizon, coverage, priority)。超 deadline 或超 horizon 的消息 Valid=False，**不参与裁决**（不是降权，而是失效）；关键消息（定位、避障地图）失效直接触发降级。这与 ROS2 QoS 的 reliability/durability/deadline 语义对齐。

**定义 320（盲区感知的信息动作）** 将 R69 的 MINT 从「模态熵」重定向到「盲区占据熵」：VoI_cover(g) = H(occ(B)) − E_{y~p(·|g)}[H(occ(B)|y)]。g ∈ {g_gaze, g_probe}（不含问句时延过大的场景）。仅当 VoI_cover(g) > c(g) 且 g 过 C-RAS-WM 认证时执行；执行只改变覆盖与后验，不改变当前执行通道。

**定义 321（消息层攻击集 ℰ_msg）** ℰ_msg = {replay（旧真实消息重放）, spoof（节点冒充）, forge（溯源/签名伪造）, skew（时钟偏移击败新鲜度）, overclaim（谎报覆盖域）}。并入 AIC：ℰ_NOTARY = ℰ_FLUID × ℰ_msg。它们不改变单条消息内容合理性，只改变身份/时序/范围，故内容级似然检验无效。

**定义 322（降级阶梯 DGL）** 按信任谓词与几何状态分级：
- L0：契约全 Valid ∧ A100 成立 ∧ feasible → NOTARY 全功能（R69 交互可用）；
- L1：存在可约 epistemic/覆盖缺口 → 允许信息动作缩盲区，执行仍走 GSK；
- L2：非安全关键输入失效/低信任 → 冻结该输入，改用冗余源或保守先验；
- L3：安全关键契约失效（定位过期、避障地图不 sound）→ 退到最后一个被认证包络 + 限速/停车；
- L4：TCB 自身不可信（时钟/公证器失配）→ 安全停车并报警，放弃保证。
允许动作集嵌套：𝒜_{L4} ⊆ 𝒜_{L3} ⊆ 𝒜_{L2} ⊆ 𝒜_{L1} ⊆ 𝒜_{L0}。

**定义 323（证书 J_NOTARY）** J_NOTARY = (J_FLUID, prov_root, per_node_contract_hashes, coverage_ratio, r_proj_p95, dgl_level, notary_ver)。Valid ⇔ Valid(J_FLUID) ∧ Valid_prov(root) ∧ coverage_ratio ≥ ρ_min ∧ r_proj_p95 ≤ τ_proj ∧ level ≤ L2。

**定义 324（契约感知风险缩放）** λ_total = λ_floor(U_ale + 未消解 U_epi) · κ(level)，其中 κ(L0)=1，κ 随级别单调不减且 ≤ κ_max；且执行动作先投影后缩放：a_exec = Π_F(a_nom) 再按 κ 施加速度上限。**投影不是可选后处理，而是执行通道的前置条件**。

**定义 325（R69 严格包含条件）** 当 𝒢_prov 退化为单信任域、所有 horizon = ∞ 且无 ℰ_msg、C_obs = WorkSpace（全coverage）、F 非约束（a_nom ∈ F）时，NOTARY 与 FLUID-RAS 逐指令相同。故 R69 = NOTARY 在「无 OS、无几何、全知」边界上的退化。

## 2. 关键算法骨架

```python
# IP-264/265 SCG + PROV：契约解析与血缘信任（信任 = 路径合取）
def trust_valid(m, now):
    if not sig_ok(m) or m.cnt <= last_cnt[m.src]: return False       # 冒充/重放
    if now - m.t_tcb > m.horizon:                 return False       # 过期/时钟偏移
    if not coverage_suffices(m.coverage, m.region): return False     # 覆盖谎报
    return all(trust_valid(p, now) for p in parents(m))              # 不可洗白

# IP-266/267 GSK + PRA：几何证人裁决（可行集只由原始几何构造）
def geometric_arbitrate(a_nom, x):
    cons = build_cbf_constraints(x)              # h_i, gamma_i，不经过学习策略
    a, ok = solve_qp(min_norm(a - a_nom), cons, a in U)
    if not ok:                                   # QP 不可行 → 认证刹车
        return certified_stop(x), INF, False
    return a, norm(a - a_nom), True              # r_proj = 几何否决量

# IP-268 BSW：覆盖 soundness（速度不得超过感知地平线）
def coverage_sound(x, v):
    rho = v * tau_react + v * v / (2 * a_max)
    return not intersects(blind_set(x), ball(x, rho))  # A100
def max_safe_speed(x):
    return solve_rho(v) == d_clear(x)            # rho(v) = d_clear 的根

# IP-272 DGL：单向降级阶梯
def degrade(prov_ok, cover_ok, flags, feasible):
    if not tcb_ok():                          return L4
    if not prov_ok or not cover_ok:           return L3
    if flags.confident_blind or not feasible: return L2
    if flags.any_epistemic:                   return L1
    return L0
def admissible(level, a_safe):
    return NESTED[level](a_safe)                 # A_L4 ⊆ ... ⊆ A_L0

# IP-275 主闭环：契约公证 → R69 提议 → 几何裁决 → 三通道 → 降级 → 审计
def NOTARY_round(M, obs):
    msgs = M.bus.drain()
    prov_ok  = all(trust_valid(m, M.tcb.now()) for m in msgs)
    cover_ok = coverage_sound(obs.x, obs.v)
    # 1) 学习层照常提议（R69），但只在提议通道
    z = M.mtm.forward(obs)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(obs, K), z)
    a_nom = select_mode(modes, U_epi).a
    # 2) 几何证人无条件裁决（不信任模态）
    a_safe, r_proj, feasible = geometric_arbitrate(a_nom, obs.x)
    # 3) 三通道：残差 / 流似然 / 几何
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, obs.raw, obs.cal)
    flags = three_channel(M.last_r_res, a_hat, r_proj)
    # 4) 盲区 → 信息动作（VoI 作用于占据熵，而非模态熵）
    if not cover_ok and M.mint.voi_cover(obs) > M.mint.cost(obs):
        g = M.bsw.choose_look(obs)
        if M.c_ras_wm.certify_info(g, obs): M.cia.execute(g)
    # 5) 降级阶梯 + 契约感知缩放
    level = degrade(prov_ok, cover_ok, flags, feasible)
    adm   = admissible(level, a_safe)
    lam   = M.efs.lambda_from_modes(modes, U_ale) * kappa(level)
    tau   = M.pi_sigma.prefix_dispatch(adm) * lam
    # 6) 审计 + 证书（证书沿血缘合成）
    M.vqa_n.submit_async(msgs, prov_ok, level, r_proj, a_hat)
    return adm, level, M.ntr.stamp(msgs, level, r_proj)
```

## 3. 推导

**引理 19（几何安全与模型去耦）** 设 Safe(x) = {a : f(x,a) ∈ 𝒞}，F(x) ⊆ Safe(x)，执行 a ∈ F(x)。则下一步状态必在 𝒞 内，**与 π_θ 的模态分布是否正确无关**。故 R69 的安全性依赖 P(模态正确)，而 NOTARY 的安全性只依赖 F 的 soundness——这是一个**假设的交换**，不是无条件的胜利：风险从「策略可能错」搬到「几何证人可能不 sound」。

**引理 20（投影残差的判别性）** 设信念障碍集 Ô 与真实 O 的 Hausdorff 距离为 δ，a_nom 的轨迹到 𝒞 边界的裕度为 ρ。若 a_nom ∈ F(Ô) 但 a_nom ∉ F(O)，则 r_proj ≥ ρ。注意 r_res 与 Δa 分别由传感器残差与策略密度计算：当传感器确实看见障碍、但策略模态校准错误时，r_res ≈ 0、Δa ≈ 0，而 r_proj > 0。因此 r_proj 能检出 R69 两条通道都看不见的「自信地瞎了」。反面：若几何本身过期（r_proj 低而真实危险高），说明问题在契约而非策略——正指向本轮最大风险。

**引理 21（信任不可洗白）** 由 Trust(m) = min{class(src), min_p Trust(p)} 与 Valid_prov 的合取定义，沿任意路径 Trust 单调不增，且任一祖先 Valid=False 使全部后代 Valid=False；节点本地计算无法把输出信任抬到输入最小值之上。故只篡改「身份/时序/范围」的重放、冒充、伪造、时钟偏移、谎报覆盖，都会在路径层被截断，而不依赖内容合理性。

**引理 22（盲区保守界与可约性）** 若 B(x,v) ∩ Ball(x, ρ_stop(v)) ≠ ∅ 且盲区不按占据处理，则任何仅基于观测障碍的 CBF 都不 sound。恢复 soundness 的两种方式：(i) 限速 v ≤ v_max 使 ρ_stop(v_max) = d_clear(x)；(ii) 把 B 视为占据。系：覆盖缺口是关于世界的 epistemic，R69 的信息动作可降低占据熵，VoI_cover(g) = H(occ(B)) − E[H(occ(B)|y_g)]——这把 R69 的 MINT 接到避障的可感知性上。

**定理 18（NOTARY 严格包含 R69）** 在定义 325 的退化条件下，NOTARY 与 FLUID-RAS 逐指令相同；一般情形下，NOTARY 的执行动作落入 R69 动作集与 F 的交集，故在 F sound 时安全侧不弱于 R69，且因 r_proj 与血缘检查获得 R69 不具备的几何/系统层防护。R69 = 「无 OS、无几何、全知」边界。

**定理 19（降级单调与无突变）** 由定义 322 的嵌套 𝒜_{L4} ⊆ … ⊆ 𝒜_{L0}，信任谓词变假只触发向更低级别的转移，允许动作集只缩不胀；升级需重新认证 + 驻留 τ_d，故不会产生极限环/chattering。GSK 的投影保证切换期间执行动作始终在 F 内，故无越界突变；R68 的提交/换装不变式（定理 15）作为 L3 的特例保持。

# IP-264/265 SCG + PROV：契约与血缘信任（信任 = 路径合取，不可洗白）
def trust_valid(m, now):
    if not sig_ok(m) or m.cnt <= last_cnt[m.src]:            return False  # 冒充/重放
    if now - m.t_tcb > m.horizon:                            return False  # 过期/时钟偏移
    if not coverage_suffices(m.coverage, m.region):          return False  # 谎报覆盖
    return all(trust_valid(p, now) for p in parents(m))                   # 不可洗白

# IP-266/267 GSK + PRA：几何证人无条件裁决（不信任模态）
def geometric_arbitrate(a_nom, x):
    cons = build_cbf_constraints(x)                # 只由原始几何，不经过学习策略
    a, ok = solve_qp(min_norm(a - a_nom), cons, a in U)
    if not ok:                                     # QP 不可行 → 认证刹车
        return certified_stop(x), INF, False
    return a, norm(a - a_nom), True                # r_proj = 几何否决量

# IP-268 BSW：覆盖 soundness / 速度上限
def coverage_sound(x, v):
    rho = v * tau_react + v * v / (2 * a_max)
    return not intersects(blind_set(x), ball(x, rho))   # A100
def max_safe_speed(x):
    return solve(v for v in (0, v_max) if rho(v) == d_clear(x))

# IP-272 DGL：单向降级阶梯（动作集嵌套）
def degrade(prov_ok, cover_ok, flags, feasible):
    if not tcb_ok():                          return L4
    if not prov_ok or not cover_ok:           return L3
    if flags.confident_blind or not feasible: return L2
    if flags.any_epistemic:                   return L1
    return L0
def admissible(level, a_safe):
    return NESTED[level](a_safe)               # A_L4 ⊆ ... ⊆ A_L0

# IP-275 主闭环：公证 → R69 提议 → 几何裁决 → 三通道 → 降级 → 审计
def NOTARY_round(M, obs):
    msgs = M.bus.drain()
    prov_ok  = all(trust_valid(m, M.tcb.now()) for m in msgs)
    cover_ok = coverage_sound(obs.x, obs.v)
    # 1) 学习层只提议（R69）
    z = M.mtm.forward(obs)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(obs, K), z)
    a_nom = select_mode(modes, U_epi).a
    # 2) 几何证人无条件裁决
    a_safe, r_proj, feasible = geometric_arbitrate(a_nom, obs.x)
    # 3) 三通道：残差 / 流似然 / 几何
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, obs.raw, obs.cal)
    flags = three_channel(M.last_r_res, a_hat, r_proj)
    # 4) 盲区 → 信息动作（VoI 作用于占据熵而非模态熵）
    if not cover_ok and M.mint.voi_cover(obs) > M.mint.cost(obs):
        g = M.bsw.choose_look(obs)
        if M.c_ras_wm.certify_info(g, obs): M.cia.execute(g)
    # 5) 降级 + 契约感知缩放（先投影后缩放）
    level = degrade(prov_ok, cover_ok, flags, feasible)

    lam   = M.efs.lambda_from_modes(modes, U_ale) * kappa(level)
    tau   = M.pi_sigma.prefix_dispatch(adm) * lam
    # 6) 审计 + 证书（沿血缘合成）
    M.vqa_n.submit_async(msgs, prov_ok, level, r_proj, a_hat)
    return adm, level, M.ntr.stamp(msgs, level, r_proj)

## 4. 推导

**引理 19（几何安全与模型去耦）** 若 `F(x) ⊆ Safe(x)` 且执行 `a ∈ F(x)`，则下一步必在安全集 `𝒞` 内，与 `π_θ` 的模态分布是否正确无关。系：R69 的安全性依赖 P(模态正确)，NOTARY 只依赖 `F` soundness——这是**假设交换**而非无条件胜利。

**引理 20（投影残差判别性）** 若 `a_nom ∈ F(Ô)` 但 `a_nom ∉ F(O)`，则 `r_proj ≥ ρ`（轨迹到边界裕度）。当传感器看见障碍而策略模态校准错误时，`r_res≈0, Δa≈0, r_proj>0`，故 `r_proj` 检出 R69 两条通道都看不见的「自信地瞎了」；反之 `r_proj` 低而真实危险高说明契约/几何过期，指向最大风险。

**引理 21（信任不可洗白）** 由 `Trust=min{class(src),min_p Trust(p)}` 与 `Valid_prov` 的合取定义，信任沿路径单调不增；任一祖先失效使全部后代失效；本地计算无法把输出信任抬到输入最小值之上。故重放/冒充/伪造/时钟偏移/谎报覆盖在路径层被截断。

**引理 22（盲区保守界与可约性）** 若 `B(x,v)` 与 `Ball(x,ρ_stop(v))` 相交且盲区不按占据处理，则仅基于观测障碍的 CBF 不 sound。恢复 soundness：限速使 `ρ_stop(v_max)=d_clear`，或视 B 为占据。系：`VoI_cover(g)=H(occ(B))−E[H(occ(B)|y_g)]`，把 R69 的 MINT 接到可感知性上。

**定理 18（NOTARY 严格包含 R69）** 在单信任域、无 `ℰ_msg`、`horizon=∞`、全coverage、`F` 非约束的退化条件下，NOTARY 与 FLUID-RAS 逐指令相同；一般情形执行动作落在 R69 动作集与 `F` 之交，故 `F` sound 时安全侧不弱于 R69，并获得几何/系统层的新防护。R69 =「无 OS、无几何、全知」边界。

**定理 19（降级单调与无突变）** 嵌套动作集 + 单向降级 ⇒ 允许动作集只缩不胀；升级需重新认证 + 驻留 `τ_d` ⇒ 无极限环/chattering；GSK 投影保证切换期间动作始终在 `F` 内 ⇒ 无越界突变；R68 提交/换装不变式作为 L3 特例保持。

## 7. 本轮最大风险

**一句话**：NOTARY-RAS 把全部安全押在「几何证人永远说真话」上——**若避障核的可行集本身不 sound（动态障碍快于假设、几何感知有偏、覆盖被谎报、地图过期），这个被所有其他组件无条件服从的「可信内核」就成了单点谎言，而且比 R69 更危险：它让系统误以为自己已经不再依赖学习模型**。

**次级风险与缓解**：几何感知偏差/动态障碍（A100 + 最坏占据 + 速度障碍膨胀 + E301/E315）；公证器被攻破/时钟劫持（最小 TCB + 硬件单调时钟 + 多源交叉 + SROS2 加固 + E306/E307）；覆盖谎报（独立传感器交叉验证 + 覆盖域签名 + E308）；降级震荡（嵌套动作集 + 驻留 + 迟滞 + E309）；投影过保守致任务失败（把保守性显式化为 r_proj 与 κ，用 VoI_cover 主动缩盲区 + E305/E314）。
