# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；新灵感循环第 1 轮；本轮灵感：「智能体」×「失败恢复」）

> 第 54 轮把技能组合提升为「动作空间剖面 + 鲁棒性谱」双证书，并建立了云规划—边校验—反向解释—重剖分的闭环。但整条栈仍隐含三个强假设：执行体是**无状态、不犯错、失败即终止**的技能调用器；证书只回答「不失败的概率」；根因解释只定位到单技能。真实智能体是**有目标、有记忆、有自模型、会失败、可恢复**的持续存在。本轮把「智能体」与「失败恢复」提升为一等公民，核心矛盾：**H22**：现有 ρ/J 证书只保证「不失败」，没有刻画「失败之后能否回来、多久回来、代价多大」，一次失败即被判定死刑；**H23**：多智能体协同时失败沿交互图级联传播，而 Explain 只给单技能根因，缺少**跨智能体的反事实责任归因与恢复移交**。

## 0. 直觉与动机

**灵感 1（智能体 = 带自模型的持续控制体）**
直觉：把智能体想成一个「会照镜子」的控制系统：它不仅按 π 执行，还在信念 B 中维护「我以为我在哪、我还能做什么、我刚才是怎么错的」的自模型 M。失败恢复的第一步不是动，而是**意识到自己失败了**。因此失败检测与自模型校准是恢复的前置条件；没有可信自模型，恢复就是盲动。

**灵感 2（失败恢复 = 有截止时间的盆地回归）**
直觉：恢复不是「再试一次」的启发式，而是一个控制问题：失败把状态踢出安全集 `S_safe`；恢复策略 ψ 必须把状态在截止时间 `T_r` 内**拉回 `S_safe` 并留住**。定义**恢复盆地 `B_rec(ψ,T_r)`**：所有能被 ψ 在 `T_r` 内带回安全集的初始状态集合。若失败落点 `x_f` 不在盆地内，再聪明的恢复策略也回不来。这把「恢复」从经验变成可判定：**先问落点是否在盆地内，再谈策略好坏**。

**灵感 3（恢复会再失败 → 恢复模式马尔可夫链）**
直觉：retry、rollback、replan、degrade、handoff、abort 六种恢复模式本身可能失败，甚至制造新失败（回滚到被污染的快照、降级后能力不可逆收缩）。所以恢复是**恢复模式上的马尔可夫链**；要证书的不是单步成功率，而是**恢复闭包 `κ = P(到达安全吸收态 before abort)`**。这把第 53 轮的链式鲁棒性推广为「恢复链」。

**灵感 4（多智能体失败归因 = 反事实责任）**
直觉：多智能体里「谁该负责」不能靠日志先后。用结构因果模型 + 反事实：若把 `agent_i` 的行为强制设回正确值，失败是否消失？消失得越多，责任越大。得到责任向量 `β`（单纯形）。归因的真正价值在**决定谁来恢复、谁该被替换**：责任方执行自恢复，非责任方准备接管。

**灵感 5（元恢复 = 恢复的恢复 → 升级阶梯）**
直觉：如果一个智能体连「自己能不能恢复」都判断不了，就需要**元恢复**：本地恢复 E0 → 同伴接管 E1 → 云端重规划 E2 → 安全中止 E3。每级带延迟与副作用预算。元恢复选「满足截止时间的最低成本级别」，把第 54 轮的云边闭环升级为**智能体恢复闭环**。

**灵感 6（把智能体层叠加到金字塔）**
直觉：在第 54 轮动作-协同层 `𝔸` 之上加**智能体恢复层 `𝔸ℝ`**：`𝔸ℝ_0` 物理/资源极限，`𝔸ℝ_1` 单智能体失败谱与盆地，`𝔸ℝ_2` 恢复模式链，`𝔸ℝ_3` 多智能体归因与移交，`𝔸ℝ_4` 元恢复升级。跨层证书必须同时携带 `ρ、J、Φ、RC、β`——形成**动作-鲁棒-恢复三证书**。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（智能体模型）**
智能体 `Ag = (X, A, O, π, B, G, M, Ψ, S_safe)`：
- `X` 状态空间，`A` 动作空间（沿用第 54 轮 `A = A_c × A_e`），`O` 观测空间；
- `π : B × G → A` 名义策略，`B` 信念空间，`G` 目标/规范集；
- `M : H → (B̂, Ĉ)` 自模型：由历史 `H` 预测自身信念与能力 `Ĉ`；
- `Ψ` 恢复控制器族，`S_safe ⊆ X` 安全集。
*失败*定义为 `G` 的时序不变量被违反，或任务截止 `T_task` 被错过。

**定义 122（失败谱 Φ）**
失败类 `f ∈ 𝔉 = {perception, action, goal, coordination, resource}`。失败谱
```
Φ_Ag(f) = (δ_f, ρ_f, b_f, λ_f)
```
其中 `δ_f = P(alarm within τ_d | f)` 为可检测度；`ρ_f = P(reach S_safe within T_r | f, alarm)` 为原始可恢复度；`b_f` 为爆炸半径（受影响智能体/任务/状态的测度）；`λ_f` 为单位时间失败强度。Φ 是第 53 轮鲁棒性谱 `ρ` 的**智能体级对偶**：ρ 描述扰动下的性能保持，Φ 描述失败后的回返能力。

**定义 123（恢复盆地与恢复半径）**
对恢复策略 ψ 与截止 `T_r`：
```
B_rec(ψ,T_r) = { x∈X | ∃ξ under ψ: ξ(0)=x, ξ(t_reach)∈S_safe,
                 ∀t∈[t_reach,T_r], ξ(t)∈S_safe, t_reach ≤ T_r }
```
失败落点集 `X_f`。**恢复半径** `r_rec = inf_{x_f∈X_f} dist(x_f, X \ B_rec)`；鲁棒恢复要求 `r_rec ≥ r_min`。证书使用保守内近似 `B̂_rec`：要求 `P(B_rec ⊆ B̂_rec) ≥ 1-ε_B`（宁可低估盆地，不可高估）。

**定义 124（恢复证书 RC）**
```
RC_Ag = (Φ_Ag, B̂_rec, T_r, β_side, ε, evidence)
```
- `β_side` 副作用预算（不可逆动作数、能耗、数据损失上限）；
- `ε = {ε_f}` 每类失败的统计风险界；
- `evidence` = 失败注入日志 + 反事实重放 + 盆地边界样本。
**Sound 条件**：对每个已声明失败类 `f`，
```
P(recover ≤ T_r ∧ side_effect ≤ β_side | f) ≥ 1 - ε_f - P(x_f ∉ B_rec)
```

**定义 125（反事实失败责任 β）**
给定交互图 `G_Ag` 上的结构因果模型 `𝔐` 与已观测失败事件 `e`。But-for 责任
```
β_i^BF = max(0, P(e) - P(e | do(a_i := a_i^nominal)))
β_i = β_i^BF / Σ_j β_j^BF        (分母>0)
```
**归因模糊度** `α_amb = 1 - Σ_{i∈C} β_i`，`C` 为覆盖 80% 责任的 but-for 原因集；`α_amb` 高表示「无可归因主因」或「存在未建模共因」。

**定义 126（恢复模式链与恢复闭包）**
`G_R = (Modes, P_R)`，`Modes = {retry, rollback, replan, degrade, handoff, abort}`，`P_R` 为（可状态相关的）转移核，`m_safe`、`m_abort` 为吸收态。恢复闭包
```
κ = P(hit m_safe before m_abort) = e_entry^T (I - Q)^{-1} R_safe
```
其中 `Q` 为瞬态子矩阵，`R_safe` 为到安全态的吸收概率。要求 `κ ≥ κ_min` 且期望恢复时间 `E[T_rec] ≤ T_r`。

**定义 127（多智能体恢复合约与移交）**
智能体 i 与 j 的恢复合约
```
H_{ij} = (F_{ij}, T_handoff, B̂_rec^j, β-share, ρ-safe)
```
`F_{ij} ⊆ 𝔉` 为 j 承诺处理的失败类。义务：若 `f∈F_{ij}`、移交状态 `x_f^trans ∈ B_rec^j`、且迁移延迟 `≤ T_handoff`，则 j 必须接管并恢复。组合 soundness：
```
P_recover^{i→j}(f) ≥ [1-ε_f^i]·[1-P(x∉B_j)]·[1-P(latency > T_handoff)]
```

**定义 128（元恢复与升级阶梯）**
升级级别 `ℓ ∈ {0:local, 1:peer, 2:cloud, 3:abort}`，每级有成本 `(latency_ℓ, side_ℓ)` 与能力集。元恢复策略
```
μ(x,f) = argmin_ℓ cost_ℓ
         s.t. x ∈ B_rec^ℓ ∧ latency_ℓ ≤ T_r ∧ side_ℓ ≤ β_side
```
升级必须**单调**：`ℓ` 失败只能升到 `ℓ+1`，禁止静默降级。`P_meta_success = Σ_ℓ P(reach ℓ before deadline)·(1-ε_ℓ)`。

## 2. 关键算法 伪代码

### IP-121 FOS（Failure Ontology Scanner）

```python
def scan_failure_spectrum(agent, faults, n_inject, tau_d, T_r, psi):
    phi = {}
    for f in faults:                      # perception/action/goal/coordination/resource
        det = rec = 0
        blasts = []
        for _ in range(n_inject):
            x0, trace = agent.inject(f)
            alarm, t_alarm = agent.monitor(trace)
            det += int(alarm and t_alarm <= tau_d)
            if alarm:
                rec += int(recover_within(agent, psi, trace, T_r))
                blasts.append(blast_radius(agent, trace))
        phi[f] = (det / n_inject, rec / max(det, 1), mean(blasts), det / n_inject)
    return phi
```

### IP-122 RBA（Recovery Basin Approximation）

```python
def estimate_recovery_basin(agent, psi, T_r, samples, eps_B=0.05, r_min=0.1):
    inside, outside = [], []
    for x in samples:
        ok, margin = rollout_recovers(agent, psi, x, T_r)
        (inside if ok else outside).append((x, margin))
    r_cut = quantile([m for _, m in outside], eps_B) if outside else inf
    B_hat = inner_approx([x for x, m in inside if m >= max(r_min, r_cut)])
    return B_hat, conformal_bound(inside, outside, eps_B)

def lyapunov_basin(agent, psi, V, T_r):
    # 安全关键子集用后向可达集 / Lyapunov 证书，而非纯采样
    return {x for x in sample_states(agent)
            if V(x) <= V_safe and lie_derivative(V, psi, x) <= -lam * V(x)}
```

### IP-123 RCA（Recovery Certificate Authority）

```python
def certify_recovery(agent, phi, B_hat, T_r, beta_side, eps, delta_max):
    for f, (delta, rho, blast, rate) in phi.items():
        p_out = prob_failure_outside_basin(agent, f, B_hat)
        lower = 1 - eps[f] - p_out
        if lower < 1 - delta_max[f]:
            return reject(f, lower, reason='basin_or_detection_unsound')
        if blast * rate > beta_side:
            return reject(f, reason='side_effect_budget_exceeded')
    return accept(RecoveryCert(phi, B_hat, T_r, beta_side, eps))
```

### IP-124 FAB（Failure Attribution via Counterfactuals）

```python
def counterfactual_blame(causal_model, agents, event_e, n_mc=2000):
    p_e = causal_model.prob(event_e)
    bf = {}
    for i in agents:
        p_fix = causal_model.prob(event_e, do={f'a_{i}': 'nominal'}, n=n_mc)
        bf[i] = max(0.0, p_e - p_fix)
    Z = sum(bf.values())
    if Z < 1e-9:
        return None, 1.0                       # 无 but-for 主因：模糊度=1
    beta = {i: bf[i] / Z for i in bf}
    top = top_causes(beta, coverage=0.8)
    ambiguity = 1 - sum(beta[i] for i in top)
    return beta, ambiguity
```

### IP-125 RCM（Recovery Closure of Mode Chain）

```python
def recovery_closure(modes, P_R, entry='retry'):
    transient = [m for m in modes if m not in ('safe', 'abort')]
    Q = submatrix(P_R, transient, transient)
    R_safe = submatrix(P_R, transient, ['safe'])
    kappa = solve((I - Q), R_safe)             # 基本矩阵：吸收前访问次数
    E_T = solve((I - Q), ones(len(transient)))
    return kappa[entry], E_T[entry]

def certify_mode_chain(kappa, E_T, kappa_min, T_r):
    return kappa >= kappa_min and E_T <= T_r
```

### IP-126 MRC（Multi-agent Recovery Contract）

```python
def match_recovery_contracts(agents, failure_classes, T_handoff):
    H = {}
    for i in agents:
        for f in failure_classes[i]:
            cands = [j for j in agents if j is not i and f in agents[j].handles
                     and state_transferable(agents[i], agents[j], f, T_handoff)
                     and agents[j].B_hat.contains(agents[i].expected_failure_state(f))]
            H[(i, f)] = max(cands, key=lambda j: recover_score(agents[j], f), default=None)
    return H

def handoff_execute(i, j, f, x, T_handoff):
    if j is None or f not in agents[j].handles:
        return escalate(i, f, level=2)          # 无人可接 → 云端
    if not inside_basin(agents[j].B_hat, x):
        return escalate(i, f, level=3)          # 落点不在盆地 → 安全中止
    return agents[j].recover(x, deadline=T_handoff)
```

### IP-127 MRE（Meta-Recovery Escalation）

```python
def meta_recover(agent, f, x, budget, min_level=0):
    for level in ['local', 'peer', 'cloud', 'abort'][min_level:]:
        plan = plan_for(level, agent, f, x)
        if plan is None:
            continue
        if (plan.x_in_basin and plan.latency <= budget.T_r
                and plan.side_effect <= budget.beta_side):
            return level, plan
    return 'abort', safe_abort(agent, x)        # 最后一级不可跳过

def escalate(agent, f, level):
    return meta_recover(agent, f, current_state(agent),
                        budget=agent.recovery_budget, min_level=level)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| FOS | O(N_inj·(T_r/Δt)·|𝔉|) | O(|𝔉|+N_inj) | 注入覆盖全部声明失败类 |
| RBA | O(N_s·T_r/Δt) | O(N_s) | 保守内近似、conformal 覆盖 |
| RCA | O(|𝔉|·N_s) | O(|𝔉|) | 盆地不越界、副作用预算闭合 |
| FAB | O(N_mc·|Ag|·|G_Ag|) | O(|Ag|) | 因果充分性、but-for 支持 |
| RCM | O(|M|³) | O(|M|²) | 吸收链、转移核校准 |
| MRC | O(|Ag|²·|𝔉|) | O(|Ag|·|𝔉|) | 合约能力集与盆地匹配 |
| MRE | O(4·|X|) | O(|X|) | 单调升级、不得静默降级 |

**正确性定理（Recovery-Aware Agent Deployment Soundness）**
承接第 54 轮 (A26)–(A28)；新增 **(A29)** 失败注入对声明失败类具统计功效 `1-δ`（置信 `1-ε`）；**(A30)** `B̂_rec` 为 `B_rec` 的保守内近似，模型误差 `ε_B`，恢复控制器 Lipschitz；**(A31)** 因果模型在交互图上 but-for sound（无未建模共因）。
则单智能体部署成功概率：
```
P_success^rec ≥ 1 - Σ_{f∈𝔉} P(f)·[ P(x_f∉B_rec) + ε_f
                                  + P(T_rec > T_r | x_f∈B_rec) ] - ε_B
```
多智能体（含合约与元恢复）：
```
P_success^multi ≥ Σ_ℓ P(reach level ℓ)·(1-ε_ℓ)
                  - Σ_f P(f)·α_amb(f)
                  - P(handoff latency > T_handoff)
```
**关键推论**：恢复证书只会把成功率从 `1-P(不可恢复失败)` 往上抬，**永远不会让失败变得无害**；它是下界而非免责声明。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 恢复盆地被高估（虚假可恢复） | 高 | 保守内近似 + conformal + 后向可达集交叉验证 |
| 自模型漂移导致漏检/误检 | 高 | 在线校准 + 分布外哨兵 + 检测器集成 |
| 恢复动作自身造成不可逆副作用 | 高 | `β_side` 硬预算 + 不可逆动作闸门 + 回滚预演 |
| 多智能体归因受共因混淆 | 中 | 随机化干预 + 敏感性分析 + `α_amb` 否决 |
| 移交延迟超过截止 | 中 | 预置接管者 + 盆地预计算 + 超时安全中止 |
| 恢复链震荡/活锁 | 中 | 单调升级 + hysteresis + 升级次数上限 |

## 6. 本轮最大风险

**一句话**：把智能体与失败恢复形式化为「失败谱 Φ + 恢复盆地 B_rec + 恢复闭包 κ + 反事实责任 β + 元恢复升级」五元组，第一次让「失败之后能否回来」成为可证书对象，但整套 soundness **同时押注于失败注入的覆盖完备性、恢复盆地的保守性、以及因果模型的无混淆假设**；一旦注入集漏掉一种真实失败、或盆地近似在边界处被高估、或归因被共因欺骗，系统就会在最需要恢复的时刻**误以为自己可恢复**，从而把资源投向错误的责任方并执行不可逆的恢复动作——这比「不恢复」更危险，因此必须以 **漏检红队 + 盆地保守下界 + 不可逆动作硬闸** 作为三道不可绕过的护栏，并坚持恢复证书只给下界、绝不给「失败免疫」的错觉。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-AgentRecover（FOS×RBA×RCA×FAB×RCM×MRC×MRE×ARL）

> 承接第 54 轮产物 v31（动作空间 × 技能组合 × 云边协同）。本轮把**智能体（agent）**与**失败恢复（failure recovery）**提升为一等公民，在「动作-鲁棒双证书」之上叠加第三类证书——**恢复证书**，并给出多智能体责任归因与升级式元恢复的闭环：
> - **FOS（Failure Ontology Scanner）**：失败类谱 `Φ_Ag`，把「会怎么坏」显式化；
> - **RBA（Recovery Basin Approximation）**：保守内近似恢复盆地 `B̂_rec` 与恢复半径 `r_rec`；
> - **RCA（Recovery Certificate Authority）**：发放/校验恢复证书 `RC`；
> - **FAB（Failure Attribution via counterfactuals）**：反事实责任向量 `β` 与归因模糊度 `α_amb`；
> - **RCM（Recovery Closure of Mode-chain）**：恢复模式马尔可夫链与恢复闭包 `κ`；
> - **MRC（Multi-agent Recovery Contract）**：跨智能体移交合约与匹配；
> - **MRE（Meta-Recovery Escalation）**：本地→同伴→云端→安全中止的单调升级；
> - **ARL（Agent Recovery Layer）**：把上述能力封装为金字塔中的智能体恢复层。
>
> IP 编号：IP-121~IP-128（共 8 个新增），并升级第 54 轮 IP-118 的联合证书为「动作-鲁棒-恢复」三证书 `T = (J, RC, β)`。

## 2. 关键算法 伪代码

### IP-121 FOS

```python
def scan_failure_spectrum(agent, faults, n_inject, tau_d, T_r, psi):
    phi = {}
    for f in faults:
        det = rec = 0
        blasts = []
        for _ in range(n_inject):
            x0, trace = agent.inject(f)                 # 定向/随机故障注入
            alarm, t_alarm = agent.monitor(trace)       # 自模型 + 检测器集成
            det += int(alarm and t_alarm <= tau_d)
            if alarm:
                rec += int(recover_within(agent, psi, trace, T_r))
                blasts.append(blast_radius(agent, trace))
        phi[f] = (det / n_inject, rec / max(det, 1), mean(blasts), det / n_inject)
    return phi
```

### IP-122 RBA

```python
def estimate_recovery_basin(agent, psi, T_r, samples, eps_B=0.05, r_min=0.1):
    inside, outside = [], []
    for x in samples:
        ok, margin = rollout_recovers(agent, psi, x, T_r)
        (inside if ok else outside).append((x, margin))
    r_cut = quantile([m for _, m in outside], eps_B) if outside else float('inf')
    B_hat = inner_approx([x for x, m in inside if m >= max(r_min, r_cut)])
    return B_hat, conformal_bound(inside, outside, eps_B)

def lyapunov_basin(agent, psi, V, lam, V_safe):
    # 安全关键子集不靠纯采样：后向可达集 + Lyapunov 证书
    return {x for x in sample_states(agent)
            if V(x) <= V_safe and lie_derivative(V, psi, x) <= -lam * V(x)}
```

### IP-123 RCA

```python
def certify_recovery(agent, phi, B_hat, T_r, beta_side, eps, delta_max):
    for f, (delta, rho, blast, rate) in phi.items():
        p_out = prob_failure_outside_basin(agent, f, B_hat)
        lower = 1 - eps[f] - p_out                     # 恢复成功率下界
        if lower < 1 - delta_max[f]:
            return reject(f, lower, reason='basin_or_detection_unsound')
        if blast * rate > beta_side:
            return reject(f, reason='side_effect_budget_exceeded')
    return accept(RecoveryCert(phi, B_hat, T_r, beta_side, eps))

def triple_certificate(J, RC, beta, T_task):
    # 动作-鲁棒-恢复三证书：任一维度否决即整体否决（AND 门）
    if not J.deployable(T_task):        return ('reject', 'action_robust_fail')
    if not RC.sound():                  return ('reject', 'recovery_unsound')
    if beta is None or beta.ambiguity > 0.2:
        return ('reject', 'attribution_ambiguous')
    return ('ok', TriCert(J, RC, beta))
```

### IP-124 FAB

```python
def counterfactual_blame(causal_model, agents, event_e, n_mc=2000):
    p_e = causal_model.prob(event_e)
    bf = {}
    for i in agents:
        p_fix = causal_model.prob(event_e, do={f'a_{i}': 'nominal'}, n=n_mc)
        bf[i] = max(0.0, p_e - p_fix)
    Z = sum(bf.values())
    if Z < 1e-9:
        return None, 1.0                               # 无 but-for 主因
    beta = {i: bf[i] / Z for i in bf}
    top = top_causes(beta, coverage=0.8)
    ambiguity = 1 - sum(beta[i] for i in top)
    return beta, ambiguity

def route_recovery(beta, f, agents):
    # 责任方自恢复，非责任方准备接管
    culprit = max(beta, key=beta.get)
    helpers = [j for j in agents if j is not culprit and f in agents[j].handles]
    return ('self_recover', culprit), helpers
```

### IP-125 RCM

```python
def recovery_closure(modes, P_R, entry='retry'):
    transient = [m for m in modes if m not in ('safe', 'abort')]
    Q = submatrix(P_R, transient, transient)
    R_safe = submatrix(P_R, transient, ['safe'])
    kappa = solve((I - Q), R_safe)
    E_T = solve((I - Q), ones(len(transient)))
    return kappa[entry], E_T[entry]

def certify_mode_chain(kappa, E_T, kappa_min, T_r):
    if kappa < kappa_min:      return ('reject', 'closure_too_low', kappa)
    if E_T > T_r:              return ('reject', 'recovery_too_slow', E_T)
    return ('ok', kappa, E_T)
```

### IP-126 MRC

```python
def match_recovery_contracts(agents, failure_classes, T_handoff):
    H = {}
    for i in agents:
        for f in failure_classes[i]:
            cands = [j for j in agents if j is not i
                     and f in agents[j].handles
                     and state_transferable(agents[i], agents[j], f, T_handoff)
                     and agents[j].B_hat.contains(agents[i].expected_failure_state(f))]
            H[(i, f)] = max(cands, key=lambda j: recover_score(agents[j], f), default=None)
    return H

def handoff_execute(i, j, f, x, T_handoff):
    if j is None or f not in agents[j].handles:
        return escalate(i, f, level=2)
    if not inside_basin(agents[j].B_hat, x):
        return escalate(i, f, level=3)
    return agents[j].recover(x, deadline=T_handoff)
```

### IP-127 MRE

```python
def meta_recover(agent, f, x, budget, min_level=0):
    for level in ['local', 'peer', 'cloud', 'abort'][min_level:]:
        plan = plan_for(level, agent, f, x)
        if plan is None:
            continue
        if (plan.x_in_basin and plan.latency <= budget.T_r
                and plan.side_effect <= budget.beta_side):
            return level, plan
    return 'abort', safe_abort(agent, x)

def escalate(agent, f, level):
    # 单调升级：只升不降，禁止静默降级
    return meta_recover(agent, f, current_state(agent),
                        budget=agent.recovery_budget, min_level=level)
```

### IP-128 ARL（层封装与证书聚合）

```python
def agent_recovery_layer(agents, faults, samples, T_r, beta_side):
    certs = []
    for ag in agents:
        phi = scan_failure_spectrum(ag, faults, N_INJ, TAU_D, T_r, ag.psi)
        B_hat, eps_B = estimate_recovery_basin(ag, ag.psi, T_r, samples)
        rc = certify_recovery(ag, phi, B_hat, T_r, beta_side, EPS, DELTA_MAX)
        kappa, E_T = recovery_closure(MODES, ag.P_R)
        if not certify_mode_chain(kappa, E_T, KAPPA_MIN, T_r)[0] == 'ok':
            rc = reject('mode_chain_unsound')
        certs.append((ag, rc))
    contracts = match_recovery_contracts([a for a, _ in certs], faults, T_HANDOFF)
    return AgentRecoveryLayer(certs, contracts)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| FOS | O(N_inj·(T_r/Δt)·\|𝔉\|) | O(\|𝔉\|+N_inj) | 注入覆盖全部声明失败类，统计功效可控 |
| RBA | O(N_s·T_r/Δt) | O(N_s) | 保守内近似；conformal 覆盖 ≥ 1-ε_B |
| RCA | O(\|𝔉\|·N_s) | O(\|𝔉\|) | 恢复下界不越界、副作用预算闭合 |
| FAB | O(N_mc·\|Ag\|·\|G_Ag\|) | O(\|Ag\|) | but-for 支持在真因上，α_amb 显式暴露混淆 |
| RCM | O(\|M\|³) | O(\|M\|²) | 吸收链闭包一致，期望恢复时间可算 |
| MRC | O(\|Ag\|²·\|𝔉\|) | O(\|Ag\|·\|𝔉\|) | 合约能力集与接收方盆地匹配 |
| MRE | O(4·\|X\|) | O(\|X\|) | 单调升级、无静默降级、超时必中止 |

**正确性定理（Recovery-Aware Agent Deployment Soundness）**
承接第 54 轮 (A26)–(A28)；新增 **(A29)** 失败注入对声明失败类具统计功效 `1-δ`（置信 `1-ε`）；**(A30)** `B̂_rec` 为 `B_rec` 的保守内近似，模型误差 `ε_B`，恢复控制器 Lipschitz；**(A31)** 因果模型在交互图上 but-for sound（无未建模共因）。
则单智能体：
```
P_success^rec ≥ 1 - Σ_{f∈𝔉} P(f)·[ P(x_f∉B_rec) + ε_f
                                  + P(T_rec > T_r | x_f∈B_rec) ] - ε_B
```
多智能体（含合约与元恢复）：
```
P_success^multi ≥ Σ_ℓ P(reach level ℓ)·(1-ε_ℓ)
                  - Σ_f P(f)·α_amb(f)
                  - P(handoff latency > T_handoff)
```
**推论**：恢复证书只抬高下界，不使失败无害；`P_success^rec ≥ 1 - P(不可恢复失败)` 是硬约束。

## 6. 本轮最大风险

**一句话**：把智能体与失败恢复形式化为「失败谱 Φ + 恢复盆地 `B̂_rec` + 恢复闭包 κ + 反事实责任 β + 元恢复升级 μ」五元组，第一次让「失败之后能否回来」成为可证书对象，但整套 soundness **同时押注于失败注入的覆盖完备性、恢复盆地的保守性、以及因果模型的无混淆假设**；一旦注入集漏掉一种真实失败、或盆地近似在边界处被高估、或归因被共因欺骗，系统就会在最需要恢复的时刻**误以为自己可恢复**，从而把资源投向错误的责任方并执行不可逆的恢复动作——这比「不恢复」更危险，因此必须以 **漏检红队 + 盆地保守下界 + 不可逆动作硬闸** 作为三道不可绕过的护栏，并坚持恢复证书只给下界、绝不给「失败免疫」的错觉。
