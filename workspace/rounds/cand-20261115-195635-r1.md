# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「隐私保护」×「个性化交互」）

> R69 教会了系统「问」——把 epistemic 歧义交给看/问/触主动消解，用流匹配的多模态先验判断「值不值得问」。但 R69 的 VoI 只记了三笔账：信息增益、物理成本、社交成本，漏掉了最贵的一笔——**披露**。每一次注视都在采集旁人的脸，每一句问话都在向周围宣布「我不知道」，每一条回答都要被记住才能「个性化」。R69 越会问，越依赖「记住用户」；越记住用户，越接近**重识别**。这不是工程细节，而是 R69 收益结构的另一面：**个性化 = 用隐私换精度**。
>
> 本轮两个灵感恰好构成一对张力：
> - **个性化交互**给出 R69 缺失的「用户先验」——同一处歧义，对老用户可能根本不用问（他知道你要什么），对新用户则必须问。个性化把「对所有人问」变成「只对该问的人、在该问的时候问」；
> - **隐私保护**给出这条路的硬边界——披露不可逆、画像会累积、审计日志本身会泄露。隐私不是「事后加个噪声」，而是**与交互预算、实时预算并列的第三类预算**。
>
> 核心命题：**把隐私做成第一等资源；个性化只在「本地 / DP 聚合」的适配器里发生；把 R69 的 VoI 升级为「披露感知的 P-VoI」；隐私预算耗尽、身份风险越界或同意撤回时，沿 P2→P1→P0 单调退化为 R69→R68。** 命名 **VEIL-RAS**（Value-of-information with Epistemic Interaction under privacy Limits）——「veil」既是面纱也是账本：看得见的收益，必须先付得起看不见的代价。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**求证之前，我凭什么决定这个代价由谁承担、又该记多久**」——隐私不是交互的对手，而是交互的定价者。

## 0. 直觉与动机

**灵感 1（隐私发生在「披露」而非「存储」）**
直觉：大家把隐私当数据库问题（加密、脱敏、删库），但对一个会交互的具身系统，隐私损失发生在**动作发生的瞬间**：注视把注意力投向谁、问句让旁边第三方听到什么、探针接触留下什么痕迹。数据可以删，披露收不回。所以隐私必须进入**动作层**——与安全认证走同一条路径，而不是事后在日志上打补丁。这把 R69 的「信息动作认证（定义 302）」自然升级为「信息动作的隐私认证」。

**灵感 2（个性化 = 用户先验 = 少问而准，一个隐私友好的正循环）**
直觉：R69 里每次模态歧义都要花一次 VoI 交互。但「歧义」是相对先验的：同一个模糊手势，对熟悉用户是「他又在指冰箱」，对陌生人是一个待解模态。个性化提供用户特定的模态先验 `w_u`、打扰容忍/沟通偏好 `c_u`、甚至「该用问句还是手势确认」的模态选择 `g_u`。它把 R69 的「统一价格」变成「用户定价」。关键在于：**个性化最大的价值不是让你被多采集，而是让你被少打扰**——懂你，是为了不必反复问你。这是与「个性化=多要数据」直觉相反的正循环。

**灵感 3（主动询问 > 被动推断：有些交互是「隐私节约型」的）**
直觉：通常交互消耗隐私，但存在一类反例——**被同意的显式提问，可以替代长期的隐蔽画像推断**。与其偷偷从行为里推断你的偏好（被动、不可见、无法拒绝），不如问一句「你希望我这样做吗」（显式、可拒绝、一次结算）。因此隐私成本 `ρ(g)` 应当是**有符号的净值**：`ε(实际披露) − ε(被替代的推断)`。这把 R69 的「交互=花钱」翻转为「有些交互是在**买回**隐私」——但前提是同意、且被替代的推断确实会发生。这是本轮最反直觉、也最重要的一条。

**灵感 4（对偶：个性化精度与可识别性是同一枚硬币）**
直觉：要让先验足够准，画像就得足够特异；而足够特异的画像就是**指纹**。在信息论上，「个性化」与「重识别」是同一个量——画像与身份的互信息。想让系统 100% 懂你，就等于让它 100% 能认出你。所以「个性化越强越好」是错的；正确目标是**在可识别风险约束下最大化个性化收益**，这是一条有拐点的曲线，而非单调直线。这也解释了为什么「精度掉一点、隐私涨很多」的中间档常常才是最优。

**灵感 5（隐私账本不可逆 + 三类新威胁）**
直觉：交互预算按单位时间刷新，隐私预算**永不刷新**；且按 DP 组合定理累积，k 次小查询可能比 1 次大查询更贵。于是 R69 的「多次小交互」在隐私维度上可能是灾难，反而应该**攒着一次问清**。同时出现三类新威胁：(a) 用户知道你在记他，会**为保护隐私而善意谎报偏好**——这击穿 R69「回答可信」的假设，是「善意的投毒」；(b) 旁观者——传感器看到的不只是用户，还有未同意的第三方；(c) 审计本身——为证明合规而保存的交互日志，恰恰是最敏感的画像。故本轮必须同时交付：策略性谎报的鲁棒估计、旁观者同意域、可验证但零知识的审计、以及「遗忘权」的形式化。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（VEIL-RAS 总览）** VEIL-RAS = (FMP, AUD, MINT†, PDP, LPA, CDG, PAud, RAS-WM††)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；个性化训练只在离线/后台，绝不进入控制环）；
(ii) **隐私预算硬约束**：不可再生的隐私里程计 `(ε_used, δ)` 按 DP 组合单调累积，越界即冻结个性化并降级（定义 315、321）；
(iii) **个性化只经本地/DP 聚合适配器**：原始画像不出设备，中央只收 DP 统计或安全聚合结果（定义 316）；
(iv) **披露可问责**：每个动作的披露进入账本，审计只用承诺/零知识，旁观者在同意域内（定义 311、318、319）。

**定义 311（披露向量与隐私账本）** 动作 `ξ=(a,g)` 关联披露向量 `d(ξ)=(d_usr, d_by, d_srv, d_log)`（对用户本人 / 旁观者 / 服务器 / 日志的披露）与成本 `ρ(ξ)=Σ_k w_k·ε_k(d_k) − ε_infer_replaced`，其中末项是「被本次显式交互替代的隐蔽推断」的隐私节省（灵感 3；无替代则记 0）。账本 `ℒ = {(t, ξ, d, ρ, consent_id)}`，只追加不删除。**登记规则**：进入预算的是实际正披露 `ρ⁺=max(ρ,0)`；负值只在 P-VoI 比较中作为收益，不冲抵历史欠账。

**定义 312（个性化用户先验）** 冻结基座策略 `π_θ` 上的用户适配器 `Δθ_u`，给出 `w_u`（模态先验）、`c_u(g)`（该用户的信息动作成本）、`g_u`（沟通模态偏好）。个性化收益 `G_u = E[cost(π_pop)] − E[cost(π_{θ+Δθ_u})]`。**个性化不是新动作，只是同一动作空间上的条件化**，故不影响安全包络（定义 322）。

**定义 313（个性化-可识别性对偶）** 重识别风险 `R_id(θ_u) = Pr[Adv 正确识别 u | θ_u]`。定义画像的信息量 `I(θ_u; id)`。核心对偶：`R_id` 是 `I` 的单调函数（A99）；因此任何提升 `G_u` 的画像特化，都会推高 `R_id`，二者不可同时无代价地拉满。

**定义 314（披露感知 VoI：P-VoI）** `VoI_priv(g) = VoI(g) − c(g) − λ_p·ρ⁺(g) + λ_p·ε_infer(g)`，其中 `λ_p` 是隐私的影子价格（由预算余量与风险偏好决定）。选择 `g* = argmax_g VoI_priv(g)`，约束：`risk(g)≤ε_int`、交互预算未超、隐私里程计余量足够、同意有效。若 `max VoI_priv ≤ 0`：不交互，退化 R69。**`λ_p→0` 时 P-VoI 逐项还原 R69 的 `VoI−c`。**

**定义 315（隐私里程计 POD）** 维护 `(ε_used, δ_used)`，每次披露用 RDP/矩会计的紧致组合更新；提供 `charge(ε)`、`remaining()`、`would_exceed(ε)`。**永不刷新**；跨会话、跨用户共享同一用户账户。达到 `ε_max` ⇒ 冻结个性化且禁用新的「高披露」信息动作（定义 321）。

**定义 316（本地个性化适配器 LPA）** 用户设备上用 DP-SGD 训练 `Δθ_u`，噪声与裁剪满足 `(ε_u,δ_u)`；仅上传 DP 聚合统计或安全聚合后的加密增量。**门槛引理**：本地样本 `n_u` 低于阈值 `n*` 时个性化增益不足以抵消 DP 噪声，应直接用总体先验（引理 22）。

**定义 317（策略性谎报与鲁棒聚合 SRA）** 用户为保护隐私给出失真报告 `w̃_u = w_u + b(u)`，`b` 是理性的、有偏的、且与真实偏好相关。把 `b` 视作**善意对抗通道**（与 R69 的 ℰ_poison 同构但动机不同），用截尾均值 / median-of-means / 鲁棒 M-估计融合多源报告，并把「报告一致性」作为置信信号。

**定义 318（同意域与旁观者）** 同意域 `C ⊆` 场景中允许采集数据的主体集合；旁观者集 `B = observed \ C`。证据选择必须满足 `d_by ≤ ε_by`：对 `B` 只能保留不可识别统计，否则遮罩/降采样/放弃该信息动作。旁观者隐私成本并入 `ρ(ξ)`（定义 311）。

**定义 319（隐私感知审计 PAud）** 审计只接受**承诺**（交互日志哈希、DP 统计、zk 证明），验证「证据纪律满足、预算未越界、同意有效」而不读取原始内容。审计日志本身通过 DP 清洗；`J_VEIL` 中的哈希不得成为指纹。

**定义 320（证书 J_VEIL）** `J_VEIL = (J_FLUID, ε_used, δ_used, odometer_state, personalization_gain, id_risk_bound, disclosure_log_commitment, consent_status, dp_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ ε_used ≤ ε_max ∧ R_id ≤ τ_id ∧ consent 有效 ∧ 账本承诺可验证`。**隐私违规是安全事件**：任一失败 ⇒ 证书失效并触发保守退避（定理 19）。

**定义 321（个性化-隐私降级阶梯与模式切换）** 三档模式：
- **P2（个性化+共享）**：本地适配 + 同意 + 预算充足，允许个性化交互；
- **P1（仅本地个性化）**：可在设备内用画像，不外传、不进入共享证据；
- **P0（非个性化）**：仅总体先验 + R69 交互（且高披露动作被禁）。
降级方向单调：`预算耗尽 / R_id 越界 / 同意撤回 / 策略性谎报检测失败` ⇒ 逐级下降。**R69 是 P2 在 `Δθ_u=0, λ_p=0` 的退化；R68 是 P0 在「永不交互」的退化。**

**定义 322（个性化-安全耦合）** 个性化只改变先验 `w_u`，不改变安全包络；`λ_floor` 仍作用于 `(U_ale, 未消解 U_epi)`（继承定义 307）。若 `w_u` 过期/错配导致先验偏移，由 C-RAS-WM 前缀认证兜底：**个性化绝不放松 `k` 与 `λ` 的安全下界**。

**定义 323（最小披露证据选择）** 在 VoI 相近（差值 ≤ 阈值）的候选信息动作中，按字典序最小化 `(d_srv, d_log, d_by, d_usr)`：**优先本地传感而非询问、优先设备内而非服务器、优先聚合而非个体**。「能自己看的，不问你；能在设备里算的，不上传」——隐私版 Occam。

**定义 324（记忆生命周期与遗忘权）** 画像条目带 TTL 与用途标签；删除请求必须在 `T_forget` 内使对应影响不再出现在未来动作中（可验证遗忘：影子模型差分 + 承诺更新）。**被遗忘的数据不得以任何聚合形式继续影响个性化**，否则证书失效。

**定义 325（隐私-个性化-效用三面权衡）** 相对「全信息个性化预言机」定义遗憾 `Regret = E[cost(π_oracle)] − E[cost(π_VEIL)]`。目标是在 `(ε_max, τ_id, consent, 实时预算)` 约束下最小化 `Regret`；由引理 21、22 得 `Regret ≤ O(λ_p·ρ_max) + O(1/√n_u) + 贝叶斯先验误差`。

**定义 326（跨轮严格包含）** 布尔退化链：`VEIL(λ_p=0, ε_max=∞, n_u=0) ≡ R69`；`R69(无交互) ≡ R68`。新层只在旧层之上**增加约束/通道**，不替换任何旧可靠性论证（与 R69「新层必须是旧层严格泛化」同姿态）。

## 2. 关键算法骨架

```python
# IP-264 PDP：不可再生隐私里程计（RDP/矩会计，跨会话共享）
class PrivacyOdometer:
    def __init__(self, eps_max, delta_max):
        self.eps_used, self.delta_used = 0.0, 0.0
        self.eps_max, self.delta_max = eps_max, delta_max
    def charge(self, eps, delta):                 # 组合更新，单调不降
        self.eps_used = compose_rdp(self.eps_used, eps)
        self.delta_used += delta
    def would_exceed(self, eps, delta):
        return compose_rdp(self.eps_used, eps) > self.eps_max or \
               self.delta_used + delta > self.delta_max
    def remaining(self):
        return max(0.0, self.eps_max - self.eps_used)

# IP-265 P-VoI：披露感知的交互决策（λ_p=0 时逐项还原 R69）
def p_voi(modes, w, o_t, budget, odometer, consent, lam_p):
    best = None
    for g in info_action_candidates(modes):
        d = disclosure_vector(g, o_t)             # usr/by/srv/log
        if not budget.allow(g):                   continue
        if not consent.allows(g, d):              continue   # 同意域 / 旁观者
        if not c_ras_wm.certify_info(g, o_t):     continue   # 安全认证（R69）
        if odometer.would_exceed(*dp_cost(g)):    continue   # 硬预算
        rho = sum(wk * dp_eps(dk) for wk, dk in zip(DISC_W, d.values()))
        rho -= infer_avoided(g, o_t)             # 被替代的隐蔽推断（可负）
        score = voi(w, g, o_t) - cost(g) - lam_p * max(rho, 0.0) \
                + lam_p * infer_avoided(g, o_t)
        if best is None or score > best.score: best = (g, score, d)
    return best if best and best.score > 0 else None   # 无利可图 → R69

# IP-266 LPA：设备内 DP 个性化（离线/后台，绝不进实时环）
def train_local_adapter(base, user_data, eps_u):
    delta = init_zero_like(base.adapter)
    for batch in batches(user_data):
        g = dp_clip(delta_grad(base, delta, batch), C)
        delta -= lr * (g + dp_noise(eps_u, C))    # DP-SGD
    return delta

# IP-269 SRA：策略性谎报下的鲁棒融合（善意投毒）
def robust_merge(reports):
    if consistency(reports) < TAU_CONSIST:
        return None                               # 谎报冲突 → 不个性化
    return median_of_means(reports)               # 对离群/有偏报告稳健

# IP-274 主闭环（继承 R69，仅在 VoI 与降级处插入 VEIL 层）
def VEIL_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)

    # 1) 个性化先验（P2/P1 才启用；样本不足或谎报冲突则跳过——引理 22/317）
    if M.mode >= P1 and M.lpa.ready(M.user) and M.sra.ok(M.user):
        w_u = M.lpa.prior(M.user)
        U_epi = M.aud.reweight(U_epi, w_u)        # 个性化只改先验，不改安全
    # 2) 披露感知交互（同意 / 预算 / 安全 / 最小披露）
    g = None
    if U_epi > TAU_EPI and not M.slow_fault_suspect:
        cand = M.pvoi.choose(modes, o, M.budget, M.odometer, M.consent, M.lam_p)
        if cand is not None:
            g = M.mindisclosure.tie_break(cand)    # 定义 323 字典序
            M.odometer.charge(*dp_cost(g))         # 先记账，后执行
            ans = M.cia.execute(g)
            U_epi = M.sra.merge_belief(modes, ans) # 证据纪律 + 反谎报
    # 3) 风险缩放：隐私退避只增不减（定理 19）
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if M.odometer.exhausted() or M.id_risk > TAU_ID or M.consent.revoked():
        M.demote()                                 # P2→P1→P0，规则见定义 321
        lam = max(lam, M.mode_floor)               # 退避单调
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = M.aud.select_mode(modes, U_epi, lam)
    # 4) 隐私审计只拿承诺（定义 319）
    M.paud.submit_async(g, commitment(M.ledger), M.odometer.state(), M.id_risk)
    return k, lam, mode, (U_ale, U_epi, M.odometer.state())
```

## 3. 推导

假设：**A99**（画像对身份是充分统计量，重识别成功率是 `I(θ_u;id)` 的单调函数）；**A100**（DP 组合用 RDP 会计，给定机制族）；**A101**（策略性谎报偏差有界且与真实偏好正相关）；**A102**（个性化只改先验，不改安全包络与认证）。

**引理 19（披露的不可逆性与组合单调）** 拟序：同源披露序列的累积隐私损失单调不降；在 advanced composition 下至少按 `~√k·ε + kε(e^ε−1)` 量级增长，且已披露事实无法被「遗忘」撤销。系：**R69 的「多次小额交互」在隐私维度上可能劣于「一次问清」**——交互调度应从「最小化单次成本」改为「最小化组合后的累积损失」。

**引理 20（个性化-可识别性下界）** 在 A99 下，重识别优势至少是 `I(θ_u;id)` 的单调不减函数；因此存在 Pareto 前沿，任何同时最大化 `G_u` 与最小化 `R_id` 的方案都不存在（除平凡点）。系：个性化必须显式带 `R_id≤τ_id` 约束，否则「更懂你」必然滑向「更能认出你」。

**引理 21（P-VoI 的保守性与退化）** 相对于 R69，`λ_p>0` 只会删除（或推迟）候选信息动作，故披露与交互次数严格不增；`λ_p→0` 时 argmax 集合还原 R69；任务遗憾上界为 `O(λ_p·ρ_max)`（影子价格定价）。系：隐私约束是**单向收紧器**，与 R69 的「退化时逐指令相同」姿态一致。

**引理 22（本地 DP 个性化的泛化门槛）** 在 DP-SGD 下，`Δθ_u` 的 excess risk `≤ O(1/√n_u) + O(噪声项(ε_u))`；存在阈值 `n*`，当 `n_u<n*` 时个性化增益被 DP 噪声吞没。系：**个性化要有「样本量门」**——新用户先走总体先验（P0 边缘），样本足够才升 P1/P2（定义 316）。

**定理 18（VEIL 严格包含 R69 与 R68）** 在 A99–A102 下，VEIL 的 P2→P1→P0 单调降级链保证：任意状态的风险 ≤ R69，且在 `λ_p=0, Δθ_u=0` 时与 R69 **逐指令相同**；在「无交互」边界上进一步与 R68 逐指令相同。安全侧不让步，效率侧靠个性化获得 resolution 之外的 personalization bonus。

**定理 19（隐私退避不增物理风险 + 隐私违规即安全事件）** 降级只减少个性化、只增加保守（`λ` 单调不降、`k` 单调不增），故物理风险不增；个性化经 A102 不触碰安全包络；由定义 320，任一隐私约束失败使证书失效并触发最保守档。⇒ **隐私与安全在前沿上不冲突**：不会为了安全而牺牲隐私，也不会为了隐私而放松安全。

## 6. 本轮最大风险

**一句话**：VEIL-RAS 的全部收益押在「隐私账本算得准」上——**而 `ε_used`、`R_id`、`λ_p` 在流式、多模态、连续交互下都没有干净且紧致的可观测上界：账本上的数字只是「我们相信泄露了多少」，不是「实际泄露了多少」；一旦高估自己的隐私保护，系统就会用一张合规的证书为过度采集与重识别背书**——**账本算错，比没有账本更危险**，因为它把「诚实的不知道」升级成「被证明的合规」。

**次级风险与缓解**：
1. **个性化先验错配/过期**（旧画像驱动新决策）→ 样本量门 `n*` + TTL + C-RAS-WM 前缀认证兜底（定义 316/324、定理 19）；
2. **策略性谎报（善意投毒）** → SRA 鲁棒融合 + 一致性置信 + 报告与行为交叉验证（定义 317、E306）；
3. **旁观者与同意域失守** → CDG 硬约束 + 遮罩 + 旁观者重识别指标（定义 318、E305）；
4. **审计日志反成画像** → 只存承诺/DP 统计 + 零知识验证（定义 319、E311）；
5. **隐私与实时预算冲突** → LPA/PAud 全部异步、实时环只加 <0.1ms 的里程计与 P-VoI（复杂度表、E313）；
6. **过度保守导致个性化不可用** → 以 `Regret` 而非「隐私最小化」为目标，给出可调 `λ_p` 的 Pareto 档位（定义 325、E302）。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** 零实时学习写操作（个性化只离线/后台）；隐私预算硬约束且不可再生；个性化只经本地/DP 聚合；披露可问责（承诺审计 + 同意域）。

**定义 311–312（披露账本与用户先验）** 每个动作记录 `(d, ρ)` 与同意 ID；账本只追加不删除，入预算的是 `ρ⁺=max(ρ,0)`，负值只在 P-VoI 中作为收益不冲抵历史欠账。个性化 = 冻结基座上的适配器 `Δθ_u`，只改先验不改安全包络。

**定义 313（个性化-可识别性对偶）** `R_id` 是 `I(θ_u;id)` 的单调函数：画像越准越可识别；故「个性化越强越好」错误，必须在 `R_id≤τ_id` 下最大化 `G_u`。

**定义 314（P-VoI）** `g*=argmax[VoI−c−λ_pρ⁺+λ_pε_infer]`，约束安全/交互预算/里程计/同意；无利可图即退化 R69。

**定义 315–316（里程计与本地适配器）** RDP 组合、跨会话不刷新；DP-SGD + 安全聚合；样本量门 `n*` 决定是否个性化（引理 22）。

**定义 317–318（谎报与同意域）** 策略性谎报 = 善意对抗通道，用鲁棒聚合 + 一致性置信；旁观者 `B` 只能得不可识别统计，否则放弃该信息动作。

**定义 319–320（审计与证书）** 审计只拿承诺/DP 统计/zk；`J_VEIL` 有效期要求 `ε≤ε_max ∧ R_id≤τ_id ∧ consent ∧ 承诺可验证`；隐私违规即安全事件。

**定义 321（降级阶梯）** P2→P1→P0 单向；预算耗尽/越界/撤回/谎报检测失败触发降级；R69 = P2 在 `Δθ_u=0, λ_p=0` 的退化，R68 = P0 在「无交互」的退化。

**定义 322–323（安全耦合与最小披露）** 个性化只改 `w_u`，`λ_floor` 与前缀认证照旧；VoI 相近时按 `(d_srv,d_log,d_by,d_usr)` 字典序最小披露：能自己看就不问，能在设备算就不上传。

**定义 324–326（遗忘/权衡/包含）** TTL + 用途标签 + 可验证遗忘；以 `Regret` 而非「隐私最小化」为目标；`VEIL(λ_p=0,ε_max=∞,n_u=0)≡R69`，`R69(无交互)≡R68`。

```python
# IP-264 PDP：不可再生隐私里程计（RDP 组合，跨会话共享）
class PrivacyOdometer:
    def __init__(self, eps_max, delta_max):
        self.eps_used = self.delta_used = 0.0
        self.eps_max, self.delta_max = eps_max, delta_max
    def charge(self, eps, delta):
        self.eps_used = compose_rdp(self.eps_used, eps); self.delta_used += delta
    def would_exceed(self, eps, delta):
        return compose_rdp(self.eps_used, eps) > self.eps_max or \
               self.delta_used + delta > self.delta_max

# IP-265 P-VoI：披露感知交互（λ_p=0 时还原 R69）
def p_voi(modes, w, o_t, budget, odometer, consent, lam_p):
    best = None
    for g in info_action_candidates(modes):
        d = disclosure_vector(g, o_t)
        if not budget.allow(g) or not consent.allows(g, d):        continue
        if not c_ras_wm.certify_info(g, o_t):                      continue
        if odometer.would_exceed(*dp_cost(g)):                     continue
        rho   = sum(wk * dp_eps(dk) for wk, dk in zip(DISC_W, d.values()))
        saved = infer_avoided(g, o_t)                             # 可负成本的来源
        score = voi(w, g, o_t) - cost(g) - lam_p * max(rho, 0.0) + lam_p * saved
        if best is None or score > best.score: best = (g, score, d)
    return best if best and best.score > 0 else None              # 无利可图 → R69

# IP-266 LPA：设备内 DP 个性化（离线，绝不进实时环）
def train_local_adapter(base, user_data, eps_u):
    delta = init_zero_like(base.adapter)
    for batch in batches(user_data):
        g = dp_clip(delta_grad(base, delta, batch), C)
        delta -= lr * (g + dp_noise(eps_u, C))                    # DP-SGD
    return delta

# IP-267 SRA：善意谎报下的鲁棒融合
def robust_merge(reports):
    if consistency(reports) < TAU_CONSIST: return None            # 冲突 → 不个性化
    return median_of_means(reports)

# IP-274 主闭环（继承 R69）
def VEIL_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)

    if M.mode >= P1 and M.lpa.ready(M.user) and M.sra.ok(M.user):
        U_epi = M.aud.reweight(U_epi, M.lpa.prior(M.user))       # 只改先验
    g = None
    if U_epi > TAU_EPI and not M.slow_fault_suspect:
        cand = M.pvoi.choose(modes, o, M.budget, M.odometer, M.consent, M.lam_p)
        if cand is not None:
            g = M.mindisclosure.tie_break(cand)                    # 定义 323
            M.odometer.charge(*dp_cost(g))                         # 先记账后执行
            U_epi = M.sra.merge_belief(modes, M.cia.execute(g))
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if M.odometer.exhausted() or M.id_risk > TAU_ID or M.consent.revoked():
        M.demote(); lam = max(lam, M.mode_floor)                   # 退避只增不减
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = M.aud.select_mode(modes, U_epi, lam)
    M.paud.submit_async(g, commitment(M.ledger), M.odometer.state(), M.id_risk)
    return k, lam, mode, (U_ale, U_epi, M.odometer.state())
```

## 4. 推导

假设：A99（重识别率是 `I(θ_u;id)` 的单调函数）；A100（RDP 会计）；A101（谎报偏差有界且与真偏好正相关）；A102（个性化只改先验、不改安全包络）。

**引理 19（披露不可逆与组合单调）** 同源披露的累积隐私损失单调不降；advanced composition 下按 `~√k·ε + kε(e^ε−1)` 增长，已披露事实无法被遗忘撤销。系：R69 的「多次小额交互」可能劣于「一次问清」，交互调度应最小化累积损失而非单次成本。

**引理 20（个性化-可识别性下界）** `R_id` 是 `I(θ_u;id)` 的单调不减函数，故 `(G_u, R_id)` 存在非平凡 Pareto 前沿；同时最大化二者不存在（除平凡点）。系：个性化必须显式受 `R_id≤τ_id` 约束。

**引理 21（P-VoI 保守性与退化）** `λ_p>0` 只删除或推迟候选，披露/交互次数严格不增；`λ_p→0` 还原 R69；遗憾上界 `O(λ_p·ρ_max)`。系：隐私约束是单向收紧器。

**引理 22（本地 DP 个性化门槛）** DP-SGD 下 excess risk `≤ O(1/√n_u)+O(噪声(ε_u))`，存在 `n*` 使 `n_u<n*` 时增益被噪声吞没。系：新用户先走总体先验，样本足够才升 P1/P2。

**定理 18（VEIL 严格包含 R69/R68）** P2→P1→P0 单调降级保证任意状态风险 ≤ R69；`λ_p=0, Δθ_u=0` 时与 R69 逐指令相同；「无交互」边界与 R68 逐指令相同。安全不让步，效率侧多出 personalization bonus。

**定理 19（隐私退避不增物理风险 + 隐私违规即安全事件）** 降级只减个性化、只增保守（`λ` 单调不降、`k` 单调不增）；个性化经 A102 不触碰安全包络；定义 320 使任一隐私约束失败即证书失效并触发最保守档。⇒ 隐私与安全在前沿上不冲突。

## 7. 本轮最大风险

**一句话**：VEIL-RAS 的全部收益押在「隐私账本算得准」上——**而 `ε_used`、`R_id`、`λ_p` 在流式、多模态、连续交互下没有干净且紧致的可观测上界：账本上的数字只是「我们相信泄露了多少」，不是「实际泄露了多少」；一旦高估自己的隐私保护，系统就会用一张合规证书为过度采集与重识别背书**——**账本算错，比没有账本更危险**，因为它把「诚实的不知道」升级成「被证明的合规」。

**次级风险与缓解**：个性化先验错配/过期（`n*` 门槛 + TTL + 前缀认证，定义 316/324、定理 19）；策略性谎报（SRA 鲁棒融合 + 交叉验证，定义 317、E306）；旁观者失守（CDG 硬约束 + 遮罩，定义 318、E305）；审计日志反成画像（只存承诺/DP 统计，定义 319、E311）；隐私与实时冲突（LPA/PAud 全异步，实时只加 <0.1ms，E313）；过度保守致个性化不可用（以 `Regret` 为目标给可调 `λ_p` 档位，定义 325、E302）。
