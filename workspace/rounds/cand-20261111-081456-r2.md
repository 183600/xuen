# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 2 轮；本轮灵感：「仿真训练」×「商业模式」）

> 第 54 轮已把技能组合提升为动作-鲁棒性双证书 `J=(ρ,A_cert,γ_ce,δ_a)`，回答了“组合在动作空间上是否可对齐”。但证书只在仿真与受控实验里成立，尚未回答一个更尖锐的问题：**这张证书在真实世界值多少钱、由谁承担它失效的代价、以及仿真训练应该在哪里停止**。本轮把仿真训练视为“证书生产线”，把商业模式视为“风险定价与责任分配机制”。核心矛盾：H22：仿真越被优化，名义成功率越高，但仿真-现实折价 `κ` 可能同步恶化，形成“证书通胀”；H23：商业上可接受的合同要求尾部风险可承保，而仿真训练只优化平均成功率，二者在长尾处系统性错配。

## 0. 直觉与动机

**灵感 1（仿真训练不是“造策略”，而是“印证书”）**
直觉：一次仿真训练的最终产物不只是一个策略网络，而是一张**带分布、置信度、证据链的统计承诺**：它在什么任务域、以多大概率成功、失败时损失上界是多少、证据来自哪些仿真种子与真实审计。没有审计的证书只是营销材料；没有域包络的证书是无限责任。于是“仿真训练”的生产函数应从 `B → p_sim` 升级为 `B → (J, S_cov, n_audit, δ_c, E_prov)`。

**灵感 2（仿真-现实折价 `κ` → 证书跨域流通的“汇率”）**
直觉：仿真里 98% 的成功率不等于现实里 98%。中间存在一个折价：`p_real ≈ κ·p_sim`。`κ` 不是常数，它取决于场景层、保真度、随机化宽度与真实审计覆盖。更危险的是，`κ` 会随着对仿真的过度优化而下降：模型学会了“仿真器的漏洞”，而不是任务本身。因此 `κ` 必须被显式估计、分层报告、并作为证书的乘性折扣，而不是藏在附录里的一个免责声明。

**灵感 3（证书通胀 → 商业上的 Goodhart 定律）**
直觉：一旦证书可以卖钱，供给方就有动机优化“证书指标”而非“现实能力”。名义成功率 `p_sim` 上升、真实成功率 `p_real` 不动甚至下降，二者的差就是**证书通胀** `I`。这和货币超发一样：短期能换取合同，长期让整个证书市场贬值。治理手段也不是道德劝诫，而是制度：独立 held-out 审计、`κ` 的置信下界、责任保证金与违约罚没。

**灵感 4（商业模式的核心不是定价，而是风险分配）**
直觉：客户买的不是“机器人”，而是“在特定任务域内、失败有人兜底的服务”。因此合同类型必须与证书强度匹配：证书强 → 可按任务收费；证书弱但均值稳 → 订阅制；证书有尾部风险 → 按成功付费或保险兜底；证书域很窄 → 只能在域内按次收费。把合同看成**风险分配机制**，定价只是它的影子价格。没有保证金与审计，市场会退化为“柠檬市场”：最强证书无法证明自己，最弱证书反而最敢承诺。

**灵感 5（仿真预算 → 优化风险调整后的商业 ROI，而不是仿真成功率）**
直觉：仿真算力应花在“最能降低责任尾部、最能提升可签约等级”的场景上，而不是花在已经把 `p_sim` 刷到 0.99 的简单场景上。定义 `V(B)=N·m(B)-K_tail(B)-c_audit(B)`，其中 `m` 用 `p_eff=κ(B)p_sim(B)`。存在一个**过拟合悬崖** `B†`：越过它，`p_sim` 还在涨，但 `κ` 掉得更快，真实价值反而下降。停止规则因此不是“再训一点”，而是“边际风险调整价值 ≤ 0”。

**灵感 6（审计飞轮与商业金字塔 𝔹）**
直觉：真实部署中的失败是最贵的负样本，也是唯一能校准 `κ` 的“硬通货”。每一次审计失败都应触发：场景挖掘 → 仿真预算重分配 → 重训练 → 重认证 → 重定价。于是在第 53 轮鲁棒性金字塔 `𝕃`、第 54 轮动作协同层 `𝔸` 之上叠加 **商业层 `𝔹`**：`𝔹_0` 执行成本，`𝔹_1` 证书，`𝔹_2` 合同/保险，`𝔹_3` 市场/监管。跨层传递的不是口号，而是 `(J, κ, CVaR_β, Dom, Bond, evidence)`。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（仿真训练生产函数与证书产出）**
`Π_sim : (B, θ_fid, D_real) → C = (J, S_cov, n_audit, δ_c, E_prov)`。
- `B = Σ_z B_z` 为仿真预算，分配维度包括场景层、保真度与随机化宽度；
- `J` 为第 54 轮联合证书；
- `S_cov = P_{φ~P_task}[φ ∈ Dom(C)]` 为证书对任务分布的覆盖；
- `n_audit` 为真实审计样本量，`δ_c` 为置信度；
- `E_prov` 为可追溯证据：仿真种子、代码/模型版本、审计 ID、失败反例。
证书不是“成功率”单点，而是“在 `Dom(C)` 内、以置信度 `1-δ_c` 成立的统计承诺”。

**定义 122（仿真-现实折价与证书通胀）**
对每个场景层 `z∈Z`，令 `p_sim(z)`、`p_real(z)` 为仿真/真实成功率。
`κ(z) = LCB_{1-δ}(p_real(z)) / max(p_sim(z), ε)`，`κ = min_z κ(z)`。
有效证书 `C_eff = (J ⊙ κ, Dom(C) ∩ {z : κ(z) ≥ κ_min})`。
证书通胀 `I(z) = max(0, p_sim(z) - UCB_{1-δ}(p_real(z)))`，`I = max_z I(z)`。
`C` 商业诚实当且仅当 `I ≤ δ_inf ∧ S_cov ≥ θ_cov`。直观：`κ` 是“仿真货币”兑换“现实货币”的汇率，`I` 是汇率被系统性高估的部分。

**定义 123（风险调整后证书 RAC）**
损失 `L(φ) = c_damage + c_downtime + c_penalty + c_recert`。
`CVaR_β(L) = min_ξ [ ξ + (1/(1-β)) · E[(L-ξ)^+] ]`。
`RAC = (C_eff, Dom(C), VaR_β, CVaR_β, ε_tail, n_tail, E_prov)`。
签发条件：`CVaR_β(L) ≤ L_max ∧ S_cov ≥ θ_cov ∧ I ≤ δ_inf`。均值好但长尾坏的证书在这里被拒收。

**定义 124（商业可行性证书 BVC）**
单任务毛利 `m = r - c_exec - c_sim(B)/N - c_verify - c_audit - \bar L`，其中 `\bar L = E[L]`。
尾部资本 `K_tail = CVaR_β(L) · N_peak`，偿付余量 `S = K_cap - K_tail`。
盈亏平衡任务量 `N_be = C_fixed / max(m, ε)`。
`BVC = (m, S, N_be, S_cov, β, E_prov)`。可行当且仅当 `m ≥ m_min ∧ S ≥ 0 ∧ S_cov ≥ cov(K)`。

**定义 125（合同-证书匹配与可信信号）**
合同空间 `𝒦 = {按任务, 订阅, 按成功付费, 保险兜底}`；每类合同有支付函数 `R_K` 与责任分配 `L_K`。
`Π_K(RAC) = E[R_K] - E[C_K] - E[L_K]`。
`feasible(RAC,K) ⇔ Π_K ≥ 0 ∧ CVaR_β(L_K) ≤ L_max ∧ S_cov ≥ cov(K)`。
可信信号：供应商缴纳责任保证金 `b`，由独立分层审计验证；若 `I > δ_inf` 则没收。存在分离均衡当 `b ≥ CVaR_β(L)` 且诚实供应商的毛利足以覆盖保证金资金成本 `ρ_cap·b`；否则市场退化为“柠檬市场”，只剩最弱证书可交易。

**定义 126（商业 ROI 与仿真预算停止规则）**
`V(B) = N·m(B) - K_tail(B) - c_audit(B)`，其中 `m(B)` 使用 `p_eff(B)=κ(B)p_sim(B)`。
`B* = argmax_{B} V(B)`，约束为 `I(B) ≤ δ_inf ∧ CVaR_β(L(B)) ≤ L_max ∧ c_audit(B) ≤ A_budget`。
边际价值 `MV(B) = N·(r+\bar L)·∂p_eff/∂B - ∂K_tail/∂B - ∂c_audit/∂B - c_sim'(B)`。
**过拟合悬崖条件**：`∂p_eff/∂B = κ·∂p_sim/∂B + p_sim·∂κ/∂B`；当 `-∂κ/∂B > (κ/p_sim)·∂p_sim/∂B` 时，更多仿真训练反而降低真实价值。停止规则：`MV(B) ≤ 0` 或 `B ≥ B†`。

## 2. 关键算法 伪代码

### IP-121 SBP（Simulation Budget Planner）

```python
def sim_budget_plan(strata, B_total, r, loss, caps):
    plan, remaining = {}, B_total
    while remaining > 1e-6:
        best_z, best_mv = None, -inf
        for z in strata:
            if plan.get(z, 0.0) >= caps[z]:      # caps[z] = 过拟合悬崖 B†(z)
                continue
            b = plan.get(z, 0.0)
            mv = marginal_value(z, b, r, loss)   # N*(r+E[L])*d(p_eff)/db - dCVaR - dcost
            if mv > best_mv:
                best_z, best_mv = z, mv
        if best_mv <= 0:                         # 停止规则：不再为负边际价值训练
            break
        step = min(step_size(best_z), remaining,
                   caps[best_z] - plan.get(best_z, 0.0))
        plan[best_z] = plan.get(best_z, 0.0) + step
        remaining -= step
    return plan
```

### IP-122 SRA（Sim-to-Real Audit）

```python
def sim_to_real_audit(cert, D_audit, Z, delta, kappa_min, delta_inf):
    kappa, inflation = {}, {}
    for z in Z:
        s, n = audit_success(D_audit, z)         # held-out、分层随机
        if n == 0:
            return ('reject', 'no_audit', z)
        lcb = clopper_pearson_lower(s, n, delta / len(Z))
        ucb = clopper_pearson_upper(s, n, delta / len(Z))
        kappa[z] = lcb / max(cert.p_sim[z], 1e-9)
        inflation[z] = max(0.0, cert.p_sim[z] - ucb)
    if max(inflation.values()) > delta_inf:
        return ('discount_or_reject', kappa, inflation,
                mine_scenarios(inflation))
    dom = {z for z in Z if kappa[z] >= kappa_min}
    return ('ok', certify_effective(cert, kappa, dom))
```

### IP-123 RAC（Risk-Adjusted Certificate）

```python
def risk_adjusted_certificate(c_eff, loss_model, beta, delta_t, n_tail):
    losses = stratified_importance_sample(loss_model, c_eff.dom, n_tail)
    var_hat = quantile(losses, beta)
    cvar_hat = mean([l for l in losses if l >= var_hat])
    eps_tail = dkw_bound(losses, delta_t)
    cvar_ucb = cvar_hat + eps_tail
    if cvar_ucb > L_max:
        return ('reject', 'tail_risk', cvar_ucb)
    return ('ok', RAC(c_eff, c_eff.dom, var_hat, cvar_ucb, eps_tail))
```

### IP-125 CCM（Contract-Certificate Mechanism）

```python
def match_contract(rac, bvc, contracts, rho_cap, audit_min, N_expected):
    best = None
    for K in contracts:
        for b in bond_grid(rac.CVaR):
            if b < rac.CVaR:                         # 保证金必须覆盖尾部
                continue
            if b * rho_cap > bvc.m * N_expected:     # 诚实供应商付得起资金成本
                continue
            if not contract_tail_ok(K, rac):
                continue
            profit = expected_profit(K, rac) - b * rho_cap
            if profit <= 0:
                continue
            best = max(best, Candidate(profit, K, b, audit_min))
    return best if best else ('reject', 'no_viable_contract')
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SBP | O(\|Z\|·T·log\|Z\|) | O(\|Z\|) | 边际价值单调、悬崖上限有效 |
| SRA | O(\|D_audit\| + \|Z\|·log(1/δ)) | O(\|Z\|) | 分层随机、审计与训练独立 |
| RAC | O(n_tail + \|Z\|) | O(n_tail) | 尾部采样覆盖、CVaR 上界 |
| BVC | O(\|𝒦\|) | O(1) | 成本项闭合、资本约束 |
| CCM | O(\|𝒦\|·\|B\|) | O(\|𝒦\|) | 保证金 IC、合同责任匹配 |
| CFL | O(cycles·(SRA+RAC+BVC+CCM)) | O(\|Z\|+n_tail) | 审计闭环、通胀不累积 |

**正确性定理（Commercial-Grade Certificate Soundness）**
假设 **(A29)** 审计按部署分布分层随机抽样，且审计集与训练集独立，覆盖 `S_cov ≥ θ_cov`；**(A30)** `κ(z)` 用 Clopper–Pearson 下界估计，且 `I ≤ δ_inf`；**(A31)** 损失有界 `L ≤ L_max`，`CVaR_β` 估计误差 `ε_tail`，置信度 `1-δ_t`；**(A32)** 证书只在 `Dom(C)` 内承诺，域外无保证。
则以概率至少 `1-δ_a-δ_t`：
```
∀z∈Dom(C):  p_real(z) ≥ p_eff(z)
CVaR_β(L_real) ≤ CVaR_β(Ĺ) + ε_tail
```
若 `BVC` 以正余量通过且 `CVaR_β(Ĺ)+ε_tail ≤ L_max`，则 `Π_K ≥ 0`，且真实损失超过 `L_max` 的概率至多 `δ_t + δ_model`，其中 `δ_model` 是审计层未覆盖的模型漂移。
关键：定理**不覆盖**未审计的层；`S_cov` 是定理的前提，不是装饰。

**命题（过拟合悬崖）** 若 `-∂κ/∂B > (κ/p_sim)·∂p_sim/∂B`，则 `∂p_eff/∂B < 0`；此时继续增加仿真预算会降低真实部署价值，即使 `p_sim` 仍在上升。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 审计分布被部署漂移穿透 | 高 | 分层随机审计 + held-out + 域外免责 |
| 证书通胀 / Goodhart | 高 | `κ` 下界 + 独立审计 + 责任保证金 + 停止规则 |

## 6. 本轮最大风险

**一句话**：把仿真证书变成可定价资产后，最大的风险不是技术失败，而是**商业激励反向优化证书而非现实**——一旦审计集被训练污染或部署分布漂移穿透 `Dom(C)`，`κ` 会被系统性高估、证书通胀与责任尾部同时积累，最终以一次未承保的长尾事故清算；故必须以**独立分层审计的 κ 下界、CVaR 尾部上界、责任保证金**三根不可绕过的支柱，宁可不卖，也不卖未审计的证书。

# 第 55 轮产物 · 创新点清单 v32：MarketGround-GenSim（SBP×SRA×RAC×BVC×CCM×CFL）

## 1. 符号体系增量（新增定义 121–126）

| `S_cov` | 证书对任务分布的覆盖 `P[φ∈Dom(C)]` |

| `I(z)` | 证书通胀 `max(0, p_sim-UCB(p_real))` |
| `C_eff = J⊙κ` | 有效证书 |
| `L(φ)` | 损失：损坏+停机+罚金+重认证 |
| `CVaR_β(L)` | 尾部条件期望损失 |
| `RAC` | 风险调整后证书 |
| `m` | 单任务毛利 |
| `K_tail` | 尾部资本 `CVaR_β·N_peak` |
| `N_be` | 盈亏平衡任务量 |
| `BVC` | 商业可行性证书 |
| `𝒦` | 合同空间（按任务/订阅/按成功付费/保险兜底） |
| `b` | 责任保证金 |
| `V(B)` | 风险调整后的商业价值 |
| `B*, B†` | 最优仿真预算 / 过拟合悬崖 |

## 2. 关键算法 伪代码

### IP-121 SBP

```python
def marginal_value(z, b, r, loss):
    p, k = p_sim(z, b), kappa(z, b)
    dp, dk = d_p_sim(z, b), d_kappa(z, b)
    dpeff = k * dp + p * dk           # 过拟合悬崖：dk<0 时可压过 dp>0
    return (N[z] * (r + E_loss(z)) * dpeff
            - d_cvar(z, b) - d_c_sim(z, b) - d_c_audit(z, b))

def sim_budget_plan(strata, B_total, r, loss, caps):
    plan, remaining = {}, B_total
    while remaining > 1e-6:
        best_z, best_mv = None, -inf
        for z in strata:
            if plan.get(z, 0.0) >= caps[z]:      # caps[z] = B†(z)
                continue
            b = plan.get(z, 0.0)
            mv = marginal_value(z, b, r, loss)
            if mv > best_mv:
                best_z, best_mv = z, mv
        if best_mv <= 0:                         # 停止规则
            break
        step = min(step_size(best_z), remaining,
                   caps[best_z] - plan.get(best_z, 0.0))
        plan[best_z] = plan.get(best_z, 0.0) + step
        remaining -= step
    return plan
```

### IP-122 SRA

```python
def sim_to_real_audit(cert, D_audit, Z, delta, kappa_min, delta_inf):
    kappa, inflation = {}, {}
    for z in Z:
        s, n = audit_success(D_audit, z)         # held-out、分层随机、与训练独立
        if n == 0:
            return ('reject', 'no_audit', z)
        lcb = clopper_pearson_lower(s, n, delta / len(Z))
        ucb = clopper_pearson_upper(s, n, delta / len(Z))
        kappa[z] = lcb / max(cert.p_sim[z], 1e-9)
        inflation[z] = max(0.0, cert.p_sim[z] - ucb)
    if max(inflation.values()) > delta_inf:
        return ('discount_or_reject', kappa, inflation,
                mine_scenarios(inflation))
    dom = {z for z in Z if kappa[z] >= kappa_min}
    return ('ok', certify_effective(cert, kappa, dom))
```

### IP-123 RAC

```python
def risk_adjusted_certificate(c_eff, loss_model, beta, delta_t, n_tail):
    losses = stratified_importance_sample(loss_model, c_eff.dom, n_tail)
    var_hat = quantile(losses, beta)
    cvar_hat = mean([l for l in losses if l >= var_hat])
    eps_tail = dkw_bound(losses, delta_t)
    cvar_ucb = cvar_hat + eps_tail
    if cvar_ucb > L_max:
        return ('reject', 'tail_risk', cvar_ucb)
    return ('ok', RAC(c_eff, c_eff.dom, var_hat, cvar_ucb, eps_tail))
```

### IP-124 BVC

```python
def business_viability_certificate(rac, N, N_peak, r, costs, K_cap, m_min):
    p = rac.p_eff_lcb
    L_bar = rac.expected_loss_lcb
    m = (r - costs.exec - costs.sim_amort - costs.verify
         - costs.audit - L_bar)
    K_tail = rac.CVaR * N_peak
    S = K_cap - K_tail
    N_be = costs.fixed / max(m, 1e-9)
    ok = (m >= m_min) and (S >= 0) and (rac.coverage >= theta_cov)
    return ('ok' if ok else 'reject', BVC(m, S, N_be, p, rac))
```

### IP-125 CCM

```python
def match_contract(rac, bvc, contracts, rho_cap, audit_min, N_expected):
    best = None
    for K in contracts:
        for b in bond_grid(rac.CVaR):
            if b < rac.CVaR:                         # 保证金覆盖尾部
                continue
            if b * rho_cap > bvc.m * N_expected:     # 诚实供应商付得起资金成本
                continue
            if not contract_tail_ok(K, rac):
                continue
            profit = expected_profit(K, rac) - b * rho_cap
            if profit <= 0:
                continue
            best = max(best, Candidate(profit, K, b, audit_min))
    return best if best else ('reject', 'no_viable_contract')
```

### IP-126 CFL

```python
def commercial_flywheel(cert, D_deploy, cycles):
    history = []
    for t in range(cycles):
        audit = heldout_stratified(D_deploy, t)
        c_eff = sim_to_real_audit(cert, audit, Z, delta, kappa_min, delta_inf)
        rac = risk_adjusted_certificate(c_eff, loss_model, beta, delta_t, n_tail)
        bvc = business_viability_certificate(rac, N, N_peak, r, costs, K_cap, m_min)
        K = match_contract(rac, bvc, contracts, rho_cap, audit_min, N)
        fails = audit_failures(D_deploy, t)
        if certificate_inflation(fails) > delta_inf:
            scenarios = mine_scenarios(fails)        # 真实失败是最贵负样本
            B = sim_budget_plan(scenarios, B_total, r, loss, caps)
            cert = retrain_and_recertify(scenarios, B)
        price = update_price(K, rac, fails)
        history.append((t, rac.CVaR, bvc.m, price, cert.I))
    return history
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SBP | O(\|Z\|·T·log\|Z\|) | O(\|Z\|) | 边际价值单调、悬崖上限有效 |
| SRA | O(\|D_audit\|+\|Z\|·log(1/δ)) | O(\|Z\|) | 分层随机、审计与训练独立 |
| RAC | O(n_tail+\|Z\|) | O(n_tail) | 尾部采样覆盖、CVaR 上界 |
| BVC | O(\|𝒦\|) | O(1) | 成本项闭合、资本约束 |
| CCM | O(\|𝒦\|·\|B\|) | O(\|𝒦\|) | 保证金 IC、合同责任匹配 |
| CFL | O(cycles·(SRA+RAC+BVC+CCM)) | O(\|Z\|+n_tail) | 审计闭环、通胀不累积 |

**命题 1（过拟合悬崖）**
`∂p_eff/∂B = κ·∂p_sim/∂B + p_sim·∂κ/∂B`。当 `-∂κ/∂B > (κ/p_sim)·∂p_sim/∂B` 时，`∂p_eff/∂B < 0`：继续增加仿真预算会降低真实部署价值，尽管 `p_sim` 仍在上升。该命题给出 SBP 的硬上限 `B†`。

**命题 2（柠檬市场）**
若无 held-out 审计与责任保证金，买方只能按平均质量定价；高质量证书的持有者退出，价格进一步下降，最终只剩最弱证书可交易。若要求 `b ≥ CVaR_β(L)` 且审计频率 `≥ audit_min`，则诚实供应商的保证金资金成本可被正毛利覆盖，而虚高证书的期望罚没超过其超额收益，分离均衡存在。

**定理（Commercial-Grade Certificate Soundness）**
假设 **(A29)** 审计按部署分布分层随机抽样，且审计集与训练集独立，覆盖 `S_cov ≥ θ_cov`；**(A30)** `κ(z)` 用 Clopper–Pearson 下界估计，且 `I ≤ δ_inf`；**(A31)** 损失有界 `L ≤ L_max`，`CVaR_β` 估计误差 `ε_tail`，置信度 `1-δ_t`；**(A32)** 证书只在 `Dom(C)` 内承诺，域外无保证。
则以概率至少 `1-δ_a-δ_t`：
```
∀z∈Dom(C):  p_real(z) ≥ p_eff(z) = κ(z)·p_sim(z)
CVaR_β(L_real) ≤ CVaR_β(Ĺ) + ε_tail
```
若 `BVC` 以正余量通过且 `CVaR_β(Ĺ)+ε_tail ≤ L_max`，则合同期望利润 `Π_K ≥ 0`，且真实损失超过 `L_max` 的概率至多 `δ_t + δ_model`，其中 `δ_model` 是审计层未覆盖的模型漂移。证明要点：分层 union bound 给出 `κ` 的 LCB；有界损失 + DKW/自助法给出 `CVaR` 上界；用 `p_eff` 代替 `p_real` 是保守的；`S_cov` 把“未审计层”排除在承诺之外，故定理不能被外推到 `Dom(C)` 之外。

**解释路由 `Explain_biz`**：
- `execution_failure` → 回第 54 轮 AEC/CEC 重规划；
- `sim_gap` → SRA 场景挖掘 + SBP 预算重分配；
- `tail_event` → RAC 重估尾部 + 提高保证金/保费；
- `contract_mismatch` → CCM 重选合同。
这把第 53/54 轮的反向解释从“技术根因”扩展到“商业根因”。

## 4. 玩具数值实验（合成参数，仅检验推导自洽性）

> 说明：以下使用合成参数，不是真机数据，也不构成对真实机器人成功率的证据。目的仅是检查“证书通胀—过拟合悬崖—停止规则—尾部证书”这组推导是否在数值上自洽，并据此设计 E162–E167。

参数族：`p_sim(B)=0.70+0.28(1-e^{-B/3})`，`κ(B)=0.97/(1+(B/20)^2)`，`N=10^5`，`r=12`，`L=20`，仿真成本 `c_sim=1500B`，审计成本 `c_aud=4000+250B`。

| `B` | `p_sim` | `κ` | `p_eff` | `I` | `V(B)` |
|---:|---:|---:|---:|---:|---:|
| 0 | 0.700 | 0.970 | 0.679 | 0.021 | 148,800 |
| 2 | 0.836 | 0.960 | 0.803 | 0.033 | 542,499 |
| 4 | 0.906 | 0.933 | 0.845 | 0.061 | 673,637 |
| **4.55** | **0.919** | **0.922** | **0.847** | **0.071** | **678,930** |
| 6 | 0.942 | 0.890 | 0.838 | 0.104 | 648,342 |
| 10 | 0.970 | 0.776 | 0.753 | 0.217 | 367,232 |
| **20** | **0.980** | **0.485** | **0.475** | **0.505** | **-538,593** |

**观察 1（停止规则有效）**：仿真最优 `B_sim=20` 把 `p_sim` 从 0.919 刷到 0.980，但 `κ` 从 0.922 跌到 0.485，真实有效成功率反而从 0.847 跌到 0.475；商业价值从 +678,930 变为 -538,593，损失约 1.22M。`V` 的最优在 `B*≈4.55`，恰在过拟合悬崖 `B†≈4.55` 附近。**“仿真更强”与“商业更值钱”在这一刻分离。**

**观察 2（证书通胀可测）**：`I` 从 0.021 单调升到 0.505。若审计只覆盖简单场景，`I` 会被低估；因此 SRA 必须分层，并对稀有场景做重要性采样。E162 应直接测 `I` 的估计误差，而不是只测平均成功率。

**观察 3（均值证书 vs 尾部证书）** 用 2,000,000 次合成损失抽样比较两个策略：

| 策略 | 成功率 | 平均损失 | `VaR_99` | `CVaR_99` | `P(L≥2500)` |
|---|---:|---:|---:|---:|---:|
| A（高均值、重尾） | 0.990 | 2.544 | 1.0 | 253.4 | 0.101% |
| B（低均值、截尾） | 0.980 | 3.002 | 150.0 | 150.0 | 0% |

A 的平均损失更低（2.544 < 3.002），**均值证书会选 A**；但 A 的 `CVaR_99` 是 B 的 1.69 倍，尾部资本要求也约为 1.69 倍。**RAC 会选 B**。这验证了 H23：商业上真正致命的是尾部，而不是平均值；E163 应把“尾部损失下降”作为主指标，把平均成功率作为次指标。

**观察 4（合同匹配）**：在 A 策略下，若 `K_cap < 253.4·N_peak`，按成功付费/保险兜底合同不可行，只能降级为域内按次收费；在 B 策略下可进入按成功付费。**证书强度决定可签约等级**，这正是 CCM 要形式化的东西。

## 5. 实验设计 E162–E167（含基线与消融）

| 实验 | 基线 | 指标 | 目标 | 风险控制 |
|---|---|---|---|---|
| E162 证书通胀检测 | 仅 `p_sim`；均匀审计 | `I` 误差、过拟合 AUROC | 误差 ≤ 0.03，AUROC ≥ 0.90 | 审计与训练严格 held-out；预注册分层 |
| E163 尾部证书 | 均值证书 | `CVaR_99`、尾事故率、资本占用 | 尾部损失降 ≥ 40% | 极值理论 + 压力场景；保守上界 |
| E164 单位经济预测 | 静态成本模型 | 毛利 MAPE、`N_be` 误差 | MAPE ≤ 15%，`N_be` 误差 ≤ 20% | 成本项逐项审计；敏感性分析 |
| E165 合同-证书匹配 | 统一按任务收费 | 相对 oracle regret、逆选择损失 | regret ≤ 10%，损失降 ≥ 25% | 保证金 IC 检查；第三方审计 |
| E166 仿真预算分配 | 均匀分配 / 纯 `p_sim` 贪心 | 每 GPU·h 风险调整价值 | 提升 ≥ 30%，能定位 `B†` | 悬崖上限；非凹时用 DP |
| E167 商业飞轮 | 不审计、不重定价 | 5 轮责任损失/毛利/审计成本 | 损失降 ≥ 35%，毛利升 ≥ 15% | 审计随机化；防 Goodhart 回灌污染 |

**消融设计**：
- **A1 去 SRA**：无 held-out 审计，预期 `I` 被低估、尾部损失上升；
- **A2 去 RAC**：均值证书，预期 `CVaR_99` 与资本占用上升；
- **A3 去保证金**：预期逆选择加剧、合同违约率上升；
- **A4 去 SBP**：均匀仿真预算，预期每 GPU·h 价值下降、更容易越过 `B†`。

## 7. 本轮最大风险

**一句话**：把仿真证书变成可定价资产后，最大的风险不是技术失败，而是**商业激励反向优化证书而非现实**——一旦审计集被训练污染或部署分布漂移穿透 `Dom(C)`，`κ` 会被系统性高估、证书通胀与责任尾部同时积累，最终以一次未承保的长尾事故清算；故必须以**独立分层审计的 κ 下界、CVaR 尾部上界、责任保证金**三根不可绕过的支柱，宁可不卖，也不卖未审计的证书。
