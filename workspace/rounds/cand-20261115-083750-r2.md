# 第 4 轮（灵感循环第 4 轮；本轮灵感：「避障控制」×「ROS」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。避障与 ROS 各修一条被前几轮默认掉的物理/系统前提——运动学可停性与中间件时空基底——且任一环节不可用都必须能一键退回 InstructGauge，二者是增强项、不是依赖项。

## 0. 直觉与动机

**灵感 1（避障控制 → 被第 3 轮默认掉的「停不下来」问题）**
直觉：第 3 轮把安全寄托在「块可被二分截断到最后安全前缀」上，但这句话悄悄假设了**截断是瞬时、无惯性的**。真实的机械臂/云台有速度与加速度上界，从「决定中止」到「真正停住」需要一段刹车距离 `d_brake(v)`。于是「前缀封闭」只保证了程序合法，**并不保证物理可停**——一个合法前缀的末端可能已经贴住障碍物，根本刹不住。避障控制里的控制屏障函数（CBF）与时间-碰撞（TTC）给出正确的对象：不是一个瞬时安全集，而是一根沿时间展开的**刹车管（braking tube）**。安全条件应改写为 `h(x_t) ≥ d_brake(v_t)`，即「到障碍的距离不小于当前速度下的刹停距离」。这把第 3 轮的「证据新鲜度 K 步」补齐为「证据新鲜度 × 刹车可行性」的二维约束。

**灵感 2（ROS → 证书其实活在一个时间/坐标基底上）**
直觉：我们的 drift、grounded、receipt 都在比较「观测」与「预测」，但 ROS 式真实系统里，每个观测都带三样被默认掉的东西：**在哪个坐标系（frame）、哪个时钟域（clock）、以什么投递保证（QoS）到达**。tf2 的 transform 会过期，传感器时钟会漂移，best-effort topic 会丢包。若 TF 超龄或时钟偏斜，几何/时间一致性已失效，此时算出的 drift 再小也是**假精确**。因此证书必须从「数值证书」升级为「**基底证书**」：显式携带 `(frame_id, stamp, clock_domain, qos)`，并在基底不一致时拒绝出证，而不是继续用错位的量做判断。

**灵感 3（两者耦合 → 空间-时间有效性管 STVT）**
直觉：避障给出空间维可行性（这条轨迹在自由空间里），ROS 给出把「空间」与「时间」对齐的基底（同一 frame/clock 下才谈得上「同一时刻的位置」）。二者耦合的产物是一根**空间-时间有效性管**：块 `C` 只有在「每个时刻 t 的预测位姿都落在自由空间且未越过刹车管」并且「该预测所依赖的 TF/时钟/回执都在有效窗口内」时才可提交。第 3 轮的 CVC 只是这根管在空间维退化（无运动/无障碍）时的截面；ROS 的角色不是「又一个模块」，而是**证书的坐标系与时钟**——它让「管」可被严格定义，也让它的失效模式变得可证伪。

## 1. 研究问题（本轮要回答什么）

- **Q1（运动学安全）**：第 3 轮的「前缀封闭截断」在有限加速度下是否仍安全？需要什么额外条件（刹车 CBF / 递归可行）才能保证「任何截断点都能停在障碍前」？
- **Q2（基底一致性）**：当 TF 超龄、时钟偏斜、QoS 丢包时，drift 与 grounded 的判定会怎样失真？能否用显式基底证书把「假精确」变成「可检测的拒绝」？
- **Q3（耦合与退化）**：空间维与时间维如何合成一根可证伪的有效性管？避障盾带来的保守性会不会把探测量压成零（信息折损）？整套增强能否严格退化回 InstructGauge？

## 2. 三条设计原则（雏形，正式化见产物区定义 448–461）

**P4 刹车可行（Braking Feasibility）**
任何被提交的块，在**每个前缀末端**都必须满足 `h(x_t) ≥ d_brake(v_t)`，即当前到障碍的净距不小于按反应延迟 + 最大减速度算出的刹停距离。这样「截断」才不是抽象的停止符，而是一条真实可执行的紧急刹车轨迹。形式化方向：刹车控制屏障 `h(f(x,u)) ≥ d_brake(v')` 定义可采纳控制集 `U_safe(x)`，并证明其递归可行。

**P5 基底一致（Substrate Consistency）**
证书必须携带并核验 `(frame_id, stamp, clock_domain, qos_mask)`。TF 沿路径任一边的时效 `age > τ_tf`、时钟偏斜区间不落在容差内、或关键回执的缺失模式未被校准覆盖 ⇒ 拒绝出证并降级，而不是用错位量继续算。基底不是元数据，是**证书的前置条件**。

**P6 管包含与生命周期静默（Tube Containment & Lifecycle Quiesce）**
被提交的块其预测轨迹必须整体落入 `X_free(t) ∩ B_t`（空间-时间管），且管外推只允许在 `q_quiesce` 处发生。将 ROS2 lifecycle 的 `deactivate → cleanup` 映射为静默点，使热替换与「在途块不观察混合契约」在中间件层也有落点（延拓第 3 轮定义 439）。

## 3. 与基线的接口（如何退化）

- 运动学理想（`a_max → ∞` 或 `v ≡ 0`，`d_brake ≡ 0`）⇒ 刹车管退化为点，STVC 退化为第 3 轮 CVC，等价 InstructGauge；
- TF 恒新鲜 / 时钟完美同步 / QoS 可靠投递 ⇒ 基底证书恒真，TFA/CLC/RBC 变为直通；
- 障碍为空或 `X_free = X` ⇒ 避障盾恒通过、`ΔH_avoid = 0`，退回纯信息驱动分块；
- lifecycle 不可用 ⇒ 退回第 3 轮定义 439 的 `q_quiesce`（时间索引版）；
- 任一基底检查失败 ⇒ 回退 InstructGauge 原路径；InstructGauge 失效 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个**刹车感知的前缀封闭**口径：把「可中止」从程序性质升级为运动学可停性，给出递归可行的刹车 CBF 与块长上界；
2. 一个**基底证书**（frame/clock/QoS）与误差传播界，把 TF 超龄、时钟偏斜、缺失回执从「静默失真」变成「显式拒绝/保守膨胀」；
3. 一根**空间-时间有效性管 STVT**，统一第 3 轮的时间证据新鲜度与本轮的空间避障可行性，并给出避障盾的信息折损上界以防「安全到停止探测」；
4. 一条完整可证伪路径：E457–E470 覆盖刹车截断、管包含、TF 超龄、时钟偏斜、QoS 丢包、生命周期热替换、动态障碍、对抗基底伪造与 50Hz 时序保全。

## 5. 本轮最大风险

**一句话**：避障与 ROS 把方案的安全性外包给了**模型与基底**——刹车距离模型、障碍膨胀、TF/时钟误差界任何一项乐观，STVC 就会给出一条看起来严格、实则**假证书**的「安全管」，因此真正的残余风险在基底/模型失配下的静默失效，而非算法本身。

## 2. 形式化定义（要点）

**定义 448（配置空间、自由空间与符号距离）** 设位形空间 `X`。时刻 `t` 的障碍集 `O_t ⊆ X`（含静态与动态、按跟踪协方差做 δ-膨胀），自由空间 `X_free(t) = X \ O_t`。符号距离 `h(x) = dist(x, O_t)`（在 `X_free` 内为正）。对动态障碍，用其预测包络 `O_t^δ` 使 `h` 对跟踪误差鲁棒（定义 461）。

**定义 449（刹停距离与刹车管）** 连续形式 `d_brake(v) = v·τ_r + v²/(2 a_max)`；离散形式 `d_brake(v_t) = Σ_{i≥1} max(v_t − i·a_max·Δ, 0)·Δ`。时刻 `t` 的刹车管截面 `B_t = {x : h(x) ≥ d_brake(v_t)}`。直观：`B_t` 是「从现在开始全力刹车也还来得及」的位形集合。

**定义 450（离散时间刹车 CBF 与紧急策略）** 对控制仿射系统 `x_{t+1} = f(x_t,u_t)`，定义 `U_safe(x_t) = {u : h(f(x_t,u)) ≥ d_brake(v_{t+1})}`。`π_brake` 为最大减速度动作。**递归可行性**要求 `π_brake ∈ U_safe` 对管内的每个状态成立，这正是引理 59 的内容。CHT（control barrier function）意义上的屏障函数可取 `H(x,v) = h(x) − d_brake(v)`，要求 `H(x_{t+1}) ≥ (1−γ)H(x_t)`，`γ∈(0,1]` 给出更保守但更平滑的收缩条件。

**定义 451（空间-时间有效性管 STVT）** 对块 `C=(a_{1:K})` 与初态 `x_0`，预测轨迹 `x_t = f(x_{t-1},a_t)`。定义
`Tube(C) = {(t, x_t) : 1≤t≤K, x_t ∈ X_free(t) ∩ B_t}`。
`C` 满足 STVT 当且仅当 `∀t≤K:(t,x_t)∈Tube(C)`。与第 3 轮定义 434 的关系：STVT 是前缀封闭在「空间-时间」上的加强——不仅每个前缀合法，且每个前缀末端物理可停。

**定义 452（STVC 空间-时间有效性证书）** `STVC(C) = (BrakeCert, CVC, FrameCert, ClockCert, QoSMask)`，其中 `BrakeCert` 证明定义 450 的递归可行，`CVC` 为第 3 轮块有效性证书，`FrameCert`/`ClockCert` 分别证明 TF 与时钟基底有效，`QoSMask` 记录回执投递模式。**提交规则**：五项全过才允许执行；任一失败 ⇒ 只执行已验证安全前缀（在刹车管意义下）并出证；无法构造安全前缀 ⇒ 只执行 `π_brake` 并告警。

**定义 453（TF 森林、时效与组合误差界）** 设变换森林有边 `e`，`age(e, stamp) = now − stamp(e)`。对从 `frame_id` 到 `target` 的路径 `P`，`FrameCert` 要求 `∀e∈P: age(e) ≤ τ_tf`。组合变换的误差上界 `ε_tf = Σ_{e∈P} ε_e + L·Σ_e ϵ_rot`，其中 `ε_e` 为平移误差、`ϵ_rot` 为旋转误差经臂长 `L` 放大。`ε_tf` 直接进入障碍膨胀：`O_t^δ ← inflate(O_t, ε_tf + v_max·τ_tf)`。

**定义 454（时钟域与偏斜区间）** 每个传感器/执行器时钟域 `c_i` 满足 `|c_i(t) − c_j(t)| ≤ ρ_ij·t + b_ij`。时间戳不再视为点，而是区间 `I_stamp = [s − δ_ij, s + δ_ij]`，`δ_ij = ρ_ij·age(s) + b_ij`。drift 比较改为区间算术：只有区间整体超过 `δ_c` 才判失效（避免把时基误差误判为物理漂移）。

**定义 455（QoS 投递账本与缺失回执）** 对窗口内期望回执序列，`M_i ∈ {0,1,⊥}` 分别表示收到、确认丢失、未知；`r_i` 为该来源的可靠率。共形校准按 `mask 模式` 分层（与定义 438 同构）：`stratum = (goal 类型, 指代个数, 条件, mask 模式, QoS 类)`。缺失不回填为「通过」，而是回填为「未知」，由分层覆盖给出保守阈值。

**定义 456（ROS2 生命周期静默）** 节点状态 `LC ∈ {unconfigured, inactive, active, finalized}` 加过渡态。定义
`q_quiesce^LC ≡ (LC ∈ {inactive, finalized} 且无在途回调/动作)`。
热替换只允许在 `q_quiesce^LC`；若在 deadline 内无法达到，则先 `deactivate` 触发 `π_brake` 再到安全态，绝不带病热替换。

**定义 457（避障准入与信息折损）** `A_avoid(C) ≡ Tube(C) ≠ ∅ ∧ STVC(C)≠⊥`。标称最优块 `C*` 与避障可采纳块 `C_safe` 的信息折损 `ΔH_avoid = ΔH(C*) − ΔH(C_safe)`。要求 `ΔH_avoid ≤ ΔH_budget`，否则触发「探测器停摆」告警——安全不能以永远不动为代价。

**定义 458（空间-时间放大因子与块长）** 在定义 440 的语义熵之外，加入基底不确定性：
`κ_st = K·(H(ι|ℓ) + H(ξ_frame) + H(ξ_clock))`，`ξ_frame, ξ_clock` 为帧/时钟失配指示变量。约束 `K ≤ K_MAX^st(ι,ξ) = ⌊K₀/(1+κ_st)⌋`。

**定义 459（刹车可行块长上界）** 给定 `x_0,t_0`，`K_brake(x_0,v_0) = max{K : ∀j≤K, x_j ∈ X_free(j) ∩ B_j}`。最终块长 `K = min(K*, K_MAX^st, K_brake)`；若 `K_brake = 0`（当前已进入刹车管外）则强制先执行 `π_brake`。

**定义 460（TubeGauge 修复证书）** `RepairCert″(s) = (ι, C, STVC, receipts, claims, substrate)`，`substrate = (frame 路径与年龄, 时钟域与偏斜界, QoS 掩码)`。审计链升级为五级：指令 → 块 → 空间-时间证书 → 逐步回执 → 基底证据。

**定义 461（鲁棒障碍膨胀）** 对跟踪不确定性协方差 `Σ_t`，`O_t^δ = O_t ⊕ B(0, c·√(λ_max(Σ_t)))`（`⊕` 为 Minkowski 和，`c` 为置信倍数）。刹车管用膨胀后的 `h_δ` 计算，保证在跟踪误差界内不碰撞。

# IP-328 BCF：刹车控制屏障（离散时间，递归可行）
class BrakeCBF:
    def brake_distance(self, v, dt):
        d, vv = 0.0, v
        while vv > 0:                      # 离散积分：反应延迟后按 a_max 减速
            vv = max(vv - A_MAX * dt, 0.0)
            d += vv * dt
        return v_react * TAU_R + d         # v_react 为决策时速度

    def safe(self, x, v, obstacle, dt):
        return obstacle.distance(x) >= self.brake_distance(v, dt)

    def U_safe(self, x, u_nom, obstacle, dt):
        x2 = self.f.step(x, u_nom, dt)
        if self.safe(x2, x2.v, obstacle, dt):
            return u_nom
        u_br = self.max_brake(x)           # 投影到最大减速度动作
        if self.safe(self.f.step(x, u_br, dt), 0.0, obstacle, dt):
            return u_br
        return None                        # 已 unavoidably unsafe：进入急停/告警

# IP-329 STVC：空间-时间有效性证书
class STVC:
    def certify(self, C, x0, env, iota, frame_ctx, clock_ctx):
        if not frame_ctx.fresh(TAU_TF):    # TF 超龄 ⇒ 拒绝出证
            return None
        if not clock_ctx.consistent(TAU_CLK):
            return None
        x = x0
        for t, a in enumerate(C.actions, start=1):
            x = env.dyn.predict(x, a)
            if x not in env.free_space(t, margin=frame_ctx.eps_tf):
                return None                # 空间管（含 TF 误差膨胀）
            if not env.bcf.safe(x.pos, x.vel, env.obstacle(t), env.dt):
                return None                # 刹车管
            if drift_interval(env.obs(t), x, clock_ctx) > C.delta_c:
                return None                # 时间管（区间算术）
        return STCert(C, frame_ctx, clock_ctx, env.qos_mask())

# IP-330 TFA：TF 森林对齐与时效
class TFAligner:
    def resolve(self, frame_id, target, stamp):
        path = self.tf.lookup_path(frame_id, target)
        if path is None:
            return None
        if any(self.tf.age(e, stamp) > TAU_TF for e in path):
            return None                    # 任一边超龄 ⇒ 整条路径无效
        T = self.tf.compose(path, stamp)
        return FrameCtx(T, self.tf.error_bound(path), path)

# IP-331 RBC：QoS 感知回执总线
class ReceiptBus:
    def collect(self, topic, window, qos):

        expected = self.expected_seqs(topic, window)
        mask = [1 if s in got else (0 if qos.reliable else UNKNOWN)
                for s in expected]
        return list(got.values()), DeliveryMask(mask, self.reliability(topic))

# IP-332 CLC：时钟一致性层（区间时间戳）
class ClockLayer:
    def interval(self, stamp, domain):
        rho, b = self.skew_bound(domain)
        delta = rho * self.age(stamp) + b
        return Interval(stamp - delta, stamp + delta)

# IP-333 LCB：生命周期静默桥
def lifecycle_quiesce(node, deadline):
    node.request("deactivate")             # 不打断在途块：先 drain
    if not node.wait_state("inactive", deadline):
        node.emergency_brake()             # 无法静默 ⇒ 先刹车到安全态
        return False
    node.request("cleanup")
    return node.wait_state("finalized", deadline)

# IP-334 TubeGauge-8C
def tubegauge_8c(M, s, ell):
    out  = M.nlib.ground(ell, M.scene, M.ontology)
    iota = out[0] if out else M.default_iota
    frame = M.tfa.resolve(M.scene.frame, M.base_frame, M.clock.now())
    if frame is None:
        return M.instructgauge_fallback(s, ell, why="substrate")
    H = M.lbox.hypothesize_in_frame(s, M.dbox.R[s], iota, frame)
    C = M.iac.plan_chunk(iota, H, M.tools, M.budget_left(s), M.drift_bound(s))
    K = min(len(C.actions), M.bcf.block_len_bound(M.base_pose(s), M.state))
    C = C.truncate(K)                                   # 刹车可行块长
    stc = M.stvc.certify(C, M.base_pose(s), M.env, iota, frame, M.clock)
    if stc is None:
        C = M.bcf.brake_first(C)                        # 先减速到可停再探
        stc = M.stvc.certify(C, M.base_pose(s), M.env, iota, frame, M.clock)
    if stc is None:
        return M.instructgauge_fallback(s, ell, why="tube")
    cert = M.cvc.commit(C, M.env, iota, stc)            # CVC 叠加空间管
    receipts, mask = M.rbus.collect(M.receipt_topic, cert.boundary, QOS)
    if mask.low_coverage():
        return stub_and_red(s, "qos_unknown")           # 未知不回填为通过
    mu, Sig = M.apcal.calibrate(receipts, H, s, stratum_extra=mask.pattern())
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
        return stub_and_red(s, "cross_failed")
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s)
    if not contract_regression(new_ec):
        return stub_and_red(s, "regression")
    if lifecycle_quiesce(M.node, DEADLINE):
        M.mreg.hot_replace_at_quiescence(M.dpe, new_ec, cert.boundary)
    bind_claims(cert, iota, receipts)
    M.pquar.record(M.apcal.last_gain, realized_gain(receipts))
    return True

## 4. 推导

**引理 59（刹车前缀安全 / 递归可行）** 设每个采样时刻满足 `h(x_t) ≥ d_brake(v_t)`，紧急策略 `π_brake` 施加最大减速度。则从任意截断点 `j` 出发，刹车轨迹在停住前始终留在 `X_free`；且 `π_brake ∈ U_safe(x_j)`（递归可行）。*证明骨架*：`d_brake(v)` 是「反应延迟内匀速 + 之后最大减速」所走距离的上界；由三角不等式，`h(x_j) ≥ d_brake(v_j)` 蕴含停住点仍在障碍前。对 `d_brake` 关于 `v` 的单调性与离散递推做归纳，得到每一步 `H(x_t) ≥ 0` 保持。动态障碍下把 `h` 换成 `h_δ`（定义 461）即可。

**引理 60（STVT 可靠性）** 若 `STVC(C)` 通过，则被执行的前缀在每一步均无碰撞（含一个控制拍 `δ_t` 的检测缺口），且感知 drift 在时钟区间意义下不超过 `δ_c`。*证明*：空间维由定义 450/451 与引理 59；时间维由第 3 轮引理 52；两者在同一 `(frame, clock)` 基底上由 `FrameCert/ClockCert` 保证可比较（引理 61），故可合取。检测缺口来自采样保持，与第 3 轮一致。

**引理 61（基底误差传播与可靠性）** 若 `age(e) ≤ τ_tf` 且时钟偏斜 `≤ ρ·age + b`，则位姿误差 `≤ v_max·τ_tf + ε_tf`，drift 区间半宽 `≤ v_max·(ρ·age + b)`。若把障碍按 `ε_tf + v_max·τ_tf` 膨胀（定义 453/461），则错误姿态下的刹车管仍是真实安全管的子集；**反之**，若不膨胀，存在跟踪/时基对抗使 `STVC` 通过而真实轨迹越界（假证书）。*证明*：Lipschitz 传播（速度有界）给出误差上界；Minkowski 膨胀的单调性给出子集关系；反例由「TF 延迟 τ_tf 内目标匀速移动」构造。

**引理 62（刹车约束下的块长）** 设标称最优块长 `K*`（引理 53）。则最终块长 `K = min(K*, K_MAX^st, K_brake)`，其中 `K_brake = K_brake(x_0,v_0)` 随 `h(x_0)` 增大而增大、随 `v_0` 与障碍接近速度增大而减小、随 `a_max` 增大而增大。特别地，若 `h(x_0) < d_brake(v_0)`，则 `K_brake = 0`，必须**先刹车后探测**。*证明*：由定义 459 的可行性单调性与引理 59；比较静态由 `d_brake` 对 `v` 单调增、对 `a_max` 单调减得到。

**引理 63（缺失回执下的分层共形覆盖）** 在投递掩码模式 `m` 下用分层共形阈值，层内可交换时 `P(h*∈H | m) ≥ 1−α`；边缘覆盖 `≥ 1−α − Σ_i (1−r_i) − Σ_s π_s·TV_s`。若把缺失当「通过」，覆盖可被系统性高估（尤其缺失与难度相关时）。*证明*：把掩码并入 stratum 后回到引理 55；缺失识别项来自可靠率下界；反例取「难样本更易丢弃」的 MNAR 构造。

**引理 64（生命周期静默热替换等价）** 若热替换仅在 `q_quiesce^LC` 执行，则无在途回调/动作观察混合契约；未涉及子图逐指令等价回到第 3 轮引理 57（再回到 ToolGauge 引理 49、LeanGauge 引理 44），新增 `substrate` 仍是纯元数据投影。*证明*：`deactivate` 保证回调 drain，`cleanup` 保证资源回收；过渡态期间拒绝替换，等价性由归纳得到。

**引理 65（避障盾的保守性与信息折损界）** 刹车 CBF 只**删减**动作：`U_safe(x) ⊆ U(x)`，故不会降低安全性；若标称块已满足 STVT，则 `ΔH_avoid = 0`，避障「免费」；一般情形 `ΔH_avoid ≤ ΔH(C*) − ΔH(C_safe)` 且当 `ΔH_avoid > ΔH_budget` 时触发停摆告警（定义 457），从而避免「安全到不再探测」的退化。*证明*：可采纳集的单调性与信息增益函数的次模性给出上界；`ΔH_budget` 为预注册常数。

**引理 66（组合退化 / 身份回退）** `a_max→∞` 或 `v≡0` 时 `d_brake→0`、`B_t→X`，`STVC` 退化为 `CVC`；TF/时钟恒完美且 QoS 可靠时 `FrameCert/ClockCert/QoSMask` 恒真、TFA/CLC/RBC 直通；无障碍时 `X_free=X`、`ΔH_avoid=0`；lifecycle 不可用时 `q_quiesce^LC` 退化为定义 439 的 `q_quiesce`。因此 TubeGauge 在全部增强关闭时逐指令等价于 InstructGauge，继而 ToolGauge / LeanGauge / MODGAUGE。*证明*：逐条代入身份元素并对闭环各阶段做结构归纳（与第 3 轮引理 57 同法）。

## 8. 本轮最大风险

**一句话**：TubeGauge 的安全性完全建立在**刹车模型与 ROS 基底**之上——只要障碍膨胀、`a_max/τ_r` 或 TF/时钟误差界中任何一项被乐观估计，STVC 就会产出一条**形式严格、物理越界的假证书**；因此真正的残余风险是「基底/模型失配下的静默假安全」，必须用 E457–E459、E468 主动证伪，并保留「无法出证即刹车/回退」这条硬开关。
