### 第 1 轮灵感驱动研究记录（指令泛化 / 可扩展性）

**灵感词**：指令泛化、可扩展性

**直觉与动机**：
SRC-USC v25 已经能用七证（USMC + SMC + RMC + MCC）回答「给定一个具体计划，能不能证」。但它没有回答两个更底层的问题：其一，面对训练分布之外的新指令，证书是否仍然成立？其二，当技能数、指令模板数、机器人数一起增长时，验证成本会不会指数爆炸？现有证书几乎都是「点态」的：SMC 证一条语义地图，MCC 证一个编队，SOC/FCC/LSC 证一个本体。它们对「指令空间」没有测度，对「组合规模」没有代数。于是留下两个盲区：**指令泛化是任务空间的维度灾难，可扩展性是证书空间的维度灾难。**

把技能想成积木，把证书想成每块积木的质检报告。若质检规则对「拼接」也成立——拼完的可靠性可以由各块报告按规则算出——那么任何新拼法都能被即时判定；反之，若拼接会产生报告没写的「化学反应」，再多的单块质检也保证不了整体。**指令泛化就是「新拼法」问题，可扩展性就是「拼法数量爆炸」问题。**

核心洞见：**指令泛化与可扩展性共享同一个数学对象——证书代数。若证书在组合下闭合（构成同态），则「未见过的指令组合」无需重新学习或逐计划重验，只需对已证技能做代数求值；指令泛化因此从「枚举指令空间」降为「覆盖技能与组合规则」。可扩展性不是工程优化，而是泛化的前提。**

**三条可证伪的直觉预测**：
1. 若只对指令做全局 conformal 校准而不按意图分层（Mondrian），长尾组合（稀有技能对）的实测覆盖率会显著低于名义 1-α；按层校准后覆盖率回升，但区间变宽。
2. 若证书代数把技能当独立模块、用并集界相加风险而忽略接口/接触耦合，则组合计划的「代数通过率」会高于暴力复核通过率，出现 false-admit；耦合越强，差距越大。
3. 若用证书代数 + 规范化缓存替代逐计划重验，验证成本随技能数/计划规模呈线性而非指数增长；但缓存跨上下文误用会让 false-admit 随复用率上升。

**严谨定义（本轮采用的骨架）**：

- **定义 A（指令空间与接地）**：记指令空间为 `ℐ`，技能库为 `Π={π_1..π_K}`。接地编译器 `g: ℐ → T(Π)` 把自然语言指令编译为项代数 `T(Π)` 的项，运算符包括顺序 `;`、并行 `∥`、择一回退 `⊔` 与参数实例化 `π(θ)`。定义语义等价 `I ~ I'` 当且仅当 `g(I) ≡ g(I')`（按结合律、可交换技能上的交换律、单位元消去做项重写）。商空间 `[ℐ]=ℐ/~` 的元素称为「指令意图」。等价类必须由人可复核的改写规则生成，禁止黑箱聚类直接合并意图。
- **定义 B（指令度量）**：`d_ℐ(I,I') = λ_t·d_emb(φ(I),φ(I')) + λ_g·d_tree(g(I),g(I'))`，其中 `d_tree` 为项树编辑距离。`φ` 为语义嵌入，权重满足 `λ_t+λ_g=1`。
- **定义 C（证书半环）**：证书束 `C=(r,S,τ,p)`，其中 `r∈ℝ_+^d` 是风险/能量/时延/带宽的逐维上界，`S` 是证书有效的上下文集合，`τ` 是有效期，`p` 是出处（provenance）。定义两种组合：
  - **合取 ⊗**（顺序与并行都要求各分量同时成立）：`r_{A⊗B}=r_A+r_B`（并集界），`S=S_A∩S_B`，`τ=min(τ_A,τ_B)`；
  - **择一 ⊕**（回退/多方案任选其一）：`r_{A⊕B}=max(r_A,r_B)`，`S=S_A∪S_B`，`τ=min`。
  零元 `0=(∞,∅)`（不可行），幺元 `1=(0,𝒳)`（恒真）。逐分量 max/sum 下 `(𝒞,⊕,⊗,0,1)` 构成交换半环（dioid），从而证书可被代数求值而非枚举。
- **定义 D（证书同态）**：把 `C` 从技能提升到项代数：`C(π_i)=` 该技能证书；`C(A;B)=C(A)⊗C(B)`；`C(A∥B)=C(A)⊗C(B)`；`C(A⊔B)=C(A)⊕C(B)`；`C(π(θ))=inst(C(π),θ)` 并检查参数域。若 `C` 是项代数到证书半环的同态，则称证书体系**组合健全**；此时良构组合的证书由分量证书唯一确定，无需重验整体。
- **定义 E（指令泛化证书 IGC）**：对指令 `I`，令 `NN(I)` 为其在训练指令集中的最近邻，`q_{1-α}^{[I]}` 为 `I` 所属意图层的 Mondrian conformal 残差分位。若 (i) 叶技能覆盖，(ii) `g(I)` 是已证原语与已证组合规则的良构项，(iii) 分层 conformal 有效，则签发
  `ℙ( R(I) ≤ min{ R_alg(C(g(I))),  R̂(NN(I)) + L·d_ℐ(I,NN(I)) + q_{1-α}^{[I]} } ) ≥ 1-α_ins`。
  第一项是**组合确定性界**（不要求见过该组合），第二项是**统计近邻界**（处理参数与语义新意），`L` 为性能关于 `d_ℐ` 的 Lipschitz 常数。
- **定义 F（证书可扩展性）**：设 `n` 个组件的验证成本为 `T(n)`，摊销成本 `A(n)=T(n)/n`，标度指数 `s = d log T / d log n`。称证书体系**可扩展**当且仅当存在常数 `c` 使 `A(n) ≤ c` 且 `s ≤ 1+ε`；配合规范化与备忘录缓存，串/并行 DAG 的 `T=O(V+E)`，而逐子集枚举为 `Ω(2^K)`。
- **定义 G（层级证书 SHC）**：把指令分解为子目标 DAG，节点携带证书、边携带组合规则检查；总验证成本 `O(|V|+|E|)`，风险预算沿 DAG 的每条源-汇路径分配，且 `Σ_{v∈path} r_v ≤ r_task`。
- **定义 H（IS-USC v26）**：`Exec_v26 = Exec_v25 ∩ Fil_instr ∩ Fil_scale`，即计划同时通过 v25 七证、IGC、证书半环健全性检查与 SHC。三条退化路径：接地歧义 → 退回 v25 的字面/遥操作；代数不健全（耦合未被接口证书捕获）→ 退回逐计划暴力重验并标记高风险；规模超预算 → 只证关键路径，其余降级为监控。

**为什么两个词必须同时出现**：没有可扩展的证书代数，指令泛化只能靠枚举或重学，长尾指令必然欠覆盖；没有指令泛化（语义等价 + 分层覆盖），证书代数只能处理已枚举的模板，规模一大就空转。二者是「组合闭合性」的正反两面，必须同时成立，且不能互相补偿。

**本轮最大风险（一句话）**：证书半环把技能当独立模块、用并集界相加风险，但真实技能会通过共享接触、共享状态与共享环境产生相关失效和涌现行为——若这些交互不能被接口证书捕获，IS-USC 会随规模扩大而「越证越快、越证越错」。

## 0. 新增核心模块（在 SRC-USC v25 / IP-447 基础上扩展）

| 编号 | 名称 | 类型 | 关键改进（相对 SRC-USC v25） |
|---|---|---|---|
| IP-448 | Instruction Generalization Certificate (IGC) | 指令泛化证书 | 指令空间 `ℐ` 的接地项 `g(I)`；意图等价 `~` 与度量 `d_ℐ`；三条件：叶技能覆盖、组合规则良构、按意图层 Mondrian conformal 覆盖；泛化界取「组合确定性界」与「Lipschitz-近邻统计界」的逐维最小 |
| IP-449 | Compositional Certificate Algebra (CCA) | 证书代数 | 证书束 `C=(r,S,τ,p)` 在合取 `⊗`（风险相加/上下文交）与择一 `⊕`（风险取 max/上下文并）下构成交换半环；`C∘g` 为项代数到证书半环的同态；规范化 + 备忘录使组合验证 `O(V+E)`，替代 `Ω(2^K)` 枚举 |
| IP-450 | Scalable Hierarchical Certificate (SHC) | 可扩展层级证书 | 子目标 DAG 分解；节点证书 + 边组合规则检查；风险预算沿路径分配；显式校验摊销成本 `A(n)` 与标度指数 `s≤1+ε`；超预算时关键路径优先 |
| IP-451 | Instruction-Scalable Unified Certificate (IS-USC) | 统一准入门 v26 | `SRC-USC ∪ IGC ∪ CCA ∪ SHC`；新增 `Fil_instr` 与 `Fil_scale`；`Exec_v26 = Exec_v25 ∩ Fil_instr ∩ Fil_scale ⊆ Exec_v25`；接地歧义/代数不健全/规模超预算三条退化路径 |

版本定位：v25 解决「能力是否各有证书」；v26 不增加新的机器人能力，而是回答「证书能否覆盖没见过的指令、能否随组合规模增长」。v26 的原则是：**不可组合的证书不可泛化，不可摊销的验证不可扩展。**

## 1. 关键算法骨架（在 IP-444–447 骨架上扩展）

```python
from dataclasses import dataclass, field
from typing import Tuple, FrozenSet, Optional
import math

RISK_DIMS = ("failure", "energy", "latency", "bandwidth")
UNIVERSE = frozenset({"*"})          # 全域上下文占位

# ============================================================
# IP-449 Compositional Certificate Algebra (CCA) — 证书半环
# ============================================================
@dataclass(frozen=True)
class CertificateBundle:
    """证书束 C=(r,S,τ,p)：逐维风险上界 + 有效上下文 + 有效期 + 出处"""
    risk: Tuple[float, ...]
    support: FrozenSet[str]
    horizon: float
    provenance: Tuple[str, ...] = ()

    @staticmethod
    def zero() -> "CertificateBundle":
        return CertificateBundle(tuple(math.inf for _ in RISK_DIMS), frozenset(), 0.0)

    @staticmethod
    def one() -> "CertificateBundle":
        return CertificateBundle(tuple(0.0 for _ in RISK_DIMS), UNIVERSE, math.inf)

    def __matmul__(self, other: "CertificateBundle") -> "CertificateBundle":
        """合取 ⊗：顺序/并行均要求两者同时成立。风险并集界相加。"""
        return CertificateBundle(
            risk=tuple(a + b for a, b in zip(self.risk, other.risk)),
            support=self.support & other.support,
            horizon=min(self.horizon, other.horizon),
            provenance=self.provenance + other.provenance,
        )

    def __add__(self, other: "CertificateBundle") -> "CertificateBundle":
        """择一 ⊕：至少一个分支成立。风险取逐维 max（最坏分支）。"""
        return CertificateBundle(
            risk=tuple(max(a, b) for a, b in zip(self.risk, other.risk)),
            support=self.support | other.support,
            horizon=min(self.horizon, other.horizon),
            provenance=self.provenance + other.provenance,
        )

    def covers(self, context: FrozenSet[str]) -> bool:
        return self.support == UNIVERSE or context <= self.support

    def within(self, budget: Tuple[float, ...], slack: float = 0.0) -> bool:
        return all(r <= b + slack for r, b in zip(self.risk, budget))


class CertificateAlgebra:
    """规范化 + 备忘录求值；验证半环公理与组合健全性。"""

    def __init__(self):
        self.cache: dict = {}

    def canonical(self, term: "SkillTerm") -> "SkillTerm":
        # 结合律展平；仅在技能声明可交换时交换；单位元消去
        return term.rewrite(term.rules)

    def eval(self, term: "SkillTerm") -> CertificateBundle:
        key = (self.canonical(term).structural_hash(), frozenset(term.context))
        if key in self.cache:
            return self.cache[key]
        if term.is_leaf():
            bundle = term.skill.bundle
        elif term.op in ("seq", "par"):
            bundle = self.eval(term.left) @ self.eval(term.right)
        elif term.op == "choice":
            bundle = self.eval(term.left) + self.eval(term.right)
        else:
            raise ValueError(f"unknown op {term.op}")
        self.cache[key] = bundle
        return bundle

    @staticmethod
    def verify_semiring_axioms(samples) -> bool:
        """抽样验证结合律、交换律(⊕)、分配律、零/幺元律。"""
        for a, b, c in samples:
            if (a + b) + c != a + (b + c):
                return False
            if a + b != b + a:
                return False
            if a @ (b + c) != (a @ b) + (a @ c):
                return False
            if a @ CertificateBundle.one() != a:
                return False
            if a + CertificateBundle.zero() != a:
                return False
        return True

    def composition_sound(self, term: "SkillTerm", brute: CertificateBundle,
                          beta_corr: float) -> bool:
        """代数证书不得比暴力复核更乐观；耦合相关失效用 beta_corr 松弛。"""
        alg = self.eval(term)
        return all(a <= b + beta_corr for a, b in zip(alg.risk, brute.risk))

    def amortized_cost(self, terms) -> Tuple[float, float]:
        """返回 (摊销成本 A(n), 标度指数 s)，用于 IP-450 的可扩展性校验。"""
        ns = [len(t.nodes()) for t in terms]
        costs = [t.verify_cost(self.cache) for t in terms]
        if len(ns) < 2:
            return (costs[0] / max(ns[0], 1), 1.0)
        xs = [math.log(max(n, 1)) for n in ns]
        ys = [math.log(max(c, 1e-9)) for c in costs]
        mx, my = sum(xs) / len(xs), sum(ys) / len(ys)
        s = sum((x - mx) * (y - my) for x, y in zip(xs, ys)) / \
            max(sum((x - mx) ** 2 for x in xs), 1e-12)
        return (sum(c / n for c, n in zip(costs, ns)) / len(ns), s)


# ============================================================
# IP-448 Instruction Generalization Certificate (IGC) — 指令泛化
# ============================================================
@dataclass
class InstructionGeneralizationCertificate:
    skill_library: dict                      # name -> CertifiedSkill(bundle, postcond)
    grammar_rules: list                      # 已证组合规则 {op, precondition}
    metric: "InstructionMetric"              # d_ℐ
    conformal: "MondrianConformal"           # 按 [I] 分层的分位
    alpha_ins: float = 0.05
    lipschitz_L: float = 0.0
    eps_eq: float = 0.05                     # 语义等价容差

    def ground(self, instruction: str, context: FrozenSet[str]) -> "SkillTerm":
        return self.metric.compiler.compile(instruction, context)

    def verify_primitive_coverage(self, term: "SkillTerm") -> bool:
        for leaf in term.leaves():
            skill = self.skill_library.get(leaf.skill_id)
            if skill is None or not skill.bundle.covers(term.context):
                return False
        return True

    def verify_compositional_closure(self, term: "SkillTerm") -> bool:
        certified_ops = {r.op for r in self.grammar_rules}
        rule_of = {r.op: r for r in self.grammar_rules}
        for node in term.internal_nodes():
            if node.op not in certified_ops:
                return False
            rule = rule_of[node.op]
            if not rule.precondition(node.left.postcondition, node.right.precondition):
                return False          # 接口/前置条件不兼容
            if not rule.certified:
                return False          # 规则本身未证
        return True

    def verify_semantic_equivalence(self, i1: str, i2: str) -> bool:
        t1, t2 = self.ground(i1, UNIVERSE), self.ground(i2, UNIVERSE)
        return self.metric.tree_distance(t1, t2) <= self.eps_eq

    def certified_risk(self, instruction: str, context: FrozenSet[str],
                       nearest_residual: Tuple[float, ...],
                       nearest_dist: float) -> Tuple[float, ...]:
        term = self.ground(instruction, context)
        alg = CertificateAlgebra().eval(term)
        stat = tuple(r + self.lipschitz_L * nearest_dist
                     + self.conformal.quantile(term.stratum)
                     for r in nearest_residual)
        return tuple(min(a, s) for a, s in zip(alg.risk, stat))

    def verify(self, instruction: str, context: FrozenSet[str],
               nearest_residual: Tuple[float, ...], nearest_dist: float,
               budget: Tuple[float, ...]) -> bool:
        term = self.ground(instruction, context)
        return (self.verify_primitive_coverage(term)
                and self.verify_compositional_closure(term)
                and self.conformal.is_valid(term.stratum)
                and all(r <= b for r, b in zip(
                    self.certified_risk(instruction, context,
                                        nearest_residual, nearest_dist), budget)))


# ============================================================
# IP-450 Scalable Hierarchical Certificate (SHC) — 可扩展层级证书
# ============================================================
@dataclass
class ScalableHierarchicalCertificate:
    max_amortized: float = 1.0        # A(n) 上限（ms/节点）
    max_scale_exp: float = 1.1        # s 上限
    max_depth: int = 32
    algebra: CertificateAlgebra = field(default_factory=CertificateAlgebra)

    def decompose(self, instruction: str) -> "SubgoalDAG":
        dag = self.compiler.to_dag(instruction)
        if dag.depth() > self.max_depth:
            raise ValueError("decomposition too deep for linear-cost guarantee")
        return dag

    def verify_scaling(self, sample_terms) -> bool:
        amortized, s = self.algebra.amortized_cost(sample_terms)
        return amortized <= self.max_amortized and s <= self.max_scale_exp

    def allocate_budget(self, dag: "SubgoalDAG",
                        total: Tuple[float, ...]) -> dict:
        """沿源-汇路径按关键度分配风险预算（water-filling），和不超过 total。"""
        paths = dag.source_sink_paths()
        weight = {v: 1.0 / max(len(paths), 1) for v in dag.nodes}
        for p in paths:
            for v in p:
                weight[v] += 1.0 / len(paths)
        norm = sum(weight.values())
        return {v: tuple(t * weight[v] / norm for t in total) for v in dag.nodes}

    def verify(self, instruction: str, budget: Tuple[float, ...]) -> bool:
        dag = self.decompose(instruction)
        if not all(n.bundle is not None for n in dag.nodes):
            return False
        if not all(e.rule.certified for e in dag.edges):
            return False
        alloc = self.allocate_budget(dag, budget)
        for v in dag.nodes:
            if not dag.node_bundle(v).within(alloc[v]):
                return False
        if not self.verify_scaling(dag.sample_terms()):
            return False
        return True

@dataclass
class InstructionScalableUnifiedCertificate:
    src_usc: "SemanticReconfigCoordUnifiedCertificate"   # v25 七证
    igc: InstructionGeneralizationCertificate
    shc: ScalableHierarchicalCertificate
    algebra: CertificateAlgebra = field(default_factory=CertificateAlgebra)
    beta_corr: float = 1e-3           # 相关失效松弛

    def admits(self, multi_plan, instruction: str, context: FrozenSet[str],
               nearest_residual, nearest_dist,
               budget, sensor_data) -> bool:
        # 1. v25 七证（单机 + 语义 + 重构 + 协同）
        if not self.src_usc.admits(multi_plan, sensor_data,
                                   gt_entities=sensor_data.get("gt_entities"),
                                   queries=sensor_data.get("queries"),
                                   retrieved=sensor_data.get("retrieved")):
            return False
        # 2. 指令泛化三条件
        if not self.igc.verify(instruction, context, nearest_residual,
                               nearest_dist, budget):
            return False
        # 3. 证书半环健全性：代数证书不得优于暴力复核（含耦合松弛）
        term = self.igc.ground(instruction, context)
        brute = self._brute_force_bundle(multi_plan, term)
        if not self.algebra.composition_sound(term, brute, self.beta_corr):
            return False
        # 4. 层级可扩展性 + 预算分配
        if not self.shc.verify(instruction, budget):
            return False
        return True

    def _brute_force_bundle(self, multi_plan, term) -> CertificateBundle:
        """退化基线：逐计划重验，仅在小规模或高风险场景启用。"""
        total = CertificateBundle.zero()
        for node in term.internal_nodes():
            total = total @ self._verify_subplan(multi_plan, node)
        return total

    def _verify_subplan(self, multi_plan, node) -> CertificateBundle:
        # 复用 v25 的逐子计划验证，返回保守证书束
        return self.src_usc.usmc.verify_subplan(multi_plan, node)

# 辅助：指令度量与 Mondrian conformal
# ============================================================
class InstructionMetric:
    def __init__(self, compiler, embedder, lambda_text=0.5):
        self.compiler, self.embedder = compiler, embedder
        self.lambda_text = lambda_text

    def tree_distance(self, t1, t2) -> float:
        return self.compiler.tree_edit_distance(t1, t2)

    def distance(self, i1: str, i2: str) -> float:
        d_emb = self.embedder.distance(i1, i2)
        d_tree = self.tree_distance(
            self.compiler.compile(i1, UNIVERSE),
            self.compiler.compile(i2, UNIVERSE))
        return self.lambda_text * d_emb + (1 - self.lambda_text) * d_tree


class MondrianConformal:
    """按意图层 [I] 分层校准；稀有层与相邻层做保守池化。"""
    def __init__(self, alpha: float, min_stratum: int = 30):
        self.alpha = alpha
        self.min_stratum = min_stratum
        self.scores: dict = {}       # stratum -> sorted residuals

    def calibrate(self, stratum, residuals):
        self.scores[stratum] = sorted(residuals)

    def quantile(self, stratum) -> float:
        s = self.scores.get(stratum)
        if s is None or len(s) < self.min_stratum:
            s = self._pooled(stratum)
        if not s:
            return math.inf           # 无校准数据：拒绝而非放行
        k = math.ceil((len(s) + 1) * (1 - self.alpha))
        return s[min(k, len(s)) - 1]

    def is_valid(self, stratum) -> bool:
        return self.quantile(stratum) < math.inf

    def _pooled(self, stratum):
        merged = []
        for s in self.scores.values():
            merged.extend(s)
        return sorted(merged)
```

## 3. 正确性论证（增量）

### 引理 13（指令泛化的组合-统计二重保证）
**陈述**：若 `IGC.verify(I)=True`，则对预算 `r_task` 有 `ℙ(R(I) ≤ r_task) ≥ 1-α_ins`。

**证明**：
1. 分两种情形。情形一：`g(I)` 是已证原语与已证组合规则的良构项。由引理 14 的证书同态，`C(g(I))` 是健全的组合证书；`verify_primitive_coverage` 与 `verify_compositional_closure` 分别保证叶技能有效、内部接口前置条件兼容。此时 `R_alg(C(g(I)))` 是确定性上界，无需 `I` 出现在训练集。
2. 情形二：`I` 含新参数或新语义成分，落到统计分支。以 `NN(I)` 为锚点，在 `d_ℐ` 上使用 Lipschitz 性：`|R(I)-R(NN(I))| ≤ L·d_ℐ(I,NN(I))`；再叠加 `[I]` 层 Mondrian conformal 残差分位 `q_{1-α}^{[I]}`，由分层可交换性得 `ℙ(R(NN(I))-R̂(NN(I)) ≤ q) ≥ 1-α`。两项相加即统计界。
3. 取两支逐维最小：`min` 不会低估（两支各自是高概率上界，且一支为确定性），故最终事件包含于 `{R(I) ≤ r_task}`。对两支的失效概率用并集界合并，得 `≥1-α_ins`（`α_ins` 已含分支预算）。
∎

**注**：该引理的关键是「第一支不要求见过该组合」。这正是把指令泛化从枚举降为组合覆盖的形式化依据。

### 引理 14（证书半环的健全性与同态性）
**陈述**：`(𝒞,⊕,⊗,0,1)` 是交换半环；在接口前置条件成立的前提下，`C(g(I))` 对良构项求值是健全的风险上界，即 `R(I) ≤ eval(C(g(I)))` 逐维成立。

**证明**：
1. **半环公理**：逐分量上，`⊕=max` 构成交换幂等幺半群（单位 `-∞` 对应 `0` 的不可行语义），`⊗=+` 构成交换幺半群（单位 `0`）；分配律 `a+max(b,c)=max(a+b,a+c)` 在实数上成立。上下文集合上，`∩` 对 `∪` 分配，故 `(S,∪,∩)` 同构于集合半环。两部分的乘积仍是半环。逐维 `max/sum` 与集合运算逐点组合，故整体为交换半环。
2. **合取界**：`R(A∧B) = P(fail_A ∨ fail_B) ≤ P(fail_A)+P(fail_B) = r_A+r_B`，即 `⊗` 的加法是并集界。
3. **择一界**：`R(A∨B) ≤ max(R(A),R(B))`，因为执行的是最坏分支；上下文取并因为任一分支的有效上下文都可支撑指令。
4. **同态**：`C` 在叶上取技能证书，在运算符上与半环运算逐点对应，故 `C(A op B)=C(A) op_C C(B)`，归纳即得。
5. **健全性**：由 1-4，`eval` 给出的是各分支失效概率的合法上界；只要组合规则的前置/后置条件（接口契约）成立，组合执行不会引入证书外的新失效模式，故上界成立。
∎

**注**：第 5 步是本引理唯一的强假设。若技能间存在未被接口证书建模的耦合（相关失效、涌现接触），并集界可能低估，需要引理 15 的 `β_corr` 松弛或退化为暴力复核。

### 引理 15（可扩展性与摊销界）
**陈述**：对含 `V` 个节点、`E` 条边的规范化项 DAG，若每个不同的规范子项至多求值一次，则 `eval` 的时间为 `O(V+E)`，摊销成本 `A(n)=O(1)`；而逐子集枚举验证为 `Ω(2^K)`。

**证明**：
1. 归纳于项结构：叶节点求值 `O(1)`；内部节点在左右子项求值后做一次 `O(d)` 的半环运算（`d` 为风险维数，常数）。每个规范子项命中缓存后为 `O(1)` 查表。
2. 规范化使结构等价但书写不同的子项映射到同一 key（结合律/交换律/单位元），因此 DAG 中同构子项只算一次；总访问次数不超过 `V`，边检查不超过 `E`，故 `O(V+E)`。
3. 对 `n` 个规模同阶的指令/计划求平均，`T(n)=O(n)`，`A(n)=O(1)`，标度指数 `s=1≤1+ε`。
4. 反例下界：若不使用代数而枚举 `K` 个技能的所有子集以找可行组合，需 `2^K` 次验证，`s→∞`。
∎

### 引理 16（v26 单调退化链与规模安全）
**陈述**：`Exec_v26 ⊆ Exec_v25 ⊆ ... ⊆ Exec_v18`；且当 `β_corr` 不足或缓存失效时，系统只降级不越权。

**证明**：在引理 12 基础上增加三条退化路径：
- 指令接地歧义/语义等价误判 → `Fil_instr` 拒绝 → 退回 `Exec_v25`，以字面解析或遥操作执行，不签发新组合。
- 代数不健全/相关耦合超 `β_corr` → `composition_sound` 失败 → 退回逐计划暴力重验（小规模）或标记高风险并仅执行已直接验证过的子计划。
- 规模/预算超限 → `Fil_scale` 拒绝 → 只证关键路径，其余子目标降级为运行时监控，不进入 `Exec_v26`。
- 组合失效取交集，单调性保持。所有退化路径都减少可执行集合，故链式包含成立。
∎

### 定理（IS-USC v26 的指令泛化-规模可扩展完备性）
**陈述**：对任意多机计划 `Π` 与指令 `I`，`IS-USC.admits(Π,I)=True` 当且仅当同时满足：
(1) v25 的十项条件（物理接地、云边一致、少样本覆盖、专利保护、结构、力控、轻量化、语义、重构、协同）；
(2) 指令泛化三条件（叶覆盖、组合闭包、分层 conformal）；
(3) 证书半环健全（公理成立且代数证书不优于含 `β_corr` 的暴力复核）；
(4) 层级可扩展（`A(n)` 有界、`s≤1+ε`、预算沿 DAG 路径不超支）。

**证明**：充分性由 `admits` 的四组连言直接给出，其中 (1) 由 v25 定理保证，(2) 由引理 13，(3) 由引理 14 与 `composition_sound`，(4) 由引理 15 与 SHC 预算检查。必要性：任一条件缺失即对应一类未被缓解的风险（指令长尾、组合未证、耦合失效、规模失控），`admits` 显式返回假，故不能进入 `Exec_v26`。单调退化由引理 16 保证。
∎
