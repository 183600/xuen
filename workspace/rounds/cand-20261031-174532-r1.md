# 第 13 轮（新灵感循环第 1 轮）· LEASH：给 VLA 的末端执行器拴上「意图管 + 能量池 + 块级安全壳」

> 日期：**2026-10-31（UTC）**。赛事身份不变：宇树 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API。本轮承接第 10 轮 **FACT-VLA**、第 11 轮 **GEO-RESIDUAL**、第 12 轮 **CHUNK-SERVO**；三个灵感词是「视觉语言动作模型」「安全交互」「末端执行器控制」。本轮不推倒 CHUNK-SERVO 的「30 步规划 + 5 步伺服」，而是给它补上最危险的一层：**什么能碰、什么时候必须让、碰的时候最多注入多少能量。**

## 0. 先给结论：CHUNK-SERVO 让最后 3 厘米「有闭环」，但没有让这个闭环「有边界」

第 12 轮做对了一件关键的事：把 30 步开环 chunk 切成 5 步执行块，把接触段的反馈周期从 1 s 压到 167 ms。但它仍然默认三件事：

1. **目标一定可以碰。** 伺服误差 \(e(t)\) 只指向任务目标；它不知道旁边有人手、有非目标高物体、有桌沿。
2. **5 步块内不会出事。** 但 evaluator 会把 5 步全部执行完，chunk 内没有新观测，也没有打断机制；只保证第 1 步安全，不等于保证整块安全。
3. **修正不会把系统搞不稳定。** 视觉伺服 + 接触 + RTT 可能持续注入能量；第 12 轮没有 passivity 约束，只有增益和限幅。

反过来，如果简单加一层「对所有物体都保持安全距离」的几何 CBF，又会掉进另一个陷阱：**插入/挂杯/拉拉链这些任务，本来就必须碰到目标物。** 对所有物体一视同仁地保持 3–5 cm，机器人会永远停在最后 3 厘米之外。产物区 §6.1 的 2D 玩具验证里，纯几何安全层成功率是 **0%**，而带意图管的 LEASH 是 **100%**；这不是精度问题，是「安全层不知道哪个物体是任务的一部分」。

所以本轮的押注是 **LEASH**：

> **用 VLA 的 30 步 plan 构造一条「意图管」，把任务相关接触和非目标硬障碍分开；用头部双目构造「人类可达集 + 刹车扫掠体」的事前分离约束；用块级鲁棒 CBF-QP 对 5 步开环 chunk 做整块认证；用能量池限制接触/延迟下注入的能量；用「接触同意」状态机决定什么时候允许法向接近，什么时候让行、回撤、重定位、恢复。**

一句话对比第 12 轮：**第 12 轮让最后 3 厘米「有闭环」；本轮让这个闭环「有边界地敢动」。**

三个灵感词怎么落到方案里：

| 灵感词 | 落到哪里 | 不做什么 |
|---|---|---|
| **视觉语言动作模型** | VLA 的 30 步 plan 变成意图管；相邻 plan 的重叠一致性 \(\sigma_{plan}\) 当作免费不确定性信号；语言/演示检索给目标语义角色 | 不加载第二个学习模型；不假设能拿到 VLA 内部 attention；不把 VLA 输出当安全证书 |
| **安全交互** | 人类可达集 + 刹车扫掠体 + 分离约束；双通道人证据；让行/回撤/重定位/恢复；风险预算 | 不假设有 depth/force/tactile；不声称 100% 不碰撞；不做「加一个学习安全分类器」 |
| **末端执行器控制** | 6-DoF EE twist 的块级 CBF-QP；接触法向/切向分解；能量池 passivity；安全前缀 + 保持/回撤后缀 | 不做力矩级力控（API 没有）；不改变 API 固定 chunk size；不做 30 Hz 广域网高增益伺服 |

## 1. 直觉与动机

### 1.1 VLA 给的是「意图」，不是「安全证书」

官方 WLA 的动作头输出 30 步、30 Hz 的 action chunk。它回答的是「如果世界按我理解的方式运行，末端应该往哪走」，它不回答：

- 这条轨迹会不会碰到人？
- 目标物旁边那个高杯子能不能碰？
- 人把目标拿走后，旧 plan 还对不对？
- 接触时继续按这个刚度推，会不会把系统推入振荡？

在单模型规则下，最自然的冲动是「再训一个安全策略/残差网络」。这条路的合规风险高、数据成本高、还会把延迟进一步拉长。LEASH 的选择是：**不增加学习模型，而是把 VLA 的输出解释成一条「意图管」**——只有落在管子里、且语义角色是目标/受器的物体，才允许接触；人永远是硬障碍；其他物体永远是硬障碍。

这样做的直接好处是：

- **位置泛化**：目标移动，意图管跟着当前观测和 VLA plan 走；
- **人为干扰**：人进入工作区，不管在不在管子里，都按硬障碍处理；
- **未见物品**：外观变化由 VLA 处理，安全层只关心几何和角色；
- **不过度保守**：目标物允许接触，插入任务不会停在最后 3 厘米。

### 1.2 安全交互：把「人」从事后编辑检测变成事前约束

第 11 轮的 GEO-RESIDUAL 已经能检测「场景动了，而且不是我的动作解释的」。但编辑检测是**事后**的：等人把目标拿走、等机器人已经朝旧目标走了 0.3 s，才触发恢复。安全交互需要的是**事前**约束：

- 人的当前占据 + 最大速度可达集；
- 机器人的刹车扫掠体；
- 两者在反应时间 \(T_{react}\) 内保持分离；
- 人进入「交互泡」时，先让行，再重定位，再恢复。

API 没有 depth、没有 force/torque、没有 tactile，只有四路 RGB + 本体。所以这里不做「学习型人检测」，而做**双通道确定性证据**：

1. **动态残差**：双目点云做自运动补偿后，机器人自身连杆按 URDF 掩码去掉，剩下的动态簇就是外部运动；
2. **几何占据**：工作区内高/宽超过阈值的簇，即使暂时静止，也按硬障碍处理；
3. **时间持续性**：同一个簇连续 \(K\) 帧存在，才升格为「人候选」；短闪点不触发急停，降低误报。

任一通道超过阈值就按人处理。宁可多停，不可漏停；但用意图管豁免任务目标，避免把「目标物本身」误判成障碍。

### 1.3 末端执行器控制：API 执行的是 5 步开环 chunk，必须块级认证

这是本轮最容易被忽略、但最硬的一条接口事实：

> `action_chunk_size=5` 时，evaluator 会依次执行返回的 5 步；chunk 内没有新观测，也没有打断机制。

所以「每步 CBF」不够。第 1 步安全、第 3 步撞人，仍然是失败。LEASH 把整个 5 步 chunk 当作一个**待认证的动作序列**：

- 对每一步 \(j=0,\ldots,4\) 都施加鲁棒 CBF 约束；
- 用名义 rollout 线性化，解一个小 QP；
- 解完后用精确非线性动力学回放 5 步，检查真实 barrier；
- 若某一步不满足，就把从该步开始的后缀替换成「最后安全位姿/安全回撤」；
- 返回的 chunk 仍然是 5 步，API 不需要改。

这比「每步 QP + 祈祷」多了一次回放检查，但换来了一个可以在实验里验证的块级安全证书。

### 1.4 为什么需要能量池：安全层自己也可能把系统搞不稳定

视觉伺服 + 接触 + RTT 是一个典型的双边/力反馈式闭环。即使每一帧的几何约束都满足，控制器仍可能持续向接触注入能量，表现为：

- 接近目标时超调，撞上去再弹回来；
- 接触后法向刚度太高，和桌面/物体形成极限环；
- 延迟让相位滞后，增益越高越容易振荡。

LEASH 在命令层加一个**能量池（energy tank）**：

\[
E_{k+1}=\mathrm{clip}\left(E_k-\Delta t\,u_k^\top v_k-\Delta t\,P_{diss},\ 0,\ \bar E\right).
\]

控制器注入能量（\(u^\top v>0\)）时池子下降；池子见底就把命令缩幅或置零。这不是力控，也不替代增益调参；它是一个**命令级 passivity 监督器**，保证「安全层和伺服层加起来，不会无限往系统里灌能量」。在延迟下用保守功率上界记账，具体见产物区 §5。

### 1.5 一个必须先讲清楚的陷阱：纯几何安全层会杀死接触任务

如果对所有物体都设 \(d_{safe}=3\) cm 的硬 barrier，那么插入网线、挂杯子、拉拉链的任务在最后 3 cm 会被安全层挡住。产物区的 2D 玩具验证（T0）把这个陷阱量化了：

| 方法 | 成功率 | 碰撞率 | 最小人-机距离 p05 | 干预步比例 |
|---|---:|---:|---:|---:|
| 无安全层 | 100% | 27% | 0.067 m | 0% |
| 纯几何 CBF（目标也当硬障碍） | **0%** | 0% | 0.111 m | 93.4% |
| **LEASH（意图管 + 人硬障碍）** | **100%** | **0%** | **0.110 m** | **13.1%** |

T0 是 2D 点末端、完美人状态、无感知噪声的玩具，不是真机证据；但它把「安全 vs. 接触」的取舍暴露得很清楚：**安全层必须知道哪个物体是任务的一部分，否则它会把任务本身当成危险。**

## 2. 诊断：CHUNK-SERVO 的三个安全缺口 + 一个过度保守陷阱

把一次「人机共处失败」拆开：

```text
t0: 人把手伸向目标物 / 人进入工作区
t0+0.1s: VLA 还在用旧观测规划；它不知道“人”这件事
t0+0.1s … t0+0.3s: 5 步伺服继续朝目标走
t0+0.3s: 机器人碰到人，或者人把目标拿走
t0+0.4s: 编辑检测才发现“场景动了”
```

| 缺口/陷阱 | 表现 | LEASH 的回应 |
|---|---|---|
| **反馈对象缺口** | 伺服只对目标闭环，不对人/非目标障碍闭环 | 人/非目标硬 barrier；目标按意图管软 barrier |
| **时间缺口** | 编辑检测是事后；人进入工作区到约束生效有延迟 | 人类可达集 + 刹车扫掠体 + 反应时间预算；事前让行 |
| **稳定性缺口** | 视觉伺服 + 接触 + RTT 可能注入能量 | 能量池 + 功率记账 + 低能量缩幅 |
| **过度保守陷阱** | 纯几何 CBF 把目标也当硬障碍，接触任务 0% 成功 | 意图管 + 接触资格 + 接触同意 |
| **单模型合规缺口** | 不能加第二个学习安全模型 | 全部用确定性几何/控制；VLA 仍是唯一学习模型 |

### 3.2 执行模型与块级时间

末端离散运动学：

\[
T_{k,j+1}=T_{k,j}\exp(\Delta t\,\hat u_{k,j}),\qquad j=0,\ldots,H_c-1.
\]

一次 `get_action` 返回 \(H_c\) 步，evaluator 开环执行；反馈周期：

\[
T_{fb}=\frac{H_c}{f_c}+\tau.
\]

默认 \(H_c=5, f_c=30\) 时，\(H_c/f_c=167\) ms；若 \(\tau=50\) ms，则 \(T_{fb}\approx 217\) ms。安全约束必须覆盖整个 \(T_{fb}\)，而不是只覆盖当前一步。

### 3.3 块级鲁棒 CBF

定义块开始时的安全集：

\[
\mathcal{S}_k=\{x: h_i(x)\ge 0,\ \forall i\in\mathcal H\cup\mathcal O\cup\mathcal G\cup\mathcal W\}.
\]

对每一步 \(j\)，要求鲁棒离散 CBF 条件：

\[
h_i(T_{k,j+1})\ge (1-\alpha_i)h_i(T_{k,j})-\beta_i\,\delta_{k,j},
\]

其中

\[
\delta_{k,j}=\delta_p+\delta_t+v_h\tau_j+\frac12 a_h\tau_j^2,\qquad
\tau_j=j\Delta t+\tau
\]

是到第 \(j\) 步为止的最坏情况不确定性扩张；\(\beta_i\) 是 barrier 对位置/姿态的 Lipschitz 常数。对距离型 barrier，\(h_i(T)=\mathrm{dist}(T,\mathcal O_i)-r_i\)，一阶展开后得到线性约束：

\[
a_{i,j}^\top u_{k,j}\ge b_{i,j}.
\]

整块约束是这 \(H_c\) 组线性约束的并集。**注意**：这不是「只约束第一步」，而是对 5 步每一步都约束；这正是对 API 开环 chunk 的适配。

### 3.4 意图管与接触资格

VLA plan 给出 30 个末端位姿 \(T^{plan}_{k,j}\)。意图管定义为：

\[
\mathcal{T}_k=\bigcup_{j=0}^{H_{plan}-1}
\left\{T\in SE(3):\ \|p(T)-p^{plan}_{k,j}\|\le r_{tube}+\sigma_{plan}\right\},
\]

姿态维度用插入轴/工具轴的角锥约束；\(r_{tube}\) 由演示中成功轨迹的跟踪误差统计得到，\(\sigma_{plan}\) 是相邻两次 VLA plan 在重叠时间窗上的不一致度：

\[
\sigma_{plan}=\left\|\log\left(T^{plan,new}_{overlap}\,(T^{plan,old}_{overlap})^{-1}\right)\right\|.
\]

\(\sigma_{plan}\) 是免费的：不需要多采样，只需要比较两次 plan。若 \(\sigma_{plan}>\sigma_{max}\)，说明 VLA 在犹豫，本轮收缩意图管，关闭接触资格。

接触资格：

\[
\mathrm{Elig}(O)=
\left[\mathrm{dist}(O,\mathcal{T}_k)\le r_{tube}\right]
\land
\left[\mathrm{Role}(O)\in\{\text{target},\text{recipient}\}\right]
\land
\neg\mathrm{Human}(O).
\]

`Role` 来自语言指令 + 演示检索的目标/受器标签；若角色不确定，一律不接触（保守）。

### 3.5 人类可达集与刹车分离

人在反应时间 \(\tau_j\) 内的可达体积：

\[
\mathcal{H}_{k,j}=\mathcal{H}_k\oplus
\mathcal{B}\left(0,\ v_h\tau_j+\frac12 a_h\tau_j^2+\delta_p\right),
\]

其中 \(\oplus\) 是 Minkowski 和。机器人从当前速度以最大减速度 \(a_{max}\) 刹车的扫掠体记为 \(\mathcal{R}_{k,j}\)。硬安全条件：

\[
\mathrm{dist}\left(\mathcal{R}_{k,j},\mathcal{H}_{k,j}\right)\ge d_{safe}^{hum}.
\]

这条条件比「当前距离大于 \(d_{safe}\)」保守，但它把「刹车距离 + 人的运动 + 感知延迟」都算进去了；2D 玩具里正是这条条件把碰撞率从 27% 降到 0%。

### 3.6 能量池

\[
E_{k+1}=\mathrm{clip}\left(E_k-\Delta t\,u_k^\top v_k-\Delta t\,P_{diss},\ 0,\ \bar E\right).
\]

- \(u_k^\top v_k>0\)：控制器向机器人注入能量，池子下降；
- \(u_k^\top v_k<0\)：机器人把能量回馈给控制器，池子上升；
- \(P_{diss}\ge0\)：泄漏项，防止池子永远满格；
- 若 \(E_{k+1}<0\)：把 \(u_k\) 按比例缩到池子能承受的范围，或置零。

延迟下用保守功率上界：

\[
P_k\le \max_{s\in[t-\tau,t]}\|u_s\|\,\|v_s\|,
\]

避免用延迟前的功率「透支」池子。能量池不保证渐近稳定，但保证控制器侧注入的能量有界；这是接触安全的最低要求。

### 3.7 风险预算

每个 episode 给定风险预算 \(\rho\)（例如 0.05）。每块分配 \(\epsilon_k\)，满足：

\[
\sum_{k=0}^{K}\epsilon_k\le\rho.
\]

在感知误差近似高斯时，鲁棒边界取：

\[
\delta_k=\sigma_p\,\Phi^{-1}(1-\epsilon_k/2);
\]

分布未知时用 Chebyshev：

\[
\delta_k=\frac{\sigma_p}{\sqrt{\epsilon_k}}.
\]

风险分配按人-机距离和接触相位加权：远离人时多花风险（更敢动），接近人/接触时少花风险（更保守）。这不是硬定理，而是一个可调的设计旋钮；实验里扫 \(\rho\in\{0.01,0.05,0.1\}\)。

### 3.8 接触同意

\[
\mathrm{Consent}_k=
\mathrm{Elig}(O)
\land
\left(d_{hum}>d_{consent}\right)
\land
\left(\sigma_{pose}<\sigma_{max}\right)
\land
\left(\text{no edit for }K\text{ frames}\right)
\land
\left(E_k>E_{min}\right).
\]

- `Consent=True`：目标物用软 barrier，只限制法向速度，允许插入；
- `Consent=False`：目标物也按硬障碍处理，保持 \(d_{contact}^{min}\)；
- 人在接触泡内、编辑检测触发、位姿协方差过大、能量池过低，任一条件都会撤销同意。

## 4. LEASH 算法

### 4.1 总架构

```text
                    ┌─────────────────────────────────────────┐
                    │ Evaluator (N ports 8765..8765+N-1)      │
                    └──────────────────┬──────────────────────┘
                                       │ obs / action chunk
                                       ▼
                    ┌─────────────────────────────────────────┐
                    │ Per-port PolicyService (CPU)            │
                    │  ├─ CHUNK-SERVO: plan cache + servo     │
                    │  ├─ Intent Tube: VLA plan -> 接触资格    │
                    │  ├─ Human Reach: 双目 -> 可达集/刹车体   │
                    │  ├─ Chunk CBF-QP: 5 步整块认证           │
                    │  ├─ Energy Tank: passivity 监督          │
                    │  └─ action adapter (WLA 54D -> API 21D) │
                    └──────────────────┬──────────────────────┘
                                       │ async, batched
                                       ▼
                    ┌─────────────────────────────────────────┐
                    │ Shared VLA server (GPU)                 │
                    │  UnifoLM-WLA-1.0, 30-step chunk         │
                    └─────────────────────────────────────────┘
```

- VLA 仍只有一份；意图管、人检测、CBF-QP、能量池全是 CPU 确定性模块。
- 每个端口独立 `reset()`、独立 plan cache、独立能量池；共享的只有只读演示索引和 VLA 权重。
- API 的 `action_chunk_size` 保持 5；安全层在内部对 5 步做认证，不改变接口。

### 4.2 每块伪代码

```text
get_action(obs):
  1. 更新本体状态：T_ee, v_ee, gripper, lower_body
  2. 立体视觉：P = stereo(obs.cam_left_high, obs.cam_right_high)
     自运动补偿 + URDF 自掩码 -> 动态点 D
     双通道人证据 -> H；几何/语义 -> O, G
  3. 更新意图管 T：VLA plan + 相邻 plan 一致性 sigma_plan
  4. 更新接触资格 Elig(G) 和同意 Consent
  5. 计算名义命令 u_nom[0:H_c]（CHUNK-SERVO）
  6. 解块级 CBF-QP：
        min sum_j ||u_j - u_nom_j||^2 + lambda ||slack||_1
        s.t. 人/非目标硬约束、目标软约束、速度/加速度限幅、能量池约束
  7. 用精确非线性动力学回放 5 步，检查 barrier
     若第 j 步不满足：把 j..H_c-1 替换为最后安全位姿/安全回撤
  8. 能量池更新；若 E 见底，缩幅或置零
  9. 转成 API 需要的绝对 EE 位姿序列，返回 5 步 chunk
 10. 记录：最小安全距离、QP 可行性、干预步数、p99 延迟、同意状态
```

### 4.3 块级 QP

\[
\min_{\{u_j\},\sigma\}
\sum_{j=0}^{H_c-1}\|u_j-u^{nom}_j\|_W^2+\lambda\|\sigma\|_1
\]

s.t.

\[
\begin{aligned}
&a_{i,j}^\top u_j\ge b_{i,j}, && i\in\mathcal H\cup\mathcal O && \text{(硬约束)}\\
&a_{i,j}^\top u_j\ge b_{i,j}-\sigma_i,\ \sigma_i\ge0, && i\in\mathcal G && \text{(软约束)}\\
&\|u_j\|_\infty\le u_{max}, && && \text{(速度/加速度限幅)}\\
&u_j^\top v_j\le P_{max}(E_k), && && \text{(能量池约束)}
\end{aligned}
\]

- 硬约束不放松；软约束只对目标物开放，且 \(\sigma\) 有惩罚。
- 线性化基于名义 rollout；解完后用精确动力学回放；若违反，二分缩小步长 \(\gamma\in(0,1]\)，直到安全或 \(\gamma=0\)（保持/回撤）。
- 若硬约束不可行：优先执行「刹车 + 远离人」的 fallback；若 fallback 也不可行，说明当前状态已经不安全，进入 HOLD 并记录事件。

### 4.4 状态机

| 状态 | 触发 | 行为 | 退出 |
|---|---|---|---|
| `FREE` | 无接触资格 | 硬障碍 + 正常伺服 | 目标进入意图管 |
| `APPROACH` | `Elig=True`，`Consent=False` | 软 barrier，降速，继续对准 | 同意条件满足 |
| `CONTACT` | `Consent=True` | 法向限速、切向伺服、滑移检测 | 接触结束/同意撤销 |
| `YIELD` | 人进入交互泡 | 刹车、沿安全方向回撤、保持 | 人离开 + 稳定 K 帧 |
| `RECOVER` | 编辑检测/目标移动 | 重定位目标、更新 goal、重规划 | 置信度恢复 |
| `HOLD` | 感知不确定/QP 不可行 | 停止，等待/请求重规划 | 不确定度下降 |
| `DONE` | 任务成功/超时 | 清理状态 | `reset()` |

状态转移带滞回：`YIELD` 退出需要人离开 \(d_{yield}\) 并持续 \(K\) 帧；`CONTACT` 退出需要法向距离/滑移信号稳定，避免抖动。

### 4.5 回退

```text
if 立体无效 or 人证据冲突:
    降速；若仍不确定 -> HOLD
elif QP 不可行:
    刹车 + 远离人；若仍不可行 -> HOLD
elif 同意撤销:
    从 CONTACT 退到 YIELD/APPROACH
elif 目标移动/消失:
    RECOVER -> 重定位 -> VLA 重规划
elif 能量池 < E_min:
    降增益/缩幅；若持续低 -> 只做 PBVS 粗对齐
else:
    正常 SERVO
```

回退不是失败：它保证 `get_action` 永远返回合法、有限、形状正确的 chunk；伺服的边际收益在 A 档任务，B 档任务回退 VLA 是预期行为。

## 6. 正确性论证

### 6.1 假设

- **A1（感知界）**：立体深度/人簇误差不超过 \(\delta_p\)；由离线标定和在线置信度给出。
- **A2（人的运动界）**：人速 ≤ \(v_h\)，加速度 ≤ \(a_h\)；由保守先验设定。
- **A3（跟踪界）**：底层 EE 跟踪误差 ≤ \(\delta_t\)；由标定/风洞给出。
- **A4（初始安全）**：块开始时 \(h_i\ge0\)，且 QP 可行。
- **A5（角色正确）**：接触资格的角色标签正确；人永远不被标成目标。
- **A6（能量池）**：底层跟踪器对命令的功率不超过记账上界。

### 6.2 命题

**P1（块级安全）**：在 A1–A6 下，若每块 QP 可行或安全 fallback 可认证，且回放检查通过，则整个 5 步 chunk 执行期间 \(h_i\ge0\)。  
证明：对 \(j\) 归纳。块级约束保证每一步的鲁棒 CBF 条件；回放检查保证线性化误差不破坏精确 barrier；后缀替换只在已验证安全的前缀之后执行保持/回撤，且保持位姿本身满足同一约束。若 QP 不可行，fallback 的刹车/回撤由同一套 barrier 检查认证；若 fallback 也不可行，则当前状态已进入不安全集，或人运动/感知界 A1/A2 被违反，命题的前提不再成立。\(\square\)

**P2（非保守/通过性）**：若名义 chunk 在所有约束上都有正裕度 \(\eta>0\)，则 QP 返回 \(u^\star=u^{nom}\)，安全层不改变任务行为。  
证明：\(u^{nom}\) 可行，目标函数在 \(u^{nom}\) 处取最小值 0；slack 为 0。\(\square\)

这条命题是「安全层不拖低正常 trial」的形式化版本。它不保证永远成立——标定误差、感知噪声、人靠近都会让名义解不可行；但它给出了一个可测的验收标准：在无人、无接触的自由空间里，干预率应接近 0。

**P3（能量有界）**：在能量池投影下，\(E_k\ge0\) 对所有 \(k\) 成立；控制器侧累计注入能量不超过 \(E_0+\sum\Delta t P_{diss}\)。  
证明：若 \(E_{k+1}<0\)，投影把 \(u_k\) 缩到使 \(E_{k+1}\ge0\) 或置零；归纳得 \(E_k\ge0\)。把机器人动能 \(T_k\) 与池子能量相加，注入项被池子吸收，剩余项由 \(P_{diss}\) 耗散。\(\square\)

**P4（畅通时活性）**：若人/非目标障碍不在意图管和刹车扫掠体内，目标 `Elig=True`，且名义 chunk 满足速度/工作区/自碰撞约束，则 \(u^{nom}\) 可行，目标可达。  
证明：所有硬约束有正裕度，软约束对目标开放；P2 给出 QP 返回名义解。\(\square\)

**P5（让行）**：若人进入 \(\mathcal{H}_{k,j}\) 与刹车扫掠体的分离区，`Consent` 撤销，状态机进入 `YIELD`；若存在安全回撤方向，回撤动作由同一 QP 认证；若不存在，机器人至少不会朝人加速（约束要求 \(a^\top u\ge b\) 且 \(b\) 对应刹车）。  
注意：这不是「绝对不碰撞」；如果人瞬移进机器人本体，或感知漏检，P5 不成立。

### 6.3 不保证什么

- 不保证感知漏检时安全；人检测是单点风险。
- 不保证 QP 永远可行；不可行时只能刹车/保持。
- 不保证能量池让接触渐近稳定；它只限制注入能量。
- 不保证意图管一定正确；VLA plan 错，管子就错；人永远是硬障碍是最后防线。
- 不保证真机成功率上涨；需要 G3/G7 的 A/B 证明。

## 7. 实验设计

### 7.1 T0 玩具验证（已完成）

产物区 §6.1 给了完整的 2D 玩具协议和结果：100 次随机人-手进入，30 Hz，5 步 chunk，刹车 barrier，完美人状态。结论：

- 无安全层：100% 成功、27% 碰撞；
- 纯几何 CBF：0% 成功、0% 碰撞（目标也被当硬障碍，停在最后 3 cm 外）；
- LEASH：100% 成功、0% 碰撞、最小距离 p05 = 0.110 m、干预步 13.1%。

T0 只验证「意图管 + 人硬障碍」的控制逻辑，不验证感知、能量池、真机。

- 任务：PlugInEthernet（插入）、HangCup（挂）、ZipUp（拉链）、StackBowls（叠）、FoldTowel（变形，防回归）。

## 9. 风险与合规

| 风险 | 影响 | 缓解 |
|---|---|---|
| 人检测漏检 | 硬安全保证失效 | 双通道证据（动态 + 几何 + 持续性）；不确定即停；不声称 100% |

| 感知延迟 | 约束生效晚 | 人类可达集 + 反应时间预算；降速；p99 门 |
| 标定漂移/换机器人 | 残差变大 | 每机器人重投影校准；误差大关伺服 |
| 单模型解释 | 被判定第二个模型 | 全部确定性；C1/C2/C3 说明；提交材料可审计 |
| 评测噪声 | +1–2pp 假阳性 | 配对 A/B、bootstrap、重复实验；320 trials SE≈2.4pp |
| 安全收益不转化为成功率 | 工程白投 | 先测 human 轴和 catastrophic failure；G3/G4 不过就不提交 |

## 10. 一句话押注与最大风险

**一句话押注**：让 VLA 决定「想碰什么」，让意图管决定「允许碰什么」，让人类可达集决定「什么时候必须让」，让块级 CBF-QP 和能量池决定「怎么碰才不失控」——在不新增学习模型的前提下，把第 12 轮的最后 3 厘米闭环从「敢动」升级为「有边界地敢动」。

**最大风险（一句话）**：LEASH 的硬安全保证建立在「人/手一定被双目动态簇或几何占据检出」上，而 API 没有深度、分割或力觉；一旦人手与目标物在颜色/运动上混淆而漏检，意图管会把接触放行——这是单点故障，必须用保守包络、双通道证据和「不确定即停」兜底。

## 0. 结论与边界

### 0.1 一句话结论

CHUNK-SERVO 的 5 步执行块把最后 3 厘米从开环变成闭环，但闭环只对「目标位姿」负责，不对「人/非目标障碍」负责，也不保证 5 步整块安全。LEASH 用 VLA 的 30 步 plan 构造**意图管**，把任务相关接触与非目标硬障碍分开；用头部双目构造**人类可达集 + 刹车扫掠体**的事前分离约束；用**块级鲁棒 CBF-QP** 对 5 步开环 chunk 做整块认证；用**能量池**限制接触/延迟下注入的能量；用**接触同意**状态机决定何时允许法向接近、何时让行/回撤/重定位/恢复。VLA 仍是唯一学习模型，LEASH 全部是确定性几何/控制。

## 2. 问题形式化

### 2.1 状态、观测、动作

在一次任务 episode 内，离散时间 \(t=k\Delta t\)，\(\Delta t=1/f_c\)，默认 \(f_c=30\) Hz。观测：

\[
o_k=\left(I^{head}_k, I^{wrist,L}_k, I^{wrist,R}_k, q_k, T^{ee}_k, g_k, \ell\right),
\]

其中 \(I\) 是 RGB，\(q_k\) 是本体关节，\(T^{ee}_k\in SE(3)\) 是末端位姿，\(g_k\) 是夹爪开度，\(\ell\) 是语言指令。动作是 5 步绝对 EE 位姿序列：

\[
A_k=\left(T^{cmd}_{k,0},\ldots,T^{cmd}_{k,H_c-1}\right),\qquad H_c=5,
\]

外加夹爪和 pivot。evaluator 依次执行，chunk 内不重新观测。

### 2.2 名义控制器（承接 CHUNK-SERVO）

第 12 轮的名义命令：

\[
u^{nom}_{k,j}=u^{ff}_{k,j}+u^{servo}_{k,j},
\]

其中 \(u^{ff}\) 来自 VLA 30 步 plan 的相对动作，\(u^{servo}\) 来自演示检索的相对目标 + IBVS/PBVS。LEASH 不改变 \(u^{nom}\) 的生成，只在它外面加安全投影。

### 2.3 安全集

\[
\mathcal{S}_k=\left\{x:\ h_i(x)\ge0,\ \forall i\in\mathcal H_k\cup\mathcal O_k\cup\mathcal G_k\cup\mathcal W\right\},
\]

- \(\mathcal H_k\)：人候选占据（硬）；
- \(\mathcal O_k\)：非目标硬障碍（硬）；
- \(\mathcal G_k\)：目标/受器（软，受接触同意控制）；
- \(\mathcal W\)：工作区边界、自碰撞、关节/速度限幅（硬）。

### 2.4 块级鲁棒 CBF

对每一步 \(j=0,\ldots,H_c-1\)：

\[
h_i(T_{k,j+1})\ge(1-\alpha_i)h_i(T_{k,j})-\beta_i\delta_{k,j},
\]

\[
\delta_{k,j}=\delta_p+\delta_t+v_h\tau_j+\frac12a_h\tau_j^2,\qquad
\tau_j=j\Delta t+\tau.
\]

\(\delta_p\) 是感知误差界，\(\delta_t\) 是跟踪误差界，\(v_h,a_h\) 是人的速度/加速度界，\(\tau\) 是 RTT+推理+图像传输的等效延迟。\(\alpha_i\in[0,1]\) 控制衰减速度；\(\alpha_i=0\) 最保守（不允许 barrier 下降）。\(\beta_i\) 是 barrier 的 Lipschitz 常数。

**为什么是块级**：API 会执行整个 5 步，chunk 内没有新观测。只约束第 0 步，等于假设第 1–4 步不会出事；这在本赛事的接触任务里不成立。

### 2.5 意图管

VLA plan 给出 \(T^{plan}_{k,j}\)，\(j=0,\ldots,H_{plan}-1\)（默认 30）。意图管：

\[
\mathcal T_k=\bigcup_{j=0}^{H_{plan}-1}
\left\{T\in SE(3):\ \|p(T)-p^{plan}_{k,j}\|\le r_{tube}+\sigma_{plan},\
\mathrm{angle}(R(T),R^{plan}_{k,j})\le\theta_{tube}\right\}.
\]

\(r_{tube}\) 由演示中成功轨迹相对 VLA plan 的偏差统计（例如 95 分位）得到；\(\theta_{tube}\) 是工具轴/插入轴的角容差。\(\sigma_{plan}\) 是相邻两次 plan 在重叠时间窗上的不一致度：

\[
\sigma_{plan}=\left\|\log\left(T^{plan,new}_{overlap}(T^{plan,old}_{overlap})^{-1}\right)\right\|.
\]

它不需要多采样、不需要额外 GPU：只比较两次 VLA 调用的重叠段。若 \(\sigma_{plan}>\sigma_{max}\)，说明 VLA 在犹豫，本轮把 \(r_{tube}\) 收缩到 0，关闭接触资格，只保留硬安全。

### 2.6 接触资格

\[
\mathrm{Elig}(O)=
\left[\mathrm{dist}(O,\mathcal T_k)\le r_{tube}\right]
\land
\left[\mathrm{Role}(O)\in\{\text{target},\text{recipient}\}\right]
\land
\neg\mathrm{Human}(O).
\]

`Role` 来自语言指令、演示检索的目标/受器标签、以及当前任务阶段。若角色不确定，`Elig=False`；保守地按硬障碍处理。人永远 `Elig=False`，即使在意图管里。

### 2.7 人类可达集与刹车分离

人在反应时间 \(\tau_j\) 内的可达体积：

\[
\mathcal H_{k,j}=\mathcal H_k\oplus
\mathcal B\left(0,\ v_h\tau_j+\frac12a_h\tau_j^2+\delta_p\right).
\]

机器人从当前 twist \(v_k\) 以最大减速度 \(a_{max}\) 刹车的扫掠体：

\[
\mathcal R_{k,j}=
\left\{T_{k,j}\exp(s\hat u):\ \|u\|\le\|v_k\|,\
s\in[0,\tau_{brake}]\right\},
\quad
\tau_{brake}=\frac{\|v_k\|}{a_{max}}.
\]

硬安全条件：

\[
\mathrm{dist}\left(\mathcal R_{k,j},\mathcal H_{k,j}\right)\ge d_{safe}^{hum}.
\]

工程上把它转成速度相关的 barrier：

\[
h^{brake}_{hum}(T_k)=h_{hum}(T_k)
-\frac{c_k^2}{2a_{max}}
-\tau_{react}c_k,
\qquad
c_k=\max\left(0,-n_k^\top(v_k-v_{h,k})\right),
\]

其中 \(n_k\) 是从人到机器人的单位向量，\(c_k\) 是相对接近速度，\(\tau_{react}=H_c/f_c+\tau+\tau_{perc}\)。\(h^{brake}\ge0\) 等价于「以当前相对速度，刹车距离 + 反应距离不超过剩余间距」。

### 2.8 能量池

\[
E_{k+1}=\mathrm{clip}\left(E_k-\Delta t\,u_k^\top v_k-\Delta t\,P_{diss},\ 0,\ \bar E\right).
\]

- 控制器注入能量（\(u_k^\top v_k>0\)）→ 池子下降；
- 机器人回馈能量（\(u_k^\top v_k<0\)）→ 池子上升；
- \(P_{diss}\ge0\) 是泄漏项；
- 若 \(E_{k+1}<0\)，把 \(u_k\) 缩到 \(\gamma u_k\)，其中
  \[
  \gamma=\max\left(0,\min\left(1,\frac{E_k-\Delta t P_{diss}}{\Delta t\,u_k^\top v_k}\right)\right)
  \]
  （当 \(u_k^\top v_k>0\)），或置零。

延迟下的保守功率上界：

\[
P_k\le\max_{s\in[t-\tau,t]}\|u_s\|\,\|v_s\|.
\]

能量池容量：

\[
\bar E=\kappa_E\left(\frac12M v_{max}^2+\frac12K_0e_{max}^2\right),
\]

\(\kappa_E\approx2\)，\(M\) 是等效质量，\(K_0\) 是标称刚度，\(e_{max}\) 是最大跟踪误差。初始 \(E_0=\bar E/2\)，每任务重置。

### 2.9 风险预算

每 episode 给定 \(\rho\)。每块分配 \(\epsilon_k\)：

\[
\sum_{k=0}^{K}\epsilon_k\le\rho,\qquad
w_k=\exp(-\beta_h d_{hum,k})\left(1+\gamma_c\mathbb 1[\text{contact}]\right),\qquad
\epsilon_k=\rho\frac{w_k}{\sum_{l=0}^{K}w_l}.
\]

高斯近似：

\[
\delta_k=\sigma_p\Phi^{-1}(1-\epsilon_k/2);
\]

分布未知：

\[
\delta_k=\frac{\sigma_p}{\sqrt{\epsilon_k}}.
\]

这不是硬定理；它是一个可调的风险分配器。实验里扫 \(\rho\in\{0.01,0.05,0.1\}\)，看任务成功率、干预率、最小距离的 Pareto。

### 2.10 接触同意

\[
\mathrm{Consent}_k=
\mathrm{Elig}(O)
\land
(d_{hum}>d_{consent})
\land
(\sigma_{pose}<\sigma_{max})
\land
(\text{no edit for }K\text{ frames})
\land
(E_k>E_{min}).
\]

- `Consent=True`：目标物用软 barrier，只限制法向速度 \(n^\top u\le v_{contact}^{max}\)，切向自由；允许插入。
- `Consent=False`：目标物按硬障碍，保持 \(d_{contact}^{min}\)。
- 人在接触泡内、编辑检测触发、位姿协方差大、能量池低，任一条件撤销同意。

### 3.1 总架构

```text
                    ┌─────────────────────────────────────────┐
                    │ Evaluator (N ports 8765..8765+N-1)      │
                    └──────────────────┬──────────────────────┘
                                       │ obs / action chunk
                                       ▼
                    ┌─────────────────────────────────────────┐
                    │ Per-port PolicyService (CPU)            │
                    │  ├─ CHUNK-SERVO: plan cache + servo     │
                    │  ├─ Intent Tube: VLA plan -> 接触资格    │
                    │  ├─ Human Reach: 双目 -> 可达集/刹车体   │
                    │  ├─ Chunk CBF-QP: 5 步整块认证           │
                    │  ├─ Energy Tank: passivity 监督          │
                    │  └─ action adapter (WLA 54D -> API 21D) │
                    └──────────────────┬──────────────────────┘

                    ┌─────────────────────────────────────────┐
```

- 每个端口独立 `PolicyService`：独立 `reset()`、独立 plan cache、独立能量池、独立意图管。
- 共享 VLA server 用 session ID 区分端口；权重只有一份。

### 3.4 块级 CBF-QP 推导

以球形障碍为例。设第 \(j\) 步末端位置 \(p_j\)，障碍中心 \(p_{o,j}\)，半径 \(r_o\)，机器人半径 \(r_r\)。距离 barrier：

\[
h_j=\|p_j-p_{o,j}\|-r_o-r_r-d_{safe}.
\]

一阶预测：

\[
p_{j+1}\approx p_j+\Delta t\,R_j u_j^{trans},
\qquad
p_{o,j+1}\approx p_{o,j}+\Delta p_{o,j}.
\]

单位方向 \(n_j=(p_j-p_{o,j})/\|p_j-p_{o,j}\|\)。鲁棒 CBF：

\[
h_j+\Delta t\,n_j^\top R_j u_j^{trans}-n_j^\top\Delta p_{o,j}
\ge(1-\alpha)h_j-\beta\delta_j.
\]

整理成线性约束：

\[
\left(\Delta t\,n_j^\top R_j\right)u_j^{trans}
\ge-\alpha h_j-\beta\delta_j+n_j^\top\Delta p_{o,j}.
\]

对速度相关 barrier \(h^{brake}\)，把 \(c_j=\max(0,-n_j^\top(v_j-v_{o,j}))\) 线性化：

\[
\frac{\partial h^{brake}}{\partial v_j}
=\left(\frac{c_j}{a_{max}}+\tau_{react}\right)n_j
\quad(c_j>0).
\]

于是约束变成：

\[
\left(\Delta t\,n_j^\top R_j+\Delta t\,\frac{\partial h^{brake}}{\partial v_j}\right)u_j
\ge
-h^{brake}_j-\Delta t\,n_j^\top(v_j-v_{o,j})+n_j^\top\Delta p_{o,j}.
\]

对胶囊/多面体障碍，用最近点/支持函数代替球心；对工作区半空间，\(h=n^\top(p-p_0)-d\)，形式相同。对自碰撞，用 URDF 胶囊对，barrier 取末端到身体最近距离。

**块级 QP**：

\[
\min_{\{u_j\},\sigma}
\sum_{j=0}^{H_c-1}\|u_j-u^{nom}_j\|_W^2+\lambda\|\sigma\|_1
\]

s.t.

\[
\begin{aligned}
&a_{i,j}^\top u_j\ge b_{i,j}, && i\in\mathcal H\cup\mathcal O\cup\mathcal W && \text{(硬)}\\
&a_{i,j}^\top u_j\ge b_{i,j}-\sigma_i,\ \sigma_i\ge0, && i\in\mathcal G && \text{(软)}\\
&\|u_j\|_\infty\le u_{max}, && && \text{(限幅)}\\
&\|u_{j+1}-u_j\|_\infty\le a_{max}\Delta t, && && \text{(加速度)}\\
&u_j^\top v_j\le P_{max}(E_k), && && \text{(能量池)}
\end{aligned}
\]

变量维数 \(6H_c=30\)，约束约 \(10H_c=50\) 条；小 QP，可用 OSQP/active-set/自写投影。硬约束不放松；软约束只对目标开放。

### 3.5 线性化 + 精确回放

线性化只在名义 rollout 附近成立。LEASH 用「解 QP → 精确回放 → 二分缩步」：

```text
gamma = 1.0
for iter in range(4):
    u = solve_qp(u_nom, constraints_at_nominal)
    T_roll = rollout_exact(u * gamma)
    if all(h_i(T_roll[j]) >= 0):
        return u * gamma
    gamma *= 0.5
return fallback_hold_or_retreat()
```

- 回放用完整 \(SE(3)\) 指数映射和精确 barrier，不用线性近似。
- 若 \(\gamma=0\) 仍不安全，说明当前状态已接近/进入不安全集；执行 fallback。
- fallback 本身也要过同一套 barrier；若不可行，进入 `HOLD` 并记录。

### 3.6 能量池更新

```text
power = max over delay window of ||u_s|| * ||v_s||
if E_k - dt*power - dt*P_diss < 0:
    if u_k^T v_k > 0:
        gamma = max(0, min(1, (E_k - dt*P_diss) / (dt * u_k^T v_k)))
        u_k = gamma * u_k
    else:
        u_k = 0
E_{k+1} = clip(E_k - dt*u_k^T v_k - dt*P_diss, 0, E_bar)
```

- 能量池低时，优先降低刚度/速度，而不是直接急停；急停只在 `HOLD`/人进入时用。
- 接触段法向增益乘 0.3–0.5，切向保留；这是第 12 轮 CAC 的延续。
- 能量池不替代增益调参；它只保证注入能量有界。

### 3.7 状态机

```text
FREE ──Elig=True──▶ APPROACH ──Consent=True──▶ CONTACT
  ▲                    │                         │
  │                    │◀──同意撤销/滑移──────────┘
  │                    ▼
  └──RECOVER◀──YIELD◀──人进入交互泡
                     │
                     └──人离开 + 稳定 K 帧──▶ APPROACH
任意状态 ──感知不确定/QP 不可行──▶ HOLD
任意状态 ──任务成功/超时──▶ DONE
```

| 状态 | 允许的接触 | 速度/增益 | 退出条件 |
|---|---|---|---|
| `FREE` | 无 | 正常 | 目标进入意图管 |
| `APPROACH` | 仅目标软 barrier | 降速 30–50% | 同意满足 |
| `CONTACT` | 目标 + 法向限速 | 法向 0.3–0.5×，切向 1× | 接触结束/同意撤销/滑移 |
| `YIELD` | 无 | 刹车/回撤 | 人离开 + K 帧稳定 |
| `RECOVER` | 无 | 停止/慢速重定位 | 位姿置信度恢复 |
| `HOLD` | 无 | 停止 | 不确定度下降/重规划 |
| `DONE` | — | — | `reset()` |

### 3.8 动作适配

- WLA 54D 输出相对 EE 动作；adapter 先 compose 成 base 系绝对位姿，再按 5 步切片。
- 安全层在绝对位姿序列上工作；输出仍是 5 步绝对 EE 位姿 + gripper + pivot。
- 若替换后缀为 hold/retreat，gripper 保持当前开度（不要突然张开/闭合）；pivot 保持当前值。
- `pivot` 的 7 维语义在挑战赛 README 中未逐维定义；先用 `example_env.py` 和单任务通道验证。若不确定，先返回零 pivot，只验证双臂。
- EE 帧/TCP 可能有夹具长度偏移；用 `example_env.py` 和真实数据做一次手眼/工具坐标校准（平移 ≤1 cm、旋转 ≤2°）。

### 3.9 完整伪代码

```python
class LeashPolicy:
    def get_action(self, obs):
        state = self.update_state(obs)
        scene = self.perceive(obs, state)          # H, O, G, confidence
        plan = self.plan_cache.get(obs, state)
        tube = self.intent_tube(plan, self.prev_plan)
        eligible = self.contact_eligibility(tube, scene)
        consent = self.consent(state, scene, eligible, self.tank)

        u_nom = self.servo.nominal(obs, state, plan)   # (H_c, 6)
        u_safe, info = self.solve_chunk_qp(
            u_nom, state, scene, tube, eligible, consent
        )
        u_safe = self.certify_and_backtrack(u_safe, state, scene, tube, consent)
        u_safe = self.energy_tank.project(u_safe, state)
        chunk = self.adapter.to_api(u_safe, state, obs)
        self.log(info, state, scene, consent)
        return chunk
```

## 5. 正确性论证

### 5.1 假设

- **A1（感知界）**：立体深度/人簇误差 ≤ \(\delta_p\)；由离线标定 + 在线置信度给出。
- **A2（人的运动界）**：人速 ≤ \(v_h\)，加速度 ≤ \(a_h\)。
- **A3（跟踪界）**：底层 EE 跟踪误差 ≤ \(\delta_t\)。
- **A4（初始安全）**：块开始时 \(h_i\ge0\)，QP 可行。
- **A5（角色正确）**：接触资格的角色标签正确；人永远不被标成目标。
- **A6（能量记账）**：底层跟踪器对命令的功率不超过记账上界。

### 5.2 命题与证明

**P1（块级安全）**  
在 A1–A6 下，若每块 QP 可行或安全 fallback 可认证，且精确回放通过，则整个 5 步 chunk 执行期间 \(h_i\ge0\)。

*证明*：对 \(j=0,\ldots,4\) 归纳。块级约束保证每一步的鲁棒 CBF 条件；精确回放排除线性化误差；后缀替换只在已验证安全的前缀之后执行保持/回撤，且保持/回撤位姿本身通过同一 barrier 检查。若 QP 不可行，fallback 的刹车/回撤由同一检查认证；若 fallback 也不可行，则当前状态已进入不安全集，或人运动/感知界 A1/A2 被违反，命题的前提不再成立。\(\square\)

**P2（通过性）**  
若名义 chunk 在所有约束上都有正裕度 \(\eta>0\)，则 QP 返回 \(u^\star=u^{nom}\)，安全层不改变任务行为。

*证明*：\(u^{nom}\) 可行，目标函数在 \(u^{nom}\) 处取 0；slack 为 0；严格凸二次目标的最小值唯一。\(\square\)

P2 是「安全层不拖低正常 trial」的形式化版本。它要求标定准确、感知噪声小、人不在附近；这些条件在 G3 中测。

**P3（能量有界）**  
在能量池投影下，\(E_k\ge0\) 对所有 \(k\) 成立；控制器侧累计注入能量不超过 \(E_0+\sum\Delta t P_{diss}\)。

*证明*：若 \(E_{k+1}<0\)，投影把 \(u_k\) 缩到使 \(E_{k+1}\ge0\) 或置零；归纳得 \(E_k\ge0\)。把机器人动能 \(T_k\) 与池子能量相加，注入项被池子吸收，剩余项由 \(P_{diss}\) 耗散。\(\square\)

**P4（畅通时活性）**  
若人/非目标障碍不在意图管和刹车扫掠体内，目标 `Elig=True`，且名义 chunk 满足速度/工作区/自碰撞约束，则 \(u^{nom}\) 可行，目标可达。

*证明*：所有硬约束有正裕度，软约束对目标开放；P2 给出 QP 返回名义解。\(\square\)

**P5（让行）**  
若人进入 \(\mathcal H_{k,j}\) 与刹车扫掠体的分离区，`Consent` 撤销，状态机进入 `YIELD`；若存在安全回撤方向，回撤动作由同一 QP 认证；若不存在，机器人至少不会朝人加速。

*证明*：分离区违反意味着 \(h^{brake}_{hum}<0\)；QP 的硬约束要求下一步的 \(h^{brake}\) 不再下降，且 \(u\) 的可行域被刹车约束限制。若回撤方向可行，QP 选它；若不可行，QP 返回零/刹车，至少不增加接近速度。\(\square\)

### 5.3 不保证什么

- 不保证人检测不漏检；这是单点风险。
- 不保证 QP 永远可行；不可行时只能刹车/保持。
- 不保证能量池让接触渐近稳定；它只限制注入能量。
- 不保证意图管正确；VLA plan 错，管子就错；人永远是硬障碍是最后防线。
- 不保证真机成功率上涨；需要 G3/G7 的 A/B。
- 不保证「绝对不碰撞」；A1/A2/A5 任一被违反，P1/P5 就不成立。

### 6.1 T0 玩具验证（已完成，2D，非真机）

**目的**：验证「意图管 + 人硬障碍」是否能在不牺牲接触任务的前提下避免碰撞；同时量化纯几何 CBF 的过度保守。

**设置**：

| 项 | 值 |
|---|---|
| 末端 | 2D 点，质量 1 |
| 控制 | 30 Hz，\(H_c=5\)，\(a_{max}=5\) m/s² |
| 目标 | \((0.45,0)\)，成功阈值 1.5 cm |
| 人-手 | 半径 6 cm，在 \(x\in[0.33,0.37]\) 从 \(y=-0.4\) 进入，停 0.8 s，再退出 |
| 机器人半径 | 2 cm |

| 反应时间 | \(\tau_{react}=0.1\) s |
| 方法 | 无安全层 / 纯几何 CBF（目标也当硬障碍，3 cm barrier）/ LEASH（目标可接触，人硬障碍） |
| 试验 | 100 次随机人-手进入时机与位置；完美人状态（无感知噪声） |

**结果**：

| 方法 | 成功率 | 碰撞率 | 最小人-机距离 p05 | 平均成功时间 | 干预步比例 | 能量池最低 |
|---|---:|---:|---:|---:|---:|---:|
| 无安全层 | 100% | 27% | 0.067 m | 0.70 s | 0% | 20.00 |
| 纯几何 CBF | **0%** | 0% | 0.111 m | — | 93.4% | 20.00 |
| **LEASH** | **100%** | **0%** | **0.110 m** | **1.45 s** | **13.1%** | **19.58** |

**解读**：

- 无安全层能完成任务，但在人手进入时碰撞率 27%；这对应「VLA 不知道人」。
- 纯几何 CBF 把所有物体（包括目标）都当硬障碍，停在最后 3 cm 外，成功率 0%；这对应「安全层杀死接触任务」。
- LEASH 允许目标接触、人保持硬障碍，成功率 100%、碰撞率 0%；干预步只有 13.1%，说明它不是「一直刹车」，而是在需要时让行。
- 平均成功时间 1.45 s vs. 0.70 s：人手在场 2.0 s，等待是预期行为；真实任务 180 s 上限下可接受。

**这个实验不证明什么**：

- 完美人状态，不含感知噪声/漏检/遮挡；
- 2D 点末端，不含姿态、夹爪、接触力；
- T0 用双积分器模拟底层跟踪器；形式化部分用速度级命令 + 加速度限幅，两者在 barrier 推导上同构，但 T0 只用于相对比较；
- 能量池几乎没被压到（最低 19.58/20），没有验证接触稳定性；
- 几何基线的目标 barrier 是刻意设置的「过度保守」对照，不代表任何真实基线；
- 不能外推到真机成功率。

## 7. 竞赛策略

### 7.1 安全层值多少分

- 人为干扰轴 = 2/10 = **20%**。若 human 轴成功率 +10pp，全局约 `0.2 × 10 = +2pp`。
- 若安全层避免 10 个接触任务的 catastrophic failure，各 +10pp，全局 `10/32 × 10 ≈ +3.1pp`。
- 两项叠加的保守区间 **+2–5pp**；但安全层的价值更多是**降低方差/避免事故**，不是直接涨点。
- 320 trials 下 \(p\approx0.25\) 的单次标准误约 **2.42pp**；不要用 +1–2pp 做结论。

### 7.2 任务组合

- **A 档（伺服 + 安全优先，19 个）**：HangCup、DisconnectEthernet、ToolboxStorage、PlugCharger、Unlock、ArrangeTestTubes、OpenPillBottle、OrganizeStationery、PackBag、ZipUp、PaperCupStacking、StoreRacket、StackCups、PlugInEthernet、StackBowls、StoreEarphones、PackPhone、OrganizePencilCase、SyringeWaterTransfer。
- **B 档（VLA 优先，13 个）**：FruitCollection、PackDoll、FruitSorting、ColorArrangement、PlacePhotoFrame、OrganizeBookshelf、PickOutBatteries、OrganizeTools、FoldTowel、ArrangePlates、SpellRobot、ConveyorSorting、RemovePinnedNote。
- **C 档**：单任务通道里 \(p_t\) 接近 0 且失败在早期感知/抓取的任务；不投安全工程，保留 VLA 基线。

优先级：

\[
\mathrm{priority}_t=\frac{q_t\,\Delta_t}{c_t},
\]

- \(q_t\)：失败发生在最后 3 cm / 人干扰的比例；
- \(\Delta_t\)：伺服/安全条件增益；
- \(c_t\)：工程/评测成本。

先做 A 档中 \(q_t\) 最高、\(c_t\) 最低的 3–5 个任务；不要一次铺 19 个。

### 7.3 单任务通道协议

1. 选 5 个代表任务：PlugInEthernet、HangCup、ZipUp、StackBowls、FoldTowel。
2. 每个任务 5 次 A/B：safety off/on；同初始条件；记录成功、步骤分、耗时、p99、干预次数。
3. 通过：无碰撞；至少 3/5 任务成功率不降；FoldTowel 不回归 >5pp。
4. 再扫 \(H_c\in\{3,5,8\}\) 和 \(\rho\in\{0.01,0.05,0.1\}\)；选 p99 和成功率的折中。
5. 最后才跑 32×10 正式评测。

### 7.4 提交节奏

- W0：官方 WLA + API adapter + chunk 30 基线；单任务通道确认 token/pivot/接口。
- W1：安全基线提交（若允许多次），锁「更早提交」tie-break。
- W2–W4：意图管/人证据/块级 QP/能量池；仿真与单任务 A/B。
- W5：chunk/risk 扫描；全量干跑；合规材料。
- W6：最终提交；保留回滚开关。

若只允许一次提交：跳过 W1，W5 后再交；不要用正式 320 trials 做未验证的 A/B。

| QP 不可行 | 刹车/保持，任务中断 | fallback 认证；记录不可行率；降增益/加裕度 |
| 感知延迟 | 约束生效晚 | 人类可达集 + 反应时间预算；降速；p99 门 |
| 标定漂移/换机器人 | 残差变大 | 每机器人重投影校准；误差大关伺服 |
| 单模型解释 | 被判定第二个模型 | 全部确定性；C1/C2/C3 说明；材料可审计 |
| 评测噪声 | +1–2pp 假阳性 | 配对 A/B、bootstrap、重复实验；320 trials SE≈2.4pp |
| 安全收益不转化 | 工程白投 | 先测 human 轴和 catastrophic failure；G3/G4 不过就不提交 |
| 仿真人模型过简 | 真机恢复率低 | 多速度/多方向/遮挡；真机小规模 pilot；保守参数 |

### 8.2 单模型合规

| 模式 | 做法 | 风险 | 建议 |
|---|---|---|---|
| C1 离线标注 | 安全/相位只离线生成标签；线上只有 VLA | 最低 | 保守退路 |
| C2 确定性控制器 | 意图管、CBF-QP、能量池都是几何/控制律，无学习权重；VLA 是唯一学习模型 | 低；需说明 | **主推** |
| C3 同 checkpoint 特征 | 目标描述子用 VLA 同一 checkpoint 的 encoder | 低–中；需说明 | 需要强描述子时用 |

**禁止**：加载第二个学习策略/残差网络/独立视觉编码器做在线决策。

**合规表述**：

- LEASH 不训练、不加载第二个学习模型；
- 人检测是双目几何 + 时间差分 + URDF 掩码，无学习权重；
- 意图管是 VLA 输出的几何包络，不是新模型；
- 能量池是确定性功率记账；
- 演示检索是只读索引，不参与在线梯度/学习。

### 8.3 安全声明

- 本报告给的是**条件安全**（A1–A6 下），不是认证安全。
- 不声称「绝对不会碰撞」；人检测漏检、瞬移、遮挡都可能破坏保证。
- 不声称「能量池保证稳定」；它只限制控制器侧注入能量。
- 不声称「LEASH 一定涨点」；需要 G3/G5/G7 的 A/B。

### 9.2 与「纯几何 CBF」路线的关系

本轮候选池里出现过纯几何 CBF 安全盾的思路（把所有障碍都当硬约束）。它的最大教训是：**安全层若不知道任务目标，就会把接触任务本身当危险。** LEASH 的意图管、接触资格、接触同意就是对这个教训的直接修正；T0 玩具用 0% vs. 100% 的成功率把这个差异量化了。LEASH 不否定 CBF，而是把 CBF 的约束对象从「所有物体」改成「人/非目标硬障碍 + 目标软接触」。

### 9.3 剪枝

- 不做从零训 VLA/World Model；
- 不做完整 sim-to-real 策略训练；
- 不做第二个学习安全模型；
- 不做力/触觉闭环；
- 不做 6D 物体位姿网络；
- 不做 30 Hz 广域网高增益伺服；
- 不做「所有物体一视同仁」的纯几何安全层；
- 不把预览榜单的任务排名当难度表。

## 11. 一句话押注与最大风险

**一句话押注**：让 VLA 决定「想碰什么」，让意图管决定「允许碰什么」，让人类可达集决定「什么时候必须让」，让块级 CBF-QP 和能量池决定「怎么碰才不失控」——在不新增学习模型的前提下，把第 12 轮的最后 3 厘米闭环从「敢动」升级为「有边界地敢动」。

**最大风险（一句话）**：LEASH 的硬安全保证建立在「人/手一定被双目动态簇或几何占据检出」上，而 API 没有深度、分割或力觉；一旦人手与目标物在颜色/运动上混淆而漏检，意图管会把接触放行——这是单点故障，必须用保守包络、双通道证据和「不确定即停」兜底。
