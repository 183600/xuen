# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「嵌入式系统」×「力控」）

> R69 把「不确定性」拆成 aleatoric/epistemic，让系统学会「问」，并用流似然做了标定不可吸收的第二意见。但 R69 有一笔它自己没算的账：它把 FLUID 的实时环路写成「< 2.6ms」，却默认自己可以**作为一个软实时软件模块**被任意插入。本轮两个灵感正好戳破这个默认：
> - **力控**的接触稳定环是 1kHz（1ms）甚至更高；2.6ms 的「实时」在接触面前是**一个数量级的超时**。更致命的是，接触时刻恰恰是「最危险 + 最模糊」之处，而 R69 的信息动作 `g_probe` 只是一个被生成出来的动作，缺少一个**保证它不会把系统推入失稳**的物理层。
> - **嵌入式系统**告诉我们：实时不是平均值而是**最坏情况（WCET）**，内存不是「O(K·H)」而是**静态可证的字节数**，神经网络不是浮点原样搬上去而是**定点/量化**。R69 的 K 自适应、ODE 积分、LLM 解码在这个世界里都不能假装免费。
>
> 核心命题：**把 FLUID-RAS 从「一个会思考的策略」改造成「一套两时间尺度的实时系统」：慢平面（思考/消歧）出『认证参考』，快平面（力控/反射）保命；两者用一份 assume-guarantee 契约连接，任何预算中断都只会让慢层更保守而绝不让快层更危险；同时把『力』从单纯执行器升级为最难伪造的接地证据通道。** 命名 **FORGE-RAS**（Force-grounded, Real-time Guaranteed Embedded RAS）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我凭什么在 1ms 内既想清楚又不失控**」——智能不是把更多计算塞进环路，而是知道哪些想法必须留在慢平面、哪些反射必须焊死在快平面。

## 0. 直觉与动机

**灵感 1（嵌入式系统 → 实时是 WCET，不是平均值）**
直觉：在 PC 上「P99 < 2.6ms」是一句性能描述；在力控机器人上它是一句**危险的话**——因为控制周期是 1ms，任何一次 2.6ms 的思考都会让接触力环少算两个周期，轻则抖动、重则穿透/弹开。嵌入式系统的第一课是「用最坏情况做设计，用平均情况做宣传」。所以 FORGE 的第一条不是更聪明的策略，而是**时间分区**：把 FLUID 的每一样东西按「能否在 1ms 内确定性完成」分到两个平面，并给慢平面一个硬 WCET 预算；任何超出都必须在**中断点**产出一个合法（更保守）的部分结果，而不是让环路等它。

**灵感 2（力控 → 接触是危险，也是证据）**
直觉：R69 的证据纪律要求「k 个正交源一致」，但它能拿到的证据大多是**可被欺骗的符号通道**（表情、语言、视觉）。力是另一类东西：你无法远距离伪造一次接触的反作用力；按下多深、环境多硬、有没有打滑，全都写在力矩/电流里。于是「力」既是 R69 最缺的**接地（grounding）证据**，也是它最缺的**物理约束**。力控因此一箭双雕：`g_probe` 不再只是「生成一个探针动作」，而是「用一个受阻抗包络保护的接触去**测量**世界」——**摸一下，胜过问十句**。

**灵感 3（两时间尺度 → 分层不是并列，而是契约）**
直觉：慢层会犯错（模态幻觉、VoI 估错），所以快层绝不能盲信慢层；快层会短视（只会保命不会解题），所以慢层不能把决策全推给它。正确姿态不是「谁领导谁」，而是一份 **assume-guarantee 契约**：慢层保证「我下发的参考永远在接触安全包络内」，快层保证「只要你守约，我保证接触稳定且不越力」。契约之外互不依赖——这正是嵌入式里「分层认证」的标准做法，也让 R69 的认证可以逐层复用，而不是重新信任一整块黑箱。

**灵感 4（anytime → 中断不是失败，是降级）**
直觉：R69 的 K=1/K=4 是一个二值开关，K=4 要么跑完要么超时。但在硬实时里，**「算到一半被打断」是常态**。所以 FORGE 把慢层做成玻璃盒：给定任意计算预算 b，返回一个**在该预算下最不保守但仍合法**的结果；预算越少，结果越接近 R68 的「只收紧」。这不是工程妥协，而是一条可证的单调性：**中断越早 ⇒ λ 越大（越保守）⇒ 安全不降**。「想得越久越敢动」被形式化成一条偏序。

**灵感 5（量化 → 第三种不确定性：表征不确定性）**
直觉：R69 把 U 分成 aleatoric 与 epistemic，默认「模型是它训练时的样子」。但一旦把流速度场压到 int8/定点搬上 MCU，策略分布就**平移**了：采样出的模态可能多一个、少一个，权重也会歪。这不是世界的噪声（aleatoric），也不是「多看一眼就能消掉」的歧义（epistemic），而是**有限精度与有限算力造成的表征不确定性 U_quant**。若不管它，R69 的模态校准（ECE）会在部署后悄悄失效——**在浮点上标定，在定点上冒险**。所以 FORGE 必须给出「量化分布偏移的界」，越界即判「模态分解无效」，退回保守。

**灵感 6（接触的双刃 → 新的失稳面与新的审计对象）**
直觉：力控不是免费的证据。接触会带来碰撞、滑移、卡死、环境刚度突变；阻抗/导纳环本身可能因时延或采样抖动而失稳。更隐蔽的是：**慢层相信快层『永远安全』，而快层一旦失稳，慢层的手术刀就变成了凶器**。所以本轮必须同时交付：接触安全包络、接触状态机的可证转换、力环时延/抖动的稳定裕度、以及把「时序/量化/接触」纳入审计的新对象。否则 FORGE 不是让 FLUID 上机器人，而是给一个会思考的大脑接上了会抖的手。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（FORGE-RAS 总览与四不变式）** FORGE-RAS = (TSE, CRG, CSM, CSE, FGK, QSB, ABS, DEG, RAS-WM††)。四不变式：
(i) **时间分离**：慢平面 Σ_s（思考/消歧/规划）与快平面 Σ_f（力控/接触状态机/安全包络）在独立时间触发表上调度；Σ_f 的最小周期 T_f 为硬实时，Σ_s 的 WCET 不进入 Σ_f 的关键路径。
(ii) **契约方向性**：Σ_s→Σ_f 只传「经过 CRG 投影的参考」（位置/阻抗/力上限），Σ_f→Σ_s 只传「残差与接触事件」；Σ_f 不执行任何未经 CSE 裁剪的 Σ_s 指令。
(iii) **anytime 合法**：Σ_s 在任意中断点输出合法（更保守）部分结果；安全随计算预算单调不降（定义 318、引理 19）。
(iv) **接地证据**：接触力/事件作为独立证据源 r_contact 进入 R69 的 k-正交证据纪律；不可用时 U_epi 保持未消解并退化 R69。

**定义 311（两时间尺度与预算）** T_f 为快环周期（如 1ms），T_s = n_s·T_f 为慢环周期（如 20ms）。慢环单轮硬预算 B_s（以执行周期/最坏指令数计）；快环 WCET ≤ ρ·T_f（ρ 如 0.7 留裕度）。Σ_s 的每个子模块必须声明 WCET 上界与内存占用，并由 WCET 认证器（IP-272）静态校验。

**定义 312（认证参考调速器 CRG）** 慢平面输出参考 ζ = (x_ref, K_imp, F_max, ẋ_max)，其中 x_ref 为位置/姿态参考、K_imp 为阻抗刚度、F_max 为力上限、ẋ_max 为速度上限。CRG 是投影 Π_CSE：ζ ↦ ζ~ ∈ 𝒞_contact（定义 314），并保证：
- Π 满足幂等与单调（越界的参考只会被夹回包络，不被放大）；
- 对任意 ζ~ ∈ 𝒞_contact，快平面 Σ_f 存在一条接触稳定轨迹（定理 18 的前提）。
慢层只能通过 ζ~ 影响任务，不能直接写快环控制量（零写操作，继承 R68-i）。

**定义 313（接触状态机 CSM）** 状态 S = {APPROACH, CONTACT, SLIP, JAM, RETREAT, EMERGENCY}，带确定性转移 δ(S, e)（e 为接触事件：首次接触、力超阈、滑移检测、卡死、超时）。CSM 运行在 Σ_f，以固定优先级抢占；任何状态进入 EMERGENCY 立即把阻抗切到最柔顺/回退，且**不允许 Σ_s 在同一接触事件窗口内覆盖**（互锁）。

**定义 314（接触安全包络 CSE）** 在接触坐标系下定义可行域 𝒞_contact = {(f_n, f_t, v_n, v_t, x_n) : 0 ≤ f_n ≤ F_max, |f_t| ≤ μ̂·f_n, |v_n| ≤ v_max, |v_t| ≤ v_max, x_n ≤ x_max}，其中 μ̂ 为摩擦估计。CSE 由环境刚度/质量估计给出保守内近似（含安全裕度 δ_env）。任何 ζ 经 CRG 后必须使预测 (f, v, x) 落在 𝒞_contact 内，否则拒绝并回退。

**定义 315（力接地证据 FGK 与接地似然）** 观测接触残差 r_contact = (f_meas − f_pred(ζ~), 事件时间戳, 接触持续性)。接地似然 ℓ_ground(m) = log p(r_contact | m) 由接触物理模型给出（刚度/摩擦/几何一致性）。与 R69 证据集合并：ℰ_FORGE = ℰ_FLUID ∪ {r_contact}。**关键区分**：r_contact 是「物理反作用」，不能被语言/表情通道伪造，故在证据图中与符号通道近似条件独立（A100）。

**定义 316（接地信息增益与探针最优）** 接触消歧收益 VoI_contact(g_probe) = H(M|o) − E_{r_contact}[H(M|o, r_contact)]，受 CSE 与力预算约束。探针策略：g_probe* = argmax_g [VoI_contact(g) − c_touch(g)]，s.t. g ∈ 𝒞_contact。若接触本身高风险（环境近奇异/刚度未知）则 VoI_contact 打折（风险惩罚），退回语言/视觉或 R69 兜底。

**定义 317（表征不确定性 U_quant 与分布偏移界）** 设浮点策略分布 P、定点/量化部署分布 Q。量化误差界 ε_q（权重/激活/累积位宽），速度场 Lipschitz 常数 L_v，ODE 步数 N，则存在常数 C 使 W_2(P, Q) ≤ C·L_v·ε_q·√N（引理 21）。定义 U_quant 为该上界估计；当 U_quant > τ_q 时，模态分解与 VoI 判定**失效**，强制走定义 307 的保守退避（与 R69 的 MCG 同级，但触发源是「部署数值」而非「数据分布」）。

**定义 318（anytime 预算采样器 ABS 与结果格）** 给定剩余预算 b，ABS 按优先级产出样本/模态/精化：先 K=1 单样本与 mode_head 廉价估计，再用剩余预算加样本/聚类/似然。定义结果格 (ℛ, ⊑)：r_lo（仅单样本，最保守）⊑ … ⊑ r_hi（K 大 + VoI 精算）。中断于任意点输出所在层的**合法下界** r。安全序：r 越「低」⇒ λ_floor 越大 ⇒ 风险越小。ABS 保证：∀ 中断点，输出 ∈ ℛ 且满足定义 307 的安全侧。

**定义 319（接触接地消歧 CGD）** 当 U_epi 高且存在物理可探测的模态差异时，优先选择**接触型信息动作**（轻触/扫掠/推拉微小位移）而非语言问句：候选 g 按「信息增益/风险/预算」排序，接触优先当且仅当 VoI_contact ≥ VoI_ask 且 risk(g_probe) ≤ ε_int。回答不是「人说的话」，而是「力/位移的测量」，因此天然满足定义 293-iii 的证据纪律（物理源与符号源正交）。

**定义 320（两时间尺度证据纪律）** 定案条件升级：至少一个**物理接地源**（r_contact）与一个符号/视觉源一致，或两个物理源一致且 VoI 增益超过高置信阈值；单次接触/单句话仍不得单独定案（防止「摸错一次」）。物理源故障（传感器饱和/漂移）计入 ℰ_FORGE 的接触欺骗集。

**定义 321（时间触发调度与 WCET 认证）** 采用静态优先级/时间触发表：WCET_f 与 Σ_s 各微步 WCET 满足可调度性判据（响应时间分析，utilization ≤ 1）。Σ_s 被切分为可抢占微步，每步独立 WCET；不允许动态内存分配、锁等待、无界循环；队列长度固定。认证器输出 J_time（每微步 WCET、上下文切换开销、抖动上界）。

**定义 322（分级降级阶梯 DEG）** 资源/置信/接触风险越界时按序降级：L0 完整 FORGE（慢层全开 + 接触探询）→ L1 关 LLM 问句、仅视觉/接触 → L2 关 VoI 交互、仅 R69 二分 → L3 R68 纯保守（λ_floor）→ L4 快层独占、慢层停机（接触安全优先）。每级有明确触发条件与可证的安全不降（引理 19／定理 19）。

**定义 323（FORGE 证书 J_FORGE）** J_FORGE = (J_FLUID, J_time, quant_shift_bound, contact_envelope_margin, csm_transition_hash, degradation_level, forge_ver)。Valid ⇔ Valid(J_FLUID) ∧ WCET 满足 ∧ U_quant ≤ τ_q ∧ 接触包络裕度 > δ_env ∧ CSM 无非法转移。

**定义 324（嵌入式审计 VQAuditor-E）** 审计对象新增：慢层是否超预算仍下发、CRG 是否被旁路、量化是否使模态失效仍驱动交互、接触事件是否被正确互锁、降级是否及时且可追溯。结论回灌 AuditBuf 与下一轮预算先验。

**定义 325（接触欺骗干扰集 ℰ_contact）** 环境侧：柔性/可变形表面伪装刚度、摩擦突变、粘滑、传感器饱和/漂移；对手侧：用可控表面在探针时改变反作用力以诱导错误模态。并入 AIC：ℰ_FORGE = ℰ_FLUID × ℰ_contact × ℰ_embed（WCET 超限／量化翻转／调度抖动）。

# IP-264 TSE：两时间尺度执行器（快环 1kHz，慢环 20ms；严格时间隔离）
class TwoTimescaleExec:
    def fast_tick(self, t, obs_f):                    # 硬实时，WCET_f <= rho*T_f
        s    = self.csm.step(obs_f)                   # 接触状态机（定义 313）
        zeta = self.crg.clamp(self.latest_zeta)       # CRG 投影到 CSE（定义 312/314）
        u    = self.force_ctrl(zeta, obs_f)           # 阻抗/导纳 + 力限幅
        ev   = self.contact_event(s, obs_f)           # 接触事件检测
        self.ring.push(ev, obs_f)                     # 固定长度，无动态分配
        return u, s, ev

    def slow_tick(self, budget):                      # 软实时，硬预算 B_s（定义 318）
        out  = self.abs.anytime(self.obs_s, budget)   # 任意中断点返回合法下界
        zeta = self.crg.project(out.zeta_raw)         # 越界即夹回/拒绝
        if self.qsb.check(self.qbound) and self.mcg.ok():
            self.latest_zeta = zeta
        else:
            self.deg.drop_to("L3")                    # 量化/校准越界 -> R68 保守

# IP-270 ABS：anytime 预算采样器（先便宜后昂贵，结果格单调）
def anytime_budget_sample(fmp, z, budget, lattice):
    r = lattice.bottom()                              # 单样本 + mode_head
    r = refine(r, fmp.sample(z, K=1))
    while budget.remaining() > COST_NEXT and not lattice.top(r):
        cost = next_refinement_cost(r)                # 加样本/聚类/似然
        if budget.remaining() < cost: break
        r = refine(r, next_step(r)); budget.spend(cost)
    return lattice.legal_floor(r)                     # 越早中断越保守（引理 19）

# IP-265 CRG：认证参考调速器（慢层唯一的输出口）
def project(zeta, cse):
    zeta = clamp_to(cse, zeta)                        # 幂等、单调，不放大
    if not cse.feasible(zeta): return REJECT          # 由快层回落安全参考
    return zeta

# IP-268 FGK：力接地证据 + 接地似然（物理源，抗符号欺骗）
def ground_evidence(modes, probe_plan, obs_f):
    r = obs_f.contact_residual(probe_plan)            # (f_meas, event, persistence)
    return {m: log p_contact(r | m) for m in modes}   # 与符号证据正交（A100）

# IP-271 DEG：分级降级（安全随降级单调不降）
def degrade(level, reason):
    assert level in ("L0","L1","L2","L3","L4")
    if level >= current_level: current_level = level
    if level == "L4": csm.force("EMERGENCY")          # 快层独占，慢层停机
    audit.log(level, reason)

# IP-276 主闭环：慢层思考，快层保命，CRG 契约连接
def FORGE_round(M):
    out   = M.abs.anytime(M.obs_s, M.budget)          # 1) anytime 消歧
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, M.obs, M.obs_cal)  # R69 第二意见
    zeta  = M.crg.project(out.zeta_raw, M.cse)        # 2) 认证参考（越界即拒）
    if M.qsb.exceeded() or not M.mcg.ok() or a_hat > TAU_FMA:
        M.deg.raise_to("L3")                          # 3) 量化/校准/故障 -> R68
    M.latest_zeta = zeta                              # 4) 只通过契约影响快环
    M.vqa_e.submit_async(M.budget, zeta, M.qsb, M.csm.events)
    return zeta, M.deg.level

## 3. 推导

**引理 19（anytime 单调安全）** 设结果格按保守序 (ℛ, ⊑) 排列，λ_floor 关于 U 单调增。ABS 在预算 b 处返回 r(b) ∈ ℛ；若 b1 ≤ b2 则 r(b1) ⊑ r(b2)（更多预算只会精化、不会更保守）。由定义 318 与 λ_floor 单调性，任意中断点满足 risk(r(b)) ≤ risk(r_hi) 且 ≥ R68 的安全下界；即**中断只会让系统更保守**，绝不越过 R68 安全侧。

**引理 20（力接地证据的不可伪造增益）** 设符号通道可被对手以概率 δ_p 欺骗，物理通道 r_contact 满足 A100（与符号通道条件独立、且伪造需真实改变反作用力 ≥ Δf）。则引入 r_contact 后，k-正交纪律的错误采纳率从 δ_p·ρ^{k−1} 降为 δ_p·ρ^{k−1}·(1 − IG_contact) + ε_f，其中 IG_contact 随接触信噪比（力分辨率/环境刚度）单调增。系：**在符号通道不可信的场景，接触优于提问**（定义 319）；但接触本身有物理代价与风险，需 CSE 约束。

**引理 21（量化分布偏移界）** 设速度场 v 对 (x, s) 的 Lipschitz 常数为 L_v，量化误差 ‖δv‖ ≤ ε_q，ODE 积分 N 步。则 W_2(P, Q) ≤ C·L_v·ε_q·√N + O(ε_q²)。故存在可静态计算的 τ_q 使 U_quant 可判；U_quant 越界即模态分解不可信（引理 17 的似然通道也可能被量化污染），必须走聚合式保守退避而非交互。

**定理 18（两时间尺度接触稳定）** 若（i）慢层参考 ζ~ ∈ 𝒞_contact 且在 Σ_f 的若干周期内保持不变（零阶保持），（ii）快层力控在接触状态机合法转移下对每个 ζ~ 存在 Lyapunov/无源性证书，（iii）Σ_s 不直接写快环、CRG 幂等单调，则闭环接触不越力包络且渐近稳定；慢层的计算延迟/超时只改变 ζ~ 的更新时刻，不破坏快层稳定域（无源性对 ZOH 与有界时延鲁棒）。

**定理 19（FORGE 严格包含 FLUID/R68）** 在预算充足、无量化偏移（U_quant ≤ τ_q）、接触证据可用且 CRG 不拒绝时，FORGE 与 R69 FLUID 逐指令一致（接触仅作为额外正交证据，不改变安全侧）；当交互无利可图/校准越界/slow-fault 时退化为 R69；当降级到 L3/L4 时退化为 R68 纯保守或快层独占。安全侧永不弱于 R68，效率侧收益来自「接地证据 + anytime resolution bonus」。

**定理 20（可调度性充分条件）** 若 Σ_f 的 WCET_f ≤ ρT_f 且 Σ_s 的微步 WCET 之和在 B_s = T_s 内被响应时间分析判定可调度（固定优先级/时间触发、无阻塞、无动态分配），则慢层不会推迟任何快环截止期；中断/抖动上界由 J_time 给出，接触稳定性所需的最大允许时延 τ_max 由定理 18 的无源性裕度确定，需 τ_max ≥ J_time。

## 6. 本轮最大风险

**一句话**：FORGE-RAS 把「快层永远安全」当成契约的前提，而**力控回路本身的稳定性又依赖一个被 R69 当作免费的前提——力传感的时延与量化抖动有界**；一旦环境刚度突变或力传感延迟逼近定理 18 的无源性裕度，快层会先失稳，而慢层因为「信任契约」不会收紧、反而继续下发精细参考——**接地的证据通道同时是最脆弱的失稳源，摸错一次比问错一次更疼**。

**次级风险与缓解**：
1. **WCET 估计偏乐观**（缓存/中断抖动）→ 离线 WCET 认证 + 测量基线 + 安全裕度 ρ，E307；
2. **量化使模态校准失效而不知** → QSB 在线界 + τ_q 门控，越界即降 L3，E305/E306；
3. **接触证据被环境欺骗**（柔性/粘滑）→ ℰ_contact 对抗集 + 两源一致纪律，E311；
4. **降级不及时/不可追溯** → DEG 单调 + VQAuditor-E 审计 + 证书 J_FORGE，E312/E316；
5. **契约被旁路**（慢层直接写快环）→ CRG 唯一出口 + 互锁 + 运行时断言，定理 18/19。

## 7. 本轮最大风险

**一句话**：FORGE 把「快层永远安全」当作契约前提，而力控回路的稳定又依赖「力传感时延/量化抖动有界」——**接地的证据通道同时是最脆弱的失稳源**：环境刚度突变或时延逼近无源性裕度时，快层先失稳而慢层因信任契约继续下发精细参考，**摸错一次比问错一次更疼**。

**次级风险与缓解**：WCET 偏乐观（离线认证+测量基线+裕度 ρ，E307）；量化致校准失效（QSB+τ_q 门控，E305/E306）；接触证据被环境欺骗（ℰ_contact+两源一致，E311）；降级不及时（DEG 单调+审计+证书，E312/E316）；契约被旁路（CRG 唯一出口+互锁+断言，定理 18/19）。
