# 第 43 轮（新循环第 3 轮） · Cert-SemMap：把语义地图升级为多机器人协作的「可合并安全契约层」（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉」。更结构性的局限是：v19 的证书以**单机状态 x** 为自变量，而地图只是被动背景（C_ms 度量语义图）。真实多机器人任务里，安全性一半由**地图语义**决定（这是不是可走的门、可承重的台面、可穿越的间隙），另一半由**协作**决定（多机共享同一张图、彼此依赖对图的判断）。本轮灵感词「多机器人协作」「语义建图」正好补这个缺口：让语义地图**自身携带证书**——每个语义实体不只给标签和置信度，而给一个**可被形式合并、只会变保守的 affordance 区间 + provenance + 有效期**；多机共享的不再是「一张大家都信的图」，而是「一张可合并的证明义务网」。这样即便两机对同一扇门判断不同，系统也不会把两个高置信度平均成一个危险的自信，而是把该区域标成 *contested/unverified*，自动剔出可导航包络，再由证书价值驱动的探索去补证。

## 0. 直觉与动机

**灵感 1（语义建图 → 从「带置信度的地图」到「带证书的地图」）**：现有语义地图（含本项目的 C_ms）输出标签 + 概率/协方差。直觉上，概率是给人看的，安全决策需要的是**可证明的下界**：这扇门的净宽下界、这块地面的承重下界、这个区域的可通行下界。于是把每个语义实体升级为 CSE=(ℓ, G_e, Σ_e, V_e, π_e, ttl)：几何带不确定集，affordance 带 sound 区间。**未知不是中性，未知等于不安全**——没有证书的区域不进可导航包络。这把地图从「世界模型」变成「安全契约层」。

**灵感 2（多机器人协作 → 地图是 join-semilattice CRDT，不是投票器）**：多机共享地图的常见做法是平均/投票，但平均值会把一个正确的保守观测和一个错误的激进观测中和成危险的中间值。直觉是采用 **CRDT + 保守半格**：融合算子 ⊕ 满足交换/结合/幂等，且对安全偏序**单调收紧**——两机无论以什么顺序融合、丢多少包，最终收敛到同一张「不小于最保守输入」的地图，never re-inflate。冲突（同一实体的区间不相交）不平均，而是显式进入 *contested 集*，标记为不可用于证书，触发再观测或用独立性加权 quorum 裁决。

**灵感 3（协作的深水区 → 独立性加权 quorum，防「共模自信」）**：如果 8 台机器人共用同一个 VLM、同一套仿真参数、同一种相机，它们对同一个错误判断的「一致同意」**不提供任何额外证据**。直觉是把 quorum 从「签名个数」升级为「有效独立证据量」：按传感器模态、视角、模型族、时间、仿真参数来源去重，算 effective sample size。只有有效独立证据达标，才把 affordance 下界从 ⊥ 抬起来。这把 v19 里「quorum 伪独立」的隐患变成一等设计约束。

**耦合升级**：语义地图负责「哪里能做什么」（CSE/CNE），多机协作负责「谁去补证、谁在何时用哪版图」；计划/任务证书引用**地图快照版本**（快照隔离），图一变，相关证书立即失效并最小重验。探索不再由 frontier 驱动，而由 **证书信息价值 CVoI** 驱动：优先观测「卡住最多已认证任务」的未证区域。42 轮的 L0/L1/CKB/SCV 全部保留：SCV 产带语义扰动的仿真数据，CKB 存已证地图补丁与对账案例，ECR 在边缘做地图证书查询。

## 1. 形式化定义（增量：定义 38–44）

**定义 38（证书化语义实体 CSE）**：e=(ℓ_e, G_e, Σ_e, V_e, π_e, ttl_e)。ℓ=语义标签（地面/门/坡道/可承重台面/动态体/未知）；G_e=几何支撑（多边形/体素集/带符号距离场）；Σ_e=几何不确定集（椭球或 conformal 集）；V_e=(a_e^lo, a_e^hi, D_e) 为 **affordance 证书**，a=(traversability, clearance, load_support, hazard) 的 sound 区间与有效域；π_e=provenance 集（观测者、模态、位姿、模型族、仿真配置哈希、时间戳）；ttl_e=有效期。约定真实 affordance a*∈[a_e^lo, a_e^hi] 以置信 1−δ 成立；无观测或过期则 a_e^lo=⊥（未证）。

**定义 39（证书化可导航包络 CNE）**：给定任务动作集 A，CNE(M_t)={x : ∀req∈A(x), a_lo^map(x) ≥ a_req ∧ clearance_lo(x) ≥ c_req}。其中 a_lo^map(x)=min_{e∋x} a_e^lo（对覆盖 x 的实体取最保守聚合），clearance_lo=dist_lo(x) − r_inflate(Σ_e)（用置信半径膨胀）。未知区域 a_lo=⊥ ⇒ x∉CNE。**CNE 是安全包络**：真实可安全执行集合 S_true ⊆ CNE。**单调性**：任何合法融合 M'=M⊕N 满足 CNE(M')⊆CNE(M)。

**定义 40（地图证书代数 / 融合算子）**：对每实体，几何用协方差交（Covariance Intersection，避免重复计数）或置信集交；affordance 用区间交：a_lo'=max(a_lo^i, a_lo^j)，a_hi'=min(a_hi^i, a_hi^j)；provenance 取并；有效期取 min(ttl)。若区间交为空 ⇒ 冲突，实体进入 contested。定义偏序 M⊑N iff CNE(M)⊇CNE(N) 且 prov(M)⊆prov(N)。**命题 1**：⊕ 在该偏序上是 join（最小上界），满足交换、结合、幂等、单调，故为 CRDT，满足强最终一致性（SEC）：乱序/重复/分区恢复后所有副本收敛且 CNE 不反向膨胀。

**定义 41（冲突对账 Rec）**：冲突集 C={e : interval(e)∩interval(e')=∅}。对账：(i) 若一方 provenance 含更高保真或更新鲜的**独立**证据且其传感器模型有证书 ⇒ 采纳并降级为带标记的单边证书；(ii) 否则 e 置 contested，a_lo=⊥，从 CNE 移除；(iii) 对非几何语义（门的开/关、区域占用）用独立性加权 quorum。**命题 2**：Rec 保持 soundness；contested 实体在被独立再观测证明前，永不可用于任何任务证书。

**定义 42（独立性加权 quorum）**：证据集 E_e={o_1..o_m}，每条观测权重 w(o)=∏ factor（模态×视角×模型族×时间×仿真来源的独立性折扣）。有效证据量 ESS_e=(Σw)²/Σw²（Kish 有效样本量）。当 ESS_e ≥ q_eff(θ) 且证据区间一致时，a_e^lo 才可从 ⊥ 抬起；等权重时退化为普通 quorum。**命题 3**：若证据两两高度相关（同模型/同仿真源），ESS 不随数量线性增长，从而防止「伪独立多数」。

**定义 43（地图快照隔离与证书 TTL）**：地图版本 v=(版本向量 DAG 的 join 哈希)。任务/计划证书 C 绑定 map_version(C)。运行时若 M_t 的版本不是 C 版本的祖先且改动影响 C 引用的实体集 E_C，则 C 立即失效，只需在 ΔE_C 上重验；未受影响部分继续有效。ttl 到期一律视为未证。

**定义 44（证书信息价值 CVoI 与分布式探索）**：候选观测动作 u（前往观测点/换视角/换模态），CVoI(u)=E[ΔCoverage_cert(CNE) + λ·Σ_tasks w_task·1(u 解锁 t)] / cost(u)。多机用次模贪心 + 分布式拍卖最大化总 CVoI；通信中断时各机在本地 contested 集上退化执行，恢复后按 CRDT 合并。**命题 4**：证书覆盖对观测集是次模函数，贪心达 (1−1/e) 近似；CVoI 排序把「最挡任务的未证区」优先补证。

## 2. 四大产出设计（增量 IP-57/58/59 + 升级 IP-49/50/51/54/55/56/47/45）

### 2.1 IP-57 CERT-SEM-MAP（证书化语义地图 CSM）
1. **CSE 构建**：LIO 几何 → 实体支撑与 Σ_e；CTC/VLM 语义只用于**选择先验、收缩区间**，绝不把点估计直接当 affordance；affordance 下界 = min(几何下界, 语义先验下界) − 不确定膨胀。
2. **CNE 计算**：八叉树上保守聚合 + 置信膨胀 + unknown=unsafe；输出可 O(log N) 查询的包络与 map_version。
3. **地图快照与 TTL**：版本向量 DAG；按实体集做最小失效，避免「图一改全盘重验」的抖动。
4. **对账**：区间交 + provenance 排序 + contested 标记；contested 区进入探索优先队列。

### 2.2 IP-58 SWARM-MAP-CERT-RUNTIME（群体地图契约运行时 SMCR）
1. **CRDT 同步**：map patch gossip（DDS/ROS2），携带版本向量与 provenance；支持乱序、重复、分区恢复。
2. **独立性加权 quorum**：模态/视角/模型族/仿真源去重，算 ESS；对高一致性但低独立性的证据拒绝抬升。
3. **地图锚定任务守卫**：CAR 守卫引用 (CNE, map_version)；版本失效 → 最小重验；contested 与未知一律 BLOCK。
4. **分层降级链**：全局 CNE → 本地已证邻域（半径 R）→ SafeStop/让出通道，每级都带证书，避免 v18 式可用性崩塌。

### 2.3 IP-59 CERT-VALUE-EXPLORER（证书价值探索 CVE）
1. **CVoI 计算**：未证/contested 区域 × 解锁任务权重 / 旅行与时间代价；用传感器模型估「观测后期望认证概率」。
2. **分布式分配**：次模贪心 + 拍卖；断连时本地 contested 优先。
3. **主动语义询问**：需要时换视角/换模态/靠近确认，而非盲目 frontier。
4. **回填闭环**：新观测 → CSE 更新 → CNE 重算 → 受影响任务证书最小重验。

## 4. 实验设计（E87–E94 硬门槛，承接 E79–E86）

| E94 长时异构群体 | 100h、N=8：不安全事件、Nominal 占比、地图发散、过期实体率 | 0 起；≥80%；有界；<5% |

回退：E87 失守 → 关闭语义先验，affordance 只取几何最坏下界（更保守）；E88 不收敛 → 退回集中式地图服务器 + 锁；E89 对账误杀多 → 只对几何量做区间交，语义量统一走 quorum；E91 共模严重 → 强制多模态/多模型族，禁止单一 VLM 认证；E92 无收益 → 退回 frontier 探索、保留 contested 优先；E93 可用性崩 → 增大地图 TTL 与滞后阈值，先保少量已证区。

## 5. 本轮最大风险

**一句话**：Cert-SemMap 的核心依赖是「语义证据的可信独立性与保守融合」，最大失效链是**语义共模自信（consensus of a false certificate）**——当所有机器人共用同一 VLM、同一仿真参数、相近视角时，独立性加权前的 quorum 会把「同一个错误判断」数成 8 票，地图把「玻璃墙当门、反光地面当自由空间」一致认证；这比单机误判更隐蔽，因为系统内部所有证据都指向同一个自信的错误。因此 E87（CNE soundness）与 E91（独立性 quorum）必须作为红线，任一不达标即熔断回退到纯几何最坏情况包络。

| CNE(M)={x: a_lo^map(x)≥a_req ∧ clearance_lo(x)≥c_req} | 证书化可导航包络 | 真实安全集 S_true⊆CNE；unknown=unsafe |
| ⊕ | 地图融合算子 | 几何协方差交 + affordance 区间交 + prov 并 + ttl min |
| M⊑N | 安全偏序 | CNE(M)⊇CNE(N) ∧ prov(M)⊆prov(N)，⊕ 为其 join |
| C={e: interval(e)∩interval(e')=∅} | 冲突集 | 区间不相交，不平均，进入 contested |
| Rec | 对账算子 | 采信/降级/置 contested，保持 soundness |
| w(o)=∏factor, ESS=(Σw)²/Σw² | 独立性加权证据 | 模态/视角/模型族/时间/仿真源折扣与有效样本量 |
| v=join(version vector) | 地图快照版本 | 任务证书绑定 map_version，支持最小失效 |
| CVoI(u)=E[ΔCov+λΣw·解锁]/cost | 证书信息价值 | 单位代价的认证覆盖与任务解锁期望 |

## 2. 关键算法（伪代码）

### IP-57 CSM：CSE 构建、CNE 计算与保守融合
```
def build_cse(lio_geom, sem_labels, calib, now):
    # 1) 几何实体与不确定集（语义不参与几何）
    G_e, Sigma_e = entity_from_geometry(lio_geom, min_points=30)
    # 2) 语义只用于选择先验、收缩区间，绝不把点估计当 affordance
    prior = calib.affordance_prior(sem_labels, material_hint)
    # 3) affordance 下界 = min(几何下界, 先验下界) - 不确定膨胀
    a_lo = clamp_min(0.0, min_vec(geom_lower(G_e), prior.lower) - inflate(Sigma_e))
    a_hi = min_vec(geom_upper(G_e), prior.upper)
    return CSE(label=sem_labels.dominant, G=G_e, Sigma=Sigma_e,
               V=IntervalV(a_lo, a_hi), provenance={obs_id}, ttl=now + TTL)

def compute_cne(M, action_req):
    cne = Octree()
    for vx in M.occupied_voxels():
        if not M.is_observed(vx):
            continue                         # 未知 = 不安全，不进 CNE
        if M.is_contested(vx):
            continue                         # 冲突实体不可用于证书
        a_lo = min_vec(*(e.V.a_lo for e in M.entities_covering(vx)))
        clr = M.dist_lower(vx) - inflate_radius(M.sigma(vx))
        if dominates(a_lo, action_req.affordance) and clr >= action_req.clearance:
            cne.insert(vx)
    return cne, M.version

def merge_patch(M, patch):
    for e_new in patch.entities:
        e_old = M.get(e_new.key)
        if e_old is None:
            M.put(e_new); M.version = join(M.version, patch.version); continue
        lo = max_vec(e_old.V.a_lo, e_new.V.a_lo)   # 区间交：只会更保守
        hi = min_vec(e_old.V.a_hi, e_new.V.a_hi)
        if any(lo > hi):
            e_old.V = CONTESTED                    # 冲突 -> 不可用
            M.contested.add(e_old.key)
        else:
            e_old.V = IntervalV(lo, hi)
        e_old.Sigma = cov_intersection(e_old.Sigma, e_new.Sigma)
        e_old.provenance |= e_new.provenance
        e_old.ttl = min(e_old.ttl, e_new.ttl)
    M.version = join(M.version, patch.version)     # 版本向量 DAG join
    return M                                   # 交换/结合/幂等/单调 => CRDT
```

### IP-58 SMCR：独立性加权 quorum、地图锚定守卫与降级
```
def independence_weight(obs, cfg):
    w = 1.0
    w *= cfg.modality_discount.get(obs.modality, 1.0)
    w *= viewpoint_discount(obs.pose, cfg.known_poses)          # 视角越近折扣越大
    w *= cfg.same_model_penalty if obs.model_family == cfg.model_family else 1.0
    w *= cfg.same_sim_penalty   if obs.sim_source  == cfg.sim_source  else 1.0
    w *= exp(-age(obs, cfg.now) / cfg.tau_time)
    return w

def effective_quorum(entity_key, evidence, q_eff, cfg):
    ws = [independence_weight(o, cfg) for o in evidence]
    ess = (sum(ws) ** 2) / max(1e-9, sum(w * w for w in ws))     # Kish ESS
    consensus = interval_consensus(evidence)                    # 区间交集
    if ess >= q_eff and consensus is not None:
        lift_lower_bound(entity_key, consensus)                 # 证据一致才抬升
        return 'CERTIFIED'
    return 'INSUFFICIENT_EVIDENCE'

def map_anchored_guard(action, x, M):
    if not M.version_is_ancestor_of(action.cert.map_version):
        return 'INVALIDATE'                  # 快照隔离：图变则证书失效
    if x not in M.cne(action.required_affordance):
        return 'BLOCK'                       # 未知/未证不在 CNE
    if M.intersects_contested(x, action.footprint):
        return 'BLOCK_CONTESTED'             # 冲突实体禁止穿越/接触
    return 'OK'

def degrade_chain(M, comm):
    if comm.global_ok:   return ('GLOBAL_CNE', M.cne)
    if comm.partial_ok:  return ('LOCAL_CERTIFIED', M.local_cne(radius=R))
    return ('SAFE_STOP', None)               # 停止并让出通道，仍带证书
```

### IP-59 CVE：CVoI 与分布式证书探索
```
def certificate_voi(u, M, tasks, sensor_model, lam=1.0):
    unlocked = 0.0
    for t in tasks:
        if not (t.blocked_by_unverified or t.blocked_by_contested):
            continue
        p = prob_certified_after(t.region, u, M, sensor_model)
        unlocked += t.weight * p
    d_cov = expected_new_certified_area(u, M, sensor_model)
    return (d_cov + lam * unlocked) / travel_cost(u)

def distributed_explore(agents, M, tasks, max_rounds=20):
    for _ in range(max_rounds):
        bids = []
        for a in agents:
            for u in a.candidate_observations(M.contested | M.unobserved, K=8):
                bids.append((certificate_voi(u, M, tasks, a.sensor_model), a, u))
        # 证书覆盖对观测集次模 => 贪心 (1-1/e)
        assignments = greedy_submodular(bids, capacity=len(agents))
        for a, u in assignments:
            M = merge_patch(M, a.observe(u))      # CRDT，可乱序/重复
        revalidate_tasks(M)                       # 只重验受影响实体集
    return M
```

### IP-51/43 升级：地图锚定的 CAR 与证书重验
```
def car_step(x, action, M):
    verdict = map_anchored_guard(action, x, M)
    if verdict == 'INVALIDATE':
        delta = affected_entities(action.cert, M.version)
        action.cert = revalidate(action.cert, delta)   # 最小重验，不整树重算
        verdict = map_anchored_guard(action, x, M)
    if verdict != 'OK':
        return SAFE_HOLD
    margin = min(cert_lookup_L0(x).m_lo, M.cne_margin(x))
    return PROCEED if margin >= action.cert.theta else SAFE_HOLD
```

## 6. 本轮最大风险

**一句话**：Cert-SemMap 的核心依赖是「语义证据的可信独立性与保守融合」，最大失效链是**语义共模自信（consensus of a false certificate）**——当所有机器人共用同一 VLM、同一仿真参数、相近视角时，quorum 会把「同一个错误判断」数成 8 票，地图把「玻璃墙当门、反光地面当自由空间」一致认证；这比单机误判更隐蔽，因为系统内部所有证据都指向同一个自信的错误。因此 E87（CNE soundness）与 E91（独立性 quorum）必须作为红线，任一不达标即熔断回退到纯几何最坏情况包络。
