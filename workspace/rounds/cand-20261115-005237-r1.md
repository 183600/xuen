# 第 3 轮（灵感循环第 3 轮；本轮灵感：「闭环控制」×「低延迟推理」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440）。
> 本轮纪律：**在 ToolGauge 之上做"动力学升级"，而不是再造模块**——第 2 轮的 6C 闭环是"事件触发的开环修复"
> （发现盲区 → 探测 → 校准 → 热替换，但**没有对修复过程自身的稳定性、时延、抖动做闭环**）。
> 本轮把 6C 升级为 **ServoGauge**：修复回路本身成为一个**受控动力系统**（闭环控制），
> 推理路径成为**任意时有效 + 投机级联**的低延迟管线（低延迟推理）。
> MODGAUGE 五不变式、ToolGauge 的工具契约层、SNC、语言主张绑定、严格退化链全部保留；
> 新增**闭环稳定性不变式**与**anova 时延违约下的安全回退不变式**，并审计修复第 2 轮遗留的 9 处缺陷（见 §5）。

## 双轴映射（升级而非重写）

| 灵感词 | 第 2 轮对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| 闭环控制 | 定义 421 6C：一次性的"探测→校准→替换"事件 | **SR-Loop + ETC + CBFGuard**：修复变成带误差信号、最小驻留、安全屏障与抗饱和的离散反馈回路 | 第 2 轮只问"这次修复对不对"，没问"连续修复会不会振荡/共振/累积超调"，更没问"多个盲区共用先验时耦合回路是否稳定" |
| 低延迟推理 | IP-318 AP-Cal：固定 N_bl 的整批后验 + 0.2–0.8s VLA | **A²-Cal + SI-Cascade + SM-Cache + LB-Contract**：任意时有效置信序列、投机-级联推理、语义记忆化、时延预算与准入控制 | 第 2 轮的"<10ms 单前向"是均值，不是尾延迟；固定 n_min 在自适应停止下失效（窥视偏差）；且修复必须等推理跑完，无法在 deadline 前优雅退让 |

**核心命题**：把 ToolGauge 的「事件式修复」升级为「**受控修复伺服**」：
1. 用误差信号 e_s = log(σ_conf/ε) 与其收缩率 ρ 描述修复动力学，事件触发 + 最小驻留给出无 Zeno 的探测节律；
2. 用**公共模抑制后的小增益条件** γ_ps·ρ < 1 形式化"多个盲区共享预训练先验"的耦合稳定性，
   正面处置第 2 轮最大风险（跨盲区相关污染），替代启发式 P-Quarantine 符号检验；
3. 用**任意时有效置信序列**替代固定 n_min，使"算到够准就停"在统计上合法；
4. 用**带证书的投机提交**把低延迟路径接到数值通道上：只有满足可计算误差界 ε_spec 的草案才允许提交，
   且 ε_spec 必须落在闭环稳定裕度 M_s 内——**时延、精度、稳定性第一次被放进同一个不等式**。

**不变式保持声明**：
- MODGAUGE 五不变式全部保留；ToolGauge 的契约完整性、主张绑定、严格退化链保留；
- **新增不变式 I6（闭环稳定性）**：γ_ps·ρ < 1 且投机误差 ε_spec ≤ M_s·ε_target，否则冻结投机并退回同步全量路径；
- **新增不变式 I7（时延违约安全回退）**：任何 deadline miss 直接应用保守 stub，h_k ≥ 0 恒成立，不等推理完成；
- **退化链**：ServoGauge 失效（裕度估计越界 / 过载 / 投机证书失败）⇒ ToolGauge 异步全量 ⇒ LeanGauge 纯数值 ⇒ MODGAUGE。

## 0. 直觉与动机

**灵感 1（闭环控制 → 修复不是一次性事件，而是一个要证明稳定的反馈回路）**
直觉：第 2 轮的 6C 像"打一枪换个地方"：D-Box 发现盲区，T-Box 打一次探测，AP-Cal 校准，热替换，结束。
但真实系统里盲区会**反复出现、相邻盲区共享先验、环境持续漂移**。把修复看成控制回路后，三个此前被忽略的问题立刻显形：
(a) **振荡/抖动**：热替换把 σ_conf 压下去，下一轮 D-Box 又因阈值抖动把它判成盲区，反复探测——
这是典型的继电器式控制 chattering；需要死区（deadband）+ 滞回（hysteresis）+ 最小驻留（dwell time）。
(b) **积分饱和**：预算与置信度会像积分项一样累积；一次系统性偏差会让预算持续偏向"再探一次"，
需要 anti-windup。
(c) **耦合稳定性**：多个盲区共用 MP-Φ 先验，等价于一个**网络化控制系统**；局部回路各自稳定，
不代表互联系统稳定——需要小增益（small-gain）条件，而不是事后检测。
(d) **安全**：探测是物理动作（敲击/变光/施力），风险门 λ 只是"准入门槛"，不是"全程不变式"；
用控制屏障函数（CBF）把它升级为**每一步都被约束的安全滤波**，且时延违约时有显式 backup 集。

**灵感 2（低延迟推理 → 不是把模型跑快，而是让"什么时候可以停/可以用草稿"可证明）**
直觉：第 2 轮把 BP-Cal 的 O(N_bl²) Cholesky 换成单前向，确实降了均值时延，但犯了三个低延迟系统常见的错误：
(a) 用**固定样本数** n_min 决定何时停——一旦允许"够了就停"，就是在做**可选停止**，
固定 n 的置信区间不再有效（peeking bias），必须换成任意时有效的置信序列；
(b) 只优化**均值**不优化**尾延迟**——VLA 的 0.2–0.8s 抖动、工具执行的物理时延，会让 P99 远超 τ_repair；
(c) 所有修复都走"全量模型 + 全量探测"，没有**快路径**——而绝大多数盲区是"见过的语义模式"，
可用蒸馏草稿 + 缓存命中在亚毫秒内给出候选，再由**廉价证书**决定能否提交。
低延迟推理的工程智慧是：**级联/早退 + 投机 + 缓存 + 尾部对冲**，其安全前提是"草稿永不直接进入数值通道"——
这恰好能接上第 2 轮"语言不进数值通道"的纪律：**把"草案不进数值通道"推广为"未经证书的推理结果不进数值通道"**。
形式上，投机提交必须给出 TV(q_commit, q_full) ≤ ε_spec 的**可计算上界**，
并且闭环的稳定裕度必须吸收这 ε_spec——否则"又快又省"会变成"又快又错"。

**两轴的交点**：闭环控制要求"误差单调收缩、有界"，低延迟推理要求"在有限时间内给出可用结果"。
两者合起来给出本轮的核心不等式：
**ε_spec + latency_term ≤ M_s**，即"低延迟带来的近似误差"必须小于"闭环能吸收的稳定裕度"。
这条不等式把一个纯工程口号（低延迟）变成了可证伪的研究命题（E445/E446/E447）。

## 1. 形式化定义（增量：定义 432–449）

**定义 432（修复伺服的误差状态 SR-Loop）** 对盲区 s，定义误差
e_s(t) = log(σ_conf(s,t) / ε_target(s))，
状态 x_s = (e_s, b_s, q_s)，其中 b_s = u_s − μ_phys(s) 为契约参数的先验偏差，q_s 为剩余工具预算。
修复回路的一步动力学：
x_s(t+1) = F(x_s(t), u_s(t), w_s(t))，
u_s(t) ∈ {probe(Π), calibrate(κ), commit, stub} 为控制量，w_s 为环境漂移 + 工具噪声 + 近似误差。
在局部工作点（引理 51 的条件下）线性化为 e_s(t+1) = ρ_s·e_s(t) + w_s(t) + ε_spec(t)，
ρ_s 为该盲区的**闭环收缩率**；稳定裕度 M_s := 1 − ρ_s > 0。

**定义 433（事件触发与最小驻留 ETC）** 触发集合
Trigger_s(t) ⇔ (|e_s(t)| ≥ δ_e) ∨ (new_blindspot(s,t)) ∨ (t − t_last(s) ≥ T_aging)，
其中 δ_e 为死区，T_aging 为老化上限。两次触发之间强制 t − t_last ≥ T_dwell，
T_dwell := max_{t∈T₀} τ_t + τ_cal + τ_swap 为最坏单次修复时延。
**滞回**：进入触发用 δ_e，退出用 δ_e·(1−Δ_h)，Δ_h ∈ (0,1)，防止阈值附近的 chattering。

**定义 434（收缩率与稳定裕度的在线辨识）** 维护最近 W 次修复的对数误差比
r_i = log(|e_i^+|/|e_i|)，以稳健回归（Huber）估计 ρ̂；取单侧下置信界 ρ_LB（保守，越大越安全）。
定义 M̂_s = 1 − ρ_LB。若 M̂_s ≤ M_min，冻结投机提交并把 δ_e 下调一档（更频繁、更保守地修复），
直到 M̂_s 恢复；本轮**不再用"预测收缩 vs 实际收缩"的启发式符号检验**（修复第 2 轮缺陷 5）。

**定义 435（公共模抑制与先验共享小增益）** 多个盲区共享 MP-Φ 时，误差耦合记
e_j^+ = (1−a_j)e_j + a_j Σ_k (W_⊥)_{jk} e_k + d_j，
其中 W_⊥ 为**经 cross.modal 参考通道做公共模抑制后**的残差耦合矩阵（抑制步骤见 IP-322）：
先减去跨通道公共偏差估计 ĉ = mean_k cross_bias_k，再在残差上估计 W_⊥。
定义先验共享增益 γ_ps := ρ(W_⊥)（谱半径）。**小增益条件**：γ_ps·ρ < 1。
若不做公共模抑制，行随机 W 必有 ρ(W)=1，回路临界——这正是第 2 轮"一次错误先验同时污染所有子图"的根因。

**定义 436（控制屏障安全滤波 CBFGuard）** 对候选动作 a 定义屏障
h_k := σ_pred(a|s) − σ_decl(a) − γ ≥ 0（即定义 419 的风险门被提升为逐步不变式）。
离散 CBF 条件：h_{k+1} ≥ (1−α_cbf)·h_k，α_cbf ∈ (0,1]。
**时延感知 backup 集**：每个探测工具 t 预注册一个保守契约 σ_decl_cons(a) = σ_pred(a|s) − γ − h_min，
满足 h = h_min > 0，且不依赖任何推理结果即可写入。deadline miss ⇒ 立即切 backup（定义 445）。

**定义 437（抗积分饱和与滞回 AW-Hyst）** 预算信用 credit_s 饱和于 B_tools；
当连续 k 次修复未使 |e_s| 下降时，对"继续探测"施加衰减因子 η^w（w 为连续失败次数），
防止"越修不好越要修"的正反馈；热替换/回退使用 Δ_h 滞回带，禁止在边界反复横跳。

**定义 438（任意时有效校准 A²-Cal）** 观测 X_i = uᵀ r_i（r_i 为有效回执，u 为契约参数投影方向），
亚高斯参数 σ。对每个候选均值 μ 构造混合鞅
M_t(μ) = exp(Σ_{i≤t} λ_i(X_i−μ) − λ_i²σ²/2)，λ_i = sqrt(2·log(1/δ_cs)/(σ²·i))（可预测）。
Ville 不等式给出 P(∃t: M_t(μ*) ≥ 1/δ_cs) ≤ δ_cs，故
CS_t = {μ : M_t(μ) < 1/δ_cs} 是 (1−δ_cs) **时间一致**置信序列。
停止规则 τ(ε) = inf{t : width(CS_t) ≤ ε}，width(CS_t) = σ·sqrt(2·log(1/δ_cs)/t)。
A²-Cal 用 CS_τ 替代第 2 轮固定 n_min 的整批后验（修复缺陷 4）。

**定义 439（投机-级联推理 SI-Cascade）** 三级管线：
(0) **缓存** SM-Cache：键 k(s) = H(featurize_num(s), R-cell 语义指纹)，命中且 age ≤ τ_cache 直接返回；
(1) **草稿** q̃ = MP-Φ̃_θ̃(ctx)，Φ̃ 为 MP-Φ 的蒸馏小模型，单次 < 1ms；
(2) **证书提交**：若可计算上界 TV(q̃, q_full) ≤ L_Φ·η_d ≤ ε_spec，且回执交叉验证余量 ≥ ε_spec，
    则提交 q̃；否则回退全量 MP-Φ（引理 54）。
L_Φ 为 MP-Φ 对上下文特征的 Lipschitz 常数（预注册、可重算），η_d 为蒸馏特征误差上界。
**提交的结果必须携带证书对象**（ε_spec, L_Φ, η_d, 回执），无证书的草稿一律丢弃。

**定义 440（语义记忆化与陈旧度 SM-Cache）** 缓存条目 (k(s), q, t_stamp, 语义指纹)。
有效期 τ_cache 满足 β_drift·τ_cache ≤ ε_spec（β_drift 为环境漂移率上界）；
过期条目降级为"草稿"而非直接命中，必须重新过证书。缓存命中 O(1)，但**命中不等于可信**。

**定义 441（时延预算契约 LB-Contract）** LB = (τ_repair, WCET_breakdown, U_max, admit_rule, hedge)：
- WCET_breakdown = τ_draft + τ_check + τ_full + τ_tool + τ_swap；
- 准入规则：仅当 slack(s,t) := deadline(s,t) − now ≥ WCET_repair(s) 时接纳新修复任务；
- 过载对冲：维持一个"保守 stub 已完成"的影子状态，deadline 前 1 个 T_dwell 仍未完成则提前切换；
- LB-Contract 是 TB-Contract（定义 424）的时延细化，预算与时序结论继承引理 45。

**定义 442（稳定性-时延-精度三角）** 定义可容许近似误差
ε_adm := M_s · ε_target / 2（由引理 52 的终值界推出；见引理 54）。
**三角不等式约束**：ε_spec + w̄_latency ≤ ε_adm，
其中 w̄_latency 为 LB-Contract 允许的时延折算误差（超时未提交导致的额外不确定度）。
违反 ⇒ 禁用投机/缓存，退回同步全量路径。β_t 的工程形式同步修正为
β_t = Ĝ_t − π_B·c_t，π_B 为预算影子价格（nats/秒），修复第 2 轮 β 的量纲错误（缺陷 1）。

**定义 443（随机全量审计 Fair-Audit）** 每个被提交的投机结果以概率 p_audit 触发一次独立全量复核；
未审计的提交按重要性权重 1/(1−p_audit) 记账。用于估计投机路径的真实错误率，
并给出"审计逃逸概率"上界（引理 54 系）；同时服务于事故复盘，不进入在线数值路径。

**定义 444（ServoGauge 7C 闭环）** H → C → S → E → C → V → U：
1. H：D-Box/L-Box 生成共形假设集 H_s（继承定义 422/425）；
2. C：VLA 编程器编译 Π_s，TCV 四查（继承定义 418）；
3. S：**新增调度与准入**——LB-Contract 检查 slack、EDF 入队、选择 缓存/草稿/全量/backup 路径；
4. E：工具执行（PROBING 态，继承定义 430），回执校验；
5. C：A²-Cal 顺序校准，满足 width ≤ ε 即停；
6. V：独立回执交叉验证 + 契约回归（继承定义 421.V，改用不相交 holdout，见修复 3）；
7. U：CBFGuard 判定后可热替换；否则 stub + RED（严格退化）。
外层再加一个**监督环 R**（低频、异步）：更新 ρ̂、γ_ps、δ_e、p_audit、投机开关——7C 由 R 包住。

**定义 445（deadline miss 安全回退）** 若 t > deadline(s) 且尚未完成 V：
立即写 σ_decl_cons(a) = σ_pred(a|s) − γ − h_min（backup 集），热替换为 stub + RED，
**不等待任何推理/校准结果**。其数值行为与"从未开始修复"等价，从而 h_k ≥ h_min 对所有 k 成立。

**定义 446（裕度越界告警与保守冻结）** 由 ρ_LB 与 γ̂_ps 计算联合裕度
M_joint := 1 − γ̂_ps·ρ_LB（取单侧下界）；M_joint ≤ M_min 时：
① 冻结 SI-Cascade；② δ_e 下调；③ p_audit 上调至 1；④ 发出"闭环裕度不足"告警。
恢复需连续 L_recover 次 M_joint ≥ 2·M_min（滞回，防抖）。

**定义 447（公平 EDF 与饥饿界）** 修复任务带年龄权重 w_j（随等待时间线性增长）；
调度优先级 = deadline 松弛度 / w_j。准入 + 加权 EDF 给出：任意被接纳任务在
(N_bl−1)·τ_repair + O(τ_repair) 内获得执行（引理 57），饥饿上界可证。

**定义 448（语义漂移的在线探测）** 用 cross.modal 的残差序列做 CUSUM：
S_t = max(0, S_{t−1} + (|z_t| − k_cusum))，S_t > h_cusum ⇒ 判定共享先验出现系统偏差。
相比第 2 轮符号检验（缺陷 5），CUSUM 有受控的平均运行长度 ARL₀ 与可计算的检测延迟。

**定义 449（继承、极限退化与记号约定）** 未重定义的记号沿用定义 398–431。
极限：δ_e = 0、T_dwell = τ_repair^max、W_⊥ = 0、p_audit = 0、无缓存、无投机 ⇒ ServoGauge ≡ ToolGauge；
再令 VLA = ∅、T₀ = {被动观测}、MP-Φ = 物理 GP ⇒ LeanGauge；再退化 ⇒ MODGAUGE。
能力包含关系统一记作 **ServoGauge ⊒ ToolGauge ⊒ LeanGauge ⊒ MODGAUGE**（⊒ 表示"能力增强且原行为可达"），
修正第 2 轮集成链箭头方向矛盾（缺陷 7）。

## 2. 关键算法骨架

```python
# IP-321 伺服调节器：事件触发 + 抗饱和 + 滞回
class ServoRegulator:
    def __init__(self): self.last, self.fail_w, self.prev_on = {}, {}, {}
    def trigger(self, s, e, now):
        if now - self.last.get(s, -1e9) < T_DWELL: return False
        enter = abs(e) >= self.delta_e[s]
        leave = abs(e) >= self.delta_e[s] * (1 - DELTA_H)
        on = enter or (self.prev_on.get(s, False) and leave)
        self.prev_on[s] = on
        return on or (now - self.last.get(s, -1e9) >= T_AGING)
    def credit(self, c): return min(c, B_TOOLS)                       # anti-windup
    def gain_penalty(self, s):
        return ETA ** self.fail_w.get(s, 0)                           # 连续失败衰减
    def on_event(self, s, now): self.last[s] = now

# IP-322 小增益监控 + 公共模抑制 + CUSUM（替代 P-Quarantine）
class SmallGainMonitor:
    def __init__(self): self.resid, self.cusum = deque(maxlen=256), 0.0
    def observe(self, e_vec, cross_bias):
        c_hat = mean(cross_bias)                                      # 公共模估计
        self.resid.append(e_vec - c_hat)                              # 残差
    def update(self):
        W_hat = robust_lstsq(self.resid)                              # W_⊥ 估计
        self.gamma_ps = spectral_radius(W_hat)
        return self.gamma_ps
    def cusum_update(self, z):
        self.cusum = max(0.0, self.cusum + (abs(z) - K_CUSUM))
        return self.cusum > H_CUSUM
    def gate(self, rho_lb): return self.gamma_ps * rho_lb < 1 - M_MIN

# IP-323 控制屏障安全滤波 + 时延感知 backup
class CBFGuard:
    def feasible(self, a, s, h_prev):
        h_next = sigma_pred(a, s) - sigma_decl(a) - GAMMA
        return h_next >= (1 - ALPHA_CBF) * h_prev
    def backup(self, a, s):                                           # 不依赖推理
        return Contract(a, sigma_decl_cons=sigma_pred(a, s) - GAMMA - H_MIN)

# IP-324 任意时有效顺序校准
class A2Cal:
    def __init__(self, sigma, delta_cs): self.S, self.n, self.sig, self.d = 0.0, 0, sigma, delta_cs
    def update(self, x): self.S += x; self.n += 1
    def width(self):
        return 0.0 if self.n == 0 else self.sig * sqrt(2 * log(1 / self.d) / self.n)
    def interval(self): return (self.S / max(self.n, 1) - self.width(),
                                self.S / max(self.n, 1) + self.width())
    def done(self, eps): return self.n > 0 and self.width() <= eps

# IP-325 投机-级联推理 + 语义缓存
class SICascade:
    def infer(self, ctx, s, eps_spec, slack):
        if (hit := self.cache.get(key(ctx))) and hit.age <= TAU_CACHE and hit.cert_ok:
            return hit.q, "cache"
        q_draft = self.draft(ctx)                                     # < 1ms
        bound   = self.L_phi * self.eta_d(q_draft, ctx)               # 可计算 TV 上界
        if bound <= eps_spec and self.cross_margin(q_draft, s) >= 2 * eps_spec:
            self.audit_schedule.maybe(q_draft, s, p_audit)            # Fair-Audit
            return q_draft, "speculative"
        if slack >= self.wcet_full:                                   # 有全量预算才等
            return self.full(ctx), "full"
        return None, "would_miss_deadline"                            # 触发 backup

# IP-326 LB-Contract 调度：准入 + 加权 EDF
class LBScheduler:
    def admit(self, s, now, deadline):
        return deadline - now >= self.wcet_repair(s)
    def push(self, task):
        heapq.heappush(self.q, (task.deadline / task.age_weight(), task))
    def pop(self, now):
        while self.q:
            _, task = heapq.heappop(self.q)
            if task.deadline - now >= self.wcet_repair(task.s): return task
            apply_backup(task.s)                                      # 过载 -> 安全回退
        return None

# IP-327 ServoGauge 7C + 监督环
def servogauge_7c(M, s, now):
    e  = log(M.dbox.sigma_conf[s] / M.eps_target[s])
    if not M.servo.trigger(s, e, now): return IDLE
    if not M.scheduler.admit(s, now, M.deadline(s)):                  # S
        return apply_backup(s)                                        # 定义 445
    H    = M.lbox.hypothesize(s, M.dbox.R[s])                         # H
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s))         # C
    prog = [c for c in prog if M.cbf.feasible(c.a, s, M.h[s])]        # CBF 滤波
    prog = [c for c in prog if M.cbf.risk_and_gain(c)]                # 双层闸门（修正量纲，定义 442）
    receipts = M.tcv.execute(prog, M.env)                             # E
    cal = M.a2cal.new(s)                                              # C
    for r in receipts:
        cal.update(project(r, H))
        if cal.done(M.eps_target[s]): break                           # 任意时停止
    if cal.n <= 0 or cal.width() > M.eps_target[s]:
        return stub_and_red(s, "insufficient_evidence")
    q, path = M.si.infer(featurize_ctx(receipts, H, s), s,
                         M.eps_adm(s), M.slack(s, now))               # 低延迟推理
    if q is None: return apply_backup(s)                              # 时延违约 -> 安全回退
    if not M.verify(q, M.cross_receipt_disjoint(s)):                  # V（不相交 holdout）
        q = M.si.full(featurize_ctx(receipts, H, s))                  #   夹紧重试 1 次
        if not M.verify(q, M.cross_receipt_disjoint(s)):
            return stub_and_red(s, "cross_failed")
    new_ec = M.a2cal.contract(q, s)
    if not contract_regression(new_ec): return stub_and_red(s, "regression")
    M.mreg.hot_replace(M.dpe, new_ec)                                 # U
    M.dbox.update_from_posterior(s, q)                               # 继承第 2 轮修复
    bind_claims(new_ec, H, prog, receipts)                            # 定义 423/427
    M.h[s] = sigma_pred(s) - sigma_decl(new_ec, s) - GAMMA            # CBF 状态推进
    M.servo.on_event(s, now)
    return True

def ServoGauge_round(M, obs, audio, tac, depth, det):
    now = M.clock.now()
    M.smallgain.observe(M.error_vector(), M.cross_bias())
    gamma_ps = M.smallgain.update()
    if M.smallgain.cusum_update(M.last_z()) or not M.smallgain.gate(M.rho_lb):
        M.freeze_speculation(); M.p_audit = 1.0; M.delta_e *= 0.5    # 定义 446
    for s in M.dbox.detect_blind_spot():

        if M.scheduler.admit(s, now, task.deadline): M.scheduler.push(task)
        else: apply_backup(s)
    while (task := M.scheduler.pop(now)) is not None:

    return MODGAUGE_round(M, obs, audio, tac, depth, det)             # 50Hz 主控不变
```

## 3. 推导

**引理 51（事件触发的无 Zeno 性、误差终值界与预算速率）**
设局部动力学 e_{k+1} = ρ e_k + w_k，ρ < 1，|w_k| ≤ w̄，触发条件 |e_k| ≥ δ_e 或老化。
(a) 两次触发间隔 ≥ T_dwell > 0（驻留计时器强制），故无 Zeno、有限时间触发次数 ≤ T/T_dwell；
(b) 触发后的误差序列满足 limsup|e_k| ≤ (δ_e + w̄)/(1−ρ)，即 δ_e → 0 时误差收敛到噪声底；
(c) 探测预算消耗速率 ≤ B_tools/T_dwell（每次事件至多一个程序）。
证明：(a) 由定义 433 直接；(b) 在两次触发间 e 按 ρ 收缩、w 有界，展开几何级数取上极限；
(c) 每个事件在 T_dwell 内至多一次，单程序 ≤ B_tools。

**引理 52（先验共享的小增益 L∞ 稳定性与污染界）**
在定义 435 的耦合误差系统下，若 a_j = a 且 γ_ps = ρ(W_⊥) < 1，则
ρ(B) = 1 − a(1 − γ_ps) < 1，且对任意满足 ‖·‖ 的诱导范数存在等价范数使 ‖B‖ < 1，于是
limsup ‖e(t)‖ ≤ ‖(I−B)⁻¹‖·sup‖d(t)‖ ≤ sup‖d‖ / M_s，M_s := 1 − ‖B‖ > 0。
若不做公共模抑制（γ_ps = 1，W 行随机），则 B 有特征值 1，回路临界：
**任何**共享先验偏差都不会衰减，只能靠外部断路器截断——这精确解释了第 2 轮最大风险的机理。
系：跨盲区污染半径 ≤ κ_c·ε_prior/M_s，其中 ε_prior 为单个盲区的先验误差上界；
只要 M_s 有正下界，污染不随盲区数 N_bl 线性增长。

**引理 53（A²-Cal 的时间一致覆盖与停止时间）**
在定义 438 的混合鞅构造下，Ville 不等式给出
P(∃t ≥ 1 : μ* ∉ CS_t) ≤ δ_cs，即覆盖对**所有可能的停止规则**一致成立。
停止时间 τ(ε) = ⌈2σ²·log(1/δ_cs)/ε²⌉ 有限，且 E[τ(ε)] ≤ 2σ²log(1/δ_cs)/ε² + 1。
与第 2 轮定义 426 的固定 n 比较：n_3 / n_2 = 2·log(1/δ_cs)/(1 − ε²/σ_0²)；
δ_cs = 0.05 时比值约为 6/(1−ε²/σ_0²) > 1。**结论**：第 2 轮的 n_min 在"够了就停"下系统性偏小，
会给出过窄区间；A²-Cal 用 log(1/δ) 因子换来对任意停止合法的覆盖（修复缺陷 4）。
系：若坚持固定 n 报告区间，则必须改用 Bonferroni 式 α/t 校正，其代价与本引理同阶。

**引理 54（投机提交的误差证书与稳定性吸收）**
设可计算界 TV(q̃, q_full) ≤ L_Φ·η_d =: ε_spec。
(a) 若提交 q̃，则其与全量结果的契约参数偏差 ≤ ε_spec（TV 控制有界函数期望差）；
(b) 把 ε_spec 视为定义 432 中的附加扰动，由引理 51(b) 得
limsup|e| ≤ (δ_e + w̄ + ε_spec)/(1−ρ)；
(c) 若 ε_spec ≤ ε_adm = M_s·ε_target/2，则相对无投机情形的终值界放大不超过 2 倍；
(d) 期望时延 E[T] = c_draft + (1−p)(c_full + c_check)（p 为提交率），
尾时延满足 P99 ≤ c_draft + c_check + c_full^WCET（最坏路径仍是有界的全量路径），
故**投机不改善最坏情况，只改善均值/常见情况**——这一点必须在 LB-Contract 中如实记账。
(e) Fair-Audit：投机错误率估计的无偏性来自 1/(1−p_audit) 加权；
逃逸概率 ≤ (1−p_audit)^m（m 次未审计提交），取 m = ⌈log δ_audit / log(1−p_audit)⌉ 可压到 δ_audit。

**引理 55（时延违约下 CBF 安全不变式）**
若准入规则保证每个被接纳任务满足 slack ≥ WCET_repair，且违约时执行定义 445 的 backup，
则对任意 k，h_k ≥ min(h_0, h_min) ≥ 0。
证明：对 k 归纳。若正常完成，CBF 条件 h_{k+1} ≥ (1−α)h_k ≥ 0；
若 deadline miss，backup 直接令 σ_decl = σ_pred − γ − h_min，故 h = h_min > 0；
准入保证不会出现"既没完成、又没到 backup 触发时刻"的窗口（提前 1 个 T_dwell 切换）。
系：安全性与推理速度**解耦**——推理再慢也不会破坏 h ≥ 0，只会更早触发保守 stub。

**引理 56（低延迟路径不破坏数值等价性与主张绑定）**
SM-Cache 命中与 SI-Cascade 提交都必须携带证书（定义 439/440），未带证书的草案被丢弃；
证书通过后进入数值通道的对象仍是一个满足定义 417 的契约更新；
claims 仍是纯投影（定义 423）。故第 1 轮引理 44/第 2 轮引理 49 的数值等价性对 ServoGauge 仍成立。
缓存陈旧误差 ≤ β_drift·τ_cache ≤ ε_spec（定义 440），已计入引理 54(b) 的扰动项。

**引理 57（加权 EDF 的可调度性与饥饿界）**
在准入控制下，被接纳任务的利用率 U = Σ C_i/T_i ≤ 1 ⇒ 全部满足 deadline（标准 EDF 结论）。
年龄权重 w_j(t) = 1 + t/T_aging 单调增长，故任意盲区在
(N_bl−1)·τ_repair + τ_repair 个事件内被服务；饥饿上界有限且与 N_bl 成线性。
系：过载时系统优先执行 backup 而非阻塞——**过载转化为精度降级，而非实时性破坏**。

## 6. 本轮最大风险（一句话）

**一句话**：ServoGauge 让修复回路跑得比审计快——事件触发与投机提交把"慢路径（全量 VLA / 人工审计 / P-Quarantine）"

系统会在一次"看起来平稳"的静默期内把局部误差放大成跨盲区共振，而能发现它的慢审计恰恰是被低延迟目标压掉的那条路径。

**次级风险与缓解**：
1. **裕度误估** → 用单侧保守下界 ρ_LB（而非均值）+ 裕度滞回 + 定期全量审计（定义 443/446，E451）；
2. **公共模抑制失效**（参考通道自身被污染）→ 双参考通道互检 + γ_ps 直接估计而非假定（E444）；
3. **投机证书过松**（L_Φ/η_d 低估）→ 证书参数预注册并周期性重算 + Fair-Audit 纠偏（引理 54(e)，E446）；
4. **缓存陈旧** → TTL 与漂移率绑定，过期即降级为草稿（定义 440，E449）；
5. **过载饥饿** → 加权 EDF + 准入 + backup 优先，饥饿界可证（引理 57，E450）；
6. **backup 自身不安全**（σ_decl_cons 仍可能越过物理限）→ h_min 由硬约束反解 + 力矩/温度硬限（定义 436/445，E448）；
7. **A²-Cal 的有效性依赖 σ 已知/亚高斯** → 用稳健方差估计 + 保守放大，未知时改 Hoeffding 型序列（E445 稳健组）。

> 理论姿态：不改数值语义，只给"修复过程如何随时间演化"补上稳定性、安全性与时延的证明义务。

## 2. 形式化定义（要点）

**定义 432（SR-Loop）** 状态 x_s=(e_s,b_s,q_s)，e_s=log(σ_conf/ε_target)；一步动力学 e_s^+=ρ_s e_s + w_s + ε_spec；
M_s=1−ρ_s>0 为稳定裕度。
**定义 433（ETC）** 触发 = (|e|≥δ_e) ∨ 新盲区 ∨ 老化；触发间强制 ≥T_dwell；进入/退出用不同阈值（滞回）。
**定义 434（在线辨识）** 稳健回归估计对数误差比得 ρ̂，取单侧下界 ρ_LB（保守）；M̂_s≤M_min ⇒ 冻结投机、下调 δ_e。
**定义 435（小增益）** 经 cross.modal 公共模抑制后得 W_⊥；γ_ps=ρ(W_⊥)；条件 γ_ps·ρ<1；否则临界（不抑制时 γ_ps=1）。
**定义 436（CBF）** h_k=σ_pred−σ_decl−γ；要求 h_{k+1}≥(1−α_cbf)h_k；预注册 backup 契约保证 h=h_min>0。
**定义 437（AW-Hyst）** credit 饱和 B_tools；连续失败对探测施加 η^w 衰减；替换/回退走滞回带。
**定义 438（A²-Cal）** 混合鞅 + Ville ⇒ 对任意停止规则 P(∀t: μ*∈CS_t) ≥ 1−δ_cs；
width_t=σ·sqrt(2log(1/δ_cs)/t)；τ(ε)=⌈2σ²log(1/δ_cs)/ε²⌉。
**定义 439（SI-Cascade）** 缓存 → 草稿 q̃（<1ms）→ 证书 TV(q̃,q_full)≤L_Φη_d≤ε_spec 且交叉验证余量≥ε_spec → 提交；否则全量。
**定义 440（SM-Cache）** 键 k(s) 为数值特征 + 语义指纹；TTL 满足 β_drift·τ_cache≤ε_spec；过期降级为草稿。
**定义 441（LB-Contract）** slack ≥ WCET_repair 才准入；deadline 前 1 个 T_dwell 未完成即提前切 backup。
**定义 442（三角约束）** ε_adm=M_s·ε_target/2；要求 ε_spec+w̄_latency≤ε_adm；β_t=Ĝ_t−π_B·c_t。
**定义 443（Fair-Audit）** 以 p_audit 随机全量复核，1/(1−p_audit) 加权；逃逸概率 ≤(1−p_audit)^m。
**定义 444（7C）** H→C→S（调度/准入/路径选择）→E→C（A²-Cal 早停）→V（不相交 holdout）→U（CBF 后热替换）；外层 R 监督环低频调参。
**定义 445（违约回退）** deadline miss 立即写 σ_decl_cons=σ_pred−γ−h_min 并 stub+RED，不等推理。
**定义 446（裕度冻结）** M_joint≤M_min ⇒ 冻结投机 / δ_e 减半 / p_audit=1 / 告警；需连续 L_recover 次 ≥2M_min 才恢复（滞回）。
**定义 447（公平 EDF）** 优先级 = 松弛度 / 年龄权重；饥饿界 O(N_bl·τ_repair)。
**定义 448（CUSUM 漂移检测）** S_t=max(0,S_{t−1}+|z_t|−k_cusum)，越过 h_cusum 判共享先验系统偏差。
**定义 449（继承与退化）** 记号沿用 398–431；δ_e=0、T_dwell=τ_repair^max、W_⊥=0、无投机/缓存 ⇒ ServoGauge≡ToolGauge；能力包含链 ⊒。

## 3. 关键算法骨架

```python
# IP-321 事件触发 + 抗饱和 + 滞回
class ServoRegulator:
    def trigger(self, s, e, now):
        if now - self.last.get(s, -1e9) < T_DWELL: return False
        enter = abs(e) >= self.delta_e[s]
        leave = abs(e) >= self.delta_e[s] * (1 - DELTA_H)
        return enter or (self.prev_on.get(s) and leave)

# IP-322 公共模抑制 + 小增益 + CUSUM（替代 P-Quarantine）
class SmallGainMonitor:
    def observe(self, e_vec, cross_bias): self.resid.append(e_vec - mean(cross_bias))
    def update(self):
        self.gamma_ps = spectral_radius(robust_lstsq(self.resid)); return self.gamma_ps
    def cusum_update(self, z):
        self.cusum = max(0.0, self.cusum + abs(z) - K_CUSUM); return self.cusum > H_CUSUM
    def gate(self, rho_lb): return self.gamma_ps * rho_lb < 1 - M_MIN

# IP-323 CBF 安全滤波 + backup
class CBFGuard:
    def feasible(self, a, s, h_prev):
        return sigma_pred(a, s) - sigma_decl(a) - GAMMA >= (1 - ALPHA_CBF) * h_prev
    def backup(self, a, s):
        return Contract(a, sigma_decl_cons=sigma_pred(a, s) - GAMMA - H_MIN)

# IP-324 任意时有效顺序校准
class A2Cal:
    def update(self, x): self.S += x; self.n += 1
    def width(self): return 0.0 if self.n == 0 else SIG * sqrt(2 * log(1 / D_CS) / self.n)
    def done(self, eps): return self.n > 0 and self.width() <= eps

# IP-325 投机-级联推理
class SICascade:
    def infer(self, ctx, s, eps_spec, slack):
        if (hit := self.cache.get(key(ctx))) and hit.fresh() and hit.cert_ok:
            return hit.q, "cache"
        q = self.draft(ctx)                                   # < 1ms
        if self.L_phi * self.eta_d(q, ctx) <= eps_spec and self.cross_margin(q, s) >= 2 * eps_spec:
            self.audit.maybe(q, s, P_AUDIT); return q, "speculative"
        return (self.full(ctx), "full") if slack >= self.wcet_full else (None, "backup")

# IP-326 准入 + 加权 EDF
class LBScheduler:
    def admit(self, s, now, deadline): return deadline - now >= self.wcet_repair(s)
    def pop(self, now):
        while self.q:
            _, task = heapq.heappop(self.q)
            if task.deadline - now >= self.wcet_repair(task.s): return task
            apply_backup(task.s)
        return None

# IP-327 7C + 监督环
def servogauge_7c(M, s, now):
    e = log(M.dbox.sigma_conf[s] / M.eps_target[s])
    if not M.servo.trigger(s, e, now): return IDLE
    if not M.scheduler.admit(s, now, M.deadline(s)): return apply_backup(s)      # S
    H = M.lbox.hypothesize(s, M.dbox.R[s])                                       # H
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s))                    # C
    prog = [c for c in prog if M.cbf.feasible(c.a, s, M.h[s])]                   # CBF
    receipts = M.tcv.execute(prog, M.env)                                        # E
    cal = M.a2cal.new(s)
    for r in receipts:
        cal.update(project(r, H))
        if cal.done(M.eps_target[s]): break                                      # 任意时停
    if cal.n == 0 or cal.width() > M.eps_target[s]: return stub_and_red(s, "insufficient")
    q, path = M.si.infer(featurize_ctx(receipts, H, s), s, M.eps_adm(s), M.slack(s, now))
    if q is None: return apply_backup(s)                                         # 时延违约
    if not M.verify(q, M.cross_receipt_disjoint(s)):                             # V
        q = M.si.full(featurize_ctx(receipts, H, s))
        if not M.verify(q, M.cross_receipt_disjoint(s)): return stub_and_red(s, "cross_failed")
    new_ec = M.a2cal.contract(q, s)                                              # U
    if not contract_regression(new_ec): return stub_and_red(s, "regression")
    M.mreg.hot_replace(M.dpe, new_ec)
    M.dbox.update_from_posterior(s, q)
    bind_claims(new_ec, H, prog, receipts)
    M.h[s] = sigma_pred(s) - sigma_decl(new_ec, s) - GAMMA
    return True
```

## 4. 推导（引理 51–57）

**引理 51（ETC 无 Zeno / 终值界 / 预算速率）** 驻留计时器 ⇒ 触发间隔 ≥T_dwell，无 Zeno；
e^+=ρe+w ⇒ limsup|e|≤(δ_e+w̄)/(1−ρ)；探测速率 ≤B_tools/T_dwell。
**引理 52（小增益 L∞ 稳定与污染界）** 若 γ_ps=ρ(W_⊥)<1、a_j=a，则 ρ(B)=1−a(1−γ_ps)<1，
limsup‖e‖≤sup‖d‖/M_s；污染半径 ≤κ_c·ε_prior/M_s，不随 N_bl 线性增长。
不抑制公共模（γ_ps=1）⇒ B 有特征值 1，回路临界，精确解释第 2 轮最大风险。
**引理 53（A²-Cal 时间一致覆盖）** Ville ⇒ P(∀t: μ*∈CS_t)≥1−δ_cs，对任意停止规则成立；
τ(ε)=⌈2σ²log(1/δ_cs)/ε²⌉ 有限；相对定义 426 的固定 n，比值 2log(1/δ_cs)/(1−ε²/σ_0²)>1，
说明固定 n_min 在可选停止下系统性偏窄（修复缺陷 4）。
**引理 54（投机提交证书）** TV(q̃,q_full)≤ε_spec；(a) 契约偏差 ≤ε_spec；(b) 终值界变 (δ_e+w̄+ε_spec)/(1−ρ)；
(c) ε_spec≤M_sε_target/2 ⇒ 放大 ≤2×；(d) E[T]=c_draft+(1−p)(c_full+c_check)，P99≤c_draft+c_check+c_full^WCET，
投机只改善常见情况不改善最坏情况；(e) Fair-Audit 加权无偏，逃逸 ≤(1−p_audit)^m。
**引理 55（时延违约下的 CBF 不变式）** 准入 + backup ⇒ h_k≥min(h_0,h_min)≥0 对任意 k 成立；
安全性与推理速度解耦，推理越慢越早退到保守 stub。
**引理 56（低延迟路径不破坏等价性）** 无证书草案丢弃；提交对象仍是定义 417 契约更新；
claims 纯投影；缓存陈旧 ≤β_drift·τ_cache≤ε_spec 已并入引理 54(b)；数值等价性同第 1 轮引理 44。
**引理 57（公平 EDF）** U≤1 ⇒ 接纳任务全满足 deadline；年龄权重给出饥饿界 O(N_bl·τ_repair)；
过载转为精度降级而非实时性破坏。

## 8. 本轮最大风险

**一句话**：ServoGauge 把"慢审计"移出关键路径后，系统跑得比发现错误的速度更快——
若在线稳定裕度（ρ_LB、γ_ps）被低估或公共模抑制失效，投机提交会在慢路径反应过来之前
把局部先验误差放大成跨盲区共振，而唯一能发现它的正是被低延迟目标压缩的那条全量审计路径。

**三重兜底**：单侧保守下界 ρ_LB + 不变式 I6（ε_spec≤M_s·ε_target 否则冻结投机）+
定义 445 的时延违约 backup（安全性与推理速度解耦）；以 E446/E448/E451/E454 证伪。
