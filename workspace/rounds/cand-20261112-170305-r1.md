# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 7 轮；本轮灵感：「6D位姿估计」×「具身智能」）

> 第 60 轮把执行接地层升级为「认知驱动的场景—执行闭环」SGEC：场景语义先验 SSM 提前收敛 K_safe、认知意图 CIEC 锁定实时约束、ROS 因果隔离 EPIR 保证据链、SERC 统一闭环、PCE++++ 四维认知预算。但仍有**两个根本缺口**：
> 1. **场景先验不等于位姿确定**：SSM 只回答「这是什么场景」，不回答「物体究竟在哪、朝哪」。当物体被遮挡、纹理缺失或存在对称性时，6D 位姿后验是**多峰、甚至「自信地错误」**（bias 藏在小方差里）的；此时 EEIS 编译出的 K_safe 沿**错误方向**收敛，场景置信度再高也挡不住接触力爆炸。
> 2. **执行证据没有反哺位姿**：第 60 轮把接触遥测用于更新场景信念与阻抗，却未把「接触力残差」当作**位姿的观测**。具身智能的核心不是「先估计再执行」，而是**用身体去估计**——接触本身就是 6D 位姿的传感器。

## 0. 直觉与动机

**灵感 1（6D 位姿估计 → 位姿不确定性各向异性阻抗 PUAI）**
直觉：位姿协方差是一个**椭球**。若机器人沿椭球长轴（最不确定方向）保持高刚度，一个 3σ 位姿偏差就会被放大成 3σ·K 的接触力；反之沿已知方向保持高刚度才能精确贴合。所以「刚度椭球」应与「位姿协方差椭球」**共轴且反向**：不确定处柔软，确定处坚硬。关键洞见：**把位姿误差视为接触空间中的乘性扰动后，安全约束就变成对 `K·Σ^{1/2}` 算子范数的约束**，而非对单个 K 数值的约束。

**灵感 2（具身智能 → 具身主动位姿探测 EAPP）**
直觉：每次接触的力残差 ≈ K·J_c·δξ 本身就是位姿观测，因此「摸哪里」是一次**实验设计**。与其被动等到位姿误差造成失败，不如主动选一个「信息增益最大且自身安全」的探测动作。关键洞见：**探测动作与探测阻抗必须联合设计**——同一个动作，高刚度摸会伤物体，低刚度摸又测不出信息；它们是同一优化问题的两个变量。

**灵感 3（位姿多模态 → 位姿模态鲁棒阻抗 PMRI）**
直觉：对称物体（杯子、方块、圆柱）的位姿后验是**多个等概率峰**的混合而非单峰高斯。对单峰假设编译的 K，可能在某个「看不见的对称模态」下灾难性失效。此时应优化**尾部风险**（CVaR），并优先选择能**区分模态**（而非只缩小方差）的探测。关键洞见：多模态下「不确定性」不是方差大小，而是**模态质量分配**；消歧的信息价值 ≠ 方差缩减的信息价值。

**灵感 4（具身 → 可观测性—可执行性联合 EOJE）**
直觉：能否估准位姿，取决于**用什么身体姿态去接触**；能否执行，取决于**抓取是否可达、力闭合**。两者常冲突（俯视抓取易执行但看不到底面，侧向抓取可观测但易滑）。关键洞见：**抓取位姿是位姿估计与操作执行的共同自变量**，应联合优化而非串联。

**灵感 5（合流 → 具身位姿—执行闭环 BIPEL）**
直觉：把上述四者串成闭环：**位姿后验 → 各向异性安全阻抗 → 主动探测（信息+安全）→ 位姿贝叶斯更新 → 模态鲁棒操作阻抗 → 执行证据 → 位姿/场景信念更新**。这是对第 60 轮 SERC 的升级：从「场景→阻抗」扩展为「场景 × 位姿 × 身体 → 阻抗」。

**灵感 6（PCE+++++ → 具身信息预算）**
直觉：探测不是免费的——消耗节拍、带来接触风险、可能磨损物体。预算需新增 B_pose（估计算力/模态数）与 B_probe（允许接触次数、累计风险、时间）。当 B_probe 耗尽而位姿仍不可用时，应**膨胀协方差**得到保守位姿包络，而不是假装确定。

## 1. 形式化定义（增量：定义 161–169）

**定义 161（位姿不确定性各向异性阻抗 PUAI）** 设物体位姿 ξ ∈ SE(3)，估计 ξ̂，误差 δξ = ξ ⊖ ξ̂ ∈ se(3) ≅ R⁶，后验 δξ ~ N(0, Σ_ξ)。接触雅可比 J_c ∈ R^{6×6} 把位姿误差映射为接触空间位移 δx_c = J_c δξ，故接触空间有效协方差
```
Σ_c = J_c Σ_ξ J_cᵀ,   Σ_c = U diag(σ₁², …, σ₆²) Uᵀ
```
对刚度 K（接触空间），要求 1−α 置信椭球内任意位姿误差产生广义力/力矩不超界：
```
δξᵀ Σ_ξ⁻¹ δξ ≤ χ²_{6,1−α}  ⟹  ‖K δx_c‖₂ ≤ W_max
```
**充要条件（算子范数形式）**：令 β = W_max / √(χ²_{6,1−α})，则安全 ⟺
```
‖K J_c Σ_ξ^{1/2}‖₂ ≤ β   （等价地 ‖K Σ_c^{1/2}‖₂ ≤ β）
```
证明要点：令 y = Σ_ξ^{-1/2}δξ，椭球即 ‖y‖ ≤ √χ²；则 ‖K J_c δξ‖ = ‖K J_c Σ_ξ^{1/2} y‖ ≤ ‖K J_c Σ_ξ^{1/2}‖₂·‖y‖ ≤ β√χ² = W_max；反向取椭球边界上算子范数的极大方向即得必要性。
**编译规则**：沿 Σ_c 的特征方向取
```
k_i = min(k_max, β/σ_i),      K_pose = U diag(k₁,…,k₆) Uᵀ
可行 ⟺ ∀i: β/σ_i ≥ k_min
```
下界 k_min 保证可操作性；上界 k_max 抑制噪声放大。不可行方向集
```
D_inf = { i : β/σ_i < k_min }
```
即「再怎么软也顶不住 3σ 位姿误差」的方向，**自动触发 EAPP 主动探测或降级**——这是位姿不确定性与具身探测之间的形式化耦合。

**定义 162（具身主动位姿探测 EAPP）** 探测动作 a ∈ A（接触点、方向、力预算、持续时间），观测模型 z_a = h_a(ξ) + ε，Fisher 信息 J_a(ξ) ∈ R^{6×6}。Laplace 后验
```
Σ'_a = (Σ_ξ⁻¹ + J_a)⁻¹,   IG(a) = ½ log det(I + Σ_ξ J_a)
```
联合选择动作与探测阻抗：
```
(a*, K_a*) = argmax_{a,K} [ IG(a) − λ_r·R(a,K) − λ_t·τ(a) ]
s.t.  ‖K J_c Σ_ξ^{1/2}‖₂ ≤ β,   a ∈ A_exec,   τ(a) ≤ τ_probe
      R(a,K) = E_{δξ~N(0,Σ_ξ)}[ max(0, ‖K J_c δξ‖ − W_soft) ]
```
其中 R 为探测自身风险；W_soft ≤ W_max 为软阈值。**关键性质**：若 PUAI 给出 D_inf ≠ ∅，则 EAPP 的目标改写为「最小化不可行方向的方差」：
```
a* = argmax_a  Σ_{i∈D_inf} [J_a]_{ii,Σ_c}  − λ_r R(a,K_a*)
```
使探测直接服务于「让 K_pose 重新可行」。

**定义 163（位姿模态鲁棒阻抗 PMRI）** 位姿后验为混合 q(δξ) = Σ_m w_m N(μ_m, Σ_m)，模态 m 对应一个对称/假设模式。定义模态风险
```
ρ_m(K) = E_{δξ~N(μ_m,Σ_m)}[ ‖K J_c δξ‖ ]
CVaR_α(ρ) = min_θ { θ + (1/α) Σ_m w_m max(0, ρ_m(K) − θ) }
```
编译：
```
K* = argmin_K  E_q[ cost(K, δξ) ]
     s.t.  CVaR_α(ρ(K)) ≤ W_max,   K ⪰ k_min I
```
并定义**模态覆盖率** coverage(K) = Σ_{m: ρ_m(K) ≤ W_max} w_m，要求 coverage ≥ 1−α。
**消歧增益**（与方差缩减区分）：
```
IG_mode(a) = I(mode; z_a) = H(m) − E_{z_a}[H(m|z_a)]
```
若 IG_mode(a) > IG(a)，优先选**测试对称性**的探测（如双侧轻触、两点差分），而非单纯缩小方差。

**定义 164（具身可观测性—可执行性联合 EOJE）** 候选抓取 g，观测算子 E_g（把位姿映射为预期接触特征），Fisher
```
J_g = E_gᵀ N⁻¹ E_g,   O_g = ½ log det(I + Σ₀ J_g)
```
可执行性 X_g ∈ [0,1]（可达性、力闭合、碰撞裕度、关节限位）。联合评分
```
S(g) = α·O_g + (1−α)·X_g
g* = argmax_g S(g)   s.t.  X_g ≥ X_min
```
α 由任务精度需求与预算决定：精密插装偏重 O_g，快速搬运偏重 X_g。EOJE 与 EAPP 的接口是：E_g 提供 EAPP 中 J_a 的**预接触结构部分**。

**定义 165（具身位姿—执行闭环 BIPEL）** 算子 BIPEL(M, obj, task, budget)：
```
① Pose:      q ← pose_estimator.posterior(obj)            # 6D 位姿混合后验
② PUAI:      K_pose, D_inf ← compile(q.Σ, J_c, β, k_min, k_max)
③ Probe:     while D_inf ≠ ∅ and B_probe > 0:
                 (a*, K_a*) ← EAPP.select(q, K_pose, budget)
                 ev ← execute_probe(a*, K_a*); budget.B_probe -= 1
                 q ← pose_estimator.bayes_update(q, ev)
                 K_pose, D_inf ← compile(q.Σ, J_c, β, k_min, k_max)
             if D_inf ≠ ∅: return DEGRADE_POSE_UNSAFE
④ PMRI:      K_manip, cvar ← PMRI.compile(q, α)
⑤ Certify:   J_pose ← build_pose_certificate(q, K_manip, cvar)
             if not J_pose.valid: return DEGRADE_POSE_UNSAFE
⑥ Dispatch:  send_impedance_params(K_manip, J_pose)       # 与 EEIS/J_exec 合成
⑦ Execute:   telemetry ← wait_contact(); EV_exec ← build_exec_evidence(...)
⑧ Feedback:  q ← pose_estimator.residual_update(q, telemetry, K_manip)
             M ← SERC.update_scene_intent(M, q, EV_exec)
⑨ Memory:    EPIR.append(EV_exec); M.epir.sync()
⑩ Return:    (q, K_manip, EV_exec, J_pose, D_inf, budget.snapshot())
```

**定义 166（具身信息预算 B_emb 与 PCE+++++）** 在 B_cog 基础上新增两维：
```
B_emb = (B_scene, B_intent, B_ros, B_exec, B_pose, B_probe)
B_pose  = (Estimate_freq, Mode_count, Pose_compute)
B_probe = (Probe_count, Risk_budget, Probe_time)
```
**VOI 扩展**：
```
voi_emb(π) = VOI_meta_pessimistic(π) − cost_cog(π) − cost_exec(π) − cost_pose(π) − cost_probe(π)
cost_pose  = λ_est·Compute(pose) + λ_mode·Mode_count
cost_probe = λ_p·N_probe + λ_r·Risk(probe) + λ_t·Time(probe)
```
**降级规则**：
- B_pose 耗尽 ⇒ 冻结模态集，用上一后验并按时间衰减膨胀 Σ；
- B_probe 耗尽且 D_inf ≠ ∅ ⇒ 构造**保守位姿包络** Σ_cons = Σ + (κ·σ_floor)² I 后重编译；若仍不可行 ⇒ 力受限搜索/慢速护持/请求人工；
- B_exec 耗尽 ⇒ 沿用第 60 轮降级；B_scene/B_intent/B_ros 耗尽 ⇒ 沿用第 60 轮策略。

**定义 167（位姿安全证书 J_pose）** 证书
```
J_pose = (Σ_ξ, q_modes, K_used, W_max, α, margin, cvar, coverage, t_stamp, seq_id, probe_trace)
margin = W_max − ‖K_used J_c Σ_ξ^{1/2}‖₂·√(χ²_{6,1−α})
```
有效性：
```
J_pose.valid ⟺ margin ≥ 0 ∧ cvar ≤ W_max ∧ coverage ≥ 1−α
              ∧ (now − t_stamp) ≤ τ_stale ∧ seq_id 连续
```
与第 59 轮 J_exec **合成**：J_exec' = J_exec ∧ J_pose，即执行证书只有在「位姿安全证书有效」时才可签发；两者共享 seq_id 以接入 EPIR 因果链。

**定义 168（位姿—阻抗—证据三元组 PIET）** 给定位姿后验 q、阻抗 K、证据 EV：
```
PIET = (pose_calibration(q), K_safety(K, q), evidence_consistency(EV, K, q))
```
其中 evidence_consistency 用接触力残差度量：
```
r = ‖F_obs − K J_c δξ̂‖ / (‖F_obs‖ + ε)
```
若 r > τ_r，判定「位姿偏差未被方差覆盖」（bias 越界），执行**偏置护栏**：
```
Σ_total ← Σ_rand + Σ_bias,  Σ_bias ← Σ_bias + η·r²·(J_cᵀJ_c)⁻¹
```
并强制重编译 K、必要时触发 EAPP。

**定义 169（具身序贯决策 BESD）** 给定当前位姿后验 q 与任务 T，决策规则：
```
if J_pose(q, K_manip).valid:
     EXECUTE
elif E[IG(a*)]·λ_info > cost_probe(a*) + λ_r·R(a*,K*) and B_probe > 0:
     PROBE(a*, K*)
elif D_inf ≠ ∅ and B_probe = 0:
     DEGRADE_CONSERVATIVE   # 保守包络 / 力受限搜索 / 人工
else:
     DEGRADE_POSE_UNSAFE
```
关键：**是否探测由「信息期望收益 vs 物理风险」决定**，而非固定的探测次数；避免无价值探测与过度保守。

## 2. 关键算法伪代码

### IP-161 PUAI（位姿不确定性各向异性阻抗）

```python
class PoseUncertaintyImpedance:
    def __init__(self, W_max, alpha=0.05, k_min=10.0, k_max=5000.0):
        self.W_max = W_max
        self.chi2 = chi2.ppf(1 - alpha, df=6)
        self.beta = W_max / np.sqrt(self.chi2)
        self.k_min, self.k_max = k_min, k_max

    def compile(self, Sigma_pose, J_contact):
        Sigma_c = J_contact @ Sigma_pose @ J_contact.T
        Lam, U = np.linalg.eigh(Sigma_c)
        sig = np.sqrt(np.clip(Lam, 1e-12, None))
        k = np.minimum(self.k_max, self.beta / sig)
        D_inf = [i for i in range(6) if self.beta / sig[i] < self.k_min]
        K = U @ np.diag(k) @ U.T
        margin = self.W_max - np.linalg.norm(K @ np.diag(sig), 2) * np.sqrt(self.chi2)
        return K, D_inf, margin
```

### IP-162 EAPP（具身主动位姿探测）

```python
class EmbodiedActivePoseProber:
    def __init__(self, actions, risk_model, lam_r=1.0, lam_t=0.1):
        self.actions, self.risk_model = actions, risk_model
        self.lam_r, self.lam_t = lam_r, lam_t

    def select(self, q, K_pose, budget, infeasible_dirs):
        best = None
        for a in self.actions:
            J = self.fisher(a, q)
            Sigma_post = np.linalg.inv(np.linalg.inv(q.Sigma) + J)
            ig = 0.5 * (logdet(q.Sigma) - logdet(Sigma_post))
            if infeasible_dirs:
                ig = self._directional_gain(J, infeasible_dirs, q.Sigma)
            risk = self.risk_model(a, K_pose, q)
            if not self.safe_under(a, K_pose, q):
                continue
            score = ig - self.lam_r * risk - self.lam_t * a.cost
            if best is None or score > best['score']:
                best = {'action': a, 'posterior': Sigma_post,
                        'ig': ig, 'risk': risk, 'score': score}
        return best
```

### IP-163 PMRI（位姿模态鲁棒阻抗）

```python
class PoseModeRobustImpedance:
    def compile(self, mixture, alpha=0.1, W_max=20.0):
        K0 = self._nominal_from_mixture(mixture)
        K = solve_cvar_program(
            objective=lambda K: self._expected_cost(K, mixture),
            cvar_constraint=lambda K: self._cvar(self._mode_risks(K, mixture), alpha),
            W_max=W_max, K0=K0, k_min=self.k_min)
        coverage = sum(w for m, w in zip(mixture.modes, mixture.weights)
                       if self._mode_risk(K, m) <= W_max)
        return K, coverage

    def disambiguation_gain(self, a, mixture):
        return mutual_information(mixture.modes, a.observation_model)
```

### IP-164 EOJE（可观测—可执行联合选抓）

```python
class EmbodimentObservabilityExecutability:
    def select_grasp(self, obj, q0, alpha=0.5, X_min=0.6):
        best = None
        for g in self.candidate_grasps(obj):
            E_g = self.observation_operator(g)
            J_g = E_g.T @ np.linalg.inv(self.noise_cov) @ E_g
            O_g = 0.5 * logdet(np.eye(6) + q0.Sigma @ J_g)
            X_g = self.executability(g)
            if X_g < X_min:
                continue
            score = alpha * O_g + (1 - alpha) * X_g
            if best is None or score > best['score']:
                best = {'grasp': g, 'score': score, 'O': O_g, 'X': X_g}
        return best
```

### IP-165 BIPEL（具身位姿—执行闭环）

```python
def body_integrated_pose_execution_loop(M, obj, task, budget):
    q = M.pose_estimator.posterior(obj)
    K_pose, D_inf, _ = M.puai.compile(q.Sigma, M.contact_jacobian(obj))
    probe_trace = []

    while D_inf and budget.B_probe > 0:
        plan = M.prober.select(q, K_pose, budget, D_inf)
        if plan is None:
            break
        ev = M.execute_probe(plan['action'], K_pose)
        q = M.pose_estimator.bayes_update(q, ev)
        budget.B_probe -= 1
        probe_trace.append((plan['action'], plan['ig'], ev.residual))
        K_pose, D_inf, _ = M.puai.compile(q.Sigma, M.contact_jacobian(obj))

    if D_inf:
        return degrade_pose_unsafe(M, q, D_inf)

    K_manip, cvar = M.pmri.compile(q, alpha=M.pmri_alpha)
    J_pose = build_pose_certificate(q, K_manip, cvar, M.W_max, probe_trace)
    if not J_pose.valid:
        return degrade_pose_unsafe(M, q, D_inf)

    dispatch_impedance_params(K_manip, J_pose)
    telemetry = wait_contact()
    EV_exec = build_exec_evidence(telemetry, K_manip, J_pose)
    q = M.pose_estimator.residual_update(q, telemetry, K_manip)
    M = M.serc.update_scene_intent(M, q, EV_exec)
    M.epir.append(EV_exec.__dict__)
    M.epir.sync()
    return q, K_manip, EV_exec, J_pose, budget.snapshot()
```

### IP-166 PCE+++++（具身信息预算）

```python
class EmbodiedBudget:
    def __init__(self, scene_ops=100, intent_ops=50, ros_retry=3,
                 pose_ops=200, probe_count=3, risk_budget=5.0):
        self.B_scene, self.B_intent, self.B_ros = scene_ops, intent_ops, ros_retry
        self.B_pose, self.B_probe = pose_ops, probe_count
        self.risk_budget = risk_budget
        self.exec_budget = ExecBudget()

    def probe_worthwhile(self, ig, risk, cost):
        return ig * self.lam_info > cost + self.lam_r * risk

    def conservative_envelope(self, Sigma, sigma_floor=0.005, kappa=3.0):
        return Sigma + (kappa * sigma_floor) ** 2 * np.eye(6)

    def fallback(self, pose_feasible):
        if self.B_probe <= 0 and not pose_feasible:
            return 'conservative_pose_envelope'
        if self.B_pose <= 0:
            return 'frozen_mode_prior'
        return 'normal'
```

**正确性定理（BIPE）**：设 A66–A70 成立：
- **(A66) 校准性**：位姿后验在无偏时满足 P(δξᵀΣ_ξ⁻¹δξ ≤ χ²_{6,1−α}) ≥ 1−α；偏置由 Σ_bias 单独有界。
- **(A67) 小误差线性化**：接触空间 δx_c = J_c δξ 的一阶近似误差 ≤ ε_lin。
- **(A68) 信息模型**：探测量测噪声高斯，Fisher 信息 J_a 可计算，Laplace 后验近似误差有界。
- **(A69) 模态覆盖**：真实模态属于混合支撑集，且先验质量 ≥ 1−α。
- **(A70) 身体模型**：E_g、J_c、抓取可执行性函数已知且连续。

则：
1. **位姿安全（PUAI）**：若 J_pose.valid 且 A66/A67 成立，则对置信椭球内任意位姿误差，接触广义力满足 ‖w‖ ≤ W_max + O(ε_lin)；即安全概率 ≥ 1−α。
2. **探测信息单调性（EAPP）**：贝叶斯更新后 Σ' ≼ Σ（Loewner 序），且对探测序列
   ```
   log det(Σ_T⁻¹) = log det(Σ_0⁻¹) + Σ_{t=1}^{T} log det(I + Σ_{t−1} J_t)
   ```
   故不确定度单调不增；贪心 D-optimal 选择在信息增益近似次模时具 (1−1/e) 近似保证。
3. **模态鲁棒（PMRI）**：若 CVaR_α(ρ(K*)) ≤ W_max，则质量 ≥ 1−α 的模态均安全；消歧探测使模态熵下降，从而降低期望风险。
4. **闭环安全（BIPEL/BESD）**：若任一 B_emb 分量耗尽，必触发对应显式降级；且永不签发无效 J_pose，故不存在「用错误位姿执行高刚度操作」的路径。

### IP-161 PUAI（位姿不确定性各向异性阻抗）

```python
class PoseUncertaintyImpedance:
    def __init__(self, W_max, alpha=0.05, k_min=10.0, k_max=5000.0):
        self.W_max = W_max
        self.chi2 = chi2.ppf(1 - alpha, df=6)
        self.beta = W_max / np.sqrt(self.chi2)
        self.k_min, self.k_max = k_min, k_max

    def compile(self, Sigma_pose, J_contact):
        Sigma_c = J_contact @ Sigma_pose @ J_contact.T
        Lam, U = np.linalg.eigh(Sigma_c)
        sig = np.sqrt(np.clip(Lam, 1e-12, None))
        k = np.minimum(self.k_max, self.beta / sig)
        D_inf = [i for i in range(6) if self.beta / sig[i] < self.k_min]
        K = U @ np.diag(k) @ U.T
        margin = self.W_max - np.linalg.norm(K @ np.diag(sig), 2) * np.sqrt(self.chi2)
        return K, D_inf, margin
```

### IP-162 EAPP（具身主动位姿探测）

```python
class EmbodiedActivePoseProber:
    def __init__(self, actions, risk_model, lam_r=1.0, lam_t=0.1):
        self.actions, self.risk_model = actions, risk_model
        self.lam_r, self.lam_t = lam_r, lam_t

    def select(self, q, K_pose, budget, infeasible_dirs):
        best = None
        for a in self.actions:
            J = self.fisher(a, q)
            Sigma_post = np.linalg.inv(np.linalg.inv(q.Sigma) + J)
            ig = 0.5 * (logdet(q.Sigma) - logdet(Sigma_post))
            if infeasible_dirs:
                ig = self._directional_gain(J, infeasible_dirs, q.Sigma)
            risk = self.risk_model(a, K_pose, q)
            if not self.safe_under(a, K_pose, q):
                continue
            score = ig - self.lam_r * risk - self.lam_t * a.cost
            if best is None or score > best['score']:
                best = {'action': a, 'posterior': Sigma_post,
                        'ig': ig, 'risk': risk, 'score': score}
        return best
```

def body_integrated_pose_execution_loop(M, obj, task, budget):
    q = M.pose_estimator.posterior(obj)
    K_pose, D_inf, _ = M.puai.compile(q.Sigma, M.contact_jacobian(obj))

### IP-168 PIET（偏置护栏）

```python
def piet_update(q, K, F_obs, J_c, tau_r=0.2, eta=0.5):
    delta = q.mean_error_projection(J_c)
    r = np.linalg.norm(F_obs - K @ J_c @ delta) / (np.linalg.norm(F_obs) + 1e-9)
    if r > tau_r:
        q.Sigma_bias += eta * r**2 * np.linalg.inv(J_c.T @ J_c)
        q.Sigma = q.Sigma_rand + q.Sigma_bias
        q.force_recompile = True
    return q, r
```
