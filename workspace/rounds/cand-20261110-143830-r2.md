# 第 45 轮（新循环第 5 轮） · Interaction-Cert × Latency-Cert：把「交互设计」与「低延迟推理」纳入证书闭环（四层架构 v10）

> 承接第 44 轮 v21（Intent-Cert × Foundation-Proposer）。v21 已把「意图理解」与「大模型提议」纳入闭环，但它仍压着两个未言明的假设：**(H5) 交互是外生的、一次性的问答**——澄清被建模成一个有成本的查询，而真实交互设计是协议、承诺、可理解性与修复，且人的未来行为会被机器人的行为与延迟**反向塑造**；**(H6) 证书与推理延迟解耦**——anytime 被视为免费的 sound，默认早退、投机、量化、缓存不会触碰证书的可靠性包络。本轮两个灵感词精确命中这两个假设：**「交互设计」**迫使我们把通信动作提升为一等动作，并证明「说出去的话」不会破坏安全；**「低延迟推理」**迫使我们给证书加上时间维度与计算溯源。二者耦合处是本轮真正的硬问题：**延迟诱导的交互不稳定**（慢→人接管/重复→负载更高→更慢）与**承诺通胀**（赶 deadline 先承诺后认证）。

## 0. 直觉与动机

**灵感 1（交互设计 → 交互是协议，不是一次问答）**：把「澄清」当成一个查询、把人当成答案分布，是 v21 最省事也最脆弱的抽象。真实交互设计关心的是：机器人**说什么**（inform/commit/explain/request-help）、**什么时候说**、**说了算不算数**、以及人是否**能预测和纠正**它。因此本轮把通信动作建模为一等动作：`inform` 必须被当前证书蕴含（不能说没证据的话），`commit` 会在承诺账本里生成一条必须在时限内履行或修复的义务，`explain` 是承诺的弱形式（解释若给出过度保证，等价于隐性承诺）。一句话：**交互设计 = 可预测 + 可纠正 + 可承诺，而这三件事都必须进证书。**

**灵感 2（低延迟推理 → 证书要证明「我算得够快，且算的是对的东西」）**：低延迟推理不是把证书删掉，而是给证书加上**时间维度**和**计算溯源**。同一条结论，用满精度模型算出来、用 INT8 早退算出来、用缓存命中算出来，可靠性包络是不同的；投机解码更是「先猜后验」，猜中的部分可信、未验的部分不可信。于是引入**延迟证明证书（DAC）**：每条结论携带计算溯源 p=(tier, approximation, quantization, input_age)、该配置的可靠包络 E、硬 deadline D 和时延证明 A。**只有当实际计算落在被背书的包络内、输入足够新鲜、且在 deadline 前完成时，证书才可用。** 这句话把「低延迟」从工程优化变成可静态审计的安全论证。

**灵感 3（耦合 → 延迟诱导的交互不稳定与承诺通胀）**：延迟不是中性的性能指标，它是交互设计的一部分。系统响应慢，人会接管、重复指令、改用肢体动作；这些新行为又抬高感知与意图负载，进一步拉长延迟——这是一个正反馈环。同时，deadline 压力会诱导系统在证书尚未 firm 时就先对人类说「我马上过去」，形成**承诺通胀**。两者叠加：延迟越高→越早承诺→人基于承诺行动→一旦未履行则更危险。因此必须同时有**闭环稳定性证书**（限制延迟-负载-接管的增益）和**承诺预算**（凭空承诺不得超过确定性与能力上界）。

**耦合升级**：IPE（交互协议引擎）把交互编译成带前置/后置条件、承诺账本与修复策略的协议；DCR（期限感知证书运行时）把计算溯源、延迟证明、临时/正式证书分档与尾部隔离做进认证栈；ILV（交互-延迟验证器）在仿真里做闭环延迟注入、人的行为漂移、承诺审计与协议一致性检查。四层架构由 v9 的「人格契约层 + 并发证书层 + 意图证书层」升级为 v10 的「…… + 交互协议层 + 期限证书层」。

## 1. 形式化定义（增量：定义 51–57）

**定义 51（交互协议与通信动作的证书语义）**：交互协议 P_u=(Σ_c, pre, post, K, Repair)：Σ_c 为通信动作集 \{inform, query, commit, explain, request-help\}，pre/post 为通信动作的前/后置条件，K 为**承诺账本**，Repair 为有界修复策略。**通信 soundness**：(a) `inform` 的命题必须被当前有效证书蕴含；(b) `commit` 生成义务 o∈K，必须携带可履行的能力界与时限；(c) `explain` 必须是决策轨迹的**忠实抽象**（定义 57），不得断言超出证书的保证。**协议可认证**：∀σ∈Σ_c，执行 σ 保持安全关键谓词，且 K 中义务不超过能力与确定性上界。**推论**：通信不是「免费的信息输出」，而是一类会改变世界状态（人的知识、承诺、期待）的动作，必须与运动动作同受守卫。

**定义 52（内生人类响应与交互闭环稳定性）**：人类响应不是一个固定分布，而是 h_{t+1} ~ Q_θ(· | h_t, a_t, σ_t, τ_t, e_t)，显式依赖机器人动作、通信、**延迟 τ_t** 与解释 e_t。交互闭环映射 T: (h_t, 状态) ↦ (h_{t+1}, 负载 L_{t+1}, 延迟 τ_{t+1})。定义**延迟诱导的接管率** P_takeover(τ)，以及**闭环稳定性**：存在有界集 S，使 T(S)⊆S 且负载-延迟增益 < 1。**命题**：若闭环不稳定，任何逐帧 sound 的证书都会被系统级的「越慢越乱、越乱越慢」拖垮，因为人的行为分布持续移出校准集。**交互稳定性证书**要求给出 τ 区间内的增益上界，而不只是单步安全性。

**定义 53（计算溯源与延迟证明证书 DAC）**：证书 c=(claim, p, E, D, A)：p=(tier, approximation, quantization, input_age) 为**计算溯源**，E=sound_envelope(p) 为该计算配置下可背书的保证集合，D 为硬 deadline，A 为时延证明。**可用判据**：c 可用 ⇔ claim∈E ∧ t_complete≤D ∧ input_age≤input_age_max。**临时证书 vs 正式证书**：临时证书（早退/投机/近似）只在**更小的包络**内 sound；正式证书需完整计算。**定理（溯源 soundness）**：若签名者无法让实际计算越过 E 所绑定的配置，则用可用证书做的守卫决策 sound；越界使用临时证书是唯一的破口。**注**：这把「用了什么算力、什么近似」从运行时隐变量变成证书的可审计字段。

**定义 54（期限感知决策与风险-延迟前沿）**：每个候选动作 a 有一个风险-延迟剖面 (R_a(τ), L_a(τ))。**期限感知决策**：a* = argmax_{a: L_a≤D ∧ cert(a) 可用} U(a) − ρ·R_a。若在 D 前没有任何可用正式证书，**必须**转入被认证的 SafeStop 或最小承诺，而不是消耗出包络的临时证书。**推论**：deadline miss 本身是一个**被认证的动作**，而不是「来不及就赌一把」；这把低延迟推理的最坏情况纳入安全论证。

**定义 55（承诺预算与承诺通胀）**：承诺账本 K 的每条义务 o=(内容, 时限, 能力消耗)。**承诺预算** B_commit 限制未履行义务的总能力消耗；**承诺 soundness**：每条义务要么在时限内履行，要么在时限前进入 Repair 并给出可验证的降级。**承诺通胀**定义为「承诺确定性需求低于当前证书等级」的比例（如用临时证书支撑不可逆承诺）。**命题**：在 deadline 压力下，最小化延迟的目标会自然诱导承诺通胀，因此 B_commit 与确定性门槛必须与延迟目标**反相关**（越紧的 D，越严的承诺门槛），否则系统会系统性地先承诺后认证。

**定义 56（端到端时限与尾部延迟隔离）**：端到端链路为感知→意图→认证→决策→执行→通信，各段有 WCET 与 p99.9 尾延迟。**时限继承**：下游安全动作的 deadline 反向约束上游认证；**尾部隔离**：认证器固定最高关键级，其预算不随 LO/HI 模式收缩（复用 IP-58 混合关键级）。**定理（时限安全）**：若认证器满足 WCET、且安全决策只使用正式证书或包络内临时证书，则任一环节 deadline miss 只能导致 SafeStop，不能导致不 sound 的驱动。

**定义 57（解释忠实性与可理解性证书）**：解释 e 是决策轨迹 π 的抽象。**忠实性**：e 必须是 π 的合法抽象（存在投影 π→e），而非事后合理化（post-hoc rationalization）。**可理解性证书**：用校准集测「人类依据 e 预测机器人未来 k 步」的准确率 L_k，并要求 L_k 达到阈值且**不因 e 产生超出证书的安全期待**。**命题**：解释是承诺的弱形式（隐性承诺）；不忠实或过度保证的解释会污染定义 52 的人模型，进而反向破坏交互稳定性。**注**：这解释了为什么「解释模块」不能是纯产品层装饰，它必须进认证器。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-63 INTERACTION-PROTOCOL-ENGINE（交互协议引擎 IPE）
1. **协议编译**：由人格契约、能力界与通信集编译出带 pre/post 条件的通信动作表；inform 内容必须可由有效证书蕴含。
2. **通信闸门**：说之前先过守卫（不引入不安全状态/错误期待/非干扰安全谓词）；commit 前查承诺账本与确定性门槛，不足则 DEFER。
3. **承诺账本与修复**：记录每条义务（内容、时限、能力消耗），到期前触发履行或可验证降级（Repair），防承诺通胀。
4. **可理解性与长期约定**：校准 L_k，支持显式约定（「我走右边」）作为降低歧义的协议状态，而非每步重猜。

### 2.2 IP-64 DEADLINE-CERT-RUNTIME（期限感知证书运行时 DCR）
1. **计算溯源**：每条证书记录 tier/近似/量化/输入年龄，绑定实际计算配置。
2. **延迟证明与分档**：临时证书（早退/投机/缓存）只在更小包络内可用；正式证书走完整认证；越界即拒绝。
3. **期限感知决策 + SafeStop**：风险-延迟前沿上选动作；无可用证书则 SafeStop 或最小承诺，绝不赌。
4. **尾部隔离与时限继承**：认证器最高关键级、预算硬隔离；上游 deadline 由下游安全动作反推。

### 2.3 IP-65 INTERACTION-LATENCY-VALIDATOR（交互-延迟验证器 ILV）
1. **闭环延迟注入**：在仿真中注入可控延迟/抖动/尾延迟，观测人的接管、重复、手势等行为漂移。
2. **承诺审计**：检查承诺通胀率、未履行义务、修复是否在时限内、承诺与证书等级是否匹配。
3. **协议一致性 fuzz**：并发说话/打断/矛盾承诺/快速用户切换，检出协议交错违例。
4. **解释忠实性回归**：金标轨迹比对，检出 post-hoc 合理化与过度保证。
5. **稳定性曲线**：扫描 τ，测安全-可用-稳定性三角，给出 E104 的稳定域。

回退：E103 不达标 → 关闭主动通信，仅保留安全必需询问；E104 不达标 → 非自适应保守协议、固定低延迟、禁用长期约定；E105 不达标 → 只用正式证书，无可用即 SafeStop；E106 不达标 → 放宽 deadline、削减并发；E107 不达标 → 收紧承诺预算、单一活跃承诺；E108 不达标 → 只输出证书内最小解释；E109 不达标 → 交互串行化、单一活跃用户；E110 失败 → 全链路熔断回退 v21。

## 5. 本轮最大风险

**一句话**：我们把「人」写成了一个可学习但不可验证的响应模型 Q_θ，而低延迟又在实时地改变这个模型——于是证书能证明机器人，却证明不了「机器人自己的延迟与承诺如何改变人」；一旦闭环被延迟推向振荡或承诺通胀，所有针对单步包络的 soundness 都会被系统性地绕过，因此 E104（闭环稳定性）与 E105（临时证书包络）必须设为红线，默认回退到「非自适应保守协议 + 只用正式证书 + 超时 SafeStop」这条不变式。

# 第 45 轮产物 · 创新点清单 v22：Interaction-Cert × Latency-Cert（IPE × DCR × ILV）× 可验证交互-延迟闭环（四层架构 v10）

## 2. 关键算法（伪代码）

### IP-63 IPE：协议编译、通信闸门、承诺账本与修复
```
def compile_interaction_protocol(persona, cert_caps, comm_set):
    acts = []
    for s in comm_set:
        if not cert_caps.entails(s.content):        # inform 必须被证书蕴含
            continue
        pre  = safe_to_say(s, persona)              # 说话不引入不安全状态/错误期待
        post = epistemic_effect(s)                  # 改变人的知识/承诺/期待
        acts.append(CommAct(s, pre, post, commitment_of(s)))
    P = Protocol(acts, repair=bounded_repair(comm_set),
                 legibility=calibrate_legibility())  # L_k 校准
    return P

def communication_gate(act, state, P, ledger):
    if not P.pre(act, state):            return BLOCK
    if intersects_critical(act, state):  return BLOCK   # 复用 IP-58 非干扰
    if act.is_commit:
        if act.certainty < cert_tier_required(state):   # 临时证书不得支撑硬承诺
            return DEFER
        if not ledger.can_commit(act.obligation, state.capability, B_commit):
            return DEFER
        ledger.add(act.obligation, deadline=state.deadline)
    return ALLOW

def repair_step(ledger, t):
    for o in ledger.overdue_or_at_risk(t):
        r = choose_repair(o)              # 限时降级/撤回/求助，均可验证
        if r is None: return SAFE_STOP
        ledger.replace(o, r)
    return OK
```

### IP-64 DCR：计算溯源、延迟证明、分档认证与期限决策
```
def make_cert(claim, p, D):
    E = sound_envelope(p)                 # 绑定 tier/approx/quant 的可靠包络
    if claim not in E: return INVALID     # 越包络的结论不可背书
    return Cert(claim, p, E, D, A=attest(p))

def usable(c, t, input_age):
    return (c.deadline >= t) and (input_age <= c.p.max_age) \
       and (c.p.actual <= c.E.bound)          # 实际计算不得超出包络

def deadline_decision(proposals, D, ledger):
    firm = [c for c in certify_all(proposals, tier=FIRM)
            if usable(c, now(), input_age(c))]
    if firm:
        return choose_by_utility(firm)         # 正常路径
    prov = [c for c in certify_all(proposals, tier=PROVISIONAL)
            if usable(c, now(), input_age(c)) and c.claim in c.E]
    if prov and min_latency(prov) <= D:
        return choose_within_envelope(prov)    # 仅包络内使用临时证书
    if now() >= D:
        return SAFE_STOP()                     # deadline miss 是被认证的动作
    return defer_or_minimal_commit(ledger)     # 不赌、不越包络

def deadline_aware_pca(o, G, persona, D, ledger):
    cand = propose_action_and_comm(o, G)
    certs = parallel_certify(cand, budget=D)   # 早退/投机/INT8 分档
    return deadline_decision(certs, D, ledger)
```

### IP-65 ILV：闭环延迟注入、承诺审计与协议一致性
```
def closed_loop_latency_sweep(protocol, human_model, tau_grid):
    results = []
    for tau in tau_grid:
        h, state, load = init()
        for t in range(T_horizon):
            a, sigma = robot_step(state, protocol, tau)     # 延迟影响决策时刻
            e = explain(state, a)                            # 解释污染人模型
            h = human_model.step(h, a, sigma, tau, e)        # 内生响应
            load = update_load(load, h, state)
            tau = latency_model(load)                        # 负载反馈到延迟
            results.append(audit(state, protocol, h, tau))
        if diverged(results): return UNSTABLE
    return stability_region(results)

def audit_commitment(ledger, certs, t):
    for o in ledger.all():
        if o.certainty_at_commit > cert_tier_at(o.time):
            return INFLATION                  # 承诺通胀
        if not (o.honored_by(t) or o.repaired_by(t)):
            return UNSOUND_COMMIT
    return OK

def audit_explanation(trace, e, gold):
    if not is_valid_abstraction(trace, e): return POSTHOC_RATIONALIZATION
    if asserts_beyond_cert(e, trace):      return OVERPROMISE
    if legibility(e) < L_min:              return UNINTELLIGIBLE
    return OK
```

### IP-61/58 升级：期限感知三分与承诺预算
```
def pca_step_v2(o, G, persona, D):
    certs = collect_usable_certs(o, G, persona, D)
    execs = [c for c in certs if c.claim.kind == EXEC]
    if execs and achieves_core(execs, G.core):
        a = best(execs)
        if is_irreversible(a):
            ok = irreversible_gate(a, G, persona) and \\
                 commitment_gate(a, persona, required=FIRM)
            return EXEC(a) if ok else CLARIFY(best_query(G))
        return EXEC(a)
    q = argmax_clarification(G, persona, D)
    if q is not None and value(q) >= V_min:
        return CLARIFY(q)
    if now() >= D:
        return SafeStopMode()                    # 不消耗出包络临时证书
    return COMMIT(least_commitment_safe(o, G, persona))

def commitment_gate(a, persona, required):
    return active_cert_tier(a) >= required and \\
           persona.commit_budget >= cost(a) and \\
           persona.consent.valid_and_revocable()
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性保证 |
|---|---|---|---|
| IP-63 协议编译 | O(\|Σ_c\|·\|cert\|) 一次性 | 协议 O(\|Σ_c\|) | inform 须被证书蕴含 ⟹ 无证据通信为 0 |
| IP-63 通信闸门 | O(\|pre\|+\|K\|) | 账本 O(\|K\|) | 非干扰 + 承诺预算 ⟹ 通信不破坏安全 |
| IP-63 修复 | O(\|K\|) 每周期 | O(\|K\|) | 义务履行或限时降级 ⟹ 承诺 sound |
| IP-64 分档认证 | O(b·T_cert(tier)) | 每证书 O(1) | 越包络拒绝 ⟹ 临时证书不静默提权 |
| IP-64 期限决策 | O(b log b) | O(b) | 仅用可用证书；miss→SafeStop ⟹ 无不 sound 驱动 |
| IP-64 溯源证明 | O(1) 校验 | O(1) | 实际计算∈E ⟹ 结论在包络内 sound |
| IP-65 延迟扫描 | O(\|τ\|·T_horizon) 离线 | 轨迹 O(T) | 覆盖稳定/发散区 ⟹ E104 稳定域可标定 |
| IP-65 承诺审计 | O(\|K\|) | 日志 O(\|K\|) | 承诺等级匹配 ⟹ 承诺通胀可检出 |
| IP-65 解释审计 | O(\|trace\|+\|e\|) | O(\|trace\|) | 合法抽象 + 不越证 ⟹ 无过度保证 |
| IP-61 期限三分 | O(b·\|Ĝ\|) | O(\|Ĝ\|) | 承诺预算 + SafeStop ⟹ 时间压力不降低 soundness |

**工程含义**：安全性 = f(认证器 + 包络校验 + 承诺预算)，延迟 = f(分档与并行)，交互质量 = f(协议与解释)。三者解耦：换更快的推理只影响临时证书的可用频率与 E106，不改变 E103/E105 的违例红线；换更好的解释只影响可理解性，不得突破定义 57 的忠实性与不越证约束。

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 内生人模型 Q_θ 不可验证，证书建立在经验模型上 | 高 | E104 红线；稳定域只在标定 τ 区间内声明；超出即回退保守协议 |
| 临时证书越包络使用（为了赶 deadline 静默提权） | 高 | E105 红线；包络由计算溯源静态绑定；越界即拒绝并 SafeStop |
| 承诺通胀：时间压力下先承诺后认证 | 高 | E107 红线；承诺预算 + 确定性门槛与 D 反相关；承诺审计 |
| 延迟-负载正反馈导致交互振荡 | 高 | E104；限制并发/自适应降级；固定低延迟兜底 |
| 解释事后合理化或过度保证，污染人模型 | 中-高 | E108 红线；解释必须为轨迹合法抽象且不越证；解释不进认证决策 |
| 通信动作与安全谓词相交（说错话即不安全） | 中-高 | 通信闸门复用 RG 非干扰；inform 须证书蕴含；协议编译静态检查 |
| 尾部延迟抖动使 deadline miss 频发 | 中 | E106；尾隔离 + 时限继承；miss 即 SafeStop，不降级到不 sound |
| 多用户并发说话/承诺交错，协议状态撕裂 | 中 | E109；协议状态原子快照（复用 seqlock）；单一活跃承诺兜底 |
| 修复策略本身失败或超时 | 中 | 修复带时限与可验证降级；失败即 SafeStop；审计日志 |

## 6. 本轮最大风险

**一句话**：我们把「人」写成了一个可学习但不可验证的响应模型 Q_θ，而低延迟又在实时地改变这个模型——于是证书能证明机器人，却证明不了「机器人自己的延迟与承诺如何改变人」；一旦闭环被延迟推向振荡或承诺通胀，所有针对单步包络的 soundness 都会被系统性地绕过，因此 E104（闭环稳定性）与 E105（临时证书包络）必须设为红线，默认回退到「非自适应保守协议 + 只用正式证书 + 超时 SafeStop」这条不变式。
