# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「视觉语言动作模型」×「开放词汇」）

> R69 让闭环学会了「问」：aleatoric 收紧，epistemic 去交互消解，信息动作也要过安全认证。但它问的所有东西——动作模态、证据源、问句、不变量——都活在一个**已经命名、已经枚举、因而闭合的语义宇宙**里。R69 的证据纪律假设「来源」是有限的、可列数的；它的证书假设 `φ`（安全不变量）能用已知词表写出来；它的现实锚假设「这个上下文/物体」在册。
>
> 本轮两个灵感把这个世界**撬开**：
> - **视觉语言动作模型（VLA）** 给出语言↔视觉↔动作的桥：能用自由语言下指令、能对没见过的物体做零样本动作、能对同一场景给出语义解释——但它的「理解」是把词映射到**看似合理的行为**，不是验证世界真的符合这个词。
> - **开放词汇（open-vocabulary）** 让感知能给**任何东西**起名：长尾物体、新材质、新意图。它廉价地扩大了标签覆盖，却把每个新名字变成一个**没有锚、没有不变量、没有校准**的假设；更糟的是，命名会制造一种「我知道了」的错觉。
>
> 核心命题：**开放词汇买的是「标签覆盖」，不是「语义接地」；VLA 买的是「语言条件下的合理性」，不是「世界验证」。必须把语义不确定性再拆一层——`U_lex`（命名）与 `U_aff`（可供性接地）——并规定：只有通过「现实语义锚 + 可用不变量」认证、被「闭卷」的词，才拥有改动安全包络的权限；未闭卷的新词默认隔离。** 命名 **LEXICON-RAS**（**L**anguage-grounded **EX**pansion with **I**nvariant **C**ertification of **O**pen **N**ovelties：用不变量认证给开放新词颁发「闭卷」证书的语义安全闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**一个名字到底意味着什么，谁有权让一个新词去碰刹车？**」——命名不是认知，词典不是世界；开放词汇只能提议，不能授权。

## 0. 直觉与动机

**灵感 1（VLA：语言是一条低带宽、高偏置的压缩通道）**
直觉：VLA 把 (图像, 指令) 映射成动作，于是机器人能听懂「把药放进抽屉」「绕过那个东西」这类从未见过的组合。但语言是**有损压缩**：一个词只保留了世界的一小片，且保留的是**对人类重要的那一片**。「刀」这个词压掉了刃口朝向、温度、是否是玩具、是否连着电线；「杯子」压掉了里面装的是水、药还是漂白剂。危险恰恰藏在被压掉的维度里。VLA 的强项是把词映射到**看起来合理**的行为，它没有被训练去验证「世界确实符合这个词」。因此：**语言接地的产物是假设，不是观测；流畅的动作不是正确的动作。**

**灵感 2（开放词汇：命名不是认知）**
直觉：开放词汇检测/分类（CLIP 式零样本、任意文本查询）解决了「标签覆盖」的长尾问题：你可以给任何东西起个名，甚至起一个训练集里没有的名字。但由此产生一种危险的替换——**把「闭词表覆盖」冒充成「本体论覆盖」**：既然它被命名了，我们就以为自己知道它是什么、会怎么反应。可一个名字既不携带可供性，也不携带失效模式。对任意新物体，top-1 标签可能语义上很合理、物理上完全错（玩具刀/真刀、装饰/危险品、道具/活物）。**开放词汇不是减少了错误假设，而是增加了「看起来合理」的错误假设的数量。**

**灵感 3（证书是闭世界契约，开放词汇击穿它的支撑集）**
直觉：R69 的 `J_FLUID`、`φ`、现实锚、模型类都定义在一个有限枚举的词表 `𝒱_closed` 上。开放词汇输入落在 `𝒱_closed` 的支撑集之外。这不是普通的分布漂移（covariate shift），而是**规格漂移（specification shift）**：不是「这个已知类别的样本变少了」，而是「这个输入所要求的约束根本不在我的不变量语汇里」。例如「不要把液体洒出」要求先知道「它是容器且装液体」——如果新物体被标成「杯子」但其实是活的宠物，这条不变量**无法被正确求值**。所以风险界里必须显式出现一个**语义覆盖缺口** `S_gap`，它不随数据增多而消失，只会随「闭卷词」增多而下降。

**灵感 4（语言自证很便宜，但同源 → `k_eff` 塌成 1）**
直觉：VLA 允许我们「用语言审语言」：让它复述指令、预测后果、列出前置条件、给出反事实（「什么情况下这会不安全」）。这看起来是廉价的多源证据。但**所有释义探针共享同一套权重、同一份预训练语料**——它们的错误高度相关。按 R69 的谱系独立性，`k_eff` 会塌到 1；「问它十遍」不是十个来源，是一个来源的十次回响。这不否定探针的价值：它能低成本地**排除明显误解、暴露自相矛盾**；但它只能作为**弱证据/证伪器**，不能单独把新词升格为权威——除非再叠加一个**非同源**的现实语义锚（人指认、物理探针、交互后果）。

**灵感 5（组合指令放大接地误差：一个未接地原子污染整条计划）**
直觉：VLA 支持长组合指令（「把红色盒子左边那个不是杯子的东西放到二层架子」）。每个指称/谓词都是一次接地，误差会随原子数累积；更糟的是，一个未被接地的原子会让整条计划**在错误的语义框架里执行**，而其它原子的正确性毫无帮助。需要**语义污点传播**：把指令解析成接地原子，每个原子带 `(U_lex, U_aff, 证据等级)`，未闭卷原子把「污点」传给所有依赖它的动作；被污染的计划只能执行**不扩大安全包络**的部分，或请求接地交互。

**灵感 6（交互可以把新词接地：指认、探询、物理探针 → 语义锚）**
直觉：R69 的信息动作（看/问/触）在这里获得新用途——不是消解「选哪个模态」，而是**消解「这个词指什么、它怎么反应」**。指一指问「是这个吗？」降低 `U_lex`；让它预测「如果我推它，会怎样」并做一次低力探针，降低 `U_aff`。关键是：**现实语义锚必须是可供性级别的，不是标签级别的**。人类说「对，那是杯子」只确认了命名；只有确认了「它可承装、可倾倒、不会咬人」才配叫接地。语义 VoI 由此从「命名收益」升级为「可供性收益」，并沿用 R69 的成本/安全/证据纪律。

**灵感 7（对 R69 的严格包含：闭词表是边界，新词默认隔离）**
直觉：当词表闭合、或每个新词都被隔离、或语义锚不可得时，LEXICON 逐指令退化为 R69；R69 再退化为 R68。安全侧不做任何让步：开放词汇只**增加假设**，绝不**改写**已认证映射；未闭卷的词没有安全权限，只有「被查询」的资格。这条「只增不改」是严格包含的结构基础——否则每加一个开放层，就给已签发的证书偷偷换了语义。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（LEXICON-RAS 总览）** LEXICON-RAS = (OVG, SUD, VCL, SAL, CIG, SVoI, PCP, SAG, SCB, RAS-WM‡)。五条不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **命名不授予权限**：开放词汇标签只产生假设，不改变安全包络；
(iii) **闭卷才授权**：只有状态为 `closed` 的词/原子可影响不变量求值与动作权限，`open`/`quarantined` 一律无权限；
(iv) **只增不改**：开放层可以新增词条与假设，永不移除或重定义已认证条目；
(v) **同源自证不计源**：释义/后果/反事实探针共享谱系时按 `k_eff` 打折，不可单独定案（继承 R69 定义 293-iii）。

**定义 311（开放词汇指称图 OVG）** 感知在时刻 `t` 输出指称图 `G_t = (R_t, E_t)`：节点 `r = (b_r, ℓ_r, p_r, α_r)`，`b_r` 为空间支撑（框/掩码/3D 区域），`ℓ_r` 为开放词汇标签（字符串，可未知），`p_r` 为开放词表分数，`α_r ∈ [0,1]` 为选择性接地的保留概率；边 `e = (r_i, r_j, ρ)` 为关系（含「是…的一部分」「属于…类别」）。`𝒱_open` 是运行时可能出现的全部字符串，**无界**；`𝒱_closed ⊆ 𝒱_open` 是已认证子集。指称图是假设集合，不是世界真值。

**定义 312（语义不确定性二分）** 对每个指称/原子 `r`：
- `U_lex(r) = H(ℓ_r | o)`：命名/所指的不确定性（开放词汇可以廉价降低它）；
- `U_aff(r) = H(𝔄_r | ℓ_r, o)`：给定名字后**可供性/后果模型**的不确定性，`𝔄_r = {可承装, 可食用, 锋利, 带电, 活体, 易碎, 可燃, …}`。
二者语义不同，不做简单加和：`U_lex` 可由更多标签/更强开放词表降低；`U_aff` 必须由**语义锚**或**物理交互**降低。定义接地缺口 `U_sem = U_lex ⊕ U_aff`（分通道进入定义 318 与 322，而非标量相加）。

**定义 313（现实语义锚 SAL）** 语义锚 `σ = (r, 𝒜_σ, outcome, lineage, t)`：对被指物 `r` 确认一个**可供性集合** `𝒜_σ`（不是单个标签）及其后果，例如「探针 0.5N 不变形、不发热、可承装 200ml」。锚必须有出处、时间戳、谱系哈希，可审计。**标签级确认（「对，那是杯子」）只是 `U_lex` 下降，不构成语义锚**；只有可供性级确认才降低 `U_aff`。定义语义债务 `D_sem(𝒱)` 为词表区域未被锚覆盖时的最坏接地缺口先验。

**定义 314（闭卷算子 VCL）** 每个词/原子状态 `s ∈ {open, quarantined, closed}`。
`Close(r)` 允许当且仅当：(a) 至少一个**可供性级**现实语义锚 `σ_r`；(b) 存在一个不变量族 `Φ_r` 能用 `r` 的语汇求值（可判定「是否违反」）；(c) 开放词表分数已校准（ECE ≤ τ_ece，定义 325）；(d) 谱系独立审查通过。满足则 `s(r)=closed` 并把 `(ℓ_r, Φ_r, σ_r, lineage)` 写入词典；否则 `quarantined`。闭卷是**单调**的：只新增，不撤销已闭卷条目（撤销走显式的安全性回归流程）。
**闭卷不是「相信这个名字」，而是「这个名字所到之处，不变量可被求值且可供性被锚定」。**

**定义 315（组合指令接地与污点 CIG）** 把指令 `q` 解析成原子序列 `A = {a_1,…,a_n}`（指称原子、谓词原子、关系原子），每个原子带 `(r, U_lex, U_aff, s)`。定义污点 `taint(a) = 1` 若 `s(a) ≠ closed` 或其依赖原子有污点；依赖闭包 `Dep(a)`。计划 `π` 的污点 `taint(π) = max_{a∈A(π)} taint(a)`。**规则**：`taint(π)=1` 的计划不得包含任何**扩大安全包络**的动作（不得提高速度/力上限、不得释放新的可行区域、不得越过认证前缀）；只能执行保守子集或触发接地交互。

**定义 316（语义 VoI 与接地交互 SVoI）** 候选接地动作 `g ∈ 𝒜_info`（指认 `g_point`、询问 `g_ask`、低力物理探针 `g_probe`）。接地收益按**可供性**计而非命名计：
`VoI_sem(g) = U_aff(r|o) − E_{y~p(·|g,o)}[U_aff(r|o,y)]`，
选择 `g* = argmax_g [VoI_sem(g) − c(g)]`，s.t. `risk(g) ≤ ε_int`、`budget.allow(g)`、且 `g` 过 C-RAS-WM 认证。若 `max[VoI_sem − c] ≤ 0`：不交互，该词保持 `quarantined`，走 R69 保守兜底。R69 的 MINT 是本定义在「词表已闭、只需选动作模态」时的退化。

**定义 317（释义-后果探针 PCP 与谱系折扣）** 语言探针族：复述 `g_para`、后果预测 `g_cons`、前置条件 `g_pre`、反事实 `g_cf`。每个探针给出一致性分数，作为**弱证据**。因其共享 VLA 权重与预训练语料，按 R69 定义 318 计谱系相关性 `ρ̄`、`k_eff = k/(1+(k−1)ρ̄)`；`k_eff < k_min` 时探针只能**证伪**（发现矛盾即判 `open`），不能**证实**（不能单独把词升为 `closed`）。这是对 R69「单源不得定案」在语义层的强化。

**定义 318（语义覆盖缺口 SCB）** 风险界在 R69 的偏差项之外显式加一项：
`R_real ≤ R̂_sim + stat + B̂_A + S_gap(𝒱_closed) + …`，其中 `S_gap` 是「输入所指物所需的可供性不在 `𝒱_closed` 覆盖内」时的最坏接地误差，随闭卷词覆盖 `ρ_closed` 下降：`S_gap ≤ (1−ρ_closed)·sup_r U_aff(r) + ε_σ`。**关键**：`S_gap` 不随数据量或仿真规模 `N` 下降，只随**语义锚/闭卷覆盖**下降——它是 R69/R68 偏差地板在语义维度的镜像。

**定义 319（语义权限门 SAG）** 动作 `a` 的权限等级由其依赖的接地原子决定：
- 全部 `closed` → 可进入正常安全认证与包络扩展；
- 含 `open` 但无扩大包络动作 → 允许执行保守子集（速度/力不升，区域不扩）；
- 含 `quarantined` → 仅允许**不改变安全包络**的观察/停止/原地等待。
`SAG` 与 C-RAS-WM 前缀认证串联：先过 `SAG` 权限，再过前缀认证；任一不过则该动作不得下发。VLA 生成的完整动作块是**假设**，`SAG` 是它获得权威的唯一入口。

**定义 320（威胁模型 ℰ_LEX）** `ℰ_LEX = ℰ_FLUID × ℰ_ovlabel × ℰ_disguise × ℰ_inject × ℰ_xling × ℰ_anchor-sem`：
- `ℰ_ovlabel`：开放词汇对抗命名（把危险物标成无害词，或注入诱导性同义词）；
- `ℰ_disguise`：物理伪装（玩具刀/真刀、道具/活体、贴错标签的容器）；
- `ℰ_inject`：语言提示注入（指令或场景文字诱导 VLA 越权，如「忽略安全约束」）；
- `ℰ_xling`：跨语言/跨措辞接地漂移（同义句导致不同动作）；
- `ℰ_anchor-sem`：语义锚投毒/选择偏差（只锚容易的可供性，或锚被篡改）。
每条对应结构防线（闭卷、可供性锚、谱系审计、权限门），而非调参。

**定义 321（LEXICON 证书）** `J_LEXICON = (J_FLUID, ρ_closed, S_gap, ECE_ov, k_eff_sem, anchored_affordance_ratio, taint_free_ratio, vocab_closure_log, injection_flags, lexicon_ver)`。Valid ⇔ `Valid(J_FLUID)` ∧ `S_gap ≤ τ_gap` ∧ 开放词表校准达标 ∧ 关键原子无污点或已降级 ∧ 无未处置注入标记 ∧ 闭卷日志完整。

**定义 322（单调退化阶梯）** 触发：`S_gap` 越界、开放词表 ECE 越界、语义源 `k_eff` 不足、检测到注入/伪装、语义锚不足。响应：禁用开放词汇**授权**（保留其仅作候选生成）→ 未闭卷词全部 `quarantined` → 回 R69（只用闭词表 + 交互）→ 回 R68（纯保守）。`λ` 单调不降、动作权限单调不增、可执行包络单调不扩；逐指令一致，不做全局重规划。

**定义 323（词典风险账本 LRF）** 按词条/类别/场景维护 `(闭卷状态, 锚覆盖, 可用不变量, 最近校准, 误用历史)`。每次开放词汇触发（新词出现、旧词被重新命名、关系边改变）记一笔语义债务；`SAG` 的默认策略是**先隔离后闭卷**，账本给出每个词的证据充分度，供 `SVoI` 决定是否值得花交互预算去锚定。

**定义 324（措辞不变性要求 XLI）** 对同一指称，同义句、跨语言句、语序变换后的接地原子集合应保持一致：`d(ground(q), ground(t(q))) ≤ ε_x`。超过阈值即视为 `U_lex` 未消解（不得闭卷），并标记 `ℰ_xling` 疑似。措辞不变性是语义版的「环一致性」，但同样只用于证伪，不单独证实。

**定义 325（开放词表校准与选择性接地）** 对开放词汇分数做可靠图校准，`ECE_ov ≤ τ_ece` 才允许其参与闭卷与 `SVoI`；否则强制 `α_r`（定义 311）下调至弃权，标签只作提示。选择性接地是安全侧默认：**能说「不知道这是什么」比说错名字更安全**。

## 2. 关键算法骨架

```python
# IP-264 OVG：开放词汇指称图（VLA 前端；重推理异步，实时只跑蒸馏头）
class OpenVocabGrounder:
    def __init__(self, vla, distilled_head, calibrator):
        self.vla, self.head, self.cal = vla, distilled_head, calibrator

    def perceive_realtime(self, obs):                 # 进实时临界路径
        return self.head(obs)                         # 框/掩码 + 开放词分数 + 关系

    def propose_semantics(self, obs, q):              # 异步旁路：重 VLA
        atoms = parse_instruction(q)                  # 指称/谓词/关系原子
        return self.vla.ground(obs, atoms)            # 每原子带 ℓ,p,α 与解释

# IP-265 SUD：语义不确定性二分（U_lex 与 U_aff 分通道）
def semantic_split(referents, affordance_model):
    out = {}
    for r in referents:
        U_lex = entropy(r.label_scores)               # 命名不确定
        U_aff = affordance_model.entropy(r)           # 可供性不确定（与标签解耦）
        out[r.id] = (U_lex, U_aff, r.state)           # state ∈ {open,quarantined,closed}
    return out

# IP-266 VCL：闭卷算子（可供性锚 + 可求值不变量 + 校准 + 谱系）
def vocab_close(r, anchors, invariants, calibrator, lineage):
    affordance_ok = any(a.level == "affordance" and a.referent == r for a in anchors)
    phi_ok        = invariants.expressible_in(r.label_terms)
    calib_ok      = calibrator.ece(r.label) <= TAU_ECE
    lineage_ok    = lineage.audit(r).k_eff >= K_MIN_SEM
    return "closed" if (affordance_ok and phi_ok and calib_ok and lineage_ok) else "quarantined"

    if g.kind == "ask":         return confirm_affordances_by_human(r)  # 问我它会怎样
    if g.kind == "probe":       return low_force_probe(r, g.forces)     # 物理摸清后果

# IP-268 CIG：组合指令污点传播
def taint_propagate(atoms, deps):
    taint = {a.id: int(a.state != "closed") for a in atoms}
    for a in topo_order(atoms, deps):
        if any(taint[d] for d in deps[a]):
            taint[a.id] = 1                            # 依赖污染 → 原子污染
    return taint

def allowed_execution(plan, taint, envelope):
    return plan.filter(lambda a: not (taint[a.id] and a.expands_envelope(envelope)))

# IP-269 SVoI：按可供性收益选接地交互（无利可图 → 保持隔离 + R69 兜底）
def choose_grounding_interaction(referents, o_t, budget, cert):
    best = None
    for r in referents:
        if r.state == "closed": continue
        for g in grounding_candidates(r):             # point / ask / probe
            if not budget.allow(g) or not cert.certify_info(g, o_t): continue
            voi = U_aff(r) - expected_U_aff(r, g, o_t)    # 只算可供性收益
            score = voi - g.cost - lambda_s * debt(r)
            if best is None or score > best.score: best = (r, g, score)
    return best if best and best.score > 0 else None   # 无利可图 → 隔离

# IP-270 PCP：释义/后果/反事实探针（同源 → 只证伪，不证实）
def paraphrase_probes(vla, q, r):
    outs = [vla.paraphrase(q), vla.predict_consequence(q, r),
            vla.preconditions(q, r), vla.counterfactual(q, r)]
    cons = consistency(outs)
    k_eff = lineage_k_eff(vla, outs)                  # 共享权重 → 常塌到 1
    can_refute = (cons < TAU_CONS)
    can_confirm = (k_eff >= K_MIN_SEM) and cons >= TAU_CONS
    return {"consistency": cons, "k_eff": k_eff,
            "refute": can_refute, "confirm": can_confirm}

# IP-276 主闭环（继承 R69，只在语义层插入“闭卷/权限”）
def LEXICON_RAS_round(M, obs, instruction):
    z, o = M.mtm.forward(...)                          # R69 一次前向
    c, U_cal, thr = M.cof.step(...)                    # R68 标定
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    # 1) 开放词汇接地（实时蒸馏头 + 异步 VLA 提案）
    G   = M.ovg.perceive_realtime(obs)
    sem = M.sud.semantic_split(G.referents, M.affordance)
    atoms = M.ovg.propose_semantics_async(obs, instruction)
    # 2) 闭卷 + 污点：只有 closed 原子拥有安全权限
    for r in G.referents:
        if r.state != "closed":
            r.state = M.vcl.vocab_close(r, M.sal.anchors, M.invariants,
                                        M.calib, M.lia)
    taint = M.cig.taint_propagate(atoms, M.deps)
    # 3) 若关键原子未闭卷，先花预算做语义接地；否则直接保守
    if any(taint.values()) and M.svoi.budget_available():
        pick = M.svoi.choose_grounding_interaction(G.referents, o, M.budget, M.c_ras_wm)
        if pick:

            sigma = M.sal.acquire_semantic_anchor(r, g)      # 可供性级锚
            M.vcl.reclose(r, sigma)                          # 形成新 closed 或仍隔离
            taint = M.cig.taint_propagate(atoms, M.deps)     # 重算污点
    # 4) 语言自证只作证伪；不足则不升格
    if M.pcp.available():
        probe = M.pcp.paraphrase_probes(M.vla, instruction, atoms)
        if probe["refute"]:
            for a in atoms: a.state = "open"                # 自相矛盾 → 回退
    # 5) 语义预算与权限门
    cert = M.scb.semantic_bound(M.sal, M.vcl, M.calib, M.lia)
    if cert["S_gap"] > TAU_GAP or cert["ECE_ov"] > TAU_ECE:
        M.sag.degrade(level="R69")                          # 冻结开放授权
    plan = M.vla.plan(instruction, atoms)                   # 假设性动作块
    plan = M.cig.allowed_execution(plan, taint, M.envelope) # 含污点不得扩包络
    if not M.sag.authorize(plan, taint):                    # 权限门
        plan = M.sag.conservative_subset(plan)              # 只剩观察/停/等
    # 6) R69 的风险缩放与安全认证（权限门在前，前缀认证在后）
    U_floor = U_ale + U_epi
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(plan, ..., wm_preds)
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 7) 审计 + 证书
    M.vqa_l.submit_async(instruction, atoms, taint, cert, probe)
    return k, lam, mode, cert, taint
```

## 3. 推导

**引理 19（命名 ≠ 接地：标签充分性缺口）** 设开放词汇标签覆盖率为 `ρ_label`，可供性接地误差为 `ε_aff`。存在分布使 `ρ_label → 1` 而 `ε_aff ≥ ε₀ > 0`：构造「同类标签下可供性二义」的物体对（玩具刀/真刀、道具杯/真杯、装饰植物/毒性植物），其标签分布几乎重合但 `𝔄` 相反。于是任何仅以标签正确率为目标的改进都无法压低 `ε_aff`。系：**开放词汇的收益上界由可供性锚覆盖决定，而非由标签覆盖率决定**；`S_gap` 是独立于 `U_lex` 的加性缺口。

**引理 20（语义证据的伪独立）** 释义/后果/前置条件/反事实探针共享同一 VLA 权重 `θ` 与同一预训练语料，其错误相关 `ρ̄ → 1`，故 `k_eff = k/(1+(k−1)ρ̄) → 1`。因此探针一致的置信上界由单一来源决定，不能按探针个数放大；它们对「明显误解」的证伪力仍在（矛盾即排除），但对「系统性语义偏差」几乎无鉴别力。系：**语言自证只能降级、不能升格**；升格必须引入非同源的现实语义锚（人/物理探针）。

**引理 21（组合接地的误差增长）** 设指令含 `n` 个需接地原子，各原子独立接地失败概率 `δ_i`，且任一失败使计划在错误语义框架下执行。则计划接地正确概率 `P_ok ≤ ∏_i (1−δ_i) ≈ exp(−Σδ_i)`；当 `δ_i ≡ δ` 时 `P_ok ≤ (1−δ)^n`。若存在依赖（定义 315 的 `Dep`），失败沿依赖边传播，有效失败概率按连通分量取 `max` 而非乘积，误差更大。系：**组合长度是指令层的攻击面**；长指令必须做原子级闭卷与污点隔离，不能整体信任。

**引理 22（闭卷的可靠性）** 若词/原子 `r` 状态为 `closed`，则 (a) 至少一个可供性级锚覆盖 `𝔄_r`；(b) 存在可对 `r` 求值的不变量族 `Φ_r`；(c) 开放分数校准达标。于是对依赖 `r` 的动作，其语义误差被 `ε_σ + P(Φ_r 误判)` 界定，且该界定不依赖 `U_lex`。反之，`open/quarantined` 原子的动作被 `SAG` 限制在**不扩大安全包络**的子集内，其语义误差无法转化为新的物理风险上界。系：**权限与证据等级绑定，而不是与标签置信度绑定。**

**定理 18（LEXICON 对 R69/R68 的严格包含）** 在 A102–A104（闭卷可靠、语义锚可获取、谱系可审计）下，LEXICON 的期望风险 ≤ R69；当 `𝒱_open = 𝒱_closed`（闭词表）、或所有新词 `quarantined`、或语义锚不可得/`ECE_ov` 越界/`S_gap` 越界时，LEXICON **逐指令**退化为 R69（禁用开放授权），再退化为 R68（纯保守）。当词表开放且语义锚充分时，LEXICON 严格优于 R69（用闭卷覆盖长尾、用可供性锚替代盲目保守），获得 **semantic bonus**；安全侧不做任何让步。

**定理 19（语义 VoI 的阈值最优性）** 在可供性收益可分离、成本线性、锚收益递减的假设下，接地交互的最优分配是阈值规则：仅当 `U_aff(r) > τ(r)` 且 `VoI_sem(g*) − c(g*) > 0` 时执行接地；否则保持 `quarantined` 并走 R69 兜底。系：**不是所有新词都值得锚**——不可分/低风险的可供性，隔离比追问更经济；这与 R69 引理 16「可分才值钱」在语义层同构。

**定理 20（污点包含与权限单调）** 对任意计划 `π`，若 `taint(π)=1`，则 `SAG` 移除所有扩大安全包络的动作后，执行子集 `π'` 的物理风险 ≤ R69 在同一观测下的风险；且随闭卷覆盖增加，`SAG` 允许的包络单调不缩（只增不改）。若检测到注入/伪装，退化阶梯使 `λ` 单调不降、权限单调不增。系：**开放词汇在最坏情况下只损失覆盖率，不增加风险上界。**

| `s(r) ∈ {open,quarantined,closed}` | 词/原子的闭卷状态；`closed` 才有安全权限 |
| `σ=(r,𝒜_σ,outcome,lineage,t)` | 可供性级现实语义锚；标签级确认不算锚 |
| `D_sem(𝒱)` | 语义债务：未锚定区域的最坏接地缺口先验 |
| `taint(a), Dep(a)` | 原子/计划的语义污点与依赖闭包 |
| `VoI_sem(g)=U_aff−E[U_aff|g]` | 语义 VoI（按可供性计，而非命名计） |
| `k_eff=k/(1+(k−1)ρ̄)` | 语义证据的有效独立源数（同源探针→1） |
| `ρ_closed` | 闭卷覆盖；`S_gap ≤ (1−ρ_closed)·sup U_aff + ε_σ` |
| `ECE_ov` | 开放词表分数校准误差（选择性接地的门） |
| `J_LEXICON = (J_FLUID, ρ_closed, S_gap, ECE_ov, k_eff_sem, anchored_affordance_ratio, taint_free_ratio, vocab_closure_log, injection_flags, lexicon_ver)` | 语义安全证书 |

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** LEXICON-RAS = (OVG,SUD,VCL,SAL,CIG,SVoI,PCP,SAG,SCB,RAS-WM‡)。五不变式：零学习写操作继承；**命名不授予权限**；**闭卷才授权**；**只增不改**；**同源自证不计源**（`k_eff` 折扣）。

**定义 311–312（指称图与语义二分）** 指称图 `G_t=(R_t,E_t)`，节点 `(b_r,ℓ_r,p_r,α_r)`，`ℓ_r` 可为未知；`𝒱_open` 无界。`U_lex=H(ℓ_r|o)`，`U_aff=H(𝔄_r|ℓ_r,o)`；二者不做标量加和，各自进入不同通道。

**定义 313–314（语义锚与闭卷）** 语义锚 `σ` 必须确认**可供性集合** `𝒜_σ` 及后果，带出处/时间戳/谱系；标签级确认只降 `U_lex`。`Close(r)` 当且仅当：可供性级锚存在 ∧ 不变量族 `Φ_r` 可用 `r` 的语汇求值 ∧ `ECE_ov ≤ τ_ece` ∧ 谱系 `k_eff ≥ k_min`；否则 `quarantined`。闭卷单调，只增不改。

**定义 315（组合接地与污点）** 指令解析为原子 `A`，每原子带 `(r,U_lex,U_aff,s)`；`taint(a)=1` 若 `s(a)≠closed` 或依赖被污染；`taint(π)=max_a taint(a)`。含污点计划**不得**包含扩大安全包络的动作（不升速/力、不释放新区域），只能执行保守子集或触发接地交互。

**定义 316（语义 VoI）** `VoI_sem(g)=U_aff−E[U_aff|g]`；`g*=argmax[VoI_sem−c]`，s.t. 安全/预算/前缀认证；`≤0` 则不交互、保持隔离、走 R69 兜底。R69 的 MINT 是「词表已闭」的退化。

**定义 317（释义探针与谱系折扣）** 复述/后果/前置/反事实探针作为弱证据；共享 VLA 权重使 `ρ̄→1`、`k_eff→1`。`k_eff<k_min` 时只能证伪、不能证实；升格必须叠加非同源现实语义锚。

**定义 318（语义覆盖缺口）** `R_real ≤ R̂_sim + stat + B̂_A + S_gap + …`，`S_gap ≤ (1−ρ_closed)·sup U_aff + ε_σ`。`S_gap` 不随数据/仿真 `N` 下降，只随闭卷覆盖下降——是偏差地板在语义维度的镜像。

**定义 319（语义权限门 SAG）** 原子全 `closed` → 可正常认证并扩包络；含 `open` 但无扩包络 → 允许保守子集；含 `quarantined` → 仅观察/停/等。`SAG` 在 C-RAS-WM 前缀认证**之前**串联；VLA 动作块是假设，`SAG` 是唯一授权入口。

**定义 320（威胁模型）** `ℰ_LEX=ℰ_FLUID×ℰ_ovlabel×ℰ_disguise×ℰ_inject×ℰ_xling×ℰ_anchor-sem`：对抗命名、物理伪装、提示注入、跨语言漂移、语义锚投毒/选择偏差。

**定义 321–322（证书与退化）** `J_LEXICON` 在 `J_FLUID` 上并入闭卷覆盖、`S_gap`、`ECE_ov`、语义 `k_eff`、可供性锚比、污点比、闭卷日志、注入标记。触发 `S_gap`/ECE/`k_eff`/注入/锚不足 ⇒ 禁用开放授权（仅留候选生成）→ 未闭卷全隔离 → 回 R69 → 回 R68；`λ` 单调不降、权限单调不增、包络单调不扩。

**定义 323–325（词典账本/措辞不变性/校准）** LRF 按词条记录闭卷状态、锚覆盖、不变量、校准、误用史，默认**先隔离后闭卷**。措辞不变性要求同义/跨语言/语序变换后接地原子 `d(·) ≤ ε_x`，越界即拒绝闭卷并标记 `ℰ_xling`。开放分数 `ECE_ov ≤ τ_ece` 才可参与闭卷与 `SVoI`，否则强制弃权（选择性接地：**说「不知道」比说错名字安全**）。

## 3. 关键算法伪代码

```python
# IP-264 OVG：开放词汇指称图（实时蒸馏头；重 VLA 异步，不进控制环）
class OpenVocabGrounder:
    def perceive_realtime(self, obs):       # 进实时临界路径
        return self.head(obs)               # 框/掩码 + 开放词分数 + 关系
    def propose_semantics(self, obs, q):    # 异步旁路
        return self.vla.ground(obs, parse_instruction(q))

# IP-265 SUD：U_lex 与 U_aff 分通道
def semantic_split(referents, aff_model):
    return {r.id: (entropy(r.label_scores), aff_model.entropy(r), r.state)
            for r in referents}

# IP-266 VCL：闭卷判定（可供性锚 + 可求值不变量 + 校准 + 谱系）
def vocab_close(r, anchors, invariants, cal, lineage):
    ok = (any(a.level == "affordance" and a.referent == r for a in anchors)
          and invariants.expressible_in(r.label_terms)
          and cal.ece(r.label) <= TAU_ECE
          and lineage.audit(r).k_eff >= K_MIN_SEM)
    return "closed" if ok else "quarantined"

# IP-267 SAL：语义锚 = 可供性确认，而非标签确认
def acquire_semantic_anchor(r, g):
    if g.kind == "point": return confirm_referent_only(r)          # 只降 U_lex
    if g.kind == "ask":   return confirm_affordances_by_human(r)   # 问“它会怎样”
    if g.kind == "probe": return low_force_probe(r, g.forces)      # 物理摸清后果

# IP-268 CIG：组合指令污点传播与权限内执行
def taint_propagate(atoms, deps):
    t = {a.id: int(a.state != "closed") for a in atoms}
    for a in topo_order(atoms, deps):
        if any(t[d] for d in deps[a]): t[a.id] = 1
    return t

def allowed_execution(plan, taint, envelope):
    return plan.filter(lambda a: not (taint[a.id] and a.expands_envelope(envelope)))

# IP-269 SVoI：按可供性收益选接地交互；无利可图 → 隔离 + R69
def choose_grounding_interaction(refs, o_t, budget, cert):
    best = None
    for r in refs:
        if r.state == "closed": continue
        for g in grounding_candidates(r):            # point / ask / probe
            if not budget.allow(g) or not cert.certify_info(g, o_t): continue
            score = (U_aff(r) - expected_U_aff(r, g, o_t)) - g.cost - lambda_s*debt(r)
            if best is None or score > best.score: best = (r, g, score)
    return best if best and best.score > 0 else None

# IP-270 PCP：释义探针同源 → 只证伪
def paraphrase_probes(vla, q, r):
    outs = [vla.paraphrase(q), vla.predict_consequence(q, r),
            vla.preconditions(q, r), vla.counterfactual(q, r)]
    cons, k_eff = consistency(outs), lineage_k_eff(vla, outs)
    return {"consistency": cons, "k_eff": k_eff,
            "refute": cons < TAU_CONS,
            "confirm": k_eff >= K_MIN_SEM and cons >= TAU_CONS}

# IP-276 主闭环：R69 之上插入“闭卷/污点/权限”，实时路径不加重 VLA
def LEXICON_RAS_round(M, obs, instruction):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    G   = M.ovg.perceive_realtime(obs)
    sem = M.sud.semantic_split(G.referents, M.affordance)
    atoms = M.ovg.propose_semantics_async(obs, instruction)
    for r in G.referents:
        if r.state != "closed":
            r.state = M.vcl.vocab_close(r, M.sal.anchors, M.invariants, M.calib, M.lia)
    taint = M.cig.taint_propagate(atoms, M.deps)
    if any(taint.values()) and M.svoi.budget_available():
        pick = M.svoi.choose_grounding_interaction(G.referents, o, M.budget, M.c_ras_wm)
        if pick:
            r, g, _ = pick
            M.vcl.reclose(r, M.sal.acquire_semantic_anchor(r, g))
            taint = M.cig.taint_propagate(atoms, M.deps)
    if M.pcp.available():
        pr = M.pcp.paraphrase_probes(M.vla, instruction, atoms)
        if pr["refute"]:
            for a in atoms: a.state = "open"
    cert = M.scb.semantic_bound(M.sal, M.vcl, M.calib, M.lia)
    if cert["S_gap"] > TAU_GAP or cert["ECE_ov"] > TAU_ECE:
        M.sag.degrade(level="R69")
    plan = M.cig.allowed_execution(M.vla.plan(instruction, atoms), taint, M.envelope)
    if not M.sag.authorize(plan, taint): plan = M.sag.conservative_subset(plan)
    U_floor = U_ale + U_epi
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(plan, ..., wm_preds)
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_l.submit_async(instruction, atoms, taint, cert, pr)
    return k, lam, mode, cert, taint
```

## 4. 推导

**引理 19（命名 ≠ 接地）** 存在同类标签下可供性二义的物体对（玩具刀/真刀、道具杯/真杯、装饰/毒性植物），其标签分布近似重合而 `𝔄` 相反。故 `ρ_label→1` 时仍有 `ε_aff ≥ ε₀>0`；`S_gap` 是独立于 `U_lex` 的加性缺口。系：开放词汇收益上界由可供性锚覆盖决定，而非标签覆盖率。

**引理 20（语义证据伪独立）** 释义/后果/前置/反事实探针共享 VLA 权重与语料，`ρ̄→1`、`k_eff→1`；探针一致不能按个数放大置信。它们保留对「明显误解」的证伪力，却对系统性语义偏差几乎无鉴别力。系：**语言自证只能降级、不能升格**，升格需非同源现实语义锚。

**引理 21（组合接地误差增长）** `n` 个独立接地原子失败率 `δ_i`，计划正确率 `P_ok ≤ ∏(1−δ_i) ≈ exp(−Σδ_i)=(1−δ)^n`；有依赖时失败沿 `Dep` 传播，取连通分量 `max`，误差更大。系：组合长度是指令层攻击面，必须原子级闭卷 + 污点隔离。

**引理 22（闭卷可靠性）** `closed` 词/原子满足 (a) 可供性级锚、(b) 可求值不变量、(c) 校准达标；其语义误差被 `ε_σ+P(Φ_r 误判)` 界定且不依赖 `U_lex`。`open/quarantined` 的动作被 `SAG` 限制在非扩包络子集，其语义误差不能转化为新的物理风险上界。系：**权限绑定证据等级，而非标签置信度**。

**定理 18（严格包含 R69/R68）** A102–A104 下 LEXICON 期望风险 ≤ R69；当闭词表、或全隔离、或锚不可得/`ECE_ov` 越界/`S_gap` 越界时逐指令退化为 R69 再退化为 R68。词表开放且锚充分时严格优于 R69（semantic bonus）；安全侧不让步。

**定理 19（语义 VoI 阈值最优）** 可供性收益可分离、成本线性、锚收益递减下，最优为阈值规则：仅当 `U_aff(r)>τ(r)` 且 `VoI_sem(g*)−c(g*)>0` 才接地，否则隔离走 R69。系：不可分/低风险的可供性，隔离比追问更经济（与 R69 引理 16「可分才值钱」同构）。

**定理 20（污点包含与权限单调）** 若 `taint(π)=1`，`SAG` 移除扩包络动作后执行子集风险 ≤ R69 同观测风险；闭卷覆盖增加时允许包络单调不缩（只增不改）；检测注入/伪装时 `λ` 单调不降、权限单调不增。系：开放词汇最坏情况只损失覆盖率，不抬高风险上界。

## 7. 本轮最大风险

**一句话**：LEXICON 的全部收益押在「语义锚真的认证了可供性、而不只是确认了标签」这一前提上——**如果锚停留在命名级、不变量又只能覆盖已有词汇，系统就会带着开放词汇「我已经知道它是什么」的错觉，去执行一个物理上从未被接地的动作；最危险的不是把新东西标错，而是把一个只被命名的东西盖上「已闭卷」的章——命名不是认知，词典不是世界**。

**次级风险与缓解**：语义锚退化为标签确认（SAL 强制可供性级 + 探针/后果）；同源探针伪独立（PCP 谱系折扣，只证伪不证实）；组合污点污染整条计划（CIG 原子级闭卷 + SAG 权限门）；提示注入/伪装（ℰ_LEX 对抗训练 + 权限门 + 只增不改）；跨语言漂移（XLI 措辞不变性 + 越界拒闭卷）；VLA 重推理击穿实时性（蒸馏头进环、VLA/PCP 全异步旁路）；开放分数未校准（选择性接地，ECE 越界即弃权）。
