# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「机器人操作系统」×「步骤分」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570；IP-354/355/356）。
> **本轮纪律**：**生命周期契约 + 步骤分证据 + QoS 相容前置**。两个灵感分别治理 v9 的两种债：**时序语义债**（MW 把"节点死亡 / 截止超时 / 语义不相容"压扁成同一种"超时"）、**证据债**（块证书把安全押在静态 β 假设上，而唯一能在执行期证伪它的正是逐步残差）。硬约束：证据化信任域必须是 v9 静态信任域的**保守细化**——新增门控只能更早撤销、绝不能更晚；QoS 全相容且租约健康时严格等价退回 v9。

## 0. 直觉与动机

**灵感 1（机器人操作系统 → 生命周期契约运行时）**
直觉：v9 的 ContractMiddleware 其实重造了半个 ROS 2——契约表≈节点接口，EDF≈执行器，超时注中立元≈看门狗。但 ROS 2 把"节点是一等公民"推进到了"**生命周期是一等公民**"：managed node 的 unconfigured/inactive/active/finalized 四态、QoS 的 deadline/liveliness/reliability 三元契约、bond 心跳、action 的 goal/feedback/cancel/result。v9 把这些压扁成单一"超时"事件，导致三种本质不同的故障被同一中立元抹平：节点**死了**（liveliness 失约）、节点**活着但算不完**（deadline 超时）、节点**活着、算完了，但说的不是同一种语言**（QoS 或契约版本不相容）。核心创新：**生命周期契约运行时（LifecycleContractRuntime, LCR）**：契约升级为 κ_m^LC=(In,Out,D_m,Ŵ_m,v_m^⊥,π_m,φ^elig,Q_m,ℓ_m)；模块是四态生命周期节点；退化链变成一条**确定性生命周期转移序列**，每个转移点注入中立元并落审计日志。QoS 不相容不再被当作"没连上"而静默，而是显式成为一个新的退化级。

**灵感 2（步骤分 → 步骤分账本与证据化信任域）**
直觉：v9 最大的口子是"信任域内前向模型误差 ≤ β"——β 是离线标定的静态假设，而 DA-ML 的 20 帧滑窗在真实跳变时恰恰最慢。可执行时我们每步都在**免费获得证据**：预测状态与实际状态的发散 δ_k、预测间隙与实测间隙的残差 ρ_k、努力度残差 ε_k、抓取有效性 γ_k。过程奖励模型（PRM/步骤分）的教训是：**对每一步打分，比只给最终结果打分更早、更密地暴露问题**。核心创新：**步骤分账本（StepScoreLedger, SSL）**：每控制步记录 σ_k=(δ_k,ρ_k,ε_k,γ_k) 及其 Lipschitz 信任包络 E_k=L^{K−k}·δ_k；块证书从"生成时的静态承诺"升级为"**每一步都在被重证的活证书**"——只要 E_k>β 就立刻在 k 处撤销，不必等块边界或 Δ_dom 滑窗。步骤分同时是蒸馏器的稠密信用，把 v9 的块级消融归因升级为步级归因，方差随 K 下降。

**灵感 3（ROS action 语义 → 分块即动作）**
直觉：v9 的 AC 分块本就是一个 ROS 2 Action：goal=a^{1:K}，feedback=σ_k 流，cancel=中止点 p*，result=块证书 Ĉ。显式化为动作语义后，可定义**取消延迟 τ_cancel**这一可测量指标，并把"中块守卫"从副作用升级为契约化的 feedback/cancel 协议。此步不新增安全假设，只把已有结构命名，便于形式化与跨机复用。

## 1. 研究问题（轮次升级版）

- **Q1（证据化信任）**：如何用执行期逐步残差（尤其状态发散 δ_k 的 Lipschitz 包络）在线证伪块证书，使撤销发生在**模型误差越界之前**而非之后？证据化信任域相对 v9 静态信任域是否严格保守？
- **Q2（时序语义分离）**：如何把"死亡 / 超时 / 不相容"三种故障编码为生命周期状态机的不同转移，使每种故障的中立元注入可区分、可审计，同时在健康时与 v9 逐位等价？
- **Q3（步骤分归因）**：步级稠密归因在什么条件下等价或优于块级消融归因？稠密分数会不会把"安全关键但低频生效"的模块误判为低贡献（v9 抖振风险的新变种）？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 生命周期退化律（Lifecycle Degradation, LCR）**
每个模块是四态生命周期节点 q_m∈{U,I,A,F}；只有 LifecycleManager 可执行状态转移，转移由 (configure/activate/deactivate/cleanup/error) 五类事件驱动且幂等。**q_m≠A ⇒ 该端口注入 v_m^⊥**。退化链 = 一条确定性转移调度 Π=(q(0)→q(1)→…)，每一步落审计日志；QoS 不相容与租约失约各有专属转移，不得与截止超时混为一谈。

**P14 证据化信任律（Evidence-Gated Trust, SSL）**
块证书在块内**逐步重证**：每步计算状态发散 δ_k 与信任包络 E_k=L^{K−k}·δ_k（L 为动力学-度量联合 Lipschitz 常数）。撤销谓词 Revoke(k) ⇔ E_k>β ∨（连续 M 步 |ρ_j|>β+ε）∨ δ_k>δ_max ∨ ¬γ_k ∨（v8 M₀ 硬检查失败）。撤销后 K_eff←1，从当前状态执行安全停驻。静态假设 β 仅用于**离线初始化**，安全不再依赖其先验正确性。

**P15 QoS 相容前置律（QoS-Compatibility Precondition, QCM）**
组合（发布-订阅接线）前必须验证 compat(Q_i,Q_j)=1：reliability、durability、deadline、liveliness、schema_hash 逐维满足偏序。不相容 ⇒ 消费者端口不激活、注 v^⊥、升级一个显式退化级；**绝不把类型/版本不匹配的陈旧数据放进下游**（fail-safe 而非 fail-silent）。

## 3. 与基线的接口（如何退化）

- SSL 失效（残差不可观测 / L 标定失效）⇒ 退回 v9 静态 β 信任域与块边界撤销，等价 v9 AC；
- LCR 失效 ⇒ 退回 v9 单一超时中立元注入，等价 v9 MW；
- QCM 失效 ⇒ 假定所有 QoS 相容，等价 v9 未建模 QoS；
- 三者全失效 ⇒ 严格退回 v9 MetricVoiceGauge-ACMD；再退回 v8 / v7 / v6。

## 4. 预期贡献

1. **生命周期契约运行时**：把退化从"超时→中立元"的单事件模型细化为死亡 / 超时 / 不相容三类转移，且是 v9 的保守细化（健康时逐位等价）；
2. **步骤分账本 / 证据化信任域**：把静态 β 假设换成执行期可证伪的 Lipschitz 包络，最坏撤销延迟从 Δ_dom 的 20 帧（≈380ms）降到 ≤M 步（≈40ms）；
3. **动作语义化分块**：取消延迟 τ_cancel 成为一等指标，feedback/cancel 协议化；
4. **步级稠密归因**：方差随 K 下降，并附"低频安全模块豁免 + 稀有事件率"防误判。

## 5. 本轮最大风险

**一句话**：步骤分的状态发散 δ_k 只给出未来误差的**上界**（经 L^{K−k} 放大），若 L 估计偏小、或状态观测本身已被域偏移污染，包络会**低估**真实误差——即"用被污染的观测去证伪被污染的预测"，证据链在域偏移时可能同源失效。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-LCSS**（Metric Voice Gauge with Lifecycle-Contract Runtime & Step-Score Ledger）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570；IP-354/355/356）。
> 本轮灵感：「机器人操作系统」×「步骤分」
> **继承纪律**：MetricVoiceGauge 九不变式 + v8 的 DA-ML/SPR/Cal + v9 的 AC/MW/ID 全部保留。新组件一律为**可选增强**：任一环节不可用 ⇒ 注入中立元，严格等价退回 v9（引理 90），而非行为漂移。特别地，证据化信任域只允许比 v9 **更早**撤销，绝不允许更晚。

## 0. 核心 IP 设计

| 编号 | 名称 | 类型 | 关键改进（相对 v9 MetricVoiceGauge-ACMD） |
|---|---|---|---|
| IP-340–356 | v8/v9 全部模块 | 继承 | 语义不变；MW 契约升级为生命周期契约 κ^LC（IP-357）；AC 块证书改为活证书（IP-358） |
| IP-357 | LifecycleContractRuntime（LCR） | 新增核心模块 | 四态生命周期节点 {U,I,A,F}；确定性 LifecycleManager 执行 configure/activate/deactivate/cleanup/error 转移；QoS 三元契约 + bond 心跳租约；退化链成为转移调度数据实例 |
| IP-358 | StepScoreLedger（SSL） | 新增核心模块 | 每步记 σ_k=(δ,ρ,ε,γ) 与 Lipschitz 信任包络 E_k=L^{K−k}δ_k；M 连超计数；逐步撤销活证书；输出稠密归因权重 |
| IP-359 | QoSContractMatcher（QCM） | 新增核心模块 | compat(Q_i,Q_j) 五维偏序校验；不相容 ⇒ 消费者端口不激活并注 v^⊥，fail-safe 而非 fail-silent；跨机 schema_hash/版本偏斜检查 |

**退化链声明（v10 契约化六级）：**
- Level-1：SSL 证据撤销（E_k>β ∨ M 连超 ∨ δ_k>δ_max ∨ ¬γ_k）⇒ K_eff←1，从当前状态安全停驻，等价 v9 AC 的中止；
- Level-2：QoS / schema 不相容（QCM）⇒ 消费者端口 deactivate 注 v^⊥，**v9 无法表达的新退化级**；
- Level-3：liveliness 租约失约（bond/watchdog）⇒ A→I，注 v^⊥（区分"节点死亡"与"截止超时"）；
- Level-4：deadline 超时 ⇒ 注 v^⊥（等价 v9 MW 的超时分支）；
- Level-5：LCR 失效 ⇒ 退回 v9 单一超时中立元注入；SSL 失效 ⇒ 退回 v9 静态 β + 块边界撤销；QCM 失效 ⇒ 假定全相容；
- Level-6：全失效 ⇒ 完整退回 v9 MetricVoiceGauge-ACMD，再退 v8 / v7 / v6。

## 1. 符号体系增量（定义 540–549）

| 符号 | 含义 |
|---|---|
| q_m ∈ {U,I,A,F} | 模块生命周期状态：Unconfigured / Inactive / Active / Finalized |
| Q_m = (rel, dur, D, live, depth) | QoS 契约：reliability / durability / deadline / liveliness / history depth |
| ℓ_m | liveliness 租约：心跳失效超过 ℓ_m 即判死亡 |
| compat(Q_i,Q_j) | QoS 相容谓词（发布 j 的 offer 满足订阅 i 的 request，五维偏序） |
| σ_k = (δ_k,ρ_k,ε_k,γ_k) | 第 k 步步骤分：状态发散、间隙残差、努力残差、抓取有效位 |
| δ_k | 状态发散：‖s_k^obs − F̂_state(s_{k−1},a^k)‖（按 σ_s 归一） |
| L | 动力学-度量联合 Lipschitz 常数：|g−ĝ|≤L‖s−ŝ‖ 且 ‖F−F̂‖ 传播放大不超过 L/步 |
| E_k = L^{K−k}·δ_k | 信任包络：状态发散在剩余时域上的误差上界 |
| β | 块证书误差预算（离线初始化，运行期可被证据证伪） |
| M | 硬撤销所需的连续残差超阈步数（默认 2） |
| τ_cancel | 取消延迟：撤销决策到速度归零且安全停驻的时间 |
| c_m^step | 步级贡献向量（定义 549，v9 定义 537 的稠密化） |
| r_m | 稀有事件率：模块在步级上"关键"的占比；r_m<r_min 的模块不得休眠 |

**新增定义 540（步骤分 StepScore）** 对块 ζ=(a^{1:K},Ĉ,P) 中已执行的第 k 步，记录五元组 σ_k=(δ_k,ρ_k,ε_k,γ_k,ψ_k)：δ_k 为状态发散；ρ_k=g_k^obs−ĝ_k 为间隙残差；ε_k=e_k^obs−ê_k 为努力残差；γ_k∈{0,1} 为抓取有效性；ψ_k 为动作一致性（可选，‖a^k−π(s_k^obs)‖）。安全判定用硬谓词（定义 542），归因用归一化标量。

**新增定义 541（Lipschitz 信任包络 TrustEnvelope）** 设动力学与指标映射均 L-Lipschitz、单步模型误差 ≤ε_m。由 δ_{k+1}≤Lδ_k+ε_m 归纳得剩余时域误差上界：
```
E_k = L^{K−k}·δ_k + ε_m·(L^{K−k}−1)/(L−1)      （L=1 时取 ε_m(K−k)）
```
L 由 E576 辨识，取保守上分位；ε_m 并入 β 预算。E_k>β 表示块证书在该步已无法继续担保。

**新增定义 542（步骤分账本 StepScoreLedger）** 当前块的追加日志 L_t=[(k,σ_k,E_k)]，并维护：
```
n_k^ρ = #{j≤k : |ρ_j| > β+ε}          （残差超阈计数）
revoked_at = min{ k : E_k>β ∨ (连续 M 步 |ρ_j|>β+ε) ∨ δ_k>δ_max ∨ ¬γ_k }
```
`revoked_at` 一旦置位即单调保持。撤销后执行"从当前状态安全停驻"（等价 v9 定义 534 的 p* 语义在 k=当前步的实例）。

**新增定义 543（证据化信任域 EvidencedTrustDomain）**
```
U_t^ev = { Δ_dom(t)<τ_dom ∧ risk_SLAM(t)<τ_SLAM
           ∧ revoked_at=∅ ∧ lease_healthy(t) ∧ QCM_ok(t) }
```
只有 U_t^ev 成立才允许 K_eff>1（取代 v9 定义 539 的两条件门控）。U_t^ev ⊆ U_t^static，故 v9 的安全性证明（引理 82）可直接继承，且额外排除了 v9 会放行的"模型误差已越界但 Δ_dom 未报警"状态。

**新增定义 544（生命周期状态机 LifecycleFSM）** q_m∈{U,I,A,F}；转移：
```
configure: U→I   守卫 contract_valid ∧ wcet_ok ∧ qos_matched ∧ resources_ok
activate:  I→A   守卫 warmup_done ∧ β_calibrated
deactivate:A→I   事件 deadline_miss | liveliness_miss | qos_mismatch | id_dormant
cleanup:   I→U
error:     任意→F （不可恢复，仅离线复位）
```
转移函数 δ_L 确定、幂等、非 A 态一律注 v_m^⊥。转移必须经 LifecycleManager，禁止模块自迁移。

**新增定义 545（生命周期契约 LifecycleContract）** κ_m^LC=(In_m,Out_m,D_m,Ŵ_m,v_m^⊥,π_m,φ_m^elig,Q_m,ℓ_m)。相对 v9 定义 535 增加 Q_m 与 ℓ_m；部署期除 Σ_m Ŵ_m≤B_dec 外，还须静态校验所有接线边 compat(Q_i,Q_j)=1 且 schema_hash 一致。

**新增定义 546（QoS 相容性 QoSCompatibility）** 令可靠性 rel∈{best_effort≺reliable}、持久性 dur∈{volatile≺transient_local}、liveliness 同理、deadline 数值越小越强。则
```
compat(Q_i,Q_j) ⇔ rel_j ⊒ rel_i ∧ dur_j ⊒ dur_i ∧ D_j ≤ D_i
                  ∧ live_j ⊒ live_i ∧ schema_hash_i = schema_hash_j
```
（发布者 j 必须能兑现订阅者 i 的请求；版本偏斜按 schema_hash 拒绝而非猜测。）

**新增定义 547（生命周期管理器与退化调度 LifecycleManager / DegradationSchedule）** 管理器持有全局 EDF 顺序与转移调度 Π；故障事件 f 映射到唯一转移序列 T(f) 与唯一中立元注入点。每次转移记录 (t,m,q_old→q_new,trigger,seq)，使"死亡/超时/不相容/证据撤销/主动休眠"在日志中可区分。

**新增定义 548（动作语义 ActionChunkSemantics）** 将块 ζ 视为 ROS2 action：
```
goal:     a^{1:K}            （K=K_eff，定义 539 升级版）
feedback: {σ_k} 流（每控制步）
cancel:   p* 或立即安全停驻
result:   Ĉ=(ĝ_min,ê_max,γ̂_grasp) 与最终 step-score 摘要
```
取消延迟 τ_cancel 定义为 cancel 决策到 v≤v_stop 且间隙≥d_safe 的时间；须满足 τ_cancel≤D_cancel（预注册）。

**新增定义 549（步级归因 StepLevelAttribution）** 对 φ^elig 模块，在消融回合内按步骤分加权聚合：
```
c_m^step ← clip( 0.9·c_m^step + 0.1·Σ_k w_k·norm(J_with,k − J_base,k), 0, 1 )
w_k = softmax_k(σ_k^scalar)
```
仅当稀有事件率 r_m≥r_min 的模块可进入 dormant；r_m<r_min 的低频安全模块即使 c_m^step 低也保持 active（防稠密分数误杀低频关键模块）。

## 2. 形式化定义（要点与升级）

**定义 493（六层指标层级）** 继承 v8/v9 不变：M=(M₀,M₁,M₂,M₃,M_dom,M_SLAM)。
**定义 495/524（MetaWeight/情感，5 维）** 继承不变。
**升级定义 533（活块证书 LiveChunkCertificate）** Ĉ 仍为生成时最坏界，但有效性不再一次性判定：块内任一步 E_k>β 即作废（定义 541/542），块边界复核退化为"周期性再标定"，紧急撤销由步级证据承担。
**升级定义 534（中止点）** p* 语义不变；新增要求：撤销时从当前状态直接安全停驻，其刹车距离按**单步观测延迟**（≤1 步 = 20ms）额外预留 d_react，即 d_safe' = d_safe + d_react。
**升级定义 535（中间件契约→生命周期契约）** 由 κ_m 升级为 κ_m^LC（定义 545），五级退化表成为理解释 547 的一个数据实例。
**升级定义 539（有效块长门控）**
```
K_eff(t) = 1                          若 U_t^ev 不成立
         = max(1, ⌊K_max·(1 − min(1, Δ_dom/τ_dom))⌋)   否则
```

def qos_compatible(req, offer):
    return (offer.rel >= req.rel and offer.dur >= req.dur
            and offer.deadline <= req.deadline
            and offer.live >= req.live
            and offer.schema_hash == req.schema_hash)

# IP-358 StepScoreLedger
class StepScoreLedger:
    def __init__(self, K, beta, L, eps_m=0.0, M=2, delta_max=0.05, eps_noise=0.0):
        self.K, self.beta, self.L, self.eps_m = K, beta, L, eps_m
        self.M, self.delta_max, self.eps_noise = M, delta_max, eps_noise
        self.records, self.streak, self.revoked_at = [], 0, None

    def _envelope(self, k, delta):
        n = self.K - k
        if self.L == 1.0:
            return delta + self.eps_m * n
        geom = (self.L ** n - 1.0) / (self.L - 1.0)
        return (self.L ** n) * delta + self.eps_m * geom   # 定义 541

    def record(self, k, s_obs, s_pred, g_obs, g_pred, e_obs, e_pred,
               grasp_ok, actionable=True):
        delta = dist(s_obs, s_pred)
        rho, eps = g_obs - g_pred, e_obs - e_pred
        E = self._envelope(k, delta)
        self.records.append(StepRecord(k, delta, rho, eps, grasp_ok, E))
        self.streak = self.streak + 1 if abs(rho) > self.beta + self.eps_noise else 0
        if self.revoked_at is None and (
                E > self.beta or self.streak >= self.M
                or delta > self.delta_max or not grasp_ok
                or not actionable):
            self.revoked_at = k
        return self.records[-1]

    def revoked(self):
        return self.revoked_at is not None

    def step_weights(self):                        # 定义 549
        z = [w for w in (self._scalar(r) for r in self.records)]
        m = max(z) if z else 0.0
        ex = [math.exp(v - m) for v in z]
        s = sum(ex) or 1.0
        return [v / s for v in ex]

    def _scalar(self, r):
        return max(0.0, 1.0 - (r.delta / self.delta_max
                              + abs(r.rho) / self.beta
                              + abs(r.eps) / self.beta) / 3.0)

## 4. 推导

**引理 87（Lipschitz 包络撤销的必要性与充分性）** 设动力学与指标映射均 L-Lipschitz、单步模型误差 ≤ε_m，且块起点模型误差 ≤β。
(i) 若 ∀j≤k，E_j≤β，则活证书在 k 步内持续有效：真实间隙误差 |g_{k+j}−ĝ_{k+j}|≤β 对 j≤K−k 成立。
(ii) 若 E_k>β，则剩余时域误差上界已超支，块证书无法再被担保；此时在 k 撤销是唯一保守动作（继续执行等于引入未经验证的假设）。
证明：(i) 由 δ_{k+1}≤Lδ_k+ε_m 归纳得 δ_{k+j}≤L^jδ_k+ε_m(L^j−1)/(L−1)；再由 |g−ĝ|≤L_gδ 与 E_k 定义即得上界 ≤β。(ii) E_k>β 意味该上界严格超过预算，任何"继续"的结论都需额外假设，故保守撤销。∎

**引理 88（撤销延迟上界与相对 v9 的提升）** 设传感器噪声 |ν_k|≤ε。硬撤销规则"连续 M 步 |ρ_j|>β+ε"在真实误差首次超过 β+2ε 后的第 M 步内触发；故 τ_detect ≤ M·Δt。取 M=2、Δt=20ms 得 ≤40ms。v9 的 Δ_dom 用 W=20 帧滑窗，最坏需 W−1 帧确认，即 ≥380ms。故证据撤销最坏检测延迟至少快 ⌈(W−1)/M⌉≈9 倍。∎

**引理 89（证据化信任域是 v9 的保守细化）** U_t^ev 在 U_t^static 的定义上增加合取项（revoked_at=∅、lease_healthy、QCM_ok），故 U_t^ev⊆U_t^static；且 revoked_at 单调不回退。因此引理 82 在 U_t^static 上成立的安全性结论自动在 U_t^ev 上成立；同时 U_t^ev 额外排除了一切"模型误差已越界而 Δ_dom 尚未报警"的状态。故 v10 不引入新的不安全行为，只更早收缩信任域。∎

**引理 90（LCR 生命周期细化与 v9 逐位等价）** 若所有接线边 compat=1、所有租约健康、所有 q_m=A，则转移调度 Π 为空，注入值恒为各 v_m^⊥（恒等元），可观测输出与 v9 MW（引理 83）逐位一致。每个 v9 退化级对应唯一 LCR 转移；QoS 不相容级仅能经 QCM 失败→deactivate→v^⊥ 到达，v9 无法表达。故 LCR 是 v9 的严格细化：QoS 全相容时 v10≡v9。∎

**引理 91（不相容与失约的安全失败）** 若 compat(Q_i,Q_j)=0，QCM 在任何消息被消费前将消费者端口 deactivate 并注 v_j^⊥，故类型/版本不匹配或陈旧数据不可能进入下游（fail-safe）。若 liveliness 租约 ℓ_m 失约，A→I 在 ℓ_m+ε_lease 内完成并注 v^⊥；看门狗检测延迟有界。两类故障与 deadline 超时在日志中由 trigger 字段区分。∎

**引理 92（步级归因的方差优势与低频豁免）** 块级归因方差 ≈σ_J^2/H（H 个回合）。步级归因对 K·H 个步骤分加权平均，若块内相关系数 ρ_c<1，则方差 ≤σ_J^2/(H·K)·(1+(K−1)ρ_c)，随 K 单调下降。但稀有事件模块的步级分数在多数步为"不关键"，直接平均会低估其贡献；故引入稀有事件率 r_m 与 φ^elig=false 豁免：仅 r_m≥r_min 且安全的模块可休眠。∎

**引理 93（取消延迟与单步观测延迟的安全性）** 从撤销步 k 到安全停驻的刹车轨迹按 d_safe'=d_safe+d_react 预留，覆盖一步观测延迟造成的间隙消耗；若 L-Lipschitz 包络成立（引理 87），则 k 时刻的真实间隙≥d_safe'，刹车终点距障碍≥d_safe。故 τ_cancel 有界且安全停驻成立。∎

## 8. 本轮最大风险

**一句话**：步骤分的状态发散 δ_k 只给出未来误差的**上界**（经 L^{K−k} 放大），若 L 估计偏小、或状态观测本身已被域偏移污染，包络会**低估**真实误差——即"用被污染的观测去证伪被污染的预测"，证据链在域偏移时可能同源失效。
