### 第 4 轮灵感驱动研究记录

**灵感词**：参数高效微调、多端口部署

**直觉与动机**：
上一轮把 KEMPC/CADVS 从「静态知识包容」推进到「动态知识自适应」，但学生策略（VADP）与证书体系仍隐含一个昂贵假设：每换一个任务、地形或机器人，要么重训整个学生网络，要么用同一套参数硬扛所有分布。**参数高效微调（PEFT）** 给了第三条路——冻结基座 θ_0，只训练极小的低秩适配器 δ_j = B_j A_j（LoRA 式），每个任务/地形配一副「知识眼镜」。这天然接住上一轮的「跨任务泛化」：迁移不再靠乘一个抽象的惩罚因子 μ_i，而是靠「加载哪个适配器、以及该适配器是否被证书授权」。直觉上，这像「一师多徒、每徒一副眼镜」——基座是共同常识，适配器是任务特异的口音。

但 PEFT 一旦进入部署，就撞上 **多端口部署**：同一个基座 + 一柜子适配器，要同时服务多台机器人、多个控制环、多种传感器配置（即多个「端口」；网络端口只是其传输底座）。过去证书认证的是「这个策略在本次运行中安全」，现在必须认证「这个基座 ⊕ 这个适配器 ⊕ 这个端口画像」的三元组合安全。单端口验证通过，不等于跨端口可复用；低秩适配器在小样本上「看起来对」，也不等于它真的覆盖了任务所需的秩。

**关键洞见**：PEFT 把「参数」变便宜了，却把「证书」变贵了——需要认证的组合从 1 个膨胀为 |适配器|×|端口| 个。多端口部署的核心矛盾不是算力，而是**证书的跨组合可迁移性**。若能用一个「谱范数扰动界」把基座证书**继承**给组合（而非逐个重证），就能把组合爆炸压回线性；反之，若盲目复用，就会产生「证书污染」：A 端口签发的安全证明被静默搬到动态不同的 B 端口。

**形式化目标（增量）**：
1. 定义知识适配器 δ_j = B_j A_j，谱范数 ε_j = ‖δ_j‖_2，及适配器证书 AC_j。
2. 定义端口画像 PortProfile_p 与端口-适配器证书 PAC_{p,j}，给出基座证书向组合继承的谱界（引理 32）。
3. 定义多端口隔离配额与端口独立性条件（引理 33），并把每端口时延预算接入 TCVM。
4. 定义跨端口污染守卫 CPCG 与适配器切换迟滞调度 ASHS，抑制复用误判与切换抖动。
5. 证明 Exec_PEMD ⊆ Exec_CADVS；并以合成/半实物实验验证：适配器银行把新任务可训练参数降到全量微调的 <1%，配额隔离使 4 端口并发 P99 抖动 <1ms，污染守卫把跨端口误用率压到 <2%。

**本轮最大风险**：**低秩适配器的「容量—证书悖论」**——PEFT 以低秩假设换取参数效率，而证书是在被低秩约束的验证分布上签发的；当任务需要高秩适应（动力学突变、执行器更换）时，低秩瓶颈使策略输出「看似正常」却系统性偏离，证书因聚合验证而通过，形成「参数高效 → 证书高效 → 风险高效」的静默失效，多端口复用还会把单端口的伪证扩散成跨端口的集体伪证。

## 2. 关键算法骨架

### IP-478 Parameter-Efficient Knowledge Adapter Bank (PEKAB)

```python
@dataclass
class KnowledgeAdapter:
    adapter_id: str
    task_sig: np.ndarray          # τ_j：任务签名
    A: np.ndarray                 # (r, d_in)
    B: np.ndarray                 # (d_out, r)
    rank: int
    eps: float = 0.0              # ε_j = ‖B A‖_2
    cert: "AdapterCert | None" = None

@dataclass
class ParameterEfficientKnowledgeAdapterBank:
    """PEKAB：冻结基座 + 低秩适配器银行，按任务签名路由"""
    base_policy: "FrozenBase"     # θ_0 冻结，forward 只读
    eps_max: float = 0.15
    input_bound: float = 4.0      # B_x
    bank: dict[str, KnowledgeAdapter] = field(default_factory=dict)

    def register(self, adapter: KnowledgeAdapter, margin0: float) -> bool:
        """注册适配器并签发谱范数证书；超出 ε_max 直接拒绝"""
        eps = float(np.linalg.norm(adapter.B @ adapter.A, 2))
        if eps > self.eps_max:
            return False
        residual = margin0 - eps * self.input_bound   # 引理 32 的残差裕度
        adapter.eps = eps
        adapter.cert = AdapterCert(
            adapter_id=adapter.adapter_id,
            eps=eps,
            residual_margin=residual,
            valid=residual > 0.0,
        )
        self.bank[adapter.adapter_id] = adapter
        return adapter.cert.valid

    def compose(self, x: np.ndarray, adapter_id: str) -> np.ndarray:
        """基座 ⊕ 适配器：u = f_θ0(x) + B A x（单层线性适配的可加性）"""
        a = self.bank[adapter_id]
        return self.base_policy.forward(x) + (x @ a.A.T) @ a.B.T

    def route_by_task(self, task_sig: np.ndarray, top_k: int = 2) -> list[str]:
        """任务签名最近邻 → 候选适配器（top-k 交证书裁决，避免硬切）"""
        ranked = sorted(self.bank.values(),
                        key=lambda a: float(np.linalg.norm(a.task_sig - task_sig)))
        return [a.adapter_id for a in ranked[:top_k]]
```

### IP-479 Adapter Composition Certificate (ACC)

```python
@dataclass
class AdapterCompositionCertificate:
    """ACC：把基座证书按谱范数扰动界继承给 base⊕adapter⊕port 组合"""
    eps_max: float = 0.15
    input_bound: float = 4.0       # B_x
    margin0: float = 0.30          # 基座证书初始裕度 m_0

    def certify(self, base_cert, adapter: KnowledgeAdapter,
                port: PortProfile) -> CompCert:
        if not base_cert.valid:
            return CompCert(valid=False, reason='base_cert_invalid')
        if adapter.eps > self.eps_max:
            return CompCert(valid=False, reason='eps_exceeds')
        # 端口覆盖：适配器训练分布须覆盖该端口动态，否则不继承
        if not self._profile_covered(adapter, port):
            return CompCert(valid=False, reason='port_profile_uncovered')
        residual = self.margin0 - adapter.eps * self.input_bound
        return CompCert(
            valid=residual > 0.0,
            residual_margin=residual,
            eps=adapter.eps,
            port_id=port.port_id,
            adapter_id=adapter.adapter_id,
            validity_window=0.050,       # 与 CADVS 证书窗口对齐
            reason='ok' if residual > 0 else 'margin_exhausted',
        )

    def _profile_covered(self, adapter, port) -> bool:
        # 适配器元数据记录训练时的动态/传感器签名；端口须落在其覆盖集内
        return (port.dyn_id in adapter.train_dyns and
                port.sensor_set <= adapter.train_sensors)
```

### IP-480 Multi-Port Deployment Orchestrator (MPDO)

```python
@dataclass
class MultiPortDeploymentOrchestrator:
    """MPDO：端口注册 + 适配器路由 + 严格配额隔离"""
    capacity_cpu: float
    capacity_gpu: float
    bank: ParameterEfficientKnowledgeAdapterBank
    ports: dict[str, PortProfile] = field(default_factory=dict)
    routes: dict[str, str] = field(default_factory=dict)   # port_id -> adapter_id

    def register_port(self, p: PortProfile) -> bool:
        used_cpu = sum(q.quota_cpu for q in self.ports.values()) + p.quota_cpu
        used_gpu = sum(q.quota_gpu for q in self.ports.values()) + p.quota_gpu
        if used_cpu > self.capacity_cpu or used_gpu > self.capacity_gpu:
            return False                     # 配额不足：拒绝注册或请求降级
        self.ports[p.port_id] = p
        return True

    def bind(self, port_id: str, adapter_id: str):
        assert adapter_id in self.bank.bank
        self.routes[port_id] = adapter_id

    def step(self, port_id: str, x: np.ndarray) -> np.ndarray:
        p = self.ports[port_id]
        aid = self.routes[port_id]
        # 端口隔离：每端口独立 cgroup / CUDA stream / CPU 亲和
        with self._isolated_quota(p):
            return self.bank.compose(x, aid)

    def rebind_if_better(self, port_id: str, task_sig: np.ndarray,
                         gain_fn, t_now: float, ashs: "ASHS"):
        cur = self.routes[port_id]
        cands = self.bank.route_by_task(task_sig, top_k=2)
        for cand in cands:
            if ashs.should_switch(port_id, cand,
                                  gain_fn(cand), gain_fn(cur), t_now):
                self.bind(port_id, cand)
                ashs.on_switch(port_id, cand, t_now)
                break
```

### IP-481 Cross-Port Certificate Contamination Guard (CPCG)

```python
@dataclass
class CrossPortCertificateContaminationGuard:
    """CPCG：阻止在端口 A 签发的证书被未经验证地复用到端口 B"""
    profile_dist_max: float = 0.25
    registry: dict[str, PortProfile] = field(default_factory=dict)

    def profile_distance(self, a: PortProfile, b: PortProfile) -> float:
        dyn = 0.0 if a.dyn_id == b.dyn_id else 1.0
        union = a.sensor_set | b.sensor_set
        sens = 1.0 - len(a.sensor_set & b.sensor_set) / max(len(union), 1)
        lat = abs(a.lat_budget - b.lat_budget) / max(a.lat_budget, b.lat_budget)
        return 0.5 * dyn + 0.3 * sens + 0.2 * lat

    def check_reuse(self, cert: CompCert,
                    target: PortProfile) -> tuple[bool, str]:
        if cert.port_id == target.port_id:
            return True, 'same_port'
        src = self.registry[cert.port_id]
        d = self.profile_distance(src, target)
        if d > self.profile_dist_max:
            return False, f'contamination_risk:{d:.3f}'
        # 即便画像接近，残差裕度也须覆盖目标端口的扰动
        if cert.residual_margin < self._required_margin(target):
            return False, 'insufficient_margin'
        return True, 'reusable_with_margin'

    def quarantine(self, port_id: str, reason: str) -> FallbackAction:
        # 污染命中：该端口降级到教师路径，并冻结其跨端口证书复用
        self._block_reuse[port_id] = True
        return FallbackAction.FORCE_TEACHER
```

### IP-482 Adapter Swap Hysteresis Scheduler (ASHS)

```python
@dataclass
class AdapterSwapHysteresisScheduler:
    """ASHS：多端口适配器切换的驻留/迟滞/暖机，抑制抖动"""
    dwell_time: float = 0.20
    warmup_steps: int = 5
    switch_margin: float = 0.05

    def __post_init__(self):
        self.active: dict[str, str] = {}
        self.last_switch: dict[str, float] = {}
        self.warmup_left: dict[str, int] = {}

    def should_switch(self, port_id, cand_id, gain_new, gain_cur, t_now) -> bool:
        if self.active.get(port_id) == cand_id:
            return False
        if t_now - self.last_switch.get(port_id, -1e9) < self.dwell_time:
            return False                                  # 驻留期内禁止切换
        if self.warmup_left.get(port_id, 0) > 0:
            return False                                  # 暖机未完成
        return gain_new > gain_cur + self.switch_margin   # 迟滞裕度

    def on_switch(self, port_id, cand_id, t_now):
        self.active[port_id] = cand_id
        self.last_switch[port_id] = t_now
        self.warmup_left[port_id] = self.warmup_steps

    def tick_warmup(self, port_id):
        if self.warmup_left.get(port_id, 0) > 0:
            self.warmup_left[port_id] -= 1
```

### PEMD 统一执行流（单端口单步）

```python
def pemd_step(port_id: str, x: np.ndarray, t_now: float,
              base_cert, acc, mpdo, cpcg, ashs) -> ControlOutput:
    """
    PEMD 单步：适配器证书三元组合 + 跨端口污染守卫 + 隔离执行
    入口：端口 p 的状态 x；出口：控制指令或回退
    """
    p = mpdo.ports[port_id]
    aid = mpdo.routes[port_id]

    # 1) 组合证书：base ⊕ adapter ⊕ port
    comp = acc.certify(base_cert[port_id], mpdo.bank.bank[aid], p)
    if not comp.valid:
        return fallback_to_teacher(port_id, x, reason=f'acc:{comp.reason}')

    # 2) 跨端口污染守卫（若该证书源自其它端口）
    ok, why = cpcg.check_reuse(comp, p)
    if not ok:
        cpcg.quarantine(port_id, why)
        return fallback_to_teacher(port_id, x, reason=why)

    # 3) 端口隔离执行（严格配额，避免跨端口时延耦合）
    u = mpdo.step(port_id, x)

    # 4) 后台按需重路由（迟滞 + 暖机），本步不切换
    mpdo.rebind_if_better(port_id, task_sig=x[-8:], gain_fn=proxy_gain,
                          t_now=t_now, ashs=ashs)
    ashs.tick_warmup(port_id)

    return ControlOutput(u, path=f'adapter:{aid}', certs=comp)
```

## 4. 正确性论证（增量）

### 引理 32（低秩适配器的谱范数证书继承）

**陈述**：设基座策略 π_0 在端口 p 上持有证书 C_0，其安全裕度为 m_0（即允许的输出扰动幅度），输入满足 ‖x‖ ≤ B_x。对适配器 δ_j = B_j A_j，记 ε_j = ‖δ_j‖_2。则组合策略 π_j(x) = π_0(x) + B_j A_j x 满足
‖π_j(x) − π_0(x)‖ ≤ ε_j ‖x‖ ≤ ε_j B_x。
若 ε_j B_x < m_0，则 π_j 在同一证书域内仍安全，残差裕度为 m_0 − ε_j B_x。

**证明**：由算子范数定义，‖B_j A_j x‖ ≤ ‖B_j A_j‖_2 ‖x‖ = ε_j ‖x‖ ≤ ε_j B_x。三角不等式给出组合输出与基座输出的偏差上界。C_0 的安全域以 m_0 为半径；偏差小于 m_0 即仍在域内，剩余裕度相减即得。∎

**工程含义**：无需为每个适配器重跑完整的十二证——只要适配器谱范数有界且端口覆盖成立，基座证书可**线性继承**。这把「|适配器|×|端口| 个组合逐一认证」降为「每适配器一次谱范数核算」。代价是 ε_j 越大残差越小，即**参数越「高效」、证书裕度越薄**。

**诚实边界**：本引理保证「相对基座不越界」，但**不保证任务正确**。若任务需要的高秩修正未被低秩子空间覆盖，残差裕度仍可能为正，而策略已系统性偏离任务最优——这正是本轮最大风险的数学根源。

### 引理 33（多端口配额隔离下的端口独立性）

**陈述**：设 K 个端口共享容量 C 的算力，每端口配额 q_p 满足 Σ_p q_p ≤ C，且每端口单步算力需求 c_p ≤ q_p；每端口时延预算 L_p ≥ L_base + L_adapter（在配额下实测）。则在采用严格配额（cgroup/CPU 亲和/CUDA stream）且端口间无共享内存带宽饱和的调度下，各端口的 P99 时延 SLO 相互独立，与其它端口活动无关。

**证明**：严格配额将每端口可用算力下界固定为 q_p，端口内单步耗时只取决于 c_p 与 q_p（工作守恒调度下），不受其它端口占用影响；c_p ≤ q_p 保证单步不超过配额对应时延；叠加 L_p 预算约束即得 SLO。∎

**诚实边界**：共享 L3 缓存、内存带宽、GPU 张量核争用会破坏「严格隔离」，故引理 33 是理想模型；工程上需以 TCVM 实测 P99 兜底，并对饱和端口动态降配额或降级（见 R35）。

### 定理（PEMD 执行集收缩与适配器条件安全）

**陈述**：在以下假设下：
(A1) 组合证书 CompCert.valid（引理 32 成立，ε_j B_x < m_0）；
(A2) 跨端口污染守卫 CPCG.check_reuse 返回 True（同端口或画像距离 ≤ ρ_max 且残差裕度足够）；
(A3) 端口配额隔离成立（引理 33，TCVM 无 SLO 违规）；
(A4) 适配器切换在 ASHS 驻留/暖机约束下进行，切换瞬态不落在证书消费窗口内；
则 (i) Exec_PEMD ⊆ Exec_CADVS；(ii) 对满足 (A1)–(A3) 的轨迹段，组合策略的输出相对基座的偏差以 ε_j B_x 为界，且证书残差裕度非负。

**证明**：
- (i) PEMD 单步在 CADVS 学生路径前额外要求 CompCert.valid（A1）与 CPCG 通过（A2），教师/回退路径原样复用 CADVS；ASHS 仅延后切换而不放宽准入。故 PEMD 执行集是 CADVS 执行集的子集：Exec_PEMD ⊆ Exec_CADVS。
- (ii) 由引理 32，组合输出偏差 ≤ ε_j B_x，残差裕度 m_0 − ε_j B_x ≥ 0 由 A1 保证；引理 33 保证端口时延不劣化证书窗口。∎

**诚实声明**：(A1) 的谱界只约束「相对基座」，不约束「相对任务最优」；低秩容量不足时残差裕度为正但任务错误（静默欠拟合）。(A2) 的画像距离是代理指标，无法捕捉动力学参数的连续漂移。PEMD 通过 CPCG 隔离与 TCVM 监控管理风险，但不能消除低秩假设本身的语义缺口。

## 7. 本轮最大风险（最终确认）

**一句话**：**低秩适配器的「容量—证书悖论」——PEFT 以低秩假设换取参数效率，而证书在低秩约束的验证分布上签发；当任务需要高秩适应（动力学突变、执行器更换）时，低秩瓶颈让策略输出「看似正常」却系统性偏离，证书因聚合验证通过，多端口复用又把单端口的伪证扩散为跨端口的集体伪证，最终形成「参数高效 → 证书高效 → 风险高效」的静默失效。**
