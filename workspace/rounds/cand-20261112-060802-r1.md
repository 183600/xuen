# 第 58 轮（承接第 57 轮「少样本元推断×跨模态对账×个性化有界信任」IP-133~138；灵感循环第 4 轮；本轮灵感：「步态规划」×「意图识别」）

> 第 57 轮把安全的赌注从"模型置信"换到"证据质量"，再用元先验、跨模态对账、个性化信任为"证据"补上校准与纵深。但它仍默默默认两件事：**任务意图是给定且静态的**（探针只为已知目标服务），**步态只是决策的输出参数**（变速箱选一个档位去执行）。这两条默认在真实部署里最容易断：人走到一半会改主意；机器人每一步既在消耗不可逆的未来，也在向人泄露"我准备干什么"。本轮两个灵感各拆一条默认：**步态规划**把"走哪一步"升级为"还剩多少可撤回的时间"——点不可逆点（PNR）与可撤回裕度 R_m 成为与稳定性并列的一等安全预算，步态选择变成"花费未来选项"；**意图识别**把"目标"从常量升级为带校准、可漂移、可被误读的隐变量——意图后验、变化点检测、可读步态与意图绑定同意共同把"为人服务"变成"为被正确理解的人服务"。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"证据可核、意图可反演、步态可撤回、同意可截止的承诺说可信"**。

核心矛盾：
- **H29（意图不可观 vs 承诺不可逆）**：物理证据门只能证明"这块地能踩"，不能证明"这一步该踩向哪"。朝向错误目标的不可逆一步，物理上完全健全，语义上已经失败；而意图没有一种不花社会信任的"探针"。
- **H30（步态既是执行也是证据）**：同一套落脚点，可以走得让人放心，也可以走得让人误解；可读性要求机器人"表演"自己的意图，效率要求它"别浪费时间"。更麻烦的是，步态同时决定"还剩多少可反悔的时间"。
- **H31（同意 vs 意图漂移）**：同意是对"某一时刻所描述的意图"的授权，而意图会漂移；静态同意会退化成"同意剧场"。但频繁追问又会训练出橡皮章，正好喂养第 57 轮 PTM 已识别的风险。

## 0. 直觉与动机

**灵感 1（步态规划 → 可撤回裕度与点不可逆点）**
直觉：不是所有步都一样。平地迈步随时可停可退；但重心越过崖沿、踏上窄梁、开始下陡坡，存在一个**点不可逆点（PNR）**——过了它，再快的刹车也回不到安全集。传统步态规划问"这一步稳不稳"，本轮改问"**离不可逆还有几秒，够不够我被人叫停？**"定义可撤回裕度 R_m = T_PNR − (意图检测延迟 + 人的否决延迟 + 步态刹停时间)。R_m≥0 的步态，是把意图错误挡在不可逆层之外的"物理保险"；R_m<0 的步态，必须由"意图已稳定 + 新鲜同意"来支付。步态规划由此从"选档位"变成"花预算"：每一步都在花掉未来的选项，而选项价值必须记账。

**灵感 2（意图识别 → 校准后验 + 变化点 + 意图绑定同意）**
直觉：意图不是标签，是一条会变的隐状态。人可能一开始说"去 A"，走到一半被现场吸引改去 B；也可能自己都没想清楚。把意图建成带校准的分布 p_t(ι|h)，用变化点检测区分"我还没看懂"与"人真的改主意了"；同意不再是对一段运动的授权，而是对 **(意图, 走廊, 时间窗)** 的授权。关键的单向性：**推断只能收缩授权，永远不能扩张授权**——机器人不能因为"我觉得人现在想要 X"就给自己发新许可，扩张必须由人显式给出。这样，"更懂人"不会变成"更敢替人做主"。

**灵感 3（步态作为主动意图探针 → 用身体提问）**
直觉：人可以靠一句"是这边吗？"消歧，机器人也可以靠一个**可撤回的小动作**提问：停半拍、重心侧移、朝目标偏转、迈半步又收回。这些意图探询步态必须落在已经过物理证据门的落脚点集合内且 R_m≥0，所以它们**用时间换信息，不用安全换信息**。VOI 由意图熵的下降给出，且设追问速率上限——问得太勤，人就麻木了。

**灵感 4（可读步态与意图-步态一致性）**
直觉：机器人走得"像要去 A"，人才有机会在它真去 A 之前喊停。可读性（legibility）让旁观者从步态正确反推意图；它与第 57 轮的跨模态对账同构：步态隐含意图 q_h(·|g) 与机器人自己的意图后验 p_t 若分歧过大，就是警报——要么人误读了（可读性失败，应解释或改写步态），要么机器人真要去做错事（应停或问）。但可读性只能"把话说清楚"，不能"把话说服"：它不得扩张授权，也不得压过物理安全裕度。

**灵感 5（PCE++ → 承诺调度同时管理"物理选项"与"语义选项"）**
直觉：把第 57 轮的探-诺-演+扩成四选一：**可撤回地执行 / 用可撤回步态探意图 / 换一条更可撤回的路 / 停下问人**。物理证据门决定"能不能踩"，意图门决定"该不该朝这踩"，同意门决定"人是否授权朝这踩"，可读性门决定"人是否看得懂我要朝这踩"。四门全过才承诺；任一门不过，优先退到更可撤回的动作，而不是更自信的解释。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（意图后验校准与非平稳检测 IDC）** 意图空间 Ι、信号史 h_t=(语音,手势/注视,人的轨迹,机器人动作史)，意图后验 p_t(ι)=Cal(q_ψ(ι|h_t))，校准契约 ECE_ι≤ε_ι；变化点指示 c_t∈{0,1} 由在线检测给出，检测延迟 ≤τ_det(δ_c)（以概率 ≥1−δ_c）。意图在 t 时刻"已稳定"记为 Settled(t) ⇔ H(p_t)≤H_settle ∧ max_ι p_t(ι)≥1−α_settle ∧ [t−Δ_settle,t] 内无变化点。动作 a 的悲观意图风险 R_ι^β(a)=CVaR_β^{ι~p_t}[Risk(a|ι)]，其中 Risk 含物理与规范两层（见定义 140）。

**定义 140（可撤回步态与点不可逆点 IGR）** 增广状态 x，步态计划 g（落脚点/时序/速度剖面），不可逆集 X_irr=X_irr^phys ∪ X_irr^norm（物理：坠落/压碎；规范：闯入禁区、贴近人、泄露等物理可退但社会不可逆）。点不可逆点 T_PNR(g,x_t)=inf{τ≥0 : 从 x_{t+τ} 出发，执行 g 的任意容许控制仍会在回到安全集前进入 X_irr}。可撤回裕度
R_m(g,x_t;L_ι) = T_PNR(g,x_t) − [τ_det(δ_c) + τ_veto(L_ι) + τ_stop(g)]
其中 τ_veto 是给定操作者/授权级 L_ι 的人否决反应上界，τ_stop(g) 是该步态的最坏刹停/反转时间。步态可行域 G_adm(x)={g : 物理证据门过 ∧ 稳定性/摩擦裕度过 ∧ R_m(g)≥0}；若计划本身包含不可避免的不可逆子动作，则该子动作另按定义 142 的"新鲜同意"处理，不能仅靠 R_m 消解。步态选择：在"进度不劣于最优 ε"的集合 G_ε 内按 (R_m, 可读性) 词典序取优——**同等进度下，先要更可撤回，再要更可读**。

**定义 141（可读步态与意图-步态一致性 IGL）** 人类观察者模型 q_h(ι|g,x)（人看机器人走 g 时对机器人意图的推断），可读性损失 ℓ_leg(g)=−E_{ι~p_t}[log q_h(ι|g,x)]。一致性分歧 D_ιg(p_t,g)=TV(p_t, q_h(·|g,x))。规则：(R1) D_ιg>θ_ι ⇒ 若 p_t 更可信，则改写步态或经 MXI 明示；若 q_h 更可信，则视为意图修订并触发 IDC；(R2) 可读性只在 G_ε 内优化，且 **不得改变授权级、不得降低 R_m 或任何物理裕度**；(R3) 任何"以提高可读性为由扩大同意范围"的操作一律拒绝。

**定义 142（意图绑定同意与截止 IBC）** 同意记录 Π=(ι_c,X_c,H,t_exp,L,nonce)，作用域谓词
Scope(a,Π) ⇔ [goal(a)∈N_{ε_ι}(ι_c)] ∧ [traj(a)⊆X_c] ∧ [t≤t_exp] ∧ [L(a)≤L(Π)]。
意图漂移 D_ι^c(t)=1−p_t(N_{ε_ι}(ι_c))。若 D_ι^c>ε_ι 或 Scope 失效 ⇒ **自动撤回**：授权降到当前会话下界、步态退到最可撤回档、通知人，并在任何跨越 PNR 的动作前要求重新确认。**推断单向性（A43）**：对任意意图更新，Π_{t+1}⊆Π_t，除非发生显式人工授权事件 e_grant；即推断只能收紧、不能扩张同意。澄清预算：追问仅在 VOI_ι>θ_ι^ask 且追问速率≤r_ask 时发起，否则默认保守停，避免把人训练成橡皮章。

**定义 143（主动意图探询步态 AIP）** 可撤回意图探询原语集 A_ι={停顿,重心侧移,朝目标偏转,半步回收,后退半步}，要求 g∈G_adm 且 R_m≥0 且不进入 X_irr。意图信息价值 VOI_ι(g)=E_o[H(p_t)−H(p_{t+1})]−c(g)（c 含时间与社会成本）。仅当 VOI_ι≥θ_ι^voi 且每检查点探询数≤k_intent 时执行；探询是"用身体提问"，其结论与显式人确认同权入账，但**不得替代不可逆动作所需的新鲜同意**。

**定义 144（意图-步态联合门 IGG 与证书 J_ig）** 动作 a 被接纳 ⇔ 四门全过：
(1) 物理门：FSE(a) 通过（第 57 轮，含 J_p）；
(2) 意图门：若 a 可撤回（所有子动作 R_m≥0），允许 H(p_t) 高；若 a 跨越 PNR，则须 Settled(t) ∧ R_ι^β(a)≤δ_ι；
(3) 同意门：Scope(a,Π) 且跨 PNR 时持有新鲜 e_grant；
(4) 可读性门：D_ιg≤θ_ι，或已明示意图且人确认。
证书 J_ig=(J_p, p_t/H_ι/c_t 日志, Π 与撤回日志, g 的 T_PNR/R_m/τ_stop, ℓ_leg/D_ιg 日志, 意图探询日志, J_g)。继承 J_p 全检。

## 2. 关键算法伪代码（完整版见产物区）

```python
def intent_update(p, h, psi, change_detector):       # IP-139
    p_new = psi.calibrate(psi.posterior(h))
    c = change_detector.detect(h)                    # 延迟 ≤ τ_det(δ_c)
    if c: p_new = psi.posterior(h[change_detector.last_cp:])
    settled = entropy(p_new) <= H_SETTLE and max(p_new) >= 1-ALPHA_SETTLE and not c
    return p_new, settled, c

def reversibility_margin(g, x, L_intent, delta_c):   # IP-140
    return point_of_no_return(g, x, X_irr) \
         - (tau_det(delta_c) + tau_veto(L_intent) + tau_stop(g))

def plan_gait_reversible(x, p, consent, M):          # IP-140/141
    best = max(progress(g) for g in admissible_gaits(x, M))
    G_eps = [g for g in admissible_gaits(x, M)
             if progress(g) >= best - EPS and physical_gate(g, M)]
    for g in G_eps: g.Rm = reversibility_margin(g, x, consent.L, DELTA_C)
    rev = [g for g in G_eps if g.Rm >= 0]
    return max(rev or G_eps, key=lambda g: (g.Rm, -legibility_loss(g, p)))

def consent_step(Pi, p, now, e_grant=None):          # IP-142: 推断只收紧
    if e_grant is not None: return expand(Pi, e_grant)   # 唯一扩权通道
    if 1 - mass(p, Pi.intent_eps) > EPS_I or now > Pi.t_exp:
        return revoke(Pi)
    return Pi
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| IDC | O(d_ψ)+O(\|h\|) | O(\|Ι\|+\|h\|) | ECE_ι≤ε_ι、变化点延迟 ≤τ_det(δ_c) |
| IGR | O(H_g·C_ctl) 求 T_PNR | O(\|G_ε\|) | T_PNR 取保守下界、τ_stop/τ_veto 取上界 |
| IGL | O(\|G_ε\|·d_ι) | O(\|G_ε\|) | 可读性不扩权、不降物理裕度 |
| IBC | O(1) | O(\|Π\|) | 推断单向收紧（A43）、新鲜同意 |
| AIP | O(\|A_ι\|·C_VOI) | O(\|A_ι\|) | 仅 G_adm∩{R_m≥0}、每检查点 ≤k_intent |
| IGG | O(\|σ\|) | O(\|σ\|) | 四门全过才承诺、跨 PNR 硬要求 |
| PCE++ | O(\|CP\|·(k_p+k_i)·(C_VOI+C_PNR)) | O(\|V\|+\|σ\|) | 可撤回优先、四态终止 |

**正确性定理（Intent-Reversible Commitment Soundness, IRCS 概要）**：在 A33–A40 上加 (A41) 意图校准与变化点（ECE_ι≤ε_ι、检测延迟 ≤τ_det(δ_c)、误报 ≤δ_fa）；(A42) 可撤回模型诚实（T_PNR 为保守下界、τ_stop/τ_veto 为上界、X_irr 含物理与规范两层且规范层显式登记）；(A43) 同意单调（推断只收紧、扩张必经 e_grant）；(A44) 可读性与探询安全（探询仅在 G_adm∩{R_m≥0} 内、可读性不改授权与物理裕度、MXI 诚实）。则：
(i) **物理健全性继承**：CCPS 的承诺失效率界不变；
(ii) **意图错误隔离**：对可撤回动作（R_m≥0），错误意图可在进入 PNR 前被检测并否决，故意图误识别对不可逆失效的贡献 ≤δ_c+δ_fa+δ_veto；对跨 PNR 动作，因要求 Settled ∧ CVaR_β≤δ_ι ∧ 新鲜同意，贡献 ≤ε_ι+δ_c+δ_grant。即"可撤回性把意图不确定性隔离在可逆层"，与第 57 轮"EV-xmodal 仅限 L1"同构；
(iii) **语义风险显式化**：若 X_irr^norm 登记完备，则任何规范不可逆动作都被当作跨 PNR 处理；若登记不完备，语义风险不可由本定理覆盖——这是本方案必须承认的边界；
(iv) **交互单调性**：意图推断、可读化、主动探询只能 (a) 收紧同意作用域、(b) 选择更可撤回/更慢的步态、(c) 在已认证落脚点内花时间换信息；不存在"更懂人 ⇒ 更敢替人做主"的升险路径；
(v) **终止性**：每检查点意图探询 ≤k_intent，PCE++ 在 k_probes+k_intent 内终止于 {承诺, 绕行, 问询, 安全停}。

## 6. 本轮最大风险

**一句话**：本轮最大风险是**规范不可逆集无法完全枚举、意图又可能被策略性隐藏**——一个物理可撤回、社会却不可逆的错误目标（闯入禁区、贴近人、泄露信息）可以满足 R_m≥0 并通过变化点检测，于是系统会稳定地"安全地做错事"；必须把规范不可逆集显式登记、把推断限定为只收紧同意，并在任何跨 PNR 前要求新鲜人工授权。

## 2. 关键算法伪代码

### IP-139 IDC（意图后验校准与非平稳检测）

```python
def intent_update(psi, h, cd, p_prev):
    c = cd.detect(h)                              # BOCPD/CUSUM，延迟 ≤ τ_det(δ_c)
    h_eff = h[cd.last_cp:] if c else h            # 变化后只用变化后窗口
    p = psi.calibrate(psi.posterior(h_eff))       # ECE_ι ≤ ε_ι
    H = entropy(p)
    settled = (H <= H_SETTLE and max(p.values()) >= 1 - ALPHA_SETTLE
               and not c)
    return p, {'H': H, 'settled': settled, 'change': c,
               'risk': cvap(p, lambda i: risk(a, i))}   # CVaR_β
```

### IP-140 IGR（点不可逆点与可撤回步态规划）

```python
def point_of_no_return(g, x, X_irr):
    future = rollout(g, x)
    for t in reversed(range(len(future))):
        if future[t].state in X_irr:
            continue
        if exists_control(lambda u: rollback_safe(future[t].state, u, g)):
            return future[t].t
        if t == 0:
            return 0.0
    return 0.0

def reversibility_margin(g, x, L_intent, delta_c):
    return point_of_no_return(g, x, X_irr) \
         - (tau_det(delta_c) + tau_veto(L_intent) + tau_stop(g))

def plan_gait_reversible(x, p, consent, M):
    gaits = admissible_gaits(x, M)
    best = max(progress(g) for g in gaits)
    G_eps = [g for g in gaits
             if progress(g) >= best - EPS and physical_gate(g, M)]
    for g in G_eps:
        g.Rm = reversibility_margin(g, x, consent.L, DELTA_C)
        g.leg = legibility_loss(g, p, q_h)
    rev = [g for g in G_eps if g.Rm >= 0]
    return max(rev or G_eps, key=lambda g: (g.Rm, -g.leg))  # 先可撤回，后可读
```

### IP-141 IGL（可读步态与意图-步态一致性）

```python
def legibility_loss(g, p, q_h):
    return -sum(p[i] * log(q_h.prob(i, g) + 1e-12) for i in p)

def intent_gait_consistency(p, g, q_h):
    return total_variation(p, q_h.distribution(g))

def legible_gait_select(G_eps, p, consent):
    g = max(G_eps, key=lambda g: (g.Rm, -legibility_loss(g, p, q_h)))
    if intent_gait_consistency(p, g, q_h) > THETA_I:
        g = announce_or_halt(g, p)          # 经 MXI 明示或停；不得扩权
    return g

def announce_or_halt(g, p):
    assert not expands_consent(g)           # A44/R3：可读性永不扩权
    return g if g.Rm >= 0 else halt()
```

### IP-142 IBC（意图绑定同意与自动截止）

```python
def consent_step(Pi, p, now, e_grant=None):
    if e_grant is not None:                 # 唯一扩权通道：显式人工授权
        return expand(Pi, e_grant)
    drift = 1.0 - mass(p, Pi.intent_eps)    # 意图漂移到同意邻域外
    if drift > EPS_I or now > Pi.t_exp:
        return revoke(Pi, reason='drift' if drift > EPS_I else 'expired')
    return Pi                               # 推断只能收紧，不能扩张

def before_pnr(a, Pi, p, settled):
    if not settled or not Scope(a, Pi):
        return False
    return Pi.has_fresh_grant(a.goal, a.corridor)   # 跨 PNR 必须新鲜同意
```

### IP-143 AIP（主动意图探询步态）

```python
def active_intent_probe(x, p, M, budget, rate, consent):
    if budget.intent_left <= 0 or rate.exceeded():
        return None
    cands = [g for g in A_INTENT
             if g in admissible_gaits(x, M)
             and reversibility_margin(g, x, consent.L, DELTA_C) >= 0
             and not enters_irr(g, x)]      # 只在已认证落脚点内提问
    if not cands:
        return None
    g = max(cands, key=lambda g: voi_intent(g, p) - cost(g))
    if voi_intent(g, p) < THETA_VOI_I:
        return None
    budget.spend_intent()
    rate.record()
    return g
```

### IP-144 IGG（意图-步态联合门与证书 J_ig）

```python
def intent_gait_gate(a, M, p, Pi, settled, q_h):
    if not fse_gate(a, M):                            # 物理门（第 57 轮）
        return ('reject', 'physical')
    crosses = a.T_PNR < float('inf')                  # 是否跨越 PNR
    if crosses:
        if not settled:
            return ('reject', 'intent_unsettled')
        if cvap(p, lambda i: risk(a, i)) > DELTA_I:    # 悲观意图风险
            return ('reject', 'intent_risk')
        if not before_pnr(a, Pi, p, settled):
            return ('reject', 'no_fresh_consent')
    else:
        if a.gait.Rm < 0:
            return ('reject', 'not_reversible')
    if intent_gait_consistency(p, a.gait, q_h) > THETA_I and not a.announced:
        return ('reject', 'illegible')                # 可读性门
    if not Scope(a, Pi):
        return ('reject', 'out_of_scope')             # 同意门
    return ('ok', J_ig(a, p, Pi, a.gait, q_h))

def certificate_jig(sched, M, p, Pi, settled, q_h, logs):
    for a in contacts(sched):
        st = intent_gait_gate(a, M, p, Pi, settled, q_h)
        if st[0] != 'ok':
            return st
    return ('ok', J_ig(M.core, core_contacts(sched), p, Pi,
                       [a.gait for a in sched], q_h, logs))
```

def probe_commit_evolve_plusplus(x0, M, task, budget, consent,

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| IDC | O(d_ψ)+O(\|h\|) | O(\|Ι\|+\|h\|) | ECE_ι≤ε_ι、变化点延迟 ≤τ_det(δ_c) |
| IGR | O(H_g·C_ctl) 求 T_PNR；O(\|G_ε\|) 选择 | O(\|G_ε\|) | T_PNR 保守下界、τ_stop/τ_veto 上界（A42） |
| IGL | O(\|G_ε\|·d_ι) | O(\|G_ε\|) | 可读性不扩权、不降物理裕度（A44） |
| IBC | O(1) | O(\|Π\|) | 推断只收紧、显式扩权（A43） |
| AIP | O(\|A_ι\|·C_VOI) | O(\|A_ι\|) | 仅 G_adm∩{R_m≥0}、≤k_intent |
| IGG | O(\|σ\|) | O(\|σ\|) | 四门全过、跨 PNR 硬要求 |
| PCE++ | O(\|CP\|·(k_p+k_i)·(C_VOI+C_PNR)+\|CP\|·A\*) | O(\|V\|+\|σ\|) | 可撤回优先、四态终止 |

**正确性定理（Intent-Reversible Commitment Soundness, IRCS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 意图校准与变化点：ID 意图 ECE_ι≤ε_ι 且声明诚实，变化点检测延迟 ≤τ_det(δ_c)、误报 ≤δ_fa；**(A42)** 可撤回模型诚实：T_PNR 为保守下界，τ_stop、τ_veto 为保守上界，X_irr=X_irr^phys∪X_irr^norm 且规范层显式登记；**(A43)** 同意单调：任何由推断触发的更新只能收缩 Scope，扩张必须经显式事件 e_grant；**(A44)** 可读性与探询安全：意图探询仅在 G_adm∩{R_m≥0} 内且不入 X_irr，可读性不改授权级、不降物理裕度，MXI 内容诚实。则：

1. **物理健全性继承**：第 57 轮 CCPS 的物理承诺失效率界不变。
2. **意图错误隔离**：对可撤回动作（R_m≥0），实际意图偏离 p_t 所需的风险可在 T_PNR 前被检测并否决，故意图误识别对不可逆失效的贡献 ≤δ_c+δ_fa+δ_veto；对跨 PNR 动作，因要求 Settled ∧ CVaR_β≤δ_ι ∧ 新鲜 e_grant，贡献 ≤ε_ι+δ_c+δ_grant。**可撤回性把意图不确定性隔离在可逆层**，与第 57 轮"EV-xmodal 仅限 L1"同构。
3. **语义风险显式边界**：若 X_irr^norm 登记完备，任何规范不可逆动作均按跨 PNR 处理；若登记不完备，语义风险不能被本定理的物理项覆盖，只能以登记审计 + 人工升级 + 保守拒绝兜底。
4. **交互单调性**：意图推断、可读化、主动探询只能经 (a) 收紧同意作用域、(b) 选择更可撤回/更慢的步态、(c) 在已认证落脚点内花时间换信息影响系统；不存在"更懂人 ⇒ 更敢替人做主"的升险路径。
5. **终止性**：每检查点意图探询 ≤k_intent，PCE++ 在 k_probes+k_intent 内终止于 {承诺, 绕行, 问询, 安全停}。
6. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])
             − P(意图漂移未检出 ∧ R_m<0) − P(同意作用域陈旧)
             − P(X_irr^norm 登记遗漏) − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)

P_wrong_intent_commit ≤ Σ_cp (ε_ι + δ_c + δ_grant + δ_fa)
```

关键：**可撤回性给意图不确定性一个物理隔离层**（能撤回时允许意图不完全确定，不能撤回时强制意图稳定 + 新鲜同意）；**意图绑定同意让"同意"从运动授权升级为作用域授权**（推断只收紧、扩权只由人给）；**可读步态让"我准备做什么"成为可被人及时否决的公共信息**；三个新机制仍全部经"更准的信念或更保守的动作"两个安全通道起作用。

云边协议 CEB++ → **CEB+++**：云端可下发意图模型与人类观察者模型的增量更新（带版本），但与第 57 轮元模型相同，**一切判定器走隔离**——先在边端以影子模式运行，校准回归测试（ECE_ι 不劣化 ∧ 变化点延迟不增 ∧ 可读性越权为 0 ∧ 规范不可逆集版本一致）通过后才接管判定；边端回传"意图漂移-撤回"事件、可读性分歧样本与 PNR 反例，作为云端意图语料与规范不可逆集的补盲依据。特别地，**规范不可逆集只能由人审阅升级，云端不得自动扩充**——否则"更懂人"会经由模型更新变成"更敢替人做主"。

## 6. 本轮最大风险

**一句话**：本轮最大风险是**规范不可逆集无法完全枚举、意图又可能被策略性隐藏**——一个物理可撤回、社会却不可逆的错误目标（闯入禁区、贴近人、泄露信息）可以满足 R_m≥0 并通过变化点检测，于是系统会稳定地"安全地做错事"；必须把规范不可逆集显式登记、把推断限定为只收紧同意，并在任何跨 PNR 前要求新鲜人工授权。
