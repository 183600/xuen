# 第 58 轮（承接第 57 轮「少样本×多模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「柔顺控制」×「轨迹优化」）

> 第 57 轮把安全的赌注从"模型置信"换到"证据承诺"，再换到"少样本可校准、跨模态可对账、个性化有界的证据承诺"；但它仍默认一个几何-静力学世界：**安全是接触点/区域的属性**。证据贴在区域 `r` 上，力上限 `F_abs` 是一个常数闸门，L0/L1/L2 是与运动无关的静态标签。真实世界里伤害由**轨迹 × 阻抗 × 时间**共同交付：同一条"已证明安全"的接触点，慢速低刚度接近是 L1，快速高刚度接近却可能在接触瞬间以冲击、力超调、滑移把可逆接触变成不可逆；反过来，一个被静态标签判成 L2 的脆弱表面，用足够柔顺的轨迹与足够低的力可以安全通过。更尖锐的是，**轨迹优化会主动把解推到模型有效域的边界**——那正是证据最稀薄、模型误差最大之处；优化器不是在使用模型，而是在"攻击"模型。本轮把承诺的单位从"接触点"改成 **(σ,Z) 轨迹-阻抗束**，把可逆性从静态标签改成**动态严重度**，把柔顺从"控制器参数"改成**同时是执行器、传感器与安全证书**，把力上限从常数改成**由证据逐级挣得的包络**。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"在已验证柔顺包络内的轨迹说可信"**。

核心矛盾：
- **H29（柔顺 vs 信息）**：柔顺降低接触力、让接触更安全，但同时也降低激励幅值与信噪比：低刚度下力-位移曲线又软又小，表面屈服、滑移起始、摩擦极限这些**只在较高力区才显现**的参数被压进噪声里。想学会高力区必须进入高力区，而不能进入高力区正是为了安全——这是一个"激励-安全"对偶；低刚度重复一百次也学不到"高力下会不会崩"。
- **H30（最优 vs 外推）**：轨迹优化（含接触隐式优化）的最优解总在约束边界上；当约束模型只用慢速、低力轨迹校准过时，最优解恰好落在未验证区。模型误差在边界处最大，而优化器偏爱高收益、低成本的边界动作，于是"性能最优"与"证据最弱"重合。鲁棒优化的不确定集若来自旧分布，边界外推仍会自信。
- **H31（可逆 vs 静态标签）**：可逆性不是位置属性，而是能量、冲量、峰值力、力变化率、滑移与损伤历史的属性。同一接触点，低 K 慢速为 L1，高 K 快速为 L2；静态标签要么把可柔顺通过的表面误判为 L2（过度保守、绕行浪费），要么把高刚度路径误判为 L1（危险）。损伤还会累积（疲劳、微裂、磨损），同一路径第二次不再等价。

## 0. 直觉与动机

**灵感 1（柔顺控制 → 把"力如何随时间交付"变成一等安全货币）**
直觉：位置控制的错误以"撞上去"的形式交付，力控/阻抗控制的错误以"顶住"的形式交付。柔顺控制器本质上是一根**可编程弹簧-阻尼器**：它把位置不确定性转换成有界力，把冲击尖峰低通掉，把不可逆接触"软化"成可逆接触。但柔顺不是免费的：太软会失去对环境的辨识力、也失去对滑移的抑制；太硬则把模型误差直接变成破坏力。于是安全不再是"接触前把力限死在 F_abs"，而是**主动设计 (速度, 刚度, 阻尼, 力上限) 的时间曲线**，让能量与冲量落在可逆阈值内。更进一步，**无源性能量罐（passivity energy tank）** 给出一个不依赖精确接触模型的能量上界：控制器只能花"存进去的能量"，花完必须变被动。它不保证峰值力，但保证不会凭空注入能量——这正好补上"优化器可能利用模型误差"的漏洞。

**灵感 2（柔顺控制 → 接触本身是传感器，但软接触会掩盖失败）**
直觉：一次柔顺接触的力-位移曲线同时暴露刚度、摩擦、屈服点与滑移趋势，是比"落足成功/失败"丰富得多的观测。但这里有个陷阱：**柔顺会把失效变安静**——低刚度下的慢滑移、蠕变、微裂往往不产生明显力尖峰，传感器看到的是一条"温和"的曲线。因此柔顺探针必须配独立的滑移/位移观测与主动微抖动（dither），并把"安静"本身当作需要证伪的假设，而不是当安全证据。

**灵感 3（轨迹优化 → 优化的是路径、时间律与阻抗的三重积）**
直觉：传统轨迹优化在给定风险地图上找一条最短/最省的路；但同一路径换一个接近速度或阻抗曲线，风险可以差一个数量级。因此本轮把决策变量扩成 `(σ, Z(·), g)`：路径、阻抗调度、步态/抓取模式一起优化。关键设计是**把约束分成两层**：硬层（硬件力熔断、关节/运动学、无源性能量罐、实时安全滤波器）与证据层（已验证柔顺包络 `𝒱_r`、严重度上界）。硬层不信任任何模型，必须在运行时兜底；证据层只允许优化器在"证据覆盖过的"区域内发挥。优化器可以激进，但不能越出证书。

**灵感 4（合流 → 探针就是一条柔顺轨迹，证据是一个包络而不是一个点）**
直觉：探询不再是"在区域 r 点一下"，而是"选择一条低阻抗、可卸载、信息量最大的柔顺轨迹"。它同时做三件事：测参数、限制风险、扩张未来允许的力/速度包络。证据的单位随之从"点声明"变成**包络证书** `ℰ_r={(v_app,K,F_cap): 预测严重度在可逆阈内且模型适用}`。承诺也不再是"这个点安全"，而是"这条轨迹的这一段在该包络内安全"——一条轨迹可以前半段 L1、后半段 L2，逐段过门、逐段承诺。

**灵感 5（证据门与算子 → 第六类证据 EV-comply，力阶梯与 J_t 证书）**
直觉：第 57 轮的五类证据（EV-probe*/visit/margin/xmodal/human）都在回答"这个区域的信念够不够"，没有一类在回答"这条轨迹的力-时间曲线会不会造成不可逆伤害"。本轮新增 **EV-comply**：在已验证包络内、带校准残差的柔顺接触证据；它证明的是一个集合，而不是一个点。不可逆接触的必要证据集升级为"探针/裕度证据 ∧ EV-comply 包络 ∧ 佐证 ∧ 力不超过已验证上限"；`EV-xmodal` 依旧只限 L1。算子 `PCTE` 把探询预算、柔顺参数与轨迹优化放在同一张预算表上：先算包络，再在包络内优化；不可行则做安全激励扩张包络；仍不可行则走"更柔顺更慢的保守管 → 绕行 → L2 协商 → 安全停"的降级梯。所有新机制只经"包络更准（含收缩）"或"动作更保守（更软/更慢/更缓/绕行/停）"两个安全通道起作用，延续交互单调性。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（动态可逆性与严重度 DCR）** 轨迹-阻抗束 `x=(σ,Z,g)`：路径与时间律 `σ:[0,T]→𝒳`，阻抗调度 `Z(t)=(M_d(t),K_d(t),D_d(t))`，步态/抓取模式 `g`；接触响应给出力 `f(t)` 与接触点速度 `v_c(t)`。严重度向量
`s(x;θ,h)=(W^+, J, F_peak, Ḟ_max, d_slip, N_cyc)`
其中 `W^+=∫max(0,f·v_c)dt` 为净注入功，`J=∫_contact‖f‖dt` 为冲量，`F_peak=max‖f‖`，`Ḟ_max=max‖df/dt‖`，`d_slip=∫‖v_t‖·1[‖f_n‖>0]dt` 为累积滑移，`N_cyc` 为疲劳循环计数；`θ` 为表面参数（刚度/摩擦/屈服力/蠕变），`h` 为接触历史（既往损伤、磨损、温度）。可逆判据 `Rev(x;θ,h) ⇔ s(x;θ,h) ≤ s_rev(θ,h)`（逐分量），可逆裕度 `m_rev=min_i (s_rev,i−s_i)/scale_i`。动态层级 `L_dyn(x;θ,h)=L0`（无接触）/`L1`（Rev 且 `m_rev≥0`）/`L2`（否则）。在信念 `b_r`（第 57 轮摊销后验或共形带）下取**鲁棒层级** `L_rob(x)=max_{θ∈Θ_r} L_dyn(x;θ,h)`，`Θ_r` 为 `1−α` 可信集；若 `Θ_r` 在某方向无界或区域为 OOD 未认证，则直接 `L_rob=L2`。层级不是标签而是**轨迹段的函数**：同一点在不同 `(σ,Z)` 下可以落在不同层级。

**定义 140（柔顺感知轨迹优化 CTO）** 决策 `x=(σ,Z,g)`，在可信集上做鲁棒/机会约束优化：
`min_x E_{θ~b_r}[c_task(σ,g)+λ_W W^++λ_J J+λ_F F_peak+λ_T T]`
`s.t. (a) L_rob(x)≤L_allowed； (b) x∈𝒱_r； (c) E_inj(t)≤E_tank(t), E_tank≥0； (d) ‖f(t)‖≤F_hw, 关节/运动学/摩擦锥； (e) m_rev(t)≥θ_m`。
其中 `𝒱_r` 是**已验证柔顺包络**（由 EV-comply 证据支撑的 `(v_app,K,F_cap)` 集合）；约束 (c)(d) 为模型无关或硬件硬层，由运行时安全滤波器兜底；约束 (a)(b)(e) 为证据层，只允许优化器在证据覆盖区内活动。单调性要求：证据更弱/更旧 ⇒ `𝒱_r` 只收缩不扩张；包络扩张必须有新边界上的 EV-comply 证据。实现上加**边界缓冲**：在归一化包络坐标中要求距边界 `≥η_env`，禁止优化器贴着证书边缘取最优；输出裕度曲线 `m(t)` 与活跃约束集。当证据层不可行时，不允许"放宽证据层"，只允许切到保守管（更低 `K`、更低 `v_app`、更高阻尼、更大 `m_rev`）或探询/绕行。

**定义 141（柔顺信息探针 CIP）** 安全激励集 `𝒮_r={x: L_rob(x)≤L1, 可卸载, E_inj≤E_tank}`；目标参数 `ψ=(μ,F_y,k_s,滑移起始,蠕变率)` 是"下一次承诺真正需要、且能扩张包络"的方向。信息目标 `I_w(x)=I(ψ;y|x)` 投影到包络扩张方向 `w`（不是任意参数的信息）；探针选择
`x_p=argmax_{x∈𝒮_r} I_w(x)/(E[severity(x)]+cost(x))`。
**力阶梯**：`0=F_0<F_1<…<F_m`，第 `i+1` 级力上限只能在第 `i` 级已验证后抬升，且 `F_{i+1}−F_i≤ΔF_cert`；`ΔF_cert` 由分层共形外推残差与局部 Lipschitz 界给出，无法给出有限界时 `ΔF_cert=0`（**不跳级规则**）。低刚度可能掩盖滑移，故探针必须带主动微抖动与独立位移/滑移通道（第 57 轮 XMC 的多模态分账在此复用），并把"没有力尖峰"当作待证伪命题而非安全结论。

**定义 142（柔顺包络证据 CCE 与 EV-comply）** 一次在已验证包络内执行的柔顺接触给出测量 `y=(f(t),x(t),v(t))` 与残差 `r=s_meas−s_pred`。按表面簇分层做共形校准，得到覆盖 `≥1−α_env` 的残差界 `ε_env`。**柔顺包络**
`ℰ_r={(v_app,K_d,F_cap): sup_{θ∈Θ_r}s(x(v_app,K_d,F_cap);θ,h)≤s_rev(θ,h) ∧ model_applicable ∧ 残差界≤ε_env}`。
`EV-comply` 是一个带四元组 `(表面簇, ℰ_r, F_valid=sup{F_cap:(·)∈ℰ_r}, 残差/校准版本)` 的证据类：它证明的是**集合**，不是点；只在 `ℰ_r` 内、且实际力/速度不超过证书上限时有效。规则：(R1) EV-comply 可为 L1 接触提供一个佐证，但不得单独授权 L2；(R2) 任何使 `(v_app,K_d,F_cap)` 越出 `ℰ_r` 的改动都会使证书立即失效，需重新探针；(R3) 表面簇重分类或第 57 轮 ρ 事后证伪触发时，按簇回溯失效；非可交换（新簇/OOD）时包络退回保守默认，不允许用旧残差外推；(R4) 力上限 `F_valid` 只能沿力阶梯单调抬升，不得由轨迹优化器自行放宽。

**定义 143（轨迹证书 J_t 与 CTC）** `J_t=(J_p, σ, Z(·), {s_i,s̄_i}, m(t), L(t), ℰ_r, F_valid, E_tank_log, model_ver, filter_log, probe_log, fallback_log, h)`，其中 `s̄_i` 为最坏情况严重度上界。校验：(1) 每段 `L_rob≤declared`；(2) `m_rev(t)≥θ_m` 且 `m(t)≥θ_m`；(3) 全程 `‖f‖≤F_valid≤F_hw`；(4) 能量罐非负且可审计；(5) 每个接触段都有覆盖该段的 EV-comply，且 `(v_app,K,F_cap)` 在 `ℰ_r` 内；(6) 不跳级、不外推；(7) 层级切换带滞回且只向保守方向瞬切；(8) 安全滤波器若介入则记录并视为"计划未被完全执行"的降级证据。承诺按**轨迹段**签发：同一轨迹可前段 L1、后段 L2；执行前逐段过门，跨段转换必须单调安全。

**定义 144（探-柔-轨-演算子 PCTE）** 每个检查点：①元推断得 `b_r,Θ_r`，据 EV-comply 得 `ℰ_r`；②在 `ℰ_r` 内解 CTO，得 `x*,m(t)`；③若不可行或 `min_t m(t)<θ_m`，做 CIP 安全激励（预算 `k_c`、能量 `E_p`）以收缩 `Θ_r` 或扩张 `ℰ_r`，回②；④仍不可行则降级梯：保守柔顺管（在 `ℰ_r` 内取最软最慢可行解）→ 绕行 → L2 协商（`τ_int(auth)`）→ 安全停；⑤仅当 `J_t` 全检通过且第 57 轮证据门通过才承诺；⑥执行后更新严重度历史 `h` 与残差校准。联合预算 `k_probes+k_cons+k_c`、能量 `E_bud`、时间 `T_bud`；每次迭代必须使"不确定度下降"或"包络有效扩张"或"动作保守度上升"之一严格发生，否则终止，保证有限步停机。

## 2. 关键算法伪代码（完整版见产物区）

```python
def feasible_trajectory(x, b_r, env, h):           # IP-139/140 合流
    theta_set = credible_set(b_r)                   # ID 后验或 OOD 共形带
    if unbounded(theta_set): return False, 'ood_unbounded'
    s_worst = max_severity(x, theta_set, h)         # 最坏情况严重度
    return (s_worst <= s_rev(theta_set)) and x in env and margin(x) >= theta_m

def cto(cands, b_r, env, h):                        # IP-140
    safe = [x for x in cands if feasible_trajectory(x, b_r, env, h)]
    if not safe: return None, 'need_probe_or_reroute'
    return min(safe, key=lambda x: robust_cost(x, b_r)), 'ok'

def cip(M, r, env, budget):                         # IP-141: 安全激励 + 力阶梯
    cands = [x for x in compliant_motions(M, r)
             if feasible_trajectory(x, M.b[r], env, M.h[r])
             and unloadable(x) and info_gain(x, target=next_commit_param(r)) > 0]
    return max(cands, key=lambda x: info_gain(x) / (exp_severity(x) + cost(x))) \
           if cands and budget.c_left > 0 else None
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| DCR | O(N_t·d_s)/评估 | O(d_s+H) | 严重度模型诚实、阈值按表面/历史校准 |
| CTO | O(\|X\|·C_TO)（含最坏情况采样） | O(\|X\|) | 只在已验证包络内优化、边界缓冲、硬层兜底 |
| CIP | O(\|A_c\|·(C_INFO+C_SEV)) | O(\|A_c\|) | 探针可卸载、力阶梯不跳级、滑移可观测 |
| CCE | O(N_env·d_s) + O(N_cal) 共形 | O(\|ℰ\|+N_cal) | 分层共形覆盖、非可交换即退回保守 |
| J_t | O(\|σ\|·N_t) | O(\|σ\|) | 逐段层级、外推禁令、滤波日志完备 |
| PCTE | O(\|CP\|·(k_p+k_c)·(C_TO+C_INFO+C_SEV)) | O(\|V\|+\|ℰ\|) | 联合预算、良基终止、四态完备 |

**正确性定理（Compliant-Trajectory Soundness, CTS 概要）**：在 A33–A40 上加 **(A41)** 严重度模型与分层共形：在表面簇内 `P(s≤s̄)≥1−α_env`，严重度预测器与残差校准诚实，分布漂移由聚类/漂移检测触发重校准；**(A42)** 已验证包络与不跳级：`𝒱_r` 的扩张必须由新边界上的 EV-comply 支撑，`F_valid` 沿力阶梯单调、`ΔF_cert` 有界或为零；**(A43)** 安全激励：每个 CIP 动作在当前 `Θ_r` 下 `L_rob≤L1`、可卸载、且信息投影到包络扩张方向；**(A44)** 无源性能量罐：`E_inj(t)≤E_tank(t)` 且罐状态可测，能量不能凭空注入；**(A45)** 安全滤波器：运行时对力/关节/能量硬界的兜底独立于优化器，介入必记录。则：
(i) **承诺健全性**：对已验证表面簇，`P(某承诺段超可逆阈值)≤δ_f+α_env+ε_meta+δ_probe+ε_h`；OOD/新簇不进入 `ℰ_r`，只能走保守默认或 L2。
(ii) **无外推性**：任一被承诺轨迹满足 `‖f(t)‖≤F_valid`，而 `F_valid` 只在相应力级被 EV-comply 验证后抬升；因此不存在"用低力证据为高力轨迹背书"的通道。
(iii) **优化器不可越证**：CTO 的解被限制在 `ℰ_r` 内且距边界 `≥η_env`，硬层滤波器独立兜底；模型误差最多使实际严重度落在共形上界内，不能通过优化被"用尽"到阈值之外。
(iv) **交互单调性强化**：柔顺、探针、轨迹优化只经"包络更准（含收缩）"或"动作更保守（更软/更慢/更缓/绕行/停）"影响承诺；不存在放宽全局硬界或提高未验证力上限的路径。
(v) **终止性**：`k_p+k_c` 与能量/时间预算有限，PCTE 终止于 {承诺, 保守管, 绕行, L2 协商, 安全停}。

## 6. 本轮最大风险

**一句话**：本轮把安全的赌注从"证据是否足够"换到"柔顺包络证书是否覆盖真实接触严重度"，而柔顺会**主动掩盖失效**（低刚度下慢滑移、蠕变、疲劳不产生明显力信号），轨迹优化又会把最优解推到包络边界——模型误差最大处；一旦严重度预测器在边界外推失效，系统会以"在包络内可证安全"的证书给出安静的、难以察觉的错误承诺，必须以模型无关的力/能量硬界、无源性能量罐、边界缓冲与跨模态滑移监测四重护栏，且力上限只能由已验证探针逐级抬升，绝不在未验证的力区间做轨迹优化。

### IP-139 DCR（动态可逆性与鲁棒层级）

```python
def severity(contact, x, theta, h):
    Wp   = integral(max(0.0, dot(f, vc)) for f, vc in contact)
    Jimp = integral(norm(f) for f in contact.force)
    Fpk  = max(norm(f) for f in contact.force)
    Fdot = max(norm(df) / dt for df in contact.force)
    slip = integral(norm(vt) * (norm(fn) > 0)
                    for vt, fn in zip(contact.v_t, contact.f_n))
    return Severity(W=Wp, J=Jimp, F=Fpk, Fdot=Fdot, slip=slip,
                    ncyc=h.ncyc + 1)

def rev_margin(s, s_rev, scale):
    return min((s_rev[i] - s[i]) / scale[i] for i in range(len(s)))

def dynamic_level(x, theta, h):
    s = severity(contact_of(x), x, theta, h)
    return (L0 if not contact_of(x).touches else
            L1 if all(s[i] <= s_rev(theta, h)[i] for i in range(len(s)))
            else L2)

def robust_level(x, b_r, h):
    theta_set = credible_set(b_r)                 # 第 57 轮后验 / OOD 共形带
    if unbounded(theta_set): return L2            # 无界即不可逆
    return max(dynamic_level(x, th, h) for th in sample_worst(theta_set))

def commitment_margin(x, b_r, h):
    theta_set = credible_set(b_r)
    return min(rev_margin(severity(contact_of(x), x, th, h),
                          s_rev(th, h), scale_of(th))
               for th in sample_worst(theta_set))
```

### IP-140 CTO（柔顺感知轨迹优化：硬层 + 证据层）

```python
def cto(cands, b_r, env, h, model):
    safe = []
    for x in cands:
        if robust_level(x, b_r, h) > L_allowed(x):  continue  # 证据层
        if not inside_env(x, env, margin=ETA_ENV):  continue  # 边界缓冲
        if commitment_margin(x, b_r, h) < THETA_M:  continue
        if not passivity_precheck(x, model):        continue  # 无源预检
        safe.append(x)
    if not safe: return None, 'need_probe_or_fallback'
    return min(safe, key=lambda x: robust_cost(x, b_r)), 'ok'

def robust_cost(x, b_r):
    return max(c_task(x) + LAM_W * s.W + LAM_J * s.J
               + LAM_F * s.F + LAM_T * T(x)
               for th in sample_worst(credible_set(b_r))
               for s in [severity(contact_of(x), x, th, h)])

def safety_filter(x_cmd, x_state, model):
    # 运行时兜底：不信任优化器的可行性声明
    u = enforce_hard_bounds(x_cmd, x_state)        # 力/关节/运动学
    u = energy_tank_clip(u, x_state)               # E_inj <= E_tank
    if not model_trusted(x_state): u = passive_fallback(u)
    return u
```

### IP-141 CIP（柔顺信息探针与力阶梯）

```python
def cip(M, r, env, budget, h):
    target = next_commit_param(r)                  # 下一次承诺真正需要的 ψ
    cands = [x for x in compliant_motions(M, r)
             if robust_level(x, M.b[r], h) <= L1
             and unloadable(x)
             and inside_env(x, env)
             and force_rung_ok(x, env.F_valid, delta_cert(M, r))
             and info_gain(x, target) > 0]
    if not cands or budget.c_left <= 0: return None
    return max(cands, key=lambda x: info_gain(x, target)
                         / (expected_severity(x) + cost(x)))

def force_rung_ok(x, F_valid, dF_cert):
    return x.F_cap <= F_valid + dF_cert          # 不跳级；dF_cert=0 即禁止抬升

def delta_cert(M, r):
    # 分层共形外推残差 + 局部 Lipschitz 界；给不出有限界则 0
    return min(lipschitz_bound(M, r), conformal_extrapolation(M, r))

def probe_with_slip_watch(x, cap):
    y = execute(x, cap=cap)
    y.slip = independent_slip_channel(y)          # 独立位移/滑移通道
    y = add_dither(y)                             # 主动微抖动暴露慢滑移
    return y
```

### IP-142 CCE（柔顺包络证据 EV-comply）

```python
def update_envelope(env, y, cluster):
    r = severity(y) - severity_pred(y, env.theta)
    env.cal[cluster].append(r)                    # 按表面簇分层
    eps = conformal_quantile(env.cal[cluster], alpha_env)
    env.residual_bound[cluster] = eps
    env.version += 1
    return env

def ev_comply_ok(e, env, cluster):
    if cluster not in env.cal: return False       # 新簇/OOD：无可交换性
    if e.v_app > env.v_max:      return False
    if e.K_d  > env.K_max:       return False
    if e.F_cap > env.F_valid:    return False     # 不得越级
    if e.model_ver != env.model_ver: return False
    return e.residual <= env.residual_bound[cluster]

def expand_envelope(env, x_probe):
    # 只允许在新边界上由 EV-comply 支撑的扩张；否则只收缩
    if ev_comply_ok(x_probe.evidence, env, x_probe.cluster) \
       and x_probe.F_cap <= env.F_valid + delta_cert(env.ctx, x_probe.region):
        env.valid |= boundary_ball(x_probe)
        env.F_valid = max(env.F_valid, x_probe.F_cap)
    else:
        env.valid &= shrink_by(x_probe)           # 单调收缩
    return env
```

def trajectory_certificate(sched, M, env, h, logs):
    for seg in segments(sched):
        if robust_level(seg.x, M.b[seg.r], h) > seg.declared_level:
            return ('reject', 'level_exceeded', seg)

| CIP | O(\|A_c\|·(C_INFO+C_SEV)) | O(\|A_c\|) | 可卸载、力阶梯不跳级、滑移可观测（A43） |
| CCE | O(N_env·d_s+N_cal log N_cal) | O(\|ℰ\|+N_cal) | 分层共形覆盖、非可交换即退回保守（A41/A42） |
| J_t | O(\|σ\|·N_t) | O(\|σ\|) | 逐段层级、外推禁令、滤波/能量日志完备（A42/A45） |
| PCTE | O(\|CP\|·(k_p+k_c)·(C_TO+C_INFO+C_SEV)) | O(\|V\|+\|ℰ\|) | 联合预算、良基终止、四态完备 |

**正确性定理（Compliant-Trajectory Soundness, CTS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 严重度模型与分层共形：在已验证表面簇内 `P(s≤s̄)≥1−α_env`，严重度预测与残差校准诚实，漂移/新簇触发重校准而非沿用旧残差；**(A42)** 已验证包络与不跳级：`𝒱_r` 的扩张必须由新边界上的 EV-comply 支撑，`F_valid` 沿力阶梯单调，`F_{i+1}−F_i≤ΔF_cert` 或 `ΔF_cert=0`；**(A43)** 安全激励：每个 CIP 动作在当前 `Θ_r` 下 `L_rob≤L1`、可卸载，且信息投影到包络扩张方向；**(A44)** 无源性能量罐：`E_inj(t)≤E_tank(t)` 且罐状态可测，能量不能凭空注入；**(A45)** 安全滤波器：对力/关节/能量硬界的运行时兜底独立于优化器，介入必记录。则：

1. **承诺健全性**：对已验证表面簇，`P(某承诺段超过可逆阈值) ≤ δ_f+α_env+ε_meta(k)+δ_probe+ε_h(w_max)`；OOD/新簇不进入 `ℰ_r`，只能走保守默认或 L2 协商。
2. **无外推性**：任一被承诺轨迹满足 `‖f(t)‖≤F_valid`；`F_valid` 只在相应力级被 EV-comply 验证后抬升。因此不存在"用低力证据为高力轨迹背书"的通道，力上限是**挣来的**而非假设的。
3. **优化器不可越证**：CTO 解被限制在 `ℰ_r` 内且距边界 `≥η_env`，证据层不因性能压力放宽；硬层滤波器独立兜底。模型误差最多使实际严重度落在共形上界内，不能被优化"用尽"到阈值之外。
4. **交互单调性强化**：探针、柔顺、轨迹优化只经 (a) 包络更准（含收缩/失效）或 (b) 动作更保守（更软、更慢、更缓、绕行、L2、停）影响承诺；不存在放宽全局硬界、提高未验证力上限或跳过力阶梯的升险路径。
5. **终止性**：`k_p+k_c`、`E_bud`、`T_bud` 有限；每轮迭代必须使不确定度下降、包络有效扩张或保守度上升之一严格发生，故 PCTE 在联合预算内终止于 {承诺, 保守管, 绕行, L2 协商, 安全停}。
6. **部署界**（对检查点与轨迹段取联合界）：

```
P_safe ≥ 1 − Σ_cp Σ_seg (δ_f + α_env + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])
             − P(𝓜 陈旧未检出) − P(能量罐约束失效) − P(安全滤波旁路)
             − P(静态标签被误用为动态层级) − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

关键：**柔顺给安全裕度、包络给证据边界**（安全不押在"这个点以前安全"上）；**力阶梯把"力"变成逐级挣得的权限**（没有新证据就没有新力级）；**EV-comply 证明集合而非点**（一次探针只扩张它真正覆盖的邻域）；**硬层与能量罐不信任优化器**（模型误差被模型无关兜底截住）。

## 6. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 严重度模型/共形在表面漂移下失效 | 高 | 表面簇分层 + 漂移检测 + 非可交换退回保守默认 + 周期性重校准与边界审计 |
| 柔顺掩盖失效（慢滑移/蠕变/疲劳"安静"） | 高 | 独立滑移/位移通道 + 主动微抖动 + 时间积分损伤 + 跨模态对账 + 把"无尖峰"当待证伪命题 |
| 优化器贴边利用模型误差 | 高 | 包络边界缓冲 `η_env` + 鲁棒最坏情况 + 模型无关硬层 + 能量罐 + 滤波介入审计 |
| 无源能量罐只界能量不界峰值力 | 中高 | 能量上界与峰值力/冲量上界并用；硬件力熔断；CBF 仅在可信模型段启用 |
| 力阶梯过保守/探针成本高 | 中 | 信息/风险比选探针；证据可复用；保守管保底而非直接绕行 |
| 鲁棒 CTO 实时性 | 中低 | 降阶接触模型、包络预计算、warm-start、anytime 回退保守管 |
| 层级切换抖动/滞回不当 | 中低 | 只向保守方向瞬切、向宽松方向需滞回与证据、切换日志审计 |

## 7. 本轮最大风险

**一句话**：本轮把安全的赌注从"证据是否足够"换到"柔顺包络证书是否覆盖真实接触严重度"，而柔顺会**主动掩盖失效**（低刚度下慢滑移、蠕变、疲劳不产生明显力信号），轨迹优化又会把最优解推到包络边界——模型误差最大处；一旦严重度预测器在边界外推失效，系统会以"在包络内可证安全"的证书给出安静的、难以察觉的错误承诺，必须以模型无关的力/能量硬界、无源性能量罐、边界缓冲与跨模态滑移监测四重护栏，且力上限只能由已验证探针逐级抬升，绝不在未验证的力区间做轨迹优化。
