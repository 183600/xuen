# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「传感器标定」×「记忆检索」）

> R69 教会系统「问」，但它问完就忘——交互得到的证据只进入本轮的统计量，不进入可被将来调用的记忆。而 R68/R69 的「标定」（COF）始终是一个**在局部窗口里现算的估计器**：窗口一滑，历史归零，于是同一台传感器在不同时间被反复「从头猜」自己的偏差。更隐蔽的是，R68 的缓变故障之所以能被标定吸收，正因为标定没有记忆——它对「上周同一工况下这台传感器长什么样」一无所知。R69 的 FMA 虽用训练分布做第二意见，却仍是**无情景的先验**：它不知道「三小时前、同样 40°C、同样负载下」残差本来应该是多少。
>
> 本轮两个灵感正好补上两块缺失：
> - **传感器标定**给出「标定是一件有出处、有适用域、有有效期的事」——严格的标定从来不是重估一个数，而是**带上下文指纹、可溯源、可失效**的计量行为；
> - **记忆检索**给出「把过去的标定情景按当前上下文取回来用」的机制——但检索本身也会错、会被投毒、会取回过期权威。
>
> 核心命题：**把标定从「局部窗口估计」重构为「检索」。当前该用哪套标定，不由当下临时拟合决定，而由「在当前上下文下、从只追加的标定记忆里检索出的、带溯源与有效期的历史情景」共同决定；反过来，检索又必须依赖标定后的感知——二者互为条件，构成一个必须用不变量锚定才能切断的不动点。** 命名 **RECALL-RAS**（Retrieval-Enhanced Calibration And Lifelong memory for Risk-adaptive systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我上次在同样情形下是怎么标定的，那段记忆还作数吗**」——标定不只是当下的一次数值估计，更是一段可检索、可溯源、可失效的记忆。

## 0. 直觉与动机

**灵感 1（标定 = 溯源 + 有效期，而不是一次拟合）**
直觉：真正的计量标定必须记录：对哪台设备标、在什么条件下（温度/负载/安装/工况）、用什么基准（参考件 / 双通道自洽）、谁签的字（来源）、何时失效（期间核查 / 再标定）。R68 的 COF 把这些全丢了，只留一个滑窗里的校正映射 c。于是它无法回答「这个标定现在还算不算数」。把每条标定写成一条带上下文指纹、适用域、来源与有效期的**情景**，标定就从「估计问题」变成「检索 + 验证问题」。

**灵感 2（记忆检索 = 取对的情景，而不是最近的情景）**
直觉：人进熟悉房间会调用旧经验，而不会重新学一遍；但也不会把客厅经验硬套到厨房。检索的关键不是「最像」，而是「因果上相关且仍然有效」。朴素最近邻会把「看起来像、其实工况不同」的旧标定取来（相似性错觉），这正是 R69「幻影模态」在记忆维度的镜像——看起来分得清，其实分错了。

**灵感 3（标定与检索互为前提 → 不动点）**
直觉：要检索标定，得先知道当前上下文 φ（温度、负载、运动状态）；但要量准 φ，又得先有一套可用的标定 c。鸡生蛋：φ 依赖 c，c 依赖 φ。硬解会震荡或收敛到错误解。出路是找一个**对 c 不敏感的锚特征** φ⊥（差分比、结构关系、时间同步模式、物理守恒量），用它把循环切断，再用收缩条件保证交替迭代收敛；若收缩条件不成立，就承认「这段记忆不可用于此处」，退回无记忆的 R69。

**灵感 4（记忆是权威 → 权威会被洗白）**
直觉：一旦系统把「检索到的历史」当权威，攻击者只要污染历史就够了：投毒几条情景、或重放一段过期的真实情景，检索就会把它洗成「过去一直如此」，而后写的记忆又被它「印证」，形成自我强化。R69 的风险是「问错比不问更危险」；R70 的风险升级为「**记错比不记更危险**」——记忆会把一次错误固化成一类错误的先验，且因其可溯源而显得更可信。

**灵感 5（严格包含 → 无记忆是安全边界）**
直觉：若检索弃权（无适用情景、或不变量锚定失败、或覆盖不足），RECALL 必须逐指令退化为 R69；R69 再在 VoI≤成本时退化为 R68。这样记忆是**纯增量收益**：有干净记忆时更快更准，没记忆或记忆不可信时不比今天差。这是本轮不可让步的安全姿态，也是与「并列新增一层黑箱」的根本区别。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（RECALL-RAS 总览）** RECALL-RAS = (CEM, CRA, RCC, CDP, MBH, MPG, RAS-WM‡)。三不变式：
(i) **实时读路径只读**：继承 R69 定义 293-i，实时环不写记忆、不学习；记忆写入只在慢路径异步进行；
(ii) **记忆不可变与溯源**：标定记忆只追加、哈希链，每条情景带上下文指纹、来源、适用域、有效期；删除只能打墓碑（tombstone），不得物理抹去审计副本；
(iii) **检索弃权纪律**：只有当前上下文落在某情景适用域内、且至少 k 条独立来源一致时允许检索；否则弃权并退化为 R69。

**定义 311（标定情景 CEM）** 一条情景 e_i = (φ_i, c_i, R_i, π_i, V_i, a_i, t_i^e, t_i^r, h_i)：上下文指纹 φ_i ∈ Φ、标定映射 c_i、参考残差分布 R_i（经验分位）、来源 π_i（基准类型 + 佐证集合）、适用域 V_i ⊆ Φ、来源信任 a_i、事件时刻 t_i^e 与记录时刻 t_i^r、内容哈希 h_i。记忆 M = {e_i}，按 h_i 串成哈希链，只追加。

**定义 312（上下文指纹与不变量锚）** φ = Φ_φ(o_t, ctx) 含工况（温度、负载、安装位姿、运动 regime、单元 ID）。其中必须显式分离出**标定不变量子空间** φ⊥ ⊆ φ：其分量对校正映射 c 的一阶导为零（如差分比值、结构关系、同步相位、守恒量残差），用于切断定义 315 的互锁；其余分量记 φ_c（依赖标定）。检索度量只在 φ⊥ 上无条件可用。

**定义 313（因果检索度量 CRA）** d_R(φ_t, φ_i) = Σ_{j∈C} (φ_tj − φ_ij)² / s_j² + λ_V·dist(φ_t, V_i)，其中 C 为经干预/后门调整验证「对残差有因果影响」的维度集合（非全部嵌入维度），s_j 为尺度，dist 为到适用域边界的距离。检索集 N_k(φ_t) = top-k under d_R，且只保留 φ_t ∈ V_i 且 a_i 达标者。**弃权条件**：|N_k| < k_min 或 k_eff（有效样本量）< k_min。

**定义 314（检索条件共形校准 RCC）** 权重 w_i ∝ exp(−d_R(φ_t,φ_i)/τ)·a_i·fresh_i（fresh 见定义 320）。对残差 r 的加权共形分位 q̂_{1−α} = 加权 ⌈(k_eff+1)(1−α)⌉ 分位。这是把 R68 的「局部滑窗」替换为「工况对齐的历史情景」；当 w≡1、N_k 退化为最近窗口时，逐点等于 R68 的共形校准。

**定义 315（标定-检索互锁 CDP）** 交替映射 T：(c, φ) ↦ (T_c(φ), T_φ(c))，T_c 用检索情景聚合出 c，T_φ 用 c 校正后重算 φ_c。不变量锚使 T_φ 在 φ⊥ 上不依赖 c。收缩常数 κ = L_c L_φ（在 φ_c 子空间）。κ < 1 ⇒ 唯一不动点、交替迭代线性收敛；κ ≥ 1 或迭代超预算 ⇒ 判「互锁不可解」，检索弃权，退 R69。

**定义 316（记忆条件残差 / memory-surprise MSA）** Δ_m = |r_obs − r_ref(N_k)|，r_ref 为检索情景 R_i 的加权参考残差。Δ_m 高而检索情景名义上有效 ⇒ 要么真漂移、要么记忆已陈旧；再用「上下文是否已越出 V_i」与「溯源审计是否通过」区分（定义 317/319）。这是 R69 FMA 的 Δa 从「训练先验」升级为「情景先验」的版本。

**定义 317（记忆卫生 MBH）** 失效触发：φ_t 越出 V_i、期间核查失败、传感器换装、被后续情景 supersede。处置：打墓碑并保留审计副本；旧情景被新情景遮影（shadow）但不清除。区分 **stale（按有效期合法过期）** 与 **poisoned（来源/佐证不合格，从未有效）**：前者降权，后者隔离并追责来源。

**定义 318（记忆写入纪律 MPG）** 写入须满足：k 个正交佐证源（多信号、多时刻、多参考件）一致，进入隔离期，附来源哈希；**禁止单源写入**。检索信任权重含来源项 a_i；对记忆层的投毒上界沿用 R69 引理 18 的 k-一致结构，只是把「单次问答」换成「单条情景」。

**定义 319（记忆投毒与洗白威胁）** ℰ_mem = {投毒情景（伪造 c/R/V）、重放（把过期真实情景当现行）、陈旧权威（valid 但早已不适用）、溯源伪造、相似性投毒（对抗性 φ 强行命中检索）}。并入 AIC-RECALL：ℰ_RECALL = ℰ_FLUID × ℰ_mem。

**定义 320（双时间与新鲜度）** 每条情景带事件时刻 t^e 与记录时刻 t^r；fresh_i = f(t^e, V_i, 失效事件)。检索权重随 fresh 单调衰减；「valid 但老」只降权不删除，「poisoned」直接隔离。防止「新记录+旧事实」被误当新鲜。

**定义 321（证书 J_RECALL）** J_RECALL = (J_FLUID, retrieval_coverage, conformal_coverage_est, q̂_{1−α}, invariant_anchor_ok, κ_est, memory_hash_root, poison_rate_upper, stale_ratio, recall_ver)。Valid ⇔ Valid(J_FLUID) ∧ 检索覆盖 ≥ 门槛 ∧ κ_est < 1（或已弃权） ∧ 溯源审计通过 ∧ 无单源写入。

**定义 322（三级保守退避）** 检索弃权 / 互锁不可解 / 覆盖不足 ⇒ 逐指令退化为 R69；R69 在 VoI(g*) ≤ c(g*) 时退化为 R68。即 R68 ⊂ R69 ⊂ R70，安全侧永不更弱。

**定义 323（记忆-标定对偶审计 VQAuditor-M）** 审计：检索是否被因果论证支持、记忆来源是否合法、有无单源写入、有无陈旧权威被当成现行、离线留出情景上的共形覆盖率是否达标。结论回灌记忆信任与检索策略（形成审计闭环，但不改动历史内容）。

**定义 324（自适应检索预算）** 默认不检索（纯 R69）：当上下文 in-distribution 且 memory-surprise 正常时直接沿用当前在线标定。仅当残差异常（Δ_m 高）、上下文新颖、或 R69 进入歧义路径时触发检索；k 与候选上限受 P99 约束。

**定义 325（跨实体迁移标定）** 允许从因果等价的其他单元/部署（车队记忆）检索情景，迁移权重由 φ⊥ 上的不变量一致性决定；用于冷启动与少样本再标定。负迁移由适用域门与不变锚约束上界。

**定义 326（遗忘-保留权衡）** 检索用有界工作集（coreset / 摘要）以守时延；审计用不可变全量记忆以守可追溯。遗忘只影响「检索得到什么」，不影响「事后能查什么」。

## 2. 关键算法骨架

```python
# IP-264 CEM：只追加、哈希链的标定情景记忆
class CalibrationEpisodicMemory:
    def __init__(self, index):
        self.episodes, self.chain, self.index = {}, [], index   # index: HNSW on phi_inv
    def append(self, e):                                        # 仅慢路径调用
        assert e.provenance.multi_source_ok and e.hash == h(e)
        self.chain.append(e.hash); self.episodes[e.hash] = e
        self.index.add(e.phi_inv, e.hash)
    def tombstone(self, h, why):                               # 不删除，只标记
        self.episodes[h].valid = False; self.episodes[h].why = why

# IP-265 CRA：因果掩码检索 + 弃权门
def retrieve_episodes(mem, phi_t, k=8, k_min=2):
    cand = mem.index.search(phi_t.inv, k=2*k)                  # 先在不变量子空间召回
    adm  = [e for e in cand if inside(e.V, phi_t) and e.provenance.ok]
    adm  = sorted(adm, key=lambda e: causal_dist(phi_t, e))[:k]
    if len(adm) < k_min or effective_size(adm) < k_min: return None   # 弃权
    return adm

# IP-266 RCC：检索条件加权共形校准
def retrieval_conformal(adm, phi_t, r_obs, alpha=0.05):
    w  = softmax([-causal_dist(phi_t, e)/TAU for e in adm]
                 * [e.trust * freshness(e) for e in adm])
    q  = weighted_quantile([e.residual for e in adm], w, 1-alpha)
    return q, coverage_estimate(adm, w)                        # q 低于残差 => 异常

# IP-267 CDP：标定-检索互锁的交替不动点（锚定后收缩）
def co_calibrate(mem, phi_t, max_it=2):
    c, phi = None, phi_t
    for _ in range(max_it):
        adm = retrieve_episodes(mem, phi)
        if adm is None: return None, None, "abstain"           # 不可解 => R69
        c_new = aggregate_calibration(adm)
        phi_c = recalibrate_context(phi, c_new)               # 只在 phi_c 上更新
        if phi_c == phi and c_new == c: break
        c, phi = c_new, phi_c
    kappa = estimate_contraction(phi_t)                        # 引理 20
    return (c, phi, "ok") if kappa < 1 else (None, None, "abstain")

# IP-268 MBH：记忆卫生（失效/遮影/墓碑）
def hygiene(mem, phi_t, audit):
    for e in mem.episodes.values():
        if not inside(e.V, phi_t) or audit.recheck_failed(e) or sensor_swapped(e):
            mem.tombstone(e.hash, "stale" if e.was_valid else "poisoned")
    # 新情景只遮影旧情景，旧情景保留供审计

# IP-270 MSA：情景先验第二意见（推广 R69 的 FMA）
def memory_surprise(adm, r_obs):
    return abs(r_obs - weighted_mean([e.residual for e in adm]))

# IP-274 主闭环（继承 R69；检索只在异常/新颖时触发）
def RECALL_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c0, U_cal, thr = M.cof.step(...)      # R69 在线标定
    trig = M.cra.should_retrieve(obs, M.last_delta_m, M.last_r_res)   # 定义 324
    if not trig:
        return M.fluid_round(obs)                                     # 退化 R69
    c, phi, status = M.cdp.co_calibrate(M.cem, obs.phi_t)
    if status == "abstain":
        return M.fluid_round(obs)                                     # 互锁不可解 => R69
    adm = M.cra.retrieve(M.cem, phi)
    q, cov = M.rcc.retrieval_conformal(adm, phi, obs.r)
    delta_m = M.msa.memory_surprise(adm, obs.r)
    stale_or_poison = (delta_m > TAU_M) and not M.mbh.explainable(adm, phi)
    if stale_or_poison:
        M.mbh.quarantine(adm); return M.fluid_round(obs)             # 记忆不可信 => R69 保守
    # 记忆可信：用检索先验替换在线标定，其余走 R69（VoI/交互/风险缩放不变）
    out = M.fluid_round(obs, calib_override=(c, q, cov))
    M.vqa_m.submit_async(adm, delta_m, cov, M.cem.chain_root)        # 定义 323
    return out
```

## 3. 推导

**引理 19（检索条件加权共形的覆盖）** 设检索集 N_k 与当前情景满足加权可交换性（测试/记忆分布比 w(x) 已知，或权重估计误差 ≤ δ_w），则对残差 r 的加权共形分位 q̂ 满足 P(r ≤ q̂) ≥ 1 − α − Δ_w，其中 Δ_w 随 δ_w 与有效样本量 k_eff 增大而减小。要点：R68 的局部滑窗恰是 k=窗口长度、w≡1 的退化共形；RECALL 把「时间上连续但工况混杂」的窗口换成「工况对齐但时间分散」的情景，在非平稳下提高了有效样本的**相关性**。但覆盖率保证只在加权可交换性成立时有效——这正是弃权门（定义 313）的统计含义：取到不满足可交换性的情景，覆盖率保证立即失效。

**引理 20（标定-检索互锁的收缩）** 设交替映射的两支 Lipschitz 常数分别为 L_c、L_φ，则 κ = L_c L_φ < 1 时存在唯一不动点且交替迭代线性收敛；若检索以锚特征 φ⊥ 为条件（∂d_R/∂c = 0），则在该子空间 κ = 0，互锁被切断；κ ≥ 1 时迭代可能振荡或收敛到错误标定，必须判「不可解」并弃权。系：**「能不能用这段记忆」本身是一个可判定的稳定性问题，而不是一个凭信心下注的问题**。

**引理 21（记忆洗白的稀释上界）** 写入需 k 个正交来源一致、各来源被污染概率 p、来源间相关 ρ<1，则检索集中被污染情景在权威加权后的有效比例 ≤ p·ρ^{k−1} + ε_σ（ε_σ 为统计波动）。若允许单源写入，比例退化为 p，且后写记忆可反向「印证」污染源（洗白），错误不可逆。系：记忆纪律必须比交互纪律更严——交互错的是一条证据，记忆错的是整类先验。

**定理 18（RECALL 严格包含 R69 与 R68）** 在 A99–A102 下，RECALL 任意状态期望风险 ≤ R69；且当检索弃权、记忆为空、互锁不可解或溯源审计失败时，与 R69 **逐指令相同**；R69 再在 VoI(g*) ≤ c(g*) 时退化为 R68。故 R68 ⊂ R69 ⊂ R70：记忆只在有干净增量信息时生效，安全侧不做任何让步。

**定理 19（记忆失效下的安全与无突变）** 陈旧/投毒经 memory-surprise（定义 316）与溯源审计（定义 323）可检；检出后 λ 单调不降地退回 R69 的保守层；记忆读路径只读、写入异步，故控制连续、无突变（继承 R68 定理 15、R69 定理 17）。匹配与换装不变式保持。

**假设 A99–A102** A99：残差在 φ⊥ 的等价类内加权可交换；A100：存在对校正映射一阶不敏感的锚特征 φ⊥；A101：交替映射在 φ_c 子空间 Lipschitz，常数可在线估计上界；A102：记忆写入的正交来源在攻击下相关性 ρ<1。

## 6. 本轮最大风险

**一句话**：RECALL-RAS 把「标定的权威」外包给了记忆，却没有任何一条**外部锚**能保证记忆本身是干净的——一旦记忆被投毒或固执陈旧，检索会把「过去曾如此」洗成「现在也如此」，而标定-检索互锁还会把这个错误锁进感知，系统于是**比完全没有记忆时更自信地错**。

**次级风险与缓解**：
1. **记忆洗白/投毒** → k-正交来源写入 + 引理 21 稀释界 + ℰ_mem 对抗训练；
2. **陈旧权威** → 双时间 + 失效触发 + memory-surprise，valid-but-stale 只降权；
3. **相似性投毒强行命中** → 因果掩码度量 + 适用域门 + 弃权纪律；
4. **互锁发散/错误收敛** → 不变量锚 + κ 在线估计 + κ≥1 即弃权回 R69；
5. **记忆无限增长击穿时延** → 有界工作集 + 摘要 + 异步写入，审计副本不可变；
6. **负迁移** → φ⊥ 一致性加权 + 适用域约束，越界即不迁移。

class CalibrationEpisodicMemory:
    def append(self, e):                                   # 仅慢路径
        assert e.provenance.multi_source_ok and e.hash == h(e)
        self.chain.append(e.hash); self.episodes[e.hash] = e

    def tombstone(self, h, why):                           # 不删除，只标记

# IP-265 CRA：因果掩码检索 + 弃权门
def retrieve_episodes(mem, phi_t, k=8, k_min=2):
    cand = mem.index.search(phi_t.inv, k=2*k)
    adm  = sorted([e for e in cand if inside(e.V, phi_t) and e.provenance.ok],
                  key=lambda e: causal_dist(phi_t, e))[:k]
    return None if len(adm) < k_min or effective_size(adm) < k_min else adm

# IP-266 RCC：检索条件加权共形校准
def retrieval_conformal(adm, phi_t, alpha=0.05):
    w = softmax([-causal_dist(phi_t, e)/TAU * e.trust * freshness(e) for e in adm])
    return weighted_quantile([e.residual for e in adm], w, 1-alpha)

# IP-267 CDP：标定-检索互锁，锚定后收缩
def co_calibrate(mem, phi_t, max_it=2):
    c, phi = None, phi_t
    for _ in range(max_it):
        adm = retrieve_episodes(mem, phi)
        if adm is None: return None, None, "abstain"
        c_new = aggregate_calibration(adm)
        phi = recalibrate_context(phi, c_new)              # 仅更新 phi_c
        if c_new == c: break
        c = c_new
    return (c, phi, "ok") if estimate_contraction(phi_t) < 1 else (None, None, "abstain")

# IP-268 MBH：记忆卫生（失效/遮影/墓碑）
def hygiene(mem, phi_t, audit):
    for e in mem.episodes.values():
        if not inside(e.V, phi_t) or audit.recheck_failed(e) or sensor_swapped(e):
            mem.tombstone(e.hash, "stale" if e.was_valid else "poisoned")

## 4. 推导

**引理 19（检索条件共形覆盖）** 加权可交换性成立、权重误差 ≤ δ_w 时，`P(r≤q̂) ≥ 1−α−Δ_w`，Δ_w 随 δ_w、k_eff 增大而减小。R68 滑窗 = `w≡1` 的退化共形；RECALL 用「工况对齐、时间分散」替代「时间连续、工况混杂」，非平稳下提高有效相关性——但保证仅在弃权门筛掉不可交换情景后成立。

**引理 20（互锁收缩）** 交替映射 κ=L_c L_φ<1 时唯一不动点、线性收敛；锚 φ⊥ 使子空间 κ=0，切断循环；κ≥1 可能振荡或错收敛，须判「不可解」并弃权。系：能否用这段记忆是可判定的稳定性问题，而非凭信心下注。

**引理 21（记忆洗白稀释）** k 正交来源、污染率 p、相关 ρ<1 ⇒ 检索集加权后污染有效比例 ≤ `p·ρ^{k−1}+ε_σ`；允许单源写入则退化为 p，且后写记忆可反向印证污染源（洗白）。系：记忆纪律须严于交互纪律——交互错的是一条证据，记忆错的是整类先验。

**定理 18（严格包含 R69/R68）** A99–A102 下 RECALL 期望风险 ≤ R69；检索弃权/记忆为空/互锁不可解/审计失败时与 R69 逐指令相同；R69 在 `VoI≤c` 时退化为 R68。故 R68 ⊂ R69 ⊂ R70，安全不让步。

**定理 19（记忆失效下安全与无突变）** 陈旧/投毒经 memory-surprise + 溯源审计可检；检出后 λ 单调不降退回 R69；读路径只读、写入异步 ⇒ 控制连续、无突变；匹配/换装不变式保持。

## 7. 本轮最大风险

**一句话**：RECALL-RAS 把「标定的权威」外包给了记忆，却没有任何**外部锚**能保证记忆本身是干净的——一旦记忆被投毒或固执陈旧，检索会把「过去曾如此」洗成「现在也如此」，标定-检索互锁还会把这个错误锁进感知，系统于是**比完全没有记忆时更自信地错**。

**次级风险与缓解**：记忆洗白/投毒（k-正交来源 + 引理 21 + ℰ_mem 对抗训练）；陈旧权威（双时间 + 失效触发 + memory-surprise，valid-but-stale 只降权）；相似性投毒（因果掩码 + 适用域门 + 弃权）；互锁发散/错收敛（不变量锚 + κ 在线估计，κ≥1 即弃权回 R69）；记忆增长击穿时延（有界工作集 + 摘要 + 异步写入，审计副本不可变）；负迁移（φ⊥ 一致性加权 + 适用域约束）。
