# 第 11 轮（新灵感循环第 2 轮；本轮灵感：「可扩展性」×「实例分割」）
> **基线**：第 10 轮 MetricVoiceGauge-NCD（定义 540–553；引理 87–95；实验 E571–E588）。
> 本轮纪律：**实例为原子 + 证书代数 + 可扩展契约**。不推倒 v10：NGE/DSL/CC/CWM/CAE/NCP 与九不变式全部保留；新组件一律以**中立元**接入，失效即严格退回 v10（引理 102），再沿 v10 九级链退回 v9/v8/v7/v6。本轮只做两件事：把"实例"提升为证书、规范、归因的最小单元；让整条管线对实例数、规范数、模块数、机器人数呈**可证明的近线性伸缩**，且在算力不足时**降低精度而不降低安全性**。

## 0. 直觉与动机

**灵感 1（实例分割 → 实例是证书的原子）**
直觉：v10 的块证书是"**整场景一个代数式**"，但真实失败总是**有对象的**：某只杯子滑、某个人的个人空间被侵犯、某一对被遮挡的物体其实在接触。实例分割 + 多目标跟踪给出带身份的掩码 M_i，于是可以把 v10 的 (Ĉ_safety, Ĉ_contact, Ĉ_norm) **按实例分解**：每个物体/人各持一份局部证书，块证书由"一元实例证书 ⊗ 稀疏交互证书"拼装。更关键的是，分割本身也会错（掩码渗出、身份跳变、严重遮挡），所以必须给证书再发一张**分割证书 Ĉ_seg**（IoU 下界、边界不确定带、身份跳变概率、遮挡标记），并利用局部证书在重叠区的**粘合残差**反过来检测关联错误。实例分割在这里既是**被保护的输入**，也是**自我校验的信号**——不是又加一个感知前端，而是让感知误差成为证书里可计量的一项。

**灵感 2（可扩展性 → 证书代数与 anytime 保真度）**
直觉：v10 的成本 O(n_cand·|N_H|·K + n·K·|S*|) 隐含假设"实例数、规范数、模块数都是常数"。真实部署会同时放大四件事：N 个实例、|N| 条规范、M 个模块、R 台机器人；朴素实现是 O(N²)（每对实例都重算交互）与 O(n_cand·N)（每个候选都扫全场景），预算立刻爆。核心创新：**证书代数（Certificate Algebra, CA）** + **交互图局部性**，让成本变成 O(N + E_int)（E_int 由空间局部性约束，近线性）；再加**anytime 保真度阶梯**，算力紧张时用更保守的低保真证书——**只丢完备性、不丢可靠性**。可扩展性不是"更快地不安全"，而是"在任意预算下都可证安全，只是更保守"。

**灵感 3（二者合流 → 实例级因果单元）**
直觉：v10 的最大风险是未观测 H 同时污染规范信念与因果模型。实例分割 + 跟踪恰好创造了**面板数据**：同一个实例 id 被反复观测、反复参与随机化激活/技能选择，于是可做**实例内差分（固定效应）**，把 H 中"随时间不变的实例级成分"（这个人一贯的偏好、这个物体的固有摩擦）消掉，只剩时变成分需要敏感性界。可扩展性则要求归因抽样随实例数增长仍保持有界方差：分层抽样 + 每实例配对，样本复杂度对精度是 O(1/ε²)，而不是随 N 线性膨胀。

**三者如何统一**
**实例是证书的原子，可扩展性就是证书代数的结构性（局部性 + 单调保真度）**。规范按人实例路由，接触按物体对索引，归因按实例 id 配对；证书在这些单元上满足交换/结合律与单调性，所以增加实例只是"多算几个局部分量、多算稀疏交互项"，而不是"全局重算"。一句话：**实例回答"对谁负责"，可扩展性回答"加更多人/物/机器之后还证不证得起"**。

## 1. 研究问题（轮次升级版）

- **Q1（实例分解的可靠性）**：如何把 v10 的块证书正确分解为实例证书与稀疏交互证书，并证明"局部证书有效 + 交互证书有效 ⇒ 全局证书有效"，同时把掩码误差与身份跳变计入证明？
- **Q2（可扩展的证书计算）**：实例数、规范数、模块数、机器人数同时增长时，证书/规范盾/归因的成本能否保持近线性，且交互图局部性的前提可在线检验、违反时可回退？
- **Q3（任意预算下的安全）**：算力不足以算完全部证书时，如何用 anytime 保真度阶梯保证"仍然可靠、只是更保守"，并把误拒率—预算曲线量化？
- **Q4（实例级因果与混杂）**：实例面板数据能在多大程度上消解 v10 的未观测 H？残余时变混杂如何界定，何时禁止据此休眠/迁移？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 实例原子律（Instance Atom）**
证书、规范、归因的最小单元是带身份的实例 i；一切"场景级"量都必须能写成实例一元项与稀疏交互项的合成。禁止存在只能"整场景重算"的证书；若某谓词无法分解，必须显式落入一个小型交互超边，而不是退回全局。

**P17 证书代数与局部性律（Certificate Algebra & Locality）**
证书按 (⊗ 合取, ⊕ 选择) 构成代数，余量满足次可加；只有当两实例进入交互邻域 r_int 或共享接触/支撑时才需要交互证书。交互图度数必须在线估计；度数超界时退化为更保守的联合证书并报告，而不是静默忽略交互项。

**P18 单调保真度律（Anytime Scalability）**
每个证书有保真度 l∈{0..L}，越粗越保守（接受集随 l 单调扩大），成本随 l 单调递增。预算不足时只能降低 l、增大裕度、缩小候选集，**不能跳过证书或篡改证书判据**。

## 3. 与基线的接口（如何退化）

- 交互图局部性失效（度数超界或关联不可信）⇒ 退化为**整场景联合证书**，等价 v10 单证书路径（S-1）；
- 实例分解失效（分割/跟踪不可用）⇒ 注入**单伪实例**中立元（N=1 覆盖全场景），等价 v10（S-2）；
- anytime 失效 ⇒ 固定 l=L，等价 v10 固定预算路径（S-3）；
- 三者全失效 ⇒ MetricVoiceGauge-NCD v10，再沿 v10 九级链退回 v9/v8/v7/v6；
- **安全继承**：交互项只能增加约束、不能删；粘合残差只能触发保守化或重分割、不能放行；保真度只能降精度、不能降判据（引理 105）。

## 4. 预期贡献

1. **实例分解证书代数**：一元实例证书 + 稀疏交互证书 + 分割证书，给出可证明的合成可靠性与分割误差传播界；
2. **近线性的证书/规范/归因计算**：交互图局部性、度数界、按实例路由规范、分层抽样归因，把 O(N²) 降到 O(N+E_int)；
3. **anytime 安全伸缩**：保真度阶梯下的"可靠但不完备"证书，量化误拒—预算曲线，并证明扩容只增保守；
4. **实例面板因果**：用实例内差分消解 H 的时间不变成分，给出残余时变混杂的敏感性界；
5. **实验 E589–E606**：分割/关联质量、合成可靠性、伸缩曲线、anytime、面板归因、多机聚合、端到端。

## 5. 本轮最大风险

**一句话**：证书代数的全部可靠性都建立在"实例关联正确"之上；一旦掩码渗出或身份跳变把两个相互作用的实例判成一个（或把一个判成两个），局部性前提失效、交互项被静默漏掉，系统会以近线性的吞吐输出一个**看似可扩展、实则漏掉相互作用**的虚假安全证书。

> 本轮灵感：「可扩展性」×「实例分割」
> **继承纪律**：MetricVoiceGauge 九不变式（CVC-闭环、SpatialCert、RT-CVC、FaultCert、PrimitiveGraph、严格退化链、OTL、GCT、ER）全部保留；v10 的 NGE/DSL/CC/CWM/CAE/NCP 与 v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 原样保留。新组件均为**可选增强**：任一不可用 ⇒ 注入中立元，严格等价退回 v10（引理 102），再沿 v10 九级链退回 v9/v8/v7/v6。

**定义 554（实例假设 Instance Hypothesis）** 由实例分割器与跟踪器给出实例假设集 𝕀_t={i}，i=(id_i,M_i,c_i,T_i,o_i)。M_i⊂Ω 为掩码（含边界不确定带），c_i 为类别/部件，T_i∈SE(3) 为位姿，o_i 为遮挡/amodal 标记。关联后验 m_i=P(i 与真实物体一一对应|观测)，关联错误率 δ_seg,i=1−m_i。

**定义 555（分割证书 Segmentation Certificate）**
```
Ĉ_seg,i = (IoU_lo,i, b_i, δ_seg,i, o_i, ρ_glue,i)
```
其中 IoU_lo,i 为 IoU 的下置信界，b_i 为边界不确定带宽（像素或米），ρ_glue,i 为定义 566 的粘合残差。若实例进入执行相关区域，Ĉ_seg,i 有效 ⇔ δ_seg,i≤ε_id ∧ IoU_lo,i≥ι_min ∧ b_i≤b_max；否则记"未标定"。Ĉ_seg 是"证书的证书"：它界定"把 i 当作一个整体来发证书"是否可靠。

**定义 556（实例证书 Instance Certificate）** 对实例 i：
```
Ĉ_i = (Ĉ_safety,i, Ĉ_contact,i, Ĉ_norm,i, Ĉ_seg,i, P_i)
```
四个分量分别是 v10 定义 533/547/543/555 的按实例切片；P_i 为该实例相关的接触安全中止点集。若 i 只被人规范约束，Ĉ_safety,i 与 Ĉ_contact,i 取平凡真。实例证书有效 ⇔ 四分量均有效。

**定义 557（交互证书 Interaction Certificate）** 对交互超边 e⊆𝕀（通常 |e|=2），
```
Ĉ_e = (ĝ_e, n̂_e, f̂_e^⊥, ŝ_e, β_int,e)
```
分别覆盖相对位姿/间隙 g_e、接触法向 n_e、法向力 f_e^⊥、共享支撑稳定性 s_e，以及该超边的交互余量。只有 e 上才有定义的谓词（接触、支撑、相对朝向、联合占位）必须放进交互证书，禁止摊到某个一元项里。

**定义 558（证书代数 Certificate Algebra）** 证书域 (𝒞,⊗,⊕,⊥,⊤)：⊗ 为合取合成，⊕ 为候选选择，⊥ 为矛盾（不可执行），⊤ 为真空真（中立元）。**可靠性**：若 Ĉ 有效且 Pred(Ĉ) 为真，则底层安全谓词成立。**余量次可加**：β_{A⊗B}≤β_A+β_B+β_int(A,B)，其中无交互证据时 β_int 取保守上界 β_int^max。合成必须满足交换律与结合律；不满足时说明前提（关联/分解）有问题，必须报错而非强行合成。多机情形下 ⊗ 亦为交换含幺半群，支持定义 568 的分布式聚合。

**定义 559（交互图与块证书装配）** 交互图 G_int(t)=(𝕀_t,E_t)：{i,j}∈E_t 当 dist(M_i,M_j)≤r_int 或共享接触/支撑。块触及实例集 𝕀_chunk 与交互边集 E_chunk 由块的技能轨迹与实例掩码相交确定。块证书：
```
Ĉ_chunk = ( ⊗_{i∈𝕀_chunk} Ĉ_i ) ⊗ ( ⊗_{e∈E_chunk} Ĉ_e )
```
**局部性前提**：i∉𝕀_chunk 且与 𝕀_chunk 无边 ⇒ 其对 Ĉ_chunk 无贡献（由物理分离保证）。

**定义 560（实例规范路由 Instance Norm Routing）** 规范 ν 绑定人类实例集合 H_ν。对候选块 ξ：
```
R_ν(ξ|b) = Σ_{h∈H_ν∩𝕀_touch(ξ)} b_{ν,h}·σ(−ρ_{ν,h}(ξ)/s_ν) + R_ν^{rel}(ξ|b)
```
其中 ρ_{ν,h} 只涉及人实例 h 的 deontic-STL 鲁棒度；R_ν^{rel} 为不可分离的关系型规范（轮流顺序、联合递物、多人共同在场），由定义 557 的小超边承载。于是规范盾成本随 |𝕀_touch| 而非 |𝕀_t| 增长。

**定义 561（保真度阶梯与单调保守性）** 证书保真度 l∈{0..L} 由掩码分辨率、接触模型阶数、STL 采样密度、rollout 步长共同决定：
- 接受集单调：l'<l ⇒ V(l')⊆V(l)（越粗越保守、误拒越多）；
- 成本单调：c(l) 随 l 不减；
- 可靠性：任意 l 的证书都满足定义 558 的可靠性（保真度只影响完备性，不影响可靠性）。

**定义 562（可扩展成本契约 Scalability Contract）** 记 N=|𝕀_t|、E=|E_t|、|N| 规范数、M 模块数、R 机器人数、n_cand 候选数、S 抽样实例数。契约要求：
```
Cost_cert = O( Σ_{i∈𝕀_touch} c_i(l) + Σ_{e∈E_touch} c_e(l) )
Cost_norm = O( |𝕀_touch|·|N_touch|·K )
Cost_attr = O( S·c_sample ),  Var ≤ σ²/S·(1+ρ)
```
并要求 E_touch≤κ_d·N 在"最小间距或有限堆积数"成立时；若前提失效，定义 559 退化为度数 d_max 的联合证书并报告前提违反（S-1）。

**定义 563（实例因果单元与面板估计）** 对模块/技能 m，实例 i 在多个回合 τ 被观测：Y_{i,τ}(do(A_m=a))。实例内差分（固定效应）估计：
```
ACE_m^FE = (1/|𝕀|) Σ_i [ (1/T_i) Σ_τ Y_{i,τ}|do(A_m=1)
                        − (1/T_i) Σ_τ Y_{i,τ}|do(A_m=0) ]
```
它消去任意只随 i 变化的混杂 H_i，例如"某人的固有规范偏好""某物体的固有摩擦"。

**定义 564（时变混杂与残余敏感性界）** 分解 H=H_i+H_{i,τ}。ACE_m^FE 消去 H_i；对 H_{i,τ} 报告面板敏感性界 B_Γ^panel。**可识别性标签**：只有当 ACE_m^FE 的下置信界仍高于休眠阈值 τ_off 才允许迁移到 dormant；否则禁止据此休眠（继承 v10 引理 92 的保守规则）。

**定义 565（实例抽样归因 Stratefied Instance Sampling）** 在预算 S 下按 (类别 × 交互度数 × 不确定性) 分层抽样实例，每实例内做 do/not-do 配对。估计量方差 Var≤σ²/S·(1+ρ)，ρ 为分层内相关。S 由精度 ε 决定而与 N 解耦，故归因成本可扩展（IPCAE+SAS）。

**定义 566（粘合一致性 Glue Consistency）** 对重叠区 Ω_{ij}=M_i∩M_j，局部证书对同一物理量（质量、位姿、占有）给出区间 [a_i,b_i]、[a_j,b_j]。粘合残差
```
ρ_glue = max(0, a_i−b_j, b_i−a_j, a_j−b_i)
```
若 ρ_glue>ε_glue 则判定关联/掩码不一致，触发重分割或保守化（增裕度/降 l），**不得继续合成**。无重叠区时用交互证书的间隙符号一致性（g_e 的符号与掩码间隙符号）作弱校验。

**定义 567（实例分解目标 Objective）** 对候选 ζ：
```
J(ζ|s,b) = Σ_{i∈𝕀_chunk} J_i(ζ_i|b) + Σ_{e∈E_chunk} J_e(ζ_e)
subject to  ∀i: Ĉ_i valid ∧ ∀e: Ĉ_e valid
          ∧ 规范路由满足（定义 560）
          ∧ ρ_glue≤ε_glue（定义 566）
          ∧ u_c≤ε_u（v10 定义 552）
```
可行集为空 ⇒ a_ask（v10 定义 544）。若因预算不足可行集为空，先按定义 561 降 l 重试，仍空才 a_ask。

**定义 568（中立元与分布式聚合 Neutral Element）**

| 新组件 | v^⊥ | 等价退化点 |
|---|---|---|
| IFC/CA 实例分解 | 单伪实例 𝕀={scene}，G_int 无边，π{scene}=v10 单证书 | S-2（v10） |
| IGM 局部性 | 全场景联合证书（度数视为 N−1） | S-1（v10） |
| ACS 保真度 | l≡L 固定 | S-3（v10） |
| INR 路由 | H_ν∩𝕀_touch 取全体，退化为 v10 全局盾 | v10 定义 543 |
| IPCAE/SAS 归因 | ACE^FE←v10 CAE 的 ACE_m | v10 定义 550 |
| NGE/DSL/CC/CWM/CAE/NCP | 沿用 v10 定义 553 | Level-1…8 |

**分布式聚合（多机）**：设机器人 r 持有不相交实例证书与跨机交互边 E_cross，⊗ 交换结合 ⇒ 全局证书 = ⊗_r Ĉ^{(r)} ⊗ ⊗_{e∈E_cross} Ĉ_e，结果与集中式一致；禁止因通信缺失而隐式删去跨机边（缺失即 fail-closed，降 l 或停）。

# IP-363/364/365 InstanceFactoredCertifier + CertificateAlgebra + InteractionGraphManager
class CertificateAlgebra:
    TOP, BOT = True, False
    def mul(self, A, B, beta_int=0.0):
        assert A and B
        return Cert(claims=A.claims + B.claims,
                    beta=A.beta + B.beta + beta_int)
    def select(self, cands):
        return [c for c in cands if c is not self.BOT]


class InstanceFactoredCertifier:
    def __init__(self, seg, tracker, ca, gcc, r_int, l_max, budget):
        self.seg, self.tracker, self.ca, self.gcc = seg, tracker, ca, gcc
        self.r_int, self.l_max, self.budget = r_int, l_max, budget
        self.cache = {}                      # 增量：按 id_i + 版本号缓存

    def update_instances(self, frame):
        hyp = self.seg.infer(frame, fidelity=self.l)     # masks/classes/scores
        inst = self.tracker.associate(hyp)               # ids, m_i, delta_seg
        return inst

    def instance_cert(self, i, state):
        key = (i.id, i.version)
        if key in self.cache:                # 局部性：未变的实例直接复用
            return self.cache[key]
        c = Cert(physical=v10_physical_slice(i, state),
                 contact=v10_contact_slice(i, state),
                 norm=InstanceNormRouter.slice(i, state),
                 seg=SegCert(i.iou_lo, i.band, i.delta_seg, i.occlusion, 0.0),
                 P_i=contact_abort_points(i, state))
        self.cache[key] = c
        return c

    def edges(self, I):
        E = []
        for i, j in local_pairs(I, self.r_int):          # 空间哈希，近线性
            if dist(i.M, j.M) <= self.r_int or shares_contact(i, j):
                E.append((i, j))
        return E

    def compose_chunk(self, chunk, I, E, state):
        touched = [i for i in I if chunk_reaches(chunk, i)]
        Et = [(i, j) for (i, j) in E if i in touched and j in touched]
        if max_degree(Et) > self.kappa_d:                # P17：超界退化
            return self.joint_certificate(touched, state)  # S-1
        c = self.ca.TOP
        for i in touched:
            c = self.ca.mul(c, self.instance_cert(i, state))
        for (i, j) in Et:
            c = self.ca.mul(c, self.interaction_cert(i, j, state),
                            beta_int=self.beta_int(i, j))
        return c if self.gcc.consistent(touched, state) else self.ca.BOT


# IP-366 InstanceNormRouter
class InstanceNormRouter:
    def __init__(self, norms):
        self.norms = norms

    def risks(self, chunk, I, b):
        touched = [h for h in I if h.is_human and chunk_reaches(chunk, h)]
        out = {}
        for nu in self.norms:
            if nu.separable:
                out[nu.id] = sum(
                    b[nu.id, h.id] * sigmoid(-stl(nu.psi_h, chunk) / nu.scale)
                    for h in touched if h.id in nu.humans)
            else:
                out[nu.id] = relational_risk(nu, chunk, touched, b)  # 小超边
        return out

    def shield(self, cands, I, b):
        keep = [z for z in cands
                if all(r <= self.eps[nu.id] for nu, r in
                       zip(self.norms, self.risks(z, I, b).values())
                       if nu.kappa == 'hard')]
        return keep


# IP-367 AnytimeCertScheduler
class AnytimeCertScheduler:
    def choose(self, remaining, cost_fn, l_max):
        for l in range(l_max, -1, -1):       # 从最细往下找，取最大可行 l
            if cost_fn(l) <= remaining:
                return l
        return 0                              # 最粗仍不可行 ⇒ 交给 a_ask/停

# IP-369/370 InstancePanelCAE + ScalableAttributionSampler
class InstancePanelCAE:
    def sample(self, I, S):
        strata = group_by(I, key=lambda i: (i.cls, degree(i), i.uncertainty))
        return stratified_sample(strata, S)          # 定义 565

    def estimate(self, m, panel):
        per_instance = []
        for i, obs in panel.items():

            if y1 is not None and y0 is not None:

        ace = mean(per_instance) if per_instance else None
        return ace, panel_sensitivity_bound(panel)   # 定义 563/564

## 4. 推导

**引理 96（证书合成可靠性）** 设安全谓词 Pred 可分解为实例一元谓词与 ≤2 阶交互谓词（高阶项显式落入超边），每个 Ĉ_i、Ĉ_e 满足各自的局部可靠性界，余量满足 β_{A⊗B}≤β_A+β_B+β_int。则 Ĉ_chunk 有效 ⇒ 全局安全谓词在 β_chunk 误差预算内成立。证明：把 Pred 按实例与超边展开，逐项代入局部可靠性，误差次可加叠加；未被触及的实例由定义 559 的分离条件贡献零项。∎

**引理 97（近线性伸缩）** 若交互半径 r_int 固定、实例最小间距 ≥s_min 或场景满足堆积数 ≤κ_p，则交互图度数 d_i≤κ_d、E_t=O(N)，于是证书成本 O(N)；若前提失效，定义 559 退化到度数 d_max 的联合证书，成本 O(N·d_max) 并报告违反。证明：以 r_int/2 为半径在每实例处作互不重叠的球，球体积给出单位体积内实例数的上界，故每个邻域内实例数有界；对每实例邻域求和即得边数线性。∎

**引理 98（anytime 可靠性与单调完备）** 在保真度阶梯上若 c(l) 单调不减、接受集满足 l'<l ⇒ V(l')⊆V(l)、且每级均满足定义 558 的可靠性，则任意预算下 AnytimeCertScheduler 的输出仍可靠，误拒率随 l 单调不增；预算→0 时退化为最粗级别，**可能高误拒但绝无误放**。证明：调度只改变 l 不改变判据，可靠性逐级成立；接受集单调保证细化只减误拒；预算不足时取 l=0 仍安全。∎

**引理 99（实例规范路由等价与伸缩）** 当所有规范可分解为逐人实例项，定义 560 的 R_ν 等于 v10 整场景 R_ν；当存在关系型规范，把它们放入定义 557 的小超边后结果仍等价，且成本从 O(|𝕀_t|) 降到 O(|𝕀_touch|)。证明：可分离时 σ 的求和对人实例逐一展开；非可分离项按超边覆盖，超边数受定义 559 局部性约束。∎

**引理 100（实例面板去混杂）** 若 H=H_i+H_{i,τ} 且 H_i 在重复观测内不变，则定义 563 的 ACE_m^FE 对 H_i 无偏；对时变部分满足 |ACE_m^FE−ACE|≤B_Γ^panel，且 B_Γ^panel 随每实例配对次数 T_i 增大而收窄。证明：实例内差分消去 H_i；时变项由面板 Rosenbaum 敏感性模型按配对展开，差分方差随 T_i 下降。∎

**引理 101（分割误差传播与粘合检测功效）** 设关联错误概率 ≤δ_seg,i、掩码边界在 Hausdorff 意义下偏差 ≤β_mask,i，且证书按定义 555 的 Ĉ_seg 计入这些项。则证书合成的额外误差 ≤Σ_i (L_i β_mask,i + M_i δ_seg,i)，取裕度补偿后引理 96 的可靠性仍成立。粘合残差对关联错误有正检测功效：若两实例被误合并，重叠区区间不一致的概率 ≥1−e^{−c·area(Ω_ij)}。证明：Hausdorff 偏差经谓词 Lipschitz 常数 L_i 放大；关联错误按全概率展开为以 δ_seg 概率取伪实例的混合；区间分离概率由集中不等式给出。∎

**引理 102（中立元退化等价 v10）** 注入单伪实例（𝕀={scene}、G_int 无边）、固定 l=L、全局规范路由与 v10 CAE，则证书代数退化为 v10 单证书、规范盾退化为 v10 全局盾、归因退化为 v10 CAE，主闭环调用序列与 v10 逐位一致（仅调度顺序可交换）。证明：逐端口代入定义 568 的中立元，⊗ 只剩单项、V(L) 固定、H_ν∩𝕀_touch=全体即可。∎

**引理 103（预算守恒）** 实例分解新增在线成本：分割/跟踪增量 ≤0.5ms（复用 v10 感知）、实例证书 O(N)、交互证书 O(E)、粘合校验 O(重叠面积)、anytime 调度 O(L)。在 N≤200、E≤3N、L≤3 时，决策 p99 ≤20ms 仍成立；超预算时按定义 561 降 l（只增保守），不跳证书、不丢安全。证明：逐项复杂度代入静态 EDF 校验 ΣŴ_m≤B_dec；降级路径由引理 98 保证可靠。∎

**引理 104（分布式证书聚合）** 若各机器人持有不相交实例的局部证书、⊗ 交换结合，跨机交互边显式建边，则多机聚合结果与集中式一致；成本 O((N+E)·R^{-α}+E_cross)，E_cross 为跨机交互边数。缺失跨机边时按 fail-closed 降 l 或停，禁止隐式删边。证明：由 ⊗ 的结合交换律把集中式乘积按机器人分组；缺失边相当于丢掉一个合取项，故必须显式处置以保证引理 96。∎

**引理 105（伸缩不降低安全）** 对任意可达预算 B 与实例数 N，anytime + 局部性路径的执行集是"所有实例证书与交互证书在全保真 l=L 下均有效"的执行集的子集；因此扩容只会让系统更保守，绝不放宽 v10/v9 的物理安全判据。证明：降 l 使接受集单调缩（引理 98），局部性漏边被 IGM 超界检测与 fail-closed 阻止（定义 559/S-1），故执行集只能更小。∎

## 8. 已知风险与失效模式

1. **实例关联错误污染证书**：掩码渗出/身份跳变使局部性前提失效，交互项被漏掉（本轮最大风险）。缓解：Ĉ_seg 与 ρ_glue 显式检测、ε_id 保守、关联不确定时降 l 或走联合证书、E595/E596 专项注入测试。
2. **交互图度数超界**：密集堆叠/人群拥挤时 κ_d 不成立，成本与误差同时上升。缓解：超界即退化联合证书（S-1）并报告，不静默截断；按空间分块与距离截断。
3. **保真度阶梯误标定**：若 c(l) 或 V(l) 单调性不成立，anytime 的"只降精度"承诺破裂。缓解：离线逐级标定、单调性回归测试（E594）、运行时断言。
4. **可分离性误判**：把关系型规范当成逐人项会低估违规（如轮流顺序）。缓解：规范显式标注 separable、关系型强制入超边、E597 对照。
5. **面板估计的时变混杂**：H_{i,τ} 不满足固定效应假设时会残留偏差。缓解：只报界、不可识别禁止休眠/迁移、E599 压力测试。
6. **分割证书自指**：Ĉ_seg 本身依赖分割，误差可能被低估。缓解：用独立信号（深度/触觉/多视角）交叉校验粘合、保守 ι_min。
7. **多机通信缺失**：跨机边缺失导致隐性漏交互。缓解：fail-closed、交叉边心跳、E601。
8. **算力与实时性**：N 大时 still 可能超预算。缓解：anytime 降 l、增量缓存、异步归因、静态 EDF。

## 9. 本轮最大风险

**一句话**：证书代数的全部可靠性都建立在"实例关联正确"之上；一旦掩码渗出或身份跳变把两个相互作用的实例判成一个（或把一个判成两个），局部性前提失效、交互项被静默漏掉，系统会以近线性的吞吐输出一个**看似可扩展、实则漏掉相互作用**的虚假安全证书。
