# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配歧义消解闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「移动操作」×「流匹配策略」）

> R69 把不确定性一分为二：aleatoric 交给 λ_floor 收紧，epistemic 交给「流匹配 + 主动交互」消解，并用 (r_res, Δa) 两条通道互为第二意见。但整套机器仍隐含一个从未被挑战的前提：**基座是不动的，因此「可行动作集」是一个常量；信息动作（看/问/触）是廉价、可逆、不改变世界状态的**。移动操作同时打破这两点：你站在哪里，决定你还能抓到哪里、看到什么、以什么力接触、以及退路在哪里；而基座位移昂贵、半不可逆，并且会把你从「当前可行动作集」搬到另一个集合里。R69 的 VoI 只问「值不值得问」，却没有问「**值不值得换一个能问、能做、也能退的地方**」。
>
> 本轮的核心命题：
>
> **移动操作的本质不是「把动作从 A 点搬到 B 点」，而是一次「对未来可行动作集的期权购买」。** 基座位姿 b 是一个 option：它花掉时间/能量/社交成本，买来一组新的可达任务、新的视角、新的接触模式，同时也卖掉当前位姿所保留的退路。流匹配策略天然生成「基座 + 手臂 + 注视」的全身轨迹，因此可以**条件在候选 b 上做反事实采样**，在真正移动之前估计每个选项的任务价值、成功风险、可达集宽度与未来 option value；再用**净移动价值（NMV）**把 R69 的 VoI、期权价值、移动成本、不可逆损失与社交成本放进同一把尺子。只有 NMV > 0、全身安全认证通过、选项校准门通过、且存在可返回路径时才移动；否则逐指令退化为 R69，R69 再退化为 R68。
>
> 流匹配还提供一条移动操作独有的诊断通道：**行为里程计**。若基座位姿估计错了（轮滑、被劫持、里程计漂移），手臂为到达同一世界目标所需的全身轨迹就会在当前 b 下变成低似然；而在正确的 b 附近似然更高。这条通道只依赖「行为可达性」而非传感器残差，因此**标定层吸收不了它**——它是 R69 的 FMA 在移动维度上的严格扩展。
>
> 命名 **ROAM-RAS**（Reachability-Option-Aware Mobility for Risk-Adaptive Systems，可达性-期权感知的移动操作风险自适应闭环）。
>
> 一句话定位：R69 问「我该向谁求证、还能问什么」，R70 问「**我该站在哪里，值不值得离开现在的位置**」——移动不是把人送过去，而是把未来的可能性买下来；买之前必须先算清「卖掉现在的位置要损失什么」。

## 0. 直觉与动机

**灵感 1（移动操作 → 动作集随基座变化，基座是一次「期权购买」）**
直觉：固定基座机械臂的动作集可以近似看作常量：够不到就是够不到，停下来就是安全。移动操作把它变成一个**由位姿参数化的集合族**：靠近货架买来「能抓上层」，退到门口买来「有退路」，转到侧面买来「不被遮挡」。于是决策对象不再是单个动作，而是**选项 b**——一个带有持续时间、成本、风险、以及「买来/卖掉哪些未来动作」的宏观承诺。用经济学的语言：移动是**真实期权（real option）**；它的价值不只是「到达后能拿多少分」，还包括「到达后还保留多少选择权」。这正是 R69 的标量 VoI 看不见的部分。

**灵感 2（流匹配策略 → 在移动之前先把每个选项「试演」一遍）**
直觉：传统基座放置依赖解析可达性地图或采样规划，能算「够不够得到」，算不出「做完之后还剩下什么」。流匹配策略把全身未来表示成一个可从噪声积分的速度场：给定候选 b，采样 K 条 (基座, 手臂, 注视) 联合轨迹，就得到该选项下的**反事实未来集合**。对集合做聚类、风险分位、可达集覆盖与继续价值估计，就能在物理移动前比较选项。更关键的是，流匹配的条件是 b，因此同一套网络可以回答「如果我现在站在 b' 会怎样」——这是**用生成模型做选项评估器**，而不是再训练一个独立的 Q 网络。

**灵感 3（期权理论 → R69 的 VoI 是「零移动成本、零期权损失」的退化情形）**
直觉：R69 选择信息动作 g 时只比较 VoI(g) 与成本 c(g)，隐含假设「做完这个动作，我的可行集不变」。看/问/触大致满足；移动不满足。把期权价值 OV(b)（包含未来可行集）与期权损失 OL（离开当前位姿所放弃的未来选择）写进目标，就得到净移动价值：
**NMV(b) = ΔTask(b) + γ·ΔOV_net(b) + λ_I·VoI_mob(b) − c_move(b) − c_irrev(b) − c_social(b)**。
当移动成本为零、期权损失为零、且 b 只改变信息不影响可行集时，NMV 退化为 R69 的 VoI − 成本。**旧层不是被替代，而是成为新层在「零移动」边界上的严格退化**——这是本系列一贯的理论姿态。

**灵感 4（流似然 → 行为里程计，补上移动操作最脆弱的基座位姿通道）**
直觉：轮式/足式基座的里程计漂移、轮滑、被抱起（kidnap）是移动操作的经典故障；而 R68 的标定层与 R69 的 FMA 都默认「基座位姿是已知的」。但全身流策略给出一个独立信号：观测到的全身轨迹 ξ_obs 在当前基座位姿 b̂ 下的似然，与在邻域候选 b 下的似然之差 Δa_base。若 b̂ 错了，手臂为了够到同一个世界目标会被迫做出「在当前 b̂ 下很别扭」的全身构型，Δa_base 升高；而里程计标定只能吸收传感器残差，吸收不了这个**行为可达性残差**。于是 (r_odo↓, Δa_base↑) 成为基座滑移/劫持的判别性联合模式——R69 定义 309 的移动版镜像。

**灵感 5（移动是双刃剑 → 自信地站错，比不动更危险）**
直觉：R69 的最大风险是「问错，比不问更危险」。移动把这句话升级：**站错，比不动更危险**。一旦机器人自信地搬到一个看似更好、实则不可逆地自断退路的位置（走进死胡同、站到斜坡边缘、被人群围住、把唯一出口让出），它失去的不只是一次动作，而是**未来所有的纠错选项**。因此本轮必须同时交付：选项价值校准门（防高估）、可达性证书（防幻觉）、不可逆预算与可返回路径（防自断退路）、移动证据纪律（单条流样本不得定案）、以及移动特有的干扰集（vantage poisoning / 基座劫持 / 对抗性流引导）。否则 ROAM 不是进步，而是给 R69 装上了一双会走向悬崖的腿。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（ROAM-RAS 总览）** ROAM-RAS = (BCF, OPE, OVE, MVI, NMV, FRI, OCG, IAB, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **移动预算硬约束**：单位时间选项切换 ≤ 1 次、累计位移 ≤ D_max、能耗 ≤ E_max、社交打扰 ≤ c_max；选项决策只在选项边界进行，控制环内不做基座重规划；
(iii) **选项证据纪律**：一个基座选项须由 ≥2 个正交证据源一致支持（感知/可达性、流似然/OPE、WM 预测），单条流样本不得单独定案；
(iv) **不可逆约束**：每个被执行的选项必须持有经认证的可中止/可返回路径；不可逆选项消耗硬预算，并需要更严格的 NMV 边际与双源证据。

**定义 311（选项空间与全身动作）** 基座选项 b = (p_b ∈ SE(2) 或 SE(3), ψ_b, t_b, κ_b)，其中 p_b 为位姿、ψ_b 为到达朝向、t_b 为时间窗、κ_b 为地形/接触/载荷 regime。候选集 B(o_t) ⊂ B 由可达性地图、任务目标、退路检查与预算共同生成（有限集，|B| ≤ 8）。全身动作 ξ = (u_base, q_arm, g_info) ∈ 𝒜_+，其中 u_base 为基座轨迹、q_arm 为手臂关节轨迹、g_info 为 R69 的信息动作（注视/探针/问句）。策略目标 π_θ(ξ_{t:t+H} | o_t, b)。

**定义 312（基座条件流策略 BCF）** 归一化全身动作块 x_1 = normalize(ξ_{t:t+H})，x_0 ~ 𝒩(0,I)，线性路径 x_s = (1−s)x_0 + s x_1。速度场 v_θ(x_s, s | z_t, c_b)，其中 z_t 复用 R69 MTM trunk 的条件编码，c_b = Enc(b, o_t) 为基座选项编码（Fourier 位姿特征 + 局部可达性地图 patch + 地形/载荷 token）。目标 L_BCF = E_{s,x_0,x_1}‖v_θ(x_s,s|z_t,c_b) − (x_1−x_0)‖²。采样用 Heun，N_step=2；采样过程中施加约束引导/投影 P_feas（自碰撞、关节限位、基座速度/加速度、支撑多边形稳定裕度、动态障碍），得到「生成即可行」的全身轨迹。

**定义 313（选项评估 OPE）** 对候选 b 采样 K_b 条全身轨迹 {ξ^{(j)}}。定义
- 成功率 p̂_succ(b) = (1/K_b)Σ_j 1[Critic(ξ^{(j)}, o) ≥ τ_succ]；
- 尾部风险 CVaR_α(b) = E[Cost | Cost ≥ VaR_α]（对最坏 α 分位求均值）；
- 可达裕度 ρ(b) = min_{τ ∈ Targets(o)} signed_margin(b, τ)，其中 signed_margin 由可操作度加权的工作空间边界距离、关节限位距离与自碰撞距离取最小；
- 选项分数 V_b = E[Return(ξ)] − λ_risk·CVaR_α(b)。
「可达性证书」通过 ⇔ ρ(b) ≥ ρ_min 且自碰撞/稳定性违规率 ≤ δ_feas。

**定义 314（期权价值 OVE 与期权损失）** 半-MDP 分解：
OV(b) = V_b + γ^{T_b}·E_{ξ∼π(·|b)}[V_cont(s_{T_b}(ξ))]，
其中 T_b 为选项持续时间，V_cont 为选项结束状态（含剩余可行集）的继续价值。定义选项宽度 Ω(b) 为从 b 出发可达的任务-接触模式集合的熵/体积；从当前 b_cur 切换到 b 的**期权损失**为
OL(b_cur → b) = max(0, OV(b_cur) − OV(b) + λ_Ω·max(0, Ω(b_cur) − Ω(b))) = max(0, −ΔOV_net(b))。
直观：OL 是「为了去 b 而卖掉的未来选择权」，它在 R69 中恒为零（信息动作不改变可行集）。

**定义 315（移动信息价值 MVI）** 设 M = (任务模式, 接触模式, 定位模式) 为当前主导 epistemic 对象。候选移动 b 的信息增益
VoI_mob(b) = H(M | o_t) − E_{y∼p(·|b,o_t)}[H(M | o_t, y)]，
其中 y 为到达 b 后的新观测（视差、遮挡解除、接触探测）。当信息增益主要来自「看清/验证」时称 **move-to-verify**；当主要来自「买来新的可操作集」时称 **move-to-manipulate**。一次移动可同时具有两种成分，MVI 只计算前者，后者进入 ΔTask 与 ΔOV_net。

**定义 316（净移动价值 NMV 与选项决策）** 
NMV(b) = ΔTask(b) + γ·ΔOV_net(b) + λ_I·VoI_mob(b) − c_move(b) − c_irrev(b) − c_social(b)，
其中 ΔTask(b) = V_b − V_{b_cur}，ΔOV_net(b) = OV(b) − OV(b_cur) − λ_Ω·max(0, Ω(b_cur) − Ω(b)) 为「期权增益扣除可行集宽度损失」（其负部正是定义 314 的期权损失 OL），c_irrev 由定义 317 的不可逆等级给出。选择
b* = argmax_{b ∈ B_cert(o_t)} NMV(b)，s.t. ρ(b) ≥ ρ_min、OCG 通过、证据纪律满足、预算未越界；
若 max_b NMV(b) ≤ 0 或不存在合格选项，则 **b* = b_cur，不移动**，执行 R69 的 FLUID 闭环。NMV 的符号就是「移动是否值得」的可审计判据。

**定义 317（不可逆性与可返回证书 IRC）** 对选项 b 定义不可逆等级 ι(b) ∈ [0,1]（由地形坡度、单向门、通道宽度、通信/系绳、人流密度、退回距离估计）。可返回证书 IRC(b) 成立 ⇔ 存在中止策略 π_abort 与时间上界 τ_a，使得从 b 的任意可达中间状态出发，执行 π_abort 能在 τ_a 内停住或退回一个经认证的安全集，且全过程满足 C-RAS-WM‡ 包络。移动决策需满足
NMV(b) ≥ ν_irr·ι(b) + ε_cert，
且当 ι(b) > ι_max 时必须额外获得一个物理可返回性证据源（例如实际倒车测试/双向通道确认）。不可逆选项的总数受硬预算 B_irr 限制。

**定义 318（流似然基座完整性 FRI）** 用瞬时变分 + Hutchinson 估计
a_score(ξ_obs | o, b) = −log p_θ(ξ_obs | o, b)。
定义基座完整性残差
Δa_base = a_score(ξ_obs | o, b̂) − min_{b ∈ N(b̂)} a_score(ξ_obs | o, b)，
其中 N(b̂) 为 b̂ 的局部位姿邻域。若 Δa_base > τ_FRI 且里程计残差 r_odo 低，则疑似基座滑移/劫持/未建模漂移。流配准 b* = argmin_{b∈N(b̂)} a_score(ξ_obs | o, b)；若 ‖b* − b̂‖ > τ_pose 且似然增益 > τ_gain，则把 b* 作为基座位姿的第二意见，并在下一控制周期采用保守 λ 与最小移动策略。该通道只依赖行为可达性，**不被里程计标定吸收**。

**定义 319（选项校准门 OCG）** 对 p̂_succ(b)、V_b、OV(b) 与 ρ(b) 做校准：可靠图、ECE、风险覆盖。若 ECE > τ_ocg 或可达性证书的假阳性率 > τ_fp，则**禁用移动决策**，退回 R69 的零移动闭环；若只有部分 b 越界，则把这些 b 从 B_cert 中剔除。OCG 是 R69 的 MCG 在移动维度上的下游版本：**不可信的选项分布不得驱动基座**。

**定义 320（全身安全认证 C-RAS-WM‡）** 把 R69 的 C-RAS-WM 前缀认证扩展到全身：基座足迹、动态稳定裕度（支撑多边形/ZMP/CBF）、倾覆裕度、自碰撞、负载挠度、系绳/通信、动态障碍预测、关节/速度/加速度限幅。认证输出全身前缀长度 k_whole 与可中止动作 a_abort；任一不过 ⇒ 该选项不合格，或只允许执行其安全前缀后停下。

**定义 321（移动证据纪律与预算）** 基座选项定案需 ≥2 个正交证据源一致：
(1) 感知/可达性地图（τ 可达且无遮挡）、(2) 流 OPE（多采样成功率与 CVaR）、(3) WM/物理预测（动态障碍与稳定性）。单条流样本不得作为移动依据。移动预算：单位时间 ≤1 次选项切换、累计位移 ≤ D_max、能耗 ≤ E_max、社交成本 ≤ c_max；选项评估只在选项边界触发（每 T_o ≥ 400ms 一次），控制环内不重评。

**定义 322（移动审计 VQAuditor-M）** 审计对象新增：选项价值是否高估、可达性是否幻觉、移动是否被 vantage poisoning 诱导、IRC 是否真实成立、证据是否单源、社交/隐私成本是否越界。审计结论回灌 OCG 与成本先验；移动日志与全身认证前缀一并进入证书。

**定义 323（移动干扰集 ℰ_ROAM）** ℰ_ROAM = ℰ_FLUID × ℰ_mob，其中
ℰ_mob = {vantage poisoning（诱导到视野差/易被困的位姿）, base kidnap/spoofing（基座位姿被篡改）, wheel slip / terrain drift（轮滑/地形漂移）, hallucinated reachability（流模型幻觉出不可达选项）, adversarial flow guidance（对抗性引导采样）, dynamic occlusion（动态遮挡使原选项失效）, social engineering（「到这儿来」式诱导）, return-path blockage（退路被人/物封死）}。

**定义 324（证书 J_ROAM）** 
J_ROAM = (J_FLUID, option_value_hat, option_value_ece, reachability_margin, option_loss, base_integrity_delta, abort_margin, mobility_log_hash, ocg_ece, roam_ver)。
Valid ⇔ Valid(J_FLUID) ∧ OCG 通过 ∧ 证据纪律满足 ∧ IRC 成立 ∧ 移动预算未越界 ∧ 全身认证前缀有效。

**定义 325（嵌套退化链）** 令 B = {b_cur}（禁用移动）且 FRI 不触发时，ROAM 逐指令等于 R69 的 FLUID；再令交互禁用（VoI ≤ 成本或 MCG 越界）时，逐指令等于 R68 的 CALM。因此
**CALM ⊂ FLUID ⊂ ROAM**：安全侧不做任何让步，效率侧同时获得 R69 的 resolution bonus 与 R70 的 option value。信任义务只有一条：**禁用移动 ⇒ 行为必须等于上一层**。

**定义 326（选项时序与边界）** 每个选项带持续时间 T_b，执行期间由 BCF 生成全身动作，决策只在选项边界发生。边界处需满足：控制指令连续或满足有界 jerk；λ 取 max 保守；若 NMV 边际小于滞回阈值 h_o，则不切换（防抖动）。该结构等价于半-MDP 的 options framework，使「移动」成为一个可评估、可中止、可审计的宏观动作，而非控制环里的瞬时指令。

**假设增量**：A99（选项离散化：候选集 B 对相关位姿的覆盖残差 ≤ ε_b）；A100（选项校准：|V̂_b − V_b| ≤ ε_V，p̂_succ 覆盖误差 ≤ ε_p）；A101（可达性证书可靠性：ρ(b) ≥ ρ_min ⇒ 目标以概率 ≥ 1−δ_r 可达）；A102（可中止性：每个认证选项存在成功率 ≥ 1−δ_a、返回时间 ≤ τ_a 的中止策略）；A103（基座完整性可辨识：基座位姿误差超过 ε_pose 时，流似然差以概率 ≥ 1−δ_i 超过噪声底）。

```python
# IP-264 BCF：基座条件全身流策略（条件编码复用 R69 trunk）
class BaseConditionedFlowPolicy:
    def __init__(self, trunk, velocity_net, option_encoder, N_step=2):
        self.trunk, self.v = trunk, velocity_net
        self.enc = option_encoder                  # b -> c_b

    def sample(self, o_t, b, K, N_step=2):
        z  = self.trunk(o_t)
        c  = self.enc(b, o_t)                      # 位姿 + 可达性 patch + regime
        xs = randn(K, D_whole)
        for i in range(N_step):
            s  = i / N_step
            v  = self.v(xs, s, z, c)
            v  = self.guide(v, xs, b, o_t)         # 稳定/限位/自碰撞/动态障碍引导
            xs = xs + (1.0 / N_step) * v
        return [self.decode(x) for x in xs]        # (u_base, q_arm, g_info)

    def log_likelihood(self, xi, o, b):            # 瞬时变分 + Hutchinson
        z, c = self.trunk(o), self.enc(b, o)
        return -hutchinson_divergence_integral(self.v, xi, z, c)

# IP-265/266 OPE+OVE：选项评估与期权价值
def evaluate_option(policy, b, o, K, critic, value_cont):
    S     = policy.sample(o, b, K)
    succ  = mean(critic(s, o) >= TAU_SUCC for s in S)
    cvar  = cvar_alpha([cost(s) for s in S], ALPHA)
    rho   = reachability_margin(b, o)              # A101 证书
    V     = mean_return(S) - LAMBDA_RISK * cvar
    OV    = V + (GAMMA ** horizon(b)) * mean(value_cont(s_end(s)) for s in S)
    Omega = feasible_set_entropy(b, o)             # 未来可行集宽度
    return Option(b, V, succ, cvar, rho, OV, Omega, S)

# IP-267 MVI：移动的信息价值（看/验证成分）
def mobility_voi(b, o, belief_M):
    y_samples = predict_observations_after(b, o)   # 视差/遮挡解除/接触探测
    return entropy(belief_M) - mean(entropy(update(belief_M, y)) for y in y_samples)

# IP-268 NMV：净移动价值（无利可图即退化 R69）
def choose_option(M, o):
    cur = M.ope.evaluate(M.b_cur, o)
    best = None
    for b in M.candidates(o):
        if not M.budget.allow_move(b):              continue
        if not M.c_ras_wm.certify_whole(b, o):      continue
        if not M.iab.has_return_path(b, o):         continue
        x = M.ope.evaluate(b, o)
        if x.rho < RHO_MIN:                         continue
        dOV  = x.OV - cur.OV
        voi  = M.mvi.mobility_voi(b, o, M.belief_M)
        nmv  = ((x.V - cur.V) + GAMMA * dOV + LAMBDA_I * voi
                - move_cost(b) - irreversibility_cost(b) - social_cost(b))
        if nmv > max(0.0, M.ocg.margin(x)) and (best is None or nmv > best.nmv):
            best = (x, nmv)
    return best                                     # None → 不移动，走 R69

# IP-269 FRI：行为里程计（基座滑移/劫持的第二意见）
def base_integrity(policy, xi_obs, o, b_hat, neighbors):
    scores = {b: -policy.log_likelihood(xi_obs, o, b) for b in neighbors | {b_hat}}
    b_star = argmin(scores)
    delta  = scores[b_hat] - scores[b_star]
    suspect = (delta > TAU_FRI) and (M.last_r_odo < TAU_ODO)
    return delta, b_star, suspect

# IP-275 主闭环（继承 FLUID_RAS_round，仅在选项边界插入移动决策）
def ROAM_RAS_round(M, obs):

    c, U_cal, thr = M.cof.step(...)                 # R68 标定照常

    return k, lam, modes, (U_ale, U_epi)
```

## 3. 推导

**引理 19（选项价值的半-MDP 分解与期权损失下界）** 设选项 b 的持续时间为 T_b，执行策略为 π_θ(·|b)，则
OV(b) = V_b|_{0:T_b} + γ^{T_b} E[V_cont(s_{T_b})]。
若从 b' 出发的可达任务-接触集合是 b 的子集，则 OV(b) − OV(b') ≥ γ^{T}[V_cont(b) − V_cont(b')]，故离开 b 去 b' 的期权损失至少是「被放弃的未来可行集」的贴现值。要点：**移动的价值不只在于到达后能得多少分，还在于到达后还剩多少选择**；这把「基座放置」从几何可行性问题变成半-MDP 的 option 评估问题。

**引理 20（移动 VoI 与期权损失的权衡）** 令 κ 为「消解一个 nat 的主导 epistemic 不确定性」所带来的期望收益。则从 b_cur 移动到 b 值得当且仅当
κ·VoI_mob(b) + ΔTask(b) + γΔOV_net(b) > c_move(b) + c_irrev(b) + c_social(b)。
注意期权损失 OL(b_cur→b) 已并入 ΔOV_net：OV 下降与可行集宽度损失都作为负项进入，**不重复加 OL**。
系 1：R69 的 VoI 判据是 ΔOV_net = 0（零期权损失）、c_move = 0、且 b 不改变可行集时的退化情形。系 2：若存在一个信息动作 g（看/问/触）与移动 b 具有相同信息增益但成本更低且不产生期权损失，则移动被 g 支配——**能问就不动，只有移动买到新的可行集或更便宜的信息时才动**。这给出了「先看/问，再移动」的偏序，而不是盲目移动。

**引理 21（流似然的基座完整性可辨识性）** 设基座位姿误差 e = b̂ − b_true，目标位于 b_true 可达域内而接近 b̂ 可达域边界。由 A103，观测全身轨迹在 b̂ 与 b_true 下的负对数似然差满足
Δa_base ≥ L_r·‖e‖ − √(tr Σ_flow)，
其中 L_r 为「可达性诱导的似然 Lipschitz 常数」（目标越靠近可达边界，L_r 越大）。里程计标定只调整 r_odo，无法改变 a_score 对全身轨迹与条件基座的依赖，故 **(r_odo↓, Δa_base↑) 是基座滑移/劫持的判别性联合模式**。这是 R69 引理 17 在移动维度上的镜像：传感器残差测「里程计自洽」，行为似然测「全身行为在假定位姿下是否自洽」。

**引理 22（选项校准下的保守选择）** 在 A100 下，若 OCG 认证 |V̂_b − V_b| ≤ ε_V 且 p̂_succ 的覆盖误差 ≤ ε_p，则只接受满足 NMV_hat(b) ≥ ε_V + ε_p·R_max + h_o 的选项，可保证真实 NMV(b) > h_o > 0。系：在 OCG 认证域内，系统不会「自信地买下一个实际负价值的选项」；一旦离开校准域，OCG 直接禁用移动并退回 R69。这把本轮最大风险（option value 高估导致承诺性失败）转成一个可门控的统计条件。

**定理 18（ROAM ⊇ FLUID ⊇ CALM，嵌套退化）** 在 A99–A103 与有效证书下：
(i) 当无合格选项（NMV ≤ 0）、OCG 失败、FRI 报基座故障或预算耗尽时，ROAM 不移动，逐指令执行 R69 的 FLUID；
(ii) 当 R69 的 VoI ≤ 成本或 MCG 越界时，FLUID 逐指令执行 R68 的 CALM；
(iii) 当执行移动时，选项必须通过 C-RAS-WM‡ 全身认证并持有 IRC 可返回路径，执行前缀落在认证不变集内，故最坏情况安全风险不超过 R69 的认证界 + ε_mob（保守裕度可取 ε_mob = 0）。
因此 **CALM ⊂ FLUID ⊂ ROAM**：安全侧不做任何让步，效率侧同时获得 resolution bonus 与 option value。

**定理 19（移动安全、边界连续与无突变）** 选项切换只发生在选项边界；切换时 λ 取 max、控制指令满足有界 jerk 或经中止前缀过渡；移动全程受 C-RAS-WM‡ 全身包络与 IRC 可返回路径约束。若 FRI 报故障、OCG 越界、预算耗尽或 IRC 失效，λ 单调不降地退回 R69，选项回滚到 b_cur。故：
(a) 移动中不与静态/动态障碍越界，不自碰撞、不倾覆；
(b) 选项切换处控制连续，无突变；
(c) R68 的换装不变式（定理 15）与 R69 的交互安全（定理 17）保持。
要点：**移动不是「更大的动作」，而是「带中止路径的选项」**；安全来自「随时能退」，而不是「从不移动」。

**推论 20（收益分解）** ROAM 相对 R68 的性能增益可分解为三项：R69 的 resolution bonus（消解 epistemic 歧义）、R70 的 option value（换位买来新的可行集）、以及 move-to-verify 的信息价值。该分解直接对应 E296/E315 的消融设计，避免把「因为多走了几步」误归因于「因为模型更聪明」。

## 6. 本轮最大风险

**一句话**：ROAM-RAS 的全部收益押在「流策略能可靠估计每个基座选项的任务价值、可达集与未来 option value」这一前提上——**若选项价值被高估（流模型幻觉出并不存在的可达性/成功模态，或 OVE 把小概率的灾难性死胡同算成高价值），机器人会自信地搬到一个看似更好、实则不可逆地自断退路的位置**；移动把 R69 的「问错」升级为「站错」，而站错之后往往连「再问一次」的机会都没有——**站错，比不动更危险**。

**次级风险与缓解**：
1. **可达性幻觉/选项高估** → OCG 校准门 + 引理 22 保守边际 + 可达性证书 ρ(b) ≥ ρ_min，越界即禁用移动、退回 R69；
2. **不可逆自断退路** → IRC 可返回证书 + 不可逆预算 B_irr + ν_irr 边际 + 高风险选项需物理可返回性证据；
3. **基座滑移/劫持/里程计漂移** → FRI 行为里程计 + 流配准 b* + (r_odo↓, Δa_base↑) 联合判据，触发即保持/回滚并收紧 λ；
4. **vantage poisoning / 社交工程** → 移动证据纪律（≥2 正交源）+ 社交成本模型 + VQAuditor-M + ℰ_MOB 对抗训练；
5. **移动中动态安全/倾覆** → C-RAS-WM‡ 全身认证 + 动态障碍预测 + 中止前缀 + 定理 19 边界连续性；
6. **选项评估击穿实时预算** → 只在选项边界低频评估 + 自适应 K + 摊薄预算，控制环保持 R69 高频路径。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** 零学习写、移动预算硬约束、选项证据纪律（≥2 正交源）、不可逆约束（每个执行选项必须持有 IRC 可返回证书）。

**定义 311–312（选项空间与 BCF）** b 含位姿/朝向/时间/regime；候选 B(o_t) 有限（≤8）。全身流 x_s=(1−s)x_0+s x_1，v_θ(x_s,s|z_t,c_b)，Heun N_step=2，采样时用 P_feas 投影/引导保证限位、自碰撞、稳定性与动态障碍可行。

**定义 313–314（OPE 与 OVE）** 每个 b 采样 K 条全身轨迹，估 p̂_succ、CVaR_α、ρ(b)、V_b；半-MDP 分解 OV(b)=V_b+γ^{T_b}E[V_cont]；期权损失 OL=max(0,OV(b_cur)−OV(b))+λ_Ω·max(0,Ω(b_cur)−Ω(b))。

**定义 315–316（MVI 与 NMV）** VoI_mob(b)=H(M|o)−E_y[H(M|o,y)]；ΔOV_net=ΔOV−λ_Ω·max(0,Ω_cur−Ω_b)；NMV=ΔTask+γΔOV_net+λ_I·VoI_mob−c_move−c_irrev−c_social；b*=argmax NMV，s.t. ρ≥ρ_min、OCG、证据、预算；max NMV≤0 ⇒ 不移动、走 R69。

**定义 317（IRC）** 不可逆等级 ι(b) 由坡度/单向门/通道/系绳/人流/退回距离估计；IRC(b) ⇔ 存在 π_abort 在 τ_a 内停住或退回认证安全集；需 NMV ≥ ν_irr·ι(b)+ε_cert，高 ι 需物理可返回性证据。

**定义 318（FRI）** a_score=−log p_θ(ξ_obs|o,b)（瞬时变分+Hutchinson）；Δa_base=a_score(b̂)−min_{b∈N(b̂)}a_score(b)；Δa_base↑ ∧ r_odo↓ ⇒ 基座滑移/劫持疑；流配准 b*=argmin a_score 作为第二意见。该通道不被里程计标定吸收。

**定义 319–320（OCG 与全身认证）** 选项价值/可达性校准，ECE>τ_ocg 或可达假阳性>τ_fp ⇒ 禁用移动、退 R69；C-RAS-WM‡ 把认证扩展到足印、ZMP/CBF、倾覆、自碰撞、负载、系绳、动态障碍，输出全身前缀与 a_abort。

**定义 321–322（预算与审计）** 单位时间 ≤1 次选项切换、位移 ≤D_max、能耗 ≤E_max、社交 ≤c_max；选项评估只在边界（T_o≥400ms）。VQAuditor-M 审选项高估/可达幻觉/vantage poisoning/IRC/单源证据，回灌 OCG 与成本先验。

**定义 323–324（干扰集与证书）** ℰ_ROAM=ℰ_FLUID×ℰ_mob，ℰ_mob={vantage poisoning, base kidnap/spoofing, wheel slip/terrain drift, hallucinated reachability, adversarial flow guidance, dynamic occlusion, social engineering, return-path blockage}；J_ROAM 并入选项 ECE、可达裕度、期权损失、基座完整性、中止裕度、移动日志。

**定义 325–326（嵌套退化与选项时序）** B={b_cur} 且 FRI 不触发 ⇒ 逐指令等于 FLUID；再禁交互 ⇒ 逐指令等于 CALM（CALM⊂FLUID⊂ROAM）。选项带 T_b、只在边界决策、切换满足有界 jerk 与滞回 h_o，等价于半-MDP options framework。

**假设增量**：A99（候选覆盖残差 ≤ε_b）；A100（选项价值校准 |V̂−V|≤ε_V、p̂_succ 覆盖 ≤ε_p）；A101（可达证书：ρ≥ρ_min ⇒ 以概率 ≥1−δ_r 可达）；A102（中止：成功率 ≥1−δ_a、返回 ≤τ_a）；A103（基座误差 >ε_pose 时流似然差以概率 ≥1−δ_i 超噪声底）。

## 3. 关键算法伪代码

```python
# IP-264 BCF：基座条件全身流策略
class BaseConditionedFlowPolicy:
    def sample(self, o_t, b, K, N_step=2):
        z, c = self.trunk(o_t), self.enc(b, o_t)       # c: 位姿+可达patch+regime
        xs = randn(K, D_whole)
        for i in range(N_step):
            v  = self.v(xs, i/N_step, z, c)
            v  = self.guide(v, xs, b, o_t)              # 稳定/限位/自碰撞/动态障碍
            xs = xs + (1.0/N_step) * v
        return [self.decode(x) for x in xs]             # (u_base, q_arm, g_info)

    def log_likelihood(self, xi, o, b):
        z, c = self.trunk(o), self.enc(b, o)
        return -hutchinson_divergence_integral(self.v, xi, z, c)

# IP-265/266 OPE+OVE：选项评估与期权价值
def evaluate_option(policy, b, o, K, critic, value_cont):
    S    = policy.sample(o, b, K)
    succ = mean(critic(s, o) >= TAU_SUCC for s in S)
    cvar = cvar_alpha([cost(s) for s in S], ALPHA)
    rho  = reachability_margin(b, o)                    # A101 证书
    V    = mean_return(S) - LAMBDA_RISK * cvar
    OV   = V + (GAMMA ** horizon(b)) * mean(value_cont(s_end(s)) for s in S)
    return Option(b, V, succ, cvar, rho, OV, feasible_entropy(b, o), S)

# IP-267 MVI：移动信息价值（看/验证成分）
def mobility_voi(b, o, belief_M):
    ys = predict_observations_after(b, o)
    return entropy(belief_M) - mean(entropy(update(belief_M, y)) for y in ys)

# IP-268 NMV：净移动价值（无利可图即退 R69）
def choose_option(M, o):
    cur, best = M.ope.evaluate(M.b_cur, o), None
    for b in M.candidates(o):
        if not M.budget.allow_move(b):             continue
        if not M.c_ras_wm.certify_whole(b, o):     continue
        if not M.iab.has_return_path(b, o):        continue
        x = M.ope.evaluate(b, o)
        if x.rho < RHO_MIN:                        continue
        nmv = ((x.V - cur.V) + GAMMA * (x.OV - cur.OV)
               + LAMBDA_I * M.mvi.mobility_voi(b, o, M.belief_M)
               - move_cost(b) - irreversibility_cost(b) - social_cost(b))
        if nmv > max(0.0, M.ocg.margin(x)) and (best is None or nmv > best.nmv):
            best = (x, nmv)
    return best                                    # None → 不移动，走 R69

# IP-269 FRI：行为里程计
def base_integrity(policy, xi_obs, o, b_hat, neighbors):
    sc = {b: -policy.log_likelihood(xi_obs, o, b) for b in neighbors | {b_hat}}
    b_star = argmin(sc); delta = sc[b_hat] - sc[b_star]
    return delta, b_star, (delta > TAU_FRI and M.last_r_odo < TAU_ODO)

# IP-275 主闭环（继承 FLUID_RAS_round）
def ROAM_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    opt = None
    if M.at_option_boundary():
        opt = M.nmv.choose_option(M, o)             # NMV<=0 → None
        if opt is not None: M.apply_option(opt)
    K = 1 if M.bcf.mode_head(z, M.b_cur) < TAU_MODE else 4
    S = M.bcf.sample(o, M.b_cur, K)
    U_ale, U_epi, modes = M.aud.decompose(S, z, M.bcf.mode_head)
    da_base, b_star, suspect = M.fri.base_integrity(M.bcf, M.last_xi, o,
                                                    M.b_cur, M.pose_neighbors(M.b_cur))
    g = (M.mint.choose_interaction(modes, o, M.budget)
         if (U_epi > TAU_EPI and not suspect and not M.in_motion()) else None)
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g), 'k>=2')
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if opt is not None: lam = max(lam, M.iab.motion_lambda(M.b_cur))
    if suspect: lam = max(lam, 0.8); M.hold_option(); M.b_cur = b_star
    k = M.c_ras_wm.certify_whole(M.bcf.decode(S), M.b_cur, M.wm_preds)
    M.vqa_m.submit_async(opt, da_base, M.budget.snapshot(), M.evidence_agreement())
    return k, lam, modes, (U_ale, U_epi)
```

## 4. 推导

**引理 19（选项价值的半-MDP 分解与期权损失下界）** OV(b)=V_b|_{0:T_b}+γ^{T_b}E[V_cont(s_{T_b})]。若 b' 的可达任务-接触集是 b 的子集，则 OV(b)−OV(b') ≥ γ^{T}[V_cont(b)−V_cont(b')]，故离开 b 去 b' 的期权损失至少是被放弃未来可行集的贴现值。要点：移动的价值不只在于到达后得分，还在于到达后还剩多少选择。

**引理 20（移动 VoI 与期权损失的权衡）** 移动值得当且仅当 `κ·VoI_mob(b)+ΔTask(b)+γΔOV_net(b) > c_move+c_irrev+c_social`；期权损失与宽度损失已并入 ΔOV_net，不重复加 OL。系 1：R69 的 VoI 判据是 ΔOV_net=0、c_move=0、且 b 不改变可行集的退化情形。系 2：若存在同信息增益但更便宜且无期权损失的信息动作 g，则移动被 g 支配——**能问就不动，只有移动买到新可行集或更便宜的信息时才动**。

**引理 21（流似然的基座完整性可辨识性）** 基座误差 e=b̂−b_true、目标接近 b̂ 可达边界时，`Δa_base ≥ L_r‖e‖ − √(trΣ_flow)`（A103）。里程计标定只改变 r_odo，改变不了 a_score 对全身轨迹与条件基座的依赖，故 `(r_odo↓, Δa_base↑)` 判别基座滑移/劫持。此即 R69 引理 17 的移动版镜像：残差测「里程计自洽」，行为似然测「假定位姿下的全身行为自洽」。

**引理 22（选项校准下的保守选择）** A100 下若 OCG 认证 |V̂−V|≤ε_V、p̂_succ 覆盖 ≤ε_p，则只接受 `NMV_hat ≥ ε_V+ε_p·R_max+h_o` 的选项可保证真实 NMV>h_o>0。系：校准域内不会自信买下负价值选项；离开校准域 OCG 直接禁用移动。这把「option value 高估导致承诺性失败」转成可门控的统计条件。

**定理 18（ROAM ⊇ FLUID ⊇ CALM，嵌套退化）** A99–A103 与有效证书下：(i) 无合格选项（NMV≤0）、OCG 失败、FRI 报故障或预算耗尽时，ROAM 不移动、逐指令执行 R69；(ii) R69 的 VoI≤成本或 MCG 越界时，FLUID 逐指令执行 R68；(iii) 执行移动时选项必须过 C-RAS-WM‡ 并持有 IRC 可返回路径，执行前缀落在认证不变集内，最坏安全风险 ≤ R69 认证界 + ε_mob（保守裕度可取 0）。故安全侧不让步，效率侧获得 option value + resolution bonus。

**定理 19（移动安全、边界连续与无突变）** 选项切换只在边界；切换时 λ 取 max、控制满足有界 jerk 或经中止前缀过渡；全程受全身包络与 IRC 约束。若 FRI/OCG/预算/IRC 任一失效，λ 单调不降退回 R69、选项回滚。故 (a) 不越界/不自碰撞/不倾覆；(b) 切换处控制连续；(c) R68 换装不变式与 R69 交互安全保持。**移动不是更大的动作，而是带中止路径的选项；安全来自随时能退，而不是从不移动。**

**推论 20（收益分解）** ROAM 相对 R68 的增益 = R69 resolution bonus（消解 epistemic 歧义）+ R70 option value（换位买来新可行集）+ move-to-verify 信息价值。该分解对应 E296/E315 消融，避免把「多走了几步」误归因于「模型更聪明」。

## 7. 本轮最大风险

**一句话**：ROAM-RAS 的全部收益押在「流策略能可靠估计每个基座选项的任务价值、可达集与未来 option value」这一前提上——**若选项价值被高估（流模型幻觉出并不存在的可达性/成功模态，或 OVE 把小概率灾难性死胡同算成高价值），机器人会自信地搬到看似更好、实则不可逆地自断退路的位置**；移动把 R69 的「问错」升级为「站错」，而站错之后往往连「再问一次」的机会都没有——**站错，比不动更危险**。

**次级风险与缓解**：可达性幻觉/选项高估（OCG + 引理 22 保守边际 + ρ≥ρ_min，越界退 R69）；不可逆自断退路（IRC + B_irr + ν_irr + 高风险选项需物理可返回证据）；基座滑移/劫持/里程计漂移（FRI + 流配准 + `(r_odo↓, Δa_base↑)`，触发即保持/回滚并收紧 λ）；vantage poisoning/社交工程（≥2 正交证据 + 社交成本 + VQAuditor-M + ℰ_mob 对抗训练）；移动中动态安全/倾覆（C-RAS-WM‡ + 动态障碍预测 + 中止前缀 + 定理 19）；实时预算击穿（只在选项边界低频评估 + 自适应 K + 摊薄预算，控制环保持 R69 高频路径）。
