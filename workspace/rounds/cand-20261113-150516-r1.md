# 第 66 轮（承接第 65 轮「VISTA 故障可归因」IP-214~223；新一轮灵感循环第 1 轮；本轮灵感：「容错控制」×「语音识别」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险同样一针见血：**归因依赖「故障属于有限假设集、且视觉与几何失效相互独立」，真实故障常是未知类型的组合，且透明/镜面/对抗 patch 会让视觉与几何共享同一个分布外失效源；此时 FIR 会把未知复合故障强行归入最近假设、只膨胀错误的球——单点故障升级为「归因错误的复合故障」，而系统因「已经归因」反而更自信地继续执行。** 本轮不再往 VISTA 里叠加更多假设，而是换两个来自别的学科的提问方式：第 65 轮问「坏的是哪一类」，FLaRe 问「**能不能像听懂一段话那样，把故障随时间的演化『解码』出来，并让控制器真的『重构』而不是仅仅『保守化』**」。本轮核心命题是：
>
> **把「故障可归因」升级为「故障可解码 + 控制器可重构」：用语音识别的「声学模型 + 语言模型 + 流式束搜索 + N-best 格 + 置信度拒识 + 二遍重打分」把 VISTA 的单时刻 6 假设 argmax 升级为故障轨迹的流式解码；用容错控制的「解析冗余 + 多重模型滤波 + 控制分配 + 降级模式状态机」把 VISTA 的「膨胀球 + 缩短前缀」升级为可认证的可重构控制律。**

## 0. 直觉与动机

**灵感 1（语音识别 → 诊断不是分类，而是「解码一段故障语言」）**
直觉：ASR 从不把一帧音频硬判成一个词，它在「声学模型 × 发音词典 × 语言模型」构成的图上做序列解码，输出的是 **N-best 格 + 每段置信度 + 拒识**，而不是一个孤立标签。VISTA 的 FIR 恰恰相反：把一个 15 维签名一次性 softmax 成 6 个静态假设，**丢掉了故障的顺序结构**。但故障天然有语法：力偏置通常先漂移后饱和；接触模型错只在加载后才显形；视觉错常是间歇的；策略 OOD 往往在块边界才出现。**这些「什么故障允许接什么故障、持续多久」正是语言模型该管的事。**

**灵感 2（语音识别 → 格、置信度与拒识，而不是非黑即白的 ambiguous）**
直觉：VISTA 只有「确定/ambiguous」两档，且 ambiguous 后仍要退回一个离散假设。ASR 的做法成熟得多：(i) 用 **N-best 格/词图** 保留多条并行解释；(ii) 用**标定过的置信度**决定是否接受；(iii) 用**集外词 OOV 拒识**处理词典里没有的词——未知复合故障在数学上就是故障词表的 OOV。更关键的是 **流式部分结果的稳定性**：ASR 只在束搜索前缀稳定时才吐字，**二遍重打分**用更强的语言模型纠正一遍实时错误。诊断也该如此：**先稳定地「说出」已确定的前缀，把不确定的尾巴留在格里**。

**灵感 3（容错控制 → 容错不是鲁棒，重构才是容错）**
直觉：VISTA 在归因后做的事是「膨胀对应的不确定球 + 缩短执行前缀」——这在容错控制里叫**被动容错（passive FTC / robust control）**：用更大的保守裕度硬扛。真正的**主动容错（active FTC）**是：利用**冗余**在故障后**重构**——解析冗余（观测器/奇偶方程）负责检测，**控制分配（control allocation）**在失效执行器被剔除后把任务重新分给剩余执行器，**降级模式状态机**保证每个健康模式下都有独立可认证的闭环包络，并区分**故障隐藏（fault hiding，良性故障可被重构吃掉）**与**故障容纳（fault accommodation，必须改变任务）**。VISTA 只做了「诊断 + 保守化」，没有真正的「重构」。

**灵感 4（容错控制 → 多重模型滤波是更物理的「声学模型」）**
直觉：VISTA 用离线故障注入拟合 `p(ρ|H)`（高斯混合/归一化流）去近似一个手搓 15 维签名的似然——这是脆弱且不可解释的。容错控制里的 **MMAE / IMM（多重模型自适应估计 / 交互多模型）** 给出更物理的「声学模型」：为每个故障模式配一个滤波器（EKF/UKF/粒子），用**新息（innovation）**计算该模式的发射似然，模式间转移由马尔可夫矩阵给出。**模式转移矩阵恰好就是故障语言模型的转移先验**——ASR 与 FTC 在这里天然合流：`声学=滤波库`、`语言模型=故障语法/转移`、`解码=束搜索`。

**灵感 5（三灵感合流 → FLaRe：Fault-Language Reconfiguration，故障语言解码 × 可重构容错闭环）**
闭环：解析冗余与残差 → **多模型滤波库 FAM** 给每个故障符号的流式发射似然 → **故障语言模型 FLM**（故障语法 + 时长 + 转移先验，WFST）→ **流式故障格解码器 FLD**（束搜索/Viterbi，CTC 式 blank 处理「无故障/时长可变」）→ **OOV 拒识与置信度标定**（未知复合故障不再被硬塞进最近假设）→ **稳定前缀发射 SPE** + **语义流二遍重打分 RSC-FL** → **控制分配与重构 CA-R**（按后验路径重构控制律，而非只膨胀球）→ **降级模式状态机 DM-FSM**（每模式独立认证包络）→ **格级认证前缀 L-CSC**（对格中每条高概率故障轨迹 + 未知兜底都验证安全）→ 实时执行与早停。VISTA 把「接触」拆成前/中/后；FLaRe 把「归因」拆成 **声学（证据）/语言（语法）/决策（拒识）/执行（重构）** 四件事。

**灵感 6（VISTA/GRIP 组件的原位升级）**
- **FIR → FLD+FAM+FLM**：静态 6 假设 softmax 升级为「滤波库声学 + 故障语法 + 流式格解码」。
- **ambiguous → OOV-Reject**：二值模糊升级为「标定置信度 + 未知故障模型 + 代价敏感拒识」。
- **RSC-V / WCV-V → CA-R**：不再只膨胀 `r_geo/r_force/r_model`，而是给出**故障模式下的可容许控制集**并做控制分配/降级。
- **CSC → L-CSC**：认证对象从「6 个假设」升级为「格中 N 条故障轨迹 + 未知兜底」，并显式处理「不同路径要求冲突控制」→ 自动缩短 `k*`。
- **CSP-V / TSL → DM-FSM**：技能规划绑定健康模式，模式切换有滞回与驻留时间，防抖振。
- **AIC-V → AIC-FL**：干扰集增「违反语法的故障」「逼出高置信错误解码的对抗残差」「语音识别式信道/时序噪声」。
- **J_vista → J_flare**：证书增 `fault_lattice_hash`、`best_path_confidence`、`oov_margin`、`mode_id`、`reconfig_cert`、`stable_prefix_len`。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（FLaRe 闭环）**：FLaRe = (VISTA, FAM, FLM, FLD, OOV-Reject, SPE, RSC-FL, CA-R, DM-FSM, L-CSC, AIC-FL, J_flare)。定位：VISTA 的「故障解码 + 可重构控制」升级。不变式：**声学/语言解码、拒识、重打分、重构规划、证书只在语义流；实时流只做滤波新息采集、束搜索局部扩展、稳定前缀读出、认证前缀执行与早停，零学习写操作。**
- **定义 234（故障符号表与故障轨迹）**：故障符号 `z ∈ 𝒵 = {∅, geo, force_drift, force_sat, model, vis, policy, unk}`，`∅` 为 blank（健康/无可分辨故障/证据不足）；连续故障幅度 θ 作为符号上的参数。一段块序列的故障轨迹 `π=(z_1,τ_1)…(z_L,τ_L)`，`τ_i` 为持续时长（可由 CTC 式对齐得到）。
- **定义 235（故障声学模型 FAM / 多模型滤波库）**：对每个模式 m 维护滤波 `F_m`（EKF/UKF），状态含机器人/接触/传感器偏置；新息 `r_t^{(m)}=y_t−ŷ_{t|t−1}^{(m)}`、协方差 `S_t^{(m)}`，发射对数似然 `ℓ_t^{(m)}=−½(rᵀS⁻¹r+logdet S)`。连续幅度用参数化模式 `θ_m`（如偏置幅值网格或粒子）。FAM 只输出**似然**，不输出真值。
- **定义 236（故障语言模型 FLM）**：加权有限状态转换器 `G=(𝒵̄,Q,q_0,F,δ,w)`，状态 `Q` 描述故障「元状态」（健康/漂移/饱和/模型/视觉/策略/未知），弧带故障符号、时长约束与对数先验代价；转移矩阵 `A_{ij}=P(z_{t+1}=j|z_t=i)`。`G` 编码物理可行演化（如 `model` 不得在无接触时出现；`force_sat` 必须先经 `force_drift` 或突变弧）。**FLM 提供 `p(π)`，取代 VISTA 的均匀先验。**
- **定义 237（流式故障格 Lattice）**：在时刻 t，束宽 B 内的所有活跃部分路径 `Π_t={π}`，每条附声学分数、语言分数与后验 `P(π|y_{1:t})`；格 `𝔏_t` 记录节点/弧与时间对齐，支持前向-后向求 token 置信度。格不是单一答案，而是「当前所有还说得通的故障解释」。
- **定义 238（故障解码目标）**：`π* = argmax_π [ log p(y_{1:t}|π) + λ_lm log p(π) + λ_len |π| ]`，其中声学项由 FAM 给出，语言项由 FLM 给出；`λ_lm` 控制语法约束强度。束搜索近似 MAP；束宽足够时等价于在 `G∘FAM` 上的 Viterbi。
- **定义 239（故障起点对齐与 blank）**：沿用 CTC 式 blank `∅`：未被 `∅` 分隔的连续符号段视为同一故障事件，`τ̂` 为该段起止。故障起点 `t_onset(z)` 取首次非 blank 且该符号后验超过 `δ_emit` 的时刻。对齐使「何时开始坏」成为一等公民，可与 VISTA 的阶段签名对接。
- **定义 240（置信度与标定）**：路径后验 `c(π)=P(π|y)` 由格上前向-后向归一化；token 置信度 `c_t(z)` 为该时刻符号后验。用温度缩放/等渗回归在标定集上校准，报告 **ECE** 与 **NLL**；只有**标定后**的置信度才允许进入拒识与认证。
- **定义 241（OOV / 未知故障模型与拒识）**：增设通用 `unk` 路径，其发射用重尾分布（Student-t 或到训练流形的核距离）拟合，先验由覆盖度估计。拒识规则（代价敏感）：若 `c(π*)<1−δ_fi ∨ H(π)<H_max ∨ oov_margin<δ_oov ∨ stable_prefix_len=0`，则拒绝硬归因，输出 `unk`/ambiguous 并进入 safe-idle 或 compliant-retreat。**关键：未知故障被「拒识」而不是被「归类」。**
- **定义 242（稳定前缀发射 SPE）**：在滑动窗 W 上取 top-B 路径的最长公共前缀（LCP）；仅当该前缀连续 W 个窗不变且后验 ≥1−δ_fi 时才「说出」诊断。已说出的前缀可被二遍重打分**纠正**，但纠正需付费 `λ_retract`——把「诊断承诺」与「证据累积」解耦，正如 ASR 只在稳定时吐字。
- **定义 243（语义流二遍重打分 RSC-FL）**：实时流只跑窄束流式解码并吐稳定前缀；语义流用更宽束、更长上下文、更强 FLM（或更大的判别模型）对格做 **n-best 重打分**，产出修正轨迹。实时错误由此被事后纠正，符合 VISTA「实时只采集、语义才学习」的分流。
- **定义 244（故障下可容许控制集与解析冗余）**：给定故障路径 `π` 与估计 `φ̂`，执行器/模态集合 `U` 减去失效模态，得可容许集 `𝒰_π={u : B_πu=v_d, g_j(u,φ̂,θ_π)≤0}`；解析冗余由观测器/奇偶方程给出残差 `r=Hy−Cx̂`，供 FAM 使用并可交叉验证视觉/力通道。`𝒰_π=∅` 即该路径下任务不可行，必须降级。
- **定义 245（控制分配与重构 CA-R）**：在 `𝒰_π` 上解 `u_π* = argmin_u ‖u−u_nom‖²_W + λ_task·loss(v_d−B_πu)`；良性故障走**故障隐藏**（重构后任务不变），危险故障走**故障容纳**（按优先级丢弃任务约束/切换子目标）。重构律附**每模式证书**（Lyapunov/CBF 包络）`Cert_π`。这取代 VISTA「只膨胀球」的被动保守化。
- **定义 246（降级模式状态机 DM-FSM）**：健康模式 `M0 full / M1 force-only / M2 visual-only+compliant / M3 safe_idle/retreat`，每模式有独立认证包络 `Env(M)`。切换守卫由稳定前缀 + 格置信度给出；带滞回与驻留时间 `dwell(M)` 防抖振；模式内策略受 `Env(M)` 约束。
- **定义 247（格级认证前缀 L-CSC）**：对格中后验 ≥δ 的所有路径 `Π_δ`（含 `unk` 兜底）及各模式，寻找最小前缀 `k*` 使 `∀π∈Π_δ, ∀s≤k*: safety_margin(u_π*[s],π)≥0` 且 `P[越界]≤δ+α_chunk`。若不同路径要求**冲突控制**，则 `k*` 自动收缩到 1 或强制切 `M3`——**格越模糊，承诺越短**，这是 VISTA「长预测短执行」在轨迹格上的推广。
- **定义 248（FLaRe 证书 J_flare）**：`J_flare=(J_vista, fault_lattice_hash, best_path_confidence, oov_margin, mode_id, reconfig_cert, stable_prefix_len, aic_fl_ver)`。Valid ⇔ `Valid(J_vista)` ∧ (归因被接受 ∨ 已显式拒识并降级) ∧ `k*≥1` ∧ `mode_id` 与重构证书一致 ∧ `δ` 标定有效 ∧ 未以未标定置信度通过认证。

## 2. 关键算法骨架

```python
# FAM：多模型滤波 → 每符号发射似然（语义流 + 实时窄带）
for m in MODES:
    r, S = filters[m].innovate(y_t, u_t)        # 新息
    emission[m] = -0.5 * (r @ solve(S, r) + logdet(S))

# FLD：故障格流式束搜索（实时窄束）
lattice = beam_decode(emission, FLM, beam=B_rt, blank=BLANK)
lattice = flag_oov(lattice, unk_model, delta_oov)   # OOV 兜底路径
prefix = longest_common_prefix(lattice.topk(B))      # 稳定前缀候选

# SPE + 拒识：只在稳定且标定置信度高时「说出」诊断
conf = calibrate(path_posterior(lattice))
accepted = (conf >= 1 - delta_fi) and oov_margin(lattice) >= delta_oov
diag = prefix if accepted and stable(prefix, W) else ('unk',)

# RSC-FL：语义流宽束重打分（纠正实时错误）
lattice_refined = rescore(lattice, wide_beam=True, longer_context=True)

# CA-R + DM-FSM：按轨迹重构控制，而非只膨胀球
mode = dm_fsm.guard(diag, conf)                      # 滞回 + 驻留
u_star, feasible = control_allocate(mode, diag, phi_hat, u_nom, v_d)
if not feasible:
    u_star, mode = dm_fsm.degrade(mode, priority_goals)

# L-CSC：格级认证前缀，冲突即缩短
k_star = lattice_certified_prefix(lattice_refined, supported(delta), m_irr)
execute(u_star[:k_star]); if early_stop(): re_decode()
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（故障语言解码一致性）**：若真实故障轨迹 `π⁰` 属于 FLM 的语言（`p(π⁰)>0`）且各模式滤波正确指定，则随证据累积，`P(π⁰|y_{1:t})` 对任意竞争路径的似然比按 `exp(−t·D(π⁰‖π))` 增长；束宽 ≥ 活跃状态数时束搜索=Viterbi=精确 MAP。**解码的误差率由故障「可听度」（模式间 KL 散度）控制**，与 VISTA 的 `κ_fi` 对应但更强：它利用整条轨迹而不只是签名。
- **引理 10（OOV 拒识的标定界）**：在可交换性下，标定后的置信度阈 `δ_oov` 使未知故障误接受率 `FAR≤α_oov+ε_cal`；但该界只覆盖标定分布，对任意分布偏移有退化项 `Δ_shift`——这正是本轮风险的来源，不能声称对任意未知故障成立。
- **引理 11（格级认证前缀安全）**：若对 `Π_δ` 内每条路径（含 `unk`）都存在满足 `Cert_π` 的重构律且前 `k*` 步安全，则单块越界概率 `≤δ+α_chunk+α_vis+ε_cal`；且当路径间控制冲突时 `k*≤1`，故不会用「平均意义的控制」去执行一个「尚未定性的故障」。
- **定理 9（FLaRe 端到端解码-重构）**：在 A94–A99 下，`Valid(J_flare)` ⇒ 故障被解码或**被显式拒识**（不再强行归类）∧ 控制律按对应模式重构并满足 `Cert_π` ∧ 格级前缀安全 ∧ 良性故障被隐藏、危险故障被容纳、未知故障降级。证书链从「…-接触-归因」扩到「…-归因-解码-重构」。
- **定理 10（重构相对保守化的支配性）**：设存在冗余 `dim(𝒰_π)>0`。在已知故障模式下，控制分配可行域包含被动膨胀所对应的鲁棒可行域，且任务损失不高于后者；当无冗余时二者重合。故「重构」弱支配「只膨胀球」，但强依赖冗余存在——这是它的边界，不是免费的。
- **实时性**：FAM 新息、束搜索局部扩展、稳定前缀读出、L-CSC 早停全在实时窄带；宽束重打分、FLM 训练、重构规划、AIC-FL 全在语义流；实时预算目标仍 ≤2.5–3ms，把 FAM 滤波库裁剪为 top-2 模式 + 其余低频。

## 2. 形式化定义（完整版）

**定义 233（FLaRe 闭环）** FLaRe 是 VISTA 的「故障解码 + 可重构控制」升级：在 VISTA 的语义流/实时流骨架上挂载 FAM（多模型滤波声学）、FLM（故障语言模型）、FLD（流式故障格解码）、OOV-Reject（未知拒识）、SPE（稳定前缀）、RSC-FL（二遍重打分）、CA-R（控制分配重构）、DM-FSM（降级模式机）、L-CSC（格级认证前缀），并原位升级 FIR→FLD、ambiguous→OOV-Reject、RSC-V/WCV-V→CA-R、CSC→L-CSC、CSP-V/TSL→DM-FSM、AIC-V→AIC-FL、J_vista→J_flare。不变式：**声学/语言解码、拒识、重打分、重构规划与证书只在语义流与低频线程；实时路径只做滤波新息采集、束搜索局部扩展、稳定前缀读出、认证前缀执行与早停，零学习写操作。**

**定义 234（故障符号表与故障轨迹）** 故障符号 `z∈𝒵={∅,geo,force_drift,force_sat,model,vis,policy,unk}`；`∅` 表示健康/无可分辨故障/证据不足（blank），`unk` 表示集外故障。连续故障幅度 θ 作为符号参数（如 F/T 偏置向量、接触刚度偏差）。一条故障轨迹
π=(z_1,τ_1),…,(z_L,τ_L)，τ_i 为事件持续步数。`∅` 段不计入事件，但保留以做时长建模与起点对齐。

**定义 235（故障声学模型 FAM / 多模型滤波库）** 对每个模式 m∈𝒵\{∅} 维护一个滤波器 F_m（EKF/UKF/粒子），状态 x_t 含机器人位姿、接触几何、F/T 偏置与接触模型参数；量测 y_t 取第 65 轮的 ρ 各通道。滤波器给出预测 ŷ_{t|t−1}^{(m)}、新息 r_t^{(m)}=y_t−ŷ_{t|t−1}^{(m)}、新息协方差 S_t^{(m)}=H_tP_{t|t−1}H_tᵀ+R，发射对数似然
ℓ_t^{(m)}=−½(r_t^{(m)ᵀ}S_t^{(m)⁻¹}r_t^{(m)}+logdet S_t^{(m)})。
连续幅度以参数化网格或粒子覆盖 θ_m。FAM 只输出**似然**，不输出物理真值；与 VISTA 的静态 `p(ρ|H)` 相比，它 (i) 有动力学状态，(ii) 能跟踪漂移，(iii) 新息对偏置/模型错有明确物理含义。

**定义 236（故障语言模型 FLM）** FLM 是加权有限状态转换器 G=(𝒵̄,Q,q_0,F,δ,w)，状态 Q 为故障元状态（健康/漂移/饱和/模型/视觉/策略/未知），弧带故障符号、时长约束与对数先验代价。其转移矩阵 A_{ij}=P(z_{t+1}=j|z_t=i) 编码物理可行演化：
- `force_drift→force_sat` 合法；`force_sat→force_drift` 合法（卸载后回落）；
- `model` 只在已进入接触后允许（无接触不得出现接触模型错）；
- `vis` 可自环（间歇视觉失效），`geo` 持续性强；
- `unk` 可从任意状态进入、可自环（兜底）。
FLM 提供 p(π)=Π_i A_{z_{i-1},z_i}·Dur(τ_i|z_i)，取代 VISTA 的均匀先验。**解码图 = FLM ∘ FAM**（类比 ASR 的 HCLG），束搜索在该图上进行。

**定义 237（流式故障格）** 时刻 t 的格 𝔏_t 由束宽 B 内所有活跃部分路径 π 组成，每路径附声学分数 `Σℓ_t`、语言分数 `log p(π)` 与后验
P(π|y_{1:t}) = exp(score(π)) / Σ_{π'∈𝔏_t} exp(score(π'))。
格记录节点、弧与时间对齐，支持前向-后向计算 token 置信度 c_t(z)=P(z_t=z|y_{1:t})。格不是单一答案，而是「当前所有还说得通的故障解释」。

**定义 238（故障解码目标）** 
π* = argmax_{π∈language(G)} [ log p(y_{1:t}|π) + λ_lm log p(π) + λ_len|π| ]，
其中声学项由 FAM 累加，语言项由 FLM 给出，λ_len 惩罚过细分的稀疏故障（避免把噪声解码成大量短符号）。束搜索近似；束宽 ≥ min(活跃状态数, B) 时等于精确 Viterbi。

**定义 239（故障起点对齐与 blank）** 沿用 CTC 式 blank：`∅` 表示「不发射故障符号」。两条相邻非 blank 符号若其间无 `∅` 则合并为同一事件；符号第一次出现且后验 c_t(z)≥δ_emit 的时刻记为 t_onset(z)，事件长度 τ̂=段内步数。对齐把「何时开始坏」变成可观测变量，可直接映射到 VISTA 的 approach/touch/load 阶段，用于交叉校验阶段签名。

**定义 240（置信度与标定）** 路径后验 c(π) 由格前向-后向归一化；token 置信度 c_t(z)。在独立标定集上用温度缩放 `softmax(score/T)` 或等渗回归拟合 T / 映射，报告 ECE 与 NLL。**只有标定后的置信度才允许进入 OOV 拒识与 L-CSC 认证**；未标定分数只用于调试。

**定义 241（OOV / 未知故障模型与拒识）** 增设 `unk` 路径，发射用重尾分布：以到训练流形的马氏距离 d_unk 构造 Student-t 似然或核密度，先验由覆盖度估计 `P(unk)`（可用极值理论/一致性预测给出保守下界）。拒识规则（代价敏感）：
`reject ⇔ c(π*)<1−δ_fi ∨ H(π)<H_max ∨ oov_margin<δ_oov ∨ s_t=0`，
其中 `oov_margin = log p(π*)/p(unk)`（或等价后验差）。拒绝时输出 `unk`/ambiguous 并进入 `M3 safe_idle` 或 `M2 compliant-retreat`。**核心：未知复合故障被「拒识」，而不是被「归入最近假设」。** 拒识阈值按 `FAR/FRR` 的代价曲线选，`δ_oov` 随任务风险等级调整。

**定义 242（稳定前缀发射 SPE）** 在滑动窗 W 上取 top-B 路径的最长公共前缀 LCP；仅当 LCP 连续 W 个窗不变且 c(LCP)≥1−δ_fi 时「说出」诊断前缀（写入审计与模式机）。已说出的前缀可被 RSC-FL 纠正，但纠正需付 `λ_retract`；把「诊断承诺」与「证据累积」解耦：**没把握的部分留在格里，有把握的前缀先用于安全**。

**定义 243（语义流二遍重打分 RSC-FL）** 实时流只跑窄束（B_rt）流式解码并吐稳定前缀；语义流用宽束（B_wide）、更长上下文、更强 FLM（或判别式重打分器）对 𝔏_t 做 n-best 重打分：
score_rescore(π) = score(π) + λ_rs·f_strong(π, history)，
产出修正轨迹。符合 VISTA「实时只采集/执行，语义才学习与深度推断」的分流，且天然纠正实时窄束的局部错误。

**定义 244（故障下可容许控制集与解析冗余）** 给定故障路径 π 与估计 φ̂，执行器/模态集合 `U` 剔除失效模态（如视觉失效→视觉伺服不可用、F/T 饱和→力反馈限幅）得
𝒰_π={u : B_π u=v_d, g_j(u,φ̂,θ_π)≤0}，
`B_π` 为故障后控制分配矩阵，`v_d` 为期望任务速度/力。解析冗余由观测器/奇偶方程残差 r=Hy−Cx̂ 提供，既作为 FAM 的额外量测，也可交叉验证视觉/力通道（若两者残差同向且超出各自标定界→共因嫌疑）。`𝒰_π=∅` 表示该路径下任务不可行，必须降级。

**定义 245（控制分配与重构 CA-R）** 在 𝒰_π 上解
u_π* = argmin_{u∈𝒰_π} ‖u−u_nom‖²_W + λ_task·loss(v_d−B_πu)。
良性故障走**故障隐藏**：重构后任务不变（如小幅 F/T 偏置用零力窗标定 + 分配补偿吃掉）；危险故障走**故障容纳**：按优先级丢弃任务约束/切换子目标（如滑移风险上升→先保夹持再保轨迹）。重构律附每模式证书 Cert_π（Lyapunov 递减或 CBF 前向不变）。这取代 VISTA「只膨胀 r_geo/r_force/r_model」的被动保守化：**不是把可行域缩小，而是在剩余冗余上重新分配。**

**定义 246（降级模式状态机 DM-FSM）** 健康模式 M0 full / M1 force-only（视觉降权）/ M2 visual-only+compliant（力通道可疑）/ M3 safe_idle/retreat（归因不可信）。每模式有独立认证包络 Env(M)（力/速度/形变/滑移上界）。切换守卫由稳定前缀与格置信度给出；带滞回阈值与驻留时间 dwell(M) 防抖振；模式内策略必须满足 Env(M)。模式迁移可看作 FLM 在「控制层」的投影：诊断语言驱动控制语法。

**定义 247（格级认证前缀 L-CSC）** 对格中后验 ≥δ 的所有路径 Π_δ（含 `unk` 兜底）与各模式，求最小 k* 使
∀π∈Π_δ, ∀s≤k*: safety_margin(u_π*[s], π)≥0，
且 P[∃s≤k*: 越界]≤δ+α_chunk（沿用 VISTA conformal）。若不同路径要求**互不相容的控制**（如 π_a 要求继续接近、π_b 要求立即回退），定义冲突度 `conf(Π_δ)=max_{π,π'}‖u_π*−u_π'*‖`；冲突超阈值时 k*←1 或强制切 M3。**格越模糊、路径越冲突，承诺越短**——这是 VISTA「长预测短执行」在整条故障轨迹格上的严格推广。

**定义 248（FLaRe 证书 J_flare）** J_flare=(J_vista, fault_lattice_hash, best_path_confidence, oov_margin, mode_id, reconfig_cert, stable_prefix_len, aic_fl_ver)。验证规则：
Valid(J_flare) ⇔ Valid(J_vista)
∧ (归因被接受 ∨ 已显式拒识并进入降级)
∧ k*≥1 ∧ mode_id 与 reconfig_cert 一致
∧ 置信度已在当前域标定（标定版本匹配）
∧ 未以未标定置信度通过认证
∧ aic_fl_ver 为当前版本。
审计链新增：**说了什么故障轨迹（格哈希）、有多大把握（置信度/OOV 裕度）、为什么这样重构（reconfig_cert）、为什么只说这么短（冲突度与 k*）**。

        return out                                   # log-emission per (mode, theta)

### IP-226/227/229/243 FLD + OOV + SPE + RSC-FL

```python
class FaultLatticeDecoder:
    def __init__(self, fam, flm, unk_model, beam=16):
        self.fam, self.flm, self.unk, self.beam = fam, flm, unk_model, beam

    def decode(self, emission, lattice_prev):
        cand = []
        for path, sc in lattice_prev:                 # 局部扩展
            for z in self.flm.allowed(path.last):
                a = sc + emission.get(z, -np.inf) + self.flm.log_prior(path.last, z)
                cand.append((path.append(z), a))
            cand.append((path.append(BLANK), sc + emission.get(BLANK, 0.0)))
        cand.sort(key=lambda p: p[1], reverse=True)
        return self._normalize(cand[:self.beam])     # -> 𝔏_t

    def flag_oov(self, lattice, delta_oov):
        p_star = max(lattice, key=lambda p: p[1])
        p_unk = sum(sc for path, sc in lattice if path.last == 'unk')
        lattice.oov_margin = p_star[1] - np.log(p_unk + 1e-12)
        lattice.rejected = lattice.oov_margin < delta_oov
        return lattice


def stable_prefix(lattice, prev_prefix, W_counter):
    lcp = longest_common_prefix([p for p, _ in lattice.topk(B)])
    W_counter = W_counter + 1 if lcp == prev_prefix else 0
    return lcp if W_counter >= W else prev_prefix     # 只在稳定时说出


def rescore(lattice, history, strong_model, lam=1.0):
    return sorted(((p, sc + lam * strong_model.score(p, history))
                   for p, sc in lattice), key=lambda z: z[1], reverse=True)
```

class ReconfigurableController:
    def __init__(self, dm_fsm, qp_solver):
        self.dm, self.qp = dm_fsm, qp_solver

    def allocate(self, pi, phi_hat, u_nom, v_d, mode):
        U = admissible_set(mode, pi, phi_hat)          # 剔除失效模态
        if U.empty:
            return None, False
        u = self.qp.solve(H=W, f=-W @ u_nom,
                          A_eq=B_pi(pi), b_eq=v_d,
                          G_ineq=constraints(U), h_ineq=bounds(U))
        feasible = safety_margin(u, pi) >= 0
        return u, feasible

    def step(self, diag_prefix, conf, pi_star, phi_hat, u_nom, v_d):
        mode = self.dm.guard(diag_prefix, conf)        # 滞回 + 驻留
        u, ok = self.allocate(pi_star, phi_hat, u_nom, v_d, mode)
        if not ok:
            mode = self.dm.degrade(mode)               # 故障容纳：丢任务保安全
            u, ok = self.allocate(pi_star, phi_hat, u_nom, v_d, mode)
        return mode, u, ok, Cert(mode, pi_star)

### IP-232 L-CSC（格级认证前缀）

```python
def lattice_certified_prefix(lattice, delta, m_irr, alpha_chunk):
    support = [p for p in lattice if path_posterior(p) >= delta]   # 含 unk 兜底
    u_by_path = {p: reconstruct(p) for p in support}
    conflict = max_pairwise_spread(u_by_path.values())
    k_best = 0
    for k in range(1, min(m_irr, len(lattice.best_path)) + 1):
        if conflict > TAU_CONFLICT:
            return 1 if k == 1 else 0                # 路径冲突 -> 只承诺一步
        if not all(safety_margin(u_by_path[p][k-1], p) >= 0 for p in support):
            break
        if violation_prob(lattice, k) <= alpha_chunk:
            k_best = k
        else:
            break
    return k_best
```

## 4. 推导

**引理 9（故障语言解码一致性）** 设真实故障轨迹 π⁰ 满足 p(π⁰)>0（在 FLM 语言内），各模式发射模型正确指定，且不同轨迹的声学分布可区分。则在格上
log P(π⁰|y_{1:t}) / P(π|y_{1:t}) = log p(π⁰)/p(π) + Σ_{s≤t}[ℓ_s(π⁰)−ℓ_s(π)]，
第二项按大数定律以速率 D(p_{π⁰}‖p_π) 线性增长（D 为模式间 KL 散度，含新息分布）。故错误路径的后验质量以 exp(−t·min_{π≠π⁰}D(π⁰‖π)) 衰减，只要该 KL 为正。当束宽 B 不小于格中活跃状态数时束搜索与 Viterbi 精确等价，故解码误差由「故障可听度」（模式间 KL）控制。与 VISTA 的 κ_fi 相比，这里用的是**整条轨迹的累计可听度**而非单时刻签名对比度——这正是利用顺序结构带来的增益。∎

**引理 10（OOV 拒识的标定界）** 设标定集与测试集可交换，置信度 c 已校准至 ECE≤ε_cal。取拒识阈 δ_oov，则对属于标定分布的未知故障，误接受率
FAR ≤ α_oov + ε_cal，
其中 α_oov 由 `oov_margin<δ_oov` 的标定分位数确定；误拒率 FRR 同理由已知故障的置信度下尾确定。该保证**只在可交换性下成立**：对任意分布偏移，界退化为 FAR ≤ α_oov + ε_cal + Δ_shift，其中 Δ_shift 是重尾/语法外故障相对标定分布的偏离。**因此不能声称对任意未知故障成立，只能声称对「落在 unk 模型覆盖内」的故障成立**——这是定义 241 与 AIC-FL 的适用边界，也是第 5 节风险的数学来源。∎

**引理 11（格级认证前缀安全）** 设 k*≤m（不可逆视界）。对格中后验 ≥δ 的每条路径 π（含 `unk`），L-CSC 已验证前 k* 步存在满足 Cert_π 的重构律且 safety_margin≥0；不在支持集内的路径总后验 ≤δ。视觉 conformal 以 ≥1−α_vis 覆盖、置信度标定误差 ≤ε_cal。由联合界，
P[块内越界] ≤ δ + α_chunk + α_vis + ε_cal。
路径冲突时 k*≤1，意味着「在诊断未定性的那一步之后立刻重新解码」，因此不会用混合/平均控制去执行一个未定性故障，避免「平均两个相反动作=T 字路口相撞」。故格级承诺不引入超出单步安全的新风险。∎

**定理 9（FLaRe 端到端解码-重构）** 在 A94–A99 下：
1. **故障可解码**：三阶段被激励且 FLM 含真轨迹时，`P(π⁰|y)` 集中（引理 9），解码误差由模式间 KL 控制；诊断带起点对齐与持续时长。
2. **未知可拒识**：`unk` 路径 + 标定置信度使未知复合故障在覆盖范围内被拒识而非归类（引理 10），直接对冲 VISTA 风险 #1。
3. **控制可重构**：CA-R 在可容许集 𝒰_π 上做控制分配，良性故障被隐藏、危险故障被容纳；只在无冗余时退化为 VISTA 式保守化（定理 10）。
4. **承诺随格熵自适应**：L-CSC 的 k* 随 Π_δ 的冲突度单调不增（引理 11），模糊/冲突时收缩到单步或 M3。
5. **证书六层链**：Valid(J_flare) ⇔ VISTA 有效 ∧ 归因被接受或显式拒识 ∧ 已重构并满足 Cert ∧ k*≥1 ∧ 置信度已标定 ∧ 模式一致。
6. **优雅降级**：视觉失效→M1 力主导；F/T 饱和→M2 视觉/柔顺主导；两者共因失效→`unk` 拒识→M3 safe_idle；未知语法外故障→OOV 拒识 + 保守重构。
7. **实时性**：实时窄带 ≤3ms，零学习写操作（A100）。∎

**定理 10（重构相对保守化的支配性）** 设故障模式已知，且存在冗余使 `dim(𝒰_π)>0`。VISTA 的被动策略在膨胀球 `B(φ̂,r)` 上求鲁棒可行控制，等价于在「所有可能 φ∈B 都安全」的约束下最小化任务损失；CA-R 则在真实（或高后验）故障参数 φ_π 对应的 𝒰_π 上优化。因 𝒰_π 基于比 `B(φ̂,r)` 更紧的后验支持，其可行任务集包含被动鲁棒可行集，且任务损失不高于后者（约束更少、目标相同）。当 `dim(𝒰_π)=0`（无冗余或执行器全失效）时二者重合。故**重构弱支配「只膨胀球」，但支配性完全来自冗余与更准的后验**——若后验错误或冗余不存在，重构可能给出错误控制，这是适用条件而非普适结论。∎

**命题（格熵与承诺长度的关系）** 设 Π_δ 的冲突度 `conf(Π_δ)` 随格熵 H(π) 单调不减（路径越多、越分散，最优控制越分散）。L-CSC 的 `k*(Π_δ)` 在冲突超阈值时为 1，否则由 conformal 越界预算决定且随支持集扩大单调不增。故 `∂k*/∂H ≤ 0`：**越不确定，越不该长承诺**。这把 VISTA 的定理 8（H 与 k 解耦）从「块长」推广到「故障轨迹格」：预测仍可长（H 用于前瞻），但执行承诺由**诊断格**而非仅由不可逆视界决定。∎

## 7. 已知风险

**一句话**：FLaRe 的置信度、OOV 拒识与格级认证全部以「故障语言模型与多模型声学库对真实故障流形是良定的、且未知故障落在 `unk` 模型可标定的覆盖内」为前提；一旦真实故障**违反语法**或声学滤波库被系统性错配，解码器会以**高标定置信度**吐出一段「语法自洽但物理错误」的故障叙事，而 CA-R 又会恰好为这段错误叙事完成认证重构——**语音识别的「自信地听错」与容错控制的「按错模式重构」相乘**，形成比 VISTA「强行归类」更隐蔽、更难被日志审计发现的复合失效。

**次级风险与缓解**：
1. **故障语法不完备（语法外故障）**：FLM 的 `LEGAL` 转移是人工/数据驱动写死的，真实故障可违反；缓解：`unk` 路径 + 语法外检测（束内最高分路径若频繁需要非法转移则触发拒识）、持续扩充语法、用数据学习转移而非硬编码。
2. **声学库系统性错配**：多模型滤波共享同一简化接触/动力学模型，错配是共因的；缓解：解析冗余交叉检查、新息白度检验（χ²）、在线重标定、把模型误差本身作为一个模式 `model` 纳入。
3. **置信度在分布偏移下过度自信**：ASR 的经典失败；缓解：在线 ECE 监控、温度重标定、拒绝域随漂移放宽、conformal 只在可交换窗内声称。
4. **`unk` 模型的覆盖不可证**：重尾/核密度只能覆盖见过的流形；缓解：把 `unk` 当「必须降级」而非「可安全归类」，AIC-FL 只在有界干扰集上给 FAR 界，绝不外推为普适保证。
5. **格级认证的组合爆炸**：|Π_δ| 可能很大；缓解：只对 top-|Π_δ| 做认证、其余质量计入 δ；冲突度用上界近似；把 `unk` 作为单一路径。
6. **重构依赖冗余**：无冗余时退化为被动容错；缓解：明确定义 `dim(𝒰_π)=0` 时走 DM-FSM 降级，不假装能重构。
7. **实时预算**：FAM 多模式 + 束搜索逼近 3ms；缓解：top-2 模式、幅度网格共享、事件触发更新、语义流卸载宽束与重打分。
