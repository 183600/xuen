# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；新灵感循环第 1 轮；本轮灵感：「对话管理」×「机器人操作系统」）

> 第 60 轮把「场景→意图→约束→阻抗→执行→EV-exec→场景更新」闭合成 SGEC，并让场景先验、意图约束、消息隔离共同为执行证据服务。但它仍把两件本质上是**分布式、有时效、可协商**的东西压成了本地静态对象：
> 1. **对话被压成一次性意图标签**：CIEC 的 φ_lock 把「慢点」锁成约束，却没有 TTL、没有撤回、没有续约，也没有区分「收紧」与「放松」。一句已撤回或已过期的话，仍可能在下一次动作中生效；而「放松」比「收紧」危险，却被同等对待。
> 2. **ROS 被当成可靠传输管道**：EPIR 只解决 EV-exec 的到达与顺序，却没有解决**约束本身在多节点间的一致视图**。对话节点、规划节点、安全节点、执行节点各自维护 K，ROS 2 的异步、乱序、可丢包与 QoS 差异会让某一节点用旧约束驱动执行——这是分布式「约束脑裂」。
> 3. **权威关系未形式化**：场景先验、人的指令、安全核谁大谁小没有定义。人的一句「快点」能否覆盖湿滑地面的场景先验？没有一个不可绕过的安全核，就没有可审计、可证明的安全。

## 0. 直觉与动机

**灵感 1（对话管理 → 话语即租约 DL）**
直觉：话语不是「设置一个变量」，而是**对执行权限的一次有期限授权**。「慢点」不应永久改写 v_max，而应产生一份租约：`(谁说的, 权限等级, 约束区域, 生效时刻, TTL, 续约/撤回条件)`。租约到期不是「恢复上一句话」，而是**回落到认证安全的默认基线 K_base**。这样既避免陈旧意图长期生效，也避免「撤回时不知道该恢复到哪一版约束」。关键洞见：**把对话管理的承诺（commitment）与分布式系统的租约（lease）合并**——承诺有语义，租约有生命周期。

**灵感 2（ROS → 承诺一致切 CLC）**
直觉：ROS 2 里没有全局时钟，也没有天然的全序。执行节点在按下动作前，必须能回答：「我看到的约束集合，是不是所有因果上在先的承诺都已经包含进来的一个**一致切**？」用向量时钟记录 ISSUE/RENEW/RETRACT/EXPIRE/COMMIT/ACTUATE 事件，执行只允许发生在承诺日志的一个**因果下闭集**上。关键洞见：**不能让执行节点各自拼一个约束视图；要证明它用的那个视图是一个一致切。**

**灵感 3（ROS QoS → 收紧/放松双平面 QC）**
直觉：ROS 2 的 QoS 不是性能参数，而是**安全契约的一部分**。以保守基线 K_base 为锚，**收紧**是往安全域内部走，**放松**是朝边界走，因此两类消息应走不同平面：T-plane（Tighten）允许单阶段应用，因为 meet 可交换、幂等、结合，乱序只导致更保守；L-plane（Loosen）必须 RELIABLE + TRANSIENT_LOCAL + 法定确认 + 因果覆盖证明，因为一条迟到的放松可能直接越过安全边界。关键洞见：**缺消息时的默认姿态必须安全**——丢一条收紧只是少保守一点（仍不低于 K_base），丢一条放松则必须保持更紧。

**灵感 4（冲突 → 约束格与权威仲裁 SKA）**
直觉：场景说「湿滑，慢」，人说「赶时间，快」，安全核说「绝对上限」。三者不是投票，而是**约束格上的交（meet）与带权限的放松**。任一已认证来源都可以收紧；要放松某条约束，必须权限等级不低于原约束、显式指名被放松的租约、并经过安全节点确认。若两个约束交集为空，系统不应擅自选一个，而应**停止动作并请求澄清**。关键洞见：**收紧无需授权，放松必须授权；无解即停，不做猜测。**

**灵感 5（安全 → 不可绕过的安全核 K_env）**
直觉：安全核不应是「最高优先级的一条约束」，而应是**执行授权的前置条件**。执行节点每次动作都需要安全节点签发一枚短 TTL 的「动作许可」（grant），许可里绑定当前一致切与 K_act。没有许可，只能执行硬停或安全基线内的最小动作。关键洞见：**把安全从「消息内容」提升为「授权通道」**——即使对话节点被攻破、消息被伪造，没有安全节点签名也无法越过 K_env。

**灵感 6（合流 → 分布式对话承诺平面 DDCP + PCE++++++）**
直觉：第 60 轮 SERC 负责「场景-阻抗-执行」；本轮在其上叠加「对话-承诺-授权」层：
`话语 → 租约 → T-plane/L-plane → 一致切 → 安全仲裁 → 动作许可 → EEIS/ERTC → EV-exec → 租约-证据证书`。
预算从四维认知预算扩展为**六维** `B_dialog/B_lease/B_ros2/B_scene/B_intent/B_exec`；任一耗尽都只能让系统更保守（fail-closed），任何降级都不得绕过安全核与授权检查。

```
 [operator console] --utterance--> [dialogue / lease manager]
                                        |  T-plane: 收紧, 单阶段, meet
                                        |  L-plane: 放松, prepare/commit + quorum
                                        v
 [scene SSM] --先验--> [commitment bus / consistent cut] <--先验-- [task planner]
                                        |
                                        v
                              [safety node / K_env]
                                        |  grant (TTL ≈ 1 control cycle)
                                        v
                              [EEIS/ERTC executor] --> EV-exec --> [EPIR]
```

## 1. 形式化定义（增量：定义 161–168）

**定义 161（对话承诺租约 DL）** 一份租约是一个七元组
`L = (ℓ_id, u_id, issuer, ρ, mode, C_L, supersedes, t0, TTL, proof)`。其中：
- `u_id` 为接地后的话语事件；`issuer` 为说话者/节点；`ρ ∈ {4:safety, 3:scene, 2:human, 1:task}` 为权限等级；
- `mode ∈ {TIGHTEN, LOOSEN}`；`C_L ⊆ ℝ⁵` 为对 `(v_max, F_max, K_p, K_d, ε_traj)` 的约束区域；
- `supersedes ⊆ ℓ_id` 为被本租约显式放松/替换的租约集合；`TTL` 为有效期；`proof` 含认证、接地与签名。
- **有效**：`Valid(L,t) ⇔ t < t0 + TTL ∧ Ver(proof) ∧ Integrated(L)`。
- **安全包络与基线**：`K_env` 为不可变硬上限（仅由安全节点签名收紧）；`K_base ⊆ K_env` 为**认证安全的保守默认基线**。
- **活跃约束**：
```
Relaxed(t) = { ℓ : ∃L'∈Active(t), L'.mode=LOOSEN, L' 已提交,
                    ℓ∈L'.supersedes, ρ_{L'} ≥ ρ_ℓ }
K_act(t)   = K_env ∩ ⋂_{L ∈ Active(t) \ Relaxed(t)} C_L
```
未被任何活跃租约约束的维度，一律取 `K_base` 的边界。
- **语义**：`TIGHTEN` 只能让 `K_act` 变小（更保守）；`LOOSEN` 只有在其放松的租约被 `Relaxed` 移除后才生效。租约到期只移除该租约，**回落到 K_base，而不是回落到上一句更松的话**。

**定义 162（承诺日志与一致切 CLC）** 每个节点 i 维护事件日志 `ℒ_i` 与向量时钟 `V_i ∈ ℕ^n`。事件
`e ∈ {ISSUE, RENEW, RETRACT, EXPIRE, COMMIT, ACTUATE}`，记 `V(e)`。
- **因果序**：`e → f ⇔ V(e) < V(f)`（逐分量 ≤ 且至少一分量严格）。
- **承诺切**：执行事件 `a` 处的切 `Cut_i(a) = {L : COMMIT(L) → a}`。
- **一致切**：`Cut_i(a)` 是一个因果下闭集，且对每个被放松的租约维度，包含其最新的、因果上在 `a` 之前的放松决定；换言之，不存在 `L'∈Cut_i(a)` 满足 `L'` 已提交却缺失其被放松的对象。
- **收敛界**：若 QoS 截止期 `δ_q` 满足且无分区，则任一提交事件在 `τ_cut ≤ δ_q + ε_sched` 内被所有活跃节点纳入切。
- **执行规则**：`ACTUATE` 只允许携带一个一致切；否则拒绝执行（fail-closed）。

**定义 163（ROS 2 QoS 契约 QC 与双平面）** 约束消息的 QoS 是安全契约
`Q = (Rel, Dur, Hist, Depth, Deadline, Liveliness, TTL_margin)`。
- **T-plane（收紧）**：`RELIABLE`（优选）/`BEST_EFFORT` 均可，`KEEP_LAST(1)`，`Deadline=δ_t`。单阶段 `apply-on-receive`，不要求 quorum。理由：meet 可交换、幂等、结合，乱序只导致更保守；且缺失的收紧不会低于认证基线 `K_base`。
- **L-plane（放松）**：`RELIABLE` + `TRANSIENT_LOCAL` + `KEEP_ALL until ACK`，`Deadline=δ_l`；必须两阶段 `prepare → quorum ACK → commit`，且 `V_commit ≻ V_conflict`（因果覆盖被放松的旧约束）。
- **失效规则**：若 Deadline 错过或 Liveliness 丢失超过 `τ_live`，节点进入 `DEGRADED`：忽略一切 LOOSEN、回落到 `K_env ∩ K_base`，只接受 T-plane 收紧。
- **保守时钟**：TTL 必须满足 `TTL_margin > 2·max_skew + τ_cut`，时钟取单调时钟。

**定义 164（安全核仲裁 SKA）** 给定活跃租约集 `𝓛`、场景先验 `π_scene` 与基线 `K_base`：
```
Arbitrate(𝓛) =
  若 ∃ 两租约 C_{L1} ∩ C_{L2} = ∅（在其共同作用维度上）:
      返回 (∅, CONFLICT)               # 无解即停，请求澄清/升级
  否则:
      K_act = K_env ∩ (⋂_{L∈𝓛\Relaxed} C_L)，
      未约束维度取 K_base
      返回 (K_act, OK)
```
- **权限规则**：收紧接受任意已认证来源；放松要求 `ρ_{L'} ≥ ρ_ℓ` 且 `ℓ ∈ L'.supersedes`。
- **安全核不可绕过**：`K_env` 只能由安全节点以签名事件收紧，任何对话租约都不能扩大它。
- **动作许可**：执行前须由安全节点签发 `grant = Sign(safety, (V_cut, K_act, t0, TTL_g))`，`TTL_g ≤ 一个控制周期`。无有效 grant ⇒ 只能硬停/最小安全动作。

**定义 165（租约-证据联合证书 LEC）** 每次执行动作 `a` 生成
`Cert(a) = (ℓ_ids, V_cut, Q_ack, π_env: K_act ⊆ K_env, Com(EV-exec), Sig_safety)`。
审计者可独立验证五件事：
1. 每个 `ℓ_id` 的 `proof` 有效且在 `a` 时刻未过期；
2. `V_cut` 是一致切，且所有放松均有因果覆盖与 quorum；
3. `Q_ack` 满足 `δ_l/δ_t`（或明确记录了 DEGRADED 模式）；
4. `K_act ⊆ K_env`（安全核未被绕过）；
5. `Com(EV-exec)` 与本地影子副本/EPIR 中的证据一致。

**定义 166（分布式对话承诺闭环 DDCP）** 算子 `DDCP(M, u, obs, δ_f_req)`：
```
① α ← speech_act(u)                         # directive/confirm/retract/assertive
② L ← lease_manager.issue_or_update(α)      # 生成 TIGHTEN 或 LOOSEN 租约
③ if L.mode = LOOSEN:
       commitment_bus.prepare(L) → quorum ACK → commit(L)   # L-plane
   else:
       commitment_bus.publish(L)                             # T-plane, apply-on-receive
④ Cut ← commitment_bus.consistent_cut(M.node, now)
⑤ K_act, conflict ← safety_kernel.arbitrate(Cut, π_scene, K_base)
⑥ if conflict or K_act=∅: return ASK_OR_DEGRADE
⑦ grant ← safety_kernel.request_grant(V_cut, K_act)          # TTL ≈ 1 cycle
⑧ if grant invalid/expired: return HARD_STOP_OR_BASE
⑨ K_safe ← EEIS.compile(δ_f_req, K_act); execute(K_safe, grant)
⑩ EV-exec ← build_exec_evidence(...); EPIR.append(EV-exec)
⑪ Cert ← build_LEC(ℓ_ids, V_cut, Q_ack, K_act, EV-exec)
⑫ lease_manager.renew_or_expire(); return (K_act, EV-exec, Cert, mode)
```

**定义 167（六维预算 PCE++++++）** `B = (B_dialog, B_lease, B_ros2, B_scene, B_intent, B_exec)`：
- `B_dialog = (turn_latency, clarification_budget, ASR/NLU_ops)`
- `B_lease = (active_lease_cap, TTL_refresh_ops, log_window)`
- `B_ros2 = (deadline_slack, DDS_queue, retransmit_budget, discovery_budget)`
- `B_scene/B_intent/B_exec` 沿用第 60 轮。
```
voi_ddcp(L) = VOI_meta_pessimistic(L) − cost_dialog(L) − cost_lease(L) − cost_ros2(L)
cost_ros2   = λ_d·max(0, p99_latency−δ_l) + λ_q·queue_overflow + λ_r·retransmits
```
降级规则（全部 fail-closed）：
- `B_ros2` 耗尽 ⇒ DEGRADED：只保留 T-plane，忽略 LOOSEN；
- `B_lease` 耗尽 ⇒ 停止签发新租约，现有租约到期即回落 K_base；
- `B_dialog` 耗尽 ⇒ 拒绝新指令，仅接受确认/撤回；
- `B_scene/B_intent/B_exec` 耗尽 ⇒ 沿用第 60 轮对应降级，但**不得绕过 grant 与 K_env**。

**定义 168（分区容忍降级 DLD）** 网络分区/节点失联时：
- 本地已提交的 TIGHTEN 继续有效直至 TTL；所有未获 quorum 的 LOOSEN **不得提交**；
- 安全节点不可达 ⇒ 执行节点进入 DEGRADED，`K_act ← K_env ∩ K_base`，只接受本地已认证收紧；
- **分区安全序**：`K_act^partition ⊆ K_act^pre-partition`（分区只会更保守，绝不更松）；
- 恢复后按向量时钟重放日志，丢弃不满足因果覆盖的 LOOSEN，重新签发 grant。

### IP-161 对话承诺租约管理器

```python
class DialogueLeaseManager:
    def __init__(self, safety, k_base, now):
        self.safety = safety
        self.k_base = k_base
        self.leases = {}
        self.relaxed = set()
        self.seq = 0

    def issue_or_update(self, act, issuer, rank):
        if act.type == 'retract':
            for lid in act.targets:
                if rank < self.leases[lid].rank:
                    return None                      # 权限不足，拒绝放松
            L = Lease(seq=self._next(), mode='LOOSEN',
                      C_L=act.region, supersedes=act.targets,
                      rank=rank, t0=now(), ttl=act.ttl)
            return self._submit_loosen(L)            # 走 L-plane
        if act.type in ('directive', 'confirm'):
            L = Lease(seq=self._next(), mode='TIGHTEN',
                      C_L=act.region, supersedes=[], rank=rank,
                      t0=now(), ttl=act.ttl or DEFAULT_TTL)
            self.leases[L.id] = L
            return L                                  # 走 T-plane
        return None                                   # assertive/expressive 不改约束

    def active_constraints(self, t, cut):
        act = [L for L in self.leases.values()
               if L.id in cut and L.valid(t) and L.id not in self.relaxed]
        return act

    def _submit_loosen(self, L):
        acks = self.safety.prepare_loosen(L)          # 两阶段
        if acks.quorum and acks.dominates_conflicts(L):
            self.leases[L.id] = L
            self.relaxed |= set(L.supersedes)         # 仅提交后才放松
            return L
        return None                                   # 保持更紧，fail-closed
```

### IP-162 承诺总线与一致切

```python
class CommitmentBus:
    def __init__(self, node_id, n_nodes):
        self.i = node_id
        self.vc = [0] * n_nodes
        self.log = []

    def publish(self, event, plane):
        self.vc[self.i] += 1
        self.log.append(Event(event, clock=tuple(self.vc), plane=plane))
        if plane == 'L':
            return self._two_phase_commit(event)
        return True

    def consistent_cut(self, node, now):
        seen = self._events_visible_to(node)
        cut = []
        for e in seen:
            if e.kind == 'COMMIT' and e.clock <= tuple(self.vc):
                cut.append(e.lease_id)
        # 只保留因果下闭集中的最新提交；缺失被放松对象则判为不一致
        return Cut(ids=cut, vc=tuple(self.vc),
                   consistent=self._is_down_set(cut, seen))

    def _two_phase_commit(self, L):
        self.safety.prepare(L)
        acks = self._collect_acks(L)                  # 需 quorum + V_commit ≻ V_conflict
        if acks.quorum and acks.causally_covers(L.supersedes):
            return self.publish(Event('COMMIT', lease_id=L.id), plane='T')
        return False
```

### IP-164 安全核仲裁与动作许可

```python
class SafetyKernel:
    def __init__(self, k_env, k_base):
        self.k_env, self.k_base = k_env, k_base

    def arbitrate(self, leases, scene_prior, t):
        active = [L for L in leases if L.valid(t)]
        for a in active:
            for b in active:
                if disjoint(a.C_L, b.C_L, dims=a.scope & b.scope):
                    return None, 'CONFLICT'            # 无解即停
        k = self.k_env & self.k_base
        for L in active:
            k &= L.C_L
        return k, 'OK'

    def request_grant(self, v_cut, k_act, now):
        if not subset(k_act, self.k_env):
            return None                                # 安全核不可绕过
        return Grant(v_cut=v_cut, k_act=k_act,
                     t0=now, ttl=CONTROL_PERIOD,
                     sig=sign(self.key, (v_cut, k_act, now)))
```

def build_lec(active, v_cut, q_ack, k_act, ev_exec, safety):
    return {
        'leases': [L.id for L in active],
        'vc': v_cut,
        'qos': q_ack,
        'env_proof': prove_subset(k_act, safety.k_env),
        'ev_commit': hash(ev_exec),
        'mode': 'DEGRADED' if q_ack.degraded else 'NORMAL',
        'sig': safety.sign((v_cut, k_act, ev_exec))
    }

def verify_lec(cert, ev_exec, safety):
    return (all_valid_and_unexpired(cert.leases) and
            is_consistent_cut(cert.vc) and
            cert.qos.ok_or_degraded() and
            verify(cert.env_proof, cert.sig, safety) and
            cert.ev_commit == hash(ev_exec))

class DdcpBudget:

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DL | O(1)/话语 | O(\|𝓛\|) | 租约 TTL 精确；放松需授权 |
| CLC | O(\|log\|)/切 | O(n + \|log\|) | 一致切为因果下闭集 |
| QC | O(1)/消息 | O(queue) | 截止期/存活丢失即 DEGRADED |
| SKA | O(\|𝓛\|²) 冲突检查 | O(1) | `K_act ⊆ K_env` 恒成立 |
| LEC | O(1)/动作 | O(1) | 五元审计可判定 |
| DDCP | O(闭环) | 复用 | 无许可不动作 |

**正确性定理（SKN-DDCP）**：假设
- **A66**：`K_base` 经认证安全，`K_env` 不可变且只由安全节点签名收紧；
- **A67**：所有租约均已认证，安全节点可信；
- **A68**：各节点使用单调时钟，且 `TTL_margin > 2·max_skew + τ_cut`；
- **A69**：L-plane 在 quorum ACK 与因果覆盖证明齐全前不提交；
- **A70**：grant 的 TTL ≤ 一个控制周期，且缺失时 fail-closed。
则：
1. **安全核不可绕过**：对任意可采纳消息序列，`K_act(t) ⊆ K_env`；不存在对话路径能扩大 `K_env`。
2. **租约安全**：任何 `ACTUATE` 都携带有效 grant 与一致切；过期租约不会继续生效，且到期只回落到 `K_base`。
3. **放松因果性**：一条 LOOSEN 只有在因果上覆盖其所放松的约束、并获得 quorum 后才生效；迟到的放松不能覆盖更新的收紧。
4. **分区安全**：分区期间 `K_act^partition ⊆ K_act^pre-partition`，恢复后不一致的 LOOSEN 被重放丢弃。
5. **可审计性**：若 `verify_lec(Cert(a))=1`，则动作 `a` 在一致切与安全核内被授权，且 EV-exec 与证据链一致。

## 4. 实验设计 E192–E196

| 实验 | 指标 | 目标 |
|---|---|---|
| E192 租约生命周期 | 撤回/到期后的陈旧执行率；TTL 误差 | 陈旧执行率 = 0；TTL 误差 ≤ 10ms |
| E193 双平面对比 | T-plane 收敛 p99；L-plane 提交 RTT；deadline miss | T p99 ≤ 20ms；L RTT ≤ 100ms；miss ≤ 1e-3 |

## 5. 本轮最大风险

**一句话**：整套方案把安全性寄托在「安全节点 + 单调时钟 + TTL 余量」上——一旦安全节点成为单点故障，或 ROS 2 节点间时钟漂移超过 TTL 余量，就会在保守侧退化为全局冻结（fail-closed 的可用性灾难）、在极端乱序下退化为陈旧放松（安全性灾难）；必须以双通道安全节点、硬件看门狗、保守 TTL 与「无授权即不动作」的默认姿态兜底。

    down = causal_down_set(visible)

def arbitrate(self, leases, t):
    active = [L for L in leases if L.valid(t)]
    if any(disjoint(a.C_L, b.C_L, dims=a.dims & b.dims)
           for a in active for b in active if a is not b):
        return None, 'CONFLICT'
    k = self.k_env & self.k_base
    for L in active:
        if L.mode == 'TIGHTEN' or L.committed:
            k &= L.C_L
    return k, 'OK'

def request_grant(self, cut, now):
    if not subset(cut.k_act, self.k_env):
        return None
    return Grant(cut.vc, cut.k_act, now, ttl=CONTROL_PERIOD,
                 sig=self.sign((cut.vc, cut.k_act, now)))

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 保证 |
|---|---|---|---|
| DL | O(1)/话语 | O(\|𝓛\|) | TTL 精确、放松需授权 |
| CLC | O(\|log\|)/切 | O(n+\|log\|) | 一致切 = 因果下闭集 |
| QC | O(1)/消息 | O(queue) | 失效即 DEGRADED |
| SKA | O(\|𝓛\|²) | O(1) | `K_act ⊆ K_env` |
| LEC | O(1) | O(1) | 五元可判定审计 |
| DDCP | O(闭环) | 复用 | 无许可不动作 |

**定理（SKN-DDCP）**：在 A66–A70 下，
1. `∀t: K_act(t) ⊆ K_env`（安全核不可绕过）；
2. `ACTUATE ⇒ 有效 grant ∧ 一致切`（租约安全）；
3. `LOOSEN` 生效 ⇒ quorum ∧ 因果覆盖（放松因果性）；
4. 分区期间 `K_act^partition ⊆ K_act^pre-partition`（分区只收紧）；
5. `verify_lec=1 ⇒` 动作在一致切与安全核内被授权且证据一致（可审计性）。

**证明要点**：
- (1) `K_act` 的定义始终含 `∩K_env`；`K_env` 只能由安全节点签名收紧；LOOSEN 的 `C_L` 也要与 `K_env` 相交；grant 前再次检查 `subset(K_act,K_env)`。
- (2) 执行入口唯一，且入口先验 `consistent_cut` 与 `request_grant`；grant TTL ≤ 控制周期，过期即拒。
- (3) L-plane 在 `prepare` 阶段不修改 `relaxed`，只有 `commit` 且 quorum + `vc_dominates(supersedes)` 后才移除旧约束；迟到 LOOSEN 的 `vc` 不满足支配关系，被一致切判定拒绝。
- (4) 分区时未提交 LOOSEN 全部丢弃，`K_act` 回落 `K_env ∩ K_base`；本地 TIGHTEN 只会进一步取交，因此只会更保守。
- (5) LEC 五元组分别由租约证明、向量时钟、QoS ACK、`subset` 证明与哈希承诺构成，验证器逐项可判定。
