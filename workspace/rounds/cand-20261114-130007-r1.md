# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配主动交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「多机器人协作」×「数据采集」）

> R69 给系统装上了一张嘴：面对可约的歧义（epistemic），它不再只会踩刹车，而会看、会触、会问。但 R69 隐含了一个孤独的假设——**只有一个决策者，且它问的每个来源都彼此独立**。一旦把系统放进机器人编队，这两条同时失效：
> - **多机器人协作**让「问同伴」成为最便宜的信息动作（同一场景、另一个视角、已经看过的人），但同伴不是独立证据：它们共享传感器型号、共享训练 checkpoint、共享标定窗口、共享通信链路、共享同一个世界。二十台机器人可能只提供**一份**证据，却投出二十票。R69 的「k 个正交证据源一致」在编队里会退化成「k 份相关的同义反复」——**共识被误当成真理（groupthink / Byzantine capture）**。
> - **数据采集**让 R69 的每次交互都变成宝贵数据（观测、问句、回答、结果）。可 R69 立过铁律：实时环零学习写操作。于是数据只能**采而不学**。问题从「问谁」变成「这些数据放哪、谁能信、何时才允许它进控制器」。若把被污染/相关的共识数据直接喂回模型，等于给 R69 那句「问错比不问更危险」再加一条：**把错的学进去，比问错更危险**。
>
> 核心命题：**把「信息源」与「数据资产」彻底分开。同伴回答只在被相关性折扣、经 k_eff 门控后才算证据；原始交互日志只进隔离区，经溯源、清洗、离线认证、换装后才可能影响控制器。协作不得制造虚假置信，采集不得污染在线控制。** 命名 **SWARM-RAS**（Shared-World Active Resolution & Multi-source harvesting with correlated-evidence discipline）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我们之中谁真正独立，而采到的数据最终去了哪里**」——协同不是把票数相加，而是把独立性算清；采集不是边跑边学，而是先封存、再认证、后换装。

## 0. 直觉与动机

**灵感 1（多机器人协作 → 「问同伴」是信息动作，但独立不是免费的）**
直觉：R69 的 MINT 在 {注视、探针、问句} 里选信息动作，默认对手是环境或人。放进编队后，最省力的信息动作常常是「问另一台已经看过那里的机器人」：它有互补视角、有历史观测、能替你先探一下。把 `g_peer` 并入增广动作空间几乎不需要新理论。真正致命的是另一面：R69 用「k 个正交证据源一致」来约束单次交互不得定案，可这个纪律**默认了独立性**。编队里，两台机器人如果同型号相机、同一个 checkpoint、同一标定窗、站在相邻位置，它们的误差是**相关**的：一致地错、自信地错。于是「多个来源」只是把一个错误复制了 n 份——投票数涨了，信息量没涨，甚至因为 n 大而更自信。所以本轮第一件事，是把「数来源」换成「估独立性」。

**灵感 2（数据采集 → 数据先是负债，才是资产）**
直觉：R69 的每次「看/问/触」都产出高价值样本：观测、查询、回答、结果、甚至失败。这是天然的主动学习数据流。但 R69 的红线是实时环零学习写操作——不能让部署数据当场改策略，否则不可复现、可被投毒、可能在线崩坏。正确姿态不是「边跑边学」，而是**采而不学**：只追加带出处的日志，进隔离区；离线去相关、去毒、训练；通过认证换装才允许上线。这带来一个新的价值函数：**数据价值 D(g) ≠ 决策价值 VoI(g)**。为「未来更准」去采集，绝不能把机器人推出当前安全包络；数据的收益是延迟的，风险却是即时的。

**灵感 3（相关性 → k_eff 取代 n，R69 是 ρ=0 的退化）**
直觉：若 n 个来源成对相关 ρ̄，其等效独立样本数是 `k_eff = n/(1+(n−1)ρ̄)`（Kish 设计效应）。ρ̄→1 时无论 n 多大 k_eff→1；ρ̄→0 时 k_eff=n。这就是 R69「k 个正交源」的严格推广：R69 只是 ρ=0 的特例。所有置信、共识门、VoI 折扣都改用 k_eff，R70 便自动**包含** R69，而不是与之并列。进一步，独立性不该被假设，而该被**测量**：用溯源签名给保守先验，用已知真值探针做实测，且估计只允许偏高不允许偏低。

**灵感 4（团队预算 → 不要所有机器人都去问同一个人）**
直觉：R69 的预算是单机的（单位时间 ≤1 次信息动作）。编队里预算变成共享的：带宽、人类注意力、运动空间都是团队级稀缺资源。各机器人各自贪心地算 VoI，会同时去问同一个人、看同一个角、探同一个点——不仅浪费，而且制造**虚假的感受一致性**（同一答案被 n 台各记一遍）。正确做法是团队级联合分配：在共享预算下最大化互补信息，避免重复覆盖同一潜变量。这是子模最大化，可贪心近似、可用廉价拍卖实现。

**灵感 5（严格包含 → 协调只是效率层，绝不碰安全层）**
直觉：R69 把 R68 收编为边界情形，本轮必须对 R69 做同样的事，否则每加一层就多一个要独立信任的黑箱。要求很明确：n=1、无同伴查询、通信关闭、采集关闭，任一成立时 SWARM 逐指令等于 FLUID-RAS（再关交互即等于 R68）。新增的机制只作用于两处——**证据如何加权**、**数据走哪条离线路径**——从不放宽实时安全包络。

**灵感 6（编队把 R68 的风险放大 → 共模漂移）**
直觉：R68 最怕「缓变故障被标定吸收而隐形」，R69 用流似然做第二意见。到了编队，这个风险变成**共模**：所有机器人共享同一标定流程，于是一起漂移、一起把残差抹平、一起在流似然上报警——或者更糟，一起不报警。单机的第二意见在共模失败前失效。必须把残差/似然拆成**共模与差模**，并保留一个不共享当前标定窗与 checkpoint 的**异构哨兵**作为独立参照。真世界变化会让共模残差与似然同升；编队缓变故障则是共模残差低、共模似然高、差模低、哨兵稳定。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（SWARM-RAS 总览与四不变式）** SWARM-RAS = (FLUID, PQA, EID, QAT, CES, CBD, HARVEST, PLT, J_SWARM)。四不变式：
(i) **实时零学习写操作**（继承定义 293-i）；
(ii) **团队级共享预算**：每机器人每单位时间信息动作 ≤1，团队合计 ≤ B_team，每轮消息 ≤ m_max，且任何信息动作（含 g_peer）仍须过 C-RAS-WM 前缀认证；
(iii) **相关性折扣证据**：团结论断只按**有效独立源** k_eff 计票，禁止用原始来源数 n 替代 k_eff；k_eff < k_min 时不得据此削减 U_epi；
(iv) **数据隔离**：部署期数据仅进入 HARVEST 隔离区，在线控制器的唯一数据入口是经离线认证的原子换装；隔离区与实时环之间无读路径。

**定义 311（团队、局部观测与增广动作-消息）** 团队 R = {r_1,…,r_n}，时刻 t 各机器人有局部观测 o_{i,t} 与局部信念。信息动作空间扩为 𝒜_info^+ = 𝒜_info ∪ 𝒜_peer，g_peer = (target j, q_type, q_arg)，q_type ∈ {viewpoint（请求其视角）, memory（请求其历史观测）, probe（请求其做标定/物理探询）, status（请求其自检/健康）}；另有 g_bcast。每机器人动作 ξ_i = (a_i, g_i, m_i)，m_i ∈ ℳ 为有界消息（≤ m_bits）。联合策略 π_Θ(ξ_{1:n} | o_{1:n})。消息长度与频率均计入预算。

**定义 312（溯源签名与相关性矩阵）** 每条证据 e 带溯源签名 sig(e) = (sensor_model_hash, ckpt_hash, calib_window_id, pose_cluster, comms_path_id, human_source_id)。若两源共享任一「共同失败因子」（同型号传感器 / 同 checkpoint / 同标定窗 / 同通信路径 / 同一人类来源），则先验相关 ρ_ij ≥ ρ0（保守下界）。相关性矩阵 P = [ρ_ij] 由签名先验与探针实测（定义 325）融合得到，且**只允许被高估、不允许被低估**（保守取 max）。

**定义 313（有效独立源 k_eff）** 由 P 的特征值 λ_i，k_eff = (Σλ_i)² / Σλ_i²（Kish 设计效应），相关等同时退化为 k_eff = n/(1+(n−1)ρ̄)。恒有 1 ≤ k_eff ≤ n；k_eff = 1 表示全相关（等价于单机器人）。**证据纪律升级为：k_eff ≥ k_min（默认 2），而非 n ≥ k_min。**

**定义 314（相关折扣 VoI）** 设当前证据集 E、候选信息动作 g 的随机回答 y_g。VoI_eff(g) = I(M; y_g | E)，其中似然 p(y_g | M, E) 必须显式建模共同因潜变量 c：e_i = f_i(M, c, ν_i)，y_g = f_g(M, c, ν_g)。当 y_g 与 E 共同受 c 支配时，条件互信息自动趋零——**相关源不再贡献 VoI**。选择 g* = argmax_g [VoI_eff(g) − c(g)]，其余同 R69。

**定义 315（团队查询分配 QAT）** 联合选择查询集 S ⊆ {(i, g)}：max Σ_{(i,g)∈S} VoI_eff(i,g)，s.t. 每机器人每轮 ≤1、Σ cost ≤ B_team、同一潜变量的重复发问被覆盖约束排除。因条件互信息对查询集合可子模，贪心达到 (1−1/e) 近似；分布式实现用 ≤ m_max 条消息的拍卖/共识，超时即退化为本地贪心。

**定义 316（相关证据筛 CES）** 接受一个模态主张需同时满足：
(a) 可信度加权后 k_eff ≥ k_min；
(b) **共同因似然比** Λ = p(证据 | 单一共同失败 c) / p(证据 | 真模态 M) 低于阈值 τ_LLR，即「这组一致能否用一次共享失败解释」。
若 (b) 无法排除，则一致性无效，U_epi 保持未消解，退回 FLUID 保守。CES 是 R69「k 正交一致」在 ρ>0 下的正确推广：ρ=0 时 (b) 自动通过，逐条退化为 R69。

**定义 317（共模/差模漂移分解 CBD）** 对每机器人的 R69 FMA 分 a_i 与残差 r_i，分解为共模 c_a = (1/n)Σa_i、差模 d_i = a_i − c_a（r 同理）。判据：
- **真世界变化**：共模 r↑ 且共模 a↑；
- **编队缓变故障**：共模 r↓（各机标定各自吸收）而共模 a↑，且差模 a 低（大家错得一样）；
- **单机故障**：差模 a_i 单独↑。
维护一个**不共享当前标定窗/checkpoint 的异构哨兵子集**作独立参照；哨兵稳而共模 a 升 ⇒ 判为编队漂移。

**定义 318（决策 VoI vs 数据 VoI）** 决策价值 VoI_dec（R69，即时降风险）；数据价值 D(g) = E[离线更新后风险/不确定性下降]·γ^Δ（延迟、非短视）。二者预算分离：信息动作先由 VoI_dec 选；仅当 VoI_dec 近零且 g 在认证安全包络内时，才用 D(g) 作 tie-break 采集。**禁止让 D(g) 把机器人推出安全包络或认证集。**

**定义 319（HARVEST 五段流水线）** collect（带 sig 的只追加日志）→ quarantine（隔离区，实时环零读）→ curate（去重、去相关、按信任加权、投毒过滤）→ offline（离线训练 + **相关性留出评估** + 投毒切片评估）→ certify（J_SWARM ∧ R66/R68 换装不变式）→ swap（原子、可回滚）。这是数据进入控制器的**唯一**路径。

**定义 320（溯源与信任账本 PLT）** 每条数据/证据记录 origin、sig、时间、经手链（Merkle root 可验）。信任 τ_(source, claim_type) ∈ [0,1] 由审计（VQAuditor-I）、历史欺骗、探针一致性在线更新；信任是**按主张类型**的，不是全局人格分。τ 只影响加权与清洗，不改在线安全阈值。

**定义 321（相关数据投毒）** 威胁：被俘机器人注入伪造轨迹/重放、通过问答投毒；或一组相关源协同投毒，使「共识」看起来可信。防御：溯源缺失即拒收；跨机器人一致性 + 哨兵 + influence-function 异常剔除；**相关数据按 k_eff 打折**——n 份相关投毒最多算 1 份，不能靠堆数量淹没清洗。定义投毒预算 δ_d 与清洗后误差上界。

**定义 322（团队级证书 J_SWARM）** J_SWARM = ({J_FLUID,i}, k_eff_report, correlation_matrix_hash, query_allocation_hash, budget_ledger, provenance_merkle_root, common_mode_drift, sentinel_report, harvest_manifest_hash, swarm_ver)。Valid ⇔ 所有机器人 J_FLUID 有效 ∧ k_eff 纪律满足 ∧ 预算未越界 ∧ 实时路径无无溯源数据 ∧ 隔离区完整性校验通过。

**定义 323（通信退化与自主回退）** 当延迟 > τ_comm、丢包 > p_loss 或分区：各机器人立即退化为独立 FLUID-RAS（k_eff→1，g_peer 不可用，消息不参与决策），重连后按溯源账本做冲突消解（不覆盖、只合并可验证部分）。**分区只能降低效率，不得提高风险**；协调永远是效率层，不是安全层。

**定义 324（严格包含 FLUID/R68）** 当 n=1，或 g_peer=∅，或通信关闭，或 HARVEST 关闭时，SWARM 逐指令等于 FLUID-RAS；再令交互关闭即等于 R68。新增机制只作用于证据加权与离线数据路径，从不放宽实时安全包络。

**定义 325（多样性 KPI 与相关性探针）** 多样性 D_team = 1/k_eff（共同失败模型下），或相关矩阵的行列式形式，作为可观测量与工程 KPI；维护手段是异构传感器/模型/位姿/标定窗。**相关性探针审计**：周期性对已知真值注入小探针（标定目标、已知地标、合成查询），实测 ρ_ij 以纠正先验；无探针时只用保守下界 ρ0。

# IP-264 PQA + IP-265 EID：相关折扣的同伴证据
def peer_evidence(team, E, modes):
    P     = correlation_matrix(team)                 # 定义 312：签名先验 + 探针
    k_eff = kish_effective_size(P)                   # 定义 313
    if k_eff < K_MIN: return E, k_eff                # 不许用共识降 U_epi
    votes = [(e, tau[src, claim]) for e, src in E if provenance_ok(e)]
    return ces_gate(votes), k_eff                    # 定义 316

# IP-266 QAT：团队共享预算下的互补查询（子模贪心）
def allocate_queries(team, modes, budget):
    S, used = [], 0.0
    for (i, g) in greedy_submodular(team, key=VoI_eff):      # 定义 314-315
        if used + cost(g) > budget.B_team: break
        if not c_ras_wm.certify_info(g, team[i].obs): continue
        S.append((i, g)); used += cost(g)
    return S

# IP-267 CES + IP-268 CBD
def ces_gate(votes, llr_thresh=TAU_LLR):
    if kish_effective_size(votes) < K_MIN: return FALLBACK
    if common_cause_llr(votes) > llr_thresh: return FALLBACK  # 共享失败可解释
    return weighted_consensus(votes)

def drift_split(team):
    a = [fma.flow_anomaly(m.fmp, m.last_action, m.obs, m.o_cal) for m in team]
    r = [m.last_r_res for m in team]
    return mean(a), mean(r), [ai - mean(a) for ai in a], sentinel_stable(team)

## 3. 推导

**引理 19（相关证据的虚假置信）** 设 n 个来源成对相关 ρ̄，等效独立样本 k_eff = n/(1+(n−1)ρ̄)。若共同因失败以概率 1−ε_c 同时翻转所有源，则多数表决错误率 ≥ 1−ε_c，与 n 无关；而若误把来源当独立，名义置信随 n 指数上升、真实置信不变。故 k_eff 才是充分统计量，R69 的 k-正交纪律是 ρ=0 的特例。

**引理 20（VoI 对相关性的单调否决）** VoI_eff(g) = I(M; y_g | E) 关于 y_g 与 E 的偏相关单调不增，ρ→1 时趋于 0。故大 n 的重复问询不增加信息；最优查询集必偏向「溯源签名差异最大」的源。系：**问一个视角不同的机器人，胜过问十个同型号同标定窗的机器人。**

**引理 21（采集不改变即时风险上界）** 数据动作 g_data 仍须过 C-RAS-WM 前缀认证（定义 310-ii）；其只影响未来模型而非当前谓词，故在线每步风险 ≤ FLUID 的风险界。数据对控制器的唯一影响经 HARVEST 离线认证换装（定义 319），失败即回滚，故不会在线放大风险。要点：**采集的当下风险被认证门拦住，未来风险被换装门拦住。**

**定理 18（SWARM 严格包含 R68/FLUID，且不以数量换置信）** 在退化边界（n=1 / 无 g_peer / 通信关闭 / 采集关闭）SWARM 逐指令等于 FLUID-RAS（定义 324）。对任意 n，认证共识使用 k_eff 而非 n，故错误采纳概率受引理 19 的 k_eff 界约束；增加机器人只能通过增加 k_eff 提高置信，不能通过增加票数。系：分区回退（定义 323）使 n_eff→1，风险不高于 FLUID，协调是纯效率层。

**定理 19（采集-换装的安全不变式）** HARVEST 对实时控制器的唯一写操作是满足 R66/R68 换装不变式的原子换装；认证失败、回滚或隔离区污染时在线策略逐位不变。因此：采集过程不改变在线安全包络；被投毒数据只有通过「相关性留出 + 投毒切片」双重认证后才可能影响下一代模型，否则被隔离。**数据可以在线采、只能离线信。**

## 6. 本轮最大风险

**一句话**：SWARM 的全部保证押在「相关性矩阵 P 只被高估、不被低估」这一前提上——若编队存在溯源签名捕获不到的共同失败模式（新共享软件缺陷、协同攻击、共同环境错觉如反光/雾/同一张误导地图），k_eff 就会被高估，CES 会把「同一辆车的错误复制 n 份」当成独立共识，从而错误削减 U_epi；更糟的是 HARVEST 会把这份被「证实」的共识写进下一代模型——**把相关误当独立，等于把同一辆车的错误复制 n 份还盖上公章；而数据采集会把这个公章合法化。**

**次级风险与缓解**：
1. **相关性低估/签名遗漏** → 保守下界 ρ0 + 探针审计 + CES 共同因检验；无法排除即退回 FLUID 保守；
2. **Byzantine 捕获/协同投毒** → k_eff 折扣 + 异构哨兵 + 溯源 + influence-function 清洗（定义 321）；
3. **团队预算/通信延迟击穿实时** → 异步陈旧消息 + 硬预算 + 超时退化本地贪心（定义 323）；
4. **采集滑向 OOD/危险** → 数据 VoI 不得越安全包络 + 换装门（定义 318–319）；
5. **编队共模缓变故障（R68 风险被放大）** → CBD 共模/差模分解 + 不共享标定窗的异构哨兵；
6. **多样性随维护退化** → D_team KPI + 相关性探针，低多样性时禁用同伴共识。

## 4. 推导

**引理 19（相关证据的虚假置信）** 成对相关 ρ̄ 的 n 源等效独立数 `k_eff=n/(1+(n−1)ρ̄)`。共同因失败以 1−ε_c 同时翻转所有源时，多数表决错误率 ≥ 1−ε_c，与 n 无关；误当独立则名义置信随 n 指数上升、真实置信不变。故 k_eff 是充分统计量，R69 的 k-正交是 ρ=0 特例。

**引理 20（VoI 对相关性的单调否决）** `VoI_eff=I(M;y_g|E)` 关于 y_g 与 E 的偏相关单调不增，ρ→1 时趋于 0。系：问一个视角不同的机器人，胜过问十个同型号同标定窗的机器人。

**引理 21（采集不改变即时风险上界）** 数据动作仍过 C-RAS-WM 认证，只影响未来模型不影响当前谓词，故在线每步风险 ≤ FLUID 界；唯一控制器影响经离线认证换装，失败回滚。采集的当下风险被认证门拦住，未来风险被换装门拦住。

**定理 18（SWARM 严格包含 R68/FLUID，且不以数量换置信）** 退化边界（n=1/无 g_peer/通信关闭/采集关闭）逐指令等于 FLUID；对任意 n，认证共识用 k_eff 而非 n，错误采纳率受引理 19 约束。增加机器人只能通过增加 k_eff 提高置信。系：分区回退使 n_eff→1，风险不高于 FLUID，协调是纯效率层。

**定理 19（采集-换装的安全不变式）** HARVEST 对实时控制器的唯一写操作是满足 R66/R68 换装不变式的原子换装；认证失败/回滚/隔离区污染时在线策略逐位不变。被投毒数据须通过「相关性留出 + 投毒切片」双重认证才可能影响下一代模型。数据可以在线采、只能离线信。

## 7. 本轮最大风险

**一句话**：SWARM 的全部保证押在「相关性矩阵 P 只被高估、不被低估」这一前提上——若编队存在溯源签名捕获不到的共同失败模式（新共享软件缺陷、协同攻击、共同环境错觉如反光/雾/同一张误导地图），k_eff 就会被高估，CES 会把「同一辆车的错误复制 n 份」当成独立共识，从而错误削减 U_epi；更糟的是 HARVEST 会把这份被「证实」的共识写进下一代模型——**把相关误当独立，等于把同一辆车的错误复制 n 份还盖上公章；而数据采集会把这个公章合法化。**

**次级风险与缓解**：相关性低估/签名遗漏（保守下界 ρ0 + 探针审计 + CES，无法排除即退回 FLUID）；Byzantine 捕获/协同投毒（k_eff 折扣 + 异构哨兵 + 溯源 + influence 清洗）；团队预算/通信延迟击穿实时（异步陈旧消息 + 硬预算 + 超时退化本地贪心）；采集滑向 OOD/危险（数据 VoI 不得越安全包络 + 换装门）；编队共模缓变故障（CBD 共模/差模 + 不共享标定窗的哨兵）；多样性退化（D_team KPI + 探针，低多样性时禁用同伴共识）。
