# 第 43 轮（新循环第 3 轮） · 联邦具身证书飞轮（FECF）：把具身智能大模型当「提议者」、把联邦学习当「证据网」，用「验证者-提议者分离」守住安全（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR）。第 42 轮把「安全证书」做成了可仿真、可检索、可边缘执行的闭环，但它的所有提议——任务、技能、动力学先验、反例——仍来自单机、单团队、有限数据。本轮灵感词「具身智能大模型」与「联邦学习」正好补上两个规模化前提：前者提供跨任务的语义先验与任务分解，使证书从「每个任务冷启动」变成「先提议、再验证」；后者提供跨机器人、跨场地、跨团队的数据规模，使大模型不必集中原始数据也能变强。但二者叠加会引入一条比第 42 轮更隐蔽的失效链：**提议者越强、越共享，若验证者也跟着共享，系统就会「集体自信地失败」**。因此本轮的核心不是「把大模型塞进证书」，而是 **验证者-提议者分离（proposer–verifier separation）**：联邦训练只更新提议者；本地验证器是不可联邦、不可回传的**信任锚**；联邦共享的只是证书证据的**充分统计量与失败指纹**，既不是证书本身，更不是放松阈值的权力。

## 0. 直觉与动机

### 0.1 灵感 1（具身智能大模型 → 证书的「提议者」，绝不是「裁决者」）

第 42 轮的 CKB/RAG 是「改着用」，但改的依据仍是历史模板；遇到全新任务族仍要冷启动。具身智能大模型的直觉是把它当成一个**跨任务提议器**：语言 + 视觉 + 本体状态进来，它提出 (1) 任务契约与成功谓词，(2) 子目标/技能序列，(3) 技能参数初值（CBF 的 nominal 轨迹、抓取位姿），(4) 动力学/接触先验（用于收紧 L_m、缩小 sim-to-real gap），(5) 对反例的语义解释。但它是一个**未经验证的高方差 oracle**：会幻觉、会过度自信、会在分布外给出看似合理却错误的分解。因此绝不能让它直接改阈值或直接执行；它只能产生**候选**，由本地证书栈逐条裁决。这样大模型负责「提高提议命中率」，证书负责「保证命中之后仍然安全」。

### 0.2 灵感 2（联邦学习 → 从「单机经验」到「跨体证据网」）

一台机器人的数据永远不够覆盖大模型的分布；但机器人数据涉及隐私、带宽、责任与商业机密，不能集中。联邦学习给出「数据不动、模型动」的路径。然而**朴素联邦对证书是危险的**：非 IID（轮足/四足/人形、不同摩擦与传感器）会让平均模型变成谁都不适用的「嵌合体」；恶意客户端可投毒；DP 噪声会悄悄侵蚀安全边际。因此本轮只联邦两样东西：**提议者的参数/适配器**，以及**证书证据的充分统计量**（边成功率计数、边际分位、失败指纹、有效域摘要）。证书本身与验证器永远留在本地。

### 0.3 灵感 3（耦合 → 三道分离，把「集体失败」变成「显式降级」）

- **通道分离**：提议通道（可联邦、可大模型）／证据通道（可联邦、但只传统计量）／裁决通道（本地、不可联邦）三通道隔离。
- **证书分解**：本地证书分成**核心核 m_core**（与任何共享先验无关，确定性 sound）与**外壳 m_shell**（用共享先验收紧，必须有本地 conformal 可采性才允许使用）；不可采时自动退回核心核。
- **投机认证**：大模型一次 draft K 步，验证器只对 chunk 做一次批量认证，通过才执行；不通过就带着拒绝原因重提议。既吃到「大模型一次想很远」的效率，又不让未认证动作落地。
- **认证聚合 + 专家分裂**：只在客户端证书域的**交集**上聚合；交集为空就拆成多个「认证专家」（F-MoCE），每个客户端按自己的证书覆盖选专家；覆盖不足则显式回退单机证书或 SafeStop。

### 0.4 与第 42 轮的耦合

第 42 轮是「Sim→RAG→Edge→Sim」的安全飞轮；本轮在其上并联一条**联邦证据飞轮**：本地部署 → 局部证书 + 失败指纹 → 安全聚合/DP → 认证专家/适配器 → 局部审计 → 再部署。SCV 用全局失败前沿生成压力测试场景，CKB 存专家注册表与证书覆盖图，ECR 执行「核/壳双界 + 投机认证」。安全从「单机可证」升级为「联邦可证，且失败可见」。

## 1. 形式化定义（增量：定义 38–44）

**定义 38（具身基础模型提议分布与认证提议）**：设具身基础模型 M_θ: (u,o,h) ↦ Δ(C×Π×Φ_dyn)，u 为语言指令、o 为多模态观测、h 为交互历史，C 为任务契约空间、Π 为技能/子目标序列空间、Φ_dyn 为动力学先验空间。一次提议 p=(c,π,φ_dyn)∼M_θ。定义**认证提议谓词** Cert(p)=1 ⇔ 存在证书 C_p 使 (m_cert≥θ) ∧ (p_lo≥p_req) ∧ (Inv 保持)，其中 m_cert 来自定义 40，p_lo 为成功率证书下界。**只有 Cert(p)=1 的提议可进入执行**；M_θ 无权修改 θ、p_req 或 Inv。

**定义 39（验证者-提议者分离与安全不变式）**：系统分解为提议者 P=(M_θ, 联邦先验) 与本地验证者 V_k=(CAR 守卫, 核心证书核, 成功率核)。安全不变式：∀t, a_t∈A_exec ⇒ V_k(s_t,a_t)=SAFE。V_k 不接受联邦参数更新，也不回传任何可放松阈值的量；联邦只能改变 P 的提议分布与 V_k 的外壳。**命题 1（提议者无关安全性）**：若 V_k 的核心核 sound，则对任意 P（含被投毒/被后门的 P），执行轨迹满足安全不变式；P 失效只降低认证接受率与可用性，不直接产生不安全动作。

**定义 40（核心-外壳证书分解与外壳可采性）**：m_cert(x)=m_shell(x) 若 Adm(x)=1，否则 m_core(x)。m_core 为模型无关下界（几何证书 + 本地经验分位）；m_shell 为用联邦先验/世界模型收紧的统计下界；Adm(x)=1 要求 x 落在本地 held-out 校准域 S_k 且 m_shell 通过本地 conformal 校准（覆盖率 ≥1−α_s）。**命题 2**：Adm=1 时 P[true margin < m_shell] ≤ α_s；Adm=0 时 true margin ≥ m_core 恒成立。因此 m_cert 是置信 ≥1−α_s 的概率安全下界，且永不弱于核心核的确定性保证。

**定义 41（联邦证书聚合与认证交集）**：客户端 k 有局部模型 θ_k、有效域 C_k、边际下界 m_k。服务器在兼容组 g 上做安全聚合 θ_g=Σ_{k∈g} w_k θ_k，定义认证交集 C_g=∩_{k∈g} C_k 与 δ_agg(g)=max_{k∈g}‖θ_g−θ_k‖。若边际对参数满足 L_agg-Lipschitz，则 ∀x∈C_g：m_{θ_g}(x) ≥ min_{k∈g} m_k(x) − L_agg·δ_agg(g) =: m_g(x)。**联邦证书审计**：服务器无数据，故 θ_g 的最终采纳由客户端在本地 held-out 上复验，返回签名 accept/reject + 局部 conformal 界；accept 比例 ≥ q 才上线，否则回滚。这使「聚合」从盲目平均变成「带本地否决权的联邦」。

**定义 42（证书感知差分隐私与安全预算）**：DP-SGD 以裁剪 C_clip、噪声 σ 训练，以概率 ≥1−δ_DP 有 ‖θ_g−θ_clean‖ ≤ B_DP(ε,δ_DP)。映射到证书退化 η_DP=L_agg·B_DP。定义 **(ε,δ_DP,η_cert)-证书感知 DP**：同时满足 (ε,δ_DP)-DP 与 η_DP ≤ η_cert。**命题 3**：证书感知 DP 下，联邦专家证书的 soundness 概率 ≥1−δ_DP−α_s，且边际退化 ≤η_cert；因此隐私预算必须显式写进证书，而不是藏在训练脚本里。

**定义 43（隐私保护失败指纹与全局失败前沿）**：失败指纹 f(ξ)=(H(语义场景), 动力学 regime 摘要, 边际崩塌模式, root-cause 标签)。客户端对 f 施加局部 DP 噪声后上传，服务器按 k-匿名桶聚合，得到全局失败前沿 F_fed。效用损失由桶内距离界出：召回损失 ≤ ε_LDP/Δ_intra。F_fed **只用于生成 SCV 压力测试场景与 CKB 候选**，不直接改任何阈值。

**定义 44（联邦证书覆盖与飞轮进化）**：覆盖 Cov(F)=满足「存在专家 g 使 C_g 覆盖客户端 k 的状态分布且 m_g≥θ」的客户端比例。飞轮每轮：本地部署 → 局部证书 + 指纹 → 认证聚合 → 专家/适配器 → 本地审计 → 再部署。**定理 1（有界异构下的覆盖）**：若客户端分布两两 W_1≤ε_h，且每组认证交集非空，则存在 N_exp ≤ O((ε_h/ρ)^d) 个专家使 Cov=1；每轮只有在「新交集仍覆盖组内既有客户端状态分布的 ρ 比例」时才并入，否则新开专家，因此覆盖单调不减。若交集为空，必须拆专家或回退单机证书——**显式降级，禁止静默合并**。

## 5. 本轮最大风险

**一句话**：整套联邦安全论证依赖「本地验证器真正独立」与「外壳可采性本地校准」——若客户端共享同一个先验盲点、或 DP 噪声被错误记账，所有客户端会在数值上「一致地同意」一个局部为假、全局自洽的证书，形成比单机失效更隐蔽的**集体静默失败**；因此 E89（聚合 soundness）、E90（DP 安全预算）、E92（投毒鲁棒）必须作为红线，任一不达标即关闭跨体聚合、退回第 42 轮单机证书。

## 2. 关键算法（伪代码）

### IP-60 FEP：提议 + 投机认证
```
def propose_and_speculate(u, o, h, verifier, K=8):
    p = M_theta.sample(u, o, h)          # 契约/子目标/技能参数/动力学先验
    chunk = p.plan[:K]                    # 一次 draft K 步
    # 批量认证：核界快查 + 外壳可采性（仅当本地校准通过）
    certs = verifier.certify_chunk(chunk, need_shell=True)
    if all(c.safe for c in certs):
        return chunk, certs               # 整段执行（每步仍由 CAR 守卫兜底）
    # 定位第一处失败，带拒绝原因让提议者重提议
    k_bad = first(lambda i: not certs[i].safe, range(K))
    return propose_and_speculate(u, o, h + reject_context(chunk, k_bad),
                                 verifier, K=max(1, k_bad))
```

    assert eta_dp <= ETA_CERT                               # 证书感知 DP 预算

    groups = cluster_by_certificate_compat(certs, rho)

## 3. 关键推导与复杂度/正确性

### 3.1 聚合边际界
对 x∈C_g，每个客户端局部界 sound：m_k(x) ≤ margin_{θ_k}(x)。由边际对参数的 L_agg-Lipschitz 性：
margin_{θ_g}(x) ≥ margin_{θ_k}(x) − L_agg‖θ_g−θ_k‖ ≥ m_k(x) − L_agg·δ_agg(g)。
对 k 取 min 得 m_{θ_g}(x) ≥ min_k m_k(x) − L_agg·δ_agg(g) = m_g(x)。证毕。**要点**：该界只在交集 C_g 上成立；交集外必须由单机证书或外壳 conformal 兜底。

### 3.2 隐私-安全联合界
DP-SGD 给出 P[‖θ_g−θ_clean‖ > B_DP(ε,δ_DP)] ≤ δ_DP；外壳 conformal 给出 P[m_shell > true margin] ≤ α_s。二者独立或经 union bound 合并，得
P[m_cert > true margin] ≤ δ_DP + α_s，
且边际退化 ≤ L_agg·B_DP = η_DP。故证书必须同时记录 (ε, δ_DP, η_cert, α_s)，任一超预算即拒绝上线。

### 3.3 投机认证的 soundness
执行序列按 chunk 分解；归纳假设「已执行前缀均通过 Cert」。新 chunk 仅当 `all(c.safe for c in certs)` 时整段执行，故 chunk 内每一步均被认证；若被拒，则不执行任何未认证步，仅回灌拒绝上下文重提议。因此执行轨迹与逐帧认证完全相同，soundness 不变；差别只在验证调用次数（期望 O(K/(1−a))，a 为接受率）。

### 3.4 F-MoCE 覆盖
在 W_1 ≤ ε_h 的有界异构下，客户端证书域在参数/域空间中的覆盖数 ~ O((ε_h/ρ)^d)。贪心集覆盖给对数近似；并入规则要求新交集仍覆盖组内既有客户端状态分布的 ρ 比例，否则新开专家，因此已有专家的认证域不被收缩，Cov 单调不减。

## 6. 本轮最大风险

**一句话**：整套联邦安全论证依赖「本地验证器真正独立」与「外壳可采性本地校准」——若客户端共享同一个先验盲点、或 DP 噪声被错误记账，所有客户端会在数值上「一致地同意」一个局部为假、全局自洽的证书，形成比单机失效更隐蔽的**集体静默失败**；因此 E89（聚合 soundness）、E90（DP 安全预算）、E92（投毒鲁棒）必须作为红线，任一不达标即关闭跨体聚合、退回第 42 轮单机证书。
