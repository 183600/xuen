# 第 2 轮（UniBot 线 · 承接 SAGE；本轮灵感：「传感器标定」×「自然语言指令」）

> **编号接续说明**：prompt 标为“第 1 轮”，但状态文件已完整承载第 1 轮 UniBot-SAGE（U1–U12 / L1–L7 / E601–E618 / IP-01–IP-08）。按“跨轮保留、深化不推倒”的规则，本轮记为**第 2 轮**，旧资产全部保留，新增 U13–U24 / L8–L14 / E619–E640 / IP-09–IP-14。若流程要求严格重置轮号，只需改标题，内容不受影响。
> **本轮口号**：从“能力栈”转向“**规范层**”——先把观测变成**跨机器人可比**的东西，再谈策略更强。

## 0. 核验分层（先分清事实、待测与假设）

第 1 轮的情报核实仍然有效。本轮只把与“标定 / 语言”相关的新命题分成三层，避免把猜想写成结论：

- **A 类（沿用第 1 轮，已核实）**：32 项桌面任务 / 5 类泛化场景 / 通才单模型赛道 / 远程 `metadata`·`get_action`·`reset` 接口 / N 台真机与连续端口 8765… / 4 路相机（头 stereo×2 + 左右腕）/ 1 维夹爪标量 / EE 相对基座位姿 / `action.pivot`(7) / 评测端用 cv2 做 `image_resize` / `obs_delta_indices` 同时决定传输键与时序叠帧 / 官方采集延迟与动作统计可信度 / teaser 榜为占位表。
- **B 类（本轮必须做“零成本探测”才能做强声明）**：① N 台机器人是否同型号、同固件、同相机支架；② 评测是否提供 base pose / IMU；③ `pivot` 的确切语义与被跟踪程度；④ chunk 的执行 / 插值 / 平滑语义；⑤ `image_resize` 的插值与宽高比处理；⑥ `obs_delta_indices` 是“帧差索引”还是“去重后的连续采样”；⑦ 语言指令是固定模板、同义改写，还是允许带空间/属性描述；⑧ 官方 32 个数据集由几台机器人采集。
- **C 类（纯假设，仅用于设计备选路径）**：不同机器人之间的外参误差量级、时延量级、夹爪零点漂移量级；未见物品的指令用词分布；人为干扰者的行为分布。

**本轮必须修正第 1 轮的三处隐含假设**：

1. **“泛化”被当成了一个东西**。第 1 轮把 5 类场景统称为“测试时分布偏移”。但其中“位置 / 背景 / 干扰物 / 未见物品 / 人为干扰”是**语义与场景层**偏移，而 **N 台真机带来的是物理层偏移（标定）**。两者混在一起，会被域随机化与更大的模型一起“糊过去”，导致归因错误。本轮显式拆成 `semantic shift` 与 `calibration shift`。
2. **抓握判定默认了坐标系是对的**。第 1 轮 GraspVerify 用“EE 速度 + 物体随动”判抓握；但 EE 速度是在某个基座/相机坐标系下算的。若外参、时间戳、夹爪零点有偏，同一套判据在不同机器人上会系统性漂移——**最需要它的泛化场景，恰恰是标定最不可信的场景**。
3. **语言只被当成任务标签**。第 1 轮只用 `language` 检索 `z_task`。但语言是整条链路里**唯一与机器人、标定、场景都无关**的信号，它还能承担“不变锚”“指代绑定”“精度预算”三种更重的角色。

## 1. 直觉与动机（两灵感的第一性原理）

### 灵感 1 ·「传感器标定」→ 偏移不是任意的，它有一张“物理参数表”

**直觉**：机器人比赛里最容易被忽略的一句话是“**你的相机装歪了**”。同一段策略代码，换一台机器人、换一个相机支架、换一次固件，效果就可能断崖式下跌。这不是模型不通用，而是观测的**物理含义**变了：像素对应的米数变了、腕部相机到手爪的变换变了、四路相机之间的时间戳错位了、夹爪“全闭”的零点漂移了。标定的第一性原理是：**不要把偏移当成无限维的域偏移，它只是一个低维、有物理结构的参数向量**。能估出来就补偿；估不出来就把策略设计成对它不敏感。

**严谨化**：定义第 `r` 台机器人的标定参数
`κ_r = (K_r, T^{cam←ee}_r, Δt_r, b^grip_r, T^{base←world})`，
其中 `K` 是（经评测端 resize 之后的）有效内参，`T^{cam←ee}` 是手眼外参，`Δt` 是视觉与本体感觉的时间偏移，`b^grip` 是夹爪零点/量程偏差。观测生成模型写成
`o_t = h(x_t; κ_r) + ε_t`。
训练集只覆盖有限个 `κ_r`（甚至可能只有少量机器人），评测在 N 台未知 `κ_r` 上。我们要的不是“估出全部 κ”（通常不可辨识），而是**估出可辨识子空间**并把不可辨识部分转成鲁棒性设计。

这里有三个具体、可操作的子洞察：

- **机器人自身就是标定靶**。腕部相机能看到自己的夹爪与静态桌面；用前向运动学预测的末端旋转去对齐腕部光流，就能在没有标定板的情况下估手眼旋转；用腕部光流与关节速度的互相关，就能估时间偏移。**不需要额外设备，也不需要专门的动作**——episode 开头 1–3 秒的自然接近动作就足够激励。
- **接口本身就是一次“标定”**。评测端用 cv2 做 `image_resize`，像素焦距会随比例缩放；`obs_delta_indices=[-2,0]` 意味着你拿到的两帧可能相隔 2 帧而不是 1 帧（33 ms vs 67 ms）。若模型内部仍按 480×640、33 ms 解释，速度、像素→米、甚至相位判据都会系统性偏。**这是零成本、必做的一层标定**。
- **“统计标定”同样重要**。第 1 轮的 `τ_conf` 只是一个阈值，没有覆盖率保证。真实要求是：说“没抓住”的时候，错判率要可证地低。这需要**置信度校准**（可靠性图 / 温度缩放 / 保形预测），否则“高置信”只是模型的自说自话。

**一个反直觉的推论**：第 1 轮已经证明“时长与成功无关、做得快没有红利”。因此在 episode 开头花 1–3 秒做标定探测，在计分上是**近乎免费**的（只要不撞总时长上限）。这使“在线自标定”从奢侈变成理性——**赛制允许你慢，但不容许你把观测理解错**。

### 灵感 2 ·「自然语言指令」→ 语言是唯一的不变锚

**直觉**：换机器人、换背景、换标定，唯一不变的是那句任务指令。人也是这样：新环境里先读任务说明，再决定“这事要多精确”。语言的三种用途按重要性递增：

1. **任务锚**（第 1 轮已做）：同一句指令 → 同一个任务 token，用于选专家。
2. **指代锚**：指令里的名词、属性、空间关系（“把**红色**杯子放到**左边**的托盘”）可以直接去查询开放词表检测器，而不必依赖策略在训练场景里记住布局。这正对“未见物品 / 干扰物 / 位置”三类泛化。
3. **精度锚**：语言隐含了容差。“插入网线”“拧开瓶盖”是亚毫米/接触级；“叠杯子”“放进盒子”是厘米级。精度需求决定了验证频率、chunk 长度、接近速度、搜索半径。**把精度预算从固定超参变成由语言预测的连续量**，是比“按任务名写 if-else”更合规、也更可泛化的做法。

**严谨化**：令 `u = E_L(ℓ)` 为语言嵌入。核心假设是**语言不变性**：在同一任务文本下，`p(u | r, κ)` 与机器人 `r`、标定 `κ` 无关（评测对同一任务给同一文本）。于是可以把 `u` 当作跨机器人对齐的锚：
`κ̂ = g_κ(probe, u)`（语言条件化的标定先验，缩小估计方差），
`β = g_β(u) ∈ [0,1]`（精度预算），
`c = g_c(o, u)`（语义上下文）。
注意：我们不把 `ℓ` 解析成离散任务分支（那会撞上 P5 的硬编码红线），而是让 `u` 作为**连续调制向量**进入 FiLM、门控与预算。

### 合成：**LAC = Language-Anchored Calibration（语言锚定标定）**

把两个灵感编译成第 1 轮三层栈之外新增的**规范层**，并把原三层接在它上面：

- **规范层（新）**：自标定探测 → `κ̂` 与不确定度 → 观测规范化 `Φ_κ`；同时做统计标定（置信度校准 / 分组保形）。
- **语义层（新，贯穿）**：语言锚 `u` → 任务/指代/精度预算 `β`。
- **接地层（第 1 轮 IP-02，修正）**：抓握隐变量在**规范系**里计算，且用校准后的置信度门控。
- **技能层（第 1 轮 IP-01）**：专家路由照旧，但输入是规范化后的观测与 `u`。
- **工程层（第 1 轮 IP-03/IP-08）**：探测时间预算、端口隔离、延迟与动作审计。
- **一个关键的负结果**（见产物区引理 L13）：纯视觉伺服**不能**抵消恒定的外参偏差——闭环会把带偏的观测误差驱到零，物理残差恰好等于偏差。所以对插入类任务，光有闭环不够，必须叠加接触搜索/柔顺或在线外参估计。这决定了本轮必须新增 IP-13。

## 2. 瓶颈在哪里（标定误差预算：把“插入为什么难”算出来）

teaser 榜最难的任务是 Plug In Ethernet（17.7）、Unlock（20.1）、Spell robot（21.8）——全是插入/旋转/细粒度对齐。第 1 轮把它归因为“最后一环”。本轮给出**可计算的解释**：这些任务的容差已经逼近、甚至低于标定误差。

设工作距离 `d`、像素视野角 `FOV`、图像宽 `W`、接近速度 `v`、时间偏移 `δt`、外参角度误差 `δθ`、任务单边容差 `c`：

| 误差源 | 典型量级 | 在 `d=0.4 m`、`v=0.1 m/s` 下的横向误差 |
|---|---|---|
| 外参角度误差 `δθ` | 0.1° = 1.75e-3 rad | 0.70 mm |
| 外参角度误差 `δθ` | 1.0° = 1.75e-2 rad | 6.98 mm |
| 像素量化 | 70°/640 px = 0.109°/px | 0.76 mm/px |
| 时间偏移 `δt` | 10 ms | 1.00 mm |
| 时间偏移 `δt` | 33 ms（1 帧 @30fps） | 3.33 mm |
| 时间偏移 `δt` | 33 ms 且 `v=0.3 m/s` | 10.0 mm |
| 夹爪零点/量程偏差 | 2% 满量程 | 亚毫米–毫米级（需实测） |

近似式：`ε_θ ≈ d·δθ`，`ε_px ≈ d·FOV/W`，`ε_t = v·δt`，
`ε_cal ≈ sqrt(ε_θ² + ε_px² + ε_t² + ε_g²)`。
插入可行的必要条件（开环绝对定位）是 `ε_cal < c/2`。

**读法**：连接器类任务的单边容差常在**亚毫米到数毫米**。若 `c = 2 mm`，要求 `ε_cal < 1 mm`；若 `c = 0.5 mm`，要求 `< 0.25 mm`。而仅“1 像素量化”就已是 0.76 mm，单帧时延就已是 1–3 mm。结论有三条：

- **T4（绝对标定不可能独自解决）**：对最难的插入任务，靠“把外参标到很准 + 开环执行”在物理上就不够；必须让策略在**闭环 + 接触**中吸收残差。
- **T5（时延是最便宜的可修项）**：时间偏移与 `obs_delta_indices` 的误读会直接制造毫米级误差，而它几乎不花算力就能估与补。**先修时钟，再修相机**。
- **T6（语言决定预算）**：同一套 `ε_cal` 对叠杯子无伤大雅，对插网线却是致命的。把“需要多精确”交给语言预测，而不是全局固定，是唯一能同时通过两类任务的做法。

**另一个量化观察**：官方数据约 169 h / 32k episodes，但由**有限台**（未披露）机器人采集；评测在 N 台机器人上。即便每台采集机器人内部的标定一致，测试机的 `κ_r` 仍可能落在训练支撑集外。这不是“更多数据”能自动填上的洞，而是**结构性协变量偏移**——正是规范层要处理的对象。

## 3. 研究问题（本轮新增 Q6–Q11）

- **Q6（可辨识性）**：只给官方观测流与自运动，哪些标定参数可辨识？手眼旋转、时间偏移、夹爪零点、有效内参各能估到什么精度？哪些参数与物体位姿/基座运动混叠而不可辨识？
- **Q7（语言锚的有效性）**：把语言嵌入 `u` 作为跨机器人不变锚，是否真的比“机器人 ID 条件化”或“无锚”更能迁移？在未见机器人上收益有多大？
- **Q8（校准不确定性的价值）**：分组条件保形（per-robot / per-task-cluster）能否把第 1 轮“高精度低召回”的介入准则从经验阈值变成**有覆盖率保证**的判据？在机器人偏移下覆盖率是否还成立？
- **Q9（指代绑定）**：用指令中的名词/属性/空间关系驱动开放词表检测，能否在“未见物品 / 干扰物 / 位置”三类场景上提升，且不伤已见任务？指代歧义如何用校准置信度处理？
- **Q10（精度预算）**：语言能否预测任务所需的精度/容差，从而调度 chunk 长度、验证频率、接近速度与搜索半径？这比“按任务名硬编码”多赚多少、风险在哪？
- **Q11（合规边界）**：在线自标定只使用自身观测与自运动，是否被允许？它与“利用评测侧私有信息”的边界在哪？若不被允许，退回离线标定的代价是多少？

## 4. 设计原则（继承 P1–P6，新增 P7–P11）

- **P1–P6（继承）**：单一计分货币；隐状态显式化；技能组合；推理期吸收偏移；合规优先；单模型/单 checkpoint/单 API。
- **P7 分离语义偏移与标定偏移**：任何实验必须能分别报告 `semantic shift` 与 `calibration shift` 的贡献，否则归因无效。
- **P8 自身即靶**：优先用自运动、夹爪、静态桌面做标定，不依赖外部靶标或额外设备；不能用“假设已标定”掩盖问题。
- **P9 语言是连续锚，不是分支**：`u` 只作为连续调制/先验/预算，禁止 `if task == "Unlock"` 式硬编码（P5 红线）。
- **P10 不确定性必须校准且分组条件**：任何介入判据必须报告覆盖率与假阳性率，并按机器人/任务簇分组，而不是只报一个全局均值。
- **P11 不可辨识即鲁棒**：对估不出的标定参数，用闭环、接触搜索、柔顺、限幅来吸收；**不假装估出来**。

## 5. 最小可提交闭环（MVP v2）与退化链

**MVP v2 = 第 1 轮 MVP（IP-06 + IP-02 + IP-03 + 基线） + IP-09（自标定探测） + IP-10（语言锚与精度预算） + IP-11（分组保形介入门）。**
理由：IP-09 里“接口标定（resize / delta_indices）”是零成本必做；IP-11 直接修第 1 轮“误判不对称”的最大风险；IP-10 是唯一能同时喂给标定、抓握与技能层的低成本信号。IP-12/13 视 Q9/Q10 的结果推进。

**严格退化链（新增部分）**：
- Level-0 自标定不可用/超时 ⇒ 用数据集名义标定 `κ0`，并收紧介入阈值；
- Level-1 语言嵌入 OOD 或缺失 ⇒ 退回通用锚 `u0` 与固定精度预算；
- Level-2 保形集不可用（样本不足/偏移过大）⇒ 退回第 1 轮经验阈值，且默认**不介入**；
- Level-3 指代歧义无法消解 ⇒ 交回 VLA 的隐式接地，不强行绑定；
- Level-4 全部失效 ⇒ 退回纯基线（安全网永远保留）。

## 6. 预期贡献（可验收）

1. **一张可复用的“插入误差预算表”**：把 UniBot 最难的插入/旋转任务为什么难，从定性说法变成可代入的公式与数字（含 resize、时延、外参、夹爪零点四项），这是全赛道的公共品。
2. **LAC 语言锚定标定**：用“机器人自身即靶”的自监督探测估计手眼/时延/夹爪零点，并以语言嵌入为先验与不变锚；给出可辨识子空间与不可辨识项的显式清单。
3. **有覆盖率保证的介入门**：把第 1 轮的 `τ_conf` 升级为分组条件保形判据，直接修掉“漏判把可救失败变硬失败”的非对称风险。
4. **语言条件化精度预算与指代绑定**：在不写任务分支的前提下，同时服务插入类高精度任务与叠放类低精度任务，并对未见物品/干扰物提供开放词表接地。
5. **一套零成本接口标定与审计**：把 `image_resize`、`obs_delta_indices` 的物理含义显式化，连同标定卡、延迟与动作审计一起交付。

## 7. 本轮最大风险

**一句话**：本轮把赌注压在“标定参数可从自运动观测中估出来”上，而**可辨识性可能根本不够**——物体位姿未知、无标定靶、运动激励有限，外参与物体运动、时延与运动模糊会相互混叠；一旦可辨识子空间太窄，LAC 就退化成“多花几秒做一次无用的估计”，反而用额外延迟与误判压低成功率。

## 8. 下一轮迭代计划（深化与修剪）

- **深化**：把 IP-09 从“一次性探测”升级为“**随 episode 持续更新的标定状态机**”（在运动丰富时提高可辨识性）；把 IP-11 的保形集从全局升级为按机器人/任务簇/精度预算分层。

## 0. 本轮结论摘要

**一句话路线**：第 1 轮造“能力栈”，本轮补**规范层**——先用“机器人自身即靶”的自标定把观测变成跨机器人可比，再用语言嵌入作为不变锚与精度预算，最后把所有介入判据换成**有覆盖率保证的校准不确定性**。

**为什么是“标定 × 语言”（四条依据）**：

| 依据 | 数值 / 事实 | 推出的设计 |

| 最难的 6 个任务全是插入/旋转/细粒度摆放（Plug In Ethernet 17.7、Unlock 20.1、Spell robot 21.8） | 容差接近亚毫米–毫米级 | 先算**标定误差预算**（L8）；插入必须闭环 + 接触搜索（IP-13） |

## 2. 新创新点详述

### IP-09 · CalibProbe 自标定探测（P0）

- **动机**：评测在 N 台未知机器人上；相机支架、固件、夹爪零点可能不同；评测端还做 `image_resize`，`obs_delta_indices` 又改变了时序间隔。第 1 轮的抓握/相位/速度判据都建立在“坐标、像素、时间是对的”这一未言明前提上。
- **与现有方案的差异**：常规做法是“用数据集名义内参/外参 + 域随机化”硬扛；或者在部署前用手眼标定板标一次。我们做的是**运行期、无靶标、用机器人自身**的自监督探测：夹爪与静态桌面就是靶，前向运动学与光流就是对应点，语言先验缩小搜索。
- **五个子模块**：
  1. **接口标定（零成本，必做）**：从声明的 `image_resize=[H',W']` 推出有效内参 `K_eff = diag(W'/W, H'/H, 1)·K0`；从 `obs_delta_indices` 推出帧间隔 `δτ = |Δindex|/fps`（如 `[-2,0]` → 66.7 ms，不是 33.3 ms）。所有像素→米、速度、相位时间常数都改用 `K_eff` 与 `δτ`。
  2. **手眼旋转**：腕部光流在静态背景上给出相机旋转 `R_cam(t)`；前向运动学给出末端旋转 `R_ee(t)`；解 `R_cam = R_ee · R_x`（Wahba / AX=XB 的旋转子问题）。要求至少 2 个非共线旋转轴，堆叠对数向量秩 ≥2。
  3. **时延**：对 `|flow_t|` 与 `|joint_vel_t|` 做互相关，在 `δt ∈ [−3, +3]` 帧内取峰；要求 episode 前段速度非恒定（有激励），否则不更新。
  4. **夹爪零点/量程**：用“全闭堵转”作为零点锚，配合数据中已知物体宽度回归量程；至少 2 个不同宽度才可辨识，否则只更新零点、不更新量程。
  5. **信任域融合**：`κ̂ = κ0 + λ(κ̂_raw − κ0)`，`λ = σ0²/(σ0²+σ_raw²)`；不确定度大时 `λ→0`，退回名义值（与第 1 轮 L6 同构）。
- **技术可行性**：高–中。所有输入都在官方观测里；光流可用轻量网络或 Lucas–Kanade；AX=XB 有闭式解。难点是激励不足与动态场景（人手/物体在动）——用 RANSAC 选静态背景、按时段加权。
- **所需资源**：探测 1–3 s，在线额外 ≤15 ms/次（只在 episode 前段/周期触发）；离线无需新数据。
- **落地步骤**：①先做接口标定并与数据回放对齐；②在官方数据上回放验证光流手眼（用数据集的多机器人差异做留一）；③时延互相关；④夹爪零点；⑤信任域与退化；⑥真机 A/B。
- **风险**：①动态场景让光流失效 ⇒ RANSAC + 静态掩码；②平移不可辨识 ⇒ 只用旋转与时延，平移交给闭环/深度；③探测动作改变初始状态 ⇒ 限制在“原地小幅运动”，不移动物体。

### IP-10 · LangAnchor 语言锚 + 精度预算（P0）

- **动机**：语言是唯一与机器人、标定、背景都无关的信号。第 1 轮只把它当任务标签，浪费了它的不变性与语义带宽。
- **与现有方案的差异**：不是“用语言选任务分支”，而是把 `u = E_L(ℓ)` 作为**连续锚**，同时做三件事：①作为标定先验 `p(κ|u)`（同类任务共享相机工作距离/精度需求）；②预测精度预算 `β(u)`；③作为 FiLM/门控条件喂给专家与规范层。全程无离散分支。
- **技术可行性**：高。评测一定给 `observation.language`；`u` 可用冻结文本编码器或策略自带语言塔；β 可用数据中的“阶段时长/失败容差”弱监督。
- **所需资源**：文本编码 <2 ms；训练只需在现有数据上加语言输入；无需新采集。
- **落地步骤**：①从官方 32 数据集提取指令文本，检查是否同义改写；②训练 `g_β: u → β`（弱标签：任务容差/阶段时长/是否插入类）；③把 β 接到 chunk 长度、验证频率、接近速度、搜索半径；④用 `u` 条件化标定先验做消融；⑤在未见物品/干扰物上测指代（与 IP-12 联动）。
- **风险**：①文本模板过窄导致 `u` 退化成任务 ID ⇒ 用同义改写增强，并保留通用锚；②β 预测错 ⇒ 用上下限裁剪 + 保形/分位数回归；③被误判为“读题硬编码” ⇒ 保持连续调制、无 `if` 分支、在代码审计中可自证。

### IP-11 · ConformalGate 分组保形介入门（P0）

- **动机**：第 1 轮的 `τ_conf` 是经验阈值，且“漏判把可救失败变硬失败”的成本不对称。若不校准，高置信只是模型自说自话；跨机器人后更不可信。
- **与现有方案的差异**：把“是否干预”从阈值判定改成**风险控制的集合预测**：对抓握隐变量、指代候选、相位判定分别构造保形集 `C_α`，并按机器人/任务簇分组校准；只有“未抓住”的判据进入 `C_α` 且风险上界 ≤ρ 时才干预。
- **技术可行性**：中–高。需要离线校准集与可交换性假设；跨机器人时用分组条件保形与保守 α；必要时用 ACI（在线 α 调整）作兜底。
- **所需资源**：校准集（可从官方数据 + 仿真/回放构造）；在线只做查表与比较，<1 ms。
- **落地步骤**：①定义非一致性分数（如 `1−g_t`）；②按 (机器人, 任务簇) 分组校准分位数；③实现风险控制阈值选择；④在代理评测上测覆盖率/假阳性；⑤偏移过大时降级为“不干预”。
- **风险**：①**可交换性被新机器人打破** ⇒ 分组 + 保守 α + 只在高置信时用；②校准集太小 ⇒ 用分层 bootstrap 与置信下界；③保形集为空 ⇒ 默认不干预（安全侧）。

### IP-12 · ReferentBind 语言指代绑定（P1）

- **动机**：5 类泛化里“未见物品 / 干扰物 / 位置”本质是**指代问题**：模型要能按指令里的名词、属性、空间关系选中目标，而不是记住训练布局。
- **与现有方案的差异**：不做端到端黑箱，而是“语言解析 → 开放词表检测/分割 → 候选集 → 校准边际 → 提交/回退”的可审计流水线；候选集保持多假设，直到边际足够大才提交给策略。
- **技术可行性**：中–高。开放词表检测（如 Grounding DINO）与分割（SAM）已成熟；难点是细粒度桌面小物体与遮挡。
- **所需资源**：检测/分割模型（可离线/异步）；算力中等；延迟需控制在预算内（可只在 episode 前段与遮挡恢复时跑）。
- **落地步骤**：①解析指令的名词短语/属性/空间关系；②生成候选框与 mask；③用校准分数与空间约束消歧；④把选中的目标作为额外条件（不替代 VLA，只提供 ref）；⑤在未见物体/干扰物切分上 A/B。
- **风险**：①错绑目标比不绑更糟 ⇒ 校准边际 + 多假设 + 回退；②检测延迟 ⇒ 异步/缓存；③指令无属性时歧义 ⇒ 交给策略隐式接地。

### IP-13 · SearchInsert 接触搜索 + 柔顺插入（P1）

- **动机**：L13 证明纯视觉伺服**不消除恒定外参偏差**；而插入容差已接近标定误差。必须让物理交互吸收残差。
- **与现有方案的差异**：不是“更准地看”，而是“**在看不准的情况下也能插进去**”：小范围螺旋/扫掠搜索 + 柔顺/阻抗控制 + 接触事件检测 + 失败回退。语言/β 决定搜索半径与速度。
- **技术可行性**：高（若可控接口允许位置/速度指令与柔顺参数）；难点是只有 1 维夹爪、无触觉，接触只能从腕部视觉 + EE 位姿/速度 + 关节电流（若可得）间接判。
- **所需资源**：真机/仿真试验；算力小；数据可用官方插入类 episodes 做轨迹先验。
- **落地步骤**：①从数据提取插入轨迹与失败模式；②实现螺旋搜索与柔顺参数调度；③用腕部视觉 + EE 微动做接触检测；④按 β 控制搜索半径/速度；⑤在 Plug In Ethernet / Unlock / Open Pill Bottle 上 A/B。
- **风险**：①搜索造成碰撞/破坏 ⇒ 限幅、限半径、限次数；②无触觉导致接触检测误判 ⇒ 多信号 + 保守回退；③柔顺降低定位精度 ⇒ 只在对齐/插入相位启用。

### IP-14 · CalibCard 标定卡与探测审计（P2）

- **动机**：官方会看延迟波动与动作统计可信度；标定探测也必须可自证“没有做奇怪的事”。
- **做法**：每端口导出 `κ̂`、`σ_κ`、探测耗时、降级次数、光流内点率、时延峰值；把这些与第 1 轮 IP-08 的延迟/jerk 看板合并。若探测内点率低或时延置信区间宽，自动标记 `calib=degraded` 并收紧介入。
- **风险**：日志本身增加延迟 ⇒ 异步写、采样。

### 对第 1 轮资产的必要修正

- **IP-02（抓握确认）**：`v_ee`、`Δgrip` 与腕部几何统一到 `Φ_κ` 规范系；`g_t` 的阈值由 IP-11 的保形集替换；增加“时延补偿后的随动”特征，避免把基座/时延误读成抓握成功。
- **IP-06（六因子代理评测）**：分解改为先过“标定可用门”，并把失败因子细化为 `{reach, grasp, transport, align, insert, release, calib}`；`calib` 因子专门记录“因标定退化导致的失败”，使归因可分离。
- **IP-03（chunk）**：`obs_delta_indices` 的时间语义进入 `T_a` 调度；短 chunk 的“高频反馈”必须用真实 `δτ` 计算，而不是假设 33 ms。

| `c` | 任务单边容差 |
| `P` | 标定探测动作序列长度（帧） |

**定义 U13（标定参数）** `κ_r = (K_r, T^{cam←ee}_r, Δt_r, b^grip_r)`，其中 `K_r` 是 resize 后的有效内参，`T` 是腕部相机到末端的刚体变换，`Δt` 是视觉相对本体的时间偏移，`b^grip` 是夹爪零点偏移。
**定义 U14（观测生成）** `o_t = h(x_t; κ_r) + ε_t`，`x_t` 为真实世界状态；同一 `x_t` 在不同 `κ_r` 下生成不同观测。
**定义 U15（可辨识性）** 若存在估计器 `g` 使 `‖g(o_{1:T}, a_{1:T}) − κ‖ ≤ δ` 对激励集合 `E` 内所有轨迹成立，则 `κ ∈ I(κ)`；否则 `κ ∈ N(κ)`。
**定义 U16（自标定探测）** 在 episode 前段执行动作序列 `a^cal_{1:P}`（原地小幅运动），得到估计 `κ̂ = g_κ(o^cal, a^cal, u)`。
**定义 U17（语言锚）** `u = E_L(ℓ)`；假设 `u ⟂ (r, κ)`（同一任务文本下）。
**定义 U18（语言条件化标定先验）** `κ̂ = argmax_κ p(o^cal | κ) · p(κ | u)`，`p(κ|u)` 由同类任务的历史标定估计得到。
**定义 U19（精度预算）** `β = g_β(u) ∈ [0,1]`，控制 `(T_a, f_verify, v_approach, r_search)`：`T_a` 随 β 增大而减小，`f_verify`、`r_search` 随 β 增大而增大，`v_approach` 随 β 增大而减小。
**定义 U20（规范系）** `Φ_κ: o ↦ o^canon` 使 `Φ_κ ∘ h(·; κ)` 对 κ 的一阶敏感度在 `I(κ)` 上被补偿；`N(κ)` 分量不进入下游判据。
**定义 U21（分组保形集）** 对组 `g=(robot, task-cluster)`，用非一致性分数 `s(o)=1−g_t` 在组内校准分位数 `q_g`，`C_α(o) = {y : s(o,y) ≤ q_g}`。
**定义 U22（风险控制介入）** 仅当“未抓住”判据进入 `C_α` 且估计风险 `R_int ≤ ρ` 且重抓次数 `<3` 时干预。
**定义 U23（指代候选集）** `B(u,o) = {(b_i, m_i, s_i)}`，`s_i` 为校准分数；当 `s_(1) − s_(2) > τ_margin` 时提交 `b_(1)`，否则保持多假设/回退。
**定义 U24（误差预算）** `ε_cal = sqrt((d·δθ)² + (d·FOV/W)² + (v·δt)² + ε_g²)`；开环插入可行必要条件 `ε_cal < c/2`。

# ===== IP-09：自标定探测（接口 / 手眼旋转 / 时延 / 夹爪零点）=====
class CalibProbe:
    def __init__(self, kappa0, prior):
        self.k0 = kappa0          # 名义标定（数据集）
        self.prior = prior        # p(kappa | u)

    def interface_calib(self, meta):
        # 评测端 cv2 resize：有效内参按比例缩放
        H0, W0 = meta["native_hw"]
        Hr, Wr = meta["image_resize"]
        K_eff = scale_intrinsics(self.k0.K, Wr / W0, Hr / H0)
        # obs_delta_indices 决定真实帧间隔，而不是想当然的 1/fps
        dt = max(abs(i) for i in meta["delta_indices"]) / meta["fps"]
        return K_eff, dt

    def estimate(self, obs, acts):
        # 1) 手眼旋转：静态背景光流 vs 前向运动学
        R_cam = optical_flow_rotation(obs.wrist_frames, mask=static_mask(obs))
        R_ee  = fk_rotation(acts, obs.joint_state)
        R_x   = solve_wahba(R_ee, R_cam)          # R_cam = R_ee @ R_x
        # 2) 时延：互相关取峰（要求速度有激励）
        dt    = argmax_dt(corr(|flow|, |joint_vel|, dt_range=[-3, 3]))
        # 3) 夹爪零点：全闭堵转 + 已知宽度回归
        b_g   = estimate_gripper_bias(obs.gripper, obs.object_widths)
        raw   = Calib(K_eff, R_x, dt, b_g)
        return self.fuse(raw)                     # 信任域融合

    def fuse(self, raw):
        # 不确定度大 -> 回退名义标定（与 L6 同构）
        lam = self.sigma0**2 / (self.sigma0**2 + raw.sigma**2 + 1e-9)
        return self.k0 + lam * (raw - self.k0), lam
```

# ===== IP-11：分组保形介入门 =====
class ConformalGate:
    def __init__(self, calib_by_group, alpha=0.05, rho=0.02):
        self.q = calib_by_group         # 每组的分位数
        self.alpha, self.rho = alpha, rho

    def should_intervene(self, g_t, group, n_retry):
        q = self.q.get(group, self.q["global"])
        s = 1.0 - g_t
        in_set = s <= q                     # "未抓住"进入保形集
        risk_ok = self.risk_upper(group) <= self.rho
        return in_set and risk_ok and n_retry < 3
```

        a = self.stitch.stitch(a, s.last_action)

## 5. 推导（L8–L14）

**引理 L8（标定误差预算 ⇒ 插入可行性）** 设误差源近似独立，`ε_cal = sqrt((d·δθ)² + (d·FOV/W)² + (v·δt)² + ε_g²)`。若开环绝对定位，插入成功的必要条件是 `ε_cal < c/2`。若误差近似零均值高斯 `N(0, σ²)`，则 `P(success) ≈ erf(c/(2√2σ))`。代入 `c=2 mm, σ=1 mm` 得 ≈68%；`c=0.5 mm, σ=1 mm` 得 ≈20%。⇒ 最难任务不能依赖开环绝对定位。∎

**引理 L9（可辨识性子空间）** ①手眼**旋转**：静态背景光流给出 `R_cam(t)`、FK 给出 `R_ee(t)`，至少 2 个非共线旋转轴时 AX=XB 旋转子问题有唯一解（Wahba）。②时延：`|flow|` 与 `|joint_vel|` 的互相关峰唯一，当且仅当速度序列非恒定（有激励）。③夹爪零点：全闭堵转给零点；量程需 ≥2 个已知宽度。④**平移**：无深度时只到尺度，需立体头或已知桌面平面。⇒ 旋转/时延可信，平移应交给闭环与接触。∎

**引理 L10（语言锚的不变性收益）** 在 Lipschitz 损失假设下，跨机器人风险差满足 `|R_1 − R_2| ≤ L·W₁(p(o|u,r_1), p(o|u,r_2))`。若 `u ⟂ (r,κ)` 且规范层把 `p(o|u,r)` 对齐到同一 `Φ_κ` 空间，则右端由 `O(‖κ̂−κ‖)` 控制而非由整幅图像距离控制。⇒ 以语言为条件的规范化比无条件域适应有更小的有效差异。∎（该界是启发式上界，非有限样本保证。）

**引理 L11（探测的“免费性”）** 由第 1 轮 L1，得分只依赖终态成功；时长不影响得分。若探测耗时 `Δ` 满足 `T_required + Δ ≤ T_max` 且探测不改变物体初始状态，则 `E[score]` 不因探测下降；只要探测使 `P(success)` 上升，期望得分为正。⇒ 在总时长不紧时，1–3 s 探测是理性投资。∎（若总时长成为硬约束，则本引理失效，必须设探测上限。）

**引理 L12（保形覆盖与偏移）** 在可交换性下，split conformal 给出 `P(Y ∈ C_α) ≥ 1−α`；分组条件保形在每个校准组内给出同样覆盖。跨到新机器人时若可交换性不成立，覆盖不再有保证；此时只能用保守 α、分组校准或 ACI 作启发式兜底。⇒ 我们能保证的是“校准分布内”的覆盖，跨机器人只是**经验**保证，必须在 E629 实测。∎

**引理 L13（纯视觉伺服不消除恒定外参偏差——负结果）** 设真实误差 `e = x − x*`，标定偏差为常数 `b`，则观测误差 `ẽ = e + b`。视觉伺服驱动 `ẽ → 0`，于是 `e → −b`，物理残差恰为 `−b`。⇒ 对容差 `c` 的插入，纯闭环成功仅当 `|b| < c/2`；否则必须接触搜索或在线估 `b`。这直接推出 IP-13 的必要性。∎

**引理 L14（信任域融合的有界退化）** 令 `κ̂ = κ0 + λ(κ̂_raw − κ0)`，`λ ∈ [0,1]`。若下游输出对 κ 的 Lipschitz 常数为 `L_κ`，则相对名义行为的偏离 `≤ λ·L_κ·‖κ̂_raw − κ0‖`。当不确定度大时 `λ→0`，最坏退化为名义标定（与第 1 轮 L6 同构）。⇒ 自标定是“可关、可回退”的增益，不是不可逆风险。∎

## 11. 本轮最值得押注的创新点（一句话）

**押注 IP-09 的“接口 + 时延”标定与 IP-11 的分组保形介入门：前者几乎零成本地把被误读的像素与时间还原成物理量，后者把第 1 轮“高精度低召回”的经验阈值升级成有覆盖率保证的判据——两者都不依赖“标定可辨识”这一高风险假设，却直接削减当前最大的两类系统性失败（插入错位与抓握漏判）。**

**本轮最大风险（一句话）**：标定参数从自运动观测中的可辨识性可能不足以支撑整套 LAC 叙事——外参与物体/基座运动、时延与运动模糊相互混叠，一旦可辨识子空间太窄，规范层就只剩“多花几秒做一次无用估计”，反而用额外延迟与误判压低成功率。
