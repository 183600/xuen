## 1. 直觉与动机（两个灵感的碰撞，再落到统一命题）

**灵感 1（行为克隆 → 赛题就是 BC，而 BC 的三个原罪正好对应三块丢分）**
直觉：整场比赛就是对一个 32k 示教集做行为克隆。BC 的教科书失败模式只有三类，且每一类都能映射到本赛的丢分点：
- **协变量漂移/误差累积**：策略一旦在抓取/接触时刻偏一点，就滑出专家状态流形；动作分块（H=30）把累积误差限制在一个 chunk 内，但**抓取决策点**没有第二道保险。
- **虚假相关（causal confusion）**：BC 会抓最容易降低训练损失的线索——背景、机械臂自身位姿、物体颜色；而这些恰好就是评测要扰动的 5 条泛化轴。也就是说，**泛化轴在惩罚 BC 的捷径**。
- **目标错配**：BC 最大化「专家动作似然」，评测却按「得分点/成功率」给分。遥操作里的停顿、犹豫、微抖与决定性抓取帧被同等加权。

反直觉点：BC 的下一分不是靠更大的模型，而是靠**重加权目标 + 注入结构约束**。

**灵感 2（抓取规划 → 抓取是主导原语，但最不该在推理期外挂 planner）**
直觉：32 任务大多可归约为「抓取 → 搬运 → 放置/插入」。显式抓取规划在**未见物体几何**上很强，正好命中第 4 条泛化轴；但本赛接口没有深度、没有相机标定（F20），外挂 6-DoF planner 既不可靠，也会撞上「单模型」边界与延迟预算。所以抓取规划在本赛的正确角色是**老师，不是队友**：用示教里现成的 EE pose + gripper 信号挖掘抓取事件与抓取标签，把「抓取点/接近方向/宽度」蒸馏成动作专家的**辅助监督**；推理期最多做软重排/软门控，绝不并联第二个策略。

反直觉点：**抓取规划最大的价值不是「推理时规划」，而是「训练时当标签生成器和正则项」——它把几何先验压进 BC，而不是与 BC 竞争。**

**统一命题（结构-目标引擎）**
v1.1 的结论是「中期胜负手在数据引擎」。本轮补上它的缺口：数据已经够多（32k 示教 + 110 语料），但**数据里的「决策时刻」和「得分优势」没有被标出来**。于是：
- **I10（结构）**：抓取事件挖掘 + 抓取感知辅助监督——告诉 BC「哪几帧是抓取决策，几何上该怎么抓」；
- **I11（目标）**：得分优势加权 BC——告诉 BC「哪些帧/片段真正换来分数」；
- 交叉升级：I5 v3 用抓取库做「重抓式」恢复合成；I9 v2 把检索从整段动作参数细化到抓取几何；I2 v3 从 episode 级质量加权升级到 frame 级优势加权；I8 增加 BC 专属的 L0 代理（协变量漂移、抓取帧误差）。
- 修剪：**I7 世界模型推理路径本轮正式裁撤**（4 步扩散 + H=30 已吃掉延迟余量），WMA-0 资产只保留为 I5 数据引擎。

一句话反直觉结论：**行为克隆的下一分不来自更多示教，而来自把示教按「决策时刻 × 得分优势」重新加权，并把抓取几何作为结构化标签蒸馏进去。**

## 2. 对 v1.1 痛点的增量修订

- **P8（示教质量）升级**：episode 级质量加权会把「好 episode 里的坏帧」和「坏 episode 里的好帧」一视同仁；I11 改为 frame 级得分优势加权，episode 质量只作先验。
- **P4（无触觉）细化**：抓取事件可由 gripper 开度变化率 + EE 速度 + 视觉接近共同定位，是「接触起始」的弱代理，不是真力信号；只能算部分缓解。
- **P2（泛化缺口）补充机制**：I10 的几何辅助头迫使策略依赖物体轮廓/抓取几何，理论上削弱背景/颜色捷径——这是对「虚假相关」的第一条针对性干预。
- **P1（弱任务洼地）细化**：最弱任务多为抓取/插入瓶颈（PlugCharger、ZipUp、PickOutBatteries 等），I10 直接对准瓶颈帧，而不是全局平摊容量。
- **新增 P9（代理目标劫持）**：一旦开始优化「进度/优势代理」，代理误差会从随机噪声变成**系统性偏差**；加权 BC 比均匀 BC 更难从 loss 上察觉退化，这是本轮的首要风险。

## 3. 研究问题（本轮立项 Q9–Q10，Q1–Q8 保留）

- **Q9（抓取监督）**：在无深度、无标定、无力的条件下，如何从示教稳定挖掘抓取事件，并定义**可迁移且可监督**的抓取标签（2D 抓取点、接近方向、宽度、EE 相对位姿）？辅助损失与主扩散损失如何配比，才不伤平滑接近段？
- **Q10（决策感知 BC）**：用得分点进度作价值代理的 advantage weighting，在扩散 BC 上的偏差-方差如何控制？在什么信噪比/有效样本量下相对均匀 BC 有净增益，何时应退回均匀？

## 4. 设计原则（新增 PR6、PR7，其余保留）

- **PR6 结构化监督律**：任何先验若要进入策略，优先以「训练时辅助标签/损失」形式蒸馏，而非推理期并联模块——同时满足单模型边界与延迟预算。
- **PR7 目标-度量一致性律**：训练损失中的样本权重必须能追溯到计分轴（scoring step / success）；只用动作似然的加权视为未完成对齐。
- PR1–PR5 保留（PR5 数据杠杆律继续约束 110 语料权重）。

## 6. 本轮最大风险

**一句话**：I10 的抓取标签来自「gripper 信号 + 视觉」的弱代理，I11 的样本权重来自「进度头估的得分优势」——两者都是代理标签；一旦代理与真实计分不一致，加权 BC 会系统性地优化错的东西（reward hacking），而且比均匀 BC 更难从 loss 上察觉，因此必须先用 L0 代理有效性检验 + 权重下限 + 与均匀 BC 的混合比例 ρ 兜底，再上计分通道。

## 7. 下轮迭代计划（深化与修剪，不推倒）

- **深化**：I10（抓取事件阈值与辅助损失配比的 L0 扫描；「抓取点/接近方向/宽度」三标签的最小充分集）；I11（优势估计的方差与有效样本量 ESS 分析，确定 ρ 混合比例）。
- **修剪**：I7 推理路径已裁撤；I1 的「位置重拼接」改为必须过 I10 抓取可行性过滤，否则只保留平移不变增广；I3 若 2D/2.5D 伺服在 L0 无法稳定，降级为纯辅助监督。
- **待核实**：数据集是否附带深度/相机标定（提交接口没有，但训练数据可能另有通道）；gripper 信号是二值还是连续、闭合方向定义；每任务得分点 JSON 与精确步骤分公式；110 语料各任务 eps 数与相机配置。

# UniBot-V1 参赛创新点清单（第 2 轮 v1.2）

> 检索日期：2026-11-26（第 1 轮）、2026-11-27（本轮）；来源见 §5。承接 v1.1：新增 I10/I11，升级 I2/I5/I8/I9，I7 推理路径裁撤，I1/I3/I4/I6 维持。清单只增改不重置。本轮主题：**把抓取几何（结构）与得分优势（目标）蒸馏进行为克隆**。

## 0. 创新点清单（每点：动机 / 与现有方案差异 / 技术可行性 / 所需资源 / 落地步骤 / 风险）

### I10 抓取事件挖掘 + 抓取感知辅助监督（新） ★★★★★
- **直觉**：抓取是 32 任务的主导原语，也是误差累积最致命的一帧；但 BC 对抓取帧与普通帧一视同仁。抓取规划在本赛不该做推理期外挂 planner（无深度/无标定/单模型边界，F20），而应做**训练期老师**：示教里已有 EE pose 与 gripper 开度，抓取事件和抓取位姿是免费标签。
- **严谨定义**：对一条示教轨迹 $\{(o_t, T_t, g_t)\}$（$T_t$ 为 EE 位姿，$g_t$ 为 gripper 开度），定义闭合时刻
  $t_g=\min\{t: g_t\le g_{\text{close}}\ \wedge\ g_{t-1}>g_{\text{close}}+h\}$，
  预抓取窗 $W=[t_g-k,\,t_g]$。抓取标签 $y=(u^*,v^*,\theta^*,w^*,T_g)$：$(u^*,v^*)$ 为接触点在 wrist 相机像平面的投影，$\theta^*$ 为接近方向（离散 8 桶或连续角），$w^*=g_{t_g}$ 为闭合宽度，$T_g=T_{t_g-\delta}$ 为预抓取 EE 位姿。在动作专家共享主干上加三个轻头：抓取热图 $\hat H\in[0,1]^{h\times w}$、宽度回归 $\hat w$、接近方向分类 $\hat\theta$。总损失
  $\mathcal L=\mathcal L_{\text{diff}}+\lambda_a\mathcal L_{\text{aff}}+\lambda_w\mathcal L_{\text{width}}+\lambda_\theta\mathcal L_{\text{ang}}$。
- **与现有方案差异**：纯 BC 没有抓取显式结构；外挂 GraspNet 类 planner 需要深度/标定且违反单模型边界。I10 只用**示教内已有信号**造标签，蒸馏进同一网络，推理期默认零并联（PR6）。
- **技术可行性**：中-高。抓取事件检测是纯数据处理；辅助头参数量可忽略；关键难点是 gripper 信号语义（二值/连续、左右手独立）与接触点投影（无内参 → 用 wrist 相机图像坐标 + EE 位姿反投影的近似）。仅对抓取/插入类 ≈18–22 个任务启用，其余任务用指令门控关闭辅助头。
- **所需资源**：抓取标签挖掘 + 质量抽检 1 人周；辅助头训练复用现有单卡（F11）；无需新数据下载。
- **落地步骤**：①统计 32 任务 gripper 信号形态，定 $g_{\text{close}},h,k$；②在 3 个抓取任务（PickOutBatteries / StoreCups / PackPhone）挖标签并人工抽检 5%；③加三辅助头做 LoRA 增量训练，扫描 $\lambda$ 配比；④L0 检验「不伤标称抓取帧误差」；⑤可选推理期软重排（采样 K 个 chunk，用 $\hat H,\hat w$ 与预测抓取帧一致性打分，K 受延迟预算约束）——默认关闭。
- **风险**：gripper 闭合≠接触成功（空抓、滑移），标签噪声；无深度导致只有 2D/2.5D 抓取，不是真 6-DoF；辅助损失过大伤平滑接近段。缓解：三信号（开度变化率 + EE 速度 + 视觉接近）联合判定、置信门控、$\lambda$ 从小起步、L0 抓取帧误差与接近段平滑度双指标。

### I11 得分优势加权行为克隆（新） ★★★★
- **直觉**：BC 最大化所有专家动作的似然，但评测按得分点给分；遥操作中的停顿、犹豫、微抖与决定性抓取帧等权，是目标错配。把「这段动作之后多拿了多少分」作为权重，BC 就会把容量集中到真正换分的片段。
- **严谨定义**：用进度头/得分点检测器构造价值代理 $V_\psi(o_t,l)\approx$ 已达成得分点比例（$l$ 为任务指令）。回报 $R_t=V_\psi(o_T)-V_\psi(o_t)$，优势 $A_t=R_t-b(o_t)$，$b$ 为 per-task 均值或 EMA 基线。权重
  $w_t=\mathrm{clip}\big(\exp(A_t/\beta),\,w_{\min},\,w_{\max}\big)$，batch 内归一化；或 top-$q$ 过滤（filtered BC）。扩散 BC 的加权去噪损失：
  $\mathcal L=\mathbb E_{t,k,\epsilon}\big[w_t\,\|\epsilon-\epsilon_\theta(a_t^0+\sigma_k\epsilon,\,k,\,o_t)\|^2\big]$。
  与均匀 BC 混合：$w'_t=(1-\rho)+\rho\,w_t$，保证 $\rho=0$ 可完全回退。
- **与现有方案差异**：v1.1 的 I2 只在 episode 级按质量加权；I11 到 frame 级、且权重直接对齐得分轴（PR7）。相对 AWR/过滤 BC 的增量在于价值代理来自**本赛官方得分点**而非外部奖励。
- **技术可行性**：高。价值代理复用 I5 的得分点进度头；加权是损失层改动，不增加推理成本。
- **所需资源**：进度头（I5 已有）1 GPU 日校准；无额外推理预算。
- **落地步骤**：①在留出集上验证 $V_\psi$ 与真实步骤分的 Spearman；②固定 $\beta$ 扫描 $\rho\in\{0,0.25,0.5,1\}$；③监控有效样本量 $\mathrm{ESS}=(\sum w)^2/\sum w^2$，低于 $0.5N$ 即增大 $\rho$；④与均匀 BC 做同预算 L0/L2 A/B。
- **风险**：代理目标劫持（P9）——价值头误差被加权放大；权重过集中导致多模态覆盖下降、长尾任务退化。缓解：$w_{\min}\ge0.2$、$\rho$ 混合、per-task 归一化、ESS 监控、留出集真实得分相关门槛（<0.5 不上线）。

### I2 v3 数据引擎 2.0：孪生迁移 + 加权共训 + 帧级优势 ★★★★★
- **动机**：单模型平均分被最弱任务支配（P1）；示教语料与质量双重浪费（P8）。
- **本轮深化**：v1.1 的三件事保留（110 语料孪生表、官方 loader 加权 patch、episode 质量加权），新增两件：
  1. **帧级得分优势加权**（I11）：episode 先验 × frame 优势，替代单一 episode 质量分；
  2. **抓取质量过滤**（I10）：抓取标签置信度低或宽度异常的 eps/片段降权，避免把空抓/滑移示教当成功样本。
- **与现有方案差异**：均匀混训 + 仅 episode 质量加权仍会放大「好集里的坏帧」；v3 把权重落到决策帧。
- **技术可行性**：高（LoRA/frozen-VLM 单卡起步，F11；全参 4–8 卡）。
- **所需资源**：孪生子集 ≈1–2TB + 32 任务 ≈2TB；训练 1×24GB 起步。
- **落地步骤**：①孪生表；②loader patch + batch 内任务频率单测；③帧级权重接入；④抓取质量过滤；⑤族级 L0 正/负迁移验证后放量。
- **风险**：负迁移（孪生任务动态相反）与权重噪声叠加——缓解：家族级 L0、低权重起步、退步即裁剪；权重与均匀混合回退。

### I5 v3 非标称示教合成 + 得分点对齐恢复 ★★★★
- **动机**：步骤分为官方得分点制（满分 100），超时仍按进度计分；示教全成功、无失败（P8）。
- **本轮深化**：v1.1 的扰动重放/跨段缝合/世界模型生成/得分点自动标注保留，但**抓取类失败改为「抓取库引导的重抓恢复」**：从 I10 抓取库检索同一物体外观下最近的成功抓取 $y^\star$，把当前偏离态到 $y^\star$ 的 EE 相对位姿用最小 jerk 插值，生成「偏离→回抓→继续」段；非抓取类（折叠、拉链、按键）仍用扰动重放。世界模型（WMA-0）只作离线续写，不进推理（I7 已裁撤）。
- **与现有方案差异**：v1.1 的扰动重放对抓取失败可能生成物理不可行的「原地重抓」；v3 用真实成功抓取几何做目标，恢复动作更在分布内。
- **技术可行性**：中-高（纯数据工程 + 插值；依赖 I10 标签质量）。
- **所需资源**：1×24GB GPU；数据工程 2 人周；检测器 1 GPU 日/任务族。
- **落地步骤**：①得分点逆向；②3 个弱任务试点（PlugCharger/ZipUp/PickOutBatteries）；③重抓合成 + 得分点过滤；④进度头改得分点监督；⑤单任务通道 A/B。
- **风险**：合成段与真实偏离分布失配、里程碑检测器误差污染标签。缓解：扰动幅度从考纲卡采样（与 I1 共用）、置信门控 + 人工抽检 5%、只用达成下一得分点的合成段。

### I9 v2 reset 期检索类比迁移 ★★★★
- **动机**：未见物品轴（同类不同外观）在 32 任务 × 2/10 次全面出现；纯参数化泛化对新外观方差大。
- **本轮深化**：检索目标从 v1.1 的「整段动作参数」细化为**抓取几何 + 技能模式**：库条目 = (物体外观嵌入, 抓取点/接近方向/宽度 $y$, 技能标签)。`reset()` 每 episode 一次检索（F18），命中则把 $y$ 作软先验注入抓取帧的宽度/接近方向门控；超距阈值退回无先验。零权重更新、零每步开销。
- **与现有方案差异**：I10 是训练期蒸馏，I9 是推理期一次性检索，两者共用同一个抓取库——训练与推理同一知识源，避免两套几何先验打架。
- **技术可行性**：中-高。库离线构建；检索 <1s。
- **所需资源**：嵌入 1×GPU 日 + FAISS；1 人周。
- **落地步骤**：①物体库（首帧开放词汇检测裁剪）；②嵌入 + 索引；③抓取几何参数化；④reset 检索 + 软注入；⑤未见轴 L0 + 真机抽测。
- **风险**：误检索注入错误先验；VLM 嵌入对同类不同外观不敏感；reset 检索合规性需书面确认。缓解：距离阈值 + 软偏置、DINOv2 patch 特征池化、L0 不伤标称场景、向组委会确认。

### I8 v3 评测运营闭环 + 分级消融注册表 ★★★★
- **动机**：真机通道稀缺 + 待验证组合爆炸（P7）；新增 I10/I11 两个便宜但高杠杆的开关，必须先离线筛。
- **本轮深化**：L0/L1/L2 分级与离线-在线相关性注册表保留，新增 **BC 专属 L0 代理**：
  - **协变量漂移代理**：在留出示教上做闭环重放/教师强制对比，测状态访问分布散度与动作误差随 horizon 的增长斜率（compounding slope）；
  - **抓取帧误差 Δgrasp**：抓取窗内动作误差（I10 标签对齐）；
  - **权重健康度 ESS**：I11 权重的有效样本量与 per-task 覆盖率，防模式坍缩。
  L1 首个 2×2 析因：{I10 aux on/off} × {I11 weighting on/off}；L2 只测 top 组合。
- **技术可行性**：高（L0 纯离线）。
- **所需资源**：代理指标 1 人周；注册表 = 表格 + 脚本。
- **落地步骤**：①代理实现；②注册表 schema；③首个用例 = I10×I11 析因；④滚动 Spearman 复盘。
- **风险**：离线代理与真机增益相关建立慢。缓解：用 3–4 个已知真机结果回填；相关性 >0.6 才单独准入 L2。

### I1 v2 考纲校准五轴增广引擎 ★★★★★（维持 + 小改）
- 六要素同 v1.1：32 张考纲卡、5 轴按官方 wiki 校准、剂量-响应、轴间交互。
- **本轮小改**：位置/位姿重拼接新增 **I10 抓取可行性过滤**——用抓取宽度与接近方向判断增广后动作是否物理可行，不可行样本剪除，直接回应 v1.1「位置重拼接物理不可行」风险；背景/干扰物两轴仍按考纲放量。

### I3 接触任务族视觉伺服回退 ★★★★（维持 + 重划）
- 六要素同 v1.1；因 F20 无深度/无标定，**几何伺服从 3D 重划为 2D/2.5D**（图像关键点 + EE 反馈），关键点用开放词汇检测零训练起步；可消费 I10 的抓取宽度/接近方向作为接触段先验；触发滞回 + 低置信回退；I3'（若混合推理违规，改训练时辅助监督）保留。

### I4 人手干预感知门控 + 自适应 chunk ★★★★（维持）
- 六要素同 v1.1；F21/F22 修正后：官方训练 chunk=30、推理 4 步去噪，干预态短 chunk（4–6）、稳定态长 chunk（8–16）仍是方向，但重规划成本按「4 步去噪 + VLM 前向」实测标定。

### I6 确定性低延迟部署服务 ★★★★（维持 + 拆账）
- 六要素同 v1.1；延迟预算按 F21 拆账：每 chunk = VLM 前向 + 4 次去噪；H=30 默认，可按 I4 调小；2×A100 80G 共享 backend 覆盖 N=3–5；p99 目标 <40ms（15Hz 参照），动作健康度回归为 PR4 门禁。

### I7 世界模型测试时前瞻 ✂ 裁撤（推理路径）
- **决定**：本轮正式裁撤推理期 rollout。理由：MMDiT 扩散已需 4 步去噪（F21），再叠加 O(1–2) 次世界模型 rollout 会击穿 15Hz/66ms 预算；其价值（高险节点择优）可被 I10 抓取软重排以近乎零成本替代。
- **资产去向**：WMA-0 仅保留为 I5 v3 离线数据引擎（扰动续写），不进计分通道。裁撤不等于废弃。

### 1.1 抓取事件挖掘（I10）

```python
def mine_grasp_events(traj, g_close=0.15, h=0.05, k=12, delta=3):
    """traj: list of (img, T_ee(4x4), g). 无深度/无力，仅用 gripper 信号 + 视觉。"""
    events = []
    for t in range(1, len(traj)):
        g_prev, g_now = traj[t-1].g, traj[t].g
        if g_prev > g_close + h and g_now <= g_close:      # 闭合沿
            window = traj[max(0, t-k):t]
            contact_uv = project_ee_to_wrist(traj[t-delta].T_ee)  # 无内参→图像坐标近似
            approach  = ee_approach_dir(traj[t-delta].T_ee)        # EE 局部 z 轴投到像平面
            events.append(dict(
                t_g=t, win=window, uv=contact_uv, theta=approach,
                width=g_now, T_pre=traj[t-delta].T_ee,
                conf=grasp_confidence(window, g_now)))   # 三信号联合置信
    return [e for e in events if e["conf"] > TAU_GRASP]
```

```python
def train_step(batch, model, lam=(0.1, 0.05, 0.05)):
    o, a = batch.obs, batch.action
    L_diff = diffusion_loss(model, o, a)                 # MMDiT, 4-step inference
    # 仅抓取/插入类任务启用；指令门控
    if batch.task_family in GRASP_FAMILIES:
        H_hat, w_hat, th_hat = model.grasp_heads(o, a)
        L_aux = (lam[0] * focal(H_hat, batch.grasp_heatmap)
                 + lam[1] * smooth_l1(w_hat, batch.grasp_width)
                 + lam[2] * ce(th_hat, batch.approach_bin))
        return L_diff + L_aux
    return L_diff
# 推理默认不调用 grasp_heads（PR6）；可选软重排受 I6 延迟门禁约束
```

### 1.3 得分优势加权扩散 BC（I11）
```python
def advantage_weights(obs, lang, V, beta=0.5, w_min=0.2, w_max=5.0):
    v = V(obs, lang)                       # 已达成得分点比例，形状 (B,T)
    R = v[:, -1:] - v                       # return-to-go（越接近完成越高）
    A = R - R.mean(dim=0, keepdim=True)     # per-task 基线
    w = (A / beta).exp().clamp(w_min, w_max)
    return w / w.mean()

def weighted_diffusion_loss(model, o, a, lang, V, rho=0.5, **kw):
    w  = advantage_weights(o, lang, V, **kw)
    w  = (1 - rho) + rho * w               # 与均匀 BC 混合，rho=0 可回退
    ess = w.sum()**2 / (w**2).sum()        # 监控：< 0.5N 则调大 rho
    return (w * per_sample_diffusion_loss(model, o, a)).mean(), ess
```

```python
def synthesize_regrasp(ep, grasp_lib, t_fail):
```

|---|---|---|---|
