>

## 0. 直觉与动机

**灵感 1（UniBot → 基准的最小单位不是「平均成功率」，而是「受限具身下的最坏可信度」）**
直觉：UniBot 只有四路 RGB（头部双目已校正）与本体感觉，没有深度、力、触觉；透明、高光、弱纹理、关节体让双目深度长期空洞，头部外参靠外推。通用基准（LIBERO / Open X-Embodiment 一类）测平均任务成功率，会把 UniBot 的结构性短板「平均掉」：在容易任务上刷高平均，比诚实报告「透明杯不可观测」更划算。挑战赛真正该测的，是**感知退化、接触不确定、人机共处下，系统是否还能给出可信的失败边界**。所以基准的第一性原则不是「更高分」，而是「分数的可证伪性与对受限具身的诚实」。

**灵感 2（基准测试 → 分数是被激励出来的，不是被测量出来的）**
直觉：只要分数进入名次，参赛者就会优化「被测量」，而不是「被期望」。这在机器人竞赛里有三个几乎免费的作弊面：
- **种子挑选**：规则报 `max@k seeds`，团队就跑 `k` 次只交最好一次；
- **选择性汇报**：只报成功 episode，失败归因于「机器故障」；
- **意图伪装**：RAS 用表情推断风险态度，参赛者用固定微笑或夸张紧张去触发/规避降级。
Goodhart 不是意外，是**均衡**。不设计激励，基准测出来的只是「谁最会考试」。因此基准必须被建模成一个机制设计问题：**评分规则本身要让诚实成为占优策略**。

**灵感 3（证书 → 把「不确定性」变成计分单位）**
直觉：VISTA 的 `J_vista` 与 RAS 的 `J_RAS` 已经携带「我声称什么、在什么条件下、置信多少」。把证书本身作为提交物，用**严格 proper scoring rule**（log score / interval score / Brier score）去打分，就能让「预测分布的真实性」直接进入分数：一个诚实说「我在透明杯上只有 60% 成功率」的团队，不应输给一个虚报 90% 的团队。校准（calibration）于是不再是软指标，而是得分本身；过度自信会被数学惩罚，而不是靠评审主观扣分。

**灵感 4（把「可复现」变成有价证券）**
直觉：复现是公共品，没人愿意为它付费——除非它被写进收益函数。UCA 要求提交**保证金**（reproducibility bond），并以概率 `p_a` 随机重跑审计；重跑不一致则没收保证金。这样「复现成本」从评审方的负担，变成参赛者的**自付风险**：越虚报，越需要押更多钱；越诚实，越能低成本参赛。保证金不是惩罚，而是**为「声称」定价**。

**灵感 5（三灵感合流 → UCA 十组件）**
UCA 保留 VISTA/RAS 的证书语义，但在其上加一层「竞技机制」：
1. **CNS（Certificate-Native Submission）**：提交 = 策略 + 证书 + 种子 + 数据护照 + 保证金；
2. **CCS（Calibrated Certificate Scoring）**：严格 proper 分数 + Murphy 可靠性分解；
3. **ALRB（Audit Lottery & Reproducibility Bond）**：随机审计抽签 + 保证金结算；
4. **P3（Peer-Prediction Payment）**：随机隐藏配对预测同伴分数，诚实报告是贝叶斯纳什均衡；
5. **RITS（Rank-Information Task Sampler）**：只选「最能区分名次」的任务，且受自适应预算约束；
6. **GBHA（Goodhart Budget & Holdout Admixture）**：公开自适应比例 `β` 封顶 + 隐藏 holdout + 审计掺混；
7. **CRM（Collusion-Resistant Matching）**：随机重配对 + 报告相关性惩罚 + Sybil 成本；
8. **CEN（Cross-Embodiment Normalization）**：随机效应模型归一化不同 UniBot 硬件，报告迁移缺口；
9. **ABC（Arena Benchmark Card）**：每个名次附覆盖、审计、校准、复现、迁移的可审计卡片；
10. **USP（UCA Score & Pareto）**：性能/可信/复现/校准/迁移五轴 Pareto 榜，名次差距小于噪声时强制显示「并列/不可辨识」。

## 1. 形式化定义（增量：定义 251–263）

- **定义 251（UCA 总览）**：`UCA = (CNS, CCS, ALRB, P3, RITS, GBHA, CRM, CEN, ABC, USP)`。定位：VISTA/RAS 的证书层升级为「可被竞技机制结算的评判层」。不变式：计分只读取证书声明与审计后的执行轨迹（语义流）；真实时控制环路零改动；任何未通过审计的声明不得进入有效榜。
- **定义 252（证书提交包）**：团队 `i` 的提交 `C_i = (π_i, h_i, K_i, Σ_i, P_i, s_i, B_i, φ_i)`，其中 `π_i` 为策略、`h_i` 为可复现哈希、`K_i` 为声明集、`Σ_i` 为种子集、`P_i` 为数据护照链（来源/场景/episode/传感器配置）、`s_i` 为签名、`B_i` 为保证金、`φ_i` 为同行预测。**提交即证书**，不接受「只有一段视频」的提交。
- **定义 253（概率声明）**：对任务 `t`，声明 `c_{i,t} = (p_{i,t}, [ℓ_{i,t}, u_{i,t}], q_{i,t})`：`p_{i,t} ∈ (0,1)` 为成功概率点预测；`[ℓ,u]` 为风险泛函 `r_{i,t}`（违规概率/力超限概率）的中心区间；`q_{i,t} ∈ [0,1]` 为「RAS 所用意图/情绪信号为真（非伪装）」的概率。
- **定义 254（校准证书分数 CCS）**：设任务 `t` 的观测为 `(y_{i,t} ∈ {0,1}, r_{i,t}, a_{i,t})`，`a` 为审计得到的意图真实性标签。定义
  `S_CCS(i) = -(1/T) Σ_t [ ℓ(p_{i,t}, y_{i,t}) + λ_I·IS_α([ℓ,u]_{i,t}, r_{i,t}) + λ_Q·(q_{i,t} - a_{i,t})² ]`，
  其中 `ℓ` 为 log loss，`IS_α` 为区间分数
  `IS_α([ℓ,u], r) = (u-ℓ) + (2/α)(ℓ-r)_+ + (2/α)(r-u)_+`。
  三项均为（严格）proper 分数；报告可靠性 `REL_i` 由 Brier 的 Murphy 分解 `BS = REL - RES + UNC` 给出。
- **定义 255（审计抽签与保证金）**：每个提交以概率 `p_a` 被抽中，或对每个种子独立以 `p_a` 抽检 `k` 个；重跑结果 `a_i ∈ {PASS, FAIL, INCONCLUSIVE}`。若 `FAIL`，没收保证金 `B_i`；若 `INCONCLUSIVE`，降权但不没收。有效审计概率 `p_a^{eff}(k) = 1-(1-p_a)^k`。
- **定义 256（同行预测支付 P3）**：每轮用隐藏随机置换 `σ` 为团队 `i` 指配同伴 `σ(i)`；`i` 提交对同伴分数桶的预测分布 `φ_{i,σ(i)}`。支付
  `PP_i = S_proper(φ_{i,σ(i)}, bucket(S_CCS(σ(i)))) - λ_c·corr(φ_{i,σ(i)}, φ_{σ(i),i})`。
  `σ` 对参赛者不可见且每轮重抽，使「猜测同伴真实水平」优于「配合串谋」。
- **定义 257（诚实均衡）**：策略 `σ*` 为 `ε`-诚实，若对任意偏离 `σ'`，`E[u_i(σ*)] ≥ E[u_i(σ')] - ε`；若 `ε=0` 对所有 `i` 成立，则 UCA 在给定先验下是**激励相容**的，且诚实报告是贝叶斯纳什均衡。
- **定义 258（排名信息与 RITS）**：设 `p(θ | D)` 为团队能力的后验（`θ_i` 为潜在技能），任务 `t` 的观测为 `Y_t`。排名信息
  `a(t) = I(rank; Y_t | D) = H(rank | D) - E_{Y_t}[H(rank | D, Y_t)]`。
  RITS 在每轮选择 `argmax_t a(t)/cost(t)`，但自适应任务总量占比不得超过 `β`。
- **定义 259（Goodhart 预算）**：公开自适应比例 `β ∈ [0,1]`、锁定 holdout 集 `H`、审计掺混比例 `γ`。榜单必须同时报告
  `Gap = |Ŝ_public - Ŝ_holdout|` 及其置信区间；`Gap > τ_G` 触发「基准过拟合」告警，相关名次标为「暂定」。
- **定义 260（UCA 分数与 Pareto 榜）**：`U_i = (Perf_i, Sound_i, Repro_i, Calib_i, Transfer_i)`，分别由成功率、证书 soundness、审计通过率、校准误差、跨具身迁移缺口给出。榜单为五轴 Pareto 前沿 + 预注册权重的标量化 `UCA_i`；若 `|UCA_i - UCA_j|` 小于可辨识阈值，则强制显示并列，禁止制造虚假名次。
- **定义 261（抗串谋）**：对联盟 `K`，`Γ(K) = max_{策略} E[Σ_{i∈K} u_i] - Σ_{i∈K} E[u_i^{truth}]`。若 `Γ(K) ≤ ε_c`，称 UCA 为 `(K, ε_c)`-抗串谋。达成手段：随机重配对、相关性惩罚 `λ_c`、Sybil 身份成本、联盟规模上限。
- **定义 262（跨具身归一化）**：具身卡 `e = (传感器, 自由度, 负载, 时延, 算力)`；随机效应模型 `s_{i,e} = θ_i + b_e + ε_{i,e}`，用 GLS/REML 估计 `θ_i` 与 `b_e`。迁移缺口 `Δ_e(i) = |θ_i^{A} - θ_i^{B}|`；若 `Δ_e` 超过排名可辨识阈值，则该条目只能申报「具身特定」，不得申报「通用」。
- **定义 263（竞技场证书 ABC）**：每个名次附带
  `ABC_i = (覆盖向量, 审计通过率, holdout gap, 校准误差, 复现哈希, 迁移矩阵, 机制版本号)`。
  `Valid(ABC_i) ⇔ 覆盖 ≥ c0 ∧ 审计 ≥ a0 ∧ Gap ≤ τ_G ∧ 无未决反例`。只有 `Valid` 的条目进入正式排名。

## 2. 关键算法骨架

```python
# UCA：证书原生竞技场的一轮
def UCA_round(bundles, task_family, posterior, beta, p_audit, bond):
    # 1) CNS：校验提交包完整性（策略/证书/种子/护照/签名/保证金）
    valid = [b for b in bundles if verify_bundle(b)]

    # 2) RITS：在自适应预算 beta 内选「最能区分名次」的任务
    adaptive = []
    budget = int(beta * len(task_family))
    while len(adaptive) < budget:
        t = max(task_family, key=lambda x: rank_info(posterior, x) / cost(x))
        adaptive.append(t); task_family.remove(t)
    tasks = adaptive + sample_holdout_admixture(gamma=0.2)   # GBHA

    # 3) 执行 + 审计抽签（ALRB）
    outcomes = {}
    for b in valid:
        outcomes[b.id] = execute(b.policy, b.seeds, tasks)
        b.audit = audit_lottery(outcomes[b.id], b.claims, p_audit)
        if b.audit.status == 'FAIL':
            settle_bond(b, bond)          # 没收保证金
        outcomes[b.id] = outcomes[b.id].mask(b.audit.verified_only)

    # 4) CCS：严格 proper 计分 + 校准分解
    for b in valid:
        b.ccs = score_ccs(b.claims, outcomes[b.id])
        b.rel = murphy_reliability(b.claims, outcomes[b.id])

    # 5) P3：隐藏随机配对，预测同伴分数
    perm = hidden_random_permutation(valid)
    for b in valid:
        peer = valid[perm[b.id]]
        b.pp = proper_score(b.peer_pred[peer.id], bucket(peer.ccs)) \
               - lambda_c * report_corr(b, peer)

    # 6) CEN：跨具身随机效应归一化 + 迁移缺口
    theta, b_e = gls_random_effects(valid)
    for b in valid:
        b.transfer = max_transfer_gap(theta, b)

    # 7) USP：Pareto + 可辨识性判定
    for b in valid:
        b.U = (b.perf, b.sound, b.audit.pass_rate, b.rel, b.transfer)
        b.uca = weighted_score(b.U)
    leaderboard = pareto_front(valid, key=lambda x: x.U)
    report_ties(leaderboard, noise_floor=identifiability_floor(valid))
    return leaderboard, [make_abc(b) for b in valid]


# 严格 proper 的证书分数
def score_ccs(claims, out):
    total = 0.0
    for t, c in claims.items():
        y, r, a = out[t]
        total += log_loss(c.p, y)
        total += LAMBDA_I * interval_score(c.lo, c.hi, r, alpha=0.1)
        total += LAMBDA_Q * (c.q - a) ** 2
    return -total / len(claims)


# 审计抽签：越大的声称越该被抽
def audit_lottery(out, claims, p_audit):
    suspicious = max(0.0, out.claim - empirical_success(out.seeds))
    p = min(1.0, p_audit * (1 + suspicious / 0.1))
    if random.random() < p:
        return re_execute(out.seeds)          # PASS / FAIL / INCONCLUSIVE
    return AuditResult(status='NOT_SAMPLED')


# RITS：排名信息增益（Plackett-Luce 后验下的一步近似）
def rank_info(posterior, task):
    H0 = rank_entropy(posterior)
    H1 = expected_rank_entropy(posterior, task, n_mc=64)
    return H0 - H1
```

## 3. 推导

**引理 11（严格 proper 分数下虚报无期望收益）** 对严格 proper 分数 `S`，`E_{Y~Q}[S(P,Y)]` 在 `P=Q` 时唯一最大。故在 CCS 中抬高 `p` 只会在期望上损失 log score；把风险区间说得更窄只会在期望上增加区间分数；把意图真实性说得更满只会在期望上损失 Brier。**虚报不是「可能赚」，而是「必然以期望为代价买方差」。**

**引理 12（审计保证金的条件）** 设虚报的相对收益为 `Δ`，审计概率为 `p_a`，保证金为 `B`。诚实优于虚报当且仅当
`(1-p_a)Δ - p_a B ≤ 0 ⇔ B ≥ Δ(1-p_a)/p_a`。
对 `k` 个独立抽检种子，`p_a^{eff}=1-(1-p_a)^k`。设计规则：`p_a=10%` 时 `B≥9Δ`；`p_a=30%` 时 `B≥2.33Δ`。这把「复现」从道德要求变成**价格**。

**定理 11（UCA 的真话均衡）** 在 A1（CCS 为严格 proper）、A2（同伴随机隐藏配对且 P3 为 proper）、A3（审计独立且保证金满足引理 12）、A4（无联盟）下，**诚实声明 + 诚实同行预测**是贝叶斯纳什均衡；当先验满支撑时，它是经迭代剔除严格劣策略后唯一存活的均衡。证明要点：三部分收益加性可分，且每一项都在真实报告处取期望最大；审计罚项在真实报告处取最小。

**定理 12（自适应预算的 Goodhart 界）** 设自适应比例为 `β`，候选策略数为 `M`，公开任务的有效样本数为 `n_pub ∝ 1/β`。则在亚高斯噪声下有选择偏差
`ε_o ≤ σ√(2 ln M / n_pub) = σ√(2β ln M / n)`。
若指标对部署分布为 `L`-Lipschitz、holdout 与部署的 Wasserstein 距离为 `δ_W`，则
`|E_deploy[U] - Ŝ_public[U]| ≤ L·δ_W + ε_o + O(√(log(1/δ)/n_H))`。
**含义**：公开榜的乐观程度由自适应预算 `β` 定价；`β→0` 回到经典 holdout 界，`β` 越大越容易被「刷榜」，因此 GBHA 必须给 `β` 封顶并保留隐藏掺混。

**定理 13（排名可辨识性）** 对团队 `i,j`，若
`|s_i - s_j| ≤ z_{1-α/2}·√(σ_i²/n_i + σ_j²/n_j)`，
则在显著性 `α` 下其先后顺序不可辨识，榜单必须报告为「并列」。可分辨名次数等于在该关系下的最大可分离链数；RITS 每单位预算最大化「被分开的对数」。**一个不肯显示并列的排行榜，只是在把噪声包装成名次。**

**推论 1（跨具身迁移界）** `|θ_i^A - θ_i^B| ≤ L_e·W_1(D_A, D_B) + b_{A,B}`。当该界超过排名可辨识阈值时，「通用」声明不成立，只能声明「具身特定」。这直接约束了 UniBot 不同硬件版本之间的「刷通用分」。

## 4. 复杂度分析

| 组件 | 时间 | 空间 | 保证 |
|---|---|---|---|
| CNS 校验 | `O(N·(|K|+|Σ|))` | `O(N·|K|)` | 签名/哈希可复现 |
| CCS 计分 | `O(N·T)` | `O(N·T)` | 引理 11：诚实期望最优 |
| ALRB 审计 | `O(p_a·N·T·C_exec)` | `O(p_a·N·T)` | 引理 12：保证金定价 |
| P3 同行预测 | `O(N·B)` | `O(N·B)` | 定理 11：真话均衡 |
| RITS 选任务 | `O(T·N log N)`/步 | `O(N)` | 定理 13：最大化可辨识对数 |
| CEN 归一化 | `O(N·E)` | `O(N+E)` | 推论 1：迁移界 |
| USP 榜单 | `O(N log N)` | `O(N)` | Pareto + 并列判定 |

## 2. 形式化定义（完整版）

**定义 251（UCA 总览）** UCA 是 VISTA/RAS 证书层之上的「评判层」：
```
UCA = (CNS, CCS, ALRB, P3, RITS, GBHA, CRM, CEN, ABC, USP)
```
不变式：
1. 计分只读取证书声明与审计后的执行轨迹（语义流）；
2. 真实时控制环路零改动；
3. 任何未通过审计或 ABC 无效的条目不得进入正式榜；
4. 所有机制参数在赛季开始前**预注册**，赛季中不可被参赛者读取内部随机流。

**定义 252（证书提交包）** 团队 `i` 的提交为
```
C_i = (π_i, h_i, K_i, Σ_i, P_i, s_i, B_i, φ_i)
```
其中 `π_i` 为策略/模型，`h_i = H(π_i, env, seeds)` 为可复现哈希，`K_i = {c_{i,t}}` 为声明集，`Σ_i` 为预注册种子集，`P_i` 为数据护照链（来源、场景、episode、传感器配置），`s_i` 为签名，`B_i` 为保证金，`φ_i` 为同行预测。**提交即证书**：没有可复现包与声明的提交视为无效。

**定义 253（概率声明）** 对任务 `t`：
```
c_{i,t} = (p_{i,t} ∈ (0,1), [ℓ_{i,t}, u_{i,t}] ⊆ ℝ, q_{i,t} ∈ [0,1])
```
`p` 为成功概率，`[ℓ,u]` 为风险泛函 `r`（违规概率/力超限概率）的中心区间，`q` 为「RAS 所用意图/情绪信号为真」的概率。声明必须覆盖提交中出现的每一个任务，禁止只报成功任务。

**定义 254（校准证书分数 CCS）** 设观测 `(y_{i,t} ∈ {0,1}, r_{i,t}, a_{i,t})`：
```
S_CCS(i) = -(1/T) Σ_t [ ℓ(p_{i,t}, y_{i,t})
                        + λ_I · IS_α([ℓ,u]_{i,t}, r_{i,t})
                        + λ_Q · (q_{i,t} - a_{i,t})² ]
```
其中
```
ℓ(p,y) = -[y ln p + (1-y) ln(1-p)]
IS_α([ℓ,u], r) = (u-ℓ) + (2/α)(ℓ-r)_+ + (2/α)(r-u)_+
```
三项均为（严格）proper 分数。校准误差用 Brier 的 Murphy 分解：
```
BS = REL - RES + UNC,   REL = (1/T)Σ_t (p_t - ō_bin)^2
```
`REL` 作为独立指标进入 `Calib` 轴。

**定义 255（审计抽签与保证金）** 对提交 `i` 的第 `j` 个种子，以
```
p_a^{eff} = min(1, p_a · (1 + max(0, p_{i,t} - f̂_i)/0.1))
```
被抽检（`f̂_i` 为已审计种子的经验成功率），独立抽检 `k` 个种子。审计结果 `a_i ∈ {PASS, FAIL, INCONCLUSIVE}`：
- `FAIL`：没收 `B_i`，本轮成绩作废；
- `INCONCLUSIVE`：成绩降权 `w<1`，不没收；
- `PASS`：正常计分。

**定义 256（同行预测支付 P3）** 每轮用隐藏随机置换 `σ` 为 `i` 指配同伴 `σ(i)`，`i` 提交对同伴 CCS 分数桶的预测 `φ_{i,σ(i)}`。支付：
```
PP_i = S_proper(φ_{i,σ(i)}, bucket(S_CCS(σ(i)))) - λ_c · corr(φ_{i,σ(i)}, φ_{σ(i),i})
```
`σ` 每轮重抽，且 `i` 不知道 `σ(i)` 的身份；`corr` 为两报告在共同任务上的皮尔逊/互信息相关，用于惩罚串谋式一致。

**定义 257（诚实均衡）** 策略 `σ*` 为 `ε`-诚实，若对任意偏离 `σ'`：
```
E[u_i(σ*)] ≥ E[u_i(σ')] - ε,   ∀i
```
若 `ε=0`，UCA 在给定先验下激励相容，诚实报告是贝叶斯纳什均衡。

**定义 258（排名信息与 RITS）** 设 `p(θ|D)` 为潜在技能后验，任务 `t` 的观测为 `Y_t`：
```
a(t) = I(rank; Y_t | D) = H(rank|D) - E_{Y_t}[H(rank|D,Y_t)]
```
RITS 选择 `argmax_t a(t)/cost(t)`，并受 `Σ_t 1[t∈adaptive] ≤ β·T` 约束。

**定义 259（Goodhart 预算）** 公开自适应比例 `β`、锁定 holdout `H`、审计掺混比例 `γ`。榜单必须报告
```
Gap = |Ŝ_public - Ŝ_holdout|
```
及其 `1-δ` 置信区间；`Gap > τ_G` 触发告警，相关名次标为「暂定」，不得用于宣称 SOTA。

**定义 260（UCA 分数与 Pareto）**
```
U_i = (Perf_i, Sound_i, Repro_i, Calib_i, Transfer_i)
UCA_i = w_P·Perf_i + w_S·Sound_i + w_R·Repro_i + w_C·Calib_i + w_T·Transfer_i
```
权重在赛季前预注册。榜单为五轴 Pareto 前沿；若
```
|UCA_i - UCA_j| ≤ z_{1-α/2}·√(σ_i²/n_i + σ_j²/n_j)
```
则强制并列。

**定义 261（抗串谋）** 对联盟 `K`：
```
Γ(K) = max_{策略} E[Σ_{i∈K} u_i] - Σ_{i∈K} E[u_i^{truth}]
```
若 `Γ(K) ≤ ε_c`，称 UCA 为 `(K, ε_c)`-抗串谋。达成手段：随机重配对、相关性惩罚 `λ_c`、Sybil 身份成本、每队可结盟规模上限。

**定义 262（跨具身归一化）** 具身 `e` 的具身卡 `(传感器, 自由度, 负载, 时延, 算力)`。随机效应模型：
```
s_{i,e} = θ_i + b_e + ε_{i,e},   ε ~ N(0, σ_e²)
```
用 GLS/REML 估计 `θ_i, b_e`。迁移缺口 `Δ_e(i) = |θ_i^A - θ_i^B|`；若 `Δ_e` 超过可辨识阈值，只能申报「具身特定」。

**定义 263（竞技场证书 ABC）**
```
ABC_i = (coverage_vector, audit_pass, holdout_gap, calib_err,
         repro_hash, transfer_matrix, mechanism_version)
```
```
Valid(ABC_i) ⇔ coverage ≥ c0 ∧ audit_pass ≥ a0 ∧ holdout_gap ≤ τ_G
               ∧ ¬∃ unresolved_counterexample
```
只有 `Valid` 的条目进入正式排名；其余进入「待证」列表。

# IP-234 CNS：提交校验
def verify_bundle(b):
    required = ['policy', 'claims', 'seeds', 'provenance', 'signature', 'bond']
    if not all(k in b for k in required):
        return False
    if hash_policy(b.policy, b.seeds) != b.hash:
        return False
    if not verify_signature(b.signature, b.hash):
        return False
    return b.bond >= bond_floor(b.claims)


# IP-235 CCS：严格 proper 计分
def score_ccs(claims, out):
    total = 0.0
    for t, c in claims.items():
        y, r, a = out[t]
        total += log_loss(c.p, y)
        total += LAMBDA_I * interval_score(c.lo, c.hi, r, alpha=0.1)
        total += LAMBDA_Q * (c.q - a) ** 2
    return -total / len(claims)


def interval_score(lo, hi, r, alpha):
    return (hi - lo) + (2/alpha) * max(0, lo - r) + (2/alpha) * max(0, r - hi)


# IP-236 ALRB：可疑度加权的审计抽签 + 保证金结算
def audit_and_settle(b, out, p_audit, k):
    f_hat = empirical_success(out.audited_seeds)
    suspicious = max(0.0, out.claimed_p - f_hat)
    p = min(1.0, p_audit * (1 + suspicious / 0.1))
    sampled = [s for s in out.seeds if random.random() < p]
    if len(sampled) > k:
        sampled = random.sample(sampled, k)
    if not sampled:
        return AuditResult('NOT_SAMPLED', weight=1.0)
    res = re_execute(b.policy, sampled)
    if res.status == 'FAIL':
        settle(b, forfeit=True)          # 没收保证金
        return AuditResult('FAIL', weight=0.0)
    if res.status == 'INCONCLUSIVE':
        return AuditResult('INCONCLUSIVE', weight=0.5)
    return AuditResult('PASS', weight=1.0)


# IP-237 P3：隐藏随机配对 + 同行预测支付
def peer_payment(valid, perm, lambda_c):
    for b in valid:
        peer = valid[perm[b.id]]
        proper = proper_score(b.peer_pred[peer.id], bucket(peer.ccs))
        corr = report_correlation(b, peer)
        b.pp = proper - lambda_c * corr
    return valid


# IP-238 RITS：排名信息增益选题
def rits_select(task_pool, posterior, beta, T):
    adaptive = []
    budget = int(beta * T)
    while len(adaptive) < budget and task_pool:
        t = max(task_pool, key=lambda x: rank_info(posterior, x) / cost(x))
        adaptive.append(t)
        task_pool.remove(t)
    return adaptive


def rank_info(posterior, task, n_mc=64):
    h0 = rank_entropy(posterior)
    h1 = sum(rank_entropy(update(posterior, task, y)) for y in sample(task, n_mc)) / n_mc
    return h0 - h1


# IP-243 USP：Pareto + 可辨识性并列
def uca_leaderboard(valid, alpha=0.05):
    for b in valid:
        b.U = (b.perf, b.sound, b.audit_pass, b.calib, b.transfer)
        b.uca = weighted_score(b.U)
    front = pareto_front(valid, key=lambda x: x.U)
    for i in front:
        for j in front:
            if i.id < j.id and abs(i.uca - j.uca) <= z(1 - alpha/2) * \
               sqrt(i.var + j.var):
                mark_tie(i, j)
    return front


# IP-242/243 端到端一轮
def UCA_round(bundles, task_pool, posterior, beta, p_audit, k, lambda_c, gamma):
    valid = [b for b in bundles if verify_bundle(b)]              # CNS
    adaptive = rits_select(task_pool, posterior, beta, len(task_pool))  # RITS
    tasks = adaptive + sample_holdout(gamma)                       # GBHA
    for b in valid:
        out = execute(b.policy, b.seeds, tasks)
        b.audit = audit_and_settle(b, out, p_audit, k)             # ALRB
        b.claims = mask_unverified(b.claims, b.audit)              # 只计已审计
        b.ccs = score_ccs(b.claims, out)                           # CCS
    perm = hidden_permutation(valid)                               # CRM
    valid = peer_payment(valid, perm, lambda_c)                    # P3
    theta, b_e = gls_random_effects(valid)                         # CEN
    for b in valid:
        b.transfer = max_transfer_gap(theta, b)
        b.abc = make_abc(b)                                        # ABC
    return uca_leaderboard([b for b in valid if Valid(b.abc)])     # USP

## 4. 推导

**引理 11（严格 proper 分数下虚报无期望收益）**
对严格 proper 分数 `S`，`E_{Y~Q}[S(P,Y)] ≤ E_{Y~Q}[S(Q,Y)]`，等号仅当 `P=Q`。因此：
1. 抬高 `p` 在期望上增加 log loss；
2. 收窄 `[ℓ,u]` 在期望上增加区间分数；
3. 抬高 `q` 在期望上增加 Brier 损失。
**虚报不是「可能赚」，而是「以期望为代价买方差」。**

**引理 12（审计保证金条件）**
设虚报相对收益 `Δ`、审计概率 `p_a`、保证金 `B`。诚实优于虚报当且仅当
```
(1-p_a)Δ - p_a B ≤ 0  ⇔  B ≥ Δ(1-p_a)/p_a
```
对 `k` 个独立抽检，`p_a^{eff}=1-(1-p_a)^k`。设计表：

| `p_a` | 5% | 10% | 20% | 30% |
|---|---|---|---|---|
| `B/Δ` 下界 | 19.0 | 9.0 | 4.0 | 2.33 |

**定理 11（UCA 真话均衡）**
在 A1（CCS 严格 proper）、A2（P3 隐藏随机配对且 proper）、A3（审计独立、保证金满足引理 12）、A4（无联盟）下，诚实声明 + 诚实同行预测是贝叶斯纳什均衡；满支撑先验下，它是迭代剔除严格劣策略后唯一存活的均衡。
*证明要点*：`u_i = S_CCS + PP_i - B_i·1[FAIL]` 三项加性可分；由引理 11 与 proper 的 peer prediction，前两项在真实报告处取期望最大；由引理 12，罚项在真实报告处取最小。故联合偏离不能增加期望收益；满支撑保证唯一性。∎

**定理 12（自适应预算的 Goodhart 界）**
设候选策略数 `M`，公开任务有效样本 `n_pub ∝ n/β`，噪声亚高斯常数 `σ`。则选择偏差
```
ε_o = E[max_i ŝ_i] - max_i E[s_i] ≤ σ√(2 ln M / n_pub) = σ√(2β ln M / n)
```
若指标对部署分布 `L`-Lipschitz、`W_1(D_hold, D_deploy)=δ_W`，则
```
|E_deploy[U] - Ŝ_public[U]| ≤ L·δ_W + ε_o + O(√(log(1/δ)/n_H))
```
*含义*：公开榜的乐观度由 `β` 定价；`β→0` 回到经典 holdout 界。故 GBHA 必须给 `β` 封顶，并以隐藏 holdout 与审计掺混估计 `Gap`。∎

**定理 13（排名可辨识性）**
对团队 `i,j`，若
```
|s_i - s_j| ≤ z_{1-α/2}·√(σ_i²/n_i + σ_j²/n_j)
```
则在水平 `α` 下顺序不可辨识，必须报「并列」。可分辨名次数等于该关系下的最大可分离链数；RITS 每单位预算最大化「被分开的对数」。**不显示并列的排行榜，只是在把噪声包装成名次。** ∎

**推论 1（跨具身迁移界）**
```
|θ_i^A - θ_i^B| ≤ L_e·W_1(D_A, D_B) + |b_A - b_B|
```
当该界超过排名可辨识阈值时，「通用」声明不成立，只能申报「具身特定」；这直接约束 UniBot 不同硬件版本之间的「刷通用分」。∎

## 6. 合成预实验（仅验证机制方向，非真实机器人数据）

在 `N=24, T=40`、真实技能 `θ_i~N(0,1)`、任务难度 `d_t~U(-0.6,0.6)`、`p=sigmoid(θ-d)` 的纯合成模型上（`seed=7/11`）：

| 检验 | 结果 | 对应结论 |
|---|---|---|
| 虚报 `δ=0.15` 的 log loss 惩罚 | +0.0599 nats/task | 引理 11 方向成立 |
| 保证金盈亏平衡 `B/Δ`：`p_a=5/10/20/30%` | 19.0 / 9.0 / 4.0 / 2.33 | 引理 12 设计表 |
| 原生 `max@10 seeds`：诚实 vs 挑种子 | 0.562 vs 0.958（+0.396） | 原生榜奖励 cherry-pick |
| CCS+审计的 log loss：诚实 vs 虚报 | 0.580 vs 1.213 | 虚报被惩罚 |
| 选择偏差 `ε_o`（`M=120, n_hold=200`）：`n_pub=5/20/80` | 0.303 / 0.022 / 0.002 | 定理 12 方向成立 |
| 可分辨对数（`N=24, σ=0.8`）：`T=10/40/160` | 70% / 87% / 93% | 定理 13：任务越多越可辨识 |

**解读**：原生 `max@k` 榜在合成模型上把「挑种子」的收益放大到 0.396 绝对成功率，而 CCS+审计把同样行为的计分从 0.580 恶化到 1.213；这说明「基准的评分规则」比「基准的规模」更决定作弊收益。选择偏差随公开样本数下降（0.303→0.002），支持 GBHA 的 `β` 封顶。

## 7. 复杂度与工程约束

| 组件 | 时间 | 空间 | 备注 |
|---|---|---|---|
| CNS 校验 | `O(N(|K|+|Σ|))` | `O(N|K|)` | 哈希/签名毫秒级 |
| CCS | `O(NT)` | `O(NT)` | 纯标量运算 |
| ALRB | `O(p_a N T C_exec)` | `O(p_a N T)` | 审计是唯一大头，建议 `p_a∈[5%,20%]` |
| P3 | `O(NB)` | `O(NB)` | 分数桶数 `B≈10` |
| RITS | `O(T N log N)`/步 | `O(N)` | Monte-Carlo 信息增益需 64 样本 |
| CEN | `O(NE)` | `O(N+E)` | `E` 为具身数，很小 |
| USP | `O(N log N)` | `O(N)` | Pareto 前沿通常 ≪N |

落地约束：随 UniBot 实机（四路 RGB + 本体感觉，无深度/力/触觉）一起部署时，UCA 全部离线运行；审计重执行在影子环境/回放器完成，实时环路零改动。

## 8. 本轮最大风险

**一句话**：UCA 把「真实」寄托在**机制参数与审计随机性本身不可被参赛者建模和反向优化**这一假设上——一旦团队能估计 `p_a`、`B`、`β` 与同行配对分布（排行榜反馈恰恰提供了估计所需的数据），所谓「诚实占优」就只是纸面均衡，榜单最终奖励的是最会表演「可复现 + 校准良好」的团队，而不是最安全的机器人。
