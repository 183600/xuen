# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因」IP-214~223；本轮灵感：「视觉编码器」×「传感器标定」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，它自陈的最大风险也很锋利：**故障假设集有限、且视觉与几何的失效被假定相互独立；一旦透明/镜面/对抗 patch 造成共因失效，FIR 会把未知复合故障强行塞进最近假设、只膨胀错误的球，并因为「已经归因」而更自信地继续执行。** 本轮不急着再加一层归因，而是往下追问一个被前两轮都默默假设掉的前提：**这些异质残差凭什么可以放在同一本账上比较？** 答案是被默认掉的——它们都已被标定进同一个物理规范。于是本轮核心命题是：
>
> **把「标定」从离线预处理升级为与故障联合可辨识的运行时状态：视觉编码器是一台没有单位、还会随域漂移的「虚拟传感器」，它的潜在度量必须用稀疏物理锚点定标；只有把「规范固定」显式写进可辨识性与安全证书，「可归因」才能在共因失效下成立，或者诚实地退化为「不可辨识」。**

## 0. 直觉与动机

### 灵感 1（视觉编码器 → 一台没有单位的虚拟传感器）

直觉：第 65 轮把 `‖e_vis‖` 当作「视觉残差」塞进签名 ρ，可这个范数的单位是什么？现代视觉编码器（DINOv2 / CLIP / ViT / 扩散特征）把图像映到潜在空间，其距离反映的是**语义相似度**，不是毫米或牛顿。同一段物理位移，在纹理丰富处与低纹理处、在白天与夜里、在正常与透明物体上，会产生完全不同的特征距离。于是「视觉残差大」可能只是**表示漂移**，不是世界真的变了。把编码器当传感器看，它是一台**没有标定、没有单位、还会随域漂移的虚拟传感器**。这正好解释第 65 轮为何在共因失效下崩：它把「编码器度量漂移」与「物理故障」记到了同一本账上，还用了同一个 σ 去归一化。

### 灵感 2（传感器标定 → 一次规范选择，而不是一次数值修正）

直觉：标定（内参 / 外参 / 时延 / 力偏置）本质是**选一个物理规范（gauge）**：把各传感器读数搬到同一坐标、同一套单位、同一条时间轴上。规范一旦选错，观测模型里就多出一个**规范自由度**；而故障也是观测空间里的一个扰动。**若故障方向恰好落在规范轨道（gauge orbit）上，二者就不可分。** 第 65 轮的「共因失效」正是这种情形：透明物体让视觉与几何同时偏移，其联合偏移可被一个「外参 / 度量标错了」的变换几乎完全解释——于是系统把真实故障**吸收进标定**，得到一个自洽但整体错位的世界图景。

### 灵感 3（标定与故障的时间/结构签名不同 → 可分离）

直觉：标定漂移是**慢变、低秩、与查询无关**的（对所有观测一致地作用，通常是测量算子的一次变换）；故障是**突发、局部、与物理量相关**的。二者差别不在「幅度」，而在「作用子空间」。于是可辨识性问题变成：**规范轨道与故障方向是否横截（transverse）**。夹角越大越可分；夹角趋零就是第 65 轮的不可辨识。更进一步：标定探针（看已知标定板、运动视差、零力窗、轻触已知刚度面）**天然是低风险探针**，因为它们可以在自由空间 / 非接触下做。所以「先定标、再归因」不只是逻辑顺序，还是**风险最优**顺序。

### 灵感 4（三灵感合流 → CALIBRA：把标定做成与归因联合的、带证书的运行时状态）

闭环：锚点选择（本体 / LiDAR / 标定板 / 接触事件）→ 编码器潜在度量标定（学一个 pullback 物理图册 Φ）→ 标定-故障联合后验（慢变规范 vs 快变故障）→ 规范固定（held-out 锚点残差约束，防「吸收」）→ 标定后的物理残差 → C-FIR 归因 → ACA 双层主动探针（先标定信息、再故障信息）→ 标定门控证书 → 安全执行。CALIBRA 不是第 66 个并列模块，而是把第 65 轮 VISTA 里**被默认成立的「共同规范」显式化、可估计、可审计**。

### 灵感 5（VISTA 组件的原位升级）

- **VPG → VPG-M**：视觉世界模型照旧，但残差用**标定后的物理度量**（Φ 的 pullback）计算，不再用原始特征范数。
- **VCV → CCV**：接触验证先检查「当前视觉尺度是否可信（calib_valid）」；不可信时输出 `calib_unobservable`，与 `visual_unobservable` 同权重，都不得用于否决接触。
- **FIR → C-FIR**：故障假设与标定状态联合推断；新增 `H_calib`（规范 / 时延 / 编码器度量漂移）作为「可吸收」假设，并用 held-out 锚点残差判定它到底是真标定还是把故障吸收进来。
- **AFA → ACA**：两层探针，第一层最大化标定信息（低风险、可自由空间），第二层才最大化故障判别信息。
- **RSC-V → RSC-C**：新增 `r_cal`（标定不确定球）与 `r_anchor`（锚点可信度），只膨胀被归因者。
- **WCV-V → WCV-C**：搜索域增加「规范一致约束」𝒢_cal（物理可容许变换群）。
- **CSP-V 不变**，但块级证书需携带 `gauge_hash`，防止「用旧规范规划、用新规范执行」。
- **AIC-V → AIC-C**：干扰集增加编码器域漂移、时延错位、锚点共因污染、**可吸收故障攻击**。
- **J_vista → J_calibra**：证书增加 `calib_posterior`、`gauge_hash`、`calib_valid`、`absorption_residual`、`anchor_trust`。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（CALIBRA 闭环）**：CALIBRA = (VISTA, ENC, GAUGE, C-FIR, CCV, ACA, RSC-C/WCV-C, AIC-C, J_calibra)。定位：VISTA 的「标定可辨识化 + 规范显式化」升级。不变式：**标定估计、联合后验、规范固定、证书只在语义流；实时流只应用缓存的物理图册 Φ 与漂移统计，零学习写操作。**
- **定义 234（视觉编码器与潜在度量）**：编码器 f_enc: I→Z，z_t=f_enc(I_t)；特征增量 Δz；潜在度量 G_φ(z) 为 Z 上的 Riemannian 度量；编码器诱导距离 d_φ(z,z′)=√(Δzᵀ G_φ Δz)。关键事实：**G_φ 默认是语义度量，不是物理度量**——批量归一化/对比学习目标并不保证特征空间的欧氏距离对应任务空间位移。
- **定义 235（物理规范与锚点）**：锚点集 𝒜={(z_i, x_i^phys, w_i)}，由本体（关节编码器 / 正运动学）、LiDAR / 深度、标定板 / 基准标记、已知接触事件（零力窗、已知刚度轻触）给出，w_i 为可信度。物理规范 π=(R,t|外参, τ|时延, s|尺度, b|力偏置, G|低秩度量修正)。标定图册 Φ_π: Z→ℝ^{d_phys} 把特征搬到物理单位；pullback 度量 G_φ=J_ΦᵀJ_Φ（再加锚点残差正则）。
- **定义 236（编码器标定目标）**：π̂ = argmin_{π∈𝒢_cal} Σ_i w_i‖Φ_π(z_i)−x_i^phys‖²_{Σ_a⁻¹} + λ‖δπ‖²_{slow}，其中 𝒢_cal 为**物理可容许规范群**（刚体变换、尺度、时间平移、力偏置、保持正定且低秩的度量修正）；输出标定后虚拟观测 y_t^phys=Φ_π̂(z_t) 与标定不确定度 Σ_π。**标定不是拟合任意光滑映射，而是拟合一个受物理约束的群元素**——这是后文「不许吸收故障」的关键。
- **定义 237（标定漂移与规范轨道）**：π_t=π_0+δπ_t，慢变先验 ‖δπ_t−δπ_{t−1}‖≤ε_slow。规范轨道 𝒪_π={C(π′)x: π′∈𝒢_cal} 是「只改标定、不改物理世界」所能到达的观测方向集合；其切空间 T_cal=span{∂C(π)x/∂π_k}。
- **定义 238（标定-故障耦合观测模型）**：y = C(π)x + f_fault(θ) + ε，θ 为故障幅度（几何 / 力 / 模型 / 视觉 / 策略）。核心：δπ 与 θ 可以解释同一份残差；否认这一点就是前两轮的隐藏错误。
- **定义 239（标定-故障横向性）**：令 v_fault=∂f_fault/∂θ。定义横向角 β=∠(T_cal, v_fault)、可分指数 γ_cf=sin²β=1−⟨Π_{T_cal}v_fault,v_fault⟩²/(‖v_fault‖²‖Π_{T_cal}v_fault‖² 归一化)。γ_cf=1 表示规范与故障完全正交（可分），γ_cf→0 表示故障可被标定完全吸收（第 65 轮共因失效的几何本质）。
- **定义 240（标定-故障联合后验）**：P(π,θ|y)∝p(y|π,θ)p(θ|π)p(π)，p(π) 取慢变 / 低秩先验，p(θ) 取稀疏 / 突发先验。采用分块坐标或 Laplace 近似：先对规范做 Schur 边缘化，再在固定规范下归因，避免把「吸收」当成归因。
- **定义 241（C-FIR 标定感知归因）**：假设集扩为 ℋ_C=ℋ∪{H_calib}。`H_calib` 的签名是「残差能被 𝒢_cal 内的某个 δπ 解释，且 held-out 锚点残差仍小」；其处置是更新 π̂ 并**保持物理假设先验不变**。若加入 H_calib 后 `absorption_residual>` 阈值，则判 `absorption_suspect` 并转 ambiguous——**不允许用标定悄悄吃掉故障**。
- **定义 242（标定有效性证书）**：calib_valid(π̂)⇔ 锚点覆盖足够（各传感器族均有）∧ held-out 锚点残差≤q_anchor（split-conformal）∧ π̂∈𝒢_cal ∧ 时延估计已收敛 ∧ 编码器域漂移统计未越界。否则输出 `calib_unobservable`，视觉证据降权且不得用于否决接触（与 `visual_unobservable` 同级）。
- **定义 243（ACA 双层主动探针）**：第一层 a₁*=argmax_a I(π;y|a)，s.t. 非接触或极低接触风险（visual_probe / null_test / motion parallax / 轻触已知刚度基准）；第二层 a₂*=argmax_a I(ℋ;y|a,π̂)，s.t. 力 / 形变安全。若标定不确定度已低于 δ_cal 则跳过第一层。理由：γ_cf 小时，未定标下的故障探针互信息被规范不确定性吃掉，先花低风险预算定标是唯一高 ROI 选择。
- **定义 244（锚点可信度与共锚失效）**：每个锚点族有可信度 w_a；**共锚失效**=同一 OOD 源同时污染物理锚点与编码器特征（透明物体既是视觉 OOD，又让深度回波偏移）。用留一锚点族交叉验证、残差一致性检验与「锚点族间分歧」估计 anchor_trust；anchor_trust 低时 calib_valid 必须为假。
- **定义 245（块级标定漂移检测）**：对每个动作块，用 `d_chunk`、阶段残差均值漂移与锚点残差漂移的联合统计量检测 δπ 是否超出慢变预算；越预算即冻结当前 Φ、在语义流触发重标定，实时流只做「冻结 + 保守编译」。
- **定义 246（规范固定的可辨识性）**：联合 Fisher `J_joint=[[J_ππ,J_πθ],[J_θπ,J_θθ]]`。在物理约束 𝒢_cal 固定规范后，故障的条件 Fisher 为 Schur 补 `J_θ|π=J_θθ−J_θπJ_ππ⁻¹J_θπᵀ`；`J_θ|π≻0 ⇔` 故障可辨识，且 `λ_min(J_θ|π)` 与 γ_cf 同阶。**γ_cf→0 时 Schur 补奇异——这正是第 65 轮不可辨识的形式化。**
- **定义 247（CALIBRA 证书 J_calibra）**：J_calibra=(J_vista, calib_posterior, gauge_hash, calib_valid, absorption_residual, anchor_trust, calib_drift_stat)。`Valid ⇔ Valid(J_vista) ∧ calib_valid ∧ (非 absorption_suspect ∨ 已执行 ACA 第二层) ∧ gauge_hash 与执行规范一致 ∧ 标定不确定度未超预算`。
- **定义 248（CALIBRA 闭环算子）**：语义流 [锚点采集→编码器度量标定 Φ→联合后验→规范固定（held-out）→C-FIR→ACA→RSC-C→WCV-C→CSP-V/CSC→AIC-C]；实时流 [应用缓存 Φ→漂移统计→阶段残差→CSC 早停→前缀派发→J_calibra 构建]。

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（规范-故障可分离性）**：在定义 238 的线性化下，若故障方向与规范轨道夹角 β 且标定漂移慢变，则条件 Fisher 的故障分量 `λ_min(J_θ|π)≥(sin²β/σ²)·‖v_fault‖²`（对一维 θ）。故可辨识裕度由 γ_cf=sin²β 控制；γ_cf→0 时归因退化，**这正是第 65 轮把共因失效归为不可辨识的几何来源**。
- **引理 10（标定的风险支配性）**：设标定探针风险 R_cal≈0、故障探针风险 R_fi>0，单位风险的故障信息增益 ∝ γ_cf。则当 γ_cf<γ_min 时，先执行标定探针的信息-风险比严格优于任何故障探针；「先定标、再归因」是风险约束下的最优序贯决策。
- **定理 9（CALIBRA 端到端归因-安全）**：若 calib_valid、γ_cf≥γ_min、锚点未共因污染，则 (i) 规范与故障被分离；(ii) 真标定漂移归入 H_calib 且只膨胀 r_cal；(iii) 物理故障不被吸收（absorption_residual 约束）；(iv) 规范不可辨时显式退化为 ambiguous + 安全降级；(v) Valid(J_calibra) ⇒ GRIP/VISTA 全部安全性质 ∧ 标定规范与执行规范一致。
- **定理 10（无静默吸收）**：若 𝒢_cal 的维数 d_cal 小于物理故障子空间的维数 d_fault（刚体 + 时延 + 尺度 + 低秩度量 ≪ 任意接触几何 / 模型 / 力故障），则余维 d_fault−d_cal≥1 的故障分量无法被任何 π∈𝒢_cal 解释；held-out 锚点残差以高概率超出 q_anchor 并被 absorption_suspect 捕获。**故「受约束的标定群」是防止自洽错误的第一道闸。**
- **命题（编码器度量标定的物理化）**：域漂移若为潜在空间的局部微分同胚 h，原始 `‖Δz‖` 会随 Jacobian 改变；用锚点拟合的 Φ 近似抵消局部 Jacobian，使物理残差误差 ≤ 锚点残差 + O(曲率·位移²)。这给出 calib_valid 的适用域：工作空间内锚点覆盖 + 低曲率区。
- **实时性**：标定、联合后验、规范固定、ACA 全在语义流；实时流只增加「Φ 的一次前向 + 漂移标量 + gauge_hash 校验」≈0.1ms，目标仍 ≤2.5ms（A93 延续）。

## 5. 本轮最大风险

## 2. 形式化定义（完整版）

**定义 233（CALIBRA 闭环）** CALIBRA 是 VISTA 的「标定可辨识化 + 规范显式化」升级：在 VISTA 的语义流/实时流骨架上挂载 ENC-M（编码器度量标定）、GAUGE（标定状态）、C-FIR（联合归因）、CCV（标定门控接触验证）、ACA（双层主动探针），并原位升级 RSC-V→RSC-C、WCV-V→WCV-C、AIC-V→AIC-C、J_vista→J_calibra。不变式：**标定估计、联合后验、规范固定、证书只在语义流；实时流只做 Φ 的一次前向、漂移标量计算、gauge_hash 校验、阶段残差采集与安全前缀执行，零学习写操作。**

**定义 234（视觉编码器与潜在度量）** 编码器 f_enc 把图像 I_t 映为 z_t∈Z。特征增量 Δz=z_{t+h}−z_t 的「长度」由潜在度量 G_φ(z) 决定：d_φ(z,z′)=√(ΔzᵀG_φ(z)Δz)。现代自监督/对比编码器只保证语义邻近，不保证 G_φ 与物理任务空间等距；因此 `‖e_vis‖` 在 VISTA 中其实是一个**无单位、随域漂移的量**。本轮把它显式标记为待标定的虚拟传感器。

**定义 235（物理规范与锚点）** 锚点集 𝒜 由四类独立族构成：(i) 本体/关节编码器经正运动学给出末端位姿；(ii) LiDAR/深度给出几何点与法向；(iii) 标定板/基准标记给出手眼与尺度；(iv) 接触事件（零力窗、已知刚度轻触）给出末端—物体相对位姿。物理规范 π=(R,t,τ,s,b,G) 包含外参、时延、尺度、力偏置与低秩度量修正。标定图册 Φ_π: Z→ℝ^{d_phys} 由 π 参数化，pullback 度量 G_φ=J_ΦᵀJ_Φ。

**定义 236（编码器标定目标）**
π̂ = argmin_{π∈𝒢_cal} Σ_{i∈𝒜_fit} w_i ‖Φ_π(z_i)−x_i^phys‖²_{Σ_a⁻¹} + λ‖δπ‖²_slow，
s.t. 𝒢_cal = {刚体变换 × 尺度 × 时间平移 × 力偏置 × 低秩 PSD 度量修正}。
输出 π̂、Σ_π（标定后验协方差）与 y_t^phys=Φ_π̂(z_t)。**关键约束：Φ 不是任意光滑映射，而是物理可容许群元素**——这决定了故障能否被「吸收」（见定理 10）。Σ_vis 由 held-out 锚点残差估计，而非用特征维度的经验协方差。

**定义 237（标定漂移与规范轨道）** π_t=π_0+δπ_t，慢变先验 ‖δπ_t−δπ_{t−1}‖≤ε_slow。规范轨道 𝒪_π={C(π′)x: π′∈𝒢_cal} 是「只改标定、不改世界」可到达的观测方向；切空间 T_cal=span_k{∂C(π)x/∂π_k}。慢变 + 低秩是标定与故障的结构签名差异。

**定义 238（标定-故障耦合观测模型）** y=C(π)x+f_fault(θ)+ε。δπ 与 θ 都能解释同一残差。第 64/65 轮隐含假设 δπ=0（标定永远正确），于是把本该归给 H_calib 的残差强行归给 H_geo/H_force/H_model。

**定义 239（标定-故障横向性）** 令 v_fault=∂f_fault/∂θ 为单位化故障方向。横向角 β=∠(T_cal,v_fault)，可分指数 γ_cf=sin²β。γ_cf=1 表示故障方向完全在规范轨道之外（可分）；γ_cf→0 表示故障落在规范轨道内（可被标定完全吸收）。共因失效（透明/镜面/对抗 patch）的几何本质就是 T_cal 与 v_fault 共线。

**定义 240（标定-故障联合后验）** P(π,θ|y)∝p(y|π,θ)p(θ|π)p(π)，p(π) 慢变/低秩，p(θ) 稀疏/突发。用 Laplace 近似：联合 Fisher `J_joint=[[J_ππ,J_πθ],[J_θπ,J_θθ]]`，先算 Schur 补 `J_θ|π=J_θθ−J_θπJ_ππ⁻¹J_θπᵀ`，再在规范固定下做故障归因。若 `J_θ|π` 接近奇异，直接判 `indistinguishable_calib_vs_fault`，不强行归因。

**定义 241（C-FIR 标定感知归因）** 假设集 ℋ_C=ℋ∪{H_calib}。H_calib 的签名是「存在 δπ∈Lie(𝒢_cal) 使残差显著下降，且 held-out 锚点残差仍≤q_anchor」。处置：
- **真 H_calib**：在 𝒢_cal 内更新 π̂（慢变、低秩），只膨胀 r_cal；不改变物理假设先验；不降级几何。
- **absorption_suspect**：若吸收后 `absorption_residual(π̂;𝒜_val)>q_anchor`，说明该 δπ 为了解释故障已把标定拉出物理可容许区（或拉到一致错位），判 ambiguous，回退 π̂，转 ACA 或安全降级。
- **其余假设**：沿用第 65 轮定向处置，但**先扣除已归因的标定分量**再计算签名，避免把标定漂移重复记到物理故障上。

**定义 242（标定有效性证书）** calib_valid(π̂) ⇔
(i) 四类锚点族均覆盖 ∧ 留一验证通过；
(ii) held-out 锚点残差 ≤ q_anchor(α_cal)（split-conformal）；
(iii) π̂∈𝒢_cal 且 G 半正定、时延 τ 已收敛；
(iv) anchor_trust≥τ_a（无共锚失效嫌疑）；
(v) 编码器域漂移统计未越界。
不满足则 `calib_unobservable`：视觉证据降权（w_vis←w_vis·κ_cal），且**不得用于否决接触**（与 `visual_unobservable` 同级）。

**定义 243（ACA 双层主动探针）**
第一层（标定）：a₁*=argmax_a I(π;y|a)，s.t. 非接触或对已知基准的极低力接触（visual_probe / null_test / motion_parallax / 轻触标定板）。
第二层（判别）：a₂*=argmax_a I(ℋ;y|a,π̂)，s.t. 预测 f_n≤f_safe、形变≤ε_strain。
若 Σ_π 已低于 δ_cal，跳过第一层。若 γ_cf<γ_min，第一层是唯一高 ROI 选择（引理 10）。易损物体只允许第一层与 visual-only 第二层。

**定义 244（锚点可信度与共锚失效）** 每个锚点族 a 有可信度 w_a。共锚失效指同一 OOD 源同时污染物理锚点与编码器特征。检测：(i) 留一锚点族重标定，若去掉某族后 π̂ 跳变>τ_jump，则该族可疑；(ii) 各族给出的 x^phys 分歧>τ_disagree；(iii) 编码器残差与锚点残差的相关性异常升高（两者被同一源推动）。输出 anchor_trust=∏_a σ_trust(·)。anchor_trust 低 ⇒ calib_valid 假 ⇒ 视觉证据降权。

**定义 245（块级标定漂移检测）** 对动作块，统计量
D_cal(t)=‖δπ̂_t−δπ̂_{t−1}‖²/ε_slow² + ‖d_chunk(t)‖²/σ_chunk² + ‖Δanchor_residual_t‖²/σ_a²，
若 D_cal(t)>χ²_3(1−α_cal) 则冻结 Φ、在语义流重标定；实时流只读冻结标记并保守编译。慢变预算 ε_slow 使「标定」与「突发故障」在时间尺度上分离。

**定义 246（规范固定的可辨识性）** 联合 Fisher J_joint 如上；固定规范（对 π 施加 𝒢_cal 约束、边缘化 Σ_π）后，故障条件 Fisher 为 J_θ|π。`J_θ|π≻0` ⇔ 故障可辨识；对一维 θ，`J_θ|π=(sin²β/σ²)‖v_fault‖²`，故 `κ_cal=λ_min(J_θ|π)/λ_max(J_θθ)=γ_cf·(…)`。**γ_cf 是把「第 65 轮共因失效」与「可辨识性」连起来的唯一标量。**

**定义 247（CALIBRA 证书 J_calibra）** J_calibra=(J_vista, calib_posterior, gauge_hash, calib_valid, absorption_residual, anchor_trust, calib_drift_stat)。验证：
Valid(J_calibra) ⇔ Valid(J_vista)
∧ calib_valid ∨ 已显式转 visual_unobservable 降级
∧ (非 absorption_suspect ∨ 已执行 ACA 第二层)
∧ gauge_hash(规划规范)=gauge_hash(执行规范)
∧ calib_drift_stat 未越预算。
审计链新增：为何相信这个规范（calib_posterior）、规范是否被故障吸收（absorption_residual）、锚点是否可信（anchor_trust）。

**定义 248（CALIBRA 闭环算子）** 语义流：[锚点采集→ENC-M 标定 Φ→GAUGE 联合后验→规范固定（held-out）→C-FIR 归因/H_calib→ACA→RSC-C→WCV-C→CSP-V/CSC→AIC-C]；实时流：[应用缓存 Φ→D_cal 漂移标量→阶段残差→CSC 早停→前缀派发→J_calibra]。

### IP-224/225 ENC-M + GAUGE（编码器度量标定）

```python
class EncoderMetricCalibrator:
    """把编码器潜在度量搬进物理单位；只在语义流。"""
    def __init__(self, group, lam=1.0, heldout=0.3):
        self.group, self.lam, self.heldout = group, lam, heldout

    def calibrate(self, anchors, pi_prev=None):
        fit, val = split_by_family(anchors, self.heldout)
        def loss(pi):
            r = [w * physical_err(Phi(pi, z), x) for z, x, w in fit]
            reg = self.lam * slow_prior(pi, pi_prev)
            return np.sum(r) + reg
        pi_hat = minimize_on_group(loss, self.group, init=pi_prev)   # 保持 π∈𝒢_cal
        G = pullback_metric(pi_hat)                                   # J_Φᵀ J_Φ
        Sigma_pi = laplace_cov(loss, pi_hat)
        Sigma_vis = anchor_residual_cov(val, pi_hat)
        q_anchor = conformal_quantile([physical_err(Phi(pi_hat, z), x)
                                       for z, x, w in val], alpha=ALPHA_CAL)
        return pi_hat, G, Sigma_pi, Sigma_vis, q_anchor

    def valid(self, pi_hat, val, q_anchor, anchor_trust, drift):
        families_ok = all_families_covered(val)
        heldout_ok = max_anchor_residual(val, pi_hat) <= q_anchor
        group_ok = in_group(pi_hat) and psd(pi_hat.G)
        return families_ok and heldout_ok and group_ok \
               and anchor_trust >= TAU_A and drift <= DRIFT_BUDGET
```

### IP-226 C-FIR（标定-故障联合归因）

```python
class CalibrationAwareFIR:
    def __init__(self, lik, delta_fi=0.15, gamma_min=0.2):
        self.lik, self.delta_fi, self.gamma_min = lik, delta_fi, gamma_min

    def attribute(self, y_phys, pi_hat, Sigma_pi, Sigma_vis, val_anchors, q_anchor):
        J = joint_fisher(y_phys, pi_hat, Sigma_pi, Sigma_vis)
        gamma = separability_index(J)                 # 由 J_πθ 与 J_θθ 估 sin²β
        if gamma < self.gamma_min:
            return {'verdict': 'indistinguishable_calib_vs_fault',
                    'posterior': None, 'gamma_cf': gamma}
        J_cond = schur_complement(J)                  # J_θ|π
        post = gaussian_posterior(y_phys, pi_hat, J_cond)
        h_star = max(post, key=post.get)
        if h_star == 'H_calib' and post[h_star] >= 1 - self.delta_fi:
            pi_new = update_within_group(pi_hat, y_phys, Sigma_pi)
            r_abs = max_anchor_residual(val_anchors, pi_new)
            if r_abs > q_anchor:                      # 标定在吃故障
                return {'verdict': 'absorption_suspect', 'pi_new': pi_hat,
                        'absorption_residual': r_abs, 'posterior': post}
            return {'verdict': 'H_calib', 'pi_new': pi_new,
                    'absorption_residual': r_abs, 'posterior': post}
        # 归因前先扣除已估标定分量，避免双重记账
        return {'verdict': h_star, 'posterior': post, 'gamma_cf': gamma,
                'pi_new': pi_hat}
```

### IP-228 ACA（双层主动探针）

```python
class ActiveCalibrationAttribution:
    CAL_PROBES = ('visual_probe', 'null_test', 'motion_parallax', 'bench_touch')
    FI_PROBES  = ('press', 'rub', 'tap', 'lift', 'visual_probe', 'null_test')

    def choose(self, Sigma_pi, post, pi_hat, f_safe, fragile, gamma_cf):
        # 第一层：标定信息，风险≈0
        a1, ig1 = None, 0.0
        if trace(Sigma_pi) > DELTA_CAL:
            for a in self.CAL_PROBES:
                ig = expected_mutual_info_cal(Sigma_pi, a)
                if ig > ig1:
                    a1, ig1 = a, ig
        # 第二层：故障判别信息；γ_cf 小时其价值本来就低
        a2, ig2 = None, 0.0
        for a in self.FI_PROBES:
            if fragile and a not in ('visual_probe', 'null_test'):
                continue
            traj = predict_probe_traj(a, pi_hat)
            if np.max(traj.f) > f_safe or np.max(traj.strain) > EPS_STRAIN:
                continue
            ig = gamma_cf * expected_mutual_info_fi(post, a)
            if ig > ig2:
                a2, ig2 = a, ig
        return (a1, ig1) if ig1 >= max(ig2, DELTA_CAL) else (a2, ig2)
```

### IP-229 RSC-C / WCV-C（规范一致编译）

```python
def wcv_c_compile(x_prime, phi_hat, balls, post, pi_hat, gauge_hash,
                  G_set, mu_hat, delta_mu, f_lim, w_vis, n_worst=8, eps=0.05):
    r = np.sqrt(sum(balls[k]**2 for k in
                    ('r_cal', 'r_anchor', 'r_geo', 'r_force', 'r_model')))
    candidates = []
    for _ in range(n_worst):
        H = sample_from(post)
        phi_c = sample_ball_intersect(phi_hat, r, G_set, mu_hat, delta_mu,
                                      f_lim, H)
        if phi_c is None:
            return None, -np.inf, True, gauge_hash
        K = olp.project(x_prime)
        K_c = eeis.compile_with_phys_constraint(K, phi_c)
        # 规范一致：编译与执行必须用同一个 Φ/gauge
        if gauge_of(phi_c) != gauge_hash:
            return None, -np.inf, True, gauge_hash
        candidates.append((phi_c, K_c, safety_margin(K_c, phi_c),
                           execution_loss_estimate(K_c, phi_c)))
    candidates.sort(key=lambda z: z[3], reverse=True)
    tail = candidates[:max(1, int(eps * n_worst))]
    K_safe = intersect_shrink([c[1] for c in tail])
    rho_rob = min(c[2] for c in tail)
    return K_safe, rho_rob, False, gauge_hash
```

## 4. 推导

**引理 9（规范-故障可分离性）** 线性化观测 y=C(π)x+f(θ)+ε，噪声协方差 Σ。联合 Fisher 分块 `J_joint=[[J_ππ,J_πθ],[J_θπ,J_θθ]]`，其中 `J_πθ=T_calᵀΣ⁻¹v_fault`。规范固定后故障的条件 Fisher 为 Schur 补 `J_θ|π=J_θθ−J_πθᵀJ_ππ⁻¹J_πθ`。把 v_fault 正交分解为沿 T_cal 的分量（幅度 cosβ）与垂直分量（幅度 sinβ）。沿规范轨道的分量可被 δπ 完全吸收，对 J_θ|π 无贡献；只有垂直分量留下信息。故对一维 θ，
`J_θ|π = (sin²β / σ²)‖v_fault‖² = (γ_cf/σ²)‖v_fault‖²`。
因此 `J_θ|π≻0 ⇔ γ_cf>0`，且可辨识裕度 `κ_cal=γ_cf·‖v_fault‖²/(σ²λ_max(J_θθ))`。当 γ_cf→0 时 J_θ|π 奇异，故障与标定在观测上等价——**第 65 轮所谓「共因失效导致 FIR 强行归因」正是 γ_cf→0 的特例**。∎

**引理 10（标定的风险支配性）** 标定探针 a_cal 可安排在自由空间或极低力基准接触，其物理风险 R_cal≈0；故障探针 a_fi 需接触/加载，风险 R_fi>0。由引理 9，未固定规范时故障探针携带的故障信息按 γ_cf 折减，故其单位风险信息增益 ≈ γ_cf·I₀/R_fi；标定探针的单位风险信息增益 ≈ I_cal/R_cal→∞（R_cal→0）。当 γ_cf<γ_min 时，任何故障探针的 ROI 都低于标定探针；因此风险约束下的最优序贯决策是「先定标、再归因」。这与第 65 轮 AFA「直接最大化故障判别互信息」形成对照：AFA 默认规范已固定。∎

**定理 9（CALIBRA 端到端归因-安全）** 在 A94–A98 下（锚点覆盖、慢变漂移、𝒢_cal 约束、conformal 覆盖、γ_cf≥γ_min）：
1. **规范可辨识**：calib_valid 时 π̂ 在 𝒢_cal 内唯一（至多慢变），Σ_π 有限；否则显式 `calib_unobservable`。
2. **故障可分离**：γ_cf≥γ_min 时 J_θ|π≻0，归因后验以 O(exp(−n·κ_cal/2)) 集中（引理 9）。
3. **不静默吸收**：H_calib 更新受 𝒢_cal 与 held-out 锚点双重约束；若吸收后 absorption_residual>q_anchor，判 absorption_suspect（定理 10）。
4. **安全降级**：γ_cf<γ_min 或 calib_valid 假时，不归因、不降级几何、视觉降权、走 ACA 或 safe_idle；不因「已经归因」而更自信。
5. **证书六层链**：Valid(J_calibra) ⇒ GRIP 有效 ∧ VISTA 有效 ∧ 规范有效 ∧ 规范未被吸收 ∧ gauge 一致 ∧ 漂移在预算内。
6. **实时性**：实时路径新增 Φ 前向 + 漂移标量 + gauge 校验 ≈0.1ms，总目标 ≤2.5ms。∎

**定理 10（无静默吸收）** 设物理故障子空间 V_fault 的维数 d_fault（含接触几何、接触模型、力偏置与视觉物理扰动的一般方向），物理可容许规范群的维数 d_cal。若 d_fault>d_cal，则存在 V_fault 的一个至少 d_fault−d_cal≥1 维余维子空间，其向量不落在 T_cal 内；对其中任何非零 θ，`v_fault(θ)∉T_cal`，故不存在 δπ∈Lie(𝒢_cal) 使 `f(θ)=C(δπ)x` 精确成立，最优吸收残差 >0。进一步，若故障是局部/查询相关的，而 𝒢_cal 是全局、低秩、与查询无关的，则吸收误差在 held-out 锚点上不会与拟合集同步下降；故 `absorption_residual>q_anchor` 以高概率触发。**结论：把标定限制在「物理可容许的低维群」而不是任意网络，是不让系统得到「自洽却整体错位世界」的第一道闸。** ∎

**命题（编码器度量标定的物理化收益）** 设编码器域漂移在潜在空间为局部微分同胚 h，原始特征距离按 Jacobian J_h 缩放。用锚点拟合 Φ 后，pullback 度量近似为 `J_ΦᵀJ_Φ`，在锚点邻域内抵消 J_h 的一阶项，物理残差误差 ≤ 锚点残差 + O(曲率·位移²)。故「标定后残差」比「原始特征范数」更接近物理故障证据；但适用域受锚点覆盖与曲率限制——这直接给出 calib_valid 的空间适用条件。∎

**命题（时延标定对阶段归因的必要性）** 时延 τ 使视觉与力残差错位；当 τ 与阶段宽度同量级时，approach/touch 边界被平移，H_model（加载后才偏）与 H_force（零力窗 DC）的签名会互相泄漏。把 τ 纳入 π 并在标定中估计后，阶段签名恢复对齐；否则第 65 轮的三阶段可辨识性（引理 7）在时延下退化。∎

## 7. 已知风险

**一句话**：CALIBRA 的分辨力取决于「锚点本身没有被共因污染」与「物理可容许规范群 𝒢_cal 恰好不含故障方向」这两个假设；一旦透明/镜面/对抗物体同时污染编码器特征与物理锚点（共锚失效），联合后验会把真实故障当作编码器度量漂移吸收进 Φ，held-out 锚点也随之一致偏移，系统就获得一个「标定得很好、但整体错位」的世界——**第 65 轮的「归因错误」由此升级为「规范化地、自洽地错误」，且证书会因为 calib_valid 为真而更自信。**

**次级风险与缓解**：
1. **共锚失效 / 锚点污染**：透明、镜面、对抗 patch 同时骗编码器与深度/LiDAR；缓解：四类异构锚点族 + 留一交叉验证 + 族间分歧检测，anchor_trust 低即 calib_valid 假；未来引入与视觉/几何物理独立的通道（IMU/关节力矩/事件相机）。
2. **𝒢_cal 选小了（真标定被拒）或选大了（故障可吸收）**：群维数与结构是设计选择；缓解：用离线故障库标定 d_cal 与 d_fault，报告「可吸收余维」；AIC-C 显式做吸收攻击认证。
3. **慢变先验与突发故障的边界模糊**：真实漂移可能阶跃，真实故障也可能缓慢累积（磨损）；缓解：多尺度漂移检测 + 把缓慢物理故障显式加入 ℋ_C（H_slow），用 held-out 锚点区分「全局一致慢漂」与「局部物理退化」。
4. **编码器度量标定的适用域窄**：锚点覆盖不足、强曲率、透明/无纹理区域 Φ 不可信；缓解：只在标定覆盖区信任 y_phys，区外退化为原始特征 + `calib_unobservable`。
5. **联合后验计算与可辨识性估计昂贵**：d_cal 增大时 Schur 补与 Fisher 估计成本上升；缓解：低秩参数化 𝒢_cal、Laplace 近似、只在语义流低频更新。
6. **时延估计在低激励下不可观**：静止或匀速运动时 τ 不可辨识；缓解：ACA 第一层显式插入快速往返/轻触激励，null_test 提供时延可观性。
7. **证书的组合复杂度**：J_calibra 叠加 J_vista 六层，审计链变长；缓解：证书分层哈希、gauge_hash 增量校验、失败即短路到安全降级。
8. **实时预算**：Φ 前向与 gauge 校验虽小，但叠加 VISTA 后逼近 2.6ms；缓解：Φ 用低秩/分段线性、与 LSF 共享编码、把一切学习更新留在语义流。
