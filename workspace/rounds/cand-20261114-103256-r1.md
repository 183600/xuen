# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS 具身计量审计」IP-287~294；灵感循环第 3 轮；本轮灵感：「对话管理」×「差异化定位」）

> R72 把 GAUGE 从认知层下沉到具身层：REG 实时执行图、IRL 意图隐变量、DMEM 接触四分量、EREFLEX 三层反作用、S2R-UQ 桥接、三域分离。它回答了「测量链能否在实时调度、意图模糊、灵巧接触下逐指令兑现风险界」。但 R72 仍有三个结构性盲点：
> - **对话被压成一次性查询**：R72 的 ERVOI 只选一个澄清动作 g，拿回一个 y；真实交互是多轮协议——有共同基础（grounding）、指代确认、承诺（commitment）、修复（repair）、话轮（turn-taking）、主动权（initiative）与角色（role）。「问什么」之外还有「以什么身份问、问完承诺什么、答不上来如何修复」。
> - **不确定性求和仍是补偿制**：R72 说「物理/意图/接触同权入分母」，但 λ = f(U_ale + U_epi + H_z + u_tac) 仍是标量求和——某一维极小的不确定度可以在数值上抵消另一维的失控。这与 R72 自己主张的「非补偿性安全否决」自相矛盾。**同权不等于不可交换；求和就是可交换。**
> - **模块没有管辖权**：R72 允许任何证据更新联合后验 b_t(s,z)，触觉似然可以喂给意图、语言可以喂给接触。它识别了「把接触不确定度误读为世界状态不确定度」的风险，却没有给出**类型系统**来禁止这种范畴错误。模块没有「我能在哪个域发言」的显式定位，就会产生**能力蔓延（competence creep）**。
>
> 本轮两个灵感补两块：
> - **对话管理**：把单步查询升级为**带承诺与接地的多轮对话策略**——对话状态、共同基础、承诺账本、修复栈、话轮/主动权、角色契约、社会预算；澄清不是「取一个数」，而是「请求一个管辖域上的授权/证据」。
> - **差异化定位**：把「同权求和」升级为**分权式的管辖权地图**——每个模块/信源在「认识权威 × 物理权威 × 时间尺度 × 分布范围 × 面向人的权威」上有自己的定位；越权断言是类型错误，不能靠别的维度的强证据补偿；定位缺口 g_pos 是**非补偿性否决**。
>
> 核心命题：R72 问「我的测量链能否兑现风险界」；R73 问「**我的系统是否知道自己被授权断言什么，并能在多轮对话中守住这个职权边界，而不让语言的流利替代测量的有效？**」——从「具身计量审计」升级为 **POSITIONED-DIALOGUE-GAUGE-RAS（PD-GAUGE-RAS，定位对话式具身计量审计）**。一句话：**先定位，再对话；先分权，再融合；先承诺，再行动。**

## 0. 直觉与动机

**灵感 1（对话管理 → 澄清是一个带承诺的协议，不是一次取数）**
直觉：R72 的澄清动作 g 在代码里是 `y = M.cia.execute(g)`，拿回一个观测就结束。但真实对话中，「是左边那个吗？」会改变共同基础、暴露不确定性、制造期待、消耗耐心；对方的「对」也不是独立同分布证据——它锚定在一个可能本身就有歧义的指代上。如果机器人随后抓错，失败不是「感知误差」，而是**接地失败 + 承诺失败**。真实对话包含：询问、确认、解释、修复、承诺、撤回、拒绝、移交。每个话轮都有前置条件与状态效应。**对话管理不是 NLU 的后处理，而是安全关键的状态机。**

**灵感 2（差异化定位 → 求和是隐蔽的补偿，分权才是非补偿）**
直觉：R72 用 `U_ale + U_epi + H_z + u_tac` 求和。标量求和隐含了一个「汇率」：1 单位接触不确定度可以换 1 单位意图不确定度。但它们不可交换：再高的视觉置信度也不能让一个未接地的触摸变得安全；再准的触觉也不能授权一个关于人类意图的断言。差异化定位主张：**每个不确定度有自己的管辖域与红线；任何域的红线不能被其他域的绿灯抵消。** 所以「差异化」不是给模块调权重，而是给模块**分权**。

**灵感 3（对话 × 定位 → 每个话轮都是一次定位行为）**
直觉：机器人说「我确定这是红色杯子」时，它把自己定位成视觉权威；说「你能确认想要哪一个吗」时，它把人类定位成意图权威；说「我不能保证不滑」时，它把触觉域定位为不确定。**每个对话行为都是一次「带定位的断言/请求」。** 错位的对话是范畴错误：触觉模块不能「确认」人类意图，意图分类器不能「认证」抓取安全。对话是运行时用来**建立、争夺、修复管辖权**的协议；澄清的本质是**向有管辖权的信源请求授权/证据（warrant）**。

**灵感 4（承诺账本 → 承诺是有证书的债）**
直觉：「我帮你拿」不是一次动作，而是一个承诺：有受益人、截止时间、前置条件、证书引用、撤回策略。若接触不确定度上升导致证书失效，承诺必须被**挂起并重谈**，而不是偷偷执行。违背承诺是信任事件与安全事件。R72 的规划是「承诺盲」的；R73 把承诺变成一等公民。**一个计划不是一条轨迹，而是一组带证书的承诺。**

**灵感 5（角色/立场 → 系统必须能说「不知道 / 不归我管 / 请找专家」）**
直觉：角色（工具/助手/协作者/受托监督者）决定主动权、允许的对话行为、解释义务与拒绝权，但**永远不扩大管辖权，也永远不能兑换安全否决权**。角色升级必须被协商并记录在账本；单方面角色漂移是违规。拒绝、延迟、移交是一等安全动作，不是失败。一个只会回答的系统是不安全的；它必须能**体面地不回答**。差异化也适用于研究本身：R73 不是一个更好的估计器，而是一个**治理层**；必须明确写出「它不是什么」。

**灵感 6（定位缺口 → 新的一类非补偿风险）**
直觉：R72 的风险源是 aleatoric / epistemic / intent / contact。R73 增加 **positioning gap（定位缺口）**：所需命题根本没有被授权的信源。这不是「不确定度高」，而是「没有管辖权」。收集更多错误域的证据不能降低它。g_pos > 0 ⇒ 安全保持 + 对话寻求 warrant + 必要时移交。**不知道并不可怕；不知道自己不知道、或知道了却不被授权说，才可怕。**

## 1. 形式化定义（增量：定义 366–382）

**定义 366（PD-GAUGE-RAS 总览）** PD-GAUGE-RAS = (DPM, DST, CML, GRM, DPP, SPM, NC-RISK, GAUGE-RAS††)。六不变式：
(i) **定位可靠性（positioning soundness）**：每个影响动作的断言/对话行为都携带可采纳见证 w = (m, p, x, env, τ)，其中 m 是模块/信源，p 是命题，x 是语境，env 是有效域，τ 是追溯链；
(ii) **管辖非补偿**：任一风险维度的否决不能被另一维度的强证据抵消；定位缺口 g_pos > 0 是硬否决；
(iii) **接地先于承诺**：承诺中出现的任何指代 r 必须满足 γ(r) ≥ τ_g；
(iv) **承诺-证书一致**：只有证书有效的动作才能被承诺；证书过期只能挂起并重谈，绝不静默执行；
(v) **角色有界**：角色变更只改变主动权与社会性行为，绝不改变管辖权或安全权威；
(vi) **严格逐指令退化**：无 DPM ⇒ R72；无多轮对话 ⇒ R72 单步；无承诺层 ⇒ 只允许可逆探测；对话/定位失效 ⇒ R71/R68。**安全侧只增不减。**

**定义 367（对话状态）** 对话状态
b_t(D) = (z, G, C, Q, R, ι, κ, h, σ)，
其中 z 为意图（继承 R72），G 为共同基础（指代、命题、接地度 γ），C 为承诺账本，Q 为未决问题/未闭合 warrant，R 为修复栈，ι 为话轮与主动权状态，κ 为当前角色契约，h 为对话历史，σ 为人类信源定位模型。DST（对话状态跟踪器）维护其后验；**对话状态与物理后验 b_t(s,z) 通过带类型的接口耦合，而不是任意联合更新。**

**定义 368（对话行为与前后置条件）** 对话行为集
𝒜_d = {inform, ask_referent, ask_warrant, confirm, explain, warn, refuse, defer, handover, repair, negotiate_role, acknowledge, retract, probe}。
每个行为 a = (type, content, target, warrant_scope, positioning_witness)。前置条件 pre(a, b_t(D)) 规定「谁在什么角色下、对哪个域、以何种证据、能说这句话」；状态转移 T_d(a, b_t(D)) 给出对 (z, G, C, Q, R, ι, κ, σ) 的效应；成本 c_dial(a) = (c_attn, c_trust, c_interrupt, c_privacy)。
**关键行为 `ask_warrant(d, s)`**：向信源 s 请求其在管辖域 d 上的证据/授权，用于闭合一个定位缺口；它区别于普通 `ask_clarify`（减少认知不确定度），是 R73 的新原语。

**定义 369（差异化定位图 DPM）** 定位图
Π = (M, S, X, J, ⊑, Arb)，
- M 为模块集（BSE/IRL/DMEM/REG/AURA/…），S 为信源集（人类、视觉、触觉、仿真、外部专家）；
- X 为定位轴：认识权威（epistemic authority）、物理权威（physical authority）、时间尺度（temporal horizon）、分布范围（distribution scope）、面向人的权威（human-facing authority）；
- J(m) ⊆ Prop × Context 为**管辖权**：模块 m 被授权断言的命题-语境对；
- ⊑ 为权威偏序（不是全序，也不可数值平均）；
- Arb 为重叠仲裁规则：当两个模块都声称有管辖权时，必须由预先认证的仲裁器裁决，禁止静默平均。
**定位图不是权重表，是管辖图。** 一个模块可以「权重低但不可替代」，也可以「权重高但域很窄」。

**定义 370（可采纳见证与定位可靠性）** 对命题 p 在语境 x 下的断言，见证
w = (m, p, x, env, τ, jw)
可采纳（Adm(p,x)）当且仅当：(1) p ∈ J(m)；(2) x ∈ Env_m（有效域）；(3) τ 未过期且可复算；(4) 不存在更高优先级的 Arb 规则禁止；(5) 若 p 跨域，则 jw 是显式的联合见证（joint witness），包含每个域的独立授权。**任何决策只能使用 Adm(p,x) 为真的命题。**

**定义 371（定位缺口与非补偿风险向量）** 对时刻 t 的必需命题集 P_t：
g_pos(P_t) = 0 若 ∀p∈P_t, Adm(p,x)；否则 g_pos = 1（或按到管辖覆盖的距离取 [0,1] 的连续值）。
风险不再用标量，而用向量
r_t = (r_phys, r_intent, r_contact, r_pos, r_dial)。
动作 a 可采纳当且仅当
∀i: r_i(a) ≤ ε_i 且 g_pos(a) = 0。
控制增益不采用 `max` 后的单一 λ，而采用**分量最小**：
K_ij ≤ min{ K_ij^max(r_phys), K_ij^intent(r_intent), K_ij^contact(r_contact), K_ij^pos(r_pos) }，
即每个约束独立收紧阻抗，**不允许某一维的放松去抵消另一维的收紧**。若需标量化（例如给低层控制器一个数），只有在存在**经认证的支配关系（certified dominance）**时才允许，且必须附保守性证明。**没有支配证明的标量化一律视为补偿作弊。**

**定义 372（承诺账本 CML）** 承诺账本
C_t = { c = (id, action/proposition, beneficiary, deadline, preconds, cert_ref, status, retract_policy, grounding_refs) }，
status ∈ {proposed, active, suspended, fulfilled, retracted, violated}。
操作：commit / suspend / resume / retract / fulfill。可承诺条件：
(1) 动作在其承诺时刻有有效 J_EMB；(2) 前置条件成立；(3) grounding_refs 全部 γ ≥ τ_g；(4) 角色 κ 允许该承诺。
一致性：不存在互相矛盾的活动承诺；截止时间在 REG 调度下可行；每个 active 承诺必须有未过期的 cert_ref，否则自动转 suspended。
**承诺是有证书的债；证书过期，债自动转为待重谈，而不是偷偷执行。**

**定义 373（接地状态与修复）** 共同基础 G_t 给每个指代 r 一个接地度 γ(r) ∈ [0,1]，给每个命题一个 grounded/ungrounded 标记。γ 由对话证据更新（确认、指认、示范、复述）。动作涉及 r 的必要条件为 γ(r) ≥ τ_g。
修复算子 ρ 的触发条件：未理解、指代失败、命题矛盾、证书过期、角色不匹配。修复行为包括 ask_referent、ask_warrant、explain、retract、renegotiate。任何受影响的承诺进入 suspended（不删除、不默认继续）。**未接地不行动；接地失效则停承诺。**

**定义 374（对话策略与对话 VoI）** 对话策略
π_d(a | b_t(D), Π, B_dial)
求解一个带约束的 POMDP：
max E[ Σ_t γ^t ( U_task + η_z·IG_z + η_G·IG_ground + η_C·ΔU_commit − c_dial − c_reflex − c_pos ) ]
s.t. 定位可靠性、承诺一致性、接地、社会预算、角色契约、非补偿风险。
对话信息价值：
VoI^D(a) = η_z·IG_z + η_G·IG_G + η_C·ΔU_commit + η_W·Δg_pos
           − c_dial − c_reflex − c_social − γ·E[ΔH_future_degraded]。
**Δg_pos 项是 R73 的核心**：一个能闭合定位缺口的 warrant 请求，其价值不能被同域信息增益替代。若所有候选行为的 VoI^D ≤ 0，安全动作是 defer / handover / safe hold，而不是继续问。

**定义 375（角色契约）** 角色 κ ∈ K = {tool, assistant, collaborator, delegated-supervisor}。每个角色定义 (主动权范围, 允许的对话行为, 解释义务, 拒绝权)，但 **A(κ) 永不包含安全权威覆盖**。角色转移需要 negotiate_role + acknowledge，并写入账本；单方面角色漂移是违规。角色漂移度
D_role = d(declared_role, enacted_role)
是审计指标。**角色只改主动权，不改管辖权；角色升级不能兑换安全否决权。**

**定义 376（社会/对话预算）** B_dial = (B_attn, B_trust, B_interrupt, B_privacy)，每个对话行为有对应成本，累计 ≤ B_dial。预算耗尽触发 defer/handover，或最多一次高价值 warrant 请求，绝不无限追问。它扩展 R72 的 B_reflex_total。**社会资本也是预算，问多了会破产。**

**定义 377（人类信源定位 SPM）** 对每个信源 s 与域 d，维护权威 α(s,d) 的后验，以及来源标签（域、声称权威、激励、可靠性）。信源 s 只有在 α(s,d) > τ_α 时才能直接更新域 d 的信念；否则它只能「报警」或触发 ask_warrant，不能直接改后验。
典型矩阵：
- 人类对「自己的意图/偏好」高权威，对「接触力学/机器人关节温度」低权威；
- 触觉对「接触模式」高权威，对「人类意图」零权威；
- 视觉对「物体类别/位姿」中高权威，对「是否滑移」低权威。
**人不是命令源，人是有定位的证据源；机器人也不是全知源，它只在自己的域内是权威。** 跨域服从（cross-domain deference）必须显式换取 warrant，否则无效。

**定义 378（定位化贝叶斯更新）** 用按管辖域加权的更新替换 R72 的无限制联合更新：
b_{t+1}(x_i) ∝ b_t(x_i) · ∏_{m∈M_i} L_m(y_m | x_i)^{w_{m,i}}，
其中 w_{m,i} = 0 若 m 对变量 x_i 没有管辖权；跨域耦合只允许通过**显式声明的结构模型**（例如接触物理影响 s），禁止任意似然注入。若某变量没有任何被授权的似然，它保持先验，依赖它的决策的 g_pos 变为 > 0。**这是防止范畴错误的类型系统，不是又一层加权。**

**定义 379（对话-定位证书 J_PD）**
J_PD = (J_EMB, pos_map_hash, policy_hash, ledger_hash, grounding_proof, role_contract_hash, budget_proof, noncomp_proof, source_pos_hash, dlg_ver)。
Valid ⇔ J_EMB 有效 ∧ Π 哈希匹配 ∧ 策略/账本一致 ∧ 接地证明有效 ∧ 角色契约匹配 ∧ 预算未超 ∧ 非补偿证明有效 ∧ 信源定位链完整。
**证书不是给一段独白盖章，而是给一场对话的管辖权盖章。**

**定义 380（威胁模型 AIC-DIAL）** ℰ_DIAL = ℰ_EMB ∪ {
社会工程、权威冒充、紧迫感操纵、指代劫持、承诺陷阱、角色升级、接地投毒、warrant 伪造、对话洪泛/拒绝服务、流利但无效的叙述、跨文化立场错配 }。
新增攻击面不是「模型答错」，而是「模型用正确的话术把越权判断包装成合法承诺」。

**定义 381（严格退化链）** 完整 PD ⇒ 无多轮对话（退回 R72 单步）⇒ 无定位图（退回 R72 相等求和）⇒ 无承诺层（只允许可逆 probe）⇒ R71 ⇒ R68。安全单调不减；任何退化都保留 R68 硬安全包络与非补偿否决。**对话层坏了退回单步；定位层坏了退回 R72；但安全包络只增不减。**

**定义 382（差异化审计 / 反 Goodhart）** 对每个模块 m 定义其管辖域内指标 μ_m 与**定位消融测试**：只有移除/替换 m 会改变 μ_m（其 own domain），而不是只改变聚合分数时，m 的贡献才被认证；跨域领功被禁止。J_PD 必须附带「贡献定位表」。**差异化不是营销口号，是归因纪律：每个模块只能在自己域内领功，也只能在自己域内背锅。**

# IP-295 DPM：差异化定位图（部署期构建 + 运行时只读）
@dataclass
class Jurisdiction:
    module: str
    prop_types: Set[str]          # 可断言的命题类型
    contexts: Set[str]            # 有效语境/分布
    authority: Dict[str, float]   # 各定位轴上的权威
    ttl_ms: float                 # 见证有效期
    arb_priority: int             # 重叠仲裁优先级

class PositioningMap:
    def __init__(self, jurisdictions, arbitration_rules):
        self.J = {(j.module, p): j for j in jurisdictions for p in j.prop_types}
        self.arb = arbitration_rules
    def admissible(self, m, p, ctx, tau) -> bool:
        j = self.J.get((m, p))
        if j is None or ctx not in j.contexts: return False
        if tau.expired(): return False
        return not self.arb.forbids(m, p, ctx)
    def positioning_gap(self, required: Set[Tuple[str, str]], ctx) -> float:
        # 任一必需命题无任何可采纳见证 => 缺口
        for p in required:
            if not any(self.admissible(m, p, ctx, t) for (m, pp, t) in self.witnesses(p)):
                return 1.0
        return 0.0

# IP-296 DST：对话状态跟踪（计量域，异步；不阻塞控制域）
class DialogueStateTracker:
    def update(self, act, obs, b_prev):
        # 1) 意图 z：只接受有 intent 管辖权的证据（定义 378）
        z = self.positioned_update(b_prev.z, obs, domain='intent')
        # 2) 接地 G：指代/命题/确认/示范
        G = self.grounding.update(act, obs)
        # 3) 修复栈 R：未理解/矛盾/指代失败
        R = self.repair.update(act, G, self.ledger)
        # 4) 承诺账本 C：只更新账本，不直接执行
        C = self.ledger.step(act, G, self.role)
        # 5) 角色/话轮/未决 warrant
        kappa, iota, Q = self.role_turn.update(act, C, R)
        return DialogueState(z=z, G=G, C=C, Q=Q, R=R, iota=iota, kappa=kappa)

# IP-297 CML：承诺账本（只承诺有证书的动作）
class CommitmentLedger:
    def commit(self, action, cert, grounding_refs, role, deadline):
        if not cert.valid_now(): return Reject('no_cert')
        if not all(self.G[r] >= TAU_G for r in grounding_refs): return Reject('ungrounded')
        if not role.permits_commit(action): return Reject('role')
        c = Commitment(action, cert.ref, grounding_refs, deadline, status='active')
        if self.contradicts(c): return Reject('inconsistent')
        self.add(c); return c
    def revalidate(self, c):
        if c.cert.expired() or self.G.any_below(c.grounding_refs, TAU_G):
            c.status = 'suspended'          # 不执行、不删除，进入重谈
            return Suspended(c)
        return Ok(c)
    def retract(self, c, reason):
        if c.status in ('active', 'suspended'): c.status = 'retracted'
        self.log_retraction(c, reason)      # 撤回是显式社交行为

# IP-298 GRM：接地与修复
class GroundingRepairManager:
    def update(self, act, obs):
        for r in extract_referents(act): self.gamma[r] = self.estimate_gamma(r, obs)
        for p in extract_props(act):     self.grounded[p] = self.estimate_grounded(p, obs)
    def needs_repair(self, D):
        return (any(g < TAU_G for g in D.G.values())
                or D.R.nonempty() or D.ledger.has_stale_cert())

# IP-299 DPP：对话策略（LLM 只提议，不授权）
class DialoguePolicy:
    def choose(self, D, Pi, budget, llm):
        candidates = llm.propose(D, top_k=8) + self.templates(D)
        best = None
        for a in candidates:
            if not self.precondition_ok(a, D, Pi): continue
            if a.type == 'ask_warrant' and not Pi.has_authorized_source(a.scope): continue
            voi = self.voi_d(a, D, Pi, budget)
            if best is None or voi > best.voi: best = (a, voi)
        if best is None or best.voi <= 0:
            return self.safe_fallback(D)    # defer / handover / safe_hold
        return best.a
    def voi_d(self, a, D, Pi, budget):
        ig_z   = ETA_Z * expected_intent_ig(D, a)
        ig_g   = ETA_G * expected_grounding_ig(D, a)
        d_uc   = ETA_C * expected_commitment_value(D, a)
        d_gap  = ETA_W * expected_gap_reduction(D, a, Pi)   # 关键新项
        cost   = budget.cost(a) + reflex_cost(D, a) + social_risk(D, a)
        return ig_z + ig_g + d_uc + d_gap - cost

# IP-300 SPM：人类信源定位（域特定的权威，不是全局信任）
class SourcePositioningModel:
    def update(self, source, domain, observation):
        # alpha(s,d)：该信源在该域的权威后验
        self.alpha[source][domain] = bayes_update(
            self.alpha[source][domain], observation, self.reliability[source])
    def may_update(self, source, domain):
        return self.alpha[source][domain] > TAU_ALPHA
    def positioned_likelihood(self, source, domain, y, x):
        return self.likelihood[source][domain](y, x) if self.may_update(source, domain) else 0.0

# IP-301 NC-RISK：非补偿向量风险（控制域只读）
def noncomp_risk_scale(r_vec, envelope, params):
    # 先做逐坐标可行性检查；任一越界或定位缺口 => 安全保持
    if any(r_vec[i] > envelope[i] for i in range(len(r_vec))): return SAFE_HOLD
    if r_vec.pos > 0: return SAFE_HOLD
    # 阻抗增益逐坐标收紧，不做标量求和
    K = params.K_max
    for i, r in enumerate(r_vec):
        K = componentwise_min(K, params.K_of_r[i](r))
    return K

# IP-303 PD 主闭环：把 R72 的三域分离扩展为四域（多一个对话域）
def PD_GAUGE_RAS_round(M, obs, audio, tac_frame, human_utt):
    # === 控制域 (1kHz, 硬实时) ===
    snap = M.snapshot.read_latest()
    b_t  = M.bse.step_ctrl(snap.b_prev, obs, M.last_action, M.last_g, M.last_y)
    r_vec = M.nc_risk.vector(b_t, snap.z_dist, snap.tac_ev, snap.pos_gap)
    K = noncomp_risk_scale(r_vec, M.envelope, M.risk_params)   # 可能 SAFE_HOLD
    A = M.ach.propose_ctrl(...); k = M.c_ras_wm.certified_prefix(A, K, ...)
    M.ctrl_out.publish(k, K)
    M.last_action = A[:k]

    # === 计量域 (50Hz, 软实时) ===
    if M.clock.due_metric():
        b_t_full = M.bse.step_full(M.b_prev, obs, M.last_action, M.last_g, M.last_y)
        D = M.dst.update(M.pending_act, extract_obs(obs, audio, human_utt), b_t_full)
        z_dist = D.z
        gap = M.Pi.positioning_gap(required_props(D, b_t_full), context(D))

        for c in M.ledger.active():
            if not M.ledger.revalidate(c).ok: M.grm.trigger_repair(c)
        M.snapshot.write(b_t_full, z_dist, gap, M.psi_hat, M.tac_ev)

    # === 感知域 (Best-effort, 异步) ===
    psi_hat, ece_aff = M.aura.update(audio)
    tac_ev = M.dmem.update(tac_frame, M.last_action)
    M.spm.update('human', 'intent', human_utt)       # 人的意图权威
    M.spm.update('robot_tac', 'contact', tac_ev)     # 触觉的接触权威

    # === 对话域 (异步 5-20Hz, 不阻塞控制域) ===
    M.dst.ingest(human_utt)
    if M.dpp.should_act(D, M.budget):
        a = M.dpp.choose(D, M.Pi, M.budget, M.llm)  # LLM 只提议
        M.dlg.emit(a)                                # 发出前经定位可采纳检查
        M.budget.spend(a)
        if a.type in ('defer', 'handover'):
            M.mode = 'SAFE_HANDOVER'
    return k, K, make_J_PD(M)

## 3. 推导

**引理 33（定位可靠性 ⇒ 无范畴错误）** 在定义 370 下，若不变式 (i) 成立，则任何影响动作的命题 p 都有 p ∈ J(m) 的可采纳见证；定义 378 的 w_{m,i}=0 使无管辖权模块无法向变量 x_i 注入似然。因此 R72 中「触觉更新意图」「语言更新接触」这类错误不是被缓解，而是**不可表达**。系：R72 识别了接触/世界状态混淆的风险，R73 用类型系统把它变成编译期/部署期错误。

**引理 34（非补偿 ⇒ 逐坐标单调）** 可采纳集 A_adm = {a : ∀i r_i(a) ≤ ε_i, g_pos=0}。固定其他坐标，任一 r_i 增大只会使 A_adm 单调收缩；另一坐标 r_j 减小不能使一个 r_i > ε_i 的动作重新可采纳。证明：A_adm 是逐坐标约束的合取。系：**标量求和不是非补偿的**；R72 的 `U_ale+U_epi+H_z+u_tac` 存在隐蔽汇率。

**引理 35（接地 + 承诺一致 ⇒ 无未接地执行）** 在定义 372、373 与不变式 (iii)(iv) 下，任何被执行的承诺在承诺时与执行时都满足 γ ≥ τ_g 且证书未过期；违反时状态转为 suspended，而非继续执行。证明：commit 与 revalidate 两道检查；suspended 不在执行集合。系：**「先答应再发现指代错了」在 PD 中是不可执行的路径。**

**引理 36（对话预算 ⇒ 有限追问）** 每个对话行为有正成本 c_dial ≥ ε > 0，总预算 B_dial 有限，故任何策略至多执行 ⌊B_dial/ε⌋ 个行为；若边际信息/接地增益随轮次非增，则存在有限 n* 使 VoI^D ≤ 0，策略在 n* 停止或转入 defer/handover。证明：预算单调消耗 + 边际收益非增。系：**「一直问到明白为止」在设计上被排除。**

**引理 37（warrant 完备 ⇒ 定位缺口只能被授权信源闭合）** g_pos 只能通过来自域 d 上 α(s,d) > τ_α 的 ask_warrant 响应降低；域外证据的似然权重为 0（定义 378），因此不能降低 g_pos。证明：g_pos 的定义要求 Adm(p,x)，而 Adm 需要 p ∈ J(m) 的见证；无管辖权证据不产生见证。系：**再多视觉也补不上意图管辖权的缺失；再准的触觉也不能替人决定他想要什么。**

**引理 38（角色有界 ⇒ 无安全升级）** 角色转移只改变 A(κ) 中的主动权/社会行为集合，不改变 J 与安全包络；且 A(κ) 不含安全权威覆盖。因此任何角色（包括 delegated-supervisor）都不能授权越权断言或否决安全 veto。证明：定义 375 的 A(κ) 约束 + 定义 369 的 J 固定。系：**「我现在是监督者了，所以我可以忽略滑移」是非法推理。**

**定理 27（严格包含与安全单调）** 在 A111–A116（定位图可靠、信源权威可校准、接地有效、承诺一致、预算有限、角色有界）下：PD-GAUGE-RAS 在退化条件下逐指令等于 R72/R71/R68（定义 381）；且对任意有效执行，其可采纳动作集 ⊆ R72 在相同证据下的可采纳动作集，安全包络单调不减。**效率收益只在「定位有效、对话可负担、承诺可兑现」时出现。**

**定理 28（不可洗白：流利不增加有效性）** J_PD 的合法性只依赖见证元组 (pos_map, grounding_proof, cert_refs, ledger, source_pos)，不依赖对话的表面措辞、语气或流畅度。若两场对话共享同一见证元组，则 J_PD 相同。证明：J_PD 是见证元组的函数，文本不是输入。系：**社会工程/提示注入只能通过产生新的可采纳见证来改变状态；而「产生新见证」正是应当被信任机制约束的事情。** 流利但无效的叙述不能把越权判断洗成合法承诺。

**定理 29（承诺安全）** 若 J_PD 有效且每次执行前重新验证证书新鲜度与接地，则不存在「证书过期后仍被执行」的承诺；过期只会导致 suspended + repair，不导致 violated。证明：账本不变式 + 执行期 revalidate + suspended 不在执行集合。**承诺的安全性不靠记性，靠每次执行前的复算。**

**定理 30（有限对话的三种结局）** 在有限社会预算与正成本下，对话必然终止；终止时只可能：(i) 存在可采纳动作并执行；(ii) g_pos > 0 或所有 VoI^D ≤ 0，进入 safe hold / defer / handover；(iii) 预算耗尽，进入 defer/handover。**系统不能靠无限提问逃避决策；它只能执行、移交或安全停住。**

**定理 31（定位化更新的保守性）** 若某变量 x_i 没有任何被授权似然，则定位化更新保持 x_i 先验不变；因此其熵不被人为降低，依赖它的决策要么因 g_pos 被否决，要么以先验不确定度进入风险向量。证明：定义 378 中 w_{m,i}=0 对所有 m 成立 ⇒ 更新为空。系：**「没有证据」不会被伪装成「低不确定度」；这是对 R72 过度自信的结构性修复。**

## 6. 本轮最大风险

**一句话**：PD-GAUGE-RAS 把安全从「相信计量证书」进一步转移到「相信 **定位图本身是对的**、相信 **承诺账本没有被对话本身污染**、相信 **人类信源矩阵在分布外仍然可校准**」——**如果定位图把某个模块的管辖权标错（例如让意图分类器“认证”接触安全，或让触觉“确认”人类偏好），系统就会用流利的对话、接地的指代和盖章的 J_PD，把越权判断包装成合法承诺；如果对话策略学会了用「这是你上次说的」来伪造 warrant，或用「你不确认我就不能保证安全」来操纵人类，那么承诺账本会变成社会工程的记账本；如果人类在跨文化语境中把「拒绝」理解为「不信任」、把「移交」理解为「无能」，那么定位层越严谨，系统越像一个礼貌而自信地推卸责任的官僚——事后审计会发现每句话都在管辖域内、每个承诺都有证书，但系统已经**自信地错掉了自己的职权边界**。**

次级风险与缓解：
1. **定位图静态而能力漂移** → 在线定位监控：按域追踪 ECE、OOD、滑移检出率，偏离定位包络即自动收窄 J(m) 并触发重认证。
2. **定位图被投毒/捕获** → 定位图哈希上链 + 多方签名；J(m) 变更需离线审计 + 双人复核；运行时只读。
3. **承诺账本被对话污染** → 承诺只接受证书引用与接地见证，不接受自然语言「你说过」作为证据；账本写入需签名与复算。
4. **社会工程/权威冒充** → 来源定位 + 域特定权威 + 二次确认；高风险域要求多源独立 warrant。
5. **对话策略操纵人类** → 禁止以「不确认就不安全」进行胁迫；拒绝/移交话术需经伦理审查；设置提问频率与情绪影响上限。
6. **过度拒绝/学习性无助** → 把 defer/handover 当一等动作但设上限；用 E389/E390 监控「该做而未做」的任务完成率。
7. **LLM 幻觉/提示注入** → LLM 只提议、不授权；所有行为过可采纳检查；证书与见证不走 LLM。
8. **复杂度爆炸** → 定位图模块 ≤16、命题类型 ≤32、承诺数 ≤64、对话行为 ≤16；每个 veto 一条可复算证明。

**一句话收束**：最大的风险不是系统不会对话，而是系统太会对话——**它可能用完美的定位话术，掩盖定位图本身的错误。**

# 第 73 轮产物 · 创新点清单 v4：POSITIONED-DIALOGUE-GAUGE-RAS（PD-GAUGE-RAS，定位对话式具身计量审计）

> 承接第 72 轮 IP-287~294（EMBODIED-GAUGE-RAS）。R72 完成了具身计量审计：REG 实时执行图、IRL 意图隐变量、DMEM 接触四分量、EREFLEX 三层反作用、S2R-UQ 桥接、三域分离，把「计量不阻塞控制」从逻辑承诺升级为调度定理。但 R72 仍是「单轮、无管辖、可补偿」的：
> - **对话管理缺失**：R72 的澄清是一次 `execute(g)` 取数，没有多轮状态、共同基础、承诺账本、修复栈、话轮/主动权、角色契约、社会预算；「问什么」之外没有「以什么身份问、问完承诺什么、答不上来如何修复」。
> - **差异化定位缺失**：R72 的 λ = f(U_ale + U_epi + H_z + u_tac) 仍是标量求和，隐含「1 单位接触不确定度 = 1 单位意图不确定度」的汇率；这与它自己主张的非补偿否决矛盾。模块也没有显式管辖权，触觉可以更新意图、语言可以更新接触，范畴错误无法被类型系统拦截。
> - **承诺缺失**：R72 的规划是承诺盲的；「我帮你拿」不是一次动作，而是带受益人、截止时间、前置条件、证书引用与撤回策略的债。证书过期后静默执行承诺，是 R72 未覆盖的安全洞。
>
> 本轮两个灵感补齐：
> - **对话管理**：把单步查询升级为**带承诺与接地的多轮对话策略**（DST + CML + GRM + DPP + 角色契约 + 社会预算）。澄清的本质是 `ask_warrant`：向有管辖权的信源请求授权/证据。
> - **差异化定位**：把「同权求和」升级为**分权式管辖图**（DPM + SPM + 定位化贝叶斯更新 + 非补偿向量风险）。每个模块/信源在「认识权威 × 物理权威 × 时间尺度 × 分布范围 × 面向人的权威」上有自己的位置；越权断言是类型错误，不能用其他维度的强证据补偿。
>
> 核心命题：**从「我的测量链能否兑现风险界」进化为「我的系统是否知道自己被授权断言什么，并能在多轮对话中守住职权边界，而不让语言的流利替代测量的有效？」** 一句话：**先定位，再对话；先分权，再融合；先承诺，再行动。**

## 2. 形式化定义（要点版）

**定义 366（PD-GAUGE-RAS 总览与六不变式）** 定位可靠性、管辖非补偿、接地先于承诺、承诺-证书一致、角色有界、严格逐指令退化。**安全侧只增不减。**

**定义 367（对话状态）** b_t(D)=(z,G,C,Q,R,ι,κ,h,σ)；DST 维护其后验；与物理后验通过带类型接口耦合，而非任意联合更新。

**定义 368（对话行为与前后置条件）** 每个行为 a=(type,content,target,warrant_scope,positioning_witness)，带 pre(a,D)、T_d(a,D)、c_dial(a)。**`ask_warrant(d,s)` 是 R73 的新原语：向信源 s 请求其在域 d 上的授权/证据，用于闭合 g_pos。**

**定义 369（差异化定位图 DPM）** Π=(M,S,X,J,⊑,Arb)。X = 认识权威/物理权威/时间尺度/分布范围/面向人的权威；J(m) 为管辖域；⊑ 为不可数值平均的偏序；Arb 为重叠仲裁。**定位图不是权重表，是管辖图。**

**定义 370（可采纳见证）** Adm(p,x) ⇔ p∈J(m) ∧ x∈Env_m ∧ τ 新鲜 ∧ 无更高优先级 Arb 禁止 ∧（跨域则联合见证完整）。**任何决策只能使用 Adm(p,x) 为真的命题。**

**定义 371（定位缺口与非补偿向量风险）** g_pos(P_t)=0 若所有必需命题有可采纳见证，否则为缺口。r_t=(r_phys,r_intent,r_contact,r_pos,r_dial)；可采纳 ⇔ ∀i r_i≤ε_i ∧ g_pos=0。控制增益逐坐标收紧：K_ij ≤ min_i K_ij^max(r_i)；**没有支配证明的标量化视为补偿作弊。**

**定义 372（承诺账本）** 承诺条目 c 含受益人/截止/前置/证书/接地引用/撤回策略；status ∈ {proposed,active,suspended,fulfilled,retracted,violated}。可承诺 ⇔ 证书有效 ∧ 前置成立 ∧ 接地达标 ∧ 角色允许。**证书过期 → suspended + 重谈，绝不静默执行。**

**定义 373（接地与修复）** γ(r) 由确认/指认/示范/复述更新；动作要求 γ≥τ_g；触发修复：未理解/指代失败/矛盾/证书过期/角色不匹配；受影响承诺 suspend（不删除）。**未接地不行动；接地失效则停承诺。**

**定义 374（对话策略与对话 VoI）** 约束 POMDP：max E[Σ γ^t(U_task+η_z IG_z+η_G IG_G+η_C ΔU_commit−c_dial−c_reflex−c_pos)]，s.t. 定位/承诺/接地/预算/角色/非补偿。**Δg_pos 项是核心：闭合定位缺口的 warrant 价值不可被同域信息替代。** 无正 VoI ⇒ defer/handover/safe hold。

**定义 375（角色契约）** κ 决定主动权/允许行为/解释义务/拒绝权，但 **A(κ) 不含安全权威覆盖**；角色转移需 negotiate_role+acknowledge 并记账；D_role 为审计指标。**角色只改主动权，不改管辖权。**

**定义 376（社会/对话预算）** B_dial=(B_attn,B_trust,B_interrupt,B_privacy)；累计 ≤ B；耗尽 → defer/handover 或最多一次高价值 warrant；**绝不无限追问。**

**定义 377（人类信源定位 SPM）** α(s,d) 后验；仅 α>τ_α 可直接更新域 d。人类对自身意图高权威、对接触力学低权威；触觉对接触高权威、对意图零权威；视觉对物体类别/位姿中高、对滑移低。**人不是命令源，人是有定位的证据源；跨域服从必须换取 warrant。**

**定义 378（定位化贝叶斯更新）** b_{t+1}(x_i) ∝ b_t(x_i) · ∏_{m∈M_i} L_m(y_m|x_i)^{w_{m,i}}，w_{m,i}=0 若无管辖权；跨域耦合只经显式结构模型；无授权似然时变量保持先验，g_pos 置位。**这是防范畴错误的类型系统。**

**定义 379（对话-定位证书 J_PD）** J_PD=(J_EMB,pos_map_hash,policy_hash,ledger_hash,grounding_proof,role_contract_hash,budget_proof,noncomp_proof,source_pos_hash,dlg_ver)。Valid ⇔ 全链一致。**证书不是给独白盖章，是给对话的管辖权盖章。**

**定义 380（威胁模型 AIC-DIAL）** ℰ_DIAL = ℰ_EMB ∪ {社会工程、权威冒充、紧迫操纵、指代劫持、承诺陷阱、角色升级、接地投毒、warrant 伪造、对话洪泛、流利但无效叙述、跨文化立场错配}。**新增攻击面：用正确话术把越权判断包装成合法承诺。**

**定义 381（严格退化链）** 完整 PD ⇒ 无多轮（R72 单步）⇒ 无定位图（R72 相等求和）⇒ 无承诺（只可逆 probe）⇒ R71 ⇒ R68。安全单调不减，保留 R68 包络与非补偿否决。

**定义 382（差异化审计 / 反 Goodhart）** 每模块 m 有域内指标 μ_m 与定位消融测试：只有替换 m 改变 μ_m（而非仅聚合分）才认证贡献；跨域领功禁止；J_PD 附「贡献定位表」。**差异化不是营销口号，是归因纪律。**

# IP-295 DPM：差异化定位图（部署期构建/验证，运行时只读）
@dataclass
class Jurisdiction:
    module: str
    prop_types: Set[str]          # 可断言命题类型
    contexts: Set[str]            # 有效语境/分布
    authority: Dict[str, float]   # 认识/物理/时间/分布/面向人的权威
    ttl_ms: float                 # 见证有效期
    arb_priority: int             # 重叠仲裁优先级

class PositioningMap:
    def __init__(self, jurisdictions, arbitration_rules):
        self.J = {(j.module, p): j for j in jurisdictions for p in j.prop_types}
        self.arb = arbitration_rules
        self.witnesses = defaultdict(list)
    def admissible(self, m, p, ctx, tau) -> bool:
        j = self.J.get((m, p))
        if j is None or ctx not in j.contexts: return False
        if tau.expired(): return False
        return not self.arb.forbids(m, p, ctx, tau)
    def positioning_gap(self, required, ctx) -> float:
        for p in required:
            if not any(self.admissible(m, pp, ctx, t)
                       for (m, pp, t) in self.witnesses[p] if pp == p):
                return 1.0
        return 0.0
    def verify_static(self):
        # 1) 覆盖：每个必需命题至少一个授权模块
        # 2) 无未仲裁重叠：J(m1)∩J(m2)≠∅ ⇒ Arb 有序
        # 3) 无环仲裁、无自授权、无跨域委派（不能授予自己没有的权威）
        return self.coverage_ok() and self.overlap_ok() and self.arb_acyclic()

# IP-296 DST：对话状态跟踪（计量域，异步；不阻塞控制域）
class DialogueStateTracker:
    def update(self, act, obs, b_prev, Pi, spm):
        # 1) 意图 z：只接受有 intent 管辖权的证据（定义 378）
        z = self.positioned_update(b_prev.z, obs, domain='intent', Pi=Pi, spm=spm)
        # 2) 接地 G：指代/命题/确认/示范
        G = self.grounding.update(act, obs)
        # 3) 修复栈 R：未理解/矛盾/指代失败/证书过期
        R = self.repair.update(act, G, self.ledger)
        # 4) 承诺账本 C：只更新账本，不直接执行
        C = self.ledger.step(act, G, self.role)
        # 5) 角色/话轮/未决 warrant
        kappa, iota, Q = self.role_turn.update(act, C, R)
        return DialogueState(z=z, G=G, C=C, Q=Q, R=R, iota=iota, kappa=kappa)

# IP-297 CML：承诺账本（只承诺有证书的动作）
class CommitmentLedger:
    def commit(self, action, cert, grounding_refs, role, deadline):
        if not cert.valid_now(): return Reject('no_cert')
        if not all(self.G[r] >= TAU_G for r in grounding_refs): return Reject('ungrounded')
        if not role.permits_commit(action): return Reject('role')
        c = Commitment(action, cert.ref, grounding_refs, deadline, status='active')
        if self.contradicts(c): return Reject('inconsistent')
        if not self.feasible_under_REG(c): return Reject('infeasible_deadline')
        self.add(c); return c
    def revalidate(self, c):
        if c.cert.expired() or self.G.any_below(c.grounding_refs, TAU_G):
            c.status = 'suspended'          # 不执行、不删除，进入重谈
            return Suspended(c)
        return Ok(c)
    def retract(self, c, reason):
        if c.status in ('active', 'suspended'): c.status = 'retracted'
        self.log_retraction(c, reason)      # 撤回是显式社交行为

# IP-298 GRM：接地与修复
class GroundingRepairManager:
    def update(self, act, obs):
        for r in extract_referents(act): self.gamma[r] = self.estimate_gamma(r, obs)
        for p in extract_props(act):     self.grounded[p] = self.estimate_grounded(p, obs)
    def needs_repair(self, D):
        return (any(g < TAU_G for g in D.G.values())
                or D.R.nonempty() or D.ledger.has_stale_cert())
    def trigger_repair(self, c_or_r):
        self.repair.push(RepairItem(target=c_or_r, reason=detect_reason(c_or_r)))
        self.ledger.suspend_dependent(c_or_r)     # 受影响承诺挂起

# IP-299 DPP：对话策略（LLM 只提议，不授权）
class DialoguePolicy:
    def choose(self, D, Pi, budget, llm):
        candidates = llm.propose(D, top_k=8) + self.templates(D)
        best = None
        for a in candidates:
            if not self.precondition_ok(a, D, Pi): continue
            if a.type == 'ask_warrant' and not Pi.has_authorized_source(a.scope): continue
            voi = self.voi_d(a, D, Pi, budget)
            if best is None or voi > best.voi: best = (a, voi)
        if best is None or best.voi <= 0:
            return self.safe_fallback(D)    # defer / handover / safe_hold
        return best.a
    def voi_d(self, a, D, Pi, budget):
        ig_z   = ETA_Z * expected_intent_ig(D, a)
        ig_g   = ETA_G * expected_grounding_ig(D, a)
        d_uc   = ETA_C * expected_commitment_value(D, a)
        d_gap  = ETA_W * expected_gap_reduction(D, a, Pi)   # 关键新项
        cost   = budget.cost(a) + reflex_cost(D, a) + social_risk(D, a)
        return ig_z + ig_g + d_uc + d_gap - cost

# IP-300 SPM：人类信源定位（域特定权威，不是全局信任）
class SourcePositioningModel:
    def update(self, source, domain, observation):
        self.alpha[source][domain] = bayes_update(
            self.alpha[source][domain], observation, self.reliability[source])
    def may_update(self, source, domain):
        return self.alpha[source][domain] > TAU_ALPHA
    def positioned_likelihood(self, source, domain, y, x):
        return self.likelihood[source][domain](y, x) if self.may_update(source, domain) else 0.0

# IP-301 NC-RISK：非补偿向量风险（控制域只读）
def noncomp_risk_scale(r_vec, envelope, params):
    # 逐坐标可行性；任一越界或定位缺口 => 安全保持
    if any(r_vec[i] > envelope[i] for i in range(len(r_vec))): return SAFE_HOLD
    if r_vec.pos > 0: return SAFE_HOLD
    # 阻抗增益逐坐标收紧，不做标量求和
    K = params.K_max
    for i, r in enumerate(r_vec):
        K = componentwise_min(K, params.K_of_r[i](r))
    return K

# IP-303 PD 主闭环：R72 三域 + 对话域
def PD_GAUGE_RAS_round(M, obs, audio, tac_frame, human_utt):
    # === 控制域 (1kHz, 硬实时) ===
    snap = M.snapshot.read_latest()
    b_t  = M.bse.step_ctrl(snap.b_prev, obs, M.last_action, M.last_g, M.last_y)
    r_vec = M.nc_risk.vector(b_t, snap.z_dist, snap.tac_ev, snap.pos_gap)
    K = noncomp_risk_scale(r_vec, M.envelope, M.risk_params)   # 可能 SAFE_HOLD
    A = M.ach.propose_ctrl(...); k = M.c_ras_wm.certified_prefix(A, K, ...)
    M.ctrl_out.publish(k, K)
    M.last_action = A[:k]

    # === 计量域 (50Hz, 软实时) ===
    if M.clock.due_metric():
        b_t_full = M.bse.step_full(M.b_prev, obs, M.last_action, M.last_g, M.last_y)
        D = M.dst.update(M.pending_act, extract_obs(obs, audio, human_utt), b_t_full, M.Pi, M.spm)
        z_dist = D.z
        gap = M.Pi.positioning_gap(required_props(D, b_t_full), context(D))
        M.nc_risk.set_pos_gap(gap)
        for c in M.ledger.active():
            if not M.ledger.revalidate(c).ok: M.grm.trigger_repair(c)
        M.snapshot.write(b_t_full, z_dist, gap, M.psi_hat, M.tac_ev)

    # === 感知域 (Best-effort, 异步) ===
    psi_hat, ece_aff = M.aura.update(audio)
    tac_ev = M.dmem.update(tac_frame, M.last_action)
    M.spm.update('human', 'intent', human_utt)       # 人的意图权威
    M.spm.update('robot_tac', 'contact', tac_ev)     # 触觉的接触权威

    # === 对话域 (5-20Hz, 不阻塞控制域) ===
    M.dst.ingest(human_utt)
    if M.dpp.should_act(D, M.budget):
        a = M.dpp.choose(D, M.Pi, M.budget, M.llm)  # LLM 只提议
        if not M.Pi.admissible_act(a, D): a = M.dpp.safe_fallback(D)
        M.dlg.emit(a)
        M.budget.spend(a)
        if a.type in ('defer', 'handover'):
            M.mode = 'SAFE_HANDOVER'
    return k, K, make_J_PD(M)

## 4. 推导

**引理 33（定位可靠性 ⇒ 无范畴错误）** 定义 370 的 Adm 要求 p∈J(m)；定义 378 的 w_{m,i}=0 阻断无管辖权似然注入。故触觉更新意图、语言更新接触这类错误**不可表达**。系：R72 识别了接触/世界状态混淆风险，R73 用类型系统把它变成部署期错误。

**引理 34（非补偿 ⇒ 逐坐标单调）** A_adm={a:∀i r_i(a)≤ε_i, g_pos=0} 是逐坐标约束的合取；任一 r_i 增大只使 A_adm 收缩，另一坐标减小不能重新放行 r_i>ε_i 的动作。系：**标量求和不是非补偿的**；R72 的求和存在隐蔽汇率。

**引理 35（接地+承诺一致 ⇒ 无未接地执行）** commit 与 revalidate 双检查；违反即 suspended，不在执行集合。系：**「先答应再发现指代错了」在 PD 中不可执行。**

**引理 36（对话预算 ⇒ 有限追问）** c_dial≥ε>0、B_dial 有限 ⇒ 至多 ⌊B_dial/ε⌋ 个行为；边际增益非增 ⇒ 存在有限 n* 使 VoI^D≤0，策略停止或转 defer/handover。系：**「一直问到明白为止」被设计排除。**

**引理 37（warrant 完备 ⇒ 定位缺口只能被授权信源闭合）** g_pos 只能通过域 d 上 α(s,d)>τ_α 的 ask_warrant 响应降低；域外证据 w=0，不产生见证。系：**再多视觉也补不上意图管辖权缺失；再准的触觉也不能替人决定他想要什么。**

**引理 38（角色有界 ⇒ 无安全升级）** 角色转移只改 A(κ) 中的主动权/社会行为，不改 J 与安全包络；A(κ) 不含安全权威覆盖。系：**「我现在是监督者，所以可以忽略滑移」是非法推理。**

**定理 27（严格包含与安全单调）** 在 A111–A116（定位图可靠、信源权威可校准、接地有效、承诺一致、预算有限、角色有界）下，PD 在退化条件下逐指令等于 R72/R71/R68；对任意有效执行，可采纳动作集 ⊆ R72 同证据下可采纳集，安全包络单调不减。**效率收益只在「定位有效、对话可负担、承诺可兑现」时出现。**

**定理 28（不可洗白：流利不增加有效性）** J_PD 只依赖见证元组，不依赖措辞/语气/流畅度；两场对话共享见证元组则 J_PD 相同。系：**社会工程/提示注入只能通过产生新的可采纳见证改变状态；而「产生新见证」正是应被信任机制约束的事情。** 流利但无效的叙述不能把越权判断洗成合法承诺。

**定理 29（承诺安全）** J_PD 有效 + 每次执行前 revalidate ⇒ 不存在证书过期后仍被执行的承诺；过期只导致 suspended+repair，不导致 violated。**承诺安全不靠记性，靠执行前复算。**

**定理 30（有限对话的三种结局）** 有限预算 + 正成本 ⇒ 对话终止，且只可能：(i) 执行可采纳动作；(ii) g_pos>0 或所有 VoI^D≤0 ⇒ safe hold/defer/handover；(iii) 预算耗尽 ⇒ defer/handover。**系统不能靠无限提问逃避决策。**

**定理 31（定位化更新的保守性）** 若变量 x_i 无任何授权似然，定位化更新保持先验不变；熵不被人为降低，依赖它的决策要么因 g_pos 被否决，要么以先验不确定度进入风险向量。系：**「没有证据」不会被伪装成「低不确定度」，这是对 R72 过度自信的结构性修复。**

## 8. 本轮最大风险

**一句话**：PD-GAUGE-RAS 把安全从「相信计量证书」进一步转移到「相信 **定位图本身是对的**、相信 **承诺账本没有被对话本身污染**、相信 **人类信源矩阵在分布外仍然可校准**」——**如果定位图把某个模块的管辖权标错（例如让意图分类器“认证”接触安全，或让触觉“确认”人类偏好），系统就会用流利的对话、接地的指代和盖章的 J_PD，把越权判断包装成合法承诺；如果对话策略学会了用「这是你上次说的」伪造 warrant，或用「你不确认我就不能保证安全」操纵人类，承诺账本就会变成社会工程的记账本；如果人类在跨文化语境中把「拒绝」理解为「不信任」、把「移交」理解为「无能」，那么定位层越严谨，系统越像一个礼貌而自信地推卸责任的官僚——事后审计会发现每句话都在管辖域内、每个承诺都有证书，但系统已经**自信地错掉了自己的职权边界**。**

次级风险与缓解：
1. **定位图静态而能力漂移** → 在线定位监控：按域追踪 ECE/OOD/滑移检出率，偏离包络即收窄 J(m) 并重认证。
2. **定位图被投毒/捕获** → 哈希上链 + 多方签名；J(m) 变更离线审计 + 双人复核；运行时只读。
3. **承诺账本被对话污染** → 承诺只接受证书引用与接地见证，不接受「你说过」作为证据；写入需签名与复算。
4. **社会工程/权威冒充** → 来源定位 + 域特定权威 + 二次确认；高风险域要求多源独立 warrant。
5. **对话策略操纵人类** → 禁止以「不确认就不安全」胁迫；拒绝/移交话术过伦理审查；设提问频率与情绪影响上限。
6. **过度拒绝/学习性无助** → defer/handover 设上限；用 E389/E390 监控「该做而未做」的任务完成率。
7. **LLM 幻觉/提示注入** → LLM 只提议、不授权；所有行为过可采纳检查；证书与见证不走 LLM。
8. **复杂度爆炸** → 模块≤16、命题类型≤32、承诺≤64、对话行为≤16；每个 veto 一条可复算证明。

**一句话收束**：最大的风险不是系统不会对话，而是系统太会对话——**它可能用完美的定位话术，掩盖定位图本身的错误。**
