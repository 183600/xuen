# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 1 轮；本轮灵感：「惯性测量单元」×「跨任务泛化」）

> 第 60 轮 SGEC 把「场景」从物理障碍升级为可预测的阻抗先验 π_scene(K|z)，用 SSM×CIEC×EPIR×SERC 实现了「场景先验提前收敛 K_safe、意图即时锁定约束、证据链防消息丢失」。但它留下**两个结构性隐患**：
> 1. **场景先验是「接触后、低频、外部感知」的**：SSM 靠力/位移遥测更新 π_scene，而这些信号在接触发生后才出现，控制频率又远低于接触瞬态；最有信息量的冲击、共振、微滑移恰好发生在接触起始的 1~5 ms 内，被低通链路抹平。对浮动基/足式机器人，基座运动还会污染腕部力信号。IMU 高频、低成本、全平台普及，却几乎是闲置的——更糟的是，IMU 直接二次积分会漂移，不能拿来算位置或形变，必须换一种**不积分**的用法。
> 2. **场景查表先验无法跨任务泛化**：π_scene(K|z) 是「场景类别→阻抗」的查表，换一个新物体、新表面、新负载就要重新标定；第 60 轮的 SIC 只度量「场景置信度」，不度量「当前任务是否落在先验覆盖范围内」。一旦任务迁移，先验可能**自信地错**，即负迁移（negative transfer）。跨任务泛化需要的不是更多类别，而是一个**对任务语义不变、对接触物理敏感**的共享潜空间，以及一张可校准的迁移证书。

## 0. 直觉与动机

**灵感 1（惯性测量单元 → 惯性接触观测器 ICO）**
直觉：IMU 是装在机器人身上的「高频听诊器」。接触发生的瞬间，冲击瞬态、共振频率、阻尼衰减、切向微振最先在 IMU 上留下指纹；腕部力传感器反而常被低通滤波、机械柔顺和基座运动污染。关键不是用 IMU 积分出位置（会漂），而是把 IMU 当作**动量观测器的代数输入 + 接触瞬态的频谱探针**：用广义动量残差估外力和接触时刻，用高通频谱估接触刚度、阻尼与滑移。这样既绕开积分漂移，又获得比力/位移高一个数量级的时间分辨率。

**灵感 2（从「场景标签」到「接触物理」→ 惯性阻抗先验 IKP）**
直觉：同一张「桌面」上，陶瓷杯沿、桌布褶皱、金属托盘边缘的阻抗可能相差一个数量级；同一个「楼梯」在不同负载、不同速度下也不一样。场景标签不是物理量，接触响应才是。IMU 签名可以直接反演物理初值：共振频率 f_res 与有效质量 m_eff 满足 K_p ≈ m_eff(2πf_res)²，冲激衰减率给出阻尼比 ζ，切向微振/滑移给出摩擦窗。物理公式给可解释的先验，学习残差给校准。**先验从「场景查表」变成「接触物理反演」**。

**灵感 3（跨任务泛化 → 任务不变阻抗潜空间 TIIL）**
直觉：跨任务泛化的关键不是记住更多任务，而是找到任务之间真正共享的东西。擦桌、开抽屉、插拔、上下楼梯在语义上天差地别，但接触响应的物理规律共享：刚度-阻尼-摩擦-有效质量。把这些量归一化后，应该存在一个**任务不变潜空间 z_K**：语义不同但「接触等价」的任务映射到同一点，接触物理不同的任务映射到不同点。用对比式不变性损失学这个空间，z_K 就成为先验检索与迁移的坐标系。

**灵感 4（元先验 + 元记忆 → XMP/TMM）**
直觉：有了 z_K，还需要「先验的先验」。在任务分布上元学习一个 π_meta(K|z_K)，部署到新任务时用少量接触做贝叶斯更新，几-shot 就能收敛；同时维护任务元记忆，防止学新任务忘旧任务（灾难遗忘），并在环境漂移时主动「忘记」过期记忆（不确定性膨胀），避免负迁移。

**灵感 5（合流 → 惯性接地跨任务闭环 IGTL / TIGER）**
直觉：ICO 给高频接触观测，IKP 给物理先验，TIIL 给跨任务坐标系，XMP/TMM 给可迁移的先验与记忆，TGC 给迁移可信度，PCE++++++ 给预算护栏。闭环为：**惯性观测→接触识别→任务嵌入→潜空间→元先验→EEIS 编译→执行→EV-exec→记忆/先验更新**。与第 60 轮 SERC 的关系是互补而非替代：SERC 解决「场景内先验收敛」，IGTL 解决「跨场景/跨任务先验迁移」；SERC 是「认识场景」，IGTL 是「把认识迁移出去」。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（惯性接触观测器 ICO）** 给定关节状态 (q, q̇, τ)、IMU 测量 (a_m, ω_m) 与机器人模型 (M, C, G, J)，ICO 输出外部接触估计 F̂_ext 与惯性接触签名 s_imu。

1. **重力补偿与偏置观测**：a_t = R(q)(a_m − b̂_a) − g，ω_t = ω_m − b̂_g；偏置 (b̂_a, b̂_g) 由互补滤波在线估计，协方差 σ_b 作为签名的一部分输出。
2. **动量观测器**（不积分加速度，只对动量做一阶残差）：
```
p = M(q) q̇
ṙ = K_o (ṗ − (τ + Cᵀ q̇ − G)) − K_o r
F̂_ext = (Jᵀ)† r
```
对浮动基机器人，ṗ 中追加 IMU 给出的基座加速度项；观测器极点由 K_o ≻ 0 决定，稳态时 r → Jᵀ F_ext。**关键：IMU 只提供代数加速度/角速度输入，不做二次积分，因此漂移有界。**
3. **惯性接触签名**：
```
s_imu = (E_hp, f_res, C_ω, ζ_imp, ρ_slip, σ_b)
```
- E_hp：a_t 在 f > f_c（默认 20 Hz）的高通能量；
- f_res：20–500 Hz 内加速度谱主峰；
- C_ω：角速度谱质心；
- ζ_imp：冲激响应的对数衰减率换算的阻尼比；
- ρ_slip：切向/法向高频能量比，作为微滑移指标；
- σ_b：偏置后验标准差，作为「这份签名有多可信」的元信息。
4. **接触起始与滑移检测**：对 ‖r‖ 做 CUSUM，g_t = max(0, g_{t−1} + ‖r_t‖ − ν)，g_t > h 触发接触；当 ‖F_t‖ > μ̂|F_n| 且 ρ_slip > τ_slip 触发滑移告警。

**定义 162（惯性阻抗先验 IKP）** IKP 把签名映射为阻抗先验：
```
K_p⁰ = m_eff (2π f_res)²
K_d⁰ = 2 ζ_imp sqrt(K_p⁰ m_eff)
μ̂⁰  = clip( (‖F_t‖/|F_n|) / (1 + ρ_slip), 0, μ_max )

π_IMU(K|s_imu) = N(K; μ_I(s_imu), Σ_I(s_imu))
μ_I = Ψ_phys(s_imu) + r_ξ(s_imu)
Σ_I = diag(σ_p², σ_d², σ_μ²) + Σ_ξ(s_imu)
```
其中 Ψ_phys 是上式给出的物理解析映射，r_ξ/Σ_ξ 是学习到的残差与不确定性校准项。若 E_hp 低于噪声门限或 f_res 不可辨，则按 σ_b 与信噪比膨胀 Σ_I，并回退到第 60 轮场景先验。校准要求：在 1−α 名义置信下，真实 K 落入可信集的频率 ≥ 1−α−δ_cal。

**定义 163（任务不变阻抗潜空间 TIIL）** 任务 T = (c_T, p_T)，其中 c_T = (v_ref, F_ref, m̂, tool_id, contact_mode, 轨迹特征) 是可观测上下文，p_T = (K*, ζ*, μ*, m_eff) 是潜在接触物理参数。编码器为：
```
z_T = g_ψ(c_T),  z_I = f_θ(s_imu),  z_K = h_φ(z_T, z_I) ∈ R^d
```
**接触等价**：T_i ~_c T_j 当且仅当存在仿射映射 (A_ij, b_ij)，使任意可行 K 下的接触响应算子满足 R_i(K) = A_ij R_j(K) + b_ij。直觉是：同一套接触物理在不同负载/工具/轨迹下只差一个任务仿射标定，其「规范接触动力学」相同。
TIIL 的训练目标：
```
L_TIIL = L_pred + λ₁ L_inv + λ₂ L_sep + λ₃ L_cal
L_pred = −log p(K_obs | z_K)
L_inv  = E_{(i,j): T_i ~_c T_j} ‖z_Ki − z_Kj‖²
L_sep  = E_{(i,j): T_i ≁_c T_j} max(0, m − ‖z_Ki − z_Kj‖)²
L_cal  = calibration_error(π_IMU)
```
表示有效性条件：z_K 近似为接触等价类的充分统计量，即 T_i ~_c T_j ⇔ ‖z_Ki − z_Kj‖ ≤ ε_K。

**定义 164（跨任务元先验 XMP）** 元先验 π_meta(K|z_K) = N(μ_η(z_K), Σ_η(z_K))，在任务分布 p(T) 上元训练：
```
η* = argmin_η E_{T~p(T)} E_{D_T~T} [
        −log ∫ p(K|z_K) π_meta(K|z_K) dK
        + λ_cal Cal(π_meta, T) + λ_reg ‖η‖² ]
```
部署到新任务时，用 k 个接触样本 D_T = {(s_imu^i, K_obs^i)} 做共轭贝叶斯更新：
```
Σ_T = (Σ_meta⁻¹ + k Σ_obs⁻¹)⁻¹
μ_T = Σ_T (Σ_meta⁻¹ μ_meta + Σ_obs⁻¹ Σ_i K_obs^i)
k_eff = k / (1 + tr(Σ_obs)/tr(Σ_meta))
```
k=0 时 π_T = π_meta；k < k_min 时触发主动探测（低幅微接触），而不是硬用不可信的先验。

**定义 165（任务元记忆 TMM）** 记忆 M = {(c_j, μ_j, Σ_j, Ω_j, n_j, t_j)}，按 z_K 检索。合并门控：
```
j* = argmin_j ‖z_K − c_j‖
if d(z_K, c_j*) > τ_new and Wald_test(μ_I, μ_j*) 显著: insert 新原型
elif d(z_K, c_j*) ≤ τ_new: μ_j* ← (n μ_j* + μ_I)/(n+1); Σ_j* ← Welford
```
抗遗忘：
```
L_TMM = L_TIIL + (λ_ewc/2) Σ_j Ω_j ‖θ − θ_j*‖² + λ_rep L_replay
```
Ω_j 为 Fisher 信息对角近似，θ_j* 为上次巩固参数，replay buffer 保留每个原型的代表样本。**过期门控**：若偏置跳变 ‖b̂_a(t) − b̂_a(t−Δt)‖ > τ_b 或 z_K 的 OOD 分数 > τ_ood，则 Σ_j ← Σ_j + Δ_stale 并标记 stale，禁止其作为迁移锚点，直到重新验证。

**定义 166（惯性接地跨任务闭环 IGTL）** 算子 IGTL(M, c_T, intent, δ_f_req)：
```
① ICO:      (F̂_ext, s_imu, onset, slip) ← ICO.step(q, q̇, τ, a_m, ω_m)
② Trigger:  if onset or slip or task_switch:
③ TCE:      z_T ← g_ψ(c_T)
④ TIIL:     z_I ← f_θ(s_imu);  z_K ← h_φ(z_T, z_I)
⑤ XMP:      (π_T, k_eff) ← XMP.adapt(z_K, D_T)
⑥ TGC:      if not TGC.valid(z_K, π_T, k_eff):
                π_T ← π_scene^general;  if TGC.need_probe: request_micro_probe()
⑦ EEIS:     K_safe ← EEIS.compile(δ_f_req, π_T, Z_env)
⑧ CIEC:     if intent: C_intent ← ϕ(I);  ERTC.lock_constraints(C_intent)
⑨ Dispatch: send_impedance_params(K_safe.best, Cert_eeis)
⑩ Execute:  telemetry ← wait_contact()
⑪ EV-exec:  EV ← build_exec_evidence(telemetry, K_safe, s_imu)
⑫ Memory:   D_T.append(s_imu, EV.K_obs)
            if TMM.gate(s_imu, EV): TMM.consolidate(z_K, π_T)
⑬ Return:   (K_safe, s_imu, z_K, π_T, TGC, EV, k_eff)
```
回退矩阵：IMU 不可用 → 第 60 轮 SSM 场景先验；场景置信度低但 TGC 有效 → IGTL 先验；两者都不可信 → 通用保守先验；B_exec 耗尽 → 第 60 轮原有降级；任一时刻 CIEC 意图约束是硬约束，优先于所有学习先验。

**定义 167（跨任务泛化证书 TGC）** 新任务 T_new 的迁移证书：
```
TGC(T_new) = (ω_T, m_K, c_K, k_eff)
```
- ω_T：任务漂移，用 z_K 到训练任务流形的马氏距离/密度比近似；
- m_K：潜空间裕度，到最近原型的距离；
- c_K：元先验可信集在留出任务上的经验覆盖率；
- k_eff：有效自适应样本数（定义 164）。
有效性条件：
```
TGC_valid = (ω_T ≤ ω_max) ∧ (m_K ≥ m_min) ∧ (c_K ≥ 1−α) ∧ (k_eff ≥ k_min)
```
风险上界（以概率 ≥ 1−δ）：
```
E[L_Tnew] ≤ L_meta + L_h·ω_T + B_cal/√k_eff + sqrt((log(1/δ)+C)/(2N))
```
其中 L_h 是 z_K→先验映射的 Lipschitz 常数。若证书无效，则按代价从低到高执行：保守先验 → 主动微接触探测 → 请求人类澄清（复用 CIEC 的意图通道），绝不允许「带病迁移」。

**定义 168（跨任务预算 PCE++++++）** B_x = (B_imu, B_task, B_meta, B_exec)，其中：
- **B_imu** = (f_imu, Bias_budget, Window_len, SNR_threshold)
- **B_task** = (Context_dim, Encoder_update_rate, Adaptation_budget k_max)
- **B_meta** = (Meta_grad_steps, Memory_capacity, Replay_budget, Stale_threshold)
- **B_exec** = (WCET_slack, Bus_bw_slack, Thermal_slack, Prio_headroom)（原有）

**VOI 扩展**：
```
voi_x(π) = VOI_meta_pessimistic(π) − cost_imu − cost_task − cost_meta − cost_exec
cost_imu  = λ_imu·f_imu·T + λ_bias·Bias_est
cost_task = λ_enc·Encoder_updates + λ_adapt·k
cost_meta = λ_mem·Memory_size + λ_replay·Replay_ops
cost_exec = λ_wcet·max(0, WCET(π)−WCET_slack) + λ_bus·max(0, Bus(π)−Bus_bw_slack) + λ_therm·max(0, Power(π)−Thermal_slack)
```
降级链：B_imu 耗尽或偏置超限 → 关闭惯性先验，回退 SSM；B_task 耗尽 → 冻结任务编码器，使用通用 z_T；B_meta 耗尽 → 只检索不更新，并膨胀 Σ；B_exec 耗尽 → 第 60 轮降级。**任何降级都先回到「更保守的先验」，再谈性能。**

### IP-161 ICO（惯性接触观测器）

```python
class InertialContactObserver:
    def __init__(self, robot, K_o=50.0, f_c=20.0, fs=1000.0,
                 nu=0.5, h=8.0, tau_slip=0.35):
        self.robot = robot
        self.K_o = K_o
        self.f_c = f_c
        self.fs = fs
        self.nu, self.h = nu, h
        self.tau_slip = tau_slip
        self.g = np.array([0.0, 0.0, -9.81])
        self.r = np.zeros(robot.n)
        self.p_prev = None
        self.b_a = np.zeros(3)
        self.b_g = np.zeros(3)
        self.cusum = 0.0

    def step(self, q, dq, tau, a_m, w_m, dt):
        M = self.robot.M(q)
        C = self.robot.C(q, dq)
        G = self.robot.G(q)
        J = self.robot.J(q)
        p = M @ dq
        if self.p_prev is None:
            self.p_prev = p
        p_dot = (p - self.p_prev) / dt
        r_dot = self.K_o * (p_dot - (tau + C.T @ dq - G)) - self.K_o * self.r
        self.r = self.r + r_dot * dt
        self.p_prev = p
        F_ext = np.linalg.pinv(J.T) @ self.r

        a = self.robot.R(q) @ (a_m - self.b_a) - self.g
        s_imu = self._signature(a, w_m - self.b_g)
        self.cusum = max(0.0, self.cusum + np.linalg.norm(self.r) - self.nu)
        onset = self.cusum > self.h
        slip = (s_imu['rho_slip'] > self.tau_slip and
                np.linalg.norm(F_ext[:2]) > s_imu['mu_hat'] * abs(F_ext[2]))
        return F_ext, s_imu, onset, slip

    def _signature(self, a, w):
        win = np.hanning(len(a))
        A = np.abs(np.fft.rfft(a * win, axis=0))
        A = np.linalg.norm(A, axis=1)
        freqs = np.fft.rfftfreq(len(a), 1.0 / self.fs)
        band = (freqs >= self.f_c) & (freqs <= min(500.0, self.fs / 2))
        E_hp = float(np.sum(A[band] ** 2))
        f_res = float(freqs[band][np.argmax(A[band])]) if band.any() else 0.0
        W = np.abs(np.fft.rfft(w * win, axis=0))
        W = np.linalg.norm(W, axis=1)
        C_w = float(np.sum(freqs * W) / (np.sum(W) + 1e-9))
        zeta = self._log_decrement(a)
        rho_slip = self._band_ratio(a, 50.0, 200.0) / (E_hp + 1e-9)
        sigma_b = float(np.trace(self.robot.imu_bias_cov))
        return {'E_hp': E_hp, 'f_res': f_res, 'centroid': C_w,
                'zeta': zeta, 'rho_slip': rho_slip,
                'mu_hat': self._mu_from_residual(), 'sigma_b': sigma_b}
```

### IP-162 IKP（惯性阻抗先验）

```python
class InertialImpedancePrior:
    def __init__(self, m_eff, residual_net=None, snr_min=5.0):
        self.m_eff = m_eff
        self.residual_net = residual_net
        self.snr_min = snr_min

    def prior(self, s_imu):
        if s_imu['E_hp'] < self.snr_min or s_imu['f_res'] <= 0:
            return None, 'low_snr_fallback'
        Kp0 = self.m_eff * (2 * np.pi * s_imu['f_res']) ** 2
        Kd0 = 2 * s_imu['zeta'] * np.sqrt(Kp0 * self.m_eff)
        mu0 = float(np.clip(s_imu['mu_hat'], 0.05, 1.0))
        phys = np.array([Kp0, Kd0, mu0])
        resid = self.residual_net(s_imu) if self.residual_net else np.zeros(3)
        mu = phys + resid
        sigma = self._sigma(s_imu)
        Sigma = np.diag(sigma ** 2)
        return NormalPrior(mu, Sigma), 'ok'

    def _sigma(self, s_imu):
        base = np.array([0.15 * abs(self.m_eff), 0.20, 0.10])
        return base * (1.0 + s_imu['sigma_b'] / 0.05)
```

### IP-163 TIIL（任务不变阻抗潜空间）

```python
class TaskInvariantEncoder:
    def __init__(self, d=32):
        self.g = TaskContextEncoder(d)
        self.f = InertialEncoder(d)
        self.h = FusionMLP(2 * d, d)
        self.head = GaussianHead(d, out_dim=3)

    def encode(self, c_T, s_imu):
        z_T = self.g(c_T)
        z_I = self.f(s_imu)
        return self.h(torch.cat([z_T, z_I], dim=-1))

    def loss(self, batch):
        zK = self.encode(batch['c_T'], batch['s_imu'])
        mu, Sigma = self.head(zK)
        L_pred = -DiagNormal(mu, Sigma).log_prob(batch['K_obs']).mean()
        d = torch.cdist(zK, zK)
        eq = batch['equiv_pair_mask']
        L_inv = (d[eq] ** 2).mean() if eq.any() else 0.0
        neg = ~eq & ~torch.eye(len(zK), dtype=torch.bool, device=zK.device)
        L_sep = F.relu(batch['margin'] - d[neg]).pow(2).mean() if neg.any() else 0.0
        L_cal = self._calibration_loss(mu, Sigma, batch['K_obs'])
        return L_pred + 0.5 * L_inv + 0.5 * L_sep + 0.1 * L_cal
```

```python
class CrossTaskMetaPrior:
    def __init__(self, encoder, lr=1e-3):
        self.encoder = encoder
        self.net = MetaPriorNet(latent_dim=32, out_dim=3)
        self.opt = torch.optim.Adam(
            list(self.net.parameters()) + list(encoder.parameters()), lr=lr)

        mu_m, Sigma_m = self.net(z_K)
        if len(D_T) == 0:
            return NormalPrior(mu_m, Sigma_m), 0.0
        K_obs = np.stack([d['K'] for d in D_T])
        Sigma_obs = np.mean([d['Sigma'] for d in D_T], axis=0)
        inv_m = np.linalg.inv(Sigma_m)
        inv_o = np.linalg.inv(Sigma_obs)
        Sigma_T = np.linalg.inv(inv_m + len(K_obs) * inv_o)
        mu_T = Sigma_T @ (inv_m @ mu_m + inv_o @ K_obs.sum(axis=0))
        k_eff = len(K_obs) / (1.0 + np.trace(Sigma_obs) / np.trace(Sigma_m))
        return NormalPrior(mu_T, Sigma_T), k_eff
```

```python
class TaskMetaMemory:
    def __init__(self, capacity=64, tau_new=0.2, tau_ood=3.0,
                 tau_bias=0.05, delta_stale=0.25):
        self.memory = []
        self.capacity = capacity
        self.tau_new, self.tau_ood = tau_new, tau_ood
        self.tau_bias, self.delta_stale = tau_bias, delta_stale

    def retrieve(self, z_K):
        if not self.memory:
            return None, float('inf')
        d = [np.linalg.norm(z_K - m['c']) for m in self.memory]
        j = int(np.argmin(d))
        return self.memory[j], float(d[j])

    def consolidate(self, z_K, prior, fisher):
        m, d = self.retrieve(z_K)
        if m is None or d > self.tau_new:
            if self._wald_significant(prior, m):
                self.memory.append({'c': z_K, 'mu': prior.mu,
                                    'Sigma': prior.Sigma, 'Omega': fisher, 'n': 1})
                if len(self.memory) > self.capacity:
                    self.memory.pop(0)
            return
        m['mu'] = (m['n'] * m['mu'] + prior.mu) / (m['n'] + 1)
        m['Sigma'] = welford_update(m['Sigma'], prior.mu, m['n'])
        m['n'] += 1

    def staleness_gate(self, bias_jump, ood_score):
        if bias_jump > self.tau_bias or ood_score > self.tau_ood:
            for m in self.memory:
                m['Sigma'] = m['Sigma'] + self.delta_stale * np.eye(len(m['Sigma']))
                m['stale'] = True
```

**正确性定理（TIGER）**：
假设 A22–A70 成立。其中新增：
**(A66) ICO 可观测性**：IMU 偏置有界、J 满足秩条件、观测器增益 K_o ≻ 0，且标定窗口内无未建模接触。
**(A67) IKP 校准**：物理先验在 1−α 名义置信下覆盖真实 K，f_res 高于噪声门限；否则触发低 SNR 回退。
**(A68) TIIL 不变性**：存在规范接触动力学，接触等价任务间存在仿射标定；z_K 对 (c_T, s_imu) 满足 Lipschitz 连续性，常数为 L_h。
**(A69) XMP 迁移**：元训练任务分布与目标任务之间的漂移满足 ω_T ≤ ω_max；自适应样本独立同分布，k_eff ≥ k_min。
**(A70) 预算安全**：B_imu/B_task/B_meta/B_exec 单调消耗，任一耗尽即触发定义 168 的降级链。

则：
1. **惯性接触可观测性**：r → Jᵀ F_ext 指数收敛，接触起始检测时延由采样率与 CUSUM 参数界定；IMU 不参与二次积分，估计误差不随运行时间累积。

3. **跨任务迁移性**：E[L_Tnew] ≤ L_meta + L_h·ω_T + B_cal/√k_eff + 有限样本项；当 TGC 有效时，迁移先验的风险受证书约束。
4. **负迁移防护**：TGC 无效时执行保守回退/主动探测，因而不会把「自信的错误先验」送入 EEIS。
5. **预算安全性**：任一分量耗尽，系统回到一个已被证明安全的保守策略。

### IP-161 ICO（惯性接触观测器）

```python
class InertialContactObserver:
    def __init__(self, robot, K_o=50.0, f_c=20.0, fs=1000.0,
                 nu=0.5, h=8.0, tau_slip=0.35):
        self.robot, self.K_o, self.f_c, self.fs = robot, K_o, f_c, fs
        self.nu, self.h, self.tau_slip = nu, h, tau_slip
        self.g = np.array([0.0, 0.0, -9.81])
        self.r = np.zeros(robot.n)
        self.p_prev = None
        self.b_a, self.b_g = np.zeros(3), np.zeros(3)
        self.cusum = 0.0

    def step(self, q, dq, tau, a_m, w_m, dt):
        M, C, G, J = self.robot.M(q), self.robot.C(q, dq), self.robot.G(q), self.robot.J(q)
        p = M @ dq
        if self.p_prev is None:
            self.p_prev = p
        p_dot = (p - self.p_prev) / dt
        r_dot = self.K_o * (p_dot - (tau + C.T @ dq - G)) - self.K_o * self.r
        self.r += r_dot * dt
        self.p_prev = p
        F_ext = np.linalg.pinv(J.T) @ self.r
        a = self.robot.R(q) @ (a_m - self.b_a) - self.g
        s_imu = self._signature(a, w_m - self.b_g)
        self.cusum = max(0.0, self.cusum + np.linalg.norm(self.r) - self.nu)
        onset = self.cusum > self.h
        slip = (s_imu['rho_slip'] > self.tau_slip and
                np.linalg.norm(F_ext[:2]) > s_imu['mu_hat'] * abs(F_ext[2]))
        return F_ext, s_imu, onset, slip

    def _signature(self, a, w):
        win = np.hanning(len(a))
        A = np.linalg.norm(np.abs(np.fft.rfft(a * win, axis=0)), axis=1)
        W = np.linalg.norm(np.abs(np.fft.rfft(w * win, axis=0)), axis=1)
        freqs = np.fft.rfftfreq(len(a), 1.0 / self.fs)
        band = (freqs >= self.f_c) & (freqs <= min(500.0, self.fs / 2))
        E_hp = float(np.sum(A[band] ** 2))
        f_res = float(freqs[band][np.argmax(A[band])]) if band.any() else 0.0
        C_w = float(np.sum(freqs * W) / (np.sum(W) + 1e-9))
        return {'E_hp': E_hp, 'f_res': f_res, 'centroid': C_w,
                'zeta': self._log_decrement(a),
                'rho_slip': self._band_ratio(a, 50.0, 200.0) / (E_hp + 1e-9),
                'mu_hat': self._mu_from_residual(),
                'sigma_b': float(np.trace(self.robot.imu_bias_cov))}
```

```python
    def __init__(self, m_eff, residual_net=None, snr_min=5.0):
        self.m_eff, self.residual_net, self.snr_min = m_eff, residual_net, snr_min

    def prior(self, s_imu):

        sigma = np.array([0.15 * abs(self.m_eff), 0.20, 0.10])
        sigma = sigma * (1.0 + s_imu['sigma_b'] / 0.05)
```

```python
        d = torch.cdist(zK, zK)
        eq = batch['equiv_pair_mask']
        L_inv = (d[eq] ** 2).mean() if eq.any() else 0.0
        neg = ~eq & ~torch.eye(len(zK), dtype=torch.bool, device=zK.device)
        L_sep = F.relu(batch['margin'] - d[neg]).pow(2).mean() if neg.any() else 0.0
        L_cal = self._calibration_loss(mu, Sigma, batch['K_obs'])
        return L_pred + 0.5 * L_inv + 0.5 * L_sep + 0.1 * L_cal
```

### IP-164 XMP（跨任务元先验与几-shot 自适应）

```python
class CrossTaskMetaPrior:
    def __init__(self, encoder, lr=1e-3):
        self.encoder = encoder
        self.net = MetaPriorNet(latent_dim=32, out_dim=3)
        self.opt = torch.optim.Adam(
            list(self.net.parameters()) + list(encoder.parameters()), lr=lr)

    def adapt(self, z_K, D_T):
        mu_m, Sigma_m = self.net(z_K)
        if len(D_T) == 0:
            return NormalPrior(mu_m, Sigma_m), 0.0
        K_obs = np.stack([d['K'] for d in D_T])
        Sigma_obs = np.mean([d['Sigma'] for d in D_T], axis=0)
        inv_m, inv_o = np.linalg.inv(Sigma_m), np.linalg.inv(Sigma_obs)
        Sigma_T = np.linalg.inv(inv_m + len(K_obs) * inv_o)
        mu_T = Sigma_T @ (inv_m @ mu_m + inv_o @ K_obs.sum(axis=0))
        k_eff = len(K_obs) / (1.0 + np.trace(Sigma_obs) / np.trace(Sigma_m))
        return NormalPrior(mu_T, Sigma_T), k_eff
```

### IP-165 TMM（任务元记忆与过期门控）

```python
class TaskMetaMemory:
    def __init__(self, capacity=64, tau_new=0.2, tau_ood=3.0,
                 tau_bias=0.05, delta_stale=0.25):
        self.memory = []
        self.capacity = capacity
        self.tau_new, self.tau_ood = tau_new, tau_ood
        self.tau_bias, self.delta_stale = tau_bias, delta_stale

    def retrieve(self, z_K):
        if not self.memory:
            return None, float('inf')
        d = [np.linalg.norm(z_K - m['c']) for m in self.memory]
        j = int(np.argmin(d))
        return self.memory[j], float(d[j])

    def consolidate(self, z_K, prior, fisher):
        m, d = self.retrieve(z_K)
        if m is None or d > self.tau_new:
            if self._wald_significant(prior, m):
                self.memory.append({'c': z_K, 'mu': prior.mu, 'Sigma': prior.Sigma,
                                    'Omega': fisher, 'n': 1})
                if len(self.memory) > self.capacity:
                    self.memory.pop(0)
            return
        m['mu'] = (m['n'] * m['mu'] + prior.mu) / (m['n'] + 1)
        m['Sigma'] = welford_update(m['Sigma'], prior.mu, m['n'])
        m['n'] += 1

    def staleness_gate(self, bias_jump, ood_score):
        if bias_jump > self.tau_bias or ood_score > self.tau_ood:
            for m in self.memory:
                m['Sigma'] += self.delta_stale * np.eye(len(m['Sigma']))
                m['stale'] = True
```

```python
def inertial_grounded_transfer_loop(M, c_T, intent, delta_f_req):
    F_ext, s_imu, onset, slip = M.ico.step(
        M.q, M.dq, M.tau, M.a_m, M.w_m, M.dt)

    z_K = M.tiil.encode(c_T, s_imu)

    if not cert.valid:
        prior = M.scene_model.general_prior()
        if cert.need_probe:

    if intent:
        M.ciec.lock(intent)

    K_safe = M.eeis.compile(delta_f_req, prior, M.env)
    dispatch_impedance_params(K_safe.best, cert)
    telemetry = wait_contact()
    ev = build_exec_evidence(telemetry, K_safe, s_imu)
    M.D_T.append({'s_imu': s_imu, 'K': ev.K_obs, 'Sigma': prior.Sigma})
    if M.tmm.gate(s_imu, ev):
        M.tmm.consolidate(z_K, prior, fisher=M.fisher_diag)
    return M, (K_safe, s_imu, z_K, prior, cert, ev, k_eff)
```

### IP-167 TGC（跨任务泛化证书）

```python
class TransferCertificate:
    def __init__(self, omega_max=2.0, m_min=0.2, alpha=0.1,
                 k_min=1.0, L_h=0.5, B_cal=0.1):
        self.omega_max, self.m_min = omega_max, m_min
        self.alpha, self.k_min = alpha, k_min
        self.L_h, self.B_cal = L_h, B_cal

    def check(self, z_K, prior, k_eff):
        omega_T = self._ood_score(z_K)
        m_K = self._latent_margin(z_K)
        c_K = self._empirical_coverage(prior)
        valid = (omega_T <= self.omega_max and m_K >= self.m_min and
                 c_K >= 1 - self.alpha and k_eff >= self.k_min)
        bound = (self.L_h * omega_T +
                 self.B_cal / np.sqrt(max(k_eff, 1.0)) +
                 self._finite_sample_term)
        return Cert(valid=valid, omega_T=omega_T, m_K=m_K, c_K=c_K,
                    k_eff=k_eff, risk_bound=bound,
                    need_probe=(not valid and k_eff < self.k_min))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| ICO | O(n²)/周期（稀疏 O(n)） | O(n + W_imu) | 检测时延 ≤ 2 ms；外力误差随 K_o 下降；无积分漂移 |
| IKP | O(1) 推理 | O(1) | 覆盖率 ≥ 1−α−δ_cal；低 SNR 回退 |
| TIIL | O(d²) 训练/批，O(d) 推理 | O(d + |θ|) | 等价对潜距 ≤ ε_K；分离对潜距 ≥ m−ε |
| XMP | O(k d²) 自适应 | O(N_p d) | 后验均值误差 ≤ O(1/√k_eff) |
| TMM | O(N_p d) 检索 | O(N_p d) | Wald 检验控假新类；过期门控防污染 |
| IGTL | O(闭环) + ICO | 复用 SERC | 场景内继承 SERC；跨任务由 TGC 门控 |
| TGC | O(d N_p) | O(1) | 风险上界成立或触发降级 |
| PCE++++++ | O(1) | O(1) | 任一耗尽即触发保守策略 |

**正确性定理（TIGER）**：
若 A22–A70 成立，其中新增 A66–A70：
- A66 ICO 可观测性：IMU 偏置有界、J 满秩、K_o ≻ 0、标定窗口无未建模接触；
- A67 IKP 校准：物理先验在 1−α 下覆盖真实 K，f_res 高于噪声门限；
- A68 TIIL 不变性：存在规范接触动力学与任务仿射标定，z_K 满足 Lipschitz 常数 L_h；
- A69 XMP 迁移：任务漂移 ω_T ≤ ω_max，自适应样本 i.i.d.，k_eff ≥ k_min；
- A70 预算安全：B_imu/B_task/B_meta/B_exec 单调消耗，任一耗尽触发降级链。

则：
1. **惯性接触可观测性**：r → Jᵀ F_ext 指数收敛；IMU 不参与二次积分，误差不随时间累积。
2. **先验校准性**：IKP 可信集覆盖率 ≥ 1−α−δ_cal；低 SNR 时回退不劣于第 60 轮 SSM。
3. **跨任务迁移性**：E[L_Tnew] ≤ L_meta + L_h·ω_T + B_cal/√k_eff + 有限样本项。
4. **负迁移防护**：TGC 无效时保守回退/主动探测，错误先验不进入 EEIS。
5. **预算安全性**：任一分量耗尽，系统回到已被证明安全的保守策略。

## 5. 本轮最大风险

**一句话**：最大风险是**负迁移**——任务不变潜空间可能把「IMU 签名相似但接触稳定性截然不同」的任务（如刚性桌面与湿滑地面）错误对齐，使元先验在未见任务上自信地给出错误的 K_safe，且自监督/TMM 的闭环会不断强化这一错误；必须以 TGC 四元证书门控、IMU 偏置与过期记忆的不确定性膨胀、低 SNR/低覆盖时的保守回退和主动微接触探测四重护栏，确保「跨任务泛化」永远不超过「接触安全」。
