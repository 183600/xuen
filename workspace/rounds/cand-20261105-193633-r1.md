# 第 22 轮（新灵感循环第 1 轮）· INTERPRETABLE-COMPLIANT-GENERALIZATION-ZEST：从「可解释性」「柔顺控制」「跨物体泛化」出发，构建面向具身智能的「解释-柔顺-泛化」三位一体架构，解决「黑箱决策、刚性交互、泛化盲区」的本质矛盾

## 0. 先给直觉：为什么 CG-ZEST 还需要「可解释性」「柔顺控制」与「跨物体泛化」的深度融合？

第 21 轮的 CG-ZEST 解决了「物体实例盲区、泛化盲区、采集盲区」，引入「物体动力声纹克隆」让系统能在 5 秒内识别未见物体的动力学特征，但它在三个本质维度上对「开放世界的长期自主运行」仍构成挑战——它有一个被掩盖的前提假设：**模型的内部推理过程对人类与下游安全模块是不透明的，控制策略本质上是「位置型」而非「阻抗型」，泛化能力依赖声纹覆盖而非物理机理理解**。

> **黑箱决策盲区**：CG-ZEST 的 OC-HEAD 通过 FiLM 以 `e_obj` 条件化预测 `γ̂_pred, h, p_failure`，AC-SYNTH 以声纹条件化合成动作块，但「为什么这瓶子预测刚度低？为什么这次混合系数降到 0.3？为什么升级云端 VLA？」——系统给不出人类可读、可审计、可干预的解释。当事故发生时，无法追溯因果链；当专家想注入先验（如「玻璃瓶易碎，阻抗应设低」）时，无处挂载。可解释性不是事后可视化，而是**架构内生的因果可追溯性**。

> **刚性交互盲区**：AHD 的 `α_blend` 本质是位置轨迹的加权平均，快策略输出位置、慢专家输出位置、合成器输出位置——**缺乏阻抗/导纳视角**。遇到未知物体时，位置控制要么「太硬」导致冲击破坏，要么「太软」导致任务失败。柔顺控制的核心是「用阻抗参数表达不确定性」：`K = K_nominal · γ_adjusted`，`D = D_nominal · h_min`——让物理交互行为直接反映预测置信，而非事后用混合系数修补。CG-ZEST 的「三重降级」只是在轨迹层面削减权重，没有下沉到执行器阻抗层。

> **泛化机理盲区**：OD-CLONE 的声纹 `e_obj` 是「黑箱嵌入」，虽经物理回归接地，但**声纹维度无显式物理语义**——第 3 维是质量？第 17 维是摩擦？不知道。跨物体泛化靠「最近邻覆盖」而非「物理参数外推」：遇到质量 2.5kg 的瓶子，声纹库最近是 2.0kg 和 3.0kg，系统只能插值，无法从「质量守恒、牛顿第二定律」推导出合理阻抗。**真正的跨物体泛化应建立在「可解释的物理参数空间」上**，而非不可解释的潜在空间。

**核心类比（本轮的灵魂，来自「可解释 AI + 阻抗控制 + 物理推理」）**：
- 可解释性：像「可解释医疗 AI」——诊断结果必须伴随「关键症状 + 推理链 + 反事实」；
- 柔顺控制：像「变阻抗假肢」——不确定时变软、确定时变硬，阻抗参数显式表达认知状态；
- 跨物体泛化：像「物理引擎参数辨识」——从交互中辨识出 `mass, friction, stiffness, CoM` 等**显式物理参数**，再用物理定律外推到未见物体。

一句话押注：

> **第 21 轮让系统「5 秒认物体、条件化预测/合成、主动采数据」；本轮引入「可解释物理参数辨识器」EP-IDENT、「阻抗感知融合控制器」IC-FUSE、「因果可追溯解释生成器」CAUSAL-EXPLAIN，「物理外推泛化器」PHYS-EXTRAP，构建「解释-柔顺-泛化」三位一体架构（Interpretable-Compliant-Generalization ZEST, ICG-ZEST）。ICG-ZEST 的核心思想是：让「物理参数」显式可解释地被辨识，让「阻抗参数」直接表达认知不确定性，让「泛化」基于物理定律外推而非潜在空间插值。**

三个可验证创新点：

1. **可解释物理参数辨识器 EP-IDENT**：从参考交互 `R` 中辨识**显式物理参数** `θ_phys = {m, μ, k, CoM, fill, wear} ∈ ℝ⁶` 而非黑箱声纹。三重保证可解释性：① **概念瓶颈**——中间层强制输出物理参数，再由物理参数预测任务量（`γ̂ = f_γ(θ_phys)`），而非直接 `e_obj → γ̂`；② **注意力归因**——Transformer 注意力权重揭示「哪段交互辨识了质量、哪段辨识了摩擦」；③ **反事实生成**——`θ_phys' = θ_phys + Δ`，预测 `γ̂'` 变化量，回答「若瓶子装满水会怎样？」。运行时显式参数 <1ms，可直接给下游阻抗控制器用。

2. **阻抗感知融合控制器 IC-FUSE**：将 AHD 的「轨迹混合」重构为「阻抗调制」——快策略输出 `(x_f, K_f, D_f)`，AC-SYNTH 输出 `(x_s, K_s, D_s)`，云端 VLA 输出 `(x_v, K_v, D_v)`，**融合在阻抗空间而非位置空间**：
   ```
   K_blend = α_K·K_s + (1−α_K)·K_f,  D_blend = α_D·D_s + (1−α_D)·D_f
   τ_cmd = K_blend·(x_blend − x) + D_blend·(ẋ_blend − ẋ) + τ_ff
   ```
   其中 `α_K = γ_adjusted`, `α_D = h_min`——**置信调制刚度，健康度调制阻尼**，物理意义清晰。三重降级直接映射为阻抗包络收缩：`ν>0.8 → K ≤ 0.3K_nom, D ≥ 2D_nom`（「陌生物体变软变阻尼」），`h_min<0.7 → D ≥ 3D_nom`（「硬件退化大阻尼」），`p_failure>0.5 → K ≤ 0.2K_nom, τ_ff=0`（「故障预警极软零前馈」）。

3. **因果可追溯解释生成器 + 物理外推泛化器 CAUSAL-EXPLAIN + PHYS-EXTRAP**：
   - **解释生成**：每步输出结构化解释 `ξ = {因果图, 关键证据, 反事实, 置信区间}`，如：`「预测 γ̂=0.35，因声纹维度 12/34/51（对应摩擦/质量/刚度）偏离训练分布；反事实：若摩擦 μ+0.2，则 γ̂→0.52；建议：降低 K 至 0.4K_nom」`——可直接供人类审计、专家注入、日志追溯。
   - **物理外推**：建立「物理参数 → 任务量」的**显式映射模型** `f_phys2task(θ_phys)`（由仿真大规模监督训练），未见物体只需辨识 `θ_phys` 即可零样本外推 `γ̂, h, π*`，无需声纹库覆盖。泛化上界由物理参数辨识误差决定：`MSE(e*) ≤ C·‖Δθ_phys‖²`，而非声纹距离。

三个词怎么落地：

| 词 | 落地 | 不做什么 |
|---|---|---|
| **可解释性** | 概念瓶颈物理参数 + 注意力归因 + 反事实生成 → 结构化解释 ξ；每步决策可追溯、可审计、可干预 | 不做事后 Grad-CAM/LIME；不做黑箱声纹不可解释 |
| **柔顺控制** | AHD→IC-FUSE：位置混合→阻抗融合；置信调制刚度、健康度调制阻尼；三重降级=阻抗包络收缩 | 不做纯位置控制混合；不做隐式柔顺 |
| **跨物体泛化** | EP-IDENT 辨识显式 θ_phys；PHYS-EXTRAP 用 f_phys2task 外推；泛化靠物理定律而非最近邻 | 不靠声纹库覆盖半径；不做黑箱潜在空间插值 |

## 1. 研究日志：从 CLONING-GENERALIZATION-ZEST 到 INTERPRETABLE-COMPLIANT-GENERALIZATION-ZEST 的演进

### 1.1 第 21 轮留下的三个「本质盲区」

```text
E1. 黑箱决策：e_obj → γ̂/h/π* 全链路不可解释；专家无法注入先验；事故无法追溯因果链。
E2. 刚性交互：AHD 在位置空间混合轨迹；阻抗隐式、不可调；未知物体易「太硬撞坏」或「太软完不成」。
E3. 泛化机理：声纹 e_obj 无显式物理语义；泛化靠最近邻覆盖而非物理外推；遇到分布外物理参数失效。
```

这些盲区决定系统能否在「人机共融、长期自主、专家可信」的开放世界中存活：若机器人在陌生厨房拿起第 1001 个瓶子时，无法解释「为什么预测它很轻」、无法把「不确定」显式转化为「变软变阻尼」、无法从「质量 0.5kg」推导出「阻抗应设多少」——就会「不敢用、不敢信、不敢放」。

### 1.2 三个新的判断

1. **物理参数必须显式、可解释、可干预**：
   - 黑箱声纹 `e_obj ∈ ℝ⁶⁴`：维度无语义、不可干预、外推靠插值；
   - 概念瓶颈 `θ_phys ∈ ℝ⁶`：每维有明确物理意义、可被专家修正（`θ_phys[1] ← 0.8`）、可用物理定律外推；
   - 注意力归因：`Attn(t, 'mass')` 告诉人类「第 3 秒摇晃最能辨识质量」；反事实：`θ_phys' = θ_phys + Δm` 直接给出预测变化——**把「黑箱克隆」升级为「白箱辨识」**。

2. **不确定性必须在阻抗空间显式表达**：
   - 位置混合 `α·x_s + (1−α)·x_f`：物理意义模糊，刚度/阻尼隐式耦合，安全包络难证明；
   - 阻抗融合 `K_blend = γ·K_s, D_blend = h_min·D_s`：置信↔刚度、健康↔阻尼、新颖↔阻抗包络，**一一对应、可证明被动性、可Lyapunov 稳定**；
   - 三重降级 = 显式阻抗约束：`ν>0.8 → {K≤0.3K₀, D≥2D₀}`——**把「认知降级」变成「物理柔顺」**。

3. **泛化必须基于物理机理外推而非潜在空间插值**：
   - 声纹最近邻：`d_knn` 小则泛化好，大则失效——**覆盖半径决定上限**，新物体类别必有盲区；
   - 物理外推：辨识出 `θ_phys = {m=2.5, μ=0.3, k=1200, ...}` → 代入 `f_phys2task`（仿真监督的物理→任务映射）→ 得到 `γ̂, h, K*, D*`——**物理参数空间天然连续、外推有理论保证**（若 `f_phys2task` 是 Lipschitz 的），新类别物体同样适用。

### 1.4 灵感词贯通：可解释性、柔顺控制、跨物体泛化

> **可解释性**：概念瓶颈让「物理参数」成为中间可解释层（对应医疗 AI 的「症状→疾病」）；注意力归因揭示「哪段交互辨识了哪参数」（对应「关键症状定位」）；反事实生成回答「若参数变化预测如何变」（对应「反事实推理」）；结构化解释 `ξ` 让每步决策可审计、可注入、可追溯。
> **柔顺控制**：阻抗控制的核心「用物理参数表达认知状态」被架构内生化——置信 `γ` 直接调制刚度 `K`，健康度 `h_min` 直接调制阻尼 `D`，新颖度 `ν` 直接收缩阻抗包络。三重降级不再是「轨迹权重裁剪」，而是「物理柔顺化」：陌生→变软变阻尼、退化→大阻尼、故障→极软零前馈。被动性与稳定性有理论保证。
> **跨物体泛化**：从「声纹空间最近邻覆盖」跃迁到「物理参数空间外推」。EP-IDENT 辨识显式 `θ_phys`；PHYS-EXTRAP 通过 `f_phys2task(θ_phys)`（仿真大规模监督的物理→任务映射）零样本外推任务量与最优阻抗。泛化上界由辨识误差 `‖Δθ‖` 决定，而非声纹距离——**新类别物体同样适用，无需声纹库覆盖**。

## 2. 直觉深化：解释-柔顺-泛化三位一体架构

CG-ZEST 是「克隆-合成-采集」泛化循环嵌入「感知-预测-决策」闭环；ICG-ZEST 在此基础上重构三个核心层，形成**解释-柔顺-泛化三位一体**：

- **解释层（白箱辨识）**：EP-IDENT 辨识显式 `θ_phys`，注意力归因揭示证据链，反事实生成回答假设性问题，CAUSAL-EXPLAIN 输出结构化解释 ξ——**「每步决策为什么、凭什么、若改变会怎样」全链路可追溯**。
- **柔顺层（阻抗融合）**：IC-FUSE 将快/慢/云三路专家的输出在阻抗空间融合，`K=γ·K_s, D=h_min·D_s`，三重降级=显式阻抗约束——**「认知不确定性」直接转化为「物理柔顺行为」，被动性可证、稳定性可证**。
- **泛化层（物理外推）**：PHYS-EXTRAP 以 `f_phys2task(θ_phys)` 替代声纹最近邻，辨识 `θ_phys` 即得任务量与最优阻抗——**「物理机理」支撑零样本外推，新类别物体同样适用**。

与既有闭环的四个耦合点（升级版）：

1. **辨识→预测**：`θ_phys` 经 `f_phys2task` 给出 `γ̂_phys, h_phys, K*_phys, D*_phys`；并行声纹路径给出 `γ̂_voice, h_voice`；**双路一致性检查** `|γ̂_phys − γ̂_voice| > τ_consist → 触发重辨识/专家介入`——把「静默故障」变成「可检测分歧」。
2. **辨识→柔顺**：`K*_phys, D*_phys` 直接作为慢专家的阻抗目标；`γ̂_phys` 调制融合刚度，`h_min` 调制融合阻尼——**物理参数辨识结果无缝下沉到执行器阻抗层**。
3. **解释→人机/专家**：结构化解释 ξ 实时推送给监控界面；专家可注入约束 `θ_phys[μ] ≥ 0.4` 或 `K ≤ 0.5K_nom`——**人类认知与机器推理在「物理参数空间」对齐交互**。
4. **泛化→采集**：PHYS-HARVEST 以「物理参数空间覆盖缺口 + 辨识不确定性 + 反事实敏感度」驱动采集——**采集目标从「声纹库填洞」变为「物理参数空间主动覆盖 + 反事实数据增强」**。

## 3. 正式化：INTERPRETABLE-COMPLIANT-GENERALIZATION-ZEST 的符号定义

### 3.1 可解释物理参数辨识器 EP-IDENT

**参考交互**（同第 21 轮）：`R = {(o_t, a_t)}_{t=1..50}`，探测原语 `Π = {POKE, PUSH, LIFT, SHAKE, SQUEEZE}`。

**概念瓶颈架构**：
```
z_t = MM-ENCODER(o_t)                              # 复用第 20/21 轮，权重共享
h_0 = W_in [z_1; ...; z_T] + E_pos
h_l = TransformerLayer(h_{l-1}), l=1..4            # d=128, 4 heads
# ── 概念瓶颈层：强制输出显式物理参数 ──
θ_phys = W_θ h_4^{CLS} ∈ ℝ⁶                        # {m, μ, k, CoM_x, fill, wear}
# 注意力归因：每头对每参数的贡献
A_mass = mean_head(Attn[:, :, 'mass_token'])       # 哪些时刻辨识质量
A_fric = mean_head(Attn[:, :, 'fric_token'])       # 哪些时刻辨识摩擦
# 任务量预测头（从物理参数预测，非从声纹）
```

### 3.2 阻抗感知融合控制器 IC-FUSE

**三路专家输出（均含阻抗）**：
```

云端 VLA：    π_v(obs) → (x_v, ẋ_v, K_v, D_v, τ_ff_v)     # 升级时提供
```

**阻抗融合（核心公式）**：
```
α_K = γ_adjusted = γ_corrected · h_min · (1 − η·ν)        # 置信调制刚度权重
α_D = h_min                                               # 健康度调制阻尼权重
K_blend = α_K · K_s + (1 − α_K) · K_f
D_blend = α_D · D_s + (1 − α_D) · D_f
x_blend = α_K · x_s + (1 − α_K) · x_f                     # 位置仍加权（但受阻抗约束）
ẋ_blend = α_K · ẋ_s + (1 − α_K) · ẋ_f
τ_ff_blend = α_K · τ_ff_s + (1 − α_K) · τ_ff_f

# 执行器命令（阻抗控制律）
τ_cmd = K_blend · (x_blend − x) + D_blend · (ẋ_blend − ẋ) + τ_ff_blend
```

**三重降级 = 显式阻抗包络收缩（硬约束，而非软权重）**：
```

    D_blend ← max(D_blend, 3.0·D_nom)
    τ_ff_blend ← 0

    D_blend ← max(D_blend, 2.0·D_nom)
    log("NOVEL_DEGRADE: K≤0.3K₀, D≥2D₀")
```

**被动性与稳定性（理论保证）**：
- 命题 IC-1：若 `K_blend ≻ 0, D_blend ≻ 0` 且 `τ_ff_blend` 有界，则闭环系统关于供给率 `s = τ_cmd^T ẋ` 是**严格被动**的。
- 命题 IC-2：降级后的阻抗包络保证 `K_blend ∈ [K_min, K_max], D_blend ∈ [D_min, D_max]`，存在 Lyapunov 函数 `V = ½ ẋ^T M ẋ + ½ (x−x_d)^T K_blend (x−x_d)` 使 `V̇ ≤ −ẋ^T D_blend ẋ + c‖τ_dist‖²` ——**输入-状态稳定 (ISS)**。

### 3.4 物理外推泛化器 PHYS-EXTRAP

**物理→任务映射 `f_phys2task`（离线仿真大规模训练，在线零开销）**：
```

  θ_phys_i ~ 程序化物体生成器 G_ψ(u) 覆盖 ℝ⁶ 物理参数空间
  γ_i, h_i, K*_i, D*_i 由仿真最优控制/系统辨识获得（Oracle）

损失：ℒ_phys2task = ‖γ̂−γ‖² + ‖h−h_gt‖² + ‖K*−K*_gt‖² + ‖D*−D*_gt‖²
     + λ_lip · ‖∇_θ f‖²                                # Lipschitz 正则化，保证外推平滑
```

**零样本外推（运行时）**：
```

输出：γ̂_phys, h_phys, K*_phys, D*_phys, u_phys
u_phys = ‖∇_θ f(θ_phys)‖ · tr(Σ_θ)                    # 一阶不确定性传播
```

**外推泛化界（命题 PE-1）**：
设 `f_phys2task` 在 Θ 上 L-Lipschitz，辨识误差 `‖θ_phys − θ_true‖ ≤ ε`，则
```

```
**泛化上界由物理参数辨识精度决定，而非声纹库覆盖半径**——新类别物体只要物理参数在 Θ 内，同等保证。

### 3.6 ICG-ZEST 主循环（骨架，完整实现见产物区）

```python
class ICGZestPolicy:
    \"\"\"ICG-ZEST 主策略：解释-柔顺-泛化三位一体\"\"\"

    def __init__(self, ...):
        # 继承 CG-ZEST 全部组件
        self.ep_ident = EPIdent()           # 可解释物理参数辨识器
        self.ic_fuse = ICFuse()             # 阻抗感知融合控制器
        self.causal_explain = CausalExplain() # 因果解释生成器
        self.phys_extrap = PhysExtrap()     # 物理外推泛化器
        self.phys_harvest = PhysHarvest()   # 物理参数驱动采集
        # 并行保留声纹路径（第 21 轮）作为校验
        self.od_clone = ODClone()           # 声纹克隆器
        self.oc_head = FiLMJointHead()      # 声纹条件化预测头
        self.synth = ACSynth()              # 动作块合成器
        self.voicebank = VoiceBank()        # 声纹库
        
        self.theta_phys = None              # 显式物理参数
        self.sigma_theta = None             # 辨识不确定性
        self.degrade_mode = "NONE"

    def ensure_physics_identified(self, obs):
        if self.theta_phys is not None:
            return
        # 复用参考交互缓冲区（同 CG-ZEST）
        self.ref_buffer.append(self.mm_encoder(self._obs2dict(obs)))
        if len(self.ref_buffer) >= 50:
            z_seq = torch.stack(self.ref_buffer).unsqueeze(0)
            # EP-IDENT 前向：输出 θ_phys + 注意力归因 + 不确定性
            self.theta_phys, self.attn_maps, self.sigma_theta = \
                self.ep_ident(z_seq, return_attn=True, return_uncert=True)
            # 并行声纹路径（校验用）
            e_stack = torch.stack([c(z_seq)[0].squeeze(0) for c in self.od_clone.ensemble])
            self.e_obj = e_stack.mean(0)
            self.u_obj = float(e_stack.std(0).mean())
            self.nu = self.voicebank.novelty(self.e_obj.detach().cpu().numpy(), self.u_obj)
            self.ref_buffer.clear()
            # 双路一致性检查
            self._check_consistency()

    def get_action(self, obs):
        self.ensure_physics_identified(obs)
        if self.theta_phys is None:
            return self._probe_action(obs)

        obs_dict = self._obs2dict(obs)
        z = self.mm_encoder(obs_dict, self._check_modality_availability(obs))
        a_fast = self._select_fast_action(obs)

        # ── 双路预测：物理外推 vs 声纹条件化 ──
        gamma_phys, h_phys, K_star, D_star, u_phys = self.phys_extrap(self.theta_phys, self.sigma_theta)
        a_vec = self._act2vec(a_fast)
        gamma_voice, h_j, h_s, h_e, p_f, h_min, nu = \
            self.oc_head(z, a_vec, self.e_obj.unsqueeze(0), 
                         torch.tensor([self.voicebank.knn_distance(self.e_obj.cpu().numpy())]),
                         torch.tensor([self.u_obj]))
        
        # 一致性检查
        consistency_pass = abs(float(gamma_phys) - float(gamma_voice)) < 0.1
        if not consistency_pass:
            self._trigger_reidentify()

        # ── 置信调制（物理路径为主，声纹为辅）──
        gamma_corrected = self._cloud_correct(self.cmap_c.compress(float(gamma_phys)))
        gamma_adjusted = gamma_corrected * float(h_min) * (1.0 - self.eta * float(nu))
        
        # ── IC-FUSE：阻抗融合 ──
        alpha_K = gamma_adjusted
        alpha_D = float(h_min)
        # 获取三路专家的阻抗输出
        x_f, K_f, D_f, tau_ff_f = self._fast_expert_impedance(obs)
        x_s, K_s, D_s, tau_ff_s = self._synth_expert_impedance(obs, K_star, D_star)
        # 阻抗融合 + 三重降级硬约束
        tau_cmd, self.degrade_mode = self.ic_fuse.fuse(
            x_f, K_f, D_f, tau_ff_f,
            x_s, K_s, D_s, tau_ff_s,
            alpha_K, alpha_D,
            float(p_f), float(h_min), float(nu))
        
        # ── 生成结构化解释 ──
        xi = self.causal_explain.generate(
            theta_phys=self.theta_phys,
            attn_maps=self.attn_maps,
            gamma_phys=gamma_phys, gamma_voice=gamma_voice,
            h_phys=h_phys, h_voice=h_min,
            K_star=K_star, D_star=D_star,
            alpha_K=alpha_K, alpha_D=alpha_D,
            degrade_mode=self.degrade_mode,
            consistency_pass=consistency_pass)
        self._push_explanation(xi)
        
        return tau_cmd

    def on_idle(self, candidate_probes):
        return self.phys_harvest.select_best(candidate_probes, self.theta_phys, self.sigma_theta)

    def on_block_finished(self, success):
        if self.theta_phys is not None:
            # 后见回标：实测物理参数 + 任务结果
            self._upload_hindsight_phys(self.theta_phys, success)
            # 反事实数据增强：生成邻域反事实样本加入训练池
            self._generate_counterfactuals(self.theta_phys)
```

### 3.7 性质、复杂度与正确性

**命题 EP-1（物理参数可辨识性，非正式）**：若 ℒ_phys_reg 收敛且注意力归因对齐 ℒ_attn_align→0，则对于物理参数差异 `‖Δθ‖ ≥ ε` 的两物体，辨识误差满足 `E‖θ̂₁ − θ̂₂‖ ≥ c·ε − δ_id`，其中 `δ_id` 为同物体跨交互辨识漂移。**显式物理参数在极限下是可辨识、可分离的**——不再有「声纹相似但物理截然不同」的混淆。

**命题 EP-2（双路一致性检测力）**：设声纹路径预测误差 `ε_voice = |γ̂_voice − γ_true|`，物理路径预测误差 `ε_phys = |γ̂_phys − γ_true|`，若两路径误差独立且零均值，则 `|γ̂_phys − γ̂_voice| > τ` 以概率 `≥ 1−α` 检测出至少一路失效。**静默故障变为可检测分歧**。

**命题 IC-1（阻抗融合被动性）**：若 `K_blend ≻ 0, D_blend ≻ 0` 且 `τ_ff_blend` 有界，则系统关于供给率 `s = τ_cmd^T ẋ` 严格被动。证明：`V = ½ ẋ^T M ẋ + ½ e^T K_blend e`，`V̇ = −ẋ^T D_blend ẋ + ẋ^T τ_ff_blend ≤ −λ_min(D)‖ẋ‖² + ‖ẋ‖‖τ_ff‖`。

**命题 IC-2（降级即稳定）**：三重降级后的阻抗包络 `K ∈ [K_min, K_max], D ∈ [D_min, D_max]` 保证存在 Lyapunov 函数使系统 ISS 稳定。关键：`ν>0.8 → K≤0.3K₀, D≥2D₀` 增加耗散；`p_failure>0.5 → K≤0.2K₀, D≥3D₀, τ_ff=0` 移除主动能量注入。

**命题 PE-1（物理外推泛化界）**：设 `f_phys2task` 在 Θ 上 L-Lipschitz，辨识误差 `‖θ̂ − θ_true‖ ≤ ε`，则任务量外推误差 `|f(θ̂) − f(θ_true)| ≤ L·ε`。**泛化上界由辨识精度决定，与声纹库覆盖无关**——新类别物体同等保证。

**命题 PE-2（反事实敏感度驱动采集最优）**：采集评分 `U_phys` 中的反事实敏感度项 `S_cf` 使贪心采集在参数空间覆盖 + 任务相关性上达 Pareto 最优。

## 6. 本轮最大的风险

### 1.3 阻抗感知融合控制器 IC-FUSE

**三路专家阻抗输出**（统一接口）：
```

合成器 π_s：      (x_s, ẋ_s, K_s=K*_phys, D_s=D*_phys, τ_ff_s)  # 物理外推最优阻抗
云端 VLA π_v：    (x_v, ẋ_v, K_v, D_v, τ_ff_v)                  # 升级时提供
```

**融合权重**（认知状态直接映射）：
```
α_K = γ_adjusted = γ_corrected · h_min · (1 − η·ν)    # 置信调制刚度权重 ∈ [0,1]
α_D = h_min                                           # 健康度调制阻尼权重 ∈ [0,1]
```

**阻抗融合核心公式**（解析解，零迭代）：
```
K_blend = α_K · K_s + (1 − α_K) · K_f                 # 刚度加权（置信高→信任合成器阻抗）
D_blend = α_D · D_s + (1 − α_D) · D_f                 # 阻尼加权（健康好→信任合成器阻尼）
x_blend = α_K · x_s + (1 − α_K) · x_f                 # 位置期望加权
ẋ_blend = α_K · ẋ_s + (1 − α_K) · ẋ_f
τ_ff_blend = α_K · τ_ff_s + (1 − α_K) · τ_ff_f
```

**执行器命令（标准阻抗控制律）**：
```
τ_cmd = K_blend · (x_blend − x) + D_blend · (ẋ_blend − ẋ) + τ_ff_blend
# x, ẋ 为当前关节位置/速度（1kHz 伺服环读取）
```

**三重降级 = 显式阻抗包络硬约束**（优先于融合公式，不可违背）：
```
def apply_degradation(K, D, τ_ff, p_f, h_min, ν):
    mode = "NONE"
    if p_f > 0.5:                     # 故障预警：极软、大阻尼、零前馈

        D = clip(D, 3.0 * D_nom, ∞)
        τ_ff = 0
        mode = "FAULT"
    elif h_min < 0.7:                 # 健康退化：大阻尼吸收震荡

        mode = "HEALTH"
    elif ν > 0.8:                     # 陌生物体：变软变阻尼（核心柔顺化）
        K = clip(K, 0, 0.3 * K_nom)
        D = clip(D, 2.0 * D_nom, ∞)
        mode = "NOVEL"
    return K, D, τ_ff, mode
```

**被动性与稳定性证明**：

> **命题 IC-1（严格被动性）**：若 `K_blend ≻ 0, D_blend ≻ 0` 且 `‖τ_ff_blend‖ ≤ τ_max`，则系统关于供给率 `s = τ_cmd^T ẋ` 严格被动。
> *证明*：取贮存函数 `V = ½ ẋ^T M ẋ + ½ e^T K_blend e`，其中 `e = x_blend − x`。
> `V̇ = ẋ^T M ẍ + e^T K_blend ė = ẋ^T (τ_cmd − τ_dist − D_blend ẋ) + e^T K_blend (−ẋ)`
> `    = ẋ^T (K_blend e + D_blend ẋ + τ_ff − τ_dist − D_blend ẋ) − ẋ^T K_blend e`
> `    = ẋ^T (τ_ff − τ_dist) ≤ ‖ẋ‖(τ_max + ‖τ_dist‖)` → 有限增益稳定，严格被动。∎

> **命题 IC-2（降级后 ISS 稳定）**：三重降级后的阻抗包络 `K ∈ [K_min, K_max], D ∈ [D_min, D_max]` 保证存在 Lyapunov 函数使系统输入-状态稳定 (ISS)。
> *证明*：降级后 `K_min = 0.2K_nom, D_min = 2D_nom`（最保守）。取 `V = ½ ẋ^T M ẋ + ½ e^T K_blend e`，
> `V̇ = −ẋ^T D_blend ẋ + ẋ^T τ_ff_blend ≤ −λ_min(D_min)‖ẋ‖² + ‖ẋ‖‖τ_ff_blend‖`。
> 当 `‖ẋ‖ > ‖τ_ff_blend‖/λ_min(D_min)` 时 `V̇ < 0`，满足 ISS 定义。∎

### 1.5 物理外推泛化器 PHYS-EXTRAP

**离线训练 `f_phys2task`（仿真大规模，程序化物体）**：
```
数据集 D_phys = {(θ_i, γ_i, h_i, K*_i, D*_i)}_{i=1..N=2M}
  θ_i ~ G_ψ(u), u ∈ ℝ¹² 覆盖物理参数空间 Θ

模型架构：共享骨干 + 4 任务头
  h_shared = MLP_backbone(θ_phys) ∈ ℝ²⁵⁶          # 3层 [256, 256, 128]
  γ̂ = Sigmoid(Linear(h_shared))                     # 刚度预测
  h = Sigmoid(Linear(h_shared))                    # 健康度预测
  K* = Softplus(Linear(h_shared)).diag()           # 对角刚度
  D* = Softplus(Linear(h_shared)).diag()           # 对角阻尼

损失函数：
ℒ_phys2task = ‖γ̂−γ‖² + ‖h−h_gt‖² + ‖K*−K*_gt‖²_F + ‖D*−D*_gt‖²_F
            + λ_lip · ‖∇_θ γ̂‖² + λ_lip · ‖∇_θ K*‖²_F  # Lipschitz 正则，保证外推平滑
```

**在线零样本外推**（运行时 <0.05ms）：
```
输入：θ_phys（辨识值），Σ_θ（辨识协方差）
前向：γ̂_phys, h_phys, K*_phys, D*_phys = f_phys2task(θ_phys)
不确定性传播（一阶近似）：
  u_phys = ‖∇_θ f(θ_phys)‖_F · sqrt(tr(Σ_θ))       # 标量不确定度
  # ∇_θ f 为 4×6 雅可比矩阵，离线预计算或在线自动微分
输出：(γ̂_phys, h_phys, K*_phys, D*_phys, u_phys)
```

**外推泛化界（命题 PE-1）**：
> 设 `f_phys2task` 在凸集 Θ 上 L-Lipschitz（由 Lipschitz 正则保证），辨识误差 `‖θ_phys − θ_true‖ ≤ ε`，则任务量外推误差满足：
> `|γ̂_phys − γ_true| ≤ L_γ · ε,  ‖K*_phys − K*_true‖_F ≤ L_K · ε`。
> **推论**：泛化上界由物理参数辨识精度 `ε` 决定，**与声纹库覆盖半径无关**——新类别物体只要 `θ_true ∈ Θ`，同等理论保证。

```python
class EPIdent(nn.Module):
    """可解释物理参数辨识器：概念瓶颈 + 注意力归因 + 不确定性量化"""
    def __init__(self, latent_dim=128, d_model=128, n_layers=4, phys_dim=6):
        super().__init__()
        self.inp = nn.Linear(latent_dim, d_model)
        self.pos = nn.Parameter(torch.randn(1, 50, d_model) * 0.02)
        layer = nn.TransformerEncoderLayer(d_model, nhead=4, dim_feedforward=256,
                                           batch_first=True, dropout=0.1)
        self.tr = nn.TransformerEncoder(layer, n_layers)
        # 概念瓶颈：显式物理参数
        self.theta_head = nn.Linear(d_model, phys_dim)           # θ_phys ∈ ℝ⁶
        self.sigma_head = nn.Linear(d_model, phys_dim)           # log σ²
        # 物理→任务映射头（轻量，共享骨干）
        self.task_backbone = nn.Sequential(
            nn.Linear(phys_dim, 128), nn.ReLU(),
            nn.Linear(128, 64), nn.ReLU()
        )
        self.gamma_head = nn.Sequential(nn.Linear(64, 1), nn.Sigmoid())
        self.h_head = nn.Sequential(nn.Linear(64, 10), nn.Sigmoid())  # 关节健康度
        self.K_head = nn.Sequential(nn.Linear(64, 6), nn.Softplus())  # 对角刚度
        self.D_head = nn.Sequential(nn.Linear(64, 6), nn.Softplus())  # 对角阻尼
        # 物理参数查询向量（用于注意力归因）
        self.phys_queries = nn.Parameter(torch.randn(3, d_model))  # mass, fric, stiff
    
    def forward(self, z_seq, return_attn=False, return_uncert=False):
        # z_seq: B×50×128
        h = self.inp(z_seq) + self.pos
        # 需要注意力权重：用自定义 forward
        attn_weights = []
        def hook(module, input, output):
            attn_weights.append(output[1])  # (B, heads, T, T)
        handles = [l.self_attn.register_forward_hook(hook) for l in self.tr.layers]
        h = self.tr(h)
        for h in handles: h.remove()
        
        cls = h[:, 0, :]                              # B×128
        theta = self.theta_head(cls)                  # B×6
        log_sigma2 = self.sigma_head(cls)
        sigma = torch.diag_embed(torch.exp(0.5 * log_sigma2))  # B×6×6
        
        task_feat = self.task_backbone(theta)         # B×64
        gamma = self.gamma_head(task_feat).squeeze(-1)
        h_health = self.h_head(task_feat)
        K = torch.diag_embed(self.K_head(task_feat))
        D = torch.diag_embed(self.D_head(task_feat))
        
        # 注意力归因
        attn_maps = {}
        if return_attn and attn_weights:
            # 平均跨层跨头，取 CLS 对各查询的注意力
            all_attn = torch.stack(attn_weights).mean(0).mean(1)  # B×50×50
            for i, name in enumerate(['mass', 'friction', 'stiffness']):
                q = self.phys_queries[i]              # 128
                attn_maps[name] = (all_attn[:, 0, :] * q.unsqueeze(0).sum(-1)).squeeze()  # 简化
        
        out = (theta, gamma, h_health, K, D)
        if return_uncert: out += (sigma,)
        if return_attn: out += (attn_maps,)
        return out


class PhysExtrap(nn.Module):
    """物理外推泛化器：离线训练 f_phys2task，在线零开销前向"""
    def __init__(self, phys_dim=6, hidden=256):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(phys_dim, hidden), nn.ReLU(),
            nn.Linear(hidden, hidden), nn.ReLU(),
            nn.Linear(hidden, hidden//2), nn.ReLU()
        )
        self.gamma = nn.Sequential(nn.Linear(hidden//2, 1), nn.Sigmoid())
        self.h = nn.Sequential(nn.Linear(hidden//2, 10), nn.Sigmoid())
        self.K = nn.Sequential(nn.Linear(hidden//2, 6), nn.Softplus())
        self.D = nn.Sequential(nn.Linear(hidden//2, 6), nn.Softplus())
        # 雅可比缓存（用于不确定性传播）
        self._jacobian_cache = None
    
    def forward(self, theta, sigma=None):
        # theta: B×6, sigma: B×6×6 (对角)
        feat = self.net(theta)
        gamma = self.gamma(feat).squeeze(-1)
        h = self.h(feat)
        K = torch.diag_embed(self.K(feat))
        D = torch.diag_embed(self.D(feat))
        
        u_phys = 0.0
        if sigma is not None:
            # 一阶不确定性传播：u = ‖J‖_F · sqrt(tr(Σ))
            J = self._compute_jacobian(theta)         # B×4×6
            J_norm = torch.norm(J, dim=(1,2))         # B
            tr_sigma = torch.diagonal(sigma, dim1=-2, dim2=-1).sum(-1)  # B
            u_phys = float((J_norm * torch.sqrt(tr_sigma)).mean())
        return gamma, h, K, D, u_phys
    
    def _compute_jacobian(self, theta):
        if self._jacobian_cache is not None:
            return self._jacobian_cache
        theta.requires_grad_(True)
        gamma, h, K, D, _ = self.forward(theta)
        J = torch.stack([
            torch.autograd.grad(gamma.sum(), theta, create_graph=False)[0],
            torch.autograd.grad(h.sum(), theta, create_graph=False)[0],
            torch.autograd.grad(K.diagonal(dim1=-2,dim2=-1).sum(), theta, create_graph=False)[0],
            torch.autograd.grad(D.diagonal(dim1=-2,dim2=-1).sum(), theta, create_graph=False)[0],
        ], dim=1)
        theta.requires_grad_(False)
        self._jacobian_cache = J
        return J

            {"id": "theta_fric", "type": "physics", "value": float(theta[1]), "unit": ""},
            {"id": "theta_stiff", "type": "physics", "value": float(theta[2]), "unit": "N/m"},
            {"id": "gamma_phys", "type": "task", "value": float(gamma)},

class ICFuse:
    """阻抗感知融合控制器：解析公式 + 三重降级硬约束"""
    def __init__(self, K_nom, D_nom, eta=0.5):
        self.K_nom = np.diag(K_nom) if np.isscalar(K_nom) else np.array(K_nom)
        self.D_nom = np.diag(D_nom) if np.isscalar(D_nom) else np.array(D_nom)
        self.eta = eta
    
    def fuse(self, x_f, K_f, D_f, tau_ff_f,
             x_s, K_s, D_s, tau_ff_s,
             gamma_corr, h_min, nu, p_f) -> Tuple[np.ndarray, str]:
        # 融合权重
        alpha_K = float(gamma_corr * h_min * (1.0 - self.eta * nu))
        alpha_D = float(h_min)
        alpha_K = np.clip(alpha_K, 0.0, 1.0)
        alpha_D = np.clip(alpha_D, 0.0, 1.0)
        
        # 阻抗融合
        K_blend = alpha_K * K_s + (1 - alpha_K) * K_f
        D_blend = alpha_D * D_s + (1 - alpha_D) * D_f
        x_blend = alpha_K * x_s + (1 - alpha_K) * x_f
        tau_ff_blend = alpha_K * tau_ff_s + (1 - alpha_K) * tau_ff_f
        
        # 三重降级硬约束
        mode = "NONE"
        if p_f > 0.5:
            K_blend = np.minimum(K_blend, 0.2 * self.K_nom)
            D_blend = np.maximum(D_blend, 3.0 * self.D_nom)
            tau_ff_blend = np.zeros_like(tau_ff_blend)
            mode = "FAULT"
        elif h_min < 0.7:
            D_blend = np.maximum(D_blend, 3.0 * self.D_nom)
            mode = "HEALTH"
        elif nu > 0.8:
            K_blend = np.minimum(K_blend, 0.3 * self.K_nom)
            D_blend = np.maximum(D_blend, 2.0 * self.D_nom)
            mode = "NOVEL"
        
        # 执行器命令（阻抗控制律）
        # 实际中 x, ẋ 从 1kHz 伺服环读取，此处返回参数供实时内核使用
        cmd = {
            "K_blend": K_blend, "D_blend": D_blend,
            "x_blend": x_blend, "tau_ff_blend": tau_ff_blend,
            "alpha_K": alpha_K, "alpha_D": alpha_D,
            "degrade_mode": mode
        }
        return cmd, mode


class PhysHarvest:
    """物理参数驱动主动采集：覆盖+熵+不确定性+反事实敏感度"""
    def __init__(self, phys_bank, sim_preview_fn, w=(1.0, 0.5, 0.3, 0.4, 0.2)):
        self.bank = phys_bank           # 物理参数库：增量 k-means 单元
        self.sim_preview = sim_preview_fn  # 仿真预演函数
        self.w1, self.w2, self.w3, self.w4, self.w5 = w
        self.cf_perturbations = [(0, 0.5), (0, -0.5), (1, 0.2), (1, -0.2), (2, 200), (2, -200)]
    
    def select_best(self, candidates: List[Dict], theta_curr, sigma_curr) -> Dict:
        best, best_score = None, -1e9
        for p in candidates:
            # 仿真预演获取预测物理参数、不确定性、成本
            preview = self.sim_preview(p)  # {"theta_hat": ..., "sigma": ..., "cost": ...}
            theta_hat = preview["theta_hat"]
            sigma = preview["sigma"]
            cost = preview["cost"]
            
            # 覆盖缺口
            G = self.bank.coverage_gap(theta_hat)
            # 后验熵（高斯近似）
            H = 0.5 * np.log((2*np.pi*np.e)**6 * np.linalg.det(sigma + 1e-6*np.eye(6)))
            # 不确定性迹
            tr_sigma = np.trace(sigma)
            # 反事实敏感度
            S_cf = 0.0
            for idx, delta in self.cf_perturbations:
                dtheta = np.zeros(6); dtheta[idx] = delta
                g1, _, K1, D1, _ = self._phys_extrap_fn(theta_hat + dtheta)
                g0, _, K0, D0, _ = self._phys_extrap_fn(theta_hat)
                S_cf += abs(float(g1 - g0)) + np.linalg.norm(K1 - K0) + np.linalg.norm(D1 - D0)
            
            score = self.w1*G + self.w2*H + self.w3*tr_sigma + self.w4*S_cf - self.w5*cost
            if score > best_score:
                best, best_score = p, score
        return best
    
    def _phys_extrap_fn(self, theta):
        # 占位：实际调用 PhysExtrap 前向
        return 0.5, np.ones(10), np.eye(6)*100, np.eye(6)*10, 0.0

class ICGZestPolicy:
    """ICG-ZEST 主策略：解释-柔顺-泛化三位一体"""
    def __init__(self, node_id, drs_client, mm_encoder, 
                 ep_ident: EPIdent, phys_extrap: PhysExtrap,
                 ic_fuse: ICFuse, causal_explain: CausalExplain,
                 phys_harvest: PhysHarvest,
                 # 并行保留第 21 轮组件（校验用）
                 od_clone, oc_head, synth, voicebank,
                 cmap_c, cmap_d, gamma_corr_fn):
        self.node_id = node_id
        self.drs = drs_client
        self.mm_encoder = mm_encoder
        
        # 本轮核心组件
        self.ep_ident = ep_ident
        self.phys_extrap = phys_extrap
        self.ic_fuse = ic_fuse
        self.causal_explain = causal_explain
        self.phys_harvest = phys_harvest
        
        # 并行校验分支（第 21 轮）
        self.od_clone = od_clone
        self.oc_head = oc_head
        self.synth = synth
        self.voicebank = voicebank
        
        # 通信/校准（第 20/21 轮）
        self.cmap_c = cmap_c
        self.cmap_d = cmap_d
        self.gamma_corr_fn = gamma_corr_fn
        
        # 状态
        self.T_ref = 50
        self.ref_buffer = []
        self.probe_queue = deque(["POKE", "PUSH", "LIFT", "SHAKE"])
        self.theta_phys = None          # 显式物理参数
        self.sigma_theta = None         # 辨识不确定性
        self.e_obj = None               # 声纹（校验用）
        self.u_obj = 0.0
        self.nu = 0.0
        self.degrade_mode = "NONE"
        self.attn_maps = None
        
        # 实时执行器（简化：实际下沉到 C++/RTOS）
        self.executor = ThreadPoolExecutor(max_workers=2)
        self.synth_future = None
        self.M_local = LocalSubMap()
        
        # 超参数
        self.eta = 0.5
        self.tau_consistency = 0.1
        self.K_nom = np.eye(6) * 200
        self.D_nom = np.eye(6) * 20
    
    # ---------- 白箱辨识：5秒参考交互 -> 显式物理参数 ----------
    def ensure_physics_identified(self, obs):
        if self.theta_phys is not None:
            return
        if not self.ref_buffer:
            self.probe_queue = deque(["POKE", "PUSH", "LIFT", "SHAKE"])
        self.ref_buffer.append(self.mm_encoder(self._obs2dict(obs)).squeeze(0))
        if len(self.ref_buffer) >= self.T_ref:
            z_seq = torch.stack(self.ref_buffer).unsqueeze(0)
            # EP-IDENT 前向：输出 θ_phys + 注意力归因 + 不确定性
            (self.theta_phys, self.gamma_phys, self.h_phys, 
             self.K_star, self.D_star, self.sigma_theta, self.attn_maps) = \
                self.ep_ident(z_seq, return_attn=True, return_uncert=True)
            
            # 并行声纹路径（校验用）
            e_stack = torch.stack([c(z_seq)[0].squeeze(0) for c in self.od_clone.ensemble])
            self.e_obj = e_stack.mean(0)
            self.u_obj = float(e_stack.std(0).mean())
            self.nu = self.voicebank.novelty(self.e_obj.detach().cpu().numpy(), self.u_obj)
            self.voicebank.add(self.e_obj.detach())
            
            self.ref_buffer.clear()
            self._check_consistency()
            self._log_ident_done()
    
    def _check_consistency(self):
        # 声纹路径预测
        z_dummy = torch.zeros(1, 128)
        a_dummy = torch.zeros(1, 18)
        d_knn = torch.tensor([self.voicebank.knn_distance(self.e_obj.cpu().numpy())])
        u_obj_t = torch.tensor([self.u_obj])
        gamma_voice, _, _, _, _, h_min_voice, _ = \
            self.oc_head(z_dummy, a_dummy, self.e_obj.unsqueeze(0), d_knn, u_obj_t)
        # 一致性检查
        self.consistency_pass = abs(float(self.gamma_phys) - float(gamma_voice)) < self.tau_consistency
        if not self.consistency_pass:
            self._trigger_reidentify()
    
    # ---------- 主控制循环 ----------
    def get_action(self, obs) -> np.ndarray:
        self.M_local.update(obs)
        _ = self.drs.get_weights()
        self.ensure_physics_identified(obs)
        
        if self.theta_phys is None:
            return self._execute_probe(obs)
        
        obs_dict = self._obs2dict(obs)
        z = self.mm_encoder(obs_dict, self._check_modality_availability(obs))
        a_fast = self._select_fast_action(obs)
        
        # ── 物理外推预测（主路径）──
        gamma_phys, h_phys, K_star, D_star, u_phys = \
            self.phys_extrap(self.theta_phys.unsqueeze(0), self.sigma_theta)
        
        # ── 声纹路径预测（校验用，异步/并行）──
        a_vec = self._act2vec(a_fast)
        d_knn = torch.tensor([self.voicebank.knn_distance(self.e_obj.cpu().numpy())])
        u_obj_t = torch.tensor([self.u_obj])
        gamma_voice, h_j, h_s, h_e, p_f, h_min, nu = \
            self.oc_head(z, a_vec, self.e_obj.unsqueeze(0), d_knn, u_obj_t)
        
        # 一致性检查
        consistency_pass = abs(float(gamma_phys) - float(gamma_voice)) < self.tau_consistency
        if not consistency_pass:
            self._trigger_reidentify()
        
        # ── 置信校准（KCL，第 20 轮）──
        gamma_c = self.cmap_c.compress(float(gamma_phys))
        gamma_corrected = float(self.gamma_corr_fn(self.cmap_d.decompress(gamma_c)).detach())
        
        # ── IC-FUSE：阻抗融合 + 三重降级 ──
        # 快策略阻抗输出
        x_f, K_f, D_f, tau_ff_f = self._fast_expert_impedance(obs)
        # 合成器阻抗输出（基于物理外推最优阻抗）
        x_s, K_s, D_s, tau_ff_s = self._synth_expert_impedance(obs, K_star, D_star)
        
        cmd, self.degrade_mode = self.ic_fuse.fuse(
            x_f, K_f, D_f, tau_ff_f,
            x_s, K_s, D_s, tau_ff_s,
            gamma_corrected, float(h_min), float(nu), float(p_f))
        
        # ── 生成结构化解释 ──
        xi = self.causal_explain.generate(
            theta_phys=self.theta_phys,
            attn_maps=self.attn_maps,
            gamma_phys=gamma_phys, gamma_voice=gamma_voice,
            h_phys=h_phys, h_voice=float(h_min),
            K_star=K_star, D_star=D_star,
            alpha_K=cmd["alpha_K"], alpha_D=cmd["alpha_D"],
            degrade_mode=self.degrade_mode,
            consistency_pass=consistency_pass)
        self._push_explanation(xi)
        
        # ── 执行器命令（阻抗参数下发给 1kHz 实时内核）──
        # 实际部署中：此处仅更新共享内存中的 K_blend, D_blend, x_blend, tau_ff
        # 1kHz 伺服环读取并计算 τ_cmd = K(x_d-x) + D(ẋ_d-ẋ) + τ_ff
        return self._pack_impedance_cmd(cmd)
    
    def _pack_impedance_cmd(self, cmd: Dict) -> np.ndarray:
        """打包阻抗命令给实时内核：[K_diag(6), D_diag(6), x_blend(6), tau_ff(6), mode_id]"""
        mode_id = {"NONE":0, "FAULT":1, "HEALTH":2, "NOVEL":3, "EXPERT":4}[cmd["degrade_mode"]]
        return np.concatenate([
            cmd["K_blend"].diagonal(),
            cmd["D_blend"].diagonal(),
            cmd["x_blend"],
            cmd["tau_ff_blend"],
            [mode_id]
        ]).astype(np.float32)
    
    # ---------- 采集：空闲时段物理参数驱动主动探测 ----------
    def on_idle(self, candidate_probes: List[Dict]) -> Optional[Dict]:
        return self.phys_harvest.select_best(candidate_probes, self.theta_phys, self.sigma_theta)
    
    def on_block_finished(self, success: bool, measured_theta: Optional[np.ndarray]=None):
        if self.theta_phys is not None:
            # 后见回标：实测物理参数 + 任务结果
            self._upload_hindsight_phys(self.theta_phys, success, measured_theta)
            # 反事实数据增强：生成邻域反事实样本
            self._generate_counterfactuals()
    
    # ---------- 内部辅助方法 ----------
    def _fast_expert_impedance(self, obs):
        # 快策略：固定名义阻抗，位置型 PD + 前馈
        x_f = self._policy_position(obs)
        return x_f, self.K_nom, self.D_nom, np.zeros(6)
    
    def _synth_expert_impedance(self, obs, K_star, D_star):
        # 合成器：基于物理外推最优阻抗的轨迹
        if self.synth_future is None:
            c = self._build_synth_cond(obs)
            self.synth_future = self.executor.submit(self.synth.sample, c, 8, 4)
        if self.synth_future.done():
            A_synth, _ = self.synth_future.result()
            self.synth_future = None
            x_s = A_synth[0, 0].cpu().numpy()  # 首步位置
        else:
            x_s = self._policy_position(obs)   # 回退
        return x_s, K_star.detach().cpu().numpy(), D_star.detach().cpu().numpy(), np.zeros(6)
    
    def _build_synth_cond(self, obs):
        # 条件：子目标嵌入 + θ_phys + 历史观测 + 快策略意图
        return torch.zeros(1, 274)  # 占位
    
    def _execute_probe(self, obs):
        primitive = self.probe_queue[0]
        return self._primitive_to_torque(primitive)
    
    def _primitive_to_torque(self, primitive):
        # 简化：返回探测原语对应的力矩命令
        return np.zeros(6)
    
    def _policy_position(self, obs):
        return np.zeros(6)
    
    def _act2vec(self, a): return torch.zeros(1, 18)
    def _obs2dict(self, obs): return {"vis":torch.zeros(1,4,256,256), "prop":torch.zeros(1,27), "force":torch.zeros(1,6), "tactile":torch.zeros(1,1,16,16)}
    def _check_modality_availability(self, obs): return {"vis":True, "prop":True, "force":True, "tactile":True}
    def _select_fast_action(self, obs): return "HOLD"
    def _trigger_reidentify(self): self.theta_phys = None; self.ref_buffer.clear()
    def _log_ident_done(self): pass
    def _push_explanation(self, xi): pass
    def _upload_hindsight_phys(self, theta, success, measured): pass
    def _generate_counterfactuals(self): pass


class LocalSubMap:

    def get_latest_obs(self): return {}
```

## 4. 本轮最大的风险

**物理参数辨识的本质不可辨识性：5 秒无损探测的 Fisher 信息矩阵可能对某些参数组合（质量-填充率耦合、摩擦-刚度耦合、CoM-惯量耦合）呈奇异或病态，导致 `θ_phys` 在极限下「原理上无法唯一辨识」；而概念瓶颈架构强制输出单一确定值，掩盖了根本的多解性——系统会「自信地给出错误物理参数」，进而通过物理外推产生「自信地错误的阻抗与预测」，且解释系统还会为这种错误生成看似合理的因果链，形成「可解释的幻觉」，比黑箱更具欺骗性。**

## 5. 灵感词贯通

> **可解释性**：概念瓶颈让「物理参数」成为中间可解释层（症状→疾病）；注意力归因揭示「哪段交互辨识了哪参数」（关键症状定位）；反事实生成回答「若参数变化预测如何变」（反事实推理）；结构化解释 ξ 让每步决策可审计、可注入、可追溯——**可解释性从事后可视化内生为架构骨干**。
> **柔顺控制**：阻抗控制的核心「用物理参数表达认知状态」被架构内生化——置信 `γ` 直接调制刚度 `K`，健康度 `h_min` 直接调制阻尼 `D`，新颖度 `ν` 直接收缩阻抗包络。三重降级不再是「轨迹权重裁剪」，而是「物理柔顺化」：陌生→变软变阻尼、退化→大阻尼、故障→极软零前馈。被动性与 ISS 稳定性有理论保证——**柔顺控制从隐式启发式升级为显式可证的核心机制**。
> **跨物体泛化**：从「声纹空间最近邻覆盖」跃迁到「物理参数空间外推」。EP-IDENT 辨识显式 `θ_phys`；PHYS-EXTRAP 通过 `f_phys2task(θ_phys)` 零样本外推任务量与最优阻抗。泛化上界由辨识误差 `‖Δθ‖` 决定，而非声纹距离——**新类别物体同样适用，无需声纹库覆盖，实现真正的零样本跨类别泛化**。
