# 灵感驱动研究循环·新灵感三元组第 1 轮；本轮灵感：「机器人操作系统」×「桌面操作」

> **基线**：第 2 轮产出 MetricVoiceGauge-NCD-HUTDH-v22 + IP-431–435（其上承 v21 语义-规范层 SDC/CAC/DCL/GIC、v20 联邦感知证书 PCA/CTS/CFC/HPC/CFCtrl、v19 DCM/OGCC/CCV/DRS/OGC、v17 CLP/S2C/HCG/PSV/APS/AMC）。
> **本轮纪律**：**操作系统不是"跑算法的容器"，而是把"证书的存在性与新鲜度"变成可调度、可审计的第一等资源；桌面操作不是"多一个场景"，而是第一次要求"受控接触"被合法化**。不推倒 v22：SDC/CAC/DCL/GIC/HDL/ACSC/DCSC/EVC/CFC++ 全部保留。本轮只做一件事：**在 v22 之上加一层"安全操作系统 + 受认证接触"层，把"避免碰撞"升级为"仅允许被认证的接触"，并封堵 v22 的最大风险（分层退化的层间振荡）**。

## 0. 直觉与动机

### 灵感 1（机器人操作系统）：安全证书是 OS 资源，不是函数返回值

直觉：v22 的证书本质上是"被调用的谓词"——它默认调用发生的那一刻，证书是新的、可靠的、被及时计算的。但在真实的 ROS 2 机器人上，证书由一堆异步节点产生：感知回调可能被规划线程饿死；TF 可能停在 300ms 之前；QoS 可能被配置成 best-effort 而静默丢帧；生命周期节点可能停在 `inactive`。于是"证书函数返回 true"与"证书当前为真"是两件不同的事。OS 视角给出三件补丁：

1. **证书即生命周期节点**：每张证书有 `INIT→CONFIGURED→ACTIVE→DEMOTE→INACTIVE→FINALIZED`；门只在 `ACTIVE` 且租约有效时承认它。
2. **QoS 即新鲜度契约**：把 DDS 的 reliability/durability/deadline/liveliness 显式解释为证书时效合同；违约不是"丢了一条消息"，而是"这张证书失效"。
3. **缺省拒绝（fail-closed）**：门必须区分"我收到了 SAFE"与"我什么都没收到"。`ALLOW` 需要全部门禁证书显式在场且有效；缺失/过期/被降级一律 `DEMOTE`，**绝不把沉默读成许可**。

再补两件与几何强相关的组件：**坐标变换完整性证书 (TIC)**——任何几何断言都在某个 frame 里，若 TF 链过期、断裂或外推，"框在 A 里不碰 B"毫无意义；**确定性回放见证 (DRW)**——用 rosbag2 + `/clock` 记录门判决的输入，使审计可离线重放出同一判决（这是审计证据，不是新的安全保证，必须诚实标注）。

严谨定义（直觉 → 形式）：
- 证书 `c = (pred_c, D_c, L_c, TTL_c, qos_c)`；有效谓词
  `Valid_t(c) ≜ (lc(c)=ACTIVE) ∧ (t − ts(c) ≤ D_c) ∧ alive(c) ∧ (t − ts(c) ≤ TTL_c)`。
- 门控 `Gate_t ≜ ALLOW ⟺ ⋀_{c∈C_req} Valid_t(c) ∧ pred_c(ζ_t)`；否则 `DEMOTE`。注意 `¬received(c) ⇒ ¬Valid_t(c)`，从结构上消灭 fail-open。
- 调度约束：安全域 `E_safe` 与感知域 `E_perc`、规划域 `E_plan` 隔离；优先级 `π_safe > π_plan > π_perc`，用优先级天花板协议防反转；准入
  `Σ_{i∈E_safe} WCET_i/T_i ≤ 1 − U_reserve`。
- TIC：`T_{w←f}(t) = ∏_i T_{i+1←i}(t_i)`，有效当且仅当所有 stamp 在 `D_TF` 内、相邻帧速度 `‖Δp‖/Δt ≤ v_max`、且不外推超过时域 `H_TF`。
- DRW：`h = H(输入流 ‖ 门判决流)`；只有可重放且哈希一致，才可作为审计见证。

反直觉点：**安全性的最大敌人常常不是感知误差，而是"沉默"**——漏发的 DENY、迟到的 SAFE、静默降级的 QoS，在谓词式证书里全都被读成"没有坏消息"。OS 层把"沉默"显式编码为拒绝。

### 灵感 2（桌面操作）：接触不是违规，而是必须被认证的对象

直觉：v22 的安全谓词是"所有对间距 > 0"，这在移动机器人里成立，在桌面操作里荒谬——抓取、放置、按压、插入都要求接触。真正的桌面安全不是"永不接触"，而是"**只接触被批准的那一对表面，且力、滑移、稳定都在界内**"。于是安全谓词从"无障碍"变成"**接触白名单 + 接触质量界**"：

- 任务给出被批准的接触流形 `K`（如 `(夹爪, 目标物)`、`(目标物, 桌面)`）；
- 任何不在 `K` 内的接触对仍是硬碰撞；
- `K` 内的接触必须满足法向力上限（防压碎）、摩擦锥/滑移裕度（防掉落）、冲量上限（防冲击）、准静态稳定裕度（防翻倒与堆叠坍塌）。

另外桌面场景让"缺席证书"更难：机械臂自身就是已知遮挡体，堆叠物体互相遮挡；若不把自遮挡从覆盖图里扣除，"桌上没人"的 AbsCert 会系统性高估自由空间。

严谨定义：
- 接触流形 `K ≜ {(a, b, Σ_{ab})}`（body 对 + 允许接触面片）。
- 计划 `π` 的接触事件集 `C(π) = {(a, b, τ, f_n, f_t, J)}`。
- 接触准入
  `CtAC(π) ≜ [C(π) ⊆ K] ∧ [∀(a,b)∉K: margin_{ab} > 0] ∧ [∀k∈C(π): 0 ≤ f_n ≤ f_max^{obj} ∧ s_k = 1 − |f_t|/(μ_s f_n) ≥ s_min ∧ J ≤ J_max] ∧ [η(π) ≥ η_min]`。
- 力估计须有界：`P(|f̂ − f| ≤ ε_f | sensor) ≥ 1 − α_f`；`f_max^{obj}` 本身带不确定区间，取保守下界。
- 支撑/抓取：支撑多边形 `P_s(o)`、质心投影 `c(o)`、稳定裕度 `m_s = dist(c, ∂P_s) ≥ m_min`；抓取质量
  `ε_grasp = max{ε : ∀w∈W_unc, ∃f∈FC_μ, G f = −w}`，要求 `ε_grasp ≥ ε_min`（**不确定性鲁棒力闭合**，而非名义力闭合）。
- 桌面域 `Ω_table`：物体不得穿越桌面；`AbsCert` 必须先扣除"自遮挡 + 已知遮挡体"掩码，否则拒发。

反直觉点：**把接触白名单 `K` 做成"几何安全的例外"是错的；正确做法是让 `K` 成为安全谓词的一部分**——安全不再等于"零接触"，而是"接触集合 ⊆ K 且接触质量达标"。

### 两者如何统一

统一为 **v23 = v22 ⊕ SOS-K ⊕ ContactCert**：

- SOS-K 管"证书是否在场、新鲜、被按时调度"，对全部 v22 证书一视同仁；
- CtAC/TSGC 管"接触是否被批准且质量达标"，只在接触模式生效；
- 动作空间被显式分区 `Π = Π_free ⊔ Π_contact`：`Π_free` 沿用 v22 的"零接触"安全继承；`Π_contact` 是**受守护的扩展**，不是 v22 的子集，其安全性由 CtAC 的"非 `K` 对仍零接触"来补。
- 关键纠正：不再声称整除的 `Exec_v23 ⊆ Exec_v22`，而是**分片安全继承**（见第 3 节）——这是本轮最需要诚实的地方。

## 1. 研究问题（轮次升级版）

- **Q12（安全 OS 的时效语义）**：如何把 DDS QoS（reliability/durability/deadline/liveliness）与证书租约、生命周期状态唯一地编译为 `Valid_t(c)`，使"消息丢失/过期/降级"恰好等价于"证书失效"而非"未知就可能安全"？如何证明门控不存在 fail-open 路径（包括回调饥饿、节点重启、时钟跳变）？

- **Q13（安全域的可调度性）**：安全门、看门狗、接触控制器必须在最坏情况下按时运行。如何在 ROS 2 executor 模型下给出 `E_safe` 的 WCET/周期界与优先级天花板配置，使 `Σ WCET_i/T_i ≤ 1 − U_reserve` 可静态核验，并对感知/规划的抖动免疫？

- **Q14（TF 与几何证书的耦合）**：几何证书在哪个 frame 求值、使用哪条 TF 链、允许多大的时间外推？TIC 如何与 v17 APS 新鲜度阶梯、v22 CAC 覆盖图对齐，使"TF 过期"必然使 CertBox/AbsCert 失效而不是悄悄用旧变换？

- **Q15（受认证接触的质量界）**：如何由力/力矩与本体感知的 conformal 误差界得到 `f_n`、`f_t`、`J` 的保守界，并保证压碎、滑移、冲击三条约束同时成立？`K` 在任务执行中被世界变化（物体被换走、人插入手、桌面移动）破坏时，如何以最小时延撤销接触许可？

- **Q16（桌面支撑与抓取鲁棒性）**：如何在 pose/mass/friction 不确定集 `W_unc` 上计算鲁棒力闭合质量 `ε_grasp` 的保守下界，并与 CTS 类先验、SDC 定位误差界衔接？堆叠/支撑的静态稳定裕度如何与接触力界联合求解？

- **Q17（接触模式与负信息的交互）**：机械臂自遮挡与堆叠遮挡如何从 `Cov_t` 中扣除，使"桌面无人"的 AbsCert 不被自有手臂的盲区伪造？GIC 的"手势 ⇒ 有人"条款在桌面交接场景下如何与 CTAC 的 `(人, 物体)` 接触对协调？

## 2. 设计原则（在 P34–P42 基础上新增 P43–P46）

**P43 证书时效律（Certificate Freshness & Fail-Closed）**
任意门禁证书 `c` 只有在 `Valid_t(c)` 成立时有效；`Valid_t(c)` 要求生命周期 `ACTIVE`、`t − ts(c) ≤ D_c`、liveliness 存活、租约未过期。门控为合取式：`Gate_t = ALLOW ⟺ ⋀ Valid_t(c) ∧ pred_c`。**缺失、过期、静默降级、节点重启都映射为 `¬Valid_t`，从而 `DEMOTE`**；系统不得提供任何"默认允许"分支。安全域内部禁止阻塞式等待与无界队列。

**P44 安全域调度隔离律（Safety-Domain Scheduling Isolation）**
安全门与看门狗运行在独立 executor/线程域 `E_safe`，与 `E_perc`、`E_plan` 之间通过无锁快照交换证书，不得共享可变锁。`E_safe` 采用固定优先级 + 优先级天花板（或 `SCHED_DEADLINE` 等价物），准入条件 `Σ_{i∈E_safe} WCET_i/T_i ≤ 1 − U_reserve` 必须在上线前静态核验。任一域超时触发看门狗 `DEMOTE`，而非继续使用陈旧证书。

**P45 受认证接触律（Certified Contact Admissibility）**
计划 `π` 的每次接触必须落在批准流形 `K` 内；`K` 外接触对保持严格正裕度；`K` 内接触满足 `f_n ≤ f_max^{obj}`、滑移裕度 `s_k ≥ s_min`、冲量 `J ≤ J_max`、准静态稳定 `η ≥ η_min`。`K` 是**带版本与 TTL 的一等对象**：世界状态变化（物体替换、人员进入、桌面移动）立即失效 `K`，接触模式回退到 `Π_free`。任何力界必须由带 conformal 覆盖的估计给出，不得使用名义值。

**P46 分片安全继承律（Mode-Partitioned Safety Inheritance）**
将动作空间分为 `Π = Π_free ⊔ Π_contact`。自由分片保持完整继承：`Exec_v23[Π_free] = Exec_v22 ∩ Fil_sos ∩ Valid(TIC) ⊆ Exec_v22`。接触分片是受守护扩展：`Exec_v23[Π_contact] = {π ∈ Π_contact : CtAC(π) ∧ TSGC(π) ∧ NonK-Invariants(π) ∧ SOS-K ∧ TIC}`，其中 `NonK-Invariants` 要求所有非 `K` 对仍满足 v22 的碰撞裕度。**因此 `Exec_v23` 不同 v22 构成全局子集关系，但在"非 `K` 对"上永不放松**；这一分离必须写进安全论证，不得含糊地宣称整除继承。

## 3. 与基线的接口（分片退化）

- SOS-K 失效（调度/看门狗/时钟异常）⇒ 全部证书 fail-closed ⇒ 退回 v22 纯避碰并保持/停机；
- TIC 失效（TF 断裂/过期/外推超限）⇒ 一切几何证书失效 ⇒ 保持不动，不签发新 CertBox/AbsCert；
- CtAC 失效或 `K` 过期 ⇒ 接触模式禁用 ⇒ 仅 `Π_free`，等价 v22；
- TSGC 失效 ⇒ 不抓取、不搬运、不堆叠，仅自由运动；
- DRW 失效 ⇒ 审计缺口（安全不受影响，但任务不可交付审计证书，按规范可选用停机）；
- `Π_free` 分片：`Exec_v23[Π_free] ⊆ Exec_v22`；
- `Π_contact` 分片：非 `K` 接触恒为零，`K` 内满足质量界；不与 v22 构成子集，但不与 v22 的避碰目标冲突；
- 全失效 ⇒ 完全回退 v22 ⇒ `Exec_v23[Π_free] ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20`。

## 4. 预期贡献

1. **证书时效的形式化与 fail-closed 门控**：把 QoS/生命周期/租约统一为 `Valid_t(c)`，从结构上消灭"沉默即许可"的 fail-open；
2. **安全域调度隔离与可调度性证明**：WCET/周期/优先级天花板配置 + 声明式准入检查，使 50Hz 安全环对感知/规划抖动免疫；
3. **TIC**：把 TF 完整性变成几何证书的前置条件，封堵"用旧变换证明不碰"的隐蔽失效；
4. **受认证接触 CtAC**：首次把"接触"从违规变成带力、滑移、冲量、稳定界的一等安全对象；
5. **不确定鲁棒力闭合与桌面支撑证书 TSGC**：在 pose/mass/friction 不确定集上给出抓取与堆叠稳定的保守判据；
6. **分片安全继承 P46**：诚实区分"避碰子集"与"受守护接触扩展"，避免用一个错误的全集包含关系掩盖接触风险。

## 5. 本轮最大风险

**一句话**：只要 ROS 2 的 QoS、executor 或生命周期任一处配置/实现让"DENY / SAFE 证书"静默丢失、被饥饿或过期，fail-closed 就会在中间件层面被悄悄改写成 fail-open；而接触模式又让机器人主动去碰，于是"没收到禁止"会被执行成一次"认证的"碰撞。

| `NonK-Invariants(π)` | 所有非 `K` 接触对仍满足 v22 正碰撞裕度 |
| `Exec_v23[Π_free]` | 自由分片执行集 `= Exec_v22 ∩ Fil_sos ∩ Valid(TIC)` |
| `Exec_v23[Π_contact]` | 接触分片执行集（受守护扩展，非 v22 子集） |
| `Exec_v23` | `Exec_v23[Π_free] ∪ Exec_v23[Π_contact]` |
| `DRW.h` | 回放见证哈希 `H(输入流 ‖ 判决流)` |
| `Verdict` | {ALLOW, DEMOTE, SAFESTOP} |

## 1. 关键算法骨架（在 IP-431–435 骨架上扩展）

```python
from dataclasses import dataclass, field
from enum import Enum
import hashlib, time

class Verdict(Enum):
    ALLOW = "ALLOW"
    DEMOTE = "DEMOTE"
    SAFESTOP = "SAFESTOP"

# ---------- IP-436 Safety Operating System Kernel ----------
class SafetyOSKernel:
    """合取式 fail-closed 门：缺任何一张证书都是 DEMOTE。"""
    def __init__(self, required, reserve_util=0.10):
        self.required = tuple(required)      # C_req: 证书名字元组
        self.reserve_util = reserve_util

    def admit(self, certs: dict, now: float) -> tuple[Verdict, str]:
        # 关键：不允许任何 default-allow 分支
        for name in self.required:
            c = certs.get(name)
            if c is None:
                return Verdict.DEMOTE, f"ABSENT:{name}"      # 沉默=拒绝
            if c.lc != "ACTIVE":
                return Verdict.DEMOTE, f"LIFECYCLE:{name}"
            age = now - c.stamp
            if age > c.D or age > c.TTL:
                return Verdict.DEMOTE, f"STALE:{name}:{age:.3f}"
            if not c.alive():
                return Verdict.DEMOTE, f"LIVENESS:{name}"
            if not c.pred():
                return Verdict.DEMOTE, f"PRED_FALSE:{name}"
        return Verdict.ALLOW, "OK"

    def schedulable(self, tasks):
        # tasks: [(WCET_i, T_i)]；静态可调度性准入
        util = sum(w / t for w, t in tasks)
        return util <= 1.0 - self.reserve_util, util

# ---------- IP-437 Certificate Freshness–QoS Bridge ----------
def cert_from_qos(msg, deadline_qos, liveliness_alive, lc="ACTIVE"):
    """把 DDS deadline/liveliness 解释成证书时效；deadline 缺省(0)视为不设保
    证 → 一律 DEMOTE（不安全默认）。"""
    if deadline_qos is None or deadline_qos <= 0:
        return None                      # 不产生"看起来有效"的证书
    return Cert(
        stamp=msg.header.stamp.to_sec(),
        D=deadline_qos,
        TTL=deadline_qos,                # 与 deadline 对齐
        lc=lc,
        alive=liveliness_alive,
        pred=lambda: msg.safe,
    )

# ---------- IP-438 Transform Integrity Certificate ----------
class TransformIntegrity:
    def __init__(self, tf_buffer, D_TF=0.05, H_TF=0.10, v_max=2.0):
        self.tf, self.D_TF, self.H_TF, self.v_max = tf_buffer, D_TF, H_TF, v_max

    def valid(self, target, source, t) -> tuple[bool, str]:
        try:
            chain = self.tf.chain(target, source, t)   # [(frame, stamp, T)]
        except LookupError:
            return False, "TF_BROKEN"
        prev = None
        for _, stamp, T in chain:
            if t - stamp > self.D_TF:
                return False, f"TF_STALE:{stamp:.3f}"
            if stamp - t > self.H_TF:                  # 不允许过度外推
                return False, "TF_EXTRAPOLATED"
            if prev is not None:
                dt = max(stamp - prev[0], 1e-6)
                v = ((T.translation - prev[1].translation).norm() / dt)
                if v > self.v_max:
                    return False, f"TF_DISCONTINUITY:{v:.2f}"
            prev = (stamp, T)
        return True, "OK"

# ---------- IP-439 Contact Admissibility Certificate ----------
class ContactAdmissibility:
    def __init__(self, K, K_ver, K_ttl, f_max, mu_s, s_min,
                 J_max=5.0, eta_min=0.05, alpha_f=0.01):
        self.K, self.K_ver, self.K_ttl = K, K_ver, K_ttl
        self.f_max, self.mu_s, self.s_min = f_max, mu_s, s_min
        self.J_max, self.eta_min, self.alpha_f = J_max, eta_min, alpha_f

    def admits(self, plan, world_version, now):
        if world_version != self.K_ver or now - self.K.stamp > self.K_ttl:
            return False, "K_STALE"                     # 世界变了，接触许可作废
        for (a, b, tau, fn_hat, ft_hat, J) in plan.contacts:
            if (a, b) not in self.K.pairs:
                return False, f"UNSANCTIONED_CONTACT:{a}-{b}"
            # conformal 误差上界：用保守上界 fn+f vs 下界似然
            fn = fn_hat + plan.eps_f                 # 保守：法向取上界
            ft = abs(ft_hat) + plan.eps_f
            if fn < 0 or fn > self.f_max:
                return False, f"CRUSH_RISK:{fn:.2f}"
            if fn <= 1e-9 or (1.0 - ft / (self.mu_s * fn)) < self.s_min:
                return False, "SLIP_RISK"
            if J > self.J_max:
                return False, "IMPULSE"
        if plan.eta < self.eta_min:
            return False, "QUASI_STATIC_UNSTABLE"
        return True, "OK"

    def non_k_invariants(self, plan, margin_fn):
        # K 之外仍要求 v22 正碰撞裕度
        return all(margin_fn(a, b) > 0
                   for (a, b) in plan.collision_pairs if (a, b) not in self.K.pairs)

# ---------- IP-440 Tabletop Support & Grasp Certificate ----------
class TabletopSupportGrasp:
    def __init__(self, m_min=0.02, eps_min=1.0, n_wrench_samples=256):
        self.m_min, self.eps_min, self.ns = m_min, eps_min, n_wrench_samples

    def support_margin(self, support_poly, com_xy):
        return min(dist_point_to_segment(com_xy, a, b)
                   for a, b in edges(support_poly))

    def admits_support(self, obj):
        if obj.com_z < obj.table_z:                     # 穿桌
            return False, "PENETRATE_TABLE"
        m = self.support_margin(obj.support_poly, obj.com_xy)
        if m < self.m_min:
            return False, f"TIP_OVER:{m:.3f}"
        return True, "OK"

    def robust_force_closure(self, G, W_unc):
        """在采样 wrench 集上取最小可行 ε（保守下界）。"""
        eps_best = float("inf")
        for w in W_unc.sample(self.ns):
            eps_w = 0.0
            for f in FC_μ.sample_directions():          # 摩擦锥离散
                if (G @ f + w).norm() <= 1e-6:
                    eps_w = max(eps_w, FC_μ.margin(f))
            eps_best = min(eps_best, eps_w)
        return eps_best

    def admits_grasp(self, obj):
        eps = self.robust_force_closure(obj.G, obj.W_unc)
        if eps < self.eps_min:
            return False, f"WEAK_GRASP:{eps:.2f}"
        return True, "OK"

# ---------- IP-441 Deterministic Replay Witness ----------
class ReplayWitness:
    def __init__(self, bag_writer):
        self.bag, self.h = bag_writer, hashlib.sha256()

    def record(self, now, certs, verdict):
        payload = repr((round(now, 6),
                        {k: (v.stamp, v.lc, v.D) for k, v in certs.items()},
                        verdict.value)).encode()
        self.h.update(payload)
        self.bag.write("/safety/gate", now, payload)

    def replay_hash(self, reader):
        h = hashlib.sha256()
        for rec in reader.read("/safety/gate"):
            h.update(rec.data)
        return h.hexdigest()

# ---------- v23 分片准入 ----------
def admits_v23(plan, ctx):
    sos, why = ctx.sos.admit(ctx.certs, ctx.now)
    if sos is not Verdict.ALLOW:
        return False, f"SOS:{why}"
    ok, why = ctx.tic.valid(ctx.base_frame, plan.frame, ctx.now)
    if not ok:
        return False, f"TIC:{why}"

    if plan.mode == "FREE":
        # 完整继承 v22：自由分片是 v22 的子集
        return ctx.v22.admits(plan) and (not plan.contacts)

    if plan.mode == "CONTACT":
        ok, why = ctx.ctac.admits(plan, ctx.world_version, ctx.now)
        if not ok:
            return False, f"CTAC:{why}"
        if not ctx.ctac.non_k_invariants(plan, ctx.v22.margin):
            return False, "NON_K_COLLISION"
        ok, why = ctx.tsgc.admits_support(plan.obj)
        if not ok:
            return False, f"TSGC_SUPPORT:{why}"
        ok, why = ctx.tsgc.admits_grasp(plan.obj)
        if not ok:
            return False, f"TSGC_GRASP:{why}"
        return True, "OK"

    return False, "UNKNOWN_MODE"
```

## 2. 分片安全继承的推导（命题 163）

**命题 163（分片安全继承）** 设 `Exec_v22` 为 v22 通过计划集，`Fil_sos` 为 SOS-K 门控过滤器，`TIC` 为坐标完整性谓词。则

1. `Exec_v23[Π_free] = Exec_v22 ∩ Fil_sos ∩ Valid(TIC) ⊆ Exec_v22`；
2. `Exec_v23[Π_contact]` 不保证为 `Exec_v22` 子集，但满足
   `∀π ∈ Exec_v23[Π_contact]: NonK-Invariants(π) ∧ CtAC(π) ∧ TSGC(π)`；
3. 任一组件失效时 `Exec_v23[Π_contact] = ∅`，系统退回 `Π_free`，故不存在"接触模式悄悄放行"的路径。

**证明梗概**
(1) 由 `admits_v23` 的自由分支直接求交，且额外要求 `plan.contacts = ∅`，故为子集。
(2) 接触分支显式检查 `NonK-Invariants`（所有非 `K` 对正裕度）与 CtAC（`K` 内力/滑移/冲量/稳定界）；这些条件只约束接触对，不隐含 v22 的全域零接触，故不能推出子集——这是**结构性事实**，必须显式写进安全论证，不能靠"看起来像"蒙混。
(3) 接触分支的每个 `return` 都要求 `K` 未过期、`CtAC` 与 `TSGC` 通过；SOS/TIC 任一 `DEMOTE` 在分支之前返回 `False`，因此接触计划在失效时不可达。∎

> **审计含义**：v23 的安全性由两条互不替代的论证组成——自由分片的整除继承，以及接触分片的"非 `K` 对零接触 + `K` 内质量界"。把两者合并成一句 `Exec_v23 ⊆ Exec_v22` 是错误且危险的。

## 4. 本轮结论与最大风险

**结论**：v23 把"证书"从函数返回值升级为**带生命周期、时效契约与调度保证的 OS 资源**，并首次把"接触"从安全违规变成需被认证的白名单对象；关键代价是必须诚实采用**分片安全继承**，而非虚假的整除包含。

**最大风险（一句话）**：只要 ROS 2 的 QoS、executor 或生命周期任一处让"DENY / SAFE 证书"静默丢失、被饥饿或过期，fail-closed 就会在中间件层面被改写成 fail-open，而接触模式又让机器人主动去碰——"没收到禁止"会被执行成一次认证的碰撞。
