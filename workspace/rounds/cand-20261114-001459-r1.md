# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「少样本学习」×「VLA」）

> R69 提出了一个漂亮的问题：「我该向谁求证」。但它默认了三件幸运的事：**(a) 技能已经在策略里**（否则问了也不会做）、**(b) 语言已经接地**（否则「把杯子放那儿」里的「那儿」本来就不可执行）、**(c) 模态分布已经校准**（否则 VoI 是建立在错信念上的追问）。一旦面对新物体、新任务、新本体，这三条同时失效——R69 会在一个它根本不具备的技能上，非常有礼貌地提问，然后把一次误导性回答盖章为「已验证」。
>
> 本轮两个灵感各补一条腿：
> - **VLA（Vision-Language-Action）** 给出一个互联网规模预训练的「语义-动作先验」与语言接地通道——它不擅长精确控制，却极擅长回答「这句话大概指的是哪个物体、哪类技能」；
> - **少样本学习**给出一种把「一次演示」快速变成「可执行假设」的机制——演示是全带宽证据，但也是最危险的证据：一条演示足以种下一个技能，也足以种下一个偏见。
>
> 核心命题：**把「演示」提升为一等证据动作，把 VLA 冻结为慢速语义先验、把 R69 的流匹配策略保留为快速几何执行器；语义歧义（做什么/指哪个/为什么）交给 VLA + 演示，几何歧义（怎么走/放多高）交给 R69；少样本适配一律走「非参数证据条件化 + 认证的离线写」，任何一次适配必须先通过可迁移性、低样本校准、演示投毒、语言接地四道门，否则逐指令退化为 R69。** 命名 **FLAIR-RAS**（Few-shot, Language-grounded, Action-Intention Refinement for Risk-adaptive systems；先验如棱镜，把少量支撑证据折射成可执行的假设）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这一课我该不该学、能不能信**」——少样本不是免费的学习，而是借来的证据；借来的证据要付「泛化间隙」的利息。

## 0. 直觉与动机

**灵感 1（少样本 → 「少样本」的本质不是「数据少」，而是「证据少」）**
直觉：在 R69 的框架里，证据来自传感器残差与主动交互（看/问/触）。演示（demonstration）是一种被严重低估的证据：一条人类演示同时编码了目标（做什么）、指代（指哪个）、几何（怎么做）、以及执行者的偏好（偏好哪种做法）。它不是「训练数据」，而是一个**高带宽、经过人类压缩、但带有来源偏置的证据包**。因此正确的姿态不是「拿它去微调」，而是「把它放进 R69 的证据集 ℰ 里，参与同一套证据纪律、同一套投毒威胁模型」。这样少样本学习就从「模型训练问题」变成了「证据条件化推断问题」——和闭环安全同构，而不是另起一套需要独立信任的黑箱。

**灵感 2（VLA → 慢速语义先验 × 快速几何执行器）**
直觉：VLA 的本质优势不是控制精度，而是**跨本体的语义泛化与语言接地**：它见过海量「图像 + 指令 + 动作」，所以能对「把红色那块放进左边的盒子」给出一个语义上大致正确的技能模式。但 VLA 推理重（数十亿参数）、动作粗、且会「流畅地幻觉」。R69 的流匹配策略恰好相反：轻、快、连续、几何精确，但语义先验弱。于是自然的架构是**双速率**：VLA 在 1–10Hz 的慢环里当「语义顾问」输出技能模式与接地分；FMP 在数百 Hz 的快速环里在给定模式下做几何细化与安全认证。**语义歧义用慢而宽的先验解，几何歧义用快而窄的执行器解**——这把 R69 的一维「模态」拆成了语义与几何两层，各自用最合适的工具。

**灵感 3（演示是最高带宽的信息动作，也是最危险的）**
直觉：R69 的信息动作是看、问、触。还有第四种、也是信息量最大的：**「请演示一次」**。一次演示的 VoI 常常高于十次注视，因为它直接给出一个可执行轨迹。但它的成本与风险也最高：占用人类时间、可能诱导演示者进入危险姿态、而且演示**本身可能是错的/恶意的/不适合本体的**。更微妙的是：问一句错了，系统还可以再问；学一条演示错了，系统会把这个错误当成先验，后续所有推理都被它条件化——**错误会自我强化（evidence adsorption）**。所以「请演示」必须是 MINT 里最严格受控的动作：高 VoI，但必须配「演示审计 + 可回滚」。

**灵感 4（小样本会制造「自信的泛化」）**
直觉：N=1 时，经验风险恒为 0——模型可以完美拟合这一条演示，却可能学到了背景颜色、桌面纹理、演示者的手部习惯。R69 的模态校准门（MCG）在互联网规模数据上还有意义，在 N=1 上几乎无法估计 ECE。**支撑集是假设生成器，不是证书颁发机构。** 因此低样本校准必须换工具：共形预测（在可交换性下给有限样本覆盖保证，哪怕 N 很小）、留一法元验证（用 N−1 条拟合、第 N 条检验）、以及「先验-支撑一致性」检查——当 VLA 先验与演示证据冲突时，不许任何一方单独胜出。

**灵感 5（冻结先验 + 写门 + 回滚，才能不破坏 R69 的不变式）**
直觉：R69 的铁律之一是「实时流零学习写操作」。少样本适配如果在线改权重，就直接破坏这条铁律，并引入不可审计的漂移。正确做法是：**运行时的「适配」只是非参数条件化**——检索支撑原型、拼进上下文、调制 Flow 的初始噪声/条件向量，**不写权重**；真正的参数适配只允许在「维护窗口」里发生，且必须过写门（DWA）与证书。任何一次写都可回滚，回滚后逐指令退化为写入前策略。这样「学习」被放进了可审计、可撤销的容器里。

**灵感 6（新威胁模型：演示投毒、捷径、先验-支撑共谋、指令注入）**
直觉：R69 已经担心「人会撒谎」。R70 的信任面更大：人会演示一个**看起来正确但会诱发危险泛化**的动作；演示者可能只演示成功样本（选择偏差）；VLA 的语言先验可能被对抗性指令注入劫持；更隐蔽的是「先验-支撑共谋」——VLA 先验和演示恰好都指向同一个错误答案（例如都受同一背景偏置影响），于是 R69 的证据纪律「两个正交源一致」会误判为「已验证」。**相关证据不是独立证据**，演示与先验往往高度相关，必须做「来源独立性审计」，否则一致性纪律形同虚设。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（FLAIR-RAS 总览）** FLAIR-RAS = (VGA, MSR, SAD, ADV, MCC, APG, GCC, DWA, SAA, FMA†, RAS-WM‡)。五条不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i；适配只允许非参数条件化或经写门的离线写）；
(ii) **适配包含性（adaptation containment）**：少样本适配只能在基准控制器已认证的安全包络内**重新加权/重塑**策略，不得扩大包络（定义 318）；
(iii) **交互预算硬约束**（继承 R69，新增演示预算：单位时间演示 ≤ 1 次，演示占用人类时间 ≤ h_max，演示动作本身须过 C-RAS-WM）；
(iv) **证据纪律**（继承并加强 R69：演示/先验属于**相关证据源**，不得互相充当「第二个正交源」，定义 325）；
(v) **可回滚性**：任何适配写都有唯一版本号与回滚点，回滚后行为逐指令等于写入前（定义 323）。

**定义 311（VLA 语义先验 VGA）** 冻结 VLA `Φ_VLA(v_t, l_t, p_t)` 输入视觉 v、语言指令 l、本体状态 p，输出语义模式分布 `π_sem(m^s | v,l,p)` 与动作 token 序列的粗解码 `ã`。只取其对**语义模式**的判别，不用其原始动作做控制。接地分 `g_gr = log π_sem(m^s_obs | v,l,p)`（观测到的行为在该指令下的语义似然）。跨本体时允许替换末端适配层（动作头），语义编码器冻结。

**定义 312（支撑集与情节证据）** 演示记忆 `S = {(o_i, l_i, ξ_i, ρ_i)}_{i=1..N}`，含观测、指令、轨迹、来源元数据 ρ_i（演示者、时间、可信度、是否成功）。一次「情节」把 S 按可交换假设切为支撑 `S_sup` 与查询 `S_qry`。`N` 通常为 1–10，**N=0 时 FLAIR 必须逐指令退化为 R69**（退化锚点）。

**定义 313（少样本适配算子 A_fs）** `A_fs(π_base, S_sup)` 有两种合法形态：
(a) **非参数条件化**（默认，运行时）：`π_adapt(ξ|o) ∝ π_base(ξ|o) · exp(β·K(o, S_sup)) · w(m^s)`，其中 `K` 为支撑原型核（定义 315），`w` 为语义模式权重；**不修改任何参数**；
(b) **认证离线写**（可选，维护窗口）：参数高效适配（adapter/LoRA），必须通过 DWA（定义 323）并记录版本。运行时不启用 (b) 的在线更新。
关键：`A_fs` 只改变「在已认证包络内如何选/如何走」，不改变包络本身。

**定义 314（语义-几何双层歧义分解 SAD）** 在 R69 的 AUD 之上，把可约不确定性细分为：
- `U_sem`：语义模式身份熵 `H(m^s)`（做什么/指哪个/为什么）；
- `U_geo = H_mode · g(Δ_min)`：R69 原有的几何模态间可约歧义（怎么走）；
- `U_adapt`：支撑充分性项 `∝ 1/√N_eff` 或留一法误差（这一课的证据够不够）；
- `U_ground`：语言接地熵 `H(m^s | l)` 与 `π_sem` 的校准偏差（指令是否可接地）。
`U_ale` 仍由 R69 的模态内协方差给出。四者可约项分通道处置，不做简单加和。

**定义 315（支撑原型与检索核 MSR）** 对每条演示抽取「状态-动作」原型：`φ_i = Enc(o_i, l_i, ξ_i)`；检索核 `K(o,S) = max_i ⟨ψ(o), φ_i⟩ / τ`（或 top-k 平滑）。原型既是条件化信号，也是**异常参照**：`r_sup(o,ξ) = min_i d(φ(o,ξ), φ_i)`，支撑残差高说明当前行为不在演示覆盖域内（定义 324）。

**定义 316（演示价值 Demo-VoI 与增广信息动作 ADV）** 新增信息动作 `g_demo ∈ 𝒜_info`（请求演示）。`VoI_demo(g) = H(m^s|o) − E_{y~p(·|g,o)}[H(m^s|o,y)]`，且 `g* = argmax_g [VoI(g) − c(g)]`，其中 `c(demo) = h_human + risk_g + λ_r·irreversibility`。关键约束：**演示只能提出假设，不能单独授予证书**；`g_demo` 的采纳仍须过 MCC + APG + GCC。

**定义 317（低样本元共形校准 MCC）** 升级 R69 的 MCG。对语义模式定义非一致性分 `s_i = 1 − π_sem(m_i | x_i)`；在校准情节 `S_qry` 上取 `q = ⌈(N+1)(1−α)⌉/N` 分位。预测集 `C(x) = {m : s(x,m) ≤ q}`。有限样本、仅需可交换性，得 `P(m* ∈ C) ≥ 1−α`。ECE 由离散度与 `N` 决定：`ECE ≤ O(N^{-1/2}) + ε_disc`（诚实声明：小 N 下覆盖率可保证，逐点 ECE 不可保证）。

**定义 318（适配包含性约束）** 设基准闭环（R69）的认证安全包络为 `Env(x) = {ξ : C-RAS-WM(ξ) ≤ ε}`。适配策略必须满足 `supp π_adapt ⊆ Env(x)`，且对任意 `ξ ∈ Env` 的**执行**不变；适配只允许改变 `Env` 内各候选的权重与细化路径。形式化：`R_worst(π_adapt) ≤ R_worst(π_base)`（在包络定义不变的前提下），否则适配被拒（APG 拒绝）。

**定义 319（先验-支撑共识门 APG）** 输入 VLA 语义分布 `π_sem` 与演示支撑分布 `π_sup`（由 S_sup 的核密度估计）。定义冲突度 `χ = W_2(π_sem, π_sup)/σ_scale`。规则：
- `χ ≤ χ_lo`：一致，可融合；
- `χ_lo < χ ≤ χ_hi`：**不融合**，向人类澄清（一次 ask，走 R69）或请求演示；
- `χ > χ_hi`：**先验锁定/支撑异常疑**，保持保守，禁止适配，并上报审计。
核心：融合权重 `ω = softmax(−χ/τ)` 且 `ω ≤ ω_max`；**永远不允许先验单独定案，也不允许单条演示单独定案**。

**定义 320（接地一致性证书 GCC）** 对接地分 `g_gr` 与执行后观测 `y`：`c_gr = −g_gr + D(π_sem(·|o), π_sem(·|o,y))`。若 `c_gr > τ_gr` 或指令含未接地指代（检索不到可指向对象），则 `U_ground` 保持未消解，禁止按该指令执行；只允许「澄清/请求演示/保守停止」。

**定义 321（适配可采纳性与负迁移界）** 设支撑分布 `P_sup`、部署分布 `P_dep`、基准风险 `R_base`、适配后风险 `R_adapt`、策略类 Lipschitz `L_π`、留一泛化间隙 `G_LOO`。可采纳当且仅当
`R_base + L_π·W_1(P_sup,P_dep) + G_LOO ≤ R_base + Δ_max`，
即 `L_π·W_1 + G_LOO ≤ Δ_max`。不可采纳 ⇒ 逐指令退化为 R69；**这是「宁可不学，不可学错」的形式化**。

**定义 322（支撑集审计 SAA）** 审计每条演示：来源可信度 ρ_i、成功标注一致性、诱导致命性（动作是否逼近/越过安全边界）、捷径检测（用背景替换/物体换色等反事实探测，若预测随无关因素翻转则标记 shortcut）、选择偏差（是否只演示成功）。任何高风险标记 ⇒ 该演示降权或隔离，不得进入写门。

**定义 323（演示写门 DWA）** 写操作仅允许在维护窗口，且需满足：`AIC-FEW` 未报警 ∧ `SAA` 全绿 ∧ `MCC` 覆盖达标 ∧ `APG` 无锁定 ∧ 写入前后 `Env` 不变。写入产出 `(version, rollback_point, diff_hash)`；运行时只读。任何异常 ⇒ 自动回滚到 `rollback_point`，行为逐指令等于写入前。

**定义 324（流/支撑/本体三重异常 FMA†）** 继承 R69 的流似然第二意见 `Δa`，新增：
- 支撑残差 `a_sup = r_sup(o, ξ_obs)`（行为是否落在演示覆盖域）；
- 本体残差 `a_emb = −log p_θ(ξ_obs | o, E)` 与参考本体 `E_0` 的似然差（跨本体迁移是否越界）。
判别模式：`(r_res↓, Δa↑)` 缓变故障（R69）；`(a_sup↑, Δa↑, a_emb↑)` 适配越界/本体失配；`(a_sup↑, r_res≈0, Δa≈0)` 演示覆盖不足（应请求演示或保守，而非报警）。

**定义 325（演示的证据纪律与来源独立性）** 演示/先验不是两个独立源。定义「独立证据簇」：`κ(源) ∈ {人, 环境, 模型先验, 物理残差, 支撑集}`。只有当一致证据来自 ≥2 个**不同簇**（如支撑集 + 物理残差），才可定案；同一簇内多个演示仍算一个源。系：R69 的 k-一致纪律在演示场景下必须做**簇级去相关**，否则「先验与演示都对」可能只是同一个偏置的两次投影。

**定义 326（证书 J_FLAIR）** `J_FLAIR = (J_FLUID, support_hash, N_eff, mc_coverage, apg_chi, gcc_score, loo_gap, adapt_version, rollback_point, demo_budget_used, fma_sup_p95, fair_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ mc_coverage ≥ 1−α ∧ apg 未锁定 ∧ gcc 通过 ∧ loo_gap ≤ Δ_max ∧ 写门全绿`。

**定义 327（支撑增长、遗忘与回滚）** 支撑集按「证据新鲜度 + 覆盖增益」做容量受限维护：新演示只有在覆盖新状态区域或显著降低留一误差时才保留；旧演示按时间/任务指纹衰减。回滚触发条件：连续 `m` 轮 `c_gr` 或 `a_sup` 越界、或审计发现投毒、或适配后 `R` 估计显著上升。**学得越多不等于越可信；支撑集必须能被裁剪。**

```python
    for g in info_candidates(modes):                        # gaze/probe/ask/demo
        if not budget.allow(g):              continue
        if not c_ras_wm.certify_info(g):     continue       # 演示也要认证
        if g.kind == 'demo' and not demo_affordable(g): continue
        score = vo_i(g, vla_dist, support) - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None        # 无利可图 → R69

# IP-268 MCC：低样本元共形校准（覆盖率保证，不假装逐点 ECE）
def conformal_modes(vla_probs, support_query, alpha):
    s = [1.0 - vla_probs[i][support_query.label[i]] for i in range(len(support_query))]
    q = quantile(s, ceil((len(s)+1)*(1-alpha))/len(s))
    return lambda m, x: (1.0 - vla_probs[x][m]) <= q            # 预测集

# IP-269 APG：先验-支撑共识门（禁止任一方单独定案）
def consensus_gate(vla_dist, sup_dist, chi_lo, chi_hi):
    chi = wasserstein(vla_dist, sup_dist) / scale
    if chi <= chi_lo:   return 'fuse', softmax_weight(chi)
    if chi <= chi_hi:   return 'clarify', None                  # 走 ask / demo
    return 'lock_suspect', None                                 # 禁适配 + 审计

# IP-270 GCC：语言接地一致性
def grounding_cert(vla, o, l, y):
    g = vla.ground_score(o, l)
    drift = divergence(vla.semantic_head(o, l), vla.semantic_head(o, l, y))
    return (-g + drift) <= TAU_GR and referents_resolved(l, o)

# IP-271 DWA：写门（运行时不写；离线写须可回滚）
def write_gate(demo_batch, support, audit_ok, mc_ok, apg_ok, env_before):
    if not (audit_ok and mc_ok and apg_ok):        return None
    if not env_equal(env_before, estimate_env_after(demo_batch)): return None
    ver = adapter.fit(demo_batch)                  # 仅维护窗口
    return WriteHandle(version=ver, rollback=snapshot(), diff_hash=hash(ver))

# IP-277 主闭环：双速率（VLA 慢环给语义假设，FMP 快环做几何执行）
def FLAIR_RAS_round(M, obs):
    # --- 慢环（可跨轮缓存，不在实时关键路径） ---
    vla_dist, g_gr = M.vga.infer(obs.v, obs.l, obs.p)
    support        = M.msr.retrieve(obs)
    Us, modes      = decompose_flair(..., vla_dist, support, M.fmp.mode_head)
    decision, w    = M.apg.consensus(vla_dist, support.dist)
    if decision == 'clarify':
        g = M.adv.choose_info_action(modes, support, M.budget, vla_dist)
        if g is not None: support = M.cia.execute_and_update(g)   # ask/demo
    elif decision == 'lock_suspect':
        M.vqa_f.report('prior_lock', vla_dist, support); Us['U_adapt'] += INF
    # --- 快环（与 R69 相同，严格实时） ---
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(obs)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    flux = M.fmp.sample(o, K, semantic_cond=vla_dist if decision=='fuse' else None)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, obs.raw, obs.calibrated)
    a_sup = M.msr.support_residual(obs, M.last_action)
    a_emb = M.fma.embodiment_residual(obs, M.body_id)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    over  = (a_sup > TAU_SUP) and (a_emb > TAU_EMB)
    if Us['U_sem'] > TAU_SEM and decision == 'fuse':
        g = M.adv.choose_info_action(modes, support, M.budget, vla_dist)
        if g is not None: vla_dist = M.cia.update_belief(g)
    # --- R69 的两级保守退避，额外受 U_ground/U_adapt 调制 ---
    U_floor = Us['U_ale'] + (Us['U_geo'] + Us['U_sem'] if decision != 'fuse' else 0.0)
    U_floor += Us['U_ground'] + Us['U_adapt'] * (decision != 'fuse')
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if slow or over or decision == 'lock_suspect': lam = max(lam, 0.8)
    A = M.ach.propose(x_prime, M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    mode = select_mode(modes, Us['U_geo'], lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_f.submit_async(decision, support, Us, a_hat, a_sup, a_emb)
    return k, lam, mode, Us, support.version
```

## 3. 推导

**引理 19（演示的信息优势与风险代价）** 设语义模式身份 `m*`，其熵为 `H(M)`。信息动作 `g` 的剩余熵满足 `H(M|y_g) ≥ H(M) − I(M; y_g)`。对演示，`y_demo` 同时含目标与执行，故 `I(M; y_demo) ≥ I(M; y_ask/probe)`，即 `VoI_demo` 在语义层面支配其它信息动作；但其成本 `c(demo)` 含人类时间与不可逆风险，且演示引入**支撑偏置**——在 `P_sup ≠ P_dep` 时，采纳演示后验的期望风险增加 `L_π·W_1(P_sup,P_dep)`。系：**演示的净价值 = 语义信息增益 − 借来证据的泛化利息**；这给出了「何时值得请人演示」的判据（定义 316、321）。

**引理 20（低样本元共形覆盖）** 若校准情节与部署样本可交换、非一致性分 `s_i` 在有限样本下按定义 317 取分位 `q`，则对新的可交换样本 `P(m* ∈ C(x)) ≥ 1−α`，无需 `N→∞`、也无需要求模型校准。注：该保证是**边际覆盖**，不是条件覆盖；小 N 下预测集偏大（保守）是特性而非缺陷；逐点 ECE 不可由此保证（诚实的边界）。系：MCC 用「覆盖率」替代「ECE」作为低样本门控指标，避免在 N=1 上估计一个没有统计意义的 ECE。

**引理 21（适配包含性）** 若 `π_adapt` 的支撑含于基准认证包络 `Env(x)`，且 C-RAS-WM 对执行前缀的认证不变，则对任意有界代价 `ℓ`，`R_worst(π_adapt) ≤ R_worst(π_base)`；当适配可采纳性（定义 321）不满足时，FLAIR 逐指令退回 `π_base`。故「学习」不改变最坏情况安全，只改变包络内的期望效率。系：**适配可以被安全地拒绝**——这是 R70 相对「端到端 VLA 微调」的根本区别。

**引理 22（先验-支撑冲突与负迁移）** 设先验分布 `P_V`、支撑分布 `P_S`，真实分布 `P*`。若 `χ = W(P_V,P_S)` 大，则至少一方与 `P*` 的 `W` 距离 `≥ χ/2`。若不做共识门而按固定权重融合，负迁移风险下界为 `L_π·(χ/2 − ε_est)`；APG 在 `χ > χ_hi` 时拒绝融合，把该下界项置零，代价是退化为「不学/澄清」。系：**冲突时保守优于融合**，与 R69「不确定就收紧」同构。

**定理 18（FLAIR 严格包含 FLUID 与 R68）** 在 A95–A99 下：当 `N=0`（无演示）、`decision ≠ fuse`、`U_sem=U_ground=U_adapt=0` 时，`A_fs` 为恒等、`g_demo` 不可用、APG 无输入，FLAIR 的每一步与 R69 逐指令相同；进一步当 `VoI≤成本` 时退化为 R68。且 FLAIR 在语义/适配信息可用时获得 resolution bonus。故 R69、R68 都是 FLAIR 的边界退化，安全侧不做任何让步。

**定理 19（安全适配与无突变）** 演示动作经 C-RAS-WM 认证、写门 DWA 保证 `Env` 不变、回滚原子化，则：(i) 任意适配后轨迹仍在 `Env` 内；(ii) 写入失败/超时/投毒时系统在有限步内回滚到 `rollback_point`，控制量连续、无突变；(iii) 语义模式切换经 `select_mode` 的滞回与 `prefix_dispatch` 的平滑，满足 R69 定理 17 的连续性条件。系：**「学习」被放进一个不改变安全包络、可撤销的容器**。

**定理 20（演示只证假设、不证安全）** 在 A99（支撑可交换、审计诚实）下，单条演示可使 `m*` 进入 MCC 预测集的概率 ≥ `1−α` 仅当 `α ≥ 1/(N+1)`；即 `N=1` 时最高只能达到 `α=0.5` 的边际覆盖。故**一次演示永远不足以单独授予安全证书**，必须与物理残差/主动探询等不同证据簇交叉（定义 325）。系：`g_demo` 的合法产出是「候选模态 + 一个待验证假设」，不是「已验证」。

## 6. 本轮最大风险

**一句话**：FLAIR 把「学习」引进了安全闭环，而少样本适配最危险的失效不是学不会，而是**学错却更自信**——一条带偏置或投毒的演示被 VLA 先验「顺水推舟」地认可（相关证据被误当独立证据），MCC 在 N=1 上给出形式上的覆盖保证、APG 因两者同源偏置而误判「一致」，于是系统把 R69 的一次「问错」升级成一次被写进支撑集、并随使用自我强化的「学错」；**学错比问错更危险，因为它会污染此后所有的证据与提问**。

**次级风险与缓解**：
1. **支撑集投毒/选择偏差** → SAA 审计 + 捷径反事实探测 + 单演示永不单独定案（定理 20）；
2. **先验锁定与负迁移** → APG 共识门 + 可采纳性界（引理 22、定义 321），冲突即拒绝适配；
3. **小 N 校准假象** → MCC 用共形覆盖替代逐点 ECE，并显式声明小 N 的保守性（引理 20）；
4. **VLA 语义幻觉/指令注入** → GCC 接地证书 + 冻结语义编码 + 未接地即停（定义 320）；
5. **适配破坏实时性/引入漂移** → 双速率 + 写门 DWA + 原子回滚，运行时不写权重（定义 323、定理 19）；
6. **支撑集无限膨胀/遗忘** → 覆盖增益准入 + 容量受限维护 + 回滚触发（定义 327）。

| `Env(x)` | 基准闭环认证安全包络（适配不得扩大） |
| `J_FLAIR = (J_FLUID, support_hash, N_eff, mc_coverage, apg_chi, gcc_score, loo_gap, adapt_version, rollback_point, demo_budget_used)` | 证书 |

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** FLAIR = (VGA, MSR, SAD, ADV, MCC, APG, GCC, DWA, SAA, FMA†, RAS-WM‡)；继承零在线学习写；新增适配包含性（适配只在包络内重塑、不扩包络）、演示预算（≤1 次/单位时间、占用人类时间 ≤ h_max、演示动作也过认证）、证据纪律加强（演示/先验为相关证据，不得互充当第二正交源）、可回滚性（写有版本与回滚点，回滚后逐指令等于写入前）。

**定义 311–313（VLA 先验 / 支撑集 / 适配算子）** `Φ_VLA` 冻结，只取语义模式与接地分；`S` 为演示证据，N=0 必须退化为 R69；`A_fs` 运行时只做非参数条件化（不改参数），参数适配只在维护窗口经 DWA 进行。

**定义 314（四分解）** `U_sem=H(m^s)`，`U_geo=H_mode·g(Δ_min)`，`U_adapt∝1/√N_eff+G_LOO`，`U_ground=H(m^s|l)` 与校准偏差；`U_ale` 继承 R69。分通道处置，不简单加和。

**定义 315–316（支撑原型与 Demo-VoI）** `φ_i=Enc(o_i,l_i,ξ_i)`，`K(o,S)=max_i⟨ψ(o),φ_i⟩/τ`；`g_demo` 纳入 `𝒜_info`，`g*=argmax[VoI−c]`，但演示只提出假设、不授予证书。

**定义 317（MCC 低样本共形）** 非一致性分 `s_i=1−π_sem(m_i|x_i)`，取 `⌈(N+1)(1−α)⌉/N` 分位；`P(m*∈C(x))≥1−α`（边际覆盖）；小 N 下 ECE 不可保证，明确以覆盖率门控。

**定义 318（适配包含性）** `supp π_adapt ⊆ Env(x)` 且执行不变；`R_worst(π_adapt) ≤ R_worst(π_base)`，否则 APG 拒绝。

**定义 319（APG 共识门）** `χ≤χ_lo` 融合（权重 ≤ω_max）；`χ_lo<χ≤χ_hi` 不融合、澄清/请求演示；`χ>χ_hi` 判定先验锁定/支撑异常，禁适配并审计。先验不得单独定案，单演示不得单独定案。

**定义 320–323（接地 / 可采纳 / 审计 / 写门）** `c_gr=−g_gr+D(π_sem(o),π_sem(o,y))`，越界即停；可采纳性 `L_π·W_1(P_sup,P_dep)+G_LOO≤Δ_max`；SAA 审计投毒/捷径/选择偏差；DWA 仅维护窗口写、前后 `Env` 不变、带版本与回滚点。

**定义 324–327（FMA† / 证据纪律 / 证书 / 支撑维护）** `(r_res↓,Δa↑)` 缓变故障；`(a_sup↑,Δa↑,a_emb↑)` 适配越界；演示/先验按「证据簇」去相关，跨 ≥2 簇一致才定案；`J_FLAIR` 并入覆盖、冲突、接地、留一间隙、版本；支撑集按覆盖增益准入、容量受限、可按回滚触发裁剪。

```python
# IP-264 VGA：冻结 VLA（慢环，1–10Hz，不在实时关键路径）
class VLAGrounding:
    def infer(self, v, l, p):
        logits = self.vla.semantic_head(v, l, p)          # 语义模式
        return softmax(logits), self.vla.ground_score(v, l, p)

# IP-265/266 MSR+SAD：四分解
def decompose_flair(samples, z, vla_dist, support, mode_head):
    U_ale, U_epi, modes, h_hat = R69_aud.decompose(samples, z, mode_head)
    return dict(U_ale=U_ale, U_geo=U_epi, U_sem=entropy(vla_dist),
                U_adapt=1/sqrt(max(support.N_eff,1))+support.loo_gap,
                U_ground=grounding_entropy(vla_dist, support.language)), modes

# IP-267 ADV：演示价值
def choose_info_action(modes, support, budget, vla_dist):
    best = None
    for g in info_candidates(modes):                      # gaze/probe/ask/demo
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        score = vo_i(g, vla_dist, support) - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None      # 无利可图 → R69

# IP-268 MCC：低样本元共形
def conformal_modes(probs, query, alpha):
    s = [1.0 - probs[i][query.label[i]] for i in range(len(query))]
    q = quantile(s, ceil((len(s)+1)*(1-alpha))/len(s))
    return lambda m, x: (1.0 - probs[x][m]) <= q

# IP-269 APG：先验-支撑共识门
def consensus_gate(vla_dist, sup_dist, chi_lo, chi_hi):
    chi = wasserstein(vla_dist, sup_dist) / scale
    if chi <= chi_lo:   return 'fuse', softmax_weight(chi)
    if chi <= chi_hi:   return 'clarify', None
    return 'lock_suspect', None

# IP-270 GCC：语言接地
def grounding_cert(vla, o, l, y):
    return (-vla.ground_score(o,l)
            + divergence(vla.semantic_head(o,l), vla.semantic_head(o,l,y))) <= TAU_GR \
           and referents_resolved(l, o)

# IP-271 DWA：写门
def write_gate(demo_batch, audit_ok, mc_ok, apg_ok, env_before):
    if not (audit_ok and mc_ok and apg_ok): return None
    if not env_equal(env_before, estimate_env_after(demo_batch)): return None
    ver = adapter.fit(demo_batch)                         # 仅维护窗口
    return WriteHandle(ver, snapshot(), hash(ver))

# IP-277 双速率主闭环
def FLAIR_RAS_round(M, obs):
    vla_dist, g_gr = M.vga.infer(obs.v, obs.l, obs.p)     # 慢环
    support = M.msr.retrieve(obs)
    Us, modes = decompose_flair(..., vla_dist, support, M.fmp.mode_head)
    decision, w = M.apg.consensus(vla_dist, support.dist)
    if decision == 'clarify':
        g = M.adv.choose_info_action(modes, support, M.budget, vla_dist)
        if g is not None: support = M.cia.execute_and_update(g)
    elif decision == 'lock_suspect':
        M.vqa_f.report('prior_lock', vla_dist, support); Us['U_adapt'] += INF
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(obs)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    flux = M.fmp.sample(o, K, semantic_cond=vla_dist if decision=='fuse' else None)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, obs.raw, obs.calibrated)
    a_sup = M.msr.support_residual(obs, M.last_action)
    a_emb = M.fma.embodiment_residual(obs, M.body_id)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    over  = (a_sup > TAU_SUP) and (a_emb > TAU_EMB)
    if Us['U_sem'] > TAU_SEM and decision == 'fuse':
        g = M.adv.choose_info_action(modes, support, M.budget, vla_dist)
        if g is not None: vla_dist = M.cia.update_belief(g)
    U_floor = Us['U_ale'] + (Us['U_geo'] + Us['U_sem'] if decision != 'fuse' else 0.0)
    U_floor += Us['U_ground'] + Us['U_adapt'] * (decision != 'fuse')
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if slow or over or decision == 'lock_suspect': lam = max(lam, 0.8)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    mode = select_mode(modes, Us['U_geo'], lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_f.submit_async(decision, support, Us, a_hat, a_sup, a_emb)
    return k, lam, mode, Us, support.version
```

## 4. 推导

**引理 19（演示的信息优势与风险代价）** `I(M;y_demo) ≥ I(M;y_ask/probe)`，故演示在语义层支配其它信息动作；但支撑偏置使出借证据的期望风险增加 `L_π·W_1(P_sup,P_dep)`。系：演示净价值 = 语义信息增益 − 泛化利息，给出「何时值得请人演示」的判据。

**引理 20（低样本元共形覆盖）** 校准情节与部署样本可交换、分位按定义 317 取，则边际覆盖 `P(m*∈C)≥1−α`，无需 N→∞、无需模型校准；小 N 下预测集偏大是特性；逐点 ECE 不可保证。系：MCC 以覆盖率替代 ECE 作低样本门控。

**引理 21（适配包含性）** `supp π_adapt ⊆ Env(x)` 且认证前缀不变 ⇒ `R_worst(π_adapt) ≤ R_worst(π_base)`；不可采纳时逐指令退回 `π_base`。系：学习不改变最坏安全，只改变包络内期望效率。

**引理 22（先验-支撑冲突与负迁移）** `χ=W(P_V,P_S)` 大 ⇒ 至少一方与 `P*` 距离 ≥ `χ/2`；固定权重融合的负迁移下界为 `L_π·(χ/2−ε_est)`；APG 在 `χ>χ_hi` 拒绝融合，把该下界置零，代价是退化澄清。系：冲突时保守优于融合。

**定理 18（FLAIR 严格包含 FLUID 与 R68）** `N=0` 且 `decision≠fuse` 且 `U_sem=U_ground=U_adapt=0` 时，FLAIR 与 R69 逐指令相同；`VoI≤成本` 时进一步退化为 R68。语义/适配可用时获 resolution bonus；安全侧不让步。

**定理 19（安全适配与无突变）** 演示动作过认证、DWA 保 `Env` 不变、回滚原子化 ⇒ 适配轨迹仍在 `Env`；失败/超时/投毒有限步回滚，控制连续；语义模式切换经滞回与平滑，满足 R69 定理 17。

**定理 20（演示只证假设、不证安全）** 单演示使 `m*` 进入预测集的边际覆盖最高仅 `α=1/(N+1)`（N=1 时 0.5）；故一次演示不足以单独授予安全证书，必须与物理残差/主动探询等不同证据簇交叉。系：`g_demo` 的合法产出是候选模态 + 待验证假设。

## 7. 本轮最大风险

**一句话**：FLAIR 把「学习」引进安全闭环，最危险的失效不是学不会，而是**学错却更自信**——带偏置/投毒的演示被 VLA 先验「顺水推舟」认可（相关证据误当独立证据），MCC 在 N=1 上给出形式覆盖、APG 因同源偏置误判一致，于是 R69 的「问错」升级为被写进支撑集并自我强化的「学错」；**学错比问错更危险，因为它会污染此后所有证据与提问**。

**次级风险与缓解**：支撑投毒/选择偏差（SAA + 反事实探测 + 单演示不定案）；先验锁定/负迁移（APG + 可采纳性界，冲突即拒绝）；小 N 校准假象（共形覆盖替代 ECE，明示保守性）；VLA 幻觉/指令注入（GCC + 冻结语义 + 未接地即停）；适配破坏实时性/漂移（双速率 + DWA + 原子回滚，运行时不写权重）；支撑膨胀/遗忘（覆盖增益准入 + 容量受限 + 回滚触发）。
