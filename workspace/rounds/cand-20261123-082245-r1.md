# 第 4 轮（灵感驱动研究循环·新灵感对第 1 轮；本轮灵感：「最优控制」×「可靠性」）

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v21+IP-425–430（语义-合规层 SDC/CAC/DCL/GIC/HPC+/CFC+；其上承 v20 联邦感知证书与 v19/v17 全链）。
> 本轮纪律：**最优控制只在「已支付的可靠度」内求最优，安全是硬约束不是软代价；可靠性不是一句断言，而是一份守恒、可花费、可审计的预算**。不推倒 v21：SDC/CAC/DCL/GIC/HPC+/CFC+ 全部保留。本轮只做一件事：**把 v21 的「可否执行」升级为「在最坏可靠度约束下、于已证可行域内最优执行」——给证书体系配一个可靠预算账本与一个受约束最优控制器，并让控制器主动「去看」以从源头削减认知不确定性（缺席幻觉）**。

## 0. 直觉与动机

**灵感 1（最优控制 → 证书给「可行域」，最优控制给「域内的最优」；安全是硬约束而非成本项）**
直觉：v21 是一套挑剔的「守门人」——它能回答「这计划允不允许」，却从不问「在这么多允许的方案里哪个最好」。结果是把性能白白留在桌上（宁可最慢也不优化），保守裕度只因循手调。最优控制（滚动时域 MPC + 终端约束 + 值函数/代价-to-go）恰好补两块：**在已证可行域内最小化任务代价**（时间、能耗、jerk、乘客舒适度），以及**把「到底该多保守」变成可推导的旋钮**。但这里有个必须守住的纪律：**安全裕度/碰撞风险进约束、不进代价**——否则优化器会学会「用性能买风险」。做法是**最小侵入安全滤波**：先求标称最优 u_nom，再用 CBF-QP 把越界点投影回证书域；若投影无解，退回证书的 SafeStop。关键反直觉点：**当标称解本就安全时，投影是恒等映射——最优性一分不损；最优控制因此是「免费」的，只在安全真正被顶住时才付出偏离代价。**

**灵感 2（可靠性 → 从「单步、被假设的可靠性」到「跨时域、守恒、可审计的可靠性预算」）**
直觉：v21 的 δ、κ_c、α 都是**单步、单模块、被假设**的数。但一次任务是成百上千步：单步 99.99% 不等于任务 99.99%——朴素把每步失败率相加（union bound）得到 T·δ 极端悲观，而假独立相乘又**系统性乐观且不成立**（故障强相关：一个标定偏差会连续很多步犯同样的错）。真正缺的不是一个更漂亮的概率数，而是**可靠性会计**：把任务级目标 δ_mission 当**有限预算**，按步/模块**分配**，只在「真的依赖某个概率假设」时才**花费**（不用 AbsCert 就不付它的账，退化为保守距离帽），预算见底就把证书参数**单调收紧**、必要时 SafeStop——全程入账、merkle 可审。而且**估计本身也要投保**：κ_c 不能当常数，要换成带置信的**召回下界 κ̂_c^LCB**，并给估计误差留一份**元可靠性子预算 δ_est**。关键反直觉点：**可靠性不是「证明很安全」，而是「承认有多少不确定、并把它花在明处」；花掉的每一分都可审计，没花的不许偷偷兑现。**

**灵感 3（两者交汇 → 主动感知/对偶控制：花一点预算「去看」，是从源头减少未来风险）**
直觉：第 3 轮最大的病是「缺席幻觉」——没看见 ≠ 证明没有，因为 κ_c 是经验假设。可靠预算只能给这个假设**定价/投保**，无法**消除认知不足**；而最优控制里的对偶控制（Feldbaum dual control）给了一个治本动作：**在代价里加「信息增益」项，让机器人主动移动到欠覆盖、高不确定区域去看**，从而降低 κ̂ 的不确定性、把未来的风险预算省回来。纪律：探索动作仍受当前 Safe(B) 硬约束——**「看」可以，但绝不越安全域去看**；并用预算的影子价格 μ 与 CVaR 尾部惩罚抑制「押注式」花预算（别为了早段信息把后半程预算花光）。关键反直觉点：**信息是有价值的、且价值可用预算度量——一次安全的「多看两眼」能把未来更大的保守代价换成现在很小的探索代价，是「以可靠换可靠」。**

**如何统一**
统一为 **v22 可靠预算最优控制（Reliability-Budgeted Optimal Control, RBOC）**：v21 证书层给出**硬可行域与其可靠度账单**；IP-431 可靠预算管理器（RBM）负责 δ_mission→每步/每模块的分配、条件花费、元可靠性投保与单调升级；IP-432 证书约束最优控制器（CCOC）在 Safe(B) 内做受限 MPC + 最小侵入滤波，终端集 X_f ⊆ Exec_v21；IP-433 对偶感知代价（DAPC）以信息增益/预算影子价格改写标称代价；IP-434 可靠自适应证书参数（RACP）把 v21 的裕度/速度帽/门槛变成剩余预算的单调函数；IP-435 可靠管证书（TubeCertificate）把单快照证书升级为跨时域可复合的管；IP-436 任务可靠证书（MRC）把整个账本 merkle 化。统一准入门 **HPC++ = (HPC+, TubeCertificate, MRC)**：几何/规范/负信息三证之外，再要求「整条规划管在当前预算下可靠、且账本可复核」。退化链保持：`Exec_v22(B) ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`，且（失败模型成立时）`P(mission unsafe) ≤ δ_mission`。

## 1. 研究问题（轮次升级版）

- **Q1（可靠预算的分解与复合）**：在依赖结构未知（且可能强相关）时，如何把 δ_mission 分解到步/模块而不失 soundness？union bound 何时过悲观、能否在「已知正相关/可分组独立」时收紧而永不转乐观？如何严格定义「条件花费」（只在实际依赖该假设时扣账，未依赖即零花费）？估计误差（i.i.d. vs 分布漂移）如何进入 δ_est 而不污染执行预算？

- **Q2（预算约束下的最优性与可行性）**：如何把 HPC+ 的单快照可行性提升为 MPC 的**终端不变集 + 逐时不变量管**，并保证**递归可行**（recursive feasibility）？在 50Hz 控制环上，MPC（低频重规划）与安全滤波（高频小 QP）如何分工使 p99 仍 ≤12ms？最小侵入滤波在非凸障碍下如何投影而不抖振、不陷入不可行死锁？

- **Q3（主动感知/对偶控制）**：覆盖/占用信念上的**期望信息增益**如何定义才与 AbsCert 的可靠性真正同构？探索带来的 κ̂ 不确定性下降能否量化为「省下的未来预算」？影子价格 μ 与 CVaR 项如何选择以**杜绝风险押注**（早段榨干预算、后段赤手空拳）？探索轨迹在 Safe(B) 内是否仍可能因模型误差进入未覆盖危险区？

- **Q4（在线标定与元可靠性）**：κ_c → κ̂_c^LCB 用 conformal/序贯检验在漂移下如何既快又 sound？系统性漏检（分布偏移、非常规人体形态）如何在**保住 soundness** 的前提下尽早检出并升级？δ_est、δ_abs、v21 conformal α 三者如何对账而不重复、不遗漏？

## 2. 设计原则（在 P34–P36 基础上新增 P37–P39）

**P37 安全即硬约束律（Safety-as-Hard-Constraint）**
证书裕度与可行集进入优化时只能是**硬约束/终端不变集/屏障**，不得作为可被最小化的软代价。优化器可以**选择花多少可靠预算**（激进↔保守），但不得超出预算，也不得把「省下的风险」当作收益。形式化：`u ∈ argmin J_task  s.t.  x_k ∈ Safe_k(B_k), x_K ∈ X_f ⊆ Exec_v21`；最小侵入滤波的恒等性（引理 165）保证标称安全时零性能损失。

**P38 可靠预算守恒律（Reliability Budget Conservation）**
所有对概率假设的依赖都从有限预算 δ_mission 支出，默认 **union-bound 可加**（**不假设独立**）；**条件花费**（依赖才扣账）；预算单调不增，见底即**单调收紧**参数并升级；估计误差由 δ_est 单独投保（元可靠性），且 `δ_exec + δ_est = δ_mission`。

**P39 可靠单调退化与探索受限律（Reliability-Monotone Degradation & Bounded Exploration）**
`B ≤ B' ⇒ Safe(B) ⊆ Safe(B')`、速度帽不升、许可门槛不降；主动感知只允许在 `Safe(B)` 内为降低认知不确定性而偏离标称代价，绝不越证书域。故 `Exec_v22(B) ⊆ Exec_v21`，且可靠性预算永不为负（花费超配即触发升级）。

## 3. 与基线的接口（如何退化）

- RBM 失效（预算账本不可信/不可读）⇒ 视作预算耗尽 ⇒ 全域最保守（共享区 SafeStop、非共享区静态距离帽）⇒ ⊆ v21；
- CCOC 失效（MPC 无解/超时）⇒ 退回 v21 的「仅验收」守门行为（在 v21 可行集中取默认保守计划，不做优化）⇒ ⊆ v21；
- DAPC 关闭（λ=μ=0）⇒ 纯任务代价 MPC，仍受 Safe(B) 硬约束 ⇒ 「无主动感知的 RBOC」⇒ ⊆ v21；
- RACP 失效 ⇒ 参数固定在 v21 默认（最保守一侧）⇒ ⊆ v21；
- κ̂ 无法获得有效 LCB（样本不足/漂移不可界定）⇒ 取 κ̂=0 ⇒ 不签 AbsCert ⇒ 退回保守距离帽 ⇒ 更保守；
- 全部失效 ⇒ v22 ≡ v21 ⇒ `Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`（引理 168）。
- **安全继承**：RBM 预算守恒且 sound、CCOC 只选 v21-可容许且终端不变、DAPC 不越 Safe(B)、RACP 单调、κ̂ 元可靠；任意失效都向更保守方向退化，且预算只会收紧不会放宽可行域。

## 4. 预期贡献

1. **可靠预算代数 + 元可靠性**：首次把 v21 的「单快照、被假设」可靠性升级为「任务级、守恒、条件花费、可审计」的预算，并显式给估计误差投保（δ_exec+δ_est），从机制上压制「可靠性剧场」。
2. **证书约束最优控制 + 最小侵入滤波**：在已证可行域内恢复性能，并证明「标称安全即零损失」；把终端不变集/可靠管接到 MPC，得到递归可行的安全最优闭环。
3. **对偶/主动感知作为可靠性改进控制**：把「去看」形式化为信息增益 × 预算影子价格，从源头削减认知不确定性，正面攻击第 3 轮缺席幻觉；并证明探索不越安全域。
4. **可靠自适应证书参数**：裕度/速度帽/意图门槛成为剩余预算的单调函数，把安全—活性—可靠度统一在同一账本下。
5. **跨时域可靠管证书 + 任务可靠证书（MRC）**：把快照可靠性复合到规划管，全链 merkle 可复放审计。
6. **v22 闭环**：`Exec_v22 ⊆ Exec_v21` 且（失败模型成立时）`P(mission unsafe) ≤ δ_mission`。

## 5. 本轮最大风险

**一句话**：可靠预算最容易沦为「账面可靠」——它只在失败模型（各步/各模块的失败概率刻画、i.i.d./可交换性、漂移可界定）本身成立时才 sound；一旦存在**未建模的系统性相关失效**（同一标定偏差连续多步犯同一错、分布漂移让 κ̂ 的 LCB 失效），账本仍会完美平衡、审计仍会通过，而真实任务失效概率远高于 δ_mission；更险的是最优控制会在预算内**主动「押注」**（早段花光预算换信息/性能），把第 3 轮的「缺席幻觉」洗成一张「可证明的低概率事故单」。

# IP-431 Reliability Budget Manager（可靠预算守恒，P38）
class ReliabilityBudgetManager:
    def __init__(self, delta_mission, modules, est_frac=0.2):
        self.delta = delta_mission
        self.delta_est = delta_mission * est_frac   # 元可靠性子预算
        self.delta_exec = delta_mission - self.delta_est
        self.modules = modules
        self.spent = 0.0

    def allocate(self, K, weights):
        # 默认 union bound，不假设独立性（引理 163）
        w = normalize(weights)
        return {k: {m: self.delta_exec * w[m] / K for m in self.modules}
                for k in range(K)}

    def spend(self, r_alloc, relied):
        # 条件花费：只有真的依赖某个概率假设才扣账
        if relied:
            self.spent += r_alloc
        return self.remaining()

    def remaining(self):
        return max(0.0, self.delta_exec - self.spent)

    def remaining_frac(self):
        return self.remaining() / self.delta_exec

    def account(self):
        # 账面必须平衡；超额即视为账本失效 → 最保守（引理 163/168）
        return {"alloc": self.delta_exec, "spent": self.spent,
                "est": self.delta_est, "ok": self.spent <= self.delta_exec}


# IP-432 Certificate-Constrained Optimal Controller（安全即硬约束，P37）
class CertConstrainedMPC:
    def __init__(self, dynamics, cost, terminal_set, hpcplus, safety_filter):
        self.f = dynamics
        self.l, self.Vf = cost
        self.Xf = terminal_set          # 不变终端集，⊆ Exec_v21
        self.gate = hpcplus
        self.filter = safety_filter      # CBF-QP 最小侵入滤波

    def solve(self, x0, budget, obstacles, belief):
        # 1) 标称最优：只在当前预算给出的 Safe(B) 内规划
        u_nom = self._nominal_ocp(x0, budget, belief)
        # 2) 最小侵入安全滤波：标称安全则恒等，越界才投影（引理 165）
        u_safe, feasible = self.filter.project(
            u_nom, x0, safe_set=budget.safe_set(obstacles),
            barrier=budget.barrier(obstacles))
        if not feasible:
            return None, "CERT_INFEASIBLE->SafeStop"
        # 3) 硬门复核：逐时 Safe_k + 终端不变集（引理 164）
        if not self._tube_ok(x0, u_safe, budget):
            return None, "TUBE_VIOLATION->SafeStop"
        return u_safe, "OK"

    def _nominal_ocp(self, x0, budget, belief):
        # 双代价：task - λ·info + μ·spend + CVaR（IP-433）
        return solve_ocp(self.f, self.l, self.Vf, x0,
                         horizon=budget.K, cost=budget.dual_cost(belief))


# IP-433 Dual / Active-Perception Cost（主动感知，P39）
class DualPerceptionCost:
    def __init__(self, coverage_model, lam, cvar_beta):
        self.cov = coverage_model
        self.lam = lam
        self.beta = cvar_beta

    def stage_cost(self, x, u, belief, mu):
        task = self.task_cost(x, u)
        info = self.cov.expected_information_gain(x, u, belief)   # ≥ 0 且有限
        spend = self.cov.expected_risk_spend(x, u, belief)
        tail = self.cvar_penalty(x, u, belief, self.beta)
        # 安全裕度不进代价；这里只对「花多少预算」定价（P37/P39）
        return task - self.lam * info + mu * spend + tail

    def value_of_information(self, belief, step):
        # 探索省下的未来预算 = 后验方差下降对应的 δ_est 配额下降（引理 166）
        return self.cov.posterior_var_reduction(belief, step)

## 3. 推导

**引理 163（可靠预算的复合性与元可靠性）** 设执行期被依赖的事件集合 E，对每个 e∈E 真实失败概率 p_e ≤ r_e（配额）。则 `P(∪_{e∈E} fail_e) ≤ Σ_{e∈E} r_e = spend_total ≤ δ_exec`，**无需独立性**（union bound）。条件花费成立：未被依赖的假设不在执行路径上贡献风险，故不扣账也不进入并集。估计层：若每个 r_e 用上置信界估计且 `P(∀e: p_e ≤ r_e) ≥ 1-δ_est`，则 `P(mission unsafe) ≤ P(∪fail | est ok) + P(est bad) ≤ δ_exec + δ_est = δ_mission`。∎

**引理 164（可靠约束最优控制的安全继承）** CCOC 约束 u 使 `x_k ∈ Safe_k(B_k)` 且 `x_K ∈ X_f ⊆ Exec_v21`；逐时 Safe_k ⊆ v21 单快照可行集；滤波输出要么满足约束、要么返回 SafeStop，故任何实际执行轨迹都 v21-可容许 ⇒ `Exec_v22 ⊆ Exec_v21`。RACP 单调：`B ≤ B' ⇒ Safe_k(B) ⊆ Safe_k(B')`；预算单调不增 ⇒ `Exec_v22(B_k)` 随 k 单调收缩。∎

**引理 165（最小侵入与最优性保持）** `u_safe = argmin_{u∈U_safe} ||u-u_nom||²`（U_safe 局部凸化为 CBF-QP 约束集）。若 `u_nom ∈ U_safe` 则投影为恒等 `u_safe = u_nom`，故 `J(u_safe) = J(u_nom)`（最优性零损失）；否则 `||u_safe-u_nom|| = dist(u_nom, U_safe)`，偏离只在安全约束活跃时发生。即「最优性只在安全域内」。∎

**引理 166（主动感知的可靠性增益与其边界）** 双代价 `J = J_task - λI + μ·E[spend] + CVaR_β`。`I ≥ 0` 且有限（视锥×时域有界），故探索步长有界；探索动作仍满足 `x ∈ Safe(B)`（硬约束），不扩大可行域 ⇒ 不影响引理 164 的安全继承。在 κ̂ 的近似后验下，一次观测的信息增益 ≥0 且期望降低后验方差，等价于降低未来所需 δ_est 配额（价值可度量）；μ 取预算约束的拉格朗日乘子时，最优花费不超配额，从而不出现「押注」。∎

**引理 167（元可靠性与缺席幻觉的界）** 若 κ̂_c^LCB 为在假设类 H（可交换样本，或有界漂移）下真实 κ_c 的 `(1-δ_est)` 下置信界，则 `P(κ̂_c^LCB > κ_c) ≤ δ_est`；代回 `δ_abs = 1 - κ̂_c^LCB ≥ 1 - κ_c` 为缺席失败概率的**上界**，故 AbsCert 的缺席保证在「LCB 有效」事件上 sound，总体 `P(absence false) ≤ δ_abs + δ_est`。若 H 被违反（系统性漏检/漂移超界），该界失效——此为残余风险核心。∎

**引理 168（v22 整体可靠-安全继承）** 同快照、同规则库、同机器人集合：RBM 预算守恒且 sound（163）、CCOC 只选 v21-可容许且终端不变（164）、滤波最小侵入（165）、DAPC 不越 Safe(B)（166）、κ̂ 元可靠（167）。故 `Exec_v22(B) ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`，且在失败模型 H 成立时 `P(mission unsafe) ≤ δ_mission`。∎

## 7. 已知风险与失效模式

1. **失败模型错设 / 账面可靠**（最大风险，见第 8 节）：union bound 只在各 r_e 为真实上界时成立；系统性相关失效或漂移会使 κ̂ LCB 与配额同时失真。缓解：默认禁用独立性相乘、δ_est 投保、在线漂移检测（E813/E814）、κ̂=0 兜底。
2. **风险押注 / 预算集中**：优化器可能早段花光预算换信息/性能。缓解：预算影子价格 μ 取拉格朗日乘子 + CVaR 尾部惩罚 + 再分配（E811）。
3. **主动感知的探索-安全耦合**：为降不确定性而贴近未覆盖区。缓解：探索动作强制 x∈Safe(B)（E812）、信息增益有限、投影兜底。
4. **MPC 实时性与终端集非凸**：受限 MPC 可能超预算，非凸障碍下终端不变集难算。缓解：MPC 低频、滤波高频、终端集离线近似+缓存（E821/E822）。
5. **多机器人预算争用与「可靠饥饿」**：弱机器人预算被耗尽。缓解：公平再分配、优先级反转抑制（E820/E823）。
6. **低预算导致活性坍缩**：保守升级叠加 v21 覆盖保守。缓解：以 DAPC 主动感知把预算省回、监控活性损失（E825）。
7. **估计分布漂移**：κ̂ 的假设类 H 被违反。缓解：有界漂移假设、序贯检验、跌破即全域保守（E813/E814）。

## 8. 本轮最大风险

**一句话**：可靠预算只在失败模型（各步/各模块失败概率刻画、i.i.d./可交换性、漂移可界定）本身成立时才 sound——一旦存在未建模的系统性相关失效，账本完美平衡、审计全过，而真实失效概率远高于 δ_mission，最优控制还会在预算内主动「押注」，把第 3 轮的「缺席幻觉」洗成一张「可证明的低概率事故单」。
