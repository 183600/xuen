# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环第 3 轮；本轮灵感：「跨任务泛化」×「路径规划」）

> R69 把不确定性拆成 aleatoric / epistemic，并让系统学会「问」。但它默认了一个隐藏前提：**当前任务的标定是有效的**。一旦换任务，J_FLUID 里的 ECE、λ_floor、VoI 成本、FMA 阈值全部是源任务的产物；策略可能泛化了，**信任结构却没有泛化**。这正是 R69 自陈风险的「任务级升维」：不是单个模态权重没校准，而是**整张证书在源任务上过拟合**，到了新任务依然「看起来有效」，把一次迁移失败洗成「已验证」。
>
> 本轮两个灵感正好补上缺口：
> - **跨任务泛化** → 真正要迁移的不是权重，而是**可运输的证书**；泛化的度量不是准确率，而是证书泛函在任务流形上的连续性。
> - **路径规划** → 在任务流形上规划一条**证书债务最小**的路，用桥接任务当路标；直跳会撞上「标定悬崖」，绕路反而更便宜；有些目标在「证书切迹」之外，任何路径都运不过去，只能重新接地。
>
> 核心命题：**把跨任务泛化重述为任务流形上的带权最短路径问题；证书沿路径的「敏感度积分」即证书债务；只有在债务预算内、路径不穿越证书切迹、且在线监测未报警时，才允许运输 R69 的证书；否则主动插入桥接任务，或退化为在目标任务上重新接地（= R69 从零跑）。** 命名 **COMPASS-RAS**（Certificate-cOntinuity Manifold Path-planning for Adaptive Safe cross-task Specialization）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这份信任能走多远、该绕哪条路过去**」——泛化不是一次跳跃，而是一条可审计的路线。

## 0. 直觉与动机

**灵感 1（跨任务泛化 → 泛化的是策略，不是信任）**
直觉：一个在任务 A 上精心标定的闭环，迁到任务 B 常常「数字都对、判断都错」。因为 COF 的残差、MCG 的 ECE、λ_floor 的形状都是在 A 的观测分布上拟合的；B 的分布一移，这些量不是失效为 0，而是**失效为错值**——它们会给出一个「看起来很健康」的证书。这是 R69 风险的严格升级：R69 担心单个模态未校准，R70 担心**整张证书在源任务上过拟合**（meta-overfitting）。所以「跨任务泛化」的正确对象不是 π_θ，而是**证书泛函 J 在任务空间上的连续性**。

**灵感 2（路径规划 → 任务空间有几何）**
直觉：任务不是离散标签，而是由目标、地图/动力学、指令族、奖励共同参数化的连续空间。把任务嵌入度量空间 (𝒯, d_𝒯) 后，「从源任务到目标任务」就是一条路径。证书的漂移不会瞬间发生，而是沿路径累积——这天然是一个**路径积分**。于是「能不能迁移」从一个是非题，变成最短路问题：能否用足够低的累积漂移把证书运过去。

**灵感 3（证书债务 → 泛化成本有可加结构）**
直觉：若证书泛函 J 沿任务路径可微，则总漂移被「局部敏感度 κ(T)=‖∇_𝒯 J‖ 沿路径的积分」控制（Grönwall 型界）。这个积分就是**证书债务**。它有一个非常好的性质：**沿路径可加**，因此可以做 Dijkstra / A*；而直跳路径若穿过高敏感度区（标定悬崖），绕经低敏感度的桥接任务反而债务更低——这正是「路径规划优于直接微调」的几何解释。

**灵感 4（证书切迹 → 有些任务根本无法靠迁移到达）**
直觉：路径规划里有一类目标「被墙隔开、绕不过去」。任务流形上同样存在**证书切迹**：任务类型跳变（如从「导航」跳到「接触装配」）、或标定敏感度发散的区域。跨越切迹时，源任务信息对目标任务的证书**没有可辨识性**——两个在源侧观测完全相同的任务可以有截然不同的目标风险。此时任何「零样本迁移 + 旧证书」都是**不可证**的，必须重新接地（在目标上重跑 R69 的完整标定）。这不是工程保守，而是一个可证明的**不可辨识性结论**。

**灵感 5（主动桥接 → 把「下一个做哪个任务」当成信息动作）**
直觉：R69 的 MINT 在一个任务内部选「看/问/触」；R70 把同一套 VoI 逻辑升到任务级——**下一个去跑哪个桥接任务，能让目标任务的证书债务期望下降最多**。桥接任务的执行成本（数据、时间、风险）就是边的代价。这样 R69 是「任务内信息动作」，R70 是「任务间信息动作」，形成干净的递归；而 R69 的主动交互恰好是桥接任务内部消歧的现成机制。

**灵感 6（严格包含 → 空路径与重新接地都是 R69）**
直觉：目标 = 源（路径长度 0）时，COMPASS 不插入任何桥接，逐指令等于 R69；当预算不足以运输、或切迹阻断时，COMPASS 在目标任务上重新接地（从零标定），这正是 R69 在新任务上单独运行。两端都退化为 R69，中间才是新增的「运输 / 绕路」能力。安全侧永不弱于「不迁移」。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（COMPASS-RAS 总览）** COMPASS-RAS = (TCM, CTF, CDM, TPP, CCL, ABP, TCA, CIM, CSG, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **运输预算硬约束**：证书债务 D ≤ D_max、验证预算 ≤ B_val、路径到切迹的裕度 ≥ m；
(iii) **运输可证性**：无在线监测证据与路径债务界一致时，不得声明目标证书有效（继承并升维 R69 证据纪律）。

**定义 311（任务流形与任务图）** 任务 T 由参数 θ ∈ Θ ⊂ ℝ^p 刻画（目标分布、地图/动力学、指令族、奖励），任务空间 𝒯={T_θ} 配度量 d_𝒯（参数 Riemann 度量或任务嵌入的 Wasserstein 距离）。部署时只访问一个有限任务图 G_𝒯=(V,E)，节点为已验证任务 / 候选桥接，边 (T,T') 的代价含运输债务与验证成本。

**定义 312（证书泛函）** 把 R69 的 J_FLUID 视为任务上的泛函 J: 𝒯 → ℝ^m，分量包括 ECE、U_epi 前后、voi_ratio、a_score_p95、风险上界等。**证书过拟合**：J 在源任务采样上很小，但在 𝒯 的邻域内快速变化——即 J 的局部 Lipschitz 常数大。

**定义 313（证书敏感度场）** κ(T)=‖∇_𝒯 J(T)‖_*（对偶范数，逐分量加权取最大）。κ 大 = 该处「标定悬崖」；κ=∞ 或 J 不可微 = 任务类型跳变。κ 由有限探针 {T_i} 上的差分估计，估计误差 ≤ ε_κ（A102）。

**定义 314（证书债务）** 对路径 γ:[0,1]→𝒯，γ(0)=T_src，γ(1)=T_tgt，
D(γ)=∫_0^1 κ(γ(s))·‖γ'(s)‖ ds；最小债务 D*(T_src,T_tgt)=inf_γ D(γ)。**债务预算** D_max=τ_ece−ECE_src（或按风险额度换算）。债务沿路径可加，故可用最短路求解。

**定义 315（证书运输算子 CTF）** Φ_{T→T'}: J ↦ J' 按分量三分：
(i) **不变量**（如安全包络 ε_int、证据纪律）原样保留；
(ii) **可重估量**（如成本 c(g)、阈值 τ_ece）用 T' 的小样本重估并给置信区间；
(iii) **不可迁移量**（如 ECE、模态校准）**必须**由路径债务界或目标侧证据重新认证，否则置为未知。
V_trans(J,T') 为真 ⇔ ∃ 路径使 D(γ)+重估不确定度 ≤ D_max，且切迹裕度 ≥ m。

**定义 316（证书切迹与同伦类）** 切迹 C={T: κ(T)=∞} ∪ {任务类型不连续点}。T_src 与 T_tgt **证书同伦**（记 T_src ~_cert T_tgt）⇔ 存在一条不穿越 C 的路径。~_cert 把任务划分为证书同伦类；跨类运输由定义 319 判为不可证。

**定义 317（桥接任务与桥接图）** 桥接任务 T_b 是位于 T_src 与 T_tgt 之间、验证成本低、且能把高 κ 区「绕过」的任务（参数插值、简化子任务、仿真变体）。桥接图节点 = 已验证任务 ∪ 候选桥接 ∪ 目标；边权 w(T,T')=D_path(T,T')+λ_v·c_validate(T')+λ_r·risk(T')。

**定义 318（任务级 VoI / 主动桥接 ABP）** 对候选桥接 T_b，
VoI_task(T_b)=E_{y~T_b}[D*_est(T_src,T_tgt | T_b 已验证)] 的期望下降 − c_validate(T_b) − c_exec(T_b)。
选 T_b*=argmax VoI_task(T_b)，s.t. 预算与安全；VoI_task ≤ 0 则不桥接（直跳或重接地）。这是 R69 定义 298 在任务层的递归。

**定义 319（路径规划目标 TPP）** 求 γ*=argmin_γ [D(γ)+λ_v·ValidationCost(γ)+λ_r·Risk(γ)]，s.t. D(γ) ≤ D_max、dist(γ,C) ≥ m、每个途经任务 V_trans 可行、总验证预算 ≤ B_val。若不存在可行 γ：当 T_src ≁_cert T_tgt 时**在目标上重新接地**（等于 R69 从零运行）；否则报告「预算内不可运输」并走保守（不迁移、逐任务跑 R69）。

**定义 320（证书充分性门 CSG）** 三档硬门：
(i) **运输档**：D*(γ*) ≤ D_max ∧ 裕度达标 ∧ CIM 无报警 ⇒ 携带 J_src 到目标，给 resolution bonus（直接复用 R69 的 λ_floor 与 VoI）；
(ii) **桥接档**：直接运输不可行但存在可行路径 ⇒ 先执行桥接，再运输；
(iii) **重接地档**：切迹阻断或预算不足 ⇒ 丢弃 J_src，在目标上重跑 R69 完整标定（λ 回到最保守的冷启动）。

**定义 321（证书膨胀界与在线监测 CIM）** 由 A100，运输后 ECE(T') ≤ ECE(T_src)+D(γ)+ε_κ。CIM 在目标侧用任何可得证据（少量标签、环一致性、R69 的 FMA 双通道）估计**实际膨胀** Δ_obs；若 Δ_obs > D(γ)+m_monitor ⇒ 判定「运输假设被违反」，立即降级为定义 320-iii。CIM 是任务级的「第二意见」，对应 R69 定义 301 在任务层的镜像。

**定义 322（任务条件适配器 TCA）** 策略与标定参数写成 π_θ(·|T)=π_core ⊕ Adapter_φ(θ)，Adapter 只允许低秩 / 小容量更新，并以**证书保持正则** R_cert=‖J(Φ_{T→T'}(J_src))−J_src‖ 受限。适配器容量预算与验证预算共同进入 D_max 的核算（适配器越强，κ 越可能被低估，需更大裕度）。

**定义 323（负迁移与证书伪装）** **负迁移**：实际风险或 ECE 膨胀超过债务界（Δ_obs > D+m）。**证书伪装**：源任务证书本身被污染（投毒源任务），使 J_src 假性健康、κ 被低估。二者都由 CIM + 源任务审计（VQAuditor-T 交叉复核）检测；检测到即降级定义 320-iii。

**定义 324（审计与威胁模型）** VQAuditor-T 审计迁移决策：路径是否越过切迹、债务估计是否被单一探针主导、桥接是否被投毒、适配器是否悄悄改变安全包络。AIC-COMPASS = AIC-FLUID × ℰ_transfer × ℰ_bridge，其中 ℰ_transfer = 源任务投毒 / 标定伪装 / 任务度量投毒；ℰ_bridge = 桥接任务投毒 / 捷径诱导（把系统骗进高 κ 区）。

**定义 325（证书 J_COMPASS）** J_COMPASS = (J_FLUID, T_src_id, T_tgt_id, cert_homotopy_class, path_hash, D_path, D_max, cut_locus_margin, cim_max_violation, transport_ver)。Valid ⇔ Valid(J_FLUID@T_tgt) ∧ D_path ≤ D_max ∧ margin ≥ m ∧ cim_max_violation ≤ 0。

## 2. 关键算法骨架

```python
# IP-264/265 TCM+CTF：证书敏感度场与运输算子
class CertificateManifold:
    def sensitivity(self, T, probes):              # κ(T)=||∇J||_*
        Js = [self.J(T_i) for T_i in probes(T)]
        return weighted_dual_norm(finite_difference(Js, probes(T)))

    def transport(self, J_src, T_src, T_tgt, gamma):
        J = clone(J_src)
        J.invariant = J_src.invariant              # ε_int / 证据纪律原样
        J.refit     = refit_bound(T_tgt, small_budget)   # 成本 / 阈值
        J.ece       = UNKNOWN                      # 必须由债务界或 CIM 认证
        return J

# IP-266/267/268 CDM+TPP+CCL：带切迹约束的证书债务最短路
def plan_certificate_path(T_src, T_tgt, graph, kappa, D_max, margin):
    edge_cost = lambda a, b: integrate_kappa(kappa, a, b) + lam_v * validate_cost(b)
    # κ=∞ 的切迹边直接删除；只保留与源点证书同伦的节点
    reach = dijkstra(graph, src=T_src, edge_weight=edge_cost,
                     node_filter=lambda T: same_homotopy(T_src, T, kappa)
                                           and margin_to_cut(T, kappa) >= margin)
    if T_tgt not in reach:
        return None                                # → 重新接地
    return reconstruct_path(reach, T_tgt), reach[T_tgt]

# IP-269 ABP：任务级 VoI 主动桥接（R69 MINT 的递归）
def choose_bridge(T_src, T_tgt, candidates, budget):
    best = None
    for T_b in candidates:
        if not budget.allow(T_b) or not safe(T_b):
            continue
        gain  = expected_debt_reduction(T_src, T_tgt, T_b)   # E[ΔD*]
        score = gain - validate_cost(T_b) - exec_cost(T_b)
        if best is None or score > best.score:
            best = (T_b, score)
    return best if best and best.score > 0 else None

# IP-271/272 CIM+CSG：在线证书膨胀监测与三档门
def certificate_gate(J_src, path, obs, labels):
    D, pred = path.debt, J_src.ece + path.debt + EPS_K
    delta_obs = observe_inflation(obs, labels)          # 目标侧证据
    if delta_obs > pred + M_MONITOR:
        return 'reground'                               # 运输假设被违反
    if path.debt <= D_MAX and path.margin >= M_CUT:
        return 'transport'
    return 'bridge'

# IP-274 主闭环（meta 层规划 + R69 实时层执行）
def COMPASS_round(M, T_tgt, obs):
    if not M.cert_homotopy(T_src, T_tgt):               # 切迹阻断
        M.reground(T_tgt); return M.R69_round(obs)      # 严格退化 R69
    path, D = M.tpp.plan_certificate_path(T_src, T_tgt, M.graph, M.kappa,
                                          M.D_max, M.margin)
    if path is None:
        M.reground(T_tgt); return M.R69_round(obs)
    while D > M.D_max and M.budget.left():              # 主动桥接
        T_b = M.abp.choose_bridge(T_src, T_tgt, M.candidates, M.budget)
        if T_b is None: break
        M.execute_bridge(T_b)
        path, D = M.tpp.replan(T_src, T_tgt, M.graph)
    J_t  = M.ctf.transport(M.J_src, T_src, T_tgt, path)
    mode = M.csg.certificate_gate(J_t, path, obs, M.labels)
    if mode == 'reground':
        M.reground(T_tgt); return M.R69_round(obs)
    if mode == 'bridge':
        M.execute_bridge(path.next()); return COMPASS_round(M, T_tgt, obs)
    return M.R69_round_with_certificate(J_t, obs)       # R69 实时环，享 bonus
```

## 3. 推导

**引理 19（运输的 Grönwall 界）** 设 J 沿 γ 分段 C¹，则 ‖J(γ(1))−J(γ(0))‖ ≤ ∫_0^1 ‖∇J(γ(s))‖·‖γ'(s)‖ ds = D(γ)。推论：ECE / 风险沿路径的膨胀不超过证书债务；D 既是「信任漂移」的严格上界，也是可加的路径代价。

**引理 20（桥接可能严格优于直跳）** 若直跳线段穿过高 κ 区，而存在绕行 γ_b 使 D(γ_b) < D(直跳)，则桥接路径严格更优；且当 T_b 落在测地线上时 D(T0,T*)=D(T0,T_b)+D(T_b,T*)。推论：**「多做一个中间任务」不一定更贵**——它可能把一条穿过标定悬崖的昂贵直跳换成两段平缓路径。

**引理 21（任务级投毒可检测性）** 若源证书被投毒使 J_src 假性健康，则要么 (i) κ 被同向压低、导致 CIM 的 Δ_obs 超出预测，要么 (ii) 沿路径的多个独立探针给出不一致的 J。故「单探针 + 单源证书」下不可检测，而「多探针交叉 + 目标侧证据」下可检测（定义 323）。系：证书同伦类必须由至少两个独立探针确认，否则不得作为运输起点。

**定理 18（运输充分性）** 在 A99–A102 下，若存在路径使 D(γ) ≤ D_max、切迹裕度 ≥ m、且 CIM 未报警，则运输后的证书在 T_tgt 上满足 ECE ≤ τ_ece 与风险 ≤ 源风险 + D(γ)。因此零样本迁移**带证可证**，而非「看起来没问题」。

**定理 19（切迹不可辨识性）** 若 T_tgt 与 T_src 不在同一证书同伦类，则不存在任何仅依赖源侧观测与源证书的运输算子能在 T_tgt 上给出可证有效的 J。证明要点：构造两个任务 T'、T''，它们在源侧产生完全相同的观测与证书，但在目标侧风险相差 > D_max；任何只读源侧证据的 Φ 无法区分二者。故最优策略是定义 319 的重新接地。**这是本轮最重要的负面结论**：跨任务泛化的边界不是「模型不够大」，而是**可辨识性**。

**定理 20（主动桥接的近似最优性）** 若任务级债务下降函数在候选桥接上自适应次模（A103），则贪心 ABP 的总成本 ≤ (1+ln K_b) 倍最优桥接序列；在单调且桥接成本有界时进一步收紧。系：任务级 VoI 是 R69 模态级 VoI 的自然递归，并继承 R69 的预算硬约束。

**定理 21（严格包含 R69 与安全单调性）** 目标 = 源或 D*=0 时 COMPASS 不插桥、逐指令等于 R69；切迹阻断或预算不足时在目标上重新接地，等于 R69 从零运行；运输档只在**不削弱**任何安全约束的前提下给 resolution bonus。故 COMPASS 的期望风险 ≤「逐任务独立跑 R69」的策略，且安全侧永不更弱。

## 6. 本轮最大风险

**一句话**：COMPASS 的全部收益押在「证书敏感度场 κ 被正确估计、任务流形坐标有意义」这一前提上——**若 κ 在切迹附近被系统性低估（有限探针看不到标定悬崖），规划器会自信地选出一条「看起来很便宜」的路径，把一张已经失效的证书运过悬崖，并盖上「跨任务已验证」的章；这比不迁移更危险，因为它把一次局部标定失败洗成了系统级的信任**——R69 是「问错比不问更危险」，R70 是「**带着旧证书迁移，比老老实实重新标定更危险**」。

**次级风险与缓解**：
1. **切迹定位错误**（κ 估计误差）→ 裕度 m > 2ε_κ + 多探针交叉 + E303 允许保守误拒；
2. **证书伪装 / 源任务投毒** → 引理 21 双探针 + VQAuditor-T 源侧复核 + E309；
3. **桥接投毒 / 捷径诱导** → ABP 安全门 + CIM 在线监测 + ℰ_bridge 对抗训练 + E310；
4. **债务界过松导致「证书永不运输」** → 债务界按分位数校准 + E313 紧致性 + 允许分阶段 resolution bonus；
5. **任务流形坐标本身无意义**（d_𝒯 选错）→ 用任务嵌入 + 下游证书预测误差反向选择度量（度量学习），并保留「重接地」兜底。

class CertificateManifold:
    def sensitivity(self, T, probes):
        Js = [self.J(T_i) for T_i in probes(T)]
        return weighted_dual_norm(finite_difference(Js, probes(T)))
    def transport(self, J_src, T_src, T_tgt, gamma):

        J.invariant = J_src.invariant              # ε_int / 证据纪律
        J.refit     = refit_bound(T_tgt, small_budget)

# IP-266/267/268 CDM+TPP+CCL：切迹约束下的债务最短路
def plan_certificate_path(T_src, T_tgt, graph, kappa, D_max, margin):
    cost = lambda a, b: integrate_kappa(kappa, a, b) + lam_v*validate_cost(b)
    reach = dijkstra(graph, src=T_src, edge_weight=cost,
                     node_filter=lambda T: same_homotopy(T_src, T, kappa)
                                           and margin_to_cut(T, kappa) >= margin)
    return (None if T_tgt not in reach
            else (reconstruct_path(reach, T_tgt), reach[T_tgt]))

# IP-269 ABP：任务级 VoI 主动桥接
def choose_bridge(T_src, T_tgt, candidates, budget):
    best = None
    for T_b in candidates:
        if not budget.allow(T_b) or not safe(T_b): continue
        score = expected_debt_reduction(T_src,T_tgt,T_b) - validate_cost(T_b) - exec_cost(T_b)
        if best is None or score > best.score: best = (T_b, score)
    return best if best and best.score > 0 else None    # 无利可图 → 直跳/重接地

def certificate_gate(J_src, path, obs, labels):

    if observe_inflation(obs, labels) > pred + M_MONITOR: return 'reground'

## 4. 推导

**引理 19（运输的 Grönwall 界）** J 沿 γ 分段 C¹ ⇒ `‖J(γ(1))−J(γ(0))‖ ≤ ∫‖∇J‖‖γ'‖ds = D(γ)`。ECE/风险膨胀不超过证书债务；D 是信任漂移的严格上界，也是可加路径代价。

**引理 20（桥接可能严格优于直跳）** 直跳穿高 κ 区、存在绕行 γ_b 使 `D(γ_b)<D(直跳)` 时桥接更优；T_b 在测地线上时债务按段相加。系：「多做中间任务」不一定更贵，可能把穿悬崖的昂贵直跳换成两段平缓路径。

**引理 21（任务级投毒可检测性）** 源证书被投毒使 J_src 假性健康时，要么 κ 被同向压低致 `Δ_obs` 超预测，要么多独立探针给出不一致 J。单探针 + 单源不可测；多探针交叉 + 目标侧证据可测。系：同伦类至少需两个独立探针确认才能作为运输起点。

**定理 18（运输充分性）** A99–A102 下，若 ∃ 路径使 `D(γ)≤D_max`、裕度 ≥ m、CIM 未报警，则运输证书在 T_tgt 满足 `ECE≤τ_ece` 且风险 ≤ 源风险 + D(γ)。零样本迁移带证可证。

**定理 19（切迹不可辨识性）** 若 T_tgt ≁_cert T_src，则不存在仅依赖源侧观测与源证书的运输算子能在 T_tgt 给出可证有效的 J。证明：构造两任务在源侧观测/证书完全相同、目标侧风险相差 > D_max，任何只读源侧证据的 Φ 无法区分。故最优策略是重接地。**跨任务泛化的边界是「可辨识性」，不是模型容量。**

**定理 20（主动桥接近似最优）** 债务下降函数在候选上自适应次模（A103）时，贪心 ABP 总成本 ≤ `(1+ln K_b)` 倍最优；单调且有界时进一步收紧。任务级 VoI 是 R69 模态级 VoI 的递归。

**定理 21（严格包含 R69 与安全单调性）** 目标 = 源或 D*=0 时不插桥、逐指令等于 R69；切迹阻断或预算不足时重接地，等于 R69 从零跑；运输档只在**不削弱**任何安全约束的前提下给 resolution bonus。故期望风险 ≤「逐任务独立跑 R69」，安全侧永不更弱。

| κ 估计（离线、有限探针） | 分钟级 / 任务族一次 | O(\|探针\|·m) | 定义 313、A102 |
| TPP 最短路（N 节点 E 边） | O((E+N) log N) | O(N+E) | 定义 319、引理 19–20 |
| ABP 任务级 VoI（候选 ≤ K_b） | O(K_b·规划) | O(K_b) | 定义 318、定理 20 |
| CTF 运输 + 重估 | O(m + 小样本标定) | O(m) | 定义 315 |
| CIM 在线监测 | < 0.1ms | O(1) | 定义 321 |
| CSG 三档门 | < 0.01ms | O(1) | 定义 320 |
| **R69 实时环路（继承）** | 与 R68/R69 持平（< 2.6ms） | 同 R69 | 定理 18、21 |

要点：规划 / 桥接发生在**元时间尺度**（离线或任务切换），不进入 2.6ms 实时回路；实时环仅在 CSG 选定证书下跑 R69，零额外实时负担。

## 7. 本轮最大风险

**一句话**：COMPASS 的全部收益押在「κ 被正确估计、任务流形坐标有意义」上——**若 κ 在切迹附近被系统性低估（有限探针看不到标定悬崖），规划器会自信地选出一条「看起来很便宜」的路径，把已失效的证书运过悬崖并盖上「跨任务已验证」的章；这比不迁移更危险，因为它把一次局部标定失败洗成了系统级信任**——R69 是「问错比不问更危险」，R70 是「**带旧证书迁移，比老老实实重新标定更危险**」。

**次级风险与缓解**：切迹定位错误（裕度 m > 2ε_κ + 多探针 + E303）；证书伪装/源投毒（引理 21 双探针 + VQAuditor-T + E309）；桥接投毒/捷径诱导（ABP 安全门 + CIM + ℰ_bridge 对抗训练 + E310）；债务界过松致拒绝运输（分位数校准 + E313 + 分阶段 bonus）；任务度量无意义（度量学习 + 重接地兜底）。
