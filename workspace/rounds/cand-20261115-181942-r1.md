# 第 9 轮（本次会话第 1 轮 / 全局第 9 轮；灵感：「桌面操作」×「仿真到现实迁移」）

> **基线**：第 8 轮 MetricVoiceGauge-DA-SPR-Cal（定义 493–540；引理 77–81；实验 E531–E550）。
> 本轮纪律：把「桌面操作」当作**受限几何域**、把「仿真到现实迁移」当作**接触动力学域偏移**问题，而不是又叠一层视觉 MMD。新增模块必须与 v8 的 DA/SPR/Cal **正交**，且任一模块失效可平滑退化回 v8。

## 0. 直觉与动机

**灵感 1（桌面操作 → 可证明的受限几何）**
桌面是一个「低维流形」：物体被桌面支撑，重力方向固定，操作准静态，工作空间有边界。通用 6-DoF 操作里难以形式化的「稳不稳、会不会掉下去、能不能够到」，在桌面上都能写成支撑多边形、包含边距、可达流形上的可证判据。桌面因此是把「安全」从统计指标变成**几何证书**的最佳试验场。

**灵感 2（仿真到现实迁移 → 视觉像 ≠ 物理像）**
v8 的域偏移 Δ_dom 是感知特征（ResNet 256 维）的 MMD，对光照、纹理、背景有效，却对**接触参数漂移**几乎不敏感：摩擦系数从 0.6 变 0.3、恢复系数变化、质心偏移几厘米，画面可以一模一样，但一推就滑、一放就倒。桌面操作的 Sim2Real gap 主项在接触而非外观。因此需要第二条正交通道：**接触域偏移 Δ_dyn**，由真实/仿真的接触力旋量、滑移事件和物体位姿残差来度量。

**交叉洞察（1+1>2）**
桌面操作天然提供**安全探针**：轻推、轻放、轻抬都是低风险接触，可用它们在线辨识摩擦/恢复/质量参数，主动收缩 sim2real 不确定性；一旦 gap 或参数不确定性过大，系统自动降级到保守技能，并给出可审计的迁移证书。这把 v8 的「感知风险 → 权重」升级为「**物理可信度 → 自主性许可**」。

## 1. 研究问题

- **Q1（接触域偏移）**：如何定义与感知域偏移 Δ_dom 正交、可在线估计、对摩擦/质量/质心漂移敏感的接触域偏移 Δ_dyn？
- **Q2（桌面几何判据）**：支撑稳定性、边界包含性、可达性如何进入指标层级，并在不破坏 v8 六层结构的前提下提供可证安全？
- **Q3（主动辨识）**：在 50Hz 硬实时、零碰撞约束下，如何调度桌面探针，使接触参数后验不确定性下降最快？
- **Q4（迁移证书）**：在 sim2real 分布偏移下，如何给出分布无关、可审计的真实成功率下界，并据此决定自主性等级？

## 2. 设计原则（在 P7–P9 上升级为 P10–P14）

**P10 双通道域偏移（Dual-Channel Domain Gap）**
感知通道 Δ_dom（继承 v8）与接触通道 Δ_dyn 并行，前者进 M_dom，后者进 M_dyn；二者只通过风险向量汇合，不共享状态，保证正交退化。

**P11 桌面几何判据（Tabletop Affordance Ladder, TAL）**
新增 M_table 层：支撑稳定性保证金 stab、边界包含边距 contain、可达性 reach、稀疏净空 clearance。判据均为几何量，可在仿真与真实中同一尺度测量。

**P12 现实锚定系统辨识（Reality-Anchored System ID, RASI）**
对接触参数 θ=(μ_s, μ_k, e, m, c_com, τ_lat) 维护贝叶斯后验；用桌面探针的真实结果做在线更新，把后验不确定度 u(t)=tr(Σ_θ) 注入 τ 收紧。

**P13 主动探针调度（Probe Scheduling, PS）**
只从「包含性/稳定性满足 + 碰撞距离 > 0」的安全探针集合中选动作，按期望信息增益/风险比贪心选取，探针在独立线程执行、主环只读结果。

**P14 迁移证书与 gap 条件屏蔽（SRTC + GapShield）**
只有当 Δ_dyn ≤ τ_gap 且后验不确定度 u ≤ u_max 且 M_table 全满足时，才允许激进技能；否则降级为保守原语。证书给出真实成功率下界，随证书一起发布到 ROS。

## 3. 与 v8 的接口（如何退化）

- **L1**：TAL 失效 ⇒ M_table 判据恒真，退回 v8 六层指标；
- **L2**：CGE 失效 ⇒ Δ_dyn ≡ 0，M_dyn 关闭，退回 v8 的纯感知 DA；
- **L3**：RASI 失效 ⇒ θ 取名义值、u ≡ 0，τ 不再被后验收紧；
- **L4**：PS 失效 ⇒ 仅被动估计不主动探测，Δ_dyn 仍可算但收敛更慢；
- **L5**：SRTC/GapShield 失效 ⇒ 证书恒通过，退回 v8 的 SoftCert；
- **L0**：全部失效 ⇒ 完整退回 MetricVoiceGauge-DA-SPR-Cal v8，再退回 v7。

## 4. 预期贡献

1. **接触域偏移 Δ_dyn**：把 sim2real gap 从「视觉相似」推进到「物理可信」，与感知 MMD 正交；
2. **桌面几何证书**：支撑多边形/包含边距/可达性给出准静态可证的桌面上安全；
3. **主动现实锚定辨识**：利用桌面安全探针在线收缩接触参数不确定性，并给出贪心近优性保证；
4. **gap 条件迁移证书**：分布无关的真实成功率下界 + 自主性降级，形成「感知-接触-几何-辨识-证书-动作」六元闭环，实验 E551–E570。

## 5. 本轮最大风险

**一句话**：接触参数后验与 Δ_dyn 都依赖「接触力/滑移可被可靠观测」这一前提，真实桌面上的力传感噪声、遮挡与接触事件稀疏会使后验长期欠收敛，进而让迁移证书给出的成功率下界过于保守、系统频繁降级而丧失效率——「用一个观测不足的物理模型去担保另一个物理模型」。

**定义 542（桌面工作空间与包含边距 TabletopWorkspace）**
```
W = (P, ∂P, g),   F_o(t) = π_P( contact_region(o) ) ⊆ P
contain_o(t) = dist(c_o(t), ∂P) − r_o^safe
M_table.contain 满足  ⇔  contain_o(t) ≥ 0  ∧  F_o(t) ⊆ P
```
其中 r_o^safe 为物体外接圆半径 + 安全余量。

**定义 543（支撑稳定性 SupportStability）**
```
S_o(t) = conv({p_k(t) : p_k 为 t 时刻与 P 的接触点})
stab_o(t) = signed_dist(c_o(t), ∂S_o(t))
M_table.stab 满足  ⇔  stab_o(t) ≥ m_min  ∧  |θ_tilt(t)| ≤ θ_max
```
准静态下，c_o 位于 S_o 内部是**无倾覆**的必要条件；m_min 吸收位姿估计误差。

**定义 544（桌面可达性 TabletopReachability）**
```
reach_o(t) = 1[ IK(q_target) 有解 ] · 1[ μ_manip(q_t) ≥ μ_min ] · 1[ q_margin(t) ≥ m_j ]
M_table.reach 满足  ⇔  reach_o(t) = 1  ∧  clr_o(t) ≥ clr_min
```
μ_manip 为可操作度（Yoshikawa 指标），q_margin 为关节限位余量。

**定义 545（接触状态对齐 ContactStateAlignment）**
```
c_t = ( w_t ∈ ℝ⁶, {p_k(t)} ⊆ ℝ³, ṡ_t ∈ ℝ³, q_t ∈ SE(3) )
r_t = A_t ⊙ ( c_t^real − c_t^sim ),   A_t 为可观测性/置信门控（0/1 对角）
```
真实与仿真的接触帧先由标定 T_cal 对齐（复用 v8 OnlineCalib-FI 的 T_est），再比较。

**定义 546（接触域偏移 ContactGap）** 对残差做鲁棒、归一化的滑动统计：
```
Δ_dyn(t) = sqrt( (1/|H_t|) Σ_{k∈H_t} ρ_τ( r_k^T Σ_r^{-1} r_k ) )
```
H_t 为最近 W_d 个**有效接触事件**（非全时步），Σ_r 为残差协方差（在线估计），ρ_τ 为 Huber 函数（τ=1.5）。分量为：
```
Δ_wrench = 力旋量残差分量,  Δ_slip = 滑移事件率差,  Δ_pose = 物体位姿漂移
Δ_dyn = sqrt( Δ_wrench² + Δ_slip² + Δ_pose² )   （加权形式，权重≥0）
```

**定义 547（接触参数后验 ContactParamPosterior）**
```
p(θ | D_t) ∝ p(D_t | θ) p_0(θ),   D_t = {(a_k, y_k)}_{k≤t} 探针-结果对
u(t) = tr(Σ_θ(t)),  Σ_θ(t) = Cov[θ | D_t]
```
似然 y_k | θ 由准静态接触模型给出：推动距离、滑移起始、落地反弹高度、抬升所需力。

**定义 548（探针期望信息增益 ProbeInfoGain）**
```
IG(a) ≈ ½ log det( I + Σ_θ J_a^T Σ_y^{-1} J_a ),   J_a = ∂E[y | θ,a]/∂θ |_{θ=θ̂}
```
其中 Σ_y 为观测噪声协方差。该式为高斯后验下的 D-最优近似。

**定义 549（迁移证书 Sim2RealTransferCert）** 给定 gap d=Δ_dyn 的校准集，发布
```
Cert(d, α) = 1[ d ≤ τ_gap ] · 1[ u ≤ u_max ] · 1[ M_table 全满足 ]
下界:  P_real(success) ≥ 1 − α − L · d
```
其中 L 为成功率对接触状态残差的 Lipschitz 常数（由上界估计或分位数回归给出）。

**定义 550（gap 条件屏蔽 GapConditionedShield）**
```
autonomy_level =
  3 (激进)  若 Cert=1 ∧ d ≤ τ_gap/2 ∧ u ≤ u_max/2
  2 (标准)  若 Cert=1
  1 (保守)  若 d ≤ τ_gap ∧ (u > u_max ∨ ¬M_table)
  0 (仅M₀)  若 d > τ_gap ∨ 关键几何违反
```
level 1 只允许 pick/place/推的保守参数化；level 0 只执行 M₀ 硬约束与停机/回撤。

**定义 551（八层指标闭合 MetricLadder v9）**
```
M = (M₀, M₁, M₂, M₃, M_dom, M_SLAM, M_table, M_dyn)
```

M_table 与 M_dyn 的退化映射 δ_table, δ_dyn 均定义为“直接触发 M₀ 硬约束检查”，且 τ_table, τ_dyn 与 τ_safe 使用同一“违背概率上界”尺度。

## 2. 形式化定义（要点）

- **定义 542（桌面工作空间）**：包含性 = 质心投影到桌边的距离扣除安全半径；footprint 必须整体在 P 内。
- **定义 543（支撑稳定性）**：稳定保证金 = 质心投影到支撑多边形边界的有符号距离；配合倾角约束吸收姿态误差。
- **定义 544（可达性）**：IK 可行 × 可操作度 × 关节余量 × 净空，全为布尔/几何量。
- **定义 545（接触状态对齐）**：真实与仿真在标定后的接触帧比较，门控剔除遮挡/无接触时步。
- **定义 546（接触域偏移）**：只统计有效接触事件的鲁棒马氏残差，避免自由飞行段稀释 gap。
- **定义 547（接触参数后验）**：贝叶斯后验，u=tr(Σ_θ) 作为 τ 的收紧信号。
- **定义 548（探针信息增益）**：D-最优近似，用于 PS 的贪心排序。
- **定义 549（迁移证书）**：gap 条件 + 不确定度 + 几何三重门槛，输出成功率下界。
- **定义 550（gap 条件屏蔽）**：四级自主性，只降不升式安全回退。
- **定义 551（八层闭合）**：新层全部退化到 M₀，无软通过硬失。
- **定义 552（系统标识）**：v9 与 v8 的可判定差异仅在三处接口。

## 3. 关键算法骨架

```python
# IP-355 ContactGapEstimator：接触域偏移
class ContactGapEstimator:
    def __init__(self, W=30, huber_tau=1.5, eps=1e-6):
        self.W = W                      # 有效接触事件窗口
        self.huber_tau = huber_tau
        self.eps = eps
        self.residuals = []             # 归一化残差平方
        self.Sigma_r = np.eye(13)       # 在线残差协方差（w6+p3+s3+q? 对齐后维数）
        self.n_seen = 0

    def update_covariance(self, r):
        self.n_seen += 1
        eta = max(1.0 / self.n_seen, 1e-3)
        self.Sigma_r = (1 - eta) * self.Sigma_r + eta * np.outer(r, r)

    def push(self, real_contact, sim_contact, gate):
        if not gate.any():
            return                      # 无有效接触，不计入
        r = gate * (real_contact - sim_contact)
        self.update_covariance(r)
        m2 = float(r @ np.linalg.pinv(self.Sigma_r + self.eps * np.eye(len(r))) @ r)
        self.residuals.append(m2)
        if len(self.residuals) > self.W:
            self.residuals.pop(0)

    @staticmethod
    def _huber(x, tau):
        return x if x <= tau * tau else 2 * tau * np.sqrt(x) - tau * tau

    def delta_dyn(self):
        if len(self.residuals) < 3:
            return 0.0                  # 预热期不收紧
        robust = np.mean([self._huber(x, self.huber_tau) for x in self.residuals])

# IP-354 TabletopAffordanceLadder：桌面几何层
class TabletopAffordanceLadder:
    def __init__(self, m_min=0.02, r_safe_margin=0.01,
                 theta_max=np.deg2rad(12), mu_min=0.05,
                 clr_min=0.01, joint_margin_min=0.05):
        self.m_min = m_min
        self.r_safe = r_safe_margin
        self.theta_max = theta_max
        self.mu_min = mu_min
        self.clr_min = clr_min
        self.jm_min = joint_margin_min

    def stab_margin(self, com_xy, contact_points_xy):
        poly = convex_hull(contact_points_xy)
        return signed_distance_to_polygon(com_xy, poly)   # 内正外负

    def containment_margin(self, com_xy, radius, table_polygon):
        return distance_to_polygon_boundary(com_xy, table_polygon) - radius - self.r_safe

    def evaluate(self, obj, robot):
        stab = self.stab_margin(obj.com_xy, obj.contact_pts_xy)
        contain = self.containment_margin(obj.com_xy, obj.radius, obj.table_poly)
        reach = (robot.ik_feasible(obj.grasp_pose)
                 and robot.manipulability() >= self.mu_min
                 and robot.joint_margin() >= self.jm_min)
        clr = obj.min_clearance()
        ok = (stab >= self.m_min and abs(obj.tilt) <= self.theta_max
              and contain >= 0 and reach and clr >= self.clr_min)
        return {'ok': ok, 'stab': stab, 'contain': contain,
                'reach': reach, 'clearance': clr,
                'risk_table': self._risk(stab, contain, clr)}

    def _risk(self, stab, contain, clr):
        # 归一到 [0,1]，越小越安全；用于 7 维风险向量第 6 维
        return float(np.clip(1.0 - min(stab / self.m_min, 1.0), 0, 1)
                     + np.clip(1.0 - min(max(contain, 0) / 0.05, 1.0), 0, 1)
                     + np.clip(1.0 - min(clr / self.clr_min, 1.0), 0, 1)) / 3.0


# IP-356 RealityAnchoredSystemID：接触参数贝叶斯辨识
class RealityAnchoredSystemID:
    def __init__(self, theta0, Sigma0, obs_noise=0.02):
        self.theta = np.array(theta0, float)     # (μs, μk, e, m, cx, cy, τlat)
        self.Sigma = np.diag(Sigma0)
        self.R = obs_noise ** 2 * np.eye(4)      # 观测: 推动位移/滑移/反弹/抬升力
        self.probe_log = []

    def predict_outcome(self, action):
        mu_s, mu_k, e, m, cx, cy, tau = self.theta
        # 准静态桌面模型（简化）: 推力阈值、滑移加速度、反弹高度、抬升力
        return np.array([push_threshold(mu_s, m, action),
                         slip_accel(mu_k, m, action),
                         bounce_height(e, action),
                         lift_force(m, cx, cy, action)])

    def jacobian(self, action, h=1e-5):
        J = np.zeros((4, len(self.theta)))
        f0 = self.predict_outcome(action)
        for i in range(len(self.theta)):
            d = np.zeros_like(self.theta); d[i] = h
            J[:, i] = (self.predict_outcome_custom(self.theta + d, action) - f0) / h
        return J

    def update(self, action, y_real):
        J = self.jacobian(action)
        y_hat = self.predict_outcome(action)
        S = J @ self.Sigma @ J.T + self.R
        K = self.Sigma @ J.T @ np.linalg.inv(S)
        self.theta = self.theta + K @ (y_real - y_hat)
        self.Sigma = (np.eye(len(self.theta)) - K @ J) @ self.Sigma
        self.probe_log.append((action, y_real))
        return self.theta, self.uncertainty()

    def uncertainty(self):
        return float(np.trace(self.Sigma))

    def info_gain(self, action):
        J = self.jacobian(action)
        S = J @ self.Sigma @ J.T + self.R
        M = np.eye(len(self.theta)) + self.Sigma @ J.T @ np.linalg.inv(self.R) @ J
        return 0.5 * float(np.linalg.slogdet(M)[1])


# IP-357 ProbeScheduler：安全探针贪心调度
class ProbeScheduler:
    def __init__(self, rasi, tal, budget=3, risk_weight=2.0):
        self.rasi = rasi
        self.tal = tal
        self.budget = budget
        self.risk_weight = risk_weight

    def candidate_probes(self, obj):
        # 桌面安全探针库：轻推四方向、轻抬、轻放、轻转
        return [dict(kind='push', dir=d, delta=0.01) for d in ('+x', '-x', '+y', '-y')] \
             + [dict(kind='lift', delta=0.015), dict(kind='place', delta=0.010),
                dict(kind='rotate', delta=np.deg2rad(5))]

    def is_safe(self, obj, action):
        # 保守预测探针后的几何状态：包含性/稳定性/净空必须仍满足
        pred = predict_after(obj, action)
        return (self.tal.containment_margin(pred.com_xy, pred.radius, pred.table_poly) >= 0
                and self.tal.stab_margin(pred.com_xy, pred.contact_pts_xy) >= self.tal.m_min
                and pred.min_clearance() >= self.tal.clr_min)

    def schedule(self, obj):
        safe = [a for a in self.candidate_probes(obj) if self.is_safe(obj, a)]
        scored = []
        for a in safe:
            ig = self.rasi.info_gain(a)
            sol = solve_probe_cost(a)          # 时间/能耗/占用
            scored.append((ig / (sol + self.risk_weight * probe_risk(a)), a, ig))
        scored.sort(reverse=True, key=lambda x: x[0])
        return [a for _, a, _ in scored[:self.budget]]

class Sim2RealTransferCert:
```

## 4. 推导

**引理 82（支撑稳定保证金的无倾覆充分条件）**
设桌面准静态，物体刚性、接触点集不变、摩擦锥足够，则 c_o(t) ∈ int(S_o(t)) 是绕任一支撑边不倾覆的必要条件；若进一步 stab_o(t) ≥ m_min 且 |θ_tilt| ≤ θ_max，则允许的质心估计误差 δ_c 满足 δ_c ≤ m_min / (1 + tan θ_max)，即 m_min 直接给出对感知误差的鲁棒半径。证明：倾覆绕支撑多边形某条边发生，力矩符号由 c_o 相对该边的有符号距离决定；距离 ≥ m_min > 0 时，误差 δ_c < m_min 不改变符号，故无倾覆。

**引理 83（接触偏移注入单调性与有界性）**
Σ_r ≻ 0 时 Δ_dyn = sqrt(ρ_τ(rᵀΣ_r^{−1}r)) ≥ 0；κ_dyn ≥ 0 故 τᵢ 中的 κ_dyn·Δ_dyn 项单调不减。若残差有界（真实传感器量程 + 仿真状态有界）且 Σ_r 的特征值有下界 λ_min>0，则 Δ_dyn ≤ sqrt(ρ_τ(‖r‖²/λ_min)) 有界。因此接触 gap 只会收紧、不会放宽 M₀/M₁ 阈值，也不会使阈值数值爆炸。

**引理 84（双通道正交退化，条件性）**
若 (i) Δ_dom 的特征提取器 φ 与接触参数 θ 统计独立，(ii) Δ_dyn 的残差 r 与感知外观特征 φ 条件独立（给定接触状态），则 ∂Δ_dom/∂θ ≈ 0、∂Δ_dyn/∂φ ≈ 0，两通道的梯度近似正交。因此在 CGE 失效（Δ_dyn≡0）时，M_dom/DA 行为与 v8 完全一致；在 DA 失效（Δ_dom≡0）时，M_dyn 行为不变。**注意这是可检验的假设，不是无条件定理**。

**引理 85（后验收缩率与探针的 D-最优性）**
在线性高斯观测 y = J_a θ + ε, ε~N(0,Σ_y) 下，n 次探针后的后验协方差满足 Σ_n = (Σ_0^{−1} + Σ_{k≤n} J_k^T Σ_y^{−1} J_k)^{−1}。故 tr(Σ_n) ≤ tr(Σ_0)/(1 + n·λ_min(Σ_0^{1/2} J^TΣ_y^{−1}J Σ_0^{1/2}))。定义 548 的 IG 正是使该下界中 λ_min 最大化的 D-最优准则；贪心每步选 IG 最大的安全探针，使 u(t) 单调下降（在不违反安全约束的前提下）。

**引理 86（gap 条件迁移下界）**
设真实接触状态分布 μ_real 与校准分布 μ_cal 的 1-Wasserstein 距离满足 W₁(μ_real, μ_cal) ≤ L·Δ_dyn（L 为成功率函数的 Lipschitz 常数）。若校准集上经验成功率的 conformal 下界为 1−α，则由传输不等式，P_real(success) ≥ 1−α−L·Δ_dyn。定义 549 用该式发布下界；当 Δ_dyn ≤ (α−α')/L 时仍保证 ≥ 1−α'。**该界依赖 Lipschitz/传输假设，需在实验中检验其保守性**。

**引理 87（探针贪心近优）**
若 IG(a) 在候选探针集合上是单调子模的（高斯 D-最优在独立观测下满足），则预算 B 的贪心选择满足 IG_greedy ≥ (1−1/e)·IG_OPT。安全过滤只会缩小候选集，不破坏子模性，故近优性在约束子集上仍成立。

**引理 88（八层软硬约束无空洞）**
δ_trigger = {σ<τ_safe ∧ γ_grasp valid ∧ Δ_dom<τ_dom ∧ risk_SLAM<τ_SLAM ∧ M_table 满足 ∧ Δ_dyn<τ_gap}。M_table 与 M_dyn 的退化映射 δ_table、δ_dyn 均定义为直接触发 M₀，且 τ_table、τ_dyn 与 τ_safe 使用同一尺度。因此任一软层违背必经 M₀，不存在“软通过、硬失败”的空洞；GapShield 的 level 0 进一步把“证书不通过”映射为只执行 M₀。

**引理 89（新增模块的 WCET 可加性）**
TAL 为常数个几何距离（O(|contact| + |poly|)），CGE 为固定维残差与一次伪逆（可预分解），RASI 的一次 EKF 更新为 O(d_θ³) 常数（d_θ=7），PS 只生成候选并异步提交。故主环新增开销为 O(1)，探针执行在独立线程，不进入 50Hz 关键路径（实验 E561 验证抖动）。

| 语音集成（E567） | ≥85% | 改指令-对象绑定、放宽几何证书 |
| 消融（E568） | 每模块均有正贡献 | 定位无效模块，简化设计 |
| 功耗（E569） | ≤28W | 探针降频、RASI 稀疏更新 |
| 竞赛（E570） | ≥v8+12% | 综合调参、分析失分瓶颈 |

## 8. 本轮最大风险

**一句话**：Δ_dyn 与 RASI 后验都以“接触力/滑移可被可靠观测”为前提，真实桌面的力传感噪声、遮挡与稀疏接触事件会让 u(t) 长期欠收敛，使引理 85 的收缩率与引理 86 的迁移下界同时变松，系统要么因证书过于保守而频繁降级、要么在 L 估计偏小时高估真实成功率——「用一个观测不足的物理模型去担保另一个物理模型」。
