# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「对比实验」×「视觉感知」）

> R69 给了系统一张嘴，问出「我该向谁求证、还能问什么」。但它判断「值不值得问」的判据 VoI 是**自指**的：在模型自己的信念里计算信息增益。若模型幻觉出一个模态，它会同时幻觉「这个模态会看到什么」，于是 VoI 对幻影也能算出正增益——系统会认真地规划「如何把这个不存在的东西问清楚」，花预算去追一个幻影。R69 自陈的最大风险正是「问错，比不问更危险」。它用模态校准与证据纪律去补，但校准只保证**平均**可信、纪律只是投票，二者都挡不住一个高权重的单个幻影。
>
> 本轮两个灵感给出真正的解药：
> - **对比实验**：科学解决这个问题从不靠更准的先验，而靠**受控对比**——构造一个让两个假设预测不同的条件，然后看世界站在哪一边。假设不能被观察「确认」，只能被实验「证伪」。
> - **视觉感知**：视觉是制造这种条件最廉价、非接触、信息量最大的通道——平移产生视差（深度），转动产生遮挡序（前后），变光产生阴影/高光（材质），靠近产生细节（类别），等待产生运动线索（动静）。而视觉的**对称性**（无纹理、透明、镜面对称、周期纹理）恰好给出「任何实验都分不开」的负空间。
>
> 核心命题：**把 R69 的「信息动作」从「获取更多数据」改造成「区分假设的对比实验」；判据从自指的 VoI 换成先验无关、可被真实数据裁决的对比判别度 D\*；再用观测等价商把残余歧义分成三类——可分辨（去做实验证伪）、等价同策（合并，不必问）、等价异策（不可消解，不追问，取最坏动作并升级人类）。** 命名 **CONVEX-RAS**（Contrastive Visual EXperiments for Risk-Adaptive Systems）。
>
> 一句话定位：R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我怎么知道我问到的是真的，而不是我自己编的**」——不问「更可能是什么」，而问「**什么实验能把它杀掉**」。

## 0. 直觉与动机

**灵感 1（对比实验 → VoI 的自指陷阱与证伪的解药）**
直觉：VoI(g) = H(M|o) − E_{y~p(·|g,o)}[H(M|o,y)]，期望是对 p(y|g,o) 取的，而这个 p 出自**可能出错的同一个模型**。这是「用嫌疑人的证词给嫌疑人作证」：模型若幻觉出模态 m_hall，它也会幻觉出 m_hall 的观测预测，于是 VoI 正得理直气壮，系统花钱去问一个幻影，再把某个误导回答盖章为「已验证」。受控实验完全不同：它的价值来自「两个假设预测的观测**实际差多少**」，而这个差异在实验执行后会被**真实数据**裁决。于是本轮把目标函数从「做完能少多少熵」换成「做完能不能把假的说杀就杀」。
形式直觉：二元等先验下 VoI 恰是两预测分布的 Jensen–Shannon 散度，仍是模型内部量；而对比判别度是似然比检验的**误差指数**（Chernoff 信息），直接对应「用真实样本多久能分开」——一个可被数据检验的量。

**灵感 2（视觉感知 → 干预原语与观测等价的负空间）**
直觉：对比实验需要一个能「廉价地、非接触地、信息量巨大地」制造条件差异的通道，视觉是天然的。它给出六种原语：平移（视差→深度）、旋转/会聚（立体→远近）、变焦（细节→类别）、光照（阴影 vs 暗物→材质）、遮挡/探头（遮挡序→前后）、等待（运动线索→动静）。每一个都在假设空间上有可预测的**观测签名**。反过来，视觉的对称性使某些假设对在**所有可行视点**下预测完全相同——这是对比实验的零空间。于是视觉不仅提供手段，还提供一个判据：**分不开的，就不该问**。

**灵感 3（观测等价商 → 把「问不出」和「不必问」分开）**
直觉：R69 把所有残余 U_epi 一律当「没问到」走保守。但「没问到」有三种完全不同的命运：
- **可分辨**：存在实验能分开 → 去做对比实验，证伪；
- **等价同策**：分不开，但两个模态**诱导同一个最优动作** → 追问毫无意义，直接合并（省预算、去幻觉）；
- **等价异策**：分不开，却导致**不同的安全后果** → 真正的不可消解歧义，追问无效，只能取最坏情形动作并**上报人类**（一次监督式升级，不计入信息动作预算）。
第三格是 R69 缺失的安全格：有些不确定性不是「还没查」，而是「永远查不到，只能承认并绕开」。

**灵感 4（阴性对照 → 对比实验自带的造假检测）**
直觉：对比实验最容易被忽略的一半是**对照**。正实验预测「有差异」，阴性对照（sham）预测「无差异」。如果 sham 也测出差异，说明测量通道（标定、编码器、对比预测器）本身坏了，整批实验结论作废——这把 R68 的标定失效、R69 的 FMA 行为似然异常接进同一条链：**对比实验既是消歧器，也是测量通道的自检器**。没有 sham 的对比实验比不做实验更危险，因为它会把噪声包装成证据。

**灵感 5（证伪账本 → 先验无关的鲁棒性）**
直觉：R69 用校准后的模态权重排序，但权重校准是平均意义的，救不了单个高权重幻影。证伪是**先验无关**的：某观测若使某模态的似然比低于阈值，就把它杀掉，不管它先前多重。于是把「权重驱动的贝叶斯后验」换成「生存记录驱动的账本」：每个模态记录通过了哪些正实验、哪些 sham 检验、被哪些观测反驳。动作只在幸存者上做，权重只用于幸存者内部的精细排序。这直接拆掉 R69 风险的地基——「自信追问幻影」在账本里先被实验杀掉，而不是被先验抬高。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（CONVEX-RAS 总览）** CONVEX-RAS = (CIP, OEQ, VCP, FAL, NCC, SVE, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **对比实验预算与安全**：每对假设至多一次主实验 + 一次阴性对照；视觉干预的位移/角速度/光照/时间必须在安全包络内，并通过与任务动作相同的 C-RAS-WM 认证（继承 R69 定义 302）；
(iii) **证伪优先于确认**：任何模态在获得 ≥1 次正实验「未能证伪」且通过阴性对照之前，不得以「已确认」身份驱动动作；阴性对照失败则整批实验作废并升级。

**定义 311（世界假设与对比三元组）** 世界假设 h = (m, ω)，其中 m 为 FMP 模态（R69 定义 296），ω 为世界参数（深度、材质、遮挡序等）。对比实验 e = (g⁺, g⁰, ψ)：g⁺ 为正干预，g⁰ 为阴性对照，ψ 为判别统计量（似然比或图像空间对比度量）。

**定义 312（视觉干预原语）** 𝒢_vis = {translate, rotate, zoom, illum, occlude, wait}，每个 g 有预测观测签名 S_g(h) = p(y | do(g), h)（do 记号强调**干预**而非相关）。每轮至多执行一个 g⁺ 与一个 g⁰。

**定义 313（对比判别度）** 对假设对 (i, j) 与干预 g，令 p_i = p(·|do(g),h_i)、p_j = p(·|do(g),h_j)，定义
D\*(g; i, j) = C(p_i, p_j) = max_{0≤λ≤1} −log Σ_y p_i(y)^λ p_j(y)^{1−λ}，
即最优似然比检验的 Chernoff 误差指数。可计算的可验证下界：D\* ≥ −log(1−H²) ≥ H² ≥ TV²/4，其中 H² = 1 − Σ_y √(p_i p_j) 为 Hellinger 平方，TV = ½‖p_i−p_j‖₁。称 (i,j) 在 g 下 **ε-可分**，若存在可行 g 使该**认证下界** ≥ ε（只接受可证的下界，避免把「看起来可分」当可分）。

**定义 314（观测等价商 OEQ）** 定义等价关系 h_i ~_obs h_j ⇔ sup_{g 可行} D\*(g; i, j) < ε。动作分歧 δ_act(i,j) = sup_a |Q(h_i,a) − Q(h_j,a)|（Q 为风险/回报）。据此分三类：
(a) **可分辨**：∃g 使认证下界 ≥ ε → 交 CIP；
(b) **等价同策**：~_obs 且 δ_act ≤ ε_a → 合并为单一动作类；
(c) **等价异策**：~_obs 且 δ_act > ε_a → 不可消解，保守 + 升级。
（在有限样本上用并查集估计，边界对打不确定性标记；宁可升级，不可静默合并。）

**定义 315（视觉对比预测器 VCP）** 学习模型 D̂(g; i, j | o) ≈ D\*(g; i, j)，无需执行即可对候选排序；需校准（ECE ≤ τ_vcp）并门控：越界则退化为只用**解析签名**（视差几何、遮挡序、光度不变式）排序。VCP 只负责排序，**认证仍由定义 313 的下界给出**——这是防止同源自举的关键。

**定义 316（对比实验规划 CIP）** g\* = argmax_g [ min_{i≠j∈S} D̂(g; i, j) − c(g) ]，s.t. g ∈ 𝒢_vis 可行、SVE 认证通过、预算允许。max-min 保证实验对**最难分的幸存对**也有裁决力。若 max < ε → 不做实验，转 OEQ 分类。

**定义 317（阴性对照 NCC）** 选取 g⁰ 使 ∀h ∈ S 的预测签名近似相同；执行后计算零效应统计量 ζ(g⁰)。若 |ζ| > τ_null → 整批作废，归因于测量通道故障（连 R68 的 r_res、R69 的 Δa），升级。NCC 使对比实验自带造假检测。

**定义 318（证伪更新 FAL）** 观测 y 后，h_i 被 e 证伪 ⇔ log p(y|do(g⁺), h_i) − max_{j≠i} log p(y|do(g⁺), h_j) < −τ_fal。幸存集 S′ = 未被任何已执行实验证伪、且所在批次 NCC 通过者。账本 ledger 记录每个 h 的（通过/失败/被反驳）轨迹；模态状态不是后验权重，而是**生存记录**。

**定义 319（先验无关的幸存者动作选择）** 只从 S′ 选动作；S′ 内部用「校准先验 × 生存置信（survivorship bonus）」排序；若 |S′| ≥ 2 且仍存在 ε-可分对且预算允许，则优先再测一次；若 S′ = ∅（全被杀 / NCC 作废）→ 退 R68/R69 最保守并升级。

**定义 320（不可消解歧义升级协议 ESC）** 若 OEQ 得到 (c) 类：不再追问；取类内最坏情形动作（minimax / λ_floor over class）；输出 escalation 证书与人类监督提示（不计信息动作预算）；J_CONVEX 标记 irreducible_ambiguity。**升级不是「再问一次」，而是「承认问不到，请人定夺」。**

**定义 321（安全视觉实验 SVE）** 每个 g ∈ 𝒢_vis 过 C-RAS-WM 前缀认证：平移 ≤ ε_g、角速度 ≤ ω_max、光照变化在光度安全域、遮挡/探头不破坏追踪；任一不过则换更安全的 g，或把该对降级为等价类。

**定义 322（对比实验证书 J_CONVEX）** J_CONVEX = (J_FLUID, separator_set, D\*_certified, n_exp, ncc_pass, falsified_modes, survivors, equivalence_classes, irreducible_flag, exp_log_hash, convex_ver)。Valid ⇔ Valid(J_FLUID) ∧ NCC 通过 ∧ 预算未越界 ∧ 每个被动作的模态有 ≥1 次未证伪的正实验。

**定义 323（视觉真对称 vs 可解别名）** 真对称：存在群作用 G 使 p(y|do(g),h) 在 g ∈ G 下不变（旋转对称、周期纹理相位、透明界面）→ 对一切可行 g 有 D\* ≈ 0，直接归入 OEQ；可解别名：仅在某些视点下相同、换视点即分开（遮挡、无纹理但可加纹理）→ 交 CIP。用**等变检验**（对观测施加 G 再比较）区分二者。

**定义 324（D\* 与 VoI 的关系）** 二元等先验下 VoI(g) = JSD(p_i, p_j)（模型内部量）；D\*(g; i, j) 是似然比检验的误差指数。良定模型下二者同向；错定时 VoI 对幻影仍可正，而 (D\*, NCC, FAL) 会用真实数据把它杀掉。故 **D\* 不是 VoI 的近似，而是它的可证伪替代**。

**定义 325（在线预算与触发）** 默认不实验；仅当 R69 报 U_epi > τ_epi 且 VCP/解析签名报存在 ε-可分对时触发；每轮 ≤ 1 主实验 + 1 对照；实验在「安全停顿」窗口内执行（继承 R69 定义 308 的实时预算与定义 302 的认证）。

# IP-264 CIP：对比实验规划（max-min 判别度，对最难分的幸存对负责）
def plan_contrast(S, o, budget):
    best = None
    for (i, j) in top_pairs(S):                        # 仅前若干对
        for g in feasible_visual(o):                   # translate/rotate/zoom/illum/occlude/wait
            if not budget.allow(g) or not sve.certify(g, o):
                continue
            d = min(vcp.D_hat(g, i, k, o) for k in S if k != i)
            score = d - cost(g)
            if best is None or score > best.score:
                best = (g, (i, j), score)
    return best if best and best.score >= EPS_D else None   # 无可分对 → 等价类

# IP-265 OEQ：观测等价商（可分 / 同策等价 / 异策等价）
def equivalence_partition(S, o, eps, eps_a):
    uf = UnionFind(S)
    for i, j in pairs(S):
        if certified_max_D(i, j, o) < eps:             # 任何可行 g 都分不开

# IP-266 NCC：阴性对照（预测无差异却测出差异 = 测量通道坏了）
def negative_control(exp, o):
    g0 = pick_null_intervention(exp.hypotheses)        # 预测所有 h 观测相同
    y0 = execute(g0)

# IP-267 FAL：证伪账本（先验无关）
def falsify(S, ledger, y, exp):
    keep = []
    for h in S:
        ref = max(loglik(y, exp.g_plus, k) for k in S if k != h)

        else:
            ledger.record(h, 'survived', exp)
            keep.append(h)
    return keep

## 3. 推导

**引理 19（对比实验的可裁决性）** 设真实假设 h₀ ∈ {h_i, h_j}，且认证下界给出 D\*(g;i,j) ≥ ε。取 n 个 i.i.d. 观测，Chernoff–Sanov 界给出最优检验的分离错误概率 ≤ e^{−nε}（常数因子忽略）。系：对比实验把「模型相信谁」变成「需要多少真实样本才能裁决」，且样本复杂度由**认证的可分程度**给出，而非模型自评的 VoI。VoI 在模型错定时不提供此保证——这正是自指陷阱的形式化。

**引理 20（阴性对照的通道故障检出）** 设测量通道偏置为 b（标定漂移/编码偏差），g⁰ 在假设间预测零差异。则观测零效应 ζ 满足 E|ζ| ≥ |b| − σ_noise；故 |ζ| > τ_null 以随 |b| 增长的势检出通道故障。系：NCC 把 R68 的 r_res 失效与 R69 的 Δa 异常纳入同一检测链，且**不需要真实标签**。

**引理 21（幻影模态的可证伪性）** 若幻影模态 m_h 在某可行 g 下与所有真实模态 ε-可分，则执行该实验后 m_h 以 ≥ 1 − e^{−nε} 概率被证伪；若对所有可行 g 都有 D\* < ε，则 m_h 落在观测等价类中：或与某真实模态同策（合并、无害），或异策（升级、不被静默采纳）。两种情况下 m_h 都不会静默驱动动作。系：CONVEX 消除 R69「把误导回答盖上已验证章」的失败模式。

**定理 18（CONVEX 对 FLUID/R68 的安全包含，含误差项）** 在 A95–A100 下，CONVEX 的「证伪或升级、绝不采纳未验证幻影」策略的期望风险 ≤ FLUID 的风险 + e^{−nε}·R_false，其中新增项仅为证伪的统计假阴性，可由 ε 与 n 控制；当不存在 ε-可分对、无可行 NCC、或 slow_fault_suspect 时，CONVEX 逐指令退化为 FLUID 的保守分支，再退化为 R68。故 R68 ⊂ FLUID ⊂ CONVEX（安全侧）。注意：这是**含显式误差项的包含**，而非无条件 ≤——诚实地把「证伪也会杀错」计入风险。

**引理 22（观测等价商把追问预算归零）** 对等价同策类，任何实验的期望动作收益 ≤ ε_a，故最优策略是不实验、直接合并；对等价异策类，任何实验都不能降低 min-max 风险，故追问是纯浪费且增加被投毒面。系：OEQ 是比 VoI 更强的「何时不该问」判据——它给的是**信息论下界**，不是收益估计。

**定理 19（视觉实验的安全与无突变）** SVE 认证的 g 使物理风险 ≤ ε_int，且不改变安全包络；NCC 失败 / 全被证伪 / 超时均使 λ 单调不降地退化到 R68；R69 的换装不变式（定理 15）与 R68 的提交不变式保持 ⇒ 控制连续、无突变。

## 6. 本轮最大风险

**一句话**：CONVEX 用「预测观测签名」的模型来设计区分假设的实验，而这个签名模型（VCP/前向观测模型）与生成模态的模型同源——**验证者是从被验证的同一个可疑模型里长出来的**；若签名模型本身系统性错误，系统会精心设计一个「能分开两个虚构」的实验，而只要 NCC 也因同源偏差而误判通过，就会得到「经实验验证」的假确定性——这比 R69 的「问错」更危险，因为它把错误升级成了**科学方法背书的错误**。

**次级风险与缓解**：
1. **同源自举**：优先用模型无关的物理先验（视差几何、遮挡序、光度不变式）作签名，VCP 仅作排序，二者分歧即降级；E311 强制比较解析与学习签名。
2. **NCC 同源失效**：NCC 用独立的物理不可能性检查（如静止相机下不应有视差），而非学习模型；E304/E315。
3. **证伪假阴性杀真模态**：误差项 e^{−nε} 进证书（定理 18），τ_fal 保守、幸存者不因单次实验被永久排除（账本可翻案）。
4. **视觉干预安全/社交成本**：SVE 认证 + 预算 + 以升级替代反复追问（定义 320–321）。
5. **等价类估计错误导致误合并/误升级**：并查集边界对打不确定性标记，宁可升级不可静默合并；E303/E305。

# 第 70 轮产物 · 创新点清单 v1：CONVEX-RAS（Contrastive Visual EXperiments for Risk-Adaptive Systems：对比实验 × 视觉感知的证伪优先不确定性闭环；CIP×OEQ×VCP×FAL×NCC×SVE×RAS-WM†）

## 4. 推导

**引理 19（对比实验的可裁决性）** 真实假设在 {h_i,h_j} 中、认证下界 `D*≥ε` 时，n 个 i.i.d. 观测的最优检验分离错误 ≤ `e^{−nε}`（Chernoff–Sanov）。系：对比实验把「模型相信谁」变成「还需多少真实样本才能裁决」，且样本复杂度由**认证的可分程度**给出，而非模型自评的 VoI；VoI 在模型错定时无此保证。

**引理 20（阴性对照的通道故障检出）** 测量通道偏置 b、`g⁰` 预测零差异时，`E|ζ| ≥ |b| − σ_noise`；故 `|ζ|>τ_null` 以随 `|b|` 增长的势检出通道故障。系：NCC 把 R68 的 `r_res` 失效与 R69 的 `Δa` 异常纳入同一检测链，且不需真实标签。

**引理 21（幻影模态的可证伪性）** 幻影若在某可行 g 下与所有真实模态 ε-可分，则执行后以 `≥1−e^{−nε}` 被证伪；若对所有可行 g 都 `D*<ε`，则落入等价类——同策则合并（无害），异策则升级（不被静默采纳）。两种情况下幻影都不会静默驱动动作。

**定理 18（CONVEX 对 FLUID/R68 的安全包含，含误差项）** A95–A100 下，`Risk(CONVEX) ≤ Risk(FLUID) + e^{−nε}·R_false`；当无 ε-可分对、无可行 NCC 或 `slow_fault_suspect` 时，CONVEX 逐指令退化为 FLUID 保守分支，再退化为 R68。故 `R68 ⊂ FLUID ⊂ CONVEX`（安全侧）；这是**含显式误差项的包含**，不宣称无条件 ≤。

**引理 22（OEQ 把追问预算归零）** 等价同策类中任何实验的期望动作收益 ≤ `ε_a`，最优是不实验、合并；等价异策类中任何实验都不能降低 min-max 风险，追问纯浪费且扩大投毒面。系：OEQ 是比 VoI 更强的「何时不该问」判据，给的是**信息论下界**而非收益估计。

**定理 19（视觉实验的安全与无突变）** SVE 认证的 g 使物理风险 ≤ `ε_int`，不改安全包络；NCC 失败 / 全被证伪 / 超时均使 λ 单调不降地退化到 R68；R69 换装不变式与 R68 提交不变式保持 ⇒ 控制连续、无突变。

## 7. 本轮最大风险

**一句话**：CONVEX 用「预测观测签名」的模型来设计区分假设的实验，而这个签名模型（VCP/前向观测模型）与生成模态的模型同源——**验证者是从被验证的同一个可疑模型里长出来的**；若签名模型本身系统性错误，系统会精心设计一个「能分开两个虚构」的实验，而只要 NCC 也因同源偏差而误判通过，就会得到「经实验验证」的假确定性——这比 R69 的「问错」更危险，因为它把错误升级成了**科学方法背书的错误**。

**次级风险与缓解**：同源自举（解析物理签名优先、VCP 仅排序、分歧即降级，E311）；NCC 同源失效（用物理不可能性检查而非学习模型，E304/E315）；证伪假阴性杀真模态（误差项进证书、τ_fal 保守、账本可翻案）；视觉干预安全/社交成本（SVE 认证 + 预算 + 升级替代，定义 320–321）；等价类误判（边界标记 + 宁可升级不可静默合并，E303/E305）。
