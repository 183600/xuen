# 第 61 轮（承接第 60 轮 SGEC「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「轮足机器人」×「手眼标定」）

> 第 60 轮用 SSM×CIEC×EPIR×SERC 实现了「认知先行的场景适应」，但其执行主体仍隐含三个假设：**固定基座、单一运动模态、几何框架精确**。当执行主体换成**轮足式移动操作机器人**（轮式高效 + 腿式越障 + 机械臂作业）时，这三个假设同时失效：
> 1. **单一运动模态假设**：第 60 轮的 K_safe 只编码「接触阻抗」，无法表达「轮滚」与「腿踏」的离散切换。楼梯前用轮式的低阻尼去接触，相当于用错误模态执行正确场景；而模态切换是一次**离散跳变**，连续阻抗编译器 EEIS 根本不认识它。
> 2. **几何框架的隐性信任**：EV-exec 与场景先验默认「相机→手」的手眼变换 X 精确且恒定。但移动基座会振动、腿式落地会冲击、关节长期磨损/热漂移会让 X 缓慢失准。第 60 轮的 SIC 只校验场景置信度与阻抗确定性，**不校验几何确定性**——这是「证据层高度确定、执行层几何错位」的新抽象泄漏口。
> 3. **标定与运动的耦合未被利用**：手眼标定 AX=XB 的可解性依赖**运动激励**；纯平面/纯旋转运动会退化。轮足机器人恰恰拥有最丰富的 6-DOF 基座激励能力，第 60 轮却把全部运动视为成本，从未把「运动」当作「标定信息源」，标定仍是离线一次性动作。

## 0. 直觉与动机

**灵感 1（轮足机器人 → 轮足场景-模态联合建模 WLSM）**
直觉：场景不仅决定「碰上去多硬」，也决定「该怎么走」。平地→wheel（低摩擦、高效、连续速度），楼梯→leg（离散落足、支撑多边形），坡面→hybrid（轮驱 + 腿调姿）。把第 60 轮的场景 z 扩展为联合状态 (z, m)，m 为离散运动模态。关键洞见：**模态是离散跳变，必须先识别后编译**——用「切换卡尔曼/IMM」同时估计场景后验与模态后验，让 K_safe 的条件从 π(K|z) 升级为 π(K|z,m)；楼梯上的阻尼先验不该来自平地轮式模型。轮足特有的**滑移率 s=(v_cmd−v_act)/v_cmd** 是区分「轮式打滑」与「腿式失稳」的关键证据。

**灵感 2（手眼标定 → 手眼几何接地 HEG）**
直觉：感知生在相机系 C，执行落在末端/世界系 W，手眼变换 X∈SE(3) 是「语义→几何」的唯一桥。第 60 轮把它当常数，实际它是**带协方差的随机变量** X=X̂·exp(ξ^)，ξ~N(0,Σ_X)，并随运动模态漂移：ξ_{t+1}=ξ_t+w_t，Q_drift 随腿式冲击显著增大。关键洞见：**几何误差会被力臂放大**——距离 r 处的点，其位置标准差约 sqrt(σ_t²+(r·σ_θ)²)；不把 Σ_X 传播进安全距离与力上限，就会出现「看到了、算对了、却碰偏了」。

**灵感 3（手眼标定 → 可观测性主动标定 OAC）**
直觉：AX=XB 不是有数据就可解。纯平移、纯平面、纯旋转等退化运动会令 Fisher 信息矩阵奇异，标定解在零空间里任意漂移。把运动分成「任务运动」与「标定激励」，用 D-最优准则 u*=argmax log det(F+F(u)) 选出**信息增益最大且安全**的激励。关键洞见：**运动既是几何扰动源，也是标定信息源**——轮足的腿可以主动制造 6-DOF 基座激励，一次「标定-任务双用运动」即可在不额外耗时的情况下收敛 Σ_X。

**灵感 4（三灵感合流 → 几何接地轮足闭环 GGL）**
直觉：WLSM 给出场景-模态先验 → HSC（混合安全切换）判断此刻能否换模态 → HEG/GSE 把 Σ_X 变成膨胀后的安全包络 → SERC 用 K_safe^geo 编译执行 → EV-exec 回传滑移、落足、标定残差 → OAC 更新 Σ_X、WLSM 更新场景-模态信念。闭环从第 60 轮的「场景-意图-执行」升级为**「场景-模态-几何-执行」**，把运动学几何第一次纳入认知闭环。

**灵感 5（预算 → 五维接地预算 PCE+++++）**
直觉：标定激励、模态切换都要消耗能量与时间，不能免费。新增**接地预算** B_ground=(B_geo, B_mode)：B_geo 限制标定激励次数、几何校验频率、变换陈旧度；B_mode 限制切换能量、切换时延、接触调度余量。若 B_geo 耗尽⇒冻结 X、放大 GSE 安全膨胀、禁止需要精确落足的切换；若 B_mode 耗尽⇒锁定当前模态、降速并只允许「停车切换」。这样「几何接地」不会变成新的算力/能量黑洞。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（轮足场景-模态联合模型 WLSM）** 联合模型 Γ_w = (S, π_w, G, Φ_base)。其中：
- **联合状态空间**：s=(z,m)，z∈Z_scene（第 60 轮场景集），m∈M={wheel, leg, hybrid, transition}
- **联合先验**：π_w(m,K|z,v) = π_mode(m|z,v,ρ_b)·π_K(K|z,m)，ρ_b 为基座状态（速度、倾角、支撑）
- **模态可行性**：g(m|z) = P(场景 z 支持模态 m)，如 g(leg|stairs)=1、g(wheel|stairs)≈0
- **基座扰动谱**：Φ_base(m,z) 给出该模态下机身振动/冲击的功率谱，用于调制接触噪声与 Q_drift
- **识别器**：离散模态用 HMM 前向-后向，连续量用 Kalman；整体为切换卡尔曼/IMM 滤波
- **滑移证据**：s_t = (v_cmd−v_act)/v_cmd，轮式打滑时 s 增大而接触力未必异常，腿式失稳时 s 抖动且 IMU 冲击增大
模态先验进入阻抗编译：K_safe^mode = {K | P(K|z,m) ≥ τ_mode} ∩ K_safe^scene，使「模态」约束「接触安全」。

**定义 162（手眼几何接地 HEG）** 几何接地元组 G = (X, Σ_X, Q_drift, T)。其中：
- **坐标链**：W ← B ← E(q) ← C，手眼变换 X = T_E^C ∈ SE(3)，q 为机械臂关节
- **随机表示**：X = X̂·exp(ξ^)，ξ~N(0,Σ_X)（se(3) 局部扰动）
- **漂移过程**：ξ_{t+1}=ξ_t+w_t，w_t~N(0,Q_drift(m,z))，腿式落地时 Q_drift 抬升、轮式匀速时衰减
- **接地算子**：相机观测 o（均值 μ_o，协方差 Σ_o）映射到世界系
  - μ_o^W = T_W^B(q_base)·T_B^E(q)·X̂·μ_o
  - Σ_o^W = J_X Σ_X J_X^T + J_q Σ_q J_q^T + J_base Σ_base J_base^T + Σ_o
  - J_X = ∂(T·X·exp(ξ^)·p)/∂ξ 为几何雅可比
- **接地置信度**：geometry_conf = exp(−κ_g·tr(Σ_X))，用于门控 MGC

**定义 163（可观测性主动标定 OAC）** 标定调度器 O = (C, F, κ_obs, IG, U_cal)。其中：
- **标定约束**：对运动对 i，AX=XB 线性化得 C_i ξ = d_i + ε_i，ε_i~N(0,Σ_i)
- **Fisher 信息**：F = Σ_i C_i^T Σ_i^{-1} C_i
- **可观测度**：κ_obs = λ_min(F)；κ_obs < θ_obs 判为**标定退化**（平面/纯转/激励不足）
- **信息增益**：IG(u) = log det(F + F(u)) − log det(F)
- **主动选择**：u* = argmax_{u∈U_cal} IG(u) s.t. 安全约束、能耗约束、时间约束
- **双用运动**：若某任务运动 u_task 的 IG(u_task) ≥ θ_IG，则记为「免费标定」，不额外消耗 B_geo
- **触发条件**：tr(Σ_X) > ε_X ∨ κ_obs < θ_obs ∨ 模态切换前后强制一次几何校验

**定义 164（几何安全包络 GSE）** 由 Σ_X 诱导的安全放大：
- **位置不确定度**：对距离 r 的点，σ_p(r) ≈ sqrt(σ_t² + (r·σ_θ)²)，σ_t²=tr(Σ_X[:3,:3])，σ_θ²=tr(Σ_X[3:,3:])
- **安全膨胀**：d_safe^geo = d_safe − β_g·σ_p，F_max^geo = F_max·exp(−λ_g·σ_p)
- **安全集编译**：K_safe^geo = {K ∈ K_safe^mode | reachable_error(K,Σ_X) ≤ ε_pos}
- **几何证书**：J_geo ≜ [P(||p_exec − p_plan|| ≤ ε_pos) ≥ 1−δ]
- **降级**：若 tr(Σ_X) > ε_X^max，则 K_safe^geo := K_conservative（最大阻尼、限力、限速），并请求 OAC 重新标定

**定义 165（混合模态安全切换 HSC）** 混合自动机 H = (Q, E, Guard, Reset, J_switch)：
- **模态**：Q = {wheel, leg, hybrid, transition(·)}，边 e=(m→m') 为切换
- **守卫**：Guard(m→m') = terrain_valid(z,m') ∧ balance_margin(x) ≥ μ_min ∧ geometry_grounded(Σ_X) ∧ energy_ok
  - 其中 geometry_grounded(Σ_X) ≜ tr(Σ_X) ≤ ε_X；不确定度越大，守卫越紧
  - μ_min(Σ_X) = μ_min^0 + γ_g·σ_p（几何越差，要求平衡裕度越高）
- **切换证书**：J_switch 需同时验证
  1. 接触调度无冲突（落足时刻不与当前接触重叠）
  2. CoM/捕获点位于支撑多边形内（或满足 ZMP 约束）
  3. 当前几何接地有效（落足点由可信 X 计算）
  4. 力矩/能量裕度 ≥ 阈值
- **时序与连续性**：切换时延 τ_switch ≤ τ_sw_max，质心速度跳变 ||Δv_CoM|| ≤ Δv_max
- **拒切换**：若 J_switch 不通过，则保持 m 并降速，或先执行一次 OAC 几何校验再重试

**定义 166（几何接地轮足闭环 GGL）** 算子 GGL(M, z, m, intent, δ_f_req)：

**定义 167（五维接地预算 PCE+++++）** 在 B_cog=(B_scene,B_intent,B_ros,B_exec) 上新增接地预算：
- **B_geo** = (Calibration_excitation_budget, Geometry_verification_rate, Transform_staleness_limit)
- **B_mode** = (Switch_energy_budget, Switch_time_budget, Contact_schedule_slack)
- **接地成本**：cost_ground = λ_cal·Calibration_cost + λ_switch·Switch_cost + λ_geo·Geo_risk
- **接地 VOI**：voi_ground(π) = voi_cog(π) − cost_ground(π)
- **降级策略**：
  - B_geo 耗尽 ⇒ 冻结 X̂、Σ_X 只增不减、收紧 GSE（β_g↑）、禁止需精确落足的切换
  - B_mode 耗尽 ⇒ 锁定当前模态、仅允许「停车切换」、降低任务速度
  - B_ros 异常 ⇒ 本地闭环；B_exec 耗尽 ⇒ 第 60 轮既有降级

**定义 168（模态-几何-置信三元组 MGC）** 扩展第 60 轮 SIC：
- **MGC** = (mode_feasibility(m|z), geometry_conf(Σ_X), scene_conf(z), K_certainty(K|z,m), exec_feasibility(K|z,m))
- **有效判定**：MGC_valid = mode_feasibility ≥ τ_m ∧ geometry_conf ≥ τ_g ∧ scene_conf ≥ τ_scene ∧ K_certainty ≥ τ_K ∧ exec_feasibility = true
- **更新**：EV-exec 返回后
  - geometry_conf ← geometry_conf·β_g + (1−β_g)·exp(−||ξ_obs||²_Σ)
  - mode_feasibility(m|z) ← mode_feasibility·β_m + (1−β_m)·exp(−slip_penalty)
- **语义**：任何一项不通过，都不得把「高置信」当作「可执行」——几何不确定时，认知置信必须折价

### IP-161 WLSM（轮足场景-模态联合模型）

```python
class WheelLeggedSceneModeModel:
    def __init__(self, scenes, modes=('wheel', 'leg', 'hybrid', 'transition')):
        self.scenes = scenes
        self.modes = list(modes)
        self.pi_mode = {m: 1.0 / len(modes) for m in modes}
        self.q_scene = np.ones(len(scenes)) / len(scenes)      # 场景后验
        self.q_mode = {m: 1.0 / len(modes) for m in modes}     # 模态后验
        self.P_trans = self._transition_matrix()               # 模态转移
        self.Q_drift = {m: np.eye(6) * q for m, q in
                        {'wheel': 1e-6, 'leg': 5e-5, 'hybrid': 2e-5, 'transition': 1e-4}.items()}

    def update(self, tau_ext, v_cmd, v_act, imu, foot_contact):
        slip = 0.0 if abs(v_cmd) < 1e-6 else (v_cmd - v_act) / v_cmd
        feats = self._terrain_features(tau_ext, slip, imu, foot_contact)
        # 离散模态：HMM 前向步（用滑移/冲击修正发射概率）
        for m in self.modes:
            emit = self._emission(m, feats)
            self.q_mode[m] = emit * sum(self.P_trans[m_prev][m] * self.q_mode[m_prev]
                                        for m_prev in self.modes)
        self._normalize(self.q_mode)
        # 连续场景：以模态为条件的 Kalman 更新
        z_post, cov = self._scene_kalman(feats, self.q_mode)
        self.q_scene, self.scene_cov = z_post, cov
        return self.top_scene(), self.top_mode(), self.q_mode

    def compute_impedance_prior(self, top_k=3):
        z, m = self.top_scene(), self.top_mode()
        base = self.scene_impedance_prior[(z, m)]
        return {'scene': z, 'mode': m, 'confidence': self.q_scene.max(),
                'impedance_prior': base, 'Q_drift': self.Q_drift[m]}
```

### IP-162 HEG（手眼几何接地）

```python
class HandEyeGrounding:
    def __init__(self, X_hat, Sigma_X, kappa_g=1.0):
        self.X_hat = X_hat                 # 4x4 SE(3)
        self.Sigma_X = Sigma_X             # 6x6
        self.kappa_g = kappa_g

    def propagate(self, mode, dz, dt):
        Q = self.Q_drift[mode] * dt
        self.Sigma_X = self.Sigma_X + Q    # 漂移只增不减（除非 OAC 观测）
        return self.Sigma_X

    def ground(self, mu_C, Sigma_C, T_WB, T_BE, Sigma_q, Sigma_base):
        T = T_WB @ T_BE @ self.X_hat
        J_X = self._jacobian_X(T, mu_C)    # 6x6 作用于 se(3) 扰动
        J_q = self._jacobian_q(T_WB, T_BE, mu_C)
        J_b = self._jacobian_base(T_WB, mu_C)
        Sigma_W = (J_X @ self.Sigma_X @ J_X.T + J_q @ Sigma_q @ J_q.T
                   + J_b @ Sigma_base @ J_b.T + Sigma_C)
        return T @ mu_C, Sigma_W

    def geometry_confidence(self):
        return float(np.exp(-self.kappa_g * np.trace(self.Sigma_X)))

    def update_from_constraint(self, C, d, Sigma_eps):
        # AX=XB 线性化：C xi = d + eps，信息形式融合
        info = C.T @ np.linalg.inv(Sigma_eps) @ C
        self.Sigma_X = np.linalg.inv(np.linalg.inv(self.Sigma_X) + info)
        xi = self.Sigma_X @ C.T @ np.linalg.inv(Sigma_eps) @ d
        self.X_hat = self.X_hat @ exp_se3(xi)
        return self.Sigma_X
```

### IP-163 OAC（可观测性主动标定）

```python
class ObservabilityAwareCalibrator:
    def __init__(self, he, theta_obs=1e-4, theta_ig=0.05, eps_X=1e-4):
        self.he = he
        self.theta_obs = theta_obs
        self.theta_ig = theta_ig
        self.eps_X = eps_X

    def fisher(self, constraints, Sigmas):
        F = np.zeros((6, 6))
        for C, S in zip(constraints, Sigmas):
            F += C.T @ np.linalg.inv(S) @ C
        return F

    def is_degenerate(self, F):
        return np.linalg.eigvalsh(F)[0] < self.theta_obs

    def select_excitation(self, candidate_motions, F, constraints, Sigmas,
                          energy_budget, safety_checker):
        best, best_ig = None, -np.inf
        for u in candidate_motions:
            if not safety_checker(u) or u.energy > energy_budget:
                continue
            C_u, S_u = self._predict_constraint(u)
            F_new = F + C_u.T @ np.linalg.inv(S_u) @ C_u
            ig = np.log(np.linalg.det(F_new + 1e-9 * np.eye(6))) - \
                 np.log(np.linalg.det(F + 1e-9 * np.eye(6)))
            if ig > best_ig:
                best, best_ig = u, ig
        # 任务运动若已足够激励，则标定「免费」
        return {'motion': best, 'info_gain': best_ig, 'free': best_ig >= self.theta_ig}

    def needs_calibration(self, obs_motion=None):
        if np.trace(self.he.Sigma_X) > self.eps_X:
            return True
        if obs_motion is not None:
            C, S = self._predict_constraint(obs_motion)
            return self.is_degenerate(self.fisher([C], [S]))
        return False
```

### IP-164 GSE（几何安全包络）

```python
class GeometricSafetyEnvelope:
    def __init__(self, beta_g=2.0, lam_g=5.0, eps_pos=0.005, eps_X_max=1e-3):
        self.beta_g, self.lam_g = beta_g, lam_g
        self.eps_pos, self.eps_X_max = eps_pos, eps_X_max

    def sigma_p(self, Sigma_X, r):
        s_t2 = np.trace(Sigma_X[:3, :3])
        s_th2 = np.trace(Sigma_X[3:, 3:])
        return float(np.sqrt(s_t2 + (r * r) * s_th2))

    def compile(self, K_safe_mode, Sigma_X, d_safe0, F_max0, r_task):
        if np.trace(Sigma_X) > self.eps_X_max:
            return self._conservative(K_safe_mode), False   # 强制降级
        sp = self.sigma_p(Sigma_X, r_task)
        d_geo = max(0.0, d_safe0 - self.beta_g * sp)
        F_geo = F_max0 * np.exp(-self.lam_g * sp)
        K_geo = {k: v for k, v in K_safe_mode.items()}       # 逐维裁剪到 d_geo/F_geo
        K_geo['K_d'] *= (1.0 + 0.5 * sp / max(self.eps_pos, 1e-6))
```

```python
    def __init__(self, mu_min0=0.15, gamma_g=1.0, tau_sw_max=0.5, dv_max=0.2):
```

```python
class WheelLeggedSceneModeModel:
    def __init__(self, scenes, modes=('wheel', 'leg', 'hybrid', 'transition')):
        self.scenes, self.modes = scenes, list(modes)
        self.q_scene = np.ones(len(scenes)) / len(scenes)
        self.q_mode = {m: 1.0 / len(modes) for m in modes}
        self.P_trans = self._transition_matrix()
        self.Q_drift = {m: np.eye(6) * q for m, q in
                        {'wheel': 1e-6, 'leg': 5e-5,
                         'hybrid': 2e-5, 'transition': 1e-4}.items()}

    def update(self, tau_ext, v_cmd, v_act, imu, foot_contact):
        slip = 0.0 if abs(v_cmd) < 1e-6 else (v_cmd - v_act) / v_cmd
        feats = self._terrain_features(tau_ext, slip, imu, foot_contact)
        for m in self.modes:
            emit = self._emission(m, feats)                 # 滑移/冲击调制
            self.q_mode[m] = emit * sum(self.P_trans[mp][m] * self.q_mode[mp]
                                        for mp in self.modes)
        self._normalize(self.q_mode)
        self.q_scene, self.scene_cov = self._scene_kalman(feats, self.q_mode)
        return self.top_scene(), self.top_mode(), self.q_mode

    def compute_impedance_prior(self):
        z, m = self.top_scene(), self.top_mode()
        return {'scene': z, 'mode': m, 'confidence': self.q_scene.max(),
                'impedance_prior': self.scene_impedance_prior[(z, m)],
                'Q_drift': self.Q_drift[m]}
```

### IP-162 HEG（手眼几何接地）

```python
class HandEyeGrounding:
    def __init__(self, X_hat, Sigma_X, kappa_g=1.0):
        self.X_hat, self.Sigma_X, self.kappa_g = X_hat, Sigma_X, kappa_g

    def propagate(self, mode, dt):
        self.Sigma_X = self.Sigma_X + self.Q_drift[mode] * dt   # 漂移只增不减
        return self.Sigma_X

    def ground(self, mu_C, Sigma_C, T_WB, T_BE, Sigma_q, Sigma_base):
        T = T_WB @ T_BE @ self.X_hat
        J_X = self._jacobian_X(T, mu_C)
        J_q = self._jacobian_q(T_WB, T_BE, mu_C)
        J_b = self._jacobian_base(T_WB, mu_C)
        Sigma_W = (J_X @ self.Sigma_X @ J_X.T
                   + J_q @ Sigma_q @ J_q.T
                   + J_b @ Sigma_base @ J_b.T
                   + Sigma_C)
        return T @ mu_C, Sigma_W

    def geometry_confidence(self):
        return float(np.exp(-self.kappa_g * np.trace(self.Sigma_X)))

    def update_from_constraint(self, C, d, Sigma_eps):
        info = C.T @ np.linalg.inv(Sigma_eps) @ C
        self.Sigma_X = np.linalg.inv(np.linalg.inv(self.Sigma_X) + info)
        xi = self.Sigma_X @ C.T @ np.linalg.inv(Sigma_eps) @ d
        self.X_hat = self.X_hat @ exp_se3(xi)
        return self.Sigma_X
```

### IP-163 OAC（可观测性主动标定）

```python
class ObservabilityAwareCalibrator:
    def __init__(self, he, theta_obs=1e-4, theta_ig=0.05, eps_X=1e-4):
        self.he, self.theta_obs = he, theta_obs
        self.theta_ig, self.eps_X = theta_ig, eps_X

    def fisher(self, constraints, Sigmas):
        return sum(C.T @ np.linalg.inv(S) @ C for C, S in zip(constraints, Sigmas))

    def is_degenerate(self, F):
        return np.linalg.eigvalsh(F)[0] < self.theta_obs

    def select_excitation(self, candidates, F, energy_budget, safety_checker):
        best, best_ig = None, -np.inf
        for u in candidates:
            if not safety_checker(u) or u.energy > energy_budget:
                continue
            C_u, S_u = self._predict_constraint(u)
            F_new = F + C_u.T @ np.linalg.inv(S_u) @ C_u
            ig = (np.log(np.linalg.det(F_new + 1e-9 * np.eye(6)))
                  - np.log(np.linalg.det(F + 1e-9 * np.eye(6))))
            if ig > best_ig:
                best, best_ig = u, ig
        return {'motion': best, 'info_gain': best_ig, 'free': best_ig >= self.theta_ig}

    def needs_calibration(self, obs_motion=None):
        if np.trace(self.he.Sigma_X) > self.eps_X:
            return True
        if obs_motion is not None:
            C, S = self._predict_constraint(obs_motion)
            return self.is_degenerate(self.fisher([C], [S]))
        return False
```

### IP-164 GSE（几何安全包络）

```python
class GeometricSafetyEnvelope:
    def __init__(self, beta_g=2.0, lam_g=5.0, eps_pos=0.005, eps_X_max=1e-3):
        self.beta_g, self.lam_g = beta_g, lam_g
        self.eps_pos, self.eps_X_max = eps_pos, eps_X_max

    def sigma_p(self, Sigma_X, r):
        s_t2 = np.trace(Sigma_X[:3, :3])
        s_th2 = np.trace(Sigma_X[3:, 3:])
        return float(np.sqrt(s_t2 + (r * r) * s_th2))

    def compile(self, K_safe_mode, Sigma_X, d_safe0, F_max0, r_task):
        if np.trace(Sigma_X) > self.eps_X_max:
            return self._conservative(K_safe_mode), False
        sp = self.sigma_p(Sigma_X, r_task)
        d_geo = max(0.0, d_safe0 - self.beta_g * sp)
        F_geo = F_max0 * np.exp(-self.lam_g * sp)
        K_geo = dict(K_safe_mode)
        K_geo['K_d'] *= (1.0 + 0.5 * sp / max(self.eps_pos, 1e-6))
        K_geo['F_max'] = min(K_geo.get('F_max', F_max0), F_geo)
        return K_geo, d_geo >= 0.0 and F_geo > 0.0
```

```python
    EV_exec.slip = M.slip
    EV_exec.Sigma_X = M.he.Sigma_X.copy()
    EV_exec.J_switch = J_switch
    M.epir.append(EV_exec.__dict__)

    M.mgc = M.mgc_engine.evaluate(z, M.current_mode, K_safe_geo,
                                  M.he.Sigma_X, J_switch)
    return M, M.mgc, K_safe_geo, J_switch, EV_exec
```

### IP-167 PCE+++++（五维接地预算）

```python
class GroundingBudget:
    def __init__(self, cal_ops=20, stale_limit=5.0,
                 switch_energy=500.0, switch_time=10.0):
        self.B_geo = {'cal_ops': cal_ops, 'stale_limit': stale_limit}
        self.B_mode = {'energy': switch_energy, 'time': switch_time}
        self.used_cal = self.used_switch = 0

    def geo_exhausted(self, transform_age, Sigma_X):
        return (self.used_cal >= self.B_geo['cal_ops']
                or transform_age > self.B_geo['stale_limit']
                or np.trace(Sigma_X) > 1e-3)

    def mode_exhausted(self, energy_used, time_used):
        return (self.used_switch >= self.B_mode['energy']
                or time_used >= self.B_mode['time'])

    def policy(self, transform_age, Sigma_X, energy_used, time_used):
        if self.geo_exhausted(transform_age, Sigma_X):
            return 'freeze_X_expand_margin_no_precise_step'
        if self.mode_exhausted(energy_used, time_used):
            return 'lock_mode_stop_to_switch'
        return 'normal'
```

**正确性定理（GGC）**：若 A66–A70 成立，则：
1. 若 mode_feasibility ≥ τ_m 且 MGC 通过 ⇒ 选中模态与场景相容，误切换率 ≤ 2%（WLSM 收敛 + 滑移证据）。
2. 若 geometry_conf ≥ τ_g ⇒ 感知→执行误差满足 J_geo，几何违规率 ≤ 0.1%（Σ_X 保序传播 + GSE 膨胀）。
3. J_switch 通过 ⇒ 切换后 CoM 在支撑多边形内、接触调度无冲突、落足几何可信（HSC 守卫）。
4. 任一 B_geo/B_mode 耗尽 ⇒ 触发冻结几何或锁定模态的安全策略，退化路径有界（PCE+++++ 单调消耗）。

## 5. 本轮最大风险

**一句话**：若在楼梯/坡面过渡时腿式冲击抬升 Σ_X、运动又恰好退化为平面激励，系统可能「自以为几何接地」而实际落足点已偏数厘米——此时模态切换证书会在错误框架上通过，导致踏空或压碎接触；必须以「κ_obs 可观测性门控 + Σ_X 超阈值冻结几何 + 切换前强制几何校验 + MGC 五元校验」四重护栏，确保「模态切换」永远不早于「几何可信」。
