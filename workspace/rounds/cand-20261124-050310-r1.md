> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v22 + IP-431–435（v22 = v21 的语义-规范层 + HDL/ACSC/DCSC/HPC-E/CFC++，其上承 v21 的 SDC/CAC/DCL/GIC 与更早的 v20/v19/v18/v17 证书与感知链）。
> 本轮纪律：**不推倒 v22**；PCA/CTS/CFC/HPC/CFCtrl/SDC/CAC/DCL/GIC/HDL/ACSC/DCSC/HPC-E/CFC++ 全部保留。本轮只做一件事：**把"联邦"从一句口号变成可证明正确的跨机结构——用"点云配准"补上各机坐标系之间的误差证书，用"多机协同"把"局部安全 / 全局活性"严格分离，并把 CFC++ 从"安全闸门"降级为"活性优化器"**。

## 0. 直觉与动机

**灵感 1（点云配准 → 联邦感知缺失的"第 0 步"：坐标系本身必须先被认证）**
直觉：v21/v22 的 CFC/CFC+/CFC++ 一直在"合并各机的票"，却默认了一件从未被证明的事——**各机的坐标系是同一个**。点云配准正是这个"第 0 步"：把 robot i 的局部点云 P_i 以刚体变换 T_{i→W} 对齐到世界系 W。但配准有三件被忽视的狠事：(1) 误差是**刚体相关**而非逐点独立——一次旋转误差 θ_reg 会让力臂 L 处的点偏移 L·θ_reg，逐点独立膨胀会在受约束方向过度保守、又在退化方向严重乐观；(2) **退化**：长廊/隧道/大面积平面/反光地面里，配准沿某些方向几乎无约束（Hessian 近奇异），算法却会"很自信地"给出错误位姿；(3) 最关键，**配准误差能把真障碍"对"到别处、伪造自由空间**，直接反噬 P34 的单调证据律。核心创新：**跨机配准证书 (Cross-Robot Registration Certificate, CRRC)** + **配准鲁棒证据融合 (Registration-Robust Evidence Fusion, RREF)**。反直觉点：**配准误差不该写成"给每个点加噪声"，而应写成"作用于整个点集的一个集合变换"——障碍取变换置信集的并（只增），自由空间取交（只减）**。于是配准不确定性被驯化成 P34 单调律的又一个"单边误差源"，而不是它的漏洞。

**灵感 2（多机协同 → 安全是局部不变量，共识只是活性优化）**
直觉：过去两轮一直想用"更强的共识"（CFC 的模态多样性、CFC++ 的层级一致性）去堵"相关误判共识"，这是方向性错误：**只要安全还依赖共识，任何跨机相关故障都能一起骗过共识**。多机协同该给的最硬教训来自分布式系统：**安全必须是每台机器人各自持有的局部不变量——即便同伴完全不配合、通信全断也成立；协同/共识只能提高"能一起做多少事"，绝不能成为"能不能安全"的前提。** 核心创新：**分区鲁棒联邦闸门 (Partition-Robust Federation Gate, PRFG)**：把不通信或证书过期的同伴按"它可能在其能量可达集内的任意位姿"做**最坏情况膨胀**当障碍；把 CFC++ 明确降级为**只在已证明安全的域内挑更优计划**的活性层。反直觉点：**"让共识更鲁棒"的正解不是更强的共识，而是"绕开共识也能安全"**——把共识移出安全路径，相关误判共识的最大风险面被结构性拆除，而不是被更强的门槛暂时压住。

**灵感 3（协同义务 → 联合可行 ≠ 各自可行，需确定性优先级破对称）**
直觉：v21 的 DCL 义务（τ 内让位）只做了**单机**可满足性；多机时"我让你、你也让我"各自都可行、合起来却互锁（死锁），或反复谦让（活锁）。核心创新：**协同义务调度器 (Cooperative Deontic Scheduler, CDS)**：把合并后的让位义务视作一次"联合可行性"检查，用**确定性优先级** `prio_i = (deadline_i, H(id_i, epoch))` 字典序（H 为抗碰撞哈希）打破对称——低优先级先让、高优先级先过；优先级在回合内稳定并带滞回，避免抖动；只有"低优先级让位后仍不可满足"才升级 SafeStop。反直觉点：**多机死锁的解不是"协商出更好的共识"，而是"用可验证的确定性全序消灭对称性"**——顺序一旦确定，对称死锁不可能存在，只剩可度量的活性损失。

**三者如何统一**
统一为 v22 之上的 **"跨机几何—协同规范"层**：CRRC/RREF 保证"我们说的是同一个世界"（含退化与力臂放大），PRFG 保证"不同世界也各自安全"，CDS 保证"同一世界里能一起动而不互锁"。共享状态扩展为 `ζ_coop = ζ_pgev ∪ (T_{i→W}, 𝒯_δ^i, deg_i, U_j(t), R_j^reach, epoch, prio)`。统一准入门升级为 **HPC-EC = (HPC-E, CRRC, PRFG, CDS)**：在 v22 的"几何∧规范∧负信息∧能量"之上再 ∧"坐标系可信 ∧ 分区下仍安全 ∧ 联合义务可行"。安全继承：`Exec_v23 = Exec_v22 ∩ Fil_reg ∩ Fil_partition ∩ Fil_joint ⊆ Exec_v22`。

## 2. 设计原则（在 P37/P41/P42 基础上新增 P43–P45）

**P43 配准不确定性单边律（Registration-Uncertainty One-sidedness）**
给定局部证据 `(O_i, ℱ_i)` 与变换置信集 `𝒯_δ^i`，世界系证据定义为
`O_i^W = ⋃_{T∈𝒯_δ} T(O_i)`（障碍只增），`ℱ_i^W = ⋂_{T∈𝒯_δ} T(ℱ_i)`（自由只减）。
任何配准不确定都只能使 `O^W` 变大、`ℱ^W` 变小；`𝒯_δ` 失效时必须让 `O_i^W → 视锥并集`、`ℱ_i^W → ∅`（全保守）。故配准是与 SDC/CAC 同向的单边误差源，不破坏 P34。

**P44 局部安全—全局活性分离律（Local-Safety / Global-Liveness Separation）**
对每个同伴 j 定义**占据不确定集** `U_j(age)`：通信新鲜且 CRRC 有效时 = 其认证位姿 ⊕ `𝒯_δ` ⊕ TTL 内位移；否则 = 其能量可达占据集 `R_j^reach`。安全判定永远对 `⋃_j U_j(age)` 做，且 `U_j` 对 age **单调不减**。于是：
- 通信/配准失效 ⇒ `U_j` 变大 ⇒ 准入门单调收缩（更保守，仍安全）；
- federation 的唯一作用是**把 `U_j` 从最坏可达集收窄到"认证实际位姿 + 误差"**，从而扩大准入集（活性）；
- 因此 federation 只影响活性，绝不是安全前提：`Safe = 对最坏 U_j 仍无碰撞`。

**P45 协同义务的确定性优先律（Deterministic-Priority Joint Obligations）**
联合让位可行 = 存在按 `prio_i = (deadline_i, H(id_i, epoch))` 字典序的让位序列，使每台机器人在各自 τ 内抵达 YieldSet 且全程避开 `⋃U_j`。低优先级先让、高优先级先通过；优先级在回合内稳定、变更带滞回；联合不可满足 ⇒ 可审计 SafeStop 升级。故 `Fil_joint ⊆` v22 的 DCL 域，`Exec_v23 ⊆ Exec_v22`。

## 3. 与基线的接口（如何退化）

- **CRRC 失效/过期** ⇒ 退回各机局部坐标系，同伴按 `R_j^reach` 最坏膨胀 ⇒ 比 v22 保守；
- **配准退化漏报 / `𝒯_δ` 被低估** ⇒ **唯一真正的失效方向**（见 §5），其余皆向保守退化；
- **PRFG 失效** ⇒ 退回"局部安全 + 全员最坏可达集" ⇒ ⊆ v22；
- **CDS 失效** ⇒ 共享区静态停机 / 全员让位 ⇒ ⊆ v22；
- **CAC/SDC/DCL/GIC/HPC-E 失效** ⇒ 按 v21/v22 既有阶梯退化 ⇒ ⊆ v22；
- **全失效** ⇒ `Exec_v23 ⊆ Exec_v22 ⊆ ... ⊆ Exec_v18`（引理 162 链）。
- **安全继承**：CRRC/RREF 只做单边集合变换、PRFG 的 `U_j(age)` 单调不减、CDS 只在 v22 已许可域内重排 ⇒ 任意失效都向更保守方向退化。

## 4. 预期贡献

1. **跨机配准证书 (CRRC)**：首次把点云配准的刚体误差变成带退化方向的 conformal 置信集，给出力臂-旋转-检测的误差复合式 `ε_loc^W ≤ ε_loc + L·θ_reg + t_reg`；
2. **配准鲁棒证据融合 (RREF)**：把配准不确定驯化为"障碍并、自由交"的单边集合变换，使 P34 单调律在跨机场景下闭合，杜绝配准诱发的伪造自由空间；
3. **局部安全-全局活性分离**：给出 `U_j(age)` 单调占据不确定集，证明 federation 只是活性优化、绝非遗安全前提，从结构上拆除"相关误判共识"风险；
4. **协同义务调度 (CDS)**：确定性优先级破对称，给出无对称死锁/无活锁（仅 σ-有界活性损失）的联合让位协议与 SafeStop 升级路径；
5. **HPC-EC 统一门**：HPC-E ∧ CRRC ∧ PRFG ∧ CDS，`Exec_v23 ⊆ Exec_v22 ⊆ ... ⊆ Exec_v18` 闭环。

## 5. 本轮最大风险

**一句话**：v23 的安全性完全押在"配准置信集 `𝒯_δ` 与同伴可达集 `R_j^reach` 都是真值的**过近似（sound over-approximation）**"这一前提上；一旦在退化场景（长廊/大面积平面/反光地面）里退化检测漏报、把 `𝒯_δ` 估小，整支机器人会在**同一个被认证为"可信"的错误坐标系**里一致地低估彼此与障碍的占据——这不是单机漏检，而是可审计地、自洽地、**整队共识地**看不见同一个人/同一障碍，且 CFC++ 会把这种一致错误当成"高置信共识"来放大。

## 2. 关键算法骨架（在 IP-431–435 骨架上扩展）

```python
import numpy as np
from dataclasses import dataclass

# IP-436 跨机配准证书：conformal 置信集 + 退化定向膨胀 + 力臂误差复合
@dataclass
class RegistrationCertificate:
    T: np.ndarray          # \hat T_{i->W}
    conf: "TransformConfidenceSet"   # 𝒯_δ
    deg: np.ndarray        # 退化方向（bool mask）
    q: float               # conformal 分位阈值

class CrossRobotRegistrationCertificate:
    def __init__(self, score_fn, delta=0.01, lam_deg=1e-3):
        self.score_fn = score_fn      # score_reg(T, T_hat)
        self.delta = delta
        self.lam_deg = lam_deg
        self.q = None

    def calibrate(self, calib_pairs):
        # calib_pairs: [(T_hat, T_true)]，交换性只需可交换样本，不假设网络正确
        scores = np.sort([self.score_fn(Th, Tt) for Th, Tt in calib_pairs])
        n = len(scores)
        k = min(int(np.ceil((n + 1) * (1.0 - self.delta))), n)
        self.q = scores[k - 1]

    def estimate(self, P_i, P_W, T_init):
        T_hat, H = self._icp_with_hessian(P_i, P_W, T_init)   # 点面 ICP
        lam, V = np.linalg.eigh(H)
        deg = lam < self.lam_deg                              # 无约束（退化）方向
        scale = np.where(deg, 1.0 / np.maximum(lam, 1e-9), 1.0)
        conf = TransformConfidenceSet(T_hat, self.q, V, deg, scale)
        return RegistrationCertificate(T=T_hat, conf=conf, deg=deg, q=self.q)

    def world_loc_error(self, eps_loc, L, theta_reg, t_reg):
        return eps_loc + L * theta_reg + t_reg   # 一阶上界

# IP-437 配准鲁棒证据融合：障碍取并（只增）、自由取交（只减）
class RegistrationRobustEvidenceFusion:
    def __init__(self, n_samples=64):
        self.n_samples = n_samples    # 置信集采样；或对膨胀盒做解析 Minkowski 和

    def world_obstacles(self, O_local, cert):
        return union_over_confidence_set(O_local, cert.conf, self.n_samples)

    def world_free(self, F_local, cert):
        return intersect_over_confidence_set(F_local, cert.conf, self.n_samples)

    def fuse(self, hull, detections, cov, certs):
        obs = union_all(hull, *[self.world_obstacles(d.box, certs[d.robot])
                                for d in detections])
        free = intersect_all(*[self.world_free(c.free, certs[c.robot])
                               for c in cov])
        # 不变量：Obs_{t+1} ⊇ Obs_t，Free_{t+1} ⊆ Free_t（P34/P43 闭合）
        return obs, free

# IP-438 分区鲁棒联邦闸门：U_j(age) 单调，federation 只收窄 U_j（只增活性）
class PartitionRobustFederationGate:
    def __init__(self, reg_ttl=0.2):
        self.reg_ttl = reg_ttl

    def peer_uncertainty_set(self, j, now):
        age = now - j.last_update
        if j.link_alive and age <= self.reg_ttl and j.crrc_valid:
            return inflate(j.certified_pose, j.crrc.conf, j.v_max * age)
        return j.reachable_occupancy()          # 最坏：能量可达集

    def sign_robust_vote(self, vote, cert):
        # 票在 𝒯_δ 下符号不变才可计入（帧一致性）
        return all(vote.sign(T(vote.point)) == vote.sign(vote.point)
                   for T in cert.conf.samples())

    def admit(self, plan, peers, now, epoch):
        U = [self.peer_uncertainty_set(j, now) for j in peers]
        frame_ok = all(self.sign_robust_vote(v, p.crrc)
                       for v, p in zip(plan.votes, peers) if p.crrc_valid)
        fresh = all(v.epoch >= epoch for v in plan.votes)
        # 安全永远对最坏 U_j 判定；federation 只是让 U_j 更小
        return plan.avoids(union_all(U)) and fresh and frame_ok

# IP-439 协同义务调度：确定性全序破对称，联合可行否则 SafeStop
class CooperativeDeonticScheduler:
    def priority(self, i):
        return (i.deadline, hash64(i.id, i.epoch))

    def joint_feasible(self, obligations, peers, now):
        order = sorted(obligations, key=lambda o: self.priority(o.robot))
        state = init_state()
        U = union_all(peers, lambda p: p.uncertainty_set(now))
        for o in order:
            if not assign_yield(o, state, avoid=U):
                return False, o          # 低优先级也让不出 ⇒ 不可满足
            state = apply_yield(o, state)
        return True, None

    def schedule(self, robots, now):
        ok, culprit = self.joint_feasible(robots.obligations, robots.peers, now)
        if ok:
            return self.commit_with_hysteresis(robots)   # 优先级带滞回，防抖动
        return self.escalate_safestop(culprit)           # 可审计升级，绝不静默死锁

# IP-440 HPC-EC 统一准入门（HPC-E 原样保留，只加三道门）
@dataclass
class HPCEC:
    hpce: "HPCE"
    crrc: dict                       # robot -> RegistrationCertificate
    prfg: PartitionRobustFederationGate
    cds: CooperativeDeonticScheduler

    def admits(self, plan, now, epoch):
        if not self.hpce.admits(plan):
            return False
        fresh = all(plan.robot_age(r, now) <= plan.reg_ttl for r in plan.robots)
        if not fresh:
            # CRRC 过期：退化为局部安全 + 全员最坏 U_j（更保守）
            return plan.avoids(union_all(p.reachable_occupancy() for p in plan.peers))
        return (self.prfg.admit(plan, plan.peers, now, epoch)
                and self.cds.joint_feasible(plan.obligations, plan.peers, now)[0])
```

## 3. 关键引理与安全继承（推导）

**引理 926.1（RREF 单边性）** 对任意置信集 `𝒯_δ`，`O^W = ⋃_{T∈𝒯_δ} T(O)` 随 `𝒯_δ` 增大单调不减，`ℱ^W = ⋂_{T∈𝒯_δ} T(ℱ)` 随 `𝒯_δ` 增大单调不增。故当 `𝒯_δ` 从真实置信集向外扩大（保守化）时，障碍只增、自由只减，与 P34 一致；配准不确定无法凭空生成自由空间。∎

**引理 926.2（`U_j` 单调与局部安全）** 若 `R_j^reach` 是 j 实际可达占据的过近似、且 `𝒯_δ` 是真变换的过近似，则 `U_j(age)` 对 age 单调不减且始终包含 j 的真实占据。于是对 `⋃_j U_j` 无碰撞的计划在任意通信/配准状态下安全；federation 收窄 `U_j` 只扩大准入集（活性），不改变安全蕴含方向。∎

**引理 926.3（CDS 无对称死锁）** 固定 epoch 下 `prio_i = (deadline_i, H(id_i, epoch))` 因 H 抗碰撞而构成全序，故让位依赖图无环；低优先级完成让位后即从依赖图移除，序列终止。因此不存在"互相等待"的对称死锁；仅可能因 deadline 过紧而不可满足，此时升级 SafeStop。优先级滞回保证跨回合不抖动（无活锁）。∎

**定理 926.4（安全继承）** `Exec_v23 = Exec_v22 ∩ Fil_reg ∩ Fil_partition ∩ Fil_joint`。由 P43 单边性、P44 单调性、P45 子集性，三个过滤器均不放大 `Exec_v22`；各自失效时退化为全保守（`Fil → ∅` 或 `U_j → R_j^reach`）。故 `Exec_v23 ⊆ Exec_v22 ⊆ ... ⊆ Exec_v18`。∎

## 4. 实验设计（验证计划）

**E1 配准置信集与退化**
场景：长廊、开阔平面、反光地面、对称房间。δ=0.01。测 (a) 真变换落入 `𝒯_δ` 的经验覆盖率（目标 ≥99%），(b) 与"逐点独立高斯膨胀"的体积比（受约束方向应更紧、退化方向应更松），(c) 退化方向召回率。指标：覆盖率、膨胀体积、退化召回。

**E2 配准鲁棒证据（phantom free / phantom obstacle）**
注入受控错配准（旋转 0.5°–5°、平移 1–10cm），对比 RREF 与逐点高斯膨胀 baseline。测 (a) 真实障碍被抹除率（RREF 应恒 0，单边性），(b) 伪造障碍体积（应随 `𝒯_δ` 有界增长）。预期：RREF 零抹除、伪障碍有界。

**E3 分区鲁棒性与活性**
N=4 机器人在共享走廊，按概率 p 随机断链/延迟/epoch 回退。测安全违规（应恒 0）、任务通过率 vs p、`U_j` 体积 vs 新鲜度（应单调）。对照"共识驱动安全"baseline（预期在相关故障下出现违规），验证 P44。

**E4 协同义务与死锁**
双机对称对遇、多人交叉让位、分区导致优先级视图不一致。测死锁次数/活锁次数（应均 0）、SafeStop 触发率、平均通过时延、优先级抖动（滞回后应 0）。对照朴素对称协商（预期出现死锁），验证引理 926.3。

**汇总指标**：安全违规、conformal 覆盖率、phantom-free 抹除率、任务通过率/吞吐、膨胀体积、SafeStop 率、死锁/活锁次数。

## 6. 本轮最大风险

**一句话**：v23 的安全性完全押在"配准置信集 `𝒯_δ` 与同伴可达集 `R_j^reach` 都是真值的**过近似（sound over-approximation）**"这一前提上；一旦在退化场景（长廊/大面积平面/反光地面）里退化检测漏报、把 `𝒯_δ` 估小，整支机器人会在**同一个被认证为"可信"的错误坐标系**里一致地低估彼此与障碍的占据——这不是单机漏检，而是可审计地、自洽地、**整队共识地**看不见同一个人/同一障碍，且 CFC++ 会把这种一致错误当成"高置信共识"来放大。
