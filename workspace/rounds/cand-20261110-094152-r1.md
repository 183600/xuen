# 第 43 轮（新循环第 3 轮） · 协同证书契约与实时推理调度：从「单机证书飞轮」到「多机可组合的实时认证团队」（四层架构 v8）

> 承接第 42 轮 v19（Sim-Cert-RAG 飞轮）。第 42 轮把单机的「仿真验证→知识沉淀→边缘低成本→持续进化」跑成了闭环，但它的证书单位始终是**一个**具身体：CAR 守卫、L0 表、INT8 监控器都默认「我只看我自己」。本轮灵感词「协同控制」与「实时推理」正好戳中规模化落地的两个新命门。**协同控制**要求把单机证书升级为**可组合的假设-保证契约**：每个机器人只对自己负责的安全谓词给出保证，对邻居只做有界假设；团队安全性由契约图的无环组合推出，而不是去枚举乘积状态空间。**实时推理**要求这些守护判断必须在**截止期内**完成：感知/监控推理一旦迟到，证书的输入就已过期，soundness 必须显式地「以时间为参数」。两者结合产生一个第 42 轮完全没有的新对象——**团队级、时间敏感的协同证书**：谁在什么新鲜度下、对哪条共享约束、拥有权威判定权，以及当通信/推理退化时如何**单方面**退回安全集而不等共识。核心口号：**安全不能等共识，共识只服务非时间关键的一致；实时推理不是越快越好，而是「可证明地在截止期前完成，且过期即降级」。**

## 0. 直觉与动机

**灵感 1（协同控制 → 从「单机证书」到「可组合契约」）**：第 42 轮的 CAR 把安全性压在一个确定性自动机上，一旦两台机器人共享同一片空间，最直接的做法是乘积自动机——但它是状态空间爆炸的重灾区。协同控制的经典答案是**假设-保证（assume-guarantee）契约**：机器人 i 给出保证 G_i（我会守住我负责的通道/距离/优先级），并假设邻居满足 A_i（邻居会在它的车道内、会礼让、会按承诺轨迹走）。只要「j 的保证 ⊇ i 的假设」且契约图无环，团队安全就由局部证书组合得到。直觉上这就是把第 42 轮 IP-47 的「模板检索组合」从结构组合升级为**语义组合**：组合的是证明责任，不是状态。关键新增是**责任分配**（ownership allocation）——把共享安全谓词切成互不重叠的「所有权」，让每个约束只有一个权威判定者，从根上消除「你等我、我等你」的循环假设。

**灵感 2（实时推理 → 证书以「时间」为参数，过期即降级）**：第 42 轮的 INT8 监控器只报 WCET < 100μs，但没回答一个致命问题：**如果推理偶尔超时，证书还成立吗？** 实时推理的直觉是给每个守护判断引入三个时间量：推理本身的最坏执行时间 W、输入状态的最大允许陈旧度 T_stale、以及端到端截止期 D。由 Lipschitz 性，|m(x_t) − m(x_{t−Δ})| ≤ L_m·v_max·Δ，于是「用多旧的状态算边际」直接换算成「多保守的阈值」。更妙的是，网络可以做成**证书感知的早退（early exit）**：不是跑到最后一层才给结论，而是每个出口都带一个已标定、可证明的保守下界；调度器根据剩余时间选出口，越早退越保守，但**永远 sound**。这把第 42 轮 LCS 的「档位」从算力维度扩展到了**时间-新鲜度维度**。多机时还能**拆分推理**（把大模型切给多台机器流水线执行）来压单机延迟，但要以通信延迟为代价——是否划算有清晰的调度不等式。

**灵感 3（协同 × 实时 → 分布式证书共识与「单方面安全」）**：多机协同最容易出的安全事故是「双方都以为对方会让」。分布式一致性能解决「大家看到同一份事实」，但共识有延迟，而安全反应时间很短。直觉上的正解是把二者**分层**：**时间关键的安全判定单方面本地完成**（任一方发现自己的约束被破坏或状态过期，立刻退回本地安全集/SafeStop，不问别人）；**非时间关键的一致**（所有权交接、任务重分配、共享地图更新）才走共识。于是得到一个强性质：**安全不依赖共识的活性（liveness），只依赖所有权划分与陈旧度上界**。这正是把第 42 轮的偏移监控飞轮扩展到团队：共享契约、所有权、调度表都可以进 CKB 检索复用。

**耦合升级**：契约（IP-57）定义「谁对什么负责、假设谁什么」，实时调度（IP-58）保证「判定在截止期前、以足够新鲜的状态完成」，分布式共识（IP-59）负责「所有权与共享事实的安全交接」。三者与第 42 轮的 SCV/CKB/ECR 飞轮咬合：SCV 在仿真里**注入通信延迟、丢包、推理超时、邻居违约**来做团队压力测试；CKB 存**团队模板**（契约图 + 所有权分配 + 推理调度）；ECR 变成**多租户实时推理运行时**。

## 1. 形式化定义（增量：定义 38–43）

**定义 38（协同证书契约 CCC）**：机器人 i 的契约 C_i = (A_i, G_i, I_i, O_i)，其中 G_i 是其**保证**（对自身安全谓词及归其所有的共享谓词），A_i 是其对邻居/环境的**假设**（如「j 在走廊内」「j 按已承诺轨迹运动」「共享通道空闲」），I_i 是**接口契约**（交换变量：相对位姿、意图轨迹、时间戳、承诺版本），O_i 是其**所有权集合**（共享约束中由 i 权威判定的子集）。团队契约图 G_c = (V, E_A)，边 j→i 表示 A_i 中提及 j 的保证。

**定义 39（契约的良基性与组合）**：称 G_c **良基（well-founded）** 当且仅当它是 DAG，且每条边 j→i 满足 **保证蕴含假设带时间裕度**：G_j ⊇ A_i ⊕ ε_t，即邻居的保证在考虑通信延迟 D_comm 与陈旧度 T_stale 后仍蕴含 i 的假设。**组合定理**：若 G_c 良基、∀i 的局部证书 sound、且共享约束的所有权划分满足 ∪_i O_i ⊇ 共享谓词集、O_i 两两不交，则团队保证 G_team = ∧_i G_i 成立。**推论**：无环性把「循环互等」排除；所有权不相交把「重复判定/漏判」排除。

**定义 40（实时推理的证书新鲜度）**：监控推理任务 τ = (W, D, T)，W = 经抽象解释认证的最坏执行时间，D = 截止期，T = 周期。证书在 t 时刻**有效**当且仅当：推理完成时间 ≤ D，且所用状态年龄 Δ ≤ T_stale。**新鲜度界**：由 Lipschitz，允许陈旧度 T_stale ≤ η / (L_m · v_max)，其中 η 是可接受的边际低估量。**命题**：若实际陈旧度 Δ > T_stale，则以 m_lo − L_m·v_max·Δ 作为下界（自动变保守），从而「超时/过期」只损失可用性，不破坏 soundness。

**定义 41（证书感知早退与时间-保守阶梯）**：网络有出口集合 {e_1,…,e_L}（由浅到深），每个出口 e 带已标定的保守下界 m_e(x) 与额外延迟 W_e（单调：e 越深，m_e 越大且 W_e 越大）。调度器在剩余预算 b 下选择最深的满足 W_e ≤ b 的出口；若全不满足则退回 L0 查表或 SafeStop。**单调保守性**：∀e<e'，m_e(x) ≤ m_{e'}(x)，故早退只会更保守。

**定义 42（分布式证书共识与安全交接）**：设共享谓词 P 的所有权在机器人间可转移。交接协议为两阶段：Owner(i) --release(g_i=SAFE)--> Owner(j) --claim(带版本向量)--> 全体。**安全不变式**：任意时刻 P 至少有一个 owner，且旧 owner 在新 owner 确认前**不得**放弃本地守卫（双守重叠期）。**定理**：在崩溃故障、消息延迟 ≤ D_comm、无拜占庭的前提下，若每个 owner 的判定陈旧度 ≤ T_stale，则 P 的安全性以概率 1 维持，与共识延迟无关；共识只影响交接的**及时性（liveness）**。

**定义 43（团队知识模板与协同飞轮）**：CKB 记录扩展为团队条目 (Φ, Ψ, G_c, O, Σ)，Φ = 团队任务指纹（技能组合、队形、角色），Ψ = 环境+通信指纹（拓扑、链路质量、带宽），G_c = 契约图模板，O = 所有权分配方案，Σ = 实时推理调度表（任务→核/出口/截止期）。SCV 的域随机化新增**交互扰动** Δ_int：通信延迟/丢包、邻居违约/掉线、推理超时注入。检索 R(Φ, Ψ) 返回候选团队模板，差集补全只需在「契约/所有权/调度」的差集上做，而非重新枚举团队状态。

## 2. 产出设计（增量 IP-57/58/59 + 升级 IP-45/47/51/52/53/55/56）

### 2.1 IP-57 COOP-CERT-CONTRACT（CCC 协同证书契约引擎）
1. **责任分配器**：把共享安全谓词（通道、路口、相对距离、共享资源）切分为互不重叠 ownership；对称任务用 token-ring/优先级打破对称，得到无环契约图。
2. **契约合成**：从 CKB 团队模板热启动 → 检查接口兼容 → 对差集求契约补丁（CEGAR），输出 DAG + 时间裕度 ε_t。
3. **假设放电（discharge）**：运行时把邻居的「承诺轨迹 + 时间戳 + 版本」与 A_i 比对，超出时间裕度立即判假设失效并降级。
4. **违约归因**：与 SCV 反例归因联动，标注「邻居违约 / 通信陈旧 / 所有权冲突 / 推理超时」。

### 2.2 IP-58 RT-INFERENCE-SCHEDULER（RIS 实时推理调度器）
1. **WCET 认证**：对 INT8 监控网络逐层区间抽象解释，得每层 WCET 上界并求和；对早退出口分别认证。
2. **调度可行性**：用响应时间分析（RTA）在多核/GPU 共享干扰下求每个监控任务的 WCRT；不可行则降出口或迁移。
3. **新鲜度管理**：维护每类状态的时间戳，Δ > T_stale 即触发保守化（放大阈值）或降级。
4. **拆分推理规划**：当多机链路延迟 < 计算节省时，把大模型按层切分做流水线；否则退回单机早退。给出「拆分收益不等式」。

### 2.3 IP-59 DIST-CERT-CONSENSUS（DCC 分布式证书共识与安全交接）
1. **所有权令牌 + 版本向量**：共享谓词的所有权随令牌转移，携带逻辑时钟；防止双主。
2. **两阶段安全交接**：释放（旧主仍守）→ 确认（新主接管）→ 回收；重叠期双守，绝不出现空窗。
3. **单方面安全兜底**：本地守卫失败/陈旧超界 → 立即 SafeStop，不等待任何投票。
4. **分区容忍**：网络分区时各分区保守收缩到本地安全集；恢复后按版本向量对账，冲突走保守合并。

## 3. 四层架构 v8

```
L1: TRI-FUSE(INT8) + PTP/逻辑时钟(时间同步) → 状态+时间戳 → 新鲜度可见
L2: 分布式感知 + 早退/拆分推理(RIS调度) → 语义摘要 + 推理时间戳
L3: IP-51 CAR(团队模式: Owned/Delegated/Discharging)
    ← IP-57 CCC(契约图 + 所有权 + 假设放电)
    ← IP-58 RIS(WCET认证 + RTA + 新鲜度 + 出口选择)
    → IP-59 DCC(所有权令牌 + 两阶段交接 + 单方面兜底)
    → IP-47 契约DAG组合 → IP-39 规划(CBF=契约保证) → IP-45 总线(契约gossip/投票/心跳)
L4: IP-54 SCV(多机域随机化 + 交互扰动注入 + 契约压力测试)
    → IP-55 CKB(团队模板检索 + 差集补全) → 契约/所有权/调度合成 → 热更新下发
运行期：本地守卫(单方面) + 新鲜度检查 + 出口调度 → 违约/超时/陈旧 → 本地降级 → 事件入KB
```

## 5. 本轮最大风险

**一句话**：本轮最大风险是**「循环假设 + 截止期违约」共同制造的团队级安全盲区**——每个机器人都假设邻居会履约，而没有任何一方在截止期内真正验证该假设，团队证书就会在协同中静默失效；因此 E87（契约无环性）与 E89/E91（截止期与交接）必须作为红线实验，任一项不达标即退回「静态所有权 + 单机 SafeStop」的最小安全模式。

### IP-57 CCC：契约合成与假设放电
```python
def build_contract_graph(team, task, KB):
    # 1. 团队模板热启动
    tmpl = KB.retrieve_team(fingerprint(task, team.env), k=5)
    # 2. 责任分配：共享谓词切分为互不重叠 ownership（对称时 token-ring 破对称）
    O = allocate_ownership(task.shared_predicates, team,
                           policy=tmpl.O, symmetric_policy='token_ring')
    assert ownership_disjoint(O) and ownership_cover(O, task.shared_predicates)
    # 3. 建契约节点（假设附时间裕度）
    Gc = ContractGraph()
    for i in team:
        C_i = tmpl.contract_for(i)
        C_i.O = O[i]
        C_i.A = attach_time_margin(C_i.A, D_comm=team.D_comm, T_stale=team.T_stale)
        Gc.add_node(i, C_i)
    # 4. 边：j 的保证在时间裕度后仍蕴含 i 的假设
    for i in team:
        for j in team.neighbors(i):
            if implies_with_margin(Gc.G[j], Gc.A[i], eps_t):
                Gc.add_edge(j, i)
    # 5. 良基性硬校验
    if not is_dag(Gc):
        O = allocate_ownership(task.shared_predicates, team, policy='priority_total_order')
        Gc = rebuild_with(O)
    assert is_dag(Gc)
    # 6. 差集补全：只在「契约/所有权」缺口上跑 CEGAR
    Delta = find_contract_gaps(Gc, task)
    Gc = cegar_patch_contracts(Gc, Delta, budget=300)
    return Gc, O

def discharge_assumptions(i, now, neighbor_msgs, C_i):
    for j, a in C_i.A.items():
        msg = neighbor_msgs.get(j)
        if msg is None:            return False, 'missing'
        if now - msg.stamp > a.T_stale: return False, 'stale'
        if not a.contains(msg.committed_traj, msg.version):
            return False, 'violated'
    return True, 'ok'
```

### IP-58 RIS：WCET 认证、RTA 与新鲜度
```python
def certify_wcet(net_int8):
    wcet = {}
    for e in net_int8.exits:               # 早退出口由浅到深
        w = 0
        for layer in net_int8.layers_up_to(e):
            w += interval_abstract_bound(layer)   # 逐层保守上界
        wcet[e] = w
    return wcet                            # 单调：e 越深 W_e 越大

def rta_schedulable(tasks, cores, interference):
    for tau in tasks:
        R = tau.W
        while True:
            R_new = (tau.W
                     + sum(ceil(R / t2.T) * t2.W for t2 in higher_priority(tau, tasks))
                     + interference(tau, cores))
            if R_new == R: break
            R = R_new
        if R > tau.D:
            return False, tau
    return True, None

def choose_exit(remaining_budget_us, wcet, cert):
    for e in reversed(cert.exits):         # 深→浅，取预算内最深出口
        if wcet[e] <= remaining_budget_us:
            return e
    return None                            # None → 退回 L0 查表 / SafeStop

def freshness_penalty(state_ts, now, L_m, v_max, eta):
    Delta = now - state_ts
    T_stale = eta / max(1e-9, L_m * v_max)
    penalty = L_m * v_max * max(0.0, Delta - T_stale)
    return (Delta <= T_stale), penalty     # 过期不破坏 sound，只加保守量

def split_inference_profitable(W_local, W_remote, D_link, n_stages):
    # 拆分收益：流水线节拍 max(W_stage, D_link) 对比单机 W_local
    return (W_local / n_stages > D_link) and (max(W_local / n_stages, D_link) < W_local)
```

### IP-59 DCC：安全交接与单方面兜底
```python
def transfer_ownership(P, old, new, version_vec):
    assert old.holds_token(P)
    send(new, RELEASE(P, version_vec, old.guard_status(P)))
    # 旧主在 ACK 前继续守卫（双守重叠，绝不空窗）
    if not wait_ack(new, timeout=D_comm):
        return 'abort'                     # 旧主保留所有权
    send_all(CLAIM(P, version_vec, old=old, new=new))
    # 新主确认后才允许旧主释放
    old.release_after(new.confirmed(P))
    return 'handover'

def local_safe_fallback(i, guard_status, freshness_ok):
    # 安全不等共识：任一条件不满足，立即单方面进入本地安全集
    if (not freshness_ok) or guard_status == 'FAIL':
        enter_local_safe_set(i)            # SafeStop / 保守收缩
        return True
    return False

def partition_reconcile(partitions, version_vecs):
    # 分区恢复：比版本向量，冲突取更保守者（交集/更大阈值）
    for P in shared_predicates():
        winners = [p for p in partitions if p.owns(P)]
        if len(winners) > 1:
            merge_conservative(P, winners)  # 交集契约 + 取最大阈值
```

### IP-51/52/56 升级：团队感知的自动机与实时运行时

```python
def car_team_transition(e, i, x, Gc, now):
    ok, reason = discharge_assumptions(i, now, Gc.msgs, Gc.C[i])
    if not ok:
        return DEGRADE(reason)             # 假设失效 → 本地降级
    if not owns_or_delegated_ok(Gc, e, i):
        return WAIT_OR_DEGRADE()           # 所有权未定 → 不冒进
    margin = cert_lookup_L0(x).m_lo[e]
    return margin >= Gc.C[i].alpha_e[e] * Gc.C[i].theta_sim[e]

def certify_light_deadline(x, guards, now, budget_us):
    fresh, penalty = freshness_penalty(x.ts, now, L_m, v_max, eta)
    b = cert_lookup_L0(x)                  # T-1
    if not fresh:
        return degrade_conservative(b, penalty)
    e = choose_exit(budget_us, WCET, cert) # 选时间-保守档
    if e is None:
        return degrade_conservative(b, 0.0)
    margin = int8_forward(model_int8, quantize(x), exit=e)
    return margin                          # 必要时叠加 penalty

def ecr_schedule(agents, tasks):
    # 多租户：每 agent 一组推理任务，按 EDF 调度，记录每状态时间戳
    for tau in tasks:
        tau.W = certify_wcet(tau.net)[tau.exit]
    ok, bad = rta_schedulable(tasks, cores, interference_model)
    if not ok:
        bad.exit = choose_exit(bad.D - bad.W_margin, WCET, bad.net)  # 降出口
```

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 契约循环依赖：对称任务里双方互相假设对方让行 | 高 | 责任分配强制不相交 + token-ring/优先级破对称；E87 无环率红线；不可破环则回退静态所有权 |

| 时钟同步漂移使陈旧度计算失真 | 中 | PTP + 逻辑时钟双轨；陈旧度按保守取大；漂移界计入 T_stale |

## 6. 本轮最大风险

**一句话**：本轮最大风险是**「循环假设 + 截止期违约」共同制造的团队级安全盲区**——每个机器人都假设邻居会履约，而没有任何一方在截止期内真正验证该假设，团队证书就会在协同中静默失效；因此 E87（契约无环性）与 E89/E91（截止期与交接）必须作为红线实验，任一项不达标即退回「静态所有权 + 单机 SafeStop」的最小安全模式。
