# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「虚实迁移」×「多任务学习」）

> 第 54 轮把技能组合从“能力匹配”升级为动作-鲁棒性双证书 `J=(ρ,A_cert,γ_ce,δ_a)`，并建立云边协同闭环。本轮补上此前一直被当作免责声明的两个维度：**仿真到现实的间隙不是标量，而是随场景参数变化的谱**；**技能库天然是多任务的，共享带来借力也带来负迁移**。核心矛盾：H22：第 54 轮的 `J` 假设“仿真可信”，但 gap 随 θ 剧烈变化，单点证书在未见 θ 上失效；H23：多任务共享表征使 `ρ(d)` 与 `α_S(a)` 变成任务条件化量，跨任务组合可能触发负迁移，而现有证书无法表达“任务相似度”这一先验。

## 0. 直觉与动机

**灵感 1（虚实间隙谱 → 把 reality gap 从免责声明变成可测的一等公民）**
直觉：仿真的“像不像”不是 0/1，而是一条曲线。对技能 S 与场景参数 θ ∈ Θ（光照、摩擦系数、传感噪声、通信时延、动力学参数），定义间隙 `g_S(θ) = D_TV(p_real(·|S,θ), p_sim(·|S,θ))`。过去我们说“仿真里成功率 95%”，其实只证明了 `g_S` 在**采样到的那几个 θ** 上小。把 `g_S` 显式成谱并用保形预测给出置信半径 `ε_n`，才知道“哪里能信、哪里不能信”。这把现实差距从拍脑袋的 domain gap 变成可测、可传递、可被证书引用的量。

**灵感 2（虚实锚点集 → 只在“仿真可信区”内承诺）**
直觉：定义锚点集 `A_ε = {θ : ĝ_S(θ)+ε_n ≤ ε_a}`，即仿真足够可信的 θ 区域。部署条件 `θ_t` 落在锚点外时，任何基于仿真的鲁棒性承诺都应被**主动否决**，而不是打折交付。锚点覆盖率 `cov_A(Θ_deploy)` 成为一个与 `ρ_min` 平级的部署前置条件。这把第 54 轮的“仿真证据”升级为“仿真证据 + 适用域声明”。

**灵感 3（任务条件化与负迁移 → 多任务不是免费午餐）**
直觉：技能 S 在任务 t 上的动作剖面是 `α_S(a|t)`，鲁棒性谱是 `ρ(d|t)`。共享表征会让任务互相借力（正迁移），也会互相污染（负迁移）。定义任务亲和度 `aff(t_i,t_j)`（梯度余弦）与干扰量 `I(t_i|lib)=perf(t_i|joint)-perf(t_i|single)`。多任务技能组合必须满足 `I ≥ -δ_I`，否则宁可退回单任务。第 54 轮的组合图 `G_S` 因而变成**任务条件化组合图** `G_S(t)`。

**灵感 4（二维迁移流形 → 任务轴 × 虚实轴同时迁移）**
直觉：真正的迁移发生在二维流形 `M = T × Θ` 上。从 `(t_s,θ_s)` 迁到 `(t_t,θ_t)`，需要同时满足“任务轴可迁”（亲和度/干扰在预算内）与“虚实轴可迁”（`θ_t` 在锚点内）。这解释了为何单轴迁移证书在另一轴上会失效：任务近但场景远 → gap 超界；场景近但任务远 → 负迁移。

**灵感 5（间隙的任务传递 + 负迁移绊线 → 用相似任务省现实样本，用在线监控兜底）**
直觉：gap 可在任务间传递：任务越相似，间隙越接近，`g_{t_j}(θ) ≤ g_{t_i}(θ) + L_aff·d_T(t_i,t_j) + η`。于是稀缺的现实数据可通过相似任务“借”到，只在高不确定处补采。另一方面，在线部署时用**负迁移绊线 NTT** 持续监控每个任务的干扰量，一旦跌破 `-δ_I` 就回滚共享参数或隔离任务头。前者省数据，后者防翻车。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（虚实间隙谱）**
场景参数 `θ ∈ Θ`，技能 `S` 的虚实间隙 `g_S(θ) = D_TV(p_real(·|S,θ), p_sim(·|S,θ))`。在 θ 网格 `{θ_1,...,θ_m}` 上得间隙谱 `𝔤_S = {g_S(θ_i)}`。用配对样本估计 `ĝ_S`，并以保形预测给出有限样本置信半径 `ε_n`，使 `P(sup_θ |ĝ_S(θ)-g_S(θ)| ≤ ε_n) ≥ 1-α`。

**定义 122（虚实锚点集与覆盖率）**
给定可信阈值 `ε_a`，锚点集 `A_ε = {θ ∈ Θ : ĝ_S(θ)+ε_n ≤ ε_a}`。部署域 `Θ_deploy` 的锚点覆盖率 `cov_A = Vol(A_ε ∩ Θ_deploy)/Vol(Θ_deploy)`。**锚点内承诺**：仅当 `θ_t ∈ A_ε` 才允许引用仿真鲁棒性证据。

**定义 123（任务条件化动作剖面与鲁棒性谱）**
技能 S 在任务 t ∈ T 上的动作剖面 `α_S(a|t) : A → [0,1]`，鲁棒性谱 `ρ_S(d|t)`。任务条件化组合图 `G_S(t) = (V, E_t)`，边条件 `compat(S_i,S_j|t) ≥ θ_a`。

**定义 124（任务亲和度与负迁移）**
任务 `t_i,t_j` 的梯度亲和度 `aff(t_i,t_j) = E_{batch}[cos(∇_φ L_{t_i}, ∇_φ L_{t_j})]`；任务干扰 `I(t_i|lib) = perf(t_i|lib) - perf(t_i|single)`。若 `I(t_i|lib) < -δ_I` 判定为**负迁移**。任务距离 `d_T(t_i,t_j) = 1 - aff(t_i,t_j)`。

**定义 125（二维迁移流形与可迁移性）**
迁移流形 `M = T × Θ`。技能库从 `(t_s,θ_s)` 到 `(t_t,θ_t)` 是 `(δ_t,δ_g)`-可迁移的，当且仅当：
```
d_T(t_s,t_t) ≤ δ_t  ∧  θ_t ∈ A_ε  ∧  g_{t_t}(θ_t) ≤ ε_a  ∧  I(t_t|lib) ≥ -δ_I
```

**定义 126（二维迁移证书 J²）**
`J² = (J, 𝔤, A_ε, aff, I, γ_rt, evidence)`：
- `J` 为第 54 轮动作-鲁棒性联合证书；
- `𝔤` 为间隙谱（含 `ε_n`）；`A_ε` 为锚点集；
- `aff` 为任务亲和度矩阵，`I` 为干扰量；
- `γ_rt : Θ_real → Θ_sim` 为现实到仿真的条件映射（双向校准）；
- `evidence` 至少含配对 real/sim 回放与跨任务探针批次。
若 `dom_{J²}(t_t,θ_t)=in`（四项条件全满足）则可部署。

**定义 127（虚实间隙的任务传递算子）**
存在任务嵌入 `z_T(t)` 与常数 `L_aff, η`，使
```
g_{t_j}(θ) ≤ g_{t_i}(θ) + L_aff·||z_T(t_i)-z_T(t_j)|| + η
```
`L_aff` 为间隙对任务距离的 Lipschitz 常数。该算子允许把源任务的 gap 证据迁移到目标任务，仅在 `L_aff·d_T` 小于预算时有效。

**定义 128（锚点约束域随机化 ACDR）**
域随机化分布 `p_DR` 需满足两条约束：锚点覆盖 `supp(p_DR) ⊇ A_ε`（保证可信区被覆盖），以及现实样本预算 `B_real` 下的覆盖率最大化。形式化为 `max_{p_DR} cov_A(p_DR) s.t. supp(p_DR) ⊇ A_ε, cost(real|p_DR) ≤ B_real`。

## 2. 关键算法 伪代码

### IP-121 RGS（Reality Gap Spectrum）

```python
def reality_gap_spectrum(skill, theta_grid, sim, real_pairs, n_cal, alpha=0.05):
    g = {}
    for theta in theta_grid:
        sim_dist = sim.rollout_dist(skill, theta, N=n_cal)
        real_dist = empirical_dist(real_pairs[theta])
        g[theta] = total_variation(sim_dist, real_dist)
    eps_n = conformal_radius(g, real_pairs, alpha)   # 有限样本校准
    return GapSpectrum(g, eps_n)
```

### IP-122 ANC（Anchor Set Construction）

```python
def anchor_set(gap_spec, eps_a):
    return {theta for theta, g in gap_spec.g.items()
            if g + gap_spec.eps_n <= eps_a}

def anchor_coverage(anchor, theta_deploy):
    return volume(intersection(anchor, theta_deploy)) / volume(theta_deploy)
```

### IP-123 MTA（Multi-Task Affinity / Interference）

```python
def task_affinity(lib, tasks, phi, probe_batches, delta_I):
    A = {}
    for ti, tj in combinations(tasks, 2):
        cos = mean(cosine(grad_loss(phi, ti, b), grad_loss(phi, tj, b))
                   for b in probe_batches)
        A[(ti, tj)] = Affinity(cos, d_T=1-cos)
    inter = {t: eval_task(t, lib.joint) - eval_task(t, lib.single[t])
             for t in tasks}
    negative = {t for t, v in inter.items() if v < -delta_I}
    return AffinityMatrix(A), inter, negative
```

### IP-124 GTC（Gap Transfer across Tasks）

```python
def transfer_gap(g_src, t_src, t_dst, z_T, L_aff, eta):
    d = norm(z_T[t_src] - z_T[t_dst])
    return {theta: g_src[theta] + L_aff * d + eta for theta in g_src}
    # 仅当 L_aff*d <= delta_g 时接受为目标任务的 gap 上界
```

### IP-125 D2C（Two-Dimensional Certificate）

```python
def two_dim_certificate(skill_seq, t_tgt, theta_tgt, J, gap, anchors, aff,
                        budgets):
    rho = compose_rho_cond(skill_seq, t_tgt, J.K)        # ρ(d|t_tgt)
    if min(rho.values()) < budgets.rho_min:
        return reject('robustness', rho)
    if theta_tgt not in anchors:                          # 出锚点，直接否决
        return reject('out_of_anchor', theta_tgt)
    if gap.estimate(theta_tgt) + gap.eps_n > budgets.eps_a:
        return reject('reality_gap', gap.estimate(theta_tgt))
    if aff.interference[t_tgt] < -budgets.delta_I:        # 负迁移
        return reject('negative_transfer', aff.interference[t_tgt])
    return ok(J2(J, gap, anchors, aff, gamma_rt=J.gamma_ce))
```

### IP-126 ACDR（Anchor-Constrained Domain Randomization）

```python
def anchor_constrained_dr(anchor, theta_deploy, B_real):
    # 在“必须覆盖锚点 + 现实样本预算有限”下最大化部署域覆盖率
    p_DR = init_uniform(theta_deploy)
    for _ in range(max_iter):
        p_DR = reweight(p_DR, target=anchor, budget=B_real)
        if anchor_coverage(support(p_DR), theta_deploy) >= cov_target:
            break
    return p_DR
```

### IP-127 NTT（Negative-Transfer Tripwire）

```python
def negative_transfer_tripwire(lib, tasks, window, delta_I):
    alerts = []
    for t in tasks:
        i_ewma = ewma(lib.interference_history[t], window)
        if i_ewma < -delta_I:
            # 先隔离任务头，再考虑回滚共享主干
            lib.isolate_head(t)
            alerts.append(('tripwire', t, i_ewma))
    return alerts
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| RGS | O(|Θ|·n_cal·rollout) | O(|Θ|) | 配对采样、保形半径有效 |
| ANC | O(|Θ|) | O(|Θ|) | 置信半径不低估 gap |
| MTA | O(|T|²·|B|·|φ|) | O(|T|²) | 梯度余弦充分探针 |
| GTC | O(|Θ|) | O(|Θ|) | 任务嵌入 Lipschitz 成立 |
| D2C | O(|S|·|A|+|T|²) | O(|A|+|T|²) | 四项条件联合 sound |
| ACDR | O(iter·|Θ|) | O(|Θ|) | 锚点覆盖约束不被预算破坏 |

**正确性定理（Two-Dimensional Transfer Soundness）**
假设第 54 轮 (A22)–(A28) 成立；**(A29)** 锚点内存在 i.i.d. 配对 real/sim 样本，保形半径满足 `P(sup|ĝ-g|≤ε_n)≥1-α`；**(A30)** 间隙对 θ 与任务嵌入满足 Lipschitz（定义 127）；**(A31)** 任务干扰量在监控窗口内平稳，NTT 响应延迟 ≤ τ_NTT；**(A32)** 目标 `θ_t` 的部署分布不逃逸 `Θ_deploy`。
则目标任务与现实条件下的部署成功概率：
```
P_success(t_t,θ_t) ≥ 1 - Σ_d(1-ρ(d|t_t)) - P(θ_t∉A_ε) - P(I(t_t)<-δ_I) - β_E - α
```
四类失败项分别对应：鲁棒性缺口、出锚点、负迁移、仿真证据误差。关键：**先在锚点内承诺，再在任务亲和预算内迁移，最后由 NTT 在线兜底**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 锚点集不具代表性、覆盖率高估 | 高 | 分层配对采样 + 保形校准 + 出锚点硬否决 |
| gap 估计器有偏（分布漂移） | 高 | 在线 conformal 更新 + 漂移检测触发重估 |
| 任务亲和度非平稳 | 高 | 滚动探针 + NTT 在线监控 + 任务头隔离 |
| 跨任务 gap 传递的 Lipschitz 常数难估 | 中 | 保守上界 + 仅在相似任务间传递 |
| 负迁移绊线误报导致震荡 | 中 | 迟滞窗口 + 隔离优先于全局回滚 |
| 二维证书组合后过度自信 | 高 | 四项条件取合取 + 最坏项主导预算 |

## 6. 本轮最大风险

**一句话**：二维迁移证书 `J²` 把“仿真可信”与“多任务共享”从隐含假设变成显式承诺，但其 soundness **三重依赖锚点集的代表性、gap 估计器的保形校准、以及任务亲和度的平稳性**；一旦部署漂移出锚点或任务相似度漂移，证书会从“保守拒答”退化为“过度自信放行”，把负迁移与未见场景包装成可部署——故必须以 **锚点覆盖率下限 + conformal 间隙半径 + 在线负迁移绊线** 三重护栏兜底，宁可因出锚点而拒答，绝不把二维流形上的“局部可信”外推成全局保证。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（RGS×ANC×MTA×GTC×D2C×ACDR×NTT）

> 承接第 54 轮产物 v31。本轮在动作-鲁棒性双证书 `J` 之上，增加 **虚实间隙谱化、锚点域声明、多任务亲和/负迁移、二维迁移证书** 四类算子：
> - **RGS（Reality Gap Spectrum）**：把 reality gap 从标量升级为随场景参数 θ 变化的可测谱 `𝔤`；
> - **ANC（Anchor Set Construction）**：构建仿真可信锚点集 `A_ε` 与覆盖率 `cov_A`，出锚点硬否决；
> - **MTA（Multi-Task Affinity）**：任务条件化 `α_S(a|t)`、`ρ(d|t)`，并度量亲和度与负迁移；
> - **GTC（Gap Transfer Certificate）**：跨任务的间隙传递上界，用相似任务省现实样本；
> - **D2C（Two-Dimensional Certificate）**：任务轴 × 虚实轴联合证书 `J²`；
> - **ACDR（Anchor-Constrained Domain Randomization）**：锚点覆盖约束下的域随机化；
> - **NTT（Negative-Transfer Tripwire）**：在线负迁移绊线与任务头隔离。
>

def task_affinity(lib, tasks, phi, probe_batches, delta_I):
    A = {}
    for ti, tj in combinations(tasks, 2):
        cos = mean(cosine(grad_loss(phi, ti, b), grad_loss(phi, tj, b))

### IP-125 D2C

```python
def two_dim_certificate(skill_seq, t_tgt, theta_tgt, J, gap, anchors, aff,
                        budgets):
    rho = compose_rho_cond(skill_seq, t_tgt, J.K)        # ρ(d|t_tgt)
    if min(rho.values()) < budgets.rho_min:
        return reject('robustness', rho)
    if theta_tgt not in anchors:                          # 出锚点，直接否决
        return reject('out_of_anchor', theta_tgt)
    if gap.estimate(theta_tgt) + gap.eps_n > budgets.eps_a:
        return reject('reality_gap', gap.estimate(theta_tgt))
    if aff.interference[t_tgt] < -budgets.delta_I:        # 负迁移
        return reject('negative_transfer', aff.interference[t_tgt])
    return ok(J2(J, gap, anchors, aff, gamma_rt=J.gamma_ce))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| RGS | O(|Θ|·n_cal·rollout) | O(|Θ|) | 保形半径覆盖 gap，误差 ≤ ε_n |
| ANC | O(|Θ|) | O(|Θ|) | 锚点内承诺、出锚点硬否决 |
| MTA | O(|T|²·|B|·|φ|) | O(|T|²) | 梯度余弦探针充分，干扰可观测 |
| GTC | O(|Θ|) | O(|Θ|) | 任务嵌入 Lipschitz，传递上界 sound |
| D2C | O(|S|·|A|+|T|²) | O(|A|+|T|²) | 四项条件合取，最坏项主导 |
| ACDR | O(iter·|Θ|) | O(|Θ|) | 覆盖约束不被预算破坏 |

**正确性定理（Two-Dimensional Transfer Soundness）**
假设第 54 轮 (A22)–(A28) 成立；**(A29)** 锚点内 i.i.d. 配对样本使 `P(sup|ĝ-g|≤ε_n)≥1-α`；**(A30)** 间隙对 θ 与任务嵌入 Lipschitz；**(A31)** 干扰量窗口内平稳、NTT 延迟 ≤ τ_NTT；**(A32)** 部署条件不逃逸 `Θ_deploy`。则：
```
P_success(t_t,θ_t) ≥ 1 - Σ_d(1-ρ(d|t_t)) - P(θ_t∉A_ε) - P(I(t_t)<-δ_I) - β_E - α
```
关键：**先在锚点内承诺，再在任务亲和预算内迁移，最后由 NTT 在线兜底**；四项条件取合取，任一项越界即拒绝部署。

## 6. 本轮最大风险

**一句话**：二维迁移证书 `J²` 把“仿真可信”与“多任务共享”从隐含假设变成显式承诺，但其 soundness **三重依赖锚点集的代表性、gap 估计器的保形校准、以及任务亲和度的平稳性**；一旦部署漂移出锚点或任务相似度漂移，证书会从“保守拒答”退化为“过度自信放行”，把负迁移与未见场景包装成可部署——故必须以 **锚点覆盖率下限 + conformal 间隙半径 + 在线负迁移绊线** 三重护栏兜底，宁可因出锚点而拒答，绝不把二维流形上的“局部可信”外推成全局保证。
