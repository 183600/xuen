# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互的不确定性二分闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「最小可行产品」×「地形适应」）

> R69 交付了一个会「问」的系统：把不确定性拆成 aleatoric / epistemic，用流匹配保留多模态，用注视/探针/问句去消解。但它仍默认两件从未被检验的事：
>
> 1. **能力栈只会增长。** R66→R69 每一轮都往闭环里加模块——MTM、COF、EFS、ACH、C-RAS-WM、VISTA、PI-SIGMA、MINT、CIA、FMA……却从不问：**此刻真的需要全部吗？** 每个模块都是能力，也都是延迟、能耗、攻击面和一个需要独立证据的失败模式。一个背着 12 个模块、却无法同时验证它们的系统，未必比只背 4 个被彻底验证模块的系统更可信。
> 2. **证书是「地形无关」的。** J_FLUID 证明「这个动作在标定过的世界里安全」，却从不声明「在哪种地面上」。同一张证书在混凝土上成立，在冰面上可能是一条通往摔倒的许可证。R69 自陈的最大风险（模态分布不可信 → 自信地问错）在真实世界的第一诱因，恰恰是**地形误判**：冰面看起来像混凝土。
>
> 本轮两个灵感正好切开这两个盲点：
> - **最小可行产品（MVP）** 教我们把「要上线多少能力」当作一个可决策、可验证、可偿还的变量：用最小可行 *实验* 去验证最大风险假设；先发一个能学的最小版本，再沿证书化路径增长；为省时间而砍掉的验证不是免费的，它是**会生息的技术债**。
> - **地形适应** 教我们：地形是那个决定「哪些能力此刻有效、哪张证书此刻有效」的**隐变量**；它非平稳、空间异质、只能靠接触探知，而探知本身有风险。
>
> 核心命题：**把「能力范围」提升为一等公民。任一时刻只部署「在当前地形后验下已认证且仍胜任」的最小可行子集 MVS；只在「能改变决策」时执行最便宜的最小可行实验 MVE；为省事留下的每个未验证假设都记入会生息的证书债务账本 CDL，超额即自动收窄包络；地形漂移经 pivot/persevere 门在「保持—换步态—升级子集—卸载—退回安全种子」间切换；而安全核永远不可被最小化。** 命名 **MOSS-RAS**（Minimum viable Operational SubSet with terrain-Scoped certification）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**此刻最小的、仍然可信的我能做什么——以及为了更小，我欠了哪些还没还的验证**」——MVP 在安全系统里不是「少做点」，而是「少留未验证的假设」。

## 0. 直觉与动机

**灵感 1（MVP → 最小可行的是「未验证面」，不是「能力」）**
直觉：精益创业里的 MVP 不是「功能最少的版本」，而是「用最少努力换取最多**经证实的认知**的实验」。多数团队把它误读成「先砍功能再说」，于是背上技术债。安全关键具身系统的正确翻法不是「少装模块」，而是**最小化未经验证的假设面**：能上线的最小集合，必须是「在当前地形包络内被完整认证」的集合；砍掉一个模块可以，但砍掉它的**验证**不可以。因此本轮把 MVP 的两个真内核提升为运行时机制：(a) 只做**能改变决策**的实验（否则是虚荣指标）；(b) 砍掉的验证要记成**债务**并付息（否则是自欺）。

**灵感 2（地形适应 → 地形是证书的隐变量）**
直觉：腿式/轮式机器人在碎石、沙地、冰面、泥地、楼梯上会切换步态、刚度、步长、落脚点——不是因为「策略变了」，而是因为**同一个策略在不同地形上的有效域不同**。R69 的证书缺的正是这个维度：它验证了行为，却没验证「行为所在的地面」。地形只能靠本体感受（打滑、下陷、力矩）和外部感知（视觉、LiDAR）联合估计，而两者都可能骗人：视觉说「平」，脚说「滑」。于是「在哪种地形上可以信哪张证书」本身是一个必须在线的、带不确定性的后验问题。

**灵感 3（两条灵感的乘积 → 能力范围 = 地形包络的函数）**
直觉：把「部署哪些模块」写成地形后验的函数 `S*(b_t)`。地形越明确、越接近已验证包络，就能用越小越便宜的已认证子集；地形越陌生，要么升级到更保守/更强冗余的子集，要么退回**共同安全种子**。这既回应了 R66–R69 的「模块只增不减」惯性，也把「保守」从一个标量 λ 变成一个**结构化的包络**：不是所有东西一起慢，而是**只保留被认证的那部分，其余显式地不部署**。

**灵感 4（MVP 的双刃 → 证书债务必须生息）**
直觉：MVP 最危险的滥用是「先欠着」。所以本轮不复用「债务」作为修辞，而把它做成可计算对象：每个未验证假设 `a` 有本金 `d_a`、利率 `γ_a`、上限 `D_max`。债务总额越界时，系统**没有自由裁量权**，只能按预设规则收窄包络（降子集/降速/退回种子）。这把「拖延验证」变成一个会自动触发保守化的负反馈，而不是可以无限滚动的信用卡。

**灵感 5（pivot/persevere → 承诺的结构化版本）**
直觉：地形会突变（从草地踏上冰面、从硬地陷入泥沼）。这时既不该固执沿用旧步态（persevere 到摔倒），也不该一有噪声就频繁换（振荡、抖动）。MVP 的「pivot or persevere」正好对应一个带**迟滞 + 驻留时间 + 共同安全种子**的门：只有变化点证据足够强才切换，且任何两个 regime 之间都必须经过同一个已认证的安全种子轨迹，从而保证切换瞬间控制连续、无突变。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（MOSS-RAS 总览与五不变式）** MOSS-RAS = (CTE, MVS, MVE, CDL, PPG, TGA, SCC, RAS-WM‡)。五不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **地形包络封闭**：任何被派发的指令必须属于「当前证书声明的地形包络 × 能力子集」；
(iii) **安全核不可砍**：安全关键模块集 `K_safe ⊆ M` 在任何子集中必须闭合（closure）；
(iv) **债务有息且触发保守**：未验证假设计息，越界即确定性收窄，无自由裁量；
(v) **共同安全种子**：任意 regime 切换必须经过同一个已认证的安全种子轨迹，且驻留时间 ≥ T_d。

**定义 311（地形隐状态与后验 CTE）** 地形状态 `τ = (c, φ) ∈ 𝒯 = 𝒯_disc × 𝒯_cont`：c 为地形类别（混凝土/碎石/沙/冰/泥/草/楼梯），φ 为连续参数（摩擦 μ、坡度、粗糙度、可变形深度）。τ 不可直接观测，观测 `y_t = (y_prop, y_extero)`。后验 `b_t(τ) = P(τ | y_{1:t}, a_{1:t-1})`，按非平稳切换核演化并允许变化点；注意 `a` 同时影响观测与地形本身（**交互混杂**）：踩下去会改变泥面，也会改变你下一步看到的泥面。

**定义 312（能力组合与地形条件胜任度）** 模块集 `M`，模块 `i` 有成本 `k_i`（时延/能耗/风险）、安全关键标志 `κ_i`。子集 `S ⊆ M` 的地形条件胜任度 `C_S(τ)`、风险 `R_S(τ)`、成本 `K(S)=Σ_{i∈S} k_i + κ_couple(S)`（耦合成本，如延迟叠加）。`C_S` 对 S **不必单调**：更多模块可能因资源争用/交互复杂度降低胜任度；只有「共同认证的包含关系」才保证安全单调（定义 323）。

**定义 313（证书有效域与证书-地形矩阵）** 模块 i 的证书在 `V_i ⊆ 𝒯` 上有效；子集 S 的联合有效域 `V_S = ⋂_{i∈S} V_i ∩ V_couple(S)`（耦合交互也需认证）。证书-地形矩阵 `A_{i,c} ∈ {0,1}` 离线标定、在线查表；`V_S` 为空即 S 对该地形不可部署。

**定义 314（最小可行子集 MVS）** 给定地形后验 b_t：
`S*(b_t) = argmin_{S⊆M} [K(S) + ρ·E_{τ~b_t} R_S(τ)]`
`s.t. E_{τ~b_t} C_S(τ) ≥ c_min`，`P_{τ~b_t}(τ ∈ V_S) ≥ 1−δ_env`，且 `K_safe ⊆ S`。
这是一个带安全闭合约束的次模背包问题；在线用「按边际 `ΔC/ΔK` 贪心 + 闭合修补」，离线按地形格预计算查表（债务改变时重算）。

**定义 315（最小可行实验 MVE 与决策相关信息）** 候选探针 `π ∈ Π`（轻踏、低速试步、侧向蹭、注视/近距视觉）。MVE 定义为**能改变子集决策的最便宜探针**：
`π* = argmin_{π} E[K(π) + R(π)]  s.t. P(S*(b_{t+1}) ≠ S*(b_t) | π) ≥ 1−ε_dec`。
若不存在满足约束的 π，则不探（「不能改变答案的问题不要问」）。在多个可翻转决策的探针中，优先翻转**风险最高假设**（riskiest-assumption-first），即最小化最坏情形决策风险。

**定义 316（证书债务账本 CDL）** 债务项 `a = (type, d_a, γ_a, t_a, scope)`：未验证假设（如「此处 μ≥0.6」「深度<2cm」「模块 i 未漂移」）在 `t_a` 以本金 `d_a` 记入，按 `d_a(t)=d_a·e^{γ_a(t−t_a)}` 生息。总债务 `D(t)=Σ_a d_a(t)`。债务可由 MVE 或新证据「偿还」（移除/降额），也可因包络外推而新增。`D(t) ≤ D_max` 是证书有效的必要条件。

**定义 317（债务触发的自动收窄 margin call）** 当 `D(t) > D_max`：按离线固定的降级序列 `G = (g_1 ≻ g_2 ≻ … ≻ g_k)`（降速 → 降子集 → 换保守步态 → 退回共同安全种子）**确定性地**执行第一项仍可认证的降级，直到债务回到上限内。该规则不看「当前是否看起来还好」，避免乐观裁量。

**定义 318（Pivot/Persevere 门 PPG）** 由本体/胜任度残差驱动的变化点检测（CUSUM/BOCPD）给出地形突变证据 `Λ_t`。决策集 `{persevere, adapt_regime, escalate_S, shed_S, retreat_seed}`；仅当 `Λ_t > τ_pp^↑` 且驻留时间 `≥ T_d` 才允许切换，`Λ_t < τ_pp^↓` 才允许回切（`τ_pp^↑ > τ_pp^↓` 为迟滞）；`retreat_seed` 无条件优先。

**定义 319（地形条件机制/步态参数 TGA）** 机制参数 `θ_g ∈ Θ`（步长、步频、关节刚度、躯干高度、支撑时序、落脚点策略）。给定 (S, b_t) 选 `θ_g* = argmax E_{τ~b_t}[C_S(τ; θ_g) − ρ R_S(τ; θ_g)]`，受 `V_S` 与执行器包络约束。

**定义 320（带域携带证书 SCC / J_MOSS）** `J_MOSS = (J_FLUID†, b_t 包络声明, S*, c_lb, debt_ledger, θ_g*, birth/expiry, seed_id, moss_ver)`。Valid ⇔ 子集联合有效域覆盖包络 ∧ `E C_S ≥ c_min` ∧ `D ≤ D_max` ∧ `K_safe ⊆ S` ∧ 共同安全种子可达 ∧ R69 证书 Valid。

**定义 321（胜任度校准门 CCG）** 胜任度图 `C_S(τ)` 须校准：预测成功率与实测成功率的分层 ECE ≤ τ_ece，且 OOD 地形上给出**保守下界** `c_lb`。`ECE > τ_ece` ⇒ 禁用「卸载」与「收窄」，退回当前已认证的全量安全子集（R69 MCG 的结构化版本）。

**定义 322（抗膨胀租金检验 Rent Test）** 模块 i 在当前包络上的**边际已证实胜任度** `ΔC_i^val` 必须覆盖其边际成本与边际风险：`ΔC_i^val ≥ λ_k·ΔK_i + λ_r·ΔR_i`。不满足、且 `i ∉ K_safe`、且移除后不破坏已认证冗余 ⇒ 可卸载。反之，新增模块必须携带「在地形包络上的新证据」，而不是「实验室里能跑」。这把 R66–R69 的「每轮加一层」惯性改为「每层都要付租金」。

**定义 323（安全单调性：只在共同认证的包含下单调）** 若 `S ⊆ S'` 且两者都在同一地形包络上被**联合认证**（`V_S ⊇ V_S'` 非空且耦合认证通过），则 `R_{S'} ≤ R_S`。**否则不得假设「多加模块更安全」**——未共同认证的模块组合可能在交互层引入新失败模式（安全集非凸的 MOSS 版）。

**定义 324（与 R69 的接口：MVE ⊇ MINT）** 当 𝒯 退化为单点（地形已知固定）、债务为零、`S*=M`、无变化点时，MVE 退化为 R69 的 MINT（探针只用于消解动作模态），PPG 退化为恒 persevere，MOSS-RAS 逐指令等于 FLUID-RAS。MINT 是本轮在「地形维退化」边界上的特例。

**定义 325（地形欺骗威胁模型 ℰ_terrain）** 视觉伪装（冰面撒沙）、地图陈旧、自身动作诱发的地形改变（踩塌）、对抗性地形布置（可承重表象/陷阱）、跨通道共谋（视觉+声音都像硬地）。并入 `ℰ_MOSS = ℰ_FLUID × ℰ_terrain`；地形证据同样受 R69 的「k 个正交源一致」纪律约束，单通道地形判定不得定案。

**定义 326（参与式审计 VQAuditor-M）** 审计新决策：卸载是否通过租金检验、债务是否被非法滚动、MVE 是否真的可能改变决策、包络声明是否被事后放宽、安全核是否被绕过。结论回灌 AuditBuf，作为下一轮租金与利率的先验；J_MOSS 附审计哈希。

# IP-264 CTE：地形后验（本体+外感融合 + 变化点检测）
class TerrainEstimator:
    def __init__(self, fuse, bcpd):
        self.fuse, self.bcpd = fuse, bcpd
    def update(self, y_prop, y_extero, a_prev):
        y = self.fuse(y_prop, y_extero, a_prev)          # 解耦自身动作造成的地形改变
        b, lam = self.bcpd.step(y)                       # 后验 + 变化点证据
        return b, lam

# IP-265 MVS：最小可行子集（闭合约束次模背包，离线查表）
def select_subset(b, table, K_safe):
    key = terrain_cell(b.argmax())
    S   = table[key] if b.confidence > TAU_ENV else safe_seed()
    S   = closure_repair(S, K_safe)                     # 安全核闭合，永不砍
    return S if cert_covers(S, b) else safe_seed()

# IP-266 MVE：只做能改变决策的实验（决策相关信息，而非虚荣指标）
def minimum_viable_experiment(b, S, probes, budget):
    best = None
    for pi in probes:
        if not budget.allow(pi): continue
        if P_subset_flip(pi, b, S) < 1 - EPS_DEC: continue   # 改不了答案 → 不问
        cost = expected_cost(pi) + expected_risk(pi)
        key  = worst_case_decision_risk(pi)                  # 优先翻转最高风险假设
        if best is None or (key, cost) < (best.key, best.cost):
            best = (pi, cost, key)
    return best.pi if best else None

# IP-267 CDL：证书债务（生息 + 越界自动收窄）
def ledger_step(ledger, evidence, dt):
    ledger.accrue(dt)                                    # d_a *= exp(gamma_a * dt)
    for a in evidence.paid: ledger.pay(a)                # 证据偿还
    for a in evidence.new:  ledger.open(a)               # 包络外推新增
    return ledger

def margin_call(ledger, cert, degrade_seq):              # 无自由裁量
    while ledger.total() > ledger.D_max:
        g = next((g for g in degrade_seq if cert.can_apply(g)), None)
        if g is None: return safe_seed()                 # 无可用降级 → 退回种子
        cert = cert.apply(g)
    return cert

# IP-268 PPG：pivot/persevere（迟滞 + 驻留 + 共同安全种子）
def pivot_persevere(lam_t, t, last_switch, cert, b):
    if lam_t > TAU_PP_UP and t - last_switch >= T_D:
        return choose_regime_action(b, cert), t          # adapt/escalate/shed/retreat
    if lam_t < TAU_PP_DOWN:
        return "persevere", last_switch
    return "persevere", last_switch                      # 迟滞区：不动

# IP-275 主闭环（继承 R69，只在「能力范围/包络」处插入 MOSS 层）

    if g is not None: b = bayes_update(b, M.mve.execute(g))
    # 3) R69 层：ale/epi 二分 + 交互消歧（限定在当前子集 S 的认证范围内）
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, K(M, z)), z)
    ...
    # 4) 债务/包络：先记账，再 setup 证书；越界则确定性收窄
    M.cdl = ledger_step(M.cdl, M.evidence(o), M.dt)
    cert  = M.scc.issue(S, b, M.cdl, M.tga.select(b, S))

    if action == "retreat_seed": return seed_round(M, obs)
    # 6) R69 风险缩放，只在 S 内认证的指令上派发
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi_unresolved))
    k   = M.c_ras_wm.certified_prefix(A := M.ach.propose(...), ..., wm_preds)
    tau = M.pi_sigma.prefix_dispatch(modes[0].a[:k]) * lam
    # 7) 参与式审计 + 带域证书
    M.vqa_m.submit_async(S, g, cert, M.cdl, action)
    return k, lam, action, (S, cert)
```

## 3. 推导

**引理 19（边际递减下 MVS 的贪心保证）** 在 A99（`C_S` 边际增益随 S 增大不增；耦合成本次可加）下，MVS 的「先取 `K_safe`、再按 `ΔC/ΔK` 贪心、最后闭合修补」对预算约束下的胜任度最大化达到 ≥ `(1−1/e)` 的最优比；闭合修补至多加 `|K_safe|` 个模块。**注意反面**：若模块间存在强互补（`1+1>2`），次模性失效，贪心可任意差——所以定义 322 的租金检验要求「互补性必须有包络上的实测证据」，否则按冗余风险处理。系：**模块数量本身不是能力，边际已证实胜任度才是。**

**引理 20（债务暴露上界）** 设债务本金 `d_0`、利率 `γ>0`、上限 `D_max`，则任何未验证假设最多被依赖 `t_max = (1/γ)·ln(D_max/d_0)` 时间，之后 margin call 必迫使其降级或验证；故「陈旧假设暴露时长」有界，且**与操作者的乐观程度无关**。系：`γ→0` 正是旧的「债务可无限滚动」失败模式；`γ>0` 把 MVP 从借口变成截止日期。

**引理 21（决策相关探针的支配性）** 设探针 π 改变子集决策的概率为 `p`，决策风险差为 `Δ_risk`。在 A100（`Δ_risk ≤ Δ_max` 且 `cost(π) > ε_dec·Δ_max`）下，若 `p < ε_dec`，则 π 的期望收益 `≤ p·Δ_risk < cost(π)`，被「不探」严格支配。且当多个探针都能翻转决策时，按最坏情形决策风险排序是单步决策树问题的 minimax 最优。系：**「只问能改变答案的问题」不是产品口号，而是最优性条件**；R69 的纯 VoI 最大化会浪费探针去问「答案不改变模态选择」的问题（虚荣指标版）。

**引理 22（抗膨胀的严格支配）** 若模块 `i ∉ K_safe`、不为已认证冗余所必需、且不通过租金检验（定义 322），则从 S 中移除 i 不降低包络上的风险调整后已认证胜任度。系：**全量栈只有在每个模块都付得起租金时才被证成**；这直接反转 R66–R69 的「默认加一层」，使模块数量本身成为证据问题。

**定理 18（MOSS 严格包含 FLUID）** 在 A99–A101 下：
(i) 退化条件（𝒯 单点、b 为点质量、债务为 0、`S*=M`、无变化点）下，MOSS 与 FLUID **逐指令相同**（定义 324）；
(ii) 一般情形下，MOSS 派发的任何动作都落在一个「地形包络以概率 ≥ 1−δ_env 覆盖当前真实地形」的带域证书内，而 J_FLUID 不含地形域，对训练分布外的地形可能授权未认证动作；故同一地形上的最坏情形风险 `Risk_MOSS ≤ Risk_FLUID`；
(iii) 当 FLUID 的地形上确实有效且全量栈通过租金检验时，MOSS 取 `S=M`，二者行为一致。
因此 R69 是 MOSS 在「地形维退化 + 零债务」边界上的严格退化；安全侧不做任何让步，效率侧获得「卸载不付租金模块」的收益。

**定理 19（切换无突变与有界 chatter）** 在 A102（任意两认证 regime 间存在共享的已认证安全种子轨迹）下，PPG 的每次切换都经过该种子：(i) 切换瞬间控制连续、无突变；(ii) 任一有限时间 `[0,T]` 内切换次数 `≤ T/(T_d + τ_seed) + 1`；(iii) 误切换概率随 `τ_pp^↑` 与 `T_d` 单调下降。故「pivot/persevere」不会引入抖动或跳变，且与 R68 定理 15 / R69 定理 17 的换装不变式相容。

## 6. 本轮最大风险

**一句话**：MOSS-RAS 的全部收益押在「地形后验 `b_t` 与胜任度图 `C_S(τ)` 是校准的」这一前提上——**若地形被表象欺骗（冰面看起来像混凝土）、或胜任度在 OOD 地形上系统性高估，最小可行子集会自信地砍掉真正需要的模块，把「最小的已认证系统」变成「最小的自欺系统」；更糟的是，证书债务会被用来合法化这种砍伐，MVP 于是从「少即是多」退化为「省掉的就是安全」——砍错，比不砍更危险。**

**次级风险与缓解**：
1. **地形误判/欺骗**（定义 325）→ 本体接触证据优先 + k 个正交源一致 + ℰ_terrain 对抗训练 + E308/E311；
2. **胜任度高估**（OOD 自信）→ CCG 校准门，ECE 越界即禁止卸载/收窄、退回全量认证子集（定义 321）；
3. **债务被无限滚动**→ 生息 + 确定性 margin call，禁止裁量（引理 20、定义 317）；
4. **安全核被「最小化」**→ `K_safe` 闭合不可砍 + 红队 E309/E316 + 审计；
5. **切换抖动/突变**→ 迟滞 + 驻留 + 共同安全种子（定理 19）；
6. **模块互补性使次模假设失效**→ 租金检验要求实测互补证据，否则按冗余风险保守处理（引理 19、定义 322）。

**定义 318–319（PPG / TGA）** 变化点 `Λ_t` 驱动 `{persevere, adapt_regime, escalate_S, shed_S, retreat_seed}`，迟滞 `τ_pp^↑>τ_pp^↓`；步态 `θ_g` 按地形后验选，受 `V_S` 与执行器包络约束。

def ledger_step(ledger, evidence, dt):
    ledger.accrue(dt)
    for a in evidence.paid: ledger.pay(a)
    for a in evidence.new:  ledger.open(a)

def pivot_persevere(lam_t, t, last_switch, cert, b):
    if lam_t > TAU_PP_UP and t - last_switch >= T_D:
        return choose_regime_action(b, cert), t
    return "persevere", last_switch               # 迟滞区/未驻留：不动

# IP-275 主闭环（继承 R69）
def MOSS_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    b, lam_t = M.cte.update(obs.prop, obs.extero, M.last_action)
    S = M.mvs.select_subset(b, M.table, M.K_safe)
    g = M.mve.minimum_viable_experiment(b, S, M.probes, M.budget) if uncertain(b) else None
    if g is not None: b = bayes_update(b, M.mve.execute(g))
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, K(M, z)), z)   # R69
    M.cdl = ledger_step(M.cdl, M.evidence(o), M.dt)
    cert  = M.scc.issue(S, b, M.cdl, M.tga.select(b, S))
    if M.cdl.over(): cert, S = margin_call(M.cdl, cert, M.degrade_seq)
    action, M.last_switch = pivot_persevere(lam_t, M.t, M.last_switch, cert, b)
    if action == "retreat_seed": return seed_round(M, obs)
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi_unresolved))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    tau = M.pi_sigma.prefix_dispatch(modes[0].a[:k]) * lam
    M.vqa_m.submit_async(S, g, cert, M.cdl, action)
    return k, lam, action, (S, cert)
```

## 4. 推导

**引理 19（MVS 贪心保证与反例）** A99（胜任度边际递减、耦合成本次可加）下，先取安全核再按 `ΔC/ΔK` 贪心并闭合修补，对预算约束的胜任度最大化达 `≥(1−1/e)` 最优比，修补至多 `|K_safe|` 个模块。若存在强互补（次模失效），贪心可任意差——故租金检验要求互补性有包络实测证据，否则按冗余风险保守处理。系：模块数量不是能力，边际已证实胜任度才是。

**引理 20（债务暴露上界）** 本金 `d_0`、利率 `γ>0`、上限 `D_max` ⇒ 未验证假设最多被依赖 `t_max=(1/γ)ln(D_max/d_0)`，之后必降级或验证；暴露时长有界且与操作者乐观程度无关。`γ→0` 即旧的「债务无限滚动」失败模式。

**引理 21（决策相关探针的支配性）** A100（`Δ_risk≤Δ_max`、`cost(π)>ε_dec·Δ_max`）下，若翻转概率 `p<ε_dec`，则探针期望收益 `< cost(π)`，被「不探」严格支配；多探针时按最坏情形决策风险排序为单步 minimax 最优。系：「只问能改变答案的问题」是最优性条件；R69 纯 VoI 会浪费探针在答案不改变模态选择的问题上。

**引理 22（抗膨胀严格支配）** 若 `i∉K_safe`、非已认证冗余所必需、且不通过租金检验，则移除 i 不降低包络上风险调整后的已认证胜任度。系：全量栈只有每个模块都付租金才被证成，模块数量从此是证据问题。

**定理 18（MOSS 严格包含 FLUID）** A99–A101 下：(i) 退化条件（𝒯 单点、b 点质量、零债务、`S*=M`、无变化点）逐指令相同；(ii) 一般情形 MOSS 的动作总落在「包络以 ≥1−δ_env 概率覆盖真实地形」的带域证书内，而 J_FLUID 无地形域、对分布外地形的授权可能是未认证的，故 `Risk_MOSS ≤ Risk_FLUID`；(iii) 当 FLUID 地形有效且全量栈付得起租金时取 `S=M`，行为一致。R69 是 MOSS 的地形维退化边界，安全不让步，效率得卸载收益。

**定理 19（切换无突变与有界 chatter）** A102（任何两认证 regime 共享已认证安全种子）下，PPG 每次切换经过种子 ⇒ 控制连续、无突变；有限时间 `[0,T]` 切换次数 `≤T/(T_d+τ_seed)+1`；误切换概率随 `τ_pp^↑、T_d` 单调下降。与 R68 定理 15 / R69 定理 17 的换装不变式相容。

## 7. 本轮最大风险

**一句话**：MOSS-RAS 的全部收益押在「地形后验 `b_t` 与胜任度图 `C_S(τ)` 是校准的」这一前提上——**若地形被表象欺骗（冰面看起来像混凝土）、或胜任度在 OOD 地形上系统性高估，最小可行子集会自信地砍掉真正需要的模块，把「最小的已认证系统」变成「最小的自欺系统」；更糟的是，证书债务会被用来合法化这种砍伐，MVP 于是从「少即是多」退化为「省掉的就是安全」——砍错，比不砍更危险。**

**次级风险与缓解**：地形误判/欺骗（本体接触优先 + k 源一致 + ℰ_terrain 对抗 + E308/E311）；胜任度高估（CCG 校准门，越界退回全量认证子集）；债务无限滚动（生息 + 确定性 margin call）；安全核被最小化（`K_safe` 闭合 + 红队 E309/E316）；切换抖动（迟滞 + 驻留 + 共同安全种子）；互补性使次模失效（租金检验要求实测互补证据）。
