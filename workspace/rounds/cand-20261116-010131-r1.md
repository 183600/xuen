# 第 12 轮（新灵感循环第 1 轮；本轮灵感：「通用操作」×「碰撞避免」）
> **基线**：第 11 轮 MetricVoiceGauge-GSCF-SRA-JSSE（定义 549–561；引理 92–96；实验 E591–E610）。
> 本轮纪律：**组合即举证 + 接触即契约**。两个灵感各自治理 v11 的一笔债：**组合/泛化债**（v11 的证书是"单技能、单块"的，却把通才策略的跨任务泛化当成可信输入；从未证明"两个各自认证的技能拼起来仍安全"，而技能边界恰是证书最易失效处）、**接触/几何债**（v11 把一切接触当碰撞，但通用操作的本质是**有意图的接触**——抓、推、拧、交接、工具使用；同时只在离散步查余量，无连续时间扫掠证书、无动态障碍的不可避免碰撞状态）。必须保持 v11 铁律：任一新模块失效 ⇒ 声明中立元，行为严格**等价**（SCC）或**支配**（CAT/HSG）于 v11；更强：**Exec(组合计划) ⊆ v11 可行集**，且每段执行的安全性不依赖通才模型的自评置信度。

## 0. 直觉与动机

**灵感 1（通用操作 → 泛化是证书的属性，不是模型的属性）**
直觉：通用操作之所以"通用"，是因为它把许多技能**组合**起来应付新任务；v11 却把"通才能做"当成"通才可信"。组合不会免费获得安全性：前/后置条件可能对不上，不变式在技能切换处失守，误差随组合深度累积（组合税 β_comp），两个技能争用同一物体/同一工作空间时各自都安全、拼起来却撞车。核心创新：**技能契约演算（Skill Contract Calculus, SCC）**——把技能写成带类型接口的契约 s=(pre,post,inv,π,β,M,κ,Supp)，并给出 seq/par/handoff 三种**组合算子**与证书代数；关键纪律是**支撑门控的泛化**：通才（VLA/任务规划器）可以**提议**任意任务图 G_T，但只有当整图能**分解**为认证支撑域内的已认证技能、且每条接口义务被满足时，证书才成立；支撑域外 ⇒ 要么继续分解，要么收缩（K_eff=1/Π_r），绝不"信任通才"。于是"通用"来自**可证明的组合**，而不是无界的模型自信。

**灵感 2（碰撞避免 → 从"处处避碰"到"接触语义"）**
直觉：在桌面操作里，碰撞避免的古典目标（离障碍越远越好）会**直接杀死任务**——不接触就抓不住、推不动、拧不开。真正要避的是**非意图接触**；意图接触必须被允许、但被**力度/冲量契约**约束。核心创新：**接触感知轨迹证书（Contact-Aware Trajectory, CAT）**——每个技能声明意图接触集 K_int 与禁触集 K_forbid，未声明接触**默认拒绝**（default-deny）；用**接触模式自动机** Σ_C 管住 approach→make-contact→maintain→release→retreat 的合法转移；用**保守推进的连续时间扫掠证书**排除穿透（tunneling）；对动态障碍给出**速度障碍 + 不可避免碰撞状态（ICS）空集**不变量。关键在于：避碰从"接触厌恶"升级为"接触有据"，既不让系统过度保守，也不给"任何东西都能碰"开口子。

**灵感 3（横切：技能边界独占 → 缝隙处的证书）**
直觉：两个各自可证的技能，在**交接**处最可能联合失效：双臂交接时"释放"与"抓取"重叠、换工具时接触状态错配、共享物体被两个技能同时认领。个体安全不蕴含联合安全，缺的不是更多余量，而是**义务**。核心创新：**交接安全监督器（Handoff Safety Governor, HSG）**——交接接口 I_h 显式声明共享物体、接触状态与力闭合条件；共享资源任一时刻至多一个 owner（边界独占）；交接要求两侧接触状态匹配、力闭合维持；不匹配 ⇒ **冻结/保持**（JSSE 接管），绝不"带病继续"。缝隙安全由义务保证，而非由置信度赌。

三者咬合：SCC 说**什么可以组合**，CAT 说**每一段运动在接触意义上安全**，HSG 说**接缝处安全**。总证书升级为 Ĉ⁺⁺⁺ = (Ĉ⁺⁺, C_comp, Ĉ_CAT, contact-mode, I_h, Supp-flag)。一句话：**通才提议，代数裁决**。

## 1. 研究问题（轮次升级版）

- **Q1（组合可证）**：如何用带类型技能的契约代数，使任意任务图的安全证书可由其子技能证书**归纳构造**，并把组合误差显式记为线性"组合税" β_comp（深度上限 D_max），从而在长程通用操作上做到**零非受控泛化**（E613/E628）？
- **Q2（接触可证）**：如何把"避碰"精确化为"无非意图接触 + 意图接触冲量受限 + 连续时间无穿透 + 动态障碍 ICS 空"，既保证 0 禁触事件，又把相对 v11 过度保守造成的接触密集任务成功率收回 ≥20%（E620）？
- **Q3（接缝与退化）**：技能边界/交接处如何用独占与接触匹配消除"个体安全、联合失效"，并在 SCC/CAT/HSG 失效时严格等价/支配于 v11，且把**契约指派错误 ε_contract** 作为唯一新增残余风险显式隔离（E626）？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 组合即举证律（Composition-as-Proof, SCC）**
任何执行计划必须由已认证技能按组合规则**归纳构造**；接口不匹配不得"尽力执行"；组合税必须支付（余量、深度、速度）；支撑域外必须分解或收缩。通才只拥有**提议权**，不拥有**认证权**。

**P17 接触语义律（Contact Semantics, CAT）**
未在契约中声明为意图的接触一律视为碰撞（**default-deny**）；意图接触必须携带力/冲量上界与合法接触模式；证书在**连续时间**上成立，离散采样只是加速、不构成证明；动态障碍必须给出 ICS 空集或中止。

**P18 边界独占律（Boundary Exclusivity, HSG）**
共享物体/共享工作空间任一时刻至多一个 owner；交接仅在接触状态与力闭合匹配时放行；不匹配即冻结；冻结行为 ⊆ v11 可行集（JSSE 保持的支配性）。

## 3. 与基线的接口（如何退化）

- **SCC 失效**（技能库/接口不可读、组合求解超时）⇒ 禁止组合，退回 v11 单技能单块证书，**等价 v11**；
- **CAT 失效**（无深度/接触模型损坏/CCD 超时）⇒ 回退 v11 的"处处避碰"距离证书（意图接触也按禁触处理）⇒ 严格更保守，**支配于 v11**（行为 ⊆ v11 可行集），任务成功率下降但安全；
- **HSG 失效**（接口不一致/锁损坏/监督超时）⇒ 技能边界一律冻结保持（JSSE 零速 + 重力补偿），**等价/支配 v11**；
- v11 九级退化链整体后移为 Level-4..12，语义不变；新增 Level-1..3 分别对应 SCC/CAT/HSG；
- 新增安全守卫 SCC/CAT/HSG 一律 φ^elig=false 永不消融；仅"支撑域/接触模型/接口画像维护"可蒸馏。

## 4. 预期贡献

1. **技能契约演算与组合税**：把"通用"从模型能力改写成可归纳证明的组合闭包，给出 β_comp 的加性界与深度上限（引理 97–98）；
2. **接触语义证书**：意图/禁触二分 + 默认拒绝 + 连续扫掠 + ICS，把避碰从"远离一切"升级为"接触有据"，消除离散 CCD 穿透与过度保守（引理 99）；
3. **接缝独占与交接监督**：以资源独占和接触状态匹配消除个体安全/联合失效，失败一律冻结（引理 100）；
4. **残余风险显式化**：唯一新增主风险是契约指派错误 ε_contract，用独立审计与对抗实验正面测量（引理 101，E626）；
5. **E611–E630** 覆盖契约标定、组合注入、支撑边界、长程/双臂/交接、扫掠 CCD、动态障碍、接触分类、退化链、预算与竞赛。

## 5. 本轮最大风险

**一句话**：整条链的可靠性最终压在**契约指派**上——"这段动作属于哪个技能、哪些接触是意图、哪个物体归谁"，而这份指派由通才/规划器生成；若它把禁触事件**洗白**成"意图接触"（例如把推人声明为推物、把未注册物体声明为可操作），则 SCC 的组合证明、CAT 的冲量界、HSG 的独占全部**相对错误规范真空成立**，而且这种错误恰在泛化/新颖场景最易发生，比 v11 的数值失准更隐蔽。

**新增定义 562（技能契约）** 技能 s 的契约是一个八元组 s=(pre_s, post_s, inv_s, π_s, β_s, M_s, κ_s, Supp_s)。pre/post 为状态集谓词；inv_s 为执行期间必须保持的不变式（含接触模式合法性）；π_s 为参数化策略（可为 VLA 技能原语或解析控制器）；β_s 为 v11 意义上已标定的证书余量；M_s⊆Resources 为资源足迹（占用物体、工作空间体积、工具、持物权）；κ_s 为接触契约（见定义 566）；Supp_s 为认证支撑域（见定义 563）。**契约是声明式数据**，与 MW 契约表同构。

**新增定义 563（认证支撑域）** Supp_s = {(x,τ) | 独立校准集上 sup‖F̂−F‖≤β_s 以概率 ≥1−ε_s，且任务 τ 处于 s 的训练/标定覆盖内}。在线隶属判定 ξ_s(x,τ) 由密度比、集成分歧（ensemble disagreement）、以及 v10/v11 的语义-几何创新度联合给出；ξ_s=out 时技能 s **不得直接使用**，只能被更细的 in-support 子图替换，或整体收缩。支撑域是"泛化"的边界，不是模型的自我声明。

**新增定义 564（任务图与组合算子）** 任务图 G_T=(V,E,ρ)，V 为技能实例，E⊆V×V×{seq,par,hand}，ρ 标注共享资源。组合合法性：
- **seq**：s1 ⊗_seq s2 合法 ⇔ post_1 ⊆ pre_2，且边界状态满足 inv_1→inv_2 的交接条件，且 κ_1→κ_2 的接触模式转移 ∈ δ_C（如 release→approach）；
- **par**：s1 ⊗_par s2 合法 ⇔ M_1∩M_2=∅，或共享资源由 HSG 托管（至多一个 owner）；且两体跨任务最小距离 ≥ d_safe；
- **hand**：见定义 571（交接接口）。

**新增定义 565（组合证书与组合税）** C_comp(G_T) = (iface_ok, β_comp, depth, supp_ok)。β_comp = Σ_{v∈V} β_v + Σ_{e∈E} β_e + β_interface·|E|；depth 为最长组合链；supp_ok = ∧_{v∈V} [ξ_v=in]。C_comp 有效 ⇔ iface_ok ∧ supp_ok ∧ depth ≤ D_max ∧ β_comp ≤ β_budget（否则降速/减块长/收缩）。**组合税定理的直觉**：组合带来通用性，但必须用余量、深度、速度三项预算支付；不支付就不得组合。

**新增定义 566（意图/禁触接触集，默认拒绝）** 对技能 s，K_int(s) ⊆ Bodies×Bodies×Σ_C 为契约显式声明的意图接触三元组（体对、接触模式、力/冲量上界）；K_forbid(s) = (Bodies×Bodies×Σ_C) \ K_int(s)。接触事件 e(t) 判为 intended ⇔ e(t)∈K_int(s) 且当前模式转移合法；**其余一律 forbidden**（含未注册物体、人、环境、未声明体对）。默认拒绝是安全默认值，不依赖分类器的"高置信"。

**新增定义 567（接触模式自动机）** Σ_C=(Q_C, q_0, δ_C, F_C)，Q_C={approach, make_contact, maintain, release, retreat, hold}。δ_C 由技能契约给出状态转移及守卫（距离/相对速度/力阈值）。执行中任一非法转移（如 maintain→maintain 却发生体对变化、release→approach 未达安全距离）⇒ Ĉ_CAT.mode_ok=false ⇒ 证书失效。

**新增定义 568（扫掠连续碰撞证书）** 沿块轨迹 τ:[0,T]→C，扫掠体积 SW(τ)=∪_{t∈[0,T]} SW(τ(t))。证书要求 ∀t∈[0,T]：dist(SW(τ(t)), O_forbid) ≥ d_safe + β_CAT，其中 O_forbid 为所有未声明为意图的体（人、未注册物、环境、其他机器人）。判定用**保守推进（conservative advancement）**在连续时间上证明；离散采样仅作加速，**不构成证明**（消除 tunneling）。

**新增定义 569（意图接触冲量与动态障碍 ICS）** 意图接触必须满足 ‖J_e‖ ≤ J_max(s)、‖f_e‖ ≤ f_max(s)，并维持力闭合 fc_ok；越界即降级为非意图（回到禁止集）。对动态障碍 o(t)，以速度障碍 VO_o 与刹车界 d_brk(v) 定义不可避免碰撞状态集 ICS = { x | 从 x 出发的任何许可制动轨迹在 horizon T_h 内与 o 相交 }。证书要求 ICS=∅；非空 ⇒ 中止（最近 p* ⇒ JSSE q_abort）或扩大 β_CAT 后重规划。

**新增定义 570（接触证书）** Ĉ_CAT=(ccd_ok, impulse_ok, ics_empty, β_CAT, mode_ok)。有效 ⇔ 五项全真。β_CAT 由 E617/E618 标定：正常场景无禁触且非穿透的余量。

**新增定义 571（交接接口）** 交接接口 I_h=(O_shared, q_contact, fc_ok, [t_lo,t_hi])：共享物体集、接触状态匹配点、力闭合条件、允许的时间窗。handoff s1→s2 合法 ⇔ (i) O_shared 的 owner 原子转移（先 s1 释放锁、后 s2 加锁，或原子 swap）；(ii) 两侧接触状态在 q_contact 上相等（位姿/速度/接触力在容差内）；(iii) fc_ok 在前一技能 release 前已建立、后一技能 maintain 后仍保持；(iv) 转移在 [t_lo,t_hi] 内完成，超窗即冻结。

**新增定义 572（交接安全监督器 HSG）** HSG 维护 owner 映射 own: O→V∪{⊥}，提供 lock(o)/unlock(o)/transfer(o,s1,s2)。任一时刻每个共享物体至多一个 owner（边界独占）。交接需双锁 + 状态匹配；不匹配 ⇒ freeze(q_current)：发送零速、位置保持 + 重力补偿力矩（JSSE 原语）。HSG **仅依赖本体感觉、编码器、力/力矩传感与契约**，不依赖视觉/语义感知，因而可在感知退化时独立兜底。

**新增定义 573（组合有效块长）** K_eff^comp(t) = min( K_eff^{v11}(t), ⌊D_remaining/ℓ_chunk⌋, K_budget(β_comp) )，其中 D_remaining 为当前技能剩余深度预算，K_budget 由 β_comp 与允许超调反解。任一分量为 0/1 ⇒ 单步（K=1）。组合不会放大块长，只会缩小。

**新增定义 574（总证书）** Ĉ⁺⁺⁺ = (Ĉ⁺⁺, C_comp, Ĉ_CAT, κ_active, I_h, Supp-flag)。有效 ⇔ v11 定义 552 条件 ∧ C_comp.valid ∧ Ĉ_CAT.valid ∧ 当前接触模式合法 ∧ 若在边界则 I_h 义务满足。δ_trigger 中「Ĉ⁺⁺ valid」升级为「Ĉ⁺⁺⁺ valid」。

**新增定义 575（台账扩展）** 哈希链 Λ（κ_h=256 不变）新增三类记录：composition record（H(G_T)、depth、β_comp、接口证据）、contact record（接触分类 intended/forbidden、冲量、模式）、handoff record（owner 转移、状态匹配证据）。台账缺口 ⇒ P13 收缩 + Λ 标记。

# IP-365 SkillContractCalculus：技能契约演算（5Hz 块生成期）
@dataclass
class SkillContract:
    sid: str
    pre: Callable[[State], bool]
    post: Callable[[State], bool]
    inv: Callable[[State], bool]
    policy: Policy
    beta: float
    footprint: frozenset          # 物体/工作空间/工具/持物权
    contact: ContactContract      # K_int, J_max, f_max, Sigma_C
    support: SupportRegion        # xi_s(x, tau)

class SkillContractCalculus:
    def __init__(self, skills, beta_interface=0.01, D_max=4, beta_budget=0.15):
        self.skills, self.beta_if = skills, beta_interface
        self.D_max, self.beta_budget = D_max, beta_budget

    def certify(self, G, x0, tau):
        order = self._topo(G)
        beta = 0.0
        for v in order:
            s = self.skills[v.sid]
            if not self.support.contains(s, x0, tau):     # 支撑门控
                return CompositionCert(False, float('inf'), 0, False,
                                       reason=f'out_of_support:{v.sid}')
            beta += s.beta
        for (u, v, kind) in G.edges:
            if kind == 'seq' and not self._seq_ok(u, v):
                return CompositionCert(False, float('inf'), 0, True, 'seq_iface')
            if kind == 'par' and not self._par_ok(u, v):
                return CompositionCert(False, float('inf'), 0, True, 'par_res')
            if kind == 'hand' and not self._hand_ok(u, v):
                return CompositionCert(False, float('inf'), 0, True, 'hand_iface')
            beta += self.beta_if
        depth = self._longest_chain(G)
        ok = depth <= self.D_max and beta <= self.beta_budget
        return CompositionCert(ok, beta, depth, True, 'ok' if ok else 'budget')

    def _seq_ok(self, u, v):   # post_u ⊆ pre_v ∧ 边界不变式 ∧ 模式转移合法
        return (implies(self.skills[u.sid].post, self.skills[v.sid].pre)
                and self._inv_edge(u, v)
                and self._mode_edge(u, v))
    def _par_ok(self, u, v):   # 资源不相交，或共享由 HSG 托管 + 跨体距离
        su, sv = self.skills[u.sid], self.skills[v.sid]
        return (su.footprint.isdisjoint(sv.footprint)
                or self.hsg.managed(su.footprint & sv.footprint)) \
               and self._cross_clearance_ok(u, v)
    def _hand_ok(self, u, v):
        return self.hsg.check_interface(u, v)   # 定义 571

# IP-366 ContactAwareTrajectory：接触感知轨迹证书（5Hz 块生成期）
class ContactAwareCertifier:
    def __init__(self, tau_geo=0.05, beta_cat=0.02, safety_margin=0.01,
                 T_h=0.5):
        self.beta_cat, self.d_safe = beta_cat, safety_margin
        self.T_h = T_h

    def certify(self, traj, scene, contract, x0):
        mode_ok = self._check_mode_automaton(traj, contract.sigma_C)
        if not mode_ok:
            return CertCAT(False, False, False, self.beta_cat, False)
        # 1) 连续扫掠：禁触体（默认全集 \ 意图接触体）
        o_forbid = scene.bodies - contract.intended_bodies()
        ccd_ok = self._conservative_advancement(traj, o_forbid,
                                                self.d_safe + self.beta_cat)
        # 2) 意图接触冲量界
        impulse_ok = self._impulse_within(traj, contract, scene)
        # 3) 动态障碍 ICS（速度障碍 + 刹车界）
        ics_empty = self._ics_empty(traj, scene.dynamic_obstacles, self.T_h)
        return CertCAT(ccd_ok, impulse_ok, ics_empty, self.beta_cat, mode_ok)

    def _conservative_advancement(self, traj, obstacles, margin):
        t = 0.0
        while t < traj.T:
            d = self._min_distance(traj(t), obstacles)      # 下界
            if d < margin:
                return False
            # 用距离下界推安全时间步，连续覆盖，不跳采样
            t += max(self._safe_dt(d - margin, traj.speed(t)), 1e-5)
        return True

    def _ics_empty(self, traj, dyn_obs, T_h):
        for o in dyn_obs:
            vo = self._velocity_obstacle(traj, o)           # 相对速度锥
            if self._intersects(traj, vo) and not self._brake_escape(traj, o):
                return False
        return True

# IP-367 HandoffSafetyGovernor：交接安全监督器（1kHz）
class HandoffSafetyGovernor:
    def __init__(self, force_tol=2.0, pose_tol=0.005):
        self.owner = {}            # object -> skill sid | None
        self.force_tol, self.pose_tol = force_tol, pose_tol

    def lock(self, obj, sid):

            self.owner[obj] = sid
            return True
        return False                # 边界独占：已有其他 owner

## 4. 推导

**引理 97（组合证书代数的可靠性）**
设 (A1) 每个技能实例 v 的证书在 Supp_v 上有效（β_v 覆盖其误差，概率 ≥1−ε_v）；(A2) 每条 seq 边满足 post_u⊆pre_v、边界不变式与接触模式转移合法；(A3) 每条 par 边满足资源不相交或由 HSG 托管，且跨体距离 ≥d_safe；(A4) 每条 hand 边满足定义 571；(A5) β_comp ≤ β_budget 且 depth ≤ D_max。则 C_comp 有效 ⇒ 沿 G_T 的任一执行，每个块满足 v11 块证书不变式，且执行行为集合 ⊆ 各子技能已认证行为之并。证明：对 G_T 的拓扑序归纳。seq：post/pre 与不变式保证下一技能从其前提状态出发，模式转移合法保证接触不"跳变"；par：资源不相交 ⇒ 两技能互不改变对方前提，跨体距离由 β_comp 吸收；hand：由 HSG 的 owner 原子转移与状态匹配保证边界等价；β_comp 的加性正好覆盖各段误差与接口误差之和。∎

**引理 98（支撑门控泛化的保守性）**
若计划 G_T 中存在 v 使 ξ_v=out，则 SCC 拒绝直接认证：要么规划器将 v 细化为全 in-support 的子图 G'_T（由引理 97 得证），要么 K_eff^comp←1（单步）或 Π_r 收缩。两种情况下 Exec(G_T) ⊆ v11 可行集，系统不产生任何未由已认证技能覆盖的新物理行为。证明：SCC 只能"允许认证"，不能"创造许可"；out-of-support 直接落入拒绝分支；细化后的子图仍由同一归纳规则认证；单步/Π_r 是 v11 已有子集。故泛化只增加**可执行的任务图**，不扩大**行为集合**。∎

**引理 99（接触语义的连续保守性）**
在 (A6) 默认拒绝（K_forbid = 全集 \ K_int）、(A7) 意图接触冲量/力在 J_max/f_max 内且力闭合维持、(A8) 扫掠证书用保守推进覆盖 [0,T]、(A9) 动态障碍 ICS=∅ 且刹车界 d_brk 有效下：任一块在连续时间上无禁触事件、无穿透、无动态障碍碰撞。证明：SW(τ) 覆盖整段轨迹；保守推进用距离下界推安全步长，步内距离只会更大，故不漏检、不穿透；默认拒绝保证任何未分类/未声明接触都计入 O_forbid；ICS 空集保证存在许可制动轨迹逃逸；冲量界把意图接触限制在契约内，越界即降级为禁触。∎

**引理 100（交接独占的支配性与中止等价）**
(i) HSG 的 lock/owner 映射保证每个共享物体任一时刻至多一个 owner；(ii) transfer 需 owner 正确、接触状态匹配、力闭合并保持，否则 freeze；(iii) freeze 命令即 v11 JSSE 的零速位置保持 + 重力补偿，故物理行为 ⊆ v11 可行集（支配性），且中止点映射沿用 v11 定义 561 的 q_abort。证明：锁不变式保证互斥；状态匹配拒绝"释放与抓取重叠"的非法交接；freeze 是 v11 Level-3 原语，不引入新行为；q_abort 由 FK 标定误差 ε_fk 约束（v11 E596）。∎

**引理 101（联合保守性与残余风险显式化）**
在引理 97–100 与**契约指派正确**的前提下，任一非安全事件被漏检的概率 ≤ ε_comp+ε_contact+ε_hand+ε_β+ε_geo+ε_sra+ε_jsse（各失效模式正交，并集界）。若契约指派错误（把 forbidden 洗白为 intended、把 out-of-support 标为 in-support、把非 owner 标为 owner），则全部证明**相对错误规范真空成立**；定义 ε_contract = P(mislabel)，该量**不能**通过增加几何验证或加严 β 降低（验证以规范为前提），只能通过 (i) default-deny 缩小可洗白面、(ii) 独立审计（E626）测量漏检率、(iii) 高风险标签强制人工/多源确认来约束。∎

## 8. 本轮最大风险

**一句话**：整条链的可靠性最终压在**契约指派**上——"这段动作属于哪个技能、哪些接触是意图、哪个物体归谁"由通才/规划器生成；若它把禁触事件**洗白**成"意图接触"（推人→推物、未注册物→可操作、越权工具→许可工具），则 SCC 的组合证明、CAT 的冲量界、HSG 的独占全部**相对错误规范真空成立**，而且该错误恰在泛化/新颖场景最易发生（正是"通用"要发挥的场合），比 v11 的数值失准更隐蔽；更棘手的是，这类错误**不能**靠更多几何验证或更严 β 修复（验证以规范为前提），只能靠 default-deny、独立审计（E626/E627）与高风险标签人工确认来约束，因此本轮真正的守门人不是组合器，而是**规范本身的独立可信度**。
