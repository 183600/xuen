# 第 1 轮（新循环） · CertOS × SimFalsify：把证书的「运行时假设」编译成 ROS2 QoS 契约，并用 Isaac Sim 做证书级证伪（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 的四层证书塔已能证明「在给定运行时语义下」个性化与并发安全，但它压着一个贯穿 40 余轮、从未写出的隐含假设 **(H3) 柏拉图运行时**：全局同步时钟、消息可靠且按时、执行器无抖动、仿真可确定性重放、证书更新原子。本轮灵感词「ROS2」「Isaac Sim」恰好从工程基底戳破它：**ROS2 是异步 DDS + 尽力而为 QoS + 无全局时钟 + 执行器回调抖动；Isaac Sim 是 GPU 并行 PhysX + 非确定性 + ROS2 bridge 时延 + sim-real 时钟差**。因此本轮不是再加一层算法，而是做一次「地基浇筑」：把证书的运行时假设 A 提升为一等公民，**(a) 编译成可执行的 ROS2 QoS/生命周期/执行器契约**，**(b) 运行时监测假设违约并把违约映射为单调降级**，**(c) 用 Isaac Sim 的 GPU 并行做证书级证伪**，专门寻找「假设悄悄破裂但证书仍被当成 sound」的反例。核心口号：**证书不是绝对真理，而是「相对运行时假设 A 的条件真理」；不能编译成 QoS 的假设，等于没有假设。**

## 0. 直觉与动机

**灵感 1（ROS2 → QoS 是证明义务，不是调参旋钮）**：直觉上，v20 的「证书租约」说得斩钉截铁：只要 `m − λ(t−τ) ≥ θ` 就能用于守卫。可谁来保证 `t−τ` 有界？在 ROS2 里，只有 DDS 的 **deadline** QoS 能给出「更新间隔 ≤ D」的观测契约，**liveliness** 给出发布者存活契约，`RELIABLE` 只保证最终送达、**根本不保证时延有界**。于是租约的 soundness 其实等价于一条可写的 QoS 约束：若 cadence ≤ D，则最坏陈旧度就是 D，守卫要成立只需 **D ≤ (m−θ)/λ**（λ = L_m·v_max 见定义 41）。这就是本轮的第一把钥匙：**ROS2 的每个 QoS 字段都对应证书的一条假设；配错 QoS 不是在调性能，而是在悄悄删掉证明的前提。** 同理——原子快照 ↔ `TRANSIENT_LOCAL`（transient local）持久化；rely-guarantee 非干扰 ↔ 把安全关键回调与对话/个性化回调放进不同的 `MutuallyExclusive` callback group / 不同 executor；定义 42 的 LO→HI 模式切换 ↔ lifecycle node 的 `deactivate`（只删不增）。一句话：**把抽象租约 realized 成 DDS 契约，证书才第一次真正「落地」。**

**灵感 2（Isaac Sim → 不只是测策略，而是证伪假设）**：直觉上，以前我们用 Isaac Sim 注入「人类延迟/反复/中断」去测**策略**；但真正会杀死 soundness 的不是策略差，而是**假设错**——系统在 `A` 从未成立的情况下仍然运行着 `C`。Isaac Sim 最有价值的能力不是物理保真，而是 **GPU 并行**：数千个环境可以同时扰动不同的时序/QoS/调度故障。于是把仿真重新定义为**证书证伪任务**，反例分两类：**I 类（假设违约未被检测）**——q(t) 已经越出安全包络、运行时却仍签发有效租约（监控盲区）；**II 类（假设成立但证书违约）**——A 真的成立，C 仍被违反（证书本身有 bug）。同时必须直面 Isaac Sim 的非确定性与 bridge 时延：用 `/clock` + 固定种子做**确定性重放**，并且只把仿真结论当作**时序裕度分布**（可迁移的是分布，不是单条轨迹），而不是 pass/fail 通行证。

**灵感 3（耦合 → 假设溯源账本，证书强度等于最弱未验证假设）**：ROS2 侧编译出的 QoS 契约，与 Isaac Sim 侧证伪出的时序裕度，必须在同一本**假设溯源账本**里对账：某个假设在仿真里被验证、但在目标板 DDS 上从未被验证，就不能记成「已验证」。这给出一个诚实且可量化的安全观：**部署安全 = 条件证书 C|A ∧ 假设覆盖率 Cov(A) ⇒ 残余风险 ε = 1 − Cov(A)。** 证书的强度不取决于它写得多漂亮，而取决于它最弱的那条**未被验证的假设**。

**耦合升级**：CQC（证书-QoS 编译器）把 `C|A` 的每条假设编译成 ROS2 QoS/lifecycle/executor 契约并检查可满足性；QCR（QoS 一致性运行时）把 DDS 违约事件即时映射为租约失效与单调降级；SCF（仿真证书证伪器）在 Isaac Sim 的 GPU 并行环境里搜索 I/II 类反例并回灌 CQC/QCR/CKB。四层架构由 v8 的「个性化并发闭环」升级为 v9 的「个性化并发 + **假设落地 + 证书级证伪**」闭环。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（运行时假设集与条件证书 `C|A`）**：证书 C 的运行时假设集 `A = (A_clock, A_delivery, A_fresh, A_atomic, A_sched)`：
- `A_clock`：存在单调、可比的时钟，且跨节点偏斜 ≤ δ；
- `A_delivery`：观测/证书消息的端到端时延 ≤ d_max，不可靠时由冗余/重传兜底；
- `A_fresh`：观测在守卫时刻的陈旧度 ≤ D（对应租约 λ）；
- `A_atomic`：证书状态快照无撕裂读/丢失更新；
- `A_sched`：安全关键回调的 WCET 与释放抖动有界，不被低关键回调头阻塞。
**定义**：C 是 **A-sound** 的，当且仅当 `A` 全部成立时 C 的结论成立。此前所有轮次的「C sound」都应读作 `C|A`；`A` 未被写出，正是本轮要补的洞。`A` 的补集称**残余假设集** `Ā`，其被证伪的难度决定残余风险。

**定义 45（证书-QoS 编译 Φ 与 deadline 预算引理）**：ROS2 QoS profile `q = (reliability, durability, history, depth, deadline, lifespan, liveliness, lease_duration)`，执行器拓扑 `X`（callback group / executor）。**编译**是映射 `Φ: (C|A) ↦ (Q_adm, X_adm)`，要求 **sound 性**：若实际 QoS 轨迹 `q(t) ∈ Q_adm` 且执行器拓扑 `∈ X_adm`（∀t），则 `A` 成立。**最小性**：在资源偏序（越弱越好）下取满足 sound 的最弱 `q`，避免过度约束。**deadline 预算引理**：若更新 cadence ≤ D 且 λ = L_m·v_max，则守卫新鲜度 `m − λ(t−τ) ≥ θ` 在两次更新之间恒成立，当且仅当 **D ≤ (m−θ)/λ**。故 deadline QoS 必须配置为 `D ≤ (m−θ)/λ`；若 DDS/网络无法达到该上界，则证书必须收缩（增大 θ 或减小允许速度），**不允许**调大 D 假装没这回事。**推论（字段对应）**：`A_atomic ⇒ durability=TRANSIENT_LOCAL(depth≥1)` 或 seqlock；`A_sched ⇒` 安全关键与低关键回调分属不同 `MutuallyExclusive` group；`A_fresh ⇒ deadline + liveliness(lease_duration≈D)`。

**定义 46（QoS 违约事件与单调降级）**：DDS 可观测事件 `E_q = {DEADLINE_MISSED, LIVELINESS_CHANGED, RELIABILITY_DOWNGRADE, SAMPLE_LOST, CLOCK_JUMP}`。定义违约映射 `δ: E_q → {收缩, 重取, 停机}`，要求 **单调性**：`δ` 只能把证书替换为子集 `C' ⊆ C`（收缩），绝不扩张。**单调降级定理**：若运行时在**事件发生时刻**（而非下一次调度）触发 `δ`，且每次 `δ` 单调收缩，则任意违约序列都不破坏安全性（因为守卫动作集只减不增）。**失败透明性谓词**：每个 `e ∈ E_q` 必须落审计日志并被至少一个关键级 ≥ geometry 的监控器消费；静默丢弃即视为实现 bug。对应地，ROS2 lifecycle 的 `deactivate` 实现定义 42 的 LO→HI 切换，且只删任务、不放松阈值。

**定义 47（Isaac Sim 证书证伪任务与反例分类）**：证伪任务 `F = (D_env, D_fault, C|A, B)`：环境分布 `D_env`、故障分布 `D_fault`（deadline miss、jitter、丢包、时钟跳变、executor 交错、bridge 延迟）、待验证书 `C|A`、预算 B。**I 类反例**：存在 `q(t) ∉ Q_adm` 但运行时未触发 `δ`（盲区）；**II 类反例**：`q(t) ∈ Q_adm`（A 成立）但 C 被违反（证书 bug）。**假设覆盖率** `Cov(F) = |{被命中的可达故障类}| / |{可达故障类}|`；**残余风险** `ε = 1 − Cov(F)`。**反例最小化**：在故障参数上取最小扰动仍复现者，便于定点修复。

**定义 48（Sim-Time 条件证书与时间膨胀界）**：Isaac Sim 用 ROS2 `/clock` 驱动，设时间膨胀 `ρ = Δt_wall / Δt_sim`，bridge 时延 ≤ L_bridge。仿真租约在 sim-time 成立 `m − λ·Δt_sim ≥ θ`。**迁移不等式**：真实陈旧度 `Δt_wall ≤ ρ_max·Δt_sim + L_bridge`，故要在真机 sound，需 `m − λ(ρ_max·Δt_sim + L_bridge) ≥ θ`。**推论**：仿真中「刚好通过」的租约在真机大概率失效；SCF 必须输出**裕度分布**（在 ρ、L_bridge 抖动下的通过率曲线），而非单点 pass。非确定性由固定 seed + 确定性重放校准，重放不一致本身也记一条 I 类风险。

**定义 49（QoS 安全包络与 timing barrier）**：在 QoS 空间定义三区：`S_safe`（C|A 可证）、`S_warn`（假设将破，必须收缩到 `C_contract`）、`S_viol`（假设已破，安全停机）。构造**时序屏障函数** `B_q(q)`，满足：`q ∈ S_safe ⇒ B_q ≥ 0`；`q ∈ S_viol ⇒ B_q < 0`；且沿运行时 QoS 演化 `B_q` 的下降速率有界（使监控能在越过边界前预警）。运行时策略：`S_safe` 正常守卫；`S_warn` 单调收缩 + 续租；`S_viol` 停机/最坏假设化。**注**：这是把第 43 轮「信任预算 τ_u」推广到时间维——**信任不是标量额度，而是 QoS 空间里一个会收缩的安全包络**。

**定理（条件证书的组合可靠性）**：若 (i) Φ 对 `C|A` sound；(ii) QCR 在 `E_q` 上检测完备且 δ 单调收缩；(iii) SCF 的假设覆盖率为 `Cov`、残余风险 `ε = 1−Cov`；则部署系统满足 `C` 的概率 ≥ `1−ε`（在假设模型内），且任何未被覆盖的假设违约都只会导致**安全停机**、不会导致不安全动作。**证明骨架**：(i) 保证正常路径上 A 成立；(ii) 保证 A 破裂时立即进入收缩域，由单调性保安全；(iii) 把「模型误差」量化为覆盖率缺口，未覆盖事件由 (ii) 兜底为停机。该定理把 v20 的「绝对 sound」降级为**可审计的条件 sound**——这是更诚实、也更可工程化的目标。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 CERT-QOS-COMPILER（证书-QoS 编译器 CQC）
1. **假设抽取**：从 `C|A`、rely-guarantee 读写集、租约 `(m,τ,λ,κ)` 中抽取 `A_clock/A_delivery/A_fresh/A_atomic/A_sched` 五类假设。
2. **QoS 约束求解**：生成 deadline 上界 `D ≤ (m−θ)/λ`、durability、liveliness、history/depth、callback group/executor 隔离等约束；在资源偏序下求**最弱可行解**；输出 `ros2 QoS profile + launch/executor 拓扑`。
3. **可满足性检查与诚实拒绝**：若目标平台/网络无法满足 deadline 预算，则拒绝签发 `C`，并给出「收缩 θ / 降 v_max / 缩短管线 / 提高更新率」四条可执行补救，**绝不**用更宽松 QoS 蒙混。
4. **可追溯性**：每个 QoS 字段标注它支撑的假设与对应证书谓词，写入假设溯源账本。

### 2.2 IP-61 QOS-CONFORMANCE-RUNTIME（QoS 一致性运行时 QCR）
1. **QoS 事件监听**：订阅 DDS `DEADLINE_MISSED / LIVELINESS_CHANGED / RELIABILITY_DOWNGRADE / SAMPLE_LOST`，并读取单调时钟检测 `CLOCK_JUMP`。
2. **违约即租约失效**：事件发生时刻立即 invalidate 对应租约（不等下一调度周期），并触发单调降级 `δ`；降级阶梯 `正常 → 收缩 C_contract → 最坏假设化 → 安全停机`。
3. **执行器隔离守卫**：安全监控跑在独立 callback group / 独立 executor（必要时独立线程 + 实时优先级），杜绝低关键回调头阻塞；审计 W3C。
4. **时间屏障监控**：维护 `B_q(q)`，在 `S_warn` 提前续租/收缩，在 `S_viol` 停机；全事件入线性一致性审计日志（复用 IP-59）。

### 2.3 IP-62 SIM-CERT-FALSIFIER（仿真证书证伪器 SCF）
1. **GPU 并行证伪**：在 Isaac Sim 中以数千并行环境跑 `F`，每环境随机化一类故障（deadline、jitter、丢包、时钟跳变、executor 交错、bridge 延迟）。
2. **I/II 类反例分类与最小化**：区分「假设违约未被检测」与「假设成立但证书违约」，最小化后定点回灌 CQC（改编译）或 QCR（补检测）。
3. **Sim-Time 校准**：用 `/clock` + 固定 seed 做确定性重放；测量 `ρ` 与 `L_bridge` 分布，按定义 48 输出**迁移裕度曲线**；重放不一致记为 I 类风险。
4. **覆盖率与残余风险报告**：维护 `Cov(F)`、`ε`，只允许把「有覆盖证据」的假设记入账本，未覆盖假设默认按最坏处理。

## 5. 本轮最大风险

**一句话**：整套条件证书最终把 soundness 外包给了 **ROS2/DDS 的 QoS**——而 DDS 的 deadline/liveliness 本质是「违约后报告」而非「违约不发生」的软契约，Isaac Sim 又无法保真复现目标板的 DDS 调度与 WCET，于是「仿真里验证过的时序假设」可能在真机上静默失效，形成一种被覆盖率报告**洗白**的「已验证的未知」。

### IP-60 CQC：假设抽取、deadline 预算与最弱 QoS 求解
```
def compile_cert_to_qos(cert, A, ros_graph):
    constraints = []
    # (1) A_fresh <- deadline + liveliness；定义 45 引理
    D_max = (cert.m - cert.theta) / cert.lambda_decay      # λ = L_m * v_max
    constraints.append(QoS.Deadline(cert.obs_topic, D_max))
    constraints.append(QoS.Liveliness(cert.obs_topic, MANUAL_BY_TOPIC,
                                      lease_duration=D_max))
    # (2) A_atomic <- transient_local（或运行时 seqlock）
    if A.atomic:
        constraints.append(QoS.Durability(cert.cert_topic,
                                          TRANSIENT_LOCAL, depth=1))
    # (3) A_delivery <- 冗余/重传预算
    if not net.bound_met(cert.obs_topic, max_delay=D_max):
        constraints.append(redundancy(cert.obs_topic, k=ceil(p_loss_target)))
    # (4) A_sched <- 执行器隔离（IP-58 RG 非干扰的 QoS 落地）
    for (safe_cb, low_cb) in cert.rg_isolation_pairs:
        constraints.append(Exec.SeparateGroups(safe_cb, low_cb))
    q, X = weakest_feasible(constraints, ros_graph)        # 最小性：最弱可行
    if q is None or not ros_graph.schedulable(X):
        return Infeasible(honest_repair(cert, constraints))
    ledger.record(cert.id, A, q, X)
    return CertContract(cert | A, q, X)

def honest_repair(cert, constraints):
    # 只收缩证书，绝不放宽 QoS 去“凑”
    return [shrink_theta(cert), lower_vmax(cert),
            shorten_pipeline(cert), raise_update_rate(cert)]
```

### IP-61 QCR：违约即时失效、单调降级与时间屏障
```
def on_qos_event(ev):
    if ev.type in {DEADLINE_MISSED, LIVELINESS_CHANGED,
                   RELIABILITY_DOWNGRADE, SAMPLE_LOST, CLOCK_JUMP}:
        ledger.log(ev, t=monotonic_now(), epoch=ev.epoch)
        invalidate_lease(ev.task)              # 事件时刻即失效，不等调度
        downgrade_monotone(ev.task)            # 只收缩，不扩张
        if ev.criticality >= K_GEOMETRY or barrier_warn(ev):
            enter_contract_mode(ev.task)       # C -> C_contract

def timing_barrier(q_hat, A):
    # B_q：safe>=0, viol<0；用最近窗口估计下降速率做预警
    slack = min_field_slack(q_hat, A)          # deadline/liveliness/时延裕度
    rate  = est_degradation_rate(q_hat)
    if slack < 0:                 return VIOL, 0.0
    if slack - rate * T_warn < 0: return WARN, slack
    return SAFE, slack
```

### IP-62 SCF：GPU 并行证伪、I/II 类分类与迁移裕度
```
def falsify(cert_cond, n_envs=4096, budget):
    envs = isaac_sim.parallel(n_envs, clock="/clock", seed=base_seed,
                              det_replay=True)
    cex = []
    for env in envs:
        fault = sample(env.rng, D_fault)       # deadline/jitter/drop/clock/sched
        run(env, fault, cert_cond)
    for tr in envs.traces:
        if not tr.q_in(Q_adm) and not tr.detected(E_q):
            cex.append(("I", minimize(tr, fault)))     # 盲区：假设破而未被检测
        elif tr.q_in(Q_adm) and tr.violates(cert_cond):
            cex.append(("II", minimize(tr, fault)))    # 证书 bug：A 成立仍违约
    cov = hit_classes(cex) / reachable_classes(D_fault)
    return cex, Report(Cov=cov, eps=1-cov,
                       transfer=margin_curve(rho, L_bridge))
```
