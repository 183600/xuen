# 第 4 轮（灵感驱动研究循环·新灵感三元组；本轮灵感：「文化适应性」×「示教学习」）

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v21 + IP-425–430（SDC/CAC/DCL/GIC/HPC+/CFC+；其上承 v20 联邦感知证书与 v19/v17 全链）。
> **本轮纪律**：**文化是规范参数的可变带，示教是规范证据的采样，物理安全是二者都不可逾越的底座**。不推倒 v21：SDC/CAC/DCL/GIC/HPC+/CFC+ 全部原样保留。本轮只做一件事：把 v21 的"单一规则库 R + 单一最严默认 π_⊥"升级为"**分层规范格 + 示教诱导不变量 + 有界文化适配**"，并顺手把 v21 最大风险（召回假设纯经验、无外部证据）用示教**只加约束**地补强。

## 0. 直觉与动机

**灵感 1（文化适应性 → 规范不是常量，而是带物理底座的参数族）**
直觉：v21 的 DCL 假设存在一份"正确"的规则库 R 与一个"最严默认" π_⊥。但"多近算近、何时该让、如何交接"因文化、场景、角色而异：把同一套个人空间半径套给所有人，要么让大间距文化使共享区活性坍缩，要么让高密度场景的机器人显得冒犯。文化适应性的诱惑是"按文化调参"，危险也恰在这里——**调参若越过物理安全，文化就成了不安全的借口**。关键反直觉点：**文化适应不应改变"能不能做"，只应改变"在已证明能做的动作里用多少、更偏好哪一个"**。于是把规范拆成三层：物理安全 S_phys（= v21 的 HPC/AbsCert 执行集，不可协商）⊇ 示教归纳的规范共识 A_U（最保守内界）⊇ 上下文容许 A_c（A_U ⊆ A_c ⊆ Exec_v21）；文化只在 [A_U, A_c] 这条**带内**移动，绝不越过 v21。默认 π_⊥ 精确回退 v21；适配只有两种合法操作：**偏好重排**（只在已认证集内选）与**凭显式同意的带内放松**（把示教收紧的部分放回 v21 上限）。绝不从外貌/受保护属性推断文化，只从**行为线索 + 用户声明**推断"当前规范上下文"。

**灵感 2（示教学习 → 示教是证据，不是真理；规范藏在"没做什么"里）**
直觉：与其手写规则库，不如让不同文化、不同身体的示范者**演示**如何让位、如何交接、保持多大间距。但示教有两个陷阱：其一，**行为克隆学到的是相关而非因果**（老师因走廊窄才靠边，不是因为"靠边"本身是规范）；其二，**单条示教只证明"这条轨迹可行/可接受"，不证明"附近轨迹安全"**。关键反直觉点：**示教最有价值的信息在"老师从不做什么"的负空间里**——从示范轨迹的补集可归纳出**不变量**（"从未进入区域 R""与人距离从未小于 d*""交接前必然减速"），它们天然是**约束**而非策略，能直接接入 v21 的单调证据体系。于是：**规范共识 A_U = 跨文化示教不变量的交集（所有人都避开的东西）；文化差异 B_c = A_c \ A_U（有人允许、有人不允许的带）；示教策略只作"提案生成器"，永远经过证书过滤。**

**两者如何统一**
统一为 **v21 之上的"文化-示教"层**：DIM（示教不变量挖掘）从负空间抽取约束，按上下文分组求交得 A_U、求差得文化带 B_c；NPL（规范格）把规范组织成有偏序的参数格，默认 π_⊥ = v21；CNI（上下文-规范推断）用行为证据 + 声明推断当前 π，输出 conformal 集，不确定即回退 π_⊥；BCA（有界文化适配）只在 [A_U, Exec_v21] 内做偏好过滤或凭许可的带内放松；DGPP（示教护栏策略）把 LfD 策略降格为提案，OOD 即弃用。统一准入门升级为 **HPC++ = (HPC+, π_id, invariant_proof, demo_provenance, adaptation_license)**。安全论证分四支：默认精确回退 v21；偏好模式 ⊆ v21；带内放松 ⊆ v21；示教只收紧。任一失效 → π_⊥ → v21。

## 1. 研究问题（轮次升级版）

- **Q1（规范共识的统计保证）**：如何从有限、非均衡的跨文化示教中，以 PAC / Clopper–Pearson 界归纳"所有人都不做"的不变量？当某文化样本不足时，交集是否仍可认证为"普适"，还是只能保留已演示核、拒绝插补？
- **Q2（非刻板的文化推断）**：如何只用行为线索与显式声明（**禁用受保护属性**）构造规范上下文的后验 / conformal 集？误判的代价如何做到非对称——误判为更保守只损失活性，误判为更放松才有规范伤害？
- **Q3（有界适配与同意）**：如何定义规范格、可变带与放松许可，使"文化适配"在数学上不可能越过 v21 的执行集？适配的振荡、漂移、撤销与审计如何落地？
- **Q4（示教的护栏）**：如何检测示教分布外（新身体/新场景/新文化）、抑制行为克隆的因果混淆、抵抗单个恶意/异常示教对共识的污染？DGPP 如何与 12ms 控制环和 v21 的 TTL 叠加？

## 2. 设计原则（在 P34–P36 之上新增 P37–P39）

**P37 分层规范律（Layered Norms）**
规范空间分为 S_phys = Exec_v21（物理安全，继承 v21，任何 π 不得触碰）、A_U（示教归纳的规范共识，最保守内界）、A_c（上下文容许，A_U ⊆ A_c ⊆ Exec_v21）、个体偏好（最细，仅排序）。默认 π_⊥ = v21。对所有 π：`A_π ⊆ Exec_v21`。

**P38 示教即证据律（Demonstration-as-Evidence）**
示教只产生两类输出：**约束**（不变量，只加入并收紧 `A_U ⊆ Exec_v21`，只紧不松）与**提案**（策略，必须再过证书）。规范共识 `A_U = ∩_c A_c`，带 PAC 置信界；样本不足的上下文不得"补全"，只能保留已演示核并令 `B_c = ∅`。

**P39 有界适配律（Bounded Adaptation）**
默认 π_⊥；适配仅两种合法操作：偏好过滤 `Exec ∩ Pref_π ⊆ Exec_v21`，或凭**显式同意 + 带内证明**在 `[A_U, A_c]` 内放松（等价于把示教收紧的部分放回 v21 上限）；不确定 / 撤销 / 过期 → π_⊥。禁止从受保护属性推断文化；用户声明优先于推断。

## 3. 与基线的接口（如何退化）

- DIM 失效 → 无示教约束 → `A_U = Exec_v21`，`B_c = ∅` → v21；
- CNI 失效 → π = π_⊥ → v21；
- BCA 失效 → 无适配、仅默认偏好 → v21；
- DGPP 失效 / OOD → 弃用示教策略，回认证规划器 → v21；
- 三者全失效 → 完全回退 v21 ⇒ `Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`（引理 168）。
- **安全继承**：DIM 只紧（`A_U ⊆ Exec_v21`）、BCA 只在 `[A_U, Exec_v21]` 内移动、CNI 向保守退化、DGPP 仅提案；任意失效都向更保守方向退化。CNI/BCA 状态机以事件方式接入 v17 APS 新鲜度阶梯：每次迁移携带时间戳，TTL 过期回落 π_⊥，控制路径仅 O(1) 查询。

## 4. 预期贡献

1. **分层规范格**：首次把"文化差异"形式化为物理安全之上的**有界参数带**，证明任何适配都不越过 v21 的执行集，把"该不该"与"能不能"彻底解耦；
2. **示教不变量挖掘**：从负空间学约束而非策略，PAC 界 + 跨上下文交集，给出"普适共识 vs 文化剩余"的可计算分离；
3. **非刻板上下文推断**：仅行为 / 声明的 conformal 规范集 + 用户覆盖 + 非对称代价，禁用受保护属性；
4. **有界适配与许可审计**：偏好过滤 / 同意放松双通道，撤销、TTL、可复放；
5. **示教护栏**：OOD 检测 + 因果混淆抑制 + 鲁棒聚合抗投毒；
6. **HPC++ 闭环**：共识、规范、示教来源、许可全链可机械复核，并给 v21 的召回假设补上"只紧"的外部证据。

## 5. 本轮最大风险

**一句话**：所谓"普适规范共识" A_U 是由示教语料交集归纳出来的经验对象——若语料系统性缺失某类身体、文化或场景，交集会把"多数人的规范"误当成"所有人的底线"，于是机器人对未被代表的人要么永久停在最紧默认（**活性歧视**）、要么在有偏的"文化适配"下自信地用满 v21 的许可（**规范伤害**）——一种可审计、可复现、却对特定人群系统性不公的"**普适性幻觉**"。

# IP-431 Norm Profile Lattice
class NormProfileLattice:
    KNOBS = ("d_space", "v_appr", "tau_yield", "G_lex", "rho_turn", "h_style")

    def __init__(self, exec_v21, pi_default):
        self.Exec = exec_v21            # v21 执行集：物理安全上界
        self.pi_default = pi_default    # 无示教/不确定时的默认

    def admissible(self, pi):
        # 规范只能落在 v21 之内：文化不可能解锁 v21 未许可的动作
        return pi.A <= self.Exec and pi.B <= self.Exec

    def meet(self, p, q):               # 冲突消解：最严者胜（与 v21 DCL 一致）
        return NormProfile({k: stricter(p[k], q[k]) for k in self.KNOBS})

    def select(self, plans, pi):
        return select_by_preference(plans, pi.pref)   # 仅排序，不新增动作


# IP-432 Demonstration Invariant Miner
class DemonstrationInvariantMiner:
    def __init__(self, predicate_class, delta=0.01, n_min=8):
        self.Phi = predicate_class      # 半空间/盒/距离阈值/时序序
        self.delta, self.n_min = delta, n_min

    def mine(self, demos_by_context):
        """demos_by_context: {c: [(traj, embodiment)]} -> (A_U, {c: A_c}, {c: B_c})"""
        A_by_c = {}
        for c, trajs in demos_by_context.items():
            n = len(trajs)
            # PAC/Clopper-Pearson 违反率上界（只用于报告与门槛，不作为放松依据）
            eps = 1.0 - self.delta ** (1.0 / max(n, 1))
            forbidden = self._maximal_avoided_set(trajs)   # 负空间：轨迹从未触及的最大区域
            A_c = complement(forbidden)                    # 可接受集的内近似（保守）
            # 样本不足：不得插补"普适"，只保留已演示核，文化带置空
            if n < self.n_min:
                A_c = self._demonstrated_core(trajs)
            A_by_c[c] = intersect(A_c, self.Exec)
        A_U = intersect_all(A_by_c.values())               # 共识 = 交集（最保守）
        B = {c: difference(A_c, A_U) for c, A_c in A_by_c.items()}
        return A_U, A_by_c, B

    def _maximal_avoided_set(self, trajs):
        # 候选消除：在 Φ 中找与全部轨迹相容的最大禁用谓词并
        return maximal_consistent_forbidden(self.Phi, trajs)


# IP-433 Context-Norm Inference
class ContextNormInference:
    ALLOWED = ("proxemics", "declared_profile", "task_role", "history")  # 禁用受保护属性
    def __init__(self, profiles, calibrator, pi_default, alpha=0.01,
                 q_ctx=0.8, ttl=5.0):
        self.profiles, self.calib = profiles, calibrator
        self.pi_default, self.alpha, self.q_ctx, self.ttl = pi_default, alpha, q_ctx, ttl

    def infer(self, evidence, t_now):
        # 用户显式声明优先于任何推断（反刻板的第一道闸）
        declared = evidence.get("declared_profile")
        if declared in self.profiles:
            return self.profiles[declared], "DECLARED"
        feats = {k: evidence[k] for k in self.ALLOWED if k in evidence}
        gamma = self.calib.conformal_set(feats, alpha=self.alpha)   # 覆盖 ≥1-α
        post = self.calib.posterior(feats)
        # 非对称：只有唯一且高后验才适配，否则回最严默认
        if len(gamma) == 1 and max(post.values()) >= self.q_ctx:
            return self.profiles[next(iter(gamma))], "INFERRED"
        return self.pi_default, "DEFAULT"


# IP-434 Bounded Cultural Adapter
class BoundedCulturalAdapter:
    def __init__(self, npl, a_u, bands, consent_store):
        self.npl, self.a_u = npl, a_u
        self.bands, self.consent = bands, consent_store

    def adapt(self, exec_v21, pi, license=None):
        base = intersect(exec_v21, self.a_u)               # 示教收紧后的保守默认
        if license is None or not self.consent.valid(license, pi):
            # 偏好模式：只在已认证集内重排，绝不新增动作
            return self.npl.select(base, pi), "PREFERENCE"
        # 同意放松：只把 B_c 放回，且仍以 Exec_v21 为上界
        band = intersect(pi.B, self.bands.get(pi.id, set()))
        relaxed = union(base, band)
        if not subset(relaxed, self.npl.Exec):             # 底座校验
            return self.npl.select(base, pi), "FALLBACK"
        return self.npl.select(relaxed, pi), "LICENSED"

    def on_uncertain(self):
        return self.pi_default, "DEFAULT"                  # 不确定/撤销/过期 → v21


# IP-435 Demonstration-Guarded Policy Proposal
class DemonstrationGuardedPolicyProposal:
    def __init__(self, lfd_policy, demo_manifold, alpha_ood=0.01):
        self.policy = lfd_policy
        self.manifold = demo_manifold
        self.rho = demo_manifold.conformal_radius(alpha=alpha_ood)

    def propose(self, obs):
        cand = self.policy(obs)                            # 仅为提案
        if self.manifold.distance(cand) > self.rho:        # 示教分布外
            return None, "OOD_FALLBACK"
        return cand, "PROPOSAL"                            # 仍需 HPC++ 准入

@dataclass
class DemonstratedNormCert:
    profile_id: str
    invariant_proof: list     # [(谓词, PAC 界, 来源上下文)]
    demo_provenance: str      # 示教语料 merkle 根
    adaptation_license: str   # None = 偏好模式；否则许可哈希
    merkle_root: str

    def profile_admissible(self):
        return self.profile_id is not None

    def floor_ok(self, hpc):
        return hpc.contains(self.profile_id) and self.merkle_root is not None

@dataclass
class HPCPlusPlus:
    hpc_plus: HPCPlus          # v21 三证（原样）

## 3. 推导

**引理 163（示教不变量的 PAC 可靠性）** 设谓词类 Φ 的 VC 维为 d，n 条同分布示教中不变量 φ 从未被违反，则以 ≥1-δ 概率，任意新样本违反 φ 的概率 ≤ ε(n,δ) ≈ (d·ln n + ln(1/δ))/n（PAC），或无分布界 `1-δ^{1/n}`（Clopper–Pearson）。故"老师从未做 X"可转化为"X 的禁用区"的可靠下界。跨上下文取交集 `A_U = ∩_c A_c` 等价于禁用取并，只会更保守；样本不足的上下文只保留已演示核且 `B_c = ∅`，**不得插补普适性**。∎

**引理 164（默认回退与单调收紧）** 若 DIM 关闭或无示教，则 `A_U = Exec_v21`、`B_c = ∅`，默认偏好 π_⊥ 即 v21 DCL，故 `Exec_v22(π_⊥) = Exec_v21`。若 DIM 开启，`A_U = ∩_c A_c ⊆ Exec_v21` 且只由"从未违反"谓词构造，故收紧后的默认 `Exec_v21 ∩ A_U ⊆ Exec_v21`；示教只紧不松。∎

**引理 165（有界适配的 v21 不变性）** 对任意 π ∈ Π_adm：偏好模式 `Exec = select(Exec_v21 ∩ A_U, π) ⊆ Exec_v21`；同意放松模式 `Exec = select((Exec_v21 ∩ A_U) ∪ (B_π ∩ B_c), π)`，而 `B_π ∩ B_c ⊆ Exec_v21`，经底座校验后仍 `⊆ Exec_v21`。因此**任何文化适配都不改变 v21 的物理安全集**：文化只决定在 v21 已许可的动作里"用多少、偏好谁"。∎

**引理 166（示教策略的 OOD 护栏）** DGPP 仅在提案到示教流形距离 ≤ ρ 时提交，且提交物仍需 HPC++ 准入；设 ρ 由 conformal 校准使 `P(接受真 OOD 提案) ≤ α_ood`，则 LfD 策略对物理安全的贡献为空（它只是提案源）。因果混淆 / 分布漂移的最坏后果是提案被拒并回退认证规划器，而非绕过证书。∎

**引理 167（非刻板上下文推断）** CNI 的特征白名单排除受保护属性，用户声明优先；推断输出 conformal 集 Γ_π，仅当 `|Γ_π| = 1` 且后验 ≥ q_ctx 才启用推断 profile，否则 π_⊥。设 conformal 覆盖 ≥1-α，则声明缺失时"误配到更放松 profile"的概率 ≤ α；其余情形一律向最严默认退化，错误方向与危害方向对齐。∎

**引理 168（v22 整体安全继承）** 同一 v21 快照与同一示教语料下：DIM 只紧（163/164）、BCA 在 v21 内移动（165）、DGPP 仅提案（166）、CNI 向保守退化（167）。故默认 `Exec_v22(π_⊥) = Exec_v21`，任意适配 `Exec_v22 ⊆ Exec_v21`，从而 `Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。注意 v22 **不修复** v21 的 AbsCert 召回假设：它只是用示教给执行集追加"只紧"的外部约束，并在规范层把"该不该"与"能不能"解耦。∎

## 7. 已知风险与失效模式

1. **普适性幻觉（最大风险，见第 8 节）**：示教语料的文化/身体/场景偏差会把"多数人规范"误当"所有人底线"。缓解：欠覆盖上下文强制 `B_c=∅`（E803）、主动示教补覆盖（E819）、分组活性公平监控（E818）、共识只紧不松（引理 164）。
2. **规范伤害而非碰撞**：误配到更放松 profile 时物理仍安全，但可能冒犯、侵犯个人空间或破坏信任。缓解：声明优先、conformal 唯一集 + 高后验才适配、非对称代价（引理 167）、TTL/撤销（E811）。
3. **刻板与隐私**：从外貌推断文化是伦理红线。缓解：特征白名单禁用受保护属性（E804）、原始图像零出域（E828）、用户覆盖。
4. **示教污染与不一致**：恶意或异常示教试图放松共识。缓解：共识取交集（放松需所有上下文同意）、鲁棒聚合、信任加权、来源 merkle 审计（E815/E816/E812）。
5. **行为克隆的因果混淆 / 分布漂移**：学到相关捷径、遇新场景失效。缓解：只挖不变量、策略仅提案、OOD 即弃用、证书准入（引理 166，E813/E814）。
6. **适配振荡与活性坍缩**：上下文反复切换或保守叠加使活性趋零。缓解：滞回 + TTL + 带内放松通道（E810/E826），并以 v21 为活性下界参照（E830）。
7. **继承 v21 的召回假设**：v22 不修复 AbsCert 的 κ_c 经验性，只追加"只紧"示教约束。缓解：DIM 约束可部分补盲（E801），κ_c 在线监控（v21 E798）继续生效。

## 8. 本轮最大风险

**一句话**：所谓"普适规范共识" A_U 是由示教语料交集归纳出来的经验对象——若语料系统性缺失某类身体、文化或场景，交集会把"多数人的规范"误当成"所有人的底线"，于是机器人对未被代表的人要么永久停在最紧默认（活性歧视）、要么在有偏的"文化适配"下自信地用满 v21 的许可（规范伤害）——一种可审计、可复现、却对特定人群系统性不公的"普适性幻觉"。
