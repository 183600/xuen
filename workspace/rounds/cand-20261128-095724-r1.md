### 第 6 轮灵感驱动研究记录（新循环首轮，承接 CADVS-v5）

**灵感词**：决策规划、灵巧操作

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）用条件流匹配把提议器连续化、用嵌入+固化把记忆闭环化、用情感调制把人因锚精细化，并以定理 6（证书不变性）把框架推广为「任意生成器 + 认证边界」。但 v5 的证书只覆盖**单一接触模式内的连续轨迹**。灵巧操作的本质是**混合系统**：成功依赖一串接触模式（接近→抓取→指内重定向→放置），真正困难的是**离散决策**（选哪些接触、何时切换、是否换手）与**模式间的过渡**，而不是任一模式内的平滑轨迹。v5 对此有三处结构性缺口：(a) 离散决策器（选模式/技能序列）完全在证书边界之外，是最大的未认证决策面；(b) 高维欠驱动多指手无法在原始关节空间做流匹配，提议维度爆炸；(c) 摩擦/接触几何/柔顺的接触不确定性未被显式建模，sim-to-real 鸿沟会静默击穿证书。本轮把两个灵感词统一为「认证灵巧决策-执行」（Certified Dexterous Decision-Execution, CDDE），形成 CADVS-v6（IP-497~500）。本轮自律：**硬门仍为七**，不新增门；把七门从「轨迹谓词」提升为「选项不变量」，并新增**过渡可容许性**（由现有七门派生，非新门）与**任务推进契约**（任务级活性，显式声明非安全门）；执行集关系为「单模式精确退化 + 混合投影嵌套」。

**直觉与动机**：

1. **决策规划 → 把「选技能序列」变成「契约组合」，让离散决策也进入信任边界**。直觉：v5 能证明「这条轨迹安全」，却不能证明「这串决策安全」；两个各自安全的接触模式之间，可能隔着一个会打滑或撞飞的切换。严谨地说，把灵巧任务建模为接触模式图 G=(M,E)，每个技能是**携带契约的选项** o=(pre,post,inv,π,cert)，其中 inv 就是七门在该驻留段的合取，cert 是 v5 证书。计划 P=o_1…o_n 可容许当且仅当契约链式衔接（post_k ⇒ pre_{k+1}）且每条过渡满足**过渡可容许性** A(τ_k)=∧_{i=1}^7 A_i(τ_k)——A_i 分别是七门在「切换瞬间」的派生谓词（物理门管冲量上界、平衡门管切换支撑、覆盖门管下一接触可达与无碰撞走廊、价值门管结局可接受、人因门管切换 veto、末点门管 C0/C1 连续、记忆门管禁用模式），**不引入第八门**。定理 9（混合组合）：各选项已铸证且各过渡可容许 ⇒ 拼接的混合执行已铸证；任一契约失败 ⇒ fail-closed 不执行该切换、转重规划。这把 v5 的定理 6 从「换提议不换门」推进到「换计划不换门」，离散规划器成为可替换提议器。

2. **灵巧操作 → 模式条件化 + 潜空间流，把高维接触提议压到可实时认证的低维**。直觉：多指手 20+ DoF、接触丰富且欠驱动，直接在关节空间采样既慢又难满足力闭合；但灵巧动作的低维结构（抓取协同/协同关节）可以被显式利用。严谨地说，把提议改为**模式条件潜流** π_θ^FM(z|c,σ)，σ 为接触模式（接触集+摩擦状态），z∈R^{d_z}（d_z≈8–12）经协同/解码器 D 映到全维关节轨迹；ODE 只在潜空间积分，门在全维解码轨迹上评估（定理 6 不受影响，因为门仍定义在解码后的轨迹上）。定义**灵巧裕度** δ_dex = min{摩擦锥有符号距离, 关节限位距离, 1/cond(J)}，作为软因子 η_dex 并作为物理门的附加安全边际（复用门，不新增）。这样既保留高维灵巧性，又让在线准入保持在 10 Hz 预览时域。

3. **接触不确定性 → 用 Lipschitz 内近似把 sim-to-real 鸿沟变成可计算的鲁棒裕度**。直觉：灵巧操作对摩擦系数、接触点、质量惯量极其敏感；v5 的「有界扰动」没有接触语义。严谨地说，定义接触不确定集 U=(μ∈[μ_lo,μ_hi], 接触点±ε_c, 质量/惯量±, 时延)，鲁棒门 kc_i^U(x)=∧_{u∈U} kc_i(x,u)；连续最坏情况不可直接算，用 Lipschitz 内近似：若分数 s_i 对 u 的 Lipschitz 常数为 L_i，则 s_i−L_i·rad(U)≥τ_i 是鲁棒通过的充分条件，鲁棒裕度 ρ_i=s_i−L_i·rad(U)−τ_i≥0。定理 10（接触不确定性单调）：U_1⊆U_2 ⇒ Exec^{U_2}⊆Exec^{U_1}；U=∅ 时精确退化为 v5。过渡可容许性同样做鲁棒化，防止「名义可切换、真实打滑」。

**关键洞见**：v5 回答「单模式、任意提议、有界扰动下证书边界是否保持」；v6 回答「当执行是接触模式混合、决策是离散技能序列、且接触参数不确定时，如何让七门边界在**计划层**仍然成立」。七硬门 kc_i 原样保留并被提升为选项不变量 inv_o；本轮新增的只有：接触模式图与契约选项、过渡可容许性 A（派生）、潜空间模式条件流、接触不确定集 U 与鲁棒裕度 ρ、以及**任务推进契约** Φ_prog（任务级活性，显式声明**不是安全门**）。执行集关系为「n=1 且无切换 ⇒ Exec_v6=Exec_v5；一般 ⇒ 混合执行在每模式上的投影 ⊆ Exec_v5^σ，且 U 增大只缩不涨」。

**形式化目标（增量）**：
1. 接触模式图 G=(M,E)；混合执行 H=((σ_1,x_1,d_1),τ_1,…,(σ_n,x_n,d_n))。
2. 契约选项 o=(pre,post,inv,π,cert)，inv=∧_{i=1}^7 kc_i；计划 P=o_1…o_n 可容许 ⇔ 契约链 ∧ 过渡 A(τ_k)。
3. 过渡可容许 A=∧_{i=1}^7 A_i（复用七门语义与阈值，不新增门）。
4. 模式条件潜流 π_θ^FM(z|c,σ)，解码 D:z↦x；灵巧裕度 δ_dex；η_dex=σ(δ_dex−b_dex)。
5. 接触不确定集 U 与鲁棒裕度 ρ_i=s_i−L_i·rad(U)−τ_i；鲁棒过渡 A^U。
6. 任务推进契约 Φ_prog（非安全门）：计划须在时域内使 Φ_prog 下降≥ε_prog。
7. 定理 9（混合组合/精确退化）、定理 10（接触不确定单调）、定理 11（安全-推进分离与退化界）、定理 12（七锚完备性保持）。
8. Exec_v6={H: 每个驻留段∧_i kc_i=1 ∧ 每条过渡 A^U=1}；n=1,无切换 ⇒ Exec_v6=Exec_v5。

**本轮最大风险**：**证书可组合 ≠ 任务有进展**——混合计划可以每一步都通过七门却「安全但无用」（回避所有接触、原地微动、钻门语义空子），而推进性不是安全门、fail-closed 在结构上无法保证它；把「安全认证」误当成「任务成功认证」，是 v6 的新信任根。

### IP-497 HSCK：接触模式图上的契约选项搜索（离散规划层，异步秒级）

```python
@dataclass
class HybridSkillContractKernel:
    """HSCK：把离散决策纳入信任边界。
    定理 9：选项已铸证 + 过渡可容许 ⇒ 拼接执行已铸证；任一失败则 fail-closed 重规划"""
    graph: Any                    # ModeGraph：M 模式，E 边带 guard 与 A 谓词
    options: dict                 # rule_id -> Option(pre, post, inv, pi, cert)
    plan_value: Any = None        # 计划价值/启发式（来自 LMEM-v3 计划宏 M_plan）
    D_max: int = 6
    b: int = 4

    def transition_admissible(self, o_k, o_next, u_set) -> bool:
        # A = ∧_{i=1}^7 A_i：全部复用七门语义与冻结阈值 τ^4（或更紧），不新增门
        a = {
            'phys': impulse_bound(o_k.exit, o_next.entry) <= I_MAX,       # 物理门
            'bal':  zmp_in_support_during_switch(o_k, o_next, S_port),    # 平衡门
            'cov':  reachable_clear_corridor(o_k.exit, o_next.pre),        # 覆盖门
            'val':  outcome_value(o_k.exit, o_next.entry) >= tau4('val'),  # 价值门
            'hick': not human_veto_during_switch(o_k, o_next),             # 人因门
            'ee':   endpoint_c0c1_continuous(o_k.exit, o_next.entry),      # 末点门
            'mem':  o_next.sigma not in forbidden_modes(o_k, o_next),       # 记忆门
        }
        return all(robust_margin_ok(a[i], i, u_set) for i in a)  # 见 CURK

    def plan(self, goal, c_ctx, u_set) -> PlanResult:
        # AND-OR / MCTS：节点=选项，边=可容许过渡；契约剪枝 + 计划宏启发式
        frontier = [(self._start(c_ctx), [self._start(c_ctx)])]
        best, expanded = None, 0
        while frontier:
            o, path = frontier.pop()
            expanded += 1
            if self._satisfies_goal(o.post, goal):
                if self._progress_ok(path):          # 推进契约（非安全门）
                    best = self._best(best, path)
                continue
            if len(path) >= self.D_max:
                continue
            for o_next in self.graph.successors(o):
                if not contract_chain(o.post, o_next.pre):
                    continue                          # 契约不衔接：剪枝
                if not self.transition_admissible(o, o_next, u_set):
                    continue                          # 过渡不可容许：fail-closed 不展开
                frontier.append((o_next, path + [o_next]))
        return PlanResult(ok=best is not None, plan=best, expanded=expanded,
                          reason='CERTIFIED_HYBRID' if best else 'NO_ADMISSIBLE_PLAN')
```

### IP-498 MCLDF：模式条件潜空间灵巧流（连续提议层，10 Hz 预览）

```python
@dataclass
class ModeConditionedLatentDexterousFlow:
    """MCLDF：ODE 只在潜空间积分，门在全维解码轨迹上评估（定理 6 不受影响）"""
    net: Any                      # v_θ(z,t|c,σ)：DiT/Transformer，条件含接触模式
    decoder: Any                  # D: z -> full-DoF joint trajectory（协同/解码）
    d_z: int = 10
    S: int = 8
    K: int = 8

    def propose(self, c, sigma, k=None) -> list:
        zs = randn(k or self.K, self.d_z)
        for s in range(self.S):
            zs = zs + (1.0 / self.S) * self.net(zs, s / self.S, c, sigma)
        return [self.decoder(z) for z in zs]      # 全维关节轨迹，供七门评估

    def dexterity_margin(self, x, sigma) -> float:
        # δ_dex = min(摩擦锥有符号距离, 关节限位距离, 1/cond(J))
        return min(friction_cone_dist(x, sigma), joint_limit_dist(x),
                   1.0 / cond(jacobian(x)))

    def train_loss(self, batch) -> float:
        # 模式条件 rectified flow：x 换成潜码 z1，目标场 z1 - z0
        z0 = randn_like(batch.z1)
        t = rand(batch.B, 1)
        z_t = (1 - t) * z0 + t * batch.z1
        return mse(self.net(z_t, t, batch.c, batch.sigma), batch.z1 - z0)
```

### IP-500 CHA-v6：计划层契约 + 连续认证级联 + 推进契约

```python
@dataclass
class CertifiedHybridAssemblerV6:
    """CHA-v6：七门不变（τ^4 冻结）+ 计划层契约组合 + 鲁棒过渡 + 推进契约"""
    hsc: HybridSkillContractKernel
    mcdf: ModeConditionedLatentDexterousFlow
    curk: ContactUncertaintyRobustificationKernel
    v5: EvidenceForgingAssemblerV5       # 复用 scf/msrg/hic/eek/vack/bck 全套

    def select(self, state, t_now, goal, context) -> tuple[bool, HybridPlan | None, str]:
        u_set = estimate_contact_uncertainty(context)          # 由接触辨识/先验给出
        pr = self.hsc.plan(goal, context, u_set)               # 离散规划（异步秒级）
        if not pr.ok:
            return False, None, 'NO_ADMISSIBLE_PLAN'           # fail-closed：安全停/重规划
        o = pr.plan[0]
        cands = self.mcdf.propose(context, o.sigma, self.mcdf.K)   # 潜流 + 解码
        # 廉价门 + 鲁棒门 + 灵巧边际
        cheap = [x for x in cands
                 if self._cheap_gates(x, o) and self.curk.robust_gate(x, context, o.sigma)
                 and self.mcdf.dexterity_margin(x, o.sigma) >= 0]
        if not cheap:
            return self._fallback_v5(context, o)               # 回退 v5 单模式提议
        best = self._cascade_v5(cheap, o, context)             # VACK -> BCK -> 边际最大
        if best is None:
            return False, None, 'MODE_REJECTED'
        bundle = CertBundle(options=pr.plan, transitions=self._transition_certs(pr.plan, u_set))
        return True, HybridPlan(plan=pr.plan, first=best, bundle=bundle), 'FORGED_CDDE'

    def ecs_v6(self, ecs_v5, dex_margin, rho_plan) -> float:
        eta_dex  = sigmoid(dex_margin - b_dex)
        eta_plan = sigmoid(rho_plan - b_plan)
        return ecs_v5 * eta_dex * eta_plan                     # 仅排序，不做安全裁决
```

## 4. 正确性论证（增量更新）

### 引理 45（契约链组合的可靠性）

**陈述**：设计划 P=o_1…o_n 满足 (i) 每段驻留满足 inv_{o_k}（即七门全过），(ii) 相邻契约链 post(o_k) ⇒ pre(o_{k+1})，(iii) 每过渡满足 A(τ_k)=∧_{i=1}^7 A_i。则拼接的混合执行 H 在每个驻留段满足七门，且在每个切换瞬间七门的派生谓词成立。

**证明**：驻留段由 (i) 直接给出；切换瞬间由 (iii) 逐门给出，而 A_i 是第 i 门在同一冻结阈值下对切换瞬间的实例化（物理/平衡/覆盖/价值/人因/末点/记忆）。对段数归纳即得。∎

### 引理 46（Lipschitz 内近似的可靠性）

**陈述**：若分数 s_i(x,u) 对 u 是 L_i-Lipschitz，且 s_i(x,u_0)−L_i·rad(U) ≥ τ_i，则 ∀u∈U：s_i(x,u) ≥ τ_i。

**证明**：|s_i(x,u)−s_i(x,u_0)| ≤ L_i‖u−u_0‖ ≤ L_i·rad(U)。故 s_i(x,u) ≥ s_i(x,u_0)−L_i·rad(U) ≥ τ_i。∎
**诚实边界**：该近似是**保守内近似**（充分不必要）——可能拒绝掉真正鲁棒的 x（误拒），但绝不把不鲁棒的 x 误判为鲁棒（无误接受）。这正符合 fail-closed 取向。

### 引理 47（潜空间解码不引入假接受）

**陈述**：门在全维解码轨迹 D(z) 上评估，故 supp(D∘π_θ^FM) ⊆ 全维轨迹空间；潜空间提议只限制「尝试通过门的分布」，不改变门的谓词。

**证明**：由定理 6（证书不变性）直接推得；解码是可测映射，pushforward 只影响提议支撑。∎

### 定理 9（混合组合与精确退化）

**陈述**：在 v4 假设 (B1)~(B6)、v5 假设 (B7) 及新增 (B8) 契约 guard 可靠、(B9) A_i 由第 i 门在同一冻结阈值派生下：
(i) 若每个选项已铸证且每条过渡 A^U-可容许，则拼接混合执行 H ∈ Exec_v6（已铸证）；
(ii) n=1 且无过渡、U=∅ ⇒ Exec_v6 = Exec_v5（精确退化）；
(iii) 任一契约/过渡失败 ⇒ fail-closed：不执行该切换（安全停或重规划），不存在「未认证切换被执行」的路径；
(iv) 阈值更紧或 U 更大 ⇒ Exec_v6 只缩不涨。

**证明**：(i) 引理 45 + 引理 46；(ii) 单段无过渡时 A 为空合取，U=∅ 时 ρ_i=s_i−τ_i，退化为 v5 七门；(iii) 由 HSCK.plan 与 select 的短路逻辑（不可容许即不展开/不执行）；(iv) 引理 46 单调性 + 定理 5/10。∎

### 定理 10（接触不确定性单调）

**陈述**：U_1⊆U_2 ⇒ Exec_v6^{U_2} ⊆ Exec_v6^{U_1}；U=∅ ⇒ Exec_v6^{U}=Exec_v5。且过渡鲁棒化 A^U 随 U 增大而单调收紧。

**证明**：rad(U) 单调增 ⇒ ρ_i 单调减 ⇒ 通过集单调缩；引理 46 保证内近似可靠。∎

### 定理 11（安全-推进分离与退化界）——本轮诚实核心

**陈述**：(i) 存在任务目标与已铸证的混合计划，使每段七门全过、每过渡可容许，但任务推进势 Φ_prog 不下降（「安全但无用」：回避接触、原地微动、退化循环）。故**任何 fail-closed 安全门都无法保证推进**。(ii) 引入显式推进契约 Φ_prog（任务级活性，非安全门）后，接受集 Exec_v6^{prog} ⊆ Exec_v6 且其中退化计划比例为 0（按构造）。(iii) 但推进契约可被博弈（选择容易满足 Φ_prog 却不真正完成任务的动作），其博弈率只有红队回归集上的**经验上界**，无结构性根除保证。

**证明**：(i) 构造：单模式内保持静止即满足覆盖/物理/平衡/末点/价值（无负价值）/记忆/人因（无 veto），但 Φ_prog 不变；反例存在即证。(ii) 由 plan() 中 progress_ok 过滤，构造性成立。(iii) Φ_prog 是任务层近似，其与真实任务成功的偏差无先验界，只能经验测量。∎

### 定理 12（七锚完备性保持）

**陈述**：v6 不增删硬锚：HSCK 是七门之上的**决策层组合**，A 是七门的派生（非新锚），MCLDF 是提议器升级，CURK 是既有门的鲁棒化，Φ_prog 明确位于安全门之外。故 v4 定理 4 的七锚完备性保持，且 Exec_v6 在各模式上的投影 ⊆ Exec_v5^σ。

**证明**：锚点集合不变 + A 的每个分量都引用对应门的冻结阈值 + 定理 5/9/10 的单调性。∎

**诚实声明**：(i) 接触不确定集 U 与 Lipschitz 常数 L_i 是 v6 的新信任根，漏项/低估会让鲁棒证书静默失效（fail-closed 只防已知不确定）；(ii) 过渡可容许性依赖冲量/接触切换模型，模型误差可导致「名义可切换、真实失稳」；(iii) 安全与推进在结构上可分离，任务成功仍需任务级验证与人工抽检；(iv) 高维潜空间可能漏掉某些灵巧模式，覆盖率难先验保证；(v) 计划层记忆固化仍继承 v5 的自指博弈风险（R57）。

## 7. 本轮最大风险（最终确认）

**一句话**：**证书可组合 ≠ 任务有进展**——混合计划可以每一步都通过七门却「安全但无用」（回避所有接触、原地微动、钻门语义空子），而推进性不是安全门、fail-closed 在结构上无法保证它；把「安全认证」误当成「任务成功认证」，是 v6 的新信任根。
