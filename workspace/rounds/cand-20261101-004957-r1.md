# 第 13 轮（新灵感循环第 1 轮）· BRACE：把双臂从「两条独立的胳膊」变成「一对差分执行器」

> 检索/复核日期：**2026-11-01（UTC）**。赛事身份不变：宇树 **UniBot 世界挑战赛**（G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API）。本轮是灵感循环第 1 轮，三个词是「鲁棒性」「社会影响」「双臂协调」。本轮不推倒第 10 轮 FACT-VLA、第 11 轮 GEO-RESIDUAL、第 12 轮 CHUNK-SERVO；相反，它把 CHUNK-SERVO 从「两条独立的单臂绝对位姿伺服」推进到「双臂相对帧协调 + 鲁棒仲裁 + 社会安全滤波」。

## 0. 先给结论：最后 3 厘米不只是「看不清」，还是「两个臂没有共同的误差定义」

第 12 轮的 CHUNK-SERVO 做对了一件关键的事：把 30 步开环 chunk 切成 5 步闭环，把反馈周期从 1 秒压到 167 毫秒；再用 33k 成功演示检索「目标→夹爪」相对位姿，用数字孪生标定延迟和增益。它的核心仍是**单臂**的：左臂和右臂各自追自己的绝对位姿，伺服误差定义在 base 系。

但在 32 个任务里，至少 **17 个**出现插入、拔出、拧、拉拉链、合盖、倒、夹等接触动词；按「终局是否需要毫米级对齐」先验地把 **19 个**列为 A 档。其中一大半不是「左臂偏了 2mm、右臂也偏了 2mm」，而是「**右臂相对左臂/物体偏了 2mm**」。绝对位姿误差里有两类成分：

- **共模成分**：基座运动、相机外参漂移、桌面整体移动、双臂共同的标定偏差；
- **差模成分**：两臂之间的相对位姿误差、锚定臂与物体之间的抓取变换误差。

任务真正关心的是差模；共模应该被拒绝，而不是被两条独立的绝对伺服同时「追」回去。更糟的是，当一条臂夹住物体（锚定臂）时，它不应该再被一个旧的绝对目标拽走；它应该成为另一条臂的机械参考。**这是第 12 轮没有利用的物理约束。**

所以本轮的押注是 **BRACE**（Bimanual Relative-frame Arbitration and Coordinated Execution，双臂相对帧仲裁与协调执行）：

> 继续用 CHUNK-SERVO 做 30 步规划 + 5 步执行；把左右臂看成一对**差分执行器**：锚定臂提供机械参考，操作臂在锚定臂/被抓物体的相对帧里做伺服；用角色仲裁与切换处理单臂失效；用控制屏障函数把人的安全距离变成硬约束；用 33k 演示检索双臂相对目标。

一句话：**把「两条胳膊各自追绝对位姿」改成「一条胳膊锚定，另一条在相对帧里追差模」；把「检测到人再重规划」改成「人的安全距离是硬约束，控制屏障函数直接改写动作」。**

三个灵感词怎么落到方案里：

| 灵感词 | 落到哪里 | 不做什么 |
|---|---|---|
| **鲁棒性** | 共模不变性、锚定位姿噪声感知增益、角色仲裁/切换、单臂失效回退、任意延迟的闭式增益界 | 不假设相对帧万能；不把锚定臂抓不稳的任务硬套 |
| **社会影响** | 把 64/320 次人为干扰 trial 当成一等目标；CBF 安全滤波；可读的停-退-等-再接近；社会成本指标；数据/算力可及性 | 不做第二个学习式人体检测器；不把安全当软惩罚；不声称零风险 |
| **双臂协调** | 相对帧伺服、双臂相对目标库、锚定臂/操作臂角色、对称模式、耦合增益 | 不做 32 个任务各一个策略；不做需要力/触觉的闭环（API 没有） |

## 1. 直觉：双臂是一对差分执行器，不是两条并联的胳膊

把两条臂想象成差分放大器：

```text
绝对位姿误差 = 共模（基座动、相机漂、桌面整体移） + 差模（两臂相对位姿/抓取变换）
任务误差     ≈ 差模
相对帧伺服   = 只放大差模，拒绝共模
```

当左臂夹住杯架、右臂挂杯子时，右臂的目标不是「base 系里的某个绝对点」，而是「相对左臂夹爪的某个位姿」。左臂被杯子/杯架约束住，它的位姿由物体决定；右臂只需要在左臂的坐标系里走完最后 3 厘米。共模的基座晃动、相机外参漂移、桌面整体移动，在 `T_AB = T_A^{-1} T_B` 里会同时作用在 `T_A` 和 `T_B` 上，因而抵消。**这不是更准的视觉，而是换了一个误差定义。**

但这个直觉有一个诚实的边界：相对帧把共模误差换成了**锚定臂/抓取变换的噪声**。如果锚定臂抓不稳、或者物体相对夹爪滑移，相对帧的噪声底就会吃掉收益。所以本轮必须同时设计：

1. **锚定臂选择**：谁的抓取置信度高、谁更可见、谁更接近物体，谁做锚定；
2. **切换**：锚定臂失效时，另一条臂接管，或者退回独立伺服；
3. **噪声门**：锚定位姿/抓取变换的协方差超过阈值时，不用高增益相对伺服，退回 CHUNK-SERVO 或只做 PBVS 粗对齐。

这三点就是「鲁棒性」在算法里的具体位置，而不是一句形容词。

## 2. 为什么现在：四个事实

### 2.1 任务结构：双臂接触是主战场，不是少数特例

沿用第 12 轮对 32 个任务的统计：17/32 有接触动词，19/32 是 A 档。进一步按「能否建立锚定臂」分：

- **锚定-操作（anchor-actor）**：一只手扶住/夹住受器，另一只手插入、挂、拧、拉、叠。典型：HangCup、PlugInEthernet、DisconnectEthernet、Unlock、ZipUp、PackBag、ArrangeTestTubes、OpenPillBottle、PaperCupStacking、StackBowls、StackCups、PlugCharger、ToolboxStorage、StoreRacket、StoreEarphones、PackPhone、OrganizePencilCase、SyringeWaterTransfer、OrganizeStationery。这是本轮的主战场。
- **对称协调（symmetric）**：两只手同时移动/折叠，物体可能变形。典型：FoldTowel；部分 PackDoll/PlacePhotoFrame 也可能。相对帧仍可用，但刚体假设变弱，需要降增益。
- **独立（independent）**：两只手各做各的子任务，没有稳定的相对目标。典型：FruitCollection、FruitSorting、ColorArrangement、ConveyorSorting。这些任务上 BRACE 应该是 no-op，直接沿用 CHUNK-SERVO。

这张分类是**先验**，不是实测；单任务通道会更新它。但它足以说明：双臂协调不是全局替换，而是一个**按任务/按相位启用**的层。

### 2.2 人的干扰占 20%，而第 12 轮只有「检测→停→重规划」

官方规则里，每个任务 10 次中有 2 次是人为干扰，占 20%。第 12 轮的 GEO-RESIDUAL 能检测「机器人动作解释不了的三维残差」，然后停、重定位、重规划。但这仍然是**事后**的：人已经进入工作空间，机器人可能已经靠近、已经加速、已经夹着物体。社会影响在本赛事里最直接的落点，就是这 64 次 trial：

- 人的手进入工作空间时，机器人是否能在安全距离外停住？
- 人把物体拿走/移动后，机器人是否能可读地退回、等待、再接近？
- 机器人是否会在人离开后突然加速、做出不可预测的动作？
- 这些行为是否以「不牺牲正常 trial 成功率」为代价？

所以本轮把安全从「检测后重规划」升级为「**控制屏障函数硬约束**」：人的占据体积是一个安全集，控制律在每一块 5 步动作上投影到安全集内；如果投影不可行，就零速保持。这不是第二个模型，是一个确定性的二次规划（QP）。

### 2.3 接口允许相对帧：两臂 EE 位姿 30Hz 可得，相对雅可比很便宜

挑战赛 API 给左右 EE 位姿 `[6]`（xyz+rpy，base 系）和双臂关节 `[7]`。相对位姿 `T_AB = T_A^{-1} T_B` 可以直接由本体感觉算出来，不需要视觉，也不需要第二个模型。相对雅可比 `J_rel = [-Ad(T_AB^{-1}) J_A^b, J_B^b]` 是 6×14 的常数级运算。换句话说：**相对帧的「传感器」是本体感觉 + 已知运动学，带宽高、延迟低、免费。** 视觉只在需要物体/受器位姿时介入。

这是本轮相比「再加一个视觉模型」最大的性价比：双臂协调的很多信息本来就在关节里，只是第 12 轮没有用。

### 2.4 本轮的玩具实验已经暴露了噪声底

我本轮先做了一个轻量的运动学玩具实验（不是物理仿真，不是真机）：

- 在 3cm/10° 的共模扰动下，独立绝对伺服的平均相对误差约 **29mm/9.6°**，在 2mm/1° 容差下 **0/500（每档）** 成功；
- 相对帧伺服在无噪声时误差为 **0**（共模不变性）；
- 给锚定/抓取变换加 0.5mm/0.1° 噪声，相对误差约 **0.79mm/0.16°**，2mm/1° 容差下 **498/500** 成功；
- 噪声升到 1mm/0.2°，成功率 **362/500**；升到 2mm/0.4°，成功率 **93/500**。

这不是真机成功率，但它把工程目标说清楚了：**相对帧的收益不是免费的，它的噪声底由锚定臂/抓取变换决定；要把成功率做上去，锚定位姿/抓取变换必须做到亚毫米、0.1° 量级。** 这也直接决定了本轮的门 G0/G2：如果做不到，就退回独立伺服，不要硬套相对帧。

## 3. 形式化核心（完整推导在产物区）

### 3.1 相对目标与相对误差

记锚定臂 A、操作臂 B 的 EE 位姿为 `T_A, T_B ∈ SE(3)`，相对位姿 `T_AB = T_A^{-1} T_B`。从成功演示检索到的期望相对位姿为 `T_AB*`。相对误差：

```text
e = log( T_AB^{-1} T_AB* ) ∈ R^6.
```

期望操作臂位姿：`T_B^d = T_A T_AB*`。注意：**目标定义在锚定臂的当前帧里，而不是 base 系里**。这是共模不变性的来源。

### 3.2 共模不变性（鲁棒性的形式化）

若存在共同变换 `G ∈ SE(3)` 同时作用于两臂：

```text
T_A' = G T_A,  T_B' = G T_B
⇒ T_AB' = (G T_A)^{-1}(G T_B) = T_A^{-1} T_B = T_AB
⇒ e' = e.
```

所以基座运动、相机外参漂移、桌面整体移动（只要目标也随锚定臂/物体一起动）不会改变相对误差。反过来，独立绝对伺服会把这些共模当成误差去追，产生 29mm/9.6° 量级的相对偏差。这是本轮最硬的一条「为什么相对帧更鲁棒」的论证。

### 3.3 相对雅可比

设 `V_a = T_a^{-1} \dot T_a` 为臂 a 的 body twist，`J_a^b` 为 body Jacobian。对 `T = T_A^{-1} T_B` 求导：

```text
V_T = V_B - Ad(T^{-1}) V_A
⇒ J_rel = [ -Ad(T^{-1}) J_A^b,  J_B^b ] ∈ R^{6×14}.
```

控制律 `V_T = -K e`，再把相对修正 compose 到操作臂的绝对目标上。一个漂亮的实现细节：若 `T_AB* = T_AB exp(e)`，则

```text
T_B^cmd = T_A T_AB exp(κ e) = T_B exp(κ e),
```

也就是说，**操作臂的绝对指令可以只由它自己的当前位姿和相对误差右乘得到**；锚定臂的绝对位姿不需要被控制，它可以保持柔顺/夹持。这正是「锚定臂是机械参考」的数学形式。

### 3.4 任意延迟的闭式稳定域

第 12 轮只分析了 0/1 块延迟。本轮把它推到任意块延迟 d：

```text
e_{k+1} = e_k - a e_{k-d},  a = K H_c.
P_d(z) = z^{d+1} - z^d + a.
```

在单位圆边界 `z=e^{iθ}` 上，`a` 为实正数的相位条件给出最小的临界值：

```text
a_d* = 2 sin( π / (2(2d+1)) ).
```

数值根轨迹在 d=0..10 上与闭式完全一致（见产物区表 C）。这条结果的价值不是「又一个公式」，而是给了一个**可执行的增益调度**：

```text
d = ceil( τ f_c / H_c )
K_max = a_d* / H_c
```

如果 RTT 高、chunk 长，增益必须按这个界降档。第 12 轮说「5 步 chunk 把反馈周期降到 167ms」是对的；但它没有说「5 步 chunk 不改变延迟稳定域」。本轮补上这一刀：**相对帧拒绝共模，但不拒绝延迟；延迟仍然要降增益。**

### 3.5 社会安全：控制屏障函数

人的占据体积 `H_t` 由头双目 + 帧差/运动分割 + 机器人自运动补偿得到（确定性，不用学习式人体检测器）。定义安全裕度：

```text
h(x) = dist(x, H_t) - δ_s,   C = { x : h(x) ≥ 0 }.
```

对每个机械臂胶囊/末端，解一个小 QP（严格版在关节速度空间用 `J_link` 建约束；EE 速度空间是近似）：

```text
u* = argmin ||u - u_cmd||²
     s.t. ∇h(x)ᵀ u + α h(x) ≥ 0,  ||u|| ≤ v_max.
```

单约束时有闭式投影；多约束时用 active-set。若 QP 不可行，`u*=0`，进入 `SAFE_HOLD`。由 CBF 的前向不变性，若初始 `h≥0` 且约束每步成立，则 `h(t)≥0` 对所有 t 成立（完美状态估计下；有估计误差时把 `δ_s` 加上误差上界）。这把「安全」从软惩罚变成了**硬约束**：VLA/伺服可以决定去哪，但不能决定穿过人的安全区。

### 3.6 角色仲裁与切换

锚定臂不是固定的。定义锚定分数：

```text
s_a = c_a · (1 + v_a) · (1 + m_a)    # c_a < c_min 时 s_a = 0
```

`c_a` 是抓取置信度（夹爪闭合 + 物体随动残差），`v_a` 是受器/物体可见度，`m_a` 是可操作度。`c_a` 是门控：没抓住的臂不能当锚定臂；`v_a/m_a` 只在两臂都抓住时打破平局。选 `s_a` 高者为锚定臂。若另一臂的分数连续 `K_h` 块高出 `Δ_h`，且相对位姿协方差 `tr(Σ) ≤ σ_h`，则切换；切换时先 `SAFE_HOLD` 一小段，再重定位。切换失败或锚定臂失效 → 单臂模式 → 安全保持。这条状态机是「鲁棒性」的第二个落点：**不是假设锚定臂永远可靠，而是让系统在它不可靠时优雅降级。**

## 4. 算法：BRACE 的四个模块

```text
┌────────────────────────────────────────────────────────────┐
│  CHUNK-SERVO 底座（第 12 轮，保留）                         │
│  30 步 VLA 规划 · 5 步执行 · 演示检索 · 数字孪生 · 单任务通道 │
└──────────────────────────┬─────────────────────────────────┘
                           │
        ┌──────────────────┼──────────────────┐
        ▼                  ▼                  ▼
┌───────────────┐  ┌───────────────┐  ┌───────────────┐
│ BGR 双臂目标库 │  │ RDS 相对帧伺服 │  │ RAS 角色仲裁   │
│ T_AB*, T_AO*  │  │ e, J_rel, K_t │  │ 锚定/切换/回退 │
└───────┬───────┘  └───────┬───────┘  └───────┬───────┘
        └──────────────────┼──────────────────┘
                           ▼
                  ┌─────────────────┐
                  │ SSF 社会安全滤波 │
                  │ CBF-QP · 可读恢复 │
                  └─────────────────┘
```

1. **BGR（Bimanual Goal Retrieval）**：在 DG-KEYFRAME 上扩展。每个关键帧不只存「受器→夹爪」，还存「锚定臂→操作臂」`T_AB*`、「锚定臂→物体」`T_AO*`、「物体→操作臂」`T_OB*` 和相位/描述子/置信度。检索时先按任务/相位过滤，再按相对位姿先验和描述子重打分。这样位置泛化、人为干扰、未见物品都能用同一个目标库处理。
2. **RDS（Relative-frame Dual-arm Servo）**：每个 5 步块算一次 `e`，用 `J_rel` 做差模修正；`K_t` 按 `tr(Σ_t)` 降档；`T_B^cmd = T_B exp(κ e)`；锚定臂保持或做对称分配。接触段法向缩幅、切向保留（沿用 GEO-RESIDUAL 的 `d_t, n_t, r_static, r_grasp`）。
3. **RAS（Role Arbitration and Switching）**：锚定分数、切换条件、单臂回退、安全保持。切换不是「换一个策略」，而是换一个参考系和角色；VLA 仍是唯一学习模型。
4. **SSF（Socially-aware Safety Filter）**：人的占据体积 + CBF-QP + 可读恢复（停→退→等→再接近）。安全是硬约束；恢复动作限速、限幅、有停留时间，避免「突然加速」这种社会不可接受的行为。

## 5. 与第 10/11/12 轮的关系：保留、升级、剪枝

**保留**：

- FACT-VLA 的相位化 BC、CAC 柔顺执行、EGP 证据门控；
- GEO-RESIDUAL 的动作条件化残差、米制表面距离、编辑检测；
- CHUNK-SERVO 的 30 步规划 + 5 步执行、DG-KEYFRAME、数字孪生、单任务通道、竞赛组合。

**升级**：

- 从「两条独立绝对伺服」→「锚定臂相对帧 + 差模伺服」；
- 从「单臂目标」→「双臂相对目标 `T_AB*, T_AO*, T_OB*`」；
- 从「检测到编辑再重规划」→「CBF 硬安全约束 + 可读恢复」；
- 从「固定角色」→「锚定分数 + 切换 + 单臂回退」；
- 从「0/1 块延迟分析」→「任意 d 的闭式稳定界 `a_d*`」。

**剪枝**：

- 不做第二个学习模型/人体检测器/残差策略（单模型风险）；
- 不做完整 sim-to-real 策略训练（数字孪生只做控制器风洞）；
- 不做力/触觉闭环（API 没有）；
- 不做 30Hz 广域网伺服（RTT 不允许；继续 5 步 chunk）；
- 不做 6D 物体位姿网络（透明/变形不可靠；用相对帧 + 局部特征）；
- 不做 32 个任务各一个策略（规则禁止，且不泛化）；
- 不把预览榜单的任务排名当实测难度（第 12 轮已证伪）。

## 7. 竞赛策略：先做「锚定-操作」的 5 个任务，不要一次铺 19 个

单任务通道优先顺序（先验）：

1. **PlugInEthernet**：最纯的锚定-插入，目标几何清楚，适合验证 `T_AB*` 和 CBF；
2. **HangCup**：挂杯，接触短、失败集中在最后 3 厘米，适合验证相对帧；
3. **ZipUp**：拉链，锚定臂必须稳住布料，适合验证「锚定臂不追绝对目标」；
4. **Unlock**：开锁，旋转+插入，适合验证相对旋转误差和延迟；
5. **FoldTowel**：变形任务，作为负对照；如果相对帧让它变差，说明模式选择/增益有问题。

每个任务先 5 次 A/B（BRACE off/on），配对同初始条件；通过标准 ≥3/5 任务 +10pp，FoldTowel 不回归 >5pp，零碰撞。然后再扫 `H_c ∈ {3,5,8}`、`κ ∈ {0.3,0.6,1.0}`、锚定噪声门。最后才跑 32×10。

收益算术（保守）：

- 如果 10 个锚定-操作任务各 +10pp：`10/32 × 10 = +3.1pp`；
- 人为干扰轴 +10pp：`0.2 × 10 = +2pp`；
- 合计约 **+5pp**；考虑到锚定噪声和真实接触动力学，保守区间 **+2–5pp**；
- 如果只有 5 个任务 +10pp：`+1.6pp + 2pp = +3.6pp`；
- 如果锚定噪声只能到 2mm/0.4°，相对帧可能打不过 VLA，退回独立伺服；此时只剩安全滤波的收益（human 轴 +1–2pp）。

不要承诺 +10pp 全局。BRACE 的收益是**条件收益**：锚定臂抓得稳、锚定位姿测得准、任务真的是锚定-操作，三者同时成立才有 +10pp 量级；否则它会优雅地退化成 CHUNK-SERVO + 安全滤波。

## 8. 社会影响：不是赛后声明，是 64 次 trial 的得分项

- **直接**：64/320 次人为干扰 trial。CBF 硬约束 + 可读恢复直接针对这 64 次；指标是碰撞数、最小人机距离、恢复时间、人类接管率。
- **间接**：BRACE 不需要新模型、不需要新数据采集、伺服/安全滤波在 CPU 上跑；它降低了小团队复现的门槛，也降低了算力和数据的环境成本。相对雅可比、CBF、检索都是确定性的，可审计（若描述子用 VLA 同一 checkpoint 的 encoder，仍属单模型）。
- **风险**：自动化可能影响桌面操作岗位；人体感知涉及隐私；安全滤波可能让人过度信任。缓解：只做深度/运动分割、不做身份识别、不上传图像；保守安全裕度；人在环；分阶段部署；在报告中写影响声明。
- **设计原则**：安全是硬约束，不是软惩罚；CBF 可以覆盖 VLA/伺服指令；但 CBF 不是机械安全或法规合规的替代品。

## 9. 一句话押注与最大风险

**押注**：用 CHUNK-SERVO 做规划与执行，用锚定臂的相对帧把共模误差变成可拒绝的差模，用角色仲裁处理单臂失效，用控制屏障函数把人的安全距离变成硬约束——在不新增学习模型的前提下，把双臂任务的成功率、鲁棒性和人机共存安全性同时往前推一小步。

**最大风险**：如果锚定臂在多数任务上抓不稳、锚定位姿/抓取变换噪声到不了亚毫米/0.1°，相对帧的收益会被噪声吃掉，BRACE 就退化成「CHUNK-SERVO + 一个保守安全滤波器」，双臂协调的复杂度换不来足够的分数。

## 1. 问题诊断：绝对帧在双臂任务上的三个失效

### 1.1 共模误差被当成任务误差

设左右臂 EE 位姿为 `T_L, T_R`，任务真正关心的是相对位姿 `T_LR = T_L^{-1} T_R` 或物体相对位姿。若存在共同变换 `G`（基座运动、相机外参漂移、桌面整体移动），绝对位姿变成 `G T_L, G T_R`，但相对位姿不变。独立绝对伺服会把 `G` 当成误差去追，结果是：

- 两臂同时被拽向旧绝对目标；如果锚定臂已经夹住物体，它会在物体上施加不必要的作用力/位移；
- 如果物体随基座/桌面一起动，旧绝对目标是错的，追回去反而破坏相对对齐；
- 视觉标定、基座里程计、桌面位置误差都以共模形式进入，直接污染最后 3 厘米。

第 12 轮用演示检索的相对目标缓解了「目标」层面的共模，但**执行层**仍是两条独立的绝对伺服；目标相对、执行绝对，两者不一致。

### 1.2 没有角色：锚定臂和操作臂被同等对待

在 HangCup、PlugInEthernet、ZipUp、Unlock、PackBag 这类任务里，一条臂夹住受器/物体，另一条臂做插入/挂/拉/拧。锚定臂的职责是**保持物体稳定**，不是追一个旧的绝对位姿。第 12 轮没有显式的锚定/操作角色，也没有：

- 锚定臂抓取置信度的估计；
- 锚定臂失效时的切换；
- 单臂回退；
- 对称模式（两手同时动）与锚定-操作模式的区分。

结果是：当锚定臂滑移、遮挡、或被人碰了一下时，系统没有「谁来接管」的语义，只能等下一个 chunk 或 VLA 重规划。

### 1.3 人的安全不是硬约束

第 12 轮的 GEO-RESIDUAL 能检测「机器人动作解释不了的三维残差」，然后停、重定位、重规划。但这是**事后**的：人已经进入工作空间，机器人可能已经靠近、已经加速、已经夹着物体。规则里每个任务 10 次有 2 次人为干扰，占 20%；这 64 次 trial 是社会影响最直接的落点。安全如果是软惩罚，优化器会在「成功率」和「安全」之间做交易；本轮把它变成硬约束。

### 1.4 第 12 轮的三处不足（本轮要补的）

| 不足 | 第 12 轮现状 | BRACE 的补法 |
|---|---|---|
| 误差定义 | 每臂绝对位姿误差 | 锚定臂相对帧误差 `e = log(T_AB^{-1}T_AB*)` |
| 角色 | 固定左/右臂各自追目标 | 锚定分数 + 切换 + 单臂回退 |
| 安全 | 检测→停→重规划（事后） | CBF-QP 硬约束 + 可读恢复（事前/事中） |
| 延迟 | 0/1 块稳定域 | 任意 d 的闭式 `a_d* = 2 sin(π/(2(2d+1)))` |
| 目标 | 受器→夹爪 | 双臂相对目标 `T_AB*, T_AO*, T_OB*` |

### 2.2 帧层级

BRACE 不只用一种「相对帧」。定义四个候选帧：

| 帧 | 定义 | 期望操作臂位姿 | 误差来源 | 适用 |
|---|---|---|---|---|
| `F0` base | 绝对位姿 | `T_B*` | 共模 + 差模 | 基线；不推荐 |
| `F1` 锚定臂 | `T_A` | `T_A T_AB*` | 锚定位姿/抓取变换 | 编队保持、锚定-操作 |
| `F2` 被抓物体 | `T_A \hat T_AO` | `T_A \hat T_AO T_OB*` | 抓取变换 `\hat T_AO` | 任务对齐（推荐） |
| `F3` 视觉目标 | `\hat T_O` | `\hat T_O T_OB*` | 视觉位姿 | 重定位、人干扰后 |

选择规则：

```text
F* = argmin_F [ tr(Σ_F) + λ_F cost_F ]
```

- `F1` 的本体位姿来自关节编码器，带宽高、延迟低；但物体相对锚定臂的抓取变换可能滑移。
- `F2` 把抓取变换显式建模；`\hat T_AO` 可以离线标定，也可以用夹爪闭合/物体随动残差在线更新。
- `F3` 在物体被移动、锚定臂没抓住、或人把物体拿走时使用；它依赖视觉，噪声最大，但能重新定位。
- `F0` 只在所有相对帧都不可辨识时回退，且必须降增益。

共模不变性对 `F1/F2` 成立（目标随锚定臂/物体一起动）；`F3` 依赖视觉重新估计，不再是严格不变，但可以用第 11 轮的编辑检测触发。

### 2.3 共模扰动

**定义 1（共模扰动）**。`G ∈ SE(3)` 是共模的，若

```text
T_A' = G T_A,   T_B' = G T_B,   T_AB*' = T_AB*.
```

即两臂和相对目标一起被 `G` 变换。若目标定义在锚定臂/物体帧里，`T_AB*` 不变。

**命题 1（共模不变性）**。在定义 1 下，`T_AB' = T_AB`，`e' = e`。

证明：

```text
T_AB' = (G T_A)^{-1}(G T_B) = T_A^{-1}G^{-1}G T_B = T_A^{-1}T_B = T_AB.
```

因此 `e' = log(T_AB'^{-1}T_AB*') = log(T_AB^{-1}T_AB*) = e`。∎

**推论 1**。若任务只关心相对位姿，且目标定义在锚定臂/物体帧里，则共模扰动不改变相对误差。独立绝对伺服在同样扰动下会把 `G` 当成误差，产生与 `G` 同量级的相对偏差（共轭后）；这就是第 12 轮在基座/桌面整体移动下的结构性弱点。

**注意**：命题 1 保护的是共模，不保护差模。锚定臂滑移、抓取变换误差、操作臂标定误差仍然是差模，必须靠 `Σ_t` 增益降档、切换、回退处理。

### 2.4 相对 Jacobian

设 `V_a = T_a^{-1}\dot T_a` 为臂 a 的 body twist，`J_a^b` 为 body Jacobian，`V_a = J_a^b \dot q_a`。对 `T = T_A^{-1}T_B` 求导：

```text
\dot T = -T_A^{-1}\dot T_A T_A^{-1}T_B + T_A^{-1}\dot T_B
      = -V_A^\wedge T + T V_B^\wedge.
```

于是

```text
V_T = T^{-1}\dot T = -Ad(T^{-1})V_A + V_B.
```

代入 `V_a = J_a^b \dot q_a`：

```text
V_T = [ -Ad(T^{-1})J_A^b,  J_B^b ] [\dot q_A; \dot q_B]
    = J_rel [\dot q_A; \dot q_B].
```

`sympy`/数值校验时注意：`Ad(T^{-1})` 是 6×6 伴随；若实现用 spatial Jacobian，需要换成对应的 `Ad` 形式，二者等价但不要混用。

### 2.5 角色与切换

**定义 2（锚定分数）**。

```text
s_a = c_a · (1 + v_a) · (1 + m_a)    # c_a < c_min 时 s_a = 0
```

- `c_a ∈ [0,1]`：抓取置信度。可由夹爪闭合量、`r_grasp`（物体随夹爪刚性运动残差，第 11 轮）、以及物体在腕部图中的特征跟踪稳定性组合。
- `v_a ∈ [0,1]`：受器/物体在头部双目或腕部相机中的可见比例。
- `m_a ∈ [0,1]`：归一化可操作度，例如 `σ_min(J_a)/σ_min^0`。

选 `A = argmax_a s_a`，`B = other`。若 `s_A = 0`（即 `c_A < c_min`），不进入锚定-操作模式。`c_a` 是门控，避免把「没抓住但看得见」的臂选成锚定臂；`v_a/m_a` 只在两臂都抓住时打破平局。

**定义 3（切换条件）**。满足以下三条时允许切换锚定臂：

1. `s_B - s_A > Δ_h` 连续 `K_h` 个 chunk；
2. `tr(Σ_t) ≤ σ_h`（当前相对位姿/抓取变换可辨识）；
3. 人的安全集允许切换动作（CBF 可行）。

切换流程：`SAFE_HOLD`（`T_h` 毫秒）→ 重定位 → 交换 A/B → 以保守增益恢复。任一条不满足，保持当前锚定；若锚定置信度低于 `c_min`，进入单臂模式或 `SAFE_HOLD`。

### 2.6 安全集与 CBF

**定义 4（人的占据体积）**。`H_t ⊂ R^3` 是由头双目深度 + 帧差/运动分割 + 机器人自运动补偿得到的并集；不包含身份信息，不保存原始图像。

**定义 5（安全裕度）**。

```text
h(x) = dist(x, H_t) - δ_s,   C = { x : h(x) ≥ 0 }.
```

`x` 是机械臂胶囊/末端上的最近点；`δ_s` 是安全裕度（默认 10cm，可配置）。对多个连杆/人，取最小的 `h`。

**定义 6（安全滤波）**。给定名义速度 `u_cmd`，解

```text
u* = argmin_{u} ||u - u_cmd||²
     s.t. ∇h(x)ᵀ u + α h(x) ≥ 0,
          ||u|| ≤ v_max.
```

单约束闭式：

```text
u* = u_cmd + max(0, -(∇hᵀ u_cmd + α h)/||∇h||²) ∇h.
```

多约束用 active-set QP；若不可行，`u*=0` 并进入 `SAFE_HOLD`。

### 2.7 社会成本

```text
SC = λ1·N_collision + λ2·T_takeover + λ3·T_recover + λ4·E
```

- `N_collision`：与人的碰撞次数（硬约束，目标 0）；
- `T_takeover`：人类接管/干预时间；
- `T_recover`：干扰后恢复时间；
- `E`：能量代理（例如 `∫||v||²dt` 或关节速度平方积分）。

官方分数不含 `SC`，但人为干扰轴占 20%；`SC` 用作门 G9 的护栏和任务选择的 tie-breaker，不替代官方成功率。

## 3. 算法

### 3.1 总架构

```text
                    ┌─────────────────────────────────────┐
                    │  Evaluator (N ports 8765..8765+N-1) │
                    └──────────────┬──────────────────────┘
                                   │ websocket: obs / action chunk
                                   ▼
                    ┌─────────────────────────────────────┐
                    │  Per-port BRACE PolicyService (CPU) │
                    │  ├─ phase/edit observer (GEO-RES.)  │
                    │  ├─ BGR bimanual goal retrieval     │
                    │  ├─ RDS relative-frame servo        │
                    │  ├─ RAS role arbitration            │
                    │  ├─ SSF CBF safety filter           │
                    │  ├─ plan cache (30-step VLA plan)   │
                    │  └─ action adapter (WLA 54D → API)  │
                    └──────────────┬──────────────────────┘
                                   │ async, batched
                                   ▼
                    ┌─────────────────────────────────────┐
                    │  Shared VLA server (GPU)            │
                    │  UnifoLM-WLA-1.0 / VLA-0, 30-step   │
                    └─────────────────────────────────────┘
```

- 每个端口独立 `reset()`、独立 plan cache、独立角色/安全状态。
- BGR 库只读共享（copy-on-write），不跨端口写。
- VLA 仍是唯一学习模型；RDS/RAS/SSF 是确定性控制器/状态机/QP。
- 安全滤波在 CPU 上跑；VLA 推理异步、可批处理。

### 3.2 BGR：双臂目标库

离线：

```text
for each episode:
    phases = segment(episode)                  # FACT-VLA CPT / GEO-RESIDUAL
    for each phase:
        k = select_keyframe(phase)             # 接触前 1-3 帧 / 目标进入腕部视野
        T_A = episode.ee[anchor][k]
        T_B = episode.ee[actor][k]
        T_O = estimate_object_pose(episode, k) # 头双目 + 局部几何
        T_AB = inv(T_A) @ T_B
        T_AO = inv(T_A) @ T_O
        T_OB = inv(T_O) @ T_B
        d = descriptor(episode.wrist[k])       # ORB/颜色/轮廓；或同 VLA checkpoint encoder
        index.add(task, phase, T_AB, T_AO, T_OB, d, quality)
```

在线：

```text
candidates = index.filter(task=task_id, phase=phase_id)
candidates = candidates.rerank(pose_prior, descriptor_distance, quality)
topk = candidates.topk(k=5)
goal = rerank(topk, pose_consistency, image_quality, phase_confidence)
if goal.confidence < θ_c:
    fallback()   # F1 fixed relative goal / independent CHUNK-SERVO
```

规则：

- 任务/相位过滤优先于外观；不要让颜色直方图把「插网线」匹配到「拔网线」。
- 对称物体（杯子/碗/盒子）用对称群 `S_O` 的等价类：检索时取 `argmin_{g∈S_O} d(g T_AO*, T_current)`，不把 180° 旋转当成不同目标；对称性不明确的物体不自动取等价。
- 同时存 `T_AB` 和 `T_BA = inv(T_AB)`，支持角色互换。
- 检索库按任务/阶段分片；N 端口只读，内存共享。
- 规模：33,276 episodes；A 档约 19k；每 episode 1–2 个伺服关键帧 → 约 20–40k 目标；128×128 JPEG 约 5–10KB → 200–400MB；描述子 40–80MB；总 <1GB。

### 3.3 RDS：相对帧伺服

每个 5 步块：

```text
T_AB = inv(T_A) @ T_B
e = se3_log(inv(T_AB) @ T_AB*)
e = delay_predict(e, tau)
K_t = K_0 / (1 + tr(Sigma_t)/sigma_0^2)
Delta = clip(K_t @ e, ±delta_p, ±delta_r)
T_B_cmd = T_B @ exp(kappa * Delta)
T_A_cmd = T_A            # anchor holds; or symmetric split
```

对称模式（两手都动）：

```text
T_A_cmd = T_A @ exp(-kappa/2 * Adj(T_AB) @ Delta)
T_B_cmd = T_B @ exp( kappa/2 * Delta)
```

其中 `e` 是 `T_AB` 的 body twist（操作臂帧），`Adj(T_AB)` 把它转到锚定臂帧；实现时必须检查帧约定，否则对称分配会引入系统性偏移。

接触段：

```text
Delta = Delta_n + Delta_t
Delta_n <- 0.3-0.5 * Delta_n, low-pass
Delta_t <- Delta_t
```

法向力不可测，用 `d_t`（夹爪到局部表面的米制距离）和 `r_static` 代理；`r_grasp` 突变 → 滑移 → 降速/重抓。

延迟补偿：

```text
e_pred = e + J_rel @ v_rel * tau
```

Smith 预测/卡尔曼预测均可；模型误差大时只做增益降档，不做激进预测。

### 3.4 RAS：角色仲裁与切换

```text
s_a = c_a * (1 + v_a) * (1 + m_a); if c_a < c_min: s_a = 0
A = argmax_a s_a; B = other
if c_A < c_min:
    mode = SINGLE_ARM or SAFE_HOLD
elif s_B - s_A > Delta_h for K_h chunks and tr(Sigma) <= sigma_h:   # Delta_h 按新分数尺度标定
    mode = SAFE_HOLD -> re-localize -> swap(A,B)
else:
    mode = ANCHOR_ACTOR
```

- 切换不是「换策略」，而是换参考系和角色；VLA 计划不变，只是 `T_AB*` 和 `T_BA*` 互换。
- 切换期间零速保持，避免两臂同时抢参考系。
- 单臂模式：操作臂追 `T_A T_AB*`（如果锚定臂还能保持）；否则退回 CHUNK-SERVO 的独立伺服。
- 最大重试/最大保持时间：超过阈值 → 失败要优雅（停在安全位，不撞）。

### 3.5 SSF：社会安全滤波

人的检测（确定性，不用学习模型）：

1. 头双目视差/深度（一次性标定；无内参时用已知基线/焦距先验）；
2. 帧差 + 光流 + 机器人自运动补偿：减去已知关节/EE 运动解释的像素运动；
3. 剩余运动区域做 3D 反投影 + 聚类，得到 `H_t`；
4. 若深度不可靠，退化为图像空间 ROI + 保守速度限制（不声称 3D 安全）。

CBF-QP：

```text
for each link capsule / EE:
    x = closest point to H_t
    h = ||x - c_H|| - r_H - delta_s
    grad = (x - c_H)/||x - c_H||
    solve QP for u
if infeasible:
    u = 0; mode = SAFE_HOLD
```

可读恢复（停→退→等→再接近）：

```text
if edit_score > theta_e or human_distance < delta_s:
    hold position
    if human present: retreat along safe direction until h >= delta_s + margin
    wait T_wait; re-localize
    if clear: resume with conservative gain
    else: request VLA re-plan
```

- 限速/限幅/最大重试；恢复动作不能突然反向加速。
- 如果人持续占据工作空间超过 `T_max`，失败要优雅（停在安全位）。

### 3.6 模式选择与耦合增益

| 相位 | 模式 | `κ` | 帧 | 增益 | 说明 |
|---|---|---:|---|---|---|
| APPROACH | INDEPENDENT/ANCHOR | 0.3 | F1 | 正常 | VLA 主导，相对修正小 |
| ALIGN | ANCHOR_ACTOR | 0.8 | F1/F2 | 正常 | 相对精度开始重要 |
| CONTACT | ANCHOR_ACTOR | 1.0 | F2 | 法向降档 | 锚定臂稳住，操作臂插入/挂/拧 |
| TRANSFER | SYMMETRIC | 0.6 | F2 | 正常 | 两手同时搬运/折叠 |
| RECOVER | SAFE_HOLD/YIELD | 0 | F3 | 0 | 停/退/等/再接近 |

`κ` 在每个 chunk 内保持不变；跨 chunk 切换用 dwell time，避免抖动。`κ` 的选择是设计先验，G7 消融会验证 0/0.6/1.0 的差异。

### 3.7 与 CHUNK-SERVO 的集成伪代码

```python
class BracePolicy:
    def get_action(self, obs):
        self.tick(obs)
        self.maybe_request_plan(obs)

        phase = self.phase.update(obs)
        human = self.human.update(obs)          # stereo + motion; no learning
        T = {a: obs.ee_pose[a] for a in ("L", "R")}
        c = {a: self.grasp_conf(obs, a) for a in ("L", "R")}
        Sigma = self.pose_cov(obs)

        goal = self.goal_lib.retrieve(self.task, phase, T, Sigma)
        if goal is None:
            return self.chunk_servo_independent(obs)

        anchor, actor = self.arbitrate(T, c, Sigma, phase)
        if self.handover.needed(anchor, actor, c, Sigma):
            self.mode = "SAFE_HOLD"
        else:
            self.mode, kappa = self.mode_for(phase, goal, c, Sigma)

        a_ff = self.plan[self.plan_idx:self.plan_idx + self.H_c]
        self.plan_idx += self.H_c

        if self.mode == "SAFE_HOLD":
            a_cmd = self.safe_hold(obs)
        elif self.mode in ("ANCHOR_ACTOR", "SYMMETRIC"):
            T_AB = inv(T[anchor]) @ T[actor]
            e = se3_log(inv(T_AB) @ goal.T_AB)
            e = self.delay_predict(e, self.rtt)
            K = self.gain(e, Sigma, self.rtt)
            Delta = clip(K @ e, self.delta_p, self.delta_r)
            a_cmd = self.compose_relative(a_ff, Delta, anchor, actor, kappa)
        else:
            a_cmd = a_ff

        a_safe, filtered = self.safety.filter(a_cmd, human, obs)
        if filtered:
            self.mode = "YIELD"

        if self.edit_score > self.theta_e:
            self.mode = "RECOVER"
            a_safe = self.safe_hold(obs)

        return self.adapter.to_api(a_safe, obs, self.token)
```

关键约束：

- VLA 永远不阻塞 `get_action`（除冷启动）；plan 过期就用旧 plan + 相对伺服。
- `a_ff` 只作为前馈增量；相对修正以当前 EE 位姿为起点，不能把 VLA 的绝对目标当成相对目标再用一次，否则会双重补偿。
- 每个 chunk 只做一次相对伺服 + 一次安全滤波；任何异常返回上一组合法 chunk 或安全保持。
- 安全滤波的输出必须仍是合法 API 动作（绝对 EE 位姿 + gripper + pivot）。
- 绝不返回 NaN/错误形状；`reset()` 清理角色、目标、滤波器状态。

### 3.8 回退

```text
if goal.confidence >= θ_c and Sigma <= σ_high:
    F2/F1 relative servo (high gain)
elif goal.confidence >= θ_c and Sigma <= σ_low:
    F1 relative servo (low gain)
elif wrist/head features valid:
    F3 visual PBVS/IBVS (CHUNK-SERVO)
else:
    independent CHUNK-SERVO / VLA open-loop
```

回退不是失败：它保证 `get_action` 永远返回合法动作；BRACE 的边际收益只在锚定-操作任务上，独立任务回退是预期行为。

## 4. 推导与正确性

### 4.1 共模不变性

见命题 1。**假设**：目标定义在锚定臂/物体帧里；`G` 同时作用于两臂和目标。**结论**：`e` 不变。**边界**：若目标定义在 base 系（`F0`），或只有一臂被扰动（差模），不变性不成立。这正是帧层级和角色仲裁要处理的。

### 4.2 相对 Jacobian

见 §2.4。**假设**：`T_a` 可微、`J_a^b` 准确、没有关节限位/奇异。**结论**：`V_T = J_rel [\dot q_A; \dot q_B]`。**边界**：在奇异位形 `J_rel` 秩亏，需要阻尼最小二乘或降增益；这属于 G2 的验证项。

### 4.3 无延迟收敛

对小误差，`\dot e ≈ V_T`。取 `V_T = -K e`：

```text
\dot e = -K e.
```

`V = 1/2 ||e||²`，`\dot V = -eᵀK e ≤ -2λ_min(K)V`，所以

```text
||e(t)|| ≤ ||e(0)|| e^{-λ_min(K)t}.
```

有界扰动 `||w||≤w` 时，`\dot V ≤ -2λ_min(K)V + ||e||w`，最终界 `||e|| ≤ w/λ_min(K)`。离散化 `e_{k+1} = (I - H_c K)e_k + w_k` 在 `0 < H_c λ_max(K) < 2` 时稳定；最终界约 `||w||/(H_c λ_min(K))`。**边界**：小误差近似、`K` 对称正定、扰动有界；大角度/大位移时需要 `J_log` 或几何伺服。

### 4.4 任意延迟的稳定域

标量 `a = H_c K`，延迟 d 块：

```text
e_{k+1} = e_k - a e_{k-d}
P_d(z) = z^{d+1} - z^d + a.
```

边界 `z=e^{iθ}`：

```text
a = e^{idθ}(1 - e^{iθ})
  = -2i sin(θ/2) e^{i(d+1/2)θ}.
```

`a` 为实正数的相位条件：

```text
(d+1/2)θ - π/2 = 2πk.
```

最小的正 `a` 在 `k=0`：

```text
θ = π/(2d+1),
a_d* = 2 sin(π/(2(2d+1))).
```

由 Jury 判据/根连续性，`0 < a < a_d*` 时 Schur 稳定。数值根轨迹（d=0..10）与闭式一致到 1e-6（表 C）。

| d | `a_d*` | `K_max = a_d*/H_c`（`H_c=1/6s`） |
|---:|---:|---:|
| 0 | 2.000 | 12.0 |
| 1 | 1.000 | 6.0 |
| 2 | 0.618 | 3.7 |
| 3 | 0.445 | 2.7 |
| 4 | 0.347 | 2.1 |
| 5 | 0.285 | 1.7 |
| 10 | 0.149 | 0.9 |

**工程规则**：

```text
d = ceil(τ f_c / H_c)
K_max = a_d* / H_c
```

若 `τ=100ms`、`H_c=5`、`f_c=30`，`d=1`，`K_max=6.0`；若 `τ=300ms`，`d=2`，`K_max=3.7`。第 12 轮的 `K_p=0.3–0.8` 在这个范围内，但高 RTT 时必须主动降档，不能假设 5 步 chunk 自动解决延迟。**边界**：标量/均匀延迟；MIMO 用 `H_c λ_max((K+Kᵀ)/2) < a_d*` 作为充分条件；分数延迟用 `ceil` 保守近似。

### 4.5 CBF 前向不变性

对 `\dot x = u`，`h` 连续可微。CBF 条件 `∇hᵀu + αh ≥ 0` 等价于 `\dot h ≥ -αh`，由比较引理：

```text
h(t) ≥ h(0)e^{-αt} ≥ 0.
```

投影滤波在约束激活时令 `∇hᵀu* + αh = 0`，否则返回 `u_cmd`；因此每步满足条件。多约束 QP 的解满足所有激活约束；若 QP 不可行，零速保持是安全回退。**边界**：完美状态估计；有估计误差 `ε` 时用 `δ_s+ε` 的鲁棒裕度；人运动时用 `\dot h = ∇hᵀ(u - v_H)`，把 `||v_H|| ≤ v_H^max` 的最坏情况加入约束；`h` 非光滑（多障碍/非凸）时用最小 `h` 或光滑化；高速/大步长时需离散 CBF 或缩小 `v_max`。严格多连杆安全应在关节速度空间用每个胶囊的 `J_link` 建约束，EE 速度空间只是近似。

### 4.6 切换安全

**命题 2（条件切换界）**。若新锚定臂满足 `tr(Σ_new) ≤ σ_h`、`c_new ≥ c_min`，且相对控制器在切换后满足 §4.3/§4.4 的稳定条件，则切换后的相对误差满足

```text
||e(t)|| ≤ ||e_0|| e^{-λt} + w/λ,
```

其中 `||e_0|| ≤ ρ(σ_h, c_min)`。若条件不满足，进入 `SAFE_HOLD`，误差由保持指令和扰动界约束。

**证明**：切换时用测量位姿初始化 `e_0`；`Σ_new` 给出 `e_0` 的界；之后由 §4.3/§4.4 的收敛/最终界得到。`SAFE_HOLD` 时 `u=0`，误差不主动增长，只受扰动 `w` 影响。∎

**边界**：这是条件保证，不是无条件安全；抓取滑移、物体变形、人的外力都可能破坏假设。因此需要 G8 真机验证和保守回退。

### 4.7 混合模式的有界性

若两个候选指令 `u_i, u_c` 都满足同一 CBF 约束和速度界，则凸组合 `u = (1-κ)u_i + κu_c` 也满足（安全集凸）。若两个候选误差分别有界 `ρ_i, ρ_c`，则

```text
||e|| ≤ (1-κ)ρ_i + κρ_c
```

由三角不等式。**注意**：这给的是有界性，不是渐近稳定性；`κ` 在每个 chunk 内保持不变，跨 chunk 用 dwell time，避免频繁切换导致的极限环。**边界**：两个控制器共享同一参考轨迹/目标；若目标不同，凸组合可能不在任何一个的吸引域内。

### 4.8 假设与局限

1. 物体/受器是刚体；变形任务（FoldTowel）只降增益使用，不声称毫米级。
2. 锚定臂的抓取变换 `T_AO` 在短时间尺度内近似恒定；滑移需要 `r_grasp`/视觉检测。
3. 相对位姿/抓取变换协方差 `Σ_t` 可估计；协方差模型误差会影响增益调度。
4. 人的占据体积 `H_t` 可被确定性立体/运动分割估计；遮挡/静止人可能漏检。
5. 延迟是块状、均匀的；分数延迟/抖动用保守 `ceil` 和降增益处理。
6. CBF 在离散 30Hz 下需要离散版本或小步长；高速时 `v_max` 要收紧。
7. 单模型合规：RDS/RAS/SSF 无学习权重；若用 VLA encoder 做描述子，必须同一 checkpoint（C3）。
8. 玩具实验是运动学，不是物理/真机；所有真机收益都要 G3/G7 验证。

## 5. 复杂度

### 5.1 时间

| 操作 | 复杂度 | 说明 |
|---|---|---|
| 相对位姿/误差 | O(1) | 4×4 矩阵、3×3 旋转 log |
| 相对 Jacobian | O(1) | 6×14；两臂 7-DoF |
| 协方差/增益 | O(1) | 6×6 |
| BGR 检索 | O(log N) ANN / O(N) 暴力 | N≈20–40k |
| CBF-QP | O(m³) 最坏 / O(m) 典型 | m≤20（连杆×人） |
| 每 chunk | <1ms 伺服 + <5ms 检索 + <1ms 安全 | VLA 100–300ms 摊到 6 个 chunk |

### 5.2 空间

- 目标库 <1GB（图像 + 描述子 + 元数据）；多端口只读共享。
- 每端口状态：角色、目标、滤波器、plan cache；<10MB。
- 无新模型权重；VLA 权重共享。
- 人的检测只保留当前帧的 3D 点/体积，不保存视频。

### 5.3 与 CHUNK-SERVO 的对比

| 项 | CHUNK-SERVO | BRACE |
|---|---|---|
| 误差定义 | 每臂绝对 | 锚定臂相对 |
| 目标 | 受器→夹爪 | 双臂相对 + 物体相对 |
| 角色 | 固定 | 锚定分数 + 切换 + 单臂回退 |
| 安全 | 事后编辑检测 | CBF 硬约束 + 可读恢复 |
| 延迟 | 0/1 块分析 | 任意 d 闭式界 |
| 学习模型 | 1 个 VLA | 1 个 VLA（不变） |
| 每 chunk 开销 | 单臂伺服 | 双臂伺服 + 小 QP（常数级） |
| 主要瓶颈 | VLA 推理/RTT | 锚定位姿噪声 + VLA 推理/RTT |

## 7. 本轮数值实验（toy kinematic，不是真机）

### 7.1 设置

- 3D 运动学玩具：位姿 = 旋转矩阵 + 平移；小误差用 `R^T R*`/`R^T(t*-t)` 的局部参数化；比例伺服 80–120 步收敛。
- 共模扰动 `G`：平移 ±3cm、旋转 ±10°；锚定臂/物体随 `G` 移动。
- 独立绝对伺服：操作臂目标固定为旧的绝对 `T_B*`（这是「目标没有随基座/物体更新」的失效模式）。
- 相对帧伺服：操作臂目标为 `T_A @ T_AB*`（当前锚定臂帧）。
- 噪声：在锚定臂/操作臂位姿上加零均值高斯噪声（代理抓取/物体变换不确定性）。
- 成功阈值：相对位置 ≤2mm、相对旋转 ≤1°。
- 代码：Python + NumPy/SciPy；本轮脚本保存在 `workspace/exp/brace_sim.py`（见 §11）。

### 7.2 共模抑制（无噪声）

`N=3000`，`G` 平移 ±3cm、旋转 ±10°。

| 控制器 | 位置误差均值 | p95 | 旋转误差均值 | p95 |
|---|---:|---:|---:|---:|
| 独立绝对伺服 | 29.3mm | 43.5mm | 9.55° | 13.7° |
| 相对帧伺服 | 0.0mm | 0.0mm | 0.0° | 0.0° |

无噪声相对帧为 0 是共模不变性的直接结果，不是真机精度声明；它只说明「误差定义换对了」。

### 7.3 噪声敏感性（相对帧）

`N=500/档`，共模 ±3cm/±10°，锚定/操作位姿噪声为 0.5/1/2mm、0.1/0.2/0.4°。

| 噪声（每臂） | 独立位置/旋转 | 相对位置/旋转 | 成功@2mm/1° |
|---|---:|---:|---:|
| 0.5mm / 0.1° | 29.3mm / 9.3° | **0.79mm / 0.16°** | **498/500** |
| 1.0mm / 0.2° | 28.5mm / 9.7° | 1.58mm / 0.33° | 362/500 |
| 2.0mm / 0.4° | 29.4mm / 9.6° | 3.21mm / 0.64° | 93/500 |

这是本轮最重要的工程结论：**相对帧把 3cm/10° 的共模误差换成锚定/抓取变换的噪声底；要把 2mm/1° 容差的成功率做到 >95%，锚定位姿/抓取变换必须到 0.5mm/0.1° 量级。** 1mm/0.2° 只有约 72%，2mm/0.4° 只有约 19%——此时应降增益或退回独立伺服，而不是硬套相对帧。

### 7.4 延迟稳定域

根轨迹数值临界值与闭式 `2 sin(π/(2(2d+1)))` 对比：

| d | 数值 `a*` | 闭式 | 误差 |
|---:|---:|---:|---:|
| 0 | 2.000000 | 2.000000 | 0 |
| 1 | 1.000000 | 1.000000 | 0 |
| 2 | 0.618034 | 0.618034 | <1e-6 |
| 3 | 0.445042 | 0.445042 | <1e-6 |
| 4 | 0.347296 | 0.347296 | <1e-6 |
| 5 | 0.284630 | 0.284630 | <1e-6 |
| 10 | 0.149460 | 0.149460 | <1e-6 |

结论：延迟稳定域随 d 收缩；5 步 chunk 降低的是**反馈周期**，不是**延迟本身**。高 RTT 时必须按 `K_max = a_d*/H_c` 降增益。

### 7.5 CBF 安全滤波

3D 点机器人，起点 `[0,0,0]`，目标 `[1,0,0]`；球形人占据半径 15cm、安全裕度 5cm（toy 参数；设计默认 10cm，可配置）；2000 次随机障碍位置；名义控制器 = 比例 + 切向绕行；CBF `α=1.5`，`v_max=0.5m/s`。

| 控制器 | 碰撞 | 成功 | 最小距离均值 | p5 | 最小 |
|---|---:|---:|---:|---:|---:|
| 无 CBF | 17/2000 | 2000/2000 | 274.5mm | 184.5mm | 117.5mm |
| CBF | **0/2000** | 2000/2000 | 286.0mm | 236.5mm | 217.5mm |

玩具里 CBF 把碰撞从 17 次降到 0，且因为名义控制器有切向绕行，成功率没有下降。真机里 CBF 可能让人停在障碍前（安全但未完成任务），这时由可读恢复/重规划处理；G4 要测恢复率，而不只是碰撞数。

### 7.6 切换 toy model

20 个 chunk，每 chunk 锚定失败概率 1%，切换成功概率 85%（切换失败则任务失败）。这里的「切换」是参考系/角色切换或重抓同一物体，不是物理换手；物理交接是独立技能，不在本轮范围：

| 策略 | 闭式 | Monte Carlo (50k) |
|---|---:|---:|
| 不切换 | 0.8179 | 0.8168 |
| 切换 | 0.9704 | 0.9695 |

闭式：`0.99^20 = 0.8179`，`(1-0.01×0.15)^20 = 0.9704`；50k Monte Carlo 与闭式一致到约 0.001。这是算术示意，不是真机抓取实验；它说明「锚定失败不是小概率事件，切换的边际收益可能很大」，但切换本身也有失败概率和风险，需要 G8 验证。

### 7.7 解读与边界

- 7.2 是机制验证：相对帧确实拒绝共模；独立绝对伺服确实把共模当误差。
- 7.3 是工程门：锚定噪声是新的瓶颈；0.5mm/0.1° 是目标，1mm/0.2° 是底线，2mm/0.4° 应回退。
- 7.4 是控制器设计：延迟必须降增益；闭式界可直接用于调度。
- 7.5 是安全层 sanity check：CBF 能消除 toy 碰撞；真机需要立体/运动分割和离散 CBF。
- 7.6 是切换收益示意：不是真机成功率；切换是角色/参考系切换或重抓，不是物理换手。
- 所有结果都是 toy kinematic，不是物理仿真，不是真机；不能直接外推成 32 任务成功率。

### 8.2 单任务通道协议

1. 选 5 个任务：PlugInEthernet、HangCup、ZipUp、Unlock、FoldTowel。
2. 每任务 5 次 A/B（BRACE off/on）；同一初始条件；记录成功、步骤分、耗时、p99、碰撞、恢复时间。
3. 通过：≥3/5 任务 +10pp；FoldTowel 不回归 >5pp；零碰撞；p99 ≤150ms。
4. 通过后再扫 `H_c ∈ {3,5,8}`、`κ ∈ {0.3,0.6,1.0}`、锚定噪声门；选 p99/成功率的最佳折中。
5. 最后才跑 32×10 正式评测。

统计：

- 配对差值 + bootstrap 95% CI；
- 5 次/任务只能看方向；不要用 +1–2pp 做结论；
- 320 trials 下单次标准误约 2.4pp（p≈0.25），但配对设计可降低；报告必须给 CI。

### 8.3 收益算术（保守）

- 10 个锚定-操作任务各 +10pp → `10/32×10 = +3.1pp`；
- 人为干扰轴 +10pp → `0.2×10 = +2pp`；
- 合计约 **+5pp**；考虑锚定噪声/接触动力学，保守区间 **+2–5pp**；
- 5 个任务 +10pp → `+1.6pp + 2pp = +3.6pp`；
- 锚定噪声 2mm/0.4° → 相对帧可能打不过 VLA，退回独立；只剩安全滤波的 human 轴 +1–2pp。

不要承诺 +10pp 全局。BRACE 的收益是条件收益：锚定稳、锚定准、任务真的是锚定-操作，三者同时成立才有 +10pp 量级。

## 9. 社会影响评估

### 9.1 直接：人机共存

- 人为干扰轴 64/320 trials；BRACE 的 CBF 硬约束 + 可读恢复直接针对这 64 次。
- 指标：碰撞数（目标 0）、最小人机距离、恢复时间（≤2s）、人类接管率、误报率（≤5%）。
- 设计原则：安全是硬约束，不是软惩罚；CBF 可以覆盖 VLA/伺服指令；QP 不可行时零速保持。

### 9.2 间接：可及性与可审计性

- 不需要新模型、不需要新数据采集；RDS/RAS/SSF 在 CPU 上跑；目标库 <1GB。
- 相对 Jacobian、CBF、BGR 检索都是确定性/可解释的，便于审计和复现（若描述子用 VLA 同一 checkpoint 的 encoder，见 C3）。
- 降低小团队的算力/数据门槛；也降低研究的环境成本。

### 9.3 风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| 自动化替代桌面操作岗位 | 社会/就业 | 研究基准而非部署；人在环；分阶段部署；影响声明 |
| 人体感知隐私 | 隐私 | 只用深度/运动，不做身份识别；本地处理；不保存原始视频 |
| 过度信任安全滤波 | 安全 | 明确 CBF 不是机械安全/法规合规的替代；保守裕度；急停 |
| 误报导致频繁停机 | 可用性 | 多线索+滞回；任务相位门控；可读恢复 |
| 漏检导致碰撞 | 安全 | 立体+运动+机器人自运动补偿；保守速度；失败安全 |
| 数据/算力不平等 | 可及性 | 开源基座 + CPU 伺服；不依赖专有第二个模型 |

### 9.4 指标

```text
SC = λ1·N_collision + λ2·T_takeover + λ3·T_recover + λ4·E
```

- 硬约束：`N_collision = 0`；
- 目标：`T_recover ≤ 2s`，误报 ≤5%，接管率不高于基线；
- `SC` 用作 G9 护栏和任务选择 tie-breaker，不替代官方成功率；
- 报告时同时给成功率和 `SC`，避免「为了分数牺牲安全」。

## 10. 风险与合规

### 10.1 单模型合规

| 模式 | 做法 | 风险 | 建议 |
|---|---|---|---|
| C1 离线标注 | GEO-RESIDUAL 只离线生成相位/接触标签；线上只有 VLA | 最低 | 保守首选 |
| C2 确定性控制器 | RDS/RAS/SSF 是几何/控制/QP，无学习权重；VLA 是唯一学习模型 | 低；需说明 | 主推 |
| C3 同 checkpoint 特征 | 目标描述子用 VLA 同一 checkpoint 的 encoder | 低–中；需说明 | 需要强描述子时用 |

禁止：加载第二个学习策略/残差网络/独立视觉编码器/学习式人体检测器做在线决策。人的检测用立体+运动分割，不用学习模型。

### 10.2 风险表

| 风险 | 影响 | 缓解 |
|---|---|---|
| 锚定臂抓不稳 | 相对帧噪声大 | 锚定分数、切换、单臂回退、降增益 |
| 锚定位姿/抓取噪声 >0.5mm/0.1° | toy 成功率从 99.6% 掉到 72%/19% | 改进标定/跟踪；低增益；退回独立 |
| 人的检测漏检 | 碰撞 | 立体+运动+自运动补偿；保守裕度；限速；急停 |
| 人的检测误报 | 频繁停机 | 滞回；相位门控；多线索 |
| CBF 降低成功率 | 分数下降 | A/B；只在人附近硬约束；可读恢复；G3/G4 |
| 单模型解释 | 判违规 | C1/C2/C3；文档；确定性模块 |
| RTT >300ms | 增益界低、性能降 | 5 步 chunk；预测；PBVS 回退；RTT 测量 |
| 任务分类错误 | 耦合反而有害 | 模式选择；独立回退；G7 |
| 变形/透明物体 | 相对帧失效 | 只对刚体启用；F3 视觉；降增益 |
| 标定漂移/换机器人 | 相对误差变大 | 每机器人重标定；夹爪 PnP 自标定；误差大关伺服 |
| 安全 QP 不可行 | 停机 | 零速保持；退回安全位；最大重试 |
| 数据泄漏 | 离线指标虚高 | 按 session/物体/背景分组划分 |
| 评测噪声 | +1–2pp 假阳性 | 配对 A/B；bootstrap；重复实验 |
| 社会影响 | 就业/隐私/过度信任 | 影响声明；本地处理；人在环；分阶段部署 |

### 10.3 未核实/未解决

- 真机锚定位姿/抓取变换噪声分布；0.5mm/0.1° 是否可达。
- 真机人体检测在遮挡、静止人、多人场景下的召回/误报。
- 真机 CBF 对成功率/时间的影响；离散 30Hz 下的安全性。
- 真实接触动力学、摩擦、变形、滑移；玩具模型没有建模。
- 32 任务中真正能建立稳定锚定关系的比例；表中分类是先验。
- 官方 WLA 与挑战赛 API 的 `pivot`/`ee` 语义是否完全一致（继承第 12 轮的未解决项）。
- 是否允许多次提交；提交次数上限。
- 真实任务成功率/失败分布（榜单是预览，不能反推）。

## 11. 与第 10–12 轮的关系

| 轮次 | 资产 | BRACE 的状态 |
|---|---|---|
| 第 10 轮 FACT-VLA | 相位化 BC、CAC 柔顺执行、EGP 证据门控 | 保留；相位标签喂给模式选择 |
| 第 11 轮 GEO-RESIDUAL | 动作条件化残差、米制表面距离、编辑检测 | 保留；接触信号喂给增益/法向缩幅；编辑检测触发恢复 |
| 第 12 轮 CHUNK-SERVO | 30 步规划 + 5 步执行、DG-KEYFRAME、数字孪生、单任务通道、竞赛组合 | 保留；升级为双臂相对帧 + RAS/SSF/BGR；延迟分析推广到任意 d |

**保留**：WLA 基座、33k 演示、官方 rubric、单任务通道、数字孪生标定、5 步 chunk、演示检索、编辑检测。

**升级**：绝对→相对；单臂→双臂；固定角色→仲裁/切换；事后安全→CBF 硬约束；0/1 延迟→任意 d 闭式界。

**剪枝**：第二个学习模型、完整 sim-to-real、力/触觉闭环、30Hz 广域网伺服、逐任务策略、6D 物体位姿网络、预览榜单难度表。

**复现**：本轮玩具脚本 `workspace/exp/brace_sim.py`（NumPy/SciPy）；参数见 §7；它不是物理仿真，不替代 G2/G3。

## 12. 一句话押注与最大风险

**押注**：用 CHUNK-SERVO 做 30 步规划 + 5 步执行，用锚定臂的相对帧把共模误差变成可拒绝的差模，用角色仲裁处理单臂失效，用控制屏障函数把人的安全距离变成硬约束——在不新增学习模型的前提下，把双臂任务的成功率、鲁棒性和人机共存安全性同时往前推一小步。

**最大风险**：如果锚定臂在多数任务上抓不稳、锚定位姿/抓取变换噪声到不了亚毫米/0.1°，相对帧的收益会被噪声吃掉，BRACE 就退化成「CHUNK-SERVO + 一个保守安全滤波器」，双臂协调的复杂度换不来足够的分数。
