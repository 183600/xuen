# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「社会规范理解」×「论文创新点」）

> 第 54 轮已建立动作-鲁棒性双证书体系，把“技能能不能组合”变成可判定问题。本轮补上第三类、也是人形机器人最致命的失败：**社会规范失败**——技能物理可行、鲁棒性达标，却在人类共处场景中“失礼”“冒犯”甚至“危险地合规”。核心矛盾：**H22 单项规范合规的技能组合可能联合违规**（规范涌现冲突）；**H23 云端规范先验与边端局部规范观察存在权威错配**，全局合法规则在本地文化/场景中失效。同时，本轮把“论文创新点”本身当作需要证明的对象：每个创新点必须附带可证伪的 `Δcapability + falsifier`，否则不算创新。

## 0. 直觉与动机

**灵感 1（规范是动作空间上的第二类场：从“能做”到“该做”）**
直觉：第 54 轮的 `α_S(a)` 回答“技能能否执行动作 a”；社会规范回答“在该上下文 c 中，动作 a 是否可接受”。定义一个**规范场** `ν_κ(a|c) ∈ [0,1]`，κ 为文化/人群/场景先验。于是动作空间被切成三层：物理可达 `A_phys`、技能覆盖 `A_skill = {α_S ≥ θ_cov}`、规范许可 `A_ν = {ν_κ ≥ θ_ν}`。可部署动作空间是三者的交集 `A_dep = A_phys ∩ A_skill ∩ A_ν`。关键洞察：**规范不是执行后的惩罚项，而是组合前的可行性约束**；把规范放进 reward 里事后惩罚，正是现有 social navigation 工作“先违规、再道歉、再微调”的根源。

**灵感 2（规范冲突是组合的第一性问题，不是单技能问题）**
直觉：单个技能 S1=“礼让行人”、S2=“快速通过走廊”各自都合规；组合 S1⊗S2 在窄走廊 + 双向人流下会生成“逼迫行人贴墙”的联合行为。这不是任一技能违规，而是**规范涌现冲突**。把规范建模为偏序格 `(N, ⪯, π)`：硬规范（安全/法律）与软规范（礼貌/效率），冲突时按优先级 π 裁决；若两条同级硬规范的许可动作集交集为空，则组合**不可判定为合规**，必须显式上报而不是默默选一个。

**灵感 3（云边规范契约：全局规则 × 本地习俗）**
直觉：云端握着“法规/组织规范”的全局先验 `ν_c`，边端握着“此刻此地”的规范观察 `ν_e`（行人反应、人类纠正、地方习俗）。二者不是同一个东西，直接下发会水土不服。定义规范契约 `C^ν_ce=(ν_c, ν_e, Δ_ν, NormExplain, τ_ν)`，边端发现 `ν_e(a) < θ_ν` 时通过 **NormExplain** 回传“哪条规范、在哪个动作、期望范围是什么”，云端据此重加权而非重写规则。这把第 54 轮的 Explain 闭环从“鲁棒性失败”扩展到“规范性失败”。

**灵感 4（从纠正中学习规范，而不是从提示词里猜规范）**
直觉：社会规范理解最可靠的一手信号是**人类纠正**（“别贴太近”“让他先走”“这边排队”），其次才是离线语料/VLM 判断。边端把纠正当作规范后验的贝叶斯证据：`P(ν|correction) ∝ P(correction|ν)P(ν)`，且只更新被纠正动作的局部邻域，避免全局漂移；云端聚合成规范库并保留 `σ_culture` 不确定度，供跨场景迁移时显式告警。

**灵感 5（论文创新点即“可证伪的能力增量”）**
直觉：大多数论文的 novelty 是形容词（“首个”“统一的”“鲁棒的”），不可审计。本轮把创新点建模为证书 `NVC=(Δ_cap, falsifier, minimal_repro, baselines, ablation_witness)`：Δ_cap 必须写成“现有方法 M 在条件 X 下做不到的能力”，falsifier 是一个**能杀死该创新点的最小实验**，minimal_repro 是复现能力的最小配置。凡是写不出 falsifier 的“创新点”，一律降级为工程实现，不进入贡献列表。这是本轮对“论文创新点”的方法论回应：**novelty 要像安全性一样被证伪，而不是被宣称**。

**灵感 6（三证书金字塔：社会可部署性的可判定化）**
直觉：把第 54 轮的 `ρ`（鲁棒性）、`A_cert`（动作占用）与本轮的 `N_cert`（规范）合并为 **社会可部署证书 `SD`**。部署不再靠“平均表现好”，而是三证书同时闭合；任何一证拒绝都给出具体反例与回退动作，使“社会可部署”第一次成为可审计的布尔判定，而非评审人的主观印象。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（规范场与规范许可动作集）**
上下文 `c ∈ C`（场景类型、人群密度、角色关系），文化/人群先验 `κ`。规范场 `ν_κ : A × C → [0,1]`，`ν_κ(a|c)` 为动作 a 在上下文 c 中的社会可接受度。硬/软阈值 `θ_h > θ_s`：
```
A_ν^hard(c) = {a | ν_κ(a|c) ≥ θ_h}
A_ν^soft(c) = {a | ν_κ(a|c) ≥ θ_s}
```
规范违规质量 `V_ν(τ,c) = (1/|τ|) Σ_{a_t∈τ} max(0, θ_s - ν_κ(a_t|c_t))`，硬违规为轨迹中 `ν < θ_h` 的动作计数。

**定义 122（规范偏序格与冲突）**
规范集合 `N`，偏序 `⪯`（`n_i ⪯ n_j` 表示 n_j 优先级不低于 n_i），优先级函数 `π: N → ℕ`。规范 n 诱导许可集 `A_ν(n|c)`。同级冲突：
```
conflict(n_i,n_j,c) = 1 ⇔ A_ν(n_i|c) ∩ A_ν(n_j|c) = ∅
                        ∧ ¬(n_i ⪯ n_j) ∧ ¬(n_j ⪯ n_i)
```
若可比且交集为空，则按 π 舍弃低优先级者，并在证书中记录**规范让位** `let_set`，而非静默选择。

**定义 123（规范感知组合图与规范证书）**
`G^ν_S=(V,E)`，边 `(i,j)` 在兼容性与鲁棒性条件之外附带：
```
N_cert = (N_hard_pass, ν_min, conflict_free, let_set,
          evidence, κ, δ_ν, σ_culture)
```
其中 `ν_min = min_{a∈A_core} ν_κ(a|c)`，`evidence` 至少含人类纠正样本与反例轨迹，`δ_ν` 为云边规范对齐容差，`σ_culture` 为文化校准不确定度。

**定义 124（云边规范契约）**
`C^ν_ce = (ν_c, ν_e, Δ_ν, NormExplain, τ_ν)`：
- `ν_c` 云端规范先验，`ν_e` 边端规范观察；
- `Δ_ν = sup_{a∈A_core} |ν_c(a|c) - ν_e(a|c)|`；
- `NormExplain : (violation, a_e, c) ↦ (n, expected_range, confidence)`；
- `τ_ν` 规范回传时延预算。

**定义 125（规范后验更新）**
边端规范后验 `b_e(ν)` 在纠正 `z` 后贝叶斯更新 `b_e'(ν) ∝ P(z|ν)b_e(ν)`，且仅在 `N(a_e)` 邻域更新：
```
b_e'(ν) = b_e(ν),  ν ∉ N(a_e)
```
云端聚合 `b_c = Aggregate({b_e^{(m)}})`，保留 `σ_culture = max_{m,n} D(b_e^{(m)} ‖ b_e^{(n)})`。

**定义 126（社会可部署证书）**
`SD = (ρ, A_cert, N_cert, γ_ce, δ_a, δ_ν)`。部署可判定：
```
deploy(SD) = 1 ⇔ dom_ρ = in ∧ δ_a < Θ_a ∧ N_hard_pass = 1
                ∧ conflict_free = 1 ∧ δ_ν < Θ_ν
```
即**安全、动作、规范三证书同时闭合**，任一失败都返回反例与回退建议。

**定义 127（创新点可证伪证书 NVC）**
`NVC = (Δ_cap, falsifier, minimal_repro, baselines, ablation_witness)`：
- `Δ_cap = (M, X, capability)`：现有方法 M 在条件 X 下不具备 capability；
- `falsifier = (experiment, threshold)`：实验未达阈值则该创新点被证伪；
- `minimal_repro`：复现能力的最小系统配置；
- `baselines`：必须含 M 与至少一个强消融；
- `ablation_witness`：去掉本 IP 后预期出现的具体失败反例。
`valid(NVC)=1` 当且仅当 falsifier 已跑通且 ablation_witness 可复现；否则该条贡献降级。

## 2. 关键算法 伪代码

### IP-121 NFC（Norm Field Characterization）

```python
def norm_field(skill, contexts, kappa, judge, human_calib, budget):
    nu = {}
    for c in active_sample(contexts, budget):        # 主动采样高不确定区域
        for a in reachable_actions(skill, c):
            v, conf = judge(skill, a, c, kappa)      # VLM + 规则库
            if conf < C_MIN:
                v = human_calib.query(skill, a, c)   # 低置信转人工校准
            nu[(a, c)] = v
    return calibrate(nu, human_calib.holdout)        # 温度/等渗校准
```

### IP-122 NCG（Norm-aware Composition Graph）

```python
def build_norm_graph(skills, contexts, theta_a, tau_e):
    G = nx.DiGraph()
    for i, s1 in enumerate(skills):
        for j, s2 in enumerate(skills):
            if i == j: continue
            if compat(s1, s2) < theta_a: continue
            if transition_cost(s1, s2) > tau_e: continue
            ncert = norm_certificate([s1, s2], contexts)
            if ncert.hard_pass and ncert.conflict_free:
                G.add_edge(i, j, N_cert=ncert,
                           cost=cost_align(s1, s2) + w_n * (1 - ncert.nu_min))
    return G
```

### IP-123 NCD（Norm Conflict Detection / Resolution）

```python
def resolve_norms(active_norms, c, lattice):
    hard = [n for n in active_norms if n.kind == 'hard']
    for n1, n2 in combinations(hard, 2):
        if disjoint(A_nu(n1, c), A_nu(n2, c)):
            if lattice.comparable(n1, n2):
                loser = lattice.lower(n1, n2)
                active_norms.remove(loser)
                return ('let', loser, active_norms)   # 记录规范让位
            return ('reject', 'hard_conflict', (n1, n2), c)
    return ('ok', active_norms)
```

### IP-124 CEN（Cloud-Edge Norm alignment）

```python
def cloud_edge_norm(P_c, nu_c, nu_e, gamma_ce, tau_nu):
    reports = []
    for sid, a_c in P_c:
        a_e = gamma_ce(a_c)
        if nu_e(a_e, c) < theta_h:
            exp = norm_explain(a_e, c, nu_e)          # (n, expected_range, conf)
            reports.append(exp)
            if exp.n.kind == 'hard':
                return ('reject', exp)                # 硬违规整段回退
        if abs(nu_c(a_c, c) - nu_e(a_e, c)) > tau_nu:
            reports.append(('drift', a_c, a_e))
    return ('reprofile', reports) if reports else ('ok', P_c)
```

### IP-125 SNL（Social Norm Learning from corrections）

```python
def update_norm_posterior(b_e, correction):
    a_e, z = correction.action, correction.signal
    for a in neighborhood(a_e):                        # 仅局部更新，防全局漂移
        b_e[a] = bayes_update(b_e[a], z)
    return b_e

def aggregate_norms(edge_posteriors):
    b_c = mixture(edge_posteriors)
    sigma_culture = max_pairwise_divergence(edge_posteriors)
    return b_c, sigma_culture
```

### IP-126 SDC（Socially Deployable Certificate）

```python
def social_deploy_certificate(seq, rho, A_cert, N_cert, gamma_ce, budgets):
    if not (N_cert.hard_pass and N_cert.conflict_free):
        return ('reject', 'norm')
    if N_cert.delta_nu > budgets.theta_nu:
        return ('reject', 'norm_drift', N_cert.delta_nu)
    if A_cert.delta_a > budgets.theta_a:
        return ('reject', 'action', A_cert.delta_a)
    if min(rho.values()) < budgets.rho_min:
        return ('reject', 'robustness', rho)
    return ('ok', SD(rho, A_cert, N_cert, gamma_ce,
                     A_cert.delta_a, N_cert.delta_nu))
```

### IP-127 NVA（Novelty Verification / reviewer attack）

```python
def verify_novelty(claim, baselines, falsifier, ablation):
    delta = run_delta_probe(claim.capability, baselines, claim.X)
    if delta <= CLAIM_EPS:
        return ('demote', 'not_novel')
    if not run_falsifier(falsifier):
        return ('demote', 'falsified')
    witness = run_ablation_without(claim.ip)
    if witness.failure_class not in claim.ablation_witness:
        return ('demote', 'witness_mismatch')
    return ('accept', NVC(claim, delta, falsifier, witness))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| NFC | O(B·|A_local|·T_judge) | O(|A|·|C|) | 主动采样覆盖 + 校准 ECE |
| NCG | O(|S|²·|A| + |N|²) | O(|S|²) | 规范证书 sound、成本单调 |
| NCD | O(|N_h|²·|A|) | O(|N|) | 同级硬规范可枚举完备 |
| CEN | O(|P|·(|A_e|+|N|)) | O(|P|) | NormExplain 闭环、τ_ν 有界 |
| SNL | O(|N(a)|·|z|) | O(|A|·|C|) | 局部更新、聚合不发散 |
| SDC | O(|A_core|+|𝔇_ρ|) | O(|A|+|𝔇_ρ|) | 三证书同时闭合 |
| NVA | O(k·T_exp) | O(k) | falsifier 可复现、消融反例匹配 |

**正确性定理（Socially-Deployable Composition Soundness）**
承接 (A22)–(A28)；新增 **(A29)** `ν_κ` 经人工校准，ECE ≤ ε_ν；**(A30)** 有限规范集下同级硬规范冲突检测完备；**(A31)** NormExplain 回传延迟 ≤ τ_ν，纠正信号无对抗污染。则：
```
P_social_success ≥ 1 - Σ_d(1-ρ_min(d)) - P(δ_a>Θ_a) - P(δ_ν>Θ_ν)
                    - P(hard_conflict) - β_E - β_ν
```
其中 `β_ν = P(ν_calibration_error > ε_ν)`。关键前提：三类证书失败事件近似独立；若规范失败与鲁棒性失败强相关（避障动作同时是规范动作），须在 `SD` 中记录 `corr(ρ,ν)` 并收紧界。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 规范场文化欠定 / 标注主观 | 高 | 多标注者 κ 一致性门槛 + 显式 σ_culture |
| VLM judge 偏见被当规范真值 | 高 | 人工校准集 + 对抗提示测试 + 规则硬底线 |
| 规范冲突导致死锁/过度保守 | 高 | 优先级格 + 让位记录 + 任务可行性兜底 |
| 纠正信号稀疏或对抗污染 | 中 | 置信门控 + 异常纠正隔离 + 云端复核 |
| 三证书组合爆炸 | 中 | 分层剪枝 + 证书缓存 + 增量校验 |
| novelty 自证偏差 | 中 | 外部 baseline 复现 + falsifier 预注册 |

## 6. 本轮最大风险

**一句话**：把社会规范提升为与动作、鲁棒性并列的第一类证书，能让“社会可部署”变成可审计判定，但其 soundness 取决于**规范场的人工校准一致性、规范冲突格的完备性、以及云边 NormExplain 回传的无污染收敛**——一旦规范被 VLM 偏见或单一文化标注冒充为普适真值，组合系统会以“合规”之名系统性冒犯本地人群，且三证书同时闭合反而放大错误自信，故必须坚持**低置信转人工 + 显式文化不确定度 + 硬规范红队反例**，宁可判“不可部署”，也不把规范场的“合规假象”当作部署前提。

## 2. 关键算法 伪代码

### IP-121 NFC

```python
def norm_field(skill, contexts, kappa, judge, human_calib, budget):
    nu = {}
    for c in active_sample(contexts, budget):
        for a in reachable_actions(skill, c):
            v, conf = judge(skill, a, c, kappa)
            if conf < C_MIN:
                v = human_calib.query(skill, a, c)
            nu[(a, c)] = v
    return calibrate(nu, human_calib.holdout)
```

### IP-122 NCG

```python
def build_norm_graph(skills, contexts, theta_a, tau_e, w_n):
    G = nx.DiGraph()
    for i, s1 in enumerate(skills):
        for j, s2 in enumerate(skills):
            if i == j: continue
            if compat(s1, s2) < theta_a: continue
            if transition_cost(s1, s2) > tau_e: continue
            ncert = norm_certificate([s1, s2], contexts)
            if ncert.hard_pass and ncert.conflict_free:
                G.add_edge(i, j, N_cert=ncert,
                           cost=cost_align(s1, s2) + w_n * (1 - ncert.nu_min))
    return G
```

### IP-123 NCD

```python
def resolve_norms(active_norms, c, lattice):
    hard = [n for n in active_norms if n.kind == 'hard']
    for n1, n2 in combinations(hard, 2):
        if disjoint(A_nu(n1, c), A_nu(n2, c)):
            if lattice.comparable(n1, n2):
                loser = lattice.lower(n1, n2)
                active_norms.remove(loser)
                return ('let', loser, active_norms)
            return ('reject', 'hard_conflict', (n1, n2), c)
    return ('ok', active_norms)
```

### IP-124 CEN

```python
def cloud_edge_norm(P_c, nu_c, nu_e, gamma_ce, tau_nu):
    reports = []
    for sid, a_c in P_c:
        a_e = gamma_ce(a_c)
        if nu_e(a_e, c) < theta_h:
            exp = norm_explain(a_e, c, nu_e)
            reports.append(exp)
            if exp.n.kind == 'hard':
                return ('reject', exp)
        if abs(nu_c(a_c, c) - nu_e(a_e, c)) > tau_nu:
            reports.append(('drift', a_c, a_e))
    return ('reprofile', reports) if reports else ('ok', P_c)
```

def update_norm_posterior(b_e, correction):
    a_e, z = correction.action, correction.signal

def aggregate_norms(edge_posteriors):

### IP-126 SDC

```python
def social_deploy_certificate(seq, rho, A_cert, N_cert, gamma_ce, budgets):
    if not (N_cert.hard_pass and N_cert.conflict_free):
        return ('reject', 'norm')
    if N_cert.delta_nu > budgets.theta_nu:
        return ('reject', 'norm_drift', N_cert.delta_nu)
    if A_cert.delta_a > budgets.theta_a:
        return ('reject', 'action', A_cert.delta_a)
    if min(rho.values()) < budgets.rho_min:
        return ('reject', 'robustness', rho)
    return ('ok', SD(rho, A_cert, N_cert, gamma_ce,
                     A_cert.delta_a, N_cert.delta_nu))
```

### IP-127 NVA

```python
def verify_novelty(claim, baselines, falsifier, ablation):
    delta = run_delta_probe(claim.capability, baselines, claim.X)
    if delta <= CLAIM_EPS:
        return ('demote', 'not_novel')
    if not run_falsifier(falsifier):
        return ('demote', 'falsified')
    witness = run_ablation_without(claim.ip)
    if witness.failure_class not in claim.ablation_witness:
        return ('demote', 'witness_mismatch')
    return ('accept', NVC(claim, delta, falsifier, witness))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| NFC | O(B·|A_local|·T_judge) | O(|A|·|C|) | 主动采样覆盖 ≥ 95%，校准 ECE ≤ 0.05 |
| NCG | O(|S|²·|A| + |N|²) | O(|S|²+|E|) | 规范证书 sound，路径成本单调 |
| NCD | O(|N_h|²·|A|) | O(|N|) | 同级硬规范可枚举完备 |
| CEN | O(|P|·(|A_e|+|N|)) | O(|P|) | NormExplain 闭环，τ_ν 有界 |
| SNL | O(|N(a)|·|z|) | O(|A|·|C|) | 局部更新，聚合不发散 |
| SDC | O(|A_core|+|𝔇_ρ|) | O(|A|+|𝔇_ρ|) | 三证书同时闭合，失败可归因 |
| NVA | O(k·T_exp) | O(k) | falsifier 可复现，消融反例匹配 |

**正确性定理（Socially-Deployable Composition Soundness）**
假设第 54 轮 (A22)–(A28) 成立；**(A29)** `ν_κ` 经人工校准，ECE ≤ ε_ν；**(A30)** 有限规范集下同级硬规范冲突检测完备；**(A31)** NormExplain 回传延迟 ≤ τ_ν 且纠正信号无对抗污染。则：
```
P_social_success ≥ 1 - Σ_d(1-ρ_min(d)) - P(δ_a>Θ_a) - P(δ_ν>Θ_ν)
                    - P(hard_conflict) - β_E - β_ν
```
其中 `β_ν = P(ν_calibration_error > ε_ν)`。关键：**规范先于组合被校验**，**云边规范漂移有界**，**规范失败可被 NormExplain 归因并触发重加权**；若 `corr(ρ,ν)` 显著，需用联合界替换独立求和界。

## 7. 本轮最大风险

**一句话**：社会规范层让“社会可部署”第一次成为可审计的三证书判定，论文创新点也第一次被 falsifier 约束，但整条链的 soundness **三重依赖规范场的人工校准一致性、规范冲突格的完备性、以及云边 NormExplain 回传的无污染收敛**；一旦 VLM 偏见或单一文化标注被当成普适规范真值，系统会以“合规”之名系统性冒犯本地人群，而三证书同时闭合反而放大错误自信，故必须以 **低置信转人工 + 显式 σ_culture + 硬规范红队反例** 为硬护栏，宁可判“不可部署”，也绝不把规范场的“合规假象”当作部署前提。
