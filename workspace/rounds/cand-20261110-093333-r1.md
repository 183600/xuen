# 第 43 轮（新循环第 1 轮） · 阻抗-无源 × 证书承运中间件：把「离散安全自动机」升级为「连续能量契约 + 分布式证书总线」（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR 飞轮）。前 42 轮的安全论证几乎都建立在「离散守卫 + 几何/时序边际」上：CAR 判 `margin ≥ θ`，LCS 比预算，ECR 查表。但这套语义在**接触 / 人机共融**场景有一个结构性盲点——安全从来不是「离开约束面」，而是「交换了多少能量」；同时所有证书都默认「算出来的下界能按时送到执行器」，而分布式中间件的调度抖动、时钟漂移恰恰会偷偷破坏这个假设。本轮灵感词「阻抗控制」「中间件」正好补上两条缺失的维度：**阻抗控制**把安全语义从「位置/速度不得越界」提升到「端口能量不得透支」，用无源性（passivity）给出接触场景可证明的稳定性与力安全；**中间件**把证书从「离线制品」变成「随消息流动的契约」，让每一跳通信、每一次调度都携带并校验证书，从而把分布式系统的时序假设纳入安全论证。二者合成一条新主线：**连续能量契约 × 分布式证书承运**。

## 0. 直觉与动机

**灵感 1（阻抗控制 → 安全从「几何边界」变成「能量预算」）**：位置/速度级 CBF 与几何证书回答的是「会不会撞上」。可一旦机器人要推门、擦桌、递物、被人拉住，问题就变成「撞上以后怎么柔顺、怎么保证不把能量灌爆」。阻抗控制用「质量-弹簧-阻尼」虚拟动力学把力与位移绑在一起：`F = -K(x-x_d) - Dẋ`，柔顺度由 K、D 调。它天然自带一个可证明的安全量——**无源性**：若控制器只耗散不产生能量（或只从「能量罐」支取已储存的能量），则它与任意无源环境互联仍稳定。于是安全证书可以从 `m(x) ≥ θ` 换成 `E_tank(t) ≥ 0 ∧ |F| ≤ F_max`：**能量罐不透支 = 物理上不可能把不稳定能量注入环境**。这把「碰撞安全」从概率性/经验性变成结构性保证，且顺带覆盖人机接触的力上限。

**灵感 2（中间件 → 证书必须「随消息走」，而不是「留在论文里」）**：第 42 轮的证书是离线算好、打包下发的一次性制品。但真实系统里，证书的每个前提（在哪个状态、在哪个时刻、由哪个节点算、多久之内有效）都依赖于**通信与调度**。中间件的直觉是：把它升级为**证书承运总线**——每条消息带一个「证书令牌」(cert_id, valid_region_hash, deadline, energy_budget)，中间件在转发/调度时强制执行 QoS 契约（截止期、速率、可靠性、顺序），并在交付前校验「令牌仍有效」。更关键的是网络延迟会破坏无源性（延迟的能量会「凭空」注入），中间件可以在传输层做**时域无源性控制（TDPC / 波变量）**，把延迟吸收进能量账本。这样中间件不只是「管道」，而是**分布式安全论证的执法者**。

**灵感 3（二者耦合 → 全局能量账本 + assume-guarantee 契约）**：单个节点的阻抗控制器管好自己的能量罐还不够——多个行为（导航、抓取、避障、人机协作）抢占同一执行器，且分布在边缘 MCU / 机载 / 云端三层。耦合点是：**中间件充当「能量银行」**，维护跨节点的全局能量账本，各阻抗控制器按契约支取/回存能量；同时用 assume-guarantee 契约把每个节点的局部无源性证书组合成系统级证书。新组合 = 各节点契约的合成，而不是重新证明整个系统。

**耦合升级**：阻抗控制提供「连续域的证书内容」，中间件提供「证书的承运、组合与执法」，LCS/ECR 提供「低成本执行」，SCV/CKB 提供「离线验证与知识沉淀」。证书从「静态断言」进化为「在总线上一跳一跳被验证的能量契约」。

## 1. 形式化定义（增量：定义 38–44）

**定义 38（端口哈密顿阻抗模型）**：机器人受控动力学写成端口哈密顿形式 `ẋ = (J(x) − R(x))∇H(x) + g(x)u`，`y = g(x)ᵀ∇H(x)`，其中 H 为存储函数（动能+势能），J 反对称（能量守恒路由），R ⪰ 0（耗散），端口 (u, y) = (速度, 力)。阻抗控制律给定目标刚度 K_d ⪰ 0、阻尼 D_d ≻ 0，使闭环在交互端口呈现 `F = −K_d(x − x_d) − D_d ẋ + F_ff`。**命题**：当 F_ff = 0 且 R ⪰ 0 时，该端口无源，即对任意容许输入 `∫ yᵀu dt ≥ H(t) − H(0) ≥ −H(0)`。

**定义 39（能量罐与无源性证书）**：能量罐 E_t(t) ≥ 0，动态 `Ė_t = P_harvest − P_inject`，P_harvest = max(0, yᵀu)（从环境交互中回收），P_inject = 控制器注入功率。**无源性证书** `Cert_pass = (E_t, H, K_d, D_d, F_max)`，有效条件：
`(i) E_t(t) ≥ 0, ∀t; (ii) Ė_t = P_harvest − P_inject; (iii) |F| ≤ F_max; (iv) H(x) ≤ H_max`。
定义**无源安全边际** `m_pass(x) = E_t(x)`（能量罐余量），与第 42 轮的几何边际 m_geo 并列成为守卫的第二坐标。

**定义 40（阻抗-安全有效域）**：`C_imp = {(x, E_t) : E_t ≥ 0 ∧ |F(x)| ≤ F_max ∧ H(x) ≤ H_max ∧ x ∈ C_geo}`。注意 C_imp 是**状态 × 能量**的联合域，比纯几何域更紧；当 E_t 低时即便几何上安全也不得执行高功率动作。**阻抗调度函数** `π_imp: x ↦ (K_d, D_d)` 必须能量可行：`P_inject(π_imp(x)) ≤ E_t / T_min`。

**定义 41（证书承运消息）**：每条总线消息 `m = (payload, token)`，token = (cert_id, region_hash, t_issue, deadline, energy_budget, node_id)。中间件提供 QoS 契约 `Q = (rate, deadline, reliability, ordering)`。**承运条件**：消息在 `deadline` 前送达，且接收方在交付时刻的 `region_hash` 与本地状态匹配；否则 token 作废，动作被拒。于是「证书有效」被细化为「证书在正确的时间、正确的状态、被正确的节点消费」。

**定义 42（时域无源性下的延迟补偿）**：设标称延迟 τ_0、抖动 Δτ，通信链路注入的「非无源能量」`E_leak = ∫ P_leak dt`。采用波变量变换或能量反射（energy reflection）后，中间件保证 `E_tank^global(t) ≥ E_tank^global(0) − E_leak^bounded`，且 `E_leak^bounded ≤ κ·τ_max·‖y‖²`。**命题**：当 τ_max ≤ τ_crit（临界延迟）时，延迟补偿后的闭环仍满足定义 39 的无源性证书。

**定义 43（分布式 assume-guarantee 证书组合）**：节点 i 的契约 `(A_i, G_i)`，A_i 为假设（输入证书的有效域），G_i 为保证（输出证书有效域及能量收支）。中间件组合规则：系统证书有效当且仅当
`∀i: G_i ⊇ A_{i+1} ∧ Σ_i E_tank,i ≥ 0 ∧ (timing) deadline 链可满足`。
**定理（组合保无源性）**：若每个节点在其 A_i 下无源、且链路由定义 42 补偿，则整个分布式系统的端口无源，系统证书 `Cert_sys = ⊗_i Cert_pass,i` 有效。

**定义 44（阻抗仲裁与被动混合）**：多行为请求阻抗集合 `{(K_i, D_i, w_i)}`，中间件求解
`(K*, D*) = argmin Σ_i w_i‖K − K_i‖² s.t. K ⪰ 0, D ≻ 0, E_tank(π) ≥ 0, |F| ≤ F_max`。
**命题**：在能量约束可行域内，被动混合（passivity-preserving blending，按能量权重而非线性平均）保持无源性；线性平均一般不保无源，故必须做能量投影。

## 2. 四大产出设计（增量 IP-57/58/59 + 升级既有 IP）

### 2.1 IP-57 PASSIVITY-CERT（无源证书引擎 PC）
1. **端口哈密顿建模**：从关节/机身动力学导出 H、J、R、g，离线用符号化工具构建端口模型；移动底盘用任务空间阻抗简化。
2. **能量罐标定与回收**：P_harvest 用交互力×速度估计（含噪声鲁棒化），设定 E_tank 上界与回充策略；能量低水位触发「阻抗变硬 + 降速」而非急停。
3. **无源性证书生成**：对每条行为边 e 给出 Cert_pass(e) = (E_t^min, H_max, F_max, τ_crit)，把 `m_pass` 与 `m_geo` 组成二维守卫。
4. **力安全**：F_max 由任务与人体工效学给出（参照 ISO/TS 15066 精神），证书强制 |F| ≤ F_max。

### 2.2 IP-58 CERT-MIDDLEWARE（证书承运中间件 CM）
1. **证书令牌协议**：在 DDS/ROS 2 之上加一层 token 头（零拷贝，<1μs 序列化）；token 含区域哈希、截止期、能量预算。
2. **QoS-证书联合调度**：把 deadline/rate 纳入证书有效性；调度器拒绝「会让证书过期」的排队，必要时降级。
3. **时域无源性补偿**：在传输节点实现波变量/能量反射，维护全局能量账本；延迟超 τ_crit 立即触发安全模式。
4. **契约组合与执法**：assume-guarantee 契约注册表；每次动作下发前做一次契约合成校验（O(度数)）；不满足则拦截。

### 2.3 IP-59 IMPEDANCE-ARBITER（阻抗仲裁器 IA）
1. **多行为阻抗融合**：导航/避障/抓取/人机协作各自给 (K_i, D_i, w_i)，仲裁器在能量可行域内做被动混合。
2. **优先级与安全投影**：安全行为（避障）的 K 方向投影不可被覆盖；能量约束统一投影。
3. **阻抗调度**：按任务相位（接近/接触/操作/撤离）调度 K、D，接入 IP-50 课程相位。
4. **可解释仲裁日志**：记录每次混合的约束活跃集，供审计与回放。

## 5. 本轮最大风险

**一句话**：本轮把安全赌注从「几何边界」搬到「能量账本 + 分布式证书承运」，最大的新失效链是**中间件的时间/时钟假设未被形式化验证**——DDS 抖动、时钟漂移、丢包会让「能量罐」在账面上非负、物理上却已透支，且这种无源性违约不像几何越界那样有可见的碰撞前兆，属于**静默的能量失效**；因此 E88（延迟下无源性）与 E90（契约组合拦截）必须作为红线实验，任何一项不达标即退回第 42 轮的纯几何证书。

## 1. 符号体系（增量：定义 38–44 符号）

| 符号 | 含义 | 定义 |
|---|---|---|
| `ẋ=(J−R)∇H+gu, y=gᵀ∇H` | 端口哈密顿模型 | J 反对称、R⪰0、端口 (u,y)=(速度,力) |
| `Cert_pass=(E_t,H,K_d,D_d,F_max)` | 无源性证书 | E_t≥0 ∧ \|F\|≤F_max ∧ H≤H_max |
| `E_t, Ė_t=P_harvest−P_inject` | 能量罐 | 从交互回收能量，向控制注入能量 |
| `m_pass(x)=E_t(x)` | 无源安全边际 | 与 m_geo 并列的第二守卫坐标 |
| `C_imp={(x,E_t): E_t≥0∧\|F\|≤F_max∧H≤H_max∧x∈C_geo}` | 阻抗-安全有效域 | 状态×能量联合域 |

## 2. 关键算法（伪代码）

### IP-57 PC：能量罐与无源性证书
```
def update_energy_tank(E_t, y, u_env, u_ctrl, dt, eta=0.8, E_max=1.0):
    # 只从被动交互中回收能量；注入受当前罐量约束
    P_harvest = max(0.0, dot(y, u_env))
    P_inject  = max(0.0, dot(y, u_ctrl))
    E_t = E_t + (eta * P_harvest - P_inject) * dt
    E_t = clamp(E_t, 0.0, E_max)          # 防透支、防无限蓄能
    return E_t

def passivity_certificate(x, E_t, model, K_d, D_d, F_max, H_max):
    F = compute_interaction_force(x, model, K_d, D_d)
    if E_t < 0:        return INVALID('energy_overdraft')
    if abs(F) > F_max: return INVALID('force_limit')
    if H(x) > H_max:   return INVALID('storage_excess')
    return VALID(E_t=(E_t,), H=H(x), F=F)

def impedance_schedule(x, phase, E_t):
    # 能量低水位 -> 变硬 + 降速（而非急停，避免可用性崩塌）
    K_d, D_d = phase_to_impedance(phase)
    if E_t < E_low:
        K_d = K_d * (1 + beta * (E_low - E_t) / E_low)
        D_d = D_d * (1 + beta * (E_low - E_t) / E_low)
    return K_d, D_d
```

### IP-58 CM：证书承运与延迟补偿
```
def middleware_forward(msg, token, now, local_region, qos):
    # 1. 截止期：证书必须在有效期内被消费
    if now > token.deadline:               return DROP('cert_expired')
    # 2. 状态匹配：接收方区域必须与证书区域一致
    if hash(local_region) != token.region_hash: return REJECT('region_mismatch')
    # 3. 全局能量预算（能量银行）
    if not energy_broker.reserve(token.node_id, token.energy_budget):
        return BLOCK('energy_denied')
    # 4. QoS 感知入队（拒绝会让令牌过期的排队）
    enqueue_with_qos(msg, token, qos)
    return ACCEPT

def tdcp_compensate(y_send, y_recv, tau_est, E_global, tau_crit):
    # 波变量/能量反射：只注入有界能量
    P_leak = wave_energy_leak(y_send, y_recv, tau_est)
    if P_leak > 0:
        E_global = max(0.0, E_global - P_leak * dt)   # 记账
    if tau_est > tau_crit:
        raise PassivityViolation('delay_exceeds_critical')
    return y_compensated(y_recv, tau_est), E_global

def check_contract_chain(contracts, action):
    # assume-guarantee 合成：G_i ⊇ A_{i+1} 且总能量非负
    for i in range(len(contracts) - 1):
        if not subset(contracts[i].G, contracts[i+1].A):
            return BLOCK(f'contract_break@{i}')
    if sum(c.E_tank for c in contracts) < 0:
        return BLOCK('global_energy_negative')
    if not deadline_chain_feasible(contracts):
        return BLOCK('deadline_infeasible')
    return ALLOW
```

### IP-59 IA：被动阻抗混合
```
def passive_blend(requests, E_tank, F_max, priority_dir):
    # requests: [(K_i, D_i, w_i)]，含安全行为与任务行为
    # QP：最小加权偏差，约束 PSD/PD、能量可行、力可行
    K, D = solve_qp(
        objective = sum(w_i * sqnorm(K - K_i) for (K_i, D_i, w_i) in requests),
        constraints = [K_psd(), D_pd(),
                       energy_constraint(E_tank), force_constraint(F_max)]
    )
    # 安全方向投影最后执行，任何混合不可削弱
    K, D = project_priority(K, D, priority_dir)
    return K, D
```

## 6. 本轮最大风险

**一句话**：本轮把安全赌注从「几何边界」搬到「能量账本 + 分布式证书承运」，最大的新失效链是**中间件的时间/时钟假设未被形式化验证**——DDS 抖动、时钟漂移、丢包会让「能量罐」在账面上非负、物理上却已透支，且这种无源性违约不像几何越界那样有可见的碰撞前兆，属于**静默的能量失效**；因此 E88（延迟下无源性）与 E90（契约组合拦截）必须作为红线实验，任何一项不达标即退回第 42 轮的纯几何证书。
