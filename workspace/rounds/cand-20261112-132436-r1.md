# 第 58 轮（承接第 57 轮「少样本×多模态×个性化」IP-133~138；灵感循环新一段；本轮灵感：「分层规划」×「手势识别」）

> 第 57 轮把安全的赌注从"模型置信"换到"证据质量"，又用元先验、跨模态对账、个性化信任把证据质量本身做成可摊销、可对账、可演化的对象。但它的风险自陈暴露了两个**结构性**而非参数性的未解问题：**(a) 证据的组合是平的**——PCE+ 把路线离散成一串检查点，用"对检查点取联合界"把逐点 δ 相加。这既过保守（把本可由结构共享的证据当成独立风险累加，长程任务上界迅速饱和到 1），又无法回答"一次承诺到底承诺到哪一层"：承诺一个落脚点、承诺一段路线、承诺整个任务，在现有体系里是同一件事；探针与协商预算只能在叶子上平均撒，没有人为顶层那个最贵的假设负责。**(b) 人的通道窄且慢**——第 57 轮的人只经"触图标注/语音确认"进入，天然滞后于运动节拍；而人最自然、最低延迟、最具空间指向性的通道——手势——被完全忽略。手势恰是"停/慢/避开/指这里"这类**收紧**语义的天然载体，却也最容易被误识别、最不适合用来"放宽"。本轮两个灵感各补一层：**分层规划**把安全论证从"逐检查点证据"升级为"**分层证据契约的组合**"（assume-guarantee + 证据预算 + 契约失效回溯）；**手势识别**把人从"慢通道标注者"升级为"**有向证据通道**"（单通道只能收紧、放宽需双通道、指代只改注意力不改阈值）。核心命题由"证据说可信"升级为 **"证据可分层组合，人可低延迟收紧而不可单通道放宽"**。

核心矛盾：
- **H29（分层 vs 证据耦合）**：分层让局部推理可解、预算可分配，但组合只有在父层假设成立、且兄弟证据真的可分时才健全；朴素地把各层 δ"乘起来"等于**契约漂移**——系统会"每一层都有证据"地证明安全，却在顶层假设被证伪时整体失效。安全从"坏先验普遍"进一步变成"**坏假设被层级稀释**"。
- **H30（手势 vs 歧义/误触发）**：手势高带宽、低延迟，但文化/视角/遮挡/逆光下歧义大、易误触发；一次假的"同意"就是一次假同意，一次漏掉的"停"更糟。且手势识别本身是分层流水线（检测→三维手姿→手势词→指代→意图），误差逐级复合，一个自信的错误指代会把探针引向错误区域。
- **H31（分层证词 vs 责任归属）**：分层契约让"下层出错"可被上层"假设"掉，责任在层间蒸发；审计与可解释性要求每个假设显式入账、可证伪、且不能被用来放宽。安全论证若不能在层间传递**责任**，分层就只是把风险藏进接口。

## 0. 直觉与动机

**灵感 1（分层规划 → 证据契约的组合，而不是风险数字的相加）**
直觉：现在的安全像"每走一步都要求全队重新体检"；分层规划像公司分层授权——任务层只向路线层要一份**可审计的保证书**，路线层向段层要，叶子给出实测证据。关键不是"分层"本身，而是**把假设也写进合同**（assume-guarantee）：父层显式声明"我假设坡度<25°、扫掠体内无人、材质属已训簇"，子层只在该假设下负责。于是安全论证从"一长串风险相加"变成"一棵契约树 + 一本假设账"。联合界仍是默认、恒健全的上界；只有在**兄弟证据支撑不相交**的分离证书成立时，才允许用更紧的独立组合，且必须显式预留共同原因预算。

**灵感 2（分层规划 → 证据预算与"该规划到多细"本身成为 VOI 决策）**
直觉：探针是稀缺货币，应花在"对顶层风险边际贡献最大"的那一层，而不是平均撒在叶子上。有时最划算的不是多探一个点，而是**把一段路线拆成两段**以获得局部证据（refinement），或**把一段合并成一条粗契约**以省掉重复协商（abstraction）。"规划到多细"因此从一个手工超参变成预算下的价值决策；预算自上而下按边际收益分配，终止条件也随之内生。

**灵感 3（手势识别 → 有向证据通道：权力不对称）**
直觉：手势是"身体说的话"，快、直观、有空间指向。但它最不该被赋予"放宽"的权力：挥手可能被识别成"继续"，戴手套/逆光/遮挡都会骗它。于是定一条不对称规则——**手势默认只能让系统更保守**（停、慢、避开、指这里），这类消息立刻接受；任何"放宽"（批准不可逆接触、提升授权、撤销警报）必须**双通道独立一致**（手势+语音/文本）并过证据门与佐证。误停只损失可用性，误放会损失安全；两者代价不对称，通道权力也必须不对称。

**灵感 4（手势识别 → 指代只改注意力，不改阈值）**
直觉：指一下"那块"是最高效的空间通信：它不告诉你"能不能过"，只告诉你"该看哪里"。所以指代手势被设计为只更新探针/注意力先验（VOI 排序、区域候选、契约节点选择），**绝不移动安全阈值 δ、θ_voi 或证据门**。若指代集合不唯一或置信不足，输出"指代弃权"，绝不猜一个区域然后自信地在那里取证。

**灵感 5（两灵感合流 → 层对齐的人机契约）**
直觉：人指着"这一步"说"这里小心"，其实是在**指定契约节点**：他收紧的不是整个任务，而是这个子目标。机器人应把解释与请求同意也渲染在同一层级（"我准备进入 B 段，需要确认这一段的不可逆接触"），并用"我理解为你指向 B 段东侧"的回显暴露指代错误。手势给层级导航，分层给手势落点——两者互为坐标系。

**灵感 6（事后证伪 → 契约依赖图上的失效传播）**
直觉：第 57 轮已能"发现某模态错了就回溯降权其历史证据"。分层后这一步应升级为**依赖导向回溯**：叶证据被证伪，沿契约依赖图反向标记所有用到它的祖先，重算 δ；超阈的已承诺节点被撤销，并只重探"最小修复集"，而不是整盘重规划。这样"坏证据长寿"在分层结构里被压成"坏证据只污染它真正支撑的那些契约"。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（分层证据契约 HEC）** 规划层级 ℓ∈{0 任务,1 路线,2 段,3 检查点,4 运动}，节点 n 覆盖执行域 scope(n)，子节点集 ch(n)。契约 C_n=(A_n,G_n,E_n,β_n,κ_n)：
- A_n 环境/上下文**假设**（可测谓词：坡度、材质簇、扫掠体内无人、光照等）；
- G_n 安全**保证** P(fail in scope(n) | A_n)≤δ_n；
- E_n **证据义务**（在何粒度、用何证据类解除）；
- β_n 探针/协商**预算份额**，满足 Σ_{c∈ch(n)} β_c≤β_n；
- κ_n 兄弟间**分离证书**，附共同原因预算 δ_cm(n)。
组合规则（均条件于 A_n 成立）：默认联合界
δ_n^U=Σ_{c∈ch(n)} δ_c + δ_cm(n)（恒健全）；
仅当 κ_n 经测量成立（兄弟失败事件共享的物理探针/传感器/材质样本/标注者会话为空，或共同原因已被 δ_cm 覆盖）时，允许紧组合
δ_n^T=1−Π_{c}(1−δ_c)+δ_cm(n)，其证书违背概率 ε_κ 计入部署界。
**假设账**：每个 A_n 处于 {verified,inherited,carried}；carried 必须带界 a_n=P(¬A_n) 与失效点（下一个检查点/不可逆接触前），且**不得用于放宽**任何承诺。根保证 P_safe≥(1−a_root)(1−δ_root)。

**定义 140（分层承诺规划 HCP）** 承诺算子 Commit(n) 当且仅当：(i) E_n 已解除；(ii) δ_n 组合有效（显式记录用 U 还是 T）；(iii) 路径上所有 carried 假设未被用于放宽。否则 Refine(n)（展开 ch(n)，depth+1≤L_max）或 Escalate(n)（升级证据类）。依赖图 D：n 的出边指向解除 E_n 所用的叶证据。失效传播：叶 e 被证伪 ⇒ 沿 D 反向闭包标记 invalid；对每个已承诺祖先重算 δ_n，若 δ_n>δ_f 则 Retract_pre(n)（接触前撤销）；若接触已发生则只做 Reclassify_post(n)（修正地图证据并触发下游重规划）。修复集 R\*=argmin_{R⊆closure(invalid)} cost(R) s.t. 根保证复原；只重探/重协商 R。

**定义 141（分层手势识别与校准指代 HGR）** 识别链 g_0 检测→g_1 三维手姿→g_2 手势词→g_3 指代 r\*∈𝓜∪O∪{⊥}→g_4 同意意图。每层输出 (ŷ_g, conf_g, abstain_g) 与误差模型；链校准约束 P(整链错)≤Σ_g ε_g 且逐层 ECE_g≤ε_{g,g} 声明诚实；任一层 abstain 向上传播为 fail-safe（收紧场景维持保守态，放宽场景即拒绝）。指代输出置信集 R̂ 而非单点：|R̂|>1 或 top-1 置信<θ_ref ⇒ 指代弃权 ⊥。时间上引入驻留 τ_dw 与冷却 τ_cd，误触发率与响应延迟构成显式帕累托前沿。

**定义 142（有向手势通道 DGC）** 安全动作格 (𝒜,⊑) 以保守度为序，meet ∧ 取更保守者。人类消息 m 带方向 dir(m)∈{tighten,neutral,loosen}。规则：
(D1) 手势单通道只可 tighten/neutral；tighten 走快路径（接受时延≤τ_fast），记 EV-gesture-tighten；
(D2) loosen 需双通道（手势+语音/文本）一致 ∧ 误差源多样性证书 δ_div ∧ 过证据门与 corrob\*(auth)；单通道 loosen 一律拒绝；
(D3) 冲突取保守：m1∧m2 为安全格 meet，并记录冲突供审计；
(D4) 指代手势只更新注意力/VOI 先验，不改 δ、θ_voi、证据门阈值；
(D5) 手势可降 vig（连续误触发计数），但不得升 auth（沿用第 57 轮单向有界）；
(D6) tighten 必须投影到**动态可行安全停域** SafeStop(x,ẋ)：不得用当前状态无法执行的急停去"更保守"，否则升级为 brace/absorb 原语——保守是"允许行为集合收缩"，不是"任何瞬时动作都更安全"。

**定义 143（分层证据门 HEG 与证书 J_h）** 证据类扩展 EV-contract（须可展开到叶证据后按 FSE 检查）、EV-gesture-tighten（仅限收紧）、EV-gesture-loosen（双通道+δ_div+佐证）；不可逆接触必要证据集仍不含任何单通道人类消息。J_h=(J_p, D, {κ_n}, {δ_cm(n)}, assumption_ledger, gesture_chain_cal, grounding_set, direction_log, cross_channel_div, contract_invalidation_log)，继承 J_p 全检。

**定义 144（分层 VOI 与终止 VOI-H）** 对可解除节点 n：
VOI_H(n)=[δ_root(¬E_n)−δ_root(E_n)]/cost(E_n)，δ_root 按 HEC 组合传播；
细化价值 VOI_ref(n)=[δ_root(n 未展开)−δ_root(n 已展开)]−cost(refine)。
预算自上而下按 max VOI_H / VOI_ref 分配，Σ探针≤Σβ，细化深度≤L_max；当候选 VOI<θ_voi 时停止，转承诺/修复/绕行/L2 协商/安全停。于是"规划深度"与"取证深度"统一为同一个预算问题。

## 2. 关键算法伪代码

```python
def contract_compose(n, kids, ledger):              # IP-139
    dcm = n.kappa.common_cause if n.kappa else widest_common_cause(n)
    if n.kappa and n.kappa.certified:
        return 1 - prod(1 - c.delta for c in kids) + dcm   # 紧，需证书
    return sum(c.delta for c in kids) + dcm                 # 默认恒健全

def commit_or_refine(n, M, ledger, D):              # IP-140
    if any(carried_used_to_loosen(n, ledger)):
        return Reject('assumption_laundering')      # A44 硬规则
    if obligations_open(n, M):
        return Refine(n) if depth(n) < L_MAX else Escalate(n)
    return Commit(n, mode='T' if n.kappa and n.kappa.certified else 'U')

def gesture_chain(frame, cal):                      # IP-141
    for g in LEVELS:                                # detect→pose→token→ground→intent
        y = g(frame)
        if y.abstain or y.conf < cal.abs[g.name]:
            return Abstain(g.name)                  # 向上传播 fail-safe
    return Gesture(y, chain_err=sum(cal.eps[g] for g in LEVELS))

def directional_apply(m, state, s_op):              # IP-142
    if m.channel == 'gesture' and m.dir == 'loosen':
        return state                                # D1: 单通道永不放宽
    if m.dir == 'loosen' and not (m.dual and m.div_cert
                                  and gate_ok(m) and s_op.auth >= 'A1'):
        return state                                # D2
    target = meet(state, m.constraint)              # D3: 保守优先
    return project_SafeStop(target, x, xdot)        # D6: 动态可行收缩
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| HEC | O(\|ch\|)/节点组合 | O(\|D\|) | 默认联合界健全、紧组合仅凭证书（A41） |
| HCP | O(\|D\|+R\*·C_VOI) | O(\|D\|) | 依赖闭包完备、接触前后区分 |
| HGR | O(Σ_g d_g)/帧 | O(\|R̂\|+d_g) | 链误差声明诚实、弃权传播（A42） |
| DGC | O(1)+meet | O(\|𝒜\|) | 单通道不放宽、保守 meet、SafeStop（A43） |
| HEG | O(\|σ\|·\|D\|) | O(\|σ\|) | EV-contract 必可展开、假设账审计 |
| VOI-H | O(\|D\|·(C_VOI+C_comp)) | O(\|D\|) | 预算守恒、深度有界、终止 |

**正确性定理（HCGS，Hierarchical Contract-Gesture Soundness）** 在 A37–A40 上增加：
(A41) 契约组合健全：默认联合界；紧组合仅在 κ_n 经测量成立、δ_cm(n) 覆盖共同原因时使用，证书违背概率 ≤ε_κ；
(A42) 分层手势链校准诚实：逐层 ECE 与链误差满足定义 141，abstain 正确传播；
(A43) 有向通道强制：不存在单通道 loosen 通过；双通道独立性与 δ_div 证书诚实；
(A44) 假设账健全：carried 假设不得用于放宽，且不可逆接触前必须转为 verified。
则：
(i) **根安全界**：P_safe ≥ (1−a_root)(1−δ_root)，且 δ_root 是实际组合风险的上界；使用紧组合引入的额外风险 ≤ N_κ·ε_κ。
(ii) **手势单调性**：仅手势通道使系统的**允许行为集合**单调收缩（风险不增，最多损失可用性）；任何风险增加必须经双通道 loosen，其增量 ≤ ε_g·ε_second + δ_div + 证据门失效率。
(iii) **失效传播完备**：任一被证伪叶证据的全部承诺祖先必被重算，超 δ_f 者必被撤销（依赖闭包覆盖），且接触后只影响下游。
(iv) **终止性**：Σ探针≤Σβ、细化深度≤L_max，PCX-H 终止于 {承诺,修复,绕行,L2 协商,安全停}。
(v) **部署界**：把第 57 轮"对检查点取联合界"替换为契约树组合界，节省量恰等于可证分离的结构共享项。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 契约漂移/责任稀释（上层假设被"假设"掉） | 高 | 假设账显式入账；carried 不可用于放宽；不可逆接触前强制 verified；审计 |

## 6. 本轮最大风险

**一句话**：本轮把安全论证从"逐检查点证据"改成"分层契约组合"，最大风险是**契约漂移与指代漂移的叠加**——上层把正确性寄存在未审计的环境假设上、兄弟节点又用"看起来独立"的分离证书把相关失效乘开，使系统在每层都"有证据"地证明安全，却在顶层假设被证伪时整体失效；同时一个自信的错误指代会把探针引向错误区域，而"双通道"若共享同一观察者误差则形同虚设。故必须以假设账（carried 不可放宽）、默认联合界+可证伪分离证书、单通道永不放宽、指代只改注意力且可弃权五重护栏，把"分层"限制为**可审计的责任分解**，而不是风险的稀释术。

    A = infer_assumptions(node, parent_assume)     # 坡度/材质簇/扫掠体/光照...
    status = classify_assumptions(A, evidence)     # verified / inherited / carried

    return Contract(A=A, status=status, E=obligations(node),
                    beta=beta, kappa=separation_cert(node))

def contract_compose(n, kids, ledger):
    dcm = n.kappa.common_cause if n.kappa else worst_common_cause(n)
    if n.kappa and n.kappa.certified:
        d = 1 - prod(1 - c.delta for c in kids) + dcm    # δ_n^T
    else:
        d = sum(c.delta for c in kids) + dcm             # δ_n^U（恒健全）
    for a in n.A:
        if ledger.status[a] == 'carried' and ledger.used_to_loosen(n):
            raise ContractViolation('A44: carried assumption used to loosen')
    return d

def separation_cert(n):
    # 兄弟共享失败模式 = 共享物理探针/传感器/材质样本/标注者会话/同一欺骗通道
    modes = [failure_modes(c) for c in ch(n)]
    if overlap(modes) == empty:
        return Kappa(certified=True, common_cause=measured_budget(n), eps_k=0.0)
    return Kappa(certified=False, common_cause=upper_bound(overlap(modes)), eps_k=0.0)

def voi_h(n, M, D, ledger):
    d_without = root_risk_without(n, M, D, ledger)
    d_with    = root_risk_with(n, M, D, ledger)
    return (d_without - d_with) / cost_evidence(n)

def voi_ref(n, M, D, ledger):
    d_flat = root_risk_unrefined(n, M, D, ledger)
    d_split = root_risk_refined(n, M, D, ledger)
    return (d_flat - d_split) - cost_refine(n)

def allocate_and_plan(root, M, D, ledger, budget):
    frontier = {root}
    while budget.left > 0:
        cands = [(voi_h(n, M, D, ledger), 'discharge', n) for n in frontier] + \
                [(voi_ref(n, M, D, ledger), 'refine',    n) for n in frontier
                 if depth(n) < L_MAX]
        v, act, n = argmax(cands)
        if v < theta_voi: break
        if act == 'refine': expand(n); frontier |= ch(n)
        else: discharge(n); frontier.discard(n)
    return terminate_in({commit, repair, reroute, negotiate, safe_stop})

| 组件 | 时间 | 空间 | 正确性保证 |

| VOI-H | O(\|D\|·(C_VOI+C_comp)) | O(\|D\|) | 预算守恒、深度有界、四态终止 |

**正确性定理（HCGS, Hierarchical Contract-Gesture Soundness）**
假设 A37–A40（第 57 轮）成立；**(A41)** 契约组合健全：默认使用联合界，紧组合仅在分离证书 κ_n 经测量成立且 δ_cm(n) 覆盖共同原因时使用，证书违背概率 ≤ε_κ；**(A42)** 分层手势链校准诚实：逐层 ECE 与链误差满足定义 141，abstain 正确传播；**(A43)** 有向通道强制：不存在单通道 loosen 通过，双通道独立性与 δ_div 证书诚实；**(A44)** 假设账健全：carried 假设不得用于放宽，不可逆接触前必须转为 verified。则：

1. **根安全界**：P_safe ≥ (1−a_root)(1−δ_root)；δ_root 是实际组合风险的上界；使用紧组合引入的额外风险 ≤ N_κ·ε_κ。
2. **手势单调性**：仅手势通道使允许行为集合按 ⊑ 单调收缩，风险不增、最多损失可用性；任何风险增加必须经双通道 loosen，增量 ≤ ε_g·ε_second + δ_div + 证据门失效率。
3. **失效传播完备**：任一被证伪叶证据的全部承诺祖先必被重算，超 δ_f 者必被撤销；接触已发生者只影响下游与地图证据。
4. **终止性**：Σ探针 ≤ Σβ、细化深度 ≤ L_max，PCX-H 终止于 {承诺, 修复, 绕行, L2 协商, 安全停}。
5. **部署界升级**（用契约树替换第 57 轮平铺联合界）：

```
P_safe ≥ 1 − Σ_{n∈frontier} (δ_n + N_κ(n)·ε_κ + a_n·1[carried∧loosen])
             − P(𝓜 陈旧未检出) − P(手势链失效) − P(SafeStop 不可达)
```

关键：**联合界是默认，紧组合是特权**（无证书不得乘开相关风险）；**假设与保证同权记账**（不写进账本的假设不能被用来放宽）；**手势只收紧**（误停损失可用性、误放损失安全，权力按代价不对称分配）；**指代只改注意力**（错指把探针引偏，但偏不过证据门）；**分层只做责任分解、不做风险稀释**。

- 云端下发**契约模板与分离证书模式库**（按场景/材质簇/任务类型），边端实例化并回传违背事件；
- **契约模板更新也走隔离**：影子模式在历史边端日志上重放，要求"根上界不劣化 ∧ 无新增单通道 loosen ∧ 假设账可闭合"才接管；
- 边端回传失效传播统计（哪些叶证据最常触发契约修复）与手势误触发样本，作为云端共同原因建模与手势校准的补盲集；
- 全局硬界、决策规则本体、单通道放宽禁令**永不下放**。

## 6. UniBot 竞赛落地映射

| 场景 | 分层契约 | 手势通道 | 演示要点 |
|---|---|---|---|
| 长程巡检 | 任务层承诺"到 B 点"，自动细化到路线/段/落脚点；顶层假设显式展示 | 手指"这块区域"→ 只改探针注意力并回显 | 大屏展示契约树与假设账，说明"每层都有证据、且假设可审计" |

| 突发风险 | tighten 快路径 + SafeStop 投影 | 手势"停/慢"≤200ms 生效 | 对比误停只损失时间、不损失安全 |
| 事后复盘 | 失效传播 + 最小修复集 | 手势指认"上次出问题的区域" | 展示坏证据只污染相关契约，不全盘重来 |

## 7. 本轮最大风险

**一句话**：本轮把安全论证从"逐检查点证据"改成"分层契约组合"，最大风险是**契约漂移与指代漂移的叠加**——上层把正确性寄存在未审计的环境假设上、兄弟节点又用"看起来独立"的分离证书把相关失效乘开，使系统在每层都"有证据"地证明安全，却在顶层假设被证伪时整体失效；同时一个自信的错误指代会把探针引向错误区域，而"双通道"若共享同一观察者误差则形同虚设。故必须以假设账（carried 不可放宽）、默认联合界+可证伪分离证书、单通道永不放宽、指代只改注意力且可弃权五重护栏，把"分层"限制为**可审计的责任分解**，而不是风险的稀释术。
