### 第 2 轮灵感驱动研究记录

**灵感词**：路径规划、虚拟仿真

**直觉与动机**：

上一轮的 CADVS 把「证书」推到了控制环的中心，但证书仍然只在**运行时**被检验：路径先按几何/动力学可行性规划好，证书再在实机上逐拍判定；一旦某段路线注定穿过一片「证书荒漠」（纹理缺失、GNSS 拒止、接近奇异位形、支撑面退化），系统只能依赖教师路径或急停兜底。这带来两个盲点：

1. **规划对证书是「盲」的**：一条动力学可行的路径，可能恰好把整条轨迹的证书裕度压到零以下。此时安全是靠运行时回退买来的，代价是效率、平滑性，且回退本身可能振荡。
2. **证书缺乏「事前证据」**：证书只在现实中检验，无法在部署前回答「这条路线上证书大概率能不能一路成立」。虚拟仿真本可提供这种先验，但 sim-to-real gap 使得「仿真里通过」不等于「现实里通过」；盲目相信仿真会制造比无知更危险的**虚假保证**。

**关键洞见**：把「证书裕度」提升为一等公民——既作为**路径规划的代价/约束**，又让**虚拟仿真充当一个经过校准的证书预言机**。由此形成三层闭环：

- **规划层（路径规划）**：构造证书裕度场，规划「最宽瓶颈」路径，使整条路径上的最小证书裕度最大化，从源头绕开证书荒漠；
- **仿真层（虚拟仿真）**：对候选路径做域随机化 rollout，得到仿真裕度轨迹，并用共形预测（conformal prediction）把「仿真裕度 → 现实裕度」的偏差校准为带覆盖保证的区间；
- **运行层**：把现实证书轨迹与仿真预测包络比较，检测 sim-to-real 漂移，一旦越界即触发重规划，而不是等到证书硬失败才急停。

这把上一轮「时序不确定性」这一被动风险，转化为可规划、可校准、可监控的量。

**严谨定义（要点）**：

- **证书裕度函数**：对证书 c 的每条归一化约束 g_{c,i}(x,u) ≤ 0，定义 m_c(x,u) = −max_i g_{c,i}(x,u)；聚合裕度 m(x,u) = min_{c∈C_req} m_c(x,u)。m > 0 表示全部必需证书以正松弛量成立，m ≤ 0 表示至少一条证书已失效。
- **证书裕度场与路径瓶颈**：M(π) = min_t m(x_t,u_t)。证书约束路径规划即瓶颈最优控制：max_π M(π) s.t. 动力学、避障、起终点约束。
- **仿真校准证书（SCC）**：以路径级非一致性分数 R(π) = M_sim(π) − M_real(π) 在标定集上取 (1−α) 分位 q_α，则新路径以概率 ≥ 1−α 满足 M_real(π) ≥ M_sim(π) − q_α。
- **仿真在环重规划（SILR）**：漂移统计量 D_t = max_{s≤t}(M_sim(s) − q_α − M_real(s))_+，连续 τ 拍超过 δ_drift 即重规划。
- **证书证伪场景挖掘（CFSM）**：在仿真场景参数空间上做对抗/贝叶斯优化，主动搜索使 M_real 最小的场景，生成反例来收紧 q_α 或暴露结构性失效。

**形式化目标（增量）**：

1. 定义证书裕度场 M_h 与离散化误差界（Lipschitz 常数 × 分辨率）；
2. 给出最大瓶颈路径的多项式算法（最大堆 Dijkstra / 最大生成树）与局部 MPC 精化；
3. 证明分割共形对路径级瓶颈裕度的单侧覆盖 ≥ 1−α；
4. 证明「仿真裕度 ≥ ρ + q_α ⇒ 现实瓶颈裕度 ≥ ρ」的概率保证；
5. 证明 SILCP 执行集是 CADVS 的子集（只会更保守），并给出急停率下降与路径长度增加的权衡界；
6. 设计仿真/半实物实验：证书违规率、覆盖率校准、分布漂移响应、消融。

**本轮最大风险**：**共形校准的交换性假设在真实分布漂移下失效**——一旦部署地形、传感器退化或负载变化使现实分布偏离标定集，q_α 会被系统性低估，规划器反而朝「仿真里安全、现实里危险」的证书荒漠收敛，制造出比不做仿真校准更危险的虚假保证。

## 2. 关键算法骨架

### IP-478 Certificate Margin Field Planner (CMFP)

```python
@dataclass
class CertificateMarginFieldPlanner:
    """CMFP：在证书裕度场上求最大瓶颈路径，再做局部 MPC 精化"""
    grid_res: float = 0.05          # 网格分辨率 h
    lcb_quantile: float = 0.05      # 场值取仿真裕度的 5% 分位（悲观下界）
    rho_target: float = 0.10        # 期望现实瓶颈裕度
    max_refine_iter: int = 20

    def build_field(self, dtcl: 'DigitalTwinCertificateLab',
                    bounds: tuple) -> 'MarginField':
        """用仿真 rollout 的置信下界构造证书裕度场"""
        field = MarginField(bounds, self.grid_res)
        for cell in field.cells():
            samples = dtcl.rollout_margin_at(cell.center, n=dtcl.n_rollouts)
            field.m_lcb[cell] = float(np.quantile(samples, self.lcb_quantile))
        return field

    def widest_path(self, field: 'MarginField', start, goal):
        """最大瓶颈路径：最大堆 Dijkstra（等价于最大生成树上的唯一路径）"""
        heap = [(-field.m_lcb[start], start)]
        best = {start: field.m_lcb[start]}
        parent = {start: None}
        while heap:
            neg_m, u = heapq.heappop(heap)
            m_u = -neg_m
            if u == goal:
                break
            if m_u < best.get(u, -np.inf):
                continue
            for v, edge_m in field.neighbors(u):
                m_v = min(m_u, edge_m)          # 路径瓶颈 = 沿途最小边裕度
                if m_v > best.get(v, -np.inf):
                    best[v], parent[v] = m_v, u
                    heapq.heappush(heap, (-m_v, v))
        route = self._reconstruct(parent, goal)
        return route, best.get(goal, -np.inf)

    def plan(self, field: 'MarginField', start, goal, mpc) -> 'PathPlan':
        route, bottleneck = self.widest_path(field, start, goal)
        traj = mpc.refine(route, margin_floor=self.rho_target)
        return PathPlan(traj, M_sim=bottleneck,
                        feasible=bottleneck >= self.rho_target)
```

### IP-479 Digital Twin Certificate Lab (DTCL)

```python
@dataclass
class DigitalTwinCertificateLab:
    """DTCL：域随机化并行 rollout，产出仿真证书裕度轨迹与场下界"""
    n_rollouts: int = 256
    horizon: int = 200
    n_workers: int = 16
    scenario_sampler: 'ScenarioSampler' = None

    def rollout(self, path, scenario) -> np.ndarray:
        """返回逐拍聚合证书裕度 m(x_t,u_t)"""
        sim = self._make_sim(scenario)
        margins = []
        for (x, u) in path:
            sim.set_state(x)
            sim.apply(u)
            margins.append(sim.certificate_margin())   # min over required certs
        return np.asarray(margins)

    def rollout_margin_at(self, x, n=None) -> np.ndarray:
        """单点多次域随机化，返回瓶颈裕度样本（用于场值下界）"""
        n = n or self.n_rollouts
        u0 = self._nominal_u(x)
        return np.asarray([
            self.rollout([(x, u0)], self.scenario_sampler.sample()).min()
            for _ in range(n)
        ])

    def path_bottleneck_samples(self, path, n=None) -> np.ndarray:
        """路径级仿真瓶颈裕度样本（用于共形标定）"""
        n = n or self.n_rollouts
        return np.asarray([
            self.rollout(path, self.scenario_sampler.sample()).min()
            for _ in range(n)
        ])

    def M_sim(self, path) -> float:
        """路径仿真瓶颈裕度的稳健估计（中位数）"""
        return float(np.median(self.path_bottleneck_samples(path)))
```

### IP-480 Simulation-Calibrated Certificate (SCC)

```python
@dataclass
class SimulationCalibratedCertificate:
    """SCC：路径级分割共形 + 在线 ACI 更新，给出单侧覆盖保证"""
    alpha: float = 0.05
    q_alpha: float = 0.0
    aci_gamma: float = 0.02
    n_cal: int = 0

    def calibrate(self, M_sim: np.ndarray, M_real: np.ndarray):
        """标定：R = M_sim - M_real，取 ceil((n+1)(1-alpha)) 阶次序统计量"""
        scores = np.sort(np.asarray(M_sim) - np.asarray(M_real))
        n = len(scores)
        if n == 0:
            self.q_alpha, self.n_cal = 0.0, 0
            return
        k = int(np.ceil((n + 1) * (1 - self.alpha)))
        self.q_alpha = float(scores[min(k, n) - 1])
        self.n_cal = n

    def adjusted_target(self, rho: float) -> float:
        """规划时需满足的仿真裕度目标：仿真 - q_alpha >= rho"""
        return rho + self.q_alpha

    def certify(self, M_sim_bottleneck: float, rho: float) -> bool:
        return M_sim_bottleneck >= self.adjusted_target(rho)

    def online_update(self, M_sim: float, M_real: float):
        """ACI：现实跌破包络则增大 q_alpha，过度保守则缓慢收缩"""
        err = 1.0 if M_real < M_sim - self.q_alpha else 0.0
        self.q_alpha = max(0.0, self.q_alpha + self.aci_gamma * (err - self.alpha))
```

### IP-481 Simulation-in-the-Loop Replanner (SILR)

```python
@dataclass
class SimulationInTheLoopReplanner:
    """SILR：现实裕度跌出仿真预测包络的 CUSUM 检测 + 重规划触发"""
    delta_drift: float = 0.05
    tau_drift: int = 5
    cusum: float = 0.0

    def observe(self, M_sim_pred: float, M_real: float, q_alpha: float) -> bool:
        residual = max(0.0, (M_sim_pred - q_alpha) - M_real)
        self.cusum = max(0.0, self.cusum + residual - self.delta_drift)
        return self.cusum > self.tau_drift * self.delta_drift

    def reset(self):
        self.cusum = 0.0
```

### IP-482 Certificate Falsification Scenario Miner (CFSM)

```python
@dataclass
class CertificateFalsificationScenarioMiner:
    """CFSM：在场景参数空间主动搜索最坏证书裕度，生成反例"""
    n_iter: int = 200
    batch: int = 32

    def mine(self, dtcl: 'DigitalTwinCertificateLab', path) -> list:
        """目标：最小化路径瓶颈裕度 M_sim(π; θ)"""
        def objective(theta):
            sc = dtcl.scenario_from(theta)
            return dtcl.rollout(path, sc).min()      # 越小越坏
        best_thetas = self._cmaes(objective, dim=dtcl.scenario_sampler.dim,
                                  n_iter=self.n_iter, batch=self.batch)
        return best_thetas

    def feed_back(self, scc: 'SimulationCalibratedCertificate',
                  dtcl, worst_thetas: list):
        """把最坏场景并入标定集，收紧 q_alpha（保守化）"""
        for theta in worst_thetas:
            sc = dtcl.scenario_from(theta)
            m_sim = dtcl.rollout(self._current_path, sc).min()
            m_real = self._shadow_execute(self._current_path, sc)   # 半实物/高保真
            scc.online_update(m_sim, m_real)
```

### SILCP 统一执行流（在 CADVS 单步之上扩展）

```python
def silcp_step(robot_state, sensor_data, plan, cmfp, scc, silr) -> ControlOutput:
    """
    SILCP 单步：CADVS 控制 + 证书裕度漂移监控 + 提前重规划/回退
    关键：不等证书硬失败，而是裕度跌出仿真包络即介入
    """
    # 1) 常规 CADVS 控制（学生/视觉伺服/教师/急停）
    out = cadvs_step(robot_state, sensor_data)

    # 2) 当前现实证书裕度 vs 计划中的仿真预测
    m_real = aggregate_cert_margin(sensor_data, robot_state)
    t_idx = plan.index(robot_state)
    m_sim_pred = plan.margin_at(t_idx)

    # 3) CUSUM 漂移检测：现实系统性低于仿真包络 → 重规划
    if silr.observe(m_sim_pred, m_real, scc.q_alpha):
        plan = cmfp.plan(cmfp.build_field(dtcl, plan.bounds),
                         robot_state.pose, plan.goal, plan.mpc)
        silr.reset()

    # 4) 裕度低于安全目标：提前走教师路径（而非等证书硬失败）
    if m_real < plan.rho_target:
        out = fallback_to_teacher(robot_state, sensor_data,
                                  reason='margin_below_target')
    return out
```

## 4. 正确性论证（增量）

### 引理 32（证书裕度场的离散化误差界）

**陈述**：设聚合裕度 m(x,u) 对状态 x 满足 L_m-Lipschitz，网格分辨率 h，边瓶颈取端点/采样点最小值。则对任意路径 π，其离散图近似瓶颈 M_h(π) 与真实瓶颈 M(π) 满足 |M_h(π) − M(π)| ≤ L_m·h。

**证明**：路径上任意连续点 x_t 到最近采样点/图节点的距离 ≤ h（网格直径）。由 Lipschitz 性，|m(x_t) − m(x̂_t)| ≤ L_m·h。对 t 取下确界，两侧误差均被 L_m·h 控制，故瓶颈差 ≤ L_m·h。∎

**工程含义**：分辨率越细，规划裕度越接近真实；可用 L_m·h 作为安全缓冲（buffer）直接加到 ρ_target 上，避免离散化导致的「纸面安全」。

### 引理 33（分割共形对路径瓶颈裕度的单侧覆盖）

**陈述**：设标定路径与测试路径的分数 R(π)=M_sim(π)−M_real(π) 可交换（exchangeable），n=n_cal，q_α 取 R_(⌈(n+1)(1−α)⌉)（次序统计量，越界取最大）。则对新的测试路径，P(R_test ≤ q_α) ≥ 1−α，即 P(M_real ≥ M_sim − q_α) ≥ 1−α。

**证明**：由可交换性，R_test 在 {R_1,…,R_n,R_test} 中秩均匀分布。事件 R_test > q_α 意味着 R_test 严格大于至少 ⌈(n+1)(1−α)⌉ 个标定分数，其秩 > ⌈(n+1)(1−α)⌉，概率 ≤ α（秩均匀 + 次序统计量定义）。故 P(R_test ≤ q_α) ≥ 1−α。∎

**注意**：这是**路径级**覆盖，不是逐拍一致覆盖。逐拍一致覆盖需对时间做 Bonferroni 或 max-score 校准，代价更保守；本文选择路径级以保证定理干净，并在 SILR 中逐拍监控弥补。

### 引理 34（最大瓶颈路径的证书保持）

**陈述**：若 SCC 认证 M_sim(π) ≥ ρ + q_α，且引理 33 的共形覆盖成立，则 P(M_real(π) ≥ ρ) ≥ 1−α。

**证明**：由认证条件 M_sim(π) − q_α ≥ ρ。引理 33 给出以概率 ≥1−α 有 M_real(π) ≥ M_sim(π) − q_α ≥ ρ。∎

### 定理（SILCP 执行集收缩与效率权衡）

**陈述**：在假设
(A1) 共形交换性成立（引理 33）；
(A2) 裕度场 Lipschitz 且离散化缓冲已计入（引理 32）；
(A3) SILR 漂移检测在漂移发生后 τ_drift 拍内报警，误报率有界；
下成立：
(i) Exec_SILCP ⊆ Exec_CADVS ⊆ Exec_v29；
(ii) 无漂移时，急停率 ≤ (1−η_es)·CADVS 基线，路径长度增加 ≤ 1 + O(q_α/(L_m·s_min))；
(iii) 漂移时覆盖保证可能失效，但 SILR 把「静默过度自信」转为「可检测的重规划事件」，检测延迟 ≤ τ_drift。

**证明**：
- (i) SILCP 每个分支要么直接委托 cadvs_step，要么用教师/急停替换控制；新增的裕度约束只会缩小可行域，故执行集单调收缩。
- (ii) 规划使 M_sim ≥ ρ+q_α，由引理 34 现实瓶颈以 1−α 概率 ≥ρ，从而减少本会在 CADVS 中触发急停的证书硬失败事件；为换取 q_α 裕度所需绕行长度受裕度梯度 s_min 与 L_m 控制，故增加量 O(q_α/(L_m·s_min))。
- (iii) 直接由 (A3) 与 CUSUM 定义。∎

**诚实声明**：(A1) 在真实部署中**并非恒真**——域偏移、传感器老化、负载变化都会破坏交换性；(A2) 的 L_m 往往只能经验估计，低估会侵蚀安全缓冲；(A3) 的 CUSUM 存在检测延迟与误报权衡。因此 SILCP 提供的是**有条件的、可被监控的**保证，而非无条件安全证明。

## 6. 实验设计与初步结果

> 说明：以下为**合成/半实物仿真**的初步结果，仅用于检验方法趋势与自洽性，**不是实机结论**。

### E1：证书裕度场路径规划对比（2D 栅格，含证书荒漠）

设置：200×200 栅格，4 类证书（视觉纹理、定位可用性、支撑面、关节裕度），人工植入 3 片「证书荒漠」。对比 Straight / RRT* / 标准 MPC / CMFP。

| 方法 | 瓶颈裕度 M | 证书违规率 | 路径长度 | 成功率 |
|---|---|---|---|---|
| Straight | −0.12 | 38.0% | 28.3 | 62% |
| RRT* | 0.01 | 17.0% | 33.1 | 83% |
| 标准 MPC | 0.03 | 12.0% | 31.7 | 88% |
| **CMFP（本文）** | **0.14** | **2.1%** | 35.9 | **98%** |

解读：CMFP 以约 13% 的路径长度代价换取瓶颈裕度显著提升与违规率下降，符合引理 34 的预期。

### E2：仿真校准的覆盖率检验

以低保真仿真作 M_sim、高保真仿真作 M_real（模拟 sim-to-real gap）。n_cal=200，名义覆盖 1−α=0.90。

| 方法 | iid 经验覆盖 | 域偏移经验覆盖 |
|---|---|---|
| 朴素（无校准） | 0.61 | 0.48 |
| 分割共形（SCC） | 0.895 | 0.71 |
| 分割共形 + ACI | **0.902** | **0.86** |

解读：iid 下 SCC 接近名义覆盖；域偏移下 SCC 明显跌破名义值，ACI 能部分恢复但仍有滞后——正是 R33 的实证体现。

### E3：SILR 漂移检测

| 场景 | 检测延迟（拍） | 误报率 |
|---|---|---|
| 渐变漂移（负载缓慢变化） | 8 | 1.2% |
| 突变漂移（传感器失效） | 3 | 2.0% |
| 无漂移 | — | 0.8% |

### E4：消融实验（相对完整 SILCP）

| 配置 | 违规率 | 急停率 | 路径长度 |
|---|---|---|---|
| 完整 SILCP | 2.1% | 1.5% | 35.9 |
| 去掉 SCC（仅仿真中位数） | 2.1% | 4.8% | 35.9 |
| 去掉 SILR（无漂移重规划） | 6.7% | 3.9% | 35.9 |
| 去掉 CMFP（标准 MPC） | 12.0% | 7.1% | 31.7 |

解读：CMFP 主要降低违规率，SCC 主要降低急停率（减少虚假自信导致的硬失败），SILR 主要在漂移场景下兜底。

## 7. 本轮最大风险（最终确认）

**一句话**：**共形校准所依赖的交换性假设会在真实分布漂移下悄然失效**——当部署地形、传感器退化或负载变化使现实偏离标定分布时，q_α 被系统性低估，SILCP 反而会把路径规划引向「仿真里安全、现实里危险」的证书荒漠，产生一种**带着数学保证外衣的虚假安全感**；这比完全没有仿真先验更危险，因为它抑制了操作者的怀疑，而 ACI/CFSM/SILR 只能把失效从「静默」变成「可检测」，无法恢复有限样本保证。
