# 第 57 轮（承接第 56 轮「证据地图×主动探询×信任协商」IP-127~132；本轮灵感：「抗干扰」×「可扩展性」）

> 第 56 轮把安全前提从"模型置信"升级为"证据承诺"，用持久地图 𝓜、探-诺-演 PCE、证据门与有界人类交互，把不确定性变成可交易对象。但它的两个隐含前提正是本轮灵感的靶心：**(P1) 证据条件独立且来源诚实**——贝叶斯融合、ECE 校准、加权人类标注都只保证"边际上大致可信"，不保证"相关扰动下仍可信"；**(P2) 地图与证书是单体对象**——全域融合、全域 VOI、整本 J_m 复算，在区域数、机队规模、操作者数量增长时同时撞上时延、隐私与单点失效。本轮把命题从"证据说可信"升级为 **"在已计入的扰动下、由独立来源佐证的可信"**，并把单体证据结构升级为 **可组合、可增量验证的证据织体**。

核心矛盾：
- **H26（抗干扰）**：第 56 轮的融合默认似然诚实、证据条件独立。可现实扰动是**相关的**——一次全场光照变化、一阵粉尘、一段通信抖动、一个被投毒的先验，会让许多区域同时产生"互相印证"的错误证据。校准是边际性质，挡不住**条件相关的系统性偏移**；来源隔离与陈旧衰减是逐源、逐区域的，挡不住"跨源跨域一起错"。当十个同源观测被当成十次独立佐证，`n_eff` 的幻觉就足以让证据门"诚实放行"。
- **H27（可扩展性）**：全域 𝓜 与整本 J_m 的代价随 |V| 线性甚至更高，全域 VOI 组合爆炸；集中式操作者信任池既是瓶颈也是隐私问题。但**朴素分片**会制造更隐蔽的失败：每个分片只看得见本地证据与接口摘要，若接口未传播共性扰动，N 个局部乐观会被组合证书叠加成全局不安全。

## 0. 直觉与动机

**灵感 1（抗干扰 → 把"扰动"从"世界"里拆出来，并给扰动记账）**
直觉：现有做法是"把证据打个折"，但正确的第一步是**分清是谁在说谎**——是世界真的变了（θ），还是观测通道坏了（ψ：光照、粉尘、振动、标定漂移、通信时延、被投毒先验）。把 `(θ, ψ)` 显式建模后，融合不再是"多加一个似然"，而是"先估扰动、再在扰动可信集内做稳健后验"。关键推论：**佐证必须按来源多样性折扣**。同一台退化相机连拍十帧，是一个证人被问了十次，不是十个独立证人；有效样本量 `n_eff` 必须按相关簇惩罚，而不是简单数条数。

**灵感 2（抗干扰 → 从"权重封顶"到"抗相关/抗拜占庭聚合"）**
直觉：第 56 轮用 `w_h ≤ w_max` 与隔离区限制坏标注，这是**单源有界**；但若 20% 的来源被同一扰动或同一对手同时污染，加权平均仍会被拉走。需要**次序统计/截尾/几何中位数**这类有崩溃点的聚合，加上"每站权重上限 + 跨站独立佐证数"的双重门槛。抗干扰不是把权重调小，而是让**少数派无法靠相关性伪装成多数派**。

**灵感 3（可扩展性 → 地图分片 + 版本化接口 + 契约组合）**
直觉：地图应像**模块化类型系统**，而不是一块整石。把区域簇切成 shard，每个 shard 自带本地信念、本地生存核、本地证书，并通过**带版本的接口**只暴露邻居所需的摘要（边界风险上界、版本、扰动体制）。安全就能**组合**：接口假设被上游保证 discharge，风险按并集界相加、裕度取 min。于是局部承诺只需 O(|shard|)，增量更新只需重验"依赖锥"，而不是整图。

**灵感 4（可扩展性 → 层级 VOI 与联邦信任）**
直觉：探询不该在全图所有区域上做 `argmax_VOI`。先用**粗粒度**决定"哪一簇 shard 值得探"，再在簇内做细粒度探针，把组合代价从 |V| 降到 |shards| + |local|。信任校准同样不应集中收原始标注：各站保留本地充分统计量，只交换**有界、可截尾**的统计摘要，用鲁棒聚合学习全局操作者权重——既护隐私，又抗单站投毒。

**灵感 5（综合 → 共性扰动哨兵：抗干扰与可扩展性的接缝）**
直觉：分片最大的盲点恰是**跨分片共性扰动**——全场光照、统一时间同步错误、同一云先验的系统偏差。这些量在单个 shard 内不可辨识，却会让所有 shard 同时偏。于是需要一层**极轻量的全局哨兵**：只估计少量共性潜变量（common-mode nuisance）与接口版本一致性，一旦检测到共性偏移，就**批量失效**受影响分片的证书并触发全局重选/降档。局部证明负责规模，全局哨兵负责相关失效——这是本轮把两个灵感缝在一起的关键。

## 1. 形式化定义（增量：定义 133–138）

**定义 133（扰动增广信念与 ε-污染稳健后验）** 世界状态 `θ_r`（标签、`(μ,k,F_bear)`）与扰动状态 `ψ ∈ Ψ` 分离；似然 `p(e | θ_r, ψ)`。信念取 ε-污染形式：
`b_r(θ) = (1−ε_d)·f(θ | e_{1:t}) + ε_d·q(θ)`，
其中 `q` 为对扰动最不利的先验，`ε_d(t) = P(ψ ∉ Ψ_δ(t)) + drift_ψ` 为**扰动预算**，`Ψ_δ(t)` 是 `ψ` 的置信集。融合用 Huber 化权重 `h(e)=min(1, c/‖score(e)‖)`，并只允许 `Ψ_δ` 内的似然参与高险承诺。

**定义 134（来源多样性-有效样本量与稳健融合）** 证据按溯源簇 `{C_j}` 分组，簇内相关 `ρ_j ∈ [0,1]`，簇间近似独立。有效样本量
`n_eff(r) = (Σ_i w_i)^2 / (Σ_i Σ_k w_i w_k ρ_{ik})`，`ρ_ii=1`。
高险承诺需同时满足 `n_eff(r) ≥ n_min` 与 `|{src_class}| ≥ k_src`。融合算子 `Fuse_robust` 取加权几何中位数/截尾似然，且 `w_i ← w_i / (1 + (|C_j|−1)ρ_j)`——**相关簇先降权，再入融合**。

**定义 135（分片地图与版本接口）** `𝓜 = (⨆_s 𝓜_s, ℐ)`；分片 `𝓜_s = (G_s, {b_r}_{r∈s}, K_{B,s}, cert_s, ver_s)`；接口
`ℐ_{s,s'} = (∂_{s,s'}, b_∂, risk_bound_∂, ψ_regime, ver_∂)`，其中 `∂_{s,s'}` 是边界区域集，`b_∂` 是边界信念摘要，`ψ_regime` 是该接口约定的扰动体制。**接口只能通过版本化摘要影响邻居**，不能回写对方内部信念。

**定义 136（假设-保证契约与证书代数）** 分片契约 `C_s = (A_s, G_s)`：`A_s` 为边界假设（入边风险上界、扰动体制、新鲜度），`G_s` 为本地保证（`risk_s ≤ δ_s`、`K_margin_s ≥ θ_K`、出边供给能力）。组合 `C_s ∘ C_{s'}` 合法当且仅当共享接口上 `G_s ⊨ A_{s'}` 且 `G_{s'} ⊨ A_s`。证书在算子 `⊕` 下构成交换幺半群：**风险相加**（并集界）、**裕度取 min**、**版本/新鲜度取合取**。增量重验证只覆盖"本地证据或接口版本变化"的依赖锥 `D_r`（默认半径 r 的分片邻域）。

**定义 137（联邦信任与抗投毒聚合）** 站点 `i` 的本地充分统计 `s_i = (n_i^+, n_i^-, cal_i)`；全局权重
`w_h(i) = clip(ρ(median_j s_j, s_i), 0, w_max)`，
并要求跨站独立佐证 `|{site: s_j 支持}| ≥ k_site`。只交换有界摘要、按站裁剪、原始标注不出站；拜占庭比例 `β` 超过 `β_max` 时降级为"仅用探针证据"。

**定义 138（层级韧性排程与规模预算）** 两级 VOI：先选分片簇 `c`，再在簇内选探针 `π`，
`VOI(c,π) = E[ΔR | π] − λ_d·Δε_d(π) − cost(π)`（`Δε_d` 为探针带来的扰动预算收缩）。韧性阶梯：评估 → 检测扰动 → 隔离坏源 → 重探 → 降档 → 安全停，每级有独立时延上界。规模预算 `k_shard`、`k_local` 保证每轮探询次数与分片数解耦。

## 2. 关键算法伪代码（完整版见产物区）

### IP-133 DRE（Disturbance-Resilient Evidence）

```python
def robust_belief_update(b, e, psi_hat, epsilon_d):
    if not in_credible_set(e, psi_hat):          # A37: 扰动外证据不入高险承诺
        return b, 'quarantined'
    like = huber_likelihood(e, c=kappa)
    post = bayes_update(b, like, weight=huber_weight(e, kappa))
    return (1 - epsilon_d) * post + epsilon_d * worst_case_prior(b), 'ok'
```

### IP-134 BCRF（Byzantine/Correlation-Resilient Fusion）

```python
def fuse_robust(M, batch):
    for r in regions(batch):
        clusters = provenance_clusters(batch[r])
        for C in clusters:                        # A38: 相关簇先降权
            rho = estimate_intra_corr(C)
            for e in C: e.w /= (1 + (len(C) - 1) * rho)
        neff = effective_sample_size(batch[r])
        if risk_class(r) == 'high' and neff < n_min:
            M.b[r] = quarantine_until_corroborated(M.b[r], batch[r])
            continue
        agg = trimmed_geometric_median(batch[r], trim=beta_max)
        M.b[r] = robust_belief_update(M.b[r], agg, M.psi[r], M.epsilon_d[r])
    return M
```

### IP-135/136 HSM + CCA（分片与契约组合）

```python
def compose_certificates(M, route):
    leaves = [certify_shard(M.s, route) for s in route.shards]
    dag = build_proof_dag(leaves)                # 节点=分片证书，边=接口
    for edge in dag.edges:                       # A39: 接口假设必须被 discharge
        if not discharges(edge.src.guarantee, edge.dst.assumption):
            return ('reject', 'interface_undischarged', edge)
    total_risk = sum(c.risk for c in leaves)     # 并集界
    min_margin = min(c.K_margin for c in leaves)
    if total_risk > route.delta_budget or min_margin < theta_K:
        return ('reject', 'composed_unsafe')
    return ('ok', CompositeCert(dag, total_risk, min_margin, versions=meet(leaves)))

def incremental_reverify(M, changed_shards):
    cone = dependency_cone(changed_shards, radius=r)   # 只重验依赖锥
    return compose_certificates(M, restrict(cone))
```

### IP-137 FTC（Federated Trust Calibration）

```python
def federated_trust(local_stats, beta_max):
    if byzantine_fraction(local_stats) > beta_max:
        return {i: 0.0 for i in local_stats}     # 降级：只信探针
    robust_ref = median([s.score for s in local_stats.values()])
    return {i: clip(rho(robust_ref, s.score), 0.0, w_max)
            for i, s in local_stats.items()}
```

### IP-138 SRP（Scalable Resilience-aware Planning）

```python
def scalable_probe_commit(x0, M, task, budget, sentinel):
    route = plan_on_layered_map(M, task)
    for cp in route.checkpoints:
        if sentinel.common_mode_shift(cp):       # 共性扰动：批量失效 + 重选
            invalidate_contracts(M, sentinel.affected_shards)
            route = global_replan(M, task)
        shard = coarse_voi_select(cp, M, budget)
        sigma, R = local_pce(x0, cp, M.shard[shard], budget)
        if select_gait(R) == 'halt':
            return negotiate_or_stop(cp, M, sigma, R, budget.consent)
    return commit_route(route), compose_certificates(M, route)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| DRE | O(\|e\|·d_ψ) | O(\|Ψ_δ\|·d_θ) | 扰动预算外不下高险承诺（A37） |
| BCRF | O(\|E_r\|·log\|E_r\|) | O(\|C_j\|) | 相关簇降权、`n_eff` 诚实（A38） |
| HSM/CCA | O(Σ_s\|𝓜_s\|)+O(\|ℐ\|) | O(Σ_s\|𝓜_s\|) | 接口假设 discharge、风险并集界（A39） |
| 增量重验 | O(\|D_r\|·\|𝓜_s\|) | O(\|D_r\|) | 依赖锥完备、版本一致 |
| FTC | O(#sites·log #sites) | O(#sites) | 截尾聚合、`β<β_max`（A40） |
| SRP | O(\|shards\|·k_shard + \|local\|·k_local) | O(\|𝓜\|) | 层级 VOI 可分解、预算终止 |

**正确性定理（Disturbance-Robust Compositional Soundness, DRCS）**：在 A33–A36 基础上加 **(A37)** 扰动可检测：`P(ψ ∉ Ψ_δ) ≤ ε_d` 且检测时延 `≤ τ_d`；**(A38)** 稳健融合对 `ε_d`-污染有界，且 `n_eff ≥ n_min`、来源多样性达标时后验误差 `≤ ε_cal + ε_d`；**(A39)** 分片契约局部成立且共享接口假设被 discharge，组合取并集界；**(A40)** 联邦聚合拜占庭比例 `β < β_max`、每站权重有界且截尾。则：
(i) 承诺接触失效率 `≤ δ_f + ε_cal + ε_d + δ_probe + ε_h + ε_byz`；
(ii) **组合健全性**：若所有分片契约成立、接口全部 discharge、且共性扰动哨兵未报未决偏移，则整条路线证书有效；
(iii) **规模界**：局部承诺代价 `O(|𝓜_s| + |∂|)`，增量重验代价正比于依赖锥而非全图；
(iv) **无静默共性失效**：哨兵未决或接口版本不一致时禁止组合，回退全局重选/降档/安全停。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 分片接口漏检跨域共性扰动 | 高 | 共性扰动哨兵 + 接口 `ψ_regime` 版本 + 全局重选回退 |
| 稳健聚合过保守导致可用性塌陷 | 高 | 按风险分级启用聚合强度；探针补证；可用性监控回退 |
| `n_eff`/相关估计被操纵或自证 | 中 | 外部溯源审计 + 多估计器交叉 + 最坏相关上界 |
| 联邦信任冷启动与小样本偏差 | 中 | 冷启动只用探针证据；按站最小样本门槛 |
| 增量重验漏掉依赖锥外级联 | 中 | 版本向量 + 锥外抽查 + 定期全量复核 |

## 6. 本轮最大风险

**一句话**：抗干扰与可扩展性一起追求，最容易制造"每个分片都诚实地安全"的错觉——真正的系统性失效藏在分片接口的**跨域共性扰动**里：当全场光照、统一时间偏差或同一被投毒先验让所有分片同时向同一方向偏移时，局部稳健与局部证书会各自成立，而组合算子把 N 个局部乐观按并集界"合法地"加成一个全局灾难；因此必须以共性扰动哨兵、接口扰动体制版本化、以及"哨兵未决即禁止组合"的保守回退作为不可绕过的第三层，宁可牺牲局部可用性，也绝不把相关失效当成独立巧合。

## 2. 关键算法伪代码

### IP-133 DRE（Disturbance-Resilient Evidence）

```python
def estimate_disturbance(evidence_batch, psi_prev):
    psi_hat = robust_filter(evidence_batch, psi_prev)      # 光照/粉尘/振动/漂移
    psi_set = credible_set(psi_hat, alpha=delta_psi)
    eps_d   = 1.0 - mass(psi_set) + drift_bound(psi_prev)
    return psi_hat, psi_set, eps_d

def robust_belief_update(b, e, psi_hat, psi_set, eps_d):
    if not in_credible_set(e, psi_set):                    # A37
        return b, 'quarantined'                            # 扰动外证据不入高险承诺
    like = huber_likelihood(e, psi_hat, c=kappa)
    post = bayes_update(b, like, weight=huber_weight(e, kappa))
    return (1 - eps_d) * post + eps_d * worst_case_prior(b), 'ok'
```

### IP-134 BCRF（Byzantine/Correlation-Resilient Fusion）

```python
def effective_sample_size(evidence):
    num = sum(e.w for e in evidence) ** 2
    den = sum(e1.w * e2.w * corr(e1, e2) for e1 in evidence for e2 in evidence)
    return num / max(den, 1e-9)                             # A38: 相关簇不重复计数

def fuse_robust(M, batch):
    for r in regions(batch):
        clusters = provenance_clusters(batch[r])
        for C in clusters:                                  # 相关簇先降权
            rho = estimate_intra_corr(C)
            for e in C: e.w /= (1 + (len(C) - 1) * rho)
        neff = effective_sample_size(batch[r])
        if risk_class(r) == 'high' and neff < n_min:
            M.b[r] = quarantine_until_corroborated(M.b[r], batch[r])
            M.audit.append(('n_eff_insufficient', r, neff)); continue
        if byzantine_fraction(batch[r]) > beta_max:
            M.b[r] = probe_only_posterior(M.b[r], batch[r])  # A40 降级
            continue
        agg = trimmed_geometric_median(batch[r], trim=beta_max)
        M.b[r], st = robust_belief_update(M.b[r], agg, M.psi[r], M.psi_set[r], M.eps_d[r])
    return M
```

### IP-135 HSM（Hierarchical Sharded Map）

```python
def shard_interface(M, s, s2):
    bd = boundary_regions(M.s[s], M.s[s2])
    return Interface(regions=bd,
                     b_summary=summarize({r: M.b[r] for r in bd}),

def refresh_interfaces(M, changed):

        M.I[s, s2] = shard_interface(M, s, s2)
    return M
```

### IP-136 CCA（Compositional Certificate Algebra）

```python
def certify_shard(M, s, route):
    local = [c for c in route.contacts if c.shard == s]
    if not all(evidence_ok(c, M) for c in local): return ShardCert.fail(s, 'evidence')
    return ShardCert(s, risk=sum(c.p_fail for c in local),
                        K_margin=min_contact_margin(local, M),
                        G=outgoing_supply(local), ver=M.s[s].ver)

def compose_certificates(M, route):
    leaves = [certify_shard(M, s, route) for s in route.shards]
    dag = build_proof_dag(leaves)
    for edge in dag.edges:                                  # A39
        if not discharges(edge.src.G, edge.dst.A):
            return ('reject', 'interface_undischarged', edge)
        if edge.dst.A.psi_regime != M.psi_regime[edge.src.s]:
            return ('reject', 'psi_regime_mismatch', edge)
    total_risk = sum(c.risk for c in leaves)                # 并集界
    min_margin = min(c.K_margin for c in leaves)
    if total_risk > route.delta_budget: return ('reject', 'composed_risk')
    if min_margin < theta_K:            return ('reject', 'composed_margin')
    if not M.sentinel.clean:            return ('reject', 'common_mode_unresolved')
    return ('ok', CompositeCert(dag, total_risk, min_margin,
                                meet_versions(leaves), M.psi_regime))

def incremental_reverify(M, changed_shards):
    cone = dependency_cone(changed_shards, radius=r)        # 依赖锥
    M = refresh_interfaces(M, changed_shards)
    return compose_certificates(M, restrict_route(cone))
```

### IP-137 FTC（Federated Trust Calibration）

```python
def federated_trust(local_stats, beta_max):
    if byzantine_fraction(local_stats) > beta_max:
        return {i: 0.0 for i in local_stats}                # 降级：只信探针
    ref = median([s.aggregate_score for s in local_stats.values()])
    out = {}
    for i, s in local_stats.items():
        raw = rho(ref, s.aggregate_score)
        out[i] = clip(raw, 0.0, w_max) if s.n >= n_site_min else 0.0
    return out
```

### IP-138 SRP（Scalable Resilience-aware Planning）

```python
def scalable_probe_commit(x0, M, task, budget):
    route = plan_on_layered_map(M, task)
    for cp in route.checkpoints:
        if M.sentinel.common_mode_shift(cp):                # 共性扰动哨兵
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DRE | O(\|e\|·d_ψ) | O(\|Ψ_δ\|·d_θ) | 扰动预算外不下高险承诺（A37） |
| BCRF | O(\|E_r\| log\|E_r\| + \|C_j\|²) | O(\|C_j\|) | 相关簇降权、`n_eff` 诚实（A38） |
| HSM | O(Σ_s\|𝓜_s\| + \|ℐ\|) | O(Σ_s\|𝓜_s\| + \|ℐ\|) | 接口摘要不越界、版本一致 |
| CCA | O(Σ_s\|contact_s\| + \|ℐ\|) | O(\|DAG\|) | 接口 discharge、风险并集界（A39） |
| 增量重验 | O(\|D_r\|·\|𝓜_s\|) | O(\|D_r\|) | 依赖锥完备、版本向量 |
| FTC | O(#sites log #sites) | O(#sites) | 截尾聚合、`β<β_max`（A40） |
| SRP | O(\|shards\| k_shard + \|local\| k_local) | O(\|𝓜\|) | 层级 VOI 可分解、预算终止 |

**正确性定理（Disturbance-Robust Compositional Soundness, DRCS）**
假设 A22–A28（第 53/54 轮）、A29–A36（第 55/56 轮）成立；**(A37)** 扰动可检测：`P(ψ∉Ψ_δ) ≤ ε_d`，检测时延 `≤ τ_d`；**(A38)** 稳健融合对 `ε_d`-污染有界，`n_eff ≥ n_min` 且来源多样性达标时后验误差 `≤ ε_cal + ε_d`；**(A39)** 分片契约局部成立、共享接口假设被 discharge，组合取并集界；**(A40)** 联邦聚合满足 `β < β_max`、每站权重有界且截尾。则：

1. **逐接触健全性**：`P(fail) ≤ δ_f + ε_cal + ε_d + δ_probe + ε_h + ε_byz`；
2. **组合健全性**：若所有分片契约成立、接口全部 discharge、`ψ_regime` 一致且共性扰动哨兵 clean，则整条路线证书有效；
3. **无静默共性失效**：哨兵未决或接口版本不一致时组合算子拒绝，回退全局重选 / 降档 / 安全停；
4. **规模界**：局部承诺 `O(|𝓜_s|+|∂|)`，增量重验正比于依赖锥，仅在契约失效时退回全局；
5. **部署界**（对检查点与分片取联合界）：

```
P_safe ≥ 1 − Σ_cp [δ_f + ε_cal + ε_d + δ_probe + ε_h + ε_byz]
             − P(共性扰动漏检) − P(接口假设未 discharge) − P(依赖锥外级联)
```

关键：**证据必须独立才算佐证**（相关簇降权 + `n_eff`）；**安全必须可组合才算规模**（契约 + 并集界 + 依赖锥）；**可组合的前提是共性扰动可见**（哨兵 + `ψ_regime` 版本 + 拒组合回退）。三者缺一，规模就把局部稳健放大成全局脆弱。

## 6. 本轮最大风险

**一句话**：抗扰与可扩展一起追求，最危险的是"每个分片都诚实地安全"的合成幻觉——全场光照、统一时间偏差或同一被投毒先验这类**跨域共性扰动**会让所有分片同时向同一方向偏移，局部稳健与局部证书各自成立，而组合算子把 N 个局部乐观按并集界"合法地"加成一个全局灾难；必须以共性扰动哨兵、接口 `ψ_regime` 版本化、以及"哨兵未决即禁止组合"的回退作为不可绕过的第三层，宁可牺牲局部可用性，也绝不把相关失效当成独立巧合。
