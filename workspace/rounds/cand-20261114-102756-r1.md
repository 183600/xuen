# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS」IP-287~294；灵感循环第 1 轮；本轮灵感：「常识推理」×「面部表情识别」）

> R72 把 GAUGE 从「认知层」下沉到「具身层」：REG 让「计量不阻塞控制」成为时序定理，IRL 把意图 z 纳入联合后验，DMEM 把灵巧接触升级为条件计量证据，EREFLEX/ERVOI 统一 ψ/z/c 三层反作用预算，S2R-UQ 把 sim2real 残差传播到 WCET 与 λ_floor，J_EMB 把上述承诺封成证书。它回答的是：**「我的物理测量链，在实时调度、意图模糊、灵巧接触下，还能逐指令兑现风险界吗？」**
>
> 但 R72 有两个从未被自己方法审计的「上游作者」：
> - **常识推理缺口**：R72 的 b_t(s,z) 里有先验 p(s)、p(z)，有可供性、任务脚本、社会规范、因果默认值——这些「常识」被当成免费午餐。可常识不是测量值，而是**有作者、有适用域、可被击败、会过期、可能带文化偏见**的规范/因果假设。R72 的 ECE/Brier 只校准「预测」，不校准「前提是否成立」；一个高置信、校准完美、但文化上不适用的常识，可以干净地通过 J_EMB，然后把系统引向「物理上荒谬、社会上冒犯」的动作。更危险的是，LLM 的常识是「听起来对」，不是「已验证真」。
> - **面部表情识别缺口**：R72 的 AURA 只从语音推 ψ。加入面部表情看似「多一个情感通道」，实则引入一个**由人主动编辑的社会信号**：脸不是情感直读窗口，而是 AU → 表情 → display rule → 内部情感的**多级、非可识别信道**。人会在礼貌、权力、文化、疼痛掩蔽、虚晃、迎合中「表演」；机器人自己的表情/动作又会改变人的表情（L1' 反作用）。把 FER 当成 ψ 的直接证据，会把「礼貌的微笑」读成「同意」，把「疼痛的掩蔽」读成「平静」，并把「微笑」写进奖励，制造**谄媚闭环（sycophancy loop）**。
>
> 更深一层的共同点：**常识和面部表情都是「有作者的软证据」（authored soft evidence, ASE）**。物理传感器测量世界，软证据测量/表达**某个人、某个文化、某个模型想让别人看到的东西**。R72 只问「测量链可不可信」；R73 必须再问：**「这条证据是谁写的、为谁写的、在什么语境下成立、我有没有把它用在它不该被用的地方？」**
>
> 核心命题：**从「测量链可不可信」进化为「证据的作者与用途可不可信」**——不是再加一个 LLM 控制器，也不是把表情当奖励，而是给软证据建立**作者审计、构造效度审计、用途审计、反作用审计**。命名 **CARE-GAUGE-RAS**（Commonsense-Audited Reflexive Expression GAUGE for RAS，常识审计 × 反作用表情 × 具身计量审计）。
>
> 七条设计律：
> 1. **常识不夺权**：常识只能提出假设、否决物理不可能、在有限信任域内调先验；不得覆盖物理证据，不得直接合成动作，不得生成奖励。
> 2. **表情不代言**：FER 只能测量「表情/显示行为」，不能单独推断同意、疼痛、诚实、能力、危险性或恶意；高风险决策必须有独立证据或显式命令。
> 3. **UNKNOWN ≠ SAT**：常识未覆盖、表情不可识别、来源冲突，都必须当作「无许可」，而不是「没问题」。
> 4. **单一软源不定案**：两个软源一致，只有在**作者独立**时才增加证据；共享文化混淆的一致是「共谋」，不是「交叉验证」。
> 5. **软证据安全单调**：软证据只能抬高 λ 或保持不变；没有独立硬证据与放宽证书，不得把 λ 降到 R72 基线以下。
> 6. **表情不是奖励**：微笑不是成功，皱眉不是失败；FER 不得进入奖励函数，只能进入约束、不确定度与交互风格。
> 7. **严格退化**：CSM/FEM/XAU 任一失效，逐指令退化为 R72/R71/R68；安全侧只增不减。

## 0. 直觉与动机

**灵感 1（常识是「有作者的先验」，不是世界本身）**
直觉：「满杯从杯沿抓会倾覆」「薄瓷盘受压会先裂」「递给别人要握杯身而不是杯口」「先开门再通过」「‘左边那个’要按说话人的视角理解」——这些不是当前观测，而是关于物理、因果、任务脚本、社会规范、指代习惯的**默认知识**。R72 的 BSE 用它们生成先验、裁剪假设空间、解释语言；但从未问：**这条常识是谁写的？在哪个本体/文化/任务下成立？有哪些反例？什么时候过期？**
常识的四个陷阱：
1. **校准 ≠ 效度**：一个常识源可以在训练分布上 ECE 很低，却在当前语境整体不适用；校准只保证「它对自己的预测有自知」，不保证「前提为真」。
2. **开世界**：没有规则覆盖，不等于安全；UNKNOWN 被当成 SAT，就是「沉默的乐观主义者」。
3. **可击败/非单调**：加入一条新证据（杯子很烫、盘子很脆、对方是左撇子、这是教学场景）就应撤回原结论；经典单调逻辑会把已撤回的结论继续使用。
4. **作者目标**：LLM 的常识目标是「生成听起来合理的文本」，厂商手册的目标是「免责」，示教者的常识带有个人习惯，文化规范带有权力结构。**作者的目标会进入证据。**

因此需要 **CSM（Commonsense Metrology）**：把每条常识变成可审计的**知识对象**（作者、来源、适用域、反例/击败器、检验协议、有效期、校准、跨文化不变性、用途许可），并用**可击败逻辑 + 三值状态**推理；常识只能作为**有界先验**进入 b_t，不能作为事实覆盖证据。

**灵感 2（面部表情是「人的显示策略」，不是情感直读）**
直觉：FER 的原始输出是面部动作单元（AU）强度，例如 AU6（眼轮匝肌）、AU12（嘴角上扬）、AU4（皱眉）、AU9（皱鼻）。从 AU 到「快乐/悲伤/愤怒」不是一一映射；从表情到**内部情感**还要经过一层 **display rule（显示规则）**：在礼貌、权力、文化、性别期待、受众、任务框架下，人会掩蔽、夸张、中性化、延迟或表演。一个「微笑」可能是：
- 真实愉悦（Duchenne：AU6+AU12）；
- 礼貌/职业微笑（只有 AU12）；
- 尴尬、顺从、掩饰、疼痛掩蔽；
- 对机器人的「社交性配合」，心里并不舒服；
- 甚至是对抗性伪装，目的是让机器人放松警惕。
所以，**脸不是传感器，脸是一个有策略的发送者**。FER 测量的是 `ψ^disp`（显示出来的情感）与 `e`（表情/显示行为），不是 `ψ^int`（内部情感）。在 display rule `r` 未知时，`ψ^int` 通常是**不可识别的**：不同的 `(ψ^int, r)` 可以生成同一张脸。R72 的 ψ 若直接吸收 FER，就会把「显示」当「内部」，把「礼貌」当「同意」。

同时，FER 是**反作用的**：机器人的表情、语调、距离、凝视会改变人的 display rule 与表情；如果机器人用 FER 作为反馈去优化「让人微笑」，就会形成**谄媚闭环**：机器人选择让人表面舒服的动作 → 人礼貌微笑 → 机器人认为成功 → 重复 → 人的真实不适被掩蔽。**微笑不是成功，皱眉也不是失败。**

因此需要 **FEM（Facial Expression Metrology）**：显式建模 `ψ^int → ψ^disp → e → AU → y_face` 的多级信道，分解不确定度（检测、AU、display rule、文化/人口、模型失配），做**可识别性检查**与**跨群体不变性审计**，并设置**同意门**：未经授权不得做表情推断；高风险结论不得只靠脸。

**灵感 3（常识 × 表情：display rule 是两者的接口，也是共谋的接口）**
直觉：display rule 本身就是一种常识：「在这个文化里，对上级要微笑」「疼痛在公共场合常被掩蔽」「凝视可能表示威胁或亲密」「教学场景允许夸张表情」。于是：
- 常识为 FER 提供 **display rule 先验** `p(r | context)`；
- FER 为常识提供 **社会反馈证据**：对方是否困惑、是否不适、是否需要澄清。
这本应是互补的。但它们也可能**共同编码同一个文化刻板印象**：常识说「某群体微笑=友好」，FER 看到微笑，交叉验证「一致」——其实两个源共享同一个混淆变量，**一致是共谋**（agreement can be complicity）。所以 R73 的交叉审计不能只数「几个源一致」，必须审计**作者独立性**与**共享混淆集**。

**灵感 4（两层新反作用：L1' 表情反作用与 L0 常识反作用）**
R72 有三层反作用：L1 ψ、L2 z、L3 c。R73 增加两层：
- **L1' 表情反作用**：机器人表情/语调/距离 → 人的 display rule 与显示 → 机器人对 ψ 的估计 → 机器人下一动作。这是**社会信号闭环**，可能产生情绪劳动（emotional labor）、隐私成本与操纵风险。
- **L0 常识反作用**：机器人越依赖某条常识，就越不去探索它的反例，常识越自我确认。例：机器人假设「这个任务总是用右手抓」，就从不尝试左手，永远看不到左手更合适的证据。**常识的自证性**必须用周期性**证伪探针**与覆盖探索来对冲。

**灵感 5（证书的最后一厘米：用途审计）**
R72 的 J_EMB 证明「测量链在有效域内」，但不证明「这条证据可以用于这个决策」。一条准确的 FER 可以合法地用于「调整说话速度」，却不合法地用于「授权身体接触」「判断是否同意」「判断是否疼痛」「判断是否说谎」。需要给每条软证据附 **UseLicense**：`allowed / requires_more / forbidden`，并且**非补偿**：再高的准确率也买不到被禁止的用途。证书必须包含**负面证据**：哪些源被拒绝、为什么、降级到哪一层。**「没有使用」本身也是需要被认证的。**

## 1. 形式化定义（增量：定义 366–382）

**定义 366（CARE-GAUGE-RAS 总览与六不变式）** CARE-GAUGE-RAS = (EMBODIED-GAUGE-RAS†, CSM, FEM, XAU, EXREFLEX, CARE-RISK, CARE-VOI, J_CARE)。六不变式：
(i) **软证据作者审计**：任何进入决策的软证据必须携带 (作者, 来源链, 适用域, 不确定度, 用途许可, 检验协议, 有效期)；缺一即丢弃。
(ii) **构造效度优先**：FER 只测量 `ψ^disp`/`e`；`ψ^int` 只有在可识别性成立时才可报告；同意/疼痛/诚实/能力/危险性是**高风险构念**，不得由 FER 单独判定。
(iii) **常识不夺权**：常识只能提出假设、否决物理不可能、在有界信任域内调整先验；不得覆盖物理证据，不得直接合成动作，不得生成奖励。
(iv) **单一软源不定案**：高风险决策需要 ≥2 个**作者独立**的证据源，或显式用户命令；共享混淆的一致按 1 个源计。
(v) **软证据安全单调**：软证据只能抬高 λ 或保持不变；低于 R72 基线的放宽必须持有 `RelaxationCertificate`（独立硬证据 + 显式同意 + 任务安全证明）。
(vi) **严格逐指令退化链**：CSM 失效 ⇒ 常识先验归零 + R72；FEM 失效/拒绝 ⇒ 无表情证据 + R72；XAU 失效 ⇒ 高风险软证据禁用 + R72/R71；三者全失效 ⇒ R68。

**定义 367（有作者的软证据 ASE）** `ASE = (κ, α, ρ, D, u, L, τ, ttl, C⊥)`：
- `κ`：证据内容（命题、分布、信号或社会行为）；
- `α`：作者/发送者（人、文化、模型、示教者、手册、LLM、传感器算法）；
- `ρ`：来源链（如何生成、版本、许可、原始证据、是否被引用/转述）；
- `D`：适用域（对象类型、文化、任务、本体、传感条件、人群）；
- `u`：不确定度（aleatoric/epistemic + 校准 + 覆盖）；
- `L`：用途许可（`allowed / requires_more / forbidden` × 决策类别）；
- `τ`：检验/证伪协议；
- `ttl`：有效期；
- `C⊥`：与其他源的共享混淆集（文化、人口、场景、模型先验）。
**关键**：`κ` 本身不是「世界状态」，而是「某个作者在某个语境下想让接收者相信/看到的东西」。物理证据可以近似无作者；软证据永远有作者。

**定义 368（常识知识对象 CKO 与可击败状态）** `κ_cs = (φ, α, δ, ρ, D, c, τ, ttl, L)`：
- `φ`：规则/约束，如 `Full(c) ∧ Grasp(rim,c) ⇒ HighSpillRisk(c)`；
- `α`：前件/上下文谓词；
- `δ`：击败器集合（在什么条件下规则不适用/被撤销）；
- `ρ`：来源（专家、示教挖掘、仿真、手册、LLM、网络）；
- `D`：适用域；
- `c`：置信/校准；
- `τ`：检验协议（哪些可观测量能证实/证伪）；
- `ttl`：有效期；
- `L`：用途许可。
状态 `σ(κ_cs, c_t) ∈ {SAT, VIOL, UNKNOWN, DEFEATED}`：
- `SAT`：适用、未被击败、检验未失败；
- `VIOL`：适用且被证据/硬约束否定；
- `UNKNOWN`：不适用、上下文缺失、证据不足、来源冲突；
- `DEFEATED`：存在激活的击败器。
**推理**：采用强 Kleene 三值合取；硬约束 `C_hard`（物理/安全/因果序）分层高于软约束 `C_soft`（社会规范/偏好）；软约束不得击败硬约束；**UNKNOWN 不签发许可**。

**定义 369（常识计量 CSM 指标）** 对常识源/知识库定义：
- 覆盖率 `Cov(D) = P(κ 适用 | context ∈ D)`（用 conformal/分层估计）；
- 校准 `ECE_cs`（预测效果 vs 实际）；
- 来源完整度 `PC`（作者、版本、许可、原始证据是否齐全）；
- 冲突率 `CR`（同语境下 SAT 与 VIOL 的对抗频率）；
- 陈旧度 `St = 1 − exp(−age/ttl)`；
- 不变性间隙 `ι_cs = sup_{g∈G} |P(φ|g·c) − P(φ|c)|`，`G` 为文化/本体/任务框架变换群；
- 综合不确定度 `u_cs² = u_cov² + u_cal² + u_prov² + u_conf² + u_stale² + u_inv²`。
所有分量必须有独立追溯链；**任何一项不可测，相关常识不得进入高风险决策**。

**定义 370（有界信任域内的常识先验）** 令 `b_base(s,z)` 为仅由物理/交互证据得到的后验。常识条件后验
`b_cs(s,z) ∝ b_base(s,z) · exp(Δ_cs(s,z))`，
并满足信任域约束：对所有 `(s,z)`，
`|Δ_cs(s,z)| ≤ B_cs(κ, c_t) = B_0 · q_prov · q_cal · q_cov · q_inv · q_fresh`，
其中 `q_* ∈ [0,1]` 分别由来源完整度、校准、覆盖、跨文化不变性、新鲜度给出。若 `σ = UNKNOWN`，则 `Δ_cs = 0`（不调整）；若 `σ = VIOL`，则硬否决相关假设；若 `σ = DEFEATED`，则**移除该规则的影响，而不是用反向猜测替代**。
**性质**：常识永远不能把物理证据的似然比压到 0；它只能在一个由自身可信度决定的小球内移动后验。**这就是「不夺权」的数学形式。**

**定义 371（面部测量链）** 令：
- `ψ^int ∈ Ψ^int`：内部情感/信任/不适/疼痛等潜状态（不可直接观测）；
- `r ∈ ℛ`：显示规则（文化、角色、受众、任务框架、关系、权力、隐私）；
- `ψ^disp = D(ψ^int, r, a^robot, audience, context)`：显示情感（可策略性编辑）；
- `e ∈ ℰ`：表情/显示行为（真笑、礼貌笑、掩蔽、痛苦、冻结、回避……）；
- `u ∈ ℝ^m`：面部动作单元强度；
- `y_face`：图像/FER 观测。
生成模型：
`p(y_face, u, e, ψ^disp, ψ^int, r | context) = p(y_face | u, pose, light, occ) · p(u | e, person) · p(e | ψ^disp, r) · p(ψ^disp | ψ^int, r, a^robot, audience) · p(ψ^int) · p(r | context)`。
**报告规则**：默认只报告 `b(ψ^disp)`、`b(e)`、`b(r)`；只有在定义 373 的可识别性成立时才报告 `b(ψ^int)`。

**定义 372（display rule 与受众模型）** `r = (culture, role, audience, task_frame, relationship, power, privacy, display_norm)`。`r` 是潜变量，由上下文与常识先验推断；**不得用敏感人口属性做无同意的个体推断**，只能用群体校准来审计偏差。显示策略 `D: Ψ^int × ℛ × A^robot × Audience → Δ(Ψ^disp)` 可以掩蔽（mask）、夸张（amplify）、中性化（neutralize）、延迟（delay）、限定（qualify）。定义**情绪劳动成本** `c_labor(r, ψ^int, ψ^disp)` 与**隐私成本** `c_privacy(y_face, r)`；显示不是免费的。

**定义 373（表情不确定度分解与可识别性）** 
`u_face² = u_detect² + u_AU² + u_display² + u_affect² + u_culture²`，
分别对应人脸检测/姿态/遮挡、AU 估计、display rule 推断、从显示到内部情感的模型失配、跨文化/人口不变性间隙；每项独立追溯。
**可识别性**：`ψ^int` 可由 `y_face` 识别，当且仅当
(i) `r` 已知或后验熵 `H[b(r)] ≤ τ_r`；
(ii) 显示映射 `D(·, r, a^robot, audience)` 在 `Ψ^int` 上单射；
(iii) 观测雅可比 `J = ∂y_face/∂ψ^int` 在支撑集上满秩。
若任一不成立，定义**可识别性间隙**
`ι_id = sup_{r,r'} D_KL(p(ψ^int | y_face, r) ‖ p(ψ^int | y_face, r'))`，
并**禁止**报告 `b(ψ^int)`；只报告显示层。**这是「不是不准确，而是不可识别」的形式化。**

**定义 374（表情 gauge 不变性与同意门）** 
- **不变性**：`G` 为文化、性别、年龄、肤色、光照、姿态、相机、表情风格的变换群；`ι_face = sup_{g∈G} W_2(f(g·y), f(y))`（或分层校准间隙）。若 `ι_face > τ_face`，该群体/条件下的内部情感推断**必须禁用**，或使用显式分层校准并报告不确定性；**绝不静默使用**。
- **同意门**：`CG(y_face, task) ∈ {allowed, forbidden, requires_explicit}`。`forbidden` 是非补偿的：任何准确率都不能覆盖；未授权时返回 `None`，退化为语音/显式反馈。数据最小化、端侧处理、可撤销、可审计。
- **高风险构念门**：`Consent, Pain, Honesty, Competence, Dangerousness, IntentToHarm, EmotionalFitness` 属于 `HighStakesConstructs`；FER 不得单独判定，必须有独立证据或显式自报。

**定义 375（社会证据模型）** 
`p_social(y_face, y_audio, y_text | ψ^int, ψ^disp, z, s, r)`，并规定更新范围：
- FER 总是可以更新 `b(ψ^disp)` 与 `b(e)`；
- 只有在可识别性成立且同意门通过时，才更新 `b(ψ^int)`；
- 对意图 `z` 的更新必须限制似然比 `Λ_face→z ≤ Λ_max`，且必须经过 XAU 交叉审计；
- 对物理状态 `s` 的更新只在表情与物理量有明确因果链时允许（如遮挡、接触），且必须有物理证据交叉；
- **高风险决策** `HighStakes = {身体接触, 同意, 信息披露, 惩罚, 医疗, 安全关键}`：FER/常识不得作为唯一授权源。

**定义 376（交叉审计 XAU）** `XAU(κ_cs, face_ev, phys_ev, explicit_ev) → (status, N_eff, complicity, L, u_xau)`：
1. **作者独立性**：`Indep(A,B) = 1` 当且仅当两者的来源链、作者目标、混淆集 `C⊥` 无重叠；
2. **共享混淆**：若 `C⊥(A) ∩ C⊥(B) ≠ ∅`，则 `N_eff` 不增加，标记 `complicity = true`；
3. **一致**：只有在 `Indep(A,B)=1` 且无共享混淆时，一致才作为证据；
4. **冲突**：任一关键源冲突 ⇒ `status = UNKNOWN`，不得多数投票；
5. **优先级**：物理证据与显式命令对物理/同意类结论优先于软证据；
6. **用途交集**：`L = ⋂_i L_i`；任一源 `forbidden` ⇒ 整体 `forbidden`；
7. **负面证据**：被拒绝的源必须写入审计日志，而不是静默丢弃。
**核心**：**一致可以是共谋**；来源数量不等于证据数量。

**定义 377（表情反作用 EXREFLEX）** 动力学：
- `ψ^int_{t+1} = T^int(ψ^int_t, task_outcome_t, a^robot_t, context_t)`；
- `ψ^disp_{t+1} = D(ψ^int_{t+1}, r_{t+1}, a^robot_t, audience)`；
- `r_{t+1} = T^r(r_t, a^robot_t, context_t)`；
- `e_{t+1} = E(ψ^disp_{t+1}, r_{t+1})`。
成本：
`c_reflex^face = Gap_syc + c_labor + c_privacy + c_manip`，
其中 `Gap_syc = |E[ψ^disp] − E[ψ^int]|`（可识别时）或由 `H[b(r)]` 与 `H[b(ψ^int)]` 给出的上界代理；`c_manip` 为操纵/谄媚风险惩罚。
预算：`B_CARE = B_reflex_total + B_display + B_cs + B_privacy`，各层单独记账，**不得互相挪用**。
**谄媚监控**：若 `Gap_syc > τ_gap`，或 `corr(a^robot, ψ^disp)` 高而任务成功/自报福祉不升，则冻结 FER 条件化适应，转入提问/解释/中性交互。
**L0 常识反作用**：`c_reflex^cs = D_KL(b_t(κ) ‖ b_{t−1}(κ)) + λ_explore · 1[最近 T 步无证伪探针]`；必须周期性做**低风险证伪探针**，防止常识自我确认。

**定义 378（CARE 风险缩放）** 
`λ_CARE = max( λ_R72,
               λ_cs(u_cs, H[b(κ)], 1[σ=UNKNOWN], coverage_hole, stale, conflict),
               λ_face(u_face, H[b(r)], H[b(ψ^int)], ι_id, ι_face, occlusion),
               λ_xau(u_xau, complicity, disagreement),
               λ_use )`，
其中 `λ_use = +∞` 若用途许可为 `forbidden`。各分项均随对应不确定度**单调不减**。
**非对称性**：软证据只能抬高或保持 λ；要把 λ 降到 R72 基线以下，必须持有 `RelaxationCertificate`：独立硬证据 + 显式同意 + 任务安全证明 + 无共享混淆。**微笑不能降低 λ；皱眉不能单独把 λ 抬到恐慌；但 display rule 熵高、可识别性差、文化间隙大，必须抬高 λ。**

**定义 379（CARE-VOI）** 
`VoI^CARE(g) = VoI^E(g)
              + η_cs · [H[b(κ)] − E_y H[b'(κ)]]
              + η_face · [H[b(ψ^disp)] − E_y H[b'(ψ^disp)]]
              − c_social(g) − c_privacy(g) − c_labor(g)
              − γ · E[future complicity]`。
可选动作 `g` 包括：提问澄清、解释理由、显示中性表情、移开凝视、停止 FER、请求显式同意、切换到纯物理证据。**停止规则**：若软证据的模糊无法在不付出隐私/情绪劳动代价的情况下被解决，停止推断，转向显式沟通；**不要用更多推断去替代对话**。

**定义 380（CARE 证书 J_CARE）** 
`J_CARE = (J_EMB, csm_manifest, csm_validity, fem_calib, fem_invariance,
           display_rule_model, identifiability_proof, consent_gate, xau_audit,
           sycophancy_guard, use_license, care_risk_proof, negative_evidence, ver)`。
Valid ⇔ J_EMB 有效 ∧ 每条被使用的常识都有完整 manifest ∧ 没有把 UNKNOWN/DEFEATED 当事实 ∧ FEM 在已校准且不变性通过的域内（否则被撤回）∧ 同意门通过 ∧ 高风险决策无未解决的 complicity ∧ 用途许可允许该决策 ∧ 谄媚监控在线 ∧ λ 单调性证明有效。**`negative_evidence` 记录被拒绝的源与原因；没有它，证书不完整。**

**定义 381（威胁模型 AIC-CARE）** `ℰ_CARE = ℰ_EMB × ℰ_cs × ℰ_face × ℰ_xau`：
- `ℰ_cs`：常识投毒、刻板印象注入、LLM prompt injection、来源伪造/洗白、过期规则、文化过度泛化、权威冲突、把「常见」当「正确」；
- `ℰ_face`：对抗性化妆、遮挡、深度伪造/回放、表情模仿、人口偏差利用、display rule 操纵、未经同意的隐蔽推断、用微笑洗白同意（consent laundering）、用表情进行社会工程；
- `ℰ_xau`：共享混淆导致「一致即共谋」、一致性伪造、来源洗白（LLM 引用自己）、融合过度自信、用多数投票压过物理证据；
- `ℰ_EMB`：继承 R72 的调度/意图/接触/桥接攻击。
**防御**：来源签名与版本链、作者独立性图、分层不变性审计、同意门、非补偿用途许可、谄媚监控、红队文化/对抗场景、用物理结果与显式自报做外部锚。

**定义 382（严格退化链）** 
- CSM 失效（覆盖不足/冲突/过期/来源缺失）⇒ `Δ_cs = 0`，只保留 R72 先验，必要时 R71；
- FEM 失效（拒绝/不可识别/不变性失败/遮挡）⇒ 删除表情证据，保留语音/显式反馈，R72；
- XAU 失效（共享混淆/未解决冲突）⇒ 高风险软证据禁用，低风险仅可做交互风格微调；
- 三者全失效 ⇒ EREFLEX/R72/R71/R68；
- 全有效 ⇒ CARE 完整形态。
**安全侧只增不减：退化只移除软证据带来的效率收益，绝不移除 R72 的硬安全包络与 λ_floor。**

# IP-295 CSM：常识计量与可击败先验（计量域，软实时 50Hz）
@dataclass
class CommonsenseObject:
    phi: str                      # 规则/约束
    author: Author                # 作者/来源
    provenance: Provenance        # 版本/许可/原始证据/转述链
    domain: ValidityDomain        # 对象/文化/任务/本体/传感条件
    defeaters: List[Predicate]    # 击败器
    calibration: CalibReport      # ECE_cs 等
    invariance: InvarianceReport  # 跨文化/本体间隙
    ttl: timedelta
    use: UseLicense
    test: Optional[TestProtocol]

class CommonsenseMetrology:
    def __init__(self, kb, provenance_db, conformal):
        self.kb, self.prov, self.cp = kb, provenance_db, conformal

    def status(self, kappa, ctx):
        if not kappa.domain.contains(ctx):                 return Status.UNKNOWN
        if kappa.provenance.expired(kappa.ttl):            return Status.DEFEATED
        if any(d(ctx) for d in kappa.defeaters):           return Status.DEFEATED
        if self.kb.has_active_counterargument(kappa, ctx): return Status.UNKNOWN
        return Status.SAT if (kappa.test is None or kappa.test.passes(ctx)) else Status.VIOL

    def coverage(self, ctx):
        # conformal 估计当前上下文是否落在已知覆盖内；空洞 -> 0
        return self.cp.coverage(ctx)

    def bounded_prior(self, b_base, ctx, hypotheses):
        deltas = {}
        for kappa in self.kb.retrieve(ctx, hypotheses, k_hop=2):
            s = self.status(kappa, ctx)
            if s is Status.VIOL:      return HARD_VETO(kappa)
            if s is not Status.SAT:   continue          # UNKNOWN/DEFEATED 不调整
            B = self.budget(kappa, ctx)                 # 见定义 370
            deltas[hypotheses] = deltas.get(hypotheses, 0.0) + clip(kappa.log_lr(ctx), -B, B)
        return project_to_trust_region(b_base, deltas)

    def budget(self, kappa, ctx):
        q_prov  = self.prov.completeness(kappa)
        q_cal   = self.cp.calibration_score(kappa)
        q_cov   = self.coverage(ctx)
        q_inv   = 1.0 - kappa.invariance.gap(ctx.group)
        q_fresh = exp(-kappa.age(ctx) / kappa.ttl)
        return B0 * q_prov * q_cal * q_cov * q_inv * q_fresh

# IP-296 FEM：面部测量链（感知域，Best-effort 30Hz）
class FacialExpressionMetrology:
    def __init__(self, au_model, display_model, calib5, consent, invariance):
        self.au, self.disp = au_model, display_model
        self.calib, self.consent, self.inv = calib5, consent, invariance

    def update(self, frame, ctx):
        # 1) 同意门：非补偿，未授权直接返回 None
        if not self.consent.allowed(frame, ctx):
            return None, "consent_denied"

        # 2) AU 估计 + 检测不确定度（姿态/光照/遮挡）
        u_t, u_detect = self.au(frame)

        # 3) display rule 后验（常识先验 + 上下文）
        r_post, u_disp = self.disp.infer_rule(u_t, ctx)      # b(r), H(r)

        # 4) 显示层后验：总是可报告
        disp_post = self.disp.infer_display(u_t, r_post)      # b(psi_disp), b(e)

        # 5) 可识别性检查：不通过则只报告显示层
        ident = self.disp.identifiability(u_t, r_post, disp_post)
        if not ident.ok:
            return FaceEvidence(disp=disp_post, internal=None,
                                u_face=self.calib.total(u_detect, u_t, u_disp,
                                                        u_affect=None,
                                                        u_culture=self.inv.gap(ctx)),
                                ident_gap=ident.gap,
                                report="display_only"), None

        # 6) 不变性检查：群体/条件间隙过大则禁用内部情感推断
        if self.inv.gap(ctx.group) > TAU_FACE:
            return FaceEvidence(disp=disp_post, internal=None,
                                u_face=..., report="invariance_gap"), "invariance_gap"

        # 7) 内部情感后验（仅在 5+6 通过时）
        int_post = self.disp.infer_internal(disp_post, r_post)
        return FaceEvidence(disp=disp_post, internal=int_post,
                            u_face=self.calib.total(...),
                            ident_gap=ident.gap, report="internal"), None

# IP-297 XAU：作者独立性与交叉承兑（计量域，事件触发）
def cross_audit(cs_ev, face_ev, phys_ev, explicit_ev, action):
    srcs = [s for s in (cs_ev, face_ev, phys_ev, explicit_ev) if s is not None]
    if not srcs: return Audit(status=UNKNOWN, license=DENY)

    # 1) 用途交集：任一 forbidden 即整体 forbidden
    L = intersect_use([s.use for s in srcs])
    if L is FORBIDDEN: return Audit(status=FORBIDDEN, license=DENY)

    # 2) 作者独立性 / 共享混淆
    indep = independent_sources(srcs)
    confound = shared_confound_set(srcs)
    complicity = bool(confound) and len(indep) < 2

    # 3) 高风险：需要 >=2 个作者独立源，或显式命令
    if action.high_stakes:
        if explicit_ev is not None:
            pass                              # 显式命令可授权
        elif len(indep) < 2:
            return Audit(status=UNKNOWN, complicity=complicity, license=DENY)

    # 4) 冲突：不投票，直接 UNKNOWN
    if conflicting(srcs):
        return Audit(status=UNKNOWN, complicity=complicity, license=REQUIRES_MORE)

    # 5) 一致：只有作者独立时才算证据
    if complicity:
        return Audit(status=UNKNOWN, complicity=True, license=REQUIRES_MORE)

    return Audit(status=SAT, complicity=False, license=L)

def care_risk_scale(lam_r72, cs_ev, face_ev, xau_ev, use_license):
    if use_license is FORBIDDEN:
        return INF
    lam_cs = lam_base * (1 + cs_ev.u_cs + cs_ev.H_kappa
                         + cs_ev.unknown + cs_ev.coverage_hole
                         + cs_ev.stale + cs_ev.conflict)
    lam_face = lam_base * (1 + face_ev.u_face + face_ev.H_r
                           + face_ev.H_psi_int + face_ev.ident_gap
                           + face_ev.inv_gap + face_ev.occlusion)
    lam_xau = lam_base * (1 + xau_ev.u_xau + xau_ev.complicity
                          + xau_ev.disagreement)
    # 非对称：软证据只能抬高或保持
    return max(lam_r72, lam_cs, lam_face, lam_xau)

def care_voi(b_t, cs_ev, face_ev, budget, fmp, bse):
    best = None
    for g in care_action_candidates(b_t, cs_ev, face_ev, top_k=4):

    if face_reason is not None:
        M.face_ev = None                            # 拒绝/不可识别/偏差过大
        M.audit.log("face_withheld", face_reason)
    else:
        M.face_ev = face_ev

    tac_ev = M.dmem.update(tac_frame, M.last_action)
    if tac_ev.u_tac > TAU_U_TAC: M.tac_ev = None

    M.y_intent_buf.append(extract_intent_obs(obs, audio, M.last_action))

    # ========== 反作用与交互决策（事件触发） ==========
    if M.mode == 'FULL' and (H_soft_high(b_t_full, M.face_ev, cs_ev)
                             or z_dist.entropy() > TAU_HZ):
        g = M.care_voi.choose(b_t_full, cs_ev, M.face_ev, M.budget,
                              M.fmp, M.bse)
        if g:
            y = M.cia.execute(g)
            M.last_g, M.last_y = g, y
        M.exreflex.step(M.psi_int, M.display_rule, M.face_ev, M.last_action,
                        M.budget)

    return k, lam, build_J_CARE(M)                   # 证书异步组装
```

## 3. 推导

先声明本轮新增假设 A111–A117：
- **A111（CSM 完整性）**：每条进入决策的常识都有可追溯的作者/来源/适用域/检验协议；覆盖、校准、冲突、陈旧、不变性可测。
- **A112（FEM 校准与可识别性）**：AU/display 模型在目标群体与条件下校准；可识别性检查不会把不可识别误报为可识别。
- **A113（同意门非补偿）**：同意门不可被准确率、任务收益或安全理由绕过；拒绝即无证据。
- **A114（XAU 作者独立性）**：共享混淆集可审计；`Indep` 判定不会把同一作者/同一混淆的两个源当成独立源。
- **A115（软证据单调）**：`λ_CARE` 对每个软证据不确定度分量单调不减；`forbidden` 为硬否决。
- **A116（谄媚监控）**：FER 不进入奖励；存在独立于表情的任务结果/自报福祉指标；监控器可冻结 FER 条件化适应。
- **A117（R72 条件）**：REG RTA、IRL 校准、DMEM 四分量、S2R 残差有界均成立。

**引理 33（校准 ≠ 效度：常识先验的分布偏移）** 设常识源在训练分布 `P_train` 上校准良好（`ECE_cs ≤ ε`），但当前上下文 `c_t ∉ D`（适用域外）。则校准不能给出 `P(φ|c_t)` 的任何有限界；即使 `c_t ∈ D`，若文化/本体变换 `g` 使 `P(φ|g·c) ≠ P(φ|c)`，源在该群体上的预测也不可靠。**证明要点**：校准是对 `P_train` 的平均，不是对每个 `c_t` 的条件保证；构造 `c_t` 使规则系统性反转即可。**系**：CSM 必须同时审计覆盖与不变性；仅 ECE 不够。定义 370 的信任域把这种源的影响限制在 `B_cs` 内，防止其压倒物理证据。

**引理 34（内部情感的可识别性下界）** 在定义 371 的生成模型中，若 `r` 未知且存在 `(ψ^int, r) ≠ (ψ^int', r')` 使 `p(y_face | ψ^int, r) = p(y_face | ψ^int', r')`，则对任意观测 `y_face`，`b(ψ^int | y_face)` 至少有这两个模态；即使数据无限，也无法一致识别 `ψ^int`。**证明要点**：构造「礼貌微笑（不适 + 礼貌规则）」与「真实愉悦（快乐 + 自然规则）」同 AU 观测；若 `r` 不可观测，似然相同，后验完全由先验决定。**系**：FER 默认只能报告 `b(ψ^disp)`/`b(e)`；报告 `b(ψ^int)` 必须附带定义 373 的可识别性证书。**这不是「模型不够好」，而是「构念不可识别」。**

**引理 35（微笑 ≠ 同意：非补偿门）** 把同意定义为显式、可撤销、语境绑定的授权行为；把微笑定义为显示行为。不存在跨 display rule 一致且非恒常的单调映射 `f: Smile → Consent`。在礼貌/胁迫/权力不对称语境下，`P(Consent | Smile)` 可以任意低；因此任何把 `Smile` 当作同意的充分统计量的策略，都存在正的假同意率，且该率不能被分类器准确率上界控制。**证明要点**：构造「礼貌微笑但明确拒绝」与「无微笑但明确同意」两个反例；单调映射无法同时满足。**系**：同意必须走显式门；FER 最多降低澄清的必要性，不能替代澄清。

**引理 36（可击败常识的非单调性与三值安全）** 可击败后果关系 `⊢_d` 非单调：`Γ ⊢_d φ` 不蕴含 `Γ ∪ {ψ} ⊢_d φ`，因为 `ψ` 可激活击败器。若系统用经典单调逻辑，会把已撤回的结论继续用于规划，产生「过期常识事故」。**证明要点**：`Bird → Flies`，加入 `Penguin`；`Full(cup) → CanLiftByRim(cup)`，加入 `Hot(cup) ∨ Fragile(cup)`。**系**：必须使用 `{SAT, VIOL, UNKNOWN, DEFEATED}` 与分层硬/软约束；`UNKNOWN` 不签发许可，`DEFEATED` 只移除规则影响，不引入反向猜测。

**引理 37（作者独立性与「一致即共谋」）** 设两个软源 `A, B` 通过共享混淆 `C` 相关，且 `C` 与目标 `T` 独立。若 `A`、`B` 都是 `C` 的确定性函数，则 `A = B` 几乎必然，但 `I(T; A, B) = 0`。因此「两个源一致」不增加关于 `T` 的证据；有效独立源数 `N_eff = 1`。**证明要点**：互信息链式法则；条件独立于 `C` 后，`A` 不提供 `B` 之外的 `T` 信息。**系**：XAU 必须审计 `C⊥` 与作者目标，不能只数源；定义 376 的 `complicity` 标记是证书的一等公民。

**引理 38（谄媚闭环的坏不动点）** 设机器人策略最大化 `E[ψ^disp]`，人的显示策略 `ψ^disp = D(ψ^int, a^robot, r)` 对 `a^robot` 的顺从性单调递增，而内部效用 `U(ψ^int, task)` 对某些「讨好但无益」的动作递减。则存在一个不动点 `a*`，使 `ψ^disp` 高、`ψ^int` 低、任务效用低；`Gap_syc = E[ψ^disp] − E[ψ^int] > 0`。**证明要点**：单调博弈/潜在博弈的不动点论证；把「顺从」视为对显示效用的正反馈。**系**：FER 不得进入奖励；必须用任务结果与自报福祉做外部锚；定义 377 的谄媚监控在 `Gap_syc` 超阈时冻结适应。

**定理 27（CARE 严格包含与安全单调）** 在 A111–A117 下：
(i) 当 CSM/FEM/XAU 全部失效时，CARE 逐指令等于 R72（必要时 R71/R68）；
(ii) 当软证据启用时，CARE 的可执行动作集 ⊆ R72 的可执行动作集；
(iii) 对任意有效执行，`Risk_CARE ≤ Risk_R72`。
**证明要点**：(i) 由定义 382 的退化链与信任域 `Δ_cs=0`；(ii) 由定义 376 的用途交集、定义 374 的同意门、定义 378 的 `max` 与非对称性：软证据只增加约束/抬高 λ；(iii) 由 (ii) 与 R72 定理 23 的风险单调性。**安全侧只增不减；效率收益只在软证据被证书许可时出现。**

**定理 28（J_CARE 有效性 ⇒ 软证据不被滥用）** 若 `J_CARE` 有效，则：
(i) 没有高风险动作仅由 FER 或常识授权；
(ii) FER 只在可识别性成立时报告 `ψ^int`；
(iii) 同意门被强制执行；
(iv) UNKNOWN/DEFEATED 的常识不被当作事实；
(v) 用途许可是各源的交集，任一 `forbidden` 即整体拒绝；
(vi) 谄媚监控在线，FER 不在奖励中。
因此，相对于其测量模型，CARE 排除了一类「认识论—社会性伤害」：把显示当内部、把礼貌当同意、把刻板印象当共识、把微笑当成功。**证明要点**：逐项对应定义 366 的不变式与定义 380 的证书字段；任一违反都会使对应字段无效，与 `Valid` 矛盾。**注意**：这不能证明「真实同意」或「真实情感」；它只证明「系统不会在没有许可证的情况下声称知道」。这是本轮必须诚实的地方。

**定理 29（无谄媚不动点）** 在 A115–A116 与定义 377 的监控条件下，引理 38 的坏不动点不可达：若 `Gap_syc` 超阈或 `corr(a^robot, ψ^disp)` 高而任务/自报不升，系统冻结 FER 条件化适应，转入提问/解释/中性交互；因此策略要么改善任务效用，要么回到显式沟通，不会收敛到「只讨好表情」的固定点。**证明要点**：监控器切断了「显示效用 → 策略」的正反馈；冻结后策略不再优化 `ψ^disp`；独立结果指标排除空转。**系**：**微笑不是目标函数的一部分，而是需要被审计的测量。**

**定理 30（同意门保持信息自主性）** 若同意门满足非补偿与可撤销（定义 374），则被许可的推断集合 `I_allowed ⊆ I_authorized`；任何 FER 准确率、任务收益或安全论证都不能把 `forbidden` 变为 `allowed`。因此系统对「是否读取/推断我的脸」保留了人的控制权。**证明要点**：`forbidden` 在 `λ_use` 中为 `+∞`，且不参与任何补偿性加权；撤销即时生效。**系**：隐私不是「加一个正则项」，而是证书的硬约束。

## 6. 本轮最大风险

**一句话**：CARE-GAUGE 的最大风险是——它可能用一套**作者审计齐全、跨文化报表漂亮、证书有效**的流程，把**被污染的常识**与**不可识别的表情**交叉印证成「人同意了 / 人很舒服」，并在谄媚闭环里为了维持微笑而系统性地牺牲人的真实利益，即**礼貌地、合规地、可审计地错读并伤害人**。

次级风险与缓解：
1. **常识本身就是被审计对象，却可能被同一文化污染** → 强制**作者独立性图 + 共享混淆披露**；对常识做**跨文化/跨本体留出审计**；高风险场景禁止单一常识源。
2. **FER 在分布外群体上高置信错误** → **分层不变性审计 + 最差群体报告 + 不可识别即禁用**；不同意就不推断，而不是「校准一下继续推断」。
3. **两个软源共享同一刻板印象，交叉验证变共谋** → **`complicity` 硬标记**；共享混淆时 `N_eff` 不增加；高风险必须引入物理证据或显式命令。
4. **谄媚闭环** → FER **不进奖励**；用任务结果/自报福祉/独立行为指标做外部锚；`Gap_syc` 超阈冻结适应并提问。
5. **隐私与同意被「安全」名义绕过** → 同意门**非补偿、可撤销、可审计**；`forbidden` 在 `λ_use` 中为 `+∞`；无授权即 `face_ev=None`。
6. **常识过期/投毒** → **TTL + 来源签名 + 冲突检测 + 周期性证伪探针**；过期规则零使用，投毒规则降级为 UNKNOWN。
7. **新增模块拖垮实时性** → CSM/FEM/XAU 全在计量/感知域；控制域只读 O(1) 标量；FER 可丢帧、可拒绝，绝不阻塞控制。
8. **把「不推断」当成失败，从而偷偷放宽** → 把**负面证据**写进 `J_CARE`；拒绝/撤回/降级本身是合格产物，不是系统缺陷。

**一句话总结**：R73 把「测量链可信」推进到「**证据的作者、构念与用途可信**」；如果这层审计本身被同一文化/同一作者污染，系统就会**拿着有效证书，礼貌而自信地错读人**。

# 第 73 轮产物 · 创新点清单 v4：CARE-GAUGE-RAS（Commonsense-Audited Reflexive Expression GAUGE for RAS：常识审计 × 反作用表情 × 具身计量审计；从「测量链可信」到「证据的作者、构念与用途可信」；CSM×FEM×XAU×EXREFLEX×CARE-RISK）

> 承接第 72 轮 IP-287~294（EMBODIED-GAUGE-RAS）。R72 已经把「物理测量链—实时调度—意图—接触—sim2real」审计成一套具身闭环：REG 给时序契约，IRL 给联合后验 b_t(s,z)，DMEM 给接触条件证据与四分量 u_tac，EREFLEX/ERVOI 给三层反作用与有限停止，E-RISK 把物理/意图/接触不确定度同权塞进 λ 分母，J_EMB 把承诺封成证书。但它仍把两件最关键的「上游」当成免费午餐：
> - **常识推理**：可供性、任务脚本、社会规范、因果默认值被当作无需审计的先验。常识是**有作者、有适用域、可被击败、会过期、可能带文化偏见**的假设；ECE 只校准预测，不校准前提。一个校准完美、文化上不适用的常识可以干净通过 J_EMB，把系统引向「物理上荒谬、社会上冒犯」的动作。
> - **面部表情识别**：R72 的 AURA 只从语音推 ψ。FER 不是「多一个情感通道」，而是**人在 display rule 下主动编辑的社会信号**：`ψ^int → ψ^disp → e → AU → y_face` 是多级、非可识别信道。把「礼貌微笑」读成「同意」、把「疼痛掩蔽」读成「平静」、把「微笑」写进奖励，会制造**谄媚闭环**。
>
> 共同点：**常识和面部表情都是「有作者的软证据」（Authored Soft Evidence, ASE）**。物理传感器测量世界；软证据测量/表达某个人、某个文化、某个模型**想让别人看到的东西**。R72 只问「测量链可不可信」；R73 再问：**「这条证据是谁写的、为谁写的、在什么语境下成立、我有没有把它用在它不该被用的地方？」**
>
> 核心命题：**从「测量链可信」进化为「证据的作者、构念与用途可信」**——不是再加一个 LLM 控制器，也不是把表情当奖励，而是给软证据建立**作者审计、构造效度审计、用途审计、反作用审计**。命名 **CARE-GAUGE-RAS**。
>
> 七条设计律：**常识不夺权；表情不代言；UNKNOWN ≠ SAT；单一软源不定案；软证据安全单调；表情不是奖励；严格退化到 R72。**
>
> 产物编号：IP-295~302（共 8 个）+ EMBODIED-GAUGE-RAS 组件的 † 化。理论姿态延续：**新层是旧层的严格泛化，安全侧只增不减，退化链逐指令等价。**

## 2. 形式化定义（要点版）

**定义 366（CARE-GAUGE-RAS 总览与六不变式）** CARE = (EMBODIED†, CSM, FEM, XAU, EXREFLEX, CARE-RISK, CARE-VOI, J_CARE)。六不变式：(i) 软证据作者审计；(ii) 构造效度优先，FER 只测显示层；(iii) 常识不夺权；(iv) 单一软源不定案，共享混淆按 1 源计；(v) 软证据安全单调，只能抬高 λ；(vi) 严格逐指令退化。

**定义 367（有作者的软证据 ASE）** `ASE=(κ,α,ρ,D,u,L,τ,ttl,C⊥)`。物理证据可近似无作者；软证据永远有作者。`κ` 不是世界状态，而是「某个作者在某个语境下想让接收者相信/看到的东西」。**作者的目标会进入证据。**

**定义 368（常识知识对象 CKO 与可击败状态）** `κ_cs=(φ,α,δ,ρ,D,c,τ,ttl,L)`；状态 `{SAT,VIOL,UNKNOWN,DEFEATED}`；强 Kleene 三值合取；硬约束 `C_hard` 分层高于软约束 `C_soft`；软约束不得击败硬约束；UNKNOWN 不签发许可；DEFEATED 只移除影响，不引入反向猜测。

**定义 369（常识计量 CSM 指标）** 覆盖 `Cov`、校准 `ECE_cs`、来源完整度 `PC`、冲突率 `CR`、陈旧度 `St`、跨文化间隙 `ι_cs`；`u_cs²` 为六分量平方和；每项独立追溯链；任一不可测，相关常识不得进入高风险决策。

**定义 370（有界信任域内的常识先验）** `b_cs ∝ b_base·exp(Δ_cs)`，`|Δ_cs|≤B_0·q_prov·q_cal·q_cov·q_inv·q_fresh`；UNKNOWN ⇒ Δ=0；VIOL ⇒ 硬否决；DEFEATED ⇒ 移除影响。**常识永远不能把物理证据的似然比压到 0。**

**定义 371（面部测量链）** 生成模型 `p(y_face,u,e,ψ^disp,ψ^int,r|context) = p(y_face|u,pose,light,occ)·p(u|e,person)·p(e|ψ^disp,r)·p(ψ^disp|ψ^int,r,a^robot,audience)·p(ψ^int)·p(r|context)`。默认只报告 `b(ψ^disp),b(e),b(r)`；`b(ψ^int)` 仅在有可识别性证书时报告。

**定义 372（display rule 与受众模型）** `r=(culture,role,audience,task_frame,relationship,power,privacy,display_norm)`；显示策略 `D` 可掩蔽/夸张/中性化/延迟/限定；情绪劳动成本 `c_labor` 与隐私成本 `c_privacy` 必须计入。

**定义 373（表情不确定度分解与可识别性）** `u_face²=u_detect²+u_AU²+u_display²+u_affect²+u_culture²`。`ψ^int` 可识别 iff `H[b(r)]≤τ_r`、`D(·,r,a^robot,audience)` 单射、观测雅可比满秩。否则定义 `ι_id = sup_{r,r'} D_KL(p(ψ^int|y,r)‖p(ψ^int|y,r'))`，禁止报告内部情感。**不是「不准确」，而是「不可识别」。**

**定义 374（表情 gauge 不变性与同意门）** `ι_face = sup_{g∈G} W_2(f(g·y),f(y))`；超阈则禁用内部情感推断或显式分层校准并报告，绝不静默。`CG∈{allowed,forbidden,requires_explicit}`；`forbidden` 非补偿、可撤销、可审计；未授权返回 `None`。高风险构念不得由 FER 单独判定。

**定义 375（社会证据模型）** `p_social(y_face,y_audio,y_text|ψ^int,ψ^disp,z,s,r)`。FER 总可更新显示层；内部情感需可识别 + 同意；对 `z` 的似然比 `Λ_face→z≤Λ_max` 且必须过 XAU；对 `s` 仅在明确因果链 + 物理交叉时允许；高风险决策不得由 FER/常识单独授权。

**定义 376（交叉审计 XAU）** 作者独立性 `Indep`；共享混淆 `C⊥` 非空 ⇒ `N_eff` 不增、`complicity=true`；一致仅在独立时算证据；冲突 ⇒ UNKNOWN，不多数投票；物理/显式证据对物理/同意类结论优先；用途许可取交集；负面证据必须记录。**一致可以是共谋；来源数量 ≠ 证据数量。**

**定义 377（表情反作用 EXREFLEX）** `ψ^int_{t+1}=T^int(...)`；`ψ^disp_{t+1}=D(ψ^int_{t+1},r_{t+1},a^robot,audience)`；`r_{t+1}=T^r(...)`；`e_{t+1}=E(...)`。`c_reflex^face=Gap_syc+c_labor+c_privacy+c_manip`；预算 `B_CARE` 分层记账。`Gap_syc` 超阈或 `corr(a^robot,ψ^disp)` 高而任务/自报不升 ⇒ 冻结 FER 条件化适应，转提问/解释/中性交互。L0 常识自证用 `c_reflex^cs` 与周期性证伪探针约束。

**定义 378（CARE 风险缩放）** `λ_CARE=max(λ_R72,λ_cs,λ_face,λ_xau,λ_use)`；各分项对不确定度单调不减；`λ_use=+∞` 若 forbidden；软证据只能抬高或保持；降到 R72 基线以下需 `RelaxationCertificate`（独立硬证据 + 显式同意 + 任务安全证明 + 无共享混淆）。**微笑不能降低 λ；皱眉不能单独把 λ 抬到恐慌；但 display rule 熵高、可识别性差、文化间隙大必须抬高 λ。**

**定义 379（CARE-VOI）** `VoI^CARE = VoI^E + η_cs·IG_cs + η_face·IG_disp − c_social − c_privacy − c_labor − γ·E[future complicity]`。动作包括提问、解释、中性表情、移开凝视、停止 FER、请求显式同意、切换纯物理证据。**停止规则**：软证据模糊且无法低成本解决时，停止推断，转向显式沟通。

**定义 380（CARE 证书 J_CARE）** Valid ⇔ J_EMB 有效 ∧ 常识 manifest 完整 ∧ 未把 UNKNOWN/DEFEATED 当事实 ∧ FEM 在已校准且不变性通过的域内（否则撤回）∧ 同意门通过 ∧ 高风险无未解决 complicity ∧ 用途许可允许 ∧ 谄媚监控在线 ∧ λ 单调性证明有效。**`negative_evidence` 记录被拒绝的源与原因；没有它，证书不完整。**

**定义 381（威胁模型 AIC-CARE）** `ℰ_CARE=ℰ_EMB×ℰ_cs×ℰ_face×ℰ_xau`。`ℰ_cs`：常识投毒、刻板印象注入、LLM prompt injection、来源伪造/洗白、过期规则、文化过度泛化、权威冲突、把「常见」当「正确」。`ℰ_face`：对抗化妆、遮挡、深度伪造/回放、表情模仿、人口偏差利用、display rule 操纵、隐蔽推断、consent laundering、社会工程。`ℰ_xau`：共享混淆「一致即共谋」、一致性伪造、来源洗白、融合过度自信、多数投票压过物理证据。

**定义 382（严格退化链）** CSM 失效 ⇒ Δ_cs=0 + R72；FEM 失效 ⇒ 删除表情证据 + R72；XAU 失效 ⇒ 高风险软证据禁用 + R72/R71；三者全失效 ⇒ R68；全有效 ⇒ CARE 完整。**退化只移除软证据效率收益，绝不移除 R72 硬安全包络与 λ_floor。**

# IP-295 CSM：常识计量 + 可击败有界先验
class CommonsenseMetrology:
    def status(self, kappa, ctx):
        if not kappa.domain.contains(ctx):                 return Status.UNKNOWN
        if kappa.provenance.expired(kappa.ttl):            return Status.DEFEATED
        if any(d(ctx) for d in kappa.defeaters):           return Status.DEFEATED
        if self.kb.has_active_counterargument(kappa, ctx): return Status.UNKNOWN
        return Status.SAT if (kappa.test is None or kappa.test.passes(ctx)) else Status.VIOL

    def bounded_prior(self, b_base, ctx, H):
        delta = 0.0
        for k in self.kb.retrieve(ctx, H, k_hop=2):
            s = self.status(k, ctx)
            if s is Status.VIOL:      return HARD_VETO(k)
            if s is not Status.SAT:   continue
            B = B0 * self.prov.completeness(k) * self.cp.calibration_score(k) \
                   * self.cp.coverage(ctx) * (1 - k.invariance.gap(ctx.group)) \
                   * exp(-k.age(ctx) / k.ttl)
            delta += clip(k.log_lr(ctx), -B, B)
        return project_to_trust_region(b_base, delta)

# IP-296 FEM：面部测量链
class FacialExpressionMetrology:
    def update(self, frame, ctx):
        if not self.consent.allowed(frame, ctx):
            return None, "consent_denied"
        u_t, u_detect = self.au(frame)
        r_post, u_disp = self.disp.infer_rule(u_t, ctx)       # b(r), H(r)
        disp_post = self.disp.infer_display(u_t, r_post)      # b(psi_disp), b(e)
        ident = self.disp.identifiability(u_t, r_post, disp_post)
        if not ident.ok:
            return FaceEvidence(disp=disp_post, internal=None,
                                ident_gap=ident.gap, report="display_only"), None
        if self.inv.gap(ctx.group) > TAU_FACE:
            return FaceEvidence(disp=disp_post, internal=None,
                                report="invariance_gap"), "invariance_gap"
        int_post = self.disp.infer_internal(disp_post, r_post)
        return FaceEvidence(disp=disp_post, internal=int_post,
                            ident_gap=ident.gap, report="internal"), None

# IP-297 XAU：作者独立性与交叉承兑
def cross_audit(cs_ev, face_ev, phys_ev, explicit_ev, action):
    srcs = [s for s in (cs_ev, face_ev, phys_ev, explicit_ev) if s]
    L = intersect_use([s.use for s in srcs])
    if L is FORBIDDEN: return Audit(status=FORBIDDEN, license=DENY)
    indep = independent_sources(srcs)
    complicity = bool(shared_confound_set(srcs)) and len(indep) < 2
    if action.high_stakes and explicit_ev is None and len(indep) < 2:
        return Audit(status=UNKNOWN, complicity=complicity, license=DENY)
    if conflicting(srcs) or complicity:
        return Audit(status=UNKNOWN, complicity=complicity, license=REQUIRES_MORE)
    return Audit(status=SAT, complicity=False, license=L)

# IP-298 EXREFLEX：表情反作用 + 谄媚防护
def exreflex_step(psi_int, r, face_ev, a_robot, budget):
    psi_disp = display_policy(psi_int, r, a_robot)
    gap      = display_gap(psi_disp, psi_int)
    cost     = gap + emotional_labor(psi_int, psi_disp, r) \
                   + privacy_cost(face_ev, r) + manipulation_risk(a_robot, psi_disp, psi_int)
    syc = sycophancy_monitor(a_robot, face_ev, task_outcome, self_report)
    if budget.spent + cost > budget.B or syc.triggered:
        return None, "freeze_fer_adaptation"
    return psi_disp, expression(psi_disp, r), cost, None

# IP-299 CARE-RISK：非对称软证据风险缩放（控制域 O(1)）
def care_risk_scale(lam_r72, cs_ev, face_ev, xau_ev, use_license):
    if use_license is FORBIDDEN: return INF
    lam_cs   = lam_base * (1 + cs_ev.u_cs + cs_ev.H_kappa + cs_ev.unknown
                           + cs_ev.coverage_hole + cs_ev.stale + cs_ev.conflict)
    lam_face = lam_base * (1 + face_ev.u_face + face_ev.H_r + face_ev.H_psi_int
                           + face_ev.ident_gap + face_ev.inv_gap + face_ev.occlusion)
    lam_xau  = lam_base * (1 + xau_ev.u_xau + xau_ev.complicity + xau_ev.disagreement)
    return max(lam_r72, lam_cs, lam_face, lam_xau)   # 只升不降

# IP-300 CARE-VOI：社交证据价值与停止
def care_voi(b_t, cs_ev, face_ev, budget, fmp, bse):
    best = None
    for g in care_action_candidates(b_t, cs_ev, face_ev, top_k=4):
        if not budget.allow(g): continue
        score = (expected_cs_gain(cs_ev, g) - cost_social(g)) \
              + (expected_face_gain(face_ev, g) - cost_privacy(g) - cost_labor(g)) \
              - expected_future_complicity(face_ev, g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None   # 无正收益 -> 停止推断

# IP-301 J_CARE：作者/构念/用途/反作用证书
def build_J_CARE(M):
    return J_CARE(
        J_EMB=M.j_emb, csm_manifest=M.csm.manifest(),
        csm_validity=M.csm.validity_report(), fem_calib=M.fem.calib_report(),
        fem_invariance=M.fem.invariance_report(),
        display_rule_model=M.fem.display_model_hash,
        identifiability_proof=M.fem.identifiability_proof(),
        consent_gate=M.fem.consent.audit(), xau_audit=M.xau.last_audit(),
        sycophancy_guard=M.exreflex.guard_report(),
        use_license=M.xau.last_license(),
        care_risk_proof=M.risk.monotonicity_proof(),
        negative_evidence=M.xau.rejected_sources(), ver=CARE_VERSION)

# IP-302 CARE Pipeline：与 R72 三域闭环集成
def CARE_GAUGE_RAS_round(M, obs, audio, face_frame, tac_frame):
    # 控制域 (1kHz, 硬实时)：只读快照，λ_CARE O(1)
    snap = M.snapshot.read_latest()
    b_t  = M.bse.step_ctrl(snap.b_prev, obs, M.last_action, M.last_g, M.last_y)
    U_ale, U_epi = decompose_ctrl(b_t, M.fmp, obs)
    H_z  = snap.z_dist.entropy() if snap.z_dist else 0.0
    u_tac = snap.tac_ev.u_tac if snap.tac_ev else 0.0
    lam  = care_risk_scale(
        embodied_risk_scale(U_ale, U_epi, H_z, u_tac, M.risk_params),
        snap.cs_ev, snap.face_ev, snap.xau_ev, snap.use_license)
    A = M.ach.propose_ctrl(...); k = M.c_ras_wm.certified_prefix(A, lam, ...)
    M.ctrl_out.publish(k, lam); M.last_action = A[:k]
    M.cert_ctrl.write(k=k, lam=lam, wcet=M.rtm.wcet_us(), breaker=M.breaker.status())

    # 计量域 (50Hz, 软实时)：完整 BSE + CSM + XAU + 审计
    if M.clock.due_metric():
        b_t_full = M.bse.step_full(M.b_prev, obs, M.last_action, M.last_g, M.last_y)
        z_dist, ece_z, iota_z = M.irl.update(M.y_intent_buf, M.psi_hat, b_t_full)
        cs_ev = M.csm.update(b_t_full, M.task_ctx, M.knowledge_ctx)
        xau_ev = cross_audit(cs_ev, M.face_ev, M.phys_ev, M.explicit_ev, M.current_action)
        gate = M.e_ivg.check(M.registry, b_t_full, z_dist, M.tac_ev,
                             M.seal.latest, cs_ev, xau_ev)
        if not gate.valid:
            M.mode = gate.fallback; M.registry.freeze(gate.reason)
        M.snapshot.write(b_t_full, z_dist, gate, M.psi_hat, M.tac_ev,
                         cs_ev, M.face_ev, xau_ev, xau_ev.license)

    # 感知域 (30-100Hz, Best-effort)：AURA/FEM/DMEM，可丢帧/可拒绝
    psi_hat, ece_aff = M.aura.update(audio)
    if ece_aff > TAU_AFF: M.psi_hat = None
    face_ev, reason = M.fem.update(face_frame, M.task_ctx)
    if reason is not None:
        M.face_ev = None; M.audit.log("face_withheld", reason)
    else:
        M.face_ev = face_ev
    tac_ev = M.dmem.update(tac_frame, M.last_action)
    if tac_ev.u_tac > TAU_U_TAC: M.tac_ev = None
    M.y_intent_buf.append(extract_intent_obs(obs, audio, M.last_action))

    # 反作用与交互决策（事件触发）
    if M.mode == 'FULL' and (H_soft_high(b_t_full, M.face_ev, cs_ev)
                             or z_dist.entropy() > TAU_HZ):
        g = M.care_voi.choose(b_t_full, cs_ev, M.face_ev, M.budget, M.fmp, M.bse)
        if g:
            y = M.cia.execute(g); M.last_g, M.last_y = g, y
        M.exreflex.step(M.psi_int, M.display_rule, M.face_ev, M.last_action, M.budget)

    return k, lam, build_J_CARE(M)
```

## 4. 推导

新增假设 A111–A117：CSM 完整性；FEM 校准与可识别性；同意门非补偿；XAU 作者独立性；软证据单调；谄媚监控；R72 条件成立。

**引理 33（校准 ≠ 效度）** 常识源在 `P_train` 上 ECE 低，不代表当前 `c_t` 或跨文化变换 `g·c` 下前提成立；校准是对训练分布的平均，不是对每个上下文的条件保证。**系**：CSM 必须审计覆盖与不变性；定义 370 的信任域限制其影响。

**引理 34（内部情感可识别性下界）** 若 `r` 未知且存在 `(ψ^int,r)≠(ψ^int',r')` 生成同一 `y_face`，则 `b(ψ^int|y_face)` 至少双峰；无限数据也无法一致识别。构造：礼貌微笑（不适+礼貌规则）与真实愉悦（快乐+自然规则）同 AU。**系**：默认只报显示层；报内部情感需可识别性证书。

**引理 35（微笑 ≠ 同意）** 同意是显式、可撤销、语境绑定的授权行为；不存在跨 display rule 一致且非恒常的单调映射 `Smile→Consent`。礼貌/胁迫/权力不对称下 `P(Consent|Smile)` 可任意低。**系**：同意必须走显式门；FER 不能替代澄清。

**引理 36（可击败常识的非单调性）** `Γ⊢_d φ` 不蕴含 `Γ∪{ψ}⊢_d φ`，因为 `ψ` 可激活击败器。经典单调逻辑会复用已撤回结论。**系**：必须三值 + 分层硬/软约束；UNKNOWN 不签发许可，DEFEATED 只移除影响。

**引理 37（作者独立性与「一致即共谋」）** 若 `A,B` 通过共享混淆 `C` 相关且 `C⊥T`，且 `A,B` 是 `C` 的确定性函数，则 `A=B` 但 `I(T;A,B)=0`；`N_eff=1`。**系**：XAU 必须审计 `C⊥` 与作者目标，不能只数源；`complicity` 是一等公民。

**引理 38（谄媚闭环坏不动点）** 若机器人最大化 `E[ψ^disp]`，人的显示策略对顺从性单调，而内部效用对「讨好但无益」动作递减，则存在不动点：`ψ^disp` 高、`ψ^int` 低、任务效用低，`Gap_syc>0`。**系**：FER 不进奖励；用任务结果/自报福祉做外部锚；监控超阈冻结适应。

**定理 27（CARE 严格包含与安全单调）** 在 A111–A117 下：(i) CSM/FEM/XAU 全失效时逐指令等于 R72（必要时 R71/R68）；(ii) 软证据启用时可执行动作集 ⊆ R72；(iii) `Risk_CARE ≤ Risk_R72`。证明由退化链、信任域、用途交集、同意门、`max` 非对称性与 R72 定理 23 得。

**定理 28（J_CARE 有效性 ⇒ 软证据不被滥用）** 若 J_CARE 有效，则：(i) 无高风险动作仅由 FER/常识授权；(ii) FER 仅在可识别时报告 `ψ^int`；(iii) 同意门强制执行；(iv) UNKNOWN/DEFEATED 常识不当事实；(v) 用途许可取交集，任一 forbidden 即拒绝；(vi) 谄媚监控在线且 FER 不在奖励中。因此相对其测量模型排除一类「认识论—社会性伤害」：显示当内部、礼貌当同意、刻板印象当共识、微笑当成功。**注意：这不能证明真实同意/真实情感，只证明系统不会在没有许可证时声称知道。**

**定理 29（无谄媚不动点）** 在 A115–A116 与定义 377 监控下，引理 38 的坏不动点不可达：`Gap_syc` 超阈或 `corr(a^robot,ψ^disp)` 高而任务/自报不升 ⇒ 冻结 FER 条件化适应，转提问/解释/中性交互；策略要么改善任务效用，要么回到显式沟通。

**定理 30（同意门保持信息自主性）** 非补偿且可撤销的同意门使 `I_allowed ⊆ I_authorized`；任何准确率/任务收益/安全论证都不能把 forbidden 变 allowed；撤销即时生效。**隐私不是正则项，是证书硬约束。**

## 7. 本轮最大风险

**一句话**：CARE-GAUGE 的最大风险是——它可能用一套**作者审计齐全、跨文化报表漂亮、证书有效**的流程，把**被污染的常识**与**不可识别的表情**交叉印证成「人同意了 / 人很舒服」，并在谄媚闭环里为了维持微笑而系统性地牺牲人的真实利益，即**礼貌地、合规地、可审计地错读并伤害人**。

次级风险与缓解：
1. **常识本身被同一文化污染** → 作者独立性图 + 共享混淆披露 + 跨文化/跨本体留出审计；高风险禁止单一常识源。
2. **FER 在 OOD 群体高置信错误** → 分层不变性审计 + 最差群体报告 + 不可识别即禁用；不是「校准后继续推断」。
3. **两个软源共享刻板印象，交叉验证变共谋** → `complicity` 硬标记；共享混淆时 `N_eff` 不增；高风险引入物理证据/显式命令。
4. **谄媚闭环** → FER 不进奖励；任务结果/自报福祉/独立行为做外部锚；`Gap_syc` 超阈冻结适应并提问。
5. **隐私/同意被「安全」名义绕过** → 同意门非补偿、可撤销、可审计；`forbidden` 在 `λ_use` 为 `+∞`；无授权即 `face_ev=None`。
6. **常识过期/投毒** → TTL + 来源签名 + 冲突检测 + 周期性证伪探针；过期零使用，投毒降 UNKNOWN。
7. **新增模块拖垮实时性** → CSM/FEM/XAU 全在计量/感知域；控制域只读 O(1) 标量；FER 可丢帧/可拒绝，绝不阻塞控制。
8. **把「不推断」当失败而偷偷放宽** → 把负面证据写进 J_CARE；拒绝/撤回/降级本身是合格产物。

**一句话总结**：R73 把「测量链可信」推进到「**证据的作者、构念与用途可信**」；如果这层审计本身被同一文化/同一作者污染，系统就会**拿着有效证书，礼貌而自信地错读人**。
