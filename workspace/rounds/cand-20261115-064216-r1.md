# 第 4 轮（研究线累计；灵感循环第 1 轮；本轮灵感：「双臂协调」×「场景理解」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。场景理解与双臂协调各沿一条轴升级 InstructGauge，且任一环节不可用都必须能一键退回；场景先验与第二臂都是增强项，不是依赖项。

## 0. 直觉与动机

**灵感 1（场景理解 → 盲区从「几何空洞」变成「场景图上的假设缺口」）**
直觉：人类不会在一个没有结构的点云里盲目扫视；他会说「盲区在金属板下面，先把盒子挪开」。场景图（物体、支撑、遮挡、包含、可供性）把「哪里可能还有东西」变成了可枚举的假设：缺的是节点、是边、还是某个物体的位姿。于是主动探测不再是对度量空间的均匀搜索，而是对场景图假设的**信息最大化实验**。但场景理解只是**先验，不是证据**：它会把「看起来像」的东西填进图里，而模型幻觉在图里就是一个不存在的节点。正确的接口是：场景图必须先被接地成**带证书的假设集**，只有被独立回执支持的部分才能驱动动作；未接地的子图只能作为规划假设，不能作为物理行动或语言主张的依据。

**灵感 2（双臂协调 → 第二臂是「可移动夹具 + 第二视角 + 独立见证」，不是简单并联）**
直觉：第二臂的价值不在于「多一只手」，而在于它能**改变场景本身**：一只臂夹住/翻转物体，另一只臂去探测原本被遮住的表面（hold-and-expose）；两臂形成基线视差，把单目深度歧义变成可三角化的约束；一只臂固定物体，另一只臂施加已知力，把位姿不确定性压成力闭合残差。所以双臂协调的第一性收益是**可控的场景编辑 + 物理约束**，而不是「两个传感器取平均」。代价同样结构性：共享物体、共享光照、共享标定会让两臂的误差**同源**；互相遮挡会让两臂争抢「谁先看」；通过物体传递的力矩会让一只臂的失效沿物理对象级联。

**灵感 3（两者耦合 → 场景是两臂共享的假设，两臂是场景的编辑者）**
直觉：最危险的不是场景理解错了，也不是双臂撞了，而是：**一个共享的、未经独立接地的高置信场景假设，被两只臂同时当成真，并据此对场景做了不可逆的编辑**。此后两臂「一致」只是因为它们共享同一个错误先验或同一套标定；它们对场景的编辑又反过来让先验失效，而系统仍用旧先验解释新回执。这就是「共同幻觉 → 联合行动 → 场景被改 → 先验更错」的正反馈。解法不是禁用场景先验或第二臂，而是四根结构支柱：**场景假设接地**（无证书不行动）、**保守反事实可见性**（编辑前预测、编辑后复核）、**共因感知联合证据**（一致 ≠ 独立）、**角色-令牌协调 + 联合不可逆屏障**（协调可抢占、不可逆编辑强制单步 + 独立见证），再叠加**场景分层共形校准**。

## 1. 研究问题（本轮要回答什么）

- **Q1（场景先验的安全性）**：场景图能否作为「只收窄、不扩权」的安全先验？幻觉节点/边能否被接地证书隔离，而不是被下游当成事实？
- **Q2（第二臂的净收益）**：第二臂在什么条件下提供**独立**的证据增益或物理约束收益（hold-and-expose、视差、力闭合），在什么条件下只是放大共因、造成遮挡竞争与物理级联？收益能否量化并可证伪？
- **Q3（共享假设的放大）**：共享场景先验 × 双臂联合行动，是否会把一次场景幻觉放大成不可逆的场景编辑？能否用结构（接地 / 保守可见性 / 共因证书 / 令牌 / 屏障）把放大压回线性、可界、可回滚？

## 2. 设计原则（雏形，正式化见产物区定义 448–463）

**P1 场景先验只做子集选择（Scene Prior as Subset Selector）**
已接地的场景图只能**过滤与重排**探测计划，不能命名新工具、不能扩张物理可行域；场景编辑动作必须带前置证书与可逆性等级，R2（不可逆）编辑一律走联合不可逆屏障。形式化方向：`Plan(𝓖_cert) ⊆ Plan_InstructGauge`，未接地节点映射为 ⊥。这给出「场景理解不会成为新的越权通道」的类型级保证。

**P2 共因不借证据（No Evidence Borrowing Across Common Cause）**
两臂证据只有在通过 `Indep(i,j)` 证书（不共享标定 / 光照 / 场景先验 / 回执血缘，且残差相关低于阈值）时才能融合并享受方差下降；否则按**单见证**处理，覆盖率取共因平台下界。物理力闭合残差是确定性约束，可作为一致性审计，但不能替代独立观测。

**P3 协调必须可抢占、可回退（Coordination Must Be Preemptible）**
任一协调状态都必须存在一条到单臂安全执行的退化路径：角色-令牌协议保证无死锁 / 无活锁，联合安全包络保证碰撞与力耦合有界，任何时刻 anchor 都能冻结为支撑、prober 都能撤回。协调不是新的依赖项，而是可丢弃的加速器。

## 3. 与基线的接口（如何退化）

- 场景图未接地 / 幻觉率超阈 / 可见性证书不可用 ⇒ 退回 InstructGauge 的度量探测（不使用场景编辑）；
- 第二臂不可用 / 协调不可行 / 共因证书缺失 ⇒ 退回单臂 InstructGauge 逐步执行；
- hold-and-expose 风险超过收益 / 编辑不可逆且无独立见证 ⇒ 禁止编辑，改用纯视角探测；
- 场景条件校准样本不足 ⇒ 回退全局共形（InstructGauge SC-Cal）；
- InstructGauge 失效 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个「场景图即带证书假设集」的接地口径，把场景先验的幻觉面压到可类型检查、可隔离的范围内；
2. 一个保守反事实可见性 + hold-and-expose 原语，把第二臂的收益从「多一个传感器」提升为「可控的场景编辑 + 物理约束」，并给出收益 / 风险的可证伪判据；
3. 一个共因感知的联合证据与联合证书，明确回答「两臂一致何时才算独立证据」，并给出覆盖率地板；
4. 一个角色-令牌协调协议 + 联合不可逆屏障，把双臂耦合的死锁、振荡与不可逆场景编辑压成可检测、可回退的结构；
5. 一条完整可证伪路径：E457–E472 覆盖场景接地、可见性完备、协调死锁、共因覆盖、hold-and-expose、编辑安全、场景分层覆盖、对抗幻觉、消融与 50Hz 时序。

## 5. 本轮最大风险

**一句话**：场景理解与双臂协调共享同一个学习先验与物理世界，因此「两臂都同意、场景图也支持」很可能只是**同一个错误的三种说法**；一旦据此执行不可逆的场景编辑，系统会亲手破坏用于判断对错的先验，真正的残余风险是「共同幻觉经联合行动写成物理事实」，而不是单臂精度或单帧识别率。

## 2. 形式化定义（要点）

**定义 448（不确定场景图 𝓖 与接地证书）**
`𝓖 = (V_s, E_s, μ, Σ, ℓ_sem, cert, occ)`。节点 `v ∈ V_s` 表示物体/表面/区域，携带位姿分布 `N(μ_v, Σ_v)`、语义标签 `ℓ_sem(v)` 与接地证书 `cert(v)`；边 `e ∈ E_s` 表示 support / occlude / contain / afford，同样带证书。接地映射
`Ground: Scene × Receipts × Prior → (𝓖_cert, 𝓖_?)`。
节点/边 actionable 当且仅当 `cert ≥ τ_scene` 且其证据含**至少一条不来自同一学习先验的独立回执**。`𝓖_? = 𝓖 \ 𝓖_cert` 为幻觉隔离区：可用于假设生成，**不得**驱动场景编辑、物理探测或语言主张。`cert` 逐项记录来源、独立性与置信度，供 JRC 审计。

**定义 449（场景签名与校准层）**
`sig(𝓖) = (物体类别多重集, 支撑关系模式, 遮挡等级桶, 可供性集合, 两臂工作空间重叠度)`。`sig` 既用于场景条件共形分层（定义 459），也用于检索相似历史场景与复用校准集。场景编辑改变 `sig` ⇒ 触发重新分层与新鲜度检查。

**定义 450（保守可见性算子与可见性证书）**
对联合视角 `q = (q₁,q₂)` 与场景图 `𝓖`：
`Vis⁺(𝓖,q) ⊇ Vis(𝓖,q)`，`Occ⁺(𝓖,q) ⊇ Occ(𝓖,q)`，且 `Vis⁺ ∪ Occ⁺ = S`。
定义**保证可见集** `SafeVis = S \ Occ⁺ ⊆ Vis(𝓖,q)`。可见性证书 `VC = (Vis⁺, Occ⁺, ε_vis)`，其中 `ε_vis ≥ |Vis⁺ \ SafeVis|` 为保守性代价（漏看的可见面积上界）。**动作许可**：仅当 `ε_vis ≤ δ_vis` 时，探测才可指向 `SafeVis`；指向 `Occ⁺` 的探测一律拒绝。编辑后必须重新计算 `VC`。

**定义 451（场景编辑动作）**
`e = (o, T, pre, post, rev, cost)`：对物体 `o` 施加变换 `T`（移动/翻转/抽出/夹持），`pre` 为可测前置（可抓、支撑稳定、无碰撞、力闭合可行），`post` 为预期后置（新增可见面、改变支撑关系），`rev ∈ {R0 可逆, R1 可补偿, R2 不可逆}`，`cost` 为时间/能耗预算。`Plan_scene` 同时包含编辑与探测。执行条件：`pre` 经证书验证；`R1` 须有补偿方案；`R2` 须进入联合不可逆屏障（定义 462）。

**定义 452（双臂联合状态与联合安全包络）**
`x = (q₁, q₂, q̇)`，联合无碰空间
`C_joint = C_free(q₁) ∩ C_free(q₂) ∩ C_self(q₁,q₂) ∩ C_payload`。
联合安全包络 `E_joint = (摩擦锥, 负载上限, 互遮挡约束, 关节力矩上限, 最坏停止时间)`。双臂动作可采纳当且仅当 `x ∈ C_joint`、接触力在摩擦锥内、关键见证视角不被另一臂遮挡、且最坏停止时间满足 `T_stop ≤ T_safe`。

**定义 453（角色-令牌协调协议 T_τ）**
角色 `r ∈ {anchor, prober}`：anchor 负责夹持/固定/让出视野，prober 负责探测。令牌 `τ` 保证**至多一个 prober**。角色切换仅允许在块静默点 `q_quiesce`（继承定义 439）。等待图 `W` 记录「谁在等谁让出物体/视角/令牌」；要求 `W` 无环且存在良基秩 `rank: 协调状态 → ℕ` 在每次切换时严格下降。满足者无死锁/无活锁；违反者立即退回单臂（CDL L2）。

**定义 454（跨臂反作用通道与耦合矩阵）**
`χ^{i→j}: a_i ↦ (Δnoise_j, Δvisibility_j, Δforce_j)`，描述臂 `i` 的动作如何改变臂 `j` 的噪声、可见性与受力。耦合矩阵 `K_ij = Lip(χ^{i→j})`，谱半径 `ρ(K)`。**弱耦合** `ρ(K) < 1`：联合最佳响应是压缩映射，存在唯一不动点（可并行协商）；**强耦合** `ρ(K) ≥ 1`：强制令牌协议，把双向追逐变成有先后的序列。这把「两臂互相让位导致来回摆动」解释为耦合映射的 2-周期，而不是调参问题。

**定义 455（共因模型与独立性证书）**
`y_i = h_i(s, ζ_shared) + ε_i`，`ε_i ⟂ (s, ζ_shared)`，`ε_i ⟂ ε_j`。不确定度分解 `u_i² = u_{i,common}² + u_{i,idio}²`，共因占比 `κ = max_i u_{i,common}²/u_i²`。**独立性证书** `Indep(i,j)` 成立当且仅当：两臂不共享标定参数、光源/投影、场景先验版本、回执血缘，且残差相关 `|ρ̂_ij| < ρ_max`。`Indep` 缺失时，禁止把两臂当独立证据做方差缩减。

**定义 456（共因感知联合证据与联合证书）**
对 `n` 个证据源，模型 `y_i = s + ζ + ε_i`，`s~N(0,σ_s²)`、`ζ~N(0,σ_c²)`、`ε_i~N(0,σ_e²)`：
`Var(s | y_{1:n}) = [1/σ_s² + 1/(σ_c² + σ_e²/n)]^{-1} ≥ σ_s²σ_c²/(σ_s²+σ_c²)`。
故无论加多少臂，后验方差都有一个由 `σ_c²` 决定的**平台**。有效样本数 `n_eff = n / (1 + (n−1)κ)`，`κ = σ_c²/(σ_c²+σ_e²)`；未通过 `Indep` 时取 `n_eff = 1`（单见证）。联合证书
`J_joint = (J_scene, J_coord, J_witness, J_fresh)`，其中 `J_witness` 记录 `Indep` 结论与 `n_eff`。**不可借安全**：联合安全量取各臂安全包络的 `inf`，不得把 A 的裕度借给 B。

**定义 457（场景条件化分块目标 SC-IAC）**
`C* = argmax_{C admissible} [ ΔH_scene(C) + w_align·A(ι,C) + w_ens·smooth(C) − λ_cost·c(C) − λ_edit·Σ_e cost(e) − λ_coord·c_coord(C) ]`
`ΔH_scene(C) = H(𝓖_?) − E[H(𝓖_? | C)]` 为对未接地场景假设的期望熵减；约束：`shield(ι)`、`|C| ≤ K_MAX(ι)`、`Barrier(C)`、`VC 有效`、`x ∈ C_joint`、`n_eff` 诚实、预算准入（继承定义 444）。场景理解只通过 `ΔH_scene` 与候选排序影响计划，不改变可采纳集。

**定义 458（hold-and-expose 原语）**
`HE(o, F, q_p) = (anchor 以力 F 夹持/固定 o, prober 移到 q_p, 暴露表面 S_expose)`。
可行性：力闭合、负载在 `E_joint` 内、`S_expose ⊆ SafeVis(q₁,q₂)`、无关键互遮挡。
净收益 `Gain_HE = ΔH_scene(HE) − λ_r·R_edit(e) − λ_c·c(HE)`，仅当 `Gain_HE > 0` 且 `x ∈ C_joint` 时启用；否则退回单臂视角探测。

**定义 459（场景条件共形校准 SCC）**
`stratum = sig(𝓖)`。对每层 `s` 用校准集 `C_cal^s` 取阈值 `q_s`，使层内覆盖 `P(h* ∈ H_s | s) ≥ 1−α`。场景编辑改变 `sig`、造成协变量漂移时，旧校准按漂移量重加权或重置；`|C_cal^s| < n_min` ⇒ 回退全局阈值。与 InstructGauge SC-Cal 的区别：分层变量从「指令类型」升级为「场景签名 + 指令类型」。

**定义 460（联合修复证书 JRC）**
`JRC(s) = (𝓖_cert, e_{1:k}, 角色/令牌轨迹, C_{dual}, {CVC_i}, J_joint, receipts, claims, rollback)`。
它使人类审计可沿「场景主张 → 场景编辑 → 协调角色 → 双臂动作块 → 逐臂回执 → 联合主张」六级证据链复现一次修复；`rollback` 记录 R0/R1 编辑的逆操作或不可逆编辑的独立见证。

**定义 461（场景主张-证据绑定 SCB）**
每条场景主张 `c`（节点存在、边关系、可供性、位姿）必须绑定 `(receipt_id, visibility_cert_id)`；`bind_scene_claims` 只保留可命中回执且落在 `SafeVis` 的主张。未绑定主张在序列化时剥离为纯解释，**不进入动作路径**（继承并强化定义 441 的 NCB）。

**定义 462（联合不可逆屏障 JIB）**
若块跨 `R2` 编辑或不可逆探测，强制 `K=1`，且**场景编辑与后续探测必须分属不同提交**；执行后须由与执行臂满足 `Indep` 的独立见证（另一臂或固定外部锚点）确认后，才允许后续块。若见证与执行臂共享共因，则不算独立见证，必须改用外部锚点或人工确认。R1 编辑须先登记补偿动作与最坏回滚时间。

**定义 463（协调退化阶梯 CDL）**
L0：全功能（场景编辑 + 双臂协调 + 共因融合）；L1：禁用场景编辑，仅用 `𝓖_cert` 做视角探测；L2：单臂执行（另一臂被动支撑或撤出）；L3：无协调的顺序单臂 InstructGauge；L4：安全停止。每级声明转移条件、最坏转移时间与保持的不变量；任一级不可用自动降一级，安全侧只增不减。

# IP-328 SGG：场景图接地与幻觉隔离
class SceneGraphGrounder:
    def ground(self, scene, receipts, prior):
        G = self.parse(scene, prior)                    # 节点/边 + 先验补全
        actionable = set()
        for v in G.nodes:
            c = self.bind(v, receipts, prior)           # 必须含非先验独立回执
            if c.conf >= TAU_SCENE and c.independent:
                actionable.add(v)
        G_cert = G.subgraph(actionable)                 # 只可行动的子图
        G_q    = G.difference(G_cert)                   # 幻觉隔离：仅规划
        return G_cert, G_q

# IP-329 CVS：反事实可见性与保守证书
class CounterfactualVisibility:
    def certify(self, G, q_joint, edits):
        occ = self.overapprox_occluded(G, q_joint)      # 真实遮挡 ⊆ Occ⁺
        for e in edits:
            if not self.pre_certified(e):
                continue
            G_next = self.apply_edit(G, e)
            occ |= self.overapprox_occluded(G_next, q_joint)
        vis  = G.surface_set() - occ
        safe = G.surface_set() - occ                    # 保证可见
        eps  = self.conservativeness(vis, safe)
        return VisibilityCert(vis, occ, safe, eps)

# IP-330 DAC：角色-令牌协调（无死锁 + 可抢占）
class DualArmContract:
    def coordinate(self, G, G_q, iota, x):
        roles = self.assign_roles(G, iota)              # anchor / prober
        W = self.wait_for_graph(roles)
        if self.has_cycle(W) or not self.well_founded(roles):
            return self.single_arm(iota)                # CDL L2
        if not self.in_joint_envelope(x):
            return self.single_arm(iota)
        if self.spectral_radius(self.K(x)) >= 1.0:
            roles = self.force_token_order(roles)       # 强耦合：串行化
        return self.hold_and_expose_or_probe(roles, x)

# IP-331 CCJ：共因感知联合证据
def joint_evidence(arms, indep_cert):
    if len(arms) == 1 or not indep_cert(arms):
        return single_witness(arms)                     # n_eff = 1
    u_common = max(a.u_common for a in arms)            # 共因不缩窄
    u_idio   = fuse_idio([a.u_idio for a in arms])      # 只融合特异分量
    return Evidence(u=combine(u_common, u_idio), n_eff=len(arms))

# IP-332 SCC：场景条件校准
class SceneConformal:
    def threshold(self, G, cal):
        s = sig(G)
        if len(cal.get(s, [])) < N_MIN:
            s = GLOBAL                                  # 低样本优雅回退
        return conformal_quantile(cal[s], alpha=ALPHA)

# IP-333 JRC：联合修复证书
def record_joint_cert(G_cert, edits, trace, certs, joint, receipts):
    rollback = [inverse(e) for e in edits if e.rev in ("R0", "R1")]
    witness  = [w for w in receipts if indep_cert(w.arm, trace.actor_arm)]
    return JointRepairCert(G_cert, edits, trace, certs, joint, receipts, rollback, witness)

# IP-334 SDG-8C 闭环
def scenegauge_8c(M, s, ell):
    G, G_q = M.sgg.ground(M.scene, M.receipts(s), M.prior)
    out  = M.nlib.ground(ell, M.scene, G)               # 场景条件化指令接地
    iota = out[0] if out else M.default_iota
    H    = M.lbox.hypothesize(s, M.dbox.R[s], iota, G_q)
    edits   = M.cvs.propose_edits(G, H, iota)
    VC      = M.cvs.certify(G, M.q_joint, edits)
    C       = M.iac.plan_scene_chunk(iota, H, G, VC, M.tools, M.budget_left(s))
    if not M.dac.coordinate_feasible(C, G, M.q_joint):
        C = M.iac.per_step(iota, H, M.tools)            # CDL L2：单臂逐步
    cert     = M.cvc.commit(C, M.env, iota)
    receipts = cert.receipts
    ev       = M.ccj.joint_evidence(receipts, M.ccj.indep_cert)
    mu, Sig  = M.apcal.calibrate(ev, H, s)
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
        return stub_and_red(s, "cross_failed")
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s)
    if not contract_regression(new_ec):
        return stub_and_red(s, "regression")
    M.mreg.hot_replace_at_quiescence(M.dpe, new_ec, cert.boundary)
    M.jrc.record(G, edits, M.dac.trace, cert, ev.joint_cert, receipts)
    M.scb.bind_scene_claims(G, receipts)
    M.pquar.record(M.apcal.last_gain, realized_gain(receipts))
    return True

def SceneDualGauge_round(M, obs, audio, tac, depth, det, ell=None):

            M.inflight.add(s)

## 4. 推导

**引理 59（场景先验的子集选择与幻觉隔离）** 在场景接地公理（actionable 必须有独立回执）与定义 451 的编辑屏障下：若 `Plan(𝓖_cert)` 可执行，则 `Plan(𝓖_cert) ⊆ Plan_InstructGauge`；任何未接地节点/边都不能单独生成物理动作或语言主张。
*证明骨架*：对计划形成做结构归纳。基础：`𝓖_cert` 只提供目标/约束/排序，过滤不增集；场景编辑是受 `pre` 守卫的动作，`R2` 进入 JIB 后强制 `K=1` 且需独立见证，不扩张可行域。归纳：复合计划由子计划组合，子集关系在并/交下保持；`𝓖_?` 不进入动作生成，故越权路径为 ⊥。

**引理 60（反事实可见性的保守完备）** 若 `Occ⁺` 是真实遮挡集的过近似（`Occ ⊆ Occ⁺`），且每次编辑后重新计算 `VC`，则任何被执行的探测都不会落在真实遮挡面上；漏看的可见面积不超过 `ε_vis`。
*证明*：探测只允许指向 `SafeVis = S \ Occ⁺ ⊆ S \ Occ`，后者由 `Occ ⊆ Occ⁺` 得证。编辑后 `VC` 重算保证过近似在新场景下继续成立；`ε_vis` 是 `Vis⁺` 中可能实际被遮挡的面积上界，即保守性代价。

**引理 61（协调无死锁与弱耦合压缩）** (i) 若等待图 `W` 无环且良基秩在每次角色切换严格下降，则角色-令牌协议无死锁/无活锁；(ii) 若 `ρ(K) < 1`，联合最佳响应映射是压缩映射，存在唯一不动点，并行协商收敛；(iii) 若 `ρ(K) ≥ 1`，令牌串行化把双向耦合拆成单向序列，序列的每步仍是单臂可回退的。
*证明*：(i) 无环等待图 + 严格下降的良基秩排除无限等待与循环等待；(ii) Banach 不动点定理；(iii) 串行化后任一时刻只有一个臂改变联合状态，另一臂冻结，故联合映射退化为单臂映射的复合。

**引理 62（共因证据的覆盖率地板）** 在定义 456 的模型下，`n` 个证据源的联合后验方差下界为 `σ_s²σ_c²/(σ_s²+σ_c²)`，与 `n` 无关；若未通过 `Indep` 而按独立证据融合，声称的覆盖率会随 `n` 增大而**虚高**，实际覆盖低于名义值。
*证明*：方差分解 `Var(s|y) = [1/σ_s² + 1/(σ_c²+σ_e²/n)]^{-1}`，令 `n→∞` 得平台；误设 `ζ=0` 时方差趋于 0，但真实误差仍含 `ζ`，故置信区间过窄、覆盖下降。`n_eff = n/(1+(n−1)κ)` 给出等价的诚实样本数；`Indep` 缺失 ⇒ `n_eff=1`。

**引理 63（hold-and-expose 的收益条件）** 设被遮挡表面 `S_h` 的假设熵为 `H(S_h)`，编辑 `e` 的失败概率 `p_f`、不可逆代价 `c_irr`。则 hold-and-expose 严格优于单臂视角探测当且仅当
`ΔH_scene(HE) > λ_r·p_f·c_irr + λ_c·c(HE)`。
特别地，若 `e ∈ R2` 且无独立见证，则 `R_edit = ∞`，条件永不成立，必须退回纯视角探测。
*证明*：净收益定义直接展开；R2 无独立见证时 JIB 拒绝执行，等价于把风险设为不可接受。可证伪点：若在 `S_h` 高熵且 `p_f` 低的场景中，单臂视角探测的增益反而更高，则收益模型被推翻（E461）。

**引理 64（场景条件共形覆盖）** 层内可交换下 `P(h* ∈ H_s | s) ≥ 1−α`；场景编辑造成层内分布漂移时，边缘覆盖按 `Σ_s π_s·TV_s` 优雅降级；低样本层回退全局后覆盖下界为 `1−α−2η_global`。
*证明*：标准分层共形 + 全变差分解；漂移项由 `TV_s` 控制，回退项由全局校准误差 `η_global` 控制。与 InstructGauge 引理 55 同构，但分层变量换成 `sig(𝓖)` 并增加编辑后的重加权项。

**引理 65（联合修复证书的归因完备）** 若每个执行的场景编辑与探测都经过 JRC 记录、每条场景主张经 SCB 绑定、每个 `R2` 动作经 JIB 独立见证，则 JRC 的证据链可复现该次修复；未绑定主张不进入动作路径，故不存在「无场景依据的物理动作」。
*证明*：对动作序列归纳，每个动作由 `(场景主张, 角色, 回执)` 三元组唯一索引；JIB 保证不可逆动作有独立见证；SCB 的剥离是纯投影，不改变数值路径（继承引理 57）。

**引理 66（复杂度与 50Hz 保全）** 场景图增量更新 `O(log|V| + deg)`（空间索引）；保守可见性 `O(|V| log|V|)`；反事实编辑规划 `O(|E|·h)`（`h` 为编辑深度上界）；协调检查 `O(|W|)`；共因融合 `O(n²)`（`n` 为臂数，实际为 2）。以上全部异步下沉，主循环新增周期 `< 0.2ms`，继承 InstructGauge 引理 58 与 ToolGauge 引理 50 的硬实时结论。
*证明*：各子过程复杂度直接由数据结构与算法给出；50Hz 路径只保留 `detect_blind_spot` 与状态发布，重计算在异步任务中完成；热替换仍受 `q_quiesce` 约束。

## 8. 本轮最大风险

**一句话**：场景理解与双臂协调共享同一个学习先验与物理世界，因此「两臂都同意、场景图也支持」很可能只是**同一个错误的三种说法**；一旦据此执行不可逆的场景编辑，系统会亲手破坏用于判断对错的先验，真正的残余风险是「共同幻觉经联合行动写成物理事实」——缓解只能依赖结构（场景接地使幻觉不行动、保守可见性使错误编辑前被预测、共因证书使一致不被误当独立、JIB 使不可逆编辑强制单步 + 独立见证），并以 E457/E460/E462/E466/E472 主动证伪。
