# 第 56 轮（承接第 55 轮 v32 GroundEdge-GenSim++++；灵感循环第 1 轮；本轮灵感：「状态隔离」×「人机协作」）

> 第 55 轮把解释推进为可执行反事实，并用双忠实证书 X 把“对人可读”与“物理真实”分离。但第 55 轮隐含一个脆弱前提：机器人有一个稳定、可回放、可干预的状态基座。真实人机协作里，这个前提最先被打破——人会在执行中改任务、碰工作区、注入指令，机器人的状态随时被外部写污染；而反事实解释又要求在同一状态快照上重放。本轮把「状态隔离」提升为一等公民：在人机之间建立**可验证的隔离边界 + 受控状态交换**，并把协作定义为隔离之下的**可串行事务**，而不是状态混同。核心矛盾：H24：强隔离保证状态不被污染、反事实可精确重放，却切断协作所需的共地，导致人机“各说各话”；H25：弱隔离换来协调流畅，却让人的错误信念直接写进机器人安全状态，并使反事实解释在重放时失去可复现性。

## 0. 直觉与动机

**灵感 1（状态隔离 = 进程隔离的具身版本）**
直觉：操作系统不会让一个不可信进程直接写另一个进程的内存，而是通过系统调用、权限和地址空间隔离。人机协作也应如此：人的意图/指令是**不可信外部输入**，只能通过受验证的命令通道“提案”，由机器人按隔离契约“提交”。机器人安全关键状态 `S_R^safe` 对人是**不可写**、甚至**不可见**的。这样，人的一个错误信念或误操作不能直接覆盖机器人状态。

**灵感 2（隔离是反事实解释可复现的基础设施）**
直觉：第 55 轮要求解释在真实机器人上 `repro` 复现，但若状态会被人并发修改，同一条反事实轨迹重放时环境已经变了。把状态**版本化 + 快照 + 溯源**后，反事实 `E` 绑定到快照 `Σ`，`replay(π|Σ)` 才是确定性的。于是**状态隔离不是可解释性的对手，而是它成立的前提**。

**灵感 3（协作不是合并状态，而是受控交换 + 共地）**
直觉：强隔离会让人和机器人无法协调。解决不是拆墙，而是在墙上开**受控的门**：定义共享工作区 `S_W` 作为唯一可并发写的区域，用 CRDT 式合并保证收敛；共地 `CG ⊆ S_W` 是双方已确认一致的子集。私有状态 `S_R, S_H` 保持隔离，只通过**承诺读出**交换。协调质量用共地覆盖率衡量，而非“状态处处一致”。

**灵感 4（分歧是显式的一等信号）**
直觉：隔离让分歧可观测：机器人对“人以为机器人知道什么”的估计、人对机器人的估计，二者与真实状态的差就是**共地分歧 D**。D 超阈值时，系统不是继续执行，而是触发澄清/解释/降自动化。这把“人和机器人想岔了”从事故后归因变成在线可测信号，接上第 55 轮的 CEG/TCC。

**灵感 5（协作事务：隔离之下的可串行性）**
直觉：人和机器人可能同时行动。私有状态互不冲突，但共享工作区上的联合动作可能交错出危险序列。把联合动作建模为**事务**：要么可交换（作用在不相交状态），要么必须按某个全序提交，否则回滚机器人一侧。隔离 + 可串行性 = 协作安全，而不是靠“人应该配合”。

**灵感 6（隔离-协调 Pareto 与隐私）**
直觉：隔离度越高，越安全、越可复现、越保护人的隐私（机器人不该泄露人的私有状态），但共地越难建立。因此存在**隔离-协调 Pareto 前沿**，按风险选工作点：安全关键场景偏隔离，教学/装配场景偏协调。证书同时记录隔离度与共地覆盖率，把“该隔多开”变成可仲裁的工程参数。

## 1. 形式化定义（增量：定义 127–133）

**定义 127（状态划分与隔离边界）**
联合状态 `S = S_R ⊎ S_H ⊎ S_W`（机器人私有、人类私有、共享工作区，互不相交）。访问控制矩阵 `M_iso`，元素
```
M_iso[i→j] ∈ {none, read, read_c, write, transactional}
```
隔离边界 `∂_iso = { (i,j) | M_iso[i→j] = none }`。**硬约束**：`M_iso[H→S_R^safe] = none`，即人的任何输入不得直接写给机器人安全关键状态；`M_iso[H→S_R] = transactional`，即只能走“提案—验证—提交”。

**定义 128（隔离剖面与隔离度）**
对每个状态变量 `σ`，隔离剖面 `ι(σ) ∈ [0,1]`，由跨主体互信息、跨主体写次数与直接写通道决定：
```
ι(σ) = 1 - λ_1·I(σ; external) - λ_2·n_write(σ) - λ_3·1[σ ∈ S_R^safe ∧ M_iso[H→σ] ≠ none]
```
整体隔离度 `Iso(S) = min_{σ∈S} ι(σ)`（最弱环节决定整体）。`Iso(S) ≥ ι_min` 是部署必要条件。

**定义 129（版本化快照与溯源）**
每个状态有单调版本 `ver(σ)`；快照 `Σ_t = { (σ, ver(σ), value(σ)) }`。溯源
```
prov(σ) = ⟨(agent_k, action_k, t_k, ver_k)⟩_{k=1..n}
```
记录每次写的来源。算子 `snap() : S → Σ`、`rollback(Σ)`、`replay(π | Σ)`。**反事实隔离条件**：`E` 只能在产生失败的同版本快照上重放：
```
repro_R(E) 有效 ⇔ replay(E.π' | Σ_fail) 且 Σ_fail 未被跨版本写污染。
```

**定义 130（人机状态交换契约 HSC）**
`C_HR = (S_R, S_H, S_W, M_iso, merge, CG, Δ_cg)`：
- `merge : S_W × S_W → S_W` 要求**交换、结合、幂等**（CRDT）：`merge(a,b)=merge(b,a)`、`merge(merge(a,b),c)=merge(a,merge(b,c))`、`merge(a,a)=a`；
- 共地 `CG ⊆ S_W` 为双方已确认一致的子集，`agree = |CG| / |S_W|`；
- `Δ_cg` 为允许的共地缺口。私有状态只能通过**承诺读出** `read_c(S_i) → commitment` 交换，原始值不越界。

**定义 131（共地分歧 D 与澄清触发）**
```
D = d_H( S_H^{R̂}, S_H ) + d_R( S_R^{Ĥ}, S_R )
```
其中 `S_H^{R̂}` 是机器人对“人以为机器人知道的人的状态”的估计，`S_R^{Ĥ}` 是人以为的机器人状态。可观测代理：共享区写冲突、意图预测误差、动作前置条件失败率。若 `D > θ_div` 或 `agree < 1-Δ_cg`，触发澄清/解释/降自动化（接 IP-124 TCC、IP-121 CEG）。

**定义 132（可串行协作事务 SCT）**
联合动作 `τ = (a_R, a_H, Σ_before, Σ_after)`。若 `a_R, a_H` 作用在不相交状态且可交换，则并发安全；否则要求存在提交全序 `≺` 使双方前置条件在该序下全部满足。否则事务**中止并回滚机器人一侧**（不回滚人）。安全不变式：任何交错都不违反 `M_iso` 与安全谓词 `Safe(Σ)`。

**定义 133（状态隔离协作证书 SIC）**
```
S = (X, M_iso, Iso, prov, D, agree, serial_order, evidence)
```
`X` 为第 55 轮双忠实证书。可部署条件：
```
X.ok ∧ Iso(S) ≥ ι_min ∧ D ≤ θ_div ∧ agree ≥ 1-Δ_cg ∧ Serializable(τ, serial_order) ∧ Safe(Σ_after)
```

## 2. 关键算法 伪代码

### IP-127 SIB（State Isolation Boundary）

```python
def build_isolation_boundary(state_vars, safe_set):
    S_R, S_H, S_W = partition(state_vars)
    M = AccessMatrix()
    for s in S_R:
        M['H', s] = 'transactional'
        M['R', s] = 'write'
    for s in S_R & safe_set:
        M['H', s] = 'none'            # 安全关键状态绝对隔离
    for s in S_W:
        M['H', s] = M['R', s] = 'write'   # 仅共享区可并发写
    for s in S_H:
        M['R', s] = 'read_c'          # 只读承诺，保护人的隐私
        M['H', s] = 'write'
    return IsolationBoundary(S_R, S_H, S_W, M)

def admit(agent, s, op, M):
    perm = M[agent, s]
    if perm == 'none':          return 'deny'
    if perm == 'read':          return 'deny' if op == 'write' else 'ok'
    if perm == 'read_c':        return 'commitment' if op == 'read' else 'deny'
    if perm == 'transactional': return 'propose'    # 必须 propose-validate-commit
    return 'ok'
```

### IP-128 SIV（State Isolation Verification）

```python
def isolation_profile(trace, S, L1, L2, L3):
    iota = {}
    for s in S:
        I_ext = mutual_information(s, external_events(trace))
        n_w   = cross_write_count(trace, s)
        viol  = 1 if (s in SAFE and M['H', s] != 'none') else 0
        iota[s] = 1 - L1*I_ext - L2*n_w - L3*viol
    return min(iota.values()), iota

def verify_isolation(trace, M, iota_min):
    for s in SAFE:
        if M['H', s] != 'none' and any_write(trace, 'H', s):
            return ('reject', 'safe_state_writable', s)
    if any_write_outside_permission(trace, M):
        return ('reject', 'isolation_violation')
    iso, _ = isolation_profile(trace, ALL_STATE, L1, L2, L3)
    return ('ok', iso) if iso >= iota_min else ('reject', 'insufficient_isolation', iso)
```

### IP-129 SVC（State Version Checkpoint）

```python
def snapshot(state):
    return Snapshot({s: VersionedValue(state.ver[s], state.val[s]) for s in state})

def rollback(state, snap):
    for s, vv in snap.items():
        state.val[s] = vv.val
        state.ver[s] = vv.ver + 1          # 回滚也是新写，保留溯源

def replay_counterfactual(policy, pi_cf, snap_fail, prov_log):
    if prov_changed_since(prov_log, snap_fail):
        return ('reject', 'snapshot_contaminated')     # 跨版本污染
    state = restore(snap_fail)
    with isolation_lock(state):                        # 重放期间冻结外部写
        return ('ok', rollout(policy, pi_cf, state))
```

### IP-130 HSC（Human-Robot State Contract）

```python
def merge_workspace(a, b):
    out = {}
    for k in a.keys() | b.keys():
        out[k] = max(a.get(k), b.get(k),
                     key=lambda x: (x.lamport, x.agent_id))
    return out       # 交换/结合/幂等 → CRDT 收敛

def state_exchange_contract(s_r, s_h, M):
    if M['H', 'S_R_safe'] != 'none':
        return ('reject', 'safe_state_exposed')
    s_w = merge_workspace(s_r.workspace, s_h.workspace)
    cg = {k for k in s_w if s_r.acked(k) and s_h.acked(k)}
    return ('ok', s_w, cg)
```

### IP-131 DDM（Divergence Detection Monitor）

```python
def divergence(robot_belief_h, human_belief_r, S_H, S_R):
    return dist(robot_belief_h, S_H) + dist(human_belief_r, S_R)

def monitor_and_route(D, agree, theta_div, delta_cg, risk):
    if D <= theta_div and agree >= 1 - delta_cg:
        return ('continue', None)
    if over_trust(risk, D):              # 接 IP-124 TCC
        return ('deautomate', 'over_trust_risk')
    return ('clarify', make_query(D))    # 接 IP-121 CEG 生成澄清
```

### IP-132 SCT（Serializable Collaboration Transaction）

```python
def serialize_joint(a_r, a_h, state):
    if disjoint(a_r.domain, a_h.domain) and a_r.commutes(a_h):
        return ('concurrent', None)
    for order in [('R', 'H'), ('H', 'R')]:
        sim = state.clone()
        if apply_in_order(sim, a_r, a_h, order) and Safe(sim) and respects_isolation(sim):
            return ('serial', order)
    return ('abort', 'conflict')         # 冲突：中止并回滚机器人侧

def commit_with_rollback(a_r, a_h, state, snap):
    status, order = serialize_joint(a_r, a_h, state)
    if status == 'abort':
        rollback(state, snap)            # 只回滚机器人侧，人的动作保留
        return ('aborted', state)
    return ('committed', order, state)
```

### IP-133 SIC（State-Isolated Collaboration Certificate）

```python
def state_isolated_certificate(X, M, iso, D, agree, a_r, a_h, state):
    if not X.ok:                       return ('reject', 'explanation_cert_fail')
    if iso < IOTA_MIN:                 return ('reject', 'insufficient_isolation', iso)
    if D > THETA_DIV or agree < 1 - DELTA_CG:
        return ('reject', 'common_ground_fail', D, agree)
    status, order = serialize_joint(a_r, a_h, state)
    if status == 'abort':              return ('reject', 'transaction_conflict')
    if not Safe(state.after):          return ('reject', 'safety_violation')
    return ('ok', SIC(X, M, iso, D, agree, order,
                      evidence=[prov_log(state), cg_log(state), replay_log(X)]))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SIB | O(\|S\|·\|agents\|) | O(\|S\|) | 安全状态不可写、权限全序 |
| SIV | O(\|S\|·\|trace\|) | O(\|S\|) | 互信息估计无偏、违规可判定 |
| SVC | O(\|S\|) 快照 / O(\|π\|) 重放 | O(\|S\|) | 版本单调、跨版本污染检测 |
| HSC | O(\|S_W\| log\|S_W\|) | O(\|S_W\|) | merge 交换/结合/幂等 |
| DDM | O(\|S\|·\|trace\|) | O(\|S\|) | 分歧代理与真实误解相关 |
| SCT | O(2·\|S\|) | O(\|S\|) | 全序覆盖、回滚只及机器人侧 |
| SIC | O(\|S\|·\|trace\| + \|π\|) | O(\|S\|+\|π\|) | 各门控 sound、证据完整 |

**正确性定理（State-Isolated Collaboration Soundness）**
承接第 55 轮 (A22)–(A32)；新增 **(A33)** 隔离边界 `M_iso` 被强制，`S_R^safe` 不可被人直写；**(A34)** 共享区 `merge` 为 CRDT，并发写必收敛；**(A35)** 反事实重放绑定同版本快照且无跨版本污染；**(A36)** 事务冲突时回滚机器人侧且 `Safe(Σ)` 保持。
若 SIC 被接受，则
```
P(success ∧ safe) ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - (1-φ) - g_s2r - β_state
β_state            ≤ P(D>θ_div | accept) + P(no serial order | accept)
P(state_contamination) = 0                       （由 A33 在模型内强制）
P(unsafe interleaving) ≤ P(abort)·P(rollback_fail)   （由 A34/A36 界定）
```
**推导要点**：A33 把“人的错误信念污染机器人安全状态”这一项从概率界中直接消为零，这是隔离相对弱耦合的根本收益；A34/A36 把并发写与交错风险转化为“回滚失败”这一可测的工程量，而非不可控的语义灾难；A35 使第 55 轮的 `repro` 从“概率近似”变为“同快照确定性重放”，故 `(1-φ)` 项不再额外叠加环境漂移。代价集中在 `β_state`：隔离越强，共地越难建立，`D` 与不可串行概率上升——这正是隔离-协调 Pareto 的来源。

## 4. 实验设计 E167–E172

| 实验 | 指标 | 目标 |
|---|---|---|
| E167 隔离边界强制 | 安全状态被外写次数、越权写拒绝率 | 被写 = 0，拒绝率 = 100% |
| E168 反事实可复现性 | 重放确定性、`repro` 提升 | 确定性 = 1，repro ↑ ≥ 10% |
| E169 共地收敛 | 并发写后 `agree`、收敛步数 | agree ≥ 0.95，收敛 ≤ 3 步 |
| E170 分歧检测 | `D` 与真实误解的 AUC、误触发率 | AUC ≥ 0.90，误触发 ≤ 5% |
| E171 协作事务安全 | 危险交错数、冲突回滚率 | 危险交错 = 0，回滚 ≤ 8% |
| E172 隔离-协调 Pareto | 成功率 vs `Iso` vs `agree` 前沿 | 高风险点 `Iso ≥ 0.8` 且成功率降幅 ≤ 3% |

**判别性对照**：与“完全共享状态（无隔离）”“硬隔离无共享区（人机各干）”“仅 CRDT 无事务”三组对比；核心消融是**去掉 SCT 可串行性检查**，预期并发交错导致的共享区语义破坏显著上升，而单看 `agree` 仍然很高——这正说明“收敛”不等于“正确”。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 隔离过度导致协作僵硬、共地不足 | 高 | 分层隔离 + 共享区扩张 + Pareto 工作点 |
| CRDT 无法表达顺序敏感任务 | 高 | 顺序敏感区禁并发，改用 OT/事务；显式顺序谓词 |
| 分歧 `D` 不可观测或估计有偏 | 高 | 多模态代理信号 + 主动探查 + 在线校准 |
| 快照/回滚开销影响实时性 | 中 | 增量快照 + 写时复制 + 异步持久化 |
| 人的私有状态被泄露（隐私） | 中 | 承诺读取 + 最小披露 + 差分隐私预算 |
| 事务冲突频繁回滚影响流畅 | 中 | 意图提前对齐 + 预测性排序 + 回滚代价建模 |

## 6. 本轮最大风险

**一句话**：状态隔离方案的最大风险在于**把协作安全押在“隔离边界与事务语义正确”之上**——一旦共享区的 CRDT 合并语义无法表达任务固有的顺序约束（例如“先拧紧再抬起”），系统会在一个“看似收敛、分歧很低”的共地上执行出顺序错误的动作，而强隔离恰恰压低了人类的可观测性，使危险从“明面冲突”退化为“沉默地收敛到错误状态”；因此必须以**顺序敏感区禁用并发 + 事务可串行性硬门控 + 分歧下限（防止隔离过度）**为不可协商的护栏。

# 第 56 轮产物 · 创新点清单 v33：GroundEdge-GenSim+++++（SIB×SIV×SVC×HSC×DDM×SCT×SIC）

> 承接第 55 轮产物 v32。本轮在“动作-鲁棒性-具身解释”之上增加 **状态隔离与人机协作** 七个算子，把“解释”与“协作”都建立在**可验证的隔离边界 + 版本化状态 + 可串行事务**之上：
> - **SIB（State Isolation Boundary）**：状态三分与访问控制矩阵，安全状态严禁人直写；
> - **SIV（State Isolation Verification）**：隔离剖面 `ι(σ)` 与隔离度 `Iso(S)` 的在线校验；
> - **SVC（State Version Checkpoint）**：版本化快照/回滚/重放，为反事实解释提供确定性基座；
> - **HSC（Human-Robot State Contract）**：共享区 CRDT 合并 + 共地 `CG` + 承诺读取；
> - **DDM（Divergence Detection Monitor）**：共地分歧 `D` 的在线检测与澄清/降级路由；
> - **SCT（Serializable Collaboration Transaction）**：联合动作可串行化与“只回滚机器人侧”；
> - **SIC（State-Isolated Collaboration Certificate）**：在双忠实证书 `X` 上叠加隔离、共地、事务三重门控。
>
> IP 编号：IP-127~IP-133（共 7 个新增），升级第 55 轮 IP-122/124/126 与第 54 轮 IP-117 的联合证书。

## 2. 关键算法 伪代码

### IP-127 SIB

```python
def build_isolation_boundary(state_vars, safe_set):
    S_R, S_H, S_W = partition(state_vars)
    M = AccessMatrix()
    for s in S_R:
        M['H', s] = 'transactional'
        M['R', s] = 'write'
    for s in S_R & safe_set:
        M['H', s] = 'none'                # 安全关键状态绝对隔离
    for s in S_W:
        M['H', s] = M['R', s] = 'write'   # 仅共享区可并发写
    for s in S_H:
        M['R', s] = 'read_c'              # 承诺读取，保护隐私
        M['H', s] = 'write'
    return IsolationBoundary(S_R, S_H, S_W, M)

def admit(agent, s, op, M):
    perm = M[agent, s]
    if perm == 'none':          return 'deny'
    if perm == 'read':          return 'deny' if op == 'write' else 'ok'
    if perm == 'read_c':        return 'commitment' if op == 'read' else 'deny'
    if perm == 'transactional': return 'propose'
    return 'ok'
```

### IP-128 SIV

```python
def isolation_profile(trace, S, L1, L2, L3):
    iota = {}
    for s in S:
        I_ext = mutual_information(s, external_events(trace))
        n_w   = cross_write_count(trace, s)
        viol  = 1 if (s in SAFE and M['H', s] != 'none') else 0
        iota[s] = 1 - L1*I_ext - L2*n_w - L3*viol
    return min(iota.values()), iota

def verify_isolation(trace, M, iota_min):
    for s in SAFE:
        if M['H', s] != 'none' and any_write(trace, 'H', s):
            return ('reject', 'safe_state_writable', s)
    if any_write_outside_permission(trace, M):
        return ('reject', 'isolation_violation')
    iso, _ = isolation_profile(trace, ALL_STATE, L1, L2, L3)
    return ('ok', iso) if iso >= iota_min else ('reject', 'insufficient_isolation', iso)
```

### IP-129 SVC

```python
def snapshot(state):
    return Snapshot({s: VersionedValue(state.ver[s], state.val[s]) for s in state})

def rollback(state, snap):
    for s, vv in snap.items():
        state.val[s] = vv.val
        state.ver[s] = vv.ver + 1          # 回滚也是新写，保留溯源

def replay_counterfactual(policy, pi_cf, snap_fail, prov_log):
    if prov_changed_since(prov_log, snap_fail):
        return ('reject', 'snapshot_contaminated')     # 跨版本污染
    state = restore(snap_fail)
    with isolation_lock(state):                        # 重放期间冻结外部写
        return ('ok', rollout(policy, pi_cf, state))
```

### IP-130 HSC

```python
def merge_workspace(a, b):
    out = {}
    for k in a.keys() | b.keys():
        out[k] = max(a.get(k), b.get(k),
                     key=lambda x: (x.lamport, x.agent_id))
    return out       # 交换/结合/幂等 → CRDT 收敛

def state_exchange_contract(s_r, s_h, M):
    if M['H', 'S_R_safe'] != 'none':
        return ('reject', 'safe_state_exposed')
    s_w = merge_workspace(s_r.workspace, s_h.workspace)
    cg = {k for k in s_w if s_r.acked(k) and s_h.acked(k)}
    return ('ok', s_w, cg)
```

def divergence(robot_belief_h, human_belief_r, S_H, S_R):
    return dist(robot_belief_h, S_H) + dist(human_belief_r, S_R)

def monitor_and_route(D, agree, theta_div, delta_cg, risk):

### IP-132 SCT

```python
def serialize_joint(a_r, a_h, state):
    if disjoint(a_r.domain, a_h.domain) and a_r.commutes(a_h):
        return ('concurrent', None)
    for order in [('R', 'H'), ('H', 'R')]:
        sim = state.clone()
        if apply_in_order(sim, a_r, a_h, order) and Safe(sim) and respects_isolation(sim):
            return ('serial', order)
    return ('abort', 'conflict')

def commit_with_rollback(a_r, a_h, state, snap):
    status, order = serialize_joint(a_r, a_h, state)
    if status == 'abort':
        rollback(state, snap)            # 只回滚机器人侧，人动作保留
        return ('aborted', state)
    return ('committed', order, state)
```

### IP-133 SIC

```python
def state_isolated_certificate(X, M, iso, D, agree, a_r, a_h, state):
    if not X.ok:                       return ('reject', 'explanation_cert_fail')
    if iso < IOTA_MIN:                 return ('reject', 'insufficient_isolation', iso)
    if D > THETA_DIV or agree < 1 - DELTA_CG:
        return ('reject', 'common_ground_fail', D, agree)
    status, order = serialize_joint(a_r, a_h, state)
    if status == 'abort':              return ('reject', 'transaction_conflict')
    if not Safe(state.after):          return ('reject', 'safety_violation')
    return ('ok', SIC(X, M, iso, D, agree, order,
                      evidence=[prov_log(state), cg_log(state), replay_log(X)]))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SIB | O(\|S\|·\|agents\|) | O(\|S\|) | 安全状态不可写、权限全序 |
| SIV | O(\|S\|·\|trace\|) | O(\|S\|) | 互信息估计无偏、违规可判定 |
| SVC | O(\|S\|) 快照 / O(\|π\|) 重放 | O(\|S\|) | 版本单调、跨版本污染检测 |
| HSC | O(\|S_W\| log\|S_W\|) | O(\|S_W\|) | merge 交换/结合/幂等 |
| DDM | O(\|S\|·\|trace\|) | O(\|S\|) | 分歧代理与真实误解相关 |
| SCT | O(2·\|S\|) | O(\|S\|) | 全序覆盖、回滚只及机器人侧 |
| SIC | O(\|S\|·\|trace\|+\|π\|) | O(\|S\|+\|π\|) | 各门控 sound、证据完整 |

**正确性定理（State-Isolated Collaboration Soundness）**
承接 (A22)–(A32)；新增 **(A33)** 隔离边界 `M_iso` 被强制，`S_R^safe` 不可被人直写；**(A34)** 共享区 `merge` 为 CRDT，并发写必收敛；**(A35)** 反事实重放绑定同版本快照且无跨版本污染；**(A36)** 事务冲突时回滚机器人侧且 `Safe(Σ)` 保持。
若 SIC 被接受，则
```
P(success ∧ safe) ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - (1-φ) - g_s2r - β_state
β_state            ≤ P(D>θ_div | accept) + P(no serial order | accept)
P(state_contamination) = 0                            （A33，模型内强制）
P(unsafe interleaving) ≤ P(abort)·P(rollback_fail)    （A34/A36）
```
**推导要点**：
1. A33 把“人的错误信念污染机器人安全状态”从概率界中直接消为零——这是隔离相对弱耦合的根本收益，不是精度提升，而是**结构性质变**。
2. A34/A36 把并发写与交错风险转化为“回滚失败”这一可测工程量，而非不可控的语义灾难。
3. A35 使第 55 轮 `repro` 从“概率近似”变为“同快照确定性重放”，故 `(1-φ)` 不再额外叠加环境漂移。
4. 代价集中在 `β_state`：隔离越强，共地越难建立，`D` 与不可串行概率上升——这正是**隔离-协调 Pareto** 的形式来源。

| 实验 | 关键指标 | 验收 |

| E170 分歧检测 | `D` 与真实误解 AUC、误触发率 | AUC ≥ 0.90，误触发 ≤ 5% |
| E171 协作事务安全 | 危险交错数、冲突回滚率 | 危险交错 = 0，回滚 ≤ 8% |
| E172 隔离-协调 Pareto | 成功率 vs `Iso` vs `agree` | 高风险 `Iso ≥ 0.8` 且成功率降幅 ≤ 3% |

**核心消融**：
- 去掉 SCT 可串行性检查：预期 `agree` 仍高、但共享区语义破坏率显著上升，证明“收敛 ≠ 正确”；
- 去掉 SIV：预期安全状态被外写的事件出现，且反事实重放确定性下降；
- 完全共享状态（无隔离）：预期状态污染导致部署失败率上升，作为隔离收益的判别性证据。

## 6. 本轮最大风险

**一句话**：状态隔离方案的最大风险在于**把协作安全押在“隔离边界与事务语义正确”之上**——一旦共享区的 CRDT 合并语义无法表达任务固有的顺序约束（例如“先拧紧再抬起”），系统会在一个“看似收敛、分歧很低”的共地上执行出顺序错误的动作，而强隔离恰恰压低了人类的可观测性，使危险从“明面冲突”退化为“沉默地收敛到错误状态”；因此必须以**顺序敏感区禁用并发 + 事务可串行性硬门控 + 分歧下限（防止隔离过度）**为不可协商的护栏。
