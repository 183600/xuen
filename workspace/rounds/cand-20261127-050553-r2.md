### 第 2 轮灵感驱动研究记录

**灵感词**：激光雷达、创新点

**直觉与动机**：
第 1 轮把结构-力学维度纳入证书链（SOC/FCC/LSC/USMC），却暴露了一个根本性的认识论缺陷：SOC 的应力/能量、FCC 的无源性、LSC 的均质化边界，全部来自与机器人本体同源的模型（FEM、阻抗模型、均质化查表）。**用模型验证模型不是证据，而是循环论证**——当 FEM 假设、传感器标定或数值积分同时失效时，三张证书会一起「通过」，正如第 1 轮最大风险所述。受「激光雷达」启发：LiDAR 是一路与 FEM/力控**物理独立**的几何观测通道，点云可直接测量本体形变、接触位形与结构拓扑，构成「几何见证」。受「创新点」启发：真正稀缺的不是再多一张证书，而是**证据的独立性与新颖性本身**——一个创新点若只是既有模型的重参数化，就不构成新证据。核心洞见：**安全准入的可信度不取决于证书数量，而取决于证据通道之间的失效独立性；LiDAR 提供物理独立的几何见证，「创新点」则被形式化为可检验的证据独立性与新颖性证书。**

**形式化目标**：
1. 定义 LiDAR 几何见证证书（LGWC）：点云 P 对名义曲面 S(ρ) 的配准残差 δ_geo 在误差预算 U 下满足 δ_geo ≤ δ_allow，并对每个关键结构单元给出覆盖率与置信上界。
2. 定义 LiDAR 退化/完整性证书（LDIC）：有效点密度、FOV 覆盖、多回波/强度物理一致性、时序一致性，量化雨雾退化与注入式欺骗的可检性。
3. 定义证据独立性与新颖性证书（EINC）：见证集 S 的成对互信息 I(E_i;E_j) ≤ ε，失效事件近似独立；并用 conformal 新颖性 p 值检验方案/模块是否越出先验技术语料流形（创新半径 r(x) ≥ r_min）。
4. 定义跨模态证书三角定位门（CMTG）：HPC-E+ ∪ USMC ∪ LGWC ∪ LDIC ∪ EINC 五层一体，要求 ≥k 条独立见证一致，Exec_v25 ⊆ Exec_v24。
5. 证明：在至多 k-1 条通道被攻陷/退化时，CMTG 仍能检出单通道故障；并保持 v18→v25 的单调退化链。

**本轮创新点（显式声明）**：
- **把「证据独立性」提升为一等公民**：证书的价值 = 证据与待证命题之间的条件互信息，而非证书数量；引入可在线检验的成对失效独立性约束。
- **LiDAR 作为几何见证而非感知输入**：不改动感知-规划主链，仅在准入层用点云独立复核结构形变与接触位形，打破「模型自证」闭环。
- **新颖性可证化**：用 conformal p 值把「创新点」从主观叙事变成带有限样本保证的统计断言，并与 IPAM 专利保护链对接。

## 1. 关键算法骨架（在 IP-440–443 骨架上扩展）

```python
# ============================================================
# IP-444 LiDAR Geometric Witness Certificate (LGWC) — 几何见证证书
# ============================================================
@dataclass
class LiDARSample:
    p: Tensor        # [N,3] 世界系点
    n: Tensor        # [N,3] 法向
    I: Tensor        # [N]   强度
    t: Tensor        # [N]   时间戳
    sigma_r: Tensor  # [N]   量测噪声 std

@dataclass
class LiDARGeometricWitnessCertificate:
    P: LiDARSample
    T_world_sensor: Tensor          # [4,4]
    Sigma_T: Tensor                 # [6,6] 配准协方差
    S_nominal: 'SignedDistanceField'  # 由 SOC rho / CAD 构建
    critical_cells: Tensor          # 承载关键单元的索引
    delta_allow: float = 2e-3       # 允许形变 2mm
    cov_min: float = 0.90
    alpha: float = 1e-3             # 有限样本置信水平

    def residual(self):
        pw = transform(self.T_world_sensor, self.P.p)
        d = self.S_nominal.signed_distance(pw)
        return d, pw

    def error_budget(self, pw: Tensor) -> Tensor:
        # 一阶传播：配准不确定性随点距原点距离放大 + 量测噪声
        jac = torch.eye(3).repeat(pw.shape[0], 1, 1)          # 简化占位
        reg = (jac @ self.Sigma_T[:3, :3] @ jac.transpose(1, 2))
        reg_std = reg.diagonal(dim1=1, dim2=2).clamp_min(0).sqrt().sum(-1)
        reg_std = reg_std * pw.norm(dim=-1).clamp_min(1e-6)
        return reg_std + 2.0 * self.P.sigma_r

    def verify_deformation(self) -> bool:
        d, pw = self.residual()
        U = self.error_budget(pw)
        upper = d.abs() + U                     # 真实形变的保守上界
        mask = self._critical_mask(pw)          # 关键单元邻域内的点
        if mask.sum().item() < 10:
            return False                        # 证据不足即拒证（fail-closed）
        q = self._conformal_quantile(upper[mask], 1.0 - self.alpha)
        return bool(q <= self.delta_allow)

    def verify_coverage(self) -> bool:
        observed = self.S_nominal.observed_cells(self.P.p, self.T_world_sensor)
        return bool(observed[self.critical_cells].float().mean().item() >= self.cov_min)

    def verify_all(self) -> bool:
        return self.verify_deformation() and self.verify_coverage()

    @staticmethod
    def _conformal_quantile(x: Tensor, level: float) -> float:
        # 有限样本修正的分位数：ceil((n+1)*level)/n 顺序统计量
        n = x.numel()
        k = min(n, int(math.ceil((n + 1) * level)))
        return float(torch.sort(x).values[k - 1].item())

# IP-445 LiDAR Degradation & Integrity Certificate (LDIC)
# ============================================================
@dataclass
class LiDARIntegrityCertificate:
    N_eff: int
    rho_pts: float
    fov_cov: float
    multi_echo_ratio: float
    intensity_plausibility: float     # 与材料先验一致的强度占比
    temporal_consistency: float       # 扫描间一致性 [0,1]
    spoof_score: float                # [0,1]
    N_eff_min: float = 5e3
    rho_min: float = 1e3
    spoof_max: float = 0.10

    def verify_density(self) -> bool:
        return self.N_eff >= self.N_eff_min and self.rho_pts >= self.rho_min

    def verify_fov(self) -> bool:
        return self.fov_cov >= 0.80

    def verify_physics(self) -> bool:
        return (self.intensity_plausibility >= 0.95 and
                self.temporal_consistency >= 0.90 and
                self.multi_echo_ratio >= 0.20)

    def verify_spoof(self) -> bool:
        return self.spoof_score <= self.spoof_max

    def verify_all(self) -> bool:
        return (self.verify_density() and self.verify_fov() and
                self.verify_physics() and self.verify_spoof())


# ============================================================
# IP-446 Evidence Independence & Novelty Certificate (EINC)
# ============================================================
@dataclass
class EvidenceChannel:
    name: str
    fail_prob: float          # 先验/在线估计的失效概率
    features: Tensor          # [n, d] 该通道证据特征样本（用于估计相关性）

@dataclass
class EvidenceIndependenceNoveltyCertificate:
    channels: list[EvidenceChannel]
    prior_art: Tensor          # [M,d] 先验技术嵌入
    eps_mi: float = 0.05       # 允许的成对互信息
    k: int = 2                 # 最少独立见证数
    alpha_nov: float = 0.05    # 新颖性显著性
    r_min: float = 0.50        # 创新半径下界

    def pairwise_mi(self) -> Tensor:
        # 用高斯互信息近似：I(X;Y) = -0.5 ln det(I - Σx^{-1} Σxy Σy^{-1} Σyx)
        C = len(self.channels)
        MI = torch.zeros(C, C)
        for i in range(C):
            for j in range(i + 1, C):
                mi = _gaussian_mi(self.channels[i].features,
                                  self.channels[j].features)
                MI[i, j] = MI[j, i] = mi
        return MI

    def select_independent_witnesses(self) -> list[int]:
        # 贪心：优先低失效概率，且与已选通道 MI ≤ eps_mi
        MI = self.pairwise_mi()
        order = sorted(range(len(self.channels)),
                       key=lambda i: self.channels[i].fail_prob)
        S = []
        for i in order:
            if all(MI[i, j] <= self.eps_mi for j in S):
                S.append(i)
        return S

    def novelty_pvalue(self, x_embedding: Tensor) -> float:
        s_prior = torch.cdist(self.prior_art, self.prior_art).min(dim=1).values
        s_x = torch.cdist(x_embedding.view(1, -1), self.prior_art).min().item()
        return float((1 + (s_prior >= s_x).sum().item()) / (len(s_prior) + 1))

    def innovation_radius(self, x_embedding: Tensor) -> float:
        return float(torch.cdist(x_embedding.view(1, -1), self.prior_art).min().item())

    def verify(self, x_embedding: Tensor) -> bool:
        S = self.select_independent_witnesses()
        return (len(S) >= self.k and
                self.novelty_pvalue(x_embedding) <= self.alpha_nov and
                self.innovation_radius(x_embedding) >= self.r_min)


# ============================================================
# IP-447 CMTG 跨模态证书三角定位门（v25）
# ============================================================
@dataclass
class CrossModalTriangulationGate:
    hpc_e_plus: 'HPCEPlus'
    usmc: 'UnifiedStructuralMechanicalCertificate'
    lgwc: LiDARGeometricWitnessCertificate
    ldic: LiDARIntegrityCertificate
    einc: EvidenceIndependenceNoveltyCertificate
    agree_tol: float = 1e-3

    def admits(self, plan, x, v, z, E_res, margin_req, modules,
               F_hist, v_hist, volume, rho_solid,
               plan_embedding: Tensor,
               soc_deform_pred: float, fcc_contact_pred: float) -> bool:
        # 1-2. 既有 HPC-E+ 与 USMC（模型侧证书）
        if not self.hpc_e_plus.admits(plan, x, v, z, E_res, margin_req, modules):
            return False
        if not self.usmc.admits(plan, x, v, z, E_res, margin_req, modules,
                                F_hist, v_hist, volume, rho_solid):
            return False
        # 3-4. LiDAR 物理独立见证
        if not self.lgwc.verify_all():
            return False
        if not self.ldic.verify_all():
            return False
        # 5. 证据独立性与新颖性
        if not self.einc.verify(plan_embedding):
            return False
        # 6. 三角定位：模型预测与几何见证需一致
        if not self._triangulate(soc_deform_pred, fcc_contact_pred):
            return False
        return True

    def _triangulate(self, soc_deform_pred: float,
                     fcc_contact_pred: float) -> bool:
        d, pw = self.lgwc.residual()
        U = self.lgwc.error_budget(pw)
        mask = self.lgwc._critical_mask(pw)
        if mask.sum().item() == 0:
            return False
        geo_lower = (d[mask].abs() - U[mask]).clamp_min(0).max().item()
        geo_upper = (d[mask].abs() + U[mask]).max().item()
        # 模型预测必须落在几何见证的置信区间内，否则判为不一致
        return (geo_lower - self.agree_tol <= soc_deform_pred <= geo_upper + self.agree_tol)
```

## 3. 正确性论证（增量）

### 引理 9（LGWC 的误差预算保守性）
**陈述**：若 `verify_deformation()` 以水平 1−α 通过，则在配准/量测误差模型成立时，关键单元真实形变 δ* 以概率 ≥1−α 满足 δ* ≤ δ_allow。
**证明**：逐点分解 d_i = δ*(x_i) + ε_reg,i + ε_sensor,i，故 |δ*| ≤ |d_i| + U_i（U_i 为一阶传播的误差预算）。对关键单元点集取有限样本 (1−α) 分位，顺序统计量给出单侧置信上界；覆盖度条件保证关键单元有足够样本。再由分位数对单元取并集，得全体关键单元上界。
∎

### 引理 10（LDIC 的退化/欺骗可检性）
**陈述**：在物理一致性谓词 φ_phys 与欺骗模型类 M_spoof 上，若 `verify_all()` 通过，则未被检出欺骗的概率 ≤ s_spoof + FN_det(M_spoof)，且有效点密度/覆盖满足下限。
**证明**：密度与 FOV 为确定性阈值；φ_phys 把多回波缺失、强度-材料冲突、时序跳变判为不可行。对 M_spoof 内任一样本，注入必然违反至少一个物理谓词，除非落在检测器假阴性集，其测度由 FN_det 界定。合取得上界。
∎（注意：这是**条件性**保证，依赖欺骗模型类假设，见风险 R12。）

### 引理 11（EINC 的独立性与新颖性有效性）
**陈述**：若 `verify()` 通过，则所选见证集 S 满足两两 I(E_i;E_j) ≤ ε 且 |S| ≥ k；在先验语料可交换假设下，conformal p 值满足 P(p_nov ≤ α_nov) ≤ α_nov（对来自先验分布的样本），故 p_nov ≤ α_nov 表示方案以显著性 α_nov 越出先验流形。
**证明**：独立性由贪心选择的可判定条件直接保证。新颖性由 conformal 预测的标准有效性（可交换性 + 秩统计）给出有限样本第一类错误控制。
∎

### 引理 12（k-of-n 单通道故障可检出）
**陈述**：设见证集 S 含 n 条两两失效独立通道，至多 k−1 条被攻陷；若被攻陷通道无法以优于 p_forge 的概率伪造与诚实独立通道的一致，则 CMTG 未检出故障的概率 ≤ C(n, k−1)·p_forge。
**证明**：当诚实通道数 ≥ n−(k−1) ≥ 1 时，三角定位要求模型预测落入几何见证区间；被攻陷通道产生偏离，需与诚实通道伪一致。对至多 k−1 个攻陷组合取并集界即得。
∎

### 引理 13（v25 单调退化链延伸）
**陈述**：任意单点/组合失效下，`Exec_v25 ⊆ Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18` 恒成立。
**证明**：v25 在 v24 基础上仅增加连言过滤器 Fil_lidar、Fil_indep，交集只会缩小执行集。新增退化路径：
- LiDAR 退化/遮挡/欺骗 → `LDIC=false` 或 `LGWC=false` → CMTG 拒证 → 退回 v24（仅失去物理独立见证，保留模型侧证书）。
- 证据共模/相关性超限 → `EINC=false`（|S|<k）→ 退回 v24（回到模型侧单源，显式标注置信降级）。
- 新颖性不足 → `EINC=false` → 拒证（避免对既有技术重复申请，保护 IPAM 链）。
- 组合失效取交集，单调性保持。
∎

### 定理（CMTG 五层准入的安全-合规-可部署-可保护-结构-几何-认识论完备性）
**陈述**：对任意计划 π，`CMTG.admits(π)=True` ⟺ π 同时满足：
(1) 物理接地安全（几何∧规范∧负信息∧能量∧差距）；
(2) 云边版本一致性与统计覆盖承诺；
(3) 少样本适应后 conformal 覆盖 ≥1−α；
(4) 核心模块专利保护完备且无侵权风险；
(5) 结构应力/能量/可制造性三重达标；
(6) 力控无源性/带宽/稳定性三重达标；
(7) 轻量化刚度/质量/屈曲三重达标；
(8) LiDAR 几何见证与感知完整性达标，且证据独立（≥k 见证）与新颖性（p_nov ≤ α_nov）达标。

**证明**：由 `CMTG.admits` 的八个连言条件，结合引理 1–3、5–7、9–12 直接可得。必要性：任一条件缺失即拒证，对应八类风险之一未缓解。充分性：八条件全满足时，引理 4/8/13 保证执行集单调链，引理 9–12 保证物理独立见证与统计有效性，构成从模型、物理、认识论三层闭合的准入链。
∎

## 6. 本轮最大风险（最终确认）

**一句话**：**「证据独立性」本身依赖一个无法在线完全验证的共模假设——当共享时钟/标定/固件或同一物理扰动让 LiDAR 几何见证与力/IMU 证据同时失效时，CMTG 的「≥k 条独立见证」会在最需要它的时刻退化为单一证据源，而 EINC 只能估计已登记通道的相关性、无法识别未登记的隐性共模，导致 v25 在物理失效已发生且多通道共同失真时仍可能错误通过。**
