# 第 1 轮（新循环，承接第 12 轮）· WINGMAN：把“看一眼”写进任务计划

> 检索/复核日期：**2026-10-31（UTC）**。赛事身份不变：宇树 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API。本轮是新灵感循环第 1 轮，研究线承接第 10 轮 FACT-VLA、第 11 轮 GEO-RESIDUAL、第 12 轮 CHUNK-SERVO。三个灵感词是「多视角视觉」「多模态交互」「任务规划」。本轮不推倒 CHUNK-SERVO 的“30 步规划 + 5 步伺服”，而是补它默认掉的一层：**CHUNK-SERVO 知道“怎么在 5 步内修正”，却不知道“现在到底完成了哪个子目标、该看哪里、看不看得见”。**

## 0. 先给结论：缺的不是第四个相机，而是“把观察当成一个动作”

CHUNK-SERVO 的核心假设是：当前子目标已知、目标物体已知、误差主要是连续位姿误差。但在 32 个多步骤任务里，真正杀死 episode 的往往是**离散状态错误**：

- 杯子其实没挂上，但 VLA 以为挂上了，继续去拿下一个杯子；
- 网线只顶在端口外面，视觉上“接触了”，但没有插入；
- 人把已经叠好的碗拿走，机器人还在按原计划做下一步；
- 腕部视角被夹爪挡住，头双目深度在 0.5 m 处只有约 15 mm/像素，最后 2 mm 的插入误差根本看不见；
- 第二只手臂在单臂阶段闲着，而它本来可以变成一个**可移动的宽基线相机**。

所以本轮押注 **WINGMAN**：

> **用官方 WLA 产生动作意图；用官方评分步骤 + 33k 成功演示编译出“谓词任务图”；用四路 RGB + 本体感觉维护“哪些子目标为真”的校准信念；把“观察”提升为任务计划里的一等动作；当一只手臂空闲时，让它移动到视差最好的位置，做另一只手臂的 wingman；人类编辑被当成外部状态翻转，触发失效传播和最小修复。**

一句话：**CHUNK-SERVO 把最后 3 厘米闭到 167 ms；WINGMAN 再往前一步，先确认“这 3 厘米是不是该走的 3 厘米”，再决定“用哪只眼睛看”。**

三个可验证创新点：

1. **OATG（Observation-Augmented Task Graph）**：把官方 score_steps 编译成谓词 DAG，动作集合从“执行/重试”扩展为“执行/观察/移动观察臂/修复/等待”；用子集 DP 求最小期望时间计划，用一步 VOI 精确选择“值不值得看一眼”。
2. **WINGMAN 视角**：把空闲的第二臂当成主动观察者；用双腕/头腕动态基线三角化，视差感知地选观察位姿；不新增学习模型，不重训 VLA。
3. **多模态证据与人类编辑**：语言给谓词先验，视觉给状态，本体感觉给接触/抓持/角色；跨模态冲突触发主动观察；人类编辑是外部 flip，进入失效传播 + 修复 DP。

三个灵感词怎么落到方案里：

| 灵感词 | 落到哪里 | 不做什么 |
|---|---|---|
| **多视角视觉** | 四路 RGB、头双目、双腕动态基线、第二臂主动观察；视差/可见性/遮挡评分选视角；协方差加权融合 | 不训多视角 3D 大模型；不在线跑 3DGS/NeRF；不把四路图硬拼进 6B VLA |
| **多模态交互** | 语言→谓词模板；视觉→谓词证据；本体→抓持/接触/角色；人编辑→外部状态翻转；跨模态冲突→主动查询 | 不做对话/LLM planner；不加力/触觉；不把人类当对话者 |
| **任务规划** | 官方 score_steps→谓词 DAG；OATG 动作；子集 DP + VOI；失效传播 + 最小修复 | 不做完整 TAMP；不做 32 个任务各一个策略；不用 LLM 从零生成计划 |

## 1. 这轮怎么想：三个词是一条链，不是三顶帽子

### 1.1 多视角视觉：不是“更多像素”，而是“谁来提供第二意见”

本轮重新核对了官方提交 README 和 HangCup 的 `meta/info.json`（2026-10-31）：

- 在线 API 给四路 RGB：`cam_left_high`、`cam_right_high`、`cam_left_wrist`、`cam_right_wrist`；没有 depth、camera_info、force/torque、tactile。
- 官方 WLA 的 `unitree.yaml` 只把 `head_stereo_left + wrist_left + wrist_right` 三路图送进模型；**右头相机从未进入 WLA**。
- HangCup 的腕部 **color 相机其实有完整内参**：左腕 `fx≈436.41`、右腕 `fx≈435.12`，还有畸变模型。第 12 轮写“腕部没有内参”是错的；没有的是腕部到 EE 的手眼外参，需要一次性标定。
- 头双目基线只有 **58.2526 mm**，左目 `fx≈282.37`。按一像素视差估算，0.5 m 处深度误差约 **15.2 mm**；而双腕如果形成 0.3 m 基线，0.5 m 处约 **1.9 mm**（θ=90°），θ=30° 时约 **3.8 mm**。

这不是“再买一个相机”的问题，而是**几何基线**的问题。头双目在 0.5 m 处对 2 mm 插入不够；双腕有更大的可变基线，但需要有人把第二只手腕**主动摆到能看见接触点的位置**。官方 WLA 不会做这件事，因为它只把腕部图当输入，不控制“观察姿态”。WINGMAN 把这件事变成任务计划的一部分。

### 1.2 多模态交互：不是“加一个模态”，而是“让模态互相查账”

在 UniBot 里，四个模态的角色非常不对称：

- **语言**：32 个任务名 + 5 条复述是封闭集；它最适合提供“这一步应该建立什么谓词”，不适合提供毫米级位姿。
- **视觉**：四路 RGB 能提供物体关系、遮挡、接触外观；但透明/反光/被夹爪挡住时会说谎。
- **本体感觉**：14 个手臂关节、EE 位姿、夹爪开度、下身体；没有力/触觉，但关节跟踪误差、夹爪开度、物体随动可以给出“接触/滑移/抓空”的弱证据。
- **人类**：不是对话伙伴，而是**外部状态编辑器**；官方 human_1/human_4 会撤销已完成子目标（把叠好的毛巾翻开、拉链拉开、盖子拧回去、把碗拿走）。

所以“多模态交互”在本轮不是再接一个 VLM，而是：

```text
语言先验  ─┐
视觉证据  ─┼─► 谓词信念 b_v ─► 冲突分数 ─► 主动观察 / 降阈值 / 修复
本体证据  ─┤
人类编辑  ─┘
```

具体地，每个谓词维护一个 log-odds；视觉/本体/语言各自给一个 log-likelihood ratio；当视觉与本体冲突（例如视觉说“插入”，但本体说“还在自由空间、没有接触阻力”）时，不硬信任何一方，而是把该谓词标成 uncertain，触发一次**主动观察**（换视角/移动第二臂）或一次**本体探针**（小幅度保持/回撤，看关节跟踪误差）。这比“再训一个多模态融合网络”便宜、可解释，也不违反单模型。

### 1.3 任务规划：不是“30 步动作计划”，而是“可验证的子目标图”

CHUNK-SERVO 的 30 步 plan 是**动作层**的计划；它没有显式的“任务状态”。官方其实已经把任务状态给了：32 个任务、94 个评分步骤，每个步骤有前置/后置语义。把它们编译成谓词 DAG 后，任务规划变成一个很小的离散问题：

- 每个任务 `n≤5–8` 个关键子目标；
- 状态是“哪些谓词为真”；
- 动作是“执行某个子目标 / 观察某个谓词 / 移动观察臂 / 修复某个失效子目标”；
- 目标是在 180 s 内最大化“所有终局谓词为真”的概率。

因为 `n` 很小，子集 DP 的复杂度是 `O(n 2^n)`，在 CPU 上微秒级；不需要 LLM，不需要 TAMP 求解器，也不需要第二个模型。真正的难点不是“算计划”，而是**观测**：很多谓词在单视角下不可辨识，必须决定“看哪里、什么时候看、值不值得看”。这就是 WINGMAN 把多视角和任务规划接在一起的地方。

## 2. 诊断：CHUNK-SERVO 的三个“盲”区

把一次失败拆成三层：

```text
任务层：我现在应该做哪个子目标？上一个子目标真的完成了吗？
观测层：哪个视角能看见这个子目标？看得见的置信度是多少？
执行层：5 步伺服怎么把这个子目标做准？
```

CHUNK-SERVO 主要修第三层；FACT-VLA/GEO-RESIDUAL 修了一部分第一/第二层，但仍以“相位/残差”隐式表达。WINGMAN 的判断是：

1. **任务层盲**：VLA 的 30 步 plan 不是可验证的任务状态；失败后只能重规划整段，不能只修复被撤销的子目标。
2. **观测层盲**：四路图是被动输入；没有“为了确认这个谓词，我应该把第二只手臂放到哪里”的决策；腕部被遮挡时没有主动换视角。
3. **交互层盲**：人类编辑被当成噪声或视觉异常；没有把它映射成“哪个谓词被翻转、哪些后继失效、最小修复是什么”。

三者叠在一起，表现就是：**机器人很努力地执行一个已经错了的计划。**

## 3. 方案：WINGMAN 的四层结构

```text
┌────────────────────────────────────────────────────────────┐
│ 任务层：谓词 DAG + 信念 + 修复 DP                           │
│   score_steps ─► G=(V,E) ─► b_v ─► A/U/F ─► repair plan     │
└──────────────────────┬─────────────────────────────────────┘
                       │ 子目标 + 观察请求
┌──────────────────────▼─────────────────────────────────────┐
│ 证据层：多视角 + 多模态                                     │
│   head stereo / left wrist / right wrist / wingman wrist    │
│   language prior + visual log-odds + proprio log-odds       │
│   cross-modal conflict ─► active query                      │
└──────────────────────┬─────────────────────────────────────┘
                       │ 目标位姿 / 观察位姿
┌──────────────────────▼─────────────────────────────────────┐
│ 观察层：WINGMAN 视角                                        │
│   free-arm role schedule ─► candidate poses ─► parallax     │
│   visibility / collision / joint-limit score ─► hold pose   │
└──────────────────────┬─────────────────────────────────────┘
                       │ 前馈动作 + 伺服修正 + 观察臂覆盖
┌──────────────────────▼─────────────────────────────────────┐
│ 执行层：CHUNK-SERVO                                         │
│   30-step VLA plan ─► 5-step servo ─► API action chunk      │
└────────────────────────────────────────────────────────────┘
```

### 3.1 任务层：OATG

定义任务 `t` 的谓词图 `G_t=(V_t,E_t)`，`|V_t|≤8`。每个节点 `v` 有：

- 技能 `π_v`：VLA 子目标提示 + 可选的伺服目标；
- 前置 `pre(v)`、后置谓词 `φ_v`；
- 估计时长 `d_v`、成功率 `p_v`；
- 评分权重 `w_v`；
- 观测需求 `r_v ∈ {none, verify, metric}`：`metric` 表示需要宽基线深度（插入/挂/叠），`verify` 表示只需确认布尔谓词。

在线维护三个集合：

- `A`：已验证为真（`b_v ≥ θ_hi`）；
- `F`：已验证为假（`b_v ≤ θ_lo`）；
- `U`：不确定（介于两者之间）。

动作集合：

```text
EXEC(v)        执行子目标 v（VLA + 伺服）
OBS(c, V_c)    用视角 c 观察一组谓词 V_c
MOVE_OBS(T_o)  把空闲的第二臂移动到观察位姿 T_o
REPAIR(v)      重做被人类/失败翻转的 v
HOLD           人类在 workspace 内时让行/等待
```

规划器用子集 DP 求“从当前 A 到目标谓词集合”的最小期望时间；不确定节点先观察还是先执行，用一步 VOI 精确比较。细节见产物区 §3–§4。

### 3.2 观察层：WINGMAN 视角

不是所有任务都需要第二臂观察。先用演示统计出每个任务/相位的**角色**：

- `single-arm`：另一只手臂空闲，可做观察者；
- `support`：另一只手臂在支撑，不能动，但它的腕部相机可能仍能看到接触；
- `bimanual`：双手都在执行，观察者只能用头双目/腰部视角。

对 `single-arm` 的 `metric` 相位，生成候选观察位姿 `T_o`：

1. 从演示里取非执行臂的 EE 位姿分布作为先验；
2. 在目标点周围采样球面候选（半径 0.2–0.5 m，方位/俯仰若干档）；
3. 用 IK、关节限位、自碰撞、桌面/物体碰撞、人占用做过滤；
4. 用 `visibility × parallax × focus − collision − travel` 评分，选最高分；
5. 如果最高分低于阈值，不移动第二臂，退回头双目/双腕被动视角。

关键几何：两视角三角化的深度误差近似

```math
\sigma_Z \approx \frac{Z^2 \sigma_d}{f\, b \sin\theta},
```

其中 `Z` 是目标距离，`σ_d` 是视差噪声（像素），`f` 是焦距，`b` 是基线，`θ` 是基线与平均视线的夹角。`sinθ` 越大、`b` 越大，深度越准。WINGMAN 的观察位姿评分就是把 `sinθ` 和可见性一起最大化。

### 3.3 交互层：人类编辑 = 外部 flip

人类编辑的官方语义是“撤销已完成子目标”。WINGMAN 不试图识别人类意图，只做三件事：

1. **检测**：动作条件化残差 + 多视角不一致 + 本体跟踪误差，得到一个 `edit_score`；
2. **失效**：把涉及对象的谓词标成 `U/F`，沿 DAG 传播失效闭包；
3. **修复**：用同一个子集 DP 从当前 `A` 重算最小修复序列；如果人类还在 workspace 内，先 `HOLD`，只观察不执行。

这和第 8 轮 SURE-BT、第 2 轮 TVC 的区别是：WINGMAN 的修复不是“重跑整段”或“查表”，而是**在证据不确定时先选择看哪里**；TVC 假设后置谓词可验证，WINGMAN 补的就是“怎么验证”。

### 3.4 执行层：CHUNK-SERVO 原样保留

- VLA 仍然输出 30 步动作意图；
- 执行仍然切成 5 步块；
- 伺服仍然用相对目标 + IBVS/PBVS；
- WINGMAN 只做两件事：给伺服提供**当前已验证的子目标/目标位姿**；在需要时**覆盖空闲臂的动作**，让它去观察位姿并保持。

也就是说，WINGMAN 不是替代 CHUNK-SERVO，而是给它一个“任务状态 + 观察调度”的上层。

## 4. 为什么现在能做：四个已经存在的事实

1. **四路 RGB + 双腕内参**：腕部 color 相机有内参，缺的只是一次手眼标定；双腕可以形成 0.2–0.5 m 的动态基线，远大于头双目 58 mm。
2. **官方评分步骤是强先验**：32 任务 94 个评分步骤，任务图很小；子集 DP 在 CPU 上微秒级，不抢 GPU。
3. **33k 成功演示**：可离线估计相位顺序、时长、成功率、每个视角的可见性/可靠性、非执行臂的观察位姿先验；不需要新采集。
4. **WLA 30 步 + 5 步伺服已经给了执行层**：WINGMAN 只需要在 5 步块边界做一次任务状态更新和观察决策，不要求 30 Hz 广域网闭环。

## 5. 预期收益与可证伪预测

不承诺具体分数，只给敏感性区间。设基线成功率 `p≈0.25`：

- **人为干扰轴**占 20%。如果 WINGMAN 把 human trial 的成功率提高 10–15pp，全局约 `+2–3pp`。
- **接触任务**（A 档 19 个中的 5–8 个）如果因为第二视角/更准深度提高 5–10pp，全局约 `+1–2.5pp`。
- **状态误判/假完成**如果减少，非 human 轴再 `+1–2pp`。

保守目标 **+3–5pp**；如果只在一个轴上有效，可能只有 +1–2pp。所有收益必须用配对 A/B 和 bootstrap 置信区间验证；320 trials 的单次标准误约 2.4pp，不能把 +1–2pp 当结论。

可证伪预测：

- 如果演示统计显示，在接触相位中第二臂可见目标的比例 <30%，WINGMAN 的主动观察层就不值得做，退化为被动多视角验证。
- 如果仿真里观察位姿带来的深度改善 <30%，或碰撞/超时率 >5%，不移动第二臂。
- 如果单任务通道里“观察+修复”相对“只重试”没有 +5pp，砍掉观察层，只保留任务图信念与修复。

## 6. 风险与最大的风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| 第二臂遮挡/碰撞/拖慢 | 比不看更糟 | 碰撞检查、工作空间分离、只在 `metric` 相位移动、失败回退头双目 |
| 腕部手眼外参不准 | 三角化/伺服偏差 | 一次性手眼标定；重投影误差门限；误差大时只用头双目 |
| VLA 对观察臂 OOD | 动作质量下降 | 观察位姿从演示的非执行臂分布里采样；缓慢移动；接触段保持不动 |
| 谓词检测器误判 | 假修复/假完成 | 多视角 + 本体冲突；阈值滞回；不确定时先观察 |
| `p_v`/`d_v` 估计不准 | DP 计划偏差 | 保守先验；单任务通道更新；对 `p_v` 做敏感性分析 |
| 单模型合规解释 | 被判定第二个模型 | 观察/规划全是确定性几何/控制；可选 VLM 查询用同一 checkpoint；C1 回退 |
| 任务图步骤太粗/太多 | 计划不准或状态爆炸 | 按演示相位细分；对称物体合并；`n>8` 用 beam search |
| 人类编辑检测漏报 | 修复晚 | 多视角 + 本体 + 官方 human 脚本先验；不声称 100% |

**本轮方案最大的风险：第二臂为了“多看一眼”而进入执行臂的工作空间，既可能遮挡/碰撞，也可能把 VLA 拖出演示分布；如果 E0/E3 证明观察姿态的可见性增益不足或碰撞率高，WINGMAN 必须退化为“只用头双目/双腕的被动多视角验证 + 任务图修复”，不再移动第二臂。**

## 7. 一句话押注

**用 WLA 做动作意图，用官方评分步骤做可验证的谓词任务图，用四路 RGB + 本体感觉维护“哪些子目标为真”的信念，把“看一眼”写成任务计划里的动作，并让空闲的第二只手臂在需要时变成宽基线观察者——这就是 WINGMAN。**

## 2. 问题形式化

### 2.1 任务图

对任务 `t`，定义谓词任务图

```math
G_t=(V_t,E_t),\qquad |V_t|=n_t\le 8,
```

节点 `v∈V_t` 表示一个可验证子目标，边 `u→v` 表示 `u` 是 `v` 的前置。每个节点有：

| 符号 | 含义 |
|---|---|
| `pre(v)⊆V_t` | 前置谓词集合 |
| `φ_v: X→{0,1}` | 后置谓词 |
| `π_v` | 技能：VLA 子目标提示 + 可选伺服目标 |
| `d_v>0` | 估计时长（秒） |
| `p_v∈(0,1]` | 单次执行成功率 |
| `w_v≥0` | 评分权重 |
| `r_v∈{none,verify,metric}` | 观测需求：无需/布尔验证/宽基线米制 |

终局目标 `g_t⊆V_t`，任务成功当且仅当 `g_t` 中所有谓词为真。官方评分步骤提供 `V_t` 的强先验；演示相位分割用于细分/合并节点。

### 2.2 状态、人类编辑与信念

潜状态 `x_t∈{0,1}^{n_t}`；`x_v=1` 表示 `φ_v` 为真。机器人执行成功时单调置 1；人类编辑是外部翻转：

```math
x \leftarrow x \wedge \neg u,\qquad u\in\{0,1\}^{n_t},
```

即人类只能撤销已完成的子目标（官方 human_1/human_4 的语义）。信念 `b_t∈[0,1]^{n_t}`，`b_v=P(x_v=1|history)`。定义

```math
A=\{v:b_v\ge\theta_{hi}\},\quad
F=\{v:b_v\le\theta_{lo}\},\quad
U=V_t\setminus(A\cup F).
```

`A` 是“已验证为真”，`F` 是“已验证为假”，`U` 是“不确定”。只有 `A` 中的节点可以免执行；`U` 中的节点要么先观察，要么保守地重做。

### 2.3 观测模型

视角集合 `C = {H_L,H_R,W_L,W_R} ∪ O`，其中 `O` 是第二臂观察候选位姿（每个候选是一个瞬时视角）。对谓词 `v` 和视角 `c`：

```math
P(z_{v,c}=1\mid x_v=1)=\alpha_{v,c},\qquad
P(z_{v,c}=1\mid x_v=0)=1-\beta_{v,c},
```

`α` 是灵敏度，`β` 是特异度。可见性 `ρ_{v,c}∈[0,1]`；不可见时 `z=⊥`，不更新。若同一视角可同时观察多个谓词，记 `V_c` 为可见谓词集合，一次观察返回 `z_{V_c}`。

贝叶斯更新（log-odds）：

```math
\operatorname{logit} b'_v
= \operatorname{logit} b_v
+ \mathbb 1[v\in V_c]\left[
z_v\log\frac{\alpha_{v,c}}{1-\beta_{v,c}}
+(1-z_v)\log\frac{1-\alpha_{v,c}}{\beta_{v,c}}
\right].
```

多视角/多模态时用加权和：

```math
\operatorname{logit} b_v
= \operatorname{logit} b_v^{prior}
+ w_{lang}\ell_{lang}(v)
+ \sum_c w_{v,c}\ell_{vis}(v,c)
+ w_{prop}\ell_{prop}(v),
```

权重在离线演示上校准；`w_{v,c}` 随可见性 `ρ_{v,c}` 降权。跨模态冲突

```math
\chi_v=\left|\ell_{vis}(v)-\ell_{prop}(v)\right|
```

超过阈值时把 `b_v` 拉回 0.5 并触发一次主动观察；这是“让模态互相查账”，不是再训一个融合器。

### 2.4 动作、成本与目标

| 动作 | 语义 | 成本 | 效果 |
|---|---|---|---|
| `EXEC(v)` | 执行子目标 `v` | `d_v` | 成功 w.p. `p_v`，`x_v←1` |
| `OBS(c)` | 用视角 `c` 观察 `V_c` | `τ_c` | 按观测模型更新 `b` |
| `MOVE_OBS(T_o)` | 空闲第二臂移动到观察位姿 | `τ_move(T_o)` | 改变候选视角/可见性 |
| `REPAIR(v)` | 重做被翻转的 `v` | `d_v` | 同 `EXEC` |
| `HOLD` | 人类在 workspace 内让行 | `τ_hold` | 不改状态，等待/观察 |

目标：在 180 s 内最大化期望得分

```math
\max_{\pi}\ \mathbb E\left[
\sum_{v\in g_t} w_v x_v(T) + w_{success}\mathbb 1[g_t\subseteq A(T)]
-\lambda T
\right],
```

并满足安全约束（关节限位、速度、碰撞、人类让行）。本轮把成功率放在第一位；时间惩罚 `λ` 用来避免无意义的观察。

### 2.5 假设与失效边界

| A4 | 视角可见性/检测器在 episode 内稳定 | 光照/遮挡突变 → 降权，回退 VLA |

## 3. WINGMAN 算法

### 3.1 离线：任务图编译与视角校准

```text
输入：官方 score_steps、32 任务语言、33k 成功演示、URDF、相机内参
1. 语言→谓词模板：把任务名/复述映射到谓词本体
   （holding / on / in / inserted / stacked / zipped / sorted / unlocked / ...）
2. score_steps→DAG：每个评分步骤一个节点；按语义/演示顺序加边
3. 演示相位分割：FACT-VLA CPT / DTW / 人工校验
   - d_v = 相位时长中位数
   - p_v = 单任务通道/仿真先验（成功演示不能直接给失败率）
   - 相位顺序一致性 = DAG 边的支持度
4. 视角校准：
   - 头双目内参/外参（已有）
   - 腕部 color 内参（已有）+ 手眼外参（棋盘格/已知 EE 运动）
   - 每个 (v,c) 的 α、β、ρ：用演示中谓词真值/任务结果做校准
5. 角色统计：
   - 每个相位标为 single-arm / support / bimanual
   - 非执行臂的 EE 位姿分布 → 观察位姿先验
6. 观察位姿候选库：每个任务/相位 8–32 个 IK 可行、无碰撞的候选
```

**关键细节**：成功演示只包含成功轨迹，不能直接估计 `p_v`。`p_v` 的初值用保守先验（0.7–0.95），在单任务不计分通道/仿真中更新；对 `p_v` 做敏感性分析，避免 DP 过拟合。

### 3.2 在线主循环

```python
def wingman_step(obs, state):
    # 1. 多模态证据更新
    b = fuse_evidence(state.b, obs, state.task_graph)
    state.b = b

    # 2. 人类编辑检测
    if edit_detected(obs, state):
        affected = edit_objects(obs, state)
        b, state.A = invalidate(b, state.A, affected, state.task_graph)
        state.mode = "INTERACT"

    if state.mode == "INTERACT":
        if human_in_workspace(obs):
            return hold_and_observe(obs, state)   # 安全优先
        state.mode = "PLAN"

    # 3. 任务状态分桶
    A, F, U = bucket(b, state.theta_hi, state.theta_lo)

    # 4. 子集 DP：所有 mask 的 cost-to-go
    C, policy = subset_dp(state.task_graph, A)

    # 5. 一步观察选择：枚举候选视角/可见谓词
    best_view, best_gain = None, 0.0
    for c in candidate_views(obs, state):
        exp_cost = observe_expected_cost(c, A, U, b, C, state)
        gain = C[A] - exp_cost
        if gain > best_gain:
            best_view, best_gain = c, gain

    if best_view is not None and best_gain > state.obs_margin:
        move_observer_if_needed(best_view, obs, state)
        return observe_action(best_view, state)

    # 6. 执行计划中的下一个子目标
    v = policy[A]
    if v is None:                      # goal reached
        return done_or_verify(state)

    a_ff = state.vla.plan(obs, subgoal=v)          # 30-step
    a_servo = state.servo.correct(obs, goal=v)     # 5-step
    observer_override = state.wingman.hold_or_move(v, obs)
    return state.adapter.compose(a_ff, a_servo, observer_override)
```

### 3.3 子集 DP：最小期望时间修复计划

定义 `C(A)` 为从已验证集合 `A` 到目标 `g_t` 的最小期望时间（stationary retry-until-success）：

```math
C(A)=
\begin{cases}
0, & g_t\subseteq A,\\
\min\limits_{\substack{v\notin A\\ pre(v)\subseteq A}}
\left(\dfrac{d_v}{p_v}+C(A\cup\{v\})\right), & \text{otherwise}.
\end{cases}
```

`d_v/p_v` 是“执行到成功”的几何期望时间。转移只增加一个 bit，因此可按 `|A|` 从大到小计算；同时保存 argmin 得到计划。若某节点被人类翻转，把它从 `A` 移到 `F/U`，重新计算即可。

**为什么这是对的（直觉）**：失败后状态不变，所以最优策略在同一状态会重复同一动作或切换到另一个动作；对固定 `v`，`T_v=d_v+(1-p_v)T_v+p_vC(A∪{v})`，解出 `T_v=d_v/p_v+C(A∪{v})`；对所有可行 `v` 取最小即为 Bellman 最优。严格证明见 §4.2。

### 3.4 一步 VOI：值不值得看一眼

在状态 `A`，候选视角 `c` 的可见不确定谓词集合 `V_c∩U`。对该集合的每个观测结果 `z`，后验把一些谓词移入 `A`；用 DP 的 `C` 计算剩余成本：

```math
E_c=\tau_c+
\sum_{z\in\{0,1\}^{V_c\cap U}}
P(z\mid b)\;C\!\left(A\cup\{v\in V_c\cap U:z_v=1\}\right).
```

选择 `c^*=\arg\min_c E_c`；若 `C(A)-E_{c^*}` 大于观察成本/风险边际，就先观察；否则执行 `policy[A]`。对未观察的 `U` 节点保守地不加入 `A`，避免假完成。

**精确性**：在“一步 lookahead + 条件独立观测 + 候选视角有限”的模型内，枚举 `c` 和 `z` 是精确的；它不是多步 POMDP 的全局最优，外层用滚动时域重规划弥补。详见 §4.3 与 §8 的已知风险。

### 3.5 WINGMAN 观察位姿

#### 3.5.1 视角图

- 头左/右：内参、R/T 已知（已 rectified）。
- 腕左/右：`T_base_cam = T_base_ee · T_ee_cam`；`T_ee_cam` 由一次性手眼标定得到；`T_base_ee` 在线可得。
- 第二臂观察候选：每个候选 `T_o` 对应一个腕部相机位姿；与执行臂腕部/头双目组成动态视角图。

任意两视角 `(c1,c2)` 若同时看见目标点，可三角化；位姿用协方差加权融合：

```math
\Sigma_{fused}^{-1}=\sum_{c\in\mathcal C_{vis}}\Sigma_c^{-1},
```

其中 `Σ_c` 由重投影/视差噪声传播得到；对 outlier 用 Huber/鲁棒权重。

#### 3.5.2 视差与深度不确定性

对两视角，设目标距离 `Z`、焦距 `f`、基线 `b`、基线与平均视线夹角 `θ`、视差噪声 `σ_d`（像素）。有效基线为 `b sinθ`，由 `Z=f b sinθ/d` 得

```math
\left|\frac{\partial Z}{\partial d}\right|
=\frac{Z^2}{f b\sin\theta},
\qquad
\sigma_Z\approx\frac{Z^2\sigma_d}{f b\sin\theta}.
```

因此固定 `Z,σ_d` 时，`sinθ` 越大、`b` 越大，深度越准。`sinθ=1`（正交基线）最优；θ=30° 时误差翻倍。

#### 3.5.3 候选生成与评分

```text
候选生成：
  1) 演示先验：非执行臂在相同相位的 EE 位姿分布，取 top-k 聚类中心
  2) 几何采样：目标点周围球面，r ∈ {0.2, 0.3, 0.4, 0.5} m，
     方位 8 档、俯仰 3 档；姿态朝向目标
  3) 过滤：IK 不可达、关节限位、自碰撞、桌面/物体碰撞、人手占用
  4) 评分：
     J(T_o) = w_v·vis(T_o)
            + w_p·min(1, sinθ(T_o)/sinθ*)
            + w_f·focus(T_o)
            - w_c·collision(T_o)
            - w_j·joint_limit(T_o)
            - w_t·travel(T_o)
  5) 若 max J < J_min：不移动第二臂，退回被动视角
```

`vis` 是目标点集在 FOV 内且未被遮挡的比例；`focus` 是目标在图像中的尺寸/清晰度；`collision/joint_limit/travel` 是安全与时间惩罚。

#### 3.5.4 角色调度

从演示统计每个任务/相位的角色：

| 角色 | 判据 | 观察者 |
|---|---|---|
| single-arm | 一侧夹爪开度不变、EE 不进入任务区域、物体不随动 | 空闲臂可移动观察 |
| support | 一侧夹爪持续夹持/支撑，位置基本不变 | 支撑臂腕部可被动看，不移动 |
| bimanual | 两侧都在接触/协同 | 头双目/腰部视角；不移动第二臂 |

只有 `single-arm` 的 `metric` 相位才允许 `MOVE_OBS`；`support` 只用其腕部相机；`bimanual` 退回被动多视角。这样避免“为了观察而破坏任务”。

### 3.6 人类编辑与修复

```python
def invalidate(b, A, affected_objects, G):
    affected_preds = predicates_involving(affected_objects, G)
    for v in affected_preds:
        b[v] = 0.5          # 不确定，等待证据
        A.discard(v)
    # 依赖闭包：依赖失效节点的后继也失效/阻塞
    for v in topological_order(G):
        if any(u in affected_preds for u in pre(v)):
            b[v] = min(b[v], 0.5)
            A.discard(v)
    return b, A
```

触发条件：动作条件化视觉残差、多视角不一致、本体跟踪误差、人类手部进入 workspace。检测到编辑后：

1. `HOLD`：停止执行臂；观察臂移到安全让行位姿（不追人手）。
2. 失效传播：把涉及对象的谓词标 uncertain/false；后继阻塞。
3. 证据收集：优先用头双目/腕部被动视角确认；必要时移动观察臂。
4. 修复：用 §3.3 的 DP 从当前 `A` 重算；若时间不够，选择“完成剩余可完成步骤”的 salvage 计划。

**与 TVC 的区别**：TVC 的账本假设后置谓词可验证；WINGMAN 把“验证”本身做成动作，并显式选择视角。TVC 的修复是主问题；WINGMAN 的修复是证据不确定下的观测-规划联合问题。

### 3.7 执行层接口

- VLA 仍输出 30 步相对 EE 动作；adapter compose 成 base 系绝对目标，按 5 步切片。
- 执行臂：`a_cmd = a_ff ∘ exp(Δ_servo)`，其中 `Δ_servo` 来自 CHUNK-SERVO 的 IBVS/PBVS。
- 观察臂：如果当前相位 `single-arm` 且需要 `metric` 观察，覆盖该臂的动作为**确定性关节空间轨迹**（IK + 限速 + 碰撞检查），到达 `T_o` 后保持；否则保持/跟随 VLA。
- 观察臂移动只在相位边界/预接触前进行；接触段保持不动，避免扰动。
- 若观察臂的 VLA 动作与观察轨迹冲突，观察轨迹优先；执行臂不受影响。

### 3.8 安全层

- 关节限位/速度/加速度限制；观察臂速度上限低于执行臂。
- 胶囊/点云粗碰撞检查：桌面、已知物体、执行臂、人体（若检测到）。
- 工作空间分离：观察臂不得进入执行臂的“接触管”（以目标点为中心、半径 `r_safe` 的球/圆柱）。
- 人类在 workspace 内：两臂停止；只允许被动观察；观察臂只做安全收臂。
- 任何异常/超时：返回上一组合法动作或安全 hold；不返回 NaN/错误形状。

## 4. 正确性论证

### 4.1 引理 1（贝叶斯更新）

在观测模型 §2.3 与条件独立假设下，log-odds 更新式给出正确的后验 `b'_v=P(x_v=1|z_{V_c})`。

**证明**：由贝叶斯公式，

```math
\frac{P(x=1|z)}{P(x=0|z)}
=\frac{P(z|x=1)}{P(z|x=0)}\frac{P(x=1)}{P(x=0)},
```

取对数即得；多视角在条件独立下相加。∎

### 4.2 定理 1（子集 DP 最优性）

在假设 A2（失败后状态不变、可重试）且 `p_v>0` 下，§3.3 的 `C(A)` 是最小期望时间，`policy[A]` 是最优首动作。

**证明**：对 `|V_t\setminus A|` 归纳。若 `g_t⊆A`，`C=0` 显然最优。否则考虑任意 stationary 策略 `π`。设它在 `A` 首选 `v`；失败后状态仍为 `A`，由最优性原理，后续值至少为 `C(A)`；成功后的值至少为 `C(A∪{v})`。因此

```math
T_\pi(A)\ge d_v+(1-p_v)C(A)+p_vC(A\cup\{v\}).
```

对最优策略取等（失败后仍最优），解出 `C(A)=d_v/p_v+C(A∪{v})`。由于“commit to v until success”是可行策略，`C(A)≤d_v/p_v+C(A∪{v})` 对所有可行 `v` 成立；故 `C(A)=min_v[d_v/p_v+C(A∪{v})]`。转移只增加 bit，归纳成立。∎

**注**：若 `p_v` 依赖当前 `A`（例如先抓后放），把 `p_v` 换成 `p_v(A)` 即可；只要 `p_v(A)>0`，证明不变。若失败会改变状态（掉落），A2 不成立，需要先观察/重定位；这是 §8 的风险。

### 4.3 定理 2（一步观察选择的精确性）

在固定当前信念 `b`、固定候选视角集合 `C`、观测条件独立、且只做一步观察的模型内，§3.4 枚举所有 `c` 与所有 `z` 得到的 `c^*` 是期望成本最小的观察。

**证明**：候选集有限，枚举覆盖所有可能的一步观察及其结果；对每个结果用 DP 的最优 continuation，故期望成本精确；取最小即最优。∎

**注**：这不是多步 POMDP 的全局最优；多步观测的值可能高于一步 VOI。外层滚动时域 + 每次重规划把误差限制在一步；若需要更强保证，可把 `U` 离散成 3 档做 belief-MDP（§8 风险）。

### 4.4 定理 3（计划有效性）

若 (i) 任务图 `G_t` 的 pre/post 正确；(ii) 每次 `EXEC(v)` 在 `pre(v)⊆A` 时执行且成功；(iii) `A` 只包含真实为真的谓词；则 `policy` 返回的序列按序执行后，`g_t⊆A`，任务成功。

**证明**：对序列长度归纳。每一步选择 `v` 满足 `pre(v)⊆A`；成功后 `φ_v` 为真，加入 `A`；由 (iii) 不会把假谓词加入。序列终止时 `g_t⊆A`。∎

**注**：现实中 `p_v<1`，定理是“成功路径”的有效性；失败由 DP 的期望时间/重试处理。若观测有假阳性，`A` 可能含假谓词，定理不成立；因此需要阈值 `θ_hi`、多视角/本体冲突检测和修复预算。

### 4.5 引理 2（视差单调性）

在 §3.5.2 的针孔/小噪声模型下，`σ_Z` 随 `sinθ` 单调递减，随 `b` 单调递减（固定 `Z,f,σ_d`）。

**证明**：`σ_Z=Z²σ_d/(f b sinθ)`，分母随 `sinθ`、`b` 增大而增大。∎

**注**：`θ→90°` 时有效基线最大；但可见性/遮挡/关节限位可能随 `θ` 变差，所以评分函数是 `vis` 与 `sinθ` 的折中，不是单纯追求正交。

### 4.6 命题 1（安全覆盖）

若碰撞检查器是保守的（不把碰撞判为自由），观察位姿候选在移动前通过检查，且执行层遵守关节/速度限制，则观察臂不会主动进入碰撞或人类占用区域。

**证明**：候选过滤阶段删除任何被检查器判为碰撞/占用的位姿；轨迹插值每步复检；人类检测触发停止。∎

**注**：这是“检查器正确”的条件保证，不是物理保证；感知漏检仍是风险。

### 4.7 命题 2（修复完整性）

若 (i) 人类编辑检测正确识别被翻转的谓词集合 `U_edit`；(ii) 失效传播覆盖 `U_edit` 的所有后代；(iii) 剩余时间 ≥ DP 修复计划的时间；则修复后 `g_t` 可再次满足。

**证明**：失效传播把 `U_edit` 及其后代移出 `A`；DP 从当前 `A` 到 `g_t` 的序列按定理 1 可行；时间足够则执行完成。∎

**注**：检测漏报/时间不足会破坏命题；这是 human 轴的主要风险。

## 5. 复杂度分析

| 模块 | 复杂度 | 典型规模 | 备注 |
|---|---|---|---|
| 信念更新 | `O(n·|C|)` | n≤8, |C|≤12 | 每 chunk 一次 |
| 子集 DP | `O(n·2^n)` | n≤8 → 2048 状态 | Python 自检 n=8 约 0.28 ms |
| 观察选择 | `O(|C|·2^{|U|})` | |C|≤12, |U|≤8 → ~3k | 一步枚举 |
| 计划重建 | `O(n)` | — | 存 argmin |
| 观察位姿 | `O(K·(IK+collision+visibility))` | K≤64 | 只在相位边界；目标 <20 ms–100 ms |
| 视角融合 | `O(|C|·m)` | m 个目标点/特征 | 头/腕/观察候选 |
| 内存 | 任务图 <1 MB；候选位姿/校准 <50 MB | — | 每端口独立，只读共享 |

**结论**：WINGMAN 的在线开销主要在观察位姿的 IK/碰撞/可见性评分，且只在相位边界触发；5 步块边界的信念/DP/VOI 是微秒–毫秒级，不抢 GPU，不阻塞 VLA 异步推理。若某任务的谓词节点 `n>8`（例如多物体收纳），先按对称物体合并/计数抽象；仍超过 12 个节点时，DP 换成 beam search（宽度 64），并在单任务通道验证计划质量。

## 6. 合成自检与算例

### 6.1 子集 DP 对拍

本轮实现了 §3.3 的 DP 和一个**策略枚举 + 线性方程求解**的暴力最优器（n=2–4，stationary deterministic policies）。在 600 个随机 DAG 上（300 个全目标、300 个随机目标子集；随机 `d∈[0.5,3]`、`p∈[0.4,0.99]`），DP 与暴力最优值的最大绝对误差 < `1e-7`，**0 个不一致**。

| n | DP 平均耗时（本机 Python） |
|---:|---:|
| 5 | 0.026 ms |
| 8 | 0.279 ms |
| 10 | 1.414 ms |
| 12 | 6.270 ms |

这是算法自检，不是机器人实验；它证明 DP 在 n≤8 的 UniBot 任务图上足够快且与暴力最优一致。

### 6.2 VOI 算例

单谓词例子：`α=β=0.9`，观察成本 `τ=0.2 s`，执行 `d=2 s`、`p=0.9`（`d/p=2.222 s`），时间惩罚 `λ=0.1 /s`。效用 `U=P(success)-λ·time`。观察后若 `z=1` 则跳过，若 `z=0` 则执行。

| 当前信念 b | 不观察：跳过 | 不观察：执行 | 观察的期望效用 | 最优 |
|---:|---:|---:|---:|---|
| 0.20 | 0.200 | 0.778 | 0.736 | 执行 |
| 0.40 | 0.400 | 0.778 | 0.791 | 观察 |
| 0.60 | 0.600 | 0.778 | 0.847 | 观察 |
| 0.80 | 0.800 | 0.778 | 0.902 | 观察 |
| 0.95 | 0.950 | 0.778 | 0.944 | 跳过 |

读法：**不确定时观察有价值；非常确定为真时不要浪费观察；非常确定/不确定到一定程度时执行更划算。** 完整系统把这张表推广到 DAG 的多谓词/多视角情形，用 §3.4 的期望 DP 成本替代单节点效用。

### 6.3 深度误差算例

§1.4 的表已经给出：头双目 0.5 m 处 15.2 mm/px；双腕 0.3 m 基线 1.9 mm/px（θ=90°），θ=30° 时 3.8 mm/px。这个算例是 WINGMAN 主动观察层的定量依据，也是 E0/E3 的门限来源：如果真实手眼标定/遮挡使双腕有效基线 <0.1 m 或 θ<20°，主动观察的收益会大幅缩水。

| 消融 | 任务图 / VOI / 修复 / 观察臂 | 各层贡献 |

通过标准（草案）：主动观察在 `single-arm metric` 相位把接触点深度误差降低 ≥30%，且总完成时间增加 ≤15%；人类编辑恢复率 ≥70%；碰撞/超时率 ≤5%。

### 7.5 E4：真机单任务 A/B（2 周）

选 5 个任务：PlugInEthernet（插入）、HangCup（挂）、ZipUp（拉链）、StackBowls（叠）、FoldTowel（变形，防回归）。

| 项 | 设计 |
|---|---|
| 次数 | 每任务 10 次配对 A/B（WINGMAN off/on）；同一初始条件 |
| 指标 | 成功率、步骤分、耗时、观察次数、p99 延迟 |
| 统计 | 配对差值 + bootstrap 95% CI；不把 +1–2pp 当结论 |
| 通过 | ≥3/5 任务 +10pp；FoldTowel 不回归 >5pp；观察臂碰撞 0 |
| 失败 | 不提交 WINGMAN；保留任务图信念/修复的被动版本 |

### 7.6 E5：全量干跑（1 周）

32×10 干跑；N 端口隔离、reset 干净、内存不涨、p99 ≤150 ms、观察臂不抢 GPU、无端口串扰。

### 7.7 门 G0–G7

| 门 | 问题 | 通过标准 | 失败动作 |
|---|---|---|---|
| G0 | 手眼/头外参可用？ | 重投影 ≤5 px；双腕有效基线 ≥0.15 m 的帧 ≥30% | 只用头双目/被动视角 |
| G1 | 任务图/谓词可信？ | AUROC ≥0.85；ECE ≤0.1；边支持度 ≥0.8 | 粗化任务图；只用官方步骤 |
| G2 | DP/VOI 正确？ | 对拍 0 不一致；计划对 p 扰动稳定 | 回退贪心/固定顺序 |
| G3 | 仿真观察有增益？ | 深度误差 −30%；时间 +≤15%；恢复 ≥70% | 关闭主动观察 |
| G4 | 真机单任务涨点？ | 3/5 +10pp；FoldTowel 不回归 | 不提交 WINGMAN |
| G5 | 延迟可接受？ | p99 ≤150 ms；timeout 不升 | 降低观察频率/分辨率 |
| G6 | 全量稳定？ | N 端口隔离；内存不涨；无串扰 | 回退 CHUNK-SERVO |
| G7 | 消融支持因果？ | 观察/修复/任务图各自有贡献 | 砍掉无贡献层 |

## 8. 风险、合规与回退

### 8.1 风险表

| 风险 | 影响 | 缓解 | 触发回退 |
|---|---|---|---|
| 第二臂遮挡/碰撞/拖慢 | 比不看更糟 | 碰撞检查、工作空间分离、只在 `single-arm metric` 相位移动 | 碰撞率 >5% 或时间 +>15% |
| 手眼外参误差 | 三角化/伺服偏差 | 一次性标定；重投影门限；协方差加权 | 重投影 >5 px |
| VLA 对观察臂 OOD | 动作质量下降 | 观察位姿从演示非执行臂分布采样；慢速；接触段保持 | 单任务退化 >5pp |
| 谓词假阳性 | 假完成/不修复 | 多视角+本体冲突；阈值滞回；修复预算 | 假完成率 >5% |
| `p_v` 未知 | DP 计划偏差 | 保守先验；单任务通道更新；敏感性分析 | 计划顺序频繁翻转 |
| 任务图错误 | 计划错误 | 人工校验；演示支持度；单任务通道 | 边支持度 <0.8 |
| 人类检测漏报 | 修复晚 | 多视角+本体+官方脚本先验 | human 轴不涨 |
| `pivot` 语义不一致 | 动作被拒/不动 | 先在 example_env/单任务通道验证；零 pivot 回退 | 任何异常 |
| 单模型合规 | 被判定第二模型 | 观察/规划确定性；可选 VLM 用同一 checkpoint；C1 回退 | 官方质疑 |

### 8.2 单模型合规

| 模式 | 做法 | 风险 | 建议 |
|---|---|---|---|
| C1 离线标注 | 任务图/VOI 只离线生成相位/评测集；线上只有 VLA + 被动验证 | 最低 | 保守回退 |
| C2 确定性控制器 | 观察/规划/修复全是几何、DP、控制律；VLA 是唯一学习模型 | 低 | 主推 |
| C3 同 checkpoint 特征 | 谓词查询用 WLA 同一 VLM checkpoint，不加载第二个模型 | 低–中 | 需要强语义时用 |

禁止：加载第二个学习策略/残差网络/独立视觉编码器做在线决策。观察臂的轨迹是 IK/碰撞检查生成的确定性轨迹，不是学习策略。

### 8.3 与前任的关系

| 前任 | 保留 | WINGMAN 增量 |

## 10. 一句话押注

**用 WLA 做动作意图，用官方评分步骤 + 33k 成功演示编译可验证的谓词任务图，用四路 RGB + 本体感觉维护子目标信念，把“看一眼”写成任务计划里的动作，并让空闲的第二只手臂在需要时变成宽基线观察者——在不新增学习模型的前提下，把“最后 3 厘米”先变成“确认该走哪 3 厘米”，再交给 CHUNK-SERVO 闭环。**

**最大风险一句话：第二臂为了“多看一眼”进入执行臂工作空间，可能遮挡/碰撞或把 VLA 拖出演示分布；若 G0/G3 的可见性增益不足或碰撞率 >5%，WINGMAN 必须退化为被动多视角验证 + 任务图修复，不再移动第二臂。**
