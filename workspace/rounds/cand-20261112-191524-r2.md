# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「共情表达」×「研究空白」）

> 第 60 轮把「执行层→证据层」的闭环升级为「认知驱动的场景-执行闭环」：SSM 把场景变成阻抗先验、CIEC 把意图变成实时约束、EPIR 保住 ROS 乱序下的证据链、SERC 统一闭环、PCE++++ 管四维认知预算。但**三个更深的结构性局限**仍未触及：
> 1. **「人」始终是约束源，而不是伙伴**：CIEC 把「请慢点/轻触」当作单向指令映射为约束，却没有建模**人的信任状态、情绪状态与理解状态**。信任是执行系统的隐变量——过度信任会让用户放弃监督、欠信任会让系统被弃用；而共情表达恰恰是**校准信任的控制信号**，前 60 轮把它当成了「输出装饰」，从未当成「控制量」。
> 2. **共情表达缺乏「证据接地」**：现有对话/多模态大模型能生成漂亮的情感话术，但在执行系统里，一句「我已经安全地轻触了」若与 EV-exec 证据不符，就是**情感幻觉**。共情必须被 EV-exec 约束，即「说出来的每一句安抚，都要有证据支撑」——这正是前 60 轮「证据接地」思想尚未延伸到人机界面之处。
> 3. **「研究空白」在系统内不可见**：前 60 轮不断新增能力，却没有任何机制回答「**我们还没在哪些场景×意图×阻抗区域验证过**」。证据密度低的区域是**认知空白**，系统对空白无感知、无主动填补，导致「证据层自信、空白区裸奔」——这本身就是当前研究最大的方法论空白。

## 0. 直觉与动机

**灵感 1（共情表达 → 证据接地的共情表达模型 EEM）**
直觉：共情不是「说好听的话」，而是**在正确时刻、用正确强度、说出与事实相符的理解**。三个要素缺一不可：内容（我理解你担心什么）、时机（在执行前后、风险前后）、强度（α 与用户情绪匹配，过度共情是操纵、不足共情是冷漠）。关键洞见：**把共情表达建成一个「证据→表达」的可验证映射 g: EV-exec × scene × intent → X**，表达中的每个断言 c 都带支撑集 supp(c)；若 conf(supp(c)) < τ_ground，则禁止输出该断言。这样「共情」第一次变成**可审计、可证伪的执行输出**，而不是话术。

**灵感 2（研究空白 → 认知空白检测器 EGD）**
直觉：研究空白 = 「证据没覆盖到的流形区域」。把场景×意图×阻抗张成流形 M = Z_scene × I_intent × K，用历史 EV-exec 在 M 上累计证据密度 ρ(m)，用后验方差 U(m) 表示不确定性。**空白分 G(m) = exp(−ρ(m))·U(m)**：既没人验证过（ρ 低）、又很不确定（U 高）的格子，就是「研究空白」。关键洞见：**系统应主动去「最空白且可安全到达」的地方做低力探测**，把「我不知道我不知道」变成「我知道哪里不知道，并去补上」。

**灵感 3（两灵感合流 → 共情-信任-空白闭环 EAGL）**
直觉：共情表达是输入，信任是状态，空白是地图。三者在同一个环里：EEM 依据 EV-exec 产出可信共情 → 共情表达调制用户信任 T_t → TSM 估计信任并与真实可靠度 R_t 比对得到校准误差 → 若过信任则加「谨慎表达+保守阻抗」，若欠信任则加「透明表达+证据展示」 → EGD 指出证据空白 → 主动探测回填 ρ → 新的 EV-exec 又成为下一轮共情的证据。形成 **场景→意图→执行→证据→共情→信任→空白→探测→证据** 的人-机双闭环。

**灵感 4（PCE+++++ → 五维预算与「共情/空白」降级）**
直觉：共情表达和空白探测都要花预算，且都有「越界即危险」的性质。新增 B_emp（表达时延、接地校验开销、情绪推断算力）与 B_gap（探测预算、空白模型更新、探索比例）。若 B_emp 耗尽 ⇒ 进入「静默执行」：只保留安全关键表达（如「正在停止」），关闭寒暄式共情；若 B_gap 耗尽 ⇒ 进入「只利用不探索」：停止主动探测，用保守先验。**共情与探索都必须能被预算关掉**，否则它们是新的失控源。

**灵感 5（面向 UniBot 竞赛的落点）**
直觉：竞赛里评委/用户看到的是「机器人懂不懂我、可不可信」。EAGL 直接对应三个可演示指标：①共情表达不吹牛（TEC 接地率）；②用户信任被校准（过信任/欠信任事件下降）；③系统能自报「我还没验证过 X 场景」（空白地图可视化）。这比再堆一层控制算法更容易形成**可感知的创新点**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（共情表达空间 EES 与证据接地）** 共情表达模型 E = (X, g, Ground, α)。其中：
- **表达空间**：X = X_verb × X_behav × X_param，分别为语言表达（「我理解你担心夹到手指」）、行为线索（减速、停顿、回撤）、参数调整（K_p↓、v_max↓）。
- **接地映射**：g: (EV-exec, z_scene, I_intent) → X，把执行证据、场景、意图映射为表达。
- **断言支撑**：表达 x 中的每个断言 c 带支撑集 supp(c) ⊆ EV-exec ∪ {scene_conf, K_certainty}；接地谓词 Ground(x) = ∧_{c∈x} [ conf(supp(c)) ≥ τ_ground ]。
- **强度校准**：α(x) = clip(âffect_est · κ_match, 0, α_max)，其中 âffect_est 为用户情绪估计，κ_match 为内容-情绪匹配度；要求 |α(x) − âffect_est| ≤ δ_emp，防止「过度共情=操纵」与「共情缺失=冷漠」。
- **安全优先**：若 x 与安全约束冲突（如「没关系，可以继续」但 K_safe 判定危险），强制 x 退化为安全表达。

**定义 162（信任状态模型 TSM）** 人的信任 T_t ∈ [0,1] 为隐状态：
- **观测**：z_t = (对话情感极性、响应时延、人工接管频率、注视/点头等可用线索) → 观测模型 P(z_t | T_t)。
- **动力学**：T_{t+1} = f(T_t, x_t, o_t)，其中 x_t 为共情表达、o_t ∈ {success, failure} 为执行结果；共情表达通过「被理解感」提高信任增益，失败通过「证据一致性」缓冲信任崩塌。
- **可靠性真值**：R_t = P(success | 当前场景-阻抗-意图)，可由历史 EV-exec 经验估计。
- **校准误差**：e_trust(t) = |T_t − R_t|；**过信任**当 T_t > R_t + δ_T（危险：用户放弃监督），**欠信任**当 T_t < R_t − δ_T（浪费：系统被弃用）。
- **目标**：min E[e_trust]，而非 max T——共情的目标是「让信任匹配真实能力」，不是「让人更喜欢机器人」。

**定义 163（认知空白/研究空白 EGD）** 流形 M = Z_scene × I_intent × K_impedance，离散化为格子 m：
- **证据密度**：ρ(m) = N_evidence(m) / N_max，由历史 EV-exec 统计。
- **不确定性**：U(m) = tr(Σ_posterior(m))（该格阻抗后验方差）。
- **空白分**：G(m) = exp(−ρ(m)) · U(m) ∈ [0,1]。
- **研究空白集**：R_gap = { m : G(m) ≥ τ_gap ∧ reachable_safe(m) }。
- **探测选择**：m* = argmax_{m∈R_gap} G(m) / cost_probe(m)，cost_probe 含时间、力、风险成本。
- **空白覆盖度**：Cov(M) = Σ_m 1[ρ(m) ≥ ρ_min] / |M|，作为方法论层面的「研究进度」度量。

**定义 164（共情-信任-空白闭环 EAGL）** 算子 EAGL(M, scene, intent, dialogue, δ_f_req)：
```
① SERC: (z_scene, K_scene, EV_exec, Cert_eeis) ← SERC(M, scene, intent, δ_f_req)
② Affect: âffect_est ← M.affect.estimate(dialogue, EV_exec)
③ Trust: T ← M.trust.observe(dialogue, behavior)；regime ← M.trust.regime(R_t)
④ Empathy: x ← E.express(EV_exec, z_scene, intent, âffect_est)；若 ¬Ground(x) 则删断言
⑤ Gap: R_gap ← EGD.research_gaps(reachable_safe)
⑥ Probe: if R_gap ≠ ∅ ∧ B_gap 充足: m* ← EGD.select_probe；M ← safe_probe(M, m*)
⑦ Joint: 依据 regime 联合调整 (x, K)：OVER_TRUST→(谨慎表达, K_conservative)；UNDER_TRUST→(透明表达, K_scene)
⑧ Cert: TEC ← build_trust_evidence_cert(x, T, Cov(M), Cert_eeis)
⑨ Return: (M, K, x, TEC, R_gap)
```

**定义 165（五维预算 B_emp/B_gap 与 PCE+++++）** B = (B_scene, B_intent, B_ros, B_exec, B_emp, B_gap)。其中：
- **B_emp** = (Expression_latency, Grounding_verification_cost, Affect_inference_budget)
- **B_gap** = (Probe_budget, Gap_model_update_rate, Exploration_ratio)
- **扩展 VOI**：
```
voi_eagl(π) = VOI_meta_pessimistic(π) − cost_cog(π) − cost_exec(π) − cost_emp(π) − cost_gap(π)
cost_emp = λ_ground·Grounding_cost(x) + λ_lat·max(0, Latency(x) − τ_emp)
cost_gap = λ_probe·Probe_cost(m*) + λ_risk·Risk(m*)
```
- **降级**：B_emp < θ_emp ⇒ 静默执行（仅安全关键表达）；B_gap < θ_gap ⇒ 只利用不探索；其余同第 60 轮。

**定义 166（信任-证据证书 TEC）** TEC = (grounding_rate, e_trust, gap_coverage, overclaim_count)。校验：
- **接地性**：grounding_rate = |{c: conf(supp(c)) ≥ τ_ground}| / |{c}| ≥ 1 − ε_overclaim；
- **校准性**：e_trust ≤ δ_T；
- **空白单调性**：Cov_{t+1}(M) ≥ Cov_t(M)（探测不得让覆盖度倒退）；
- **可审计**：每个断言 c ↦ (supp(c), conf) 可回放。
TEC 与第 60 轮 J_exec 组合成 **J_human = J_exec ∧ TEC**，只有「执行合规 ∧ 共情诚实 ∧ 信任校准」才允许对外宣称成功。

**定义 167（空白导向主动探测 GAP-Probe）** 在安全包络 E_safe = {执行参数 : 预测力/速度 < 安全阈值} 内做低力探测：
- **采样**：以 G(m) 为权重做 Thompson/UCB 采样，优先覆盖 R_gap；
- **安全闸**：probe 的预测接触力 F_pred ≤ F_probe_max，且失败可无伤回撤；
- **收敛**：每次探测更新 ρ(m) 与 U(m)，理论上 G(m*) 随探测次数单调下降（在平稳场景假设下）。
- **研究空白报告**：系统可输出「尚未验证区域清单」，作为对研究者/评委的**方法论自省产物**。

**定义 168（共情-信任-空白联合决策 HTD）** 给定 (regime, R_gap, B)，决策规则：
```
if regime == OVER_TRUST:
    x ← x.with_caution(EV_exec)；K ← K_conservative
elif regime == UNDER_TRUST:
    x ← x.with_transparency(EV_exec)；K ← K_scene
else:
    x ← x；K ← K_scene

if R_gap ∩ M_critical ≠ ∅ and B_gap 充足:
    schedule safe_probe
elif R_gap ∩ M_critical ≠ ∅ and B_gap 耗尽:
    x ← x.with_unknown_disclosure()   # 主动告知「该区域未验证」，用不确定性表达替代冒险探索
```
关键：**当空白无法被填补时，共情表达转为「诚实披露不确定性」**——宁可说「这里我没把握」，也不假装可靠。

## 2. 关键算法伪代码

### IP-161 EEM（证据接地的共情表达）

```python
class EmpathicExpressionModel:
    def __init__(self, tau_ground=0.8, alpha_max=0.8, delta_emp=0.2):
        self.tau_ground = tau_ground
        self.alpha_max = alpha_max
        self.delta_emp = delta_emp

    def express(self, ev_exec, scene_dist, intent, affect_est):
        claims = self._derive_claims(ev_exec, scene_dist, intent)
        grounded = [(c, s) for c, s in claims
                    if self._support_conf(s) >= self.tau_ground]
        dropped = len(claims) - len(grounded)
        alpha = min(self.alpha_max, affect_est * self._match(grounded, intent))
        return EmpathicExpr(claims=grounded, intensity=alpha,
                            overclaim=dropped, safe=self._safe_check(grounded))

    def _derive_claims(self, ev_exec, scene_dist, intent):
        return [
            ("我理解你担心接触力过大", {'F_peak': ev_exec.F_peak}),
            ("当前接触力在安全范围内", {'F_peak': ev_exec.F_peak,
                                       'F_max': ev_exec.K_safe.F_max}),
            ("场景是" + scene_dist.top_scene, {'scene_conf': scene_dist.conf}),
        ]

    def _support_conf(self, support):
        return min(getattr(v, 'conf', 1.0) if not isinstance(v, float) else v
                   for v in support.values())
```

### IP-162 TSM（信任状态建模）

```python
class TrustStateModel:
    def __init__(self, alpha=0.5, beta=0.3, delta_T=0.15):
        self.T = 0.5
        self.alpha, self.beta, self.delta_T = alpha, beta, delta_T
        self.e_trust = 0.0

    def observe(self, dialogue_feat, behavior_feat):
        z = self._encode(dialogue_feat, behavior_feat)
        self.T = self._bayes_update(self.T, z)
        return self.T

    def update(self, expr, outcome, reliability):
        gain = expr.intensity * expr.grounding_rate
        self.T = clip(self.T + self.alpha * (outcome - self.T)
                      + self.beta * gain * (outcome - self.T), 0, 1)
        self.e_trust = abs(self.T - reliability)

    def regime(self, reliability):
        if self.T > reliability + self.delta_T: return 'OVER_TRUST'
        if self.T < reliability - self.delta_T: return 'UNDER_TRUST'
        return 'CALIBRATED'
```

### IP-163 EGD（认知空白检测）

```python
class EpistemicGapDetector:
    def __init__(self, tau_gap=0.7, rho_min=0.05):
        self.density = defaultdict(int)
        self.uncertainty = {}
        self.tau_gap, self.rho_min = tau_gap, rho_min

    def observe(self, scene, intent, K, post_var):
        m = self._cell(scene, intent, K)
        self.density[m] += 1
        self.uncertainty[m] = post_var

    def gap_score(self, m):
        rho = self.density[m] / max(self.max_density(), 1)
        U = self.uncertainty.get(m, 1.0)
        return math.exp(-rho) * U

    def research_gaps(self, reachable_safe):
        return [m for m in reachable_safe if self.gap_score(m) >= self.tau_gap]

    def select_probe(self, reachable_safe, cost_fn):
        return max(reachable_safe,
                   key=lambda m: self.gap_score(m) / max(cost_fn(m), 1e-6))

    def coverage(self):
        cells = set(self.density)
        covered = {m for m in cells
                   if self.density[m] / max(self.max_density(), 1) >= self.rho_min}
        return len(covered) / max(len(cells), 1)
```

### IP-164 EAGL（共情-信任-空白闭环）

```python
def empathic_trust_gap_loop(M, scene, intent, dialogue, delta_f_req):
    z, K_scene, EV_exec, cert = serc_step(M, scene, intent, delta_f_req)

    affect = M.affect.estimate(dialogue, EV_exec)
    T = M.trust.observe(dialogue, M.behavior)
    regime = M.trust.regime(cert.reliability)

    expr = M.eem.express(EV_exec, z, intent, affect)
    if not expr.safe:
        expr = expr.with_safety_override()

    gaps = M.egd.research_gaps(M.reachable_safe())
    if gaps and M.budget.gap_available():
        m_star = M.egd.select_probe(gaps, M.cost_probe)
        M = safe_probe(M, m_star)

    if regime == 'OVER_TRUST':
        expr = expr.with_caution(EV_exec); K = conservative(K_scene)
    elif regime == 'UNDER_TRUST':
        expr = expr.with_transparency(EV_exec); K = K_scene
    else:
        K = K_scene

    tec = build_trust_evidence_cert(expr, T, M.egd.coverage(), cert)
    return M, K, expr, tec, gaps
```

### IP-165 PCE+++++（五维预算）

```python
class EmpathicGapBudget:
    def __init__(self, emp_ops=40, gap_probes=5, exec_budget=None):
        self.B_emp, self.B_gap = emp_ops, gap_probes
        self.ops_emp, self.ops_gap = 0, 0
        self.B_exec = exec_budget or ExecBudget()

    def emp_available(self):
        return self.ops_emp < self.B_emp

    def gap_available(self):
        return self.ops_gap < self.B_gap

    def emp_mode(self):
        return 'expressive' if self.emp_available() else 'silent_safety_only'

    def gap_mode(self):
        return 'explore_exploit' if self.gap_available() else 'exploit_only'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| EEM | O(|claims|·|supp|) 每条表达 | O(claims) | 接地率 ≥ 1−ε_overclaim，情感幻觉率 ≤ 1% |
| TSM | O(1) 观测更新 | O(1) | 信任校准误差 e_trust ≤ δ_T，过信任检出 ≥ 90% |
| EGD | O(|M|) 空白扫描 / O(|R_gap|) 选点 | O(|M|) | 覆盖度单调不降，探测风险 ≤ F_probe_max |
| EAGL | O(SERC + |M|) | 复用 + O(|M|) | 联合证书 J_human 通过 |

**正确性定理（EAGL）**：假设 A22–A70 成立；新增 **(A66)** EEM 的每个断言支撑集可回放且 conf 有界；**(A67)** TSM 观测模型可辨识，信任动力学在有界输入下稳定；**(A68)** EGD 的流形离散化有限、reachable_safe 可判定；**(A69)** GAP-Probe 在安全包络内且失败可回撤；**(A70)** B_emp/B_gap 单调消耗，耗尽即触发静默/只利用策略。则：
1. **共情诚实性**：任何通过 TEC 的对外表达，其接地率 ≥ 1−ε_overclaim（无情感幻觉）。
2. **信任校准性**：EAGL 闭环下 e_trust 有界且随交互下降；过信任触发保守化，欠信任触发透明化。
3. **空白可解释性**：系统能枚举 R_gap，且 Cov(M) 在探测预算内单调提升；预算耗尽时转为「不确定性披露」而非冒险。
4. **人-机双闭环安全**：J_human = J_exec ∧ TEC，任一分量为假即拒绝宣称成功。

### IP-161 EEM（证据接地的共情表达）

```python
class EmpathicExpressionModel:
    def __init__(self, tau_ground=0.8, alpha_max=0.8, delta_emp=0.2):
        self.tau_ground = tau_ground
        self.alpha_max = alpha_max
        self.delta_emp = delta_emp

    def express(self, ev_exec, scene_dist, intent, affect_est):
        claims = self._derive_claims(ev_exec, scene_dist, intent)
        grounded = [(c, s) for c, s in claims
                    if self._support_conf(s) >= self.tau_ground]
        dropped = len(claims) - len(grounded)
        alpha = min(self.alpha_max, affect_est * self._match(grounded, intent))
        return EmpathicExpr(claims=grounded, intensity=alpha,
                            overclaim=dropped, safe=self._safe_check(grounded))

    def _derive_claims(self, ev_exec, scene_dist, intent):
        return [
            ("我理解你担心接触力过大", {'F_peak': ev_exec.F_peak}),
            ("当前接触力在安全范围内", {'F_peak': ev_exec.F_peak,
                                       'F_max': ev_exec.K_safe.F_max}),
            ("场景是" + scene_dist.top_scene, {'scene_conf': scene_dist.conf}),
        ]

    def _support_conf(self, support):
        return min(getattr(v, 'conf', 1.0) if not isinstance(v, float) else v
                   for v in support.values())

    def _safe_check(self, grounded):
        return all(not self._contradicts_safety(c) for c, _ in grounded)
```

### IP-162 TSM（信任状态建模）

```python
class TrustStateModel:
    def __init__(self, alpha=0.5, beta=0.3, delta_T=0.15):
        self.T = 0.5
        self.alpha, self.beta, self.delta_T = alpha, beta, delta_T
        self.e_trust = 0.0

    def observe(self, dialogue_feat, behavior_feat):
        z = self._encode(dialogue_feat, behavior_feat)
        self.T = self._bayes_update(self.T, z)
        return self.T

    def update(self, expr, outcome, reliability):
        gain = expr.intensity * expr.grounding_rate
        self.T = clip(self.T + self.alpha * (outcome - self.T)
                      + self.beta * gain * (outcome - self.T), 0, 1)
        self.e_trust = abs(self.T - reliability)

    def regime(self, reliability):
        if self.T > reliability + self.delta_T: return 'OVER_TRUST'
        if self.T < reliability - self.delta_T: return 'UNDER_TRUST'
        return 'CALIBRATED'
```

### IP-163 EGD（认知空白检测）

```python
class EpistemicGapDetector:
    def __init__(self, tau_gap=0.7, rho_min=0.05):
        self.density = defaultdict(int)
        self.uncertainty = {}
        self.tau_gap, self.rho_min = tau_gap, rho_min

    def observe(self, scene, intent, K, post_var):
        m = self._cell(scene, intent, K)
        self.density[m] += 1
        self.uncertainty[m] = post_var

    def gap_score(self, m):
        rho = self.density[m] / max(self.max_density(), 1)
        U = self.uncertainty.get(m, 1.0)
        return math.exp(-rho) * U

    def research_gaps(self, reachable_safe):
        return [m for m in reachable_safe if self.gap_score(m) >= self.tau_gap]

    def select_probe(self, reachable_safe, cost_fn):
        return max(reachable_safe,
                   key=lambda m: self.gap_score(m) / max(cost_fn(m), 1e-6))

    def coverage(self):
        cells = set(self.density)
        covered = {m for m in cells
                   if self.density[m] / max(self.max_density(), 1) >= self.rho_min}
        return len(covered) / max(len(cells), 1)
```

def empathic_trust_gap_loop(M, scene, intent, dialogue, delta_f_req):
    z, K_scene, EV_exec, cert = serc_step(M, scene, intent, delta_f_req)

    affect = M.affect.estimate(dialogue, EV_exec)
    T = M.trust.observe(dialogue, M.behavior)
    regime = M.trust.regime(cert.reliability)

    expr = M.eem.express(EV_exec, z, intent, affect)
    if not expr.safe:
        expr = expr.with_safety_override()

    gaps = M.egd.research_gaps(M.reachable_safe())
    if gaps and M.budget.gap_available():
        m_star = M.egd.select_probe(gaps, M.cost_probe)
        M = safe_probe(M, m_star)
    elif gaps and not M.budget.gap_available():
        expr = expr.with_unknown_disclosure(gaps)

        expr = expr.with_caution(EV_exec); K = conservative(K_scene)

class EmpathicGapBudget:
    def __init__(self, emp_ops=40, gap_probes=5, exec_budget=None):
        self.B_emp, self.B_gap = emp_ops, gap_probes
        self.ops_emp, self.ops_gap = 0, 0

        return self.ops_emp < self.B_emp

    def gap_available(self):

    def emp_mode(self):
        return 'expressive' if self.emp_available() else 'silent_safety_only'

def build_trust_evidence_cert(expr, T, coverage, cert_eeis):
    grounding_rate = len(expr.claims) / max(len(expr.claims) + expr.overclaim, 1)
    tec = TrustEvidenceCert(
        grounding_rate=grounding_rate,
        e_trust=abs(T - cert_eeis.reliability),
        gap_coverage=coverage,

**正确性定理（EAGL）**：若 A66–A70 成立，则：
1. 通过 TEC 的对外表达无情感幻觉（grounding_rate ≥ 1−ε_overclaim）。
2. EAGL 闭环下信任校准误差 e_trust 有界；过信任触发保守化、欠信任触发透明化。
3. 系统可枚举 R_gap；探测预算内 Cov(M) 单调提升，耗尽时转为不确定性披露。
4. J_human = J_exec ∧ TEC，任一分量为假即拒绝宣称成功。
