# 第 62 轮（承接第 61 轮 ESEC；灵感循环第 1 轮；本轮灵感：「创新点」×「多任务学习」）

> 第 61 轮 ESEC 用 USR×MEL×DMS×SRT-Dual×PCE+++++ 把「场景语义、意图语义、物理先验、执行证据」统一到语义流-实时流双流闭环，解决了「模块拼接」与「大模型-实时控制时序鸿沟」。但**四个训练层局限**仍未触及：
> 1. **模块独立训练导致表征割裂**：USR 的对齐损失是部署后的后验修补，MEL、DMS、EEIS、XMC+++ 各自优化自己的目标，**没有在训练阶段共享统计强度**；数据稀缺任务（零样本物理属性、罕见对话意图）无法从数据丰富任务（场景分类、视觉描述）中获益。
> 2. **朴素多任务学习的负迁移与安全塌陷**：若把 7 个任务简单塞进一个 backbone，任务梯度冲突会让平均性能上升、**安全任务（力超限/滑移）却被平均掉**；现有 MTL 方法（PCGrad、CAGrad、不确定性加权）都无法表达「安全是硬约束而非普通损失」。
> 3. **「创新点」不可证伪**：第 61 轮列出 10 个 IP，但无法回答「去掉 IP-176 性能掉多少」「两个 IP 是否冗余」「哪个 IP 在什么任务上真正有贡献」。创新点停留在叙事层，**缺少边际贡献的因果度量与置信区间**。
> 4. **任务收益随分布漂移而变化**：辅助任务并非永久有益；新材质、新对话风格、新 ROS 拓扑会让原本正迁移的任务转为负迁移，**固定任务权重与固定网络结构无法自适应**。

## 0. 直觉与动机

**灵感 1（多任务学习 → 任务依赖感知的共享-专用网络 TDG-TSN）**
直觉：第 61 轮的 USR、MEL、DMS 像「七个专家各学一门语言，再靠翻译器拼接」。多任务学习的关键不是「共享一个 backbone」这么简单，而是**任务之间存在物理因果依赖**：场景→物理属性→阻抗→安全；意图→对话→约束；执行证据→阻抗→安全。若把依赖关系写进网络（父任务的中间表征作为子任务的输入），共享层被迫学习「因果中间量」而不是「表面相关性」，从而同时缓解语义割裂与负迁移。共享主干提供统计强度，任务专用低秩适配器保留异质性，依赖边则提供归纳偏置。

**灵感 2（创新点 → 可计量的创新贡献账本 ICL）**
直觉：第 61 轮的 IP 是「并列宣称」，缺少「反事实」。把每个创新点视为对任务子集的一次干预，用 Shapley 值或留一消融估计其边际贡献，就能把「创新点」从叙事变成**可证伪的因果声明**：贡献的置信区间不跨零才保留，否则降级为「待验证假设」。这直接回应「创新点」这一灵感词——**创新点不是列出来的，而是测出来的**。

**灵感 3（安全约束下的多任务优化 SCLO）**
直觉：多任务学习最危险的失败不是平均性能下降，而是**安全任务被平均掉**——为了提升抓取速度而牺牲力超限约束。因此安全不能作为普通损失项与性能任务做标量加权，而应作为**字典序硬约束**：先进入安全可行域，再在可行域内优化多任务性能；梯度冲突时做安全锥投影，而不是简单调大 λ_safe。

**灵感 4（跨任务伪标签与不确定性门控 CTPD）**
直觉：物理属性标注昂贵，但场景、证据、对话数据相对充足。让高置信的父任务预测给子任务当伪标签，相当于「用已会的任务教不会的任务」；但必须用不确定性门控与一致性检验，防止「自信的错误」在任务间传播。

**灵感 5（动态任务组合 DTP + 六维预算）**
直觉：不是所有辅助任务都长期有益。用 bandit/UCB 维护「活跃任务集」，把 PCE+++++ 的预算分配给边际贡献为正的任务，实现**任务层面的 VOI**：当某任务从正迁移转为负迁移，自动降权、隔离或剪枝。

**灵感 6（MT-ESEC 总闭环）**
直觉：第 61 轮 ESEC 是「语义流-实时流」的部署闭环；本轮在训练层加入多任务共享基座，在部署层保留安全字典序与双流解耦，形成**「训练多任务协同、部署安全约束兜底、创新贡献可审计」**的三层结构。

## 1. 形式化定义（增量：定义 173–182）

**定义 173（任务依赖图 TDG）** 任务依赖图 G_T = (T, E, Pa, T_safe, ≺)。其中：
- **任务集** T = {τ_scene, τ_phys, τ_intent, τ_impedance, τ_evidence, τ_dialogue, τ_safety}，分别对应场景语义、物理属性、意图信念、阻抗编译、执行证据、对话管理、安全约束。
- **依赖边** E ⊆ T×T，取 E = {(scene,phys), (phys,impedance), (intent,dialogue), (evidence,impedance), (impedance,safety), (dialogue,safety), (phys,safety)}。
- **父任务函数** Pa(τ) = {τ' : (τ',τ) ∈ E}；G_T 必须无环，≺ 为其任一拓扑序。
- **安全任务集** T_safe = {τ_safety}，其损失不参与标量加权，而进入字典序约束。
- **数据分布** 每个任务 i 有 D_i，允许半监督/无标签；任务间标签空间不必相同。

**定义 174（共享-专用任务网络 TSN）** TSN = (f_θ, {a_i}, {h_i}, Φ)。其中：
- **共享主干** f_θ: X → ℝ^d_z，所有任务共享，承担统计强度与跨任务泛化。
- **任务适配器** 对任务 i，a_i 以自身表征与父任务表征为输入：
  ```
  a_i(z; {z_j}_{j∈Pa(i)}) = z + U_i σ(V_i [z ; mean_{j∈Pa(i)} P_{ij} z_j])
  ```
  其中 U_i ∈ ℝ^{d_z×r}, V_i ∈ ℝ^{r×(d_z+|Pa(i)|d_z)}，r ≪ d_z 为低秩瓶颈；根任务去掉父任务项。
- **任务头** h_i: ℝ^{d_z} → Y_i，输出任务预测；z_i = h_i(a_i(f_θ(x), {z_j}_{j∈Pa(i)}))。
- **参数划分** 共享参数 θ，专用参数 Φ = {U_i, V_i, P_{ij}, ψ_i}；共享参数承担迁移，专用参数承担异质性与安全隔离。

**定义 175（依赖感知多任务目标 DAMTL）**
```
L_MT(θ,Φ) = Σ_{i∈T\T_safe} λ_i L_i(θ,Φ_i)
          + λ_dep Σ_{(i,j)∈E, j≠safety} ||P_{ij} z_i - z_j||²
          + λ_cal Σ_i L_cal,i
```
其中 λ_i = 1/(2σ_i²)，σ_i 为可学习任务不确定性；L_dep 迫使子任务表征「可由父任务预测」，抑制依赖链上的语义漂移；L_cal 为校准损失。安全任务 τ_safety 不进入 L_MT，而进入定义 176 的约束。

**定义 176（安全字典序约束优化 SCLO）** 令性能损失 L_perf = L_MT，安全风险
```
C_safe(θ,Φ) = E_x[max(0, Risk(x;θ,Φ) - κ_safe)] + λ_u E_x[U_safety(x)]
```
可行域 K = {Θ : C_safe(Θ) ≤ 0}。优化问题为字典序：
```
Θ* ∈ argmin_{Θ∈K} L_perf(Θ),  若 K=∅ 则先 argmin C_safe(Θ)
```
梯度更新：令 g_p = ∇L_perf，g_s = ∇C_safe。
- 若 C_safe > 0：沿 -g_s 方向恢复可行性（可加信赖域）；
- 若 C_safe ≤ 0 且 ⟨g_p, g_s⟩ < 0：投影 g_p ← g_p - (⟨g_p,g_s⟩/||g_s||²) g_s；
- 否则直接使用 g_p。
该规则保证安全下降方向不被性能任务抵消，是「安全锥投影」而非标量惩罚。

**定义 177（创新贡献账本 ICL）** 把创新点集合 I = {I_1,…,I_m} 与任务集 T 组成合作博弈 (T, v)，价值函数 v(S) = F(MT-ESEC 仅在任务子集 S 上训练) - F(∅)。任务 i 的 Shapley 贡献：
```
φ_i(v) = Σ_{S⊆T\{i}} |S|!(|T|-|S|-1)!/|T|! · [v(S∪{i}) - v(S)]
```
对创新点 I_m，定义干预价值 v_m(S) = F(启用 I_m 的 MT-ESEC 在 S 上训练) - F(禁用 I_m 的 MT-ESEC 在 S 上训练)，其 Shapley 值 Δ_m = φ(v_m)。账本条目：
```
L_I(I_m) = (Δ_m, CI_95(Δ_m), 关联任务子集 S_m, 消融协议, 证据哈希)
```
决策规则：若 CI_95(Δ_m) 的下界 > 0，则 I_m 记为「已验证创新点」；若 CI 跨零，记为「待验证假设」；若上界 < 0，记为「负贡献，降级或删除」。

**定义 178（动态任务组合 DTP）** 第 r 轮维护活跃集 A_r ⊆ T。任务 i 的边际效用 u_i = Δ_i - cost_i，其中 cost_i 来自 PCE+++++ 的六维预算。用 UCB/LCB：
```
LCB_δ(Δ_i) = Δ̂_i - β sqrt(Var(Δ̂_i) / n_i)
A_{r+1} = {i : LCB_δ(Δ_i) > 0} ∪ T_required
```
其中 T_required = {τ_safety, τ_impedance} 为安全与执行必需任务，永不被剪枝。预算分配采用注水：
```
b_i ∝ max(0, Δ̂_i - cost_i),  Σ_i b_i ≤ B_cog5
```
并以 ε 概率探索被剪枝任务，防止分布漂移后错过重新激活的机会。

**定义 179（跨任务伪标签蒸馏 CTPD）** 对依赖边 (i,j) ∈ E，若标签空间存在映射 M_{ij}: Y_i → Y_j，且父任务置信度 c_i(x) ≥ τ_i，则
```
L_pseudo = Σ_{(i,j)∈E} E_x[ c_i(x) · d(h_j(x), sg(M_{ij}(f_i(x)))) · 1(c_i(x)≥τ_i) ]
```
若标签空间不可映射，则退化为表征级蒸馏：
```
L_repr = Σ_{(i,j)∈E} E_x[ c_i(x) · ||z_j - sg(P_{ij} z_i)||² ]
```
sg(·) 为 stop-gradient；c_i 由定义 180 的校准后置信度给出，避免「自信错误」传播。

**定义 180（多任务不确定性校准 MUC）** 对每个任务 i，学习温度 T_i，使校准后概率 p_i = softmax(h_i/T_i) 满足 ECE_i ≤ ε_ECE；对安全任务使用保形风险控制：
```
P(Risk(x) ≤ κ_safe) ≥ 1 - α_safe,  α_safe ≤ 1e-3
```
校准结果同时驱动 CTPD 的置信门控、DTP 的贡献置信区间、以及 SCLO 的安全裕度。

**定义 181（任务干扰度量与负迁移证书 TIM）** 对任务 i,j：
```
ρ_ij = ⟨g_i, g_j⟩ / (||g_i|| ||g_j||)
NT_ij = R_j(Θ_MT) - R_j(Θ_j^single)
```
其中 g_i 为任务 i 的梯度，R_j 为任务 j 的风险。若 ρ_ij < -ρ_0 且 NT_ij > δ_NT，则签发「冲突证书」，触发适配器隔离、任务剪枝或依赖边重估。证书写入 ICL，作为创新点负贡献的证据。

**定义 182（MT-ESEC 总闭环）** MT-ESEC = (TDG, TSN, DAMTL, SCLO, ICL, DTP, CTPD, MUC, TIM) ∘ ESEC。训练与部署流程：
1. 依据领域知识构建 TDG，冻结安全子图；
2. 用 DAMTL + CTPD 在全部任务上多任务预训练；
3. 用 SCLO 做安全约束微调，保证 C_safe ≤ 0；
4. 用 ICL 估计各任务/各创新点的 Shapley 贡献与置信区间；
5. 用 DTP 剪枝负贡献任务，重分配 B_cog5 预算；
6. 部署时复用第 61 轮 ESEC 的 USR 语义锚点与 SRT-Dual 双流；
7. 在线用 TIM 监控梯度冲突与负迁移，周期性回到步骤 3–5。

### IP-183 TDG（任务依赖图构建）

```python
def build_task_graph(domain_spec):
    T = {scene, phys, intent, impedance, evidence, dialogue, safety}
    E = [(scene, phys), (phys, impedance), (intent, dialogue),
         (evidence, impedance), (impedance, safety),
         (dialogue, safety), (phys, safety)]
    assert is_dag(T, E)
    return TaskDependencyGraph(T, E, safe_tasks={safety})
```

### IP-184 TSN（共享-专用网络）
```python
class TaskSharedNetwork(nn.Module):
    def forward(self, x, graph):
        z = self.shared_trunk(x)
        zs = {}
        for task in graph.topological_order():
            parents = [zs[p] for p in graph.parents(task)]
            zs[task] = self.adapters[task](z, parents)
        return {t: self.heads[t](zs[t]) for t in graph.tasks()}
```

### IP-185 DAMTL（依赖感知多任务损失）
```python
def damtl_loss(outputs, targets, graph, log_sigma):
    loss = 0
    for t in graph.performance_tasks():
        lam = 1 / (2 * torch.exp(2 * log_sigma[t]))
        loss += lam * task_losses[t](outputs[t], targets[t])
    for (i, j) in graph.performance_edges():
        loss += LAMBDA_DEP * mse(P[i, j](outputs.z[i]), outputs.z[j])
    return loss + LAMBDA_CAL * calibration_loss(outputs)
```

### IP-186 SCLO（安全字典序优化）
```python
def sclo_step(params, g_perf, g_safe, c_safe, eta):
    if c_safe > 0:
        return params - eta * g_safe
    inner = (g_perf * g_safe).sum()
    if inner < 0:
        g = g_perf - inner / (g_safe.norm() ** 2 + 1e-8) * g_safe
    else:
        g = g_perf
    return params - eta * g
```

### IP-187 ICL（创新贡献账本）
```python
def innovation_shapley(innovation, tasks, value_fn, M=200):
    diffs = []
    for _ in range(M):
        perm = random_permutation(tasks)
        for k, task in enumerate(perm):
            S = set(perm[:k])
            diffs.append(value_fn(innovation, S | {task}) -
                         value_fn(innovation, S))
    delta = mean(diffs)
    ci = bootstrap_ci(diffs, n_boot=1000)
    return delta, ci
```

### IP-188 DTP（动态任务组合）
```python
def update_portfolio(ledger, budget, rng):
    active = set()
    for task in ledger.tasks():
        if ledger.lcb(task) > 0 or task in REQUIRED_TASKS:
            active.add(task)
        elif rng.random() < EPSILON:
            active.add(task)  # 探索
    alloc = water_filling({t: max(0, ledger.delta[t] - cost[t]) for t in active},
                          budget.total)
    return active, alloc
```

### IP-189 CTPD（跨任务伪标签蒸馏）与 IP-190 MUC（校准）
```python
def ctpd_loss(outputs, graph, calibrated_conf):
    loss = 0
    for (i, j) in graph.edges():
        c = calibrated_conf[i]
        mask = (c >= TAU_CONF).float()
        if compatible(i, j):
            loss += (c * mask * ce(outputs[j], M[i, j](outputs[i]).detach())).mean()
        else:
            loss += (c * mask * mse(outputs.z[j], P[i, j](outputs.z[i]).detach())).mean()
    return loss
```

### IP-191 TIM（任务干扰监控）与 IP-192 MT-ESEC（总调度）
```python
def tim_certificate(grads, risks, single_risks, rho0=0.1, delta_nt=0.02):
    certs = []
    for i, j in combinations(tasks, 2):
        rho = cosine(grads[i], grads[j])
        nt = risks[j] - single_risks[j]
        if rho < -rho0 and nt > delta_nt:
            certs.append(ConflictCertificate(i, j, rho, nt))
    return certs
```

## 3. 复杂度与正确性（概要）

| 组件 | 时间 | 空间 | 正确性/保证 |
|---|---|---|---|
| TSN | O(d_z² + |T| r d_z) 每 batch | O(d_z² + |T| r d_z) | 依赖图无环；适配器低秩，参数共享 |
| DAMTL | O(|T| + |E|) 额外损失 | O(|T| d_z) | 任务不确定性加权收敛；依赖一致性有界 |
| SCLO | O(d_z) 投影 | O(d_z) | 安全可行域内不降低 C_safe；冲突梯度被投影 |
| ICL | O(M|T|) 价值评估 | O(M) | Shapley 估计无偏，M 增大 CI 收缩 |
| DTP | O(|T| log |T|) | O(|T|) | 必需任务不剪枝；ε-探索保证遗憾有界 |
| MT-ESEC | 训练 O(d_z²)，部署继承 ESEC O(1) 预算检查 | 共享 ~2GB，适配器 ~MB | 安全字典序 + 贡献账本可审计 |

**定理（MT-ESEC-Safe，概要）** 在假设：
- **(A71)** 共享主干 f_θ 为 L-Lipschitz，任务头为 μ-强凸；
- **(A72)** 安全约束集 K 非空、凸，且 Slater 条件成立；
- **(A73)** TDG 无环，依赖边满足任务条件独立性；
- **(A74)** Shapley 蒙特卡洛估计无偏、方差有界；
- **(A75)** 校准后置信度满足 ECE ≤ ε_ECE，安全保形覆盖 ≥ 1-α_safe；

下成立：
1. **安全保持**：SCLO 的投影更新保证 C_safe(Θ_t) ≤ C_safe(Θ_0) + O(η)，且当 C_safe > 0 时单调下降；安全任务不会被性能任务的平均梯度抵消。
2. **样本效率**：若任务在共享表征下条件独立，则每个任务的样本复杂度从 O(d_z/ε²) 降为 O(d_z/(|T|ε²) + d_i/ε²)；共享容量 C(Θ_shared) < Σ_i C(Θ_i)，泛化界更紧。
3. **负迁移可控**：TIM 证书在 ρ_ij < -ρ_0 且 NT_ij > δ_NT 时触发隔离/剪枝；DTP 剪枝后，活跃任务集的期望风险不高于剪枝前（在置信区间正确的前提下）。
4. **创新点可证伪**：ICL 的 95% 置信区间以概率 ≥ 0.95 覆盖真实 Shapley 值；CI 下界 > 0 的 IP 具有正边际贡献，CI 跨零的 IP 不得宣称已验证。
5. **端到端**：MT-ESEC 在部署层继承 ESEC 的语义-实时双流与安全护栏，训练层的多任务收益不改变实时流 ≤ 1ms 的时序契约。

## 4. 实验设计（概要：E201–E210）

| 实验 | 对比 | 指标 | 目标 |
|---|---|---|---|
| E201 多任务样本效率 | 单任务 ESEC vs 朴素 MTL vs DAMTL | 达到 90% 性能所需样本量 | 减少 ≥ 40% |
| E202 零样本物理属性 | 第 61 轮 MEL vs MT-ESEC | μ/k/η/σ 误差 | μ<12%，k<16% |

### IP-183 TDG（任务依赖图）

```python
class TaskDependencyGraph:
    def __init__(self, tasks, edges, safe_tasks):
        self.tasks = list(tasks)
        self.edges = list(edges)
        self.safe_tasks = set(safe_tasks)
        self.parents = {t: [] for t in self.tasks}
        self.children = {t: [] for t in self.tasks}
        for u, v in self.edges:
            self.parents[v].append(u)
            self.children[u].append(v)
        assert self.is_dag(), "task graph must be acyclic"

    def is_dag(self):
        indeg = {t: len(self.parents[t]) for t in self.tasks}
        q = [t for t in self.tasks if indeg[t] == 0]
        seen = 0
        while q:
            u = q.pop()
            seen += 1
            for v in self.children[u]:
                indeg[v] -= 1
                if indeg[v] == 0:
                    q.append(v)
        return seen == len(self.tasks)

    def topological_order(self):
        indeg = {t: len(self.parents[t]) for t in self.tasks}
        q = [t for t in self.tasks if indeg[t] == 0]
        order = []
        while q:
            u = q.pop(0)
            order.append(u)
            for v in self.children[u]:
                indeg[v] -= 1
                if indeg[v] == 0:
                    q.append(v)
        return order

    def performance_edges(self):
        return [(u, v) for (u, v) in self.edges if v not in self.safe_tasks]
```

```python
class TaskAdapter(nn.Module):
    def __init__(self, d_z, rank=32):
        super().__init__()
        self.down = nn.Linear(d_z, rank)
        self.up = nn.Linear(rank, d_z)
        self.parent_proj = nn.ModuleDict()  # per-parent projection

    def forward(self, z, parent_zs):
        if parent_zs:
            p = torch.stack([self.parent_proj[i](pz) for i, pz in parent_zs.items()])
            p = p.mean(dim=0)
            inp = torch.cat([z, p], dim=-1)
        else:
            inp = z
        return z + self.up(F.silu(self.down(inp)))


class TaskSharedNetwork(nn.Module):
    def __init__(self, graph, d_in, d_z=512, rank=32, n_classes=None):
        super().__init__()
        self.graph = graph
        self.shared_trunk = nn.Sequential(
            nn.Linear(d_in, d_z), nn.GELU(),
            nn.Linear(d_z, d_z), nn.LayerNorm(d_z)
        )
        self.adapters = nn.ModuleDict({
            t: TaskAdapter(d_z, rank) for t in graph.tasks
        })
        self.heads = nn.ModuleDict({
            t: nn.Linear(d_z, n_classes[t]) for t in graph.tasks
        })

    def forward(self, x):
        z0 = self.shared_trunk(x)
        zs, ys = {}, {}
        for t in self.graph.topological_order():
            parent_zs = {p: zs[p] for p in self.graph.parents[t]}
            zs[t] = self.adapters[t](z0, parent_zs)
            ys[t] = self.heads[t](zs[t])
        return ys, zs
```

```python
def damtl_loss(ys, zs, targets, graph, log_sigma, lambda_dep=0.1, lambda_cal=0.01):
    loss = 0.0
    for t in graph.performance_tasks():
        lam = 1.0 / (2.0 * torch.exp(2.0 * log_sigma[t]))
        loss = loss + lam * task_losses[t](ys[t], targets[t])
    for (i, j) in graph.performance_edges():
        loss = loss + lambda_dep * F.mse_loss(P[i, j](zs[i]), zs[j].detach())
    loss = loss + lambda_cal * calibration_loss(ys, targets)
    return loss


def damtl_step(model, batch, optimizer, graph, log_sigma):

    loss = damtl_loss(ys, zs, batch.targets, graph, log_sigma)
    optimizer.zero_grad()
    loss.backward()
    nn.utils.clip_grad_norm_(model.parameters(), 1.0)
    optimizer.step()
```

### IP-186 SCLO（安全字典序约束优化）

```python
class SafetyLexicographicOptimizer:
    def __init__(self, model, lr=1e-4, kappa=0.0, trust_radius=0.1):
        self.model = model
        self.opt = torch.optim.Adam(model.parameters(), lr=lr)
        self.kappa = kappa
        self.trust_radius = trust_radius

    def step(self, batch, graph, log_sigma):
        ys, zs = self.model(batch.x)
        l_perf = damtl_loss(ys, zs, batch.targets, graph, log_sigma)
        c_safe = safety_risk(ys[SAFETY], batch.targets[SAFETY]) - self.kappa

        g_perf = torch.autograd.grad(l_perf, self.model.parameters(),
                                     retain_graph=True, create_graph=False)
        g_safe = torch.autograd.grad(c_safe, self.model.parameters(),
                                     retain_graph=False, create_graph=False)
        flat_p = flatten(g_perf)
        flat_s = flatten(g_safe)

        if c_safe.item() > 0:
            direction = -flat_s
        else:
            inner = torch.dot(flat_p, flat_s)
            if inner < 0:
                direction = flat_p - inner / (flat_s.norm() ** 2 + 1e-8) * flat_s
            else:
                direction = flat_p

        # trust-region 裁剪
        if direction.norm() > self.trust_radius:
            direction = direction / direction.norm() * self.trust_radius
        self._apply_flat_grad(direction)
        self.opt.step()
        return {"l_perf": l_perf.item(), "c_safe": c_safe.item()}

    def _apply_flat_grad(self, flat):
        offset = 0
        self.opt.zero_grad()
        for p in self.model.parameters():
            n = p.numel()
            p.grad = flat[offset:offset + n].view_as(p).clone()
            offset += n
```

### IP-187 ICL（创新贡献账本）

```python
class InnovationContributionLedger:
    def __init__(self, tasks, value_fn, n_perm=200, n_boot=1000):
        self.tasks = list(tasks)
        self.value_fn = value_fn
        self.n_perm = n_perm
        self.n_boot = n_boot
        self.entries = {}

    def shapley(self, innovation):
        diffs = []
        for _ in range(self.n_perm):
            perm = random.sample(self.tasks, len(self.tasks))
            for k, task in enumerate(perm):
                S = set(perm[:k])
                v_with = self.value_fn(innovation, S | {task})
                v_without = self.value_fn(innovation, S)
                diffs.append(v_with - v_without)
        delta = float(np.mean(diffs))
        ci = self._bootstrap_ci(diffs)
        return delta, ci

    def _bootstrap_ci(self, diffs):
        boots = []
        n = len(diffs)
        for _ in range(self.n_boot):
            sample = np.random.choice(diffs, size=n, replace=True)
            boots.append(np.mean(sample))
        return float(np.percentile(boots, 2.5)), float(np.percentile(boots, 97.5))

    def register(self, innovation_id, delta, ci, task_subset, protocol, evidence_hash):
        status = ("verified" if ci[0] > 0 else
                  "negative" if ci[1] < 0 else "pending")
        self.entries[innovation_id] = {
            "delta": delta, "ci95": ci, "tasks": task_subset,
            "protocol": protocol, "evidence": evidence_hash, "status": status
        }
        return status
```

### IP-188 DTP（动态任务组合）

```python
class DynamicTaskPortfolio:
    def __init__(self, required_tasks, epsilon=0.1):
        self.required = set(required_tasks)
        self.epsilon = epsilon

    def update(self, ledger, costs, budget):
        active = set(self.required)
        utility = {}
        for task in ledger.tasks:
            delta = ledger.entries[task]["delta"]
            lcb = ledger.entries[task]["ci95"][0]
            utility[task] = max(0.0, delta - costs[task])
            if lcb > 0 or random.random() < self.epsilon:
                active.add(task)
        # 注水分配预算
        total = sum(utility[t] for t in active)
        alloc = {t: (budget.total * utility[t] / total if total > 0 else 0.0)
                 for t in active}
        return active, alloc
```

```python
def ctpd_loss(ys, zs, graph, calibrated_conf, tau_conf=0.8):
    loss = 0.0
    for (i, j) in graph.edges:
        if j in graph.safe_tasks:
            continue
        c = calibrated_conf[i]
        mask = (c >= tau_conf).float()
        if label_map_exists(i, j):
            pseudo = label_map[i, j](ys[i]).detach()
            loss = loss + (c * mask * ce_loss(ys[j], pseudo)).mean()
        else:
            loss = loss + (c * mask * F.mse_loss(zs[j], P[i, j](zs[i]).detach())).mean()
    return loss
```

```python
class MultiTaskCalibrator:
    def __init__(self, tasks, alpha_safe=1e-3):
        self.temps = {t: nn.Parameter(torch.ones(1)) for t in tasks}
        self.alpha_safe = alpha_safe
        self.conformal = {}

    def calibrate(self, task, logits, labels):
        # 温度缩放
        opt = torch.optim.LBFGS([self.temps[task]], lr=0.1, max_iter=50)
        def closure():
            opt.zero_grad()
            loss = F.cross_entropy(logits / self.temps[task], labels)
            loss.backward()
            return loss
        opt.step(closure)
        return logits / self.temps[task]

    def fit_conformal(self, task, scores):
        q = np.quantile(scores, 1 - self.alpha_safe if task == SAFETY else 1 - ALPHA)
        self.conformal[task] = q
        return q

    def prediction_set(self, task, probs):
        return (probs >= (1 - self.conformal[task])).nonzero()
```

```python
class TaskInterferenceMonitor:
    def __init__(self, rho0=0.1, delta_nt=0.02):
        self.rho0 = rho0
        self.delta_nt = delta_nt

    def certificate(self, grads, risks, single_task_risks):
        certs = []
        for i, j in itertools.combinations(grads.keys(), 2):
            rho = F.cosine_similarity(grads[i].flatten(), grads[j].flatten(), dim=0).item()
            nt = risks[j] - single_task_risks[j]
            if rho < -self.rho0 and nt > self.delta_nt:
                certs.append({
                    "type": "negative_transfer",
                    "i": i, "j": j, "rho": rho, "nt": nt,
                    "action": "isolate_adapter_or_prune"
                })
        return certs
```

```python
class MTESEC:
    def __init__(self, graph, model, sclo, ledger, portfolio, calibrator, esec):
        self.graph = graph
        self.model = model
        self.sclo = sclo
        self.ledger = ledger
        self.portfolio = portfolio
        self.calibrator = calibrator
        self.esec = esec
        self.active = set(graph.tasks)

    def train_round(self, data, budget):
        # 1. 多任务预训练（DAMTL + CTPD）
        for batch in data:
            ys, zs = self.model(batch.x)
            loss = damtl_loss(ys, zs, batch.targets, self.graph, self.model.log_sigma)
            loss = loss + ctpd_loss(ys, zs, self.graph, batch.calibrated_conf)
            self.model.optimizer.zero_grad()
            loss.backward()
            nn.utils.clip_grad_norm_(self.model.parameters(), 1.0)
            self.model.optimizer.step()

        # 2. 安全约束微调（SCLO）
        for batch in data.safety_loader:
            self.sclo.step(batch, self.graph, self.model.log_sigma)

        # 3. 创新贡献账本（Shapley）
        for ip in INNOVATIONS:
            delta, ci = self.ledger.shapley(ip)
            self.ledger.register(ip, delta, ci, ip.tasks, ip.protocol, ip.hash)

        # 4. 动态任务组合
        costs = budget.costs()
        self.active, alloc = self.portfolio.update(self.ledger, costs, budget)

        # 5. 校准与保形
        for t in self.active:
            self.calibrator.calibrate(t, data.val_logits[t], data.val_labels[t])
        self.calibrator.fit_conformal(SAFETY, data.safety_scores)

        # 6. 部署：复用 ESEC 双流
        return self.esec.deploy(self.model, active_tasks=self.active, alloc=alloc)
```

**定理 1（安全保持）** 在 (A71)(A72) 下，SCLO 的投影更新满足：
```
C_safe(Θ_{t+1}) ≤ max(0, C_safe(Θ_t) - η ||g_s||² + O(η²))
```
且当 C_safe > 0 时，安全风险单调不增；当 C_safe ≤ 0 时，若 ⟨g_p,g_s⟩ < 0，投影后的性能梯度与安全梯度正交，不会产生使 C_safe 上升的一阶分量。

*证明草图*：可行时，g_p 对 g_s 的负分量被减去，故一阶安全变化为 0；不可行时沿 -g_s 下降，凸性 (A72) 保证可行域方向。∎

**定理 2（样本效率）** 若任务在共享表征下条件独立，且共享主干容量为 C(Θ_shared)，则多任务泛化界：
```
R_i ≤ R̂_i + O( sqrt(C(Θ_shared)/n) + sqrt(C(Φ_i)/n_i) + sqrt(log(1/δ)/n) )
```
其中 n = Σ_i n_i。当 C(Θ_shared) < Σ_i C(Θ_i) 时，多任务界优于各任务独立训练界；当任务相似度 s_ij 越高，共享项收益越大。

**定理 3（负迁移可控）** 若 TIM 在 ρ_ij < -ρ_0 且 NT_ij > δ_NT 时触发隔离/剪枝，则 DTP 剪枝后的活跃集 A' 满足：
```
E[R_j(Θ_A')] ≤ E[R_j(Θ_A)] + O( sqrt(log(1/δ)/n_j) )
```
即剪枝不增加期望风险（在证书正确的前提下）；若证书误报，则需用 ε-探索重新激活。

**定理 4（创新点可证伪）** 设 Shapley 估计量 Δ̂_m 无偏、方差 σ_m²，则对任意 δ ∈ (0,1)：
```
P(|Δ̂_m - Δ_m| ≤ z_{1-δ/2} σ_m / sqrt(M)) ≥ 1 - δ
```
bootstrap CI 渐近覆盖真实 Δ_m；决策规则「CI 下界 > 0 才宣称已验证」将假阳性率控制在 δ 水平（在正则条件下）。

**定理 5（端到端）** MT-ESEC 的训练层不改变 ESEC 的实时流接口：USR 语义锚点、SRT-Dual 版本号协议、PCE+++++ 六维预算均保持第 61 轮定义；多任务训练只更新共享主干与任务头，部署时仍由 Π 投影与 SCLO 安全门控保障 K_safe。因此第 61 轮的实时性定理（周期 ≤1ms、锚点新鲜度 ≥95%）在 MT-ESEC 下继续成立。

### 实验协议要点
- **数据划分**：按场景族/材质族/对话风格做分布外划分，避免同族泄漏；零样本测试集不参与任何任务训练。
- **安全评估**：使用独立安全测试集，统计力超限、滑移、碰撞、急停次数；安全违规以「每千次交互」计。
- **贡献账本**：每个创新点做 5 次随机种子 × 200 个 Shapley 排列，bootstrap 1000 次；以留一消融作为外部效度检验。
- **统计检验**：配对 bootstrap 检验，报告 95% CI 与效应量；所有目标均需在 3 个随机种子上复现。

## 7. 本轮最大风险

**一句话**：若任务依赖图把「相关」误当成「因果」、或 Shapley 价值函数被短期指标污染、或安全字典序约束在训练早期因可行域为空而被迫放松，则多任务共享会把「表面相关」放大成系统性偏差，导致「创新点账本看起来很漂亮、真实安全与零样本泛化却在分布漂移下崩塌」；必须以「依赖边可消融检验 + 安全约束硬门控 + 贡献账本分布外复核 + TIM 在线冲突证书」构成训练层的可证伪护栏。
