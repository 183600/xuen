# 第 59 轮（承接第 58 轮「KG-SFT-UX」IP-139~144；灵感循环第 1 轮；本轮灵感：「边缘计算」×「动作空间」）

> 第 58 轮把安全论证的中心推到"结构化记忆"：KG 同时驱动检索、OOD、微调、证据合成与心智预测，代价是共模故障——一张系统性错误的图可以让所有机制一起失效。它自陈的四重护栏（仅证据门通过可写入、边级溯源、事后证伪回溯、向量并行兜底）都在回答"图可不可信"，却没有回答两个部署层的问题：**(a) 安全判定在哪里算、用多新的状态算**——第 58 轮默认所有证据与图谱都在一个始终在线、始终同步、算力不受限的节点上；真实部署是云-边分离、链路会断、云端状态会旧、边缘算力只够做轻量校验。**(b) 安全到底是在"选动作"还是在"划动作空间"**——第 58 轮默认动作空间固定，只问哪个动作期望最好；但不可逆接触的真正安全，往往不是选出一个更好的动作，而是把整个可选集合收缩到"即使选错也不会死"的子集。本轮两个灵感各补一条腿：**边缘计算**把云端降格为"发证书的顾问"、把边缘升格为"只做验证与收缩的安全内核"，让延迟与分区不再靠"假设网络很好"；**动作空间**把安全对象从单个动作提升为**带粒度与租约的动作空间证书**，并证明一条比置信度更强的性质——**没有新证书，边缘的动作空间只许缩、不许涨**。核心命题由"结构化记忆守护的安全自适应"升级为 **"云端只发证书、边缘只做收缩、动作空间不扩张的实时证据承诺"**。

核心矛盾：
- **H37（云端全局 vs 边缘陈旧）**：云端 KG/元模型更全，但到达边缘时可能已过期；用陈旧知识扩大动作空间，等于用昨天的地图解锁今天的悬崖；而"不用云端"又退化为第 57 轮之前的局部短视。
- **H38（收缩 vs 任务可行性）**：收缩保安全，但过度收缩会让任务不可行、机器人被困；必须有"永远保留的返航/安全核"，以及一条可证明不会进入死胡同的降级链。
- **H39（抽象粒度 vs 证据对齐）**：粗动作隐藏细失效（"前进一格"掩盖打滑），细动作难认证且带宽高；证书粒度与被执行的细化动作不匹配时，"证书覆盖"只是把危险藏到抽象层之下。
- **H40（通信分区 vs 安全自治）**：分区时边缘必须独自决策，但自洽的保守策略可能永远等不到云端；租约、失效、重认证必须形式化，不能靠"重连后再说"。

## 0. 直觉与动机

**灵感 1（边缘计算 → 云端发证书，边缘只验证）**
直觉：把云端想成"出考卷的人"，边缘是"进考场的人"。云端可以慢慢算、看很多历史，但它不能在机器人抬脚前 5ms 才把答案送到。正确分工不是"把模型裁小搬到边缘"，而是**把安全判定编译成一张可在边缘 O(|A_cert|) 验证的证书**：证书声明"在条件 cond、版本 ver、有效期 L 内，动作集合 A_cert 中的每个动作都满足安全护栏"。边缘不重跑元推断，只做三件便宜事：**成员检查**（我要做的动作在不在 A_cert）、**条件检查**（cond 现在还成立吗）、**收缩**（本地证据一冲突，就把集合交小）。这把边缘安全关键路径从"推理成本"降为"验证成本"，且验证可审计、可复现。

**灵感 2（动作空间 → 证书化动作空间与非扩张不变式）**
直觉：安全的对立面不是"选错动作"，而是"可选集合里混进了不该有的动作"。因此引入**动作空间证书** C_A=(A_cert, cond, granularity, lease, ver)：它不给单个动作打分，而是给一个**集合**背书；边缘每步构造 A_exec = A_cert ∩ A_local(证据) ∩ A_E(能量) ∩ A_recover(可返航)，只许取交集。关键不变式是**非扩张**：在没有一张通过验证且覆盖当前颗粒度的新证书之前，A_exec(t+1) ⊆ A_exec(t)。这把"旧快照解锁新承诺"从概率问题变成结构不可能——陈旧云端最多让动作空间变小，永远不会让它变大。

**灵感 3（粒度 → 证书粒度与执行粒度必须对齐）**
直觉：一张"允许前进 0.3m"的粗证书，不能自动覆盖底层 1kHz 的力矩指令。粗粒度证书只对抽象动作成立，执行时还要经过细化映射 R：coarse cell → 2^{fine actions}。我们要求：**执行动作必须落在某个被认证 cell 的细化域内**，否则要么夹到 cell 内，要么请求重认证；证书还必须带**最坏细化护栏**（cell 内所有细化动作的 guard 都成立）。否则"证书覆盖"只是把危险藏在抽象层之下。

**灵感 4（最不承诺 → 保留可选性的动作选择）**
直觉：两条都安全的动作之间，应优先选**日后更可放弃**的那条。定义可放弃性：执行 a 后，仍存在一条被证书覆盖的返航/退避动作，且不可逆深度不增加。于是动作选择从"期望收益最大"变成"在安全集合内最大化未来可选空间（option value）"，平局取不可逆深度更小者。这直接对抗"证书很对、但把自己走进死胡同"的失败。

**灵感 5（合流 → 边缘证据门、租约失效、双证书提交）**
直觉：第 58 轮六类证据门在本轮增加两类边缘维度：**EV-edge**（新鲜但局部的边缘证据）与 **EV-lease**（未过期且版本匹配的云端证书），再加 **EV-aps**（动作保留证书化退路）。提交需要**双证书**：证据证书（我该不该信）+ 动作空间证书（这个动作在不在被背书的集合里）；任一缺失或过期即收缩/返航/交接。击穿安全需要：云端证书本身错 ∧ 条件误声明 ∧ 租约未及时失效 ∧ 细化越界 ∧ 本地收缩失效 ∧ 人也错——纵深比第 58 轮更依赖"集合非扩张"这条结构性护栏，而不是更多置信度。

## 1. 形式化定义（增量：定义 145–150）

**定义 145（边缘-云信任契约 ECT）** 状态分层 σ=(σ_E,σ_C)：σ_E=(𝓑_E,证据龄,租约表,A_local,s_o,e)、σ_C=(𝒢,φ_meta,𝒟_meta)。证据统一记为 e=(origin,age,ver,scope,payload)，origin∈{edge,cloud,human,sim}。云端只输出**证书**而非决策：KG 增量证书、元模型适配器证书、动作空间证书 C_A（定义 146）。边缘接受云端更新须同时满足：(i) ver 单调；(ii) 租约未过期且 scope 覆盖当前区域/粒度；(iii) 通过本地**非扩张检查**——除非显式激活一张新证书，接受操作不得使 A_exec 变大。形式化两类允许变化：本地收缩 ↓（无需云端、随时可做）与**证书切换** Act(C_A)（非单调，须租约/版本/范围/审计四重校验并记入 auth_log）。定义边缘有效权限 A_eff(t)=A_cert(t)∩A_local(t)∩A_E(t)∩A_recover(t)。

**定义 146（动作空间证书 ASC）** 动作空间按抽象格分层 A_fine ⪯ A_coarse，细化映射 R: A_coarse→2^{A_fine}。证书 C_A=(A_cert,cond,g,lease,ver,δ_ref)，其中 g 为认证粒度，cond 为声明条件（材质/坡度/光照/载荷/能量区间），lease=(v_max,τ_exp,scope)，δ_ref 为细化护栏余量。**可靠性**：cond 成立 ⇒ ∀c∈A_cert, ∀a∈R(c), Safe(a,x)（粗粒度须对 cell 内最坏细化成立）。**粒度对齐**：执行 a 合法 ⇔ ∃c∈A_cert: a∈R(c) ∧ x⊨cond(c)；否则 clamp 到 cell 边界或请求重认证。**非扩张引理**：若 t 与 t+1 之间未发生 Act(C_A) 且租约未续，则 A_exec(t+1)⊆A_exec(t)。

**定义 147（陈旧折算与租约失效 SDF）** 云端证据权重 w_C(e)=w_0·exp(−age/τ_s)·1[ver≥ver_min]·1[scope∋x]；其贡献只用于**加宽/收缩**，不用于扩大未被当前证书覆盖的动作。租约失效谓词 Exp(t)⇔(t−t_issue>τ_exp)∨(ver_gap>Δ_v)∨¬cond(x_t)。Exp 一旦成立：A_cert↓A_core（安全核：安全停/返航/最小移动），EV-lease 关闭，边缘切本地探询；重认证须新证书 ∧ 驻留 T_dwell ∧ 本地反例检查通过。这一条把"陈旧解锁"写成结构上不可达，而不是概率上很小。

**定义 148（可选性保持选择 LCO）** 动作 a 的不可逆深度 dep(a)=沿 a 后最坏恢复路径的不可逆接触次数；退路谓词 Esc(a)⇔∃r∈A_exec(t+1|a): r 为证书覆盖的返航/退避动作 ∧ dep(r)≤dep(a)。选择规则：a\*=argmax_{a∈A_exec}[Û(a)+β·log|A_exec(t+1|a)|]，s.t. Esc(a)，平局取 dep 更小；其中 Û 为悲观收益。**EV-aps** ⇔ Esc(a\*) ∧ 退路证书 ver 匹配 ∧ dep 不增。

**定义 149（边缘自治降级阶梯 EDR）** 阶梯 ℓ∈{0 全证书,1 局部收缩,2 安全核,3 安全停/交接}，每级 I_ℓ=(A_ℓ,探询率,租约容忍,Inv_ℓ)。降级实时（Exp ∨ 本地反例 ∨ 能量门失败 ∨ 分区超时）；升级需新证书 ∧ 驻留 T_dwell ∧ n_recover 次本地验证 ∧ 无未决反例。逐级不变式：A_{ℓ+1}⊆A_ℓ 且 A_core⊆A_ℓ（∀ℓ）；级间加滞回，禁止抖振。核心硬约束：**A_core 永不被收缩掉**，否则任务不可行而非更安全。

**定义 150（边缘探-诺-演 PCX-E）** 每检查点：①读已验证证书与本地证据；②构造 A_exec（定义 145）；③粒度对齐检查与 clamp；④若 Exp 或反例 ⇒ 降级（定义 149）；⑤在 A_exec 内按 LCO 选动作并做双证书判定 G_ev∧G_act；⑥仅当双证书过 ∧ 未过期 ∧ 退路存在才提交，否则收缩→返航→交接/安全停。证据门=EV-probe\*/EV-visit/EV-margin/EV-xmodal/EV-human/EV-ft/EV-ux ∪ {EV-edge,EV-lease,EV-aps}；不可逆接触必要集仍不含 EV-xmodal/EV-ft，且额外要求 EV-lease 有效或显式退回本地证书。

## 2. 关键算法伪代码（完整版见产物区）

```python
def edge_commit(cp, sigma_E, certs, budget):
    cert = activate_cert(certs, cp)                    # 版本/租约/范围校验
    if cert is None or lease_expired(cert, cp.t):
        A_exec = A_core(sigma_E)                        # 失效 ⇒ 安全核
        return fallback(cp, sigma_E, 'lease_expired')
    A_exec = intersect(cert.A_cert, local_admissible(sigma_E, cp),
                       energy_admissible(sigma_E, cp),
                       recoverable(sigma_E, cp))        # 只取交集
    a = argmax(A_exec, key=lambda a: utility(a) + beta*log(future_set_size(a)),
               tie_break=min_irreversible_depth)
    if not granularity_aligned(a, cert): return clamp_or_replan(a, cert)
    if local_counterexample(sigma_E, a, cert.cond):      # 便宜的条件反例检查
        return shrink_and_retry(A_exec, a, sigma_E)
    if evidence_gate(sigma_E, cp) and action_gate(cert, a) and Esc(a):
        return commit(a)
    return fallback(cp, sigma_E, 'dual_cert_failed')
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| ECT | O(\|租约表\|) 校验 | O(\|证书\|) | 版本单调、租约/范围校验、云端只建议 |
| ASC | O(\|A_cert\|) 成员检查 | O(\|A_cert\|·\|A_fine\|) | 证书可靠、粒度对齐、非扩张引理 |
| SDF | O(1)/证据 | O(\|证据龄窗口\|) | 权重随龄非增、失效 ≤1 控制周期 |
| LCO | O(\|A_exec\|·C_future) | O(\|A_exec\|) | 退路存在、不可逆深度不增 |
| EDR | O(1)/步 + O(H) | O(阶梯表) | 逐级包含、A_core 保留、滞回 |
| PCX-E | O(\|CP\|·(\|A_cert\|+k_p·C_probe)) | O(\|V\|+\|σ_E\|+\|证书\|) | 双证书、有界轮次、四态完备 |

**正确性定理（证书化动作空间健全性 CAS，概要）**：在 A22–A45 基础上加 (A46) ECT 版本单调、租约/范围校验诚实、云端仅输出证书；(A47) ASC 证书在其声明条件与有效期内可靠、细化映射健全、粒度对齐被强制执行；(A48) SDF 权重随龄非增、Exp 检出 ≤1 控制周期、失效后 A_exec↓A_core；(A49) LCO 退路谓词与不可逆深度估计保守；(A50) EDR 逐级包含、A_core 永不删除、升级有据有界；(A51) PCX-E 双证书判定原子、轮次有界。则：

(i) **非扩张安全**：任意两次合法 Act(C_A) 之间 A_exec(t+1)⊆A_exec(t)；陈旧云端在没有有效新证书时**不可能**扩大动作空间，"陈旧解锁"概率为 0（结构性，而非界）。
(ii) **边缘分区安全**：若分区开始于 t0，则 t0+τ_exp 起 A_exec⊆A_core，且 P(安全停/返航成功)≥1−δ_lease−δ_ref−δ_part。
(iii) **粒度健全**：任意提交动作 a 满足 a∈R(c) 且 x⊨cond(c)，故 P(假证书覆盖)≤δ_ref+δ_cond，其中 δ_cond 为条件误声明率。
(iv) **可选性**：每次提交保留证书化退路，P(无路可退/被困)≤δ_strand；任务不可行时按 EDR 有序降级而非硬停。
(v) **部署界**：第 58 轮联合界增加 δ_lease+δ_ref+δ_cond+δ_strand，并显式扣除"云端证书系统性错误""cond 在租约内漂移""粗粒度隐藏细失效"三项结构风险。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 云端证书系统性错误（图错/元模型错） | 高 | 证书只是**集合背书**、非扩张不变式兜底；边缘条件反例与本地收缩；证书按租约分片、可独立回滚 |
| cond 在租约内漂移（干地变冰面） | 高 | 短租约 + 边缘便宜不变式监测 + 反例即缩 + 条件误声明计入 δ_cond |
| 粗粒度抽象隐藏细失效 | 中高 | 最坏细化护栏 + 粒度对齐强制 + clamp/重认证 |
| 过度收缩导致被困 | 中 | A_core 永存、LCO 退路、EDR 有序降级、任务不可行即交接 |
| 降级阶梯抖振/重连风暴 | 中 | 滞回、驻留时间、重认证限速、分区去抖 |
| 边缘验证器本身被攻破/实现错误 | 中 | 最小可信验证核、形式化成员检查、证书独立重放与审计 |

## 6. 本轮最大风险

**一句话**：本轮把"信任"从模型置信换成了**证书 + 租约**——证书可靠性和条件声明成了新的单点先验；若云端在租约有效期内把"干地"误声明为"冰面也已覆盖"，或粗粒度 cell 的细化护栏漏掉一个打滑微动作，边缘会因为"证书看起来有效"而把危险动作留在集合里，而结构性非扩张只能保证集合不涨、不能保证集合本身正确；必须以短租约、边缘条件反例、最坏细化护栏、A_core 永存与证书独立重放五重护栏，宁可把证书切碎、提前退回安全核，也绝不把"云端说可以"当作"世界说可以"。

> 承接第 58 轮 IP-139~144（KGMM/SFT-KG/UXSE/KGES/ACC/PCX++）与第 57 轮 IP-133~138。本轮把部署前提从「结构化记忆守护下的安全自适应」升级为 **「云端只发证书、边缘只做收缩、动作空间不扩张的实时证据承诺」**：安全判定的位置从"单节点全局推断"拆成"云端编译证书 / 边缘验证与收缩"；安全对象从"单个动作的置信度"提升为"带粒度、条件、租约的动作空间集合"；新鲜度从隐含假设变成显式的陈旧折算与租约失效；动作选择从期望收益最大化改为在安全集合内保留可选性。第 58 轮"仅证据门通过可写入、事后证伪可回溯"在本轮延伸到**动作空间**：云端只能往边缘的集合里**写入被证书背书的子集**，本地只能**删除/收缩**，任何扩张都必须以一张通过租约、版本、范围、审计四重校验的新证书为凭据。

### IP-145 ECT（边缘-云信任契约）

```python
class EdgeCloudTrustContract:
    def __init__(self):
        self.certs = {}                 # cert_id -> C_A（含 ver/lease/scope）
        self.ledger = EdgeEvidenceLedger()   # 单调收缩 + 证书切换日志
        self.local = LocalEvidence()

    def accept_cloud(self, msg, cp):
        """云端消息只能是证书；接受需四重校验。"""
        if msg.type not in ('KG_DELTA', 'ADAPTER', 'ACTION_CERT'):
            return Reject('cloud_must_send_certificates_only')
        if msg.ver <= self.certs.get(msg.cert_id, C_ZERO).ver:
            return Reject('version_not_monotone')
        if not in_scope(msg.lease.scope, cp.region, cp.granularity):
            return Reject('scope_mismatch')
        if not self.audit_ok(msg):
            return Reject('audit_failed')
        # 扩张只能作为显式证书切换；否则只允许收缩
        if expands(msg.A_cert, self.current_A(cp)):
            self.ledger.log_activation(msg)      # 非单调操作，单写者定序
        self.certs[msg.cert_id] = msg
        return Accept(msg)

    def current_A(self, cp):
        return intersect_all([c.A_cert for c in self.certs.values()
                              if c.lease.valid(cp.t) and c.scope.covers(cp)])

    def local_shrink(self, cp, reason):
        """本地收缩：无需云端、随时可做、可交换。"""
        self.local.shrink(cp.region, reason)
        self.ledger.log_shrink(cp, reason)
```

### IP-146 ASC（动作空间证书与粒度对齐）

```python
class ActionSpaceCertificate:
    def __init__(self, A_cert, cond, g, lease, ver, delta_ref):
        self.A_cert, self.cond, self.g = A_cert, cond, g
        self.lease, self.ver, self.delta_ref = lease, ver, delta_ref

    def certifies(self, a_fine, x):
        """粒度对齐 + 条件成立 + 细化域覆盖，三者缺一不可。"""
        cell = self.exec_cell(a_fine)              # 找出 a_fine 所属粗动作 c
        if cell is None or cell not in self.A_cert:
            return False, 'not_in_certified_cell'
        if not self.cond(x):
            return False, 'condition_violated'
        if not refinement_within_guard(cell, a_fine, self.delta_ref):
            return False, 'refinement_escape'
        return True, 'ok'

def build_exec_set(cert, sigma_E, cp):
    A = cert.A_cert if cert and cert.lease.valid(cp.t) else set()
    A = intersect(A, local_admissible(sigma_E, cp))       # 证据门过的本地动作
    A = intersect(A, energy_admissible(sigma_E, cp))      # 能量门
    A = intersect(A, recoverable(sigma_E, cp))            # 存在返航/退避
    A = intersect(A, A_core(sigma_E)) if A & A_core(sigma_E) else A
    return A

def non_expansion_guard(prev_A, new_A, activated_cert):
    if activated_cert is None and not subset(new_A, prev_A):
        return Reject('non_expansion_violated')           # 结构性护栏
    return Accept()
```

### IP-147 SDF（陈旧折算与租约失效）

```python
class StalenessDiscountedFusion:
    def weight(self, e, now):
        if e.ver < self.ver_min or not self.scope.covers(e.scope):
            return 0.0
        return self.w0 * math.exp(-(now - e.t) / self.tau_s)

    def expired(self, cert, cp):
        return ((cp.t - cert.lease.t_issue > cert.lease.tau_exp) or
                (self.ver_gap(cp) > self.delta_v) or
                (not cert.cond(cp.x)))

    def on_expiry(self, sigma_E, cp):
        sigma_E.A_exec = intersect(sigma_E.A_exec, A_core(sigma_E))
        sigma_E.EV_lease_enabled = False
        sigma_E.rung = max(sigma_E.rung, 2)               # 至少安全核
        return sigma_E

    def re_certify(self, cert, sigma_E, cp):
        ok = (self.audit_ok(cert) and not self.local_counterexample(cp, cert) and
              sigma_E.dwell >= self.T_dwell and
              sigma_E.recover_count >= self.n_recover)
        if ok: sigma_E.rung = min(sigma_E.rung, 0)
        return ok
```

### IP-148 LCO（最不承诺选择）

```python
def least_commitment_select(A_exec, sigma_E, cp, beta):
    best, best_val = None, -inf
    for a in A_exec:
        if not Esc(a, sigma_E, cp):          # 必须保留证书化退路
            continue
        future = future_set_size(a, sigma_E, cp)   # 执行 a 后仍可用的动作数
        val = pessimistic_utility(a, sigma_E) + beta * math.log(max(1, future))
        key = (val, -irreversible_depth(a, sigma_E))
        if key > best_val:
            best, best_val = a, key
    return best

def tag_ev_aps(a, sigma_E, cp):
    return (Esc(a, sigma_E, cp) and
            cert_covers_escape(a, sigma_E, cp) and
            irreversible_depth_after(a) <= irreversible_depth(sigma_E))
```

### IP-149 EDR（边缘自治降级阶梯）

```python
class EdgeDegradationRungs:
    RUNGS = {
        0: ('full',     dict(probe_rate=1.0, lease_tol=1.0, inv='cert_ok')),
        1: ('local',    dict(probe_rate=0.7, lease_tol=0.5, inv='local_shrink')),
        2: ('core',     dict(probe_rate=0.3, lease_tol=0.0, inv='A_core_only')),
        3: ('stop',     dict(probe_rate=0.0, lease_tol=0.0, inv='safe_stop')),
    }
    def step(self, rung, sigma_E, cp):
        if safe_stop_required(sigma_E, cp):        return 3
        if lease_expired(sigma_E, cp) or self.local_counterexample(sigma_E): return 2
        if self.partition_timeout(sigma_E, cp):    return max(rung, 2)
        if self.local_shrink_fired(sigma_E):       return max(rung, 1)
        return rung

    def can_promote(self, rung, cert, sigma_E, cp):
        return (rung > 0 and cert.lease.valid(cp.t) and
                sigma_E.dwell >= self.T_dwell and
                sigma_E.recover_count >= self.n_recover and
                self.invariants_hold(rung - 1, sigma_E) and
                not self.oscillating(sigma_E, window=3))
```

### IP-150 PCX-E（边缘探-诺-演）

```python
def probe_commit_evolve_edge(x0, M, task, budget, certs, consent):
    route, sched, log = plan_on_map(M, task), [], []
    for cp in route.checkpoints:
        # ① 证书激活与失效检查
        cert = M.ect.activate(certs, cp)
        if cert is None or M.sdf.expired(cert, cp):
            M = M.sdf.on_expiry(M, cp)
            sched.append(fallback(cp, M, 'lease_expired'))
            if M.rung >= 3: break
            continue

        # ② 构集合（定义 145/146）+ ③ 粒度对齐
        A_exec = build_exec_set(cert, M.sigma_E, cp)
        if not A_exec:
            M.rung = M.edr.step(M.rung, M.sigma_E, cp)
            sched.append(fallback(cp, M, 'empty_action_set'))
            continue

        # ④ 本地反例：便宜的不变式监测，先于任何承诺
        if M.sdf.local_counterexample(cp, cert):
            M = M.ect.local_shrink(cp, 'local_counterexample')
            M.rung = max(M.rung, 1)
            continue

        # ⑤ 最不承诺选择 + 双证书判定
        a = least_commitment_select(A_exec, M.sigma_E, cp, M.beta)
        ev = tag_evidence_edge(cp, M, a, cert)
        if (a is not None and
            few_shot_evidence_gate_edge(ev, M, consent) and
            action_gate_edge(cert, a, cp) and
            tag_ev_aps(a, M.sigma_E, cp) and
            not granularity_mismatch(a, cert)):
            sched.append(commit(a, cp))
            log.append(ev)
            continue

        # ⑥ 收缩→降级→返航/交接
        M = M.ect.local_shrink(cp, 'dual_cert_failed')
        M.rung = max(M.rung, 1)
        if M.rung >= 2:
            sched.append(fallback(cp, M, 'rung>=2'))
            if M.rung >= 3: break
    return sched, log, M

def few_shot_evidence_gate_edge(c, M, consent):
    if c.ev == 'EV-edge':
        ok = c.fresh and c.local_gate_ok and c.level != 'L2_irreversible'
    elif c.ev == 'EV-lease':
        ok = c.lease_valid and c.ver_match and c.scope_ok
    elif c.ev == 'EV-aps':
        ok = c.esc_exists and c.cert_covers_escape and c.dep_nonincrease
    elif c.ev == 'EV-xmodal':
        ok = c.level == 'L1' and c.indep_declared and c.D <= c.theta_D
    elif c.ev == 'EV-ft':
        ok = c.ft_audit_passed and c.level != 'L2_irreversible'
    elif c.ev == 'EV-ux':
        ok = c.level == 'L2' and c.mu_mis <= c.theta_mis
    elif c.ev in ('EV-probe*', 'EV-visit', 'EV-margin', 'EV-human'):
        ok = round58_checks(c, M)
    else:
        return False
    if c.irreversible and c.ev in ('EV-xmodal', 'EV-ft', 'EV-aps'):
        ok = False                                    # 集合/退路证据不得替代不可逆必要证据
    return ok

def action_gate_edge(cert, a, cp):
    ok, why = cert.certifies(a, cp.x)
    return ok and cert.lease.valid(cp.t) and in_scope(cert.lease.scope, cp)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ECT | O(\|证书\|) 校验/检查点 | O(\|证书\|+\|日志\|) | 版本单调、租约/范围校验、云端只发证书、扩张需审计 |
| ASC | O(\|A_cert\|) 成员检查 | O(\|A_cert\|·\|A_fine\|) | 证书可靠、细化健全、粒度对齐强制、非扩张 |
| SDF | O(1)/证据 + O(1)/检查点 | O(证据龄窗口) | 权重随龄非增、Exp 检出 ≤1 周期、失效即安全核 |
| LCO | O(\|A_exec\|·C_future) | O(\|A_exec\|) | 退路存在、dep 不增、可选空间不缩 |
| EDR | O(1)/步 + O(H) 证书网格 | O(阶梯表) | 逐级包含、A_core 永存、滞回、升级有据 |
| PCX-E | O(\|CP\|·(\|A_cert\|+k_p·C_probe+k_c·C_probe)) | O(\|V\|+\|σ_E\|+\|证书\|) | 双证书、有界轮次、四态完备 |

**正确性定理（证书化动作空间健全性，CAS）**
假设 A22–A45（第 53–58 轮）成立；**(A46)** ECT：云端只输出证书，边缘按 ver 单调、lease 未过期、scope 覆盖、审计通过四重校验接受；扩张必须走显式 Act(C_A) 并单写者定序；**(A47)** ASC：证书在其声明 cond 与有效期内可靠，细化映射 R 健全，执行动作必须落在某个被认证 cell 的细化域内，δ_ref 覆盖 cell 内最坏细化；**(A48)** SDF：w_C 随 age 单调非增，Exp 检出延迟 ≤1 控制周期，失效后 A_exec⊆A_core；**(A49)** LCO：dep 与 Esc 的估计保守，退路动作证书版本匹配；**(A50)** EDR：A_{ℓ+1}⊆A_ℓ、A_core⊆A_ℓ、升级需新证书+驻留+恢复验证、级间滞回；**(A51)** PCX-E：双证书判定原子、不迟到提交、轮次有界。则：

1. **结构性非扩张**：对任意合法轨迹，若区间 (t,t+1] 内没有 Act(C_A)，则 A_exec(t+1)⊆A_exec(t)。特别地，陈旧云端证据**不可能**扩大动作空间，故 P(stale_unlock)=0。
2. **分区安全**：若通信在 t0 中断，则 t0+τ_exp 后 A_exec⊆A_core，且 P(返航/安全停成功)≥1−δ_lease−δ_ref−δ_part。
3. **粒度健全**：每个提交动作 a 满足 ∃c∈A_cert: a∈R(c) ∧ cond(x)，故 P(假覆盖)≤δ_ref+δ_cond；其中 δ_cond 为条件误声明率、δ_ref 为细化护栏残余。
4. **可选性/非困死**：每次提交保留 Esc，且在任务不可行时沿 EDR 有序降级（全证书→局部→安全核→停/交接），P(被困且未交接)≤δ_strand。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                   + δ_ft·1[回滚窗口] + δ_kg·1[检索失败] + δ_ux·1[μ_mis>θ_mis]
                   + δ_lease + δ_ref + δ_cond + δ_strand)
         − P(云端证书系统性错误未检出) − P(cond 在租约内漂移)
         − P(边缘验证核实现错误) − P(A_core 估计错误)
```

关键：**云端只做"编译"、边缘只做"验证与收缩"**——安全关键路径不依赖云端在线，也不依赖边缘重跑大模型；**动作空间是安全的一等对象**——非扩张是结构性的，不靠概率；**粒度与租约是证书的两个必填字段**——没有它们，"证书覆盖"与"动作空间"都是空话。三个新机制（证书、陈旧折算、可选性）只经"集合更小"或"退路更多"两条安全通道起作用。

云边协议 CEB+++ → **CEB-A（Action-Certified）**：云端下发 **三类证书**——KG 增量证书（带 scope/ver/lease）、元模型适配器证书（走第 58 轮 SFT-KG 完整审计）、动作空间证书（带 A_cert/cond/g/lease/δ_ref）；**边缘只接受证书，不接受裸决策**，且任何扩张必须走 Act(C_A) 四重校验并记审计。边端回传：租约失效事件、本地反例、细化越界、退路失败、A_core 触发、证书重放摘要、每检查点实际执行 cell——作为云端重编译与租约时长整定的校准集。第 58 轮"知识图谱走隔离"在本轮延伸为：**动作空间也走隔离——云端只能写入被证书背书的子集，本地只能删除/收缩，任何扩张都要有可独立重放的凭据**。

## 6. 本轮最大风险

**一句话**：本轮把"信任"从模型置信换成了**证书 + 租约**——证书可靠性和条件声明成了新的单点先验；若云端在租约有效期内把"干地"误声明为"冰面也已覆盖"，或粗粒度 cell 的细化护栏漏掉一个打滑微动作，边缘会因为"证书看起来有效"而把危险动作留在集合里，而结构性非扩张只能保证集合不涨、不能保证集合本身正确；必须以短租约、边缘条件反例、最坏细化护栏、A_core 永存与证书独立重放五重护栏，宁可把证书切碎、提前退回安全核，也绝不把"云端说可以"当作"世界说可以"。
