# 第 12 轮（新灵感循环第 1 轮；本轮灵感：「夹爪控制」×「论文创新点」）
> **基线**：第 11 轮 MetricVoiceGauge-GSCF-SRA-JSSE（定义 549–561；引理 92–96；实验 E591–E610）。
> 本轮纪律：**接触判真 + 可证伪归约**。两个灵感治理 v11 的两笔债：**落地债**（v11 把安全证书越堆越高，但一切安全最终都要在接触面兑现；JSSE 的“中止等价”只证了末端位姿等价，握着物体时并不等于物体安全——可能滑落/压碎）、**创新债**（模块与缩写持续通胀，“到底哪个机制在支撑主命题”无法回答；v11 的 ε 仍多为点估计）。必须保持铁律：新组件失效 ⇒ 声明中立元，行为对 v11 **等价**（GCC）或**支配**（OFSA 只收缩/保守）；FRB 失效 ⇒ 只失去“贡献认证”，物理行为不变。本轮更强：**先立一条可被实验打败的主定理，再让每个模块回答“删了我，哪个指标会坏”**；不能回答的模块降级为工程细节，不再算创新点。

## 0. 直觉与动机

**灵感 1（夹爪控制 → 安全最终在接触面兑现）**
直觉：v6→v11 的证书全部以“位姿—间隙—力矩”为中心，但抓取任务里唯一不可逆的物理损失发生在**接触面**：物体滑落、被压碎、脱手飞出。v11 的 JSSE 把中止写成“FK(q_abort)=p*±ε_fk 并保持”，这是**末端执行器坐标系的等价**，不是**物体坐标系的安全**——握着杯子急停时，杯子仍可能因惯性滑出或被夹碎。夹爪控制给出了真正的判据：摩擦锥、力闭合、滑移裕度、压碎上限、力窗可行性。核心创新：**接触接地证书（Grounded Contact Certificate, GCC）**——用抓取矩阵 G 把预测外力旋量映射为所需接触力，用**标定摩擦下界 μ_lo** 计算滑移裕度 ρ_c 与压碎裕度 c；块证书增列 (ρ_c, c, W(a))。关键一步：把“抓得稳”从视觉分数 γ̂_grasp 升级为**接触物理命题**，它不依赖语义/外观，因而不会被对抗纹理欺骗；同时也把 v11 中止假设的隐藏漏洞显式化。

**灵感 2（论文创新点 → 创新是“评估轴上可证伪的增量”，不是模块数量）**
直觉：审稿人不会为第 13 个模块买单，只会为“在一个已被接受的评估轴上，比基线多走了一步，且这一步可被实验打败”买单。v11 已积累 25+ IP、96 条引理，但“删掉哪个模块主命题会坏”没有统一答案——这是**创新债**。核心创新：**证伪-归约委员会（Falsification & Reduction Board, FRB）**——把每个模块写成贡献元组 C=(claim, channel, falsifier, δ_min, ablation, status)，其中 channel 是“断言的证据通道”（几何/接触/时序/规范），falsifier 是“主张为假就必然失败的最小实验”，δ_min 是预注册最小可分离效应。**归约算子 Reduce** 把模块分为 TIGHTEN（收紧主定理界）/WIDEN（扩大适用域）/CHEAPEN（降低证据成本）/DEMOTE（不能回答“删了我哪条实验变差”⇒ 降级为工程细节）。本轮只保留一条主定理 **CGFAT**（接触接地的可证伪中止定理），其余模块必须挂在主定理上；这与「断在哪，证在哪」同构。

**灵感 3（咬合：把 v11 的三重守护压成“一主二辅”）**
直觉：v11 的三重守护各自失效模式可能同时触发（强遮挡+动态+标定漂移），说明“层数”不等于“鲁棒性”。本轮不再加第四重守护，而是：GCC 证接触侧、OFSA 证物体坐标系中止、FRB 证“这两个证明确实在支撑主张”。三者共同把 v11 证书 Ĉ⁺⁺ 升级为**接触接地证书 Ĉ^c = (ĝ_min, ê_max, β_GSCF, n_t, n_t^reason, Q_abort^obj, ρ_c, c, W(a), h_claim)**；若力窗为空，不硬撑，进入**受控释放**。关键纪律：**接触通道只能否决，不能放行**——它绝不允许 v11 本会中止的动作继续，只把已触发的保守中止改成不丢物体的中止。这样 v12 不引入新的危险延续行为，只把“保守但可能损坏物体”的中止升级为“保守且物体安全”的中止。

## 1. 研究问题（轮次升级版）

- **Q1（接触判真）**：如何把 γ̂_grasp 升级为带摩擦下界 μ_lo 的接触证书，使在预测外力旋量误差 ≤β_w 下力闭合成立、滑移 ≤ε_slip、压碎力 ≤F_crush，且接触模型不可用时严格退化为 v11？
- **Q2（物体坐标中止）**：如何定义并实现物体坐标系的等价中止，使握着物体时的中止/受控释放不滑落、不压碎，并把 v11 的 EE 等价升级为 object-frame 等价（原假设被显式修补）？
- **Q3（可证伪归约）**：如何用贡献元组 + 归约算子 + 证伪台，把 v11 的模块通胀压缩为一条可消融主定理，使每个保留模块都能给出“删了我哪个指标变差 ≥δ_min”的预注册证据，且 δ_min 有统计功效保证？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 接触判真律（Contact-Physical Grounding, GCC）**
抓取/搬运安全必须由接触物理裕度（摩擦锥、力闭合、滑移、压碎）判定；视觉/语义分数只能作为先验，不能作为放行依据；μ_lo 必须标定且保守；接触模型不可用时不得静默信任，退化为 v11。

**P17 物体坐标等价律（Object-Frame Equivalence, OFSA）**
任何中止/急停等价性必须在物体坐标系陈述；EE 坐标等价只是必要条件，不是充分条件；力窗为空 ⇒ 受控释放，绝不维持不安全夹持。

**P18 可证伪归约律（Falsifiable Reduction, FRB）**
每个被称“创新点”的模块必须拥有 (channel, falsifier, δ_min, ablation)；无法在预注册实验中与基线分离的模块降级为工程细节；证伪债务未清零不得发布主张；归约只改“贡献清单”，不改“运行时控制器”，任何运行时删除需另立安全案。

## 3. 与基线的接口（如何退化）

- **GCC 失效**（力觉/触觉不可用、μ 标定过期、力窗不可解）⇒ ρ_c←∞、c←∞、证书回 v11 Ĉ⁺⁺：物理行为严格等价 v11（放弃接触约束，不静默更信任）；
- **OFSA 失效**（物体位姿不可得、恢复规划超时、运动学损坏）⇒ 回 v11 JSSE 关节空间急停保持（等价 v11 Level-3），但台账标记“物体安全未证”；
- **力窗为空**（W(a)=∅）⇒ 受控释放（支撑面已知）/ 最低可达高度释放（未知），绝不维持不安全夹持；
- **FRB 失效** ⇒ h_claim←⊥、所有主张标 unverified，物理行为不变；
- **GSCF/SRA/STF/NRB/AC/ID/MW/v8 失效** ⇒ 沿 v11 九级退化链原样下移；
- **单调性**：接触通道只做 AND 否决与中止模式选择，不产生新的任务空间延续动作；故 v12 的“继续执行集” ⊆ v11，“中止集”增加但均为物体安全中止或受控释放。

## 4. 预期贡献

1. **接触接地证书**：用摩擦锥/压碎/滑移裕度替换标量抓取分数，使接触通道成为不可被语义欺骗的第二物理判据（引理 97–98）；
2. **物体坐标安全中止**：显式修补 v11 引理 95 的 EE 坐标假设，给出握持状态下的中止等价与受控释放（引理 99–100）；
3. **可证伪归约**：贡献元组 + Reduce + 证伪台，把“创新点”从不可检验的模块清单变成可消融的主定理（引理 102–103）；
4. **E611–E632** 覆盖 μ_lo 标定、力窗、滑移/压碎、物体坐标中止、受控释放、双通道仲裁、消融必要性、δ_min 功效、长跑与竞赛。

## 5. 本轮最大风险

**一句话**：GCC 的“滑移为零”依赖**刚性抓取 + 已知质量/惯量 + μ_lo 保守 + 力觉可信**这一组模型假设，OFSA 的“物体坐标等价”又仍建立在同一套标定 FK/T_g 上——对软体/未知物体、湿滑表面、力觉饱和、μ_true<μ_lo 或系统性运动学偏差，力窗会给出**虚假非空**、等价目标本身被带偏，物体仍可能滑落/压碎；FRB 的 δ_min 若被设小或统计功效不足，还会把这种失效判成“有贡献”，形成“可证伪外观下的不可证伪”。

**新增定义 562（接触状态与接触旋量）** 接触状态 o_c(t) 记录 m 个接触点的法向力 f_{n,i}、切向力 f_{t,i}、接触点 p_i、法向 n_i、滑移速度 v_{s,i}，以及传感器健康标志 λ_c=(fresh, calibrated, saturated)。物体所受接触旋量 w_c=Σ_i [f_i; p_i×f_i]。接触通道只依赖本体感觉/触觉/力觉与标定运动学，不依赖视觉、语义或 VQA。

**新增定义 563（抓取矩阵与所需接触力）** 抓取矩阵 G(q)∈R^{6×3m} 把接触力映射为物体旋量。给定预测外力旋量 ŵ_ext，名义所需接触力
```
f* = argmin_f ‖f‖²  s.t.  G f = −ŵ_ext,
     f_{n,i} ≥ 0,  ‖f_{t,i}‖ ≤ μ_lo f_{n,i},  Σ_i f_{n,i} ≤ F_crush.
```
这是一个小规模二阶锥/线性化 QP，5Hz 块生成期求解；不可行 ⇒ GCC 无效（而不是降级为视觉信任）。

**新增定义 564（滑移裕度与滑移分数）** 定义 μ_req,i=‖f*_{t,i}‖/max(f*_{n,i},ε)、ρ_i=μ_lo f*_{n,i}−‖f*_{t,i}‖、ρ_c=min_i ρ_i/f_scale，其中 f_scale 为压碎力标称值。ρ_c>0 表示名义摩擦锥内；ρ_c≥ρ_min+裕度表示对预测误差鲁棒。另定义 σ_s=max_i ‖v_{s,i}‖ 的 5 帧 EMA，作为滑移领先指标。

**新增定义 565（压碎裕度）** 设 F_crush,i 为第 i 个接触的压碎力上限，F_crush=Σ_i F_crush,i 为总预算；c_i=(F_crush,i−f*_{n,i})/f_scale，c=min_i c_i。F_crush,i 由材料标定给出；材料未知时取保守下限或令 GCC 无效。c≥c_min 保证夹持力不越过压碎上限（含力跟踪误差 ε_f）。

**新增定义 566（力窗）** 对中止轨迹的物体加速度/角加速度 (a_o,α_o)，物体所需外力旋量 w(a)=[m_o(a_o+g); I_oα_o+ω_o×I_oω_o]。定义最小持握法向力
```
F_slip(w) = min { Σ_i f_{n,i} | ∃f: G f=−w, ‖f_{t,i}‖≤μ_lo f_{n,i}, f_{n,i}≥0 }.
```
力窗 W(w)=[F_slip(w)+L_f(β_w+ε_f)+δ_f, F_crush−L_f ε_f−δ_c]。W(w) 非空 ⇔ 存在既不打滑也不压碎的静态持握。对称双指特例：F_slip=m_o a_eff/(2μ_lo)，a_eff=√(‖a_o+g‖²+(I_o‖α_o‖/(m_o r_g))²)；可证安全减速度 a_safe 满足 F_slip(w(a_safe))≤F_crush−δ_c。

**新增定义 567（物体坐标位姿与中止集）** x_o(q)=T_g∘FK(q)，T_g 为标定抓取变换，误差 ‖T_g−T̂_g‖≤ε_g。安全物体域 X_safe 包含无碰撞、高度/姿态在支撑域、速度/加速度受限。定义
```
Q_abort^obj = { q ∈ C_q_safe | x_o(q) ∈ X_safe,
                W(w(a_abort)) ≠ ∅, ‖x_o(q)−x_o^*‖ ≤ ε_obj }.
```
其中 x_o^*=T_g p* 为任务空间中止点对应的物体目标位姿，ε_obj=ε_g+ε_fk（见引理 99）。

**新增定义 568（接触接地证书）** Ĉ_t^c 有效当且仅当：v11 定义 552 的 Ĉ⁺⁺ 有效；U_t^c 成立；ρ_c≥ρ_min+L_f(β_w+ε_f)/f_scale；c≥c_min；σ_s≤σ_max；且 (Q_abort^obj≠∅ 或存在受控释放计划 R_safe)。接近阶段（未接触）GCC 不参与，回 v11 的 β_GSCF；抓取/搬运/释放阶段 GCC 参与。

**新增定义 569（物体坐标安全中止 OFSA）** OFSA 把任务空间中止点 p* 映射为物体安全动作：
1. 若 W(w(a_abort))≠∅ 且 Q_abort^obj≠∅：选 q_abort=argmin_{q∈Q_abort^obj}‖q−q_current‖，沿满足 a_o≤a_safe−a_margin 的关节插值执行，同时把夹持法向力指令限制在 W(w(t))∩[F_slip+δ_f, F_crush−δ_c]；
2. 若力窗为空：执行受控释放 Rec（支撑已知 → 降至支撑面 h_s 再张开；支撑未知 → 降至最低可达高度 h_min，以受限速度 v_r 张开）；
3. 若 OFSA 规划失败：回 v11 JSSE 关节急停保持，并标“物体安全未证”。

**新增定义 570（接触信任域）** U_t^c=(freshness(o_c)≤T_c) ∧ calibrated(μ_lo) ∧ ¬saturated(force) ∧ valid(T_g) ∧ (material_known ∨ conservative_bound)。任一不满足 ⇒ GCC 失效，按 Level-1 回 v11，不得用视觉分数替代接触证书。

**新增定义 571（接触接地证书元组）** Ĉ_t^c=(ĝ_min, ê_max, γ̂_grasp, β_GSCF, n_t, n_t^reason, Q_abort^obj, ρ_c, c, W(a), σ_s, h_claim)。h_claim 是 FRB 对该块所用主张的哈希（可为 ⊥）；它不参与控制，只用于审计“这块动作基于哪条已注册主张”。

**新增定义 572（贡献元组）** 每个模块 m 注册 C_m=(claim_m, channel_m, falsifier_m, δ_min,m, ablation_m, status_m)。channel∈{geo, contact, temporal, norm, system}；claim 必须是“在指标 μ 上，相对基线 B 的增量 ≥δ”；falsifier 是一个最小实验及预注册失败条件；ablation 是移除 m 的对照；status∈{unverified, verified, refuted, demoted}。没有 channel 或 falsifier 的模块不得称创新点。

**新增定义 573（可分离性与 δ_min 功效约束）** Sep(C_m) 成立当且仅当预注册的消融/证伪实验给出 Δ_m≥δ_min，且 Δ_m 的 1−α 置信下界 ≥δ_min，统计功效 ≥1−β；同时 δ_min≥MDE(n,σ,power)，其中 MDE=(z_{1−α}+z_{1−β})σ√(2/n)（两样本近似），多重比较用 Holm 校正。δ_min 小于 MDE ⇒ 该主张“不可检测”，不得注册为创新点。此约束防止“把 δ_min 设成 0.001 来自证有贡献”。

**新增定义 574（归约算子 Reduce）** Reduce 把模块集 M 映射为带标签的有向图 D，边指向 CGFAT 的指标向量 (ε_slip, ε_drop, ε_obj, F_crush, L_abort, E_cost)：
- TIGHTEN：在相同假设下严格收紧至少一个上界；
- WIDEN：扩大适用域（物体类别/接触模式/扰动）且不放松任何上界；
- CHEAPEN：相同界下降低算力/能耗/标注成本，且按 P15 携带证据预算；
- DEMOTE：以上皆不成立，或其消融效应 <δ_min。
DEMOTE 只把模块从**贡献清单**移除，不自动从控制器移除；任何运行时删除需另立安全案与证伪实验。D 必须无环，且每条边可追溯到一条实验。

**新增定义 575（证伪债务与主张台账）** D_f=Σ_m [status_m≠verified]。发布门槛：D_f=0，或对每个未验证主张在“Limitations”中显式登记（含缺失实验、功效、风险）。FRB 维护 append-only 哈希链台账 Λ_claim，记录 (C_m, falsifier 结果, Δ_m, CI, n, power, 代码版本, 数据版本)；篡改可检出，缺口本身触发“主张降级”。

**新增定义 576（主定理 CGFAT：接触接地可证伪中止定理）** 在以下假设下：
(A1) μ_true≥μ_lo 以概率 ≥1−δ_μ；
(A2) 预测外力旋量误差 ‖w_ext−ŵ_ext‖≤β_w；
(A3) 接触力跟踪误差 ≤ε_f；
(A4) 抓取变换误差 ≤ε_g；
(A5) 运动学误差 ≤ε_fk；
若 GCC 有效且力窗 W(w(a_abort)) 非空，则 OFSA 中止满足：滑移位移 ≤ε_slip、夹持力 ≤F_crush、物体坐标等价 ‖x_o(q_abort)−x_o^*‖≤ε_obj=ε_g+ε_fk；若力窗为空，则受控释放的跌落高度 ≤ε_drop。并且该主张在证伪台上可被反驳：若移除 GCC 或 OFSA 后没有任何 CGFAT 指标恶化 ≥δ_min，则“接触接地/物体坐标中止”作为创新点被证伪并降级。CGFAT 是 v12 唯一要求读者检验的主命题，其余模块只作为其支撑或工程细节。

**新增定义 577（反事实见证）** 每次中止/守卫触发时，记录影子 v11 动作 a_v11 与预测指标 m_v11（含模型误差界），形成 WΔ=(a_v12, a_v11, Δm±e_m)。WΔ 只用于 FRB 的离线贡献归因与在线审计，**绝不回灌当期控制**；WΔ 缺失/写入失败 ⇒ 该次事件不计入贡献证据，物理行为不变。

# IP-365 GroundedContactCertificate：接触接地证书（5Hz + 50Hz 守卫）
class GroundedContactCertificate:
    def __init__(self, kin, dyn, mu_lo, F_crush, f_scale=50.0,
                 rho_min=0.15, c_min=0.10, sigma_max=0.02,
                 T_c=0.05, beta_w=2.0, eps_f=0.5,
                 L_f=1.0, delta_f=0.5):
        self.kin, self.dyn = kin, dyn
        self.mu_lo, self.F_crush, self.f_scale = mu_lo, F_crush, f_scale
        self.rho_min, self.c_min, self.sigma_max = rho_min, c_min, sigma_max
        self.T_c, self.beta_w, self.eps_f = T_c, beta_w, eps_f
        self.L_f, self.delta_f = L_f, delta_f
        self.o_c = None

    def required_forces(self, G, w_hat):
        # 小规模 QP：min ||f||^2 s.t. G f = -w_hat, 摩擦锥内, 合力上限
        return solve_contact_qp(G, -w_hat, self.mu_lo, self.F_crush, warm_start=True)

    def margins(self, G, f_star):
        rho = min((self.mu_lo * f_star.n[i] - norm(f_star.t[i])) / self.f_scale
                  for i in range(f_star.m))
        F_crush_i = self.F_crush / f_star.m               # 均分；实际可用逐接触标定数组
        c = min((F_crush_i - f_star.n[i]) / self.f_scale
                for i in range(f_star.m))
        return rho, c

    def force_window(self, object_model, a_cmd):
        w = object_model.inertial_wrench(a_cmd)          # [m(a+g); Iα+ω×Iω]
        F_slip = object_model.min_hold_force(w, self.mu_lo, self.F_crush)
        lo = F_slip + self.L_f * (self.beta_w + self.eps_f) + self.delta_f
        hi = self.F_crush - self.L_f * self.eps_f - self.delta_f
        return (lo, hi) if lo <= hi else None            # None ⇒ 空窗

    def certify(self, G, w_hat, object_model, a_cmd, contact_state, U_c):
        if not U_c:
            return None                                  # Level-1：回 v11
        f_star = self.required_forces(G, w_hat)
        if f_star is None:
            return None
        rho, c = self.margins(G, f_star)
        W = self.force_window(object_model, a_cmd)
        rho_req = self.rho_min + self.L_f * (self.beta_w + self.eps_f) / self.f_scale
        if rho < rho_req or c < self.c_min or W is None:
            return None
        sigma_s = contact_state.slip_score()             # 5 帧 EMA
        if sigma_s > self.sigma_max:
            return None
        return ContactCert(rho, c, W, sigma_s, f_star)

    def guard_check(self, G, w_hat, object_model, a_cmd, o_c, U_c):
        # 50Hz 检 6：O(m)，≤0.1ms
        cert = self.certify(G, w_hat, object_model, a_cmd, o_c, U_c)
        rho_req = self.rho_min + self.L_f * (self.beta_w + self.eps_f) / self.f_scale
        return cert is not None and cert.rho >= rho_req


# IP-366 ObjectFrameSafeAbort：物体坐标安全中止（5Hz 规划 + 1kHz 执行）
class ObjectFrameSafeAbort:
    def __init__(self, kin, dyn, gcc, eps_g=0.002, eps_fk=0.002,
                 a_margin=0.20, v_r=0.05, h_min=0.02, t_detect=0.05,
                 eps_drop=0.03):
        self.kin, self.dyn, self.gcc = kin, dyn, gcc
        self.eps_g, self.eps_fk = eps_g, eps_fk
        self.a_margin, self.v_r = a_margin, v_r
        self.h_min, self.t_detect, self.eps_drop = h_min, t_detect, eps_drop

    def object_pose(self, q, T_g):
        return T_g.compose(self.kin.fk(q))

    def plan(self, p_star, T_g, q_current, object_model, support=None):
        x_star = T_g.apply(p_star)                       # 物体坐标中止目标
        a_safe = object_model.a_safe(self.gcc.mu_lo, self.gcc.F_crush,
                                     margin=self.a_margin)
        Q = self._object_abort_set(T_g, x_star, object_model, a_safe)
        if Q:
            q_abort = min(Q, key=lambda q: norm(q - q_current))
            return ('abort_object', q_abort, a_safe)
        h_min = self._reachable_h_min()
        if support is not None:                          # 空窗：受控放置
            return ('release_to_support', support, self.v_r)
        if h_min <= self.eps_drop:                       # 空窗：最低高度释放
            return ('release_low', h_min, self.v_r)
        return ('release_unsafe', h_min, self.v_r)       # 标记并请求人工接管

    def execute(self, plan, q_current, contact_state):
        kind, target, param = plan
        if kind == 'abort_object':
            traj = self._joint_interp(q_current, target, param)
            F_cmd = clamp(self.gcc.hold_force(contact_state),
                          *self.gcc.force_window_for(param))
            return ('joint_traj', traj, F_cmd)
        if kind in ('release_to_support', 'release_low'):
            return ('controlled_release', target, param)
        if kind == 'release_unsafe':
            return ('controlled_release_flagged', target, param)  # 请求接管
        return ('jsse_emergency_hold', q_current, None)

    def _object_abort_set(self, T_g, x_star, object_model, a_safe):
        # 离散候选 q（或用 JSSE 的 Q_abort 做初值），过滤 x_o∈X_safe、力窗非空
        return [q for q in self._candidate_q(x_star)
                if self._in_X_safe(self.object_pose(q, T_g))
                and self.gcc.force_window(object_model, a_safe) is not None]

# IP-367 FalsificationReductionBoard：证伪-归约委员会（离线，不改控制回路）
class FalsificationReductionBoard:
    def __init__(self, ledger, metrics=('eps_slip','eps_drop','eps_obj',
                                       'F_crush','L_abort','E_cost')):
        self.ledger, self.metrics = ledger, metrics
        self.claims = {}

    def register(self, module_id, claim, channel, falsifier, delta_min,
                 ablation, n, sigma, alpha=0.05, power=0.8):
        mde = (z(1 - alpha) + z(power)) * sigma * sqrt(2.0 / n)
        if delta_min < mde:
            raise ValueError('delta_min < MDE: claim undetectable')
        self.claims[module_id] = Claim(module_id, claim, channel, falsifier,
                                       delta_min, ablation, 'unverified', n, power)

    def falsify(self, module_id, result):
        c = self.claims[module_id]
        c.delta, c.ci = result.delta, result.ci
        c.status = ('verified' if result.delta >= c.delta_min
                    and result.ci.lo >= c.delta_min and result.power >= c.power
                    else 'refuted')
        self.ledger.append(c)

    def reduce(self, modules):
        D = {}
        for m in modules:
            cls = classify(m, self.claims)
            D[m.id] = (cls, [e for e in m.edges if e.target in self.metrics])
        return D

    def debt(self):
        return sum(1 for c in self.claims.values() if c.status != 'verified')

    def release_gate(self):
        return self.debt() == 0

## 3. 推导

**引理 97（GCC 的鲁棒力闭合可靠性）** 设在 (A1)–(A3) 下，GCC 以摩擦锥内解 f* 计算裕度，并满足 ρ_c≥ρ_min+L_f(β_w+ε_f)/f_scale、c≥c_min；若抓取矩阵 G 列满秩或使用其最小范数广义逆，且 F_slip 对 w 的 Lipschitz 常数为 L_f，则真实外力旋量 w_ext 下存在接触力 f（‖f−f*‖≤L_G(β_w+ε_f)）使所有接触点严格在摩擦锥内，滑移裕度 ≥ρ_min f_scale，且夹持力 ≤F_crush。证明：f* 对 ŵ_ext 的扰动经 G^+ 线性放大，误差上界 L_G β_w；接触力跟踪再引入 ε_f；摩擦裕度对 f 的 Lipschitz 性给出最多 L_f(L_G β_w+ε_f) 的损耗，由 ρ_min 余量吸收；压碎裕度同理。若 G 非满秩，则以最小范数解和最小奇异值给出同类界。∎

**引理 98（力窗可行性与中止滑移界）** 给定中止轨迹的 (a_o(t),α_o(t)) 与对应 w(t)，若对每个控制周期选择的夹持法向力 F_n(t) 满足 F_n(t)∈W(w(t))，且接触力跟踪误差 ≤ε_f，则整个中止过程无宏观滑移（滑移位移 ≤ε_slip=v_ε·T_guard，v_ε 为传感器噪声等效速度）。若 W(w(t)) 在某个 t 为空，则不存在同时满足“不打滑”和“不压碎”的静态持握力。证明：W 的定义就是摩擦锥可行性与压碎约束的交；非空即存在可行 f。滑移由静摩擦未饱和保证；传感器噪声只造成 ≤v_ε·T_guard 的等效位移。空窗时两约束矛盾，故无解。∎

**引理 99（物体坐标中止等价——修补 v11 引理 95）** 设 x_o(q)=T_g∘FK(q)，‖T_g−T̂_g‖≤ε_g，‖FK(q)−FK_true(q)‖≤ε_fk。若 OFSA 选择 q_abort 使 x_o(q_abort) 距目标 x_o^*=T_g p* 最近，则
```
‖x_o(q_abort) − x_o^*‖ ≤ ε_g + ε_fk + L_FK‖q_abort−q*‖,
```
其中 q* 为精确逆解；在 OFSA 的离散候选集上取最近点可把最后一项并入 ε_obj。更重要的是，OFSA 额外约束物体加速度 a_o≤a_safe 与力窗非空，故由引理 98 得滑移 ≤ε_slip、夹持力 ≤F_crush。反观 v11 引理 95 只证 ‖FK(q_abort)−p*‖≤ε_fk，**未约束物体速度/加速度与接触力**；当握持物体时，EE 等价不蕴含物体安全（急停惯性可使物体滑出，或夹持力越过压碎上限）。因此 v12 把“中止等价”从 EE 坐标升级为物体坐标，并显式补上接触约束。∎

**引理 100（空窗受控释放的安全界）** 若 W(w) 为空，则任何静态夹持力要么 <F_slip（滑移）要么 >F_crush（压碎），故静态保持不可证安全。OFSA 的受控释放：(i) 支撑已知：降至支撑面 h_s 后张开，冲击速度 ≤v_r，无自由跌落；(ii) 支撑未知：降至最低可达高度 h_min，以速度 v_r 张开，检测延迟 t_detect，跌落高度
```
h_drop ≤ h_min + v_r t_detect + ½ g t_detect²,
```
冲击能量 ≤m_o g h_drop。若 h_drop≤ε_drop，则释放满足预注册的跌落/能量上界；否则标记“无法安全释放”，进入最低风险姿态并请求人工/远程接管。证明：运动学与能量守恒；释放瞬间物体仅受重力，故自由落体高度由初速度、检测延迟与释放高度决定。∎

**引理 101（单边仲裁：接触只能否决，不能放行）** 定义 v12 的“继续执行集” C_v12 与 v11 的 C_v11。由于 (i) GCC 检 6 只在接触异常时触发中止，(ii) 接触正常时不会把 v11 已判定的中止改回继续，(iii) FRB 不进入控制回路，故 C_v12 ⊆ C_v11。v12 新增的只是中止模式的细化（OFSA 物体安全中止/受控释放），以及 GCC 触发的更早中止；中止是动作空间的收缩，不是扩张。因此 v11 的最大风险之一“GSCF 虚假低导致 K_eff 长期收缩”不会被 v12 用“接触放行”来掩盖——v12 仍付同样的保守代价，但把保守中止变成不丢物体的中止；要消除该效率代价必须允许接触放行，这会破坏支配性，故本轮明确不做。∎

**引理 102（归约可靠性：无无主主张）** 若 FRB 对每个保留模块执行了预注册 falsifier/ablation，且 Sep(C_m) 要求 Δ_m≥δ_min、CI 下界≥δ_min、功效≥1−β、δ_min≥MDE，则论文贡献清单中的每条主张都对应至少一条可复现实验和一个明确的消融路径；任何 DEMOTE 模块的 Δ_m<δ_min 或缺少 channel，故其不能作为贡献。若 FRB 失效，则所有主张 status=unverified，控制行为不变。证明：由定义与假设检验的直接构造；多重比较用 Holm 校正保证家族错误率 ≤α。DEMOTE 只改贡献清单，不改控制器，故不会因“降级”而引入运行时安全风险。∎

**引理 103（联合保守性与支配性）** 在 (A1)–(A5) 下，GCC/OFSA 健康时 v12 的碰撞/跌落/压碎联合风险满足
```
P_unsafe(v12) ≤ P_unsafe(v11) + δ_μ + δ_w + δ_f + δ_g + δ_rel,
```
且当 GCC 或 OFSA 失效时严格回退 v11（前两项误差项消失，行为等价）。v12 不引入新的任务空间延续动作，所有新增动作都是中止或释放；故相对 v11 是保守精化而非能力扩张。证明：由引理 97–101 与并集界；各失败模式（摩擦标定、外力预测、力跟踪、抓取变换、释放支撑）在不同物理通道，联合失效概率用并集界控制。∎

## 7. 本轮最大风险

**一句话**：GCC 的“滑移为零”依赖**刚性抓取 + 已知质量/惯量 + μ_lo 保守 + 力觉可信**这一组模型假设，OFSA 的“物体坐标等价”又仍建立在同一套标定 FK/T_g 上——对软体/未知物体、湿滑表面、力觉饱和、μ_true<μ_lo 或系统性运动学偏差，力窗会给出**虚假非空**、等价目标本身被带偏，物体仍可能滑落/压碎；FRB 的 δ_min 若被设小或统计功效不足，还会把这种失效判成“有贡献”，形成“可证伪外观下的不可证伪”。
