# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；灵感驱动循环第 1 轮；本轮灵感：「指令泛化」×「力矩控制」）

> 第 54 轮把技能从「能力」剖面化为动作空间占用 `α_S`，并把云边协同做成「粗规划—细校验—反向解释—重剖分」的闭环。本轮把视线从**动作层**继续下沉到**物理层**，同时把输入从**任务序列**上抬到**自然语言指令**。核心矛盾：H22：语义等价不等于力矩可行等价——同一指令的两个改写（paraphrase）可落到同一任务规格，却在负载/接触/摩擦变化下给出完全不同的力矩剖面；H23：动作空间证书在位置/速度层成立，却对力矩饱和、力矩变化率带宽一无所知，导致「动作可行、物理不可执行」的静默失效。

## 0. 直觉与动机

**灵感 1（指令泛化不是语言近邻，而是力矩可行域的原像）**
直觉：我们通常把「指令泛化」理解为对改写、语序、同义词的鲁棒性。但机器人真正执行的是力矩轨迹，不是句子。设指令 `i` 在上下文 `c` 下经接地函数 `κ` 得到任务规格 `κ(i,c)`，技能 `S` 的力矩可行集为 `𝕋_S(c)`。那么技能对指令的泛化域应当是
```
D_I(S,c) = { i ∈ I | ∃ τ∈𝕋_S(c): τ 满足 κ(i,c) 且 μ_S(τ,c) ≥ μ_min }
```
即**力矩可行集在接地映射下的原像**。这条直觉把「指令泛化」从 NLP 指标变成可判定的物理覆盖问题：一句改写能不能被泛化，取决于它是否落在同一片力矩可行域里，而不是它和原句的余弦相似度。

**灵感 2（力矩裕度谱 → 给动作证书补一条物理地板）**
直觉：第 54 轮的 `ρ` 描述「扰动下还能不能成」，`α_S` 描述「动作占不占得到」，但二者都可以在力矩饱和前就为真。给技能补一条**力矩裕度谱** `μ_S(t;c) = min_j (1 - |τ_j(t)|/τ_j^max)`，它沿轨迹逐点给出距离执行器极限的相对余量。`min_t μ_S` 就是该技能的**物理地板**；地板低于阈值时，任何动作空间上的「可行」都是纸面可行。于是鲁棒性谱 `ρ` 负责「扰动维」，力矩裕度 `μ` 负责「物理维」，二者正交。

**灵感 3（语义-力矩错配 → 指令近邻，力矩远邻）**
直觉：最危险的不是明显不同的指令，而是**语义上几乎相同、力矩上却分叉**的改写。例如「轻轻放下」与「放稳一点」在语义空间距离很小，但前者约束接触力上界，后者约束终端速度，接地后会生成不同的 `τ(t)`；在重载或低摩擦上下文里，一个可行、一个饱和。定义**语义-力矩错配度** `div_τ(i1,i2;c)`：语义距离小、力矩轨迹距离大，就是一条「语义别名陷阱」。泛化测试必须专门采样这类对，否则高泛化率只是语义平滑带来的假象。

**灵感 4（力矩感知的组合与反射护栏）**
直觉：第 54 轮的组合图只看动作兼容 `compat` 与转换成本 `c_trans`，但两个动作兼容的技能在切换瞬间可能要求力矩突变，超过执行器带宽 `B_τ`。因此组合边还要检查**力矩连续性** `c_τ(S_i,S_j) ≤ B_τ` 与**组合地板** `μ_{S_i⊗S_j} ≥ μ_min`。同时需要一个在线**力矩反射护栏**：当 `μ(t)` 跌破安全线时，立即降级为柔顺/限幅/重规划，并把这次触发作为反例写回证书——它相当于力矩层的「绊线」，宁可保守停一下，也不让饱和悄悄穿透。

**灵感 5（指令-力矩联合证书 → 上抽象与下接地的双向一致性）**
直觉：第 54 轮的联合证书 `J=(ρ,A_cert,γ_ce,δ_a)` 是「动作-鲁棒」二维的。本轮补成**指令-力矩联合证书** `J_IT=(𝒞_sem, ρ, μ_env, D_I, C_env, evidence)`：
- 向上（语义抽象）：`𝒞_sem` 声明该技能覆盖的指令等价类；
- 向下（物理接地）：`μ_env` 声明在上下文包络 `C_env` 内力矩地板不低于 `μ_min`；
- 中间用 `D_I` 把二者锁在一起：`D_I` 是原像，不是语言聚类。
这样，指令泛化与力矩控制不再是两个模块，而是同一张证书的两个方向。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（指令接地与改写邻域）**
指令空间 `I`，上下文空间 `C`（负载、接触、摩擦、温度等）。接地映射 `κ: I × C → 𝒯` 把指令映射为任务规格。改写邻域 `N_ε(i) = { i' | d_sem(i,i') ≤ ε }`，`d_sem` 为语义编辑距离（同义替换、语序、指代消解）。

**定义 122（力矩裕度谱与上下文包络）**
单关节力矩 `τ_j(t)`，极限 `τ_j^max`。归一化力矩裕度
```
μ_j(t;c) = 1 - |τ_j(t;c)| / τ_j^max,    μ_S(t;c) = min_j μ_j(t;c)
μ_S^*(c) = min_t μ_S(t;c)
```
上下文包络 `C_env ⊆ C` 是证书声明「力矩结论仍成立」的闭集；`μ_env(S) = min_{c∈C_env} μ_S^*(c)`。

**定义 123（指令泛化域与半径）**
```
D_I(S,c) = { i ∈ I | ∃ τ∈𝕋_S(c): τ ⊨ κ(i,c) ∧ μ_S(τ,c) ≥ μ_min }
r_I(S,i,c) = sup{ ε ≥ 0 | N_ε(i) ⊆ D_I(S,c) }
```
`r_I` 是**物理接地后的泛化半径**，不是语言模型的置信度。

**定义 124（操作等价与力矩见证）**
两指令**操作等价** `i1 ≡_op i2` 当且仅当 `∀ S,c: i1∈D_I(S,c) ⇔ i2∈D_I(S,c)`。若 `i1 ~ i2`（语义等价）但 `i1 ≢_op i2`，则存在**力矩见证** `w_τ = (S,c,τ_1,τ_2)` 使二者可行性子集不同。证书必须携带 `w_τ` 或显式声明无见证的上下文包络。

**定义 125（语义-力矩错配度）**
```
div_τ(i1,i2;c) = || τ*(i1,c) - τ*(i2,c) ||_∞ / max_j τ_j^max
```
其中 `τ*(i,c)` 为最优可行力矩轨迹。若 `d_sem(i1,i2) ≤ ε` 且 `div_τ(i1,i2;c) ≥ θ_τ`，称 `(i1,i2)` 为**语义别名陷阱**。

**定义 126（力矩感知组合）**
组合边 `(S_i,S_j)` 可判定当且仅当第 54 轮条件成立且
```
μ_{S_i⊗S_j}(c) ≥ μ_min   ∧   c_τ(S_i,S_j) ≤ B_τ
c_τ(S_i,S_j) = max_t |dτ/dt| / B_τ  （切换邻域内取上确界）
```
并有**组合地板引理**：若力矩轨迹关于时间 `L_τ`-Lipschitz，则
```
μ_{S_i⊗S_j} ≥ min(μ_{S_i}, μ_{S_j}) - L_τ · c_τ
```
即切换越猛，组合地板相对单技能地板的下沉越深。

**定义 127（指令-力矩联合证书）**
```
J_IT = (𝒞_sem, ρ, μ_env, D_I, C_env, γ_ce, a_τ, evidence)
```
- `𝒞_sem` 指令等价类集合；`ρ` 第 53 轮鲁棒性谱；
- `μ_env` 上下文包络下的力矩地板；`D_I` 指令泛化域；
- `C_env` 上下文包络；`γ_ce` 云边映射；
- `a_τ` 反射护栏动作（限幅/柔顺/重规划）及其触发阈值；
- `evidence` 至少含力矩见证、力矩裕度轨迹、以及至少一条改写泛化反例。
若 `dom(T)=in`、`δ_a < Θ_a`、`μ_env ≥ μ_min` 且 `D_I ⊇ 𝒞_sem`，则称 `J_IT` **双接地成立**，可部署。

## 2. 关键算法 伪代码

### IP-121 IGX（Instruction Generalization eXpansion）

```python
def generalization_radius(skill, i, context, paraphrases, mu_min, eps_grid):
    best = 0.0
    for eps in eps_grid:
        ok = True
        for i2 in paraphrases:
            if d_sem(i, i2) > eps: continue
            tau = skill.ground(kappa(i2, context))
            if tau is None or torque_margin(tau, context) < mu_min:
                ok = False
                witness = TorqueWitness(i2, context, tau, reason='torque_floor')
                break
        if not ok: break
        best = eps
    return best, witness
```

### IP-122 TQM（Torque Margin Spectrum）

```python
def torque_margin_spectrum(skill, context, rollout):
    mu = []
    for t, tau in enumerate(rollout.torque):
        m = min(1.0 - abs(tau[j]) / tau_max[j] for j in joints)
        mu.append((t, m, argmax_abs(tau)))
    mu_star = min(m for _, m, _ in mu)
    crit = [t for t, m, _ in mu if m < mu_min]
    return MarginSpectrum(mu, mu_star, crit, context)
```

### IP-123 STG（Semantic-Torque Grounding）

```python
def semantic_torque_alias(i1, i2, contexts, eps, theta_tau):
    if d_sem(i1, i2) > eps: return None
    for c in contexts:
        tau1, tau2 = ground(i1, c), ground(i2, c)
        if tau1 is None or tau2 is None:
            return Alias(i1, i2, c, witness='ungroundable')
        div = max_abs_diff(tau1, tau2) / tau_max
        if div >= theta_tau:
            return Alias(i1, i2, c, div, witness=(tau1, tau2))
    return None
```

### IP-124 TSC（Torque-aware Skill Composition）

```python
def torque_aware_composition(G, skills, mu_min, B_tau, L_tau):
    for i, s1 in enumerate(skills):
        for j, s2 in enumerate(skills):
            if i == j or not G.has_edge(i, j): continue
            c_tau = torque_transition_cost(s1, s2) / B_tau
            mu_comp = min(s1.mu_env, s2.mu_env) - L_tau * c_tau
            if mu_comp < mu_min or c_tau > 1.0:
                G.remove_edge(i, j)
            else:
                G[i][j]['mu_comp'] = mu_comp
                G[i][j]['c_tau'] = c_tau
    return G
```

### IP-125 TRG（Torque Reflex Guard）

```python
def torque_reflex_guard(state, tau_cmd, mu_min, a_tau):
    mu = min(1.0 - abs(tau_cmd[j]) / tau_max[j] for j in joints)
    if mu >= mu_min:
        return tau_cmd, 'normal'
    if a_tau == 'clamp':
        return clamp(tau_cmd, tau_max * (1 - mu_min)), 'clamped'
    if a_tau == 'compliant':
        return compliance_control(state, tau_cmd), 'compliant'
    return replan_with_margin(state, mu_min), 'replanned'
```

### IP-126 IJC（Instruction-Torque Joint Certificate）

```python
def joint_instruction_torque_cert(skill_seq, sem_class, C_env, mu_min, rho_min):
    D_I, witnesses = {}, []
    for s in skill_seq:
        for i in sem_class:
            r, w = generalization_radius(s, i, C_env, paraphrases(i), mu_min)
            D_I[i] = r
            if w: witnesses.append(w)
    mu_env = min(torque_margin_envelope(s, C_env) for s in skill_seq)
    rho_comp = compose_robustness_chain([s.rho for s in skill_seq], K)
    if min(rho_comp.values()) < rho_min: return ('reject', 'robustness', rho_comp)
    if mu_env < mu_min: return ('reject', 'torque_floor', mu_env, witnesses)
    if any(D_I[i] <= 0 for i in sem_class):
        return ('reject', 'instruction_gap', D_I, witnesses)
    return ('ok', J_IT(sem_class, rho_comp, mu_env, D_I, C_env, witnesses))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| IGX | O(|N_ε|·|ε_grid|·T_rollout) | O(|N_ε|) | 改写采样覆盖、接地可判定 |
| TQM | O(T_rollout·|J|) | O(T_rollout) | 力矩模型误差上界 |
| STG | O(|C_env|·T_rollout·|J|) | O(T_rollout) | 语义距离与力矩距离可分离 |
| TSC | O(|S|²·T_rollout) | O(|S|²) | 力矩 Lipschitz、带宽约束 sound |
| TRG | O(|J|) | O(1) | 触发延迟 < 临界时间 |
| IJC | O(|S|·|𝒞_sem|·|N_ε|·T_rollout) | O(|𝒞_sem|) | 原像覆盖闭合、见证完备 |

**正确性定理（Instruction-Torque Double-Grounding Soundness）**
假设第 53/54 轮 (A22)–(A28) 成立；**(A29)** `κ` 关于改写距离 `L_κ`-Lipschitz；**(A30)** 力矩模型残差 `|τ_real - τ_model| ≤ ε_τ`，且证书按 `ε_τ` 留安全余量；**(A31)** 反射护栏触发延迟 `τ_g < τ_crit`。
则对携带 `J_IT` 的部署 `P`：
```
P_success(P) ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a > Θ_a)
                - P(κ 接地错误) - P(μ_env < μ_min) - P_guard_fail
```
其中 `P(μ_env < μ_min)` 由上下文包络与力矩残差界控制，`P(κ 接地错误)` 由 `L_κ` 与语义采样密度控制。

**推论（语义-力矩错配的必要条件）**
若 `i1 ~ i2` 且 `(i1,i2)` 不是语义别名陷阱，则 `|μ_{S}^*(i1,c) - μ_{S}^*(i2,c)| ≤ L_τ·div_τ(i1,i2;c)`。故任何声称「语义等价即泛化等价」的证书，都必须额外证明 `div_τ` 在 `C_env` 上有界；否则该证书在力矩层不 sound。

| 风险 | 等级 | 缓解 |

## 6. 本轮最大风险

**一句话**：把「指令泛化」重新定义为力矩可行域的原像、把「力矩控制」提升为证书的物理地板，能让语义泛化第一次具备可执行的物理含义；但其 soundness **同时押注在力矩模型残差上界、上下文包络完备性、以及语义接地 `κ` 的消歧正确性**上，三者任一被高估，都会让证书在真实负载/接触下出现「语义正确、力矩饱和」的静默失效，因此必须以 **残差留余量的力矩包络 + 对抗改写见证 + 反射护栏** 三重护栏，宁可把泛化域报小，绝不把语义等价误当作力矩可行。

| `D_I(S,c)` / `r_I(S,i,c)` | 指令泛化域 / 物理接地泛化半径 |
| `≡_op` | 操作等价（对所有技能与上下文可行性相同） |
| `div_τ(i1,i2;c)` | 语义-力矩错配度 |
| `c_τ(S_i,S_j)` | 力矩转换成本（切换处力矩变化率 / 带宽） |
| `μ_comp` | 组合力矩地板 |
| `J_IT` | 指令-力矩联合证书 |

## 2. 关键算法 伪代码

### IP-121 IGX

```python
def generalization_radius(skill, i, context, paraphrases, mu_min, eps_grid):
    best, witness = 0.0, None
    for eps in sorted(eps_grid):
        violated = None
        for i2 in paraphrases:
            if d_sem(i, i2) > eps:
                continue
            tau = skill.ground(kappa(i2, context))
            if tau is None or torque_margin(tau, context) < mu_min:
                violated = TorqueWitness(i2, context, tau, reason='torque_floor')
                break
        if violated is not None:
            witness = violated
            break
        best = eps
    return best, witness

def generalization_domain(skill, sem_class, C_env, mu_min):
    D_I = {}
    for i in sem_class:
        D_I[i] = min(
            generalization_radius(skill, i, c, paraphrases(i), mu_min, EPS)[0]
            for c in C_env
        )
    return D_I
```

### IP-122 TQM

```python
def torque_margin_spectrum(skill, context, rollout):
    spec = []
    for t, tau in enumerate(rollout.torque):
        ratios = [abs(tau[j]) / tau_max[j] for j in joints]
        j_star = argmax(ratios)
        spec.append(TorquePoint(t, 1.0 - max(ratios), j_star))
    mu_star = min(p.mu for p in spec)
    crit = [p.t for p in spec if p.mu < mu_min]
    return MarginSpectrum(spec, mu_star, crit, context)

def torque_margin_envelope(skill, C_env, residual_eps):
    # 以模型残差上界做保守下修，绝不低估真实力矩
    return min(torque_margin_spectrum(skill, c, skill.rollout(c)).mu_star
               for c in C_env) - residual_eps
```

### IP-123 STG

```python
def semantic_torque_alias(i1, i2, contexts, eps, theta_tau):
    if d_sem(i1, i2) > eps:
        return None
    for c in contexts:
        tau1, tau2 = ground(i1, c), ground(i2, c)
        if tau1 is None or tau2 is None:
            return Alias(i1, i2, c, witness=TorqueWitness(reason='ungroundable'))
        div = max_abs_diff(tau1, tau2) / tau_max
        if div >= theta_tau:
            return Alias(i1, i2, c, div_tau=div, witness=(tau1, tau2))
    return None

def mine_alias_traps(sem_classes, contexts, eps, theta_tau):
    traps = []
    for cls in sem_classes:
        for i1, i2 in combinations(cls, 2):
            a = semantic_torque_alias(i1, i2, contexts, eps, theta_tau)
            if a is not None:
                traps.append(a)
    return traps
```

### IP-124 TSC

```python
def torque_aware_composition(G, skills, mu_min, B_tau, L_tau):
    for i, s1 in enumerate(skills):
        for j, s2 in enumerate(skills):
            if i == j or not G.has_edge(i, j):
                continue
            c_tau = torque_transition_cost(s1, s2) / B_tau
            mu_comp = min(s1.mu_env, s2.mu_env) - L_tau * c_tau
            if c_tau > 1.0 or mu_comp < mu_min:
                G.remove_edge(i, j)
            else:
                G[i][j]['c_tau'] = c_tau
                G[i][j]['mu_comp'] = mu_comp
                G[i][j]['mu_cert'] = (s1.mu_env, s2.mu_env, c_tau, mu_comp)
    return G
```

### IP-125 TRG

```python
def torque_reflex_guard(state, tau_cmd, mu_min, a_tau):
    mu = min(1.0 - abs(tau_cmd[j]) / tau_max[j] for j in joints)
    if mu >= mu_min:
        return tau_cmd, 'normal', None
    if a_tau == 'clamp':
        out, mode = clamp(tau_cmd, tau_max * (1 - mu_min)), 'clamped'
    elif a_tau == 'compliant':
        out, mode = compliance_control(state, tau_cmd), 'compliant'
    else:
        out, mode = replan_with_margin(state, mu_min), 'replanned'
    return out, mode, GuardEvent(guard='TRG', mu=mu, mode=mode, state=state.snapshot())
```

### IP-126 IJC

```python
def joint_instruction_torque_cert(skill_seq, sem_class, C_env, mu_min, rho_min,
                                  delta_a_budget, gamma_ce):
    D_I, witnesses, aliases = {}, [], []
    for s in skill_seq:
        for i in sem_class:
            r, w = generalization_radius(s, i, C_env, paraphrases(i), mu_min, EPS)
            D_I[i] = min(D_I.get(i, r), r)
            if w:
                witnesses.append(w)
    aliases = mine_alias_traps([sem_class], C_env, eps=EPS_SEM, theta_tau=THETA_TAU)
    mu_env = min(torque_margin_envelope(s, C_env, RESIDUAL_EPS) for s in skill_seq)
    rho_comp = compose_robustness_chain([s.rho for s in skill_seq], K)
    delta_a = max_alignment_error(gamma_ce, reduce(intersection, [s.alpha for s in skill_seq]))
    if min(rho_comp.values()) < rho_min:
        return ('reject', 'robustness', rho_comp)
    if mu_env < mu_min:
        return ('reject', 'torque_floor', mu_env, witnesses)
    if delta_a > delta_a_budget:
        return ('reject', 'action_mismatch', delta_a)
    if any(D_I[i] <= 0 for i in sem_class):
        return ('reject', 'instruction_gap', D_I, witnesses)
    return ('ok', J_IT(sem_class, rho_comp, mu_env, D_I, C_env, gamma_ce,
                       a_tau=TRG_POLICY, evidence=(witnesses, aliases)))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| IGX | O(|N_ε|·|ε_grid|·T_rollout·|C_env|) | O(|N_ε|) | 改写覆盖 ≥ 95%，接地可判定 |
| TQM | O(T_rollout·|J|·|C_env|) | O(T_rollout) | 力矩残差保守下修，不低估 |
| STG | O(|𝒞_sem|²·|C_env|·T_rollout) | O(T_rollout) | 别名对可复现、见证可重放 |
| TSC | O(|S|²·T_rollout) | O(|S|²+|E|) | 力矩 Lipschitz、带宽约束 sound |
| TRG | O(|J|) | O(1) | 触发延迟 `τ_g < τ_crit` |
| IJC | O(|S|·|𝒞_sem|·|N_ε|·T_rollout·|C_env|) | O(|𝒞_sem|) | 原像覆盖闭合、见证完备 |

**正确性定理（Instruction-Torque Double-Grounding Soundness）**
假设第 53/54 轮 (A22)–(A28) 成立；**(A29)** `κ` 关于改写距离 `L_κ`-Lipschitz；**(A30)** 力矩模型残差 `|τ_real - τ_model| ≤ ε_τ`，且 `μ_env` 已按 `ε_τ` 保守下修；**(A31)** 反射护栏触发延迟 `τ_g < τ_crit`。
则携带 `J_IT` 的部署成功概率：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a > Θ_a)
            - P(κ 接地错误) - P(μ_env < μ_min) - P_guard_fail
```
其中
```
P(μ_env < μ_min) ≤ P(∃c∈C_env: μ_real^*(c) < μ_min)
P(κ 接地错误)  ≤ L_κ · ε · sampling_gap
```

**组合地板引理（Torque Composition Floor）**
若切换邻域内力矩轨迹关于时间 `L_τ`-Lipschitz，则
```
μ_{S_i⊗S_j} ≥ min(μ_{S_i}, μ_{S_j}) - L_τ · c_τ(S_i,S_j)
```
因此 TSC 的边约束 `μ_comp ≥ μ_min ∧ c_τ ≤ B_τ` 是组合安全的充分条件（在 A30 的残差余量下）。

**推论（泛化证书的物理下界）**
若 `i1 ~ i2` 且 `div_τ(i1,i2;c) ≤ θ_τ` 在 `C_env` 上成立，则
```
|μ_S^*(i1,c) - μ_S^*(i2,c)| ≤ L_τ · θ_τ
```
故任何「语义等价 ⇒ 泛化等价」的声明都必须附带 `div_τ` 上界；否则 IJC 拒绝签发。

## 6. 本轮最大风险

**一句话**：把「指令泛化」重新定义为力矩可行域的原像、把「力矩控制」提升为证书的物理地板，能让语义泛化第一次具备可执行的物理含义；但其 soundness **同时押注在力矩模型残差上界、上下文包络完备性、以及语义接地 `κ` 的消歧正确性**上，三者任一被高估，都会让证书在真实负载/接触下出现「语义正确、力矩饱和」的静默失效，因此必须以 **残差留余量的力矩包络 + 对抗改写见证 + 反射护栏** 三重护栏，宁可把泛化域报小，绝不把语义等价误当作力矩可行。
