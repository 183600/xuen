### 第 1 轮灵感驱动研究记录（承接 CADVS-v5 状态）

**灵感词**：云边协同、原型验证

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把提议换成条件流匹配、记忆升级为嵌入+固化、人因加入情感调制，并用定理 6（证书不变性）把框架推广为「任意生成器 + 认证边界」。但 v5 隐含假设了一个**单一信任域 + 单机时域**：流提议、记忆固化、联邦聚合与七硬门执行被默认放在同一台机器、同一信任域内完成。真实部署却天然分层——重生成、固化、联邦与审计在云端（算力/数据密集），1 kHz 控制与 fail-closed 硬门在边缘（实时/隐私/断网可用）。两个灵感词统一为主题「**云边分层认证执行**」（Layered Certified Cloud-Edge Execution, LCCE），形成 CADVS-v6（IP-497~500）。本轮自律：**执行硬门数量仍不增**（维持七门，继续偿还 R52 锚点维护负债），把云边与原型验证做成「证书生命周期」的分层与晋级，而非新增运行时执行门；边缘侧执行集保持 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **云边协同 → 证书生命周期拆成「云端铸造 / 边缘验证」，信任方向严格单向：云可以提议，永不能授权。** 直觉上，安全边界必须钉在离物理世界最近、断网也能独立工作的一端。形式化：边缘本地钉扎只读清单 (gate_hash\*, tau_hash\*, schema_v\*, root_pubkey)；云端下发的 θ_FM、记忆 token、联邦原型、标定参数都是**带签名的候选工件**，边缘先校验来源/版本/完整性，再让它们只作为「提议源」进入同一套本地冻结硬门。由此得到**定理 9（边缘安全不变性/云不可信）**：无论云端正常、陈旧还是被攻陷，边缘接受集 ⊆ 本地门通过集 ⊆ Exec_v5；云只能降低可用性、或让「该收紧的没收紧」，**永远不能扩大执行集**。这把定理 6「提议无关」从「单机换提议器」推广为「跨信任域换提议源」。情感调制 γ≥1 的结构性非负在此额外兜底：即使云端下发的 FER 权重被投毒，最坏也只能退化为 γ≡1（精确退回 v4 静态阈值），无法把阈值放松到 v4 以下。

2. **云边协同的第二层是分区语义：CAP 式取舍——放弃「提议新鲜度的一致性」，保「安全 + 分区可用」。** 定理 10（分区 fail-safe）：断网时边缘切回本地规则提议或上一版已晋级 θ；七门与 τ⁴ 全在本地，故 Exec 在任意分区序列前后恒 ⊆ Exec_v5；重连后云端候选必须重新过门，绝不追溯放行。代价只是新颖性/泛化退化，而非安全退化。

3. **原型验证 → 把「云端自评晋级」换成「分阶段物理原型验证 + 统计晋级门」，并给 R57 补上缺失的外部真值。** R57 的根因是固化语料只有自铸证、没有外部真值。原型验证恰好提供外部真值：数字孪生 → 硬件在环 (HIL) → 影子/金丝雀小批边缘 → 全舰队逐级放量；只有通过序贯统计检验（成功率/安全违例率/证书博弈率 CGR/红队回归的非劣或改进）的候选才被签名晋级。更进一步，把「原型验证过的结局」作为固化语料的**准入标签**，并用**主动原型采样**优先验证「高不确定 ∧ 高覆盖缺口 ∧ 高博弈嫌疑」的片段，以有限物理预算买外部真值，直接补上 R57 缺失的那条外部参照。得到定理 11（原型晋级可靠性，仅对原型分布成立）与定理 12（真值锚定固化的自指缩减界）。

**关键洞见**：v5 问「换任意生成器，证书边界是否不变」；v6 问「当生成器在云端、执行在边缘、断网与投毒都可能发生时，证书边界钉在哪里、由谁晋级」。答案：**边界钉在边缘、晋级钉在原型**。云边解决「谁有资格提议」，原型验证解决「凭什么相信提议真的更好」；两者共同把 R57 的自指回路从「策略博弈门」改写为「策略必须先在物理原型上兑现结局」。且 PVPK 是**发布门**（离线、低频），不参与 Exec 定义、不进 1 kHz 环，故不新增运行时执行锚。

**形式化目标（增量）**：

1. 云边工件：Art = (payload, kind, schema_v, gate_hash, tau_hash, dp_eps, nonce, signer, sig)；边缘验证器 Ver(Art, manifest) 以本地只读清单校验，失配即拒（引理 45）。
2. 边缘执行集：Exec_edge(c) = {x ∈ supp(π_src) : ∧_i kc_i(x,c; τ_i⁵)=1}，π_src ∈ {π_FM^cloud, π_local^fallback, π_promoted}；与 π_src 无关地 ⊆ Exec_v5（定理 9）。
3. 分区算子 Part：安全不变量 Safe(t) := (Exec_edge(t) ⊆ Exec_v5) 在任意分区/重连序列下恒真（定理 10）。
4. 原型晋级：Promo(θ_new, E_proto) 用 anytime-valid 置信序列检验 Δ=(成功率, 安全违例率, CGR, 红队回归) 非劣；α 预算分摊 + 预注册 + 轮换留出（定理 11）。
5. 真值锚定固化：C_cons ⊆ {ep : proto_verified(ep) ∨ human_audit(ep)}；主动采样 acq(ep) = 不确定度 × 覆盖缺口 × 博弈嫌疑 / 物理成本（定理 12）。
6. Exec_CADVS-v6 = Exec_edge ∩ supp(π_promoted) ⊆ Exec_CADVS-v5。

**本轮最大风险**：**原型-现实分布差距叠加原型 Goodhart**——晋级定理只在原型/孪生分布上成立，而原型覆盖永远小于部署分布；一旦把「原型验证过的结局」当作固化真值，策略的优化目标就从「骗过门」迁移为「骗过原型」，在未覆盖的角落，安全仍只是一个外推假设。

## 2. 关键算法骨架

### IP-497 CECP：云边证书分层协议（边缘常驻，验证在控制环外）

```python
@dataclass
class CloudEdgeCertificateProtocol:
    """CECP：云端铸造、边缘验证；信任单向。
    定理 9：云不可信也不能扩大执行集；定理 10：分区安全不变。"""
    manifest: Manifest            # 只读钉扎：gate_hash*, tau_hash*, schema_v*, root_pubkey
    fallback: Any                 # v5 规则提议 / 上一版已晋级 θ
    _cache: dict = field(default_factory=dict)

    def verify(self, art: Artifact) -> bool:
        # 引理 45：版本/哈希/签名/吊销/防重放全部通过才接受
        if art.schema_v != self.manifest.schema_v:      return False
        if art.gate_hash != self.manifest.gate_hash:    return False
        if art.tau_hash != self.manifest.tau_hash:      return False
        if art.nonce in self._seen_nonces:              return False
        if revoked(art.signer, self.manifest.revocation): return False
        return ed25519_verify(self.manifest.root_pubkey, art.payload, art.sig)

    def current_source(self, link: str) -> PolicySource:
        if link == 'down':
            return self.fallback                     # 断网：本地回退，安全不依赖云
        art = self.pull_latest()
        if art is None or not self.verify(art):
            return self.fallback                     # 验签失败：fail-closed 回退
        return self._admit_kind(art)                 # 只接受白名单 kind

    def _admit_kind(self, art: Artifact) -> PolicySource:
        # 红线：gate / threshold 覆盖类工件一律拒绝；阈值只由本地 γ·τ⁴ 生成
        if art.kind not in {'proposal', 'memory_token',
                            'global_prototype', 'calibration'}:
            return self.fallback
        return PolicySource(policy=art.payload, provenance=art.signer)
```

### IP-498 PVPK：原型验证与晋级核（云端编排，离线/低频）

```python
@dataclass
class PrototypeValidationPromotionKernel:
    """PVPK：五级阶梯 + anytime-valid 序贯检验 + 自动回滚。
    定理 11：晋级可靠性仅在原型分布上成立；α 预算控制 optional-stopping 膨胀。"""
    ladder: tuple = ('digital_twin', 'hil', 'shadow', 'canary', 'fleet')
    alpha_budget: float = 0.05

    def promote(self, theta_new, theta_old, proto: ProtoStream) -> Decision:
        spent = 0.0
        for stage in self.ladder:
            alpha_s = self.alpha_budget / len(self.ladder)   # α 预算分摊
            ev = proto.run(stage, theta_new, theta_old)      # 物理/孪生 rollout
            if not self._noninferior(ev, alpha=alpha_s):
                return Decision(False, stage, ev, 'NONINFERIORITY_FAIL')
            if stage in ('canary', 'fleet') and ev.safety_violation > 0:
                return Decision(False, stage, ev, 'ROLLBACK_SAFETY')  # 金丝雀见血即回滚
            spent += alpha_s
        return Decision(True, 'fleet', ev,
                        'PROMOTED', cert=sign_artifact(theta_new, ev))

    def _noninferior(self, ev, alpha) -> bool:
        # anytime-valid 置信序列：对任意停时有效，避免“多看一眼”抬升假阳性
        cs = anytime_valid_cs(ev.deltas, alpha=alpha)
        return cs.lower_bound_SR >= -self.margin_sr and \
               cs.upper_bound_SVR <= self.margin_svr and \
               cs.upper_bound_CGR <= self.margin_cgr and \
               cs.upper_bound_RT <= self.margin_rt
```

### IP-499 GTAC：物理真值锚定固化（云侧训练；边缘只上传 DP 摘要）

```python
@dataclass
class GroundTruthAnchoredConsolidation:
    """GTAC：固化语料必须带外部真值标签，破 R57 自指回路。
    定理 12：残余博弈率上界 = 覆盖缺口·CGR_max + ε，无法根除。"""
    dp_eps: float = 8.0
    kl_eps: float = 0.05

    def admit(self, ep) -> bool:
        # 不再接受“仅自铸证”的片段；必须有原型验证或人工审计的外部结局
        return bool(ep.proto_verified or ep.human_audit)

    def acquisition_score(self, ep) -> float:
        # 主动挑最值得花物理预算验证的片段
        return (ep.uncertainty * ep.coverage_gap * ep.gaming_suspicion) \
               / max(ep.phys_cost, 1e-6)

    def select_for_prototype(self, episodes, budget: int) -> list:
        ranked = sorted(episodes, key=self.acquisition_score, reverse=True)
        chosen, cost = [], 0
        for ep in ranked:                       # 贪心：覆盖增益/成本（引理 46）
            if cost + ep.phys_cost > budget: continue
            chosen.append(ep); cost += ep.phys_cost
        return chosen

    def consolidate(self, episodes, fmpp, pvpk) -> None:
        # 1) 先主动选片送原型验证，拿到外部真值；2) 只固化真值锚定片段
        to_validate = self.select_for_prototype(episodes, budget=PV_BUDGET)
        pvpk.validate_batch(to_validate)        # 回填 ep.proto_verified
        corpus = [ep for ep in episodes if self.admit(ep)]
        # 3) DP-SGD + KL 正则 + 失败回放；门与 τ⁴ 只读，梯度不经过门
        dp_sgd_kl(fmpp, corpus, eps=self.dp_eps, kl_eps=self.kl_eps)
```

```python
    其中 ε_promo 为晋级门允许的 CGR 上界。证明：已验证支撑上由晋级门约束，
    未验证支撑上无外部真值，只能用最坏 CGR_max 兜底。∎
    诚实边界：δ_cov 未知且随分布漂移；此界只能说明“博弈被赶到未覆盖角落”，
    不能说明“博弈被消除”。
    """
    return "Proven (bound); coverage deficit empirical only"
```

### IP-500 EFA-v6：七硬门不变 + 云边验证 + 本地回退

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：执行门与阈值逐字节冻结在边缘；云端只是提议源。"""
    cecp: CloudEdgeCertificateProtocol
    pvpk: PrototypeValidationPromotionKernel
    v5: EvidenceForgingAssemblerV5          # 复用七门全套

    def select(self, x0_state, t_now, rule_id, context, link) -> Result:
        src = self.cecp.current_source(link)         # 验签/分区回退（定理 9/10）
        if src.provenance is not None and not self.cecp.verify(src.artifact):
            src = self.cecp.fallback
        c = build_ctx(context, self.v5.famk.observe(context.face, t_now),
                      self.v5.lmem)               # FAMK 端侧；记忆本地
        cands = src.policy.propose(c, K=8)           # 云端或本地提议
        # —— 以下全部是本地冻结门，云端无从干预 ——
        surv = [x for x in cands if self.v5._cheap_gates(x, gamma=local_gamma)]
        if not surv:
            return self._fallback_rule_proposal(local_gamma)   # fail-closed
        finals = self.v5._vack_and_bck(surv[:3], context)
        if not finals:
            return Result(False, None, 'ALL_CANDIDATES_REJECTED')
        return Result(True, max(finals, key=certified_margin), 'FORGED_LCCE')

    def ecs_v6(self, base_ecs_v5, delta_cov: float) -> float:
        eta_proto = sigmoid(K_P * (1.0 - delta_cov) - B_P)   # 覆盖越低分越低
        return base_ecs_v5 * eta_proto
```

## 4. 正确性论证（增量更新）

### 引理 45（验证器可靠性 / 版本错配拒绝）

**陈述**：若 manifest_edge 由可信根钉扎、Ed25519 不可伪造，且 Ver 检查 schema_v/gate_hash/tau_hash/signature/revocation/nonce，则任何被接受的工件都满足 gate_hash=gate_hash\*、tau_hash=tau_hash\*、schema_v=schema_v\*，且不可重放。特别地，云端无法注入新门或覆盖阈值。

**证明**：签名绑定 payload 与元数据；任何字段被篡改则验签失败；哈希字段相等由显式比较保证；nonce 去重防重放。∎

**推论**：即使云端被完全攻陷，能注入的只有 `kind ∈ 白名单` 的提议负载；执行谓词不受影响。

### 引理 46（主动原型采样的覆盖增益）

**陈述**：设片段覆盖价值函数 v(·) 非负、次模，物理成本 c(·)>0；按 acq = v/c 贪心选片，在预算 B 下达到最优覆盖的 (1−1/e) 近似。

**证明**：带成本的次模最大化贪心近似比标准结果。∎

**诚实边界**：覆盖价值函数 v=u·g·r 是启发式估计，次模性只是建模假设；若估计有偏，近似比失效。

### 引理 47（云边 DP 组合）

**陈述**：人脸/轨迹原始数据留在边缘；上传的聚合统计满足 ε_i-DP。跨 T 次上传的端到端隐私预算 ε_total ≤ Σ ε_i（基础组合）或 O(√(T log(1/δ))·ε + Tε²)（高级组合）。

**证明**：DP 的串行组合定理。∎

### 定理 v6（分层收缩、云不可信与晋级可靠性，总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) manifest 可信根完整、(B9) 原型证据无污染且检验预注册下：
(i) **执行集嵌套**：Exec_CADVS-v6 = Exec_edge ∩ supp(π_promoted) ⊆ Exec_v5 ⊆ Exec_v4 ⊆ … ⊆ Exec_v29；
(ii) **云不可信安全**：对任意云端行为（含投毒、陈旧、断网），Safe(t) 恒真（定理 9）；
(iii) **分区 fail-safe**：任意分区序列下安全不变，仅可用性/新颖性退化（定理 10）；
(iv) **晋级可靠性**：Promo=1 ⇒ 在 P_proto 上以置信 1−α 非劣/改进，误晋级概率 ≤ α（定理 11）；
(v) **自指缩减**：真值锚定固化把部署博弈率压到 δ_cov·CGR_max + ε_promo（定理 12）；
(vi) **七锚完备性**：执行锚集合不变（CECP/PVPK/GTAC 是部署/治理层，不是运行时执行锚）。

**证明**：(i) 同门 + 本地阈值只紧 + 晋级支撑受限；(ii)(iii) 由定理 9/10 逐时刻应用；(iv)(v) 由定理 11/12；(vi) 锚集合未增删，γ≥1 保持单调。∎

**诚实声明**：(B8) 可信根依赖供应链与 OTA 安全；(B9) 原型污染与选择偏差无法从统计内部发现；(iv) 只对 P_proto 成立，**原型-现实差距无结构兜底**；(v) 的 δ_cov 不可观测且会漂移；GTAC 的主动采样可能偏向“易验证”而非“最危险”的片段。

## 7. 本轮最大风险（最终确认）

**一句话**：**原型-现实分布差距叠加原型 Goodhart**——晋级定理只在原型/孪生分布上成立，而原型覆盖永远小于部署分布；一旦把「原型验证过的结局」当作固化真值，策略的优化目标就从「骗过门」迁移为「骗过原型」，在未覆盖的角落，安全仍只是一个外推假设。
