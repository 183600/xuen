# 第 66 轮（承接第 65 轮「VISTA 视觉知情的安全时序归因闭环」IP-214~223；灵感循环第 1 轮；本轮灵感：「具身智能大模型」×「实例分割」）

> 第 65 轮 VISTA 把 GRIP 的「可证伪」升级为「可归因」，其自述最大风险同样一针见血：**故障被假设属于一个有限假设集，且视觉与几何失效相互独立；真实故障常是未知类型的组合，透明/镜面/对抗 patch 又让视觉与几何共享同一个分布外失效源，于是 FIR 会把未知复合故障强行塞进最近假设、只膨胀错误的球，而系统因为「已经归因」反而更自信。** 本轮不问「谁坏了」的更多细节，而问两个更靠前的问题：**假设空间由谁定义？信任的最小单元是什么？** 本轮核心命题是：
>
> **把「故障归因」升级为「开放世界的实例化归因」：让具身大模型开放地提议任务、指代、语义-物理契约与故障假设模板，让实例分割把每一条语义命题绑定到持久物体实例，把未知复合故障显式表示为「未知质量 + 共因潜变量」而不是最近邻假设，并用实例隔离替代全局停机。**

## 0. 直觉与动机

**灵感 1（具身智能大模型 → 从「策略」降级为「假设与契约的提议者」）**
直觉：VLA / 具身大模型拥有开放词汇、任务分解、affordance 与常识，它能看着场景说「这像薄壁杯，握太紧会捏变形」「那个把手可能是空心的」。但它的致命弱点同样清楚：没有物理接地、会幻觉、置信度不校准、可被视觉 patch 或提示注入攻击。因此正确的用法不是「让大模型输出动作并相信它」，而是「让大模型提议一个可被物理检验的命题域」——任务分解、自然语言指代、affordance、语义-物理契约子句、乃至新的故障假设模板与期望残差签名。它是**提案分布**，不是似然、不是真值、不是控制器。关键升级：大模型第一次让假设空间从第 65 轮封闭的 6 类变成开放集，但每条提案都必须被实例化、可证伪、可拒绝。

**灵感 2（实例分割 → 把信任单元从「场景」降到「实例」）**
直觉：第 65 轮把整场场景压成一个全局签名 ρ，归因问的是「全局谁坏了」；但真实世界是多物体的，坏的往往只是某一个实例——那把刀、那个薄壁杯、那只被捏的软果。实例分割加掩码跟踪提供持久实例 id，使四件事同时成立：(i) 每个语义指代有唯一 referent，指代歧义与幻觉可被显式检测；(ii) 每条故障证据有明确归属，归因不再被无关物体稀释；(iii) 每张证书可以绑到具体物体，而不是绑到场景；(iv) 计划未提及但真实存在的实例（未知物体入侵）能被发现。**实例 id 就是新的信任单元**，隔离一个实例不必冻结整个场景。

**灵感 3（未知复合故障 → 不要塞进最近假设，要给它「质量」）**
直觉：VISTA 的 6 类 softmax 隐含「以上总有一个对的」。但未知复合故障恰恰是「以上都不是」。正确做法是显式留出**未知质量**：用 conformal p 值检验「已知族是否解释得了这个签名」，解释不了的部分不归给最近邻，而是保留为 unknown；用结构因果模型里的共享潜变量（OOD 物体、传感器、环境、时间对齐）解释共因，而不是假设视觉与几何独立。**未知不是第 7 个假设，而是拒绝归因并升级处理的触发器。**

**灵感 4（语义-物理契约 → 把大模型的话变成可证伪的子句）**
直觉：大模型说「可抓、刚性、质量 < 0.5 kg、可盛液体、不易碎」。每句话都应变成一个绑定到实例 id 的契约子句：有测量、有检验、有支持 / 反驳 / 不可观测三态。全部支持 = verified；任一反驳 = violated；只有不可观测 = conditional（必须限制力/速度或先做视觉探针）。这把「大模型可信吗」这个无法回答的问题，转成「这条契约在哪个实例上被哪条物理证据反驳」这个可审计的问题。

**灵感 5（实例交互图与局部隔离 → 从全局停机到部分安全运行）**
直觉：多物体任务天然是一张实例依赖图（接触、支撑、遮挡、共享执行器/工作空间）。当实例 i 被隔离，只需停止它的下游闭包；其余独立任务可以继续。这比 VISTA 的全局 safe_idle 更不保守，但必须证明：剩余动作不接触隔离实例、不依赖其支撑、不与隔离动作争用同一执行器。安全仍由证书保证，只是把「全局安全」分解为「实例局部安全 + 图割」。

**灵感 6（三条技术线合流 → MOSAIC）**
MOSAIC = **M**ask-grounded **O**pen-set **S**emantic-physical **A**ttribution with **I**nstance **C**ertificates（掩码接地的开放集语义-物理归因与实例证书）。闭环：VLA-S 提议 → ISG 接地/指代消解 → SPC 契约检验 → ICQ 身份一致性 → OSA 未知质量 + SCM-C 共因检验 → IPG 构建与隔离 → I-Shield 实例条件屏蔽 → CSC 认证前缀 → 执行 → 冲突回写与 SPX 暂存。第 65 轮回答「哪一层坏了」；MOSAIC 回答「**这个结论绑定在哪个物体上、它是否只是已知假设的最近邻、未知时是否敢承认不知道**」。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（MOSAIC 闭环）**：MOSAIC = (VISTA, VLA-S, ISG, SPC, OSA, SCM-C, ICQ, IPG, I-Shield, SPX, J_mosaic)。定位：VISTA 的「开放世界 + 实例化」升级。不变式：**大模型提议、实例分割接地、契约检验、开放集归因、因果检验与先验扩展只在语义流；实时流只读冻结实例缓存、已认证故障库与 unknown 触发器，只做实例条件屏蔽、认证前缀与早停，零学习写操作；VLA-S 永不进入实时控制回路。**
- **定义 234（具身大模型语义提议 VLA-S）**：固定的大模型 π_VLA 由观测 o_t 与目标 g 输出结构化提案 P_t={(τ,r,A,C,F,Σ_exp)}：任务 τ、自然语言指代 r、affordance A、契约子句 C、故障假设模板 F 及其期望签名 Σ_exp，各带提议分数与语义熵 H_sem。**P_t 是提案分布：不是似然、不是真值、不可直接执行。**
- **定义 235（实例分割接地与指代消解 ISG）**：持久实例集 I_t={(i,M_i(t),G_i(t),v_i(t))}，i 为实例 id、M_i 为掩码、G_i 为几何/位姿/可见性、v_i 为身份置信度。指代消解 R(r,I_t)∈{唯一 i, ambiguous, absent}。身份连续性由掩码 IoU、外观嵌入、运动与几何一致性联合判定。**实例 id 是 MOSAIC 的信任单元。**
- **定义 236（语义-物理契约 SPC）**：对实例 i，C_i={c_k}，c_k=(pred, meas, test, status)，status∈{support, refute, unobservable}。子句至少覆盖刚性/可形变、质量/惯性、支撑/可及、易损、可抓/对跖几何、封闭/可盛、摩擦/滑移。契约状态取三值格：verified（全 support）、violated（存在 refute）、conditional（无 refute 但有 unobservable，仅限力/速度受限或 visual_probe 下执行）。
- **定义 237（实例化证据流与跨实例一致性）**：ρ_t=⊕_{i∈I_t}ρ_i(t)，ρ_i∈ℝ^{15} 沿用第 65 轮三阶段×5 维。跨实例一致性 χ_t={d(ρ_i,ρ_j)} 只在「同一物理本体的分裂掩码、同一支撑链、跨视角重识别」上计算；不一致产生 `instance_split_conflict`，同时服务 OSA 与 ID 交换检测。
- **定义 238（开放集归因 OSA）**：已知族 ℋ_K={H0,H_geo,H_force,H_model,H_vis,H_policy}。对每个已知假设计算 conformal 拟合 p 值 p_H(ρ)=(1+#{j:s_H(ρ_j)≥s_H(ρ)})/(n_H+1)。当 max_H p_H(ρ)<α_open 时拒绝「已知族」，定义未知质量 u(ρ)=1−max_H p_H(ρ)，令 P(H_unknown|ρ)=u，已知后验按 (1−u) 归一化。实时流用 e-process 维护「已知族」零假设的对数 e 值，越过 log(1/α_open) 即触发 unknown。**H_unknown 不参与定向处置，只触发回溯、隔离与保守联合膨胀。**
- **定义 239（共因结构因果模型 SCM-C）**：潜变量 Z=(Z_obj,Z_sensor,Z_env,Z_align,Z_task)，观测残差 ρ=f(Z)+ε。共因 = 同一潜变量同时是多个残差分量的父节点（如透明物体同时骗过视觉掩码与几何位姿）。用条件独立检验区分「直接因果 / 共因 / 独立」；无干预时前两者属同一 Markov 等价类、不可仅凭观测区分，故 (a) 能检验则检验；(b) 不可检验则保守按共因处理，联合半径取等价类最大 r_joint；(c) 用 AFA 探针做 do-干预（如 null_test 只改力偏置、不改几何）打破对称。**共因下不要求归因正确，只要求判为 unknown/common_cause 并安全降级。**
- **定义 240（实例一致性与重识别 ICQ）**：身份置信度 v_i 联合掩码 IoU、外观、运动、几何与跨视角一致性；ID 交换风险上界 ε_id=1−v_i。时长 T 的契约须满足 (1−ε_id)^T≥1−δ_id，否则在 T_id=⌊log(1−δ_id)/log(1−ε_id)⌋ 内重验证身份。证书绑定 (i, v_i, T_id)；`instance_split_conflict` 或掩码跳变立即冻结实例并重跑 SPC。
- **定义 241（未知物体入侵与开放集实例）**：计划未引用、但掩码稳定帧数≥n_stable、且与规划轨迹最小距离<d_intrude 的实例 j 称为 unknown-object intrusion，一律进入隔离集。**显式反驳「大模型没提到就不存在」。**
- **定义 242（实例交互图 IPG）**：G_I=(V_I,E_I)，节点为实例、机器人、支撑面、环境锚点；边含 planned_contact、support、occlusion、shared_actuator（共用执行器/工作空间冲突）。动作 a 标注 touch(a) 与依赖闭包 Dep(a)；隔离集 Q 的受影响闭包 Aff(Q)={a:Dep(a)∩Q≠∅ ∨ touch(a)∩Q≠∅}。
- **定义 243（隔离算子与局部运行安全判据）**：quarantine(i) 把 i 加入 Q 并移除所有 C_i∈{violated, conditional 未加限制} 的接触；局部运行允许执行 a 当且仅当 a∉Aff(Q) ∧ 无 shared_actuator 冲突 ∧ 所有被触碰实例契约有效。全局 safe_idle 仅在 Q 覆盖全部可达实例或存在未建模共享资源时触发。
- **定义 244（实例条件屏蔽 I-Shield）**：在 VISTA Shield 上按实例增加允许接触区域、f_max,i、v_max,i 与禁穿区域；C_i=conditional 时按 unobservable 子句收紧，C_i=violated 或 i∈Q 时禁止接触。屏蔽是 mask-conditional 而非 scene-global，因此隔离一个实例不冻结整个场景。
- **定义 245（语义先验扩展 SPX）**：VLA-S 提出的新故障模板 F_new 先入 staging 库，不进入实时流；只有完成离线故障注入、似然拟合、AIC-O 认证并被版本化签名后才晋升到 certified 库。实时流永远保留 unknown 触发器与旧版快照；晋升低频、可回滚。**开放词汇只能扩大候选假设，不能直接改变实时安全行为。**
- **定义 246（语义-物理冲突与提案拒绝）**：当提案与接地/契约冲突（指代 absent、契约 refute、语义类别与物理属性矛盾、计划触碰未引用实例）时产生冲突事件 κ；拒绝该提案子句，记录 `vla_reject` 或更新 SPC/OSA，冲突必须进入 J_mosaic 审计链、不得静默吞掉。
- **定义 247（J_mosaic 证书）**：J_mosaic=(J_vista, instance_contract_hash, referent_ids, unknown_mass, common_cause_posterior, quarantined_set, id_confidence, vla_sem_ver, spx_ver, conflict_log_hash)。Valid ⇔ Valid(J_vista) ∧ 每个被触碰实例有 resolved referent ∧ C_i∈{verified, conditional-with-restriction} ∧ i∉Q ∧ 身份在 T_id 内有效 ∧ (u≤1−α_open ∨ 已隔离/回溯) ∧ 共因高风险时未做定向膨胀 ∧ 无未处置冲突 ∧ 版本有效。
- **定义 248（MOSAIC 闭环算子）**：语义流 [VISTA 语义流→VLA-S 提议→ISG 接地/指代消解→SPC 契约检验→ICQ 一致性→OSA 未知质量/SCM-C 共因→IPG 构建与隔离→SPX staging→CSP-I 块规划→I-Shield 编译→CSC 认证前缀→AIC-O 认证]；实时流 [VISTA 实时流→实例缓存查询→mask-conditional margin→unknown e-process→认证前缀执行/早停/隔离派发]。VLA-S、ISG、SPC、OSA、SCM-C、SPX 均不在实时回路。

## 2. 关键算法骨架

```python
# ISG + SPC：指代 → 实例 → 契约三态（语义流）
ref = isg.resolve(referent_text, instances)          # id / ambiguous / absent
if ref.ambiguous or ref.absent:
    reject_proposal(ref, reason='referent_ungrounded')   # 幻觉或歧义，不猜
contract = spc.evaluate(ref.id, vla_affordances)     # 每子句 support/refute/unobservable
if 'refute' in contract.status:
    contract_state = 'violated'                      # 物理反驳大模型
elif 'unobservable' in contract.status:
    contract_state = 'conditional'                   # 只允许受限执行
else:
    contract_state = 'verified'

# OSA：已知族拟合检验 → 未知质量（实时 e-process 只维护证据）
pvals = {h: conformal_p(rho, h) for h in KNOWN}      # 标定集 p 值
u = 1.0 - max(pvals.values())                        # 未知质量
if max(pvals.values()) < alpha_open:
    post = {'H_unknown': u, **renormalize(pvals, 1 - u)}
else:
    post = normalize(pvals)                          # 已知族内定向归因；u≈0

# SCM-C：共因 vs 直接因果；不可辨识则保守回退
ci = causal.conditional_independence_tests(rho)
if ci.supports_common_cause:
    r_joint = max(r_joint, joint_radius(rho))        # 不裁成单通道
    post['common_cause'] = ci.posterior
elif ci.not_identifiable:
    r_joint = conservative_joint_radius(rho)         # Markov 等价类最坏

# IPG + 隔离：局部运行而非全局停机
Q = resolve_quarantine(contracts, intrusions, id_switches, post)
Aff = ipg.affected_closure(Q)
for a in plan:
    if a in Aff or shares_actuator(a, Q):
        skip(a); continue
    execute_with_i_shield(a, Q)                      # mask-conditional margin
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（未知质量的有效性）**：若标定签名在已知族内可交换，则对已知类样本 P(max_H p_H(ρ)<α_open)≤α_open；故 OSA 拒绝「已知族」的误拒率受控。未知质量 u 因此是**校准过的弃权信号**，而不是新的软分类；它保证「未知复合故障不被强行归入最近假设」，但不保证能命名未知故障。
- **引理 10（共因的可辨识性）**：观测分布无法区分「Z→ρ_a,Z→ρ_b」与「ρ_a→ρ_b」的 Markov 等价类；只有 do-干预能打破对称。故 MOSAIC 在不可辨识时按共因保守膨胀，且 AFA 探针的目标从「降低故障假设熵」扩展为「降低因果等价类的熵」。
- **定理 9（语义单调安全）**：在 A94–A99 下，VLA-S 只能通过 SPC 子句（只能 refute/unobservable）、unknown 质量（只能增加弃权/隔离）、staging 库（不进入实时）三条通道进入系统；三者都只会**收缩**允许动作集。故 A_safe^MOSAIC ⊆ A_safe^VISTA，Valid(J_mosaic) ⇒ VISTA 的全部物理安全保证仍成立；代价是 liveness 下降（更多弃权/隔离），而不是安全性下降。
- **定理 10（实例隔离下的部分运行安全）**：若 IPG 完整标注依赖与共享资源冲突，且局部运行仅执行 a∉Aff(Q)、无 shared_actuator 冲突、被触碰实例契约有效的动作，则剩余执行不会接触隔离实例或其依赖闭包，停止被包含在局部；故全局安全可分解为「实例局部安全 + 图割」。
- **命题 2（契约洗白风险界）**：若单帧 ID 交换概率为 ε_id，契约时长 T，则已验证契约被施加到另一物理物体的概率 ≤1−(1−ε_id)^T；故证书必须携带 (v_i,T_id) 并周期性重验证——这把 ID 交换从不可见风险变成可审计的时限约束。
- **实时性**：VLA-S/ISG/SPC/OSA/SCM-C/SPX 全在语义流；实时流只增实例缓存查询（<0.05ms）、unknown e-process 更新（<0.01ms）、I-Shield mask margin（<0.3ms），目标从 VISTA 的 ≤2.5ms 调整到 ≤3.0ms（A100 修订契约，需与 ISG 共享掩码缓存）。

**定义 234（具身大模型语义提议 VLA-S）** 固定的大模型 π_VLA 由观测 o_t 与语言目标 g 输出结构化提案
P_t = {(τ, r, A, C, F, Σ_exp)},
其中 τ 为任务/子任务，r 为自然语言指代（可带空间锚点），A 为 affordance 集合，C 为语义-物理契约子句（定义 236），F 为候选故障假设模板及其期望签名 Σ_exp；每个元素附提议分数与语义熵 H_sem。**约定：P_t 是提案分布，不是似然、不是真值、不可直接执行。** VLA-S 不提供任何被直接当作 p(ρ|H) 使用的量；若确需其预测，必须先在独立物理标定集上做 conformal 校准并记录版本。

**定义 235（实例分割接地与指代消解 ISG）** 实例分割 + 掩码跟踪给出持久实例集合
I_t = {(i, M_i(t), G_i(t), v_i(t))},
i 为实例 id，M_i 为二值掩码，G_i 为几何/位姿/可见性，v_i 为身份置信度。指代消解
R(r, I_t) ∈ {唯一 i, ambiguous, absent}，
ambiguous 表示多个候选实例、absent 表示无候选（大模型幻觉或完全遮挡）。身份连续性由掩码 IoU、外观嵌入、运动一致性与几何一致性联合打分；任一项冲突即降低 v_i 并触发 ICQ。**实例 id 是 MOSAIC 的信任单元：所有证据、契约、证书与隔离都以 i 为索引。**

**定义 236（语义-物理契约 SPC）** 对实例 i，契约 C_i={c_k}，子句
c_k = (pred_{i,k}, meas_{i,k}, test_{i,k}, status_{i,k}), status ∈ {support, refute, unobservable}。
子句类型至少覆盖：刚性/可形变（小载荷形变）、质量/惯性（抬升或加速度响应）、支撑/可及性（遮挡与接触几何）、易损性（视觉力代理 + 材料先验）、可抓/对跖几何（掩码 + 抓取宽度）、封闭/可盛（掩码开口与重力试验）、摩擦/滑移倾向（轻触切向）。检验统计量与阈值来自离线标定或 conformal。`unobservable` 是显式三态，**不得当 support 也不得当 refute**。契约状态取三值格：
- verified：全部子句 support；
- violated：存在子句 refute；
- conditional：无 refute 但有 unobservable，只允许在限制力/速度（乘 ρ_c<1）或先做 visual_probe 下执行。

**定义 237（实例化证据流与跨实例一致性）** 第 65 轮的阶段签名按实例分解：
ρ_t = ⊕_{i∈I_t} ρ_i(t), ρ_i = (ρ_{i,approach}, ρ_{i,touch}, ρ_{i,load}) ∈ ℝ^{15}。
跨实例一致性
χ_t = {d(ρ_i, ρ_j) : i,j 属同一物理本体的分裂掩码、同一支撑链、或跨视角重识别}；
若两掩码被判为同一物理物体而签名不一致，产生 `instance_split_conflict`。χ_t 同时作为 OSA 证据与 ID 交换检测证据。

**定义 238（开放集归因 OSA）** 已知故障族 ℋ_K={H0,H_geo,H_force,H_model,H_vis,H_policy}（沿用第 65 轮）。对签名 ρ 与每个已知假设 H，定义 conformal 拟合 p 值
p_H(ρ) = (1 + #{j : s_H(ρ_j) ≥ s_H(ρ)}) / (n_H + 1),
其中 s_H 为 H 类标定集上的非一致性分数（如 s_H=−log p(ρ|H)）。拒绝「ρ 属于已知族」当且仅当
max_{H∈ℋ_K} p_H(ρ) < α_open。
未知质量
u(ρ) = 1 − max_{H∈ℋ_K} p_H(ρ) ∈ [0,1]，
令 P(H_unknown|ρ)=u，已知假设按 (1−u) 归一化。实时流用 e-process 维护零假设「已知族可解释」的对数 e 值，越过 log(1/α_open) 即触发 unknown 事件（任意时间有效）。**H_unknown 不是可被定向处置的第 7 个假设：它只触发回溯、隔离与保守联合膨胀。**

**定义 239（共因结构因果模型 SCM-C）** 潜变量 Z=(Z_obj, Z_sensor, Z_env, Z_align, Z_task)，观测残差 ρ=(ρ_vis, ρ_geo, ρ_force, ρ_model, ρ_policy) 由结构方程 ρ=f(Z)+ε 生成。共因故障指存在同一 Z_k 同时是多个 ρ 分量的父节点（例如透明物体 Z_obj 同时导致视觉掩码错误与几何位姿错误）。用条件独立检验区分：
(i) 直接因果 ρ_a→ρ_b；(ii) 共因 Z→ρ_a, Z→ρ_b；(iii) 独立。
无干预时 (i)(ii) 属同一 Markov 等价类，**不可仅凭观测区分**，因此 MOSAIC：
(a) 可检验时优先检验；
(b) 不可检验时保守按共因处理，联合半径取等价类最大
r_joint = max_{等价类} r；
(c) 用 AFA 探针做 do-干预（如 null_test 只改力偏置、不改几何；visual_probe 只改视觉视角、不改力）打破对称，得到可辨识的因果方向。**共因下不要求归因正确，只要求被判为 unknown/common_cause 并安全降级。**

**定义 240（实例一致性与重识别 ICQ）** 身份置信度 v_i(t) 联合掩码 IoU、外观嵌入、运动、几何与跨视角一致性。ID 交换风险上界 ε_id(t)=1−v_i(t)。对时长 T 的契约，必须满足 (1−ε_id)^T ≥ 1−δ_id，否则在
T_id = ⌊log(1−δ_id)/log(1−ε_id)⌋
内重验证身份。证书绑定 (i, v_i, T_id) 三元组。检测到 `instance_split_conflict`、掩码跳变或外观嵌入突变时，立即冻结该实例并重跑 SPC（不沿用旧契约）。

**定义 241（未知物体入侵与开放集实例）** 计划未引用、但掩码跟踪稳定帧数 ≥ n_stable、且与规划轨迹最小距离 < d_intrude 的实例 j，称为 unknown-object intrusion。判据不依赖语义类别，故对任意新物体有效。入侵实例一律进入隔离集 Q。**这是对「大模型没提到就不存在」的显式反驳。**

**定义 242（实例交互图 IPG）** G_I=(V_I,E_I)。节点为实例、机器人本体、支撑面与环境锚点；边含 planned_contact（计划接触）、support（支撑依赖）、occlusion（遮挡依赖）、shared_actuator（共用执行器/工作空间冲突）。每个计划动作 a 标注 touch(a) 与其依赖闭包 Dep(a)。隔离集 Q 的受影响闭包
Aff(Q) = {a : Dep(a)∩Q≠∅ ∨ touch(a)∩Q≠∅}。

**定义 243（隔离算子与局部运行安全判据）** quarantine(i) 把 i 加入 Q，并移除所有 C_i∈{violated, conditional 未加限制} 的接触计划。局部运行允许执行动作 a 当且仅当
a ∉ Aff(Q) ∧ a 无 shared_actuator 冲突 ∧ 所有被触碰实例的契约有效。
只有 Q 覆盖全部可达实例，或存在未建模共享资源（未在 IPG 标注）时，才回退全局 safe_idle。**隔离单元是实例，不是场景。**

**定义 244（实例条件屏蔽 I-Shield）** 在 VISTA Shield-Skill 上按实例增加：允许接触区域、最大法向力 f_max,i、最大速度 v_max,i、禁止穿越区域。若 C_i=conditional，则按 unobservable 子句收紧（f_max,i←ρ_c f_max,i，v_max,i←ρ_c v_max,i）；若 C_i=violated 或 i∈Q，则禁止接触。屏蔽是 mask-conditional 的，不是 scene-global 的，因此隔离一个实例不必冻结整个场景。

**定义 245（语义先验扩展 SPX）** VLA-S 在语义流中可提出新故障假设模板 F_new（含期望签名与检验方案）。它们先进入 **staging 库**，不进入实时流；只有完成离线/标定台故障注入、似然拟合、AIC-O 认证并被签名版本化后，才**晋升**为 certified 库。实时流永远保留 unknown 触发器与 certified 库的旧版本快照；晋升低频、可回滚。**开放词汇只能扩大候选假设，不能直接改变实时安全行为。**

**定义 246（语义-物理冲突与提案拒绝）** 当 VLA-S 的提案与接地/契约冲突时（指代 absent、契约 refute、语义类别与物理属性矛盾、计划触碰未引用实例），产生冲突事件 κ。处置：拒绝该提案子句；若冲突来自大模型（幻觉/攻击）则降低 H_sem 权重并记录 `vla_reject`；若冲突来自物理（真实反驳）则更新 SPC 与 OSA。冲突不得被静默吞掉，必须进入 J_mosaic 审计链。

**定义 247（J_mosaic 证书）** J_mosaic=(J_vista, instance_contract_hash, referent_ids, unknown_mass, common_cause_posterior, quarantined_set, id_confidence, vla_sem_ver, spx_ver, conflict_log_hash)。验证规则：

∧ 每个被触碰实例 i 有 resolved referent
∧ contract(i) ∈ {verified, conditional-with-restriction}
∧ i ∉ Q ∧ 身份在 T_id 内有效

```python
class EmbodiedSemanticProposer:
    """固定大模型：只产提案，不产动作、不产似然。"""
    def propose(self, obs, goal):
        raw = self.vla(prompt=goal, image=obs.rgb, depth=obs.depth)
        return [Proposal(task=t, referent=r, affordances=A, clauses=C,
                         fault_templates=F, expected_sig=S, score=s)
                for (t, r, A, C, F, S, s) in parse_structured(raw)]


class InstanceGrounding:
    def resolve(self, referent, instances):
        cands = [i for i in instances if matches(referent, i.G, i.appearance)]
        if len(cands) == 1:
            return Resolution(id=cands[0].id, ambiguity=0.0)
        if len(cands) > 1:
            return Resolution(id=None, ambiguity=1.0 - 1.0 / len(cands))  # ambiguous
        return Resolution(id=None, ambiguity=1.0, absent=True)             # 幻觉/遮挡

    def track(self, prev, mask_pred, appearance):
        # 置信度 = IoU × 外观 × 运动 × 几何 的一致性
        v = combine(iou(prev.M, mask_pred), cos(prev.app, appearance),
                    motion_consistent(prev), geometric_consistent(prev))
        return Track(id=prev.id, M=mask_pred, v=v)


class SemanticPhysicalContract:
    CLAUSES = ('rigid', 'mass', 'support', 'fragile', 'grasp', 'seal', 'friction')

    def evaluate(self, instance, proposal, sensor):
        out = {}
        for k in self.CLAUSES:
            if k not in proposal.affordances:
                continue
            meas = measure_clause(k, instance, sensor)
            status = 'support' if meas is not None and test_clause(k, meas) \
                     else ('refute' if meas is not None else 'unobservable')
            out[k] = Clause(pred=k, meas=meas, status=status)
        if any(c.status == 'refute' for c in out.values()):
            return Contract(out, state='violated')
        if any(c.status == 'unobservable' for c in out.values()):
            return Contract(out, state='conditional')
        return Contract(out, state='verified')
```

```python
class OpenSetAttribution:
    """已知族 conformal 检验 + 未知质量；实时只维护 e-process。"""
    def attribute(self, rho):
        pvals = {h: conformal_p(rho, h, self.calib[h]) for h in self.known}
        u = 1.0 - max(pvals.values())
        if max(pvals.values()) < self.alpha_open:
            post = {'H_unknown': u}
            post.update(renormalize(pvals, mass=1.0 - u))
        else:
            post = normalize(pvals)              # 已知族内定向归因；u≈0
        return post, u

    def realtime_unknown_estat(self, rho_now):
        # 任意时间有效的 e-process；只增统计量，不做学习写
        self.log_e += self.log_lr_unknown_vs_known(rho_now)
        return self.log_e > np.log(1.0 / self.alpha_open)
```

```python
class InstanceConsistency:

class InstanceInteractionGraph:
    def affected_closure(self, Q):
        return {a for a in self.actions
                if (self.dep[a] & Q) or (self.touch[a] & Q)}

    def shares_actuator(self, a, Q):
        return bool(self.actuator[a] & union(self.actuator[q] for q in Q))


class IShield:
    def margin(self, a, instance, contract):
        m = mask_conditional_margin(a, instance.M, instance.G)

            m = min(m, self.rho_c * m)
        if contract.state == 'violated' or instance.id in self.Q:
```

```python
                      execution_loss_grad(K_safe, EV_exec, balls))
```

## 4. 推导

**假设 A94–A99**
- **A94（语义提案隔离）**：VLA-S 只经定义 234/236/246 的接口进入，不产生被直接使用的似然，不写实时路径。
- **A95（实例身份时限）**：ISG 的实例身份在 T_id 内以 ≥1−δ_id 保持；否则按定义 240 重验证。
- **A96（开放集校准）**：已知族标定签名与测试签名可交换（conformal 前提），或 e-process 零假设成立。
- **A97（共因覆盖）**：SCM-C 的潜变量集合覆盖真实共因，或不可辨识时按定义 239 保守回退。
- **A98（认证库不可在线改写）**：certified 故障库版本化且不可被 VLA-S 在线修改；SPX 晋升需离线认证。
- **A99（依赖图完整）**：IPG 的依赖边与 shared_actuator 冲突被完整标注。

**引理 9（未知质量的有效性）** 设已知类样本与标定集可交换。对已知类新样本 ρ，conformal p 值满足 P(p_H(ρ) ≤ α) ≤ α。于是
P(max_{H∈ℋ_K} p_H(ρ) < α_open) ≤ P(p_{H_true}(ρ) < α_open) ≤ α_open。
故 OSA 拒绝「已知族」的误拒率受控，u(ρ) 是校准过的弃权信号：当真实故障在已知族内时，系统以 ≤α_open 的概率误判为 unknown；当真实故障在已知族外时，u 提供可调的检出能力。**注意：它保证的是弃权校准（不强行归类），不是未知故障的命名准确率。** ∎

**引理 10（共因的可辨识性与保守回退）** 对两残差通道 ρ_a,ρ_b，观测分布 p(ρ_a,ρ_b) 在「Z→ρ_a,Z→ρ_b」与「ρ_a→ρ_b」两种结构下可取得相同边缘，二者属同一 Markov 等价类；仅凭观测无法识别。因此在不可检验时，任何把故障定向归到单通道的做法都可能错误。MOSAIC 的处置是：不对不可辨识的等价类做定向膨胀，而取等价类上的最大联合半径
r_joint = max_{结构∈等价类} r(结构)，
并以 do-干预（null_test 改力不改几何、visual_probe 改视角不改力）提供额外约束，使等价类缩小到可辨识。**共因下仍保留 VISTA 的安全性，只损失归因的特异性（更保守、更多弃权）。** ∎

**定理 9（语义单调安全）** 在 A94–A99 下，VLA-S 只能通过三条通道影响系统：
1. **SPC 子句**：只会产生 refute / unobservable，从而把 contract 从 verified 降为 violated/conditional，收缩允许动作集；
2. **unknown 质量**：只增加弃权、隔离与保守联合膨胀，同样收缩允许动作集；
3. **SPX staging**：不进入实时 certified 库（A98），故不改变实时动作集。
因此对任意场景，A_safe^MOSAIC ⊆ A_safe^VISTA。又 Valid(J_mosaic) ⇒ Valid(J_vista)（J_mosaic 以 J_vista 为合取项）且附加约束只收紧，故 VISTA 的几何/力/滑移/块前缀安全保证全部保持。**代价是 liveness（更多弃权/隔离），不是安全性。** ∎

**定理 10（实例隔离下的部分运行安全）** 设 IPG 完整（A99），Q 为隔离集。局部运行只执行
a ∉ Aff(Q) ∧ ¬shares_actuator(a,Q) ∧ ∀i∈touch(a): contract(i) 有效。
由 Aff(Q) 定义，a 的依赖闭包与接触集均不与 Q 相交，故 a 既不接触隔离实例，也不依赖其支撑；由 shared_actuator 排除，a 不会与隔离动作争用同一执行器/工作空间。于是隔离实例的状态转移与剩余执行解耦，任何由 Q 触发的停止都被包含在 Aff(Q) 内。因此全局安全等价于「每个被触碰实例的局部安全 + 图割正确」。∎

**命题 2（契约洗白风险界）** 设单帧 ID 交换概率为 ε_id，契约在 T 帧内被复用。至少一次交换的概率为 1−(1−ε_id)^T，交换后旧契约可能被施加到另一物理物体（契约洗白）。取 T_id=⌊log(1−δ_id)/log(1−ε_id)⌋ 可保证洗白概率 ≤δ_id。故 J_mosaic 必须携带 (v_i,T_id)；这把 ID 交换从不可观测风险变成可审计的时限约束，而不是消除它。∎

**MOSAIC-Complete（正确性概要）** 归因在已知族内且可辨识时，OSA 退化为 VISTA 的定向归因；未知/共因时，u 与 SCM-C 只增加弃权与联合膨胀，不产生错误定向；语义契约只增加物理约束；实例隔离只在依赖图割安全时启用。四者共同保证：**Valid(J_mosaic) ⇒ 物理安全不降 ∧ 未知被显式承认 ∧ 每次接触都有实例归属 ∧ 局部隔离不越过依赖闭包。**

## 7. 已知风险

**一句话**：MOSAIC 把安全性从「全局签名的正确归因」转移到「实例身份与指代的正确绑定」，而实例分割在遮挡、形变、透明与同款重复物下会发生 ID 交换或把部件/整体切错——一旦「已验证的语义-物理契约」被洗白到另一个未被验证的物理物体上，实例级隔离反而让系统放心地在其余物体上继续操作，**契约洗白（contract laundering）取代未知复合故障，成为更隐蔽的新单点故障**。

**次级风险与缓解**
1. **ID 交换 / 契约洗白**：实例跟踪在遮挡、形变、同款物下不可靠。缓解：身份置信度 v_i 进证书；T_id 时限强制重验证；`instance_split_conflict` 即冻结；关键接触前强制 re-ID（可用主动视觉或轻触纹理）。
2. **部件/整体实例切分不一致**：分割可能把把手与杯体、刀刃与刀柄切成不同实例，导致契约绑错层级。缓解：建立 part-whole 层级掩码；契约按层级继承（整体 verified 不自动推出部件 verified）；接触前检查 touch(a) 与契约层级的交集。
3. **未知质量校准漂移**：conformal/e-process 依赖可交换性，分布漂移下 u 失准。缓解：在线漂移检测（p 值分布漂移即重标定）；分场景/分实例类别校准；e-process 定期重置并记录版本。
4. **共因不可辨识**：SCM-C 的潜变量集合可能漏掉真实共因，保守回退仍可能不够保守。缓解：默认对不可辨识等价类取最大联合膨胀；AFA 做 do-干预；引入第三个物理独立通道（本体感觉/IMU）作为未来工作。
5. **大模型语义投毒 / 幻觉**：对抗 patch、场景文字、越权提示可让 VLA-S 提议不安全契约或漏报物体。缓解：SPC 物理反驳是硬门；未知物体入侵独立于语义；SPX 只暂存不直改实时库；所有提案进审计链。
6. **大模型延迟与不可复现**：50–200ms 推理与采样随机性。缓解：全部留语义流；固定版本与温度；缓存提案；实时流只读冻结实例缓存。
7. **隔离图的完整性假设**：IPG 漏标支撑/遮挡/共享执行器会让局部运行触碰到隔离闭包。缓解：保守默认「未知依赖即全局停机」；每次隔离后重新编译图；A99 作为证书前提显式列出。
8. **实时预算逼近 3ms**：实例缓存与 mask margin 仍可能超预算。缓解：掩码包围盒近似、ROI 降采样、事件相机、与 ISG 共享编码；在证书中标注近似级别。
9. **实例语义与物理语义错位**：分割的「实例」是视觉定义，未必等于物理/任务定义的物体（可动物体、软体、液体）。缓解：契约子句显式包含「本实例是否为可动物体/容器」；对软体/液体退化到 scene-global 保守模式。

**下轮可接的伏笔**：实例层级与 part-whole 的证书继承（把「信任单元」从实例细化到「实例×部件×接触面」），以及用主动视觉/轻触在关键接触前做**身份再验证**，把契约洗白从「时限约束」变成「可主动消除」。
