# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环新周期第 1 轮；本轮灵感：「社会影响」×「UniBot世界挑战赛」）

> 第 60 轮 SGEC 用 SSM×CIEC×EPIR×SERC×PCE++++ 把「场景先验提前收敛 K_safe、意图即时锁定约束、证据链防消息丢失」闭合起来。但整条链路仍建立在**四个未被审视的假设**上：
> 1. **场景只有物理属性，没有社会属性**：同一张桌面，面对熟练操作者、儿童、或正在分心的照护对象，可接受的接近速度、解释频率、力上限完全不同。第 60 轮把「人」放在场景之外，导致 K_safe 只对物安全、不对人安全。
> 2. **认知意图是单用户、单轮、单向的**：CIEC 把「慢点」当作一次静态约束写入 ERTC，却忽略了机器人自己的动作、解释、接近方式会反过来改变人的信任、舒适与下一步意图。**影响是双向的，而第 60 轮只建了单向映射**。
> 3. **证据链只证「执行合规」，不证「社会合规」**：EV-exec 能回答「阻抗是否按契约执行」，却回答不了「是否在未经同意的情况下操纵了人的信任」「是否违反了挑战赛的交互规范」。社会影响一旦发生，就不可逆，必须留下可审计证据。
> 4. **自设实验无法代表挑战赛的隐藏分布**：UniBot 世界挑战赛的判据是隐藏任务族、跨本体、最差层、限时、可复现；而 SGEC 的 SIC 置信度是自洽性的产物，越出训练分布时反而更自信（OOD 过度自信）。**在本实验室 95% 成功的证书，可能在隐藏测试上直接失效**。

## 0. 直觉与动机

先给直觉，再给定义：本轮不是再加一个感知模态，而是给第 60 轮加一层**「社会后果层 + 竞赛证据层」**——社会影响刻画「机器人把这个人变成了什么状态」，挑战赛刻画「这张证书离开当前任务族还成不成立」。

**灵感 1（社会影响 → 社会影响场 SIF）**
直觉：人对机器人的信任、舒适、心理负荷不是静态参数，而是被机器人动作持续改写的**状态变量**。一个突然加速的接近动作会让信任骤降；一次可解释的减速会让舒适回升。反过来，人的状态又决定机器人还能不能自主执行。关键洞见：把「社会影响」建模为**带同意掩码的受控状态转移**：h_{t+1}=A h_t+B u_t+w_t，其中 u_t 同时包含物理动作 a_t 与社会信号 s_t（语音、手势、接近距离、可读轨迹）。机器人只能在「同意」的维度上施加影响；对未同意维度的影响计入**操纵暴露**，并受影响预算 B_inf 约束。这样「社会影响」既不是软性偏好，也不是可随意优化的奖励，而是**有方向、有上限、可审计的干预**。

**灵感 2（UniBot 世界挑战赛 → 挑战任务分布 UCP 与泛化证书 CCG）**
直觉：挑战赛不是「在熟悉场景里跑高分」，而是「在没见过的任务、物体、本体、时间预算下不崩」。公开集均分高但隐藏集最差层崩塌的方案会被直接淘汰。关键洞见：把「这条策略能不能迁移」写成一个**可撤销的统计证书**——用共形风险控制在隐藏校准族上给出分数下置信界，用分布鲁棒优化给出 Wasserstein 球内的最差分数，并显式维护「公开-隐藏泛化缺口」G(π)。一旦版更或分布漂移使证书失效，策略自动降级为「只能监督下使用」。这把「竞赛成绩」从一次性数字变成**带失效条件的证据**。

**灵感 3（社会规范 → 规范约束编译 SNCC）**
直觉：社会规范（不侵入个人空间、先解释再动作、遇到犹豫要停）和挑战赛规则（限速、限力、限时、禁止危险探索）本质上是**可执行的约束集合**，而不是训练时的软惩罚。关键洞见：把规范 n_i 编译成触发条件 trigger_i 与可容许动作集 Admissible_i，硬规范直接与 ERTC 契约求交；一旦交集为空，触发**规范冲突升级**而不是静默违反。这样「社会合规」与「执行安全」共享同一套实时约束机制。

**灵感 4（社会证据 → 社会证据账本 SEEL）**
直觉：执行证据只记录「机器做了什么」，社会证据还要记录「人因此变成了什么状态、机器人是否越过了同意边界」。关键洞见：把 EV-soc 与 EV-exec 用因果 ID 链接，写入哈希链 / Merkle 账本；审计函数同时检查**规范合规、影响预算、证据链接完整性**。一旦缺链，系统必须报告「证据缺口」，而不是默认合规。

**灵感 5（合流 → 社会影响-挑战闭环 SICEL 与社会可接受帕累托决策 SAPD）**
直觉：SIF 给出人的状态后验 → SNCC 编译社会约束 → ERTC/EEIS 收紧执行 → 动作改变人的状态 → SEEL 记录社会后果 → CCG 更新泛化证书 → SAPD 在「任务收益 / 社会风险 / 泛化风险 / 预算」之间选一个**可接受且可复现**的解。形成闭环：**社会状态→规范→约束→执行→社会后果→证据→证书→再决策**。

**灵感 6（预算 → PCE+++++ 与挑战级可复现证书 CRC）**
直觉：社会影响不是免费的：解释要带宽、规范检查要算力、审计要存储、校准要样本、测试时适应要时间。把这些纳入预算 B_soc 与 B_chal；任一耗尽就退回「低影响、低自主、可监督」模式。最终用 CRC 把配置、数据哈希、随机种子、指标置信区间、共形覆盖、两份证据账本根哈希打包，使挑战赛成绩**可复现、可审计、可撤销**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（社会影响场 SIF）** 社会状态 h_t ∈ ℝ^d（默认 d=4：信任 trust、舒适 comfort、负荷 workload、参与度 engagement），机器人影响输入 u_t = (a_t, s_t)，其中 a_t 为物理动作，s_t 为社会信号（语音、手势、接近距离、可读轨迹）。社会影响场为线性高斯受控系统：
```
h_{t+1} = A h_t + B u_t + c + w_t,   w_t ~ N(0, Q)
o_t     = C h_t + v_t,               v_t ~ N(0, R)
```
- **社会后验**：b_t(h)=N(μ_t, Σ_t)，由 Kalman 滤波递推。
- **社会可接受集**：H_acc = {h | trust ≥ τ_tr, comfort ≥ τ_co, workload ≤ τ_wl}。
- **同意掩码**：c ∈ [0,1]^d，c_i=1 表示第 i 维影响已获同意（任务相关信息性影响），c_i=0 表示未同意（潜在操纵性影响）。
- **影响预算与操纵暴露**：
```
I_T = Σ_{t=1}^T ||diag(c) B u_t||_1 ≤ B_inf
M_T = Σ_{t=1}^T ||diag(1-c) B u_t||_1
```
- **社会风险**：
```
R_soc(b_t, u_1:T) = P_{h~b_t}(h ∉ H_acc) + λ_man · M_T/(B_inf+ε)
```
- **可辨识性假设（A66）**：ρ(A)<1，Q≻0，R≻0，系统一致可观测；社会状态误差有界，且 R_soc 的校准误差 ≤ ε_cal。

**定义 162（社会规范约束编译 SNCC）** 规范 n_i=(trigger_i, Admissible_i, priority_i, hardness_i, source_i)，其中 source ∈ {challenge_safety, human_safety, consent, social_convention, efficiency}。给定社会后验 b_t、场景 z_t 与挑战规则 R_ch：
```
Active_t = {n_i | trigger_i(b_t, z_t, R_ch)=true}
C_social = ⋂_{n_i∈Active_t, hardness_i=hard} Admissible_i
R_norm(u_t) = Σ_{n_i∈Active_t, hardness_i=soft} severity_i · 1[u_t ∉ Admissible_i]
C_rt^soc = C_rt ∩ C_social
```
- **优先级**：challenge_safety ≻ human_safety ≻ consent ≻ social_convention ≻ efficiency；硬规范冲突不可用软惩罚抵消。
- **规范冲突升级 NCE**：若 C_rt^soc=∅，在 τ_arb 内向人类请求仲裁；超时则 SAFE_STOP，并写入「规范冲突证据」。
- **规范漂移**：人类反馈与某软规范持续矛盾时，更新该规范的置信度；硬规范不可漂移。

**定义 163（挑战任务分布 UCP 与泛化证书 CCG）** 挑战 C=(T, D_ch, M, R, S)，任务 τ=(z_scene, e_embodiment, p_human, ξ_perturb) ~ D_ch，J(π,τ) 为挑战评分。数据分为公开集 D_pub、校准集 D_cal、隐藏集 D_hid 与对抗扰动集 D_adv。经验分数 J_pub(π)=E_{D̂_pub}[J]。
- **泛化缺口**：G(π)=E_{D_hid}[J(π,τ)] − E_{D̂_pub}[J(π,τ)]。
- **下置信界（共形/经验 Bernstein 形式）**：以概率 1−δ，
```
J_hid(π) ≥ J_pub(π) − G_upper(π, δ)
G_upper(π, δ) = R_J · sqrt( log(1/δ)/(2n) ) + Lip_J(π)·ε_W
```
其中 R_J 为分数值域，n 为校准样本数，ε_W 为 Wasserstein 半径，Lip_J 为评分对任务扰动的 Lipschitz 常数。
- **鲁棒分数**：J_rob(π)=inf_{D': W_1(D',D̂_pub)≤ε_W} E_{D'}[J(π,τ)]。
- **挑战泛化证书**：CGC=(n, δ, ε_W, J_pub, J_rob, G_upper, exchangeability_pvalue, split_hash)。
- **挑战级有效性**：CGC 有效 ⇔ G_upper ≤ ε_G ∧ exchangeability_pvalue ≥ α ∧ split_hash 未被污染。

**定义 164（社会证据账本 SEEL）** 社会证据条目
```
e_t = (seq_id, timestamp, link_exec, μ_t, Σ_t,
       norm_mask, influence_vector, human_feedback, prev_hash, hash)
```
其中 link_exec 为对应 EV-exec 的 seq_id，norm_mask 记录每条规范的合规位，influence_vector 记录 diag(c)Bu_t 与 diag(1−c)Bu_t。账本根 R_soc=MerkleRoot({e_t})。审计函数：
```
Audit(SEEL, N, B) ∈ {PASS, VIOLATION, EVIDENCE_GAP}
PASS ⇔ 全部硬规范合规 ∧ link_exec 可匹配 EV-exec ∧ I_T ≤ B_inf ∧ 哈希链完整
```
- **社会证书**：J_soc=(R_soc, compliance_vector, I_T, M_T, Audit)。若出现缺链，必须标记 EVIDENCE_GAP，禁止默认判为合规。

**定义 166（社会-挑战预算 PCE+++++）** B_soc=(B_inf, B_norm, B_expl, B_audit)，B_chal=(B_adapt, B_eval, B_calib)，并保留 B_exec 与 B_cog。
```
voi_soc(π) = VOI_meta_pessimistic(π)
             − cost_soc(π) − cost_chal(π) − cost_cog(π) − cost_exec(π)
cost_soc  = λ_inf·I_T + λ_norm·NormCheckCost + λ_expl·ExplanationCost + λ_audit·LedgerCost
```

降级规则：
- B_inf 耗尽 ⇒ 冻结说服性/高影响社会信号，只保留最小信息性信号；
- B_norm 冲突或不确定 ⇒ 取所有触发规范的保守交集；空集则 SAFE_STOP；
- B_expl 耗尽 ⇒ 仅用预置解释模板，停止多轮解释；
- B_audit 耗尽 ⇒ 本地缓冲审计，显式标记 audit_incomplete；
- B_chal 耗尽 ⇒ 停止测试时适应，使用鲁棒默认策略；
- B_exec 耗尽 ⇒ 回退第 60 轮的执行降级。

**定义 167（社会可接受帕累托决策 SAPD）** 可行集
```
F_t = {π | R_soc(b_t,π) ≤ ε_soc ∧ Audit(π)=PASS ∧ G_upper(π,δ) ≤ ε_G ∧ BudgetOK(π)}
J_total(π) = E[U_task(π)] − λ_soc·R_soc(π) − λ_man·M_T(π)/B_inf − λ_gen·G_upper(π,δ)
```

### IP-161 SIF（社会影响场）

```python
class SocialInfluenceField:
    def __init__(self, dim=4, dt=0.1, B_inf=1.0):
        self.A = np.eye(dim) + dt * np.diag([-0.20, -0.10, -0.05, -0.10])
        self.B = np.zeros((dim, 6))
        self.C = np.eye(dim)
        self.Q = np.diag([0.01, 0.01, 0.02, 0.02])
        self.R = np.diag([0.05, 0.05, 0.05, 0.05])
        self.mu = np.array([0.6, 0.6, 0.3, 0.5])
        self.Sigma = np.diag([0.1, 0.1, 0.1, 0.1])
        self.consent = np.ones(dim)
        self.B_inf = B_inf
        self.I = 0.0
        self.M = 0.0

    def predict(self):
        self.mu = self.A @ self.mu
        self.Sigma = self.A @ self.Sigma @ self.A.T + self.Q

    def observe(self, o):
        S = self.C @ self.Sigma @ self.C.T + self.R
        K = self.Sigma @ self.C.T @ np.linalg.inv(S)
        self.mu = self.mu + K @ (o - self.C @ self.mu)
        self.Sigma = (np.eye(len(self.mu)) - K @ self.C) @ self.Sigma

    def intervene(self, a, s):
        u = np.concatenate([a, s])
        dh = self.B @ u
        self.I += np.linalg.norm(np.diag(self.consent) @ dh, 1)
        self.M += np.linalg.norm(np.diag(1.0 - self.consent) @ dh, 1)
        return dh

    def social_risk(self, lam_man=0.5, eps=1e-9):
        p_out = monte_carlo_outside(self.mu, self.Sigma, H_acc, n=512)
        return p_out + lam_man * self.M / (self.B_inf + eps)

    def acceptable(self, eps_soc):
        return self.social_risk() <= eps_soc and self.I <= self.B_inf
```

### IP-162 SNCC（社会规范约束编译）

```python
class NormConstraintCompiler:
    PRIORITY = {'challenge_safety': 4, 'human_safety': 3,
                'consent': 2, 'social_convention': 1, 'efficiency': 0}

    def compile(self, norms, belief, scene, challenge_rules):
        active = [n for n in norms
                  if n.trigger(belief, scene, challenge_rules)]
        active.sort(key=lambda n: (n.hard, self.PRIORITY[n.source]),
                    reverse=True)
        C = ActionUniverse()
        penalty = 0.0
        for n in active:
            C_next = C.intersect(n.admissible)
            if C_next.is_empty():
                if n.hard:
                    return None, NormConflict(n, active)
                penalty += n.severity
            else:
                C = C_next
        return C, penalty
```

### IP-163 UCP / CCG（挑战泛化与证书）

```python
class ChallengeGeneralizer:
    def __init__(self, delta=0.1, eps_w=0.05, eps_g=0.08):
        self.delta = delta
        self.eps_w = eps_w
        self.eps_g = eps_g

    def gap_upper(self, scores, lip=1.0):
        n = len(scores)
        rng = float(np.max(scores) - np.min(scores)) + 1e-9
        return rng * np.sqrt(np.log(1.0 / self.delta) / (2.0 * n)) \
               + lip * self.eps_w

    def robust_score(self, policy, calib_tasks, alpha=0.1):
        scores = [policy.score(t) for t in calib_tasks]
        return float(np.quantile(scores, alpha))

    def select(self, policies, calib_tasks, lam_rob=0.5, lam_gen=1.0):
        best, best_val = None, -float('inf')
        for p in policies:
            scores = [p.score(t) for t in calib_tasks]
            j_pub = float(np.mean(scores))
            j_rob = self.robust_score(p, calib_tasks)
            g_up = self.gap_upper(scores)
            val = j_pub - lam_rob * (j_pub - j_rob) - lam_gen * g_up
            if val > best_val:
                best, best_val = p, val
        return best, best_val

    def certificate(self, scores, split_hash, exchange_p):
        return CGC(n=len(scores), delta=self.delta, eps_w=self.eps_w,
                   j_pub=float(np.mean(scores)),
                   j_rob=self.robust_score(None, scores),
                   gap_upper=self.gap_upper(scores),
                   exchange_pvalue=exchange_p, split_hash=split_hash)
```

### IP-164 SEEL（社会证据账本）

```python
class SocialEvidenceLedger:
    def __init__(self):
        self.entries = []
        self.root = '0' * 64

    def append(self, ev_exec, belief, norm_mask, influence):
        entry = {
            'seq_id': len(self.entries) + 1,
            'timestamp': time.time(),
            'link_exec': ev_exec.seq_id,
            'mu': belief.mu.tolist(),
            'sigma': belief.Sigma.tolist(),
            'norm_mask': norm_mask,
            'influence': influence,
            'prev_hash': self.root,
        }
        entry['hash'] = sha256(canonical_json(entry))
        self.entries.append(entry)
        self.root = merkle_root([e['hash'] for e in self.entries])
        return entry

    def audit(self, norms, budget):
        for e in self.entries:
            if any(v == 0 for v in e['norm_mask'].values()):
                return 'VIOLATION'
            if not exec_exists(e['link_exec']):
                return 'EVIDENCE_GAP'
            if e['influence']['I'] > budget.B_inf:
                return 'VIOLATION'
```

## 2. 关键推导

### 2.1 社会风险的可计算上界

设 b_t=N(μ,Σ)，H_acc 由 m 个半空间约束 `g_j(h)=α_j^T h − β_j ≥ 0` 定义。令边界余量 `d_j=(α_j^T μ−β_j)/‖α_j‖`，标准差 `σ_j=sqrt(α_j^T Σ α_j)/‖α_j‖`。由联合界与高斯尾界：
```
P(h ∉ H_acc) ≤ Σ_{j=1}^m P(g_j(h) < 0) = Σ_{j=1}^m Φ(−d_j/σ_j)
```
因此
```
R_soc^upper = Σ_j Φ(−d_j/σ_j) + λ_man · M_T/(B_inf+ε)
```
该上界只需 μ、Σ 与规范参数，可在线 O(m) 计算，直接作为 SAPD 的可行性判据（要求 R_soc^upper ≤ ε_soc）。相比 Monte Carlo，它给出**确定性保守上界**，避免采样误差掩盖社会风险。

### 2.2 影响预算的坐标分解

由于同意掩码按坐标划分，`diag(c)+diag(1−c)=I`，故
```
I_T + M_T = Σ_t (‖diag(c)Bu_t‖₁ + ‖diag(1−c)Bu_t‖₁) = Σ_t ‖Bu_t‖₁ ≜ T_T
```
于是只要执行时同时满足 `T_T ≤ B_inf_total` 与 `I_T ≤ B_inf`，就自动有 `M_T ≤ B_inf_total − B_inf`。这把「防操纵」从软性伦理约束变成**可实时校验的预算不等式**：未同意维度的影响越多，可用于正当信息性影响的空间越小。

### 2.3 挑战泛化的下置信界

设 J(π,τ)∈[0,R_J]，校准样本 n 个独立同分布（给定 split 内可交换）。由 Hoeffding 不等式，以概率 1−δ：
```
|E[J]−Ĵ| ≤ R_J·sqrt(log(2/δ)/(2n))
```
再叠加分布鲁棒项 `Lip_J(π)·ε_W`（Wasserstein 球内评分 Lipschitz 变化），得到
```
J_hid(π) ≥ J_pub(π) − R_J·sqrt(log(2/δ)/(2n)) − Lip_J(π)·ε_W
```
右端即 `J_pub−G_upper`。证书 CGC 有效当且仅当 `G_upper ≤ ε_G`、split 未被污染、交换性检验 p 值 ≥ α。任何「隐藏集上再调参」都会使 split_hash 失效，从制度上阻止排行榜过拟合。

### 2.4 二阶信号单调性引理

**引理（只收紧）**：若 `C_social` 由硬规范可容许集交叠而成，`C_rt^soc=C_rt∩C_social`，则对任意新增硬规范 n，`C_rt^soc' = C_rt∩C_social∩Admissible_n ⊆ C_rt^soc`。进一步，若 SAPD 的可行集 `F_t` 以 `R_soc^upper`、`G_upper`、`Audit=PASS` 作为附加约束，则新增任何社会/泛化证据只会使 `F_t` 单调收缩，不会扩大自主动作集。

**证明要点**：集合交运算单调递减；可行集是动作集与若干上界约束的交，新增约束不可能增加元素。故「二阶信号」天然只能降低自主性，满足安全单调性。这条引理是 SICG 与「用信任分数换自主权」类方案的根本区别。

### IP-161 SIF（社会影响场）

```python
class SocialInfluenceField:
    def __init__(self, dim=4, dt=0.1, B_inf=1.0):
        self.A = np.eye(dim) + dt * np.diag([-0.20, -0.10, -0.05, -0.10])
        self.B = np.zeros((dim, 6))
        self.C = np.eye(dim)
        self.Q = np.diag([0.01, 0.01, 0.02, 0.02])
        self.R = np.diag([0.05, 0.05, 0.05, 0.05])
        self.mu = np.array([0.6, 0.6, 0.3, 0.5])
        self.Sigma = np.diag([0.1, 0.1, 0.1, 0.1])
        self.consent = np.ones(dim)
        self.B_inf, self.I, self.M = B_inf, 0.0, 0.0

    def predict(self):
        self.mu = self.A @ self.mu
        self.Sigma = self.A @ self.Sigma @ self.A.T + self.Q

    def observe(self, o):
        S = self.C @ self.Sigma @ self.C.T + self.R
        K = self.Sigma @ self.C.T @ np.linalg.inv(S)
        self.mu = self.mu + K @ (o - self.C @ self.mu)
        self.Sigma = (np.eye(len(self.mu)) - K @ self.C) @ self.Sigma

    def intervene(self, a, s):
        u = np.concatenate([a, s])
        dh = self.B @ u
        self.I += np.linalg.norm(np.diag(self.consent) @ dh, 1)
        self.M += np.linalg.norm(np.diag(1.0 - self.consent) @ dh, 1)
        return dh

    def risk_upper(self, H_acc, lam_man=0.5, eps=1e-9):
        p_out = sum(gaussian_tail(margin_j, sigma_j)
                    for margin_j, sigma_j in H_acc.margins(self.mu, self.Sigma))
        return p_out + lam_man * self.M / (self.B_inf + eps)
```

### IP-162 SNCC（社会规范约束编译）

```python
class NormConstraintCompiler:
    PRIORITY = {'challenge_safety': 4, 'human_safety': 3,
                'consent': 2, 'social_convention': 1, 'efficiency': 0}

    def compile(self, norms, belief, scene, challenge_rules):
        active = [n for n in norms
                  if n.trigger(belief, scene, challenge_rules)]
        active.sort(key=lambda n: (n.hard, self.PRIORITY[n.source]),
                    reverse=True)
        C, penalty = ActionUniverse(), 0.0
        for n in active:
            C_next = C.intersect(n.admissible)
            if C_next.is_empty():
                if n.hard:
                    return None, NormConflict(n, active)
                penalty += n.severity
            else:
                C = C_next
        return C, penalty
```

```python
        self.delta, self.eps_w, self.eps_g = delta, eps_w, eps_g

    def gap_upper(self, scores, lip=1.0):
        n = len(scores)
        rng = float(np.max(scores) - np.min(scores)) + 1e-9
        return rng * np.sqrt(np.log(2.0 / self.delta) / (2.0 * n)) \
               + lip * self.eps_w

    def robust_score(self, scores, alpha=0.1):
        return float(np.quantile(scores, alpha))

    def select(self, policies, calib_tasks, lam_rob=0.5, lam_gen=1.0):
        best, best_val = None, -float('inf')
        for p in policies:
            scores = [p.score(t) for t in calib_tasks]
            j_pub = float(np.mean(scores))
            j_rob = self.robust_score(scores)
            g_up = self.gap_upper(scores)
            val = j_pub - lam_rob * (j_pub - j_rob) - lam_gen * g_up
            if val > best_val:
                best, best_val = p, val
        return best, best_val

    def certificate(self, scores, split_hash, exchange_p):
        return CGC(n=len(scores), delta=self.delta, eps_w=self.eps_w,
                   j_pub=float(np.mean(scores)),
                   j_rob=self.robust_score(scores),
                   gap_upper=self.gap_upper(scores),
                   exchange_pvalue=exchange_p, split_hash=split_hash)
```

```python
               - LAM_GEN * p.gap_upper(cgc))
```

## 5. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| SIF | O(d³)/步，d=4 | O(d²) | 社会风险上界 R_soc^upper 可计算且保守 |
| SNCC | O(|N|·|A|)/周期 | O(|N|) | 硬规范 100% 进入 C_social，冲突必升级 |
| UCP/CCG | O(n log n) 校准 | O(n) | 以概率 1−δ，J_hid ≥ J_pub−G_upper |
| SEEL | O(1) 追加 + O(log n) 根 | O(n) | 篡改可检测；缺链报 EVIDENCE_GAP |
| SICEL | O(闭环) | 复用 SGEC | 每步满足社会风险/规范/预算不变量 |
| SAPD | O(|Π|·|F|) | O(|Π|) | 可行集非空 ⇒ 帕累托前沿内解；空集安全停止 |
| CRC | O(账本大小) | O(n) | 复现通过 ⇔ 指标与双根哈希在容差内 |

**正确性定理（SICG）**：若 A66–A72 成立，则：
1. 社会安全：`P(h∉H_acc) ≤ R_soc^upper ≤ ε_soc`，且 `M_T ≤ B_inf_total−B_inf`。
2. 规范合规：执行动作 ∈ C_social，或触发 SAFE_STOP/NCE，不存在静默违反。
3. 泛化可信：以概率 1−δ，`J_hid ≥ J_pub−G_upper`；CGC 失效则强制降级。
4. 社会可审计：每个 EV-exec 存在唯一 EV-soc 链接；违反/缺口可独立验证。
5. 预算安全：任一 B_soc/B_chal 耗尽 ⇒ 低影响、低自主、可监督模式。
6. 可复现：`ClaimValid=1 ⇒` 指标、双证据根与配置可被 replay 验证。
