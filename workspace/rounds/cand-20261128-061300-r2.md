### 第 6 轮灵感驱动研究记录

**灵感词**：状态估计、无刷电机

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把提议升级为条件流匹配、记忆升级为嵌入+固化、人因升级为情感调制，并以定理 6（证书不变性）把框架推广为「任意生成器 + 认证边界」（CGE）。但 v5 有一个未言明的前提：**所有门都直接读真状态**。本轮指出这是整个证书体系最薄弱的隐含假设——门是轨迹空间上的谓词，可它吃进去的状态 s（末端位姿、接触拓扑、关节速度、人类意图）几乎从不是直接测量，而是估计出来的。两个灵感词统一为主题「观测受限下的认证执行」（Certified Execution under Observation Limits, CEOL），形成 CADVS-v6（IP-497~500）。无刷电机不是装饰性类比，而是本轮的核心试金石：无感 BLDC/PMSM 在低速时反电动势 ∝ 转速而趋于零，位置观测性塌缩，换相误差直接经雅可比放大成末端力误差；这正是「证书算得对，但算在错误状态上」的最小可复现实例。本轮自律：**七硬门仍不增**，新增的只是「门的状态输入从点估计升级为信念集」与「观测性作为可认证性的一等约束」。

**直觉与动机**：

1. **状态估计 → 证书必须对「状态的不确定性」稳健，而不是对「状态的点估计」稳健**。v5 的 kc_i(x, c) 把状态当已知常数；真实系统只有信念 b_t = N(μ_t, Σ_t) 甚至非高斯集。直觉：如果一个门在 μ 处边际 0.02、而状态标准差对应 0.05 的分数扰动，那这个门其实没有通过——它只是「碰巧在估计均值上通过」。把每个门提升为「在最坏可信状态上的分数仍过阈」：s_i^rob(x;b) = min_{s∈B_ε} s_i(x;s) ≥ τ_i。这把估计误差变成显式的安全预算，且天然单调：Σ 越大，执行集越小。**定理 9** 给出 Σ1 ⪯ Σ2 ⇒ Exec_v6(Σ2) ⊆ Exec_v6(Σ1) ⊆ Exec_v5，Σ→0 且未建模项为零时精确退化为 v5。这是把「状态估计」从工程细节提升为证书语义的一步。

2. **无刷电机 → 观测性不是常数，它随工况退化；「估计不出来」必须是一等失败模式，而不是悄悄降级**。无感 FOC 的转子位置可由反电动势观测器估计，但低速/零速时 E = k_e·ω → 0，信噪比塌缩；若观测器仍自信输出，换相角误差 δθ 经 ∂F/∂θ 放大为力误差，wrench/ZMP 门就会在错误状态上「合法通过」。类比到机械臂：低速接触任务恰是力控最需要精度的时刻，也恰是关节速度/接触状态最难观测的时刻。由此引入**观测性指数 ρ_obs**与**可认证性对偶（定理 10）**：在给定置信度下，证书的最坏情形误差下界随有效观测性下降而上升；当 ρ_obs < ρ_min 时，任何有限样本证书都无法保证，系统必须**主动激励恢复观测性**或**安全停机**，二者都不能绕过。无刷电机的工程解法（低速高频注入 HFI、切换编码器、受控刹车）正好对应三条策略：主动探测、冗余切换、观测包络外安全停。

3. **主动激励与安全停 → 观测性可以被「买」回来，但价格是控制权限与扰动，且激励本身必须被认证**。无感电机在零速用高频电压注入，靠凸极效应产生可测电流响应，但注入幅度受电流/转矩纹波限制；机械臂对应「受认证的探测动作」：小幅、可回退、预测轨迹仍在 Exec_v5 内的激励。**定理 11**：若存在 u_exc ∈ U_safe 且预测后状态仍在 Exec_v5、同时提升 λ_min(F)，则探测保持 fail-closed 与执行集嵌套；不存在则只剩安全停。关键红线：**激励不得以放松任何门为代价**，且「没有免费观测性」——提升 Fisher 信息必然付出控制能量/纹波，需在代价里显式记账。

**关键洞见**：v5 回答「提议是任意生成器时证书边界是否不变」；v6 回答「当门读到的状态本身带误差、且误差随工况退化时，证书还意味着什么」。七硬门 kc_evidence_forged_v4 原样保留，但每个门的状态参数从 s 换成信念 b_t 上的稳健化版本；新增的不是门，而是**观测层**：OASEK（观测性感知估计 + 一致性监控）、CBGI（信念稳健门膨胀）、AOIK（认证探测 + 观测包络安全停）。执行集升级为 Exec_CADVS-v6 = {x ∈ supp(π_FM) : ∧_i kc_i^rob(x,b_t)=1 ∧ ρ_obs ≥ ρ_min} ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**形式化目标（增量）**：
1. 信念状态 b_t=(μ_t,Σ_t)，置信椭球 B_ε(Σ)={s:(s−μ)^TΣ^{-1}(s−μ)≤χ²_{d,ε}}；估计器 E:(y_{0:t},u_{0:t})→b_t。
2. 有效观测性 ρ_obs = λ_min(O_t^T W O_t)/(λ_max(Σ_nuis)+σ²) 的归一化形式（定义 2247），O_t 为观测 Gramian、W 为噪声权重、Σ_nuis 为未建模项协方差。
3. 稳健门：s_i^rob(x;b) = s_i(μ) − L_i·(r_ε + r_nuis)，r_ε=√(χ²_{d,ε}λ_max(Σ))；kc_i^rob=1[s_i^rob≥τ_i]。
4. 定理 9（信念稳健化单调性）、定理 10（观测性-可认证性对偶）、定理 11（认证探测的安全性与无免费观测性）、定理 12（估计器-门分离：估计器不得在自铸证片段上训练以膨胀执行集）。
5. EFA-v6：先估 b_t → 一致性检验（NEES/NIS χ²）→ 稳健门膨胀 → 观测性检查 → 必要时认证探测/安全停 → 其余复用 v5 级联。
6. Exec_CADVS-v6 = {x∈supp(π_FM): ∧_i kc_i^rob(x,b_t)=1 ∧ ρ_obs≥ρ_min} ⊆ Exec_CADVS-v5。

**本轮最大风险**：**观测性幻觉**——估计器在真实观测性已塌缩时仍报告小而错误的协方差（反电动势观测器锁到错误换相扇区、未建模死区/摩擦被吸收进状态），稳健门围绕错误均值收紧，一致性监控又被相关噪声骗过，于是系统对「一个不存在的状态」签发了形式合法的证书；这是比 v5 的固化自指回路更隐蔽的失效，因为它在门这一层完全看不出问题。

```python
class ObservabilityAwareStateEstimator:
    """OASEK：估计信念而非点，显式监控观测性与一致性。
    红线：估计器不读真状态，只在离线回放中用真值做 NEES 审计"""

    W: np.ndarray                 # 量测噪声权重
    rho_min: float = 0.08         # 可认证性下限
    nees_ci: tuple = (0.90, 0.99) # 一致性置信区间

    def step(self, b_prev, y, u) -> Belief:
        # 1) UKF/MHE 预测-更新（非线性；MHE 仅在事件触发时用，见 §3）
        b = self._ukf_update(self._predict(b_prev, u), y)
```

### IP-498 CBGI：信念稳健门膨胀（准入/控制环，O(n_gates·d_s)）

```python
def robust_score(s_i, x, b, L_i, chi2_eps) -> float:
    """s_i^rob = s_i(μ) − L_i·(r_ε + r_nuis)。
    s_i 对 s 为 L_i-Lipschitz 时，这是置信椭球上的严格下界（引理 45）"""
    r_eps = sqrt(chi2_eps * lambda_max(b.Sigma))
    r_nuis = sqrt(chi2_eps * lambda_max(b.Sigma_nuis))
    return s_i(x, b.mu) - L_i * (r_eps + r_nuis)
```

### IP-499 AOIK：认证探测与观测包络安全停（事件触发，10–50 Hz）

```python
@dataclass
class ActiveObservabilityInjectionKernel:
    """AOIK：观测性不足时，用「受认证的激励」买回信息，否则安全停。
    无刷电机对照：HFI 高频注入 / 切编码器 / 受控刹车"""
    u_safe: Callable               # U_safe 约束（电流、力矩、速度、接触力上限）
    pred: Callable                 # 预测后状态（用名义模型 + b）
    energy_budget: float

    def act(self, b, exec_v5) -> Action:
        if b.rho_obs >= self.rho_min and b.consistent:
            return Action(kind='NOMINAL')
        # 候选激励：机械臂小幅 dither；电机 HFI / 强制换相 / 切冗余传感器
        cands = self._candidate_excitations(b)
        feasible = [u for u in cands
                    if self.u_safe(u) and self.pred(b, u) in exec_v5
                    and self._lminF(b, u) > self._lminF(b, None)]
        if feasible:
            # 在可行集中选「单位能量信息增益最大」者（无免费观测性，显式记账）
            u_best = max(feasible, key=lambda u: self._info_gain(u) / self._energy(u))
            return Action(kind='PROBE', u=u_best, cost=self._energy(u_best))
        # 无可行激励：进入认证安全停（受控刹车，受停止距离/接触力约束）
        return Action(kind='SAFE_STOP', plan=Stop(b, exec_v5))
```

### IP-500 EFA-v6：先估计再认证的装配器

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：七硬门不变；状态输入 b_t；观测性作为可认证性前置条件"""
    oasek: ObservabilityAwareStateEstimator
    cbgi: Any                          # 稳健门膨胀
    aoik: ActiveObservabilityInjectionKernel
    v5: EvidenceForgingAssemblerV5     # 复用 FMPP/LMEM-v2/FAMK/七门级联

    def select(self, y_hist, u_hist, t_now, rule_id, context):
        b = self.oasek.step(context.b_prev, context.y, context.u)   # 信念
        if not b.consistent:
            # 一致性失败：先尝试探测恢复，否则 fail-closed
            act = self.aoik.act(b, Exec_v5)
            if act.kind != 'PROBE':
                return False, None, 'ESTIMATOR_INCONSISTENT_SAFE_STOP'
            b = self.oasek.step_after_probe(b, act.u)
        # 观测性门：低于下限则探测或安全停（不是悄悄降级）
        if b.rho_obs < self.aoik.rho_min:
            act = self.aoik.act(b, Exec_v5)
            if act.kind == 'PROBE':
                b = self.oasek.step_after_probe(b, act.u)
            elif act.kind == 'SAFE_STOP':
                return False, None, 'OBSERVABILITY_FLOOR_SAFE_STOP'
        # 稳健门：七门原样，状态换成 b 上的最坏情形
        if not all(self.cbgi.kc_robust(g, x, b, g.tau4, g.L) for g in SEVEN_GATES):
            return False, None, 'ROBUST_GATE_REJECT'
        # 其余复用 v5：FMPP 提议 → 廉价门 → VACK → BCK；c 含 (μ,Σ,ρ_obs)
        ok, x, code = self.v5.select(x0_state=b.mu, t_now=t_now,
                                     rule_id=rule_id,
                                     context=with_belief(context, b))
        return ok, x, code

    def ecs_v6(self, base, b):
        eta_obs = sigmoid((b.rho_obs - self.aoik.rho_min) / 0.02)
        eta_cons = 1.0 if b.consistent else 0.0
        return base.ecs_v5(...) * eta_obs * eta_cons
```

### 实例：无感 BLDC/PMSM 关节为何是「最小可复现反例」

```
电机侧（dq 系）: v_q = R i_q + L_q di_q/dt + ω(L_d i_d + λ_m)
               e_q ≈ k_e·ω  →  ω→0 时反电动势趋于 0，无感位置观测失效
               τ = (3/2)p[λ_m i_q + (L_d−L_q)i_d i_q]；HFI 用凸极 (L_d−L_q) 在零速测位置
换相误差传播:   δθ → δτ ≈ (∂τ/∂θ)δθ → δF ≈ J^{-T}δτ
              ⇒ wrench/ZMP 门在错误状态上通过；低速接触任务恰是 δθ 影响最大处
工程三解法:     HFI 高频注入（≈认证探测）/ 切编码器（≈冗余）/ 受控刹车（≈安全停）
```

**与 v5 的接缝**：v5 的定理 6 说「换提议不换门」；v6 说「门不变，但门的输入必须是带不确定集的信念」。两者正交，可组合为「任意提议 + 任意（可认证的）估计器 + 固定门」。

## 4. 正确性论证（增量更新）

### 引理 45（Lipschitz 稳健化下界）

**陈述**：若门分数 s_i(x;·) 对状态 s 为 L_i-Lipschitz，则对任意 s∈B_ε(Σ)⊕B_ε(Σ_nuis)，有 s_i(x;s) ≥ s_i(x;μ) − L_i(r_ε+r_nuis)。故 s_i^rob 是置信集上的严格下界。∎

**证明**：‖s−μ‖ ≤ r_ε+r_nuis（三角不等式 + 椭球半径定义），再由 Lipschitz 性。∎

### 引理 46（观测性-协方差下界，含未建模项）

**陈述**：在正则无偏估计下 Σ ⪰ F^{-1}，故 λ_max(Σ) ≥ 1/λ_min(F)；于是 r_ε ≥ √(χ²/λ_min(F))。加入未建模项后 r_ε+r_nuis ≥ √(χ²/λ_min(F)) + r_nuis。∎

**诚实边界**：CRLB 只对无偏、模型正确、正则分布成立；未建模项、非高斯、强非线性都会使实际误差大于此界。因此该引理给的是**必要条件**（观测性太低必然不可认证），不是充分条件（观测性高也可能因偏差失败）。

### 引理 47（信息增益-激励能量界，假设 A_energy）

**陈述**：在局部线性化量测 y = O s + ν 下，λ_min(F(u)) − λ_min(F_0) ≤ C·‖u−u_0‖²/σ²。即信息增益被激励能量上界约束。∎

**证明**：F(u)=O(u)^T W O(u)，O 对 u 的灵敏度受执行器增益与状态转移范数约束，展开一阶项并用 λ_min 的 Lipschitz 性。∎

### 定理 v6（观测受限下的执行集收缩与可认证性，总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 门分数 Lipschitz、(B9) 估计器正则/未建模项有界下：
(i) Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29；
(ii) 信念稳健化单调：Σ1 ⪯ Σ2 ⇒ Exec_v6(Σ2) ⊆ Exec_v6(Σ1)（定理 9）；
(iii) 观测性下限：ρ_obs < ρ_min ⇒ 无证书可签发，必须探测或安全停（定理 10）；
(iv) 认证探测保持 fail-closed，且无免费观测性（定理 11）；
(v) 估计器-门分离：冻结门 + 独立真值训练 ⇒ 估计器无法主动膨胀执行集（定理 12）；
(vi) 精确退化：Σ→0、Σ_nuis→0、ρ_obs≥ρ_min 时 Exec_v6 = Exec_v5。

**证明**：(i) 由稳健门只紧 + 观测性条件额外剔除；(ii)(iii)(iv)(v) 分别由定理 9/10/11/12；(vi) 由引理 45 中半径归零 + 门谓词一致。∎

**诚实声明**：(i) 观测性幻觉（协方差本身失真）不被任何上述定理排除，NIS 一致性监控只能检测部分不一致，相关噪声可系统性骗过；(ii) CRLB 下界依赖模型正确与无偏，实际系统常有偏且模型错，故 ρ_min 只能工程标定；(iii) 未建模项半径 r_nuis 的估计本身不可靠，偏小会静默放大风险；(iv) 安全停也可能不安全（刹车距离/接触力），Stop 必须同样过门。

## 7. 本轮最大风险（最终确认）

**一句话**：**观测性幻觉**——估计器在真实观测性已塌缩时仍报告小而错误的协方差（反电动势观测器锁到错误换相扇区、未建模死区/摩擦被吸收进状态），稳健门围绕错误均值收紧，一致性监控又被相关噪声骗过，于是系统对「一个不存在的状态」签发了形式合法的证书；这是比 v5 固化自指回路更隐蔽的失效，因为它在门这一层完全看不出问题。
