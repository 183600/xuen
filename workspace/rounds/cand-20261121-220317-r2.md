# 第 3 轮（灵感循环；本轮灵感：「双足机器人」×「仿真到现实迁移」）

> **基线**：第 2 轮产出 MetricVoiceGauge-NCD-HUTDH-v20 + IP-420–424（感知层）。
> 本轮纪律：**证书要证明「动态可行」，迁移要证明「间隙可控」**。不推倒 v20：PCA/CTS/CFC/HPC/CFCtrl 与 v17–v19 全部保留。本轮只做一件事：**把 v20 的「静态零碰撞证书」升级为「双足动态可行 + 可迁移」的证书，并把 sim-to-real 间隙作为一等公民纳入证书的保守性证明**。

## 0. 直觉与动机

**灵感 1（双足机器人 → 安全不是「不碰」，而是「该碰的碰对」）**
直觉：对轮式底盘/机械臂，安全≈零碰撞；但对双足机器人，**脚必须碰地**，且必须碰在支撑多边形内、落在摩擦锥内、产生可行接触力。一个「零碰撞」的计划可能根本站不住。v20 的 CCV 把所有几何都当障碍，会**把地面/支撑面误判为碰撞**，或把「脚底接触」当成风险。核心创新：**接触感知碰撞证书 (Contact-Aware Collision Certificate, CACC)**。把接触分成**支撑接触 / 操作接触 / 禁止接触**三类，未分类接触一律按禁止处理；支撑接触必须通过**接触力锥 (CWC)** 与**摩擦锥**验证。关键反直觉点：**双足安全证书的保守性应加在「接触模式切换」上，而不是加在「静态离障距离」上**——sim-to-real 的误差恰恰在接触瞬间最大。

**灵感 2（仿真到现实迁移 → 证书的可迁移性本身必须被证明）**
直觉：仿真里证明的证书，是关于「仿真器」的定理，不是关于「真实机器人」的定理。摩擦、执行器延迟、关节柔顺、负载、地形高度都会让证书失效。与其追求「更准的仿真器」，不如承认间隙存在并**给间隙一个分布无关的界**。核心创新：**现实间隙包络 (Reality-Gap Envelope, RGE)**：用少量 sim-real 配对轨迹做**保形预测 (conformal prediction)**，得到以高概率包含真实参数的包络 Δ_α；再用**鲁棒迁移证书编译器 (Robust Transfer Certificate Compiler, RTC)** 把仿真证书编译成「∀δ∈Δ_α 都成立」的证书。关键反直觉点：**sim-to-real 迁移不是把仿真做得更像现实，而是把证书做得对残余间隙不敏感**——一个有界间隙下的鲁棒证书，比一个更精确但间隙无界的仿真更可信。

**灵感 3（两者的统一 → 证书是「接触 × 间隙」的收缩算子）**
直觉：双足机器人的安全 = 碰撞安全（不该碰的不碰）× 动态可行（该碰的碰对）× 迁移可信（间隙有界）。三者不是并列检查，而应合成为一个**单调收缩算子**：CACC 收缩禁止接触集，DFC 收缩动态可行域，RGE/RTC 按间隙半径膨胀保守边界再收缩执行域。核心创新：**双足迁移证书 (Bipedal Transfer Certificate, BTC)**，把三类证据编码为同一张可审计证书，并要求 `Exec_v21 ⊆ Exec_v20`。关键反直觉点：**间隙越大，证书越「窄」而不是越「松」**——包络越宽，鲁棒收缩越强，活性下降但安全性单调不降。

## 1. 研究问题（轮次升级版）

- **Q1（接触分类与 CWC）**：如何定义接触分类器，使「脚底支撑」被放行而「膝/肘擦地」被拒绝？支撑接触的 CWC 可行性如何在**参数域**上被证书化，而不是逐帧数值检查？接触模式切换时如何给出保守的「切换间隙」？

- **Q2（动态可行证书 DFC）**：如何把 capture point / ZMP / 接触力锥可行性写成一个**可判定的参数域约束**？在线性倒立摆近似失效（大扰动、双支撑、手接触）时如何退化而不产生假阳性？DFC 的 witness（可行的接触力轨迹）如何作为可审计证明的一部分？

- **Q3（现实间隙包络 RGE）**：如何选择 sim-real 校准轨迹，使保形预测的包络既不过宽（活性损失）也不过窄（安全失效）？间隙在部署中漂移（地形/负载/磨损）时，在线保形如何保持有效性？多参数（摩擦、延迟、柔顺）的联合包络如何避免维数灾难？

- **Q4（鲁棒迁移 RTC 与回退）**：如何用安全谓词对间隙参数的 Lipschitz 常数把仿真余量膨胀为真实余量？当包络不可用/漂移检测触发时如何回退到 v20？如何保证 `Exec_v21 ⊆ Exec_v20` 在证书组合下严格成立？

## 2. 设计原则（在 P31–P33 基础上新增 P34–P36）

**P34 接触分类保守律（Contact Taxonomy Conservatism）**
每个接触必须被显式分类为 `C_support / C_manip / C_forbidden`；未分类接触默认 `C_forbidden`。`C_support` 仅在同时满足 (a) 接触点在支撑多边形内，(b) 接触力 ∈ 摩擦锥，(c) 接触力 ∈ CWC 时被放行。**证书只能「移除」有正面证据的禁止接触，不能「新增」支撑接触**。接触模式切换点必须保留 `margin_switch` 的保守间隙。

**P35 现实间隙包络律（Reality-Gap Envelope Conservatism）**
仿真证书只有在存在有界包络 Δ_α（保形覆盖概率 ≥ 1-α，且在留出校准集上复核）时才可迁移。包络按参数维度给出（μ, τ_act, k_c, m_p, h_t, b_s），联合覆盖用 Bonferroni 或椭球保形。**包络无界、校准样本不足、或漂移检测触发 ⇒ 拒绝迁移**。

**P36 鲁棒迁移收缩律（Robust Transfer Contraction）**
对安全谓词 φ（最小离障距离、capture point 余量、摩擦余量）取其对 δ 的 Lipschitz 常数 `L_φ`；真实余量满足 `m_real ≥ m_sim - L_φ·r_α`。因此要求 `m_sim ≥ L_φ·r_α + margin_col`。RTC 只能收缩域：`Exec_v21 = Exec_v20 ∩ RobustDomain(Δ_α) ⊆ Exec_v20`。任一组件失效 ⇒ 回退 v20；v20 再失效 ⇒ v19。

## 3. 与基线的接口（如何退化）

- CACC 失效（接触模型缺失）⇒ 只接受静态零碰撞域 ⇒ 等价 v20（更保守）；
- DFC 失效（无 CWC/动力学模型）⇒ 退化为准静态支撑多边形检查 ⇒ 等价 v20 的静态域；
- RGE 无界/校准不足 ⇒ 不迁移，只用仿真内证书 ⇒ 等价 v20（在仿真域内）；
- RTC 无法给出 Lipschitz 界 ⇒ 用最坏情况常数（极大保守）或拒绝；
- 全失效 ⇒ 完全回退 v20 ⇒ 等价 v19；
- **安全继承**：`Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19`（引理 162）。

## 4. 预期贡献

1. **接触即安全前提**：首次把双足「支撑接触」纳入碰撞证书，用 CACC 的接触三分类 + CWC/摩擦锥可行性，填补「零碰撞 ≠ 站得住」的鸿沟；
2. **可迁移性可证明**：首次把 sim-to-real 间隙写成证书的显式保守项，RGE 的分布无关包络 + RTC 的 Lipschitz 余量膨胀，使「证书可迁移」成为可证明命题；
3. **统一收缩算子**：CACC × DFC × RTC 合成为单调收缩算子，配合可审计 BTC 证书，`Exec_v21 ⊆ Exec_v20`；
4. **漂移下的在线校准**：在线保形 + 漂移检测 + 回退，使间隙随时间演化时安全边界仍可验证；
5. **双足基准**：给出双足行走/搬运的端到端 sim-to-real 基准与消融，量化「动态可行 + 可迁移」的收益。

## 5. 本轮最大风险

**一句话**：RGE 的保形保证是**边际（marginal）**而非**条件（conditional）**的——它保证「平均意义上」真实参数落在包络内，却无法保证在**最危险的尾部接触场景**（新地形、湿滑、负载突变）落在包络内；一旦部署分布漂移，证书可能在「统计上合规」的前提下恰好在致命接触处失效，即**平均安全下的尾部失效**。

```python
# IP-425 Contact-Aware Collision Certificate
class ContactAwareCollisionCertificate:
    def __init__(self, ccv, taxonomy, mu_min=0.4, margin_switch=0.01):
        self.ccv = ccv                    # 复用 v20 CCV 做非接触几何
        self.taxonomy = taxonomy          # 接触分类器（几何 + 运动学先验）
        self.mu_min = mu_min
        self.margin_switch = margin_switch

    def classify(self, plan, robot_state):
        """把每个接触显式分到 支撑/操作/禁止；未分类一律并入禁止。"""
        raw = self.taxonomy.propose(plan, robot_state)
        out = {"support": [], "manip": [], "forbidden": [], "unclassified": []}
        for c in raw:
            label = self.taxonomy.label(c)   # None 表示无把握
            out[label if label is not None else "unclassified"].append(c)
        out["forbidden"].extend(out["unclassified"])
        return out

    def certify(self, plan, contacts, gap_env):
        # 1. 禁止接触：任一段出现即拒绝（不可被其他证据抵消）
        if contacts["forbidden"]:
            return CACCResult(False, reason="FORBIDDEN_CONTACT")

        # 2. 支撑/操作接触：摩擦锥 + CWC（用间隙下界 μ_min - r_α(μ)）
        mu_worst = self.mu_min - gap_env.radius("mu")
        for c in contacts["support"] + contacts["manip"]:
            if not self.within_friction_cone(c, mu_worst):
                return CACCResult(False, reason="FRICTION")
            if not self.cwc_feasible(c):
                return CACCResult(False, reason="CWC")

        # 3. 接触模式切换间隙：按地形高度不确定性膨胀
        for k in range(len(plan.segments) - 1):
            need = self.margin_switch + gap_env.radius("h_t")
            if not self.switch_gap_ok(plan, k, need):
                return CACCResult(False, reason="SWITCH_GAP")

        # 4. 非接触几何复用 v20 CCV（只能收紧，不能放宽）
        return self.ccv.certify(plan, contacts["forbidden"])

    def within_friction_cone(self, contact, mu):
        return norm(contact.f_t) <= mu * max(contact.f_n, 0.0)

    def cwc_feasible(self, contact):
        """用线性规划判断接触力是否落在接触力锥内。"""
        return contact.cwc_lp.is_feasible()

    def switch_gap_ok(self, plan, k, need):
        return plan.clearance_at_switch(k) >= need


# IP-426 Dynamic Feasibility Certificate
class DynamicFeasibilityCertificate:
    def __init__(self, cwc_solver, cp_margin_min=0.02):
        self.cwc_solver = cwc_solver
        self.cp_margin_min = cp_margin_min

    def certify(self, plan, contacts, gap_env):
        witness = []
        worst = float("inf")
        for phase in plan.phases:
            # 1. capture point 余量（LIPM），按执行器延迟膨胀
            S = support_polygon(phase, contacts)
            xi = capture_point(phase.state)
            m_cp = signed_distance(xi, S)
            need = self.cp_margin_min + gap_env.radius("tau_act")
            if m_cp < need:
                return DFCResult(False, reason="CAPTURE_POINT", witness=witness)
            worst = min(worst, m_cp - need)

            # 2. CWC 线性可行性：求一条可行接触力轨迹作为 witness
            w = self.cwc_solver.solve(phase, contacts)
            if w is None:
                return DFCResult(False, reason="CWC_INFEASIBLE", witness=witness)
            witness.append(PhaseWitness(phase.id, xi, S, w))

        return DFCResult(True, witness=witness, margin=worst)


# IP-427 Reality-Gap Envelope Estimator
class RealityGapEnvelopeEstimator:
    DIMS = ("mu", "tau_act", "k_c", "m_p", "h_t", "b_s")

    def __init__(self, alpha=0.05, scale=None, n_min=30):
        self.alpha = alpha
        self.scale = scale or {d: 1.0 for d in self.DIMS}
        self.n_min = n_min

    def nonconformity(self, sim, real):
        """逐维归一化残差：把不同量纲统一成可比分数。"""
        return {d: abs(sim[d] - real[d]) / self.scale[d] for d in self.DIMS}

    def calibrate(self, pairs):
        n = len(pairs)
        if n < self.n_min:
            return RealityGapEnvelope.bounded_false(n=n)

        scores = [self.nonconformity(s, r) for s, r in pairs]
        # 逐维保形分位，联合覆盖用 Bonferroni：每维 α/d
        q = min(1.0, ceil((n + 1) * (1 - self.alpha)) / n)
        q_dim = q ** (1.0 / len(self.DIMS))
        radii = {}
        for d in self.DIMS:
            vals = sorted(s[d] for s in scores)
            idx = min(len(vals) - 1, ceil(q_dim * len(vals)) - 1)
            radii[d] = vals[idx]

        return RealityGapEnvelope(radii=radii, coverage=1 - self.alpha, n=n)

    def update_online(self, new_pairs, window=200):
        """滑动窗口保形：只保留最近 window 个配对，适应缓慢漂移。"""
        buf = (self.buffer + new_pairs)[-window:]
        self.buffer = buf
        env = self.calibrate(buf)
        env.drift = self.drift_statistic(buf)
        return env

    def drift_statistic(self, buf):
        """前后半窗的保形半径比值：显著变大说明分布漂移。"""
        if len(buf) < 2 * self.n_min:
            return 1.0
        h = len(buf) // 2
        r_old = self.calibrate(buf[:h]).max_radius()
        r_new = self.calibrate(buf[h:]).max_radius()
        return r_new / max(r_old, 1e-9)


# IP-428 Robust Transfer Certificate Compiler
class RobustTransferCertificateCompiler:
    def __init__(self, lipschitz):
        # lipschitz: {"clearance": L_c, "cp": L_cp, "friction": L_mu}
        self.L = lipschitz

    def compile(self, sim_cert, gap_env):
        if not gap_env.bounded or gap_env.n < gap_env.n_min:
            return None, "ENVELOPE_UNBOUNDED"

        # 每个安全谓词的迁移余量 = Lipschitz × 保形半径
        m_transfer = {phi: self.L[phi] * gap_env.radius(phi)
                      for phi in ("clearance", "cp", "friction")}

        # 只能收缩：在仿真证书的域上再扣掉迁移余量
        robust = sim_cert.shrink(
            clearance=m_transfer["clearance"] + sim_cert.margin_col,
            cp=m_transfer["cp"] + sim_cert.margin_cp,
            friction=m_transfer["friction"] + sim_cert.margin_mu,
        )
        if robust.is_empty():
            return None, "ROBUST_DOMAIN_EMPTY"

        return RobustDomain(robust, m_transfer, gap_env, proof=sim_cert.proof), "OK"

# IP-430 Sim2Real Calibration Controller
class Sim2RealCalibrationController:
    def __init__(self, rge, cfctrl, ttl=30.0, drift_threshold=1.5):
        self.rge = rge
        self.cfctrl = cfctrl
        self.ttl = ttl
        self.drift_threshold = drift_threshold
        self.last_cal = 0.0

    def tick(self, t, new_pairs):
        env = self.rge.update_online(new_pairs)

        # 1. 漂移或包络无界 ⇒ 立即回退 v20（不迁移）
        if env.drift > self.drift_threshold or not env.bounded:
            return self.cfctrl.fallback("V20", reason="GAP_DRIFT")

        # 2. 超过 TTL ⇒ 主动请求校准轨迹（覆盖高风险接触模式）
        if t - self.last_cal > self.ttl:
            self.request_active_calibration(modes=["rough", "slope", "wet"])
            self.last_cal = t

        return "RTC_ACTIVE"
```

## 2. 推导（引理 157–162）

**引理 157（CACC 保守性）** 未分类接触全部并入 `C_forbidden`；`C_support/C_manip` 仅在摩擦锥与 CWC 同时可行时放行，且非接触几何仍走 v20 CCV。故 CACC 放行的接触集 ⊆ 真实允许接触集，且不会把禁止接触「升级」为支撑接触；只可能漏放，不可能误放。∎

**引理 158（DFC 可靠性）** 若 DFC 返回可行，则存在 witness 接触力轨迹 `w(t)∈CWC(σ(t))` 且 `m_cp ≥ margin_cp`，在 LIPM 近似下满足牛顿-欧拉与 capture point 约束；若不可行则拒绝。LIPM 近似失效（大扰动/多接触）时，DFC 以「无法构造 witness」返回拒绝，不产生假阳性。∎

**引理 159（RGE 覆盖性）** 在可交换性假设下，逐维保形分位给出单维覆盖 ≥ 1-α/d，Bonferroni 联合覆盖 ≥ 1-α。滑动窗口在局部可交换时保持有效；漂移破坏可交换性，由 `drift_stat` 检出并触发回退。∎

**引理 160（RTC 鲁棒性）** 设 φ 对 δ 满足 L_φ-Lipschitz，则 ∀δ∈Δ_α：`φ(π;P(δ)) ≥ φ(π;P(δ_sim)) - L_φ·‖δ-δ_sim‖ ≥ m_sim - L_φ·r_α`。令 `m_sim ≥ L_φ·r_α + margin`，得 `φ(π;P(δ)) ≥ margin`。故鲁棒域内的计划对包络内任意真实植物安全。∎

**引理 161（BTC 可审计性）** BTC 的 witness 含接触分类、CWC 的 LP 解、保形分位与 Lipschitz 膨胀参数；`merkle_root` 链式绑定每次校准与每段 witness。独立验证器可完整复算 `valid()`，无需信任生成方。∎

**引理 162（v21 整体安全继承）** `Exec_v21 = Exec_v20 ∩ CACC_pass ∩ DFC_pass ∩ RobustDomain(Δ_α)`。CACC/DFC/RTC 均为交集式收缩，且任一失效回退 v20。故 `Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。∎

## 6. 已知风险与失效模式

1. **保形保证是边际而非条件**：RGE 只保证平均覆盖，条件覆盖（尤其尾部接触）可能不足。缓解：按接触模式分层保形、尾部加保守分位、条件风险价值（CVaR）约束。
2. **可交换性被破坏**：部署分布随地形/负载/磨损漂移，滑动窗口只能缓慢适应。缓解：漂移检测 + 主动校准 + 回退 v20。
3. **Lipschitz 常数被低估**：安全谓词在接触切换附近可能高度非线性，解析界偏小导致余量不足。缓解：区间算术/自动微分给出保守上界，并用对抗扰动验证。
4. **接触分类器误判**：把擦碰误标为支撑会直接放行危险接触。缓解：未分类默认禁止、禁止接触零容忍、分类器置信度门槛。
5. **CWC/LIPM 近似失效**：大扰动、多接触、手部支撑时 LIPM 不成立。缓解：多接触 CWC、角动量判据、失效即拒绝。
6. **RGE 维数灾难**：六维联合包络在小样本下过宽。缓解：分层/分组保形、低维充分统计量、椭球参数化。
7. **证书组合的顺序依赖**：CACC/DFC/RTC 若实现为非交换收缩，可能产生不一致。缓解：统一为交集算子并做单调性测试。
8. **计算延迟**：CWC 的 LP 与在线保形可能挤占 50Hz 控制环。缓解：离线预编译、增量 LP、控制环只查缓存证书。

## 7. 本轮最大风险

**一句话**：RGE 的保形保证是**边际**而非**条件**的，且其有效性依赖可交换性；一旦真实部署在最危险的尾部接触场景发生分布漂移（新地形、湿滑、负载突变），证书会在「统计上合规」的前提下恰好在致命接触处失效——即**平均安全下的尾部失效**，而这类失效恰恰是双足机器人跌倒的主因。
