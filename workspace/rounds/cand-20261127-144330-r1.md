### 第 4 轮灵感驱动研究记录（对比实验 × 桌面操作）

**灵感词**：对比实验、桌面操作

**直觉与动机**：

前几轮把框架推到了 CADVS：证书驱动的分布式视觉伺服，证书链、时序有效性、多机一致性都已成形。但这里藏着一个被忽略的元问题：**我们凭什么相信这些证书真的有用？** 现有论证是「构造性」的——只要证书通过，就证明稳定性/一致性；但没有任何证据表明证书在真实任务分布上优于「无证书」，也没有说明收益究竟来自哪个部件。灵感词「对比实验」正击中这一软肋：证书的价值是一个**因果量**，必须用对照实验识别，而不能靠自证。

而「桌面操作」提供了理想试验场：桌面任务（抓取、放置、轴孔装配、推动、堆叠、倾倒）具有**准静态、几何可度量、失败可归因**三大特点。相比双足运动，桌面失败往往有清晰的几何/接触原因（滑移、碰撞、遮挡、超程），因此可以把「证书是否预测失败」当作可观测变量，做严格的 ROC 与消融分析。这是把 KEMPC/CADVS 从「理论自洽」推进到「经验可证」的关键一步。

核心洞见：**证书不是安全性的同义词，而是一个带代价的预测器**。每张证书都以「干预率」为代价换取「失败率」下降；只有当它预测失败的 TPR 足够高、误报 FPR 足够低、且干预代价可接受时才值得部署。于是研究问题从「证书是否保证安全」转为「在给定任务分布与代价预算下，哪组证书位于安全-效率帕累托前沿的哪个点」。

为此提出三件事：
1. **桌面证书族（TCS）**：把抓取力闭合裕度、接触力锥、工作空间/碰撞、遮挡可见性、滑移风险统一为可计算的 (pass, margin) 证书；
2. **证书操作特性（COC）与失效预测模型（CPFM）**：把证书裕度标定为失败概率，给出 TPR/FPR/AUC/校准误差；
3. **对比消融协议（CCAP）**：分层配对随机化 + 留一证书消融 + 预注册 + 序贯停止 + 反事实回放，把「证书有用」变成可重复、有置信区间的结论。

**关键洞见**：对比实验不是「跑个 baseline」，而是一种**认识论工具**——它强迫我们区分三种收益：(a) 证书真实降低失败（因果）；(b) 证书只是让任务变慢/变简单（混淆）；(c) 证书在基准上过拟合（构念效度失效）。只有「配对设计 + 留一消融 + 反事实回放」三者结合，才能把 (a) 从 (b)(c) 中分离出来。

**形式化目标（增量）**：
1. 定义桌面证书族 TCS = {GC, CCC, WSC, VOC, SLC}，每张证书输出 (pass, margin)，margin ≥ 0 ⇔ pass；
2. 定义证书操作特性 COC：TPR_i(τ), FPR_i(τ), AUC_i, 校准误差 ECE_i；
3. 定义证书价值泛函 V_i = C_fail·P(Y=1) − min_τ [C_fail·P(Y=1 ∧ ¬F_i) + C_int·P(F_i) + C_alarm·P(Y=0 ∧ F_i)]，仅当 V_i>0 部署；
4. 定义分层配对对比设计：同一 (任务, 物体, 初始位姿, 随机种子) 下比较 C0(无证书)/C1(全证书)/C2(留一证书)/C3(预言机)；
5. 定义反事实回放估计量（IPS / 双重稳健 DR），从日志估计「移除某证书」的因果效应；
6. 预注册主假设：全证书相对无证书成功率提升 ΔSR ≥ 8pp，假安全率降低 ≥ 50%，干预率 IR ≤ 15%。

**本轮最大风险**：**基准过拟合与构念效度危机**——桌面基准中的成功率/干预率只是真实部署风险的有偏代理，证书阈值在有限样本上调优后会记住基准特有的失败模式，导致对比实验显示显著收益、却在开放桌面环境中失效。

### IP-478 Tabletop Certificate Suite (TCS)

```python
from dataclasses import dataclass
import numpy as np

@dataclass
class CertResult:
    name: str
    passed: bool
    margin: float          # 归一化裕度，>=0 ⇔ pass
    detail: dict

class TabletopCertificateSuite:
    """五证统一接口：每张证书返回 (pass, margin)，margin 已归一化到 0 为边界。"""

    def __init__(self, cfg):
        self.cfg = cfg    # 阈值：eps_min, d_min, mu, tau_max, J_max, rho_max, N_min, p_max

    # GC：抓取力闭合裕度 + 质心投影裕度
    def grasp_cert(self, contacts, com_xy, support_poly) -> CertResult:
        eps = self._ferrari_canny_quality(contacts, self.cfg.mu)   # 力闭合 epsilon 质量
        d_com = self._distance_to_polygon(com_xy, support_poly)
        m_eps = eps / self.cfg.eps_min - 1.0
        m_com = d_com / self.cfg.d_min - 1.0
        m = min(m_eps, m_com)
        return CertResult('GC', m >= 0.0, m,
                          {'eps': eps, 'd_com': d_com})

    # CCC：接触力锥 / 力矩 / 冲量裕度
    def contact_cert(self, f_n, f_t, tau, impulse) -> CertResult:
        m_f = 1.0 - np.linalg.norm(f_t) / max(self.cfg.mu * f_n, 1e-9)
        m_tau = 1.0 - abs(tau) / self.cfg.tau_max
        m_J = 1.0 - impulse / self.cfg.J_max
        m = min(m_f, m_tau, m_J)
        return CertResult('CCC', m >= 0.0, m,
                          {'m_f': m_f, 'm_tau': m_tau, 'm_J': m_J})

    # WSC：碰撞距离 / 可操作度 / 关节限位裕度
    def workspace_cert(self, q, signed_dist, sigma_min, sigma_min0) -> CertResult:
        m_col = signed_dist / self.cfg.d_min - 1.0
        m_man = sigma_min / sigma_min0 - 1.0
        m_lim = self._joint_limit_margin(q)
        m = min(m_col, m_man, m_lim)
        return CertResult('WSC', m >= 0.0, m,
                          {'m_col': m_col, 'm_man': m_man, 'm_lim': m_lim})

    # VOC：遮挡比例 / 内点特征数裕度
    def visibility_cert(self, occ_ratio, n_inlier) -> CertResult:
        m_occ = (1.0 - occ_ratio) / (1.0 - self.cfg.rho_max) - 1.0
        m_feat = n_inlier / self.cfg.N_min - 1.0
        m = min(m_occ, m_feat)
        return CertResult('VOC', m >= 0.0, m,
                          {'m_occ': m_occ, 'm_feat': m_feat})

    # SLC：滑移概率裕度（触觉/力比）
    def slip_cert(self, phi_tactile) -> CertResult:
        p_slip = 1.0 / (1.0 + np.exp(-(self.cfg.w @ phi_tactile + self.cfg.b)))
        m = (self.cfg.p_max - p_slip) / self.cfg.p_max
        return CertResult('SLC', m >= 0.0, m, {'p_slip': p_slip})

    def evaluate(self, obs) -> dict[str, CertResult]:
        return {
            'GC':  self.grasp_cert(obs.contacts, obs.com_xy, obs.support_poly),
            'CCC': self.contact_cert(obs.f_n, obs.f_t, obs.tau, obs.impulse),
            'WSC': self.workspace_cert(obs.q, obs.signed_dist,
                                       obs.sigma_min, obs.sigma_min0),
            'VOC': self.visibility_cert(obs.occ_ratio, obs.n_inlier),
            'SLC': self.slip_cert(obs.phi_tactile),
        }
```

### IP-479 Certificate Operating Characteristic & Failure Predictor (COC-CPFM)

```python
class CertificateFailurePredictor:
    """把证书裕度标定为失败风险 h_i(m)，并给出 ROC / 校准 / 最优门控阈值。"""

    def fit(self, margins: dict[str, np.ndarray], y: np.ndarray):
        # 单调非增约束：裕度越大，失败概率越低
        self.h = {}
        for name, m in margins.items():
            self.h[name] = IsotonicRegression(increasing=False, out_of_bounds='clip').fit(m, y)

    def hazard(self, name, m):
        return float(self.h[name].predict([m])[0])

    def roc(self, name, margins, y, grid=np.linspace(-1, 3, 81)):
        tpr, fpr = [], []
        for tau in grid:
            fail = margins[name] < tau
            tpr.append(((fail) & (y == 1)).sum() / max((y == 1).sum(), 1))
            fpr.append(((fail) & (y == 0)).sum() / max((y == 0).sum(), 1))
        return np.array(tpr), np.array(fpr)

    def ece(self, name, margins, y, n_bins=10):
        p = self.h[name].predict(margins[name])
        edges = np.quantile(p, np.linspace(0, 1, n_bins + 1))
        ece = 0.0
        for lo, hi in zip(edges[:-1], edges[1:]):
            sel = (p >= lo) & (p <= hi)
            if sel.sum() == 0:
                continue
            ece += sel.mean() * abs(y[sel].mean() - p[sel].mean())
        return float(ece)

    def optimal_threshold(self, name, margins, y, cost):
        # 最小化期望总代价：漏检失败 + 干预 + 误报
        grid = np.linspace(-1, 3, 161)
        best_tau, best_cost = None, np.inf
        for tau in grid:
            fail = margins[name] < tau
            c = (cost.C_fail * ((~fail) & (y == 1)).mean()
                 + cost.C_int * fail.mean()
                 + cost.C_alarm * (fail & (y == 0)).mean())
            if c < best_cost:
                best_cost, best_tau = c, tau
        return best_tau, best_cost

    def certificate_value(self, name, margins, y, cost):
        tau, cost_at_tau = self.optimal_threshold(name, margins, y, cost)
        cost_no_cert = cost.C_fail * (y == 1).mean()
        return cost_no_cert - cost_at_tau, tau     # V_i > 0 才部署
```

### IP-480 Comparative Certificate Ablation Protocol (CCAP)

```python
class ComparativeCertificateAblationProtocol:
    """分层配对随机化 + 留一消融 + 预注册 + 序贯停止。"""

    def __init__(self, tasks, objects, seeds, conditions, alpha=0.05, power=0.8):
        self.blocks = [(t, d, o, s)
                       for t in tasks
                       for d in ('easy', 'medium', 'hard')
                       for o in objects
                       for s in seeds]
        self.conditions = conditions   # ['C0', 'C1', 'C2_GC', ..., 'C3']
        self.alpha, self.power = alpha, power

    def required_blocks(self, sigma_d, delta, z_a=1.96, z_b=0.84):
        # 配对差值设计：n = (z_{1-a/2}+z_{1-b})^2 * sigma_d^2 / delta^2
        return int(np.ceil((z_a + z_b) ** 2 * sigma_d ** 2 / delta ** 2))

    def run_block(self, block, env, policy):
        """同一 block 内跑全部条件；条件顺序用 Williams 拉丁方平衡以消携带效应。"""
        order = self._williams_order(self.conditions, block)
        results = {}
        for cond in order:
            env.reset(seed=block.seed, task=block.task,
                      obj=block.obj, q0=block.q0)
            results[cond] = policy.rollout(env, condition=cond,
                                           certs=self._certs_for(cond))
            env.washout(steps=10)          # 条件间重置，抑制携带效应
        return results

    def paired_effects(self, results):
        """C1 vs C0 的配对成功率差 + 配对 bootstrap 置信区间。"""
        y1 = np.array([r['C1'].failure for r in results])
        y0 = np.array([r['C0'].failure for r in results])
        d = y0 - y1                       # 正=证书降低失败
        boot = [np.mean(np.random.choice(d, len(d), replace=True))
                for _ in range(10000)]
        return {'delta_sr': d.mean(),
                'ci95': (np.percentile(boot, 2.5), np.percentile(boot, 97.5)),
                'wilcoxon_p': wilcoxon(d, alternative='greater').pvalue}

    def leave_one_out(self, results):
        """留一消融：ΔSR_{-i} = SR(C1) − SR(C1 \\ c_i)，Holm 校正。"""
        base = np.array([r['C1'].success for r in results])
        out = {}
        for c in self.certs:
            ablated = np.array([r[f'C2_{c}'].success for r in results])
            out[c] = (base - ablated).mean()
        return holm_correction(out, alpha=self.alpha)

    def sprt(self, deltas, delta0=0.02, delta1=0.08):
        """序贯概率比检验：H0 Δ≤delta0 vs H1 Δ≥delta1，可提前停止。"""
        llr = 0.0
        for x in deltas:
            llr += np.log(self._f1(x) / self._f0(x))
            if llr >= np.log((1 - self.alpha) / (1 - self.power)):
                return 'accept_H1', llr
            if llr <= np.log(self.power / (1 - self.alpha)):
                return 'accept_H0', llr
        return 'continue', llr
```

### IP-481 Counterfactual Certificate Replay (CCR)

```python
class CounterfactualCertificateReplay:
    """从全证书行为策略日志估计『移除某证书』的因果效应。"""

    def __init__(self, clip=10.0):
        self.clip = clip

    def estimate(self, log, target_policy):
        # log: [(s, a, behavior_prob, cert_mask, reward, done)]
        ratios, rewards = [], []
        for s, a, pb, cert_mask, r, done in log:
            pa = target_policy.prob(a, s, cert_mask)
            rho = min(pa / max(pb, 1e-9), self.clip)
            ratios.append(rho)
            rewards.append(r)
        rho = np.array(ratios)
        ess = rho.sum() ** 2 / max((rho ** 2).sum(), 1e-9)   # 有效样本量
        v_ips = float((rho * np.array(rewards)).mean())
        return {'v_ips': v_ips, 'ess': ess,
                'shift_warning': ess < 0.1 * len(log)}

    def doubly_robust(self, log, q_model, target_policy):
        vals = []
        for s, a, pb, cert_mask, r, done in log:
            pa = target_policy.prob(a, s, cert_mask)
            rho = min(pa / max(pb, 1e-9), self.clip)
            v_hat = q_model(s, a)
            vals.append(v_hat + rho * (r - v_hat))
        return float(np.mean(vals))
```

### IP-482 Safety-Efficiency Pareto Router (SEPR)

```python
class SafetyEfficiencyParetoRouter:
    """按剩余风险预算选择证书子集，贪心逼近安全-效率帕累托前沿。"""

    def select(self, certs: dict[str, CertResult], values: dict[str, float],
               costs: dict[str, float], budget: float):
        candidates = [(n, values[n] / max(costs[n], 1e-9))
                      for n in certs if values[n] > 0]
        candidates.sort(key=lambda x: x[1], reverse=True)
        chosen, spent = [], 0.0
        for name, _ in candidates:
            if spent + costs[name] <= budget:
                chosen.append(name)
                spent += costs[name]
        # 已失败且高价值的证书强制纳入（不可被预算裁掉）
        forced = [n for n, c in certs.items() if not c.passed and values[n] > 0]
        return sorted(set(chosen) | set(forced))
```

## 3. 对比实验设计（核心贡献）

### 3.1 任务与分层

| 维度 | 取值 | 说明 |
|---|---|---|
| 任务 𝒯 | pick, place, peg-in-hole, push, stack, pour | 覆盖自由空间、接触、装配、准静态流动 |
| 难度 d | easy / medium / hard | 按容差、遮挡、摩擦不确定性、初始位姿偏移划分 |
| 物体 𝒪 | 5 类（刚性盒、圆柱、软袋、细长杆、易碎杯） | 覆盖抓取/滑移/碰撞失效模式 |
| 种子 𝒮 | 20 | 固定随机种子，保证条件间同分布 |
| 初始位姿 q₀ | 每块随机但条件间共享 | 配对设计的核心 |

### 3.2 实验条件（同块内配对）

| 条件 | 含义 | 作用 |
|---|---|---|
| C0 | 无证书门控（固定控制器） | 下界基线 |
| C1 | 全 TCS + 十二证 | 主张方案 |
| C2_i | 留一证书 c_i（其余全开） | 消融，估计边际贡献 |
| C3 | 预言机（用真实失败标签干预） | 上界，衡量证书与理想差距 |

条件顺序用 Williams 拉丁方平衡；条件间 `washout(steps=10)` 重置场景与控制器积分项，抑制携带效应。

### 3.3 指标定义

| 指标 | 定义 | 方向 |
|---|---|---|
| SR | 成功率 1 − P(Y=1) | ↑ |
| ΔSR | SR(C1) − SR(C0)，主终点 | ↑ |
| FSR | 假安全率 P(Y=1 \| 全证书通过) | ↓ |
| IR | 干预率 P(∃ c_i 触发) | ↓（约束） |
| TTC | 任务完成时间（含重试） | ↓ |
| RSR | 干预后恢复成功率 | ↑ |
| AUC_i / ECE_i | 单证书失败预测判别力 / 校准 | ↑ / ↓ |
| ΔSR_{-i} | 留一消融边际贡献 | ↑ |

### 3.4 统计与功效

- **配对差值**：Δ̂ = mean(Y^{C0} − Y^{C1})；配对 bootstrap（10,000 次）给 95% CI；Wilcoxon 符号秩检验（单侧）。
- **方差缩减**：Var(Δ̂) = (σ₁² + σ₀² − 2ρσ₁σ₀)/n；块内相关 ρ 越大，配对越省样本。
- **功效**：取 σ_d = 0.35、Δ = 0.08、α = 0.05、power = 0.8 ⇒ n ≈ ⌈(1.96+0.84)²·0.35²/0.08²⌉ ≈ 150 块/条件；本设计 6×3×5×20 = 1800 块，冗余充足。
- **多重比较**：5 个留一消融用 Holm–Bonferroni 校正。
- **预注册**：主终点（hard 层 ΔSR ≥ 8pp）与全部阈值（ε_min、μ、ρ_max 等）在 test 集开启前冻结；按 60/40 划分 dev/test，仅 dev 调参。
- **序贯停止**：4 次中期分析，O'Brien–Fleming α 消耗；或 SPRT（H0: Δ≤0.02 vs H1: Δ≥0.08）。

### 3.5 反事实回放（离线因果）

用 C1 全证书日志，估计「移除 c_i」的反事实失败率。采用 IPS 与双重稳健（DR）估计，importance ratio 截断到 10；以 ESS ≥ 0.1n 作为可信门槛，否则判定分布偏移、拒绝该反事实结论。

### 3.6 防混淆检查清单

1. **标签泄漏**：C3 的失败标签绝不能进入任何证书特征或路由特征；
2. **顺序效应**：拉丁方平衡 + washout + 分析时把 order 作为协变量；
3. **调参泄漏**：阈值只在 dev 冻结，test 一次性评估；
4. **成功定义一致**：所有条件用同一自动判定器，判定器对条件盲；
5. **失败归因盲评**：人工归因标注者对条件盲，计算 Cohen's κ 一致性。

## 5. 正确性 / 有效性论证

### 命题 33（单调门控的安全-效率权衡）

**陈述**：若失效风险 h_i(m) 关于 m 单调非增（isotonic 标定成立），则对 τ₁ < τ₂：
FSR(τ₂) ≤ FSR(τ₁)，且 IR(τ₂) ≥ IR(τ₁)。

**证明**：FSR(τ) = P(Y=1 | m ≥ τ) = E[h_i(m) | m ≥ τ]。τ₂ > τ₁ 把条件期望限制到更高的 m 区间；由 h_i 单调非增，该区间上的条件期望不增。IR(τ) = P(m < τ) 随 τ 单调增。∎

**工程含义**：帕累托前沿可由单参数 τ 扫描得到；CPFM 的单调性假设是前沿凸性的前提，若标定非单调（样本噪声），需用保序回归强制单调并报告违反率。

### 命题 34（配对差值估计的无偏性与方差缩减）

**陈述**：在 SUTVA、一致性、无携带效应（washout 充分）且条件顺序随机化下，配对估计 Δ̂ = (1/n)Σ(Y_b^{C0} − Y_b^{C1}) 是块总体平均处理效应（ATE）的无偏估计；其方差为 (σ₁² + σ₀² − 2ρσ₁σ₀)/n。

**证明**：每个块内两条件作用于同一 (τ,o,s,q₀)，块级差值期望等于该块处理效应；对块随机抽样即得 ATE 无偏性。方差按差值随机变量展开即得，其中 ρ 为块内两条件结果的相关系数。∎

**诚实声明**：无携带效应是理想化假设。桌面操作中抓取策略可能改变物体位姿，使后续条件并非从同一 q₀ 开始；washout 只能部分缓解。因此协议要求每个条件独立重置场景（不只是控制器），并在分析中报告 order 效应是否显著。

### 命题 35（留一消融的次可加性）

**陈述**：若各证书触发的干预集合互不重叠，则 ΔSR(C1 vs C0) = Σ_i ΔSR_{-i}（可加）；一般情况下因干预重叠，有 ΔSR(C1 vs C0) ≤ Σ_i ΔSR_{-i}（次可加）。

**证明**：可加情形下每次干预独立贡献边际收益，直接相加。重叠时同一失败被多张证书同时拦截，单独移除任一张仍可能被其余证书拦截，故单证边际贡献之和会重复计数同一收益，超过联合收益。∎

**工程含义**：不能把留一消融简单相加当作联合贡献；需同时报告边际贡献与 Shapley 值（对 |C|=5 可精确枚举 2⁵ 个联盟）。

## 8. 本轮最大风险（最终确认）

**一句话**：**基准过拟合与构念效度危机**——桌面基准的成功率/干预率只是真实部署风险的有偏代理，证书阈值在有限样本上调优后会记住基准特有的失败模式，使对比实验显示显著收益、却在开放桌面环境中失效；这是「用实验证明证书有用」这一路线本身的**认识论生死线**，只能靠预注册、dev/test 隔离、分布外扰动与 Shapley 分解来压缩，而无法消除。
