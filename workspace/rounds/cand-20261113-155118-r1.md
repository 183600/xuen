# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因」IP-214~223；灵感循环第 1 轮；本轮灵感：「视觉编码器」×「语音识别」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险一针见血：**归因依赖"故障属于有限假设集 + 视觉与几何失效相互独立"；真实故障常是未知类型的组合，透明/镜面/对抗 patch 又让视觉与几何共享同一个分布外失效源，于是 FIR 把未知复合故障强行归入最近假设、只膨胀错误的球，而系统因"已经归因"更自信地继续执行。** 本轮不再补第 7 个假设，也不满足于"可观测/不可观测"的二分，而是换一个更根本的类比：第 65 轮的 FIR 本质上是"**1-best、无置信度、无时序对齐、不支持拒识、闭词表**"的分类器；而语音识别几十年来的核心工作，恰好就是把**变长、带噪、时序错位、含未知词的信号**解码成离散事件序列，并且明确知道**何时该说"听不清"而不是硬猜一个词**。本轮核心命题是：
>
> **把「故障分类」升级为「故障序列的流式解码」：用视觉编码器的 token 级等变表征提供可对齐的细粒度证据，用 CTC 的对齐自由性消除阶段切分的脆弱，用假设格 / N-best / 全量重打分 / 子词组合 / 拒识把"一次性 argmax"变成"部分假设 + 重打分 + 显式拒识"，并用"故障文法"约束因果可行的故障叙事。**

## 0. 直觉与动机

**灵感 1（视觉编码器 → 从"检测框/标量"到"token 级、等变、可线性探测"的表征）**
直觉：第 65 轮的视觉证据是 2D 语义检测（接触斑中心、面积、法向、形变嵌入），它的信息密度低、且与"几何先验"高度共享失效结构。现代视觉编码器（ViT/DINO/MAE/CLIP 类）提供的是**稠密 patch token**：同一套特征天然带出局部对应、部件原语与多尺度结构，可作为视觉与力残差在时间轴上对齐的"帧级特征"。但这里有一个**必须点破的反直觉陷阱**：绝大多数视觉编码器被训练成对位姿、尺度、光照**不变**，而这些恰恰是故障诊断最需要的**敏感方向**——一个对故障方向不变的编码器会让故障在特征空间里**不可观测**（本轮将给出引理）。因此 TGE 要的不是"更强的语义识别"，而是**任务接地的等变表征**：保留 SE(3)/尺度信息、用 register token 抑制高范数伪影 token、用冻结编码器 + 轻量线性探针给出**可校准**的每事件 logit、再用编码器特征空间的**时间残差**（而非像素差）检测接触/滑移的起始。诚实边界：特征坍缩、伪影 token、对抗 patch、完全 OOD 物体仍会让它失效，故必须输出 `feature_unobservable`，它只是**一条可错证据**，不是真值。

**灵感 2（语音识别 → 对齐自由的事件解码，替掉脆弱的阶段切分）**
直觉：第 65 轮把块硬切成 approach / touch / load 三段，并聚合成 15 维签名。这一步有两个致命脆弱点：(i) 切分依赖接触状态与力阈值，边界模糊会**污染零力窗**，而零力窗正是区分"力偏置 vs 几何幻觉"的唯一证据；(ii) 故障事件可能**跨阶段、重复出现或顺序颠倒**，固定分段无法表达。语音识别处理的是同一类问题：音频帧与词之间没有逐帧标签、时长可变、还有静音与噪声。CTC 的解法是引入 **blank** 并**对所有合法对齐求边缘**——不需要先切分，就能得到序列似然。ECHO 把残差流 `r_t` 当"声学帧"，把故障事件（接触建立/滑移/力阶跃/模型偏离/几何冲突/策略偏移…）当"词"，用 CTC 式解码器直接输出**事件序列**。**阶段不再是输入，而是解码结果的副产品**：先解码事件，再由此派生阶段，从根本上消除"切分错误 → 归因错误"的传导链。

**灵感 3（语音识别 → 假设格、N-best、重打分、拒识、上下文偏置与同音词）**
直觉：第 65 轮的 `argmax_H P(H|ρ)` 等价于语音里的"**1-best 解码且没有置信度**"，它的全部风险都来自把"最高分"当"正确"。语音识别的成熟答案是：(i) 保留 **N-best / 混淆网络（lattice）**，而不是只留一条路径；(ii) **流式部分假设 + 全量重打分**，先低延迟给出临时结论，再用更多上下文修正；(iii) **置信度校准与拒识**，OOV/噪声必须能被判为"不知道"；(iv) 对关键命令用**关键词唤醒（KWS）**，以极低误唤醒率单独兜底；(v) 用**上下文偏置（shallow fusion）**把"当前场景下物理上可能出现的故障"作为先验注入，而不重训模型；(vi) 用 **WFST 文法**约束因果合理的故障顺序。最深刻的类比是**同音词（homophone）**：两个不同故障若在当前轨迹上产生完全相同的残差分布，就在信息论上不可分；上下文先验只有在**先验本身不同**时才能打破平局，先验错了就会**幻觉出一个最"像话"的故障**。这正是第 65 轮"共因故障"的严格形式化，也给出了"何时该拒识"的判据。

**灵感 4（三灵感合流 → ECHO：Event-Centric Hypothesis-lattice Online diagnosis，事件中心假设格在线诊断）**
闭环：视觉编码器 token 证据（TGE）→ 残差帧嵌入 → CTC 事件解码（CTC-ED）→ 故障 WFST 文法解码（F-WFST）→ 故障假设格与置信度（FHL）→ 上下文偏置与全量重打分（CBA/RRS）→ 故障活动检测与拒识/关键词兜底（FAD/REJ/KWS）→ 解码事件驱动的定向处置（RSC-L）→ **在假设格上按概率质量**认证执行前缀（LSC）→ 块级文法规划（CSP-L）→ 对抗与自适应（AIC-E/ADP）→ 证书 J_echo。ECHO 的三层对齐关系是：**表征层**（视觉 token ↔ 声学帧）、**解码层**（CTC/WFST ↔ 故障事件句）、**决策层**（假设格质量 ↔ 安全认证的积分域）。一句话：**不再问"是 6 类里的哪一类"，而问"在全部高概率的故障叙事里，我最多还能安全走几步"**。

**灵感 5（VISTA 组件的原位升级）**
- **VPG → TGE-VPG**：从标量视觉残差升级为 token 级、等变、可线性探测的特征残差；输出 `feature_unobservable` 与每事件 logit。
- **FIR → CTC-ED + F-WFST + FHL**：从 15 维签名分类升级为对齐自由的事件序列解码、文法约束与 N-best 假设格；支持子词组合未知故障。
- **阶段切分（Stage）→ FAD 事件端点检测**：阶段由解码事件派生，不再先验硬切；引入迟滞与活动检测防止事件混叠。
- **AFA → AMB（Active Margin Boosting）**：探针目标从"故障假设互信息"改为"**提升假设格的最小间隔 / 降低格上歧义质量**"，把"分清楚谁坏了"变成"把第二名彻底压下去或确认压不下去"。
- **CSC → LSC**：认证域从 top-2 假设改为**按概率质量剪枝的假设格**，风险上界由被剪枝质量显式给出。
- **RSC-V → RSC-L / WCV-V → WCV-L**：不确定膨胀按格上后验质量加权，只膨胀高概率事件对应的通道；搜索域对格做边缘化 CVaR。
- **CSP-V → CSP-L**：块级规划以"格状态"为节点、以故障文法为可行性约束，代价含格熵与未覆盖质量。
- **AIC-V → AIC-E**：干扰集增同音别名故障、时间伸缩/延迟、域漂移、编码器对抗 patch 与共因；认证不要求归因正确，只要求"高概率格路径"都不越界。
- **J_vista → J_echo**：证书增 `lattice_mass`、`tail_mass`、`top1_conf`、`reject/OOV`、`feature_unobservable`、`grammar_ver`、`encoder_ver`。

## 1. 形式化定义（增量：定义 233–252）

- **定义 233（ECHO 闭环）**：ECHO = (VISTA, TGE, CTC-ED, F-WFST, FHL, CBA, RRS, FAD, REJ/KWS, LSC, RSC-L, WCV-L, CSP-L, AIC-E, ADP, J_echo)。定位：VISTA 的"序列解码 + 表征接地 + 拒识"升级。不变式：**编码器推理、CTC/WFST 解码、重打分、文法学习、自适应、证书只在语义流；实时流只做帧级特征/残差采集、前向 beam、端点判定、前缀执行与早停，零学习写操作。**
- **定义 234（任务接地等变视觉编码器 TGE）**：编码器 f_enc 把图像 I_t 映射为多尺度 token 特征 Z_t={z_{t,k}}∈ℝ^{K×d} 与寄存器 token z_reg；要求对任务相关群 G（SE(3) 子群、尺度）**等变**而非不变：f_enc(g·I)=ρ(g)f_enc(I)。任务观测量 y_t 由 token 上的线性探针 P_τ(z_{t,k}) 得到（位姿/接触斑/形变/可动部件），并给每事件校准 logit。特征时间残差 e_feat(t)=‖Z_t−ŵ(Z_{t−1},a_{t−1})‖²_{Σ_z⁻¹}，用于接触建立/滑移的细粒度起始检测。`feature_unobservable` 当且仅当探针置信度低于 q_probe(α) 或检测到特征坍缩/伪影主导。
- **定义 235（故障事件词表与子词原语）**：事件词表 ℰ=ℰ_prim ∪ {blank}，原语 ℰ_prim={contact_make, contact_break, slip_onset, force_step, force_drift, geo_conflict, model_dev, vis_conflict, policy_dev, jam, …}。为支持未知复合故障，引入**子词式原语分解**：任何故障叙事是 ℰ_prim 上的序列；未知故障可被解码为已知原语的**新组合**，而不是被塞进最近的整类。帧嵌入 o_t=ϕ([r_t; vec_pool(Z_t)]), r_t 为 VISTA 的 [e_vis,e_force,e_torque,d_chunk,u_chunk]。
- **定义 236（CTC 事件解码器 CTC-ED）**：帧后验 y_t^e=softmax(W o_t+b)_e。路径 π∈ℰ^T，折叠算子 B 先合并相邻重复再去 blank。序列似然
  p(ℓ|o_{1:T})=Σ_{π:B(π)=ℓ} ∏_{t=1}^T y_t^{π_t}，
  用前向-后向精确计算，并得到每个事件的**对齐占据** γ_t(e) 与时间区间。CTC 把"何时开始/持续多久/有无静默"边缘化掉，故对时间抖动、延迟、事件跨阶段与重复出现**天然鲁棒**；阶段 P={approach,touch,load} 由解码事件序列实时派生，而非解码输入。
- **定义 237（故障文法 WFST）**：把"词法 L（子词→事件）+ 物理/因果文法 G（如 model_dev 仅在 load 后、force_drift 需先有 force_step、slip 需先 contact_make）+ 先验 P"合成为 F=T∘L∘G∘P（T 为 CTC 拓扑）。解码为在 F 上的最短路径/beam 搜索。G 是**软约束**（带代价），避免把未知但物理可行的序列直接判死；文法可离线从成功/失败 episode 学习并与手写物理规则混合。
- **定义 238（故障假设格 FHL）**：由 WFST 搜索得到带后验的 DAG/混淆网络，弧 a=(e,[t1,t2],p_a)。格上路径 ℓ 的后验 p(ℓ|o)∝p(o|ℓ)p(ℓ)。定义 top-k 质量 M_k、尾部质量 Tail(τ)=Σ_{ℓ:p(ℓ)<τ}p(ℓ)、混淆度 H_lat=−Σ_a p_a log p_a、最小间隔 margin=p(ℓ1)−p(ℓ2)。**FHL 取代 argmax：诊断输出是"带质量的路径集合"，不是单个标签。**
- **定义 239（故障活动检测 FAD / 端点）**：类似 VAD，检测故障 episode 的起止（残差能量+事件后验的迟滞阈值），避免把两次独立事件混成一个签名；FAD 在实时流只做 O(1) 门控。
- **定义 240（置信度、拒识与关键词兜底）**：对 top-1 输出经温度/保形校准的置信度 c_top；OOV 分数 ρ_oov 由子词重组惩罚与帧级新颖度给出；拒识域 {c_top<1−δ_rej ∨ ρ_oov>q_oov(α)} → 输出 `unknown_fault`/`ambiguous`，**禁止 argmax**。对少数致命故障（碰撞、过力、失稳）训练独立 KWS 头，以严格误报率 FAR≤α_kws 单独兜底，不参与开放词表竞争。
- **定义 241（上下文偏置 CBA / shallow fusion）**：给定技能 σ、物体类别与工位，上下文先验 p_ctx(ℓ|σ,obj)。偏置打分
  log p_b(ℓ|o)=log p(ℓ|o)+λ·log p_ctx(ℓ|σ,obj)−μ·log p_neg(ℓ)，
  p_neg 为"物理上不可能"的负偏置。λ,μ 需在标定集上约束误偏置率；当上下文先验与观测冲突时**不允许覆盖观测**，只允许在似然接近时打破平局。
- **定义 242（全量重打分与提交 RRS）**：实时流用前向前缀给出部分后验 p_t(ℓ)；语义流用完整残差、世界模型与几何一致性对 N-best 重打分得 p_T(ℓ)。提交规则：仅当 c_top≥1−δ_commit **且** 后验在 w 帧内变化率 <ε_stable 时提交；否则保持"部分假设"并继续观察。定义延迟-准确率曲线与每技能提交预算。
- **定义 243（同音别名与上下文可解性）**：两条事件序列 ℓ1,ℓ2 在轨迹 τ 上**别名** ⇔ 对所有观测 p(o|ℓ1,τ)=p(o|ℓ2,τ)。此时后验比仅由先验比决定：p(ℓ1|o)/p(ℓ2|o)=p(ℓ1)/p(ℓ2)。若先验相等 → 任何解码器错误率 ≥1/2，**必须拒识**；若上下文先验可分且校准可信 → 可用 CBA 打破平局。这形式化了第 65 轮的共因故障，并给出"上下文偏置何时帮忙、何时幻觉"的边界。
- **定义 244（特征可观测性与不变性陷阱）**：设故障参数 θ 诱发像素变换 g_θ。若编码器对 g_θ 不变（f(g_θ·I)=f(I)），则 ∂f/∂θ=0，故障在特征空间**不可观测**；可观测性由特征雅可比秩与探针敏感度 s_j=sup_{‖w‖=1}|Cov(wᵀz,θ_j)| 度量。故 TGE 必须对故障敏感方向等变；对确实无关的干扰（如纹理）才允许不变。此定义把"视觉编码器越强越好"修正为"**编码器的不变群必须避开故障敏感方向**"。
- **定义 245（假设格安全证书 LSC）**：给定执行前缀 k 与格 L，定义越界路径集 V_k={ℓ∈L:∃s≤k, margin(ℓ,s)<0}。认证即要求 p(V_k)≤α_chunk。用质量剪枝：保留路径集 L_τ={ℓ:p(ℓ)≥τ}，验证其全部安全；则 p(V_k)≤α_chunk+Tail(τ)，**尾部质量被显式计入风险预算**。选最大 k 使 k≤m（不可逆视界）且 Σ_{ℓ∈L_τ} p(ℓ)·1[ℓ 安全] 满足预算。VISTA 的 top-2 是本定义在"尾部质量未知"时的启发式特例。
- **定义 246（RSC-L 格加权定向膨胀）**：对每通道 c∈{geo,force,model,vis,policy}，用格上事件后验质量 m_c=Σ_{ℓ∋event_c}p(ℓ) 加权膨胀：r_c←r_c·(1+κ·m_c)，只膨胀高概率事件对应通道；可观测方向不膨胀。融合半径仍按 √Σr_c²，但每项带质量权重，避免"把所有球一起撑大"。
- **定义 247（WCV-L 格边缘化压缩）**：搜索域按格路径后验加权采样（而非只按 top-2 假设）：CVaR 尾部对 p(ℓ|o) 做**格边缘化**；交集为空 → 回退并置 `lattice_conflict=True`；尾部质量>δ_tail 则拒绝编译、进入保守联合膨胀。
- **定义 248（CSP-L 文法约束块规划）**：块级 A* 的状态含当前格摘要（活动事件、混淆度、top-k 质量）；块边可行需 Valid(J_echo) ∧ k*≥1 ∧ 文法可接受；元技能含 `look_around`、`null_test`、`visual_probe`、`excite`、`ask_human`；代价增 λ_H·H_lat+λ_T·Tail(τ)+λ_k·hinge(k*−k_req)。
- **定义 249（AIC-E 同音/时变/域漂移对抗认证）**：ℰ_E=ℰ_V×ℰ_alias×ℰ_time×ℰ_domain×ℰ_enc。ℰ_alias 为同音别名故障、ℰ_time 为时间伸缩/重放/延迟/端点漂移、ℰ_domain 为物体/工位/光照域漂移、ℰ_enc 为对抗 patch 与特征坍缩。**认证目标从"归因正确"放宽为"高概率格路径安全 + 真值不被以大于 δ 的质量排除"**；n_cert 160→192（其中 32 给别名/时序）。
- **定义 250（自适应 ADP）**：用部署数据做无监督/半监督自适应：集成共识的高置信伪标签 + 一致性门控（多增强一致才采纳）；时间伸缩/速度扰动、token/channel mask（类 SpecAugment）扩增；只更新语义流的探针/似然/文法权重，实时流冻结。防止伪标签污染导致"自信地学错"。
- **定义 251（ECHO 证书 J_echo）**：J_echo=(J_vista, lattice_mass, tail_mass, top1_conf, reject_flag, oov_score, feature_unobservable, grammar_ver, encoder_ver, align_occupancy_hash, aic_e_ver)。Valid ⇔ Valid(J_vista) ∧ (c_top≥1−δ_commit ∨ reject_flag) ∧ Tail(τ)≤δ_tail ∧ k*≥1 ∧ 语法版本/编码器版本一致 ∧ 视觉不可观测未用于否决接触 ∧ 认证覆盖格内质量≥1−δ_tail。

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（对齐自由等价性）**：在理想尖峰条件后验下，CTC 序列似然对事件内部任意单调时间伸缩不变；一般情形下时间伸缩导致的似然扰动被 Σ_t‖y_t−y_{σ(t)}‖ 界住。因此**阶段切分误差不再系统性偏置归因**——它只增加边缘化后的方差，而 VISTA 的固定阶段聚合会把跨阶段事件混叠成错误签名。
- **引理 10（假设格认证的紧致性）**：若保留质量 1−Tail(τ)，则 p(越界)≤α_chunk+Tail(τ)；取使 Tail(τ)≤δ_tail 的 τ，风险预算严格可控。VISTA 的 top-2 启发式对应"把未验证质量当作 0"，其真实尾部质量未知且可能远大于 δ；LSC 把这一隐藏量变成**可计算、可审计、可设预算**的项。
- **引理 11（不变性陷阱）**：若编码器对故障敏感方向不变，特征雅可比在该方向秩亏、探针敏感度为 0，则任何基于该特征的解码器都不可能诊断该故障。故"更强的视觉编码器"若以位姿/尺度不变为目标，反而**主动抹掉**几何/标定的故障证据；等变表征是可观测性的前提。
- **定理 9（ECHO 端到端解码-安全）**：在 A94–A100 下，系统输出三态之一：已解码（格 top-1 提交且格质量覆盖 ≥1−δ_tail，只在被解码事件对应通道上膨胀）、拒识（unknown/ambiguous，禁止强制归因，保守降级）、不可观测（特征/视觉不可观测显式标注且不用于否决）。认证前缀在**格质量**上满足 P[越界]≤α_chunk+Tail(τ)+α_vis+α_geo。
- **定理 10（同音不可分与上下文的作用边界）**：若 ℓ1,ℓ2 在当前轨迹上别名且先验相等，则任何解码器期望错误率 ≥1/2，**唯一安全动作是拒识**；若上下文先验不同且校准可信，则 Bayes 风险由先验对数比与观测似然间隔共同决定。CBA 在似然间隔小于 λ·|Δlog p_ctx| 时有效，超出则**制造幻觉**——这给出 λ 的安全上界。
- **命题（子词组合对未知故障的召回-误报权衡）**：把未知复合故障解码为已知原语的新序列，可在不扩充整类假设的情况下提高未知故障召回；代价是原语序列的**组合爆炸与伪组合**（把噪声解释成合理句子）。故需 CBA 负偏置 + 拒识 + 文法代价共同控制。
- **实时性**：TGE 帧级特征（ROI 池化，<0.3ms）、前向 CTC/beam（受词表与 beam 宽度限制，<0.5ms）、FAD/置信门控（<0.05ms）、LSC 早停（<0.05ms）在实时流；完整前向-后向、WFST 重打分、CBA、ADP、AIC-E 全在语义流（A94 契约，目标 ≤2.5ms）。

## 2. 形式化定义（完整版）

**定义 233（ECHO 闭环）** ECHO 是 VISTA 的"序列解码 + 表征接地 + 拒识"升级：保留 VISTA 的"语义流 ∘ 实时流"骨架与 GRIP 的物理安全底座，挂载 TGE（等变视觉编码器）、CTC-ED（事件解码）、F-WFST（故障文法）、FHL（假设格）、CBA/RRS（偏置与重打分）、FAD/REJ/KWS（端点与拒识），并原位升级 CSC→LSC、RSC-V→RSC-L、WCV-V→WCV-L、CSP-V→CSP-L、AFA→AMB、AIC-V→AIC-E、J_vista→J_echo。不变式：**编码器推理、CTC/WFST 解码、重打分、文法与自适应、证书构建只在语义流与低频线程；实时路径只做帧级特征/残差、前向 beam、端点与置信门控、前缀执行与早停，零学习写操作。**

**定义 234（任务接地等变视觉编码器 TGE）** 编码器 f_enc 把图像 I_t 映射为多尺度 token 特征 Z_t={z_{t,k}}_{k=1}^K∈ℝ^{K×d} 与寄存器 token z_reg。传统编码器以不变性为训练目标，但故障诊断需要的是**可辨识的敏感方向**，故要求对任务相关群 G（SE(3) 子群 × 尺度）等变：
f_enc(g·I)=ρ(g)f_enc(I)，g∈G。
任务观测量 y_t=P_τ(Z_t)（线性/浅层探针：6D 位姿、接触斑中心/面积/法向、可动部件、低维形变），并给每事件一个校准 logit。特征时间残差用预测器 ŵ 得
e_feat(t)=‖Z_t−ŵ(Z_{t−1},a_{t−1})‖²_{Σ_z⁻¹}，
它对接触建立、滑移起始比像素差更敏感且对光照/纹理变化更稳。`feature_unobservable` 当探针置信度 <q_probe(α)、检测到特征坍缩（有效秩骤降）或 register 伪影能量占比过高时置位；**不可见不等于不存在**，不得据此否定接触。

**定义 235（故障事件词表与子词原语）** 事件词表 ℰ=ℰ_prim∪{blank}，原语
ℰ_prim={contact_make, contact_break, slip_onset, force_step, force_drift, geo_conflict, model_dev, vis_conflict, policy_dev, jam, …}。
任何故障叙事是 ℰ_prim 上的序列；为支持未知复合故障，采用**子词式分解**：故障由原语组合而成，未知故障可解码为已知原语的**新组合**（类似 ASR 用 BPE/子词处理 OOV），而不是被塞进最近的整类。每帧嵌入
o_t=ϕ([r_t; vec_pool(Z_t)])，r_t=[e_vis,e_force,e_torque,d_chunk,u_chunk] 为 VISTA 残差通道。

**定义 236（CTC 事件解码器 CTC-ED）** 帧后验 y_t^e=softmax(W o_t+b)_e。路径 π∈ℰ^T，折叠 B 合并相邻重复并删 blank。序列似然
p(ℓ|o_{1:T})=Σ_{π:B(π)=ℓ} ∏_{t=1}^T y_t^{π_t}，
用对数域前向-后向精确计算：
α_t(s)=logsumexp(α_{t−1}(s)+y_t^{ℓ'_s}, α_{t−1}(s−1)+y_t^{ℓ'_s}, α_{t−1}(s−2)+y_t^{ℓ'_s})，
其中 ℓ' 为插入 blank 的扩展标签序列。后向 β 与 α 给出事件对齐占据 γ_t(e)=∂log p/∂log y_t^e，从而恢复每个事件的**时间区间**。CTC 把"何时开始/持续多久/是否静默/事件是否跨阶段"全部边缘化，故对时间抖动、通信延迟、重复事件与多事件复合**天然鲁棒**。阶段 P={approach,touch,load} 由解码事件序列**派生**（如 contact_make 之前为 approach），而非解码输入。

**定义 237（故障文法 WFST）** 把词法 L（子词→事件）、物理/因果文法 G、先验 P 与 CTC 拓扑 T 合成为
F=T∘L∘G∘P。
G 编码因果可行顺序：`model_dev` 只在 `contact_make ∧ load` 之后、`force_drift` 通常需先有 `force_step`、`slip` 需先 `contact_make`、`geo_conflict` 在 approach 即可出现。G 是**软约束**（弧上带代价），避免把未知但物理可行的序列直接判死。文法可离线从成功/失败 episode 学习（FST 学习/加权自动机）并与手写物理规则混合；`grammar_ver` 入证书。

**定义 238（故障假设格 FHL）** 由 WFST beam 搜索得到带后验的 DAG/混淆网络，弧 a=(e,[t1,t2],p_a)。路径后验 p(ℓ|o)∝p(o|ℓ)p(ℓ)。定义 top-k 质量 M_k=Σ_{i≤k}p(ℓ_i)、尾部质量 Tail(τ)=Σ_{ℓ:p(ℓ)<τ}p(ℓ)、格熵 H_lat=−Σ_a p_a log p_a、最小间隔 margin=p(ℓ1)−p(ℓ2)。**诊断输出是带质量的路径集合，不是单个标签**；`argmax` 只在 `c_top≥1−δ_commit` 且 `Tail(τ)≤δ_tail` 时才被允许提交。

**定义 239（故障活动检测 FAD / 端点）** 类似 VAD：用残差能量 + 事件后验的迟滞阈值检测故障 episode 起止（`start`/`end`），在线维护活动段。目的：避免把两次独立事件（一次力阶跃 + 一次滑移）混成一个签名，也避免静默段主导似然。实时流只做 O(1) 门控与迟滞更新。

**定义 240（置信度、拒识与关键词兜底）** 对 top-1 输出经温度缩放/保形校准的置信度 c_top；OOV 分数
ρ_oov = −log p(ℓ|o) + β_sub·subword_recombination_penalty(ℓ)
（子词重组惩罚度量该序列在训练分布中的"不自然度"）。拒识域：
(c_top<1−δ_rej) ∨ (ρ_oov>q_oov(α)) → `unknown_fault` / `ambiguous`，
**禁止对该样本取 argmax**。对少数致命故障（碰撞、过力、失稳、工具飞出）训练独立 KWS 头，以严格误报率 FAR≤α_kws 单独兜底；KWS 命中即压过开放词表输出（安全优先），且其触发不计入归因置信度。

**定义 241（上下文偏置 CBA / shallow fusion）** 给定技能 σ、物体类别与工位，上下文先验 p_ctx(ℓ|σ,obj)。偏置打分
log p_b(ℓ|o)=log p(ℓ|o)+λ·log p_ctx(ℓ|σ,obj)−μ·log p_neg(ℓ)，
p_neg 为"物理上不可能"的负偏置（如空抓时判 slip）。λ,μ 在标定集上受约束：若观测似然间隔 Δ_obs=log p(o|ℓ1)−log p(o|ℓ2) 满足 Δ_obs>λ·|Δlog p_ctx|，则偏置**不得**翻转 top-1（防止上下文覆盖观测）。上下文只在似然接近时打破平局。

**定义 242（全量重打分与提交 RRS）** 实时流用前向前缀给 p_t(ℓ)（低延迟、可粗糙）；语义流用完整残差、世界模型与几何一致性对 N-best 重打分得 p_T(ℓ)。提交规则：
commit(ℓ1) ⇔ c_top≥1−δ_commit ∧ Tail(τ)≤δ_tail ∧ 后验在窗口 w 内变化率 <ε_stable ∧ 格最小间隔 >δ_margin。
否则保持"部分假设"并继续观察；若故障快速不可逆而无法在预算内提交，则交给 KWS/保守降级。定义延迟-准确率曲线与每技能提交预算。

**定义 243（同音别名与上下文可解性）** 两条事件序列 ℓ1,ℓ2 在轨迹 τ 上**别名** ⇔ 对所有观测 p(o|ℓ1,τ)=p(o|ℓ2,τ)。此时
p(ℓ1|o)/p(ℓ2|o)=p(ℓ1)/p(ℓ2)。
若先验相等 → 任何解码器期望错误率 ≥1/2，**唯一安全动作是拒识**；若上下文先验可分且校准可信 → CBA 可打破平局。这形式化了第 65 轮的共因故障（视觉与几何被同一 OOD 源骗过），并给出"上下文何时帮忙、何时幻觉"的严格边界。

**定义 244（特征可观测性与不变性陷阱）** 设故障参数 θ 诱发像素变换 g_θ。若编码器对 g_θ 不变，f(g_θ·I)=f(I)，则
∂f/∂θ = Df(g_θ I)·(∂g_θ/∂θ) = 0，
故障在特征空间**不可观测**，任何基于该特征的解码器对 θ 的 Fisher 信息为 0。可观测性由特征雅可比秩与探针敏感度
s_j=sup_{‖w‖=1}|Cov(wᵀz,θ_j)|
度量。故 TGE 必须对故障敏感方向等变；仅对确实无关的干扰（纹理、曝光）允许不变。**"更强的视觉编码器"若以位姿/尺度不变为目标，反而主动抹掉几何/标定故障证据。**

**定义 245（假设格安全证书 LSC）** 给定执行前缀 k 与格 L，越界路径集
V_k={ℓ∈L:∃s≤k, margin(ℓ,s)<0}。
认证要求 p(V_k)≤α_chunk。用质量剪枝：保留 L_τ={ℓ:p(ℓ)≥τ}，验证其全部安全，则
p(V_k) ≤ α_chunk + Tail(τ)。
选最大 k* 使 k*≤m（不可逆视界）且保留路径全部安全、越界质量在预算内。VISTA 的 top-2 是本定义在"尾部质量未知"时的启发式特例；LSC 把隐藏尾部质量变成**可计算、可审计、可设预算**的项。

**定义 246（RSC-L 格加权定向膨胀）** 对通道 c∈{geo,force,model,vis,policy}，用格上事件后验质量 m_c=Σ_{ℓ∋event_c}p(ℓ) 加权：
r_c←r_c·(1+κ·m_c),
只膨胀高概率叙事涉及的通道；可观测方向不膨胀。融合半径 r=√Σ_c r_c²（带质量权重），避免第 65 轮"把所有球一起撑大"的过度保守。

**定义 247（WCV-L 格边缘化压缩）** 搜索域按格路径后验加权采样（而非只按 top-2 假设）：CVaR 尾部对 p(ℓ|o) 做**格边缘化**，n_worst=8；交集为空 → 回退 B(φ̂,r) 并置 `lattice_conflict=True`；若 Tail(τ)>δ_tail 则拒绝编译、进入保守联合膨胀 + safe_idle。

**定义 248（CSP-L 文法约束块规划）** 块级 A* 的状态含格摘要（活动事件、混淆度 H_lat、top-k 质量、尾部质量）；块边可行需 Valid(J_echo) ∧ k*≥1 ∧ 文法可接受；元技能含 `look_around`（多视角）、`null_test`（零力窗标定）、`visual_probe`、`excite`（安全激励）、`ask_human`。代价增 λ_H·H_lat+λ_T·Tail(τ)+λ_k·hinge(k*−k_req)。主动探针 AMB 选择
a*=argmax_a E[margin_{L}(ρ_{1:T'}(a))]，
即最大化格最小间隔 / 降低歧义质量，而非第 65 轮的假设互信息；约束同 VSP（力/形变/时间安全）。

**定义 249（AIC-E 同音/时变/域漂移对抗认证）** 干扰集
ℰ_E=ℰ_V×ℰ_alias×ℰ_time×ℰ_domain×ℰ_enc，
ℰ_alias 为同音别名故障（不同故障同签名）、ℰ_time 为时间伸缩/重放/延迟/端点漂移、ℰ_domain 为物体/工位/光照/传感器老化域漂移、ℰ_enc 为编码器对抗 patch、特征坍缩与伪影 token。**认证目标从"归因正确"放宽为"高概率格路径安全 + 真值不被以大于 δ 的质量排除"**；n_cert 160→192（其中 32 给别名/时序/编码器）。共因故障下不要求归因正确，只要求被判为高 tail_mass/ambiguous 并安全降级。

**定义 250（自适应 ADP）** 用部署数据做无监督/半监督自适应：多个增强/集成模型的高置信共识作伪标签，**一致性门控**（多增强一致才采纳）抑制伪标签污染；时间伸缩/速度扰动、token/channel mask（类 SpecAugment）扩增；只更新语义流的探针、似然与文法权重，实时流冻结。自适应版本写入 `encoder_ver`/`grammar_ver` 并触发 AIC-E 重认证。

**定义 251（ECHO 证书 J_echo）** J_echo=(J_vista, lattice_mass, tail_mass, top1_conf, reject_flag, oov_score, feature_unobservable, grammar_ver, encoder_ver, align_occupancy_hash, aic_e_ver)。验证规则：
Valid(J_echo) ⇔ Valid(J_vista)
∧ (c_top≥1−δ_commit ∨ reject_flag)
∧ Tail(τ)≤δ_tail
∧ k*≥1 ∧ 认证覆盖格内质量 ≥1−δ_tail
∧ grammar_ver/encoder_ver 与当前一致
∧ (feature_unobservable ⇒ 未以视觉否定接触)
∧ aic_e_ver 为当前版本。
审计链新增：解码出了哪些事件（align occupancy）、为什么只信到 1−δ_tail、为什么拒绝提交、视觉是否可观测。

**定义 252（ECHO 闭环算子）** 语义流：[LiDAR→LSF→USR/MEL→TGE 特征→CTC-ED→F-WFST→FHL→CBA/RRS→FAD/REJ/KWS→RSC-L→WCV-L→CSP-L/AMB→LSC→Shield-Skill→OCB-Skill→执行 k*→EV_exec→ADP→AIC-E]；实时流：[锚点读→帧特征/残差→前向 beam→端点/置信门控→LSC 早停→WCV-L 编译→π_σ 前缀派发→J_echo 构建]。

```python
    """冻结等变编码器 + 任务探针；不变群必须避开故障敏感方向。"""
```

### IP-225 CTC-ED（对齐自由事件解码）

```python
def ctc_loglik(o, labels, blank=0):
    """对数域前向-后向；返回 log p(labels | o) 与逐事件对齐占据。"""
    ext = [blank] + [x for l in labels for x in (l, blank)]   # 插入 blank
    T, S = len(o), len(ext)
    logp = log_softmax(o, axis=1)
    a = np.full((T, S), -INF); a[0, 0] = logp[0, ext[0]]
    if S > 1: a[0, 1] = logp[0, ext[1]]
    for t in range(1, T):
        for s in range(S):
            prev = [a[t-1, s]]
            if s >= 1: prev.append(a[t-1, s-1])
            if s >= 2 and ext[s] != blank and ext[s] != ext[s-2]:
                prev.append(a[t-1, s-2])
            a[t, s] = logsumexp(prev) + logp[t, ext[s]]
    b = np.full((T, S), -INF); b[-1, S-1] = 0.0
    if S > 1: b[-1, S-2] = 0.0
    for t in range(T-2, -1, -1):
        for s in range(S):
            nxt = [b[t+1, s] + logp[t+1, ext[s]]]
            if s+1 < S:
                nxt.append(b[t+1, s+1] + logp[t+1, ext[s+1]])
            if s+2 < S and ext[s] != blank and ext[s] != ext[s+2]:
                nxt.append(b[t+1, s+2] + logp[t+1, ext[s+2]])
            b[t, s] = logsumexp(nxt)
    logZ = logsumexp(a[-1, [S-1, S-2] if S > 1 else [S-1]])
    gamma = np.exp(a + b - logZ)                  # 对齐占据 -> 事件区间
    return logZ, gamma


class CTCEventDecoder:
    def decode(self, o):
        logZ, gamma = ctc_loglik(o, self.labels)
        return {'logp': logZ, 'occupancy': gamma,
                'prefix': self.beam_prefix(o, width=self.beam_w)}
```

```python
class HypothesisLattice:
    def posterior(self):
        z = logsumexp([p.logp for p in self.paths])
        return [p._replace(post=math.exp(p.logp - z)) for p in self.paths]

    def tail_mass(self, tau):
        return sum(p.post for p in self.paths if p.post < tau)

    def margin(self):
        s = sorted((p.post for p in self.paths), reverse=True)
        return s[0] - (s[1] if len(s) > 1 else 0.0)
```

```python
def context_bias(post, skill, obj, lam, mu, delta_obs):
    scores = {}
    for p in post:
        d_ctx = math.log(prior_ctx(p.events, skill, obj) + 1e-12)
        d_neg = math.log(prior_neg(p.events, skill, obj) + 1e-12)
        if lam * abs(d_ctx) >= delta_obs:       # 不得用上下文覆盖强观测
            d_ctx = 0.0
        scores[p] = p.logp + lam * d_ctx - mu * d_neg
    return renormalize(scores)
```

```python
def lattice_certified_prefix(A, lattice, m, alpha_chunk, delta_tail):
    lattice = lattice.posterior()
```

## 4. 推导

**引理 9（对齐自由等价性与阶段切分的偏差消除）** 设观测序列 o 经单调时间伸缩 σ 变为 o'（事件内部时长改变、静默伸缩）。在"尖峰条件"（每帧接近 one-hot）下，CTC 对全部对齐边缘化，故 p(ℓ|o')=p(ℓ|o)。一般情形下
|log p(ℓ|o')−log p(ℓ|o)| ≤ Σ_t |log y_t^{π_t} − log y'_{σ(t)}{}^{π_t}| ≤ TV(o,o')·const，
即时间伸缩只增加方差、不产生系统性方向偏置。反观 VISTA 的固定阶段聚合：设真实阶段归属矩阵为 M（把帧映射到 approach/touch/load），切分误差使实际签名期望变为 E[ρ]=MSθ；则
J_fi=(MS)ᵀΣ_ρ⁻¹(MS)，κ_fi=λ_min(J_fi)/λ_max(J_fi)。
当 M 偏离置换矩阵（跨阶段事件、边界污染零力窗）时，H_force 与 H_geo 的列不再正交、κ_fi 下降乃至奇异——这正是第 65 轮风险 #4 的数学形式。CTC 通过边缘化对齐，等价于对 M 求和而非固定一个错误 M，故不放大该偏差。∎

**引理 10（假设格认证的紧致性与 VISTA top-2 的隐含假设）** 保留集 L_τ 全安全，则
P[V_k]=Σ_{ℓ∈V_k}p(ℓ)=Σ_{ℓ∈V_k∩L_τ}p(ℓ)+Σ_{ℓ∈V_k∖L_τ}p(ℓ) ≤ 0 + Tail(τ) ≤ δ_tail，
叠加 conformal 覆盖误差得 P[越界]≤α_chunk+δ_tail+α_vis+α_geo。VISTA 的 top-2 相当于断言 Tail=0（未验证质量为零）；其真实尾部质量随故障数、别名数与未知度增长，可能远超 δ，故其"违规=0"的实验结论依赖分布内闭集。LSC 的预算可显式设定并在 AIC-E 中按最坏别名分布验证。∎

**引理 11（不变性陷阱）** 若 f(g_θ I)=f(I) 对所有 θ∈Θ 成立，则对 θ 求导得 Df(g_θ I)·(∂g_θ/∂θ)=0，故特征不含 θ 的信息，任何解码器对 θ 的 Fisher 信息为 0，后验等于先验，错误率由先验下界决定。若 f(g_θ I)=ρ(g_θ)f(I) 且 ρ 非平凡，则 ∂f/∂θ=dρ/dθ·f+ρ·Df·∂g/∂θ 一般非零，探针敏感度 s_j>0。故 TGE 的等变群选择直接决定可诊断性的上界；对纹理/曝光不变是安全的，对位姿/尺度不变则是**主动致盲**。∎

**定理 9（ECHO 端到端解码-安全）** 在 A94–A100 下：
1. **不强制归因**：若 c_top<1−δ_rej 或 ρ_oov>q_oov，系统输出 unknown/ambiguous 并进入保守降级；若 top-1 已提交，则 Tail(τ)≤δ_tail 且认证覆盖格质量 ≥1−δ_tail。
2. **只膨胀对的通道**：RSC-L 按 m_c 加权，只有被解码事件确实涉及的通道半径增长；未涉及通道（如 H_force 时的 r_geo）保持不变，对冲第 65 轮的误降级。
3. **执行安全**：LSC 在保留格路径上验证 k*≤m 步安全，越界概率 ≤α_chunk+δ_tail+α_vis+α_geo。
4. **未知可分解**：子词原语允许未知复合故障以新序列表达；若仍 OOV 则拒识，不取最近类。
5. **优雅降级**：视觉不可观测→feature_unobservable、退回力/几何；F/T 失效→高概率 force 事件；编码器对抗→KWS/拒识；全部失准时 tail_mass 超预算→safe_idle + compliant retreat。
6. **实时性**：实时流 ≤2.5ms，零学习写操作（A94）。∎

**定理 10（同音不可分与上下文偏置的作用边界）** 设 ℓ1,ℓ2 在轨迹 τ 上别名且 p(ℓ1)=p(ℓ2)。对任意解码器 d(o)，最小期望错误率
R* = ½(1−‖p(o|ℓ1)−p(o|ℓ2)‖_TV) = ½，
故无法区分，唯一零伤害动作是拒识。若先验不等，Bayes 决策阈值由 log[p(ℓ1)/p(ℓ2)] 决定；上下文偏置注入 λΔlog p_ctx 等价于移动该阈值。若注入方向与真实先验一致，可降低错误率；若不一致（域漂移/物体误识别），则错误率不降反升，且系统会**自信地幻觉**。安全约束 Δ_obs>λ|Δlog p_ctx| 保证偏置不覆盖强观测，从而把幻觉限制在"观测本来就模糊"的区域。∎

**命题（子词组合的召回-伪组合权衡）** 设原语数 |ℰ_prim|=P、平均叙事长度 L，则组合空间为 P^L。把未知故障表达为原语新序列可提升召回，但伪组合概率随 L 与噪声增大而上升。CBA 负偏置与文法代价相当于在组合空间上施加先验正则，使伪组合的后验质量被压到 δ_tail 以下；若无法压低，则拒识——这给出"扩展表达力"与"可认证性"的显式权衡。∎

**命题（流式提交的延迟-修订权衡）** 前缀后验 p_t 与全量 p_T 的期望 KL 随 lookahead T−t 单调不增（更多观测不增信息熵）。稳定提交规则等价于要求 D_KL(p_T‖p_t)<ε_stable 且 margin>δ_margin，故每技能存在最小提交延迟 t*(σ)；对快速不可逆故障需 t*(σ)≤m/控制周期，否则必须依赖 KWS/保守降级。∎

## 7. 已知风险

**一句话**：ECHO 把"被迫误分类"换成了"**流畅但错误的故障叙事**"——学习型视觉编码器 + CTC 先验 + 上下文偏置 + 故障文法会联合幻觉出一段听起来最合理的故障句（高置信、低熵、格质量集中），而文法/先验又可能把真正新颖的故障当作"不合语法"提前剪掉；一旦分布漂移使校准与尾部质量失准，LSC 会**恰好剪掉真故障所在的低概率路径**，于是系统再次"因为已经归因"而自信地继续执行——只是这次带着一个自洽的故事。这是本轮全部表征、解码与认证论证共同依赖的隐藏假设（A100）。

**次级风险与缓解**：
1. **叙事幻觉（narrative hallucination）**：CTC 先验 + 文法 + 上下文偏置共同放大"像话"的序列；缓解：λ,μ 受 Δ_obs 约束、负偏置、格熵/尾部质量门控、独立 KWS、拒识优先策略。
2. **文法压制新颖故障**：G 是软约束但 beam 仍可能剪掉低分真路径；缓解：文法代价封顶、保留一条"无文法"旁路 beam、AIC-E 显式测"真值被δ质量排除"的频率。
3. **尾部质量估计在分布漂移下失准**：Tail(τ) 依赖校准；缓解：分域/分视界保形校准、在线漂移检测、最坏别名分布认证、tail_mass 超预算即 safe_idle。
4. **编码器对抗与特征坍缩**：对抗 patch、register 伪影、OOD 物体；缓解：register token、有效秩监控、feature_unobservable、多视角/多编码器等变一致性。
5. **CTC 尖峰假设被违反**：同时多事件、无 blank 的连续故障会破坏对齐边缘化；缓解：多标签/多 blank 扩展、事件并发因子、FAD 分段。
6. **子词组合爆炸与伪组合**：组合空间 P^L；缓解：WFST 文法剪枝、负偏置、长度先验、拒识。
7. **流式提交错过快速故障**：稳定窗与 margin 要求可能慢于不可逆视界；缓解：快速通道 KWS、按技能设 t*≤m、force 通道硬阈值并行。
8. **伪标签污染自适应**：ADP 可能"自信地学错"；缓解：多增强一致门控、回滚版本、ADP 后重认证、只在语义流更新。
9. **KWS 误报与漏报**：严格 FAR 会牺牲召回；缓解：分层阈值（警告/停机）、与 LSC 交叉、人工确认通道。
10. **实时预算**：前向 beam 与 TGE 帧特征逼近 2.5ms；缓解：ROI 降采样、事件驱动编码、beam 宽度自适应、重解码全留语义流。
