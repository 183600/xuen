# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「真实世界泛化」×「移动操作」）

> R69 把不确定性一分为二，并让系统学会「问」。但它默认了三件事：**(a) 观测分布是外生的、固定的**——机器人只能看/问/触，不能改变自己站在哪里；**(b) 不确定性是关于「离散动作模态」的**——歧义可以聚类成 K 个模态；**(c) 安全包络是固定的**——认证一次就够。
>
> 「真实世界泛化」×「移动操作」同时击穿这三点：
> - 移动底盘意味着机器人**能通过移动改变自己的测试分布**——「站在哪里」既是最大的信息动作，也是最大的风险源；
> - 真实世界的漂移不是多峰，而是**结构性漂移**：新地板摩擦、新物体质量/柔顺性、新房间外观。它没有「模态」可分，也**问不出来**，本质是**训练支撑集（support）之外**；
> - 安全包络随底盘移动而移动，并与「我还在不在胜任区」耦合。
>
> 核心命题：**在 aleatoric（噪声）与 epistemic（歧义）之外，补上第三种不确定性 U_sup（支撑/胜任区违反）；并把「真实世界泛化」重新定义为闭环的可达性性质——机器人必须把全身轨迹「拴」在一个经校准的胜任区内，同时可以主动移动去重新进入它。** 命名 **GROUND-RAS**（Generalization via Reachability-bounded Operational Uncertainty under Non-stationary Dynamics）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**为了求证，我究竟还能站在哪里**」——泛化不是策略「拥有」的属性，而是闭环「维持」的区域。

## 0. 直觉与动机

**灵感 1（真实世界泛化 → 缺失的第三种不确定性）**
直觉：R69 的二分法隐含假设「失败要么是噪声（不可约），要么是歧义（可问出来）」。但换了一种地板、换了一个质量的箱子、进了一间没见过的房间，这三者都不是：**整个动作分布被搬走了**。把 K 个采样聚类，只会把「整体偏移」错误地报成「低方差、单模态」——系统会极度自信地走进分布外。严谨说法：R69 的 U_ale 度量模态内方差，U_epi 度量模态间熵，二者都在「支撑集内部」；缺的是**状态到训练支撑集的距离**。定义 U_sup 为该状态相对校准集的一致性（conformal）违反度，它是与 U_ale/U_epi 正交的第三个通道：噪声→收紧；歧义→交互；支撑违反→**重新进入支撑 / 适应 / 放弃**。这三者不能相加，只能分路处置。

**灵感 2（移动操作 → 泛化是可控制性，不是静态属性）**
直觉：固定底座的机械臂无法改变自己的测试分布；移动操作机器人可以——走到光线更好的位置、换个能看清的视角、选一个自己练过的抓取方向。于是「OOD」不再只是一个报警灯，而是一个**可以被规划到达的设定点**。严谨说法：底盘位姿 q_b 是一个控制量，它同时改变任务相关坐标 ψ、支撑分数 s(q,ψ) 与安全约束。把「保持/返回支撑集」写成一个**控制 Lyapunov 约束**（tether CLF），泛化失败就从「静默漂移」变成一个**可达性问题**：要么可恢复，要么明确判定为不可恢复并退回 R69 的保守路径。这是本轮最核心的视角转换：**泛化是闭环能维持的区域，不是策略参数里的性质。**

**灵感 3（先规范不变，再移动 → 不要用昂贵运动去补表征的洞）**
直觉：很多「真实世界不泛化」其实不是世界变了，而是模型把「绝对房间坐标」背了下来。移动底盘时，任务在**末端-物体相对坐标系**里根本没变——这是规范（gauge）自由度。严谨说法：把底盘位姿与外观变化视为一个群 G_b × G_n，要求编码器在 G_b 下不变、在 G_n 下不变（或等变）。于是泛化误差可以**分解**为「不变性误差 ε_inv」+「剩余支撑违反 ρ_sup」+「适应误差」+「集中误差」。关键推论：能用表征修掉的第一项，绝不该动用有风险的底盘运动去补；移动只应去修表征修不掉的剩余支撑缺口（引理 20）。这条分解也是本轮所有实验设计的骨架。

**灵感 4（拴绳是双刃剑 → 支撑约束会与任务/安全冲突）**
直觉：一直待在胜任区里是最安全的，但可能根本完成不了任务；而要到达胜任区，有时又必须穿过一段不安全/不胜任的走廊。R69 的「只收紧」在这里会退化成永久死锁。所以必须区分「可恢复」与「被困住」，并给出证明：若存在受认证的全身控制使拴绳势函数 V 单调下降，则能回到胜任区（定理 19）；否则必须诚实地说「不可恢复」并停机/求助，而不是一边慢慢走一边自我安慰。移动操作还引入倾覆、打滑、动态障碍、接触力等全身安全约束，必须与支撑约束取交集（定义 320）。

**灵感 5（估计器也会撒谎 → 对「胜任区估计」本身不信任）**
直觉：conformal 覆盖率保证依赖可交换性；真实结构性漂移恰恰破坏它。最危险的场景不是「被检测到 OOD」，而是**支撑估计器在 OOD 上依然自信**——移动操作会让机器人**主动加速驶入这个虚假的胜任区**。R69 用 MCG 不信任「模态权重」；R70 必须再往上一层：用两个独立支撑估计器（密度比 vs 集成分歧）做互检 SUD，一旦分歧过大，就认定「胜任性本身不可认证」，退回固定的 OOD-鲁棒保守包络，且**禁止任何基于支撑的 λ 放松**。这是 R69「问错比不问更危险」的镜像：**自信地走错地方，比停在原地更危险。**

## 1. 形式化定义（增量：定义 310–327）

**定义 310（GROUND-RAS 总览）** GROUND-RAS = (RIC, CSE, SUD, SU3, SCOPE, TCL, ASR, WBC, SAL)。四不变式：
(i) **实时环路零学习写操作**（继承 R68 定义 276-i）；任何适应只发生在 SAL（定义 324），且必须带证书与回滚；
(ii) **拴绳不变式**：任何被执行的全身前缀，其预测状态必须落在胜任包络 K_τ 内并保留逐步裕度（定义 316、319）；不满足时只允许恢复/放弃动作；
(iii) **单估计器不信任**：除非 SUD 认证两个支撑估计器一致，否则禁止任何基于支撑的保守放松（定义 325）；
(iv) **R69 严格包含**：底盘不动、无结构漂移、SUD 通过时，逐指令退化为 FLUID-RAS（定理 18）。

**定义 311（移动操作模型）** 位姿-构型 q = (q_b, q_a) ∈ SE(3) × Q_a；全身动作 u = (u_b, u_a)，其中 u_b 为底盘运动、u_a 为关节/夹爪动作。含未知环境参数的动力学 q_{t+1} = f(q_t, u_t; θ_env)，θ_env =（摩擦、质量、柔顺性、载荷等）。观测 o = (o_ext, o_prop)。策略 π_θ(u_{t:t+H} | o_t, q_t)。R69 的增广动作 ξ=(a,g) 是 u 在「底盘冻结」子空间上的投影。

**定义 312（任务相关坐标）** ψ = Ψ(o, q) =（物体在末端坐标系下的相对位姿、局部几何/接触特征、接触力旋量、本体感觉）。Ψ 在所有任务相关意义上**不依赖世界系原点与朝向**，因此是对底盘位姿规范不变的坐标。

**定义 313（规范群与漂移分类）** 底盘规范群 G_b = SE(3)（作用于世界系）；外观干扰群 G_n（光照、纹理、颜色、背景变换，作用于 o_ext）。**域内漂移**：P_test 是 P_train 在 G_b×G_n 下的推前；**结构漂移**：θ_env 或物体类别改变，且不在 G_b×G_n 的轨道上。真实世界泛化的目标 = 对域内漂移不变，对结构漂移可控。

**定义 314（规范不变编码 RIC）** 编码器 Φ 满足 Φ(g_b·o, g_b·q) = Φ(o, q)（G_b 不变）与 Φ(g_n·o, q) = Φ(o, q)（G_n 不变）。实现为：等变骨干 + 相对位姿特征 + 不变池化。不变性误差 ε_inv = sup E‖Φ(变换后) − Φ(原)‖。z_t = Φ(o_t, q_t) 同时供 R69 的流策略与 CSE 使用。

**定义 315（胜任场与非一致性分）** 胜任场 C(q, ψ) = P(成功或低后悔 | q, ψ)。非一致性分 s(q, ψ) = α·Ens(q,ψ) + (1−α)·d_kNN(ψ; D_train)，其中 Ens 为策略/动力学集成分歧，d_kNN 为到训练支撑的分布距离（密度比）。s 越大越不可信。

**定义 316（conformal 胜任包络 CSE）** 给定可交换的校准集 D_cal，τ_α = D_cal 上 s 的 (1−α) 分位数；K_τ(α) = { (q,ψ) : s(q,ψ) ≤ τ_α }。则对新的可交换样本，P(s_new ≤ τ_α) ≥ 1−α。K_τ 就是「策略可胜任区」的可操作定义。

**定义 317（支撑违反度 U_sup）** 状态处 conformal p 值 p_sup = (1 + #{i: s_i ≥ s(q,ψ)}) / (n+1)；支撑裕度 m_sup = τ_α − s(q,ψ)；U_sup = max(0, −m_sup)/τ_α ∈ [0,1]。它度量「离训练支撑有多远」，**既不可约（不是噪声）也不可由单次询问消除（不是歧义）**。

**定义 318（三路不确定性分解 SU3）** U_ale = Σ_k ŵ_k tr(Σ_k)（模态内，不可约）；U_epi = H_mode·g(Δ_min)（模态间，可由信息动作消解）；U_sup = 上式（支撑外，需移动/适应/放弃）。三路**不同语义、不同通道、不做简单加和**：U_ale → λ_floor；U_epi → MINT/ASR 的信息动作；U_sup → 恢复 / SAL / 放弃。只有当某一路无法处置时，才按 R68/R69 的两级退避并入 λ_floor。

**定义 319（拴绳深度与 horizon 裕度）** 对预测时域 H，取逐步失败率 α/H（联合界），定义拴绳深度 d(q) = τ_{α/H} − s(q,ψ) 与拴绳集 T = {d ≥ 0}。d 是「离胜任区边界的距离」，也是风险缩放可放松的额度来源（定义 323）。

**定义 320（安全-胜任交集）** 可执行集 S = Safety(WBC) ∩ TaskFeasible ∩ T，其中 Safety(WBC) 含倾覆稳定、接触力/力矩、动态障碍、关节/速度极限；TaskFeasible 含运动学可达与任务约束。整套闭环只允许在 S 内执行非恢复动作。

**定义 321（支撑约束全身规划 SCOPE）** 规划全身动作 u_{t:t+H}，最大化期望任务进度，s.t. 所有预测状态 ∈ S 且逐步 d ≥ 0、动力学可行、控制平滑。若该约束规划不可行，则转入恢复（定义 322），而非放宽约束。

**定义 322（拴绳控制 Lyapunov 函数与恢复 TCL）** 令 V(q) = max(0, −d(q))。若在 S \ T 上存在受 WBC 认证的 u 使 V(f(q,u)) ≤ (1−η)V(q)（η∈(0,1]），则称状态**可恢复**，并可在 ≤ log(V_0/ε)/η 步内回到 T。若某状态不存在这样的 u，则判定**不可恢复**（支撑集不连通 / 被安全墙隔断），执行 R69 保守回退：减速、停机、求助或交还人类，绝不在不可恢复状态下继续任务。

**定义 323（主动寻支撑 ASR）** 选定移动/注视/探针动作 m，最大化 E[任务进度 + β·Δd − c(m)]，s.t. WBC 认证、风险 r(m) ≤ ε_move、拴绳不破。若不允许底盘运动（u_b=0），ASR 逐项退化为 R69 的 MINT/VoI（引理 20）。注意：移动既可增加 d（更胜任），也可能降低 d 或提高安全风险，故必须联合约束。

**定义 324（慢适应环 SAL）** 仅在实时环之外、低频率运行：用近期数据估计低维 θ_env（摩擦/质量/柔顺），据此平移/缩放 K_τ 与 C 的校准；每次写操作必须通过 J_GROUND 校验并保存回滚检查点；**绝不修改实时环内的安全关键状态**。适应是有界、可撤销、可审计的，因此不违反定义 310-i。

**定义 325（胜任性互检 SUD）** 两个独立支撑估计器：A = conformal 密度比（定义 316），B = 集成分歧排序。分歧 D(q,ψ) = |s_A − s_B| / τ_α。若 D > τ_D，则「胜任性不可认证」：禁止任何 λ 放松，采用固定的 OOD-鲁棒保守包络 K_τ^0，并允许 R69 回退。SUD 是 MCG 在支撑层面的上移——不信任「我不确定」这件事本身的估计。

**定义 326（证书 J_GROUND）** J_GROUND = (J_FLUID, coverage_empirical, support_margin_p5, tether_violations, sud_disagreement_p95, recovery_success, sal_rollback_count, ground_ver)。Valid ⇔ Valid(J_FLUID) ∧ 覆盖 ∈ [1−α−δ, 1−α+δ] ∧ tether_violations = 0 ∧ 任何 λ 放松均有 SUD 认证。

**定义 327（分布泛化间隙）** G(π) := R_test(π) − R_train(π)。在本框架下分解为四项：不变性项 ε_inv、支撑违反项 ρ_sup、适应项 ε_adapt、集中项 ε_conc（见命题 19）。泛化改进的每一分都必须归因到某一项，禁止把「靠移动躲开难例」冒充成「表征变好了」。

# IP-264 RIC：规范不变编码（底盘位姿 + 外观干扰）
class GaugeInvariantEncoder:
    def __call__(self, o, q):
        rel = relative_pose_features(o.object_pose, q.end_effector)  # G_b 不变
        ext = invariant_pool(self.backbone(o.ext))                   # G_n 不变
        return concat(rel, ext, o.prop)                              # z_t

# IP-265/266 CSE + SUD：conformal 胜任包络与互检
class ConformalSupportEnvelope:
    def score(self, q, psi):                       # 非一致性分
        return 0.5 * self.ens.disagreement(q, psi) \
             + 0.5 * self.knn.distance(psi, self.train_support)
    def pvalue(self, s):
        return (1 + (self.cal_scores >= s).sum()) / (len(self.cal_scores) + 1)
    def tether_depth(self, q, psi, H):
        tau = self.tau(alpha=self.alpha / H)       # 逐步失败率 α/H
        return tau - self.score(q, psi)

class SupportUncertaintyDistrust:
    def disagreement(self, q, psi):
        return abs(self.cse.score(q, psi) - self.ensemble_score(q, psi)) / self.tau_alpha

# IP-268/269 SCOPE + TCL：支撑约束全身规划与恢复
def support_constrained_plan(models, q, psi, d, H, allow_move, lam_relax):
    if d < 0 and not tcl.exists_certified_descent(q, psi):
        return RecoveryPlan(reason='unrecoverable')          # 定义 322
    best = None
    for u in whole_body_candidates(models, allow_move):
        traj = rollout(models.f, q, u, H)
        if not all(s in S for s in traj):                    # 安全-胜任交集
            continue
        score = expected_progress(traj) + (beta * min_depth(traj) if lam_relax else 0)
        best = argmax(best, score)
    return best or RecoveryPlan(reason='infeasible')

# IP-271 WBC：全身安全证书（继承并扩展 C-RAS-WM）
def certified_whole_body(plan, q):
    return (tip_over_margin(plan, q) > 0 and contact_forces_ok(plan)
            and dynamic_obstacles_clear(plan) and kinematic_ok(plan))

# IP-276 主闭环
def GROUND_RAS_round(M, obs, q):
    z, psi = M.ric(obs, q)                              # 1) 规范不变状态
    # 2) 三路不确定性：R69 复用，新增支撑项
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(z, K), z)
    s = M.cse.score(q, psi)
    U_sup = 1.0 - M.cse.pvalue(s)
    D = M.sud.disagreement(q, psi); sud_ok = D <= TAU_D
    # 3) 拴绳与可恢复性
    d = M.cse.tether_depth(q, psi, H=M.vista.H)
    if (d < 0) and not M.tcl.exists_certified_descent(q, psi):
        return M.r69_fallback(q)                        # 不可恢复：停机/求助
    # 4) 主动寻支撑：可移动、可注视、可问；仅在 SUD 通过时允许 λ 放松
    plan = M.scope.plan(modes, q, psi, d, allow_move=True, lam_relax=sud_ok)
    k = M.wbc.certified_prefix(plan, q)                 # 5) 全身安全证书
    if not k:
        return M.r69_fallback(q)
    # 6) 风险缩放：三路分道；支撑裕度可换 resolution bonus
    U_floor = U_ale + (0.0 if plan.resolved else U_epi)
    if not sud_ok:
        U_floor += U_sup                                # 支撑不可信 → 保守并入
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if sud_ok and d > 0:
        lam = max(lam_min, lam - beta * d)              # 拴绳越深越可放松（有界）
    # 7) 执行、审计、慢适应（均在实时环之外）
    M.vqa_g.submit_async(plan, s, D, d, U_sup)
    M.sal.maybe_update_async(q, psi, s)                 # 有界、可回滚
    return k, lam, plan

## 3. 推导

**命题 19（泛化间隙四分解）** 在 A99–A103 下，损失 ℓ 有界 L_max、在 ψ 上 L_R-Lipschitz，记 ρ_sup = P_test(s > τ_α)，W_1^K 为在支撑交集 K 上的 1-Wasserstein 距离，则
R_test(π) − R_train(π) ≤ L_R·( ε_inv + W_1^K(ψ_#P_test, ψ_#P_train) ) + L_max·ρ_sup。
证明要点：把 R_test 拆成 K 内与 K 外两部分；K 内用三角不等式和 Lipschitz 性，把差异归到编码器不变性误差与 ψ 分布距离；K 外由 ℓ ≤ L_max 与概率 ρ_sup 直接界定。三项结论：(i) RIC 廉价地攻击 ε_inv；(ii) ρ_sup 是**独立可加项**，任何模态消歧都无法消除——这正是必须引入第三路 U_sup 的理论理由；(iii) 移动/适应只能降低 ρ_sup，不能降低 ε_inv，故「先修表征，再动底盘」。

**引理 19（拴绳的 horizon 联合界）** 若每一步选择 τ_{α/H} 使单步支撑逃逸概率 ≤ α/H，则由联合界，长度 H 的时域内至少一次逃逸的概率 ≤ α。推论：拴绳深度必须随 H 增大而加深，或提高重规划频率——这给出「τ–H 曲线」，解释了为什么长时程移动操作比短程抓取需要更深的裕度。

**定理 18（GROUND 在静态边界严格包含 R69/R68）** 若底盘冻结（u_b=0）、无结构漂移（s ≤ τ_α 且 SUD 认证通过），则 U_sup 通道关闭、ASR 退化为 MINT/VoI、SCOPE 退化为 R69 的认证前缀且拴绳恒满足，故 GROUND 的每一步决策与 FLUID-RAS 逐指令相同；又因 GROUND 在任何 λ 放松前都要求 SUD 认证，其安全侧永不弱于 R68。即 R69 = GROUND 在「不移动、不结构漂移」边界上的退化。

**定理 19（可恢复性的 CLF 判据）** 在 A102/A104 下，若在 S \ T 上存在受 WBC 认证的 u 满足 V(f(q,u)) ≤ (1−η)V(q)，则从任意 q∈S 出发，存在一条保持在 S 内的受认证控制序列，在 ≤ log(V_0/ε)/η 步内进入 T。反之，若某状态不存在这样的 u，则不存在任何受认证控制器能保证返回；GROUND 显式判定「不可恢复」并执行 R69 回退。故「泛化失败」从静默漂移变为**可判定的可达性问题**。

**引理 20（主动寻支撑 = 移动上的 VoI）** 移动 m 把支撑分从 s 变到 s'，成本 c_m、风险 r_m ≤ ε_move。其净收益为 E[Δloss(s→s')] − c_m − κ·r_m。仅当该值 > 0 时才移动；否则停在原地走 R69。故移动不是免费的泛化，而是又一种信息-风险权衡，R69 的 VoI 正是 u_b=0 的特例。特别地，若移动会降低 d 或越出 S，则即使在分布意义上「更接近训练集」也必须被拒绝——**支撑收益不能抵消安全代价**。

**引理 21（SUD 互检界）** 设两个估计器在有效时误差各 ≤ e_A, e_B，分歧为 D。则被选中估计的误差 ≤ D + min(e_A, e_B)。若 D > τ_D，则至少一个估计器失效，胜任性不可认证，必须退回固定保守包络。它把「我不确定」从一阶判断升级为二阶判断：**先确认自己有没有资格谈胜任，再谈胜任。**

## 6. 本轮最大风险

**一句话**：GROUND-RAS 的全部安全性押在「胜任区估计器在真实结构性漂移下仍然可信」这一前提上——而 conformal 覆盖率依赖可交换性，真实世界的持续漂移恰恰会悄悄破坏它；一旦估计器在 OOD 上仍然自信，移动操作会让机器人**主动、加速地驶入一个虚假的「胜任区」**——**自信地走错地方，比停在原地更危险。**

**次级风险与缓解**：
1. **支撑估计的样本效率与分层偏差** → 按房间/地面类型做条件 conformal + 主动采样填补校准空白；
2. **拴绳过紧导致死锁** → 可恢复性判定 + 分层裕度（任务关键段更紧、巡航段更松）+ E307 死锁率门控；
3. **移动本身不安全**（倾覆、打滑、动态障碍）→ 定义 320 安全-胜任交集 + WBC 认证 + 定理 19；
4. **SAL 适应破坏安全** → 仅在实时环外、有界低维、证书+回滚、E311 强制验证；
5. **对抗性支撑投毒**（伪造校准集使 K_τ 变大）→ SUD 双估计器互检 + 校准集来源审计 + E316。

def encode(o, q):
    rel = relative_pose_features(o.object_pose, q.end_effector)   # G_b 不变

def support_score(q, psi):
    return 0.5*ens_disagreement(q, psi) + 0.5*knn_dist(psi, train_support)

def pvalue(s, cal_scores):
    return (1 + (cal_scores >= s).sum()) / (len(cal_scores) + 1)

def tether_depth(q, psi, H, alpha, cal_scores):
    tau = quantile(cal_scores, 1 - alpha/H)        # 逐步失败率 α/H
    return tau - support_score(q, psi)

def plan_whole_body(models, q, psi, d, H, lam_relax):

## 4. 推导

**命题 19（泛化间隙四分解）** 损失有界 `L_max`、ψ 上 `L_R`-Lipschitz，`ρ_sup=P_test(s>τ_α)`：
`R_test − R_train ≤ L_R(ε_inv + W_1^K(ψ_#P_test, ψ_#P_train)) + L_max·ρ_sup`。
要点：K 内用 Lipschitz + 三角不等式归到不变性误差与 ψ 分布距离；K 外由有界损失与 ρ_sup 界定。推论：(i) RIC 廉价攻击 ε_inv；(ii) ρ_sup 是独立可加项，模态消歧无法消除——这是第三路 U_sup 的理论 necessity；(iii) 移动/适应只降 ρ_sup，不降 ε_inv，故「先修表征，再动底盘」。

**引理 19（horizon 联合界）** 若每步用 `τ_{α/H}` 使单步逃逸 ≤ α/H，则长度 H 时域内至少一次逃逸 ≤ α。故拴绳深度须随 H 加深，或提高重规划频率。

**定理 18（静态边界严格包含 R69/R68）** 底盘冻结、无结构漂移、SUD 通过时，U_sup 通道关闭，ASR→MINT、SCOPE→R69 认证前缀、拴绳恒满足 ⇒ 逐指令等价 FLUID-RAS；且任何 λ 放松都需 SUD 认证，安全侧不弱于 R68。

**定理 19（CLF 可恢复性）** 在 `S\T` 上若 ∃ 认证 u 使 `V(f(q,u))≤(1−η)V(q)`，则从任意 `q∈S` 可在 ≤ `log(V_0/ε)/η` 步内回到 T 且保持在 S；若不存在，则任何认证控制器都无法保证返回，GROUND 判定不可恢复并执行 R69 回退。泛化失败由此变为可判定可达性问题。

**引理 20（主动寻支撑 = 移动上的 VoI）** 移动净收益 `E[Δloss] − c_m − κ r_m`；仅当 > 0 才移动，否则原地走 R69。若移动降低 d 或越出 S，即使「更接近训练集」也必须拒绝——支撑收益不能抵消安全代价。R69 的 VoI 是 `u_b=0` 特例。

**引理 21（SUD 互检界）** 两估计器有效误差各 ≤ e_A,e_B、分歧 D 时，选中估计误差 ≤ `D + min(e_A,e_B)`；`D>τ_D` ⇒ 至少一个失效 ⇒ 胜任性不可认证 ⇒ 退回固定保守包络。

## 7. 本轮最大风险

**一句话**：GROUND-RAS 的安全性押在「胜任区估计器在真实结构漂移下仍可信」上——而 conformal 覆盖率依赖可交换性，持续漂移恰恰会悄悄破坏它；一旦估计器在 OOD 上仍自信，移动操作会让机器人**主动加速驶入虚假的「胜任区」**——**自信地走错地方，比停在原地更危险。**

**次级风险与缓解**：支撑估计分层偏差（条件 conformal + 主动采样）；拴绳过紧死锁（可恢复性判定 + 分层裕度 + E307）；移动本身不安全（安全-胜任交集 + WBC + 定理 19）；SAL 破坏安全（环外、有界、回滚、E311）；对抗支撑投毒（SUD 互检 + 来源审计 + E316）。
