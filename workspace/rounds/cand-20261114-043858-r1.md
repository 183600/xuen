# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「深度学习」×「关节空间控制」）

> R69 教会系统「不确定就去问」。但它从头到尾都在一个被归一化的**任务空间**里思考：策略吐出的 ξ、似然 p_θ(ξ|o)、模态间距 Δ_min、VoI，全部是任务坐标。机器人却不是任务空间里的质点，而是一条关节链。于是有两个被忽略的事实：
>
> 1. **歧义的代价不由任务空间距离决定，而由它诱导的关节运动决定。** 在奇异位形附近，任务空间里 1mm 的两难，可能是关节空间里 30° 的一步；而在冗余构型下，任务空间里相隔很远的两条轨迹，也许只需一个零空间的小转身（肘部翻转）。R69 在错误的尺子上量不确定性。
> 2. **深度策略能生成一条任务空间里光滑、高似然、却根本不可被关节执行的轨迹。** 这不是模态幻觉，而是**动作幻觉**（phantom motion）——R69 防的是「追问一个幻影模态」，R70 要防的是「认证一个幻影动作」。
>
> 本轮两个灵感正好补上这块地基：
> - **关节空间控制**提供真正的度量与控制变量——Jacobian 诱导的有效度量、关节限位、力矩/速度约束、奇异值、零空间；
> - **深度学习**提供两个受限但强大的工具：学习**可行性/度量的廉价代理**（KFN），以及只在**零空间里**学习的残差策略（NSP）——把深度网络关进「不可能破坏任务意图」的笼子里。
>
> 核心命题：**在 R69 之下再垫一层「关节空间证书核」：深度策略负责提议，关节空间负责兑现；所有任务空间提议必须先经可实现性认证，所有不确定性度量必须搬到 Jacobian 诱导的度量下重算。** 命名 **JACO-RAS**（Jacobian-Aware Certified Operational-space risk-adaptive safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这条我打算做的动作，身体真的做得到吗**」——在关节空间里，安全不是一个标签，而是每一度、每一牛米、每一奇异值。

## 0. 直觉与动机

**灵感 1（任务空间是投影，关节空间是本体）**
直觉：把机械臂想成一个影子。任务空间是我们看到的影子，关节空间是投出影子的身体。R69 一直在影子上做决策：影子上的两个模态分得很开，就以为「歧义很大，值得问」；影子上的两个模态几乎重合，就以为「没歧义，直接做」。可是影子的距离和身体的代价之间隔着一个 Jacobian。奇异位形处，影子轻轻一动，身体要剧烈扭转（需要巨大的关节速度，可能超限）；冗余位形处，影子相距很远，身体却可以从零空间抄近路。**用影子上的尺子量身体的不确定性，会在两个方向上都错。** 这是本轮的第一性原理：不确定性有度量，而度量必须由实际执行它的坐标给出。

**灵感 2（深度学习的正确笼子：度量代理 + 零空间残差）**
直觉：完全用解析模型做关节空间证书当然最可信，但质量矩阵、摩擦、负载、接触让解析模型在真实机器人上永远有偏差；完全用心学习又不可认证。折中不是「各让一半」，而是**让深度网络承担它擅长且可被约束的部分**：
- **学习可行性/度量代理 KFN**：给定任务轨迹与条件编码，预测 σ_min(J)、关节余量、力矩余量、需要的最小修正。它取代昂贵的逐点 IK/QP 内层迭代，但输出必须经**单侧保形校准**，只能低估可行、不能高估可行（安全方向）。
- **零空间残差策略 NSP**：把可学习残差投影进 J 的零空间，`(I−J⁺J)N_ψ`。零空间残差在一阶意义上不改变任务轨迹，却可以「学会待在可认证区域」——远离奇异、靠近关节中位、保留力矩余量。这是深度学习的**安全用法**：它只能在安全的子空间里优化，而没有能力推翻任务意图。

**灵感 3（两条第二意见：动作幻觉 vs 慢漂移）**
直觉：R69 的 FMA 用「任务似然」抓被标定吸收的缓变故障。R70 需要两条**关节侧**的第二意见：
- **动作幻觉**：任务似然很高、但关节可行性似然很低 → 这条轨迹是「影子合理、身体做不到」。度量 Δ_real = a_joint − a_task。
- **漂移的先兆**：任务仍然完成得很好，但构型在缓慢滑向奇异/限位/力矩边界。任务似然看不出来，关节余量看得见。度量 Δq_drift（余量的时间导数）。
这两条正好补上 R69 第二意见在「空间维度」上的盲区：FMA 看时间上的不自洽，JSO 看空间上的不可兑现。

**灵感 4（交互本身也要过身体这一关，而且「换个姿势再看」是一种信息动作）**
直觉：R69 引入「看/问/触」作为消除歧义的动作，但这些动作也要由关节执行。注视要转头（可能触发关节限位），探针要伸手（可能经过奇异区）。更妙的是：**有时候最好的信息动作是先退半步、把手臂移出奇异区，再重新看**——改变构型本身就能降低度量扭曲 α_sing，让原本算不清的歧义变得可分。于是「交互」与「关节空间」不是两层，而是同一个决策：在哪个构型下、用什么动作、获取什么信息。定义**构型信息动作 g_reconf**，并把 R69 的 VoI 修正为「可实现 VoI」。

**灵感 5（新层必须是旧层的边界，而不是并列黑箱）**
直觉：如果 JACO 只是在 R69 旁边再加一个关节空间安全盒，那每加一层就多一个要信任的黑箱，系统会更脆。正确的姿态仍是**严格包含**：当机器人处于良态（κ(J) 小、各余量充足、不需要关节层修正）时，关节证书核的修正 δ_cert = 0，JACO 逐指令等于 R69。R69 恰好是 JACO 在「身体不构成约束」这一边界上的退化。安全侧永不变差，性能侧白赚。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（JACO-RAS 总览）** JACO-RAS = (JMD, KFN, NSP, JCB, RAG, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i——学习中只在慢环，控制环只做推理与 QP）；
(ii) **关节空间证书先行**：任何任务空间提议 ξ 在派发前必须通过 JCB 求得认证关节命令，并报告可实现余量；证不出即不执行；
(iii) **失败即退化**：可实现性不达标、证书为空、或 KFN 校准失效时，逐指令退回 R69 的保守路径，λ 单调不降。

**定义 311（双空间与约束）** 关节构型 q ∈ Q ⊂ ℝⁿ，任务坐标 x = f(q) ∈ ℝᵐ（m ≤ n），Jacobian J(q)=∂f/∂q ∈ ℝ^{m×n}。硬约束集：q_min ≤ q ≤ q_max、|q̇| ≤ v_max、|τ| ≤ τ_max、自碰撞距离 ≥ d_safe、奇异余量 σ_min(J(q)) ≥ σ0。状态可行域 𝒞 = {q : 所有约束满足}。

**定义 312（诱导有效度量）** 质量矩阵 M(q) ≻ 0。把任务位移 dx 兑现为最小关节动能的代价为
G_eff(q) = (J(q) M(q)^{-1} J(q)^T)^{-1}，
即 dq = M^{-1}J^T G_eff dx 时 ||dq||_M² = dx^T G_eff dx。对固定 q，G_eff 的特征值落在 [1/σ_max(J)²·λ_min(M)^{-1}, 1/σ_min(J)²·λ_max(M)^{-1}] 区间内（M=I 时简化为 [σ_max^{-2}, σ_min^{-2}]）。因此任务空间欧氏距离到关节代价的扭曲上界由 **条件数 κ(J)=σ_max/σ_min** 控制。定义有效距离 d_G(x,x') = inf_γ ∫ sqrt(γ̇^T G_eff γ̇) dt。

**定义 313（δ-可实现在 ℛ_δ）** 任务轨迹 ξ(t) 属于 ℛ_δ，当且仅当存在关节轨迹 q(t) 使 f(q(t))=ξ(t)、q(t)∈𝒞、且 ∫||q̇||_M dt ≤ (1+δ)·inf 关节代价。ℛ_δ 是「身体真的兑现得了」的轨迹集合。

**定义 314（可实现余量与动作幻觉）** 对任务轨迹 ξ，定义可实现余量
ρ(ξ) = min{ σ_min(J(q))−σ0, margin_q(q), margin_τ(q), collision_margin(q) : q ∈ IK(ξ)∩𝒞 }。
ρ ≥ 0 即可实现。若 ξ 在任务空间高概率、低代价，却 ρ(ξ) < 0，称 ξ 为**动作幻觉（phantom motion）**；定义幻觉间隙 Δ_real = d_G(ξ, ℛ_0)（到可实现在的距离，用有效度量）。R69 的证书只约束任务空间，故 Δ_real > 0 而 Valid(J_FLUID) 可以同时成立。

**定义 315（KFN 运动学可行性网络）** 深度网络 K_φ(ξ, z) → (σ̂_min, m̂_q, m̂_τ, ĉ_corr)，以特权 IK/QP 标签训练。它输出的是**可行性代理**，必须经单侧保形校准（定义 322）：认证余量 m̂_cert = m̂ − q̂_α，q̂_α 为非一致性分数 s = m̂ − m_true 的 (1−α) 上分位数，保证 P(m_true ≥ m̂_cert) ≥ 1−α。**只允许低估可行，绝不低估不可行。**

**定义 316（关节度量扭曲 JMD）** 把 R69 的模态统计搬到有效度量下：模态间距离用 W_2^G（G_eff 诱导的 Riemannian Wasserstein），模态内方差用 tr_G(Σ_k)。定义两个扭曲因子：α_sing = d_G/d_task（奇异放大，任务低估关节代价）与 α_red = d_task/d_G（冗余别名，任务高估关节代价，例如肘部翻转使两个远处任务模态对应近处关节构型）。R69 的 Δ_min、U_epi、VoI 仅在 α_sing ≈ α_red ≈ 1 时成立；否则须重算。

**定义 317（可实现 VoI）** 信息动作 g 的价值必须扣除「它自己能不能被兑现」：VoI_ℛ(g) = VoI_G(g) · 1[g ∈ ℛ_δ]，其中 VoI_G 用 G_eff 度量下的后验熵计算（一个模态被「消解」指交互后其 G-间距超过阈值）。选择 g* = argmax_g [VoI_ℛ(g) − c_G(g)]，c_G(g) 含关节行程与社交/物理成本。

**定义 318（零空间残差策略 NSP）** 关节速度 q̇ = J⁺(q) ẋ_d + (I − J⁺J) N_ψ(z, q, ẋ_d)，其中 N_ψ 为有界学习残差，||N_ψ|| ≤ η，J⁺ 用阻尼最小二乘（阻尼 λ_d 保证 ||J⁺|| 有界）。一阶上零空间分量不改变任务速度；N_ψ 的学习目标是最大化奇异余量/关节中位/力矩余量，即「学会待在可认证区域」。深度网络被投影算子关进笼子。

**定义 319（关节空间证书核 JCB）** 在每个控制周期解
min_{q̇} ||q̇ − q̇_ref||_M²  s.t.  ġ_joint-limit + α h_joint-limit ≥ 0, |q̇|≤v_max, |τ(q,q̇,q̈)|≤τ_max, collision ≥ d_safe, ḣ_sing + α_s h_sing ≥ 0（h_sing=σ_min(J)−σ0）。
返回 (q̇_cert, δ_cert = ||q̇_cert − q̇_ref||, margin 向量)。若 QP 不可行（证书为空），返回 None 并触发预计算的安全回退 q̇_backup，**不返回半可行解**。

**定义 320（可实现性门 RAG）** 若 q̇_cert = None、δ_cert > ε_cert、或 min(m̂_cert) < margin0，则拒绝 ξ：λ ← max(λ, λ_floor(U_ale + U_epi))，执行安全回退，且本轮不信任由该 ξ 驱动的交互结论。接受则派发 q̇_cert。RAG 记录 (δ_cert, Δ_real, α_sing, α_red) 供审计。

**定义 321（关节空间第二意见 JSO）** 定义任务似然 a_task = −log p_θ(ξ|o) 与关节可行性似然 a_joint = −log p_feas(ξ|o)（由 KFN 与约束裕度构造）。动作幻觉分 Δ_real_lik = a_joint − a_task；漂移分 Δq_drift = −min(ḣ_margin)（余量下降最快方向）。判据：**a_task 低而 a_joint 高 ⇒ 动作幻觉**；**任务似然低但余量仍正且持续下降 ⇒ 慢漂移先兆**。二者与 R69 的 FMA 正交：FMA 测时间自洽，JSO 测空间可兑现。

**定义 322（度量校准门 LMC）** KFN 与 G_eff 代理须做单侧保形校准：在标定集上收集 s=m̂−m_true，取 (1−α) 上分位数 q̂_α；在线用 m̂_cert=m̂−q̂_α。若在线覆盖率跌破 1−α−ε_cov，或分布漂移检测触发，则**禁用 NSP 与 KFN 认证**，退化为「解析证书 + R69 纯保守」。这是 R69 MCG 在「可行性通道」上的镜像：不让不可信的可行性代理签发通行证。

**定义 323（构型信息动作与交互-可实现对偶）** 在 R69 的 𝒜_info 上增加 g_reconf ∈ 𝒬_adm（在 𝒞 内的小幅重配置，位移 ≤ ε_g）。它不直接答问题，而是把构型移到 κ(J) 更小、σ_min 更大的位置，从而降低 α_sing、放大真正的模态可分性。定义对偶：**先问「是否值得问」之前，先问「当前构型下问得清吗」**；若 α_sing 超过阈值，优先 g_reconf，再执行 R69 的看/问/触。g_reconf 与所有信息动作一样必须过 JCB。

**定义 324（时序分层与自适应精度）** 感知/流策略/ KFN 在慢环（约 100Hz）；JCB 在控制环（1kHz）；G_eff 用质量矩阵解析式 + KFN 修正。仅当 RAG 拒绝率上升或 α_sing 超阈时，慢环才升精度（重算 IK 分支/加密采样），保证 P99 实时预算。

**定义 325（参与式审计 VQAuditor-J）** 审计对象新增：提议是否因不可实现被正确拒绝、NSP 是否越出零空间/有界假设、KFN 是否高估可行、是否对幻影动作发起追问、g_reconf 是否越界。结论回灌 AuditBuf，成为下一轮 RAG 阈值与 LMC 先验。

**定义 326（证书 J_JACO）** J_JACO = (J_FLUID, σ_min^p05, margin_q^min, margin_τ^min, δ_cert_p99, Δ_real_p95, α_sing, α_red, LMC_coverage, jaco_ver)。Valid ⇔ Valid(J_FLUID) ∧ LMC_coverage ≥ 1−α−ε_cov ∧ 所有 margin ≥ 0 ∧ δ_cert_p99 ≤ ε_cert ∧ 证书非空。

## 2. 关键算法骨架

```python
# IP-265 KFN：运动学可行性网络（单侧保形校准，只许低估可行）
class KinematicFeasibilityNet:
    def __init__(self, net, q_alpha):
        self.net, self.q_alpha = net, q_alpha          # q_alpha = 非一致性上分位数
    def predict(self, xi, z):
        return self.net(xi, z)                         # (sigma_min, m_q, m_tau, corr)
    def certified_margin(self, xi, z):
        return self.predict(xi, z) - self.q_alpha      # 保守下界

# IP-266 NSP：零空间残差（深度学习被投影算子关进笼子）
def null_space_residual(q, xdot, z, J, J_pinv, N_psi, eta):
    r = N_psi(z, q, xdot)
    r = eta * r / max(eta, norm(r))                    # 有界 ||r|| <= eta
    return (eye(len(q)) - J_pinv @ J) @ r              # 一阶不改任务速度

# IP-267 JCB：关节空间证书核（1kHz QP / CBF）
def joint_certificate(q, qdot_ref, J, M, limits):
    H = M
    rows, rhs = cbf_rows(q, J, limits)                 # 限位/速度/力矩/自碰撞/奇异 CBF
    qdot = solve_qp(H, -M @ qdot_ref, rows, rhs)
    if qdot is None:
        return None, INF                               # 空证书 -> 安全回退，绝不派发半解
    return qdot, norm(qdot - qdot_ref)

# IP-269 JSO：关节空间第二意见（与 R69 的 FMA 正交）
def joint_second_opinion(kfn, policy, xi, o, z):
    a_task  = -policy.log_likelihood(xi, o)            # 时间/行为自洽
    a_joint = -kfn.feasibility_loglik(xi, z)           # 空间可兑现
    return a_joint - a_task, kfn.margin_derivative(z)  # 动作幻觉分 / 漂移先兆

# IP-275 主闭环（在 R69 的 ξ 与执行之间插入关节证书层）
def JACO_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    # ---- R69 层：多模态提议 + 交互，但度量已搬到关节空间 ----
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    G = M.jmd.effective_metric(o)                      # G_eff，来自 J、M，KFN 修正
    U_ale, U_epi, modes, _ = M.aud.decompose_G(samples, z, G)
    g = M.mint.choose_realizable(modes, o, M.budget, M.kfn, M.jcb)  # 可实现 VoI
    if g is not None:
        U_epi = M.cia.update_belief(modes, M.cia.execute_cert(g))
    # ---- JACO 层：把任务提议兑现为关节命令 ----
    xi = select_mode(modes, U_epi, M.efs.risk_scale(...))   # 仍是任务空间提议
    m_hat = M.kfn.certified_margin(xi, z)                    # 保守可行性下界
    J = M.jacobian(q)
    qdot_ref = M.ik.resolve(xi, q)                           # 冗余/零空间初值
    qdot_ref = null_space_residual(q, qdot_ref, z, J, M.pinv(J), M.nsp, M.eta)
    qdot_cert, delta = M.jcb.solve(q, qdot_ref, J, M.mass(q), M.limits)
    # ---- RAG：兑现不了就逐指令退回 R69 保守 ----
    if qdot_cert is None or delta > EPS_CERT or min(m_hat) < MARGIN0:
        lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi))
        qdot_cert = M.backup.safe_retreat(q)                  # 预计算安全回退
        M.vqa_j.log_reject(xi, delta, m_hat)
    else:
        lam = max(M.efs.risk_scale(...), lam_floor(U_ale))
    tau = M.inverse_dynamics(q, qdot_cert) * lam
    # ---- 审计与证书 ----
    M.vqa_j.submit_async(xi, qdot_cert, delta, m_hat,
                         M.jso.score(xi, o, z))
    return tau, lam, (U_ale, U_epi), M.jaco_cert(...)
```

## 3. 推导

**引理 19（度量扭曲界）** 设 M(q)=I，有效度量 G_eff=(JJ^T)^{-1}。对任意任务微元 dx，关节代价 dx^T G_eff dx 与任务欧氏代价 ||dx||² 的比值落在 [σ_max(J)^{-2}, σ_min(J)^{-2}]，故相对扭曲因子有界：1 ≤ α_sing ≤ κ(J)=σ_max/σ_min。M 非常数时再乘 √(λ_max(M)/λ_min(M))。**系：R69 在任务空间算出的 Δ_min 与 VoI，一旦用关节代价衡量，误差最坏可达 κ(J) 倍；当 κ(J)≈1（良态）时误差为零，R69 恰好正确。**

**引理 20（任务安全 ≠ 关节安全：动作幻觉存在）** 取平面二连杆，工作点使 σ_min(J)→0（肘近伸直）。构造任务轨迹 ξ，使它在任务空间始终位于半径 ε 的管道内（任务空间安全、流似然高），但穿越奇异邻域需要关节速度 ||q̇|| ≥ ||ẋ||/σ_min(J) > v_max。于是 ρ(ξ)<0 而 Valid(J_FLUID) 成立。**系：J_FLUID 不是关节可行性的充分证书，必须新增 J_JACO；两类证书不可互相替代。**

**引理 21（零空间残差有界性）** 阻尼伪逆满足 ||J⁺|| ≤ 1/(2√λ_d)，故 ||q̇|| 有界；零空间投影 ||(I−J⁺J)|| ≤ 1，残差 ||(I−J⁺J)N_ψ|| ≤ η。任务速度偏差一阶为 0，二阶偏差 ≤ O(η²/σ_min)。**系：NSP 无法推翻任务意图；但在 σ_min→σ0 的边缘，二阶项放大，故必须在 JCB 的奇异余量约束内使用 NSP，而不是拿它去「救」奇异区。**

**引理 22（保形可行性的单侧保证）** 令非一致性分数 s=m̂−m_true。交换性下，取标定集 (1−α) 上分位数 q̂_α，则 P(m_true ≥ m̂−q̂_α) ≥ 1−α。RAG 用 m̂_cert=m̂−q̂_α 与阈值 margin0 判定，故误收（把不可行当可行）概率 ≤ α，漏收（把可行当不可行）只损失效率、不损安全。**系：KFN 的深度误差被转化为单侧、可量化、可审计的安全预算。**

**定理 18（JACO 严格包含 R69）** 在 A99–A101（质量矩阵有界、J 连续、KFN 校准有效）下，JACO 的每步期望风险 ≤ R69；且当 κ(J) ≤ κ0、所有余量 ≥ margin0、δ_cert=0、且 α_sing≈α_red≈1 时，JACO 与 R69 **逐指令相同**。由于引理 20 给出了 R69 可行而 JACO 拒绝的状态，包含是严格的：JACO 在良态退化为 R69，在病态严格更安全。

**定理 19（可实现交互与无突变）** 所有信息动作（含 g_reconf）经 JCB 认证，物理风险 ≤ ε_int 且不改变任务安全包络；可实现 VoI 只在交互动作本身可兑现时非零，故交互不会把系统推向不可实现区；KFN/LMC 失效、证书为空或 RAG 拒绝时，λ 单调不降地退化为 R69，且阻尼伪逆与 QP 解连续（或由预计算 backup 接管），控制无突变。**系：R69 的「诚实的不知道」不会被升级成「被认证的错误动作」。**

## 6. 本轮最大风险

**一句话**：JACO 把「可认证」从任务空间搬到了关节空间，但**认证的权威来自 KFN 这个深度代理与解析模型（质量矩阵/摩擦/负载）的准确性**——一旦 KFN 在分布漂移下高估可行（或质量矩阵/力矩模型失配），RAG 就会放行一个**被盖章的幻影动作**，这比 R69「诚实的不知道」更危险；我们没有消灭幻影，只是把它从影子搬到了身体里。

**次级风险与缓解**：
1. **证书为空导致死锁**（贴限位/奇异边缘 QP 不可行）→ 预计算安全回退 + 收缩可行域 + 定义 319 绝不返回半解；
2. **KFN 分布外高估** → 单侧保形 + LMC 覆盖率门控 + 越界即退回解析+纯保守；
3. **NSP 在奇异边缘二阶放大** → 奇异余量约束内使用 + 有界残差 + 引理 21；
4. **深度可行性代理本身是黑箱** → 只让它做「廉价排序/下界」，硬约束仍由解析 CBF/QP 签署；
5. **度量代理误差污染 VoI** → α_sing/α_red 显式记录并审计，ECE/覆盖率越界即禁用交互。

## 3. 关键算法伪代码

```python
# IP-265 KFN：单侧保形可行性代理（只许低估可行）
class KinematicFeasibilityNet:
    def __init__(self, net, q_alpha): self.net, self.q_alpha = net, q_alpha
    def predict(self, xi, z): return self.net(xi, z)
    def certified_margin(self, xi, z): return self.predict(xi, z) - self.q_alpha

# IP-266 NSP：零空间残差（深度学习被投影算子关进笼子）
def null_space_residual(q, xdot, z, J, J_pinv, N_psi, eta):
    r = N_psi(z, q, xdot); r = eta * r / max(eta, norm(r))
    return (eye(len(q)) - J_pinv @ J) @ r              # 一阶不改任务速度

# IP-267 JCB：关节空间证书核（1kHz QP / CBF）
def joint_certificate(q, qdot_ref, J, M, limits):
    rows, rhs = cbf_rows(q, J, limits)                # 限位/速度/力矩/自碰撞/奇异 CBF
    qdot = solve_qp(M, -M @ qdot_ref, rows, rhs)
    if qdot is None: return None, INF                 # 空证书 -> 回退，不派发半解
    return qdot, norm(qdot - qdot_ref)

# IP-269 JSO：关节空间第二意见
def joint_second_opinion(kfn, policy, xi, o, z):
    a_task  = -policy.log_likelihood(xi, o)
    a_joint = -kfn.feasibility_loglik(xi, z)
    return a_joint - a_task, kfn.margin_derivative(z)

# IP-275 主闭环（在 R69 的 ξ 与执行之间插入关节证书层）
def JACO_RAS_round(M, obs):

    G = M.jmd.effective_metric(o)                     # G_eff

    g = M.mint.choose_realizable(modes, o, M.budget, M.kfn, M.jcb)
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute_cert(g))
    xi   = select_mode(modes, U_epi, M.efs.risk_scale(...))
    m_hat = M.kfn.certified_margin(xi, z)
    J    = M.jacobian(q)
    qref = null_space_residual(q, M.ik.resolve(xi, q), z, J, M.pinv(J), M.nsp, M.eta)
    qdot, delta = M.jcb.solve(q, qref, J, M.mass(q), M.limits)
    if qdot is None or delta > EPS_CERT or min(m_hat) < MARGIN0:
        lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi))
```

## 4. 推导

**引理 19（度量扭曲界）** M=I 时 G_eff=(JJᵀ)⁻¹；任务微元 dx 的关节代价与 ‖dx‖² 之比 ∈ [σ_max⁻², σ_min⁻²]，故 1 ≤ α_sing ≤ κ(J)（非常数 M 再乘 √(λ_max(M)/λ_min(M))）。系：R69 的 Δ_min/VoI 用关节代价衡量最坏错 κ(J) 倍；κ(J)≈1 时为零，R69 恰正确。

**引理 20（任务安全≠关节安全）** 平面二连杆近肘直（σ_min→0）时，管道内任务轨迹仍需 ‖q̇‖≥‖ẋ‖/σ_min>v_max，故 ρ<0 而 Valid(J_FLUID) 成立。系：J_FLUID 非关节可行性的充分证书，必须新增 J_JACO。

**引理 21（零空间残差有界）** 阻尼伪逆 ‖J⁺‖≤1/(2√λ_d)，‖(I−J⁺J)‖≤1，故 ‖(I−J⁺J)N_ψ‖≤η；任务速度偏差一阶为 0、二阶 ≤O(η²/σ_min)。系：NSP 无法推翻任务意图，但需在奇异余量约束内使用，不能用它「救」奇异区。

**引理 22（保形可行性单侧保证）** s=m̂−m_true 的 (1−α) 上分位数 q̂_α 满足 P(m_true≥m̂−q̂_α)≥1−α；RAG 用 m̂_cert 判定，误收 ≤α，漏收只损效率。系：KFN 深度误差被转化为单侧、可量化、可审计的安全预算。

**定理 18（JACO 严格包含 R69）** A99–A101 下 JACO 每步期望风险 ≤ R69；当 κ(J)≤κ0、全 margin≥margin0、δ_cert=0、α≈1 时逐指令相同。由引理 20 存在 R69 可行而 JACO 拒绝的状态，故包含严格：良态退化为 R69，病态严格更安全。

**定理 19（可实现交互与无突变）** 所有信息动作（含 g_reconf）过 JCB，物理风险 ≤ε_int 且不改任务安全包络；可实现 VoI 仅当信息动作自身可兑现时非零；KFN/LMC 失效、证书为空或 RAG 拒绝时 λ 单调不降地退化为 R69，阻尼伪逆与 QP 解连续（或 backup 接管），控制无突变。

## 7. 本轮最大风险

**一句话**：JACO 把「可认证」从任务空间搬到关节空间，但**认证权威依赖 KFN 深度代理与解析模型（质量矩阵/摩擦/负载）的准确性**——KFN 一旦在分布漂移下高估可行（或模型失配），RAG 就会放行一个**被盖章的幻影动作**，这比 R69「诚实的不知道」更危险；我们没有消灭幻影，只是把它从影子搬进了身体。

**次级风险与缓解**：证书为空死锁（预计算安全回退 + 收缩可行域 + 绝不返回半解）；KFN 分布外高估（单侧保形 + LMC 覆盖率门控 + 越界退回解析纯保守）；NSP 奇异边缘二阶放大（奇异余量约束内使用 + 有界残差）；可行性代理黑箱（仅做廉价下界/排序，硬约束由解析 CBF/QP 签署）；度量代理误差污染 VoI（α_sing/α_red 显式记录，越界即禁用交互）。
