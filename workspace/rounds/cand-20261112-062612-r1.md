# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「腕部相机」×「可靠性」）

> 第 57 轮把可信从"模型置信"推进到"证据质量"，并用 MFSL/XMC/PTM 分别补上少样本校准、跨模态对账与个性化信任。但它留下一个更隐蔽的盲点：**所有证据都被当作"已经取到手的观测"来评估，却没人追问这份观测是在什么仪器状态、什么视角、什么采集策略下取得的。** 「腕部相机」把这个盲点具象化：它是唯一贴着执行器、随动作移动、在最后一厘米做见证的传感器——它既能在接触前"看见"，也因此把**手眼校准误差、运动模糊、遮挡、反光、镜头污染，以及"只看向自己想看的地方"的选择偏差**全部带进证据链；而「可靠性」提醒我们，可靠性从来不是传感器的静态标签，而是**取证事件在特定上下文中的属性**，并且会随使用退化、会共因失效、会被自证污染。本轮因此不新增一个"感知模块"，而是把证据体系从"证据是否可信"升级为"**这份证据由谁、在何种校准与可靠性状态下、按何种采集策略取得，因而可以被相信到什么程度**"：**(1)** 腕部证据必须挂**可观测性证书**——只能为视觉可达的属性作证，绝不能替代对隐藏力学性质的接触测量；**(2)** 手眼校准成为一等可靠性状态，误差协方差沿证据链传播，校准失验则证据自动降级；**(3)** 可靠性估计须做**采集策略倾向校正**并保留"反证凝视"预算，防止"不看风险所以显得安全"；**(4)** 可靠性按退化/共因建模并进入任务级可靠性预算，触发 **fail-operational 降级阶梯**而非二元信任。核心命题升级为 **"取证可归因、仪器可校准、可靠性有下界的证据承诺"**。

核心矛盾：
- **H29（可见 ≠ 可证）**：腕部相机在接触前提供了海量、廉价、非破坏的视觉证据，但"看起来安全"正是透明冰面、伪装材质、镜面反光最擅长制造的错觉；把视觉观测升格为承诺证据，等于用外观为隐藏力学性质背书。
- **H30（校准是共因）**：所有腕部视觉证据都继承同一个手眼变换误差；一旦校准漂移，多目/多模态"相互印证"会一起错——第 57 轮 A38 的条件独立假设在共因面前失效，冗余并不自动带来可靠性。
- **H31（可靠性内生）**：看哪里由策略决定，可靠性又只能用策略采到的数据估计——策略可以"回避风险区"来刷高可靠性；可靠性估计器同时是被告与法官。
- **H32（降级 vs 可用）**：可靠性低就保守会滑向"可靠性崩塌"（永远不敢动），可靠性低却照常行动则把风险藏在仪表里；需要可运营的降级阶梯与可偿还的可靠性债务，而不是二元开关。

## 0. 直觉与动机

**灵感 1（腕部相机 → 最后一厘米的见证者与"可观测性"闸门）**
直觉：腕部相机是机器人的"手眼"，它贴着即将接触的表面，能在不可逆接触发生前看清对象身份、位姿、接近间隙、遮挡与表面纹理，甚至见证接触瞬间。这让它成为最便宜的**非破坏性预接触证据**。但"看见"不等于"证成"：视觉能因果地触达的是几何与外观，触达不到刚度、摩擦、承载这些隐藏力学量；而外观恰恰是最容易被透明、反光、伪装欺骗的通道。于是本轮给腕部证据加一道**可观测性证书**：只有当属性落在视觉的因果可达域内、且观测视锥未被夹爪/负载遮挡时，腕部证据才能作为承诺证据；对隐藏力学属性，它只能作为"**去哪里探、怎么探**"的先验，永远不能顶替那一次真正测到它的接触。这把"证据替代"从"跨模态一致即可"收紧为"可观测才可替代"。

**灵感 2（可靠性工程 → 可靠性是取证事件的属性，会退化、会共因）**
直觉：传统可靠性工程不看"这个零件好不好"，而看"在给定应力剖面下，它在任务窗口内失效的概率"。把它搬到证据上：一条证据的可靠性取决于**取证时刻的仪器健康、环境应力、运动状态与校准版本**，而不是"视觉"这个标签。镜头被油污、线缆磨损、热漂移、碰撞后的手眼偏移，都是**退化过程**；而所有视觉通道共享同一套标定、光照与安装，是典型的**共因失效**。因此 ρ 不再是一个模态常数，而是一个带生存曲线与共因因子的状态：融合两个共享共因的通道，其有效可靠性有上界，冗余不能凭空制造独立证据。相应地，系统维护一份**任务级可靠性预算**，可靠性跌破阈值时沿 fail-operational 阶梯降级（全速→减速加佐证→仅接触→安全停）。

**灵感 3（手眼校准 → 仪器的可靠性沿证据链传播）**
直觉：腕部相机的每一句"物体在 (x,y,z)"都要先经过手眼变换 T_{h→c}。校准一旦漂移，所有视觉证据会**一致地、安静地**偏掉——这比随机噪声危险得多，因为它自洽。于是把校准状态 c=(T̂,Σ_c,上次校验时刻,漂移风险) 作为一等公民：像素误差经雅可比传播成决策协方差，Σ_c 大时"高精度"结论直接不成立；超过校验视界或接触残差检验失败，则腕部证据被限幅。反过来，每一次**真实接触**（力/位觉给出独立的接触点）都是一次天然的校准校验：预测接触点与实测接触点之差，就是手眼误差的可观测量。腕部相机因此不只是传感器，也是**自校准的审计工具**——但必须用力/位觉而非腕部相机自身来定义"实测"，否则就是用尺子校验尺子。

**灵感 4（内生取证 → 倾向校正与反证凝视）**
直觉：机器人不会均匀地看世界，它看向任务相关处。用这种**策略选择过的**数据估计可靠性，会系统性高估——因为风险区往往正是它回避去看的地方（幸存者偏差/选择偏差）。所以可靠性估计必须按采集策略做**逆倾向加权**，并在每次任务中保留一个**反证凝视预算 k_dis**：专门去看当前信念认为"安全"的地方，用主动证伪来给可靠性估计纠偏。这不是普通的主动感知——普通主动感知为"确认任务可行"而看，反证凝视为"尝试推翻自己的安全信念"而看，两者的最优视角常常相反。配套地，决策只用可靠性的**置信下界 ρ_LB**，不用点估计；并记录"可靠性债务"——在未校验仪表上运行所累积的未偿付风险，必须由后续审计偿还。

**灵感 5（合流 → 取证上下文进入证据门，算子 RPC）**
直觉：第 57 轮的证据门问"是哪一类证据"；本轮证据门追加问"**这份证据的取证上下文是否允许它作证**"。EV-wrist 需同时满足可观测性证书、校准有效、ρ_LB≥阈、视锥无遮挡；EV-contact-truth 只能用于校验仪表与其它模态，不能反过来证明它自己参与测量的那个命题（反循环）；一切证据携带溯源四元组 (来源, 校准版本, 采集策略/倾向权重, ρ_LB)。算子 RPC 在探询前先做"仪表体检"，用腕部相机缩小"去哪里探"的搜索，用接触事件偿还可靠性债务，并在可靠性跌破阶梯阈值时切换到更保守的运营模式。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（取证事件与可观测性证书 OEC）** 取证事件 e=(m,v,t,a,c)：模态/视角与视锥/时刻/动作上下文/校准状态。属性集 P=P_vis∪P_hid（外观几何 vs 刚度/摩擦/承载等隐藏力学量）。可观测性证书 OEC(p,m,ctx)∈{0,1} 为真仅当 p∈P_vis、p 在 m 的因果可达域、且视锥扣除遮挡体后覆盖目标。腕部证据作承诺证据的必要条件：OEC=1 ∧ 校准有效 ∧ 无遮挡。对 p∈P_hid，腕部证据只允许进入"探针选择先验"π_prior，禁止进入承诺证据集。**负证据（不存在/无障碍）** 仅在自由视锥 𝔽_free=𝔽_view∖Occluders 内、且深度不确定度 ≤ε_d 的体素上有效，视锥外与遮挡后一律记为"未知"而非"安全"。

**定义 140（手眼校准可靠性状态 CAE）** c=(T̂_{h→c},Σ_c,t_verify,λ_cal)，Σ_c 为手眼变换协方差，λ_cal 为漂移风险率。任一腕部导出量 y=f(T̂,·) 的协方差 Σ_y=J_f Σ_c J_fᵀ+Σ_sensor。校准有效域：t−t_verify≤T_cal ∧ 接触残差检验 r_cal=‖p̂_contact−p_contact^FT‖_{Σ}≤θ_cal。失验则腕部证据可靠性限幅 ρ_wrist≤ρ_stale 且禁止支撑高精度几何断言（如紧配合抓取）。接触自校准：以力/位觉的独立接触点为真值，最小化预测残差更新 T̂ 与 Σ_c；腕部相机不得参与定义该真值（反循环）。

**定义 141（内生可靠性与反证凝视 ERE）** 采集策略 π_gaze(o|ctx) 选择视角。可靠性估计须倾向校正：ρ̂_m=Σ_i w_i·1[correct_i]/Σ_i w_i，w_i=clip(1/π_gaze(o_i),1,w_max)；决策使用下界 ρ_LB=LCB_α(ρ̂_m)。反证凝视预算 k_dis：每任务强制以 argmax_o ¬Belief(safe|o)（最可能推翻当前安全信念的视角）取证，其数据进入可靠性审计集而非任务成功统计。定义**回避偏差** β_avoid=ρ̂(π_gaze)−ρ̂(π_uniform/adversarial)；β_avoid>θ_avoid 时可靠性估计不可用于放宽任何阈值。

**定义 142（可靠性退化、共因与预算 HBM）** 每源生存函数 R_m(t)=exp(−∫_0^t λ_m(s)ds)，λ_m 含婴儿期/随机/耗损三段（bathtub）。共因因子 κ_cc∈[0,1] 刻画共享校准/光照/安装的耦合；共因校正融合的可靠性上界 ρ_fuse^cc≤1−κ_cc·(1−∏_m ρ_m)。任务可靠性预算 B_rel=Σ_τ cost_rel(mode_τ)；债务 D_rel 在未校验仪表上运行时累积，经审计/接触校验偿还。降级阶梯：M0 全速 → M1 减速+加佐证 → M2 仅接触证据 → M3 安全停；转移仅由 R_m/ρ_LB/D_rel 触发，且降级实时、升级有据有界（沿用 IP-135 单向性）。

**定义 143（取证上下文证据门 RBG 与证书 J_r）** 证据类 EV-probe*/visit/margin/xmodal/human 之上新增 **EV-wrist**（腕部预接触证据，须 OEC=1 ∧ c 有效 ∧ ρ_LB≥θ_wrist ∧ 𝔽_free 内）与 **EV-contact-truth**（接触事件作校验标签；不得自证）。每条证据携带溯源四元组 prov=(m,c.version,π_gaze/倾向权重,ρ_LB)。规则：(G1) 无 prov 或 prov 不可信 ⇒ 拒；(G2) EV-wrist 不得单独满足不可逆接触必要证据集；(G3) 负证据仅在 𝔽_free 内有效，遮挡记为未知；(G4) ρ_LB<θ 的证据可作探针先验不可作承诺证据。不可逆接触必要证据集 = (EV-probe*∨EV-margin) ∧（若涉及隐藏力学量则强制实测）∧ 佐证；EV-xmodal/EV-wrist 仅限 L1。J_r 继承 J_p，另加 (c 版本与 Σ_c, 接触残差序列, π_gaze 与倾向权重, R_m/λ_m 与 B_rel, κ_cc, k_dis 记录, 降级模式轨迹, D_rel)。

**定义 144（可靠性感知探-诺-演算子 RPC / PCE+++）** 每检查点：①**仪表体检**：检查 c 有效性、ρ_LB、R_m 与 D_rel，必要时进入/退出降级模式；②**腕部预视**：在 OEC 约束下用腕部相机缩小探针搜索空间、判定 𝔽_free，产出 π_prior 而非证据；③**探询**：VOI_元悲观 叠加"隐藏量不确定性降低量"，探针须非破坏（继承 A34）；④**接触校验**：接触事件更新 T̂、Σ_c 与 ρ（反循环：不用该证据自证）；⑤**承诺** ⇔ ∃g:R≤δ_f ∧ RBG 通过；否则绕行→降级模式重试→L2 协商（τ_int(auth)）→安全停；⑥**反证凝视**：每任务至少执行 k_dis 次，结果入审计账。终止：探针 ≤k_probes+k_cons，反证 ≤k_dis，模式有限。

## 2. 关键算法伪代码（完整版见产物区）

```python
def wrist_precontact_evidence(r, obj, c, policy, M):      # IP-139/140
    if not calib_valid(c) or c.rho_lb < THETA_WRIST:      # 仪器失验/可靠性不足
        return None, prior_only(r, obj)                   # 只作探针先验
    v = policy.next_view(r, obj)                          # 采集策略选视角
    free = frustum(r, v) - occluders(r, obj, gripper)     # 负证据仅在自由视锥
    obs = capture(v)
    if not OEC(obj.target_prop, 'wrist', ctx(r)):         # 隐藏力学量不可见
        return None, prior_only(r, obj)
    return Evidence('EV-wrist', prov=('wrist', c.version, policy.w(v), c.rho_lb),
                    free=free, geom=propagate_cov(obs, c)), None

def contact_self_cal(c, p_contact_ft, p_contact_pred, audit):  # IP-140 反循环
    r = whitened_residual(p_contact_pred, p_contact_ft, c.Sigma)  # 力/位觉为真值
    c.T, c.Sigma = kalman_update(c.T, c.Sigma, r)
    if norm(r) > THETA_CAL: c.t_verify = now(); audit.flag('recalibrate')
    c.rho_lb = reliability_lcb(update_reliability(c, r))     # 更新仪器可靠性
    return c

def reliability_estimate(streams, policy):                 # IP-141 倾向校正
    rho = sum(w(o) * correct(o) for o in streams) / sum(w(o) for o in streams)
    lcb = lower_confidence_bound(rho, n_eff(streams))
    beta = rho_policy - rho_uniform(streams)              # 回避偏差
    return lcb, beta

def degrade_step(mode, R, rho_lb, D_rel):                 # IP-142 fail-operational
    if rho_lb < THETA_M2 or D_rel > B_rel: return 'M2'
    if rho_lb < THETA_M1: return 'M1'
    return mode
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| OEC | O(\|𝔽\|·\|Occl\|) | O(\|𝔽\|) | 隐藏量不可替代、负证据限自由视锥 |
| CAE | O(1)+O(d_c²) 传播；O(N_contact) 自校准 | O(d_c²) | Σ_c 传播、失验限幅、反循环 |
| ERE | O(N_stream·d_o) | O(N_stream) | 倾向权重截断、LCB、β_avoid |
| HBM | O(1)/更新 | O(\|ℳ\|) | 共因上界、预算与债务守恒 |
| RBG | O(\|σ\|) | O(\|σ\|) | 溯源完整、EV-wrist 限 L1、不单独满足不可逆 |
| RPC | O(\|CP\|·(k_p+k_c+k_dis)·(C_VOI+d_φ)) | O(\|V\|+\|σ\|) | 仪表体检先于承诺、终止有界 |

**正确性定理（EPRS 概要）**：在 A33–A40 上加 (A41) OEC 诚实且隐藏力学量必经实测；(A42) 校准状态误差有界、失验限幅、接触自校准用独立力/位觉真值；(A43) 倾向校正与 ρ_LB 诚实、反证凝视预算被执行；(A44) 退化/共因模型保守、降级阶梯 fail-operational 且债务守恒。则：(i) 承诺失效率 ≤ δ_f+ε_meta+δ_probe+ε_h+δ_ood·α_conf+δ_xm+δ_wrist+δ_cal+δ_rel；(ii) 可靠性单调性：腕部证据、校准更新与可靠性估计只能经 (a) 缩小探针搜索、(b) 提供带下界的校验、或 (c) 触发更保守模式影响系统，不存在"看得更清反而更敢赌"的路径；(iii) RPC 在 k_probes+k_cons+k_dis 内终止于 {承诺, 绕行, 降级, L2, 安全停}。

## 6. 本轮最大风险

**一句话**：本轮把证据的可信度押在"仪器自报的可靠性"上——若手眼校准校验与可靠性估计都依赖同一路被污染或共因失效的感知（尤其用腕部相机去校验腕部相机），系统会以高度自洽的方式"自信地失准"；因此必须以独立力/位觉接触作为校准真值、失验即限幅、EV-wrist 不得单独支撑不可逆接触、可靠性只用置信下界并保留审计隔离，宁可承认"仪表未知"，绝不把自证当成证据。

### IP-139 OEC（腕部预接触证据与可观测性闸门）

```python
def wrist_precontact_evidence(M, r, obj, c, policy):
    ctx = region_context(r, M)
    if not calib_valid(c):                                # 校准失验 → 不作证据
        return None, prior_only(r, obj)
    v = policy.next_view(r, obj)                          # 采集策略选视角
    view = frustum(r, v)
    free = view - occluders(r, obj, gripper_of(M))        # 负证据限自由视锥
    obs = capture(v)
    prop = obj.target_prop
    if prop in P_HID:                                     # 隐藏力学量：不可替代
        return None, prior_only(r, obj, hint=appearance_prior(obs))
    if not OEC(prop, 'wrist', ctx):                       # 属性不在视觉因果可达域
        return None, prior_only(r, obj)
    if c.rho_lb < THETA_WRIST:                            # 仪器可靠性不足
        return None, prior_only(r, obj)
    geom = propagate_cov(obs, c)                          # Σ_y = J Σ_c Jᵀ + Σ_sensor
    ev = Evidence('EV-wrist', prov=('wrist', c.version, policy.w(v), c.rho_lb),
                  free=free, geom=geom)
    return ev, None

def absence_evidence(free, occupancy, eps_d):
    # 负证据：只在自由视锥内、深度不确定度达标的体素上成立
    certified = {vx for vx in free
                 if occupancy[vx].depth_sigma <= eps_d and not occupancy[vx].occupied}
    unknown = free - certified
    return Evidence('EV-absence', region=certified, unknown=unknown)  # unknown≠safe
```

### IP-140 CAE（校准状态、误差传播与接触自校准）

```python
def propagate_cov(y_fn, c, obs_sigma):
    J = jacobian(y_fn, c.T)                               # ∂y/∂T
    return J @ c.Sigma @ J.T + obs_sigma

def calib_valid(c, now):
    fresh = (now - c.t_verify) <= T_CAL
    return fresh and c.r_cal_last <= THETA_CAL and c.rho_lb >= RHO_STALE_MIN

def contact_self_cal(c, p_pred, p_ft, audit):
    # 真值来自力/位觉的接触点；腕部相机不参与定义真值（反循环）
    r = whitened_residual(p_pred, p_ft, c.Sigma)
    c.T, c.Sigma = kalman_update(c.T, c.Sigma, r)         # 更新 T̂ 与 Σ_c
    c.r_cal_last = norm(r)
    if c.r_cal_last > THETA_CAL:
        c.t_verify = now(); audit.log(('recalibrate', c.version, c.r_cal_last))
    c.rho_lb = reliability_lcb(update_reliability(c, r))
    return c

def require_precision(claim, c):
    # 高精度断言必须通过校准协方差检查，否则拒绝（如紧配合抓取）
    if trace(propagate_cov(claim.y_fn, c, claim.sensor_sigma)) > claim.eps_prec:
        return ('reject', 'calibration_precision_insufficient')
    return ('ok', claim)
```

### IP-141 ERE（逆倾向加权、下界与反证凝视）

def reliability_estimate(streams, policy, alpha):
    w = [clip(1.0 / policy.pi(o), 1.0, W_MAX) for o in streams]
    rho_hat = sum(wi * correct(o) for wi, o in zip(w, streams)) / sum(w)
    rho_lb = lower_confidence_bound(rho_hat, n_eff(w), alpha)
    beta = rho_hat - reliability_uniform(streams)         # 回避偏差
    return rho_lb, beta

def disconfirming_gaze(M, budget, risk_model):
    # 为"推翻当前安全信念"而看，而非为"确认任务可行"而看
    for _ in range(budget.k_dis):
        target = argmax_region(-Belief_safe(M, r))        # 当前认为最安全处
        v = argmax_view(ExpectedFalsification(target, M))
        obs = capture_and_register(v)
        M.audit.add(obs)                                  # 入审计集，不计任务成功
    return M

### IP-142 HBM（退化、共因、预算与降级阶梯）

def hazard_update(source, dt, stress):
    lam = bathtub(source.age, stress)                     # 婴儿期/随机/耗损
    source.R *= exp(-lam * dt)                            # 生存函数
    source.lambda_hat = lam
    return source

def fuse_reliability(rhos, kappa_cc):
    naive = prod(rhos)                                    # 若错误假设独立
    return min(naive, 1 - kappa_cc * (1 - naive))         # 共因上界

def degrade_step(mode, rho_lb, D_rel, B_rel):
    if mode == 'M3': return 'M3'
    if rho_lb < THETA_M2 or D_rel > B_rel: return 'M2'    # 仅接触证据
    if rho_lb < THETA_M1: return 'M1'                     # 减速+加佐证
    if mode == 'M2' and rho_lb >= THETA_M1_UP and D_rel < B_REL_UP:
        return 'M1'                                       # 升级有据有界+迟滞
    return mode

### IP-144 RPC（可靠性感知探-诺-演）

```python
def reliability_probe_commit(x0, M, task, budget, consent, personas, rel):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        # ① 仪表体检
        rel.mode = degrade_step(rel.mode, rel.rho_lb, rel.D_rel, rel.B_rel)
        if rel.mode == 'M3': return negotiate_or_stop(cp, M, None, None, consent)
        # ② 腕部预视：只产出探针先验，不产出承诺证据
        ev_w, prior = wrist_precontact_evidence(M, cp.region, cp.obj,
                                                rel.calib, rel.gaze_policy)
        inf = meta_few_shot_infer(M, cp.region, M.obs[cp.region], meta)
        M.b[cp.region] = inf.post if inf.cls == 'ID' else worst_in(inf.belt)
        sigma = foothold_schedule(x0, cp, M); R = schedule_risk(sigma, M)
        while select_gait(R) == 'halt' and budget.probes_left > 0:
            cands = admissible_probes(cp, M, F_abs, prior=prior)   # 先验缩搜索
            if not cands: break
            p = argmax(cands, key=lambda q: voi_meta_pessimistic(q, M, inf)
                       + hidden_uncertainty_gain(q) - cost(q))
            if voi_meta_pessimistic(p, M, inf) < theta_voi: break
            obs = execute_probe(p, cap=F_abs)
            M, _, D = xmodal_fuse(M, cp.region, obs)
            # ④ 接触校验：独立力/位觉真值 → 校准与可靠性更新
            if obs.contact:
                rel.calib = contact_self_cal(rel.calib, obs.p_pred, obs.p_ft,
                                             M.audit)
                rel.rho_lb, rel.beta = reliability_estimate(M.streams, rel.gaze_policy)
                rel.D_rel = max(0.0, rel.D_rel - REPAY_PER_CONTACT)
            sigma = reselect_footholds(x0, cp, M); R = schedule_risk(sigma, M)
            budget.spend(p)
        # ⑤ 承诺 / 降级重试 / 绕行 / 协商 / 停
        g = select_gait(R); lv = contact_level(cp)
        ev = tag_evidence_r(sigma, M, lv, rel)
        if g != 'halt' and reliability_evidence_gate(core_contact(cp), M,
                                                     personas, ood_reg)[0] == 'ok':
            sched.append(commit(sigma, g)); log.append(ev); continue
        if rel.mode in ('M1', 'M2'):                       # 降级模式重试
            sigma2 = conservative_gait(sigma, rel.mode)
            if reliability_evidence_gate(core_contact(cp), M, personas,
                                         ood_reg)[0] == 'ok':
                sched.append(commit(sigma2, rel.mode)); continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt': route = alt; continue
        return negotiate_or_stop(cp, M, sigma, R, consent,
                                 tau_int=tau_int(personas.active.auth))
    disconfirming_gaze(M, budget, risk_model)             # ⑥ 反证凝视入审计
    return sched, log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| OEC | O(\|𝔽\|·\|Occl\|) | O(\|𝔽\|) | 隐藏量不可替代、负证据限自由视锥（A41） |
| CAE | O(1)+O(d_c²)/传播；O(N_contact) 自校准 | O(d_c²) | Σ_c 传播、失验限幅、反循环（A42） |
| ERE | O(N_stream·d_o) | O(N_stream) | 倾向权重截断、ρ_LB、β_avoid（A43） |
| HBM | O(1)/更新 | O(\|ℳ\|) | 共因上界、预算/债务守恒（A44） |
| RBG | O(\|σ\|) | O(\|σ\|) | 溯源完整、EV-wrist 限 L1、不单独满足不可逆 |
| RPC | O(\|CP\|·(k_p+k_c+k_dis)·(C_VOI+d_φ)) | O(\|V\|+\|σ\|) | 体检先行、终止有界、四态+降级完备 |

**正确性定理（Evidence-Provenance Reliability Soundness, EPRS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 可观测性证书诚实：EV-wrist 仅用于 P_vis，隐藏力学量必经实测，负证据仅在 𝔽_free 内有效；**(A42)** 校准状态误差有界：Σ_c 诚实、失验即限幅、接触自校准以独立力/位觉为真值且腕部相机不自证；**(A43)** 可靠性估计诚实：逆倾向权重截断、决策用 ρ_LB、反证凝视预算 k_dis 被执行、β_avoid 超阈即冻结阈值放宽；**(A44)** 退化/共因模型保守、降级阶梯 fail-operational、可靠性债务守恒。则：

1. **承诺健全性**：P(fail) ≤ δ_f+ε_meta(k)+δ_probe+ε_h(w_max)+δ_ood·α_conf+δ_xm·1[L1]+δ_wrist·1[P_vis]+δ_cal+δ_rel。
2. **可靠性单调性**：腕部证据、校准更新、可靠性估计只能经 (a) 缩小探针搜索空间、(b) 提供带置信下界的校验标签、或 (c) 触发更保守的运营模式影响系统；不存在"看得更清 ⇒ 更敢赌"的升险路径；共因折减保证冗余不会凭空降低风险估计。
3. **反循环性**：EV-contact-truth 只进入审计/校准通道，不能作为它所校验命题的承诺证据；因此校准误差不会通过"自证"被系统性低估。
4. **终止性与可运营性**：RPC 在 k_probes+k_cons+k_dis 内终止于 {承诺, 绕行, 降级重试, L2 协商, 安全停}；降级实时、升级有据有界，M3 为吸收态。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                   + δ_wrist·1[P_vis] + δ_cal + δ_rel)
             − P(共因未建模) − P(倾向权重失真) − P(降级阶梯失效)
```

关键：**腕部相机给效率（预接触缩小搜索），共形与下界给保底**；**可观测性把"看得见"与"证得成"分开**；**校准是共因，必须用力/位觉独立校验且不得自证**；**可靠性只用下界，并且要按采集策略纠偏、主动反证**。

## 6. 本轮最大风险

**一句话**：本轮把证据的可信度押在"仪器自报的可靠性"上——若手眼校准校验与可靠性估计都依赖同一路被污染或共因失效的感知（尤其用腕部相机去校验腕部相机），系统会以高度自洽的方式"自信地失准"；因此必须以独立力/位觉接触作为校准真值、失验即限幅、EV-wrist 不得单独支撑不可逆接触、可靠性只用置信下界并保留审计隔离，宁可承认"仪表未知"，绝不把自证当成证据。
