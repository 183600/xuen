# 第 62 轮（承接第 61 轮 ESEC；灵感循环第 8 轮；本轮灵感：「视觉语言动作模型」×「仿真到现实」）

> 第 61 轮用 ESEC 打通了「统一语义表征（USR）—具身大模型（MEL）—多轮对话（DMS）—语义/实时双流（SRT-Dual）—六维预算（PCE+++++）」。但 ESEC 刻意把 MEL 约束为「只产先验、不产动作」，并用 A67 把 sim2real gap 压缩为一个标量界。这两个设计选择留下了 **四个更深的局限**：
> 1. **动作语义缺席**：MEL 输出 z_scene、φ_phys、π_intact，却不输出「做什么动作」。而视觉语言动作模型（VLA）的核心价值正是把视觉-语言直接映射为动作块。ESEC 缺少「VLA 动作意图 → 1 kHz 阻抗控制」的接地接口，语义正确不等于动作正确。
> 2. **Sim2Real 差距被过度简化**：A67 假设 gap ≤ δ_sim2real，但真实差距是 **结构化、场景相关、多源耦合** 的（物理参数、感知外观、接触动力学、时延同步），并被阻抗控制非线性放大；域随机化只能覆盖训练分布，无法给出「未见真实场景」的安全保证。
> 3. **动作级安全不可证**：第 61 轮的安全证书 J_sem_exec 作用于「阻抗参数」层。VLA 的危险却发生在「动作意图」层——方向对、力过大，或动作块时序不一致。缺少动作级控制屏障（CBF）与不可行时的安全回退。
> 4. **数据飞轮是单向的**：仿真训练 → 现实部署。真实执行证据 EV-exec 只进入 USR 做语义对账，没有回流去修正仿真物理参数、接触模型与 VLA 策略，导致 sim2real gap 长期不收敛，且无法主动选择最有信息量的真实试验。

## 0. 直觉与动机

**灵感 1（VLA → 动作-阻抗分解 VLA-AIF）**
直觉：VLA 直接回归关节力矩是「用 5-20 Hz 的语义模型去驱动 1 kHz 的物理闭环」，既慢又难稳。更合理的分解是：让 VLA 只预测 **动作意图三元组**——运动意图 z_m（往哪走）、力意图 z_f（用多大力）、柔顺意图 z_c（多软/多硬），再由一个轻量、可证明 Lipschitz 的适配器 A_imp 把三元组编译成阻抗轨迹 (x_d, F_d, K_p, K_d)。这样 VLA 保留视觉-语言泛化，实时层保留稳定性；两者通过「阻抗」这个物理接口解耦，而不是通过 token 硬拼接。

**灵感 2（Sim2Real → 结构化差距张量 SRGT）**
直觉：sim2real gap 不是「一个数」，而是一组 **有方向、有相关性、有物理含义的偏差**：摩擦系数偏低、质量偏小、接触刚度偏硬、相机色偏、控制时延抖动。把它们组织成差距张量 G = (G_phys, G_perc, G_contact, G_lat)，就能把它 **传播** 过阻抗控制器，得到「最坏情况下仍安全」的鲁棒约束，而不是拍一个经验安全系数。

**灵感 3（Sim2Real → 真-仿-真校准飞轮 R2S2R）**
直觉：真实机器人每一次接触都是免费的「系统辨识实验」。把 EV-exec 变成在线辨识数据，估计真实物理参数 φ̂_real，用它校准仿真 φ_sim；再用校准后的仿真做 VLA 微调与残差学习，部署后继续收集证据。飞轮每转一圈，gap 半径 ρ 应单调收缩；若 ρ 不降反升，说明存在 **不可辨识的系统性偏差**，必须扩大域随机化或触发主动采样，而不是继续信任证书。

**灵感 4（VLA → 动作级安全护栏 VLA-ACTS）**
直觉：VLA 可以「说对话、看对物、指对方向」，但仍可能「用力过猛」。因此在动作块进入控制器前加一道 **时序集成 + 鲁棒控制屏障 QP**：先对多个动作块做时序集成得到 ā，再把 ā 投影到满足 CBF 的安全动作集；若 QP 不可行，直接回退到第 61 轮 GARI 编译出的保守阻抗。安全永远由可验证的物理约束兜底，而不是由大模型的置信度兜底。

**灵感 5（合流 → 七/八维预算 PCE^8 与差距证书 J_gap）**
直觉：VLA 推理与 sim2real 校准都要花预算。把第 61 轮的 B_cog5 扩展为 **B_cog8 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_vla, B_sim)**（并借此修正第 61 轮「五维却列六项」的计数不一致）：B_vla 管动作块长度/推理频率/集成样本数，B_sim 管仿真步数/真实试验次数/校准轮次/允许 gap 半径。任一预算耗尽都触发 **只降低性能、不降低安全** 的降级链。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（VLA 动作-阻抗分解 VLA-AIF）** 令 VLA 策略与适配器为
```
π_vla:  (V_{1:k}, L, P_{1:t}, e_scene) → Z_a = {(z_m^τ, z_f^τ, z_c^τ)}_{τ=1}^{H}
A_imp:  Z_a × φ_phys × Anchor → Ξ_H = {(x_d^τ, F_d^τ, K_p^τ, K_d^τ)}_{τ=1}^{H}
```
其中 z_m^τ ∈ ℝ³（任务空间运动意图），z_f^τ ∈ ℝ（法向力意图），z_c^τ ∈ [0,1]^q（柔顺剖面）；H 为动作块长度，π_vla 以 f_vla = 5–20 Hz 运行，A_imp 将 Ξ_H 插值为 1 kHz 连续轨迹。硬约束：
```
K_p^τ = clamp(σ(K_p^0 + W_c z_c^τ), K_p^min, K_p^max)
F_d^τ = clip(z_f^τ, 0, (μ̂ - ρ_μ)·N̂·(1 - m_safe))
‖A_imp(z,·) - A_imp(z',·)‖ ≤ L_a ‖z - z'‖      （Lipschitz 接地条件）
```
关键点：**VLA 不输出力矩**；它输出的是可被 EEIS 编译、可被 CBF 投影、可被证书审计的「意图」。

**定义 174（结构化 Sim2Real 差距张量 SRGT）** 
```
G = (G_phys, G_perc, G_contact, G_lat)
G_phys    = {Δφ = (Δμ, Δm, Δk, Δη) : Δφᵀ Σ_phys⁻¹ Δφ ≤ ρ_phys²}
G_perc    = {(δ_v, δ_t) : ‖δ_v‖ ≤ ρ_v, ‖δ_t‖ ≤ ρ_t}
G_contact = {δ_f : ‖δ_f‖ ≤ ρ_c}          # 摩擦锥/形变/黏滑建模误差
G_lat     = {δ_τ : 0 ≤ δ_τ ≤ τ_max}       # 感知-控制-通信同步抖动
```
差距算子 d_G(P_real, P_sim) 取各分量加权积分概率度量（如 Wasserstein-1）。SRGT.estimate(EV-exec) 由贝叶斯系统辨识的后验给出 (φ̂, ρ_phys)，并由感知/接触/时延残差给出其余半径。

**定义 175（差距感知鲁棒阻抗 GARI）** 在 EEIS 编译中显式对 G 取最坏情况：
```
K* = argmin_{K ∈ K_feas} J_task(K; φ̂)
     s.t. ∀ Δφ ∈ G_phys, ∀ δ_f ∈ G_contact, ∀ δ_τ ∈ G_lat:
          ḣ(x_t, K, φ̂+Δφ) + α_cbf·h(x_t) ≥ L_h·(δ_f + δ_τ)
```
闭式保守近似（在线 1 kHz 可用）：
```
μ_safe = μ̂ - ρ_μ,  N_safe = N̂ - ρ_N
F_max^rob = μ_safe · N_safe · (1 - m_safe)
K_p^rob = K_p^nom · (1 - α_p·ρ_phys),   K_d^rob = K_d^nom · (1 + α_d·ρ_phys)
margin_cbf = h(x_t) - (L_h·(ρ_c + τ_max) + L_g·ε_g)/α_cbf
```
其中 m_safe 取 gap 后验的 1-δ 分位，而非固定常数。

**定义 176（真-仿-真校准闭环 R2S2R）** 第 k 个校准周期执行：
```
1) 在线辨识：φ̂_real ~ p(φ | EV-exec^{1:N_k})       （贝叶斯系统辨识）
2) 仿真校准：φ_sim^{k+1} = (1-α_k)·φ_sim^k + α_k·E[φ̂_real]
3) 接触模型：sim^{k+1} = update_contact(sim^k, EV-exec)
4) 策略适配：π_vla^{k+1}, θ_res^{k+1} ← finetune_on(sim^{k+1}, 真实修正数据)
5) 差距更新：ρ^{k+1} = Quantile_{0.95}(‖φ̂_real - φ_sim^{k+1}‖_{Σ_phys})
6) 若 ρ^{k+1} > ρ_max：扩大域随机化 或 触发 GAVOI 主动采样
```
在平稳性、持续激励与可辨识性下，后验收缩给出 ρ^k = O(1/√N_k)；R2S2R 的转移风险随周期单调不增。

**定义 177（有界残差 Sim2Real 适配器 RSA）** 
```
z_{t+1} = f_sim(z_t, u_t) + g_θ(z_t, u_t) + w_t
‖g_θ(z,u)‖ ≤ ε_g,  ‖g_θ(z,u) - g_θ(z',u')‖ ≤ L_g(‖z-z'‖ + ‖u-u'‖)
```
g_θ 由真实转移在线学习，并施加残差上界惩罚；安全集按 ε_g 膨胀：Ω_ε = {z : h(z) ≥ ε_g/α_cbf}。RSA 的作用不是「修正仿真」，而是把 **残余建模误差显式计入安全集**。

**定义 178（VLA 动作级 CBF 护栏 VLA-ACTS）** 对 K 个动作块或时序集成结果：
```
ā_t = Σ_i w_i a_t^{(i)}                          # temporal ensembling
a* = argmin_{a ∈ U} ‖a - ā_t‖_Q²
     s.t. ĥ(z_t, a) + α_cbf·h(z_t) ≥ L_g·ε_g + L_h·(ρ_c + τ_max)
若 QP 不可行: a* ← SAFE_FALLBACK = K_safe^rob(GARI)
cert: margin_cbf = h(z_t) - (L_g·ε_g + L_h·(ρ_c+τ_max))/α_cbf
```
该护栏使「动作语义正确但物理危险」的 VLA 输出在进入 ERTC 前被投影或拒绝。

**定义 179（差距感知主动采样 GAVOI）** 
```
VOI_real(x) = H(φ | D) - E_{y~p(·|x)}[ H(φ | D ∪ {(x,y)}) ]
x* = argmax_{x ∈ X_safe} VOI_real(x) / cost_real(x)
```
用后验熵或 BALD 近似；只在 h(x) ≥ 安全阈值的真实试验上采样，避免「为了辨识而冒险」。

**定义 180（VLA 语义-动作-阻抗闭环 SR-VLA-ESEC）** 
```
SR-VLA-ESEC(M, V, L, P, Δf_req):
  # 慢流 5–20 Hz：VLA + 校准
  z_a ← π_vla(V, L, P, M.anchor)
  (φ̂, G) ← SRGT.estimate(M.evidence_buffer)
  Ξ_H ← A_imp(z_a, φ̂, M.anchor)
  # 中频：动作级护栏
  Ξ_safe, margin ← ACTS.project(Ξ_H, G, M.anchor)
  M.anchor ← USR.commit(Ξ_safe, φ̂, G)
  # 快流 1 kHz：鲁棒阻抗
  K_safe ← GARI.compile(Δf_req, Ξ_safe, G)
  dispatch(K_safe); EV_exec ← wait_contact()
  # 反馈：校准飞轮
  M.evidence_buffer.push(E_evidence(EV_exec))
  if calibration_due: ρ ← R2S2R.step(EV_exec); RSA.update(EV_exec)
  M.J_gap ← build_gap_cert(EV_exec, M.anchor, G, margin)
  return M, K_safe, EV_exec, M.J_gap
```
与第 61 轮 ESEC 的本质差别：ESEC 的缓慢流只写「语义锚点」，SR-VLA-ESEC 额外写「动作意图 + 差距半径」，并让快流消费 **带不确定性的阻抗区间** 而非点估计。

**定义 181（八维认知-仿真预算 B_cog8 / PCE^8）** 为修正第 61 轮 B_cog5「名为五维、实列六项」的不一致，本轮按实际维度命名：
```
B_cog8 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_vla, B_sim)
B_vla = (H_max, f_vla_min, K_ensemble, token_budget)
B_sim = (sim_steps, real_trials, calibration_epochs, ρ_max)
cost_cog8 = Σ_i λ_i·cost_i + λ_vla·(H·K/H_max·K_max) + λ_sim·(N_real/N_budget)
```
降级链（安全不降级）：
- B_vla 耗尽 → H 减半 → K_ensemble = 1 → 复用缓存动作块 → 仅用 GARI 保守阻抗；
- B_sim 耗尽 → 冻结策略微调 → 冻结校准 → ρ 按上一后验上界保守放大 → 回退纯 GARI。
- B_mel / B_usr 沿用第 61 轮：蒸馏→缓存→冻结锚点；冻结投影头。

**定义 182（差距感知联合证书 J_gap）** 
```
J_gap = (J_sem_exec, ρ_gap, ε_g, margin_cbf, sim_version,
         calibration_epoch, gap_coverage)
Valid(J_gap) ⇔ Valid(J_sem_exec)
            ∧ ρ_gap ≤ ρ_max
            ∧ ε_g ≤ ε_g_max
            ∧ margin_cbf ≥ m_min
            ∧ gap_coverage ≥ 1-δ
            ∧ (now - calibration_epoch.time) ≤ τ_calib
```
其中 gap_coverage 是真实 EV-exec 落在 SRGT 预测区间内的经验覆盖率；它是「证书是否过于乐观」的直接体检指标。

**定义 183（Sim2Real 迁移风险界）** 
```
Risk_real(π) ≤ Risk_sim(π) + ½·d_G(P_real, P_sim) + λ_π·ρ_gap
λ_π = Lip(π_vla)·L_a·L_transition
```
该界把「动作 Lipschitz 常数、适配器 Lipschitz 常数、转移模型 Lipschitz 常数、gap 半径」统一到一条可测量的风险链；J_gap 的 ρ_max 正是由目标风险预算反解得到。

**定义 184（差距课程与主动校准）** 
```
ρ_0 ≥ ρ_1 ≥ … ≥ ρ_T,  ρ_T ≤ ρ_max
π^{k+1} = argmin_π  E_{s~sim(φ∈G(ρ_k))}[L(π,s)] + β·max_{Δφ∈G(ρ_k)} L(π,s)
采样：x* = GAVOI.select(X_safe)
```
若 ρ_k → ρ_∞ 且后验收缩，则 Risk_real(π^k) → Risk_real(π*) + O(ρ_∞)；当 ρ_∞ > ρ_max 时，**必须拒绝签发 J_gap**，而不是继续下调安全系数。

### IP-183 VLA-AIF（动作-阻抗分解）

```python
class VLAActionImpedanceFactorizer:
    def __init__(self, H=8, f_vla=10, d_a=32, Kp0=200.0):
        self.H, self.f_vla, self.d_a = H, f_vla, d_a
        self.vla = VLAPolicy()            # 视觉-语言-动作骨干
        self.W_c = nn.Linear(d_a, 3)      # 柔顺剖面 -> 刚度
        self.Kp0 = Kp0

    def infer(self, V, L, P, anchor):
        z_a = self.vla(V, L, P, anchor.scene_emb, anchor.intent_emb)  # [H, d_a]
        return z_a

    def decode(self, z_a, phi_phys, gap):
        traj = []
        for tau in range(self.H):
            z_m, z_f, z_c = split(z_a[tau])
            Kp = torch.sigmoid(self.W_c(z_c)) * (phi_phys.k_max - phi_phys.k_min) + phi_phys.k_min
            F_rob = max(0.0, (phi_phys.mu - gap.rho_phys) *
                        phi_phys.N * (1.0 - self.m_safe(gap)))
            Fd = torch.clamp(z_f, 0.0, F_rob)
            traj.append(Impedance(x_d=z_m, F_d=Fd, K_p=Kp, K_d=phi_phys.eta_damp))
        return interpolate(traj, f_ctrl=1000)   # 1 kHz 连续轨迹

    def lipschitz_bound(self):
        return self.W_c.weight.norm(2) * self.vla.lipschitz_bound()
```

### IP-184 SRGT（结构化差距张量估计）

```python
class Sim2RealGapTensor:
    def __init__(self, sim_phi, prior):
        self.sim_phi = sim_phi
        self.prior = prior
        self.posterior = prior

    def estimate(self, evidence_buffer):
        samples = self.bayes_system_id(evidence_buffer)   # 后验样本 {Δφ}
        rho_phys = np.quantile(np.linalg.norm(samples, axis=1), 0.95)
        rho_v = self.perception_residual(evidence_buffer)
        rho_c = self.contact_residual(evidence_buffer)
        rho_t = self.latency_jitter(evidence_buffer)
        return GapTensor(rho_phys=rho_phys, rho_v=rho_v,
                         rho_c=rho_c, rho_t=rho_t,
                         phi_hat=self.sim_phi + samples.mean(axis=0))
```

### IP-185 GARI（差距感知鲁棒阻抗编译）

```python
class GapAwareRobustImpedance:
    def __init__(self, alpha_p=0.5, alpha_d=0.5, m_base=0.1):
        self.alpha_p, self.alpha_d, self.m_base = alpha_p, alpha_d, m_base

    def compile(self, delta_f_req, xi, gap):
        mu_s = gap.phi_hat.mu - gap.rho_phys
        N_s  = gap.phi_hat.N - gap.rho_phys
        m_s  = self.m_base + 0.5 * gap.rho_phys
        F_max = max(0.0, mu_s * N_s * (1.0 - m_s))
        Kp = xi.K_p * (1.0 - self.alpha_p * gap.rho_phys)
        Kd = xi.K_d * (1.0 + self.alpha_d * gap.rho_phys)
        margin = xi.h - (gap.rho_c + gap.rho_t + gap.eps_g) / self.alpha_cbf
        if margin < self.m_min:
            return None, margin          # 拒绝，交由上层降级
        return Impedance(x_d=xi.x_d, F_d=min(xi.F_d, F_max),
                         K_p=Kp, K_d=Kd), margin
```

### IP-186 R2S2R（真-仿-真校准飞轮）

```python
class RealToSimToRealCalibrator:
    def __init__(self, sim, policy, rsa, rho_max=0.2):
        self.sim, self.policy, self.rsa = sim, policy, rsa
        self.rho_max = rho_max
        self.epoch = 0

    def step(self, evidence):
        phi_hat = self.sim.bayes_id(evidence)                 # 后验
        self.epoch += 1
        alpha = 1.0 / (self.epoch + 1)
        self.sim.phi = (1 - alpha) * self.sim.phi + alpha * phi_hat.mean
        self.sim.update_contact(evidence)
        self.rho = np.quantile(phi_hat.samples_norm, 0.95)
        if self.rho > self.rho_max:
            self.sim.dr.expand(self.rho)                       # 扩大域随机化
            self.active_sampler.request(self.gap_entropy_map())
        self.policy = finetune(self.policy, self.sim, evidence)
        self.rsa.update(evidence)
        return self.rho
```

### IP-188 VLA-ACTS（动作级 CBF 护栏）

```python
class VLA_ACTS:
    def __init__(self, alpha_cbf=1.0, L_g=1.0, L_h=1.0):
        self.alpha_cbf, self.L_g, self.L_h = alpha_cbf, L_g, L_h

    def project(self, chunks, z, gap):
        a_bar = temporal_ensemble(chunks)                     # 时序集成
        bound = (self.L_g * gap.eps_g +
                 self.L_h * (gap.rho_c + gap.rho_t)) / self.alpha_cbf
        a_star = solve_cbf_qp(z, a_bar, h=self.h, alpha=self.alpha_cbf, bound=bound)
        if a_star is None:                                    # 不可行 -> 物理兜底
            a_star = self.safe_fallback(gap)
        margin = self.h(z) - bound
        return a_star, margin
```

```python
def sr_vla_esec(M, V, L, P, delta_f_req, budget):

    xi_safe, margin = M.acts.project(xi_H, M.anchor, gap)
    M.anchor = M.usr.commit(xi_safe, phi_hat, gap)
    K_safe, margin = M.gari.compile(delta_f_req, xi_safe, gap)
    if K_safe is None:
        K_safe = M.gari.conservative_fallback(gap)      # 安全不降级
    M.ertc.dispatch(K_safe)
    ev = wait_contact()
    M.evidence_buffer.push(M.usr.evidence_encoder.encode(ev))
    if budget.due(R2S2R):
        gap.rho = M.r2s2r.step(ev)
        M.rsa.update(ev)
    M.J_gap = build_gap_cert(ev, M.anchor, gap, margin)
    return M, K_safe, ev, M.J_gap
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|

**正确性定理（SR-VLA-Complete）** 假设 A61–A70 及：
**(A71)** A_imp Lipschitz 常数 L_a，K 落在紧集 K_feas；动作块插值 C¹。
**(A72)** SRGT 各分量有界，后验校准（经验覆盖率在 1-δ 置信下 ≥ 1-δ）。
**(A73)** GARI 的最坏情况集非空、内近似保守；鲁棒 QP 有可行回退。
**(A74)** 系统辨识持续激励；仿真参数化覆盖真实；RSA 残差 ‖g_θ‖ ≤ ε_g。
**(A75)** 控制仿射系统的 CBF h 有效；VLA-ACTS 的 QP 或回退必达安全集。

则：
1. **动作-阻抗安全接地**：∀ z_a, z_a'，‖K(z_a) - K(z_a')‖ ≤ L_a‖z_a - z_a'‖；VLA 动作扰动不会在控制层被隐式放大。

4. **动作级安全**：VLA-ACTS 的 QP 可行时保证 ḣ + αh ≥ 0；不可行时回退 GARI 仍满足 A73。
5. **数据效率**：GAVOI 在安全试验集上的期望后验熵下降快于均匀采样，样本复杂度降低 ≥ 2×（实验目标）。

### IP-183 VLA-AIF（动作-阻抗分解）

```python
class VLAActionImpedanceFactorizer:
    def __init__(self, H=8, f_vla=10, d_a=32, Kp0=200.0):
        self.H, self.f_vla, self.d_a = H, f_vla, d_a
        self.vla = VLAPolicy()                 # 视觉-语言-动作骨干
        self.W_c = nn.Linear(d_a, 3)           # 柔顺意图 -> 刚度
        self.Kp0 = Kp0

    def infer(self, V, L, P, anchor):
        # 慢流：只产动作意图，不产力矩
        return self.vla(V, L, P, anchor.scene_emb, anchor.intent_emb)  # [H, d_a]

    def decode(self, z_a, phi_phys, gap):
        traj = []
        for tau in range(self.H):
            z_m, z_f, z_c = split(z_a[tau])
            Kp = torch.sigmoid(self.W_c(z_c)) * (phi_phys.k_max - phi_phys.k_min)
            Kp = Kp + phi_phys.k_min
            F_rob = max(0.0, (phi_phys.mu - gap.rho_phys) *
                        phi_phys.N * (1.0 - self.m_safe(gap)))
            Fd = torch.clamp(z_f, 0.0, F_rob)
            traj.append(Impedance(x_d=z_m, F_d=Fd,
                                  K_p=Kp, K_d=phi_phys.eta_damp))
        return interpolate(traj, f_ctrl=1000)  # 1 kHz 连续轨迹

    def lipschitz_bound(self):
        return self.W_c.weight.norm(2) * self.vla.lipschitz_bound()
```

### IP-185 GARI（差距感知鲁棒阻抗）

```python
class GapAwareRobustImpedance:
    def __init__(self, alpha_p=0.5, alpha_d=0.5, m_base=0.1,
                 alpha_cbf=1.0, m_min=0.02):
        self.alpha_p, self.alpha_d, self.m_base = alpha_p, alpha_d, m_base
        self.alpha_cbf, self.m_min = alpha_cbf, m_min

    def compile(self, delta_f_req, xi, gap):
        mu_s = gap.phi_hat.mu - gap.rho_phys
        N_s = gap.phi_hat.N - gap.rho_phys
        m_s = self.m_base + 0.5 * gap.rho_phys
        F_max = max(0.0, mu_s * N_s * (1.0 - m_s))
        Kp = xi.K_p * (1.0 - self.alpha_p * gap.rho_phys)
        Kd = xi.K_d * (1.0 + self.alpha_d * gap.rho_phys)
        bound = (gap.rho_c + gap.rho_t + gap.eps_g) / self.alpha_cbf
        margin = xi.h - bound
        if margin < self.m_min:
            return None, margin               # 拒签，交给降级链
        return Impedance(x_d=xi.x_d, F_d=min(xi.F_d, F_max),
                         K_p=Kp, K_d=Kd), margin

    def conservative_fallback(self, gap):
        return Impedance(K_p=gap.k_min, K_d=gap.eta_max,
                         F_d=0.0, x_d=hold_position())
```

### IP-186 R2S2R（真-仿-真校准飞轮）

```python
class RealToSimToRealCalibrator:
    def __init__(self, sim, policy, rsa, sampler, rho_max=0.2):
        self.sim, self.policy, self.rsa = sim, policy, rsa
        self.sampler, self.rho_max = sampler, rho_max
        self.epoch = 0

    def step(self, evidence):
        phi_hat = self.sim.bayes_id(evidence)
        self.epoch += 1
        alpha = 1.0 / (self.epoch + 1)
        self.sim.phi = (1 - alpha) * self.sim.phi + alpha * phi_hat.mean
        self.sim.update_contact(evidence)
        rho = np.quantile(phi_hat.samples_norm, 0.95)
        if rho > self.rho_max:
            self.sim.dr.expand(rho)            # 扩大域随机化
            self.sampler.request(self.sim.gap_entropy_map())
        self.policy = finetune(self.policy, self.sim, evidence)
        self.rsa.update(evidence)
        return rho
```

```python
class GapAwareActiveSampler:
    def __init__(self, gap_model, cost_fn):
        self.gap_model, self.cost_fn = gap_model, cost_fn

    def select(self, candidates, safe_filter):
        best, best_score = None, -np.inf
        H0 = self.gap_model.posterior_entropy()
        for x in filter(safe_filter, candidates):
            H1 = self.gap_model.expected_posterior_entropy(x)
```

```python
        calibration_epoch=budget.sim.epoch,
        gap_coverage=gap.coverage(gap.heldout_real),
    )

def valid(j, cfg):
    return (valid_sem_exec(j.j_sem_exec)
            and j.rho_gap <= cfg.rho_max
            and j.eps_g <= cfg.eps_g_max
            and j.margin_cbf >= cfg.m_min
            and j.gap_coverage >= 1 - cfg.delta
            and age(j.calibration_epoch) <= cfg.tau_calib)
```

### IP-192 SR-VLA-ESEC（统一闭环）

```python
def sr_vla_esec(M, V, L, P, delta_f_req, budget):
    # 慢流 5-20 Hz
    z_a = M.vla.infer(V, L, P, M.anchor)
    phi_hat, gap = M.srgt.estimate(M.evidence_buffer)
    xi_H = M.vla.decode(z_a, phi_hat, gap)
    # 中频：动作级护栏
    xi_safe, margin = M.acts.project(xi_H, M.anchor, gap)
    M.anchor = M.usr.commit(xi_safe, phi_hat, gap)
    # 快流 1 kHz：鲁棒阻抗
    K_safe, margin = M.gari.compile(delta_f_req, xi_safe, gap)
    if K_safe is None:
        K_safe = M.gari.conservative_fallback(gap)
        M.safety_events.log('robust_infeasible', gap.rho_phys)
    M.ertc.dispatch(K_safe)
    ev = wait_contact()
    M.evidence_buffer.push(M.usr.evidence_encoder.encode(ev))
    # 反馈：校准飞轮 + 主动采样
    if budget.due('r2s2r'):
        gap.rho_phys = M.r2s2r.step(ev)
        M.rsa.update(ev)
        x_next = M.sampler.select(M.safe_candidates(), M.is_safe)
        M.schedule_real_trial(x_next)
    M.J_gap = build_gap_cert(ev, M.anchor, gap, margin, budget.sim)
    return M, K_safe, ev, M.J_gap
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| VLA-AIF | O(H·d_a) + O(H_rt) 插值，~1–2 ms | O(H·d_a) | 动作扰动经 L_a 有界映射为阻抗扰动 |
| SRGT | O(N_ev·n_φ²)，离线 10–50 ms | O(N_ev·n_φ) | 真实 gap 经验覆盖率 ≥ 1-δ |
| GARI | O(1) 闭式 / O(n²) QP，< 0.1 ms | O(n) | 最坏 gap 下 CBF 前向不变 |
| R2S2R | O(sim_steps + N_k) 每周期 | O(sim_state) | ρ^k = O(1/√N_k)，风险单调不增 |
| RSA | O(d_z²)，< 1 ms | O(d_z²) | ‖g_θ‖ ≤ ε_g，安全集膨胀有效 |
| VLA-ACTS | O(K·H) + O(n³) QP，< 1 ms | O(K·H) | QP 可行 ⇒ CBF；不可行 ⇒ 安全回退 |
| PCE^8 | O(1) | O(1) | 任一预算耗尽只降性能、不降安全 |

**正确性定理（SR-VLA-Complete）** 在 A61–A70 基础上追加：
**(A71)** A_imp 为 L_a-Lipschitz，K 落在紧集 K_feas，动作块插值 C¹。
**(A72)** SRGT 各分量有界，后验校准（真实 gap 覆盖率在 1-δ 置信下 ≥ 1-δ）。
**(A73)** GARI 最坏情况集非空、内近似保守，鲁棒 QP 必有可行安全回退。
**(A74)** 系统辨识持续激励；仿真参数化覆盖真实；RSA 残差 ‖g_θ‖ ≤ ε_g。
**(A75)** 控制仿射系统 CBF h 有效；VLA-ACTS 的 QP 或回退必达安全集。

则：
1. **动作-阻抗安全接地**：∀ z_a, z_a'，‖K(z_a) - K(z_a')‖ ≤ L_a‖z_a - z_a'‖；VLA 动作扰动不会在控制层被隐式放大。
2. **差距鲁棒安全**：若真实 gap ∈ G 且 K ∈ K_robust，则约束违反概率 ≤ δ；margin_cbf ≥ m_min 时安全集前向不变。
3. **校准收敛**：R2S2R 下 ρ^k = O(1/√N_k)；若 ρ_∞ ≤ ρ_max，则 Risk_real 随周期单调不增。
4. **动作级安全**：VLA-ACTS 的 QP 可行时 ḣ + αh ≥ 0；不可行时回退 GARI 仍满足 A73。
5. **数据效率**：GAVOI 在安全试验集上的期望后验熵下降快于均匀采样，样本复杂度降低 ≥ 2×（实验目标）。
6. **实时性**：VLA 与校准均在慢流；1 kHz 快流只做闭式 GARI + 小规模 QP，不依赖大模型时序。
7. **证书不可伪造**：J_gap 的 gap_coverage 与 calibration_epoch 联合约束使「低 gap 但无真实覆盖」的乐观证书无法通过验证。

## 4. 实验设计 E201–E210

| 实验 | 指标 | 目标 |
|---|---|---|
| E201 VLA-AIF | 动作块→阻抗轨迹保真度；力矩平滑度；任务成功率 | 轨迹误差 < 5%；jerk 降低 ≥ 30% |

**消融设计**：分别去掉 VLA-AIF（VLA 直接输出阻抗）、SRGT（固定安全系数）、R2S2R（仅域随机化）、VLA-ACTS（仅软约束）、GAVOI（均匀采样），验证每个 IP 对 E210 的边际贡献；重点报告「证书覆盖率」而非仅成功率。

## 5. 本轮最大风险

**一句话**：若 sim2real gap 中不可辨识的系统性偏差（突变摩擦、柔性体、时延尖峰）被 SRGT 误当作可校准的随机噪声，导致 ρ 被低估、J_gap 过于乐观，则 VLA-ACTS 的 CBF 与 RSA 的残差界会同时失效，产生「仿真中证书齐全、现实中破坏性动作」的**证书幻象**；必须以「gap_coverage 在线体检 + ρ 不可降时拒签证书 + 动作级物理回退优先于大模型置信度」作为最后防线。
