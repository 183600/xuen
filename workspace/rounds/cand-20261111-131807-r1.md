# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「大语言模型」×「状态隔离」）

> 第 54 轮用动作空间剖面 `α_S` 与动作-鲁棒性联合证书 `J` 判定技能组合，但 `α_S` 只回答“能否执行动作”，`ρ` 只回答“扰动下能撑多远”，二者都**看不见技能携带的隐藏状态**。本轮提出 **状态足迹 `σ_S`、状态隔离契约 SIC、LLM 提议-验证协议 LPV、情节状态隔离 ESI**，把“状态隔离”提升为与动作兼容、鲁棒性并列的第三判定轴；并正视一个反转：LLM 既是提出隔离契约的助手，也是需要被隔离的最大状态污染源。

## 0. 直觉与动机

**灵感 1（状态足迹 → 从“看得见的动作”到“看不见的状态”）**
直觉：两个技能可以动作剖面完全相同、鲁棒谱也都不差，却在组合后失败。原因常是隐藏状态：一个技能把接触模式留在“左脚支撑”，另一个默认“右脚支撑”；一个把积分器留在饱和，另一个接手后继续积分。`α` 和 `ρ` 都看不出这种冲突，因为污染发生在**状态变量 X** 而不是动作空间 A。于是给技能补一个状态足迹 `σ_S=(R_S,W_S,κ_S,λ_S)`：读集、写集、跨调用持久私有状态、以及所有权/新鲜度标注。组合的第一性问题从“动作是否兼容”升级为“动作兼容 ∧ 状态可隔离”。

**灵感 2（状态隔离 ≠ 切断共享，而是把共享变成显式契约）**
直觉：完全隔离会切断必要的交接（导航给抓取传位姿、云端给边端传目标位姿）。正确的目标不是零共享，而是**无未声明共享**：所有跨技能共享必须走显式桥 `D_ij`，并带新鲜度与失效谓词；未声明的读写冲突 `U=H\D` 必须为空或污染势低于预算。这样“隔离度”是一个可度量的连续量，而不是二值开关，允许在安全与性能之间选隔离等级 `ℓ∈{L0..L3}`。

**灵感 3（LLM 提议-验证 → 用 LLM 的召回，不用它的可信）**
直觉：LLM 极擅长从自然语言任务猜出“这个技能大概会动哪些状态、该怎么交接”，召回高但**不可靠**（会漏标、会幻觉出不存在的手柄）。把它降级为**提案者**而非裁决者：LLM 产出组合骨架、足迹注解 `σ̂` 与候选桥；验证器用静态效应抽取 + 动态 rollout 得到 `σ*`，做差分；不一致处默认拒绝（default-deny），并让 LLM 根据反例轨迹生成补丁（加锁、检查点/恢复、状态复位、显式桥），最多 `k_max` 轮。LLM 的召回负责“想到”，验证器的 soundness 负责“放行”。

**灵感 4（LLM 自身也要状态隔离 → 情节沙箱与污染上游）**
直觉：规划用的 LLM 自己就是一个有状态系统：上下文窗口、检索记忆、KV 缓存。多个任务共享同一会话时，前一个任务的目标、失败、甚至环境里的恶意文本会污染后一个任务（提示注入、记忆串味）。因此引入**情节状态隔离**：全局本体 `O` 只读且签名；每个任务一个隔离情节库 `E_t`；跨任务只能通过**单向交接胶囊** `H_{t→t'}` 提升“已验证事实”；外部非可信文本打污点 `T`，污点不得写入控制变量。这与机器人运行时状态隔离同构：都是“状态不许隐式越界”。

**灵感 5（三层隔离金字塔 → 与鲁棒性金字塔、动作协同层叠加）**
直觉：状态存在于三个层次：设备/RTOS 变量、技能潜在状态与组合共享信念、任务情节记忆（含 LLM 上下文）。在第 53 轮 `𝕃` 与第 54 轮 `𝔸` 之上叠加**状态隔离层 `𝕊`**：`𝕊_0` 设备变量/句柄，`𝕊_1` 技能潜在状态 κ 与组合共享信念，`𝕊_2` 云边状态同步（云端信念 vs 边端真实状态），`𝕊_3` 任务情节与 LLM 上下文。跨层证书必须同时携带 `ρ`、`A_cert`、`σ_cert`，形成**动作-状态-鲁棒性三证书**。

**灵感 6（把隔离并入组合搜索 → 污染感知的最短路）**
直觉：第 54 轮的技能组合图 `G_S` 只按动作兼容与转换成本连边；本轮把每条边的可行性再加一条“隔离可行”过滤，并把 `(1-ISO)` 与污染势 `ψ` 计入路径成本。搜索目标变为 `min Σ [w_a(1-compat)+w_ρ(1-ρ)+w_ce||γ_ce-id||+w_s·ψ]`，在动作、鲁棒、状态三轴同时预算内找路径。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（状态足迹 State Footprint）**
设机器人可寻址状态空间 `X = X_dev ⊎ X_belief ⊎ X_epi`（设备 / 组合信念 / 情节）。技能 `S` 的状态足迹
`σ_S = (R_S, W_S, κ_S, λ_S)`，其中 `R_S,W_S ⊆ X` 为读 / 写集，`κ_S ⊆ W_S` 为跨调用持久私有状态（积分器、RNN 隐状态、接触模式、在线标定偏置），`λ_S: W_S → {private, shared, exported}` 给出所有权与新鲜度寿命。**注意 `σ_S` 与 `α_S` 正交**：`α_S` 描述“能执行什么动作”，`σ_S` 描述“会动什么隐藏状态”。

**定义 122（状态隔离度与污染势）**
对技能 `S_i,S_j`，令冲突集
`H_ij = (W_i∩R_j) ∪ (W_j∩R_i) ∪ (W_i∩W_j)`（最后一项仅在并发执行时计入）。
设 `D_ij` 为契约声明的桥通道（方向、新鲜度预算 `τ_ij`、失效谓词），则未声明冲突 `U_ij = H_ij \ D_ij`。
- 隔离度 `ISO_ij = 1 - |U_ij| / |W_i ∪ W_j|`；
- 污染势 `ψ_ij = Σ_{x∈U_ij} w_x · E[|Δx|]/scale_x`，`w_x` 为关键度。
称 `S_i,S_j` 在等级 `ℓ` 上 **ℓ-隔离** 当且仅当 `U_ij=∅`（或 `ψ_ij ≤ Ψ_ℓ`）且所有 `D_ij` 的陈旧度 `≤ τ_ℓ`。**完全隔离 `ISO=1` 不是目标；目标是无未声明共享。**

**定义 123（状态隔离契约 SIC）**
`C_iso = (σ_{S_1..S_k}, D, ℓ, bridge, rollback)`：足迹集合、显式桥集合、隔离等级、交接协议与持久状态回滚检查点。契约可判定的三个条件：
```
(1) U = ⋃_{i<j} U_ij = ∅  或  ψ ≤ Ψ_ℓ
(2) κ 的每次跨技能转移都经 bridge，且方向/新鲜度被声明
(3) rollback 能把 κ 恢复到组合前快照（可逆性）
```

**定义 124（LLM 提议-验证协议 LPV）**
协议 `Γ=(L,V,R,k_max)`：`L` 由 LLM 产出组合骨架、足迹注解 `σ̂`、候选桥 `D̂`；`V` 由静态效应抽取 + 动态 rollout 得到 `σ*`，做**差分** `Diff(σ̂,σ*)` 并验证 `C_iso`；`R` 在拒绝时以反例轨迹 `ce` 让 LLM 生成补丁。准入规则：
```
accept ⇔ V(σ*,C_iso)=ok ∧ Diff(σ̂,σ*).undeclared=∅ ∧ rollback 可执行
```
LLM 输出永远视为**不可信输入**；任何未声明的共享写默认拒绝（default-deny）。`k_max` 限界防止修复发散。

**定义 125（动作-状态-鲁棒性联合证书 J⁺）**
在第 54 轮 `J=(ρ,A_cert,γ_ce,δ_a,evidence)` 上增广：
`J⁺ = (ρ, A_cert, σ_cert, γ_ce, δ_a, δ_s, evidence)`，
其中 `σ_cert=(U,ψ,D,ℓ,κ-ownership,rollback)`，`δ_s` 为状态陈旧度/污染裕度。部署条件：
```
dom(T)=in ∧ δ_a≤Θ_a ∧ δ_s≤Θ_s ∧ ℓ≥ℓ_min(T) ∧ min_d ρ(d)≥ρ_min(d)
```

**定义 126（情节状态隔离与交接胶囊 ESI）**
LLM 规划器的状态分为：只读签名本体 `O`、每任务隔离情节库 `E_t`、污点集 `T`（来自环境文本/检索的非可信内容）。跨任务只允许单向提升：
`H_{t→t'} = (promoted_facts, provenance, signature)`，
满足 `raw_context_t ∩ E_{t'} = ∅`（原始上下文不跨任务），且 `T` 不得出现在控制变量写集 `W_ctrl` 中。污染上界 `ε_ctx(t→t') ≤ Σ_{f∈H} stale(f)·w_f`，超过 `Θ_ctx` 则新建情节而非续用。

## 2. 关键算法 伪代码

### IP-121 SFP（State Footprint Profiling）
```python
def state_footprint(skill, X, static, sampler, n_roll=64):
    R, W = static.effect_sets(skill.code)          # 静态过近似
    kappa, lam = set(), {}
    for _ in range(n_roll):
        tr = sampler.rollout(skill, probe=True)
        R |= tr.reads; W |= tr.writes             # 动态细化
        kappa |= tr.persistent_across_calls
    for x in W:
        lam[x] = classify_owner(x, R, W, kappa)    # private/shared/exported
    return Footprint(R, W, kappa, lam,
                     coverage=len(R | W) / len(X))  # 覆盖度自报
```

### IP-122 SIV（State Isolation Verifier）
```python
def isolation_verify(seq, footprints, concurrency, level):
    U, psi = set(), 0.0
    for i, j in concurrency.pairs(seq):            # 仅并发/相邻交接对
        W_i, R_i = footprints[i].W, footprints[i].R
        W_j, R_j = footprints[j].W, footprints[j].R
        H = (W_i & R_j) | (W_j & R_i) | (W_i & W_j)
        U_ij = H - declared_bridges(seq, i, j)
        U |= U_ij
        psi += contamination_potential(U_ij, footprints)
    if U and psi > PSI[level]:
        return Reject(counterexample=U, psi=psi)    # 反例交给 LLM 修复
    return Accept(iso=1 - len(U) / total_writes(seq), psi=psi, U=U)
```

### IP-123 LPV（LLM Propose-Verify）
```python
def lpv_compose(task, llm, verifier, skills, k_max=2):
    plan, sigma_hat, bridges = llm.propose(task, skills)
    for it in range(k_max + 1):
        sigma_star = {s: state_footprint(s, X, static, sampler) for s in plan}
        diff = differential_check(sigma_hat, sigma_star)   # 漏标/幻觉
        verdict = verifier.verify(plan, sigma_star, bridges)
        if diff.undeclared or verdict.reject:
            ce = verdict.counterexample or diff
            plan, sigma_hat, bridges = llm.repair(task, ce, plan, sigma_hat)
            continue
        return Accept(plan, sigma_star, bridges, iters=it)
    return Reject('repair_budget_exceeded')          # 宁可放弃，不静默放行
```

### IP-124 SIC（State Isolation Certificate）
```python
def isolation_certificate(plan, sigma_star, bridges, level, budgets):
    iso = isolation_verify(plan, sigma_star, concurrency, level)
    if iso.reject: return iso
    ho = check_handoffs(plan, sigma_star, bridges)   # κ 交接完整性
    if not ho.ok: return Reject('hidden_state_leak', ho)
    A_core = reduce(intersection, [s.alpha for s in plan])
    J = joint_certificate(plan, gamma_ce, budgets.delta_a, budgets.rho_min)
    if J.reject: return J
    delta_s = max(iso.psi, ho.staleness)
    if delta_s > THETA_S[level] or level < L_MIN[plan.task]:
        return Reject('isolation_budget_exceeded', delta_s)
    sigma_cert = (iso.U, iso.psi, bridges, level, ho.kappa_owner, ho.checkpoint)
    return Accept(J_plus(J, sigma_cert, delta_s))
```

### IP-125 ESI（Episodic State Isolation）
```python
def episodic_plan(task, llm, O, store, untrusted):
    capsule = store.handoff_for(task) or HandoffCapsule.empty(task)
    ctx = Sandbox(readonly=O, episode=capsule.facts, taint=untrusted)
    plan = llm.plan(task, ctx)
    if ctx.taint.touches(plan.control_writes):       # 污点不得写控制量
        return Reject('taint_leak', ctx.taint.trace())
    promoted = verify_and_extract(plan, capsule)     # 只提升已验证事实
    if contamination(promoted, capsule) > THETA_CTX:
        return Reject('episode_contaminated')
    return plan, HandoffCapsule.make(promoted, provenance=ctx.provenance,
                                     signed=True)
```

### IP-126 CAS（Contamination-Aware Search）
```python
def contamination_aware_search(G, task, level, budgets):
    G2 = G.copy()
    for i, j in list(G.edges):
        iso = isolation_verify([skill[i], skill[j]], fp, concurrency, level)
        if iso.reject:
            G2.remove_edge(i, j)                    # 隔离不可行则剪边
        else:
            G2[i][j]['psi'] = iso.psi
    cost = lambda u, v: (w_a*(1-G2[u][v]['compat'])
                         + w_r*(1-G2[u][v]['rho_comp'])
                         + w_ce*G2[u][v]['align']
                         + w_s*G2[u][v]['psi'])      # 状态污染入成本
    return a_star(G2, task.start, task.goal, heuristic=cost)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SFP | O(\|S\|·(\|X\|+n_roll·T_roll)) | O(\|X\|) | 静态过近似 + 动态细化，覆盖度自报 |
| SIV | O(\|S\|²·\|X\|) | O(\|S\|·\|X\|) | 冲突集完备、桥显式、并发对正确 |
| LPV | O(k_max·(C_LLM+C_verify)) | O(\|S\|·\|X\|) | LLM 不可信、差分 default-deny |
| SIC | O(\|S\|·\|X\| + \|𝔇_ρ\|) | O(\|X\|+\|𝔇_ρ\|) | 交接完整、回滚可逆、δ_s 预算闭合 |
| ESI | O(\|E_t\|+\|T\|) | O(\|E_t\|+\|T\|) | 原始上下文不跨界、污点单向、签名提升 |
| CAS | O(\|S\|²·\|X\| + \|V\|log\|V\|+\|E\|) | O(\|S\|²) | 剪边 sound、成本单调 |

**正确性定理（State-Isolated Composition Soundness）**
在 (A22)–(A28) 成立基础上增加：
**(A29)** 足迹抽取的漏检概率 `P(x∈live∩shared 逃逸静态+动态) ≤ β_f`；
**(A30)** 运行时状态监控在一个控制周期内捕获未声明共享写的概率 `≥ 1-β_m`；
**(A31)** LLM 提议在 `k_max` 轮内被修复或拒绝的概率 `≥ 1-β_L`。
则组合部署成功率满足：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a) - P(compat<θ_a)
                - β_f(1-β_m) - β_L - P(δ_s>Θ_s)
```
关键：**动作兼容、鲁棒谱、状态隔离三轴任一不满足都不得放行**；LLM 只贡献召回，不贡献可信度；运行时监控为静态漏检兜底。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 足迹抽取不完备导致漏检 | 高 | 静态过近似 + 动态 rollout + 运行时影子监控 + default-deny |
| LLM 幻觉/漏标效应 | 高 | 差分验证、反例驱动修复、k_max 限界、永不作为 oracle |
| 过度隔离切断必要交接 | 高 | 显式桥 + 新鲜度预算 + 隔离等级 ℓ 自适应 |
| 隔离开销拖垮实时性 | 中 | 脏页检查点、copy-on-write、只隔离 `κ∪shared` |
| 异步技能竞态/重放不确定 | 高 | happens-before 追踪 + 确定性回放 + 冲突即回滚 |
| 情节沙箱经检索侧信道泄漏 | 中 | 污点标签、签名提升、原始上下文不跨界、定期隔离审计 |

## 6. 本轮最大风险

**一句话**：状态隔离把技能组合的判定轴从“动作兼容 + 鲁棒谱”补全为“动作 × 鲁棒 × 隐藏状态”，并用 LLM 提议-验证把高召回与 soundness 解耦；但其 soundness **仍压在足迹抽取的完备性、LLM 提议的可修复性、运行时监控的及时性**三根支柱上——一旦隐藏状态在静态与动态中都逃逸、LLM 又漏标且监控未能在一个控制周期内捕获，污染会以“动作正确、鲁棒达标、状态已串味”的方式静默传播，故必须坚持 **default-deny + 反例驱动修复 + 运行时影子监控**，宁可组合被拒，绝不把“看不见的状态”当成不存在。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim+SI（SFP×SIV×LPV×SIC×ESI×CAS）

> 承接第 54 轮产物 v31。本轮在“动作空间剖面 + 动作-鲁棒联合证书”之上，补入 **隐藏状态轴**，增加六个算子：
> - **SFP（State Footprint Profiling）**：技能状态足迹 `σ_S=(R_S,W_S,κ_S,λ_S)`，把隐藏状态显式化；
> - **SIV（State Isolation Verifier）**：冲突集 `U=H\D`、隔离度 `ISO` 与污染势 `ψ` 的可判定验证；
> - **LPV（LLM Propose-Verify）**：LLM 高召回提议 + 形式验证裁决 + 反例驱动修复；
> - **SIC（State Isolation Certificate）**：把 `J` 升级为动作-状态-鲁棒三轴证书 `J⁺`；
> - **ESI（Episodic State Isolation）**：LLM 规划器的情节沙箱、污点与单向交接胶囊；

## 2. 关键算法 伪代码

### IP-121 SFP
```python
def state_footprint(skill, X, static, sampler, n_roll=64):
    R, W = static.effect_sets(skill.code)          # 静态过近似
    kappa, lam = set(), {}
    for _ in range(n_roll):
        tr = sampler.rollout(skill, probe=True)
        R |= tr.reads; W |= tr.writes             # 动态细化
        kappa |= tr.persistent_across_calls
    for x in W:
        lam[x] = classify_owner(x, R, W, kappa)    # private/shared/exported
    return Footprint(R, W, kappa, lam, coverage=len(R|W)/len(X))
```

### IP-122 SIV
```python
def isolation_verify(seq, footprints, concurrency, level):
    U, psi = set(), 0.0
    for i, j in concurrency.pairs(seq):
        W_i, R_i = footprints[i].W, footprints[i].R
        W_j, R_j = footprints[j].W, footprints[j].R
        H = (W_i & R_j) | (W_j & R_i) | (W_i & W_j)
        U_ij = H - declared_bridges(seq, i, j)
        U |= U_ij
        psi += contamination_potential(U_ij, footprints)
    if U and psi > PSI[level]:
        return Reject(counterexample=U, psi=psi)
    return Accept(iso=1-len(U)/total_writes(seq), psi=psi, U=U)
```

### IP-123 LPV
```python
def lpv_compose(task, llm, verifier, skills, k_max=2):
    plan, sigma_hat, bridges = llm.propose(task, skills)
    for it in range(k_max + 1):
        sigma_star = {s: state_footprint(s, X, static, sampler) for s in plan}
        diff = differential_check(sigma_hat, sigma_star)   # 漏标/幻觉
        verdict = verifier.verify(plan, sigma_star, bridges)
        if diff.undeclared or verdict.reject:
            ce = verdict.counterexample or diff
            plan, sigma_hat, bridges = llm.repair(task, ce, plan, sigma_hat)
            continue
        return Accept(plan, sigma_star, bridges, iters=it)
    return Reject('repair_budget_exceeded')
```

### IP-124 SIC（含云边状态同步）
```python
def isolation_certificate(plan, sigma_star, bridges, level, budgets):
    iso = isolation_verify(plan, sigma_star, concurrency, level)
    if iso.reject: return iso
    ho = check_handoffs(plan, sigma_star, bridges)      # κ 交接完整性
    if not ho.ok: return Reject('hidden_state_leak', ho)
    # 云边状态同步：云端信念不做隐式共享，必须显式桥 + 陈旧度预算
    sync = cloud_edge_sync(cloud_belief, edge_state, bridges, tau_s=budgets.delta_s)
    if sync.staleness > THETA_S[level]: return Reject('cloud_edge_state_stale', sync)
    A_core = reduce(intersection, [s.alpha for s in plan])
    J = joint_certificate(plan, gamma_ce, budgets.delta_a, budgets.rho_min)
    if J.reject: return J
    delta_s = max(iso.psi, ho.staleness, sync.staleness)
    if delta_s > THETA_S[level] or level < L_MIN[plan.task]:
        return Reject('isolation_budget_exceeded', delta_s)
    sigma_cert = (iso.U, iso.psi, bridges, level, ho.kappa_owner, ho.checkpoint)
    return Accept(J_plus(J, sigma_cert, delta_s))
```

### IP-125 ESI
```python
def episodic_plan(task, llm, O, store, untrusted):
    capsule = store.handoff_for(task) or HandoffCapsule.empty(task)
    ctx = Sandbox(readonly=O, episode=capsule.facts, taint=untrusted)
    plan = llm.plan(task, ctx)
    if ctx.taint.touches(plan.control_writes):        # 污点不得写控制量
        return Reject('taint_leak', ctx.taint.trace())
    promoted = verify_and_extract(plan, capsule)      # 只提升已验证事实
    if contamination(promoted, capsule) > THETA_CTX:
        return Reject('episode_contaminated')
    return plan, HandoffCapsule.make(promoted, provenance=ctx.provenance,
                                     signed=True)
```

### IP-126 CAS
```python
def contamination_aware_search(G, task, level, budgets):
    G2 = G.copy()
    for i, j in list(G.edges):
        iso = isolation_verify([skill[i], skill[j]], fp, concurrency, level)
        if iso.reject:
            G2.remove_edge(i, j)                       # 隔离不可行则剪边
        else:
            G2[i][j]['psi'] = iso.psi
    cost = lambda u, v: (w_a*(1-G2[u][v]['compat'])
                         + w_r*(1-G2[u][v]['rho_comp'])
                         + w_ce*G2[u][v]['align']
                         + w_s*G2[u][v]['psi'])
    return a_star(G2, task.start, task.goal, heuristic=cost)
```

## 3. 关键推导：为什么动作兼容不蕴含状态可隔离

构造反例（H22 的最小见证）：
- 技能 `S_1`（左支撑步态）与 `S_2`（右支撑步态）动作剖面 `α_{S_1}=α_{S_2}`（都在同一关节/足端动作集上可执行），鲁棒谱 `ρ_{S_1}=ρ_{S_2}` 均达标；
- 但 `κ_{S_1}={contact_mode=left}`，`κ_{S_2}` 读取并写入 `contact_mode`，即 `contact_mode ∈ W_1∩R_2`；
- 第 54 轮判据 `compat≥θ_a ∧ c_trans≤τ_e ∧ ρ≥ρ_min` **全部通过**，组合却被放行；
- 状态判据给出 `H_12 ∋ contact_mode`，若 `contact_mode ∉ D_12`，则 `U_12≠∅`，`ψ_12=w_contact·E[|Δcontact|]/1 > 0`，SIC 拒绝或要求显式交接。

由此得**正交性命题**：`(α_{S_1}=α_{S_2}) ∧ (ρ_{S_1}=ρ_{S_2}) ⇏ (U_12=∅)`。故状态隔离不是动作/鲁棒判据的推论，而是独立判定轴。

**污染传播上界**：设组合链 `S_1⊗…⊗S_k`，每步未声明冲突概率 `p_i ≤ β_f`、监控漏报 `β_m`，则一次执行的状态污染事件概率
```
P_contam ≤ 1 - Π_i (1 - p_i·β_m) ≤ Σ_i β_f·β_m = k·β_f·β_m
```
取 `β_f=0.05, β_m=0.1, k=8` 得 `P_contam ≤ 0.04`，与正确性定理中的 `β_f(1-β_m)` 项一致（监控捕获即回滚，不计入失败）。这解释了为何 **运行时影子监控** 必须是证书体系的一部分而非可选优化。

**LLM 提议的风险分解**：设 LLM 足迹召回 `r_L`、精确率 `p_L`，验证器对漏标的差分检出率 `r_V`。可部署提议满足
```
P(accept ∧ unsound) ≤ (1-p_L)·(1-r_V) + (1 - P(repair within k_max))
```
含义：LLM 的收益体现在提高 `r_L`（少漏想），但放行概率由 `r_V` 与修复收敛控制；因此 **LLM 越强越要配强验证器**，否则召回提升会转化为更多“被接受的漏标”。

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SFP | O(\|S\|·(\|X\|+n_roll·T_roll)) | O(\|X\|) | 静态过近似 + 动态细化，覆盖度自报 |
| SIV | O(\|S\|²·\|X\|) | O(\|S\|·\|X\|) | 冲突集完备，桥显式，并发对正确 |
| LPV | O(k_max·(C_LLM+C_verify)) | O(\|S\|·\|X\|) | LLM 不可信，差分 default-deny |
| SIC | O(\|S\|·\|X\|+\|𝔇_ρ\|) | O(\|X\|+\|𝔇_ρ\|) | 交接完整、回滚可逆、δ_s 预算闭合 |
| ESI | O(\|E_t\|+\|T\|) | O(\|E_t\|+\|T\|) | 原始上下文不跨界、污点单向、签名提升 |
| CAS | O(\|S\|²·\|X\|+\|V\|log\|V\|+\|E\|) | O(\|S\|²) | 剪边 sound、成本单调 |

**正确性定理（State-Isolated Composition Soundness）**
假设第 54 轮 (A22)–(A28) 成立，并新增：
**(A29)** `P(x∈live∩shared 逃逸静态+动态) ≤ β_f`；
**(A30)** 运行时状态监控在一控制周期内捕获未声明共享写 `≥ 1-β_m`；
**(A31)** LLM 提议在 `k_max` 轮内被修复或拒绝 `≥ 1-β_L`。
则：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a) - P(compat<θ_a)
                - β_f(1-β_m) - β_L - P(δ_s>Θ_s)
```
关键：**动作、鲁棒、状态三轴同时满足才可部署**；LLM 只贡献召回，验证器贡献 soundness，监控贡献兜底。

## 8. 本轮最大风险

**一句话**：状态隔离把技能组合的判定轴从“动作兼容 + 鲁棒谱”补全为“动作 × 鲁棒 × 隐藏状态”，并用 LLM 提议-验证把高召回与 soundness 解耦；但其 soundness **仍压在足迹抽取的完备性、LLM 提议的可修复性、运行时监控的及时性**三根支柱上——一旦隐藏状态在静态与动态中都逃逸、LLM 又漏标且监控未能在一个控制周期内捕获，污染会以“动作正确、鲁棒达标、状态已串味”的方式静默传播，故必须坚持 **default-deny + 反例驱动修复 + 运行时影子监控**，宁可组合被拒，绝不把“看不见的状态”当成不存在。
