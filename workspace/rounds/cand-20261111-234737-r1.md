# 第 57 轮（承接第 56 轮「证据地图×主动探询×信任协商」IP-127~132；灵感循环第 1 轮；本轮灵感：「零样本泛化」×「通用操作」）

> 第 56 轮把承诺建立在“证据”上：没有 `EV-probe/visit/margin/human` 就不承诺。这套逻辑在“到过的、见过的”世界里是健全的，但一旦走到**没见过的物体、没做过的任务**，证据门就面对一个尴尬的空集：直接证据为零，于是系统只能拒绝（安全但不可用），或者偷偷用语义/几何相似性把 OOD 当 ID（可用但不安全）。更根本的是，第 56 轮的证据都是**结果证据**——“这个东西以前承住过我”。零样本要求我们在**没有结果证据**时仍然行动；通用操作要求一个系统面对成百上千种物体与任务。本轮的核心命题是：**零样本的安全性不能来自相似性，只能来自可证明的结构同态；通用性不能来自万能策略，只能来自可验证原语的组合闭包。**

核心矛盾：
- **H26（零样本 = 结果证据空集，而非证据本身空集）**：第 56 轮的证据门把“没有到访/探针/标注”直接判为不可承诺；但零样本场景中结果证据天然为零。若用特征相似度替代，则相似不等于同构——一个看起来像杯子的新物体可能遵循完全不同的接触物理，语义相似性会把 OOD 静默洗成 ID。
- **H27（通用 = 组合覆盖，而非单策略容量）**：端到端通用策略的失败模式不可枚举、不可证明；跨任务安全性无法由训练分布上的平均成功率保证。把“通用”交给一个黑箱，等价于把“可验证性”交出去。

## 0. 直觉与动机

**灵感 1（零样本泛化 → 把证据从“结果”换成“机制”）**
直觉：人第一次用一把没见过的螺丝刀，并不是因为它“像”以前用过的某把，而是因为**杠杆、摩擦、力矩平衡这些不变量**在新旧物体上同时成立。零样本不是“没有证据”，而是**证据的类型换了**：从“结果证据”（我见过它成功）换成“机制证据”（它的安全相关结构与已知结构同态，且安全证明所依赖的量被保持）。于是安全的依据从**相似性**变成**可迁移的不变量**。

**灵感 2（通用操作 → 通用性住在原语代数和契约里）**
直觉：真正通用的不是“一个网络打天下”，而是“一套接触原语 + 严格的接口契约”：reach/grasp/place/push/pull/insert/handover/tool-use 各自带前置条件、后置条件、保持不变量、失效集合与力/能量界。新任务只要能被分解成这套原语的合法组合，就自动继承每个原语的安全证书。**通用性 = 组合闭包的覆盖，而不是参数量的覆盖。** 对可变形、未知材质，原语只承诺“有界迁移类”，超出即拒绝。

**灵感 3（迁移同态 → 零样本证书是一张“模拟关系”）**
直觉：形式化地说，零样本迁移的安全性可以用**模拟关系/同态 φ** 来刻画：把目标（新物体/新场景）的状态映射到源（已认证场景），要求 (i) 安全规范被保持，(ii) 动力学在 φ 下交换到有界残差 `ε_φ`，(iii) 控制器决策在 φ 下等变。证书不是“它们很像”，而是“**它们的差被一个可测的界 `ε_φ` 吃掉**”。这直接复用了形式化方法里的前向模拟关系，而不是嵌入空间里的余弦距离。

**灵感 4（机制探询 → 探针从估参数升级为打假设）**
直觉：第 56 轮的探针在“估这个区域的 `μ/F_bear`”。零样本下更值钱的是**证伪**：探针的首要任务是找出“哪个不变量其实不成立”。一张迁移证书的强度等于它最弱的那条未证伪假设；因此机制探询按**证伪价值**排序，先打最可能断的假设，再谈估计精度。探针仍需继承非破坏公理，否则“验证薄冰”本身就会踩塌薄冰。

**灵感 5（开放世界弃权 → 不知道就诚实地说不知道）**
直觉：不变量库不可能完备。必须把新颖度分成三态：**ID（有直接证据）/ ZS-cert（无结果证据但有机制证书）/ OOD-unk（连机制对应都找不到）**。第三态的唯一安全动作是**弃权 + 保守回退**。这比“用相似度硬猜”诚实，也比“一律拒绝”可用——系统的价值由**风险预算下的认证覆盖率**衡量，而不是平均成功率。

## 1. 形式化定义（增量：定义 133–138）

**定义 133（证据闭包与新颖度三分）** 直接证据 `E(x)` 同第 56 轮；不变量库 `ℐ={ι}`，`Cl_ℐ(E)` 为 E 在 ℐ 下可推出的闭包。新颖度 `nov(x)=(E(x), Cert_ℐ(x))`：
- `ID`：`E(x)≠∅`；
- `ZS-cert`：`E(x)=∅` 但 `∃T` 使残差 `ε_φ≤δ_mech` 且假设账本对安全关键集闭合；
- `OOD-unk`：其余。

零样本被严格定义为“**结果证据为空、机制证据非空**”，而不是“证据为空”。`OOD-unk` 不是失败，而是系统必须显式支付的弃权决策。

**定义 134（安全保持迁移同态）** 源系统 `S=(X,U,f,ψ)` 已认证；目标 `S'=(X',U',f',ψ')`。迁移同态 `φ:X'→X` 满足：
(T1) **规范保持**：`ψ'(x') ⇒ ψ(φ(x'))`（带裕度 `ρ_φ`）；
(T2) **动力学交换**：`d(φ(f'(x',u)), f(φ(x'),u)) ≤ ε_φ(x',u)`；
(T3) **控制器等变**：`π(φ(x')) = π'(x')`（同一原语/同一认证动作）。

证书 `T=(φ, ε_φ, A_T, cls)`，`A_T` 为未建模物理的假设集，`δ_mech = L_ψ·ε_φ + ε_inv`，其中 `L_ψ` 是安全裕度对状态扰动的 Lipschitz 常数。`T` 是**前向模拟关系**，不是相似度分数。`cls∈{exact, bounded(ε), refuse}` 给出可迁移等级，`refuse` 类原语不得进入零样本承诺。

**定义 135（接触原语代数 CAP）** 原语 `p=(Pre_p, Post_p, Inv_p, Fail_p, C_p)`，`C_p` 含力/能量界、时长、可容忍不确定度、迁移类。组合 `p₁⊗p₂` 合法当且仅当在框架条件 `Inv` 下 `Post_{p₁} ⇒ Pre_{p₂}` 且接口（力/几何/接触模式）兼容；契约按 rely-guarantee 合成：
`Pre=Pre₁`，`Post=Post₂`，`Inv=Inv₁∩Inv₂∩I_iface`，`Fail⊆Fail₁∪Fail₂∪Fail_iface`。

任务 `τ` 的**通用能力** `G(τ)=1 ⇔ ∃` 合法计划 `Π` 精化 `τ`，且每个原语在**实际对象**上经直接或迁移证据认证。覆盖面 `Cov(G)={τ: G(τ)=1}`。

**定义 136（机制探询与假设账本）** 假设集 `H`，探针 `q` 的观测 `o`，信息增益 `IG(q)=H(H)−E_o H(H|o)`，证伪价值 `FV(q)=P(q 能推翻 A 中某假设)·err(h)`。`VOI_m(q)=IG(q)+λ_f·FV(q)−cost(q)`；**证伪优先**。账本 `L_A` 给每条假设打标 `{law, probed, fallback, unprobed}`；提交要求安全关键假设无 `unprobed`，否则弃权或走保守回退。

**定义 137（组合生存核 CVK）** `viable_c(x,Π,𝓜) ⇔` 所有契约与接口不变量成立、`P_fail(Π) ≤ δ_f(g)`、全身动力学可行且 `x∈𝒳_safe`。风险按
`P_fail(Π) ≤ Σ_i P_fail(p_i) + ε_comp`
计（联合界 + 接口误差），`ε_comp` 由 composition shield 在线监测；接口不变量显式包含接触模式一致性（stick/slip/rolling）与交接时的 wrench closure。

**定义 138（通用证据证书 GEC）** `G=(𝓜_core, J_m, {T_i}, L_A, falsify_log, novelty, Cov, probe_log, consent_log)`。每个承诺接触的证据类扩展为五类 `{EV-probe, EV-visit, EV-margin, EV-human, EV-invariant}`；`EV-invariant` 必须挂有效 `T`、`ε_φ≤δ_mech`、假设账本闭合；新颖度为 `OOD-unk` 或存在未证伪的关键假设 → 拒绝/弃权。

### IP-133 ECN（新颖度三分）

```python
def novelty_triage(x, task, M, lib):
    E = direct_evidence(x, M)
    if E.nonempty: return 'ID', E
    certs = [certify(x, T, lib) for T in match_morphisms(x, task, lib)]
    certs = [c for c in certs
             if c.residual <= delta_mech and c.assumptions.closable()]
    return ('ZS-cert', best(certs)) if certs else ('OOD-unk', None)
```

### IP-134 STM（迁移证书）

```python
def certify(x, T, lib):
    phi = T.phi
    res = max(d(phi(f_t(x, u)), f_s(phi(x), u))
              for x, u in sample_boundary(x))
    spec = all(psi_t(x) <= psi_s(phi(x)) + rho_phi for x in sample_states(x))
    A = uncovered_assumptions(x, T, lib)       # 未建模物理的显式假设
    return Cert(phi, res, A, cls=T.cls, valid=spec and res <= delta_mech)
```

### IP-135 CAP（原语组合）

```python
def compose(p1, p2, M, x):
    require(implies(p1.post, p2.pre, frame=p1.inv))
    require(compatible(p1.iface, p2.iface))    # 力/几何/接触模式
    inv  = p1.inv & p2.inv & iface_inv(p1, p2)
    fail = p1.fail | p2.fail | iface_fail(p1, p2)
    return Primitive(p1.pre, p2.post, inv, fail, cost=p1.cost + p2.cost)
```

### IP-136 MPQ（机制探询）

```python
def mechanism_probe(cp, M, ledger, budget):
    for q in sorted(falsification_probes(cp, M, ledger),
                    key=lambda q: voi_m(q, ledger) - cost(q), reverse=True):
        if budget.done() or ledger.critical_closed(): break
        ledger.update(q, execute(q, cap=F_abs))   # 继承非破坏公理
    return ledger
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| ECN | O(\|ℐ\|·C_match) | O(\|T\|) | 三态互斥、无静默 OOD |
| STM | O(N_b·T_dyn) | O(\|φ\|) | 残差可测、规范保持 |
| CAP | O(\|p\|²·C_iface) | O(\|Π\|) | 契合同态、接口可靠 |
| MPQ | O(k_m·C_FV) | O(\|H\|) | 证伪优先、账本闭合 |
| CVK | O(\|Π\|·T_dyn+QP) | O(\|X\|+\|Π\|) | 风险可加、组合 shield |
| GEC | O(\|σ\|+\|L_A\|) | O(\|σ\|) | 五类证据门、弃权完备 |

**正确性定理（Certified Zero-Shot Commitment Soundness, CZCS）**：在 A29–A36 基础上加
**(A37)** 不变量库对安全相关物理**闭合或显式弃权**（未建模项以 `ε_inv` 有界，概率 `≥1−δ_inv`）；
**(A38)** 迁移同态满足 T1–T3 且残差有界；
**(A39)** 组合契约在框架条件下可靠、`ε_comp` 有界；
**(A40)** 机制探针证伪可靠且非破坏。则：

1. **零样本承诺失效率** `≤ δ_f + L_ψ(ε_φ+ε_inv) + ε_comp + ε_cal + δ_probe + ε_h`；
2. **无静默 OOD**：`OOD-unk` 或关键假设未闭合时只能弃权/保守回退，不能承诺；
3. **覆盖单调**：新增认证原语/不变量只增不减 `Cov`，且不破坏已证安全性；
4. **选择性风险**：在覆盖率 `1−α` 下，报告的是认证风险上界，而不是平均成功率。

注意 A37 不是可无条件获得的定理，而是必须被工程化保障的**认识论假设**；这正是本轮把“假设账本 + 弃权”设为一级公民的原因。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 假不变量：证书相对错误模型“正确地错” | 极高 | 证伪优先探针 + 假设账本显式化 + 保守残差 + 弃权 |
| 不变量库不完备（开放世界） | 高 | OOD-unk 三态 + 覆盖率报告 + 保守回退，不宣称万能 |
| 组合接口失配 / 风险累积 | 高 | rely-guarantee 契约 + interface shield + `ε_comp` 预算 |
| 迁移同态不可辨识（多个候选 φ） | 中 | 多候选 φ + 消歧探针 + 残差检验 |
| 基准泄漏导致“伪零样本” | 中 | 未见组合/未见物体划分、禁用测试时任务 ID |
| 探针在未知物体上破坏性 | 高 | 继承 `F_abs` 力帽 + 非破坏审计 + 承载下界预检 |

## 6. 本轮最大风险

**一句话**：本轮把零样本安全建立在“不变量同态”上，但证书只对它显式建模的物理成立——一旦目标物体违反一条**未被写进不变量库**的隐含规律（隐藏柔性、未知摩擦律、非刚性接触），系统会拿着一份“证明正确、事实错误”的证书，比相似性迁移更自信地跨过 OOD 边界；因此必须以**证伪优先探针、显式假设账本、残差保守界与 OOD-unk 弃权**把“未知的未知”挡在承诺之外，宁可少认证，不可假认证。

```python
            M.I[e.inv.id] = update_invariant(M.I[e.inv.id], e,
                                             w=source_weight(e))
        elif e.layer == 'primitive':                # 原语契约（带版本）
            M.P[e.prim.id] = merge_contract(M.P[e.prim.id], e.contract, e.ver)
        elif e.layer == 'transfer':                 # 迁移证书入图
            M.T[(e.src, e.dst)] = e.cert
    M.ver.bump_all(changed or [e.region for e in batch])
    return M, changed
```

> 与第 56 轮“人类标注隔离区”同构：**云端/人类下发的不变量与契约也先进隔离区**，必须经一次本地探针或到访佐证后才能用于 `EV-invariant` 承诺。防止“上游一条错误的不变量”污染全图零样本证书。

### IP-134 STM（Safety-preserving Transfer Morphism）

```python
def certify(x, T, lib):
    phi = T.phi
    # (T2) 动力学交换残差：在安全边界与工作点上采样
    res = max(d(phi(step_target(x, u)), step_source(phi(x), u))
              for x, u in sample_boundary(x, T.u_adm))
    # (T1) 规范保持：目标安全裕度不超过映射回源后的裕度
    spec_ok = all(margin_target(xs) <= margin_source(phi(xs)) + rho_phi
                  for xs in sample_states(x))
    # (T3) 控制器等变：同一原语/动作在两侧决策一致（接口级检查）
    equiv = all(decide_target(xs) == decide_source(phi(xs))
                for xs in sample_states(x))
    # 未建模物理显式化：每条 mismatch 都变成账本里的假设
    A = uncovered_assumptions(x, T, lib)
    cls = T.cls                                  # exact / bounded(eps) / refuse
    valid = spec_ok and equiv and cls != 'refuse' and res <= delta_mech
    return TransferCert(phi=phi, residual=res, rho=rho_phi,
                        assumptions=A, cls=cls, valid=valid)
```

**关键点**：`uncovered_assumptions` 不是内部实现细节，而是**安全接口**。任何“这里假设是刚体/库仑摩擦/无侧隙”的话，都必须成为账本中的一行，并接受证伪探针。

### IP-135 CAP（Contact-primitive Algebra）

```python
def compose(p1, p2, M, x):
    # 框架条件下检查后置 ⇒ 前置
    if not implies(p1.post, p2.pre, frame=p1.inv & p2.inv):
        raise ContractViolation('precondition', (p1, p2))
    if not compatible(p1.iface, p2.iface):        # 力/几何/接触模式/坐标系
        raise ContractViolation('interface', (p1, p2))
    inv  = p1.inv & p2.inv & iface_inv(p1, p2)
    fail = p1.fail | p2.fail | iface_fail(p1, p2)
    cost = p1.cost + p2.cost
    return Primitive(pre=p1.pre, post=p2.post, inv=inv,
                     fail=fail, C=p1.C + p2.C, cost=cost)

def plan_search(task, M, lib):
    for seq in enumerate_primitive_sequences(task, lib):   # 有界深度/预算
        try:
            Pi = fold(compose, seq)
        except ContractViolation:
            continue
        if all(primitive_certified(p, task.obj, M, lib) for p in seq):
            return Pi
        # 未认证的原语：转为机制探询目标，而不是硬上
        task.pending_probes += uncertified_assumptions(seq, M, lib)
    return None
```

### IP-136 MPQ（Mechanism Probing Query）

```python
def falsification_probes(cp, M, ledger):
    out = []
    for h in ledger.unprobed_critical():
        out += probes_that_can_refute(h, cp, M)   # 设计上优先打最弱假设
    return dedup(out)

def mechanism_probe(cp, M, ledger, budget):
    while not budget.done() and not ledger.critical_closed():
        cands = falsification_probes(cp, M, ledger)
        if not cands: break
        q = max(cands, key=lambda q: voi_m(q, ledger) - cost(q))
        if voi_m(q, ledger) < theta_voi: break
        obs = execute(q, cap=F_abs)               # 非破坏公理继承（A34）
        ledger.update(q, obs)
        if ledger.refuted_critical():
            return ledger, 'refuted'              # 立即降级/弃权
    return ledger, ('closed' if ledger.critical_closed() else 'open')
```

**与第 56 轮探询的差别**：第 56 轮问“这个区域的参数是多少”，本轮先问“我关于这个世界的哪条假设是错的”。前者在 OOD 上尤其昂贵，后者能在少量探针内把假证书打掉。

```python
def compositional_viable(x, Pi, M, gait):
```

### IP-138 GEC（Generalist Evidence Certificate）

```python
def generalist_certificate(novelty, sched, log, M, consent_log, budgets):
    # 0) 新颖度：OOD-unk 直接弃权，不给“相似度后门”
    if novelty.cls == 'OOD-unk':
        return ('abstain', 'no_mechanism_evidence', novelty)

    for c in contacts(sched):
        if   c.ev == 'EV-probe':     ok = c.probe.passed and c.probe.nondestructive
        elif c.ev == 'EV-visit':     ok = M.prov[c.region].n_visits >= k_v
        elif c.ev == 'EV-margin':    ok = c.m_s >= theta_m_strict
        elif c.ev == 'EV-human':     ok = c.op_cal >= theta_cal and c.corroborated
        elif c.ev == 'EV-invariant':
            T = c.transfer
            ok = (T.valid and T.residual <= delta_mech
                  and T.assumptions.critical_closed()
                  and not T.assumptions.has_unprobed_critical())
        else:
            return ('reject', 'no_evidence_class', c)      # 无证据不承诺
        if not ok:
            return ('reject', 'evidence_insufficient', c)

    # 1) 组合层检查（本轮的“通用”是在这里被证明的）
    for p in primitives(sched):
        if p.cls == 'refuse': return ('reject', 'untransferable_primitive', p)
    if not interface_invariants_hold(primitives(sched), M):
        return ('reject', 'interface_invariant', sched)
    if sum(p.fail_prob for p in primitives(sched)) + eps_comp > budgets.delta_f:
        return ('reject', 'composition_risk', sched)

    # 2) 继承第 56 轮地图/证据证书检查
    if min(x.K_margin for x in sched) < budgets.theta_K: return ('reject', 'K_margin')
    if rho_sem(sched, M) < budgets.rho_min:             return ('reject', 'rho_sem')
    if semantic_perturbation(M.core) > budgets.Theta_s: return ('reject', 'delta_s')
    if not all(l2.resolved for l2 in consent_log):      return ('reject', 'consent_open')

    return ('ok', GeneralCert(
        map_cert=MapCert(M.core, core_contacts(sched), budgets),
        transfers=[c.transfer for c in contacts(sched) if c.ev == 'EV-invariant'],
        assumption_ledger=L_A, falsify_log=falsify_log,
        novelty=novelty.cls, coverage=Cov(G), probe_log=probe_log,
        consent_log=consent_log))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|

| ECN | O(\|ℐ\|·C_match + \|T\|·N_b) | O(\|T\|) | 三态互斥、`OOD-unk` 无承诺路径 |

| CAP | O(\|p\|²·C_iface + D^d·C_plan) | O(\|Π\|) | 契合同态、接口可靠（A39） |
| MPQ | O(k_m·C_FV) | O(\|H\|) | 证伪优先、`k_m` 预算终止（A40） |
| CVK | O(\|Π\|·T_dyn + QP/SOCP) | O(\|X\|+\|Π\|) | 风险可加、组合 shield、`δ_f(g)` 单调 |
| GEC | O(\|σ\|+\|L_A\|) | O(\|σ\|) | 五类证据门、账本闭合、弃权完备 |

**正确性定理（Certified Zero-Shot Commitment Soundness, CZCS）**

假设 A22–A28（第 53/54 轮）、A29–A32（第 55 轮）、A33–A36（第 56 轮）成立；新增：
- **(A37) 闭包诚实**：不变量库对安全相关物理**闭合或显式弃权**；未建模项对安全裕度的影响以 `ε_inv` 有界，且 `P(违反) ≤ δ_inv`；不能闭合的项必须进入 `OOD-unk`。
- **(A38) 迁移同态**：`φ` 满足 T1–T3，`ε_φ` 由边界采样可测且上界成立。
- **(A39) 组合契约**：`Pre/Post/Inv/Fail` 在框架条件下可靠；接口误差 `ε_comp` 有界；风险按联合界可加。
- **(A40) 机制探针**：证伪可靠（`P(漏检关键违背) ≤ δ_falsify`）且非破坏（继承 A34）。
- **(A41) 覆盖诚实**：`Cov(G)` 只统计“原语全部认证且组合合法”的任务；不得把未认证任务计入覆盖率。

则：
1. **承诺健全性**：任一被 GEC 放行的接触满足
   `P(fail) ≤ δ_f + L_ψ(ε_φ + ε_inv) + ε_comp + ε_cal + δ_probe + ε_h`；
2. **无静默 OOD**：`novelty=OOD-unk` 或关键假设未闭合时，GEC 无放行路径，只能弃权/保守回退/协商；
3. **组合健全性**：计划 `Π` 的失效率不超过各原语失效率之和加 `ε_comp`；接口不变量被在线 shield 监测，违背即降档或停；
4. **覆盖单调性**：新增已认证原语/不变量不会使 `Cov(G)` 减小，也不会绕过 GEC 的逐接触检查；
5. **选择性风险**：对覆盖率 `1−α`，报告的上界是条件风险而非常平均成功率：
   `SR(α) = P(fail | commit, coverage=1−α) ≤ (δ_f + δ_mech + ε_comp + …)/(1−α)`（用校准集估计并给出置信区间）。

**证明要点**：(i) 由 A38，目标轨迹在 `φ` 下与源轨迹的偏差被 `ε_φ` 限制，安全裕度是 Lipschitz 的，故规范保持可传播；(ii) A37 把未建模项限制为 `ε_inv`，否则直接弃权，故不会产生“未覆盖但被认证”的路径；(iii) A39 保证组合的 rely-guarantee 推理不被接口悄悄破坏；(iv) 证据门检查确保每个承诺接触至少有一条证据链，且 `EV-invariant` 的链必须包含闭合账本；(v) 因此击穿需“同态残差超界 ∧ 假设未证伪 ∧ 组合接口失配”同时发生，防御从第 56 轮的单层证据升级为**机制-组合-交互三层纵深**。
