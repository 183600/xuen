# 第 3 轮迭代（灵感循环 v3：「任务规划」×「联邦学习」）—— 从"反应式修补"升级为"价值核算的联邦计划-修复"

> 承接 v2 的 UIP-01′~15。本轮**不是再加一堆点**，而是做**结构性升级 + 精简**：用两个新词各补 v2 的一个结构性缺陷。**任务规划**补"只会 redo、没有全局计划、不会级联修复"；**联邦学习**补"32 个异质任务如何训练成一个合规单模型，以及 N 端口并发下如何只共享'经验'而不共享'状态'"。本轮**不引入新的外部事实**（沿用 2026-11-12 已核实证据），所有新构造明确标注为"推导 / 工作假设"。

---

## 0. 直觉先行（先直觉，后定义）

### 0.1 「任务规划」的直觉

v2 的策略像"按剧本干活、一被破坏就把这一步重做"的工人。真实赛制更像"有个捣蛋鬼不断把你刚做完的步骤偷偷撤回"的厨房。只做单步 redo 有两个坑：

1. **级联失效**：撤回 A 之后，依赖 A 的 B、C 即便"表面还在"也可能已失效——毛巾被翻开后，"第二折已完成"不再成立；碗被拿走第二层后，第三层无处可依。
2. **价值与预算不对称**：各步分值不同（末步恒 ≥ 前序步）、episode 有预算，所以"先修哪步、修到什么程度、何时放弃该步保住其余分"是一个**带价值的调度与重规划**问题，不是原地重做。

一句话直觉：**把"检测-重做"升级成"检测-评估-重规划-修复"**。

### 0.2 「联邦学习」的直觉

32 个任务像 32 个偏科学生：共享一本教材（骨干），各自有笔记（适配器）。评测时 N 个端口并发，规则要求**每端口状态隔离**——机器人不能偷看彼此的实时画面；但可以"课后"交换抽象笔记（参数 / 统计量）。关键界线：**共享参数 / 统计量 ≠ 共享 episode**；前者在离线训练里是常规操作，后者一定违规。

一句话直觉：**联邦学习在这里不是"隐私装饰"，而是"在强隔离约束下唯一合法的经验共享方式"**。

## 2. 严谨定义（先直觉，后形式化）

### 2.1 规划域：把技能图升级为带删除效应的操作符域

**定义 1（规划域）**：\(D=\langle S,O,\Delta,G,w,B\rangle\)

- \(O\) 为技能操作符集合，\(o=\langle pre_o, add_o, del_o, c_o\rangle\)，采用 STRIPS 式前置 / 增 / 删效果；
- \(\Delta\) 为扰动操作符集合，\(\delta=\langle pre_\delta, del_\delta\rangle\)，**只含删除效果**——这正是 `human_*` 的"撤回"语义（T14 拧回、T16 翻开、T19 拉开、T27 拿走第二个）；
- \(G=(g_1,\dots,g_N)\) 为**有序**计分步，分值 \(w_i\)，\(\sum_i w_i=100\)，且 \(w_N\ge\max_{i<N} w_i\)（v2 已核实的计分结构）；
- \(B\) 为 episode 预算（时间 / 调用次数 / 延迟上限）。

**直觉**：技能图只是"能选哪些动作"；规划域还告诉你能不能用、用了会改变什么、别人能删掉什么。

### 2.2 回归与修复闭包

**定义 2（进度状态）**：\(p\in\{0,1\}^N\)，\(p_i=1\) 表示 \(g_i\) 当前成立。无扰动时 \(p\) 单调；扰动 \(\delta\) 执行 \(p_i\leftarrow 0\)。

**定义 3（修复闭包）**：对回归步 \(i\)，令
\[
\mathrm{Depend}(i)=\{j\ge i:\ pre_{o_j}\cap add_{o_i}\neq\varnothing\}
\]
取传递闭包。修复集合 \(R(i)=\{i\}\cup\{j\in\mathrm{Depend}(i):p_j=1\}\)，**按拓扑序修复**。

**直觉**：不是"把第 i 步再做一遍"，而是"把所有因第 i 步失效而悬空的后继一起重验"。

### 2.3 目标函数与回归暴露排程（RES）

正式口径是"成功率 + 步骤分"。在扰动过程下，定义**回归暴露**：
\[
E=\sum_{i=1}^{N} w_i\,\lambda_i\,(T-t_i)
\]
其中 \(\lambda_i\) 是第 i 步完成后的回归风险率，\(t_i\) 是完成时刻，\(T\) 为 episode 结束。最小化 \(E\) 等价于在**前序约束**下最大化 \(\sum_i w_i\lambda_i t_i\)——即把"高权重 × 高回归风险"的步尽量早做（并尽早核验）。

**关键可行性**：\(N\le 5\)，拓扑序至多 \(5!=120\) 种，**离线暴力枚举即可得到每任务的最优暴露排程**，无需近似求解器。这是"任务规划"落到本题最便宜的收益。

### 2.4 价值感知修复索引（VRI）

在线偏离计划后，用索引决定"先修谁 / 还是继续推进"：
\[
I_i=\frac{w_i\,\lambda_i\,(1-b_i)\,s_i}{c_i},\qquad
A_j=\frac{w_j\,s_j}{c_j}
\]
\(b_i\) 为当前完成置信度，\(s_i\) 修复成功率，\(c_i\) 期望代价。若 \(\max_i I_i>\kappa A_j\log_2(1+|R(i)|)\)（级联越深、越要求更高把握）且预算尚存 ⇒ 修 \(\arg\max I_i\)；否则推进。**这是 Whittle / Gittins 风格的索引近似，不宣称最优**，但可解释、可消融、可在线计算。

### 2.5 联邦多任务训练（FMT）：一个合规单模型

**定义 4（联邦目标）**：客户端 \(k=1..K\)（可先按 32 任务，再按技能族聚类），数据 \(D_k\sim P_k\) 为 Non-IID：
\[
\min_{\theta,\{\phi_k\}}\ \sum_{k}\frac{n_k}{N}\Big[F_k(\theta,\phi_k)+\frac{\mu}{2}\|\phi_k-\theta\|^2\Big]
\]
服务端对共享参数 \(\theta\) 做 FedAvg，客户端保留个性化 \(\phi_k\)。**最终提交物是一个 checkpoint**：共享骨干 \(\theta^\*\) + 一个以语言 / 任务嵌入为条件的适配器 \(g_\psi(l)\)，用蒸馏把 \(\{\phi_k\}\) 合并进去：
\[
\min_\psi\ \sum_k \mathbb{E}_{D_k}\big[\mathrm{KL}(\pi_{\theta^\*,\phi_k}\,\|\,\pi_{\theta^\*,\psi}(\cdot\mid l_k))\big].
\]
这样既吃到联邦的抗遗忘 / 抗 Non-IID 收益，又满足"单模型多任务"合规。

### 2.6 联邦计划先验（FPA）与隔离安全条件

**定义 5（计划先验）**：各仿真 / 开发 worker 只上报**充分统计量**：\(n^{reg}_{k,i}\)（第 i 步被撤回次数）、\(n^{repair}_{k,i}\)（修复尝试 / 成功数）。服务端加裁剪与高斯噪声后发布
\[
\hat\lambda_i=\frac{\sum_k n^{reg}_{k,i}+\nu}{\sum_k n_{k,i}+\nu'},\qquad
\hat s_i=\frac{\sum_k n^{repair,suc}_{k,i}}{\sum_k n^{repair}_{k,i}}.
\]

**定义 6（端口隔离下的消息可接受性）**：一条联邦消息 \(m_k\) 合法，当且仅当同时满足
(a) 是 **≥M 个本地 episode 的聚合统计量**，维度与 episode 数 / 身份无关；
(b) 对任一单 episode 满足 \(\varepsilon\)-DP（裁剪 + 噪声）；
(c) **不含**观测、动作、状态、任务身份的原值；
(d) 在**正式计分运行期间默认冻结**（仅离线 / 自建开发端口启用）。

> 这条定义把"联邦学习"从一个热词变成**可检查的合规断言**：违反任一条即视为跨 episode 泄漏。

## 3. 瓶颈假设（更新）

- **H1（最高杠杆）**：回归后的收益主要来自**级联修复 + 重规划**，而非单步 redo；在 T16/T19/T27/T24 这类深依赖任务上差距最大。
- **H2**：在回归风险下，**暴露最优排程（RES）**优于固定顺序，且 \(N\le5\) 可离线精确求解——低风险、可立刻验证。
- **H3**：32 任务强 Non-IID；**FedProx + 个性化适配器 + 蒸馏合并**在"单模型"约束下优于集中式联合训练（更少遗忘、更低方差）。
- **H4**：跨端口"在线联邦"在合规上高风险；**只能把联邦限定在离线仿真 worker / 自建开发端口**，正式运行冻结。
- **H5**：联邦聚合的 \(\hat\lambda_i,\hat s_i\) 若能由 GSO/DRF 校准，可显著锐化 VRI；但先验错时会**放大**级联修复的错误。

## 5. 本轮最大风险

**一句话**：这套方案的最大风险是——**用人工编写的级联依赖与 \(\lambda_i\) 先验（只在仿真里校准）去驱动一个会放大错误的修复计划器，同时让"联邦"在合规边缘试探**；一旦真机回归分布与先验不符，级联修复会把局部误判放大成全局崩盘，而任何跨评测端口的在线聚合都会从"创新"直接变成"违规"。

## 1. 旗舰深潜：UIP-16 · FedPlan

### 1.1 直觉
把 episode 当成一场"带捣蛋鬼的接力赛"：先按**回归暴露最小**排出棒次（RES），跑的时候每 k 步核验，发现某棒被撤回就计算**级联闭包**，用**价值索引**决定先补哪棒、是否放弃、何时保分收手。

### 1.2 机制（四层）
1. **计划层（离线）**：技能图 → STRIPS 操作符域；每任务枚举 \(\le120\) 个拓扑序，按 \(\min E=\sum_i w_i\lambda_i(T-t_i)\) 预计算**暴露最优排程**（\(\lambda_i\) 初值来自 FPA，缺失时用均匀先验）。
2. **感知层（在线）**：DCR-R 每 k 步输出 `done/ongoing/regressed/fail`；`regressed` 触发修复闭包，`done` 推进，`fail` 走重试。
3. **决策层（在线）**：VRI 在"修复闭包 / 推进下一步 / 放弃并保分"三者间选择（见 §2）。
4. **执行层（在线）**：ACS 按阶段定 k（接触密集步小 k）；CSG 给重试/重做设延迟与次数预算；动作块严格按接口形状返回。

### 1.3 与 v2 的本质差异
| 维度 | v2 UIP-01′ | v3 UIP-16 |
|---|---|---|
| 回归后的动作 | redo 当前子目标 | **级联闭包 + 拓扑序修复** |
| 目标 | 启发式"保前置搏末步" | **显式最大化 \(\sum w_i p_i\)**，含暴露排程 |
| 计划 | 技能图路由 | **STRIPS 域 + 前序约束调度** |
| 泛化来源 | 单机数据 | **联邦多任务 + 联邦先验** |
| 失败处理 | 重试 | **目标松弛 / 放弃不可恢复步，保其余分** |

### 1.4 可行性
- \(N\le5\) ⇒ 排程精确枚举，成本可忽略；
- 在线只做查表 + 简单算术，可塞进现有 `get_action` 调用预算；
- 修复闭包依赖图由计分步语义人工 / 半自动生成（32 任务可一次性写好）。

## 2. UIP-17 · VRI / RES（调度内核）

### 2.1 RES：回归暴露排程（离线，精确）
\[
\min_{\text{拓扑序}}\ E=\sum_i w_i\lambda_i(T-t_i)
\iff \max_{\text{拓扑序}}\sum_i (w_i\lambda_i)\,t_i
\]
**推导**：\(T\sum_i w_i\lambda_i\) 为常数，故等价。高 \(w_i\lambda_i\) 的步应尽量早完成。\(N\le5\) 直接枚举。

### 2.2 VRI：在线修复索引
\[
I_i=\frac{w_i\,\lambda_i\,(1-b_i)\,s_i}{c_i},\quad
A_j=\frac{w_j\,s_j}{c_j},\quad
\text{repair if } \max_{i\in R}I_i>\kappa\,A_j\log_2(1+|R|)
\]
- 分母 \(c_i\)：期望步数 / 延迟代价；
- \(\log_2(1+|R|)\)：**级联越深，越要求更高把握**，防止误修复连锁；
- 预算不足或目标物不可恢复 ⇒ `salvage`：放弃该步，重排剩余可达步，保分。

### 2.3 伪代码
```python
def repair_closure(i, p, domain):
    R, frontier = {i}, [i]
    while frontier:
        k = frontier.pop()
        for j in domain.dependents[k]:      # j 的前置依赖 k 的 add 效果
            if p[j] and j not in R:         # 只修复"当前看似完成"的悬空后继
                R.add(j); frontier.append(j)
    return domain.topo_sort(R)

def choose(belief, p, lam, s, cost, w, budget, kappa=0.8):
    if current_event == "regressed":
        R = repair_closure(current_step, p, D)
        idx = {i: w[i]*lam[i]*(1-belief[i])*s[i]/cost[i] for i in R}
        adv = w[next_step]*s[next_step]/cost[next_step]
        if idx and max(idx.values()) > kappa*adv*(1+len(R)).bit_length():
            return ("repair", max(idx, key=idx.get), R)
    if belief[next_step] < done_thr and budget > 0:
        return ("advance", next_step, None)
    return ("salvage", best_reachable_remaining(), None)
```

## 3. UIP-18 · FMT（联邦多任务训练 → 单模型）

### 3.1 客户端与聚类
- 一级客户端：32 个任务数据集（Non-IID）；
- 二级聚类：按技能族（抓/放/插/折/拉链/叠/分拣/开合/挑取）做 **clustered FL**，簇内共享更强、簇间只共享骨干。

### 3.2 目标与更新
\[
\min_{\theta,\{\phi_k\}}\sum_k\frac{n_k}{N}\Big[F_k(\theta,\phi_k)+\frac{\mu}{2}\|\phi_k-\theta\|_2^2\Big]
\]
服务端：\(\theta\leftarrow\sum_k\frac{n_k}{N}\theta_k\)；客户端每轮从 \(\theta\) 出发做带近端项的本地 SGD。

### 3.3 合并成单模型（合规关键）
- 共享骨干 \(\theta^\*\) + **语言/任务条件适配器** \(g_\psi(l)\)；
- 用蒸馏把 32 个 \(\phi_k\) 的行为压进 \(g_\psi\)：
\[
\min_\psi\sum_k\mathbb{E}_{D_k}\big[\mathrm{KL}(\pi_{\theta^\*,\phi_k}\|\pi_{\theta^\*,\psi}(\cdot|l_k))\big]
\]
- 提交物：**一个 checkpoint、一次前向**；不保留 32 个独立模型，避免"多模型"歧义。

### 3.4 为什么不是普通多任务
FedProx 的近端项抑制客户端漂移，个性化 \(\phi_k\) 吸收任务异质，聚类缓解负迁移；这两点直接对应 32 任务 Non-IID 的主要失败模式（遗忘 / 干扰）。

## 4. UIP-19 · FPA（联邦计划先验，安全版）

### 4.1 只传统计量
每个 worker（GSO/DRF 仿真实例或自建开发端口）上报：
- \(n^{reg}_{k,i}\)：第 i 步被撤回次数；
- \(n^{repair}_{k,i}, n^{repair,suc}_{k,i}\)：修复尝试 / 成功；
- 样本数 \(n_{k,i}\)。

服务端：裁剪 + 高斯/拉普拉斯噪声，输出
\[
\hat\lambda_i=\frac{\sum_k n^{reg}_{k,i}+\nu}{\sum_k n_{k,i}+\nu'},\qquad
\hat s_i=\frac{\sum_k n^{repair,suc}_{k,i}+a}{\sum_k n^{repair}_{k,i}+a+b}.
\]

### 4.2 可接受性断言（写进代码）
```python
def admissible(msg, official_run):
    assert not official_run or FEDERATION_FROZEN, "official run: federation must be off"
    assert msg.aggregated_over >= M, "must aggregate >= M episodes"
    assert msg.dimension_independent_of_episode, "no per-episode dimension"
    assert msg.contains_no_raw_obs_act_state_identity, "no raw state leakage"
    assert msg.is_dp(eps=1.0), "clipped + noised"
    return True
```

### 4.3 与 GSO/DRF 的关系
- GSO 提供"判分 + 回归事件"；
- DRF 提供"级联修复演示"；
- FPA 把二者的统计量聚合为 \(\hat\lambda,\hat s\)，供 RES/VRI 使用。
- **正式计分运行期间**：所有联邦聚合冻结（环境变量 / 配置硬开关），只用已冻结的离线先验。

## 6. 实验设计 E201–E210（v3）

| 实验 | 对照 | 指标 | 可证伪判据 |
|---|---|---|---|
| E201 | v2 UIP-01′ 单步 redo vs UIP-16 级联修复 | 步骤分 / 单位预算得分 | 深依赖任务上 UIP-16 显著更高，否则 H1 假 |
| E202 | 固定顺序 vs RES 暴露排程 | 期望步骤分（同一 \(\lambda\)） | RES 不劣且在高 \(\lambda\) 下更优，否则 H2 假 |
| E203 | 均匀修复 vs VRI 索引 | 修复成功率 / 误修复率 | VRI 在同等预算下分更高且误修复率更低 |
| E204 | 集中联合训练 vs FMT(FedProx+适配器) | 32 任务均分 / 遗忘率 | FMT 遗忘率更低，否则 H3 假 |
| E205 | 32 个适配器分别部署 vs 蒸馏合并单模型 | 均分 / 合规标记 | 合并后均分下降可接受且合规，否则重新设计 |
| E206 | FPA 无 DP vs 有 DP（\(\varepsilon\) 扫描） | 先验误差 vs 隐私预算 | 存在 \(\varepsilon\) 使先验仍有效，否则放弃 FPA |
| E207 | 仅仿真先验 vs 仿真+真机锚点 | 先验-真机相关性 \(\rho\) | \(\rho\) 显著提升，否则 H5 假 |
| E208 | 在线跨端口聚合（仅实验） vs 冻结 | 合规风险 / 性能差 | 在线收益若小于合规风险 ⇒ 永久冻结 |

## 7. 合规与风险

- **单模型**：FMT 合并为单 checkpoint；**不使用外部 VLM 验证器**（v2 已识别的合规隐患）。
- **端口隔离**：在线只做每端口私有状态；跨端口只允许"参数 / 充分统计量"，且**正式运行冻结**（UIP-19 §4.2 断言）。
- **离线联邦边界**：FPA 只在 GSO/DRF 仿真 worker 与自建开发端口运行；不接触官方评测 episode。
- **仿真过拟合**：RES/VRI 的 \(\lambda_i\) 先在仿真估，必须用真机时段做锚点（E207）；否则级联修复会放大先验误差。
- **接口红线**：动作块形状 / dtype / 块长严格按 README；返回块长与声明不一致会伤可信度。
- **手册未取到**：位置 / 干扰物 / 背景三轴、评测轮次与时限仍待飞书手册公开后核实。

## 9. 本轮最大风险 & 押注

**一句话**：最大风险是"**人工先验驱动、只在仿真里校准的计划器 + 在合规边缘试探的联邦**"——\(\lambda_i\) / 级联依赖一旦与真机不符，级联修复会把局部误判放大成全局崩盘，而跨端口在线聚合会直接触碰"每端口状态隔离"红线。

**→ 押注：UIP-16（RES + 级联修复 + VRI）× UIP-18（FMT 单模型合并）× UIP-19（仅离线的 FPA 先验）**——它把 v2 的"扰动恢复闭环"从**反应式补丁**升级为**有规划、有价值核算、且合规边界清晰**的闭环；正式运行期完全不跨端口共享状态，把风险压到"先验是否准"这一个可校准变量上。
