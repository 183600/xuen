# 第 58 轮（承接第 57 轮「元推断×跨模态对账×个性化信任」IP-133~138；灵感循环第 4 轮；本轮灵感：「模块化设计」×「因果推理」）

> 第 57 轮把安全的赌注从"模型置信"推到"证据承诺"，再从"证据质量"推到"元先验质量"，并诚实地划下一条边界：**语料里没有的世界不采信**。但这条边界本身仍是一份整体式（monolithic）论证——安全依赖 A33–A40 一长串联合假设，任何一条被新机制悄悄削弱，整条定理一起失效；而"元先验为何会在盲区里自信地错"仍只有现象学描述，没有机制解释。本轮两个灵感各补一块。**模块化设计**说：安全不该是一条越焊越长的定理，而应是一组**有显式假设-保证契约、可独立验证、可替换、可组合**的模块——换一块板子不必重验整台机器，只要新板细化旧契约且接口类型不变；但模块化的代价是**接口泄漏**：被信息隐藏藏起来的内部假设会顺共享通路外溢，于是"局部都安全"并不蕴含"组合安全"。**因果推理**说：此前所有证据本质上都是**观测的**（"看起来干、探起来硬"与"能承重"相关），而承诺是**干预的**（"踩下去/松开手会发生什么"）——隐混杂（埋冰层、油污、维护状态）足以让观测不变性与干预安全性脱钩，这正是"坏先验普遍"的机制：元先验学到的是被混杂污染的关联，而非可迁移的因果机制。于是本轮把两词合流为一个命题：**可组合的因果承诺**——每个安全模块对外只承诺一个**带假设的干预效应界**，模块间以因果接口契约组合，系统级安全由**带证明的组合项**（proof term）承载而非一条整体定理；无法识别的因果量一律给**部分识别最坏界**，绝不伪装成点估计。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为 **"模块可组合、机制可不变、干预可识别（或诚实给界）的因果承诺"**。

核心矛盾：
- **H32（模块化 vs 接口泄漏）**：模块化用信息隐藏换可替换与局部验证，但被藏起来的内部假设会经共享缓存/时序侧信道外溢；"每块都安全"组合起来未必安全，且组合证明越长，跨模块的联合假设越没有人重验。
- **H33（观测 vs 干预）**：历史语料全是观测的，部署承诺全是干预的；隐混杂使观测不变性 ≠ 干预安全性，而混杂的识别又依赖"无未测混杂/正性"这类无法从同一批数据完全验证的假设——安全的赌注从"先验质量"再后移到"因果假设质量"。
- **H34（不变性 vs 可检验性）**：不变因果预测需要多个真环境；若所有环境共享同一混杂，不变性不可检验；跨模态只是准环境，仍可能被同一物理性质联合混杂（第 57 轮"单模态共谋"的因果版）。

## 0. 直觉与动机

**灵感 1（模块化设计 → 安全论证从整体定理变成可组合契约）**
直觉：现在的安全体系像一块越焊越大的单板：每轮加一层护栏、一条假设、一个 union 项，谁也不敢拆、谁也不敢单独换。模块化设计的核心不是"分块"，而是**契约**：Parnas 的信息隐藏要求模块内部藏起来，但安全上藏起来的东西必须由**假设-保证（A/G）契约**显式赎回——模块对外只声明"在我的输入假设 A 下，我对 P_fail 的贡献不超过 G"。组合时，若一块的 G 能 discharge 另一块的 A，即可拼接。于是"换模块"变成"检查细化关系 + 接口类型不变"，而非重验全系统。模块化的致命副作用是**接口泄漏**：内部状态经共享缓存/隐式通路影响外部，声明接口与实际信息流不符，契约名存实亡。故本轮把接口泄漏审计提升为与契约同等的一等公民。

**灵感 2（因果推理 → 从"相关地看"到"干预地问"）**
直觉：前 57 轮反复问"这区域看起来/探起来像不像安全"，那是 P(Y|X)；真正要问的是 P(Y|do(step),X)——踩下去会怎样。两者只在无混杂时相等。冰面之所以骗人，正因"看起来干"与"能承重"背后有一个共同原因（低温 + 薄冰层）同时驱动，观测关联在混杂变化时瞬间失效。因果推理给出三件前几轮没有的工具：**do 演算**把干预查询化为可识别/不可识别的形式问题；**不变因果预测（ICP）**只允许元先验依赖跨环境不变的机制特征，把"坏先验普遍"解释为"机制误识别"；**部分识别**在不可识别时不装作知道，直接给最坏界（自然界/Manski 界），把不确定性转成可承诺的保守量。

**灵感 3（两灵感合流 → 因果是契约的语义，模块是因果命题的组合结构）**
直觉：单有因果，你得到一个巨大 SCM，改一处要重估全身；单有模块，你得到一堆可替换的盒子，却不知道每个盒子到底承诺了什么。合流后：**每个模块的契约内容是一个因果量**（"在假设 A 下，执行 a 使释放失稳概率 ≤ G"），**组合结构是模块代数**（串联/并联/旁路）。因果负责"说什么"，模块负责"怎么拼"。这也让安全证明第一次可以**局部证伪**：某模块的干预效应被新证据推翻，只回滚该模块及其下游闭包，而非整条定理。

**灵感 4（回看第 57 轮最大风险 → 混杂是"坏先验普遍"的机制，干预是它的解药）**
直觉：第 57 轮说风险在"语料盲区"。因果视角把它讲得更准：盲区之所以危险，不是"没见过"，而是盲区里的**因果机制与训练分布不同**，而观测层 OOD 分数只在边缘分布偏移大时才报警；一个"表面特征一样、背后混杂不同"的区域会完美穿过 OOD 门，却在干预下崩。解药不是更多观测语料，而是**用干预去测假设**：设计能改变可疑混杂或直接区分竞争机制的探针（去混杂干预），把"不可检验的无混杂假设"尽量转成"可检验的干预证据"；转不了的，就诚实报告 Γ-敏感界。

**灵感 5（PCE++ → 探针预算按"最弱模块的契约缺口"分配）**
直觉：既然安全由模块契约组合而成，探针就不该按全局 VOI 花，而应优先补**组合项里最弱的那条 discharge 边**——哪条假设最可能不成立、补一次干预能把它从"假设"降级为"已验证"，就往哪儿探。这是把第 57 轮证据门与第 58 轮公平放置的经济学再推一层：**用干预买假设，而不是用观测买置信**。

## 1. 形式化定义（增量：定义 139–145）

**定义 139（模块化安全契约 MSC）** 安全论证分解为模块集 𝔐={M_1,…,M_n}，M_i=(I_i,O_i,c_i)。接口 I_i/O_i 是**类型化因果效应描述子**（查询 (z_r,a) → 效应界 [L,U] + 支持环境集 ℰ_i），不是裸信念。契约 c_i=(A_i,G_i)：A_i 是对输入接口的假设集（无未测混杂、正性、机制不变、接口无泄漏、时延界…），G_i 是对输出的保证（对 P_fail 的贡献上界与失败模式集 F_i）。组合 c_i⊕c_j 合法 ⇔ G_i ⊨ A_j（G_i 能 discharge A_j）。组合器三类：串联（因果链）、并联（风险按次可加上界求和：ΣG）、旁路（回退到保守模块 M_i^⊥）。**可替换性**：M_i' 可替换 M_i ⇔ c_i'⊑c_i（细化：假设更弱或保证更强）∧ I/O 类型不变 ∧ **联合重验**通过（见 CGE）。组合结果是一个**带证明项** J_c（不是布尔标志），记录每条 A 由哪条 G discharge、剩余未 discharge 假设集 A_open。

**定义 140（接口泄漏审计 ILA）** 模块可对外暴露的信息受声明接口约束。声明容量 C_i^decl 由接口类型给出上界，实际容量 C_i^act=I(X_i^{int}; O_i ∪ 共享状态 ∪ 时序侧信道)。泄漏判据 L_i=C_i^act−C_i^decl>ε_leak ⇒ 契约失效，模块强制旁路。检测手段：跨模块互信息/依赖检验、**反事实扰动**（改变内部状态而保持声明接口输入不变，观察下游是否变化）、以及"影子模块"差分回放。

**定义 141（因果不变元先验 CIM）** 结构因果模型 𝔊=(V,E)，V={X 可观区域特征, C 隐混杂, Y 结果（可通行/支撑刚度/释放稳定裕度）, A 干预（探/踏/放）}。元先验只允许依赖**机制不变特征** S_inv，S_inv 由不变因果预测 ICP 从候选集中选出：要求 ∀e∈ℰ（ℰ={模态, 区域簇, 季节, 场地}）P(Y|X_{S_inv},do(A),e) 不变，且在声明检验力 β 下不可拒绝；被拒绝的特征进环境特异集 S_env，只允许任务/场地私有使用。混杂处理：可观测混杂做后门/前门调整；隐混杂做 **Γ-敏感性分析**——报告"需多大的未测混杂优势比才能翻转结论"，Γ≤Γ_max 才可进承诺。区域状态由二分升级为三分：**ID-inv**（机制不变且可识别）/ **ID-conf**（分布内但因果未识别，只进加宽界）/ **OOD-mech**（机制不匹配，退第 57 轮共形带）。这把"坏先验普遍"机制化为"混杂误识别/机制漂移"。

**定义 142（干预证据与部分识别 CIP）** 证据格 ℒ_ev 按"对干预查询的支持强度"排序：EV-obs ⊏ EV-do ⊏ EV-do-inv。探针 p 执行 do(F=f)，给出干预效应估计 τ̂_p=E[Y|do(F=f),z_r]。若可识别（do 演算可约到观测）给 τ̂±δ_id；若不可识别，给**部分识别界** [L_p,U_p]（自然界 + 单调性/有界性假设，必要时 Manski 界），并以**最坏界**进入 P_fail。承诺门：不可逆动作（踩落/释放）要求 U(P_fail)≤δ_f，且仅 EV-do-inv（跨环境不变干预）可进入不可逆必要证据集；EV-do 只可替代一次 L1 佐证；**纯 EV-obs 永远不足以单独承诺不可逆动作**。干预有效性还要求**正性/可行性**：do 值落在执行约束（F_abs、关节力矩、接触时间）内，否则该查询无效、不得计为证据。

**定义 143（模块化因果接口与解释 MCI）** 每个模块对外只暴露**因果接口描述子** D_i=(效应界 [L,U], 支持环境集 ℰ_i, 假设列表 A_i, 敏感界 Γ_i, 反事实说明 CF)，禁止任何下游模块绕过接口直读内部信念或内部状态（否则触发 ILA）。解释内容由"区域属性摘要"升级为"若执行 a，Y 的因果效应为 τ̂∈[L,U]，依赖假设 A；若 A 破，结论翻转为 …"；渲染模态仍按操作者个性化（继承 MXI/PTM），但**假设与敏感界披露是刚性的、不可被个性化隐藏或弱化**。跨模块解释必须引用接口描述子，形成"只通过公开接口讲话"的模块化解释。

**定义 144（可组合证据门 CGE 与证书 J_c）** 证据类升级为 EV-obs / EV-do / EV-do-inv / EV-xmodal（限 L1 且须过 ILA）/ EV-human（auth≥A1、佐证≥corrob\*(auth)、且人模块须 discharge G_h）。每条证据必须携带**来源模块契约实例** c_i 与其假设在本上下文的实例化 A_i(z_r,a)。门通过 ⇔ 组合证书 J_c 可构造：①所有 A 被某条 G discharge，或剩余 A_open 显式列入"未验证假设"并经授权人确认；②接口泄漏审计 ILA 全过；③隐混杂敏感界 Γ≤Γ_max；④部分识别最坏界 U(P_fail)≤δ_f；⑤正性成立。J_c=(模块契约集, discharge 链, 泄漏审计, 因果识别报告, Γ 敏感界, 部分识别界, 假设实例化, 版本/回滚点)。任一关键假设未 discharge 且未授权 ⇒ 拒绝；**禁止用"平均假设/默认无混杂"糊过去**。

**定义 145（PCE++ 因果-模块探-诺-演）** 每检查点：①CIM 定位机制（ID-inv/ID-conf/OOD-mech）；②**契约闭包**：对当前查询选最小模块子集使 A 尽量全 discharge；③若存在 ID-conf / Γ>Γ_max / 不可识别 ⇒ 生成**去混杂探针**（优先使可疑混杂代理变化或直接区分竞争机制的 do 干预），选 EV-do-inv 边际增益最大者；④承诺 ⇔ J_c 可构造；⑤失败时按模块旁路逐级降级（替换为共形/手工模块），不整体崩溃；⑥探针预算按"最弱未 discharge 边的干预价值"分配（因果版 max-min），终止于 {承诺, 绕行, L2 协商, 安全停}。

## 2. 关键算法伪代码（完整版见产物区）

```python
def compose_certificate(modules, query, ctx):        # IP-139: 最小契约闭包
    sub = min_contract_closure(modules, query)        # 覆盖查询所需模块
    J = ProofTerm()
    for m in topo_order(sub):
        if not discharges(J, m.A):                    # 未被前驱 G discharge
            J.open |= {a for a in m.A if not testable(a, ctx)}
        J = J ++ m.G
    if J.open and not authorized(J.open): return None
    return J

def interface_leak_audit(M, shared):                 # IP-140: 泄漏即失效
    for m in M:
        act = mutual_info(m.internal_state,
                          observe(m.outputs, shared, time_channel()))
        if act - m.declared_capacity > eps_leak:
            return 'LEAK', m                         # 强制旁路
    return 'ok', None

def causal_invariant_prior(M, r, obs, meta):         # IP-141
    S_inv = icp_select(meta.candidates, environments=M.envs, alpha=beta)
    x = features(obs)[S_inv]
    if environment_mismatch(M, r, meta):             # OOD-mech
        return Inf(cls='OOD-mech', belt=conformal_belt(meta.res, r, alpha_conf))
    ident = identify(effect_query(r, 'step'), meta.scm)
    if ident.ok:
        return Inf(cls='ID-inv', tau=ident.estimate, delta=delta_id)
    return Inf(cls='ID-conf', bounds=partial_identify(effect_query, meta.scm,
                                                      gamma=gamma_sens(meta)))

def commit_gate_causal(c, M, J, persona):            # IP-143
    if c.ev == 'EV-obs' and c.irreversible: return 'reject', 'obs_never_irreversible'
    if c.ev == 'EV-do'  and c.irreversible: return 'reject', 'do_needs_invariance'
    if c.ev == 'EV-do-inv':
        ok = (c.bounds.U <= delta_f and gamma_sens(M) <= Gamma_max
              and positivity_ok(c.do_value) and c.inv_environments >= n_env)
    elif c.ev == 'EV-xmodal':
        ok = c.level == 'L1' and interface_leak_audit(M, c.shared)[0] == 'ok'
    else:
        ok = round57_gate(c, M, persona)             # EV-obs/human 继承
    return ('ok', c) if ok and J is not None else ('reject', 'contract_open')
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| MSC | O(\|𝔐\|²) 组合检出；缓存 O(1) | O(\|𝔐\|·\|A\|) | discharge 完备、细化关系保持 |
| ILA | O(\|𝔐\|·d_int·H) | O(\|𝔐\|·d_int) | 泄漏漏检 ≤ε_leak、反事实扰动充分 |
| CIM | O(d_φ+\|ℰ\|·N_env) | O(\|𝒟_meta\|) 静态 | 不变集诚实、Γ 敏感界覆盖 |
| CIP | O(d_sep)/查询；部分识别 O(d_sep²) | O(\|𝔐\|+\|ℰ\|) | 识别/部分识别声明忠实、正性 |
| CGE | O(\|σ\|·\|𝔐\|) | O(\|σ\|·\|A\|) | 无证书即拒、纯观测禁不可逆 |
| PCE++ | O(\|CP\|·(k_p+k_c+k_conf)·C_VOI) | O(\|V\|+\|σ\|) | 契约闭包、终止性、局部回退 |

**正确性定理（Composable Causal Soundness, CCS 概要）**：在 A33–A40 上加 (A41) 契约诚实且组合合法（每条 A 被 G discharge 或显式授权）；(A42) 接口泄漏检测完备到 ε_leak；(A43) 因果识别/部分识别声明与 Γ-敏感界诚实、正性成立；(A44) 不变性检验力 β 与"环境不受协变"声明诚实。则：(i) **组合健全性**：J_c 可构造 ⇒ P_fail ≤ Σ_i G_i + δ_id + δ_sens(Γ)；模块替换若满足细化 + 联合重验，则系统界不变；(ii) **因果承诺健全性**：不可逆动作若无 EV-do-inv 则拒绝，若有则 P_fail ≤ δ_f+δ_id+δ_sens(Γ)+ε_meta；(iii) **三分完备**：任何区域落入 {ID-inv, ID-conf, OOD-mech} 之一，无第四态；(iv) **局部证伪**：推翻某模块只回滚其下游闭包，其余证书复用；(v) PCE++ 在 k_probes+k_conf+k_cons 内终止。

def min_contract_closure(modules, query):
    need = effect_vars(query)                          # 查询涉及的结果/干预变量
    sub, covered = [], set()
    for m in reverse_topo(modules):                    # 从输出侧回溯
        if m.O ∩ need and m.id not in {x.id for x in sub}:
            sub.append(m); covered |= m.O | {a for a in m.A}
    return sub                                         # 覆盖查询的最小模块子集

def compose(modules, query, ctx):
    sub = min_contract_closure(modules, query)
    J = ProofTerm()
    for m in topo_order(sub):
        und = [a for a in m.A if not discharges(J, a)]
        for a in und:
            if not testable(a, ctx):
                J.open.add((m.id, a))                  # 显式未验证假设
        J = J >> m.G                                   # 串联组合，风险上界求和
    if J.open and not authorized(J.open, ctx):
        return None                                    # 关键假设未赎回：拒绝
    return J

def substitutable(m_old, m_new):
    return (m_new.contract.refines(m_old.contract)     # c' ⊑ c
            and m_new.I.type == m_old.I.type
            and m_new.O.type == m_old.O.type
            and joint_reverification(m_new, m_old.downstream))  # 不得只做局部检查

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MSC | O(\|𝔐\|²) 组合检出；缓存 O(1) | O(\|𝔐\|·\|A\|) | discharge 完备、细化保持（A41） |
| ILA | O(\|𝔐\|·d_int·H) | O(\|𝔐\|·d_int) | 泄漏漏检 ≤ε_leak（A42） |

| MCI | O(1) | O(\|Exp\|) | 假设刚性披露、禁内部引用 |
| CGE | O(\|σ\|·\|𝔐\|) | O(\|σ\|·\|A\|) | 无证书即拒、纯观测禁不可逆 |
| PCE++ | O(\|CP\|·(k_p+k_c+k_conf)·C_VOI) | O(\|V\|+\|σ\|) | 契约闭包、终止、局部回退 |

**正确性定理（Composable Causal Soundness, CCS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 契约诚实且组合合法：每个模块 A_i 由前驱 G_j discharge，或列入 A_open 并获显式授权，细化关系 c'⊑c 保持接口类型；**(A42)** 接口泄漏检测完备到 ε_leak：实际信息流 C^act 与声明容量 C^decl 之差在阈值内，反事实扰动/影子差分不漏；**(A43)** 因果识别/部分识别声明忠实：可识别的给点界 ±δ_id，不可识别的给自然界/Manski 最坏界，Γ-敏感界诚实，正性（do 值可行）成立；**(A44)** 不变性检验力 β 与"环境集不受协变"声明诚实。则：

1. **组合健全性**：若 J_c 可构造，则 P_fail ≤ Σ_i G_i + δ_id + δ_sens(Γ)；若模块替换满足细化 + 联合重验，则系统级界不变——替换只改变局部项，不放松全局。
2. **因果承诺健全性**：不可逆动作若仅 EV-obs 则被拒（"相关不蕴含可踩"）；若有 EV-do-inv，则 P_fail ≤ δ_f + δ_id + δ_sens(Γ) + ε_meta；ID-conf 路径以部分识别最坏界进入，OOD-mech 路径以共形带最坏值进入。
3. **三分完备**：任何区域落入 {ID-inv, ID-conf, OOD-mech} 之一，无第四态；三分互斥且覆盖。
4. **局部证伪与回滚**：某模块契约被新证据证伪，只回滚其下游闭包（discharge 依赖图上的后代），其余证书复用；因此单调性扩展为"证伪只向保守方向传播"。
5. **终止性/回退**：每检查点探针 ≤ k_probes + k_conf + k_cons，PCE++ 终止于 {承诺, 绕行, L2 协商, 安全停}；单模块失败触发旁路替换，不导致全局崩溃。
6. **部署界**（对检查点与模块取联合界）：

```
P_safe ≥ 1 − Σ_cp [ Σ_i G_i + δ_id + δ_sens(Γ) + δ_probe + ε_h + δ_xm·1[L1] ]
             − P(接口泄漏漏检) − P(A_open 授权误判) − P(模块替换违反细化)
```

关键：**模块化给"可验证的组合结构"，因果给"每个契约的语义内容（干预/不变/混杂）"**；安全证明从"一条整体定理"变成"可局部替换、局部证伪、带证明的组合项"；部分识别保证"不知道就诚实说不知道"，把不确定性变成可承诺的保守界。

## 6. 本轮最大风险

**一句话**：本轮把安全的最终赌注押在"每个模块的无未测混杂/正性/机制不变假设"上，并用模块化把它分散成一堆看似独立的局部契约——最大风险是"**组合证明在形式上闭合、世界的混杂却在模块边界处联合发作**"：每个模块在自己的语料里都通过，接口泄漏与共享隐混杂却让它们一起错，而可替换性又使没有人再为跨模块的联合假设负责；必须以接口泄漏审计、Γ-敏感界、EV-do-inv 仅进不可逆必要证据、以及替换时的联合重验四道护栏，把"组合得起来"与"世界真的如此"分开。
