# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 7 轮；本轮灵感：「共享控制」×「协同控制」）

> 第 60 轮把「执行层→证据层」升级为「认知驱动的场景-执行闭环」：SSM 场景语义、CIEC 意图约束、EPIR 证据隔离、SERC 闭环、PCE++++ 认知预算。但**四个更深层的局限**仍未解决：
> 1. **认知先行仍是「单主体独裁」**：CIEC 把一句「慢点」直接映射为锁定约束，隐含假设「人类意图=确定指令」。真实共享控制中，人的输入常是**带噪声、带犹豫、带试探的连续信号**；直接锁死 ERTC 会把人的不确定误当成确定，且人类与自主系统之间缺少**连续的权限中间态**。
> 2. **EPIR 只覆盖「单机-云端」**：第 60 轮的因果隔离区保证单机器人 EV-exec 不因 ROS 丢包而断裂，但多操作者/多机器人协同下会出现**证据冲突与权限冲突**：两个操作者同时下指令、两台机器人对同一场景给出不同 EV-exec 时，缺少仲裁、共识与责任归属机制。
> 3. **置信度是「自评」的**：第 60 轮的 scene_conf、τ_response 都由单一主体估计，缺少对「人类能力/机器能力」的联合建模。共享控制的核心不是「谁听谁」，而是「**谁在什么通道上更可信**」。
> 4. **切换成本未入预算**：第 60 轮的 B_cog 未包含「权限切换成本」「协同通信成本」「信任校准成本」。频繁接管与协商会造成隐性不稳定，甚至比不共享更危险。

## 0. 直觉与动机

**灵感 1（共享控制 → 权限场/权限向量 SAM）**
直觉：共享控制不是「0/1 交接」，而像调音台上的一排推子：速度、阻抗、轨迹、任务选择各自有一个连续权限系数 α_k。α_k=1 表示该通道全自主，α_k=0 表示该通道全由人主导，中间值是「人机共同作者」。关键洞见：**权限本身是一种稀缺资源**，必须满足单纯形/下界约束，并且安全关键通道永远保留一个「不可让渡的自主否决下界」α_k^min。

**灵感 2（共享控制 → 安全仲裁算子 SAC）**
直觉：简单地把人的指令和机器人的指令做加权平均，可能平均出一个**谁都没想要、而且会撞墙**的动作（人说前进、机器人说停，平均后慢速前进）。因此必须先「仲裁」再「投影」：把混合指令投影到控制障碍函数定义的**安全集**内，且取最小干预投影。关键洞见：**共享控制的安全性不能依赖 α 的正确性**——无论权限怎么分，安全滤波器都必须保留最终否决权。人类输入只是参考，不是安全证书。

**灵感 3（协同控制 → 鲁棒共识 CCC）**
直觉：多机器人/多操作者协同时，直接对动作取平均会被「坏节点」污染；而取中位数又可能丢失证据质量。应使用**证据加权 + 鲁棒几何中位数 + 安全集交集**：每个主体提出 (动作, 证据)，先按证据质量加权，再用抗污染估计器聚合，最后把共识动作投影到所有诚实主体安全集的交集。关键洞见：**协同的是「安全动作集」，不是「原始指令」**；无共识时回退到最小风险动作，而不是强行折中。

**灵感 4（共享 × 协同 → 信任-能力解耦 TCS）**
直觉：权限应该跟随**真实能力**，而不是跟随**主观信任**。人类过度信任机器人会导致监督松弛；机器人过度信任人类会导致危险接管。因此需要双向状态：T_{h→r}（人信任机）、T_{r→h}（机信任人），以及客观能力 C_h、C_r。关键洞见：**信任只决定「何时可交接」，能力才决定「权限给多少」**；两者错配时触发校准干预，而不是直接把权限让出去。

**灵感 5（三灵感合流 → 共享-协同闭环 SCCL）**
直觉：第 60 轮的 SSM/CIEC 提供场景与意图先验；本轮 SAM 把先验转成连续权限；SAC 保证任意权限下的执行安全；CCC 把单机动作扩展为多主体安全共识；EV-exec 回流更新能力与信任；CSAC 保证多主体对场景的「共同理解」不漂移。形成闭环：**场景/意图→能力/信任→权限分配→安全仲裁→协同共识→执行→多主体证据→能力/信任/场景更新**。

**灵感 6（PCE+++++ → 权限预算）**
直觉：共享控制的隐性成本不是算力，而是**人的注意力、交接抖动、协商轮次、信任校准**。因此把第 60 轮的 B_cog 扩展为 B_auth：若 B_intv（干预带宽）耗尽，降低自主权限、固定保守策略；若 B_hand（交接预算）耗尽，冻结当前权限不切换；若 B_cons（共识轮次）耗尽，退化为本地最小风险闭环；若 B_trust（校准预算）耗尽，强制透明化/请求人类确认。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（共享权限模型 SAM）** 共享权限模型 A = (α, A_inv, ρ, F_alloc)。其中：
- **权限向量**：α = (α_1,...,α_m) ∈ [0,1]^m，m 为控制通道数（速度、阻抗、轨迹、任务选择等）；约定 u = α ⊙ u_r + (1−α) ⊙ u_h，α_k=1 为全自主，α_k=0 为全人类。
- **权限不变量**：A_inv = {α | α_k ≥ α_k^min, ∀k∈K_safety}，K_safety 为安全关键通道集合；α_k^min 是不可让渡的自主否决下界。
- **权限分配函数**：F_alloc: (C_r, C_h, L_h, γ_scene, E_h) → α，满足 α ∈ A_inv。C_r/C_h 为机器/人类能力估计，L_h 为人类认知负荷，γ_scene 为场景置信度，E_h 为人类参与度。
- **权限修订周期** ρ：权限不是每帧重算，而是按 ρ 节拍更新，避免 α 高频抖动。

**定义 162（安全仲裁算子 SAC）** 给定状态 s、人类输入 u_h、自主输入 u_r、权限 α、控制障碍函数族 {h_i}：
```
u_blend = α ⊙ u_r + (1−α) ⊙ u_h
S(s) = {u | L_f h_i(s) + L_g h_i(s)·u + γ_i h_i(s) ≥ 0, ∀i; u ∈ U}
u* = argmin_{u∈S(s)} ||u − u_blend||_W^2
```
若 S(s)=∅，不返回折中解，而返回**最小风险控制** u_mrc（制动/保持/退让），并记录「安全集为空」事件。**干预距离** d_int = ||u* − u_blend||_W 衡量安全滤波器对人类/自主混合意图的修正幅度。

**定义 163（双向信任-能力状态 TCS）** 对主体 i∈{h,r}，状态 (C_i, T_{i→j}, L_i)：
- **能力估计**：C_i(t+1) = (1−η_C)·C_i(t) + η_C·r_i(t)，其中 r_i(t)=exp(−λ_D·D⁺_exec(t))·1[无违规] 为证据化可靠性。
- **信任更新**：T(t+1)=clip(T(t)+η_T·(r(t)−T(t))−λ_F·1[near-miss], 0, 1)。
- **信任校准误差**：e_T = |T − C|；e_T > τ_T 触发「校准干预」（解释、强制示范、请求确认），**不直接改变权限**。
- **权限使用规则**：F_alloc 只依赖 C 与 L，不依赖 T；T 仅用于 AHP 的交接时机与人类准备度判断。

**定义 164（协同共识控制 CCC）** 给定 n 个主体，每个主体提出 (u_i, e_i, S_i)，e_i 为证据质量，S_i 为其安全集：
```
w_i = softmax(λ_e·q(e_i) + λ_c·C_i − λ_f·age(e_i))
S_c = ∩_{i∈Honest} S_i
u_c = argmin_{u∈S_c} Σ_i w_i·ρ_H(||u−u_i||)
```
其中 ρ_H 为 Huber 鲁棒损失，等价于证据加权几何中位数；若 S_c=∅ 或共识轮次超限，返回 u_mrc。**协同证据不一致度** D_col = weighted pairwise disagreement({EV_i})；若 D_col > τ_col，先交换证据再重算，不直接投票。

**定义 165（共享-协同控制闭环 SCCL）** 算子 SCCL(M, human_inputs, agents, intent)：
```
① SSM/CIEC: 取第 60 轮场景后验 γ_scene 与意图约束 C_intent
② TCS: 由 EV-exec 历史更新 (C_r, C_h, T_h→r, T_r→h, L_h)
③ SAM: α ← F_alloc(C_r, C_h, L_h, γ_scene, E_h)，并投影到 A_inv
④ 各主体本地 SAC: u_i* ← SafetyArbitrate(u_h,i, u_r,i, α, CBF_i)
⑤ CCC: (u_c, D_col) ← RobustConsensus({u_i*, e_i, S_i})
⑥ AHP: 若 e_T>τ_T 或 C 突变>τ_C 或 D_col>τ_col，触发权限移交/校准
⑦ Execute: telemetry ← execute(u_c)
⑧ EV-exec_i ← build_evidence(telemetry_i)；EPIR-M.append(EV-exec_i)
⑨ TCS/SSM 更新；B_auth 扣减；返回 (u_c, α, EV-exec, D_col, status)
```

**定义 166（权限预算 B_auth 与 PCE+++++）** B_auth = (B_intv, B_hand, B_cons, B_trust)：
- B_intv：单位时间允许的干预/权限修订次数；
- B_hand：允许的权限移交次数；
- B_cons：允许的协同共识轮次；
- B_trust：信任校准/解释交互预算。
```
voi_auth(π) = VOI_meta_pessimistic(π) − cost_cog(π) − cost_exec(π) − cost_auth(π)
cost_auth = λ_h·HumanWorkload + λ_hand·HandoverCost + λ_cons·ConsensusRounds + λ_trust·CalibrationCost
```
降级顺序：B_cons 耗尽 → 本地最小风险闭环；B_hand 耗尽 → 冻结当前 α；B_intv 耗尽 → 降低自主权限并固定保守策略；B_trust 耗尽 → 强制人类确认后继续。

**定义 167（权限移交协议 AHP）** 移交是状态机 H = (NORMAL, REQUEST, RAMP, TRANSFER, CONFIRM, REVERT)：
- **有界权限速率**：|dα_k/dt| ≤ r_max，避免权限突跳造成执行抖动；
- **交接窗口**：人类准备度 g_h ∈ [0,1] 与剩余时间 τ_hand 共同决定是否允许移交；
- **超时回退**：若 τ_hand 内未完成 CONFIRM，自动回到上一安全 α 并记录「移交失败」；
- **安全条件**：移交期间 SAC 始终在线，任何时刻 u* ∈ S(s)。

**定义 168（协同情境一致性 CSAC）** 多主体场景后验 {γ_i} 与阻抗先验 {π_i}：
- **情境不一致度**：D_SA = max_{i,j} JS(γ_i || γ_j) + λ_W·W_2(π_i, π_j)；
- **对齐规则**：若 D_SA > τ_SA，暂停权限移交与协同共识，先执行「证据交换 + 共同观察」；对齐后 D_SA 仍超限则降级为「各自最小风险 + 人工仲裁」。

### IP-161 SAM（共享权限分配）

```python
class SharedAuthorityModel:
    def __init__(self, m_channels, alpha_min):
        self.m = m_channels
        self.alpha_min = np.asarray(alpha_min)  # 每通道自主否决下界
        self.alpha = np.ones(m_channels)
        self.rho = 0.1  # 权限修订周期(s)

    def allocate(self, C_r, C_h, L_h, scene_conf, engagement):
        # 能力差 + 场景置信度 - 人类负荷；信任不进入此式
        raw = (C_r - C_h) + 0.5 * (scene_conf - 0.5) - 0.3 * L_h
        alpha = 1.0 / (1.0 + np.exp(-4.0 * raw))
        alpha = np.maximum(alpha, self.alpha_min)
        alpha = np.clip(alpha, 0.0, 1.0)
        # 参与度低时不允许全人类通道，避免“名义共享、实际无人监督”
        alpha = np.where(engagement < 0.2, np.maximum(alpha, 0.5), alpha)
        self.alpha = alpha
        return alpha
```

### IP-162 SAC（安全仲裁）

```python
def safety_arbitrate(u_h, u_r, alpha, cbf_list, W):
    u_blend = alpha * u_r + (1.0 - alpha) * u_h
    # CBF: Lf_h + Lg_h u + gamma h >= 0  ->  A u + b >= 0
    A, b = build_cbf_constraints(cbf_list)
    u_star = solve_qp_min_norm(u_blend, W, A, b)
    if u_star is None:                      # 安全集为空
        return minimal_risk_control(), "S_EMPTY"
    d_int = np.sqrt((u_star - u_blend) @ W @ (u_star - u_blend))
    return u_star, d_int
```

### IP-163 TCS（双向信任-能力）

```python
class TrustCompetenceState:
    def __init__(self, eta_C=0.1, eta_T=0.05, lam_F=0.2):
        self.C = {'h': 0.7, 'r': 0.7}
        self.T = {'h2r': 0.7, 'r2h': 0.7}
        self.eta_C, self.eta_T, self.lam_F = eta_C, eta_T, lam_F

    def update(self, evidence, near_miss=False):
        r = np.exp(-evidence.D_plus / 10.0) if evidence.verified and not evidence.violation else 0.0
        for k in self.C:
            self.C[k] = (1 - self.eta_C) * self.C[k] + self.eta_C * r
        for k in self.T:
            self.T[k] = np.clip(self.T[k] + self.eta_T * (r - self.T[k])
                                - self.lam_F * float(near_miss), 0.0, 1.0)

    def calibration_gap(self, who='h2r'):
        src, dst = who.split('2')
        return abs(self.T[who] - self.C[dst])
```

### IP-164 CCC（鲁棒协同共识）

```python
def robust_consensus(proposals, safe_sets, tau_col=0.15):
    D_col = evidence_disagreement(proposals)
    if D_col > tau_col:
        return None, D_col, "ALIGN_FIRST"   # 先对齐证据，不投票
    u = weighted_geometric_median([p.u for p in proposals], [p.w for p in proposals])
    S = intersect_safe_sets(safe_sets)
    if S.is_empty():
        return minimal_risk_control(), D_col, "S_INTERSECTION_EMPTY"
    if u not in S:
        u = project_to_set(u, S)
    return u, D_col, "OK"
```

```python
def shared_collaborative_loop(M, human_inputs, agents, intent):
    M.scene_model.update(M.telem_force, M.telem_pos)
    gamma_scene = M.scene_model.get_scene_confidence()
    M.intent_ctrl.receive_intent(intent)          # 第 60 轮 CIEC
    M.tcs.update(M.last_evidence, M.last_near_miss)

    alpha = M.sam.allocate(M.tcs.C['r'], M.tcs.C['h'],
                           M.human_load, gamma_scene, M.engagement)

    local = []
    for a in agents:
        u_i, d_int = safety_arbitrate(human_inputs[a.id], a.policy(M),
                                      alpha, a.cbf_list, M.arb_weight)
        local.append(Proposal(u_i, a.evidence_quality(), a.safe_set(M), a.id))

    u_c, D_col, status = robust_consensus(local, [p.S for p in local], M.tau_col)
    if u_c is None:
        u_c, D_col, status = M.csac.align_then_retry(local, agents)

    ev = execute_and_collect(u_c, agents)
    for e in ev:
        M.epir_m.append(e)
    M.tcs.update(merge_evidence(ev), near_miss=any(e.near_miss for e in ev))

    if M.ahp.should_request(M.tcs, D_col, status):
        M.ahp.request(M.tcs, deadline=M.tau_hand)

    return u_c, alpha, ev, D_col, status, M.budget_auth.status()
```

### IP-166 PCE+++++（权限预算）

```python
class AuthorityBudget:
    def __init__(self, interventions=20, handovers=3, consensus=5, trust=100):
        self.B_intv, self.B_hand = interventions, handovers
        self.B_cons, self.B_trust = consensus, trust
        self.used = dict(intv=0, hand=0, cons=0, trust=0)

    def spend(self, kind):
        self.used[kind] += 1
        return self.used[kind] <= getattr(self, 'B_' + kind)

    def status(self):
        if self.used['cons'] >= self.B_cons:
            return 'LOCAL_MIN_RISK'
        if self.used['hand'] >= self.B_hand:
            return 'FREEZE_AUTHORITY'
        if self.used['intv'] >= self.B_intv:
            return 'CONSERVATIVE_AUTONOMY'
        if self.used['trust'] >= self.B_trust:
            return 'REQUIRE_HUMAN_CONFIRM'
        return 'NORMAL'
```

### IP-167 AHP（权限移交）

```python
class AuthorityHandoverProtocol:
    def __init__(self, r_max=0.5, tau_hand=2.0):
        self.r_max, self.tau_hand = r_max, tau_hand
        self.state = 'NORMAL'

    def request(self, tcs, deadline):
        if tcs.calibration_gap() > 0.3 and tcs.C['r'] < tcs.C['h']:
            self.state = 'REQUEST'
            self.t0 = time.time()
            return {'state': self.state, 'deadline': deadline}

    def ramp(self, alpha_from, alpha_to, dt):
        step = self.r_max * dt
        delta = np.clip(alpha_to - alpha_from, -step, step)
        return alpha_from + delta   # 有界速率，避免权限突跳
```

### IP-168 CSAC（协同情境一致性）

```python
def situation_alignment(scene_beliefs, impedance_priors, tau_sa=0.2):
    D_sa = max(js_divergence(bi, bj) for bi in scene_beliefs for bj in scene_beliefs)
    D_sa += 0.1 * max(wasserstein2(pi, pj)
                      for pi in impedance_priors for pj in impedance_priors)
    if D_sa > tau_sa:
        return 'ALIGN_EVIDENCE', D_sa   # 暂停交接/投票，先共同观察
    return 'ALIGNED', D_sa
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SAM | O(m) 分配 + O(m) 投影 | O(m) | α ∈ A_inv；安全通道下界不被突破 |
| SAC | O(QP)（m 很小，常数级） | O(m + n_cbf) | 若 S(s)≠∅，则 u*∈S(s)，安全前向不变 |
| TCS | O(1) 更新 | O(1) | 信任校准误差有界；权限不直接依赖 T |
| CCC | O(n log n·iter) 鲁棒中位数 | O(n) | f<n/3 时共识偏差有界；S_c 非空则安全 |
| AHP | O(m) 每步 | O(1) | |dα/dt|≤r_max；超时回退上一安全 α |
| CSAC | O(n²) 成对散度 | O(n) | D_SA 超阈值时禁止交接/投票 |

**正确性定理（SHACC）**：
假设 A66–A70 成立：**(A66)** CBF 相对度 1 且安全集在需要时非空；**(A67)** 能力估计误差有界；**(A68)** Byzantine 主体比例 f<n/3，诚实主体提议直径 ≤ D；**(A69)** 权限速率与交接窗口满足 r_max、τ_hand；**(A70)** 场景后验已校准，CSAC 散度可计算。则：
1. **安全不变性**：对任意 α∈A_inv（甚至任意 α∈[0,1]^m），只要 SAC 的 QP 可行，执行 u*∈S(s)，系统对 CBF 定义的安全集前向不变；人类输入与权限分配不能绕过安全否决。
2. **协同鲁棒性**：若 f<n/3 且诚实安全集交集非空，CCC 输出 u_c∈S_c，且与诚实提议区域的偏差由 O(D) 界定；证据不一致超阈值时拒绝投票，避免「先污染后平均」。
3. **权限移交安全**：AHP 的有界速率与超时回退保证 α(t) 连续、无突跳；移交失败回到上一安全权限，安全性不因交接而破坏。
4. **能力-信任解耦**：权限误差由能力估计误差主导，而非信任误差；信任错配只触发校准，不直接导致权限反转，从而抑制过度信任/过度不信任。
5. **预算安全**：B_auth 任一维耗尽即触发确定性降级（本地最小风险/冻结权限/保守自主/人工确认）。

**消融设计**：去掉 SAC（直接混合）应显著增加违规；去掉 TCS 解耦（用信任替代能力）应增加过度信任事故；去掉 CCC 的鲁棒估计（改算术平均）应在 f=1 个恶意节点时崩溃；去掉 AHP 有界速率应出现权限突跳与执行抖动。

### IP-161 SAM（共享权限分配）

```python
class SharedAuthorityModel:
    def __init__(self, m_channels, alpha_min):
        self.m = m_channels
        self.alpha_min = np.asarray(alpha_min)
        self.alpha = np.ones(m_channels)
        self.rho = 0.1

    def allocate(self, C_r, C_h, L_h, scene_conf, engagement):
        raw = (C_r - C_h) + 0.5 * (scene_conf - 0.5) - 0.3 * L_h
        alpha = 1.0 / (1.0 + np.exp(-4.0 * raw))
        alpha = np.maximum(alpha, self.alpha_min)
        alpha = np.clip(alpha, 0.0, 1.0)
        alpha = np.where(engagement < 0.2, np.maximum(alpha, 0.5), alpha)
        self.alpha = alpha
        return alpha
```

### IP-162 SAC（安全仲裁）

```python
def safety_arbitrate(u_h, u_r, alpha, cbf_list, W):
    u_blend = alpha * u_r + (1.0 - alpha) * u_h
    A, b = build_cbf_constraints(cbf_list)      # A u + b >= 0
    u_star = solve_qp_min_norm(u_blend, W, A, b)
    if u_star is None:
        return minimal_risk_control(), "S_EMPTY"
    d_int = np.sqrt((u_star - u_blend) @ W @ (u_star - u_blend))
    return u_star, d_int
```

### IP-163 TCS（双向信任-能力）

```python
class TrustCompetenceState:
    def __init__(self, eta_C=0.1, eta_T=0.05, lam_F=0.2):
        self.C = {'h': 0.7, 'r': 0.7}
        self.T = {'h2r': 0.7, 'r2h': 0.7}
        self.eta_C, self.eta_T, self.lam_F = eta_C, eta_T, lam_F

    def update(self, evidence, near_miss=False):
        r = np.exp(-evidence.D_plus / 10.0) if evidence.verified and not evidence.violation else 0.0
        for k in self.C:
            self.C[k] = (1 - self.eta_C) * self.C[k] + self.eta_C * r
        for k in self.T:
            self.T[k] = np.clip(self.T[k] + self.eta_T * (r - self.T[k])
                                - self.lam_F * float(near_miss), 0.0, 1.0)

    def calibration_gap(self, who='h2r'):
        src, dst = who.split('2')
        return abs(self.T[who] - self.C[dst])
```

```python
class AuthorityBudget:
    def __init__(self, interventions=20, handovers=3, consensus=5, trust=100):
        self.B_intv, self.B_hand = interventions, handovers
        self.B_cons, self.B_trust = consensus, trust
        self.used = dict(intv=0, hand=0, cons=0, trust=0)

    def spend(self, kind):
        self.used[kind] += 1
        return self.used[kind] <= getattr(self, 'B_' + kind)

    def status(self):
        if self.used['cons'] >= self.B_cons:
            return 'LOCAL_MIN_RISK'
        if self.used['hand'] >= self.B_hand:

        if self.used['trust'] >= self.B_trust:
            return 'REQUIRE_HUMAN_CONFIRM'
```

### IP-167 AHP（权限移交）

```python
class AuthorityHandoverProtocol:
    def __init__(self, r_max=0.5, tau_hand=2.0):
        self.r_max, self.tau_hand = r_max, tau_hand
        self.state = 'NORMAL'

    def request(self, tcs, deadline):
        if tcs.calibration_gap() > 0.3 and tcs.C['r'] < tcs.C['h']:
            self.state = 'REQUEST'
            self.t0 = time.time()
            return {'state': self.state, 'deadline': deadline}

    def ramp(self, alpha_from, alpha_to, dt):
        step = self.r_max * dt
        delta = np.clip(alpha_to - alpha_from, -step, step)
        return alpha_from + delta
```

```python
def situation_alignment(scene_beliefs, impedance_priors, tau_sa=0.2):
    D_sa = max(js_divergence(bi, bj) for bi in scene_beliefs for bj in scene_beliefs)
    D_sa += 0.1 * max(wasserstein2(pi, pj)
                      for pi in impedance_priors for pj in impedance_priors)
    if D_sa > tau_sa:
        return 'ALIGN_EVIDENCE', D_sa
    return 'ALIGNED', D_sa
```
