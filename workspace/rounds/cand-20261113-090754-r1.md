# 第 66 轮（承接第 65 轮「VISTA 故障可归因安全时序闭环」IP-214~223；灵感循环第 1 轮；本轮灵感：「夹爪控制」×「跨物体泛化」）

> 第 65 轮 VISTA 把「几何可证伪」升级为「故障可归因」，其自述最大风险一针见血：**归因依赖「故障属于有限假设集」与「视觉/几何独立失效」两个假设**；真实故障常是未知类型的组合，透明/镜面/对抗 patch 会让视觉与几何共享同一个分布外失效源，此时 FIR 会把未知复合故障强行归入最近假设、只膨胀错误的球——**第 64 轮的单点故障升级为「归因错误的复合故障」，而且系统会因为「已经归因」而更自信地继续执行（A88）。** 本轮不再增加第 6 个模态，也不继续扩充假设集，而是把 VISTA 一直当作「已知量」的两样东西拿回台面：**夹爪本身和物体本身**。本轮核心命题是：
>
> **把夹爪从「执行末端」升级为「可编程的物理实验台」，把跨物体泛化从「策略迁移」升级为「可辨识性与证书的迁移」：用物体无关的夹爪参考实验固定测量规范（gauge），用受控激励把「物体物理属性」与「夹爪/传感器/模型故障」分离，用物体相对安全包络与分组 conformal 让证书在物体族之间可携带、在物体族之外显式降级。**

## 0. 直觉与动机

**灵感 1（夹爪控制 → 把夹爪当量具：物体无关的参考实验与规范固定）**
直觉：VISTA 的所有残差都默认「夹爪是可信的、物体是已知的」。但真正跨物体时，最先坏掉的恰恰是这两个默认。夹爪有一个被忽视的优势：**它可以不对着任何物体做实验**。自由空间开合、恒速扫掠、对已知参考件做力斜坡，能单独辨识夹爪自己的力偏置 b_g、力尺度 s_g、背隙/迟滞 δ_b、指面柔顺 c_g——这些量**与部署物体无关**，因此可以迁移。没有这一步，力传感器读数 f_m=s_g·f_true+b_g 与物体刚度 k 只以乘积 s_g·k 出现，**「物体更硬」和「力传感器读数偏高」在观测上不可分**。这不是一个工程细节，而是跨物体泛化一直在偷偷假设掉的**规范自由度（gauge freedom）**。

**灵感 2（夹爪控制 → 受控激励把「物体属性」从「故障」里分出来）**
直觉：VISTA 用「自由空间→轻触→加载」三阶段创造可辨识性，但那是**自然发生**的阶段，不是**设计出来**的激励。夹爪可以主动改变实验条件：同一姿态下用两个不同的目标力夹一次（分离载荷无关的偏置与载荷相关的刚度/模型误差）；小幅改变夹爪开口（分离几何落点偏差与柔顺）；做一次微抬升/微滑移（分离摩擦与质量）。**夹爪控制把「被动观测阶段」升级为「主动实验设计」**：每多一个可控变量，就多一个把物体参数和故障参数分开的方程。关键是这些实验可以被归一化成与物体尺度无关的模板，从而在不同物体上重复。

**灵感 3（跨物体泛化 → 泛化的对象不是策略，而是可辨识性与证书）**
直觉：通常的跨物体泛化追求「策略在没见过物体上也成功」，但 VISTA 的失败模式不是策略不会动，而是**证书在新物体上失效**：残差分布变了、安全力限变了、归因似然变了。于是把泛化目标改写为：不迁移动作，而迁移「**如何测这个物体、如何把测量归一化、如何声明证书对哪一类物体有效**」。物体被压缩成低维物理描述子 φ_o=(m,μ,k,c,σ_break,g_o)，跨物体时只需重新估计 φ_o，而夹爪标定 β_g、故障假设结构、归一化后的 conformal 分数可以复用。**物体变，量具与实验协议不变。**

**灵感 4（跨物体泛化 → 物体相对安全包络与分组 conformal）**
直觉：同一个 5 N 的力，对鸡蛋是灾难，对木块是挠痒。所以安全限不能是绝对力，而应是**物体相对量**：ρ_f=f/f_max(φ_o)、滑移裕度 1−f_min/f、应变比 ε/ε_strain。把安全裕度写在归一化坐标里，证书才可能在物体族之间比较。统计上，用**分组（Mondrian）conformal**：按物体类别/描述子分箱分别校准，保证每个物体组内的覆盖率；对连续描述子漂移用密度比加权 conformal；新物体落在族外时输出 `object_out_of_scope`，只膨胀 r_obj 并要求保守动作——**「新物体」不是「故障」**，二者必须走不同的处置分支。

**灵感 5（合流 → GRACE：Gripper-controlled Reference experiments for Attribution and Cross-object Envelopes）**
闭环：GRC 夹爪参考自标定 → ONP 物体归一化探针库 → ODE 物体描述子估计 → G-FIR 规范固定的联合归因 → AOP 物体感知探针选择 → OSE 物体相对安全包络 → CGC 跨物体分组 conformal → RSC-G/CSC-G 定向膨胀与认证前缀 → AIC-G 跨物体/夹爪对抗认证 → J_grace 证书。第 65 轮把「接触」拆成接触前/中/后；GRACE 把「归因」拆成「**量具可分离、物体可描述、证书有作用域**」三层，并第一次让夹爪**主动为可辨识性负责**。

**灵感 6（GRACE 对 VISTA 的原位升级）**
- **FIR → G-FIR**：从单物体 15 维签名分类，升级为「规范固定后的联合估计」；新增 H_grip（夹爪机构/标定）与 H_obj（物体描述子 OOD），并用「参考件换测」区分二者。
- **AFA → AOP**：探针从「物理动作」升级为「归一化实验设计」，目标从故障互信息升级为「物体参数+故障的联合信息 / 单位物理风险」。
- **VCV/VPG**：视觉残差先按物体描述子归一化，避免把「新物体外观」误判为视觉故障。
- **RSC-V → RSC-G**：新增 r_grip/r_obj；H_grip 时重跑 GRC，H_obj 时只膨胀 r_obj，绝不误伤 r_geo/r_force。
- **CSC → CSC-G**：认证前缀用物体相对裕度，并加物体族作用域门；族外 k* 截断。
- **WCV-V → WCV-G**：搜索域增加物体描述子可信集 C_o 与物体族约束。
- **CSP-V → CSP-G**：技能块签名按物体族归一化，块边要求 J_grace 有效。
- **AIC-V → AIC-G**：干扰集增「欺骗性物体」「规范对消攻击」「夹爪磨损」，并显式建模物体-夹爪共因。
- **J_vista → J_grace**：证书增 object_descriptor_posterior、object_scope、cross_object_coverage、gauge_margin、gripper_calib_ver、ose_margin。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（GRACE 闭环）**：GRACE = (VISTA, GRC, ONP, ODE, G-FIR, OSE, CGC, AOP, RSC-G, CSC-G, WCV-G, CSP-G, AIC-G, J_grace)。定位：VISTA 的「量具可分离 + 物体可描述 + 证书作用域化」升级。不变式：**夹爪参考标定、物体描述子推断、探针设计、联合归因、证书构建只在语义流；实时流只执行归一化探针/安全前缀、采集残差、早停与派发，零学习写操作。**
- **定义 234（夹爪状态与参考标定 GRC）**：命令 u=(q_cmd,f_cmd,v_cmd)，状态 q（开口）、f_m（力测量）、i（电流）。模型 f_m=s_g·f_true+b_g+η、q=q_cmd+δ_b(q_cmd)+ε_q。自由空间（f_true=0）辨识 b_g 与噪声；恒速扫掠辨识 δ_b 与开口尺度；对已知刚度 k_ref 的参考件做力斜坡辨识 s_g 与指面柔顺 c_g。输出 β_g=(ŝ_g,b̂_g,δ̂_b,ĉ_g) 及 Σ_g、版本 ver_g。**GRC 不使用部署物体，故物体无关、可迁移。**
- **定义 235（物体物理描述子与物体族）**：φ_o=(m, μ_s, μ_k, k, c, σ_break, g_o, ε_p)（质量、静/动摩擦、刚度、阻尼、强度、接触几何、塑性参数）。物体族 𝒪={o: φ_o∼P_𝒪}。描述子只是**假设**，其后验 Σ_o 必须一路传播；「在族内」由后验可信集与族支撑的散度判定，而非点估计。
- **定义 236（物体归一化探针 ONP）**：探针 a=(u_{1:T}, 阶段模板, 停止规则)。模板：P0 自由空间开合（GRC）、P1 恒速接近至首触（零力窗）、P2 力控微夹到归一化力比 ρ=f/f̂_max、P3 固定力下小幅开口调制、P4 微抬升/微滑移、P5 纯视觉探针。所有命令无量纲化：速度按物体尺度、力按强度/质量估计归一。风险泛函 R_phys(a,φ_o)=E[max_t(f_n/f_max, ε/ε_strain, slip)]。
- **定义 237（受控激励残差模型与规范自由度）**：对探针 p，测量 y_p 线性化：y_p=S_o(p)φ_o+S_g(p)β_g+S_f(p)θ_f+ε_p。S_g、S_f 为**量具/故障载荷，物体无关**；S_o 依赖物体与探针。若存在非零 (Δφ_o,Δβ_g,Δθ_f) 使所有探针上 S_oΔφ_o+S_gΔβ_g+S_fΔθ_f=0，则分解不可辨识，称**规范自由度**。单次力-位移探针中 s_g 与 k 只以乘积出现，即一维规范。
- **定义 238（规范固定与联合可辨识性）**：GRC 提供 S_o=0 的物体无关约束，参考件提供已知 φ_ref 的约束。堆叠全部探针 Y=Sψ+ε、ψ=(φ_o,β_g,θ_f)，J_GR=SᵀΣ_ε⁻¹S。ψ 可辨识 ⇔ J_GR≻0；规范固定 ⇔ S 的零空间与 (β_g,θ_f) 方向无交。定义 κ_GR=λ_min(J_GR)/λ_max(J_GR) 与规范裕度 γ_g=σ_min(S_eff)。P0→参考件→P1→P2→P3 的**阶梯式设计**逐级固定规范；缺 P0/参考件时 κ_GR 退化。
- **定义 239（夹爪/物体故障假设与 G-FIR）**：在 VISTA 的 ℋ 上增 H_grip（背隙、摩擦、指面柔顺、力尺度/偏置）与 H_obj（物体描述子 OOD/物理参数错）。G-FIR：p(H|ρ,φ_o)∝p(ρ|H,φ_o)p(H)，签名按物体归一化 ρ̃=ρ/σ_o(φ_o)。判别规则：**参考件换测**——同一探针在参考件上复现残差 ⇒ H_grip；只在目标物体上出现 ⇒ H_obj；自由空间即出现 DC 偏置 ⇒ H_force。H_obj 与 H_grip 的分离是跨物体泛化的核心，因为二者在单物体上几乎同形。
- **定义 240（物体相对安全包络 OSE）**：平行夹持 f_min=(1+κ_s)mg/(2μ_s)、f_max=σ_break·A_c(g_o)/S_f；要求 f_min+zσ_fmin≤f_safe≤f_max−zσ_fmax，f_safe=min(f_max/S_acc, f_max−zσ)。归一化 ρ_f=f/f_max、滑移裕度 1−f_min/f、应变比 ε/ε_strain。易损/未知物体用强度下界 σ_break^LB；若 OSE 为空或 f_safe<f_probe_min，禁止接触探针，退 P5/P0。
- **定义 241（跨物体分组 conformal CGC）**：按物体组 g 分层校准，Mondrian 分位 q_g 使 P[s_test≤q_g|g]≥1−α；连续描述子用分箱或密度比加权 w(o)=dP_dep/dP_cal(o)；新物体用后验加权混合分位 q*=Σ_g P(g|o*)q_g 并计入混合覆盖罚。覆盖差距 Δ_cov(g)=|1−α−empirical|；Δ_cov>ε_cov 或 n_g<n_min ⇒ 证书不可迁移。
- **定义 242（物体感知探针选择 AOP）**：a*=argmax_a I(φ_o,ℋ;y(a)|history)/(R_phys(a,φ_o)+λ)，s.t. R_phys≤B_risk、f_n≤f_safe^LB、ε≤ε_strain。夹爪可控变量就是实验设计变量；易损物体只允许 P0/P5/极低力 P1。目标从 VISTA 的「故障互信息」升级为「物体参数+故障的联合信息 / 单位物理风险」。
- **定义 243（物体族作用域与 OOD）**：作用域 Σ_O=(描述子范围, ver_g, 环境)。OOD 分数 d_O 取 φ_o 后验均值到族的马氏距离与密度比；d_O>τ_O 或 n_eff<n_min ⇒ `object_out_of_scope`，r_obj↑、k*←min(k*,1)，且**不得把 OOD 判成 H_geo/H_force**。族外走探索/保守分支，而非故障处置分支。
- **定义 244（RSC-G / CSC-G / WCV-G）**：不确定球增 r_grip、r_obj，r=√(r_geo²+r_force²+r_model²+r_grip²+r_obj²)。H_grip→r_grip↑ 并重跑 GRC；H_obj→r_obj↑ 并收紧 OSE；H_force→r_force↑；H_geo→r_geo↑。CSC-G 用物体相对裕度与 φ_o 后验，越界预算 α_chunk+δ_fi+α_vis+α_obj+α_grip+α_cgc；作用域门不匹配时截断 k*。WCV-G 搜索域增物体可信集 C_o。
- **定义 245（AIC-G 跨物体/夹爪对抗认证）**：ℰ_G=ℰ_V×ℰ_obj×ℰ_grip×ℰ_gauge。ℰ_obj 含欺骗性质量/摩擦/刚度、对抗纹理、透明、易损；ℰ_grip 含磨损、背隙漂移、指面老化；ℰ_gauge 含「同时改物体与传感器尺度使乘积对消」的规范攻击。n_cert 128→160（32 给物体/夹爪/规范）；J_dir 增 gripper_calib_ver、object_scope_hash。
- **定义 246（J_grace 证书）**：J_grace=(J_vista, object_descriptor_posterior, object_scope, cross_object_coverage, gauge_margin, gripper_calib_ver, ose_margin, probe_log, aic_g_ver)。Valid ⇔ Valid(J_vista) ∧ γ_g≥γ_min ∧ (object∈Σ_O ∨ 已显式 OOD 并降级) ∧ Δ_cov≤ε_cov ∧ OSE 非空 ∧ 探针风险≤B_risk。
- **定义 247（物体条件可交换性）**：归一化分数 s(o) 在物体族内**物体条件可交换**：对任意校准集与同族新物体 o*，给定描述子分箱后 (s_1,…,s_n,s_{o*}) 可交换。这是 CGC 覆盖率的唯一统计假设；物体族漂移、夹爪版本变化都会破坏它，必须显式检验并计入 δ_scope。
- **定义 248（GRACE 闭环算子）**：语义流 [VISTA 语义流→GRC 夹爪参考标定→ONP 生成归一化探针→ODE 估 φ_o→G-FIR 规范固定联合归因→AOP 选探针→OSE 物体相对包络→CGC 分组 conformal→RSC-G→CSC-G→WCV-G→CSP-G→AIC-G]；实时流 [锚点读→探针/前缀执行→力/位/视觉残差采集→归一化→早停→J_grace 构建]。

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（阶梯式规范固定）**：P0 自由空间使 S_o=0，先隔离 β_g；参考件已知 φ_ref 隔离 s_g；扣除后物体探针只需 S_o 列满秩即可辨识 φ_o。缺 P0/参考件时存在零空间向量 (Δk,Δs_g) 满足 s_gΔk+kΔs_g=0，J_GR 奇异——这正是「物体更硬」与「力读数更高」不可分的根源。
- **引理 10（物体相对包络的迁移覆盖）**：若 P[φ_o∈C_o]≥1−α_o，且对 C_o 内所有 φ_o 归一化安全裕度≥0，并且分数物体条件可交换，则新同族物体上 P[越界]≤α_o+α_cgc。证明用可信集与 conformal 的联合界；族外时 α_scope 显式进入预算。
- **定理 9（GRACE 端到端跨物体归因-安全）**：在 A94–A99 下，Valid(J_grace) ⇒ 规范已固定、物体在作用域内（或显式 OOD 降级）、故障被正确归因或显式 ambiguous、块前缀安全；单块越界概率 ≤α_chunk+δ_fi+α_vis+α_obj+α_grip+α_cgc。
- **定理 10（跨物体泛化误差界）**：新物体 o* 的归一化风险估计误差满足 |R(o*)−R̂(o*)| ≤ L_φ‖φ̂_o−φ_o‖ + L_scope·d_𝒪(P_{o*},P_cal) + coverage_gap。故泛化误差由**描述子估计误差与族漂移**控制，而不是由策略误差控制；这给出「先量物体、再谈泛化」的严格理由。
- **命题（探针的单位风险信息）**：线性高斯下，D-最优探针设计在风险预算内呈注水解；AOP 的贪心「边际信息/风险」是其可行近似，且当信息函数自适应次模时具 (1−1/e) 近似保证。风险预算把「更准」与「更安全」放在同一目标里。
- **实时性**：GRC/ODE/G-FIR/AOP/CGC 全在语义流；实时流只增归一化（<0.05ms）、作用域门（<0.02ms）、OSE 查表（<0.01ms）与 CSC-G 早停（<0.02ms），目标 ≤2.6ms（A99 修订契约）。

## 5. 本轮最大风险

## 2. 形式化定义（完整版）

**定义 233（GRACE 闭环）** GRACE 是 VISTA 的「量具可分离 + 物体可描述 + 证书作用域化」升级：保留 GRIP/VISTA 的语义流/实时流骨架，新增 GRC（夹爪参考标定）、ONP（物体归一化探针）、ODE（物体描述子估计）、G-FIR（规范固定联合归因）、OSE（物体相对安全包络）、CGC（跨物体分组 conformal）、AOP（物体感知探针选择），并原位升级 RSC-V→RSC-G、CSC→CSC-G、WCV-V→WCV-G、CSP-V→CSP-G、AIC-V→AIC-G、J_vista→J_grace。不变式：**夹爪参考标定、物体描述子推断、探针设计、联合归因、证书构建只发生在语义流与低频线程；实时路径只做归一化、探针/安全前缀执行、残差采集、早停与派发，零学习写操作。**

**定义 234（夹爪状态与参考标定 GRC）** 夹爪命令 u=(q_cmd,f_cmd,v_cmd)，内部状态 q（实际开口）、f_m（力测量）、i（电机电流）。一阶模型
f_m = s_g·f_true + b_g + η,  q = q_cmd + δ_b(q_cmd) + ε_q,
其中 s_g 为力尺度、b_g 为力偏置、δ_b 为背隙/迟滞、η/ε_q 为噪声。GRC 用三类**物体无关**实验辨识 β_g=(s_g,b_g,δ_b,c_g)：
1. **自由空间开合**（无物体，f_true=0）：恒速开/合、停顿、反向，估 b_g、噪声与 δ_b 的速率依赖；
2. **恒速扫掠**：以多个速度扫掠，拟合 δ_b(q_cmd) 与开口尺度；
3. **参考件力斜坡**：对已知刚度 k_ref、已知几何的参考件做慢斜坡，f_true≈k_ref·δ，估 s_g 与指面柔顺 c_g。
输出 β_g、协方差 Σ_g、版本 ver_g。**GRC 不使用部署物体，因此物体无关、可跨物体迁移；ver_g 变化时 J_grace 必须重签。** 关键：没有 GRC 时，单次力-位移观测只给 s_g·k 的乘积，物体刚度与力尺度不可分（定义 237 的规范自由度）。

**定义 235（物体物理描述子与物体族）** 物体 o 由低维物理描述子
φ_o=(m, μ_s, μ_k, k, c, σ_break, g_o, ε_p)
刻画：m 质量、μ_s/μ_k 静/动摩擦、k 刚度、c 阻尼、σ_break 强度、g_o 接触几何（曲率/法向/接触面积）、ε_p 塑性/非线性参数。物体族 𝒪={o: φ_o∼P_𝒪}。描述子是**假设而非真值**：ODE 输出后验 p(φ_o|probe_log)（均值、协方差 Σ_o，必要时用粒子/归一化流），所有下游（OSE、CGC、G-FIR）必须传播 Σ_o。判定「在族内」不使用点估计，而用可信集 C_o 与族支撑的散度（定义 243）。

**定义 236（物体归一化探针 ONP）** 探针 a=(u_{1:T}, 阶段模板, 停止规则)。模板库：
- **P0 自由空间开合**：不对物体，供 GRC；
- **P1 恒速接近至首触**：零力窗，测首触位置/法向/接近速度；
- **P2 力控微夹到归一化力比 ρ=f/f̂_max**：测力-位移、刚度、接触面积；
- **P3 固定力下小幅开口调制 Δq**：测接触几何/柔顺/背隙；
- **P4 微抬升/微滑移**：测摩擦、质量、滑移起始；
- **P5 纯视觉探针**：运动视差/主动视觉，不接触。
所有命令无量纲化：接近速度按物体尺度 √(g·size)，目标力按 f̂_max(φ_o) 的分数，开口调制按接触斑尺度。探针风险泛函
R_phys(a,φ_o)=E[max_t( f_n(t)/f_max(φ_o), ε(t)/ε_strain, slip(t) )]。
归一化使同一模板可跨物体复用；这也是「实验协议可迁移」的具体含义。

**定义 237（受控激励残差模型与规范自由度）** 对探针 p，测量 y_p（力、力矩、开口位移、滑移起始、视觉残差）线性化：
y_p = S_o(p)·φ_o + S_g(p)·β_g + S_f(p)·θ_f + ε_p,  ε_p∼N(0,Σ_ε)。
其中 S_g、S_f 是**量具/故障载荷**，与物体无关；S_o 依赖物体与探针。若存在非零 (Δφ_o,Δβ_g,Δθ_f) 使
S_oΔφ_o + S_gΔβ_g + S_fΔθ_f = 0  （对所有可用探针 p）
则分解不可辨识，称**规范自由度**。典型例子：单次力-位移探针中 f_m=s_g·k·δ，只有乘积 s_g·k 可观测；零空间方向为 (Δk,Δs_g) 满足 s_gΔk+kΔs_g=0。另一个例子：几何落点偏差与夹爪开口零位偏差在单一 P1 探针上同形，需要 P3 的开口调制来分离。

**定义 238（规范固定与联合可辨识性）** GRC 提供 S_o=0 的物体无关约束（P0），参考件提供已知 φ_ref 的约束。堆叠所有探针：
Y = Sψ + ε,  ψ=(φ_o,β_g,θ_f),  J_GR=SᵀΣ_ε⁻¹S。
ψ 可辨识 ⇔ J_GR≻0；**规范固定** ⇔ S 的零空间与 (β_g,θ_f) 方向无交（即不存在只靠改物体参数就能吸收量具/故障变化的模式）。定义
κ_GR=λ_min(J_GR)/λ_max(J_GR),  γ_g=σ_min(S_eff),
其中 S_eff 是投影掉参考件已知方向后的有效设计矩阵。**阶梯式设计** P0→参考件→P1→P2→P3 逐级固定规范：P0 隔离 β_g，参考件隔离 s_g，剩余探针只需 S_o 列满秩即可辨识 φ_o。缺 P0 或缺参考件时，对应方向坍缩，J_GR 奇异或病态。

**定义 239（夹爪/物体故障假设与 G-FIR）** 在 VISTA 的 ℋ={H0,H_geo,H_force,H_model,H_vis,H_policy} 上增：
- **H_grip**：夹爪机构/标定故障（背隙、指面摩擦、指面柔顺、力尺度/偏置漂移）。签名：**命令-响应失配**在自由空间与参考件上就出现，且随载荷呈迟滞；**物体无关**。
- **H_obj**：物体描述子 OOD 或物理参数错（新物体、非线性材料、内部动力学）。签名：物体归一化残差 ρ̃ 偏大，但量具通道（P0/参考件）一致；**只在目标物体上出现**。
G-FIR 后验
P(H|ρ,φ_o) ∝ p(ρ|H,φ_o)·P(H),
签名先按物体归一化 ρ̃=ρ/σ_o(φ_o)。**参考件换测（reference swap）**是核心判别器：把同一探针在参考件上复现一次——
- 残差在参考件上**复现** ⇒ H_grip（量具问题，与物体无关）；
- 残差**只在目标物体上出现** ⇒ H_obj（物体问题）；
- 自由空间即出现 DC 偏置 ⇒ H_force（力传感器偏置）；
- 视觉落点/法向不符而力通道一致 ⇒ H_geo（沿用 VISTA VCV 门控）。
定向处置：
- H_grip：r_grip↑，**重跑 GRC**，更新 ver_g，不降级几何；
- H_obj：r_obj↑，收紧 OSE（用强度下界），进入保守探索/换抓取策略，**不判 H_geo/H_force**；
- H_force：r_force↑，零力窗重标定（沿用 VISTA）；
- H_geo/H_model/H_vis/H_policy：沿用 VISTA 定义 221；
- ambiguous：进入 AOP 或参考件换测。

**定义 240（物体相对安全包络 OSE）** 对平行夹持，物体相关的最小/最大力
f_min(φ_o) = (1+κ_s)·m·g / (2·μ_s),
f_max(φ_o) = σ_break·A_c(g_o) / S_f,
其中 κ_s 为滑移裕度，A_c 为接触面积，S_f 为强度安全系数。要求
f_min + z_{1−α}σ_fmin ≤ f_safe ≤ f_max − z_{1−α}σ_fmax,
f_safe = min(f_max/S_acc, f_max − zσ_fmax)。
归一化量：ρ_f=f/f_max、滑移裕度 ρ_slip=1−f_min/f、应变比 ε/ε_strain。**安全裕度写在归一化坐标里**，才可跨物体比较与迁移。易损/未知物体用强度下界 σ_break^LB（视觉/材料先验/极低力探针）：
- 若 OSE=∅ 或 f_safe<f_probe_min ⇒ 禁止接触探针，退 P5/P0；
- 若 σ_break 只知下界，则 f_max 用下界，证书显式标注 `strength_lower_bound=True`。

**定义 241（跨物体分组 conformal CGC）** 标定集按物体组 g（类别或描述子分箱）分层。对每组 g，取归一化分数 s_i（归一化残差或归一化安全裕度）的 Mondrian 分位
q_g = ⌈(n_g+1)(1−α)⌉/n_g 分位数，
使 P[s_test≤q_g | g]≥1−α。连续描述子漂移用密度比加权 w(o)=dP_dep/dP_cal(o)（Tibshirani 加权 conformal）；新物体 o* 用后验加权混合分位
q* = Σ_g P(g|o*)·q_g,
并把混合覆盖罚 δ_mix 计入预算。定义组覆盖差距
Δ_cov(g)=|1−α − empirical_coverage(g)|。
判定：Δ_cov>ε_cov 或 n_g<n_min ⇒ 该组证书不可迁移；o* 的后验跨多组且最大组权重<δ_g ⇒ `object_scope_ambiguous`，取最保守 q_g 并截断 k*。

**定义 242（物体感知探针选择 AOP）** 探针 a=(模板, 归一化命令, 停止规则)。选择
a* = argmax_{a∈A} I(φ_o, ℋ; y(a) | history) / (R_phys(a,φ_o)+λ),
s.t. R_phys(a,φ_o)≤B_risk, f_n≤f_safe^LB, ε≤ε_strain, 支持早停。
夹爪的可控变量（接近速度、目标力、开口调制幅度、微抬升高度）就是**实验设计变量**。目标从 VISTA AFA 的「故障假设互信息」升级为「物体参数 + 故障的联合信息 / 单位物理风险」：因为跨物体时，先把 φ_o 估准，故障归因才有意义。易损物体（f_safe<f_min_probe 或 σ_break^LB 低）只允许 P0/P5 与极低力 P1；边际信息<δ_fi 时放弃物理探针。

**定义 243（物体族作用域与 OOD）** 证书作用域
Σ_O = (描述子范围, ver_g, 环境范围)。
OOD 分数
d_O = sqrt( (φ̂_o−μ_𝒪)ᵀ Σ_𝒪⁻¹ (φ̂_o−μ_𝒪) ) + λ_d·log( p_𝒪(φ̂_o)/p_dep(φ̂_o) )。
判定：d_O>τ_O 或 n_eff<n_min ⇒ `object_out_of_scope`。处置：r_obj↑、OSE 收紧到最保守、k*←min(k*,1)、禁止把该样本用于在线故障学习。**关键区分**：OOD 物体不是故障，不能走 H_geo/H_force 的「降级几何/重标定力」分支；它走「探索/换策略/保守抓取」分支。反过来，故障也不能被「新物体」解释掉——用参考件换测切断这条逃逸路径。

**定义 244（RSC-G / CSC-G / WCV-G / CSP-G）** 维护五个独立不确定半径 r_geo、r_force、r_model、r_grip、r_obj，融合
r = sqrt(r_geo² + r_force² + r_model² + r_grip² + r_obj²)。
RSC-G 只膨胀被归因者：H_grip→r_grip↑ 并重跑 GRC；H_obj→r_obj↑ 并收紧 OSE；H_force→r_force↑；H_geo→r_geo↑；H_model→r_model↑。相比 VISTA 的 r_geo/r_force/r_model，新增的两个球把「量具问题」和「新物体问题」从几何/力故障中分离，避免跨物体时误降级正确几何。
CSC-G 的认证前缀：对块 A 与前缀 k，在物体后验可信集 C_o 与故障后验支持集上逐一验证物体相对裕度 ρ_safe≥0；越界预算
α_total = α_chunk + δ_fi + α_vis + α_obj + α_grip + α_cgc。
作用域门：object∉Σ_O ⇒ k*←min(k*,1)（只执行一步后强制重估/重规划）。约束 k*≤m（不可逆视界，沿用 VISTA）。
WCV-G 的搜索域增物体可信集：B(φ̂,r)∩𝒢(g)∩K(μ̂)∩ℱ(f_lim)∩𝒱∩C_o；C_o 为空时回退保守包络并置 `object_scope_conflict=True`。
CSP-G 的技能块签名按物体族归一化；块边要求 Valid(J_grace) 且 k*≥1；技能可插入 `grc_probe`、`obj_probe`、`reference_swap` 元技能。

**定义 245（AIC-G 跨物体/夹爪对抗认证）** 干扰集
ℰ_G = ℰ_V × ℰ_obj × ℰ_grip × ℰ_gauge,
- ℰ_obj：欺骗性质量/摩擦/刚度（外观像重物实则轻、表面像高摩擦实则低）、对抗纹理、透明、易损、内部空腔；
- ℰ_grip：指面磨损、背隙漂移、力尺度温漂、单指卡滞；
- ℰ_gauge：**规范对消攻击**——同时改变物体刚度与力传感器尺度，使单次力-位移观测的乘积不变，专门攻击「只做一次测量」的系统。
n_cert 128→160（其中 32 给物体/夹爪/规范）；ρ_dir 在 ℰ_G 上重算；ρ_force 在最坏偏置与最坏物体下取最坏。J_dir 增 gripper_calib_ver、object_scope_hash。**规范对消攻击下不要求归因正确，只要求 γ_g 下降能被检出并触发补测（P0/参考件）或安全降级。**

**定义 246（J_grace 证书）**
J_grace=(J_vista, object_descriptor_posterior, object_scope, cross_object_coverage,
         gauge_margin, gripper_calib_ver, ose_margin, probe_log, aic_g_ver)。
验证规则：
Valid(J_grace) ⇔ Valid(J_vista)
∧ γ_g ≥ γ_min（规范已固定）
∧ (object∈Σ_O ∨ 已显式 `object_out_of_scope` 并降级)
∧ Δ_cov ≤ ε_cov（分组覆盖差距可接受）
∧ OSE 非空且 f_safe 有正裕度
∧ 探针累计风险 ≤ B_risk
∧ gripper_calib_ver 为当前版本
∧ aic_g_ver 为当前版本。
审计链新增：尺子是否校准（gripper_calib_ver）、物体是什么/有多确定（object_descriptor_posterior）、证书对哪个族有效（object_scope）、规范是否可辨识（gauge_margin）、归一化安全裕度（ose_margin）。

**定义 247（物体条件可交换性）** 归一化分数 s(o) 在物体族内**物体条件可交换**：对任意校准集 {o_1,…,o_n} 与同族新物体 o*，给定描述子分箱 g 后，{s(o_1),…,s(o_n),s(o*)} 在组 g 内可交换。这是 CGC 覆盖率的唯一统计假设。以下任一情况破坏它，必须显式检验并计入 δ_scope：
1. 物体族漂移（部署分布偏离校准分布）；
2. 夹爪版本变化（ver_g 不同，量具分布变）；
3. 描述子分箱过粗（组内异质）；
4. 选择偏差（只挑「看起来好抓」的物体做校准）。

**定义 248（GRACE 闭环算子）** 语义流：[VISTA 语义流 → GRC 夹爪参考标定 → ONP 生成归一化探针 → ODE 估 φ_o → G-FIR 规范固定联合归因 → AOP 选探针/参考件换测 → OSE 物体相对包络 → CGC 分组 conformal → RSC-G → CSC-G → WCV-G → CSP-G → AIC-G]。实时流：[锚点读 → 探针/前缀执行 → 力/位/视觉残差采集 → 按 φ_o 归一化 → 作用域门 → CSC-G 早停 → WCV-G 编译 → π_σ 前缀派发 → J_grace 构建]。

### IP-224 GRC（夹爪参考标定）

```python
class GripperReferenceCalibration:
    """物体无关的量具标定：自由空间 + 恒速扫掠 + 已知参考件。"""
    def calibrate(self, free_space_log, sweep_log, reference_log, k_ref, ver):
        # 1) 自由空间：f_true=0，估力偏置与噪声
        b_g = robust_mean(free_space_log.f_m)
        sigma_f = robust_std(free_space_log.f_m)

        # 2) 恒速扫掠：开口尺度与背隙/迟滞（正反行程差）
        q_scale, delta_b = fit_backlash(sweep_log.q_cmd, sweep_log.q,
                                        sweep_log.v_cmd)
        # 3) 参考件力斜坡：f_m = s_g * k_ref * delta + b_g
        delta = reference_log.q_cmd - reference_log.first_contact_q
        s_g, c_g = fit_scale_compliance(reference_log.f_m - b_g, delta, k_ref)

        beta_g = dict(s_g=s_g, b_g=b_g, delta_b=delta_b, c_g=c_g)
        Sigma_g = bootstrap_cov([b_g, s_g, delta_b, c_g], n=200)
        return beta_g, Sigma_g, dict(ver_g=ver, k_ref=k_ref, sigma_f=sigma_f)
```

### IP-226 ODE（物体描述子估计）

```python
class ObjectDescriptorEstimator:
    """分层贝叶斯/稳健最小二乘：用归一化探针估 φ_o，输出后验与 OOD。"""
    def estimate(self, probe_log, beta_g, family_prior):
        # 观测模型 y_p = S_o(p) φ_o + S_g(p) β_g + ε
        # 先用 β_g 扣掉量具项，再做稳健拟合
        y = probe_log.y - probe_log.S_g @ pack(beta_g)
        S = probe_log.S_o
        # 分层先验：族先验 N(mu_O, Sigma_O)，物体内弱信息先验
        phi_map, Sigma_o = hierarchical_map(y, S, family_prior)
        # 非线性参数（μ_s, σ_break）用可行域约束/变换
        phi_map = project_physical(phi_map)          # m,k,mu,sigma>0
        d_O = ood_score(phi_map, family_prior)
        return phi_map, Sigma_o, d_O
```

### IP-227 G-FIR（规范固定联合归因 + 参考件换测）

```python
class GaugeFixedFaultIsolation:
    HYP = ('H0', 'H_geo', 'H_force', 'H_model', 'H_vis', 'H_policy',
           'H_grip', 'H_obj')

    def attribute(self, probe_log, beta_g, phi_o, Sig_o):
        psi, J = joint_fit(probe_log, beta_g, phi_o)      # ψ=(φ_o,β_g,θ_f)
        gamma_g = gauge_margin(J, reference_dirs=probe_log.ref_dirs)
        if gamma_g < GAMMA_MIN or np.linalg.cond(J) > KAPPA_MAX:
            return {'verdict': 'gauge_unfixed',
                    'action': 'run_P0_and_reference_probe'}

        rho_tilde = normalize_signature(probe_log.rho, phi_o, Sig_o)
        post = softmax({h: loglik[h](rho_tilde, phi_o) + logprior[h]
                        for h in self.HYP})
        h_star = max(post, key=post.get)
        ambiguous = post[h_star] < 1.0 - DELTA_FI

        if h_star in ('H_grip', 'H_obj') and not ambiguous:
            h_star = self.reference_swap_test(probe_log, h_star)
        return {'post': post, 'h_star': h_star, 'ambiguous': ambiguous,
                'gauge_margin': gamma_g, 'rho_tilde': rho_tilde}

    def reference_swap_test(self, probe_log, h_star):
        """同一探针在参考件上复现 → 量具问题；只在目标物体上 → 物体问题。"""
        rho_ref = replay_on_reference(probe_log)          # 物体无关
        if is_significant(rho_ref):
            return 'H_grip'                               # 尺子坏了
        return 'H_obj'                                    # 物体超出描述子
```

### IP-229 OSE（物体相对安全包络）

```python
def object_safe_envelope(phi_o, Sig_o, alpha=0.05, S_f=2.0, kappa_s=0.1):
    m, mu_s, k, sigma_b = phi_o['m'], phi_o['mu_s'], phi_o['k'], phi_o['sigma_break']
    A_c = contact_area(phi_o['g_o'])
    f_min = (1 + kappa_s) * m * G / (2 * mu_s)
    f_max = sigma_b * A_c / S_f
    # 一阶不确定度传播 + 强度下界
    s_fmin = sigma_of_fmin(m, mu_s, Sig_o)
    s_fmax = sigma_of_fmax(sigma_b, A_c, Sig_o)
    f_lo = f_min + z(1 - alpha) * s_fmin
    f_hi = f_max - z(1 - alpha) * s_fmax
    feasible = f_lo <= f_hi
    f_safe = min(f_hi / S_acc, f_hi) if feasible else 0.0
    return dict(f_min=f_min, f_max=f_max, f_safe=f_safe,
                rho_f=f_safe / max(f_max, EPS),
                ose_margin=(f_hi - f_lo) / max(f_hi, EPS),
                feasible=feasible,
                strength_lower_bound=('sigma_break_LB' in phi_o))
```

```python
class ObjectAwareProbe:
    TEMPLATES = ('P0', 'P1', 'P2', 'P3', 'P4', 'P5')

    def choose(self, phi_o, Sig_o, post, ose, B_risk):
        if not ose['feasible'] or ose['f_safe'] < F_PROBE_MIN:
            return self._no_contact_probe(phi_o, post)    # P0/P5 only
        best, best_score = None, -np.inf
        for tpl in self.TEMPLATES:
            for cmd in normalized_command_grid(tpl, phi_o):
                risk = predict_risk(tpl, cmd, phi_o, Sig_o)
                if risk > B_risk or predict_f(tpl, cmd, phi_o) > ose['f_safe']:
                    continue
                info = expected_joint_info(phi_o, post, tpl, cmd)  # φ_o 与 H
                score = info / (risk + LAMBDA)
                if score > best_score:
                    best, best_score = (tpl, cmd), score
        return best, best_score

    def _no_contact_probe(self, phi_o, post):
        # 易损/未知：先视觉或自由空间，不碰物体
        return ('P5' if visual_reduces_entropy(post) > DELTA_FI else 'P0',
                None)
```

### IP-230 CGC（跨物体分组 conformal）

```python
class CrossObjectConformal:
    def fit(self, scores, groups, alpha, n_min=30):
        self.q = {}
        for g in np.unique(groups):
            s = scores[groups == g]
            if len(s) < n_min:
                self.q[g] = np.inf              # 样本不足：不承诺
            else:
                self.q[g] = weighted_quantile(s, alpha)
        return self

    def predict_interval(self, o_star, posterior_g, weights=None):
        # 后验加权混合分位；跨组不确定时取最保守
        q_star = sum(posterior_g[g] * self.q[g] for g in posterior_g)
        if max(posterior_g.values()) < DELTA_G:
            q_star = max(self.q[g] for g in posterior_g)
        return q_star

    def coverage_gap(self, scores, groups, alpha):
        return {g: abs((1 - alpha) - np.mean(scores[groups == g] <= self.q[g]))
                for g in self.q}
```

## 4. 推导

**引理 9（阶梯式规范固定）** 将探针按类型分块：P0（自由空间）、P_ref（参考件）、P_obj（目标物体探针）。对 P0，f_true=0，故 S_o(P0)=0，观测只含 S_g(P0)β_g + ε，可辨识 β_g 在 S_g(P0) 行空间内的分量。对 P_ref，φ_ref 已知，扣除 S_o(P_ref)φ_ref 后同样只含 β_g，且参考件的已知刚度提供 s_g 的绝对尺度。对 P_obj，扣除已知 β_g 后，观测为 S_o(P_obj)φ_o + S_f(P_obj)θ_f + ε。若 S_o(P_obj) 列满秩，则 φ_o 可辨识；若故障基 S_f 与 S_o 的列不共线（VISTA 的三阶段签名保证），则 θ_f 可辨识。故堆叠矩阵 S 满列秩、J_GR≻0。

反之，若删去 P0 与 P_ref，只保留一次力-位移探针，则观测标量满足 y=s_g·k·δ+…；对任意 λ≠0，变换 (k,s_g)→(k+λ, s_g−λ·s_g/k) 保持乘积不变，存在非零零空间方向，J_GR 奇异。几何落点与开口零位在单一 P1 上同形，需要 P3 的开口调制（改变 Δq 而保持位姿）来分离。∎

**引理 10（物体相对包络的迁移覆盖）** 设 ODE 给出可信集 C_o 使 P[φ_o∈C_o]≥1−α_o。OSE 定义为：对 C_o 内所有 φ_o，f_min(φ_o)+zσ≤f_safe(φ_o)≤f_max(φ_o)−zσ。因此若真实 φ_o∈C_o，则真实安全裕度 ρ_safe≥0 的概率至少 1−α_o。对同族新物体，CGC 在组 g 上给出 P[s_test≤q_g|g]≥1−α_cgc。由联合界，新物体上「物体参数落在可信集外」或「归一化分数超过 conformal 界」的概率 ≤α_o+α_cgc。若物体在族外，则 α_scope 显式加入，且 k* 被截断到 1，故即使覆盖失效，执行承诺也被压回单步。∎

**定理 9（GRACE 端到端跨物体归因-安全）** 在 A94–A99 下：
1. **量具可分离**：GRC 的物体无关约束使规范固定，γ_g≥γ_min；若 γ_g<γ_min，G-FIR 拒绝归因并触发补测，不会在未固定规范下给出 H_geo/H_force。
2. **物体可描述**：ODE 的 φ_o 后验覆盖真值（概率≥1−α_o）；OSE 在 C_o 上非空且正裕度。
3. **故障可归因**：G-FIR 在 ρ̃ 上以 Laplace 速率集中；H_grip/H_obj 通过参考件换测分离，H_force/H_geo 沿用 VISTA 的零力窗与 VCV 门控。
4. **证书可迁移**：CGC 在物体组内给出覆盖；作用域门把族外样本截断为 k*=1；J_grace 的 Valid 条件逐项对应上述保证。
5. **安全**：单块越界概率 ≤α_chunk+δ_fi+α_vis+α_obj+α_grip+α_cgc；k*≤m 保证故障在块首发生时也能在不可逆点前停下。
6. **优雅降级**：GRC 失效→H_grip→r_grip↑、保守力限；ODE 失效/族外→r_obj↑、k*=1；两者同时失效→safe_idle + 参考件换测；规范攻击→γ_g 下降→补测或安全降级。∎

**定理 10（跨物体泛化误差界）** 设归一化风险 R(o) 关于 φ_o 是 L_φ-Lipschitz，关于物体族分布是 L_scope-Lipschitz（在 Wasserstein-1 下）。对同族新物体 o*，
|R(o*) − R̂(o*)| ≤ L_φ·‖φ̂_o − φ_o‖ + L_scope·W_1(P_{o*}, P_cal) + Δ_cov + δ_mix。
证明：第一项由 ODE 的估计误差与 Lipschitz 性；第二项由密度比/加权 conformal 的分布漂移项（Tibshirani 等）；第三项由分组覆盖差距定义；第四项由后验混合分位与单组分位的差异上界。故跨物体泛化误差由**描述子估计误差与族漂移**控制，而不是由策略误差控制。这解释了为什么「先量物体」比「多训策略」更直接地改善证书迁移。∎

**命题（探针的单位风险信息）** 在线性高斯观测 y_p=S_pψ+ε、风险约束 Σ_p R_phys(a_p,φ_o)≤B_risk 下，最大化 log det J_GR 的 D-最优设计满足注水解：边际信息/风险比相等的探针获得非零权重。AOP 的贪心选择「边际信息/风险」是该注水解的可行近似；当信息函数在探针集上自适应次模时，贪心有 (1−1/e) 近似保证。风险预算把「更准」与「更安全」放在同一目标里，避免 VISTA AFA 在易损物体上「为归因而归因」。∎

**假设 A94–A99**
- **A94**：GRC 的自由空间与参考件实验能覆盖量具的主要自由度（力尺度/偏置/背隙/柔顺），且参考件参数已知或可溯。
- **A95**：物体描述子 φ_o 是低维且可辨识的；接触几何/材料非线性可用 ε_p 吸收，残余不显著。
- **A96**：物体族内条件可交换（定义 247）；校准与部署的物体分布漂移可由密度比/加权 conformal 校正。
- **A97**：G-FIR 的故障基 S_f 与物体基 S_o 不共线；三阶段/受控探针提供足够激励。
- **A98**：CSC-G 的 k*≤m，越界预算含 α_obj/α_grip/α_cgc。
- **A99**：实时路径 ≤2.6ms，零学习写操作；GRC/ODE/G-FIR/AOP/CGC 全部在语义流。

## 7. 已知风险

**一句话**：GRACE 的跨物体证书依赖「物体可由低维物理描述子刻画、且物体族条件可交换」这两个假设；一旦新物体的接触几何、材料非线性或内部动力学超出描述子（或夹爪在接触中的摩擦/背隙随载荷变化），归一化会把「物体模型错误」洗成「安全裕度充足」，从而在从未见过的物体上给出高置信度的错误放行——**这比第 65 轮的归因错误更隐蔽，因为证书看起来完全合规。**

**次级风险与缓解**：
1. **描述子欠拟合/过拟合**：低维 φ_o 无法覆盖软体、颗粒、空腔、各向异性；缓解：加 ε_p 非线性项、用非参数残差上界、把 OOD 判据放在 φ_o 后验而非点估计；必要时扩大描述子维度但保持可辨识性。
2. **规范仍不可辨识**：GRC 只覆盖自由空间与参考件，接触中的摩擦/背隙随载荷变化；缓解：P3 开口调制 + 多载荷水平 + 在线 γ_g 监测；γ_g 低时拒绝归因、补测或安全降级。
3. **物体族不可交换**：部署物体分布漂移、选择偏差、只挑好抓物体校准；缓解：密度比加权 conformal、族外 OOD、隐藏留出物体、最差组指标；Δ_cov 进入证书。
4. **参考件本身漂移/被污染**：参考件磨损、温漂、装夹变化会让 GRC 把错误写进 s_g；缓解：多参考件交叉、参考件版本化、GRC 残差监控、ver_g 失效即重签证书。
5. **主动探针损伤易损物体**：即使 OSE 可行，探针仍可能局部压碎；缓解：强度下界 + 风险预算 + 易损只走 P0/P5/极低力 P1；累计风险预算 B_risk 硬约束。
6. **参考件换测不可行**：部署现场没有参考件、或换测代价高；缓解：用「同族锚物体」或仿真参考件；退化时只输出等价类/保守动作，不强行分 H_grip/H_obj。
7. **CGC 小样本组**：新物体族样本少，分位不稳定；缓解：n_g<n_min 时置 q_g=∞、不承诺覆盖；层次贝叶斯借力、保守回退。
8. **计算与实时预算**：ODE/G-FIR/AOP/CGC 在语义流，但参考标定与换测可能抢占周期；缓解：GRC 只在版本变化/漂移时触发，换测异步、缓存、与 VISTA 语义流共享编码；实时路径只做归一化/查表/门控。
9. **规范对消攻击**：同时改物体与传感器尺度使乘积不变，是 GRACE 的专门攻击面；缓解：P0/参考件周期性复测、多探针冗余、AIC-G 显式建模、γ_g 下降即报警。
