# 第 41 轮 · 灵感 v8：接触证书统一抓取与全身平衡 × 接触调度代数 × 证书投影式全身流执行（四层架构 v6）

> 承接第 40 轮（v17：可认证流匹配执行 × 度量语义几何锚定 × 证书驱动课程引擎，四层架构 v5）。本轮灵感词「抓取规划、人形机器人」把设计从「运动与几何的可认证」推进到「接触的可认证」：将抓取规划中的力封闭/扳手空间裕度提升为系统级一等证书；借人形机器人「手与脚同为接触端」的统一视角，把抓取证书与全身平衡证书合并为同一个广义接触证书；并用接触调度代数把二者接入既有的技能总线、任务代数与课程引擎。

## 0. 直觉与动机

**灵感 1（抓取规划 → 把「接触」提升为一等证书）**：第 40 轮认证了策略网络（λ, L）、积分器（L_v, κ, ε_ode）、几何（C_ms, B_t）与有效区域，但没有任何一条证书在说「手真的抓住了」「脚真的踩稳了」。抓取规划领域早已把这件事形式化：接触力必须落在摩擦锥内，力封闭意味着接触扳手张成整个 wrench 空间，Ferrari–Canny 的 ε 指标就是「在扳手空间里能容下多大的扰动球」。这恰好补上证书链的最后一环——第 40 轮执行层输出的是动作块，本轮要求每条动作块附带一个**接触证书**：在当前接触模式下，存在一组满足摩擦锥、单向约束、力矩上限的接触力，使需求扳手落在可达扳手集内部，且留有余量。抓取不再是独立的感知-规划模块，而是「接触模式 + 接触证书」的一次类型化迁移。

**灵感 2（人形机器人 → 手与脚是同一个物理对象）**：人形机器人是浮动基座 + 多接触端系统；走路时脚与地面的关系，和抓取时手与物体的关系，在力学上是同一件事：接触点 p_i、法向 n_i、摩擦系数 μ_i、接触力 f_i，以及它对参考体产生的扳手 G_i(p_i) f_i。ZMP/CMP/捕获点等平衡判据，本质是「质心动力学所需净扳手是否落在支撑接触的可达扳手集内」。于是**平衡证书 = 接触证书在支撑接触集上的特例**，不需要两套理论。人形机器人还带来两个新难点：接触会切换（抬脚、放手、换握），系统欠驱动且接触冲击不可忽略——所以必须显式引入**接触调度**，并让证书沿调度传播，而不是只在瞬时成立。

**灵感 3（耦合 → 接触调度代数作为胶水）**：抓取规划给出「选哪个接触、余量多大」，人形机器人给出「何时切换接触、切换后是否还稳」。二者合起来是接触调度的组合问题：抓取=加入手-物接触，释放=移除，落脚=重定位足-地接触。用证书裕度给接触模式图做启发式搜索（证书越高越优先），并对调度做代数组合与裕度传播。第 40 轮的流匹配执行改为以接触模式为条件变量，生成后由证书做投影式 QP 过滤；课程引擎把 ρ_rob、d_ξ、T_cap 纳入证书赤字。

## 1. 形式化定义

**定义 27（接触模式与广义可达扳手集）**：接触模式 σ = {(b_i, p_i, n_i, μ_i, f_max,i)}_{i=1}^{n_c}，描述手-物、足-地、手-环境等所有接触；参考点 r 下接触力 f_i 产生的扳手映射为
G_i(p_i) = [ I_3 ; [p_i − r]_× ] ∈ R^{6×3}，
摩擦锥线性化为 f_i = E_i α_i, α_i ≥ 0（E_i 的列由法向与切向锥生成元按 μ_i 缩放组成）。广义可达扳手集
W(σ) = { Σ_i G_i(p_i) E_i α_i : α_i ≥ 0, 1ᵀα_i ≤ f_max,i, τ_min ≤ −Σ_i J_iᵀ E_i α_i ≤ τ_max }。
抓取时 w_req = [m_obj(ä_obj − g); L̇_obj]（参考物体质心）；全身时 w_req = [m(ċ − g); L̇]（参考机器人质心）。于是「抓取」与「平衡」统一为同一个可行性问题 w_req ∈ int W(σ)。

**定义 28（接触证书 C_ct）**：对接触位置不确定球 p_i ∈ B(p̂_i, B_i)（由 IP-49 的 C_ms 给出），定义
ρ(σ) = dist(w_req, ∂W(σ)) = min_{‖u‖=1} ( h_W(u) − uᵀ w_req )，h_W(u)=max_{w∈W} uᵀw，
即所需扳手到可达扳手集边界的距离（Ferrari–Canny ε 的广义形式）。由于 G_i 对 p_i 的 Lipschitz 常数满足 L_i ≤ f_max,i，得
ρ_rob = max(0, ρ − Σ_i f_max,i · B_i)。
接触证书 C_ct = (σ, ρ, ρ_rob, ρ_min, B_p)，当且仅当 ρ_rob ≥ ρ_min 且 w_req ∈ W(σ) 时有效。
**定理 1（鲁棒力封闭）**：若 C_ct 有效，则对任意真实接触位置 p_i ∈ B(p̂_i, B_i)，仍存在合法接触力分布使 w_req ∈ W(σ_true)，且边界裕度不小于 ρ_rob。证明：W 是各接触扳手像的 Minkowski 和，位置扰动使每个像的 Hausdorff 距离至多增加 f_max,i·B_i，故到边界距离最多下降 Σ f_max,i·B_i。

**定义 29（全身平衡证书 C_bal）**：取支撑接触子集 σ_s（足底、必要时手撑），由流策略轨迹反解质心状态 (c, ċ, L̇)。定义
- 质心扳手裕度 ρ_wb = dist(w_req, ∂W(σ_s))，w_req = [m(ċ − g); L̇]；
- 发散分量 ξ = c_xy + ċ_xy/ω，ω = √(g/c_z)，支撑域 S(σ_s) 为支撑接触点的凸包；
- 捕获裕度 d_ξ = signed_dist(ξ, ∂S)；捕获时间 T_cap = max{ t ≥ 0 : ξ + t ξ̇ ∈ S }。
C_bal = (σ_s, ρ_wb, d_ξ, T_cap)，当且仅当 ρ_wb ≥ 0 且 T_cap ≥ T_min（T_min 为一步再规划所需反应时间）时有效。它是定义 28 在支撑接触集上的特例，额外携带时间维安全余量。

**定义 30（接触调度与接触代数）**：接触调度 Σ = ((σ_0, Δt_0), …, (σ_K, Δt_K))，σ 分段常值。Σ 有效当且仅当：a) 每段均有 C_ct 与 C_bal 有效；b) 每次切换存在满足动量跳变与摩擦锥的接触冲量，使切换后的 DCM 落入新支撑域的捕获区；c) 新接触点运动学可达且 ESDF 无碰撞。组合 Σ₁ ⊕ Σ₂ 要求 σ₁ 的末模式与 σ₂ 的首模式一致；定义裕度传播 ρ(Σ) = min_k min(ρ_ct,k, ρ_bal,k, d_ξ,k, T_cap,k/T_min)（取最小者，与 IP-46 的 D-K 组合同构）。抓取=σ ↦ σ ∪ {手-物} 的迁移，释放为其逆，落脚=σ_s ↦ σ'_s 的单接触重定位。

## 2. 三大产出设计

### 2.1 IP-51 CONTACT-WRENCH-CERT（广义接触证书）
1. 点云抓取候选：反极点采样 + affordance 网络给接触点、法向与 μ 估计；统一转成 σ。
2. 线性化摩擦锥（法向 + 8 切向生成元）→ 扳手多面体 W(σ)；用对偶 LP 求 ρ，用 SDP 对关键接触做摩擦锥精确收紧。
3. 鲁棒化：由 C_ms 的 B_i 直接得 ρ_rob = ρ − Σ f_max,i B_i；对高价值候选做 interval-LP 收紧，避免过度保守。
4. 输出 C_ct 并注册到 CertBundle；候选排序用 ρ_rob/ρ_min 而非启发式评分。

### 2.2 IP-52 WHOLEBODY-BALANCE-CERT（全身平衡证书）
1. 从 IP-48 流策略轨迹反解质心与动量，逐段构造 w_req。
2. 每控制周期解一次小 LP 得 ρ_wb；解析式计算 ξ、d_ξ、T_cap。
3. 切换处校验接触冲量可行性与 DCM 落点，输出带时间维的 C_bal。
4. 在线监测：T_cap < T_min → 触发 IP-53 重调度；仍不可行 → IP-38 捕获步/跌倒保护。

### 2.3 IP-53 CONTACT-SCHEDULE-ALGEBRA（接触调度代数）
1. 接触模式图：节点=σ（手/脚接触组合），边=抓取/释放/落脚/换握；边代价用证书裕度。
2. 证书引导 A*/MCTS：以 min(ρ_rob, d_ξ) 为启发式，先扩展高裕度分支；节点数超预算即回退保守调度。
3. 组合代数：Σ 的拼接、逆、裕度传播；与 IP-47 任务代数共享类型检查，抓取即「接触类型迁移」。
4. 与课程引擎闭环：调度失败样本按接触赤字加权回放。

### 2.4 对既有 IP 的升级
- **IP-48**：流匹配 ODE 条件由 (c, s, g) 扩为 (c, s, g, σ)，输出全身关节块 + 接触力目标双头；生成后做证书投影 QP，投影距离超阈值则重采样/重调度。
- **IP-47**：类型系统增加接触模式类型，组合裕度 ρ(Σ) = min；抓取成为可类型检查的接触迁移。
- **IP-49**：几何锚定增加抓取 affordance、接触位置不确定球、落脚点可达性与支撑面检测。
- **IP-50**：证书赤字增加 ρ̂_rob、d̂_ξ、T̂_cap；课程任务加入推挤、不平地面、双臂协同搬运与 loco-manipulation。
- **IP-38**：以 T_cap 为触发量，先尝试捕获步/接触重调度，失败再进入跌倒保护。
- **IP-39**：规划器输出接触调度 Σ 而非单一轨迹；**IP-46** 的 CertBundle 增 C_ct/C_bal/Σ；**IP-45** 契约增接触前提与后置；**IP-36** 语义图挂接 affordance 与支撑面。

## 2. 关键算法

### IP-51 广义接触证书（伪代码）
```
def contact_wrench_certificate(contacts, w_req, B_p, f_max, rho_min):
    # contacts: [(p_i, n_i, mU_i, body_i)]
    G = [wrench_map(p, ref=current_ref) for p in contacts]
    E = [lin_friction_cone(n, mU, n_dirs=8) for n,mU in contacts]
    # 对偶 LP：ρ = min_{facet u} h_W(u) − u·w_req
    rho = wrench_margin_lp(G, E, w_req, f_max, torque_limits)
    # 关键接触再做 SDP 收紧（精确二阶锥摩擦锥）
    if high_value(contacts):
        rho = min(rho, wrench_margin_socp(contacts, w_req, f_max))
    rho_rob = rho - sum(f_max[i]*B_p[i] for i in range(len(contacts)))
    if rho_rob < rho_min: return None
    return C_ct(contacts, rho, rho_rob, rho_min, B_p)

def robust_grasp_rank(candidates, obj_w_req, B_p, f_max):
    certs = [contact_wrench_certificate(c, obj_w_req, B_p, f_max, rho_min) for c in candidates]
    return sorted([c for c in certs if c is not None], key=lambda c: -c.rho_rob)
```

### IP-52 全身平衡证书（伪代码）
```
def balance_certificate(traj, sigma_s, dt, T_min):
    min_rho, min_dxi, min_Tcap = +inf, +inf, +inf
    for t in horizon(traj, dt):
        c, cdot, cddot, Ldot = centroidal_state(traj, t)
        w_req = [m*(cddot - g); Ldot]                  # 全身质心动力学
        rho   = wrench_margin_lp(sigma_s.contacts, w_req, f_max, torque_limits)
        xi    = c[:2] + cdot[:2]/omega(c)
        dxi   = signed_dist(xi, support_polygon(sigma_s))
        Tcap  = capture_time(xi, xi_dot(c,cdot), sigma_s)
        min_rho, min_dxi, min_Tcap = min(min_rho,rho), min(min_dxi,dxi), min(min_Tcap,Tcap)
    valid = (min_rho >= 0) and (min_Tcap >= T_min)
    return C_bal(sigma_s, min_rho, min_dxi, min_Tcap, valid)
```

```
def plan_contact_schedule(start, goal, geom, budget):
    pq = [(-heuristic(start,goal), start)]
    while pq and budget.consume():
        S = pop_max_margin(pq)
        if goal_reached(S): return certify_schedule(S)
        for sigma_new in contact_mode_expansions(S, geom.affordances):
            w_req = required_wrench(goal, sigma_new)
            Cct   = contact_wrench_certificate(sigma_new.contacts, w_req, geom.B, f_max, rho_min)
            Cbal  = balance_certificate(preview_traj(S,sigma_new), sigma_new.support, dt, T_min)
            if Cct and Cbal.valid:
                margin = min(Cct.rho_rob/rho_min, Cbal.dxi/d_min, Cbal.Tcap/T_min)
                push(pq, (-margin, compose(S, sigma_new, margin)))
    return None   # -> IP-38 捕获步 / 接触重调度

def compose(S1, S2, margin):
    assert S1.end_mode == S2.start_mode
    return ContactSchedule(S1.phases + S2.phases,
                           margin=min(S1.margin, S2.margin),
                           transitions=S1.transitions + S2.transitions)
```

### IP-48 证书投影式全身流执行（升级伪代码）
```
def certified_wholebody_execute(v_theta, c, s, g, sigma, eps_tol):
    x = adaptive_stream_sample(v_theta, cond=(c,s,g,sigma), eps_tol=eps_tol)  # 第 40 轮 IP-48
    x_proj, d = project_contact_feasible(x, sigma)   # QP: C_ct + C_bal 线性化约束
    if d > d_max or not balance_certificate(x_proj, sigma.support, dt, T_min).valid:
        sigma  = plan_contact_schedule(current_mode(x), goal, geom, budget)
        x_proj = project_contact_feasible(resample(v_theta, sigma), sigma)[0]
    return x_proj

def project_contact_feasible(x, sigma):
    # min ||x'−x||²_Q  s.t.  ρ_rob(x',σ) ≥ ρ_min, d_ξ(x') ≥ d_min,
    #                       torque/joint/ESDF 约束（接触位置处线性化）
    return solve_qp(x, sigma)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 正确性保证 |
|---|---|---|
| W(σ) 构造 | O(n_c·m_i) 约束 | 线性化摩擦锥为内近似（保守） |
| ρ LP | ~O((n_c m_i)³)，热启动 ms 级 | 对偶 LP 精确；SDP 收紧摩擦锥 |
| ρ_rob | O(n_c) | **定理 1**：位置扰动球内鲁棒力封闭 |
| C_bal 时域 | H 次 LP + O(1) 解析 DCM | 每时刻扳手可行 + DCM 捕获域 |
| 接触调度 | 最坏指数；证书启发式 + 预算剪枝 | 有界预算内返回或保守回退 |
| 流执行 + 投影 | N* 次前向 + 1 个 QP（N*≤8） | 投影后满足线性化接触约束 |
| 任务/调度组合 | O(|V|+|E|) | 类型检查 + 裕度 min 传播（结合 IP-46 D-K） |
| 课程采样 | O(1)/任务（按 D 预索引） | Robbins-Monro 收敛性沿用第 40 轮 |

## 5. 预期结果与判据（预注册）

| 预测 | 依据 | 若不符则说明 |
|---|---|---|

## 6. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 瞬时扳手可行 ≠ 动态可行（虚假安全） | 高 | 时域 C_bal + DCM 捕获时间 + E75 守门；必要时升级为管状/Robust MPC 证书 |
| 接触调度组合爆炸 | 高 | 证书启发式 + 预算剪枝 + 分层（先足后手）+ 失败回退固定序列 |
| 摩擦锥线性化过保守 → 抓取全被否 | 中 | LP 粗筛 + SOCP 精修；μ 下界置信估计 |
| 接触位置不确定球 B_i 被低估 | 高 | 与 IP-49 的 Bennett 界联动，E74 注入对抗位姿噪声 |
| 接触冲击/柔顺形变破坏准静态假设 | 中 | 加入冲量锥与柔顺模型；限速切换；E77 守门 |
| 双头流（关节+接触力）训练不稳定 | 中 | 分阶段训练 + 接触力头用证书投影监督 |

## 7. 本轮最大风险

**一句话**：瞬时扳手可行只是动态全身接触可行的必要非充分条件——若把 ρ_rob 当作抓取与平衡成功的充分保证，证书会在接触冲击、柔顺形变与切换瞬间给出虚假安全感，故必须以滚动时域/Robust MPC 式管状证书为重、以 E75/E76 为第一守门实验。
