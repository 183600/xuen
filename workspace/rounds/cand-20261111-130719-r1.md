# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「动作分块」×「深度学习」）

> 第 54 轮把技能组合推进为「动作剖面 α_S + 鲁棒性谱 ρ + 云边映射 γ_ce」的双证书体系，但它默认了**证书单元 = 单步动作**、**执行方式 = 逐步闭环**。真实 VLA 策略（ACT、Diffusion Policy、π0/GR00T 类）执行的却是一个 h 步**动作块（action chunk）**：块内开环、块间重规划。证书单元与执行单元一旦错位，就会出现「逐步都稳、整块失败」。本轮引入 **块级证书层**，并把「深度学习」拆成两个角色：它负责**提议**块长与风险，但只有经过保形校准与符号兜底的证书才能**裁决**部署。核心矛盾：**H24（证书单元错位）**：第 54 轮的 ρ/α 是逐动作闭环保守量，无法推出 h 步开环块的复合误差与边界不连续；**H25（学习不确定性错位）**：深度集成给出的不确定性在分布内校准良好，却在 UniBot 的五类泛化轴上系统性过度自信，直接把 σ 当证书用会在最需要兜底的区域失效。

## 0. 直觉与动机

### 0.1 本轮思考轨迹

1. 回看第 54 轮：`α_S(a)`、`ρ_S(d)`、`compat(S_i,S_j)` 全部定义在**单步动作**上，`J` 的 soundness 也默认每一步都能重新观测、重新纠偏。这个假设在真机上不成立：为了降低推理频率、平滑轨迹、缩短有效决策视界，主流策略一次预测并执行 h 步动作。
2. 盯住「动作分块」：它不是把 h 个单步动作简单打包，而是改变了**信息结构**。块内没有新观测，误差只能沿动力学传播；块间有新观测，但会引入接缝。2026 年的研究把分块收益归因于非马尔可夫表达力、降低复合误差与隐式集成，同时明确指出一致性—反应性权衡：块越长越连贯，但对突发状态越迟钝。
3. 盯住「深度学习」：深度学习既是问题的来源（块策略是学出来的，误差分布未知），也是解法的来源（深度集成可估 epistemic 不确定性，残差模型可估误差动力学，保形预测可把点估计变成带覆盖保证的集合）。关键是分工：**学习负责提议，证书负责裁决**。
4. 拉到 UniBot 现实：32 项桌面任务、32,000 条演示、169 小时数据、5 类泛化场景（位置变化、干扰物、背景差异、未见物品、人为干扰），按平均成功率与步骤分排名，选手通过标准化 API 远程接入。榜首成功率仍不高，说明「会做」与「稳定做对」之间还有巨大缺口；而块长、推理延迟、块边界与失败恢复会直接进入分数。
5. 找到缺口：第 54 轮能回答「这个单步动作在该技能的动作剖面里稳不稳」，但不能回答「这个 h 步块在该任务、该泛化轴、该 API 延迟下是否可证明地稳」。块长不是超参数，而是**风险预算的分配变量**。
6. 于是本轮把证书从「点」提升为「段」：块级剖面、块漂移界、块长证书、接缝证书、保形学习证书、部署证书。目标不是让分块一定更好，而是让「何时可以长块、何时必须短块、何时必须退回闭环」变成可判定问题。

### 0.2 六个直觉

**灵感 1（动作分块 → 把证书单元从动作升级为块）**
直觉：块 `c = (a_t, …, a_{t+h-1})` 应被视为一个**宏动作**。技能 S 不再只占用单步动作空间 A，而是占用块空间 `C_h = A^h` 的一个子集；块级剖面 `α_S^h(c)` 衡量「一次性下发这 h 步，整段都能被技能覆盖」的概率。组合也应先问「块与块能否接上」，而不是只问「单步动作是否相交」。

**灵感 2（复合误差 → 块长是风险预算，不是超参数）**
直觉：块内开环时，误差满足 `e_{t+1} = L e_t + ε_t`。若任务流形是收缩的（L<1），误差不会无限累积，长块还能减少块间接缝；若任务处于接触丰富或临界稳定区（L≥1），误差随 h 增长，长块就是把单步小错放大成整段失败。块长应由 `Δ(h) = L^h e_0 + ε(1-L^h)/(1-L) ≤ δ_task` 决定，而不是由调参经验决定。

**灵感 3（自适应块长 → 证书驱动 h，而不是人调 h）**
直觉：固定块长在简单段浪费反应性、在困难段透支误差预算。正确做法是维护一张**块长证书** `H_cert`：在每段根据残差模型给出的 `Δ^+(h)`、块级鲁棒性 `ρ^h`、任务反应时间 `τ_react(h)` 与推理时延 `T_inf`，选满足全部约束的最大 h；一旦观测残差超过绊线，立即缩短块并重规划。这相当于把 ACT/ACPPO-Corr 的「块内反馈」思想变成证书触发器。

**灵感 4（块边界 → 新的失效面必须单独证书）**
直觉：块内平滑不代表块间平滑。相邻块在重叠区可能给出不一致的动作，产生速度跳变、夹爪开合抖动或抓取点漂移；时序集成能把接缝抹平，但也会引入「旧预测拖慢新反应」的滞后。接缝残差 `b_i` 与滞后必须进入证书，否则组合证书会在边界处系统性高估成功率。

**灵感 5（深度学习 → 学习提议、保形校准、符号裁决）**
直觉：深度集成能给出「哪里不确定」，但它不是覆盖保证。把每个任务的每个泛化轴上的非 conformity 分数做**分组保形校准**，才能在分布内得到 `1-α` 覆盖；再做协变量漂移检测与加权保形，才能把「未见物品/人为干扰」的过度自信显式暴露。最终门控仍是符号的：`r(x) ≤ q_g` 且 `shift ≤ θ_s` 才允许采用学习提议的块长与风险，否则退回保守 `h_min` 或第 54 轮的闭环保守证书。

**灵感 6（部署 → 蒸馏、量化、远程 API 也会改变证书对象）**
直觉：UniBot 通过标准化 API 远程评测，端侧可能部署蒸馏/量化后的块策略。压缩会改变块分布与推理时延：时延超过 `h·Δt` 时，实际执行的是被截断的 `h_eff < h`；行为漂移 `d_B(π,π')` 会让原来 sound 的证书在部署版上失效。因此部署版必须单独发一张 `D_cert`，并在模型版本、量化格式、API 时延或任务族变化时触发再证书。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（块空间、分块算子与块级剖面）**
轨迹 `τ = (o_0,a_0,o_1,a_1,…)`，动作空间 `A`。对步长 `Δt`、块长 `h`、步幅 `s ≤ h`，分块算子
```
χ_{h,s}(τ) = (c_0, c_1, …),  c_i = (a_{t_i}, …, a_{t_i+h-1}),  t_{i+1}=t_i+s.
```
块空间 `C_h = A^h`，重叠 `o = h - s`。技能 S 的块级剖面
```
α_S^h(c) = P_sim(⋀_{k=0}^{h-1} cover(S, a_{t+k}) | c)
```
为由结构化仿真校准的下界（继承第 54 轮 A26）。块级鲁棒性 `ρ_S^h(d)` 定义为在维度 d 上整块成功的 `1-α` 下置信界。块覆盖 `cover_h(S,C_T)=1` 当且仅当 `∀ c∈C_T, α_S^h(c) ≥ θ_cov`。

**定义 122（块漂移证书）**
设任务空间误差 `e_t = q(a_t^cmd) - q(a_t^exec)`，误差动力学满足
```
‖e_{t+1}‖ ≤ L‖e_t‖ + ε_t,   L ≥ 0,  ε_t ≥ 0.
```
`L` 为任务流形的局部收缩系数，`ε_t` 为单步新息（含模型误差、执行噪声、标定漂移）。给定新息上界 `ε^+`（由残差模型 + 保形校准得到），块长 h 的漂移上界为
```
Δ_S^+(h) = L^h ‖e_t‖ + ε^+ · (L^h - 1)/(L - 1)   (L ≠ 1),
Δ_S^+(h) = h · ε^+                                (L = 1).
```
**块漂移证书** `CDB = (h, L, ε^+, Δ^+, δ_task)`；块通过当且仅当 `Δ_S^+(h) ≤ δ_task`。注意 `L < 1` 时 `Δ^+` 有上界 `ε^+/(1-L)`，长块可行；`L ≥ 1` 时 `Δ^+` 随 h 单调增长，长块必须被否决或改为块内反馈。

**定义 123（块长证书与自适应控制器）**
块长证书
```
H_cert = (h, s, Δ^+, ρ^h, U_cal, τ_react, T_inf, expiry)
```
其中 `τ_react(h) = h·Δt + T_inf + T_seam` 为最坏反应时间，`U_cal` 为学习证书在相关任务族/泛化轴上的保形覆盖状态。给定任务预算 `δ_task`、`ρ_min`、`τ_task`，证书块长为
```
h* = max { h ∈ [h_min, h_max] : Δ^+(h) ≤ δ_task
           ∧ min_d ρ^h(d) ≥ ρ_min
           ∧ τ_react(h) ≤ τ_task
           ∧ U_cal 有效 }.
```
运行时若观测残差 `‖e_t‖ > κ·Δ^+(h)`、接缝残差超限或漂移检测告警，则触发 `h ← max(h_min, ⌊h/2⌋)` 的**缩短回退**，并重新查询块策略。

**定义 124（接缝一致性证书）**
相邻块 `c_i, c_{i+1}` 在重叠区 `o = h-s` 上定义接缝残差
```
b_i = ‖a^i_o - a^{i+1}_0‖_∞ + λ_v‖v^i_o - v^{i+1}_0‖_∞ + λ_g |g^i_o - g^{i+1}_0|,
```
其中 `v` 为末端速度、`g` 为夹爪开合。时序集成输出 `â_t = Σ_k w_k a_{t|t-k}`，权重 `w_k ∝ exp(-m·k)`。**接缝证书** `B_cert = (o, b_max, w, δ_b, jerk_max)`；通过条件为 `b_max ≤ δ_b` 且 `jerk_max ≤ J_max`。接缝失败概率上界取 `P_seam ≤ min(1, b_max/δ_b · p_seam)`，作为保守项进入总界。

**定义 125（保形学习证书）**
深度集成 `{f_m}_{m=1}^M` 在观测 x 上输出块均值 `μ(x)` 与尺度 `σ(x)`。非 conformity 分数
```
r(x,c) = ‖c - μ(x)‖ / (σ(x) + σ_0).
```
按任务族 `k` 与泛化轴 `g ∈ G = {位置, 干扰物, 背景, 未见物品, 人为干扰}` 分组校准，得到分数 `q_{k,g}^{1-α}`，使得在可交换性下
```
P(r(X,C) ≤ q_{k,g}^{1-α}) ≥ 1 - α.
```
定义漂移分数 `s(x)`（密度比或集成分歧），当 `s(x) > θ_s` 时使用加权保形（权重 `w(x)=dP_test/dP_cal`，要求 `‖w‖_∞` 有界），否则退回 `h_min`。**学习证书** `L_cert = (q_{k,g}, α, s, θ_s, coverage, fallback)`；只有当 `r ≤ q` 且 `s ≤ θ_s` 时，学习提议的 `(h, risk)` 才可提交给符号证书。

**定义 126（部署块证书）**
完整策略 `π` 与部署策略 `π'`（蒸馏/量化/远程）之间的块行为距离
```
d_B(π,π') = sup_{x∈supp(μ_task)} W_1( π(·|x), π'(·|x) ),
```
其中 `W_1` 为块分布的一阶 Wasserstein 距离。推理时延导致的截断
```
h_eff = min(h, ⌊(τ_api - T_other)/Δt⌋).
```
**部署证书** `D_cert = (d_B^+, h_eff, T_inf, δ_d, version, expiry, recompute_triggers)`；通过条件为 `d_B^+ ≤ δ_d`、`h_eff ≥ h_min`、`T_inf ≤ τ_api`。模型版本、量化格式、API 时延、任务族或泛化轴发生变化时强制再证书。

## 2. 关键算法 伪代码

### IP-121 CHP（Chunk Horizon Profiling）

```python
def chunk_profile(skill, trajectories, h, s, sampler, alpha=0.05):
    C = [traj[i:i+h] for traj in trajectories for i in range(0, len(traj)-h+1, s)]
    profile = {}
    for c in C:
        # 结构化仿真 + 校准，返回整块覆盖成功与否
        ok, conf = sampler.rollout_chunk(skill, c)
        profile[tuple(c)] = lower_confidence_bound(ok, conf, alpha)
    rho_h = block_robustness(profile, dimensions)
    return ChunkProfile(h, s, profile, rho_h)
```

### IP-122 CDB（Chunk Drift Bound）

```python
def chunk_drift_certificate(skill, h, residual_model, calib_set, delta_task, alpha=0.05):
    L, eps_samples = [], []
    for e_t, a_t, e_next in calib_set:
        L.append(residual_model.contraction(e_t, a_t))
        eps_samples.append(residual_model.innovation(e_t, a_t, e_next))
    L_hat = upper_quantile(L, 1 - alpha)
    eps_plus = upper_quantile(eps_samples, 1 - alpha)
    if abs(L_hat - 1.0) < 1e-9:
        delta_plus = h * eps_plus
    else:
        delta_plus = L_hat**h * norm(e0) + eps_plus * (L_hat**h - 1) / (L_hat - 1)
    ok = delta_plus <= delta_task
    return CDB(h, L_hat, eps_plus, delta_plus, delta_task, ok)
```

### IP-123 AHC（Adaptive Horizon Controller）

```python
def select_horizon(cert_bank, delta_task, rho_min, tau_task, h_min, h_max):
    best = None
    for h in range(h_max, h_min - 1, -1):
        cdb = cert_bank.drift(h)
        rho = cert_bank.rho(h)
        if cdb.delta_plus > delta_task:          # Δ 随 h 通常单调，可直接 break
            continue
        if min(rho.values()) < rho_min:
            continue
        if react_time(h) > tau_task:
            continue
        if not cert_bank.learning_valid(h):       # 保形覆盖/漂移检查
            continue
        best = h
        break
    return best if best is not None else h_min

def run_chunked(policy, cert_bank, task):
    h = select_horizon(cert_bank, task.delta, task.rho_min, task.tau, 1, task.h_max)
    while not task.done:
        c = policy.predict_chunk(task.obs, h)
        for k, a in enumerate(c):
            task.step(a)
            if task.residual > KAPPA * cert_bank.drift(h).delta_plus:
                h = max(1, h // 2)                # 证书触发缩短
                break
        if task.residual < KAPPA * cert_bank.drift(h).delta_plus:
            h = min(task.h_max, h + 1)            # 缓慢恢复，迟滞防震荡
```

### IP-124 BCC（Boundary Consistency Certificate）

```python
def boundary_certificate(chunks, delta_b, jerk_max, lam_v=1.0, lam_g=1.0):
    worst_b, worst_j = 0.0, 0.0
    for c_i, c_next in zip(chunks[:-1], chunks[1:]):
        o = overlap(c_i, c_next)
        b = norm_inf(c_i[-o] - c_next[0])
        b += lam_v * norm_inf(vel(c_i, -o) - vel(c_next, 0))
        b += lam_g * abs(grip(c_i, -o) - grip(c_next, 0))
        worst_b = max(worst_b, b)
        worst_j = max(worst_j, jerk(c_i, c_next))
    ok = worst_b <= delta_b and worst_j <= jerk_max
    return BCC(worst_b, worst_j, ok, p_seam=min(1.0, worst_b / delta_b))
```

### IP-125 CLC（Conformal Learned Certificate）

```python
def conformal_learned_certificate(ensemble, calib, alpha, theta_s, task_family, axis):
    scores = []
    for x, c in calib[task_family][axis]:
        scores.append(nonconformity(ensemble, x, c))   # ‖c-μ‖/(σ+σ0)
    q = quantile(scores, 1 - alpha)
    def gate(x, c, h):
        if shift_score(x) > theta_s:
            return ('fallback', h_min)
        return ('accept', h) if nonconformity(ensemble, x, c) <= q else ('reject', h)
    return LCert(q, alpha, theta_s, gate)
```

### IP-126 DCC（Deployment Chunk Certificate）

```python
def deployment_certificate(pi_full, pi_deploy, calib_states, tau_api, delta_d):
    d_b = max(wasserstein1(pi_full(x), pi_deploy(x)) for x in calib_states)
    h_eff = min(pi_deploy.h, int((tau_api - T_other) / DT))
    ok = d_b <= delta_d and h_eff >= H_MIN and pi_deploy.latency <= tau_api
    return DCC(d_b, h_eff, pi_deploy.latency, ok,
               triggers=['version', 'quant', 'latency', 'task_family'])
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CHP | O(|C|·h) | O(|C|) | 块仿真校准；块级 LCB 有效 |
| CDB | O(N·d + h) | O(N) | L、ε 的上界覆盖；误差递推成立 |
| AHC | O(h_max·|𝔇_ρ|) | O(h_max) | Δ(h) 单调时二分 O(log h_max)；回退触发器 |
| BCC | O(m·o·d_a) | O(m·o) | 接缝残差可测；时序集成权重有界 |
| CLC | O(M·N_cal·d) 训练后 O(M·d) 推理 | O(N_cal) | 分组可交换性；漂移权重有界 |
| DCC | O(N_cal·M·d) | O(N_cal) | 行为距离上界；时延截断 h_eff |

**正确性定理（Chunked Execution Soundness, CES）**
假设第 54 轮 (A26)–(A28) 成立，并新增：
- **(A29)** `Δ_S^+(h)` 以置信度 `1-α_d` 覆盖真实块漂移；
- **(A30)** 所有接缝满足 `b_i ≤ δ_b` 且失败概率上界为 `p_seam`；
- **(A31)** 学习证书在每个任务族/泛化轴上以 `1-α_c` 保形覆盖，漂移检测漏报率 ≤ `α_s`；
- **(A32)** 部署版满足 `d_B ≤ δ_d` 且 `T_inf ≤ τ_api`，截断后 `h_eff ≥ h_min`；
- **(A33)** 块级 `ρ^h` 是校准仿真给出的有效下界。

则对含 m 个块的计划，
```
P_success ≥ 1 - Σ_{i=1}^m (1-ρ_i^h) - Σ_{i=1}^{m-1} p_seam,i
              - α_d - α_c - α_s - P(d_B > δ_d) - P(T_inf > τ_api).
```
证明要点：块内失败由 `ρ_i^h` 控；块间失败由接缝证书控；漂移/学习/部署三项各由假设给出失败概率上界；对 m 个块做 union bound。证毕。

**命题（逐步证书不能逐点提升为块证书）**
存在误差动力学使 `∏_{t=1}^{h} ρ_t(a_t) = 1`，而块成功率任意低。取 `L=1.02, ε~N(0,0.02²), δ=0.15` 的玩具模型：单步阈值内概率为 1，但 `h=32` 时块成功率约 0.57，`h=64` 时约 0.22。因此第 54 轮的逐动作证书**不能**直接乘成块证书；必须显式引入 `Δ^+(h)` 与接缝项。这一命题是 CHP/CDB 存在的理由，而不是对第 54 轮的否定。

## 6. 本轮最大风险

**一句话**：把证书从单步提升到块，本质上是把 soundness 押在「误差动力学可分段线性化、保形可交换性在五类泛化轴上仍成立、接缝残差能代表真实失败」这三个假设上；一旦接触丰富段的 `L` 估计偏低或未见物品导致保形覆盖静默失效，长块会在真实 G1 上把单步小误差放大成整段失败，且证书仍显示「通过」——因此必须用 **分段 L 估计 + 分组保形 + 接缝实测审计** 三重护栏，宁可短块多问，绝不把「块内平滑」当作「整块可靠」。

## 1. 六个创新点（动机 / 差异 / 可行性 / 资源 / 落地 / 风险）

### IP-121 CHP：块级动作剖面

- **动机**：第 54 轮的 `α_S(a)` 是单步占用，块内 h 步是联合事件；把单步覆盖率相乘会忽略时间相关性，既可能高估也可能低估。
- **与现有方案差异**：ACT/Diffusion Policy 只把块当输出格式，不把块当**证书对象**；CHP 显式定义块空间、块覆盖与块级 LCB。
- **技术可行性**：在现有仿真器里以块为单位 rollout，统计整块成功；块级剖面可直接复用第 54 轮 ACS 的采样器，只是把采样单元从 `a` 换成 `c`。
- **所需资源**：UniBot-V1 的 32,000 条演示（32k×169h）用于先验；仿真算力为主，真机只做少量校准；接口只需在策略输出侧增加 `(h,s)` 元数据。
- **落地步骤**：先离线构建 `C_h` 的块字典与成功标签 → 训练块级成功预测器 → 用保形校准得到 `α_S^h` 下界 → 接入 SCOM 边权。
- **风险**：块空间组合爆炸；缓解为动作哈希 + 分层采样 + 只对任务相关块建表。

### IP-122 CDB：块漂移证书

- **动机**：动作分块的核心代价是块内开环，误差沿动力学累积；没有漂移界，块级成功率就是无根据的乐观估计。
- **与现有方案差异**：2026 年关于「为什么动作分块有效」的工作指出收益来自非马尔可夫表达力、降低复合误差与隐式集成；CDB 把「降低复合误差」从经验观察变成**可校准上界**，并给出何时不该用长块的判据。
- **技术可行性**：`L` 与 `ε` 可由残差模型（预测 `e_{t+1}`）在标定集上估计；递推界是解析的，不需要额外训练大模型。
- **所需资源**：带执行误差标注的仿真 rollout；少量真机重复执行以估计接触段 L；无需新增硬件。
- **落地步骤**：采集 `(e_t,a_t,e_{t+1})` → 拟合残差模型 → 分任务族/接触模式估 L、ε → 用上分位数构造 `Δ^+` → 接入 AHC。
- **风险**：接触丰富段 L 非局部、非恒定；缓解为分段 L + 接触模式检测 + 块内反馈（ACPPO-Corr 式）。

### IP-123 AHC：证书驱动的自适应块长

- **动机**：固定块长在简单段浪费反应性、在困难段透支误差预算；块长应随任务段与观测残差变化。
- **与现有方案差异**：BID 在测试时平衡「长期一致性 vs 短期反应性」，SPACE 从成功轨迹蒸馏块边界，ACPPO-Corr 在块内加反馈校正；AHC 的不同点是**由证书约束求 h***，并用观测残差触发缩短，形成「证书—执行—回退」闭环。
- **技术可行性**：`h*` 只需在 `[h_min,h_max]` 上枚举或二分（Δ(h) 单调时可二分）；运行时开销可忽略。
- **所需资源**：推理时延测量（API P50/P95）；无需额外数据，可直接叠加在现有 VLA 上。
- **落地步骤**：先实现离线 `select_horizon` → 再实现运行时残差绊线与迟滞恢复 → 在 32 任务上对固定 h 做 A/B。
- **风险**：证书过度保守导致步骤分下降；缓解为「证书下界 + 经验成功率」双监控，并按任务族重校准。

### IP-124 BCC：接缝一致性证书

- **动机**：块内平滑不代表块间平滑；接缝处的速度/夹爪跳变是真实失败源，且第 54 轮的组合证书完全没有这一项。
- **与现有方案差异**：时序集成（TE）是启发式平滑，BCC 把接缝残差、jerk 与滞后变成**可测、可拒绝**的证书项。
- **技术可行性**：接缝残差只需相邻块的重叠动作；jerk 可由动作序列差分得到；无需学习。
- **所需资源**：策略需输出重叠块（ACT/流匹配策略天然支持）；真机只需记录接缝附近轨迹。
- **落地步骤**：在数据管线中计算 `b_i` → 标定 `δ_b, J_max` → 在推理时拒绝/混合超限接缝 → 把 `p_seam` 写入联合证书。
- **风险**：只测动作不测结果，可能漏掉「动作连续但物理失败」；缓解为接缝处加视觉/力觉校验并做相关性审计。

### IP-125 CLC：保形学习证书

- **动机**：深度集成的 `σ` 是启发式不确定性，不是覆盖保证；在 UniBot 的未见物品/人为干扰轴上，它最容易过度自信。
- **与现有方案差异**：UGR 用逐时间步不确定性做稀疏精修，ACPPO-Corr 用块内校正；CLC 的不同点是**按任务族×泛化轴分组做保形校准**，并把漂移检测与保守回退写成门控，学习只负责提议。
- **技术可行性**：保形预测是后处理，不需要改网络；深度集成可用 MC-dropout/多 seed/多 checkpoint 近似；分组校准在 32 任务×5 轴上样本量足够。
- **所需资源**：每个任务族/泛化轴的校准集（可从 169h 演示与仿真扩充）；推理时需保留 M 个集成成员或蒸馏出不确定性头。
- **落地步骤**：先按官方五类泛化轴切分校准/测试 → 训练集成 → 计算非 conformity 分数 → 分组求分位数 → 接入门控与 `h_min` 回退。
- **风险**：可交换性在真实分布漂移下失效；缓解为加权保形（密度比有界）+ 漂移检测 + 漏报率预算 `α_s`。

### IP-126 DCC：部署块证书

- **动机**：UniBot 通过标准化 API 远程评测，端侧可能用蒸馏/量化模型；压缩改变块分布与推理时延，原证书不再自动成立。
- **与现有方案差异**：现有 VLA 部署工作多关注吞吐/延迟，不把「部署版行为漂移」写进证书；DCC 用 `d_B` 与 `h_eff` 把部署风险显式化。
- **技术可行性**：`d_B` 可在校准状态集上用块分布采样估计；`h_eff` 由 API 时延分位数直接算出；再证书触发是工程规则。
- **所需资源**：部署版与完整版的同状态对比；API 时延监控；量化/蒸馏工具链（GPTQ/AWQ/LoRA 等按现有栈选择）。
- **落地步骤**：灰度部署 → 估计 `d_B` 与 `h_eff` → 发 `D_cert` → 版本/量化/时延/任务族变化时强制重证。
- **风险**：`d_B` 的支撑集覆盖不足导致低估；缓解为多分布校准集 + 三角不等式上界 + 灰度回滚。

## 3. 关键算法 伪代码

### IP-121 CHP

```python
def chunk_profile(skill, trajectories, h, s, sampler, alpha=0.05):
    C = [traj[i:i+h] for traj in trajectories
         for i in range(0, len(traj)-h+1, s)]
    profile = {}
    for c in C:
        ok, conf = sampler.rollout_chunk(skill, c)
        profile[tuple(c)] = lower_confidence_bound(ok, conf, alpha)
    return ChunkProfile(h, s, profile, block_robustness(profile, dimensions))
```

### IP-122 CDB

```python
def chunk_drift_certificate(h, residual_model, calib_set, delta_task, alpha=0.05):
    Ls, eps = [], []
    for e_t, a_t, e_next in calib_set:
        Ls.append(residual_model.contraction(e_t, a_t))
        eps.append(residual_model.innovation(e_t, a_t, e_next))
    L_hat = upper_quantile(Ls, 1 - alpha)
    eps_plus = upper_quantile(eps, 1 - alpha)
    if abs(L_hat - 1.0) < 1e-9:
        delta_plus = h * eps_plus
    else:
        delta_plus = L_hat**h * norm(e0) + eps_plus * (L_hat**h - 1) / (L_hat - 1)
    return CDB(h, L_hat, eps_plus, delta_plus, delta_task, delta_plus <= delta_task)
```

### IP-123 AHC

```python
def select_horizon(cert_bank, delta_task, rho_min, tau_task, h_min, h_max):
    for h in range(h_max, h_min - 1, -1):
        cdb = cert_bank.drift(h)
        if cdb.delta_plus > delta_task:      # Δ(h) 单调时可 break 加速
            continue
        if min(cert_bank.rho(h).values()) < rho_min:
            continue
        if react_time(h) > tau_task or not cert_bank.learning_valid(h):
            continue
        return h
    return h_min

def run_chunked(policy, cert_bank, task):
    h = select_horizon(cert_bank, task.delta, task.rho_min, task.tau, 1, task.h_max)
    while not task.done:
        c = policy.predict_chunk(task.obs, h)
        for a in c:
            task.step(a)
            if task.residual > KAPPA * cert_bank.drift(h).delta_plus:
                h = max(1, h // 2)           # 证书触发缩短
                break
        else:
            h = min(task.h_max, h + 1)       # 迟滞恢复
```

### IP-124 BCC

```python
def boundary_certificate(chunks, delta_b, jerk_max, lam_v=1.0, lam_g=1.0):
    worst_b = worst_j = 0.0
    for c_i, c_next in zip(chunks[:-1], chunks[1:]):
        o = overlap(c_i, c_next)
        b = norm_inf(c_i[-o] - c_next[0])
        b += lam_v * norm_inf(vel(c_i, -o) - vel(c_next, 0))
        b += lam_g * abs(grip(c_i, -o) - grip(c_next, 0))
        worst_b = max(worst_b, b)
        worst_j = max(worst_j, jerk(c_i, c_next))
    return BCC(worst_b, worst_j, worst_b <= delta_b and worst_j <= jerk_max,
               p_seam=min(1.0, worst_b / delta_b))
```

### IP-125 CLC

```python
def conformal_learned_certificate(ensemble, calib, alpha, theta_s, family, axis):
    scores = [nonconformity(ensemble, x, c) for x, c in calib[family][axis]]
    q = quantile(scores, 1 - alpha)
    def gate(x, c, h):
        if shift_score(x) > theta_s:
            return ('fallback', H_MIN)
        return ('accept', h) if nonconformity(ensemble, x, c) <= q else ('reject', h)
    return LCert(q, alpha, theta_s, gate)
```

### IP-126 DCC

```python
def deployment_certificate(pi_full, pi_deploy, calib_states, tau_api, delta_d):
    d_b = max(wasserstein1(pi_full(x), pi_deploy(x)) for x in calib_states)
    h_eff = min(pi_deploy.h, int((tau_api - T_OTHER) / DT))
    ok = d_b <= delta_d and h_eff >= H_MIN and pi_deploy.latency <= tau_api
    return DCC(d_b, h_eff, pi_deploy.latency, ok,
               triggers=['version', 'quant', 'latency', 'task_family'])
```

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CHP | O(|C|·h) | O(|C|) | 块仿真校准；块级 LCB |
| CDB | O(N·d+h) | O(N) | L、ε 上界覆盖；递推界解析成立 |
| AHC | O(h_max)（单调可二分 O(log h_max)） | O(h_max) | 约束交集非空；回退绊线 |
| BCC | O(m·o·d_a) | O(m·o) | 接缝残差可测；权重有界 |
| CLC | 训练 O(M·N_cal·d)，推理 O(M·d) | O(N_cal) | 分组可交换性；加权密度比有界 |
| DCC | O(N_cal·M·d) | O(N_cal) | 行为距离上界；时延截断 |

**定理（Chunked Execution Soundness, CES）**
在 (A26)–(A28) 与新增 (A29)–(A33) 下（见想法区），对 m 块计划：
```text
P_success ≥ 1 - Σ_{i=1}^m (1-ρ_i^h) - Σ_{i=1}^{m-1} p_seam,i
              - α_d - α_c - α_s - P(d_B>δ_d) - P(T_inf>τ_api).
```
**解释**：块内由 `ρ_i^h` 控，块间由 `p_seam,i` 控，漂移/学习/部署各贡献一个可审计的失败项；所有项都能在部署前从证书读出。若某项无法校准，则不允许该块部署，而不是假设它为零。

**分离命题（为什么需要新层）**
逐动作证书满足 `∏ρ_t=1` 时，块成功率仍可很低。1D 玩具：`L=1.02, ε~N(0,0.02²), δ=0.15`，`h=32` 时块成功率约 0.57、`h=64` 约 0.22；因此第 54 轮的证书不能被逐点乘成块证书。该分离命题是 CHP/CDB 的必要性证明，而不是对 v16 的替代。

## 5. 玩具数值校验（非 UniBot 真机结果）

设置：`e_{t+1}=L e_t+ε_t`，`e_0=0`，`ε~N(0,0.02²)`，误差预算 `δ=0.15`，5 万条轨迹；`ε^+` 取 `|ε|` 的 95% 分位数（0.03897）；`Δ^+(h)` 用定义 122 的解析式。覆盖率 = 模拟 `|e_h| ≤ Δ^+(h)` 的比例。

## 6. 集成更新：v16+++ → v17 GroundEdge-ChunkCert

```text
根信任 + 能力格
│
├─ L0 分布式底座与执行边 (GPC/SEN/TBC)
├─ L0.5 任务迁移与仿真证据 (TIX,XFR,CRC,SFE,FDR,RAB,DST,SBC)

├─ L2 任务/上下文/记忆/语音
...
└─ L6 原型证伪/XFER/LFF/IXD
```

联合块证书与 JCPS 输出扩展：
```text
J_h = (J, H_cert, B_cert, L_cert, D_cert)
JCPS = (v,a,m,q,ι,κ,g,λ,τ,σ,ρ,Explain,RUR_state,α_S,A_cert,γ_ce,δ_a,
        h,s,Δ^+,ρ^h,b_max,h_eff,d_B)
```
新增字段含义：
- `h,s`：块长与步幅；
- `Δ^+`：块漂移上界；
- `ρ^h`：块级鲁棒性下界；
- `b_max`：接缝残差；
- `h_eff`：部署后的有效块长；
- `d_B`：部署版块行为距离。

**与 v16+++ 的退化关系**：
- 令 `h=1, s=1`，则 CHP→ACS、CDB 退化为单步误差界、BCC 无接缝、AHC 恒选 1；
- 令 `d_B=0, h_eff=h`，则 DCC 退化为恒真；
- 若保形校准集与测试同分布且 `α→0`，CLC 退化为第 54 轮的仿真下界。
因此 v17 是 v16+++ 的**严格扩展**，不是另起炉灶。

## 9. 本轮最大风险

**一句话**：块级证书把 soundness 从「单步可控」换成「L 可分段估计 + 保形在五类泛化轴上可交换 + 接缝残差能代表真实失败」三个更强假设，任一假设在接触丰富或未见物品场景下静默失效，长块都会在真实 G1 上把单步小误差放大成整段失败而证书仍显示通过；因此必须以 **分段 L 估计 + 分组保形 + 接缝实测审计** 三重护栏，宁可短块多问，绝不把「块内平滑」当作「整块可靠」。
