## 1. 两个灵感的第一性原理

### 灵感 1 ·「传感器标定」→ 标定是被隐式化的「第二状态层」，而且它先于状态层

**直觉**：任何测量都不是物理量本身，而是 `y = S(x) + b + ε`。标定要估的是灵敏度 `S`、零偏 `b` 与噪声协方差 `Σ_ε`。第 3 轮把「现在在哪、目标是谁」交给场景图（IP-13），再用卡方门限（U17）把「到没到点」变成可校准的假设检验——但这一步**偷偷假设了 `Σ` 已经校准**。真实系统里头/腕相机内外参、相机与本体感受的时间戳偏移、关节编码器零位、夹爪电机位置到实际开口的映射（含背隙与迟滞）全都未知或会漂移。没有标定，卡方断言的误拒率不是设计值 `α`，而是某个未知数。所以本轮主张：**标定不是预处理，而是状态层的承重墙**，必须是显式、可观测性受控、带漂移监控的子系统（IP-16），而不是一次性脚本。

标定的三层严格化（先直觉，后定义）：
1. **传感器级（SelfCal）**：手眼标定 `AX = XB`（头双目 + 腕单目 + 正运动学）；时间偏移用「同一运动在两条信号上的互相关峰」估计；夹爪用双轨模型（命令位置 → 实际开口，显式建模背隙死区与迟滞）。形式化为 U19 标定台账。
2. **不确定性级（Conformal）**：把 U17 的 `d²` 当非一致性分数，用留出标定集的经验分位数替代 `χ²` 分位点 → 有限样本、分布无关的覆盖保证（L14）。这把 L11 的强假设「`Σ` 已校准」弱化为「样本可交换」，更诚实、更可检验。形式化为 U20 共形卡方断言。
3. **仪器级（BenchCal）**：代理评测 IP-06 本身是测量仪器，需对真榜做「仿射 + 噪声」标定并报告预测区间（IP-18，条件于榜单开放）。这是「标定」从传感器向评测栈的严格同构迁移。

### 灵感 2 ·「无刷电机」→ 执行栈本来就是级联控制，缺的是频带分离与无感观测器

**直觉**：无刷电机不是「给电压就转」——FOC 把三相电流分解成转矩/磁通分量，外面套电流环 > 速度环 > 位置环的级联，环与环的带宽必须拉开（内环快 5–10 倍）才不会互相打架；无感驱动没有霍尔/编码器，就用反电动势观测器估转子位置，观测器不可信时退回「强制定位 + 斜坡启动」的开环。我们的执行栈是同构级联：VLA（~1–5 Hz）→ chunk/技能（~10–30 Hz）→ 伺服（~100–500 Hz）。第 3 轮只给了「状态层低频、伺服高频」的直觉分工，本轮把它变成硬约束：**频带分离**（P13）、**执行器可行域过滤**（P14）与**无感接触估计**（L15）。

三个直接可用的转译：
- **无感观测器 ↔ 观测器退化链**：无感 BLDC 的位置估计不可靠时不会硬撑，而是切到开环斜坡；对应我们的 P10 退化链。本轮统一为「**观测器质量门控**」：任何基于估计的模块必须报告自身可信度，低于门限就切保守开环。
- **电机位置 → 无感力估计**：夹爪/灵巧手只有电机位置，没有力/触觉。位置环稳态下 `e = q_cmd − q_act ≈ τ_ext / K_p`（`K_p` 为位置环刚度）——**跟随误差就是外部力矩的代理**。抓取时命令继续闭合而位置停滞（stall）= 接触；运输中跟随误差突然下降 = 夹持力丢失/滑移。这把 IP-14 的纯视觉 SlipGuard 升级为「视觉 + 本体感受」双通道，且不需要新硬件（IP-17，L15）。
- **换相 ↔ 技能切换的相位**：无感换相需要估转子电角度；技能/chunk 切换需要估任务相位（进度）。两者都是「用观测推断隐相位」，可共用 IP-13 的估计器；换相错相 → 抖动/失步，对应 chunk 边界错相 → jerk/ACTION REJECTED。这给 IP-03 的缝合一个物理判据：**相位连续**。

## 2. 研究问题（新增 Q13–Q16，接第 1–3 轮 Q1–Q12）

- **Q13（自标定可观测性与精度）**：手眼/时间/夹爪参数能否仅从任务执行中的自然激励在线估计？精度能否把 U17 覆盖率拉回设计值？（E634/E635）
- **Q14（共形覆盖）**：样本可交换假设下，共形卡方能否给出 `≥1−α` 的有限样本覆盖，且相对高斯 χ² 不显著损失功效？（E635）
- **Q15（执行器感知）**：频带分离 + 可行域过滤 + 跟随误差接触估计，能否减少 ACTION REJECTED/jerk，并提升抓握与滑移判定？（E636/E637/E638）
- **Q16（仪器标定，条件）**：榜单开放后，代理评测对真榜的仿射/噪声标定能否给出可用的预测区间与排序一致性？（E639，条件于 F2）

## 3. 设计原则（新增 P13–P15，接第 1–3 轮 P1–P12）

- **P13（频带分离）**：层级回路带宽至少 5× 分离；状态层与标定层只能事件触发，不得进入高频环；感知延迟按相位预算折算（L16），外环带宽受 `ω_o ≤ min(ω_i/N, φ_m/τ)` 约束。
- **P14（执行器可行域）**：所有动作必须先过执行器模型（位置/速度/力矩/加加速度、背隙补偿）；不可行动作在策略内整形，绝不发给底层。IP-03 的「ACTION REJECTED=0」由此获得物理保证，而不只是试错。
- **P15（标定可观测）**：只估计有激励源的参数；不可观测参数固定为保守常数并登记；每个在线估计量必须有漂移监控与失效回退。**不做「假装估出来」的标定。**

## 5. 本轮最大风险

**标定自欺（calibration self-deception）**：在线自标定可能拟合噪声，或在不可观测方向上「估出一个自信的错误 Σ」，使卡方断言比固定阈值更糟——这是比地图毒化更底层的失败，因为整条断言/介入链都建在它上面。对冲：可观测性门控（U21）+ 共形覆盖的留出检验（E635）+ 漂移监控 + Level-1.7 保守回退。

## 3. 新增 IP 详述

### IP-16 · CalibrationLedger + SelfCal 标定台账与在线自标定（P0，新）

- **动机**：第 3 轮把断言交给卡方门限（U17），而 L11 的结论「断言质量 = 协方差校准质量」实际上把整条链的正确性押在一个没人交付的 `Σ` 上。本轮补上这个交付物。官方资产包（F4）恰好提供 URDF 运动学与相机标称参数，可作为出厂先验。
- **与现有方案差异**：VLA 文献普遍把内外参/时间同步当作既定事实；本方案把标定当作**运行时可观测、可漂移、可退化**的状态，并把「共形覆盖」作为标定的验收指标（而非只看重投影误差）。
- **技术可行性**：高。手眼 `AX=XB`、互相关时延估计、双轨背隙模型、split-conformal 全是成熟件；激励来自任务本身的自然运动，无需专门标定动作（必要时插入 ≤2 步的微小激励，过 P12 记账）。
- **资源**：数据=官方 URDF + IP-06 回放；算力=小（低频/离线）；接口=无新增字段（内部台账）。
- **落地步骤**：①从 URDF 导出厂参数先验与相机标称内外参；②手眼 `AX=XB` + 双目/腕部联合优化；③时延互相关估计；④夹爪双轨（命令→开口，背隙/迟滞）辨识；⑤把残差喂 U20 共形标定集；⑥漂移监控（滑动窗口残差检验）与 Level-1.7 回退。
- **风险**：不可观测方向估出假参数（U21 门控 + P15）；跨本体混用参数（Brainco vs Dex1 分域）；在线标定吃步骤（事件触发 + P12 记账）。

### IP-17 · ActuatorModel + StallSense 执行器模型与无感接触（P1，新）

- **动机**：观测只有电机位置，没有力/触觉；夹爪/灵巧手的「位置」是电机侧量，含背隙与迟滞。运输滑落（IP-14）与抓握确认（IP-02）都需要接触/力信息，而硬件不给。无刷电机的「无感力矩估计」提供了正解：跟随误差是外部力矩的代理。
- **差异**：不是新控制器，而是给现有伺服/chunk 加一层**物理约束与观测器**：可行域整形（P14）、相位连续（IP-03）、stall 接触（L15）。与 IP-16 共享辨识数据与参数台账。
- **可行性**：中高。位置环稳态的 `e ≈ τ_ext/K_p` 关系在刚性接触、未饱和时成立；背隙会让符号在换向瞬间翻转，需用双轨模型 + 方向门控。官方 URDF 给连杆惯量/限位先验。
- **资源**：官方 URDF + 回放；IP-06 含成功/失败抓取，可半自动标注 stall；算力近零。
- **步骤**：①从 URDF + 回放辨识 `K_p`、背隙、速度/力矩/加加速度限；②可行域整形器接入 IP-03/IP-09；③stall 检测器（命令闭合而位置停滞 / 运输中跟随误差骤降）；④证据融合进 IP-02/IP-14；⑤E636–E638。
- **风险**：整形引入跟踪误差（只保留硬限幅）；stall 与「物体太软/自由闭合」混淆（需方向 + 时间窗）；跨手参数不可迁移（分域）。

### IP-18 · BenchCal 评测仪器标定（P1·条件，新）

- **动机**：把「标定」从传感器同构迁移到评测：IP-06 是测量仪器，仪器必须对真值标定。第 3 轮目标「与真机 |r|≥0.5」只是相关性，不是可用的测量保证。
- **差异**：对真榜做「仿射 + 异方差噪声」标定，输出**逐任务/逐轴的预测区间**，并用排序一致性而非单一相关系数验收。
- **可行性**：方法成熟（回归 + conformal）；**唯一阻塞是真榜未开放（F2 本轮 567）**，故列为条件项，预注册先行。
- **资源**：真榜公开数据 + IP-06 结果；算力小。
- **步骤**：①预注册标定模型与验收口径；②榜单开放 48 h 内抓取任务级数据；③拟合仿射 + 噪声；④共形预测区间；⑤重算 IP-06 矩阵并标注不确定度。
- **风险**：真榜样本少/选择偏差（分层 + 报告区间）；评测协议差异（先对齐提交配置再标定）。

## 5. 符号与定义（新增 U19–U22；U1–U18 沿用第 1–3 轮）

- **定义 U19（标定台账）**：按本体/末端分域的持久结构 `C = (θ_kin, θ_cam, τ_sync, g_grip, K_p, Σ_cal, health)`；`θ_kin` 为运动学/零位参数，`θ_cam` 为内外参，`τ_sync` 为传感器时间偏移，`g_grip: q_cmd ↦ (开口, 背隙, 迟滞)`，`K_p` 为位置环刚度，`Σ_cal` 为共形标定集与阈值，`health` 为漂移监控状态。生命周期跨 episode（同本体），须过合规确认。
- **定义 U20（共形卡方断言）**：给定可交换的标定样本 `{(x_j, g_j)}`，非一致性分数 `s_j = (x_j−g_j)ᵀ Σ⁻¹ (x_j−g_j)`；取 `q̂ = s_{(⌈(n+1)(1−α)⌉)}`（升序第 `⌈(n+1)(1−α)⌉` 个），断言「到点」⇔ `s_new ≤ q̂`。则在可交换性下边际覆盖 `P(s_new ≤ q̂) ≥ 1−α`（L14），不要求高斯或 `Σ` 精确。
- **定义 U21（标定可观测性）**：参数 `θ` 在激励轨迹 `ξ` 上局部可观测 ⇔ 其雅可比 `J_ξ(θ)` 满列秩（等价地 Fisher 信息 `JᵀJ` 最小特征值 > ε）；只对满秩参数做在线估计，否则固定为出厂常数并标记 `frozen`。
- **定义 U22（执行器模型）**：`A = (q_min/q_max, q̇_max, τ_max, j_max, b_backlash, K_p)`；可行动作集 `F = {a : a 满足位置/速度/力矩/加加速度与背隙约束}`。stall 残差 `e = q_cmd − q_act`；稳态接触力代理 `F̂ = K_p · e / ℓ`（`ℓ` 为等效力臂）。

```python
# ===== IP-16: 标定台账（分域；可观测性门控 + 漂移监控）=====
class CalibrationLedger:
    def __init__(self, embodiment, urdf):
        self.prior = load_urdf_prior(urdf)      # U19: 出厂先验
        self.cal = dict(self.prior)             # θ_kin/θ_cam/τ_sync/g_grip/K_p
        self.cal_set = []                        # U20: 共形标定集 (x, g)
        self.health = {"drift": False, "obs_ok": True}

    def fit(self, traj, min_eig=1e-6):
        J = jacobian(traj, self.cal)             # U21
        mask = eigvalsh(J.T @ J) > min_eig       # 只估可观测方向
        self.cal = refine_observable(self.cal, traj, mask)
        self.health["obs_ok"] = bool(mask.any())
        return self.cal

    def check_drift(self, residuals):
        if page_hinkley(residuals) > LAMBDA_DRIFT:
            self.health["drift"] = True          # P15 / Level-1.7

    def fallback(self):
        self.health["obs_ok"] = False
        return self.prior                        # Level-1.7: 保守常数
```

```python
# ===== U20: 共形到点断言（替换 U17 的 χ² 分位点；分布无关）=====
def conformal_threshold(scores, alpha):
    s = np.sort(np.asarray(scores))
    n = len(s)
    k = math.ceil((n + 1) * (1 - alpha))
    return s[min(k, n) - 1] if k <= n else np.inf   # 样本不足则不放行

def assert_waypoint_conformal(wp, state, ledger, alpha):
    x, S = state.estimate_ee_object_rel(wp)         # Σ 来自 U19 台账
    s = mahalanobis(x, wp.goal, S)
    q = conformal_threshold(ledger.cal_set_for(wp), alpha)
    return s <= q, s, q
```

```python
# ===== IP-17: 执行器可行域整形（P14；背隙感知）=====
def shape_action(a_des, model, q_act):
    a = clamp(a_des, model.q_min, model.q_max)
    a = rate_limit(a, model.qd_max, model.dt)
    a = accel_limit(a, model.j_max, model.dt)
    a = backlash_compensate(a, q_act, model.b_backlash)
    return a                                        # 永不越过物理限

def stall_contact(q_cmd, q_act, model, phase):
    e = q_cmd - q_act                               # U22 跟随误差
    if phase == "grasp" and closing(q_cmd) and abs(e) > TAU_STALL:
        return True                                 # 命令闭合而位置停滞 → 接触
    if phase == "transport" and abs(e) < TAU_LOSS:
        return "SLIP_SUSPECT"                       # 夹持力丢失 → 滑移告警
    return False
```

## 7. 推导（新增引理 L14–L16；L1–L13 沿用第 1–3 轮）

**引理 L14（共形覆盖）** 设标定样本与测试样本可交换（i.i.d. 为特例），非一致性分数 `s_j` 连续无并列，取 `q̂ = s_{(⌈(n+1)(1−α)⌉)}`，则 `P(s_new ≤ q̂) ≥ 1−α`。证明：在 `n+1` 个可交换分数中，`s_new` 的秩均匀分布于 `1..n+1`；`s_new ≤ q̂` 当且仅当其秩 ≤ `⌈(n+1)(1−α)⌉`，故覆盖概率为该秩/`(n+1) ≥ 1−α`。∎ ⇒ 断言的正確性由「可交换性 + 标定集」保证，不再依赖 L11 的高斯/Σ 精确假设；代价是覆盖率保守（有限样本）且要求标定集与部署同分布（分布漂移时须重置，Q13/Q14）。

**引理 L15（跟随误差作为接触力代理）** 位置环稳态（`q̇≈0, q̈≈0`）下电机力矩平衡 `K_p(q_cmd−q_act) = τ_ext`（`K_p` 为位置环刚度，忽略摩擦/饱和），故 `F̂ = K_p e / ℓ`。抓取相位「命令持续闭合而 `e` 增大并饱和」是接触的充分迹象（自由闭合时 `e→0`）；运输相位「`e` 从接触稳态骤降到近零」是夹持力丢失的迹象。⇒ 无力传感时，**stall 的符号与幅值给出接触/滑移的二值 + 连续代理**；有效性边界：刚性接触、未饱和、背隙方向已知（否则用双轨模型门控）。∎

**引理 L16（延迟受限的外环带宽）** 级联系统中内环带宽 `ω_i`、外环 `ω_o`，为抑制相互作用需 `ω_o ≤ ω_i/N`（`N≥5`）。设感知/通信死时间 `τ`，外环在 `ω_o` 处附加相位滞后 `≈ ω_o τ`；要求相位裕度 `φ_m`，则 `ω_o τ ≤ φ_m`（弧度），即 `ω_o ≤ φ_m/τ`。合取得 `ω_o ≤ min(ω_i/N, φ_m/τ)`。⇒ 例：`τ=100 ms, φ_m=45°≈0.785` → `ω_o ≤ 7.85 rad/s ≈ 1.25 Hz`——**这就是「状态层为什么必须低频 + 事件触发」的硬上限**，也解释 U12/E633 的延迟预算不是工程偏好而是稳定性约束。∎
