# 第 1 轮（灵感循环第 1 轮；基线：第 7 轮 MetricVoiceGauge-OTL-GC-ER，定义 493–525，引理 73–76，实验 E513–E525）

> 本轮灵感：「UniBot世界挑战赛」×「技能学习」
> 本轮纪律：**外部评测锚定 + 技能契约 + 泛化证书**。挑战赛提供「公开/私有赛道分割」的外部任务分布；技能学习提供可复用、可组合的能力单元；二者交汇于「在私有赛道上被证明有效」这一目标，而非「在自评指标上好看」。

## 0. 直觉与动机

**灵感 1（UniBot世界挑战赛 → 从自评指标到赛题契约）**
直觉：前七轮把指标体系做到了「自洽」，但再精致的指标体系仍然只是**自评**。世界挑战赛的真正价值不在奖杯，而在于它是一套外部、隐藏、协议固定的评测：分赛道（操作 / 导航 / 移动操作 / 人机协作 / 长程任务）、统一评分 rubric、公开训练集与私有测试集分离、以及时限与硬件约束。研究系统最大的敌人往往不是「不会做」，而是**在自己的指标上过拟合**（Goodhart 定律）。因此本轮把「竞赛契约」提升为一等公民：先有 `ChallengeContract`（赛道→任务→技能三层本体 + rubric + 公开/私有分布），再把 rubric 编译为内部指标层级，并要求「内部指标全改善 ⇒ 官方分数不下降」的单调性；任何结论都必须附带**私有赛道泛化证书**，而不是只报公开集分数。

**灵感 2（技能学习 → 可组合、可认证的能力库）**
直觉：与其每一轮都从零规划轨迹，不如维护一个不断生长的**技能库**。每个技能带类型化契约（前置条件 / 效果 / 终止 / 资源），可被组合成更长程的行为；技能有「熟练度等级」，由有限次试验的统计下界认证；技能之间构成偏序格，支持泛化 / 特化与跨赛道迁移。于是 MetricVoiceGauge 的指标不再只挂在「当前轨迹」上，而是挂在**技能及其组合**上；组合是否合法、是否保持安全不变式，从经验问题变成可证明的问题。

**交汇：挑战驱动的技能课程（Challenge-driven Skill Curriculum）**
直觉：挑战赛的多赛道恰好是技能迁移的天然测试床；技能学习则让「一个赛道学到的能力」可被复用到另一个赛道。核心研究目标因此变成：**用最少的私有赛道试错预算，把技能格中真正能迁移的部分认证出来**——不是「刷公开榜」，而是「用证书逼近私有榜」。这也解释了为什么两个灵感词不是简单拼接：挑战给出「评什么」，技能学习给出「如何长出被评的能力」，而证书是二者之间的桥。

## 1. 研究问题

- **Q1（赛题→指标编译）**：如何把官方 rubric 编译为 MetricLadder 的层级与权重，使内部优化对官方分数**单调**，并通过反事实 rubric 扰动的抗作弊审计？
- **Q2（技能契约与组合可靠性）**：如何定义类型化技能契约，使组合 s₁∘s₂ 的合法性可判定，且组合后仍保持 CVC / SpatialCert 安全不变式？
- **Q3（隐藏分布下的认证）**：当公开 / 私有赛道存在分布偏移时，需要多少次试验、以何种统计下界，才能把技能认证到等级 ℓ，并保证迁移到私有赛道的风险可控？
- **Q4（课程调度）**：在固定算力 / 试错预算下，如何选择下一个要学的技能，使私有赛道的期望分数增益最大？

## 2. 设计原则（P10–P12，继承 P7–P9）

**P10 赛题锚定指标（Challenge-Anchored Metric, CAM）**
官方 rubric ρ 编译为指标层级映射 𝔠: M → rubric 分项，要求**单调性**：

```
∀ s, s': (∀ i, Mᵢ(s) ⪰ Mᵢ(s')) ⇒ score_ρ(s) ≥ score_ρ(s')
```

并配合反事实审计：对 rubric 施加保序小扰动，若策略的官方分变化超过阈值，则判定存在 reward hacking。

**P11 类型化技能契约（Typed Skill Contract, TSC）**
技能 s 的契约 κ_s = (Pre_s, Eff_s, Term_s, Res_s, Cert_s)。组合 s₁∘s₂ 合法当且仅当 Eff_{s₁} ⊨ Pre_{s₂}（在框架公理下蕴含）。安全义务 Safety_s 作为契约的附加合取项，沿组合链累积；因此「组合健全」不是靠测试碰运气，而是由契约的结构给出。

**P12 渐进认证与课程前沿（Progressive Certification & Curriculum, PCC）**
技能熟练度 ℓ ∈ {N, C, P, E}（新手 / 胜任 / 熟练 / 专家），由成功次数 k、试验次数 n 的置信下界 L(k,n,δ) 与等级阈值 θ_ℓ 比较决定。课程只在「前沿技能」（其前置技能均已认证）中选取，按「期望私有增益 / 算力」排序，避免在简单技能上无限刷分。

## 3. 与基线接口（如何退化）

- `ChallengeContract` 缺失 ⇒ 退化为单默认任务，等价于 v7；
- 技能库缺失 ⇒ 退化为原始动作原语执行，等价于 v7；
- 认证模块失效 ⇒ 用经验成功率点估计替代置信下界，证书降级为「经验声明」；
- 课程调度失效 ⇒ 均匀轮转；
- 任一情形都保留 v7 的 OTL / GCT / ER，且不改变 50Hz 主路径 WCET。

## 4. 预期贡献

1. **ChallengeContract → MetricLadder 编译器**：赛道 / 任务 / 技能三层本体、rubric 锚定、单调性与抗作弊审计；
2. **类型化 SkillContract 与 SkillLattice**：组合合法性判定与安全不变式保持证明；
3. **隐藏分布下的渐进认证**：Clopper–Pearson 下界 + 分布偏移预算，给出可审计的技能证书；
4. **课程调度器**：以「私有赛道期望增益 / 算力」为目标的前沿探索；
5. 完整 **挑战-技能-指标-语音** 闭环与退化链，实验 E531–E550。

## 5. 本轮最大风险

**一句话**：认证是在公开赛道上做的，而课程又天然偏好「容易认证」的技能，系统可能把「证书覆盖率」误当成「真实能力」，在私有赛道上出现**认证了但不胜任**的泛化崩塌。

**新增定义 526（竞赛契约 ChallengeContract）**
```
C = (T, K, S, ≺, ρ, D_pub, D_priv)
```
其中 T 为赛道集合，K 为任务集合，S 为技能集合，≺ 为「技能先于技能」偏序，ρ 为官方评分函数族（含分项权重与门限），D_pub / D_priv 为公开与私有任务分布。

**新增定义 527（任务技能需求 TaskSkillRequirement）**
```
req: K → 2^S,   κ(k) = {s ∈ S : s 为完成任务 k 所必需}
```
并要求 `≺` 与 `req` 一致：若 s ≺ s' 且 s' ∈ κ(k)，则 s ∈ κ(k)。

**新增定义 528（评分编译与单调性 RubricCompiler / MRM）**
编译映射 `𝔠: M → ρ` 将指标层级的每个分项映射到 rubric 分项；称 𝔠 满足**指标-rubric 单调性（MRM）**当且仅当
```
∀ s, s': (∀ i ∈ {0,1,2,3}, Mᵢ(s) ⪰ Mᵢ(s')) ⇒ Score_ρ(s) ≥ Score_ρ(s')
```
编译器须输出 MRM 的检查见证（每个 rubric 分项的单调依赖表）。

**新增定义 529（抗作弊审计 AntiHackAudit）**
设 `Π_ρ` 为 rubric 的保序扰动族（分项权重在容差内变动但不改变分项排序）。定义
```
HackMargin_ε(π) = sup_{ρ' ∈ Π_ρ} |Score_{ρ'}(π) − Score_ρ(π)|
```
若 `HackMargin_ε(π) > ε_hack` 或内部奖励与官方分的 Spearman 相关 `< 0.9`，判定为可疑 reward hacking。

**新增定义 530（类型化技能契约 TypedSkillContract）**
```
κ_s = (Pre_s, Eff_s, Term_s, Res_s, Safety_s)
```
Pre_s 为前置状态谓词，Eff_s 为效果（含框架公理，声明未被改变的事实），Term_s 为终止条件，Res_s 为资源/时间界，Safety_s 为附加安全义务（CVC、SpatialCert 等的合取）。

**新增定义 531（技能组合 SkillComposition）**
组合 `s₁ ∘ s₂` 为部分函数，定义域为
```
dom(∘) = {(s₁, s₂) : Eff_{s₁} ⊨ Pre_{s₂} ∧ Res_{s₁} + Res_{s₂} ≤ Res_budget}
```
组合契约与安全义务：
```
Pre_{s₁∘s₂} = Pre_{s₁}
Eff_{s₁∘s₂} = (Eff_{s₁} \ Pre_{s₂}) ∪ Eff_{s₂}      （框架公理下）
Safety_{s₁∘s₂} = Safety_{s₁} ∧ Safety_{s₂}
```

**新增定义 532（技能格 SkillLattice）**
```
𝕃 = (S, ⪯),   s ⪯ s' ⇔ Pre_{s'} ⇒ Pre_s ∧ Eff_s ⇒ Eff_{s'} ∧ Safety_{s'} ⇒ Safety_s
```
即 s' 的前置更弱、效果更强、义务更强，则 s' 覆盖 s。𝕃 用于三件事：组合闭包、泛化/特化检索、跨赛道迁移邻域。

**新增定义 533（熟练度等级 CompetenceLevel）**
```
ℓ(s) = max { ℓ ∈ {N,C,P,E} : L(k_s, n_s, δ_s) ≥ θ_ℓ }
```
若集合为空则 ℓ(s) = N（未认证）。课程调度只使用已认证等级，不使用未经验证的点估计。

**新增定义 534（Clopper–Pearson 下界）**
对 k 次成功、n 次独立伯努利试验、单侧置信水平 1−δ：
```
L(k, n, δ) = Beta^{-1}(δ; k, n−k+1),  1 ≤ k ≤ n
L(0, n, δ) = 0
```
满足 `P_p(p ≥ L(k,n,δ)) ≥ 1−δ`。认证所需样本量可用
```
n_min(ℓ, δ, ε) ≈ ⌈ z_{1−δ}² · θ_ℓ(1−θ_ℓ) / (θ_ℓ − ε)² ⌉
```
做预算规划，其中 ε 为可接受的真实成功率裕度。

**新增定义 535（泛化证书 GeneralizationCert）**
```
GenCert_s = (n_s, k_s, L_s, Δ̂_s, ε_priv,s, δ_s)
```
对取值于 [0,1] 的有界损失，私有风险满足（以概率 ≥ 1−δ−δ_Δ）
```
R_priv(s) ≤ (1 − L_s) + sqrt( log(1/δ_s) / (2 n_s) ) + Δ̂_s
```
证书仅在 `Δ̂_s ≤ Δ_max` 时签发；否则标记为「偏移超预算，不可迁移」。

**新增定义 536（分布偏移预算 DistributionShiftBudget）**
用域分类器误差 e 估计总变差上界：
```
Δ̂(D_pub, D_priv) = 1 − 2·ê + sqrt( log(1/δ_Δ) / (2 m) )
```
其中 ê 为域分类器在 m 个无标注样本上的留出误差，δ_Δ 为其置信参数。

**新增定义 537（课程前沿 CurriculumFrontier）**
```
F = { s ∈ S : ∀ s' ≺ s, ℓ(s') ≥ P } \ { s : ℓ(s) = E }
gain(s) = [θ_{next(ℓ(s))} − L_s]_+ · LP(s) · Transfer(s) / Res_s
next(s) = 认证 ℓ(s) 之后的目标等级
```
LP 为学习进度（窗口内成功率的绝对变化），Transfer 由 𝕃 上的迁移邻域估计。

**新增定义 538（技能信用 SkillCredit）**
对长度为 m 的技能链 P = (s₁,…,s_m)，用 Shapley 值归因：
```
φ_s = Σ_{A ⊆ P\{s}} [ |A|! (m−|A|−1)! / m! ] · ( v(A ∪ {s}) − v(A) )
```
其中 v(A) 为子链 A 的实测回报。用 K 个随机排列做蒙特卡洛估计，`O(K·m)`。

**新增定义 539（语音接地技能选择 VoiceGroundedSkillSelector）**
```
ℓ_voice → ASR → (text, conf)
if conf < τ_voice: ι ← ι₀
else: text → NLI → ι（含 GCT 抓取几何检查）
      ι → τ_k（任务实例）→ S_τ = { s ∈ S : s 可满足 κ(k) 且 Pre_s(τ_k) 成立 }
      if S_τ = ∅: 请求澄清 / 退回 ι₀
      else: π = min-cost 组合覆盖 κ(k)（在 𝕃 上搜索）
```

**新增定义 540（挑战闭环 Φ_SLC）**
```
Φ_SLC = { C 编译为 𝔠(M), S_τ 由语音接地选出, π 由合法组合生成,
          ℓ 由 GenCert 认证, 下一轮课程由 gain 选出 }
```

**新增定义 541（退化映射 ∂: SLC → v7）**
∂ 逐模块把 SLC 的可选增强替换为 v7 的固定行为，且要求
```
Behavior(∂(SLC)) ≡ Behavior(v7)
```
在外部可观测的指令-轨迹-证书三元组上成立。

## 2. 形式化定义（要点补充）

**定义 542（内部-官方分数对齐 ScoreAlignment）**
在留出任务集上，内部总奖励 J_M 与官方分 Score_ρ 的 Spearman 秩相关须 ≥ 0.9；否则 MRM 视为未建立，禁止用 J_M 做模型选择。

**定义 543（技能证书链 CertificateChain）**
长程任务 k 的证书链为 `CertChain(k) = (GenCert_{s₁}, …, GenCert_{s_m})`，并要求组合安全义务 `⋀ᵢ Safety_{sᵢ}` 与任务级 CVC/SpatialCert 合取后仍可满足。

## 3. 关键算法骨架

```python
# IP-350/351/352：竞赛契约编译 + 单调性 + 抗作弊
class ChallengeContract:
    def __init__(self, tracks, tasks, skills, precedes, rubric, d_pub, d_priv):
        self.T, self.K, self.S = tracks, tasks, skills
        self.precedes = precedes
        self.rho = rubric
        self.d_pub, self.d_priv = d_pub, d_priv

    def req(self, k):
        """任务 k 的必需技能集合（与 precedes 一致）"""
        need = set(self.S[k].required)
        for s in list(need):
            for s0 in self.S:
                if self.precedes(s0, s) and s in need:
                    need.add(s0)
        return need


class RubricCompiler:
    def __init__(self, metric_ladder, rubric):
        self.M, self.rho = metric_ladder, rubric

    def compile(self):
        """rubric → 指标层级权重；输出单调依赖表作为 MRM 见证"""
        mapping = {}
        for item, spec in self.rho.items():
            mapping[item] = [i for i, m in enumerate(self.M.layers) if m.name in spec.deps]
        witness = self._monotone_witness(mapping)
        if not witness.ok:
            raise ValueError(f"MRM 违例: {witness.counterexample}")
        return mapping, witness

    def _monotone_witness(self, mapping):
        """在有限状态网格上检查 ∀i Mᵢ↑ ⇒ score↑"""
        for s, s2 in self._sample_comparable_pairs():
            if all(self.M.value(s, i) >= self.M.value(s2, i) for i in range(4)):
                if self.rho.score(s) < self.rho.score(s2):
                    return Witness(ok=False, counterexample=(s, s2))
        return Witness(ok=True)


class AntiHackAudit:
    def __init__(self, epsilon_hack=0.02, min_spearman=0.9):
        self.epsilon_hack, self.min_spearman = epsilon_hack, min_spearman

    def audit(self, policy, contract, val_tasks):
        scores, internals = [], []
        for k in val_tasks:
            pi = policy.plan(k)
            scores.append(contract.rho.score(pi))
            internals.append(policy.internal_reward(pi))
        rho = spearman(internals, scores)
        drift = max(abs(contract.rho.score(policy.plan(k), perturbed=True)
                        - contract.rho.score(policy.plan(k))) for k in val_tasks)
        return AuditResult(ok=(drift <= self.epsilon_hack and rho >= self.min_spearman),
                           drift=drift, spearman=rho)


# IP-353/354/355：契约、技能格、组合
class Skill:
    def __init__(self, name, pre, eff, term, res, safety):
        self.kappa = dict(Pre=pre, Eff=eff, Term=term, Res=res, Safety=safety)

    def __le__(self, other):
        """s ⪯ s'：s' 覆盖 s"""
        return (implies(other.Pre, self.Pre)
                and implies(self.Eff, other.Eff)
                and implies(other.Safety, self.Safety))


class SkillComposer:
    def __init__(self, lattice, res_budget):
        self.L, self.res_budget = lattice, res_budget

    def compose(self, s1, s2):
        if not entails(s1.Eff, s2.Pre):
            return None, "Eff₁ ⊭ Pre₂"
        if s1.Res + s2.Res > self.res_budget:
            return None, "资源超预算"
        return ComposedSkill(s1, s2,
                             pre=s1.Pre,
                             eff=(minus(s1.Eff, s2.Pre) | s2.Eff),
                             safety=And(s1.Safety, s2.Safety)), "ok"

    def plan(self, need):
        """在技能格上搜索最小代价合法组合覆盖 need"""
        return astar(self.L, start=empty_plan, goal=need,
                     expand=self.compose, cost=lambda p: p.res)


# IP-356/357：认证 + 泛化证书
class SkillCertifier:
    def __init__(self, levels=(0.55, 0.70, 0.85, 0.95), delta=0.05, delta_shift=0.05):
        self.theta = dict(zip(["N", "C", "P", "E"], levels))
        self.delta, self.delta_shift = delta, delta_shift

    def cp_lower(self, k, n, delta):
        if k == 0:
            return 0.0
        return beta_ppf(delta, k, n - k + 1)

    def certify(self, s, k, n, d_pub, d_priv):
        L = self.cp_lower(k, n, self.delta)
        level = "N"
        for lv in ["N", "C", "P", "E"]:
            if L >= self.theta[lv]:
                level = lv
        n_min = math.ceil((z(1 - self.delta) ** 2 * self.theta["P"] * (1 - self.theta["P"]))
                          / (self.theta["P"] - 0.05) ** 2)
        delta_hat = estimate_tv(d_pub, d_priv, self.delta_shift)
        eps_priv = (1 - L) + math.sqrt(math.log(1 / self.delta) / (2 * n)) + delta_hat
        ok = delta_hat <= DELTA_MAX
        return GenCert(n=n, k=k, L=L, delta_hat=delta_hat,
                       eps_priv=eps_priv, level=level, transferable=ok, n_min=n_min)


# IP-358：课程前沿
class CurriculumFrontier:
    def __init__(self, lattice, certifier, transfer):
        self.L, self.cert, self.transfer = lattice, certifier, transfer

    def frontier(self, certs):
        return [s for s in self.L.S
                if all(certs.get(p, GenCert.untrained()).level in ("P", "E")
                       for p in self.L.predecessors(s))
                and certs.get(s, GenCert.untrained()).level != "E"]

    def next_skill(self, certs, budget):
        best, best_gain = None, -1.0
        for s in self.frontier(certs):
            c = certs.get(s, GenCert.untrained())
            gain = max(0.0, self._next_theta(c.level) - c.L) \
                   * self._learning_progress(s) * self.transfer(s) / max(s.Res, 1e-6)
            if gain > best_gain and s.Res <= budget:
                best, best_gain = s, gain
        return best, best_gain


# IP-360：语音接地技能选择
class VoiceGroundedSkillSelector:
    def __init__(self, grasp_typing, contract, composer):
        self.gct, self.C, self.composer = grasp_typing, contract, composer

    def select(self, audio_stream, state):
        iota, ok, log = self.gct.process(audio_stream)   # 含 GCT 抓取几何
        if not ok:
            return None, "语音/几何退化", log
        k = self.C.task_from_iota(iota)
        need = self.C.req(k)
        candidates = [s for s in need if s.Pre(state)]
        if not candidates:
            return None, "前置条件均不满足，请求澄清", log
        plan, reason = self.composer.plan(need)
        if plan is None:
            return None, f"无合法组合: {reason}", log
        return plan, "ok", log

def metricvoicegauge_round_8(M, s, obs, audio_stream=None, ell=None,
                             contract=None, certifier=None,
                             curriculum=None, selector=None):

    C, spatial_cert, claims = M.v7_core(s, plan, metrics, tau, R)
```

## 4. 推导

**引理 77（组合健全性）** 若每个技能契约 frame-complete（效果之外的事实不变），且 `Eff_{s₁} ⊨ Pre_{s₂}`，则 s₁∘s₂ 的任一执行都从 `Pre_{s₁}` 出发、终止于 `Eff_{s₁∘s₂}`，且不破坏 `Safety_{s₁} ∧ Safety_{s₂}`。
*证明要点*：对执行长度归纳。s₁ 终止时，框架公理保证 Eff_{s₁} 之外的事实不变；由蕴含关系，Pre_{s₂} 在此时成立，故 s₂ 可启动；两条安全义务各自在其执行区间成立，区间不重叠且边界由框架公理衔接。∎

**引理 78（认证覆盖率）** 在独立同分布试验下，定义 534 的 CP 下界满足 `P(p ≥ L(k,n,δ)) ≥ 1−δ`；因此按定义 533 判定的等级 ℓ 不会系统性地高估真实成功率。
*证明要点*：Clopper–Pearson 下界与 Beta 分布的尾概率对偶性，标准结论。∎

**引理 79（课程前沿单调推进）** 在固定预算下，CurriculumFrontier 每步要么认证一个前沿技能到更高等级，要么提升某技能的下界 L；前后沿集合只增不减（直到预算耗尽或 F 为空），因此不会在已认证技能上无限循环。
*证明要点*：前沿定义排除前置未认证技能与已达 E 级技能；每步更新 k/n 使 L 单调不减（k 增或 n 增时 CP 下界的单调性），当所有前沿技能达 E 或预算耗尽时终止。∎

**引理 80（泛化证书有效性）** 若损失有界于 [0,1]、公开样本 iid、偏移估计 `Δ̂ ≥ TV(D_pub, D_priv)` 以概率 ≥ 1−δ_Δ 成立，则定义 535 的私有风险上界以概率 ≥ 1−δ−δ_Δ 成立。
*证明要点*：Hoeffding 给 `R_pub ≤ R̂_pub + sqrt(log(1/δ)/(2n))`；TV 定义给出 `|E_pub ℓ − E_priv ℓ| ≤ TV`；CP 给 `R̂_pub ≤ (1−L)` 的覆盖；三者并集界合并。∎

**引理 81（退化等价性）** 若 SLC 的任一模块失效并按定义 541 替换为 v7 行为，则外部可观测的指令-轨迹-证书三元组与 v7 同分布。
*证明要点*：逐模块检查：契约缺失只删去 rubric 映射与技能候选过滤，不改变 v7 的 OTL/GCT/ER 与安全层；组合缺失使计划退化为原语序列，与 v7 的 PrimitiveGraph 一致；认证缺失只把证书从统计下界换成点估计，不改变执行路径；课程缺失只改变「下一轮学什么」，不改变当前轮执行。∎
