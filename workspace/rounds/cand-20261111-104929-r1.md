# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「可扩展性」×「数据集构建」）

> 第 54 轮把技能组合提升为动作-鲁棒性双证书，但该体系在真实规模下暴露出两个未被处理的硬约束。本轮聚焦 **动作剖面的可扩展化、证据数据集的覆盖契约、解释驱动的定向采集**。核心矛盾：H22：动作剖面与组合图的成本随 `|S|`、`|A|` 组合爆炸，穷举采样无法支撑证书规模，且绝大多数动作格子高度冗余；H23：证书所需证据按“任务/场景”散落云边，数据集有量无覆盖，联合证书 `J` 存在未被发现的覆盖空洞。

## 0. 直觉与动机

**灵感 1（可扩展性 → 把动作剖面从穷举表变为低秩可补全结构）**
直觉：`α_S : S×A → [0,1]` 名义上是 `|S|·|A|` 个数，但真实技能由少量共享运动原语构成，剖面近似低秩：`α(S,a) ≈ Σ_{k=1}^r u_{S,k} φ_k(a)`，`r ≪ min(|S|,|A|)`。于是穷举采样退化为「少量 D-最优锚点 + 主动采样 + 矩阵/张量补全」。校准成本从 `O(|S|·|A|)` 降到 `O(r(|S|+|A|))`。**可扩展性的第一性来源是结构复用，而不是更快的暴力枚举。**

**灵感 2（数据集构建 → 从“采数据”变成“采证据”）**
直觉：证书需要的不是数据量，而是**覆盖证据**。把数据集 `D` 组织为按 `(技能, 动作格子, 鲁棒维度)` 分层的**证据账本** `𝔾`，每格记录样本数 `n_g`、标签均值 `ŷ_g`、置信区间 `CI_g`、反例集与 Explain 根因。定义**证据覆盖度 `Cov(D)`**：只有当 `Cov(D) ≥ Θ_cov` 且分层无空洞时，数据集才“足以支撑证书”。这把数据集构建从堆量变成可审计的覆盖契约，直接对接第 54 轮的 `J`。

**灵感 3（解释驱动采集 → 用失败根因选择“采哪里”）**
直觉：第 54 轮的 `Explain` 已能返回边端失败根因 `a_e`。把 `Explain` 的输出当作采集分布 `Q_exp(· | failure)`，在根因动作格子的邻域加密采样，而非全空间均匀随机。形成 **失败 → 解释 → 定向采集 → 重剖面 → 再验证** 的数据闭环，单位样本对覆盖度的边际收益显著高于随机采样。

**灵感 4（惰性组合图 → 边搜索边展开，存储与技能数脱钩）**
直觉：`G_S` 全量 `|S|²` 边在技能库变大时爆炸。改为**惰性展开**：`A*` 只在访问节点时，用动作签名 `LSH` 检索候选邻居，动态生成并验证 `compat`；未展开的 frontier 用可采纳下界 `h_adm` 估计。最优性不变，存储从 `O(|S|²)` 降为访问带 `O(b·d)`。这把第 54 轮的 `SCOM` 从“先建全图”改为“按需证实”。

**灵感 5（可扩展证书 → Merkle 证据根 + 增量重算）**
直觉：证书会随数据集持续增长。把 `D` 分层哈希成**证据根 `R_D`**，联合证书只携带 `R_D` 与覆盖摘要 `Cov`；新增一个样本只需 `O(log n)` 更新根路径，跨层迁移证书引用根即可，无需传全量数据。这样证书体积与验证成本**与数据规模解耦**，也天然支持云边各自持有分片、按根对账。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（动作剖面低秩分解）**
动作剖面张量 `𝒜 ∈ [0,1]^{|S|×|A|}` 的低秩近似 `α̂(S,a) = Σ_{k=1}^{r} u_{S,k} φ_k(a)`，其中 `φ_k ∈ Φ` 为共享动作基。**剖面秩** `r_α(ε) = min{ r : ‖α̂ - α‖_F ≤ ε_α }`。当 `r_α` 远小于 `min(|S|,|A|)` 时称剖面**可压缩**。

**定义 122（分层证据账本）**
分层网格 `𝔾 = 𝕊 × 𝔸_disc × 𝔇_ρ`，其中 `𝔸_disc` 为动作空间的离散格子划分，`𝔇_ρ` 为第 53 轮鲁棒维度集。每个格子 `g∈𝔾` 记录 `E_g = (n_g, ŷ_g, CI_g, Cex_g, root_g)`：样本数、标签均值、置信区间、反例集、Explain 根因摘要。账本 `D = {E_g}` 构成数据集的结构化视图。

**定义 123（证据覆盖度）**
令可靠性判据 `reliable(g) = 1[n_g ≥ n_min ∧ width(CI_g) ≤ ε_c]`，风险权重 `w_g ≥ 0`，则
```
Cov(D) = Σ_{g∈𝔾} w_g · reliable(g) / Σ_{g∈𝔾} w_g
```
**空洞集** `Gap(D) = {g : n_g < n_min ∧ g 可采集}`，**不可采集盏** `Starve(D)` 单独记录，二者共同解释覆盖为何未达标。

**定义 124（数据集充分性证书 DSC）**
`DSC = (R_D, Cov, Gap, Starve, sampler_policy, δ_ds)`，`R_D` 为账本 Merkle 根。当 `Cov(D) ≥ Θ_cov ∧ Gap(D) = ∅` 且 `sampler_policy` 的偏差经重要性权重校正时，称 `DSC` 对目标域 `(A_core, 𝔇_ρ)` **sound**；`δ_ds` 为对未观测格的分布偏移上界。

**定义 125（惰性技能组合图）**
`G_S^lazy = (V′, E′, F, h_adm)`：`V′ ⊆ V` 为已展开节点，`E′` 为按需生成的边，`F` 为 frontier，`h_adm` 为可采纳下界。对任意访问节点 `n`，候选邻居由动作签名索引 `Idx_h(n.alpha)` 给出，边仅在通过 `compat(S_i,S_j) ≥ θ_a ∧ c_trans ≤ τ_e` 时实体化并附 `C_comp`。

**定义 126（动作签名与局部敏感哈希）**
动作签名 `h: A → {0,1}^b` 满足 `Pr[h(a)=h(a′)] = sim(a,a′)`。签名索引 `Idx_h` 以 `k` 张表支持近似最近邻；召回缺口 `β_lsh` 定义为真兼容邻居未被检索到的概率上界。

**定义 127（可扩展联合证书 SJ）**
`SJ = (ρ, A_cert, γ_ce, δ_a, R_D, Cov)`，其中 `ρ, A_cert, γ_ce, δ_a` 承接定义 120，`R_D, Cov` 来自 `DSC`。其序列化体积为 `O(|ρ| + |A_core| + log|D|)`，验证时只需根路径与覆盖摘要，不必传输原始数据集。

## 2. 关键算法 伪代码

### IP-121 LAP（Low-rank Action Profiling）

```python
def low_rank_action_profile(skills, A, r_max, eps_alpha, budget):
    # 1) D-最优锚点，保证基可辨识
    anchors = d_optimal_select(A, r_max, budget0)
    M = {(s, a): sampler.query(s, a) for s in skills for a in anchors}
    # 2) 交替最小二乘拟合共享动作基
    U, Phi = als_complete(M, rank=r_max)
    # 3) 主动补全：优先高不确定 / 高杠杆格
    while budget_left() and reconstruction_err(U, Phi, M) > eps_alpha:
        (s, a) = argmax_uncertainty(U, Phi, observed=M)
        M[s, a] = sampler.query(s, a)
        U, Phi = als_update(U, Phi, M)
    r_hat = effective_rank(U, Phi, eps_alpha)
    return lambda s, a: dot(U[s], Phi[a]), r_hat
```

### IP-122 CoDaC（Coverage-calibrated Dataset Construction）

```python
def construct_dataset(skills, grid, cov_target, n_min, eps_c):
    D = EvidenceLedger(grid)
    for g in stratified_seed(grid):          # 每层至少一个种子，防冷启动偏差
        D.add(g, collect(g, n=1))
    while D.coverage() < cov_target and not exhausted(grid):
        g = argmin_cell_score(D, grid, key=lambda x: (reliable(x), -risk(x)))
        D.add(g, collect(g, n=batch_size(g)))
        if D.starved(g):
            D.mark_starve(g)                 # 不可采集，记入 Starve 而非伪装覆盖
    return D, DatasetSufficiencyCert(
        R_D=D.merkle_root(),
        Cov=D.coverage(),
        Gap=D.gaps(),
        Starve=D.starved(),
        sampler_policy=D.policy,
        delta_ds=D.domain_shift_bound())
```

### IP-123 LSCG（Lazy Skill Composition Graph）

```python
def lazy_composition_search(start, goal, Idx_h, theta_a, tau_e, cert, k):
    open_ = heap(); push(open_, start, f=h_adm(start, goal))
    gbest, parent = {start: 0.0}, {}
    expanded = set()
    while open_:
        n = pop_min_f(open_)
        if n == goal:
            return reconstruct(parent, goal)
        if n in expanded:
            continue
        expanded.add(n)
        for m in Idx_h.query(n.alpha, topk=k):       # 只检索动作签名近邻
            if not (compatible(n, m, theta_a) and transition_cost(n, m) <= tau_e):
                continue
            w = cost_align(n, m)
            if gbest.get(m, inf) > gbest[n] + w:
                gbest[m] = gbest[n] + w
                parent[m] = n
                push(open_, m, f=gbest[m] + h_adm(m, goal))
    return None
```

### IP-124 EDA（Explanation-Driven Acquisition）

```python
def explanation_driven_acquisition(failure, explain, grid, D, delta):
    roots = explain.root_cause_actions()            # 失败根因动作格子集合
    Q = mixture(uniform_prior(grid),
                local_kernel(roots, bandwidth=delta))  # 根因邻域加密
    cells = sample_cells(Q, m=acquisition_batch)
    for g in cells:
        D.add(g, collect(g, n=1))
    D.reweight_importance(Q)                        # 偏差校正，保证 Cov 无偏
    return D, Q
```

### IP-125 SJ（Scalable Joint Certificate）

```python
def scalable_joint_certificate(skill_seq, gamma_ce, D, delta_a_budget, rho_min, Theta_cov):
    A_core = reduce(intersection, [s.alpha for s in skill_seq])
    delta_a = max_alignment_error(gamma_ce, A_core)
    if delta_a > delta_a_budget:
        return ('reject', 'action_mismatch', delta_a)
    cov = D.coverage_on(A_core, dims=rho_dims)
    if cov < Theta_cov or D.gaps_on(A_core, rho_dims):
        return ('reject', 'insufficient_evidence', cov, D.gaps_on(A_core, rho_dims))
    rho_comp = compose_robustness_chain([s.rho for s in skill_seq], K)
    if min(rho_comp.values()) < rho_min:
        return ('reject', 'robustness_fail', rho_comp)
    return ('ok', SJ(rho_comp, A_cert=(A_core, buffer_zone(A_core, delta_a)),
                     gamma_ce=gamma_ce, delta_a=delta_a,
                     R_D=D.merkle_root(), Cov=cov))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| LAP | `O(r(|S|+|A|) + T·r²)` | `O(r(|S|+|A|))` | 低秩近似误差 ≤ ε_α、主动采样无偏 |
| CoDaC | `O(|𝔾|·n_min + N_active·b)` | `O(N)` | 分层完备、覆盖度可由账本重算 |
| LSCG | `O(b·d·(log b + cost_compat))` vs 全图 `O(|S|²)` | `O(b·d)` | `h_adm` 可采纳、LSH 召回缺口 ≤ β_lsh |
| EDA | `O(m·|A|)` / 每次失败 | `O(m)` | 重要性权重校正、根因定位 sound |
| SJ | `O(|S|·|A_core| + log|D|)` | `O(|A_core| + log|D|)` | DSC sound、Merkle 根绑定证据 |
| FedDA | `O(|D_c| + |D_e|)` | `O(|D|)` | 云边分片按格对齐、根可对账 |

**正确性定理（Scalable Evidence-Certified Composition Soundness）**
承接第 54 轮 (A26)–(A28)，新增：**(A29)** 剖面低秩近似误差 `‖α̂-α‖_F ≤ ε_α`，且鲁棒性对剖面误差 `L_ρ`-Lipschitz；**(A30)** `DSC` 对 `(A_core, 𝔇_ρ)` sound（`Cov ≥ Θ_cov ∧ Gap = ∅`）；**(A31)** LSH 未检索到真兼容邻居的概率 ≤ `β_lsh`；**(A32)** `Q_exp` 经重要性权重校正。则
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a > Θ_a)
            - P(Cov < Θ_cov) - β_lsh - L_ρ·ε_α
```
即：**低秩误差、覆盖缺口、近邻漏召三者是新增的三类系统性失败源，且均可被证书显式计量**，而不是被数据量假象掩盖。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 低秩假设对异构技能失效 | 高 | 秩自适应 + 技能分簇低秩 + 残差兜底 |
| 覆盖度自指偏差（同一特征空间度量覆盖） | 高 | 独立留出层 + 红队格 + 置信下界 |
| LSH 漏召导致漏掉兼容路径 | 中 | 多表 + 精确回退 + `β_lsh` 计入证书 |
| 主动采样冷启动偏差 | 中 | 分层种子 + 风险加权 + 重要性校正 |
| Merkle 根与真实样本脱节 | 中 | 锚点抽检 + 可复现数据指纹 |

## 6. 本轮最大风险

**一句话**：本轮把证书的可扩展性押注在「低秩动作结构 + 覆盖契约」上，但覆盖度是在构建数据集的**同一特征空间**上度量的，一旦分层网格本身漏掉了真实的高风险动作格子，`DSC` 会以“高覆盖”的假象为空洞背书；故必须用 **独立留出层 + 红队格 + 置信下界** 三重外推校验，绝不让覆盖指标自己证明自己。

```python
def lazy_composition_search(start, goal, Idx_h, theta_a, tau_e, cert, k):
    open_ = heap(); push(open_, start, f=h_adm(start, goal))
    gbest, parent, expanded = {start: 0.0}, {}, set()
    while open_:
        n = pop_min_f(open_)
        if n == goal:
            return reconstruct(parent, goal)
        if n in expanded:
            continue
        expanded.add(n)
        for m in Idx_h.query(n.alpha, topk=k):
            if not (compatible(n, m, theta_a) and transition_cost(n, m) <= tau_e):
                continue
            w = cost_align(n, m)
            if gbest.get(m, inf) > gbest[n] + w:
                gbest[m] = gbest[n] + w
                parent[m] = n
                push(open_, m, f=gbest[m] + h_adm(m, goal))
    return None
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| LAP | `O(r(|S|+|A|) + T·r²)` | `O(r(|S|+|A|))` | 近似误差 ≤ ε_α、主动采样无偏 |
| CoDaC | `O(|𝔾|·n_min + N_active·b)` | `O(N)` | 分层完备、覆盖可由账本重算 |
| LSCG | `O(b·d·(log b + cost_compat))` | `O(b·d)` | `h_adm` 可采纳、`β_lsh` 计入 |
| EDA | `O(m·|A|)` / 每次失败 | `O(m)` | 根因 sound、重要性校正 |
| SJ | `O(|S|·|A_core| + log|D|)` | `O(|A_core| + log|D|)` | DSC sound、Merkle 绑定证据 |
| FedDA | `O(|D_c|+|D_e|)` | `O(|D|)` | 分片按格对齐、根可对账 |

**正确性定理（Scalable Evidence-Certified Composition Soundness）**
承接第 54 轮 (A26)–(A28)，新增：**(A29)** 低秩误差 `≤ ε_α` 且 `ρ` 对剖面 `L_ρ`-Lipschitz；**(A30)** `DSC` 对 `(A_core,𝔇_ρ)` sound；**(A31)** LSH 漏召概率 `≤ β_lsh`；**(A32)** `Q_exp` 经重要性校正。则
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a > Θ_a)
            - P(Cov < Θ_cov) - β_lsh - L_ρ·ε_α
```
关键：**低秩误差、覆盖缺口、近邻漏召** 是三类新的系统性失败源，且都能在证书中被显式计量，而不是被“数据量大”掩盖。

## 5. 本轮最大风险

**一句话**：本轮把证书的可扩展性押注在「低秩动作结构 + 覆盖契约」上，但覆盖度是在构建数据集的**同一特征空间**上度量的，一旦分层网格本身漏掉了真实的高风险动作格子，`DSC` 会以“高覆盖”的假象为空洞背书；故必须用 **独立留出层 + 红队格 + 置信下界** 三重外推校验，绝不让覆盖指标自己证明自己。
