# 第 71 轮（承接第 70 轮「CRAFT-RAS 用户共创×原型验证」IP-264~278；本轮灵感：「数据采集」×「抓取位姿估计」）

> R70 给闭环补上了社会认识论：谁共同署名、怎样验证才不是回声。但 R68–R70 一路默认了两件关于「底座」的事，且从未写进定义：
> 1. **动作/标签空间是一个忠实的坐标系**——不同的坐标就是不同的物理结果，于是不确定性、VoI、校准都可以直接在这个空间里算；
> 2. **数据是世界的静止随机样本**，怎么采、谁来采、采完之后世界是否还是它采时那样，都与「我要学什么、我要考什么」无关。
>
> **抓取位姿估计**击穿第 1 条：物体有旋转对称，抓取位姿 `g` 与 `g·h`（`h∈G_obj`）是**同一个物理抓取**；近似对称（把手、贴纸、磨损）更让最优抓取不是孤立点，而是一条低损失的**脊**。R69 的流匹配策略会在 SE(3) 上采样出多个「模态」，其中一部分只是同一抓取的对称像——模态熵与 VoI 被系统性抬高，系统会去追问一个「问也问不出区别」的伪问题，或沿着一条没有任务意义的规范方向做校准。这不是 aleatoric 噪声，也不是 epistemic 歧义，而是第三种东西：**规范自由度（gauge）**。
>
> **数据采集**击穿第 2 条：一次抓取成功不是 `(object, pose)` 的属性，而是 `(object, pose, gripper, controller, env, t)` 的属性；换了控制器/夹爪/桌面摩擦，旧标签就**过期**了。而采集本身就是一次被策略选择的干预：数据集分布是 `p(x|π_collect)`，不是世界的 `p_world`。若采集者同时是评测者，就得到 R70 回声的数据版——**模型测到的是自己旧控制器留下的脚印，却把它当作世界**。
>
> 核心命题：**先商掉规范自由度，再谈不确定性；数据不是世界的样本，而是采集策略的脚印。**
> 1. 在抓取位姿空间先**模掉对象对称群**，在商空间 `SE(3)/G` 上做三分解：`U_ale`（噪声）/ `U_epi`（可问的歧义）/ `U_gauge`（不可辨识、只需选一致截面的规范冗余）。商之前谈 ale/epi 是范畴错误。
> 2. 把「对称」当成一个**可验证的安全量**：只商已被 `ε`-对称证书验证的精确对称；近对称若被误商，任务相关差异就被当成冗余丢掉——这是能直接摔坏物体的错误。
> 3. 把数据集变成**带来源账本（provenance）的干预记录**：每个样本记录对象/场景/夹爪/控制器版本/环境/采集者/时间/同意/采集策略哈希；训练与评测在来源上不相交，标签有**半衰期**，过期即降权或重采。
> 4. 把主动采集变成**风险预算下的探索**：采集价值 = 商空间信息增益 + 覆盖增益，除以尾部物理风险（CVaR）+ 成本；且必须走认证兜底与安全探索，拒绝「越不确定越去试」的冒险病理。
> 5. 权威按数据资格发放：来源污染、标签过期、对称误设、或采集风险超预算，任何一项都**不得升级、并立即去商/停更**，退回 R70/R69 的保守。
>
> 命名 **GRASP-RAS**（Gauge-quotient, Risk-aware Active Sampling with Provenance for Risk-Aware Systems）——grasp 既是抓取，也是「抓住问题的正确坐标」。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「这回答是真相还是我教出的回声」，R71 问「**我是在哪个等价类里算这个答案的；我采的这批数据，是世界的样本，还是我自己挑出来、还带着旧控制器口音的样本**」。

## 0. 直觉与动机

**灵感 1（对称 → 先有规范，才有不确定性）**
直觉：一个无把手的杯子绕自身轴转 120°，物理抓取完全一样；模型却可能报出三个「不同」的抓取模态。R69 把模态熵 `H_mode` 当作可约歧义，于是算 VoI、设计提问、收紧风险——全都在一个**带冗余坐标的空间**里做，结论自然是错的。正确顺序是：先在 `SE(3)/G` 上聚类、算熵、算间距，再决定 ale/epi。**不确定性不是先有再分类，而是先要在一个没有冗余坐标的商空间里才有意义。**

**灵感 2（近似对称 → 是一条脊，不是一个点）**
直觉：真实物体只是近似对称。沿对称方向微调抓取，成功率几乎不变——这是一条低损失脊。沿脊方向 Fisher 信息退化：参数不可辨识。R68 的 `λ_floor` 会把这种不可辨识当成 aleatoric 噪声去收紧（过度保守）；R69 的 VoI 会把它当成 epistemic 去追问（问了也没用，因为真值本身就不是单点）。第三类必须单列：**`U_gauge` 既不收紧、也不追问，而是选一个光滑一致的截面（canonical section）**。

**灵感 3（数据采集 → 数据集是干预的产物）**
直觉：抓取数据集不是从世界均匀抽样来的；它来自遥操作、主动试抓、失败重试、某台夹爪恰好能抓的物体——一个**采集策略**。于是训练分布 `p(x|π_collect)` 与部署分布 `p_deploy` 不是一回事。R70 已知道「验证是干预」，但没往下问：**训练数据本身也是干预的产物**。采集策略是系统的一部分，必须进证书，也就可以被优化——也就可以被 Goodhart。

**灵感 4（标签不是对象属性 → 标签有半衰期）**
直觉：一次抓取成功属于 `(object, pose, gripper, controller, env, t)`，不属于 `(object, pose)`。换控制器、换夹爪、换桌面，旧标签就过期。R68 只担心在线标定漂移，没有担心**离线标签漂移**。定义「标签半衰期」：标签可信度随版本漂移指数衰减；拿过期标签训练，等于用旧世界的口音校准新世界。这是 R70「回声」的数据版。

**灵感 5（主动采集 = 风险寻求 → 好奇心要预算）**
直觉：R69 的 VoI 去「问」，成本是社交；抓取的主动采集去「试抓」，成本是**物理风险**（掉落、碰撞、挤压）。更糟的是，按不确定性驱动的采集天然冲向最不确定、最 OOD 的区域——正是最危险的地方。于是「越学越安全」的叙事可能是「越学越敢在危险区试」。数据采集必须带 **CVaR 尾部风险预算** 与认证兜底：好奇心需要预算，否则主动学习就是主动冒险。

**灵感 6（数据来源 → 数据级的回声与污染）**
直觉：R70 的 cohort 污染在数据层更严重：采集与评测共用对象/场景/采集员/控制器版本，评测就会「记住」训练集。更隐蔽的是**来源伪造**：投毒样本伪造 provenance，或故意在窄对象集上刷量，让数据集「看起来」大而多样。需要来源账本、来源不相交划分、以及把采集策略哈希写进证书。

**灵感 7（对 R70/R69 的姿态 → 平凡规范 + 静止数据是边界情形）**
直觉：`G` 平凡（无对称）、标签半衰期 `∞`（控制器/环境静止）、`π_collect = π_deploy`、provenance 完整可信时，商空间等于原空间、`U_gauge = 0`、主动采集退化为普通留出采样、商一致评测退化为 R70 的普通验证；主闭环逐指令等于 CRAFT/FLUID。**新层必须是旧层在「无规范自由度、数据静止且来源可信」边界上的严格退化**，这样加层不是多一个黑箱，而是把旧层没写出的底座前提显式化。

## 1. 形式化定义（增量：定义 328–346）

**定义 328（GRASP-RAS 总览与五不变式）** `GRASP-RAS = (GQA, TUD, EQC, QVOI, PDL, LHL, RAC, SXC, DPG, QCE, DPL, VQAuditor-D, RAS-WM¶)`。五条不变式：
(i) **实时流零学习写操作**（继承 R70 定义 310-i；对称估计、数据重加权、采集全部在慢时间尺度）；
(ii) **规范纪律**：只对**已验证的精确对称** `G_verified` 做商；近对称 `ε` 不得被商掉（否则把任务相关差异当冗余丢掉）；
(iii) **数据来源纪律**：每个训练/验证样本携带 provenance；训练与评测在 object/scene/collector/controller-version 上来源不相交或显式分层声明；缺失 provenance 的样本不得进入认证集；
(iv) **采集风险预算**：数据采集的尾部风险 `CVaR_β ≤ R_data`，且每个试抓经 C-RAS-WM 认证；
(v) **标签时效**：使用超过半衰期的标签必须降权或重采，禁止把过期标签当作现状。

**定义 329（抓取位姿空间与对称商）** 抓取配置 `g ∈ SE(3)`（或任务定义的抓取流形 `𝒢_raw`）；对象对称群 `G_obj ≤ SE(3)`（离散旋转群、连续轴对称、或近似）。物理等价 `g ~ g·h, h∈G_obj`。商空间 `𝒢 = 𝒢_raw / G_obj`。抓取成功谓词须满足 `S(g) = S(g·h)`（精确对称）；不满足则对称不成立，不得商。

**定义 330（规范截面与商距离）** 取光滑截面 `σ: 𝒢 → 𝒢_raw`（每个等价类选一个代表，如最小角代表；在轨道稳定子处有奇点，须显式处理）。商距离
`d_𝒢([g],[g']) = min_{h∈G_obj} d_SE3(g, g'·h)`。
模态聚类、间距 `Δ_min`、误差度量、VoI 全部改在 `(𝒢, d_𝒢)` 上计算。

**定义 331（三分解 TUD）** 后验在商空间与纤维上的正交分解
`H(g) = H([g]) + E_{[g]}[H(g | [g])] + H_noise`，
其中 `H([g])` → `U_epi`（不同的抓取类，可问），`E[H(g|[g])]` → `U_gauge`（同一类内的规范冗余 / 近对称脊，不可问），`H_noise` → `U_ale`（不可约噪声）。可用对称生成元/任务雅可比估计：沿近零特征值方向与轨道切空间的方差为 `U_gauge`，任务相关谱为 `U_task`。
**处置律**：`U_ale → λ_floor`；`U_epi → QVOI 交互`；`U_gauge → canonicalization`（选截面），**既不进 λ_floor，也不进 VoI**。

**定义 332（ε-对称证书 EQC）** 称 `G` 在容差 `ε_s` 下可商，若存在验证集使
`sup_{g, h∈G} |S(g) − S(g·h)| ≤ ε_s`，且成功率随 `d_𝒢` 单调、轨道内失败率方差不超阈值。只对通过证书的**离散精确对称**做商。近似/连续对称：不商，或只商到 `ε_s` 并附加安全裕度；若 `L_s·ε_s > ε_task`，保留为 `U_epi` 并收紧。证书失败 ⇒ 禁用商，退回原始 SE(3)（此时保守）。

**定义 333（商 VoI QVOI）** 信息动作 `g` 的信息增益只在商空间的类上计算：
`QVOI(g) = H([M]|o) − E_{y~p̃}[H([M]|o,y)] − c(g) − η·b(g) − γ·D(g)`。
规范方向 `U_gauge` 不参与 VoI：它用 `canonicalize(·)` 消解而不是提问。若 `max QVOI ≤ 0` 或 EQC 失败 ⇒ 不交互，退 R70/R69 兜底。`G` 平凡且截面唯一时 `QVOI = VoI`。

**定义 334（来源数据账本 PDL）** 每个样本 `x = (o, g, y, prov)`，
`prov = (object_id, scene_id, gripper_id, controller_version, env_params, collector_id, consent, t, policy_hash)`。
只追加、可重放、可哈希；训练/评测集必须给出 provenance 划分；无 provenance 或同意状态不明者不得进入认证训练集。

**定义 335（标签模型与半衰期 LHL）** 抓取成功 `y ~ Ber(p_s(g; c, e, ζ))`，`c` 控制器版本、`e` 环境、`ζ` 未观测混杂。随版本漂移，旧标签对当前 `p_s` 的偏差随 `Δt` 增长。标签半衰期 `T½ = ln2/κ`（`κ` 为漂移率），有效样本权重 `w(x) = exp(−κ·age(x))`；过期的成功标签不得当作当前成功。

**定义 336（陈旧标签偏差）** 用 `age > t` 的标签估计成功率 `p̂_old` 相对真值 `p_now`：
`|p̂_old − p_now| ≤ L_p·E[drift] + √(σ² / n_eff)`，`n_eff = Σ_x w(x)`。
故保持偏差 ≤ `ε` 需 `n_eff ≥ σ²/ε²` 且重采周期 ≤ `T½`。**数据采集频率由标签半衰期决定，而不是由算力/预算决定。**

**定义 337（风险感知主动采集 RAC）** 候选采集试抓 `A_coll`（对象 × 位姿 × 场景 × 夹爪）。采集价值
`CV(g) = [IG_𝒢(g) + λ_cov·Coverage_𝒢(g)] / [CVaR_β(Risk(g)) + c(g)]`，
选 `g* ∈ argmax CV`，s.t. `CVaR_β(Risk) ≤ R_data`、采集预算与认证。与 VoI 不同：分母是**尾部物理风险**而非社交成本；且禁止把「不确定性最大」当作唯一采集目标（风险寻求病理）。

**定义 338（安全探索 SXC）** 每个采集试抓必须可从任意失败恢复（软表面/低高度/网兜）、有认证兜底、可交接、有硬力/位包络。若 `Risk(g) > R_safe`，改用仿真/仿真到现实校准或放弃。禁止在无人监督下采集高风险 OOD。

**定义 339（来源不相交验证 DPG）** 训练/认证评测在对象实例、场景、采集员、控制器版本上不相交（或显式分层）；`contamination = max_overlap(train, eval)`；`contamination > τ_c ⇒ 评测无效`。跨对象泛化须报告 object-disjoint 指标。

**定义 340（商一致评测 QCE）** 用 `d_𝒢` 而非原始 SE(3) 度量抓取误差；成功率以「成功率–位姿容差曲线」在给定容差下报告；近边界样本单列（boundary-conditioned）；按 provenance 分层报告。禁止单一平均成功率。

**定义 341（采集诱导漂移指数 CSI）** `CSI = dist(p(x|π_collect), p_deploy)`（MMD 或对抗判别器 AUC）。证书必须报告；`CSI` 高则采集策略须改变，或部署分布须显式声明。

**定义 342（数据威胁模型 DPL）** `ℰ_data`：provenance 伪造、窄对象集刷量、过期标签复用、控制器特化样本、边界标签噪声注入、采集策略 Goodhart、评测泄漏。并入 `ℰ_GRASP = ℰ_CRAFT × ℰ_data`。

**定义 343（数据审计 VQAuditor-D）** 审计每条样本的 provenance 完整性、标签年龄、划分重叠、采集风险花费，以及商决策是否错误地商掉了近对称。违规样本隔离，结论回灌 AuditBuf，影响下一轮 RAC 成本与 DPG 阈值。

**定义 344（证书 J_GRASP）**
`J_GRASP = (J_CRAFT, gauge_cert_hash, quotient_dim, U_gauge_p95, provenance_root_hash, contamination, n_eff/T½, cvar_risk_spend, collect_policy_hash, csi, qce_version, grasp_ver)`。
`Valid ⇔ Valid(J_CRAFT) ∧ EQC 通过 ∧ 划分无污染 ∧ n_eff 足够 ∧ 风险花费 ≤ R_data ∧ CSI 已报告`。

**定义 345（严格包含与两级退避）** 若 `G` 平凡、`ε_s = 0`、`T½ = ∞`、provenance 完整且 `π_collect = π_deploy`，则 `U_gauge = 0`、`QVOI = VoI`、RAC = 普通采样、QCE = 普通评测、主闭环逐指令 = R70。任一 EQC/来源/时效/风险失败 ⇒ 回到未商空间的最保守 `λ_floor(U_ale + U_epi + U_gauge)`（此时近对称被视为真实歧义），停止数据更新与权威升级。安全侧永不弱于 R70。

**定义 346（对称误设监测 SMR）** 在线检测假设的 `G` 是否仍成立：监测沿轨道方向的任务损失曲率、物体形变/遮挡、夹爪不对称、以及轨道内失败率方差。若 `Var_orbit(failure) > τ_sym` 或曲率出现正谱，判定对称误设 ⇒ 立即**去商（de-quotient）**、`U_gauge → U_epi`、收紧 `λ`。这是 EQC 的在线对偶。

## 2. 关键算法骨架

```python
# IP-279/280 GQA + TUD：先在商空间上分解，再谈不确定性
def gauge_quotient_decompose(samples, obj, task_jac):
    G = obj.verified_symmetry_group()            # 只取 EQC 通过的精确对称
    classes = cluster_on_quotient(samples, G)    # 在 SE(3)/G 上聚类（DTW/Fréchet）
    U_epi   = mode_entropy(classes) * separability(classes, metric=quotient_dist)
    # 沿对称生成元/任务雅可比零空间的方差 = gauge；其余 = 任务相关
    U_gauge = project_onto_null(task_jac, G, samples)
    U_ale   = total_var(samples) - U_gauge
    reps    = canonicalize(samples, G)           # 每类选光滑截面代表，非提问
    return U_ale, U_epi, U_gauge, reps

# IP-281 EQC：epsilon-对称是一个可验证的安全量
def epsilon_symmetry_cert(obj, G, eval_set, eps_s):
    diffs = [abs(S(g) - S(g @ h)) for g, h in orbit_pairs(eval_set, G)]
    orbit_var = failure_rate_variance_within_orbits(eval_set, G)
    ok = max(diffs) <= eps_s and orbit_var <= TAU_SYM and monotone_under_dG(eval_set, G)
    return ok, max(diffs), orbit_var            # 失败 ⇒ 禁止商，退回原始 SE(3)

# IP-283/284 PDL + LHL：来源账本与标签半衰期
def effective_weight(sample, now, kappa):
    if not sample.prov.valid or not sample.prov.consent:
        return 0.0
    return exp(-kappa * (now - sample.prov.t)) # 过期标签降权，不当作现状

# IP-285/286 RAC + SXC：风险预算下的主动采集（不是纯不确定性）
def choose_collection_trial(candidates, data_budget, cvar_budget):
    best = None
    for g in candidates:
        if not sxc.recoverable(g):        continue   # 安全探索：失败可恢复
        if not c_ras_wm.certify_trial(g): continue   # 认证兜底
        tail = cvar_tail_risk(g)                     # CVaR_beta(Risk)
        if tail > cvar_budget:            continue   # 尾部风险预算
        cv = (info_gain_on_quotient(g) + LAMBDA_COV * coverage_gain(g)) \
             / (tail + cost(g))
        if best is None or cv > best.cv: best = (g, cv)
    return best                                      # 无利可图 / 全超预算 ⇒ 不采

# IP-287/288 DPG + QCE：来源不相交划分 + 商一致评测
def provenance_split(dataset, keys=('object','scene','collector','controller')):
    return disjoint_or_stratified_split(dataset, keys)

def quotient_aware_eval(policy, testset, G):
    err   = mean(min_over_orbit(policy(o), g, G) for o, g in testset)  # d_G
    curve = success_vs_pose_tolerance(policy, testset)                # 边界条件化
    return err, curve, stratify_by_provenance(curve)

# IP-293 主闭环：R70 外套「商 + 数据环」
def GRASP_RAS_round(M, obs, dataset):
    # 0) 商与三分解（在 R70 实时路径之前插一层）
    U_ale, U_epi, U_gauge, reps = M.gqa.decompose(obs, M.obj, M.task_jac)
    if not M.eqc.valid:                       # 对称不可信 → 去商，gauge 升为 epi
        U_epi += U_gauge; U_gauge = 0.0
    # 1) R70 实时路径：QVOI 只对商类、只对 U_epi；gauge 用截面消解
    k, lam, mode, (U_ale2, U_epi2) = M.craft.step(obs, reps)
    U_floor = U_ale + (U_epi2 if not M.resolved else 0.0)
    lam = max(lam, lam_floor(U_floor))
    if not M.eqc.valid or M.smr.detects_misspec():   # 去商 / 立即收紧
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(mode))
    # 2) 数据环（异步）：采集 → 标注 → 时效 → 审计
    if M.collect_tick.due():
        g = M.rac.choose(M.candidates, M.data_budget, M.cvar_budget)
        if g is not None:
            M.pdl.append(M.sxc.execute_with_provenance(g))
    if M.data_tick.due():
        M.lhl.reweight(dataset, M.clock)          # 半衰期重加权
        ok = M.dpg.check(dataset)                 # 来源不相交
        M.vqa_d.audit(dataset)                    # 账本/年龄/商决策
        if not ok: M.j_grasp.invalidate()
    M.j_grasp.emit(M.eqc, M.pdl.root(), M.dpg, M.lhl, M.rac, M.csi)
    return k, lam, mode, (U_ale, U_epi, U_gauge)
```

## 3. 推导

**引理 22（规范冗余导致的不确定性虚高）** 设后验在每条对称轨道上有 `|G_eff|` 个等质量模态。原始位姿空间上
`H_raw = H_𝒢 + log|G_eff|`（精确对称），故 `U_epi_raw = U_epi_𝒢 + log|G_eff|`，R69 的互信息与 VoI 至少被高估 `log|G_eff|` 项。商后该冗余项消失。系：**对称性越强，R69 的「越问越确定」越是在问一个伪问题**——先商，再问。

**引理 23（陈旧标签偏差与半衰期）** 在漂移率 `κ` 下，使用全部历史标签的成功率偏差随 `1 − e^{−κΔt}` 增长；保持 ≤ `ε` 需重采周期 ≤ `T½ = ln2/κ` 且 `n_eff ≥ σ²/ε²`。系：**数据采集频率必须由标签半衰期决定**；否则模型在旧世界的分布上被校准，却在新世界里被抓取。

**引理 24（不确定性驱动的风险集中）** 若采集目标只是最大化 `H`（纯不确定性），采集分布单调向 OOD/高风险区漂移，`E[Risk]` 与 `CVaR_β` 随轮数上升，无预算时上界为 ∞。加入 `CVaR_β ≤ R_data` 后尾部风险被约束，采集价值必须同时含 coverage 项，否则会永远在同一个危险空洞里打转。系：**好奇心需要风险预算，否则主动学习就是主动冒险**。

**定理 20（GRASP 严格包含 R70）** 在 A99（`G` 平凡或已验证、`ε_s = 0`、`T½ = ∞`、provenance 完整、`π_collect = π_deploy`）下，`U_gauge = 0`、`QVOI = VoI`、RAC = 普通采样、QCE = 普通评测，主闭环逐指令等于 R70；任一 EQC/来源/时效/风险失败则退回未商空间的最保守 `λ_floor` 并停更。R70 是「无规范自由度、数据静止且来源可信」边界上的退化：安全不让步，效率才获得 resolution bonus。

**定理 21（商的安全性条件）** 对**精确已验证**对称 `G`，商保持任务成功率（因 `S(g) = S(g·h)`）；对 `ε`-近似对称，商掉后执行成功率相对原始最多变化 `≤ L_s·ε_s`。因此只在 `L_s·ε_s ≤ ε_task` 时允许商，否则保留为 `U_epi` 并收紧。系：**商的合法性是一个可测量的安全量，不是建模者的信仰**。

**定理 22（风险预算下采集的可行性）** 在 `CVaR_β(Risk) ≤ R_data` 与认证兜底（定义 338）下，任何采集序列的期望尾部损失 ≤ `R_data / (1−β)` 量级，且不影响已认证安全包络；采集只改变「学什么」，不改变「能冒多大险」。系：**数据可以买来安全，但不能用突破安全包络的方式买**。

## 6. 本轮最大风险

**一句话**：GRASP-RAS 的全部效率收益押在「对称性被正确识别、标签时效被正确估计」这两个前提上——**若对称是近似的（一根把手、一次形变、一个不对称夹爪），被商掉的正是任务相关的 `ε`，系统会自信地执行一个它认为等价、实际会掉件的抓取；若 provenance 可伪造或控制器漂移未被建模，来源不相交只是标签，过期标签会冒充现状，模型就在自己旧控制器留下的脚印上测出「世界」**。前者把冗余当差异的反面——把差异当冗余——直接摔东西；后者把回声当真相——与 R70 同病，但更深一层。

**次级风险与缓解**：
1. **对称误设** → EQC 只商已验证精确对称 + SMR 在线去商 + `L_s·ε_s ≤ ε_task`（定理 21）；
2. **标签过期/控制器漂移** → LHL 半衰期重加权 + 重采触发 + `n_eff` 门槛（引理 23）；
3. **采集风险集中** → CVaR 预算 + 覆盖项 + 安全探索兜底（引理 24、定理 22）；
4. **数据污染/来源伪造** → PDL 账本 + DPG 来源不相交 + VQAuditor-D（定义 334/339/343）；
5. **评测泄漏与 Goodhart** → QCE 商一致 + 分层报告 + CSI + 采集策略哈希进证书；
6. **商空间奇点/截面不连续** → 稳定子处显式跳变处理 + 监控截面切换引发的控制不连续。

## 2. 形式化定义（要点版）

**定义 328（总览与五不变式）** `GRASP-RAS` 组件如上；五不变式：零学习写实时流继承；**规范纪律**（只商已验证精确对称）；**数据来源纪律**（provenance 与来源不相交）；**采集风险预算**（`CVaR_β ≤ R_data` + 认证）；**标签时效**（过期降权/重采）。

**定义 329–330（商与截面）** `g ~ g·h, h∈G_obj`；`𝒢=𝒢_raw/G_obj`；`d_𝒢([g],[g'])=min_h d_SE3(g,g'h)`；`σ` 在稳定子处有奇点须显式处理。聚类/熵/间距/误差/VoI 全部改用 `d_𝒢`。

**定义 331（三分解 TUD）** `H(g)=H([g])+E[H(g|[g])]+H_noise`；`U_epi` 来自类间、`U_gauge` 来自纤维/近对称脊、`U_ale` 来自噪声。处置律：`U_ale→λ_floor`、`U_epi→QVOI`、`U_gauge→canonicalization`（既不收紧也不追问）。

**定义 332（EQC）** 可商需 `sup_{g,h}|S(g)−S(g·h)| ≤ ε_s`、轨道内失败率方差不超阈、`d_𝒢` 单调；且 `L_s·ε_s ≤ ε_task`。证书失败 ⇒ 禁用商，退回原始 SE(3) 并保守。

**定义 333（QVOI）** `QVOI(g)=H([M]|o)−E_{p̃}H([M]|o,y)−c−ηb−γD`；规范方向不参与信息增益；无利可图/EQC 失败则退 R70/R69；`G` 平凡时等于 VoI。

**定义 334（PDL）** 样本 `(o,g,y,prov)` 只追加、可哈希、可重放；无 provenance/同意不明不得进认证集。

**定义 335–336（LHL 与陈旧偏差）** `y~Ber(p_s(g;c,e,ζ))`；`T½=ln2/κ`，`w=e^{−κ·age}`；`|p̂_old−p_now| ≤ L_p E[drift]+√(σ²/n_eff)`；保持偏差 ≤ ε 需重采周期 ≤ T½ 且 `n_eff ≥ σ²/ε²`。

**定义 337–338（RAC 与 SXC）** `CV=[IG_𝒢+λ_cov·Coverage]/[CVaR_β(Risk)+c]`，s.t. `CVaR≤R_data`、预算、认证；禁止纯不确定性采集；试抓须可恢复、认证兜底、硬包络、可交接，高风险转仿真。

**定义 339–341（DPG/QCE/CSI）** 来源（对象/场景/采集员/控制器版本）不相交或分层，`contamination>τ_c` 评测无效；商距离 + 成功率–容差曲线 + 边界条件化 + provenance 分层；`CSI` 衡量采集与部署分布差并进证书。

**定义 342–344（威胁/审计/证书）** `ℰ_data`：来源伪造、窄集刷量、过期复用、控制器特化、边界噪声注入、采集 Goodhart、评测泄漏；`ℰ_GRASP=ℰ_CRAFT×ℰ_data`。VQAuditor-D 审 provenance/年龄/重叠/风险花费/商决策。`J_GRASP` 并入 gauge 证书、商维度、`U_gauge` 分位、来源根哈希、污染、`n_eff/T½`、CVaR、CSI。

**定义 345–346（严格包含与在线去商）** `G` 平凡、`ε_s=0`、`T½=∞`、来源完整、`π_collect=π_deploy` ⇒ 主闭环逐指令 = R70；任一失败 ⇒ 未商空间最保守并停更。SMR 监测轨道内失败率方差/曲率，检出对称误设即去商、`U_gauge→U_epi`、收紧。

## 3. 关键算法伪代码

```python
# IP-279/280 GQA + TUD：先在商空间上分解
def gauge_quotient_decompose(samples, obj, task_jac):
    G = obj.verified_symmetry_group()
    classes = cluster_on_quotient(samples, G)
    U_epi   = mode_entropy(classes) * separability(classes, quotient_dist)
    U_gauge = project_onto_null(task_jac, G, samples)   # 对称/近零方向
    U_ale   = total_var(samples) - U_gauge
    return U_ale, U_epi, U_gauge, canonicalize(samples, G)

# IP-281 EQC：epsilon-对称是一个可验证的安全量
def epsilon_symmetry_cert(obj, G, eval_set, eps_s):
    diffs = [abs(S(g) - S(g @ h)) for g, h in orbit_pairs(eval_set, G)]
    ok = max(diffs) <= eps_s and failure_var(eval_set, G) <= TAU_SYM
    return ok, max(diffs)          # 失败 ⇒ 禁止商，退回原始 SE(3)

# IP-283/284 PDL + LHL：来源账本与半衰期
def effective_weight(sample, now, kappa):
    if not sample.prov.valid or not sample.prov.consent: return 0.0
    return exp(-kappa * (now - sample.prov.t))

# IP-285/286 RAC + SXC：风险预算下的主动采集
def choose_collection_trial(candidates, cvar_budget):
    best = None
    for g in candidates:
        if not sxc.recoverable(g) or not c_ras_wm.certify_trial(g): continue
        tail = cvar_tail_risk(g)
        if tail > cvar_budget: continue
        cv = (info_gain_on_quotient(g) + LAMBDA_COV * coverage_gain(g)) \
             / (tail + cost(g))
        if best is None or cv > best.cv: best = (g, cv)
    return best

# IP-287/288 DPG + QCE
def provenance_split(dataset, keys=('object','scene','collector','controller')):
    return disjoint_or_stratified_split(dataset, keys)

def quotient_aware_eval(policy, testset, G):
    err   = mean(min_over_orbit(policy(o), g, G) for o, g in testset)
    curve = success_vs_pose_tolerance(policy, testset)
    return err, curve, stratify_by_provenance(curve)

# IP-293 主闭环：R70 外套「商 + 数据环」
def GRASP_RAS_round(M, obs, dataset):
    U_ale, U_epi, U_gauge, reps = M.gqa.decompose(obs, M.obj, M.task_jac)
    if not M.eqc.valid:                          # 去商：gauge 升为 epi
        U_epi += U_gauge; U_gauge = 0.0
    k, lam, mode, (U_ale2, U_epi2) = M.craft.step(obs, reps)
    lam = max(lam, lam_floor(U_ale + (U_epi2 if not M.resolved else 0.0)))
    if not M.eqc.valid or M.smr.detects_misspec():
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(mode))
    if M.collect_tick.due():
        g = M.rac.choose(M.candidates, M.cvar_budget)
        if g is not None: M.pdl.append(M.sxc.execute_with_provenance(g))
    if M.data_tick.due():
        M.lhl.reweight(dataset, M.clock)
        ok = M.dpg.check(dataset); M.vqa_d.audit(dataset)
        if not ok: M.j_grasp.invalidate()
    M.j_grasp.emit(M.eqc, M.pdl.root(), M.dpg, M.lhl, M.rac, M.csi)
    return k, lam, mode, (U_ale, U_epi, U_gauge)
```

## 4. 推导

**引理 22（规范冗余导致不确定性虚高）** 每条对称轨道有 `|G_eff|` 个等质量模态时，原始位姿空间 `H_raw=H_𝒢+log|G_eff|`，故 `U_epi` 与 VoI 至少被高估 `log|G_eff|`；商后消除。**系**：对称越强，R69「越问越确定」越是在问伪问题——先商再问。

**引理 23（陈旧标签偏差与半衰期）** 漂移率 `κ` 下，历史标签偏差随 `1−e^{−κΔt}` 增长；保持 ≤ ε 需重采 ≤ `T½=ln2/κ` 且 `n_eff ≥ σ²/ε²`。**系**：采集频率由标签半衰期决定，而非算力/预算。

**引理 24（不确定性驱动的风险集中）** 纯 `H` 驱动的采集向 OOD/高风险漂移，`E[Risk]`、`CVaR_β` 单调上升，无预算上界为 ∞；加入 `CVaR_β ≤ R_data` 后尾部受限，价值须含 coverage。**系**：好奇心需要风险预算。

**定理 20（GRASP 严格包含 R70）** `G` 平凡或已验证、`ε_s=0`、`T½=∞`、provenance 完整、`π_collect=π_deploy` 时，`U_gauge=0`、`QVOI=VoI`、RAC=普通采样、QCE=普通评测，主闭环逐指令 = R70；任一失败则回未商空间最保守并停更。**安全不让步，效率获红利。**

**定理 21（商的安全性条件）** 精确已验证对称下商保持成功率；`ε`-近似对称下商掉后成功率变化 `≤ L_s·ε_s`；故仅当 `L_s·ε_s ≤ ε_task` 允许商。**系**：商的合法性是安全量，不是信仰。

**定理 22（风险预算采集可行性）** `CVaR_β(Risk) ≤ R_data` + 认证兜底 ⇒ 采集序列期望尾部损失 ≤ `R_data/(1−β)` 量级，且不改变认证安全包络。**系**：数据可以买安全，但不能用突破安全包络的方式买。

## 7. 本轮最大风险

**一句话**：GRASP-RAS 的全部效率收益押在「对称性被正确识别、标签时效被正确估计」这两个前提上——**若对称是近似的（一根把手、一次形变、一个不对称夹爪），被商掉的正是任务相关的 `ε`，系统会自信地执行一个它认为等价、实际会掉件的抓取；若 provenance 可伪造或控制器漂移未被建模，来源不相交只是标签，过期标签会冒充现状，模型就在自己旧控制器留下的脚印上测出「世界」**。前者把差异当冗余，直接摔东西；后者把回声当真相，比 R70 更深一层。

**次级风险与缓解**：对称误设（EQC 只商已验证精确对称 + SMR 在线去商 + `L_s·ε_s` 检查）；标签过期/控制器漂移（LHL 重加权 + 重采触发 + `n_eff` 门槛）；采集风险集中（CVaR 预算 + 覆盖项 + 安全探索兜底）；数据污染/来源伪造（PDL + DPG + VQAuditor-D）；评测泄漏与 Goodhart（QCE 商一致 + 分层 + CSI + 采集策略哈希入证书）；商空间奇点/截面不连续（稳定子显式跳变 + 截面切换监控）。
