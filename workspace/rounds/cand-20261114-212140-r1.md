# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「技能学习」×「任务规划」）

> R69 教会系统「问」，但它仍是一个**单技能、短视界**的反应式闭环：所有不确定性都被压在「这一块动作怎么选」上，它从未认真问过三件更靠上的事——**我该做哪件事**（任务分解）、**这套技能顺序接得上吗**（前后条件）、**我真的会做这个技能吗**（能力边界）。于是 R69 的「问」只能消解动作模态的歧义，消解不了「计划本身是错的」「技能在分布外根本不可靠」「我在用一个自己都不会的技能」。
>
> 本轮两个灵感正好补上这两层：
> - **技能学习**告诉我们，学到的技能不是一个确定性函数，而是一份**带前置/后置条件、能力包络、恢复条款和风险上界的合同**；能力是上下文相关的，必须被校准、被版本化、被审计。
> - **任务规划**告诉我们，计划不是符号序列，而是**合同的概率化复合**：每条后置条件要蕴含下一条前置条件；每一步都有失败风险；长时程会累积「风险蠕变」；规划器可能幻觉出自己并不具备的能力。
>
> 核心命题：**把「技能」升级为合同、把「规划」升级为风险预算下的合同复合、把「学习」升级为归因门控的合同重谈；三分不确定性——执行不确定性（R69）、计划不确定性（选哪条计划）、能力不确定性（我能不能做到）——各自进入不同的修复通道：消歧 / 重规划 / 试做 / 分解 / 求助 / 弃权。** 命名 **CRAFT-RAS**（Contract-governed, Risk-budgeted, Attribution-gated Flow for Tasks and skills）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我到底会做什么、下一步该做什么、我凭什么相信这两件事**」——不确定性不只是刹车或提问，也可以是一份可审计的技能合同和一份有预算的任务计划。

## 0. 直觉与动机

**灵感 1（技能学习 → 技能是合同，不是函数）**
直觉：一个学到的技能从来不是「输入状态、输出动作」的纯函数。它是一份**有条件的承诺**：在什么前置条件下我承诺达到什么后置条件，我在什么上下文里可靠，失败时我能退回到哪里，这次承诺最多承担多大风险。把技能当函数，就会在分布外自信地执行；把技能当合同，才会在签合同之前先检查条款是否成立。R69 的流匹配策略只是合同里的「执行条款」，不是合同本身。

**灵感 2（任务规划 → 计划是风险的复合，不是符号的拼接）**
直觉：经典任务规划假设动作是确定的：前置满足就一定能达到后置。真实技能是随机的、上下文相关的、会失败的。于是计划的正确性问题从「符号是否可满足」变成「**合同链是否概率可复合**」：后置条件必须以足够概率蕴含下一条前置条件；整条计划的失败风险是各段风险与守护条件的复合；长时程会把「每步 2%」累积成「整晚 40%」。规划器不能只看可达性，必须看**风险预算**。

**灵感 3（三本账 → 执行、计划、能力必须分开记账）**
直觉：R69 把一个标量不确定性拆成 aleatoric/epistemic，但两者都还是「执行层」的。长时程任务至少有三本账：
- **执行账**（R69）：这一块动作是噪声还是歧义？→ 交互消歧 / 收紧；
- **计划账**：选哪条计划？计划 A 与 B 的差别是否真的改变动作？→ 问清目标 / 重规划 / 弃权；
- **能力账**：我能不能可靠完成这个技能？→ 试做 / 分解 / 求助 / 换技能。
三本账的**修复动作不同**。把它们混成一个 U，就会用「多问一句」去解决「根本不会」，或用「再练一练」去解决「目标没听清」。

**灵感 4（试做是带真实风险的信息动作）**
直觉：R69 的信息动作是看、问、触，它们主要消耗时间/社交成本，不改变任务状态。但技能学习里最有力的信息动作是**试做**：先做一小步，看技能是否进入预期吸引域。试做与提问的本质区别是——**它会改变世界，而且可能失败**。所以试做不能免费：必须有可逆包络、逃逸策略、风险上界，并从「风险电池」里扣费。没有可逆性的试做不是信息，是赌博。

**灵感 5（归因先于学习 → 别让计划的错污染技能）**
直觉：技能学习最隐蔽的错误不是「学不会」，而是「学错了」：计划的前置条件没满足，技能失败，系统却把这次失败记到技能头上，于是技能被训练得越来越保守；或者计划侥幸成功，系统把功劳记给技能，于是技能被过度泛化。**失败必须先在「计划 / 技能 / 世界 / 规格」之间归因，才允许更新技能。** 这是技能学习与任务规划之间最重要的接口，也是本轮的核心安全机制。

**灵感 6（选择偏差 → 规划器与能力模型会互相确认）**
直觉：如果规划器只提议「能力模型认为可行」的技能，而能力模型又只用规划器选中的样本来更新，就形成闭环：**只做自认为会的，永远不学不会的；能力模型在规划器偏爱的区域越来越自信，在从未被选中的区域保持无知甚至幻觉。** 这不是普通的概念漂移，而是**正反馈式的选择偏差**（positivity violation）。破解它需要两件事：显式的探索下限（独立于规划器抽样审计）和带倾向权重的离策略评估（IPW/DR）。否则「风险预算」只是在错误的能力信念上做精致算术。

**灵感 7（技能库是依赖图，不是文件夹）**
直觉：更新一个技能，可能让所有依赖它的计划失效；改一个后置条件，可能让下游技能的前置条件不再被满足。技能库必须像软件依赖一样**版本化、原子切换、回归测试、可回滚**。一个没有版本号的技能库，等于一个没有锁的共享内存：今天能跑，明天在长时程里悄悄坏掉。

**灵感 8（与 R69 的关系 → 新层严格包含旧层）**
直觉：CRAFT 的执行层就是 R69 的 FLUID 策略。当计划退化为单技能、能力视为完美（κ≡1）、不试做、不学习时，CRAFT 必须逐指令退化为 R69；当能力门或规划门关闭时，也必须退回 R69 的单技能闭环；再往下才是 R68 的纯保守。理论姿态不变：**新层是旧层在「无规划、无能力不确定性」边界上的严格泛化**，而不是又一个需要独立信任的黑箱。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（CRAFT-RAS 总览）** CRAFT-RAS = (SCL, PLC, CAG, STR, PRR, FAL, CDL, SCV, AIC-CRAFT, RAS-WM‡)。继承 R69 定义 293 的实时零学习写操作、交互预算与证据纪律，新增四条不变式：
(i) **合同纪律**：任何计划不得调用没有有效合同的技能；技能的后置条件必须蕴含下一条技能的前置条件（或由守护条件显式补偿）；
(ii) **能力不夸大**：技能只有在当前上下文的能力下置信界（LCB）≥ 1−ε_s 时才允许执行；否则必须走修复通道（试做/分解/重规划/求助）或弃权；
(iii) **风险电池**：任何计划与任何试做都必须从全局风险电池 B_t 扣费，累计认证风险不得超过 B_t；B_t 只在可认证的安全运行/恢复后按受控速率回充；
(iv) **归因先于学习**：未完成归因的结果不得更新技能参数；计划失败不得更新技能；学习只发生在关键路径之外，且新/改技能必须通过准入认证。

**定义 311（技能合同 SCL）** 技能 s = (π_s, Pre_s, Post_s, κ_s, ρ_s, Abort_s, ε_s, v_s)。其中 π_s 是 R69 的流匹配执行策略（或由子技能复合而成）；Pre_s/Post_s 是信念状态上的前置/后置谓词；κ_s(φ) 是上下文特征 φ 上的成功率预测器；ρ_s 是恢复/逃逸策略；Abort_s 是允许中止的状态集；ε_s 是合同声明的单次失败风险上界；v_s 是版本号。**合同在上下文 φ 有效** 当且仅当 Pre_s(φ) 成立、κ_s 的校准 LCB ≥ 1−ε_s、ρ_s 在 Abort_s 上可行、且 v_s 为当前版本。

**定义 312（能力包络与校准 LCB）** 技能 s 的 ε-能力包络
C_s^ε = {φ : κ_s^{LCB}(φ) ≥ 1−ε}。
LCB 由分层（Mondrian）split conformal 或 Clopper–Pearson 在留出校准集上给出：在上下文单元内可交换的假设下，P(success | φ) ≥ κ_s^{LCB}(φ) 至少以 1−α 概率成立；分布偏移用加权 conformal 或在线 conformal 修正。另维护能力校准误差 ECE_κ；ECE_κ > τ_ece 时 CAG 关闭（定义 323）。**能力不是点估计，而是带置信下界的区间**。

**定义 313（版本化技能库）** 技能库 S_t = {s_v} 是不可变版本的集合；更新只能创建新版本，不得静默改写旧版本。计划在生成时**钉住**它使用的每个技能版本；库更新后，受影响的计划必须重新验证。库切换是原子的：控制环只会看到旧快照或新快照，不会看到半更新的依赖图。准入与回滚见定义 322。

**定义 314（计划与概率化可靠性）** 计划 π = (s_{i_1}^{v_1}, …, s_{i_n}^{v_n}) 附带守护条件 γ_i。符号状态转移 x_{i+1} = Post_{s_i}(x_i)。计划**符号可靠**当且仅当对所有 i，Post_{s_i} ∧ γ_i ⇒ Pre_{s_{i+1}}。计划**概率可靠**当且仅当在 A105 下，P(Post_{s_i} ∧ γ_i | 执行成功至 i) ≥ 1−ε_i。CRAFT 只接受同时通过符号检查与概率检查的计划。

**定义 315（计划风险与合同风险电池 CRB）** 计划风险
R(π) = 1 − ∏_{i=1}^{n} (1−ε_i) ≤ Σ_i ε_i + Σ_i ε_{γ_i}，
其中 ε_{γ_i} 是守护条件失败风险。风险电池 B_t 的动态：
B_{t+1} = min(B_max, B_t − R̂(π_t) + r·Δt·1[safe_t])，
R̂ 为认证上界，r 为受控回充率，safe_t 表示本周期在认证安全集内运行。**计划可行的必要条件**是 R̂(π) ≤ B_t；否则必须重规划、试做、求助或弃权，不能“先做做看”。这防止长时程的「每步一点点」累积成「整晚一次大失败」。

**定义 316（计划级不确定性）** 规划器给出计划后验 P(π | g, M_t)（可来自 LLM、PDDL、学习型规划器或它们的集成，但必须经定义 314 的验证器）。定义**决策相关计划不确定性**
U_plan = Σ_π w(π) · [J(a*(π̂)) − J(a*(π))]_+，
其中 π̂ 是当前最优计划，a*(π) 是计划 π 诱导的执行动作/技能选择，J 是任务代价 + 风险。只有「换一条计划会改变动作或风险」的歧义才计入；符号上不同但诱导相同动作的计划，对控制价值为零。

**定义 317（修复算子与计划级 VoI）** 修复算子集
G = {g_ask（澄清目标/约束）, g_inspect（R69 的看/触/问）, g_trial（STR 试做）, g_decompose（换更细的子技能）, g_replan（换计划）, g_abstain（弃权/停下求助）}。
对 g 定义计划级信息价值
VoI_plan(g) = E_{y~p(·|g)}[R(π̂) − R(π̂|y)] − c(g) − c_risk(g)，
约束为 g 通过 R69 定义 302 的信息动作安全认证、预算未超、且试做必须持有定义 318 的试做证书。选择 g* = argmax VoI_plan；若所有候选收益 ≤ 0，则不修复，按当前最优可行计划执行；若根本没有 R̂(π) ≤ B_t 的可行计划，则强制弃权/求助——**弃权是一等公民，不是失败**。

**定义 318（安全试做证书 STR）** 试做 τ = (s, x, h_τ, ρ, S_inv, ε_trial)。有效当且仅当：
(1) S_inv 在恢复策略 ρ 下前向不变，且从任意 x'∈S_inv 出发，ρ 能在 h_abort 内把状态带回认证安全集 S_safe；
(2) 试做的真实风险 ≤ ε_trial，并从风险电池扣费；
(3) 试做结果对 κ_s 在当前上下文有可辨识性（不是重复已知信息）；
(4) 试做不进入不可逆状态、不造成不可恢复的信息损失（例如不可撤回的抓取、不可逆的结构改变）。
满足后，试做是**有界真实风险的信息动作**：它可能失败，但失败被包络在可恢复集合内。

**定义 319（执行监控与合同合规）** 执行层复用 R69 的 FLUID-RAS；监控器逐步检查 Pre/Post/γ 与能力残差，输出合规信号：
- **前置失效**：立即中止，转计划修复（不是技能修复）；
- **后置未达**：计划失效，转重规划/分解；
- **执行不确定高**：走 R69 的交互消歧；
- **能力残差高**（实际成功模式与 κ_s 预测显著偏离）：降级该技能的 LCB，转试做/求助。
监控器不直接改参数，只产生**归因证据**。

**定义 320（失败归因 FAL）** 设结构化结果模型 Y = f(Plan, Skill, World, ε)，观测包含前置满足 P、后置满足 Q、守护状态 G。归因规则：
- ¬P ∧ ¬Q ⇒ **计划/前置错**（不更新技能）；
- P ∧ ¬Q ⇒ **技能错**（允许更新 κ_s，但需 k 源证据）；
- P ∧ Q ∧ 任务仍失败 ⇒ **世界/规格错**（转 R69 交互或求助）；
- 证据冲突/不足 ⇒ **未归因**（冻结更新，记录待查）。
为消除选择偏差，规划器对每个技能的选择记录倾向 e_i = P(select s_i | context)；技能更新使用 IPW/DR 估计，且要求 e_i ≥ e_min > 0。归因置信度低于阈值时，结果只进入审计缓冲，不进入训练集。

**定义 321（能力导向课程 CDL）** 学习优先级
L_s = (∂U_plan/∂κ_s) · Var(κ_s) / (c_learn(s) + c_risk(s))。
只学「对当前计划风险贡献大、且能力不确定性高」的技能；技能不足时优化学**残差技能**（在已有技能上加一个小残差，而不是从零学一个会覆盖旧技能的大网络），以降低干扰与灾难性遗忘。真实世界的学习只能通过定义 318 的试做或仿真沙盒；仿真中学到的技能仍需准入认证。

**定义 322（技能准入与版本化 SCV）** 新/改技能进入库前必须通过：
(1) 合同测试（前置/后置、边界条件、随机种子扫描）；
(2) 留出上下文上的能力 LCB 覆盖；
(3) OOD/分布偏移测试；
(4) 恢复/中止测试（Abort_s 与 ρ_s 的可行性）；
(5) 对现有计划的回归测试（依赖它的计划不得静默失效）；
(6) 版本钉住与回滚演练。
任一项失败 ⇒ 拒绝准入；已准入技能发现回归 ⇒ 原子回滚到旧版本，并触发审计。

**定义 323（能力门 CAG 与规划门 PLG）** 两道独立门：
- **CAG**：能力校准 ECE_κ > τ_ece 或 LCB 覆盖不达标 ⇒ 禁用多技能计划与试做，退回 R69 单技能模式；
- **PLG**：规划器输出未通过定义 314 的符号/概率验证，或规划器被提示注入/不可信 ⇒ 关闭多步规划，退回 R69 单技能模式。
两门都关闭时，CRAFT 逐指令退化为 R69；R69 再按 R68 的 λ_floor 退化。**能力不可信时，不允许用“更精细的计划”来掩盖。**

**定义 324（威胁模型 AIC-CRAFT）** ℰ_CRAFT = ℰ_FLUID × ℰ_skill × ℰ_plan × ℰ_learn：
- ℰ_skill：演示投毒、奖励黑客、能力造假（伪造成功日志）、后门触发、技能干扰/灾难性遗忘；
- ℰ_plan：通过场景文本/用户输入对规划器做提示注入、能力幻觉（规划器假设不存在的技能）、利用乐观风险估计的“看似合规”计划、目标操纵、陈旧计划重放；
- ℰ_learn：失败错误归因、在自身错误上自训练、选择偏差、课程劫持、版本回滚攻击。
核心不是承诺「不被骗」，而是**限制欺骗能造成的后果方向**：能力造假只能让计划更保守（若 LCB 门有效）或被审计抓住；想扩大可行域必须同时攻破 k 源证据、归因、试做包络与风险电池。

**定义 325（参与式审计 VQAuditor-S）** 审计对象新增：合同声明与真实结果的一致性、计划风险声明的诚实度、失败归因的正确性、试做证书、版本变更与回归、课程是否只挑“容易成功的样本”、规划器是否只提议自认为会的技能。结论回灌 AuditBuf，成为下一轮 CAG/PLG 阈值、能力先验与风险的证据。

## 2. 关键算法骨架

```python
# IP-264 SCL：技能合同（技能是承诺，不是函数）
@dataclass(frozen=True)
class SkillContract:
    policy: object          # R69 flow policy π_s
    pre: Predicate          # 前置条件
    post: Predicate         # 后置条件
    kappa: CalibratedModel  # 上下文 -> 成功率（带 LCB）
    rho: object             # 恢复/逃逸策略
    abort: Set[State]       # 允许中止的状态集
    eps: float              # 合同风险上界
    version: int

# IP-267 CAG：能力下置信界门（不夸大能力）
def admissible(s, context, alpha=1e-3):
    if not s.pre(context):                    return False, "precondition"
    lcb = s.kappa.lcb(context, alpha=alpha)   # Mondrian conformal / Clopper-Pearson
    if lcb < 1.0 - s.eps:                     return False, "competence"
    if not recovery_feasible(s.rho, s.abort, context):
                                              return False, "recovery"
    return True, lcb

# IP-266 PLC：风险预算下的计划构造（LLM/PDDL 只提议，不裁决）
def construct_plan(goal, library, battery, context):
    candidates = planner.propose(goal, library.snapshot(), context)  # 分布
    feasible = []
    for pi in candidates:
        if not symbolically_sound(pi, library):        continue  # Post_i => Pre_{i+1}
        if not probabilistically_sound(pi, library, context): continue
        risk = sum(1 - s.kappa.lcb(context) for s in pi.skills) + guard_risk(pi)
        if risk <= battery.level:
            feasible.append((risk, plan_cost(pi), pi))
    if not feasible:
        return None                                    # 弃权/重规划，绝不“先做做看”
    return min(feasible, key=lambda z: (z[0], z[1]))[2]

# IP-268 STR：可逆试做（真实风险的信息动作）
def safe_trial(s, x, h_tau, battery):
    cert = trial_certificate(s, x, h_tau)              # S_inv, rho, h_abort, eps_trial
    if cert is None or cert.eps > battery.level:       return None
    if not cert.reversible or not cert.informative:    return None
    battery.charge(cert.eps)
    y = execute_with_abort(s, x, h_tau, cert.rho)      # 失败也在包络内
    return y, cert

# IP-269 PRR：计划修复路由（消歧 / 试做 / 分解 / 重规划 / 求助 / 弃权）
def route_repair(pi, context, battery, uncertainty):
    best = None
    for g in repair_candidates(pi, uncertainty):
        if not safety_certified(g, context):           continue  # 复用 R69 定义 302 + 定义 318
        voi = expected_risk_reduction(pi, g) - cost(g) - risk_cost(g)
        if best is None or voi > best.voi: best = (g, voi)
    if best and best.voi > 0:                          return best.g
    return "abstain" if pi is None or pi.risk > battery.level else None

# IP-270 FAL：归因先于学习（计划错 ≠ 技能错）
def attribute(outcome, context, propensity):
    P, Q, G = outcome.pre_ok, outcome.post_ok, outcome.guard_ok
    if not P and not Q:    return "plan"
    if P and not Q:        return "skill"
    if P and Q and not outcome.task_ok: return "world_or_spec"
    return "unresolved"                                # 冻结更新，进审计

def update_skill(s, outcome, context):
    if propensity[outcome.skill_id] < E_MIN:           # positivity 失败
        return "defer_to_audit"
    label = attribute(outcome, context, propensity)
    if label != "skill":                               return "no_skill_update"
    w = 1.0 / propensity[outcome.skill_id]             # IPW，抵消选择偏差
    s.kappa.update(outcome, weight=w)                  # 只更新能力，不覆盖执行策略
    return "updated"

# IP-276 CRAFT 主闭环（执行层继承 R69，失败时向上修复）
def CRAFT_round(goal, x, context, M):
    # 1) 计划层：风险预算 + 双门
    pi = M.plc.construct_plan(goal, M.library, M.battery, context) if M.plg.open else single_skill(goal)
    if pi is None:
        return M.prr.execute("abstain", goal, context)          # 弃权/求助，而不是冒险
    # 2) 执行层：逐技能执行，R69 处理动作歧义
    for s in pi.skills:
        ok, why = M.cag.admissible(s, context)
        if not ok:
            g = M.prr.route_repair(pi, context, M.battery, why)
            return M.prr.execute(g, goal, context)              # 试做/分解/重规划/求助
        U_ale, U_epi, mode = M.fluid.execute(s.policy, context) # R69 的 FLUID-RAS
        outcome = M.monitor.run(s, mode, context)               # Pre/Post/γ/能力残差
        label = M.fal.attribute(outcome, context, M.propensity)
        if label in ("plan", "world_or_spec", "unresolved"):
            M.vqa_s.submit_async(outcome, label, pi, M.battery.level)
            return M.prr.execute("replan" if label == "plan" else "ask",
                                 goal, context)
        M.battery.charge(s.eps)                                  # 真实执行扣费
        if not outcome.post_ok:
            M.cdl.record_bottleneck(s, context)                  # 课程：只学瓶颈
            return M.prr.execute("decompose", goal, context)
    M.vqa_s.submit_async(pi, M.battery.level, M.library.version)
    return "done"
```

## 3. 推导

假设：
- **A105**：技能合同的条件失败率有界：在执行到第 i 步仍成功的条件下，第 i 步失败概率 ≤ ε_i；守护条件失败概率 ≤ ε_{γ_i}。
- **A106**：能力校准集与部署上下文在 Mondrian 单元内可交换（或加权 conformal 的密度比有界）；α 为覆盖显著性。
- **A107**：试做证书的 S_inv 前向不变，ρ 在 h_abort 内可达 S_safe；试做风险 ≤ ε_trial。
- **A108**：归因前置检测器的漏检率 ≤ δ_P；规划器对技能的选择倾向 e_i ≥ e_min > 0（探索下限保证 positivity）。
- **A109**：规划器只输出经定义 314 验证的计划；技能库版本原子切换。

**引理 19（合同复合与风险电池）** 在 A105 下，计划 π 的失败概率 ≤ Σ_i ε_i + Σ_i ε_{γ_i}；若每步认证风险都从 B_t 扣费且 B_t 不为负，则截至 T 次计划尝试的累计认证风险 ≤ B_0 + rT。特别地，当 r=0 时，累计风险**与尝试次数无关**，不会随长时程线性蠕变。系：风险电池把「每步 2%」的局部安全，变成「整晚 ≤ B_0」的全局可声明安全；B_t 耗尽时系统必须弃权/求助，而不是继续以小博大。

**引理 20（能力 LCB 的假准入上界）** 在 A106 下，单个技能在上下文单元内被 CAG 误判为「达到 1−ε_s」的概率 ≤ α；对 n 个技能做 Bonferroni 校正 α'=α/n，则任一技能被假准入的概率 ≤ α。若分布偏移使密度比上界为 W，则假准入概率 ≤ α·W + ECE_κ（加权 conformal 的覆盖损失）。系：**能力门的保证是「有限样本 + 显式校准误差」的，不是「模型说自己行就行」**；ECE 越界时必须关门。

**引理 21（试做的有界风险与非负信息增益）** 在 A107 下，试做 τ 的失败概率 ≤ ε_trial，且失败状态仍在 S_inv ∪ S_safe 内；试做结果 y 对能力参数的后验熵期望不增（Bayes 信息不等式），即 E[H(κ_s | y)] ≤ H(κ_s)。因此试做是「有真实成本、但信息收益非负」的动作；是否执行由 VoI_plan 的净值决定，而不是由好奇心决定。系：**不可逆的试做不是信息动作**——它没有 S_safe 可回退，必须被定义 318 直接拒绝。

**引理 22（归因与选择偏差）** 在 A108 下：
(1) 若只在前置满足时把失败归因给技能，则计划失败污染技能的概率 ≤ δ_P；因此技能更新的偏差 ≤ δ_P·L_κ（L_κ 为能力模型 Lipschitz）。
(2) 若规划器对技能的选择倾向 e_i ≥ e_min > 0，则 IPW/DR 估计无偏（或渐近无偏）；若某些技能 e_i=0（规划器从不选它），则其能力**不可识别**，任何基于被执行样本的估计都可能无限偏离真实值。
系：**探索下限不是效率选项，而是能力可识别性的前提**；没有探索的技能库，其「零失败」可能只是「零尝试」。

**定理 18（CRAFT 对 R69 的严格包含）** 在 A105–A109 下：
- 当计划退化为单技能、κ≡1、不试做、不学习、B_t 足够大时，CRAFT 的执行层与 R69 的 FLUID-RAS **逐指令相同**；
- 当 CAG 或 PLG 任一关闭时，CRAFT 退回 R69 的单技能闭环；
- 当 R69 的流/标定也关闭时，继续退回 R68 的 λ_floor 保守模式。
因此 R69 是 CRAFT 在「无规划、无能力不确定性」边界上的退化；CRAFT 的安全侧不做任何让步，效率侧通过「能规划、敢试做、会换招」获得 resolution bonus。

**定理 19（长时程无风险蠕变）** 在引理 19 与有效合同下，若 B_t 的回充只在认证安全集内发生，则截至任意时刻，系统累计的认证计划失败风险 ≤ B_0 + rT；当 B_t 接近 0 时，CRAFT 只能选择 R̂(π) ≤ B_t 的计划，若不存在则弃权。故 **CRAFT 不会因为“任务还长”而把风险预算透支**；它宁可停下来求助，也不会把长时程变成一场必然的赌博。

**定理 20（规划门与执行安全）** 在 A109 下，若规划器只输出通过符号/概率验证的计划，则任何执行失败都不再是「前置条件不成立」导致的计划错，而是技能失败/世界变化/规格错；这使得归因歧义从「三类混合」降为「两类可辨」，从而引理 22 的 δ_P 可被显著压低。且 PLG 关闭时退回 R69，不会让未经验证的多步计划进入控制环。系：**规划器的价值在提议，不在裁决**；验证器是规划器与安全之间的隔离带。

**预实验 E316p（合成机制验证，仅验证假设，不作性能声明）**：在纯 Python 合成环境中（12 个技能、计划长度 3、3000 个规划问题）比较「点估计规划」与「LCB + 风险电池」。结果：点估计规划以平均声明风险 0.088 选出计划，实际失败率 0.391（**声明风险严重低估**）；LCB 规划在 B=0.25/0.40 时因无可行计划而 100% 弃权，在 B=0.55 时执行计划的声明风险 0.472、实际失败率 0.405（**声明是上界**）。另在 8 技能、300 轮的截断反馈实验中（200 个随机种子）：仅截断记录成功 → 能力 MAE 0.253、后期失败率 0.259；加 20% 探索下限 + 归因完整记录 → MAE 0.094、后期失败率 0.146。初步支持两点：**风险必须用下置信界而非点估计**；**归因与探索下限是能力可识别性的前提**。

## 6. 本轮最大风险

**一句话**：CRAFT 的全部收益押在「能力模型可信」上，而能力模型只观测到规划器允许它尝试的样本——**规划器与能力模型会互相确认：只规划自认为会的，永远不学不会的；在分布外，LCB 与风险电池会把多次小乐观累积成一次大失败，而证书仍然显示「Valid」**——**最危险的不是不会，而是自以为会，并且有一份看起来很严谨的合同为它背书。**

**次级风险与缓解**：
1. **合同风险上界不诚实**（ε_s 低估、守护条件漏算）→ 分层 conformal + 校准审计 + E316 + 风险电池双重扣费；
2. **能力造假/演示投毒/后门** → k 源证据 + 归因 + 版本化准入 + ℰ_skill 对抗训练；
3. **规划器提示注入/能力幻觉** → PLG 符号/概率验证 + 规划器只提议不裁决 + E317；
4. **试做越界/不可逆** → 定义 318 的可逆包络 + 风险电池 + E320，未持证不试做；
5. **错误归因污染技能** → 定义 320 + 前置检测 + 审计缓冲 + E321；
6. **选择偏差/能力坍缩** → 显式探索下限 + IPW/DR + 审计“只挑容易的” + E322；
7. **实时预算被规划/试做击穿** → 规划异步、门控查表、试做低频、K=1 默认路径。

## 2. 形式化定义（要点版）

**定义 310（总览与四条不变式）** CRAFT-RAS = (SCL, PLC, CAG, STR, PRR, FAL, CDL, SCV, AIC-CRAFT, RAS-WM‡)。继承 R69 的实时零学习写操作、交互预算、证据纪律；新增：合同纪律、能力不夸大、风险电池、归因先于学习。

**定义 311–313（合同、能力包络、版本化库）** 技能是合同 `s=(π,Pre,Post,κ,ρ,Abort,ε,v)`；合同在上下文有效 ⇔ Pre 成立 ∧ `κ^LCB ≥ 1−ε` ∧ 恢复可行 ∧ 版本当前。能力包络 `C_s^ε` 由分层 conformal / Clopper–Pearson 给出；技能库不可变版本、计划钉住版本、原子切换。

**定义 314–315（计划可靠性与风险电池）** 符号可靠：`Post_i ∧ γ_i ⇒ Pre_{i+1}`；概率可靠：`P(Post_i ∧ γ_i | 成功至 i) ≥ 1−ε_i`。计划风险 `R(π) ≤ Σ ε_i + Σ ε_{γ_i}`。风险电池 `B_{t+1}=min(B_max, B_t−R̂(π_t)+rΔt·1[safe])`；`R̂(π) ≤ B_t` 是执行的硬前提，否则弃权/求助。

**定义 316–317（计划不确定性与修复）** `U_plan = Σ_π w(π)[J(a*(π̂))−J(a*(π))]_+`，只计会改变动作/风险的歧义。修复算子集 `G={ask, inspect, trial, decompose, replan, abstain}`；`VoI_plan(g)=E[R(π̂)−R(π̂|y)]−c(g)−c_risk(g)`；没有可行计划时强制弃权。

**定义 318（安全试做）** 试做有效 ⇔ S_inv 在 ρ 下前向不变、h_abort 内可回 S_safe、风险 ≤ ε_trial 且从电池扣费、对 κ_s 可辨识、不进入不可逆状态。不可逆试做直接拒绝。

**定义 319–320（监控与归因）** 监控器只产证据：前置失效→计划；后置未达→重规划；执行不确定→R69 消歧；能力残差→降 LCB。归因规则：¬P∧¬Q⇒计划；P∧¬Q⇒技能；P∧Q 且任务失败⇒世界/规格；冲突⇒冻结。技能更新用 `1/e_i` 的 IPW，要求 `e_i ≥ e_min>0`。

**定义 321–322（课程与准入）** 学习优先级 `L_s=(∂U_plan/∂κ_s)·Var(κ_s)/(c_learn+c_risk)`；优先学瓶颈、优先残差技能。新/改技能需通过合同测试、LCB 覆盖、OOD、恢复/中止、依赖回归、版本回滚六项。

**定义 323–326（双门、威胁、审计、证书）** CAG（能力门）与 PLG（规划门）独立；任一关闭退回 R69 单技能模式，二者都关再退 R68。`ℰ_CRAFT=ℰ_FLUID×ℰ_skill×ℰ_plan×ℰ_learn`。VQAuditor-S 审计合同/计划/归因/试做/版本/课程。`J_CRAFT` 并入版本、计划风险上界、电池水位、能力 ECE/覆盖、试做风险、归因置信、探索下限统计。

## 3. 关键算法伪代码

```python
# IP-264 SCL：技能合同
@dataclass(frozen=True)
class SkillContract:
    policy: object; pre: Predicate; post: Predicate
    kappa: CalibratedModel; rho: object; abort: Set[State]
    eps: float; version: int

# IP-267 CAG：能力下置信界（不允许“自认为会”）
def admissible(s, ctx, alpha=1e-3):
    if not s.pre(ctx):                          return False, "precondition"
    lcb = s.kappa.lcb(ctx, alpha=alpha)         # Mondrian conformal
    if lcb < 1.0 - s.eps:                       return False, "competence"
    if not recovery_feasible(s.rho, s.abort, ctx):
                                                return False, "recovery"
    return True, lcb

# IP-266 PLC：规划器只提议，验证器+风险电池裁决
def construct_plan(goal, lib, battery, ctx):
    cands = planner.propose(goal, lib.snapshot(), ctx)
    ok = []
    for pi in cands:
        if not symbolically_sound(pi, lib):       continue   # Post_i => Pre_{i+1}
        if not probabilistically_sound(pi, lib, ctx): continue
        risk = sum(1-s.kappa.lcb(ctx) for s in pi.skills) + guard_risk(pi)
        if risk <= battery.level: ok.append((risk, plan_cost(pi), pi))
    return min(ok, key=lambda z:(z[0],z[1]))[2] if ok else None   # None => 弃权

# IP-268 STR：可逆试做（带真实风险的信息动作）
def safe_trial(s, x, h, battery):
    cert = trial_certificate(s, x, h)             # S_inv, rho, h_abort, eps_trial
    if cert is None or cert.eps > battery.level:  return None
    if not (cert.reversible and cert.informative):return None
    battery.charge(cert.eps)
    return execute_with_abort(s, x, h, cert.rho), cert

# IP-270 FAL：归因先于学习
def attribute(outcome):
    P, Q = outcome.pre_ok, outcome.post_ok
    if not P and not Q:                  return "plan"
    if P and not Q:                      return "skill"
    if P and Q and not outcome.task_ok:  return "world_or_spec"
    return "unresolved"                  # 冻结更新，进审计

def update_skill(s, outcome, propensity):
    if propensity[outcome.skill_id] < E_MIN:      return "defer_to_audit"
    if attribute(outcome) != "skill":             return "no_skill_update"
    s.kappa.update(outcome, weight=1.0/propensity[outcome.skill_id])  # IPW
    return "updated"

# IP-276 CRAFT 主闭环
def CRAFT_round(goal, x, ctx, M):
    pi = (M.plc.construct_plan(goal, M.library, M.battery, ctx)
          if M.plg.open else single_skill(goal))
    if pi is None:
        return M.prr.execute("abstain", goal, ctx)
    for s in pi.skills:
        ok, why = M.cag.admissible(s, ctx)
        if not ok:
            return M.prr.execute(M.prr.route_repair(pi, ctx, why), goal, ctx)
        U_ale, U_epi, mode = M.fluid.execute(s.policy, ctx)   # R69 执行层
        outcome = M.monitor.run(s, mode, ctx)                  # Pre/Post/γ/能力残差
        label = M.fal.attribute(outcome)
        if label in ("plan","world_or_spec","unresolved"):
            M.vqa_s.submit_async(outcome, label, pi, M.battery.level)
            return M.prr.execute("replan" if label=="plan" else "ask", goal, ctx)
        M.battery.charge(s.eps)
        if not outcome.post_ok:
            M.cdl.record_bottleneck(s, ctx)
            return M.prr.execute("decompose", goal, ctx)
    M.vqa_s.submit_async(pi, M.battery.level, M.library.version)
    return "done"
```

## 4. 推导

**引理 19（合同复合与风险电池）** A105 下，计划失败概率 ≤ `Σ_i ε_i + Σ_i ε_{γ_i}`；若每步认证风险从 B_t 扣费且 B_t 不为负，则截至 T 次尝试的累计认证风险 ≤ `B_0 + rT`。r=0 时累计风险与尝试次数无关，杜绝长时程风险蠕变；B_t 耗尽则必须弃权/求助。

**引理 20（能力 LCB 假准入上界）** A106 下，单技能假准入概率 ≤ α；n 个技能 Bonferroni 校正后 ≤ α。分布偏移密度比 W 时，假准入 ≤ `αW + ECE_κ`。系：能力保证是「有限样本 + 显式校准误差」的，ECE 越界必须关门。

**引理 21（试做的有界风险与非负信息增益）** A107 下，试做失败概率 ≤ ε_trial，失败状态仍在 `S_inv ∪ S_safe`；Bayes 信息不等式给出 `E[H(κ|y)] ≤ H(κ)`。故试做是「有真实成本、信息收益非负」的动作，执行与否由 VoI 净值决定；不可逆试做不是信息动作，直接拒绝。

**引理 22（归因与选择偏差）** 前置漏检率 δ_P 下，计划失败污染技能的概率 ≤ δ_P，技能更新偏差 ≤ `δ_P·L_κ`；若规划器倾向 `e_i ≥ e_min>0`，IPW/DR 估计无偏；若某些技能 `e_i=0`，其能力不可识别，「零失败」可能只是「零尝试」。系：探索下限是能力可识别性的前提，不是效率选项。

**定理 18（CRAFT 严格包含 R69）** 单技能、κ≡1、不试做、不学习、B_t 足够大时，CRAFT 执行层与 R69 逐指令相同；CAG 或 PLG 关闭 ⇒ 退回 R69 单技能闭环；R69 的流/标定也关闭 ⇒ 退回 R68 的 λ_floor。R69 是 CRAFT 在「无规划、无能力不确定性」边界上的退化，安全不让步，效率获 resolution bonus。

**定理 19（长时程无风险蠕变）** 有效合同 + 受限回充下，累计认证计划失败风险 ≤ `B_0 + rT`；B_t 接近 0 时只能选 `R̂(π) ≤ B_t` 的计划，无可行计划则弃权。故 CRAFT 不会因「任务还长」而透支风险预算，宁停不赌。

**定理 20（规划门与执行安全）** A109 下，规划器只输出经符号/概率验证的计划，执行失败不再来自「前置不成立」的计划错，而归因歧义从三类混合降为两类可辨，δ_P 显著压低；PLG 关闭即退回 R69，未验证计划不进入控制环。系：规划器的价值在提议，不在裁决。

## 7. 本轮最大风险

**一句话**：CRAFT 的全部收益押在「能力模型可信」上，而能力模型只观测到规划器允许它尝试的样本——**规划器与能力模型会互相确认：只规划自认为会的，永远不学不会的；在分布外，LCB 与风险电池会把多次小乐观累积成一次大失败，而证书仍然显示「Valid」**——**最危险的不是不会，而是自以为会，并且有一份看起来很严谨的合同为它背书。**

**次级风险与缓解**：合同风险上界不诚实（分层 conformal + 审计 + 电池双重扣费 + E316）；能力造假/演示投毒/后门（k 源证据 + 归因 + 版本化准入 + ℰ_skill 对抗训练 + E325）；规划器提示注入/能力幻觉（PLG 符号/概率验证 + 规划器只提议 + E317）；试做越界/不可逆（定义 318 可逆包络 + 电池 + E320）；错误归因污染技能（定义 320 + 前置检测 + 审计缓冲 + E321）；选择偏差/能力坍缩（显式探索下限 + IPW/DR + 审计“只挑容易的” + E322）；实时预算被规划/试做击穿（规划异步、门控查表、试做低频、K=1 默认）。
