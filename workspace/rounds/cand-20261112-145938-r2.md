# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 2 轮；本轮灵感：「材料选型」×「模型蒸馏」）

> 第 60 轮把场景语义（SSM）、认知意图（CIEC）、ROS 因果隔离（EPIR）统一为 SERC 闭环，但仍有三个未解决的「接地缺口」：
> 1. **阻抗先验暗含「材料不变」假设**：π_scene(K|z) 与 K_safe 都在软件阻抗层调参，却默认末端接触材料固定。现实中换软硅胶指腹 / 硬质金属指尖 / 防滑橡胶垫 / 吸盘，会直接改变接触刚度 K_c、摩擦锥 μ、损伤阈值 F_damage 与磨损率 w——**软件阻抗只能补偿，无法弥补错误的硬件材料选型**；「阻抗可调 ≠ 材料可选」。
> 2. **认知模型太重、边端放不下**：SSM 场景识别、意图映射、材料-接触物理预测在云端大模型 / 高保真有限元上成立，但 ROS 边端算力有限；不蒸馏则无法满足实时周期，蒸馏后又出现「学生模型过/欠自信」的保真度缺口。
> 3. **双源不确定性无法相乘估计**：材料批次差异（物理不确定性）与蒸馏误差（认知不确定性）是两个独立误差源，第 60 轮的 SIC 只建模场景置信度，未对二者做联合最坏界；一旦「模型很准但材料批次反常」或「材料很好但学生过自信」，安全边界会被非线性映射悄悄击穿。

## 0. 直觉与动机

**灵感 1（材料选型 → 物理阻抗先验）**
直觉：机器人末端与世界的「第一层阻抗」不是软件参数，而是材料本身。软硅胶指腹像低刚度、高阻尼、大摩擦的弹簧；硬质金属指尖像高刚度、小阻尼、易滑的刚体；防滑橡胶垫提高 μ，却带来磨损与温升。EEIS 里的 K_safe 只能在这一层材料给定的可行域内调参。关键洞见：**把材料 m 视为「不可微的物理先验」，软件阻抗 K_s 是对它的补偿**；选错材料，K_s 再准也只是「在错误的可行域里最优」。因此需要材料能力模型：每种材料 m 在场景 z 下给出接触阻抗 K_c(m)、摩擦锥 μ(m)、损伤阈值 F_damage(m)、磨损率 w(m)、热限 T_max(m)，并把它们变成 K_safe 的硬约束。

**灵感 2（模型蒸馏 → 认知保真先验）**
直觉：云端大模型 / 高保真有限元仿真是好老师，但边端跑不动。蒸馏把 teacher 的策略与物理预测压成 student，使 SSM、意图映射、材料-接触预测能进入 ROS 实时周期。但蒸馏不是免费午餐：student 会「遗忘」老师对罕见材料的谨慎，也会在训练分布外过度自信。关键洞见：**安全系统的蒸馏必须是单向保守蒸馏**——允许 student 比 teacher 更谨慎，不允许更乐观；用保形预测（conformal）把「学生风险低估」压到可证上界 α，并把保形覆盖作为证书随执行证据一起回传。

**灵感 3（材料×蒸馏 → 双源不确定性球）**
直觉：材料批次误差（同牌号不同批次的 E、μ 有 ±x% 波动，且随磨损漂移）与蒸馏误差（student 对接触参数的预测偏差）是两个正交误差源。它们不是简单相加，而是在「阻抗→力→滑移风险」的非线性映射下**相乘放大**。关键洞见：把二者合成一个**双源不确定性集** U(m,z) = P_batch(m) ⊕ C_α^student(m,z)（Minkowski 和），在 U 上取最坏风险 r_wc；只有 r_wc ≤ ε_safe 才允许执行——这给出与「老师多准、学生多小」无关的分布自由安全界。

**灵感 4（合流 → 材料-蒸馏接地闭环 MDGL）**
直觉：SSM 给场景 z → MCM 给材料可行域 → MSC 在双源不确定性下共选 (m,K) → SDT 蒸馏给出实时 student → SERCL+ 执行并回传带 MDC 证书的 EV-exec → DLC 监测漂移并触发再蒸馏/换材料。形成「场景→材料→阻抗→执行→证据→(再蒸馏/换材料)」的第二层闭环，把第 60 轮的「认知先行」升级为「**物理先行 + 认知保真**」。

**灵感 5（预算 → PCE+++++ 六维）**
直觉：材料试错是物理成本（库存、试件、磨损），蒸馏是认知成本（teacher 查询、算力、再校准样本）。二者共享同一笔「安全预算」：材料探索越激进，需要越多 calibration 数据来标定 student；teacher 查询越少，越依赖保守材料。把 B_mat、B_distill 加入预算，任一耗尽回退到「已认证材料 + 冻结 student」。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（材料能力模型 MCM）** 材料目录 M = {m₁, …, m_M}，材料属性向量
p(m) = (E, ν, η, μ_s, μ_k, κ_th, w, c, ρ, A_contact)，
分别表示杨氏模量、泊松比、粘弹性阻尼、静/动摩擦系数、热导率、磨损率、单位成本、密度、标称接触面积。材料条件接触阻抗由 Hunt–Crossley / Kelvin–Voigt 模型近似：
```
K_c(m) = c_K · E(m) · sqrt(A_contact) / (1 − ν(m)²)
B_c(m) = c_B · η(m) · A_contact
```
材料允许阻抗集：
```
K_adm(m,z) = { K_s | K_min(m) ≤ K_s ≤ K_max(m),
                     F_n(K_s,z) ≤ F_damage(m,z),
                     |F_t| ≤ μ(m,z)·F_n,
                     T(K_s) ≤ T_max(m),
                     K_total = K_s ⊕ K_c(m) }
```
其中 `F_damage(m,z) = σ_damage(m)·A_contact·(1 − w(m)·n_wear)`，体现磨损累积使损伤阈值下降；`⊕` 为弹簧串联。

**定义 162（材料-阻抗共选 MSC）** 决策 x = (m, K_s)，候选集 C(z) = {m ∈ M | Inventory(m) > 0}。目标
```
J(m,K_s) = E_{p∈U(m,z)}[ ℓ_task(m,K_s,z,p) + λ_s·r_slip(m,K_s,z,p) ]
           + λ_w·wear(m,K_s) + λ_c·cost(m)
```
约束：SIC_valid(z,K_s) ∧ K_s ∈ K_adm(m,z) ∧ r_wc(m,K_s) ≤ ε_safe。采用**字典序安全优先**：
1. 可行域 F(z) = {(m,K_s) | 上述约束成立}；
2. 若 F(z)=∅ → 返回 DEGRADE_MATERIAL（保持当前认证材料 + 保守 K）；
3. 否则 (m*,K_s*) = argmin_{(m,K_s)∈F} [λ_D·D⁺(m,K_s) + λ_w·wear + λ_c·cost]。
可选探索：在 B_mat 允许时，用约束贝叶斯优化（SafeOpt 型）扩张安全集，采集函数只接受以概率 ≥ 1−β 满足 r_wc ≤ ε_safe 的点。

**定义 163（安全蒸馏 SDT）** teacher 映射 f_T: (z,I,p(m)) → (K, r_T)，student f_S(·;θ)。蒸馏损失
```
L(θ) = E_{(s,a)∼D_T}[ ℓ_task(f_S(s),a) + λ_safe·ℓ_one-side(f_S(s),f_T(s)) ] + λ_cal·L_cal
ℓ_one-side = max(0, r_T(s) − r_S(s) − ε_r)
            + max(0, d(f_S(s), A_safe^T(s)) − margin_safe)
```
第一项禁止 student 比 teacher 更乐观（低估风险超过 ε_r），第二项惩罚 student 靠近 teacher 的不可行域。保形校准：在留出校准集 D_cal 上计算非一致性分数 s_i = r_S(s_i) − r_T(s_i)，取分位数 q_{1−α}，得到有限样本保证
```
P( r_S(s) ≥ r_T(s) − q_{1−α} ) ≥ 1 − α
```
输出蒸馏证书 `D_cert = (student_hash, teacher_hash, α, q_{1−α}, ε_task, calib_id)`。

**定义 164（材料蒸馏先验 MDP）** 高保真物理 teacher `f_T^phys: (m,z)→p(m,z)`（有限元 / 实测标定），边端 student `f_S^phys` 给出点预测 p̂ 与非一致性分数。对材料批次 b 构造保形集
```
C_α(m,z,b) = { p | s(m,z,b;p) ≤ q_{1−α}(b) }
```
若批次 b ∉ B_cal（无校准样本），则标记 OOD，退化为 teacher 先验高分位椭球或直接触发 teacher 查询。物理材料不确定集由批次公差与磨损给出
```
P_batch(m) = ∏_i [ p_i^nom·(1−δ_i·(1+w(m)·n)),  p_i^nom·(1+δ_i·(1+w(m)·n)) ]
U(m,z) = { p + e | p ∈ P_batch(m), e ∈ C_α(m,z,b) }
r_wc(m,K_s) = max_{p∈U(m,z)} r_slip(m,K_s,z,p)
```

**定义 165（蒸馏生命周期 DLC）** 状态 Σ_dlc = (v_S, v_T, D_cal, ψ_drift)。漂移检测对实时特征流与蒸馏训练分布做 MMD / 两样本检验得 ψ_drift；覆盖率监测在滑动窗口 W 上重算经验覆盖率 ĉ。触发规则：
- 若 ψ_drift > δ_drift 或 ĉ < 1−α−δ_cov，或批号 b ∉ B_cal → RE_DISTILL 或 TEACHER_QUERY；
- 若 RE_DISTILL 后验证失败 → 回滚到上一认证版本 v_S^cert；
- 再蒸馏与查询次数计入 B_distill。

**定义 166（材料-蒸馏接地闭环 SERCL+）** 算子 SERCL+(M, z, I, δ_f_req)：
```
① SSM: z, conf ← R_scene.update(obs)                        # 第 60 轮
② MDP: C_α(m) ← student.predict(m,z); U(m) ← P_batch ⊕ C_α
③ MSC: (m*,K_adm) ← robust_select(U, z, budget)             # 双源最坏界
④ if OOD(m*,z) or B_distill exhausted: teacher_query / 保守材料
⑤ CIEC: C_intent ← φ(I); ERTC.lock(C_intent)               # 第 60 轮
⑥ EEIS: K_safe ← compile(δ_f_req, K_adm(m*) ∩ K_safe^scene)
⑦ Execute: telemetry ← contact()
⑧ EV-exec ← build_evidence(telemetry, material=m*, batch=b, D_cert)
⑨ MDC ← certify(m*, b, v_S, v_T, α, q, coverage); EPIR.push(EV-exec, MDC)
⑩ SIC update; DLC.drift_check(ψ_drift, ĉ); maybe schedule re-distill
⑪ Return (m*, K_safe, EV-exec, MDC, budget.status)
```

**定义 167（六维预算 PCE+++++）** B = (B_scene, B_intent, B_ros, B_exec, B_mat, B_distill)：
- **B_mat** = (Inventory, Trial_budget, Wear_budget, Batch_calib_samples)
- **B_distill** = (Teacher_query_budget, Distill_compute, Recalib_budget, Version_slots)
```
voi_md(π) = VOI_cog(π) − cost_mat(π) − cost_distill(π)
cost_mat = λ_trial·N_trial + λ_wear·E[wear] + λ_inv·Inventory_locked
cost_distill = λ_q·N_query + λ_comp·FLOPs + λ_recal·N_calib
```
降级：B_mat < θ_mat → 锁定认证材料，禁止探索；B_distill < θ_distill → 冻结 student、关闭 teacher 查询、用 teacher 缓存的保守策略；其余沿用第 60 轮 B_scene/B_intent/B_ros/B_exec 降级。

**定义 168（材料-蒸馏证书 MDC）**
```
MDC = (material_id, batch_id, prop_interval, student_hash, teacher_hash,
       α, q_{1−α}, coverage_emp, drift_stat, validity_horizon, signature)
```
验证谓词：
```
MDC_valid = (hash_chain 完整) ∧ (coverage_emp ≥ 1−α−δ_cov)
```

### IP-161 MCM（材料能力模型）

```python
class MaterialCapabilityModel:
    def __init__(self, catalog):
        self.catalog = catalog  # {m_id: {E,nu,eta,mu_s,mu_k,kth,wear,cost,batch_tol,...}}

    def contact_impedance(self, m, A=1e-4):
        p = self.catalog[m]
        Kc = p['cK'] * p['E'] * np.sqrt(A) / (1 - p['nu']**2)
        Bc = p['cB'] * p['eta'] * A
        return Kc, Bc

    def damage_threshold(self, m, n_wear):
        p = self.catalog[m]
        return p['sigma_damage'] * p['A_contact'] * (1 - p['wear'] * n_wear)

    def admissible_set(self, m, z, n_wear):
        p = self.catalog[m]
        return {
            'm': m,
            'K_range': (p['K_min'], p['K_max']),
            'mu': p['mu_k'],
            'F_damage': self.damage_threshold(m, n_wear),
            'T_max': p['T_max'],
            'wear_rate': p['wear'],
            'cost': p['cost'],
        }
```

### IP-162 MSC（材料-阻抗共选）

```python
class MaterialImpedanceCoSelector:
    def __init__(self, mcm, risk_model, budgets, eps_safe=1e-2):
        self.mcm, self.risk, self.B, self.eps = mcm, risk_model, budgets, eps_safe

    def robust_uncertainty(self, m, z, batch, alpha):
        P_batch = self.mcm.batch_interval(m, batch)
        C_alpha = self.risk.conformal_set(m, z, batch, alpha)   # student model
        return minkowski_sum(P_batch, C_alpha)

    def select(self, z, delta_f_req):
        feasible = []
        for m in self.B.available_materials():
            if self.B.inventory[m] <= 0:
                continue
            adm = self.mcm.admissible_set(m, z, self.B.n_wear.get(m, 0))
            U = self.robust_uncertainty(m, z, self.B.batch[m], self.B.alpha)
            K = self._robust_compile(adm, U, delta_f_req)
            if K is None:
                continue
            r_wc = max(self.risk.slip(m, K, z, p) for p in U.samples())
            if r_wc > self.eps:
                continue
            feasible.append((m, K, r_wc, adm['cost'], adm['wear_rate']))
        if not feasible:
            return ('DEGRADE_MATERIAL', None, None)
        m, K, _, _, _ = min(
            feasible,
            key=lambda x: self.B.lam_D * self.risk.exec_discrepancy(x[0], x[1], z)
                          + self.B.lam_w * x[4] + self.B.lam_c * x[3])
        return (m, K, 'ROBUST_FEASIBLE')

    def _robust_compile(self, adm, U, delta_f_req):
        K_lo = max(adm['K_range'][0], max(p['K_min_real'] for p in U.samples()))
        K_hi = min(adm['K_range'][1], min(p['K_max_safe'] for p in U.samples()))
        if K_lo > K_hi:
            return None
        return clip(EEIS.compile(delta_f_req), K_lo, K_hi)
```

### IP-163 SDT（安全蒸馏）

```python
class SafeDistiller:
    def __init__(self, teacher, student, alpha=0.05, eps_r=1e-3, lam_safe=2.0):
        self.T, self.S, self.alpha, self.eps_r, self.lam = teacher, student, alpha, eps_r, lam_safe
        self.q = None

    def safety_loss(self, s, a):
        rT, safe_set = self.T.risk_and_safe_set(s)
        rS = self.S.risk(s, a)
        under = torch.relu(rT - rS - self.eps_r)
        near = torch.relu(self.T.margin(s, a) - self.eps_r)
        return under + near

    def train(self, D_T, D_cal, epochs=50):
        for _ in range(epochs):
            for s, a in D_T:
                loss = task_loss(self.S(s), a) + self.lam * self.safety_loss(s, a)
                loss.backward(); opt.step()
        scores = [self.S.risk(s, a) - self.T.risk(s, a) for s, a in D_cal]
        self.q = np.quantile(scores, 1 - self.alpha)
        cov = np.mean([self.S.risk(s, a) >= self.T.risk(s, a) - self.q for s, a in D_cal])
        return DistillCertificate(self.S.hash, self.T.hash, self.alpha, self.q, cov)
```

### IP-164 MDP（材料蒸馏先验）

```python
class MaterialDistillationPrior:
    def __init__(self, teacher_phys, student_phys, alpha=0.05):
        self.T, self.S, self.alpha = teacher_phys, student_phys, alpha
        self.q_by_batch = {}

    def calibrate_batch(self, batch_id, D_cal_batch):
        scores = [abs(self.S.predict(m, z) - self.T.predict(m, z)) for m, z in D_cal_batch]
        self.q_by_batch[batch_id] = np.quantile(scores, 1 - self.alpha)

    def conformal_set(self, m, z, batch_id):
        if batch_id not in self.q_by_batch:
            return None                     # OOD -> teacher query
        q = self.q_by_batch[batch_id]
        p_hat = self.S.predict(m, z)
        return IntervalSet(p_hat - q, p_hat + q)

    def worst_case_risk(self, m, K, z, batch_id, risk_fn):
        U = minkowski_sum(self.batch_interval(m, batch_id),
                          self.conformal_set(m, z, batch_id))
        return max(risk_fn(m, K, z, p) for p in U.corner_samples())
```

### IP-165 DLC（蒸馏生命周期）

```python
class DistillationLifecycle:
    def __init__(self, delta_drift=0.05, delta_cov=0.02, window=200):
        self.dd, self.dc, self.W = delta_drift, delta_cov, window
        self.live = deque(maxlen=window)

    def observe(self, feature):
        self.live.append(feature)

    def check(self, mdp, batch_id, certified_versions):
        if batch_id not in mdp.q_by_batch:
            return 'TEACHER_QUERY'
        psi = mmd(self.live, mdp.ref_distribution(batch_id))
        cov_hat = empirical_coverage(self.live, mdp, batch_id)
        if psi > self.dd or cov_hat < 1 - mdp.alpha - self.dc:
            candidate = retrain_student(mdp)
            if validate(candidate) and candidate.hash in certified_versions:
                return 'PROMOTE'
            return 'ROLLBACK'
        return 'HOLD'
```

### IP-166 SERCL+（材料-蒸馏接地闭环）

```python
def scene_material_distillation_loop(M, intent, delta_f_req):
    z, conf = M.ssm.update(M.telem_force, M.telem_pos)           # 第 60 轮 SSM
    U = {}
    for m in M.budget.available_materials():
        C = M.mdp.conformal_set(m, z, M.budget.batch[m])
        if C is None:
            m, K, status = M.msc.conservative(M, z, delta_f_req)  # teacher query path
            return M, m, K, None, status
        U[m] = minkowski_sum(M.mcm.batch_interval(m, M.budget.batch[m]), C)
    m_star, K_adm, status = M.msc.select(z, delta_f_req, uncertainty=U)
    if status == 'DEGRADE_MATERIAL':
        return M, None, None, None, status
    M.intent_ctrl.receive_intent(intent)                          # 第 60 轮 CIEC
    K_safe = M.eeis.compile(delta_f_req, admissible=K_adm)
    telemetry = M.execute(m_star, K_safe)
    ev = build_exec_evidence(telemetry, material=m_star, batch=M.budget.batch[m_star])
    mdc = M.certify(m_star, M.budget.batch[m_star], M.mdp.d_cert)
    M.epir.push(ev, mdc)                                          # 第 60 轮 EPIR
    M.sic.update(z, K_safe, ev)
    action = M.dlc.check(M.mdp, M.budget.batch[m_star], M.certified_versions)
    if action in ('TEACHER_QUERY', 'PROMOTE', 'ROLLBACK'):
        M.budget.spend_distill(action)
    return M, m_star, K_safe, mdc, status
```

```python
class DualSourceBudget:
    def __init__(self, mat, distill, cog):
        self.mat = mat          # inventory / trial / wear / calib
        self.distill = distill  # query / compute / recalib
        self.cog = cog          # 第 60 轮认知预算
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MCM | O(M·d) 属性预测/周期 | O(M·d) | 材料属性误差 ≤ δ_m；K_adm 保守 |
| MSC | O(M·(|U|+|C|)) 筛选 + O(T_BO) 探索 | O(M·|U|) | r_wc ≤ ε_safe 时物理违约概率 ≤ α+δ_m |
| SDT | 离线 O(|D|·|θ|)；在线 O(1) | O(|θ|) student | 风险低估 ≤ q_{1−α}，覆盖 ≥ 1−α |
| MDP/DLC | O(|C_α|) 区间运算；漂移 O(1) 摊销 | O(|B_cal|) | 批次 OOD 必拒；漂移检测 ≤ δ_t |
| SERCL+ | O(闭环) + O(M·|U|) | 复用 | 双源不确定下无安全违约 |

**正确性定理（MDGL）**：假设 A66–A70 成立：
**(A66)** MCM：材料属性 p(m) 落在批次区间 P_batch(m) 内，接触阻抗模型误差 ≤ δ_m；**(A67)** MSC：最坏风险 r_wc 是真实风险的上界（保守风险模型），可行域非空时 (m*,K*) ∈ F；**(A68)** SDT：teacher 安全集包含真实安全集，student 风险满足 P(r_S ≥ r_T − q_{1−α}) ≥ 1−α；**(A69)** MDP：同一材料批次内样本可交换，保形集满足 P(p ∈ C_α) ≥ 1−α；**(A70)** DLC：漂移检测在 δ_t 内以概率 ≥ 1−β 捕获分布偏移，认证版本集 V_cert 只含通过验证的 student。

则：
1. **材料安全界**：若 (m*,K*) ∈ F 且 r_wc ≤ ε_safe，则真实执行的不安全概率 ≤ α + δ_m + δ_t + β。证明：真实 p 同时落入 P_batch 与 C_α 的概率 ≥ 1−α−δ_m，其上 r_wc 为上界，漂移漏检概率 ≤ β。
2. **蒸馏保守性**：student 的风险低估不超过 q_{1−α}，且 q 随校准集增大单调收紧；SDT 不会在 1−α 置信下把 teacher 判为危险的动作判为安全。
3. **证据可审计性**：MDC 绑定 (material_id, batch_id, student_hash, teacher_hash, α, q, coverage)；未校准批次、未认证版本或漂移超限均使 MDC_valid=false，EV-exec 降级为条件合规，不进入强证据集。
4. **预算安全性**：B_mat 或 B_distill 耗尽触发 CERTIFIED_MATERIAL_ONLY / FROZEN_STUDENT，禁止在新材料/新模型上继续探索，回到已证安全子集。

### IP-161 MCM（材料能力模型）

```python
class MaterialCapabilityModel:
    def __init__(self, catalog):
        self.catalog = catalog  # {m_id: {E,nu,eta,mu_s,mu_k,kth,wear,cost,batch_tol,...}}

    def contact_impedance(self, m, A=1e-4):
        p = self.catalog[m]
        Kc = p['cK'] * p['E'] * np.sqrt(A) / (1 - p['nu']**2)
        Bc = p['cB'] * p['eta'] * A
        return Kc, Bc

    def damage_threshold(self, m, n_wear):
        p = self.catalog[m]
        return p['sigma_damage'] * p['A_contact'] * (1 - p['wear'] * n_wear)

    def admissible_set(self, m, z, n_wear):
        p = self.catalog[m]
        return {
            'm': m,
            'K_range': (p['K_min'], p['K_max']),
            'mu': p['mu_k'],
            'F_damage': self.damage_threshold(m, n_wear),
            'T_max': p['T_max'],
            'wear_rate': p['wear'],
            'cost': p['cost'],
        }

    def batch_interval(self, m, batch):
        p = self.catalog[m]
        tol = p['batch_tol']
        n_wear = self.wear_counter.get(m, 0)
        lo = np.array([p[k] * (1 - tol[k] * (1 + p['wear'] * n_wear)) for k in tol])
        hi = np.array([p[k] * (1 + tol[k] * (1 + p['wear'] * n_wear)) for k in tol])
        return BoxSet(lo, hi)
```

### IP-162 MSC（材料-阻抗共选）

```python
class MaterialImpedanceCoSelector:
    def __init__(self, mcm, risk_model, budgets, eps_safe=1e-2):
        self.mcm, self.risk, self.B, self.eps = mcm, risk_model, budgets, eps_safe

    def robust_uncertainty(self, m, z, batch, alpha):
        P_batch = self.mcm.batch_interval(m, batch)
        C_alpha = self.risk.conformal_set(m, z, batch, alpha)   # student model
        return minkowski_sum(P_batch, C_alpha)

    def select(self, z, delta_f_req):
        feasible = []
        for m in self.B.available_materials():
            if self.B.inventory[m] <= 0:
                continue
            adm = self.mcm.admissible_set(m, z, self.B.n_wear.get(m, 0))
            U = self.robust_uncertainty(m, z, self.B.batch[m], self.B.alpha)
            K = self._robust_compile(adm, U, delta_f_req)
            if K is None:
                continue
            r_wc = max(self.risk.slip(m, K, z, p) for p in U.samples())
            if r_wc > self.eps:
                continue
            feasible.append((m, K, r_wc, adm['cost'], adm['wear_rate']))
        if not feasible:
            return ('DEGRADE_MATERIAL', None, None)
        m, K, _, _, _ = min(
            feasible,
            key=lambda x: self.B.lam_D * self.risk.exec_discrepancy(x[0], x[1], z)
                          + self.B.lam_w * x[4] + self.B.lam_c * x[3])
        return (m, K, 'ROBUST_FEASIBLE')

    def _robust_compile(self, adm, U, delta_f_req):
        K_lo = max(adm['K_range'][0], max(p['K_min_real'] for p in U.samples()))
        K_hi = min(adm['K_range'][1], min(p['K_max_safe'] for p in U.samples()))
        if K_lo > K_hi:
            return None
        return clip(EEIS.compile(delta_f_req), K_lo, K_hi)
```

### IP-163 SDT（安全蒸馏）

```python
class SafeDistiller:
    def __init__(self, teacher, student, alpha=0.05, eps_r=1e-3, lam_safe=2.0):
        self.T, self.S, self.alpha, self.eps_r, self.lam = teacher, student, alpha, eps_r, lam_safe
        self.q = None

    def safety_loss(self, s, a):
        rT, safe_set = self.T.risk_and_safe_set(s)
        rS = self.S.risk(s, a)
        under = torch.relu(rT - rS - self.eps_r)          # 禁止 student 更乐观
        near = torch.relu(self.T.margin(s, a) - self.eps_r)
        return under + near

    def train(self, D_T, D_cal, epochs=50):
        for _ in range(epochs):
            for s, a in D_T:
                loss = task_loss(self.S(s), a) + self.lam * self.safety_loss(s, a)
                loss.backward(); opt.step()
        scores = [self.S.risk(s, a) - self.T.risk(s, a) for s, a in D_cal]
        self.q = np.quantile(scores, 1 - self.alpha)
        cov = np.mean([self.S.risk(s, a) >= self.T.risk(s, a) - self.q for s, a in D_cal])
        return DistillCertificate(self.S.hash, self.T.hash, self.alpha, self.q, cov)
```

### IP-164 MDP（材料蒸馏先验）

```python
class MaterialDistillationPrior:
    def __init__(self, teacher_phys, student_phys, alpha=0.05):
        self.T, self.S, self.alpha = teacher_phys, student_phys, alpha
        self.q_by_batch = {}

    def calibrate_batch(self, batch_id, D_cal_batch):
        scores = [abs(self.S.predict(m, z) - self.T.predict(m, z)) for m, z in D_cal_batch]
        self.q_by_batch[batch_id] = np.quantile(scores, 1 - self.alpha)

    def conformal_set(self, m, z, batch_id):
        if batch_id not in self.q_by_batch:
            return None                     # OOD -> teacher query
        q = self.q_by_batch[batch_id]
        p_hat = self.S.predict(m, z)
        return IntervalSet(p_hat - q, p_hat + q)

    def worst_case_risk(self, m, K, z, batch_id, risk_fn):
        U = minkowski_sum(self.batch_interval(m, batch_id),
                          self.conformal_set(m, z, batch_id))
        return max(risk_fn(m, K, z, p) for p in U.corner_samples())
```

```python
class DistillationLifecycle:
    def __init__(self, delta_drift=0.05, delta_cov=0.02, window=200):

        self.live = deque(maxlen=window)

            return 'ROLLBACK'
        return 'HOLD'
```

```python
def scene_material_distillation_loop(M, intent, delta_f_req):
    z, conf = M.ssm.update(M.telem_force, M.telem_pos)           # 第 60 轮 SSM
    U = {}
    for m in M.budget.available_materials():
        C = M.mdp.conformal_set(m, z, M.budget.batch[m])
        if C is None:
            m, K, status = M.msc.conservative(M, z, delta_f_req)  # teacher query path
            return M, m, K, None, status

    m_star, K_adm, status = M.msc.select(z, delta_f_req, uncertainty=U)
    if status == 'DEGRADE_MATERIAL':
        return M, None, None, None, status
    M.intent_ctrl.receive_intent(intent)                          # 第 60 轮 CIEC
    K_safe = M.eeis.compile(delta_f_req, admissible=K_adm)
    telemetry = M.execute(m_star, K_safe)

    mdc = M.certify(m_star, M.budget.batch[m_star], M.mdp.d_cert)
    M.epir.push(ev, mdc)                                          # 第 60 轮 EPIR
    M.sic.update(z, K_safe, ev)
    action = M.dlc.check(M.mdp, M.budget.batch[m_star], M.certified_versions)
    if action in ('TEACHER_QUERY', 'PROMOTE', 'ROLLBACK'):
        M.budget.spend_distill(action)
    return M, m_star, K_safe, mdc, status
```

| E196 端到端 | vs 第 60 轮：材料切换适应时间、双源违约率、MDC 通过率、ΔECE | −40%；≤ α；≥ 99.9%；ΔECE ≥ 20% |

## 5. 本轮最大风险

**一句话**：蒸馏 student 在材料批次分布漂移下仍保持高置信（校准集与真实批次不同源），会让 MSC 用错误的材料能力集提前锁定 K_safe 并跳过 teacher 查询，使「物理材料误差 × 认知蒸馏误差」在非线性接触映射下被严重低估——必须以「批次校准标签」「保形覆盖校验」「双源不确定性最坏界」「强制 teacher 回退」四重护栏阻断这一乘积风险，否则「物理先行」会变成「物理自信地走向失效」。
