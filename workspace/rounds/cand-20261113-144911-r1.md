# 第 68 轮（承接第 67 轮「SimRAS 仿真增强闭环」IP-233~242；灵感循环第 1 轮；本轮灵感：「智能体」×「对话管理」）

> 第 66 轮 RAS 把闭环从「被动故障响应」升级为「主动意图感知」；第 67 轮 SimRAS 又把它升级为「离线仿真预训练 + 世界模型前瞻 + 视觉问答审计」。两轮都在追问：**风险如何被看见、被预测、被审计**。
>
> 但它们共享一个隐蔽假设：**机器人是一个独白式的单体**。它在内部完成归因、探针、预测、审计，然后执行；人只被当作「情绪信号源」或「被审计的对象」，而不是**共同决策者**。
>
> 本轮灵感「智能体 × 对话管理」精准击中这个盲区：真实共享自主不是独白，而是**对话**——人机必须持续就「目标是什么、谁握控制权、这一步是否被认可、误解如何修复」建立**共同基础（common ground）**。一个动作即使安全，只要**未被双方确认**，在共享自主里仍然是失败。
>
> 核心命题：
>
> **把「认证前缀」升级为「承诺前缀」：控制动作只有在（a）安全且（b）被共同确认（grounded）时才被认证执行；把物理探针与口头澄清统一为同一类「信息价值（VoI）驱动的认知动作」，用对话管理为共享控制提供可审计的承诺语法（CoRAS: Conversational Risk-aware Adaptive Closure）。**
>
> CoRAS 问的不再是「谁控制、控制多少」，而是「**凭什么执行、谁同意了、我们是否在同一页上**」。

## 0. 直觉与动机

**灵感 1（智能体 → 承诺是能动性的最小单位）**
直觉：一个「控制器」与一个「智能体」的差别，不在于是否会规划，而在于**能否做出承诺并为之负责**。多智能体系统之所以需要通信，是因为承诺无法靠共享内存自动同步。若机器人执行了人类从未确认的动作，它不是自主（autonomous），而是任意（arbitrary）。因此，**智能体的控制权必须由承诺派生，而不能被默认拥有**。

**灵感 2（对话管理 → 控制权的语法）**
直觉：对话管理不是「说话好听」，而是一套**协调多方承诺的机制**。它恰好提供了共享控制缺的那套语法：
- **轮次（turn-taking）** ↔ 控制权交接：谁持有「话轮 / 控制轮」；
- **共同基础（grounding）** ↔ 认证：双方是否确认「我们说的是同一件事」；
- **澄清（clarification）** ↔ 探针：信息不足时主动索取；
- **修复（repair）** ↔ 故障恢复：发现误解/故障后回滚并重建一致；
- **言语行为（speech act）** ↔ 控制承诺：请求 / 确认 / 拒绝 / 许诺；
- **对话状态跟踪（DST）** ↔ 故障/意图后验：对隐藏状态做贝叶斯信念更新。

**灵感 3（结构同构）**

| 对话管理 | 共享控制映射 | 现有组件（第 66–67 轮） |
|---|---|---|
| DST 信念更新 | 故障-情绪联合后验 | EFS / EFS-WM |
| 对话策略 | 控制权仲裁 | RAS 的 λ_risk / k* |
| Grounding | 认证（动作被共同确认） | C-RAS / C-RAS-WM |
| Clarification | 主动探针 | FAS |
| Repair | 故障恢复 / 回滚 | AIC 的保守回退 |
| Turn-taking | 控制权交接 | 缺 |
| Speech act | 承诺 / 授权 | 缺 |

这张表说明：RAS/SimRAS 已经有了「信念」与「认证」，但**缺了「授权」与「交接」**——而这两者正是对话管理的核心。

**灵感 4（认知动作的统一）**
直觉：FAS 的 emotion probe 是「花时间去看」，对话澄清是「花时间去问」。二者本质相同：都是 POMDP 中的 **epistemic action**，都用「信息价值 − 成本」来决策。把它们统一后，系统不必预设「先探针、后对话」，而是让**物理探针、口头提问、减速等待、请求接管**在同一个 VoI 排序里竞争。这是本轮最有解释力的统一。

**灵感 5（合流 → CoRAS）**
CoRAS = (SAX, DST, CGL, TAR, CRP, REP, CAC, RAS-WM)：
1. **SAX** 把话语解析为言语行为与承诺；
2. **DST** 维护 `(用户目标, 控制权, 共同基础状态)` 的信念；
3. **CGL** 用只追加账本记录「已共同确认的动作集合」，为证书提供可审计根；
4. **TAR** 依据信念与风险仲裁控制权（HUMAN / SHARED / AGENT）；
5. **CRP** 以 VoI 统一选择物理探针或对话澄清；
6. **REP** 在误解 / 故障时进入有界修复；
7. **CAC** 把认证前缀收缩为「安全 ∧ 已 grounded」的承诺前缀 `k*CoRAS`；
8. **RAS-WM** 提供原有的安全 / 前瞻 / 审计底座。

**灵感 6（组件升级）**
- **FIR → DST**：后验从「故障」扩展到「故障 × 意图 × 控制权 × 共同基础」；
- **FAS → CRP**：探针集合扩充为物理 + 语言两类认知动作；
- **CSC → CAC**：`k*CoRAS = min(k_VISTA, k_emo, k_wm, k_ground)`，未 grounded 的动作只能进入「影子计划」或请求确认；
- **J_RAS → J_CoRAS**：证书新增 `cgl_root / dialogue_state_hash / grounded_prefix / authority / repair_count`；
- **AIC → AIC-CoRAS**：干扰集新增 `ℰ_dialogue = {ASR 误识, 语用歧义, 反讽/胁迫, 提示注入, 确认疲劳, 冒充/重放}`；
- **ERS → TAR**：控制塑造不再只是力/风险缩放，而是「控制权—承诺窗口」的联合调度。

## 1. 形式化定义（增量：定义 266–285）

- **定义 266（CoRAS 总览）** `CoRAS = (SAX, DST, CGL, TAR, CRP, REP, CAC, RAS-WM)`。不变式：语音/文本解析、DST 更新、账本写入只在语义流；实时流仅消费 `k_ground`、`authority`、`early_stop` 三个标量，零学习写操作。
- **定义 267（对话轮）** `turn_t = (speaker_t, u_t, σ_t, c_t)`，`σ_t ∈ Σ = {REQUEST, INFORM, CONFIRM, DISCONFIRM, PROMISE, ACK, CLARIFY, REJECT}`；`c_t` 为承诺内容（可为空）。
- **定义 268（对话状态）** `s_t = (g, a, γ)`：目标 `g ∈ G`，控制权 `a ∈ {HUMAN, AGENT, SHARED}`，共同基础 `γ ∈ {UNGROUNDED, PROPOSED, GROUNDED, RETRACTED}`。信念 `b_t(s) = P(s | u_{1:t}, ρ_{1:t})`。
- **定义 269（DST 更新）** `b_t(s') ∝ O(u_t | s') · Σ_s T(s' | s, σ_t) · b_{t-1}(s)`，`T` 由相邻对（adjacency pair）约束：REQUEST 期待 CONFIRM/REJECT，PROPOSE 期待 ACCEPT/REJECT。
- **定义 270（共同基础账本 CGL）** 只追加链 `L_t = L_{t-1} ⊕ (c_t, proof_t)`，`proof_t = (speaker, σ_t, nonce, channel_binding, H(L_{t-1}))`。`grounded_actions(L_t)` 返回所有有效承诺覆盖的动作。
- **定义 271（承诺）** `c = (owner, act_set, scope, expiry, auth)`；`valid(c, t) ⇔ t ≤ expiry(c) ∧ auth(c) = ⊤`。
- **定义 272（控制权仲裁 TAR）** `a_t* = argmax_a E_{b_t}[U(a; g, risk)]`，约束「高风险 ⇒ 不得纯 AGENT」。当 `P(a=HUMAN) > τ_handover` 或 `risk > τ_risk` 时向人类交权。
- **定义 273（承诺认证前缀）** `k*CoRAS = min(k_VISTA, k_emo, k_wm, k_ground, m)`，其中 `k_ground = max{k : ∀i ≤ k, A_i ∈ grounded_actions(L_t)}`。
- **定义 274（认知动作与信息价值）** `q ∈ Q_phys ∪ Q_verbal`。`VoI(q) = E_{o~q}[V(b') − V(b)] − cost(q)`；CRP 选 `q* = argmax VoI(q)`，仅当 `VoI(q*) > τ_voi` 才执行。
- **定义 275（澄清请求策略 CRP）** `Q_verbal = {"继续吗?", "要我接管吗?", "刚才那步对吗?"}`，`Q_phys = {head_tilt, eye_contact, micro_expression, slow_down}`；两类动作同池竞争。
- **定义 276（修复协议 REP）** 触发条件 `mismatch = (执行动作 ∉ 承诺) ∨ (fault_post > τ) ∨ (utterance 与承诺冲突)`；流程：暂停 → 诊断 → 提议 → 确认 → 恢复，最多 `R_max` 轮。
- **定义 277（言语行为识别 SAX）** `σ_t = SAX(u_t, ctx)`；标定要求 `ECE(SAX) ≤ 0.05`，歧义度 `H(σ_t) > τ_ambig` 时强制降级为 CLARIFY。
- **定义 278（承诺窗口）** `W_t = [t, t + k*CoRAS)`；窗口外动作必须重新协商，禁止「越窗执行」。
- **定义 279（对话证书 J_CoRAS）** `J_CoRAS = (J_SimRAS, cgl_root, dialogue_state_hash, grounded_prefix, authority, repair_count)`；`Valid ⇔ Valid(J_SimRAS) ∧ (authority ≠ AGENT ∨ grounded_prefix ≥ 1) ∧ ¬replayed`。
- **定义 280（AIC-CoRAS 干扰集）** `ℰ_CoRAS = ℰ_SimRAS × ℰ_dialogue`，`ℰ_dialogue = {ASR 误识, 语用歧义, 反讽/胁迫, 提示注入, 确认疲劳, 冒充/重放}`。
- **定义 281（确认疲劳检测）** 若 `P(CONFIRM | u) > 1−ε` 且响应时延 `< τ_fast` 且与内容无关，则标记 `rubber_stamp = True`，后续高风险动作必须走 challenge-response。
- **定义 282（防重放/冒充）** 承诺绑定 `nonce + channel_binding`；跨会话重放视为无效，`replayed = True`。
- **定义 283（对话有效性）** `DV = 1 − (unauthorized_execution_rate + ungrounded_commit_rate)`。
- **定义 284（相邻对完整性）** 每个 REQUEST/PROPOSE 必须有配对的 CONFIRM/REJECT/ACCEPT；缺失时状态为 `PENDING`，超时后保守回退（HOLD 或 HUMAN）。
- **定义 285（CoRAS 在线不变式）** 实时流只允许执行 `A[:k*CoRAS]`；`k_ground = 0` 时禁止自主执行，必须 HOLD 或交权。

## 2. 关键算法骨架

```python
class SpeechActExtractor:              # IP-243
    def parse(self, u, ctx):
        dist = self.model(u, ctx)      # over Σ
        if entropy(dist) > self.tau_ambig:
            return {'act': 'CLARIFY', 'ambiguous': True}
        return {'act': argmax(dist), 'p': max(dist), 'dist': dist}


class DialogueStateTracker:            # IP-244
    def update(self, b, sigma, obs):
        nxt = {s2: self.O(obs, s2) *
                   sum(self.T(s2, s1, sigma) * b[s1] for s1 in self.S)
               for s2 in self.S}
        return normalize(nxt)


class CommonGroundLedger:              # IP-245
    def commit(self, c, speaker, act):
        if act not in ('PROMISE', 'CONFIRM', 'ACCEPT'):
            return False
        proof = (speaker, act, c.nonce, self.channel, self.root())
        self.chain.append((c, proof))
        return True

    def grounded(self, action, t):
        return any(action in c.act_set and c.valid(t) for c, _ in self.chain)


def arbitrate(b, risk, cfg):           # IP-246 TAR
    p_h = sum(p for s, p in b.items() if s.authority == 'HUMAN')
    if risk > cfg.tau_risk or p_h > cfg.tau_handover:
        return 'HUMAN'
    return 'SHARED' if max(b.values()) < cfg.tau_conf else 'AGENT'


class ClarificationRequestPolicy:      # IP-247 CRP
    def choose(self, b, Q, value_fn, cost_fn):
        best, best_voi = None, -float('inf')
        for q in Q:
            b2 = self.expected_belief(b, q)
            voi = value_fn(b2) - value_fn(b) - cost_fn(q)
            if voi > best_voi:
                best, best_voi = q, voi
        return (best, best_voi) if best_voi > self.tau_voi else (None, best_voi)


def certified_prefix_coras(A, k_ras, ledger, t, m):   # IP-249 CAC
    k_ground = 0
    for i, a in enumerate(A[:m]):
        if ledger.grounded(a, t + i):
            k_ground = i + 1
        else:
            break
    return min(k_ras, k_ground, m)
```

## 3. 推导

**引理 13（DST 后验收缩）** 若 `T` 对核范数 ρ-压缩、观测似然有界，则 `||b_t − b*_t||_TV ≤ ρ^t ||b_0 − b*_0|| + ε_obs/(1−ρ)`。含义：对话再长，信念误差也有上界，不会因轮数增加而发散。

**引理 14（承诺单调性）** 在一个无 REP 的修复纪元内，`grounded_actions(L_t)` 单调不减，故 `k_ground` 单调不减。含义：**多一轮对话不会让已确认的动作变少**（除非显式撤回），这保证了「对话是增益而非负担」。

**引理 15（认知动作的信息下界）** 若 `b` 校准且 `q` 与隐藏状态 `s` 条件互信息为 `I(s; o_q)`，则 `VoI(q) ≥ I(s; o_q) − cost(q) − ε_cal`。含义：当探针/提问几乎不提供信息时，系统会自然选择「不问、直接保守执行」。

**定理 14（承诺-安全一致性）** 在不变式「执行 ⊆ 已 grounded」下：
1. `P(执行动作 ∉ 共同基础) ≤ α_sax + δ_dst + α_chunk`；
2. `k_ground = 0 ⇒ 不产生自主执行`；
3. `authority = HUMAN ⇒ 控制指令来自人类，CoRAS 仅提供安全屏蔽`。

**定理 15（对话不降低安全性）** 在正确的成本模型与保守回退下，CoRAS 的期望安全违规不高于仅探针的 FAS：`E[Violation_CoRAS] ≤ E[Violation_FAS] − VoI_adopted + ε_model`。即**对话若有用则收益为正，若没用则 VoI 自动把它关掉**。

**定理 16（修复终止性）** 在有限状态空间与合作型用户下，REP 至多 `min(R_max, |S|)` 轮终止并恢复一致 grounded 状态；对抗型用户下无界，故必须设 `R_max` 并在超时后保守回退。

**定理 17（对话延迟的实时隔离）** 由于语义流只向实时流暴露 `k_ground / authority / early_stop`，且动作按**承诺窗口**成批预授权，实时环路延迟保持 `<3ms`，与对话轮次解耦。

## 6. 本轮最大风险

**一句话**：CoRAS 把「安全」建立在「共同基础」之上，但共同基础本身是可被伪造的社会事实——确认疲劳（人机械地点"同意"）、语用歧义、反讽/胁迫、提示注入与重放，都会让系统**把"看起来被同意"误当成"真的被授权"**，于是承诺账本为危险动作签发了合法证书，形成比单纯误判更隐蔽的「同意洗白（consent laundering）」；这是本轮所有理论依赖的核心假设：**言语行为能可靠反映真实意图与控制权，且共同基础无法被社会工程或疲劳批量制造。**

## 2. 形式化定义（完整版）

**定义 266（CoRAS 总览）** CoRAS 是 RAS/SimRAS 的「独白式安全」向「对话式承诺安全」的升级：
```
CoRAS = (SAX, DST, CGL, TAR, CRP, REP, CAC, RAS-WM)
```
不变式：语音/文本解析、DST 更新、账本写入只在语义流；实时流仅消费 `k_ground`、`authority`、`early_stop` 三个标量，零学习写操作。

**定义 267（对话轮）** `turn_t = (speaker_t, u_t, σ_t, c_t)`，其中 `σ_t ∈ Σ = {REQUEST, INFORM, CONFIRM, DISCONFIRM, PROMISE, ACK, CLARIFY, REJECT}`，`c_t` 为承诺内容（可为空）。

**定义 268（对话状态）** `s_t = (g, a, γ)`：目标 `g ∈ G`，控制权 `a ∈ {HUMAN, AGENT, SHARED}`，共同基础 `γ ∈ {UNGROUNDED, PROPOSED, GROUNDED, RETRACTED}`。信念：
```
b_t(s) = P(s | u_{1:t}, ρ_{1:t})
```

**定义 269（DST 更新）**
```
b_t(s') ∝ O(u_t | s') · Σ_s T(s' | s, σ_t) · b_{t-1}(s)
```
`T` 由相邻对约束：REQUEST 期待 CONFIRM/REJECT，PROPOSE 期待 ACCEPT/REJECT。

**定义 270（共同基础账本 CGL）** 只追加链 `L_t = L_{t-1} ⊕ (c_t, proof_t)`，`proof_t = (speaker, σ_t, nonce, channel_binding, H(L_{t-1}))`。`grounded_actions(L_t)` 返回所有有效承诺覆盖的动作。

**定义 271（承诺）** `c = (owner, act_set, scope, expiry, auth)`；`valid(c, t) ⇔ t ≤ expiry(c) ∧ auth(c) = ⊤`。

**定义 272（控制权仲裁 TAR）** `a_t* = argmax_a E_{b_t}[U(a; g, risk)]`，约束「高风险 ⇒ 不得纯 AGENT」。当 `P(a=HUMAN) > τ_handover` 或 `risk > τ_risk` 时向人类交权。

**定义 273（承诺认证前缀）**
```
k*CoRAS = min(k_VISTA, k_emo, k_wm, k_ground, m)
k_ground = max{k : ∀i ≤ k, A_i ∈ grounded_actions(L_t)}
```

**定义 274（认知动作与信息价值）** `q ∈ Q_phys ∪ Q_verbal`：
```
VoI(q) = E_{o~q}[V(b') − V(b)] − cost(q)
```
CRP 选 `q* = argmax VoI(q)`，仅当 `VoI(q*) > τ_voi` 才执行。

**定义 275（澄清请求策略 CRP）** `Q_verbal = {"继续吗?", "要我接管吗?", "刚才那步对吗?"}`，`Q_phys = {head_tilt, eye_contact, micro_expression, slow_down}`；两类动作同池竞争。

**定义 276（修复协议 REP）** 触发 `mismatch = (执行动作 ∉ 承诺) ∨ (fault_post > τ) ∨ (utterance 与承诺冲突)`；流程：暂停 → 诊断 → 提议 → 确认 → 恢复，最多 `R_max` 轮。

**定义 277（言语行为识别 SAX）** `σ_t = SAX(u_t, ctx)`；标定要求 `ECE(SAX) ≤ 0.05`，歧义度 `H(σ_t) > τ_ambig` 时强制降级为 CLARIFY。

**定义 278（承诺窗口）** `W_t = [t, t + k*CoRAS)`；窗口外动作必须重新协商，禁止越窗执行。

**定义 279（对话证书 J_CoRAS）**
```
J_CoRAS = (J_SimRAS, cgl_root, dialogue_state_hash, grounded_prefix, authority, repair_count)
```
`Valid ⇔ Valid(J_SimRAS) ∧ (authority ≠ AGENT ∨ grounded_prefix ≥ 1) ∧ ¬replayed`。

**定义 280（AIC-CoRAS 干扰集）** `ℰ_CoRAS = ℰ_SimRAS × ℰ_dialogue`，`ℰ_dialogue = {ASR 误识, 语用歧义, 反讽/胁迫, 提示注入, 确认疲劳, 冒充/重放}`。

**定义 281（确认疲劳检测）** 若 `P(CONFIRM | u) > 1−ε` 且响应时延 `< τ_fast` 且与内容无关，则标记 `rubber_stamp = True`，后续高风险动作必须走 challenge-response。

**定义 282（防重放/冒充）** 承诺绑定 `nonce + channel_binding`；跨会话重放视为无效，`replayed = True`。

**定义 283（对话有效性）** `DV = 1 − (unauthorized_execution_rate + ungrounded_commit_rate)`。

**定义 284（相邻对完整性）** 每个 REQUEST/PROPOSE 必须有配对的 CONFIRM/REJECT/ACCEPT；缺失时状态为 `PENDING`，超时后保守回退（HOLD 或 HUMAN）。

**定义 285（CoRAS 在线不变式）** 实时流只允许执行 `A[:k*CoRAS]`；`k_ground = 0` 时禁止自主执行，必须 HOLD 或交权。

**定义 286（多用户权威冲突）** 当 `|speakers| > 1` 时，权威为向量 `a = (a_1, ..., a_n)`；冲突消解按「角色优先级 × 风险方向」：高风险动作需最高优先级发言者确认，低风险动作可由任意已授权者确认。

**定义 287（承诺摊销）** 一次交换可预授权一个窗口 `|W_t| = k`，使对话频率降至约 `1/k`；`k` 由任务可预测性与 `τ_voi` 共同决定。

**定义 288（语义流 / 实时流接口）** 语义流每轮只输出三元组 `(k_ground, authority, early_stop)`；实时流不得读取原始 utterance 或账本，保证实时性与攻击面隔离。

**定义 289（信任校准）** `TC = 1 − |trust_reported − trust_actual|`，其中 `trust_actual` 由实证安全率估计；过度信任（over-trust）定义为 `trust_reported > trust_actual + 0.2`。

**定义 290（CoRAS 与 SimRAS 的关系）** CoRAS 是 SimRAS 的上层治理外壳，不替代其证书，而是**收窄其执行集**：`execute ⊆ grounded ∧ safe ⊆ safe`。因此 `Valid(J_CoRAS) ⇒ Valid(J_SimRAS)`，反之不成立。

# IP-243 SAX：言语行为识别
class SpeechActExtractor:
    def __init__(self, model, tau_ambig=0.6):
        self.model, self.tau_ambig = model, tau_ambig

    def parse(self, utterance, context):
        dist = self.model(utterance, context)      # over Σ
        if entropy(dist) > self.tau_ambig:
            return {'act': 'CLARIFY', 'ambiguous': True, 'dist': dist}
        return {'act': argmax(dist), 'p': max(dist), 'dist': dist}


# IP-244 DST：对话状态跟踪
class DialogueStateTracker:
    def __init__(self, S, T, O):
        self.S, self.T, self.O = S, T, O

    def init(self):
        return normalize({s: 1.0 for s in self.S})

    def update(self, b_prev, sigma, obs):
        nxt = {}
        for s2 in self.S:
            nxt[s2] = self.O(obs, s2) * sum(
                self.T(s2, s1, sigma) * b_prev[s1] for s1 in self.S)
        return normalize(nxt)


# IP-245 CGL：共同基础账本
class CommonGroundLedger:
    GENESIS = '0' * 64

    def __init__(self, channel):
        self.chain, self.channel = [], channel

    def root(self):
        return self.chain[-1][1][-1] if self.chain else self.GENESIS

    def commit(self, c, speaker, act):
        if act not in ('PROMISE', 'CONFIRM', 'ACCEPT'):
            return False
        proof = (speaker, act, c.nonce, self.channel, self.root())
        self.chain.append((c, proof))
        return True

    def grounded(self, action, t):
        return any(action in c.act_set and c.valid(t) for c, _ in self.chain)


# IP-246 TAR：控制权仲裁
def arbitrate(b, risk, cfg):
    p_human = sum(p for s, p in b.items() if s.authority == 'HUMAN')
    if risk > cfg.tau_risk or p_human > cfg.tau_handover:
        return 'HUMAN'
    if max(b.values()) < cfg.tau_conf:
        return 'SHARED'
    return 'AGENT'


# IP-247 CRP：VoI 驱动的认知动作选择
class ClarificationRequestPolicy:
    def __init__(self, tau_voi=0.1):
        self.tau_voi = tau_voi

    def choose(self, b, Q, value_fn, cost_fn):
        best, best_voi = None, -float('inf')
        for q in Q:
            b2 = self.expected_belief(b, q)
            voi = value_fn(b2) - value_fn(b) - cost_fn(q)
            if voi > best_voi:
                best, best_voi = q, voi
        return (best, best_voi) if best_voi > self.tau_voi else (None, best_voi)

    def expected_belief(self, b, q):
        out = {}
        for o, p_o in self.observation_model(q).items():
            for s, p_s in b.items():
                out[s] = out.get(s, 0.0) + p_o * self.posterior(s, q, o, b)
        return normalize(out)


# IP-248 REP：有界修复协议
def repair_protocol(M, mismatch, budget):
    for r in range(budget):
        M.hold()
        diag = M.diagnose(mismatch)
        proposal = M.propose_fix(diag)
        if M.await_confirmation(proposal):
            M.resume(proposal)
            return {'repaired': True, 'turns': r + 1}
    M.fallback_conservative()
    return {'repaired': False, 'turns': budget, 'fallback': True}


# IP-249 CAC：承诺认证前缀
def certified_prefix_coras(A, k_ras, ledger, t, m):
    k_ground = 0
    for i, a in enumerate(A[:m]):
        if ledger.grounded(a, t + i):
            k_ground = i + 1
        else:
            break
    return min(k_ras, k_ground, m)


# IP-252 CoRAS 在线环路
def CoRAS_round(M, obs, utterance, t):
    # 1) 原有 SimRAS 安全前向
    k_sim, λ_risk, joint_post, face_gate, wm_preds = M.simras.step(obs)

    # 2) 语义流：言语行为 → DST → 账本
    sigma = M.sax.parse(utterance, {'scene': obs, 'b': M.dst.b})
    M.dst.b = M.dst.update(M.dst.b, sigma['act'], {'utt': utterance})
    if sigma['act'] in ('CONFIRM', 'ACCEPT', 'PROMISE'):
        M.cgl.commit(extract_commitment(utterance), 'human', sigma['act'])

    # 3) 统一认知动作：探针 或 澄清
    Q = M.crp.physical_probes() + M.crp.verbal_questions(M.dst.b)
    q, voi = M.crp.choose(M.dst.b, Q, M.task_value, M.cost_model)
    if q is not None:
        obs_new = M.execute_epistemic(q)          # 物理探针或提问
        M.dst.b = M.dst.update(M.dst.b, 'INFORM', obs_new)
        k_sim, λ_risk, joint_post, face_gate, wm_preds = M.simras.step(obs_new)

    # 4) 控制权仲裁
    authority = arbitrate(M.dst.b, risk_from(joint_post), M.cfg)
    if authority == 'HUMAN':
        return {'mode': 'HUMAN', 'k': 0, 'authority': authority}
    if authority == 'SHARED':
        k_sim = min(k_sim, M.cfg.k_shared)

    # 5) 承诺前缀：安全 ∩ 已 grounded
    A = M.simras.current_chunk()
    m = min(M.vista.m, M.er.max_m_emotion)
    k_coras = certified_prefix_coras(A, k_sim, M.cgl, t, m)

    # 6) 未 grounded 部分：影子计划 or 请求确认
    if k_coras < k_sim:
        if M.crp.confirm_voi(A[k_coras:k_sim]) > M.crp.tau_voi:
            M.ask_confirmation(A[k_coras:k_sim])
            return {'mode': 'HOLD', 'k': k_coras, 'authority': authority}
        # 否则只执行已确认前缀，剩余降级为影子计划
    tau_cmd = M.simras.dispatch(A[:k_coras]) * λ_risk
    M.cgl.advance(t + k_coras)
    return {'mode': authority, 'k': k_coras, 'tau': tau_cmd,
            'authority': authority, 'cert': build_cert(M, k_coras, authority)}

## 4. 推导

**引理 13（DST 后验收缩）** 设状态转移核 `T(·|·, σ)` 在 TV 距离下为 `ρ`-压缩（`0 ≤ ρ < 1`），观测似然满足 `ε_obs = sup_{u,s} |O(u|s) − Ô(u|s)|`。则
```
||b_t − b*_t||_TV ≤ ρ^t ||b_0 − b*_0||_TV + ε_obs/(1−ρ)
```
含义：对话轮数增加不会使信念误差发散，给 DST 提供了稳定的收敛域。

**引理 14（承诺单调性）** 在一个无 REP 的修复纪元内，`grounded_actions(L_t)` 单调不减，因此 `k_ground(t)` 单调不减。含义：**多一轮对话不会减少已确认的动作**（除非显式撤回并开启新纪元），这保证对话是增益而非负担。

**引理 15（认知动作的信息下界）** 若 `b` 经校准且认知动作 `q` 与隐藏状态 `s` 的条件互信息为 `I(s; o_q)`，则
```
VoI(q) ≥ I(s; o_q) − cost(q) − ε_cal
```
含义：当探针/提问几乎不提供信息时，VoI 自动降到阈值以下，系统选择「不问、直接保守执行」。

**定理 14（承诺-安全一致性）** 在不变式「执行 ⊆ 已 grounded」下：
1. `P(执行动作 ∉ 共同基础) ≤ α_sax + δ_dst + α_chunk`；
2. `k_ground = 0 ⇒ 不产生自主执行`；
3. `authority = HUMAN ⇒ 控制指令来自人类，CoRAS 仅提供安全屏蔽`。

**定理 15（对话不降低安全性）** 在正确的成本模型与保守回退下，
```
E[Violation_CoRAS] ≤ E[Violation_FAS] − VoI_adopted + ε_model
```
即：对话若有用则收益为正；若无用，VoI 会把它自动关闭，因此 CoRAS 不会因「多问」而变差。

**定理 16（修复终止性）** 在有限状态空间 `|S| < ∞` 与合作型用户下，REP 至多 `min(R_max, |S|)` 轮终止并恢复一致 grounded 状态；对抗型用户会使终止性失效，故必须设 `R_max` 并在超时后保守回退。

**定理 17（对话延迟的实时隔离）** 语义流只向实时流暴露 `(k_ground, authority, early_stop)`，且动作按承诺窗口成批预授权（`|W_t| = k`），故实时环路延迟保持 `<3ms`，与对话轮次解耦；对话频率被稀释到约 `1/k`。

**定理 18（证书收缩）** `Valid(J_CoRAS) ⇒ Valid(J_SimRAS)`，且 `execute(CoRAS) ⊆ execute(SimRAS)`。含义：CoRAS 只收窄、不放大 SimRAS 的执行集，是安全的**保守精化**。

## 7. 本轮最大风险

**一句话**：CoRAS 把「安全」建立在「共同基础」之上，但共同基础本身是可被伪造的社会事实——确认疲劳（人机械地点"同意"）、语用歧义、反讽/胁迫、提示注入与重放，都会让系统**把"看起来被同意"误当成"真的被授权"**，于是承诺账本为危险动作签发了合法证书，形成比单纯误判更隐蔽的「同意洗白（consent laundering）」；这是本轮所有理论依赖的核心假设：**言语行为能可靠反映真实意图与控制权，且共同基础无法被社会工程或疲劳批量制造。**
