# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~302；新灵感循环第 1 轮；本轮灵感：「UniBot-V1」×「避障控制」）

> R73 把「证据」做成了契约、可组合、可审计，并把反作用从手写三层推广为模块声明的通道（深度相机是 L4：动作改变视角 → 改变噪声）。但 R73 有一个隐含前提：**测量者是我们自己**。证据从我们的传感器来，证书由我们的审计集签，安全界相对我们的执行体成立。
>
> 本轮两个灵感恰好把这个前提抽掉：
> - **UniBot-V1** 不是一个数据集，而是一台**远程黑箱仪器**：策略跑在参赛者自己的服务器上，评测方通过 WebSocket 连过来，在 N 台真实机器人上按随机顺序一次性执行 32 个桌面任务（4 路 RGB、双 7 轴臂、语言指令、joint/ee 两种控制空间、可返回动作分块）；官方同时记录响应延迟、延迟稳定性与动作规律性。于是「榜单数字」不是模型属性，而是 **（策略，网络，机队，场景采样，评分器）五者的联合读数**——一台我们不拥有、也无法完全观测的仪器给出的读数。
> - **避障控制** 是「安全 vs 泛化」的正面交点，也是远程评测最脆弱处：只有单目 RGB、没有深度，远程相机内外参未知，延迟可变，episode 一次性不可复现，机队异质，而成功率评分未必惩罚碰撞。一个「快而鲁莽」的策略完全可能比「稳而安全」的策略排名更高。
>
> 由此得到本轮核心命题：**不再问「模型在 UniBot-V1 上成功率多高」，而问「远程黑箱榜单给出的数字，能否成为一个带分辨率、带有效域、可被安全硬否决的测量——使避障安全在不可复现的一次性远程执行中仍然可证？」** 把 R73 的 MODGAUGE 再上提一层，扩展为 **OASIS-GAUGE**（Obstacle-Aware Safety under Instrumented Submission with GAUGE audits）——**评估仪器计量 × 单目避障安全 × 延迟预算 × 证书感知榜单**。
>
> 结构性后果是两条新通道：**L6 通信反作用**（动作分块长度 ↔ 有效延迟/抖动/丢包 ↔ 反应延迟 ↔ 安全裕度），以及 **L7 观察者反作用**（策略在榜单压力下会主动选择“可得分但高风险”的行为——评测规则本身改变了被评测对象）。L7 是 R73「动作改变噪声」之上的社会-技术版本：**规则改变策略**。

## 0. 直觉与动机

**直觉 1（榜单是一台未校准的仪器，不是一张成绩单）**
我们习惯把「A 模型 62%，B 模型 60%」当作事实。但换一个计量的问法：这个 2% 是**真实能力差**，还是**仪器噪声 + 机队差异 + 场景采样 + 延迟**？UniBot-V1 的结构决定了它同时含六种误差源：场景/物体采样（u_scene）、机队异质（u_embody）、评分歧义与步分（u_score）、网络延迟的系统效应（u_net，且与模型混淆）、一次性不可复现（u_oneshot）、远程相机标定未知（u_calib）。把这些压成一个成功率，等于把 R73 反复批判的「把 X 不确定度误读为 Y 不确定度」搬到了评测层：**把仪器不确定度误读为模型能力差**。第一性产物不是更高的分，而是**榜单的分辨率**（minimum detectable difference, MDD）。

**直觉 2（避障控制的正确安全量在单目下不是距离，而是时间）**
单目 RGB 无法给出度量深度：同一幅图像可以被缩放成任意尺度的场景（相似变换不可辨识）。任何依赖「障碍 1.2 米」的安全滤波都继承了尺度歧义。但 **time-to-contact τ 与 bearing (θ, θ̇) 是尺度不变的**：光流散度给出 1/τ，障碍框膨胀率给出 1/τ，方位角速率判别碰撞航向。于是避障安全应当建立在 (τ, θ, θ̇) 上，而不是伪造的度量距离。这是 R73「证据契约必须声明有效域」在**深度不可得**时的极端实例：不是「深度差」，而是「根本没有深度」——所以安全量的选择本身必须尺度不变。

**直觉 3（延迟不是工程细节，是可控的反作用通道 L6）**
UniBot-V1 允许返回**动作分块**。分块长度 N 是一个真实的控制杠杆：N 大 ⇒ 往返次数少、带宽省、抖动被摊薄，但机器人「盲走」更久，反应延迟 ≈ N/(2f_exec) + RTT/2；N 小 ⇒ 反应快，但请求频率高、丢包与抖动概率上升。也就是说，**策略自己的接口选择改变了它的安全裕度**（L6）。R73 的 χ_R 是「动作如何调制噪声」；L6 是「**接口如何调制执行延迟**」。这必须进契约、进预算、进安全约束，而不是留给工程调参。

**直觉 4（一次性执行 ⇒ 不可反事实 ⇒ 安全必须事前证明）**
每个 episode 在真实机器人上只跑一次，你无法事后重放「如果当时左转会怎样」。这颠倒了通常的离线强化学习/事后归因范式：**安全证书必须在 episode 之前由 backup 集 + 延迟鲁棒不变集给出，而不是事后由日志重建**。因此 submission 必须携带一个「可证明的紧急备份策略」（RBS），网络一断就执行它。

**直觉 5（评分规则会改变被评分对象 L7）**
当榜单只奖成功率、不惩罚碰撞时，最优策略是激进；当加入安全硬否决时，最优策略改变。这不是 bug，是**观察者反作用**：评测规则（observer）改变了被测系统（policy）的行为分布。于是「在榜单上训练」与「在真实部署中安全」之间存在 Goodhart 张力，必须用**证书感知评分（CAS）**把安全从「可补偿的扣分项」升为「不可补偿的硬否决」，并报告 Pareto 前沿而不是标量。

**直觉 6（证书要绑到「实际执行体」，不是策略服务器）**
策略在云端，执行体在评测场。R73 的安全界相对「我们的机器人」成立；这里必须相对 **远程机器人 + 远程相机 + 网络** 成立。任何只在策略服务器局部成立的保证（例如「我的规划器输出平滑」）都不构成安全证书，除非它能被远程执行体与延迟通道验证。

## 1. 形式化定义（增量：定义 383–396）

**定义 383（OASIS-GAUGE 总览与六不变式）** OASIS-GAUGE = (RIM, OASIS, LAC, CAS, CBC, MODGAUGE†)。六不变式：
(i) **执行体锚定**：安全主张只相对「实际执行体 + 实际观测通道 + 实际延迟」成立，不相对策略服务器；
(ii) **延迟显式**：Δ_eff 进入证据契约与安全裕度，禁止零延迟假设；
(iii) **尺度诚实**：单目度量深度不可得时，只允许尺度不变安全量（τ, θ, θ̇）；禁止把伪造的度量距离送入安全滤波；
(iv) **一次性预注册**：安全证书在 episode 前由 RBS + 延迟鲁棒不变集给出；禁止事后反事实归因；
(v) **分辨率诚实**：榜单差值 < MDD 时不得声称优越；安全违规为硬否决，不进入可补偿平均；
(vi) **严格退化**：Δ=0、标定已知、单机、深度可用 ⇒ MODGAUGE†，再退化 R72/R68；安全侧只增不减。

**定义 384（远程提交仪器 RSI）** 仪器 I = (O, A, Π_eval, F, Δ, S)。O 为观测目录（4×RGB、双 7 轴本体、语言），A 为动作空间（joint/ee、gripper、pivot、分块长度 N），Π_eval 为评分协议，F = {r_1,…,r_N} 为机队，Δ 为往返延迟分布，S 为场景/物体采样器。被测量
Y = (Y_succ, Y_safe, Y_step, Y_lat) ~ p(· | π, I, ξ)，
其中 ξ 为 episode 种子。**关键**：Y 是 π 与 I 的联合函数，不可分离；除非 I 有仪器证书 I_cert =（标定、采样规则、评分版本、机队身份、延迟分布），否则「π 的能力」不可识别。

**定义 385（评估六分量与量表分辨率）**
u_eval² = u_scene² + u_embody² + u_score² + u_net² + u_oneshot² + u_calib²。
- u_scene：场景/物体/初始位姿采样（有限 episode）；
- u_embody：机队异质（动力学、标定、磨损、夹爪间隙）；
- u_score：评分歧义（部分成功、步分、人工判定）；
- u_net：延迟对成功率/步分的系统效应（与模型能力混淆，是最大偏差项）；
- u_oneshot：一次性不可复现（无重复测量，方差不可由重测估计）；
- u_calib：远程相机内外参未知/漂移。
有效样本量（设计效应校正）：n_eff = n / (1 + (m−1)·ρ̄)，m 为簇大小（同一机器人或同一场景），ρ̄ 为簇内相关。**最小可分辨差**
MDD = (z_{1−α/2} + z_{1−β})·sqrt(2·u_eval² / n_eff)。
**分辨率主张**：若 |μ_A − μ_B| < MDD，则 A、B 在该仪器上不可分辨，任何“更优”声明无效。

**定义 386（延迟鲁棒障碍证书 OBC）** 离散安全集 C = {x : h(x) ≥ 0}，控制周期 T_c，执行延迟 Δ_eff ∈ [0, Δ_max]。OBC 要求存在**备份控制** u_b，使
∀δ∈[0,Δ_max]：h(x_{t+δ}) ≥ 0，且 h(x_{t+Δ_eff}) ≥ (1−γ)·h(x_t)，γ∈(0,1]。
对 TTC 形式取 h(x) = τ − τ_safe(v, Δ_eff)，其中
τ_safe(v, Δ_eff) = Δ_eff + v/(2·a_max) + ε/v
（三项均为**秒**：延迟、以最大减速度停下的时间、低速余量——不需要度量距离）。**备份集 RBS = {u_b : 证书保证其停在 C 内}** 随 submission 声明；网络中断/超时即执行 RBS。

**定义 387（单目尺度不变危害证据）** 观测 o = (θ_i, θ̇_i, τ̂_i, texture_i, flow_div_i)。τ̂ = 1/div(flow)（或障碍框膨胀率），在相似变换下不变；θ、θ̇ 由几何给出。有效域
D_mono = {texture ≥ τ_tex ∧ (|v_ego| ≥ v_min ∨ obstacle_moving) ∧ 光照∈[l_min,l_max] ∧ 无饱和}。
出域 ⇒ τ̂ 不可观 ⇒ **否决并制动**（而不是猜一个距离）。碰撞航向判据：θ̇ ≈ 0 且 τ̂ 单调递减 ⇒ 立即进入 OBC。多相机一致性：4 路 τ̂ 的跨视角残差须落在 SEAL 校准的 conformal 集内（R73 COMP-PAR 的复用）。

**定义 388（L6 通信反作用通道 χ_6）** χ_6: N ↦ (Δ_eff(N), σ_Δ(N), p_drop(N))，其中 Δ_eff(N) ≈ N/(2·f_exec) + RTT/2（反应延迟），σ_Δ(N) 为抖动，p_drop(N) 为丢包率。反作用预算
c_6(N) = λ_τ·Δ_eff(N) + λ_σ·σ_Δ(N) + λ_d·p_drop(N)，Σ c_6 ≤ B_6，且硬约束 Δ_eff(N) ≤ Δ_max(safety)。**N 是契约字段，不是超参**：入图前必须声明并给出其 Δ_eff 上界。

**定义 389（远程证据契约 REC）** REC = EC ⊕ (Δ_max, Δ_eff(N), RBS, D_mono, one_shot_trace, I_cert, MDD)。继承 R73 的 EC 全部字段（类型、预算、χ_R、有效域、追溯合并、否决、WCET、密封引用）；新增字段全部是「远程执行」带来的测量条件。

**定义 390（证书感知评分 CAS）** 报告向量 score = (S_safe, S_step, L_{p50}, L_{p99})：
- **安全硬否决**：任一安全违规 ⇒ S_safe = 0，且不可用成功率/步分补偿（继承 R73 COMP-VETO 非补偿语义）；
- **证书下界**：certified success = LCB_{1−α}(Y_succ | Y_safe=1)，用 conformal risk control 给出；
- **禁止标量榜**：只发布 Pareto 前沿 + 区间，标量加权仅作展示且必须附 MDD。

**定义 391（评估证书 J_BENCH）** J_BENCH = ⊗_i J(module_i) ⊗ J_comp(MReg) ⊗ J_RIM(I_cert, MDD) ⊗ J_OASIS(RBS, Δ_max, D_mono)。Valid(J_BENCH) ⇒ (i) 报告值落在真实性能 ±u_eval 内；(ii) 安全主张在 D_mono 与 Δ_max 内成立；(iii) 榜单比较仅在 ≥MDD 时有效。否则只能标 **exploratory**，不得进入主张。

**定义 392（一次性统计推断）** episode 一次性 ⇒ 采用「机器人/场景」**簇 block bootstrap** 估计 u_eval；用 conformal risk control 给出成功率下界；预注册 α、指标、停止规则；禁止在 holdout 上调参（否则置换检验失效）。**报告纪律**：任何“提升”必须同时报告 n_eff、MDD 与簇结构，否则视为不可解释。

**定义 393（OOD 障碍与有效域）** 障碍分布偏移类：外观新颖、无纹理/透明/镜面、快速出现、多径/反光、尺度极端。检出（材质后验 + 多相机 τ̂ 分歧 + 新颖度）⇒ **VETO**（非补偿），退到 RBS；不把 OOD 情形混入平均成功率。

**定义 394（退化与 stub）** 网络中断 ⇒ **RBS stub**（执行认证备份，不接收新动作）；单目相机失效 ⇒ 单目 stub（保守制动 + 声学/本体减速）；深度可用 ⇒ 回退 R73 DPEM†；评分器不可信 ⇒ 仅报 safety 指标、不报成功率主张。

**定义 395（主张-榜单-证书绑定 CBC）** 把 R73 的 CPB 从「组件→主张」推广为「主张→仪器→可分辨实验」：
- C1（单目尺度不变避障安全）← OASIS ← MB4 ← AB4（τ/θ 基线 vs 伪造度量深度 vs 端到端 VLA）← (安全违规率，τ 估计 ECE，OOD 否决正确率)；
- C2（延迟预算/分块）← LAC ← MB5 ← AB5（自适应 N* vs 固定 N）← (Δ_eff P99，安全裕度，成功率)；
- C3（证书感知榜单分辨率）← CAS/RIM ← MB6 ← AB6（Pareto+MDD vs 标量榜）← (MDD，排名翻转率，安全违规被掩盖率)。
非绑定组件 = 工程附件，不进认证路径、不进正文。

**定义 396（结构上限）** |V_M| ≤ 32、组合深度 ≤ 4、|O| ≤ 8、Δ_max ≤ 300 ms、N ≤ 32、|障碍类| ≤ 8——全部为 MReg/契约的可审计图性质，而非文档纪律。

```python
class RemoteInstrument:

    scorer_version: str            # 评分规则版本（u_score）
    def u_eval(self, n, clusters): # 定义 385：六分量 + 设计效应

# IP-304 OBC：延迟鲁棒障碍证书 + 备份集
def obstacle_certificate(x, v, a_max, delta_max, mono_ev):
    if not mono_ev.in_domain:                 # D_mono 出域 ⇒ 不可观
        return VETO_BRAKE                    # 不猜距离，直接否决
    tau_safe = delta_max + v/(2*a_max) + EPS/v
    if mono_ev.tau_hat < tau_safe:
        return VETO_BRAKE
    rbs = certify_backup_stop(x, v, a_max, delta_max)   # 可证明停在 C 内
    return SAFE(rbs)

# IP-305 单目尺度不变危害：τ / θ / θ̇，不用度量深度
def monocular_hazard(rgb4, proprio, prev):
    flows = [optical_flow(prev[i], rgb4[i]) for i in range(4)]
    tau   = [1.0/divergence(f) for f in flows]         # 尺度不变
    theta = bearing(proj(flow)); dtheta = theta - prev_theta
    tex   = texture_energy(rgb4)
    consist = conformal_covers(SEAL, spread(tau))       # 多相机一致性
    in_dom  = (tex >= TAU_TEX) and (abs(proprio.v) >= V_MIN or moving(flow))
    return MonoEvidence(tau=median(tau), theta=theta, dtheta=dtheta,
                        in_domain=in_dom and consist)

# IP-306 LAC：分块长度作为反作用通道（L6）
def choose_chunk_N(delay_model, f_exec, budget, safety):
    best, best_c = None, INF
    for N in range(1, 33):
        d_eff = N/(2*f_exec) + delay_model.rtt/2
        if d_eff > safety.delta_max: break
        c = (LAM_T*d_eff + LAM_S*delay_model.sigma(N)
             + LAM_D*delay_model.p_drop(N))
        if c < best_c: best, best_c = N, c
    return best                                  # 定义 388 的 N*

# IP-307 RIM：评估分辨率（榜单到底能分辨多大差）
def minimum_detectable_difference(u_eval, n, m, rho_bar, alpha, beta):
    n_eff = n / (1 + (m-1)*rho_bar)              # 设计效应
    return (z(1-alpha/2)+z(1-beta)) * sqrt(2*u_eval**2/n_eff)

# IP-308 CAS：证书感知榜单（Pareto + 硬否决 + conformal 下界）
def certificate_aware_score(runs):
    if any(r.safety_violation for r in runs):
        return Score(S_safe=0, claimable=False)  # 非补偿硬否决
    lcb = conformal_lower_bound([r.success for r in runs], alpha=PRE.alpha)
    return Score(S_safe=1, certified_success=lcb,
                 pareto=(lcb, p50(runs.lat), p99(runs.lat)))

# IP-309/310 OASIS-GAUGE 主闭环（复用 R73 三域）
def OASIS_round(M, obs, rgb4, language):
    N   = M.lac.current_N                         # L6 契约字段
    mono= M.dpe_mono.update(rgb4, M.proprio)       # IP-305
    cert= obstacle_certificate(M.x, M.v, M.a_max,
                               M.delta_max, mono)   # IP-304
    if cert.veto:
        k = M.rbs.execute()                       # 备份集（事前证明）
    else:
        k = M.policy.get_action(obs, language, chunk=N)
        k = M.safe_filter.project(k, cert.rbs, M.delta_eff)
    M.net.heartbeat(); M.rec.log(delta_eff=M.delta_eff, N=N)
    return k, M.rim.u_eval(M.n, M.clusters)       # 附分辨率，不报裸标量
```

## 3. 推导

**引理 38（延迟鲁棒裕度的保守充分性）** 在匀速-有限减速度模型下，若 τ̂ ≥ τ_safe(v, Δ_max) = Δ_max + v/(2a_max) + ε/v 且 τ̂ 的估计误差上界 ≤ ε/v，则任意 Δ_eff ≤ Δ_max 下执行认证备份 u_b 可保证 h ≥ 0。证明：把延迟内位移 v·Δ、刹停距离 v²/(2a_max) 分别换算为时间 Δ 与 v/(2a_max)，与 τ 同量纲相加；ε/v 吸收估计误差。系：**安全裕度可以在秒域上核算，不需要度量深度——这是单目可行的关键。**

**引理 39（尺度不变量的可辨识性边界）** 在相似变换 x ↦ s·x, t ↦ t 下：τ、θ、θ̇ 不变，度量距离 d 与相对速度 ż 按 s 缩放、不可单独辨识。故任何声称单目得到度量 d 的安全滤波在无外部尺度锚时不可证；D_mono 是 τ̂ 可观测的**必要**条件（纹理不足或自运动≈0 ⇒ 光流散度≈0 ⇒ τ̂→∞ 假安全）。系：**单目避障的第一性错误不是估计不准，而是把不可观量当成可观量。**

**引理 40（榜单分辨率的簇效应）** 若 episode 以机器人/场景成簇且簇内相关 ρ̄>0，则朴素 i.i.d. 方差低估真实方差 1+(m−1)ρ̄ 倍；因此 MDD 必须用 n_eff。忽略簇结构时，名义 95% 置信区间的实际覆盖率随 ρ̄ 单调下降；当 ρ̄=0.3、m=10 时覆盖率可跌破 70%。系：**“排名第一”在统计上可能只是簇采样的一次幸运。**

**引理 41（分块-延迟-丢包的内部最优）** Δ_eff(N) 对 N 单调增；在常见网络模型中 p_drop(N) 与 σ_Δ(N) 随请求频率（∝1/N）单调增。若 c_6 的第一项凸、后两项随 1/N 凸，则存在唯一内部 N* 平衡「反应慢」与「丢包多」；硬约束 Δ_eff ≤ Δ_max 给出 N 的上界。系：**N 不是调参自由，而是受安全约束支配的契约量。**

**定理 30（远程安全保持）** 若 submission 的 REC 满足：(i) D_mono 内 τ̂ 可观测；(ii) 安全滤波满足定义 386 的延迟鲁棒条件；(iii) RBS 在 Δ_max 内可证明停在 C 内；(iv) 网络中断执行 RBS；则对任意 Δ_eff ≤ Δ_max 与任意抖动实现，远程执行体的轨迹保持 h ≥ 0。证明由引理 38 + RBS 的闭环不变性 + 中断时 u=u_b 的单调切换。**证明重量在「执行体模型与延迟上界在远程可验证」上，而不在策略精度上。**

**定理 31（榜单不可分辨性与主张合法性）** 设两策略真实差 δ。若 δ < MDD（定义 385），则任何基于该仪器单次榜单的“A 优于 B”主张在水平 α 下不可拒绝零假设；证书感知 Pareto + conformal 下界是唯一不违反分辨率不变式的主张形式。系：**标量榜单的分辨率以下部分是噪声货币化——它把仪器误差卖成了模型能力。**

**定理 32（严格包含）** 当 Δ=0、标定已知、单机、深度可用、评分无歧义时，OASIS-GAUGE 逐指令退化为 MODGAUGE（R73），再退化为 R72/R68；所有新增字段取平凡值（Δ_max=0、D_mono=全空间、RBS=∅）。**安全侧只增不减，性能仅在契约满足时获益。**

**定理 33（模块/通道失效的零级联）** 单目失效 ⇒ 单目 stub（保守制动）；网络失效 ⇒ RBS stub；评分失效 ⇒ 仅 safety 指标。任一 stub 不产生新动作、不参与并联缩窄、不污染其他模块审计（继承 R73 定理 28–29）。系：**失效传播路径唯一，且唯一方向是“更保守”。**

## 6. 本轮最大风险

**一句话**：OASIS-GAUGE 把安全与可信的证明责任从「我们的系统」转移到「**远程仪器的可验证性**」——但远程机器人真实动力学/制动极限、评测方评分规则与场景采样器、以及网络延迟分布，都是我们**不拥有也无法完全观测**的黑箱；如果这些被假设而非被测量（Δ_max 低估、a_max 偏乐观、D_mono 覆盖不足、或评分器本身把碰撞当成功），那么证书会在「所有模块证书有效、所有榜单校验通过」的表象下成立，却在真实远程执行体上失效——系统用一套类型正确、分辨率诚实、Pareto 完备的评估，**自信地给一个错误的世界打了分**。

次级风险与缓解：
1. **执行体模型黑箱** → submission 前用握手阶段做短程制动辨识（a_max、执行周期），只在辨识置信区间内签发 OBC；超界即降级为保守制动。
2. **Δ_max 系统性低估** → 在线估计延迟分布的尾部（P99.9）而非均值；N* 以尾部约束求解；心跳丢失即 RBS。
3. **D_mono 覆盖不足（无纹理/低自运动）** → 硬边界 + 多相机一致性 + 出域即否决；不将出域样本计入成功率。
4. **评分器/场景采样不可审计** → I_cert 版本化 + 预注册指标 + 只报 safety 指标当评分不可信；主张标 exploratory。
5. **L7 观察者反作用 / Goodhart** → 安全硬否决 + Pareto + 预注册 α；禁止仅以榜单成功率作为训练奖励。
6. **单次不可复现的统计脆弱** → 簇 block bootstrap + conformal 下界 + n_eff/MDD 强制报告；区分探索性与认证性结论。
7. **尺度不变量的边界误用** → τ̂ 仅在 D_mono 内；对「近似静止且近距离」的退化场景，用本体/触觉/超声第三方通道交叉否决，绝不单目定案。

> 本轮结论一句话：把避障安全建立在尺度不变的 τ/θ 与延迟鲁棒备份集上，并把榜单本身当作一台必须报告分辨率（MDD）的仪器，是让远程黑箱评测从「名次」变成「可证伪测量」的最小可行路径；其最大风险是仪器与执行体的关键参数仍被假设而非实测。

**定义 396（结构上限）** |V_M|≤32、深度≤4、|O|≤8、Δ_max≤300ms、N≤32、|障碍类|≤8；全部为可审计图性质。

```python
# IP-303 RIM：远程评测仪器
@dataclass(frozen=True)
class RemoteInstrument:
    obs_spec: ObsSpec; act_spec: ActSpec
    fleet: List[RobotId]; delay: DelayModel
    scorer_version: str
    def u_eval(self, n, clusters):
        u = sqrt(U_SCENE**2 + U_EMBODY**2 + U_SCORE**2
                 + U_NET**2 + U_ONESHOT**2 + U_CALIB**2)
        n_eff = n / (1 + (len(clusters)-1)*RHO_BAR)
        return u, n_eff

# IP-304 OBC：延迟鲁棒障碍证书 + 备份集
def obstacle_certificate(x, v, a_max, delta_max, mono_ev):
    if not mono_ev.in_domain:
        return VETO_BRAKE                      # D_mono 出域：不可观 ⇒ 否决
    tau_safe = delta_max + v/(2*a_max) + EPS/v # 秒域，不需要度量深度
    if mono_ev.tau < tau_safe:
        return VETO_BRAKE
    rbs = certify_backup_stop(x, v, a_max, delta_max)
    return SAFE(rbs)                           # 定义 386

# IP-305 单目尺度不变危害（τ/θ/θ̇）
def monocular_hazard(rgb4, proprio, prev):
    flows = [optical_flow(prev[i], rgb4[i]) for i in range(4)]
    tau   = [1.0/divergence(f) for f in flows] # 尺度不变
    theta = [bearing(proj(f)) for f in flows]
    tex   = texture_energy(rgb4)
    consist = conformal_covers(SEAL, spread(tau))
    in_dom  = (tex >= TAU_TEX) and \
              (abs(proprio.v) >= V_MIN or any(moving(f) for f in flows))
    return MonoEvidence(tau=median(tau), theta=median(theta),
                        dtheta=median_theta_rate(theta),
                        in_domain=in_dom and consist)

# IP-306 LAC：分块长度作为 L6 反作用通道
def choose_chunk_N(delay, f_exec, budget, safety):
    best, best_c = None, INF
    for N in range(1, 33):
        d_eff = N/(2*f_exec) + delay.rtt/2
        if d_eff > safety.delta_max: break
        c = LAM_T*d_eff + LAM_S*delay.sigma(N) + LAM_D*delay.p_drop(N)
        if c < best_c:
            best, best_c = N, c
    return best                                # 定义 388 / 引理 41

# IP-307 RIM：最小可分辨差
def minimum_detectable_difference(u_eval, n, m, rho_bar, alpha, beta):
    n_eff = n / (1 + (m-1)*rho_bar)            # 设计效应
    return (z(1-alpha/2) + z(1-beta)) * sqrt(2*u_eval**2/n_eff)

# IP-308 CAS：证书感知榜单
def certificate_aware_score(runs):
    if any(r.safety_violation for r in runs):
        return Score(S_safe=0, claimable=False)   # 非补偿硬否决
    lcb = conformal_lower_bound([r.success for r in runs], alpha=PRE.alpha)
    return Score(S_safe=1, certified_success=lcb,
                 pareto=(lcb, p50(runs.lat), p99(runs.lat)))

# IP-309 一次性统计推断（簇 block bootstrap）
def one_shot_interval(runs, cluster_key, alpha):
    blocks = group_by(runs, cluster_key)
    boots = [resample_blocks(blocks).mean() for _ in range(B)]
    return percentile(boots, alpha/2), percentile(boots, 1-alpha/2)

# IP-310 OASIS-GAUGE 主闭环
def OASIS_round(M, obs, rgb4, language):
    N    = M.lac.current_N                     # L6 契约字段
    mono = M.mono.update(rgb4, M.proprio)      # IP-305
    cert = obstacle_certificate(M.x, M.v, M.a_max,
                                M.delta_max, mono)  # IP-304
    if cert.veto:
        k = M.rbs.execute()                    # 事前证明的备份动作
    else:
        k = M.policy.get_action(obs, language, chunk=N)
        k = M.safe_filter.project(k, cert.rbs, M.delta_eff)
    M.net.heartbeat()
    M.rec.log(delta_eff=M.delta_eff, N=N, d_mono=mono.in_domain)
    u_eval, n_eff = M.rim.u_eval(M.n, M.clusters)
    return k, u_eval, minimum_detectable_difference(
        u_eval, M.n, M.m, M.rho_bar, PRE.alpha, PRE.beta)
```

## 4. 推导（要点版）

**引理 38（延迟鲁棒裕度）** τ̂ ≥ Δ_max + v/(2a_max) + ε/v ⇒ 任意 Δ_eff≤Δ_max 下认证备份可保 h≥0。延迟位移与刹停距离都换算为时间，与 τ 同量纲相加。系：安全裕度可在秒域核算，无需度量深度。

**引理 39（尺度不变可辨识边界）** 相似变换下 τ,θ,θ̇ 不变，度量 d 按 s 缩放不可单独辨识；D_mono 是 τ̂ 可观测的必要条件（纹理/自运动不足 ⇒ τ̂ 假大 ⇒ 假安全）。系：单目避障第一性错误是把不可观量当可观量。

**引理 40（分辨率簇效应）** 簇内相关 ρ̄>0 ⇒ 朴素方差低估 1+(m−1)ρ̄ 倍；MDD 必须用 n_eff；忽略簇结构时覆盖率随 ρ̄ 单调下降（ρ̄=0.3, m=10 可跌破 70%）。系：排名第一可能只是簇采样幸运。

**引理 41（分块内部最优）** Δ_eff(N) 单调增，p_drop/σ_Δ 随 1/N 增；c_6 凸 ⇒ 唯一 N*；Δ_eff≤Δ_max 给出上界。系：N 是受安全支配的契约量，不是自由超参。

**定理 30（远程安全保持）** 若 (i) D_mono 内 τ̂ 可观测；(ii) OBC 满足定义 386；(iii) RBS 在 Δ_max 内可停；(iv) 断网执行 RBS，则任意延迟/抖动实现下远程轨迹保持 h≥0。证明：引理 38 + 闭环不变性 + 中断单调切换。

**定理 31（榜单不可分辨性）** δ<MDD ⇒ “A 优于 B”在水平 α 下不可拒绝 H0；证书感知 Pareto + conformal 下界是唯一不违反分辨率不变式的主张形式。系：标量榜在分辨率以下把仪器误差货币化为模型能力。

**定理 32（严格包含）** Δ=0、标定已知、单机、深度可用、评分无歧义 ⇒ 逐指令退化为 MODGAUGE（R73）→ R72 → R68；新增字段取平凡值。安全单调不减。

**定理 33（零级联）** 单目失效⇒单目 stub；网络失效⇒RBS stub；评分失效⇒仅 safety。任一 stub 不产生新动作、不参与并联缩窄、不污染其他模块审计。失效方向唯一：更保守。

## 7. 本轮最大风险

**一句话**：OASIS-GAUGE 把证明责任从「我们的系统」转移到「**远程仪器的可验证性**」——但远程机器人的真实制动极限与动力学、评测方评分规则与场景采样、以及延迟分布都是我们不拥有也无法完全观测的黑箱；一旦这些被假设而非实测（Δ_max 低估、a_max 偏乐观、D_mono 覆盖不足、评分器把碰撞当成功），证书就会在「所有模块证书有效、所有榜单校验通过」的表象下成立，却在真实远程执行体上失效——系统用一套类型正确、分辨率诚实、Pareto 完备的评估，**自信地给一个错误的世界打了分**。

次级风险与缓解：
1. **执行体黑箱** → 握手阶段短程制动辨识 a_max/周期，仅在置信区间内签发 OBC；超界降级保守制动。
2. **Δ_max 低估** → 估计延迟尾部 P99.9 而非均值；N* 以尾部约束求解；心跳丢失即 RBS。
3. **D_mono 覆盖不足** → 硬边界 + 四相机一致性 + 出域即否决；出域样本不计入成功率。
4. **评分器/采样不可审计** → I_cert 版本化 + 预注册 + 评分不可信时只报 safety 指标；主张标 exploratory。
5. **L7 观察者反作用 / Goodhart** → 安全硬否决 + Pareto + 预注册 α；禁止只以榜单成功率作训练奖励。
6. **一次性统计脆弱** → 簇 block bootstrap + conformal 下界 + 强制报告 n_eff/MDD；区分探索性与认证性结论。
7. **尺度不变量边界误用** → τ̂ 仅在 D_mono 内；近距近似静止退化场景用本体/触觉/超声交叉否决，绝不单目定案。

> 本轮结论一句话：把避障安全建立在尺度不变的 τ/θ 与延迟鲁棒备份集上，并把榜单本身当作一台必须报告分辨率（MDD）的仪器，是让远程黑箱评测从「名次」变成「可证伪测量」的最小可行路径；其最大风险是仪器与执行体的关键参数仍被假设而非实测。
