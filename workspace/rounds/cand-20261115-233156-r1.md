# 第 11 轮（新灵感循环第 1 轮；本轮灵感：「力矩控制」×「无刷电机」）
> **基线**：第 10 轮 MetricVoiceGauge-STF-NRB-LS（定义 540–548；引理 87–91；实验 E571–E590）。
> 本轮纪律：**执行器真值 + 接触可证 + 故障安全**。v10 把证书从"位置/语义信任"推进了一大步，但仍把执行器当成理想力矩源：ê_max 是抽象标量，既不知道无刷电机的 k_t 随温度漂移，也不知道母线电压、热上限、再生制动和相/编码器故障。两个灵感正好治理 v10 的三种债：**执行债**（effort 没有物理真值）、**接触债**（力矩/阻抗控制可向接触注入能量，冲击力未入证书）、**失效债**（力矩掉线时"零力矩"可能比抱闸更危险）。铁律不变：新模块失效 ⇒ 注入声明中立元，行为对 v10 **等价**或**支配**；力矩级新增行为只允许出现在声明的安全退化路径（STS）中。

## 0. 直觉与动机

**灵感 1（力矩控制 → 从"运动证书"到"力矩-接触证书"）**
直觉：v10 的证书管的是"会不会撞、余量够不够"，但真正决定接触安全的是**交付到关节/环境的力矩**，不是位置误差。位置控制下，碰撞表现为"位置误差 → 大力矩"；力矩/阻抗控制下，接触可以变软，但也可能把能量注入接触、把柔性环境变成极限环。核心创新：**力矩真值包络（TorqueTruthEnvelope, TTE）** + **无源能量罐（PassivityEnergyTank, PET）** + **接触力界**。证书里的 ê_max 升级为逐关节区间 E_τ(t) 与笛卡尔接触力上界 F̂_contact；速度/刚度预算按 STF/NRB 给出的人-机距离分级。关键不是"用 torque control 更柔顺"，而是**把柔顺性变成可证的无源性与有界接触力**：能量罐保证不向接触注入超过预算的能量；1kHz 反射弧在 1ms 内把违规力矩降下来。这样 v10 的"位置安全"与 v11 的"力矩安全"不是替代，而是串联：位置证书保运动学，力矩证书保动力学与接触。

**灵感 2（无刷电机 → 执行器是一等公民，不是理想力矩源）**
直觉：无刷电机（PMSM/BLDC）的力矩不是命令值，而是 τ ≈ k_t(T_w)·i_q + 齿槽/纹波 − 摩擦。k_t 随磁体温度下降、R_s 随铜温上升，母线电压又限制高速时的可用电流；再生制动会把能量灌回母线；相开路/短路、霍尔/编码器滑移、抱闸磨损都会**静默削减力矩权限**。v10 把这一切藏在 ê_max ≤ τ_eff 里，相当于给一个虚构的理想执行器发证书。核心创新：**执行器健康台账（ActuatorHealthLedger, AHL）** + **热/能量预算（ThermalEnergyBudget, TEB）** + **安全力矩态（SafeTorqueState, STS）**。AHL 用电流跟踪残差、广义动量观测器、相电流和编码器/Hall 一致性、抱闸自检，给出逐关节健康度 h_t 与故障自适应包络；TEB 用保守热模型和 I²t/再生能量预算给出热余量与降额；STS 在力矩权限不足时执行"抱闸 + 重力补偿 + 阻尼 + 受控下放"，而不是简单切零力矩（零力矩在重力下可能直接坠落）。

**灵感 3（合成：多速率反射弧）**
直觉：力矩环在 1kHz，动作块在 5Hz，中间隔着两个数量级。用 50Hz 守卫去管 1kHz 的力矩安全，等于用"秒表"管"毫秒"。核心创新：**多速率执行器守卫（MultirateActuatorGuard, MAG）**——1kHz 反射弧只做"减小力矩/加阻尼/抱闸/STS"的单调动作，拥有对 50Hz 和 5Hz 的**否决权**；50Hz 守卫在 v10 四检上增加执行器/热/力/能量罐检查；5Hz 块生成做完整 TTE/热/无源/接触力证书。三者的组合由"失效标志 + 版本号"保证：反射弧一旦置位，任何旧证书不得再执行。

## 1. 研究问题（轮次升级版）

- **Q1（力矩真值）**：如何把 v10 的抽象标量 ê_max 升级为逐关节、随温度/转速/母线电压/老化漂移的力矩区间 E_τ，使覆盖率 ≥99.9%，并在冷/热两端都不产生"证书有效但执行器已失去权限"的静默失效？
- **Q2（接触可证）**：力矩/阻抗控制如何同时给出无源性证明与接触力上界 F̂_contact ≤ F_safe，使冲击/柔性环境/人-机接触下的力不超限，且能量罐耗尽时退化为耗散模式而非极限环？
- **Q3（故障安全）**：无刷电机相/编码器/抱闸/热故障如何在 ≤N_d 个 1ms 周期内被检出并进入故障自适应包络或 STS，且 STS 在重力下不自由落体、接触力有界、行为可证支配于"零力矩"？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P19）

**P16 执行器真值律（Actuator Truth Law, ATL）**
任何 effort/force 界必须可追溯到实测电流/力矩与标定参数区间；抽象 effort 不得为力矩模式执行发证书。冷/热/高速/低压四种边界必须显式进入区间，而不是用一个额定常数覆盖。

**P17 先无源后性能律（Passivity-Before-Performance, PBP）**
力矩/阻抗执行必须先满足无源能量约束；能量罐不足时只许耗散/冻结/降额，不许靠提高增益"顶过去"。接触力上界优先于任务误差。

**P18 快环否决律（Fast-Loop Veto, FLV）**
1kHz 反射弧的动作集是单调的：只许减小力矩、加阻尼、抱闸、进 STS；它对 50Hz/5Hz 有否决权，慢环不得覆盖快环的安全置位。快环自身不得被非安全任务抢占。

**P19 失效力矩态律（Fail-Safe Torque State, FTS）**
力矩权限不足时，安全态不是"零力矩"，而是 STS：抱闸（若有）+ 重力补偿 + 阻尼 + 受控下放/支撑。STS 是声明的退化路径，不是任务行为；其动能与接触力必须可证不劣于"零力矩"。

## 3. 与基线的接口（如何退化）

- **TTE 失效**（参数区间不可用/电流采样超时/标定过期）⇒ E_τ ← [−τ_eff, +τ_eff]^n，退回 v10 的 ê_max 证书；行为**等价** v10（中立元）；
- **PET 失效**（能量罐状态不可信/延迟超界）⇒ 关闭力矩/阻抗模式，切回 v10 位置/速度控制；行为**等价** v10；
- **AHL 失效** ⇒ 冻结最后健康参数，按 δ_h 膨胀包络并降速/降增益；行为**支配** v10（更保守）；
- **TEB 失效** ⇒ 用连续力矩上限 + 最坏环境温度 + 额定热参数；行为**支配** v10；
- **执行器故障**（h < h_fail）⇒ STS（抱闸 + 重力补偿/受控下放）；这是 v10 未覆盖的声明退化路径，支配"零力矩"；
- **STF/NRB/AC/ID/MW/LS 失效** ⇒ 沿 v10 六级退化链原样执行；v11 不改变 v10 的语义/规范/轻量化路径。

## 4. 预期贡献

1. **力矩真值证书**：TTE 把执行器从理想力矩源变成带参数区间、热/电压/转速约束的可观测对象，修复 v10 在冷/热边界的静默失效（引理 92–93）；
2. **接触可证执行**：PET + 接触力界把阻抗/力矩控制的柔顺性变成可证无源性与有界力（引理 94）；
3. **故障安全**：AHL + STS + MAG 给出 BLDC 故障的检测时延、故障自适应包络与不失稳退化（引理 95–96）；
4. **E591–E610** 覆盖参数辨识、冷热真值、热/再生、无源接触、故障注入、多速率时延、长跑与竞赛。

## 5. 本轮最大风险

**一句话**：TTE 的窄区间依赖 k_t/R_s/热参数/接触刚度的在线可辨识性，而温度、磁饱和、减速器摩擦与接触刚度往往在同一个残差里不可分；一旦标定漂移或环境刚度远超假设，证书会用"看似物理"的窄区间掩盖真实的力矩/接触力超限，且 1kHz 反射与 50Hz 证书之间的时序缝隙可能让一次冲击在证书更新前发生——这比 v10 的"已知的宽保守"更危险，因为它把不确定性从"承认宽"变成了"错误地相信窄"。

**新增定义 549（无刷电机执行器模型与参数区间）** 关节 j 的 PMSM/BLDC 在 FOC（i_d=0）下：
```
L_q di_q/dt = v_q − R_s(T_w) i_q − p ω ψ_f(T_w)
τ_j = (3/2) p ψ_f(T_w) i_q + τ_cog(θ_j) + τ_fric(ω_j) + η_j
C_th dT_w/dt = P_cu + P_iron + P_mech − (T_w − T_amb)/R_th
P_cu = (3/2) R_s(T_w) i_q^2
k_t(T_w) = k_t0 (1 − α_m (T_w − T_ref)),  R_s(T_w) = R_s0 (1 + α_c (T_w − T_ref))
```
其中 α_m,α_c>0；磁体高温退磁使 k_t 下降、铜温上升使 R_s 上升，二者在热端同向恶化。执行器安全集 A_j(T_w,ω,V_bus)={τ: |τ|≤τ_max,j^-(T_w,ω,V_bus), |i_q|≤i_max, |di_q/dt|≤i_max'}；τ_max^- 取参数区间、母线电压与热约束的保守下界。抱闸力矩 τ_b∈[0,τ_b,max]，失电默认抱闸（spring-applied）；无抱闸关节必须显式标注。

**新增定义 550（力矩真值包络 TTE）** 电流测量/跟踪区间 [i_q^-,i_q^+]=[i_q^m−δ_i(ω), i_q^m+δ_i(ω)]，δ_i(ω)=δ_i0+c_v|ω|（反电动势/母线压降/电流环带宽导致的误差上界）。区间乘加：
```
E_τ,j(t) = [k_t^-,k_t^+] ⊗ [i_q^-,i_q^+] ⊕ [−ρ_j, ρ_j]
ρ_j = ρ_cog,j + ρ_fric,j|ω_j| + ρ_harm,j + η_j
```
⊗ 为区间乘（端点四乘积取 min/max），⊕ 为 Minkowski 和。覆盖事件 C_τ={∀j, τ_act,j(t)∈E_τ,j(t)}，标定满足 P(C_τ)≥1−ε_τ（E591–E593）。块内逐 k 预测 E_τ,k；块覆盖概率由 union bound 给出 ≥1−K·n·ε_τ。定义宽度 w_j=|E_τ,j|；紧致性指标为 w_j 相对 v10 固定区间 [−τ_eff,j,τ_eff,j] 的宽度比。

**新增定义 551（热/能量预算 TEB）** 保守热上界（取 R_th^+、C_th^-、T_amb^+、P_loss^+）：
```
T̂_w(t+Δ) = T_amb^+ + (T_w(t)−T_amb^+) e^{−Δ/(R_th^- C_th^-)}
           + R_th^+ P_loss^+ (1−e^{−Δ/(R_th^- C_th^-)})
P_loss^+ = (3/2) R_s^+ (i_q^+)^2 + P_iron^+ + P_mech^+
Θ(t) = T_w,max − δ_T − max_{0≤Δ≤Δ_chunk} T̂_w(t+Δ)
```
热可行条件：Θ≥0 且 τ_max^-(T̂_w^+,ω) 覆盖块内力矩。再生与母线：
```
E_regen = ∫ max(0, −Σ_j τ_j ω_j) dt
E_bus^safe = (1/2) C_bus (V_max^2 − V_nom^2)
```
要求 E_regen≤E_bus^safe+E_brake（E_brake=P_brake^max·Δ_brake）且总电耗 E_elec=∫(P_cu+P_iron+P_comp)dt≤E_m（LS 配额）。超限时只许插入滑行/降速/制动斩波，不得仅靠软件声明"已处理"。

**新增定义 552（无源能量罐与接触力界 PET）** 阻抗控制 τ=J^T(K_p e+K_d ė)+g(q)+τ_ff。能量罐 e_tank∈[0,E_tank,max]：
```
ΔE_inj   = max(0, (τ_imp^T q̇ − P_diss) Δt)
ΔE_delay = δ_t ||τ_imp|| ||q̇||
e_tank  ← clip(e_tank − ΔE_inj + η_diss ΔE_diss − ΔE_delay, 0, E_tank,max)
```
若更新后 e_tank 将 <0，则 τ_imp←τ_diss（纯阻尼/冻结），即耗散回退；不回退到"提高增益顶过去"。无源条件：e_tank≥0 且延迟 δ_t≤δ_max。接触力上界：
```
F̂_contact = K_p^max δ_x^max + m_eff v^max / Δt_r
```
Δt_r 为反射/检测时延（≤1ms），m_eff 为有效惯量上界。接触安全集 C_safe(F_safe)={(v,K_p,δ_x): F̂_contact≤F_safe}。F_safe 由 STF/NRB 人-机距离分级：近人 F_safe^human（默认 50N），远人 F_safe^prop（默认 120N）；STF 失效时取近人保守默认（支配 v10）。位置证书仍由 v10 的 ĝ_min 负责；F̂_contact 是新增的接触维度，不替代运动学证书。

**新增定义 553（执行器健康台账 AHL）** 逐关节健康度 h_j=min{h_i,h_o,h_ph,h_enc,h_th,h_b}：
- h_i=1−clip(|i_q^m−i_q^cmd|/δ_i,max,0,1)（电流跟踪）；
- h_o=1−clip(|r_j|/r_max,0,1)，r_j 为广义动量观测器残差：
```
r_j = K_o ( p_j − ∫(τ_j + C^T q̇ − g + r_j) dt )
```
- h_ph=1−clip(|i_a+i_b+i_c|/ε_ph,0,1)（三相电流和，正常应≈0）；
- h_enc=1−clip(|q_enc−q_hall|/ε_enc,0,1)（双传感器一致性）；
- h_th=clip(Θ/Θ_min,0,1)（热余量）；
- h_b∈{0,1}（启动抱闸自检）。
故障自适应包络 E_τ,j^h=E_τ,j⊕[−δ_h(1−h_j),+δ_h(1−h_j)]；h_t=min_j h_j 同时门控 K_eff^τ 与 F_safe。h_j<h_min ⇒ 锁关节/降速/降增益；h_j<h_fail ⇒ STS。δ_h 与阈值经 E598 标定，要求漏检率与误报率同时入预注册。

**新增定义 554（安全力矩态 STS）**
```
STS(q,q̇) = { τ = g(q) + D_STS q̇ + τ_b :
              |τ| ≤ τ_max^- , τ_b∈[0,τ_b,max],
              若 |q̇|≤ε_v 则抱闸；否则沿认证下降方向受控下放 }
```
不变量：(i) 无自由落体——沿下降方向势能不增；(ii) 最终动能 ≤½m_eff ε_v²；(iii) 接触力 ≤F_safe。无抱闸时用重力补偿+阻尼+受控下放至支撑位。STS 是声明的故障安全路径；其动作集 ⊆ 允许的故障动作集，且**支配零力矩**（零力矩在重力下可能自由落体）。STS 不得被任务层覆盖，只能由人工/离线复核在安全停驻后清除。

**新增定义 555（力矩感知证书 Ĉ_t^τ）**
```
Ĉ_t^τ = ( ĝ_min, {E_τ,k}_{k=1..K}, F̂_contact, Θ, E_regen,
          h_t, γ̂_grasp, β_STF, n_t, c_τ )
valid ⇔ v10 定义 543 全部条件
      ∧ ∀k,j: E_τ,k,j ⊆ A_j
      ∧ Θ≥0（块内热可行）
      ∧ E_regen ≤ E_bus^safe + E_brake
      ∧ F̂_contact ≤ F_safe(prox)
      ∧ 块内 e_tank≥0
      ∧ h_t ≥ h_min
      ∧ c_τ = (1−ε_τ)^{K·n} ≥ 1−ε_cert
```
任一不满足 ⇒ 不入块；按 v10 的修复/单步回退，或按 A5 进 STS。证书的 `c_τ` 是覆盖置信度，不是装饰性字段：它把"力矩区间大概率对"变成可审计的数值承诺。

**新增定义 556（多速率执行器守卫 MAG）** 周期 T_r=1ms（1kHz 反射）、T_c=20ms（50Hz 块守卫）、T_g=200ms（5Hz 块生成）。反射检查：TTE 覆盖、热预警、再生预警、接触力预警、e_tank、h_t、抱闸状态。反射动作集 D_reflex={τ←ατ (0<α≤1), 加阻尼, 抱闸, STS}，**只减不增**。优先级 T_r>T_c>T_g；反射置位 invalidation_flag 并递增 epoch，任何旧 epoch 的块在下一次 dispatch 前作废。禁止慢环清除快环置位（只能由人工/离线复核在安全停驻后清除）。反射弧自身不得被非安全任务抢占（RT-CVC 优先级继承）。

**新增定义 557（v11 退化链）** 见 §0 的 Level-0/A1–A5/B；每个 Level 的切换写 MW 契约事件与 Λ 台账（若可用），并记录触发原因、h_t、Θ、E_regen、E_τ 宽度。切换只收缩动作集，不改写任务目标。

**新增定义 558（力矩感知有效块长 K_eff^τ）**
```
K_eff^τ = min( K_eff^v10, K_thermal, K_force, K_health, K_tte )
K_thermal = max{ K : Θ≥0 且 E_regen≤预算 }
K_force   = max{ K : 沿块 C_safe 成立 }
K_health  = max{ 1, floor(K_max · h_t) }
K_tte     = max{ 1, floor(K_max · (1−ε_τ)^{K·n}) }   # 取满足 c_τ≥1−ε_cert 的最大 K
```
语义：热/力/健康/真值任一余量小，块自动变短；极端 K=1 退回逐步。v10 的双门控（Δ_dom 与 T）保留为上层门控。

# IP-361 TorqueTruthEnvelope：力矩真值区间（1kHz，O(1)/关节）
class TorqueTruthEnvelope:
    def __init__(self, params, delta_i0=0.02, c_v=0.01, rho_cog=0.05,
                 rho_fric=0.01, rho_harm=0.02, eta=0.03, eps_tau=1e-4):
        self.p = params              # 定义 549 的参数区间
        self.delta_i0, self.c_v = delta_i0, c_v
        self.rho_cog, self.rho_fric = rho_cog, rho_fric
        self.rho_harm, self.eta, self.eps_tau = rho_harm, eta, eps_tau

    def interval(self, iq_m, omega, Tw):
        di = self.delta_i0 + self.c_v * abs(omega)
        iq_lo, iq_hi = iq_m - di, iq_m + di
        k_lo, k_hi = self.p.kt_interval(Tw)       # 含温度/磁饱和区间
        prods = (k_lo*iq_lo, k_lo*iq_hi, k_hi*iq_lo, k_hi*iq_hi)
        rho = (self.rho_cog + self.rho_fric*abs(omega)
               + self.rho_harm + self.eta)
        return (min(prods) - rho, max(prods) + rho)

    def pred_chunk(self, iq_cmd_seq, omega_seq, Tw0, dt):
        """返回 E_tau[k][j] = (lo, hi)，k 为块内步，j 为关节。"""
        Tw, out = Tw0, []
        for iq_cmd, omega in zip(iq_cmd_seq, omega_seq):
            step = [self.interval(iq_cmd[j], omega[j], Tw[j])
                    for j in range(len(iq_cmd))]
            out.append(step)
            Tw = self.p.hot_upper(Tw, iq_cmd, omega, dt)   # 最坏热端
        return out


# IP-364 ThermalEnergyBudget：热与再生预算（10Hz 预测，O(K·n)）
class ThermalEnergyBudget:
    def __init__(self, params, Tw_max=120.0, delta_T=10.0,
                 V_max=60.0, V_nom=48.0, C_bus=1e-3, E_brake=20.0):
        self.p = params
        self.Tw_max, self.delta_T = Tw_max, delta_T
        self.V_max, self.V_nom, self.C_bus, self.E_brake = V_max, V_nom, C_bus, E_brake

    def predict(self, tau_hi_seq, omega_seq, Tw0, dt):
        Tw, regen, elec = Tw0, 0.0, 0.0
        for tau_hi, omega in zip(tau_hi_seq, omega_seq):
            iq_hi = [abs(t) / max(self.p.kt_lo, 1e-6) for t in tau_hi]
            Pcu = sum(1.5 * self.p.Rs_hi * i * i for i in iq_hi)
            Ploss = Pcu + self.p.Piron_hi + self.p.Pmech_hi
            tau_th = self.p.Rth_lo * self.p.Cth_lo
            Tw = self.p.Tamb_hi + (Tw - self.p.Tamb_hi) * math.exp(-dt / tau_th)
            Tw += self.p.Rth_hi * Ploss * (1 - math.exp(-dt / tau_th))
            regen += max(0.0, -sum(t*w for t, w in zip(tau_hi, omega))) * dt
            elec += (Pcu + self.p.Piron_hi + self.p.Pcomp) * dt
        theta = self.Tw_max - self.delta_T - max(Tw, Tw0)
        E_bus = 0.5 * self.C_bus * (self.V_max**2 - self.V_nom**2)
        return theta, regen, E_bus + self.E_brake, elec


# IP-363 PassivityEnergyTank：无源能量罐 + 接触力界（1kHz）
class PassivityEnergyTank:
    def __init__(self, Emax=2.0, eta=0.8, delta_t=0.002,
                 Kp_max=800.0, dx_max=0.02, meff_max=2.0):
        self.e, self.Emax, self.eta, self.delta_t = Emax, Emax, eta, delta_t
        self.Kp_max, self.dx_max, self.meff_max = Kp_max, dx_max, meff_max

    def step(self, tau_imp, qdot, dt, diss_meas):
        inj = max(0.0, float(tau_imp @ qdot) - diss_meas)
        delay = self.delta_t * float(np.linalg.norm(tau_imp)) * float(np.linalg.norm(qdot))
        self.e = min(self.Emax, max(0.0, self.e - inj*dt + self.eta*diss_meas*dt - delay))
        return 'dissipative' if self.e <= 1e-9 else 'ok'

    def force_bound(self, Kp, dx, v, dt_r):
        return Kp * dx + self.meff_max * v / dt_r

    def safe(self, s, F_safe, dt_r):
        return self.force_bound(s.Kp, s.dx, s.v, dt_r) <= F_safe

    def tank_feasible(self, cand):
        return cand.E_inj <= self.e + self.eta * cand.E_diss - cand.E_delay


# IP-362 ActuatorHealthLedger：执行器健康与故障自适应包络（10Hz 更新，1kHz 残差）
class ActuatorHealthLedger:
    def __init__(self, n, Ko=20.0, r_max=0.5, eps_ph=0.5, eps_enc=0.01,
                 delta_h=0.15, h_min=0.6, h_fail=0.3):
        self.n, self.Ko, self.r_max = n, Ko, r_max
        self.eps_ph, self.eps_enc = eps_ph, eps_enc
        self.delta_h, self.h_min, self.h_fail = delta_h, h_min, h_fail
        self.p = np.zeros(n); self.r = np.zeros(n); self.integral = np.zeros(n)
        self.h = np.ones(n); self.brake_ok = np.ones(n, dtype=bool)

    def observe(self, iq_m, iq_cmd, tau, qdot, C, g, i_sum, q_enc, q_hall, dt):
        # 广义动量观测器（无加速度）
        self.integral += (tau + C.T @ qdot - g + self.r) * dt
        self.r = self.Ko * (self.p - self.integral)
        hi = 1 - np.clip(np.abs(iq_m - iq_cmd) / 0.2, 0, 1)
        ho = 1 - np.clip(np.abs(self.r) / self.r_max, 0, 1)
        hph = 1 - np.clip(np.abs(i_sum) / self.eps_ph, 0, 1)
        henc = 1 - np.clip(np.abs(q_enc - q_hall) / self.eps_enc, 0, 1)
        hb = self.brake_ok.astype(float)
        self.h = np.minimum.reduce([hi, ho, hph, henc, hb])
        return self.h

    def inflate(self, E_tau):
        return [[(lo - self.delta_h*(1-h), hi + self.delta_h*(1-h))
                 for (lo, hi), h in zip(step, self.h)]
                for step in E_tau]

    def status(self):
        if np.min(self.h) < self.h_fail:
            return 'sts'
        if np.min(self.h) < self.h_min:
            return 'derate'
        return 'ok'

    def max_chunk(self):
        return max(1, int(self.K_max * float(np.min(self.h))))


# IP-361/364/363 集成：力矩感知块生成
class TorqueAwareCertifier(StructuredChunkCertifier):
    def __init__(self, *a, tte=None, teb=None, pet=None, ahl=None,
                 f_safe=50.0, dt_r=1e-3, dt=0.02, eps_cert=1e-3, **kw):
        super().__init__(*a, **kw)
        self.tte, self.teb, self.pet, self.ahl = tte, teb, pet, ahl
        self.f_safe, self.dt_r, self.dt, self.eps_cert = f_safe, dt_r, dt, eps_cert

    def generate_chunk(self, state, ctx, stf, nrb):
        # 1) 上层 v10 门控：Δ_dom、语义信任场、有效块长
        K10 = self.effective_K(ctx.delta_dom, ctx.tau_dom, stf.trust_ok(ctx))
        if K10 == 1:
            return self._single_step_fallback(state)
        # 2) 执行器层预门控：健康/热
        if self.ahl.status() == 'sts':
            return self._sts_chunk(state)
        K = min(K10, self.ahl.max_chunk())
        best = None
        for cand in self.policy.sample_sequences(state, K, n=64):
            pred = self.Fq.rollout(state, cand)
            # 3) TTE：逐 k 逐关节力矩区间
            E_tau = self.tte.pred_chunk(cand.iq_seq, pred.omega_seq, state.Tw, self.dt)
            E_tau = self.ahl.inflate(E_tau)
            if not all(state.actuator_safe_sets[j].contains(lo, hi)
                       for step in E_tau
                       for j, (lo, hi) in enumerate(step)):
                continue
            # 4) 热/再生/电耗预算
            tau_hi_seq = [[max(abs(lo), abs(hi)) for (lo, hi) in step]
                          for step in E_tau]
            theta, regen, regen_budget, elec = self.teb.predict(
                tau_hi_seq, pred.omega_seq, state.Tw, self.dt)
            if theta < 0 or regen > regen_budget or elec > state.E_m:
                continue
            # 5) 无源能量罐 + 接触力界（按 STF/NRB 的人-机距离分级）
            F_safe = self.f_safe_for(stf, nrb)
            if not self.pet.safe(cand.contact, F_safe, self.dt_r):
                continue
            if not self.pet.tank_feasible(cand):
                continue
            # 6) 覆盖置信度（union bound）
            c_tau = (1 - self.tte.eps_tau) ** (K * state.n)
            if c_tau < 1 - self.eps_cert:
                continue
            # 7) v10 证书 + NRB 审查
            chunk = Chunk(cand, CertTau(g_min=pred.min_clearance,
                                        E_tau=E_tau, F_contact=F_safe,
                                        theta=theta, regen=regen,
                                        h=self.ahl.h,
                                        beta_stf=self.beta_stf(pred, stf),
                                        c_tau=c_tau),
                          self._abort_points(state, cand, pred))
            chunk, verdict = nrb.review_chunk(chunk, stf, ctx)
            if chunk is None:
                continue
            if best is None or self.policy.score(chunk, pred) > best.score:
                best = chunk
        return best or self._single_step_fallback(state)

    def midchunk_guard(self, chunk, k, live, stf, nrb):
        # v10 四检（定义 547）
        v10 = super().midchunk_guard(chunk, k, live, stf, nrb)
        if v10[0] == 'abort':
            return v10
        # v11 增检：执行器健康、热、再生、力、能量罐
        if self.ahl.status() == 'sts':
            return ('abort', self._nearest_abort(chunk, k), 'sts')
        if self.ahl.status() == 'derate':
            chunk.cert.E_tau = self.ahl.inflate(chunk.cert.E_tau)
        theta, regen, regen_budget, _ = self.teb.predict(
            chunk.remaining_tau_hi(k), chunk.remaining_omega(k), live.Tw, self.dt)
        if theta < 0 or regen > regen_budget:
            return ('abort', self._nearest_abort(chunk, k), 'thermal')
        F_safe = self.f_safe_for(stf, nrb)
        if self.pet.force_bound(live.Kp, live.dx, live.v, self.dt_r) > F_safe:
            return ('abort', self._nearest_abort(chunk, k), 'force')
        if self.pet.e <= 1e-9:
            return ('abort', self._nearest_abort(chunk, k), 'passivity')
        return ('continue', k + 1)


# IP-366 1kHz 反射弧：只减不增，快环否决
def actuator_reflex_1khz(joint, obs, tte, teb, pet, ahl, invalidation):
    h = ahl.observe(obs.iq_m, obs.iq_cmd, obs.tau, obs.qdot,
                    obs.C, obs.g, obs.i_sum, obs.q_enc, obs.q_hall, obs.dt)
    for j in range(len(obs.iq_m)):
        lo, hi = tte.interval(obs.iq_m[j], obs.omega[j], obs.Tw[j])
        if not (lo - 1e-9 <= obs.tau[j] <= hi + 1e-9):
            invalidation.set('tte')
    if teb.warn(obs.Tw, obs.regen):
        invalidation.set('thermal')
    if pet.step(obs.tau_imp, obs.qdot, obs.dt, obs.diss_meas) == 'dissipative':
        invalidation.set('passivity')
    if pet.force_bound(obs.Kp, obs.dx, obs.v, obs.dt_r) > obs.F_safe:
        invalidation.set('force')
    if ahl.status() == 'sts':
        invalidation.set('sts')
        return sts(joint, obs)          # 抱闸/重力补偿/受控下放
    if ahl.status() == 'derate':
        return derate(joint, obs, alpha=0.6), 'derate'
    if invalidation.any():
        return derate(joint, obs, alpha=0.8), 'derate'
    return obs.tau_cmd, 'ok'

## 3. 推导

**引理 92（TTE 的覆盖性与对 v10 的支配/修复）** 设 (A1) 参数区间在运行包络内包含真值（E591 标定）；(A2) |i_q^m−i_q|≤δ_i(ω)（E592）；(A3) 齿槽/摩擦/未建模力矩幅值 ≤ρ_j（E594）；(A4) 区间运算保守。则对每个 t，P(τ_act,j(t)∈E_τ,j(t))≥1−ε_τ；块内 P(∀k,j)≥1−K·n·ε_τ。并且：
(i) 当执行器健康且 T_w≤T_ref 时，若 τ_eff,j≥sup E_τ,j，则 E_τ,j⊆[−τ_eff,j,τ_eff,j]，v11 的可行动作集在 effort 维上 ⊆ v10 ⇒ 行为支配；
(ii) v10 的固定界在冷端可能被真实力矩突破（k_t 随温度降低而升高，冷态同电流产生更大 τ），在热端可能失去权限（k_t 下降 + R_s 上升 + 热降额 ⇒ 实际可用 τ_max 低于额定 τ_eff，重力补偿/制动可能不足）；TTE 用参数区间与热端 τ_max^- 同时覆盖这两种方向。
证明：(i) 由区间包含与 τ_eff 的定义直接得；(ii) 冷端取 T_w<T_ref，k_t(T_w)>k_t0，令 i_q=i_q^cmd，则 τ_act=k_t(T_w)i_q>k_t0 i_q，若 k_t0 i_q 接近 τ_eff 则 τ_act>τ_eff；热端由定义 549 的 k_t(T_w) 单调下降、R_s(T_w) 单调上升及 A_j 的 τ_max^- 得可用力矩下界低于额定值。v10 只用额定常数，故两种边界都可能静默失效；TTE 将其显式化。∎

**引理 93（热/再生安全）** 设 (A1) R_th^+≥R_th、C_th^-≤C_th、T_amb^+≥T_amb；(A2) P_cu^+≥P_cu 且 P_iron^+、P_mech^+ 分别为上界；(A3) 初始 T_w(0)≤T̂_w(0)。则保守热 ODE 的解逐点上界真实温度：T_w(t)≤T̂_w(t)，∀t。若块内 Θ≥0，则绕组温度不超过 T_w,max−δ_T；若 E_regen≤E_bus^safe+E_brake，则母线电压不超过 V_max（在电容/斩波模型内）。证明：一阶 ODE 的比较原理；右端对 R_th、C_th^-、T_amb、P_loss 单调；再生能量与母线电压由电容能量平衡给出。∎

**引理 94（无源性与接触力界）** 设 (A1) 力矩跟踪误差落在 TTE 内；(A2) 反射/检测时延 Δt_r≤1ms；(A3) 能量罐更新使用实测/估计耗散，η_diss≤1，并扣除延迟项 ΔE_delay；(A4) 接触力模型 F=K_p δ_x+m_eff v/Δt_r 为上述界。则：
(i) 阻抗控制的机器人-接触系统无源：存储能量（动能+弹性势能+e_tank）不增超过外部输入；e_tank=0 时耗散回退仍无源；
(ii) 若块满足 C_safe(F_safe) 且反射弧执行 v≤v_safe，则 F_contact≤F_safe；
(iii) 罐空后速度单调下降（纯阻尼/冻结），接触力随速度下降，不产生极限环。
证明：无源性由能量平衡与罐的递推式直接得；延迟项扣除保证离散/延迟系统仍满足耗散不等式；力界由冲量-动量定理与准静态刚度项相加；耗散回退的阻尼矩阵正定。∎
注：无源性不自动给出力界，二者是并列条件；这是 v11 与"只讲柔顺"的方案的关键区别。

**引理 95（执行器故障检测与 STS 安全/支配）** 设 (A1) 故障幅值 ≥δ_f 时，广义动量观测器残差在 N_d 个 1ms 周期内超过 r_th（E598 标定）；(A2) 健康度随残差单调下降；(A3) 故障自适应包络 E_τ^h 在检测窗口内覆盖故障后的力矩误差；(A4) STS 的抱闸或受控下放已认证。则：
(i) 检测时延 ≤N_d·T_r；
(ii) 检测窗口内证书仍 sound（由 δ_h 膨胀覆盖）；
(iii) h<h_fail 后 STS 保证无自由落体、最终动能 ≤½m_eff ε_v²、接触力 ≤F_safe；且 STS 的动作集 ⊆ 允许故障动作集，支配"零力矩"（零力矩可能自由落体）。
证明：残差阈值 ⇒ 检测；包络膨胀 ⇒ 覆盖；STS 的势能/动能不等式与抱闸力矩上界 ⇒ 安全；支配性由"零力矩"是 STS 的边界特例（τ_b=0,D_STS=0,g 项缺失）直接得。∎
注：若故障是瞬时大电流（相间短路），δ_h 可能来不及覆盖；此时 1kHz 电流限幅与抱闸是最后防线，E598 必须包含该场景。

**引理 96（多速率组合与不漏检）** 设 (A1) 1kHz 反射 WCET≤1ms 且优先级最高；(A2) 50Hz 守卫 WCET≤0.5ms；(A3) 5Hz 块生成 ≤12ms 且证书原子发布（epoch 版本号）；(A4) 每次动作 dispatch 前检查 invalidation_flag/epoch。则块执行期间发生的力矩/热/力/罐违规在 ≤1 个反射周期内被检出并置位；置位后旧 epoch 的块在下一次 dispatch 前作废，不会继续执行超过一个反射周期的违规动作。证明：优先级保证反射不被慢环阻塞；flag/epoch 的检查顺序保证"先置位、后 dispatch"；对周期数归纳。∎

## 7. 本轮最大风险

**一句话**：TTE 的窄区间依赖 k_t/R_s/热参数/接触刚度的在线可辨识性，而温度、磁饱和、减速器摩擦与接触刚度往往在同一个残差里不可分；一旦标定漂移或环境刚度远超假设，证书会用"看似物理"的窄区间掩盖真实的力矩/接触力超限，且 1kHz 反射与 50Hz 证书之间的时序缝隙可能让一次冲击在证书更新前发生——这比 v10 的"已知的宽保守"更危险，因为它把不确定性从"承认宽"变成了"错误地相信窄"。
