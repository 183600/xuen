# 第 69 轮（承接第 68 轮「CALM-RAS」IP-243~252；灵感循环新循环第 2 轮；本轮灵感：「多模态交互」×「机械臂」）

> 第 68 轮 CALM-RAS 把「测量可信度」升级为在线标定潜变量，用零标签自监督与单模型多任务回答了「我的测量还准吗」，也亲手写下了原罪：**标定能力越强，落在标定带宽内的缓变故障越隐形**。但更深的病根不在滤波器，而在**辨识方式本身**：R68 始终是被动的——它在静态段等待残差，在残差里猜测「世界变了 / 传感器歪了 / 模型漂了」。当慢故障与标定漂移以纯加性偏置进入同一可观测子空间时，二者在信息论上不可分；这不是滤波器不够好，而是**被动数据里根本没有区分它们的信息**。
>
> 本轮两个灵感各补一半：
>
> - **机械臂**不只是一个被控对象，而是一台**可编程实验平台**。改变构型可让重力在力/力矩传感器上重新分布；自由空间正弦轨迹可激发关节力矩动力学；有界接触轻敲/抖动可激发接触刚度与传感器非线性。于是「参数是否可辨识」第一次成为系统自己的**可设计量**，而不是世界的恩赐——这正是持续激励（persistent excitation）与主动系统辨识的核心。
> - **多模态交互**提供两样被动观测给不了的东西：(i) **冗余仪器阵列**——视觉/触觉/力/本体/音频对同一次已知激励给出独立见证，单仪器故障可被多数投票隔离；(ii) **可询问的外部参照**——当物理探针不安全或信息不足时，人的语言/手势可作为最后一种「外部计量」，但人本身也必须被建模为有可靠度、有延迟、可能被欺骗的模态。
>
> 核心命题：
>
> **AMI-RAS（Active Multimodal Identifiability RAS，主动多模态可辨识性风险自适应闭环）——把交互当作实验：在经认证的安全壳内，选择使潜在成因可辨识的探针动作；用多模态冗余见证隔离坏仪器、用外部参照打破内部自洽；先可辨识，后归因；不能辨识，就收缩。**
>

## 0. 直觉与动机

**灵感 1（机械臂 → 机器人是唯一能主动设计数据的传感器）**
直觉：R68 最绝望的场景是「传感器慢漂 + 慢故障同时发生，静态段里它们长得一模一样」。但机械臂有一个任何被动监测都没有的自由度：**它能改变自己和世界的关系**。把末端转到另一个姿态，重力在六维力传感器上的投影就变了；做一次已知的正弦抖动，关节力矩传感器的增益误差会以不同频率响应暴露；轻敲一下已知刚度的表面，接触非线性会产生被动数据里永远看不到的谐波。被动观测是「看世界碰巧给了什么」，主动交互是「问世界一个精心设计的问题」。可辨识性从「运气」变成「规划」。

**灵感 2（多模态交互 → 冗余仪器 + 可询问的外部参照）**
直觉：单一模态的故障会伪装成世界异常。但视觉、触觉、力、本体、音频在物理上由不同器件、不同链路、不同失效模式产生；对同一次已知探针，它们本应给出一致答案，分歧处就能定位「是哪一件仪器坏了」，而不是只得到「哪里不对」。更进一步，人可以用语言/手势回答「你刚才是不是碰到了一个透明杯子？」——这是闭环外部、非同一权重分布的信息源，是打破 R68「解释与被解释共用同一套权重」的关键。但人也会错、会慢、会被欺骗，所以人不是裁判，而是**一个必须标定可靠度的模态**。

**灵感 3（可辨识性 → 被动观测的根本盲区是秩亏，不是噪声）**
直觉：如果两个成因对观测的影响只差一个常数倍方向（例如标定零偏与力传感器纯加性慢漂都表现为「读数整体偏移」），那么无论采样多久、滤波多好，后验只能停在先验上——似然对该方向完全平坦。工程上表现为「越标越准，故障越隐形」。把 Fisher 信息矩阵/敏感度矩阵的**最小奇异值**作为可辨识性裕度 κ，系统就能在行动前知道「这个问题现在有没有答案」，而不是先行动、再对后验过度自信。

**灵感 4（探针有代价 → 信息增益必须除以风险）**
直觉：主动交互不是免费的。接触探针会施加力、注入能量、可能激起环境响应甚至改变环境；人机交互有打扰成本与延迟；频繁激励会加速机械磨损。因此探针选择不是「最大信息增益」，而是「**单位风险的信息增益**」：EIG(u)/ρ(u)，且受能量罐、力上限、无滑移裕度、可恢复性、人类舒适度组成的硬安全壳约束。信息有价值，但价值不能超过安全预算。

**灵感 5（多模态见证 → 用「仪器多样性」把故障从世界中分离）**
直觉：R68 的残差一致性只能告诉你「不一致」，不能告诉你「谁错了」。主动探针提供已知输入后，每个模态都能独立预测自己「应该看到什么」；在已知输入下，跨模态分歧的归因变成可计算的：一个模态偏离其余模态的共识 → 该模态故障；所有模态一致偏离 → 世界变了；力/触觉与视觉在已知接触下仍系统性不一致 → 标定或力链故障。引用一句系统辨识的常识：**要分离两个未知量，至少需要两个独立方程；要分离「世界」与「仪器」，至少需要两件独立仪器。**

**灵感 6（对 R68 原罪的正面回应与不可辨识边界）**
R68 的慢故障之所以隐形，是因为「解释」与「被解释」共用同一套权重，且系统只被动等待。AMI-RAS 引入三重外部性：(i) **主动激励**在标定带宽之外制造可观测响应（ω_p ≥ 3ω_cal），标定滤波器物理上无法吸收（R68 引理 13 的主动对偶）；(ii) **多模态见证**用异源器件打破共模；(iii) **外部参照**用人的语义知识打破参数自洽。但必须诚实：**纯加性、线性、无限慢的故障与标定漂移在任何内部探针下都可能仍然不可辨识**——此时唯一出路是外部计量或人。这不是缺陷，而是方案的边界；AMIRAS 的纪律是「边界内主动求真，边界外显式收缩」，而不是假装边界不存在。

## 1. 形式化定义（增量：定义 293–310）

**定义 293（AMI-RAS 总览与三不变式）** AMI-RAS = (MIM, PIM, PEP, CSS, MWV, HIT, AID, PAC, AIC-AMI, J-AMI, RAS-WM†)。三条不变式：
(i) **可辨识优先**：任何被用于控制决策的成因 θ，必须满足 κ(u) ≥ τ_id 且成对可分性 D_ij ≥ τ_sep；否则该成因进入歧义集 𝒜，按最坏情况处理；
(ii) **探针安全壳**：任何物理探针必须先通过 CSS 的静态认证，执行中由**独立于学习模型的硬件监控**（力矩/电流限幅、机械柔顺、看门狗）实时兜底；
(iii) **信息不回避**：若歧义集包含 H_slow 或 H_fast 且其后验超过 ε_f，系统不得以「不探针」来逃避保守回退；要么执行合规探针，要么显式收缩并记入审计。

**定义 294（交互事件图）** 交互表示为事件图 G_t = (E_t, R_t)。事件 e_k = (t_k, type, m, payload) 来自模态 m ∈ {vis, tac, force, prop, audio, lang, gesture}；类型含接触起始/力峰/滑移起始/形变/注视/话语轮次。边 R 含时序边、物理因果边（接触 → 力峰 → 形变）、指称边（注视/手势 → 物体）、语言边（话语 → 指称）。对齐使用 R68 的 Δt_sync 估计，容差 τ_evt。

**定义 295（MIM 多模态交互模型）** 在 R68 MTM 的共享 trunk z_t ∈ ℝ²⁵⁶ 上增加两个头：
- `interact_head`: (z_t, a^p) → {(ŷ_m, Σ_m)}_{m=1}^{6}，预测候选探针 a^p 在各模态上的期望响应；
- `probe_head`: (z_t, a^p) → 探针响应类别（无接触/线性/非线性/滑移/异常）。
其余 emo/fault/wm/cal/qual 五头保留。一次 trunk 前向 + 两头轻量推理，保证「同一潜状态解释交互」。

**定义 296（成因空间）** θ = (c, f_s, f_f, w, h) ∈ Θ：c 为 R68 标定潜变量（慢、可吸收），f_s 为慢故障（如增益退化、迟滞、渐进松动），f_f 为快故障（断线、突跳、卡死），w 为真实世界变化，h 为人类意图/指称。控制相关的成因类别为 {CAL, SLOW, FAST, WORLD, HUMAN}。

**定义 297（可辨识性裕度）** 对观测模型 y = h(θ, u) + ε, ε ~ 𝒩(0, R)，定义敏感度 S(u) = ∂E[y|θ,u]/∂θ 与先验尺度 Σ_θ。可辨识性裕度
κ(u) = σ_min( R^{-1/2} S(u) Σ_θ^{1/2} )，
即成对成因 i,j 的可分性 D_ij(u) = ‖R^{-1/2}(μ_i(u) − μ_j(u))‖²。可辨识 ⇔ κ(u) ≥ τ_id ∧ min_{i≠j} D_ij(u) ≥ τ_sep。歧义集 𝒜_t = {θ : p(θ | y_{≤t}) ≥ ε_amb}。

**定义 298（被动不可辨识子空间）** 对纯加性模型 y = c + f_s + w + ε，在名义输入 u=0 下 S_c = S_{f_s} = I，Fisher 矩阵在 (c, f_s) 子空间上秩亏，方向 (1, −1) 落在零空间。记该子空间为 𝒩_pass；任何被动估计器在 𝒩_pass 上的后验比恒等于先验比（引理 16）。

**定义 299（探针库与风险等级）** U = {u_r}，风险等级 r ∈ {R0, R1, R2, R3}：
- R0 非接触重构：改变臂构型使重力再分布、改变视角/光照/音频 ping；
- R1 自由空间激励：已知幅值/频率的正弦轨迹、关节空间抖动；
- R2 接触激励：有界轻敲、切向小幅抖动、抓取—抬升—放下；
- R3 人类询问：语言/手势查询，仅在社会成本与延迟可接受时使用。
每个 u 携带激励频谱 Ω(u)、幅值 A(u)、时长 τ(u)、预算能量 E(u)、可恢复动作 ρ_rec(u) 与认证标签。

**定义 300（探针价值）** 期望信息增益 EIG(u) = I(θ; y_u | y_{<t})；线性高斯下
EIG(u) = ½ log det( I + Σ_θ S(u)ᵀ R^{-1} S(u) )。
风险成本 ρ(u) = w_E E(u) + w_F P(力越界|u) + w_T τ(u) + w_S social(u)。
探针规划：u* = argmax_{u∈U} EIG(u)/ρ(u)，s.t. EIG(u) ≥ E_min, u ∈ CSS, E(u) ≤ E_budget_remaining。

**定义 301（CSS 认证安全壳）** u 必须同时满足：
1. 无源/能量：∫ vᵀF dt ≤ E_tank，机器人端口阻抗正实；
2. 力/力矩：由**独立硬件限幅**保证 |F| ≤ F_hw、|τ_j| ≤ τ_hw；
3. 无滑移裕度：|F_t| ≤ (1−m_s)·μ̂·F_n；
4. 可恢复性：存在认证逃逸动作，且从任意探针中断态可在 Δt_rec 内回到 Z_safe；
5. 人类舒适：人机距离/速度/噪声上限；
6. 激励窗口：ω_p ≥ 3ω_cal 且幅值落在期望的可辨识线性区。
静态认证 + 运行时包络监控双保险；任一越界立即中止并判 H_fast。

**定义 302（MWV 多模态见证与投票）** 给定已知探针 u，条件独立见证模型
p(θ | y, u) ∝ p(θ) Π_m p(y_m | θ, u) · q_m,
其中 q_m 为模态可靠度。定义模态 m 的见证偏差 L_m = log p(y_m|θ_cons,u) − max_{θ≠θ_cons} log p(y_m|θ,u)。若 L_m < −τ_w 且其余 M−1 个模态一致，则判 m 为坏仪器并降权；若所有模态一致偏离预期，则判 WORLD；若力/触觉与视觉在已知接触下持续不一致，则优先归因 CAL 或 SLOW。

**定义 303（HIT 人类交互信任）** 人类回答 y_h 是一个带可靠性 q_h、延迟 L_h、指称歧义与潜在欺骗的模态。融合模型 p(y_h | h) 由校准混淆矩阵给出；未校准时用保守下界 q_h ≥ 0.6。查询成本 ρ_h = w_T L_h + w_S social。**人不是安全裁判**：人的回答只能改变成因后验，不能突破 CSS；拒绝/超时按缺失证据处理，不得当作确认。

**定义 304（AID 主动可辨识纪律）** 若 𝒜_t ∩ {SLOW, FAST} ≠ ∅ 且 max p ≥ ε_f：
- 若存在合规 u 使 EIG(u) ≥ E_min 且 E(u) ≤ 剩余预算 → **必须**执行价值最高的探针；
- 否则 → 冻结归因，取歧义集上的最坏风险 θ_wc = argmax_{θ∈𝒜} risk(θ)，并施加 λ_floor、k 收缩；
- 停止准则：max p(θ|y) ≥ 1−ε_stop 或 H(θ|y) ≤ H_stop 或预算耗尽；
- 信息回避审计：若歧义含故障却未探针且未收缩，记入 ℰ_avoid 并强制下一轮补探。

**定义 305（PAC 探针感知认证）** 三阶段：
1. **事前**：探针计划过 CSS 静态门 + 价值门（EIG/风险）+ 可恢复性门；
2. **事中**：硬件包络监控，偏离预测包络 > 3σ 即中止，并按「探针揭示异常」而非「探针失败」记录；
3. **事后**：探针日志入 J-AMI；CAC 新增 canary 探针——影子适配器必须能在注入慢故障的 canary 上通过主动辨识，否则一票否决。

**定义 306（AIC-AMI 干扰集）** ℰ_AMI = ℰ_CALM × ℰ_probe × ℰ_witness × ℰ_human × ℰ_avoid：
- ℰ_probe = {探针致伤、探针扰动世界、探针被环境欺骗/规避、失准下认证探针}；
- ℰ_witness = {模态共模故障、见证投毒、条件独立性失效}；
- ℰ_human = {人错、人慢、人被欺骗、指称歧义}；
- ℰ_avoid = {信息回避、探针预算饥饿、只问容易问题}。

**定义 307（J-AMI 证书）** J-AMI = (J_CALM, probe_log_hash, κ_cert, 𝒜_t, excitation_spectrum, witness_votes, human_query_log, probe_risk_ledger, ami_ver)。Valid ⇔ Valid(J_CALM) ∧ 被采用成因均满足 κ ≥ τ_id ∧ 风险台账未超预算 ∧ 歧义含故障时已收缩或已合规探针。

**定义 308（管线）** 离线：多模态自监督预训练 MIM（事件预测 + 探针响应预测）→ 探针库建模与 CSS 证书生成 → 见证可靠度校准 → 注入慢故障/非线性故障做主动辨识回归 → PAC 首次提交。在线：被动 CALM 监测 → 歧义触发 PEP 规划 → CSS 认证执行 → MWV/HIT 融合归因 → 收缩或行动 → 日志与异步审计。

**定义 309（探针指纹）** 对探针 u_p(t) = A sin(ω_p t)，响应分解 y_p(t) = A_1 sin(ω_p t + φ_1) + Σ_{k≥2} A_k sin(kω_p t + φ_k) + r_dc。定义指纹 h(u_p) = (A_2/A_1, A_3/A_1, 20log₁₀(A_1/A))。**标定不变性**：纯加性标定只改变 r_dc 与低频项，不改变谐波比；增益故障改变基频增益；非线性/迟滞故障抬高谐波比。故 h 是区分 CAL 与 SLOW 的校准不变量。

**定义 310（探针风险台账）** 维护累计能量 E_used、峰值力余量、社会打扰次数、探针频次。硬上限 E_used ≤ E_total；软约束用于防止「连续探针刷信息」。台账是 J-AMI 的必填项，且跨轮保留。

class MultimodalInteractionModel:
    def forward(self, obs, a_prev, ctx, tasks=('emo','fault','wm','cal','qual','interact')):
        z = self.trunk(obs, a_prev, ctx)          # 同源潜状态，五头共享
        out = {t: self.heads[t](self.adapters[t](z)) for t in tasks if t != 'interact'}
        return z, out

    def predict_probe(self, z, probe):
        # 返回每个模态的期望响应与协方差，供 EIG 与见证残差使用
        return self.heads['interact'](z, probe)    # {m: (y_hat_m, Sigma_m)}

    def probe_class(self, z, probe):
        return self.heads['probe'](z, probe)       # 无接触/线性/非线性/滑移/异常


# IP-254 PIM：可辨识性分析（敏感度/Fisher 秩）
class ProbeIdentifiabilityModule:
    def __init__(self, theta_dim=16, tau_id=0.15, tau_sep=2.0):
        self.p, self.tau_id, self.tau_sep = theta_dim, tau_id, tau_sep

    def margin(self, theta, probe, R, Sigma_theta):
        S = numeric_jacobian(lambda th: expected_obs(th, probe), theta)  # p×d
        W = inv_sqrt(R)
        M = W @ S @ sqrtm(Sigma_theta)
        kappa = svdvals(M)[-1]                    # 最小奇异值
        return kappa, pairwise_separability(theta, probe, R)

    def ambiguous(self, post, kappa, sep):
        A = {th for th, p in post.items() if p >= EPS_AMB}
        return (kappa < self.tau_id or min(sep) < self.tau_sep), A

        S = numeric_jacobian(lambda th: expected_obs(th, probe), theta_post.mean)
        return 0.5 * logdet(eye(self.p) + Sigma_theta @ S.T @ inv(R) @ S)

    def plan(self, post, css, ledger):
        best = None
        for u in self.U:                          # |U| <= 12，可近穷举
            if not css.static_ok(u, post) or u.energy > ledger.remaining:
                continue
            if self.eig(post, u, R, Sigma_theta) < E_MIN:
                continue
            val = self.eig(post, u, R, Sigma_theta) / risk_cost(u, post)
            best = max(best, (val, u), key=lambda x: x[0])
        return None if best is None else best[1]

## 3. 推导

**引理 16（被动不可辨识界——R68 病理的根源）** 对纯加性慢故障与标定模型 y = c + f_s + w + ε，在名义输入 u=0 下 S_c = S_{f_s} = I，Fisher 矩阵 F = σ^{-2}[I I]ᵀ[I I] 在 (c, f_s) 子空间上秩为 1；方向 v = (1, −1)/√2 满足 Fv = 0。故任一被动估计器在 v 方向上的后验比恒等于先验比，最小可辨识裕度 κ(0) = 0。系：R68 的 CFA 对该子类故障的判别只反映先验，而不反映数据；「标定吸收故障」不是阈值问题，是秩亏问题。

**引理 17（主动激励恢复可辨识性——引理 13 的主动对偶）** 施加探针 u_p(t) = A sin(ω_p t)，ω_p ≥ 3ω_cal。R68 的标定滤波等效带宽为 ω_cal，故标定通道在 ω_p 处的增益 |H_c(jω_p)| ≤ ω_cal/ω_p ≤ 1/3，**探针响应不可能被标定吸收**（这正是引理 13 反吸收界在主动端的镜像）。若故障带有增益/非线性签名，则响应基频增益与谐波比（定义 309）是 c 的不变量：
κ(u_p) ≥ (A/σ)·√(1 − |H_c(jω_p)|²)·|∂g_f/∂f| ≥ (√8/3)·(A/σ)·|∂g_f/∂f| > 0。
故故障签名非零时，κ(u_p) ≥ τ_id 可在有限探针时长内达成；纯加性线性故障的签名项为零，κ 仍为 0（见定理 17 的不可辨识边界）。

**引理 18（EIG 的子模性与贪婪界）** 在线性高斯模型下，集合信息增益 EIG(S) = ½ log det(I + Σ ∑_{u∈S} S_uᵀ R^{-1} S_u) 关于探针集合 S 单调、子模。基数约束下贪婪算法达到 (1−1/e) 近似最优。风险预算约束下使用拉格朗日松弛 EIG(u) − μρ(u) 的比率贪婪；由于 |U| ≤ 12，工程上直接枚举即得精确最优，故理论界主要用于说明「短视探针仍接近最优」。

**引理 19（多模态见证的多数界）** 设 M 个模态在给定成因下条件独立，各自判对概率 p_m ≥ 1/2 + γ。由 Hoeffding 不等式，多数投票错误率 P_err ≤ exp(−2Mγ²)。若仅一个模态故障（判对概率 < 1/2）且 M ≥ 3、其余模态一致，则多数结论仍由健康模态决定；故单仪器故障可被隔离而不会翻转归因。系：**多模态的价值不是「更准的平均」，而是「可分离的失效模式」**。

**定理 16（AMI-RAS 端到端风险一致性）** 在 R68 的 A87–A94 及新增 A95（探针响应可加性）、A96（见证条件独立）下：
1. P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + **α_probe + α_ident + α_human**；其中 α_probe 由 CSS 认证与硬件限幅约束，α_ident 由停止准则与 κ ≥ τ_id 约束，α_human 由 q_h 下界约束；
2. 若 𝒜_t 含 SLOW/FAST 且无法合规探针 ⇒ λ_risk ≥ 0.8 ∧ τ_risk 收紧 ∧ k 收缩——**不能辨识永远导向收缩**；
3. 探针在 ω_p ≥ 3ω_cal 时不被标定吸收（引理 17），故主动辨识不牺牲 R68 的慢故障—标定分离能力；
4. 单模态故障导致归因翻转的概率 ≤ exp(−2(M−1)γ²)，M ≥ 3 时指数小。

**定理 17（慢故障可检测性前沿与不可辨识边界）** 对带增益/非线性签名、幅度 δ 的慢故障，主动探针的检测概率随探针信噪比 SNR_p = (A δ/σ)² 单调上升，且存在 N_probe 使 P_det ≥ 1−η 在安全壳允许的幅值/时长内达成。反之，对纯加性、线性、无限慢的故障子类，c 与 f_s 在任意内部探针下仍不可辨识（引理 16 的零空间不因任何内部输入而扩张）；此时唯一出路是**外部参照**——人、外部计量、或已知物理基准。系：AMI-RAS 的能力边界是「可激励的故障签名」，不是「所有慢故障」。

## 6. 本轮最大风险

**一句话**：AMI-RAS 的「安全壳」是由可能正被慢故障污染的测量链来认证的——**诊断动作的合法性依赖于被诊断对象本身；若故障同时偏置了力/位置估计，一个被判定为「安全」的探针可能正是致伤动作，这是主动辨识的认知循环（epistemic circularity）**。

**次级风险与缓解**：
1. **不可辨识边界**：纯加性线性慢故障对任何内部探针都不可分（定理 17）→ 显式声明边界 + 外部计量/人 + 保守回退，绝不假装可辨；
2. **探针扰动世界**：激励本身改变被辨识对象（接触改变摩擦/变形）→ 探针前后双基线 + 世界变化 w 作为独立成因 + 可逆探针优先；
3. **见证共模失效**：多模态共享机械/电源/时钟故障 → 条件独立假设审计 + 引入物理异源（音频/视觉/力） + 共模检测；
4. **人类被欺骗/指称歧义** → q_h 保守下界 + 多轮指称消歧 + 人言永不覆盖物理安全；
5. **信息回避/探针预算饥饿** → 强制补探审计 + 探针义务 + 风险台账硬上限（防刷也防逃）；
6. **探针致磨损** → 探针频次/能量软约束 + 优先 R0/R1 + 磨损计入长期成本。

**定义 293（总览与三不变式）** 可辨识优先（被采用成因须 κ ≥ τ_id 且 D_ij ≥ τ_sep，否则入歧义集）；探针安全壳（CSS 静态认证 + 独立硬件限幅/柔顺/看门狗）；信息不回避（歧义含慢/快故障时不得靠「不探针」逃避保守回退）。

**定义 294（交互事件图）** `G_t=(E_t,R_t)`，事件来自 vis/tac/force/prop/audio/lang/gesture，边含时序、物理因果（接触→力峰→形变）、指称、语言；用 R68 的 Δt_sync 对齐，容差 τ_evt。

**定义 295（MIM）** R68 MTM 的 trunk `z_t∈ℝ²⁵⁶` 上增加 `interact_head: (z_t,a^p)→{(ŷ_m,Σ_m)}` 与 `probe_head: (z_t,a^p)→响应类别`；其余五头保留，保证同源解释。

**定义 296–297（成因空间与可辨识性）** 敏感度 `S(u)=∂E[y|θ,u]/∂θ`；`κ(u)=σ_min(R^{-1/2}SΣ_θ^{1/2})`；`D_ij(u)=‖R^{-1/2}(μ_i−μ_j)‖²`；可辨识 ⇔ κ ≥ τ_id ∧ min D_ij ≥ τ_sep。

**定义 298（被动不可辨识子空间）** 纯加性模型 `y=c+f_s+w+ε` 在 u=0 下 `S_c=S_{f_s}=I`，Fisher 在 (c,f_s) 子空间秩 1，方向 `(1,−1)/√2` 落入零空间 𝒩_pass；被动后验比 = 先验比（引理 16）。

**定义 299（探针库）** R0 非接触重构（重力再分布/视角/光照/音频 ping）；R1 自由空间正弦/关节抖动；R2 有界轻敲/切向抖动/抓取—抬升—放下；R3 人类询问。每个探针带频谱、幅值、时长、能量、可恢复动作、认证标签。

**定义 300（探针价值）** `EIG(u)=½logdet(I+Σ_θSᵀR^{-1}S)`；`ρ(u)=w_E E+w_F P(越界)+w_Tτ+w_S social`；`u*=argmax EIG/ρ` s.t. `EIG≥E_min, u∈CSS, E≤预算`。

**定义 301（CSS 安全壳）** 无源/能量罐；力/力矩**硬件限幅**；无滑移裕度 `|F_t|≤(1−m_s)μ̂F_n`；可恢复逃逸；人类舒适；`ω_p≥3ω_cal` 且幅值落在线性可辨识区。静态认证 + 运行时包络监控（3σ 越界即中止）。

**定义 302（MWV 见证）** `p(θ|y,u)∝p(θ)Π_m p(y_m|θ,u)q_m`；见证偏差 `L_m`；`L_m<−τ_w` 且其余一致 ⇒ m 坏仪器降权；全体一致偏离预期 ⇒ WORLD；力/触觉与视觉在已知接触下持续不一致 ⇒ 优先 CAL/SLOW。

**定义 303（HIT 人类信任）** 人回答带可靠度 `q_h`、延迟 `L_h`、指称歧义与欺骗；未校准取 `q_h≥0.6`；人言只改后验、不破 CSS；拒绝/超时 = 缺失证据。

**定义 304（AID 纪律）** 歧义含 SLOW/FAST 且 `max p≥ε_f`：有合规探针（EIG≥E_min、预算足）⇒ **必须探**；否则冻结并按 `θ_wc=argmax_{𝒜} risk` 最坏情况归因 + λ_floor + k 收缩；停止于 `max p≥1−ε_stop` 或 `H≤H_stop` 或预算耗尽；未探未缩 ⇒ 记 ℰ_avoid 并强制补探。

**定义 305（PAC）** 事前：CSS 静态门 + 价值门 + 可恢复门；事中：硬件包络监控，越界中止并按「探针揭示异常」记录；事后：探针日志入证；CAC 增 canary 慢故障探针，影子适配器不能辨识即一票否决。

**定义 306–308（干扰集/证书/管线）** `ℰ_AMI=ℰ_CALM×ℰ_probe×ℰ_witness×ℰ_human×ℰ_avoid`；`J-AMI` Valid ⇔ Valid(J_CALM) ∧ 采用成因 κ≥τ_id ∧ 台账未超预算 ∧ 歧义含故障时已探/已缩；离线多模态自监督预训练 + 探针库/CSS 证书 + 主动辨识回归 → 在线被动监测 → 歧义触发探针 → 见证/人融合 → 收缩或行动。

**定义 309–310（探针指纹/风险台账）** 响应谐波分解，`h(u_p)=(A₂/A₁,A₃/A₁,20log(A₁/A))`；纯加性标定不改 h，增益故障改基频增益，非线性/迟滞抬高谐波比——区分 CAL 与 SLOW 的校准不变量。台账累计能量/峰值力/社会打扰/频次，硬上限 + 软约束防「探针刷信息」。

class ProbeIdentifiabilityModule:
    def margin(self, theta, probe, R, Sigma_theta):
        S = numeric_jacobian(lambda th: expected_obs(th, probe), theta)
        M = inv_sqrt(R) @ S @ sqrtm(Sigma_theta)
        return svdvals(M)[-1], pairwise_separability(theta, probe, R)

    def ambiguous(self, post, kappa, sep):
        A = {th for th, p in post.items() if p >= EPS_AMB}
        return (kappa < TAU_ID or min(sep) < TAU_SEP), A


# IP-255 PEP：EIG/风险探针规划（|U|<=12）
class ProbeExperimentPlanner:
    def eig(self, post, u, R, Sigma_theta):
        S = numeric_jacobian(lambda th: expected_obs(th, u), post.mean)
        return 0.5 * logdet(eye(P) + Sigma_theta @ S.T @ inv(R) @ S)

    def plan(self, post, css, ledger):
        cand = []
        for u in self.U:
            if not css.static_ok(u, post) or u.energy > ledger.remaining: continue
            e = self.eig(post, u, R, Sigma_theta)
            if e < E_MIN: continue
            cand.append((e / risk_cost(u, post), u))
        return max(cand, key=lambda x: x[0])[1] if cand else None

def active_identifiability_discipline(post, pim, pep, css, ledger):
    kappa, sep = pim.margin(post.mean, None, R, Sigma_theta)
    amb, A = pim.ambiguous(post, kappa, sep)

        u = pep.plan(post, css, ledger)
        return ('PROBE', u, A) if u else ('WORST_CASE', worst_case(A), A)
    return ('ACT', None, A)

## 4. 推导

**引理 16（被动不可辨识界）** 纯加性 `y=c+f_s+w+ε`、u=0 下 `S_c=S_{f_s}=I`，Fisher `F=σ^{-2}[I I]ᵀ[I I]` 秩 1，`v=(1,−1)/√2` 满足 `Fv=0`，κ(0)=0；被动后验比 = 先验比。**R68 的「标定吸收故障」是秩亏，不是阈值问题。**

**引理 17（主动激励恢复可辨识——引理 13 的主动对偶）** `u_p=A sin(ω_p t), ω_p≥3ω_cal` 时标定通道 `|H_c(jω_p)|≤ω_cal/ω_p≤1/3`，探针不被吸收；故障的增益/谐波指纹是 c 的不变量：
`κ(u_p) ≥ (A/σ)√(1−|H_c|²)|∂g_f/∂f| ≥ (√8/3)(A/σ)|∂g_f/∂f| > 0`。
签名非零 ⇒ 有限时长内 κ≥τ_id；纯加性线性故障签名项为零 ⇒ κ 仍 0（见定理 17 边界）。

**引理 18（EIG 子模性）** 线性高斯下集合 EIG 单调、子模；基数约束贪婪达 (1−1/e)。风险预算用拉格朗日比率贪婪；|U|≤12 时直接枚举得精确最优。

**引理 19（多模态见证多数界）** M 个条件独立模态各判对 `p_m≥1/2+γ`，Hoeffding 给 `P_err≤exp(−2Mγ²)`；单模态故障且 M≥3、其余一致 ⇒ 结论由健康模态决定；多模态价值在**可分离失效模式**。

**定理 16（端到端风险一致性）** 
1. `P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_probe+α_ident+α_human`（α_probe 由 CSS/硬件限幅约束，α_ident 由停止准则与 κ 约束，α_human 由 q_h 下界约束）；
2. 歧义含 SLOW/FAST 且无合规探针 ⇒ λ≥0.8 ∧ τ_risk 收紧 ∧ k 收缩；
3. `ω_p≥3ω_cal` 探针不被标定吸收，主动辨识不损 R68 分离能力；
4. 单模态故障致归因翻转概率 ≤ exp(−2(M−1)γ²)。

**定理 17（慢故障前沿与不可辨识边界）** 带增益/非线性签名、幅度 δ 的慢故障：检测概率随 `SNR_p=(Aδ/σ)²` 单调上升，安全壳内存在 `N_probe` 使 `P_det≥1−η`。纯加性线性无限慢故障：c 与 f_s 在任意内部探针下仍不可辨识（引理 16 零空间不因内部输入扩张），唯一出路是外部参照（人/外部计量/物理基准）。系：**能力边界是「可激励的故障签名」，不是「所有慢故障」。**

## 7. 本轮最大风险

**一句话**：AMI-RAS 的「安全壳」由可能正被慢故障污染的测量链来认证——**诊断动作的合法性依赖于被诊断对象本身；若故障同时偏置了力/位置估计，一个被判定为「安全」的探针可能正是致伤动作，这是主动辨识的认知循环（epistemic circularity）**。

**次级风险与缓解**：不可辨识边界（纯加性线性慢故障无内部解，只能外部参照 + 显式声明）；探针扰动世界（前后双基线 + 世界变化 w 独立成因 + 可逆探针优先）；见证共模失效（条件独立审计 + 物理异源 + 共模检测）；人类被欺骗/指称歧义（q_h 保守下界 + 多轮消歧 + 人言不覆盖物理安全）；信息回避/预算饥饿（强制补探 + 探针义务 + 台账硬上限）；探针磨损（频次/能量软约束 + 优先 R0/R1）。
