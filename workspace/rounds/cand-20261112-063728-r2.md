# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化证据承诺」IP-133~138；灵感循环第 4 轮；本轮灵感：「任务规划」×「灵巧手」）

> 第 57 轮把单点承诺做成"证据说可信"：元少样本摊销、跨模态对账、个性化有界信任。但它仍是**局部、反应式**的——每个检查点独立取证、独立承诺，计划只是"检查点序列"，证据的**全局时序价值**从未被建模。一旦把平台从"四足过地形"推进到"灵巧手做长程操作"，两个裂口立刻暴露：**(a) 长程计划的联合界失效**：第 57 轮部署界是对检查点取 union bound，几十次接触后 Σδ 迅速超过 1，界变成废纸；而灵巧操作的失败大多是**可恢复**的（掉落可重抓、滑移可再握），把它与"摔下悬崖"同价计费，既悲观又掩盖了真正不可逆的那几步。**(b) 符号前提与接触现实脱节**：TAMP 把"可抓/稳定"当布尔前提，灵巧手却要通过一族接触模式（捏/握/指尖/in-hand）在欠驱动、摩擦不确定下把它实现出来；在符号层承诺一个计划，只是把过度自信从"动作"上移到了"前提"。本轮两个灵感各补一刀：**任务规划**把证据从"逐点探询"升级为"跨计划的证据预算分配 + 可恢复性退款"，让长程计划的界不随步数线性恶化；**灵巧手**把接触从"动作"升级为"动作兼测量"——多数任务接触天然带观测，只要落在安全-可恢复包络内就是**自由证据**，只有包络外才需付费探针。核心命题由"证据说可信"升级为 **"计划说可信、接触可退避、证据可摊销到全局"**。

核心矛盾：
- **H29（符号前提 vs 接触现实）**：符号算子把"可抓/稳定"当布尔量，灵巧手的真实可行性是接触模式条件下的分布；证书若建立在错误的模式抽象上，规划器会精确利用该抽象的盲区（Goodhart）——抽象没写出的失败模式，就是它最爱的捷径。
- **H30（长程 vs 联合界）**：对检查点取 union bound 在长程操作下必然空洞；既不假设独立、又不能线性累加——唯一出路是把失败分解为互斥事件，并让可恢复失败"退款"。
- **H31（灵巧 vs 可验证）**：自由度越大，成功路径越多、失败模式也越多；接触模式空间组合爆炸，而在手内探询本身昂贵甚至破坏性，需要"保守抽象 + 触觉模式辨识 + 歧义加宽"三件套。

## 0. 直觉与动机

**灵感 1（任务规划 → 把计划看成证据预算的分配）**
直觉：我们一直把规划与验证分成两段——先规划一条路，再逐步找证据。但对长程任务，证据不是"点"而是"预算"：总风险预算 δ_plan 固定，关键步骤（下游依赖多、不可逆）多分，可恢复步骤少分；规划器在搜索时就该把 δ_i 当资源分配出去，而不是事后祈祷每步都过。于是"计划"与"证据"不是两阶段，而是同一个优化——**在 (任务状态 × 证据预算) 上搜索**；规划器天然知道"哪一步值得多问一句"。

**灵感 2（灵巧手 → 双用接触与自由证据）**
直觉：脚落地主要是"测量"，手操作天然是"动作 + 测量"——抓握的力/滑移/位姿观测本来就会发生。于是存在**自由证据**：只要该接触落在安全-可恢复包络内、且其观测不循环依赖待证结论，就可免费加固下游算子的证书；只有包络外的信息才需显式付费探针。灵巧不是"多做动作"，而是"让每个动作顺便作答"——这正好把探针开销从"额外成本"变成"操作副产物"。

**灵感 3（合流 → 可恢复性退款与首次失败分解）**
直觉：长程界之所以爆，是因为把"掉落"和"摔死"同价。把计划失败重新定义为**进入无可恢复的坏吸收态**；可恢复失败退款，不进入失败界。于是"首次不可恢复失败"这些事件天然互斥——一个 episode 至多发生一次——求和即精确概率，而不是松散的 union bound。灵巧手的再抓/再握正是"退款算子"，恢复半径 Rec(o) 因此成为证书的一等公民：计划级风险 ≈ Σ_i (1−Rec_i)·p̄_i，只要多数接触可恢复，界就不随步数恶化。

**灵感 4（接触模式辨识 → 歧义即加宽，辨识即探针）**
直觉：同一个"抓取成功"背后可能是 power grasp、precision pinch 或指尖三点接触，它们的失败谱完全不同。触觉/力签名给接触模式后验；模式歧义 amb(o) 直接加宽成功上界，歧义过大则禁止不可逆提交，先做一次在手内辨识动作（转腕/轻压/微滑）——它既是探针又推进任务，是灵感 2 的一个特例。

**灵感 5（闭环 → 证据持久、重规划防抖）**
直觉：重规划不应清零已获证据，否则每次扰动都要重探——证据要有持久性；同时重规划要设最小间隔，避免"证据抖动"引起计划抖动。计划证书 J_plan 是跨重规划复用的账本，也是"重规划经济学"的度量。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（接触模式算子 CMO）** 灵巧手算子 o=⟨pre_o, Eff_o, 𝒞(o), O_c, p̄(o,c), Rec_o⟩：𝒞(o) 为有限接触模式集（power/precision/pinch/fingertip/in-hand）；对 c∈𝒞(o)，p̄(o,c) 为保守成功上界（由接触力学包络与标定给出），O_c 为观测模型；pre_o 由任务状态与"接触可达性"共同判定；Eff_o 只有在模式被辨识（定义 143）且计划证书（定义 141）通过后才可提交。算子携带双用观测通道（定义 140）。

**定义 140（双用接触与自由证据 DUC）** 执行动作 a 产生任务转移 T_a 与观测 z_a。称 z_a 为**自由证据** free(a)，当且仅当：(i) a 的接触落在安全-可恢复包络 ℰ_rec 内；(ii) z_a 的获取不循环依赖它所要证的结论（观测必须在提交前可用）；(iii) 若 a 失败，存在已知恢复算子 r∈G_rec 使其回到已认证状态。否则 z_a 只能由显式付费探针获得。自由证据可更新**下游**算子（i'>i）的证书，但永不更新自身算子的提交证据（防自证）。

**定义 141（风险预算化计划证书 RBP）** 计划 π 为算子序列/树，风险预算 {δ_i} 满足 Σ_i δ_i ≤ δ_plan；按关键度 κ_i=(下游分支数)×(不可逆度)×(1+amb_i) 分配 δ_i（拉格朗日/贪心，见算法）。**首次不可恢复失败分解**：若坏吸收集 B 一经进入即终止，则

P(π 命中 B) = Σ_i P(o_i 是首个不可恢复失败) ≤ Σ_i (1−Rec_i)·(p̄(o_i,c_i)+amb_i) + δ_plan，

可恢复失败不计入。J_plan 记录 {δ_i}、{Rec_i 证据}、G_rec 与模式后验。

**定义 142（任务-信念联合规划 TBP）** 在 (s, b_𝒞) 上做条件规划，b_𝒞 为未提交算子的接触模式后验；动作空间 = 任务动作 ∪ 证据动作（含 in-hand 辨识）；目标

π\* = argmax_π E[任务收益] − λ_risk·P_fail(π) − λ_ev·cost(evidence(π))，

产出 AND/OR 条件计划树，每个叶节点挂 J_plan；证据动作只在 (s,b_𝒞) 的信念前沿上分支。

**定义 143（接触模式辨识 CMI）** 签名 y（触觉阵列/关节力矩/腕部位姿微分）→ 后验 b_𝒞(c|y)，校准契约 ECE_mode≤ε_mode；模式歧义 amb(o)=1−max_c b_𝒞(c|y)（或归一化熵）。若 amb(o)>θ_amb：成功上界改用扩张上界 p̄+amb，且禁止不可逆提交；必须先执行辨识动作 a_id∈𝒜_id（转腕/轻压/微滑），其代价计入证据预算；仍不可辨识则退保守模式（如 power grasp）或拒绝。

**定义 144（可恢复性退款重规划 RRR 与 J_plan）** 恢复图 G_rec 给出失败态→已认证态的算子；恢复半径 Rec(o)=P(在预算 b_rec 内回到已认证态 | o 失败)。坏吸收集 B 为 G_rec 不可达的失败态。J_plan=({J_p(o_i)},{δ_i},G_rec,{Rec_i},{b_𝒞(o_i)},free_log,replan_log)。重规划触发条件：某算子证据被证伪或 amb 超阈；重规划**复用**未受影响的证据（证据持久性），并满足最小间隔 Δ_replan（防抖）。

## 2. 关键算法伪代码（完整版见产物区）

```python
def evidence_aware_plan(s0, G_task, belief, delta_plan):   # IP-139/141/142
    pi = AND_OR_search((s0, belief), G_task,
                       cost=lambda o: evidence_cost(o, belief) + irreversibility(o))
    delta = alloc_risk_budget(pi, delta_plan, kappa=criticality(pi, G_rec))
    for o in leaves(pi):                                   # 未认证叶：插探针/恢复
        if o.evidence not in ('free', 'certified'):
            pi = insert_probe_or_recovery(pi, o)
    return pi, J_plan(pi, delta)

def alloc_risk_budget(pi, delta_plan, kappa):              # 关键度加权预算
    w = softmax([kappa[o] for o in pi])                   # 不可逆/高歧义 → 多分
    return {o: delta_plan * w[o] for o in pi}

def execute_contact(o, x, M):                              # IP-140/143
    y = tactile_signature(x, o)                            # 力/滑移/位姿
    bC = mode_identify(y, o)
    if ambiguity(bC) > theta_amb and o.irreversible:
        return ('need_identify', plan_identify_motion(o))  # 辨识动作=探针
    if o.evidence == 'free' and within_recovery_envelope(x, o):
        update_downstream_certs(o, y)                      # 自由证据：只帮下游
    ok = within_success_envelope(x, o, bC)
    if not ok and o in G_rec:
        x = recover(o, x, G_rec)                           # 可恢复失败：退款
        return ('refunded', x)
    return ('ok' if ok else 'first_unrecovered_failure', x)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| CMO | O(\|𝒞(o)\|·d_c)/算子 | O(\|𝒞\|) | 模式抽象保守（A41） |
| DUC | O(d_y)/接触 | O(1) 在线 | 观测偏序、只更新下游（A44） |
| RBP | O(\|π\| log\|π\|) 分配 | O(\|π\|) | 预算和≤δ_plan、关键度单调 |
| TBP | O(\|CP\|·(\|𝒞\|·b)) | O(\|V\|·\|𝒞\|) | 条件分支有限、终止 |
| CMI | O(d_y·\|𝒞\|) | O(\|𝒞\|) | ECE_mode≤ε_mode、歧义加宽 |
| RRR | O(1)+O(H_rec) | O(\|G_rec\|) | 恢复半径下界可信（A43） |

**正确性定理（PACES 概要）**：在 A33–A40 上加 (A41) 接触模式抽象保守（真实成功率≤p̄+amb）；(A42) 模式辨识校准且不可辨识时强制保守/拒绝；(A43) 恢复半径经验下界可信、G_rec 对 B 之外均可达；(A44) 风险预算 Σδ_i≤δ_plan 且关键度分配单调。则：

(i) **首次失败分解**：P(π 命中 B) ≤ Σ_i (1−Rec_i)(p̄_i+amb_i)+δ_plan，不依赖独立性；可恢复步数增加不使界恶化；全可恢复且 amb≤θ_amb 时 P≤δ_plan，与步数无关。
(ii) **自由证据单向性**：自由证据只更新下游证书或保持原证书，不存在"用本步成功观测提高本步提交概率"的路径 ⇒ 计划层交互单调性延续。
(iii) **终止性**：每个算子辨识/探针数受 k_plan 约束，TBP 在有限分支内终止于 {提交, 重规划, 退保守模式, 拒绝}。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 接触模式抽象过乐观（Goodhart） | 高 | 保守模式合并 + sim-to-real 残差包络 + 抽象层自身送隔离/OOD 证书 |
| 自由证据自证/循环依赖 | 高 | 观测时序偏序 + 只更新下游 + 全程审计 |
| 恢复半径被高估 | 高 | 恢复算子独立标定 + 恢复也走证据门 + 退款上限 |
| 触觉模式辨识分布漂移 | 中 | 在线校准 + 不可辨识即退保守模式 |
| 长程搜索爆炸 | 中 | AND/OR 惰性展开 + 关键度剪枝 + 证据预算上限 |

## 6. 本轮最大风险

**一句话**：本轮把"计划可不可信"押在"有限接触模式抽象是否保守"上——灵巧接触是连续、欠驱动、微滑主导的，一旦模式格遗漏了某类"符号上成功、物理上缓慢失效"的接触（如捏持中的微滑累积），规划器会精确地反复选用这个盲区，风险预算与可恢复性退款反而把这份系统性乐观"洗白"成漂亮的全局保证；必须以保守模式合并、恢复半径经验下界、以及把抽象层本身送进隔离区（抽象级 OOD/可达性证书）三道护栏，宁可把灵巧手降级成笨拙但可证的 power grasp，也不让证书建立在一个没被验证的接触抽象上。

def realize(o, x, M):
    # 符号效果只在模式辨识且证书通过后暴露

### IP-141 RBP（风险预算化计划证书）

```python
def alloc_risk_budget(pi, delta_plan, G_rec):
    kappa = {}
    for o in nodes(pi):
        kappa[o] = (downstream_branch_count(o, pi)
                    * irreversibility(o)
                    * (1.0 + ambiguity(o)))       # 关键度
    w = softmax(list(kappa.values()))
    delta = {o: delta_plan * w[o] for o in nodes(pi)}
    assert sum(delta.values()) <= delta_plan + 1e-12
    return delta

def plan_certificate(pi, delta, M):
    leak = 0.0
    for o in nodes(pi):
        if o.evidence == 'free':
            continue
        c = committed_mode(o)
        leak += (1.0 - Rec(o, M.G_rec)) * (pbar(o, c) + ambiguity(o))
    # 首次不可恢复失败分解：互斥事件求和，非 union bound
    return ('ok' if leak + delta_plan <= M.delta_tol else 'reject',
            P_fail_upper=leak + delta_plan,
            budgets=delta, recovery=M.G_rec,
            mode_post=M.bC, free_log=M.free_log)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CMO | O(\|𝒞(o)\|·d_c)/算子 | O(\|𝒞\|) | 模式抽象保守（A41） |
| DUC | O(d_y)/接触 | O(1) 在线 | 观测偏序、只更新下游（A44） |
| RBP | O(\|π\| log\|π\|) | O(\|π\|) | 预算和≤δ_plan、关键度单调 |
| TBP | O(\|CP\|·\|𝒞\|·b·(D+V)) | O(\|V\|·\|𝒞\|) | 条件分支有限、四态完备 |
| CMI | O(d_y·\|𝒞\|) | O(\|𝒞\|) | ECE_mode≤ε_mode、歧义加宽 |
| RRR | O(1)+O(H_rec) | O(\|G_rec\|) | 恢复半径下界可信（A43） |

**正确性定理（Plan-level Affordance-Certified Evidence Soundness, PACES）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 接触模式抽象保守：∀o,c，真实成功率 ≤ p̄(o,c)+amb(o)；**(A42)** 模式辨识校准：ECE_mode≤ε_mode，不可辨识时强制退保守模式或拒绝；**(A43)** 恢复诚实：Rec(o) 经验下界可信，且 G_rec 对坏吸收集 B 之外所有失败态可达；**(A44)** 证据时序与预算：自由证据必须在提交前可观测、只更新下游；Σ_i δ_i≤δ_plan 且关键度分配对不可逆/高歧义步骤单调不减。则：

1. **首次不可恢复失败分解（核心）**：因 B 为吸收态，事件 {"o_i 是首个不可恢复失败"} 两两互斥，故
   `P(π 命中 B) = Σ_i P(o_i 首个不可恢复失败) ≤ Σ_i (1−Rec_i)(p̄_i+amb_i) + δ_plan`。
   与独立性无关；可恢复步数增加不使界恶化；若所有 Rec_i=1 且 amb_i≤θ_amb，则 P≤δ_plan **与计划长度无关**——直接修复第 57 轮长程 union bound 空洞化问题。
2. **自由证据单向性**：free(a) 只更新下游证书或保持原值，且观测在提交前可得，故不存在"用本步成功率反推本步提交"的循环；计划层交互单调性延续（证据只让信念更准或动作更保守）。
3. **灵巧退避单调性**：amb 上升 ⇒ 上界扩张、禁止不可逆提交、优先辨识；辨识失败 ⇒ 退保守模式或拒绝；该链只向保守方向滑动。
4. **终止性**：每计划辨识/探针 ≤k_plan，重规划间隔 ≥Δ_replan，TBP 在有限 AND/OR 分支内终止于 {提交, 重规划, 退保守模式, 拒绝}。
5. **部署界**：

```
P_safe ≥ 1 − Σ_i (1−Rec_i)(p̄_i+amb_i) − δ_plan
             − P(模式抽象失配未检出) − P(恢复图不完备未检出)
             − P(自由证据循环未审计) − P(重规划超时 ∧ 安全停失效)
```

关键：**证据从"逐点"变"预算"**（长程可组合、不靠独立性）；**接触从"动作"变"动作兼测量"**（探针开销被任务动作摊销）；**失败从"二值"变"可退款"**（可恢复性成为证书一等公民）；**歧义从"隐藏"变"加宽"**（灵巧度必须用可验证性付账）。

## 6. 本轮最大风险

**一句话**：本轮把"计划可不可信"押在"有限接触模式抽象是否保守"上——灵巧接触是连续、欠驱动、微滑主导的，一旦模式格遗漏了某类"符号上成功、物理上缓慢失效"的接触（如捏持中的微滑累积），规划器会精确地反复选用这个盲区，而风险预算与可恢复性退款反而把这份系统性乐观"洗白"成漂亮的全局保证；必须以保守模式合并、恢复半径经验下界、以及把抽象层本身送进隔离区（抽象级 OOD/可达性证书）三道护栏，宁可把灵巧手降级成笨拙但可证的 power grasp，也不让证书建立在一个没被验证的接触抽象上。
