# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因」IP-214~223；灵感循环第 3 轮；本轮灵感：「关节驱动」×「迭代验证」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险是：VISTA 依赖"故障属于有限假设集、且视觉与几何失效相互独立"；未知复合故障会被强行归入最近假设、只膨胀错误的球，系统因"已经归因"而更自信。**但在这一层风险之下，还有一个更上游、所有安全论证都默认成立却从未被检验的隐藏假设（A94）：证书所认证的"动作"，真的就是机器人兑现给世界的那个动作。** 第 65 轮的整条闭环——认证前缀、力限、滑移判据、不可逆视界——全部建立在 `dispatched = delivered` 之上；而关节驱动链路（电流环、电机常数、谐波减速器摩擦/背隙、传动柔顺、热漂移、力矩饱和）会在指令与环境之间插入一个**未被建模、慢变、状态相关**的映射。VISTA 把这个映射的全部误差都塞进 `H_force`，于是"传感器偏置"与"执行器没兑现"被混为一谈。本轮不问"谁坏了"，而问：
>
> **我们认证的那个动作，真的是机器人兑现出去的动作吗？如果不是，能否把驱动层的误差从传感/环境误差中分离出来，并用跨周期的迭代验证证明"它已经被兑现"，而不是用同一批数据反复说服自己？**
>
> 核心命题：**把执行动作从"已认证的指令"升级为"经关节驱动层迭代验证的兑现动作"：用驱动残差模型给出指令→兑现的显式映射，用跨周期、跨构型的安全激励创造驱动故障的可辨识性，用 anytime-valid 的迭代验证协议保证"反复验证"不会退化为"自我确认"，并让安全证书带上随热漂移/磨损而失效的租约。**

## 0. 直觉与动机

**灵感 1（关节驱动 → 兑现动作，而非指令动作）**
直觉：机械臂的"力"不是策略直接给的。策略给的是关节指令，经电流环变成电机力矩，再经减速器摩擦、背隙、柔顺、热降额，才变成关节侧力矩，最后经雅可比映射成环境力。这条链路每一环都会让"指令"与"兑现"分叉。VISTA 的所有安全谓词都在说"我准备施加 f"，但世界感受到的是 f′。**在接触之前，这条链路还只影响运动精度；一旦接触，它直接决定力限、滑移与不可逆伤害。** 因此"兑现动作"必须成为一个独立的、可验证的对象，而不是证书里的隐含项。

**灵感 2（关节驱动 → 驱动残差有独特的、跨构型的签名）**
直觉：驱动侧故障不是任意噪声，它有很强的物理结构：摩擦是速度符号相关、低速有 Stribeck 与爬行；背隙/迟滞在换向时出现不随增益缩小的死区；传动柔顺让"关节刚度"与"环境刚度"串联，看起来像接触变软；电流-力矩增益与摩擦随温度缓慢漂移；力矩饱和是硬平台。它们共同的特征是：**在自由空间（无接触）就存在，且随构型、速度、温度、载荷方向变化**。这与几何幻觉（只在接触、且与视觉足迹冲突）、力传感器偏置（与运动方向无关）在观测结构上不同——只要我们去激励它。

**灵感 3（迭代验证 → 跨周期的时间轴创造可辨识性）**
直觉：第 65 轮已经用块内三阶段（接近/轻触/加载）创造了一个时间轴。但驱动故障是慢变参数，**单个块、单个构型内不可辨识**：一次静态读数无法区分"传感器偏置"与"增益误差"，一次正向运动无法区分"库仑摩擦"与"恒值偏置"。可辨识性来自**第二个时间轴——迭代轴**：在不同构型、不同速度、换向、不同载荷与不同温度下重复激励。迭代不是"多检查几遍"，而是**驱动层可辨识性的来源**；没有跨周期激励，驱动故障在观测上就是不可分的。

**灵感 4（迭代验证 → 必须是非自证的合约，而不是习惯）**
直觉：一旦把"反复验证"写进闭环，最危险的失败模式不是漏检，而是**自证**：用同一批构型拟合、再用同一批构型验证；根据上一轮验证结果挑选下一轮验证样本；验证次数越多、越容易"证明"一个错误模型。这与数据驱动的 Goodhart 效应同构。因此迭代验证必须是一门**合约**：识别集与验证集按构型/时间严格分离；用 e-process（检验鞅）做 anytime-valid 判决，允许"看到不好就停"而不膨胀假阳性；必须包含一次**证伪激励**（模型没见过的方向）；验证集不许被自适应复用。

**灵感 5（迭代验证 → 证书是租约，不是永久产权）**
直觉：驱动参数会随热、磨损、负载历史漂移，所以"验证通过"只在有限时间/工况内成立。正确抽象是把证书看成**带租约的凭证**：每次执行消耗验证信用，热漂移或磨损超过漂移界、或租约到期，就必须重新验证，未续租不得继续扩张动作包络。这比"离线标定一次、永久信任"更诚实，也比"每步都重标定"更可行。租约长度由漂移界与安全裕度共同决定，形成一个可优化的**验证节奏**。

**灵感 6（合流 → JIVE：Joint-drive Iterative Validation & Excitation，关节驱动层迭代验证与激励闭环）**
闭环：兑现接地门（AGG）算驱动残差 → 驱动残差模型（DRM）给出指令→兑现映射 → 驱动/感知/环境三侧分解（JDR）→ 归因扩展（H_sense/H_act/H_trans/H_thermal/H_sat）→ 归因模糊或漂移超界时用**迭代激励查询 IEQ** 选安全激励（换向、低速扫掠、多构型静载、载荷阶跃）→ **迭代验证环 IVL** 在独立构型上做 anytime-valid 证伪 → 通过则续租、失败则冻结扩张并回退 → 驱动感知膨胀 RSC-A / WCV-A / CSP-A / AIC-A。JIVE 把 VISTA 的"接触前/中/后"再往前推一层：**在接触之前，先验证"手"本身是否兑现**。

**灵感 7（VISTA 组件的原位升级）**
- **FIR → JDR**：故障轴从"几何/力/模型/视觉/策略"细化为"感知侧/驱动侧/传动侧/热/饱和/环境"，驱动侧误差不再被塞进 `H_force`。
- **AFA → IEQ**：探针目标从"故障假设互信息"升级为"驱动参数可辨识性 + 证书决策价值"，激励必须跨构型、含换向。
- **CSC → CSC-L**：认证前缀额外约束**兑现力**（而非指令力），并按证书剩余租约截断 `k*`。
- **RSC-V → RSC-A**：增 `r_act / r_trans / r_thermal / r_sat / r_wear`，且膨胀随"距上次验证的时间"增长。
- **WCV-V → WCV-A**：搜索域增"兑现力约束"与"驱动参数支持域"；在参数后验上对 `f_deliv` 取最坏。
- **CSP-V → CSP-A**：技能图增 `verify_drive / excite_drive / renew_lease / retreat` 元技能；块边需租约有效。
- **AIC-V → AIC-A**：干扰集增驱动退化、换向背隙、热斜坡、饱和、**传感-驱动共因**（共用电流/编码器）。
- **J_vista → J_jive**：证书增 `θ̂_act, Σ_act, κ_act, excitation_cov, val_evalue, lease_remaining, drm_ver, data_role_hash`。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（JIVE 闭环）**：JIVE = (VISTA, AGG, DRM, JDR, IEQ, IVL, ALV, RSC-A, WCV-A, CSP-A, AIC-A, J_jive)。定位：VISTA 的"兑现动作接地 + 驱动层迭代验证"升级。不变式：**驱动残差模型辨识、激励设计、迭代验证与证书只在语义流；实时流只做残差采集、租约倒计时、兑现力早停与派发，零学习写操作；识别集、验证集、认证集三者按构型与时间不相交。**
- **定义 234（兑现动作与接地残差 AGG）**：派发 `a=(q,q̇,τ_cmd)`，兑现记为 `a*=(q,q̇,τ_j)`。关节侧残差 `ε_j=τ_j−τ_cmd`；任务空间兑现力 `f_deliv=J^{-T}(q)(τ_j−M(q)q̈−C(q,q̇)q̇−g(q))`，接地残差 `e_act=‖f_deliv−f_cmd‖_{Σ_a⁻¹}`。仅当该段无接触或接触模型可信时 `e_act` 才可用于驱动辨识；否则置 `grounding_mask`。
- **定义 235（关节驱动残差模型 DRM）**：对第 j 关节
  `τ_j = clip( g_j(T)·(k_t,j(T)·i_j + b_i,j(T)) − τ_fric,j(q̇_j) − τ_trans,j(q_m,j−q_j;β_j,k_c,j), ±τ_max,j(T) ) + w_j`，
  其中 `τ_fric,j = sign(q̇_j)[f_c,j+(f_s,j−f_c,j)e^{−|q̇_j|/v_s,j}]+f_v,j q̇_j`，`τ_trans,j = k_c,j·B_{β_j}(q_m,j−q_j)` 为含背隙/迟滞的传动项，`k_t,j(T)=k_t0,j(1−α_T,j(T−T_0))`。参数 `θ_act={g,b,f_c,f_s,f_v,v_s,β,k_c,τ_max,α_T,λ_drift}`；`λ_drift` 为参数漂移率上界。
- **定义 236（驱动/感知/环境三侧分解 JDR）**：定义三条残差通道：`ε_drive=τ_j−D_θ(τ_cmd,·)`（指令到关节侧）、`ε_sense=f_FT−J^{-T}τ_j`（力传感器与关节力矩估计之差）、`ε_env=f_deliv−f_model(φ)`（接触后环境侧）。线性化 `E[e|θ]=S_J θ`，`θ=(θ_act,θ_sense,θ_env)`。`S_J` 的分块结构决定了驱动侧故障能否被分离：恒值传感器偏置列在自由空间与运动方向无关，摩擦列与 `sign(q̇)` 相关，背隙列在换向处出现而增益列不出现。
- **定义 237（迭代激励设计 IEQ）**：以"周期"为设计单位，激励集 `D={traj_i}`（多构型静载、低速正反扫掠、换向、载荷阶跃、热升载）。驱动 Fisher 信息 `J_act(D)=Σ_i Φ(a_i)ᵀΣ_ε⁻¹Φ(a_i)`；选择 `D*=argmax_D λ_min(J_act(D))`，s.t. 预测力/形变/磨损增量 ≤ 风险与寿命预算 `B_exc`。激励覆盖 `c=({c_pose},{c_rev},{c_v},{c_τ},{c_T})`：构型数、换向覆盖、速度跨度、载荷跨度、温度跨度。`c_rev=0` 时摩擦与偏置不可分。
- **定义 238（跨迭代签名张量）**：VISTA 的阶段轴 `P={approach,touch,load}` 之外增**迭代轴** `K={cold,warm,aged}`。签名 `ρ_J[p,k]=[ē_drive,ē_sense,ē_env,d̄_chunk,ū_chunk,T,τ_cmd/τ_max]_p,k ∈ ℝ^{7×3×3}`。其线性化矩阵 `S_J` 近似块三角：`H_sense` 仅入 `ē_sense` 且与 `k` 无关；`H_act` 入 `ē_drive` 且随 `k` 缓变；`H_trans` 在换向与 `load` 显形；`H_thermal` 与 `T,k` 强相关；`H_env` 仅入接触后的 `ē_env`。
- **定义 239（驱动感知故障假设扩展）**：`ℋ_J={H0, H_sense, H_act, H_trans, H_thermal, H_sat, H_env, H_vis, H_policy, H_unknown}`。`H_act`=增益/摩擦/死区，`H_trans`=背隙/迟滞/柔顺，`H_thermal`=热漂移，`H_sat`=力矩饱和/限幅；`H_env` 合并 VISTA 的几何与接触模型错，`H_unknown` 承接开放世界拒绝归因。
- **定义 240（驱动感知归因 JDR-attribute）**：离线在驱动标定台上做故障注入，拟合 `p(ρ_J|H)`；后验 `P(H|ρ_J)∝p(ρ_J|H)P(H)`。判别规则强调**证据的可及性**：无自由空间段则禁止区分 `H_act` 与 `H_sense`；无换向则禁止区分 `H_trans` 与 `H_act`；无温度变化则禁止区分 `H_thermal`；后验不集中或违反上述可及性时置 `attribution_inadmissible`，进入 IEQ，而**不是**强行归因。
- **定义 241（迭代验证环 IVL）**：每轮 `t` 在识别集 `D_id,t` 上估计 `θ̂_act,t`，在**独立构型/时间段** `D_val,t`（与 `D_id,t`、认证集 `D_audit` 均不相交）上计算验证残差 `r_t`。对零假设"驱动模型已足够好"构造检验鞅 `E_t=∏_{s≤t} (p_1(r_s)/p_0(r_s))`；由 Ville 不等式，`P[∃t:E_t≥1/α]≤α`，故允许**看结果再决定是否继续验证**而不膨胀假阳性。判决：`E_t≥1/α` 判"驱动模型不足"→ 冻结扩张、重辨识；否则续租。另设**证伪激励**：每轮至少一条不在拟合集中的方向（新构型或反向），未通过则整轮验证无效。
- **定义 242（验证信用与证书租约 ALV）**：证书携带租约 `L=(θ̂_act,Σ_act, t_val, Δ_max)`，`Δ_max` 由漂移界 `‖θ(t)−θ(t_val)‖≤λ_drift·Δ+σ_w√Δ` 与安全裕度反解。每次执行消耗信用；当 `t−t_val>Δ_max`、温度越界、或累计磨损超阈值时租约失效，`Valid(J_jive)←false`，只允许执行已认证前缀到安全停点，并触发 `renew_lease`。包络**单调收缩**：未验证前只减不增；重新扩张必须由新的独立验证证据支持。
- **定义 243（驱动感知膨胀 RSC-A）**：维护 `r_geo,r_force,r_model` 与新增 `r_act,r_trans,r_thermal,r_sat,r_wear`。按归因定向膨胀（如 `H_act→r_act↑`、`H_thermal→r_thermal↑` 并触发热重标定），且带租约老化项 `r_act(t)=r_act^0+λ_drift·(t−t_val)`。融合 `r=√(r_geo²+r_force²+r_model²+r_act²+r_trans²+r_thermal²+r_sat²)` 进入 WCV-A；未归因的驱动残差一律计入 `r_act`，**绝不静默丢弃**。
- **定义 244（驱动感知 WCV-A）**：搜索域 `B(φ̂,r)∩𝒢∩K∩ℱ_deliv∩𝒱∩𝒜`，其中 `ℱ_deliv={θ_act:∀j, |f_deliv,j(θ_act)|≤f_lim}` 是**兑现力**（不是指令力）约束，`𝒜` 是驱动参数支持域（`θ_act` 后验的置信集）。CVaR 尾部对 `θ_act` 与 `θ_env` 联合最坏；若参数支持域使交集为空，回退并置 `actuation_conflict=True`。
- **定义 245（驱动感知规划 CSP-A）**：块级技能图增元技能 `verify_drive`（自由空间静载/扫掠）、`excite_drive`（受预算激励）、`renew_lease`（验证后续租）、`retreat`（租约失效保守回退）。每条块边需 `Valid(J_jive)`、租约未过期、且兑现力在 `ℱ_deliv` 内；技能绑定其典型驱动参数分布，偏离即 OOD。
- **定义 246（对抗驱动认证 AIC-A）**：干扰集 `ℰ_J=ℰ_V×ℰ_act×ℰ_lease`，`ℰ_act` 含摩擦翻倍、增益失配、背隙增大、柔顺下降、热斜坡、力矩饱和；`ℰ_lease` 含验证集复用、自适应重验证、静默老化；并显式建模**传感-驱动共因**（共用电流/编码器）与**驱动-环境共模**（摩擦增大被误读为接触变软）。`n_cert` 提高，`J_dir` 增 `drm_ver, lease_ver, data_role_hash`。
- **定义 247（JIVE 证书 J_jive）**：`J_jive=(J_vista, θ̂_act, Σ_act, κ_act, excitation_cov, val_evalue, lease_remaining, attribution_axis, drm_ver, data_role_hash, aic_a_ver)`。`Valid(J_jive) ⇔ Valid(J_vista) ∧ κ_act≥κ_min ∧ excitation_cov≥c_min ∧ (E_t<1/α) ∧ lease_remaining>0 ∧ 兑现力在 ℱ_deliv 内 ∧ 识别/验证/认证集互斥 ∧ aic_a_ver 为当前版本`。
- **定义 248（JIVE 闭环算子）**：语义流 [VISTA 闭环 → AGG 兑现接地 → DRM 辨识 → JDR 三侧分解/归因 → 可及性检查 → (不充分? IEQ 选激励 → IVL 验证 → ALV 续租/冻结) → RSC-A → WCV-A → CSP-A → CSC-L 认证前缀 → AIC-A]；实时流 [读编码器/电流/温度/力 → 驱动残差采集 → 兑现力早停 → 租约倒计时 → 派发前缀 → J_jive 构建]。

```python
    allowed_prefix = csc_l.prefix_to_safe_stop(tau, post, lease)
    assert not csc_l.expand_allowed(lease)

# CSC-L：用兑现力而非指令力认证前缀
k_star = csc_l.certified_prefix(A, post, theta_hat, Sigma_act, m, alpha_chunk, lease)
for a in A[:k_star]:
    dispatch(a)
    if delivered_force_guard(a, theta_hat, Sigma_act).abort: break   # 实时早停
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（驱动层可辨识性）**：若激励集包含至少两个构型下的自由空间静载（分离增益与恒值偏置）与正反速度扫掠（分离摩擦与偏置），并覆盖温度变化（分离热漂移），则 `S_J` 的驱动/感知列满秩，`κ_act=λ_min(J_act)/λ_max(J_act)` 可下界；若 `c_rev=0` 或仅单一构型，摩擦与传感器偏置列共线，驱动侧不可辨识，任何"驱动故障"归因都不可信。
- **引理 10（迭代验证的 anytime-valid 非自证）**：若 `D_val,t` 与 `D_id,t` 独立且验证样本在原假设下可交换，则检验鞅 `E_t` 的 Ville 界保证任意可选停止下假接受率 ≤α；一旦复用同一验证集或按上轮结果挑样本而不做 e-value 修正，鞅性质破坏，假接受率随验证次数增长。故"迭代验证"必须写成 e-process + 构型不相交，否则迭代本身制造虚假安全。
- **定理 9（JIVE 端到端兑现-安全）**：在 A95–A99 下，`Valid(J_jive)` ⇒ 兑现动作以 ≥1−α_act 落在认证包络内 ∧ 驱动/感知/环境故障被归因或显式判不可归因 ∧ 租约未过期 ∧ 不存在"执行器静默放松安全"的盲区 ∧ VISTA 全部保证仍成立。证书链由"几何-技能-干扰-接触-归因"扩到"几何-技能-干扰-接触-归因-兑现"。
- **定理 10（迭代验证的收敛与最优节奏）**：在持续激励与有界漂移下，参数误差按 `E‖θ̂_t−θ‖²≤(1−η)^t e_0+σ_drift²` 收缩至漂移地板；验证成本 `c_v/Δ` 与漂移风险 `c_d L²Δ²` 的最优验证间隔 `Δ*=(c_v/(2c_d L²))^{1/3}`。故"越频繁验证越好"是错的，存在按漂移率与激励代价决定的最优节奏。
- **命题（兑现接地降低 VISTA 误归因）**：VISTA 中归入 `H_force` 的误差质量可拆成传感器与驱动两部分；JIVE 在自由空间就可测得驱动分量，故对"几何正确却被误降级"的保守化质量可显著降低，且不需要新增外部模态。
- **实时性**：AGG/兑现力守卫/租约倒计时在实时流（<0.1ms），DRM 辨识、JDR 归因、IEQ/IVL 全在语义流；沿用第 65 轮 2.5ms 预算，新增实时开销目标 ≤0.15ms。

## 2. 形式化定义（完整版）

**定义 233（JIVE 闭环）** JIVE 是 VISTA 的"兑现动作接地 + 驱动层迭代验证"升级：在 VISTA 的语义流/实时流骨架上，于策略与 WCV 之间挂载 AGG（兑现接地）、DRM（驱动残差模型）、JDR（三侧分解与再归因）、IEQ（迭代激励）、IVL（迭代验证）、ALV（租约），并原位升级 RSC-V→RSC-A、WCV-V→WCV-A、CSP-V→CSP-A、AIC-V→AIC-A、J_vista→J_jive。不变式：**驱动辨识、激励设计、迭代验证、证书构建只在语义流；实时流只做编码器/电流/温度/力残差采集、兑现力守卫、租约倒计时与派发，零学习写操作；识别集、验证集、认证集严格互斥。**

**定义 234（兑现动作与接地残差 AGG）** 设策略派发 `a=(q,q̇,τ_cmd)`。关节侧兑现力矩 `τ_j` 由关节力矩传感器或"电机电流×转矩常数−摩擦/传动模型"估计。任务空间兑现力
`f_deliv = J^{-T}(q)(τ_j − M(q)q̈ − C(q,q̇)q̇ − g(q))`，
接地残差 `e_act = ‖f_deliv − f_cmd‖_{Σ_a⁻¹}`，其中 `f_cmd = J^{-T}τ_cmd`。定义接地掩码 `grounding_mask=1` 当且仅当该段处于自由空间，或处于接触但接触模型与视觉都可信；有接触且模型存疑时 `e_act` 不得用于驱动参数辨识，只能作为"未知接地误差"计入 `r_act`。**AGG 的职责不是消除残差，而是保证后续归因不会把环境误差当成驱动故障。**

**定义 235（关节驱动残差模型 DRM）** 对第 j 关节，兑现力矩由下式给出：
`τ_j = clip( g_j(T)·(k_t,j(T)·i_j + b_i,j(T)) − τ_fric,j(q̇_j) − τ_trans,j(q_m,j−q_j;β_j,k_c,j), ±τ_max,j(T) ) + w_j`
其中
- 摩擦：`τ_fric,j = sign(q̇_j)[f_c,j+(f_s,j−f_c,j)exp(−|q̇_j|/v_s,j)] + f_v,j q̇_j`，含 Stribeck 低速度段与库仑/黏性项；`|q̇|<v_eps` 时用静摩擦/死区近似。
- 传动：`τ_trans,j = k_c,j·B_{β_j}(q_m,j−q_j)`，`B_β` 为带背隙的迟滞/死区算子；串联柔顺使关节侧刚度 `k_joint=(1/k_c+1/k_env)⁻¹`，会伪装成"接触变软"。
- 热：`k_t,j(T)=k_t0,j(1−α_T,j(T−T_0))`，`f_c,j(T)=f_c0,j exp(−β_T,j(T−T_0))`。
- 饱和：`clip(·,±τ_max,j(T))`，`τ_max,j(T)` 随温度降额。
参数 `θ_act` 带先验 `p(θ_act)` 与漂移模型 `θ_act(t+Δ)=θ_act(t)+λ_drift·Δ+σ_w√Δ·ξ`。DRM 是**可错的物理先验**，不是真值：它的作用是把"驱动误差"从一个黑箱标量变成有结构、可激励、可证伪的参数后验。

**定义 236（驱动/感知/环境三侧分解 JDR）** 定义三条正交化残差通道：
1. `ε_drive = τ_j − D_θ(τ_cmd,q,q̇,T)`：指令到关节侧的兑现误差（DRM 残差）。
2. `ε_sense = f_FT − J^{-T}τ_j`：力传感器读数与"由关节力矩反推的环境力"之差（感知侧）。
3. `ε_env = f_deliv − f_model(φ)`：兑现力与几何/接触模型预测之差（环境侧）。
线性化 `E[e|θ] = S_J θ`，`θ=(θ_act,θ_sense,θ_env)`，`e=(ε_drive,ε_sense,ε_env)`。`S_J` 的块结构给出**可及性条件**：
- 恒值传感器偏置 `b_sense` 只进 `ε_sense`，且与运动方向、温度无关；
- 增益误差 `g`、库仑摩擦 `f_c` 进 `ε_drive`，摩擦与 `sign(q̇)` 相关、在 `q̇=0` 消失；
- 背隙 `β` 在换向处产生不随增益缩小的死区；
- 热项 `α_T` 与 `T` 相关；
- 环境/几何误差只进 `ε_env`，且只在接触后出现、与视觉足迹冲突。
因此**驱动侧与感知侧的可分性不是估计器性质，而是动作是否激励出方向/构型/温度差异的设计性质。**

**定义 237（迭代激励设计 IEQ）** 以"验证周期"为单位设计激励集 `D={traj_i}`。每条 traj 覆盖：多构型自由空间静载（用已知重力矩分离增益与恒值偏置）、低速正反扫掠（分离摩擦与偏置）、换向段（激励背隙）、载荷阶跃（分离柔顺与环境刚度）、热升载（激励热漂移）。驱动 Fisher 信息
`J_act(D)=Σ_{a∈D} Φ(a)ᵀΣ_ε⁻¹Φ(a)`，
选择
`D* = argmax_D λ_min(J_act(D))`，
s.t. 预测接触力 ≤ f_safe(易损物体优先自由空间)、预测形变 ≤ ε_strain、累计磨损增量 ≤ B_wear、总激励时间 ≤ B_time。等价地可在诊断子空间上做 D-最优。**若 `c_rev=0`（无换向）或 `c_pose=1`（单构型），则 `J_act` 秩亏，IEQ 必须显式报告"当前预算下不可辨识"，而不是返回一个伪最优。**

**定义 238（跨迭代签名张量）** 在 VISTA 的阶段轴 `P={approach,touch,load}` 之外增迭代/寿命轴 `K={cold,warm,aged}`。签名
`ρ_J[p,k] = [ē_drive, ē_sense, ē_env, d̄_chunk, ū_chunk, T, τ_cmd/τ_max]ᵀ ∈ ℝ⁷`，
整张量 `ρ_J ∈ ℝ^{7×3×3}`。线性化 `E[ρ_J|θ]=S_J θ` 近似块三角：
- `H_sense` 列仅非零于 `ē_sense`，且与 `k` 无关；
- `H_act` 列非零于 `ē_drive`，随 `k` 缓慢变化；
- `H_trans` 列在换向与 `load` 显形；
- `H_thermal` 列与 `T,k` 强相关；
- `H_env` 列仅非零于接触后的 `ē_env`。
**迭代轴 K 是本轮相对 VISTA 的关键增量：VISTA 的时间轴是块内的，JIVE 的时间轴是跨块的；慢变驱动故障只能在后者中可辨识。**

**定义 239（驱动感知故障假设扩展）** `ℋ_J={H0 健康, H_sense 力/力矩传感偏置, H_act 驱动增益/摩擦/死区, H_trans 背隙/迟滞/柔顺, H_thermal 热漂移/降额, H_sat 力矩饱和/限幅, H_env 几何+接触模型错, H_vis 视觉错, H_policy 策略 OOD, H_unknown 未知}`。相对 VISTA：把 `H_force` 拆成 `H_sense`（感知）与 `H_act/H_trans/H_thermal/H_sat`（执行），把 `H_geo/H_model` 合并为 `H_env`，并保留 `H_unknown` 的拒绝归因状态。

**定义 240（驱动感知归因 JDR-attribute）** 离线在驱动标定台（含可编程摩擦/背隙/热箱）与仿真中做故障注入，拟合各假设下的签名似然 `p(ρ_J|H)`（高斯混合或归一化流）。后验
`P(H|ρ_J) ∝ p(ρ_J|H)P(H)`。
但归因必须通过**可及性检查** `Adm(H, E_avail)`：
- `H_act` vs `H_sense` 需要自由空间段 + 至少一次换向；
- `H_trans` 需要换向段或载荷反向；
- `H_thermal` 需要温度跨度 `c_T≥c_T,min`；
- `H_sat` 需要命令接近/超过 `τ_max` 的样本。
若 `max_H P(H|ρ_J)≥1−δ_fi` 且 `Adm` 通过，则定向处置；若后验集中但 `Adm` 不通过，置 `attribution_inadmissible`；若后验不集中，置 `ambiguous`。后两者均进入 IEQ。**"数据不足以区分"必须显式成为一等状态，不能被最近邻假设吞掉。**

**定义 241（迭代验证环 IVL）** 每一轮 t：
1. 在识别集 `D_id,t`（构型集合 `C_id`）上最小化 DRM 残差，得 `θ̂_act,t, Σ_act,t`。
2. 在验证集 `D_val,t`（构型集合 `C_val`，`C_val∩C_id=∅`，且与 `D_audit` 不相交）上计算归一化验证残差 `r_t`。
3. 构造检验鞅 `E_t=∏_{s≤t} (p_1(r_s)/p_0(r_s))`，其中 `p_0` 为"模型足够好"下的残差密度、`p_1` 为备择。由 Ville 不等式：`P_{H0}[∃t:E_t≥1/α]≤α`，故**允许根据中间结果决定是否继续验证/停止**而不膨胀假阳性。
4. 判决：`E_t≥1/α` → 拒绝"模型足够好"，冻结动作包络扩张、要求重辨识；否则续租。
5. **证伪激励**：每轮至少包含一条不在拟合集中的方向（新构型或反向），若该条预测失败则整轮验证作废。
6. 记录 `n_looks`、验证构型哈希与 `data_role_hash`；禁止把验证集样本回流到识别集。
**注意：e-process 只对"验证样本在 H0 下可交换且与识别过程独立"成立。复用验证集或按历史结果挑样本会破坏鞅性，这正是 AIC-A 要攻击的点。**

**定义 242（验证信用与证书租约 ALV）** 证书携带租约 `L=(θ̂_act,Σ_act,t_val,Δ_max)`。由漂移界 `‖θ_act(t)−θ̂_act‖≤λ_drift·Δ+σ_w√Δ` 与安全裕度 `m` 反解
`Δ_max = max{Δ: λ_drift·Δ+σ_w√Δ ≤ m / L_f,js}`，
其中 `L_f,js` 为驱动误差到兑现力的 Lipschitz 常数（由雅可比与传动比给出）。每次执行消耗信用；出现以下任一即租约失效：`t−t_val>Δ_max`、温度越界、累计磨损超阈、或 `E_t` 超界。失效后 `Valid(J_jive)←false`，只允许执行**收缩到安全停点**的前缀，禁止扩张动作空间，直到 `renew_lease` 成功。**包络单调性：未重新验证前只减不增；扩张必须由新的独立验证证据支持。**

**定义 243（驱动感知膨胀 RSC-A）** 维护 `r_geo,r_force,r_model`（继承 VISTA）与 `r_act,r_trans,r_thermal,r_sat,r_wear`。归因定向膨胀：
- `H_act → r_act↑`，并排程一次自由空间扫掠重标定；
- `H_trans → r_trans↑`，并在换向处插入柔顺/低增益过渡；
- `H_thermal → r_thermal↑`，并触发热降额重标定；
- `H_sat → r_sat↑`，并降低命令上限；
- `H_sense → r_force↑`（沿用 VISTA，不升 `r_geo`）；
- `H_env → r_geo/r_model↑`（沿用 VISTA，不升驱动半径）。
带租约老化项 `r_act(t)=r_act^0+λ_drift(t−t_val)`。融合
`r=√(r_geo²+r_force²+r_model²+r_act²+r_trans²+r_thermal²+r_sat²)`。
**任何未能归因的兑现残差一律计入 `r_act`，绝不静默丢弃——这是"兑现盲区不消失，只会变保守"的结构性保证。**

**定义 244（驱动感知 WCV-A）** 搜索域
`B(φ̂,r) ∩ 𝒢(g) ∩ K(μ̂) ∩ ℱ_deliv ∩ 𝒱 ∩ 𝒜`，
其中 `ℱ_deliv={θ_act: ∀j, |f_deliv,j(θ_act)|≤f_lim}` 用**兑现力**而非指令力，`𝒜={θ_act: (θ_act−θ̂)ᵀΣ_act⁻¹(θ_act−θ̂)≤χ²_{d_θ,1−β}}` 为驱动参数置信支持域。CVaR 尾部对 `(θ_act,θ_env)` 联合采样取最坏；若 `𝒜` 与几何/视觉约束交集为空，回退 `B(φ̂,r)` 并置 `actuation_conflict=True` 写入证书。**关键差异：VISTA 保证"我命令的力不超限"，JIVE 保证"世界收到的力不超限"。**

**定义 245（驱动感知规划 CSP-A）** 块级技能图增四个元技能：
- `verify_drive`：自由空间静载/低速扫掠，估计增益/偏置/摩擦；
- `excite_drive`：在 `B_exc` 内执行换向/载荷阶跃，提升 `J_act`；
- `renew_lease`：在独立构型上重跑 IVL 并续租；
- `retreat`：租约失效时收缩到安全停点并告警。
每条块边需 `Valid(J_jive)`、租约未过期、且 `ℱ_deliv` 在支持集上成立。技能 σ 绑定典型驱动参数分布 `𝒟_σ`，实际估计的 Mahalanobis 距离 >τ_drive 即判 OOD、不入图。软约束代价增 `λ_lease·Σ hinge(Δ_max−Δ_req)` 与 `λ_exc·B_wear`。

**定义 246（对抗驱动认证 AIC-A）** 干扰集
`ℰ_J = ℰ_V × ℰ_act × ℰ_lease`，
- `ℰ_act`：摩擦翻倍/减半、增益失配 ±20%、背隙增大 3×、柔顺下降、热斜坡 −20℃~+40℃、力矩饱和、编码器量化；
- `ℰ_lease`：验证集复用、按上轮结果自适应选择验证样本、静默老化、e-value 重放；
- 共因：**传感-驱动共因**（共用电流/编码器使 `ε_drive` 与 `ε_sense` 同源）、**驱动-环境共模**（摩擦增大被读成接触变软）。
在 `ℰ_J` 上重算 `ρ_dir`，`n_cert` 提高（如 128→192），并对 e-process 做"恶意可选停止"攻击测试。`J_dir` 增 `drm_ver, lease_ver, data_role_hash`。**共因故障下不要求归因正确，只要求判 `ambiguous/inadmissible` 并安全降级，且租约不得被错误续期。**

**定义 247（JIVE 证书 J_jive）** 
`J_jive = (J_vista, θ̂_act, Σ_act, κ_act, excitation_cov, val_evalue, lease_remaining, attribution_axis, drm_ver, data_role_hash, aic_a_ver)`。
验证规则：
`Valid(J_jive) ⇔ Valid(J_vista)`
`∧ κ_act ≥ κ_min ∧ excitation_cov ≥ c_min`
`∧ (E_t < 1/α 或已判 inadmissible 并冻结)`
`∧ lease_remaining > 0`
`∧ 兑现力在 ℱ_deliv 内`
`∧ C_id∩C_val=∅ ∧ C_val∩C_audit=∅ ∧ data_role_hash 与当前数据角色一致`
`∧ aic_a_ver 为当前版本`。
审计链新增：**为什么相信这个驱动模型（θ̂_act, Σ_act, κ_act）、这条激励覆盖了什么（excitation_cov）、验证是否可能自证（val_evalue, data_role_hash）、证书还剩多少租约（lease_remaining）。**

**定义 248（JIVE 闭环算子）** 见 IP-233 伪代码。语义流：[VISTA 闭环 → AGG 兑现接地 → DRM 辨识 → JDR 三侧分解/归因 → 可及性检查 → (不充分? IEQ 设计激励 → IVL 验证 → ALV 续租/冻结) → RSC-A → WCV-A → CSP-A → CSC-L 认证前缀 → Shield → 执行 → AIC-A]；实时流：[读编码器/电流/温度/力 → 驱动残差采集 → 兑现力守卫 → 租约倒计时 → CSC-L 早停 → 派发前缀 → J_jive 构建]。

### IP-224 AGG（兑现接地）

```python
def actuation_grounding(tau_cmd, tau_j, q, qd, qdd, T, in_contact, contact_conf):
    # tau_j 可由关节力矩传感器，或电流×转矩常数−DRM 估计
    eps = tau_j - tau_cmd
    f_cmd = jacobian_invT(q) @ tau_cmd
    f_del = jacobian_invT(q) @ (tau_j - M(q) @ qdd - C(q, qd) @ qd - g(q))
    e_act = mahalanobis(f_del - f_cmd, SIGMA_A)
    # 有接触且接触模型不可信时，禁止用 e_act 做驱动辨识
    mask = (not in_contact) or (contact_conf >= CONF_MIN)
    return {'eps': eps, 'e_act': e_act,
            'f_deliv': f_del, 'grounding_mask': mask}
```

### IP-225 DRM（驱动残差模型）

```python
class DriveResidualModel:
    """tau_j = clip(g*(kt(T)*i+bi) - fric(qd) - trans(qm-q; beta,kc), tau_max(T)) + w"""
    def __init__(self, n_joints, prior, drift_rate=1e-3, sigma_w=1e-3):
        self.J, self.prior = n_joints, prior
        self.lam, self.sig_w = drift_rate, sigma_w

    def predict(self, tau_cmd, q, qd, T, theta):
        out = []
        for j in range(self.J):
            g, b, fc, fs, fv, vs, beta, kc, tmax, aT = theta[j]
            tau_m = g * (kt(T[j]) * current_of(tau_cmd[j]) + b)
            tau_f = np.sign(qd[j]) * (fc + (fs - fc) * np.exp(-abs(qd[j]) / vs)) + fv * qd[j]
            tau_t = kc * backlash(qm(j) - q[j], beta)
            out.append(np.clip(tau_m - tau_f - tau_t, -tmax(T[j]), tmax(T[j])))
        return np.array(out)

    def identify(self, log, mask):
        # 只在 grounding_mask=1 的样本上做加权最小二乘/极大似然
        data = [s for s, m in zip(log, mask) if m]
        theta_hat = map_estimate(data, self.prior)      # 含摩擦/背隙非光滑项
        Sigma = laplace_covariance(theta_hat, data)
        return theta_hat, Sigma

    def drift_bound(self, dt):
        return self.lam * dt + self.sig_w * np.sqrt(dt)
```

### IP-226 JDR（三侧分解与归因）

```python
class JointSideAttributor:
    HYP = ('H0', 'H_sense', 'H_act', 'H_trans', 'H_thermal',
           'H_sat', 'H_env', 'H_vis', 'H_policy', 'H_unknown')

    def decompose(self, residual_log, theta_hat, f_FT, f_model, visual):
        eps_drive = residual_log.tau_j - DRM.predict(residual_log.tau_cmd, theta_hat)
        eps_sense = f_FT - jacobian_invT(residual_log.q) @ residual_log.tau_j
        eps_env = residual_log.f_deliv - f_model(visual.phi_hat)
        return {'drive': eps_drive, 'sense': eps_sense, 'env': eps_env}

    def admissibility(self, evidence_avail, H):
        need = {
            'H_sense':  {'free_space', 'reversal'},
            'H_act':    {'free_space', 'reversal'},
            'H_trans':  {'reversal', 'load'},
            'H_thermal':{'thermal_span'},
            'H_sat':    {'near_saturation'},
            'H_env':    {'contact', 'visual'},
        }
        return need.get(H, set()) <= evidence_avail

    def attribute(self, rho_J, avail, delta_fi=0.15):
        logp = {h: np.log(self.lik[h](rho_J) + 1e-12) + np.log(self.prior[h])
                for h in self.HYP}
        post = softmax(logp)
        h_star = max(post, key=post.get)
        if not self.admissibility(avail, h_star):
            return post, h_star, 'inadmissible'      # 数据不足以区分，不是"故障"
        if post[h_star] < 1 - delta_fi:
            return post, h_star, 'ambiguous'
        return post, h_star, 'ok'
```

### IP-228 IVL（迭代验证环）

```python
class IterativeValidator:
    """独立构型 + 证伪激励 + e-process anytime-valid 判决。"""
    def __init__(self, alpha=0.05, log_lr=None):
        self.alpha, self.log_lr = alpha, log_lr or default_log_lr
        self.logE = 0.0
        self.val_configs = set()

    def validate(self, theta_hat, D_id_configs, D_val_configs, falsify_traj):
        if self.val_configs & set(D_id_configs):
            raise ValueError('validation/identification config overlap')
        # 证伪激励：必须包含拟合集未覆盖的方向
        r_falsify = residual(falsify_traj, theta_hat)
        if r_falsify > FALSIFY_TAU:
            self.logE += np.log(1 / self.alpha)       # 直接判失败
            return False, np.exp(self.logE), 'falsification_failed'
        for s in D_val_configs:
            self.logE += self.log_lr(residual(s, theta_hat))
        self.val_configs |= set(D_val_configs)
        reject = self.logE >= np.log(1 / self.alpha)
        return (not reject), np.exp(self.logE), ('reject' if reject else 'accept')

    def reset_after_reidentify(self):
        self.logE, self.val_configs = 0.0, set()
```

### IP-229 ALV（租约）

```python
class ActuationLease:
    def __init__(self, theta, Sigma, t_val, lam, sig_w, margin, L_f):
        self.theta, self.Sigma, self.t_val = theta, Sigma, t_val
        self.lam, self.sig_w, self.margin, self.L_f = lam, sig_w, margin, L_f
        self.Delta_max = self._solve_lease()

    def _solve_lease(self):
        # lam*D + sig_w*sqrt(D) <= margin / L_f
        b = self.sig_w / self.lam
        return ((np.sqrt(b*b + 4*self.margin/(self.lam*self.L_f)) - b) / 2) ** 2

    def tick(self, t, T, wear):
        expired = (t - self.t_val > self.Delta_max) or out_of_temp(T) or wear > WEAR_MAX
        return {'expired': expired,
                'remaining': max(0.0, self.Delta_max - (t - self.t_val))}

    def renew(self, theta, Sigma, t):
        self.theta, self.Sigma, self.t_val = theta, Sigma, t
        self.Delta_max = self._solve_lease()
```

```python
def JIVE_round(M, obs, delta_f_req):
```

## 4. 推导

**引理 9（驱动层可辨识性）** 设线性化 `E[e|θ]=S_J θ`，`e=(ε_drive,ε_sense,ε_env)`，`θ=(θ_act,θ_sense,θ_env)`。把驱动参数按特征分解为：恒值项 `b_act`、方向项 `sign(q̇)·f_c`、速度项 `f_v q̇`、换向项 `β·1[换向]`、热项 `α_T(T−T_0)`、饱和项 `1[|τ_cmd|≈τ_max]`。则 `S_J` 的行由**激励轨迹的特征**给出：
- 自由空间静载（`q̇=0`，多个构型）只激励 `g,b_act` 与重力相关的行，`f_c` 列在 `q̇=0` 处为零，故可先分离 `g`（随载荷/构型变化）与 `b_act`（不随载荷变化）；
- 自由空间低速正反扫掠给 `sign(q̇)` 取 ±，使 `f_c` 列与恒值 `b_act` 列线性无关；
- 换向段使 `β` 列出现一阶不连续，而 `g` 列连续；
- 温度跨度使 `α_T` 列与其余列近正交；
- `ε_sense` 通道与 `ε_drive` 通道在 `H_sense` 与 `H_act` 下取值模式不同。
若 `c_rev=0`，则 `sign(q̇)` 恒为 +，`f_c` 列退化为 `b_act` 列的倍数，`S_J` 秩亏，摩擦与传感器偏置不可分；若 `c_pose=1`，则 `g` 与 `b_act` 在同一构型下共线，增益与偏置不可分。因此 `κ_act=λ_min(J_act)/λ_max(J_act)` 由 `({c_pose},{c_rev},{c_v},{c_τ},{c_T})` 控制，而非由估计器控制。∎

**引理 10（迭代验证的 anytime-valid 非自证）** 设原假设 `H0`：DRM 的预测误差分布为 `p_0`；备择 `H1`：误差分布为 `p_1`。若每轮 `D_val,t` 与 `D_id,t` 独立、且在 `H0` 下验证样本可交换，则 `E_t=∏_{s≤t} p_1(r_s)/p_0(r_s)` 是非负鞅，`E_{H0}[E_t]≤1`。Ville 不等式给出 `P_{H0}[∃t:E_t≥1/α]≤α`，即**任意可选停止策略**（包括"看结果不好就继续验证直到通过"）下假接受率仍 ≤α。反之，若复用同一验证集、或按上一轮 `E_s` 自适应挑选验证样本，则 `r_t` 不再在 `H0` 下与历史独立，鞅性破坏；重复使用 k 次同一验证集会令有效显著性约放大 k 倍，"迭代验证"变成"迭代过拟合"。证毕。∎

**定理 9（JIVE 端到端兑现-安全）** 在 A95–A99 下（A95：DRM 参数在租约内漂移有界；A96：识别/验证/认证集按构型与时间互斥；A97：激励覆盖至少达到 `c_min`；A98：兑现力与关节力矩的映射 Lipschitz；A99：传感与驱动不共享未建模共因，或共因被 `H_unknown` 吸收）：
1. **兑现可测**：`Valid(J_jive) ⇒ P[∀s≤k*: f_deliv(s)∈ℱ_deliv]≥1−α_chunk−α_act`，由 WCV-A 在 `𝒜` 上对 `θ_act` 取最坏与 CSC-L 的 conformal 覆盖得到。
2. **故障可分**：若 `Adm(H)` 通过且 `κ_act≥κ_min`，引理 9 给出驱动/感知/环境列的近正交，`JDR` 后验以 `O(exp(−nκ_act/2))` 集中；归因正确时只膨胀对应半径（定义 243），不会把驱动故障误判为几何幻觉。
3. **非自证**：若验证协议满足定义 241，引理 10 给出迭代假接受率 ≤α；`data_role_hash` 与 `C_id∩C_val=∅` 保证验证集未被设计过程污染。
4. **租约安全**：`lease_remaining>0` 且 `t−t_val≤Δ_max` 时，漂移界保证 `‖θ(t)−θ̂‖≤m/L_f`，故兑现力误差不超过安全裕度；过期只允许收缩，不引入新风险（定义 242）。
5. **优雅降级**：驱动不可辨识→`attribution_inadmissible` + 冻结扩张；租约失效→收缩至安全停点；传感/驱动共因→`H_unknown` + 保守联合膨胀；VISTA 全部保证在 `θ_act` 已知子空间上仍成立。
6. **实时性**：AGG/守卫/倒计时 ≤0.15ms，其余在语义流（A100）。∎

**定理 10（迭代验证的收敛与最优节奏）** 设 DRM 参数在验证间隔 Δ 内按 `θ(t+Δ)=θ(t)+λ_driftΔ+σ_w√Δ ξ` 漂移，单次验证使误差按 `(1−η)` 收缩（持续激励下最小二乘/极大似然的标准结论），则第 t 次验证后的均方误差满足
`E‖θ̂_t−θ‖² ≤ (1−η)^t e_0 + (λ_drift²Δ² + σ_w²Δ)/(1−(1−η))`。
在长期运行中第二项主导，形成漂移地板。另一方面，单位时间验证成本 `c_v/Δ`（激励、磨损、停机），漂移风险成本 `c_d(λ_drift²Δ²+σ_w²Δ)`。对 Δ 最小化
`C(Δ)=c_v/Δ + c_d(λ_drift²Δ²+σ_w²Δ)`，
由 `−c_v/Δ² + c_d(2λ_drift²Δ+σ_w²)=0`，在 `σ_w` 较小时得 `Δ*≈(c_v/(2c_dλ_drift²))^{1/3}`。故"越频繁验证越安全"不成立：存在由漂移率与激励代价决定的最优验证节奏；租约 `Δ_max` 应取安全约束下的上界，而实际重验证节奏取 `min(Δ_max,Δ*)`。∎

**命题（兑现接地降低 VISTA 误归因）** VISTA 的 `H_force` 质量可分解为感知侧 `M_sense` 与驱动侧 `M_act`。JIVE 在自由空间即可测得 `M_act`，故可把 VISTA 中"因驱动误差而触发的几何降级"质量移出。设 VISTA 的误降级率为 `R_V = P[H_geo|H_force]`，JIVE 在 `Adm` 通过时把该条件概率降为 `P[H_geo|H_env]`；两者之差为可归因的驱动误差质量。定量上，若驱动误差占总力残差比例 ρ，且自由空间段占比 γ，则误降级率的期望下降至少 `ργR_V`。∎

## 7. 已知风险

**一句话**：JIVE 的全部保证依赖"激励覆盖足够、验证集真正独立、驱动参数漂移有界"这三个前提；真实场景里磨损与热漂移会让驱动模型与环境模型互相吸收误差（摩擦增大被读成接触变软、增益下降被读成几何偏差），而共用的电流/编码器又让"识别"与"验证"共享同一故障源，于是系统可能用消耗寿命的激励反复确认一个自洽却错误的驱动模型——**迭代验证从安全机制退化为自我确认的仪式，证书租约越续越自信，直到兑现力越过真实力限。**

**次级风险与缓解**：
1. **驱动不可辨识却被迫归因**：低速度/单构型作业天然缺换向；缓解：显式 `inadmissible` 状态、强制插入 `verify_drive`、或用外部激励台/多指协同创造构型差；不可辨识时只保守膨胀，不归因。
2. **迭代验证自我确认**：验证集复用、自适应挑选、e-value 重放；缓解：构型/时间不相交、e-process anytime-valid、`data_role_hash` 审计、AIC-A 主动攻击。
3. **驱动-环境共模**：摩擦/柔顺增大被读成接触变软或几何偏差；缓解：自由空间先验、换向段、联合后验（`θ_act` 与 `θ_env` 的交叉协方差）、必要时插入已知刚度标定件。
4. **传感-驱动共因**：共用电流/编码器使 `ε_drive` 与 `ε_sense` 同源；缓解：独立关节力矩传感器/双编码器、共因模型、`H_unknown` + 保守联合膨胀。
5. **激励损伤与磨损**：验证本身消耗寿命、可能压坏易损物体；缓解：易损物体只用自由空间/视觉激励、磨损预算 `B_wear` 记账、激励幅度自适应。
6. **租约参数保守性**：漂移界 `λ_drift` 过大会使租约过短、频繁停机；缓解：离线标定 + 在线漂移检测、按 `Δ*` 与安全上界取折中、分层续租。
7. **DRM 模型误设**：Stribeck/背隙/迟滞模型族本身不完整（如未建模的齿槽、温变非线性）；缓解：残差 `H_unknown`、非参数补偿项、模型族叠加与 AIC 选择。
8. **实时预算**：WCV-A 对 `θ_act` 采样逼近 2.65ms；缓解：预编译参数支持域、`θ_act` 降维/子空间、把 AGG 与守卫与 LSF 共享编码。
