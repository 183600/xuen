# 第 43 轮（新循环第 3 轮） · 语义地图成为证书的坐标系：多模态主动接地 × 可信语义图 × 语义-度量证书图谱（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉」，本质是两类**被动压缩的失真**：环境被压成向量指纹 ψ，语义被 VLM 一次性压成单标签。本轮灵感词「语义地图」「多模态交互」正好补回被压缩掉的两样东西——**结构**与**主动检验**。语义地图把环境从「一个点」还原成「一张可分解、可组合的图」，于是证书可以按语义区域切片、按边界契约拼接；多模态交互把「相信 VLM 的语义」变成「在证书最敏感处，用接触/视角/听觉/人类问答主动证伪它」。核心转变：证书自变量从 x 升级为 (x, h)（h 为语义假设）；语义地图是证书的**索引结构与组合骨架**，多模态交互是**降低语义不确定性、换取更紧证书**的主动手段。

## 0. 直觉与动机

**灵感 1（语义地图 → 从「指纹」到「坐标系与拼图骨架」）**：人不会把整个房间当成一个黑箱指纹；人会说「厨房—走廊—玻璃门」，不同区域的危险机理不同，过门槛有明确的通行规则。第 42 轮恰恰把整张地图压成 ψ，CKB 检索靠向量相似度，导致对「结构相似但语义不同」的屋子失灵；同时全局 L_m 把所有区域绑在一起，边界处的剧烈变化被迫用最坏 Lipschitz 覆盖，可用性被拖垮。语义地图给出的正是这种分解：**Map → Atlas**——证书 patch 挂在语义节点上，跨区域用**边界契约**（guard + margin reserve）拼接；全局 L_m 分解为「区域内 L_m^v + 边界预留 ε_{uv}」，保守性显著下降，且组合失败点从「全局不可证」收缩为「某条边契约不满足」这一可定位、可修复的局部。

**灵感 2（多模态交互 → 证书感知的主动证伪）**：VLM 说「这是玻璃门」可能错；伸手轻触、换视角看反光、听敲击声、或问一句人，就能极低成本证伪。关键约束是：**探测本身可能危险**（推玻璃门、摸热表面、抓易碎物），所以必须「只在证书价值最高处探测」，且探测动作本身要在最坏语义假设下安全。于是探测不是漫无目的的探索，而是一个**证书信息价值**问题：VoI_cert(a) = 预期语义边际下界的提升 / (时间 + 风险)，并带一条硬约束——探测轨迹必须落在最坏假设 h_⊥ 的证书内（self-certifying probe）。这把多模态交互从「感知层的一个融合模块」提升为「证书闭环里的一个受约束决策」。

**灵感 3（语义不确定性升为一等公民 → 可信语义图与标签翻转应急）**：与其赌一个标签，不如携带「标签集合 + 置信」。证书对**整个可信标签集**成立才放行；一旦出现反证据，标签翻转直接触发重颁或 SafeStop。第 42 轮的语义错误是「静默失效」（自信地用错了标签），本轮把它变成**显式、可监控、可回退**的状态机分支。这并非消除语义错误，而是让错误**可被观测、可被计费、可被熔断**。

**耦合升级**：语义地图为 CKB 提供**子图检索键**（结构对齐取代向量相似度）；多模态交互为语义地图供**接地证据账本**；证据更新触发证书重颁（SM-RAG）；CKB 中的历史 patch 与接地历史让下一次探测更省、更准。四者构成 **Perceive → Probe → Certify → Compose → Re-issue** 的语义闭环，与第 42 轮的 Sim→RAG→Edge→Sim 飞轮正交叠加：前者管「语义对不对」，后者管「数值偏不偏」。

## 1. 形式化定义（增量：定义 38–44）

**定义 38（可信语义-度量地图 CSM）**：M = (V, E, X, ℓ, b, π)。V 为语义区域/物体节点；E 为邻接（含门、坡道、过渡带）；X: V → 2^{R³} 为度量支撑；ℓ: V → 2^L \ {∅} 为**可信标签集**（不再是单标签）；b: V → Δ(ℓ(v)) 为节点信念；π 为全局假设先验。语义假设 h: V → L 满足 h(v) ∈ ℓ(v)，假设空间 H = Π_v ℓ(v)。给定置信度 β，取**可信假设集** H_β = 满足 π(H_β) ≥ 1−β 的最小假设集（probability box 的 β-截断）。每个 h 诱导一张度量语义地图 M_h = (X, ⟨通行性, 摩擦类, 可变形性, 危险语义类型⟩_h)。直觉：M 不是一个地图，而是**一族地图 + 一个关于「哪族成员可信」的信念**。

**定义 39（标签条件证书与语义边际）**：对假设 h，C_h = {x : m_h(x) ≥ θ_h}。称 x 在语义不确定性水平 β 下 **β-安全** ⟺ ∀h ∈ H_β, x ∈ C_h。**语义边际** σ(x) = min_{h∈H_β} [m_h(x) − θ_h]，它是一张证书对「语义还可能是什么」取的最坏情形。**语义稳健半径** ρ_sem(v) = min_{h'∉H_β} d_H(h*, h')，h* 为当前最大后验，d_H 为标签翻转的加权汉明距离。ρ_sem 小 ⟺ 该区域贴近「标签判决面」⟺ 高探测价值——这是 CAMP 的价值信号来源。

**定义 40（证书感知多模态探测 CAMP）**：探测动作 a ∈ A_probe = {换视角, 接触轻触, 推/拉, 抓取, 主动光照, 人类问答}；观测模型 O_a(o | h)。更新后可信集为 H_β^{+o}。**证书信息价值** VoI_cert(a) = E_{o∼O_a}[ (σ_pre(x) − σ_post(x))_+ ]，即「预期把安全可知域边界向外推多少」。探测选择 a* = argmax_a VoI_cert(a) / (c_a + λ·r(h_⊥, a))，并施加**硬约束**：a 在最坏假设 h_⊥ 下满足**自证安全**。自证探测定义为：执行 a 的轨迹始终落在 C_{h_⊥} 内，且 a 的启动条件不依赖任何未验证的正标签（不允许「因为看起来是空地所以先冲过去」）。

**定义 41（接地证据账本与可信更新）**：证据 e = (v, μ, ℓ̂, y, c, t)，μ 为模态，ℓ̂ 为声称标签，y ∈ {support, contradict, inconclusive}，c 为代价、t 为时刻。硬更新：support 时 H_{t+1} = H_t ∩ {h : h(v)=ℓ̂}；contradict 时 H_{t+1} = H_t ∩ {h : h(v)≠ℓ̂}；inconclusive 不收缩只降权。若交集为空 → **语义惊奇（semantic surprise）**：真实标签落在 ℓ 之外（open-world），此时扩标签集、把区域置 Unknown、触发 SafeStop 或立即再探测。软更新采用温度化贝叶斯，输出经校准（期望校准误差 ECE 受监控）的 b。直觉：账本不是「感知日志」，而是**可回溯、可审计的语义判决依据**。

**定义 42（语义-度量证书图谱 Atlas 与边界契约）**：证书 patch P_v = (Inv_v, θ_v, m_v, T_hold^v, L_m^v, h_v)。边界契约 Γ_{uv} = (guard_{uv}, ε_{uv}, mod_{uv})，要求 Inv_u ∩ guard_{uv} ⊆ Inv_v。**拼接定理**：若 (i) 每片 P_v 在其标签假设下 sound；(ii) 每条边界满足契约且 margin reserve ε_{uv} ≥ L_m·δ_boundary；(iii) 语义假设 h 在整条连通路径上一致——则沿路径拼接得到的证书 sound。含边界后，全局 L_m 被替换为 max_v L_m^v + ε_boundary，过保守性大幅下降。关键点：**语义边界正是 L_m 的不连续面**，必须显式建模而不是被全局最坏值吞掉。

**定义 43（SM-RAG 子图检索）**：查询 Q = 当前区域及其 k 跳邻域的语义子图（带可信标签）。相似度 Sim(Q, r) = max_{φ∈Emb(Q,r)} Σ_v b_Q(v)·b_r(φ(v))·sim_label(ℓ_Q, ℓ_r) + λ_g·结构匹配，Emb 为子图嵌入/图编辑匹配集合。检索返回 (patch 模板, 接地历史, 边界契约)。迁移差集扩展为 Δ = Δ_geo ∪ Δ_label，其中 Δ_label = {v : ℓ_Q(v) ∩ ℓ_r(v)=∅ 或 b 距离过大}。直觉：检索键从「一个向量」变成「一张小图」，于是「结构像但语义不同」的误检索会被 Δ_label 显式挡下，而不是被高余弦相似度蒙混过关。

**定义 44（交互感知成本与风险）**：COT_v3 = C_sim/N + C_edge·T + C_human·N_verify + C_probe·N_probe。风险 R = Σ_v P(flip_v)·Consequence_v，P(flip_v) 由 H_β 后验给出。Pareto 前沿在 (COT, 语义违例率, Nominal 占比, 探测负担) 四维上显式化。直觉：探测不是免费的正确性，它要与「多问一句人」和「直接 SafeStop」在经济上竞争。

## 2. 产出设计（增量 IP-57/58/59 + 升级 IP-51/52/53/49/50/47/45/35/55/56）

### 2.1 IP-57 CAMP（Cert-Aware Multimodal Probing，证书感知多模态探测器）
1. **探测原子库**：按模态分组的参数化动作（视角 δθ、接触力上限 F_max、推/拉位移上限、抓取位姿、主动光照模式、结构化人类问句模板），每个动作带代价与最坏情形风险模型。
2. **自证安全过滤器**：所有候选动作先过 h_⊥ 证书检查，只保留「最坏语义假设下仍安全」的动作；这是 CAMP 与普通主动感知的分水岭。
3. **VoI_cert 估计器**：用观测模型对候选动作做蒙特卡洛/解析后验，估计语义边际下界提升；对高价值动作再跑一次低成本 Sim 复核（复用 IP-54）。
4. **探测预算与冷却**：全局 VoI/成本阈值 + 区域冷却时间，防止对同一判决面反复探测；探测失败升级为人类问答或 SafeStop。

### 2.2 IP-58 CSMA（Credal Semantic-Metric Atlas，可信语义-度量证书图谱）
1. **可信标签构建**：以 VLM/检测器输出为初值，经「标签集扩增 + 温度化信念」得到 ℓ(v), b(v)；低置信节点显式保留多个标签，禁止过早塌缩为单标签。
2. **patch 生成与区域 L_m**：每个语义节点独立标定 L_m^v（复用 IP-49/54 的经验分位），危险机理不同的区域不共享 Lipschitz。
3. **边界契约提取**：对每条跨区域边，学习/验证 guard_{uv}（如「进入厨房前速度 ≤ v_kitchen」「过玻璃门前必须已接地为 open」）与 margin reserve ε_{uv}；契约不满足直接判 UNKNOWN，不上报全局失败。
4. **拼接与冲突定位**：沿路径做 atlas 组合，输出「哪一条边、哪一个假设」导致失败，供 RCA 精准修复。

### 2.3 IP-59 GLEAN（Grounding Ledger & semantic re-issue，接地账本与语义重颁）
1. **证据账本**：记录每次 support/contradict/inconclusive，带模态、代价、时间戳、传感器快照哈希，支持审计与回放。
2. **可信更新与惊奇检测**：硬更新遇空集即语义惊奇；惊奇事件进入「open-world 队列」，强制扩标签集或升级人工。
3. **SM-RAG 子图检索与条件迁移**：以语义子图为键检索历史 patch/契约/接地历史；先在 Δ_label 上探测，再在 Δ_geo 上跑 CEGAR，合成成本 ∝ |Δ_geo| + |Δ_label|。
4. **标签翻转重颁**：任何节点的最大后验翻转或 b 越过阈值，触发 RCA 重颁证书（新 InterestedArea/假设标签入证书对象），并热更新到 IP-51/IP-56。

## 5. 本轮最大风险

**一句话**：本轮把「语义」从一次性标签升级为可信假设集、并让多模态交互去主动证伪，但**语义假设空间本身不封闭（unknown unknowns）**——可信语义图只能表达「我们想到过的标签」，自证探测又默认最坏标签 h_⊥ 的动力学已知；一旦出现从未建模的语义（如「透明玻璃=可通行」「反光地面=干燥」），系统会自信地认为语义已被主动证伪覆盖，证书在假设空间之外静默失效，比第 42 轮的检索幻觉更隐蔽、更致命，因此 E92（open-world 语义惊奇）与 E88（探测自证安全）必须作为红线实验，任一不达标即熔断回退到 h_⊥ 单假设 + 固定 SafeStop。

## 2. 关键算法（伪代码）

### IP-57 CAMP：自证过滤 + 证书信息价值选探测
```
def cert_aware_select_probe(M, x, H_beta, A_probe, budget):
    sigma_pre = semantic_margin(M, x, H_beta)
    best = None
    for a in A_probe:
        # 硬约束：最坏语义假设下仍安全，且不依赖任何未验证正标签
        if not self_certifying(a, x, h_null=M.h_null):
            continue
        if cost(a) + lam * flip_risk(h_null, a) <= 0:
            continue
        # 用观测模型估计后验边际提升（可解析处解析，否则 MC 采样）
        sigma_post = expected_post_margin(M, a, H_beta, x)
        voi = max(0.0, sigma_post - sigma_pre)
        score = voi / (cost(a) + lam * flip_risk(h_null, a))
        if best is None or score > best.score:
            best = Probe(score=score, action=a, voi=voi)
    return best  # None 表示无可自证的高价值探测 → 转人类问答或降级

def self_certifying(a, x, h_null):
    # 执行 a 的整条轨迹必须落在最坏假设证书内
    traj = rollout(a, x, dynamics=h_null)
    return all(m_h_null(s) >= theta_h_null for s in traj)
```

### IP-59 GLEAN：可信更新 + 语义惊奇 + 标签翻转重颁
```
def update_credal(M, e, H_beta):
    if e.y == 'support':
        H_new = {h for h in H_beta if h[e.v] == e.label}
    elif e.y == 'contradict':
        H_new = {h for h in H_beta if h[e.v] != e.label}
    else:
        H_new = H_beta  # inconclusive：不收缩，仅降该模态权重
    if len(H_new) == 0:
        return semantic_surprise(M, e)   # open-world：扩标签集 / Unknown / SafeStop
    return recalibrate_belief(M, H_new)

def semantic_surprise(M, e):
    M.labels[e.v] = M.labels[e.v] | {e.label_alt}   # 扩标签集
    M.unknown.add(e.v)
    bus.publish('semantic/flip', {'region': e.v, 'cause': 'surprise', 'evidence': e})
    return TriggerReissue(region=e.v, mode='SafeStop')  # 或立即再探测

def on_label_flip(M, region, h_new):
```

### IP-58 CSMA：atlas 拼接与边界契约
```
def compose_atlas(path, atlas):
    cert = atlas[path[0]].patch
    for u, v in zip(path, path[1:]):
        Gamma = atlas.contract(u, v)
        # 契约必要条件：离开 u 的不变式 + 跨区守卫 ⇒ 进入 v 的不变式
        if not subset(intersect(cert.Inv, Gamma.guard), atlas[v].patch.Inv):
            return Conflicting(edge=(u, v), reason='invariant')
        # 边界预留：局部 Lipschitz 只在区域内有效，跨界必须留余量
        reserve = cert.margin_at_boundary(u, v) - atlas[v].patch.L_m * DELTA_BOUNDARY
        if reserve < Gamma.eps:
            return Conflicting(edge=(u, v), reason='margin_reserve')
        cert = stitch(cert, atlas[v].patch, Gamma)
    return cert   # 成功拼接：全局 sound，保守性 = max_v L_m^v + boundary

def merge_contracts(contracts):
    # 同一边多条契约：guard 取合取（更严）、eps 取 max、模态假设取并集
    return Contract(
        guard=all_and([g.guard for g in contracts]),
        eps=max(g.eps for g in contracts),
        mod=set().union(*[g.mod for g in contracts])
    )
```

### IP-59 SM-RAG：子图检索 + 双差集补全
```
def smrag_synthesize(Q, H_beta, KB, budget_cegar=300):
    # 1) 子图检索：结构 + 标签信念 + 图嵌入
    cand = KB.subgraph_retrieve(Q, k=5)
    # 2) 条件合并（仅在与当前假设集一致的记录上迁移）
    patches = merge_patches([c.patch for c in cand], H_beta)
    contracts = merge_contracts([c.contract for c in cand if c.matches(Q)])
    # 3) 双差集：几何差集 + 标签差集
    Delta_geo = find_geometric_gaps(patches, Q)
    Delta_label = {v for v in Q.V
                   if Q.labels[v].isdisjoint(patches.labelset[v])
                   or belief_distance(Q.b[v], patches.b[v]) > TAU_B}
    # 4) 先探测标签差集（CAMP），再对几何差集跑 CEGAR
    probes = [cert_aware_select_probe(Q, v, H_beta, A_probe, budget)
              for v in Delta_label]
    patch = cegar_fill(Delta_geo, budget=budget_cegar)
    C_new = assemble(patches, patch, contracts)
    # 5) 生成探测/课程草案
    Pi_draft = merge_probe_curriculum([c.Pi for c in cand])
    return C_new, Pi_draft, Delta_geo, Delta_label, probes
```

### IP-51 CAR：语义不确定状态机
```
# states: Nominal, SemanticUncertain, Probing, Degraded, SafeStop
def car_step(state, x, M, H_beta):
    if M.unknown.non_empty() or surprise_queue.non_empty():
        return SafeStop
    sigma = semantic_margin(M, x, H_beta)
    if sigma >= 0:
        return state if state in (Nominal, Probing) else Nominal
    # 非 β-安全：先看是否有自证探测能救
    p = cert_aware_select_probe(M, x, H_beta, A_probe, budget)
    if p is not None and state != SafeStop:
        return Probing
    # 无自证探测 → 单调保守降级
    if can_degrade(x):
        return Degraded
    return SafeStop

def car_transition_guard(e, x, M, H_beta):
    # 守卫对可信假设集取最坏，而非对单标签
    return all(margin_under_h(M, x, h)[e] >= theta_h[e] for h in H_beta)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性保证 |
|---|---|---|---|

| IP-57 自证安全 | 每动作 O(T_roll) | O(T_roll) | 轨迹逐点满足 h_⊥ 证书 ⟹ 探测动作本身 β-安全 |
| IP-58 atlas 拼接 | O(|path|·(|Inv|+|E_b|)) | O(|path|·patch) | 契约 + 边界预留 + 假设一致 ⟹ 拼接 sound（拼接定理） |
| IP-58 边界契约检查 | O(1)/边 | O(1)/边 | Inv_u∩guard⊆Inv_v 且 ε≥L_m·δ ⟹ 边界无漏洞 |

## 6. 本轮最大风险

**一句话**：本轮把语义升级为可信假设集、并用多模态交互主动证伪，但**语义假设空间本身不封闭（unknown unknowns）**——可信语义图只能表达「我们想到过的标签」，自证探测又默认最坏标签 h_⊥ 的动力学已知；一旦出现从未建模的语义（如「透明玻璃=可通行」「反光地面=干燥」），系统会自信地认为语义已被主动证伪覆盖，证书在假设空间之外静默失效，比第 42 轮的检索幻觉更隐蔽、更致命，因此 E92（open-world 语义惊奇）与 E88（探测自证安全）必须作为红线实验，任一不达标即熔断回退到 h_⊥ 单假设 + 固定 SafeStop。
