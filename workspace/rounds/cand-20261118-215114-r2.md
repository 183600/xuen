# 第 14 轮（灵感驱动研究循环第 2 轮；本轮灵感：「分布外泛化」×「可解释性」）

> **基线**：第 13 轮 MetricVoiceGauge-NCD-HUTD（定义 583–594；引理 113–121；实验 E627–E646）。
> 本轮纪律：**偏移即价格 + 解释即证书 + 认知债务预算**。不推倒 v13：v11 的 HAS/HCC/HATD/HDT、v12 的 USG/TGC/BAA/GAGP/UC、v13 的 AIO/CPD/DDL/RTCR、v10 的 NGE/DSL/CC/CWM/CAE/NCP、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 与九不变式全部保留。三个新组件——SEC（分布偏移信用证书，含 CDRE 与 SIG）、IRE（不变理由解释器，含 SRC/CCX 与 IRC）、EDA（认知债务会计）——加一个集成层 ASR（可审计偏移路由器），一律以**中立元**接入；任一失效即严格退回 v13（引理 129），再沿 v13 退化链退回 v12/v11/v10/v9/v8/v7/v6。本轮只做三件事：把"分布外"从二值漂移告警改写为**可证的价格**（对每个证书间隙按密度比上界保守膨胀）；把"可解释"从事后显著图改写为**可执行、可证伪的充分理由证书**；把二者合成一条**越新奇、解释与偏移价格越贵、认知债务越不可透支**的审计链。

## 0. 直觉与动机

**灵感 1（分布外泛化 → 偏移不是开关，而是价格）**
直觉：v13 对分布外只有一个动作——漂移检测触发后塌缩到第 0 档。这既太粗（轻微偏移也全塌缩、活动性损失大），又太危险（检测器没触发时，`U_gap`/`U_dis` 仍按 i.i.d. 校准分位使用，偏移下根本不覆盖）。真正需要的不是"是否漂移"的二值判断，而是**漂移了多少、因此每个间隙要加价多少**。核心创新：**分布偏移信用证书（Shift Envelope Certificate, SEC）**与**偏移膨胀间隙（Shift-Inflated Gap, SIG）**。SEC 用分类器两样本检验估计部署/校准的密度比，并给出**单侧上界** `κ`（不是点估计）；SIG 把共形分位从 `1−α` 收紧到 `1−α/κ`——只要密度比不超过 `κ`，偏移下的单侧覆盖仍成立。关键反直觉点：**偏移的正确回应不是"换更快的档"或"全塌缩"，而是"给同一个证书加一个可计算的价格"**；价格高到预算之外才允许塌缩，且塌缩本身要留下可复核的依据。

**灵感 2（可解释性 → 解释不是显著图，而是可执行证书）**
直觉：事后显著图既不可证伪，也不忠实于决策路径——模型可以"看起来解释了"，却依赖完全不同的特征。安全关键系统需要的不是好看的热图，而是**这一次决策到底靠哪几条证据/约束成立**，以及**这些证据被破坏时决策会不会被及时发现**。核心创新：**充分理由证书（Sufficient Reason Certificate, SRC）**，输出一个最小理由集 `R`：固定 `R`、其余特征在认证扰动球内任意变化，动作与安全余量都不变；解释对象 `CCX=(a,R,m_R,ε,δ,证书链,对照集)` 是**可重放验证的证明对象**，不是独立代理模型的输出。它同时是运行时守卫：新观测一旦越出 `R` 的认证盒，或使非理由残差超界，旧决策**当场失效**，必须在本帧内重决，否则回退。关键反直觉点：**解释的目标不是"让人满意"，而是"让人能证伪"**；理由集越小越好，但必须足以挡住认证扰动。

**灵感 3（分布外×可解释 → 不变理由、分解价格与认知债务）**
直觉：偏移下决策之所以危险，往往不是输入"新"，而是决策依赖了**非不变的相关特征**（光照、背景纹理、接触面材质的偶然组合）。若能证明本次决策的理由集 `R` 跨环境不变、且非理由部分对余量的贡献被 `η` 界住，那么即使全局密度比 `κ` 很大，**这个决策的有效偏移价格可以只按理由坐标计**——理由不变时 `κ_R≈1`，真正要付的只是 `η`。这把"解释"从合规装饰变成**降低 OOD 证书价格的凭据**。同时，未解释的新奇性不会消失，它会累积成**认知债务** `D_ep`：新奇度减去已被理由/校准覆盖的部分，必须由主动采样、共形重校准或人工审计偿还；债务预算是与迁移/蒸馏/时间预算并列、**不可挪用**的硬约束。核心创新：**不变理由证书（Invariant Reason Certificate, IRC）+ 认知债务会计（EDA）+ 可审计偏移路由器（ASR）**。

**三者如何统一**
统一为 **v13 证书之上的"审计层"**：v13 回答"在时限内能安全实现多少"（`Exec_v13`），v14 回答"这些实现所依赖的世界假设今天还成立多少、能不能被人复核"（`Exec_v14`）。SEC 给世界偏移定价（`κ`），IRE 给决策理由发证书（`R/IRC/CCX`），EDA 给未知记账（`D_ep`），ASR 只在"价格—理由—债务"三者都过关时放行并附带解释。共享状态 `ζ_xa=(κ, U^shift, CCX, IRC, D_ep, mode, SEC, stamp)`。**SEC 回答"世界变了多少"，IRE 回答"这个决定靠什么成立、变了还成不成立"，EDA 回答"还有多少未知没还"，ASR 回答"这一帧到底该放行、审计还是弃权"**。四者不是四个补丁，而是"定价—举证—记账—裁决"的审计链。

## 1. 研究问题（轮次升级版）

- **Q1（偏移的可证定价）**：如何从有限部署流中给出密度比的**单侧上界** `κ`，而不是会被新颖样本系统性低估的点估计？在非平稳/对抗流下，块状在线共形与变点检验怎样组合才不产生"窗口内看似稳定、窗口外已失效"的假覆盖？语义偏移（新任务组合、新技能）与协变量偏移能否用同一套证书代数处理？
- **Q2（解释的忠实与可证伪）**：怎样定义"充分理由"才既不依赖代理模型、又能被运行时验证？最小性、稳定性、跨环境不变性三者如何同时刻画？当模型确实依赖非不变特征、或不存在小理由集时，解释应当诚实地报告失败，而不是给出一个"真但无用"的理由？
- **Q3（债务与裁决的最优性）**：如何度量新奇度与"已被解释/校准覆盖"的部分，使认知债务既可加总又不可被其他预算冲抵？在"放行—审计—弃权—塌缩"四态间，在线策略如何权衡进度、偏移风险、解释成本与债务偿还，而不退化为永远弃权？
- **Q4（与 v13 的兼容与活性）**：全局膨胀会不会把所有正常样本都推出可行集、使系统长期 `a_ask`？解释守卫是否可能在接触瞬间误杀有效决策？不变理由是否可能被"便宜但无关"的特征集合伪造？新增审计层能否守住 v13 的 50Hz/p99≤22ms 与 `Exec_v14⊆Exec_v13`？

## 2. 设计原则（在 P22–P24 基础上新增 P25–P27）

**P25 偏移即价格律（Shift is a Price）**
不存在"漂移/未漂移"的二值安全。每个间隙在使用前必须按其所在支撑上的密度比上界 `κ` 做保守膨胀：`U^shift = SIG(U;α,κ_R)+η`。`κ` 必须是单侧置信上界且带失效时间；变点触发或支撑越界时 `κ←∞`，此时唯一合法动作是第 0 档/`a_ask`。膨胀只准收紧、不准放宽任何 v13 阈值。

**P26 解释即证书律（Explanation is a Certificate）**
每个被放行的安全关键决策必须携带可重放的 `CCX`：理由集 `R`、认证扰动盒 `(ε,δ)`、绑定证书链与对照集。`CCX` 必须由**同一条决策路径**导出，禁止用独立代理模型"事后补解释"；其忠实性以"盒内动作/余量不变"判定，而非人类观感。运行时若观测越出认证盒，解释失效即决策失效；解释不得作为放宽 v13 证书的理由。

**P27 认知债务不可透支律（Epistemic Debt Cannot Be Overdrawn）**
新奇度中未被理由/校准覆盖的部分必须记入 `D_ep`，并以主动采样、重校准或人工审计偿还。`D_ep>B_ep` 时系统只能进入审计/弃权态，禁止用更多时间、更多迁移样本或更多蒸馏来"冲抵"债务。债务账本必须可单调审计：单调增（无偿还时）、非负、且每次偿还可追溯到具体证据。

## 3. 与基线的接口（如何退化）

- SEC 失效 ⇒ `κ≡1、α_s=0`，SIG 退化为 v13 的原始共形分位，只剩 v13 的支撑检查与漂移塌缩，**等价 v13 证书定价路径**；
- IRE 失效 ⇒ `R≡G、ε≡0、δ≡0、η≡0、γ≡0`，`CCX` 退化为恒真占位符、守卫只做逐位重复检查，**等价 v13 无解释路径**；
- EDA 失效 ⇒ `B_ep≡∞`、`D_ep≡0`，不设债务门，**等价 v13 无债务路径**；
- ASR 失效 ⇒ 直接调用 v13 的 RTCR 与 v13 间隙，**等价 v13 调度路径**；
- 四者全失效 ⇒ MetricVoiceGauge-NCD-HUTD v13，再沿 v13 退化链退回 v12/v11/v10/v9/v8/v7/v6；
- **安全继承**：SEC 只放大间隙、IRE 只增加必要证据条件、EDA 只增加债务门、ASR 只在 v13 档位中裁决。四端口互不相交，均不能新增授权或放宽阈值；`Exec_v14⊆Exec_v13` 由引理 128 保证。

## 4. 预期贡献

1. **偏移的证书化定价**：把"分布外"从检测器开关改写为带单侧置信的密度比上界与可计算的间隙膨胀，并给出偏移下共形覆盖的显式水平修正 `1−α/κ`；
2. **解释作为可执行证书**：把可解释性从显著图改写为最小充分理由集 + 认证扰动盒 + 运行时证伪守卫，使"解释失效"成为可检测、可阻断的事件；
3. **不变理由—偏移价格的分解**：证明当理由集跨环境不变时，OOD 价格可只按理由坐标计（`κ_R`）而非全局 `κ`，首次把解释从合规成本变成安全收益；
4. **认知债务预算**：用与迁移/蒸馏/时间并列且不可挪用的 `B_ep` 显式记账未知，给出"放行—审计—弃权—塌缩"四态裁决，并用 `Exec_v14⊆Exec_v13` 把审计与安全解耦；E647–E666 覆盖偏移覆盖、解释忠实/最小/稳定、不变性、债务动力学、端到端与消融。

## 5. 本轮最大风险

**一句话**：`κ`、理由集与债务账本都建立在我们**已经见到的部署流**上——当真正的新奇场景既让两样本检验低估密度比、又让"跨环境不变"的理由集恰好落在未覆盖的相关特征上时，系统会同时给出"已膨胀、有解释、债务未超"的三重自洽证据，执行一个**可审计、分布偏移自洽、却仍然绝对错误**的安全决定。

**定义 595（分布偏移信用证书 SEC）**
```
SEC = ( P_cal, P_t, S_cert, κ, α_w, α_s, β_w, T_w, method, stamp )
```
有效当且仅当：
1. **支撑**：`P_t(X∉S_cert) ≤ α_s`；
2. **包络**：以概率 `≥1−β_w`（对校准集与部署流联合）有 `sup_{x∈S_cert} w(x) ≤ κ`；
3. **平稳窗口**：在窗口 `T_w` 内两样本变点检验未触发；一旦触发令 `κ←∞`、SEC 失效，直到重校准签发新证书；
4. `κ≥1`；若 `κ=∞` 或条件 1 失败，SEC 视为无效，只允许第 0 档/`a_ask`。
SEC 是**证书**，不是告警标志：它必须携带 `stamp`（签发时刻、样本量、方法版本）以便审计与过期失效。

**定义 596（认证密度比包络 CDRE）** 用分类器两样本检验（C2ST）估计密度比：
```
ĥ(x) = P(label=1 | x),   ŵ(x) = ĥ(x)/(1−ĥ(x)) · (n_cal/n_t)
κ = min{ k : 以置信 1−β_w 有 sup_{x∈S_cert} w(x) ≤ k }
```
`κ` 取单侧置信上界（分块 conformal / PAC 界 / 经验 Bernstein 上界均可），**禁止使用点估计或均值**。非平稳时按块更新、块间用变点检验切断；块内样本不足时取 `κ=∞`，宁可弃权。

**定义 597（偏移膨胀间隙 SIG 与分解价格）**
```
SIG(U; α, κ) = Quantile_{1−α/κ}({V_i})          # κ≥1，有限样本修正取 ⌈(1−α/κ)(n+1)⌉ 阶
U^shift = SIG(U; α, κ_R) + η                     # κ_R 只在理由坐标 R 上估计
Δ_shift = U^shift − U ≥ 0
```
`V_i` 为 v13 的 DGC/TGC 非一致性分数。`R=G` 时 `κ_R=κ, η=0`，退化为全局膨胀；IRC 有效时 `κ_R≈1`，价格只剩 `η`；`κ_R=1,η=0` 时严格等于 v13。特别地，当 `U` 本身是 `(1−α)` 分位时，`SIG` 通过把水平收紧到 `1−α/κ` 换取偏移下的覆盖（引理 122）。

**定义 598（充分理由证书 SRC 与证书携带解释 CCX）** 设决策函数 `a(x)`、安全余量 `m(x,a)`、特征组 `G`、范数 `‖·‖_∞`。若
```
∀x' : x'_R = x_R ∧ ‖x'_{G\R} − x_{G\R}‖_∞ ≤ ε
    ⇒ a(x')=a ∧ m(x',a) ≥ m(x,a) − δ ,
```
则称 `R` 在 `x` 处对 `a` 是 `(ε,δ)`-**充分**的。解释对象为
```
CCX = ( a, R, m_R=m(x,a), ε, δ, {绑定证书 ID}, contrast, stab )
```
其中 `contrast={C_r}_{r∈R}` 是对每个理由组的最小反事实改动（使其翻转动作或跌破阈值），`stab` 是重采样下 `R` 仍充分的频率。`R` 取**包含极小**（不允许删去任一组后仍充分）；`ε→0` 时退化为"逐位重复即充分"的平凡解释。

**定义 599（不变理由证书 IRC）** 记 `x^{(R)}` 为把非理由组替换为环境无关参考值后的输入。要求存在已认证的界 `η,γ` 使对所有环境对 `e,e'∈E_set`：
```
(i)   |m(x,a) − m(x^{(R)},a)| ≤ η             # 非理由贡献有界（Lipschitz/区间界）
(ii)  |m_e(x^{(R)},a) − m_{e'}(x^{(R)},a)| ≤ γ  # 理由部分跨环境稳定
(iii) m(x^{(R)},a) ≥ θ + η + γ                  # 理由部分自身过阈值
```
则 `IRC=(R,η,γ,E_set,θ,stamp)` 有效。直觉：把决策拆成"不变理由的证据"与"可能随环境漂移的残差"，只要证据本身够硬、残差有界，环境变化就不能翻转决策（引理 125）。

**定义 600（解释的运行时证伪守卫）** 对已放行动作 `(a,CCX)` 定义认证盒
```
B_R(x) = { x' : x'_R = x_R ∧ ‖x'_{G\R} − x_{G\R}‖_∞ ≤ ε } .
```
若实时观测 `x_t∉B_R(x)`，或 `|m(x_t,a) − m(x^{(R)}_t,a)| > η`，则 `CCX` **失效**：动作必须在本控制帧内重新裁决；重决不能在帧内完成时执行 `P^xa` 中的认证回退。解释因此是"活的守卫"，不是一次性日志。

**定义 601（认知债务 EDA）** 定义新奇度与已解释覆盖
```
ν(x) = log κ(x) + λ_s·1[x∉S_cert] + λ_task·novelty_task(x)
ξ(x) = cover(R,x) + cover(S_cert,x)          # 理由覆盖的绑定证书比例 + 支撑覆盖
d(x) = max(0, ν(x) − ξ(x))
D_ep(t+1) = clip( γ_ep·D_ep(t) + d(x_t) − r_t , 0, ∞ )
```
`r_t≥0` 为主动采样、共形重校准或人工审计带来的偿还。硬预算 `D_ep≤B_ep`，且 `B_ep` 与 `B_transfer,B_distill,B_time,B_safe` **不可互相挪用**（定义 593 扩展）。

**定义 602（审计路由状态）**
```
ζ_xa = ( κ, U^shift, CCX, IRC, D_ep, mode, SEC, stamp )
mode ∈ { certified, audited, abstain, collapse }
```
`certified`：SEC/IRC/CCX 全部有效且 `D_ep≤B_ep`；`audited`：动作超出认证集但获得带范围与有效期的审计回执；`abstain`：无认证动作，只执行 `S_0`/`a_ask` 并给出弃权解释；`collapse`：`κ=∞`/支撑越界/变点触发，冻结学习证书并重校准。状态只能沿 `certified→audited→abstain→collapse` 单调向保守方向转移，恢复需新 `SEC` 与重校准。

**定义 603（审计模式与回执）** `audited` 模式的动作必须携带审计回执 `HAC=(动作范围, 有效期 T_h, 审计者, 依据, 剩余债务额度)`。`HAC` 是**有界许可证**：只在 `范围×T_h` 内有效，且每次使用都从 `B_ep` 扣减；不得把 `HAC` 当作永久放宽，也不得跨场景复用。

**定义 604（升级定义 592 的偏移—解释—债务感知选择）**
```
max_g   E[Progress(g)]
        − λ_risk · ( U^shift_gap(g) + U^shift_dis(g) )
        − λ_time · E[latency(g)] − λ_ask · E[false_reject(g)]
        − λ_x    · E[explain_cost(g)] − λ_ep · D_ep(g)
s.t.    v11/v12/v13 物理/接触/谐波/规范/gap/时限证书全部有效
        Σ_seg ( U^shift_gap + U^shift_dis ) ≤ B_total + B_shift
        W_p99(g) ≤ D ,  P^xa(g) ≠ ∅
        Acc_i(g) ⊆ Acc_T(g) ,  IRC(g) 有效 ,  CCX(g) 忠实
        D_ep(g) ≤ B_ep
```
任何一项超预算时，唯一允许的动作是沿阶梯更保守、进入 `audited`/`abstain`，或把信息价值高的组合转为**离线校准/审计采样**。

**定义 605（中立元表 v14 扩展）**

| 新组件 | v^⊥ | 等价退化点 |
|---|---|---|
| SEC | `κ≡1, α_s=0`，无膨胀，只剩 v13 支撑/漂移检查 | Level-4（v13 定价路径） |

| ASR | 直接调用 v13 RTCR / v13 间隙 | Level-1（v13 选档） |

**定义 606（审计执行策略与执行集）**
```
Exec_v14 = { a : a∈Acc_{i*(B)}(x)                    # v13 档位授权
                ∧ v11/v12/v13 证书全部有效
                ∧ SEC 在 x 处有效 (x∈S_cert, w(x)≤κ)
                ∧ CCX(a,R) 忠实且 R 包含极小

                ∧ P^xa ≠ ∅ } .
π_xa(x;B) = argmax_{a∈Exec_v14(x)} value(a) ,  空集则 abstain/collapse 。
```
要求对所有 `x,B` 有 `Exec_v14(x) ⊆ Exec_v13(x) ⊆ Exec_v12(x)`；解释与债务只是额外合取项，绝不替换任何 v13 阈值。

# IP-375 ShiftEnvelopeCertifier：偏移定价，宁可取 ∞
class ShiftEnvelopeCertifier:
    def __init__(self, support, alpha_w=0.1, alpha_s=0.05, beta_w=0.05,
                 window=2000, method="c2st_conformal"):
        self.support, self.alpha_w, self.alpha_s = support, alpha_w, alpha_s
        self.beta_w, self.window, self.method = beta_w, window, method
        self.kappa = 1.0
        self.stamp = None

    def fit(self, cal, stream):
        # 1) 支撑检查：部署流落在认证支撑外的比例
        if self._mass_outside(stream, self.support) > self.alpha_s:
            return self._issue(kappa=float("inf"))
        # 2) C2ST 密度比 + 单侧置信上界（禁止点估计）
        score = self._density_ratio(cal, stream)          # ŵ(x)
        kappa = self._ucb(score, beta=self.beta_w)        # 定义 596
        # 3) 变点检验：窗口内不平稳则拒绝签发
        if self._change_point(stream):
            return self._issue(kappa=float("inf"))
        return self._issue(kappa=max(1.0, kappa))

    def _issue(self, kappa):
        self.kappa = kappa
        self.stamp = (time.now(), len(cal), self.method)
        return SEC(kappa=kappa, alpha_w=self.alpha_w, alpha_s=self.alpha_s,
                   support=self.support, stamp=self.stamp)


# IP-376 InvariantReasonExplainer：解释是证明对象，不是代理模型
class InvariantReasonExplainer:
    def __init__(self, groups, theta, eps=0.02, delta=0.01, eta_max=0.05,
                 gamma_max=0.03, envs=()):
        self.G, self.theta = groups, theta
        self.eps, self.delta, self.eta_max, self.gamma_max = eps, delta, eta_max, gamma_max
        self.envs = envs

    def explain(self, model, margin, x, a):
        # 自后向前删除：充分性对 R 单调向上，故得到包含极小理由集
        R = list(self.G)
        for g in reversed(self.G):
            cand = [r for r in R if r != g]
            if self._sufficient(model, margin, x, a, cand):
                R = cand
        eta = self._residual_bound(model, margin, x, a, R)   # 定义 599(i)
        gamma = self._cross_env_gap(model, margin, x, R)     # 定义 599(ii)
        if margin(x, a) < self.theta + eta + gamma or eta > self.eta_max or gamma > self.gamma_max:
            return None                                      # 诚实失败：无可用 IRC
        return CCX(a=a, R=R, m_R=margin(x, a), eps=self.eps, delta=self.delta,
                   certs=self._binding(model, x, a, R),
                   contrast=[self._contrast(model, margin, x, a, g) for g in R],
                   stable=self._stability(model, margin, x, a, R))

    def _sufficient(self, model, margin, x, a, R):
        # 盒内采样/区间验证：x_R 固定，其余在 ε 内扰动
        for xp in self._box_samples(x, R, self.eps):
            if model.act(xp) != a or margin(xp, a) < margin(x, a) - self.delta:
                return False
        return True

    def guard(self, ccx, x_t, margin):
        # 定义 600：越盒或残差超界 ⇒ 解释失效 ⇒ 决策失效
        if not self._in_box(x_t, ccx):
            return False
        return abs(margin(x_t, ccx.a) - margin(self._ref(x_t, ccx.R), ccx.a)) <= self.eta_max


# IP-377 EpistemicDebtAccountant：不可挪用的债务账本
class EpistemicDebtAccountant:
    def __init__(self, budget=1.0, gamma=0.99, lam_s=0.5, lam_task=0.5):
        self.B_ep, self.gamma = budget, gamma
        self.lam_s, self.lam_task = lam_s, lam_task
        self.D_ep = 0.0

    def step(self, kappa, in_support, task_novelty, explain_cover, repayment=0.0):
        nu = log(kappa) + self.lam_s * (not in_support) + self.lam_task * task_novelty
        d = max(0.0, nu - explain_cover)
        self.D_ep = max(0.0, self.gamma * self.D_ep + d - repayment)
        return self.D_ep

    def can_execute(self):
        return self.D_ep <= self.B_ep

## 4. 推导

**引理 122（SEC–SIG 的偏移覆盖）** 设 `w(x)≤κ` 对所有 `x∈S_cert` 成立，且 `P_t(X∉S_cert)≤α_s`。对任意非一致性分数 `V`，取 `q=SIG(V;α,κ)=Q_{1−α/κ}(P_cal)`。则
```
P_t(V>q) ≤ κ·P_cal(V>q) + α_s ≤ κ·(α/κ) + α_s = α + α_s .
```
若 `κ` 仅为 `1−β_w` 置信上界，则联合取 `q=Q_{1−α/κ}` 得 `P_t(V>q) ≤ α+α_s+β_w`；把水平写成 `1−(α−α_s)/κ` 可吸掉 `α_s`。证明：对支撑内积分用 `dP_t=w·dP_cal≤κ·dP_cal`，支撑外用 `α_s`，再并上 `κ` 的置信事件。∎ 推论：**偏移下不需要重训模型，只需按 `κ` 收紧共形水平**；`κ=1` 时逐字回到 v13 引理 114。

**引理 123（偏移价格的单调性与解释收益）** `SIG(U;α,κ)` 关于 `κ` 单调不减，`SIG(U;α,1)=U`，故 `Δ_shift≥0`；`κ→∞` 时 `q→max V_i`（或 `∞`），证书收缩到空集，只能塌缩。若 IRC 有效且 `κ_R=1`，则 `U^shift=U+η`，相对全局膨胀 `SIG(U;α,κ)+0` 严格更便宜（当 `κ>1` 且 `η` 小于全局加价）。证明：次序统计量关于分位水平单调；`1−α/κ` 随 `κ` 增大而增大；IRC 的 `η` 界由定义 599(i) 给出且与全局 `κ` 无关。∎ 推论：**解释不是免费的合规项，而是能实际降低 OOD 证书价格的凭据**；这正是本轮把"可解释性"接进安全论证的接口。

**引理 124（CCX 的充分性、极小性与构造代价）** 若 `R` 在 `x` 处 `(ε,δ)`-充分且 `m(x,a)≥θ+δ`，则对认证盒内任意 `x'` 有 `a(x')=a ∧ m(x',a)≥θ`。若充分性对 `R` 单调向上（固定 `R` 的盒是固定更大集合的子集），则自后向前贪心删除返回**包含极小**理由集，最多调用 `|G|` 次充分性判定；若充分性判定只是 `ρ`-近似，则返回 `ρ`-近似极小。证明：充分性定义直接给出安全；贪心每次删去一个仍充分的组，终止时任一剩余组的删除都会破坏充分性，即包含极小。∎

**引理 125（不变理由 ⇒ 偏移下决策保持）** 设 `x'` 满足 `x'_R=x_R` 且 `‖x'_{G\R}−x_{G\R}‖_∞≤ε`，`IRC` 有效。若残差界 `|m(x',a)−m(x^{(R)},a)|≤η` 对 `x'` 成立，且跨环境 `|m_e(x^{(R)},a)−m_{e'}(x^{(R)},a)|≤γ`，则
```
m_{e'}(x',a) ≥ m_{e}(x^{(R)},a) − η ≥ (θ+η+γ) − η ≥ θ + γ > θ .
```
证明：三角不等式；定义 599(iii) 给出 `m_e(x^{(R)},a)≥θ+η+γ`。∎ 推论：**当偏移只移动非理由坐标、且理由集跨环境不变时，决策无需全局 `κ` 膨胀就能保持安全**；这把引理 122 的全局价格分解为"理由坐标几乎不涨价 + 非理由残差有界"。

**引理 126（解释证伪守卫的及时性）** 若守卫按控制帧检查定义 600 的两个条件，且 `CCX` 在 `x_0` 处有效，则任何使 `x_t∉B_R(x_0)` 或残差超界的动作在至多一帧内被判定失效；若该帧预算足够则重决，否则执行 `P^xa` 的认证回退。于是"带着已失效解释继续执行"的概率满足
```
P(陈旧不安全执行) ≤ P(监测漏检) + P(重决截止期错过) + P(P^xa=∅) .
```
证明：守卫是确定性谓词；帧内检查保证最迟下一帧发现；`P^xa` 非空时必有安全回退。∎

**引理 127（认知债务的守恒与不可挪用）** `D_ep` 非负；无偿还 (`r_t=0`) 且单步赤字 `d(x_t)>0` 时，`D_ep` 以 `γ_ep` 折扣累积并在有限步内超过任意有限 `B_ep`（若 `d` 有正下界）。在 `D_ep≤B_ep` 期间，长期未解释新奇率满足
```
E[d] ≤ (1−γ_ep)·B_ep + E[r] + o(1) .
```
且任何 `B_time/B_transfer/B_distill` 的增加都不改变该不等式——只有 `r_t`（主动采样/审计）能降低债务。证明：对更新式取期望并用平稳性；非挪用由定义 601 的预算独立性与 `clip` 直接得到。∎ 推论：**时间买不到认知**；赶截止期不能偿还"没解释过的新奇"。

**引理 128（v14 的安全继承）** 由定义 606，`Exec_v14 = Exec_v13 ∩ {SEC 有效} ∩ {CCX 忠实} ∩ {IRC 有效} ∩ {D_ep≤B_ep}`；又 `SIG(U;α,κ)≥U`。因此 `Exec_v14⊆Exec_v13⊆Exec_v12`，v13 引理 117 与 v12/v11 的全部安全继承继续成立。证明：逐项取交；`κ≥1` 时共形水平只会更严。∎

**引理 129（中立元退化等价 v13）** 注入定义 605 的四中立元：`SEC(κ=1,α_s=0)` 使 `SIG=U`；`IRE(R=G,ε=δ=η=γ=0)` 使 `IRC` 恒真、`CCX` 平凡、守卫退化为逐位重复；`EDA(B_ep=∞)` 使债务门失效；`ASR` 直调 `RTCR`。逐式代入定义 595–606，所有集合与阈值点wise 等于定义 583–594，主闭环调用序列与 v13 逐位一致，再沿 v13 链退回 v12/v11/…/v6。证明：逐端口代入并核对边界条件；四端口互不相交，中立元不改变任何 v13 证书检查。∎

**引理 130（偏移—蒸馏—解释的联合界与三难）** 记 `E_exp` 为解释不忠实造成的决策偏差。则
```
J_real(S) − J* ≤ U^shift_gap + U^shift_dis + I_cross + δ_approx + D_ep + E_exp
```
以概率 `≥1−α_gap−α_dis−α_w−α_s−β_w` 成立。证明：v13 引理 121 给出 `J_real(S)−J_sim(T)≤U_gap+U_dis`；引理 122 把它升级为偏移版本；`D_ep` 由定义 601 记账未解释部分；`E_exp` 叠加解释近似误差；联合用并集界。∎ 进一步的**解释—鲁棒—效用三难**：存在决策族，使任何同时满足 (i) `|R|≤k`、(ii) 对任意 `ε`-偏移保持决策、(iii) 无效用损失 的理由集都不存在——构造上让唯一充分理由依赖一个非不变特征，而任何不变理由集必须包含 `Ω(d)` 个组。推论：**"小解释 + 强鲁棒 + 零代价"不可能同时成立**；必须用 `η`、`|R|`、或活动性显式交换，这正是 `B_ep` 存在的理由。

## 8. 已知风险与失效模式

1. **κ 的自我指涉**：SEC 用部署流估计部署分布，若流本身被对手或非平稳性污染，`κ` 会被系统性低估；"膨胀后的证书"仍是建立在错误价格上的证书。缓解：块状在线共形 + 变点切断、PAC 上界、独立影子流、`κ=∞` 的保守默认、限制宣称支撑。
2. **高维密度比不可估**：C2ST 在低样本/高维下过拟合，`ĥ` 接近 0/1 使 `ŵ` 方差爆炸。缓解：降维/条件化、分类器正则、分块局部密度比、必要时退化为支撑检查与全局塌缩。
3. **解释不忠实（真但无用）**：`R` 可能只是"恰好充分"的无关特征集合，跨环境立刻失效；或解释由代理模型生成而与真实决策路径脱节。缓解：强制同路径导出、证书链绑定、IRC 跨环境校验、对抗重采样、把解释失败显式暴露给审计者。
4. **不变特征不存在**：某些任务在给定环境集下确实没有跨环境不变的理由，IRC 永远失败，系统退化为频繁弃权。缓解：扩充环境集/数据增强、允许"条件不变"（按环境类型分层）、把活动性损失计入预算、必要时人工审计。
5. **解释计算拖垮实时性**：盒内采样/最小性搜索成本可能超帧预算。缓解：离线预计算理由候选、在线只做 O(|R|) 守卫、解释生成降到 1–5Hz、按需触发、缓存。
6. **债务预算被误设或游戏化**：`B_ep` 过大等于没有债务门，过小则长期弃权；`ξ` 的覆盖度量可能被"便宜证书"刷高。缓解：预注册 `B_ep`、独立审计账本、覆盖度量绑定真实校准证据、禁止用解释数量替代解释质量。
7. **审计者自动化偏见**：人类看到"有 CCX、有 SEC"就倾向批准，`HAC` 可能变成橡皮图章。缓解：呈现对照解释与失败案例、随机盲审、限制 `HAC` 范围与有效期、对批准后的结果做反事实复盘。
8. **偏移与蒸馏间隙联合低估**：新场景同时落入 v13 校准外与 v14 流外，`U_gap^shift` 与 `U_dis^shift` 可能同时被低估。缓解：联合三角界（引理 130）、`B_shift/B_ep` 独立预算、双流变点检测、任一失效即 `a_ask`/最低档。

## 9. 本轮最大风险

**一句话**：`κ`、理由集与债务账本都建立在我们**已经见到的部署流**上——当真正的新奇场景既让两样本检验低估密度比、又让"跨环境不变"的理由集恰好落在未覆盖的相关特征上时，系统会同时给出"已膨胀、有解释、债务未超"的三重自洽证据，执行一个**可审计、分布偏移自洽、却仍然绝对错误**的安全决定。
