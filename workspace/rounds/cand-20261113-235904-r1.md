# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「评测指标」×「持续学习」）

> R69 把不确定性拆成 aleatoric / epistemic，用「看—问—触」去消解可约的歧义，并诚实地交出最大风险：**整条效率收益押在「流模型的模态分布可信」这一前提上**。它给的防线是 ECE 校准门（MCG）。但这里漏了一层——**ECE 本身是一个测出来的数**：它来自有限评测集、有采样误差、会随世界漂移而过期，更糟的是，一旦开始持续学习，评测集会被「学进去」。R69 一直在问「我的测量还准吗」「我该向谁求证」，却从没问：**我用来判断「我准不准」的那个分数，凭什么可信？**
>
> 本轮两个灵感正好接上这个递归：
> - **评测指标**不是真理，是**仪器**——必须带置信序列、最小可检测效应、数据户籍/泄漏诊断、保质期与隐藏审计；
> - **持续学习**是抗漂移的唯一出路，但必须被**隔离**——学习进影子通道，提交是一个离散、任意时刻有效、可回滚、安全阈值写保护的**承诺事件**。
>
> 核心命题：**把「学习」与「承诺」彻底分离。学习可以在环外持续发生；但任何对部署行为的改变，都必须通过一道以「外生评测 + 任意时刻有效证据 + 反古德哈特审计 + 安全写保护」为合取条件的晋升门；拿不到可信评测时，正确动作不是「测一下再说」，而是「不承诺」。** 命名 **GAUGE-RAS**（Gauged Anytime-valid Uncertainty-aware Governance of Evaluation：评测计量的持续标定与反古德哈德闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我凭什么相信我的成绩单——而且这张成绩单有没有被我偷偷改过**」。

## 0. 直觉与动机

**灵感 1（评测指标 → 指标是仪器，不是判决书）**
直觉：工程师看万用表，不会只看指针指到 5.0，还会问量程、精度、校准日期。但机器学习里的「成功率 87%」「ECE 0.04」常被当成判决书：一个点估计、一次评测、一个阈值，然后据此决定部署。评测指标至少有五种病：**采样误差**（n 不够）、**欠功效**（真实差异小于最小可检测效应）、**数据泄漏/自适应过拟合**（反复在同一个评测集上调，等于把它变成训练集）、**分布漂移**（昨天的校准今天过期）、**古德哈德**（指标一旦用于决策，就被优化目标本身污染）。所以本轮要把指标升级为一个**带置信集的随机变量 + 一份来源与功效的证书**，而不是一个裸数。**「不显著」不等于「无差异」；在欠功效时，「通过」多半是运气或偏倚，不是证据。**

**灵感 2（持续学习 → 学习必须被隔离，承诺必须被认证）**
直觉：世界在漂，静态模型必然过期，所以必须持续学习。但 R68 的铁律是「实时流零学习写操作」——这不是保守，而是安全：在线改权重等于在飞行中换引擎。正确解法不是「学还是不学」，而是**把学习挪到环外（影子学习器），把「提交」变成一个独立的、低频、可审计、可回滚的事件**。于是持续学习从「每步偷偷更新」变成「候选模型持续产生 + 承诺门偶尔放行」。遗忘、漂移、回滚，全部变成承诺门上的显式条件，而不是隐性风险。安全性上，**学习器永远不能下调自己的安全底线**：λ_floor、安全包络、证据纪律 k、各阈值进只读签名注册表，学习器只能提议 diff，提交需人签或形式化验证。

**灵感 3（R69 的主动交互污染了它自己的考场）**
直觉：这是本轮最关键的桥。R69 让系统「看、问、触」来消歧，但信息动作**改变了它之后采到的数据分布**——它问的问题、看的方向决定了它见到什么。于是用「系统自己采的数据」评「系统自己」就是选择偏倚下的自证：它可能因为只问某类问题而永远看不到反例。要评一个会改变数据分布的候选策略，必须用**反事实 / off-policy 评测**（IPS/DR）加**支持集诊断**（ESS、最大重要性权重）；当候选策略问了日志策略从未问过的问题（无重叠），评测在统计上**不可认证**，晋升必须阻断。**评测的第一步不是算分，是问「我有没有资格算这个分」。**

**灵感 4（对称性 → VoI 问世界，VoE 问自己）**
直觉：R69 的 MINT 用 value-of-information 决定「该向世界问什么」。本轮提出它的镜像 **VoE（value-of-evaluation）**：该对自己测什么——多采多少样本、要不要开隐藏集、要不要做一次长跑、要不要花钱请人标注。评测不是免费的，它消耗数据、标注、时间与「隐藏集查询次数」。当所有评测的 VoE 都低于成本时，正确的动作是**不承诺**（保持当前保守策略），而不是「随便测一下让流程看起来完整」。这把 R69 的「问错比不问更危险」推进为「**乱测比不测更危险**」。

**灵感 5（递归 → 谁来评测评测者）**
直觉：如果「评测评测者」也靠学习模型，就无限回归。本轮的截断方式是三条硬约束，而不是再学一个元模型：(a) **外生性**——审计数据不得由候选自身动作生成；(b) **隐藏性**——学习器不可见的审计指标，信息屏障本身就是防线；(c) **写保护**——安全阈值与人签锚点不能被任何学习过程触碰。诚实地讲，这条递归只能被「截断」而不能被「解决」，截断点的可靠性就是本轮的最大风险。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（GAUGE-RAS 总览）** GAUGE-RAS = (MVM, EVC, SLL, AGS, GOP, GDA, RAS-WM‡)。五不变式：
(i) **实时流零学习写**（继承 R68 定义 276-i、R69 定义 293-i）；
(ii) **学习-承诺分离**：学习只发生在影子通道（SLL）；部署权重的改变是一个离散、可审计、可回滚的**承诺事件**，不是每步写操作；
(iii) **评测外生性**：用于晋升的指标数据不得由候选策略自身闭环动作生成，除非经 off-policy 校正且支持集诊断通过（GOP）；
(iv) **任意时刻有效**：晋升判定用 e-process / 置信序列，允许持续偷看而不膨胀假晋升率（EVC）；
(v) **安全写保护**：安全包络、λ_floor、证据纪律 k、阈值 τ_* 存放于只读签名注册表，学习器只能提议不能提交（SWP）。

**定义 311（评测对象与指标随机变量）** 一次评测 E = (𝒟_eval, M, ĝ, U_eval)：M 为（可为向量的）指标函数，ĝ 为估计量，U_eval 为评测不确定性。**关键姿态：指标值不是数，而是带置信集的随机变量**。记 m̂ 为点估计，CS_δ 为 1−δ 置信区间/置信序列。

**定义 312（指标证书 MetricCert）** MetricCert(M) = (m̂, CS_δ, coverage, power, mde, provenance_hash, leakage_score, eval_n, gauge_ver)。称 M 在决策裕度 Δ_dec 上**可判（decision-worthy）** 当且仅当 CS_δ 半径 < Δ_dec（等价于 MDE ≤ Δ_dec 且标称覆盖成立）。不可判时，任何「无显著差异」都不构成「无差异」，也不构成「可晋升」。

**定义 313（最小可检测效应与欠功效）** 配对比较的 MDE(n, σ, α, β) = (z_{1−α} + z_{1−β})·σ/√n。若真实 |Δ| < MDE，则检验**功效不足**，结论必须记为「未知（Underpowered）」：既不得晋升，也不得否决。不确定性在这里的正确处置是「继续测或不承诺」，而非「默认通过」。

**定义 314（任意时刻有效证据 EVC）** 对持续到达的对照数据流 {X_t}，构造 e-process E_t（非负鞅，H0 下对任意停时 τ 有 E[E_τ] ≤ 1）。当 E_t ≥ 1/α 时拒绝 H0（候选优于基线）；否则继续监控。安全非劣用对偶的单侧 e-process。与重复 p 值检验不同，**任意停时 / 连续偷看不膨胀第一类错误**（引理 19）。

**定义 315（影子学习器 SLL 与训练写防火墙）** 影子学习器在实时环外的独立进程/显存中训练，输入回放缓冲 ℬ 与新增日志，输出候选权重 θ'。θ' 与部署权重 θ_deploy 物理隔离；实时环只读 θ_deploy。训练写操作对实时环**不可见、不可阻塞**（定义 310-i）。

**定义 316（锚定回放与遗忘上界）** 锚集 𝒜 = 安全关键状态 ∪ 稀有模态 ∪ 历史故障回放，由只读注册表维护，学习器不可编辑。遗忘度 F(θ', θ) = max_{a∈𝒜} [ℓ_{θ'}(a) − ℓ_θ(a)]_+；晋升要求 F 的置信上界 ≤ ε_forget。

**定义 317（任意时刻晋升门 AGS）** 晋升是合取门，全部通过才提交：
(a) 安全非劣（单侧 e-process，水平 α_s）；
(b) 目标任务改进（e-process ≥ 1/α_t）；
(c) 模态校准不退化（R69 MCG 的 ECE 置信上界 ≤ τ_ece）；
(d) 遗忘上界 F ≤ ε_forget；
(e) 指标可判且无泄漏（ MetricCert 可判、leakage_score ≤ θ_leak）；
(f) 支持集通过（GOP 的 ESS ≥ n_min、w_max ≤ w_cap）。
子检验以 e-value 合并或 Bonferroni 控总 α；**禁止「哪项好看就只看哪项」**。

**定义 318（反古德哈特审计 GDA）** 维护学习器**不可见**的隐藏审计指标 M_audit，在**外生数据**（非候选自身动作生成）上计算；代理指标与审计指标的**古德哈特间隙** G_t = M_proxy(π_t) − M_audit(π_t)。若 M_proxy 上升而 G_t 越界（或滑动窗内显著上升），触发冻结晋升。另设指标实现集合的分歧度 D = dispersion{M^(1..m)}：分歧高说明指标未定义清楚或正被利用。

**定义 319（评测数据户籍与泄漏守卫 PLG）** 评测集户籍哈希与轮换：公开集 𝒟_pub 承担学习可见的常规评测；隐藏集 𝒟_hid 仅按聚合、限次开放，每次访问入审计日志（防止反复查询变成自适应过拟合）。泄漏分 δ_leak 由成员推断 / 近邻重复检测估计；δ_leak > θ_leak ⇒ MetricCert 作废。

**定义 320（评价漂移与「计量的计量」 EBM）** 指标本身依赖分布：输入漂移、标注口径变化或协变量偏移权重 w(x)=p_new/p_old 越界时，旧 ECE / 旧分数失效。EBM 在滑动窗上重估 U_eval 并用密度比诊断评测分布漂移。**评测证书也有保质期**，过期即降级到保守策略。

**定义 321（反事实 / off-policy 评测 GOP）** R69 的主动交互改变数据分布（选择偏倚），故候选 π_new 不能用「它自己采的数据」评。以行为策略 π_old 的倾向 b(a|o) 与日志做 IPS/DR：V̂_DR = (1/n)Σ_i [w_i r_i + (1−w_i)·V̂(o_i)]，w_i = π_new(a_i|o_i)/b(a_i|o_i)。支持诊断：ESS = (Σw)²/Σw²，w_max。若 ESS < n_min 或 w_max > w_cap ⇒ **无支持 ⇒ 不可认证 ⇒ 晋升阻断**。**会提问的系统污染了自己的考场**——这是 R69 主动交互的直接后果。

**定义 322（回滚证书 RBR）** 每次晋升登记 (checkpoint_hash, 触发条件, 影子-部署分歧监视器, 回滚预算)。部署指标触及触发条件即**自动回滚**；回滚是降级，**不需要** e-value 证据（安全方向单侧、即时），且回滚后**不重置**全局 e-process（定义 326）。

**定义 323（安全写保护 SWP）** 安全包络、λ_floor、证据纪律 k、τ_ece/τ_fma/τ_epi 等存放于**签名只读注册表**。学习器只能提出 diff；提交需离线签名（人）或形式化验证通过。**学习器不得下调自己的安全底线。** 这是对「递归评测」的硬截断。

**定义 324（VoE：评测预算分配器）** 与 R69 的 VoI 对偶：VoI 问「该向世界问什么」，VoE 问「该对自己测什么」。评测动作 e（加采样、加标注、开隐藏集、长跑）成本 c_e，价值为减少错误承诺的期望损失：VoE(e) = E[loss(decide | prior) − loss(decide | E_e)]。选 argmax_e [VoE(e) − c_e] s.t. 评测预算 B_eval。**当所有评测都不划算时，正确动作是「不承诺」，而不是「随便测一下」。**

**定义 325（证书 J_GAUGE）** J_GAUGE = (J_FLUID, metric_cert_hash, e_value, mde, ess, leakage, forgetting, goodhart_gap, eval_epoch, rollback_hash, gauge_ver)。Valid ⇔ Valid(J_FLUID) ∧ 指标可判 ∧ 无泄漏 ∧ 有支持 ∧ 遗忘达标 ∧ 审计间隙未越界 ∧ 安全注册表未变。

**定义 326（晋升代数与全局误差预算）** 整个部署生命周期共享**一个**全局 e-process / α 预算；晋升、回滚、再晋升**不得重置计数器**。否则多次机会会累积假晋升（引理 19 系）。多次晋升的正确语义是「沿时间连续的一条证据轨迹」，不是「每轮重新开考」。

## 2. 关键算法骨架

```python
# IP-264 MVM：指标证书（点估计 + 任意时刻置信序列 + 可判性）
def metric_cert(data, metric, delta_dec, alpha=0.05, beta=0.2):
    m_hat = metric.estimate(data)
    cs    = metric.confidence_sequence(data, alpha)        # anytime-valid
    mde   = minimum_detectable_effect(len(data), metric.sigma, alpha, beta)
    return MetricCert(
        m_hat, cs, mde=mde,
        decision_worthy=(cs.radius < delta_dec) and (mde <= delta_dec),
        provenance_hash=hash_dataset(data),
        leakage_score=leakage_probe(data),
        coverage=metric.empirical_coverage(data))

# IP-265 EVC：任意时刻有效证据（不因回滚/再晋升而重置）
class EProcess:
    def __init__(self, alpha):
        self.logE, self.alpha = 0.0, alpha
    def update(self, paired_advantage):                    # 新对照样本到达
        self.logE += e_increment(paired_advantage)         # H0 下为超鞅
        return math.exp(self.logE) >= 1.0 / self.alpha

# IP-268 GOP：off-policy 支持诊断（R69 主动交互会污染考场）
def ope_support(logs, pi_new, pi_old, n_min, w_cap):
    w = [pi_new(a, o) / max(pi_old(a, o), 1e-9) for (o, a, r) in logs]
    ess = (sum(w) ** 2) / sum(wi * wi for wi in w)
    if ess < n_min or max(w) > w_cap:
        return None, {'ess': ess, 'reason': 'no_support'}  # 不可认证
    return dr_estimate(logs, w), {'ess': ess}

# IP-269 GDA：反古德哈特（隐藏审计 + 指标集合分歧）
def goodhart_alarm(pi, proxy, audit_hidden, alpha_g):
    gap   = proxy.score(pi) - audit_hidden.score(pi)       # 必须外生数据
    alarm = gap > gap_bound(alpha_g) or \
            dispersion(metric_ensemble(pi)) > D_MAX
    return alarm, gap

# IP-267 AGS：任意时刻晋升门（合取；不能只看好看的项）
def promotion_gate(cand, base, ev):
    return (non_inferior_safety(cand, base, ev.e_safety)   # (a)
            and target_better(cand, base, ev.e_target)      # (b)
            and ece_upper(cand) <= TAU_ECE                  # (c)
            and forgetting(cand, base) <= EPS_FORGET        # (d)
            and ev.metric_cert.decision_worthy              # (e)
            and ev.metric_cert.leakage_score <= THETA_LEAK
            and ev.ope is not None and ev.ope['ess'] >= N_MIN)  # (f)

# IP-276 GAUGE 主闭环（R69 之上，仅在「承诺」处插入计量层）
def GAUGE_round(M, obs):
    out = M.fluid.round(obs)                    # 实时路径与 R69 逐指令相同
    M.mvm.observe_proxy(out)                    # 只读监视，异步
    M.ebm.observe_drift(obs)                    # 评测漂移，异步
    return out                                  # 实时环绝不写学习状态

def GAUGE_promotion_tick(M):                    # 低频（分钟/小时级）
    cand = M.sll.propose()                      # 影子权重，实时环无感
    ev   = M.collect_evidence(cand)             # 外生 / off-policy / 隐藏审计
    if not M.ags.pass_all(cand, ev):  return 'keep'
    if M.gda.alarm(cand, ev):         return 'freeze'      # 古德哈特告警
    if M.swp.diff_touches_safety(cand): return 'escalate'  # 只能人签
    M.deploy.commit(cand, rollback=M.rbr.register(cand))
    return 'promoted'

def GAUGE_watchdog(M):                          # 每个控制周期
    if M.rbr.trigger_fired() or M.gda.gap_over():
        M.deploy.rollback()                     # 降级即时，不需 e-value
    # 全局 e-process 不重置（定义 326）
```

## 3. 推导

**引理 19（任意时刻有效性 / 可选停止）** 若对同一假设做 m 次独立 α 检验并「看到显著就停」，假晋升率升至 1−(1−α)^m；而 e-process 在 H0 下满足 P(sup_t E_t ≥ 1/α) ≤ α，对任意停时成立。故持续监控下晋升判定必须用 e-process/置信序列。**系**：每次晋升后若重置计数，m 次机会的累积假晋升仍会逼近 1−(1−α)^m；因此定义 326 要求全局共享单一误差预算。

**引理 20（欠功效下的「通过」无信息性）** 若 MDE > Δ_dec，则真实差异 |Δ| < Δ_dec 时检验功效 ≤ 1−β；此时「未拒绝」既不能证明无差异，也无法区分「真无差」与「样本不够」。更关键：**低功效下观察到「显著改进」更多由选择偏倚与偷看驱动**，其证据量远低于名义水平。故定义 313 把欠功效结论强制标为「未知」，禁止据其承诺。

**引理 21（古德哈特间隙是信息屏障的函数，而非指标选择的函数）** 设策略类 Π，代理指标 M_p、审计指标 M_a，间隙上确界 G* = max_{π∈Π}[M_p(π) − M_a(π)]。若 M_a 可见并参与训练，学习器可在同时抬高两者的方向上做多目标优化，把 G 压到 0（指标被「打通」）；若 M_a 隐藏且外生，学习器无法定向降低 G，则当策略滑向 M_p↑ / M_a↓ 区域时 G 单调上升、可被 e-process 检出。**结论：反古德哈德靠的是信息屏障与外生性，不是换一个更聪明的指标。**

**引理 22（OPE 支持崩溃）** 若候选策略在状态 o 上以正概率选择行为策略支撑外的动作（R69 的「问一个新问题」正是如此：π_old(a|o)=0），则重要性权重 w=π_new/π_old 无界，IPS 方差无界、DR 估计有偏。支持度可用 ESS ≈ n·(有效重叠) 度量；ESS < n_min 意味着评测数据不足以认证该候选。故**主动交互越激进，越需要显式声明「此处不可认证」**。

**定理 18（安全持续学习 / 无回归）** 在 A99–A103 下，沿部署生命周期，期望安全指标不下降、安全违规率以概率 ≥ 1−α 不超过晋升前基线：因为 (i) 晋升要求安全非劣的任意时刻有效证据；(ii) 安全阈值与人签锚点写保护、学习器不可下调；(iii) 回滚是安全方向的即时单侧动作；(iv) 全局 e-process 不重置。**安全侧不对持续学习做任何让步。**

**定理 19（GAUGE 严格包含 FLUID-RAS / R69）** 当晋升被禁用（e-process 永不越过阈值）、或隐藏审计/外生数据不可得、或 SWP 拒绝一切 diff 时，GAUGE-RAS 与 R69 的 FLUID-RAS **逐指令相同**。效率收益只能来自被认证的晋升；R69 是 GAUGE 在「永不承诺」边界上的退化。**新层不引入需要独立信任的常开黑箱。**

**定理 20（古德哈特的可检测性与检测延迟）** 在隐藏、外生审计与指标集合分歧下，若策略持续滑向 G > G* 的区域且代理指标保持上升 T 个晋升周期，则 GDA 在期望延迟 ≤ T_detect(α) 内触发冻结的概率 ≥ 1−α；延迟由 e-process 的成长率与间隙幅度决定。**系**：审计不可见是硬前提——一旦泄漏，引理 21 的 G* 可被压到 0，检测器失效。

## 6. 本轮最大风险

**一句话**：GAUGE-RAS 的全部合法性押在「评测数据是外生的、审计集是隐藏的」这一前提上——**一旦持续学习间接看见了自己的考场（评测集泄漏、主动交互改变了被评测的分布、标注者与系统共谋），晋升门就会给一个「自我实现的分数」盖上认证章**：系统越来越擅长通过考试，而不是越来越擅长做事；而当「谁来评测评测者」只能靠再学一个元评测时，递归只是被往上推了一层——**真正的锚点只有一个：不能被任何学习过程触碰的外生、人签、写保护的安全与审计基线；它若失守，整套认证就只是在为漂移背书。**

**次级风险与缓解**：
1. **隐藏审计集泄漏 / 反复查询**（自适应过拟合）→ 限次开放 + 访问审计 + 泄漏分作废证书 + E306/E314；
2. **OPE 无支持却硬评**（新问句超出日志支撑）→ ESS/w_max 硬门 + 阻断晋升 + E307；
3. **欠功效被当成「无差异」** → MDE 显式门槛 + 强制「未知」标签 + E302；
4. **古德哈特间隙迟滞** → 隐藏 + 外生 + 指标集合分歧 + Theorem 20 的检测延迟界 + E305；
5. **评测漂移使证书过期** → EBM 滑动窗重估 + 证书保质期 + 过期即保守 + E310；
6. **学习器绕过写保护下调安全底线** → SWP 签名注册表 + 人签 diff + E309。

# 第 70 轮产物 · 创新点清单 v1：GAUGE-RAS（Gauged Anytime-valid Uncertainty-aware Governance of Evaluation：评测计量的持续标定与反古德哈德闭环；MVM×EVC×SLL×AGS×GOP×GDA×RAS-WM‡）

```python
# IP-264 MVM：指标证书（点估计 + 任意时刻置信序列 + 可判性）
def metric_cert(data, metric, delta_dec, alpha=0.05, beta=0.2):
    cs  = metric.confidence_sequence(data, alpha)          # anytime-valid
    mde = minimum_detectable_effect(len(data), metric.sigma, alpha, beta)
    return MetricCert(metric.estimate(data), cs, mde=mde,
                      decision_worthy=(cs.radius < delta_dec) and (mde <= delta_dec),
                      provenance_hash=hash_dataset(data),
                      leakage_score=leakage_probe(data))

# IP-265 EVC：任意时刻有效证据（回滚/再晋升均不重置）
class EProcess:
    def __init__(self, alpha): self.logE, self.alpha = 0.0, alpha
    def update(self, paired_advantage):
        self.logE += e_increment(paired_advantage)         # H0 下超鞅
        return math.exp(self.logE) >= 1.0 / self.alpha

# IP-268 GOP：off-policy 支持诊断（R69 主动交互污染考场）
def ope_support(logs, pi_new, pi_old, n_min, w_cap):
    w = [pi_new(a, o)/max(pi_old(a, o), 1e-9) for (o, a, r) in logs]
    ess = (sum(w)**2) / sum(wi*wi for wi in w)
    return (dr_estimate(logs, w), {'ess': ess}) if ess >= n_min and max(w) <= w_cap \
           else (None, {'ess': ess, 'reason': 'no_support'})

# IP-269 GDA：反古德哈特（隐藏审计 + 指标集合分歧）
def goodhart_alarm(pi, proxy, audit_hidden, alpha_g):
    gap = proxy.score(pi) - audit_hidden.score(pi)
    return (gap > gap_bound(alpha_g) or
            dispersion(metric_ensemble(pi)) > D_MAX), gap

# IP-267 AGS：任意时刻晋升门（合取）
def promotion_gate(cand, base, ev):
    return (non_inferior_safety(cand, base, ev.e_safety)
            and target_better(cand, base, ev.e_target)
            and ece_upper(cand) <= TAU_ECE
            and forgetting(cand, base) <= EPS_FORGET
            and ev.metric_cert.decision_worthy
            and ev.metric_cert.leakage_score <= THETA_LEAK
            and ev.ope is not None and ev.ope['ess'] >= N_MIN)

# IP-276 GAUGE 主闭环（R69 之上，仅在「承诺」处插入计量层）
def GAUGE_round(M, obs):

    M.mvm.observe_proxy(out); M.ebm.observe_drift(obs)   # 只读、异步
    return out                            # 实时环绝不写学习状态

def GAUGE_promotion_tick(M):              # 低频
    cand = M.sll.propose(); ev = M.collect_evidence(cand)

    if M.swp.diff_touches_safety(cand): return 'escalate'  # 只能人签

    # 全局 e-process 不重置（定义 326）
```

## 4. 推导

**引理 19（任意时刻有效性 / 可选停止）** 重复 α 检验「见显著就停」，m 次假晋升升至 `1−(1−α)^m`；e-process 在 H0 下 `P(sup_t E_t ≥ 1/α) ≤ α`，对任意停时成立。系：晋升/回滚/再晋升不得重置计数（定义 326）。

**引理 20（欠功效的「通过」无信息性）** `MDE>Δ_dec` 时功效不足；「未拒绝」既不证明无差异，也无法区分「真无差」与「样本不够」。低功效下观察到的「显著改进」多由选择偏倚与偷看驱动，证据量远低于名义水平。

**引理 21（古德哈特间隙是信息屏障的函数）** 设虚伪间隙上确界 `G*=max_π[M_p−M_a]`。审计可见并参与训练 ⇒ 学习器可多目标挤压 G→0（指标被打通）；审计隐藏且外生 ⇒ 学习器无法定向降低 G，滑向 `M_p↑/M_a↓` 时 G 单调上升、可被检验。**反古德哈德靠信息屏障，不靠换指标。**

**引理 22（OPE 支持崩溃）** 候选在 `π_old` 支撑外动作（如问一个日志里从未出现的问题）⇒ `w=π_new/π_old` 无界，IPS 方差无界、DR 有偏；`ess<n_min` 表示数据不足以认证。**主动交互越激进，越要显式声明「此处不可认证」。**

**定理 18（安全持续学习 / 无回归）** A99–A103 下，期望安全指标不降、违规率以概率 ≥1−α 不超过晋升前基线：安全非劣用任意时刻有效证据、安全阈值人签写保护、回滚是即时安全单侧动作、全局 e-process 不重置。**安全侧不对持续学习让步。**

**定理 19（GAUGE 严格包含 FLUID-RAS / R69）** 晋升禁用、或隐藏审计/外生数据不可得、或 SWP 拒绝一切 diff 时，GAUGE 与 R69 **逐指令相同**。效率收益仅来自被认证晋升；R69 = 「永不承诺」边界。

**定理 20（古德哈特可检测性与延迟）** 隐藏外生审计 + 指标集合分歧下，若策略持续滑向 `G>G*` 且代理指标上升 T 个周期，GDA 在期望延迟 `≤T_detect(α)` 内冻结的概率 ≥1−α。系：审计一旦泄漏，`G*` 可被压到 0，检测器失效——**隐藏性是硬前提**。

## 7. 本轮最大风险

**一句话**：GAUGE-RAS 的全部合法性押在「评测数据外生、审计集隐藏」这一前提上——**一旦持续学习间接看见自己的考场（评测集泄漏、主动交互改变被评测分布、标注者与系统共谋），晋升门就会给一个「自我实现的分数」盖上认证章**：系统越来越擅长通过考试，而不是越来越擅长做事；而「谁来评测评测者」若只能靠再学一个元评测，只是把递归往上推一层——**唯一的真锚点是不能被任何学习过程触碰的外生、人签、写保护的安全与审计基线；它失守，整套认证就只是在为漂移背书。**

**次级风险与缓解**：隐藏审计泄漏（限次 + 访问审计 + 泄漏分 + E306/E314）；OPE 无支持硬评（ESS/w_max 硬门 + E307）；欠功效被当「无差异」（MDE 门槛 + 强制「未知」+ E302）；古德哈特迟滞（隐藏 + 外生 + 指标分歧 + 定理 20 + E305）；评测漂移过期（EBM + 保质期 + E310）；学习器绕过写保护（SWP 签名表 + 人签 + E309）。
