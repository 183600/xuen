# 第 47 轮（承接第 46 轮 v23；本轮灵感：UniBot × 机械臂） · Embodied-Arm-Cert：关节空间证书、执行器热-能量租约与机械臂主动感知（五层架构 v11）

> 承接第 46 轮 v23 Memory-Safety-Voice。v9/v10/v23 把姿态证书、能量租约、记忆与语音安全逐步补齐，但隐含假设 H5：**机械臂只是姿态证书的下游执行器，其本体不确定性、动力学、热约束与运动不反过来影响证书本身**。UniBot 实机中机械臂既是执行器又是传感器载体（eye-in-hand），关节编码器误差、连杆偏置、间隙、负载、自碰撞、关节热漂移都会改变末端位姿；同时机械臂运动可主动改变观测视角，使"感知"与"操作"共享同一份能量与安全预算。两个灵感词精确命中 H5：**UniBot** 给出整机本体（底盘-躯干-双臂-云台）的异构本体与跨机一致性；**机械臂** 给出关节空间可操作度、碰撞、接触、负载与热约束。新问题因此变为：**当机械臂既是被认证对象又是证书的观测来源时，如何联合保证关节空间安全、执行器热-能量租约与感知姿态证书，且在本体漂移、负载突变、热降频时不发生证书静默失效**。

## 0. 直觉与动机

**灵感 1（UniBot → 整机本体与跨机护照）**
直觉：同一型号的 UniBot 也不是同一台机器。连杆加工误差、装配偏置、减速器背隙、轮系打滑、相机外参都因机而异，且随磨损漂移。把整机参数记为"本体护照" θ_e=（连杆长度、零位偏置、背隙、关节刚度、摩擦、内外参），证书必须按 θ_e 参数化；换机或漂移后，用少量目标机标定样本重新共形校准，而不是默认复用源机半径。跨机一致性因此是一个可审计的统计迁移问题，而不是"同型号即同分布"的默认假设。

**灵感 2（机械臂 → 关节空间证书而非末端点估计）**
直觉：末端位姿不是一个点，而是关节置信椭球经正运动学推前（pushforward）后的集合。真正决定能不能动的不是末端误差，而是**可操作度 μ(q)、条件数 κ(q)、自碰撞距离 d(q)、关节力矩/热余量**。若 μ 过低或 d_min 过小，即使末端位姿"看起来准"，任务在该方向上也不可达或不可安全执行。因此要把末端姿态证书升级为**关节空间证书 + 可操作度/碰撞/力矩的联合可行域**，并在不可行时给出"减速/换构型/换技能"的结构化降级。

**灵感 3（机械臂作为主动传感器 → 轨迹级联合证书）**
直觉：eye-in-hand 让机械臂成为可移动的相机。透明、镜面、弱纹理层不只靠开深度相机解决，还可以让机械臂移动到能避开高光/遮挡的视角。但"为了看得更清"而运动本身要消耗大量能量、可能进入狭窄/碰撞空间、可能使关节热升。于是主动感知不能是独立的 NBV 模块，而应是**在碰撞与热-能量硬约束下，最大化信息增益的轨迹选择**，并给整条轨迹（而非单个静态位姿）签发联合证书。

**耦合升级**：在 v10 四层上新增 **本体-机械臂层（Embodied Arm Layer）**，形成 v11 五层：根信任层增加执行器热-能量租约 ℓ_a 与本体护照 θ_e；L1 几何层由关节空间证书推前得到末端姿态集，并输出 μ/κ/d_min；L2 上下文层把语言技能绑定到本体化技能护照；L3 安全层用鲁棒 CBF-QP 把标称动作投影到碰撞/力矩/热可行域；L4 采集层按"碰撞边界 + 热边界 + 主动感知"三类不确定性做主动学习；L5 新增主动感知-操作耦合层，用机械臂轨迹同时换取可观测性增益。

## 1. 形式化定义（增量：定义 59–64）

**定义 59（关节空间证书 J_t 与推前姿态集）**
设关节构型 q∈Q⊂R^n，估计 q̂_t 与协方差 Σ_q。用独立标定集做共形校准，得到
J_t = { q : (q-q̂_t)^T Σ_q^{-1} (q-q̂_t) ≤ r_q^2(α_q) }，
满足 P(q_t∈J_t) ≥ 1-α_q。正运动学 f:Q→SE(3)，令 P_t = f(J_t)={f(q):q∈J_t}。若 f 在 J_t 上 L_f-Lipschitz，则
rad(P_t) ≤ L_f·rad(J_t)，rad(J_t)=r_q·λ_max(Σ_q)^{1/2}。
**端点证书**由关节证书推前得到，而不是独立估计后再拍一个半径。

**定义 60（可操作度-碰撞联合可行域）**
可操作度 μ(q)=sqrt(det(J(q)J(q)^T))，条件数 κ(q)=σ_max(J)/σ_min(J)。有符号距离 d(q)（含自碰撞与环境碰撞）。定义
A_t = { q∈J_t : μ(q)≥μ_min, κ(q)≤κ_max, d(q)≥d_safe }。
由 Lipschitz 性给出可计算的保守下界：
d_min(t) = d(q̂_t) - L_d·rad(J_t)，μ_min(t)=μ(q̂_t)-L_μ·rad(J_t)。
若 A_t=∅，该技能在当前不确定度/构型下不可认证，必须换构型、降速或转人工。

**定义 61（执行器热-能量租约 ℓ_a）**
关节 j 的功率 P_j=max(0,τ_j q̇_j)+k_c τ_j^2（机械功率 + 铜损）。一阶热模型
T_j(t+1)=a_j T_j(t)+(1-a_j)(T_amb+R_th,j P_j)，
能量 E(t+1)=E(t)-Σ_j P_j Δt。租约
ℓ_a=(τ_max, T_max, E_min, P_cap, τ_a)，
可行判据 T_j(t+Δ)≤T_max-m_T 且 E(t+Δ)≥E_min 且 Σ_j P_j≤P_cap。失效时机械臂进入"认证制动"（可证明停在 A_t∩安全停机集内），并使其签发的姿态证书级联失效。

**定义 62（鲁棒碰撞安全证书与 CBF）**
标称安全集 C_t={q∈A_t : d(q)≥d_safe}。取 h(q)=d_min(q)-d_safe 作为鲁棒控制屏障函数，要求
ḣ(q,q̇) ≥ -γ h(q), γ>0。
由于 d_min 已对 J_t 内全部构型取下界，满足该约束即对关节不确定性鲁棒。CBF-QP 在力矩/速度/热功率约束下把标称速度投影到 {ḣ≥-γh}。

**定义 63（主动感知-操作联合证书）**
轨迹 ξ=q_{t:t+Δ}，eye-in-hand 相机位姿 v(ξ)。信息增益
IG(ξ)=H(ω|c_t)-E_{v(ξ)}[H(ω|v(ξ),c_t)]。
联合证书 A_t^+ =(J_t, P_t, ℓ_a, A_t, P(ω|v(ξ)))，要求
(i) ξ 全程落在 C_t 且 ℓ_a 有效；(ii) 由 ξ 末态推前的 P_t 仍满足 P(X_t∈P_t)≥1-α_p。
调度目标：ξ* = argmax_{ξ∈Ξ_safe} IG(ξ) / [E_cost(ξ)+λ_T·ΔT_max(ξ)]，并设信息增益阈值 τ_info；低于阈值则"原地保持 + 开深度"，不拿安全换视角。

**定义 64（本体护照与跨机证书迁移）**
技能库 K={(s,pre,post,π_s,τ_cert,θ_e)}，θ_e 为本体护照。对目标机标定集 D_cal，非一致性分数 s_i=nonconformity(π_s,x_i;θ_e)，取 r_target=Quantile(s,1-α)。若源机与目标机分数分布经检验显著漂移（如 KS 检验 p<δ），则判迁移失败，要求重新标定或 fail-closed；通过分组条件共形可对"负载档/构型簇/温度档"分别校准，避免边缘覆盖被平均掩盖。

## 2. 新增 IP 与既有 IP 升级

**IP-69 JSC（Joint-Space Certificate Engine）**
- 编码器 + EKF 估计 q̂、Σ_q；独立标定集共形半径 r_q(α_q)
- FK 推前姿态集 P_t，输出 L_f 局部 Lipschitz 上界
- 可操作度/条件数/自碰撞/环境碰撞的保守下界与可行性判定
- 不可行时输出结构化降级：换构型 / 降速 / 换技能 / 认证制动

**IP-70 TAL（Thermal-Actuator Lease）**
- 关节功率与一阶热模型在线辨识（R_th、a_j 用递推最小二乘更新）
- 力矩/热/功率/能量四重租约与余量预测
- 租约失效 → 认证制动轨迹 → 级联使 ℓ_p、P_t 失效 → CAR fail-closed
- 与 IP-63 共享总能量预算，机械臂与深度相机互相竞价

**IP-71 NBV-ARM（Active Perception Arm Scheduler）**
- 候选轨迹库：绕物体弧线、升高俯视、侧向避高光、拉远避遮挡
- 安全预筛（CBF/碰撞/热）后算信息增益与能耗比
- 轨迹级联合证书 A_t^+；低增益时回退"原地 + Depth On"
- 与 IP-67 语音需求分布 R(v) 对齐：语音指哪，NBV 优先补哪一层

**IP-72 EBT（Embodiment Transport & Skill Passport）**
- 本体护照辨识（零位、背隙、刚度、摩擦、内外参）
- 跨机分组条件共形迁移 + 漂移检验
- 技能护照绑定前置条件（负载、构型簇、温度档）
- 漂移超阈 → 技能冻结、要求重标定，禁止静默复用

**既有 IP 升级**
IP-63 ECPS：能量预算从"感知模态"扩展为"感知+执行器"联合资源分配，求解二维（m_t, 关节速度尺度 s_t）的约束效用。
IP-60 PSE：P_t 改由关节证书推前，并与头部云台证书记融合，取外包集。
IP-61 DCL：采集任务新增碰撞边界、热边界、主动视角三类主动学习项，采集本身受 ℓ_a 约束。
IP-62 CCA：新增关节不确定性注入、负载突变、热降频、跨机分布漂移红队。
IP-51 CAR：守卫加入 A_t≠∅、d_min≥d_safe、ℓ_a 有效、CBF-QP 可行四项。
IP-68 SAB：语音意图先绑定到技能护照，再检查 B(v_t,P_t) 与技能前置条件，二者同时通过才执行。
IP-45 总线：新增 joint-state / joint-cert / thermal-lease / skill-passport / nbv-plan / safe-stop 话题。

## 3. 算法骨架

每控制周期（1 kHz 级）：
1. 读编码器 q、力矩 τ、关节温度 T、电池 B，更新 q̂、Σ_q、ℓ_a
2. JSC 计算 J_t、P_t、μ_min、d_min、A_t
3. 由任务/语音/上下文生成标称关节速度 q̇_nom
4. CBF-QP 求解 q̇*，满足碰撞、力矩、热、功率约束
5. 若 A_t=∅ 或 QP 不可行或 ℓ_a 失效 → 认证制动 + 证书级联失效 + CAR fail-closed
慢时间尺度（10–100 Hz）：
6. NBV-ARM 生成候选轨迹，安全预筛后用 IG/能耗比选 ξ*
7. EBT 在换机/漂移告警时重标定技能护照
8. PSE 用当前 J_t 与 ξ* 末态重签 P_t，CAR 用 A_t^+ 守卫

## 4. 本轮最大风险

**一句话**：关节空间证书经 FK Lipschitz 推前会天然偏保守，而跨机共形迁移又依赖"同机同分布"的交换性假设；一旦负载、热漂移或本体磨损使该假设破裂，证书要么宽到机械臂几乎不能动，要么静默失效却仍被技能护照放行，让机械臂在"证书看似有效"时执行了不再被覆盖的动作；因此必须在线漂移检测、负载/热租约门控，并在任何假设破裂时 fail-closed 到认证制动。

## 2. 关键算法 伪代码

### IP-69 JSC
```
def joint_cert(q_hat, Sigma_q, alpha_q, D_cal, fk, J, env):
    # 共形半径：用独立标定集的分位数，不假设高斯
    scores = [mahalanobis(q_i, q_hat, Sigma_q) for q_i in D_cal]
    r_q = quantile(scores, 1 - alpha_q)
    J_t = Ellipsoid(q_hat, Sigma_q, r_q)

    # 局部 Lipschitz 上界（按构型簇取 max）
    L_f = local_fk_lipschitz(J_t, fk)
    P_t = pushforward(fk, J_t)
    rad_P = L_f * r_q * sqrt(max_eig(Sigma_q))

    # 可操作度 / 碰撞的保守下界
    mu_hat = sqrt(det(J(q_hat) @ J(q_hat).T))
    L_mu = local_lipschitz(mu, J_t)
    mu_min = mu_hat - L_mu * r_q * sqrt(max_eig(Sigma_q))

    d_hat = signed_distance(q_hat, env)
    L_d = local_lipschitz(distance, J_t)
    d_min = d_hat - L_d * r_q * sqrt(max_eig(Sigma_q))

    feasible = (mu_min >= mu_req) and (d_min >= d_safe)
    return J_t, P_t, rad_P, mu_min, d_min, feasible
```

### IP-70 TAL
```
def thermal_lease(q, dq, tau, state, params, B, dt):
    P = [max(0, tau[j]*dq[j]) + k_c*tau[j]**2 for j in range(n)]
    T_next = [a[j]*state.T[j] + (1-a[j])*(T_amb + R_th[j]*P[j])
              for j in range(n)]
    E_next = B - sum(P)*dt

    valid = (max(T_next) <= T_max - m_T
             and E_next >= E_min
             and sum(P) <= P_cap
             and max(abs(tau)) <= tau_max)
    lease = Lease(valid, T_next, E_next, P, sum(P))
    return lease

def certified_brake(q, dq, J_t, env, L_d):
    # 在安全停机集内求解最短制动轨迹：dq 单调递减且 h(q) 不越界
    for dq_brake in brake_profile(dq, dq_max):
        if all(d_min_traj(q, dq_brake, env, L_d) >= d_safe):
            return dq_brake
    return None  # 无可行制动 -> 硬件急停（最后防线）
```

### IP-71 NBV-ARM
```
def nbv_schedule(q, c_t, omega_t, cert, lease, R_v, candidates):
    best, best_u = None, -inf
    for xi in candidates:
        if not trajectory_safe(xi, cert, lease):   # CBF/碰撞/热硬约束
            continue
        IG = info_gain(xi, c_t, omega_t)
        # 信息增益按语音需求分布加权：只看用户关心的层
        IG_w = sum(R_v[w] * IG[w] for w in omega_t)
        cost = energy_cost(xi, lease) + lambda_T * thermal_rise(xi)
        U = IG_w / (cost + eps)
        if U > best_u:
            best, best_u = xi, U

    if best is None or best_u < tau_info:
        return None, 'hold_and_depth_on'   # 不拿安全换视角
    return best, 'move'
```

### IP-72 EBT
```
def embodiment_transport(skill, theta_target, D_cal, alpha, delta):
    scores = [nonconformity(skill.pi, x, theta_target) for x in D_cal]
    r = quantile(scores, 1 - alpha)

    # 漂移检验：源机分数 vs 目标机分数
    p_val = ks_test(skill.source_scores, scores)
    if p_val < delta:
        return 'freeze_skill_and_recalibrate'   # fail-closed

    # 分组条件共形：按负载档/温度档/构型簇分别校准
    groups = groupby(D_cal, key=skill.group_key)
    radii = {g: quantile([nonconformity(skill.pi, x, theta_target)
                          for x in xs], 1 - alpha)
             for g, xs in groups.items()}
    return SkillPassport(skill, theta_target, r, radii, p_val)
```

### IP-68 SAB + IP-51 CAR 联合守卫
```
def arm_guard(v_t, skill, cert, lease, theta_e):
    # 语音意图必须绑定到技能，而不是直接绑定末端点
    if not skill_preconditions(skill, skill.passport, theta_e):
        return 'reject'
    if not cert.feasible or not lease.valid:
        return 'safe_stop'
    B_prob = safety_bind(v_t, cert.P_t, omega_t)

def car_guard(A_plus, lease_p, lease_a):

    if not (lease_p.valid and lease_a.valid and A_plus.feasible):
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| JSC | O(n^3)（可增量 O(n^2)） | O(n^2) | q_t∈J_t ⇒ P_t 覆盖末端位姿，Lipschitz 推前 |
| TAL | O(n) | O(n) | 租约有效 ⇒ 不超温/超力矩/超功率，能量可续 |
| CBF-QP | O(m^3)，m 为约束数 | O(m) | QP 可行 ⇒ 一步鲁棒安全；不可行 ⇒ 认证制动 |
| NBV-ARM | O(|Ξ|·T_h) | O(|Ξ|) | 仅从安全预筛集选轨迹，A_t^+ 保持 |
| EBT | O(|D_cal|) | O(|D_cal|) | 交换性成立 ⇒ 目标机覆盖 ≥1-α；否则冻结 |

**正确性定理（联合安全-覆盖）**：假设 (i) 关节估计满足 P(q_t∈J_t)≥1-α_q；(ii) L_f、L_d、L_μ 为证书区间上的有效 Lipschitz 上界；(iii) CBF-QP 每步可行且 ℓ_a 有效。则闭环轨迹以概率 ≥1-α_q 全程满足 d(q_t)≥d_safe，且推前姿态集满足 P(X_t∈P_t)≥1-α_p（α_p 为对 Lipschitz 推前的保守折算）。若 (ii)/(iii) 任一破裂或 A_t=∅，系统执行认证制动并级联使 P_t、ℓ_p 失效，因此任务可能失败但安全不变式不被违反；主动感知仅在安全预筛集内选择轨迹，故 IG 优化不削弱安全保证。

## 4. 实验设计 E115–E120

| 实验 | 指标 | 门槛 |
|---|---|---|
| E115 关节证书覆盖 | 经验覆盖率 vs 1-α_q；不同负载 | 覆盖率 ≥ 1-α_q-1%；负载 0/2/5kg 稳定 |
| E116 可操作度-碰撞守卫 | 最小碰撞距离、违例次数、成功率 | 碰撞违例 0；任务成功率 ≥ 90% |
| E117 热-执行器租约 | 超温次数、降频事件、单任务能耗 | 超温 0；能耗 ≤ 基线 1.05× |
| E118 主动感知 NBV | 信息增益、能耗、深度启用率 | 姿态覆盖不降；深度使用时长降 ≥ 30% |
| E119 跨机迁移 | 目标机覆盖率、标定样本数、漂移检出 | 覆盖率 ≥ 1-α-2%；≤ 50 样本；漂移检出 ≥ 95% |
| E120 100h 整机闭环 | 安全违例、成功率、单任务能耗 | 违例 0；成功率 ≥ 95%；能耗 ≤ 基线 |

回退策略：E115 覆盖率不达标 → 增大 r_q 并降低速度上限；E116 碰撞余量不足 → 提高 d_safe 并禁用高风险构型簇；E117 热租约频繁失效 → 降低连续负载占空比、强制间歇；E119 漂移检出失败 → 关闭跨机迁移，逐机重标定；E120 安全-效率冲突 → 进入"Depth On + 半速 + fail-closed"保守模式。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| FK Lipschitz 推前过保守，机械臂几乎不能动 | 高 | 构型簇局部 Lipschitz、区间/zonotope 传播、自适应共形 |
| 热模型失配导致意外超温或过度降频 | 高 | 在线辨识 R_th/a_j、保守余量、独立热审计 |
| 负载突变使关节证书与技能护照失配 | 高 | 负载传感门控、负载档分组共形、超阈冻结技能 |
| 主动感知轨迹为增益进入狭窄/遮挡空间 | 中 | CBF 硬约束 + 安全预筛 + 低增益回退原地 |
| 跨机交换性破裂导致覆盖静默失效 | 高 | KS/MMD 漂移检验、分组条件共形、破约即 fail-closed |
| 记忆复用旧技能忽略新本体参数 | 中 | 技能护照前置条件 + 本体护照校验 + 能量/热租约门控 |

## 6. 本轮最大风险

**一句话**：最大的风险是关节空间证书经 FK 推前与跨机共形迁移后可能"宽到不能动"或"静默失效仍被放行"——一旦负载、热漂移或本体磨损破坏交换性假设，机械臂会在证书看似有效时执行不再被覆盖的动作；因此必须在线漂移检测、负载/热租约门控，并在假设破裂时 fail-closed 到认证制动。
