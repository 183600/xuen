# 第 4 轮（灵感循环第 4 轮；本轮灵感：「任务规划」×「同步定位与建图」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承。
> 本轮纪律：**增量升级 + 严格退化**。任务规划沿「时间/层级范围」轴升级，SLAM 沿「空间信念」轴升级；两者都是可选增强，任一失效都必须能逐级回退。

## 0. 直觉与动机

**灵感 1（任务规划：从「就地修一个盲区」到「有前置、有资源、有顺序的修复计划」）**
直觉：前几轮把系统做成了一个很强的「反应式外科医生」——发现盲区、就地探测、更新契约。但真实工作不是单点：有多个盲区、共享工具/镜头、需要先清洁或先标定、有总时间预算，还有材料去除这类不可逆步骤。任务规划（HTN / PDDL 式）真正带来的不是「排序」本身，而是**显式前置/后置与资源约束**：每一步为什么可执行、依赖哪条地图谓词、消耗什么，都能被审计。关键危险也在这里：任务规划默认谓词真值已知，而谓词建立在地图上，地图只是估计。

**灵感 2（SLAM：地图与位姿是估计量，回环是「改写过去」的非单调更新）**
直觉：过去系统默认场景与位姿是已知坐标系；SLAM 把它们变成因子图上的随机变量。更进一步，计量回执本身也应是因子——**测量可以校验地图，地图也可以校验测量**，二者应当联合估计，而不是单向喂参数。SLAM 最危险的操作不是「当前漂移」，而是**回环闭合**：一次回环可以把「位置 i 与位置 j 是同一处」从假改真、也可以把旧的错误合并拆开，从而**回溯性改变**已建地图、已接地谓词与已完成步骤的证书。这不是第 3 轮的「证据陈旧」，而是更强的「过去被重写」。

**灵感 3（耦合：任务—地图的追溯性失配）**
直觉：任务计划在旧地图上是正确的；回环后地图变了，计划前提可能已不成立，而系统已经走了若干步。若没有依赖追踪，就会出现「用一张已作废的地图证明任务完成」的审计幻觉。解法不是禁用回环，而是三根结构支柱：**溯源化失效**（只回滚依赖受变因子的证书，而不是全量回滚）、**承诺地平线 / 回环屏障**（在可能改写过去的边界前强制重定位，限制暴露窗口）、**规范不变的分层谓词**（计划只依赖拓扑/关系量，不依赖全局度规框架）。再叠加两项增强：**任务相关主动 SLAM**（把探测预算花在会改变任务决策的不确定性上，而非全局地图熵）、**共形鲁棒计划**（对地图假设集保证计划失效概率 ≤ α）。

## 1. 研究问题（本轮要回答什么）

- **Q1（非单调正确性）**：当 SLAM 回环可以改写过去，任务计划的「正确性」如何定义与审计？能否只失效受影响的证书，而不推翻全部已完成工作？
- **Q2（预算分配）**：任务进度与建图不确定性共享同一探测预算；如何定义「任务相关」的价值，使主动建图服务于任务而不是地图美观？
- **Q3（追溯性损害的界）**：回环造成的追溯性失效能否被溯源 + 承诺地平线压到线性、局部、可修复？假回环（感知别名）下又如何避免「静默地把错误证明成正确」？

## 2. 四条设计原则（雏形，正式化见产物区定义 448–463）

**P1 溯源化证书（Provenance-Certified Truth）** 每个地图元素、谓词真值、任务步骤与计量证书都携带其依赖的原始因子集合 `prov(·)`；任一证书的真值只能是 `prov(·)` 的确定性函数。回环只失效 `prov` 与「变化因子集」相交的对象。没有溯源，就没有资格利用回环做热更新。

**P2 承诺地平线与回环屏障（Commitment Horizon & Loop Barrier）** 任务步骤在「可能被回环改写」的地图区域上有一个安全承诺窗口：窗口由谓词真值裕度 `m_min` 与单步漂移 `δ` 决定，并同时受回环风险率 `λ_lc` 约束；越界前必须重定位/闭合回环；不可逆动作前窗口强制为 0。动作分块的块长 `K` 也必须被剩余地平线截断。

**P3 规范不变的分层谓词（Gauge-Invariant, Stratified Predicates）** SLAM 的全局坐标系存在规范自由度（整体 SE(3)；单目还有尺度）。允许任务规划使用的谓词必须来自不变片段（邻接、同址、相对次序、距离比、目标计数）；绝对度规谓词只有在附带「框架证书」时才允许使用。这样任务计划不会依赖一个不可观测的全局框架。

**P4 任务相关主动建图（Task-Relevant Active SLAM）** 探测动作的价值定义为「对最优任务计划/谓词真值的互信息」，而不是全局地图熵；在预算约束下做贪心子模最大化。全局熵下降但任务决策不变的不确定性，一分钱都不该花。

## 3. 与基线的接口（如何严格退化）

- 单子目标 + 静态已知地图 ⇒ 任务层与 SLAM 层同时空转，8C 退化为 InstructGauge 7C；
- 多盲区但地图/位姿已知、无回环因子 ⇒ `H_commit = ∞`、失效集为空，退化为「按顺序跑 InstructGauge」；
- 回环候选歧义 / 数据关联不唯一 ⇒ **不修地图**，保守使用先验地图（静态地图模式），绝不带着假回环前进；
- 溯源不可用 ⇒ 禁止利用回环做热替换，只能冷重建或保持静态地图；绝不产生无溯源证书；
- 任务规划无可行计划 / 任务域缺失 ⇒ 退回反应式盲区修复（InstructGauge）；
- InstructGauge 失效 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个**非单调地图更新下的证书失效语义**：用溯源 DAG 定义变化因子集与最小失效影响集，给出可靠/完备条件；
2. 一个**承诺地平线 + 回环屏障**，把「用旧地图执行新步骤」的暴露窗口从无界压到由漂移裕度与回环风险显式界定，并与动作分块的 `K` 联动；
3. 一个**规范不变的任务谓词分层**与**任务相关 VoI** 的主动建图分配器，使长程任务不被全局框架与地图美观绑架；
4. 一条可证伪路径：E457–E472 覆盖规范不变性、失效可靠性、追溯损伤、共形计划有效性、承诺地平线、感知别名、对抗回环与 50Hz 时序。

## 5. 本轮最大风险

**一句话**：回环是整套系统里唯一能「改写过去」的操作——若溯源不完整或数据关联出现假阳性，系统会用一张已作废的地图把任务证书审计为「正确」，因此真正的残余风险在溯源完整性与回环确认，而不在任务规划或 SLAM 单个组件。

## 2. 形式化定义（要点）

**定义 448（任务域与三值接地）** 任务域 `D = (P, O, M_th)`：谓词集 `P`、算子集 `O`（每个 `o = (pre_o, eff_o, cost_o, res_o, dur_o)`）、方法集 `M_th`（复合任务分解）。接地函数 `Grd: P × Map × Belief → {T,F,?}`，`?` 表示在当前地图假设集下真值不确定。任务计划 `Π = (x_1,…,x_n)` 合法当且仅当每步前置在信念下为 `T`（不是 `?`），且资源与预算不超。规划器只接受 `T`；`?` 必须转为「先探测」的子目标。

**定义 449（分层地图）** `Map = (G_top, X_met)`：`G_top = (V_top, E_top, ℓ_sem)` 为拓扑-语义图（地点、邻接、语义标签）；`X_met` 为度量因子图（位姿、路标、回环因子）。商投影 `π: X_met → G_top` 把度量节点映到地点。地点身份 `id(v)` 是潜变量，由数据关联决定。

**定义 450（计量-SLAM 联合信念）** `b_t = (X_t, Θ_t, Σ_t)`。因子图 `F = F_odom ∪ F_rec ∪ F_lc`：里程计因子、**计量回执因子**、回环因子。联合 MAP：`b_t = argmax_b Σ_{f∈F} ρ(‖r_f(b)‖²_{Σ_f})`。双向耦合：回执约束地图，地图先验约束回执的解释；因此计量契约与地图必须同层估计，不能单向喂参。

**定义 451（溯源函数与依赖 DAG）** 每个派生对象 `x`（因子、地图边、谓词真值、计划步骤、证书）携带 `prov(x) ⊆ 2^F`，递归定义为输入因子之并；`prov` 构成有向无环依赖图 `DAG = (X, E_prov)`。约定：任何进入数值路径或审计路径的对象必须有 `prov(x) ≠ ∅`。

**定义 452（回环事件与地图修正）** 回环事件 `ℓc = (i, j, z_ij, switch)`，其中 `z_ij` 为相对观测，`switch` 为可切换约束。修正算子 `Rev: (b, ℓc) → b'` 重估后验。关键：`Rev` **非单调**——谓词真值可 `T→F` 或 `F→T`，地图可合并或拆分；定义修正距离 `d_rev(ℓc) = TV(b, b')`。回环不是规范变换，不能用定义 459 的规范不变性豁免。

**定义 453（变化因子集与失效影响集）** `A(ℓc) = {f ∈ F : |post_f − prior_f| > τ_f}` 为后验变化超过容差的因子集。失效影响集 `I(ℓc) = {x ∈ X : prov(x) ∩ A(ℓc) ≠ ∅}`；实际失效证书 `Stale(ℓc) = {c ∈ Certs : prov(c) ∩ A(ℓc) ≠ ∅}`。**最小修复集** `R(ℓc) ⊆ I(ℓc)` 是覆盖所有 `Stale`、且代价 `Σ c_rep(x)` 最小的可重观测/重规划集合。

**定义 454（任务相关不确定性与 VoI）** 任务相关熵 `H_task(b) = H(Π*(b) | b)`，即最优计划身份（或计划代价分位）的不确定性。探测动作 `a` 的任务相关价值 `VoI_task(a) = I(Π*; Z_a | b) − λ c(a)`，其中 `Z_a` 为观测。**只计会改变计划/谓词真值的不确定性**；与计划无关的全局地图熵不计入。

**定义 455（预算化探测分配）** `A* = argmax_{A ⊆ 𝒜_probe, |A| ≤ k} Σ_{a∈A} VoI_task(a | b, A_{<a})`，满足安全盾与 `B_chunk ≤ B_left`。采用贪心（子模时给 `1−1/e` 近似），并在每步观测后滚动重规划。

**定义 456（承诺地平线与回环屏障）** 设谓词真值裕度 `m_min`（当前估计到最近决策边界的距离）、单步漂移上界 `δ`、回环风险率 `λ_lc`、允许失效概率 `ε`。承诺地平线 `H_commit = min(⌊m_min/δ⌋ − 1, ⌊ε/λ_lc⌋)`。屏障规则：`t − t_last_lc ≥ H_commit` 或下一步 `a_t ∈ I_irr` ⇒ 必须先重定位/闭合回环（`K=1`，禁止不可逆），然后才允许继续。分块长度被 `K ≤ H_commit − (t − t_last_lc)` 截断。

**定义 457（共形地图假设集与 α-鲁棒计划）** 用任务相关校准集 `C_cal` 构造地图假设集 `H_α`，使 `P(b* ∈ H_α) ≥ 1−α`（按任务分层校准）。计划 `Π` 是 `α`-鲁棒的，若对每个 `b ∈ H_α` 都存在可执行策略（或修复策略 `π_rep`）使其完成；`TaskCert` 记录 `H_α` 与 `α`。若层内样本 `< n_min` ⇒ 回退全局/保守静态地图集。

**定义 458（任务证书与修复策略）** `TaskCert(Π) = (goal, grounded Π, prov DAG, H_α, receipts, invalidation log, π_rep)`。审计可沿「因子→地图→谓词→计划步骤→证书」回溯；任一失效必须写入 `invalidation log`，不得静默覆盖。

**定义 459（规范群与不变谓词片段）** 规范群 `G_gauge` 作用在度量状态上（整体 SE(3)，单目加正尺度）。谓词片段 `ℒ_inv` 对 `G_gauge` 不变：邻接、同址、相对次序、距离比、目标计数等。允许使用绝对度规谓词 `p_met` 仅当附带框架证书 `FrameCert`；否则 `Grd(p_met) = ?`。计划编译优先落入 `ℒ_inv`。

**定义 460（数据关联证书与感知别名）** 回环候选 `(i,j)` 的 DA 证书 `DA(i,j) = (score, Λ_alias, neg_evidence)`，其中 `Λ_alias` 为与 `(i,j)` 不可区分的候选集。仅当 `|Λ_alias| = 1` 且 `score > τ_da` 才允许接受回环；否则 `defer` 并要求主动消歧（换视角/主动探测）；消歧预算耗尽 ⇒ 保持静态地图。

**定义 461（回滚与重规划语义）** 当 `Stale(ℓc) ≠ ∅`，系统在 `{re-certify, rollback, replan}` 中选择：重观测受影响对象、回滚到影响集外最后一个已提交步骤、或从当前信念重规划。硬语义：**任何前置谓词处于未解决失效集内的步骤不得执行**。回滚代价 `C_rollback` 计入联合目标。

**定义 462（任务-地图联合目标）** `J(Π, A) = E[cost(Π)] + λ_u E[H_task(b_T)] + λ_r E[C_rollback] + λ_s E[safety margin violation]`，`s.t.` 安全盾、`Barrier`、`|A| ≤ k`、`H_commit`。分层求解：任务层选子目标与顺序，地图层选探测动作，计量层做证书与热替换。

**定义 463（地图静默点 q_map 与热替换）** `q_map` 指「无在途任务步骤依赖受影响地图区域、无未解决失效集、无待处理不可逆动作」的时刻。任务/地图热替换只允许在 `q_map`；否则 drain 到边界或按 `π_rep` 回滚补偿，避免任何步骤观察到「混合地图」。

# IP-328 TPG：HTN 任务规划（三值接地 + 共形地图集）
class TaskPlanner:
    def decompose_ground(self, goal, domain, stmap, belief, alpha):
        H = conformal_map_set(belief, alpha)          # H_α：任务相关共形集
        grounded = {}
        for p in domain.predicates(goal):
            vals = {ground_predicate(p, stmap, b) for b in H}
            grounded[p] = vals.pop() if len(vals) == 1 else UNKNOWN
        if needs_unknown(goal, grounded):
            return self.plan_sensing_subgoal(goal, grounded)   # 先补信息
        return htn_plan(domain, goal, grounded)       # 仅用 T 谓词

# IP-329 MSLAM：计量回执作为因子的联合估计
class MetrologySLAM:
    def update(self, odom, receipts):
        self.graph.add_factors(odom, receipts)        # F_odom ∪ F_rec
        cand = self.detect_loop(self.graph)           # 候选 (i,j,z_ij)
        if cand is None:
            return self.marginal(self.graph), None
        da = self.data_assoc_cert(cand, self.graph)   # 定义 460
        if da.ambiguous or not da.unique:
            return self.marginal(self.graph), ("defer", da)
        b = self.revise(self.graph, cand, da)         # 非单调修正（定义 452）
        return b, ("loop", cand, da)

# IP-330 PInv：溯源失效与最小修复集
class ProvenanceInvalidator:
    def on_loop(self, lc, dag, certs, tau_f):
        A = changed_factors(lc, tau_f)                # 定义 453
        stale = [c for c in certs if set(dag.prov(c)) & A]
        for c in stale:
            c.mark_stale()                            # 不静默覆盖
        I = dag.reverse_lookup(A)                     # 依赖闭包
        return RepairSet(stale, dag.minimal_repair(I))

# IP-331 TVoI：任务相关探测分配（贪心，子模）
class TaskVoI:
    def allocate(self, candidates, budget, belief, plan):
        A = []
        for _ in range(budget):
            a = max(candidates - set(A),
                    key=lambda x: task_voi(x, belief, plan))   # 定义 454
            if task_voi(a, belief, plan) <= 0:
                break
            A.append(a)
            belief = belief.predict(a)
        return A

# IP-332 CHB：承诺地平线 / 回环屏障
class CommitmentBarrier:
    def guard(self, plan, t, belief, last_lc, m_min, delta, lam_lc, eps):
        H_drift = max(0, floor(m_min / max(delta, 1e-9)) - 1)
        H_lc    = max(1, floor(eps / max(lam_lc, 1e-9)))
        H       = min(H_drift, H_lc)
        if t - last_lc >= H or is_irreversible(plan[t]):
            return "force_relocalize"                 # 先验证，再走
        return "ok"

    def truncate(self, C, t, last_lc, H):
        return C.truncate(min(len(C), max(1, H - (t - last_lc))))

# IP-333 CPR：共形鲁棒计划证书
def certify_plan(plan, H_alpha, domain, alpha):
    for b in H_alpha:
        if not executable(plan, b, domain):
            return None                               # 非 α-鲁棒
    return TaskCert(plan, prov=provenance_dag(plan), H=H_alpha, alpha=alpha)

# IP-334 PlanGauge-8C 闭环：T→M→G→C→E→L→V→U
def plangauge_8c(M, goal, ell=None):
    # T: 任务分解
    tasks = M.tpg.decompose(goal, M.domain)
    # M: 计量-SLAM 联合更新
    b, lc = M.mslam.update(M.odom, M.pending_receipts())
    if lc and lc[0] == "loop":
        repair = M.pinv.on_loop(lc[1], M.dag, M.certs, M.tau_f)
        if repair.nonempty:
            return replan_or_rollback(M, repair, tasks)   # 定义 461
    # G: 三值接地（只接受 T）
    G = M.tpg.ground(tasks, M.stmap, b, M.alpha)
    # C: 选子目标 + 受屏障约束的分块
    s    = M.tpg.select(G, M.budget_left())
    iota = M.nlib.ground(ell, M.scene, M.ontology) if ell else M.default_iota
    C    = M.iac.plan_chunk(iota, M.lbox.hypothesize(s, b), M.tools,
                            M.budget_left(), M.drift_bound())
    C    = M.chb.truncate(C, M.t, M.last_lc, M.H_commit)
    # E: 执行（回执同时喂给 SLAM 与计量）
    cert = M.cvc.commit(C, M.env, iota)
    M.pending_receipts.extend(cert.receipts)
    # L: 回环检查；V/U: 沿用 InstructGauge 的验证与更新
    maybe_close_loop(M.mslam, cert)
    return instructgauge_verify_update(M, cert, iota)

# IP-335 主闭环（50Hz 路径不变）
def PlanGauge_round(M, obs, audio, tac, depth, det, goal=None, ell=None):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            submit_async(plangauge_8c, M, M.task_of(s, goal), ell)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)

## 4. 推导

**引理 59（规范不变性与商计划）** 若任务计划只使用 `ℒ_inv` 谓词，则对任意 `g ∈ G_gauge`，`Grd(p, b) = Grd(p, g·b)`，最优计划与代价不变；绝对度规谓词在无 `FrameCert` 时只能取 `?`，不会进入数值路径。*证明*：`ℒ_inv` 按定义在群作用下不变；计划代价只依赖不变量；带 `FrameCert` 的度规谓词在证书失效时降级为 `?`。推论：全局坐标系选择不会改变任务。**但回环不是规范变换**——它改变地点恒等关系，故本引理不提供回环保护，这正是 P1/P2 的必要性。

**引理 60（失效影响集的可靠性与完备性）** 在 (A1) `DAG` 无环且 `prov` 完整、(A2) 变化因子判定精确 下，`Stale(ℓc)` 恰好是所有真值可能改变的证书；`I(ℓc)` 是可靠且相对依赖闭包最小的。*证明*：证书真值是 `prov(c)` 上因子的确定性函数；若 `prov(c) ∩ A = ∅`，则所有依赖因子变化在容差内，真值不变（可靠性）；反之若真值可变，必存在依赖因子越过容差，故 `c ∈ Stale`（完备性）。注意：A1 一旦被违反，可靠性会**静默失败**——这是本轮最大风险的形式化来源。

**引理 61（追溯性损伤界）** 设计划 `n` 步、每步依赖至多 `k` 个因子，回环影响区域有 `|A|` 个变化因子，则 `|Stale ∩ Π| ≤ min(n, k|A|)`。若步骤空间局部，回环影响直径为 `D`、步长为 `ℓ`，则受影响步骤数 `≤ O(D/ℓ) + 边界项`（线性而非二次）。若计划只用 `ℒ_inv` 谓词，则度规重估不改变计划结构，失效被限制在度规叶子证书；只有拓扑改变（回环合并/拆分）才可能改变计划，其期望损伤 `≤ p_f·n`，`p_f` 为假回环率。*证明*：每条步骤依赖集有界 + 局部性计数；不变片段对度规重估不敏感；假回环触发拓扑改变的概率为 `p_f`。

**引理 62（承诺地平线安全）** 设 `m_min` 为谓词真值裕度、`δ` 为单步漂移上界。无回环区间内，若 `t·δ < m_min`，则被使用谓词的真值不会翻转，故 `H_drift = ⌊m_min/δ⌋ − 1` 是漂移安全地平线。设回环到达率为 `λ_lc`、检查周期为 `H`，两次检查间遇到回环的概率 `≤ 1 − e^{−λ_lc H} ≤ λ_lc H`；取 `H_lc = ⌊ε/λ_lc⌋` 使暴露概率 `≤ ε`。取 `H_commit = min(H_drift, H_lc)` 同时防御两类失效；仅防漂移在 `λ_lc` 大时不可靠，仅防回环在 `δ` 大时不可靠。不可逆动作把窗口强制为 0（与定义 445 合并）。*证明*：三角不等式给出漂移不越界；风险率给暴露界。

**引理 63（共形鲁棒计划有效性）** 若 `H_α` 在任务相关校准集上满足 `P(b* ∈ H_α) ≥ 1−α`，且 `Π` 在 `H_α` 上可执行（或 `π_rep` 可完成），则 `P(Π 在 b* 上失效) ≤ α + TV_task`，`TV_task` 为任务相关分布漂移。按任务 stratum 校准则逐层成立；低样本回退全局集，覆盖按 `−2η_global` 降级。关键：用**全局地图误差**校准不足以保证任务覆盖——必须校准「会改变任务谓词/计划」的误差（任务条件化共形）。*证明*：计划有效事件包含于覆盖事件；TV 展开。

**引理 64（VoI 子模性与贪心近似）** 在观测条件独立于地图与计划的假设下，`F(A) = I(Π*; Z_A | b)` 单调子模；基数约束下贪心达到 `(1−1/e)` 最优。注意 `Π*` 随观测改变，故这是滚动时域的一步保证而非全局最优；若回环使观测相关，子模性可能失效，此时回退到全局熵或自适应子模条件。*证明*：互信息链式法则 + 条件独立给出收益递减。

**引理 65（严格退化）** （i）任务层关闭（单子目标、固定顺序）⇒ 8C 的 `T/G` 坍缩，等价 InstructGauge-7C；（ii）SLAM 关闭（静态已知地图、无 `F_lc`）⇒ `b` 固定、`A = ∅`、`H_commit = ∞`，等价按序执行 InstructGauge；（iii）任务与 SLAM 同时关闭 ⇒ ToolGauge / LeanGauge / MODGAUGE 链；（iv）溯源不可用 ⇒ 禁止回环热更新（静态地图或冷重建），因此不会产生无溯源证书，只是放弃增强。*证明*：逐分支代入定义；新增证书均为纯投影/附加记录，不改变数值路径。

**引理 66（实时性与复杂度）** 任务规划与 SLAM 均异步；增量 SLAM `O(|F|)`，回环检测摊销 `O(1)/关键帧`（索引），失效查询用反向 `prov` 索引 `O(|A| + |I|)`，屏障每步 `O(1)`，分块截断 `O(1)`。50Hz 主路径仅增加 `O(1)` 屏障检查与回执入队，新增周期 `< 0.3ms`；重规划/重观测在异步域，最坏 `O(n log n)` 但不进实时路径。*证明*：各数据结构操作界 + 关键路径只读不可变快照。

## 8. 本轮最大风险

**一句话**：回环是整套系统里唯一能「改写过去」的操作——若溯源不完整或数据关联出现假阳性，系统会用一张已作废的地图把任务证书审计为「正确」；因此真正的残余风险在溯源完整性与回环确认，而不在任务规划或 SLAM 单个组件。
