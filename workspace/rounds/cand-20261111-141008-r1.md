# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「放置」×「场景泛化」）

> 第 54 轮把技能组合升级为动作-鲁棒性双证书 `J=(ρ,A_cert,γ_ce,δ_a)`，但其证书是**场景无关**的：它回答"在已标定的动作空间里能不能组合、能不能对齐"，却不回答"换一个没见过的场景还能不能放对"。本轮聚焦 **放置的场景条件化、泛化的可度量性、弃权式安全**。核心矛盾：H22：放置不是末端动作而是贯穿全链的反向约束，"能抓到"不等于"能放稳"，若组合规划最后一步才检查放置，会把不可放置的路径当可行；H23：场景泛化不能被"平均成功率"掩盖，训练场景的支撑面语义在测试场景可能整体漂移，导致放置证书在分布外场景上"自信地错"。

## 0. 直觉与动机

**灵感 1（放置 = 场景条件化约束满足，而非一个末端动作）**
直觉：抓起一个物体时，"能不能放稳"其实已经反向决定了该怎么抓、从哪条路走、以什么姿态接近。放置的可行域 `M(o;c)` 不是"一个目标点"，而是一张受场景上下文 `c`（支撑面、摩擦、遮挡、可容纳空间、重力方向）约束的流形。因此放置应作为**第一性约束**参与规划，而不是末端的一次性判定。

**灵感 2（场景泛化 = 沿场景度量保持证书有效，而非更多数据）**
直觉：泛化不是"见得多"，而是"证书在一个可度量的场景邻域内仍然 sound"。定义场景度量 `d_C` 与**泛化半径** `R_gen`：只要测试场景落在标定场景的 `R_gen` 球内，放置证书的 soundness 不被破坏；超出则系统应弃权而非硬放。进一步用**支撑面等价类** `[Σ]_aff` 刻画"哪些支撑面在可供性上本就等价"，使证书可在同类支撑面之间平移，而不必逐场景重标。

**灵感 3（场景切片格 → 把平均成功率换成最差切片）**
直觉：把场景分解为正交扰动因子（支撑材料/摩擦、杂物密度、视角、光照、物体类别、初始位姿），构成切片格 `𝔾`。泛化能力应由**最差切片**而非均值决定：`G_gap = mean_g S(g) − min_g S(g)`。若 `G_gap` 大，说明均值在掩盖某个系统性崩塌的切片，绝不可部署。

**灵感 4（反向放置约束 → 用放置流形反推并裁剪技能图）**
直觉：从任务终点的放置流形 `M(o;c)` 反向投影，得到每个前置技能必须满足的姿态/可达集 `B(S_k,M)`，直接剪掉动作剖面无法到达可行放置的边。这样第 54 轮的 `G_S` 从"前向能力拼接"变为"终点约束下的反向可达搜索"，"能抓但放不了"的路径被提前否决。

**灵感 5（按切片分组的保形证书 → 分布无关的覆盖保证）**
直觉：在每个场景切片内用保形预测校准放置可行性阈值 `q_α`，给出 `P(V=1 | g) ≥ 1−α_g` 的分布无关覆盖；跨切片不混池。未覆盖的切片不猜测，直接弃权。

**灵感 6（弃权式安全与主动切片发现）**
直觉：可靠的放置系统不是对所有场景都硬给答案，而是知道自己"不知道"。当测试场景超出已标定切片格或 `R_gen`，系统弃权并触发一次最小主动标定（主动把场景推进到已认证邻域，或请求一次人类示范）。这把场景泛化从"预测问题"重构为"证书覆盖问题"，把灾难性误放转化为可控的弃权成本。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（场景上下文与场景度量）**
场景上下文 `c = (Σ, O, Φ, Λ)`：`Σ` 支撑面集合，`O` 物体集合，`Φ` 物理参数（摩擦系数、质量、可变形性），`Λ` 感知扰动（光照、纹理、视角、杂物）。场景度量
```
d_C(c,c') = Σ_k w_k · d_k(c_k,c'_k),   Σ_k w_k = 1,  d_k ∈ [0,1]
```
其中 `d_k` 为归一化因子度量（几何 Hausdorff 距离、摩擦差、语义标签距离等）。

**定义 122（场景条件化放置谓词与放置流形）**
放置谓词 `V(o,s,p;c) ∈ {0,1}` 为真当且仅当同时满足：支撑多边形包含质心投影、摩擦锥内稳定、无穿透、机械臂可达、目标区域无遮挡。**放置流形**
```
M(o;c) = { (s,p) | V(o,s,p;c)=1 }
```
并携带放置鲁棒裕度 `ρ_place(o,s,p;c) = (ρ_stab, ρ_pen, ρ_fric, ρ_reach, ρ_occl)`。

**定义 123（放置鲁棒谱，扩展 ρ）**
在第 54 轮鲁棒性谱 `ρ(d)` 上增加放置维度 `d_place ∈ 𝔇_place = {stab, pen, fric, reach, occl}`：
```
ρ(d_place | c) = inf_{(o,s,p) ∈ M(o;c)} ρ_place^{d_place}(o,s,p;c)
```
即放置维度上的最坏裕度。`dom_ρ(T, c)=in` 当且仅当 `ρ(d_place|c) ≥ ρ_min ∀ d_place`。

**定义 124（场景切片格与最差切片鲁棒性）**
扰动因子集 `F = {material, clutter, viewpoint, lighting, category, pose}`，切片 `g ∈ 𝔾` 为因子的一个赋值。切片成功率 `S(g) = E_{c∼C_g}[V]`。定义
```
R_worst = min_{g∈𝔾_cov} S(g),   G_gap = mean_{g∈𝔾_cov} S(g) − R_worst
```
仅在已标定切片集合 `𝔾_cov` 上计算，未覆盖切片不参与统计、只触发弃权。

**定义 125（场景泛化半径与支撑面等价类）**
对切片 `g`，泛化半径
```
R_gen(g) = sup { r ≥ 0 : ∀ c, d_C(c, c_calib) ≤ r ⇒ ρ(d_place|c) ≥ ρ_min }
```
支撑面等价类 `[Σ]_aff = { Σ' : contact_normal / friction_cone / support_polygon 签名一致 }`。证书在测试场景 `c_t` 有效，当且仅当 `d_C(c_t,c_calib) ≤ R_gen` 或 `Σ_t ∈ [Σ]_aff`。

**定义 126（放置泛化证书）**
```
G = (g_cert, R_gen, [Σ]_aff, q_α, δ_place, abstain, evidence)
```
- `g_cert` 已认证切片；
- `R_gen` 泛化半径（保守下界）；
- `q_α` 分切片保形阈值，保证 `P(V=1|g) ≥ 1−α_g`；
- `δ_place` 放置执行容差（接触后微调预算）；
- `abstain` 弃权布尔与原因码（`out_of_radius` / `uncovered_slice` / `support_mismatch`）；
- `evidence` 至少含物理仿真反例、切片统计、支撑签名。部署规则：`covered(c_t) ∧ ¬abstain ∧ δ_place ≤ Θ_p ⇒ deploy`。

**定义 127（放置反向可达集与弃权门）**
给定技能 `S_k` 与终点放置流形 `M`，反向可达集
```
B(S_k, M) = { a ∈ A_{S_k} : ∃ 轨迹 a ⇝ (s,p) ∈ M, 执行成本 ≤ τ_e }
```
技能图边 `(i,j)` 可保留的必要条件为 `A_{S_i} ∩ B(S_j,M) ≠ ∅`。弃权门
```
AG(c_t) = deploy if covered(c_t) ∧ d_C(c_t,c_calib) ≤ R_gen
        = calibrate(c_t) if uncovered_slice
        = abstain if support_mismatch ∨ out_of_radius
```

## 2. 关键算法 伪代码

### IP-121 SPM（Scene-conditioned Placement Manifold）

```python
def build_placement_manifold(obj, scene, sampler, physics):
    M, margins = {}, {}
    for (support, pose) in sampler.candidates(obj, scene):
        ok, m = physics.check_stable(obj, support, pose, scene)
        if ok:
            M[(support.id, pose)] = True
            margins[(support.id, pose)] = m   # (stab, pen, fric, reach, occl)
    return M, margins
```

### IP-122 SGR（Scene Generalization Radius，保守二分）

```python
def calibrate_radius(c_calib, g, rho_min, rho_fn, r_max=1.0, eps=0.02):
    lo, hi = 0.0, r_max
    while hi - lo > eps:
        mid = (lo + hi) / 2
        worst = min(rho_fn(sample_scene_near(c_calib, mid))
                    for _ in range(N_SAMPLE))
        if min(worst.values()) >= rho_min:
            lo = mid
        else:
            hi = mid
    return lo   # 保守下界 R_gen
```

### IP-123 BPC（Backward Placement Constraint）

```python
def prune_by_placement(G, M, skills, tau_e):
    for (i, j) in list(G.edges):
        B = backward_reachable(skills[j], M, tau_e)
        if not (skills[i].action_set & B):
            G.remove_edge(i, j)
    return G
```

### IP-124 SSL（Scene Slice Lattice）

```python
def slice_lattice(factors, calibrate):
    stats = {}
    for g in product(*factors.values()):
        scenes = sample_slice(g)
        stats[g] = mean(success(s, g) for s in scenes)
    worst = min(stats.values())
    gap = mean(stats.values()) - worst
    return stats, worst, gap
```

### IP-125 CPS（Conformal Placement Certificate）

```python
def conformal_thresholds(calib_by_slice, alpha, score_fn):
    q = {}
    for g, samples in calib_by_slice.items():
        scores = sorted(score_fn(x) for x in samples)
        n = len(scores)
        q[g] = scores[min(n - 1, ceil((n + 1) * (1 - alpha)) - 1)]
    return q
```

### IP-126 APG（Abstain Placement Gate）

```python
def deploy_gate(c_t, G, scene_sig, rho_min):
    if scene_sig not in G.g_cert and c_t.support not in G.support_class:
        return ('abstain', 'support_mismatch')
    if d_scene(c_t, G.c_calib) > G.R_gen:
        return ('abstain', 'out_of_radius')
    if G.q_alpha.get(slice_of(c_t)) is None:
        return ('calibrate', 'uncovered_slice')
    if rho_place(c_t)[d] < rho_min:
        return ('reject', 'robustness_fail')
    return ('deploy', G)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SPM | O(\|Cand\|·\|𝔇_place\|) | O(\|M\|) | 采样覆盖放置流形、物理校验 sound |
| SGR | O(log(1/ε)·N_SAMPLE·\|𝔇_place\|) | O(1) | 场景度量 Lipschitz、保守下界 |
| BPC | O(\|E\|·\|A\|·\|M\|) | O(\|V\|+\|E\|) | 反向可达完备、剪枝不误删可行边 |
| SSL | O(\|𝔾_cov\|·N_slice) | O(\|𝔾_cov\|) | 切片正交、因子张成测试场景 |
| CPS | O(Σ_g n_g log n_g) | O(Σ_g n_g) | 切片内可交换、分组不混池 |
| APG | O(\|𝔾_cov\| + \|𝔇_place\|) | O(1) | 覆盖判定 sound、弃权优先于误放 |

**正确性定理（Placement-Aware Scene-Generalized Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增：
**(A29)** 放置谓词 `V` 由物理仿真校准，与真值误差 ≤ β_P；
**(A30)** 放置鲁棒谱对场景度量 `L_p`-Lipschitz：`|ρ(c) − ρ(c')| ≤ L_p·d_C(c,c')`；
**(A31)** 每个已覆盖切片内保形校准满足 `P(V=1|g) ≥ 1−α_g`。
则对测试场景 `c_t`，在 `deploy` 条件下：
```
P(placement success | deploy) ≥ 1 − α_g − L_p·R_gen − β_P
```
且在弃权门开启时，灾难性误放概率
```
P(catastrophic place) ≤ P(uncovered) + α_g + L_p·R_gen + β_P
```
关键：**放置先验反向约束**，**场景证书按切片覆盖**，**未覆盖即弃权**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 切片格未张成测试场景因子（软/透明/负障碍支撑） | 高 | 主动切片发现 + 支撑签名校验 + 弃权门 |
| 场景度量手工设计、Lipschitz 常数不可信 | 高 | 学习式度量 + 经验 Lipschitz 上界 + 保守 R_gen |
| 保形交换性在分布漂移下失效 | 高 | 分切片校准 + 加权保形 + 覆盖审计 |
| 反向可达计算爆炸 | 中 | 粗化动作抽象 + 分层 BPC + 剪枝缓存 |
| 弃权率过高导致不可用 | 中 | 主动标定回合 + 等价类复用 + 人类示范最小化 |

## 6. 本轮最大风险

**一句话**：放置反向约束与场景泛化证书把系统从"场景无关的能力拼接"推进到"可度量、可弃权的场景覆盖"，但其 soundness **双重依赖场景切片格确实张成测试场景的支撑-可供性因子、以及放置成功对场景度量满足可信的 Lipschitz 界**；一旦测试场景引入格外的支撑因子（可变形/透明/负障碍）或场景度量在极限处失真，`R_gen` 会成为虚假包络、分切片保形覆盖静默崩坏，系统将"自信地放错"，故必须以 **主动切片发现 + 支撑签名校验 + 物理接触后验证** 三重护栏，宁可弃权，绝不把"证书覆盖的假象"当作部署前提。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（SPM×SGR×BPC×SSL×CPS×APG）

> 承接第 54 轮产物 v31。本轮在动作-鲁棒性双证书 `J` 之上，增加 **放置的场景条件化、场景泛化的可度量覆盖、弃权式安全** 三大算子：
> - **SPM（Scene-conditioned Placement Manifold）**：把放置从"目标点"升级为受场景约束的可行流形 `M(o;c)` + 放置鲁棒裕度；
> - **SGR（Scene Generalization Radius）**：定义场景度量 `d_C` 与泛化半径 `R_gen`，使证书可在可度量场景邻域及支撑面等价类内平移；
> - **BPC（Backward Placement Constraint）**：从终点放置流形反向投影裁剪技能图，使"能抓不能放"的路径提前否决；
> - **SSL（Scene Slice Lattice）**：正交场景因子切片格 + 最差切片指标，替换会掩盖崩塌的平均成功率；
> - **CPS（Conformal Placement Certificate）**：按切片分组的保形阈值 `q_α`，给出分布无关覆盖；
> - **APG（Abstain Placement Gate）**：覆盖判定 + 弃权 + 主动标定的部署门。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-118/120 以纳入场景维与放置维。

### IP-123 BPC

```python
def backward_reachable(skill, M, tau_e):
    B = set()
    for a in skill.action_set:
        for (s, p) in M:
            traj = skill.trajectory(a, s, p)
            if traj is not None and traj.cost <= tau_e:
                B.add(a); break
    return B

def prune_by_placement(G, M, skills, tau_e):
    for (i, j) in list(G.edges):
        B = backward_reachable(skills[j], M, tau_e)
        if not (skills[i].action_set & B):
            G.remove_edge(i, j)
    return G
```

    q = {}

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SPM | O(\|Cand\|·\|𝔇_place\|) | O(\|M\|) | 流形采样覆盖、物理校验 sound |
| SGR | O(log(1/ε)·N·\|𝔇_place\|) | O(1) | 度量 Lipschitz、半径保守 |
| BPC | O(\|E\|·\|A\|·\|M\|) | O(\|V\|+\|E\|) | 反向可达完备、不误删可行边 |
| SSL | O(\|𝔾_cov\|·N_slice) | O(\|𝔾_cov\|) | 因子正交、切片覆盖测试分布 |
| CPS | O(Σ_g n_g log n_g) | O(Σ_g n_g) | 切片内交换性、分组不混池 |
| APG | O(\|𝔾_cov\|+\|𝔇_place\|) | O(1) | 覆盖判定 sound、弃权优先 |

**正确性定理（Placement-Aware Scene-Generalized Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增：
**(A29)** `V` 由物理仿真校准，与真值误差 ≤ β_P；
**(A30)** `ρ` 对 `d_C` 满足 `L_p`-Lipschitz；
**(A31)** 已覆盖切片内保形校准满足 `P(V=1|g) ≥ 1−α_g`。
则 `deploy` 条件下：
```
P(placement success | deploy) ≥ 1 − α_g − L_p·R_gen − β_P
```
弃权门开启时：
```
P(catastrophic place) ≤ P(uncovered) + α_g + L_p·R_gen + β_P
```
关键：**放置先验反向约束**、**场景证书按切片覆盖**、**未覆盖即弃权**。

## 6. 本轮最大风险

**一句话**：放置反向约束与场景泛化证书把系统从"场景无关的能力拼接"推进到"可度量、可弃权的场景覆盖"，但其 soundness **双重依赖场景切片格确实张成测试场景的支撑-可供性因子、以及放置成功对场景度量满足可信的 Lipschitz 界**；一旦测试场景引入格外的支撑因子（可变形/透明/负障碍）或场景度量在极限处失真，`R_gen` 会成为虚假包络、分切片保形覆盖静默崩坏，系统将"自信地放错"，故必须以 **主动切片发现 + 支撑签名校验 + 物理接触后验证** 三重护栏，宁可弃权，绝不把"证书覆盖的假象"当作部署前提。
