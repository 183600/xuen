# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环第 3 轮；本轮灵感：「中间件」×「材料选型」）

> R69 把不确定性一分为二，并让系统学会「问」：aleatoric 收紧、epistemic 去交互消解。但 R69 的整个求证框架建立在两个未言明的假设上：**(a) 从多模态证据到后验更新的「求证路径」是语义保真的**；**(b) 被探对象与本体（embodiment）的物理性质已知、稳定、各向同性**。本轮两个灵感正好击穿这两条：
> - 证据从不直接进入信念更新：它先穿过序列化、坐标/单位、时间戳/时钟域、版本协商、重试/去重等**中间件**。一个「看起来对、意思变了」的适配器（弧度当角度、机体系当世界系、旧固件当新固件）会让 `r_geo/r_sync/r_emo` 在表示上为真、在物理上为假；R69 的 MCG 只校准了模态权重，从未审计中介层。
> - 信息动作 `g_probe` 是一个**真实的力/位接触**；它是否安全、是否可逆、以及 R69 的流似然第二意见是否仍有效，都取决于被探对象的**批次、老化、各向异性**材料性质。材料替换会同时改变物理安全包络与行为密度，而性质既不能取平均，也不能只靠行为测试证明。
>
> 两个灵感因此指向同一个数学对象：**替换同态（substitution morphism）**。换中间件，是替换「表示与协议的载体」；换材料/组件，是替换「物理性质的载体」。两者都在问：**替换之后，哪些安全不变式被保持、哪些被削弱、哪些丢了？** R69 的「证据一致」只是它在恒等替换下的特例。
>
> 核心命题：**把「求证路径保真 + 物理性质已知」这两个隐含前提，升级为可验证的「保持剖面 + 丢失账本 + 鲁棒性质包络」：任何中间件适配或材料/组件替换都必须声明它在安全不变式集上的保持/削弱/丢失；中间件是可审计的语义中介流水线，材料选择是性质不确定（批间/老化/各向异性）下的鲁棒 Pareto 选择；只有在替换于所需不变式上鲁棒占优、丢失可补偿、且通过独立化验时，才允许替换，否则单调回退到 R69 的已认证组件。** 命名 **MORPH-RAS**（Mediation-preserving, Object-substitution, Robust Property Homomorphism）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我求证所走的那条路、以及被求证的那块材料，还是我以为的那个吗**」——从「主动求证」到「求证路径与物理底座的保持性」。

## 0. 直觉与动机

**灵感 1（中间件 → R69 的求证路径是一个未被审计的适配层）**
直觉：R69 的主动跨模态对齐（CIA）把 `r_geo/r_sync/r_zero/r_emo/r_wm` 当作可信证据，再按互信息挑最具判别力的模态对。但证据进入后验之前，要经过层层中介：消息序列化、坐标系与单位、时间戳与时钟域、重试与去重、缓存与批处理、模型/固件版本。任何一层都可能「表示对、语义错」。一个把弧度当角度、把机体系当世界系、把旧固件当新固件的适配器，会让 R69 在**错误的世界表示**上计算 VoI 与后验。因此本轮不再把中间件当作透明管道，而把每个适配器变成一等公民：携带 `(Pres, Side, ver, idem, tap)` 契约，声明它保持哪些不变式、有哪些隐藏副作用、版本是否被证明、是否幂等，并把差异记入**丢失账本**。

**灵感 2（材料选型 → 探测是真实接触，安全裕度是材料性质的函数且不能平均）**
直觉：R69 的 `g_probe ∈ ℝ³×[0,f_max]` 会施加真实力；同一次接触在弹性软材料上可恢复，在脆性材料上直接碎裂。材料性质是向量而非标量：密度、模量、屈服、断裂韧性、摩擦、热膨胀……它们**冲突**（强度 vs 重量 vs 成本）、**带不确定**（批间公差、数据表虚标）、**会老化**、**各向异性**。若安全裕度对性质是 `L`-Lipschitz，用均值判安全最多会高估 `L·ε`；存在「名义可行、鲁棒不可行」的候选。更隐蔽的是：R69 的 FMA（流似然第二意见）以「策略密度对当前本体/对象成立」为前提；材料替换会改变动力学，使行为似然整体偏移，FMA 可能把「换了材料」误读为「出了故障」，或反之。所以选材必须在**鲁棒可行集**上做 Pareto，且 `Rev` 与 FMA 基准都必须随实例重算。

**灵感 3（统一对象 → 替换同态与保持剖面）**
直觉：中间件适配 `A→B` 与材料替换 `A→B` 都是**态射**，都只保持一部分结构。把「保持什么」显式化为剖面 `Pres_σ(i) = (status, δ, cond)`：`EXACT`（精确保持）、`LIPSCHITZ`（损失有界）、`LOST`（丢失）。替换 σ 在所需不变式集 `I_req` 上可采纳，当且仅当没有 LOST、条件成立、且加权损失不超过预算。R69 的「k 个正交证据源一致」于是成为 `EXACT ∧ cond=⊤ ∧ δ=0` 的退化情形——新层严格泛化旧层，而不是并列替代。

**灵感 4（局部透明 ≠ 全局透明）**
直觉：每个适配器都声明「我保持安全不变式 i」，但可能只在某个前提 `A_i` 下保持；第二个适配器要求的前提，恰好被第一个适配器破坏了。于是两级各自 EXACT，组合却 LOST。这是 R69 假设-保证式推理在**中介层**的镜像：组合保持剖面时，必须组合**前提条件**，不能只把状态合并。这是本轮最容易被工程直觉漏掉的严格结论。

**灵感 5（行为测试是输出-only 检验 → 材料版的交互投毒）**
直觉：R69 知道单个来源可能撒谎，所以要求多个正交证据源一致。材料替换完全同构：只在有限载荷用例上做的合格性测试，也是一种输出-only 检验；一个替代材料可以完美通过被抽样的用例、在未抽样的载荷/老化阶段失效（Goodhart）。因此材料认证必须包含**独立性质化验（测得 p，而不只是任务通过）+ 对供应方盲化的留出载荷 + 批次/版本证明**。行为测试是必要不充分条件，正如单次交互不能单独定案。

**灵感 6（替换是双刃剑 → 洗白与围堵）**
直觉：一旦允许替换，就有了新的攻击面：伪造数据表、批次调包、旧料当新料、各向异性当各向同性、中间件供应链投毒、版本静默降级、以及**替换洗白**（A→B→A，让账本看起来干净）。所以必须：丢失账本**单调且传递**（不因回退而清零）、替换预算（在途最多一个未验证替换）、不可逆替换需显式确认、替换失败可回滚且回滚本身不扩张安全包络。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（MORPH-RAS 总览）** MORPH-RAS = (MMA, PPL, LLG, PIM, RPE, SMC, RPS, RRV, ATT, SBC, RAS-WM†)。六不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）；
(ii) **无证书不替换**：任何替换 σ（中间件适配器替换 / 材料或组件替换）都必须持有可采纳的保持证书；**恒等替换永远可采纳**；
(iii) **丢失不可隐藏**：每个适配器/替换声明保持剖面，所有损失进入账本；未声明的漂移即违规；账本单调且传递（A→B→A 不清零）；
(iv) **鲁棒占优**：可采纳性在批间/老化/各向异性不确定集上的**鲁棒性质包络**上判定，绝不用名义均值；
(v) **可逆性随实例重算**：`Rev` 依赖材料/实例性质；不确定集跨越阈值即保守降级，不可逆接触须显式确认；
(vi) **替换确认前零安全信用 + 单调回退**：效率/安全信用只在鲁棒验证与独立化验通过后兑现；失败、超时、账本失衡 ⇒ 回退到已认证 incumbent，λ 单调不降地回到 R69 的 `λ_floor`。

**定义 311（语义中介流水线 / 中间件 MMA）** 中介流水线 `μ = μ_n ∘ … ∘ μ_1`，连接证据/动作接口 `A_0` 与 R69 的信念更新/安全认证接口 `A_n`。每个适配器 `μ_i: A_{i-1}→A_i` 携带
`M_i = (Pre_i, Pres_i, Side_i, ver_i, idem_i, tap_i)`：
`Pre_i` 为入口前提；`Pres_i` 为保持剖面（定义 312）；`Side_i` 为隐藏状态/副作用帧；`ver_i` 为版本与证明；`idem_i` 为幂等/至多一次语义；`tap_i` 为带外可观测抽头。中间件必须**拒绝未协商版本**，且 `Side_i` 若改变语义则必须计入证书。`μ` 在 `I_req` 上语义透明 ⟺ 组合剖面为 EXACT。

**定义 312（保持剖面 Preservation Profile）** 对替换/适配 σ 与不变式 `i ∈ ℐ`：
`Pres_σ(i) = (status_i, δ_i, cond_i)`，其中 `status_i ∈ {EXACT, LIPSCHITZ, LOST}`，`δ_i ≥ 0` 为保持误差上界，`cond_i` 为界成立所需前提。σ 对 `I_req` **可采纳**当且仅当
`∀i ∈ I_req: status_i ≠ LOST ∧ cond_i 成立 ∧ Σ_i w_i δ_i ≤ δ_budget`，
并对硬不变式（全局安全 G、力/位包络、证据帧一致性）额外要求 `status_i = EXACT`。R69 的「正交证据一致」对应 `EXACT ∧ cond=⊤ ∧ δ=0`。

**定义 313（丢失账本 LLG）** 账本 `L` 累加所有适配器与替换的已声明损失，带来源（版本/批次/责任方）。三条纪律：(a) **单调**：除经独立证据的显式再认证外不减；(b) **传递**：组合损失一经产生即永久保留，替换洗白 A→B→A 不清零；(c) **守恒校验**：带外抽头/差分测试观测到的语义漂移 `≤` 声明上界 `+ tol`，否则触发回滚。未声明的损失是**违规**，不是误差。

**定义 314（性质向量与材料模型 PIM）** 实例/供应方 `m` 的性质向量 `p = (ρ, E, σ_y, K_IC, μ, α, …)`，且在受力方向 `u` 上可依赖 `p(u)`。不变式 `j` 的安全容量记为 `g_j(p, u, load)`。若 `p(u)` 在载荷方向集上的变化超过容差，称**各向异性**；`K_IC` 低且塑性储备小者称**脆性**。

**定义 315（不确定集与鲁棒性质包络 RPE）** 批间公差 `ε_b`、老化漂移 `ε_age(t)`（单调不减）、化验/测量噪声 `ε_m`。性质不确定集
`P_m(t) = { p : ‖W(p − p̂)‖₂ ≤ ε_b + ε_age(t) + ε_m }`（各向异性时对每个 `u` 分别取）。
鲁棒裕度 `ḡ_j(m) = min_{p ∈ P_m(t), u ∈ U_load} g_j(p, u)`；要求 `ḡ_j(m) ≥ g_j^req · SF_j`。**名义值 p̂ 只用于估计，不用于安全判定。**

**定义 316（替换同态 SMC）** 替换 `σ: A→B` 把已认证 incumbent A 映射到候选 B，携带保持剖面与性质包络。σ 对任务 τ 可采纳当且仅当：
(a) `I_req(τ)` 上剖面可采纳（定义 312）；
(b) 鲁棒包络占优：`∀j: ḡ_j(B) ≥ g_j^req`（定义 315）；
(c) `Rev` 经 RRV 重算且不弱于所需；
(d) 证书与独立化验通过（定义 322）；
(e) 替换预算未越界（定义 323）。
任一不满足 ⇒ σ 被拒，执行 incumbent。**恒等替换 σ=id 永真。**

**定义 317（替换组合与丢失传播 PPL）** `σ_2 ∘ σ_1` 的剖面按不变式组合：若两级在兼容前提下均 EXACT ⇒ EXACT；若任一 LOST 且无显式补偿适配器 ⇒ LOST；否则 LIPSCHITZ，且在度量 `d` 下 `δ_{21} ≤ δ_1 + L_2 δ_2`（`L_2` 为二级 Lipschitz 常数）。**关键**：若 `μ_2` 只在前提 `cond_2` 下保持 `i`，而 `μ_1` 的输出不再满足 `cond_2`，即使两级各自对其声明的不变式 EXACT，组合仍为 LOST。组合必须组合**条件**，不能只合并状态。

**定义 318（鲁棒 Pareto 选材 RPS）** 候选集 `M`（材料/工具/适配器）。鲁棒可行集 `F_rob = { m : ḡ_j(m) ≥ g_j^req, ∀j }`；目标向量 `(Cost, Mass, Latency, Risk(Eff))`；在 `F_rob` 上取 Pareto 前沿并选点。注意 `F_rob ⊆ F_nom`，且**名义 Pareto 最优可以是鲁棒不可行**。选中候选到实际使用仍是一次替换 σ，须经定义 316。

**定义 319（可逆性重算 RRV）** `Rev` 不是静态标签。定义
`Rev_a(m) = R` 若在不确定集内最坏弹性储能 `≤ E_limit·(1−margin)`；`= C` 若可通过有界残余补偿；否则 `= I`。若不确定集跨越 R/C 或 C/I 阈值，保守降级 `R→C→I`。`Rev=I` 的接触必须显式确认后才可执行（沿用 R69 信息动作安全认证，新增人工/责任方确认门）。

**定义 320（替换证书 J_MORPH）**
`J_MORPH = (J_FLUID, {Pres_σ}, ledger_root, property_evidence_hash, batch_aging_evidence, robust_margin_vector, rev_recompute_hash, fma_rebaseline_hash, assay_hash, substitution_log_hash, morph_ver)`。
`Valid ⇔` `Valid(J_FLUID)` ∧ 所有适配器/替换可采纳 ∧ 账本守恒 ∧ 无未声明损失 ∧ 鲁棒裕度满足 ∧ `Rev` 保守 ∧ FMA 基准已按新材料重标定 ∧ 在途未验证替换 ≤ 1 ∧ 不可逆替换有确认。

**定义 321（威胁模型 ℰ_MORPH）** `ℰ_MORPH = ℰ_FLUID × ℰ_sub`，其中
`ℰ_sub = { 假冒材料/伪造合格证、数据表虚标、批次调包、旧料当新料、各向异性当各向同性、中间件供应链投毒、适配器语义漂移（单位/坐标系/时间戳）、版本静默降级、等价性伪装（抽样通过、离样本失效）、替换洗白 A→B→A }`。
（`ℰ_FLUID` 继承 R69 定义 304：投毒 × 流采样故障 × 模态坍缩。）

**定义 322（独立化验与盲化留出 ATT）** 仅在有限载荷集 `U_test` 上的行为合格性测试是**输出-only**检验：存在性质不同但测试输出相同的材料。因此要求：(a) 独立性质化验（测得 `p` 而非仅任务通过）；(b) 对供应方/集成方**盲化**的留出载荷 `U_hold`；(c) 批次/版本/来源证明（attestation）；(d) 随机抽查。化验命中率 `p_a` 时，`m` 次抽查检出下界 `≥ 1 − (1−p_a)^m`。行为测试是必要不充分条件，正如 R69 的单次交互只提供似然、不单独定案。

**定义 323（替换预算与围堵 SBC）** 每回合**在途未验证替换 ≤ 1**；不可逆替换需显式确认；替换的 blast radius `≤ r_sub`；回滚到 incumbent 必须在时间/能量预算内完成；预算按**计划级**核算，禁止 A→B→C 拆分规避「单次替换」限制。

**定义 324（老化与再认证）** `ε_age(t)` 单调不减 ⇒ 鲁棒包络 `ḡ_j(t)` 单调不增；替换在 `t_0` 对地平线 `T` 可采纳，只保证 `t ≤ T`。到期未再认证，或漂移检测器（如 R69 的 FMA 行为似然通道）报警 ⇒ 必须降级/回退，不得继续使用过期信用。

**定义 325（严格退化到 R69）** 当 `μ=id`（所有适配器 EXACT、账本为空）、`σ=id`（无替换）、性质已知各向同性（`ε→0`）、FMA 基准不变且 `Rev` 不变时，MORPH 的 `argmax` 选择与 R69 逐项相同，`J_MORPH ≡ J_FLUID`，在途替换区间为空。故 **R69 是 MORPH 在「不换中间层、不换材料/组件」边界上的严格退化**。

## 2. 关键算法骨架

```python
# IP-264 MMA：语义中介适配器（版本/副作用/幂等/带外抽头）
class MediationAdapter:
    def __init__(self, src, dst, pres, pre, side, ver, idem=False):
        self.src, self.dst, self.pres = src, dst, pres
        self.pre, self.side, self.ver, self.idem = pre, side, ver, idem

    def apply(self, x):
        if not self.pre(x):             raise ContractError
        if not self.attested(self.ver): raise VersionMismatch   # 拒绝静默降级
        y = self.forward(x)
        self.tap.emit(x, y, self.ver)   # 带外可观测，供账本守恒校验
        return y

# IP-266/265 PPL + LLG：组合保持剖面，损失单调累积
def compose_profile(p1, p2, invars):
    out = {}
    for i in invars:
        a, b = p1[i], p2[i]
        if a.lost or b.lost:                       out[i] = LOST
        elif a.exact and b.exact and implies(a.cond, b.pre):
            out[i] = EXACT
        else:                                      # 局部透明 ≠ 全局透明
            out[i] = LIPSCHITZ(a.delta + b.L2 * b.delta,
                               cond=inter(a.cond, b.cond))
    return out

def ledger_conserved(declared, observed, tol):
    return observed <= declared + tol              # 未声明漂移 -> 回滚

# IP-268 RPE：鲁棒性质包络（批间 + 老化 + 各向异性），禁用均值
def robust_margin(g, p_hat, eps_batch, eps_age, dirs):
    eps = eps_batch + eps_age
    return min(g(p_hat + dp, u)
               for dp in ball(eps) for u in dirs)  # 或 g(p_hat) - L*eps 的 Lipschitz 界

# IP-269/316 SMC：替换同态准入
def substitution_admissible(sigma, req, p_hat, eps, dirs):
    if not profile_ok(sigma.pres, req.invariants):       return False
    if robust_margin(sigma.g, p_hat, eps, dirs) < req.bound:
        return False                                     # 必须鲁棒占优
    if not rev_recompute_ok(sigma):                      return False
    if not fma_rebaseline_ok(sigma):                     return False
    if not attest_and_assay(sigma):                      return False
    return True

# IP-270 RPS：鲁棒 Pareto 选材
def robust_pareto_select(cands, req, eps, dirs):
    feasible = [m for m in cands if all(
        robust_margin(m.g[j], m.p_hat, eps, dirs) >= req[j] for j in req)]
    return pareto_front(feasible, key=lambda m: (m.cost, m.mass, m.risk))

# IP-271 RRV：可逆性随材料重算（不确定跨阈值即降级）
def recompute_rev(action, material, eps):
    lo, hi = energy_interval(action, material, eps)
    if hi <= material.elastic_limit:                      return R
    if lo > material.elastic_limit and action.compensable: return C
    return I                                             # 保守降级，触发确认

# IP-275 主闭环：R69 原样在前，中介与替换在后
def MORPH_round(M, obs, task):
    k, lam, mode, U = FLUID_RAS_round(M, obs)         # R69 完全保留
    mu = M.mma.negotiate(M.versions)                  # 版本/适配器认证
    if not M.ppl.pipeline_admissible(mu, task.invariants):
        return k, lam, mode, U                        # 中介不可证 => 不替换
    sigma = M.rps.select(task, M.materials)           # 鲁棒 Pareto
    if sigma is None or not M.smc.admissible(sigma, task):
        return k, lam, mode, U                        # 退回已认证 incumbent
    before = M.llg.snapshot()
    res = M.sbc.execute_with_rollback(sigma)          # 在途零信用 + 围堵
    if not M.llg.conserved(before, M.tap.observed(), TOL):
        M.sbc.rollback(sigma)                         # 丢失不可隐藏
        return k, lam, mode, U
    rev = M.rrv.recompute(task.actions, sigma.material)
    if rev is I and not task.owner_confirm():
        M.sbc.rollback(sigma); return k, lam, mode, U
    M.fma.rebaseline(sigma.material)                  # 行为似然基准重标定
    M.vqa.submit_async(sigma, M.llg, res)             # 参与式审计
    return k, lam, mode, U
```

## 3. 推导

**引理 19（保持剖面的组合界；局部透明 ≠ 全局透明）** 设语义状态空间带度量 `d`，二级适配器对 `d` 为 `L_2`-Lipschitz。则组合损失 `δ_{21} ≤ δ_1 + L_2 δ_2`（三角不等式）——这是「误差可加」的乐观界。但更强也更危险的是：若 `μ_2` 只在前提 `cond_2` 下保持不变式 `i`，而 `μ_1` 的输出不再满足 `cond_2`，即使 `μ_1`、`μ_2` 对各自声明的不变式均 EXACT，组合仍为 LOST。因此**组合保持剖面必须同时组合条件**；只合并状态会系统性地把「接缝失配」误判为安全。系：**中间件的危险不在单层，而在层的接缝**——R69「多源一致」若各源共享同一个偏置适配器，其一致性可能只是同一个语义错误的多次复制。

**引理 20（均值不可用于安全；鲁棒-名义间隙）** 若安全裕度 `g_j` 对性质向量在 `W`-范数下为 `L_j`-Lipschitz，则对不确定半径 `ε = ε_b + ε_age + ε_m` 有
`ḡ_j ≥ g_j(p̂) − L_j ε`，且存在材料使该界紧。于是用名义 `p̂` 判安全最多高估 `L_j ε`；存在候选满足名义约束却违反鲁棒约束（**鲁棒反转**）。系：**「平均性质合格」不是安全证据**；必须用鲁棒包络，且 `SF_j` 至少补偿 `L_j ε`。

**引理 21（替换的不可辨识性；材料版 Goodhart）** 若合格性只在有限载荷集 `U_test` 上测试，而性质 `p` 仅在 `U_test` 上被约束（或候选可被对抗性选择），则存在两个材料在 `U_test` 上输出完全相同、在 `U_hold` 上行为不同。故任何仅依赖 `U_test` 行为的证书对离样本/离方向行为**零功效**。独立性质化验 + 盲化留出载荷提供外部真值，抽查 `m` 次检出下界 `≥ 1−(1−p_a)^m`。系：**材料认证必须基于性质，而非仅基于任务通过**——这正是 R69 引理 18「单源投毒需正交证据」在材料域的重述。

**引理 22（老化单调性与证书过期）** `ε_age(t)` 单调不减 ⇒ `ḡ_j(t)` 单调不增。若替换在 `t_0` 对地平线 `T` 可采纳，则对一切 `t ≤ T` 可采纳；超过 `T` 未再认证则不得继续兑现安全信用。系：**材料安全是单向棘轮**，证书必须带过期时间，过期即回退。

**引理 23（FMA 基准的替换敏感性）** R69 的 `a_score = −log p_θ(ξ|o)` 以训练/标定时的本体与对象动力学为基准。材料替换改变被控对象动力学，使 `a_score` 的分布整体平移 `Δ_plant`；若不在替换后重标定基准，则 `Δa` 会把「换了材料」与「缓变故障」混淆。故替换准入必须包含 FMA 基准重标定，否则行为似然通道在替换后失去判别力。系：**第二意见本身也有前提**——它相信的是「物理底座未变」。

**定理 18（MORPH 严格包含 R69）** 在 R69 的 A95–A98 下，MORPH 在任意状态 `s` 的期望风险 ≤ R69；且当 `μ=id`、`σ=id`、性质已知、账本为空、FMA 基准不变时两者**逐指令相同**（定义 325）。恒等替换永远可采纳、回退永远安全，故安全侧不做任何让步，效率侧获得「可证替换」的收益。

**定理 19（中介安全 / 保持同态）** 若 (i) 每个适配器的保持剖面被认证；(ii) 组合剖面在 `I_req` 上可采纳且加权损失 ≤ 预算；(iii) 中间件版本/来源经证明、无未协商降级；(iv) 账本守恒（观测漂移 ≤ 声明上界）；则中介流水线保持 `I_req`，从而 R69 的证据更新与安全认证在其真实语义上成立。**这把 R69「证据可信」的隐含前提，拆成「每个适配器剖面可证 + 组合条件可证 + 账本守恒」三件可检查的事**——但信任根转移到剖面认证与证明根（见风险）。

**定理 20（鲁棒替换安全，含可逆性与 FMA 重标定）** 若替换 `σ: A→B` 满足定义 316（剖面可采纳、鲁棒包络占优、`Rev` 保守重算、FMA 基准重标定、独立化验通过、预算合规），则对一切 `p ∈ P(t)` 与一切 `t ≤ T`，替换后系统仍满足 G；且回退到 incumbent A 永远安全。故替换**不会削弱安全**，只可能改善效率/性能；`Rev` 的不确定跨越阈值时被保守降级，避免把脆性替换误判为可逆。

**定理 21（替换的单调回退与无突变）** 在替换被验证前的在途区间内，`λ ≥` R69 的 `λ_floor(U_ale+U_epi)`，holding policy 为 R69 兜底；替换失败、超时、账本失衡或化验未过 ⇒ `λ` 单调不降地回到该地板，回滚只作用于已声明的替换差异，不扩张安全包络；老化到期同理。故替换不破坏 R69 定理 17 的连续性——**替换只改变「用哪个已认证组件」，不改变安全包络本身**。

## 6. 本轮最大风险

**一句话**：MORPH-RAS 的全部安全性押在「保持剖面与材料证明是真的」这一前提上——**而当证书只覆盖被抽样的不变式/载荷时，一个替换可以通过全部认证却在未测维度上已降级（伪造数据表、批间调包、各向异性、适配器离样本语义漂移），系统于是用一张合法的「等价证书」为它背书；R69 说「问错比不问更危险」，R70 的对应句是「证明错比不证明更危险」——被证明的等价，可能只是被抽样到的等价。**

**次级风险与缓解**：
1. **剖面自证 / 条件漏组合** → 组合必须组合条件（引理 19），剖面需第三方认证，E302/E303；
2. **均值判安全 / 鲁棒反转** → 只用鲁棒包络 + `SF` 补偿 `L·ε`，绝不用名义值，E304/E305；
3. **行为测试的 Goodhart** → 独立性质化验 + 盲化留出 + 随机抽查，E308/E309；
4. **替换洗白与预算规避** → 账本单调传递 + 计划级预算 + 不可逆需确认，E310；
5. **FMA 基准被替换污染** → 替换即重标定 + 基准版本入证书，引理 23、E307；
6. **老化后证书仍被使用** → 证书带过期地平线 `T`，到期或 FMA 报警即回退，E313。

## 2. 形式化定义（要点版）

**定义 310（总览与六不变式）** 零学习写继承；无证书不替换（恒等永真）；丢失不可隐藏（账本单调传递）；鲁棒占优（禁用均值）；可逆性随实例重算；替换确认前零信用、失败单调回退。

**定义 311–312（中间件与保持剖面）** `μ` 为带 `(Pre,Pres,Side,ver,idem,tap)` 的适配器链，拒绝未协商版本；`Pres_σ(i)=(status,δ,cond)`，`I_req` 可采纳 ⟺ 无 LOST ∧ 条件成立 ∧ 加权损失 ≤ 预算；硬不变式要求 EXACT。R69 的「正交证据一致」= `EXACT ∧ cond=⊤ ∧ δ=0`。

**定义 313（丢失账本 LLG）** 账本单调（除非独立再认证）、传递（A→B→A 不清零）、守恒（观测漂移 ≤ 声明上界 + tol）；未声明损失即违规。

**定义 314–315（性质模型与鲁棒包络）** `p=(ρ,E,σ_y,K_IC,μ,α,…)`，方向依赖 `p(u)`；不确定集 `P(t)` 含批间/老化/噪声；`ḡ_j=min_{p∈P,u∈U} g_j`；要求 `ḡ_j ≥ g_j^req·SF_j`，名义 `p̂` 仅用于估计。

**定义 316（替换同态 SMC）** `σ:A→B` 可采纳 ⟺ 剖面可采纳 ∧ 鲁棒占优 ∧ Rev 保守重算 ∧ FMA 基准重标定 ∧ 证书+独立化验通过 ∧ 预算合规；否则执行 incumbent；恒等替换永真。

**定义 317（剖面组合 PPL）** 组合必须同时组合**条件**：两级各自 EXACT 仍可因 `cond_2` 被破坏而 LOST；有界时 `δ_{21} ≤ δ_1 + L_2 δ_2`。局部透明不蕴含全局透明；共享偏置适配器的多源一致可能只是同一错误的多份复制。

**定义 318（鲁棒 Pareto RPS）** `F_rob` 上做 Pareto；`F_rob ⊆ F_nom`，名义 Pareto 最优可能鲁棒不可行；选中候选仍须经 SMC。

**定义 319（可逆性重算 RRV）** `Rev_a(m)` 由最坏弹性储能与补偿能力决定；不确定跨越 R/C、C/I 阈值即保守降级；`Rev=I` 的接触须显式确认。

**定义 320–321（证书与威胁模型）** `J_MORPH` 并入剖面、账本、性质/批次/老化、鲁棒裕度、Rev、FMA 重标定、化验、替换日志；`ℰ_MORPH=ℰ_FLUID×ℰ_sub` 覆盖假冒/虚标/调包/旧料/各向异性/供应链/语义漂移/静默降级/等价伪装/洗白。

**定义 322–324（独立化验 / 替换预算 / 老化）** 行为测试是输出-only，必须加性质化验 + 盲化留出 + 证明，检出 `≥1−(1−p_a)^m`；在途未验证替换 ≤ 1，不可逆需确认，按计划级核算；`ε_age(t)` 单调 ⇒ 证书带地平线 `T`，过期或 FMA 报警即回退。

**定义 325（严格退化）** `μ=id`、`σ=id`、性质已知、账本空、FMA 基准不变时，MORPH ≡ R69，`J_MORPH ≡ J_FLUID`，在途替换区间为空。

## 3. 关键算法伪代码

```python
# IP-264 MMA：语义中介适配器（版本/副作用/幂等/带外抽头）
class MediationAdapter:
    def __init__(self, src, dst, pres, pre, side, ver, idem=False):
        self.src, self.dst, self.pres = src, dst, pres
        self.pre, self.side, self.ver, self.idem = pre, side, ver, idem

    def apply(self, x):
        if not self.pre(x):             raise ContractError
        if not self.attested(self.ver): raise VersionMismatch   # 拒绝静默降级
        y = self.forward(x)
        self.tap.emit(x, y, self.ver)   # 带外可观测，供账本守恒校验
        return y

# IP-266/265 PPL + LLG：组合保持剖面，损失单调累积
def compose_profile(p1, p2, invars):
    out = {}
    for i in invars:
        a, b = p1[i], p2[i]
        if a.lost or b.lost:                       out[i] = LOST
        elif a.exact and b.exact and implies(a.cond, b.pre):
            out[i] = EXACT
        else:                                      # 局部透明 ≠ 全局透明
            out[i] = LIPSCHITZ(a.delta + b.L2 * b.delta,
                               cond=inter(a.cond, b.cond))
    return out

def ledger_conserved(declared, observed, tol):
    return observed <= declared + tol              # 未声明漂移 -> 回滚

# IP-268 RPE：鲁棒性质包络（批间 + 老化 + 各向异性），禁用均值
def robust_margin(g, p_hat, eps_batch, eps_age, dirs):
    eps = eps_batch + eps_age
    return min(g(p_hat + dp, u)
               for dp in ball(eps) for u in dirs)  # 或 g(p_hat) - L*eps 的 Lipschitz 界

# IP-269/316 SMC：替换同态准入
def substitution_admissible(sigma, req, p_hat, eps, dirs):
    if not profile_ok(sigma.pres, req.invariants):       return False
    if robust_margin(sigma.g, p_hat, eps, dirs) < req.bound:
        return False                                     # 必须鲁棒占优
    if not rev_recompute_ok(sigma):                      return False
    if not fma_rebaseline_ok(sigma):                     return False
    if not attest_and_assay(sigma):                      return False
    return True

# IP-270 RPS：鲁棒 Pareto 选材
def robust_pareto_select(cands, req, eps, dirs):
    feasible = [m for m in cands if all(
        robust_margin(m.g[j], m.p_hat, eps, dirs) >= req[j] for j in req)]
    return pareto_front(feasible, key=lambda m: (m.cost, m.mass, m.risk))

# IP-271 RRV：可逆性随材料重算（不确定跨阈值即降级）
def recompute_rev(action, material, eps):
    lo, hi = energy_interval(action, material, eps)
    if hi <= material.elastic_limit:                      return R
    if lo > material.elastic_limit and action.compensable: return C
    return I                                             # 保守降级，触发确认

# IP-275 主闭环：R69 原样在前，中介与替换在后
def MORPH_round(M, obs, task):
    k, lam, mode, U = FLUID_RAS_round(M, obs)          # R69 完全保留
    mu = M.mma.negotiate(M.versions)                   # 版本/适配器认证
    if not M.ppl.pipeline_admissible(mu, task.invariants):
        return k, lam, mode, U                         # 中介不可证 => 不替换
    sigma = M.rps.select(task, M.materials)            # 鲁棒 Pareto
    if sigma is None or not M.smc.admissible(sigma, task):
        return k, lam, mode, U                         # 退回已认证 incumbent
    before = M.llg.snapshot()
    res = M.sbc.execute_with_rollback(sigma)           # 在途零信用 + 围堵
    if not M.llg.conserved(before, M.tap.observed(), TOL):
        M.sbc.rollback(sigma)                          # 丢失不可隐藏
        return k, lam, mode, U
    rev = M.rrv.recompute(task.actions, sigma.material)
    if rev is I and not task.owner_confirm():
        M.sbc.rollback(sigma); return k, lam, mode, U
    M.fma.rebaseline(sigma.material)                   # 行为似然基准重标定
    M.vqa.submit_async(sigma, M.llg, res)
    return k, lam, mode, U
```

## 4. 推导

**引理 19（保持剖面组合界；局部透明 ≠ 全局透明）** 二级适配器 `L_2`-Lipschitz 时 `δ_{21} ≤ δ_1 + L_2 δ_2`。但若 `μ_2` 只在 `cond_2` 下保持 `i`，而 `μ_1` 输出破坏 `cond_2`，即使两级对各自声明不变式均 EXACT，组合仍 LOST。故组合必须组合条件；中间件的危险在接缝，且 R69 的多源一致若共享同一偏置适配器，只是同一语义错误的多次复制。

**引理 20（均值不可用于安全；鲁棒-名义间隙）** `g_j` 为 `L_j`-Lipschitz 时 `ḡ_j ≥ g_j(p̂) − L_j ε` 且界可紧。用名义 `p̂` 最多高估 `L_j ε`，存在名义可行而鲁棒不可行的候选（鲁棒反转）。故 `SF_j` 至少补偿 `L_j ε`，禁用均值判安全。

**引理 21（替换不可辨识性；材料版 Goodhart）** 若只在有限 `U_test` 上测试且 `p` 仅在该集被约束（或候选可对抗选择），则存在材料在 `U_test` 输出相同、在 `U_hold` 行为不同；测试-only 证书对离样本行为零功效。独立性质化验 + 盲化留出给出外部真值，检出 `≥1−(1−p_a)^m`。系：材料认证必须基于性质，而非仅任务通过——R69 引理 18「单源投毒需正交证据」的材料域重述。

**引理 22（老化单调性与证书过期）** `ε_age(t)` 单调不减 ⇒ `ḡ_j(t)` 单调不增；在 `t_0` 对地平线 `T` 可采纳只保证 `t ≤ T`；超期未再认证不得兑现安全信用。材料安全是单向棘轮，证书必须带过期时间。

**引理 23（FMA 基准的替换敏感性）** `a_score=−log p_θ(ξ|o)` 以标定时的本体/对象动力学为基准；材料替换使分布平移 `Δ_plant`。若不重标定，`Δa` 会把「换了材料」与「缓变故障」混淆，行为似然通道在替换后失去判别力。故替换准入必须含 FMA 基准重标定——第二意见也有前提：它相信物理底座未变。

**定理 18（MORPH 严格包含 R69）** R69 的 A95–A98 下期望风险 ≤ R69；`μ=id、σ=id、性质已知、账本空、FMA 基准不变`时逐指令相同。恒等替换永远可采纳、回退永远安全，故安全不让步，效率获可证替换收益。

**定理 19（中介安全 / 保持同态）** 适配器剖面被认证 ∧ 组合剖面在 `I_req` 可采纳且损失 ≤ 预算 ∧ 版本/来源已证明 ∧ 账本守恒 ⇒ 中介流水线保持 `I_req`，R69 的证据更新与安全认证在其真实语义上成立。这把 R69「证据可信」拆成「剖面可证 + 条件可证 + 账本守恒」三件可检查的事；信任根转移到剖面认证与证明根（见风险）。

**定理 20（鲁棒替换安全，含可逆性与 FMA 重标定）** 若 σ 满足定义 316，则对一切 `p∈P(t)`、`t≤T`，替换后仍满足 G；回退 incumbent 永远安全。替换不削弱安全，只可能改善效率；Rev 不确定跨阈值时被保守降级，避免把脆性替换误判为可逆。

**定理 21（替换单调回退与无突变）** 在途区间 `λ ≥` R69 的 `λ_floor(U_ale+U_epi)`、holding policy 为 R69；失败/超时/账本失衡/化验未过 ⇒ λ 单调不降回地板，回滚只作用于已声明替换差异、不扩张安全包络；老化到期同理。替换只改变「用哪个已认证组件」，不改变安全包络。

## 7. 本轮最大风险

**一句话**：MORPH-RAS 的全部安全性押在「保持剖面与材料证明是真的」这一前提上——**当证书只覆盖被抽样的不变式/载荷时，一个替换可以通过全部认证却在未测维度上已降级（伪造数据表、批间调包、各向异性、适配器离样本语义漂移），系统于是用一张合法的「等价证书」为它背书；R69 说「问错比不问更危险」，R70 的对应句是「证明错比不证明更危险」——被证明的等价，可能只是被抽样到的等价。**

**次级风险与缓解**：剖面自证/条件漏组合（组合条件 + 第三方认证 + E302/E303）；均值判安全/鲁棒反转（鲁棒包络 + `SF` 补偿 `L·ε`，E304/E305）；行为测试 Goodhart（独立性质化验 + 盲化留出 + 抽查，E308/E309）；替换洗白与预算规避（账本单调传递 + 计划级预算 + 不可逆需确认，E310）；FMA 基准被替换污染（替换即重标定 + 基准版本入证书，引理 23、E307）；老化后仍用旧证书（证书带地平线 `T`，到期或 FMA 报警即回退，E313）。
