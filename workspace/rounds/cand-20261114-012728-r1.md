# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配×主动交互不确定性二分闭环」IP-253~263；本轮灵感：「大语言模型」×「开源软件」）

> R69 让闭环第一次学会「问」：把 epistemic 歧义交给看、问、触，用 VoI 判断值不值得问，并用「k 个正交证据一致」防止单源定案。但它对「答案」的信任模型仍然很薄：**证据纪律只数来源个数，不检查答案内部是否可追溯、可复现、可撤回**。一条来自大语言模型或人类的、听上去完全合理的回答，只要凑够两个「正交」源，就会被盖上「已验证」的章——而这两个源可能共享同一个幻觉、同一次投毒、同一个训练语料。
>
> 本轮两个灵感正好从两个方向补这块：
> - **大语言模型**是典型的「会说不会看」的非观测性先验：它能把歧义命名、把假设写清楚、把「该看哪里」说出来，但它对当前世界零观测。把它当神谕，幻觉会被放大；把它当**假设编译器**，它才安全。
> - **开源软件**给出一种与权威无关的信任范式：代码可信不是因为作者有名，而是因为**可检查（diff）、可复现（reproducible build）、可依赖追踪（SBOM）、可 fork、可撤销（revocation）**。把这条范式搬到「信念」上，正好是 R69 缺的那一层治理。
>
> 核心命题：**把每一条非观测性知识来源（LLM 先验、人类回答、检索记忆）都当作一个不受信任的第三方依赖；epistemic 不确定性不能靠「相信一个答案」消除，只能靠把答案编译成一个预注册、可区分竞争假设、可确定性重放的实验，实验通过才允许 merge；冲突的信念保留为并行 fork，按最坏分支运行；来源失效时可沿依赖图撤销并回退；来源独立性/多样性是与算力同级的稀缺安全预算。** 命名 **FORGE-RAS**（Forkable, Observable, Reproducible, Governed Epistemics for Risk-adaptive Systems）——既是「软件 forge（GitHub/GitLab 式协作平台）」，也是「把信任锻造出来」。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我拿到的这个答案，能不能被追溯、被复现、被 fork 掉**」——信任不是对来源的感觉，而是一个可复现产物的属性。

## 0. 直觉与动机

**灵感 1（大语言模型 = 扶手椅专家，强在提假设、弱在接地）**
直觉：R69 的信息来源只有传感器和（可能存在的）人。LLM 插入的是第三种东西：一份被压缩进参数的人类知识/语言先验。它不需要观测就能说「这可能是一扇玻璃门」「他这句话可能是在客气」「这个抓取失败通常是因为重心偏了」。这非常有价值——它能把 R69 里一团模糊的 U_epi **命名**成一个具体的竞争假设集合。但它的致命弱点同样清楚：**它没有当前世界的观测通道**，它说的「可能」是语料里的统计回声，不是此刻的证据。所以正确的用法不是问它「现在是什么」，而是问它「**要区分这几种可能，我该去看什么、看多久、什么结果算哪种**」。把 LLM 从 oracle 降级为 hypothesis compiler，是本轮第一根支柱。

**灵感 2（开源软件 = 信任来自可检验的产物，不来自权威）**
直觉：开源世界里没人因为「这是某大牛写的」就信任一段代码；信任来自你能读 diff、能跑测试、能复现构建、能在它出错时 fork 掉它。R69 的失效模式恰好是反过来的：一条流畅的回答 + 一个自信的语气 + 一个「正交」来源，就被当成结论。开源范式给的解药是：**把「回答」降级为一次 pull request，把「结论」升级为一次 CI 通过**。语言回答是散文，不可审计；编译后的实验才是 diff，可审计。这条直觉直接对准 R69 自陈的最大风险——「把误导性回答盖上已验证的章」。

**灵感 3（可证伪编译 = claim → diff，LLM 的最佳岗位是写测试）**
直觉：一个 claim 只有能改变某个可观测量，才是可证伪的；否则它只是叙事。开源里一个 PR 之所以能被 review，是因为它给出具体的 diff 和可运行的测试。于是 FORGE 的核心动作是 **Claim Compilation**：LLM 输出 `(主张 φ, 竞争假设 ¬φ)`，再由它（或独立方）写出 `(信息动作 g, 观测量 y, 预注册判定规则 π, 成本界 δ)`；只有当在 π 下观测结果能区分 φ 与 ¬φ 时，这个 claim 才有资格进入 CI。**LLM 写得最好的是测试，而不是结论**——这是对它能力边界的诚实利用。

**灵感 4（供应链安全 / SBOM / fork / revocation = 知识的纵向治理）**
直觉：开源最深刻的贡献不只在「开放」，更在「依赖是可见的」。一条信念可能依赖于某个模型版本、某次标定、某个人的回答；当其中任一被later 发现有问题时，你需要 **SBOM（这里叫 BBOM，Belief Bill of Materials）+ 污染传播 + 回退**。而面对两个都合理、暂时无法判定的信念，开源的做法不是取平均，而是开两个 branch：**fork 并存，按最坏分支运行**，等一个能区分的测试出现再 merge。这把 R69 的「k 源一致」从一次性的投票，升级成有版本、有依赖、有撤销、有分支的**纵向生命周期**——这是 R69 完全没有的时间维度安全性。

**灵感 5（多眼原则的陷阱 = 独立性是稀缺资源，单一栽培是系统性风险）**
直觉：开源箴言「given enough eyeballs, all bugs are shallow」有一个常被忽略的前提：**眼睛必须相互独立**。同一基座模型的多个 reviewer 会以极高相关（ρ→1）的方式一起幻觉；一个机队共用同一个 LLM 先验，就是把一次幻觉变成跨机队的**认识论单一栽培（epistemic monoculture）**。于是「多问几个」可能只是给同一个错误投了多张票，制造虚假的安心。R69 的「k 个正交证据」必须配一个**可测的独立性指标**，否则「正交」只是口号。多样性（不同模型族、人类、物理实验）因此不是锦上添花，而是与算力同级的**安全预算**。

**综合命题**：R69 把不确定性分成「不可约」与「可约」，并给可约的歧义配了「问」这个动作；FORGE 追一层——**「问到的答案凭什么算数」**。答案本身永远只是输入，实验通过才是结论。这样 R69 不是被推翻，而是被包含为「所有 claim 都不可证伪 / 来源不可信 / 无预算验证」的退化边界（此时只剩 R68 的保守）。

## 1. 形式化定义（增量：定义 310–323）

**定义 310（FORGE-RAS 总览与三不变式）** FORGE-RAS = (KSB, CCL, BCI, BOM, FORK, REV, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i），且实时环路**不含任何 LLM 推理**（定义 323 的构建/运行分离）；
(ii) **无预注册验证不 merge**：任何非观测性 claim 只能作为实验的输入，不能作为信念的输出；单源（无论多自信、多有权威）不得直接定案；
(iii) **信念可追溯、可复现、可撤销**：每条信念携带 provenance 与依赖边，任何被污染的来源可在有界时间内沿 BOM 传播并回退到最后一个已验证版本。

**定义 311（知识源与声明）** 知识源 s ∈ S = {LLM, human, memory, geometry}。一条声明 c = (φ, s, κ, prov)，其中 φ 为关于世界/策略的命题（自然语言或符号），κ 为来源自报置信（**不当作概率使用**），prov 为来源记录。核心立场：κ 与来源身份不进入可信度计算，只进入「是否需要更多验证」的预算。

**定义 312（来源记录与 BBOM）** prov(c) = (source_id, version_hash, timestamp, context_hash, dependency_set, liability_class, attestation)。信念依赖图 G_B = (V_B, E_dep) 是一张有向无环图；BBOM 是 G_B 的根哈希快照。BBOM 支持两类查询：向下「这条信念依赖了什么」，向上「哪些信念会因为某个来源失效而受污染」。

**定义 313（可证伪编译 CCL）** 声明编译器 CCL 把 c 映射为实验规格 e = (g, y, π, δ, alt)：g ∈ 𝒜_info 复用 R69 的信息动作（看/触/问/等），y 为观测量取值空间，π 为**在看到数据之前固定**的判定规则，δ 为成本/时延上界，alt 为显式列出的竞争假设。**可证伪性要求**：存在 y 使得 π(y, c) ≠ π(y, alt)；否则 c 被判为不可编译的叙事，直接拒绝（不进入 CI）。e 就是 claim 的「diff」。

**定义 314（信念 CI：BCI）** BCI 在 C-RAS-WM† 认证下执行 e 得到 y，按预注册 π 给出裁决 v ∈ {support, refute, inconclusive}。仅当 v=support、检验功效 ≥ β、且满足 R69 定义 293-iii 的独立证据纪律时，才允许 update_belief。inconclusive ⇒ 不改变信念，走 R69 兜底。

**定义 315（证明携带的信念与重放）** 信念 b = (φ, v, e_hash, y_hash, π_hash, verifier_id, versions) 是**可采纳的**，当且仅当它能由（观测日志、标定版本、策略版本、来源版本）**确定性重放**并得到同一裁决。重放不一致 ⇒ 信念立即失效（可复现性失败），并按定义 319 处理。

**定义 316（分叉 Fork 与合并 Merge）** 当两条 claim 冲突或检验不可判时，二者作为分支 b_A、b_B **并存**，各自携带独立的风险预算，**严禁对其参数或模态权重取平均**。控制器必须在所有存活分支上按**最坏分支**运行（max 风险）。仅当一个能区分二者的测试 e* 通过时才 merge；fork 在合并前一直存在。`select_mode` 因此从「选一个模态」变成「在一个分支集合上求最坏安全包络」。

**定义 317（信任责任等级与风险上限）** 不用标量 trust，而用责任等级 L(b) ∈ {verified, attested, unverified}：verified 有可重放的通过证书；attested 有来源证明但无独立重放；unverified 仅有自报置信。等级映射到**允许的风险缩放上限**：unverified 的 claim 不得把 λ 放松到 R68 下界以下；LLM 默认 unverified（即使 κ 很高）。来源版本变更（语义版本 bump）自动使依赖它的信念降级。

**定义 318（评审独立性与有效眼数）** 评审者集合 R 的错误相关矩阵 ρ_ij 由已知答案探针估计。有效独立评审数 n_eff = 1 + Σ_{i<j}(1−ρ_ij)/(n−1) 的截断形式（或简化为 n_eff ≈ 1/(1−ρ̄)）。只有 n_eff ≥ k 的评审才计入 R69 的正交证据；同一基座模型的不同 prompt/温度**不计入**独立源。「多眼」的信任信用按 n_eff 折扣，ρ→1 时折扣为 1（等于只看一眼）。

**定义 319（撤销与污染传播 REV）** 若来源 (s, v) 被证实有缺陷或被投毒，所有在 BOM 中依赖 (s, v) 的信念被标记 tainted；tainted 信念回退到最近一个 verified 版本，并在重验证完成前把 λ 抬到 R68 保守下界。撤销沿 G_B 传递，传播深度和扇出必须有界（A102），回退在 T_rev 内完成。

**定义 320（编译感知的 VoI）** 扩展 R69 定义 298：
VoI_FORGE(c) = [H(M|o) − E_{y~p(·|CCL(c),o)} H(M|o,y)] − c(g) − c_compile(c) − c_verify(c)，
且**仅当 CCL(c) 可区分 alt、来源等级允许、且在预算内**才计入候选。若 max VoI_FORGE ≤ 0，则不查询、不交互，退化为 R69/R68。系：**不可证伪的 claim 价值恒为 0 而成本为正，故永不查询**——这是「只问那些答案能改变你想法的问题」的形式化。

**定义 321（知识供应链威胁模型 ℰ_FORGE）** ℰ_FORGE = ℰ_FLUID × ℰ_supply，其中 ℰ_supply 含：提示注入（观测/人类回答中夹带指令）、语料投毒（LLM 先验在特定概念上的系统性偏差）、provenance 伪造（伪造来源记录与哈希）、近似重复 claim（typosquat 式混淆）、test-washing（自证测试：由 claim 来源自己写测试并自己解释结果）、评审共谋（相关评审者制造虚假多眼）。

**定义 322（证书 J_FORGE）** J_FORGE = (J_FLUID, bom_root_hash, cc_discrimination_rate, replay_pass, revocation_depth, reviewer_independence_rho, unverified_dependency_count, forge_ver)。Valid ⇔ Valid(J_FLUID) ∧ replay_pass ∧ 无 unverified 依赖用于放松 λ ∧ 撤销在 T_rev 内完成 ∧ cc_discrimination_rate ≥ τ_disc。

**定义 323（构建期/运行期分离）** FORGE 是异步「信念构建系统」，不是控制器：claim 编译、CI 执行、重放、撤销都在慢环完成，产物是被预先验证的**信念快照**；实时环只读取快照，做 O(1) 的等级查表与最坏分支 enveloping。因此 R69 的实时预算不变式（P99 < 2.6ms）与 R68 的零写不变式都不被 LLM 延迟击穿。

## 2. 关键算法骨架

```python
# IP-264 KSB + IP-265 CCL：把 claim 编译成预注册的可证伪实验（慢环 / 异步）
class ClaimCompiler:
    def compile(self, claim, o_t, budget):
        alts = self.llm.propose_alternatives(claim)            # 只生成假设，不裁决
        if not alts:
            return None                                        # 不可证伪的叙事，拒绝
        spec = self.llm.propose_experiment(claim, alts, o_t)   # (g, y, alt)
        e = pre_register(spec, pi=spec.rule, delta=budget.max_cost)  # 阈值先固定
        if not discriminates(e, claim, alts):                  # 必须能分开 φ 与 ¬φ
            return None
        if not self.c_ras_wm.certify_info(e.g, o_t):
            return None
        return e

# IP-266 BCI + IP-267 BOM：执行、裁决、写依赖（只有通过才 merge）
def belief_ci(e, source, bom, budget):
    if not budget.allow(e):                return Verdict.INCONCLUSIVE
    y = execute_under_cert(e.g, e.y)        # 复用 R69 信息动作 + 认证
    v = apply_preregistered(e.pi, y)        # 先注册、后观测，防 p-hacking
    if v is Verdict.SUPPORT and source.independent_evidence() >= 2:
        b = Belief(e.claim, v, hash(e), hash(y), source.id)
        bom.add(b, deps=source.provenance_deps)      # 写依赖边
        return b
    return v

# IP-268/269 FORK + 多眼独立性：冲突不平均，按最坏分支运行
def fork_merge(beliefs, new_b, reviewers):
    for old in beliefs:
        if contradicts(old, new_b):
            if discriminating_test(old, new_b) is None:
                return keep_fork(old, new_b)     # 并存，最坏分支 envelope
            else:
                return merge_on_test(old, new_b)
    n_eff = effective_independent_count(reviewers, rho_hat)  # 同基座模型 rho~1
    if n_eff < 2:
        new_b.level = Level.UNVERIFIED           # 多眼不给信用
    return beliefs + [new_b]

# IP-271 REV：撤销沿 BBOM 传递，回到最后 verified
def revoke(source_id, version, bom):
    tainted = bom.descendants(source_id, version)         # 有界深度/扇出
    for b in tainted:
        b.level = Level.TAINTED
        rollback_to_last_verified(b)
    return max(bom.beliefs, key=risk)                     # 期间按最坏分支运行

# IP-274 主闭环：实时环只消费已验证快照，不调用 LLM
def FORGE_RAS_round(M, obs):
    z, o = M.mtm.forward(...)
    snap  = M.forge.snapshot(o)                # O(1)：已构建的信念快照
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, snap.K), z, M.fmp.mode_head)
    # 只有 verified/attested 且可编译的 claim 才能影响模态先验
    prior = snap.admissible_prior()            # unverified 不入 prior
    U_epi = snap.shrink(U_epi, prior)          # 只是先验收缩，不是证据
    g = M.mint.choose_interaction(modes, o, M.budget) if U_epi > TAU_EPI else None
    if g is not None:
        M.forge.submit_async(g, snap)          # 慢环编译 + CI，绝不阻塞实时环
    # 最坏分支 envelope：冲突信念未被 merge 时按更危险的一支运行
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (U_epi if g is None else 0.0)))
    lam = max(lam, snap.worst_branch_floor())  # fork 存在时抬到 R68 保守
    if snap.has_tainted():
        lam = max(lam, 0.8)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    mode = snap.select_mode(modes, lam)        # 只选所有分支都安全的模态
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    return k, lam, mode, (U_ale, U_epi)
```

## 3. 推导

**引理 19（可证伪性给出 VoI 的硬上界）** 设 claim φ 与竞争假设 ¬φ 在实验 e 下的观测分布为 p(y|φ,e)、p(y|¬φ,e)。则任何基于 e 的消歧所能带来的互信息 I(M;y) ≤ ½‖p(·|φ,e) − p(·|¬φ,e)‖_TV，故 VoI_FORGE(e) ≤ ½ TV·(模态熵的 Lipschitz 常数) − c(e)。当 TV=0（两种假设预测完全相同的观测）时 VoI=0。系：**不可区分 = 不可消歧 = 不该问**；R69 里那些「熵很大但问什么都一样」的歧义，其实是伪价值，FORGE 把它们标成零。

**引理 20（置信度与权威无关性）** 在 A99（预注册）与 A100（确定性重放）下，信念的可采纳性只是 (e, y, π, versions) 的函数，与来源自报置信 κ、来源身份、语气流畅度无关。形式化：若两条 claim 编译出同一 e 且得到同一 y，则它们获得同一裁决，无论来源是 LLM、专家还是检索记忆。系：**「听起来很确定」不进入信任计算**——这是对 R69 最大风险（自信回答被盖章）的形式解。

**引理 21（多眼独立性折扣）** 设每个评审者的假接受率为 δ、两两错误相关为 ρ。多数投票的假接受率 ≤ δ·ρ^{⌊(n−1)/2⌋} + ε_σ；当 ρ→1 时上界退化为 δ，**增加评审者不产生任何可信度增益**。定义有效独立眼数 n_eff，使 n_eff 个完全独立的评审者达到同等上界；同基座模型 n_eff ≈ 1。系：R69 的「k 个正交源」必须用 n_eff 而非人数计数，否则「多问几个」只是给同一幻觉投多张票。

**定理 18（FORGE 严格包含 R69）** 在 A99–A101 下，FORGE 在任意状态的期望风险 ≤ R69；且当所有候选 claim 都不可编译（引理 19 的 TV=0）、来源等级为 unverified、或编译/验证预算不足时，FORGE 的决策与 R69 **逐指令相同**（退回 R69 的 VoI；再无可交互则退 R68）。故 R69 = FORGE 在「所有答案都免检」边界上的退化：**验证只在能降低错误信念时才介入，不能降低时不做任何额外让步**。

**定理 19（分叉的最坏分支安全性）** 若冲突信念在 merge 前按 max-risk 分支运行，则即使其中一支完全错误，控制输出的风险不超过「已知该支错误」时的风险；即 fork 不会因为信念不确定而低于 R68 的安全下界。合并只可能移除一个风险分支、不会新增模态，故风险单调不增。系：**不确定时不是取平均（会落在两支都不安全的中间），而是走更危险的那支的保守包络**。

**定理 20（撤销的有界污染）** 在 A102（BOM 深度 ≤ d、扇出 ≤ f）下，单个来源 (s,v) 被投毒后，受影响信念数 ≤ f^d；REV 在 T_rev 内把所有 tainted 信念回退到最后一个 verified 版本，此后 λ 回到 R68 下界。故单源投毒对安全侧的影响有界，且不能通过「依赖链」无限放大。与引理 21 合并：认识论单一栽培的危害，被 n_eff 折扣与 BOM 撤销共同限幅。

**定理 21（反 test-washing 的条件）** 若测试 π 由**独立于 claim 来源**的一方预注册（A99），则通过测试后的假接受率 ≤ 测试自身的假阳性率 α，与 claim 的先验可信度无关；若允许来源自写测试并自释结果，则该上界失效（来源可构造只检验自身假设的 π）。系：**自证是 FORGE 唯一的致命构造漏洞**——必须把「提出 claim」与「设计/解释测试」在制度上分离（不同模型族、人类或物理实验）。

## 6. 本轮最大风险

**一句话**：FORGE 的全部安全性押在「**提出 claim 的人/模型**」与「**设计并解释测试的人/模型**」真正独立这一制度前提上——一旦同一个 LLM 既写假设、又写测试、又解释结果（或测试本身编码了 claim 的假设），系统就会产出一个**自证闭环**：CI 永远通过，provenance 完整、重放一致、证书漂亮，而它验证的只是自己的叙事；这比 R69 的「诚实的不知道」更危险，因为它把不确定性洗成了**有证书的确定性**——**假的可复现，比不可复现更可信，也更难被推翻**。

**次级风险与缓解**：多眼虚假独立（定义 318 的 n_eff 折扣 + 跨模型族/人类/物理正交）；LLM 延迟击穿实时环（定义 323 构建/运行分离，实时环零 LLM）；BOM 无限增长与撤销爆炸（深度/扇出上界 + 快照压缩）；来源伪装与 typosquat（内容哈希 + 语义去重）；分歧长期 fork 导致过度保守（VoI 优先驱动能区分分支的测试，给 fork 收敛预算）。

## 4. 推导

**引理 19（可证伪性 = VoI 上界）** 实验 e 对 φ vs ¬φ 的消歧互信息 ≤ ½‖p(·|φ,e)−p(·|¬φ,e)‖_TV；TV=0 ⇒ VoI=0。系：不可区分的歧义是伪价值，FORGE 标零、不查询。

**引理 20（置信度与权威无关性）** A99/A100 下，可采纳性只是 `(e,y,π,versions)` 的函数，与来源自报置信、身份、语气无关。系：自信回答不能买信任。

**引理 21（多眼独立性折扣）** 假接受率 ≤ δ·ρ^{⌊(n−1)/2⌋}+ε_σ；ρ→1 时无增益。同基座模型 n_eff≈1，不计入正交证据。

**定理 18（严格包含 R69）** 任意状态期望风险 ≤ R69；所有 claim 不可编译/未验证/预算不足时，与 R69 逐指令相同（再退 R68）。R69 = 「所有答案免检」边界。

**定理 19（fork 最坏分支安全）** 冲突信念按 max-risk envelope 运行，即使一支全错也不低于 R68 下界；merge 只移除风险分支，风险单调不增。禁平均，因为平均会落进两支都不安全的中间。

**定理 20（撤销有界污染）** BOM 深度≤d、扇出≤f 时，单源投毒影响 ≤ f^d；REV 在 T_rev 内回退，λ 回 R68。单一栽培危害被 n_eff 折扣与 BOM 撤销共同限幅。

**定理 21（反 test-washing 条件）** 测试由独立于 claim 来源的一方预注册时，通过后假接受率 ≤ 测试 α，与 claim 先验无关；来源自写测试并自释结果时上界失效。系：必须制度性分离「提 claim」与「设计/解释测试」。

## 7. 本轮最大风险

**一句话**：FORGE 的安全性依赖「**提出 claim 的一方**」与「**设计并解释测试的一方**」真正独立——若同一个 LLM 既写假设、又写测试、又解释结果，系统会形成自证闭环：CI 永远通过、provenance 完整、重放一致、证书漂亮，而它验证的只是自己的叙事；这比 R69 的「诚实的不知道」更危险，因为它把不确定性洗成了**有证书的确定性**——**假的可复现，比不可复现更可信，也更难被推翻**。

**次级风险与缓解**：多眼虚假独立（n_eff 折扣 + 跨模型族/人类/物理正交）；LLM 延迟击穿实时环（构建/运行分离，实时环零 LLM）；BOM 膨胀与撤销爆炸（深度/扇出上界 + 快照压缩）；来源伪装与 typosquat（内容哈希 + 语义去重）；长期 fork 过度保守（用 VoI 优先驱动能区分分支的测试，给 fork 收敛预算）。
