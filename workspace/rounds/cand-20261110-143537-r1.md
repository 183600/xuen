# 第 45 轮（承接第 44 轮 v21；本轮灵感：机器人操作系统 × 产学研合作） · ROS-Cert × Fed-Cert：把「证书」从节点内对象升级为「端到端运行时契约 + 跨机构联合签署」（四层架构 v10）

> 承接第 44 轮 v21（Pose-Cert × Data-Cert）。v21 把姿态升为根信任并给出可审计数据闭环，其自陈最大风险是「审计集与采集策略不独立 → Goodhart」。但 v21 与整个 v19–v21 证书栈仍共享一个未言明假设：**(H4) 证书所依赖的证据，在到达消费节点时是新鲜、完整、保序、时钟一致、来自预期生产者的，且这些节点与链路由同一可信主体控制**。现实中 UniBot 跑在 ROS 2/DDS 上：QoS 可被默认或运行时降为 best-effort、history 深度有限、执行器共享线程池、TF 与时钟会外推/跳变、节点会重启并重放旧状态、参数可在线漂移、计算图可动态重组；而**产学研**意味着传感器、算法、数据、审计来自不同机构，各自只对局部负责。两个灵感词精确命中 H4：**机器人操作系统**迫使我们把证书从「节点内对象」升级为**沿 ROS 计算图的端到端传输契约与可调度性契约**；**产学研合作**迫使我们把「谁有权为哪条声明签字」升级为**职责分离的联邦认证与来源清单**。二者耦合出本轮真正的新问题：**端到端证书的 soundness 跨越多个机构拥有的节点与链路，而审计方常常既不拥有链路也不控制调度——若路径监控器本身寄生在同一不可信中间件上，或职责分离退化为「签字仪式」，整条证书链会静默失效**。

## 0. 直觉与动机

**灵感 1（机器人操作系统 → 证书是一条「路径」，不是一堆「节点」）**
直觉：ROS 2 的计算图是分布式的 pub/sub。一个安全结论从双目相机到最终刹车，要经过发布者序列化 → DDS 传输 → 订阅者反序列化 → 执行器调度 → 谓词求值。每一跳都可能丢包、延迟、乱序、时钟错位、被低优先级的 VLM/检索回调饿死。节点内的证书再完美，只要最后一步在 D_safe 之后才跑出来，它就不是「当前」的结论。因此要把证书写成一条**证书路径** P_c：只有 (a) 每跳本地证书在其证据时刻 sound、(b) 每跳传输契约成立、(c) 证据仍在新鲜度预算内、(d) 决策回调可调度，四者同时成立，端到端证书才 sound。任何一跳违约，整条路径 fail-closed，而不是「局部降级后继续用」。

**灵感 2（产学研 → 信任不是「信某个机构」，而是「一条职责分离的签名链」）**
直觉：当传感器来自企业、算法来自高校、数据来自研究院，最危险的失败不是技术错误，而是**自产自审**：数据提供方给自己的数据签「覆盖达标」，传感器厂商给自己的标定签「无偏」。于是把证书拆成断言（claim），每个断言只能由「有能力独立审计它」的角色签署，红线断言要求签名方 ≠ 证据提供方且至少两个独立机构。证书 = 断言集 + 签名聚合 + 来源清单哈希；信任降为「职责分离是否真实成立」。再叠加来源清单（代码/参数/QoS/数据护照/标定模型/硬件配置/计算图快照的哈希链），使第三方可以重放并复现结论；不可重放的证书只是「一次性声明」。

**灵感 3（耦合 → 运行时计算图就是供应链，证书必须同时绑定调度与组织）**
直觉：路径监控器如果和 AI 回调共用同一个 DDS 与执行器，它自己就会被降级/延迟/投毒——用不可信的中间件去监控不可信的中间件毫无意义。所以必须有一个**认证执行器**：安全回调走独立优先级带与时间预算，AI 回调只能吃预留之外的 slack，准入控制保证最坏响应时间；同时用一个**认证运行时监控器**（独立线程/独立 QoS/独立时钟源）核对部署图与来源清单同构（无影子节点、无参数漂移、无未声明 QoS 降级）。产学研的职责分离，必须与这条运行时可观测链绑定，否则签名可以对着一个「已被替换的运行时」签发。

**耦合升级**：CPR（证书路径运行时）产出传输契约、CCM、认证执行器与路径级 fail-closed；FCA（联邦认证）产出职责分离断言、来源清单、跨机构撤销与覆盖缺口；CBC（证书预算编译器）把端到端新鲜度/时延/不确定性预算分配到各节点并识别关键路径。架构由 v9 的「姿态根信任 + 校准数据治理」升级为 v10：新增**运行时契约层**与**组织治理层**，二者把 v21 的「姿态 → 数据 → 覆盖 → 证书」闭环扩展为「组件 → 链路 → 调度 → 签署 → 端到端证书」的可审计供应链。

## 1. 形式化定义（增量：定义 50–56）

**定义 50（证书路径与传输契约）**
ROS 计算图 G = (V, E)，节点 v 为发布者/订阅者/执行器回调，边 e = (u, v) 为一条消息流。证书路径 P_c = (v_0 = sensor, …, v_k = actuator)。每条边携带传输契约 κ_e = (τ_e^max, p_e^drop, δ_e^clk, ord_e, auth_e, q_e)，分别是最坏时延、最大丢失概率、时钟偏斜上界、保序性、完整性与 QoS。路径合成：τ_max(P) = Σ_e τ_e^max，p_drop(P) ≤ 1 − Π_e (1 − p_e^drop)，δ_clk(P) = Σ_e δ_e^clk，ord(P) = ∧_e ord_e，auth(P) = ∧_e auth_e。证据时戳 τ_ev 是证据被采集的时刻（不是被消费的时刻）。

**定义 51（端到端证书 soundness）**
端到端证书 C(P) 在决策时刻 t sound，当且仅当
Sound(C(P), t) ⇔ ∧_{v∈P} Sound(c_v, t_v) ∧ TransportOK(P) ∧ Fresh(P, t) ∧ SchedOK(P)，
其中 TransportOK 要求每条边的实际时延/丢失/乱序/时钟偏斜不超出 κ_e；Fresh(P,t) 要求 t − τ_ev ≤ F(P)（F 为路径新鲜度预算）；SchedOK 要求决策回调最坏响应时间 R_v ≤ D_v 且不被低关键级回调阻塞。**路径命题**：即使每个 c_v 局部 sound，只要任一链路或调度条件不成立，C(P) 不可用于安全守卫。安全类谓词仍只能做定义 45 的 □ 提升，且提升必须发生在「路径仍新鲜」的时刻。

**定义 52（QoS→证书编译器与证书携带消息）**
QoS 配置 q = (reliability, durability, deadline, liveliness, history_depth) 编译为它可保证的传输契约 κ(q)。RELIABLE 且资源充足时 p_drop = 0；BEST_EFFORT 时 p_drop > 0 且必须显式计入 p_drop(P)；history_depth 过小意味着 burst 时乱序/丢旧证据。可采纳 QoS 集 Q_adm = {q : κ(q) ⪯ κ_req(P)}（逐分量不劣）。**证书携带消息** CCM = (payload, evidence_ts, cert_ref, manifest_hash, expiry)。消费者在 now − evidence_ts > τ_max(P) + F(P)、cert_ref 失效或 manifest_hash 不匹配时**必须拒收**。任何运行时把 RELIABLE 改 BEST_EFFORT、缩小 history、放宽 deadline、改变 durability 的操作都定义为**契约降级**，必须触发证书重评估，否则是静默失效。

**定义 53（认证执行器与可调度性准入）**
执行器分安全执行器 E_safe（截止期 D_s，关键级 K_s）与尽力执行器 E_be（VLM/检索/采集）。准入：只有满足响应时间分析 R_i ≤ D_i 的回调可进入 E_safe；采用固定优先级带 + 时间触发预算，E_be 只能使用预留之外的 slack。**单调可调度命题**：若 E_safe 在当前集合上可调度，则加入任意 E_be 回调不改变 E_safe 的最坏响应时间上界；否则拒绝部署（而不是上线后赌它不饿死安全回调）。这直接针对 ROS 2 默认单线程/多线程执行器不保证关键回调优先的事实。

**定义 54（联邦认证与职责分离）**
参与方角色 R = {P 数据/传感器提供方, C 校准方, A 审计方, I 集成方}。每个机构 o 只能在它有能力独立审计的声明上签名。断言 a = (claim, evidence, signer, scope)。**职责分离公理**：对红线断言 a，要求 signer(a) ≠ provider(evidence(a))，且至少一个 signer ∈ A，且 |distinct_orgs(signers(a))| ≥ 2。证书 = 断言集合 + 签名聚合 + 来源清单哈希。跨机构信任不是「信任某机构」，而是「信任一条职责分离的签名链」；单机构自签的红线断言一律视为未认证。

**定义 55（来源清单与可重放证书）**
来源清单 M = H(code) ⊕ H(params) ⊕ H(qos) ⊕ H(data_passports) ⊕ H(calib_model) ⊕ H(hardware_cfg) ⊕ H(ros_graph_snapshot)。证书 c 引用 manifest_hash(M)。**运行时一致性**：部署的图快照 G_deployed 必须与 M 中的图同构（无影子节点、无未声明参数漂移、无未声明 QoS 降级）。**可重放性**：给定 M 与签名数据，任一第三方可在仿真/回放中复现证书的覆盖与安全结论；不可重放的证书只能算「一次性声明」，不得作为跨机构红线证据。

**定义 56（联邦级联撤销与跨机构覆盖缺口）**
若机构 o 撤销或污染组件 x，则所有 manifest 依赖 x 的证书沿依赖图级联失效（定义 46 的根失效从「姿态」扩展为「任意被撤销组件」）。跨机构覆盖缺口 federation_gap_ω = 1 − (#independent_orgs(ω) / required_orgs)。红线层要求 federation_gap_ω = 0，即至少两个独立机构的数据/审计支撑，否则该层不得签发跨机构红线证书——这直接防「产学研中某一方自产自审」。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-63 CERT-PATH-RUNTIME（证书路径运行时 CPR）
1. **路径编译与契约合成**：从计算图枚举传感器到执行器的证书路径，把每条边 QoS 编译为 κ_e 并合成为端到端契约；不可满足则在**部署前拒绝**，而非上线后降级。
2. **CCM 与新鲜度闸门**：所有安全相关消息携带 (evidence_ts, cert_ref, manifest_hash, expiry)；消费端对陈旧、失效、清单不匹配的证据一律拒收。
3. **认证执行器**：E_safe/E_be 隔离 + 优先级带 + 时间预算 + 准入控制；AI 回调绝不吃安全预算。
4. **契约降级与影子节点检测**：运行时比对部署图与 manifest，检测 QoS 降级、参数漂移、影子节点、非法图重组，命中即路径级 fail-closed。

### 2.2 IP-64 FED-CERT-AUTHORITY（联邦认证机构 FCA）
1. **职责分离签名**：按角色授权断言，红线断言强制「非自产自审 + ≥2 独立机构 + 至少一个审计方」。
2. **来源清单与可重放**：签发引用 manifest_hash 的证书；提供第三方回放复现协议；不可重放则降级为一次性声明。
3. **跨机构覆盖缺口**：按层统计独立机构覆盖，federation_gap > 0 的红线层拒绝签发。
4. **联邦撤销与冲突裁决**：组件撤销沿依赖图级联失效；两机构断言冲突时进入隔离区，由预注册仲裁方按证据重放裁决。

### 2.3 IP-65 CERT-BUDGET-COMPILER（证书预算编译器 CBC）
1. **端到端预算分配**：把总时延/新鲜度/不确定性预算按「对下游 margin 的敏感度」分配到各节点，生成每节点契约配额。
2. **关键路径识别**：找出对端到端 margin 最敏感、最易违约的节点/边，指导优化与采集。
3. **契约综合与可行性判定**：若某节点最小可行配额都无法满足，返回「契约不可满足」，拒绝该部署或该证书声明。
4. **配额漂移监控**：运行期监控各节点实际时延/不确定性与配额的偏离，提前于端到端失效发出告警并触发降级。

## 3. 四层架构 v10

```
组织治理层（新）:
  IP-64 FCA: 角色定义 → 职责分离签名 → 断言聚合 → 来源清单哈希 → 撤销级联
    ← IP-55 CKB 数据护照/谱系 + IP-62 CCA 跨机构第三方审计
    → 红线证书(manifest_hash, 签名链, 可重放) 或 拒绝签发

运行时契约层（新，横切 L1–L4）:
  IP-63 CPR: ROS 2 计算图 → κ_e 传输契约 → 证书路径 P_c → CCM 新鲜度闸门
    + 认证执行器 E_safe/E_be + 契约降级/影子节点检测 → 路径级 fail-closed
  IP-65 CBC: 端到端 F/τ/ε 预算 → 各节点配额 → 关键路径 → 不可满足则拒绝部署

根信任层: IP-60 PSE 姿态证书（须携带 evidence_ts + 传输来源）
L1: 几何/物体 6D 位姿（以证据时刻与路径 sound 为前提）
L2: CTC + VLM + IP-35 仲裁（运行在 E_be，永不阻塞 E_safe）
L3: IP-51 CAR(Sound(C(P),t) 前置) → IP-49 □ 提升 → IP-47 组合 → IP-39 规划 → IP-53 监控
L4: IP-61 DCL + IP-62 CCA（跨机构覆盖 + 运行时图审计）→ 重校准 → IP-55 CKB
运行期：路径编译 → 契约绑定 → CCM 传递 → 执行器隔离 → 路径级判定
        契约违约/影子节点/陈旧证据/未认证清单 → fail-closed；撤销 → 全局级联失效
```

| E110 100h 产学研-ROS 闭环 | 可重放证书比例；跨机构复现一致率；不安全事件；可调度性违约 | ≥95%；≥99%；0 起；0 |

## 5. 本轮最大风险

### IP-63 CPR：路径编译、传输契约、CCM 与认证执行器
```
def compile_cert_path(ros_graph, req):
    paths = enumerate_paths(ros_graph, src=sensors, dst=actuators)
    feasible = []
    for P in paths:
        kaps = [edge_contract(e) for e in P]
        kap  = compose(kaps)                      # τ=Στ, drop≤1−Π(1−p), δ=Σδ
        if kap.tau <= req.F and kap.drop <= req.p and kap.order:
            feasible.append((P, kap))
    if not feasible:
        return RejectDeployment('path_infeasible')   # 部署前拒绝，不事后降级
    return choose_min_budget(feasible)

def edge_contract(e):
    q = e.qos
    p = 0.0 if q.reliability == 'RELIABLE' else observed_or_worst_drop(e)
    return Kappa(tau=q.deadline or measured_p99(e),
                 drop=p, clk=clock_skew_bound(e),
                 order=(q.history_depth > 1), auth=e.security, qos=q)

def compose(kaps):
    return Kappa(tau=sum(k.tau for k in kaps),
                 drop=1 - prod(1 - k.drop for k in kaps),
                 clk=sum(k.clk for k in kaps),
                 order=all(k.order for k in kaps),
                 auth=all(k.auth for k in kaps))

def accept_evidence(ccm, now, kap, manifest_hash):
    if ccm.manifest_hash != manifest_hash: return Drop('manifest_mismatch')
    if now - ccm.evidence_ts > kap.tau + FRESHNESS_BUDGET:
        return Drop('stale')                      # 陈旧证据不得用于安全守卫
    if not ccm.cert_ref.valid_now(): return Drop('cert_expired')
    return ccm.payload

def safety_executor_admit(cb, D, K, current):
    if cb.criticality < K_SAFE: return E_be
    if worst_case_response(cb, current) <= D: return E_safe
    return Reject('unschedulable')                # 宁可拒绝部署，不赌不超期

def executor_dispatch(E_safe, E_be, t):
    if E_safe.pending(): return E_safe.pop_highest()
    if slack(t) >= E_be.wcet(): return E_be.pop()
    return idle                                   # 绝不把安全预算借给 AI

def detect_contract_downgrade(snapshot, manifest):
    if not graph_isomorphic(snapshot, manifest.graph):
        return Violation(None, 'graph_mismatch')
    for e in snapshot.edges:
        if not qos_at_least(e.qos, manifest.qos[e.id]):
            return Violation(e, 'qos_downgrade')  # RELIABLE→BEST_EFFORT 等
        if e.node_hash != manifest.code[e.node]:
            return Violation(e, 'shadow_node')
        if e.param_hash != manifest.params[e.node]:
            return Violation(e, 'param_drift')
    return None
```

```
def sign_claim(claim, evidence, org, role):

    if claim.redline and evidence.provider == org:

def aggregate_certificate(claims, atts, required_orgs=2):
    for c in claims:
        if c.redline:
            signers = distinct_orgs(a for a in atts if a.claim == c)
            if len(signers) < required_orgs:
                return Reject('insufficient_independence')
            if any(a.signer == c.provider for a in atts if a.claim == c):
                return Reject('self_dealing')
            if not any(a.role == 'A' for a in atts if a.claim == c):
                return Reject('no_auditor_signed')
    return Certificate(claims, atts, manifest_hash=hash_manifest(claims))

def federation_gap(stratum, data_index):
    return max(0.0, 1 - len(independent_orgs_covering(stratum, data_index))
                         / REQUIRED_ORGS)

def replay_certificate(cert, signed_data, sim):
    if not cert.replayable or not verify(signed_data, cert.signatures):
        return NOT_REPLAYABLE                     # 一次性声明，不得作红线证据
    return sim.reproduce(cert.claim, signed_data).evidence == cert.evidence

def revoke(component, dep_graph):
    for c in descendants(dep_graph, component):
        c.status = 'revoked'                      # 级联，不局部降级
        notify(c.subscribers)
```

### IP-65 CBC：端到端预算分配与关键路径监控
```
def allocate_cert_budget(req, path):
    sens = {v: sensitivity(v, req.phi) for v in path.nodes}
    w = normalize(sens)
    quotas = {v: Budget(tau=w[v]*req.tau, eps=w[v]*req.eps,
                        fresh=w[v]*req.F) for v in path.nodes}
    if any(quotas[v].tau < min_feasible(v) for v in path.nodes):
        return None                               # 契约不可满足 → 拒绝部署
    return quotas

def critical_path_monitor(path, quotas, runtime):
    vio = []
    for v in path.nodes:
        if runtime.latency[v]     > quotas[v].tau: vio.append(('latency', v))
        if runtime.uncertainty[v] > quotas[v].eps: vio.append(('eps', v))
        if runtime.freshness[v]   > quotas[v].fresh: vio.append(('fresh', v))
    return vio or None
```
