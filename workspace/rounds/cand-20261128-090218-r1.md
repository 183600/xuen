### 第 6 轮灵感驱动研究记录

**灵感词**：轻量化结构、机器人竞赛

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把提议升级为条件流匹配、记忆升级为嵌入固化、人因升级为情感调制，并以定理 6（证书不变性）把框架推广为「任意生成器 + 认证边界」，执行集 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。v5 的最大风险 R57 是**记忆固化自指回路**：证书由系统自己铸造、自己验证，缺乏外部真值。本轮两个灵感词恰好对准这一软肋——「轻量化结构」让证书便宜到可被外部独立复验，「机器人竞赛」提供竞争性、可对抗、带留出集的外部真值。二者合成 CADVS-v6 主题「轻量竞证执行」（Lightweight Competitive Certified Execution, LCCE），新增 IP-497~500。本轮自律不变：**七硬门不增**——轻量证书只是同一组门的更紧凑可验证表示，竞赛只是门外的对抗审计层，均不构成第八门；所有改动只紧不松，执行集证书边界升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **轻量化结构 → 证书也要「轻量化」**。v5 的证书是一个不可分割的大谓词，验证要跑满七个门，外部审计成本高，于是只能自证自验；R57 的根源之一正是「外部想验也验不起」。把证书做成**结构稀疏的和/或树**（门 × 时间分段 × 接触模式），每个叶节点带区间算术界，用**分支定界**只展开临界子树：能证明就早停，证明不了就 fail-closed 退回全量验证。这样证书是**单侧可靠**的（草图判真 ⇒ 全证书必真，绝无假接受），代价只是偶尔多跑全量——这是可用性风险，不是安全风险。轻量化的收益是外部审计变得廉价，从而把 R57 从「只能自证」推向「可被独立复验」。同一词在物理侧也成立：轻量/柔性连杆惯量低、抗扰弱，物理门需要**惯性感知安全系数 σ_struct ≥ 1** 补偿，只收紧。

2. **机器人竞赛 → 用竞争制造外部真值**。v5 的证书缺少「系统之外的真值」。机器人竞赛提供三样东西：(a) **标准化任务与评分**，可复现、可跨站比较；(b) **对抗性红队**，独立队伍以悬赏方式寻找门的反例（exploit）；(c) **公开/私有留出集分离**，公开榜用于激励，私有集用于真实裁决，直接对抗 Goodhart。定义**竞赛硬化算子**：每发现一个 exploit，只能「禁用受影响的提议模式 / 收紧阈值 / 加入回归语料」，**禁止放宽任何门**，因此执行集单调收缩（定理 12）。竞赛不新增硬门，它是门外的审计层，把 v5 定理 7(iii) 的经验上界从「自家红队」升级为「开放竞争的下界估计」——但仍只是经验界，不承诺根除。

3. **轻量化结构 → 提议器也要轻量化到端侧**。v5 的流策略 FMPP 需 GPU、5–20 ms（R54）。用**结构化剪枝 + 蒸馏**压到端侧 NPU，并给出**压缩保持**：门不变 ⇒ 压缩只改提议支撑、不改证书边界（定理 6 的直接推论）；蒸馏误差 ε_v 经向量场 Lipschitz 传播为轨迹偏差与边际退化界（定理 11，Grönwall），据此决定能否上线。于是「轻量」同时指证书、模型、物理结构三者，而三者共用同一个「只紧不松」的单调性骨架。

**关键洞见**：v5 回答「提议任意化后证书边界如何不变」；v6 回答「如何让证书便宜到能被外部独立复验，并用竞争性外部真值约束自指回路」。七门 kc_i 原样复用；新增的只有：结构化证书 LCK、结构感知裕度 SAMK（σ_struct ≥ 1）、竞赛裁判 CRP（只硬化）、压缩提议 π̂。执行集证书边界 Exec_v6 ⊆ Exec_v5 由「同门 + σ_struct ≥ 1 + 竞赛只硬化」保证；提议支撑永远只是内近似，永不扩张边界（定理 6）。ECS_v6 = ECS_v5 · η_comp · η_compete。

**形式化目标（增量）**：
1. 证书树 C = ∧_{i=1}^{7} kc_i，每个 kc_i 分解为时间 × 接触模式子约束；叶区间 [l,u] ⊇ 真值（向外舍入）；Kleene 三值分支定界草图。
2. σ_struct = 1 + c_I·(I_ref/Ī − 1)_+ + c_K·κ_compliance + c_P·ρ_payload ≥ 1；τ_i^6 = σ_struct,i · τ_i^5 = σ_struct,i · γ_i · τ_i^4。
3. 压缩提议 π̂ = Compress(π_FM)（结构化剪枝 + 蒸馏），误差 ‖v_θ − v_θ̂‖_∞ ≤ ε_v；仅当 ε_v ≤ ε_v^max 且回归通过才上线。
4. 竞赛硬化：Exec^(t) = Harden(Exec^(t-1), Exploit_t) ⊆ Exec^(t-1)；公开/私有留出集分离；补丁只紧不松。
5. 定理 9（轻量证书单侧可靠性/成本界）、定理 10（结构感知单调性）、定理 11（压缩保持与边际退化界）、定理 12（竞赛硬化单调与外部真值经验界）。

**本轮最大风险**：**竞赛基准的 Goodhart 化**——一旦公开榜固定，它就从「外部真值」退化为「又一个可优化的代理指标」，参赛者会过拟合公开集、私有留出集迟早泄漏，竞争性外部真值重新塌回自指回路；轻量证书的分支定界又可能被可用性压力诱导去「跳过未证明子树」，把单侧可靠悄悄改回双向近似。

### IP-498 SAMK：结构感知裕度核（离线标定 + 在线 O(1)）

```python
@dataclass
class StructureAwareMarginKernel:
    """SAMK：轻量/柔性结构的惯性感知安全系数 σ_struct ≥ 1。
    定理 10：σ ≥ 1 ⇒ τ^6 ≥ τ^5 ⇒ 执行集只缩。"""
    c_I: float = 0.15
    c_K: float = 0.20
    c_P: float = 0.10
    I_ref: float = 1.0

    def sigma(self, link, payload, task) -> dict:
        # 低惯量/高柔性/高负载比 -> 更大安全系数
        s = (1.0
             + self.c_I * max(self.I_ref / max(link.I, 1e-6) - 1.0, 0.0)
             + self.c_K * link.compliance
             + self.c_P * payload.ratio)
        s = max(1.0, s)                       # 只紧不松
        return {'wrench': s,
                'zmp': s,
                'bal': 1.0 + 0.5 * (s - 1.0),
                'val': 1.0 + 0.3 * (s - 1.0)}

    def thresholds(self, tau5: dict, sig: dict) -> dict:
        return {i: sig[i] * tau5[i] for i in tau5}   # τ^6 = σ·τ^5
```

### IP-500 EFA-v6：七硬门 + 结构感知阈值 + 轻量证书 + 压缩提议

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：七硬门不变（τ^6=σ·γ·τ^4，只紧）+ 轻量证书 + 竞赛硬化"""
    fmpp_c: Any                         # 压缩提议 π̂（端侧）
    lck: LightweightCertificateKernel
    samk: StructureAwareMarginKernel
    crp: CompetitiveRefereeProtocol
    v5: EvidenceForgingAssemblerV5

    def select(self, x0_state, t_now, rule_id, context):
        s_emo = self.v5.famk.observe(context.face, t_now)
        gamma = self.v5.famk.gamma(s_emo)
        sig = self.samk.sigma(context.link, context.payload, context.task)
        tau6 = self.samk.thresholds(
            {i: gamma[i] * TAU4[i] for i in TAU4}, sig)   # τ^6 = σ·γ·τ^4
        c = build_ctx(context, s_emo, self.v5.lmem)
        cands = self.fmpp_c.propose(c, k=8)
        # 轻量证书分支定界先筛（廉价、单侧可靠；UNKNOWN 自动全量）
        surv = [x for x in cands if self.lck.verify(x, tau6)]
        if not surv:
            return self.v5._fallback_rule_proposal(gamma)  # fail-closed
        # 后续 VACK / BCK 与 v5 相同，仅消费 τ^6
        finals = self.v5._vack_and_bck(surv, tau6, context)
        if not finals:
            return False, None, 'ALL_CANDIDATES_REJECTED'
        best = max(finals, key=certified_margin)
        return True, best, 'FORGED_LCCE'

    def ecs_v6(self, eps_v: float, v_private: float, **kw) -> float:
        eta_comp = sigmoid(-(eps_v - EPS_V_MAX) / s_v)
        eta_compete = 1.0 - min(0.5, lam_c * v_private)
        return self.v5.ecs_v5(**kw) * eta_comp * eta_compete
```

## 4. 正确性论证（增量更新）

### 引理 45（区间外扩可靠性）

**陈述**：若每个叶约束 s_i 用向外舍入得到 [l_i,u_i]，且 l_i ≤ s_i(x) ≤ u_i，则 l_i ≥ τ_i ⇒ s_i(x) ≥ τ_i，u_i < τ_i ⇒ s_i(x) < τ_i。Kleene 三值的 AND/OR 组合不产生假真、也不产生假假。∎

### 引理 46（蒸馏误差传播）

**陈述**：Euler S 步、步长 h=1/S，若 ‖v−v̂‖_∞ ≤ ε_v 且 v 为 L_v-Lipschitz，则轨迹偏差 ‖x(1)−x̂(1)‖ ≤ (ε_v/L_v)(e^{L_v}−1)，门边际退化 ≤ L_m·该偏差。**证明**：离散 Grönwall 归纳。∎

### 定理 9（轻量证书单侧可靠性/成本界）

**陈述**：三值分支定界中，判真⇒全证书真、判假⇒全证书假、未知⇒全量验证；故永不假接受（soundness），直接假拒率为 0。当证书离边界 margin ≥ Δ 且 ε_int < Δ，在 O(depth) 叶内早停，期望代价 ≤ O(log|C|)·P(临界) + O(|C|)·P(未知)。∎

### 定理 10（结构感知单调性）

**陈述**：σ_struct ≥ 1 且门为规范形 ⇒ τ^6 = σ·τ^5 ≥ τ^5 ⇒ Exec_v6 ⊆ Exec_v5；σ≡1 精确退化 v5。∎

### 定理 11（压缩保持与边际退化界）

**陈述**：门不变 ⇒ 压缩只改提议支撑、不改证书边界（定理 6 推论），realized Exec(π̂) ⊆ Exec_gate(τ^6)；由引理 46，边际退化 ≤ L_m(ε_v/L_v)(e^{L_v}−1)；仅当 ε_v ≤ ε_v^max 且回归通过才上线。∎

### 定理 12（竞赛硬化单调与外部真值经验界）

**陈述**：Harden 只允许禁用/收紧/加回归 ⇒ Exec^(t) ⊆ Exec^(t-1)；真实 exploit 给出 V_true 的经验下界 V_true ≥ |Exploit|/|B_private|；GoodhartGap 只作过拟合报警，无上界保证。∎

### 定理 v6（轻量竞证执行总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 区间外扩正确、(B9) ε_v ≤ ε_v^max 下：
(i) 证书边界单调：Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29（同门 + σ_struct ≥ 1 + 竞赛只硬化）；
(ii) 轻量证书单侧可靠，无假接受（定理 9）；
(iii) 压缩不降安全性，仅影响能力与边际（定理 11）；
(iv) 竞赛硬化单调，外部真值仅经验下界（定理 12）；
(v) 七锚完备性保持（不增删锚点）。

**证明**：(i) 由定理 10 + 定理 12 单调 + 同门；(ii)(iii)(iv) 分别由定理 9、11、12；(v) 锚点集合不变。∎

**诚实声明**：(B8) 区间外扩若实现有误（舍入方向、浮点）会破坏 soundness，属实现级高危；(B9) 蒸馏能力退化只有经验界；(ii) 竞赛外部真值可被 Goodhart 化、私有集可泄漏，只能检测不能根除；(iii) σ_struct 依赖惯量/柔性模型精度，轻量柔性结构建模误差大；(iv) 加性价值假设 (B4) 继承自 v5，未解决。

## 7. 本轮最大风险（最终确认）

**一句话**：**竞赛基准的 Goodhart 化**——公开榜一旦固定就退化为可优化的代理指标，参赛者过拟合公开集、私有留出集迟早泄漏，竞争性「外部真值」重新塌回自指回路；同时轻量证书的分支定界可能被可用性压力诱导去跳过未证明子树，把单侧可靠悄悄改回双向近似。冻结门、私有裁决、GoodhartGap 报警与形式化审计只能缓解，无法根除。
