# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「通用机器人平台」×「角色一致性」）

> R69 把不确定性一分为二，学会「向谁求证、还能问什么」。但它默认了一个隐含前提：**只有一个身体、一个任务、一段可审计的短时程，而且「提问者」没有身份**。R69 的 MINT 只问「问了值不值」，从不问「这是不是我这个角色该问的话」；它的 J_FLUID 证书也只对当次 episode、当前 embodiment 成立。一旦把系统放上**通用机器人平台**——同一套 trunk / 标定 / 证书要跨机械臂、移动底盘、人形，跨工人 / 陪护 / 守卫等多种岗位——R69 就暴露两个平台级空洞：
> - **信任不可迁移**：J_FLUID 是「这一台、这一岗、这一刻」的证书，换身体 / 换任务就要从零重认证，平台的经济性荡然无存；若咬牙直接迁移，又会把 A 身体的安全裕度静默带到 B 身体。
> - **「提问者身份」没有被约束**：R69 允许为消歧生成任何高 VoI 的信息动作。但一个陪护机器人突然像安检机器人一样连珠炮式盘问，虽然「信息上划算」，却已经**不是它自己**了。更危险的是，这种身份漂移可被外部**多轮驯化**（persona steering / 角色越狱），而 R69 的投毒模型只覆盖单次交互。
>
> 本轮两个灵感正好接上：
> - **通用机器人平台**给出「一个栈、多个身体 / 岗位」的复用问题，逼出**可迁移信任**与**角色族证书**；
> - **角色一致性**给出平台级的第一公民不变量：**角色是一个参考系**——适配是角色内的协变移动，漂移是角色参考系本身的非法移动。
>
> 核心命题：**把「角色」提升为一等公民的安全契约。用角色参考系把「适应任务」与「身份漂移」在几何上分开（规范分解）；用角色条件查询把 R69 的 VoI 减去「像不像我」的成本；用带迁移间隙的角色族证书让一次认证跨身体 / 岗位复用；用角色切换协议与漂移监控守住跨时程一致性；并硬性规定角色只能由外部授权改变、系统自我不能越权改角色。** 命名 **ROLE-RAS**（Role-consistent Open-pLatform Latent-Embodiment Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**换了身体、换了岗位、被驯化了很久之后，我还是不是同一个我**」——身份不是装饰，而是让平台级信任可迁移、可审计的坐标系。

## 0. 直觉与动机

**灵感 1（通用机器人平台 → 复用即信任迁移问题）**
直觉：平台的卖点是「一套栈服务 N 个身体 / 岗位」，所以它的核心指标不是单机性能，而是**复用率**。但 R69 的每一份安全承诺都绑定在具体身体与任务上：trunk 见过什么分布、COF 标定了哪台传感器的漂移、流似然在哪副动力学上成立。复用若只是「把权重拷过去」，安全裕度会随身体差异被悄悄稀释。真正要复用的是**信任**，而复用信任必须回答一个问题：「这次迁移到底带过去多少未知？」——这正好可以写成一个可审计的**迁移间隙**。直觉上的结论是：平台复用不是免认证，而是「一次认证 + 逐次加间隙」。

**灵感 2（角色一致性 → 提问者也有身份）**
直觉：R69 把「问」当成纯信息动作，但人从不这样看。同样一句「你到底想要什么」，从陪护机器人口中说出是关心，从事故调查机器人口中说出是审问。**信息动作同时是身份表达**。因此「该不该问」不只由 VoI 决定，还要减去「这像不像我」。更关键：如果角色不被约束，系统可以为每一集都挑最高 VoI 的问法，久而久之滑成一个「什么都敢问」的通用查询机——这就是角色不一致，也是平台级隐患：越权角色会获得越权信息。

**灵感 3（角色一致性 → 一个参考系，而不是一个性格标签）**
直觉：一致性最容易被误解成「语气 / 表情别变」。对平台而言它必须更强也更精确：**角色是一个参考系**。把行为签名投到一个把任务实例、embodiment、时间平移都商掉的潜空间里；在角色参考系内，适配（换抓取、换步态、换问法）是协变的、允许的；越出这个参考系的移动才是漂移。这样一来，「适应」与「漂移」不再靠阈值拍脑袋，而是切向 / 法向的几何区分：切向是合法的任务适配，法向是身份的改变。

**灵感 4（迁移 + 角色 → 一次认证、多处复用、逐处加账）**
直觉：平台最贵的不是推理，是认证。若每换一个岗位都要重新跑一遍 J_FLUID，平台就退化成「一堆单机」。角色族证书的思路是：共享层认证一次，每个角色只保留自己的残差，每次跨身体 / 跨角色迁移再显式记一笔迁移间隙。**复用不是免认证，而是「一次认证 + 逐次加间隙」**——把未知写成账单，而不是假装它不存在。这样平台的经济性与安全性不再是零和：省下的是重复认证，付出的是逐次可见的间隙。

**灵感 5（角色是双刃剑 → 驯化与合法化）**
直觉：一旦系统有「稳定的角色」，就有了两种新攻击。其一是**驯化**：攻击者不制造异常轨迹，而在策略分布内一步步把系统牵到另一个角色——每一步都合法、都低似然异常，唯独签名在缓慢偏移。其二是**合法化**：一个稳定地扮演错误角色的系统，会因为「一致」而通过审计，甚至越用越可信。所以本轮必须交付：角色漂移监控（并承认它必然有检测延迟）、角色龄上限与强制重认证、角色只能外部授权切换、跨角色证据隔离，以及把「一致 ≠ 正确」写进证书语义。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（ROLE-RAS 总览与四不变式）** ROLE-RAS = (RCM, RSI, GCD, PTC, R-MINT, RLB, RDM, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i / R69）；
(ii) **交互预算硬约束**（继承 R69 定义 293-ii）；
(iii) **证据纪律**（继承 R69 定义 293-iii）；
(iv) **角色一致性**：除经认证的角色切换外，任一时刻行为签名相对当前角色参考的散度 D_role(t) ≤ ρ_role；且**角色标识只可由外部授权写，系统自身的可学习写集合不包含角色标识**。

**定义 311（角色契约 RCM）** 角色 r = (𝒜_r, 𝒢_r, ρ_r^risk, s_r, Σ_s, E_r, T_r, D_r^max)。𝒜_r ⊆ 𝒜_+ 为允许动作集；𝒢_r ⊆ 𝒜_info 为允许的询问 / 注视 / 探针样式；ρ_r^risk 为风险容忍；s_r ∈ ℝ^{d_s} 为角色签名参考；Σ_s 为签名度量；E_r 为可访问证据域；T_r 为角色龄上限；D_r^max 为累积漂移上限。

**定义 312（身体不变角色签名 RSI 与角色散度）** 签名 φ: (o, ξ) ↦ ℝ^{d_s} 需满足**身体不变性**：对 nuisance 变换 ψ ∈ Ψ（任务实例重参数化、embodiment 换装、时间平移），有 ‖φ(ψ·(o,ξ)) − φ(o,ξ)‖ ≤ ε_ψ。角色散度 D_role(t) = inf_{ψ∈Ψ} ‖φ(ψ·(o_t,ξ_t)) − s_r‖²_{Σ_s^{-1}}（Mahalanobis）。一致性 ⇔ sup_{t∈W} D_role(t) ≤ ρ_role。关键：**商掉 nuisance 之后剩下的差异才算身份差异**。

**定义 313（角色规范的适应 / 漂移分解 GCD）** 角色流形 ℳ_r = {行为分布 : D_role ≤ ρ_role}。任一步状态变化 Δ 分解为 Δ = Δ_∥ + Δ_⊥，Δ_∥ ∈ T_xℳ_r（切空间，协变适配），Δ_⊥ ⊥ T_xℳ_r（法向，漂移）。单步漂移 δ_drift(t) = ‖Δ_⊥‖；累积漂移 D_drift = ∫ δ_drift dt。规范变换 ψ 下 Δ_∥ 协变（物理上无关的差异被商掉），Δ_⊥ 不协变（是不可商掉的真实身份改变）。⇒ **适配 = 角色内切向运动；漂移 = 法向逃逸**。

**定义 314（迁移间隙与角色族证书 PTC）** 设源身体 / 任务 A 上证书 J_FLUID^A。目标任务 / 身体 B 的迁移间隙 τ_gap(A→B) = sup_{probe p} |R̂_A(p) − R̂_B(p)|，由共享潜空间标定探针估计，并被界为 L_trans·W₂(μ_A, μ_B) + ε_dec（W₂ 为特征分布距离，ε_dec 为解码 / 动力学差异）。J_ROLE = (role_id, role_family_id, J_FLUID^A, τ_gap, D_role^p95, D_drift, signature_hash, auth_token_hash, age, role_ver)。迁移合法 ⇔ Valid(J_FLUID^A) ∧ τ_gap ≤ τ_max；此时 **B 上风险上界 R_B ≤ R_A + τ_gap**（保守加性）。否则必须在 B 上重认证。

**定义 315（角色族与一处认证、多处复用）** 角色族 ℛ = {r_1,…,r_m} 共享 trunk 与标定。族证书 J_family = (共享层证书, {ρ_i})，每个角色只保留残差 ρ_i。组合有效 ⇔ 对所用角色 r_i 有 Valid(J_ROLE(r_i)) 且共享层未被任一角色越权写。⇒ 平台复用 = 共享层证书 + 每角色残差；复用不是免认证，而是「认证一次、迁移多处、各自加间隙」。

**定义 316（角色条件查询 R-MINT）** g* = argmax_{g ∈ 𝒢_r} [VoI(g) − c(g) − κ·D_role(g)]，s.t. g 过 C-RAS-WM 认证、预算未越。其中 D_role(g) 为执行 g 后角色签名的（预期）散度增量，κ 为「像不像我」的价格。若 max ≤ 0：不交互，退化到 R69 的 R68 兜底。要点：**信息价值与身份表达价值进入同一个目标**——问什么，本身是在表态「我是谁」。

**定义 317（角色切换协议 RSP）** 角色 r→r′ 只能由外部授权令牌 σ_auth 触发。协议五步：(1) quiescence：drain 在途承诺、回到安全静止；(2) re-anchor：把签名参考切到 s_{r′}，重置 Δ_⊥；(3) 重认证：J_ROLE(r′) 必须有效，否则拒绝并留在 r；(4) 迁移间隙校验：τ_gap(r→r′) ≤ τ_max；(5) 过渡期 λ **单调不降**。系统可**请求**切换，但不可自行切换。

**定义 318（角色泄漏屏障 RLB）** 证据带角色溯源标签 prov(e) ∈ ℛ。跨角色使用证据需 re-validation：e 从 r 迁移到 r′ 使用，必须满足 e ∈ E_{r′} ∧ 一次独立验证（R69 的 k 源一致在跨角色版的加强）；**禁止用 r 的私有证据静默更新 r′ 的信念**。角色切换时，未决证据进入 quarantine，不得续用。

**定义 319（角色漂移监控 RDM）** 对 D_role(t) 与 δ_drift(t) 做时序变点检测（Page-CUSUM），并联合 R69 的 (r_res, Δa) 双通道：**角色漂移攻击常表现为「残差与似然都正常，但签名缓慢偏移」**——因为攻击者在策略分布内逐步牵引，不制造异常轨迹。定义三元报警 (r_res↓, Δa↑, D_role↑ 缓升) 以分离「故障 / 单次投毒 / 多轮驯化」。

**定义 320（角色条件退避）** 若 D_role > ρ_role 或 RDM 报警：冻结适配（Δ_∥ = 0），λ → R68 保守，必要时进入**安全静止角色 r_0**（最小动作集、最小询问集），并请求外部重新授权。禁止在置信不足时继续扮演高权限角色。

**定义 321（角色–任务折中与预算）** 角色一致性预算 ρ_role 与任务适配收益构成 Pareto：ρ 太小 → 无法适配新任务（R69 的 resolution bonus 拿不到）；ρ 太大 → 身份漂移不可辨。可容许工作点集合 𝒫 = {(ρ, reward) : D_drift ≤ D_max}；平台调度器在 𝒫 上按角色分配预算。

**定义 322（角色龄与强制重认证）** 角色龄 age(r) = 连续处于 r 且通过一致性检查的时长；超过 T_r 或累积 drift 超 D_r^max ⇒ 强制重认证（防止「缓慢合法化」的长时程漂移）。重认证**不重置**证据纪律。

**定义 323（ℰ_ROLE 威胁模型）** ℰ_ROLE = ℰ_FLUID × ℰ_role_drift（多轮 persona steering / 角色越狱）× ℰ_role_leak（跨角色证据窃取 / 污染）× ℰ_transfer_gap（用 A 的证书在 B 上偷渡安全裕度）。并入 AIC。

**定义 324（J_ROLE 证书与有效性）** J_ROLE 见定义 314。Valid ⇔ Valid(J_FLUID) ∧ D_role^p95 ≤ ρ_role ∧ D_drift ≤ D_r^max ∧ (若迁移则 τ_gap ≤ τ_max ∧ auth_token 合法) ∧ RLB 未被违反 ∧ age ≤ T_r。

**定义 325（参与式审计 VQAuditor-R）** 审计新增：角色越权（自我改角色）、越角色证据使用、角色外的信息动作、切换是否被授权、迁移间隙是否被正确加性计入。结论回灌 AuditBuf，成为下一轮 R-MINT 的 κ 先验与角色预算调度依据。

```python
# IP-265 RSI：身体不变签名与角色散度（商掉任务/embodiment/时间 nuisance）
def role_divergence(phi, o, xi, r, Psi):
    return min(maha(phi(psi(o, xi)), r.s, r.Sigma) for psi in Psi)  # |Psi|<=4

# IP-266 GCD：把一步变化分解为「协变适配」与「法向漂移」
def gauge_decompose(delta, role_manifold, x):
    T      = role_manifold.tangent(x)
    d_par  = project(delta, T)          # 允许：角色内适配
    d_perp = delta - d_par              # 报警：身份漂移
    return d_par, d_perp

# IP-268 R-MINT：角色条件查询（把 R69 的 MINT 加上「像不像我」）
def choose_interaction_role(modes, w, o, r, budget, kappa):
    best = None
    for g in info_actions(r.G):                         # 只在角色允许的询问集内
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o): continue
        voi    = entropy(w) - expected_entropy(w, g, o)
        d_role = expected_signature_divergence_gain(g, o, r)
        score  = voi - cost(g) - kappa * d_role         # 信息 - 身体 - 身份
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None    # 无利可图/越角 → R69/R68

# IP-267 PTC：迁移间隙与加性安全界
def transfer_gap(src_stats, tgt_stats, L_trans):
    return L_trans * wasserstein2(src_stats.features, tgt_stats.features) \
           + src_stats.decoder_gap(tgt_stats)

def certify_transfer(src_cert, gap, tau_max):
    ok = valid(src_cert) and gap <= tau_max
    return ok, src_cert.risk + gap                      # 复用 = 认证 + 间隙

# IP-273 RSP：角色切换（必须外部授权；λ 单调不降）
def role_switch(state, r_new, auth):
    if not auth.valid_for(r_new):                        return reject()
    if not state.quiescent():                            state.drain()
    if not valid(J_ROLE(r_new)) or \
       transfer_gap(state.features, r_new.features) > TAU_MAX:
        return reject()
    return reanchor(state, r_new, lam_monotone=True)

# IP-275 主闭环（继承 R69，仅在「身份」维度上加约束）
def ROLE_RAS_round(M, obs, r):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, K), z)
    a_hat = M.fma.flow_anomaly(...)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    # 第二意见 2：角色签名漂移（故障/投毒/驯化的三元判别）
    Drole = role_divergence(M.phi, o, M.last_action, r, M.Psi)
    drift_alarm = M.rdm.step(Drole, a_hat, M.last_r_res)
    # 角色条件查询：越角或漂移时退回 R68 保守
    g = (M.rmint.choose_interaction(modes, o, r, M.budget, M.kappa)
         if (U_epi > TAU_EPI and not slow and not drift_alarm) else None)
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if drift_alarm or Drole > r.rho:                    # 角色条件退避
        lam = max(lam, 0.8); r = M.ctrl.safe_quiescent_role()
    k = M.c_ras_wm.certified_prefix(...)
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_r.submit_async(r, g, Drole, a_hat, M.ptc.gap())
    return k, lam, mode, (U_ale, U_epi, r)
```

## 3. 推导

**引理 19（规范分解下的无损适配）** 若任务重参数化 ψ 只改变 nuisance（定义 312），则 R69 允许的适配（模态选择、resolution bonus）全部落在切空间 T_xℳ_r，法向分量为零；即 R69 的行为在 ROLE-RAS 下不增加 D_drift。因此 R69 是 ROLE-RAS 在「单角色、无迁移、角色内无限预算、κ=0」处的一个退化点，新层没有推翻旧层。

**引理 20（迁移间隙的加性安全界）** 若 τ_gap 的估计满足 |R_A − R_B| ≤ τ_gap，则 B 上沿用 A 证书的保守风险上界为 R_A + τ_gap；仅当 τ_gap ≤ τ_max 且 R_A + τ_gap ≤ R_max 时可免重认证。要点：**迁移不是消除不确定性，而是把「未知的身体差异」显式记成一张可审计的账单**。系：τ_gap 若被低报 δ，可靠性以 δ 线性退化——所以 τ_gap 必须由独立探针估计、并被审计，不能由被认证对象自报。

**引理 21（角色条件查询的最优性与「问→不问」的理性）** 在角色约束 g ∈ 𝒢_r 下，R-MINT 的解是「信息–身份」联合目标的最优；当 κ=0 且 𝒢_r = 𝒜_info 时逐点退化为 R69 的 MINT。系：存在「高信息但越角」的动作时，若 κ·D_role(g) > VoI(g) − c(g)，则最优是**不问**（或换一个信息更低但合身的问法）。**身份约束会把「问」重新变回「不问」——这不是退步，而是平台级的理性。**

**引理 22（角色漂移的可检测性边界）** 若攻击者单步牵引 ε_step 落在策略分布内，且 D_role 单步增量小于「检测阈值 / 采样率」，则单步不可检；但累积漂移 D_drift 随步数线性增长，Page-CUSUM 在期望步数 O(ρ_role / (ε_step·SNR)) 内报警。系：**漂移检测必然有延迟**，故必须有「角色龄上限 + 定期强制重认证」兜底，不能只靠在线监控。

**定理 18（三层严格包含）** 在 A99–A101 下，ROLE-RAS 在任意状态的风险 ≤ FLUID-RAS ≤ R68；当「单角色 + 无迁移 + κ=0 + 𝒢_r=𝒜_info + 无漂移」时逐指令等于 R69；再叠加「不交互」时逐指令等于 R68。角色约束只收缩动作集，不扩风险。

**定理 19（切换无突变与授权不可伪造）** RSP 后控制连续、λ 单调不降；未持有效 auth_token 的切换请求一律拒绝；自我改角色在写路径上被硬阻断（角色标识不在可学习写集合内）⇒ **角色越狱在系统层不可达**，只剩社会工程层，需 RLB 与审计兜底。

**定理 20（可迁移证书的可靠性）** 若迁移间隙界成立且共享层未被越权写，则 J_ROLE 在目标身体 / 任务上的有效性蕴含风险 ≤ R_A + τ_gap；若 τ_gap 被低报，则可靠性沿 δ 线性退化。因此平台证书的可信度不是单点认证，而是**认证 + 间隙 + 审计**三件套的联合可信度。

## 6. 本轮最大风险

**一句话**：ROLE-RAS 最大的风险是把「角色一致」误当成「角色正确」——**一个稳定地扮演错误角色、或被外部在多轮交互中缓慢驯化成另一个角色的平台，会以更高的一致性做错事，而它的稳定签名反而帮它通过审计**；一致性是身份的必要条件，不是正确性的充分条件，把二者混淆，等于给错的身份发一张越用越可信的证书。

**次级风险与缓解**：
1. **一致性压制适应性**（ρ_role 过紧，新任务无法适配）→ 定义 321 的 Pareto 工作点 + 平台按角色分配预算；
2. **漂移检测有必然延迟**（定义 319 / 引理 22）→ 角色龄上限 T_r + 强制重认证兜底（定义 322）；
3. **迁移间隙被低报**（引理 20 的 δ）→ 独立探针估计 + 审计，禁止自报（定义 324 / 325）；
4. **角色越狱/泄漏**（ℰ_role_drift / ℰ_role_leak）→ 外部授权切换 + RLB 证据隔离 + ℰ_ROLE 对抗训练；
5. **身份签名可被博弈**（在未观测子空间悄悄漂移）→ 签名多样化观测 + 与 (r_res, Δa) 双通道联合，且始终保留「一致 ≠ 正确」的证书语义。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** ROLE-RAS = (RCM, RSI, GCD, PTC, R-MINT, RLB, RDM, RAS-WM‡)；继承零学习写 / 交互预算 / 证据纪律；新增**角色一致性**：除认证切换外 D_role ≤ ρ_role，且角色标识只可外部授权写（自我写集合不含它）。

**定义 311–312（角色契约与签名）** 角色是安全契约而非性格标签；φ 满足身体不变性 ‖φ(ψ·(o,ξ))−φ(o,ξ)‖ ≤ ε_ψ；D_role 为商掉 nuisance 之后的 Mahalanobis 散度；一致性 ⇔ sup_W D_role ≤ ρ_role。

**定义 313（GCD 分解）** 角色流形 ℳ_r 的切 / 法分解：Δ_∥ 协变（适配，允许），Δ_⊥ 不协变（漂移，报警）；D_drift = ∫‖Δ_⊥‖。**适配 = 角色内运动；漂移 = 角色参考系的非法移动。**

**定义 314–315（PTC 与角色族）** τ_gap = sup_p |R̂_A(p)−R̂_B(p)| ≤ L_trans·W₂(μ_A,μ_B)+ε_dec；迁移合法 ⇔ Valid(J_FLUID^A) ∧ τ_gap ≤ τ_max，且 R_B ≤ R_A + τ_gap；族证书 = 共享层 + 每角色残差，复用 = 一次认证 + 逐次加间隙。

**定义 316（R-MINT）** `g* = argmax_{g∈𝒢_r}[VoI(g) − c(g) − κ·D_role(g)]`；`max ≤ 0` 则不交互、退 R69 的 R68 兜底。身份与信息进入同一目标。

**定义 317（RSP）** 仅外部 σ_auth 可切换；五步 quiescence → re-anchor → 重认证 → 间隙校验 → λ 单调不降；系统可请求、不可自切。

**定义 318–320（RLB / RDM / 条件退避）** 证据带 prov(e)，跨角色需 re-validation + quarantine；D_role / δ_drift 走 Page-CUSUM，并与 (r_res, Δa) 组成三元判别；越界或报警则冻结适配、λ→R68、必要时进入安全静止角色 r_0。

**定义 321–322（折中与角色龄）** ρ_role 与适配收益构成 Pareto 工作点 𝒫；age(r) 超 T_r 或 D_drift 超 D_r^max 强制重认证（防缓慢合法化），重认证不重置证据纪律。

**定义 323–325（威胁 / 证书 / 审计）** ℰ_ROLE 含多轮驯化、跨角色泄漏、迁移偷渡；J_ROLE 见符号表，Valid 需全项满足；VQAuditor-R 审计越权切换、越角色证据、间隙低报，回灌 κ 先验与角色预算。

```python
def role_divergence(phi, o, xi, r, Psi):
    return min(maha(phi(psi(o, xi)), r.s, r.Sigma) for psi in Psi)  # |Psi|<=4

# IP-266 GCD：适应(切向) vs 漂移(法向)
def gauge_decompose(delta, role_manifold, x):
    T = role_manifold.tangent(x)
    d_par, d_perp = project(delta, T), delta - project(delta, T)
    return d_par, d_perp

# IP-268 R-MINT：角色条件查询

                - kappa * expected_signature_divergence_gain(g, o, r)
        if best is None or score > best.score: best = (g, score)

    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_r.submit_async(r, g, Drole, a_hat, M.ptc.gap())
    return k, lam, mode, (U_ale, U_epi, r)
```

## 4. 推导

**引理 19（规范分解下的无损适配）** 任务重参数化只改 nuisance 时，R69 的适配（模态选择 / resolution bonus）落在 Tℳ_r，法向分量为零 ⇒ R69 行为在 ROLE-RAS 下不增加 D_drift。R69 是「单角色 + 无迁移 + κ=0 + 无限角色预算」退化点。

**引理 20（迁移间隙的加性安全界）** 若 |R_A − R_B| ≤ τ_gap，则 B 上沿用 A 证书的保守上界为 R_A + τ_gap；仅当 τ_gap ≤ τ_max 且 R_A+τ_gap ≤ R_max 可免重认证。系：τ_gap 低报 δ ⇒ 可靠性沿 δ 线性退化，故必须独立探针估计并审计。

**引理 21（角色条件查询最优性与「问→不问」理性）** 在 g∈𝒢_r 下 R-MINT 最优；κ=0 ∧ 𝒢_r=𝒜_info 时退化为 R69 MINT。系：若 κ·D_role(g) > VoI−c，则最优是不问或换合身问法——**身份约束把「问」变回「不问」是平台级理性，不是退步**。

**引理 22（漂移可检测性边界）** 单步小牵引不可检；累积漂移线性增长，Page-CUSUM 期望 O(ρ_role/(ε_step·SNR)) 步报警 ⇒ **检测必有延迟**，必须用角色龄上限 + 强制重认证兜底。

**定理 18（三层严格包含）** A99–A101 下，ROLE-RAS 风险 ≤ FLUID-RAS ≤ R68；退化边界逐指令相同。角色约束只收缩动作集，不扩风险。

**定理 19（切换无突变与授权不可伪造）** RSP 后控制连续、λ 单调不降；无有效 auth_token 一律拒绝；系统写路径不含角色标识 ⇒ **角色越狱在系统层不可达**，只剩社会工程层。

**定理 20（可迁移证书可靠性）** 间隙界成立且共享层未被越权写时，J_ROLE 有效 ⇒ 目标风险 ≤ R_A + τ_gap；τ_gap 低报则线性退化。平台证书可信度 = **认证 + 间隙 + 审计** 三件套。

## 7. 本轮最大风险

**一句话**：ROLE-RAS 最大的风险是把「角色一致」误当成「角色正确」——**一个稳定地扮演错误角色、或被外部多轮缓慢驯化成另一个角色的平台，会以更高的一致性做错事，而它的稳定签名反而帮它通过审计**；一致性是身份的必要条件、不是正确性的充分条件，把二者混淆，等于给错的身份发一张越用越可信的证书。

**次级风险与缓解**：一致性压制适应性（定义 321 Pareto 工作点 + 按角色分配预算）；漂移检测必然有延迟（定义 322 角色龄上限 + 强制重认证）；迁移间隙被低报（独立探针 + 审计，禁止自报）；角色越狱 / 泄漏（外部授权切换 + RLB + ℰ_ROLE 对抗训练）；签名可被博弈（多观测 + (r_res, Δa) 联合，并始终保留「一致 ≠ 正确」的证书语义）。
