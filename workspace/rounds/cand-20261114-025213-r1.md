# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环第 3 轮；本轮灵感：「多机协同」×「工具调用」）

> R69 把不确定性一分为二，并让系统学会「问」：aleatoric 收紧、epistemic 去交互消解。但 R69 的整个求证框架建立在两个未言明的假设上：**(a) 证据源相互独立**（「k 个正交证据源一致」）；**(b) 被问对象是只读、可逆、会如实回答的**。真实的多机协同与工具调用同时击穿这两条：
> - 队友常常共享同一个预训练 trunk / 同源传感器 / 同一训练分布——**k 个队友不是 k 个独立证人，而是一个证人被复印了 k 份**；一致可以是共同偏差，甚至是被制造的共识。
> - 工具调用不是连续动作，而是一份**带前置/后置条件、有副作用、可能不可逆、可能很慢、可能说谎的离散承诺**；R69 的「看一眼 / 问一句 / 摸一下」只是它最良性、可逆的特例。
>
> 核心命题：**把「向世界提问」升级为「向队友/工具委派」，并把安全从「每个成员各自合格」升级为「成员之间的契约可组合」。** 用**工具契约**描述每次调用的 pre/post/effect/可逆性/责任人；用**有效独立度 k_eff** 修正 R69 的相关性盲点；用**两阶段契约提交**保证「副作用前先验证、在途不取安全信用」；用**联邦证书**把局部安全组装成全局安全；用**盲化金丝雀 + 责任归因 + 信任账本**对付共谋、能力虚报与契约漂移。命名 **CITADEL-RAS**（Contract-Interface-Trust-Attribution-Delegation-Evidence-Latency）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我该把这件事托付给谁，我们合起来还安全吗**」——从「向世界提问」到「向队友委派，并为组合后果负责」。

## 0. 直觉与动机

**灵感 1（多机协同 → 一致性可能只是共同偏差）**
直觉：R69 用「k 个正交证据源一致」对抗单源投毒，隐含假设证据独立。但编队里的机器人往往同厂商、同模型、同传感器，甚至共用 R69 的 MTM trunk。它们对同一个错觉会给出同一份「确认」：四台机器人异口同声说门是开的，可能只是四个副本在重复同一个错误。更糟的是，一致性本身可以被**制造**（共谋、Sybil 代理）。所以「数票」之前必须先问：**这些票的有效独立数是多少？** 统计学给出的答案很干净——`k_eff = k/(1+(k−1)ρ̄)`，ρ̄ 是误差相关系数。ρ̄=0 时退化为 k；ρ̄→1 时无论 k 多大都只有 1。R70 的第一块基石就是把这一「设计效应」显式化并门控。

**灵感 2（工具调用 → 调用是一份可撤销的契约，不是一段动作）**
直觉：连续动作错了可以随时修正；工具调用一旦产生副作用（抓取、开门、下单、对外广播、把控制权交给另一个 agent），就可能不可逆。因此每次调用都应携带一份契约：前置条件 Pre、后置条件 Post、影响帧 Eff、成本、最大时延 ℓ、可逆等级 Rev、唯一责任人 Owner。R69 的「看 / 触 / 问」正好是 Rev=reversible、Eff=∅、Post=「我获得了信息」的最弱契约。把这一层显式化后，安全不再是「这个动作对不对」，而是「**这份契约的前置条件此刻成立吗、它的副作用还在安全包络内吗、失败后我能撤销吗**」。

**灵感 3（委派是三角形，不是标量）**
直觉：R69 的 MINT 只优化 VoI − 成本，因为它假设被问方「知道就说」。委派给队友/工具则要同时看三件事：**能力**（它真能完成吗）、**对齐**（它会按我的意图做吗）、**可逆性**（做错了能收回吗）。一个工具可以极大降低我的 epistemic 不确定性，却执行一个危险副作用——VoI 高不等于该委派。于是把 R69 的 VoI 升级为**委派值 DV = 期望任务收益 − 成本 − 副作用风险 − 信任惩罚 − 时延惩罚**，并加上「契约可满足 / 信任 ≥ 阈值 / 可逆性」三重约束。VoI 是它在「只读、可逆、无副作用」处的特例。

**灵感 4（组合安全 → 局部证书不蕴含全局安全）**
直觉：R69 给每个闭环发一张证书。多机/多工具时，即使每张证书都有效，组合也可能不安全——最典型的失败不是某个模块错，而是**假设-保证失配**：A 的后置条件不满足 B 的前置条件，A 以为「门已开」，B 以为「门是关的」，各自都对，合起来撞门。这是构件化系统里最常见、也最隐蔽的漏洞。因此本轮必须交付「接口良构性」的运行时检查（`Post_a ⇒ Pre_b`）与**联邦证书**，把「每个都合格」升级为「接缝也合格」。

**灵感 5（新攻击面 → 一致性识别不了共谋）**
直觉：R69 的投毒模型是「单个来源撒谎」，所以多数一致能压住。但只要两个来源**串通**，它们可以在任何输出分布上伪装成诚实且独立的两个来源——任何只看输出的检验都无法区分「真的一致」与「演出来的一致」。因此对抗共谋必须引入**外部真值通道**：用已知答案的金丝雀 / 挑战查询做随机抽查，才能把「相关」与「共谋」分开。而且金丝雀必须**对来源盲化**：若来源能识别出这是抽查，它只要在抽查时说实话、在真实查询时撒谎即可。这是本轮一个偏信息论的硬结论：**在输出上识别共谋是不可能的，必须花预算去问一个你已经知道答案、且来源无法识别的问题。**

**灵感 6（慢调用 → 在途期间不能预支安全）**
直觉：工具调用有延迟，等待时世界会变，前置条件可能过期。R69 在「交互成功」后立刻兑现 resolution bonus；R70 不能这么做：**在 Post 被确认之前，不取任何安全信用**，λ 保持 R69 的保守地板，并维持 R69 兜底作为 holding policy。这条「在途零信用」是 R69「未消解 epistemic 视同 aleatoric」在时间维度上的镜像。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（CITADEL-RAS 总览）** CITADEL-RAS = (ICC, CDC, EDE, CCP, 2PCC, AGF, CA, TL, RAS-WM†)。五不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **契约先于副作用**：任何调用在产生 Eff 前必须通过提交时刻的 Pre 复核（定义 317）；
(iii) **在途零安全信用**：Post 未确认前 λ 不低于 R69 的 λ_floor，holding policy 恒为 R69（定义 318）；
(iv) **有效独立门控**：证据聚合要求 `k_eff ≥ k_min`（默认 2，定义 315）；
(v) **唯一责任人**：每个不可逆副作用必须绑定一个可追溯 Owner，且需显式确认（定义 317/320）。

**定义 311（调用契约 ICC）** 一个可调用体（工具/agent/技能）c 的契约为
`C_c = (Pre_c, Post_c, Eff_c, Cost_c, ℓ_c, Rev_c, Owner_c, ver_c)`，
其中 Pre/Post 是世界状态谓词，Eff 是受影响变量帧，ℓ 是最大时延，`Rev_c ∈ {R, C, I}`（reversible / compensable / irreversible），ver 用于检测契约漂移。称 c 在状态 s **可采纳**当且仅当 `Pre_c(s) ∧ Eff_c ⊆ SafeFrame(s)`（副作用不推出安全包络）。

**定义 312（细化与组合；契约健全性）** `C_a ⊑ C_b` 当且仅当 `Pre_b ⇒ Pre_a`、`Post_a ⇒ Post_b`、`Eff_a ⊆ Eff_b`、`Cost_a ≤ Cost_b`、`Rev_a` 不弱于 `Rev_b`。组合 `C_a ; C_b = (Pre_a ∧ (Post_a ⇒ Pre_b), Post_b, Eff_a ∪ Eff_b, …)`。组合**良构**当且仅当 `Post_a ⇒ Pre_b`；否则称发生**假设-保证失配**。A99（契约健全性假设）：运行时监视器对 Pre/Post/Eff 的判定与真实世界一致，且在有效窗口内不漂移。

**定义 313（联盟计划 DAG）** 一个委派计划是 DAG `π = (V, E, τ)`：每个顶点是一份调用契约，每条边 a→b 表示「a 的产物喂养 b」，要求 `Post_a ⇒ Pre_b`（定义 312）。计划**拓扑良构**当且仅当对所有边成立良构且 `Eff_π = ∪Eff_v ⊆ SafeFrame`。安全在计划的每一个割集上都要求全局不变式 G 成立——不是只在末尾检查。

**定义 314（委派值 DV；MINT 的严格泛化）** 对任务 τ 与候选 c：
`DV(c,τ) = E[V(τ,c) | C_c, o] − Cost_c − Risk(Eff_c) − TP(c) − Lat(ℓ_c)`，
约束为 `admissible(c) ∧ trust(c) ≥ τ_trust ∧ cap 覆盖 τ`。选择 `c* = argmax DV` s.t. 约束成立；若 `max DV ≤ 0` 或无可采纳者 → **本地执行，退回 R69**。当 c 为信息动作、`V=VoI`、`Eff=∅`、`Rev=R`、`TP=Lat=0` 时，DV 退化为 R69 的 `VoI − c(g)`，故 MINT 是 DV 的边界情形。

**定义 315（有效独立度 EDE）** 给定 k 个证据源及其在校准集上的误差 `e_i`，令 `ρ̄` 为误差两两相关均值，则
`k_eff = k / (1 + (k−1)ρ̄)`。
要求 `k_eff ≥ k_min` 方可做决定性聚合；若 `k_eff < k_min`，不得靠「再加一个同源队友」凑数，只能寻找**去相关源**（不同模态 / 时间尺度 / 物理原理），或弃权。ρ̄ 不可估时按 `ρ̄=1` 保守处理（等价单源）。R69 的「k 个正交源」隐含 `ρ̄=0 ⇒ k_eff=k`，是本定义的特例。

**定义 316（相关 vs 共谋；盲化金丝雀）** **相关**是统计性的共同误差（共享 trunk/传感器/训练分布），可由历史估计；**共谋**是策略性的协同作假，任意仅依赖输出的检验对其**零功效**（因为共谋者可模拟诚实源的输出分布）。因此引入金丝雀协议 CCP：以 m 个**对来源盲化、真值不被来源获知**的已知答案查询抽查，单次命中概率 p_c，则检出概率 `≥ 1 − (1−p_c)^m`。定义共谋可疑度 `χ = 1 − ∏_i (1 − fail_i)`。**只有通过盲化金丝雀的源，才可计入决定性一致**；未通过者视为相关源（按其 k_eff 折算，最坏按 1 计）。若金丝雀不盲化（来源能识别抽查），则 p_c=0，协议失效——这是必须写进威胁模型的前提。

**定义 317（两阶段契约提交 2PCC）** 对调用 c：
(1) *propose*：在 t0 验证 Pre、预留 Eff；
(2) *commit*：在 `t1 ≤ t0 + valid_window` **重新**验证 Pre（世界可能已变）；不成立则释放预留并 ABORT；
(3) *execute + confirm*：执行并在 ℓ_c 内监视 Post；
(4) *处置*：Post 成立 → 释放安全信用；`Rev ∈ {R,C}` 且 Post 失败 → 补偿（compensate）；`Rev=I` 或补偿失败 → 上报 Owner 并冻结计划余下顶点。不可逆调用额外要求 `Owner_confirm(c)=true`。

**定义 318（在途安全与 holding policy）** 从 propose 到 confirm 的整个**在途区间**内，令 `λ ≥ λ_floor(U_ale + U_epi)`（R69 定义 307 的未消解值），且执行策略为 R69 兜底。**在途不兑现 resolution bonus**；Post 确认后才允许降 λ。ABORT/失败/超时 → λ 单调不降地回到 R69 地板。这是 R69 定理 17「无突变」在时间维度的镜像。

**定义 319（能力证书）** `cap_c = (domain_c, verified_success_c, expiry_c, evidence_hash_c)`。委派只允许发生在 `domain_c` 内；能力**虚报**通过金丝雀/探针任务检出（在已知难度的任务上失败）。过期能力需重验，不允许「一次认证，永久使用」。

**定义 320（信任账本 TL）** 每个可调用体维护 `t_c ∈ [0,1]`：成功且金丝雀通过时 `t_c ← t_c + η(1 − t_c)`，失败时 `t_c ← t_c − η' t_c`，长期未验证则衰减；金丝雀失败、Post 说谎、或契约漂移 → **立即吊销**并把该 c 从候选集移除，直到重新认证。t_c 直接门控 DV（定义 314）。

**定义 321（责任归因 CA）** 联盟失败后，对每个成员 i 计算其对失败的反事实贡献（Shapley 值）
`φ_i = Σ_{S⊆N\{i}} [|S|!(n−|S|−1)!/n!] · (v(S∪{i}) − v(S))`，
其中 v(S) 为成员子集 S 参与时的失败指示。φ 用于**更新信任账本与路由审计**，不用于惩罚；且**不得由单方日志单独定案**（防止把锅甩给工具）。k≤5 时精确计算，否则蒙特卡洛近似。

**定义 322（联邦证书 J_CITADEL）** `J_CITADEL = ({J_i}, {interface_proof_ij}, k_eff, collusion_checks, cap_evidence, delegation_log_hash, in_flight_ledger_hash, attribution, citadel_ver)`。
`Valid ⇔` 每个成员 `J_i` 有效 ∧ 所有调用边良构（定义 312）∧ `k_eff ≥ k_min` ∧ 所有不可逆调用有 Owner 确认 ∧ 在途期无安全信用 ∧ 金丝雀通过率 ≥ 阈值。**联邦证书不要求信任一个整体联盟模型**，只要求信任每个成员证书 + 每条接缝证明。

**定义 323（威胁模型 ℰ_CITADEL）** `ℰ_CITADEL = ℰ_CALM × ℰ_poison × ℰ_tool × ℰ_collude`：
ℰ_tool = {供应链投毒、Post 说谎、能力虚报、契约漂移（工具版本静默变更）、Blast radius 越界}；
ℰ_collude = {共谋一致、共享 trunk 的相关失败被对抗性放大、Sybil 代理（一个实体伪装成多个独立源）}。
（ℰ_CALM、ℰ_poison 继承 R68/R69。）

**定义 324（双预算：交互预算 × 承诺预算）** 继承 R69 的交互频率/位移/社交成本；新增**承诺预算**：每回合不可逆副作用 ≤ 1（或强制人工确认）、可逆副作用 ≤ b_rev、blast radius ≤ r_max。预算按**计划级**核算（定义 313），不得通过把一个大调用拆成多个小调用规避。

**定义 325（严格退化到 R69）** 当联盟有效规模 = 1、所有调用为只读可逆信息动作（Eff=∅, Rev=R, Cost=VoI 成本）、所有接缝平凡良构、且 `ρ̄=0 ⇒ k_eff=k` 时，CDC 的 `argmax DV` 逐项等于 MINT 的 `argmax[VoI−c]`，`J_CITADEL ≡ J_FLUID`，在途区间为空。故 **R69 恰是 CITADEL 在「单机 / 只读工具 / 独立证据」边界上的退化**。

## 2. 关键算法骨架

```python
# IP-264 ICC：调用契约与运行时监视
class Contract:
    # Pre/Post: state -> bool; Eff: frame; Rev in {R,C,I}
    def admissible(self, s):
        return self.pre(s) and subset(self.eff, safe_frame(s))

# IP-266 EDE：有效独立度（把 R69 的「k 个正交源」变成可测的量）
def effective_independence(errors):
    k   = len(errors)
    rho = mean_pairwise_error_corr(errors) if k > 1 else 0.0
    return k / (1.0 + (k - 1) * rho), rho      # k_eff, rho_hat

# IP-267 CCP：盲化金丝雀（区分相关与共谋；非盲化则 p_c=0）
def canary_check(sources, m, p_c, blind=True):
    fails = [src.fail_canary(blind=blind) for src in sources]
    chi   = 1.0 - prod(1.0 - f for f in fails)  # 共谋可疑度
    return chi, fails, 1.0 - (1.0 - p_c) ** m   # (chi, fail flags, 检出下界)

# IP-268 2PCC：副作用前复核，在途零信用
def two_phase_commit(c, s, valid_window):
    if not c.contract.admissible(s):            return ABORT
    reserve(c.contract.eff)                     # λ 仍 >= R69 floor
    s1 = observe_fresh()
    if not c.contract.pre(s1):                  # 前置条件已过期
        release(c.contract.eff);               return ABORT
    res = c.execute()
    if c.contract.post(res):                    return COMMIT
    if c.contract.rev in (R, C): compensate(c); return COMPENSATED
    escalate(c.contract.owner);                return FROZEN

# IP-265 CDC：委派值选择（VoI 的严格泛化；无利可图即本地 R69）
def choose_delegate(task, candidates, s, budget, k_eff_gate):
    best = None
    for c in candidates:
        if not budget.allow_plan(c) or not trust_ok(c):        continue
        if not cap_covers(c, task) or not well_formed(c):      continue
        dv = (expected_value(task, c)
              - c.contract.cost - risk(c.contract.eff)
              - trust_penalty(c) - latency_penalty(c.contract.ell))
        if best is None or dv > best.dv: best = (c, dv)
    return best if best and best.dv > 0 else LOCAL_R69    # 退化边界

# IP-269 AGF：联邦证书（局部安全 -> 组合安全）
def federation_valid(plan, members, k_eff, collusion, inflight):
    if not all(J_i.valid for J_i in members):                 return False
    if not all(post(a) >> pre(b) for a, b in plan.edges):     return False  # 接缝
    if k_eff < K_MIN or collusion > TAU_COLLUDE:              return False
    if any(edge.in_flight and edge.took_safety_credit
           for edge in plan.edges):                           return False
    return True

# IP-273 主闭环：R69 原样在前，委派与组合安全在后
def CITADEL_round(M, obs, task):
    k, lam, mode, U = FLUID_RAS_round(M, obs)          # R69 完全保留
    plan = M.cdc.propose_plan(task, M.tools, obs)      # 契约 DAG
    if not M.agf.federation_valid(plan, M.members,
                                  M.ede.last_k_eff, M.ccp.last_chi,
                                  M.inflight):
        return k, lam, mode, U                          # 不可组合 => 本地执行
    for call in topo_sort(plan):
        if call.rev is I and not call.owner_confirm():  continue
        out = two_phase_commit(call, obs, call.valid_window)
        M.inflight.record(call, out)                    # 在途 λ 不降
        if out is FROZEN:                               break
    M.tl.update_from(M.inflight); M.ca.attribute(M.inflight)
    M.vqa_i.submit_async(plan, M.inflight, M.ede.rho_hat)
    return k, lam, mode, U
```

## 3. 推导

**引理 19（有效独立度收缩；R69 引理 18 的修正）** 在 R69 的 k 源多数一致纪律下，若误差两两相关均值 ρ̄，则错误采纳率上界从 `δ_p·ρ^{k−1}` 修正为 `δ_p·ρ^{k_eff−1} + ε_σ`，其中 `k_eff = k/(1+(k−1)ρ̄) ≤ k`，等号当且仅当 ρ̄=0。系：**共享 trunk 的 k 个队友可能 k_eff<2**，此时「十票一致」的信息量还不如一个独立传感器；R69 的「k 个正交源」在 ρ̄>0 时是空洞的，必须由 EDE 门控。

**引理 20（共谋的输出不可辨识性；为何必须外部真值）** 若共谋者可实现与诚实源相同的输出条件分布（它们知道该分布），则「诚实」与「共谋」两个假设在输出序列上同分布，任何只依赖输出的检验功效为 0。因此决定性一致必须依赖一条外部真值通道。金丝雀协议在**盲化**且来源无法获知真值时可检出，检出概率 `≥ 1−(1−p_c)^m`。系：**金丝雀的盲化是安全前提，不是工程细节**；可被识别的抽查等于没有抽查。

**引理 21（假设-保证失配的脆弱性）** 即使 `C_a`、`C_b` 各自在其自洽域内健全，若缺少 `Post_a ⇒ Pre_b`，组合仍可违反 G；失配概率随接口维度与工具版本漂移上升。AGF 在产生 Eff 前检查该蕴含，把「运行期相撞」变成「提交期拒绝」。系：组合安全的瓶颈在**接缝**，不在单件。

**定理 18（CITADEL 严格包含 R69）** 在 A95–A99 下，CITADEL 在任意状态 s 的期望风险 ≤ R69；且当 `DV(c*) ≤ 0`、`k_eff < k_min`、`χ > τ`、联邦证书无效或 `Rev=I` 未获确认时，两者**逐指令相同**（定义 314、322、325）。故 R69 是 CITADEL 在「单机 / 只读 / 独立证据」边界上的退化，安全侧不做任何让步，效率侧获得委派收益。

**定理 19（在途无安全信用 ⇒ 无突变）** 在 propose→confirm 的在途区间内 λ 不低于 R69 的 `λ_floor(U_ale+U_epi)`，且 holding policy 为 R69；ABORT/失败/超时使 λ 单调回到该地板，不产生新的不安全状态转移；补偿只作用于已预留的 Eff，不扩张安全包络。故委派引入的慢调用不违反 R69 定理 17 的连续性。

**定理 20（联邦证书可靠性）** 若 (i) 每个成员 `J_i` 有效，(ii) 计划的每条边良构（`Post_a ⇒ Pre_b`），(iii) `k_eff ≥ k_min` 且共谋可疑度 `χ ≤ τ`，(iv) 每个不可逆副作用有 Owner 确认，(v) 在途无安全信用，则组合系统满足全局不变式 G。**前提是契约监视器健全（A99）**——这是本定理唯一、也是致命的信任根。

## 6. 本轮最大风险

**一句话**：CITADEL-RAS 的全部组合安全都押在「契约是真的」这一前提上——**若契约漂移或被伪造（Post 说谎、Pre 判定错误、工具版本静默变更），定理 20 证明的只是一个不存在的联盟，系统会用一张合法的联邦证书为一个实际越界的行为背书**；一个错误的契约比没有契约更危险，因为它把「未知」包装成「已证明」。

**次级风险与缓解**：
1. **k_eff 的 ρ̄ 估计在分布漂移下失准** → 不确定时按 ρ̄=1 保守处理（等价单源）+ 在线重估 + E302；
2. **共谋者识别金丝雀** → 金丝雀盲化 + 随机化 + 真值不可被来源获知，必要时改用不可伪造的物理探针（E304）；
3. **在途期间世界剧变** → validity window + 提交时复核 + holding policy，超窗即 ABORT（定义 317–318、E307）；
4. **责任归因被博弈**（把锅甩给工具）→ Shapley 反事实 + 审计抽样 + 单方日志不得定案（定义 321、E309）；
5. **预算被拆分规避** → 计划级 DAG 全局核算，不按单次调用计（定义 324）。

## 3. 关键算法伪代码

```python
# IP-266 EDE：有效独立度（修正 R69 的「k 个正交源」）
def effective_independence(errors):
    k   = len(errors)
    rho = mean_pairwise_error_corr(errors) if k > 1 else 0.0
    return k / (1.0 + (k - 1) * rho), rho          # k_eff, rho_hat

# IP-267 CCP：盲化金丝雀（区分相关与共谋）
def canary_check(sources, m, p_c, blind=True):
    fails = [s.fail_canary(blind=blind) for s in sources]
    chi   = 1.0 - prod(1.0 - f for f in fails)
    return chi, fails, 1.0 - (1.0 - p_c) ** m

# IP-265 CDC：委派值（VoI 的严格泛化，无利可图即本地 R69）
def choose_delegate(task, candidates, s, budget):
    best = None
    for c in candidates:
        if not budget.allow_plan(c) or not trust_ok(c):      continue
        if not cap_covers(c, task) or not well_formed(c):    continue
        dv = (expected_value(task, c) - c.contract.cost
              - risk(c.contract.eff) - trust_penalty(c)
              - latency_penalty(c.contract.ell))
        if best is None or dv > best.dv: best = (c, dv)
    return best if best and best.dv > 0 else LOCAL_R69

# IP-268 2PCC：副作用前复核，在途零信用
def two_phase_commit(c, s, valid_window):
    if not c.contract.admissible(s):            return ABORT
    reserve(c.contract.eff)
    s1 = observe_fresh()
    if not c.contract.pre(s1):                  # 前置条件已过期
        release(c.contract.eff);                return ABORT
    res = c.execute()
    if c.contract.post(res):                    return COMMIT
    if c.contract.rev in (R, C): compensate(c); return COMPENSATED
    escalate(c.contract.owner);                 return FROZEN

# IP-269 AGF：联邦证书（局部安全 -> 组合安全）
def federation_valid(plan, members, k_eff, chi, inflight):
    if not all(J.valid for J in members):                     return False
    if not all(post(a) >> pre(b) for a, b in plan.edges):     return False  # 接缝
    if k_eff < K_MIN or chi > TAU_COLLUDE:                    return False
    if any(e.in_flight and e.took_safety_credit for e in plan.edges):
        return False                                          # 在途零信用
    return True

# IP-273 主闭环：R69 原样保留，委派与组合安全在其后
def CITADEL_round(M, obs, task):
    k, lam, mode, U = FLUID_RAS_round(M, obs)          # R69 完全保留
    plan = M.cdc.propose_plan(task, M.tools, obs)      # 契约 DAG
    if not M.agf.federation_valid(plan, M.members, M.ede.last_k_eff,
                                  M.ccp.last_chi, M.inflight):
        return k, lam, mode, U                          # 不可组合 => 本地执行
    for call in topo_sort(plan):
        if call.rev is I and not call.owner_confirm():  continue
        out = two_phase_commit(call, obs, call.valid_window)
        M.inflight.record(call, out)                    # 在途 λ 不降
        if out is FROZEN:                               break
    M.tl.update_from(M.inflight); M.ca.attribute(M.inflight)
    M.vqa_i.submit_async(plan, M.inflight, M.ede.rho_hat)
    return k, lam, mode, U
```

## 4. 推导

**引理 19（有效独立度收缩；R69 引理 18 修正）** k 源一致纪律的错误采纳上界由 `δ_p·ρ^{k−1}` 修正为 `δ_p·ρ^{k_eff−1}+ε_σ`，`k_eff=k/(1+(k−1)ρ̄)≤k`，等号当且仅当 ρ̄=0。系：共享 trunk 的队友可 `k_eff<2`，「十票一致」不如一个独立传感器——R69 的正交性假设在 ρ̄>0 时是空洞的。

**引理 20（共谋不可辨识；为何必须外部真值）** 若共谋者可模拟诚实源的输出条件分布，则「诚实」与「共谋」在输出序列上同分布，仅依赖输出的检验功效为 0。盲化金丝雀提供外部真值通道，检出 `≥1−(1−p_c)^m`。系：金丝雀盲化是安全前提，非工程细节；可被识别的抽查等于没有抽查。

**引理 21（假设-保证失配的脆弱性）** 各自健全的 `C_a,C_b` 若缺 `Post_a⇒Pre_b`，组合仍可违反 G；失配概率随接口维度与版本漂移上升。AGF 在产生 Eff 前拒绝，把运行期相撞变成提交期拒绝。系：组合安全瓶颈在接缝。

**定理 18（CITADEL 严格包含 R69）** A95–A99 下任意状态期望风险 ≤ R69；当 `DV≤0`、`k_eff<k_min`、`χ>τ`、证书无效或 `Rev=I` 未确认时两者逐指令相同。R69 是「单机/只读/独立证据」边界，安全不让步，效率获委派收益。

**定理 19（在途无安全信用 ⇒ 无突变）** 在途区间 λ 不低于 R69 地板，holding policy 为 R69；ABORT/失败/超时使 λ 单调回地板，补偿只作用于已预留 Eff，不扩张安全包络；慢调用不破坏 R69 定理 17 的连续性。

**定理 20（联邦证书可靠性）** 成员证书有效 ∧ 每条接缝良构 ∧ `k_eff≥k_min` ∧ `χ≤τ` ∧ 不可逆副作用有 Owner 确认 ∧ 在途零信用 ⇒ 组合系统满足 G。**唯一信任根是契约监视器健全（A99）**。

## 7. 本轮最大风险

**一句话**：CITADEL-RAS 的全部组合安全押在「契约是真的」这一前提上——**若契约漂移或被伪造（Post 说谎、Pre 判定错误、工具版本静默变更），定理 20 证明的只是一个不存在的联盟，系统会用一张合法的联邦证书为一个实际越界的行为背书**；一个错误的契约比没有契约更危险，因为它把「未知」包装成「已证明」。

**次级风险与缓解**：ρ̄ 在分布漂移下失准（按 ρ̄=1 保守 + 在线重估 + E302）；共谋者识别金丝雀（盲化 + 随机化 + 不可伪造的物理探针，E304）；在途世界剧变（validity window + 提交复核 + holding policy，E307）；归因被博弈（Shapley 反事实 + 审计抽样 + 单方日志不定案，E309）；预算被拆分规避（计划级 DAG 全局核算，定义 324）。
