# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「伦理与合规」×「工具调用」）

> 第 54 轮把技能组合推进到动作空间剖面 α_S 与云边联合证书 J。本轮把问题从“能不能做、做得稳不稳”推进到“**该不该做、凭什么做、做完能否问责**”。核心矛盾：H22：能力证书与合规证书正交，能力越强越可能越权——一个高 ρ 的技能完全可以同时是“不可许”的；H23：工具调用是系统与世界之间的**副作用原子**，一次不可逆调用可绕过多轮鲁棒性保证，把“仿真内可信”直接放大为“现实中的不可撤销伤害”。

## 0. 直觉与动机

**灵感 1（从“能”到“可”：规范动作空间）**
直觉：第 54 轮的 `α_S(a)` 只回答“能否执行”，不回答“是否被允许”。合规是一个**规范投影** `ν(a;c)`，依赖上下文 `c=(管辖域, 主体, 目的, 同意状态, 政策版本, 时刻)`。真正可部署的动作空间是 `A_dep = A_cap ∩ A_perm`，是**交集而非替代**。关键：`forbid` 是吸收态，任何能力证书都不能覆盖它；`conditional` 必须附带义务（记录、通知、补偿、再征得同意）并证明义务已履行。伦理判断不能被“我做得很好”所抵消。

**灵感 2（工具调用 = 有副作用的动作原子）**
直觉：工具调用 `t` 不只是函数调用，而是带**效果签名** `E(t)` 的状态转移：改了哪些状态、作用在谁身上、影响面 `blast` 多大、是否可逆 `rev∈{R,C,I}`。其中 `I`（不可逆）是“伦理奇点”——一旦执行无法回滚。于是合规门控的重心不是“调不调得动”，而是“这个副作用能否被撤回或补偿”。这把第 54 轮的抽象动作 `a` 落到了“现实后果”上。

**灵感 3（双钥匙：能力与合规不可互相推导）**
直觉：部署一次有副作用的工具调用需要两把钥匙同时插入：能力钥匙 `J_cap`（第 54 轮联合证书）与合规钥匙 `C_comp`（授权、目的、效果、可逆性、审计）。二者正交：可靠地读取隐私数据仍是违规；合规但不可靠的调用仍不能上线。**能力永远不蕴含合规**，这是本轮的结构性公理，也是整个体系的安全边界。

**灵感 4（授权只会衰减：委托格与混淆代理）**
直觉：用户 → Agent → 子 Agent → 工具形成委托链，权限必须沿链单调收缩 `A_{i+1} ⊑ A_i`。任何“放大”都是越权。特别地，低权限调用者借高权限工具行事的**混淆代理**（confused deputy）必须在格上被静态检出。这与 L0 的“根信任 + 能力格”天然衔接，只是把“信任”细化为“可证明的授权衰减”。

**灵感 5（分级自主：把伦理变成显式门控函数）**
直觉：伦理不是一句口号，而是按风险分级的**自主度函数** `ℓ(t)=min(ℓ_cap(ρ), ℓ_comp(ν), ℓ_risk(r))`。不可逆、大 blast、弱主体、敏感数据 → 风险等级 R3 → 必须 human-only；能力再强也不能自动放行。这是“比例原则”的工程化：越危险的动作，需要越强的证据与越高的人类参与。

**灵感 6（合规漂移 + 可审计账本：授权时合规 ≠ 执行时合规）**
直觉：授权是一个时间快照，政策会变、同意会过期、管辖域会切换。必须定义**合规漂移** `δ_c` 并在超阈值时即时重校验；同时用哈希链账本把每次工具调用的证书、效果、结果不可篡改地记录下来，使事后问责与重放成为可能。Explain 也从“物理失败根因”扩展为“**规范失败根因**”（违反哪条规则、哪段授权、哪项义务未履行）。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（规范动作空间与合规剖面）**
上下文 `c=(j,u,p,k,v,τ) ∈ C`，分别表示管辖域、主体、目的、同意状态、政策版本、时刻。规范剖面 `ν: A × C → D × O × [0,1]`，`D={permit, conditional, forbid}`，`O` 为义务集合。合规判定：
```
comp(a;c) ⇔ ν(a;c).decision ≠ forbid ∧ ∀o ∈ O(a;c): discharged(o,c)
```
可部署动作空间 `A_dep(c) = { a ∈ A | α_S(a) ≥ θ_cov ∧ comp(a;c) }`。**单调性假设（A29）**：若 `c'` 比 `c` 更严格，则 `A_dep(c') ⊆ A_dep(c)`；`forbid` 为吸收态，不可被任何能力证据覆盖。

**定义 122（工具调用原子与效果签名）**
工具调用 `t=(id,args,pre,E,rev,b,subj,ttl)`：
- `E ⊆ ΔS` 为效果签名（被执行后必须成立的状态差分集合）；
- `rev(t) ∈ {R,C,I}`：`R` 存在精确逆操作，`C` 存在有界残差的补偿操作，`I` 不存在逆或补偿；
- `b(t)=Σ_{e∈subj} severity(e,E)` 为影响面；
- 执行语义：`s --t--> s'` 当且仅当 `pre(s)` 成立且 `(s'⊖s) ⊨ E`。
“不可逆”意味着任何事后审计只能追责、不能复原，故必须在**执行前**门控。

**定义 123（双钥匙证书）**
```
C_tool = (J_cap, Auth, Pur, E, rev, Obl, root, pol_ver, ttl, sig)
```
`Valid(C_tool,c)` 当且仅当六项同时成立：
1. `J_cap.dom=in` 且 `J_cap.ρ ≥ ρ_min(Pur)`（能力钥匙，承接第 54 轮）；
2. `Auth ⊑ Auth_root` 且 `purpose_bound(Auth,Pur)`（目的绑定，不得挪用）；
3. `comp(t;c)` 且 `Obl ⊆ discharged`（规范钥匙）；
4. `rev=I ⇒ b ≤ blast_budget(Pur) ∧ ℓ=human-only 且已获批准`；
5. `pol_ver=current` 或 `δ_c ≤ Θ_c`（未过期、未漂移）；
6. `root = ledger.root`（审计根一致）。
部署条件：`deploy(t) ⇔ Valid(C_tool,c) ∧ GAL(t)=pass`。**两把钥匙缺一不可，且互不推导。**

**定义 124（授权格与委托衰减）**
授权格 `(𝔄, ⊑, ⊓, ⊔, ⊥, ⊤)`。委托链 `π=A_0,...,A_k`。**衰减**：`attenuated(π) ⇔ ∀i, A_{i+1} ⊑ A_i`。**放大**：`¬attenuated(π)`。**混淆代理**：调用者权限 `A_c` 调用需要 `A_t` 的工具且 `¬(A_t ⊑ A_c)`。任何放大或混淆代理都是硬拒绝，不进入后续成本权衡。

**定义 125（风险分级与分级自主）**
风险等级 `r(t)=g(b(t), rev(t), sensitivity(subj), jurisdiction_risk) ∈ {R0,R1,R2,R3}`。自主度 `ℓ(t)=min_ℓ(ℓ_cap(ρ), ℓ_comp(ν), ℓ_risk(r))`，等级序 `auto < notify < confirm < human-only`。规则：`r=R3` 或 `rev=I ∧ b>B_1` ⇒ `ℓ=human-only`，能力再强不得降级。

**定义 126（合规漂移与可审计账本）**
```
δ_c = w_p·d(pol_ver_auth, pol_ver_exec) + w_k·d(consent_auth, consent_exec) + w_j·d(jur_auth, jur_exec)
```
若 `δ_c > Θ_c` 则执行前强制重校验。审计账本 `L=[(i, h_i, hash(C_i), effect_i, outcome_i, h_{i-1})]`，`h_i=H(h_{i-1}‖hash(C_i)‖effect_i‖outcome_i‖t_i)`，构成哈希链，具备防篡改与可重放性。**规范 Explain** 返回 `(rule_id, authority_path, unmet_obligation, remedy)`。

## 2. 关键算法 伪代码

### IP-121 NPC（Normative Projection & Compliance）

```python
def normative_projection(a, c, policy):
    d, obls, conf = policy.query(a, c)          # d in {permit, conditional, forbid}
    if d == 'forbid':
        return NormDecision('forbid', obls, conf, absorbing=True)
    met = all(obligation_satisfied(o, c) for o in obls)
    return NormDecision(d, obls, conf, obligations_met=met)

def deployable_space(A, alpha, c, policy, theta_cov=0.8):
    out = []
    for a in A:
        if alpha.get(a, 0.0) < theta_cov:       # 能力门（第 54 轮）
            continue
        nd = normative_projection(a, c, policy)
        if nd.decision != 'forbid' and nd.obligations_met:  # 规范门
            out.append((a, nd))
    return out
```

### IP-122 TCA（Tool Call Atomization）

```python
def atomize_tool_call(tool, args, state, subject):
    E   = tool.effect_signature(args, state)    # 状态差分集合
    rev = classify_reversibility(tool, E)       # 'R' | 'C' | 'I'
    b   = blast_radius(E, subject)              # 受影响实体 × 严重度
    pre = preconditions(tool, args, state)
    return ToolAtom(tool.id, args, pre, E, rev, b, subject)

def is_safe_to_auto(atom):
    return atom.rev == 'R' or (atom.rev == 'C' and has_bounded_compensation(atom))
```

### IP-123 CCC（Capability-Compliance Conjunction Certificate）

```python
def dual_key_certificate(atom, J_cap, auth, purpose, policy, ledger):
    nd = normative_projection(atom, purpose.context, policy)
    if nd.decision == 'forbid' or not nd.obligations_met:
        return ('reject', 'compliance', nd)                     # 规范钥匙失败
    if not (J_cap.dom == 'in' and J_cap.rho >= purpose.rho_min):
        return ('reject', 'capability', J_cap)                  # 能力钥匙失败
    if not authority_covers(auth, atom) or not purpose_bound(auth, purpose):
        return ('reject', 'authority')
    if atom.rev == 'I' and atom.b > purpose.blast_budget:
        return ('reject', 'irreversible_blast', atom.b)
    C = ToolCert(J_cap, auth, purpose, atom.E, atom.rev,
                 nd.obligations, ledger.root, policy.version, purpose.ttl)
    return ('ok', C)
```

### IP-124 ADL（Authority Delegation Lattice）

```python
def check_delegation_chain(chain):
    for parent, child in zip(chain, chain[1:]):
        if not lattice_leq(child, parent):        # child ⊑ parent
            return ('violation', 'amplification', parent, child)
    return ('ok', meet_all(chain))

def detect_confused_deputy(caller_auth, tool_auth):
    return not lattice_leq(tool_auth, caller_auth)   # 工具权限不得高于调用者
```

### IP-125 GAL（Graduated Autonomy Layer）

```python
def autonomy_gate(atom, rho, nd, policy):
    r    = risk_tier(atom, policy)                 # R0..R3
    l_cap  = level_from_rho(rho, r)
    l_comp = level_from_norm(nd, r)
    l_risk = policy.min_autonomy[r]                # R3 -> 'human-only'
    ell  = meet_levels(l_cap, l_comp, l_risk)      # 取最严格
    if ell == 'human-only' and not human_approval(atom):
        return ('blocked', 'human_required', r)
    if ell == 'confirm' and not user_confirm(atom):
        return ('blocked', 'confirm_required', r)
    return ('ok', ell, r)
```

### IP-126 CDL（Compliance Drift Ledger）

```python
def audit_append(ledger, cert, atom, outcome):
    h = H(ledger.root, hash(cert), atom.id, atom.E, outcome, now())
    ledger.append((h, cert.pol_ver, atom.E, outcome))
    return h

def drift_check(cert, now_ctx, policy):
    delta  = policy_drift(cert.pol_ver, now_ctx.pol_ver)
    delta += consent_drift(cert, now_ctx)
    delta += jurisdiction_drift(cert, now_ctx)
    if delta > THETA_C:
        return ('revalidate', delta)
    return ('ok', delta)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| NPC | O(|A|·|O|·|policy|) | O(|A|+|O|) | ν 单调、forbid 吸收、义务可判定 |
| TCA | O(|E|+|subj|) | O(|E|) | 效果签名完备、可逆分类 sound |
| CCC | O(|O|+|Auth|) | O(1) | 双钥匙独立、目的绑定、不可逆门控 |
| ADL | O(k·|𝔄|) | O(k) | 格序正确、衰减传递、无放大 |
| GAL | O(1) | O(1) | 等级序单调、R3 强制 human-only |
| CDL | O(1) 追加 / O(log n) 证明 | O(n) | 哈希链防篡改、漂移阈值闭合 |

**正确性定理（Capability-Compliance Separation Soundness）**
假设第 54 轮 (A26)–(A28) 成立，且 **(A29)** ν 对上下文严格化单调、`forbid` 吸收；**(A30)** 委托链严格衰减、无放大；**(A31)** 审计账本哈希链防篡改、政策版本只增不改；**(A32)** 漂移检测的陈旧度 ≤ τ_c。则对任一通过 `Valid(C_tool,c)` 与 `GAL(t)` 的工具调用：

```
P(未授权不可逆副作用) ≤ ε_ν + ε_del + P(δ_c > Θ_c) + ε_audit + ε_obl
```

**分离推论**：`J_cap 有效 ⇏ deploy(t)`，`C_comp 有效 ∧ J_cap 无效 ⇏ deploy(t)`。即能力与合规**互为必要条件、互不充分**，且不可逆动作的失败代价不由鲁棒性谱兜底。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 规范规格缺口（spec gap） | 高 | 未知默认 forbid/conditional + 红队规范场景 + 伦理委员会复核 |
| 工具效果签名不完备（隐藏副作用） | 高 | 能力沙箱 + 污点追踪 + 出网管控 + dry-run 预演 |
| 授权链/政策版本伪造或回滚 | 高 | 签名政策 + 只增账本 + 透明日志（transparency log） |
| 合规漂移导致执行时违规 | 高 | 短 TTL + 即时重校验 + 撤销传播 |
| 过度阻断与自动化偏见 | 中 | 分级自主 + 申诉通道 + 过阻断率监控 |
| 用证书替代真实伦理判断 | 高 | 高风险强制人类问责锚点 + 残余风险显式披露 |

## 6. 本轮最大风险

**一句话**：双钥匙与规范投影把“能力”与“合规”在形式上彻底分离，但其 soundness 依赖**规范规格的完备性、工具效果签名的无遗漏、以及政策版本与授权链的不可伪造**；一旦规范欠定义而效果签名又漏掉隐藏副作用，系统就会产出“证书齐全却伦理失效”的**合规剧场**，让不可逆、大 blast 的工具调用在被证明合规的同时造成真实伤害，故必须坚持“未知即 forbid 或 human-only”的保守默认、把人类问责锚点置于证书之上，绝不允许能力证书替代规范判断。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（NPC×TCA×CCC×ADL×GAL×CDL）

> 承接第 54 轮产物 v31。本轮在“动作空间 + 鲁棒性 + 云边协同”之上，增加 **伦理合规 × 工具调用** 层，回答“该不该做、凭什么做、做完能否问责”：

| `δ_c` | 合规漂移（政策/同意/管辖） |
| `L=[(i,h_i,hash(C_i),effect_i,outcome_i,h_{i-1})]` | 哈希链审计账本 |

### IP-121 NPC

```python
def normative_projection(a, c, policy):
    d, obls, conf = policy.query(a, c)
    if d == 'forbid':
        return NormDecision('forbid', obls, conf, absorbing=True)
    return NormDecision(d, obls, conf,
                        obligations_met=all(obligation_satisfied(o, c) for o in obls))

def deployable_space(A, alpha, c, policy, theta_cov=0.8):
    return [(a, nd) for a in A
            if alpha.get(a, 0.0) >= theta_cov
            and (nd := normative_projection(a, c, policy)).decision != 'forbid'
            and nd.obligations_met]
```

### IP-123 CCC

```python
def dual_key_certificate(atom, J_cap, auth, purpose, policy, ledger):
    nd = normative_projection(atom, purpose.context, policy)
    if nd.decision == 'forbid' or not nd.obligations_met:
        return ('reject', 'compliance', nd)
    if not (J_cap.dom == 'in' and J_cap.rho >= purpose.rho_min):
        return ('reject', 'capability', J_cap)
    if not authority_covers(auth, atom) or not purpose_bound(auth, purpose):
        return ('reject', 'authority')
    if atom.rev == 'I' and atom.b > purpose.blast_budget:
        return ('reject', 'irreversible_blast', atom.b)
    return ('ok', ToolCert(J_cap, auth, purpose, atom.E, atom.rev,
                           nd.obligations, ledger.root, policy.version, purpose.ttl))
```

### IP-124 ADL

```python
def check_delegation_chain(chain):
    for parent, child in zip(chain, chain[1:]):
        if not lattice_leq(child, parent):
            return ('violation', 'amplification', parent, child)
    return ('ok', meet_all(chain))

def detect_confused_deputy(caller_auth, tool_auth):
    return not lattice_leq(tool_auth, caller_auth)
```

### IP-125 GAL

```python
def autonomy_gate(atom, rho, nd, policy):
    r      = risk_tier(atom, policy)             # R0..R3
    ell    = meet_levels(level_from_rho(rho, r),
                         level_from_norm(nd, r),
                         policy.min_autonomy[r])
    if ell == 'human-only' and not human_approval(atom):
        return ('blocked', 'human_required', r)
    if ell == 'confirm' and not user_confirm(atom):
        return ('blocked', 'confirm_required', r)
    return ('ok', ell, r)
```

### IP-126 CDL

```python
def audit_append(ledger, cert, atom, outcome):
    h = H(ledger.root, hash(cert), atom.id, atom.E, outcome, now())
    ledger.append((h, cert.pol_ver, atom.E, outcome))
    return h

def drift_check(cert, now_ctx, policy):
    delta  = policy_drift(cert.pol_ver, now_ctx.pol_ver)
    delta += consent_drift(cert, now_ctx)
    delta += jurisdiction_drift(cert, now_ctx)
    return ('revalidate', delta) if delta > THETA_C else ('ok', delta)
```

### 部署判定总流程

```python
def deploy_tool_call(tool, args, state, J_cap, auth, purpose, policy, ledger):
    atom = atomize_tool_call(tool, args, state, purpose.subject)   # TCA
    if check_delegation_chain(auth.chain) != ('ok', ...):          # ADL
        return ('reject', 'delegation')
    ok, C = dual_key_certificate(atom, J_cap, auth, purpose, policy, ledger)  # CCC
    if ok != 'ok':
        return (ok, C)
    gate = autonomy_gate(atom, J_cap.rho, C.obligations, policy)   # GAL
    if gate[0] != 'ok':
        return gate
    if drift_check(C, purpose.context, policy)[0] != 'ok':         # CDL
        return ('reject', 'drift')
    root = audit_append(ledger, C, atom, outcome='pre_exec')       # 事前落账
    return ('ok', C, root)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| NPC | O(|A|·|O|·|policy|) | O(|A|+|O|) | ν 单调、forbid 吸收、义务可判定 |
| TCA | O(|E|+|subj|) | O(|E|) | 效果签名完备、可逆分类 sound |
| CCC | O(|O|+|Auth|) | O(1) | 双钥匙独立、目的绑定、不可逆门控 |
| ADL | O(k·|𝔄|) | O(k) | 格序正确、衰减传递、无放大 |
| GAL | O(1) | O(1) | 等级序单调、R3 强制 human-only |
| CDL | O(1) 追加 / O(log n) 证明 | O(n) | 哈希链防篡改、漂移阈值闭合 |

**正确性定理（Capability-Compliance Separation Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** ν 对上下文严格化单调且 `forbid` 吸收；**(A30)** 委托链严格衰减、无放大；**(A31)** 审计账本哈希链防篡改、政策版本只增不改；**(A32)** 漂移检测陈旧度 ≤ τ_c。则通过 `Valid(C_tool,c)` 与 `GAL(t)` 的工具调用满足：
```
P(未授权不可逆副作用) ≤ ε_ν + ε_del + P(δ_c > Θ_c) + ε_audit + ε_obl
```
**分离推论**：能力有效不蕴含合规，合规有效不蕴含能力；不可逆动作的代价不由鲁棒性谱 ρ 兜底。故 `A_dep = A_cap ∩ A_perm` 必须是**交集**，而非任一单侧近似。

## 6. 本轮最大风险

**一句话**：双钥匙与规范投影把“能力”与“合规”在形式上彻底分离，但其 soundness 依赖**规范规格的完备性、工具效果签名的无遗漏、以及政策版本与授权链的不可伪造**；一旦规范欠定义而效果签名又漏掉隐藏副作用，系统就会产出“证书齐全却伦理失效”的**合规剧场**，让不可逆、大 blast 的工具调用在被证明合规的同时造成真实伤害，故必须坚持“未知即 forbid 或 human-only”的保守默认、把人类问责锚点置于证书之上，绝不允许能力证书替代规范判断。
