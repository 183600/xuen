# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「平衡控制」×「行为树」）

> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> **本轮纪律**：**连续可行性 + 离散仲裁**。两个灵感分别治理 v9 的两种未被显式命名的债：
> **动力学债**——AC 的中止点只保证"几何上停得住"（`d_brake+d_safe ≤ 间隙余量`），却可能急停导致 ZMP 出支撑多边形、DCM 逃出可捕获集，即"安全地摔倒"；
> **仲裁债**——MW 把退化链压成扁平 EDF 表，回退顺序是隐式排序约定，缺乏可组合、可模型检验的反应式结构。
> 必须通过**可行性证书 + 退化行为树**保证新增结构失效时严格退回 v9/v8 语义，而非行为漂移。

## 0. 直觉与动机

**灵感 1（平衡控制 → 把"不撞"升级为"不摔"）**
直觉：v9 的 `AC` 是几何安全，但真实机器人（尤其搬重物的移动操作手）在急停、侧向被推、地毯/斜坡上摩擦失准时，最先失效的往往不是避障而是平衡。平衡控制的核心量——**线性倒立摆的捕获点/DCM** `ξ=x+ẋ/ω`、**可行性核**（N 步可捕获集）、**接触扳手锥/CWC**、**恢复原语**（踝/髋/迈步/支撑）——正好补上这块连续安全语义。
核心创新：**平衡可行性证书器（BalanceViabilityCertifier, BVC）**。把块证书从"指标最坏界"升级为"指标最坏界 + 可行性证书"；中止点必须**同时**满足几何停车不变式与动力学可行性 `V(s_p)`。这直接封堵 v9 引理 82 的隐含前提"中止一定可执行"。

**灵感 2（行为树 → 退化链从"表"变成"反应式程序"）**
直觉：v9 的五级退化链在 MW 里是排序 + if-else 的数据实例，能等价，但不能**组合**、不能**局部替换**、不能对"失败后回退到哪/重试几次/何时放弃"做形式化验证。行为树的 Sequence/Fallback/Parallel/记忆节点/守卫装饰器，是工业界已验证的反应式仲裁原语，且其 tick 语义可映射到迁移系统做模型检验。
核心创新：**认证行为树（CertifiedBehaviorTree, CBT）**：每个动作叶携带契约 `κ_ℓ` 与守卫 `g_ℓ`，控制流只允许四类节点；v9 五级退化链成为一棵 `Fallback` 树的数据实例；新增末叶 `safe_halt`。退化从"按时间片排序"升级为"按语义回退"，并能像软件一样做回归验证（子树叶替换不影响其余子树）。

**灵感 3（合流 → 可行性引导行为树）**
直觉：连续控制需要离散结构来组合，离散仲裁需要连续不变式来兜底。若 BT 选兄弟节点只看固定优先级，就会出现"优先级高的动作任务分高但在把机器人推向可行性边界"。
核心创新：**可行性引导仲裁（ViabilityGuidedArbiter, VGA）**：兄弟选择按 `(可行性, 平衡裕度, 任务得分)` 字典序；裕度改善小于 `δ_hys` 时保持上次选择（迟滞，防抖）；块长 `K_eff` 同样受 `m_bal` 门控；树底 `safe_halt` 叶在可行核内**由构造保证**可执行。这是一次真正的跨学科桥接：BT 管"离散地做什么"，平衡控制管"连续地还能不能安全做"。

## 1. 研究问题（轮次升级版）

- **Q1（动力学可行性证书）**：在 LIPM/CWC 模型误差与接触不确定性（摩擦系数、质心偏移、负载）下，如何构造**保守有效**的可行性证书 `V̂`，使 `V̂(s) ⇒ V(s)`，并让块中止点同时满足几何停车与动力学可行？模型误差上界 `β_bal` 如何在线标定与漂移监控？
- **Q2（退化行为树的等价与可验证性）**：如何把 v9 五级退化链与 v8 四级链编码为一棵 `Fallback` 行为树，使 tick 语义在可观测日志层面与 v9 逐位等价，且可通过模型检验证明"无死锁、`safe_halt` 可达、无叶饥饿、反应时间有界"？
- **Q3（可行性引导仲裁）**：字典序 + 迟滞的仲裁能否证明不抖振（无 Zeno）、救援级联有界且无活锁，同时相对固定优先级不损失任务性能（有界遗憾）？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 动力学可行性律（Dynamic Viability, BVC）**
每个将执行动作与每个中止点 `p` 必须满足：`V̂(s_p) ∧ m_bal(s_p) ≥ ε_bal + β_bal`。任一候选块在块内任一步不满足即**拒绝该候选**；若全部候选皆因平衡被拒，则 `K_eff ← 1`（逐步执行）并在可行核内触发恢复原语，而非放行一个几何可行但动力学不可行的块。

**P14 认证行为树律（Certified Behavior Tree, CBT）**
控制流只允许 `Sequence / Fallback / Parallel / Guarded-Decorator / Retry`；每个动作叶声明契约 `κ_ℓ=(In,Out,D_ℓ,Ŵ_ℓ,v_ℓ^⊥,π_ℓ,φ_ℓ^elig)` 与守卫 `g_ℓ(s)`；退化链是 `Fallback` 的数据实例，且保留 `safe_halt` 终叶。树必须通过模型检验：无死锁、`safe_halt` 从根可达、无叶饥饿、单 tick 反应时间有界。

**P15 可行性引导仲裁律（Viability-Guided Arbitration, VGA）**
兄弟节点按 `(V(s'), m_bal(s'), score(s'))` 字典序选择；若最优兄弟相对上次选择的裕度改善 `< δ_hys` 则保持上次选择（迟滞）；任何时刻允许在 `m_bal < ε_bal` 前回退到 `safe_halt` 叶。仲裁只在块边界或 viable 状态发生迁移，不改变 v9 的 50Hz 执行节拍。

## 3. 与基线的接口（如何退化）

- BVC 失效（模型误差超 `β_bal` / CWC 求解不可用）⇒ `m_bal ≡ +∞`（忽略平衡项），严格等价 v9 的几何中止（引理 88 退化分支）；
- CBT 失效（BT 运行时不可用 / 树校验失败）⇒ 切换 v9 的 MW 平坦 EDF 退化路径；
- VGA 失效（可行性投影不可用）⇒ 固定优先级字典序，等价 v9 的排序选择；
- AC 失效（前向模型超差 / 证书连续失效）⇒ `K_eff ← 1`，逐步执行，等价 v8 决策粒度；
- MW 失效 ⇒ 切换 v8 手写网关代码路径；
- ID 失效 ⇒ 全模块 active、归因冻结，等价 v8 全模块常开；
- v8 的 DA/SPR/Cal 任一失效 ⇒ 中立元注入（`Δ_dom≡0 / risk_SLAM≡0 / sensor_weight≡1`），等价 v7；
- 全失效 ⇒ 退回 MetricVoiceGauge-OTL-GC-ER v7，再退回 v6。

## 4. 预期贡献

1. **动力学可行性证书**：把块证书从"指标最坏界"扩展为"指标最坏界 + 可行核成员资格"，首次使分块执行的安全证明覆盖"停得住且不摔"；
2. **认证行为树退化链**：把 v9 扁平退化表升级为可组合、可模型检验的反应式程序，退化链的局部替换与回归验证成为常规工程；
3. **可行性引导仲裁**：连续平衡裕度进入离散仲裁，给出迟滞无抖振与救援级联有界的证明草图；
4. **连续-离散安全桥**：`m_bal` 同时门控 `K_eff`、仲裁与恢复，形成"感知—决策—平衡"三层闭环；E571–E590 覆盖推扰恢复、接触失准、级联界、BT 等价与端到端。

## 5. 本轮最大风险

**一句话**：把安全委托给"可行性证书 + 行为树回退"后，系统会把每一次失败都转化为一次恢复尝试；一旦接触/摩擦模型在地毯、斜坡、负载突变等未建模工况下失准，`V̂` 会把"即将不可行"误报为"仍可行"，回退链便陷入「每拍都返回 RUNNING、可行性却在单调收缩」的**救援级联**——即在每个 tick 上合法，却在有限时间内把机器人推出可行性核并摔倒。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-BalBT**（Balance-Viability Certified Behavior Tree）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮灵感：「平衡控制」×「行为树」
> **继承纪律**：MetricVoiceGauge 九不变式（CVC-闭环、SpatialCert、RT-CVC、FaultCert、PrimitiveGraph、严格退化链、OTL、GCT、ER）全部保留；v9 的 AC/MW/ID 三模块原样继承。新组件一律为**可选增强**：任一环节不可用 ⇒ 注入中立元/退回 v9 路径，严格等价退回 v9/v8 行为（引理 88–89），而非行为漂移。

- Level-6：全失效或可行核告急 ⇒ `safe_halt`，再退回 v6。

## 1. 符号体系增量（定义 540–550）

| 符号 | 含义 |
|---|---|
| `ω = sqrt(g/z_c)` | LIPM 倒立摆自然频率（`z_c` 质心高度） |
| `ξ(s) = x + ẋ/ω` | 发散运动分量 / 捕获点（DCM） |
| `C_N(s)` | N 步可捕获集（capturability set），由落脚规划器给出 |
| `P_supp(s)` | 支撑多边形；`ZMP(s)` 为零矩点 |
| `m_bal(s)` | 平衡裕度：`min(d(ξ,∂C_N), d(ZMP,∂P_supp))`（有符号，≥0 可行） |
| `CWC(s)` | 接触扳手锥可行集（摩擦锥 × 质心力矩） |
| `S_bal` | 可行核：`{s : m_bal(s) ≥ ε_bal ∧ CWC(s) ≠ ∅}` |
| `β_bal` | 可行性证书模型误差余量（接触/摩擦/质心偏移） |
| `V̂_t(s)` | 可行性证书：预测 `s ∈ S_bal` 的保守布尔值 |
| `Π_rec` | 恢复原语库 `{π_ankle, π_hip, π_step, π_brace, π_stop}` |
| `T = (V,E,r,type,ℓ,κ,g)` | 认证行为树：节点/边/根/节点类型/叶标签/契约/守卫 |
| `τ_T(s) → (status, s')` | BT tick，`status ∈ {SUCCESS, FAILURE, RUNNING}` |
| `δ_hys` | 仲裁迟滞阈值（裕度改善不足则保持上次选择） |
| `R_max` | 救援级联重试预算（防活锁） |

**新增定义 540（平衡裕度 BalanceMargin）** 令 `ξ(s)=x+ẋ/ω`，`ω=sqrt(g/z_c)`：
```
m_bal(s) = min( d(ξ(s), ∂C_N(s)), d(ZMP(s), ∂P_supp(s)) )
```
`m_bal ≥ 0` 表示当前状态仍有可行恢复；`< 0` 表示已越出可捕获/支撑边界。采用 `min` 是为了取两类失衡（发散分量逃逸、压力中心出界）中更紧的一侧，保证保守。

**新增定义 541（可行性核 ViabilityKernel）**
```
S_bal = { s ∈ S : m_bal(s) ≥ ε_bal  ∧  CWC(s) ≠ ∅ }
```
其中 `CWC(s) = { w=(F,τ) : A(s)w ≤ b(s,μ) }` 为线性化摩擦锥与质心力矩约束。`S_bal` 是对 v9 几何安全集 `S_geo` 的**收紧**：`S_bal ⊆ S_geo`（当 `μ→0` 或支撑退化时退化为空，触发 `safe_halt`）。

**新增定义 542（可行性证书 ViabilityCertificate）** 对冻结前向模型 `F̂` 预测的块内状态序列 `ŝ_{1:K}`，证书
```
V̂_t = ⋀_{k=1..K} [ m̂_bal(ŝ_k) ≥ ε_bal + β_bal ∧ ĈWC(ŝ_k) ≠ ∅ ]。
```
块被接受 ⇔ `Ĉ_t.valid ∧ V̂_t`。`β_bal` 由 E574 标定（模型误差上界 × 1.2），并由 E575 做在线漂移监控；漂移越限即 `V̂_t ← false`（保守降级）。

**新增定义 543（恢复原语库 RecoveryPrimitiveLibrary）** `Π_rec` 中每个原语 `π=(guard_π, dur_π, Δm_π, cost_π)`：`guard_π` 为可执行前置条件，`Δm_π` 为其在模型内的裕度增益，`cost_π` 为耗时/能量。BT 的恢复子树按 `Δm_π/cost_π` 排序，且仅当 `guard_π` 当前成立才可 tick。

**新增定义 544（认证行为树 CertifiedBehaviorTree）** `T=(V,E,r,type,ℓ,κ,g)`，`type ∈ {Seq, Fall, Par, Guard, Retry, Leaf}`；每个叶 `ℓ` 携带契约 `κ_ℓ`（沿用定义 535）与守卫 `g_ℓ:S→{0,1}`。记忆型控制节点保留上次 `RUNNING` 的子索引，避免同一 tick 反复重入失败子树。

**新增定义 545（行为树 tick 语义 BT-Tick）**
```
τ_Leaf(s)   = if ¬g_ℓ(s): (FAILURE, s)
              elif mw.deadline_ok(κ_ℓ): (run_ℓ(s).status, run_ℓ(s).s')
              else: (FAILURE, inject v_ℓ^⊥)      # 与 v9 中立元一致
τ_Fall(s)   = 依次 tick 子节点：首个 SUCCESS/RUNNING 即返回；全 FAILURE 返回 FAILURE
τ_Seq(s)    = 依次 tick 子节点：首个 FAILURE/RUNNING 即返回；全 SUCCESS 返回 SUCCESS
τ_Par(s)    = 所有子节点均 tick；失败率超阈值则 FAILURE，否则按策略聚合
τ_Guard(g)(s) = if g(s): τ_child(s) else (FAILURE, s)
τ_Retry(n)(s) = 至多重试 n 次；每次 FAILURE 计数，超预算返回 FAILURE
```

**新增定义 546（退化行为树 DegradationTree）** 即第 0 节的 `Fallback(L1..L6)`。`L1` 的守卫 `trust_ok ∧ V̂` 把 v9 的 `U_t`（信任域）与新的可行核合并；`L6` 为 `safe_halt` 叶，其 `run` 依次尝试 `π_stop→π_brace`，并要求 `m_bal ≥ ε_bal`。

**新增定义 547（可行性引导仲裁 ViabilityGuidedArbiter）**
```
choice = argmax_{c ∈ children} ( [V(s'_c)], m_bal(s'_c), score_c(s'_c) )   # 字典序
if choice ≠ last and m_bal(s'_choice) − m_bal(s'_last) < δ_hys:
    choice = last                                                          # 迟滞
```
其中 `s'_c` 为子节点证书投影的目标状态（**不执行 dry-run**，只用其块证书/守卫求值），故仲裁成本 O(|children|)。

**新增定义 548（救援级联与预算 RescueCascade）** 一次"失败→恢复"记一级；级联深度受 `R_max` 与 BT 记忆约束。定义级联指标 `ρ = 1 − m_bal/ε_bal`，当 `ρ` 单调上升且超过 `ρ_max` 时强制 `safe_halt`。

**新增定义 549（安全停驻叶 SafeHalt）** `safe_halt(s)` 仅在 `V(s) ∧ m_bal(s) ≥ ε_bal` 时返回 `SUCCESS` 并锁死其余动作；若此时已不满足，返回 `FAILURE` 并上报"**tick 前不变式已破坏**"（见引理 90 的边界情形）。`safe_halt` 不是"恒成功"，而是"可行时必然可停、不可行时显式报警"，避免用永远 SUCCESS 的叶掩盖前置违约。

**新增定义 550（平衡门控块长 BalanceGatedChunkLength，升级定义 539）**
```
K_eff(t) = 1                                     若 U_t 不成立 ∨ m_bal(t) < ε_bal
         = max(1, ⌊K_max·(1 − max(Δ_dom/τ_dom, m_pen(t)))⌋)   否则
m_pen(t) = clip(1 − m_bal(t)/ε_max, 0, 1)
```
域越陌生、平衡裕度越低，块越短；`K_eff=1` 时 BT 落到 `L2`（逐步 + 恢复原语）。

## 2. 形式化定义（要点与升级）

**定义 532–539（v9 动作块/证书/中止点/契约/中立元/消融/状态机/块长）** 继承 v9；其中：
- **定义 533 块证书** 升级为 `Ĉ_t=(ĝ_min, ê_max, γ̂_grasp, V̂_t)`（增加可行项）；
- **定义 534 中止点** 升级为双重合取：`d_stop(p) ∧ V̂(ŝ_p)`；
- **定义 539 块长** 由定义 550 取代（几何门控扩为几何+平衡门控）；
- **定义 535 契约表** 增加行为树叶的 `g_ℓ` 与 `type` 字段，`Σ Ŵ ≤ B_dec` 与 EDF 可行性不变。

**升级定义 496（软证书，v10）** `δ_trigger` 六条件：
```
σ < τ_safe ∧ γ_grasp valid ∧ Δ_dom < τ_dom ∧ risk_SLAM < τ_SLAM
          ∧ Ĉ_t valid ∧ V̂_t valid
```
新增 `V̂_t` 与 `Ĉ_t` 同尺度触发 `M₀` 硬检查：任一可行项失效即刻进入 `safe_halt` 候选，无"块内几何通过、动力学失效"的空洞（引理 87+88 联合）。

**升级定义 531（软硬约束衔接）** `M₀` 判据增加"可行性入口"：`m_bal < ε_bal` 时直接判 `M₀` 违规并触发 `safe_halt`，不等块边界。

# IP-357 BalanceViabilityCertifier：平衡可行性证书器
class BalanceViabilityCertifier:
    def __init__(self, z_c, g=9.81, eps_bal=0.03, beta_bal=0.01,
                 N_steps=3, mu=0.6, eps_max=0.15):
        self.omega = math.sqrt(g / z_c)
        self.eps_bal, self.beta_bal = eps_bal, beta_bal
        self.N_steps, self.mu, self.eps_max = N_steps, mu, eps_max

    def dcm(self, s):                       # 定义 540
        return s.com + s.com_vel / self.omega

    def margin(self, s):
        xi = self.dcm(s)
        m_dcm = signed_dist(xi, self.capture_set(s).boundary)   # C_N(s)
        m_zmp = signed_dist(zmp(s), s.support_polygon.boundary)
        return min(m_dcm, m_zmp)

    def cwc_nonempty(self, s):
        return solve_feasible(A(s), b(s, self.mu))              # 定义 541

    def viable(self, s):
        return self.margin(s) >= self.eps_bal and self.cwc_nonempty(s)

    def certify(self, pred):                # 定义 542
        for k in range(1, pred.K + 1):
            s_k = pred.state[k]
            if not self.cwc_nonempty(s_k):
                return False
            if self.margin(s_k) < self.eps_bal + self.beta_bal:
                return False
        return True

    def m_pen(self, s):                     # 定义 550
        return min(1.0, max(0.0, 1.0 - self.margin(s) / self.eps_max))


# IP-354（升级）：AC 的中止点与块长加入可行性
class ActionChunkCertifier:
    def _abort_points(self, state, actions, pred):
        pts = []
        for p in range(1, len(actions)):
            geo = (pred.clearance[p] - self.d_brake(pred.speed[p])
                   - self.d_safe >= pred.path_len[p:])           # v9 几何
            dyn = self.bvc.viable(pred.state[p])                 # v10 动力学
            if geo and dyn:
                pts.append(p)
        return pts

    def effective_K(self, state, delta_dom, tau_dom, trust_ok):
        if not trust_ok or self.bvc.margin(state) < self.bvc.eps_bal:
            return 1
        pen = max(min(1.0, delta_dom / tau_dom), self.bvc.m_pen(state))
        return max(1, int(self.K_max * (1 - pen)))

    def generate_chunk(self, state, delta_dom, tau_dom, trust_ok):
        K = self.effective_K(state, delta_dom, tau_dom, trust_ok)
        if K == 1:
            return self._single_step_fallback(state)
        best = None
        for cand in self.policy.sample_sequences(state, K, n=64):
            pred = self.F.rollout(state, cand)
            if not self.bvc.certify(pred):                      # 定义 542
                continue
            g_min = pred.min_clearance - self.beta
            e_max = pred.max_effort + self.beta
            if g_min < self.d_safe or e_max > state.tau_eff:
                continue
            pts = self._abort_points(state, cand, pred)
            if not pts:
                continue
            score = self.policy.score(cand, pred)
            if best is None or score > best.score:
                best = Chunk(cand, Cert(g_min, e_max, True), pts, score)
        return best or self._single_step_fallback(state)


# IP-358 BehaviorTreeArbiter：认证行为树运行时
class Status(Enum):
    SUCCESS, FAILURE, RUNNING = 0, 1, 2

@dataclass
class Leaf:
    name: str
    run: object                              # s -> (Status, s')
    contract: object                         # 定义 535 的 κ
    guard: object = lambda s: True

    def tick(self, s, mw):
        if not self.guard(s):
            return Status.FAILURE, s
        if not mw.deadline_ok(self.contract):
            return Status.FAILURE, mw.inject_neutral(self.contract, s)
        return self.run(s)

@dataclass
class Fallback:
    children: list
    memory: bool = True
    _i: int = 0

    def tick(self, s, mw):
        start = self._i if self.memory else 0
        for i in range(start, len(self.children)):
            st, s2 = self.children[i].tick(s, mw)
            if st in (Status.RUNNING, Status.SUCCESS):
                self._i = i if st is Status.RUNNING else 0
                return st, s2
        self._i = 0
        return Status.FAILURE, s

@dataclass
class Guard:
    cond: object
    child: object
    def tick(self, s, mw):
        return self.child.tick(s, mw) if self.cond(s) else (Status.FAILURE, s)

@dataclass
class Retry:
    child: object
    n: int = 3
    def tick(self, s, mw):
        for _ in range(self.n):
            st, s2 = self.child.tick(s, mw)
            if st is not Status.FAILURE:
                return st, s2
            s = s2
        return Status.FAILURE, s

# IP-359 ViabilityGuidedArbiter：可行性引导仲裁
class ViabilityGuidedArbiter:
    def __init__(self, bvc, delta_hys=0.005):
        self.bvc, self.delta_hys = bvc, delta_hys
        self.last, self.last_margin = None, -float('inf')

    def choose(self, children, s):
        best = None
        for c in children:                   # 只做证书投影，不执行 dry-run
            st, s2 = c.project(s)
            if st is Status.FAILURE or not self.bvc.viable(s2):
                continue
            key = (self.bvc.margin(s2), c.score(s2))
            if best is None or key > best[0]:
                best = (key, c, s2)
        if best is None:
            return None                      # 交给 Fallback 的 L6 safe_halt
        if (self.last is not None
                and best[0][0] - self.last_margin < self.delta_hys):
            return self.last, None           # 迟滞：保持上次选择
        self.last, self.last_margin = best[1], best[0][0]
        return best[1], best[2]

## 4. 推导

**引理 87（可行性证书可靠性）** 设可行核模型误差 `‖m̂_bal − m_bal‖∞ ≤ β_bal` 且 `ĈWC` 对 `CWC` 保守（线性化不放大可行域）。若 `V̂_t(s)=true`，则 `s ∈ S_bal`。证明：对每个 `k`，`m_bal(ŝ_k) ≥ m̂_bal(ŝ_k) − β_bal ≥ ε_bal + β_bal − β_bal = ε_bal`；且 `ĈWC(ŝ_k)≠∅ ⇒ CWC(ŝ_k)≠∅`（保守性），故 `m_bal ≥ ε_bal ∧ CWC≠∅`，即 `s ∈ S_bal`。∎

**引理 88（平衡可行中止，升级引理 82）** 若块 `ζ` 的中止点 `p ∈ P_t` 同时满足几何停车不变式 `d_stop(p)` 与 `V̂(ŝ_p)`，则在信任域 `U_t` 内从 `p` 执行安全停驻，轨迹全程 `s ∈ S_bal` 且终点间隙 `≥ d_safe`。证明：几何部分由引理 82(ii) 给出；动力学部分由引理 87 得 `s_p ∈ S_bal`，恢复原语库的闭包性（`π_stop` 的 `guard` 要求在 `S_bal` 内且 `Δm_π ≥ 0`）保证停驻过程不越出 `S_bal`；两者合取得证。∎ 退化：若 `bvc` 不可用，则 `V̂≡true`，`P_t` 回到 v9 的几何判据，引理退化为引理 82。

**引理 89（认证行为树退化等价）** 对 v9 的每个退化级，存在 `Fallback` 树 `D` 的唯一守卫前缀，使得在对应失效注入下 `τ_D` 的叶选择序列与 v9 MW 的调用序列一致，且每叶返回值经 `v_ℓ^⊥` 注入后与 v9 逐位相同。证明：由定义 546 的分层守卫 `trust∧V̂ → trust → mw.healthy → True…`，失效集合单调包含关系保证恰好命中与 v9 相同的级；叶的 `deadline_ok` 与中立元注入直接复用定义 535/536 的契约与 `v^⊥`，故取值集合与顺序一致；BT 仅改变控制流表达，不改变叶的输入输出语义。∎

**引理 90（行为树安全不变式 / 无死锁）** 设根 tick 前 `s ∈ S_bal`。若 `τ_T(s)` 返回 `SUCCESS` 或 `RUNNING`，则返回状态 `s' ∈ S_bal`；若全部叶 `FAILURE`，则 `L6 safe_halt` 被 tick，且在 `s ∈ S_bal` 时返回 `SUCCESS`。故系统不存在"返回 RUNNING 却已越出可行核"的静默违约。证明：对树高归纳。叶层：`L1/L2` 的守卫含 `V̂`，`L3/L4/L5` 经引理 89 回到 v9/v8 已知安全路径；`L6` 在 `s∈S_bal` 时由恢复原语闭包性可停（引理 88）。控制层：`Fallback` 只在子叶返回非 FAILURE 时返回，`Guard` 不修改状态，`Retry` 不改变"失败则继续"语义，故 RETURN/RUNNING 的 `s'` 必来自满足守卫的叶。死锁：`Fallback` 覆盖 `True` 守卫链，`L6` 恒可选；若 `L6` 也 FAILURE，则 `s∉S_bal`，与前提矛盾，系统显式报警（定义 549）。∎

**引理 91（救援级联有界 / 无活锁）** 设 BT 记忆节点保留 `RUNNING` 子索引、`Retry` 预算 `R_max` 有限、且级联指标 `ρ` 超过 `ρ_max` 时强制 `L6`。则任一失败事件的救援级联深度 `≤ R_max·|V|`，且不会无限重入同一失败子树。证明：记忆节点使同一 tick 不会重复进入已 FAILURE 的兄弟；每次 FAILURE 至多消耗 `Retry` 预算 1；状态空间 `|V|` 有限，预算耗尽或 `ρ` 越限即转 `L6`；故级联长度有界，无活锁。∎

**引理 92（仲裁迟滞无抖振 + 有界遗憾）** `δ_hys>0` 且 `m_bal` 关于状态 Lipschitz（常数 `L`）、每 tick 状态变化 `≤ v_max·Δt`，则相邻两次切换间隔 `≥ δ_hys/(L·v_max·Δt)`，有限时间切换次数有限（无 Zeno）。字典序选择在可行兄弟中取 `m_bal` 最大者，故对"最大化最小裕度"的目标无遗憾；任务得分为次级键，仅在裕度相等时生效。∎

**引理 93（tick 预算与 50Hz 守恒）** BVC 的 `margin` 为 O(1) 几何查询（捕获集与支撑多边形预计算，≤0.15ms），CWC 可行性为小规模 LP（≤0.25ms）；BT tick 为 O(|V|) 指针遍历 + 契约调用，`|V|≈20` ⇒ ≤0.1ms。故平衡+BT 每周期新增 ≤0.5ms，配合 v9 分块摊销（典型 ≤8ms、p99 ≤20ms）仍满足 50Hz。∎

**一句话**：把安全委托给"可行性证书 + 行为树回退"后，系统会把每一次失败都转化为一次恢复尝试；一旦接触/摩擦模型在地毯、斜坡、负载突变等未建模工况下失准，`V̂` 会把"即将不可行"误报为"仍可行"，回退链便陷入「每拍都返回 RUNNING、可行性却在单调收缩」的**救援级联**——即在每个 tick 上合法，却在有限时间内把机器人推出可行性核并摔倒。
