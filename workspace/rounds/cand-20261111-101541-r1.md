# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「柔顺控制」×「无刷电机」）

> 第 54 轮把技能组合推进到动作空间剖面 `α_S`、云边映射 `γ_ce` 与动作-鲁棒性联合证书 `J`。但那一层的“动作空间”仍是运动学抽象：它默认“能发出这个动作”≈“能柔顺、稳定、持续地完成这个动作”。本轮用两个物理锚点校正这个默认：**柔顺控制**要求系统可控的是阻抗（刚度-阻尼-惯量）而不只是位置/速度；**无刷电机**决定阻抗到底能被合成到什么程度。核心矛盾由此变为——H22：柔顺性是**执行器能力**而非纯控制律属性，阻抗指令一旦超出电机的力矩-转速-热-带宽包络，就会被饱和、纹波、热降额与观测噪声悄悄改写；H23：接触稳定性的时间尺度（电流环 ~kHz、阻抗环 ~kHz、云端规划 ~10Hz）天然分离，第 54 轮“云端发计划、边端做校验”的契约缺少显式的**时间尺度接口**，证书会在接触瞬间失效；H24：技能切换等价于阻抗突变，会向接触系统注入能量，必须用**无源能量预算**约束组合。

## 0. 直觉与动机

**灵感 1（柔顺不是“软”，而是“用有限力矩精确地假装一个弹簧-阻尼系统”）**
直觉：阻抗控制的目标律 `τ = Jᵀ(K e + D ė)` 看起来只是把位置误差乘一个增益，但电机真正能提供的是有限、带纹波、受热约束的力矩。于是“柔顺”有两个物理边界：**下界**由力分辨率、摩擦、齿槽纹波决定（再软就分辨不出接触），**上界**由力矩裕度与闭环带宽决定（再硬就饱和或振荡）。第 54 轮的 `α_S` 只回答了“动作可达”，没有回答“这个动作的阻抗是否可被真实渲染”。导纳控制是其对偶：对高刚度传动，位置型机器人用“测力→改位置”，但受限于力传感噪声与位置环带宽，同样存在可行域，只是坐标从 `(K,D)` 换成 `(M_f,D_f)`。

**灵感 2（无刷电机为柔顺划出一个随运行点变化的可行阻抗域）**
直觉：FOC 的电流环带宽、母线电压、反电动势、峰值/连续电流、绕组热时间常数、齿槽转矩与死区纹波，共同定义了 `Z_feas(ω,T_w)`：在转速 `ω` 与绕组温度 `T_w` 下，哪些 `(K,D)` 能被稳定、无饱和地渲染。这个域不是常数，而是一张**随转速收缩、随温度降额**的曲面——高速时反电动势吃掉电压裕度，高温时连续力矩降额，低速时无感观测变差。技能的动作剖面应从 `α_S(a)` 升级为 `ζ_S(K,D,ω)`，覆盖检查必须先问“阻抗在不在域内”。

**灵感 3（无源能量罐：技能组合的“能量守恒预算”）**
直觉：两个各自稳定的柔顺技能，切换时若刚度从软跳到硬，会像突然压缩的弹簧一样向系统注入能量，接触可能发散。无源性理论给出的解是能量罐：每个技能维护一个非负能量预算，切换/增刚必须从罐中“支付”能量，耗散/减速才能“充值”。于是技能图的一条边不只需要动作/阻抗兼容，还需要 `E_comp ≥ E_min`。

**灵感 4（多时间尺度契约：云端只配“编排”，边端才配“接触”）**
直觉：不能要求云端以 10Hz 的更新去保证 1kHz 的接触稳定。正确做法是显式的 assume-guarantee：云端承诺任务级可行性与参数调度，边端承诺在本地执行时维持包络、无源性与热预算；一旦边端 `revoke`，云端只做重规划，不越权保证接触稳定性。第 54 轮的 `γ_ce` 缺的正是这层“频率契约”。

**灵感 5（柔顺作为热安全阀：越热越软，而不是越热越停）**
直觉：传统保护是过热→降额→停机；但对接触任务，停机常常等于任务失败甚至工件损坏。更好的策略是**用柔顺换生存**：当热/电压/电流裕度下降时，平滑地降低刚度、增加阻尼，既减少铜损，又保持接触闭合。柔顺在这里不只是性能选项，而是一个**可证明的安全降级自由度**：任务可能变慢变糙，但硬件与接触不会崩溃。

**灵感 6（电机即力传感器：电流、反电动势与齿槽纹波都是信息）**
直觉：`τ ≈ k_t I_q` 让无刷电机天然是一个力矩传感器；齿槽/纹波虽在低速力控中是扰动，但它是**电角度周期性的确定性信号**，可标定、可前馈抵消，剩余纹波还能给出力误差上界。更妙的是，接触本身提供了约束信息：在零速附近反电动势不可观测时，接触力把某些位置模态“点亮”了，形成 contact-aware observability。这把“低速无感不可观测”从死区变成了一个受约束但可判定的区间。

**灵感 7（双空间技能图：动作兼容 × 阻抗兼容）**
直觉：第 54 轮的 `G_S` 边只检查动作重叠；现在一条边应同时通过 `compat_A` 与 `compat_Z`，并携带共享能量罐与时间尺度契约。技能组合从此是**运动学 × 阻抗 × 能量 × 时间**的四重可判定问题，而不是单空间匹配。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（阻抗动作空间与执行器可行阻抗包络）**
设关节电机参数 `(k_t,k_e,R,L,I_max,V_bus)`，连续/峰值力矩 `T_cont(T_w),T_peak`，电流环带宽 `f_c`，编码器分辨率 `δ_q`。柔顺动作 `z=(K,D)∈A_Z`。在运行点 `(ω,T_w)` 定义
```
T_max(ω,T_w) = min( T_cont(T_w), k_t I_max, k_t·max(0, V_bus - k_e|ω|)/R )
Z_feas(ω,T_w) = { z=(K,D) : ∃ τ(·), |τ(t)|≤T_max(ω,T_w),
                  BW_z ≥ f_min, Δf(z) ≤ Δf_max, E_z ≤ E_max, passive }
```
其中 `BW_z` 为阻抗闭环带宽，`Δf` 为力分辨率，`E_z` 为单步渲染能量。技能 `S` 的**阻抗剖面** `ζ_S:A_Z×Ω→[0,1]`，`ζ_S(z,ω)=1` 当且仅当 `z` 在 `(ω,T_w)` 下可渲染且误差 `≤ε_z`。**阻抗覆盖** `cover_Z(S,Z_T)=1` 当且仅当 `∀(z,ω)∈Z_T, ζ_S(z,ω)≥θ_z`。

**定义 122（双空间兼容性与柔顺技能图）**
```
compat_A(S_i,S_j) = |A_i∩A_j|/|A_i∪A_j|
compat_Z(S_i,S_j) = |Z_i∩Z_j|/|Z_i∪Z_j|
```
`G_S^Z=(V,E_Z)`，边 `(i,j)` 当且仅当
```
compat_A ≥ θ_a ∧ compat_Z ≥ θ_z ∧ c_trans ≤ τ_e ∧ E_{S_i⊗S_j} ≥ E_min
```
边证书 `C_comp^Z = (A_overlap, Z_overlap, E_shared, f_contract, ρ_comp)`。注意 `compat_Z` 用**体积/测度**而非简单数值区间交集，避免高刚度端点被低刚度大区间“稀释”。

**定义 123（无源能量罐与预算组合）**
技能 `S` 的能量罐 `E_S(t)≥0`，按 passivity-based control 更新
```
Ė_S = α·max(P_in,0) + β·P_diss - γ·|P_out|,   P_in = fᵀẋ
```
切换/组合能量代价
```
E_sw(z_i,z_j) = ½ (z_j-z_i)ᵀ H (z_j-z_i),   H ≻ 0
E_{S_i⊗S_j} = E_{S_i} + E_{S_j} - E_sw
```
组合可执行当且仅当 `E_{S_i⊗S_j} ≥ E_min`，且存在 guard：当 `E(t)<E_low` 时冻结增刚/增大阻尼。`H` 可取关节广义惯量映射后的阻抗度量，使“刚度突变”按物理能量而非数值差计费。

**定义 124（多时间尺度云边契约）**
`f_e`（电流环）、`f_i`（阻抗/力环）、`f_t`（任务/云）。契约
```
C_mts = (f_e,f_i,f_t, K_des,D_des, E_budget, task_seq, admit, revoke)
```
要求 `f_e ≥ 10 f_i ≥ 100 f_t`。云端承诺：在契约参数下任务级可行；边端承诺：局部包络、无源性、热预算。边端回传 `(admit,K_actual,D_actual,h_Z,E_remaining,f_actual)`；`revoke` 只触发云端重规划，不允许云端直接覆盖边端实时环。该契约把第 54 轮的 `γ_ce` 从“动作映射”升级为“频率与权限的分层委托”。

**定义 125（执行器裕度与柔顺调速器）**
归一化裕度
```
m_th=(T_w,max-T_w)/ΔT_w,   m_v=(V_bus-k_e|ω|-R|I|)/V_bus,
m_i=(I_max-|I|)/I_max,     m_o=1-ε_o/ε_o,max
m = min(m_th,m_v,m_i,m_o)
κ(m)=clip((m-m_0)/(1-m_0), κ_min, 1)
K_eff=κ·K_des,   D_eff=κ·D_des+(1-κ)·D_safe
```
其中 `D_safe` 选取为使软化模态满足 `D ≥ 2√(K_eff M)`（或至少不破坏无源性）。**柔顺调速不变式**：若 `m≥0`，则 `|τ|≤T_max` 且 `T_w` 不越界，且软化只降低接触力上界；若 `m<0`，则必须 `revoke` 而非继续硬撑。

**定义 126（柔顺安全联合证书）**
```
J_c = (Z_cert, E_cert, F_cert, T_cert, O_cert, evidence)
Z_cert=(Z_core,h_Z,ε_z)
E_cert=(E_tank,E_min,E_budget)
F_cert=(f_e,f_i,f_t, separation margins)
T_cert=(T_w_pred,T_w_max,t_episode)
O_cert=(ε_o,ε_r, sensor_mode)
```
部署当且仅当 `h_Z≥h_min`、`E_tank≥E_min`、时间尺度分离成立、`T_w_pred+margin≤T_w,max`、`ε_o≤ε_o,max`、`ε_r≤ε_r,max`。`evidence` 至少包含：阻抗包络标定日志、能量罐轨迹、热预测残差、纹波标定表与接触力对比。

## 2. 关键算法 伪代码

### IP-121 IEA（Impedance Envelope Algebra）

```python
def renderable(motor, K, D, w, Tw):
    Tmax = min(motor.T_cont(Tw), motor.kt*motor.Imax,
               motor.kt*max(0.0, motor.Vbus - motor.ke*abs(w))/motor.R)
    resp = closed_loop_step(motor, K, D, Tmax, motor.fc)
    return (not resp.saturated and resp.bw >= motor.f_min
            and resp.force_res <= motor.df_max and resp.passive)

def impedance_envelope(motor, omega_grid, temp_grid, z_grid):
    Z = {}
    for w in omega_grid:
        for Tw in temp_grid:
            Z[(w, Tw)] = {z for z in z_grid if renderable(motor, *z, w, Tw)}
    return Z

def headroom(Z_feas, z):
    return distance_to_boundary(Z_feas, z) / radius(Z_feas)
```

### IP-122 PBC（Passivity Budget Composition）

```python
def tank_update(skill, dt, f, xdot, alpha, beta, gamma):
    P = dot(f, xdot)
    E = skill.E + dt*(alpha*max(P, 0) + beta*min(P, 0) - gamma*abs(P))
    skill.E = clip(E, 0.0, skill.E_max)
    return skill.E

def govern_tank(E, E_low, dK):
    return 0.0 if (E < E_low and dK > 0) else dK

def compose_passive(S1, S2, z1, z2, H, E_min):
    E_sw = 0.5 * (z2 - z1) @ H @ (z2 - z1)
    E = S1.E + S2.E - E_sw
    if E < E_min:
        return Reject('energy_budget', E, E_sw)
    return Accept(E_comp=E, E_sw=E_sw)
```

### IP-123 MTC（Multi-Timescale Contract）

```python
def cloud_issue(task_seq, K_des, D_des, E_budget, f_t, f_i, f_e):
    assert f_e >= 10*f_i and f_i >= 10*f_t
    return Contract(task_seq, K_des, D_des, E_budget, f_t, f_i, f_e)

def edge_admit(contract, motor, state):
    if not timescale_ok(contract, motor):
        return Revoke('timescale')
    K, D, m, kappa = governor(contract.K_des, contract.D_des, state, motor)
    if not in_envelope(motor, K, D, state.w, state.Tw):
        return Revoke('envelope', headroom(...))
    if state.E < contract.E_min:
        return Revoke('energy')
    return Admit(K, D, headroom(...), state.E, motor.f_i)
```

### IP-124 CAG（Compliance-Aware Governor）

```python
def governor(Kd, Dd, state, motor):
    m_th = (motor.Tw_max - state.Tw) / motor.dTw
    m_v  = (motor.Vbus - motor.ke*abs(state.w) - motor.R*abs(state.I)) / motor.Vbus
    m_i  = (motor.Imax - abs(state.I)) / motor.Imax
    m_o  = 1.0 - state.eps_o / motor.eps_o_max
    m    = min(m_th, m_v, m_i, m_o)
    kappa = clip((m - motor.m0) / (1 - motor.m0), motor.kappa_min, 1.0)
    K = kappa * Kd
    D = kappa * Dd + (1 - kappa) * motor.D_safe
    return K, D, m, kappa
```

### IP-125 RRC（Ripple & Observability Certificate）

```python
def torque_estimate(motor, Iq, w, theta_e):
    return (motor.kt*Iq - friction(w)
            - sum(a*sin(k*motor.p*theta_e + phi)
                  for k, a, phi in motor.harmonics))

def ripple_residual(motor, calib):
    return max(abs(torque_estimate(*s) - calib.f_ft[s]) for s in calib.samples)

def observability_margin(motor, w, contact, mode):
    if mode == 'encoder':
        return 1.0
    if mode == 'sensorless' and abs(w) < motor.w_min:
        return contact_normal_snr(contact) / motor.snr_min
    return back_emf_snr(motor, w) / motor.snr_min
```

### IP-126 CSC（Compliance Safety Certificate）

```python
def compliance_certificate(seq, motor, state):
    Z_core = intersect([s.Z for s in seq])
    h_Z = min(headroom(Z_feas(state), z) for z in Z_core)
    E = compose_chain_energy(seq)
    F = timescale_margins(seq, motor)
    Tw_pred = thermal_predict(seq, state, motor)
    O = observability_cert(seq, state)
    ok = (h_Z >= h_min and E >= E_min and F.ok
          and Tw_pred + margin <= motor.Tw_max and O.ok)
    return JointComplianceCert(ok, Z_core, h_Z, E, F, Tw_pred, O)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| IEA | `O(|Ω|·|T|·|A_Z|·T_sim)` | `O(|Ω|·|T|·|A_Z|)` | 包络边界保守、渲染判据可靠 |
| PBC | `O(|S|·|A_Z|)` | `O(|S|)` | 能量罐非负、切换代价可加 |
| MTC | `O(|P|)` | `O(|P|)` | 频率分离成立、admit/revoke 原子性 |
| CAG | `O(1)` 每控制拍 | `O(1)` | 裕度单调、软化保持无源性 |
| RRC | `O(|H|·|A|)` | `O(|H|)` | 纹波模型周期正确、残差可界 |
| CSC | `O(|S|·|A_Z|+|𝔇_ρ|)` | `O(|A_Z|+|𝔇_ρ|)` | 六类裕度联合 sound |

**正确性定理（Actuator-Grounded Compliance Soundness, AGCS）**
假设第 54 轮 (A26)–(A28) 成立；并新增 **(A29)** 阻抗指令位于 `Z_feas(ω,T_w)` 且 `h_Z≥h_min`；**(A30)** 组合满足能量罐非负（PBC guard 生效）；**(A31)** `f_e ≥ 10 f_i ≥ 100 f_t`；**(A32)** 热/电压/电流裕度 `m≥0`，调速器只在 `m≥0` 域内软化；**(A33)** 观测误差 `ε_o≤ε_o,max`、纹波残差 `ε_r≤ε_r,max`。
则接触闭环在能量意义下无源（或有限增益 `L_2` 稳定），且力跟踪误差满足
```
||f - f_d||_∞ ≤ ε_Z + ε_r + L_c·ε_o + (1-κ)·ΔK·|e|_max
```
任务成功概率满足
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - P(h_Z<h_min) - P(E<E_min) - P(m<0) - β_E
```
关键：**柔顺必须先在执行器包络内成立**，**组合必须先在能量预算内成立**，**接触稳定性只在边端时间尺度上被承诺**。三者任一失效，证书都必须 `reject` 而非降级解释。

## 6. 本轮最大风险

**一句话**：本轮把柔顺从“控制律属性”下沉为“执行器物理能力”，但阻抗包络、能量罐、热预算与低速可观测性四个证书都依赖电机参数与接触动力学的在线辨识，一旦辨识偏差或云端时间尺度违约，柔顺调速器可能在真实接触中悄悄饱和、注入能量或热失控；因此必须坚持“物理包络优先、证书不过不部署、宁可更软更慢也不越界”的保守原则，绝不把仿真里的理想阻抗当成电机能兑现的柔顺。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-Compliance（IEA×PBC×MTC×CAG×RRC×CSC）

> 承接第 54 轮产物 v31（GroundEdge-GenSim+++ / IP-115~120）。上一轮把“技能组合”从能力匹配提升为动作空间 + 云边映射 + 鲁棒性联合证书，但动作空间仍是运动学抽象。本轮引入两个物理锚点——**柔顺控制（阻抗可控）**与**无刷电机（阻抗可合成）**——新增六个算子，把证书下沉到执行器物理层：
> - **IEA（Impedance Envelope Algebra）**：从电机参数计算随运行点变化的可行阻抗域 `Z_feas(ω,T_w)` 与阻抗剖面 `ζ_S`；

> - **CAG（Compliance-Aware Governor）**：热/电压/电流/观测裕度驱动的“越界即软化”安全调节器；
> - **RRC（Ripple & Observability Certificate）**：齿槽纹波补偿 + 电流估力 + 低速接触可观测性证书；
> - **CSC（Compliance Safety Certificate）**：`J_c=(Z,E,F,T,O)` 六裕度联合部署门。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/116/118/120 以纳入阻抗与能量维度。

## 2. 关键算法 伪代码

### IP-121 IEA

```python
def renderable(motor, K, D, w, Tw):
    Tmax = min(motor.T_cont(Tw), motor.kt*motor.Imax,
               motor.kt*max(0.0, motor.Vbus - motor.ke*abs(w))/motor.R)
    resp = closed_loop_step(motor, K, D, Tmax, motor.fc)
    return (not resp.saturated and resp.bw >= motor.f_min
            and resp.force_res <= motor.df_max and resp.passive)

def impedance_envelope(motor, omega_grid, temp_grid, z_grid):
    return {(w, Tw): {z for z in z_grid if renderable(motor, *z, w, Tw)}
            for w in omega_grid for Tw in temp_grid}

def headroom(Z_feas, z):
    return distance_to_boundary(Z_feas, z) / radius(Z_feas)

def cover_Z(skill, Z_T, theta_z=0.8):
    return all(skill.zeta.get(z, 0.0) >= theta_z for z, w in Z_T)
```

### IP-122 PBC

```python
def tank_update(skill, dt, f, xdot, alpha, beta, gamma):
    P = dot(f, xdot)
    E = skill.E + dt*(alpha*max(P, 0) + beta*min(P, 0) - gamma*abs(P))
    skill.E = clip(E, 0.0, skill.E_max)
    return skill.E

def govern_tank(E, E_low, dK):
    return 0.0 if (E < E_low and dK > 0) else dK

def compose_passive(S1, S2, z1, z2, H, E_min):
    E_sw = 0.5 * (z2 - z1) @ H @ (z2 - z1)
    E = S1.E + S2.E - E_sw
    return Reject('energy_budget', E, E_sw) if E < E_min else Accept(E_comp=E, E_sw=E_sw)
```

### IP-123 MTC

def cloud_issue(task_seq, K_des, D_des, E_budget, f_t, f_i, f_e):
    assert f_e >= 10*f_i and f_i >= 10*f_t
    return Contract(task_seq, K_des, D_des, E_budget, f_t, f_i, f_e)

def edge_admit(contract, motor, state):
    if not timescale_ok(contract, motor):
        return Revoke('timescale')
    K, D, m, kappa = governor(contract.K_des, contract.D_des, state, motor)
    if not in_envelope(motor, K, D, state.w, state.Tw):
        return Revoke('envelope', headroom(...))
    if state.E < contract.E_min:
        return Revoke('energy')
    return Admit(K, D, headroom(...), state.E, motor.f_i)

### IP-124 CAG

```python
def governor(Kd, Dd, state, motor):
    m_th = (motor.Tw_max - state.Tw) / motor.dTw
    m_v  = (motor.Vbus - motor.ke*abs(state.w) - motor.R*abs(state.I)) / motor.Vbus
    m_i  = (motor.Imax - abs(state.I)) / motor.Imax
    m_o  = 1.0 - state.eps_o / motor.eps_o_max
    m    = min(m_th, m_v, m_i, m_o)
    kappa = clip((m - motor.m0) / (1 - motor.m0), motor.kappa_min, 1.0)
    K = kappa * Kd
    D = kappa * Dd + (1 - kappa) * motor.D_safe
    return K, D, m, kappa
```

### IP-125 RRC

```python
def torque_estimate(motor, Iq, w, theta_e):
    return (motor.kt*Iq - friction(w)
            - sum(a*sin(k*motor.p*theta_e + phi)
                  for k, a, phi in motor.harmonics))

def ripple_residual(motor, calib):
    return max(abs(torque_estimate(*s) - calib.f_ft[s]) for s in calib.samples)

def observability_margin(motor, w, contact, mode):
    if mode == 'encoder':
        return 1.0
    if mode == 'sensorless' and abs(w) < motor.w_min:
        return contact_normal_snr(contact) / motor.snr_min
    return back_emf_snr(motor, w) / motor.snr_min
```

### IP-126 CSC

```python
def compliance_certificate(seq, motor, state):
    Z_core = intersect([s.Z for s in seq])
    h_Z = min(headroom(Z_feas(state), z) for z in Z_core)
    E = compose_chain_energy(seq)
    F = timescale_margins(seq, motor)
    Tw_pred = thermal_predict(seq, state, motor)
    O = observability_cert(seq, state)
    ok = (h_Z >= h_min and E >= E_min and F.ok
          and Tw_pred + margin <= motor.Tw_max and O.ok)
    return JointComplianceCert(ok, Z_core, h_Z, E, F, Tw_pred, O)
```

|---|---|---|---|
| IEA | `O(|Ω|·|T|·|A_Z|·T_sim)` | `O(|Ω|·|T|·|A_Z|)` | 包络边界保守，渲染判据可靠 |

| CSC | `O(|S|·|A_Z|+|𝔇_ρ|)` | `O(|A_Z|+|𝔇_ρ|)` | 六裕度联合 sound |

**正确性定理（AGCS）**：若 (A26)–(A28) 与 (A29)–(A33) 成立（阻抗在包络内、能量罐非负、时间尺度分离、热/电裕度非负、观测/纹波达标），则接触闭环无源（或有限增益 `L_2` 稳定），力误差
```
||f-f_d||_∞ ≤ ε_Z + ε_r + L_c·ε_o + (1-κ)·ΔK·|e|_max
```
且 `P_success ≥ 1 - Σ_d(1-ρ_min(d)) - P(h_Z<h_min) - P(E<E_min) - P(m<0) - β_E`。

## 4. 解析示例（无刷电机 ↔ 柔顺边界）

取单个关节电机示例参数：`k_t=k_e=0.12`（SI）、`R=0.2Ω`、`L=0.1mH`（`τ_e=0.5ms`）、`I_max=20A`、`V_bus=48V`、`T_peak=2.4N·m`、`T_cont=0.9N·m`、`r=0.1m`（等效力臂）、接触位移上限 `e_max=5mm`。

| 转速 `ω` (rad/s) | 反电动势 (V) | 电压允许电流 (A) | `T_max` 峰值 (N·m) | `K_max=T/r e_max` (N/m) |
|---|---|---|---|---|
| 0 | 0 | 240 | 2.40 | 4800 |
| 200 | 24 | 120 | 2.40 | 4800 |
| 380 | 45.6 | 12 | 1.44 | 2880 |
| 395 | 47.4 | 3 | 0.36 | 720 |
| 400 | 48.0 | 0 | 0 | 0 |

结论 1：同一关节在高速段可渲染的刚度上界会掉一个数量级，`Z_feas` 必须按运行点索引，不能用额定点常数。

结论 2（能量罐数值示例）：从 `K1=200N/m` 切到 `K2=1800N/m`，接触误差 `e=1mm` 时切换能量 `E_sw=½ΔK e²=0.8mJ`；若 `E_min=5mJ` 则允许。若 `e=3mm`，`E_sw=7.2mJ>E_min`，必须拒绝或先增大阻尼耗散再切换。这把“看似平滑的刚度切换”变成了可计算的能量门。

结论 3（热降额）：连续力矩 0.9N·m 对应 `I=7.5A`，铜损 `I²R=11.25W`；设 `R_th=1.2K/W`、`C_th=15J/K`，则稳态温升 13.5K、热时间常数 18s。若任务需要 `K` 使平均力矩升到 1.2N·m（`I=10A`、铜损 20W、温升 24K），则调速器应按 `m_th` 提前软化，而不是等到热保护跳闸。
