# 第 59 轮（承接第 58 轮「KGMM×SFT-KG×UXSE×KGES×ACC×PCX++」IP-139~144；灵感循环第 5 轮；本轮灵感：「跨任务泛化」×「抗干扰」）

> 第 58 轮把部署前提从"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为"结构化记忆守护下的安全自适应"：知识图谱 𝒢 同时驱动元推断检索、OOD 判定、微调触发、证据合成、心智模型预测，KG 的隔离写入与事后证伪回溯使"图里写着的知识"不能绕过证据门。但它自陈的最大风险同时暴露了两个尚未被正面处理的维度：**(a)** 全部安全论证仍然**绑定在单一任务/单一技能族**上——同一张 KG 的相似边、同一套共形残差、同一份校准证书，都被默认"对四足地形遍历有效，就对机械臂抓取/巡检/移动操作也有效"；跨任务复用一旦发生，风险签名、失败模式、不可逆等级都可能不同，而当前证据门没有任何机制检查"这份证据在任务语义上是否仍然成立"。**(b)** 抗干扰只被处理成"物理欺骗"这一特例：跨模态分歧能抓"同一物理性质骗过多个模态"，却抓不住**主动干扰**——传感器注入、通信丢包/延迟、GPS 欺骗、风扰与打滑，以及"把干扰伪装成良性噪声"的对抗策略；共形带假设样本可交换，一旦观测分布被对手按检查点选择性扭曲，覆盖保证就失效。本轮两个灵感各补一条腿：**跨任务泛化**把安全论证从"任务专用"提升为"风险签名可迁移"——任务只负责给出技能与风险签名，安全内核只认风险签名，迁移必须携带迁移证书与目标侧确认；**抗干扰**把"鲁棒"从经验指标提升为"声明干扰集下的证书"——随机平滑给出感知认证半径、鲁棒 CBF 给出控制不变集、干扰归因只许收紧不许放松。核心命题升级为 **"任务可迁移、干扰可证伪的证书化安全"**。

核心矛盾：
- **H29（迁移 vs 健全）**：跨任务复用证据是把"一个任务的样本"借给另一个任务，效率来自共享结构，风险也来自共享结构——一个在风险签名里未被建模的失败模式，可以让两个"看起来等价"的技能在迁移后同时失效；迁移越省探针，负迁移越难被发现。
- **H30（鲁棒 vs 效用）**：认证鲁棒性有半径、有度量、有代价——半径越大越保守、弃权越多、承诺越慢；而且证书只对声明的干扰度量成立，对手可以换一个未被认证的度量（度量规避），把"已认证"变成"未覆盖"。
- **H31（干扰 vs 归因）**：良性扰动与恶意干扰在残差上同形；把干扰误判为良性会延迟降级，把良性误判为干扰会浪费任务机会；对手还可以主动把干扰塑造成良性噪声的统计特征，使归因本身成为攻击面。
- **H32（任务边界 vs 内核）**：安全内核要任务无关，但"当前是哪个任务/技能"本身是一个会被误判的分类问题；任务误识别若发生在内核之外，会让系统带着正确的内核去执行错误的技能。

## 0. 直觉与动机

**灵感 1（跨任务泛化 → 风险签名内核 + 迁移税）**
直觉：把"任务"和"安全"解耦。任务 τ 只负责给出目标、技能序列与成功谓词；安全只认**风险签名** R(σ)=(不可逆等级, 接触能量上界, 失败模式集, 干扰敏感度, 不确定源)。安全内核 K_safe 只吃签名，不吃任务名——这样"四足过冰面"和"机械臂抓玻璃杯"可以共享同一套安全推理，只要它们的风险签名落在同一等价类。跨任务迁移不是"把模型复制过去"，而是"把源技能的证据按迁移税借给目标技能"：迁移税 = 技能图距离的指数折扣 + 目标侧确认探针 + 迁移共形膨胀。离得越远、分歧越大，借来的证据越轻；不可逆动作永远不借。

**灵感 2（抗干扰 → 认证半径 + 鲁棒不变集）**
直觉：鲁棒不应该靠"检测到异常再处理"，而应该靠"按声明的干扰集预先留出裕度"。感知侧用随机平滑给出认证半径 R_cert：只要 R_cert(x)≥ε_p，就声明"在这个 L_p 球内标签不变"；控制侧用鲁棒 CBF 给出干扰集下的不变集：只要离散下降条件成立，就声明"在 Δ 内不出安全集"。证据门新增 **EV-robust**：只有"认证半径 ≥ 声明干扰预算"且"干扰账本未透支"的证据才算数。检测是第二道防线，证书是第一道。

**灵感 3（干扰归因 → 歧义集 + 单向收紧）**
直觉：不要求系统准确回答"这是噪声还是攻击"，而是维护歧义集 𝒜_ε（所有与残差史相容的分布），安全决策对 𝒜_ε 取最坏。归因 A 只做一件事：把动作集往小里收。它不能解锁任何证据类、不能降低任何门限、不能缩短任何超时——**归因错误的最坏代价被限制在"更保守"，而不是"更敢赌"**。这与第 57/58 轮"个性化只能向保守方向滑动"是同一条单调性纪律。

**灵感 4（降级阶梯 → 有不变式的优雅降级）**
直觉：抗干扰不是一个二元开关，而是一条有证书的阶梯：正常 → 鲁棒 → 减传感 → 安全停 → 人接。每一级都有可用通道、动作包络、不变式与证书条件；降级实时（干扰账本透支/通道污染/认证半径不足），升级要攒够恢复证据与驻留时间；被标记污染的通道不得出现在任何一级的不变式里。这样"干扰持续"最终必然收敛到安全停或人接，而不是在"检测/恢复"之间反复抖动。

**灵感 5（三灵感合流 → 证据门从六类到八类、从单任务到可迁移）**
直觉：第 58 轮六类证据门在本轮获得两个新成员：**EV-xfer**（限 L1，需目标侧确认，带迁移税与负迁移门）与 **EV-robust**（需认证半径，干扰账本未透支）。不可逆必要集仍然只认目标侧的 EV-probe*/EV-margin + 佐证——迁移来的证据与鲁棒证书都不得单独进入不可逆接触。击穿安全需要：风险签名不完备 ∧ 迁移分歧漏检 ∧ 认证半径失效 ∧ 归因误判 ∧ 降级不变式被污染 ∧ 人也错——纵深从五层扩到七层。

## 1. 形式化定义（增量：定义 145–150）

**定义 145（任务-技能风险签名内核 RSK）** 任务 τ=(G_τ,Π_τ,Succ_τ)，技能原语集 Σ∋σ=(pre_σ,ctrl_σ,post_σ,ℓ_σ,𝔉_σ)，ℓ_σ∈{L0,L1,L2}。风险签名 R(σ)=(ι_σ,E_σ,𝔉_σ,S_σ,U_σ)：不可逆等级、接触能量上界、失败模式集、逐通道干扰敏感度 S_σ∈ℝ_{≥0}^{|𝒞|}、不确定源向量。签名距离
d_R(R,R')=max{w_ι·𝟙[ι≠ι'], w_E·|E−E'|/E_scale, w_F·J(𝔉,𝔉'), w_S·‖S−S'‖_∞/S_scale, w_U·‖U−U'‖_1}。
等价 σ≈_ρ σ' ⇔ d_R≤ρ ∧ ι_σ=ι_σ' ∧ S_{σ'}⪯S_σ（目标不得比源更敏感）。安全内核 K_safe(R,b,evidence,L_int)→2^A 不含任何 τ 语义；任务迁移只能经 K_safe。任务误识别被限制在内核之外：内核只认签名，认错任务最多导致选错技能，不能改变签名到动作的映射。

**定义 146（跨任务迁移证书 XTC）** 源证据 E_s 定义在 σ_s 上且已过原证据门；目标 σ_t 满足 σ_s≈_ρσ_t。取风险相关特征 φ_R（接触能量/滑移/材质簇/干扰敏感通道），密度比 w(x)=p_t(φ_R)/p_s(φ_R)，χ² 分歧 D_R=χ²(p_t‖p_s)。负迁移门：D_R>θ_xfer 或 d_R>ρ ⇒ 拒迁。迁移共形：C_t=C_s⊕Δ_xfer，Δ_xfer=Q_{1−α}({迁移残差差})，覆盖 ≥1−α−δ_xfer。迁移税 w_xfer=γ^{d_Σ(σ_s,σ_t)}, γ∈(0,1)；目标确认集 K_t 须满足 |K_t|≥k_conf(ι)（L0=0,L1=1,L2=禁迁）。证书 J_xfer=(σ_s,σ_t,d_Σ,D_R,Δ_xfer,w_xfer,k_conf,confirm_log)。

**定义 147（对抗干扰鲁棒性 AIR）** 干扰集 Δ=Δ_obs(ε_p)×Δ_act(ε_a)×Δ_comm(p_drop)×Δ_phys(ε_d)。感知认证：随机平滑分类器 g_RS，认证半径 R_cert(x)=(σ_s/√2)(Φ^{-1}(p_(1)(x))−Φ^{-1}(p_(2)(x)))，p_(1),p_(2) 为最高与次高类概率。鲁棒证据 EV-robust ⇔ R_cert(x)≥ε_p ∧ 通道完整性 ∧ 干扰账本 L_int≤B_int。控制不变：离散鲁棒 CBF h(x_{k+1})≥(1−α_cbf)h(x_k)−L_Δ·ε，安全集 S_ε={x:h(x)≥h_min+κ·ε}。L_int 按检查点累积（观测扰动/动作延迟/丢包/物理扰动各记一账），透支即触发 RGD。

**定义 148（干扰归因歧义集 DAB）** 假设集 ℋ={H_benign,H_adv}；歧义集 𝒜_ε={P:D_KL(P‖P_0)≤ε ∧ sup dP/dP_0≤e^ε}。归因 A 把残差史映为后验，但安全动作集
A_safe(a)=A_base∩(∩_{P∈𝒜_ε}A_safe(P))。
单向收紧公理：∀a，A_safe(a)⊆A_base 且 A_safe(H_adv)⊆A_safe(H_benign)；归因不产生证据类、不解锁权限、不改变 θ 门限、不缩短 τ_int。于是归因误判只能让系统更保守，不能让它更敢赌。

**定义 149（鲁棒优雅降级阶梯 RGD）** 阶梯 ℓ∈{0,1,2,3,4}=正常/鲁棒/减传感/安全停/人接。每级 I_ℓ=(可用通道 C_ℓ,动作包络 A_ℓ,不变式 Inv_ℓ,证书条件 Cert_ℓ)。转移：降级实时（L_int 透支 ∨ 通道污染 ∨ R_cert<ε_p）；升级需 n_rec≥N_up(ℓ) ∧ 驻留≥T_dwell ∧ 覆盖≥1−α。污染通道集 Q：∀ℓ，Inv_ℓ 不得引用 C_ℓ∩Q。完备性：干扰持续 ⇒ 有限检查点内到达 ℓ≥3；无抖振：同一干扰段内降级次数≤1。

**定义 150（PCX+++ 算子）** 每检查点：①任务/技能识别（误差≤δ_task）→ R(σ)；②σ 为新技能时经 XTC 检索迁移证据（迁移税+目标确认），否则只用本地证据；③AIR 估干扰、DAB 归因、RGD 选级；④证据门八类判定；⑤探-诺-演，含新预算 B_xfer/B_robust/B_degrade。硬禁令：不可逆必要集={目标侧 EV-probe*∨EV-margin}∪佐证，不含 EV-xmodal/EV-xfer/EV-robust（单独）/EV-ft/EV-ux；EV-xfer 仅限 L1；EV-robust 仅可替代一次 L1 佐证。

## 2. 关键算法伪代码

```python
def rsk_signature(sigma):
    return RiskSig(irr=sigma.level, energy=sigma.E_max,
                   fail_modes=sigma.F, sens=channel_sensitivity(sigma),
                   unc=uncertainty_sources(sigma))

def cross_task_transfer(sigma_t, lib, target_evidence):
    cands = [s for s in lib
             if dR(rsk(s), rsk(sigma_t)) <= rho
             and s.level == sigma_t.level
             and dominates(s.sens, sigma_t.sens)]
    if not cands: return None, 'no_equivalent_skill'
    s = min(cands, key=lambda x: dSigma(x, sigma_t))
    if chi2_div(p_target(phi_R), p_source(s, phi_R)) > theta_xfer:
        return None, 'negative_transfer'
    if sigma_t.level == 'L2':
        return None, 'L2_transfer_forbidden'          # 不可逆永不借证据
    C_t = inflate(C_s, quantile(transfer_residuals, 1 - alpha))
    cert = XferCert(s, sigma_t, C_t, w_xfer=gamma ** dSigma(s, sigma_t),
                    need=k_conf(sigma_t.level))
    if len(target_evidence.confirmations) < cert.need:
        return cert, 'need_target_confirmation'
    return cert, 'ok'

def air_guard(obs, h_prev, eps_p, eps_d, ledger):
    r_cert = smooth_radius(obs)                       # 随机平滑认证半径
    robust_ok = (r_cert >= eps_p) and channel_intact(obs) and ledger.remaining() > 0
    cbf_ok = h(obs) >= (1 - alpha_cbf) * h_prev - L_Delta * eps_d
    return robust_ok and cbf_ok, r_cert

def dab_attribution(residuals, amb_set):
    post = bayes_update(residuals, amb_set)           # 只用于收紧
    return post

def rgd_step(rung, state, post, ledger):
    if ledger.exhausted() or channels_compromised(state):
        return min(rung + 1, 4)                       # 降级实时
    if rung > 0 and can_upgrade(state):               # 升级有据有界
        return rung - 1
    return rung

def pcx_plus_plus_plus(cp, M, skill_lib, budget):
    sigma = identify_skill(cp, M)                     # ① 任务/技能识别
    R = rsk_signature(sigma)
    xfer, status = cross_task_transfer(sigma, skill_lib, M.target_evidence)
    ok_robust, r_cert = air_guard(M.obs[cp], M.h_prev, M.eps_p, M.eps_d, M.ledger)
    post = dab_attribution(M.residuals[cp], M.amb_set)  # ③ 归因只收紧
    M.rung = rgd_step(M.rung, M, post, M.ledger)
    ev = tag_evidence_ppp(cp, M, R, xfer, ok_robust, r_cert, M.rung)
    return evidence_gate_ppp(ev, M, status)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| RSK | O(\|Σ\|·\|𝔉\|) 离线；查表 O(1) | O(\|Σ\|) | 签名诚实、等价类不隐藏未建模失败模式 |
| XTC | O(\|Σ\|·d_φ + N_res) | O(\|Σ\|·\|𝒟_xfer\|) | 负迁移门、迁移共形覆盖、L2 禁迁 |
| AIR | O(1)/推理（平滑）+ O(d_x) CBF | O(d_x) | 认证半径声明诚实、ε 与账本一致 |
| DAB | O(\|𝒜\|) 更新 | O(\|𝒜\|) | 歧义集含真分布、单向收紧 |
| RGD | O(1)/检查点 | O(\|𝒞\|) | 降级实时、升级有界、无抖振 |
| PCX+++ | O(\|CP\|·(k_p+k_c+k_x+k_r+k_d)·(C_VOI+d_φ)+\|CP\|·A\*) | O(\|V\|+\|σ\|+\|Σ\|) | 六预算单调、八类证据门硬禁令 |

**正确性定理（TPIRS 概要）**：在 A22–A45 上加 **(A46)** 风险签名相对声明失败模式分类完备、d_R 为度量、等价类不跨 ι；(A47) 迁移分歧估计诚实、负迁移门漏检≤δ_xfer、迁移共形覆盖≥1−α−δ_xfer；(A48) 认证半径健全、干扰预算 ε 诚实、鲁棒 CBF 下降条件成立；(A49) 歧义集含真分布、归因单调只收紧；(A50) 阶梯不变式有证书、污染通道不入 Inv、完备且无抖振；(A51) 任务识别误差≤δ_task 且误识别不能绕过内核。则：
(i) 安全界
P_safe ≥ 1 − Σ_cp(δ_f+ε_meta(k)+δ_probe+ε_h+δ_ood·α_conf+δ_xm·1[L1]+δ_ft·1[回滚]+δ_kg·1[检索失败]+δ_ux·1[μ_mis>θ_mis]+δ_task+δ_xfer·1[迁移]+δ_robust·1[ε_p>0]+δ_attr·1[干扰]+δ_degrade·1[降级]) − P(签名不完备) − P(𝒜_ε 不含真分布) − P(阶梯失效)；
(ii) 迁移单调性：任何 XTC 复用只能加宽区间或缩小允许动作集，L2 不可逆永不依赖迁移证据；
(iii) 干扰单调性：归因与降级只能收紧，良性归因不解锁任何证据类；
(iv) 终止性：PCX+++ 在 k_probes+k_cons+k_ft+k_ux+k_xfer+k_robust+k_degrade 内终止于 {承诺,绕行,L2 协商,安全停,人接}。

### IP-145 RSK（风险签名内核）

```python
class RiskSignatureKernel:
    def __init__(self, weights, rho):
        self.w = weights          # (w_iota, w_E, w_F, w_S, w_U)
        self.rho = rho

    def signature(self, sigma):
        return RiskSig(
            irr=sigma.level,
            energy=sigma.E_max,
            fail_modes=frozenset(sigma.F),
            sens=channel_sensitivity(sigma),     # {channel: >=0}
            unc=uncertainty_sources(sigma),
        )

    def distance(self, R, R2):
        w = self.w
        return max(
            w[0] * (0.0 if R.irr == R2.irr else 1.0),
            w[1] * abs(R.energy - R2.energy) / E_SCALE,
            w[2] * jaccard(R.fail_modes, R2.fail_modes),
            w[3] * linf(R.sens, R2.sens) / S_SCALE,
            w[4] * l1(R.unc, R2.unc),
        )

    def equivalent(self, sigma_s, sigma_t):
        R, R2 = self.signature(sigma_s), self.signature(sigma_t)
        return (self.distance(R, R2) <= self.rho
                and R.irr == R2.irr
                and dominates(R.sens, R2.sens))   # S_t <= S_s 逐通道

    def safe_actions(self, R, belief, evidence, ledger):
        # 任务无关：只看签名，不看 τ
        A = base_action_envelope(R.irr, R.energy)
        A &= margin_envelope(belief, R.fail_modes)
        A &= interference_envelope(R.sens, ledger)
        return A
```

### IP-147 AIR（认证抗干扰）

```python
class AIRGuard:
    def __init__(self, sigma_smooth, alpha_cbf, h_min, kappa, L_Delta):
        self.sigma_s = sigma_smooth
        self.alpha_cbf = alpha_cbf
        self.h_min = h_min
        self.kappa = kappa
        self.L_Delta = L_Delta

    def certified_radius(self, x):
        p = self.smoothed_probs(x)
        p1, p2 = top2(p)
        return (self.sigma_s / math.sqrt(2)) * (
            norm_ppf(p1) - norm_ppf(p2))

    def robust_evidence_ok(self, x, eps_p, ledger):
        return (self.certified_radius(x) >= eps_p
                and channel_intact(x)
                and ledger.remaining() > 0)

    def robust_cbf_ok(self, h_prev, h_next, eps):
        return h_next >= (1 - self.alpha_cbf) * h_prev \
               - self.L_Delta * eps

    def step(self, x, h_prev, eps_p, eps_d, ledger):
        r = self.certified_radius(x)
        ok = self.robust_evidence_ok(x, eps_p, ledger) \
             and self.robust_cbf_ok(h_prev, h(x), eps_d)
        return ok, r
```

```python
class RobustGracefulDegradation:
    RUNGS = [
        # (可用通道, 动作包络, 不变式, 证书条件)
        ('normal',  ALL_CHANNELS, A_NORMAL, INV_NORMAL, CERT_NORMAL),
        ('robust',  ALL_CHANNELS, A_ROBUST, INV_ROBUST, CERT_ROBUST),
        ('reduced', SAFE_CHANNELS, A_REDUCED, INV_REDUCED, CERT_REDUCED),
        ('stop',    NONE, A_STOP, INV_STOP, CERT_STOP),
        ('handoff', NONE, A_HANDOFF, INV_HANDOFF, CERT_HANDOFF),
    ]

    def step(self, rung, state, ledger, compromised):
        # 降级实时
        if ledger.exhausted() or (compromised & self.RUNGS[rung].channels):
            return min(rung + 1, len(self.RUNGS) - 1)
        # 升级有据有界：恢复证据 + 驻留 + 覆盖
        if rung > 0 and self.can_upgrade(rung, state):
            return rung - 1
        return rung

    def can_upgrade(self, rung, state):
        target = self.RUNGS[rung - 1]
        return (state.n_recover[rung] >= N_UP[rung]
                and state.dwell[rung] >= T_DWELL
                and state.coverage >= 1 - ALPHA
                and not (state.compromised & target.channels))

    def invariant_ok(self, rung, state):
        # 污染通道不得出现在不变式中
        return not (self.RUNGS[rung].channels & state.compromised) \
               and self.RUNGS[rung].invariant(state)
```

### IP-149 与 IP-147 的联动：干扰账本与降级触发

```python
class InterferenceLedger:
    def __init__(self, B_int):
        self.B_int = B_int
        self.spent = 0.0

    def charge(self, obs_residual, delay, drop, phys):
        self.spent += (w_o * obs_residual + w_a * delay
                       + w_c * drop + w_p * phys)

    def remaining(self):
        return self.B_int - self.spent

    def exhausted(self):
        return self.remaining() <= 0

    def replenish(self, calibration_gain):
        self.spent = max(0.0, self.spent - calibration_gain)
```

**正确性定理（Task-Portable Interference-Robust Soundness, TPIRS）**
假设 A22–A45（第 53–58 轮）成立；**(A46)** RSK：风险签名相对声明失败模式分类完备，d_R 为度量，σ≈_ρσ' 不跨 ι 且目标敏感度不高于源；**(A47)** XTC：χ² 分歧估计诚实、负迁移门漏检 ≤δ_xfer、迁移共形覆盖 ≥1−α−δ_xfer、L2 禁迁由结构保证；**(A48)** AIR：随机平滑认证半径声明健全、干扰预算 ε 诚实、鲁棒 CBF 下降条件在 Δ 内成立；**(A49)** DAB：歧义集 𝒜_ε 含真分布、归因满足单向收紧 A_safe(a)⊆A_base；**(A50)** RGD：每级不变式有证书、污染通道不入 Inv_ℓ、降级实时、升级有界、干扰持续时有限步到达 ℓ≥3；**(A51)** PCX+++：任务识别误差 ≤δ_task，且误识别不能绕过 K_safe（内核只认签名）。则：

1. **任务可迁移健全性**：任何经 XTC 复用的证据，其贡献只能使后验区间加宽（C_t=C_s⊕Δ_xfer）或使允许动作集缩小（迁移税 w_xfer≤1、目标确认只增不减）；L2 不可逆接触的必要证据集不含任何迁移证据。
2. **抗干扰认证健全性**：若 EV-robust 成立，则在该检查点的声明干扰集 Δ 内，感知标签不变且控制状态保持在 S_ε；干扰账本透支前必有降级或安全停。
3. **归因单向性**：∀a，A_safe(a)⊆A_base，且 A_safe(H_adv)⊆A_safe(H_benign)；归因不产生任何证据类、不解锁权限、不改变门限与 τ_int。
4. **降级完备性**：干扰持续 ⇒ 有限检查点内 ℓ≥3；同一干扰段内降级次数 ≤1（无抖振）；升级需 n_rec、驻留与覆盖三重条件。
5. **终止性**：PCX+++ 在 k_probes+k_cons+k_ft+k_ux+k_xfer+k_robust+k_degrade 内终止于 {承诺,绕行,L2 协商,安全停,人接}。
6. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                   + δ_ft·1[回滚窗口] + δ_kg·1[检索失败] + δ_ux·1[μ_mis>θ_mis]
                   + δ_task + δ_xfer·1[迁移] + δ_robust·1[ε_p>0]
                   + δ_attr·1[干扰] + δ_degrade·1[降级])
         − P(风险签名不完备) − P(𝒜_ε 不含真分布) − P(阶梯不变式失效)
         − P(护盾回退失败) − P(τ_int 超时 ∧ 安全停失效)
```

关键：**任务与安全解耦**（K_safe 只认风险签名，任务误识别无法改变签名→动作映射）；**迁移必付税**（负迁移门 + 共形膨胀 + 目标确认 + L2 禁迁，四重使"借来的证据"永远弱于"自己测的证据"）；**抗干扰前移为证书**（认证半径 + 鲁棒 CBF + 干扰账本，检测只是第二道）；**归因只收紧**（歧义集最坏 + 单向公理，归因错误最多更保守）；**降级有不变式**（污染通道不入 Inv，干扰持续必达安全停/人接）。

## 6. 本轮最大风险

**一句话**：本轮同时引入两个新的"判定权"——**风险签名决定"两个任务是否等价"**、**干扰归因决定"当前该多保守"**；若签名不完备（某失败模式不在 𝔉 里），伪等价会让迁移证据带着证书跨任务扩散；若对手能把干扰塑造成良性噪声的统计特征，归因会迟迟不降级——两者在同一检查点叠加，就形成"既借了不该借的证据、又没触发该触发的降级"的共模缺口。必须以「签名完备性审计、L2 永久禁迁、目标侧确认、归因单向收紧、阶梯不变式不依赖污染通道」五重护栏，宁可退回"每任务从零探、每干扰按最坏算"的又慢又保守模式，绝不采信"签名说等价、归因说没事"。
