# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「仿真训练」×「多模态融合」）

> R69 把不确定性拆成 aleatoric / epistemic，用「流匹配多模态策略 + 主动多模态交互」去消解 epistemic；它甚至预判了自己的死穴——**问错比不问更危险**——并给出对策 MCG：模态权重 ECE 越界就退回纯保守。但这个对策有一个致命的结构问题：**真实世界里 ECE 的「真值」不可观测**。你不知道真实的模态是什么，所以你不知道自己的模态权重对不对；你也无法在日志里估计一次「没被问出口的追问」的 VoI，因为日志里没有反事实。于是 R69 的「可信」是一个**开环断言**：它用一个自己无法验证的量，来决定能不能去问。这等于说「我相信我的镜子是平的，所以我可以照着它化妆」，却从不检查镜子本身。
>
> 本轮两个灵感正好补上「照镜子」这件事：
> - **仿真训练**给出真实世界给不出的东西——**可标注的歧义**（注入已知 latent mode）与**可执行的 do(g) 反事实**（答者、材质、时延都可被干预）。它能把 R69 的 ECE、VoI、可识别性从「不可观测」变成「在孪生里可测」。
> - **多模态融合**给出判断「我到底在哪个仿真世界」的**见证**——域随机化孪生预测的是**跨模态联合分布**；真实的多模态残差若与所有孪生都不一致，就是 sim-to-real gap 的物理证据；而模态对的可识别性，也由融合统计量在仿真中预先算出。
>
> 核心命题：**R69 问「我该向谁求证」；R70 先问「我以为自己在的那个世界，还是我训练时那个世界吗」。** 用域随机化数字孪生银行提供带 ground truth 的标定与反事实，用真实多模态证据反推 regime；只有当真实观测落在**已被标定、且检验有功效**的孪生包络内，才允许 R69 的交互；否则逐级退回 FLUID / R68。命名 **MIRROR-RAS**（Multimodal Identification of Regime & Reliability via Oracle Rehearsal）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我现在还算在我被标定过的那个世界里吗**」——镜子裂了，就别照着镜子化妆。

## 0. 直觉与动机

**灵感 1（仿真训练 → 把不可观测的标定变成可测量的标定）**
直觉：R69 的 MCG 想回答「模态权重可信吗」，但真实世界里 mode 标签不存在；你只能拿一个代理指标（比如熵、置信度）去近似 ECE，而代理指标本身可能正是错的。仿真里可以**注入歧义**：我亲手设定「这里是绕左还是绕右」「这句话是开心还是紧张」，于是 mode 有 ground truth，ECE 可测，VoI 可用 do(g) 精确估计。仿真不是为了训更强的策略，而是为了**给不确定性本身提供标签**——这叫「元标定」（meta-calibration）：标定的不是策略，而是「策略对自己不确定性的判断」。

**灵感 2（仿真训练 → 但孪生会骗人，而且骗得比真实更自信）**
直觉：孪生是模型，模型有盲区。更危险的是，只要真实故障落在**所有**孪生都没建模的盲区里，跨模态残差仍会「自洽」地落进某个孪生包络，识别器会以最高置信说「我认得这个世界」。所以本轮不能把仿真当真值，只能当作**一个证据源**；并且必须显式度量**孪生多样性** D_Θ——如果所有孪生对同一个缺口给出相同预测，那么「缺口检验」根本没有功效，必须诚实地说「gap 不可判」，而不是伪造「银行内」。

**灵感 3（多模态融合 → 融合残差是 sim-to-real gap 的物理见证）**
直觉：单模态分布很容易被域随机化「覆盖」（噪声大一点、模糊一点），但**跨模态的关系**很难被覆盖：视觉说「杯子在前方 30cm」，触觉却摸到 5cm；语气说「开心」，表情却僵住。域随机化孪生预测的不是边缘分布，而是**联合分布** p(视觉,触觉,语气,表情 | regime)。真实世界的跨模态联合残差若落在所有孪生联合包络之外，就是 gap 的可观测证据。多模态融合在此从「提精度」升级为「提可证伪性」。

**灵感 4（多模态融合 → 可识别性先验：先问「这题答得出吗」再问）**
直觉：R69 的 CIA 只会在「已经决定要问」之后，选最有判别力的模态对；但它没先问一个更基本的问题：**这类歧义到底有没有任何一对模态能分开？** 比如「绕左还是绕右」若两个方向在视觉上完全对称、触觉也对称，那么再问也问不出来。仿真能预计算每类歧义在每个模态对上的 KL/Fisher 可识别性 I_{jk}(c)；MIG 门把「能不能答得出」从事后 VoI 变成**事前可行性**——这直接掐掉大量「追问幻影」的预算。

**灵感 5（包含关系 → MIRROR 只收紧、不放松）**
直觉：本轮最容易犯的错，是又加一个并列黑箱。所以我们把姿态定死：**MIRROR 只缩减 R69 允许交互的动作集合，从不增加；安全包络与 C-RAS-WM 认证完全继承；仿真量永远只是一个证据源。** 于是 R70 不可能在安全上弱于 R69；它的全部收益来自把「自信的错误追问」换成「诚实的弃权」，以及用可识别性把每次追问花在刀刃上。FLUID 是 MIRROR 在「孪生银行退化为一元、多样性为零、关闭 gap 检验」时的边界构型；R68 是再关闭 ECE 门的边界构型。

## 1. 形式化定义（增量：定义 310–323）

**定义 310（MIRROR-RAS 总览）** MIRROR-RAS = (TTB, SIC, CIV, MIG, FGR, TCC, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；孪生银行与标定图只在部署间隙离线更新；
(ii) **交互许可单调性**：MIRROR 在任意状态允许交互的动作集合 ⊆ FLUID 的（只会更少问、不会更多问），安全包络与 C-RAS-WM 认证完全继承；
(iii) **仿真不作真值**：任何仿真导出的量（ECE、VoI、可识别性）只能作为「一个证据源 / 先验」，不得单独认证一次追问；真实证据纪律（R69 定义 293-iii）不变。

**定义 311（域随机化孪生银行 TTB）** 孪生 T_i = (Θ_i, P_i^sim, R_i)，i=1..N。Θ_i 为随机化参数（噪声、时延、材质、答者诚实度、动力学）；P_i^sim 为仿真观测-动作联合分布；R_i 为仿真答者模型。仿真内可施加已知歧义注入 a†（真实 latent mode m†）与真实动作标签 ξ†，得到**带 ground truth 的校准集** D_i = {(o, m†, ξ†, g, y)}。校准图 C_i(g) = (ECE_i, TPR_i, FPR_i, VoI_i^{do})。

**定义 312（仿真-真实识别与包含 SIC）** 用融合编码器 φ(o) 表示真实跨模态证据。regime 后验 π_i = p(φ(o)|T_i) p(i) / Z，其中似然取**跨模态联合**（非边缘乘积，避免「各自合理但彼此矛盾」被高估）。novelty ν(o) = −log Z（负对数边缘似然）；regime 熵 H_reg = H(π)。**在银行内** ⇔ ν ≤ τ_nov 且 H_reg ≤ τ_reg。

**定义 313（反事实 / 干预式 VoI CIV）** 在孪生 T_i 内，对信息动作做 do(g) 干预并由 R_i 采样答者 y：VoI_i^{do}(g) = H(M|o) − E_{y~P_i(y|do(g),o)}[H(M|o,y)]。跨孪生聚合得区间 [VoI_lo, VoI_hi]；决策只用**下置信界** VoI_LCB = Quantile_α({VoI_i^{do}})。与 R69 定义 298 的观测式 VoI 的关键差异：do(g) 打破「问句—答者—真值」的混杂，避免自证式追问。

**定义 314（可识别性门 MIG）** 对歧义类 c 与模态对 (j,k)，在仿真中估计可识别性 I_{jk}(c) = min_{m≠m'} D_KL(p(φ_{jk}|m,c) ‖ p(φ_{jk}|m',c))（或 Fisher 信息下界）。查询计划 g 可采纳 ⇔ ∃(j,k)：I_{jk}(c_g) ≥ τ_id 且 (j,k) 两模态均可由 g 激励（看得见 / 摸得到 / 问得到）。这给出「**这个问题是否原则上答得出**」的事前判据，补 R69 只做事后 VoI 的缺口。

**定义 315（融合缺口残差 FGR）** 可靠性加权融合给出跨模态预测-观测残差 r_fuse（如由视觉预测触觉、由语气预测表情）。孪生 T_i 下 r_fuse ~ D_i。标准化缺口 z_fuse = (r_fuse − μ_i)/σ_i；sim-to-real gap 判据 G(o) = 1[∄i：z_fuse ∈ [−κ,κ] ∧ π_i ≥ τ_reg]。**关键诚实性**：定义孪生多样性 D_Θ = min_{i≠j} W_2(D_i, D_j)；若 D_Θ < τ_div，则 FGR 检验**无功效**（所有孪生预测同一缺口），必须显式标注「gap 不可判」，不得伪造「银行内」结论。

**定义 316（标定迁移证书 TCC）** 孪生 T_i 在置信 1−δ 下**可迁移** ⇔ (a) 留出仿真上 ECE_i ≤ τ_ece；(b) ν ≤ τ_nov 且 π_i ≥ τ_reg；(c) D_Θ ≥ τ_div（检验有功效）；(d) z_fuse ∈ 包络；(e) R69 定义 293-iii 证据纪律满足。证书 J_MIRROR = (J_FLUID, π_reg, H_reg, ν, D_Θ, z_fuse, VoI_LCB, I_{jk}, mirror_ver)。

**定义 317（幻影模态的反事实回放 PACR）** 对运行时提出的模态 m，在孪生银行内做回放：若 ∃T_i 使 m ∈ supp(P_i^sim|o) 且 π_i ≥ τ_reg，称 m **可被孪生重现**；否则 m 判为 **未重现**（幻觉模态，或银行外真模态——二者都不许单源定案）。PACR 把 R69 的「幻影模态」从只能事后审计，变成**事前可证伪**：只允许可重现模态进入 MINT 的候选集。

**定义 318（三级保守退避 TFB，λ 单调）**
- **T0**（孪生内 + TCC 可迁移）：允许 R69 交互；λ = λ_floor(U_ale)（resolution bonus）；
- **T1**（孪生内但 TCC 不可迁移 / D_Θ 低 / z_fuse 越界 / PACR 有未重现模态）：禁用交互，λ = λ_floor(U_ale + U_epi)（等同 R69 未消解）；
- **T2**（银行外：ν > τ_nov 或 H_reg > τ_reg）：禁用交互并回 R68 最保守，λ = max(λ_floor(U_ale+U_epi), λ_R68)，且 k 取 R68 收缩前缀。
**单调性**：λ_T0 ≤ λ_T1 ≤ λ_T2，且交互许可集 𝒢_T0 ⊆ 𝒢_FLUID，𝒢_T1 = 𝒢_T2 = ∅。

**定义 319（严格包含的退化配置）** 令 N=1、Θ 单点、D_Θ=0 且关闭 FGR（κ=∞），则 TCC 的 (b)(c)(d) 恒真，MIRROR 的交互决策逐条退化为 R69 的 MCG（仅剩 ECE 门）；再令 ECE 检查关闭，则逐指令退化为 R68。因此 FLUID、R68 都是 MIRROR 的边界构型。

**定义 320（离线歧义课程与共训）** 离线构造歧义课程 a† ~ Curriculum：模式数、间距 Δ_min、答者诚实度 δ_p、跨模态相关 ρ 逐级变化；用于训练 (i) 模态 / regime 编码器 φ，(ii) 廉价 mode_head，(iii) VoI_LCB 的 α 分位。固守 R69 定义 293-i：课程只改离线权重，运行时零学习写。

**定义 321（分布漂移与再识别）** 长时程用滑动窗 regime 后验的 Wasserstein 漂移作为再识别触发；漂移 > τ_drift 时冻结交互并重估 π（只重推后验、不更新权重），防止「孪生标定随时间失效却仍被复用」。

**定义 322（仿真投毒威胁 ℰ_twin）** 孪生银行可能在构建阶段被污染（错误 ground truth、被操纵的答者模型、被删掉的失败模式），导致「错误的银行内」结论。并入 AIC：ℰ_MIRROR = ℰ_FLUID × ℰ_twin × ℰ_gap；要求孪生来源可审计（数据血缘哈希）与银行交叉验证（不同来源孪生互证）。

**定义 323（参与式审计 VQAuditor-M）** 新增审计项：某次追问依据的孪生 / 证书是否可追溯；是否把仿真当唯一证据；是否在 D_Θ 低时「假装通过」gap 检验；regime 漂移是否被忽略。结论回灌 AuditBuf，成为下一轮孪生采样与预算的先验。

```python
# IP-264 TTB：离线构建域随机化孪生银行 + 带 ground-truth 的标定集
def build_twin_bank(N, theta_sampler, ambiguity_curriculum):
    bank = []
    for i in range(N):
        theta = theta_sampler()                      # 噪声/时延/材质/答者诚实度
        sim   = make_simulator(theta)
        data  = []                                   # (o, m_true, xi_true, g, y)
        for abstract in ambiguity_curriculum:        # 注入已知 latent mode
            o, m_true, xi_true = sim.rollout(abstract)
            for g in info_action_candidates(m_true):
                y = sim.responder.do(g, m_true)      # do(g) 反事实
                data.append((o, m_true, xi_true, g, y))
        C = calibrate_with_ground_truth(data)        # ECE / TPR / FPR / VoI^do
        I = identifiability_map(data)                # 每类歧义 × 模态对
        bank.append(Twin(theta, sim, data, C, I))
    return bank

# IP-265 SIC：跨模态联合 regime 后验 + novelty + 孪生多样性
def identify_regime(phi_o, bank, pi_prior):
    ll     = [twin.log_joint_likelihood(phi_o) for twin in bank]   # 联合，不是边缘乘积
    logZ   = logsumexp([l + log(p) for l, p in zip(ll, pi_prior)])
    post   = softmax([l + log(p) for l, p in zip(ll, pi_prior)])
    nu     = -logZ                                  # 负对数边缘似然 = novelty
    H_reg  = entropy(post)
    D_theta = min_pairwise_w2(bank)                 # 孪生多样性（检验功效）
    return post, nu, H_reg, D_theta

# IP-266 CIV：干预式 VoI 的下置信界（跨孪生）
def interventional_voi_lcb(modes, g, bank, post, alpha=0.05):
    vals = [twin.voi_do(modes, g) for twin in bank if post[twin] > TAU_REG]
    return quantile(vals, alpha) if vals else -inf  # 只信下界，防自证式追问

# IP-267 MIG：先问「这题答得出吗」
def identifiability_gate(c, bank, post):
    I = max(max_identifiability(bank[i], c) for i in top_regimes(bank, post))
    return I >= TAU_ID                              # 否则不问

# IP-268 FGR：跨模态融合缺口残差（sim-to-real 见证）
def fusion_gap(o_modalities, bank, post):
    r = reliability_weighted_fusion(o_modalities)
    z = min(abs((r - twin.mu_r) / twin.sigma_r) for twin in top_regimes(bank, post))
    return z > KAPPA, z                             # 越界 ⇒ 疑似 gap

# IP-270 PACR：幻影模态的反事实回放
def replay_mode(m, o, bank, post):
    return any(m in twin.support(o) and post[twin] >= TAU_REG for twin in bank)

# IP-274 主闭环（继承 R69，只增加「是否允许交互」的门）
def MIRROR_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    K     = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    modes = M.aud.decompose(M.fmp.sample(o, K), z)
    # 1) 我在哪个孪生世界？检验是否有功效？
    phi_o = M.fusion.encode(o)
    post, nu, H_reg, D_theta = M.sic.identify_regime(phi_o, M.bank, M.prior)
    in_bank = (nu <= TAU_NOV) and (H_reg <= TAU_REG)
    # 2) gap 见证：联合残差 + 多样性是否足以判定
    if D_theta >= TAU_DIV:
        gap_suspect, z_fuse = M.fgr.fusion_gap(o, M.bank, post)
    else:
        gap_suspect, z_fuse = False, None            # 检验无功效，显式标注不可判
    # 3) 幻影模态回放：未重现的模态不许进候选
    modes = [m for m in modes if M.pacr.replay_mode(m, o, M.bank, post)]
    # 4) 三级许可
    tier = 2 if not in_bank else (1 if (gap_suspect or D_theta < TAU_DIV) else 0)
    g = None
    if tier == 0 and M.mig.identifiability_gate(M.aud.class_of(modes), M.bank, post):
        g = M.mint.choose_interaction(
                modes, o, M.budget,
                voi=lambda gg: M.civ.interventional_voi_lcb(modes, gg, M.bank, post))
    U_ale, U_epi = M.aud.split(modes)
    if g is not None:

        U_floor = U_ale
    else:
        U_floor = U_ale + U_epi
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if tier == 1: lam = max(lam, lam_floor(U_ale + U_epi))

    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_m.submit_async(tier, post, nu, D_theta, g, mode)
    return k, lam, mode, (U_ale, U_epi, tier)
```

## 3. 推导

**引理 19（孪生条件标定迁移）** 若真实观测分布与孪生 T_i 的观测分布在总变差下满足 TV(P_real, P_i) ≤ ε，且标定泛函（ECE、VoI）对分布是 L-Lipschitz 的（似然比有界），则 |ECE_real − ECE_i| ≤ L·ε + e_est，|VoI_real − VoI_i^{do}| ≤ L'·ε。**要点**：标定只能迁移到孪生的 ε-邻域内，证书的「有效半径」由 ε 决定；银行外的观测没有任何迁移保证。这为 TCC（定义 316）的 (b)(d) 提供了理论依据，也解释了为何 T2 必须回 R68 而不是继续信任仿真。

**引理 20（可识别性下界与幻影追问的代价）** 若歧义类 c 在所有可采纳模态对上的最大可识别性 max I_{jk}(c) < τ_id，则任何信息动作 g ∈ 𝒢 执行后模态后验熵仍 ≥ H_min(c) > 0，故 max VoI ≤ H_min(c)。又，若候选模态 m 在孪生银行中不可重现（PACR 失败），则 p(m 为真 | o, 银行) 不可由仿真辨识；此时单源采纳 m 的期望损失 ≥ 直接保守（R69 引理 18 的单源下界）。**系**：MIG + PACR 把「追问一个答不出 / 不存在的模态」的期望损失压到不劣于不问，正是 R69 最大风险的正面回应。

**引理 21（共同盲区不可检性）** 存在真实世界 W 与孪生 T_i，使得所有银行可观测的跨模态统计 φ 在两者下的分布完全相同（KL = 0），但模态语义与交互后果不同。于是任何仅依赖 φ 的检测器功效为 0。**系 1**：覆盖性只能相对银行成立，不能被银行自身证明；孪生多样性 D_Θ 是「检验有功效」的**必要非充分**条件。**系 2**：落在 D_Θ 零空间里的新故障不可检，必须依赖银行外的独立探针 / 人类审计来兜底——这是本轮诚实性的核心，也是最大风险的来源。

**定理 18（MIRROR 对 FLUID / R68 的安全单调包含）** 在 A99–A102 下，任意状态 s 的期望风险满足 R_MIRROR(s) ≤ R_FLUID(s)（威胁模型 ℰ_MIRROR ⊇ ℰ_FLUID，含幻影模态与 gap）；当银行有效（TCC 成立、D_Θ ≥ τ_div、观测在包络内）时 MIRROR 与 FLUID **逐指令相同**（无效率损失）；当取退化配置（定义 319）时逐指令退化为 FLUID，再关闭 ECE 门则退化为 R68。**机理**：仿真只**门控**交互许可，从不放松 C-RAS-WM 安全包络；三级退避使 λ 单调不降。

**定理 19（干预式 VoI 的保守性）** 当答者答案与真实模态之间存在混杂（社会压力、提问暗示、共谋欺骗），观测式 VoI 会高估信息增益；干预式 VoI 的下置信界满足 VoI_LCB ≤ VoI_obs。于是用 LCB 决策永不高估一次追问的价值，差值 (VoI_obs − VoI_LCB) 可作为**混杂指数**供 VQAuditor-M 审计——这正是 R69「单次交互不得单独定案」在估计层面的对应物。

## 6. 本轮最大风险

**一句话**：MIRROR 的全部可信性押在「真实故障落在孪生银行的覆盖内」这一**无法从内部验证**的前提上——一旦某个失败模式同时缺席于所有孪生，跨模态残差仍会自洽地落进某个孪生包络，系统会以最高置信说「我识别到了这个世界」并**停止追问**：**镜子裂了，却照不出裂缝；最危险的不是它看不见，而是它确信自己看见了。**

**次级风险与缓解**：
1. **孪生多样性不足导致 gap 检验无功效** → 显式 D_Θ 门（定义 315），低于阈值一律标注「不可判」并降级 T1；
2. **孪生银行投毒 / 偏置** → ℰ_twin 威胁模型 + 数据血缘哈希 + 跨来源孪生互证（定义 322）；
3. **regime 后验过拟合到 φ** → 长时程漂移监控与再识别（定义 321）+ E312；
4. **PACR 误拒真实新模态** → 只拒「单源定案」，未重现模态仍可作为弱证据；辅以 E310 误拒率门；
5. **仿真当唯一证据** → 不变式定义 310-iii + VQAuditor-M 强制审计（定义 323）。

## 2. 形式化定义（要点版）

**定义 310（总览与三不变式）** 零学习写操作继承；**交互许可单调性**（𝒢_MIRROR ⊆ 𝒢_FLUID，安全包络与认证完全继承）；**仿真不作真值**（仿真量只作一个证据源，不得单独认证追问）。

**定义 311–312（TTB 与 SIC）** 孪生 `T_i` 在已知歧义注入下产出带 ground-truth 校准集；用**跨模态联合** `p(φ(o)|T_i)` 得 `π_i`、`ν=−logZ`、`H_reg`；`ν≤τ_nov ∧ H_reg≤τ_reg` 为「银行内」。

**定义 313–314（CIV 与 MIG）** `VoI_i^{do}(g)=H(M|o)−E_{y~P_i(y|do(g),o)}[H(M|o,y)]`，决策用 `VoI_LCB`；`I_{jk}(c)=min_{m≠m'} KL(p(φ_{jk}|m,c)‖p(φ_{jk}|m',c))`，`I≥τ_id` 才允许把该类歧义列入查询候选。

**定义 315–316（FGR 与 TCC）** `z_fuse` 越出所有高后验孪生包络 ⇒ gap 嫌疑；`D_Θ<τ_div` ⇒ 检验无功效、标注「不可判」。TCC 五条件（ECE / 银行内 / 多样性 / 缺口 / 证据纪律）全满足才授予 T0。

**定义 317–318（PACR 与 TFB）** 模态必须在高后验孪生中可重现，否则不作为可定案证据；三级退避 `λ_T0 ≤ λ_T1 ≤ λ_T2`，且 `𝒢_T0 ⊆ 𝒢_FLUID`、`𝒢_T1=𝒢_T2=∅`。

**定义 319–320（退化配置与课程）** `N=1、D_Θ=0、κ=∞` 时逐条退化为 R69 MCG；再关 ECE 门退化为 R68。离线歧义课程共训，运行时零学习写。

**定义 321–323（漂移 / 投毒 / 审计）** 滑窗 regime 漂移触发再识别并冻结交互；`ℰ_MIRROR=ℰ_FLUID×ℰ_twin×ℰ_gap`；VQAuditor-M 审计仿真依据可追溯、多样性伪通过、漂移忽略。

```python
# IP-264 TTB：域随机化孪生银行 + 带 ground-truth 标定集
def build_twin_bank(N, theta_sampler, ambiguity_curriculum):
    bank = []
    for i in range(N):
        sim  = make_simulator(theta_sampler())       # 噪声/时延/材质/诚实度
        data = []
        for abstract in ambiguity_curriculum:        # 注入已知 latent mode m†
            o, m_true, xi_true = sim.rollout(abstract)
            for g in info_action_candidates(m_true):
                y = sim.responder.do(g, m_true)      # do(g) 反事实
                data.append((o, m_true, xi_true, g, y))
        bank.append(Twin(sim, data,
                         calibrate_with_ground_truth(data),   # ECE/TPR/FPR/VoI^do
                         identifiability_map(data)))          # 歧义类×模态对
    return bank

# IP-265 SIC：跨模态联合 regime 后验 + novelty + 多样性
def identify_regime(phi_o, bank, pi_prior):
    ll   = [t.log_joint_likelihood(phi_o) for t in bank]      # 联合，非边缘乘积
    logZ = logsumexp([l + log(p) for l, p in zip(ll, pi_prior)])
    post = softmax([l + log(p) for l, p in zip(ll, pi_prior)])
    return post, -logZ, entropy(post), min_pairwise_w2(bank)

# IP-266 CIV：干预式 VoI 下置信界
def interventional_voi_lcb(modes, g, bank, post, alpha=0.05):
    vals = [t.voi_do(modes, g) for t in bank if post[t] > TAU_REG]
    return quantile(vals, alpha) if vals else -inf

# IP-267 MIG：先问「这题答得出吗」
def identifiability_gate(c, bank, post):
    return max(max_identifiability(bank[i], c)
               for i in top_regimes(bank, post)) >= TAU_ID

# IP-268 FGR：跨模态联合缺口残差
def fusion_gap(o, bank, post):
    r = reliability_weighted_fusion(o)
    z = min(abs((r - t.mu_r) / t.sigma_r) for t in top_regimes(bank, post))
    return z > KAPPA, z

# IP-270 PACR：幻影模态反事实回放
def replay_mode(m, o, bank, post):
    return any(m in t.support(o) and post[t] >= TAU_REG for t in bank)

# IP-274 主闭环（继承 R69，只加「是否允许交互」的门）
def MIRROR_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    K     = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    modes = M.aud.decompose(M.fmp.sample(o, K), z)
    phi_o = M.fusion.encode(o)
    post, nu, H_reg, D_theta = M.sic.identify_regime(phi_o, M.bank, M.prior)
    in_bank = (nu <= TAU_NOV) and (H_reg <= TAU_REG)
    gap, z_fuse = (M.fgr.fusion_gap(o, M.bank, post) if D_theta >= TAU_DIV
                   else (False, None))                    # 无功效时禁止伪通过
    modes = [m for m in modes if M.pacr.replay_mode(m, o, M.bank, post)]
    tier  = 2 if not in_bank else (1 if (gap or D_theta < TAU_DIV) else 0)
    g = None
    if tier == 0 and M.mig.identifiability_gate(M.aud.class_of(modes), M.bank, post):
        g = M.mint.choose_interaction(
                modes, o, M.budget,
                voi=lambda gg: M.civ.interventional_voi_lcb(modes, gg, M.bank, post))
    U_ale, U_epi = M.aud.split(modes)
    if g is not None:
        U_epi = M.cia.update_belief(modes, M.cia.execute(g)); U_floor = U_ale
    else:
        U_floor = U_ale + U_epi
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if tier == 1: lam = max(lam, lam_floor(U_ale + U_epi))
    if tier == 2: lam = max(lam, LAM_R68); k = min(k, k_cal_shrink(x_prime, U_cal))
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_m.submit_async(tier, post, nu, D_theta, g, mode)
    return k, lam, mode, (U_ale, U_epi, tier)
```

## 4. 推导

**引理 19（孪生条件标定迁移）** 若 `TV(P_real, P_i) ≤ ε` 且标定泛函对分布 L-Lipschitz（似然比有界），则 `|ECE_real−ECE_i| ≤ Lε+e_est`、`|VoI_real−VoI_i^{do}| ≤ L'ε`。标定只在孪生的 ε-邻域内可迁移；银行外无保证，故 T2 必须回 R68。

**引理 20（可识别性下界与幻影代价）** 若 `max I_{jk}(c) < τ_id`，任意 `g∈𝒢` 执行后模态熵仍 `≥ H_min(c)`，故 `max VoI ≤ H_min(c)`；若模态 m 在银行中不可重现，则单源采纳 m 的期望损失 ≥ 直接保守。系：MIG+PACR 把「追问答不出/不存在的模态」的损失压到不劣于不问。

**引理 21（共同盲区不可检性）** 存在真实 W 与孪生 T_i 使所有银行可观测跨模态统计 φ 的分布相同（KL=0）但语义不同；任何仅依赖 φ 的检测器功效为 0。系 1：覆盖只能相对银行成立，`D_Θ` 是检验有功效的**必要非充分**条件；系 2：D_Θ 零空间内的新故障不可检，须由银行外独立探针/人类审计兜底。

**定理 18（MIRROR 对 FLUID/R68 的安全单调包含）** 在 A99–A102 下 `R_MIRROR(s) ≤ R_FLUID(s)`（含幻影/gap 的 ℰ_MIRROR）；银行有效时与 FLUID **逐指令相同**（零效率损失）；退化配置（定义 319）逐指令退化为 FLUID，再关 ECE 门退化为 R68。仿真只门控、不放松安全包络，三级退避使 λ 单调不降。

**定理 19（干预式 VoI 的保守性）** 答者答案与真实模态存在混杂时，观测式 VoI 高估信息增益，`VoI_LCB ≤ VoI_obs`；LCB 决策永不高估一次追问的价值，差值 `VoI_obs−VoI_LCB` 作为**混杂指数**供 VQAuditor-M 审计。

## 7. 本轮最大风险

**一句话**：MIRROR 的全部可信性押在「真实故障落在孪生银行的覆盖内」这一**无法从内部验证**的前提上——一旦某个失败模式同时缺席于所有孪生，跨模态残差仍会自洽地落进某个孪生包络，系统会以最高置信说「我识别到了这个世界」并**停止追问**：**镜子裂了，却照不出裂缝；最危险的不是它看不见，而是它确信自己看见了。**

**次级风险与缓解**：多样性不足致 gap 检验无功效（D_Θ 门 + 显式「不可判」并降 T1）；孪生投毒/偏置（ℰ_twin + 血缘哈希 + 跨来源互证）；regime 后验过拟合 φ（漂移监控 + E312）；PACR 误拒真实新模态（只拒单源定案，未重现模态仍可作弱证据 + E310）；把仿真当唯一证据（定义 310-iii + VQAuditor-M）。
