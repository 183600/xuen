# 第 43 轮（新循环第 3 轮） · 证明携带的意图与合规（PCIC）：把「意图识别」升格为证书入口、把「伦理与合规」编译为可审计证据链（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR 的 Sim-Cert-RAG 飞轮）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉」导致证书静默失效。本轮灵感词「意图识别」「伦理与合规」击中了一个更靠上游、也更靠下游的双重盲区：**整条证书栈默认任务意图 φ 是「已给且正确」的**——它证明「若 φ 正确，则轨迹安全」，却从不证明「我们确实理解了 φ」，也从不证明「执行 φ 在伦理与法规上被允许」。前者是证明链的**语义入口**，后者是证明链的**规范出口**。一个在错误意图下被证明安全的轨迹，恰恰是最危险的轨迹；一个技术上无碰撞、却违反人类监督义务或知情同意的行为，是「合法却失德 / 合德却违法」。本轮**增量插入** IP-57/58/59，把 v19 的「可仿真、可检索、可边缘化」升级为「**可理解、可问责、可审计**」，形成意图→安全→合规的端到端证明链 PCIC。

## 0. 直觉与动机

**灵感 1（意图识别 → 意图不是标签，而是「带覆盖保证的集合」）**：传统意图识别输出 argmax 标签，再用 softmax 置信度当挡箭牌；但 softmax 不校准，分布偏移下会「自信地错」。证书语言要的是**单边保证**，因此直觉是把意图识别改造成**共形预测器**：输出一个意图集合 C_α(o)，满足 P(ι_true ∈ C_α(o)) ≥ 1−α 的边际覆盖保证，且集合大小自适应（清晰输入→单元素集，歧义输入→多元素集）。集合本身就是「该不该问」的信号：集合为单元素且落在**可容许意图集** A(o) 内 → 可自动执行；集合含多个可容许意图 → 必须**澄清**；集合含不可容许/危险意图且质量不可忽略 → **HOLD/最小风险**。意图还会随时间漂移（人改主意、证据更新），于是再建一个与 CAR 同构的**意图转移自动机 ITA**，把「意图改变」也变成可观测、可证书化的事件。

**灵感 2（伦理与合规 → 从「人工翻文档」到「义务编译 + 证据账本」）**：伦理原则与法规条款（EU AI Act Art.9 风险管理 / Art.12 日志 / Art.13 透明 / Art.14 人类监督、ISO 10218、ISO/TS 15066 协作安全、GDPR 数据最小化）本质是自然语言规范。直觉是像编译器一样处理它们：把每条条款**编译**为一条**证据义务** e(r) =（谓词 π_r，见证 w_r，时限），谓词作用于证书对象与运行日志。证书每颁一次，就自动抽取一批见证（实验号、哈希、统计量、审计人），写入 append-only 的**合规账本**。于是「合规审计」从数天的人工阅读变成账本上的**证明检查**——这也是「证明携带代码」思想在治理层的移植：证书不只携带自己的正确性证明，还携带「它为何合法」的见证。伦理硬约束（如「不得在未获澄清时执行不可逆动作」）用道义/时序逻辑表达并模型检查；软约束（效用、公平、隐私）做 Pareto 权衡并输出解释。

**灵感 3（耦合 → 监督是控制律，不是开关）**：人类监督（human-in-the-loop）常在论文里被写成「有人在环里」，实质却是**橡皮图章**（automation bias）。直觉是把监督建成一个**决策论控制律**：给定意图后验、风险、合规义务完成度，在 AUTO / ASK / HOLD 三态间选择，最小化期望成本 = 误执行成本·P(误解) + 打扰成本·P(ASK) + 延迟成本。由此可得**可证明的监督触发界**：当 P(危险意图 | o) 超过 c_ask / c_fail 时必然询问。监督因此不是兜底，而是与证书并联、有理论保证的一等公民。

**耦合升级**：意图证书是安全证书的**前置门控**（意图不成立则不进入 CAR，直接 ASK/HOLD）；合规账本是安全与意图证书的**出口见证**；而合规义务反过来**约束意图识别策略**（禁止基于敏感属性推断意图=反歧视、数据最小化=隐私、必须保留人类否决权=监督）。三者形成 **proof-carrying intent & compliance（PCIC）**：一份可发布的机器人行为，必须同时携带「我理解对了」「我做得安全」「我这样做合法合德」三张证明。

## 1. 形式化定义（增量：定义 38–43）

**定义 38（意图后验、可容许意图集与意图证书）**：观察 o（语言/手势/轨迹/场景/历史）。意图空间 I = I_allow ⊔ I_unsafe ⊔ I_unknown 按合规与安全预分割。识别器输出后验 p(ι|o) 与共形集合 C_α(o)。**可容许意图集** A(o) ⊆ I_allow 由能力约束、伦理硬约束、法规适用域共同决定。**意图证书** IC(o) 成立当且仅当三条同时满足：(i) **覆盖**：P(ι_true ∈ C_α(o)) ≥ 1−α；(ii) **质量/间隔**：Σ_{ι∈A∩C_α} p(ι|o) ≥ 1−δ_int，且 max_{ι∈A∩C_α} p − max_{ι∈I_unsafe∩C_α} p ≥ κ_int；(iii) **校准**：后验 ECE ≤ δ_cal。任一条不满足 → 禁止直接执行，必须 ASK 或 HOLD。

**定义 39（意图转移自动机 ITA 与意图漂移）**：ITA = (S_int, E_int, →_int, s_0, F_int)，与 CAR 同构：状态=意图假设集，边=证据更新事件，守卫=后验阈值。**意图漂移统计量** D_t = JS(p_{t−τ} ‖ p_t)（对称 KL 的平方根）。若 D_t > τ_intent，触发**重协商**（re-negotiate）：旧意图证书作废、重跑 IC，而非沿用旧证书。设迟滞带 [τ_low, τ_high] 防止抖动。

**定义 40（合规义务编译与证据映射）**：法规/伦理规范库 R = {r_1,…,r_n}。**合规编译器** CC(r) = e(r) = (π_r, w_r, deadline_r)，π_r 是作用于证书字段与运行日志的谓词，w_r 是见证提取函数，deadline_r 是证据时效。证书 C 对 r **合规**当且仅当 ∃w = w_r(C, logs)：π_r(C, w) = 真。全部义务 E_app = {e(r) : r 适用于 (φ, ψ, 部署域)}。**证据账本** L 是 append-only、哈希链式日志：L ← L ‖ (hash(w), r, timestamp, cert_hash)。审计 Aud(L, R) = 逐条做证明检查，输出未满足义务集 U。

**定义 41（伦理约束的形式化）**：伦理约束 G = G_hard ∪ G_soft。G_hard 用时序/道义逻辑表达，例如：
- G1（澄清优先）：□(不可逆动作(a) → ◇(已澄清 ∨ 明确授权) U a)；
- G2（人类否决）：□(监督者否决 → ◇(停止 ∧ 说明理由))；
- G3（不伤害）：□(P(危害 | o, a) > ρ → ¬a)。
**伦理可行性证书**：存在计划 π 使 π ⊨ G_hard（模型检查通过），且软约束加权和 ≥ η_soft 或给出非支配解释。G_soft 包括效用、公平差距（不同人群误执行率差 ≤ ε_fair）、隐私（推断所用信息 ⊆ 最小数据集）。

**定义 42（监督控制律）**：在 AUTO/ASK/HOLD 三态上最小化期望成本：
Cost(ASK|o) = c_ask + c_delay·E[Δt]；Cost(AUTO|o) = Σ_{ι∈I_unsafe} p(ι|o)·c_fail(ι) + c_reg·1[义务未满足]；Cost(HOLD|o) = c_hold + c_avail_loss。
**监督触发界**（命题）：若 c_fail > c_ask + c_delay·E[Δt]，则当 P(危险意图|o) > (c_ask + c_delay·E[Δt])/c_fail 时，ASK 严格优于 AUTO。HOLD 在 U ≠ ∅（合规证据缺失）时强制生效。

**定义 43（证明携带的意图-合规合约 PCIC）**：一次可发布行为 = 四元组 Π = (IC, C_safety, E_compliance, π_explain)，分别是意图证书、安全证书（CAR/LCS/CMC 链）、合规证据集、反事实解释。**运行规则**：仅当 IC 成立 ∧ C_safety 有效 ∧ U = ∅ 时进入 AUTO；IC 质量不足 → ASK；C_safety 失效或 U ≠ ∅ → HOLD + 降级。**定理（意图-合规闭环）**：若 (a) 共形覆盖成立、(b) 意图后验 δ_cal 校准、(c) C_safety sound、(d) 每条适用义务有见证、(e) 监督律满足触发界，则以概率 ≥ 1−α−δ_int−δ_cal，系统在任意运行点的「伦理-合法可执行性」成立。证明思路：由 (a)(b) 得意图集合正确且概率可控，由 (c) 得给定意图下轨迹安全，由 (d) 得规范出口闭合，由 (e)+G_hard 排除「该问而未问」的路径，并对三条失效事件做 union bound。

## 2. 产出设计（增量 IP-57/58/59 + 升级 IP-51/55/56/50/45/47/49/53）

### 2.1 IP-57 INTENT-CERT-RECOGNIZER（ICR，意图证书识别器）
1. **多模态意图融合**：语言（VLM 指令解析）+ 手势/视线 + 历史交互 + 场景可供性，输出意图后验 p(ι|o)。
2. **共形意图集**：用 split-conformal / 自适应 conformal，按风险分层给不同 α（不可逆动作 α 更小），输出 C_α(o) 与集合大小。
3. **可容许性判定**：A(o) 由能力、伦理硬约束 G_hard、法规适用域求交；产生「可执行 / 需澄清 / 禁止」三态。
4. **意图转移自动机 + 漂移监控**：JS 散度 + 迟滞带；漂移即重协商。
5. **对抗歧义压力测试接口**：向 IP-54 SCV 暴露「歧义输入生成器」，与仿真风洞共用。

### 2.2 IP-58 COMPLIANCE-COMPILER（CCL，合规编译器与证据账本）
1. **法规 DSL**：条款 → 证据义务 (π_r, w_r, deadline_r)；内置 EU AI Act 高风险条款、ISO 10218、ISO/TS 15066、GDPR 模板。
2. **见证抽取器**：从证书对象、实验报告（E 系列）、总线日志、审计签名自动抽取见证；缺失即报 U。
3. **哈希链账本**：append-only，块含 (r, hash(w), cert_hash, sim_config_hash, git_commit, 硬件版本)，支持重放与回滚。
4. **差距分析（gap analysis）**：给定部署域自动列出未覆盖条款与建议补充实验（回灌到 IP-54 / 课程引擎）。
5. **合规语义审计门**：形式谓词无法覆盖的「实质义务」强制人工法务对照，防「合规剧场」。

### 2.3 IP-59 ETHICS-GUARD & HUMAN-OVERSIGHT（EGHO，伦理守卫与监督控制）
1. **硬约束模型检查**：把 G_hard 编译为时序逻辑，对计划/乘积自动机做模型检查（复用 IP-47 组合代数）。
2. **软约束权衡与解释**：多目标（效用/公平/隐私）Pareto 前沿；为选中动作生成反事实解释（「若意图为 ι′ 则会 X」）与充分性评分。
3. **监督控制律**：AUTO/ASK/HOLD 三态，按定义 42 的期望成本决策；ASK 时给出最小澄清问句（信息增益最大）。
4. **人类否决与接管协议**：否决即写入账本、触发 ITA 转移、必要时 HOLD 并降级。
5. **反歧视/隐私闸门**：意图推断所用特征 ⊆ 最小数据集；对敏感代理变量做检测与剔除。

## 5. 本轮最大风险

**一句话**：意图证书把「语义正确性」纳入证明链，却同时引入**分布偏移下共形/校准失效**与**合规形式化鸿沟（合规剧场）**两条新失效链——机器人可能以「证据完备、账本漂亮」的姿态，执行一个被误读、且伦理上有争议的意图，而形式化账本反而让这种错误更难被人发现；因此 E87（校准覆盖）与 E90（实质义务的人工法务对照）必须作为**红线实验**，任一不达标即禁止进入 AUTO 并全链路回退到 ASK/HOLD。

### IP-57 ICR：共形意图集与意图证书
```
def intent_certificate(o, calibrator, A_fn, alpha=0.05, delta_int=0.02, kappa=0.2):
    p = multimodal_intent_posterior(o)          # 语言+手势+场景+历史
    C = calibrator.conformal_set(p, alpha)      # 自适应共形；覆盖 >= 1-alpha
    A = A_fn(o)                                 # 能力 ∩ G_hard ∩ 法规适用域
    mass_allow = sum(p[i] for i in C if i in A)
    mass_unsafe = max([p[i] for i in C if i in I_UNSAFE] + [0.0])
    gap = max([p[i] for i in C if i in A] + [0.0]) - mass_unsafe
    ok = (calibrator.covered()) and mass_allow >= 1-delta_int and gap >= kappa
    return IntentCert(p=p, C=C, A=A, ok=ok,
                      ece=calibrator.ece(), mass_allow=mass_allow, gap=gap)

def ita_step(state, o):
    # 意图转移自动机：证据更新 + 漂移监控 + 迟滞重协商
    p_new = multimodal_intent_posterior(o)
    D = js_divergence(state.p, p_new)
    if D > TAU_HIGH:
        state.p = p_new; state.epoch += 1
        return 'RENEGOTIATE', intent_certificate(o, calib, A_fn)
    if D > TAU_LOW:
        state.p = p_new; state.streak += 1
    else:
        state.streak = 0
    return 'CONTINUE', state
```

### IP-58 CCL：义务编译、见证抽取与账本

def compile_obligations(R_app, cert, logs):
    obligations, unmet = [], []
    for r in R_app:
        e = R_DB[r]                              # (pi_r, w_r, deadline_r) DSL
        w = e.extract_witness(cert, logs)        # 证书字段/实验号/日志/签名
        if w is None or not e.pi(cert, w):
            unmet.append((r, e.missing_reason(cert, logs)))
        else:
            obligations.append((r, w))
    return obligations, unmet

def ledger_append(ledger, obligations, cert):
    for r, w in obligations:
        block = {
            'clause': r,
            'witness_hash': H(w),
            'cert_hash': H(cert),
            'sim_config_hash': cert.sim_config_hash,
            'git_commit': cert.git_commit,
            'hw_version': cert.hw_version,
            'ts': now()
        }
        block['prev'] = ledger.tail_hash if ledger else GENESIS
        block['hash'] = H(block)
        ledger.append(block)
    return ledger

def audit(ledger, R_app):

### IP-59 EGHO：伦理守卫、解释与监督控制律
```
def ethics_feasible(plan, G_hard, ctx):
    # 时序/道义逻辑模型检查（复用 IP-47 乘积自动机）
    return model_check(compile_temporal(G_hard), plan, ctx)   # 0 违例才 True

def choose_supervision(IC, C_safety, unmet, costs):
    # 定义 42：期望成本最小化
    if not C_safety.valid or len(unmet) > 0:
        return 'HOLD'                             # 合规/安全失效强制 HOLD
    if not IC.ok:
        return 'ASK'                              # 意图证书不成立 → 澄清
    p_danger = sum(IC.p[i] for i in IC.C if i in I_UNSAFE)
    c_ask = costs.c_ask + costs.c_delay * costs.expected_dt
    if p_danger > c_ask / costs.c_fail:
        return 'ASK'                              # 触发界：必问
    return 'AUTO'

def suggest_clarification(IC, candidates, o):
    # 选信息增益最大的最小澄清问句
    best, best_gain = None, -1
    for q in clarification_questions(candidates):
        gain = expected_entropy_reduction(IC.p, q, o)
        if gain > best_gain: best, best_gain = q, gain
    return best

def counterfactual_explain(plan, I, IC, k=2):
    # 反事实：若意图为另一高概率候选，机器人会怎么做
    alts = sorted([i for i in IC.C if i in I_ALLOW], key=lambda i: -IC.p[i])[:k]
    return [{'if_intent': i, 'would_do': replan(plan, i)} for i in alts]
```

## 6. 本轮最大风险

**一句话**：意图证书把「语义正确性」纳入证明链，却同时引入**分布偏移下共形/校准失效**与**合规形式化鸿沟（合规剧场）**两条新失效链——机器人可能以「证据完备、账本漂亮」的姿态，执行一个被误读、且伦理上有争议的意图，而形式化账本反而让这种错误更难被人发现；因此 E87（校准覆盖）与 E90（实质义务的人工法务对照）必须作为**红线实验**，任一不达标即禁止进入 AUTO 并全链路回退到 ASK/HOLD。
