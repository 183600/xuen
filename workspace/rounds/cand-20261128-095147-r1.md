### 第 6 轮灵感驱动研究记录（新循环首轮，承接 CADVS-v5）

**灵感词**：多机评测、抗干扰

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把提议器升级为条件流匹配（FMPP）、记忆升级为嵌入+固化（LMEM-v2）、人因升级为情感调制（FAMK），并用「定理 6 证书不变性」把框架推广为「任意生成器 + 认证边界」，执行集 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。v5 的三条遗留边界在本轮成为主问题：(a) 全部证书是**单机/单站**的，n 个各自认证的机器人放在同一工作空间里并不等价于联合安全——个体证书不可组合；(b) v5 只对**有界扰动**做了假设，没有显式的干扰信道模型，通信时延/丢包/传感器欺骗会让「此刻有效的证书」在下一刻失效；(c) v5 的联邦评测用 FedAvg + 平均指标，对拜占庭站点与选择性上报（挑场景/挑指标）没有结构性防御。本轮把两个灵感词统一为「认证的舰队级抗干扰执行」（Certified Fleet-level Interference-Robust Execution, CFIRE），形成 CADVS-v6（IP-497~500）。本轮自律：**硬门数量仍为七**，不新增门，而是把七门从单机**提升（lifting）**到联合空间，并叠加干扰鲁棒化；执行集关系改为「单机精确退化 + 一般投影嵌套」：n=1 且 I=∅ ⇒ Exec_v6 = Exec_v5，一般情形 π_r(Exec_v6) ⊆ Exec_v5^r。

**直觉与动机**：

1. **多机 ≠ 单机证书之和：从「逐机认证」到「门提升 + 耦合项」**。直觉上，每个机器人都拿到 v5 证书，只说明「单独看每个都安全」，不能说明「一起动起来安全」：两条各自无碰撞的轨迹可以相交，两个各自无死锁的策略可以互相等待成环，两个各自 ZMP 稳定的机器人共抬重物时合力可以失衡。严谨地说，v5 的 Exec 是单机轨迹空间的子集，而舰队安全是**联合轨迹空间**上的谓词；联合谓词不能由各坐标谓词的合取推出（存在耦合项）。因此本轮不新增第八门，而是做**门提升**：对第 i 门定义 kc_i^F(X) = ∧_r kc_i^r(x^r) ∧ κ_i^coup(X)，其中 κ_i^coup 是该门语义下的跨机耦合谓词（物理门管扫掠体互穿/互力锥，平衡门管共抬 ZMP，记忆门管共享资源认领一致性，价值门管舰队福利与负外部性）。七门原样保留，只是定义域从 x 升到 X。好处是继承 v5 全部定理，并给出精确退化：n=1 且 I=∅ 时耦合项为空，Exec_v6 = Exec_v5。

2. **抗干扰不是「加个噪声项」，而是「对干扰集做最坏情况量化 + 证书租约」**。直觉上，干扰有两种伤害：**值伤害**（传感器欺骗让测量偏了，名义安全的轨迹其实不安全）与**时序伤害**（通信延迟让证书过期，机器人拿着旧证书执行新状态）。严谨地说，引入干扰集 I = I_comm × I_sens × I_phys × I_adv 与预算 B；把每门改成鲁棒门 kc_i^{F,I}(X) = ∧_{δ∈I} kc_i^F(X,δ)。连续最坏情况不可直接算，于是用 Lipschitz 裕度给出**可靠内近似**：若分数 s_i 对干扰的 Lipschitz 常数为 L_i，则 s_i(X) − L_i·rad(I) ≥ τ_i 是鲁棒通过的充分条件，定义鲁棒裕度 ρ_i = s_i − L_i·rad(I) − τ_i ≥ 0。时序上用**证书租约** ℓ = min(ℓ_max, min_i ρ_i / L_t)（L_t 为裕度衰减率）：只在年龄 ≤ ℓ 内消费证书，通信延迟 d 与计算延迟 τ_c 之和超过 ℓ 时 fail-closed 安全停。关键性质：I 越大 ⇒ 鲁棒执行集越小（单调收缩），I=∅ 时精确退化为 v5。

3. **多机评测要防的不是「算错」，而是「可被博弈」**。直觉上，跨站/跨机评测若允许各站自报场景与指标、允许挑最好的一轮上报，平均分会被系统性高估；一个拜占庭站点还能伪造「我通过了」的证书。严谨地说，评测协议必须满足三条：**封存与轮换**（测试场景集 commit-reveal，评测前不可见，防挑场景）、**签名证据链**（每条结果绑定 kc_evidence_forged_v4 的签名证书，跨站不可伪造，防冒名）、**拜占庭鲁棒聚合**（逐坐标中位数/截尾均值，f < n/3 时误差有界，防单点污染）。同时报告**最差分层**而非只报均值，避免辛普森悖论式掩盖。

**关键洞见**：v5 回答「单机、任意提议、有界扰动下证书边界是否保持」；v6 回答「当证书必须**组合**、干扰必须**显式建模**、评测必须**抗博弈**时，如何让边界在舰队层仍然成立」。七硬门 kc_i 原样保留并被提升为 kc_i^F；本轮新增的只有：耦合谓词 κ_i^coup、干扰集 I 与鲁棒裕度 ρ_i、证书租约 ℓ、以及签名证据/拜占庭聚合的评测层。执行集关系为「精确退化 + 投影嵌套 + 鲁棒单调」，不追求字面上的全局集合包含（联合空间维度不同），而是给出可检验的投影包含与单机退化两个锚点。

**形式化目标（增量）**：
1. 舰队状态 X=(x^1,…,x^n)，联合提议 π_F = ⊗_r π_r（流匹配或规则均可，定理 6 仍适用）。
2. 门提升：kc_i^F(X,δ)=∧_r kc_i^r(x^r+δ_sens^r;τ_i^5) ∧ κ_i^coup(X,δ)，i=1..7。
3. 干扰集与预算：I = Box(d_max,p_max,ε_p,ε_w,w_max) × 拜占庭上界 f；鲁棒门 kc_i^{F,I}(X)=∧_{δ∈I} kc_i^F(X,δ)。
4. 鲁棒裕度 ρ_i(X)=s_i(X)−L_i·rad(I)−τ_i^5；内近似执行集 Exec_v6^inner={X:∧_i ρ_i≥0} ⊆ Exec_v6。
5. 证书租约 ℓ=min(ℓ_max, min_i ρ_i/L_t)；消费条件 age+τ_c ≤ ℓ，否则 fail-closed 安全停。
6. 定理 9（门提升组合与精确退化）、定理 10（抗干扰鲁棒单调）、定理 11（租约时序安全）、定理 12（多机评测拜占庭鲁棒与不可博弈）。
7. 执行集：n=1,I=∅ ⇒ Exec_v6=Exec_v5；一般 ⇒ π_r(Exec_v6)⊆Exec_v5^r，且 I1⊆I2 ⇒ Exec_v6^{I2}⊆Exec_v6^{I1}。

**本轮最大风险**：**干扰集 I 是整个鲁棒证书的新信任根**——若 I 漏掉相关干扰（通信时延与传感器欺骗相关、跨机接触的隐式耦合、攻击者协同），鲁棒证书会在「模型以为安全」时静默失效，而 fail-closed 只能防已知干扰、无法感知模型本身的错误；v6 把 v5 的「自指博弈」风险换成了「模型设定错误」风险。

### IP-497 FGLK：舰队门提升核（准入/10–50 Hz，不在 1 kHz 环）

```python
@dataclass
class FleetGateLiftingKernel:
    """FGLK：七门从单机提升到联合空间。
    红线：不新增第八门；耦合项只做合取（fail-closed），永不放松单机门"""
    n: int
    bvh: Any                          # 扫掠体层次包围盒，O(n log n + k)
    coupling: dict = field(default_factory=dict)   # i -> κ_i^coup；缺省 True（n=1 时为空）

    def lift(self, X, delta, tau5, per_robot_gates) -> dict:
        # 1) 逐机门：复用 v5，注入 δ_sens 后评估（鲁棒化在外层 IRCK 做）
        per = {i: all(per_robot_gates[i](X[r] + delta.sens[r], tau5[i])
                      for r in range(self.n))
               for i in GATES}
        # 2) 耦合项：只做合取；n=1 时 coupling 为空 → 精确退化 v5
        for i in GATES:
            per[i] = per[i] and self.coupling.get(i, _always_true)(X, delta)
        return per

    # 各门耦合谓词（示意）
    def kappa_phys(self, X, d):        # 扫掠体互不穿透 + 互力锥可行
        return (not self.bvh.any_overlap(X)) and mutual_wrench_cone_feasible(X, d)
    def kappa_bal(self, X, d):         # 共抬时共享 ZMP 支撑多边形
        return shared_zmp_feasible(X, d)
    def kappa_mem(self, X, d):         # 共享对象/区域无双重认领（租约唯一）
        return shared_resource_leases_consistent(X)
    def kappa_val(self, X, d):         # 舰队福利不劣化 + 无负外部性
        return fleet_welfare(X) >= MIN_WELFARE and no_negative_externality(X)
    def kappa_cov(self, X, d):         # 联合覆盖无遗漏且无重复空转
        return joint_coverage_complete(X) and not redundant_idle(X)
    def kappa_hum(self, X, d):         # 多人类场景取最保守 veto
        return all(hick_veto_conservative(X, h) for h in humans_in_workspace(X))
    def kappa_ee(self, X, d):          # 联合末点无同目标抢占
        return no_endpoint_claim_conflict(X)
```

### IP-498 IRCK：干扰鲁棒证书核（鲁棒化 + 租约）

```python
@dataclass
class InterferenceRobustCertificateKernel:
    """IRCK：显式干扰集 → Lipschitz 鲁棒裕度 → 证书租约。
    定理 10：I 越大执行集越小；I=∅ 时精确退化为 v5。
    诚实边界：鲁棒性只对「已建模的 I」成立"""
    I: InterferenceSet                 # Box(d_max,p_loss,eps_p,eps_w,w_max) × adv 上界
    L: dict                            # 每门分数的 Lipschitz 常数 L_i（离线标定上界）
    L_t: float                         # 裕度时间衰减率
    ell_max: float = 0.20              # 租约上限（s）

    def rad(self) -> float:
        return self.I.weighted_radius()          # 预计算，O(1)

    def robust_margin(self, scores: dict, tau5: dict) -> dict:
        r = self.rad()
        return {i: scores[i] - self.L[i] * r - tau5[i] for i in scores}

    def lease(self, rho: dict) -> float:
        m = min(rho.values())
        return 0.0 if m <= 0 else min(self.ell_max, m / self.L_t)

    def certify(self, X, delta0, tau5, gates) -> Cert | None:
        scores = gates.scores(X, delta0)              # 名义分数
        rho = self.robust_margin(scores, tau5)
        if any(v < 0 for v in rho.values()):
            return None                              # fail-closed：至少一门鲁棒失败
        ell = self.lease(rho)
        if ell <= 0:
            return None
        return Cert(t_issue=now(), lease=ell, rho=rho,
                    sig=sign(scores, X, self.I.budget_hash))

    def valid(self, cert, t_now, d_comm, tau_c) -> bool:
        age = (t_now - cert.t_issue) + d_comm + tau_c
        return age <= cert.lease and not self.freshness_violated(cert)
```

## 4. 正确性论证（增量更新）

### 引理 45（鲁棒裕度内近似的可靠性与保守性）

**陈述**：设分数 s_i(X,·) 对干扰 δ 为 L_i-Lipschitz，且 rad(I) 界住 ∀δ∈I 的加权范数。则 ∀δ∈I，s_i(X,δ) ≥ s_i(X,0) − L_i·rad(I)。因此 ρ_i = s_i(X,0) − L_i·rad(I) − τ_i ≥ 0 蕴含 s_i(X,δ) ≥ τ_i 对所有 δ∈I 成立。内近似 Exec_v6^inner ⊆ Exec_v6 可靠，保守间隙至多 L_i·rad(I)。

**证明**：由 Lipschitz 定义与范数界直接得到。∎

**诚实边界**：L_i 与 rad(I) 都依赖模型；若真实干扰超出 I 或 L_i 低估，soundness 失效（见 R64）。

### 引理 46（租约时程安全）

**陈述**：若鲁棒裕度衰减率 ≤ L_t，租约 ℓ = ρ(t0)/L_t，则 t∈[t0, t0+ℓ] 内 ρ(t) ≥ 0。若消费时 age = Δt + d_comm + τ_c ≤ ℓ，则执行时刻证书仍有效；反之拒绝消费并安全停。

**证明**：ρ(t) ≥ ρ(t0) − L_t·(t−t0) ≥ ρ(t0) − L_t·ℓ = 0。∎

### 引理 47（逐坐标中位数拜占庭误差界）

**陈述**：n 个站点中 f 个拜占庭且 3f<n，逐坐标中位数的 breakdown point ≈ floor((n+1)/2)/n > 1/2，其误差不超过诚实站点该坐标的某一顺序统计量。

**证明**：中位数的稳健性标准结论；污染少于一半时中位数保持在诚实样本范围内。∎

**诚实边界**：仅抗少数污染；f ≥ n/3 的协同共谋无结构保证。

### 定理 9（门提升组合与精确退化）

**陈述**：kc_i^F(X,δ)=∧_r kc_i^r(x^r+δ_sens^r;τ_i^5) ∧ κ_i^coup(X,δ)。
(i) n=1 且 I=∅ ⇒ κ 为空合取、δ=0 ⇒ Exec_v6 = Exec_v5。
(ii) 一般情形 π_r(Exec_v6) ⊆ Exec_v5^r。
(iii) Exec_v6 ⊆ {X : ∀r, x^r ∈ Exec_v5^r}。

**证明**：(i) 空合取为真，逐机门即 v5 门；(ii) 由 kc_i^F ⇒ kc_i^r 逐 r 合取消去；(iii) 耦合只增合取不增析取，交集单调收缩。∎

### 定理 10（抗干扰鲁棒单调）

**陈述**：I1 ⊆ I2 ⇒ Exec_v6^{I2} ⊆ Exec_v6^{I1} ⊆ Exec_v6^{∅}；内近似由引理 45 保证 sound；I=∅ 时精确退化为 v5。

**证明**：最坏情况量化的量化域扩大 ⇒ 谓词逐点变弱（更难满足）⇒ 通过集缩小；空集时 ρ_i=s_i−τ_i^5。∎

### 定理 11（租约时序安全）

**陈述**：在 (C1) 裕度衰减率 ≤ L_t、(C2) 执行前检查 age ≤ ℓ、(C3) 超时安全停下，不存在消费过期证书的违例；d_comm > ℓ 时不执行候选。

**证明**：引理 46 + 条件分支：age≤ℓ 走执行分支且裕度非负；否则走安全停分支。∎

### 定理 12（多机评测完整性与不可博弈）

**陈述**：在 (E1) 场景 commit-reveal 封存轮换、(E2) 签名证据绑定证书、(E3) 3·f_byz<n 且逐坐标中位数聚合下：(i) 评测前挑场景/指标不可行；(ii) 跨站伪造证书被拒；(iii) 少数拜占庭偏移由引理 47 界住。博弈成功率 ≤ 红队检测率（经验上界）。

**证明**：(i) commit 先于 reveal，信息不可得；(ii) 签名不可伪造，归约到 kc_evidence_forged 可靠性；(iii) 引理 47。∎

**诚实边界**：f≥n/3 协同共谋、部署分布漂移、以及「合法但选择性披露」不在保证内。

### 定理 v6（舰队级执行集总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 真实干扰 δ∈I、(B9) L_i 为有效上界、(B10) 3·f_byz<n 下：
(i) 单机精确退化：n=1, I=∅ ⇒ Exec_v6 = Exec_v5；
(ii) 投影嵌套：π_r(Exec_v6) ⊆ Exec_v5^r ⊆ … ⊆ Exec_v29；
(iii) 鲁棒单调：I1⊆I2 ⇒ Exec_v6^{I2}⊆Exec_v6^{I1}，且内近似 sound；
(iv) 租约时序安全：无过期证书消费；
(v) 评测完整性：挑场景/伪造/少数污染被结构性阻断（经验界）；
(vi) 七锚完备性保持：七门被提升而非新增，锚点集合不变。

**证明**：(i) 定理 9(i)；(ii) 定理 9(ii) + v5 嵌套；(iii) 定理 10 + 引理 45；(iv) 定理 11；(v) 定理 12；(vi) 提升不改变门索引集合，耦合项是门内合取。∎

**诚实声明**：(B8) 是承重假设且**无法在线验证**——干扰模型漏项时，鲁棒证书会静默失效；(B9) L_i 离线标定的上界可能被分布漂移突破；(B10) 只覆盖少数拜占庭，不覆盖协同共谋；鲁棒化带来保守性（误冻结/吞吐下降），且「过度保守导致死锁」与「不够保守导致违例」是同一预算的两端，无免费午餐。

## 6. 已知风险与缓解（增量更新）

| 风险编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| R19–R59 | v1~v5 全部既有风险 | — | 随原版继承；**R57 固化博弈在 v6 仍存在**，仅由冻结门 + 红队缓解 | 见既有表 |
| R60 | 鲁棒化过度保守 → 舰队误冻结/死锁/吞吐塌缩 | **高** | 干扰预算分级（正常/降级/安全停）；ρ 低于阈值时先降速再停；最差分层监控；ℓ_max 上限 | 长尾干扰下保守性不可避免（price of robustness） |
| R61 | 耦合检查可扩展性与分布式一致性（n²、竞态、消息乱序） | 中 | BVH/空间哈希；≤3 轮协商；摘要带版本号与时间戳；失败 fail-closed | 大规模 n 时通信与一致性成本上升 |
| R62 | 通信干扰导致证书过期或频繁安全停 | 高 | 租约预计算；降级模式（缩短 ℓ、降低速度）；断连即停 | 时延不可预测时只能保守停 |
| R63 | 评测共谋/协同攻击（f≥n/3）与「合法选择性披露」 | **高** | 签名 + 中位数 + 封存轮换 + 最差分层；外部审计 | 共谋超阈值无结构保证 |
| R64 | **干扰集 I 与 L_i 的模型错误**（漏项、低估、相关性未建模） | **极高** | 干扰日志在线监控 + 漂移告警；保守取 L_i 上界；红队扩展 I；I 版本化 | **原理性：fail-closed 只防已知干扰，无法感知模型错误** |
| R65 | 多机价值冲突/公平性（舰队福利聚合掩盖单机牺牲） | 中 | min-welfare 约束 + 最差机器人报告 + 可解释仲裁 | 价值多元下无唯一正确聚合 |

## 7. 本轮最大风险（最终确认）

**一句话**：**干扰集 I 是整个鲁棒证书的新信任根**——若 I 漏掉相关干扰（通信时延与传感器欺骗相关、跨机接触的隐式耦合、攻击者协同），鲁棒证书会在「模型以为安全」时静默失效，而 fail-closed 只能防已知干扰、无法感知模型本身的错误；v6 把 v5 的「自指博弈」风险换成了「模型设定错误」风险。
