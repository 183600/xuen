# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「差异化定位」×「多语言支持」）

> 前几轮一路把证书从“能力匹配”推进到“动作-鲁棒性”，再下探到“语义-接触生存核”。本轮换一个此前没触碰的层面：**证书所描述的能力“身份”本身是否稳定**。核心矛盾：**H24（差异化定位）**：部署目录里两个技能若在“动作剖面 × 语义接触 × 参考系”上不可区分，系统会在毫不知情时用错技能——差异不是营销词，而是**可辨识性（identifiability）**；**H25（多语言支持）**：自然语言指令/标签是多对一、语言相关的映射，`“support / 支撑 / 靠住 / 托住”` 并不共享同一个可供性外延，上一轮 `κ(l,c)` 一旦跨语言就漂移，使单语言验证过的证书在另一种语言下失效。

## 0. 直觉与动机

**灵感 1（差异化定位 → 先把“定位”拆成两层：能力生态位与空间参考系）**
直觉：一个技能“有没有用”不是重点，“会不会被错认成别的技能”才是部署事故的来源。差异化定位有两层含义：其一是**能力生态位**——这个技能擅长什么、边界在哪、和最近邻居差多少；其二是**空间定位**——同一技能从不同基座位姿、不同相机外参出发，看到的接触几何不同。二者其实在问同一件事：“换一个位置、换一个名字，我还能确认这是同一个能力吗？”

**灵感 2（多语言支持 → 语言是感知到控制之间的一层“表示”，不是字符串）**
直觉：多语言不是把界面翻译一遍。`“support / 支撑 / 靠住 / 托住”` 在可供性上是不同的动作—接触组合；同一句“把杯子稳住”，不同语言的语用预设不同（是压住、夹住还是扶住）。上一轮 `κ(l,c)` 把标签当成了唯一本体；本轮必须承认 **本体是复数**：`κ` 应定义在跨语言共享的**概念** `q∈Q` 上，语言 `ℓ` 只是概念的一个有损呈现 `g_ℓ:U_ℓ→Δ(Q)`。

**灵感 3（统一视角 → 表示群与商空间上的能力身份）**
直觉：把“换语言”和“换参考系”都看成作用在能力表示上的表示群 `G`（翻译/改写 × 坐标变换）。一个真正的能力身份应当是一个 **G-轨道**：沿轨道证书不变（不变性），轨道之间彼此可分（可辨识性）。于是“差异化定位 + 多语言支持”合并成一句可检验的要求：**证书必须活在商空间里，并且在商度量下有间隔**。

**灵感 4（翻译税 → 差异裕度要为语言/参考系失真付“税”）**
直觉：任何规范化（canonicalization）与翻译都会压缩类间距离。若两技能原本只差 `m_id`，经过 `ε` 失真的翻译与位姿规范化后可能只剩 `m_id-2ε`。因此“差异化定位”不能卡在阈值上，必须留 **guard band**：`m_id ≥ θ_id + 2(ε_pose + L_κ δ_lang)`。这是本轮最可操作的结论——**多语言能力不是免费的，它直接从可辨识裕度里扣预算**。

**灵感 5（宁可问，不可猜 → 主动消歧替代静默替换）**
直觉：当两个技能在商空间里靠得太近，或某个低资源语言的地基（grounding）置信不足，正确行为不是“选最近的”，而是 **主动请求澄清 / 换一种说法 / 切换参考系**。消歧是把 H24/H25 挡在不可逆动作之前的最小代价手段。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（能力定位签名）**
技能/机器人 `S` 的定位签名 `ζ_S=(α_S, Σ_S, κ_S, F_S)`：动作剖面 `α_S:A→[0,1]`、核心语义分布 `Σ_S`、概念可供性 `κ_S:Q×C→[0,1]`、规范化参考系 `F_S∈SE(3)`。度量 `d_ζ` 在四分量上按权重拼接（各分量先归一化）。

**定义 128（差异化定位 / 可辨识性）**
对技能目录 `𝒮`，`S_i,S_j` 可区分当且仅当 `d_ζ(ζ_i,ζ_j)≥θ_id`。目录的差异裕度 `m_id(S_i)=min_{j≠i} d_ζ(ζ_i,ζ_j)`。**注意**：近对称技能（左右手、前后步）天然 `m_id` 低，必须由参考系/上下文显式打破，而不是依赖默认值。

**定义 129（多语言可供性算子）**
语言集合 `𝓛`，概念空间 `Q`。落地 `g_ℓ:U_ℓ→Δ(Q)`；概念可供性 `κ:Q×C→[0,1]`。语句可供性
`κ_ℓ(u,c)=Σ_{q∈Q} g_ℓ(q|u)·κ(q,c)`。翻译 `T_{ℓ→ℓ'}` 只承诺在本体上的**保义性**，不承诺逐字保形。

**定义 130（跨语言 / 跨参考系失真）**
对同义对 `(u,u')`，`δ_lang(u,u')=||κ_ℓ(u,·)-κ_{ℓ'}(u',·)||_∞`；对位姿变化 `F,F'`，`ε_pose=sup|d_ζ(·,F)-d_ζ(·,F')|`。设规范化 `canon` 与翻译 `T` 在 `d_ζ` 下的逆扰动为 `ε_dist`，即 `d_ζ(canon(x),canon(y)) ≥ d_ζ(x,y)-2ε_dist`。

**定义 131（差异-语言联合可辨识性 / guard band）**
技能 `S` 在语言集 `L_set` 上联合可辨识，当且仅当
`m_id(S) ≥ θ_id + 2(ε_pose + L_κ·δ_lang)` 且 `δ_lang ≤ Θ_lang`。
右侧第二项是 **表示税**：多语言与位姿规范化对差异裕度的最大侵蚀。

**定义 132（差异-语言联合证书 DLC）**
`J_dl=(m_id, δ_lang, ε_pose, ρ_lang, L_set, evidence)`，其中
`ρ_lang(ε)=inf_{dist(T)≤ε} P(viable(x,Σ) | κ_ℓ)`。
可部署当且仅当通过定义 131 的 guard band、`ρ_lang≥ρ_min`、且 `L_set` 内**每种语言**都通过；任一语言失败则整条证书不可部署（不允许“多数语言通过”）。

## 2. 关键算法 伪代码

### IP-127 DPS（Differentiated Positioning Signature）

```python
def positioning_signature(skill, pose, alpha, Sigma_core, kappa, Q):
    F = canonical_frame(pose, skill.reference)      # 归一到技能局部系
    zeta = Signature(alpha=alpha, Sigma=Sigma_core,
                     kappa=project(kappa, Q), frame=F)
    return zeta
```

### IP-128 IDC（Identifiability Certificate）

```python
def identifiability_certificate(catalog, theta_id, metric_zeta):
    worst = float('inf')
    for i, s in enumerate(catalog):
        dists = [(j, metric_zeta(s.zeta, t.zeta))
                 for j, t in enumerate(catalog) if j != i]
        m_id, j_nn = min(dists, key=lambda x: x[1])
        if m_id < theta_id:
            return ('reject', 'aliasing', i, j_nn, m_id)
        worst = min(worst, m_id)
    return ('ok', IdentityCert(worst))
```

### IP-129 XAG（Cross-lingual Affordance Grounding）

```python
def cross_lingual_affordance(u, lang, g, kappa, C):
    q_dist = g[lang].ground(u)                       # Delta(Q)，需校准
    return {c: sum(q_dist[q] * kappa[q][c] for q in Q) for c in C}
```

### IP-130 XLC（Cross-lingual Consistency）

```python
def cross_lingual_consistency(pairs, g, kappa, C, Theta_lang):
    worst, witness = 0.0, None
    for (u_a, la, u_b, lb) in pairs:                 # 同义/翻译句对
        ka = cross_lingual_affordance(u_a, la, g, kappa, C)
        kb = cross_lingual_affordance(u_b, lb, g, kappa, C)
        d = max(abs(ka[c] - kb[c]) for c in C)
        if d > worst:
            worst, witness = d, (u_a, la, u_b, lb)
    return ('ok' if worst <= Theta_lang else 'reject',
            LanguageConsistency(worst, witness))
```

### IP-131 DLC（Differentiation-Language Certificate）

```python
def differentiation_language_certificate(S, catalog, pairs, budgets):
    idc = identifiability_certificate(catalog, budgets.theta_id, d_zeta)
    if idc.status != 'ok':
        return idc
    xlc = cross_lingual_consistency(pairs, g, kappa, C, budgets.Theta_lang)
    if xlc.status != 'ok':
        return xlc
    guard = 2 * (budgets.eps_pose + budgets.L_kappa * xlc.delta_lang)
    if idc.m_id < budgets.theta_id + guard:          # 表示税未付清
        return ('reject', 'guard_band', idc.m_id, guard)
    for lang in budgets.L_set:                       # 不允许多数通过
        rho = language_robustness(S, lang, budgets.eps_lang)
        if rho < budgets.rho_min:
            return ('reject', 'language_robustness_fail', lang, rho)
    return ('ok', DLCert(idc.m_id, xlc.delta_lang, budgets.eps_pose,
                         budgets.L_set, budgets.rho_min))
```

### IP-132 LDP（Language Disambiguation Protocol）

```python
def language_disambiguation(S, candidates, u, lang, ambiguity):
    if ambiguity < theta_amb:
        return ('act', best_candidate(candidates))
    if near_symmetric(candidates):
        return ('reanchor', request_frame_change(S))   # 换参考系打破对称
    if lang in HIGH_RESOURCE and has_paraphrase(u):
        return ('reask', paraphrase(u, lang))          # 同语言换说法
    return ('switch_language', pick_pivot_language(candidates))  # 用更可辨识语言
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| DPS | O(|A|+|Q|·|C|) | O(|A|+|Q|·|C|) | 参考系规范化可逆、投影保义 |
| IDC | O(|S|²·d) | O(|S|·d) | 度量 `d_ζ` 满足三角不等式、目录完备 |
| XAG | O(|Q|·|C|) | O(|Q|·|C|) | `g_ℓ` 校准、概念本体对齐 |
| XLC | O(|P|·|Q|·|C|) | O(|Q|·|C|) | 同义对覆盖、`δ_lang` 可复现 |
| DLC | O(|S|²d+|P||Q||C|+|L_set|·|X|) | O(|S|d+|Q||C|) | guard band 闭合、逐语言全通过 |
| LDP | O(|Cand|·|A|) 每次 | O(|Cand|) | 消歧策略单调、澄清收敛 |

**正确性定理（Cross-lingual Differentiated Identifiability Soundness）**
假设上一轮 (A29)–(A32) 成立；**(A33)** `d_ζ` 为伪度量，`canon` 与 `T` 的逆扰动 ≤ `ε_dist`；**(A34)** `g_ℓ` 经温度/分位数校准，ECE ≤ `ε_g`；**(A35)** guard band 成立。
则对任意两个不同能力 `i≠j` 及任意 `ℓ,ℓ'∈L_set`：

```
P(correct_capability | ℓ) ≥ 1 - P(m_id < θ_id + 2ε_dist)
                             - P(δ_lang > Θ_lang)
                             - P(κ 本体失配)
P(substitute i→j | ℓ) ≤ P(d_ζ(canon ζ_i, canon ζ_j) < θ_id)
                       ≤ P(m_id - 2ε_dist < θ_id)
```

关键：**可辨识性只有在“规范化之后”仍成立才算数**；翻译与规范化带来的逆扰动，必须由差异裕度显式预付。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 概念本体跨语言错位（“支撑”外延更宽） | 高 | 共享概念层 + 多语言锚点集 + 本体对齐审计 |
| 低资源语言 `g_ℓ` 稀疏、校准失效 | 高 | 枢轴语言回退 + 低资源专门校准 + 主动消歧 |
| 位姿估计误差使 `canon` 不稳、裕度塌缩 | 高 | 位姿不确定度进 `ε_pose`、鲁棒参考系选择 |
| 过度差异化导致目录碎片化 | 中 | 合并近同义技能 + 生态位预算 |
| 度量 `d_ζ` 权重可被“刷分” | 中 | 度量预注册 + 下游替换率做外部效度检验 |

## 6. 本轮最大风险

**一句话**：差异化定位与多语言支持把能力证书从“功能对不对”推进到“身份稳不稳、跨语言还认不认得”，但其 soundness **双重依赖 `d_ζ`/`canon` 的语义忠实与稳定性、以及跨语言概念本体的对齐**；一旦规范化把两个真实能力压进同一个商空间邻域，或某语言的地基系统性地把“支撑”译成“抓取”，guard band 的算术会一本正经地给出“可辨识、可部署”的证书，系统却在真实世界里持续静默替换技能——因此必须以 **本体对齐审计 + 位姿不确定度入账 + 主动消歧兜底** 三重护栏，宁可多问一句，绝不把“名字不同”当作“能力可分”。

# 第 55 轮产物 · 创新点清单 v32：PolyID-GroundEdge（DPS×IDC×XAG×XLC×DLC×LDP）

> 承接第 54 轮产物 v31。v31 解决“技能组合在动作与鲁棒性上是否可拼”，本轮新增一层此前缺失的**能力身份层**：
> - **DPS（Differentiated Positioning Signature）**：把动作剖面、核心语义、概念可供性与参考系拼成可比较的定位签名 `ζ`；
> - **IDC（Identifiability Certificate）**：验证目录内两两能力可分，输出差异裕度 `m_id`；
> - **XAG（Cross-lingual Affordance Grounding）**：在任何语言上把语句落地到共享概念的接触可供性；
> - **XLC（Cross-lingual Consistency）**：量化同义/翻译句对的 `δ_lang`，把翻译当作有预算的扰动；
> - **DLC（Differentiation-Language Certificate）**：差异裕度 + 语言一致性 + guard band 的联合证书 `J_dl`；
> - **LDP（Language Disambiguation Protocol）**：靠得太近时主动澄清/换参考系/换语言，禁止静默替换。
>
> IP 编号：IP-127~IP-132（共 6 个新增）；升级 IP-118/120 的联合证书，追加身份与语言维度。

```python
        return ('reanchor', request_frame_change(S))
    if lang in HIGH_RESOURCE and has_paraphrase(u):
        return ('reask', paraphrase(u, lang))
    return ('switch_language', pick_pivot_language(candidates))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DPS | O(\|A\|+\|Q\|\|C\|) | O(\|A\|+\|Q\|\|C\|) | 参考系规范化可逆、投影保义 |
| IDC | O(\|S\|²d) | O(\|S\|d) | `d_ζ` 伪度量、目录完备 |
| XAG | O(\|Q\|\|C\|) | O(\|Q\|\|C\|) | `g_ℓ` 校准、本体对齐 |
| XLC | O(\|P\|\|Q\|\|C\|) | O(\|Q\|\|C\|) | 同义对覆盖、`δ_lang` 可复现 |
| DLC | O(\|S\|²d+\|P\|\|Q\|\|C\|+\|L_set\|\|X\|) | O(\|S\|d+\|Q\|\|C\|) | guard band 闭合、逐语言全通过 |
| LDP | O(\|Cand\|\|A\|) | O(\|Cand\|) | 消歧策略单调、澄清收敛 |

**guard band 推导（表示税）**
设规范化 `canon` 与翻译/落地 `T` 对 `d_ζ` 的逆扰动均不超过 `ε_pose` 与 `L_κδ_lang`，令 `ε_dist=ε_pose+L_κδ_lang`。对任意 `i≠j`：

```
d_ζ(canon(ζ_i), canon(ζ_j)) ≥ d_ζ(ζ_i, ζ_j) - 2ε_dist ≥ m_id - 2ε_dist
```

要求规范化后仍可分，即 `m_id - 2ε_dist ≥ θ_id`，故
`m_id ≥ θ_id + 2(ε_pose + L_κδ_lang)`。这就是本轮的核心可检验不等式。

**正确性定理（Cross-lingual Differentiated Identifiability Soundness）**
假设 (A29)–(A32) 成立；**(A33)** `d_ζ` 为伪度量且 `canon`、`T` 逆扰动 ≤ `ε_dist`；**(A34)** `g_ℓ` 校准 ECE ≤ `ε_g`；**(A35)** guard band 成立。则

```
P(correct_capability | ℓ) ≥ 1 - P(m_id < θ_id + 2ε_dist)
                             - P(δ_lang > Θ_lang)
                             - P(κ 本体失配)
```

关键：**证书必须对“表示变化”不变、对“能力类别”可分；不变性以预算形式折算成差异裕度的税。**

## 6. 本轮最大风险

**一句话**：身份-语言层把“能力可分”和“跨语言不变”写进了可部署证书，但其 soundness **双重依赖 `d_ζ`/`canon` 的语义忠实与稳定性、以及跨语言概念本体的对齐**；一旦规范化把两个真实能力压进同一商空间邻域，或某语言的地基系统性地把“支撑”译成“抓取”，guard band 的算术会一本正经地给出“可辨识、可部署”的证书，系统却在真实世界里持续静默替换技能——故必须以 **本体对齐审计 + 位姿不确定度入账 + 主动消歧兜底** 三重护栏，宁可多问一句，绝不把“名字不同”当作“能力可分”。
