# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「视觉伺服」×「对比实验」）

> 第 57 轮把承诺的赌注从"模型置信"推到"证据质量"：MFSL 摊销先验、XMC 跨模态对账、PTM 个性化信任，使"证据说可信"变得可校准、可对账、可审计。但它仍是**开环的、绝对的、单臂的**：先攒证据、再判后验、然后一次性承诺；它相信一个**绝对**校准契约（ECE_k≤ε_meta(k)）与一个**绝对**后验，而它自陈的最大风险正是"坏先验普遍"。本轮两个灵感各补一刀。**视觉伺服**说：不要把证据攒够再开环下注，把"风险裕度"放进闭环里连续调节——闭环对模型/标定误差的鲁棒性来自反馈而非更好的先验；同时借来交互矩阵、视野约束与局部极小三个概念：**探针能不能看见危险方向（可观测性）**比"攒了多少信息"更根本，**证据出视野**与**证据停滞**必须被显式检测。**对比实验**说：证据不该是一个绝对后验，而应是一条**带对照臂的差分信号**——每个断言都问"相对谁"；共同模式 nuisance 在差分中抵消，但随之而来的是它最深的陷阱：**两臂同坏时 Δ≈0 会被读成"无效应"**，差分必须锚在一个绝对安全点上；而且机器人自适应决定何时探、何时停，这是可选停止，固定样本的 ECE/CI 保证全部失效，必须改用**任意时有效（anytime-valid）的 e-value/置信序列 + 预注册对比**。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"可闭环调节、危险方向可观测、对照可锚定且统计任意时有效的证据说可信"**。

核心矛盾：
- **H29（闭环收敛 vs 可观测）**：闭环能把误差驱到零，但只在探针能激励、能观测的方向上；落在证据雅可比零空间里的危害对伺服不可见，环路会"稳定地"把一个看不见的危险认证为安全。闭环收敛不等于正确——这是视觉伺服局部极小在证据域的翻版。
- **H30（差分抵消 vs 锚点依赖）**：对照把共同模式 nuisance 抵消掉，但危险若恰好是两臂共有的，Δ≈0 就变成"假阴性"；要让差分有意义，对照臂必须由一个**绝对**锚点认证，而锚点可靠性正是第 57 轮想摊销掉的那个先验——安全赌注被悄悄搬回原点。
- **H31（自适应探询 vs 统计有效）**：探针顺序、停止时刻由策略自适应决定，这是可选停止与多重比较；固定样本校准与置信区间在自适应数据下系统性过窄。若不在探针前预注册对比方向与停止规则，并用任意时有效统计，系统会"用数据钓鱼"制造自信。

## 0. 直觉与动机

**灵感 1（视觉伺服 → 证据不是攒够再判，而是闭环调节）**
直觉：第 57 轮像"看一眼、算位姿、开环走过去"——先验/标定错多少，误差就原样留在承诺里。视觉伺服反其道：把任务误差关进控制回路，标定有偏也能靠反馈收敛。证据域同理：定义标量**认证风险裕度** m_t=δ_f−R̂_t，把"承诺所需裕度"当作期望特征，用探针去调节误差 e_t=m_req−m_t；承诺只在误差进带、环路稳定、且危险方向可观测时发生。由此得到第 57 轮最缺的性质：**对元先验偏差的鲁棒性来自反馈增益，而不是来自一个更准的先验**。再借三个概念：**证据有效域 𝒱**（对应视野/线性化有效区，出域=特征丢失→停-重捕获）；**证据停滞**（对应局部极小：误差不降但探针已不动，静止≠收敛→升级而非承诺）；**证据雅可比 J_e**（对应交互矩阵：探针能多快把裕度推向安全）。

**灵感 2（对比实验 → 从绝对后验到带对照臂的差分证据）**
直觉：绝对问法是"这个后验够好吗"，对比问法是"相对什么"。给每个危害断言配一个匹配对照臂：处理臂打主动探针，对照臂来自"危害缺席/已知安全"的参照，取对 nuisance 不变的对比量 Δ=D(o_T,o_C)。若照明漂移、材质批次、传感器偏置同时作用于两臂，差分把它们抵消——这正好补上第 57 轮"单模态共谋"的软肋：**共同模式欺骗会把信号一起抵消，于是不承诺（安全），而不是误承诺**。但差分也带来三个必须工程化的东西：**预注册**（探针前锁定要检出的方向，禁止事后编故事）；**任意时有效统计**（自适应探针=可选停止，用 e-value/置信序列把假阳性压在 α 下）；**绝对锚点 + 哨兵**（否则两臂同坏会把危险读成无效应）。对比实验的方法学还反过来改造本轮的评估本身：预注册假设、配对设计、消融、阴性对照、效应量与任意时置信区间、仿真-真实外部效度。

**灵感 3（合流 → 证据门第六类与承诺谓词的闭环化）**
直觉：第 57 轮证据门五类（EV-probe\*/visit/margin/xmodal/human）本轮新增 **EV-contrast**（对照差分证据），且承诺谓词从"后验过门"变成四合一：**裕度误差进带 ∧ 危险方向可观测 ∧ 对照差分任意时显著 ∧ 哨兵/锚点健康**。击穿安全不再只需"先验错"，而需同时绕过闭环反馈、可观测性审计、差分对照与绝对锚点——纵深从五层到六层。

**灵感 4（PCE++ → 探询预算变成一次受控实验）**
直觉：每次探针不再是"多问一句"，而是一次有处理/对照/预注册/停止规则的小型对照实验；VOI 换成"该探针对危险方向的可观测增益"，零空间方向上的探针即使信息熵很高也判 VOI≈0。伺服在预算内收敛或停滞；停滞不是"再等等"，而是升级（换模态/换方向/人/绕行/安全停）。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（证据伺服 EVS）** 检查点 r 的证据状态 s_t=(R̂_t,u_t,z_t)：R̂_t 为经第 57 轮证据门认证的风险估计，u_t 为证据不确定度，z_t 为上下文。安全承诺阈 δ_f，裕度 m_t=δ_f−R̂_t，目标裕度 m_req>0，误差 e_t=m_req−m_t（e_t>0 表示证据不足）。 admissible 非破坏探针集 Π_adm（继承 A34）。证据交互矩阵 J_e(t,π)=∂E[m_{t+1}|s_t,π]/∂π。伺服律 π_{t+1}=Proj_{Π_adm}(π_t−λ·Ĵ_e^+e_t)，λ 由 ‖Ĵ_e−J_e‖≤η_J 下的闭环收缩条件选取。证据有效域 𝒱={(z,s):J_e 与校准契约、线性化同时成立}；z_t∉𝒱 记**证据出视野**，触发停-重捕获（换模态/换方向/人）。**证据停滞**：e_t 在 k_stall 步内不降且 ‖Δπ‖<ε_π，或误差更新方向与危险方向 d_h 正交 ⇒ 判停滞并升级。承诺仅当 e_t≤−m_margin ∧ 稳定窗内单调 ∧ OBS 通过 ∧ 对照有效。

**定义 140（可观测性审计 OBS）** 版本化**声明**危害集 ℋ（未建模危害显式排除在保证之外并披露）。对每个 h∈ℋ，危险方向 d_h 为区分 h 与 ¬h 所需证据变化方向。探针组合的可观测矩阵 O=[J_e(π_1);…;J_e(π_M)]，投影 O_h=P_{d_h}O，证书 O_cert(h)=σ_min(O_h)。h 为 ε-可观测 ⇔ O_cert(h)≥ε_obs 且对照方向对齐 |⟨d_h,d_Δ⟩|≥ε_align。任一必需 h 不可观测 ⇒ 对不可逆接触**硬阻断**（非降低置信），要求新增模态/自由度或人。持续激励：选使 min_h O_cert(h) 最大的探针组合以维持秩；在危险方向零灵敏的探针，对该危害 **VOI≡0**，无论其信息熵收益多大。

**定义 141（对照差分证据 DCT）** 对区域 r 关于 h 的断言，取处理臂观测 o_T（主动探针）与匹配对照臂 o_C（h 缺席或已知安全参照），声明 nuisance 集 𝒰。对比量 Δ=D(o_T,o_C)，D 取对 𝒰 中 nuisance 不变的泛函（乘性/单调 nuisance 用比值或秩）。估计量 τ_h=E[Δ|h]−E[Δ|¬h]，方向须在探针前预注册。共同模式抵消：若 u∈𝒰 对两臂作用相同 g_u，则 D(g_u(o_T),g_u(o_C))=D(o_T,o_C)。锚点条件：o_C 必须由**绝对**锚点 A 认证（不靠差分），A 由冗余且物理独立的证据或人认证，且与 T 的共同模式不超出已声明可抵消集。**两臂同坏守卫**：Δ≈0 但锚点/哨兵向 h 的签名移动 ⇒ 判"两臂同坏"并冻结，而非"无效应"。EV-contrast 仅当预注册方向 ∧ 任意时有效 e-value≥1/α ∧ 锚点健康。

**定义 142（随机对照探针设计 RCD）** 假设集 ℋ_r，设计矩阵 X 指定探针方向/位置/模态；对顺序与位置随机化以打断时间/位置混淆，配对并共用随机数（common random numbers）以降方差。序贯证据用 e-value E_t=∏_{i≤t}(1+λ_i(Δ_i−μ_0))（或似然比），满足 P_{H0}(sup_t E_t≥1/α)≤α（任意时有效）；承诺需 E_t≥1/α_ev。预注册哈希 h_pre 在探针前绑定 (h,方向,α,停止规则,对照臂规格)，任何偏离只记探索性、不得进入承诺。多重比较按 e-value 合并校正；设**阴性对照探针**（应 Δ≈0）作设计自检。

**定义 143（对照哨兵 CSM）** 哨兵集 𝒜 为每会话重探的已知安全参考斑块，各哨兵物理独立。漂移 z_A=|o_A−μ_A|/σ_A，危害签名距离 ψ_A。z_A>θ_A ⇒ 会话级共同模式漂移，作废差分证据并重校准/冻结。**锚点轮换**：锚点有服务寿命，须以绝对方式刷新；禁止全部锚点同物理，否则共同模式抵消形同虚设。哨兵同时承担两臂同坏检测：Δ≈0 而 ψ_A 向危害签名移动 ⇒ 判两臂同坏。

**定义 144（对比伺服承诺算子 PCE++）** 每检查点：①哨兵/漂移检查（异常→冻结重校准）；②OBS 审计（必需危害不可观测→硬阻断并升级）；③在有效域内按 RCD 做闭环差分探针，直至 e_t≤−m_margin 或停滞/预算尽；④预承诺检查：六类证据门（含 EV-contrast）+不确定度+同意态；⑤承诺 ⇔ 全过；停滞→绕行→降档→L2 协商→安全停。证书 J_c=(J_p,e 轨迹,Ĵ_e,O_cert,contrast_log,e_value_log,prereg_hash,sentinel_log,anchor_registry,stall_log)。

## 2. 关键算法伪代码（完整版见产物区）

```python
def evidence_servo(M, r, inf, budget):
    e = m_req - margin(M, r, inf)
    while e > -m_margin and budget.probes_left > 0:
        if z(r) not in validity_region(M):            # 证据出视野
            return reacquire_or_escalate(M, r)
        obs = observability_audit(M, r)               # σ_min vs ε_obs
        if not obs.ok:
            return block_or_escalate(M, r, obs)       # 硬阻断，不是降置信
        pi, Je = servo_probe(M, r, e)                 # π=-λĴ⁺e，非破坏约束
        oT = execute(pi, cap=F_abs)
        oC = matched_control(pi, M, r, anchors)       # 对照臂
        E = e_value_update(E, contrast(oT, oC), H0)   # 任意时有效
        M = fuse_contrast(M, r, oT, oC, E)
        e_prev, e = e, m_req - margin(M, r, inf)
        if stalled(e, e_prev, pi):                    # 局部极小
            return escalate_or_reroute(M, r)
        budget.spend(pi)
    return commit_or_escalate(M, r, e, E, obs, sentinel)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| EVS | O(k_servo·(d_s+\|Π\|+d_φ)) | O(\|V\|·d_s) | 闭环收缩（A41）、出域/停滞可检 |
| OBS | O(\|ℋ\|·(\|Π\|·d_π·d_s+rank)) | O(\|ℋ\|·\|Π\|·d_π) | ε_obs 秩条件、危害集版本化（A42） |
| DCT | O(#contrast·d_o) | O(#contrast) | 对照可交换、锚点绝对认证（A43） |
| RCD | O(\|X\|) | O(\|X\|) | 任意时有效、预注册不可变（A44） |
| CSM | O(\|𝒜\|) | O(\|𝒜\|) | 哨兵物理独立、轮换 |
| PCE++ | O(\|CP\|·(k_servo+K_stat)+...) | O(\|V\|+\|σ\|) | 伺服终止或停滞升级 |

**正确性定理（Differential Servo Soundness, DSS 概要）**：在 A33–A40 上增加 (A41) 伺服模型诚实：‖Ĵ_e−J_e‖≤η_J，λ 满足收缩 ρ<1，且全程留在 𝒱；(A42) 可观测性相对**声明**危害集 ℋ 完备，O_cert(h)≥ε_obs 方可承诺，未建模危害显式免责；(A43) 对照可交换、锚点由绝对证据认证、共同模式集 𝒰 声明诚实；(A44) 任意时有效统计：e-value 在 H0 下满足 sup 上界，预注册哈希不可变。则：
1. **对先验偏差去敏**：若全程留 𝒱 且 OBS 通过，稳态裕度误差 ≤η_servo=η_J·m_req/(λ(1−ρ))，故 P(fail)≤δ_f+η_servo+η_meas，**与元先验偏差 b_prior 无关**——这是相对第 57 轮 δ_f+ε_meta(k) 的关键改进；一旦出域或不可观测，该保证作废并转为保守默认。
2. **盲区保证**：若声明危害 h 的 O_cert(h)<ε_obs，则不发生针对 h 的不可逆承诺（硬阻断）；对未建模危害无保证（须披露）。
3. **对照健全性**：锚点有效且 h∉共同模式集时，假阳性≤α_e（任意时有效）；h∈共同模式集时差分失去功效→不承诺（保守，不误承诺）；锚点失效则保证失效（本轮最大风险）。
4. **终止性**：伺服在 ≤k_servo 步内达到 e≤−m_margin 或触发停滞，PCE++ 在 |CP|·k_servo 内终止于 {承诺,绕行,L2,安全停}。

## 6. 本轮最大风险

### IP-139 EVS（证据伺服）

```python
def evidence_servo(M, r, inf, budget, anchors):
    e = m_req - margin(M, r, inf)                 # e>0: 证据不足
    hist = []
    while e > -m_margin and budget.probes_left > 0:
        if z(r) not in validity_region(M):        # 证据出视野
            return reacquire_or_escalate(M, r)    # 停-重捕获/换模态/人
        Je_hat = estimate_J(M, r)                 # 前向 O(d_phi)
        pi = project_admissible(-lam * pinv(Je_hat) * e, M, F_abs)
        oT = execute(pi, cap=F_abs)
        oC = matched_control(pi, M, r, anchors)   # 对照臂（IP-141）
        M, delta = fuse_contrast(M, r, oT, oC)
        E = e_value_update(E, delta, mu0)         # IP-142 任意时有效
        e_prev, e = e, m_req - margin(M, r, inf)
        hist.append((e, pi))
        if stalled(hist, k_stall, eps_pi):        # 局部极小
            return escalate_or_reroute(M, r)
        budget.spend(pi)
    return commit_or_escalate(M, r, e, E, anchors)
```

```python
def observability_audit(M, r):
    H = M.hazard_set(r)                            # 版本化、声明、可审计
    portfolio = probe_portfolio(M, r)              # 持续激励候选
    O = stack([M.Je(r, p) for p in portfolio])

                 unmodeled=M.unmodeled_disclosure) # 未建模危害显式免责
```

### IP-141 DCT（对照差分证据 + 绝对锚点）

```python
def contrast_commit(M, r, oT, oC, h, prereg, E):
    assert prereg.hash == h_pre(h)                 # 预注册不可绕过
    delta = D(oT, oC)                              # D 对 declared nuisance 不变
    E = e_value_update(E, delta, mu0)
    if h in common_mode_set(M) and not anchor_discriminates(h, oC):
        return ('freeze', 'h_common_mode_masked')  # 差分无功效→不承诺
    if both_arms_bad(oT, oC, M.sentinels):         # Δ≈0 但两臂都异常
        return ('freeze', 'both_arms_bad')
    if delta <= theta_d or E < 1 / alpha_ev:
        return ('insufficient', delta, E)
    return ('ok', delta, E)

def both_arms_bad(oT, oC, sentinels):
    hazard_sig = hazard_signature(oT)
    return (distance(hazard_sig, hazard_signature(oC)) < eps_delta
            and any(psi_A(o, hazard_sig) < theta_A for o in sentinels))
```

```python
def rcd_design(M, r, Hr, budget):
    X = factorial_design(Hr, modalities(M), directions(M))
    X = randomize_order_and_position(X)            # 打断时间/位置混淆
    X = pair_with_common_random_numbers(X)         # 降方差
    prereg = PreRegistration(hazards=Hr, alpha=alpha,
                             stopping_rule=budget.k_max,
                             control_spec=control_spec(M, r))
    E = {}
    for x in X:
        if budget.exhausted(): break
        oT = execute(x); oC = matched_control(x, M, r)
        for h in Hr:
            E[h] = e_value_update(E.get(h, 1.0), D(oT, oC), mu0)
            if E[h] >= 1 / alpha_ev and prereg.matches(h):
                return ('commit_candidate', h, E[h])
        if negative_control_ok(x, M, r) is False:  # 设计自检
            return ('design_invalid', x)
    return ('inconclusive', E)
```

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| EVS | O(k_servo·(d_s+\|Π\|+d_φ)) | O(\|V\|·d_s) | 闭环收缩 η_servo、出域/停滞可检（A41） |
| OBS | O(\|ℋ\|·(\|Π\|·d_π·d_s+rank)) | O(\|ℋ\|·\|Π\|·d_π) | O_cert≥ε_obs 才可承诺（A42） |
| DCT | O(#contrast·d_o) | O(#contrast) | 对照可交换、锚点绝对认证（A43） |
| RCD | O(\|X\|) | O(\|X\|) | 任意时有效、预注册不可变（A44） |
| CSM | O(\|𝒜\|) | O(\|𝒜\|) | 哨兵物理独立、锚点轮换 |
| PCE++ | O(\|CP\|·(k_servo+K_stat)+\|CP\|·A\*) | O(\|V\|+\|σ\|) | 伺服终止或停滞升级、四态完备 |

**正确性定理（Differential Servo Soundness, DSS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 证据伺服模型诚实：‖Ĵ_e−J_e‖≤η_J，λ 满足 ρ=‖I−λĴ_e⁺J_e‖<1，且检查点全程留在有效域 𝒱；**(A42)** 可观测性相对**声明**危害集 ℋ 完备：必需 h 满足 O_cert(h)≥ε_obs 才允许承诺，未建模危害显式免责并披露；**(A43)** 对照有效性：处理/对照可交换（随机化/匹配），锚点 A 由绝对（非差分）证据认证，共同模式集 𝒰 声明诚实，h∉𝒰 或锚点可判别 h；**(A44)** 任意时有效统计：e-value 在 H0 下满足 P(sup_t E_t≥1/α)≤α，预注册哈希不可变、停止规则固定。则：

1. **对元先验偏差去敏（核心收益）**：全程留 𝒱 且 OBS 通过时，稳态裕度误差
   `η_servo ≤ η_J·m_req/(λ(1−ρ))`，故 `P(fail) ≤ δ_f + η_servo + η_meas`，**不含 b_prior**。对比第 57 轮 `δ_f+ε_meta(k)`：先验偏差被反馈增益压制，而不是被摊销得更准。出域或不可观测时该保证作废，转保守默认。
2. **盲区保证**：若必需 h 的 O_cert(h)<ε_obs，则不发生针对 h 的不可逆承诺（硬阻断）；对未建模危害无保证，须披露并走更强人工复核。
3. **对照健全性**：锚点有效且 h∉𝒰 时，假阳性 ≤α_e（任意时有效）；h∈𝒰 时差分失去功效 ⇒ 不承诺（保守）；锚点失效时保证失效——这是本轮的最大风险，非定理可消除。
4. **终止性**：伺服在 ≤k_servo 步达到 e≤−m_margin 或触发停滞，故 PCE++ 在 |CP|·k_servo 内终止于 {承诺, 绕行, L2 协商, 安全停}。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + η_servo + η_meas + α_e·1[contrast] + δ_xm·1[L1])
             − P(𝒱 出域未检出) − P(锚点失效) − P(两臂同坏未检出)
             − P(未建模危害) − P(护盾回退失败) − P(超时 ∧ 安全停失效)
```

关键：**闭环给鲁棒、共形给保底、可观测给盲区、对照给抵消、任意时统计给诚实、锚点给绝对**——六者各管一段，且必须显式披露各自失效域；任何一项沉默，保证都不可叠加。

## 7. 本轮最大风险

**一句话**：差分证据只在"对照臂与处理臂共享**可抵消** nuisance"时成立；一旦危险本身两臂共有（两臂同坏），Δ≈0 会被读成"无效应/安全"，安全重新押回那个绝对锚点，而锚点可靠性恰是第 57 轮试图摊销掉的先验——风险从"坏先验普遍"变成"**坏锚点被差分洗白**"。
