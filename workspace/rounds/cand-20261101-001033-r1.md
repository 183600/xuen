# 新循环 R1（总第 13 轮）· GRASP-CAGE：把抓取位姿估计从「6D 回归」改成「等变锚点检索 + 几何认证 + 保形 OOD 门控」

> 日期：**2026-11-01（UTC）**。承接第 10 轮 FACT-VLA、第 11 轮 GEO-RESIDUAL、第 12 轮 CHUNK-SERVO。本轮三个灵感词：**抓取位姿估计**、**分布外泛化**、**桌面操作**。本轮不做新的外部检索；A 级事实沿用第 12 轮 2026-10-28 的核实结果，新增的是几何分析（B 级）与设计假设（C 级）。

## 0. 先给结论：第 12 轮闭环了「最后 3 厘米」，但「第一厘米」还开着

第 12 轮 CHUNK-SERVO 的视觉伺服目标是**受器/容器**：挂杯的杯架、插网线的网口、叠碗的碗沿。它默认物体已经在夹爪里，或者至少默认 VLA 能把夹爪送到物体上。这个默认在本赛制里很危险：

- 32 任务 × 10 次 = 320 trials，10 次按 5 类泛化各 2 次分配：位置、干扰物、桌面背景、未见物品、人为干扰；**每一次都带某一类偏移**，其中人为干扰占 2/10。最早被分布外偏移击中的，不是最后的插入，而是**第一次抓取**。
- 位置偏移把物体挪走；背景/干扰物让分割和局部特征漂移；未见物品改变几何；人为干扰把物体拿起/移走/遮挡。抓取位姿估计错 1–2 厘米，后面的伺服再准也没有用。
- API **没有 depth、没有 force/torque、没有 tactile**。头双目基线只有 **58.2526 mm**，`fx≈282 px`；在 0.6–1.0 m 工作距离上，0.5 px 的视差噪声对应 **约 11–30 mm** 的深度误差（本轮 B 级计算）。这对小物体（拉链头、钥匙、试管、耳机）远远不够。腕部相机没有内参矩阵，必须先标定。
- 单模型规则禁止再训一个 GraspNet/AnyGrasp 式的抓取网络。但**演示模板检索 + 解析几何 + 保形门控没有学习权重**，它不是第二个模型，是控制器/数据索引。这是本轮真正的开口。

所以本轮的押注是 **GRASP-CAGE**（**C**onformalized **A**ffordance-anchored **G**rasp **E**stimation）：

> 不从零回归 6D 抓取位姿，而是从 33k 条成功演示里挖出「夹爪闭合瞬间的局部物体几何模板」；测试时用 SE(3) 等变的局部配准把模板搬到当前物体上；用解析几何判断这个抓取是否可行；用保形分位数给「模板迁移误差」一个有限样本的误差球；只有误差球整个落在可行域内才接管 VLA，否则把控制权还给 VLA/CHUNK-SERVO。抬升验证作为在线标签，驱动自适应保形门控（ACI）。

一句话：**把「抓取位姿估计」从点回归改成带证书的集合估计；只在能证明 VLA 抓取不可行、或 CAGE 显著更优时才接管。**

## 1. 直觉：人抓新杯子，不是先解 6D 位姿，而是搬一个「抓取图式」

想象你第一次看到一个没见过的马克杯。你不会先估计它的 6D 位姿、再回归夹爪位姿；你会认出「杯身/杯柄」这个功能结构，把「从侧面夹杯身」或「从上方捏杯沿」的图式搬过去，同时用眼睛确认手指不会撞到杯壁。这个图式是**相对物体局部几何**的，不是相对桌面绝对坐标的。

这正好对应演示数据的结构：

- 33,276 条成功演示里，绝大多数至少有一次夹爪闭合（具体需 P0 核实）。闭合瞬间的夹爪位姿 `g_i` 和腕部/头部图像，就是一个「抓取图式」的样本。
- 把闭合瞬间夹爪附近的物体点云变换到夹爪坐标系，得到局部模板 `P_i`。它编码的是「手指应该贴在哪、从哪个方向进、张开多大」，而不是物体类别。
- 测试时，在当前场景里找 `P_i` 的最佳 SE(3) 对齐；对齐变换直接给出候选抓取 `ĝ_i`。因为模板是局部的、相对的，所以：
  - 物体平移/旋转 → 对齐跟着变，等变；
  - 背景/干扰物 → 局部模板和桌面平面去除，天然降权；
  - 未见物品 → 只要局部功能几何相似，模板可迁移；不像 6D 位姿网络那样依赖精确 CAD；
  - 人为干扰 → 每轮重新分割/对齐；物体被移动，模板跟着走；被遮挡，弃权。

但「搬图式」还不够，必须回答两个问题：

1. **这个候选抓取在几何上可行吗？** 用解析几何检查对跖接触、夹爪开度、接近 clearance、支撑/摩擦锥、碰撞、可达性。可行域 `F` 是显式定义的，不靠第二个网络打分。
2. **模板迁移误差有多大？** 用成功演示做留一校准，得到迁移误差 `e_i = d_SE3(ĝ_i, g_i)` 的经验分位数 `q`。如果候选的几何裕度 `m(ĝ)` 大于 `L_m(q+ε)`（`L_m` 是裕度函数的 Lipschitz 常数，`ε` 是感知不确定性），那么以至少 `1-α` 的概率，真实理想抓取落在以 `ĝ` 为心、半径 `q` 的球内，且整个球都在可行域内。这时才执行 `ĝ`；否则弃权。

这套东西的妙处是：**它把「抓取位姿估计」变成了「带覆盖保证的集合估计」**。我们不需要相信一个点预测，只需要相信一个可校准的误差球；球太大就弃权。弃权不是失败，弃权是把控制权还给 VLA——而 VLA 是唯一学习模型，合规。

## 2. 三个灵感词怎么落地

| 灵感词 | 落到哪里 | 明确不做什么 |
|---|---|---|
| **抓取位姿估计** | 从成功演示的夹爪闭合事件挖局部模板；FPFH+RANSAC+ICP 做 SE(3) 对齐；解析几何认证；输出候选抓取 + 误差球 + 弃权标志 | 不训 GraspNet/AnyGrasp/6-DOF GraspNet；不做 6D 物体位姿网络；不假设 API 有 depth；不硬编码 32 个任务的抓取位姿 |
| **分布外泛化** | 用局部相对几何获得平移/旋转/背景/干扰物不变性；用功能几何聚类覆盖未见实例；用保形/ACI 门控处理残差偏移；用抬升验证做在线标签 | 不靠「更多数据/更大模型」；不做测试时训练；不声称 conformal 在任意 shift 下都有覆盖保证 |
| **桌面操作** | 桌面平面 RANSAC、重力/支撑/摩擦锥、俯视/斜视抓取先验、180 s 预算、N 端口 CPU 轻量 | 不做移动底盘/全身控制；不做非桌面场景；不依赖力/触觉；不让 CAGE 抢 GPU |

## 3. 与第 10/11/12 轮的关系：保留、升级、剪枝

**保留**：

- FACT-VLA 的相位化 BC、CAC 柔顺执行、EGP 证据门控；
- GEO-RESIDUAL 的动作条件化残差、米制表面距离、编辑检测、`r_grasp` 滑移信号；
- CHUNK-SERVO 的 30 步规划 + 5 步伺服、相对目标、数字孪生标定、单任务通道；
- 官方 WLA 基座、33k 演示、单模型合规模式 C1/C2/C3。

**升级**：

- CHUNK-SERVO 的「目标检索」从**受器**扩展到**被抓物体**：第 12 轮检索的是「受器→夹爪」相对位姿；本轮检索的是「物体局部几何→夹爪」抓取模板。两者共用同一套演示索引和 SE(3) 工具，但目标不同。
- 从「点估计 + 伺服」升级到「集合估计 + 认证 + 弃权」：伺服负责把夹爪送到候选；认证负责判断该不该送。
- 从「开环抓取 + 事后恢复」升级到「抓取前认证 + 抬升验证 + 在线自适应」：抬升验证给出一个廉价的在线标签，驱动 ACI；这是第 12 轮没有的闭环。
- 从「人为干扰只做后验恢复」升级到「抓取阶段就重新分割/重新认证」：人手进入视野、物体被移动，CAGE 重新对齐；不确定就弃权。

**剪枝**：

- 不训第二个抓取模型/残差策略；
- 不做 6D 物体位姿网络（透明/反光/变形不可靠，且是第二个模型）；
- 不做 depth completion（API 没有 depth，且 completion 是第二个模型）；
- 不做 32 个任务各一套抓取位姿（不泛化，规则也不鼓励）；
- 不做力/触觉闭环（API 没有）；
- 不做 30 Hz 广域网重配准（抓取事件稀疏，异步预取即可）。

## 4. 核心形式化（简版；完整版在产物区）

设 `g = T_{W←E} ∈ SE(3)` 是夹爪位姿，`w` 是开度。演示 `i` 在夹爪闭合帧给出 `(g_i, w_i, o_i)`。把夹爪附近物体点云变换到夹爪系，得到模板 `P_i`。测试时对 top-M 模板做配准，得到候选 `ĝ_1..ĝ_M`，取 Fréchet 中位数 `ĝ`。

定义可行裕度 `m(g)`：对跖角、开度、接近 clearance、支撑/摩擦锥、碰撞、可达性六项的米制最小松弛；`m(g) ≥ 0 ⇔ g ∈ F`。

定义迁移误差 `e_i = d_SE3(ĝ_i, g_i)`（模对称群）。在留一校准集上取 `q_t = Quantile_{1-α_t}({e_i})`。若

```math
m(\hat g) \;\ge\; L_m\,(q_t + \varepsilon) + \delta_{\mathrm{safe}},
```

其中 `ε` 是双目/标定/分割的感知不确定性。若成立，则以至少 `1-α_t` 的概率，真实理想抓取 `g*` 落在 `B(ĝ, q_t)` 内；又因 `m` 是 `L_m`-Lipschitz，整个球（含感知膨胀）都在 `F` 内，故 `ĝ ∈ F`。执行 `ĝ`；否则弃权，执行 VLA 原计划。

`α_t` 用 ACI 更新：抬升验证失败 `fail_t=1` 时减小 `α_t`（更保守，`q_t` 变大）；成功时缓慢增大。对任意损失序列，有

```math
\left|\frac{1}{T}\sum_{t=1}^T fail_t - \alpha\right|
\;\le\; \frac{\alpha_{\max}-\alpha_{\min}}{\gamma T},
```

即（常数 `γ` 版本下）长期认证失败率收敛到目标 `α`，与分布如何漂移无关（只要 `fail_t` 可观测）。非对称更新的严格界更弱，产物区会单独说明；这是本轮最硬的统计保证，但不要把它外推到非对称版本。

## 5. 可证伪假设与止损

| 假设 | 判据 | 不过怎么办 |
|---|---|---|
| H1 模板可迁移 | 留一演示：中位误差 ≤5 mm/2°，90 分位 ≤10 mm/4°，recall@5 ≥0.8 | 放弃模板，退回 VLA + CHUNK-SERVO |
| H2 认证够准 | 标称集：覆盖率 `1-α±0.05`，认证精度 ≥0.95；仿真覆盖率 ≥0.5 时精度 ≥0.9 | 只做离线分析，不接管 |
| H3 OOD 门控有效 | 5 类 shift：认证精度 ≥0.85，覆盖率 ≥0.3；ACI 失败率 ≤`α+0.03` | 改为只在标称/位置轴启用 |
| H4 真机涨点 | 单任务通道 5 任务 A/B：≥3/5 首次抓取 +10pp；B 档不回归 >5pp | 不提交 CAGE 版本 |
| H5 延迟可接受 | CAGE 模块 p99 ≤50 ms（异步）；端到端 p99 ≤150 ms；timeout 不升 | 降 top-M、降采样、关认证 |

**止损线**：如果 H1 在 1 周内不过，说明演示局部几何的迁移误差已经大于抓取容差，CAGE 的整个前提不成立；这时不投真机时间，直接把本轮降级为「离线抓取可行性分析」。

## 6. 为什么是现在

- **数据**：33,276 条成功演示、169.28 h、32 任务，足够按任务/物体聚类出抓取模板；大多数演示至少一次闭合事件（P0 核实）。
- **基座**：官方 WLA-1.0 6B 已开源，24 GB 可微调；不需要从零训大模型，省下的算力可以投到执行层。
- **几何**：头双目已标定（基线 58.2526 mm，`fx≈282`），桌面平面/支撑/摩擦锥都是解析可算的；腕部相机可一次性标定。
- **统计**：保形预测和 ACI 都是有限样本/在线可证的方法，不需要额外的学习模型；抬升验证提供在线标签。
- **赛制**：单任务不计分通道允许低成本 A/B；5 类泛化轴正好对应 CAGE 的五个失效模式，可以逐轴测。
- **空白**：现有榜单头部都是开环 chunk + 大 VLA；没有人把「演示抓取模板 + 解析认证 + 保形门控」接进 VLA 的执行层。这是一个工程上可行、统计上有保证、规则上合规的空白。

## 7. 竞赛策略：把「抓取失败」从「插入失败」里拆出来

第 12 轮用 `q_t` 表示「失败发生在最后 3 厘米的比例」。本轮把它拆成两个可测量：

- `q_grasp,t`：失败发生在**成功抬升之前**的比例；
- `q_insert,t`：失败发生在成功抬升之后的比例。

优先级变成：

```text
priority_t = q_grasp,t * Δ_grasp / cost_t
```

- **A 档（抓取优先，先验）**：PlugInEthernet、DisconnectEthernet、Unlock、ZipUp、ArrangeTestTubes、OpenPillBottle、OrganizeStationery、HangCup、PlugCharger、StackCups、PaperCupStacking、StoreEarphones、PackPhone、OrganizePencilCase、SyringeWaterTransfer、ToolboxStorage、StoreRacket、StackBowls。共 18 个。
- **B 档（VLA 优先）**：FruitCollection、ColorArrangement、PlacePhotoFrame、OrganizeBookshelf、PickOutBatteries、OrganizeTools、ArrangePlates、PackDoll、FoldTowel、SpellRobot、ConveyorSorting、RemovePinnedNote、PackBag、FruitSorting。共 14 个。
- **C 档（观察）**：单任务通道里首次抓取成功率已经很高、或失败在早期语义/感知的任务；不投 CAGE 工程。

这张表是先验，不是结论。单任务通道每测 3–5 个任务更新一次 `q_grasp,t`。不要一次铺 18 个。

**5 类 OOD 轴的机制映射**：

| 轴 | CAGE 机制 | 残余风险 |
|---|---|---|
| 位置 | 局部模板 SE(3) 等变；对齐跟着物体走 | 物体被完全遮挡/出视野 |
| 干扰物 | 桌面平面去除 + 局部 ROI + 碰撞认证 | 干扰物与目标同色/接触 |
| 背景 | 局部几何 + 法线/深度，不依赖全局纹理 | 无纹理/透明背景 |
| 未见物品 | 功能几何聚类 + 局部模板迁移 | 几何差异过大，检索 inlier 低 |
| 人为干扰 | 每轮重新分割/对齐；不确定弃权；抬升验证 | 人手遮挡目标/快速移动 |

**收益算术（保守）**：若 18 个 A 档任务里 10 个的首次抓取 +10pp，且抓取后成功率约 0.7，则全局约 `10/32 × 0.7 × 10pp ≈ +2.2pp`；若 18 个都 +10pp，约 +3.9pp。人为干扰轴的收益与任务级抓取收益重叠，不能简单相加；保守合计 **+2–5pp**，不是 +10pp。这个量级才配得上 320 trials 的噪声（`SE≈2.4pp`）；要声称 +5pp 以上，必须有配对 A/B 和重复实验。

## 8. 一句话押注

**用 33k 成功演示挖出的抓取模板做 SE(3) 等变迁移，用解析几何给可行域、用保形分位数给误差球、用抬升验证驱动在线自适应门控——只在能证明 VLA 抓取不可行或 CAGE 显著更优时才接管，其余时间把控制权还给 VLA 和 CHUNK-SERVO。**

**当前方案最大的风险是：演示抓取模板与解析几何认证只在刚性、有纹理、深度可见的物体上成立；对透明/反光/可变形/小目标，门控会频繁弃权，CAGE 只增加延迟而不涨点。**

# 新循环 R1（总第 13 轮）产物 · GRASP-CAGE 技术报告

> 日期：**2026-11-01（UTC）**。对象：宇树 **UniBot 世界挑战赛**（G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API）。本报告是第 13 轮想法区「GRASP-CAGE」的工程化产物；不替换第 10 轮 FACT-VLA、第 11 轮 GEO-RESIDUAL、第 12 轮 CHUNK-SERVO，而是补上它们没有覆盖的**首次抓取**层。

## 0. 结论与边界

### 0.1 一句话结论

CHUNK-SERVO 把「最后 3 厘米」从 1 秒开环变成了 167 ms 闭环，但它默认物体已经在夹爪里；在 5 类泛化轴（位置、干扰物、背景、未见物品、人为干扰）下，**第一次抓取**才是更早的失效点。本报告把抓取位姿估计重新表述为「演示局部模板的 SE(3) 等变迁移 + 解析几何可行域 + 保形误差球 + 在线自适应门控」：只在误差球整个落在可行域内时接管 VLA，否则弃权并把控制权还给 VLA/CHUNK-SERVO。它不新增任何学习权重；按 C2（确定性控制器）解释，不违反单模型规则。

### 0.2 证据等级

| 等级 | 含义 | 本报告中的例子 |
|---|---|---|
| A | 官方文档、提交模板、数据集元数据、排行榜 JSON 直接核实；**本轮不重新检索，全部继承第 12 轮 2026-10-28** | 规则、API、33,276 eps、头双目基线 58.2526 mm、WLA `chunk_size=30` |
| B | 我们在公开数据/几何上做的分析，可复现 | 双目深度误差表、合成 1D 保形校验 |
| C | 设计假设，需 G8–G13 验证 | 模板误差 ≤5 mm/2°、认证精度 ≥0.9、真机 +10pp |

### 0.3 本轮不做什么

- 不做新的外部检索；不把未核实的新论文/新榜单数字写进方案。
- 不训第二个抓取网络（GraspNet/AnyGrasp/6-DOF GraspNet/RL residual）。

### 1.2 双目深度误差：为什么抓取不能只靠头双目（B 级）

头双目基线 `b=0.0582526 m`，焦距 `f≈282.37 px`。视差 `d = f b / Z`，深度误差：

```math
\sigma_Z = \left|\frac{dZ}{dd}\right|\sigma_d
= \frac{Z^2}{f b}\,\sigma_d .
```

取 `σ_d = 0.2 px`（乐观）和 `0.5 px`（现实）：

| 工作距离 Z | 视差 d | `Z²/(fb)` | `σ_Z` @0.2px | `σ_Z` @0.5px |
|---:|---:|---:|---:|---:|
| 0.4 m | 41.1 px | 9.73 mm/px | 1.95 mm | 4.86 mm |
| 0.6 m | 27.4 px | 21.9 mm/px | 4.38 mm | 10.94 mm |
| 0.8 m | 20.6 px | 38.9 mm/px | 7.78 mm | 19.45 mm |
| 1.0 m | 16.4 px | 60.8 mm/px | 12.16 mm | 30.40 mm |

**推论**：

1. 头双目在 0.4 m 近距、0.2 px 噪声下才接近 2 mm；在 0.6–1.0 m 的桌面工作距离，深度误差是 4–30 mm。拉链头、钥匙、试管、耳机等小目标不能只靠头双目。
2. 腕部近距（10–20 cm）是米制抓取的必要条件；但腕部没有内参，必须先做一次棋盘格/已知尺寸标定。标定不过（G0），腕部只做 2D 验证，米制抓取交给头双目 + 保守弃权。
3. 认证必须把深度/位姿误差 `ε` 显式膨胀进几何裕度；否则「看起来可行」的抓取在真机上会差 1–2 cm。

### 1.3 数据里到底有没有「抓取事件」？（P0 必须先查）

模板库的前提是能从演示中定位**夹爪闭合瞬间**。需要核实：

- HF 数据集的 `action` 是否包含夹爪维度；若包含，闭合事件 = 夹爪命令从开到闭的跳变。
- 若 `action` 不含夹爪，`observation.state` 是否含夹爪开度；若有，闭合事件 = 开度下降沿。
- 若两者都没有，腕部图像是否能看到夹爪闭合；可用图像差分/夹爪轮廓做弱检测，但可靠性下降。
- 闭合帧附近是否有头部双目/腕部图像；若没有，模板无法建。

**这是本轮第一个 kill switch**：如果数据里连闭合事件都定位不了，CAGE 的整个模板库不成立，应在一周内放弃，而不是先写系统。

## 2. 问题形式化

### 2.1 符号

| 符号 | 含义 |
|---|---|
| `W` | 机器人 base/world 系 |
| `E` | 夹爪（end-effector）系；`z_E` 为接近轴，`y_E` 为闭合轴，`x_E = y_E × z_E` |
| `g = T_{W←E} ∈ SE(3)` | 夹爪位姿；`p_g ∈ R³`，`R_g ∈ SO(3)` |
| `w ∈ [w_min, w_max]` | 夹爪开度（米） |
| `o_t` | 观测：4 路 RGB、关节、EE 位姿、夹爪、下身体、语言 |
| `D = {τ_i}` | 33k 成功演示轨迹集合 |
| `E_i = {(o_{i,k}, g_{i,k}, w_{i,k})}` | 演示 `i` 的抓取闭合事件集合 |
| `P_i` | 以 `g_i` 为原点、在 `E` 系表达的局部物体点云模板 |
| `φ_i` | 模板的几何/颜色描述子 |
| `ĝ` | 当前场景的候选抓取（top-M 对齐后的 Fréchet 中位数） |
| `F` | 解析几何可行域：`F = {g : m(g) ≥ 0}` |
| `m(g)` | 米制可行裕度；`m≥0 ⇔ g∈F` |
| `d_SE3(g,h)` | 加权 SE(3) 距离，见 §2.3 |
| `e_i` | 留一校准的模板迁移误差 |
| `q_t` | 迁移误差的 `1-α_t` 分位数 |
| `L_m` | 裕度函数的 Lipschitz 常数 |
| `α_t` | 当前允许的认证失败率；ACI 在线更新 |
| `fail_t` | 第 t 次认证抓取是否在抬升验证中失败 |

### 2.2 目标

单次任务成功可以粗分解为：

```math
p_{\mathrm{task}} \;\approx\; p_{\mathrm{grasp}}\; p_{\mathrm{post}},
```

其中 `p_grasp` 是首次抓取并成功抬升的概率，`p_post` 是抓取后完成放置/插入/挂/叠的概率。第 12 轮的 CHUNK-SERVO 主要提升 `p_post`；本轮提升 `p_grasp`。

形式化地，CAGE 是一个带弃权的覆盖策略：

```math
\pi_{\mathrm{CAGE}}(o_t) =
\begin{cases}
\hat g_t, & \text{if } m(\hat g_t) \ge L_m (q_t+\varepsilon) + \delta_{\mathrm{safe}},\\
\varnothing \ (\text{abstain, execute VLA}), & \text{otherwise}.
\end{cases}
```

目标不是最大化认证数量，而是在认证精度 `p_C` 高于 VLA 基线 `p_V` 的前提下最大化认证覆盖率 `P(C)`：

```math
\mathbb E[Y] = P(C)\,p_C + (1-P(C))\,p_V,
\qquad
\Delta = P(C)\,(p_C - p_V).
```

因此：

- 若 `p_C ≤ p_V`，CAGE 不该接管；
- 若 `p_C > p_V`，覆盖率越大越好；
- 认证精度由几何可行性 + 保形误差球 + ACI 共同支撑；
- 弃权不是失败，弃权是保底。

### 2.3 SE(3) 距离与对称性

定义加权距离：

```math
d_{\mathrm{SE3}}(g,h)
= \sqrt{\|p_g-p_h\|^2 + r_g^2 \|\log(R_h^\top R_g)\|^2},
\qquad r_g = 0.1\ \mathrm{m/rad}.
```

`r_g` 是抓取局部 patch 的特征半径（约 10 cm）；它把旋转误差换算成抓取点附近的等效位移。

物体可能有对称群 `S`（圆柱绕轴旋转、平板 180° 翻转）。校准误差必须模对称：

```math
e_i = \min_{s\in S} d_{\mathrm{SE3}}(\hat g_i,\, g_i s).
```

`S` 由几何检测给出（圆柱轴、平面法线），不靠学习。若对称性检测不可靠，取 `S={I}`，此时校准偏保守（误差球更大，弃权更多），不会过于乐观。

### 2.4 分布外假设

测试分布 `P_test` 与演示分布 `P_train` 在五个轴上偏移：

1. **位置**：物体/受器的 SE(2) 位姿变化；
2. **干扰物**：额外物体进入桌面；
3. **背景**：桌面纹理/颜色变化；
4. **未见物品**：同一任务换物体实例；
5. **人为干扰**：人移动/遮挡/拿走物体。

CAGE 的机制不是「让 P_test 等于 P_train」，而是：

- 用**局部相对几何**消除全局位置/背景变化；
- 用**解析可行域**拒绝几何上不可能的抓取；
- 用**保形误差球**量化模板迁移的残差；
- 用**在线 ACI** 在 shift 下调整保守度；
- 用**弃权**把无法认证的样本交还给 VLA。

### 2.5 关键假设（以及违反时会发生什么）

| 编号 | 假设 | 违反时的后果 | 缓解 |
|---|---|---|---|
| A1 | 抓取阶段目标物体在头双目或腕部视野内 | 无法建模板/认证 | 弃权；VLA；主动转头重观测 |
| A2 | 目标物体近似刚体 | 模板几何失效 | 变形任务（FoldTowel）禁用 CAGE |
| A3 | 演示闭合事件可定位 | 模板库不成立 | P0 先查；不行则放弃 |
| A4 | 局部几何在实例间可迁移 | 迁移误差大 | 功能几何聚类；G8 止损 |
| A5 | 抬升验证可观测 | ACI 无标签 | 用夹爪开度/腕部图像/`r_grasp` 代理；仍不行则退回静态保形 |
| A6 | 相机/手眼标定在门限内 | 米制误差大 | G0；每机器人一次重投影校准 |
| A7 | 标称校准与测试可交换 | 保形覆盖失效 | ACI；按轴分层校准；保守 α |
| A8 | 认证失败率可用 `fail_t` 观测 | ACI 无反馈 | 只在单任务通道启用 ACI |

## 3. 算法：GRASP-CAGE

### 3.1 总架构

```text
                         ┌──────────────────────────────────────────────┐
                         │  Evaluator (N ports 8765..8765+N-1)          │
                         └───────────────────┬──────────────────────────┘
                                             │ obs / action chunk
                                             ▼
                         ┌──────────────────────────────────────────────┐
                         │  Per-port PolicyService (CPU)                │
                         │  ├─ VLA plan cache (30-step, async)          │
                         │  ├─ phase / grasp-event detector             │
                         │  ├─ CAGE: segmentation → retrieval → align   │
                         │  │        → certification → conformal gate   │
                         │  ├─ CHUNK-SERVO: 5-step visual servo         │
                         │  ├─ GEO-RESIDUAL: r_grasp / edit detection   │
                         │  └─ action adapter (WLA 54D → API 21D)       │
                         └───────────────────┬──────────────────────────┘
                                             │ async, batched
                                             ▼
                         ┌──────────────────────────────────────────────┐
                         │  Shared VLA server (GPU)                     │
                         │  UnifoLM-WLA-1.0 / VLA-0, 30-step chunk      │
                         └──────────────────────────────────────────────┘
```

- **唯一学习模型**：VLA。CAGE 没有学习权重；模板库是数据索引，认证是解析几何，门控是保形统计。
- **每端口独立**：CAGE 状态（模板缓存、α_t、blacklist）按端口隔离；模板索引只读共享。
- **异步**：CAGE 在 VLA 的 30 步 plan 到达后、夹爪闭合前预取；`get_action` 永不等待 CAGE。
- **可控接管**：CAGE 只改写夹爪闭合前后的短窗口；其余时间 VLA/CHUNK-SERVO 原样执行。

### 3.2 离线：抓取事件挖掘与模板库

#### 3.2.1 事件检测

对每条演示 `τ_i`：

1. 读取 `action` 与 `observation.state`，定位夹爪开度序列 `w_t`。
2. 闭合事件 = `w_t` 从 `> w_open_thresh` 降到 `< w_close_thresh` 的第一个帧；若动作里有夹爪命令，优先用命令的下降沿。
3. 取闭合帧 `k` 及前 2 帧/后 1 帧，选择双目/RGB 质量最好的一帧作为模板帧。
4. 记录 `g_i = T_{W←E}(k)`、`w_i = w(k)`、`task_id`、`episode_id`、`session_id`。

若一条演示有多次抓取（例如先抓工具再抓零件），保留所有闭合事件；用 `phase` 或时间间隔聚类。

#### 3.2.2 模板提取

```text
input:  episode i, event k, g_i, w_i
S      = stereo_reconstruct(episode, k)          # 头双目；腕部可选
S      = remove_table(S)                         # RANSAC 平面 + 法向约束
S      = remove_robot(S, joints(k))              # URDF 自滤波
S_obj  = crop_in_ee_frame(S, g_i, radius=0.10)   # 以夹爪为心，10cm 球/盒
S_obj  = remove_finger_points(S_obj, gripper_model, inflate=0.01)
P_i    = voxel_downsample(S_obj, 0.005)          # 5mm
P_i    = keep_largest_component(P_i)             # 去掉飞点
phi_i  = descriptor(P_i)                         # FPFH-VLAD + HSV + normal hist
library.add(task_id, phase, P_i, phi_i, g_i, w_i,
            symmetry_group(P_i), episode_id, session_id, quality)
```

**模板坐标系**：`P_i` 直接存在夹爪系 `E` 中。这里的「affordance 锚点」不是手工语义关键点，而是夹爪闭合瞬间的局部接触几何——由演示直接定义，不需要额外标注。这样测试时把 `P_i` 对齐到当前场景，得到的变换 `T_{W←E}` 就是候选抓取 `ĝ_i`，不需要显式的物体 6D 位姿。若为了聚类/对称性需要规范帧 `F`，则存 `T_{F←E}`，候选为 `ĝ_i = T_{W←F} T_{F←E}`；两种实现等价，默认用 `E` 系以降低复杂度。

**质量过滤**：

- 点数 `< 80`：丢弃（太小/遮挡）。
- 模板 patch 的深度无效比例 `>40%`：丢弃。
- 夹爪闭合时物体宽度 `w_i` 不在 `[w_min+2mm, w_max-2mm]`：丢弃（夹爪已到限位，抓取可能不牢）。
- 模板帧与闭合帧间隔 `>3` 帧：丢弃（运动模糊/时序不对）。

**对称性增强**：

- 圆柱：RANSAC 拟合轴，内点 `>70%` 且轴稳定 3 帧 → 绕轴旋转 `0/90/180/270°` 生成 4 个模板变体。
- 平板：拟合主平面，内点 `>70%` → 绕法线 180° 翻转生成 2 个变体。
- 其他：`S={I}`。
- 增强只增加模板数量，不增加学习参数；用 `variant_id` 去重，避免同一物理抓取被多次计数。

#### 3.2.3 描述子与索引

- **局部**：FPFH（33 维/点），对点云密度和全局位置不敏感。
- **全局**：FPFH-VLAD（k=32 码本，k-means 在 5% 子样本上离线拟合；无监督、无标签）拼接 16-bin HSV 直方图 + 10-bin 法线方向直方图；L2 归一化。
- **可选 C3**：用 VLA 同一 checkpoint 的视觉 encoder 对腕部 crop 取特征；只作为重打分项，不单独决策。若合规审查严格，关闭 C3，只用几何描述子（C2）。
- **索引**：FAISS IVF-Flat 或 scipy cKDTree；按 `task_id` 分片；每片 top-M 检索。
- **去重**：同一 `episode_id` 的相邻帧只保留一个事件；同一 `session_id` 的模板在校准 split 中整组排除，避免泄漏。

#### 3.2.4 留一校准

```text
scores = []
for held_out_episode in D:
    for event in held_out_episode.grasp_events:
        candidates = library.query(task(event), phi(event), topM=20,
                                   exclude_session=held_out_episode.session)
        aligned = [align(c, scene(held_out_episode, event)) for c in candidates]
        aligned = [a for a in aligned if a.fitness >= 0.3 and a.rmse <= 0.01]
        if len(aligned) == 0: continue
        g_hat = frechet_median(aligned)
        e = min_{s in S(event)} d_SE3(g_hat, g_event * s)
        scores.append(e)
q_grid[alpha] = quantile(scores, 1-alpha)   # 预计算 0.005..0.5 的网格
```

- 校准只使用**成功演示**；它度量的是「把一条成功演示的抓取模板迁移到另一条成功演示的场景」的误差，不是抓取成功率。
- 校准按任务分层；若某任务样本 `<200`，与同物体簇的任务合并，或对该任务禁用 CAGE。
- 验证集与校准集按 `session_id`/物体实例分组划分；相邻帧不跨 split。

### 3.3 在线：感知、检索、对齐

#### 3.3.1 抓取窗口检测

CAGE 不需要每帧运行，只在**夹爪即将闭合**时运行：

1. 从 VLA plan 中找第一个夹爪闭合索引 `close_idx`（命令跨阈值，方向以 P0 实测为准）。
2. 若 `close_idx` 在当前 chunk 或下一个 chunk 内，进入 `GRASP_WINDOW`。
3. 相位观察器（FACT-VLA/GEO-RESIDUAL）给出闭合/接触分数 `p_close`；若 `p_close < θ_p`，弃权（VLA 可能在做推/倒/放，不是抓）。
4. 若 VLA plan 中没有闭合（例如任务全程用吸盘/推），CAGE 不启用。

**仲裁**：`close_idx` 与 `p_close` 必须一致；不一致时宁可弃权。抓取窗口的 lookahead 约 1 s，正好覆盖 CAGE 的异步计算。

#### 3.3.2 分割与目标选择

```text
S = stereo_reconstruct(o_t)                 # 头双目；腕部可选
S = voxel_downsample(S, 0.005)
S = remove_table_plane(S, dist=0.005, normal_tol=20°)
S = remove_robot(S, joints=o_t.joints)      # URDF + 当前关节角
clusters = euclidean_cluster(S, tol=0.015, min_points=30)
clusters = [c for c in clusters if in_workspace(c, o_t)]
```

- **目标选择**：用 VLA 的 `g_VLA`（从 plan compose 出的闭合位姿）和模板描述子给每个 cluster 打分：
  ```text
  score(c) = w1 * exp(-d(g_VLA, c.center)/0.1)
           + w2 * max_j sim(phi(c), phi_j)
           + w3 * size_prior(c, task)
  ```
  取 top-2；对两者都跑 CAGE；选认证裕度更大的；若差距 `<2mm`，弃权。
- **干扰物**：不进入目标候选的 cluster 不丢弃，保留在 `S_obstacles` 里做碰撞检查；这样干扰物不会导致碰撞，只会导致弃权。
- **背景**：桌面平面移除；局部 patch 不使用全局纹理；颜色描述子权重降低（`w_color=0.1`），防止背景/桌布主导。
- **人为干扰**：GEO-RESIDUAL 的 `edit_score` 触发时，暂停 CAGE，等待 3 帧重新分割；若目标被手遮挡超过 30% 模板点数，弃权。

#### 3.3.3 检索

```text
phi_t = descriptor(target_cluster)
candidates = index[task_id].search(phi_t, k=20)
candidates = [c for c in candidates
              if width_compatible(c.w, target_width, tol=0.02)
              and scale_compatible(c, target_cluster, tol=0.25)]
if len(candidates) == 0 or min_dist > theta_retrieval:
    abstain("no template")
```

- `width_compatible`：模板闭合宽度与当前物体估计宽度差 ≤2cm；否则模板可能抓的是另一个部位。
- `scale_compatible`：模板 patch 的包围盒尺度与当前 cluster 差 ≤25%；防止把小物体模板套到大物体上。
- `theta_retrieval`：描述子距离阈值，由校准集的 95 分位确定。

#### 3.3.4 对齐

对每个候选模板 `P_j`：

1. 体素降采样到 5 mm；估计法线；计算 FPFH。
2. RANSAC 全局配准：对应点距离阈值 1 cm，最大迭代 50k，置信度 0.999；至少 3 个对应。
3. 点对平面 ICP：最大对应距离 2 cm，30 次迭代；收敛阈值 1e-6。
4. 质量：`fitness`（内点比例）≥0.3，`rmse` ≤1 cm；否则丢弃。
5. 候选 `ĝ_j = T_{W←E_j}`（模板存在 E 系）；若用规范帧，`ĝ_j = T_{W←F_j} T_{F_j←E_j}`。

**对称性处理**：

- 若模板有对称群 `S_j`，先对候选做 `ĝ_j s` 规范化到参考姿态，再聚合；否则对称变体可能把 Fréchet 中位数拉到物体内部。
- 若当前物体检测到对称性但模板没有，按当前对称群扩增候选，再聚合。
- 若对称性检测不稳定（3 帧内轴/平面变化 >10°），`S={I}`，并在 `ρ` 大时弃权。

#### 3.3.5 候选聚合

```text
G = [g_1, ..., g_M]                   # 对齐后的候选
w_j = fitness_j * exp(-rmse_j/0.01)   # 权重
g_hat = frechet_median(G, weights=w)
rho = weighted_median_j d_SE3(g_hat, g_j)
if rho > rho_max: abstain("ambiguous")
```

- `frechet_median` 用迭代加权平均：初始化 `g_hat = g_1`，重复 `g_hat ← g_hat · exp(Σ w_j log(g_hat^{-1} g_j)/Σw_j)`，直到收敛（≤10 次）。
- `ρ` 是候选分散度；它同时是「模板是否一致」的指标。`ρ_max` 由校准集的 90 分位确定。
- 校准误差 `e_i` 必须用**同一个聚合器**计算（不是 top-1），否则保形覆盖不匹配。

### 3.4 解析几何认证

#### 3.4.1 六项米制裕度

给定候选 `ĝ` 和场景点云 `S`，把 Dex1 夹爪几何（两指 + 掌）变换到 `ĝ`，计算：

1. **开度裕度** `m_width`：
   ```math
   m_{\mathrm{width}} = \min(w_{\mathrm{obs}} - w_{\min},\; w_{\max} - w_{\mathrm{obs}}),
   ```
   `w_obs` 是沿闭合轴 `y_E` 与物体表面的两个交点间距；若指间没有两个交点，`m_width = -∞`。

2. **对跖角裕度** `m_anti`：
   ```math
   m_{\mathrm{anti}} = r_g \cdot \min(\theta_{\max}-\theta_+,\; \theta_{\max}-\theta_-),
   ```
   `θ_±` 是两侧接触点法线与闭合轴 `±y_E` 的夹角；`θ_max=25°`；乘以 `r_g=0.1m` 换成米制弧长。

3. **接近 clearance** `m_clear`：沿 `z_E` 的接近锥（半径 `r_g`、长度 8 cm）内，夹爪/手指到最近 scene 点的距离减去 5 mm 安全量；若有穿透，取负值。

4. **碰撞裕度** `m_collision`：夹爪扫掠体积（从预抓取到闭合）到所有非目标点（含干扰物、桌面、机器人自身）的符号距离；负值表示穿透。

5. **支撑/摩擦裕度** `m_support`：
   ```math
   m_{\mathrm{support}} = \mu\, r_{\mathrm{contact}} - \|x_{\mathrm{com}} - x_{\mathrm{contact}}\|,
   ```
   `μ` 取 0.5–1.0（按物体材质先验，保守取 0.5）；`r_contact` 是接触 patch 的等效半径；`x_com` 是物体质心投影。若质心估计不可靠（透明/变形），该项置 0 并降级为布尔检查。

6. **可达性裕度** `m_reach`：对候选做 IK，取最小关节限位裕度（弧度）乘以特征连杆长度（0.2 m）；若 IK 无解，`m_reach=-∞`。

最终：

```math
m(\hat g) = \min\{m_{\mathrm{width}},m_{\mathrm{anti}},m_{\mathrm{clear}},
m_{\mathrm{collision}},m_{\mathrm{support}},m_{\mathrm{reach}}\}.
```

`m≥0` 当且仅当六项全部通过（零安全量）；实际执行要求 `m ≥ δ_safe`，默认 `δ_safe=2 mm`。

#### 3.4.2 感知不确定性的膨胀

观测几何 `Ŝ` 与真实几何 `S` 的偏差用 `ε` 表示（米制 + 旋转弧长）。两种等价做法：

- **几何膨胀**：把夹爪膨胀 `ε`、把物体表面内缩 `ε`、把障碍物外扩 `ε`，再算 `m`。
- **裕度扣减**：在观测几何上算 `m_obs`，用 `m_true ≥ m_obs - L_m ε`。

默认用几何膨胀（更直观）；`ε` 由双目深度协方差、手眼标定残差、分割边缘误差合成：

```math
\varepsilon = \sqrt{\sigma_Z^2 + \sigma_{\mathrm{cal}}^2 + \sigma_{\mathrm{seg}}^2}
+ r_g \sqrt{\sigma_{R}^2 + \sigma_{\mathrm{handeye}}^2}.
```

`σ_Z` 按 §1.2 表；`σ_cal≈2mm`、`σ_seg≈3mm`、`σ_R≈2°`、`σ_handeye≈1°` 是先验，需 G0 标定。`ε` 在 0.4–0.6 m 工作距离通常为 5–15 mm；这也是为什么小物体必须用腕部近距或弃权。

#### 3.4.3 Lipschitz 常数

`m` 是六个米制松弛的最小值。对抓取局部 patch 内的任意点 `x`（`||x||≤r_g`），位姿变化 `(Δp, ΔR)` 引起的位移满足：

```math
\|(p_g+R_g x)-(p_h+R_h x)\|
\le \|\Delta p\| + \|(R_g-R_h)x\|
\le \|\Delta p\| + r_g\|\Delta\theta\|
\le \sqrt{2}\,d_{\mathrm{SE3}}(g,h).
```

因此每个基于距离/弧长的松弛都是 `√2`-Lipschitz；最小值仍是 `√2`-Lipschitz。取保守 `L_m=2`。支撑项的 `x_com` 也随位姿刚体变换，同样满足；可达性项用关节角弧长换算，近似同阶。

#### 3.4.4 认证条件

```math
\boxed{\;m_{\mathrm{obs}}(\hat g) \;\ge\; L_m\,(q_t+\varepsilon) + \delta_{\mathrm{safe}}\;}
```

- `q_t` 是模板迁移误差的 `1-α_t` 分位；
- `ε` 是感知不确定性；
- `δ_safe` 是安全量（2 mm）；
- `L_m=2`。

满足则认证通过，执行 `ĝ`；否则弃权。

**保守性**：这是充分条件，不是必要条件。它会拒绝一些其实可行的抓取；G9 用覆盖率衡量保守程度。若覆盖率 `<20%`，优先降 `ε`（标定/腕部近距）或降 `δ_safe`，而不是放宽 `L_m`（放宽会破坏证明）。

### 3.5 保形门控与在线 ACI

#### 3.5.1 静态保形

校准分数 `{e_i}` 来自 §3.2.4 的留一迁移。对给定 `α`：

```math
q(\alpha) = e_{(\lceil (n+1)(1-\alpha)\rceil)},
```

即第 `⌈(n+1)(1-α)⌉` 个顺序统计量；若该索引超过 `n`，`q=∞`（弃权）。在可交换性下：

```math
\Pr(e_{\mathrm{test}} \le q(\alpha)) \ge 1-\alpha.
```

这是标准的 split conformal 覆盖保证；它保证的是「模板迁移误差不超过 `q`」，不是「抓取一定成功」。抓取成功还取决于几何模型、摩擦、夹爪动力学；解析认证负责前者，实验负责后者。

#### 3.5.2 在线 ACI

抬升验证给出 `fail_t ∈ {0,1}`（认证抓取是否在抬升时失败）。维护 `α_t`：

```math
\alpha_{t+1}
= \Pi_{[\alpha_{\min},\alpha_{\max}]}
\left(\alpha_t + \gamma_t\,(\alpha_{\mathrm{target}} - fail_t)\right),
\qquad
\gamma_t =
\begin{cases}
\gamma_{\mathrm{up}}, & fail_t=1,\\
\gamma_{\mathrm{down}}, & fail_t=0.
\end{cases}
```

- `fail_t=1` → `α_t` 减小 → `q_t` 变大 → 更保守；
- `fail_t=0` → `α_t` 缓慢增大 → 更敢认证；
- 默认 `α_target=0.02`、`α_min=0.005`、`α_max=0.15`、`γ_up=0.05`、`γ_down=0.002`。
- 非对称更新：失败时快速收紧，成功时慢慢放松；避免把失败率「学习」到 10%（合成实验显示，`α_target=0.1` 会放松过头）。
- 冷启动：前 `N_warm=20` 次认证抓取用 `α_0=0.02` 的静态阈值；之后启用 ACI。
- 若 `fail_t` 不可观测（没有可靠的抬升验证），关闭 ACI，只用静态 `α=0.02`。

**长期界（常数 γ 版本）**：令 `ℓ_t=fail_t`，未裁剪更新满足

```math
\sum_{t=1}^T (\ell_t-\alpha)
= \frac{\alpha_1-\alpha_{T+1}}{\gamma},
```

因此

```math
\left|\frac{1}{T}\sum_{t=1}^T \ell_t-\alpha\right|
\le \frac{\alpha_{\max}-\alpha_{\min}}{\gamma T}.
```

投影裁剪只会把 `α` 拉回区间，长期界多一个同阶项。这个界对任意损失序列成立，不要求分布平稳；前提是 `fail_t` 可在线观测。它控制的是「认证抓取的失败率」，不是任务成功率，也不是「未认证样本」的失败率。

**非对称更新的边界**：实际使用的 `γ_up≠γ_down` 没有同一形式的无偏界；`γ_t` 变化时只能得到加权平均的界，不能直接推出未加权失败率。工程上用「经验失败率 + 分组 bootstrap + 保守 α_target」监控，不把非对称版本当成定理。若需要严格界，退回常数 `γ` 的对称更新。

#### 3.5.3 弃权后的行为

| 情况 | 行为 |
|---|---|
| 未认证，VLA 抓取几何可行 | 执行 VLA 原计划；CAGE 只记录 |
| 未认证，VLA 抓取几何不可行 | 执行 VLA 原计划（保底），或安全 hold；不强行 CAGE |
| 认证通过，VLA 抓取不可行 | 执行 CAGE 候选；抬升验证 |
| 认证通过，VLA 抓取可行但 CAGE 更优 | 保守模式：不接管；激进模式：接管（见 §3.6） |
| 感知失败/无模板/多目标歧义 | 弃权；VLA |
| 人为干扰/目标被遮挡 | hold；重新观测；超时则 VLA |

### 3.6 执行与仲裁

#### 3.6.1 提取 VLA 抓取

WLA 输出相对 EE 动作；按第 12 轮 adapter 先 compose 成 base 系绝对位姿序列，取 `close_idx` 处的 `g_VLA` 和夹爪命令。若无法提取（动作格式/帧不匹配），保守模式无法比较 `m_VLA`；此时只在 CAGE 认证通过且语义一致性检查通过时接管，否则弃权。

#### 3.6.2 仲裁规则

**保守模式（默认）**：

```text
if g_VLA extractable and m_VLA >= delta_safe:
    execute VLA grasp            # 不接管
elif CAGE certified:
    execute CAGE grasp
else:
    execute VLA grasp            # 保底
```

只修「VLA 抓取几何上明显不可行」的情况（撞桌、超开度、对跖角太差、IK 无解）。这让 CAGE 的干预最小化，风险最低。

**激进模式（消融）**：

```text
if CAGE certified and m_CAGE >= m_VLA + Delta_m:
    execute CAGE grasp
else:
    execute VLA grasp
```

`Δ_m=5mm`。激进模式可能涨点更多，也可能与 VLA 的语义意图冲突；只在仿真和单任务通道通过后启用。

**语义一致性检查**：无论哪种模式，CAGE 候选必须与 VLA 的抓取点/物体 cluster 一致（描述子相似度、空间距离）；否则弃权。防止 CAGE 抓了旁边的干扰物。

#### 3.6.3 预抓取、闭合、抬升

```text
g_pre = g_hat * exp(-d_pre * e_z)     # 沿接近轴后退 5cm
servo_to(g_pre)                        # CHUNK-SERVO PBVS；腕部 IBVS 可选
servo_to(g_hat)                        # 最后 1-2cm 降速；限幅 1cm/块
close_gripper()                        # 监测开度/速度
if width_stall < w_min + 2mm: fail     # 没夹到东西
lift(3-5cm)                            # 慢速
if r_grasp indicates object follows: success
else: fail
```

- **闭合检测**：夹爪开度在闭合后 300 ms 内是否停在物体宽度附近；若继续闭合到限位，说明没夹到。
- **抬升验证**：用 GEO-RESIDUAL 的 `r_grasp`（物体随夹爪刚性运动假设的残差）；若残差突增，滑移/没夹住。腕部图像可做辅助（物体是否随夹爪移动）。
- **失败重试**：打开、后退、blacklist 当前模板；尝试下一个候选（top-M 中的下一个）；最多 1 次重试；再失败则 VLA 或安全放弃。
- **成功交接**：把物体位姿/夹持状态传给 CHUNK-SERVO；后续运输/插入由第 12 轮负责。
- **超时**：抓取阶段最多 15 s；超时放弃，避免 180 s 预算被一个抓取耗尽。

#### 3.6.4 状态机

```text
IDLE
  └─ grasp window ──▶ SEGMENT ──▶ RETRIEVE ──▶ ALIGN
                                                │
                          ┌─────────────────────┤
                          ▼                     ▼
                      CERTIFY                ABSTAIN ──▶ VLA
                          │
              ┌───────────┴───────────┐
              ▼                       ▼
          SERVO_PRE ──▶ CLOSE ──▶ LIFT_VERIFY
                                      │
                          ┌───────────┴───────────┐
                          ▼                       ▼
                      HANDOFF                  RETRY/FAIL
```

每个状态有超时；任何异常 → 返回上一组合法 chunk 或安全 hold；绝不返回 NaN/错误形状。

### 3.7 回退层级

```text
1. CAGE certified + VLA grasp infeasible/absent  → CAGE grasp
2. CAGE certified + aggressive mode + margin gain → CAGE grasp
3. CAGE not certified                             → VLA original plan
4. CAGE perception/alignment failure              → VLA original plan
5. VLA plan unavailable/timeout                   → last valid chunk or safe hold
6. Repeated CAGE failure                          → blacklist task/template; VLA only
7. Human edit / occlusion                         → hold; re-observe; VLA
```

回退不是失败；它保证 `get_action` 永远返回合法动作，且 CAGE 不会把系统拖垮。

### 3.8 完整伪代码

```python
class GraspCagePolicy:
    def __init__(self, vla, template_index, servo, verifier, cfg):
        self.vla = vla
        self.index = template_index          # read-only, shared
        self.servo = servo
        self.verifier = verifier
        self.cfg = cfg
        self.alpha = cfg.alpha0              # e.g. 0.02
        self.fail_count = 0
        self.cert_count = 0
        self.blacklist = set()
        self.pending = None                  # async CAGE result
        self.executor = ThreadPoolExecutor(max_workers=2)

    def get_action(self, obs):
        # plan cache 维护 plan_idx 与 chunk 推进；这里只展示抓取接管逻辑
        plan = self._get_plan_async(obs)
        if plan is None:
            return self._safe_hold(obs)

        close_idx = detect_gripper_close(plan)
        if close_idx is None or not self._phase_agrees(obs, close_idx):
            return self._chunk(plan, 0, self.cfg.H_c)

        # prefetch CAGE during approach; never block get_action
        if self.pending is None and self._time_to_prefetch(close_idx):
            self.pending = self.executor.submit(self._run_cage, snapshot(obs), plan, close_idx)

        if self.pending is not None and self.pending.done():
            result = self.pending.result()
            self.pending = None
            if result.close_idx != close_idx:
                return self._chunk(plan, 0, self.cfg.H_c)   # stale result
            if result.certified and self._arbitrate(result, plan, close_idx):
                return self._cage_chunk(result, plan, close_idx)

        # default: VLA plan unchanged
        return self._chunk(plan, 0, self.cfg.H_c)

    def _run_cage(self, obs, plan, close_idx):
        clusters = self._segment(obs)
        target, obstacles = self._select_target(clusters, plan, close_idx)
        if target is None:
            return CageResult.abstain("no target")

        candidates = self.index.search(obs.task_id, descriptor(target), topM=self.cfg.M)
        if not candidates:
            return CageResult.abstain("no template")

        aligned = []
        for c in candidates:
            a = align(c, target, obs)
            if a.fitness >= self.cfg.fit_min and a.rmse <= self.cfg.rmse_max:
                aligned.append(a)
        if not aligned:
            return CageResult.abstain("alignment failed")

        g_hat, rho = frechet_median(aligned, weights=[a.score for a in aligned])
        if rho > self.cfg.rho_max:
            return CageResult.abstain("ambiguous")

        m = margin(g_hat, target, obstacles, obs)
        q = self.q_grid[self.alpha]
        eps = perception_uncertainty(obs)
        if m < self.cfg.Lm * (q + eps) + self.cfg.delta_safe:
            return CageResult.abstain("not certified", m=m, q=q)

        return CageResult.certified(g_hat, m=m, q=q, rho=rho,
                                   target=target, obstacles=obstacles,
                                   obs=obs, close_idx=close_idx)

    def _arbitrate(self, result, plan, close_idx):
        g_vla = extract_vla_grasp(plan, close_idx)
        if g_vla is None:
            return True
        m_vla = margin(g_vla, result.target, result.obstacles, result.obs)
        if self.cfg.mode == "conservative":
            return m_vla < self.cfg.delta_safe
        return result.m >= m_vla + self.cfg.Delta_m

    def on_grasp_result(self, success, result):
        if not result.certified:
            return
        self.cert_count += 1
        fail = 0.0 if success else 1.0
        if self.cert_count <= self.cfg.N_warm:
            return
        gamma = self.cfg.gamma_up if fail > 0 else self.cfg.gamma_down
        self.alpha = clip(self.alpha + gamma * (self.cfg.alpha_target - fail),
                          self.cfg.alpha_min, self.cfg.alpha_max)
```

### 3.9 复杂度、内存、延迟

#### 3.9.1 离线

| 步骤 | 复杂度 | 估算 |
|---|---|---|
| 事件检测 | O(T) | 33k episodes × 数百帧；分钟级 |
| 双目重建/分割/FPFH | O(N log N)，N≈10k | 每条事件 ~0.1 s CPU；33k × 0.1 s ≈ 1 h |
| 模板库构建 | O(M log M) | 33k–60k 模板；分钟级 |
| 留一校准 | O(E × M × R) | E≈33k，M=20，R=50k RANSAC；可并行，数小时 |
| 存储 | 模板 256 点 × 3 × 4B + 描述子 | 33k × ~3.3 KB ≈ 110 MB；索引 ~20 MB |

#### 3.9.2 在线

| 步骤 | 复杂度 | 估算（CPU） |
|---|---|---|
| 点云降采样/平面/聚类 | O(N log N)，N≈5k | 5–15 ms |
| FPFH | O(N log N) | 5–10 ms |
| 检索 | O(log M) | <1 ms |
| 对齐（M=10） | O(M × (R + I × N)) | 20–80 ms（C++/Open3D）；Python 100–300 ms |
| 认证（6 项） | O(N + IK) | 5–15 ms |
| 总计 | — | 目标 p99 ≤50 ms（C++/降采样/top-3）；Python 需异步 |

**异步策略**：

- VLA plan 提前 1 s 到达；CAGE 在 `close_idx` 前 0.5–1.0 s 启动。
- 若 CAGE 未在窗口内完成，跳过本次接管，VLA 原计划执行；不阻塞。
- 每端口一个 CAGE worker；共享模板索引只读；内存映射/COW。
- 不在 30 Hz 循环里做重配准；只在抓取窗口做一次。

#### 3.9.3 内存

- 模板库：~110 MB；
- 索引：~20 MB；
- 每端口缓存：点云/描述子/候选 <50 MB；
- 无学习权重；VLA 在共享 GPU 服务器。
- 总 CPU 内存 <1 GB/端口；N 端口线性增长，但模板库共享。

### 3.10 实现细节与边界情况

| 项 | 选择 | 备注 |
|---|---|---|
| 点云库 | Open3D（原型）/ PCL C++（低延迟） | FPFH/RANSAC/ICP 都有 |
| 双目 | OpenCV StereoSGBM + WLS 滤波 | 头双目已 rectified；无效视差置 NaN |
| 桌面平面 | RANSAC + 法向约束 | 法向与重力夹角 <20° |
| 自滤波 | URDF 碰撞点云 + 当前关节角 | 去掉机器人自身点 |
| 夹爪模型 | Dex1 两指 + 掌，膨胀 5 mm | 认证碰撞 |
| 聚类 | 欧氏聚类 1.5 cm，min 30 点 | 桌面小物体 |
| 描述子 | FPFH-VLAD + HSV + normal hist | 颜色权重 0.1 |
| 对称性 | 圆柱 RANSAC / 平面拟合 | 不稳定则 `S={I}` |
| 标定 | 腕部棋盘格 + 手眼；头双目重投影 | G0 |
| 多目标 | top-2 都认证，取裕度大者 | 差距 <2 mm 弃权 |
| 透明/反光 | 双目无效 → 腕部 2D；无米制则弃权 | 不硬做 |
| 变形 | 模板 RMSE 高/多帧不一致 → 弃权 | FoldTowel 禁用 |
| 人手 | edit_score + 遮挡比例 | 遮挡 >30% 弃权 |
| 标定漂移 | 重投影 >5 px → 关 CAGE | 每机器人一次 |
| 网络 | CAGE 本地 CPU；VLA 异步 | 不增加 websocket 负担 |
| 安全 | 工作空间盒、限速、限幅、最大重试 | 见 §7 |

**边界情况处理**：

- **目标被夹爪自身遮挡**：模板 patch 的点被手指挡住 >30% → 弃权；或用腕部视角补点。
- **物体在桌沿/堆叠**：支撑/碰撞认证会拒绝悬空抓取；只允许从上方/侧面进入。
- **物体太薄**（纸片、便签）：双目无法给厚度；用腕部 2D + 边缘；认证降级为 2D，弃权优先。
- **物体太滑**：摩擦系数未知；`μ=0.5` 保守；若抬升验证频繁滑移，blacklist 该模板。
- **多机器人/多端口**：每端口独立 `α_t`、blacklist、模板缓存；模板索引只读共享；`reset()` 清空端口状态。
- **时钟/延迟**：CAGE 用观测时间戳对齐；VLA plan 的 `close_idx` 用动作索引，不用墙钟；避免网络抖动导致错位。

## 4. 正确性论证

### 4.1 命题 1：局部模板迁移的 SE(3) 等变性

**命题**：设场景点云 `S` 经刚体变换 `T∈SE(3)` 变为 `T·S`；若分割、FPFH 描述、RANSAC/ICP 配准都是刚体等变的，则 CAGE 的候选抓取满足

```math
\hat g(T\cdot S) = T\cdot \hat g(S).
```

**证明**：FPFH 是局部几何的相对量（法线夹角、距离比），对刚体变换不变；RANSAC 的对应点距离和 ICP 的点对平面残差都是刚体不变的；因此配准得到的 `T_{W←E}` 随场景左乘 `T`。Fréchet 中位数在左不变度量 `d_SE3` 下等变。取模板变换的复合即可。∎

**推论**：物体在桌面上的平移/旋转不会改变「物体局部坐标系里的抓取」，只会改变 `T_{W←E}`。位置/旋转泛化不是靠数据增强，而是靠表示。

**误差**：体素降采样（5 mm）破坏严格等变；误差上界约 `5/√12 ≈ 1.4 mm`（体素量化）。这是 `ε` 的一部分；G8 会测实际值。

### 4.2 命题 2：认证的几何可靠性

**假设**：

1. 真实理想抓取 `g*` 满足 `d_SE3(ĝ, g*) ≤ q`（由命题 3 以概率 `1-α` 给出）；
2. 裕度 `m` 是 `L_m`-Lipschitz；
3. 观测裕度 `m_obs` 与真实裕度满足 `m_true(g) ≥ m_obs(g) - L_m ε`（几何膨胀/扣减保证）；
4. 认证条件 `m_obs(ĝ) ≥ L_m(q+ε)+δ`。

**命题**：在上述条件下，对任意 `g∈B(ĝ,q)`，有 `m_true(g) ≥ δ > 0`，即 `g` 在真实几何中可行；特别地 `g*` 和 `ĝ` 都可行。

**证明**：由 Lipschitz 性，

```math
m_{\mathrm{true}}(g)
\ge m_{\mathrm{obs}}(g)-L_m\varepsilon
\ge m_{\mathrm{obs}}(\hat g)-L_m d(\hat g,g)-L_m\varepsilon
\ge m_{\mathrm{obs}}(\hat g)-L_m(q+\varepsilon)
\ge \delta.
```

∎

**边界**：这个命题证明的是「几何可行」，不是「抓取一定成功」。摩擦、夹爪动力学、物体质量分布、接触形变都不在 `m` 的模型里；这些由抬升验证和实验负责。`δ` 是安全量，不是成功概率。

### 4.3 命题 3：保形覆盖

**命题**：若校准误差 `e_1..e_n` 与测试误差 `e_{n+1}` 可交换，且

```math
q = e_{(\lceil (n+1)(1-\alpha)\rceil)},
```

则

```math
\Pr(e_{n+1} \le q) \ge 1-\alpha.
```

**证明**：在 `n+1` 个可交换分数中，测试分数排在第 `k` 位之后的概率至多 `k/(n+1)`。取 `k=⌈(n+1)α⌉`，则 `Pr(e_{n+1} > q) ≤ α`。∎

**推论**：`Pr(d_SE3(ĝ,g*) ≤ q) ≥ 1-α`。

**边界**：

- 校准集来自成功演示；测试物体可能更难；可交换性只是近似。OOD 下覆盖会掉，ACI 负责在线修正失败率，但不恢复 `g*` 的覆盖保证。
- 校准分数之间因模板重叠而不完全独立；分组划分（按 session）只能缓解，不能消除。报告必须给分组 bootstrap 的置信区间，而不是只报点估计。
- 若 `n` 太小（某任务 `<200`），`q` 的分位数不稳定；该任务禁用 CAGE 或合并到同物体簇。

### 4.4 命题 4：ACI 长期失败率界

**命题**：令 `α` 为目标失败率，`ℓ_t∈[0,1]` 为第 t 次认证抓取的失败指示，`α_{t+1}=α_t+γ(α-ℓ_t)`（未裁剪），则

```math
\left|\frac{1}{T}\sum_{t=1}^T\ell_t-\alpha\right|
\le \frac{\alpha_{\max}-\alpha_{\min}}{\gamma T}.
```

**证明**：令 `Δ_t=α_t-α`，则 `Δ_{t+1}=Δ_t-γ(ℓ_t-α)`。 telescoping：

```math
\Delta_{T+1}-\Delta_1
= -\gamma\sum_{t=1}^T(\ell_t-\alpha).
```

移项并取绝对值，`|Σ(ℓ_t-α)| = |Δ_1-Δ_{T+1}|/γ ≤ (α_max-α_min)/γ`。∎

**投影版本**：`α_t` 被裁剪到 `[α_min,α_max]` 时，投影是非扩张的；长期界多一个同阶项。实际使用中 `γ=0.05/0.002`，`T=320` 时界约 `(0.15-0.005)/(0.002×320)≈0.23`（用慢速率），偏松；因此不能把界当成逐任务保证，只能当成「长期不会系统性失控」的定性保证。报告中应同时给经验失败率和 bootstrap CI。

**关键**：这个界对任意 `ℓ_t` 序列成立，不要求分布平稳；但要求 `ℓ_t` 可观测。抬升验证是它的前提。若抬升验证不准，ACI 的标签就是错的，界不成立。

### 4.5 命题 5：接管的收益分解

**命题**：设 `C` 为认证事件，`p_C=E[Y|C]`，`p_V=E[Y|¬C]`（回退 VLA 的成功率），则

```math
\mathbb E[Y] = P(C)p_C + (1-P(C))p_V,
\qquad
\Delta = P(C)(p_C-p_V).
```

**推论**：

- 若 `p_C ≤ p_V`，CAGE 不该接管；
- 若 `p_C > p_V`，增大 `P(C)` 才涨点；
- 若认证失败有额外代价 `c`（时间、碰撞风险），则
  ```math
  \Delta = P(C)\left[(p_C-p_V) - (1-p_C)c\right],
  ```
  需要 `p_C-p_V > (1-p_C)c` 才值得。

**用途**：这个分解把「涨点」拆成两个可测量：认证覆盖率 `P(C)` 和认证精度 `p_C`。G9/G10 先测这两个，再谈任务成功率；不要直接跳到 320 trials。

### 4.6 保证的边界（必须写进论文/提交材料）

1. **几何模型是近似的**：摩擦锥、接触刚度、夹爪指垫形变、物体质量分布都简化了；`m≥0` 是必要条件，不是充分条件。
2. **保形覆盖是边际的**：`1-α` 是平均覆盖，不是每个任务/每个物体的条件覆盖；小样本任务可能严重欠覆盖。
3. **OOD 下交换性不成立**：ACI 控制认证失败率，不保证 `g*` 的覆盖；不能宣称「任意 shift 下 90% 覆盖」。
4. **校准误差 ≠ 任务成功**：模板迁移误差小，不代表抓取后能完成任务；`p_post` 由 CHUNK-SERVO/VLA 负责。
5. **对称性/分割错误会破坏认证**：错误的对称群会把候选拉到错误姿态；分割把干扰物当目标会认证一个错误物体。语义一致性检查和弃权是必要的。
6. **体素化/标定误差**：等变性是近似的；`ε` 的估计可能偏乐观；G0/G8 必须实测。
7. **ACI 的标签偏差**：抬升验证可能把「夹住了但滑移」判成成功，或把「物体卡住」判成失败；标签噪声会污染 ACI。

## 5. 分布外泛化的机制分析

### 5.1 五个轴逐一拆解

| OOD 轴 | CAGE 机制 | 可能失效的地方 | 观测指标 | 预期（C 级） |
|---|---|---|---|---|
| **位置** | 局部模板 + SE(3) 等变配准；不依赖全局坐标 | 物体移动太快/在观测与执行之间被移动；体素化误差 | 位置偏移下的迁移误差、认证覆盖率 | 最稳；应接近标称 |
| **干扰物** | 桌面平面去除；目标 top-2；碰撞认证包含干扰物 | 干扰物与目标重叠/同色；分割合并 | 干扰物注入下的目标选择准确率、碰撞拒绝率 | 中等；重叠时弃权 |
| **背景** | 局部几何；颜色权重 0.1；不依赖全局纹理 | 背景与目标局部几何相似（另一个杯子） | 背景替换下的检索 recall、认证精度 | 较稳；语义先验补 |
| **未见物品** | 局部模板迁移；功能几何（圆柱/圆环/把手/平板）聚类 | 新物体局部几何差异大；模板库无覆盖 | 留一物体 recall@5、迁移误差、弃权率 | 最弱；决定 CAGE 上限 |
| **人为干扰** | 每轮重新分割/对齐；edit_score 触发 hold；遮挡 >30% 弃权；抬升验证重抓 | 手遮挡目标；人快速移动；人把物体拿走 | 检测延迟、恢复率、误抓率 | 中等；安全优先 |

### 5.2 为什么局部几何能抗 OOD（以及不能）

**能**：

- 抓取本质上只依赖局部接触几何：手指贴在哪、从哪个方向进、张开多大。全局物体类别/背景/位置是无关变量。
- 演示模板把这个局部几何直接编码在夹爪系里；测试时配准的是同一个局部结构。这是一种**表示层面的 OOD 不变性**，不是数据增强的统计不变性。
- 解析认证进一步排除了「局部像但物理不可行」的候选（例如模板来自杯柄，但当前物体那个位置是空的）。

**不能**：

- 如果新物体的局部几何与模板差异大到 FPFH 配准失败，CAGE 没有可迁移的锚点；这时只能弃权。
- 透明/反光物体没有稳定深度，局部几何不存在；2D 颜色/边缘模板可以退而求其次，但无法做米制认证。
- 可变形物体的局部几何随状态变化；模板失效。
- 对称物体（杯子、瓶子）有多个等价抓取；如果对称性检测错误，Fréchet 中位数可能落在不可行区域。保守做法是 `S={I}` + 弃权，而不是猜对称。
- 人为干扰不是几何问题，是**时序/安全**问题；CAGE 只能检测「场景动了且不是我的动作解释的」，不能理解人的意图。

### 5.3 与第 12 轮 CHUNK-SERVO 的分工

```text
感知/语义：VLA（唯一学习模型）
抓取前：  CAGE（模板检索 + 认证 + 门控）
抓取后：  CHUNK-SERVO（相对目标 + 5 步伺服）
接触/恢复：GEO-RESIDUAL（r_grasp / edit_score）+ FACT-VLA（相位）
```

- CAGE 解决「抓不到/抓错位置」；CHUNK-SERVO 解决「抓到了但放不准」。
- 两者共用同一套演示索引和 SE(3) 工具，但目标不同：CAGE 检索「物体→夹爪」，CHUNK-SERVO 检索「受器→夹爪」。
- 两者都不新增学习模型；VLA 仍是唯一策略。
- 失败分诊：如果失败在抬升前，CAGE 负责；如果失败在抬升后，CHUNK-SERVO 负责。单任务通道用 `q_grasp/q_insert` 分开统计。

### 6.1 离线实验

#### 6.1.1 数据划分

| 划分 | 做法 | 目的 |

#### 6.1.2 指标

| 指标 | 定义 | 目标 |
|---|---|---|
| Recall@K | top-K 模板中存在几何有效锚点（误差 ≤ 容差）的比例 | ≥0.8 @K=5 |
| 迁移误差 | `d_SE3(ĝ, g_demo)` 的中位数/90 分位 | ≤5 mm/2°；≤10 mm/4° |
| 认证覆盖率 | 认证通过的测试抓取比例 | ≥0.5 标称；≥0.3 OOD |
| 认证精度 | 认证通过中「误差 ≤ 容差」的比例（离线）；仿真用实际抓取成功 | ≥0.95 标称；≥0.85 OOD |
| 校准误差 | 经验覆盖率 vs 名义 `1-α` | ±0.05 |
| 弃权率 | 未认证比例，按原因分解（无模板/配准失败/裕度不足/歧义） | 报告，不设单一目标 |
| OOD AUROC | 用非一致性分数区分标称/OOD episode | ≥0.8（辅助） |

#### 6.1.3 离线门 G8

- 中位迁移误差 ≤5 mm/2°；
- 90 分位 ≤10 mm/4°；
- Recall@5 ≥0.8；
- 认证精度 ≥0.95（离线，误差 ≤ 容差）；
- 认证覆盖率 ≥0.5（标称）。

不过 G8 → 不投真机；先改模板/描述子/对齐，或放弃。

### 6.6 合成 sanity check（B 级，非真机证据）

**目的**：在写系统前，用一维玩具模型验证「静态保形在 OOD 下会保守/失效，ACI 能恢复覆盖率，但收益受覆盖率上限约束」这一逻辑。它不是 3D 几何、不是抓取仿真、不是真机结果。

**模型**：

- 真实抓取误差 `e ~ N(0, σ²)`；容忍 `τ=10 mm`；
- 感知偏差 `b ~ N(μ_b, σ_b²)`，机器人以为的容忍是 `τ+b`；
- 观测裕度 `m_obs = τ+b-|e|`；
- 标称校准 `|e| ~ N(0,3²)`，n=50,000；`q(α)` 为 `1-α` 分位；
- 认证：`m_obs ≥ q(α)`；执行后成功当 `|e|≤τ`；弃权回退 VLA，成功率 `p_V=0.30`；
- ACI：`α_target=0.02`，`α_0=0.02`，`γ_up=0.05`，`γ_down=0.002`，`α∈[0.001,0.15]`（与 §3.5.2 的 `α_max=0.15` 一致，防止 ACI 放松过头）；每个场景 5,000 trials。

| 场景 | 静态覆盖率 | 静态精度 | 静态总体 | ACI 覆盖率 | ACI 精度 | ACI 总体 |
|---|---:|---:|---:|---:|---:|---:|
| 标称（σ=3, b~(0,1)） | 0.656 | 1.000 | 0.759 | 0.872 | 1.000 | 0.910 |
| 轻度 OOD（σ=6, b~(0,3)） | 0.383 | 1.000 | 0.568 | 0.547 | 0.999 | 0.683 |
| 严苛 OOD（σ=8, b~(-4,4)） | 0.106 | 0.998 | 0.374 | 0.130 | 0.994 | 0.390 |
| 极严苛 OOD（σ=10, b~(-6,5)） | 0.065 | 0.994 | 0.345 | 0.093 | 0.991 | 0.365 |

**解读**：

1. **静态保形偏保守**：标称校准的名义覆盖率是 98%，但认证还要同时满足 `m_obs≥q`；感知偏差 `b` 和误差分布把实际认证覆盖率压到 0.656；认证精度 1.0。
2. **ACI 能恢复覆盖率**：标称从 0.656 提到 0.872，总体从 0.759 提到 0.910；轻度 OOD 从 0.383 提到 0.547，总体从 0.568 提到 0.683。
3. **严苛 OOD 下覆盖率崩塌**：即使 ACI，覆盖率也只有 0.13/0.093；回退 VLA 占主导，CAGE 的增益很小。这验证了「OOD 泛化的上限由认证覆盖率决定」，不是由门控算法决定。
4. **精度保持高位**：所有场景 ≥0.99；门控在不确定时弃权，而不是硬抓。
5. **ACI 目标不能设 0.1**：早期用 `α_target=0.1` 时，ACI 会把阈值放松到失败率 10%，精度掉到 0.97–0.99；改为 0.02 + 非对称更新后，精度回到 0.99+。真实系统应把认证失败率目标设得远低于任务可接受失败率。
6. **玩具的局限**：一维、无分割、无 3D 配准、无摩擦；`b` 只是感知误差的粗糙代理。它只能验证门控逻辑，不能预测真机收益。

### 6.8 统计与报告规范

- **配对设计**：同一初始条件、同一任务、A/B 交替；报告配对差值，不只报两个平均值。
- **不确定性**：按任务/ session 分组 bootstrap；给 95% CI；5 次/任务只能看方向，不能宣称显著性。
- **多重比较**：5 个任务 × 多个指标；预先指定主指标（首次抓取成功率、任务成功率），其余为探索性；必要时 Holm 校正。
- **320 trials**：`p≈0.3` 时 `SE≈2.6pp`；`p≈0.25` 时 `SE≈2.4pp`。不要用 +1–2pp 做结论。
- **仿真**：≥100–200/条件；报告成功率、覆盖率、精度、碰撞率、p99；仿真只用于相对排序，不预测真机绝对值。
- **数据泄漏**：按 session/物体/背景分组；相邻帧不跨 split；模板库排除测试 episode 的相邻帧。
- **负结果**：如果认证覆盖率 <20%，报告「CAGE 不适用」而不是「门控有效但保守」。

### 6.9 什么结果会证伪本轮

1. **G8 不过**：留一迁移误差中位 >10 mm 或 Recall@5 <0.5 → 局部模板不可迁移，CAGE 的前提错。
2. **G9 不过**：认证覆盖率 <20% 或精度 <0.8 → 认证太保守/几何模型太差，接管没有意义。
3. **G10 不过**：OOD 精度 <0.7 → 门控在 shift 下失效，不能上线。
4. **G11 不过**：真机首次抓取没有 +10pp，或任务成功回归 → CAGE 不涨点。
5. **安全事件**：任何碰撞/人机接触 → 立即回滚，优先修安全。
6. **合规否决**：官方认定模板检索/认证是第二个模型 → 退回 C1 离线模式，或放弃在线接管。

### 9.2 四层执行栈

```text
语义/任务： FACT-VLA / VLA（唯一学习模型）
几何/接触： GEO-RESIDUAL（r_grasp / edit_score / 米制距离）
抓取：      GRASP-CAGE（模板 + 认证 + 保形门控）
抓取后：    CHUNK-SERVO（相对目标 + 5 步伺服）
```

这四层不是四个模型，而是**一个学习模型 + 三个确定性控制器/数据索引**。这是本程序对「单模型规则」的回应：不靠堆模型，靠把执行层做成可认证的闭环。

### 9.3 什么会让我们放弃 CAGE

- P0 发现数据里没有可靠的闭合事件；
- G8 迭代后仍 >10 mm 或 Recall@5 <0.5；
- G9 认证覆盖率 <20%；
- G11 真机无 +10pp；
- 合规否决；
- 安全事件。

放弃 CAGE 不等于放弃执行层：CHUNK-SERVO + GEO-RESIDUAL 仍是第 12 轮的有效方案；CAGE 只是在其上加的一层高风险/高回报的抓取认证。

## 11. 一句话押注

**用 33k 成功演示挖出的抓取模板做 SE(3) 等变迁移，用解析几何给可行域、用保形分位数给误差球、用抬升验证驱动在线自适应门控——只在能证明 VLA 抓取不可行或 CAGE 显著更优时才接管，其余时间把控制权还给 VLA 和 CHUNK-SERVO。**

**当前方案最大的风险是：数据里可能没有可靠的抓取闭合事件/腕部标定，或者演示局部几何的迁移误差已经大于抓取容差；如果是这样，模板库和误差球都建立在错误前提上，CAGE 只会增加延迟而不涨点。因此 P0 第一周必须先验证这两件事，再谈真机收益。**
