# 第 70 轮（承接第 69 轮「FLUID-RAS 不确定性二分交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「仿真到现实迁移」×「语音合成」）

> R69 把不确定性一分为二，让系统学会「问」：aleatoric 收紧，epistemic 主动交互消解，并用一条「流似然第二意见」补 R68 的缓变故障盲区。但 R69 悄悄押了两个未言明的假设：(a) **第二意见是独立的**——传感器残差通道与行为似然通道彼此正交；(b) **回答的分布是真实的**——问来的证据、训练用的交互数据代表真实人类。这两个假设恰好被本轮两个灵感击中：
> - **仿真到现实迁移**：策略、世界模型、标定先验、乃至 R69 的流似然，全部训在仿真里。sim-real gap 不是随机噪声，而是**有结构、可分解、可定位**的偏差；把它压成一个标量 ‖Δ‖，等于把「哪一块错了」这个最有用的问题扔掉。
> - **语音合成**：交互层的大量「人」其实是合成的人。TTS 既是**可控探针**（音高/语速/情绪/口音/噪声都可调），又是**共谋欺骗的温床**（表情与语音由同一生成器一起合成，天然自洽）。
>
> 核心命题：**provenance（来源）是被忽视的共同原因。两条「独立」通道若共享来源（同一仿真器家族、同一合成器、同一数据 cohort），它们的独立性是制造出来的；共同盲区会被误读为相互确认。R70 把来源提升为一等公民：所有证据带 lineage，独立性由来源重叠算出有效独立数 k_eff；sim-real gap 按类记账、按类定界；语音合成同时用作可控探针与共谋压力源。** 命名 **SIREN-RAS**（Sim-to-real Independence via Rehearsal Evidence Network）——也是塞壬的歌声：最危险的往往不是陌生的噪声，而是你自己仿真器唱出的、让你放松警惕的那首歌。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「测量还准吗」，R69 问「该向谁求证」，R70 问「**教我这一切的仿真器与合成器，自己可靠吗**」——追问的不是答案，而是答案的出身。

## 0. 直觉与动机

**灵感 1（仿真到现实迁移 → 现实落差是有结构的，不是标量）**
直觉：如果把 sim-real gap 当成一个标量 ‖Δ‖，λ 就只会在「整体不信任」与「整体信任」之间摆动，而且永远不知道该往哪补数据。但落差是可分解、可定位的：**动力学/接触**（Δ_dyn，改变可达集与接触力）、**感知/传感器**（Δ_perc，改变条件编码 z）、**交互/社会**（Δ_soc，改变对回答内容与韵律的解读）、**标定**（Δ_cal，已被 R68 的 COF 部分吸收）。四类对策略的影响路径不同，可用的校准手段也不同。R70 把 gap 变成一个**账本（ledger）**：每笔证据记来源，每类 gap 单独估计、单独进入风险界；能配对的片段用「配对回放」直接测，不能配对的用域分类器/分布距离估。关键直觉：**定位比缩小更便宜，也更诚实**——不知道差值多大时，先说清它是哪一类，比强行估一个总数更安全。

**灵感 2（语音合成 → 我们训练交互层用的是「合成的人」）**
直觉：R69 让系统学会「问」，但回答的分布从哪来？很大一部分来自 TTS、语音克隆、脚本化的人类模拟器。语音合成是一把双刃剑。**作为探针**：音高、语速、情绪、口音、噪声都是连续可调的旋钮，可以系统测试「系统是否把某段韵律当成某个意图」；同一句话换一组声音（re-voicing）就能检验结论是不是韵律伪影。**作为威胁**：如果表情、语气、措辞由同一个生成器联合合成，它们会天然自洽——而 R68/R69 赖以判断的「跨模态一致性」恰恰被满足。**一致性不等于真实性：合成器最容易生产的就是自洽。** 于是「看起来很真诚的合成人」可以比「矛盾的真实人」更容易骗过系统。

**灵感 3（两条腿长在同一个幻影身上 → 虚假独立性，本轮核心）**
直觉：R68 用传感器残差，R69 加一条行为似然第二意见，并假设二者正交。但如果这两条通道的训练数据都来自同一个仿真器、同一个语音合成器，它们的「独立」就是**制造出来的**。仿真器有某个偏差 → 残差通道偏；同一偏差也塑造了策略密度 → 似然通道也偏，而且偏得**一致**。于是两条通道同时对一个错误世界说「没问题」。这不是随机噪声，是**共同模式失效（common-mode failure）**。R69 的 k 个「正交证据源」若共享 provenance（来源家族），其有效独立数 k_eff 可能只有 1。主动交互「问到的一致」，可能只是同一个幻影的两个回声。

**灵感 4（域随机化 ≠ 来源多样化）**
直觉：domain randomization 常用「把仿真参数随机化」提升迁移，但随机的仍是**同一个仿真器家族**——它扩大了覆盖，却没有增加来源的正交性。覆盖降的是方差/aleatoric，正交降的才是共同模式。SIREN 因此把随机化预算拆成两笔：**覆盖（coverage）** 与 **正交（orthogonality）**，并主张对共同模式风险，第二笔才是有效投资。这也解释了为什么有些系统在「训练集覆盖很广」时依然在真实世界里犯同一类错：它只是把一个盲区铺得很开。

**灵感 5（韵律是证据，也是可伪造的出身信号）**
直觉：一句回答的**内容**与**韵律**可能来自不同 provenance：真人口述 vs 克隆音色、现场 vs 回放、自然情感 vs 合成情感。判断「这是人还是合成」本质上是一次**来源推断（provenance inference）**。系统绝不能让「听起来很自信的韵律」直接给内容加权——自信本身是最廉价、最可伪造的线索。SIREN 因此要求：声学层给出「来源置信度 + 欺骗指纹」，作为证据纪律的输入，而不是事后解释。

**灵感 6（不可辨识的边界 → 本轮必须自陈的负结果）**
直觉：如果故障完全落在所有通道**共享的来源支撑集**里（sim 与 real 的偏差恰好与仿真器先验一致、合成器与真人的某个共同偏差一致），那么所有通道的期望残差都为 0，**没有任何通道间不一致可供检测**。这不是工程没做好，而是**原理上不可辨识**。承认它，才能把「多来源冗余」与「同一来源更多冗余」区分开：前者能扩支撑集，后者不能。这条负结果会直接成为本轮最大风险的骨架。

## 1. 形式化定义（增量：定义 310–323）

**定义 310（SIREN-RAS 总览）** SIREN-RAS = (PGL, SGI, CPO, TRB, VSP, CSS, RAS-WM†)。四不变式：
(i) **来源强制标注**：每条证据/先验 e 必须带 lineage π(e)，缺失来源视为「最不可信来源」；
(ii) **独立性由来源计算，不由声明**：任何佐证必须满足 k_eff(π) ≥ k_min（定义 312、316）；
(iii) **合成锚定**：安全相关信念若 synthetic_share > τ_syn，必须由一条 provenance-disjoint 的真实通道锚定，否则保守退避（定义 318、322）；
(iv) **落差局部化**：迁移风险按分量成界，不用单一全局标量（定义 313、315）。

**定义 311（来源原子与 lineage）** 来源族 ℱ = {仿真引擎及版本, 真实站点/cohort, TTS 引擎及音色模型, 传感器驱动/固件, 标注者 cohort, 人类真人}。每条证据 e 的 lineage 为加权集合 π(e) ⊆ ℱ（权重为贡献质量）。两条证据 provenance-disjoint ⇔ π(e_i) ∩ π(e_j) = ∅。

**定义 312（来源重叠与有效独立数）** 重叠度 P_ij = |π_i ∩ π_j| / |π_i ∪ π_j|（Jaccard）。有效独立数（有效样本量形式）
k_eff = (Σ_i w_i)² / Σ_{i,j} w_i w_j ρ_ij，其中 ρ_ij ≥ P_ij 为同源误差相关下界（A99）。
特例：全部同源（P_ij=1）⇒ k_eff = 1；两两 disjoint（P=0）⇒ k_eff = n。**R69 的 k 是 k_eff 在全 disjoint 时的特例。**

**定义 313（结构化现实落差账本）** Δ_real(t) = (Δ_dyn, Δ_perc, Δ_soc, Δ_cal)。账本 L 逐片段记录 (segment, provenance, gap 分量及置信区间, 是否可配对, 采集成本)。Δ_cal 复用 R68 的 r_res；其余见定义 314。

**定义 314（配对回放估计 SGI）** 对可在仿真与真实中复放同一动作块 a_{t:t+H} 的片段：
Δ_dyn = d_F(ξ_sim, ξ_real)（Fréchet/DTW 轨迹距离，除以可达尺度归一化）；
Δ_perc = MMD(Φ(o_sim), Φ(o_real)) 或域分类器 AUC 映射；
Δ_soc = 对真实 cohort 与合成 cohort 的回答分布做联合距离（内容嵌入 + 韵律特征），取 Wasserstein；
Δ_cal 由 R68 残差给出。不可配对片段用重要性加权/域分类器给带偏估计，并标注「低可信」。

**定义 315（迁移风险界 TRB）** 设策略 π 在仿真上的风险 R_sim，gap 敏感权重 W = (w_dyn, w_perc, w_soc, w_cal)，迁移算子 T 的 Lipschitz 常数 L_T，则
R_real(π) ≤ R_sim(π) + L_T · ‖W ⊙ Δ_real‖ + coverage_penalty。
逐分量给出界，取最大者指导补数据；coverage_penalty 计入真实分布外状态。

**定义 316（来源条件证据纪律 PED）** 佐证条件由「k 个源一致」升级为「k_eff 个来源有效独立一致」：要求 k_eff ≥ k_min（默认 2）且拓扑上存在互相 disjoint 的锚定通道。若不满足 ⇒ 证据不足 ⇒ 退 FLUID（若 FLUID 仍不满足 ⇒ 退 R68）。

**定义 317（韵律可控探针 VSP）** 信息动作扩展语音控制 u = (pitch, rate, emotion, accent, noise)。问句 g_ask(u) 由冻结 LLM + TTS 解码。韵律条件 VoI：
VoI_u(g) = H(M|o) − E_{y(u)~p(·|g,u,o)}[H(M|o,y(u))]，
选 u* = argmax_u [VoI_u(g) − c_social(u) − c_phys(u)]，且 u 需过 C-RAS-WM 的社交/物理包络（不得用极端韵律诱发危险反应）。

**定义 318（合成份额与真实锚定）** 信念 b 的合成份额 s_syn(b) = 来自合成生成器（仿真器、TTS、脚本模拟器）的 provenance 质量 / 总质量。不变式：安全相关且 s_syn > τ_syn 的信念，必须有一条 provenance-disjoint 的真实锚点（真人/真实传感器/独立引擎）佐证，否则按定义 322 保守退避。

**定义 319（共合成欺骗 CSS）** 攻击者用单一生成器 G_adv 联合合成语音、面部、韵律，使跨模态一致性**按构造满足**。检测不得只靠一致性，必须依赖：(a) 生成器指纹/反欺骗声学特征；(b) 声称来源与实际检测来源的不匹配；(c) 细粒度物理/时序线索（呼吸、齿音、微表情时序）。形式化为：一致性探测器在 CSS 下的错误采纳率不随模态数下降（呼应定理 19）。

**定义 320（换声不变性 RVI）** 同一内容问句 q 在一组声音 V 下的决策 c 称为 V-不变，若 ∀v∈V 决策不变；翻转概率上界 ≤ 2·TV(P_v, P_v')·Lip_dec。RVI 是「结论非韵律伪影」的**必要非充分**条件。

**定义 321（共同模式不可辨识极限）** 令 S = ⋂_i supp(通道 i 的训练分布) 为共享来源支撑集。若故障 δ 的支撑完全落在 S 内，即对所有通道 i 有 E[e_i | δ] = E[e_i | 0]，则任何仅使用通道间不一致的检测器对 δ 的功效为 0。⇒ 只有引入 support-disjoint（不同来源族）的锚点才能改变可辨识性；同族内增加冗余无效。

**定义 322（SIREN 保守退避与风险缩放）** 记 U_gap = TRB 中的迁移不确定项（gap 界的后验宽度）。λ = λ_floor(U_ale + U_epi_unresolved + U_gap)。若 k_eff < k_min、s_syn > τ_syn 无锚、或 Δ_real 超阈 ⇒ λ 单调不降地钉到 R68 最保守档。⇒ 失败路径只会更安全。

**定义 323（证书 J_SIREN）** J_SIREN = (J_FLUID, provenance_coverage, k_eff, Δ_real 分量, s_syn, spoof_auc, transfer_bound, siren_ver)。Valid ⇔ Valid(J_FLUID) ∧ provenance_coverage ≥ τ_prov ∧ (k_eff ≥ k_min ∨ 已退避) ∧ transfer_bound ≤ τ_T ∧ 反欺骗门通过。

## 2. 关键算法骨架

```python
# IP-264 PGL：来源账本（每条证据强制带 lineage，缺失即降级为最不可信）
class ProvenanceLedger:
    def tag(self, evidence, lineage):            # lineage: {source_atom: weight}
        assert lineage, "无来源的证据按‘未知/最不可信’入账"
        return Evidence(evidence, lineage)
    def overlap(self, e_i, e_j):                 # Jaccard
        a, b = set(e_i.lineage), set(e_j.lineage)
        return len(a & b) / max(1, len(a | b))

# IP-265 SGI：结构化 sim-real gap（能配对就配对回放，否则带偏估计并标注）
def estimate_gap(sim_log, real_log, pairable):
    out = {}
    for seg in pairable:                         # 同动作块配对回放
        out['dyn']  = frechet(sim_log.traj(seg), real_log.traj(seg)) / reach_scale
        out['perc'] = mmd(embed(sim_log.obs(seg)), embed(real_log.obs(seg)))
        out['soc']  = wasserstein(sim_log.answers(seg), real_log.answers(seg))  # 内容+韵律
    out['cal'] = cof.residual_stats()            # R68 通道
    return {k: (v, bootstrap_ci(v)) for k, v in out.items()}

# IP-266 CPO：有效独立数（同源不重复计数）
def effective_independence(evidences):
    w = [e.weight for e in evidences]
    rho = [[max(ledger.overlap(e_i, e_j), rho_floor(e_i, e_j))
            for e_j in evidences] for e_i in evidences]   # rho_floor 由同源下界给
    num = sum(w) ** 2
    den = sum(w[i]*w[j]*rho[i][j] for i in range(len(w)) for j in range(len(w)))
    return num / max(den, 1e-9)                  # 全同源 -> 1；全 disjoint -> n

# IP-267 TRB：迁移风险界（逐分量，指导补数据）
def transfer_bound(risk_sim, gap, W, L_T, coverage_penalty):
    term = {k: L_T * W[k] * gap[k][0] for k in gap}
    return risk_sim + sum(term.values()) + coverage_penalty, term

# IP-268 VSP：韵律条件探针 + 换声不变性
def choose_probe(modes, o, voices):
    best = None
    for g in info_candidates(modes):
        for u in voices.controls():              # pitch/rate/emotion/accent/noise
            if not ras_wm.certify_info(g, u, o): continue
            if not budget.allow(g):              continue
            score = prosody_voi(modes, g, u, o) - social_cost(u) - phys_cost(u)
            if best is None or score > best.score: best = (g, u, score)
    return best if best and best.score > 0 else None   # 无利可图 -> FLUID/R68

def revoice_invariant(conclusion, q, voice_set):
    flips = sum(decide(conclusion, q, v) != decide(conclusion, q, v0) for v in voice_set)
    return flips == 0, flips / len(voice_set)

# IP-270 PED：来源条件证据纪律（k_eff 取代 k）
def provenance_discipline(evidences, k_min=2):
    k_eff = effective_independence(evidences)
    has_disjoint_anchor = exists_disjoint_pair(evidences)
    if k_eff >= k_min and has_disjoint_anchor: return 'accepted', k_eff
    return 'insufficient', k_eff               # -> 退 FLUID，必要时退 R68

# IP-271 SIREN 主闭环（继承 FLUID/R68，只在“证据可信度”处插入来源层）
def SIREN_round(M, obs):
    z, o = M.mtm.forward(obs)
    # 1) 落差账本 + 迁移界（离线/周期更新，不占实时主路径）
    gap = M.sgi.cached_gap()                     # (dyn, perc, soc, cal)
    _, term = M.trb.transfer_bound(M.risk_sim, gap, M.W, M.L_T, M.cov_pen)
    U_gap = M.trb.posterior_width(gap)
    # 2) FLUID 的不确定性二分照常
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    # 3) 证据必须带来源；独立性按来源算
    ev = [M.pgl.tag(r, r.lineage) for r in M.collect_evidence(o)]   # r: 残差/环一致/似然/回答
    if M.pgl.missing_lineage(ev):
        ev = [M.pgl.downgrade(e) for e in ev]    # 无来源 -> 最不可信
    status, k_eff = provenance_discipline(ev, k_min=M.k_min)
    # 4) 交互只在来源可支撑时进行；探针可带韵律控制
    g = None
    if U_epi > TAU_EPI and status == 'accepted' and not M.gap_suspect(term):
        g = M.vsp.choose_probe(modes, o, voices=M.voice_set)
    # 5) 合成锚定：合成份额过高且无独立真实锚 -> 不采信，退避
    if g is not None:
        ans_e = M.cia.execute(g)
        if M.pgl.synthetic_share(ans_e) > TAU_SYN and not M.pgl.has_real_anchor(ans_e):
            ans_e, status = None, 'insufficient'
    U_epi = M.cia.update_belief(modes, ans_e) if (g and ans_e) else U_epi
    # 6) 风险缩放：aleatoric + 未消解 epistemic + 迁移不确定 三者同向
    U_floor = U_ale + (U_epi if ans_e is None else 0.0) + U_gap
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if status == 'insufficient' or M.gap_suspect(term):
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, term))   # 回最保守
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 7) 来源审计 + 证书
    M.vqa_p.submit_async(ev, g, k_eff, gap, term)
    return k, lam, mode, (U_ale, U_epi, U_gap, k_eff)
```

## 3. 推导

先立三条本轮判据：
**A99（同源误差相关下界）** 若两条证据共享来源比例 P，则其误差相关 ρ ≥ P − ε_s（误差经共享潜在生成偏差分解）。
**A100（风险对 gap 的局部 Lipschitz）** 存在逐分量权重 W 使 |R_real − R_sim| ≤ L_T‖W ⊙ Δ_real‖。
**A101（来源对齐）** 声称来源与实际生成器一致；否则视为 A99 中的共享被迫取最大（P=1）。

**引理 19（来源重叠 ⇒ 误差相关；R69 佐证界须改用 k_eff）** 在 A99 下，若 n 条证据的平均两两重叠为 P̄，则 k_eff ≤ n / (1 + (n−1)P̄)。代入 R69 引理 18 的投毒上界，得单源欺骗率相关下的错误采纳率 ≤ δ_p · ρ^{k_eff − 1} + ε_σ。当 P̄→1 时 k_eff→1，指数保护完全消失。**系：R69 的「k 个正交源」在共享仿真器/合成器下会高估自身安全，SIREN 修正为按来源计数。**

**引理 20（换声不变性界）** 对有限声音集 V，判断翻转概率 ≤ min(1, 2·TV(P_v, P_v')·Lip_dec)。故 RVI 通过是「结论非韵律伪影」的必要条件；但若所有 v 由同一合成器生成，V 的支撑可能整体偏离真实韵律分布（A101），RVI 会给出**虚假的稳定**。这与引理 19 同源：稳定可能只是同族内的一致。

**引理 21（落差局部化的界更紧、更可行动）** 在 A100 下，逐分量界 max_k L_T W_k Δ_k ≤ 总界 L_T‖W ⊙ Δ‖，且前者指出最大贡献分量 k*。补数据/校准应投向 argmax 分量，因此局部化同时收紧证书与指导采集；全局标量只能收紧、不能指路。

**定理 18（SIREN 严格包含 FLUID，修正其未言明假设）** 在 A99–A101 下：
(i) **安全侧**：Valid(J_SIREN) ⇒ Valid(J_FLUID) ⇒ Valid(J_R68)；SIREN 的可信动作集只会是 FLUID 的（经来源门/合成门的）子集或等集，故风险不高于 FLUID。
(ii) **退化**：当 provenance 全 disjoint（k_eff=n≥k_min）、Δ_real 的估计置信区间含 0、且所有证据 s_syn ≤ τ_syn 时，SIREN 与 FLUID **逐指令相同**。故 R68 ⊂ FLUID ⊂ SIREN 构成严格包含链。
(iii) **增益**：当 k_eff < k_min 或 s_syn 超阈时，SIREN 会拒绝 FLUID 本会采信的「伪一致」，这是 FLUID 无法表达的保守；当引入 disjoint 真实锚点时，SIREN 又能在 FLUID 因过度保守而失败处恢复分辨率（resolution bonus）。
**姿态**：SIREN 不是又一个并列模块，而是把 FLUID 的**隐含假设显式化、可检验化、可定价化**。

**定理 19（共同模式盲区：可辨识性极限）** 在 A99/A101 与定义 321 下，若故障 δ 的支撑完全落在共享来源支撑集 S 内，则对所有通道 E[e_i|δ]=E[e_i|0]，任何只依赖通道间不一致的检测器对 δ 的检测功效 ≤ 显著性水平 α。系 1：**同族内增加冗余（更多同仿真器数据、更多同合成器音色）不改变可辨识性**；只有 support-disjoint 的真实锚点能改变 S。系 2：domain randomization 若仍在同一仿真器家族内，只降覆盖/方差风险，不降共同模式风险——与灵感 4 一致。
**这是本轮的负结果**：SIREN 不能凭空消除共同盲区，只能**如实标注它不可观测**，并优先投资来源多样化。

**定理 20（韵律探针的收益条件与欺骗边界）** 设回答的信息量随韵律 u 变化，则 prosody-VoI ≥ 0 当且仅当 u 改变「意图→回答」的判别性；若 u 只改变表面置信而不改变判别性（合成器可轻易做到「自信但无信息」），则 VoI_u → 0 而社交成本仍付，故 argmax 会正确拒绝。系：CSS 下（定义 319），一致性线索按构造满足，唯有生成器指纹/来源不匹配可提供非零检测信号——再次把「独立证据」问题归约到「独立来源」问题。

## 6. 本轮最大风险

**一句话**：SIREN 的全部保证押在「provenance 标签完整且诚实」上——一旦来源缺失、错标或被静默升级（仿真器/合成器版本漂移、克隆语音被冒名顶替为真人），k_eff 会被**高估**、迁移界会被**低估**，系统就会把「共同盲区」当成「独立确认」，**在最需要警惕的地方最自信**；而若故障完全落在所有通道共享的来源支撑集内，它在原理上不可辨识（定理 19），再多通道冗余也救不了——**最危险的不是仿真到现实的落差，而是你以为两条腿在走路，其实两条腿长在同一个幻影身上。**

**次级风险与缓解**：
1. **来源标注成为新的单点信任** → lineage 由生成管线自动签名（cryptographic provenance）+ 缺失即降级，绝不默认信任；
2. **反欺骗本身被攻破**（高质量克隆/对抗指纹） → 多检测器 + 真实锚点强制 + E308 红队，且安全决策永不单靠声学；
3. **TRB 保守导致效率下降** → 分辨率只从 provenance-disjoint 真实锚点恢复（resolution bonus），不用更小的 gap 估计换效率；
4. **TTS 探针诱发社交/安全副作用** → 定义 317 的社交/物理包络认证 + 定理 17 无突变继承；
5. **负结果被忽视**（团队只加同源冗余） → 证书 J_SIREN 显式记录 k_eff 与 provenance_coverage，把「不可辨识」变成可见的审计项，而非沉默的假设。

## 3. 关键算法伪代码

```python
# IP-264 PGL：来源账本（缺失来源即降级，绝不默认可信）
class ProvenanceLedger:
    def tag(self, evidence, lineage):
        assert lineage, "无来源证据按‘未知/最不可信’入账"
        return Evidence(evidence, lineage)
    def overlap(self, a, b):
        A, B = set(a.lineage), set(b.lineage)
        return len(A & B) / max(1, len(A | B))

# IP-265 SGI：结构化 gap（配对回放；离线/周期，绝不上实时主路径）
def estimate_gap(sim_log, real_log, pairable):
    g = {}
    for seg in pairable:
        g['dyn']  = frechet(sim_log.traj(seg), real_log.traj(seg)) / reach_scale
        g['perc'] = mmd(embed(sim_log.obs(seg)), embed(real_log.obs(seg)))
        g['soc']  = wasserstein(sim_log.answers(seg), real_log.answers(seg))
    g['cal'] = cof.residual_stats()
    return {k: (v, bootstrap_ci(v)) for k, v in g.items()}

# IP-266 CPO：有效独立数（同源不重复计数）
def effective_independence(ev, ledger):
    w = [e.weight for e in ev]
    rho = [[max(ledger.overlap(e_i, e_j), rho_floor(e_i, e_j))
            for e_j in ev] for e_i in ev]
    num = sum(w) ** 2
    den = sum(w[i]*w[j]*rho[i][j] for i in range(len(w)) for j in range(len(w)))
    return num / max(den, 1e-9)          # 全同源 -> 1；全 disjoint -> n

# IP-267 TRB：逐分量迁移界（指导补数据）
def transfer_bound(risk_sim, gap, W, L_T, cov_pen):
    term = {k: L_T * W[k] * gap[k][0] for k in gap}
    return risk_sim + sum(term.values()) + cov_pen, term

# IP-268 VSP：韵律条件探针（无利可图退 FLUID/R68）
def choose_probe(modes, o, voices):
    best = None
    for g in info_candidates(modes):
        for u in voices.controls():
            if not ras_wm.certify_info(g, u, o) or not budget.allow(g): continue
            score = prosody_voi(modes, g, u, o) - social_cost(u) - phys_cost(u)
            if best is None or score > best.score: best = (g, u, score)
    return best if best and best.score > 0 else None

# IP-270 PED：k_eff 取代 k 的来源条件证据纪律
def provenance_discipline(ev, ledger, k_min=2):
    k_eff = effective_independence(ev, ledger)
    ok = k_eff >= k_min and exists_disjoint_pair(ev)
    return ('accepted' if ok else 'insufficient'), k_eff

# IP-276 主闭环（继承 FLUID，在“证据可信度”处插入来源层）
def SIREN_round(M, obs):
    z, o = M.mtm.forward(obs)
    gap = M.sgi.cached_gap()                         # 离线/周期更新
    _, term = M.trb.transfer_bound(M.risk_sim, gap, M.W, M.L_T, M.cov_pen)
    U_gap = M.trb.posterior_width(gap)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    ev = [M.pgl.tag(r, r.lineage) for r in M.collect_evidence(o)]
    if M.pgl.missing_lineage(ev): ev = [M.pgl.downgrade(e) for e in ev]
    status, k_eff = provenance_discipline(ev, M.pgl, M.k_min)
    g = None
    if U_epi > TAU_EPI and status == 'accepted' and not M.gap_suspect(term):
        g = M.vsp.choose_probe(modes, o, M.voice_set)
    if g is not None:
        ans = M.cia.execute(g)
        if M.pgl.synthetic_share(ans) > TAU_SYN and not M.pgl.has_real_anchor(ans):
            ans, status = None, 'insufficient'
    U_epi = M.cia.update_belief(modes, ans) if (g and ans) else U_epi
    U_floor = U_ale + (U_epi if ans is None else 0.0) + U_gap
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if status == 'insufficient' or M.gap_suspect(term):
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, term))
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_p.submit_async(ev, g, k_eff, gap, term)
    return k, lam, mode, (U_ale, U_epi, U_gap, k_eff)
```

## 4. 推导

判据：**A99** 共享来源比例 P ⇒ 误差相关 ρ≥P−ε_s；**A100** |R_real−R_sim| ≤ L_T‖W⊙Δ_real‖；**A101** 声称来源=实际生成器，否则视为共享最大化（P=1）。

**引理 19（来源重叠 ⇒ 误差相关）** 平均两两重叠 P̄ 下 `k_eff ≤ n/(1+(n−1)P̄)`；代入 R69 引理 18，错误采纳率 ≤ `δ_p·ρ^{k_eff−1}+ε_σ`。P̄→1 时 k_eff→1，指数保护消失。系：R69 的「k 正交源」在共享仿真器/合成器下高估自身安全。

**引理 20（换声不变性界）** 翻转概率 ≤ `2·TV(P_v,P_v')·Lip_dec`；RVI 是必要非充分——若所有 v 同源，RVI 可能给出**虚假稳定**。

**引理 21（局部化界更紧）** `max_k L_T W_k Δ_k ≤ L_T‖W⊙Δ‖`，且指出最大贡献分量 k*，同时收紧证书与指导采集；全局标量只能收紧不能指路。

**定理 18（SIREN 严格包含 FLUID）** A99–A101 下：(i) Valid(J_SIREN)⇒Valid(J_FLUID)⇒Valid(J_R68)，可信动作集只为 FLUID 的子集/等集 ⇒ 风险不高于 FLUID；(ii) 全 disjoint、gap 置信区间含 0、s_syn≤τ_syn 时逐指令等于 FLUID ⇒ R68⊂FLUID⊂SIREN；(iii) k_eff 不足/合成超阈时 SIREN 拒绝 FLUID 会采信的「伪一致」，有 disjoint 真实锚点时又恢复 resolution bonus。

**定理 19（共同模式盲区/可辨识性极限）** 故障 δ 支撑在共享支撑 S 内 ⇒ 所有通道 E[e_i|δ]=E[e_i|0] ⇒ 任何仅靠通道间不一致的检测器功效 ≤ α。系 1：同族内加冗余不改变可辨识性；系 2：同族 domain randomization 只降覆盖/方差，不降共同模式。**负结果：SIREN 不能凭空消除共同盲区，只能如实标注其不可观测并优先投资来源多样化。**

**定理 20（韵律探针收益与欺骗边界）** prosody-VoI≥0 当且仅当 u 改变「意图→回答」的判别性；若 u 只改表面置信而无信息，则 VoI_u→0 而成本仍付，argmax 正确拒绝。系：CSS 下一致性按构造满足，唯有生成器指纹/来源不匹配提供非零信号——独立证据问题最终归约为独立来源问题。

## 7. 本轮最大风险

**一句话**：SIREN 的全部保证押在「provenance 标签完整且诚实」上——一旦来源缺失、错标或被静默升级（仿真器/合成器版本漂移、克隆语音冒名顶替为真人），k_eff 会被**高估**、迁移界会被**低估**，系统就会把「共同盲区」当成「独立确认」，**在最需要警惕的地方最自信**；而若故障完全落在所有通道共享的来源支撑集内，它在原理上不可辨识（定理 19），再多通道冗余也救不了——**最危险的不是仿真到现实的落差，而是你以为两条腿在走路，其实两条腿长在同一个幻影身上。**

**次级风险与缓解**：来源标注成为新单点信任（管线自动签名 + 缺源即降级）；反欺骗本身被攻破（多检测器 + 真实锚点强制 + E308 红队）；TRB 过度保守（分辨率只从 disjoint 真实锚点恢复）；TTS 探针诱导社交/安全副作用（定义 317 包络认证 + 定理 17 无突变）；负结果被忽视（J_SIREN 显式记录 k_eff/provenance_coverage，把不可辨识变成可见审计项）。
