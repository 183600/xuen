# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环第 2 轮；本轮灵感：「安全性」×「技能组合」）

> R69 把「不确定性」从刹车踏板变成了一句提问：把 U 拆成 aleatoric/epistemic，用流匹配呈现多峰动作，用 VoI 选信息动作去消歧。但它仍默认闭环是**一个**策略：一个流场、一个动作空间、一套模态分解、一次认证。真实机器人不长这样——它是一支**技能库**（抓、放、开抽屉、递物、避让、求助），每个技能在自己的包络里单独做过安全认证，再被在线拼成长任务。
>
> 拼接正是安全保证最容易断裂的地方。单技能证书都是**局部**的：`Safe(技能, 包络, 前提)`，从来不是「技能本身安全」。两个各自安全的技能首尾相接，可以在**没有任何单技能违规**的情况下产生全局不安全行为，原因至少有四类：(a) 前者后置条件不满足后者前提（前提缺口）；(b) 切换瞬间的暂态越出任何一个包络（接缝暂态）；(c) 两者共享同一份力/间隙/注意力预算（预算双花）；(d) 各自都「礼让」或都「优先」，合起来死锁或对撞（非组合性）。
>
> 本轮两个灵感正好咬合：
> - **安全性**：安全不是一个技能的属性，而是「技能 × 包络 × 假设」的三元关系，只在该包络内有意义；出包络，证书必须作废，不能外推。
> - **技能组合**：组合不是把证书相加，而是产生**新的、无人拥有的义务**——接缝义务。谁签字、谁监控、谁兜底，必须在组合层显式定义。
>
> 核心命题：**把安全认证从「单技能」提升到「接缝」：每个技能携带可检查的类型化契约；组合是一个带六条义务的部分算子；任何无法在预算内证明的接缝一律默认拒绝（default-deny），退回上一个已认证状态或 R69 的交互/保守。** 命名 **SEAM-RAS**（Safety-Envelope Algebra for Modular skills）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这些安全保证拼在一起还成立吗？接缝处谁签字？**」——组合不创造安全，它只忠实传播契约的诚实度。

## 0. 直觉与动机

**灵感 1（安全性是局部的 → 证书有作用域）**
直觉：人们习惯说「这个抓取策略是安全的」，这是范畴错误。任何安全认证都暗含一个包络（速度、力、间隙、负载、光照）和一组假设（世界静态、人不在场、传感器在校准内）。R68/R69 已经把「测量是否还准」「模态是否可信」做成了在线门，但**证书的作用域**仍被默认成全局。一个在 E_i 内证明过的技能，一旦被组合推进到 E_i 之外，证书不是「变弱」，而是**无效**。所以 SEAM 的第一条纪律是 scope guard：运行时先问「我现在还在证书覆盖的包络里吗」，而不是问「这个技能上次表现好吗」。

**灵感 2（技能组合 → 接缝是新的责任主体）**
直觉：单技能契约只描述「我自己从 P_i 出发、在 E_i 内、保证 G_i」；它根本没有义务描述「我从别人手里接过来的状态有多脏」。组合 A⊳B 需要六件单技能都不负责的事：前提是否被满足、残差是否在 B 的容忍球内、暂态走廊是否安全、切换是否连续、共享预算是否够、全局不变式是否仍成立。把这六条写成**接缝义务** `Obl(A,B)`，组合就成了一个**部分算子**：不满足就不许拼。工程上，这等价于把「接口设计」从软件工程搬进物理安全：接缝要有明确的前后置条件、误差预算和违约处理。

**灵感 3（非组合性 → 单技能安全的合取不是组合安全）**
直觉：`Safe(A) ∧ Safe(B)` 甚至加上 `P_B ⊆ G_A`，都推不出 `Safe(A⊳B)`。两条最干净的反例：其一，A、B 各自被认证为「占用 60% 的制动权限即可避免碰撞」，并行组合后需要 120%，而每个证书都「没撒谎」；其二，A、B 各自被认证为「对方先行时我礼让」，组合后双方无限礼让（活性失败）或都判定自己优先（对撞）。这说明安全不是可加的标量，而是一个**资源 + 时序 + 假设**的联合谓词。SEAM 不做「证书求和」，只做「义务逐条证明」。

**灵感 4（接缝 = 歧义聚集处 → 把交互预算花在刀刃上）**
直觉：R69 的 VoI 在所有时刻一视同仁地算「值不值得问」。但组合系统里，绝大多数时刻技能在自己的包络内稳稳运行，真正需要确认的只有**接缝谓词**：抓稳了吗？物体还在吗？人准备好了吗？抽屉真的空了吗？这些恰好是「下一条契约能否适用」的判断。于是本轮把 R69 的 MINT 从「对动作模态求 VoI」升级为「对**接缝谓词真值**求 VoI」：安全最脆弱的位置与 epistemic 不确定性最高的位置**同址**，交互预算按接缝风险加权，而不是均匀撒。这让 R69 与 R70 不是并列两层，而是同一个「不确定性—动作」闭环在**组合粒度**上的重参数化。

**灵感 5（契约是新的攻击面 → 组合会放大一个谎）**
直觉：R69 的风险是「不信模态分布」；R70 的风险是「不信技能契约」。若某技能的包络/后置条件被高估、谎报或投毒（把 5cm 间隙写成 8cm，把 80% 成功率写成 99%），**每个局部接缝检查都会通过**，因为检查只对照声明值；而组合会把这个技能用在许多接缝上，于是一处谎言被复制、放大成全局不安全。更隐蔽的是**预算双花**：两个技能各自合法地预支同一份紧急制动权限或同一段人类注意力。故 SEAM 必须交付：契约哈希绑定、后置条件**独立测量**（不采信自报）、资源干扰矩阵、以及「单契约不得自证」的审计纪律。

**灵感 6（默认拒绝的代价 → 安全性与可用性的显式 Pareto）**
直觉：最安全的三条规则是「不组合、不越界、不确定就停」，但它们会让系统几乎不可用。SEAM 不假装能消除这个张力，而是把它变成**显式旋钮**：接缝证明的置信阈值 τ_seam 越高越安全、越不活跃。由于组合数随技能数指数爆炸，不可能离线证明所有序列，只能**惰性认证 + 有限前瞻**：每次跨接缝前，只证明接下来 L 步可达的接缝；证不出就 hold/回退。默认拒绝保证「安全不受损」，代价是「可用性有损」，而这个代价必须被测量（E306），不能装作不存在。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（SEAM-RAS 总览）** SEAM-RAS = (SCT, SCA, SGO, SBA, SCS, MIT†, RAS-WM§)。四条不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **接缝默认拒绝**：任何未在预算内获得有效接缝证明（离线或在线）的跨越一律不执行，退回上一个已认证状态、hold 或 R69 保守/交互；
(iii) **证书作用域诚实**：技能证书仅在其声明包络 `E_i` 与假设集 `A_i` 内有效，越界即作废，禁止外推、禁止「上次通过」式继承；
(iv) **接缝预算守恒**：组合分配的安全预算（力/间隙/能量/时距/人类注意力）在干扰矩阵下必须 ⊑ 全局预算，禁止预算双花。

**定义 311（技能契约 SCT）** 技能 i 的契约 `C_i = (P_i, G_i, E_i, ρ_i, b_i, F_i, scope_i, h_i)`：前提集 `P_i`（状态谓词）、后置/保证集 `G_i`、认证包络 `E_i`（含假设 `A_i`）、后置残差上界 `ρ_i`（`d(x_τ, G_i) ≤ ρ_i`）、预算足迹向量 `b_i ∈ ℬ`、失效模式集 `F_i`、证书作用域 `scope_i`（可适用的状态/环境集合）、内容哈希 `h_i`。契约是**类型化、可检查、可绑定**的对象，不是一段自然语言承诺。

**定义 312（技能语义）** 技能 i 是一个受控 option `(I_i, β_i, π_i, T_i, E_i)`：初始集 `I_i ⊆ P_i`、终止谓词 `β_i`（成功或失败）、策略 `π_i`、转移关系 `T_i`。一次执行是一条停留在 `E_i` 内直至 `β_i` 的轨迹；离开 `E_i` 视为契约失效，而非「继续但降级」。

**定义 313（组合代数 SCA）** 组合算子：顺序 `A⊳B`、并行 `A⊗B`、兜底 `A⊔B`，均为**部分算子**。`A⊳B` 有定义当且仅当接缝 `σ_{A→B}` 满足义务集 `Obl(σ) = {O1..O6}`（定义 314）。`A⊗B` 额外要求包络非干扰与预算可行；`A⊔B` 要求兜底技能在 A 失败集 `F_A` 上仍满足其前提。

**定义 314（接缝与六条义务）** 接缝 `σ_{A→B} = (x_τ, Transfer, S_σ, I_σ)`：交接状态、切换映射、预认证走廊、接缝不变式。义务：
- **O1 前提蕴含**：`x_τ ⊨ P_B`（或对全部可达 `x_τ ∈ Reach(A)` 有 `G_A ⊨ P_B`）；
- **O2 残差受控**：实测残差 `ρ̂_σ = d(x_τ, G_A) ≤ e_B^max`（B 的认证初始误差球）；
- **O3 走廊包含**：切换暂态全部落在 `E_A ∪ E_B ∪ S_σ` 内；
- **O4 无扰切换**：`δ_σ = sup_t ‖d(Transfer)/dt‖ ≤ δ_max`，加驻留/迟滞以抑制颤振；
- **O5 预算可行**：`b_A ⊕ b_B ⊑ b_global`，`⊕` 计入干扰矩阵 `M`（定义 315）；
- **O6 全局归纳**：全局不变式 `I_G` 被每个技能步与每条接缝走廊保持（定义 321）。
`Obl` 全部满足时记 `A⊳B ↓`（有定义），否则 `↑`（拒绝）。

**定义 315（安全资源代数 SBA）** 资源向量 `b = (c_clear, f_force, E_energy, t_ttc, a_attn)`；`(ℬ, ⊕, ⊑)` 是**保守、次可加、非幂等**的半格：`b_1 ⊕ b_2 ⊒ b_1 + b_2`（干扰只增不减），`A⊕A ⊐ A`（重复执行有磨损/热累积），并带干扰矩阵 `M_{ij} ≥ 0`。可行当且仅当存在分配使 `Σ_i b_i + Σ_{i,j} M_{ij}·共享量 ⊑ b_global`。**人类注意力 `a_attn` 是预算分量**：R69 的信息动作会占用它，可能延迟紧急响应。

**定义 316（接缝证书 SCS）** `J_SEAM = (J_FLUID_1..n, {cert(σ_k)}, resource_witness, I_G_proof, contract_hashes, scope_coverage, compose_ver)`。`Valid ⇔` 每个单技能 `J_FLUID_i` 有效 ∧ 每条已执行接缝 `Obl` 有证明 ∧ 资源可行性见证有效 ∧ `I_G` 归纳证明通过 ∧ 契约哈希与部署一致 ∧ 作用域覆盖实际状态。

**定义 317（作用域守卫）** 每步检查 `x_t ∈ E_i ∧ x_t ∈ scope_i ∧ hash(deployed_i) = h_i` 且证书未过期（时延窗口内）。任一不满足 ⇒ 该技能证书作废，不得作为接缝证明的前提。

**定义 318（接缝治理器 SGO）** 运行时组件：(i) 跨越前验证 `O1, O2` 的**实测**版本；(ii) 监视 `O3` 走廊与 `O4` 暂态；(iii) 估计残差 `ρ̂_σ`；(iv) 预判违约时中止并插入恢复技能（定义 320）；(v) 全量记录到接缝日志。SGO 是否决核，不可被蒸馏/近似/跳过（沿用 R69 的「否决必须昂贵地可信」）。

**定义 319（接缝触发 VoI，MIT†）** 接缝谓词 `Q_σ`（「B 的前提在交接后仍成立吗」「切换成功了吗」「共享预算够吗」）。把 R69 的 MINT 目标改为 `VoI_σ(g) = H(Q_σ|o) − E_{y∼p(·|g,o)}[H(Q_σ|o,y)]`，选择 `g* = argmax [VoI_σ(g) − c(g)]`，并按接缝风险 `r_σ` 加权分配注意力：`a_attn(g*)` 计入预算。`VoI_σ ≤ c` 或预算不足 ⇒ 不交互，直接默认拒绝。

**定义 320（恢复技能与可恢复性）** 每个接缝配一个有限恢复集 `R_σ`（回退到上一认证状态、松手、撤离、求助）。恢复技能的契约也必须完整（前提/包络/预算/失效模式）；**中止本身是一个技能**，不是「什么都不做」。可恢复性：存在 `r ∈ R_σ` 使在预算内可从 `x_τ` 回到某个已认证状态且不违反 `I_G`；否则该接缝不可恢复，必须禁止进入。

**定义 321（全局不变式与归纳组合）** 给定 `I_G`（安全集），组合安全要求：(i) 每个技能在 `E_i` 内保持 `I_G`；(ii) 每条接缝走廊 `S_σ` 保持 `I_G`；(iii) `I_G` 对组合转移关系归纳。由此把「逐技能证书」与「逐接缝证明」提升为**局部到全局**的归纳证明（定理 18）。

**定义 322（惰性接缝认证与可达集）** 组合数指数爆炸，故只对**有限前瞻 L** 内的可达接缝在线认证：用保守可达集上近似 `R̂ ⊇ R` 枚举 `σ ∈ R̂`，逐条证明；缓存证明摊销。若下一步接缝不在 `R̂` 内或证明超时 ⇒ 默认拒绝（hold/回退）。安全性不因 L 变小而下降，只有可用性下降。

**定义 323（无扰切换与颤振界）** 切换映射 `Transfer` 需满足 `δ_σ ≤ δ_max` 且驻留时间 `≥ t_dwell`；在迟滞带内不切换。由此给出切换次数的上界与轨迹 Lipschitz 界，继承 R68 的「无突变」要求并把它推广到技能边界。

**定义 324（契约认证与反洗白）** 契约不得自证：后置条件由**独立于技能策略的测量器**观测（例如残差由外部位姿/力估计，而非技能内部自报），并要求两路正交估计一致（沿用 R69 证据纪律）。`h_i` 与部署二进制/参数绑定；审计记录不可抵赖。定义两类攻击：**证书洗白**（把 `E_i`/`G_i` 声明得比真实宽，使局部检查恒通过），**预算双花**（多个技能对同一资源各报一份不冲突的预算）。

**定义 325（组合威胁模型 AIC-COMPOSE）** `ℰ_COMPOSE = ℰ_FLUID × ℰ_contract × ℰ_seam`：`ℰ_contract` = 乐观包络/后置条件谎报/哈希替换/参数漂移；`ℰ_seam` = 接缝去同步（两条技能对交接状态估计不一致）、时延导致的陈旧证书、恶意竞争共享资源、以「恢复」为名的越界动作。

**定义 326（参与式审计 VQAuditor-S 与组合安全案例）** 审计对象从「这次交互对不对」升级为「这条接缝的义务是否被真正证明、契约是否诚实、预算是否守恒」。输出一份可离线复核的**组合安全案例**（claim–argument–evidence），回灌 AuditBuf，成为下一轮 `τ_seam` 与预算分配的先验。证书 `J_SEAM`（定义 316）随任务归档。

## 2. 关键算法骨架

```python
# IP-264 SCT：技能契约（类型化、可哈希、可检查）
@dataclass(frozen=True)
class SkillContract:
    P: Predicate; G: Predicate              # 前提 / 保证（后置）
    E: Envelope                             # 认证包络（含假设 A_i）
    rho: float                              # 后置残差上界
    b: BudgetVec                            # 力/间隙/能量/时距/注意力 足迹
    F: set[str]; scope: Scope; h: str       # 失效模式 / 作用域 / 哈希

# IP-265 SCA：六义务组合检查（部分算子）
def compose_defined(A, B, seam, x_tau, budget, I_G) -> bool:
    if not entails(A.G, B.P) or not satisfies(x_tau, B.P): return False   # O1
    if measured_residual(x_tau, A.G) > B.e_max:            return False   # O2
    if not corridor_subset(seam.S, A.E, B.E):              return False   # O3
    if seam.delta > DELTA_MAX or seam.dwell < T_DWELL:     return False   # O4
    if not budget.feasible(A.b, B.b, M=interference(A,B)): return False   # O5
    if not inductive(I_G, A, B, seam):                     return False   # O6
    return True

# IP-266 SGO：接缝治理器（否决核；默认拒绝）
def seam_governor(x, A, B, ctx):
    if not scope_guard(x, A) or stale(A):            # 定义 317
        return abort_to_certified(A, ctx)
    if not compose_defined(A, B, ctx.seam(x), x, ctx.budget, I_G):
        g = seam_voi(A, B, x, ctx)                   # IP-268，仅接缝谓词
        if g is not None and ctx.budget.allow(g):
            x = apply_answer(x, execute(g))          # 看/问/触/等，带 R69 认证
        if not compose_defined(A, B, ctx.seam(x), x, ctx.budget, I_G):
            return hold_or_recover(A, ctx)           # 默认拒绝（定义 310-ii）
    if not lazy_certified(A, B, x, L=ctx.L):         # IP-270，有限前瞻
        return hold_or_recover(A, ctx)
    return bumpless_transfer(x, A, B, ctx)           # IP-271，δ_σ ≤ δ_max

# IP-270 LSC：惰性接缝认证（安全不随前瞻缩小而下降，只损失可用性）
def lazy_certified(A, B, x, L):
    for sigma in enumerate_reachable_hat(A, x, L):   # 保守可达集 R̂ ⊇ R
        if not cached_valid(sigma) and not prove(sigma): return False
    return True

# IP-274 SEAM-RAS 主闭环（继承 R69；只在组合粒度上插入）
def SEAM_RAS_round(M, obs):
    z, o = M.mtm.forward(...)                        # R69 一次前向
    i = M.skill_selector.current(o)                  # 当前技能 / 下一候选
    if not M.sgo.scope_guard(o, i):                  # 证书越界即作废
        return M.sgo.abort_to_certified(i, o)
    # R69 的不确定性层保留，但 VoI 改为接缝谓词（定义 319）
    U_ale, U_epi, modes = M.fluid.estimate(o)
    if M.sgo.at_seam(i):
        ok = M.sca.compose_defined(i, M.skill_selector.next(o), o, M.budget, M.I_G)
        if not ok and U_epi > TAU_EPI:
            g = M.mint_seam.choose(o, M.sgo.seam_predicates())
            if g is not None: ok = M.sca.compose_defined(
                i, M.skill_selector.next(apply_answer(o, M.cia.execute(g))),
                o, M.budget, M.I_G)
        if not ok:
            return M.sgo.hold_or_recover(i, o)       # 默认拒绝
        if not M.lsc.certified(i, M.skill_selector.next(o), o):
            return M.sgo.hold_or_recover(i, o)
        M.sgo.bumpless_transfer(i, M.skill_selector.next(o), o)
    k, lam, a = M.fluid.act(o, modes, U_ale, U_epi)  # R69 动作与 λ_floor
    M.sba.charge(i, a)                               # 预算记账（含人类注意力）
    M.vqa_s.submit_async(i, M.sgo.last_seam, U_epi, M.sba.snapshot())
    return k, lam, a
```

## 3. 推导

**引理 19（契约偏差的接缝放大）** 设技能 i 的声明残差/包络相对真实值乐观偏差为 `ε_i ≥ 0`（洗白量）。沿一条含 n 条接缝的链，组合安全裕度满足 `M_true ≤ M_claim − Σ_{k=1}^{n} κ_k ε_{i_k}`（`κ_k > 0` 为接缝敏感度）；若某技能被复用 m 次，其偏差在每次使用处各贡献一次。**系**：组合安全的木桶由**最不诚实的契约**决定，而非平均；且局部接缝检查无法发现它（检查只对照声明值），必须靠定义 324 的独立测量。这正面回答「一处谎言为何能污染全局」。

**引理 20（残差收缩、终止与无颤振）** 若每条接缝的恢复技能使残差按 `ρ ← κρ`（`κ<1`）收缩且单次成本 `≥ c_min > 0`，则重复修复至容忍界内所需步数 `≤ ⌈log(ρ_0/ε)/log(1/κ)⌉`，否则预算耗尽并转兜底；配合驻留时间 `t_dwell`，单位时间切换次数有上界，故不会 Zeno/颤振。**系**：「中止/恢复」是一个有契约、会终止的技能，不是无限重试。

**引理 21（惰性认证的健全性与可用性代价）** 设保守可达集 `R̂ ⊇ R`、前瞻 `L`。由于默认拒绝，任何实际执行的跨越都已被证明，故**安全性不随 L 缩小而下降**；可用性损失上界为 `P(R ∖ R̂) + P(证书陈旧)`。**系**：实时性与安全性解耦——缩短 L 只买到延迟，不买到风险。

**定理 18（组合安全 / 局部到全局）** 在 A99–A104 下，若所有实际执行的接缝满足 `O1–O6` 且测量噪声 `≤ ε_σ`，`I_G` 归纳，则组合轨迹始终满足 `I_G`，且每条接缝风险 `≤ ε_i + ε_σ`。证明按接缝数归纳：基础技能在其 `E_i` 内保持 `I_G`；归纳步用 O1/O2 建立 B 的前提与容忍球，O3 限制暂态，O4 保证连续，O5 保证资源，O6 重建 `I_G`；未证明的接缝由默认拒绝直接排除在可达轨迹之外。失败安全：不跨越 ⇒ 绝不进入未认证区域，故安全侧不弱于 R68 的纯保守。

**定理 19（非组合性与义务的必要性）** 存在技能 A、B，满足 `Safe(A,E_A,A_A)`、`Safe(B,E_B,A_B)` 且 `P_B ⊆ G_A`，但 `A⊳B` 违反 `I_G`。构造：A、B 各被认证「占用 60% 制动权限即可避撞」，并行后需 120%，单看每个证书都成立（`M` 矩阵体现耦合）；或 A、B 各自「对方先行则礼让」，组合后死锁/对撞。故任何忽略 O3/O5/O6 的组合规则都不健全，单技能证书的合取**不是**组合证明。

**定理 20（SEAM 严格包含 FLUID-RAS）** 单技能、无接缝时 `Obl = ∅`、SGO 不触发、接缝 VoI 退化为 R69 的 MINT，故 SEAM 逐指令等于 FLUID-RAS；当所有接缝均离线证明且交互无限时，任务行为等于 FLUID-RAS。因此 R70 是 R69 在「组合粒度为 1」边界上的严格泛化：安全侧不做让步（默认拒绝只会更保守），效率侧获得「已证明接缝的通行」；反之 R69 是 SEAM 的「永不组合」退化。

## 6. 本轮最大风险

**一句话**：SEAM-RAS 的全部安全性上界押在「技能契约诚实」这一前提上——**若某个技能的包络/后置条件被高估、谎报或投毒（证书洗白、预算双花），每个局部接缝检查都会通过，而组合会把这一处谎言沿所有经过它的接缝复制放大，于是系统可以在「每一步都有证书」的情况下执行全局不安全的行为——组合不创造安全，它只忠实传播契约的诚实度。**

**次级风险与缓解**：
1. **接缝暂态越界 / 颤振**（切换瞬间最危险）→ O3 走廊 + O4 无扰切换 + 驻留时间 + 引理 20；
2. **组合数指数爆炸** → 惰性认证 + 保守可达集 + 默认拒绝；安全性不降、只损失可用性（引理 21）；
3. **默认拒绝导致可用性崩塌** → `τ_seam` 显式 Pareto（E306）+ 恢复技能 + 离线预证明热接缝；
4. **契约认证被绕过（自报后置条件）** → 独立测量 + 双路正交 + 哈希绑定 + 不可抵赖审计（定义 324）；
5. **人类注意力被信息动作挤占** → `a_attn` 进入预算代数，紧急响应优先，E312 专测。

## 3. 关键算法伪代码

```python
# IP-264 SCT：类型化技能契约
@dataclass(frozen=True)
class SkillContract:
    P: Predicate; G: Predicate; E: Envelope
    rho: float; b: BudgetVec; F: set[str]; scope: Scope; h: str

# IP-265 SCA：六义务检查（部分算子）
def compose_defined(A, B, seam, x, budget, I_G):
    return (entails(A.G, B.P) and satisfies(x, B.P)                 # O1
            and measured_residual(x, A.G) <= B.e_max               # O2
            and corridor_subset(seam.S, A.E, B.E)                  # O3
            and seam.delta <= DELTA_MAX and seam.dwell >= T_DWELL  # O4
            and budget.feasible(A.b, B.b, M=interference(A, B))    # O5
            and inductive(I_G, A, B, seam))                        # O6

# IP-266 SGO：接缝治理器（默认拒绝）
def seam_governor(x, A, B, ctx):
    if not scope_guard(x, A) or stale(A):
        return abort_to_certified(A, ctx)
    if not compose_defined(A, B, ctx.seam(x), x, ctx.budget, I_G):
        g = seam_voi(A, B, x, ctx)                # IP-268，仅接缝谓词
        if g is not None and ctx.budget.allow(g):
            x = apply_answer(x, execute(g))
        if not compose_defined(A, B, ctx.seam(x), x, ctx.budget, I_G):
            return hold_or_recover(A, ctx)        # 默认拒绝
    if not lazy_certified(A, B, x, L=ctx.L):      # IP-270
        return hold_or_recover(A, ctx)
    return bumpless_transfer(x, A, B, ctx)        # IP-271

# IP-267 SBA：预算记账（保守、非幂等、含注意力）
def charge(skill, action, budget):
    budget.take(skill.b, M=interference(skill, budget.active))   # 双花检测
    if action.is_informational:
        budget.take_attention(action.cost)        # 提问挤占紧急响应预算
    assert budget.remaining() >= 0

# IP-274 主闭环（继承 R69，仅插入组合层）
def SEAM_RAS_round(M, obs):
    i = M.skills.current(obs)
    if not M.sgo.scope_guard(obs, i):
        return M.sgo.abort_to_certified(i, obs)
    U_ale, U_epi, modes = M.fluid.estimate(obs)
    if M.sgo.at_seam(i):
        j = M.skills.next(obs)
        ok = M.sca.compose_defined(i, j, obs, M.budget, M.I_G)
        if not ok and U_epi > TAU_EPI:
            g = M.stv.choose(obs, M.sgo.seam_predicates())
            if g is not None:
                ok = M.sca.compose_defined(i, j, apply_answer(obs, M.cia.execute(g)),
                                           M.budget, M.I_G)
        if not ok or not M.lsc.certified(i, j, obs):
            return M.sgo.hold_or_recover(i, obs)
        M.sgo.bumpless_transfer(i, j, obs)
    k, lam, a = M.fluid.act(obs, modes, U_ale, U_epi)
    M.sba.charge(i, a); M.vqa_s.submit_async(i, M.sgo.last_seam, U_epi)
    return k, lam, a
```

## 4. 推导

**引理 19（契约偏差的接缝放大）** 声明相对真实值的乐观偏差 `ε_i` 沿 n 条接缝使 `M_true ≤ M_claim − Σ κ_k ε_{i_k}`；某技能复用 m 次则每次使用各贡献一次。系：组合安全由**最不诚实的契约**决定，局部检查只对照声明值、无法发现，必须独立测量。

**引理 20（残差收缩、终止与无颤振）** 恢复技能以 `ρ←κρ`（κ<1）、单次成本 `≥c_min>0` 收缩残差，则至容忍界步数有上界，否则预算耗尽转兜底；配合驻留时间 `t_dwell`，切换次数有上界，不会 Zeno/颤振。

**引理 21（惰性认证的健全性与可用性代价）** `R̂⊇R`、前瞻 L；默认拒绝保证任何执行跨越都已证明，故安全性不随 L 下降；可用性损失 `≤ P(R∖R̂)+P(证书陈旧)`。系：缩短 L 只买延迟，不买风险。

**定理 18（组合安全 / 局部到全局）** A99–A104 下，若所有执行接缝满足 O1–O6、噪声 ≤ ε_σ、`I_G` 归纳，则组合轨迹满足 `I_G`，每条接缝风险 ≤ ε_i+ε_σ。未证明接缝被默认拒绝排除在可达轨迹外 ⇒ 失败安全，安全侧不弱于 R68 纯保守。

**定理 19（非组合性与义务必要性）** 存在 `Safe(A)∧Safe(B)∧P_B⊆G_A` 但 `A⊳B` 违反 `I_G`（共享制动权限 60%+60%=120%；或双方互相礼让/都自认优先）。故忽略 O3/O5/O6 的组合规则不健全，单技能证书合取 ≠ 组合证明。

**定理 20（SEAM 严格包含 FLUID-RAS）** 单技能无接缝时 `Obl=∅`、SGO 不触发、接缝 VoI 退化为 R69 MINT，故逐指令相等；全接缝离线证明且交互无限时任务行为等于 R69。R70 是 R69 在「组合粒度 1」边界的严格泛化，安全侧不让步。

## 7. 本轮最大风险

**一句话**：SEAM-RAS 的全部安全性上界押在「技能契约诚实」这一前提上——**若某技能的包络/后置条件被高估、谎报或投毒（证书洗白、预算双花），每个局部接缝检查都会通过，而组合会把这一处谎言沿所有经过它的接缝复制放大，于是系统可以在「每一步都有证书」的情况下执行全局不安全行为——组合不创造安全，它只忠实传播契约的诚实度。**

**次级风险与缓解**：接缝暂态越界/颤振（O3 走廊 + O4 无扰 + 驻留 + 引理 20）；组合数指数爆炸（惰性认证 + 保守可达集 + 默认拒绝，引理 21）；默认拒绝致可用性崩塌（`τ_seam` 显式 Pareto + 恢复技能 + 热接缝离线预证明）；契约自证被绕过（独立测量 + 双路正交 + 哈希绑定 + 不可抵赖审计）；人类注意力被挤占（`a_attn` 入预算代数，紧急优先，E312）。
