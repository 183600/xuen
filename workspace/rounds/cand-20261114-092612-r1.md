# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「产学研合作」×「低成本方案」）

> R69 让系统学会「问」，但它默认了一个**单一、免费、诚实、永远在线**的回答者，代价只记了社交成本。真实世界的知识是**机构化**的：实验室有强模型但慢、且不懂产线；工厂有窄而快的边缘服务但会过时；人类专家灵活但贵、会累、可能被收买。更根本地，R69 的效率收益押在「流模型模态可信」上，而校准它需要数据与算力——低成本设备恰恰两样都没有。
>
> 本轮两个灵感把 R69 的「交互」升级为「**合作**」：
> - **产学研合作**：不是问一个人，而是向一个**异质联盟**采购能力。联盟成员能力不同、成本不同、利益不同、会共谋、会过时。合作能成立靠的不是「相信」，而是**合同、验收、托管、署名、退出机制**。
> - **低成本方案**：便宜设备买不起「确认」，只能买得起「**伪证**」。它无法证明外部答案对，但可以用物理不变量、时序一致性、短程预测快速尝试证明它**错**；错不了才用，用了再慢慢蒸馏成本地能力。
>
> 核心命题：**R70 把「问谁」变成「向谁采购、如何验收、何时内化」——外部能力只能被『借用』，永不被『信任』；借用必须过独立于提供方的廉价伪证；只有经过反复验证的能力才允许蒸馏成本地技能，且必须可追溯、可摊销、可吊销。** 命名 **GUILD-RAS**（Guild-mediated Uncertainty-aware Incentive-compatible Low-cost Delegation）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**这个外部能力值多少钱、我验得起吗、验过之后能不能变成我自己的**」——产学研合作的本质不是共享知识，而是**把不可信的外部知识变成可验证、可摊销、可撤回的本地能力**。

## 0. 直觉与动机

**灵感 1（产学研合作 → 知识是有机构属性的商品）**
直觉：R69 的「证据源」是传感器模态，它们共享同一个身体、同一个世界，误差其实高度相关。产学研联盟提供的是真正异质的源：研究型模型（OOD 强、产线弱、延迟高）、产业型边缘服务（产线强、包络窄、易陈旧）、人类专家（开放、贵、有激励）。它们的价值不在「谁更准」，而在**在哪个包络内、以什么成本、由谁担责**。所以系统需要的是**采购**，不是融合：先看合同包络，再算边际收益/成本，而不是把所有人的输出平均。把最强的模型用在所有地方，在成本约束下是被严格支配的策略（引理 19）。

**灵感 2（低成本方案 → 验证必须比被验证对象便宜一个数量级）**
直觉：便宜机器人没有高精度力传感器、没有大模型算力，但它有**物理常识**：关节限位、非穿透、支撑多边形、动量守恒、短程预测一致性。这些检查几乎免费，却足以**否证**大部分离谱的外部建议。关键认识：**验证的目标不是「证明对」，而是「以可接受的成本排除错」**。因此我们不用「可信度」这种无法测的东西做门槛，而用「伪证功率」——一类可离线标定、可审计、可组合的拒错能力。便宜的代价是存在伪证盲区，这个盲区必须被显式承认（引理 20）。

**灵感 3（学徒制 → 合作的时间维度：从借用走向内化）**
直觉：产学研合作最有价值的产物不是一次咨询，而是**能力转移**。便宜机器人应像学徒：先看师傅做（借用），再在师傅监督下做（验证），最后出师（蒸馏）。内化后不再需要外部调用，成本被摊销，延迟消失，隐私也解决了。但学徒制也意味着**不可逆性**：学错的东西会跟着你一辈子，师傅走了也没法再问。所以内化必须有「任期与吊销」：信任是挣来的、有上限的、会过期的。

**灵感 4（R69 是单提供者、单成本维的退化情形）**
直觉：R69 的 VoI 只减去了 `c(g)`（物理/社交成本），提供者默认为一个无限可用的「环境/人类」。把提供者集合限制为 `P={human}`、预算限制为社交成本、去掉蒸馏与合同，GUILD 就逐指令退化为 FLUID-RAS。这是本轮的理论姿态：**新层必须是旧层的严格泛化**；当联盟不可用、不合规或验不起时，自动退化为 R69，再退化为 R68，安全侧永不变坏。

**灵感 5（合作的阴暗面 → 弱验证 + 离线内化 = 不可召回的污染）**
直觉：低成本意味着验不动；产学研联盟意味着多方利益。两者相乘会产生 R69 没有的新攻击面：**劣质认证**（工厂给过期证书）、**共谋验收**（两个提供者一起演，跨机构一致性失效）、**托管套利**（收了钱给错答案，赌你验不出）、**投毒蒸馏**（把错误能力内化，之后永久离线复现）。最危险的是**不可撤回性**：一旦蒸馏进本地策略，即使后来发现错了，外部答案早已删除、提供者早已下线、证书早已过期。**问错还能再问，学错就再也问不出来了**——这是本轮的中心风险。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（GUILD-RAS 总览）** GUILD-RAS = (HKP, CT, DC, CFB, AT, RAS-WM§)。四不变式：
(i) **实时流零外部调用、零学习写操作**（强化 R69 定义 293-i）：控制环只用本地策略；外部能力只在决策边界异步获取，编译为有界技能/参数。
(ii) **预算守恒**：钱、时、能、社交四类预算统一记账；单决策周期外部调用 ≤ 1；总成本 ≤ B_t。
(iii) **无授权不采用**：任何外部能力进入本地前，必须通过至少一个与提供方独立的廉价伪证器；单源外部答案永不单独定案。
(iv) **可召回性**：蒸馏能力必须带 provenance 与吊销句柄；不可追溯/不可吊销的能力不得进入安全关键路径。

**定义 311（异质知识提供者 HKP）** P = {p_0, p_1, …, p_n}，p_0 为本地廉价策略（c=0、包络=部署域、能力弱）。外部提供者 p 带有：机构类型 κ_p ∈ {研究 R, 产业 I, 人类 H}、能力包络 E_p ⊆ O×Q、单位成本 c_p(q) ≥ 0、延迟 ℓ_p、可靠性证书 Cert_p。三类机构的典型画像：
- 研究型 p_R：包络宽、OOD 强、c 高、ℓ 高、产线细节弱；
- 产业型 p_I：包络窄、产线强、c 低、ℓ 低、证书易过期；
- 人类 p_H：包络最宽、语义开放、c 高（含社交）、方差大。
本地 p_0 与外部不是「同一模型的大小版」，而是**比较优势不同**（引理 19）。

**定义 312（能力合同 CT）** 合同 Ct_p = (E_p, c_p(·), ℓ_p, δ_p, V_p, e_p, valid_until, prov_p)，其中 δ_p 为合同声称的错误上界，V_p 为强制验收条款，e_p 为托管金额，prov_p 为可验证来源。仅当 q ∈ E_p、now ≤ valid_until、Cert_p 通过签名验证时，合同才**可执行**；包络外查询一律拒绝，禁止「超范围发挥」。

**定义 313（增广预算）** B_t = (B_money, B_time, B_energy, B_social)。一次委派 q→p 的成本 c_tot(p,q) = c_p(q) + λ_t ℓ_p + λ_e e_p(q) + λ_s social(p,q)。R69 的交互预算是其在 B_money=B_energy=∞ 且 P={p_H} 上的投影。

**定义 314（委派价值 DV）** 给定当前模态后验与 R69 的 U_epi，候选 (p,q) 的委派价值
DV(p,q) = E[ΔR_task | p,q] − c_tot(p,q) − λ_liab·L_p(q)，
其中 ΔR_task 为期望任务风险下降（可由 U_epi 的期望下降近似），L_p(q) 为「答错且未被伪证拦截」的期望责任/损失。选择 (p*,q*) = argmax DV，约束 q∈E_p、合同有效、预算未超；若 max DV ≤ 0，不委派，走 R69。

**定义 315（廉价伪证器 CFB）** 伪证器 f: (q, y, o_t) → {pass, reject}，成本 c_f ≪ min_p c_p(q)，仅用本地传感/物理不变量。其犯两类错：误拒率 α_f、**误受率 β_f**。电池 F = {f_1,…,f_m}，按成本递增顺序做**序贯检验**（SPRT/e-value），一旦拒绝即停。伪证功率（对某类错误）Π_F = 1 − Π_{f∈F_ind} β_f，仅在伪证器条件独立时成立。伪证器例子：关节/速度限位、非穿透与支撑多边形、短程 WM 预测一致性、R69 的 r_res/r_sync、跨传感器符号一致性、动作-结果时序因果检查。

**定义 316（伪证优先采纳规则）** 外部答案 y 被采纳 ⇔ (a) 所有强制伪证器 pass；(b) 至少一个独立伪证器的标定功率 ≥ π_min；(c) 若风险等级高，还需通过定义 317 的跨机构一致。永远不存在「因为提供者权威所以采纳」的路径：**权威只影响排序，不影响验收**。

**定义 317（跨机构一致 XIA）** 高责任场景下，取两个**机构类型不同**的提供者 p_i, p_j，要求它们在**决策相关投影** φ(y) 上一致（不是全文一致）。令二者误差相关 ρ_{ij}；在 ρ<1 时，一致后错误率 ≤ δ(ρ+(1−ρ)δ)+ε_φ。但 ρ 不可观测且可被共谋拉到 1，故 XIA **只作为辅助证据**，不能替代伪证与托管（引理 21）。

**定义 318（学徒蒸馏 AT）** 本地学生 π_0 对提供者 p 的蒸馏只允许在「已验证上下文集」D_p 上进行：
D_p = { (o,y) : p 在同类上下文通过伪证 ≥ k_tenure 次，且与另一机构型提供者一致 ≥ 1 次，且本地可模仿误差 ≤ ε_student }。
蒸馏目标是**有界技能/选项或校准映射**，不是原始策略；损失 L_distill + λ·Risk。蒸馏样本必须来自**验证后**的结果，禁止用提供者自评作标签（防止自证）。

**定义 319（任期与吊销 TTM）** 对每个 (p, 上下文簇 c) 维护信任 T_p(c) ∈ [0,1]，单调更新：通过 → 增，伪证拒绝/漂移 → 减。任期允许**跳过部分非关键伪证**（降低验证成本），但永不允许跳过 π_min 功率的核心伪证。触发吊销：分布漂移（R68/69 变点）、合同过期、审计失败、跨机构一致突然破裂。吊销后可恢复，但需重新累计 k_tenure 次验证。

**定义 320（来源账本 PL）** 追加式账本，每项记录：提供者 id、合同哈希、查询特征、答案哈希、执行过的伪证器及结果、托管结算、蒸馏去向、吊销事件。账本支持**根检查**：来自同一提供者/同一合同批次的知识不得在「独立证据」计数中重复计入。

**定义 321（托管与结算 ESM）** 支付 = 基础费 + 成功奖金；成功由**验证窗口**内的伪证/结果判定，而非提供者自报。若被伪证判定为错，托管退款并罚没；若无法判定，按保守先验部分退款。托管规模必须与伪证功率匹配（引理 22），否则提供者有套利动机。

**定义 322（低成本约束与摊销 FBA）** 本地资源 L = (FLOPs, RAM, Energy) 与单次委派成本 c_esc，蒸馏一次性成本 C_dist。盈亏平衡使用次数
N* = ⌈ C_dist / (c_esc − c_local) ⌉。
当上下文预期复用次数 ≥ N* 时，蒸馏优于持续委派；否则委派更省。低成本方案的最优结构因此是**高频场景内化、低频高价值场景外购**（定理 21）。

**定义 323（安全编译与执行 SC）** 外部能力 → 有界技能 g_p(θ) 或参数 θ_p，经 C-RAS-WM§ 前缀认证后由本地控制器执行；外部不得直接下发实时控制指令。技能必须带**包络、限幅、失效回退**；认证失败则丢弃并回退本地策略。

**定义 324（联盟威胁模型 ℰ_guild）** ℰ_guild = ℰ_FLUID × ℰ_contract × ℰ_collusion × ℰ_distill × ℰ_escrow：劣质/过期证书、超包络冒充、跨机构共谋、伪证盲区利用、蒸馏投毒、托管套利、提供者突然下线。

**定义 325（证书 J_GUILD）** J_GUILD = (J_FLUID, provider_ids, contract_hashes, falsification_log_hash, cross_inst_agreement, escrow_settlement, distill_provenance, tenure_state, cost_ledger_root, guild_ver)。Valid ⇔ Valid(J_FLUID) ∧ 合同全部有效 ∧ 伪证纪律满足 ∧ 预算未越界 ∧ 蒸馏可追溯/可吊销。

**定义 326（四级降级链）** GUILD → FLUID（P={p_H}，无蒸馏）→ CALM（不交互）→ 本地最保守。任一层合同失效、预算耗尽、伪证失败、审计失败、提供者下线，都**单调降级**，绝不升级到更强依赖。R69 是 GUILD 在「单提供者 + 无合同 + 无蒸馏」上的严格退化（定理 18）。

```python
# IP-264/265 HKP + CT：只接受包络内、未过期、签名有效的合同
class GuildRegistry:
    def candidates(self, q, o_t):
        return [p for p in self.providers
                if p.contract.covers(q) and p.contract.valid(now())
                and p.cert.verify() and p.cert.delta <= DELTA_MAX]

# IP-266 DC：把 R69 的 VoI 升级为带成本与责任的采购
def delegate(q, o_t, budget, U_epi):
    best = None
    for p in guild.candidates(q, o_t):
        if not budget.allows(p.contract.cost(q)): continue
        dv = expected_risk_drop(q, p) - p.contract.cost(q) - LAMBDA_LIAB * liability(p, q)
        if best is None or dv > best.dv: best = (p, dv)
    return best if best and best.dv > 0 else None      # 不划算 → R69

# IP-267/268 CFB + XIA：便宜地试图证明答案是错的
def falsify(q, y, o_t, risk_tier, p):
    independent_ok = False
    for f in battery.ordered(risk_tier):               # 成本从低到高，序贯
        if f(q, y, o_t) == REJECT: return REJECT, f
        if f.calibrated_power >= PI_MIN: independent_ok = True
    if not independent_ok: return REJECT, "no_power"   # 验不动就不采纳
    if risk_tier == HIGH:
        p2 = guild.orthogonal(p, q)                    # 不同机构类型
        if p2 is None or not agree(projection(y), p2.query(q)):
            return DEFER, "xia"                        # 辅助证据不足，转人工/保守
    return ACCEPT, None

# IP-269/270 AT + TTM：只蒸馏验证过（且非自证）的能力
def maybe_distill(p, D_verified, student, tenure):
    if len(D_verified) < K_TENURE or tenure[p].rank < RANK_JOURNEYMAN:
        return None
    if not cross_heldout_gain(student, p, D_verified): return None
    skill = distill(student, D_verified, bounded=True)  # 有界技能/参数
    prov  = ledger.record(skill, p, D_verified, hash_only=True)
    return skill, prov

# IP-273/274/278 主闭环：控制环永远本地，外部只在边界异步介入
def GUILD_RAS_round(M, obs):
    z, o = M.mtm.forward(obs)
    # R69：本地即可解的不确定性，先按原路径处理
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    # R70：只有本地解不了且买得起、验得起时，才去联盟采购
    y = None
    if U_epi > TAU_EPI and M.budget_ok(B_t):
        q = form_query(modes, o)
        choice = delegate(q, o, M.budget, U_epi)
        if choice:
            p, _ = choice
            y = p.query(q)                             # 异步获取，绝不下发实时控制
            verdict = falsify(q, y, o, risk_tier(U_epi), p)
            M.ledger.record(q, p, y, verdict)
            if verdict == ACCEPT:
                skill, prov = maybe_distill(p, M.verified_ctx(p), M.student, M.tenure)
                if skill: M.local_install(skill, prov)         # 内化，可吊销
                else:     M.borrow(y, contract=p.contract)     # 只借用
            else:
                M.escrow.settle(p, success=False)              # 退款/罚没
                y = None
        else:
            y = None
    # R69 的交互消歧作为「提供者=人类」的特例
    g = (M.mint.choose_interaction(modes, o, M.budget)
         if (y is None and U_epi > TAU_EPI) else None)
    if g is not None:
        ans = M.cia.execute(g)                         # 人类也是一种 p_H
        if falsify(form_query(modes, o), ans, o, risk_tier(U_epi), P_H) == ACCEPT:
            U_epi = M.cia.update_belief(modes, ans)
    # 安全收尾：R69 → R68 的降级链
    U_floor = U_ale + (U_epi if (y is None and g is None) else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    skill = M.safety.compile_local(M.last_skill)       # C-RAS-WM§ 认证
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), skill=skill)
    M.vqa_g.submit_async(q if 'q' in locals() else None, y, verdict if y else None)
    return k, lam
```

## 3. 推导

**引理 19（委派的比较优势）** 设提供者 p 在查询 q 处的风险下降为 ΔR_p(q)、总成本为 c_p(q)。在合同包络内，DV 最优选择满足 p* = argmax_p [ΔR_p(q) − c_p(q) − λ_liab L_p(q)]，即**按单位成本的边际能力排序，而非按绝对能力排序**。特别地，若研究型 p_R 的 δ_R < δ_I 但 c_R > c_I，则当
λ_liab(δ_I − δ_R) ≤ c_R − c_I
时产业型 p_I 严格更优。系：**低成本方案应把窄而廉的产业服务用于包络内高频查询，把宽而贵的研究型服务留给包络外的新颖情形**；在所有查询上都用最强模型，在成本约束下被严格支配。这就是「产学研合作」的 Ricardo 比较优势：不是谁最强，而是谁在各自包络内最划算。

**引理 20（廉价伪证的盲区下界）** 设提供者错误率 δ_p，伪证电池 F 各伪证器对错误答案的误受率为 β_f 且条件独立，则采纳答案的错误率 ≤ δ_p·Π_{f} β_f。但若所有伪证器共享一个盲区事件 S（P(S)=ζ），则不论 m 多大，采纳错误率 ≥ δ_p·ζ。系：**廉价验证有硬下界，增加同类伪证器不能穿过盲区；正交伪证器的价值远高于数量**。因此 CFB 必须按「失效原理正交」设计，且必须承认剩余风险不能由本地验证消除，只能由 XIA/托管/保守兜底（引理 21、22）。

**引理 21（跨机构一致不是信任）** 设两个提供者边际错误率均为 δ、错误相关系数 ρ，则二者同时犯错的概率为 P(both wrong) = ρδ + (1−ρ)δ²；在二者一致的条件下，错误率为 δ(ρ+(1−ρ)δ)。当 ρ→1（共谋或同源训练）时错误率退化为 δ，一致**不提供任何信息**。系：XIA 的效力完全依赖「机构异质 ⇒ 误差去相关」这一**不可观测假设**，可被共谋击穿；因此 XIA 只能作为辅助证据，必须与伪证、托管和审计联合使用。

**引理 22（托管规模与激励相容）** 设提供者说谎可多获收益 g（更高成功费或更低成本），被伪证拦截时罚没 e，伪证误受率 β。说谎的期望净收益为 g·β − e·(1−β)；诚实的期望净收益归零。故**诚实是弱占优策略当且仅当**
e ≥ g·β / (1 − β)。
系：**验证越便宜/越弱（β 越大），托管必须越大**——低成本方案不能同时省掉验证与押金；「验不起」必须用「押得起」补偿，否则联盟必然逆向选择。

**定理 18（GUILD 严格包含 R69）** 取 P={p_H}、合同为平凡合同（E=全体、c=社交成本）、CFB 即 R69 的证据电池、关闭 AT/ESM，则 GUILD 的决策序列与 FLUID-RAS 逐指令相同。进一步，在合同有效且核心伪证功率 ≥ π_min 时，GUILD 的期望委派风险 ≤ R69 的期望风险；在降级边界上取等号。故安全侧永不变坏，效率侧获得「联盟采购 + 摊销」的增益。

**定理 19（学徒收敛与摊销）** 在包络内平稳、标签经伪证验证的假设下，学生相对提供者的超额风险随验证样本数 N 以 O(1/√N) 收敛，直到逼近误差 ε_student；当上下文复用次数 N_c ≥ N*（定义 322）时，蒸馏后的期望总成本不高于持续委派。若漂移检测延迟上界为 τ_d，则任期吊销把污染窗口限制在 τ_d 内。故合作能带来净成本下降，而信任不会无限增长。

**定理 20（委派安全与无突变）** 外部技能经 SC 编译并由 C-RAS-WM§ 认证后，其物理风险 ≤ ε_int；外部永不直接进入实时控制环。任一层失败时降级链单调、无升级依赖；提交/换装不变式（R68 定理 15）保持，故控制连续、无突变。提供者中途下线时至多在当前技能包络内完成或安全停机，不会把控制权交给不可达的外部。

**定理 21（低成本最优结构：内化与外购的相变）** 由定义 322，存在复用次数阈值 N*，使最优策略为「N_c ≥ N* 则蒸馏、否则委派」；N* 随一次性蒸馏成本 C_dist 增大、随单次委派成本 c_esc 减小。系：低成本机队应优先内化高频技能，并把**已通过验证的技能及其 provenance** 在机队内共享以摊薄 C_dist；但共享技能进入新机体仍需本地重验（至少核心伪证），不得零验证复用。

## 6. 本轮最大风险

**一句话**：低成本弱伪证 + 离线蒸馏 = **不可召回的污染**——廉价验证放过了错误的外部能力，学徒制把它固化成永久本地技能；等发现时提供者已下线、证据已过期、错误已复制到整个机队——**问错还能再问，学错就再也改不回来**。

**次级风险与缓解**：
1. **共谋/假认证**（跨机构一致被拉到 ρ→1）→ XIA 降级为辅助证据 + 托管押金 + 第三方审计 + E309；
2. **托管套利**（验得越弱越敢说谎）→ 引理 22 的押金下界 + 按 β 动态定价 + E308；
3. **伪证盲区**（正交性假设不成立）→ 按失效原理设计电池 + 保守 π_min + 显式剩余风险 + 兜底降级；
4. **提供者突然下线** → 外部只编译为有界技能、不接管实时控制 + 四级降级链 + E315；
5. **隐私/数据外泄**（把产线数据发给研究方）→ 只上传哈希/特征、provenance 最小化、合同数据条款；
6. **内化后的漂移**（本地技能随环境过时）→ 任期吊销 + 周期性重验 + 机队共享技能需本地复核。

```python
    if U_epi > TAU_EPI and M.budget_ok(B_t):           # 买得起、验得起才采购
        q = form_query(modes, o)
        choice = delegate(q, o, M.budget, U_epi)
        if choice:
            p, _ = choice
            y = p.query(q)                             # 异步，绝不下发实时控制
            verdict = falsify(q, y, o, risk_tier(U_epi), p)
            M.ledger.record(q, p, y, verdict)
            if verdict == ACCEPT:
                skill, prov = maybe_distill(p, M.verified_ctx(p), M.student, M.tenure)
                if skill: M.local_install(skill, prov)         # 内化，可吊销
                else:     M.borrow(y, contract=p.contract)     # 只借用
            else:
                M.escrow.settle(p, success=False)              # 退款/罚没
                y = None
    # R69 的交互消歧 = 提供者为人（p_H）的特例
    g = (M.mint.choose_interaction(modes, o, M.budget)
         if (y is None and U_epi > TAU_EPI) else None)
    if g is not None:
        ans = M.cia.execute(g)
        if falsify(form_query(modes, o), ans, o, risk_tier(U_epi), P_H) == ACCEPT:
            U_epi = M.cia.update_belief(modes, ans)
    U_floor = U_ale + (U_epi if (y is None and g is None) else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    skill = M.safety.compile_local(M.last_skill)       # C-RAS-WM§ 认证
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), skill=skill)
    M.vqa_g.submit_async(q if 'q' in locals() else None, y, verdict if y else None)
    return k, lam
```

## 4. 推导

**引理 19（委派的比较优势）** 在合同包络内，最优委派按**单位成本的边际能力**排序，而非绝对能力：`p* = argmax[ΔR_p − c_p − λ_liab L_p]`。若研究型 `δ_R<δ_I` 但 `c_R>c_I`，当 `λ_liab(δ_I−δ_R) ≤ c_R−c_I` 时产业型严格更优。系：窄而廉的产业服务用于包络内高频，宽而贵的研究型留给包络外新颖情形；全场景使用最强模型被成本严格支配。

**引理 20（廉价伪证的盲区下界）** 独立伪证下采纳错误率 `≤ δ_p Π β_f`；若存在共享盲区事件 `P(S)=ζ`，则任何数量伪证都不能把错误率压到 `δ_p ζ` 以下。系：正交伪证器价值远高于同类堆叠；剩余风险只能由 XIA/托管/保守兜底。

**引理 21（跨机构一致不是信任）** 边际错误率 δ、相关系数 ρ 时，一致条件错误率为 `δ(ρ+(1−ρ)δ)`；`ρ→1`（共谋/同源）时退化为 δ，一致毫无信息量。系：XIA 依赖「机构异质⇒误差去相关」这一不可观测假设，只能作辅助证据。

**引理 22（托管规模与激励相容）** 说谎多获 g、被伪证拦截罚没 e、误受率 β，则诚实弱占优当且仅当 `e ≥ gβ/(1−β)`。系：**验得越弱，押金必须越大**；低成本方案不能同时省掉验证与押金。

**定理 18（GUILD 严格包含 R69）** 取 `P={p_H}`、平凡合同、CFB=R69 证据电池、关闭 AT/ESM，则 GUILD 与 FLUID-RAS 逐指令相同；合同有效且核心伪证功率 ≥ π_min 时，期望委派风险 ≤ R69；降级边界取等号。

**定理 19（学徒收敛与摊销）** 包络内平稳、标签经验证时，学生超额风险以 `O(1/√N)` 收敛至 `ε_student`；复用次数 `N_c ≥ N*` 时蒸馏总成本 ≤ 持续委派；漂移检测延迟 `τ_d` 界定了污染窗口。

**定理 20（委派安全与无突变）** 外部技能经 SC 编译与 C-RAS-WM§ 认证后物理风险 ≤ ε_int，外部永不进入实时控制环；四级降级单调，R68 换装不变式保持，故控制连续、无突变。

**定理 21（低成本最优结构：内化/外购相变）** 存在 `N*` 使最优策略为「`N_c ≥ N*` 则蒸馏，否则委派」；`N*` 随 `C_dist` 增、随 `c_esc` 减。系：机队应内化高频技能并共享**已验证且带 provenance** 的技能摊薄成本，但新机体仍需本地核心伪证复核。

## 7. 本轮最大风险

**一句话**：低成本弱伪证 + 离线蒸馏 = **不可召回的污染**——廉价验证放过错误的外部能力，学徒制把它固化成永久本地技能；等发现时提供者已下线、证据已过期、错误已复制到整个机队——**问错还能再问，学错就再也改不回来**。

**次级风险与缓解**：共谋/假认证（XIA 降级为辅助 + 托管 + 审计 + E309）；托管套利（引理 22 押金下界 + 动态定价）；伪证盲区（正交设计 + 保守 π_min + 显式剩余风险）；提供者下线（有界技能 + 四级降级 + E315）；数据外泄（哈希/特征最小化 + 合同数据条款）；内化后漂移（任期吊销 + 周期重验 + 机队共享仍需本地复核）。
