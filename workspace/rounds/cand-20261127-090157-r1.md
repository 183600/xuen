### 第 2 轮灵感驱动研究记录（数据集 / 数据集构建）

**灵感词**：数据集、数据集构建

**直觉与动机**：
前几轮把机器人系统堆叠成十证一体的准入门（USMC / SMC / RMC / MCC，Exec_v25），但所有证书都隐含一个未被言明的前提：**证书所依赖的数据是可信的、覆盖部署工况的、且校准集与测试集可交换**。Conformal 覆盖 ℙ(s_i∈C(x))≥1-α 只在可交换性（exchangeability）下成立；RMC 的动力学残差 δ_dyn 依赖辨识数据覆盖 (q,q̇,q̈,负载) 工况；MCC 的纳什/Pareto 结论依赖交互数据覆盖编队规模与通信拓扑；SOC/FCC/LSC 则依赖材料试验与力觉标定的数据切片。换言之，**数据集不是证书之外的工程细节，而是证书的公理系统本身**：D 是公理，π_D（构建协议）是公理的选择规则，证书 c 是 D 上的定理。若 D 存在选择偏差、校准/测试泄漏、标签噪声或部署漂移，证书只是"自洽的幻觉"。受「数据集/数据集构建」启发，核心洞见是：**证书的可信度 = 证书逻辑 × 数据充分性；必须把"数据充分性"本身证书化，并让数据集构建成为以证书有效性为目标的可优化过程，而非事后补丁**。

**形式化目标**：
1. 定义数据集构建证书（DCC）：对构建协议 π_D 输出六元组证书——来源可溯性 Prov(D)、泄漏隔离 Free(D_cal,D_test)、工况覆盖 ρ_reg(D)、可交换性 e-value e_ex、标签质量 η(D)、可复现性 Repr(π_D)。
2. 定义数据充分性：D 对证书 c（名义风险 α）是 (Δ,η,δ)-充分的，当且仅当对任意部署分布 P_dep 满足 W₁(φ#D, φ#P_dep)≤Δ 时，c 的实际风险 ≤ α + g(Δ,η,α_ex) 以概率 ≥1-δ，其中 g 为显式退化函数。
3. 数据条件证书传递（DCCT）：给出 g(Δ,η,α_ex) 的推导，覆盖 conformal 覆盖、动力学残差、碰撞概率、纳什近似四类证书，并保证缺陷→0 时 g→0。
4. 证书引导的主动数据构建（CG-ADC）：在采集预算与标注预算约束下，以"证书压力工况覆盖"函数 F(S) 为目标做子模最大化，贪心给出 (1-1/e) 近似；用哈希分层切分保证层内可交换。
5. 数据接地统一准入门（DG-UCG）：Exec_v26 = Exec_v25 ∩ Fil_data，并证明数据证书失效时向 Exec_v25(α↑,δ_dyn↑) 保守回退的单调退化链。
6. 交付"证书—数据依赖矩阵"：把每个下游证书映射到其必需数据切片与最敏感缺陷，使数据预算分配可审计。

```python
# ============================================================
# IP-448 Dataset Construction Certificate (DCC) — 数据集构建证书
# ============================================================
@dataclass
class DataCard:
    """机器可读的证书-数据契约，随每个下游证书一起发布与版本化"""
    dataset_hash: str
    protocol_hash: str
    version: str
    splits: dict[str, str]          # split_name -> index-manifest hash
    regime_counts: dict[str, int]
    provenance_depth: int
    label_noise_bound: float
    delta_W: float
    exchangeability_e: float
    created_at: str
    audit_regimes: list[str]        # 未参与构建、仅用于审计的留出工况


@dataclass
class DatasetConstructionCertificate:
    D: 'Dataset'
    protocol: 'ConstructionProtocol'          # π_D
    splits: dict[str, list[int]]              # train/cal/test 索引
    provenance: 'ProvenanceGraph'
    regime_space: 'RegimeSpace'               # R，7 轴
    k_per_regime: dict[str, int]              # k_r
    rho_min: float = 0.90
    eta_max: float = 0.02
    ESS_min: int = 2000
    delta_W_max: float = 0.05
    alpha_ex: float = 0.05

    # ---------- 六项验证 ----------
    def verify_provenance(self) -> bool:
        """Prov(D)：每个样本可回溯到 传感器→采集→清洗→标注→切分 全链"""
        required = {"sensor", "capture", "clean", "label", "split"}
        return all(
            self.provenance.has_chain(i) and
            required.issubset(self.provenance.stages(i))
            for i in range(len(self.D))
        )

    def verify_leakage_free(self) -> bool:
        """D_train / D_cal / D_test 两两不交，且同一场景/实体不跨切片"""
        tri = (set(self.splits["train"]),
               set(self.splits["cal"]),
               set(self.splits["test"]))
        if any(tri[i] & tri[j] for i in range(3) for j in range(i + 1, 3)):
            return False
        # 场景/实体级隔离：同一 group_id 不得跨切片
        return self.provenance.group_disjoint(self.splits)

    def verify_coverage(self) -> bool:
        """ρ_reg(D) ≥ rho_min 且 ESS(D) ≥ ESS_min"""
        counts = self._regime_counts()
        rho = sum(min(1.0, counts.get(r, 0) / k)
                  for r, k in self.k_per_regime.items()) / len(self.k_per_regime)
        ess = self._effective_sample_size()
        return rho >= self.rho_min and ess >= self.ESS_min

    def verify_exchangeability(self, lam: float = 0.5) -> bool:
        """Vovk 可交换性 test martingale：
           用校准集拟合非一致性分数，在 cal∪test 上计算秩 p_i=rank_i/(n+1)，
           e = Π_i (1 + λ(p_i - 1/2))。若 e ≥ 1/α_ex 则拒绝可交换（不通过）。"""
        scores = self._nonconformity_on_cal_test()
        ranks = _average_ranks(scores)
        n = len(scores)
        e = 1.0
        for r in ranks:
            p = r / (n + 1)
            e *= (1.0 + lam * (p - 0.5))
        self._last_e_ex = e
        return e < 1.0 / self.alpha_ex   # 不拒绝 H0 才通过

    def verify_label_quality(self) -> bool:
        """η(D) ≤ eta_max：双人复核 + 交叉一致性（Cohen's κ）"""
        eta = self._estimate_label_noise()
        kappa = self._inter_annotator_kappa()
        return eta <= self.eta_max and kappa >= 0.8

    def verify_reproducibility(self) -> bool:
        """Repr(π_D)：协议含固定随机种子、版本锁、切分清单哈希"""
        return (self.protocol.has_seed() and
                self.protocol.has_version_lock() and
                self.protocol.split_manifest_hash() == self._split_hash())

    # ---------- 汇总 ----------
    def certify(self) -> Optional[DataCard]:
        ok = (self.verify_provenance() and
              self.verify_leakage_free() and
              self.verify_coverage() and
              self.verify_exchangeability() and
              self.verify_label_quality() and
              self.verify_reproducibility())
        if not ok:
            return None
        return DataCard(
            dataset_hash=self.D.content_hash(),
            protocol_hash=self.protocol.hash(),
            version=self.protocol.version,
            splits={k: _hash_indices(v) for k, v in self.splits.items()},
            regime_counts=self._regime_counts(),
            provenance_depth=self.provenance.max_depth(),
            label_noise_bound=self._estimate_label_noise(),
            delta_W=self._estimate_delta_W(),
            exchangeability_e=self._last_e_ex,
            created_at=_now_iso(),
            audit_regimes=self.regime_space.audit_regimes(),
        )

    # ---------- 估计器 ----------
    def _effective_sample_size(self) -> float:
        w = self._importance_weights()
        return float(w.sum() ** 2 / (w ** 2).sum())

    def _estimate_delta_W(self) -> float:
        """Sinkhorn 熵正则 OT 估计 W₁(φ#D, φ#P_dep)"""
        X = self._features(self.D)
        Y = self._deployment_proxy_features()
        return entropic_wasserstein(X, Y, reg=0.01, p=1)

# IP-449 DCCT — 数据条件证书传递（退化函数 g 的实现）
# ============================================================
class DataConditionalCertificateTransfer:
    def __init__(self, L_W_sem=1.0, L_W_dyn=2.0, L_W_coord=1.5):
        self.L_W = {"sem": L_W_sem, "dyn": L_W_dyn, "coord": L_W_coord}

    def degradation(self, delta_W: float, eta: float,
                    alpha_ex: float, n_cal: int,
                    kind: str = "sem") -> float:
        """g = L_W·Δ + η + √(log(1/α_ex)/(2n_cal))"""
        L = self.L_W[kind]
        return L * delta_W + eta + math.sqrt(
            math.log(1.0 / alpha_ex) / (2.0 * max(n_cal, 1)))

    def transferred_risk(self, alpha_nominal: float, delta_W: float,
                         eta: float, alpha_ex: float, n_cal: int,
                         kind: str = "sem") -> float:
        """数据折损后的有效风险（仍 ≤1）"""
        return min(1.0, alpha_nominal + self.degradation(
            delta_W, eta, alpha_ex, n_cal, kind))

    def is_still_certified(self, alpha_nominal: float, alpha_budget: float,
                           **kw) -> bool:
        return self.transferred_risk(alpha_nominal, **kw) <= alpha_budget

# IP-450 CG-ADC — 证书引导的主动数据集构建
# ============================================================
def certificate_guided_dataset_construction(
        pool: 'Dataset', regime_space: 'RegimeSpace',
        k_per_regime: dict[str, int], budget: int,
        quality_fn=None, redundancy_fn=None,
        lam_q: float = 0.1, lam_d: float = 0.05,
        seed: int = 0) -> tuple['Dataset', DatasetConstructionCertificate]:
    """单调子模覆盖 F(S) = Σ_r min(1, |S∩r|/k_r)，贪心 (1-1/e) 近似。
       附加质量奖励与冗余惩罚；最终用哈希分层切分。"""
    rng = random.Random(seed)

    def regime_of(sample) -> str:
        return regime_space.key(sample)

    def marginal_gain(s_idx: int, counts: dict[str, int]) -> float:
        r = regime_of(pool[s_idx])
        gain = 0.0
        if counts.get(r, 0) < k_per_regime.get(r, 0):
            gain += 1.0 / max(k_per_regime.get(r, 1), 1)
        if quality_fn is not None:
            gain += lam_q * quality_fn(pool[s_idx])
        if redundancy_fn is not None:
            gain -= lam_d * redundancy_fn(pool[s_idx], selected)
        return gain

    selected: list[int] = []
    counts: dict[str, int] = {}
    while len(selected) < budget:
        best, best_gain = None, -float("inf")
        for i in range(len(pool)):
            if i in selected:
                continue
            g = marginal_gain(i, counts)
            if g > best_gain:
                best, best_gain = i, g
        if best is None or best_gain <= 0:
            break
        selected.append(best)
        r = regime_of(pool[best])
        counts[r] = counts.get(r, 0) + 1

    D = pool.subset(selected)

    # 哈希分层切分：同一 group 永远同侧，杜绝泄漏；层内哈希近似均匀 ⇒ 层内可交换
    splits = {"train": [], "cal": [], "test": []}
    for i in selected:
        bucket = int(_stable_hash(pool.group_id(i), seed) % 100)
        split = "train" if bucket < 60 else ("cal" if bucket < 80 else "test")
        splits[split].append(i)

    dcc = DatasetConstructionCertificate(
        D=D, protocol=pool.protocol, splits=splits,
        provenance=pool.provenance, regime_space=regime_space,
        k_per_regime=k_per_regime)
    return D, dcc

# IP-451 DG-UCG — 数据接地统一准入门
# ============================================================
@dataclass
class DataGroundedUnifiedCertificateGate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'
    dcc: DatasetConstructionCertificate
    dcct: DataConditionalCertificateTransfer

    def admits(self, multi_plan, data_card: Optional[DataCard], **kw) -> bool:
        # 1. 数据层门：DCC 必须出证
        card = self.dcc.certify()
        if card is None:
            return False
        # 2. 漂移门：Δ_W 超限即拒（保守）
        if card.delta_W > self.dcc.delta_W_max:
            return False
        # 3. 传递门：每个下游证书的数据折损后仍需落在风险预算内
        n_cal = len(self.dcc.splits["cal"])
        checks = [
            ("sem", kw["alpha_sem"], self.dcct.degradation(
                card.delta_W, card.label_noise_bound,
                self.dcc.alpha_ex, n_cal, "sem")),
            ("dyn", kw["delta_dyn_budget"], self.dcct.degradation(
                card.delta_W, card.label_noise_bound,
                self.dcc.alpha_ex, n_cal, "dyn")),
            ("coord", kw["beta_coord"], self.dcct.degradation(
                card.delta_W, card.label_noise_bound,
                self.dcc.alpha_ex, n_cal, "coord")),
        ]
        for kind, budget, loss in checks:
            if loss > budget:
                return False
        # 4. 原有 SRC-USC 十证门
        return self.src_usc.admits(multi_plan, **kw["src_kw"])

    def fallback(self, reason: str) -> dict:
        """数据层拒证时的保守回退：不是直接停机，而是加宽风险参数后重验"""
        return {
            "reason": reason,
            "mode": "conservative_v25",
            "alpha_sem": min(0.10, 2 * self.dcc.alpha_ex),
            "delta_dyn": 10.0 * 1e-3,
            "beta_coord": 0.05,
            "note": "冻结主动探索，仅执行已通过审计留出工况的最保守计划",
        }


# 在线再认证：e-process 监控部署期数据漂移
class DriftEProcess:
    def __init__(self, alpha: float = 0.05):
        self.wealth = 1.0
        self.alpha = alpha

    def update(self, new_batch: 'Dataset', ref: 'Dataset') -> bool:
        """每批新数据与参考分布算一个预注册的检验统计量并下注"""
        stat = two_sample_energy_distance(new_batch, ref)   # 0..1 归一
        self.wealth *= 1.0 + 0.5 * (stat - 0.5)
        if self.wealth >= 1.0 / self.alpha:
            return False   # 漂移显著，触发再认证/保守回退
        return True
```

**辅助函数**：`_average_ranks`（平均秩）、`entropic_wasserstein`（Sinkhorn 迭代，O(n²) 每步）、`_stable_hash`（sha256→int，按 group 稳定）、`two_sample_energy_distance`（能量距离，O(n²)）。

## 3. 复杂度分析（增量）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| DCC 来源可溯 | O(n · d_prov) | O(n · d_prov) | d_prov≤8 链深 |
| DCC 泄漏隔离 | O(n α(n)) 并查集 | O(n) | group 级隔离 |
| DCC 工况覆盖 ρ_reg | O(n + \|R\|) | O(\|R\|) | \|R\|≤10⁴ |
| DCC ESS | O(n) | O(n) 权重 | - |
| DCC 可交换性 e-value | O(n log n) 排序 | O(n) | n_cal+n_test≤10⁵ |
| DCC Δ_W（Sinkhorn） | O(n² / ε²) | O(n²) 或分块 O(B²) | n≤10⁴，B=512 |
| CG-ADC 贪心 | O(budget · n · d) | O(n) | budget≤5×10⁴ |
| DCCT 退化函数 | O(1) | O(1) | - |
| DG-UCG 准入 | 原 SRC-USC + O(n log n) | +O(n) | 数据层为一次性/低频 |
| 端到端单步（在线） | 仅 DriftEProcess O(B²) | O(B) | B=512 批次 |

**实时性说明**：DCC 是**离线/批次级**证书（随数据集版本发布），不进入 50Hz 控制环；在线只保留 DriftEProcess 的批次级能量距离 O(B²)，B=512 时约 1~2ms/批，可挂到 1Hz 监控线程。控制环内 DG-UCG 直接查 DataCard 的缓存标量，O(1)。

## 4. 正确性论证（增量）

### 定义 13（数据充分性）
称 D 对证书 c（名义风险 α）在预算 (Δ,η,α_ex) 下是**充分的**，若对任意满足 W₁(φ#D, φ#P_dep)≤Δ 的部署分布 P_dep，c 在 P_dep 上的实际风险 R_c(P_dep) ≤ α + g(Δ,η,α_ex) 以概率 ≥1−δ成立，且 g 关于各缺陷单调不减、在 (0,0,0) 处 g=0。

### 引理 13（DCC 六重保证的等价性）
**陈述**：`DCC.certify() ≠ None` ⟺ D 同时满足 (1) 来源全链可溯，(2) 训练/校准/测试场景级隔离，(3) ρ_reg≥ρ_min ∧ ESS≥ESS_min，(4) 可交换性检验未拒绝，(5) η≤η_max ∧ κ≥0.8，(6) 构建协议可复现。
**证明**：`certify` 是六个 `verify_*` 的合取，每个 `verify_*` 直接判定对应谓词；DataCard 仅在六者全真时构造，故等价。∎

### 引理 14（数据条件保真：conformal 覆盖的显式折损）
**陈述**：设非一致性分数有界于 [0,1]，标签噪声率 ≤η，φ 上证书损失 L 为 L_W-Lipschitz，且可交换性检验未拒绝（水平 α_ex），则对任意 W₁(φ#D,φ#P_dep)≤Δ：
R_cal(P_dep) ≥ 1 − α − η − L_W·Δ − √(log(1/α_ex)/(2 n_cal))。
**证明（要点）**：
1. 在理想可交换且无噪情形，conformal 给出 1−α 覆盖（Vovk）。
2. 标签噪声 η 使非一致性分数最多偏移 η（有界损失下），覆盖最多下降 η（在标注正确样本上做条件分解）。
3. 分布漂移：由 Kantorovich–Rubinstein 对偶与 L_W-Lipschitz，风险差 ≤ L_W·W₁ ≤ L_W·Δ。
4. 可交换性检验的有限样本代价：未拒绝 H0 的检验以 α_ex 水平控制第一类错误，其检验统计量秩的有限样本波动贡献 √(log(1/α_ex)/(2n_cal))（Hoeffding/经验 Bernstein）。
5. 四类误差由联合界相加，令 g=L_WΔ+η+√(log(1/α_ex)/(2n_cal))，即得；各缺陷→0 时 g→0，退化为名义证书。∎
（注：该界对 Δ、η、α_ex 单调，是"保守但可审计"的显式折损，不追求最紧。）

### 引理 15（CG-ADC 的近似比与层内可交换）
**陈述**：覆盖目标 F(S)=Σ_r min(1,\|S∩r\|/k_r) 是单调子模函数，预算贪心返回 ≥(1−1/e)·OPT 的覆盖；哈希分层切分保证同一 group 不跨切片，且层内样本按稳定哈希近似均匀，从而层内可交换性成立。
**证明**：
1. 每个 min(1,·/k_r) 是基数覆盖函数的凹截断，单调且子模；子模函数之和仍子模（Nemhauser–Wolsey–Fisher 1978）。
2. 标准贪心对单调子模在基数约束下达到 (1−1/e) 近似。
3. 稳定哈希把 group_id 映射到固定桶，group 内所有样本同侧，故无 group 泄漏；对层内独立同分布样本，哈希只依赖 group_id 而非特征/标签，故不破坏层内可交换性（若 group 划分与标签无关；否则需在 DataCard 中显式记录该假设）。∎

### 引理 16（DG-UCG 的单调退化链延伸）
**陈述**：任意数据层失效下，`Exec_v26 ⊆ Exec_v25 ⊆ …` 恒成立；且 DCC 失效时存在保守回退 Exec_v25(α↑,δ_dyn↑)。
**证明**：
- 定义上 Exec_v26 = Exec_v25 ∩ Fil_data，故包含关系显然。
- 来源缺失/泄漏/覆盖不足/可交换性拒绝/标签噪声超限/不可复现 → `certify()=None` → DG-UCG 拒证 → 回退到 `fallback()` 指定的保守 v25（放宽 α/δ_dyn/β 并冻结探索），不回退到 v24 以下，保持单机物理安全。
- 漂移 Δ_W 超限或 DriftEProcess 触发 → 同一拒证路径，触发再认证。
- 组合失效取交集，单调性保持。∎

### 定理（数据接地的十七证完备性）
**陈述**：`DG-UCG.admits(Π) = True` ⟺ Π 同时满足 v25 的十项（物理接地、云边一致、少样本覆盖、专利、结构、力控、轻量化、语义、重构、协同）**以及**七项数据维度：(11) 来源可溯，(12) 无泄漏，(13) 工况覆盖与 ESS，(14) 可交换，(15) 标签质量，(16) 可复现，(17) 漂移在预算内。
**证明**：`admits` 先过 DCC 六项与漂移门，再过 DCCT 三项折损门，最后合取 `src_usc.admits`。必要性与充分性分别逐项对应；由引理 13–16 保证数据层不破坏 v25 的单调链，并在缺陷→0 时精确恢复 v25。∎
