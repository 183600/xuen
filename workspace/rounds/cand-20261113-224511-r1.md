# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配主动交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「联邦学习」×「人机协作」）

> R69 教会闭环「问」：把不确定性拆成 aleatoric / epistemic，用流匹配保住动作模态，用看 / 问 / 触主动消解歧义，并用 (r_res, Δa) 双通道盯防缓变故障。但 R69 的「问」有一个隐藏主语——**它问的是「我」这个单一智能体所拥有的证据源**。它要求「k 个正交证据源一致」，却从未回答：这些证人从哪来？它们真的独立吗？谁有资格当证人？谁有权拍板？
>
> 在真实的人机团队里，证据是**分布式**的：另一台机器人见过这个货架，这位工人知道这条产线的隐含规则，边缘模型见过十万个相似场景。把原始数据集中起来既不可能（隐私 / 带宽 / 产权）也无必要——决策需要的不是数据，而是**各方对同一个潜变量的局部后验**。这正是联邦学习的形状。但直接 FedAvg 参数 / 策略会犯一个致命错误：**把 R69 辛苦保住的多个动作模态平均成一个从未存在过的中间模态**——联邦层面的模式坍缩。
>
> 同时，人机协作提醒我们：**人不是神谕，是合作者**。人有自己的不确定性、偏好、注意力预算、隐私边界，以及最终权威。R69 的「问一次人」在协作语境下必须升级为「**征得同意、最小披露、按角色授权**的多人协商」。
>
> 核心命题：**把不确定性的消解从「单智能体、单神谕」升级为「隐私保护的联邦证据 + 法定人数认证 + 同意 / 权威治理」：只联邦化证据（对数似然 / 模态后验 / 支持集），不联邦化参数；用可测量的条件独立性与拜占庭鲁棒聚合组成法定人数；把隐私预算、同意、角色权威作为硬约束嵌入 VoI；只有当可信且合法的法定人数认证时才行动，否则逐指令退化为 R69（再退化为 R68）。** 命名 **QUORUM-RAS**（Quorate Uncertainty Resolution via Unified Multi-party evidence，法定人数式多边证据消歧）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**谁有资格当证人、他们会不会串供、谁有权替我拍板**」——从「我一个人去问」到「我们这群人是否真的比我更知道」。

## 0. 直觉与动机

**灵感 1（联邦学习 → 证据在边缘，决策在中心）**
直觉：R69 的证据源都长在同一个智能体身上：同一副传感器、同一个 MTM trunk、同一批数据。它们可以「一起错」。而一个团队的价值恰恰在于**每个人看到的不同**：A 机器人有近距离几何，B 有人类长期观察，C 有跨场景先验。联邦学习的形式——数据留在本地、只交换充分统计量——正好匹配「分布式证据」。但关键不是「联邦训练一个更大的模型」，而是「联邦一次**信念更新**」。前者把证据压进参数再读出来，后者直接在决策层合并后验。决策需要的只是后者。

**灵感 2（不要 FedAvg 参数，要 FedBayes 证据 → 联邦模式坍缩）**
直觉：R69 的全部价值在于保留多峰动作分布。若把各方的速度场 / 策略参数做加权平均，得到的不是「更聪明的平均策略」，而是一个**在真实数据上从未出现过的中间策略**——两个模态的中点通常是低密度、甚至危险的区域。这与 R69 警告的模态坍缩同构，只是发生在联邦层：**联邦均值会把「少数但致命」的模态抹掉，而少数派恰恰可能是唯一见过该危险的一方**。因此 R70 的第一条硬规则：**跨边界流动的是证据（对数似然、模态后验、支持集），不是参数；聚合是贝叶斯式的支持并集，不是算术平均。**

**灵感 3（人机协作 → 人是合作者，不是可无限调用的神谕）**
直觉：R69 里的人类是一个「你问、他答、答案变证据」的接口。真实的合作者有五个 R69 没建模的属性：(a) 他自己也不确定，会说「我不知道」——这是关于**他可靠性**的信息，不是关于世界的证据；(b) 他有偏好和价值，**不能被平均**（把两位用户的口味平均成第三个人的口味是荒谬的）；(c) 他的注意力 / 同意 / 隐私是有限资源，不能无限征用；(d) 他有权威，可以否决；(e) 他可能错、可能被骗、可能与别人串供。R70 必须把这些从「假设」变成「约束」。

**灵感 4（对偶 → 信息增益与合法性的对偶）**
直觉：联邦学习许诺「多方数据 → 更好的模型」，隐含假设是**独立且诚实**；人机协作许诺「人 + 机 > 任一」，隐含假设是**目标一致且共享 common ground**。这两个假设都是社会性的，无法仅从数据证明。于是 R70 有两条必须同时满足的轴：**信息轴**（证据是否真的降低了不确定性）与**合法性轴**（这次消解是否被同意、被授权、且未被俘获）。只优化前者会得到一个高效但非法的「多数暴政」；只优化后者会得到一个礼貌但无知的系统。QUORUM 要求两轴同时过门。

**灵感 5（隐私是信息动作的第四种成本）**
直觉：R69 的 MINT 只算物理与社交成本。联邦语境下，「请对方披露证据」本身有隐私成本；而差分隐私加的噪声会**稀释证据**，可能让法定人数恰好凑不齐。这不是 bug，而是一条可计算的前沿：**披露越少越安全，但披露太少就无法认证**。于是交互优化从「最大化 VoI」变成「在满足认证置信度的前提下最小化披露」——把数据最小化原则写进控制器。

**灵感 6（权威分离 → 证据不等于许可）**
直觉：一个高置信的法定人数可以告诉你「世界是什么样」，但不能自动告诉你「你可以做什么」。把二者混在一起，就会出现「算法说可以」的责任真空。R70 显式区分 **epistemic（相信什么）** 与 **deontic（被允许做什么）**：法定人数只认证信念，角色授权（mandate）单独决定许可；人类否决优先，除非触发经过认证的紧急例外。这让「meaningful human control」成为可审计的结构，而非口号。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（QUORUM-RAS 总览）** QUORUM-RAS = (FEA, QAC, MINT-F, SCG, MANDATE, J_QUORUM, RAS-WM†)。参与方集合 P = {p_0, p_1, …, p_N}，p_0 为本体机器人，其余为人类 / 机器人 / 边缘模型。三不变式：
(i) **数据最小化**：原始数据、原始观测与参数不出本地，跨边界只有经校准、可加噪的证据充分统计量；
(ii) **无人可单独定案**：任何模态认证需一个合法法定人数 Q ⊆ P（定义 313–314），否则输出 UNVERIFIED 并退化；
(iii) **同意 / 隐私 / 权威为硬约束**：无同意不查询、超预算不查询、越授权不执行。

**定义 311（本地证据与共享接口）** 对 R69 AUD 给出的模态假设 M ∈ {1,…,K̂}，参与方 p 在本地计算证据
e^{(p)} = (ℓ^{(p)} ∈ ℝ^{K̂}, supp^{(p)} ∈ {0,1}^{K̂}, cal^{(p)})，
其中 ℓ^{(p)}_k = log p_p(o^{(p)} | M=k)（可由本地模型、人类判断或本地小样本给出），supp 表示该方是否「见过 / 支持」该模态，cal 为本地校准参数。只有 e^{(p)} 或其 ε_p-DP 版本可跨边界；o^{(p)} 与 θ_p 永不离开。

**定义 312（联邦证据聚合 FEA）** 给定权重 w_p（由信任与独立性给出，定义 318），聚合对数证据
ℓ̂_k = Σ_{p∈Q} w_p ℓ^{(p)}_k，后验 ŵ_k ∝ exp(ℓ̂_k) · 1[k ∈ Supp(Q)]，
其中 Supp(Q) = ∪_{p∈Q} supp^{(p)}。**支持保持原则**：若 k ∈ supp^{(p)} 且 trust_p ≥ τ_t，则 k 必须保留且 ŵ_k ≥ w_min（不得因平均而归零）。这与参数空间 FedAvg 形成对照（定义 317）。

**定义 313（条件独立审计 QAC 与有效独立数）** 对 p,q 估计给定 M 后的证据条件依赖 ρ_{pq} = Î(e^{(p)}; e^{(q)} | M)（留出集 / 自助法），组成相关矩阵 R。有效独立数
k_eff(Q) = (tr R)² / tr(R²)（参与率），或保守地取 1/λ_max(R)。
法定人数 Q 是**统计合法**的，若 |Q| ≥ q、k_eff(Q) ≥ q_eff，且合并证据通过预注册的 e-value 检验（水平 α）。这把 R69 的「假设正交」变成「测量正交」。

**定义 314（法定人数合法性与共识俘获）** 设 Q 中拜占庭 / 串谋比例为 f，名义独立但因共享偏置而实际串谋的有效比例为 f_eff（由 R 的主特征向量集中度给出）。合法法定人数要求 f_eff < 1/2（多数 / 中位数聚合）且 N ≥ 3f+1（BFT 通信界）；否则拒证。**共识俘获**定义为：在 f_eff 或 R 被误估时，Q 认证了一个与 p_0 本地证据及后续观测都矛盾的模态。俘获检测用「事后反证率」与「跨情境一致性」。

**定义 315（联邦 VoI 与隐私预算 MINT-F）** 候选查询 g = (p, 查询类型, 披露级别 ε_p)。加噪证据 ℓ̃^{(p)} = ℓ^{(p)} + Lap(Δ/ε_p)。定义
V_fed(g) = I(M; ℓ̃^{(p)}_g | o) − λ_p ε_p − c_int(g) − c_soc(g)，
选择 g* = argmax V_fed，s.t. consent(p,g)=1、ε_p ≤ B_p、认证后验概率 P_cert ≥ 1−δ。无可行 g ⇒ 不查询，UNVERIFIED，退化 R69 / R68。

**定义 316（最小必要披露前沿）** 令 P_cert(ε) 为总隐私花费 ε 下法定人数认证成功的概率。假设其关于 ε 单调不降，则最小披露 ε*(δ) = inf{ε : P_cert(ε) ≥ 1−δ}。控制器在 ε* 处查询——**只披露认证所必需的最小信息**；任何 ε > ε* 视为违反数据最小化，除非由风险等级显式授权。

**定义 317（支持保持与联邦模式坍缩 FMC）** 定义联邦模式覆盖率 Cov(π) = Σ_k 1[π_k ≥ w_min] · 1[k ∈ Supp]。参数 FedAvg 得到的 π_avg 可能满足 Cov(π_avg) < max_p Cov(π_p)（引理 19），而 FEA 保证 Cov(π_FEA) = |Supp(Q)| / K̂ ≥ max_p Cov(π_p)。FMC 风险定义为 W₂(π_true, π_fed) − W₂(π_true, π_FEA) > 0 的区域；这是 R69 模态坍缩在联邦层的镜像。

**定义 318（上下文信任与弃权）** 每方信任 t_p 是一个按任务域索引的 Beta 后验，按「证据与最终认证模态的一致性、校准、以及是否被后续反证」更新：t_p ← Beta(a_p+Δa, b_p+Δb)。信任**不是全局人格评分**，而是「在这个任务、这个域上，该证人的话有多可信」。人类 / 模型说「我不知道」是一个 abstention，更新 t_p 的可靠性而非 M 的后验（定义 325）。

**定义 319（共享安全先验与个性化偏好）** 团队维护共享安全先验 π_0（「什么普遍不安全」，需鲁棒聚合）与每方个性化偏好 π_p（「这位用户想要什么」，**保持本地、不聚合**）。决策后验 ∝ π_0 · Π_p (π_p)^{λ_p} · 证据；安全先验可联邦，价值偏好只做 personalized federation，防止把少数群体的偏好抹平。

**定义 320（角色与权威 MANDATE）** 对每个动作类 a，授权 m(a) ∈ {autonomous, confirm, veto}。法定人数输出信念后验与风险；MANDATE 将 (信念, 风险, 法规) 映射为许可：
perm(a) = 1 ⇔ risk(a|Q) ≤ ρ_{m(a)} ∧ (m(a)=autonomous ∨ human_confirm=1) ∧ human_veto=0。
**证据不产生许可**：即使后验 99.9%，m(a)=confirm 仍需确认。

**定义 321（异步、陈旧与两级时标）** 各方证据带时间戳 τ_p；陈旧证据按 exp(−(t−τ_p)/τ_half) 降权。联邦协商在「审议频率」（1–5Hz / 事件触发）运行，绝不进入 R69 的 2.6ms 内环；超时即回退，安全环永不被网络阻塞。

**定义 322（证书 J_QUORUM）** J_QUORUM = (J_FLUID, quorum_id, k_eff, independence_audit_p, privacy_spend_vector, consent_ledger_hash, mandate_used, mode_coverage, fmc_guard, quorum_ver)。Valid ⇔ Valid(J_FLUID) ∧ Q 统计合法 ∧ 同意 / 隐私 / 授权均满足 ∧ 无俘获嫌疑。

**定义 323（退化边界与严格包含）** 若 N=1、无同意方、k_eff < q_eff、隐私预算耗尽、认证超时或俘获嫌疑 ⇒ 不启用联邦，逐指令执行 R69（其自身在 VoI ≤ 成本时退化 R68）。故 QUORUM 在「无法组成合法法定人数」边界上逐指令等于 R69。

**定义 324（联邦审计 VQAuditor-Q）** 审计对象：法定人数构成是否合法、独立性估计是否被污染、隐私披露是否最小、人类是否被诱导 / 自动化偏见、个性化偏好是否被平均、否决是否被尊重。结论回灌信任先验与下一轮 Q 的组成策略。

**定义 325（弃权与元不确定性通道）** 人类 / 模型可输出 abstain 或 low_confidence。弃权不改变 M 的似然，只降低该方在本次 Q 中的有效权重并更新 t_p；若弃权比例过高，Q 判为信息不足 ⇒ UNVERIFIED。这把「诚实的不知道」从失败变成一等公民。

**定义 326（互惠与贡献计量）** 维护贡献账本：长期提供被采纳证据的参与方在后续查询与资源分配中获得优先权（reciprocity）；只受益不贡献（free-riding）的参与方信任与配额衰减。互惠是长期人机协作的激励相容条件，也是防止「公共品困境」的结构。

```python
# IP-264 FEA：联邦证据聚合（反对参数平均；只合并后验充分统计量）
def aggregate_evidence(evidence, trust):
    # evidence[p] = (loglik[K], supp[K], cal)；永不接触原始数据/参数
    K = len(next(iter(evidence.values())).loglik)
    num, den, supp = zeros(K), 0.0, zeros(K, dtype=bool)
    for p, e in evidence.items():
        l = calibrate(e.loglik, e.cal)           # 本地校准后再共享
        w = trust[p].mean()
        num, den, supp = num + w * l, den + w, supp | e.supp
    logpost = num / max(den, eps)
    logpost[~supp] = -inf                         # 无任何可信支持 -> 不下结论
    return preserve_minority(softmax(logpost), evidence, trust, w_min=1e-3)

# IP-265 QAC：条件独立性审计 + 法定人数判定
def quorum_valid(evidence, Q, R, alpha, q, q_eff):
    k_eff = (trace(R) ** 2) / trace(R @ R)       # 有效独立数（参与率）
    if len(Q) < q or k_eff < q_eff:
        return False, k_eff
    e = merge_evidences({p: to_evalue(evidence[p]) for p in Q})  # 依赖鲁棒合并
    return e_test(e, alpha), k_eff                # 通过才可认证

# IP-266 MINT-F：隐私约束下的最小披露查询
def choose_federated_query(modes, parties, budgets, delta):
    best = None
    for p in parties:
        if not consent(p) or budgets[p].privacy <= 0:
            continue
        for q in query_types(p):
            eps_star = min_disclosure(p, q, target=1 - delta)    # 定义 316
            if eps_star > budgets[p].privacy:
                continue
            v = fed_voi(q, eps_star) - privacy_price * eps_star - cost(p, q)
            if best is None or v > best.v:
                best = (p, q, eps_star, v)
    return best if best and best.v > 0 else None

# IP-267 MANDATE：证据 -> 许可（权威与信念分离）
def authorize(action, post, risk, mandate, human):
    if human.veto:
        return DENY
    rule = mandate[class_of(action)]
    if rule == "autonomous":
        return ALLOW if risk <= rho_auto else DENY
    if rule == "confirm":
        return ALLOW if human.confirmed else DEFER
    return DENY                                    # veto class

# IP-274 主闭环（继承 R69，仅在“问谁”处插入联邦层；联邦异步、不入内环）
def QUORUM_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)   # R68/R69
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    # 1) 本地证据 + 已有的（缓存）联邦证据；缺证据则本回合走 R69
    e0 = local_evidence(modes, o)
    Q, ev, R = M.fea.form_quorum(e0, M.parties, M.trust, M.budget)  # 只取同意方
    # 2) 合法法定人数 -> 联邦认证；否则退化单智能体
    if Q and M.qac.quorum_valid(ev, Q, R, alpha, q, q_eff):
        post, certified = M.fea.aggregate_evidence(ev, M.trust), True
        U_epi_after = epistemic_of(post)
    else:
        g = M.mint.choose_interaction(modes, o, M.budget) if U_epi > TAU_EPI else None
        post = M.cia.update_belief(modes, M.cia.execute(g)) if g else modes
        certified, U_epi_after = False, epistemic_of(post)
    # 3) 只有“被合法认证”的消解才享受 resolution bonus
    U_floor = U_ale + (0.0 if certified else U_epi_after)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    mode = select_mode(post, U_epi_after, lam)
    A = M.ach.propose(mode.a, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    # 4) 证据 -> 许可；人类否决优先，越权即延迟
    if not M.mandate.authorize(mode.a, post, risk(A), M.mandate.rules, M.human):
        return 0, max(lam, 1.0), DEFER
    # 5) 审计与证书
    M.vqa_q.submit(Q, ev, R, cert=J_QUORUM(...))
    return k, lam, mode, (U_ale, U_epi_after)
```

## 3. 推导

假设 A99（客户端策略可由线性化流 / 一阶近似，模态间距 Δ_min ≥ 3σ_in，支持保持可定义）；A100（证据近似高斯，相关矩阵 R 在留出集上稳定可估）；A101（DP 机制 Fisher 信息随 ε 单调，P_cert 单调）；A102（除 Q 外，本体证据与后续观测可作为独立反证）。

**引理 19（证据聚合 vs 参数平均的模态保持）** 设各客户端真实策略对应多模态分布，且存在互不重叠的支持模态。在 A99 下，参数空间 FedAvg 的平均速度场 v̄ = Σ w_p v_{θ_p} 采样出的轨迹会滑向模态之间的低密度「峡谷」；当两个支持模态分离 Δ_min 时，π_avg 在任一原模态邻域的质量可任意小。相反，支持保持聚合 π_FEA 满足 Supp(π_FEA) = ∪ Supp(π_p)，且每个可信支持模态质量 ≥ w_min，故 Cov(π_FEA) ≥ max_p Cov(π_p) ≥ Cov(π_avg)。**系**：联邦层必须合并证据而非参数，否则 R69 保留模态的努力在上层被抵消。

**引理 20（相关性修正与置信度校准）** 若 Q 中证据条件相关，R 的最大特征值 λ_max > 1，则朴素相加把有效样本量从 k_eff 夸大为 |Q|，对数优势被放大 ≈ |Q|/k_eff 倍。在 A100 下，未修正的误认证概率随该比值指数上升；以 1/λ_max 做温度缩放后，合并证据的 KL 散度不超过真实联合信息量。**系**：k_eff 不是修辞，而是必须进入认证阈值的物理量；「证人越多越可信」在没有独立性审计时是错的。

**引理 21（最小披露的单调性与存在性）** 对 ε-DP 机制，证据的 Fisher 信息随 ε 单调不增（Laplace 噪声方差 ∝ 1/ε²）；在 A101 下 P_cert(ε) 单调不降，故 ε*(δ) 存在，且是满足认证的最小披露。**系**：在给定风险等级下，多问一句 / 多披露一点若超过 ε*，既无认证收益，又违反数据最小化；隐私不是事后过滤，而是查询设计的约束。

**引理 22（共识俘获阈值与有效串谋率）** 设 Q 中真实拜占庭 / 串谋比例为 f，中位数 / 截尾聚合的崩溃点为 f < 1/2。但若独立性估计使用被污染的 R，则有效串谋率 f_eff 可接近 1：当所有证人共享同一文化 / 训练先验时，它们的证据高度相关，名义上的 N 个证人实际只提供一个方向的信息。此时即使名义 f 很小，认证也会系统性偏向俘获模态。**系**：安全阈值必须建在 f_eff 与 k_eff 上，而不是名义人数上；「更多证人」不等于「更可信」。

**定理 18（QUORUM 严格包含 R69）** 在 A99–A101 下，QUORUM 在任意状态的期望风险 ≤ R69；当无合法法定人数（N=1 / 无同意 / k_eff < q_eff / 隐私耗尽 / 俘获嫌疑）时，两者**逐指令相同**。因此安全侧不让步，协作侧获得信息增益；R69 是 QUORUM 在「无法组成合法法定人数」边界上的严格退化。

**定理 19（异构性是收益，也是攻击面）** 在条件独立、信任校准且无俘获的假设下，联邦后验的期望对数损失 ≤ 任一方，团队相对最优单方的增益等于 I(M; o^{(Q)} | o^{(0)})，上界由 k_eff 给出。当相关性被误估或 f_eff ≥ 1/2 时，增益可变为负。**故「团队 > 个体」不是无条件定理，而是有合法性前提的条件定理**——这正是 R70 把治理写进数学的原因。

**定理 20（证据-权威分离的无突变）** 若法定人数只更新信念、MANDATE 单独裁决许可，则任何被允许动作的风险包络与 R69 相同；否决 / 确认 / 拒绝只会收缩动作集合，不会扩张安全包络；超时或退化路径单调回到 R69。故控制连续、无突变，且人类权威不被证据置信度架空。

## 6. 本轮最大风险

**一句话**：QUORUM-RAS 的安全证书最终押在「法定人数是合法且未被俘获的」这一前提上——而**合法性本身是用被俘获方提供的证据估计出来的**：当串谋者、Sybil 身份、或仅仅是共享同一文化 / 训练偏置的人类与模型一起点头时，独立性审计与信任状态会被共同污染，系统会「制造确定性」并把 R69 的「一个骗子」升级为「一群证人盖章的谎言」；**被俘获的法定人数，比一个诚实说『我不知道』的单人更危险。**

**次级风险与缓解**：
1. **隐私反噬**（证据 / 梯度反演泄露）→ DP 预算 + 证据最小化 + 安全聚合；E304/E305；
2. **联邦延迟击穿安全环** → 两级时标，联邦只做异步审议，超时逐指令回退（定义 321、定理 18）；
3. **非 IID 稀有模态丢失** → 支持并集 + 少数模态保底 + E314；
4. **自动化偏见 / 权威空心化** → 证据-许可分离 + 人类否决硬约束 + E309；
5. **free-riding 与长期激励崩溃** → 贡献账本 + 互惠配额（定义 326、E313）。

```python
# IP-264 FEA：联邦证据聚合（反对参数平均）
def aggregate_evidence(evidence, trust):
    K = len(next(iter(evidence.values())).loglik)
    num, den, supp = zeros(K), 0.0, zeros(K, dtype=bool)
    for p, e in evidence.items():
        l = calibrate(e.loglik, e.cal)            # 本地校准后再共享
        w = trust[p].mean()
        num, den, supp = num + w*l, den + w, supp | e.supp
    logpost = num / max(den, eps)
    logpost[~supp] = -inf                          # 无可信支持 -> 不下结论
    return preserve_minority(softmax(logpost), evidence, trust, w_min=1e-3)

def quorum_valid(evidence, Q, R, alpha, q, q_eff):
    k_eff = (trace(R)**2) / trace(R @ R)
    if len(Q) < q or k_eff < q_eff: return False, k_eff
    e = merge_evidences({p: to_evalue(evidence[p]) for p in Q})

    if human.veto: return DENY
    rule = mandate[class_of(action)]
    if rule == "autonomous": return ALLOW if risk <= rho_auto else DENY
    if rule == "confirm":    return ALLOW if human.confirmed else DEFER
    return DENY

# IP-274 主闭环（继承 R69，联邦异步、不入内环）
def QUORUM_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    e0 = local_evidence(modes, o)
    Q, ev, R = M.fea.form_quorum(e0, M.parties, M.trust, M.budget)   # 仅同意方
    if Q and M.qac.quorum_valid(ev, Q, R, alpha, q, q_eff):
        post, certified = M.fea.aggregate_evidence(ev, M.trust), True
        U_epi_after = epistemic_of(post)
    else:
        g = M.mint.choose_interaction(modes, o, M.budget) if U_epi > TAU_EPI else None
        post = M.cia.update_belief(modes, M.cia.execute(g)) if g else modes
        certified, U_epi_after = False, epistemic_of(post)
    U_floor = U_ale + (0.0 if certified else U_epi_after)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    mode = select_mode(post, U_epi_after, lam)
    A = M.ach.propose(mode.a, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if not M.mandate.authorize(mode.a, post, risk(A), M.mandate.rules, M.human):
        return 0, max(lam, 1.0), DEFER
    M.vqa_q.submit(Q, ev, R, cert=J_QUORUM(...))
    return k, lam, mode, (U_ale, U_epi_after)
```

## 4. 推导

**引理 19（证据聚合 vs 参数平均的模态保持）** A99（线性化流、模态间距 `Δ_min≥3σ_in`、支持可定义）下，参数 FedAvg 的平均速度场采样会滑向模态间低密度峡谷，`π_avg` 在原模态邻域质量可任意小；支持保持 FEA 满足 `Supp(π_FEA)=∪Supp(π_p)` 且每模态 `≥w_min`，故 `Cov(π_FEA)≥max_p Cov(π_p)≥Cov(π_avg)`。系：联邦层必须「FedBayes 证据」，不能「FedAvg 参数」。

**引理 20（相关性修正）** 若 R 的 `λ_max>1`，朴素相加把有效样本量从 `k_eff` 夸大为 `|Q|`，对数优势放大 `≈|Q|/k_eff` 倍；A100 下未修正的误认证概率随该比值指数上升；以 `1/λ_max` 温度缩放后，合并证据的 KL 不超过真实联合信息量。系：k_eff 必须进入认证阈值。

**引理 21（最小披露存在性）** A101 下，ε-DP 证据的 Fisher 信息随 ε 单调不增，`P_cert(ε)` 单调不降，故 `ε*(δ)` 存在且是认证所需的最小披露。系：超过 ε* 的披露既无认证收益又违反数据最小化。

**引理 22（共识俘获阈值）** 名义拜占庭比例 f 的崩溃点为 `f<1/2`；但实际证据共享文化 / 训练偏置时，有效串谋率 `f_eff` 可接近 1——N 个证人只提供一个方向的信息。此时即使名义 f 很小，认证也系统性偏向俘获模态。系：阈值必须建在 `f_eff` 与 `k_eff` 上，「更多证人」≠「更可信」。

**定理 18（QUORUM 严格包含 R69）** A99–A101 下，QUORUM 任意状态期望风险 ≤ R69；且当 `N=1`、无同意、`k_eff<q_eff`、隐私耗尽或俘获嫌疑时两者逐指令相同。R69 = 「无法组成合法法定人数」边界；安全不让步，协作获信息增益。

**定理 19（异构性是收益也是攻击面）** 条件独立 + 信任校准 + 无俘获时，联邦后验期望对数损失 ≤ 任一方，团队增益 = `I(M; o^{(Q)}|o^{(0)})`，上界由 k_eff 给出；相关性误估或 `f_eff≥1/2` 时增益可为负。故「团队 > 个体」是带合法性前提的条件定理。

**定理 20（证据-权威分离的无突变）** 法定人数只更新信念、MANDATE 单独裁决许可 ⇒ 被允许动作的风险包络与 R69 相同；否决 / 确认 / 拒绝只收缩动作集合；超时 / 退化单调回 R69。故控制连续、无突变，人类权威不被置信度架空。

## 7. 本轮最大风险

**一句话**：QUORUM-RAS 的安全证书最终押在「法定人数是合法且未被俘获的」这一前提上——而**合法性本身是用被俘获方提供的证据估计出来的**：当串谋者、Sybil 身份、或仅仅是共享同一文化 / 训练偏置的人类与模型一起点头时，独立性审计与信任状态会被共同污染，系统会「制造确定性」并把 R69 的「一个骗子」升级为「一群证人盖章的谎言」；**被俘获的法定人数，比一个诚实说『我不知道』的单人更危险。**

**次级风险与缓解**：隐私反演（DP + 证据最小化 + 安全聚合，E304/E305）；联邦延迟击穿安全环（两级时标、异步审议、超时逐指令回退，定义 321/定理 18）；非 IID 稀有模态丢失（支持并集 + 少数模态保底 + E314）；自动化偏见 / 权威空心化（证据-许可分离 + 人类否决硬约束 + E309）；free-riding 与长期激励崩溃（贡献账本 + 互惠配额，定义 326/E313）。
