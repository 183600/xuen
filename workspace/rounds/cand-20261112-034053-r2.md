# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化证据承诺」IP-133~138；灵感循环第 2 轮；本轮灵感：「运动控制」×「力觉传感」）

> 第 57 轮把证据做得可校准、可对账、可个性化，却仍把"接触"当成一个**离散开关**：L0/L1/L2 三级、探针是原子观测、承诺是一次性判定。它自己的风险自陈暴露三个盲点：**(a)** 它从未问"用多大力、多快、压多久"——真正的损伤由力-位-时的连续轨迹决定，而不是"是否接触"这个布尔量；**(b)** 它把每个探针当独立样本，但在力觉体系里**探针是一次受控激励**，同一次激励同时驱动视觉/触探/本体多个模态，反而制造相关——第 57 轮 XMC 的"条件独立"假设，恰恰被它自己的探针破坏；**(c)** 它的证据没有"机械价格"：在脆弱表面上，区分"软"与"脆"所需的激励幅度可能已经越过损伤阈值，有些证据根本买不起。本轮两个灵感各补一条腿：**力觉传感**把接触从离散开关变成连续的力-速度-阻抗包络，安全阀从"是否承诺"变成"沿可行包络多紧地执行"；**运动控制**把探针从原子观测变成受约束的最优控制/对偶控制，把"激励"这一自由量显式化。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为 **"可负担的证据、可证安全的接触、可解耦的激励"**。

核心矛盾：
- **H29（激励 vs 安全）**：辨识刚度/脆性需要足够的力×位移激励，安全却恰恰限制激励幅度；存在"安全力预算 < 辨识阈值"的 **SU（safe-unidentifiable）区域**——证据第一次有了机械价格，而且有些价格在安全约束下永远付不起。
- **H30（连续接触 vs 离散承诺）**：决定损伤的是力/速度/累计功的轨迹，而非离散等级；但把安全交给高频连续控制，又引入"1 kHz 反射 vs ≤1 Hz 推理"的时间尺度冲突，以及力觉饱和、漂移、时延与串扰。
- **H31（激励制造的模态相关）**：探针控制同时驱动多个模态，使第 57 轮"声明性条件独立"失效——力与本体对同一次压入的响应天然共模；独立必须由**激励设计挣得**，不能靠声明。

## 0. 直觉与动机

**灵感 1（力觉传感 → 接触是连续包络，证据是轨迹而非样本）**
直觉：第 57 轮问"这个区域值不值得碰"，力觉传感逼我们改问"以多大的力、多快的速度、压多久去碰才既安全又能看清"。一次接触不是抛硬币，而是一条 (f(t), v(t), x(t)) 曲线：刚度是它的斜率、滑移是它的毛刺、损伤是它的功积分。于是"每个探针一个似然"要升级为"每条轨迹一组充分统计量"，而安全的可行域不是"能否接触"，而是力-速度-阻抗空间里一张随证据收放的**包络**。包络之内，接触本身就是安全动作；承诺只是把动作开到包络边缘。

**灵感 2（运动控制 → 探针即最优控制，安全性即前向不变性）**
直觉：既然探针是轨迹，选探针就是选控制输入。经典的对偶控制（dual control）早就说清：最优控制必须同时"激励以学习"和"收敛以达成"。本轮把探针合成为有限时域、受安全约束的最优实验设计：**最大化每焦耳机械代价换来的信息增益**，并用控制屏障函数（CBF）保证整条轨迹落在包络内。更关键的是把安全交给一个独立的**反射安全层**：在任何承诺判定之下，1 kHz 的力反馈过滤器和 CBF 都在实时否决越界命令——安全因此不再依赖高层信念是否正确。

**灵感 3（激励-安全两难 → 可辨识性下界与"买不起的证据"）**
直觉：用噪声 σ_f 的力传感器把刚度 κ 估到误差 ε，需要足够的位移/力范围（Cramér–Rao 下界）：激励幅度 ∝ σ_f/ε，而峰值力 ∝ κ·幅度。若表面安全力上限 F_safe 低于辨识所需的 F_req(ε)，则**任何**遵守安全包络的策略都无法把 κ 辨识到 ε——不是算法不够好，而是物理上买不起。系统必须识别这种 SU 区域并诚实降级：绕行、改用非接触证据、请人用外部工具，而不是假装"多探几次就行"。

**灵感 4（合流 → 独立性由激励设计挣得，反射证据是单侧的）**
直觉：跨模态一致性曾是第 57 轮最强的新证据；但力觉与本体是同一压入的两种读数，共模相关会让"假一致"骗过系统。解法不是放弃一致性，而是让 DPC 主动设计**解耦激励**（法向压入 vs 切向扫掠激发不同模态响应方向），只有激励可分性 D_sep 达标的探针才有资格产生 EV-xmodal。另一个微妙结论：反射层的"未触发"是**右删失**，不能当作"安全"的正证据——只有"触发"才携带信息。于是安全过滤只能证伪、不能证实，这正好与"不可逆接触需要正证据"互补。

**灵感 5（PCX++ → 探-诺-演闭环接上两个时间尺度）**
直觉：高层以低频做元推断/对账/承诺，低层以高频做 CBF 过滤；两者之间用"陈旧膨胀"桥接——信念越久未更新，反射层用的包络越保守。证据只能把包络沿格（lattice）单调加宽，且只在非接触的安全同步点提交，避免"边压边改安全线"。这样三套机制各守一关：元先验给效率、共形/包络给保守、反射层给最后一道不可被人否决的闸门。

## 1. 形式化定义（增量：定义 139–145）

**定义 139（接触包络与轨迹证据 FCE）** 接触状态 z=(f_n,f_t,v,δ,s)，区域 r 的安全包络
𝒮_r={ (f,v): f_n≤F_n^max(r), ‖f_t‖≤μ̂(r)f_n (摩擦锥), f·v≤P_max(r), ∫(f·v)^+dt≤D_max(r) }。
每条限值带后验，认证包络取保守下置信界 Ŝ_r(α_env)={…Q_α(F_n^max)…}⊆𝒮_r。一段接触轨迹 y_{0:T}=(f(t),v(t),x(t),a(t)) 的轨迹证据为充分统计量
E_traj=(κ̂, μ̂, P_peak, W_cum, slip_events, δ_max)，由 f_n–δ 回归、切向stick-slip、耗散功积分得到；原子 EV-probe 仅保留为 E_traj 的退化特例。

**定义 140（激励-安全可辨识下界 ISB）** 接触律 f_n=κδ^β，噪声方差 σ_f²。由 Cramér–Rao，估 κ 至误差 ε 至少需峰值位移 δ_req=c·σ_f/ε（对 β=1），对应所需峰值力
F_req(ε)=κ·(c·σ_f/ε)^β。
若 F_n^max(Ŝ_r)<F_req(ε)，称 r 关于 ε 为 **安全-不可辨识（SU）**。命题（买不起的证据）：对任意策略 π，若全程 f∈Ŝ_r，则 P(|κ̂−κ|≤ε)≤p_max(σ_f,δ_max)<1，不存在可签发证书。SU 区域由不可负担证据账本 U 记录，禁作不可逆接触的正证据。

**定义 141（对偶探针控制 DPC）** 检查点处对探针求解有限时域问题
max_{u_{0:T}} RVOI(a)=I(θ;y_{0:T}|a) / (c_W·E[W(a)]+c_F·E[max_t‖f_t‖]+c_S·E[slip])
s.t. x_{t+1}=F(x_t,u_t), f_t=G(x_t,u_t), h(f_t,v_t)≥0（CBF），T≤T_probe, ‖u‖≤u_max。
RVOI 即"每焦耳信息增益"（bits/J）。求解 anytime：维护当前可行 incumbent，超时即返回 incumbent（安全可行），绝不以未收敛解替代。

**定义 142（反射安全层 RSL 与单侧证据）** 给定高层名义指令 u_nom，1 kHz 求解
u*=argmin_u ‖u−u_nom‖²_Q s.t. ḣ≥−α h(f_meas,v_meas), f_meas∈Ŝ_r^inflate。
不可行则 u*=u_retreat（顺从退让）。RSL 拥有**硬否决权**：任何 auth/个性化/高层信念都不能旁路它，只有物理急停或包络重认证可改。反射证据单侧：trip ⇒ 危险的正证据；no-trip ⇒ 右删失（似然比恒 1），**不得**计入不可逆接触的正证据。

**定义 143（双时间尺度证据-控制一致性 TRC）** 反射周期 Δ_r≈1 ms，推理周期 Δ_d≤1 s。任何时候反射层使用陈旧膨胀包络
Ŝ_r^inflate(t)=Inflate(Ŝ_r, γ(t−t_last_update))，
越陈旧越保守。包络只允许沿认证格 **单调加宽**（join），且仅当新包络仍是真实 𝒮_r 的子集、且当前非接触（或力低于阈值）时提交；禁止在接触中突变安全线。高层停顿、丢帧、超时都不改变反射层的前向不变性。

**定义 144（力域证据门 FSE⁺、设计性独立与证书 J_f）** 证据类：
EV-traj（须 f∈Ŝ_r、CBF 残差≥0、Fisher 信息≥I_min、且 r∉U）；EV-xmodal（限 L1，且须 D_sep(a)≥θ_sep ∧ r∉U）；EV-margin/EV-visit（继承）；EV-human（继承 auth 佐证）。
设计性独立
D_sep(a)=1−Σ_{m≠m'}E[⟨J_m u,J_{m'}u⟩] / Σ_m E‖J_m u‖²，
即探针激励的共模占比之补；只有被 DPC 解耦的探针才可主张条件独立。不可逆接触必要证据集仍为 {EV-traj∨EV-margin}∪佐证，且新增排除 U。证书 J_f=(J_p 全项, env_θ/Ŝ_r, W_cum/trip_log, D_sep, ISB_class, U, reflex_log, trc_last_update)。

**定义 145（探-诺-演++ 算子 PCX++）** 每检查点：①TRC 取膨胀包络；②ISB 分类——SU ⇒ 直接进入绕行/外部工具/人工，不浪费探针；③DPC 合成探针（RVOI 最优、CBF 约束、anytime）；④执行经 RSL 过滤，回填 FCE 轨迹统计；⑤对账：D(r)>θ_D 且未做共识探针 ⇒ 发最大分歧模态的解耦探针（预算 k_cons，且须 D_sep 达标才可计入 EV-xmodal）；⑥承诺 ⇔ ∃g:R≤δ_f(g) ∧ FSE⁺ 过 ∧ 反射层可维持 Ŝ_r 前向不变；否则 VOI 元悲观 ≥θ_voi 继续探，探尽→绕行→降档→L2 协商（τ_int(auth)）或安全停。四态扩展为 {承诺, 绕行, 外部工具/人工, 安全停}。

## 2. 关键算法伪代码（完整版见产物区）

```python
def contact_envelope_update(env, r, traj):            # IP-139: 轨迹→包络
    stats = traj_stats(traj)                          # kappa,mu,P_peak,W_cum,slip
    env.theta[r] = bayes_update(env.theta[r], stats)
    env.S[r] = lcb_envelope(env.theta[r], alpha_env)  # 只取保守下界
    return env, stats

def dual_probe_control(cp, env, belief, H):           # IP-141: 探针即控制
    best = safe_nominal(cp)
    for _ in anytime_iterations():                    # 超时即停
        u = optimize(H, obj=rvoi, cons=[cbf(env.S[cp.region])], warm=best)
        if feasible(u): best = u
    return best                                       # 永远返回可行 incumbent

def reflex_filter(u_nom, x, f, env, r):               # IP-142: 硬否决
    h = margin(inflate(env.S[r], stale_age(r)), f)    # IP-143 陈旧膨胀
    u = solve_qp(min_norm(u - u_nom), cbf(h, f, alpha))
    return u if u is not None else RETREAT            # 不可行→顺从退让
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| FCE | O(N_traj) 更新/查询 O(1) | O(\|V\|·k_env) | Ŝ_r⊆𝒮_r（A41）、单调加宽 |
| ISB | O(1)/区域（Fisher 闭式）+O(N_env) | O(\|V\|) | F_req 诚实、U 账本完整（A43） |
| DPC | O(iter·H(n²+n\|u\|))，anytime 有界 | O(H·n) | 只返回可行 incumbent（A44） |
| RSL | O(\|u\|³) QP/1ms tick | O(\|u\|²) | CBF 前向不变、硬否决（A42） |
| TRC | O(1) 膨胀 | O(1) | 陈旧只增保守（A45） |
| FSE⁺ | O(\|σ\|) | O(\|σ\|) | SU 禁正证据、D_sep 达标（A46） |
| PCX++ | O(\|CP\|·(iter·H·n²+k_c)+\|CP\|·A\*) | O(\|V\|+\|σ\|) | 四态完备、k_p+k_c 终止 |

**正确性定理（Force-Certified Contact Soundness, FCCS 概要）**：在 A37–A40 上加
(A41) 包络可靠性：Ŝ_r⊆𝒮_r 以 ≥1−α_env 成立且单调加宽；
(A42) 反射层：在扰动/时延界内 CBF 前向不变，且 RSL 不可被 auth 旁路；
(A43) 可辨识性账本诚实：F_req 与 U 无漏记；
(A44) DPC anytime 只输出可行解；
(A45) 陈旧膨胀只增保守；
(A46) 设计性独立：仅 D_sep≥θ_sep 的探针可产生 EV-xmodal。
则：
(i) **安全与高层解耦**：只要 A41∧A42 成立，不可逆接触的物理安全不依赖元先验/对账/人是否正确；高层错误只导致更保守（更小包络、绕行），不导致越界。
(ii) **不可负担证据不伪造**：r∈U 时 FSE⁺ 拒绝签发 EV-traj 正证据（由 ISB 命题）。
(iii) **单侧反射证据守恒**：no-trip 不计入正证据，避免删失偏差。
(iv) 部署界：P_safe ≥ 1−δ_env−δ_reflex−δ_sensor−Σ_cp(δ_f+ε_meta+δ_probe+ε_h+δ_ood·α_conf+δ_xm·1[L1])；注意此界把"信念正确"从安全必要条件降级为效率条件，**代价是 δ_env+δ_reflex+δ_sensor 成为新的单点**。

## 6. 本轮最大风险

**一句话**：本轮把安全的最后一道闸门从"高层的证据判定"下移到"依赖力觉的反射包络"，于是单点故障由"坏先验"换成"**坏包络 + 坏力觉**"——一旦安全包络在最需要保守时被高估（而力觉恰在接近损伤时饱和/漂移），反射层会以"完全合规"的姿态、且按设计不可被人否决地，把系统径直压向一个错误的极限。

### IP-139 FCE（接触包络与轨迹证据）

```python
def traj_stats(traj):
    kappa = regress_slope([(d, f_n) for f_n, f_t, v, d, t in traj])   # f_n=κδ^β
    mu    = stick_slip_ratio(traj)
    W     = sum(max(0.0, dot(f, v)) * dt for f, v, dt in traj)
    slip  = count_events(traj, kind='tangential_drop')
    return Stats(kappa=kappa, mu=mu, P_peak=max(f_n for f_n,*_ in traj),
                 W_cum=W, slip=slip, delta_max=max(d for *_, d, t in traj))

def contact_envelope_update(env, r, traj):
    env.theta[r] = bayes_update(env.theta[r], traj_stats(traj))
    env.S[r] = lcb_envelope(env.theta[r], alpha_env)   # 保守下置信界
    assert subset(env.S[r], env.hard_bound[r])          # 永不超过全局硬界
    return env
```

### IP-140 ISB（可辨识性下界与不可负担证据账本）

```python
def f_required(kappa, sigma_f, eps, beta, c_crlb):
    return kappa * (c_crlb * sigma_f / eps) ** beta

def classify_region(env, r, eps):
    req = f_required(env.theta[r].kappa, env.sigma_f, eps, env.beta, C_CRLB)
    F_safe = env.S[r].F_n_max                        # 认证包络（保守）
    if F_safe < req:
        env.U.add(r, reason=('unaffordable', req, F_safe))
        return 'SU'                                  # 物理上买不起证据
    return 'ID'

def su_downgrade(cp, env, consent):
    # SU 不允许"多探几次"：直接走非接触/外部工具/人工三选一
    return first_feasible([detour(cp), external_tool(cp), request_human(cp, consent)])
```

### IP-141 DPC（对偶探针控制，CBF 约束的最优实验设计）

```python
def rvoi(u_trace, belief, obs_model):
    info = mutual_information(belief, u_trace, obs_model)      # I(θ;y_{0:T}|a)
    cost = (C_W * expected_work(u_trace)
            + C_F * expected_peak_force(u_trace)
            + C_S * expected_slip(u_trace))
    return info / max(cost, eps_cost)

def dual_probe_control(cp, env, belief, H, iter_cap):
    best, best_val = safe_nominal(cp), -inf            # 可行 incumbent
    for it in range(iter_cap):                         # anytime：超时即返回
        u = optimize(horizon=H, warm_start=best,
                     objective=lambda a: rvoi(a, belief, cp.obs_model),
                     constraints=[cbf(env.S[cp.region]), dynamics(cp),
                                  box(u_max)])
        if feasible(u) and rvoi(u, belief, cp.obs_model) > best_val:
            best, best_val = u, rvoi(u, belief, cp.obs_model)
        if time_left() < T_RESERVE:
            break
    return best                                        # 绝不返回不可行解
```

### IP-142 RSL（反射安全层与单侧证据）

```python
def safety_margin(S_r, f, v):
    return min(S_r.F_n_max - f_norm(f),          # 法向力裕度
               S_r.P_max   - dot(f, v),          # 功率/损伤率裕度
               S_r.D_max   - S_r.W_cum,          # 累计功裕度
               S_r.mu_fric * f_norm(f) - f_tang(f))  # 摩擦锥裕度

def reflex_filter(u_nom, x, f_meas, env, r, alpha):
    S = inflate(env.S[r], gamma=stale_age(r))        # IP-143 陈旧膨胀
    h = safety_margin(S, f_meas, vel(x))
    u = solve_qp(minimize=quad(u - u_nom, Q),
                 subject=[cbf_derivative(h, f_meas, x) >= -alpha * h,
                          force_within(S, f_meas)])
    if u is None:
        return RETREAT                                # 顺从退让，不是继续压
    return u                                          # RSL 硬否决：auth 不可旁路

def reflex_evidence(trip):
    return Evidence('danger', lr=trip_lr()) if trip else CENSORED
    # no-trip 右删失：likelihood ratio≡1，禁止计入不可逆接触正证据
```

### IP-143 TRC（双时间尺度证据-控制一致性）

```python
def inflate(S_r, gamma):
    return Envelope(F_n_max=S_r.F_n_max - gamma,
                    P_max=S_r.P_max - gamma,
                    D_max=S_r.D_max - gamma)          # 越陈旧越保守

def commit_envelope(env, r, new_S, in_contact):
    if in_contact and not near_zero_force():
        return env                                     # 禁止接触中突变安全线
    assert subset(new_S, env.hard_bound[r])
    if dominates(new_S, env.S[r]):                     # 认证格：只允许单调加宽
        env.S[r] = new_S
    return env
```

```python
    if c.ev == 'EV-traj':
```

### IP-145 PCX++（探-诺-演++ 算子）

```python
def probe_commit_evolve_plusplus(x0, M, env, task, budget, consent, personas):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        env.S[cp.region] = inflate(env.S[cp.region], stale_age(cp.region))  # TRC
        if classify_region(env, cp.region, eps_cert) == 'SU':              # ISB
            alt = su_downgrade(cp, env, consent)
            if alt is None: return negotiate_or_stop(cp, ..., 'SU')
            route = alt; continue
        b = M.b[cp.region]
        while select_gait(schedule_risk(foothold_schedule(x0, cp, M), M)) == 'halt' \
              and budget.probes_left > 0:
            u_probe = dual_probe_control(cp, env, b, H=H_PROBE, iter_cap=IT_MAX)  # DPC
            traj = execute_with_reflex(u_probe, env, cp.region)                  # RSL 在线否决
            if traj.tripped:                       # 单侧反射证据→触发重规划
                route = reroute_around(route, cp, env); break
            env = contact_envelope_update(env, cp.region, traj)                  # FCE
            b = fuse_traj(b, traj, env)
            if disagreement(b) > THETA_D and 'consensus' not in cp.done:
                p2 = most_disagreeing_decoupled_probe(cp, env, b)
                traj2 = execute_with_reflex(p2, env, cp.region)
                env = contact_envelope_update(env, cp.region, traj2)
                cp.done.add('consensus')
            budget.spend(u_probe)
        g = select_gait(schedule_risk(foothold_schedule(x0, cp, M), M))
        ev = tag_evidence_f(traj, env, contact_level(cp))
        if (g != 'halt'
            and force_evidence_gate(core_contact(cp), env, b, personas)[0] == 'ok'
            and env.reflex_certifies(cp.region)):      # 反射层可维持前向不变
            sched.append(commit(schedule_risk(foothold_schedule(x0, cp, M), M), g))
            log.append(ev); continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt':
            route = alt; continue
        return negotiate_or_stop(cp, M, ..., tau_int=tau_int(personas.active.auth))
    return sched, log, M, env
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| FCE | O(N_traj) 更新；O(1) 查询 | O(\|V\|·k_env) | Ŝ_r⊆𝒮_r，单调加宽（A41） |
| ISB | O(1)/区域 + O(N_env) | O(\|V\|) | F_req 诚实、U 无漏记（A43） |
| DPC | O(iter·H(n²+n\|u\|))，anytime 有界 | O(H·n) | 仅返回可行 incumbent（A44） |
| RSL | O(\|u\|³)/1ms tick | O(\|u\|²) | CBF 前向不变、硬否决（A42） |
| TRC | O(1) | O(1) | 陈旧只增保守（A45） |
| FSE⁺ | O(\|σ\|) | O(\|σ\|) | SU 禁正证据、D_sep 达标（A46） |
| PCX++ | O(\|CP\|·(iter·H·n²+k_c)+\|CP\|·A\*) | O(\|V\|+\|σ\|) | 四态完备、k_p+k_c 终止 |

**正确性定理（Force-Certified Contact Soundness, FCCS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；新增：
**(A41)** 包络可靠性：认证包络 Ŝ_r⊆𝒮_r 以 ≥1−α_env 成立，且只沿认证格单调加宽；
**(A42)** 反射层：在有界扰动/时延内 CBF 前向不变，RSL 对 auth/高层不可旁路；
**(A43)** 可辨识性账本诚实：F_req 由 CRLB 导出，U 不漏记；
**(A44)** DPC anytime 只输出可行解，超时返回 incumbent；
**(A45)** 陈旧膨胀只增保守；
**(A46)** 设计性独立：仅 D_sep(a)≥θ_sep 的探针可产生 EV-xmodal。
则：

1. **安全-高层解耦**：若 A41∧A42 成立，则不可逆接触的物理安全不依赖元先验、跨模态对账或人是否正确；高层任何错误只能使包络更小、动作更保守或触发绕行，不能造成包络越界。
2. **不可负担证据不伪造**：r∈SU 时 FSE⁺ 拒绝签发 EV-traj 正证据（由 ISB 命题：F_safe<F_req ⇒ 任何安全策略的估计误差>ε 以正概率）。
3. **单侧反射证据守恒**：no-trip 为右删失，似然比≡1，不计入不可逆接触正证据；避免"没出事=安全"的删失偏差。
4. **时间尺度分离**：反射层对陈旧膨胀包络保持前向不变，故 Δ_d 抖动/停顿/丢帧不破坏安全；包络仅在非接触安全点提交，禁止接触中突变。
5. **部署界**：

```
P_safe ≥ 1 − δ_env − δ_reflex − δ_sensor
             − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])
```

关键：**安全的第一必要条件从"信念正确"改成"包络可靠 ∧ 反射前向不变 ∧ 力觉可信"**；信念只决定效率与舒适。这是本轮最大的结构变化，也是最大的单点所在。

云边协议 CEB++ → **CEB#**：云端可下发"包络先验/元模型/探针库"三类增量，但都先过隔离区影子运行；新增硬规则——**任何下发的包络先验在边端只能作为 Ŝ_r 的上界候选，必须经本地保守收缩与 CBF 影子验证后才能生效**；边端回传反射触发、饱和/漂移事件、SU 发现与 D_sep 统计，作为云端包络学习与语料补盲依据。第 57 轮"一切判定器走隔离"在本轮推广为 **"一切安全线走物理保守下界，且下发的安全线默认不可信"**。

## 6. 本轮最大风险

**一句话**：本轮把安全的最后一道闸门从"高层的证据判定"下移到"依赖力觉的反射包络"，于是单点故障由"坏先验"换成"**坏包络 + 坏力觉**"——一旦安全包络在最需要保守时被高估（而力觉恰在接近损伤时饱和/漂移），反射层会以"完全合规"的姿态、且按设计不可被人否决地，把系统径直压向一个错误的极限；必须以保守下置信界、非接触点的单调加宽、力觉饱和/漂移自检与冗余、以及物理急停四重护栏，把"反射层永远比高层更悲观"当成不可谈判的公理。
