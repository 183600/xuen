# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「并发推理」×「用户测试」）

> R69 的 FLUID-RAS 把不确定性一分为二（aleatoric 走 R68 铁律、epistemic 交给流匹配多模态策略 + 主动交互），问出「我该向谁求证、还能问什么」。但它仍然是一个**串行、同步、单一用户模型**的系统：必须"先算清楚该不该问 → 停下来问 → 再决定怎么做"；它的 resolution bonus 依赖一个离线标定过的"人类回答者模型"，并用有限的 E294 用户研究一次性背书。
>
> 这留下两个隐藏假设：
> - **(A) 时间是可牺牲的顺序资源**：消歧（多采样、轨迹聚类、VoI、交互）可以串行插进控制环，且"交互预算 ≤1 次/单位时间"就等于安全。真实系统里，多个歧义同时存在、证据获取时延差异巨大（注视 ms 级、语言提问 s 级），串行会错过决策窗口；而一旦并发提出多个请求，"每分支各自守预算"会让全局预算被悄悄击穿，并长出**重复提问、证据串扰、旧证书重放**等分布式系统病。
> - **(B) "测过" = "可信"**：VoI 里的人类模型、问句措辞、交互策略，只要在一个面板、一个时段上跑过一次用户测试，就当作长期有效。真实用户会**疲劳**、会**适应系统**、会被提问**诱导**、会产生**自动化偏置**；测试本身也会被**偷看（optional stopping）**、**多重比较**、**面板过拟合**、**人群外推失配**腐蚀。R69 自陈的最大风险（问错比不问更危险）在 R70 升级为：**如果你连"问"的资格都没有被真正检验，那么"已验证"本身就是最大的谎言。**
>
> 本轮两块补丁：
> - **并发推理**：把消歧从「串行前置」重构为「并发投机」——保守默认分支永远在跑（fail-safe），昂贵认知分支在后台并行推进，只在**安全提交点**上用**新鲜证书**投机提交；错过截止/仲裁冲突/证书过期/验证失败则默认分支照常执行。既隐藏 R69 的延迟，又把 R68 的安全性作为结构下界保留下来。
> - **用户测试**：把"用户模型"从一次性假设升级为**在线、预注册、有功效约束、非劣性检验**的持续试验；每次保守性减免（resolution bonus）必须绑定一张可审计的试验凭证，凭证失效（功效不足/偷看/外推失败/用户漂移）则减免归零、退回 R68。
>
> 核心命题：**并发推理决定"你能不能及时拿到证据"，用户测试决定"你拿到的证据算不算数"；二者相乘得到一条守恒律——任何保守性减免都不能超过被独立验证过的安全裕度，没有免费的分辨率红利。** 命名 **CONCERT-RAS**（CONcurrent speculative reasoning + Real-user TEsting）。
>
> 一句话定位：R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我能不能一边做一边求证，以及我的『求证』本身有没有被真正检验过**」——不确定性不只是刹车、提问，也可以是一条并行推测线上的「预备动作」和一张可被审计的「试验凭证」。

## 0. 直觉与动机

**灵感 1（并发推理 → 消歧不该堵在控制环里）**
直觉：R69 的 pipeline 是"先想后做"：mode_head → 多采样 → 聚类 → VoI → 交互 → 再执行。但控制环不会等你。人类其实是"边做边想"：脚已经在走保守路线，眼睛和大脑并行地寻找更好的方案，一旦看清就在下一个落点切换。这正是**投机执行（speculative execution）**：默认路径永远可执行、永远安全；投机路径并行准备；只在"提交点"（还能安全切换的最后一刻）决定用哪个。搬到 R69：默认分支 = R68 保守策略（恒可行），投机分支 = K 采样 + AUD + FMA + 受仲裁器约束的交互；提交点 = C-RAS-WM 认证前缀的边界。于是 R69 的"多采样击穿实时预算"被**并发隐藏**，而不是被牺牲。

**灵感 2（并发推理 → 并发会长出新的时序病）**
直觉：一旦多个分支并行，就会出现分布式系统的经典病：两个分支都想提问 → **交互风暴/重复提问**；分支 A 的证据被分支 B 拿去用 → **证据串扰（lost update）**；分支在旧观测上算出的证书被拿到新时刻提交 → **证书过期（stale certificate）**；晚到证据"事后追认"已执行的决策 → **时间旅行（retroactive justification）**。这些不是工程细节，而是会直接破坏 R69 证据纪律的**正确性漏洞**。所以并发层必须配一个**可线性化的单写者交互仲裁器**：把人机通道变成全序队列，预算按**全局**而非分支本地记账，证据带序号且不可回溯。

**灵感 3（用户测试 → 人类模型非平稳，且测试会腐蚀）**
直觉：R69 的 VoI 隐含一个 `p(answer | question, user)` 模型，再用有限用户研究给它背书。但用户会**疲劳**（第 50 次提问时敷衍）、会**适应**（学会怎么答让机器人快点走）、会**策略化**（故意误导以试探边界）、会产生**自动化偏置**（机器人问了，我就答它想听的）。更危险的是测试本身：来回看结果决定停不停、在同一面板上反复调参、用实验室用户外推到部署人群——都会让"测过"变成统计幻觉。用户测试不是一次盖章，而是**预注册 + 功效分析 + 非劣性检验 + 序贯 alpha 控制 + 影子部署**的持续过程。

**灵感 4（两者相乘 → 一条守恒律）**
直觉：单独看，"并发"像免费的时间机器，"用户测试"像万能的合法印章。合在一起才看清：**并发让你更快拿到证据，用户测试决定这些证据值多少**。R69 的 resolution bonus 本质是"用交互换来的安全裕度减免"。R70 要求每一次减免都能追溯到一张有效试验凭证；试验无效则减免归零。这不是保守主义复辟，而是给效率收益装上**会计**：没有凭证的收益，一律记为负债。

**灵感 5（对 R69 的姿态 → 严格包含，R69 是「串行 + 已测」边界）**
直觉：CONCERT 不推翻 FLUID，而是把它的两个隐含维度显式化：**并发度 m** 与 **试验有效性 v**。当 m=1（无投机并行）且 v=1（试验有效、无漂移）时，CONCERT 逐指令退化为 R69；当 v=0（无有效试验）或投机提交失败时，退化为 R68。安全侧仍单调：任何不确定性增加只会让系统滑向更保守的一端，绝不反向。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（CONCERT-RAS 总览）** CONCERT-RAS = (CSP, CCU, ILA, SSV, UTO, TVG, UTA, RBL, VQAuditor-C2, RAS-WM†)。三不变式：
(i) **默认分支永远可行**（fail-safe by construction）：任一时刻都存在一个已认证的 R68 保守动作 `a^D_t`，投机分支只能"替换"它，不能"阻塞"它；
(ii) **交互全局单写者**：所有人机交互经 ILA 线性化排队，预算与证据纪律按全局口径计算，晚到证据不得回溯追认；
(iii) **减免必须有凭证**：任何 resolution bonus `r>0` 必须绑定一张通过 TVG 的 UTO 试验凭证；凭证失效 ⇒ `r=0` ⇒ R68。

**定义 311（投机分支结构 CSP）** 默认分支 `D=(a^D_{t:t+H}, U_ale, λ^D)` 由 R68 步产生且恒可执行。投机分支集合 `S={s_1,…,s_m}`，每个 `s_j` 是在观测 `o_t` 上 fork 出来的异步计算图：多采样 → AUD → (可选) MINT/CIA 交互 → FMA。join 发生在提交点，而非固定时刻。`m` 受空闲算力与全局交互预算约束，默认 `m∈{0,1}`。

**定义 312（提交点、纪元与证书新鲜度 CCU）** 提交点 `τ_c` = C-RAS-WM 认证前缀的末端（越过它就不能无代价切换）。证书带**纪元** `e`（生成时的观测序号）与**年龄** `Δ=t−τ_e`。仅当 `e=e_now`，或 `Δ≤τ_stale` 且漂移界 `(L_Φ+L_v)Δ≤ε_stale` 时证书有效；否则投机分支作废——是"丢弃"，不是"降级使用"。

**定义 313（交互线性化仲裁器 ILA）** ILA 把人机通道建模为单写者队列：`submit(g, branch, e)` 在锁内分配全序序号并检查**全局**预算（频率、位移、社交成本、总次数）。语义满足线性一致性：并发的两个交互请求必有一个先被接受、另一个被拒绝或排队，不存在"两个都以为自己成功"。全局预算函数 `B_glob` 取代 R69 的按次预算。

**定义 314（证据因果性）** 证据 `y` 带获取序号 `seq(y)` 与观测纪元 `e(y)`。规则：**任何已提交动作只能被 `seq(y)<seq(commit)` 且 `e(y)≤e(commit)` 的证据支持**；晚到证据只能进入下一轮先验，不能回溯修改已提交的证书。这把 R69 的"单次交互不得单独定案"升级为"单次交互也不得跨纪元定案"。

**定义 315（并发安全验证 SSV）** 投机分支提交前必须由 SSV 用**提交时刻**的观测（或其 `L_Δ` 漂移包络）重新验证 C-RAS-WM 前缀与 CBF 约束；验证与分支计算并行，但验证结果的纪元必须匹配提交纪元。验证失败/超时 ⇒ 丢弃投机分支，执行默认分支。

**定义 316（用户试验协议 UTO）** 一次用户试验 `T = (prereg_hash, n, β, Δ_NI, seq_plan, population, heldout)`：预注册假设、样本量/功效、安全**非劣性**边距、序贯检验计划（alpha-spending）、测试人群、外推目标与留出集。仅当 `power≥β`、安全非劣性成立（部署风险 ≤ R68 + Δ_NI）、且外推人群匹配时，试验通过。

**定义 317（影子与分阶段上线）** 交互策略经历 shadow（只记录不执行）→ canary（小流量、可撤回）→ general 三阶段；每阶段设中止规则（安全事件、用户负担阈值、漂移告警）。把"用户测试"从离线实验变成**在线、可撤销**的部署学。

**定义 318（用户非平稳模型 UTA）** 用户状态 `u_t=(f_t, α_t, σ_t, b_t)`：疲劳 `f`、适应/学习 `α`、策略性/欺骗 `σ`、自动化偏置 `b`。回答模型 `p(a|q,u_t)` 非平稳；`U_user(t)∈[0,1]` 是"用户当前不可信度"综合标量，进入 VoI 折扣与减免折扣。漂移检测器在 `U_user` 超阈值时**吊销**相关试验凭证。

**定义 319（试验有效性门 TVG）** 检测：optional stopping/偷看、多重比较未校正、面板过拟合、人群外推失配、功效不足、结局指标替换。任一项触发 ⇒ 凭证无效 ⇒ `r=0`。TVG 是"用户测试"这一层的 MCG（对应 R69 的模态校准门）。

**定义 320（分辨率红利账本 RBL）** 每轮记录：`U_ale, U_epi`、证据 uniq id/序号/纪元、试验凭证 ID、`r`、`λ`、"若 r=0 的 R68 反事实风险"。账本 append-only、可审计、可撤销；撤销某凭证会回溯地使依赖它的历史减免在**统计报表**上失效（但不改变已执行的控制——用定义 314 的因果性区分）。

**定义 321（可采纳减免比 r 与风险缩放）**
`r = 1[试验有效] · ρ_ev · ρ_test · (1 − U_user) ∈ [0,1]`，其中 `ρ_ev` = 证据充分度（k 源一致强度），`ρ_test` = 试验效应下置信界 / 预期效应。风险缩放
`λ = λ_floor( U_ale + (1 − r)·U_epi )`。
`r=0` ⇒ 逐指令 R68；`r=1` ⇒ 逐指令 R69 的完全消解；中间值是新的、可审计的连续谱。**这是本轮对 R69 的严格泛化。**

**定义 322（证书 J_CONCERT）** `J_CONCERT = (J_FLUID, commit_log_root, m, stale_violations, ILA_order_hash, prereg_hash, power, Δ_NI, U_user, drift, RBL_root)`。Valid ⇔ Valid(J_FLUID) ∧ 无过期证书提交 ∧ 无全局预算越界 ∧ 证据因果性未被破坏 ∧ 凭证有效。

**定义 323（AIC-CONCERT 威胁模型）** `E_CONCERT = E_FLUID × E_conc × E_test`：
- `E_conc`：双问/交互风暴、证据串扰与重放、旧证书重放、乐观执行竞态；
- `E_test`：面板过拟合、偷看/换终点、人群外推攻击、用户适应/欺骗导致凭证吊销延迟。
新增**并发投毒**：攻击者只需在提交窗口内注入一条过期/伪造证据，即可让投机分支带着错证书先于默认分支提交。

**定义 324（并发异常监控）** 在线统计：重复提问率 `π_dup`、提交过期率 `π_stale`、仲裁拒绝率、证据序号乱序率、凭证吊销延迟。任一超阈值 ⇒ 关闭投机（`m→0`），退回 R69 串行。

**定义 325（并发交互调度）** 多个歧义同时存在时，按 `priority(k)=U_epi,k·VoI_k/(c_k+burden_k)` 排序；允许把同一用户/同一时刻的多个问题**批处理**为一个多问题交互（降低打扰成本），但批处理不得违反证据纪律（每问单独可拒答、单独记账）。注视/探针等低成本信息动作可真并行，语言提问经 ILA 串行。

**定义 326（退化阶梯）** 投机提交（m≥1 且凭证有效）→ R69 串行（m=1，无并行交互）→ R68 保守（r=0）。任一层失败都单调滑向下一层，绝不反向。

**定义 327（试验感知 VoI）** `VoI^test(g) = VoI(g)·(1−U_user)·ζ(voucher) − c(g) − burden(g)`，其中 `ζ` 是凭证有效强度。把"问得值不值""问了算不算数""问得累不累"分开计费。

# IP-264 CSP：并发投机规划（默认分支恒可行）
class SpeculativePlanner:
    def step(self, o_t, arb, m_max):
        D = self.default_branch(o_t)              # R68：已认证、恒可执行
        S = []
        if self.mode_head(self.trunk(o_t)) > TAU_MODE and self.spare(m_max):
            S.append(self.fork(self.epistemic, o_t, epoch=self.clock.e))  # 异步
        return D, S

# IP-265 CCU：提交判定（新鲜度 + 因果性 + 仲裁 + 重验）
def try_commit(D, S, clock, arb, c_ras_wm, o_now):
    for s in sorted(S, key=lambda x: x.score, reverse=True):
        if not s.done:                                  continue
        if not s.cert.valid_for(clock.e, clock.age(s)): continue   # 过期/纪元不符
        if arb.is_conflicting(s):                       continue   # 证据串扰
        if not c_ras_wm.certify(s.prefix_actions(), o_now): continue  # SSV 重验
        return s.action, s
    return D.action, None                               # fail-safe

# IP-266 ILA：全局单写者交互仲裁
class InteractionArbiter:
    def submit(self, g, branch, epoch):
        with self.lock:
            if not self.budget_global.allow(g): return Reject("global_budget")
            seq = self.seq.next()
            self.log.append((seq, epoch, branch, g))    # 全序，不可回溯
            return Ticket(seq)

# IP-268 UTO + TVG：签发试验凭证
def issue_voucher(policy, protocol):
    if protocol.prereg_hash is None:                    return None
    r = sequential_test(policy, protocol)               # alpha-spending
    if r.power < protocol.beta:                         return None
    if not r.non_inferior(protocol.delta_NI):           return None
    if not validity_guard(protocol, r):                 return None   # TVG
    return Voucher(policy.id, r.effect_lcb, protocol.population)

# IP-269 可采纳减免比
def resolution_ratio(evidence, voucher, uta):
    if voucher is None or voucher.expired:              return 0.0
    if uta.drift() > TAU_DRIFT:                          return 0.0
    rho_ev   = evidence.agreement_ratio()               # k 源一致
    rho_test = voucher.effect_lcb / voucher.effect_target
    return clamp(rho_ev * rho_test * (1 - uta.U_user()), 0.0, 1.0)

# IP-275 主闭环
def CONCERT_round(M, obs):
    D, S = M.csp.step(obs, M.arb, m_max=M.spare)
    action, spec = try_commit(D, S, M.clock, M.arb, M.c_ras_wm, obs)
    # 投机分支已在后台完成 AUD / FMA / 受 ILA 约束的交互
    r = M.bonus.resolution_ratio(spec.evidence, M.vouchers[spec.policy_id], M.uta) if spec else 0.0
    lam = lam_floor(U_ale + (1.0 - r) * U_epi)          # r=0→R68；r=1→R69
    k   = M.c_ras_wm.certified_prefix(action, ...)
    if spec is None and M.arb.anomaly() > TAU_ANOM:      # 并发异常→关投机
        M.csp.disable()
    M.ledger.record(U_ale, U_epi, spec, r, lam, r68_counterfactual=True)
    M.vqa.submit_async(spec, r, M.arb.log.tail())
    return k, lam, action, r

## 3. 推导

**引理 19（并发交互的重复提问界）** 若 m 个分支各自以概率 p 独立决定提问且无仲裁，则重复提问概率 `π_dup = 1 − (1−p)^m`；ILA 全局单写者下 `π_dup = 0`，且全局预算严格不被越界。系：并发度 m 的收益必须以"全局预算"而非"每分支预算"记账，否则 m 增大时打扰成本超线性上升。

**引理 20（证书新鲜度的漂移界）** 观测漂移满足 `L_Φ`-Lipschitz、动作场满足 `L_v`-Lipschitz，则纪元差 Δ 的证书在提交时刻的条件/动作偏差 `≤ (L_Φ+L_v)Δ`。故要求 `Δ ≤ τ_stale = ε_stale/(L_Φ+L_v)`，否则必须重验；晚到证据因定义 314 无法追认。系：投机"抢跑"的安全裕度是可量化的时间-距离预算，不是免费的。

**引理 21（试验有效性与 Goodhart 界）** 在 M 个候选中用有限面板 n 选优并允许偷看，部署效应与测量效应之差（optimism）期望 `≥ c·√(log M / n)`（标准选择偏差）。预注册 + alpha-spending + 留出人群把 optimism 压到 `O(√(log M / n_heldout))`。故 TVG 不是形式主义，它决定了 `ρ_test` 的置信下界。

**定理 18（投机严格包含 R68 / R69）** 在引理 19–20 与定义 310–312 下，默认分支恒可行、提交只在新鲜认证点发生 ⇒ 任意状态的期望风险 ≤ R68（`r=0` 边界逐指令相同）。当 m=1、无并行交互、凭证有效且 `r∈{0,1}` 时，逐指令等于 R69（`r=1` 完全消解、`r=0` 未消解）。故 CONCERT 在 (m, v) 平面上以 R68 为角点、R69 为一条边，自身是二维严格泛化。

**定理 19（无免费红利 / 保守性守恒）** 对任意轮次，可采纳减免满足 `r ≤ ρ_ev·ρ_test·(1−U_user) ≤ 1`，且试验无效/漂移/过期任一成立时 `r=0`。因此
`E[risk] ≤ E[risk_R68] − r·ΔR_evidence + ε_stale(m)`，
即减免带来的风险下降**不可能超过**被独立验证的安全裕度；测试无效则收益严格归零。系：任何"跳过用户测试直接发放 resolution bonus"的变体都会破坏该上界（其 `r` 没有下置信界支撑）。

**定理 20（并发安全与无突变）** 在 SSV 提交时刻重验 + ILA 全序 + 默认分支可行下，投机提交不改变安全包络（只换动作、不换约束）；冲突/超时/验证失败时 `λ` 单调不降地退回默认分支；R68 换装不变式保持 ⇒ 控制连续。并发只加快"可选动作的出现速度"，不加快"安全边界"，故无突变。

## 6. 本轮最大风险

**一句话**：CONCERT 把「并发」当成免费的时间机器、把「用户测试」当成万能的合法印章——**真正的危险是：并发让系统在安全截止前抢跑提交，而一旦用户试验的统计有效性或人群外推被 Goodhart 腐蚀，抢跑就会带着一张"已验证"的错证书穿过安全边界；此时系统不但更激进，还更自信**。

**次级风险与缓解**：
1. **并发时序病**（双问、串扰、旧证书、时间旅行）→ ILA 全局单写者 + 证据序号/纪元 + SSV 提交重验 + 并发异常监控自动关投机（定义 313–315、324、引理 19–20）；
2. **试验有效性造假/腐蚀** → 预注册 + alpha-spending + 留出人群 + TVG，无效即 `r=0`（定义 316–319、321、引理 21、定理 19）；
3. **用户非平稳/被利用** → UTA 在线漂移 + 凭证吊销 + 影子/金丝雀可撤回（定义 317–318、325）；
4. **投机算力耗尽主环** → 后台核隔离 + `m` 上限 + 主环延迟与 m 无关（复杂度表）；
5. **伦理风险（把用户当免费测试对象）** → 明示同意、可退出、禁止暗中随机化安全关键交互、E314 审计。

# IP-264 CSP：并发投机规划（默认分支恒可行）
class SpeculativePlanner:
    def step(self, o_t, arb, m_max):
        D = self.default_branch(o_t)              # R68：已认证、恒可执行
        S = []
        if self.mode_head(self.trunk(o_t)) > TAU_MODE and self.spare(m_max):
            S.append(self.fork(self.epistemic, o_t, epoch=self.clock.e))  # 异步
        return D, S

# IP-265 CCU：提交判定（新鲜度+因果性+仲裁+重验）
def try_commit(D, S, clock, arb, c_ras_wm, o_now):
    for s in sorted(S, key=lambda x: x.score, reverse=True):
        if not s.done:                                  continue
        if not s.cert.valid_for(clock.e, clock.age(s)): continue
        if arb.is_conflicting(s):                       continue
        if not c_ras_wm.certify(s.prefix_actions(), o_now): continue  # SSV
        return s.action, s
    return D.action, None                               # fail-safe

# IP-266 ILA：全局单写者交互仲裁
class InteractionArbiter:
    def submit(self, g, branch, epoch):
        with self.lock:
            if not self.budget_global.allow(g): return Reject("global_budget")
            seq = self.seq.next()
            self.log.append((seq, epoch, branch, g))
            return Ticket(seq)

# IP-268 UTO + TVG：签发试验凭证
def issue_voucher(policy, protocol):

    r = sequential_test(policy, protocol)               # alpha-spending
    if r.power < protocol.beta:                         return None
    if not r.non_inferior(protocol.delta_NI):           return None
    if not validity_guard(protocol, r):                 return None   # TVG
    return Voucher(policy.id, r.effect_lcb, protocol.population)

# IP-269 可采纳减免比
def resolution_ratio(evidence, voucher, uta):
    if voucher is None or voucher.expired:              return 0.0
    if uta.drift() > TAU_DRIFT:                          return 0.0
    rho_ev   = evidence.agreement_ratio()
    rho_test = voucher.effect_lcb / voucher.effect_target
    return clamp(rho_ev * rho_test * (1 - uta.U_user()), 0.0, 1.0)

# IP-275 主闭环
def CONCERT_round(M, obs):

## 4. 推导

**引理 19（并发重复提问界）** m 个分支各以概率 p 独立提问且无仲裁 ⇒ `π_dup = 1−(1−p)^m`；ILA 全局单写者下 `π_dup=0` 且全局预算不被越界。系：并发收益必须按"全局预算"记账，否则打扰成本随 m 超线性上升。

**引理 20（证书新鲜度漂移界）** 观测 `L_Φ`-Lipschitz、动作场 `L_v`-Lipschitz ⇒ 纪元差 Δ 的条件/动作偏差 `≤(L_Φ+L_v)Δ`；要求 `Δ≤τ_stale=ε_stale/(L_Φ+L_v)`，否则重验；晚到证据不可追溯。系：投机抢跑的安全裕度是时间-距离预算，不是免费的。

**引理 21（试验有效性与 Goodhart 界）** M 候选、有限面板 n、允许偷看时，部署与测量效应差（optimism）期望 `≥ c√(log M/n)`；预注册 + alpha-spending + 留出人群把它压到 `O(√(log M/n_heldout))`。故 TVG 决定 `ρ_test` 的置信下界。

**定理 18（投机严格包含 R68/R69）** 默认分支恒可行、提交只在新鲜认证点 ⇒ 任意状态期望风险 ≤ R68（r=0 逐指令相同）；当 m=1、无并行交互、凭证有效且 `r∈{0,1}` 时逐指令等于 R69。故 CONCERT 在 (m,v) 平面以 R68 为角点、R69 为边，是二维严格泛化。

**定理 19（无免费红利 / 保守性守恒）** `r≤ρ_ev·ρ_test·(1−U_user)≤1`，试验无效/漂移/过期则 `r=0`；故 `E[risk]≤E[risk_R68]−r·ΔR_evidence+ε_stale(m)`：减免带来的风险下降不超过被独立验证的安全裕度；测试无效则收益严格归零。

**定理 20（并发安全与无突变）** SSV 提交重验 + ILA 全序 + 默认分支可行 ⇒ 投机只换动作不换安全包络；冲突/超时/失败时 λ 单调不降退回默认；R68 换装不变式保持 ⇒ 控制连续、无突变。

## 7. 本轮最大风险

**一句话**：CONCERT 把「并发」当成免费的时间机器、把「用户测试」当成万能的合法印章——**真正的危险是：并发让系统在安全截止前抢跑提交，而一旦用户试验的统计有效性或人群外推被 Goodhart 腐蚀，抢跑就会带着一张"已验证"的错证书穿过安全边界；此时系统不但更激进，还更自信**。

**次级风险与缓解**：并发时序病（ILA 全序 + 证据序号/纪元 + SSV 重验 + 异常自动关投机）；试验腐蚀（预注册 + alpha-spending + 留出人群 + TVG，无效即 r=0）；用户非平稳（UTA 漂移 + 凭证吊销 + 影子/金丝雀可撤回）；投机算力耗尽主环（后台核隔离 + m 上限 + 与 m 无关的主环延迟）；伦理（明示同意、可退出、禁止暗中随机化安全关键交互 + E314）。
