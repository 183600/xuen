# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「视觉定位」×「意图识别」）

> 第 54 轮把技能组合推进到「动作空间剖面 + 技能组合图 + 云边协同 + 动作-鲁棒性联合证书」，形成一个动作感知的部署闭环。但整套体系有一个被隐式假设掉的地基：任务动作序列 `A_T` 与执行坐标系都是**给定的**。本轮把这两个地基显式化为**两个需要估计的隐变量**——视觉定位给出位姿信念 `b(ξ)`，意图识别给出意图信念 `b(ι)`——并追问：当接地（grounding）本身有歧义时，第 54 轮那些证书还剩多少有效性？核心矛盾：**H22（框架幻觉）**：位姿在估计帧中自洽、在真实帧中错位，`A_cert/ρ` 于“假帧”里 sound；**H23（意图漂移）**：`A_T` 由意图后验生成，意图本体偏移会令系统“正确地执行错误任务”；**H24（耦合歧义）**：位姿与意图并非独立，语义地图使二者共享证据，边缘分布相乘会系统性低估联合不确定性。

## 0. 直觉与动机

**灵感 1（视觉定位 → 从坐标点变为多峰位姿信念）**
直觉：视觉定位的输出不该是一个 `ξ̂∈SE(3)`，而应是 `b(ξ)`——一张可能多峰的位姿后验。重复纹理、长走廊、玻璃幕墙、动态行人会让单纯的点估计“自信地错”。证书若只依赖 `ξ̂`，就等于把一次感知赌注当成公理。更合理的做法是：**所有几何断言都带一个位姿条件**，并在 `b(ξ)` 的高概率区域上取最坏情形。

**灵感 2（意图识别 → 从标签变为可分解的任务后验）**
直觉：意图识别不是分类出一个标签，而是给出 `b(ι)`，且意图本体本身是有结构的（去某处 / 取某物 / 跟随 / 避让 / 待命）。第 54 轮的 `A_T` 其实是 `A_T(ι)`：意图决定任务动作子集。意图歧义不是“噪声”，而是**任务目标的集合值不确定性**。因此覆盖检查应从“对单个 `A_T` 覆盖”变为“对意图支撑集内的所有 `A_T(ι)` 覆盖”。

**灵感 3（语义-几何耦合 → 联合信念优于乘积分工）**
直觉：位姿与意图通过语义地图强耦合。看到“冰箱”既提高“我在厨房”的位姿置信，也提高“去拿牛奶”的意图置信；反过来，意图“去会议室”会抑制“我在厨房”的位姿假设。若强行把 `b(ξ)` 与 `b(ι)` 当独立因子相乘，会漏掉这种互证/互斥，导致在歧义场景下过度自信。**联合信念 `b(ξ,ι)` 是本轮的第一性对象。**

**灵感 4（框架一致性 → 证书必须是规范等变的几何对象）**
直觉：证书不是一段文字，而是附着在动作上的几何/概率断言。世界坐标系可任意选取，因此证书应在刚体变换 `T_g` 下**等变**：`C(T_g ξ, ι) = T_g·C(ξ,ι)`，有效性不随坐标系选择改变。真实的失效来源是**框架差异** `δ_ξ = d_SE3(ξ̂, ξ*)`：同一动作向量在估计帧与真实帧中对应不同的物理动作。第 54 轮的 `δ_a` 只度量“云边映射对齐误差”，本轮补上“世界框架对齐误差”这一维。

**灵感 5（主动消歧 → 把歧义当作可控制量，而非被动承受）**
直觉：位姿与意图的歧义可以通过**信息动作**降低：转头/移动获得更好的视觉约束（主动视觉定位），追问/指认/等待澄清降低意图熵（主动意图识别）。但信息动作本身有代价与风险。于是应当有一个门控：当证书裕度不足时，优先执行**期望信息增益高、风险预算内**的消歧动作，而不是硬着头皮执行任务动作。这把第 54 轮的技能组合图扩展为“任务边 + 消歧边”的混合图。

**灵感 6（金字塔扩展 → 新增接地层 𝔾）**
直觉：在第 53 轮鲁棒性层 `𝕃`、第 54 轮动作协同层 `𝔸` 之下，需要一个更底层的**接地层 `𝔾`**：`𝔾_0` 像素/点云观测，`𝔾_1` 位姿信念 `b(ξ)`，`𝔾_2` 语义地图，`𝔾_3` 意图信念 `b(ι)`，`𝔾_4` 联合接地上下文 `b(ξ,ι)`。上层证书只有携带 `𝔾` 的条件与裕度，才是“接地的证书”而非“悬空的证书”。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（位姿-意图联合信念）**
令位姿空间 `Ξ = SE(3)`，意图空间 `ℐ`（离散本体 + 参数槽位）。联合信念 `b_t(ξ,ι) = P(ξ_t=ξ, ι_t=ι | z_{1:t})`，由因子图分解：
```
b_t(ξ,ι) ∝ Φ_loc(z_t^loc | ξ) · Φ_int(z_t^int | ξ,ι) · Ψ_sem(ξ,ι | M) · Ψ_dyn(ξ,ι | ξ_{t-1})
```
其中 `M` 为语义地图，`Ψ_sem` 编码“物体可见性 ↔ 意图/位姿”的互证项，`Ψ_dyn` 为运动先验。**联合熵** `H_t = H(b_t(ξ,ι))` 为本轮的核心不确定性度量（而非 `H(b(ξ))+H(b(ι))`）。

**定义 122（接地上下文与条件证书）**
接地上下文 `g = (ξ,ι) ∈ 𝔾 = Ξ × ℐ`。第 54 轮任一证书 `C`（`C_comp`、`A_cert`、`J`）实际上是条件对象 `C(g)`，其有效性谓词记为 `Valid_C(g) ∈ {0,1}`。**未接地证书**写作 `C(ξ̂, ι̂)`；**接地证书**是一个映射 `g ↦ C(g)`，部署时必须声明其适用的 `g` 支撑集。

**定义 123（规范等变性与框架差异）**
对刚体变换 `T_g`，动作协变 `a ↦ T_g a`。证书 `C` **规范等变**当且仅当 `Valid_C(T_g ξ, ι) = Valid_C(ξ,ι)` 且 `C(T_g ξ,ι) = T_g·C(ξ,ι)`。定义
```
δ_ξ(ξ̂, ξ*) = d_SE3(ξ̂, ξ*)          # 估计帧与真实帧的差异
equiv_res(C) = max_g || C(T_g ξ,ι) - T_g C(ξ,ι) ||
```
`equiv_res` 度量实现层面的非等变残差（数值/离散化/阈值化造成）。**框架一致部署**要求 `δ_ξ ≤ Θ_ξ` 且 `equiv_res(C) ≤ ε_eq`。

**定义 124（意图条件动作集与鲁棒覆盖）**
`A_T(ι)` 为意图 `ι` 对应的任务动作序列。技能 `S` 在意图信念 `b(ι)` 下的**鲁棒覆盖**：
```
cover_robust(S, b) = min_{ι : b(ι) ≥ θ_mass} cover(S, A_T(ι))
```
即在意图高概率质量集合上的最坏覆盖。相应地，`ρ_S(d|ι)` 为意图条件鲁棒性谱，**意图条件鲁棒**定义为 `min_{ι∈supp_θ(b)} min_d ρ_S(d|ι) ≥ ρ_min`。

**定义 125（接地裕度与 Lipschitz 稳定性）**
对条件证书 `C`，其有效域 `V_C = {g : Valid_C(g)=1}`，**接地裕度**
```
m_C(g) = dist(g, ∂V_C) = min_{g'∉V_C} d_𝔾(g, g')
```
其中 `d_𝔾((ξ,ι),(ξ',ι')) = d_SE3(ξ,ξ') + λ_ι·1[ι≠ι']`。称 `C` 为 `(L_ξ,L_ι)`-**接地 Lipschitz**，若
```
|m_C(g) - m_C(g')| ≤ L_ξ·d_SE3(ξ,ξ') + L_ι·1[ι≠ι']
```
从而对真实上下文 `g*`：
```
m_C(g*) ≥ m_C(ĝ) - L_ξ·δ_ξ - L_ι·1[ι̂≠ι*]
```

**定义 126（消歧信息价值与门控策略）**
对候选信息动作 `a_info`，**期望信息增益**
```
EIG(a_info) = H_t(b_t(ξ,ι)) - E_{z'~P(·|a_info)}[ H_{t+1}(b_{t+1}(ξ,ι)) ]
```
**门控策略** `π_gate : (C, b_t) → {EXECUTE, DISAMBIGUATE, ABORT}`：
```
EXECUTE       若 m_C(ĝ) ≥ m_req 且 H_t ≤ H_max
DISAMBIGUATE  若 m_C(ĝ) < m_req 且 ∃a_info: EIG(a_info) ≥ ε_EIG ∧ risk(a_info) ≤ B_risk
ABORT         否则（转人工/安全停靠）
```
**消歧不可无限拖延**：要求 `π_gate` 在 `k_max` 步内收敛到非 DISAMBIGUATE 状态（否则触发 ABORT）。

**定义 127（接地联合证书）**
第 54 轮联合证书 `J` 升级为**接地联合证书**
```
J^g = (J; ĝ, b_t(ξ,ι), m_C(ĝ), δ_ξ, equiv_res(C), β_g)
```
其中 `β_g = P(g* ∉ supp_θ(b_t))` 为接地覆盖失败概率。当且仅当
```
m_C(ĝ) ≥ m_req ∧ δ_ξ ≤ Θ_ξ ∧ equiv_res(C) ≤ ε_eq ∧ β_g ≤ β_max
```
时称 `J^g` 为 **可部署证书**，记 `dom(J^g)=in`。

## 2. 关键算法 伪代码

### IP-121 PIB（Pose-Intent Belief）

```python
def update_joint_belief(b_prev, z_loc, z_int, semantic_map, motion_model):
    particles = predict(b_prev, motion_model)                 # Ψ_dyn 采样
    for p in particles:                                      # 联合重加权
        p.w *= loc_likelihood(z_loc, p.xi)                   # Φ_loc
        p.w *= intent_likelihood(z_int, p.xi, p.iota)        # Φ_int
        p.w *= semantic_consistency(p.xi, p.iota, semantic_map)  # Ψ_sem
    b = normalize(resample(particles, ess_threshold=0.5))
    return b, joint_entropy(b), top_modes(b, k=3)

def grounding_context(b):
    g_hat = argmax_{(xi,iota)} b(xi, iota)                   # MAP
    mass  = sum(w for (xi,iota),w in b if b(xi,iota) >= theta_mass)
    return g_hat, mass                                      # beta_g = 1 - mass
```

### IP-122 GCX（Gauge-Consistent Certificate）

```python
def gauge_equivariance_residual(cert_builder, g, T_g, actions):
    C1 = cert_builder(g)
    C2 = cert_builder(transform_context(g, T_g))
    lhs = [C1.valid(T_g @ a) for a in actions]
    rhs = [C2.valid(a) for a in actions]
    res = max(abs(int(x) - int(y)) for x, y in zip(lhs, rhs))
    return res, C1, C2

def ground_certificate(cert_builder, b, theta_xi, eps_eq):
    g_hat, mass = grounding_context(b)
    res, C_hat, _ = gauge_equivariance_residual(cert_builder, g_hat, I, C_hat_actions)
    if delta_xi(g_hat, b) > theta_xi or res > eps_eq:
        return ('reject', 'frame_inconsistent', res)
    return ('ok', C_hat, g_hat, 1.0 - mass)
```

### IP-123 RIC（Robust Intent Coverage）

```python
def robust_intent_coverage(skill, b, theta_mass=0.9, theta_cov=0.8):
    support = [iota for iota in intent_support(b) if b.marginal_intent(iota) >= theta_mass]
    worst = 1.0
    for iota in support:
        A_T = task_actions(iota)
        worst = min(worst, cover(skill.alpha, A_T, theta_cov))
        if min(skill.rho(d, iota) for d in dimensions) < rho_min:
            return 0.0, ('intent_robustness_fail', iota)
    return worst, ('ok', len(support))
```

### IP-124 ADP（Active Disambiguation Planner）

```python
def gate_and_disambiguate(C, b, g_hat, budget, k_max):
    m = grounding_margin(C, g_hat)
    if m >= m_req and joint_entropy(b) <= H_max:
        return ('EXECUTE', None)
    best = None
    for a_info in info_action_candidates(b):
        eig = expected_information_gain(b, a_info)
        risk = risk_bound(a_info, C)
        if eig >= eps_EIG and risk <= budget.B_risk:
            score = eig - lambda_r * risk - lambda_c * cost(a_info)
            best = max(best, (score, a_info), key=lambda x: x[0])
    if best is None:
        return ('ABORT', 'no_safe_disambiguation')
    return ('DISAMBIGUATE', best[1])   # 外层保证 <= k_max 步，超时 ABORT
```

### IP-125 GMR（Grounding Margin Robustifier）

```python
def grounding_margin(C, g_hat, sampler, n=256):
    # 在无效域方向采样，估计到边界的最短距离
    invalid = [sampler.invalid_near(g_hat, C) for _ in range(n)]
    invalid = [g for g in invalid if g is not None]
    if not invalid:
        return float('inf')               # 全域有效（需采样保证）
    return min(d_G(g_hat, g) for g in invalid)

def lipschitz_margin_bound(m_hat, L_xi, L_iota, delta_xi, p_intent_err):
    return m_hat - L_xi * delta_xi - L_iota * p_intent_err
```

### IP-126 GTC（Grounded Transfer Certificate）

```python
def grounded_transfer_certify(J_src, L_tgt, phi, delta_xi, delta_iota, budgets):
    J_src_g = J_src.grounded                      # 已含 b, m, delta_xi
    rho_tgt = coupling_correction(J_src.rho, K, phi)
    # 1) 接地一致性：源域证书在目标域的框架/意图漂移
    d_xi = delta_xi + frame_drift(phi)
    d_iota = delta_iota + intent_ontology_shift(phi)
    # 2) 裕度传递
    m_tgt = J_src_g.m - (L_xi * d_xi + L_iota * d_iota)
    if m_tgt < budgets.m_req or d_xi > budgets.Theta_xi:
        return ('reject', 'grounding_drift', m_tgt, d_xi, d_iota)
    # 3) 动作与鲁棒性联合预算
    if sum(max(0, J_src.rho[d] - rho_tgt[d]) for d in J_src.rho) > budgets.delta_rho:
        return ('reject', 'robustness_budget_exceeded')
    return ('ok', GTC(J_src, L_tgt, phi, m_tgt, d_xi, d_iota))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| PIB | O(N·|Ξ|·|ℐ|) 每步（N 粒子） | O(N) | 联合似然正确、重采样无偏、支撑覆盖 |
| GCX | O(|C|·|A|·|T|) | O(|C|) | 等变残差可测、变换群闭合 |
| RIC | O(|ι_supp|·|A|·|𝔇_ρ|) | O(|A|) | θ_mass 支撑完备、条件 ρ 单调 |
| ADP | O(|A_info|·(|Ξ|·|ℐ|)) | O(|A_info|) | EIG 估计无偏、k_max 收敛 |
| GMR | O(N·d_𝔾) | O(N) | 边界采样充分、Lipschitz 局部成立 |
| GTC | O(|𝔇_ρ|+|𝔾|) | O(|𝔇_ρ|) | 域偏移有界、裕度可传递 |

**正确性定理（Grounded Certificate Soundness）**
承接第 54 轮 (A22)–(A28)；新增假设：
**(A29)** 联合信念支撑覆盖真实接地：`P(g* ∈ supp_θ(b_t)) ≥ 1 - β_g`；
**(A30)** 条件证书 `C` 在 `supp_θ(b_t)` 上为 `(L_ξ,L_ι)`-接地 Lipschitz，且 `Valid_C(g) ⟸ m_C(g) ≥ 0`；
**(A31)** 门控 `π_gate` 在 `k_max` 步内终止，且消歧动作风险 `≤ B_risk`。
则对可部署接地证书 `J^g`：
```
P_success ≥ 1 - Σ_d (1-ρ_min(d)) - β_E - P(δ_a>Θ_a) - β_g
            - P(m_C(ĝ) < L_ξ·δ_ξ + L_ι·1[ι̂≠ι*])
```
若进一步假设 `δ_ξ ≤ Θ_ξ` 且 `P(ι̂≠ι*) ≤ β_ι`，则退化为
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a) - β_g - β_ι - L_ξ·Θ_ξ
```
**关键**：先接地、再验证、后执行；接地失败与框架漂移都被显式计入预算，而非被证书静默吞掉。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 联合信念多峰、粒子退化 | 高 | 多假设跟踪 + 分层重采样 + 语义因子解耦 |
| 感知混叠导致“自信地错” | 高 | 多模态校准 + OOD 检测 + 保守支撑截断 |
| 接地 Lipschitz 常数随场景剧变 | 高 | 分区域局部 Lipschitz + 在线估计 + 退化到最坏情形 |
| 规范等变在离散阈值处破缺 | 中 | 软化阈值 + 等变残差监控 + 回滚到保守域 |
| 主动消歧被滥用为拖延 | 中 | `k_max` 硬约束 + 信息增益递减检测 + 人工接管 |
| 意图本体跨域漂移 | 中 | 共享本体版本化 + 槽位级校验 + 澄清模板 |

## 6. 本轮最大风险

**一句话**：把证书从“无条件断言”改为“以位姿-意图联合信念为条件的接地断言”，在原理上补上了第 54 轮最大的隐含漏洞，但其 soundness 完全押在**接地裕度对位姿/意图误差的 Lipschitz 线性化**上；一旦证书有效边界在真实场景中呈强非线性或跳变（尤其在遮挡突变、意图本体切换处），名义裕度会给出虚假的安全感，系统可能在“看起来还有余量”时于真实帧中失效，故必须以**分区局部 Lipschitz 在线估计 + 等变残差绊线 + 消歧步数硬上限**三重护栏，宁可频繁 ABORT，也不把“接地裕度的线性外推”当成部署保证。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（PIB×GCX×RIC×ADP×GMR×JGC×GTC）

> 承接第 54 轮产物 v31。第 54 轮把技能组合提升为「动作空间剖面 + 云边协同 + 动作-鲁棒性联合证书」，但其证书始终默认两件事已知：世界坐标系 `ξ` 与任务动作序列 `A_T`。本轮以「视觉定位」×「意图识别」为灵感，引入**接地层**，把这两件事显式化为需要估计的隐变量，并把所有证书改造为**条件于位姿-意图联合信念**的接地证书：
> - **PIB（Pose-Intent Belief）**：`SE(3)×ℐ` 上的联合因子图信念，替代位姿/意图的边缘乘积分工；
> - **GCX（Gauge-Consistent Certificate）**：规范等变的证书校验，显式度量框架差异 `δ_ξ` 与等变残差 `equiv_res`；
> - **RIC（Robust Intent Coverage）**：意图条件动作集上的最坏覆盖与意图条件鲁棒性；
> - **ADP（Active Disambiguation Planner）**：以期望信息增益门控的主动消歧；
> - **GMR（Grounding Margin Robustifier）**：接地裕度 `m_C` 与 Lipschitz 稳定性外推；
> - **JGC（Joint Grounded Certificate）**：接地联合证书 `J^g` 的装配与可部署判定；
> - **GTC（Grounded Transfer Certificate）**：跨场景/跨用户的接地迁移证书，升级 IP-120 JTC。
>
> IP 编号：IP-121~IP-127（共 7 个新增），升级 IP-118（AEC）、IP-120（JTC）以纳入接地维度。

## 2. 关键算法 伪代码

### IP-121 PIB

```python
def update_joint_belief(b_prev, z_loc, z_int, semantic_map, motion_model):
    particles = predict(b_prev, motion_model)
    for p in particles:
        p.w *= loc_likelihood(z_loc, p.xi)
        p.w *= intent_likelihood(z_int, p.xi, p.iota)
        p.w *= semantic_consistency(p.xi, p.iota, semantic_map)   # 互证/互斥
    if ess(particles) < 0.5 * len(particles):
        particles = stratified_resample(particles)
    b = normalize(particles)
    return b, joint_entropy(b), top_modes(b, k=3)

def grounding_context(b, theta_mass=0.9):
    g_hat = argmax_{xi,iota} b(xi, iota)
    mass  = sum(w for (xi,iota), w in b if b(xi,iota) >= theta_mass)
    return g_hat, mass, 1.0 - mass          # beta_g = 1 - mass
```

### IP-122 GCX

```python
def gauge_equivariance_residual(cert_builder, g, T_g, probe_actions):
    base = cert_builder(g)
    moved = cert_builder(transform_context(g, T_g))
    res = 0.0
    for a in probe_actions:
        lhs = int(base.valid(compose(T_g, a)))
        rhs = int(moved.valid(a))
        res = max(res, abs(lhs - rhs))
    return res

def ground_certificate(cert_builder, b, probe_actions,
                       Theta_xi, eps_eq):
    g_hat, mass, beta_g = grounding_context(b)
    res = gauge_equivariance_residual(cert_builder, g_hat, I, probe_actions)
    delta_xi = max(d_SE3(g_hat.xi, s.xi) for s in b.support(theta=0.9))
    if delta_xi > Theta_xi or res > eps_eq:
        return ('reject', 'frame_inconsistent', delta_xi, res)
    return ('ok', cert_builder(g_hat), g_hat, beta_g, delta_xi, res)
```

### IP-123 RIC

```python
def robust_intent_coverage(skill, b, dimensions,
                          theta_mass=0.9, theta_cov=0.8, rho_min=0.7):
    support = [i for i in b.intent_support() if b.marginal_intent(i) >= theta_mass]
    worst_cover, worst_rho = 1.0, float('inf')
    for iota in support:
        worst_cover = min(worst_cover, cover(skill.alpha, task_actions(iota), theta_cov))
        worst_rho   = min(worst_rho, min(skill.rho(d, iota) for d in dimensions))
    if worst_rho < rho_min:
        return 0.0, ('intent_robustness_fail', worst_rho)
    return worst_cover, ('ok', len(support))
```

### IP-124 ADP

```python
def gate_and_disambiguate(C, b, g_hat, budget, k_max):
    m_hat = grounding_margin(C, g_hat)
    if m_hat >= m_req and joint_entropy(b) <= H_max:
        return ('EXECUTE', None, 0)
    best = None
    for a_info in info_action_candidates(b):
        eig  = expected_information_gain(b, a_info)
        risk = risk_bound(a_info, C)
        if eig >= eps_EIG and risk <= budget.B_risk:
            score = eig - lambda_r * risk - lambda_c * cost(a_info)
            if best is None or score > best[0]:
                best = (score, a_info)
    if best is None:
        return ('ABORT', 'no_safe_disambiguation', 0)
    return ('DISAMBIGUATE', best[1], k_max)   # 外层强制 <= k_max 步，超时 ABORT
```

### IP-125 GMR

```python
def grounding_margin(C, g_hat, sampler, n=256):
    best = float('inf')
    for _ in range(n):
        g_bad = sampler.invalid_near(g_hat, C)     # 沿无效域方向采样
        if g_bad is not None:
            best = min(best, d_G(g_hat, g_bad))
    return best                                    # inf = 全采样域内有效

def lipschitz_margin_bound(m_hat, L_xi, L_iota, delta_xi, p_intent_err):
    return m_hat - L_xi * delta_xi - L_iota * p_intent_err

def local_lipschitz_estimate(margin_fn, g_hat, probes):
    # 分区估计，避免全局常数失效
    vals = [(d_G(g_hat, g), abs(margin_fn(g_hat) - margin_fn(g)))
            for g in probes if d_G(g_hat, g) > 1e-6]
    if not vals:
        return float('inf')                        # 触发保守退化
    return max(dm / dg for dg, dm in vals)
```

### IP-126 JGC

```python
def joint_grounded_certificate(skill_seq, b, cert_builder, probe_actions,
                               budgets):
    ok, C_hat, g_hat, beta_g, d_xi, res = ground_certificate(
        cert_builder, b, probe_actions, budgets.Theta_xi, budgets.eps_eq)
    if not ok:
        return ('reject', 'frame_inconsistent', d_xi, res)
    m_hat = grounding_margin(C_hat, g_hat, budgets.sampler)
    m_lb  = lipschitz_margin_bound(
        m_hat, budgets.L_xi, budgets.L_iota, d_xi, budgets.p_intent_err)
    if m_lb < budgets.m_req or beta_g > budgets.beta_max:
        return ('DISAMBIGUATE_OR_ABORT', m_lb, beta_g)
    rho = compose_robustness_chain([s.rho for s in skill_seq], budgets.K)
    if min(rho.values()) < budgets.rho_min:
        return ('reject', 'robustness_fail')
    return ('ok', Jg(C_hat, g_hat, b, m_lb, d_xi, res, beta_g, rho))
```

### IP-127 GTC

```python
def grounded_transfer_certify(Jg_src, L_tgt, phi, budgets):
    d_xi   = Jg_src.delta_xi   + frame_drift(phi)
    d_iota = Jg_src.p_intent_err + intent_ontology_shift(phi)
    m_tgt  = Jg_src.m_lb - (budgets.L_xi * d_xi + budgets.L_iota * d_iota)
    if m_tgt < budgets.m_req or d_xi > budgets.Theta_xi:
        return ('reject', 'grounding_drift', m_tgt, d_xi, d_iota)
    rho_tgt = coupling_correction(Jg_src.rho, budgets.K, phi)
    drift = sum(max(0.0, Jg_src.rho[d] - rho_tgt[d]) for d in Jg_src.rho)
    if drift > budgets.delta_rho:
        return ('reject', 'robustness_budget_exceeded', drift)
    return ('ok', GTC(Jg_src, L_tgt, phi, m_tgt, d_xi, d_iota))
```

## 3. 推导、复杂度与正确性

### 3.1 裕度外推的一个数值例（用于标定门控阈值）

设当前接地裕度 `m_C(ĝ)=0.35`，局部 Lipschitz `L_ξ=0.8`（每米位姿误差损失的裕度），定位误差 `δ_ξ=0.05m`，意图误判代价 `L_ι=0.20`、`P(ι̂≠ι*)=0.02`：

```
m_lb = 0.35 - 0.8×0.05 - 0.20×0.02 = 0.35 - 0.04 - 0.004 = 0.306 > 0  → EXECUTE
```

若定位误差漂移到 `δ_ξ=0.45m`：

```
m_lb = 0.35 - 0.8×0.45 - 0.004 = 0.35 - 0.36 - 0.004 = -0.014 < 0  → DISAMBIGUATE
```

门控的解析阈值：`Θ_ξ* = (m_C(ĝ) - L_ι·P(ι̂≠ι*)) / L_ξ ≈ (0.35-0.004)/0.8 ≈ 0.4325m`。
这说明：**同一份证书，在不同定位质量下应给出不同的部署结论**——这正是第 54 轮缺失的维度。

### 3.2 复杂度

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| PIB | O(N·|Ξ|·|ℐ|) / 步 | O(N) | 联合似然无偏、重采样、支撑覆盖 |
| GCX | O(|A_probe|·|C|) | O(|C|) | 变换群闭合、等变残差可测 |
| RIC | O(|ι_supp|·|A|·|𝔇_ρ|) | O(|A|) | θ_mass 支撑完备、条件 ρ 单调 |
| ADP | O(|A_info|·N·|ℐ|) | O(|A_info|) | EIG 估计、k_max 收敛 |
| GMR | O(N_probe·d_𝔾) | O(N_probe) | 边界采样充分、局部 Lipschitz |
| JGC | O(PIB + GCX + RIC + GMR) | O(N+N_probe) | 预算闭合、可部署判定 |
| GTC | O(|𝔇_ρ|+|𝔾|) | O(|𝔇_ρ|) | 域偏移有界、裕度可传递 |

### 3.3 正确性定理（Grounded Certificate Soundness）

承接第 54 轮 (A22)–(A28)；新增：
**(A29)** `P(g* ∈ supp_θ(b_t)) ≥ 1-β_g`；
**(A30)** `C` 在 `supp_θ(b_t)` 上 `(L_ξ,L_ι)`-接地 Lipschitz，且 `Valid_C(g) ⟸ m_C(g) ≥ 0`；
**(A31)** `π_gate` 在 `k_max` 步内终止，消歧动作风险 `≤ B_risk`。

则对可部署 `J^g`：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a) - β_g
            - P(m_C(ĝ) < L_ξ·δ_ξ + L_ι·1[ι̂≠ι*])
```

在 `δ_ξ ≤ Θ_ξ`、`P(ι̂≠ι*) ≤ β_ι` 时：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a) - β_g - β_ι - L_ξ·Θ_ξ
```

**证明要点**：把第 54 轮的部署成功事件分解为 `{接地正确} ∩ {框架一致} ∩ {动作-鲁棒性证书成立}`。接地正确由 (A29) 保证概率 `≥1-β_g`；框架一致即在 `m_C ≥ 0` 时 `Valid_C` 成立，由 (A30) 与 `m_lb` 定义，其失败概率上界为 `P(m_C(ĝ) < L_ξδ_ξ+L_ι1[·])`；动作-鲁棒性部分沿用第 54 轮定理的 `Σ_d(1-ρ_min(d)) + β_E + P(δ_a>Θ_a)`。三者取并集上界即得。若门控选择 DISAMBIGUATE，则由 (A31) 在有限步内回到 EXECUTE/ABORT，不引入额外无限期风险。

## 6. 本轮最大风险

**一句话**：把证书从“无条件断言”改为“以位姿-意图联合信念为条件的接地断言”，在原理上补上了第 54 轮最大的隐含漏洞，但其 soundness 完全押在**接地裕度对位姿/意图误差的 Lipschitz 线性化**上；一旦证书有效边界在真实场景中呈强非线性或跳变（尤其在遮挡突变、意图本体切换处），名义裕度会给出虚假的安全感，系统可能在“看起来还有余量”时于真实帧中失效，故必须以**分区局部 Lipschitz 在线估计 + 等变残差绊线 + 消歧步数硬上限**三重护栏，宁可频繁 ABORT，也不把“接地裕度的线性外推”当成部署保证。
