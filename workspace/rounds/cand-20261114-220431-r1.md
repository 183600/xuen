# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「动态避障」×「人机协作」）

> R69 给了闭环一张嘴，问出「我该向谁求证、还能问什么」，并把不确定性拆成 aleatoric（噪声，收紧）与 epistemic（歧义，主动消解）。但 R69 有一个隐蔽前提：**被求证者是被动的信息源**——问就答、看就被看，`p(y|g,o)` 是固定条件分布。在「动态避障 × 人机协作」里这个前提当场失效：
> 1. 障碍物在动，而且**人会对我的动作做出反应**。我的探询不是在读取一个静止世界，而是在**改变被观测系统**——这是博弈，不是查询。R69 在固定条件下算的 VoI 会系统性失准（甚至符号错）。
> 2. 高速相遇时（闭合速度 ~1.5 m/s），「停下来问一句」来不及。真正够快的交互通道是**运动本身**：减速、侧偏、让行、注视——肢体语言就是信息动作。
> 3. 最危险的既不是噪声也不是意图歧义，而是**策略不确定性**：对方会让、会抢、还是在假装让？这类不确定性**不能靠「假设对方合作」来消解**——那正是责任泡沫（responsibility bubble）的来源。
>
> 核心命题：**把不确定性再切一刀，分出第三类 U_strat（策略/耦合不确定性）。aleatoric、epistemic 完全继承 R69；strategic 单独走一条通道，且带一条不可交易的铁律：安全地板永远用 worst-case 非合作响应模型计算，合作/level-k 模型只能在已认证安全集内买效率。** 用共同知识通行权（ROW）给出对称、可独立复算的责任分配；时间够就用 R69 的显式问句，时间不够就用**可读运动**当隐式信号；死锁时单调升级（隐式→显式→停车让行），绝不用安全换 liveness。命名 **TANGO-RAS**（Trust-aware Negotiated Game-theoretic Obstacle avoidance）——避障是两个人的舞，不是一个人绕开一根木桩。
>
> 一句话定位：R69 问「**我该向谁求证**」，R70 问「**当对方也在看我的时候，我该怎么动**」——不确定性不只是刹车踏板、也不只是一句提问，还可以是一次**可读的侧身**。

## 0. 直觉与动机

**灵感 1（动态避障不是绕桩，是共舞）**
直觉：经典避障把障碍物当外生、未来轨迹给定，预测器与执行器解耦。但只要障碍物是人，人的未来就**依赖我怎么做**：我加速他退、我犹豫他抢、我让行他过。此时「预测→执行」的两段式在数学上就是错的——。因为预测的输入（我的动作）本身是预测的输出。正确对象不是「人的轨迹」，而是**耦合系统的联合轨迹**（我与他共同满足的一个不动点/博弈均衡）。这把 R69 的「单边信息动作」升级为「双边策略互动」。

**灵感 2（第三类不确定性：策略不确定性 U_strat）**
直觉：R68/R69 的二分隐含一个世界观：世界有个客观状态 θ，噪声不可约（ale）、歧义可查（epi）。但博弈里对方的「类型」——合作/竞争/分心/激进、反应时、进退风格——既不是纯噪声，也不是我能「问出来」的客观事实，因为**对方的策略会针对我而变化**。我越确定、越可读，对手越能利用。U_strat 是**反身（reflexive）**的：它的分布取决于我自己的策略。因此它不能被「观测消解」，只能被「博弈分析 + 防御性设计」管理。这是本轮最重要的概念增量。

**灵感 3（安全/效率必须分家：worst-case 保安全，合作模型买效率）**
直觉：R69 的「epistemic 消解后获得 resolution bonus」很优雅，但直接搬到博弈里会致命：如果我用「对方大概率会让」去放宽安全裕度，一旦赌错就是碰撞。所以本轮的架构是一句话——**安全地板用最坏情况（非合作、可 feint）算；合作/level-k 只决定在安全集内部怎么走得好看、走得快**。集合包含关系保证：任何合作假设最坏也只是让效率退化，绝不能让安全退化。这正是 R69「新层必须是旧层严格泛化」的姿态在博弈维度的延伸。

**灵感 4（运动即信号：最慢的嘴，最快的腿）**
直觉：R69 的显式交互（问/看/触）在低速、时间充裕时最优；但在动态避障里，说一句话要几百毫秒，一次注视可能被误读，而**减速与侧偏是零延迟、跨语言、不可撤回地可读的**。于是信息动作空间必须扩容出「隐式信号」分支：轨迹形状、朝向、让行点、速度剖面都是可设计的信号。关键是它和 R69 一样是 VoI 问题，只是「问句」换成了「运动参数」，且信号成本 = 效率损失。「该明说就明说，来不及就用身体说。」

**灵感 5（通行权 ROW：把「默契」变成可认证的共同知识）**
直觉：相互避让最怕两件事——**双让死锁**（都停）和**双抢碰撞**（都以为对方让）。人类靠眼神、手势、社会规范解决；机器人需要一个**对称、确定、只依赖共同可观测状态**的优先级规则（右侧优先、让速不让道、主路优先、弱势优先……），让双方**各自独立算出一致结论**。只有当规则是共同知识，安全证明才不需要假设对方「善良」，只需要假设对方「看得见、算得出、会反应」。ROW 把「默契」从玄学变成可认证的协议。

**灵感 6（对 R69 最大风险的镜像：责任泡沫）**
直觉：R69 自陈「模态分布不可信 → 问错比不问更危险」。R70 的对应物更阴险：**如果我对「人的响应模型」标定错了，系统会把自己的让行动作解读为「对方已经领会并会让」，于是越让越放心、越放心越激进**——两个智能体都以为对方会避让，共同制造一个「责任泡沫」，泡沫破裂时同时撞上。它不是「问错一个模态」，而是「在一个会回应的对手面前，押错了对方的策略类型」。所以本轮必须交付：策略校准（反应模型可靠图）、feint/试探威胁模型、ROW 责任证书、以及「 reciprocity credit 必须靠观察到的让行历史挣得，不能预先支取」。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（TANGO-RAS 总览）** TANGO-RAS = (RAP, SPG, ROW, LEG, LMS, CCM, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **策略安全地板不可交易**：认证安全包络恒按 worst-case 非合作响应模型 ℋ_wc 计算，合作/level-k 预测只允许在包络**内部**降成本，绝不允许扩张包络；
(iii) **共同知识通行权**：所有反应性主体共享一个对称、确定、只依赖共同可观测状态的优先级规则；机器人证书包含自己的 ROW 义务，并只假设「共同知识」，不假设「善意」。

**定义 311（反应性划分与反应性信念）** 障碍集合 O = O_react ⊔ O_inert。对主体 i，反应性 r_i = P(动作与我过去动作相关 | 历史)。r_i < τ_react ⇒ 按惰性处理（走 R69 预测不确定性通道，保守）；r_i ≥ τ_react ⇒ 按策略主体处理（进入博弈通道）。**安全侧的不对称**：分类不确定时按「反应性最强 + 最不利」处理，绝不把可能的对手误判成木桩。

**定义 312（动作条件化响应模型与 level-k）** 人的策略写作 π_H^{(k)}(a_H | s, a_R)，k 为推理层级：level-0 为固定先验（非反应），level-k 对机器人 level-(k−1) 的名义动作做最佳响应。关键：响应**同时以我的动作 a_R 为条件**，而不只是观测 o——这就是「单边预测」与「耦合博弈」的分水岭。机器人采用有界层级 K_L（默认为 1）。

**定义 313（三元不确定性）** U = (U_ale, U_epi, U_strat)，三者语义不同、分通道处置：
U_ale = 模态内噪声（不可约 → R68 λ floor）；
U_epi = 模态间/意图歧义（可约 → R69 主动交互）；
U_strat = H(θ_H | h) + 均衡集多峰性，θ_H =（合作性、反应时、激进程度、是否 feint 等类型参数）。U_strat 的**反身性**：其分布依赖我的策略 π_R，故不能被被动观测「消解」，只能被博弈分析、信号设计与防御性裕度管理。

**定义 314（策略可能性博弈与鲁棒包络）** 对候选机器人动作 a_R，人类响应集 BR(a_R; ℋ) = {a_H : a_H ∈ argmax_{a} Q_H(s, a_R, a; θ_H), θ_H ∈ ℋ}。认证安全集
S_wc = {a_R : Collide( Reach(π_R, BR_wc(a_R) ∪ O_inert) ) = ∅}，其中 ℋ_wc = 非合作 + feint 覆盖的 worst-case 类型集，Reach 为**联合**可达管。
效率集 S_co = {a_R ∈ S_wc : 与 level-k 合作响应的联合可达管无碰撞}。恒有 S_co ⊆ S_wc；动作必须 ∈ S_wc，仅在 ∈ S_co 时取合作捷径。

**定义 315（通行权 ROW 与责任证书）** 优先级 π(s) = 对称、确定、仅依赖共同可观测状态的函数（接近角、速度、主/支路、社会角色、意图可读性；社会规则如「右侧优先 / 让速不让道 / 弱势优先」）。让行义务 Y_i ∈ {proceed, yield, uncertain}；C_row 保证：若双方各自从 π 复算并履行义务，则联合轨迹无碰撞；且在「合理人集合 ℋ_reason」内无死锁（引理 20）。**关键：机器人无论相信对方会怎么做，都先履行自己的义务**（防御性）。

**定义 316（运动即信号：可读性 LEG）** 隐式信息动作 g_imp = 轨迹整形参数（侧偏方向/幅度、速度剖面、让行点、朝向、注视）。可读性 Leg(ξ) = E_{人类意图推断}[D_KL(p(g_R|ξ)‖p(g_R))] 或「人类对机器人意图后验熵的期望下降」。信号成本 = 效率损失（时间/路径长度）。在时间充裕或冲突缓和时，它与 R69 的显式 g_ask 并列；在 TTC 紧张时，它**是唯一可行的交互通道**。

**定义 317（延迟感知交互模态选择 LMS）** 给定 TTC、预算与两类 VoI：mode* = argmax_{m ∈ {none, implicit, explicit}} [VoI_m − cost_m]，s.t. m 在 TTC 内物理可行。显式（问/看/触）需 TTC > τ_ask 且预算允许；否则只能隐式；都无利可图则不交互，走保守。

**定义 318（耦合闭环监测 CCM）** 不再用「冻结的人类预测器」滚动机器人，而是求联合不动点：(ξ_R, ξ_H) 满足 ξ_R = π_R(s)，ξ_H = π_H^{(k)}(s, a_R)，s 沿二者联合演化。收缩条件下（Lipschitz 乘积 L_R·L_H < 1）不动点存在且唯一；证书沿**耦合可达管**给出（而非解耦管）。若收缩失败/无不动点 ⇒ 回退 worst-case 非反应滚动（R68 形）。

**定义 319（策略/表演性 VoI）** VoI_strat(g) = H(θ_H|h) − E_{y∼p(·|g,θ_H,π_H)}[H(θ_H|h,y)]，但 y 的分布取决于人类如何**解读** g。对竞争型 θ_H，暴露 g 反而让对方更占优 ⇒ 定义带符号的「信息优势」，允许 VoI_strat < 0（**信号可能有害**）。故并非所有可读性都是好事：高对抗下应选择「最小信息让行」（沉默服从/停车），而非高调表白。

**定义 320（防御性互惠 DRL）** 机器人可依赖「对方会让行」的额度（reciprocity credit）**必须靠观察到的让行历史挣得**，且只能用于 S_wc 内的效率选择；安全裕度永远按 ℋ_wc。未挣得额度的初始状态 = 完全非合作地板。这从机制上消灭「责任泡沫」：合作预期可以花，但不能用来拆安全垫。

**定义 321（安全-活性分离与死锁升级）** 两张独立证书：安全证书 ∀θ_H ∈ Θ_wc（含对抗/feint）；活性证书仅对 θ_H ∈ ℋ_reason + ROW 共同知识。活性假设不成立时，由死锁检测器单调升级：隐式→显式（若 TTC 允许）→停车让行；**升级绝不放松安全证书，也不用安全换 liveness**。检测「无进展」（双方速度 < δ 且间距稳定）或「极限环振荡」。

**定义 322（参与式审计 VQAuditor-R）** 审计新增：ROW 责任分配是否被正确复算、reciprocity credit 发放是否有证据、feint 是否被识别、显式/隐式模态切换是否及时。结论回灌 AuditBuf，成为下一轮 RAP 类型先验与 LMS 成本先验。

**定义 323（AIC-TANGO 威胁模型）** ℰ_TANGO = ℰ_FLUID × ℰ_strat，后者含：**feint**（假装让行后抢行）、**试探**（人故意测试机器人是否让行）、**协同围堵**（多人配合挤压）、**响应模型投毒**（训练/在线数据被污染使 RAP 误判类型）、**耦合振荡**（双方镜像反应形成极限环）。要点：feint 既非 aleatoric 噪声也非 epistemic 歧义，它是**策略性**的，必须由 ℋ_wc 覆盖，不能靠「多问一句」解决。

**定义 324（证书 J_TANGO）** J_TANGO = (J_FLUID, row_certificate, reciprocity_credit, U_strat_before/after, mode_ratio_explicit/implicit, deadlock_escalations, feint_flags, coupled_reach_margin, tango_ver)。Valid ⇔ Valid(J_FLUID) ∧ 安全证书在 ℋ_wc 下成立 ∧ ROW 义务已履行 ∧ credit 发放有据。

**定义 325（时序/层级/均衡预算）** 默认 K_L=1（人 level-1：对机器人当前名义动作做最佳响应）；仅当 TTC < τ_ttc 时做完整耦合定点滚动；均衡枚举上限 M（默认 4）；隐式计算复用 R69 的 Heun N_step=2。层级与均衡数本身是「算力-置信」折中，保证 P99 实时预算。

## 2. 关键算法骨架

```python
# IP-264 RAP：动作条件化的人类响应模型（level-k，复用 R69 冻结 trunk 与流策略）
class ReciprocalActionPredictor:
    def __init__(self, trunk, flow, level=1, horizon=H):
        self.trunk, self.flow, self.level = trunk, flow, level
    def respond(self, s, a_R_nominal, level=None):
        k = self.level if level is None else level
        if k == 0:
            return self.flow.sample_human_prior(s)        # 非反应先验
        return self.flow.best_response_human(s, a_R_nominal, level=k-1)

# IP-265 SPG：策略可能性博弈，返回 worst-case 与协作两个包络（S_co ⊆ S_wc）
def strategic_envelope(s, a_R, rap, wc_model, M=4):
    coop = rap.respond(s, a_R)
    wc   = wc_model.worst_responses(s, a_R, M)            # 集合：非反应 + 对抗 + feint
    return coupled_reachable(s, a_R, wc), coupled_reachable(s, a_R, {coop})

# IP-266 ROW：共同知识通行权 + 责任证书
def right_of_way(s, me, others):
    prio  = {i: priority_fn(s, i) for i in [me, *others]} # 对称、确定、可复算
    order = sorted(prio, key=prio.get, reverse=True)
    ob    = 'proceed' if order[0] == me else 'yield'
    return ob, row_certificate(s, prio, ob)               # 无论信念如何先履行义务

# IP-267 LEG：把运动本身当信号（legible yielding）
def legible_shaping(s, a_R, intent_dist, S_wc):
    return argmax(a, [legibility(a, intent_dist) - w_eff*cost(a)
                      for a in candidates if a in S_wc])   # 安全集内最大化可读性

# IP-268 LMS：延迟感知的显式/隐式模态选择
def select_modality(s, TTC, budget, voi_exp, voi_imp):
    if TTC > TAU_ASK and budget.allow('explicit') and voi_exp > voi_imp:
        return 'explicit'                                  # 继承 R69 的问/看/触
    if voi_imp > cost_implicit(s):
        return 'implicit'                                  # 减速/侧偏/注视
    return 'none'

# IP-269~272 主闭环：耦合监测 + ROW + 防御性互惠 + 死锁升级
def TANGO_RAS_round(M, s):
    R, I = classify_reactivity(s, M.history, tau=M.tau_react)
    # 1) 仅 TTC 紧张时做完整耦合定点滚动；否则沿用 R68/R69 惰性通道
    if s.TTC < M.tau_ttc:
        S_wc, S_co = M.spg.strategic_envelope(s, M.a_nom, M.rap, M.wc)
        joint = M.ccm.fixed_point_rollout(s, M.policy, M.rap, M.level)
        coupled_ok = joint is not None
    else:
        S_wc = M.ras_wm.certified_set(s, I); S_co = S_wc; coupled_ok = True
    # 2) 通行权：安全侧永远按义务，不信「对方会让」
    ob, row_cert = M.row.right_of_way(s, M.id, R)
    # 3) 显式 vs 隐式交互（来不及只能「用动作说话」）
    mode = M.lms.select_modality(s, s.TTC, M.budget, M.voi_exp, M.voi_imp)
    g = (M.leg.legible_shaping(s, M.a_nom, M.intent, S_wc) if mode == 'implicit'
         else M.mint.choose_interaction(s, M.modes, M.budget))
    # 4) 安全地板 worst-case；合作捷径只在 S_co 内、且已挣得 reciprocity credit
    a_safe = project(M.policy.sample(s), S_wc)
    a_eff  = project(M.policy.sample(s), S_co) if (ob == 'proceed' and M.drl.credit() > 0) else a_safe
    a      = a_eff if (coupled_ok and ob == 'proceed') else a_safe
    # 5) 死锁/振荡：单调升级，绝不拿安全换 liveness
    if M.ddl.no_progress(s) or M.ddl.oscillating(s):
        a = M.ddl.escalate(s, a, allow_explicit=(s.TTC > M.tau_ask))
    # 6) 认证 + 审计 + 证书
    k = M.c_ras_wm.certified_prefix(a, s, S_wc)
    M.vqa_r.submit_async(row_cert, mode, M.rap.level, S_wc, S_co)
    return k, a, ob, mode, (S_wc, S_co)
```

## 3. 推导

**引理 19（表演性 VoI 的偏差）** 设 R69 的被动 VoI₀ 用冻结的 p(y|g,o)。在策略互动下响应分布依赖 g 如何被解读：VoI_strat(g) = VoI₀(g) − p_adv·Δ_leak(g) + ε，其中 p_adv 为对抗型概率，Δ_leak 为 g 暴露给对手的信息价值（与 Leg(g) 正相关）。系：**高对抗下高可读信号可能使 VoI_strat < 0**——此时最优策略是「沉默服从」（停车/最小信息让行），而非高调表白；这也是「该明说才明说」的理论依据。

**引理 20（ROW 的安全与活性）** 设优先级 π 对称、确定、仅依赖共同可观测状态，让行义务配合有界减速度。则 (a) 只要机器人**无论信念如何都履行义务**，联合系统对任意 θ_H ∈ Θ_wc 无碰撞；(b) 若双方 ∈ ℋ_reason 且遵守 ROW，则存在势函数 Φ（按优先级排序的间距泛函）沿轨迹单调下降到「有进展」，无死锁。系：安全不依赖善意，活性依赖共同知识——两者被干净分离。

**引理 21（防御性互惠的支配性）** 令 S_wc 为在 ℋ_wc 下认证的安全集。任何只在 S_wc 内使用合作捷径的策略，其风险 ≤ 任何在 S_wc 外信任对方合作的策略（后者存在 θ_H ∈ Θ_wc 使其碰撞）。故 reciprocity credit 只影响成本、绝不改变安全下界；且 credit 靠观察让行历史挣得，使期望风险不高于「预支信任」。

**定理 18（TANGO 严格包含 FLUID，进而包含 R68）** 当 O = O_inert（无反应性主体）或 U_strat = 0 时，RAP/SPG/ROW 分支自动失活，S_wc = S_co = R69 认证集，隐式/显式选择退化为 R69 的 MINT，TANGO 与 FLUID **逐指令相同**；FLUID 在 VoI≤成本时又退化为 R68。安全地板在每一层只增不减，效率在 ℋ_reason 下获得 resolution bonus。

**定理 19（安全-活性分离与无突变切换）** TANGO 对任意 θ_H ∈ Θ_wc 保证安全而无需 liveness 假设；对 θ_H ∈ ℋ_reason 保证 liveness。显式/隐式切换与死锁升级均为**单调**操作，且始终在已认证前缀内 ⇒ 继承 R68 定理 15（提交/换装不变式），控制连续、无突变；升级失败时退化为最保守停车让行，安全侧永不弱于 R68/R69。

## 6. 本轮最大风险

**一句话**：TANGO 的整个安全承诺都押在「我能正确界定最坏情况响应集合 Θ_wc」这一前提上——**若最坏集被欠近似（没想到人的急停、折返、假装让行），那个被漏掉的策略会同时击穿安全与 liveness；更糟的是 ROW 的「共同知识」会让我们把「我没枚举到的动作」默认成「对方不会做」，从而在两个人心里同时吹起一个责任泡沫**——「以为对方会让，比谁都不让更危险」。

**次级风险与缓解**：
1. **响应模型标定错误（责任泡沫）** → 安全地板恒用 ℋ_wc，合作仅在 S_co 内、且 credit 靠历史挣得（引理 21）；
2. **feint/试探/协同围堵** → ℰ_strat 覆盖 + feint 检测 + E307；
3. **ROW 共同知识假设被破坏**（对方不懂规则）→ 机器人无条件先履行义务，活性失败只降级为停车，不降安全；
4. **耦合定点不收敛/振荡** → 收缩检测 + 回退非反应 worst-case（定义 318）；
5. **实时预算被耦合滚动击穿** → 仅 TTC<τ_ttc 触发 + K_L=1 + M≤4 + 层级自适应。

## 4. 推导

**引理 19（表演性 VoI 偏差）** 被动 VoI₀ 用冻结 `p(y|g,o)`；策略互动下 `VoI_strat(g)=VoI₀(g)−p_adv·Δ_leak(g)+ε`，`Δ_leak` 与 `Leg(g)` 正相关。系：高对抗下高可读信号可能使 VoI<0，最优为「沉默服从」（停车/最小信息让行）——「该明说才明说」的理论依据。

**引理 20（ROW 安全与活性）** (a) 机器人无条件履行义务 ⇒ 对任意 θ_H∈Θ_wc 无碰撞；(b) 双方∈ℋ_reason 且遵守 ROW ⇒ 势函数 Φ 单调下降到「有进展」，无死锁。系：安全不依赖善意，活性依赖共同知识。

**引理 21（防御性互惠支配性）** 只把合作捷径限制在 S_wc 内，风险 ≤ 任何在 S_wc 外信任合作的策略（后者存在 θ_H∈Θ_wc 致碰撞）。故 credit 只影响成本、不改安全下界；靠历史挣得使期望风险不高于预支信任。

**定理 18（TANGO 严格包含 FLUID，进而包含 R68）** 当 `O=O_inert` 或 `U_strat=0`：RAP/SPG/ROW 失活，`S_wc=S_co=R69` 认证集，模态选择退化为 MINT，TANGO 与 FLUID **逐指令相同**；FLUID 在 VoI≤成本时又退化为 R68。安全地板每层只增不减，ℋ_reason 下效率获 resolution bonus。

**定理 19（安全-活性分离与无突变切换）** 对任意 θ_H∈Θ_wc 保证安全而无需 liveness；对 θ_H∈ℋ_reason 保证 liveness。显式/隐式切换与死锁升级均单调且始终在已认证前缀内 ⇒ 继承 R68 定理 15，控制连续、无突变；升级失败退化为最保守停车让行，安全侧永不弱于 R68/R69。

## 7. 本轮最大风险

**一句话**：TANGO 的整个安全承诺都押在「我能正确界定最坏情况响应集合 Θ_wc」这一前提上——**若最坏集被欠近似（没想到人的急停、折返、假装让行），那个被漏掉的策略会同时击穿安全与 liveness；更糟的是 ROW 的「共同知识」会让我们把「我没枚举到的动作」默认成「对方不会做」，从而在两个人心里同时吹起一个责任泡沫**——「以为对方会让，比谁都不让更危险」。

**次级风险与缓解**：响应模型标定错误/责任泡沫（安全地板恒用 ℋ_wc + credit 靠历史挣得，引理 21）；feint/试探/围堵（ℰ_strat + feint 检测 + E307）；ROW 共同知识被破坏（无条件先履行义务，活性失败只降级为停车）；耦合定点不收敛/振荡（收缩检测 + 回退非反应 worst-case）；实时预算被击穿（仅 TTC<τ_ttc 触发 + K_L=1 + M≤4 + 层级自适应）。
