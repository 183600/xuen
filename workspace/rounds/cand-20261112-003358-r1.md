# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；新灵感循环第 1 轮；本轮灵感：「谐波减速器」×「专利布局」）

> 前 54 轮把技能组合提升为「动作-鲁棒性双证书」，但有一个被悬置的物理前提：动作剖面 `α_S` 与对齐容差 `δ_a` 都是"软件可承诺"的量，默认底层执行器能精确兑现。谐波减速器提醒我们：真实关节存在空回、非线性扭转刚度、传动误差与疲劳退化，这给任何证书设了一个**物理精度地板**。专利布局提醒我们：创新点本身也需要"权利要求"——核心方法（属）与变体（种）共同构成围栏，否则易被设计绕过。本轮把**传动非理想性**下推到证书底层，并把创新点组织为**权利要求图**。核心矛盾：H22：证书在软件层看似 sound，但在传动层被执行器的迟滞/柔度击穿，形成"软件可证、硬件不可达"的假阳性；H23：创新点清单是扁平列表，缺少属/种层级与空白区检测，novelty 覆盖存在结构性缺口。

## 0. 直觉与动机

**灵感 1（谐波减速器 = 精度地板）**
直觉：谐波减速器靠柔轮（flexspline）的弹性变形与 2 齿差实现大减速比，带来零背隙、高扭矩密度，但也带来空回 `δ_lost`、非线性扭转柔度 `τ/K_t`、周期传动误差 `e_trans(θ)` 和迟滞 `H`。这意味着即使电机指令完美，输出端仍有一个不可消除的偏差下界 `Θ_min = δ_lost + τ_max/K_{t,min} + ε_te`。**任何承诺优于 Θ_min 的证书都是物理不可实现的**。把 `Θ_min` 作为证书的第一性下界，是给前几轮"可解释鲁棒性"补上物理地基。

**灵感 2（2 齿差 = 杠杆不对称 → 预算缩放律）**
直觉：谐波减速器 `R ≈ N_cs/2` 很大（常 50–160）。运动学误差沿减速比被**缩小** `δ_o = δ_cmd/R`，但负载柔度误差 `τ/K_t` 位于输出侧、**不被 R 衰减**。于是存在**杠杆缺口** `G_lev = δ_o - δ_cmd/R = δ_lost + τ/K_t + e_trans ≥ 0`：证书若只按 `δ_cmd/R` 传递预算、忽略柔度项，就会在重载/低速工况系统性低估输出误差。预算必须"运动学缩减 + 柔度不缩减"分通道传播。

**灵感 3（柔轮疲劳 = 证书保鲜期）**
直觉：柔轮是疲劳件，循环数增加时 `K_t` 下降、`δ_lost` 上升，精度地板 `Θ_min(n)` 单调抬升。证书不是"一签永逸"，而是有**半衰期 `T_½`**：当 `Θ_min(n) > Θ_o` 前必须重认证。这把证书从静态对象变为**带时效的安全包线**。

**灵感 4（传动感知剖面 = 鲁棒腐蚀）**
直觉：动作剖面 `α_S` 应做形态学**腐蚀**：`G̃_S = {a : B_ε(a) ⊆ G_S}`，其中 `B_ε(a)` 是传动不确定球。只有被不确定球完整包住的"好动作"才可信。这把第 54 轮的 `δ_a` 从"调参容差"变成"由硬件谱推出的物理量"。

**灵感 5（专利布局 = 权利要求图 + 围栏覆盖）**
直觉：创新点不是扁平清单，而是一棵**权利要求树**：独立权利要求覆盖"属"（宽），从属权利要求覆盖"种"（窄，作 fallback 防规避）。用"围栏覆盖"衡量布局：`F = ∪ C_i` 覆盖目标解空间 `Ω_target`，`Ω_target \ F` 是**空白区**（可被对手抢占）。布局目标是在**可实施性（enablement）**约束下，用最少的证据成本最大化覆盖并保留 fallback——这是带背包约束的最大覆盖问题，贪心可达 `1-1/e`。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（传动非理想谱 TIS）**
对含谐波减速器的关节，定义
```
Δ_T = (δ_lost, K_t(τ), e_trans(θ), H, f_res, λ_fat)
```
其中 `δ_lost` 为空回（统一换算到输出侧弧度），`K_t(τ)` 为非线性扭转刚度，`e_trans(θ)` 为周期传动误差，`H` 为迟滞算子，`f_res` 为一阶谐振，`λ_fat` 为疲劳退化率。输出偏差界
```
ε_Δ(τ,θ) = δ_lost + |τ|/K_t(τ) + |e_trans(θ)| + ε_H
```
**精度地板** `Θ_min = δ_lost + τ_max/K_{t,min} + max_θ|e_trans(θ)|`。

**定义 122（传动感知动作剖面 TAP）**
名义好动作集 `G_S = {a : α_S(a) ≥ θ_cov}`，传动不确定球 `B_ε(a) = {a' : d(a,a') ≤ ε_Δ(τ(a),θ(a))}`。鲁棒好动作集为形态学腐蚀
```
G̃_S = G_S ⊖ B_ε = {a ∈ G_S : B_ε(a) ⊆ G_S}
```
鲁棒覆盖 `cover_Δ(S,A_T)=1` 当且仅当 `A_T ⊆ G̃_S`。

**定义 123（传动杠杆律 TLL）**
设减速比 `R`，任务雅可比 `J_o`，任务容差 `Θ_x`，输出容差 `Θ_o = Θ_x/‖J_o‖`。真实输出偏差
```
δ_o = δ_cmd/R + δ_lost + τ/K_t + e_trans = δ_cmd/R + G_lev
```
杠杆缺口 `G_lev = δ_o - δ_cmd/R ≥ 0`。预算可传播条件：`Θ_o > G_lev`，此时可发放的命令容差 `δ_cmd = R·(Θ_o - G_lev)`。

**定义 124（证书半衰期 CEL）**
退化模型
```
K_t(n) = K_t0·(1 - κ·n/N_f),   δ_lost(n) = δ_lost0·(1 + η·n/N_f)
```
`Θ_min(n)` 单调递增。半衰期 `T_½ = min{n : Θ_min(n) > Θ_o}`。证书携带 `expiry = T_½`，执行前须满足 `n < T_½`。

**定义 125（创新点权利要求图 IPCG）**
`IPCG = (V, E_⊑, scope, prio, evid, pa)`：`V` 为创新点；`E_⊑` 为属→种的从属/细化边；`scope(v) ⊆ Ω` 为权利要求覆盖的解空间区域；`prio(v)` 优先日；`evid(v) ∈ [0,1]` 证据强度；`pa(v)` 现有技术重叠。围栏覆盖 `F = ∪_v scope(v)`，空白区 `W = Ω_target \ F`。

**定义 126（可布局性与围栏增益 FCL）**
布局质量
```
L = α·|F∩Ω_target|/|Ω_target| + β·(1 - redundancy) + γ·fallback_count - δ·mean(pa)
```
约束 `evid(v) ≥ θ_e`（宽权利要求须可实施）。围栏增益
```
fencescore(v) = |scope(v) ∩ W| / cost_evidence(v)
```
即每单位证据成本可填补的空白区。

## 2. 关键算法 伪代码

### IP-121 TIS（Transmission Imperfection Spectrum）标定

```python
def transmission_spectrum(joint, torque_grid, theta_grid, calib):
    delta_lost = calib.measure_lost_motion(joint)          # 输出侧 rad
    K_t   = fit_piecewise_stiffness(calib.torque_twist(joint, torque_grid))
    e_te  = fit_periodic_error(calib.transmission_error(joint, theta_grid))
    e_te_max = max(abs(e_te(th)) for th in theta_grid)
    eps_H = calib.hysteresis_residual_bound(joint)

    def eps(tau, th):
        return delta_lost + abs(tau)/K_t(tau) + abs(e_te(th)) + eps_H

    theta_min = delta_lost + max(torque_grid)/K_t.min + e_te_max
    return TIS(delta_lost, K_t, e_te, eps, theta_min, calib.resonance(joint))
```

### IP-122 TAP（Transmission-Aware Profile）鲁棒覆盖

```python
def robust_profile(alpha, tis, theta_cov=0.8):
    G = {a for a, v in alpha.items() if v >= theta_cov}
    G_tilde = set()
    for a in G:
        r = tis.eps(tau_of(a), theta_of(a))
        if uncertainty_ball(a, r) <= G:      # 形态学腐蚀：球整体落在好集内
            G_tilde.add(a)
    return G_tilde

def cover_delta(G_tilde, A_T):
    return set(A_T) <= G_tilde
```

### IP-123 TLL（Transmission Leverage Law）预算传播

```python
def propagate_budget(theta_x, J_o_norm, R, tis, tau_max):
    theta_o = theta_x / J_o_norm
    gap = tis.delta_lost + tau_max / tis.K_t.min + tis.e_te_max
    if theta_o <= gap:
        return ('infeasible', 'below_precision_floor', gap)   # 物理不可实现
    delta_cmd = R * (theta_o - gap)
    return ('ok', delta_cmd, gap)
```

### IP-124 CEL（Certificate Expiry & Lifespan）

```python
def certificate_lifespan(tis0, theta_o, kappa, eta, N_f, tau_max, horizon):
    for n in range(horizon):
        Kt = tis0.K_t.min * (1.0 - kappa * n / N_f)
        dl = tis0.delta_lost * (1.0 + eta * n / N_f)
        theta_min = dl + tau_max / Kt + tis0.e_te_max
        if theta_min > theta_o:
            return n          # T_half：必须重认证
    return horizon
```

### IP-125 IPCG（IP Claim Graph）构建

```python
def build_claim_graph(ips, prior_art):
    G = nx.DiGraph()
    for v in ips:
        G.add_node(v.id, scope=v.scope, prio=v.priority_date,
                   evid=v.evidence, pa=claim_overlap(v, prior_art))
    for v in ips:                    # 属 -> 种
        for u in ips:
            if u.refines(v):
                G.add_edge(v.id, u.id, kind='dependent')
    covered = set().union(*[d['scope'] for _, d in G.nodes(data=True)])
    return G, covered

def white_space(covered, omega_target):
    return omega_target - covered
```

### IP-126 FCL（Fence Coverage Layout）贪心围栏

```python
def greedy_fence(candidates, omega_target, budget, theta_e):
    covered, chosen = set(), []
    while True:
        best, best_gain = None, 0.0
        for c in candidates:
            if c.cost > budget or c.evid < theta_e:
                continue                       # 预算 / 可实施性约束
            gain = len(c.scope & (omega_target - covered)) / c.cost
            if gain > best_gain:
                best, best_gain = c, gain
        if best is None:
            break
        chosen.append(best)
        covered |= best.scope
        budget -= best.cost
        candidates.remove(best)
    return chosen, omega_target - covered      # 选择集 + 剩余空白区
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| TIS | O(|τ|·|θ|) | O(|τ|+|θ|) | 刚度/误差上界、迟滞残差界 |
| TAP | O(|A|·|B_ε|) | O(|G|) | 腐蚀算子 sound、ε 上界保守 |
| TLL | O(1) | O(1) | 分通道传播、floor 可判定 |
| CEL | O(H) | O(1) | 退化模型单调有界 |
| IPCG | O(|V|²·|Ω|) | O(|V|·|Ω|) | 属/种偏序无环、scope 闭合 |
| FCL | O(k·|C|·|Ω|) | O(|Ω|) | enablement + 预算、贪心近似比 |

**正确性定理（Transmission-Aware Certificate Soundness, TACS）**
假设 (A29) `ε_Δ` 由数据手册 + 在线辨识给出保守上界；(A30) 任务雅可比 `‖J_o‖ ≤ J_max`；(A31) 疲劳模型在 `[0,H]` 上单调有界；承接第 54 轮 (A26)–(A28)。则对有效期 `n < T_½` 内的证书 `J_Δ = (ρ, A_cert, Δ_T, T_½)`：
```
P(fail) ≤ P(ε_Δ > Θ_o) + P(τ > τ_max) + P(n > T_½) + β_E + Σ_d(1 - ρ_min(d))
```

**命题 1（精度地板不可逾越）**：`∀` 软件层证书，若 `Θ_o < Θ_min`，则存在工况使成功概率为零——软件无法补偿传动层的物理下界。

**命题 2（杠杆缺口下界）**：朴素预算 `δ_o^naive = δ_cmd/R` 与真实 `δ_o` 之差恰为 `G_lev ≥ 0`；重载时 `G_lev → τ_max/K_{t,min}` 主导，且不随 `R` 缩小。

**定理 3（围栏覆盖近似比）**：在 enablement 与预算约束下，贪心 FCL 的覆盖量 `≥ (1 - 1/e)·OPT`。

## 6. 本轮最大风险

**一句话**：精度地板 `Θ_min` 由空回/柔度/传动误差的在线估计决定，而这些参数随温度、负载与疲劳持续漂移；一旦低估 `ε_Δ`，证书会在"软件 sound、硬件失效"的盲区里给出假阳性，故须以 **保守上界 + 在线传动辨识 + 强制半衰期重认证** 三重护栏，宁可把地板抬高，也绝不把未标定的传动当作理想执行器。

```python
        G.add_node(v.id, scope=v.scope, prio=v.priority_date,
                   evid=v.evidence, pa=claim_overlap(v, prior_art))
    for v in ips:
        for u in ips:
            if u.refines(v):
                G.add_edge(v.id, u.id, kind='dependent')
    covered = set().union(*[d['scope'] for _,d in G.nodes(data=True)])
    return G, covered
```

### IP-126 FCL

```python
def greedy_fence(candidates, omega_target, budget, theta_e):
    covered, chosen = set(), []
    while True:
        best, best_gain = None, 0.0
        for c in candidates:
            if c.cost > budget or c.evid < theta_e: continue
            gain = len(c.scope & (omega_target - covered)) / c.cost
            if gain > best_gain: best, best_gain = c, gain
        if best is None: break
        chosen.append(best); covered |= best.scope
        budget -= best.cost; candidates.remove(best)
    return chosen, omega_target - covered
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TIS | O(|τ|·|θ|) | O(|τ|+|θ|) | 刚度/误差上界、迟滞残差界 |
| TAP | O(|A|·|B_ε|) | O(|G|) | 腐蚀 sound、`ε_Δ` 保守上界 |
| TLL | O(1) | O(1) | 分通道传播、floor 可判定 |
| CEL | O(H) | O(1) | 退化单调有界 |
| IPCG | O(|V|²·|Ω|) | O(|V|·|Ω|) | 属/种无环、scope 闭合 |
| FCL | O(k·|C|·|Ω|) | O(|Ω|) | enablement+预算、`1-1/e` 近似 |

**正确性定理（TACS）**
假设 (A29) `ε_Δ` 为数据手册+在线辨识的保守上界；(A30) `‖J_o‖≤J_max`；(A31) 疲劳模型在 `[0,H]` 单调有界；承接 (A26)–(A28)。则有效期内证书
```
P(fail) ≤ P(ε_Δ>Θ_o) + P(τ>τ_max) + P(n>T_½) + β_E + Σ_d(1-ρ_min(d))
```

**命题 1（精度地板不可逾越）** 若 `Θ_o<Θ_min`，则存在工况使成功率 `=0`。
**命题 2（杠杆缺口下界）** `δ_o - δ_cmd/R = G_lev ≥ 0`，重载时 `G_lev→τ_max/K_{t,min}`。
**定理 3（围栏近似比）** 贪心 FCL 覆盖 `≥(1-1/e)·OPT`。

## 7. 本轮最大风险

**一句话**：精度地板 `Θ_min` 由空回/柔度/传动误差的在线估计决定，而这些参数随温度、负载与疲劳持续漂移；一旦低估 `ε_Δ`，证书会在"软件 sound、硬件失效"的盲区里给出假阳性，故须以 **保守上界 + 在线传动辨识 + 强制半衰期重认证** 三重护栏，宁可把地板抬高，也绝不把未标定的传动当作理想执行器。
