# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「抓取位姿估计」×「材料选型」）

> 第 54 轮把技能组合推进为“动作-鲁棒性双证书”。本轮换轴：**抓取位姿不是纯几何量，而是接触对的函数**。核心矛盾：H22：抓取位姿估计器在“材质无关刚体”假设下训练，材料一变（摩擦、柔顺、透明、表面污染），同一位姿 `g` 的力闭合从成立变为不成立，位姿置信度与抓取成功率解耦；H23：材料选型按平均性能独立决策，未以抓取位姿分布为约束，导致材料在均值上最优、却在薄壁/曲面/透明等关键位姿子集上系统性失败。

## 0. 直觉与动机

**灵感 1（材料是抓取位姿估计的隐变量，而非外部标签）**
直觉：看到一只杯子，我们估计的不是单一 `g`，而是“它可能是什么材料 × 哪种抓法能闭合”的联合信念。透明/反光/深色物体破坏深度与点云，材料恰是感知退化的原因，也是抓取力学的关键参数。因此估计目标应从 `p(g|O)` 变为 `p(g,m_o|O)`，其中 `m_o` 为物体材料（含表面状态）。材料后验不只是分类结果，而是 **抓取位姿不确定性的一个可解释来源**。

**灵感 2（抓取质量写成接触对上的材料条件场）**
直觉：抓取是否成立取决于摩擦锥、接触刚度、黏附与变形，而这些由 **接触对** `c=(m_o,m_f)` 的接触律决定，`m_f` 为指尖/夹爪材料。把抓取质量定义为 `Q(g;c)`，则同一 `g` 在硅胶指尖上可能稳健、在金属指尖上可能打滑。进一步以材料可信集 `C_ε` 取最坏情况，得到 **材料鲁棒抓取集** `G_ε(m_f) = {g : inf_{m_o∈C_ε} Q(g;m_o,m_f) ≥ q_min}`。这把“位姿估计”升级为“位姿-材料联合可行性判定”。

**灵感 3（材料选型 = 对抓取位姿分布的覆盖问题）**
直觉：材料选型不是“选综合评分最高的那一种”，而是“选一组指尖材料，使任务分布中尽可能多的抓取位姿存在至少一种材料可稳健闭合”。这是一个设施选址/最大覆盖结构：每种材料覆盖一部分 `(物体, 位姿, 材料)` 区域，目标是预算约束下最大化期望覆盖。由于 `max` 作用于模块化评分，目标天然是 **单调子模**，可用贪心获得 `1-1/e` 近似。材料选择由此获得可证明的性能下界，而非经验拍板。

**灵感 4（材料-抓取联合证书：把“测不准的材料”变成可部署预算）**
直觉：真实系统永远无法确知材料。与其假装确知，不如在证书里显式记录 **材料后验、可信集直径、位姿不确定度、最坏情况抓取裕度**。部署条件不是“材料分类正确”，而是“即使材料在可信集内任意取值，抓取仍有裕度”。这把材料歧义转化为可审计的容差 `δ_mat`，并与第 54 轮的联合证书 `J` 对接。

**灵感 5（金字塔扩展：材料层 𝕄 与感知-接触-决策三向耦合）**
直觉：在第 54 轮动作-鲁棒性金字塔之上叠加材料层 `𝕄`：`𝕄_0` 材料物理属性极限（摩擦、硬度、黏附、耐温），`𝕄_1` 接触对抓取质量场，`𝕄_2` 材料选型覆盖集，`𝕄_3` 材料-任务约束（食品接触、洁净、磨损寿命）。跨层证书同时携带 `ρ`、`A_cert` 与 `MG`，形成“可解释的材料-动作-鲁棒性三证书”体系。注意本框架的材料是双向的：既可是 **物体侧材料估计**，也可是 **机器人侧指尖材料选择**；二者在接触律处汇合。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（材料描述与接触对）**
物体材料 `m_o ∈ 𝔐_o`，指尖材料 `m_f ∈ 𝔐_f`，接触对 `c=(m_o,m_f)`。接触律 `Φ(c) = (μ_s, μ_k, k_n, e, a)`，分别表示静/动摩擦系数、法向刚度、恢复系数、黏附强度。材料属性本身带不确定度：`Φ(c) ∈ [Φ_lo(c), Φ_hi(c)]`。

**定义 122（材料条件化抓取位姿后验）**
给定多模态观测 `O`（RGB-D、触觉、音频、热），
```
p(g, m_o | O) ∝ p(O | m_o) · p(g | m_o) · p(m_o)
```
其中 `g ∈ SE(3) × 𝒲`（位姿 × 夹爪开度/接近方向）。**材料可信集** `C_ε ⊂ 𝔐_o` 为后验质量至少 `1-ε` 的最小高密度区域：`P(m_o ∈ C_ε | O) ≥ 1-ε`。

**定义 123（材料-抓取质量场）**
```
Q(g; c) = P(force closure ∧ wrench margin ≥ γ | g, c, Φ(c))
```
由摩擦锥与扳手空间积分/蒙特卡洛估计。**材料鲁棒质量**：
```
Q_ε(g, m_f) = inf_{m_o ∈ C_ε} Q(g; m_o, m_f)
```
**材料鲁棒抓取集** `G_ε(m_f) = {g : Q_ε(g,m_f) ≥ q_min}`。

**定义 124（材料选型覆盖目标）**
任务分布 `𝒟` 给出候选位姿集 `G_x`。材料目录 `𝔐_f`，成本 `c(m_f)`，预算 `B`。选型目标：
```
max_{S ⊆ 𝔐_f, Σ c(m_f) ≤ B}  F(S) = E_{x∼𝒟}[ max_{m_f∈S} max_{g∈G_x} Q_ε(g,m_f) ]
```
`F` 单调子模；带背包约束的贪心满足 `F(S_greedy) ≥ (1-1/e)·F(S*)`（在预算近似意义下）。

**定义 125（材料歧义直径与漂移）**
可信集直径 `diam(C_ε) = max_{m,m'∈C_ε} ||φ(m)-φ(m')||`，`φ` 为材料属性嵌入。摩擦漂移 `δ_fric(t) = ||Φ_t(c) - Φ_0(c)||` 由在线触觉辨识估计。**材料预算**：`diam(C_ε) ≤ Δ_m` 且 `δ_fric ≤ Δ_f`。

**定义 126（材料-抓取联合证书）**
```
MG = (g, m_f, C_ε, Q_min, δ_pose, diam(C_ε), δ_fric, evidence)
```
部署条件：
```
Q_min ≥ q_min ∧ δ_pose ≤ Θ_p ∧ diam(C_ε) ≤ Δ_m ∧ δ_fric ≤ Δ_f
```
`evidence` 至少包含材料后验、仿真接触试验反例、真实/半实物打滑记录。只有当 `MG` 与第 54 轮 `J` 同时通过，才允许进入动作空间组合。

## 2. 关键算法 伪代码

### IP-121 MGP（Material-Grasp Posterior）

```python
def material_grasp_posterior(O, pose_proposals, mat_prior, mat_clf, grasp_prior):
    logp = {}
    for m_o in mat_prior.support():
        log_m = mat_clf.log_prob(O, m_o) + log(mat_prior.prob(m_o))
        for g in pose_proposals:
            logp[(g, m_o)] = log_m + grasp_prior.log_prob(g, m_o)
    Z = logsumexp(list(logp.values()))
    post = {k: exp(v - Z) for k, v in logp.items()}
    g_best = max(pose_proposals, key=lambda g: sum(post.get((g, m), 0) for m in mat_prior.support()))
    return post, g_best

def credible_set(post, eps=0.05):
    marg = {}
    for (g, m), p in post.items():
        marg[m] = marg.get(m, 0.0) + p
    items = sorted(marg.items(), key=lambda kv: kv[1], reverse=True)
    S, acc = set(), 0.0
    for m, p in items:
        S.add(m); acc += p
        if acc >= 1 - eps:
            break
    return S
```

### IP-122 MAQ（Material-Aware Grasp Quality）

```python
def robust_grasp_quality(g, m_f, C_eps, contact_model, gamma, n_mc=512):
    q = 1.0
    for m_o in C_eps:
        c = ContactPair(m_o, m_f)
        lo, hi = contact_model.friction_interval(c)
        wrenches = contact_model.wrench_space(g, c, mu=lo, n=n_mc)  # 保守用下界
        margin = min_wrench_margin(wrenches, g, mu=lo)
        q = min(q, sigmoid((margin - gamma) / tau))
    return q

def robust_grasp_set(poses, m_f, C_eps, q_min, **kw):
    return {g for g in poses if robust_grasp_quality(g, m_f, C_eps, **kw) >= q_min}
```

### IP-123 MSC（Material Selection under Coverage）

```python
def select_materials(D, M_f, B, cost, C_eps_fn, q_min, contact_model):
    S, spend = set(), 0.0
    while True:
        best, best_gain = None, 0.0
        for mf in M_f - S:
            if spend + cost(mf) > B:
                continue
            gain = 0.0
            for x in D:                          # 期望覆盖增量
                C_eps = C_eps_fn(x.O)
                base = max([robust_q(x, m, C_eps) for m in S], default=0.0)
                new = max(base, robust_q(x, mf, C_eps))
                gain += new - base
            gain /= len(D)
            if gain > best_gain:
                best, best_gain = mf, gain
        if best is None or best_gain <= 1e-6:
            break
        S.add(best); spend += cost(best)
    return S
```

### IP-124 MGC（Material-Grasp Certificate）

```python
def material_grasp_certificate(g, m_f, O, post, budgets):
    C_eps = credible_set(post, eps=budgets.eps)
    q_min = robust_grasp_quality(g, m_f, C_eps, contact_model, gamma=budgets.gamma)
    if q_min < budgets.q_min:
        return ('reject', 'material_robustness', q_min)
    dp = pose_uncertainty(g, O)
    if dp > budgets.Theta_p:
        return ('reject', 'pose_uncertainty', dp)
    if diam(C_eps) > budgets.Delta_m:
        return ('reject', 'material_ambiguity', diam(C_eps))
    if online_friction_drift() > budgets.Delta_f:
        return ('reject', 'friction_drift')
    return ('ok', MG(g, m_f, C_eps, q_min, dp, diam(C_eps),
                     online_friction_drift(), evidence=(O, post, sim_trials(g))))
```

### IP-125 OMI（Online Material Identification）

```python
def online_material_update(post, tactile_window, slip_event):
    # 打滑是“实际摩擦 < 假设摩擦”的强似然，触发可信集扩张而非强行纠错
    lik = slip_likelihood(tactile_window, slip_event)
    post = bayes_update(post, lik)
    if slip_event and max(post.values()) > 0.9:
        post = temper(post, T=1.5)      # 抑制过度自信
    return post
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| MGP | O(|𝔐_o|·|G|·C_sensor) | O(|𝔐_o|·|G|) | 材料先验覆盖、后验校准 |
| MAQ | O(|C_ε|·n_mc) | O(n_mc) | 摩擦下界保守、wrench margin 计算正确 |
| MSC | O(|𝔐_f|·|𝒟|·|C_ε|·n_mc)（贪心轮数≤|𝔐_f|） | O(|𝒟|) | 子模性、预算可行 |
| MGC | O(|C_ε|·n_mc + |G|) | O(|C_ε|) | 可信集覆盖、预算闭合 |
| OMI | O(|𝔐_o|·|触觉窗口|) | O(|𝔐_o|) | 似然校准、漂移可检测 |

**正确性定理（Material-Conditioned Grasp Soundness）**
承接第 54 轮 (A26)–(A28)；新增假设：**(A29)** 真实物体材料以概率 `≥ 1-ε` 落入可信集 `C_ε`；**(A30)** 仿真接触律在 `C_ε` 上的质量模型误差 `≤ β_m`；**(A31)** `Q` 对位姿误差 `L_g`-Lipschitz。
则对任意通过 `MG` 的抓取：
```
P(success | deploy) ≥ q_min - β_m - L_g·δ_pose - ε
```
且材料选型满足带背包约束的近似下界 `F(S_greedy) ≥ (1-1/e)·F(S*)`。关键：**材料歧义被显式预算化，最坏情况质量而非平均质量决定可部署性**。

## 6. 本轮最大风险

**一句话**：材料-抓取联合建模把“位姿估计”升级为“接触对上的最坏情况判定”，但其 soundness 依赖材料后验可信集与摩擦律的可校准性——一旦后验过度自信或摩擦随湿度/磨损漂移，鲁棒抓取集会错误扩张，产生“证书通过却真实打滑”，故必须以 **在线触觉摩擦辨识 + 保守可信集膨胀 + 打滑绊线** 三重护栏，宁可少抓，也不把材料后验的均值当成接触物理的真值。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-MaterialGrasp（MGP×MAQ×MSC×MGC×OMI）

> 承接第 54 轮产物 v31。本轮在动作-鲁棒性双证书之上，增加 **材料条件化抓取位姿估计** 与 **抓取位姿约束下的材料选型** 两个算子族：
> - **MGP（Material-Grasp Posterior）**：把材料作为隐变量，估计 `p(g,m_o|O)` 并输出可信材料集 `C_ε`；
> - **MAQ（Material-Aware Quality）**：接触对上的抓取质量场 `Q(g;m_o,m_f)` 与最坏情况鲁棒质量 `Q_ε`；
> - **MSC（Material Selection under Coverage）**：预算约束下对抓取位姿分布的材料覆盖最大化（单调子模）；
> - **MGC（Material-Grasp Certificate）**：材料-抓取联合证书 `MG`，把材料歧义与摩擦漂移预算化；
> - **OMI（Online Material Identification）**：触觉/打滑驱动的在线材料后验与摩擦漂移更新。
>
> IP 编号：IP-121~IP-125（共 5 个新增）；升级 IP-115/118/120，使动作剖面、动作-鲁棒性联合证书、迁移证书纳入材料维度。

```python
        q = min(q, sigmoid((margin - gamma) / tau))
    return q

def robust_grasp_set(poses, m_f, C_eps, q_min, contact_model, gamma):
    return {g for g in poses
            if robust_grasp_quality(g, m_f, C_eps, contact_model, gamma) >= q_min}
```

### IP-123 MSC

```python
def select_materials(D, M_f, B, cost, C_eps_fn, q_min, contact_model):
    S, spend = set(), 0.0
    while True:
        best, best_gain = None, 0.0
        for mf in M_f - S:
            if spend + cost(mf) > B:
                continue
            gain = 0.0
            for x in D:
                C_eps = C_eps_fn(x.O)
                base = max([robust_q(x, m, C_eps) for m in S], default=0.0)
                gain += max(base, robust_q(x, mf, C_eps)) - base
            gain /= len(D)
            if gain > best_gain:
                best, best_gain = mf, gain
        if best is None or best_gain <= 1e-6:
            break
        S.add(best); spend += cost(best)
    return S
```

```python
def material_grasp_certificate(g, m_f, O, post, budgets):
    C_eps = credible_set(post, eps=budgets.eps)
    q_min = robust_grasp_quality(g, m_f, C_eps, contact_model, gamma=budgets.gamma)
    if q_min < budgets.q_min:
        return ('reject', 'material_robustness', q_min)
    dp = pose_uncertainty(g, O)
    if dp > budgets.Theta_p:
        return ('reject', 'pose_uncertainty', dp)
    if diam(C_eps) > budgets.Delta_m:
        return ('reject', 'material_ambiguity', diam(C_eps))
    if online_friction_drift() > budgets.Delta_f:
        return ('reject', 'friction_drift')
    return ('ok', MG(g, m_f, C_eps, q_min, dp, diam(C_eps),
                     online_friction_drift(), evidence=(O, post, sim_trials(g))))
```

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MGP | O(|𝔐_o|·|G|·C_sensor) | O(|𝔐_o|·|G|) | 后验校准、可信集覆盖 ≥ 1-ε |
| MAQ | O(|C_ε|·n_mc) | O(n_mc) | 摩擦下界保守、wrench margin sound |
| MSC | O(|𝔐_f|²·|𝒟|·|C_ε|·n_mc) | O(|𝒟|) | 单调子模、背包近似 `1-1/e` |
| MGC | O(|C_ε|·n_mc + |G|) | O(|C_ε|) | 预算闭合、证书 sound |
| OMI | O(|𝔐_o|·|W|) | O(|𝔐_o|) | 似然校准、漂移可检测 |

**正确性定理（Material-Conditioned Grasp Soundness）**
承接第 54 轮 (A26)–(A28)；新增：**(A29)** `P(m_o ∈ C_ε) ≥ 1-ε`；**(A30)** 仿真接触律在 `C_ε` 上质量模型误差 `≤ β_m`；**(A31)** `Q` 对位姿误差 `L_g`-Lipschitz。
则通过 `MG` 的抓取满足：
```
P(success | deploy) ≥ q_min - β_m - L_g·δ_pose - ε
```
材料选型满足：
```
F(S_greedy) ≥ (1 - 1/e) · F(S*)   （预算近似意义下）
```
关键：**以最坏情况材料质量决定部署，而非平均质量**；材料歧义被显式转化为 `diam(C_ε)` 预算。

## 6. 本轮最大风险

**一句话**：材料-抓取联合建模把“位姿估计”升级为“接触对上的最坏情况判定”，但其 soundness 依赖材料后验可信集与摩擦律的可校准性——一旦后验过度自信或摩擦随湿度/磨损漂移，鲁棒抓取集会错误扩张，产生“证书通过却真实打滑”，故必须以 **在线触觉摩擦辨识 + 保守可信集膨胀 + 打滑绊线** 三重护栏，宁可少抓，也不把材料后验的均值当成接触物理的真值。
