# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC / IP-153~160；灵感循环第 1 轮；本轮灵感：「模型蒸馏」×「视觉问答」）

> 第 60 轮的 SGEC 已经把「场景→意图→约束→阻抗→执行→证据→场景更新」的认知闭环搭起来：SSM、CIEC、EPIR、SERC、PCE++++。但它默认了三个从未被审视的前提：
> 1. **场景语义是闭集标签**：SSM 的 Z_scene 是一张固定场景表（桌面、楼梯、湿滑……），而真实人机交互中的语义问题往往是**开放、任务相关、问题条件化**的——「这个杯子能抓吗？」「桌面是湿的吗？」「前面是楼梯还是斜坡？」固定标签集既表达不了这些问题，也无法把「问什么」变成感知策略。
> 2. **语义推理可以实时、边缘、零成本**：真正具备开放语义能力的是云端大视觉语言模型（VLM），而执行回路需要在几十毫秒内拿到场景先验。直接调用大模型会击穿第 59 轮的 B_exec 实时预算；常规模型蒸馏又只对齐答案准确率，**不保安全相关的风险序、弃权与校准**。
> 3. **语言语义与执行证据天然一致**：VQA 说「光滑桌面」，力觉却感到周期性抖动；若直接信任语言先验，就会把第 60 轮警告的「证据层高度确定、执行层灾难性失效」的抽象泄漏放大。语言先验必须有接地仲裁，且**永远不能扩张执行安全集**。
>
> 本轮用「视觉问答」把场景语义改造成**问题条件化的按需投影**，用「模型蒸馏」把大 VQA 教师的**风险序、弃权与校准**编译到边缘学生，再用**保形弃权**把「语义不确定」变成可执行的硬安全界。

## 0. 直觉与动机

**灵感 1（视觉问答 → 问题条件化场景先验 QV-SSM）**
直觉：VQA 的答案不是一个孤立标签，而是对场景隐变量的一次**有损投影**。问「桌面湿吗」投影出摩擦系数，问「杯子能抓吗」投影出可抓性，问「前面是楼梯吗」投影出地形类别。同一个场景，不同问题给出不同侧面的证据。数学上，把 SSM 的固定后验 P(z|O) 推广为 P(z|I,q)：答案 a 经由**语义接地核** g_q(a) 映射到场景空间，再由场景-阻抗先验得到 π_scene(K|I,q)。关键洞见：**问题本身就是一种传感器动作**；问什么，决定了场景先验在哪个方向上被收窄。

**灵感 2（模型蒸馏 → 风险敏感蒸馏 SAD）**
直觉：云端大 VQA 教师答得准，但边缘执行等不起。常规知识蒸馏（KD）只对齐答案分布 p_T 与 p_S，会丢掉三样安全关键的东西：(i) 教师对「假安全」的敏感；(ii) 教师「不知道」时的弃权；(iii) 教师的置信校准。把蒸馏目标从 KL 改成**教师信念下的期望执行危害**：学生随机动作 b 在教师认为的真实答案 a 下的代价，用非对称危害矩阵 H(a,b) 加权。关键洞见：**蒸馏应当保风险序，而不是保平均准确率**；一个在「湿滑 vs 光滑」上更保守、总体准确率低 2% 的学生，可能比一个总体准确率高 2% 但在假安全上更激进的学生安全得多。

**灵感 3（校准 → 保形可靠性蒸馏 CRD）**
直觉：只给学生一个 argmax 答案，等于把「不知道」伪装成「知道」。让学生输出**保形预测集合** C_α(I,q)：只有集合是单例、且该答案是安全答案时才允许执行；否则回退教师、人类或保守先验。关键洞见：**弃权不是失败，而是安全动作**；在可交换假设下，这套规则给出 P(危险执行) ≤ α 的硬界，而且这个界与学生的准确率无关——准确率只决定「能安全行动的比例」。

**灵感 4（接地 → 答案-证据融合 AGF）**
直觉：VQA 说「光滑」，力觉却感到周期性抖动；语言先验与执行证据冲突时，不能「少数服从多数」，而要让**执行证据拥有否决权**。三源（VQA 语义 q_s、SSM 力位 q_k、EV-exec q_e）做对数线性融合；冲突超阈值就冻结语言先验、触发复问。关键洞见：**语义先验只能收窄候选集，不能扩张安全集**——这是第 60 轮「认知先行从不超过执行安全」的正式化。

**灵感 5（主动 VQA → AVQA）**
直觉：不确定时，与其猜，不如问一个**最有信息量**的问题。用期望信息增益减去延迟/教师/人类成本，得到问题的 VOI；在 B_semantic 预算内选 q*。关键洞见：**提问是有成本的感知动作**，问题选择应进入与探测、执行同一套 VOI 框架，而不是由人随意触发。

**灵感 6（合流 → SDGL + PCE+++++ + RPDC）**
直觉：QV-SSM 给先验，SAD 给边缘学生，CRD 给安全弃权，AGF 给接地仲裁，AVQA 给主动提问；五者合成**语义蒸馏接地闭环 SDGL**：问→答→先验→阻抗→执行→证据→再问/复校准。PCE+++++ 把语义、延迟、蒸馏新鲜度纳入预算；RPDC 给出一份**风险保持蒸馏证书**，把「学生可不可信」从一次性训练结论变成可持续监控的运行时不变量。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（问题条件化场景先验 QV-SSM）** 语义先验模型 Γ_q = (Q, A_q, g_q, π_scene)。其中：
- **问题本体** Q：开放词汇问题经本体投影到有限属性（材质、湿度、可抓性、地形、障碍软硬……）。
- **答案空间** A_q：问题 q 的候选答案集；开放问题用「是/否/不确定 + 属性值」规范化。
- **语义接地核** g_q: A_q → Δ(Z_scene)，把答案映射为场景后验；由本体规则与少量标定学习共同给出。
- **场景后验**：P(z | I, q, H) ∝ P(z | H) · Σ_{a∈A_q} g_q(a)(z) · p_S(a | I, q)，其中 H 为历史证据。
- **阻抗先验**：π_scene(K | I,q) = Σ_z P(z|I,q) · N(K; μ_z, Σ_z)。
- **问题充分性**：q 是 (ε,δ)-充分的，若 π_scene 的 1−δ 可信椭球直径 ≤ ε；否则需要继续提问或回退。
- **退化关系**：q=∅ 时 QV-SSM 退化为第 60 轮 SSM；固定标签分类是「只允许一个 q」的特例。

**定义 162（风险敏感蒸馏 SAD）** 非对称危害矩阵 H ∈ R^{|A|×|A|}_{≥0}，H(a,b) 表示「真实答案 a、执行答案 b」的代价；假安全项 H(a, safe)（a≠safe）取最大。风险敏感蒸馏损失：
```
L_SAD(θ_S) = E_{(I,q)∼D} [ Σ_a p_T(a|I,q) · Σ_b H(a,b) · p_S(b|I,q) ]
           + λ_r · L_rationale + λ_c · L_calib + λ_abs · L_abstain
```
- **rationale 蒸馏**：L_rationale = D(Attn_S(I,q) ‖ Attn_T(I,q))，把「证据在图像哪一块」也蒸馏下来，便于审计与 OOD 检测。
- **校准蒸馏**：L_calib = (τ_S^{-1} − τ_T^{-1})² 或对 ECE 的可微代理；学生继承教师的温度。
- **弃权蒸馏**：L_abstain = BCE(α_S(I,q), α_T(I,q))，把教师「不知道」的行为蒸馏成学生的弃权头。
- **退化关系**：H 取 0-1 对称代价、p_T 视为 one-hot 标签时，L_SAD 退化为交叉熵；H 取对称均匀代价时退化为 KL 蒸馏。

**定义 163（保形可靠性蒸馏 CRD）** 分数 s(I,q,a) = 1 − p_S(a|I,q)（或 APS 分位数分数）。给定标定集 D_cal = {(I_i,q_i,a_i)}_{i=1}^n（与测试可交换），令
```
q̂_α = 第 ⌈(n+1)(1−α)⌉ 个经验分位数（s 升序），
C_α(I,q) = { a ∈ A_q : s(I,q,a) ≤ q̂_α }。
```
- **覆盖**：P(a_true ∈ C_α) ≥ 1−α（有限样本、分布无关）。
- **安全执行规则**：act iff C_α = {â} 且 â ∈ A_safe；否则弃权并回退。
- **危险动作界**：P(act ∧ a_true ≠ â) ≤ α。
- **自适应版本 ACI**：α_{t+1} = α_t + γ(α − 1{a_true ∉ C_{α_t}})，用于非可交换流；长期平均覆盖 ≥ 1−α−o(1)。
- **语义不确定度**：u = |C_α| / |A_q|，作为 SSM/SERC 的回退触发器。

**定义 164（答案-证据接地融合 AGF）** 三源后验 q_s（VQA）、q_k（SSM 力位）、q_e（EV-exec），可靠性权重 λ_i ≥ 0：
```
log q(z) = λ_s log q_s(z) + λ_k log q_k(z) + λ_e log q_e(z) + const
λ_i = 1/(1+ECE_i) · exp(−Δt_i/τ_age) · 1{i 可用}
```
- **冲突度**：D_conf = JS(q_s ‖ q_k)（或 max_z |log q_s(z)/q_k(z)|）。
- **仲裁**：若 D_conf > τ_conf，或 q_s 与 q_e 的安全方向矛盾，则 λ_s ← 0、触发复问；执行证据有**否决权**：K_safe ← K_safe ∩ K_conservative。
- **SIC++ 四元组**：SIC++ = (scene_conf, K_certainty, execution_feasibility, answer_calibration)。

**定义 165（主动 VQA，AVQA）** 候选问题集 Q_cand，当前场景熵 H(z|H)：
```
IG(q) = H(z|H) − E_{a∼p_S(·|I,q)} H(z | H, a)
VOI(q) = IG(q) − λ_lat·latency(q) − λ_T·1[需教师] − λ_H·1[需人类]
q* = argmax_{q∈Q_cand} VOI(q),  s.t. 累计成本 ≤ B_semantic
```
停止条件：max_q VOI(q) ≤ 0，或 q 已 (ε,δ)-充分。关键：问题选择与第 60 轮 PCE 的探测/执行共享同一套 VOI 语义。

**定义 166（语义蒸馏接地闭环 SDGL）** 算子 SDGL(M, I_t, utterance, δ_f_req)：
```
① Dialogue parse: (I_intent, q) ← parse(utterance)          # 同一句话可同时含意图与问题
② Active query:   if q=∅ and U(z)>τ_u: q ← AVQA.select(...)
③ Distilled VQA:  p_S(a|I,q) ← S(I,q);  C_α ← CRD.set(p_S)
④ Safe gate:      if C_α={â} and â∈A_safe: use p_S
                   elif B_vqa.teacher_ok: p_T ← T(I,q); use p_T (并回填标定)
                   else: q_s ← None（回退）
⑤ Scene prior:    q_s ← QV-SSM.scene_posterior(I,q,H)（若④可用）
⑥ Grounding:      q_fused, D_conf ← AGF(q_s, q_k, q_e)
⑦ Constraint:     if I_intent: CIEC.receive_intent(I_intent)
⑧ Compile:        K_safe^scene ← EEIS.compile_with_scene_prior(q_fused, δ_f_req)
⑨ Execute:        (M, EV-exec, Cert) ← closed_loop_exec_probe(...)
⑩ Evidence:       EPIR.append(EV-exec); SIC++.update(q_fused, D_conf, p_S)
⑪ Budget:         PCE+++++.spend(...); if 违约: CRD.recalibrate / fallback
⑫ Return:         (q_fused, K_safe^scene, EV-exec, Cert, D_conf, C_α)
```

**定义 167（PCE+++++ 语义-延迟-蒸馏预算）** B_sem = (B_vqa, B_distill, B_question, B_exec)：
- **B_vqa** = (Student_latency_slack, Teacher_query_budget, Conformal_set_size_limit)
- **B_distill** = (Freshness, Drift_threshold, Recalibration_budget, Rationale_cache)
- **B_question** = (Human_attention_budget, Questions_per_episode)
- **B_exec** = 第 59 轮原有四预算（WCET / Bus / Thermal / Prio）
```
voi_sem(π) = VOI_meta_pessimistic(π) − cost_vqa(π) − cost_distill(π) − cost_question(π) − cost_exec(π)
```
耗尽策略：B_vqa 耗尽⇒只用学生 + 保形弃权；B_distill 过期⇒放大 α（更保守）；B_question 耗尽⇒停止提问、用最后后验；B_exec 耗尽⇒第 59 轮原有降级。任一预算耗尽都必须**收缩安全集**，不能扩张。

**定义 168（风险保持蒸馏证书 RPDC）** 证书
```
Cert_vqa = (α, n_cal, ĉov, LCB(ĉov), ECE, drift_stat, expiry,
            teacher_version, student_hash, scene_scope)
```
- **签发条件**：LCB(ĉov) ≥ 1−α−ε_cov，ECE ≤ τ_ece，drift_stat ≤ τ_drift，freshness ≤ τ_age。
- **运行时监控**：滑窗覆盖、ECE、输入/答案分布漂移；一旦违约，**吊销**证书并回退到教师/人类/保守先验。
- **与 J_exec 的关系**：J_exec 保证「执行合规」，RPDC 保证「语义先验合规」；两者共同构成「认知—执行」双证书。

## 2. 主线算法（SDGL 的骨架）

```python
def semantic_distillation_grounding_loop(M, image, utterance, delta_f_req):
    intent, q = parse_dialogue(utterance)

    if q is None and M.sic_pp.uncertainty() > TAU_U:
        q = M.avqa.select(M.student, image, M.sic_pp.scene_entropy(),
                          M.candidates(), M.budget)
    q_s = None
    pS = None
    if q is not None:
        pS = M.student.predict(image, q)              # [A_q]
        C = M.crd.predict_set(pS)
        if M.crd.safe_action(pS) is not None:         # 单例且安全
            q_s = M.qv_ssm.scene_posterior(pS, q, M.prior_z)
        elif M.budget.teacher_ok():
            pT = M.teacher.predict(image, q)
            q_s = M.qv_ssm.scene_posterior(pT, q, M.prior_z)
            M.crd.calibrate_from_teacher(pT, q)        # 只用于回填，不伪造真值覆盖
            M.budget.spend_teacher()
        # else: 回退，不产生 q_s

    q_k = M.ssm.scene_posterior(M.telem_force, M.telem_pos)
    q_e = M.exec_likelihood(M.ev_exec_prev)
    q_fused, d_conf = answer_grounded_fusion(q_s, q_k, q_e, M.weights,
                                             M.tau_conf, M.safety_kernel)
    if intent:
        M.ciec.receive_intent(intent)

    K_scene = M.eeis.compile_with_scene_prior(q_fused, delta_f_req)
    M, ev, cert = closed_loop_exec_probe(M, M.current_cp, delta_f_req, M.budget)
    M.epir.append(ev)
    M.sic_pp.update(q_fused, d_conf, pS)
    M.budget.tick(M.sic_pp, M.crd)
    return M, q_fused, K_scene, ev, cert, d_conf
```

## 3. 关键推导

### 3.1 为什么风险敏感蒸馏是「对的」目标
令 R(p) = min_b Σ_a p(a) H(a,b) 为在信念 p 下的贝叶斯执行风险。对任意学生随机策略 p_S，有
```
L_SAD ≥ E_{a∼p_T}[ H(a, b*) ] = R(p_T),  b* 为教师信念下的贝叶斯动作；
```
当 p_S 退化为 b* 处的 delta 时取等。因此最小化 L_SAD 是在把学生推向「教师认为最优的代价敏感动作」。另一方面，对任意两个信念 p_T、p_S，
```
|R(p_T) − R(p_S)| ≤ H_max · ‖p_T − p_S‖_1 ≤ H_max · sqrt(2 · KL(p_T‖p_S))   （Pinsker）
```
所以学生与教师的**风险差**被答案分布的 KL 控制；加权版只要 w_min ≥ 1 仍有 KL_w ≥ KL，优化 L_SAD 同时压这个上界。注意这个 Pinsker 界很松（第 6 节的数值校验里上界 7.02 而实际差 0.26），**不能把它当部署保证**；硬保证来自 3.2 的保形弃权。

### 3.2 保形单例规则的危险动作上界
**定理 1**（危险动作界）若标定集与测试样本可交换，C_α 按定义 163 构造，执行规则为「C_α 为单例且为安全答案才动作」，则
```
P(act ∧ a_true ≠ â) ≤ α。
```
**证明**：act ⇒ C_α = {â}。若 a_true ≠ â，则 a_true ∉ C_α。由覆盖定理 P(a_true ∉ C_α) ≤ α，故 P(act ∧ a_true ≠ â) ≤ P(a_true ∉ C_α) ≤ α。∎

这个界与学生的准确率、校准、教师质量**全部无关**；准确率只影响 P(act)（能安全行动的比例）与危险条件概率 P(a_true≠â | act) = P(act∧wrong)/P(act)。这解释了为什么「保形弃权」是安全底座，而「风险敏感蒸馏」是提高可用性的上层：SAD 降低假安全偏置，从而降低 P(wrong|act)，让同样的 α 下能多行动。

### 3.3 漂移下会发生什么
定理 1 的前提是**可交换**。真实部署中场景分布会漂移（新桌面、新光照、新物体），交换性失效，标准保形覆盖可以任意下降——**恰恰在最需要安全界的新场景里，证书会静默失效**。因此 RPDC 必须做两件事：(i) 用 ACI 在线更新 α_t，保证长期平均覆盖；(ii) 用漂移统计量触发「吊销 + 回退」，而不是继续相信一张过期的证书。

## 4. 与第 60 轮的接口

| 第 60 轮 | 第 61 轮增量 | 关系 |

## 5. 本轮最大风险

**一句话**：保形危险界依赖「标定与测试可交换」，而真实机器人在新场景上的分布漂移会让覆盖在最需要它的时刻静默失效；若再叠加教师 VQA 的自信幻觉与语言先验越过执行证据，就会出现「证书漂亮、执行灾难」——必须以 ACI 在线覆盖、漂移检测、执行证据否决与教师/人类回退四重机制，把证书从一次性结论变成运行时可持续监控的不变量。

### IP-161 QV-SSM（问题条件化场景先验）

```python
class QuestionConditionedScenePrior:
    def __init__(self, scene_bank, ontology, student, alpha=0.05):
        self.scenes = scene_bank          # [(mu_z, Sigma_z)]，来自第 60 轮 SSM
        self.ontology = ontology          # ground(q, a) -> P(z|a,q)
        self.student = student            # 边缘 VQA 学生
        self.alpha = alpha
        self.prior_z = np.ones(len(scene_bank)) / len(scene_bank)

    def answer_dist(self, image, question):
        p = self.student.predict(image, question)       # [A_q]
        return np.clip(p, 1e-9, 1.0) / np.sum(p)

    def scene_posterior(self, p_a, question, prior_z=None):
        prior_z = self.prior_z if prior_z is None else prior_z
        qz = np.zeros(len(self.scenes))
        for a, pa in enumerate(p_a):
            qz += pa * self.ontology.ground(question, a)  # [Z]
        qz = qz * prior_z
        return qz / np.sum(qz)

    def impedance_prior(self, qz):
        mu = np.array([s[0] for s in self.scenes])
        Sigma = np.array([s[1] for s in self.scenes])
        return GaussianMixture(mu, Sigma, weights=qz)
```

### IP-162 SAD（风险敏感蒸馏）

```python
def train_risk_sensitive_distillation(student, teacher, loader, H,
                                      lam_r=0.1, lam_c=0.1, lam_a=0.1):
    for image, question, _ in loader:
        pT = teacher.predict(image, question)            # [N, A]
        pS = student.predict(image, question)            # [N, A]
        # 教师信念下的期望执行危害；H[a,b] = 真实 a、执行 b 的代价
        L_risk = np.einsum('na,nb,ab->n', pT, pS, H).mean()
        L_rat = rationale_divergence(student.attn(image, question),
                                     teacher.attn(image, question))
        L_cal = (student.inv_temp - teacher.inv_temp) ** 2
        L_abs = binary_cross_entropy(student.abstain(image, question),
                                     teacher.abstain(image, question))
        loss = L_risk + lam_r * L_rat + lam_c * L_cal + lam_a * L_abs
        student.step(loss)
```

### IP-163 CRD（保形可靠性蒸馏）

```python
class ConformalReliabilityDistiller:
    def __init__(self, alpha=0.05, gamma=0.01):
        self.alpha = alpha
        self.alpha_t = alpha
        self.gamma = gamma
        self.scores = []

    def calibrate(self, p, a_true):
        self.scores.append(1.0 - p[a_true])

    def qhat(self):
        n = len(self.scores)
        k = min(int(np.ceil((n + 1) * (1.0 - self.alpha_t))), n)
        return np.sort(self.scores)[k - 1]

    def predict_set(self, p):
        q = self.qhat()
        return [a for a in range(len(p)) if 1.0 - p[a] <= q + 1e-12]

    def safe_action(self, p):
        C = self.predict_set(p)
        if len(C) == 1 and C[0] in SAFE_ANSWERS:
            return C[0]
        return None                      # 弃权：教师/人类/保守先验

    def aci_update(self, covered):
        err = 0.0 if covered else 1.0
        self.alpha_t += self.gamma * (self.alpha - err)
        self.alpha_t = float(np.clip(self.alpha_t, 1e-3, 0.5))
```

### IP-164 AGF（答案-证据接地融合）

```python
def answer_grounded_fusion(q_s, q_k, q_e, weights, tau_conf, safety_kernel):
    w = np.array(weights, dtype=float)
    q_s = np.zeros_like(q_k) if q_s is None else q_s
    logq = (w[0] * np.log(q_s + 1e-9)
            + w[1] * np.log(q_k + 1e-9)
            + w[2] * np.log(q_e + 1e-9))
    q = softmax(logq)
    d_conf = js_divergence(q_s, q_k)
    fallback = False
    if d_conf > tau_conf:
        w[0] = 0.0                   # 冻结语言先验
        fallback = True
    if safety_kernel.veto(q_e, q_s):  # 执行证据否决语言先验
        q = q * safety_kernel.mask(q_e)
        q = q / q.sum()
    return q, d_conf, fallback
```

### IP-165 AVQA（主动问题选择）

```python
def select_question(student, image, H_z, candidates, budget):
    best, best_voi = None, -np.inf
    for q in candidates:
        p = student.predict(image, q)
        ig = H_z - expected_cond_entropy(p, q)       # 期望信息增益
        voi = ig - question_cost(q)                 # 减去延迟/教师/人类成本
        if voi > best_voi and budget.can_afford(q):
            best, best_voi = q, voi
    if best_voi <= 0 or budget.exhausted():
        return None
    return best
```

### IP-166 SDGL（语义蒸馏接地闭环）

```python
def semantic_distillation_grounding_loop(M, image, utterance, delta_f_req):
    intent, q = parse_dialogue(utterance)
    if q is None and M.sic_pp.uncertainty() > TAU_U:
        q = M.avqa.select(M.student, image, M.sic_pp.scene_entropy(),
                          M.candidates(), M.budget)

    q_s, pS = None, None
    if q is not None:
        pS = M.student.predict(image, q)
        C = M.crd.predict_set(pS)
        if M.crd.safe_action(pS) is not None:
            q_s = M.qv_ssm.scene_posterior(pS, q, M.prior_z)
        elif M.budget.teacher_ok():
            pT = M.teacher.predict(image, q)
            q_s = M.qv_ssm.scene_posterior(pT, q, M.prior_z)
            M.crd.calibrate_from_teacher(pT, q)
            M.budget.spend_teacher()

    q_k = M.ssm.scene_posterior(M.telem_force, M.telem_pos)
    q_e = M.exec_likelihood(M.ev_exec_prev)
    q_fused, d_conf = answer_grounded_fusion(q_s, q_k, q_e, M.weights,
                                             M.tau_conf, M.safety_kernel)
    if intent:
        M.ciec.receive_intent(intent)

    K_scene = M.eeis.compile_with_scene_prior(q_fused, delta_f_req)
    M, ev, cert = closed_loop_exec_probe(M, M.current_cp, delta_f_req, M.budget)
    M.epir.append(ev)
    M.sic_pp.update(q_fused, d_conf, pS)
    M.budget.tick(M.sic_pp, M.crd)
    return M, q_fused, K_scene, ev, cert, d_conf
```

### IP-167 PCE+++++（语义预算）

```python
class SemanticBudget:
    def __init__(self, student_ms=50, teacher_calls=20, questions=10,
                 distill_age=50, exec_budget=None):
        self.B_vqa = dict(student_ms=student_ms, teacher_calls=teacher_calls)
        self.B_distill = dict(freshness=0, max_age=distill_age)
        self.B_question = dict(questions_left=questions)
        self.B_exec = exec_budget or ExecBudget()

    def teacher_ok(self):
        return self.B_vqa['teacher_calls'] > 0 and not self.exec_exhausted()

    def can_afford(self, question):
        return self.B_question['questions_left'] > 0

    def tick(self, sic_pp, crd):
        self.B_distill['freshness'] += 1
        if self.B_distill['freshness'] > self.B_distill['max_age']:
            crd.alpha_t = min(0.5, crd.alpha_t + 0.05)   # 过期→更保守
            self.B_distill['freshness'] = 0
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| QV-SSM | O(|A_q|·|Z|) / 问 | O(|Z|²) | 后验归一；q=∅ 退化为 SSM |
| SAD | O(B·|A|²) / batch | O(|A|²) | L_SAD ≥ R(p_T)；风险差 ≤ H_max·sqrt(2KL) |
| CRD | O(n log n) 标定 / O(|A|) 推理 | O(n_cal) | 覆盖 ≥ 1−α；危险动作 ≤ α |
| AGF | O(|Z|) | O(|Z|) | 执行证据否决⇒安全集只缩不扩 |
| AVQA | O(|Q|·|A|·|Z|) | O(|Q|) | 仅选 VOI>0；预算内提问 |
| SDGL | 由 VQA 前向 + EEIS 主导 | 复用 | 组合安全（见定理） |

**正确性定理（SDGL）** 假设：
- **A66（可交换/漂移）** 标定与测试在场景内可交换；漂移时启用 ACI，长期平均覆盖 ≥ 1−α−o(1)。
- **A67（答案对齐）** 教师与学生共享答案空间 A_q 与接地核 g_q。
- **A68（接地权重）** AGF 权重非负；执行证据否决算子是收缩算子（输出安全集 ⊆ 输入安全集）。
- **A69（预算单调）** B_vqa/B_distill/B_question/B_exec 单调消耗，耗尽触发收缩策略。
- **A70（危害有界）** 0 ≤ H(a,b) ≤ H_max。

则：
1. **危险动作界**：P(act ∧ a_true ≠ â) ≤ α；ACI 下长期平均 ≤ α+o(1)。
2. **蒸馏风险**：L_SAD ≥ R(p_T)；且 |R(p_T)−R(p_S)| ≤ H_max·sqrt(2·KL(p_T‖p_S))。
3. **接地安全**：执行证据否决后 K_safe ⊆ K_safe^prior ∩ K_conservative，安全集不扩张。
4. **预算安全**：任一 B_sem 维度耗尽，必触发对应收缩/回退，不产生新的安全集扩张。
5. **证书有效**：Cert_vqa 未过期且 LCB(ĉov) ≥ 1−α−ε_cov 时，覆盖界成立；违约即吊销。

## 5. 数值校验（合成数据，非真机）

**目的**：只验证定理 1（保形危险界）与「假安全偏置驱动条件危险」的机制，不代表真机性能。

**设置**：4 个答案 {safe=0, slippery=1, fragile=2, unknown=3}；教师/学生由同一隐场景生成，学生额外带「乐观偏置」（更倾向答 safe）；危害矩阵 H：假安全 10、假警报 1、其他 3；分数 s=1−p_S；标定 3000 条、测试 8000 条、30~40 次重复；α 取 0.05/0.10；对照组为「学生 argmax 直接执行」。

**表 1（乐观学生，bias=0.9）**

| α | 实际覆盖 | 危险动作率（保形，无条件） | 行动率 P(act) | P(危险 \| act) | argmax 危险率 |
|---|---|---|---|---|---|
| 0.05 | 0.9508 | 0.0317 | 0.268 | 0.1181 | 0.1071 |
| 0.10 | 0.9023 | 0.0653 | 0.310 | 0.2108 | 0.1071 |

**表 2（α=0.05，假安全偏置消融）**

| 学生乐观偏置 | 实际覆盖 | 危险动作率（保形） | 行动率 | P(危险 \| act) | argmax 危险率 |
|---|---|---|---|---|---|
| 0.00 | 0.9511 | 0.0097 | 0.226 | 0.0430 | 0.0181 |
| 0.45 | 0.9504 | 0.0231 | 0.254 | 0.0909 | 0.0480 |
| 0.90 | 0.9508 | 0.0317 | 0.268 | 0.1181 | 0.1071 |

**读法**：
1. 保形危险动作率在所有偏置下都 ≤ α（0.0317、0.0653 均低于 0.05、0.10），**定理 1 成立**；argmax 直接执行的危险率高达 0.107，是 α=0.05 时的 3.4 倍。
2. 覆盖稳定在 1−α 附近（0.9508 / 0.9023），说明有限样本分位数实现正确。
3. 假安全偏置从 0 增到 0.9，保形危险率仅从 0.0097 增到 0.0317，但 **P(危险|act) 从 0.043 增到 0.118**——偏置主要侵蚀「行动时的条件安全」，这正是 SAD 要优化的对象：不是把 argmax 改保守，而是把学生的假安全分布改准。
4. **风险差上界校验**：R(p_T)=0.1294、R(p_S)=0.3925，实际差 0.2631；KL=0.2465、L1=0.5154、H_max·sqrt(2KL)=7.0220。上界成立但很松（27 倍余量），印证「Pinsker 界不能当部署保证，硬保证必须来自保形弃权」。
5. **代价敏感决策对照**：用 H 直接做贝叶斯决策可把危险率压到 0，但 safe 选择率仅 6.5%（R=0.390），几乎不行动；说明单纯保守化牺牲可用性，需要 SAD 改善学生分布 + CRD 的 α 调节来恢复行动率。

## 6. 本轮最大风险

**一句话**：保形危险界依赖「标定与测试可交换」，而真实机器人在新场景上的分布漂移会让覆盖在最需要它的时刻静默失效；若再叠加教师 VQA 的自信幻觉与语言先验越过执行证据，就会出现「证书漂亮、执行灾难」——必须以 ACI 在线覆盖、漂移检测、执行证据否决与教师/人类回退四重机制，把证书从一次性结论变成运行时可持续监控的不变量。
