# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「数字孪生」×「Gazebo」）

> 第 57 轮把承诺的判定权下沉到"元推断 + 跨模态对账 + 信任状态机"，但它始终在一个稀缺资源上做文章：**真实证据太贵**——每次探针、每次到访都要花时间、节拍与不可逆风险，于是只好用先验摊销与共形保底把 1~5 个样本"榨干"。数字孪生与 Gazebo 提供的诱惑正是这种稀缺性的反面：在虚拟世界里，探针几乎免费、可以跑一万次、可以重来到满意为止。于是本轮面对的不再是"证据不够"，而是"证据太多且太便宜"。这带来一个与第 57 轮相反的风险结构：第 57 轮怕**坏先验普遍**，本轮怕**廉价证据通胀**——一个自洽、连续、可无限复现的仿真会把"我们模型里有的世界"演得无比真实，却系统性地对"模型里没有的物理"保持沉默。更危险的是，孪生若用部署遥测在线校准，又用同一批遥测为承诺背书，就会形成一个**自我确认的回音室**：越仿真越自信，越自信越敢砍掉真实探针，而真实世界恰恰是唯一没被检查的地方。本轮的核心命题因此不是"用仿真替代现实"，而是 **"孪生可证伪、现实可锚定、仿真不可独断的证据说可信"**：让 Gazebo 负责**花钱搜索**（反事实证伪、危险假设生成、探针预算规划），让真实世界负责**签字承诺**（不可逆接触的最后证据）。一句话：**仿真能买搜索，不能买信任。**

核心矛盾：
- **H29（廉价 vs 真实）**：虚拟证据的边际成本趋零，但边际信息量随重复仿真迅速塌缩——同一物理引擎跑一万次只是把同一个建模误差问一万遍；sim-real 差距恰在稀有/未建模物理处最大，而效率增益又诱导我们正是在那里砍掉真实探针。
- **H30（确认 vs 证伪的不对称）**：孪生极擅长复现"我们已建模的世界"，对"未建模的世界"系统性失明。用它**确认**是危险的（sim 成功 ≠ 现实成功），用它**证伪**却相对可靠（sim 失败 ⇒ 存在一个可能失败的现实情形）——前提是能把"真实危险"与"求解器伪影/穿模/数值爆炸"区分开。
- **H31（同步 vs 污染）**：在线同步的孪生能保持新鲜，也会把同一批真实观测既用于校准孪生、又用于为承诺背书（双重计数），并把陈旧信念"洗"成看似独立的虚拟证据；昨天有效的孪生证书，今天可能因漂移而静默失效。

## 0. 直觉与动机

**灵感 1（数字孪生 → 有证书的预言机，而非免费神谕）**
直觉：把数字孪生当"免费神谕"是这一轮最容易犯的错。它更像一个**需要年检的预言机**：只有在声明的有效域内、在独立现实锚点上校准过、且当前未漂移时，它的预测才配叫"证据"，否则只能叫"假设"。因此本轮先给孪生发一张**有效性证书 TVC**：有效域（材质×坡度×接触类型×负载×光照）、sim-real 差距上界（用与承诺证据不相交的现实锚点做共形校准）、同步年龄与漂移监测。证书之内，孪生可作**预测性证据**（调整先验、压缩探针预算）；证书之外，它只配做**假设生成器**。预言机可以很忙，但它的签字权必须被限额。

**灵感 2（Gazebo → 反事实证伪与跨引擎对账）**
直觉：Gazebo 的真正价值不是"把已知世界再演一遍"，而是**批量制造反事实**：把摩擦、质量、质心、接触刚度、传感器噪声、光照、透明/反光塞进参数盒，主动搜索让当前计划失败的参数点。这里有一条漂亮的不对称：**找到一个可实现的失败参数点，是硬证据；找到一个成功的参数点，只是弱证据**。但 Gazebo 也会撒谎——穿模、求解器抖动、大时间步爆炸会制造"假失败"。于是配套**可实现性过滤**：同一反事实在细化时间步下复现、且在第二个物理引擎（ODE 与 DART/Bullet）下也复现，才算真实危险；两引擎分歧则进"仿真伪影登记处"，不浪费真实探针。跨引擎对账 XER 就是第 57 轮"跨模态对账"在仿真内部的类比：**分歧即不可信，一致才是反事实。**

**灵感 3（孪生 ↔ 现实 → 锚点账本与禁双重计数）**
直觉：孪生最隐蔽的作弊是**把同一份现实证据用两次**：先用它拟合/校准孪生，再让孪生"预测"同一现象，然后把预测当成独立确认。这在统计上就是自我引用。本轮引入**现实锚点预算 RAB**：真实观测分成"校准锚点"与"部署证据"两个互斥账本，每条证据带 provenance，跨账本复用必须按有效独立数 n_eff 打折；孪生用电越多，其虚拟证据的独立性越差，能抵扣的真实探针就越少。**没有免费的证据，只有预付的锚点。**

**灵感 4（在线同步 → 影子更新与漂移召回）**
直觉：第 57 轮已经确立"一切判定器（含元模型）走隔离"，孪生是又一个判定器，而且是一个会持续长大的判定器。于是孪生更新必须在**影子模式**下进行：新参数/新世界先在边端探针流上影子运行，通过校准回归（差距不劣化 ∧ 证伪检出率不降 ∧ 漂移告警不增）才接管；一旦在线漂移超阈，所有依赖该孪生的证书**即时挂起并召回**，退回第 57 轮的纯现实证据路径。孪生可以犯错，但不能**安静地**犯错。

**灵感 5（PCE-T → 先证伪、后承诺的探-诺-演）**
直觉：把第 57 轮 PCE+ 的检查点顺序重排成**"虚拟先证伪、现实后签字"**：每个检查点先在 Gazebo 里做反事实搜索（便宜），把找到的可实现反事实转成现实世界必须回答的探针或保守动作；只有在反事实被现实证据清除、且第 57 轮证据门通过后，才允许承诺。VOI 用孪生预测做**乐观先验**、用 TVC 差距带做**悲观修正**；孪生越不确定，VOI 越接近第 57 轮的纯现实版本。所有新机制仍只经"信念更准或动作更保守"两个安全通道起作用，是对第 56/57 轮交互单调性的第四次强化。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（数字孪生与有效性证书 TVC）** 孪生 T=(G_SDF, Θ_sim, Σ_sim, syn)，G_SDF 为 Gazebo 世界（SDFormat），Θ_sim 为物理/传感参数（引擎、步长、摩擦模型、噪声、光照），Σ_sim 为策略与执行器模型，syn=(t_last, A_cal, age, drift) 为同步状态。有效域 Z_val 为（材质×坡度×接触类型×负载×光照）的声明子集。按机制类 A 定义 sim-real 差距 Δ_A=d(p_real(·|A),p_sim(·|A))，用与部署证据不相交的锚点 A_cal 做分层加权共形校准，得差距上界 ε_twin(A) 与覆盖 ≥1−α_twin。**TVC 通过** ⇔ r∈Z_val ∧ sup_A Δ_A≤ε_twin(A) ∧ age≤τ_age ∧ drift≤θ_drift ∧ 锚点独立性成立。证书外的孪生输出一律降级为假设（见定义 143 的 EV-sim 分层）。

**定义 140（虚拟证伪搜索 VFS 与跨引擎对账 XER）** 参数空间 Θ=(μ_f,m,CoM,k_c,σ_sensor,光照/透明标志,…)，反事实 c=(θ_c,情形)，风险分 R(c)。搜索 c\*=argmax_{θ∈Θ_adm} R(c)，Θ_adm 为物理可达参数集。**可实现性过滤 RF(c)**：c 在细化步长 h/2 下复现 ∧（引擎 e1 与 e2 均复现 ∨ 单引擎但附接触力/能量守恒见证）∧ 参数点不越 Θ_adm ∧ 非穿模/非数值爆炸。RF 通过的反事实进危险登记处 H_sim，**只具否决权**（迫使现实探针或保守动作）；RF 不过的进仿真伪影登记处 H_bug，**不消耗现实探针**。**XER**：e1,e2 结论一致 ⇒ 反事实可信↑；分歧 ⇒ 判数值/求解器依赖，禁止作为证据。**单向性**：失败反事实可证危险（存在性），成功仿真不证安全（需 TVC）。

**定义 141（现实锚点预算与禁双重计数 RAB）** 真实观测账本分 A_cal（校准/验证孪生）与 E_dep（部署承诺证据），约束 A_cal∩E_dep=∅。每条证据 e 带 provenance DAG 与来源标签 src(e)∈{real,sim,hybrid}。有效独立数 n_eff(E)=独立失效模式组数，同源 sim 证据只计一组。**证据洗白指数** L(E)=corr(fit(A_cal),support(E_dep))≤λ_max，超限则逼真实探针注入或降低 EV-sim 抵扣额度。锚点预算 B_anchor(t) 有限：每消耗一个锚点即减少可抵扣的真实探针数，**虚拟证据的信用 = 锚点信用**。

**定义 142（孪生漂移与召回 TDR）** 漂移分 D_twin(t)=TV(p̂_sim(τ_{1:t}),τ_real(1:t))+‖ΔΘ_sim‖/Θ_scale+1[世界变化]。**影子更新**：候选孪生 T′ 先影子运行，须通过回归闸（ε_twin 不劣化 ∧ H_sim 检出率不降 ∧ 误报率不升 ∧ 漂移告警不增）才接管。D_twin>θ_drift 或回归闸失败 ⇒ 证书挂起，沿 provenance 反向召回所有依赖该项的承诺/证书（suspend→re-verify→restore/降级），召回时延 ≤ 一个同步窗口。**禁止静默漂移**：孪生可错，不可悄悄错。

**定义 143（孪生-现实证据门 SEG）** 证据类 = EV-real（继承第 57 轮 EV-probe\*/visit/margin/xmodal/human）+ **EV-sim**，其中 EV-sim 分三层：**EV-sim^F（证伪）**：RF 通过的反事实，始终可入安全门且**只能否决**；**EV-sim^P（预测）**：TVC 通过时可作先验，并把现实探针预算压到 η_sim 比例（η_sim 随 ε_twin 与 L 单调递减），但**不可替代不可逆接触的最后一次真实确认**；**EV-sim^C（佐证）**：仅在已有真实证据且 n_eff≥2 时可加入，不单独支撑承诺。不可逆接触必要证据集 = {EV-real 物理证据（EV-probe\*∨EV-margin∨EV-visit）} ∪ 佐证，**显式不含任何 EV-sim**。证书 J_twin=(J_p,TVC,H_sim,H_bug,anchor_ledger,provenance,drift_log,recall_state,gap_budget)。

**定义 144（探-诺-演·孪生 PCE-T）** 每检查点：①同步与漂移检查（TVC 是否有效）；②**虚拟先证伪**：在 Gazebo 参数盒内做 VFS，得可实现反事实集 H_sim(cp)；③若 H_sim≠∅ 且未被现实证据清除 ⇒ 强制现实探针/保守动作，**不得进入承诺**；④若无未决反事实，用 EV-sim^P 修正 VOI（乐观预测 + TVC 悲观带），在 η_sim 限额内削减现实探针；⑤按第 57 轮证据门签字承诺；⑥遥测回流→影子更新孪生→若漂移超阈则召回。终止于 {承诺,绕行,L2 协商,安全停}，且仿真实预算 k_sim 与现实预算 k_real 均有限。

## 2. 关键算法伪代码（完整版见产物区）

```python
def twin_valid(T, r, anchors):                      # IP-139 TVC
    if r not in T.Z_val or T.age > T.tau_age: return False
    if T.drift > T.theta_drift: return False
    return T.gap_bound(r) <= T.eps_twin(r) and disjoint(T.A_cal, anchors)

def virtual_falsify(T, cp, theta_adm):              # IP-140 VFS + XER
    C = search_counterfactuals(T.G, cp, theta_adm)  # Gazebo 参数盒搜索
    accepted, bugs = [], []
    for c in C:
        ok_e1 = replay(T, c, engine='ode',  h=T.h/2)
        ok_e2 = replay(T, c, engine='dart', h=T.h/2)
        if realizes(c, theta_adm) and ok_e1 and ok_e2 and not artifact(c):
            accepted.append(c)                      # 只否决、不批准
        else:
            bugs.append(c)                          # 仿真伪影，不进现实探针
    return accepted, bugs

def sim_evidence(T, r, real_ev, anchors):           # IP-143 SEG
    if not twin_valid(T, r, anchors):
        return SimEv('hypothesis_only')
    tier = 'P' if T.gap_bound(r) <= T.eps_twin(r) else 'C'
    return SimEv(tier, eta=T.eta_sim(tier, T.gap(r), washout(anchors, real_ev)))
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| TVC | O(N_cal·d) 校准；O(1)/查询 | O(\|A_cal\|) | 差距上界诚实、锚点不相交 |
| VFS | O(\|Θ\|·(T_sim/h)·E) 搜索 | O(\|H_sim\|) | RF 过滤、跨引擎一致 |
| RAB | O(\|E\|·log\|E\|) provenance | O(\|E\|) | 禁双重计数、n_eff 保守 |
| TDR | O(1)/同步窗 | O(\|cert\|) | 漂移召回完整、影子回归 |
| SEG | O(\|σ\|) | O(\|σ\|) | EV-sim 不入不可逆必要集 |
| PCE-T | O(\|CP\|·(k_sim+k_real)) | O(\|V\|+\|σ\|) | 先证伪后承诺、双预算终止 |

**正确性定理（Twin-Anchored One-sided Soundness, TAOS）**：在 A33–A40 上增 (A41) TVC 校准诚实、锚点与部署证据不相交、漂移可监测；(A42) RF 健全（被接受反事实的假阳性率 ≤β_rf）且 XER 分歧不作证据；(A43) RAB 无双重计数、n_eff 保守、L≤λ_max；(A44) EV-sim 单向使用、不可逆接触必要集不含 EV-sim、漂移即时召回。则：
(i) **证伪单向安全**：任意被接受、未被现实证据清除的反事实都阻断承诺，故孪生只能降低而非提高承诺失效率；EV-sim 不进入不可逆必要集，其建模误差最多损失效率，不直接进入 P_fail。
(ii) **抵扣有界**：用 EV-sim^P 削减现实探针时，额外失效率 ≤ η_sim·(ε_twin+δ_twin)，且 η_sim→0 当 ε_twin→大或 L→λ_max；与第 57 轮实证据项相加即得部署界。
(iii) **漂移可召回**：D_twin>θ_drift 时一个同步窗内撤销全部依赖证书，系统退回第 57 轮纯现实路径，安全界不劣化、只损失效率。
(iv) **终止性**：k_sim 与 k_real 均有限，检查点有限，PCE-T 终止于四态。

部署界：
```
P_safe ≥ 1 − Σ_cp [ 第57轮实证据项 + η_sim·(ε_twin+δ_twin) + β_rf·1[H_sim未决] ]
             − P(漂移未检出) − P(双重计数未检出) − P(召回失败)
```
关键：**仿真买搜索，现实买信任**（效率与安全分离）；**证伪可入、确认须证**（单向性把 sim-real gap 从安全论据里剥离）；**锚点有限、证据不可洗白**（防回音室）。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| sim-real gap 在未建模物理处最大 → 自信的虚拟证据 | 高 | TVC 有效域 + 共形差距上界 + 域外只作假设 |
| 仿真成功被误当安全证据 | 高 | 单向性：EV-sim 不入不可逆必要集；只否决不批准 |
| Gazebo 求解器伪影制造假危险/假安全 | 高 | RF 细化步长复现 + ODE/DART 跨引擎对账 + H_bug 登记 |
| 锚点双重计数 → 回音室 | 高 | RAB 互斥账本 + provenance + n_eff + L 指数 |
| 孪生在线漂移静默失效 | 中高 | 影子回归闸 + 漂移监测 + provenance 反向召回 |
| 反事实搜索成本过大 | 中 | 参数盒 BO/CMA-ES + 并行 Gazebo 世界 + k_sim 预算 |

## 6. 本轮最大风险

**一句话**：孪生可能变成一台"自洽的幻觉引擎"——它便宜、连续、可无限复现，于是制造出大量彼此一致却高度相关、且恰好对未建模物理失明的虚拟证据；若 TVC 用同一批遥测既校准又背书，系统会越仿真越自信、越敢砍真实探针，而真实世界是唯一没被检查的地方；必须以"仿真只否决不批准、锚点与部署证据互斥、漂移即时召回、EV-sim 永不进入不可逆必要集"四道闸门约束。

## 2. 关键算法伪代码

### IP-139 TVC（孪生有效性证书）

```python
def fit_twin_validity(T, anchors_cal, mech_classes, alpha_twin):
    T.eps_twin = {}
    for A in mech_classes:                          # 按机制类分层，勿混池
        res = [gap_residual(T, a) for a in anchors_cal if a.mech == A]
        T.eps_twin[A] = weighted_conformal(res, alpha=alpha_twin,
                                           sim=lambda a: csim(a, T.Z_val))
    T.coverage = empirical_coverage(T.eps_twin, anchors_cal)   # 须 ≥1−α_twin
    T.certificate = CertTwin(eps_twin=T.eps_twin, coverage=T.coverage,
                             Z_val=T.Z_val, age=0, drift=0)
    return T

def twin_valid(T, r, E_dep):
    if r not in T.Z_val:                       return Tier('hypothesis_only')
    if T.age > T.tau_age:                      return Tier('hypothesis_only')
    if T.drift > T.theta_drift:                return Tier('hypothesis_only')
    if not disjoint(T.A_cal, E_dep):           return Tier('C')   # 锚点污染
    if T.gap_bound(r) > T.eps_twin[r.mech]:    return Tier('C')
    return Tier('P')                            # 预测层
```

### IP-140 VFS + XER（虚拟证伪与跨引擎对账）

```python
def virtual_falsify(T, cp, theta_adm, budget):
    # Gazebo：SDFormat 世界 + 参数盒；批量并行世界，确定性种子
    C = bayes_opt(lambda th: risk(T.G, cp, th),
                  search_space=theta_adm, budget=budget.k_sim)
    accepted, bugs = [], []
    for c in C:
        if not in_adm(c.theta, theta_adm):                 continue
        e1 = replay(T, c, engine='ode',  h=T.h)            # 基线
        e1f = replay(T, c, engine='ode', h=T.h/2)          # 细化步长
        e2 = replay(T, c, engine='dart', h=T.h)            # 第二引擎
        reproduced = e1f.failed and (e2.failed or conserved(e1f, e2))
        if artifact(c, e1, e1f, e2):                       # 穿模/爆炸/抖动
            bugs.append(c); continue
        if reproduced:
            accepted.append(c)                             # 只否决、不批准
        else:
            bugs.append(c)                                 # 数值脆弱性
    return accepted, bugs

def cross_engine_verdict(c, e1, e2):
    if e1.verdict == e2.verdict:  return 'realizable' if e1.failed else 'weak'
    return 'solver_dependent'                              # 禁止作证据
```

### IP-141 RAB（现实锚点预算与禁双重计数）

```python
def admit_real_evidence(e, ledger, lambda_max):
    if e.id in ledger.A_cal and e.id in ledger.E_dep:
        return 'reject_double_count'
    ledger.E_dep.add(e.id) if e.src == 'real' else None
    if ledger.washout(lambda_max) > lambda_max:
        ledger.require_fresh_anchors(e.region)             # 逼真实探针
    return 'ok'

def eta_sim(tier, T, r, ledger):
    if tier != 'P':                    return 0.0
    return clamp(ETA_MAX * (1 - T.gap_bound(r)/T.eps_twin[r.mech])
                        * (1 - ledger.washout()/lambda_max), 0, ETA_MAX)
```

### IP-142 TDR（孪生漂移与召回）

```python
def twin_sync(T, telemetry, candidate):
    gate = (candidate.eps_twin <= T.eps_twin and
            candidate.recall_Hsim >= T.recall_Hsim and
            candidate.false_alarm <= T.false_alarm and
            candidate.drift_alarm <= T.drift_alarm)
    if not gate: 
        return T                                           # 影子期不接管
    T = candidate
    T.drift = tv_divergence(T.pred_telemetry, telemetry)
    if T.drift > T.theta_drift:
        for cert in provenance.reverse(T.certificate):
            cert.suspend(); schedule_reverify(cert)        # 一个同步窗内
        T.certificate = None
    return T
```

### IP-143 SEG（孪生-现实证据门 + 证书 J_twin）

```python
def sim_real_gate(c, T, E_dep, ledger, ood_reg):
    if c.ev.startswith('EV-sim'):
        if c.ev == 'EV-sim^F':
            ok = c.in_Hsim and c.rf_pass and c.unresolved
            return ('veto' if ok else 'ignore', c)         # 只能否决
        if c.ev == 'EV-sim^P':
            return ('ok' if twin_valid(T, c.region, E_dep) == 'P'
                    and c.irreversible is False else 'reject', c)
        if c.ev == 'EV-sim^C':
            return ('ok' if c.has_real and n_eff(c.groups) >= 2 else 'reject', c)
    return round57_few_shot_evidence_gate(c, T.M, T.persona, ood_reg)

def twin_certificate(sched, T, ledger, ood_reg):
    for c in contacts(sched):
        st = sim_real_gate(c, T, ledger.E_dep, ledger, ood_reg)
        if st[0] in ('reject', 'veto'):
            return st                                       # 未决反事实即阻断
        if c.irreversible and c.ev.startswith('EV-sim'):
            return ('reject', 'sim_on_irreversible', c)     # 硬禁令
    if ledger.washout() > lambda_max:  return ('reject', 'washout')
    if not T.certificate or T.drift > T.theta_drift:
        return ('reject', 'twin_invalid')
    return ('ok', Jtwin(T.certificate, H_sim, H_bug, ledger,
                        provenance, drift_log, recall_state, gap_budget))
```

### IP-144 PCE-T（探-诺-演·孪生版）

```python
def probe_commit_evolve_twin(x0, T, task, budget, consent, personas):
    route = plan_on_map(T.M, task, risk_model)
    for cp in route.checkpoints:
        # ① 同步/漂移；② 虚拟先证伪（便宜，先花 sim 预算）
        twin_sync(T, telemetry, candidate=None)
        Hsim, Hbug = virtual_falsify(T, cp, T.theta_adm, budget)
        # ③ 未决可实现反事实 → 必须用现实证据清除，否则不承诺
        pending = [c for c in Hsim if not resolved_by_real(c, T.M)]
        if pending:
            if not real_probe(pending, budget, T.M):        # 现实探针清除
                alt = reroute(T.M, cp, risk_model)
                if not alt: return negotiate_or_stop(cp, T.M, consent)
                route = alt; continue
        # ④ 无未决反事实 → EV-sim^P 修正 VOI，限额削减现实探针
        inf = meta_few_shot_infer(T.M, cp.region, T.M.obs[cp.region], T.meta)
        eta = eta_sim('P', T, cp.region, T.ledger)
        sigma = foothold_schedule(x0, cp, T.M, probe_cap=(1-eta)*budget.k_real)
        R = schedule_risk(sigma, T.M)
        while select_gait(R) == 'halt' and budget.real_left > 0:
            p = argmax(admissible_probes(cp, T.M, F_abs),
                       key=lambda q: voi_twin_pessimistic(q, T.M, inf, T.gap_bound))
            if voi_twin_pessimistic(p, T.M, inf, T.gap_bound) < theta_voi: break
            T.M, _, _ = xmodal_fuse(T.M, cp.region, execute_probe(p, cap=F_abs))
            budget.spend_real(p)
            sigma = reselect_footholds(x0, cp, T.M); R = schedule_risk(sigma, T.M)
        # ⑤ 第 57 轮证据门签字
        if sim_real_gate(core_contact(cp), T, T.ledger.E_dep,
                         T.ledger, T.ood_reg)[0] == 'ok':
            commit(sigma, select_gait(R)); continue
        # ⑥ 失败→绕行/L2/安全停
        return negotiate_or_stop(cp, T.M, sigma, R, consent,
                                 tau_int=tau_int(personas.active.auth))
    return route, T
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TVC | O(N_cal·d) 校准；O(1)/查询 | O(\|A_cal\|) | 差距上界诚实、锚点不相交（A41） |
| VFS | O(BO_iter·(T_sim/h)·E_engines) | O(\|H_sim\|+\|H_bug\|) | RF 健全、XER 分歧不作证据（A42） |
| RAB | O(\|E\|·log\|E\|) provenance | O(\|E\|) | 禁双重计数、n_eff 保守（A43） |
| TDR | O(1)/同步窗 + O(\|cert\|) 召回 | O(\|cert\|) | 漂移即时召回、影子回归（A41/A44） |
| SEG | O(\|σ\|) | O(\|σ\|) | EV-sim 不入不可逆必要集（A44） |
| PCE-T | O(\|CP\|·(k_sim·T_sim/τ + k_real·(C_VOI+d_φ))) | O(\|V\|+\|σ\|) | 先证伪后承诺、双预算终止 |

**正确性定理（Twin-Anchored One-sided Soundness, TAOS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；并新增：**(A41)** TVC 有效：有效域内 sim-real 差距以共形上界 ε_twin 覆盖（≥1−α_twin），校准锚点 A_cal 与部署证据 E_dep 不相交，漂移分 D_twin 可在线监测且告警漏检 ≤δ_drift；**(A42)** 可实现性过滤健全：被接受反事实的假阳性（把伪影当真实危险）率 ≤β_rf，XER 分歧一律不作证据；**(A43)** 锚点账本无双重计数，provenance 无环，n_eff 保守，洗白指数 L≤λ_max；**(A44)** EV-sim 单向使用：只否决不批准，绝不进入不可逆接触必要证据集，漂移超阈即时召回。则：

1. **证伪单向安全**：若存在被接受且未被现实证据清除的反事实，PCE-T 阻断承诺；故引入孪生只能降低而非提高承诺失效率。由于 EV-sim 不进入不可逆必要集，孪生的建模误差最多损失效率，不直接进入 P_fail。
2. **抵扣有界**：用 EV-sim^P 把现实探针压缩到 (1−η_sim) 比例时，额外失效率界为 η_sim·(ε_twin+δ_twin)+β_rf·1[H_sim未决]；当 ε_twin 或 L 逼近上限时 η_sim→0，自动退回第 57 轮纯现实路径。
3. **漂移可召回**：D_twin>θ_drift 在一个同步窗内挂起并沿 provenance 反向召回所有依赖证书，系统安全界不劣化、只损失仿真带来的效率。
4. **终止性**：k_sim、k_real 均有限，检查点有限，PCE-T 终止于 {承诺,绕行,L2 协商,安全停}。

**部署界（对检查点取联合界）**：

```
P_safe ≥ 1 − Σ_cp [ δ_57(cp) + η_sim·(ε_twin+δ_twin) + β_rf·1[H_sim未决] ]
             − P(漂移未检出) − P(双重计数未检出) − P(召回失败)
其中 δ_57(cp) = δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
```

关键：**仿真买搜索，现实买信任**（效率与安全解耦，孪生的错不进入不可逆签字）；**证伪可入、确认须证**（把 sim-real gap 从"安全论据"里剥离，只保留其作为"危险假设源"的正面作用）；**锚点有限、证据不可洗白**（同一份现实证据不能既校准又背书，防回音室）。三个机制都只经"信念更准（含更悲观）"或"动作更保守"两个安全通道起作用。

## 4. 实验设计 E177–E181

| 实验 | 指标 | 目标 |
|---|---|---|
| E177 TVC 校准与失效域 | 差距上界经验覆盖率；有效域外误用率；锚点数-精度曲线；分层机制类覆盖 | 覆盖 ≥1−α_twin；域外误用 0；锚点 ↓≥30% |
| E178 Gazebo 反事实证伪 | 可实现反事实召回率/误报率；穿模/爆炸伪影过滤率；搜索成本 | 召回 ≥85%；误报 ≤5%；伪影拦截 ≥95%；k_sim 有界 |
| E179 跨引擎对账 XER | 单引擎假失败率 vs 双引擎一致失败率；求解器依赖率；ODE/DART 分歧率 | XER 后假失败 ↓≥70%；一致失败保持 ≥90% |
| E180 锚点账本与回音室 | 双重计数事件数；洗白指数 L；削减探针后的假承诺率；n_eff 估计偏差 | 双重计数 0；L≤λ_max；假承诺不增；偏差 ≤10% |
| E181 端到端 PCE-T | 新材质/未建模物理场地 vs 第 57 轮：真实探针数/成功率/首访承诺时延/漂移召回时延 | 探针 ↓≥45%；成功率 ≥持平；时延 ↓≥25%；召回 ≤1 同步窗 |

**预期结果（待验证，不伪造实测）**：E177 的难点在机制类分层——若把不同摩擦/接触机制混池校准，共形上界会被最差机制拖宽、导致 η_sim 塌到 0；预计需要"机制类最小样本 + 分层 union bound"才能既保覆盖又不浪费锚点。E178/E179 的关键在伪影过滤：单引擎下穿模会制造大量假失败，预计 XER 能砍掉七成以上，但两引擎**同时**数值脆弱时仍会漏过，需保留保守偏置。E180 预计是全局最敏感项：只要允许同一批遥测跨账本，洗白指数会随部署时长上升，最终把 EV-sim 抵扣额度吃光——这恰好是安全阀在起作用。E181 的效率增益主要来自"用反事实提前砍掉坏路线"，而非"用仿真替代真实确认"；若观察到成功率下降，几乎必然意味着 EV-sim 越过了不可逆必要集。

## 6. 本轮最大风险

**一句话**：孪生可能变成一台"自洽的幻觉引擎"——它便宜、连续、可无限复现，于是制造出大量彼此一致却高度相关、且恰好对未建模物理失明的虚拟证据；若 TVC 用同一批遥测既校准又背书，系统会越仿真越自信、越敢砍真实探针，而真实世界是唯一没被检查的地方；必须以"仿真只否决不批准、锚点与部署证据互斥、漂移即时召回、EV-sim 永不进入不可逆必要集"四道闸门约束。
