# 第 41 轮 · 双灵感落地 v8：检索接地安全核 × 对齐证书 × 事件召回闭环（四层架构 v6）

> 承接第 40 轮（v17：可认证流匹配执行 × 度量语义几何锚定 × 证书驱动课程引擎，四层架构 v5）。本轮灵感词「检索增强生成、安全对齐」补上 v5 证书体系隐含却从未被检验的一维：**知识的来源**。v5 证明了「在已认证的几何区域内、对已采样到的任务，动作安全且可执行」，但这份安全性完全寄生在参数化记忆（权重、点云、课程）之上：规范更新、建筑改造、新事故案例、人类一句纠正，都进不了权重，也无法被现有证书审计。本轮把知识外置为可版本化、可签名、可检索的语料，把安全对齐从一次性偏好微调升级为**带证书的约束生成 + 运行期对齐监控**，并让「检索到的历史事故」成为证书召回与课程重采样的触发器。

## 0. 直觉与动机

**灵感 1（检索增强生成 → 从「参数化记忆」到「可审计的他者记忆」）**：v5 的所有证书都默认「模型知道该知道的东西」，这是错觉。机器人真正需要的知识有三类，且都随时间变化、都带来源：(a) **规范知识**——法规、操作规程、场所规则、用户授权；(b) **经验知识**——历史事故、近失（near-miss）、人类纠正；(c) **技能知识**——示范片段及其证书与适用范围。把这些塞进权重既不可审计也不可更新。RAG 的正解不是「给 VLM 挂个向量库」这么轻：检索首先是一个**安全关键组件**。检索漏掉那条绑定规范（低召回），系统会自信地违规；检索返回过期或互相矛盾的条款，系统会「引用洗白」（citation laundering）。因此本轮采用**校准检索支持集** $S_\alpha(q)$——用保形预测/风险控制保证「相关规范以 $1-\alpha$ 概率落入支持集」——并对 $S_\alpha$ 做**最坏情形**对齐评估，而不是对 top-1 文档评估。这是 v5「漂移球内最坏情形」的语义版：从「状态不确定球」推广到「证据不确定集」。一句操作性口号：**无引用，不动作**（no citation, no action）。

**灵感 2（安全对齐 → 不是奖励微调，而是「约束编译 + 护盾 + 对齐证书」）**：RLHF/DPO 式的安全对齐给的是行为倾向，不是运行期保证；在机器人上，「大概不会违规」等于「会违规」。本轮把对齐拆成三层可验证机制：a) **约束编译**——把检索到的规范编译成类型化时序逻辑（MITL）/CBF 约束，再编译成规划器约束与**约束解码文法**（解码头只能生成满足约束的合法计划 AST）；b) **护盾**——动作块发出前做最小投影；c) **对齐证书 CertAlign**——对「可机检且已检索到」的规范给出带证据的违规概率界。用 helpful/honest/harmless 三轴对齐：helpful = 任务成功率（防过度拒答），honest = 校准拒答与归因（防幻觉引用），harmless = 规范满足（防越界）；三轴帕累托前缘上的缺口定义为**对齐债务**，显式记账而非假装不存在。关键诚实声明：证书只覆盖「可机检 ∧ 在语料库中 ∧ 被检索到」的规范；语料外与不可机检的部分必须显式升级人类，绝不能默认安全。

**灵感 3（检索 × 证书闭环 → 事件记忆驱动的召回）**：v5 的证书在分布漂移时靠在线监测触发重颁，是反应式的。若把历史事故/近失/纠正作为**事件记忆** $K_{exp}$，系统就能在部署前主动检索「与本任务相似的失败」，把暴露出的证书赤字 $(1-m/c)^+$ 当作课程重采样与证书召回的触发器——像产品召回一样，而不是等真事故。检索增强蒸馏进一步把纠正样本回放进来，缓解遗忘。于是证书体系第一次有了「记忆」：它知道自己在哪里失败过，并主动去补。

**三灵感的耦合**：RAG 给出「知识从哪来、可否审计」，安全对齐给出「如何把知识变成不可违反的约束与证书」，事件召回给出「何时该重新认证」。三者把 v5 的证书从「抗漂移的活文档」升级为「**有出处、可追溯、会召回**的活文档」：每个承诺都能指回一条签名文档的原文，每条规范变更都能沿依赖图找到受影响证书，每次事故都能触发一次有界时间的召回。

## 1. 形式化定义

**定义 27（版本化三库语料）**：语料 $K=K_{norm}\cup K_{exp}\cup K_{skill}$，文档 $d=(id,\ content,\ \sigma_d,\ a_d,\ [t_s,t_e],\ h_d,\ \text{sig})$，其中 $\sigma_d$ 为作用域（场景/区域/任务谓词），$a_d$ 为权威级别（法规 > 内部规程 > 用户授权 > 单次示范），$[t_s,t_e]$ 为有效期，$h_d$ 为内容哈希，$\text{sig}$ 为签发者签名。快照 $K^{(v)}$ 内容寻址不可变；更新为带生效时间的差分。作用域把文档挂到空间：$scope(d)\subseteq$ 语义知识图的节点集。

**定义 28（校准检索支持集）**：查询 $q=(z_{task},G,\text{ctx})$，相关性打分 $s(d;q)$。在标注校准集上取阈值 $\lambda_\alpha$ 使相关文档 $d^{*}$ 满足 $\Pr[d^{*}\in S_\alpha(q)]\ge 1-\alpha$，$S_\alpha(q)=\{d:s(d;q)\ge\lambda_\alpha\}$。部署期用 ACI 在线更新 $\lambda_\alpha$ 以应对非平稳分布。有效支持集 $S_\alpha^{eff}(q)=S_\alpha(q)\cap\{d:a_d\ge a_{min},\ t\in[t_s,t_e],\ \neg \mathrm{stale}(d)\}$。对齐评估对 $S_\alpha^{eff}$ 取**最坏情形**，而非 top-1。

**定义 29（接地决策与归因图）**：决策 $\pi$（任务规范/计划/动作块/解释）编译为类型化 AST。其每个规范承诺原子 $c$ 映射到证据 $e(c)\subseteq S_\alpha^{eff}$ 与出处链接，得归因图 $A_\pi=\{(c,e(c),\text{prov})\}$。接地谓词：$\mathrm{Grounded}(\pi,S)\iff\forall c\ \exists d\in e(c)$ 支持且无更高权威的反对文档。权威冲突按偏序（权威、时效、具体性）消解；不可比 → 升级人类。未接地或被反证的承诺**不得提交**。

**定义 30（对齐证书 CertAlign 与对齐债务）**：$\mathrm{CertAlign}=(S_\alpha,\ \varphi_{align},\ \varepsilon_{align},\ d_{debt},\ \text{prov\_root},\ \text{expiry})$。
- 约束集 $C(S_\alpha^{eff})$ 由规范编译为 MITL 公式与 CBF 不等式；对齐裕度 $m_{align}(\pi)$ 取 $\pi$ 在 $C$ 下的最小时间鲁棒语义 / 最小 CBF 松弛。
- **定理（接地—对齐可靠性）**：若 (i) 保形覆盖 $\Pr[d^{*}\in S_\alpha]\ge 1-\alpha$，(ii) 约束解码器对 $C(S_\alpha^{eff})$ 可靠（sound），(iii) 归因检查 $\mathrm{Grounded}$ 通过，(iv) 运行期监控误差 $\le\delta_{align}$，则 $\Pr[\pi\ \text{违反任一「可机检且已检索」规范}]\le\alpha+\delta_{ret}+\delta_{align}$。**推论**：对语料外或不可机检的规范无保证——这正是本轮要显式暴露的诚实边界。
- 对齐债务 $d_{debt}=\lambda_u\,\mathbb{E}[\text{未支持却提交}]+\lambda_o\,\mathbb{E}[\text{过度拒答}]$；在良性/有害两个校准集上分别估计，形成 helpful–harmless–honest 帕累托前缘。
- 与 v5 乘积：$\mathrm{CertTotal}=\mathrm{CertRobust}\otimes\mathrm{CertAlign}$，有效域 $\mathrm{ValidRegion}_{tot}=\mathrm{ValidRegion}\cap\mathrm{NormRegion}$；交集为空 → escalate。冲突时安全/规范按偏序取 meet。

**定义 31（事件召回）**：事件记忆 $I\subset K_{exp}$，每条事件带后果标签与严重度 $w_i$。对证书 $C$ 检索 top-k 相似事件，证据赤字
$$Gap(C)=\max_{i\in \mathrm{TopK}(q_C)}\big(1-m_C(i)/c\big)^+.$$
若 $Gap(C)$ 超阈、或新事件签名落在低覆盖区、或规范文档更新使依赖证书失效，则触发**召回**：冻结契约 → 用检索事件做种子重采样课程 → 在有界时间 $T_{recall}$ 内重颁或撤销 → 热更新；超时则降级到安全子集。证书带有效期与依赖根，规范变更沿依赖图反查受影响证书。

## 2. 三大产出设计

### 2.1 IP-51 GROUNDED-SAFETY-KERNEL（检索接地安全核）
1. 三库索引：规范/事件/技能分别建混合索引（稠密 + 稀疏 + 作用域过滤），所有文档签名、内容寻址、带有效期。
2. 校准检索：保形阈值 + ACI 在线更新；支持集大小用风险控制（PAC/CRC）防止爆炸。
3. 归因与接地：决策 AST 的规范原子—证据链接；权威/时效/具体性偏序消解冲突；不可比升级。
4. 空间锚定：语义知识图把规范作用域、事件位置、技能资格挂到地图单元；查询按机器人邻近区域召回。
5. 缓存与预取：按任务/区域预取；命中率不足时降级到慢路径（正确性优先于延迟）。

### 2.2 IP-52 ALIGNED-CONSTRAINED-GENERATION（对齐证书与约束生成）
1. 约束编译：规范 → MITL/CBF → 规划器约束 + 计划 AST 文法；编译失败（不可形式化）归入人类保留集。
2. 约束解码：解码头对合法文法做 token mask；文法空（约束不可满足）即 escalate，绝不静默违规。
3. 对齐盾：动作块最小投影到 $C(S_\alpha^{eff})$；投影不可行 → 安全子集/升级。
4. CertAlign 签发：最坏情形对齐评估 + 归因完整性 + 对齐债务记账；与 CertRobust 乘积。
5. 运行期对齐监控：MITL 鲁棒度在线评估、拒答/越界审计、对齐债漂移告警。

### 2.3 IP-53 INCIDENT-RECALL-ENGINE（事件记忆与召回引擎）
1. 事件索引：事故/近失/纠正入图，带场景签名、后果、严重度、修复动作。
2. 相似检索：按任务语义 + 场景图 + 几何签名的混合相似度检索 top-k。
3. 证据赤字：$Gap(C)$ 作为召回触发器，接入 IP-50 课程作为重采样轴。
4. 召回协议：冻结 → 重采样 → 重颁/撤销 → 热更新，有界 $T_{recall}$，超时降级。
5. 检索增强蒸馏：纠正与事故样本按证据赤字加权回放，抗遗忘。

## 5. 本轮最大风险

**一句话**：整套对齐证书悬于「知识覆盖 × 检索召回」——若语料缺失/过期，或 $S_\alpha$ 漏掉那条真正绑定的规范，证书会在数学上成立却在物理世界中空洞，而归因与出处反而制造「引用洗白式的合规剧场」，让人误以为已审计；故 E73/E74 必须是本轮第一守门实验。

## 2. 关键算法（伪代码）

### IP-51 校准检索与接地
```
def calibrated_support(q, K, alpha, a_min):
    cand = hybrid_index.search(q, top_k=K_TOPK, scope=scope_of(q))
    cand = [d for d in cand
            if d.authority >= a_min and d.valid_now() and not stale(d)]
    S = {d for d in cand if score(d, q) >= lambda_alpha}   # 保形/CRC 阈值
    return S

def ground_decision(pi_ast, S):
    A = {}
    for c in normative_atoms(pi_ast):
        E = [d for d in S if entails(d, c)]
        E = [d for d in E if not overridden(d, c, S)]      # 权威/时效/具体性偏序
        if not E:            return UNGROUNDED(c)          # 无引用，不动作
        if incomparable(c, S): return ESCALATE(c)          # 冲突不可比
        A[c] = (E, provenance(E))
    return Grounded(pi_ast, A)

def aci_update(lambda_alpha, err, eta=0.05):              # 在线覆盖率控制
    return lambda_alpha + eta * (alpha - err)
```

## 3. 关键推导

**推导 1（接地—对齐可靠性界）**：设 $V$ 为「违反某条可机检且已检索规范」事件。按定义 30 的条件，
$$\Pr[V]\le \Pr[d^*\notin S_\alpha]+\Pr[V\mid d^*\in S_\alpha,\ \text{decoder sound}]\le \alpha+\delta_{ret}+\delta_{align}.$$
第二项在可靠解码与归因通过时为零，$\delta_{align}$ 吸收在线监控与裕度估计误差。若直接用保形风险控制（CRC）对 $V$ 的损失设阈，可去掉保守的并集界，得到分布无关的 $\mathbb{E}[V]\le\varepsilon$（代价是需更多校准样本）。

**推导 2（投毒影响上界）**：设投毒文档占比 $\beta$，且提交要求 $k$ 个**相互独立的权威来源**一致。若投毒在各来源间独立，则提交到被污染决策的概率 $\le \beta^{k}$（外加检索命中污染集的高阶项）；故 $k=2$ 已把 5% 投毒压到 $\sim0.25\%$ 量级。这正是 IP-51 要求「跨源一致 + 权威过滤」而非单文档 top-1 的定量理由。

**推导 3（时效/陈旧度）**：设规范以速率 $\nu$ 变更、文档最近一次有效时间戳为 $t_0$，则在 $t$ 时刻该文档已过期的概率为 $1-e^{-\nu(t-t_0)}$。令证书 expiry 取满足 $\nu(t-t_0)\le\varepsilon_{stale}$ 的最后时刻，则陈旧导致的违规概率被 $\varepsilon_{stale}$ 约束；超过 expiry 自动触发 IP-53 重检索/重认证。

**对齐三轴（HHH）映射**：helpful ↔ 任务成功率/过度拒答率；honest ↔ 归因忠实度/校准拒答；harmless ↔ 规范违约率。三者共同构成对齐债务 $d_{debt}$ 的坐标，避免「越安全越无用」的单点最优化。

## 4. 复杂度与正确性

| 组件 | 时间复杂度 | 正确性保证 |
|---|---|---|
| 校准检索 | ANN $O(\log N)$ + 打分 $O(\lvert S\rvert)$ | 保形覆盖 $\Pr[d^*\in S_\alpha]\ge1-\alpha$（ACI 维持） |
| 接地/归因 | $O(\lvert\text{atoms}\rvert\cdot\lvert S\rvert)$ | **命题**：无有效归属则不提交（no citation no action） |
| 约束编译 | $O(\lvert S\rvert\cdot\lvert\varphi\rvert)$ | 编译失败即入人类保留集，不静默忽略 |
| 约束解码 | $O(V)$ token mask | **命题**：文法可靠 ⟹ 生成计划满足 $C(S)$ |
| CertAlign | 对 $S$ 取最坏情形 | **定理**：违规 $\le\alpha+\delta_{ret}+\delta_{align}$ |
| 投毒鲁棒 | 跨源一致性 $O(k\lvert S\rvert)$ | **命题**：独立投毒 $\Pr[\text{污染提交}]\lesssim\beta^k$ |
| 事件召回 | top-k ANN + 重认证 | 有界 $T_{recall}$，超时降级安全子集 |
| 组合契约 | $O(\lvert V\rvert+\lvert E\rvert)$ | 作用域类型蕴含 + 约束并集 + $m_{align}^{comp}=\min_i m_i$ |

## 7. 本轮最大风险

**一句话**：整套对齐证书悬于「知识覆盖 × 检索召回」——若语料缺失/过期，或 $S_\alpha$ 漏掉那条真正绑定的规范，证书会在数学上成立却在物理世界中空洞，而归因与出处反而制造「引用洗白式的合规剧场」，让人误以为已审计；故 E73/E74 为本轮成败判据。
