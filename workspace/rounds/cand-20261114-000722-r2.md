# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「文化适应性」×「遥操作」）

> R69 把不确定性一分为二，并让系统学会「问」：aleatoric 收紧，epistemic 用流匹配多模态 + 主动多模态交互消解。但它默认了三件事：**「问」这个动作本身是文化中性的、回答只关于任务、机器人的行为只由机器人自己承担后果**。遥操作把这三条同时打穿：
> - 操作员在远端，指令与观测都经过**时延**，沉默既可能是延迟、是礼貌、是不同意，也可能是通道故障；把「没回答」当成「没意见」是最危险的误读。
> - 机器人是远端操作员的**化身**，它的文化失礼会被记在操作员（甚至其组织）头上，而不是记在机器人头上——代价由不在场的第三方承担。
> - 「文化」不是一个可以查表的国籍标签，而是一组**会话级的隐约定**：直接还是委婉、谁先开口、能否注视、能否触碰、风险由谁拍板。R69 的 VoI 只算任务信息增益，没算「问」本身的规范成本。
>
> 核心命题：**把 epistemic 再拆成「任务歧义」与「约定歧义」；把「规范风险」升为一等成本；把「权威」从隐式推断改为显式契约；把「文化适应」限制在可逆、可审计、不可越过底线、不可从受保护属性推断的范围内。** 命名 **CULT-RAS**（Cultural, Latency-aware Teleoperation Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**在这个文化里，我该怎么问、该不该问、问完算谁的**」——适应不是猜对文化，而是在文化不确定下仍然体面、可解释、可退出。

## 0. 直觉与动机

**灵感 1（遥操作 → 沉默是四种事情的叠加）**
直觉：在双边遥操作里，操作员不说话，可能是网络延迟、是在等你先动（礼貌/权力距离）、是不同意但不愿直说、是通道断了。这四者在「只有沉默」这一个观测下不可区分；R69 的 MINT 会把「没有新证据」当成「VoI 不够」，或者更糟，把「没反对」当成「默认同意」。所以第一件事不是更聪明的提问，而是**先把沉默拆开**：用时间模型、主动心跳探测、第二通道（触觉/文字）做归因。归因错了，后面所有 VoI 都建立在错误的信念上。

**灵感 2（文化适应性 → 文化是会话级隐变量，不是国籍）**
直觉：同一个人在不同场景（和长辈/和同事/和陌生人）也会切换约定；把文化等同于国籍既不准也不道德。更可操作的建模是：一组**约定画像** c =（直接/委婉、权威期望、风险容忍、模态偏好），它是会话级、缓慢变化、可由少量交互证据更新、也可以由操作员显式声明或一键重置的隐变量。机器人推断的是「这次怎么合作」，不是「你是哪里人」。这条线同时决定了伦理边界：**禁止用受保护属性及其代理做推断**。

**灵感 3（规范成本 → 「问」不是免费的）**
直觉：R69 的 VoI(g)=H(M|o)−E[H(M|o,y)] 只算「问了能知道多少」，没算「问这个动作在这里合不合适」。在有的语境里，直接追问是失礼，盯着看是冒犯，碰一下是越界；问错一次可能比不问损失更大。于是定义**规范风险** R_norm(g,c)（尊严、隐私、同意、面子、身体自主、第三方归因）并把目标改成 VoI − λ·R_norm − μ·R_delay。R69 是 R_norm≡0 的退化。由此得到一个反直觉结论：**可分的歧义不一定值得问；当规范成本超过信息价值时，最优动作是「不问」，改用文化不变的动作或显式协商。**

**灵感 4（文化地板 → 适应不能把底线适应掉）**
直觉：如果「适应文化」意味着服从当地的一切规范，那遇到支持危险、欺骗、羞辱的规范怎么办？所以必须有一个**不随 c 变化的地板** N_0：物理安全、知情同意、不欺骗、不羞辱、隐私、操作员的申诉权。适应只在 N_0 之内进行；文化相对主义不能侵蚀安全。更进一步，文化之间可能是**不可通约**的：没有唯一最优，只有一组 Pareto 可接受动作。此时系统的正确行为不是偷偷选一个，而是**显式升级冲突**（pluralism escalation），把选择交还给受影响的人。

**灵感 5（适应会反噬 → 刻板印象、操纵、煤气灯）**
直觉：一个会「读文化」的系统，也可以被用来「演文化」：故意给出矛盾线索让后验震荡（gaslighting）、用礼貌的间接拒绝诱导系统误判同意、用延迟伪装犹豫、把机器人当代理去损害操作员声誉。适应越快，越容易被操纵；越自信，越像刻板印象。所以必须同时交付：**证据的文化不变性检验、适应速率预算、单次交互不定案、受保护属性代理审计、权威契约的显式同意、以及对抗干扰集**。否则 R70 不是更懂文化，而是更会冒犯、更会被利用。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（CULT-RAS 总览）** CULT-RAS = (CPM, DTA, ASA, CIG, NGF, CAB, PEX, CCG, DWC, RAS-WM‡)。五不变式：
(i) 实时流零学习写操作（继承 R69 定义 293-i）；
(ii) **权威显式**：共享控制权 α 与否决/升级规则必须写入权威契约 K，任何权威变更需操作员同意或显式默认披露，不得由文化后验静默改写；
(iii) **文化地板**：存在不随 c 变化的可行约束 N_0（物理安全、知情同意、不欺骗、不羞辱、隐私、申诉权），适应只在 N_0 内进行；
(iv) **可逆适应**：文化画像会话级、有速率上限、可冻结/重置，禁止以受保护属性或其代理为输入；
(v) **证据纪律**：单次交互/单源证据不定案；文化敏感证据必须条件化或降权（定义 319）。

**定义 311（约定画像 CPM）** 会话级隐变量 c = (c_dir, c_auth, c_risk, c_comm) ∈ C，分别表示沟通直接度、权威/主动性期望、风险容忍、模态偏好。p(c) 为专家 curation 的离散先验（支持集 |C|≤8），不是国籍分布；证据 e 来自可观测交互（措辞、扣除网络延迟后的响应时延残差、是否覆盖建议、显式声明），更新 p(c|e) ∝ p(c)·p(e|c)·1[e admissible]。c 在一个会话内缓慢变化，跨会话不继承。

**定义 312（遥操作时延模型）** 机器人观测 o_t = h(s_{t−τ_t}, c, ν_t)，操作员指令 u^op_t = π_op(b^op_{t−τ'_t}, c)，其中 τ_t, τ'_t 为上下行时变时延，b^op 为操作员对状态的信念。遥操作引入两类陈旧性：**观测陈旧**与**指令陈旧**；定义时延诱导 epistemic U_delay = E[‖s_t − ŝ_{t|t−τ}‖²]。

**定义 313（三路不确定性）** U_ale（噪声，继承 R69）；U_epi = (U_task, U_conv)，其中 U_task 是「哪个任务模态」，U_conv 是「这条证据/动作在此约定下是什么意思」；U_delay（陈旧）；U_norm 不是可由信息消解的 uncertainty，而是**价值冲突的规范风险**。四者分通道处置：U_task→R69 交互；U_conv→低成本可逆约定探针；U_delay→预测/心跳/第二通道；U_norm→地板约束 + 显式协商。

**定义 314（约定条件语义与规范成本）** 动作/证据 y 在约定 c 下的语义为 p(y|a,c)（如手势、目光、沉默、赞许）；规范成本 R_norm(a,c) = Σ_k w_k r_k(a,c)，r_k ∈ {尊严, 隐私, 同意, 面子, 身体自主, 第三方归因}，由文化专家面板标定并在部署地做本地校准。R_norm 是一等成本，不是软惩罚。**归因项** r_attr 显式刻画「机器人失礼记在远端操作员头上」。

**定义 315（文化感知信息增益 CIG）** 对候选信息动作 g：
VoI_c(g) = E_{c~p(c|e)}[ H(M|o,c) − E_{y~p(·|g,o,c)} H(M|o,y,c) ]；
净收益 = VoI_c(g) − λ·E_c[R_norm(g,c)] − μ·R_delay(g) − c(g)。
选择 g* = argmax 净收益，s.t. g ∈ A_feas（N_0 投影）、权威契约允许、预算未超。若 max ≤ 0：不交互，改用文化不变动作或 PEX 协商。R69 的 MINT 是 R_norm≡0、c 已知、τ=0 的退化。

**定义 316（时延—信任归因 DTA）** 观测到操作员「沉默/迟疑/覆盖」信号 z 时，维护原因后验 q ∈ {delay, deference, disagreement, channel_failure, polite_refusal}：
P(q|z,t) ∝ P(q)·P(z|q,t;τ̂)·P(q|c)。
其中 P(z|delay,t;τ̂) 用扣除网络时延后的残差建模；P(z|deference,c) 依赖 c_auth；P(z|polite_refusal,c) 依赖 c_dir。**单靠沉默不可辨识**（引理 20）；DTA 只在有主动心跳、第二通道或显式询问时才允许后验熵降到阈值以下。

**定义 317（权威契约 ASA）** 权威状态 α ∈ {robot_lead, shared, operator_lead}（或连续 α∈[0,1]）；契约 K = (α, veto 规则, 升级策略, 交接协议, 披露语言)。K 是显式、可读、可审计的对象，双方可检查；文化后验只能**提议** K 的默认值（例如高权威期望→更倾向 operator_lead），变更需操作员确认或采用已披露的默认。机器人不得通过改变自己的行为「诱导」操作员放弃否决权。

**定义 318（规范地板 NGF）** N_0 = {a : r_k(a,c) ≤ ε_k, ∀k∈hard, ∀c∈C_support}，hard 至少含物理安全、知情同意、不欺骗、不羞辱、隐私。可行集 A_feas(c) = A_safe(定义 322) ∩ N_0。**N_0 与 c 无关**：任何 c 都不能把 N_0 放宽。N_0 之外的价值冲突交给 PEX，不做标量折中。

**定义 319（文化证据不变性）** 对证据源 j 定义似然比幅度 I_j = sup_{c,c'∈C_support} p(e_j|c)/p(e_j|c')。若 I_j > κ_inv，则该证据标记为**文化敏感**：只能条件化于 c 使用，或降权；不得单独更新 U_task，也不得单独触发文化后验更新。只有 I_j ≤ κ_inv 的**文化不变证据**可进入 R69 的 k-正交证据纪律。这把 R69 的「k 个正交源」升级为「k 个正交且跨文化不变/已条件化的源」。

**定义 320（适应预算与反刻板 CAB）** 文化后验更新满足 (i) 速率约束 TV(p_t, p_{t−1}) ≤ η；(ii) 证据约束：每次更新至少需要 k_ev 个文化不变/已条件化证据源；(iii) 输入禁止：受保护属性（国籍、种族、性别、年龄、宗教、残障、性取向等）及其代理不得作为特征；(iv) 可逆：操作员可冻结/重置 c，会话结束即丢弃；(v) 代理审计：对抗分类器从实际输入预测受保护属性的 AUC 必须 ≤ 0.5+δ_proxy，否则删除/混淆相应特征。

**定义 321（多元升级 PEX）** 若不存在 a 使 max_{c∈C_support} R_norm(a,c) ≤ ε_norm，则进入显式协商模式：向操作员/在场者披露「存在规范冲突」、给出 2–3 个 Pareto 可接受选项及其后果、请求选择或授权。PEX 的默认不是「替他们决定」，而是「安全暂停 + 可解释选项」。在 worst-case 规范风险意义下，显式协商不劣于任何静默猜测（定理 20）。

**定义 322（时延感知安全证书 DWC）** 继承 R69 的 C-RAS-WM 前缀认证，但认证视野随 τ_max 收缩：k_τ = max{k : reachable_set(s_t, k, τ_max) ⊆ S_safe}；并叠加时域无源/屏障约束 ˙B(s) ≤ −αB(s) + L·τ_max（B 为屏障函数）。遥操作指令重放/时延注入视为对抗扰动，必须被 DWC 的时序一致性检查拦截。

**定义 323（约定校准门 CCG）** 文化后验需校准：定义 convention ECE 与可靠图。若 ECE > τ_conv 或后验熵低但被后续证据反复证伪（**文化过自信**），则禁用文化条件化与自适应默认，退回「文化不变动作 + PEX」。这是 R68 标定门在规范层的对应物。

**定义 324（归因感知审计 VQAuditor-X）** 审计对象新增：是否用受保护属性/代理；权威是否被静默改变；是否把延迟误判为同意/拒绝；规范探针是否可逆、是否取得同意；机器人行为是否给远端操作员带来未披露的声誉风险。结论回灌 AuditBuf，成为下一轮 CIG 的规范成本先验与 PEX 触发条件。

**定义 325（文化对抗干扰集 ℰ_culture）** 规范挑衅（故意表现被冒犯以逼系统让步）、礼貌诱导（间接拒绝被误读为同意）、后验煤气灯（矛盾线索使 c 震荡）、延迟伪装（注入时延伪造犹豫/服从）、重放/伪装操作员、跨文化社会工程（借机器人损害操作员声誉）。并入 AIC：ℰ_CULT = ℰ_FLUID × ℰ_culture × ℰ_tele（时延/重放/伪造）。

**定义 326（证书 J_CULT）** J_CULT = (J_FLUID, convention_profile_hash, authority_contract_hash, convention_ece, norm_risk_bound, delay_bound τ_max, adaptation_budget_used, evidence_invariance_report, pex_log, proxy_audit_auc, cult_ver)。Valid ⇔ Valid(J_FLUID) ∧ ECE_conv ≤ τ_conv ∧ N_0 满足 ∧ 权威契约未被静默改写 ∧ 代理审计通过。

**定义 327（对 R69 的严格包含）** 当 c 已知且同质、R_norm≡0、τ=0、权威契约固定为 operator_lead 时，CULT-RAS 逐指令退化为 FLUID-RAS；物理安全侧不弱于 R69；规范侧新增地板与审计。R69 是 CULT-RAS 在「文化中性 + 零时延 + 无规范成本」边界上的退化。

```python
# IP-264 CPM：会话级约定画像（禁止受保护属性，速率受限）
class ConventionPrior:
    def update(self, evidence, c_prior, budget):
        ev = [e for e in evidence if admissible(e, KAPPA_INV)]  # 定义 319
        if len(ev) < K_EV: return c_prior, False
        post = bayes(c_prior, ev)
        if tv(post, c_prior) > budget.eta: post = temper(post, budget.eta)
        return post, True

# IP-265 DTA：把沉默拆成延迟/礼貌/不同意/故障
def attribute_silence(z, dt, tau_hat, c):
    q = {
        'delay':       delay_likelihood(z, dt, tau_hat),
        'deference':   deference_likelihood(z, c.c_auth),
        'disagree':    disagreement_likelihood(z, c),
        'failure':     channel_failure_likelihood(z),
        'polite_no':   polite_refusal_likelihood(z, c.c_dir),
    }
    return normalize(q)   # 熵高时只允许“等/心跳/第二通道”，不得当同意

# IP-267 CIG：把规范成本与时延成本并入 VoI
def choose_info(modes, c_post, budget, contract):
    best = None
    for g in info_candidates(modes, c_post):
        if not budget.allow(g) or not contract.permits(g): continue
        if not ngf.feasible(g, c_post.support): continue          # 文化地板
        voi   = expected_voi(modes, g, c_post)
        score = voi - LAM * expected_norm_risk(g, c_post) \
                    - MU * delay_cost(g) - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None   # 不问 → 不变动作/PEX

# IP-266 ASA：权威契约显式化，文化只能“提议”
def propose_authority(c_post, current_contract):
    want = c_post.map_to_default_authority()          # 建议，不是命令
    if want == current_contract.alpha: return current_contract
    return current_contract.with_proposal(want, requires_consent=True)

# IP-268 NGF：硬投影，任何 c 都不能放宽
def project_floor(a):
    for r in HARD_NORMS:                              # 安全/同意/不欺骗/不羞辱/隐私
        if r.violated(a): return r.minimal_repair(a)
    return a

# IP-270 PEX：不可通约时显式协商
def pluralism_escalate(options, c_post):
    if min over options of max_{c in c_post.support} norm_risk(o,c) > EPS_NORM:
        return ask_human(options_to_pareto(options), reveal_conflict=True)
    return None

# IP-276 主闭环（继承 R69，插入文化/时延/权威层）
def CULT_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    c_post, ok = M.cpm.update(M.evidence_buffer, M.c_post, M.cab)
    if M.ccg.overconfident(c_post): c_post = M.cpm.fallback()   # 退回不变动作
    q = M.dta.attribute_silence(M.last_silence, M.dt, M.tau_hat, c_post)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    g = (M.cig.choose_info(modes, c_post, M.budget, M.contract)
         if (U_epi > TAU_EPI and q.is_conclusive()) else None)
    if g is not None:
        U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.dwc.certified_prefix(M.ach.propose(...), tau_max=M.tau_max)
    a = M.ngf.project_floor(select_mode(modes, U_epi, lam).a)
    if M.pex.trigger(a, c_post):
        return M.pex.escalate(a, c_post)              # 安全暂停 + 选项
    tau = M.pi_sigma.prefix_dispatch(a[:k]) * lam
    M.vqa_x.submit_async(g, c_post, M.contract, q, a)
    return k, lam, a, (U_ale, U_epi, c_post)
```

## 3. 推导

**引理 19（规范影子价格）** 设信息动作 g 的任务收益为 ΔH·V_task，规范成本为 λR_norm(g,c)，时延成本 μR_delay(g)。若 λR_norm + μR_delay ≥ ΔH·V_task，则 g 不是最优；最优动作属于「不问」集合（文化不变动作或 PEX）。系：**R69 在高规范成本语境下系统性过度提问**；把 R_norm 设为零等价于假设「问永远免费」，这在跨文化遥操作中不成立。

**引理 20（沉默的不可辨识性）** 仅观测「在 t 内无响应」时，延迟 D、礼貌性等待 F、不同意但不直说 X、通道故障 Φ 的似然在参数区域上可完全相同，故 KL(p(z|D)‖p(z|X))=0，后验不可辨识。要使后验熵降到 ε 以下，必须存在一个**干预**（主动心跳、改变请求时序、切换第二通道）使至少两假设的似然比偏离 1；否则任何「把沉默当同意」的推断都是无根据的。系：DTA 的第一原则是「先制造可区分性，再谈信任」。

**引理 21（文化地板的安全保持）** 若 N_0 只含与 c 无关的硬约束，且 A_feas = A_safe ∩ N_0，则对任意 c，投影后的动作物理风险 ≤ R69 的安全证书上界；文化适应不能降低安全，只能改变 N_0 内的偏好排序。系：文化相对主义被限制在安全壳内。

**引理 22（反刻板的条件不变性）** 若策略输入不含受保护属性及其代理，且只使用文化不变或已条件化证据，则对相同可观测交互证据，动作分布与受保护属性条件独立。代理泄漏由 CAB 的对抗审计控制：若代理分类器 AUC ≤ 0.5+δ_proxy，则泄漏上界 ≤ δ_proxy（在给定审计族下）。注意这是**条件**保证，不宣称绝对公平；未审计的代理仍是风险。

**定理 18（CULT-RAS 严格包含 FLUID-RAS）** 在 A99–A102 下，CULT-RAS 的物理期望风险 ≤ FLUID-RAS；当 c 已知同质、R_norm≡0、τ=0、契约固定 operator_lead 时逐指令相同。故 R69 是 R70 的「文化中性/零时延/零规范成本」边界；安全不让步，社会侧新增地板与审计。

**定理 19（适应稳定性与无震荡）** 在会话内 c 缓变（漂移率 δ）、似然比有界、更新速率 ≤ η 的条件下，文化后验的跟踪误差满足 E[TV(p_t, p*_t)] ≤ C(η + δ/η)（标准跟踪界）；若检测到后验震荡（来回穿越阈值），CCG 触发冻结并退回不变动作。故适应不会因对抗线索无限震荡，也不会把一次交互放大成永久画像。

**定理 20（多元升级的 minimax 优势）** 当 max_{c∈C_support} R_norm(a,c) > ε_norm 对所有 a 成立时，任何静默选择的 worst-case 规范风险 ≥ ε_norm；PEX 通过披露冲突并把选择权交还受影响方，其 worst-case 规范风险不超过「安全暂停 + 不行动」的基线，且不劣于静默猜测。系：**在不可通约处，诚实地说「我不知道该按谁的规矩来」优于自信地猜一个。**

## 6. 本轮最大风险

**一句话**：CULT-RAS 的核心假设是「约定画像可被少量交互证据可靠识别且不被操纵」——一旦这个假设错了，系统会**用刻板印象替代理解、用自信的适应替代诚实的协商**；在遥操作里，机器人是远端操作员的化身，一次「得体」的误判会被记在操作员头上，成为无法撤回的跨文化事故——**适应错了，比不适应更具破坏性，因为它带着“我懂你”的表情冒犯你。**

**次级风险与缓解**：
1. **刻板印象/代理泄漏** → 禁止受保护属性、CAB 代理审计、条件不变性（引理 22）、E306；
2. **文化相对主义侵蚀安全** → N_0 硬地板 + 引理 21，任何 c 不能放宽；
3. **沉默误判为同意** → DTA 不可辨识性（引理 20）+ 主动探测/第二通道 + 单次不定案；
4. **权威被静默改写** → 权威契约 + 显式同意 + VQAuditor-X + E304；
5. **时延/重放攻击** → DWC 时序一致性 + τ_max 收缩 + ℰ_tele；
6. **后验震荡/过自信** → 适应速率预算 + CCG 冻结 + PEX 兜底（定理 19–20）。

```python
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    g = (M.cig.choose_info(modes, c_post, M.budget, M.contract)
         if (U_epi > TAU_EPI and q.is_conclusive()) else None)
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.dwc.certified_prefix(M.ach.propose(...), tau_max=M.tau_max)
    a = M.ngf.project_floor(select_mode(modes, U_epi, lam).a)
    if M.pex.trigger(a, c_post): return M.pex.escalate(a, c_post)
    tau = M.pi_sigma.prefix_dispatch(a[:k]) * lam
    M.vqa_x.submit_async(g, c_post, M.contract, q, a)
    return k, lam, a, (U_ale, U_epi, c_post)
```

## 4. 推导

**引理 19（规范影子价格）** 若 λR_norm(g,c)+μR_delay(g) ≥ ΔH·V_task，则 g 非最优，最优属于「不问」集合（不变动作/PEX）。系：R69 在高规范成本语境系统性过度提问；R_norm≡0 等价于「问永远免费」。

**引理 20（沉默不可辨识）** 仅「t 内无响应」时，延迟/礼貌/不同意/故障的似然可完全相同，KL=0，后验不可辨识；必须用主动心跳、改变请求时序或第二通道制造似然比偏离，否则「沉默=同意」无根据。

**引理 21（地板安全保持）** N_0 只含与 c 无关的硬约束、A_feas=A_safe∩N_0 时，任意 c 下投影后物理风险 ≤ R69 证书上界；文化适应只能改变壳内偏好，不能降低安全。

**引理 22（反刻板条件不变性）** 输入不含受保护属性/代理且只用不变或已条件化证据时，相同可观测交互证据下动作分布与受保护属性条件独立；代理泄漏由 CAB 审计控制在 δ_proxy 内（给定审计族；非绝对公平保证）。

**定理 18（严格包含 FLUID-RAS）** A99–A102 下物理期望风险 ≤ R69；c 已知同质、R_norm≡0、τ=0、契约固定 operator_lead 时逐指令相同。R69 是「文化中性/零时延/零规范成本」边界；安全不让步，社会侧新增地板与审计。

**定理 19（适应稳定性）** 会话内 c 漂移率 δ、似然比有界、更新速率 ≤η 时，跟踪误差 E[TV] ≤ C(η+δ/η)；检测到后验震荡即 CCG 冻结并退回不变动作。故不会因对抗线索无限震荡，也不会把单次交互放大成永久画像。

**定理 20（PEX 的 minimax 优势）** 若所有 a 的 max_c R_norm(a,c)>ε_norm，任何静默选择的 worst-case 规范风险 ≥ε_norm；PEX 披露冲突并交还选择权，其 worst-case 风险不超过「安全暂停 + 不行动」基线，且不劣于静默猜测。系：不可通约处，诚实说「不知道该按谁的规矩」优于自信猜一个。

## 7. 本轮最大风险

**一句话**：CULT-RAS 的核心假设是「约定画像可被少量交互证据可靠识别且不被操纵」——一旦错了，系统会**用刻板印象替代理解、用自信的适应替代诚实的协商**；在遥操作里，机器人是远端操作员的化身，一次「得体」的误判会被记在操作员头上，成为无法撤回的跨文化事故——**适应错了，比不适应更具破坏性，因为它带着“我懂你”的表情冒犯你。**

**次级风险与缓解**：刻板印象/代理泄漏（禁受保护属性 + CAB 代理审计 + 引理 22 + E306）；文化相对主义侵蚀安全（N_0 硬地板 + 引理 21）；沉默误判同意（DTA 不可辨识性 + 主动探测 + 单次不定案）；权威静默改写（权威契约 + 显式同意 + VQAuditor-X + E304）；时延/重放（DWC + τ_max 收缩 + ℰ_tele）；后验震荡/过自信（适应预算 + CCG 冻结 + PEX 兜底）。
