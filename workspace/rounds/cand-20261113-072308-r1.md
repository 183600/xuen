# 灵感循环 v3 · 第 1 轮（总第 3 次迭代，承接 v2）：「对比实验」×「个性化交互」——把“验证-重做”改写成“个性化受控对比 + 对抗式交互”

> **直觉先行。** v2 已经知道“人会把进度反向撤回”，但它把这件事当成一个**单帧分类问题**（这一帧像不像被撤回）。真实评测里有两层不确定性被忽略了：① 每个 episode 的物体、摆位、光照都不同，**绝对阈值会把“没见过”误判成“被撤回”**；② 干扰者不是随机噪声，而是一个**有策略的交互者**——他专挑你刚完成的步骤、在你最接近末步高分时动手。本轮把 v2 的验证器升级为**受控对比**：把“执行的动作块”当作干预，把“若无人干扰的预测”当作对照，用**残差**做因果式判断；再用**个性化**同时适配“这个物体”和“这个干扰者”。一句话：不再问“像不像完成”，而问“**相对于这个实例、这个对手，这一步的进展是否被显著地反向改变**”。

**三条硬修正，直接决定本轮方案形态：**

1. **不能靠“运行时改块长”换反应性。** `T_a` 是编译期常量；只能在离线权衡 `T_a` 大小，并在**块内**设计“可被中断/可被覆盖”的动作序列。
2. **不能假设完整状态可得。** 没有 depth、没有基座位姿、没有力触觉；所谓“进度”只能是**对象中心的关系/属性读数**，必须带不确定性，不能当毫米级真值。
3. **外部大模型不能进运行期。** 单模型合规 + 延迟约束 ⇒ 对比器的先验只能**离线蒸馏**进同一骨干；在线只保留非参数校准与轻量头。

## 2. 两个灵感词的解读

### 2.1 对比实验：从“像不像”到“相对于对照，变了多少”

**直觉**：医生不会只看“这个指标高不高”，而是看“相对于不吃药的那组，高了多少”。v2 的验证器只看“这一帧像不像完成”，没有对照，所以一旦物体换了、光照变了，读数整体偏移，就会被误判。**受控对比**要求：① 有一个明确的干预（刚执行的动作块）；② 有一个可比的对照（若无人干扰，模型预测会发生什么）；③ 控制混杂（用同一实例的校准量把“物体差异”减掉）。

**严谨定义（在线对比器）**：设当前子目标为 `g`，动作为 `a_{t:t+T_a}`，个性化上下文为 `c`。定义

- 进度读数 `Φ(o_t) = p_t ∈ [0,1]^m`（对象中心，m 个与计分点对齐的谓词）；
- 个性化前向模型 `F_θ(p_t, a_{t:t+T_a}, c) = p̂^0_{t+T_a}`（“若无人干扰”的对照）；
- 观测读数 `p^obs_{t+T_a}`；
- 残差 `r_j = (p^obs_j − p̂^0_j) − δ̂_j`，其中 `δ̂` 是本实例的校准偏移。

在“无干扰”假设 `H_0` 下 `r ~ p_0`；在“进度被反向撤回”假设 `H_1` 下 `r ~ p_1`。用对数似然比累积证据：

`ℓ_t = log p(r_t | H_1) / p(r_t | H_0)`，`S_t = max(0, S_{t-1} + ℓ_t)`，当 `S_t ≥ h` 判 `H_1`。

这不是“更复杂的阈值”，而是把**误报率**变成可调预算：`h` 由离线 `H_0` 校准确定，使每个子目标的误报率 ≤ `α/m`（m 为每 episode 子目标数），从而把**每 episode 误报率**控制在 `α` 附近。

**因果假设（必须写清）**：观测与反事实预测之差，主要来自“干扰”这一处理；模型误差是被校准的 nuisance，而不是第二个处理。若这条不成立（例如前向模型系统性偏差），对比器会退化——这正是本方案的最大风险来源。

### 2.2 个性化交互：对“这个物体”和“这个对手”分别建模

**直觉**：同一个“抓杯子”，对你家的杯子和评测台上没见过的杯子，力控与抓取点不同；同一个“反向撤回”，对不同干扰者，动手时机与目标步骤也不同。**个性化不是给每个任务训一个模型**（那会撞“单模型”合规），而是给同一个骨干喂一个**从本 episode 观测出来的上下文向量**。

**严谨定义（个性化算子）**：设基础策略 `π_θ(a|o,l)`。个性化算子 `Π_c` 把它改写为 `π_θ(a|o,l,c)`，其中

`c_t = (e, δ̂, q_t)`

- `e`：实例嵌入，由首帧 4 路 RGB + `language` 得到（对象外观/几何/可供性）；
- `δ̂`：实例校准偏移，由 episode 前若干“假定完好”的 chunk 估计（人扰多发生在中途，首段完好是可辩护的弱假设）；
- `q_t`：干扰者风格后验。

干扰者建模为一个**交互策略**：风格 `s ∈ S`（如 `none / reverse-only / relocate-only / remove-late / aggressive-early`），干预 `z_i ∈ {none, reverse, relocate, remove}`，目标子目标 `g_i`、时机 `τ_i`。后验

`P(s | z_{1:t}) ∝ P(s) · Π_i P(z_i, g_i, τ_i | s)`。

据此预测 `P(z_{t+1} ≠ none | history)` 与目标分布 `P(g_{t+1} | history)`，用于**预防性防护**（见产物区 §3）。这就是“个性化**交互**”：不是把干扰当噪声，而是把干扰者当成一个需要在线识别的对手。

## 3. 瓶颈假设（本轮）

- **H1（校准）**：实例 nuisance 是 v2 误报的主因；个性化校准能在**不降低检出**的前提下把误报率显著压低。
- **H2（序贯）**：人扰是**持续性反向变化**，不是单点噪声；在同等误报预算下，序贯变化检测优于单帧阈值。
- **H3（价值加权）**：末步分值更高 ⇒ 重做的代价应随子目标价值变化；“一刀切阈值”必然在“低价值步过度重做”与“高价值步漏检”之间二选一。
- **H4（对手）**：干扰风格可从少量干预中推断；当再干预概率高时，**预防性防护**的期望收益高于“被撤回后再重做”。
- **H5（因果归因）**：只有**配对因子实验**（每次只改一个因子）才能把增益归因到具体机制；随机增广会把“物体/位置/背景/干扰”混在一起，无法证伪。

---

## 4. 候选与合并 → v3 清单

围绕两词发散 10 个草案，合并后得到 5 个新条目（UIP-16~20），并把 v2 的 01′/09′/13/15 分别升级或纠错并入。旗舰是 **CPAI（Contrastive-Personalized Adversarial Interaction，对比-个性化对抗交互）**，由 **UIP-16 对比器 + UIP-17 实例个性化 + UIP-18 对手模型 + UIP-19 效用执行器**四条腿组成；**UIP-20** 提供可证伪的实验方法论。

---

## 5. 本轮最大风险

**一句话**：对比器的证据通道只有它自己的前向模型那么可靠——在未见物体上，“新奇”与“被撤回”可能产生同向残差，再好的序贯检验也无法修正一个有偏的证据源，必须用检索到的真实配对样本与真机锚点给残差“接地”，否则整套 CPAI 会变成“用模型误差解释模型误差”的自我循环。

# 第 3 轮产物 · UniBot 创新点清单 v3（UIP-16~20，承接 v2 的 UIP-01′~15）

> 本轮不推倒重来：v2 的旗舰（扰动撤回检测-重做）保留，但把它的**验证器**换成“个性化受控对比”，把**执行器**换成“价值加权效用决策”，把**对手**从噪声换成“可在线识别的交互策略”。

## 1. 旗舰深潜：CPAI 的形式化

### 1.1 记号与约束

- 动作块长度 `T_a` 固定；一次 `get_action` 返回 `(T_a, …)`，评测端整块执行后才重观测。
- 子目标 `g_1..g_m` 与计分点对齐，权重 `w_j`（来自 v2 的 32 任务计分表，`Σ w_j = 100`）。
- 观测 `o_t` 只含 RGB + 本体；**无 depth/基座位姿/力触觉**。因此“进度”只能是对象中心的关系/属性读数 `Φ(o_t) ∈ [0,1]^m`，不是米制真值。
- 每 episode 可用的“自然实验”次数 = episode 时长 / `T_a`；每次重观测都是一次**对比机会**。

### 1.2 个性化上下文（UIP-17）

`c_t = (e, δ̂, q_t)`：

- `e = Enc_φ(o_0, l)`：实例嵌入（外观/几何/可供性），由首帧 4 路 RGB + 语言得到；
- `δ̂ = mean_{t ∈ 完好前缀}(Φ(o_t) − F_θ(·))`：实例校准偏移；人扰多发生在中途（v2 的 `human_*` 证据），首段完好是可辩护的弱假设；
- `q_t = P(s | z_{1:t})`：干扰者风格后验（见 §3）。

**个性化算子**：`π_θ(a|o,l) → π_θ(a|o,l,c)`。个性化只改**条件输入**，不新增模型，满足“单模型多任务”。

### 1.3 对比反事实器（UIP-16）

对当前子目标 `g` 与动作块 `a_{t:t+T_a}`：

1. **对照**：`p̂^0 = F_θ(Φ(o_t), a_{t:t+T_a}, c)`（“若无人干扰”）；
2. **观测**：`p^obs = Φ(o_{t+T_a})`；
3. **校准残差**：`r_j = (p^obs_j − p̂^0_j) − δ̂_j`，只对 `j ≤ g` 的已完成/进行中子目标计算；
4. **证据累积**：高斯近似下 `ℓ_j = −2 μ r_j / v`（`v` 含校准方差），`S ← max(0, S + Σ_j ℓ_j)`；
5. **判决**：`S ≥ h_g` → `regressed`；`p^obs_g ≥ done_thr_g` → `done`；否则 `ongoing`。

**为什么用 CUSUM 而不是单帧阈值**：人扰是**持续性反向变化**，CUSUM 对“持续漂移”最优；单帧阈值无法把误报与漏检解耦。`h_g` 由离线 `H_0` 校准，按**每 episode 误报预算** `α` 分配：

`α_sub = 1 − (1 − α_ep)^{1/m}`（m 个子目标；例如 `α_ep=0.05, m=3 ⇒ α_sub≈1.7%`）。

**接地（防止自欺）**：`F_θ` 的预测不凭空来——用检索库中**同语言、同子目标、同动作块**的真实演示做参照；`r` 的分布 `p_0/p_1` 也在这些配对样本上离线标定。若检索不到近邻，降低置信度并退回“保守前进”，而不是硬判。

### 1.4 效用执行器（UIP-19，合并 ACS/CSG）

计分语义未核实（“曾经达成” vs “终局结算”）。因此对每个候选宏动作 `a ∈ {advance, redo, restore_then_redo, retry_alt, hold}` 计算：

`U(a) = min( U_ever(a), U_final(a) ) − λ·latency(a) − μ·P_false_redo(a) − ν·Var(latency)`

其中

- `U_ever = Σ_j w_j · P(g_j 曾被达成)`，`U_final = Σ_j w_j · P(g_j 终局仍成立)`；
- `min(·,·)` 是对未知计分语义的**鲁棒准则**：宁可两种语义下都不差，也不赌其中一种；
- `P_false_redo` 来自当前 `S` 与 `h_g` 的后验，而不是事后惩罚；
- `latency/Var` 直接对应 README §6 的可信度。

**恢复原语的两段式**：干扰可能把物体挪走/合上，直接“重做”可能无效。候选里显式区分 `redo`（从当前状态重做）与 `restore_then_redo`（先恢复到子目标前状态再重做），由效用选择——这是 v2 没有的。

### 1.5 人类对手模型（UIP-18）

风格 `s ∈ {none, reverse_only, relocate_only, remove_late, aggressive_early}`；干预 `z_i=(type, target g_i, timing τ_i)`。后验

`P(s|z_{1:t}) ∝ P(s) Π_i P(z_i,g_i,τ_i | s)`。

据此得到**风险图** `ρ_j = P(下一次干预目标 = j | history)`，并做三件事：

1. **预防性防护**：对高风险且已完成的子目标，选择“更难被反向”的合法动作变体（保持夹持接触到下一 chunk；把容器合上/转开把手；把已叠物件推到低风险区）。
2. **恢复排序**：若再干预概率高，先恢复“最贵且最易被撤回”的子目标，而不是按原顺序从头来。
3. **何时放弃**：若 `P(反复干预)` 高到重做期望收益为负，`hold` 或转向其它可得分步，避免把延迟预算耗在同一个子目标上。

## 2. 对比实验方法论（UIP-20 FCP）

### 2.1 在线：每个 chunk 都是一次自然实验

- 干预 = 刚执行的动作块；对照 = 反事实预测；处理效应 = 校准残差。
- 因果假设：干扰是唯一未被模型解释的差异；模型误差是已校准 nuisance。**这条假设必须被显式检验**（见 §2.3 负对照）。

### 2.2 离线：2⁴ 配对因子实验

| 因子 | 水平 0 | 水平 1 |
|---|---|---|
| P 个性化 | 无（population） | 实例 + 对手 |
| C 对比器 | v2 单帧阈值 | C3 + CUSUM |
| A 对手模型 | 无 | HAM |
| R 重做策略 | 无/固定 | DTE 效用 |

- 16 个 cell；每个 cell **配对种子**、**配对干扰脚本**（同一 episode 的“处理组/对照组”只差一个因子）；
- 指标：成功率、步骤分、**误报重做率**、恢复延迟、延迟方差、代理-真机相关 `ρ`；
- 估计：配对差 `Δ` + bootstrap 置信区间；报告**主效应与交互**（例如 P×C 是否互补）；
- **预注册**：`α`、`h`、效用权重 `(λ, μ, ν)` 在看结果前固定，避免“调参到显著”。

### 2.3 负对照（证伪用）

- **打乱干扰标签**：若增益仍显著，说明增益来自别的因素；
- **随机重做**：与 DTE 比，若差距消失，说明“效用”是装饰；
- **固定 `δ̂=0`**：若与 PIC 无差，说明个性化没抓住 nuisance；
- **只改背景/只改物体**的配对：检验对比器是否把“新奇”误当“撤回”。

### 2.4 配对数据如何反哺个性化（对比学习）

对每个因子 `f`，生成**只改 `f`** 的配对 episode。用 InfoNCE 训练实例编码器：同因子值跨 nuisance 变化为正样本，不同因子值但 nuisance 匹配为负样本。这样得到的 `e` 才能把“物体差异”与“进度差异”分开——这正是 §1.2 的 `δ̂` 可辨识的前提。

## 3. 个性化交互：把“被动重做”变成“主动防护”

| 层级 | 个性化对象 | 可观测信号 | 动作后果 |
|---|---|---|---|
| 实例级 | 未见物体/摆位/光照 | 首帧 RGB + language + 前若干 chunk | 校准 `δ̂`、调整抓取点/力控/`done_thr` |
| 交互级 | 干扰者风格/时机/目标 | 每次干预的类型、目标步、相对完成时刻 | 预测风险图 `ρ_j`，预防性防护与恢复排序 |

**关键约束**：防护动作必须落在任务允许的动作空间内，不能改变计分点顺序；能做的是“时机、路径、接触保持、容器开合、物件摆放位置”等**合法变体**。若手册最终禁止任何“防人”行为，UIP-18 退化为纯恢复排序，不影响 UIP-16/17/19。

## 4. 合成校准结果（先验证 ordering，不是真机结论）

> 脚本：`exp/cpai_sprt_sim.py`；结果：`exp/cpai_sprt_results.json`。**这是合成数据，不是机器人结果。**
> 生成模型：每子目标 8 个检查点；`H_0: x=δ+N(+1,1)`，`H_1`（从第 s 步起）：`x=δ+N(−1,1)`；`δ~N(0,0.8)` 为实例 nuisance；个性化用 3 个完好检查点估 `δ̂`。目标误报预算 5%/10%/20%，在 `H_0` 上把各方法调到同一误报率，再在 `H_1` 上比较。

**误报预算 5% 时（每子目标）：**

| 方法 | 误报率 | 检出率 | 平均延迟(检查点) | 期望损失* |
|---|---|---|---|---|
| v2 式单帧阈值（population） | 5.1% | 41.2% | 2.22 | 22.94 |
| 单帧阈值 + 实例个性化 | 5.0% | 51.3% | 2.23 | 19.39 |
| 两帧确认（population） | 4.9% | 40.8% | 2.69 | 23.51 |
| CUSUM（population） | 5.0% | 41.4% | 3.14 | 23.72 |
| **CUSUM + 个性化** | **4.8%** | **57.8%** | **2.71** | **17.58** |
| CUSUM + 真实 δ（oracle 上界） | 4.4% | 78.3% | 2.12 | 9.82 |

\* 期望损失 = `P_false·5 + P_miss·35 + delay·1`，仅为示意权重。

**误报预算 10% 时**：单帧 population 检出 51.1% → CUSUM+个性化 66.8%；损失 19.46 → 14.08（−28%）。20% 时：60.3% → 70.9%。

**读法（谨慎）**：

1. **ordering 与假设一致**：在**同等误报预算**下，个性化 + 序贯检测的检出率高于 v2 式单阈值（5% 预算下 57.8% vs 41.2%）；损失下降约 23–28%。
2. **个性化贡献最大**：仅加实例校准，单帧阈值就从 41.2%→51.3%；这说明“没见过”确实是误报主因（H1）。
3. **序贯检测的增益依赖“持续性”**：CUSUM 单独用（population）并不比单帧好，因为 nuisance 偏移会持续推高统计量；**必须先个性化再序贯**，两者是互补而非替代（P×C 交互）。
4. **上界仍很远**：oracle 78.3% vs 实现 57.8%，说明 `δ̂` 估计与模型误差仍是主要瓶颈——这正是需要真实配对样本“接地”的地方。
5. **每 episode 误报**：若每 episode 有 m=3 个子目标，5% 子目标误报 ⇒ 约 14% episode 误报；因此 `α_sub` 必须按 `1−(1−α_ep)^{1/m}` 收紧。

## 5. 与 v2 的差异（一句话版）

| 维度 | v2 | v3 |
|---|---|---|
| 撤回判据 | 单帧“像不像完成” | 个性化残差 + 序贯变化检测（有误报预算） |

| 对干扰者 | 当随机扰动 | 当可识别的交互策略，预测并预防 |
| 重做决策 | 硬状态机 + 次数上限 | 两种计分语义下的鲁棒效用最大化 |
| 实验 | 单因素对照 | 2⁴ 配对因子 + 负对照 + 预注册 |
| 块长 | 误以为可运行期自适应 | 明确 `T_a` 固定，离线选 + 块内设计 |

## 7. 合规与风险

- **单模型合规**：PIC/HAM 只增加条件输入与轻量头，共享同一骨干；外部 VLM 验证器仍不进入运行期。
- **反事实的证据源**：`F_θ` 与 `p_0/p_1` 必须用真实配对样本标定；否则 CUSUM 只是在检验模型偏差。
- **手册未知**：计分语义、5 轴定义、评测时限/频率仍待核实；DTE 的 `min(U_ever,U_final)` 与 `α_ep` 分配是对此的防御性设计。
- **接口红线**：`T_a` 固定、形状/dtype/token 严格；不要尝试“返回短块”或运行期改 `obs_delta_indices`。
- **对手建模的伦理/规则风险**：若规则不允许“防人”动作，UIP-18 仅保留恢复排序；不得做任何超出任务动作空间的干预。
