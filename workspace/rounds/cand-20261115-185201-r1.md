# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「需求洞察」×「虚实迁移」）

> R69 把不确定性一分为二——aleatoric（不可约噪声）交给 λ_floor，epistemic（可约动作歧义）交给「流匹配多模态策略 + 主动交互」。但两分仍默认了一个更深的给定：**目标函数 J（「要什么」）是已知且固定的**。R69 的 VoI 问的是「该选哪个动作模态」，不是「我在为谁、为什么优化」。真实系统里最贵的不确定性恰恰在目标侧：用户说「快点」而真实需求是「别洒」；说「随便」却会在某个隐含偏好上打分；需求还会随场景漂移。**R69 可以完美消歧动作，同时高效地把错事做对。**
>
> 本轮加入第三类不确定性——**规范不确定性 U_spec（需求 / 偏好 / 效用的不确定性）**，并用两个灵感各补一块：
> - **需求洞察**：把交互从「选动作」升级为「建模需求」——区分 stated 与 revealed，用比较式提问而非绝对打分，用 **EVPI（完美信息期望价值）** 判断「问这一句是否真的会改变行动」；
> - **虚实迁移**：数字孪生是廉价的需求假设生成器与「提问彩排」沙盘，但现实差距（reality gap）必须被证书化、被折扣；**仿真只能提议，不能定案**。
>
> 核心命题：**不确定性三分解 (U_ale, U_act, U_spec)；R69 管前两项，本轮把 U_spec 交给「虚实协同的需求洞察」，并用安全需求包络 SNE + minimax 后悔兜底保证——推断出的需求永远不能扩张动作可行域。** 命名 **VIRTUE-RAS**（Virtual-real Insight for Requirement-aware Task-Utility Elicitation）。
>
> 一句话定位：R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我到底该要什么，而且这个『要』是真的吗**」——从「动作不确定性」走到「目标不确定性」。

## 0. 直觉与动机

**灵感 1（需求洞察 → 目标本身是一个隐变量）**
直觉：人经常说不清自己要什么，甚至不知道自己不知道。直接问「你要多快 / 多安全 / 多安静」得到的绝对评分噪声大、易受措辞影响；但「A 还是 B」「如果能重来你会选哪个」这种**比较式 / 反事实**问题更稳定，因为它把回答锚定在同一个可想象的结局上。于是系统应维护一个 **need 后验 p(θ)**（θ 是一组可解释需求原子的权重），用选择行为与回答联合更新。关键洞察不是「熵大就问」，而是：**若所有需求假设对当前最优动作给出相同排序，问也白问**——所以需求不确定性的正确度量是**行动相关的 EVPI**，而不是后验熵。EVPI≈0 时，即使需求很模糊，也不值得开口。

**灵感 2（虚实迁移 → 廉价的假设生成与「提问彩排」）**
直觉：现实里问人昂贵、慢、有社交成本；而数字孪生可以**廉价彩排**——在仿真里放一组具有不同 need profile 的虚拟回答者，预演候选问题：「哪一句最能把这组需求分开」「哪一句明显在诱导」「问了之后动作会变吗」。这让系统在消耗真人的注意力之前，先筛掉无用甚至操纵性的问题。但虚拟回答者不是真人：仿真带着 reality gap、训练数据偏差与刻板印象。于是**仿真证据必须携带差距证书并按可靠性折扣**，它只负责提出假设与排列问题，不负责给需求盖章。

**灵感 3（三分解 → U_spec 与 U_act 正交，R69 看不见它）**
直觉：设想走廊里绕左/绕右两个动作模态都安全，U_act 很高；但如果用户真实需求是「别吵醒人」而系统以为「最快到达」，系统可能选出唯一一个「快但吵」的模态——此时动作层面可以毫无歧义（U_act≈0），**后悔却巨大**。这说明「动作不确定性」与「目标不确定性」是两个正交方向：前者问「怎么做」，后者问「做什么 / 为谁做」。R69 的所有机制对后者完全失明。R70 必须让 R69 成为「θ 退化为点质量、U_spec=0」的严格边界，而不是并列替代。

**灵感 4（安全与价值底座 → 推断需求不能扩张可行域）**
直觉：最危险的不是「问不到需求」，而是把**被仿真先验或误导答案塑造出来的假需求**当成真理去优化——这正是 specification gaming / reward hacking 的入口。所以三条硬规矩：(a) 硬安全约束与不可逆动作的可行性与 θ 无关，推断需求只能改「在安全集内偏好哪个」，不能改安全集本身；(b) 不可逆动作需要高置信或显式确认；(c) 需求未消解时，**不最大化一个可能错的期望效用，而是最小化最坏后悔（minimax regret）**——这是 R70 版「只收紧」铁律。这样「需求洞察」获得的效率永远不来自放松安全。

**灵感 5（虚实迁移是双刃剑 → 新的偏差与攻击面）**
直觉：一旦允许仿真参与需求建模，就出现「需求洗白」（先有想做的动作，再设计提问让它显得被需求授权）、仿真刻板印象放大（虚拟回答者把某类用户的偏好固化成先验）、需求漂移被当成噪声平滑掉、以及数字孪生被投毒。**仿真越像真的，越容易被误当成真的。** 因此本轮必须同时交付：reality-gap 证书与迁移安全门、非操纵性审计、需求漂移检测、仿真投毒干扰集，以及「单次回答不得定案」的证据纪律。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（VIRTUE-RAS 总览）** VIRTUE-RAS = (NIP, SUD, VRE, VRG, TSG, PEC, SNE, MRS, NDA, FMP†, RAS-WM†)。五不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **价值底座**：推断需求只能改变安全集内的偏好排序，**不得扩张动作可行域**；不可逆动作另需确认门（定义 319）；
(iii) **需求集可审计**：θ 取自有限、可解释、带显式「未知」质量 θ_∅ 的假设集，禁止无边界的黑箱 reward；
(iv) **仿真证据受证书约束**：无 VRG 证书的仿真证据不得进入后验，且有证书也只能按 ρ_gap 折扣、不得单独定案；
(v) **证据纪律**：单次回答 / 单一来源不得设定 θ；需 k 个正交证据一致，或 EVPI 在高置信下坍缩。

**定义 311（需求假设空间）** 需求原子集 A = {安全裕度, 速度, 彻底性, 舒适, 隐私, 社交打扰, 能耗}；需求假设 θ ∈ Θ = {θ_1,…,θ_M} ∪ {θ_∅}，θ 为原子权重，效用 J_θ(τ) = Σ_i θ_i φ_i(τ)（φ_i 为可观测结局特征）。θ_∅ 表示「未知 / 不拟合任何已知画像」，其后验质量 p_t(θ_∅) 是开放世界弃权的依据。后验 p_t(θ) 由语言指令、示范、历史选择、交互回答与（折扣后的）仿真先验联合更新。

**定义 312（不确定性三分解）** 给定动作集 A、需求后验 p、模态后验 w：
U_ale = Σ_k w_k tr(Σ_k)（模态内噪声，不可约，→ λ_floor）；
U_act = H_mode·g(Δ_min)（R69 的动作歧义，可约，→ 主动交互）；
U_spec = EVPI(Θ, p, A) = E_{θ∼p}[ max_{a∈A} J_θ(a) ] − max_{a∈A} E_{θ∼p}[ J_θ(a) ]（需求歧义的有效信息价值）。
三者语义不同、分通道处置；**U_spec 用 EVPI 而非熵**，因为「不影响动作排序的需求模糊」不值得花社交成本去问。

**定义 313（差距折扣的虚拟证据 DEB）** 设仿真似然 p_V(y|g,θ)，reality gap 指标 d_gap（定义 314），证书给出的迁移可靠度 ρ_gap ∈ [0,1]（ρ_gap = exp(−κ·d_gap) 或经验校准值）。真实似然用污染模型稳健化：p_R(y|g,θ) = (1−ρ_gap)·p_V(y|g,θ) + ρ_gap·q(y)，q 取参数邻域内的最坏情形分布（或对 y 均匀）。后验更新只用 p_R；于是**仿真证据对后验的最大推动量被 ρ_gap 硬性限制**。

**定义 314（虚实差距证书 VRG）** 在锚点场景集 𝒜_anchor 上做成对虚实回放，定义 d_gap = sup_{s∈𝒜_anchor} W_1(p_real(·|s), p_sim(·|s))（或需求相关统计量的最大偏差），证书 = (𝒜_anchor, d_gap, 适用域 D, 有效期, 签发哈希)。证书只在其适用域与有效期内有效；越域即失效。

**定义 315（迁移安全门 TSG）** 仿真预训练的需求先验 / 策略仅在 d_gap ≤ τ_gap 且成对回放的符号检验通过时获准作为先验；否则丢弃仿真先验，退回纯真实证据 + R69。TSG 是「仿真不能单独定案」的工程实现。

**定义 316（虚拟彩排引擎 VRE）** 给定候选交互 g 与需求假设集 Θ，用虚拟回答者集合 Y_sim 预演：VoI_sim(g) = EVPI_before − E_{y∼p_R}[EVPI_after(y)]；同时标注诱导性 / 选项偏置 / 刻板印象泄漏风险。VRE 只产生**候选问题排序**，不产生 posterior 定案。

**定义 317（偏好询问控制器 PEC）** 询问类型：比较选择（A vs B）、反事实（「如果能重来」）、示范请求、澄清提问。选择
g* = argmax_g [ ρ_gap·VoI_sim(g) − c(g) ]，s.t. 非操纵性约束与交互预算；
用置信上界 UCB(g) = ρ_gap·VoI_sim(g) + β·L_V·d_gap 保守化。若 UCB(g*) ≤ c(g*)：**不问，走规范保守兜底**（定义 320）。

**定义 318（需求后验更新与证据纪律）** 比较式回答用随机效用 / Bradley–Terry 似然建模（带温度），避免把「勉强选 A」当「强烈偏好 A」。更新采用定义 313 的 p_R；保留未知质量下界 ε_∅（p(θ_∅) ≥ ε_∅）。单次回答只提供似然，不单独定案；定案需 k 个正交证据（语言 / 示范 / 选择 / 询问）一致，或 EVPI 在高置信下坍缩到阈值以下。

**定义 319（安全需求包络 SNE）** 设 𝒮 为可接受需求集（由价值底座与不可逆性约束定义），投影 Π_𝒮。若 Π_𝒮(p) 的投影距离 > δ_proj，标记「需求越界」并拒绝据此行动。不可逆动作集 ℐ 需满足 p(θ 的偏好排序在 a 上一致) ≥ 1−δ_irr，或获得显式人类确认；硬约束的可行性**与 θ 无关**。

**定义 320（规范保守兜底 MRS）** 若 U_spec 未消解 / VRG 失效 / 漂移告警 / 审计失败，选择
a* = argmin_{a∈A_safe} max_{θ∈supp(p)} Regret_θ(a)，Regret_θ(a) = max_{a'} J_θ(a') − J_θ(a)。
即**最小化最坏后悔**而非最大化期望效用。这是 R70 版「只收紧」；当 p 退化为点质量（U_spec=0）时，MRS 与 R69 的效用最大化选择逐指令一致。

**定义 321（需求漂移检测 NDA）** 对选择一致性残差 e_t = 1[choice_t ≠ argmax_a E_{θ∼p_t} J_θ(a)] 做 CUSUM；超阈值即判定需求漂移：向 p 重新注入熵（抬高 θ_∅ 与邻域质量），在预算内重开询问，并把漂移事件写入审计。

**定义 322（需求原子库与跨任务虚实迁移）** 可复用需求原子库 𝒜_lib 跨任务迁移；每个原子携带来源（真实 / 仿真）、VRG 证书 id、适用域。跨任务使用前须过 TSG；这使「需求洞察」可积累，但每一份积累都可追溯来源与可信度。

**定义 323（非操纵性审计 VQAuditor-N）** 审计：问句是否诱导（预设答案 / 情绪施压）、选项集是否对称、是否重复逼问、是否泄漏仿真刻板印象、是否忽视「未知」、是否过度打扰。结论回灌 AuditBuf，成为下一轮 PEC 的成本与约束先验。

**定义 324（需求侧威胁模型 ℰ_need）** 偏差 / 对抗性回答、数字孪生投毒、仿真刻板印象、需求洗白（先定动作再用提问背书）、奖励黑客、需求漂移、开放世界漏假设（真实需求不在 Θ 中）。并入 AIC：ℰ_VIRTUE = ℰ_FLUID × ℰ_need。

**定义 325（证书 J_VIRTUE）** J_VIRTUE = (J_FLUID, θ 后验哈希, U_spec_before, U_spec_after, evpi_ratio, vrg_cert_id, d_gap, rehearsal_log_hash, nonmanip_score, sne_projection_flag, drift_flag, virtue_ver)。Valid ⇔ Valid(J_FLUID) ∧ VRG 在域内有效 ∧ SNE 未越界 ∧ 证据纪律满足 ∧ 非操纵性达标。

**定义 326（与 R69 的组合）** FMP 条件由 z_t 扩为 (z_t, θ)：采样时按 p_t 取 θ（Thompson）或对 θ 求混合；动作模态选择仍走 R69 的 γ_cal / λ_floor，只在「效用目标」处换成 J_θ。U_ale 与 U_act 的处置完全继承 R69，保证安全侧不回退。

**定义 327（预算与时延）** |Θ| ≤ 4（含 θ_∅）；VRE 彩排离线 / 异步；实时路径只做后验更新、UCB 判定与 SNE 投影，P99 预算与 R69 同量级（< 3.0ms）。仿真重彩排以「问题缓存 + 证书复用」摊销。

**定义 328（开放世界弃权）** 若 p(θ_∅) > τ_∅，或所有候选问题的 UCB ≤ 成本，或 SNE 越界：系统必须**弃权于不可逆动作**并请求显式确认 / 拒绝执行。「知道自己不知道对方要什么」是合法且被鼓励的输出，而不是必须被填满的空洞。

```python
# IP-264 NIP：需求后验（语言/示范/选择/询问 + 折扣仿真先验）
class NeedInsightPosterior:
    def __init__(self, atoms, vrg, tsg, eps_unknown=0.05):
        self.Theta = enumerate_need_hypotheses(atoms) + [THETA_UNKNOWN]
        self.vrg, self.tsg, self.eps = vrg, tsg, eps_unknown
        self.p = uniform_with_unknown(self.Theta, self.eps)

    def update(self, evidence, source):
        if source == 'sim':
            if not self.vrg.valid_for(evidence.domain): return self.p   # 无证书不采纳
            if not self.tsg.allow(self.vrg):           return self.p   # 差距过大
            lh = gap_discounted_likelihood(evidence, self.vrg.rho)     # 定义 313
        else:
            lh = real_likelihood(evidence)                              # 比较式/示范
        q = bayes(self.p, lh)
        return project_unknown_floor(q, self.eps)                       # 证据纪律

# IP-265 SUD：三分解 + EVPI（行动相关，而非熵）
def decompose_three(U_ale, U_act, Theta, p, A_safe):
    evpi = expected_max_utility(Theta, p, A_safe) - max_expected_utility(Theta, p, A_safe)
    return U_ale, U_act, max(evpi, 0.0)        # U_spec = EVPI

# IP-267 VRE：仿真里彩排候选问题（只排序，不定案）
def rehearse_questions(candidates, Theta, vrg):
    out = []
    for g in candidates:
        if not nonmanipulation_filter(g): continue
        y_sim = virtual_respondents(g, Theta)          # 不同 need profile
        voi = evpi_before - mean(evpi_after(y) for y in y_sim)
        out.append((g, voi, risk_of_leading(g), stereotyping_risk(g)))
    return sorted(out, key=lambda z: z[1], reverse=True)

# IP-268 PEC：差距折扣的 UCB 询问决策（无利可图即兜底）
def choose_question(ranked, vrg, budget, beta=1.0):
    best = None
    for g, voi_sim, lead, stereo in ranked:
        if lead > TAU_LEAD or stereo > TAU_STEREO: continue
        if not budget.allow(g):                    continue
        ucb = vrg.rho * voi_sim + beta * L_V * vrg.d_gap   # 定义 317
        score = ucb - social_cost(g)
        if best is None or score > best.score: best = (g, score)
    return best[0] if best and best.score > 0 else None    # 不求助 → MRS

# IP-270 MRS：需求未消解时的规范保守选择（minimax regret）
def minimax_regret_select(Theta, p, A_safe):
    supp = [th for th in Theta if p[th] > TAU_MASS]
    def worst_regret(a):
        return max(max(J(th, a2) for a2 in A_safe) - J(th, a) for th in supp)
    return min(A_safe, key=worst_regret)                   # θ 点质量时 = R69

    # 1) R69：动作层（aleatoric + action-epistemic）
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_act, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    # 2) R70：需求层（EVPI，而非熵）
    M.nip.update(recent_evidence(obs, human), source='real')
    M.nip.update(sim_prior(obs), source='sim')                  # 过 VRG/TSG
    U_ale, U_act, U_spec = M.sud.decompose_three(U_ale, U_act,
                                                 M.nip.Theta, M.nip.p, M.safe.A)
    # 3) 需求可约且值得问 → 虚实彩排 + 询问；否则规范保守
    g = None
    if U_spec > TAU_SPEC:
        ranked = M.vre.rehearse_questions(candidate_questions(M.nip), M.nip.Theta, M.vrg)
        g = M.pec.choose_question(ranked, M.vrg, M.budget)
    if g is not None:

    # 4) 动作层仍走 R69 的 λ / 认证；目标层用后验或 MRS
    U_floor = U_ale + (U_act if M.action_unresolved() else 0.0)

    else:
        a_star = M.fmp.select_modes(modes, M.nip.p, lam)        # 用 J_θ 选模态
    # 5) 不可逆动作确认门 + 漂移 + 审计 + 证书
    a_star = M.sne.irreversibility_gate(a_star, M.nip.p, human)
    M.nda.step(human.last_choice, M.nip.p)
    M.vqa_n.submit_async(g, ans if g else None, U_spec, M.vrg, M.nip.p)
    return k, lam, a_star, (U_ale, U_act, U_spec)
```

## 3. 推导

**引理 19（EVPI 是需求不确定性的行动相关度量）** EVPI ≥ 0；EVPI = 0 当且仅当存在一个动作在 supp(p) 中所有 θ 下同时最优（或所有 θ 的最优动作一致）。且 EVPI ≤ H(θ)·L_J，其中 L_J 为效用对需求原子权重的 Lipschitz 常数。要点：**需求熵大但 EVPI 小，说明问也白问**；EVPI 大才值得付出社交成本。这解释了为何 R70 的询问门控不能沿用 R69 的熵阈值。

**引理 20（仿真彩排的 VoI 误差上界）** 设真实 VoI 与仿真 VoI 对似然的依赖是 L_V-Lipschitz，则 |VoI_real(g) − VoI_sim(g)| ≤ L_V·d_gap + O(ε_sim)。故按定义 317 的 ρ_gap 折扣与 β·L_V·d_gap 的 UCB 保守化，可在高概率下不把「仿真觉得值钱、现实不值钱」的问题问出去。系：**reality gap 直接转化为询问的假阳性成本上界。**

**引理 21（MRS 的安全退化）** 当 p 退化为点质量 θ_0（U_spec=0）时，minimax regret 选择与 R69 的效用最大化选择逐指令一致；当 supp(p) 扩大时，MRS 的最坏后悔 ≤ 期望效用最大化策略的最坏后悔。故规范保守兜底不会比 R69 更冒险，且严格优于「在错误 θ 下最大化期望效用」。

**定理 18（VIRTUE 严格包含 R69）** 在定义 310 不变式与 A95–A99 下，VIRTUE 的期望后悔（对真实 θ*）≤ R69；且当 U_spec ≤ τ_spec、VRG 失效、或 R69 的询问门控不触发时，两者在动作层逐指令相同。R69 是 VIRTUE 在「目标已知、仿真不可信」边界上的退化：安全侧不让步，目标侧获得 EVPI 收益。

**定理 19（规范不确定性的可分离收益）** 存在状态 s 使 R69 的 U_act = 0（动作无歧义）而 U_spec > 0（目标错误），此时 R69 的后悔 ≥ EVPI − c(g*)；VIRTUE 通过一次有效询问把后悔降到 ≤ c(g*) + ε_σ。故 R70 不是对 R69 的重包装，而是覆盖了一个 R69 结构上无法观测的失效模式——**「做对动作，做错需求」**。

**定理 20（价值底座与不可逆安全）** 在 SNE 投影 + 不可逆确认门下，即使需求后验完全错误，违反硬约束的概率为 0（硬约束与 θ 无关）；不可逆动作被错误授权的概率 ≤ δ_irr + δ_proj + δ_drift（分别由确认门、投影越界拒绝、漂移检测给出）。故「需求洞察」的效率收益不来自放松安全，而来自在安全集内更快选对偏好。

## 4. 推导

**引理 19（EVPI 的行动相关性）** `EVPI≥0`；`EVPI=0` 当且仅当存在动作在 `supp(p)` 的所有 θ 下同时最优；且 `EVPI ≤ H(θ)·L_J`。系：需求熵大但 EVPI 小 ⇒ 问也白问。

**引理 20（彩排 VoI 误差界）** 若 VoI 对似然 L_V-Lipschitz，则 `|VoI_real−VoI_sim| ≤ L_V·d_gap + O(ε_sim)`；故 `ρ_gap` 折扣 + `β·L_V·d_gap` UCB 可控制「仿真值钱、现实不值钱」的假阳性成本。

**引理 21（MRS 安全退化）** p 为点质量时 MRS 与 R69 效用最大化逐指令一致；supp(p) 扩大时 MRS 最坏后悔 ≤ 期望效用最大化策略最坏后悔。

**定理 18（VIRTUE 严格包含 R69）** 定义 310 + A95–A99 下，VIRTUE 对真实 θ* 的期望后悔 ≤ R69；当 `U_spec≤τ_spec`、VRG 失效或 R69 门控不触发时动作层逐指令相同。R69 = 目标已知、仿真不可信边界上的退化。

**定理 19（规范不确定性的可分离收益）** 存在状态使 R69 的 `U_act=0` 而 `U_spec>0`：R69 后悔 ≥ `EVPI−c(g*)`；VIRTUE 一次有效询问后 ≤ `c(g*)+ε_σ`。故 R70 覆盖了 R69 结构上看不见的「做对动作、做错需求」。

**定理 20（价值底座与不可逆安全）** SNE + 确认门下，硬约束违规概率为 0（与 θ 无关）；不可逆动作误授权概率 ≤ `δ_irr+δ_proj+δ_drift`。效率收益不来自放松安全。

## 8. 本轮最大风险

**一句话**：VIRTUE-RAS 的全部目标侧收益押在「需求假设集 Θ 覆盖真实需求、且被询者的回答比其行为更可信」这一前提上——一旦 Θ 被仿真先验与刻板印象塑形而漏掉真实需求，或 stated 与 revealed 偏好系统性背离，系统会把一个**被证书与审计层层背书的假需求**当成真理；此时它比 R69 更危险：R69 只是把错事做慢，R70 却可能**自信而高效地做错事**。

**次级风险与缓解**：仿真刻板印象/投毒（TSG + VRG + ℰ_need + E315）；需求洗白/诱导提问（VQAuditor-N + 选项对称 + E308）；开放世界漏假设（θ_∅ 下界 + 弃权/确认 + E306）；需求漂移被平滑（CUSUM + 熵重注入 + E307）；推断需求扩张可行域（SNE + 不可逆门 + MRS + 定理 20）。
