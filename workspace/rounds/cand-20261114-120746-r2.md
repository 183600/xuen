# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~301；灵感循环第 4 轮；本轮灵感：「具身智能大模型」×「消融实验」）

> R73 用 MMS/DPEM/CCA/ΣREFLEX/CPB 把「证据」做成了可组合契约，但留下两个**层级**问题：
> - **谁在说话**：MODGAUGE 计量的是传感器证据，不是**语义提议**。具身智能大模型（VLA / 世界模型 / 语言规划器）一旦进入闭环，输出的是一条**无类型、无预算、无否决语义的提议**——指代错误、常识幻觉、能力越界、上下文漂移、提示注入都能直接变成动作。R73 的 EC 能包住深度计和触觉垫，却包不住一个「会说话的策略」。
> - **怎么证伪**：CPB 要求 C1/C2/C3 各有隔离消融，但 R73 从没定义「消融」到底是什么操作。直接删模块会破坏契约、混淆容量、方向不可预测——复杂系统里的消融极易退化成「给写好的故事配图」。**主张可证伪**是论文的命门，而 R73 只给了消融的**位置**，没给消融的**语义**。
>
> 本轮两个灵感正好补这两层：
> - **具身智能大模型** → **PCS（提议-认证分离）+ SEM（语义证据计量）+ GBC（接地桥契约）+ CCE（能力证书包络）**：大模型只能**提议**，不能**认证**；提议进入控制前，每条原子主张必须被计量证据**结清**（discharge）。FM 成为一个带**权限格**的 EC 模块，热替换只重认证该模块。
> - **消融实验** → **ABA（消融代数）+ ABP（消融协议）+ AIM（隔离矩阵）**：把「删组件」升级为**契约保持的干预算子**；借 R73 组合单调性给出**方向性预测**（消融不该让安全变好）；用隔离矩阵检验三条主张是否真的可分离。
>
> 核心命题：**不问「这个具身大模型可信吗」，而问「它的提议能否被证据逐条结清，它的贡献能否在契约保持的干预下被可证伪地隔离？」**——**EFM-GAUGE-RAS**（Embodied Foundation Model — Grounded Audit under Gauge Evidence）＋ **消融代数**。

## 0. 直觉与动机

**灵感 1（具身大模型 = 会说话的证人，不是测量仪器）**
直觉：R73 每条证据都有物理生成机制，可校准、可追溯、可否决；大模型不一样——它输出的是**提议**（「把杯子放左边」「这条路能走」「用户要红色那件」），来源是语言/互联网先验，没有逐条不确定度、没有有效域、没有否决语义，而且自报置信经常不校准。把 FM 当「又一个观测 y」喂进 BSE，等于**把证词当物证**。

结构直觉（PCS）：**大模型可以扩大「可提议集」，但绝不能扩大「可认证集」。** 在证据预算固定时，更强的 FM 只应提高提案被接受的比例（效率），不能抬高安全界（safety）。这与 R72/R73「安全侧只增不减」同源，只是从物理模态延伸到语义模态：**更强的智能体不能买到更弱的审计**。

但「提议不能直接执行」还不够，还要回答「怎样才算结清」。于是 **GBC**：把提议拆成**原子主张**（对象身份 GROUND、可抓取性 AFFORD、路径自由 PATH、人类意图 INTENT、动作前提 PRECOND……），每条主张声明所需证据类型与阈值；能被证据结清的主张进入认证路径，不能的标为 unverified，只能降至低权限或请求人类确认。**CEL（主张-证据账本）** 逐条记录「谁说的、哪条证据结清的、u 多少、域是否满足、权限几何」，把追溯从传感器级下沉到**语义级**——出事后能回答「哪个主张错了、哪条证据该结清却没结清」。

FM 的不确定度同样有结构，**SEM 六分量**：u_ground（指代接地）、u_sem（指令语义歧义）、u_afford（动作可负担性）、u_skill（任务能力/包络外风险）、u_calib（自报置信校准）、u_ctx（上下文漂移/注入）。它与 DPEM 六分量、DMEM 四分量同构：各有独立机制、独立追溯、条件近似独立，漏一项就系统性低估。差别在噪声来源：深度/接触来自**物理**，语义来自**数据分布与语言**——所以 SEM 的校准必须做**分布偏移审计**，不能只报 IID 的 ECE。

权限格（CCE）：A2 全权（提议可直接触发已认证动作）、A1 顾问（须经典认证器或人类背书）、A0 影子（只记录）、A∅ 静默。能力证书包络给出 FM 在哪些 (任务、对象、上下文) 上够得上 A2；出包络即自动降格。**降格是格上的单调下降**，A∅ 与 R73 的 stub 语义重合——R73 的「零级联」因此对 FM 也成立。

**灵感 2（消融实验 = 对论文主张做因果计量）**
直觉：R73 的 CPB 要求 AB1–AB3，但没定义「消融」这个动作。直接删模块有三宗罪：(i) **契约破坏**——删掉一个模块会改变下游输入类型，测到的是另一个系统；(ii) **容量混淆**——删掉大模块同时删掉参数/算力/时延，效应无法归因给「计量」本身；(iii) **方向不可证伪**——跑出一个数就能讲故事，没有事前预测。

把消融形式化为 MReg 上的**干预算子**（do 语义）：
- `STUB(m)`：契约保持地替换为 R73 定义 381 的 stub——问「没有这条证据会怎样」；
- `PLACEBO(m)`：容量匹配、信息破坏的安慰剂（同参数量随机初始化/权重打乱/输入置换）——把「计量贡献」与「容量贡献」分开；
- `ORACLE(m)`：换成 ground-truth 证据——给出上界与余量（headroom），回答「这条证据最多还值多少」；
- `OFF(χ)` / `SCRAMBLE(φ)` / `SHUFFLE(ctx)` / `CUT(τ)`：分别关反作用通道、打乱某个不确定度分量、打乱上下文、切断追溯链——每个精确对应一条主张或一个不变式；
- `DROP(m)`：唯一改变契约的结构性干预，只许探索，必须重过 CCA，不能进确认性结论。

有效性三条：**契约保持**（确认性消融必须是同 EC 实现替换）、**单调相容**（由 R73 引理 34，STUB 不该让安全指标变好；变好即契约/主张被证伪，而不是「消融有效」）、**无旁路混淆**（报告算力/时延/内存，PLACEBO 匹配容量）。三条把消融从「讲故事」变成「可证伪」。

再进一步，消融是**论文主张的计量**：**AIM 隔离矩阵**，行=组件、列=各主张的预注册指标。理想情况对角占优（删 C1 组件最伤 C1 指标，不是最伤 C2/C3）；若 off-diagonal 很大，说明主张不可分离，CPB 蒸馏失败——这正是 E390「无孤悬组件」的定量版本。再加 null ablation（同实现重建）测噪声地板、placebo 控容量、功效分析与预注册 MDE，消融才配得上「实验」二字。

**灵感 3（合起来：运行时结清提议，论文时结清主张）**
直觉：PCS/GBC 在**运行时**逐条结清语义主张；ABA/ABP 在**论文时**逐条结清科学主张。两者共享同一种证明义务：主张必须绑定可复算的证据/干预，并允许被证伪。R73 的 CPB 只说「要有消融」，R74 说「消融必须是什么算子、朝哪个方向、隔离到什么程度」。这一步把「有实验」变成「有方法论」。

## 1. 形式化定义（增量：定义 383–399）

**定义 383（EFM-GAUGE-RAS 总览与六不变式）** EFM-GAUGE-RAS = (PCS, SEM, GBC, CCE, ABA, ABP, MODGAUGE-RAS†)。六不变式：
(i) **契约完整性**（继承）：模块图中每个节点实例化完整证据契约（R73 定义 367）；
(ii) **组合单调性**（继承）：所有组合路径经 CCA 校验（R73 定义 370），无「凭空变好」；
(iii) **反作用通道完备**（继承，含 χ_efm）：每个证据模块声明反作用通道，ΣREFLEX 预算闭合；
(iv) **提议-认证分离**：控制域只接受 `Certified[T]`；`Proposal[T]` 不允许直接进入控制路径；
(v) **主张结清**：进入 `Certified` 的每个原子主张在 CEL 中有 discharge 记录（证据引用 + u + D + 追溯链）；
(vi) **消融可证伪**：每条 CPB 主张绑定预注册干预族 + 方向预测 + 隔离判据；无消融绑定的组件不得作为贡献声明。

**定义 384（提议-认证类型系统 PCS）**
- `Proposal[T] = (t, content, π, ctx, src, prov)`，content 为原子主张元组，π 为 FM 自报置信（不可信）；
- `Evidence[T]` 由 EC 模块产生（R73 定义 367）；
- 唯一构造规则 `certify: Proposal[T] × CEL × 𝒰_budget → Certified[T] ⊎ Reject`：仅当 ∀c∈content 存在 discharge 证据 e 使 u_e ≤ τ_c、D_c 满足、I⊥ 为空时成功；
- **私有构造**：`Certified` 只能由 `certify` 产生，FM 无法实例化；
- **安全不变式**：`CertifiedSet(Evidence)` 与 FM 实现无关，只依赖证据与 CEL。

**定义 385（语义证据计量 SEM）**
u_efm² = u_ground² + u_sem² + u_afford² + u_skill² + u_calib² + u_ctx²，
- u_ground：指代接地（多视角/多模态一致性残差，复用 DPEM/DMEM 的 s 估计）；
- u_sem：指令歧义（conformal 语义解释集大小/熵）；
- u_afford：动作可负担性（在 D_depth ∩ D_contact 上的可行域体积与边界距离）；
- u_skill：任务能力（CCE 失效率 + 共形上界）；
- u_calib：自报置信与经验正确率的偏差（ECE 型）；
- u_ctx：上下文漂移/记忆不一致/注入指示。
有效域 D_efm = {task∈T_cert ∧ u_ground<τ_g ∧ u_skill<τ_s ∧ ¬injection ∧ u_ctx<τ_c}。**反作用通道 χ_efm**：动作与询问改变上下文与视角 → 改变 (u_ground, u_skill, u_ctx)——这是 R73「层数=模块声明」的直接兑现（不需要新主闭环分支）。

**定义 386（接地桥契约 GBC）**
GBC = (𝒞_atom, ρ, τ_c, discharge, α_map)：
- 𝒞_atom = {GROUND(obj), AFFORD(obj,act), PATH(free), INTENT(human), PRECOND(act), SAFE(grip), …}，|𝒞_atom| ≤ 32；
- ρ: 𝒞_atom → 2^{证据类型}：每条主张需要哪些证据；
- τ_c：主张级阈值；discharge(c, E) ∈ {discharged, unverified, vetoed}；
- α_map: 𝒞_atom × 状态 → 权限格（默认由 CCE 决定）。
**主张原子化（claim atomization）必须由独立于 FM 的解析器完成**——否则 FM 可以「挑选容易结清的措辞」，即 discharge gaming（见风险 8）。

**定义 387（主张-证据账本 CEL）**
只追加、哈希链的账本，条目 e = (t, claim_id, src∈{FM, evidence}, rule, refs, u, D, status, auth, chain_hash)。接口：`coverage(t)` = 已结清主张/总主张；`blame(claim)` = 该主张的全部相关条目；`hash_ok()` = 哈希链完整。CEL 是 J_MOD 的**运行时对偶**。

**定义 388（能力证书包络 CCE）**
CCE = (T_cert, D_cert, ε, 1−α, expiry, calibration_set=SEAL-EFM)。T_cert 内经验风险 ≤ ε 且共形覆盖 ≥ 1−α 才授予 A2。权限格 A∅ ⊏ A0 ⊏ A1 ⊏ A2，`degrade` 对 SEM 证据逐分量单调下降；A∅ 的实现等价于 R73 stub。

**定义 389（FM 作为 EC 模块）**
FM 的 EC：T_in=(instruction, obs, ctx)，T_out=Proposal，𝒰_in=上下文/证据预算，𝒰_out=SEM 六分量，χ_R=χ_efm，D=D_efm，τ_merge=CEL 链接，I⊥={unsafe-intent, ungrounded, injection}，W=端到端时延，seal_ref=SEAL-EFM。**权限级别写入契约**，因此热替换的等价性检查包含 CCE 形状。

**定义 390（消融干预算子 ABA）**
对 MReg 的 do 算子：STUB、PLACEBO、ORACLE、OFF(χ_R)、SCRAMBLE(φ)、SHUFFLE(ctx)、CUT(τ)、DROP。算子可复合 `do(α₂)∘do(α₁)`；每个产出 (MReg′, 干预标签, 旁路计量)。DROP 标记为结构干预，其余为契约保持干预。

**定义 391（干预有效性）**
确认性干预有效 ⇔ (1) 类型/EC 保持（DROP 除外，且 DROP 必须重过 CCA）；(2) 无未声明旁路（算力/时延/内存/随机源受控并记录）；(3) PLACEBO 容量与架构匹配；(4) 全部变更写入消融账本。违者只能作探索性证据。

**定义 392（消融估计量）**
对指标 Y 与干预 α：Δ_α = E[Y | do(α)] − E[Y | do(∅)]；按场景/种子配对、分块估计；报告效应量、置信区间与等价界。方向预测 s(α) ∈ {≤0, ≥0} 由 R73 单调性给出。

**定义 393（消融隔离矩阵 AIM）**
AIM[i,j] = 标准化 |Δ_{α_i}^{metric_j}|；隔离分 Iso_j = diag_j / (max_{i≠j} offdiag + ε)。主张可分离 ⇔ ∀j, Iso_j ≥ κ 且 offdiag ≤ δ（κ、δ 预注册）。

**定义 394（单调消融检验 MAT）**
安全类指标预测 Δ_STUB ≤ 0（等价界 δ_safe 内）；能力类指标预测 Δ_STUB ≤ 0。若观测到 Δ_STUB > δ_safe 且 CI 排除零 ⇒ **契约或主张被证伪**，不是「负消融」的胜利。对 C2 预注册偏序：STUB(ΣREFLEX) ≺ OFF(χ_v) ≺ full（成本/交互）。

**定义 395（零消融与安慰剂消融）**
null：以同实现重建（新种子/新哈希）；其效应必须落在 null CI 内。placebo：容量匹配、信息破坏。**真实计量效应** = Δ_α − Δ_placebo 超出 null CI 的部分；只有它才算主张证据。

**定义 396（预注册与功效 ABP）**
每条主张预注册：干预族、指标、MDE、α、power ≥ 0.8、种子数、排除规则、分析计划、封印哈希。只有预注册分析进 CPB；事后分析一律标 exploratory。

**定义 397（提议拒绝与权限降级）**
Reject(t) → A1/A0；unverified → A1 或 human query；vetoed（unsafe/ungrounded/injection）→ A0/A∅。降级路径单调；A∅ 时 FM 不产生观测，等价 R73 stub，**零级联**。

**定义 398（EFM 复杂度结构上限）**
|𝒞_atom|≤32、|T_cert|≤64、SEM 分量=6、每条主张的干预族≤8、消融总干预≤|V_M|·8、CEL 条目按窗口滚动、`certify` 单次 ≤2ms。全部为可审计结构性质（继承 R73 定义 377）。

**定义 399（严格退化链）**
FM=A∅、GBC 平凡、ABA 为空 ⇒ EFM-GAUGE 逐指令退化为 MODGAUGE；再退化到 R72/R71/R68。降级方向安全单调不增，效率单调不增。

# IP-302 PCS：提议-认证类型系统（Certified 私有构造，FM 无法伪造）
@dataclass(frozen=True)
class Proposal:
    t: type; content: Tuple[Claim, ...]; pi: float
    ctx: Context; src: str; prov: str

class Certified:
    __slots__ = ('t', 'content', 'cel_ref', 'u')
    def __init__(self, *_): raise TypeError("Certified is constructed only by certify()")
    @classmethod
    def _make(cls, p, cel, ev):
        c = object.__new__(cls); c.t, c.content, c.cel_ref = p.t, p.content, cel
        c.u = max(e.u for e in ev); return c

def certify(p, cel, budget):
    if p.t not in CCE.envelope:  return Reject('OUT_OF_ENVELOPE')
    need = 0.0
    for c in p.content:                                   # 逐条主张结清
        rules = GBC.rho(c)
        ev = [cel.lookup(r) for r in rules]
        if any(e is None for e in ev):   return Reject('UNVERIFIED', c)
        if any(e.veto for e in ev):      return Reject('VETOED', c)
        if not all(e.u <= GBC.tau(c) and GBC.domain_ok(c, e) for e in ev):
            return Reject('UNVERIFIED', c)
        need += max(e.u for e in ev)
    if budget.remaining() < need:        return Reject('BUDGET')
    return Certified._make(p, cel, ev)                    # 唯一合法构造
```

def sem_update(p, obs, ctx, hist):
    u_ground = grounding_residual(p.content, obs.rgb, obs.depth, obs.tac)
    u_sem    = semantic_conformal_set(p).size

# IP-304 GBC + CEL：把语义主张结清并记账
class GroundingBridge:
    def discharge(self, c, cel):
        ev = cel.materialize(self.rho(c))
        if ev is None:              return 'unverified'
        if any(e.veto for e in ev): return 'vetoed'
        return 'discharged' if all(e.u <= self.tau(c) and self.domain_ok(c, e)
                                   for e in ev) else 'unverified'

class CEL:
    def append(self, t, claim, src, rule, refs, u, D, status, auth):
        h = H(self.tail, t, claim, tuple(refs), u, status)
        self.entries.append(Entry(t, claim, src, rule, refs, u, D, status, auth, h))
        self.tail = h
    def coverage(self, t):
        es = [e for e in self.entries if e.t == t and e.src == 'FM']
        return sum(e.status == 'discharged' for e in es) / max(len(es), 1)
    def blame(self, claim): return [e for e in self.entries if e.claim == claim]

    if sem.u_ctx > TAU_CTX:              a = min(a, A.SHADOW)

    return a
```

def do(mreg, op):

    elif op.kind == 'SCRAMBLE': m2 = mreg.permute_field(op.m, op.field)
    elif op.kind == 'SHUFFLE':  m2 = mreg.shuffle_context(op.m)
    elif op.kind == 'CUT':      m2 = mreg.cut_provenance(op.m)
    elif op.kind == 'DROP':     m2 = mreg.remove_and_rewire(op.m); CCA.validate(m2)
    assert interven_valid(op, m2)                     # 定义 391
    return m2

## 3. 推导

**假设增量**：A114（提议完整性：FM 的提议可被独立解析器忠实分解为原子主张）；A115（证据-主张可结清性：存在证据类型与阈值使真主张可结清、假主张不可，即 discharge 有判别力）；A116（CCE 校准不被分布偏移破坏，或偏移可被 u_ctx 检出）。

**引理 38（SEM 六分量的条件正交性）** 给定 (task, object, context) 条件下，六分量由独立机制产生：接地=跨模态关联、语义=语言解释、可负担性=物理可行性、能力=策略分布、校准=置信报告、上下文=输入分布。条件近似不相关；遗漏任一 ⇒ 系统性低估（与引理 33/30 同型）。注意 u_skill 与 u_ground 在 OOD 下可能相关，故必须条件于 OOD 分数。系：**语义证据不是「再报一个 softmax 熵」，而是把语言/数据/物理三类噪声分离。**

**引理 39（PCS 类型安全：FM 能力不进安全界）** `Certified` 私有构造，`certify` 只引用 Evidence 与 CEL，不引用 FM 内部。故固定证据预算下 `CertifiedSet` 与 FM 选择无关；更强 FM 只改变 `Pr[certify 接受]`（效率），不改变认证集（安全）。系：**换 FM 不改定理 28 的安全界**——这是 FM 热替换可行的根。

**引理 40（CCE 与权限格的单调退化）** `authority` 对 SEM 证据逐分量单调；格上 min 单调 ⇒ 证据变差时权限只降不升。A∅ 等价 R73 stub ⇒ 由定理 29 得零级联。系：**FM 的失效传染路径同样只有一条（该提议不被认证），不污染其他模态。**

**引理 41（干预有效性 ⇒ 因果可解释）** 若干预保持 EC 且无旁路变化，则系统级指标差异只能归因于该模块的**证据函数**；若为 DROP，则只能归因于图结构，不能归因于模块。系：**确认性消融必须是 STUB/PLACEBO/ORACLE/OFF/SCRAMBLE/SHUFFLE/CUT，DROP 只能探索。**

**引理 42（单调消融检验的检出力）** R73 单调性 ⇒ STUB 不可能提高认证安全。单侧假设 H0: Δ_STUB ≤ δ_safe，方向已知使单侧检验检出力高于双侧；若真实效应为「变好」，则拒绝 H0，结论是**契约/主张被证伪**而非「负消融」。系：**把「消融意外变好」从尴尬变成信号。**

**引理 43（AIM 的分离判据）** 若 C1/C2/C3 由互异机制生成，则各条效应集中于对角；若能观测到 offdiag > δ，则要么主张共享机制（蒸馏不成立），要么指标不特异（测量污染）。二者都可操作：前者合并主张，后者换指标。系：**主张可分离性第一次成为可测的统计命题。**

**定理 30（EFM-GAUGE 严格包含 MODGAUGE）** 在 A114–A116 下：FM=A∅、GBC 平凡、ABA 为空时，PCS 退化为恒等、SEM 退化空证据、CCE 退化 A∅ stub ⇒ 逐指令等于 R73；再退化 R72/R71/R68。安全/效率单调不增。

**定理 31（提议-认证分离的端到端安全）** 若 (i) certify 可靠（引理 39）、(ii) CCE 校准（覆盖 ≥1−α）、(iii) CEL 完整（每个被执行主张都有 discharge 记录），则 FM 来源动作的物理风险 ≤ ε_mod + ε_sem + ε_cce，**与 FM 能力无关**。证明：J_EFM 四项分别由引理 39、定理 28、共形覆盖、CEL 完整性给出；FM 只影响接受率，不进安全项。

**定理 32（消融可归因性 / 主张可分离）** 若预注册干预族满足定义 391 且方向相容（定义 394），且 AIM 满足 Iso ≥ κ、offdiag ≤ δ，则每条 CPB 主张有因果隔离的效应，论文贡献在 Popper 意义上可证伪；若 AIM 失败，主张必须合并或撤回 CPB。证明：引理 41 给可归因，引理 43 给分离判据，引理 42 给方向检验。

**定理 33（FM 热替换与认证成本）** 同 EC（含 CCE 形状）替换 FM 实现，只需重认证 SEAL-EFM + CCE；系统级性质由引理 39 + R73 引理 35 保持。认证成本 O(FM 模块) 而非 O(系统)，把 R73 引理 35 推到最难替换的组件。系：**从「换手」到「换脑」都是模块级重认证。**

## 6. 本轮最大风险

**一句话**：PCS 与 ABA 可能**共享同一条捷径**——大模型、证据模块和消融干预都通过一个未观测的混杂特征（语言先验与场景纹理偶然一致、同一光源/振动/温度场、同一数据集标注习惯）把「主张正确」与「证据充分」同时做出来；于是 `certify` 结清的是一个碰巧正确的幻觉，PLACEBO 与 STUB 又都依赖同一条捷径，AIM 的对角占优只是捷径在对角上的投影——系统会在「提议已认证、消融已隔离、日志每一步都合规」的情况下，把**一个共享的偏见**同时写进安全定理和论文贡献。

次级风险与缓解：
1. **CCE 过保守**（FM 几乎拿不到 A2，效率归零）→ 包络在线自适应 + 课程式扩包络 + 分级授权（A1 先跑人类背书样本）。
2. **SEM 分量不可辨识**（u_skill 与 u_ctx 混淆）→ 上下文随机化 + OOD 分层条件化 + 消融 SCRAMBLE 验证可分离性。
3. **CEL 开销与存储** → 窗口滚动 + 稀疏哈希链 + 只对认证路径全记，影子路径采样记。
4. **主张原子化爆炸 / discharge gaming** → |𝒞_atom|≤32 + 独立解析器 + 语义忠实性审计（提议措辞不可自选结清规则）。
5. **PLACEBO 架构不匹配**（同参数量 ≠ 同架构）→ 架构匹配 + 随机标签 + 多次重初始化，报告容量-效应曲线。
6. **预注册成本与 HARKing** → 封印哈希时间戳 + 只认预注册分析 + 探索性结果单独附录。
7. **分布偏移使 CCE 失效** → 部署期在线共形 + u_ctx 门槛 + 包络过期强制重认证。
8. **消融/认证共享捷径**（本轮头号风险）→ 加入**捷径探针**（与任务无关但与环境相关的对照特征）+ 环境级随机化 + 第三方共因传感器（温度/振动/光照）作为 VETO 输入；AIM 之外再报 shortcut-null 对比。
9. **DROP 探索结果泄漏进确认叙事** → 消融账本强制标注 exploratory，CPB 只读确认性条目。
10. **FM/AI 安全对齐的口惠** → 明确边界：PCS 不保证 FM 的意图好，只保证未结清意图不能执行；恶意但可结清的提议仍由 R73 风险层与人类否决兜底。

| `𝒞_atom = {GROUND, AFFORD, PATH, INTENT, PRECOND, SAFE, …}` | 主张原子类型（\|𝒞_atom\|≤32） |
| `ρ, τ_c, discharge(c,E) ∈ {discharged, unverified, vetoed}` | 主张→证据映射、主张级阈值、结清函数 |
| `CEL` | 主张-证据账本：只追加、哈希链；`coverage`/`blame`/`hash_ok` |
| `CCE = (T_cert, D_cert, ε, 1−α, expiry, SEAL-EFM)` | 能力证书包络 |
| `A∅ ⊏ A0 ⊏ A1 ⊏ A2` | 权限格：静默/影子/顾问/全权；单调降级 |
| `do(α)`，α ∈ {STUB, PLACEBO, ORACLE, OFF, SCRAMBLE, SHUFFLE, CUT, DROP} | MReg 上的消融干预算子 |
| `Δ_α = E[Y \| do(α)] − E[Y \| do(∅)]` | 消融估计量（配对、分块、CI、等价界） |
| `AIM[i,j], Iso_j = diag_j / (max offdiag + ε)` | 消融隔离矩阵与隔离分 |
| `s(α) ∈ {≤0, ≥0}` | 由组合单调性给出的方向预测 |
| `null / placebo` | 零消融（同实现重建）与容量匹配安慰剂；真实效应 = Δ_α − Δ_placebo |
| `J_EFM = J_MOD ⊗ CEL ⊗ CCE ⊗ abl` | 扩展组合证书（模块、账本、包络、消融绑定） |

## 2. 形式化定义（要点版）

**定义 383（EFM-GAUGE 总览与六不变式）** 契约完整性 / 组合单调性 / 反作用通道完备（含 χ_efm）/ 提议-认证分离（控制域只吃 `Certified`）/ 主张结清（CEL 有 discharge 记录）/ 消融可证伪（预注册干预族 + 方向预测 + 隔离判据）。

**定义 384（PCS）** `Proposal` 不受信；`Certified` 私有构造；`certify` 逐条主张校验 u≤τ、域满足、无否决、预算足够；认证集只依赖证据，不依赖 FM 实现（引理 39）。

**定义 385（SEM）** 语义六分量；D_efm 硬边界；χ_efm 反作用通道；校准必须做分布偏移审计（不只 IID ECE）。

**定义 386（GBC）** 主张原子化（独立解析器）+ 主张级证据映射与阈值 + discharge 三态 + 权限映射；防 discharge gaming。

**定义 387（CEL）** 只追加、哈希链；条目含 t/claim/src/rule/refs/u/D/status/auth/chain_hash；`coverage`、`blame`、`hash_ok`；J_MOD 的运行时对偶。

**定义 388（CCE）** 能力包络 (T_cert, ε, 1−α, expiry)；包络内且校准才 A2；权限格单调降级；A∅ ≡ R73 stub。

**定义 389（FM 作为 EC 模块）** T_in=(instruction,obs,ctx)，T_out=Proposal，𝒰_out=SEM 六分量，χ_R=χ_efm，I⊥={unsafe-intent,ungrounded,injection}，权限写入契约 ⇒ 热替换检查包含 CCE 形状。

**定义 390（ABA）** 八个 do 算子；STUB/PLACEBO/ORACLE/OFF/SCRAMBLE/SHUFFLE/CUT 为契约保持干预，DROP 为结构干预（须重过 CCA）。

**定义 391（干预有效性）** EC 保持（DROP 例外）+ 无未声明旁路 + PLACEBO 容量架构匹配 + 全部入消融账本；否则仅探索性。

**定义 392（消融估计量）** Δ_α 配对分块估计，报效应量/CI/等价界；方向预测 s(α) 由 R73 单调性给出。

**定义 393（AIM）** AIM[i,j] = 标准化 |Δ|；Iso_j = 对角/最大非对角；可分离 ⇔ Iso≥κ 且 offdiag≤δ（预注册）。

**定义 394（MAT）** 安全/能力指标预测 Δ_STUB ≤0（δ_safe 内）；Δ_STUB>δ_safe 且 CI 排除零 ⇒ 契约/主张被证伪。C2 预注册偏序 STUB(ΣREFLEX) ≺ OFF(χ_v) ≺ full。

**定义 395（零消融与安慰剂）** null 效应落 null CI；真实计量效应 = Δ_α − Δ_placebo 超出 null CI。

**定义 396（ABP）** 预注册干预族/指标/MDE/α/power≥0.8/种子/排除规则/分析计划/封印哈希；只有预注册分析进 CPB。

**定义 397（拒绝与降级）** Reject→A1/A0；unverified→A1 或 human query；vetoed→A0/A∅；A∅ 等价 stub，零级联。

**定义 398（结构上限）** \|𝒞_atom\|≤32、\|T_cert\|≤64、SEM 分量=6、每主张干预≤8、CEL 窗口滚动、certify ≤2ms——可审计图/类型性质。

**定义 399（严格退化链）** FM=A∅、GBC 平凡、ABA 空 ⇒ MODGAUGE ⇒ R72 ⇒ R71 ⇒ R68；安全与效率单调不增。

# IP-302 PCS：提议-认证类型系统（Certified 私有构造）
@dataclass(frozen=True)
class Proposal:
    t: type; content: Tuple[Claim, ...]; pi: float
    ctx: Context; src: str; prov: str

class Certified:
    __slots__ = ('t', 'content', 'cel_ref', 'u')
    def __init__(self, *_): raise TypeError("Certified is constructed only by certify()")
    @classmethod
    def _make(cls, p, cel, ev):
        c = object.__new__(cls); c.t, c.content, c.cel_ref = p.t, p.content, cel
        c.u = max(e.u for e in ev); return c

def certify(p, cel, budget):
    if p.t not in CCE.envelope:  return Reject('OUT_OF_ENVELOPE')
    need = 0.0
    for c in p.content:                                   # 逐条主张结清
        rules = GBC.rho(c)
        ev = [cel.lookup(r) for r in rules]
        if any(e is None for e in ev):   return Reject('UNVERIFIED', c)
        if any(e.veto for e in ev):      return Reject('VETOED', c)
        if not all(e.u <= GBC.tau(c) and GBC.domain_ok(c, e) for e in ev):
            return Reject('UNVERIFIED', c)
        need += max(e.u for e in ev)
    if budget.remaining() < need:        return Reject('BUDGET')
    return Certified._make(p, cel, ev)                    # 唯一合法构造
```

# IP-303 SEM：语义证据计量
def sem_update(p, obs, ctx, hist):
    u_ground = grounding_residual(p.content, obs.rgb, obs.depth, obs.tac)
    u_sem    = semantic_conformal_set(p).size
    u_afford = affordance_unc(p.content, obs, D_depth=obs.d_ev.D, D_contact=obs.t_ev.D)
    u_skill  = CCE.risk(p.t, p.src)

# IP-304 GBC + CEL：语义主张结清与账本
class GroundingBridge:
    def discharge(self, c, cel):
        ev = cel.materialize(self.rho(c))
        if ev is None:              return 'unverified'
        if any(e.veto for e in ev): return 'vetoed'
        return 'discharged' if all(e.u <= self.tau(c) and self.domain_ok(c, e)
                                   for e in ev) else 'unverified'

class CEL:
    def append(self, t, claim, src, rule, refs, u, D, status, auth):
        h = H(self.tail, t, claim, tuple(refs), u, status)
        self.entries.append(Entry(t, claim, src, rule, refs, u, D, status, auth, h))
        self.tail = h
    def coverage(self, t):
        es = [e for e in self.entries if e.t == t and e.src == 'FM']
        return sum(e.status == 'discharged' for e in es) / max(len(es), 1)
    def blame(self, claim): return [e for e in self.entries if e.claim == claim]
```

A = OrderedEnum(['A_NONE', 'A_SHADOW', 'A_ADVISOR', 'A_FULL'])

```python
# IP-306 ABA：契约保持的干预算子
def do(mreg, op):
    if   op.kind == 'STUB':     m2 = mreg.replace(op.m, stub(op.m))           # EC 保持
    elif op.kind == 'PLACEBO':  m2 = mreg.replace(op.m, placebo(op.m))        # 容量匹配
    elif op.kind == 'ORACLE':   m2 = mreg.replace(op.m, oracle(op.m))
    elif op.kind == 'OFF':      m2 = mreg.replace_channel(op.m, op.ch, identity)
    elif op.kind == 'SCRAMBLE': m2 = mreg.permute_field(op.m, op.field)
    elif op.kind == 'SHUFFLE':  m2 = mreg.shuffle_context(op.m)
    elif op.kind == 'CUT':      m2 = mreg.cut_provenance(op.m)
    elif op.kind == 'DROP':     m2 = mreg.remove_and_rewire(op.m); CCA.validate(m2)
    assert interven_valid(op, m2)                     # 定义 391
    return m2
```

# IP-308 EFM-GAUGE 主闭环
def EFM_GAUGE_round(M, instruction, obs, tac, depth):
    p = M.efm.propose(instruction, obs, M.ctx, M.hist)        # Proposal，不受信
    sem = M.sem.update(p, obs, M.ctx, M.hist)                 # SEM 六分量
    M.ctx = M.ctx.push(p, obs)                                # χ_efm

    auth = M.cce.authority(p, sem)                            # 权限格
    if auth <= A.SHADOW:
        M.cel.append(..., status='shadow'); return M.hold(), 'shadow'
    cert = certify(p, cel, M.budget)                          # 唯一认证入口
    if isinstance(cert, Reject):
        M.cel.append(..., status=cert.reason); return M.fallback(), cert.reason
    M.cel.append(..., status='discharged', auth=auth)
    return M.modgauge_round(cert.content, depth, tac, obs), 'certified'

## 4. 推导

**假设增量**：A114（提议完整性：独立解析器忠实原子化）、A115（discharge 判别力：真主张可结清、假主张不可）、A116（CCE 校准在偏移下可检出）。

**引理 38（SEM 条件正交性）** 给定 (task, object, context) 下六分量机制独立、条件近似不相关；漏一项即系统性低估；u_skill 与 u_ground 的 OOD 相关须以 OOD 分数条件化。系：语义证据不是「再报一个熵」，而是语言/数据/物理三类噪声的分离。

**引理 39（PCS 类型安全）** `certify` 只引用证据与 CEL ⇒ 固定证据预算下认证集与 FM 无关；更强 FM 只提高接受率，不抬高安全界。系：换 FM 不改安全定理。

**引理 40（CCE 单调退化）** `authority` 逐分量单调 + 格 min 单调 ⇒ 证据变差权限只降；A∅ ≡ stub ⇒ 零级联。

**引理 41（干预有效性 ⇒ 因果可解释）** EC 保持 + 无旁路 ⇒ 指标差只归因于证据函数；DROP 只归因图结构。

**引理 42（MAT 检出力）** 由 R73 单调性，STUB 不可能提高认证安全；单侧检验检出力更高；「消融变好」= 契约/主张被证伪。

**引理 43（AIM 分离判据）** 主张机制互异 ⇒ 效应对角集中；offdiag>δ ⇒ 主张共享机制或指标不特异，二者均可操作。

**定理 30（严格包含）** FM=A∅、GBC 平凡、ABA 空 ⇒ 逐指令等于 MODGAUGE ⇒ R72/R71/R68；安全与效率单调不增。

**定理 31（PCS 端到端安全）** certify 可靠 ∧ CCE 校准 ∧ CEL 完整 ⇒ FM 来源动作风险 ≤ ε_mod+ε_sem+ε_cce，与 FM 能力无关。四项由引理 39、定理 28、共形覆盖、CEL 完整性给出。

**定理 32（消融可归因 / 主张可分离）** 预注册干预族有效 + 方向相容 + AIM 达标 ⇒ 每条 CPB 主张有因果隔离效应，贡献可证伪；AIM 失败 ⇒ 合并主张或撤回 CPB。

**定理 33（FM 热替换）** 同 EC（含 CCE 形状）替换 FM ⇒ 只需重认证 SEAL-EFM + CCE；系统级性质由引理 39 + R73 引理 35 保持；认证成本 O(FM 模块)。

## 7. 本轮最大风险

**一句话**：PCS 与 ABA 可能**共享同一条捷径**——大模型、证据模块与消融干预都通过一个未观测的混杂特征（语言先验与场景纹理偶然一致、同一光源/振动/温度场、同一数据标注习惯）把「主张正确」与「证据充分」同时做出来；于是 `certify` 结清的是一个碰巧正确的幻觉，PLACEBO/STUB 又依赖同一条捷径，AIM 的对角占优只是捷径在对角上的投影——系统会在「提议已认证、消融已隔离、日志每一步都合规」的情况下，把**一个共享的偏见**同时写进安全定理和论文贡献。

次级风险与缓解：
1. **CCE 过保守**（FM 拿不到 A2）→ 在线自适应包络 + 课程式扩包络 + A1 人类背书样本。
2. **SEM 分量不可辨识**（u_skill 与 u_ctx 混淆）→ 上下文随机化 + OOD 分层 + SCRAMBLE 可分离性验证。
3. **CEL 开销** → 窗口滚动 + 稀疏哈希链 + 认证路径全记、影子路径采样。
4. **原子化爆炸 / discharge gaming** → \|𝒞_atom\|≤32 + 独立解析器 + 语义忠实性审计。
5. **PLACEBO 架构不匹配** → 架构匹配 + 随机标签 + 重初始化 + 容量-效应曲线。
6. **预注册 HARKing** → 封印哈希 + 只认预注册分析 + 探索性单列附录。
7. **分布偏移使 CCE 失效** → 在线共形 + u_ctx 门槛 + 包络过期强认证。
8. **消融/认证共享捷径**（头号风险）→ 捷径探针（任务无关、环境相关对照特征）+ 环境级随机化 + 第三方共因传感器 VETO + shortcut-null 对比。
9. **DROP 探索结果泄漏** → 消融账本强制标注 exploratory，CPB 只读确认性条目。
10. **意图安全边界** → PCS 不保证 FM 意图好，只保证未结清意图不能执行；恶意但可结清的提议仍由 R73 风险层与人类否决兜底。
