# 第 56 轮（承接第 55 轮 v32 语义-接触接地；新一轮灵感循环第 1 轮；本轮灵感：「伦理与合规」×「容错控制」）

> 第 55 轮把接触从“语义标签”提升为“可执行约束”，用生存核与护盾保证全身物理可行性。本轮把问题从 **“物理上能不能做”** 推进到 **“规范上该不该做，以及故障下还能不能守住该做/不该做的边界”**。核心矛盾：**H24**：伦理与合规不是动作空间上的静态布尔谓词，而是带 **时效、授权、证据与信息流方向** 的义务（同意可撤回、目的受限、最小化采集、管辖地变化），动作护盾只看 `(x,u,λ)`，看不见“这次观测与这条日志本身是否被允许”；**H25**：容错控制若只保物理安全，故障时会把系统降级成“安全但违规”（停在消防通道、拒绝已同意的必要辅助、无人在环却继续高风险操作），若只保合规则可能“合规但不安全”，故需要 **安全 ∩ 合规的联合吸引子**，而非 fail-closed；**H26**：合规监视器自身也会故障，一个“永远报告合规”的坏监视器比没有监视器更危险，且审计证据本身可能是隐私泄露源，因此合规必须像安全一样具备 **独立冗余、可重建、可隐私保护** 的失效证据。

## 0. 直觉与动机

**灵感 1（伦理与合规 → 运行时规范状态，而非部署清单）**
直觉：合规不是上线前打勾，而是每时每刻的运行时状态。一次抓取是否合法，取决于此刻的同意图、任务目的、管辖地、被照护者脆弱性与授权链，而不是固化的“抓取技能已认证”。因此需要 **规范状态** `N_t` 与 **合规裕度** `m_c`：前者记录 `(策略版本, 管辖地, 同意图, 目的, 脆弱性画像, 授权, 在环模式)`，后者度量“离违规边界还有多远”。这把第 55 轮的“语义不确定”扩展成 **规范不确定**：策略歧义、同意过期、管辖冲突都要像分割扰动一样进入证书。

**灵感 2（容错控制 → “安全且合规”的吸引子，而非急停）**
直觉：故障安全的朴素做法是停机，但 **不作为也可以是违规**（阻塞通道、遗弃被照护者、拒绝已授权的必要干预）。FTC 的正确目标不是“停下来”，而是“在故障集 `F` 与有界检测延迟 `τ_d` 内，仍维持安全 ∧ 合规，或进入 **有授权的** 合规保持/人机交接”。因此需要定义 **容错合规生存核** `K^F(N)` 与 **恢复域**：不是“是否存在一个安全动作”，而是“是否存在一个策略，使得任意有界故障下先守住不变量，再在 `T_r` 内进入可问责的降级态”。

**灵感 3（合规监视器的自身故障 → 独立冗余与规范 FDI）**
直觉：若合规判断来自单一学习模块，它可能被分布外输入、提示注入或奖赏 hack 成“恒真”。安全上我们不会信任单一碰撞检测器，合规上也不能信任单一规范监视器。需要 **跨通道解析冗余**：签名策略新鲜度、同意链有效性、管辖一致、解释-轨迹一致性、传感器真实性、信息流目的匹配；并区分 **主动故障**（检测-隔离-重构）与 **被动故障**（鲁棒不变集覆盖未及时检测的窗口）。

**灵感 4（可问责与隐私的悖论 → 隐私保护型证据）**
直觉：合规要求可审计、可解释、可追责，而审计日志恰恰会记录个人数据与行为轨迹，与数据最小化/被遗忘权冲突。解法不是不审计，而是 **审计可验证但不可窥探**：对同意与身份存承诺、对决策存哈希链/Merkle 根、对“策略允许该目的”给选择性披露证明；保留期用可删除密钥实现密码学擦除。**审计本身必须满足合规**，否则会制造第二重违规。

**灵感 5（人机权责交接 → 授权不扩张与有界接管）**
直觉：故障降级不是“把决定权悄悄交给云端或模型”，而是 **授权只减不增**：任何自动降级不得扩大可执行动作集，除非操作者显式重新授权。交接要有 **上界延迟 `T_h`** 与“人不可用”的预授权兜底，否则会把“等人类”变成新的死锁；同时要防自动化偏见（人盲目确认）与频繁误停导致的“安全机制被绕过”。

**灵感 6（云边合规接口 → 签名策略下发、最小回传）**
直觉：云端适合做全局一致的政策编译与签名发布，边端适合做实时强制与本地证据。接口应只传 **策略包 `(π, sig, version, jurisdiction)`** 与 **证明/承诺**，不回传原始感知与身份数据；策略版本/管辖不一致直接触发受限态，而不是“先跑再说”。

## 1. 形式化定义（增量：定义 127–133）

**定义 127（规范状态）**
`N_t = (π_t, j_t, C_t, p_t, v_t, A_t, o_t)`：
- `π_t` 为签名策略包及其版本哈希；
- `j_t` 管辖地，`p_t` 当前任务目的；
- `C_t` 同意图：边 `(subject, scope, purpose, expiry, revocable, evidence_id, state∈{granted,revoked,expired,unknown})`；
- `v_t` 脆弱性/照护画像，`o_t ∈ {in_the_loop, on_the_loop, out_of_loop}`；
- `A_t` 授权关系：谁能授权哪些高风险动作（含双人规则）。
`N_t` 具有 **时效有效性** `valid(N_t)=1 ⇔ age(π_t)≤T_π ∧ consent 未全量过期 ∧ j_t 与部署地一致`。

**定义 128（合规约束系统与合规裕度）**
策略编译为带优先级的三值约束系统 `Φ = Φ_hard ⊎ Φ_def`。硬约束（不可克减）如禁止未授权接触、禁止目的外数据外传、禁止进入排除区；可克减义务带 `(priority, justification_schema, deadline, evidence_required, authority_required)`。三值满足
`sat(τ, Φ, N) ∈ {sat, unknown, viol}`，**`unknown` 一律按“未满足”处理**（不得静默当满足）。
对每条义务 `φ` 定义松弛 `slack_φ(t)`（截止前剩余时间、到禁止状态/流的距离、证据完整度）；合规裕度
`m_c = min_φ slack_φ`，存在 `unknown` 时 `m_c=0`。**规范鲁棒性谱**
`ρ_norm(ε_n) = inf_{||N-N̂||≤ε_n} P(sat(τ,Φ,N) | N̂)`，`ε_n` 覆盖策略歧义、同意不确定与管辖边界。

**定义 129（故障集与容错合规生存核）**
故障集 `F = F_sense ∪ F_act ∪ F_comm ∪ F_norm`；`F_norm` 含策略过期、规则误编译、监视器崩溃、同意缓存陈旧、提示注入导致的价值漂移。每个 `f` 有检测延迟上界 `τ_d(f)`；假设任意时刻活动故障通道数 `|F_active| ≤ f_max`。容错合规生存核
`K^F_ε(N) = {x | ∃π* ∀F'⊆F,|F'|≤f_max : x_{t+1}∈K(Σ)∩Sat_hard(Φ) ∧ m_c≥ε (t<τ_d) ∧ 故障检出后 T_r 内到达 M3/M4 ∧ 授权不扩张 ∧ 审计不断链}`。
`(f,ε)`-安全合规即 `x∈K^F_ε(N)`；不可达时证书必须给出 **恢复域** `R(N,M3)` 而非空泛“保证安全”。

**定义 130（规范护盾与可采纳回退）**
`u* = argmin_u ||u-u_nom||²_W`
s.t. `x_{t+1}∈K^F_ε(N)`，`supp(λ)⊆C^+(Σ)`，`λ∈FC(μ)`，且 **信息流约束** `flow(u, sensors, p_t) ⊆ allowed(p_t)`（目的受限、最小化采集）；高风险动作还须 `authority(u, A_t)=1`。
若可行集为空，回退不是任意“急停”，而是 **可采纳回退集**
`A_fb = {u | u∈K^F_ε(N), sat(τ,Φ,N)≠viol, 到达 M3/M4 且不阻塞通道/不遗弃被照护者}`；
`A_fb=∅` 本身即证书拒签条件。**关键**：停机只是回退的候选之一，不是默认公理。

**定义 131（容错合规监督器状态机）**
`M={M0 nominal, M1 restricted, M2 supervised, M3 authorized_hold, M4 handover}`。转移 `M_i→M_j` 带守卫 `(故障签名, 裕度, 授权, 证据)`。三条不变式：
(i) **授权不扩张** `Auth(M_j) ⊆ Auth(M_i)`，除非显式重新授权；
(ii) **审计连续** 任何转移的 `evidence` 必须可链接到同一根；
(iii) **无静默自愈** `M1/M2→M0` 必须完整重认证，禁止“带病恢复”。
用驻留时间 `dwell` 与滞回抑制模式抖动。

**定义 132（可问责审计证书）**
`A_t = (h_π, commit(N_t), decision_log, evidence_root_t, fault_log, override_log)`，
`evidence_root_t = H(evidence_root_{t-1} ‖ h(log_t))` 构成哈希链/Merkle 树。同意与身份以承诺存储；用选择性披露/零知识证明“在 `π_t` 下目的 `p_t` 被同意覆盖”而不暴露主体；保留期用可删除密钥实现 **密码学擦除**。定义 **审计可靠性**（篡改可检出、重建完整）与 **隐私泄漏上界**（互信息/可区分优势）。

**定义 133（伦理-合规联合证书）**
`J_ce = (K_margin, m_c, ρ_norm, ρ_sem, F_bound, mode, authority, A_root, δ_s, evidence)`。
可部署当且仅当：`K_margin≥θ_K`、`m_c≥θ_c`、`ρ_norm≥ρ_min`、`ρ_sem≥ρ_min`、`|F_active|≤f_max`、`mode∈{M0,M1,M2}`、审计可验证且隐私泄漏 ≤ `ε_p`、`A_fb≠∅`。**“通过审计”不等于“符合伦理”**：证书只对已编译、已授权、可验证的部分负责，未形式化的价值冲突必须上报人类裁决。

def compile_normative_context(policy_bundle, jurisdiction, consent_graph, purpose, vuln):
    assert verify_signature(policy_bundle) and fresh(policy_bundle, T_pi)
    assert policy_bundle.jurisdiction == jurisdiction
    Phi_hard, Phi_def = [], []
    for rule in policy_bundle.rules_for(jurisdiction, purpose):
        phi = compile_rule(rule, consent_graph, vuln)   # STL / timed automaton
        if phi.non_derogable:
            Phi_hard.append(phi)

            Phi_def.append(phi.with_priority(rule.priority))
    N = NormState(policy_bundle.hash, jurisdiction, consent_graph, purpose, vuln,
                  authority=derive_authority(policy_bundle, consent_graph))
    return N, Phi_hard, Phi_def

### IP-128 NMS（Normative Monitor & Shield）

```python
def normative_shield(u_nom, x, N, Phi, Kernel_F, C_plus, W):
    hard_ok, mc_hard = check_three_valued(Phi.hard, x, N)   # unknown -> fail
    if hard_ok != 'sat' or mc_hard < theta_c:
        return select_fallback(x, N, Phi, Kernel_F, C_plus), 'normative_hold'
    u = qp_solve(
        H=W, g=-W @ u_nom,
        constraints=[
            viability_constraint(x, u, Kernel_F.K_in),
            contact_constraint(u, C_plus),
            friction_cone_constraint(u, mu),
            infoflow_constraint(u, N.purpose, N.consent_graph),
            authority_constraint(u, N.A_t),
        ],
    )
    if u is None:
        return select_fallback(x, N, Phi, Kernel_F, C_plus), 'shield_infeasible'
    mc = min_slack(Phi, x, u, N)
    if mc < theta_c:
        return select_fallback(x, N, Phi, Kernel_F, C_plus), 'compliance_margin_low'
    return u, 'ok'
```

### IP-129 FDI-N（Fault Detection & Isolation for Normative / Data Flows）

```python
def normative_fdi(streams, detectors, tau_d):
    residuals = {
        'policy': version_mismatch(streams.policy, signed_registry),
        'consent': staleness_and_revocation(streams.consent, streams.purpose),
        'jurisdiction': jurisdiction_drift(streams.deploy, streams.policy),
        'explain': trace_explanation_consistency(streams.decision, streams.traj),
        'sensor_auth': replay_spoof_score(streams.raw),
        'infoflow': purpose_leak_score(streams.egress, streams.purpose),
        'value': distribution_shift(streams.planner, streams.policy_baseline),
    }
    health = {k: 1 - sigmoid(cusum(residuals[k]) - lambda_k) for k in residuals}
    faulty = {k for k,h in health.items() if h < h_min}
    if 'policy' in faulty or 'jurisdiction' in faulty:
        return 'hard_restrict', faulty           # 立即 M1
    if len(faulty) > f_max:
        return 'handover', faulty
    return 'reconfigure', faulty
```

### IP-130 FTCS（Fault-Tolerant Compliance Supervisor）

```python
def ftcs_step(mode, x, N, Phi, faults, Kernel_F, evidence_root):
    if not valid(N) or 'policy' in faults or 'jurisdiction' in faults:
        return transition(mode, 'M1', why='policy_invalid', evidence=evidence_root)
    if unresolved_hard_unknown(Phi, x, N):
        return transition(mode, 'M3', why='normative_unknown', evidence=evidence_root)
    if len(faults) > f_max or not Kernel_F.contains(x):
        return handover_or_fallback(mode, x, N, Kernel_F, evidence_root)
    if faults and mode == 'M0':
        return transition(mode, 'M1', why='degraded', evidence=evidence_root)
    if not faults and mode in ('M1','M2') and recertified(x, N):
        return transition(mode, 'M0', why='recertified', evidence=evidence_root)
    return mode
```

### IP-133 JEC（Joint Ethics-Compliance Certificate）

```python
def issue_jec(traj, Sigma, N, Phi, rho_sem, rho_norm, budgets):
    if not valid(N) or any(u == 'unknown' for u in hard_status(Phi, traj)):
        return ('reject', 'normative_unknown')
    K_margin = min(dist_to_boundary_K(x, Sigma) for x in traj)
    m_c = min_slack(Phi, traj, N)
    if K_margin < budgets.theta_K or m_c < budgets.theta_c:
        return ('reject', 'margin_exceeded', K_margin, m_c)
    if rho_sem(budgets.delta_s) < budgets.rho_min or rho_norm(budgets.eps_n) < budgets.rho_min:
        return ('reject', 'robustness_fail')
    if not audit_verify(traj.audit) or privacy_leak(traj.audit) > budgets.eps_p:
        return ('reject', 'audit_or_privacy_fail')
    if latency_and_handover_slo(traj) > budgets.T_h:
        return ('reject', 'handover_slo_fail')
    return ('ok', EthicsCert(K_margin, m_c, rho_sem, rho_norm,
                             F_bound=traj.fault_bound, A_root=traj.audit.root))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| NCC | O(|Φ|·|N|) | O(|Φ|) | 硬约束编译 sound（零假阴性）、策略签名与新鲜度 |
| NMS | O(|Φ|) + O(QP) 每步 | O(|A_WB|+|Φ|) | 三值 `unknown≠sat`、信息流与授权约束完整 |
| FDI-N | O(|K|·|r|) 每步 | O(|K|) | 残差可观测、检测延迟 ≤ τ_d、监视器独立性 |
| FTCS | O(1) 转移 + O(|evidence|) | O(|log|) | 授权不扩张、审计不断链、无静默自愈 |
| AAC | O(1) 追加 / O(log n) Merkle 证明 | O(n) | 哈希链抗碰撞、选择性披露与擦除正确 |
| SAH | O(1) 握手 + T_h | O(1) | 交接活性、预授权兜底、防自动化偏见 |
| JEC | O(|traj|·(|Ω|+|Φ|)) | O(|Φ|+|Ω|) | 各预算闭合、`A_fb≠∅` |

**正确性定理（Fault-Tolerant Compliant Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** 策略包签名且新鲜 `age(π)≤T_π`，管辖地一致；**(A34)** 硬约束编译器对轨迹无假阴性，NMS 单步延迟 ≤ `τ_m`，硬约束由 ≥2 条独立监视路径确认；**(A35)** 任意时刻 `|F_active|≤f_max` 且故障检测延迟 ≤ `τ_d`；**(A36)** 交接活性：人类在 `T_h` 内响应，或存在预授权兜底策略；**(A37)** 审计链抗碰撞，选择性披露 sound，密码学擦除有效。
则部署后单步 “安全 ∧ 合规，或进入有授权的合规保持/交接” 的概率满足
```
P ≥ 1 - P(policy stale ∨ jurisdiction drift) - P(compiler FN)
      - P(|F_active| > f_max) - P(detect delay > τ_d)
      - P(monitor Byzantine undetected) - P(handover fail)
      - P(||Σ-Σ̂||∞ > ε_s) - P(audit break) - P(privacy leak > ε_p)
```
关键：**合规是带证据的运行时不变式，不是部署勾选项；停机不是默认合规；任一层失守都不允许把“审计通过”当作“伦理成立”。**

## 6. 本轮最大风险

**一句话**：本轮把“合规”升级为带证据的运行时不变式，但最大风险是 **规范编译与监视器的假阴性**——一旦硬约束被错误编译、或故障下独立监视被同时绕过，系统会在“自认为合规”的审计链上继续执行违规动作，而可问责证据反而为错误决策背书；因此必须以 **双独立监视 + 签名策略新鲜度 + 最小权限降级与合规回退集 + 隐私保护证据** 四重护栏，宁可进入有授权的合规保持并上报人类，也绝不把“审计通过”当作“符合伦理”。

def issue_jec(traj, Sigma, N, Phi, rho_sem, rho_norm, budgets):
    if not valid(N) or any(u == 'unknown' for u in hard_status(Phi, traj)):
        return ('reject', 'normative_unknown')

    m_c = min_slack(Phi, traj, N)

**正确性定理（Fault-Tolerant Compliant Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** 策略包签名且新鲜，管辖一致；**(A34)** 硬约束编译器无假阴性，NMS 延迟 ≤ `τ_m`，硬约束由 ≥2 条独立监视确认；**(A35)** `|F_active|≤f_max` 且检测延迟 ≤ `τ_d`；**(A36)** 交接活性或预授权兜底在 `T_h` 内；**(A37)** 审计链抗碰撞、选择性披露 sound、密码学擦除有效。
则部署后单步 “安全 ∧ 合规，或进入有授权的合规保持/交接” 的概率：
```
P ≥ 1 - P(stale ∨ jurisdiction drift) - P(compiler FN)
      - P(|F_active|>f_max) - P(τ_d exceeded)
      - P(monitor Byzantine undetected) - P(handover fail)
      - P(||Σ-Σ̂||∞>ε_s) - P(audit break) - P(privacy leak>ε_p)
```
关键：**合规进入运行时证书、故障界进入生存核、审计与隐私同时可证、停机不是默认合规**。
