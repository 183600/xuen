# 第 64 轮（承接第 63 轮「LIRO 几何-技能-干扰闭环」IP-193~203；灵感循环 II 第 3 轮；本轮灵感：「可用性评估」×「预测性维护」）

> 第 63 轮把 ROSE 升级为 LIRO：LSF 几何先验、USL/CSP 技能抽象、DIR/AIC 干扰认证，并产出 J_liro 证书。但 LIRO 仍有两个结构性盲点：
> 1. **时间维缺失**：J_liro 只回答「此刻是否安全」，不回答「还能安全多久」。LiDAR 会积灰、关节会磨损、E_geo 会随环境漂移、DIR 不变性会衰减、SSB 场景会陈旧、标定会过期——第 63 轮没有任何组件预测这些退化，也没有维护调度，只能在指标跌破后被动反应（break-fix / clarify-spam）。
> 2. **证书自指盲区（self-referential blind spot）**：LSF→φ̂→WCV→DIR→AIC→J_liro 全部建立在同一个几何嵌入 g 之上。若 E_geo 产生系统性幻觉几何（第 63 轮自述最大风险 A77），则 φ̂、𝒢(g)、ρ_rob、ρ_dir 会**一致地错**——内部监控彼此印证、看不出异常。这不是「监控不够多」，而是「监控共享同一错误源」。打破相关性失效需要一个**机理独立的外部观测通道**。
>
> 本轮两个灵感正好补这两点：**可用性评估**提供与内部证书不共享错误源的「人」的观测通道（对应可靠性工程的 P 点），**预测性维护**提供时间维的退化预测与主动介入（对应 P-F 区间）。二者合流为 **PULSE**：把「何时修、修什么、修了有没有用」变成可预测、可调度、可验证的闭环。

## 0. 直觉与动机

**灵感 1（可用性评估 → UAT：Usability Assessment Telemetry）**
直觉：可靠性工程有一条经典曲线——**P-F 曲线**：设备从「潜在失效 P」滑到「功能失效 F」之间存在一个时间窗（P-F interval），维护应发生在 P-F 之间而不是 F 之后。把这条曲线搬到人机系统：**任务失败/证书失效是 F，而用户「开始觉得不好用」是 P**——响应变慢、反复纠正、接管变多、澄清问题变多、信任开始失准。这些行为信号比内部指标更早，且**与内部证书不共享错误源**。UAT 用**隐式行为遥测**（成功率、完成时间、接管/纠正/澄清频次、路径效率、犹豫停顿、是否重复确认）实时估计可用性向量 u_t=(有效性 E、效率 F、安全性 S、可学习性 L、信任校准 T、自主性 A)，仅用**稀疏显式问卷**（SUS / NASA-TLX / 信任量表）做锚点校准，并用 conformal 给出覆盖区间。**关键洞见：可用性不是体验指标，而是安全关键的独立观测通道。**

**灵感 2（预测性维护 → PHM-C：Cyber-Physical Health Prognostics）**
直觉：预测性维护的核心不是「坏了再修」，而是用退化模型预测 RUL（remaining useful life）并在成本最优时刻维护。第 63 轮的系统是一个**软硬耦合资产**：既有物理件（LiDAR 光学、关节、夹爪、标定），也有学习件（E_geo、DIR、OLP、RSC 球、SSB、技能库）。两类件都会「老化」，而且都会使 J_liro 失效。PHM-C 为每条退化通道建立健康指数 h_j(t) 与随机退化过程（磨损用 Gamma 过程、漂移用 Wiener 过程、突变用 Bayesian changepoint），输出带 conformal 区间的 RUL，并给出**证书剩余有效期 GRUL**（J_liro 还能保鲜多久）。

**灵感 3（二者合流 → SLD：Service-Limit Discovery）**
直觉：预测性维护通常用工程阈值（温度、振动、电流）定义「失效」，但软硬耦合系统的真正失效是**可用性不可接受**。SLD 把维护阈值 h_j* 从「工程经验」改为「**由可用性退化反推的服务极限**」：找到健康水平 h_j*，使得「在 Δ 窗口内可用性跌破 U_ref」的风险达到 α。于是可用性评估定义了预测性维护的**终点**，预测性维护提供了可用性的**前瞻**——u 是 h 的早期症状，h 是 u 的未来。这正是二者的咬合点，而不是两个模块的简单堆叠。

**灵感 4（打破自指盲区 → 独立通道 + 反事实验证）**
直觉：如果 E_geo 幻觉，内部所有证书会用「同一个错误几何」自洽地证明自己安全（第 63 轮最大风险）。用户不会配合这种自洽：他会因为抓空、碰撞、反复失败而放慢、接管、抱怨。因此 UAT 是**唯一能证伪内部证书的外部证据**。反过来，维护是否真的有效也不能只看内部健康指标（可能只是「化了妆」）：MVE 用中断时间序列/合成控制估计维护的**因果效应**，要求「维护后可用性真的恢复」才算有效，否则回滚到上一个已知良好状态（checkpoint + 标定快照）。

**灵感 5（整体 → PULSE 闭环）**
PULSE = LIRO 的「时间 × 人」双层扩展：LIRO 每步输出 J_liro（此刻安全），PULSE 在其上叠加 J_pulse（还能安全多久 + 维护计划 + 可用性）。闭环：LIRO 运行 → UAT 遥测 → JHS 融合健康/可用性隐状态 → PHM 预测 RUL/GRUL → SLD 校准服务极限 → MSC 调度维护 →（执行维护）→ MVE 验证因果效果 → 更新退化先验与维护模型 → 回到 LIRO。**安全不变式**：维护动作本身也过 Shield，且只在安全态执行；维护失败自动回滚。**PULSE 是「可观测性（人）× 可预测性（退化）× 可维护性（调度）」的三位一体**。

## 1. 形式化定义（增量：定义 201–216）

- **定义 201（PULSE 闭环）**：PULSE = (LIRO, UAT, PHM-C, SLD, JHS, MSC, MVE, GRUL, PulseShield, J_pulse)。定位：在 LIRO 之上加一层「健康-可用性-维护」时间闭环，不改变 LIRO 的实时契约与任何既有接口；所有预测/调度/验证仅在语义流低频线程执行。
- **定义 202（UAT 可用性遥测）**：u_t = UAT(τ_t, exec_log_t) ∈ ℝ^6，六维为 E/F/S/L/T/A。隐式代理 ψ_t 由执行日志抽取（成功率、单位任务时长、接管率、纠正率、clarify 率、路径效率、停顿熵）；显式锚 a_s（SUS/TLX/信任评分）稀疏出现（每 N 任务或用户主动触发）。UAT 输出带区间：û_t = (u_t, C_t^u)，保证 P(u_t^true ∈ C_t^u) ≥ 1−α_u。
- **定义 203（可用性标量化 U_t）**：U_t = Σ_i w_i·φ_i(u_t^i)，w 由 Bradley-Terry 成对偏好或与 SUS 的单调映射离线标定；φ_i 为各维归一化 link 函数。U_ref 为任务族给定的可用性下限；"可用性失效"定义为 U_t < U_ref 持续 Δ_u 个任务。
- **定义 204（隐式-显式锚定）**：以显式锚 a_s 对隐式代理做残差校准（GP 回归 / 分位数回归），并用 split-conformal 给 û_t 覆盖区间；显式锚过稀时用同任务族历史锚做迁移，锚量不足则区间自动放宽（避免假自信）。
- **定义 205（PHM-C 退化通道）**：通道集 𝒥 = {LiDAR 光学, 关节摩擦/磨损, 夹爪柔顺, E_geo 几何保真, DIR 不变性, OLP 权重漂移, RSC 球膨胀, SSB 场景陈旧, 标定有效性}（J=9）。每通道健康指数 h_j(t) ∈ [0,1]，由条件监测特征 z_j(t) 经退化状态空间模型估计。
- **定义 206（随机退化与 RUL）**：磨损类用 Gamma 过程 H_j(t)（单调增损伤 D_j=1−h_j，增量 ~ Gamma(α_j·Δ, β_j)）；漂移类用 Wiener 过程 dD_j = μ_j dt + σ_j dW；突变类用 Bayesian online changepoint（BOCPD）触发重置。首次通过时间 T_j = inf{t: h_j(t) ≤ h_j*}，RUL_j(t) = T_j − t，输出预测分布 p(RUL_j | z_{1:t})。
- **定义 207（Conformal RUL 区间）**：以历史维护/失效事件（含右删失）训练基础生存模型（Weibull/Cox/梯度提升生存），用 conformal survival（删失感知分位数）校准区间 [RUL_j^lo, RUL_j^hi]，保证 P(RUL_j ∈ 区间) ≥ 1−α_rul。
- **定义 208（SLD 服务极限）**：h_j* = argmin_h E[ C_maint + L_use(h) ]，其中 L_use(h) 为从健康 h 起至下次维护的累计可用性损失，C_maint 为维护代价；等价地可写为风险约束形式 h_j* = max{h: P(U_{t+Δ} < U_ref | h_j(t)=h) ≤ α_u}。服务极限由 UAT 的可用性事件与 PHM 的健康轨迹联合估计（生存回归，终点为"可用性失效"而非"机械故障"）。
- **定义 209（JHS 联合隐状态）**：以因子图融合遥测 z_t、可用性观测 û_t、稀疏锚 a_s、维护事件 m_t，输出后验 p(h_t, U_t^{latent} | 历史)。传感失效/删失用鲁棒因子（Huber/Student-t）降权，避免单一坏通道污染全局健康估计。
- **定义 210（MSC 维护调度）**：状态 s_t=(p(h_t), {p(RUL_j)}, û_t, 任务负载, 维护预算余量)；动作 a ∈ 𝒜_maint（定义 211）。目标：max E[Σ_t U_t − λ_c Σ C_maint]，s.t. P(任一通道功能失效) ≤ α_f 且维护预算 ≤ B。形式为 CMDP，用拉格朗日松弛 + 每通道 restless bandit 的 Whittle 指数近似（健康在「不维护」时也在演化，故 restless）。
- **定义 211（维护动作与安全包络）**：𝒜_maint = {do_nothing, recalibrate(RSC/φ̂), refit(OLP), retrain(DIR), refresh_geometry(E_geo 新扫描微调/重标定), re_mine(SSB), swap_skill(USL), physical_service(清洁/润滑/换夹爪), degrade_mode, request_human}。安全包络：仅在「可暂停且非接触」状态执行；维护前 checkpoint（权重+标定+场景银行快照），维护后未过 MVE 则回滚。
- **定义 212（MVE 维护有效性）**：维护动作 a 在 t 的因果效应 ΔU = E[U_{t+Δ}|do(a)] − E[U_{t+Δ}|do(nothing)]，用中断时间序列（ITS）或合成控制（从 SSB 相似场景构造反事实）估计；若 ΔU 的置信下界 ≤ 0（无收益）或健康改善但可用性不改善（cosmetic fix），标记 maintenance_ineffective 并回滚 + 降低该动作的调度先验。
- **定义 213（GRUL 证书剩余有效期）**：T_cert = inf{t: ¬Valid(J_liro(t))}，Valid 条件含 ρ_dir ≥ 0、dir_fresh、csp_feasible、geo_hash 有效、ρ_rob ≥ 0。GRUL(t) = T_cert − t，由各退化通道到其服务极限的联合首次通过时间近似：p(GRUL) ≈ min_j p(RUL_j) 的耦合（用 copula 处理通道相关性）。给出 [GRUL^lo, GRUL^hi]。
- **定义 214（J_pulse 可用性-健康证书）**：J_pulse = (J_liro, û_t, C_t^u, ĥ_t, {RUL_j, [lo,hi]}, GRUL, maintenance_plan, plan_horizon, mve_status, pulse_ver)。Valid(J_pulse) ⇔ Valid(J_liro) ∧ (GRUL^lo > plan_horizon) ∧ (û_t 覆盖区间下界 ≥ U_low) ∧ (MSC 计划的维护在预测失效前可完成) ∧ pulse_fresh。审计链新增 pulse_ver 与维护日志哈希。
- **定义 215（降级/回滚不变式）**：任一维护动作执行期间，LIRO 进入可暂停安全态；若 MVE 判定无效或 J_pulse 校验失败，系统回滚至最近 checkpoint，并把该动作在该健康区间上的先验均值下调（负证据更新）。**维护不得使原本有效（Valid(J_pulse)）的证书变为失效**——否则视为维护事故。
- **定义 216（PULSE 闭环算子）**：语义流：[LIRO 语义步 → 执行日志沉淀 → UAT → JHS → PHM/GRUL → SLD → MSC → PulseShield → 维护执行 → MVE → 退化先验/维护模型更新 → J_pulse]；实时流：[LIRO 实时步（不变） → J_liro → 叠加最新 J_pulse 元数据（只读）]。实时路径**不新增任何计算**，只读取缓存的 J_pulse。

## 2. 关键算法骨架

```python
# UAT：隐式遥测 + 稀疏显式锚 → 可用性向量与覆盖区间
psi = extract_implicit(exec_log)          # 成功率/时长/接管/纠正/clarify/停顿
u_hat, C_u = usability.estimate(psi, anchors)   # conformal 区间
# JHS：因子图融合健康与可用性隐状态
h_post, U_latent = jhs.filter(z_telemetry, u_hat, maint_events)
# PHM：每通道 RUL + conformal 区间
rul = {j: phm.rul(j, h_post[j]) for j in channels}
# SLD：可用性定义的服务极限
h_star = sld.solve(u_events, h_trajectories, alpha_u)
# MSC：restless bandit / Whittle 调度
maint_action, plan_horizon = msc.schedule(h_post, rul, u_hat, budget, task_load)
# PulseShield：维护安全包络 + checkpoint
if not in_safe_state(): defer(maint_action)
checkpoint = snapshot()
# MVE：维护后因果验证
delta_U = mve.effect(maint_action, ssb_counterfactual)
if delta_U.lower <= 0: rollback(checkpoint); penalize(maint_action)
# GRUL / J_pulse
grul = grul.estimate(h_post, h_star)
J_pulse = build_j_pulse(J_liro, u_hat, C_u, h_post, rul, grul, maint_action)
```

## 3. 保证概要与推导要点

- **引理 5（可用性区间校准）**：若 (ψ_t, a_s) 可交换，split-conformal 使 P(U_t^true ∈ C_t^u) ≥ 1−α_u，且锚越稀区间越宽（不产生假自信）。
- **引理 6（RUL 校准）**：删失感知 conformal 生存校准使 P(RUL_j ∈ [lo,hi]) ≥ 1−α_rul，对任意基础生存模型成立（模型无关覆盖）。
- **定理 4（维护调度近似最优）**：若各退化通道在 Whittle 意义下可索引（indexable），restless bandit 的 Whittle 策略在预算 B→∞ 时相对最优的平均可用性差距趋于 0；有限预算下给出 O(√(J·T·log T)) 的 regret 型界。
- **定理 5（GRUL 安全）**：若 GRUL^lo 以概率 ≥ 1−α_g 是 T_cert 的下界，且 MSC 在 GRUL^lo 前安排维护并成功执行，则「在证书失效状态下继续运行」的概率 ≤ α_g + α_mve。
- **命题（独立通道破盲）**：在 E_geo 幻觉导致内部证书相关性失效的场景下，若可用性对几何误差单调（抓空/碰撞→成功率与接管率变化），则 UAT 的检测时延严格小于内部指标（因为内部指标以同一 g 为条件而近似不变），即 T_u < T_internal，P-F 窗口由 UAT 保持非空。
- **实时性**：PULSE 全部计算在语义流；实时路径仅读取缓存 J_pulse，新增 0ms，≤ 1ms 契约继承 LIRO。

## 5. 本轮最大风险

## 2. 形式化定义（完整版）

**定义 201（PULSE 闭环）** PULSE 是 LIRO 的「时间 × 人」外层：LIRO 每语义步给出 J_liro（此刻安全），PULSE 在其上维护健康后验 p(h_t)、可用性估计 û_t、RUL/GRUL 预测、维护计划与因果验证状态，给出 J_pulse（还能安全多久 + 维护是否有效）。不变式：全部预测/调度/验证只发生在语义流低频线程；实时路径（1–10kHz）**不新增任何计算**，只读取缓存的 J_pulse 元数据。PULSE 不修改 LIRO 的任何数据通路，只旁路观测其执行日志与证书。

**定义 202（UAT 可用性遥测）** 
- 隐式代理 ψ_t = (succ_rate, time_per_task, takeover_rate, correction_rate, clarify_rate, path_efficiency, hesitation_entropy) 由 LIRO 的 EV_exec、Shield-Skill 日志、DMS clarify 队列直接抽取（无需额外传感）。
- 显式锚 a_s = (SUS_s, TLX_s, Trust_s) 稀疏出现（每 N=50 任务或用户主动触发）。
- 六维映射：E=succ_rate，F=1−time_per_task 归一，S=1−takeover_rate，L=任务族内成功率斜率，T=1−|Trust_s − 客观可靠度|（行为信任代理=建议接受率与接管时机的偏差），A=1−clarify_rate。
- 输出 û_t = (u_t, C_t^u)；区间由定义 204 校准。**UAT 是被动的**：不打扰用户，不改变任务流。

**定义 203（可用性标量化）** U_t = Σ_i w_i φ_i(u_t^i)，φ_i 为各维 min-max 或 logit 归一键；w 由 Bradley-Terry 成对偏好（用户在两段执行中选更好）或与 SUS 的单调单调映射离线标定。可用性失效事件：U_t < U_ref 连续 Δ_u=3 个任务。U_ref、Δ_u 按任务族配置（如「递交」族更看重 S 与 T，「整理」族更看重 E 与 A）。

**定义 204（隐式-显式锚定 + Conformal）** 以显式锚 a_s 对隐式代理做残差校准：u_t^i = g_i(ψ_t) + r_i(a_s)，g_i 为离线模型，r_i 为 GP/分位数回归残差。split-conformal：留出校准集 D_cal，非一致性分数 s_t = ‖u_t^true − û_t‖，取 q = Quantile_{1−α_u}(s_t)，则 C_t^u = [û_t − q, û_t + q]。锚过稀时用同任务族历史锚做迁移并自动放大 q；**锚不足则区间显著变宽**（宁可承认不知道，也不假自信）。

**定义 205（PHM-C 退化通道）** 9 条通道及条件监测特征 z_j：
1. LiDAR 光学：回波强度直方图、有效点密度、dropout 率；
2. 关节摩擦/磨损：电流特征、温度、RSC 摩擦参数残差；
3. 夹爪柔顺：触觉标定残差、滑移事件率；
4. E_geo 几何保真：几何-物理不一致度（法向 vs 反力方向、曲率 vs 刚度）、跨视角重投影误差；
5. DIR 不变性：ε_causal 在线估计、回放缓冲上的对比对齐损失；
6. OLP 权重漂移：投影后遗憾代理、W 范数轨迹；
7. RSC 球膨胀：r_t 相对基线的膨胀率、覆盖率残差；
8. SSB 场景陈旧：新场景发现率、簇漂移、fp_cloud 碰撞率；
9. 标定有效性：φ̂ 偏差、标定时间戳老化。
每通道健康指数 h_j(t) 由对应退化状态空间模型给出。

**定义 206（随机退化与 RUL）** 
- 磨损类（关节/夹爪/LiDAR 污染）：D_j(t) 为 Gamma 过程，D_j(0)=0，增量 D_j(t+Δ)−D_j(t) ~ Gamma(α_jΔ, β_j)；h_j = 1−D_j。
- 漂移类（E_geo/DIR/OLP/标定）：dD_j = μ_j dt + σ_j dW；μ_j 由滑动窗口估计，σ_j 为扩散系数。
- 突变类（SSB 陈旧、几何分布外）：BOCPD 检测变点后重置 μ_j。
RUL_j(t) = inf{τ≥0: h_j(t+τ) ≤ h_j*}，通过蒙特卡洛（10³ 条退化轨迹）或首次通过时间解析式（Gamma/Wiener）给出预测分布。

**定义 207（Conformal RUL）** 历史维护/失效事件含右删失（未失效即被维护）。用 CQR（conformalized quantile regression）或 conformal survival：在校准集上计算非一致性分数，对删失样本用逆概率加权；输出 [RUL_j^lo, RUL_j^hi]，覆盖 ≥ 1−α_rul，**模型无关**（Weibull/Cox/GBM 均可作基础模型）。

**定义 208（SLD 服务极限）** h_j* = argmin_h E[C_maint + L_use(h)]，其中 L_use(h) 为从 h 起至下次维护的累计可用性损失（∫(U_ref − U_t)^+ dt 的期望）。等价风险形式：h_j* = max{h: P(U_{t+Δ} < U_ref | h_j(t)=h) ≤ α_u}。估计方法：以「可用性失效」为终点（而非机械故障）做存活回归，协变量含所有通道健康；对通道 j 做偏依赖/反事实扫描得到 h_j*。**这把预测性维护的"失效"定义从机械工程迁移到了人机系统**。

**定义 209（JHS 联合隐状态）** 因子图节点：h_t（健康隐态）、U_t^latent、观测 z_t、û_t、a_s、m_t（维护事件）。因子：退化转移 h_{t+1}|h_t（定义 206）、观测 z_t|h_t、可用性 û_t|h_t（可用性是健康的函数，见命题）、维护 m_t 造成的跳变 h_t→h_t^+。用粒子滤波/扩展卡尔曼；对异常通道用 Student-t 或 Huber 鲁棒因子降权，避免 E_geo 单通道幻觉污染全局健康。输出 p(h_t)、p(U_t^latent)。

**定义 210（MSC 维护调度）** 状态 s_t=(p(h_t), {p(RUL_j)}, û_t, 负载, 预算余量)。CMDP：
max_{π} E[Σ_t U_t − λ_c Σ_t C_maint(a_t)]  s.t. P(∃j: h_j ≤ h_j*) ≤ α_f, Σ C_maint ≤ B。
拉格朗日松弛为每通道「激活/被动」两臂 restless bandit：通道在被动时健康仍退化（restless），激活时执行对应维护并支付成本。Whittle 指数 I_j(s) = 使两臂 Q 值相等的补贴；按 I_j 降序调度。切换成本与共享预算通过索引阈值与预算影子价格 λ_B 处理。

**定义 211（维护动作与安全包络）** 𝒜_maint = {do_nothing, recalibrate(RSC/φ̂), refit(OLP), retrain(DIR), refresh_geometry(E_geo), re_mine(SSB), swap_skill(USL), physical_service, degrade_mode, request_human}。安全包络（PulseShield）：维护仅当 (i) 机器人处于可暂停、非接触状态；(ii) 当前 J_pulse 有效或可安全降级；(iii) 已生成 checkpoint（权重+标定+SSB 快照+GRUL 记录）。维护期间强制 degrade_mode 或暂停任务，Shield-Skill 拒绝任何接触类技能提案。

**定义 212（MVE 维护有效性）** 维护动作 a 于 t 执行的因果效应 ΔU = E[U_{t+Δ}|do(a)] − E[U_{t+Δ}|do(nothing)]。估计：
- 中断时间序列（ITS）：以维护时刻为断点，控制任务难度/时段协变量，检验水平跳变与斜率变化；
- 合成控制：从 SSB 中匹配 fp_cloud/φ_sig 相似且未维护的场景，构造反事实轨迹。
判定：ΔU 的 95% 下界 ≤ 0 → maintenance_ineffective；若健康指标显著改善但 ΔU 无改善 → cosmetic_fix（化妆式维护）。两者都触发回滚 + 该动作在该健康区间先验均值下调。

**定义 213（GRUL 证书剩余有效期）** T_cert = inf{t: ¬Valid(J_liro(t))}，Valid 条件见第 63 轮定义 197（ρ_dir ≥ 0、dir_fresh、csp_feasible、geo_hash 有效、ρ_rob ≥ 0）。GRUL(t) = T_cert − t。联合预测：对各通道首次通过时间用 copula（Gaussian/Clayton，相关性由 JHS 后验残差估计）耦合，p(GRUL) = P(min_j T_j − t)。输出 [GRUL^lo, GRUL^hi]，并给出「最早失效通道」解释（可解释性）。

**定义 214（J_pulse）** J_pulse = (J_liro, û_t, C_t^u, ĥ_t, {RUL_j, [lo,hi]}, GRUL, maintenance_plan, plan_horizon, mve_status, pulse_ver)。
Valid(J_pulse) ⇔ Valid(J_liro) ∧ GRUL^lo > plan_horizon ∧ û_t 下界 ≥ U_low ∧ MSC 计划维护可在预测失效前完成 ∧ pulse_fresh（pulse_ver ≥ curr_ver − 1）∧ mve_status ≠ ineffective_pending。
审计链：pulse_ver、geo_hash、维护日志哈希、mve 因果估计版本。

**定义 215（降级/回滚不变式）** 维护执行期间 LIRO 处于安全态；若 MVE 失败或 J_pulse 校验失败，回滚至最近 checkpoint，并对该维护动作在该健康区间做负证据更新（Beta-Binomial 后验成功率下调）。**不变式：维护不得把有效证书变为无效**——任何此类事件记为维护事故，必须进入 SSB 并触发根因分析。

**定义 216（PULSE 闭环算子）** 语义流：[LIRO 语义步 → EV_exec/日志沉淀 → UAT → JHS → PHM/GRUL → SLD → MSC → PulseShield → 维护执行 → MVE → 退化先验与维护模型更新 → J_pulse 构建]；实时流：[LIRO 实时步（完全不变） → J_liro → 只读叠加缓存 J_pulse 元数据]。**实时路径新增 0ms**，LIRO ≤ 1ms 契约完全继承。

### IP-204 UAT（可用性遥测 + conformal）

```python
class UsabilityTelemetry:
    def __init__(self, alpha_u=0.1, anchor_period=50):
        self.alpha_u, self.anchor_period = alpha_u, anchor_period
        self.cal_scores = []          # 非一致性分数校准集
        self.anchors = []             # (psi, explicit_ratings)
        self.n_tasks = 0

    def implicit(self, exec_log):
        return {
            'succ': exec_log.success,
            'time': exec_log.time_per_task,
            'takeover': exec_log.takeovers,
            'correction': exec_log.corrections,
            'clarify': exec_log.clarifications,
            'path_eff': exec_log.path_efficiency,
            'hesit_ent': entropy(exec_log.pause_intervals),
        }

    def to_vector(self, psi):
        E = psi['succ']
        F = 1.0 - normalize(psi['time'])
        S = 1.0 - normalize(psi['takeover'])
        L = self._learning_slope()
        T = 1.0 - abs(self.trust_reported - self.objective_reliability())
        A = 1.0 - normalize(psi['clarify'] + psi['correction'])
        return np.array([E, F, S, L, T, A])

    def estimate(self, exec_log):
        psi = self.implicit(exec_log)
        u = self.to_vector(psi)
        u = self._residual_correct(u, psi)              # 用最近锚做残差校准
        q = np.quantile(self.cal_scores, 1 - self.alpha_u) if self.cal_scores else np.inf
        return u, np.array([u - q, u + q])              # C_u

    def add_anchor(self, psi, sus, tlx, trust):
        u_true = self._anchor_to_vector(sus, tlx, trust)
        u_pred = self.to_vector(psi)
        self.cal_scores.append(np.linalg.norm(u_true - u_pred, ord=np.inf))
        self.anchors.append((psi, u_true))
        if len(self.anchors) > 200: self.anchors.pop(0)
```

### IP-205/207 PHM-C（退化 + RUL conformal）

```python
class HealthPrognostics:
    def __init__(self, channels, alpha_rul=0.1):
        self.channels, self.alpha_rul = channels, alpha_rul
        self.models = {j: DegradationModel(kind=CHANNEL_KIND[j]) for j in channels}
        self.rul_cal = {j: [] for j in channels}

    def update(self, z, dt):
        h = {}
        for j in self.channels:
            self.models[j].step(z[j], dt)               # Gamma/Wiener/BOCPD 更新
            h[j] = 1.0 - self.models[j].damage()
        return h

    def rul(self, j, h_j, h_star):
        dist = self.models[j].first_passage(h_j, h_star)  # 1e3 条 MC 轨迹或解析
        lo, hi = self._conformal(j, dist)
        return {'mean': dist.mean(), 'lo': lo, 'hi': hi, 'dist': dist}

    def _conformal(self, j, dist):
        q = np.quantile(self.rul_cal[j], 1 - self.alpha_rul) if self.rul_cal[j] else np.inf
        return max(0.0, dist.quantile(self.alpha_rul/2) - q), dist.quantile(1-self.alpha_rul/2) + q

    def calibrate(self, j, true_rul, pred_dist):
        self.rul_cal[j].append(abs(true_rul - pred_dist.median()))
```

```python
class ServiceLimitDiscovery:
    """以『可用性失效』为存活终点估计 h_j*，而非机械故障。"""
    def __init__(self, alpha_u=0.1, horizon=50):
        self.alpha_u, self.horizon = alpha_u, horizon
        self.survival = None                      # 存活模型（Weibull/Cox/GBM）

    def fit(self, histories, u_events):
        # histories: 每通道健康轨迹；u_events: 可用性失效时刻（可删失）
        X = np.stack([h_trajectory_at(histories, t) for t in range(len(u_events))])
        self.survival = SurvivalModel().fit(X, u_events, censoring=...)

    def solve(self, j):
        # 扫描 h，找满足 P(U_{t+Δ}<U_ref | h_j=h) ≤ α_u 的最大 h
        grid = np.linspace(0, 1, 101)
        risks = [self.survival.risk(h=h, horizon=self.horizon, channel=j) for h in grid]
        feasible = [h for h, r in zip(grid, risks) if r <= self.alpha_u]
        return max(feasible) if feasible else 0.0

    def cost_optimal(self, j, c_maint, loss_fn):
        grid = np.linspace(0, 1, 101)
        vals = [c_maint + loss_fn(h) for h in grid]
        return grid[int(np.argmin(vals))]
```

### IP-208 MSC（restless bandit 调度）

```python
class MaintenanceScheduler:
    def __init__(self, channels, lambda_c=1.0, alpha_f=0.05, budget=100.0):
        self.channels, self.lambda_c = channels, lambda_c
        self.alpha_f, self.budget = alpha_f, budget
        self.index = {j: WhittleIndex(CHANNEL_MAINT[j]) for j in channels}

    def schedule(self, h_post, rul, u_hat, load):
        # 1) 失效风险约束 → 提高紧迫通道的索引
        urgency = {j: (h_post[j] <= SAFE_MARGIN[j]) for j in self.channels}
        # 2) Whittle 索引（含预算影子价格 λ_B）
        idx = {j: self.index[j].value(h_post[j], rul[j], lambda_B=self._shadow_price())
               for j in self.channels}
        # 3) 选择：先满足 urgency，再按索引降序、预算内贪心
        order = sorted(self.channels, key=lambda j: (urgency[j], idx[j]), reverse=True)
        plan, spent = [], 0.0
        for j in order:
            if spent + COST[j] <= self.budget and (urgency[j] or idx[j] > THETA):
                plan.append((j, CHANNEL_MAINT[j]))
                spent += COST[j]
        plan_horizon = min(rul[j]['lo'] for j, _ in plan) if plan else float('inf')
        return plan, plan_horizon

    def _shadow_price(self):
        return self.lambda_c * (1.0 + 0.1 * self.budget_usage())
```

```python
        lo, hi = bootstrap_ci(post - synth)
        cosmetic = (health_hist[t:].mean() - health_hist[t-1]) > 0 and hi < 0
        if lo <= 0 or cosmetic:
            return {'delta_U': delta_U, 'lo': lo, 'hi': hi,
                    'status': 'cosmetic_fix' if cosmetic else 'ineffective'}
        return {'delta_U': delta_U, 'lo': lo, 'hi': hi, 'status': 'effective'}
```

### IP-210 GRUL（证书剩余有效期）

```python
class GuaranteeRUL:
    def __init__(self, channels, alpha_g=0.1):
        self.channels, self.alpha_g = channels, alpha_g

    def estimate(self, rul, h_star, cert_conditions):
        # 各通道首次通过时间样本（来自 RUL 分布）
        samples = {j: rul[j]['dist'].sample(1000) for j in self.channels}
        # copula 耦合（相关性来自 JHS 残差）
        corr = estimate_channel_corr()
        coupled = gaussian_copula(samples, corr)
        T_cert = np.min(np.stack(list(coupled.values())), axis=0)
        lo = np.quantile(T_cert, self.alpha_g / 2)
        hi = np.quantile(T_cert, 1 - self.alpha_g / 2)
        earliest = min(self.channels, key=lambda j: samples[j].mean())
        return {'mean': T_cert.mean(), 'lo': lo, 'hi': hi, 'earliest': earliest}
```

### IP-211/213 PULSE 闭环算子

```python
def PULSE_semantic_step(M, J_liro, exec_log, t):
    # 1) 可用性遥测（旁路，不干扰任务流）
    u_hat, C_u = M.uat.estimate(exec_log)
    if exec_log.needs_anchor(): M.uat.add_anchor(exec_log.psi, *exec_log.explicit)
    # 2) 健康状态融合
    z = collect_telemetry(M, exec_log)
    h_post, U_latent = M.jhs.filter(z, u_hat, M.maint_events)
    # 3) SLD 服务极限（低频重估，如每 1000 步）
    if t % 1000 == 0:
        M.sld.fit(M.health_history, M.u_events)
        h_star = {j: M.sld.solve(j) for j in M.channels}
    # 4) PHM-C RUL + GRUL
    rul = {j: M.phm.rul(j, h_post[j], h_star[j]) for j in M.channels}
    grul = M.gruls.estimate(rul, h_star, J_liro.conditions)
    # 5) 调度 + 安全包络
    plan, plan_horizon = M.msc.schedule(h_post, rul, u_hat, M.load)
    if plan and M.pulseshield.in_safe_state():
        ckpt = M.pulseshield.checkpoint()
        M.liro.enter_degraded_mode()
        for j, action in plan:
            execute_maintenance(M, action)
            eff = M.mve.effect(action, t, M.u_history, M.health_history)
            if eff['status'] != 'effective':
                M.pulseshield.rollback(ckpt)
                M.msc.penalize(action, h_post[j])
                break
        M.liro.exit_degraded_mode()
    # 6) 构建 J_pulse
    return build_j_pulse(J_liro, u_hat, C_u, h_post, rul, grul,
                         plan, plan_horizon, M.mve.status, pulse_ver=M.pulse_ver)
```

## 4. 推导

**引理 5（可用性区间校准）** 设校准样本 (ψ_t, a_s) 与测试样本可交换，非一致性分数 s_t = ‖U_t^true − û_t‖_∞，q = Quantile_{1−α_u}({s_t})。由 split-conformal 的经典结论，P(U_t^true ∈ [û_t−q, û_t+q]) ≥ 1−α_u（有限样本、分布无关）。当显式锚减少时，残差模型方差增大 → q 单调增大，区间变宽而不产生假自信。∎

**引理 6（RUL 区间校准）** 对删失数据以逆概率加权构造非一致性分数 s = |T − median(p)|，校准集覆盖 1−α_rul。conformal survival 的一步、模型无关性质给出 P(T ∈ [lo,hi]) ≥ 1−α_rul，只要校准与测试的删失机制可交换。∎

**定理 4（维护调度近似最优）** 将 9 条通道视为 restless bandit，若每条通道的「维护/不维护」两臂满足 indexability（Whittle 1979；Weber–Weiss 1990 的单调性条件），则 Whittle 策略在每步可维护通道数 M 与预算 B 增长时，平均可用性收益收敛到松弛最优的 (1−1/M) 比例界；有限预算下，标准 rested/restless 分析给出 O(√(J·T·log T)) 的 regret 上界。CMDP 的失效风险约束经拉格朗日乘子 λ_f 并入奖励，λ_f 用原始-对偶在线更新保证约束满足率 → α_f。∎

**定理 5（GRUL 安全）** 若 GRUL^lo 以概率 ≥ 1−α_g 下界 T_cert（由引理 6 与 copula 保序性），且 MSC 在 GRUL^lo 之前完成维护并经 MVE 验证有效（成功概率 ≥ 1−α_mve），则「系统在证书已失效状态下继续运行」的概率 ≤ α_g + α_mve + α_f。证明：三类失败事件取并集界。∎

**命题（独立通道破盲，回应第 63 轮最大风险）** 设 E_geo 幻觉使内部指标 Ï = (φ̂, ρ_rob, ρ_dir) 满足 Ï = F(g)，即**以同一 g 为条件**。当 g→g+δ（幻觉）时，内部指标的变化可被自洽性地「吸收」（例如 φ̂ 与 𝒢(g) 同向偏移，ρ_rob 仍在错误球内为正），故 ∂Ï/∂δ 可能很小。而可用性 U 依赖**真实物理结果**（是否抓空、是否碰撞、是否反复失败），∂U/∂δ 不由 g 决定。若 U 对几何误差单调，则用阈值检测时 T_U(δ) < T_Ï(δ)，P-F 窗口由 UAT 保持非空。这正是「可用性评估作为安全关键独立传感器」的形式化理由。∎

**命题（MVE 化妆式维护识别）** 若维护动作 only 改变可观测健康指标而真实任务能力不变，则 ΔU = 0 但 Δh > 0；MVE 的合取判据（Δh>0 ∧ ΔU 置信上界<0）以高于随机水平识别该类动作；合成控制消除任务难度混杂后，误判率由匹配质量（SSB fp_cloud 距离）控制。∎

## 7. 已知风险

**一句话**：如果人类会**适应**退化（习得性无助、锚定、对慢速劣化不敏感），可用性曲线会在崩溃前长期平坦，P 点被拖到接近 F 点、P-F 窗口消失；更糟的是 MSC 若以可用性代理为奖励，可能学会「少问澄清、强推任务、隐藏错误」的**化妆式维护**，短期指标上升而真实健康继续恶化（A83/A86 的单点假设：可用性代理必须与真实任务能力保持单调耦合）。

**次级风险与缓解**：
1. **可用性代理被博弈**：MSC 直接优化 U 代理会 incentives 操纵 → 代理只用**不可被策略直接写入**的被动行为量（接管、碰撞、重复失败），并在 MVE 中强制以真实任务结果为准；对代理与显式锚做持续一致性审计。
2. **显式锚过稀/有偏**：受试者样本偏置 → 分层锚定（按任务族/经验水平）+ 主动学习选锚点 + 区间自动放宽；锚不足时不触发高风险维护。
3. **删失与维护事件混淆**：「维护后未失效」不等于「健康」 → conformal survival 的逆概率加权 + 反事实（不做维护）合成控制双保险。
4. **通道相关性导致 RUL 过度乐观**：E_geo 与 DIR 同源退化 → copula 相关性由 JHS 残差在线估计，并在相关性高时对 GRUL 做保守下修。
5. **维护本身破坏系统**：标定/重训引入回归 → PulseShield 安全包络 + checkpoint/回滚 + MVE 门控；维护不得使有效证书失效（定义 215）。
6. **计算/存储开销**：RUL MC 与存活回归较重 → 全部放语义流低频（每 1000 步），实时路径零新增；RUL 用解析首次通过时间近似替代 MC。
7. **长尾场景无历史失败样本**：某些通道从未失效 → 用物理退化模型 + 加速老化台架的先验迁移，并显式标注「无数据区间」使 GRUL 区间变宽而非乐观。
