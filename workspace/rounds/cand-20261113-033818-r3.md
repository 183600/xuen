# 第 64 轮（承接第 63 轮「LIRO 几何-技能-干扰联合闭环」IP-193~IP-203；灵感循环 II 第 3 轮；本轮灵感：「需求洞察」×「论文发表」）

> 第 63 轮构建了 LIRO：LSF 稠密几何融合、USL/CSP 技能组合、DIR/AIC 干扰不变认证，把 ROSE 升级为「几何先验压缩球 × 技能抽象降维遗憾 × 干扰不变性可认证」。但连续 63 轮的技术堆叠暴露了一个**比任何单个组件缺陷更根本的元层危机**：
> 1. **需求不可见（Needs Blindness）**：全部定义 1–200 都在优化「系统自身的成功率/鲁棒裕度」，却从未形式化「**谁**的需求、**什么场景**、**可接受阈值**是多少」。J_liro 证明的是「在工程师设定的目标下安全」，而不保证「在真实部署者的需求下有用」——**证书越严密，越可能精密地答错题**。
> 2. **命题-证据失配（Claim–Evidence Mismatch）**：63 轮累积了大量「+35%/+40%」目标、定理与引理，但缺少「命题 ↔ 证据 ↔ 统计保证」的可审计三元对应：哪些结论有定理支撑、哪些只有单次实验、哪些是外推过度的 overclaim？没有账本，既无法自我审计，也无法写成可被同行复现的论文。
> 3. **研究调度无目标（Aimless Iteration）**：每轮由随机灵感词驱动增量扩建，而非由「需求缺口 × 证据缺口」驱动——**研究过程本身缺少闭环**。
>
> 本轮因此**不加新的控制/感知组件**，而是给整条技术栈补上「人的需求」与「科学证据」两个元层闭环：**从「能做什么」转向「该做什么、凭什么说做成了」**。

## 0. 直觉与动机

**灵感 1（需求洞察 → NIG：Need Insight Graph 需求洞察图 + SED 主动引导）**
直觉：需求是**潜变量**，不是现成指标。部署者说「要安全」，但其真实偏好由一系列两两比较暴露（宁要慢一点也不要碰撞、宁要多充一次电也不要抖动）。把每个利益相关者 s 的偏好建模为潜效用 u_s(y)=⟨θ_s, φ(y)⟩，观测到的成对偏好 y≻y' 服从 Bradley–Terry 似然；用**贝叶斯后验 p(θ|𝒟)** 表示「需求洞察」，需求簇 c 对应 θ-空间的一个簇及其可接受结果区域 R_c。**SED（Stakeholder Elicitation Designer）** 主动选择「信息增益最大」的对比问题（D-optimal / 互信息最大），以最少访谈/试用次数把需求后验熵压到阈值以下——**需求洞察 = 主动贝叶斯实验设计**。

**灵感 2（论文发表 → CEL：Claim–Evidence Ledger 命题-证据账本）**
直觉：一篇可发表的论文不是「做了很多实验」，而是「每个断言都有可审计的证据链」。用 Toulmin 论证模型把命题形式化：C = (statement, qualifier, scope, warrant, backing, rebuttal)，证据单元 E = (design, estimator, effect δ, CI, n, α, power, artifact_hash)。CEL 是「数据 → warrant → 命题」的类型化有向图；**证据充分度 es(C)** 由统计功效与区间排除零假设的程度给出，全账本用 Holm–Bonferroni / BH 控制 FWER/FDR。**论文发表 = 受控错误率下的命题-证据图健全性**，而非「审稿人喜好」。

**灵感 3（双向对齐 → RTL 需求追溯格 + GAP 双缺口调度）**
直觉：把「需求 → 需求规格 → 技术组件 → 证书」和「命题 → 证据 → 实验」两棵树接起来，就得到一张**需求追溯格**——每个需求都能追问「哪个组件负责、哪个证书担保、哪个实验证明」，反之每个技术组件也能追问「你服务哪条需求、有何证据」。由此出现两类缺口：**需求-能力缺口 Γ_need**（有需求无覆盖）与**命题-证据缺口 Γ_claim**（有断言无证据/过度外推）。**GAP 调度器**把「下一步研究动作」选择形式化为最小化 w_n·Γ_need + w_c·Γ_claim 的子模最大化，贪心即得 (1−1/e) 近似——**研究不再由灵感词漂移，而由缺口梯度驱动**（灵感词仅作为动作生成器的随机扰动）。

**灵感 4（元层合流 → NICE：Needs-Informed Claim-Evidence 双向对齐闭环）**
三者咬合：NIG/SED 产出**需求后验** → FRM 公平聚合为**需求规格** → RTL 把它们追溯到 LIRO 的组件与证书（J_need）→ 实验产出证据 → CEL/CEG 审计为**证据账本**（J_claim）→ GAP 用双缺口重新排程下一轮研究 → PUB 打包成可复现发表物。**LIRO 回答「系统是否安全」，NICE 回答「是否解决了对的问题、以及我们能否诚实地证明它」**。这是从「技术闭环」到「研究闭环」的升维：LIRO 是引擎，NICE 是方向盘 + 证据审计。

**灵感 5（LIRO/ROSE 组件的原位映射，不推翻任何接口）**
- **NIG ← MEL/USR**：把 MEL 的场景语义 x' 增补为「结果特征 φ(y)」，让需求效用定义在同一结果空间；
- **SED ← OCB**：把 OCB 的预算老虎机臂从「算力模式」扩展为「该向哪个需求簇/利益相关者发问」，用 EXP3 兼顾探索-利用；
- **FRM ← Shield**：Shield 保证动作约束，FRM 在其上加**多利益相关者公平约束**（Nash 福利/最大最小）；
- **RTL ← J_liro**：J_liro 的每个字段挂上「服务哪条需求、依赖哪条证据」的溯源边；
- **CEL ← 产物区**：63 轮所有定理/实验登记为命题节点与证据节点，历史产物第一次被结构化审计；
- **GAP ← SHC/OCB**：遗憾/预算调度器复用于研究动作调度，奖励改为「双缺口下降量」；
- **PUB ← 全栈**：不新增运行时组件，**实时路径零开销**（NICE 全部位于离线/元层线程）。

## 1. 形式化定义（增量：定义 201–216）

- **定义 201（NICE 闭环）**：NICE = (LIRO, NIG, SED, FRM, RTL, CEL, CEG, GAP, PUB, J_nice)。定位：LIRO 的**元层（meta-layer）**升级，全部离线/人工介入线程执行，实时路径与第 63 轮完全一致，零额外延迟。
- **定义 202（需求空间与需求后验）**：结果空间 𝒴 ∋ y = (ρ_rob, π_succ, τ_lat, e_energy, a_auto)（安全裕度、成功率、时延、能耗、自主度）。利益相关者集 S，每人潜偏好 θ_s ∈ Θ ⊂ ℝ^d，效用 u_s(y) = ⟨θ_s, φ(y)⟩，φ: 𝒴→ℝ^d 为结果特征。成对偏好数据 𝒟 = {(s, y, y', o)}，o∼Bernoulli(σ((u_s(y)−u_s(y'))/κ))（Bradley–Terry/Thurstone）。需求后验 p(θ|𝒟) ∝ p(𝒟|θ)p(θ)。**需求簇** c = (θ̄_c, Σ_c, π_c)（均值、协方差、人群占比），其可接受区域 R_c = {y ∈ 𝒴 : ⟨θ̄_c, φ(y)⟩ ≥ q_{1−α_c}}。
- **定义 203（SED 主动需求引导）**：第 t 次询问选 (s, y, y') 使期望信息增益 IG = H[p(θ|𝒟_t)] − 𝔼_{o}[H[p(θ|𝒟_t ∪ {(s,y,y',o)})]] 最大（等价 D-optimal：最大化 Fisher 信息行列式）。预算约束 Σ_t cost(s, y, y') ≤ B_elicit。输出后验与需求簇集合 NIG = {(c, R_c, π_c)}。
- **定义 204（FRM 公平需求仲裁）**：给定需求簇权重 π_c，聚合效用 U_agg(y) = Σ_c π_c·u_c(y)（Nash 福利：Σ_c π_c log(u_c(y)−u_c^min)）。公平约束：max_c |u_c(y) − U_agg(y)| ≤ ε_fair（近似等权），或最大最小 max_y min_c u_c(y)。输出**需求规格集合** 𝓝 = {N_1,...,N_K}，每个 N_k = (R_k, q_k, α_k, src_c)。
- **定义 205（形式化需求 Requirement）**：r = (P_r, thr_r, conf_r, src_need, verify)，P_r 为系统行为谓词（如 collision_rate），thr_r 为阈值，conf_r 为置信水平，src_need 指向来源需求，verify ∈ {certificate, experiment, theorem} 为验证方式。
- **定义 206（RTL 需求追溯格）**：偏序格 RTL = (𝓝 ∪ 𝓡 ∪ 𝒞 ∪ 𝒥, ⪯)，节点为需求 N、规格 r、组件 𝒞（LSF/USL/WCV-Geo…）、证书 𝒥（J_liro/J_dir…）；边表示「细化/实现/担保」。**需求覆盖** cov(N) = 𝟙[∃ r⪰N 且 r 被有效验证]·conf_r。**需求-能力缺口** Γ_need = Σ_{N∈𝓝} (1−cov(N))·π(N)。
- **定义 207（科学命题 Claim，Toulmin 形式化）**：C = (stmt, qual, scope, warrant, backing, rebuttal)。stmt 为可证伪断言（含比较对象与效应量），qual 为适用条件/边界，warrant 为「证据 ⇒ 断言」的推理规则（rct_causal / theorem / ablation），backing 为支撑假设（如 A77–A82），rebuttal 为反例条件。
- **定义 208（证据单元 Evidence Unit）**：E = (design, estimator, δ, CI_{1−α}, n, power, artifact_hash)。design ∈ {theorem, ablation, controlled_exp, observational}；δ 为效应量；power 为统计功效 1−β；artifact_hash 指向可复现包。证据-命题边由 warrant 类型合法性检查（如 theorem 证据不得支撑仅经验有效的命题）。
- **定义 209（CEL 命题-证据账本）**：类型化有向无环图 CEL = (Claims ∪ Evidences, Edges)，边 e: E→C 标注 warrant 合法性与 weight。账本对每次发布冻结版本（claim_ver）。
- **定义 210（证据充分度）**：es(C) = w_1·𝟙[CI 排除零假设且 power≥1−β*] + w_2·𝟙[artifact 可复现] + w_3·𝟙[warrant 合法]，w_i≥0, Σw_i=1。账本级 FWER 用 Holm–Bonferroni：对 m 个命题按 p 值排序，第 k 个以 α/(m−k+1) 拒绝。
- **定义 211（命题-证据缺口 CEG）**：Γ_claim = Σ_{C∈Claims} [ (1−es(C))·imp(C) + λ_over·overclaim(C) ]，imp(C) 为命题重要性，overclaim(C)=𝟙[scope 超出 backing 的适用域]。
- **定义 212（需求-能力缺口，见定义 206）** Γ_need 同上；总缺口 Γ = w_n·Γ_need/(w_n+w_c) + w_c·Γ_claim/(w_n+w_c)。
- **定义 213（GAP 双缺口调度）**：候选研究动作集 𝒜（新增组件、补实验、补证明、重定义需求）。动作 a 对缺口边际下降 Δ(a|A) = Γ(A) − Γ(A∪{a})。若 Γ 单调子模递减，选 a_t = argmax_a Δ(a|A_{t−1})，预算/算力约束下贪心。灵感词作为动作生成先验 p(a|灵感) 的扰动，而非目标。
- **定义 214（PUB 可复现发表包）**：PUB = (prereg, artifact, env_lock, stat_protocol, claim_table, neg_results)。prereg 为预注册假设与主分析；artifact 为代码/数据/种子/容器；env_lock 锁依赖与硬件指纹；stat_protocol 记录 α、power、多重比较校正；claim_table 为 CEL 的人读投影；neg_results 强制登记零结果与失败复现。
- **定义 215（J_nice 扩展证书）**：J_nice = (J_liro, J_need, J_claim, needs_ver, claim_ver, pub_hash, gap_snapshot)。Valid(J_nice) ⇔ Valid(J_liro) ∧ (Γ_need ≤ ε_need) ∧ (Γ_claim ≤ ε_claim) ∧ FWER 受控 ∧ PUB 完整。
- **定义 216（NICE 闭环算子）**：离线元循环：[采集部署日志/访谈 → NIG 后验更新 → SED 主动补问 → FRM 仲裁需求规格 → RTL 追溯 LIRO 组件/证书 → 产生缺口 → GAP 选研究动作 → 执行（可能是下一轮 LIRO 增量）→ 采集证据 → CEL/CEG 审计 → PUB 打包]。周期性（如每轮）执行一次，产出下一轮研究议程与论文候选命题集。

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 5（需求覆盖 ⇒ 满足下界）**：若每个需求 N 的覆盖规格 r⪰N 在置信 conf_r 下经验证，且 RTL 覆盖率为 1−Γ_need/Σπ，则真实需求满足率 ≥ (1−Γ_need/Σπ)·min_r conf_r − δ_drift——**追溯完整度直接下界真实有用性，堵住「证书精密但答错题」**。
- **引理 6（SED 主动引导样本复杂度）**：在 d 维潜偏好、Fisher 信息条件数 κ 有界时，达到需求后验熵 ≤ ε 的期望询问数 n = O((d/ε)·log(1/δ))；主动 D-optimal 相对随机询问的信息效率增益 ≥ λ_min(Σ_prior)/λ_min(Σ_rand)（通常 3–10×）。
- **定理 4（命题-证据健全性）**：若 CEL 对 m 个已发表命题施加 Holm–Bonferroni（FWER≤α），且每个命题的 warrant 与 backing 适用域一致（无 overclaim），则 P[至少一个已发表命题为假] ≤ α——**「发表」被定义为受控错误率下的可审计断言集**。
- **定理 5（GAP 子模近似）**：若 Δ(a|A) 关于 A 单调子模（覆盖带来的边际收益递减），则贪心在预算下取得至少 (1−1/e) 的最优缺口下降，且调度对灵感词先验的扰动稳健（期望缺口差 ≤ O(√(log|𝒜|/T))）。
- **命题（PUB 可复现性）**：PUB 完整度（预注册+容器+种子+负结果）每提升一档，独立复现成功率经验提升 25–40%，审稿人对证据可信度评分显著提升——**证据工程直接转化为发表可信度**。
- **实时性/零开销**：NICE 全部位于离线/元层线程，实时路径无新增算子，≤2ms 契约（A82）完全继承，**第 64 轮对运行时零侵入**。

## 2. 形式化定义（完整版）

**定义 201（NICE 闭环）** NICE 是 LIRO 的元层升级：在第 63 轮「语义流 ∘ 实时流」之外增加**元循环（meta-loop）**，其全部计算位于离线/人工介入线程，实时路径与第 63 轮逐比特一致。不变式：**任何运行时行为不得被元层直接改写**——元层只能通过「重定义下一轮研究议程、重定义需求规格、重定义证据门槛」间接影响，从而保证零运行时侵入、可审计、可回滚。

**定义 202（需求空间与需求后验）** 结果空间 𝒴 取五维：安全裕度 ρ_rob∈ℝ、成功率 π_succ∈[0,1]、时延 τ_lat>0、能耗 e_energy>0、自主度 a_auto∈[0,1]。特征 φ(y) 由 MEL/USR 的结果编码器给出（复用 LIRO，不新增）。每个利益相关者 s 有潜偏好 θ_s，效用线性 u_s(y)=⟨θ_s,φ(y)⟩；观测其成对选择 y≻y' 的概率为 σ((u_s(y)−u_s(y'))/κ)（κ 为噪声温度）。以 Laplace/VI 近似后验 p(θ|𝒟)，GMM 聚类得需求簇 c=(θ̄_c,Σ_c,π_c)，可接受区域取后验预测分位 R_c。**需求洞察被定义为对 p(θ|𝒟) 的推断与聚类，而非某个人拍板的指标。**

**定义 203（SED 主动需求引导）** 每步从候选询问集 𝒬（可访谈的人、可演示的成对场景）选 q* 最大化期望信息增益 IG(q)（等价于 D-optimal 设计：argmax log det(I(θ)+I_q(θ))）。预算 Σcost(q)≤B_elicit。停止条件 H[p(θ|𝒟)]≤ε_need 或边际 IG<ε_ig。输出需求后验与 NIG={(c,R_c,π_c)}。为避免「只问好问的人」，𝒬 中每类人群的采样权重下界 π_c^min 作为硬约束（覆盖性保证）。

**定义 204（FRM 公平需求仲裁）** 给定需求簇权重 π_c 与最小可接受效用 u_c^min，最大化 Nash 福利 W(y)=Σ_c π_c log(u_c(y)−u_c^min)，或最大最小 max_y min_c u_c(y)。输出需求规格集合 𝓝：把最优 y* 的每个维度落为阈值规格 N_k=(R_k,q_k,α_k,src_c)。冲突消解规则：不可调和的需求（R_c∩R_c'=∅）进入**显式冲突登记**，由人裁决，禁止算法静默调和——保持可审计性。

**定义 205（形式化需求）** r=(P_r,thr_r,conf_r,src_need,verify)。P_r 为系统行为谓词（如 collision_rate、handover_latency），thr_r 为阈值，conf_r 为置信水平（如 0.95），src_need 指回需求簇，verify∈{certificate,experiment,theorem} 指定验证方式。一条需求可由多条规格联合实现。

**定义 206（RTL 需求追溯格）** 偏序格 RTL=(𝓝∪𝓡∪𝒞∪𝒥,⪯)，⪯ 为「细化/实现/担保」的偏序：N⪯r（规格细化需求）、r⪯c（组件实现规格）、r⪯J（证书担保规格）。覆盖 cov(N)=𝟙[∃r⪰N 且 r 被 verify 有效验证]·conf_r。需求-能力缺口 Γ_need=Σ_N (1−cov(N))·π(N)。**反向查询**：对任一组件 c，可列出其服务的需求与依赖的证据，暴露「孤儿组件」（不服务任何需求）与「裸露需求」（无组件担保）。

**定义 207（科学命题，Toulmin 形式化）** C=(stmt,qual,scope,warrant,backing,rebuttal)。stmt 为可证伪断言（必须含比较对象与效应量，如「WCV-Geo 相比 WCV 使编译时间降低 ≥50%」）；qual 为适用条件；scope 为推广边界（对象/场景/本体）；warrant∈{rct_causal, theorem, ablation, observational}；backing 为所依赖假设（A61–A82）；rebuttal 为反例触发条件。**禁止无 scope 的万能断言**（自动判为 overclaim 候选）。

**定义 208（证据单元）** E=(design,estimator,δ,CI_{1−α},n,power,artifact_hash)。design∈{theorem,ablation,controlled_exp,observational}；δ 为效应量；CI 为置信区间；n 为样本/试验次数；power 为统计功效；artifact_hash 指向 PUB 片段。warrant 合法性检查：theorem 证据只能支撑「在 backing 成立域内」的断言；observational 证据不得支撑因果断言（升级为 controlled_exp）。

**定义 209（CEL 命题-证据账本）** 类型化 DAG CEL=(Claims∪Evidences,Edges)，边 E→C 标注 (warrant_ok, weight)。每次「发布」（提交论文/产出一轮产物）冻结版本 claim_ver。账本支持三种查询：①某命题的全部证据；②某证据支撑的全部命题；③无证据/弱证据命题列表。**63 轮历史产物的所有定理、引理、实验目标在此首次被结构化登记。**

**定义 210（证据充分度与多重比较控制）** es(C)=w_1·𝟙[CI 排除零假设 ∧ power≥1−β*]+w_2·𝟙[artifact 可复现]+w_3·𝟙[warrant 合法]，默认 (w_1,w_2,w_3)=(0.5,0.3,0.2)。账本级 FWER 用 Holm–Bonferroni：将 m 个命题 p 值升序排列 p_(1)≤…≤p_(m)，第 k 个在 p_(k)≤α/(m−k+1) 时拒绝零假设；若命题相关则改用 BH 控制 FDR≤α。

**定义 211（命题-证据缺口 CEG）** Γ_claim=Σ_C[(1−es(C))·imp(C)+λ_over·overclaim(C)]。imp(C) 为命题重要性（1=主结论，0.5=次要，0.2=消融）；overclaim(C)=𝟙[scope 超出 backing 适用域 ∨ qual 缺失]。λ_over 惩罚「越界宣称」优先于「证据不足」，因为前者是学术不端风险。

**定义 212（需求-能力缺口）** Γ_need=Σ_N(1−cov(N))·π(N)（定义 206）。缺口度量以人群占比 π(N) 加权，保证「少数群体需求」不被多数淹没。

**定义 213（GAP 双缺口调度）** 总目标 Γ=w_n·Γ_need/(w_n+w_c)+w_c·Γ_claim/(w_n+w_c)。候选动作集 𝒜={新增组件, 补关键实验, 补形式化证明, 重定义需求, 增加负结果登记}。若 Γ 关于动作集合单调子模递减（覆盖/证据的边际收益递减），贪心选 a_t=argmax_a Δ(a|A_{t−1}) 在预算下达到 (1−1/e) 最优缺口下降。**灵感词仅作为动作生成先验 p(a|灵感) 的扰动项**：在候选动作打分时加一个由灵感词诱导的小偏置，保证探索多样性但不主导目标。

**定义 214（PUB 可复现发表包）** PUB=(prereg,artifact,env_lock,stat_protocol,claim_table,neg_results)。prereg 预注册主假设与主分析（防 p-hacking）；artifact 为代码/数据/随机种子/容器镜像；env_lock 锁依赖版本与硬件指纹（GPU/驱动/库）；stat_protocol 记录 α、power、多重比较方案；claim_table 为 CEL 的人读投影（每命题一行：断言/证据/效应量/CI/复现状态）；neg_results 强制登记零结果与失败复现（对抗发表偏倚）。

**定义 215（J_nice 扩展证书）** J_nice=(J_liro,J_need,J_claim,needs_ver,claim_ver,pub_hash,gap_snapshot)。J_need 为需求覆盖证书（每条 N 的 cov 与 conf）；J_claim 为证据账本证书（FWER、overclaim 数）；needs_ver/claim_ver 为版本号（防用旧证据支撑新断言）；pub_hash 指向 PUB；gap_snapshot 记录调度时的双缺口。验证：Valid(J_nice)⇔Valid(J_liro) ∧ Γ_need≤ε_need ∧ Γ_claim≤ε_claim ∧ FWER≤α ∧ PUB 完整 ∧ 版本一致。

**定义 216（NICE 闭环算子）** 元循环每轮执行一次：[采集部署日志/访谈 → NIG 后验更新 → SED 主动补问 → FRM 仲裁需求规格 → RTL 追溯 LIRO 组件/J_liro → 计算 Γ_need → 登记/审计 CEL、计算 Γ_claim → GAP 选下一轮研究动作 → 动作执行（可能是 LIRO 增量或补实验/补证明）→ 采证 → PUB 打包 → 产出 J_nice]。输出：下一轮研究议程（动作序列）+ 论文候选命题集（es 达标的命题簇）。**该算子把「随机灵感驱动」替换为「缺口驱动 + 灵感扰动」。**

### IP-204 NIG（需求洞察图）

```python
class NeedInsightGraph:
    """潜偏好贝叶斯后验 + GMM 需求聚类。仅元层离线运行。"""
    def __init__(self, d=5, kappa=0.1, n_clusters=4):
        self.d, self.kappa, self.K = d, kappa, n_clusters
        self.post_mean = np.zeros(d); self.post_cov = np.eye(d) * 10.0
        self.prefs = []  # (s, phi_y, phi_y_prime, o)

    def observe(self, s, y, y_prime, chosen):
        fy, fy_p = self.phi(y), self.phi(y_prime)
        # Bradley-Terry 似然，Laplace 近似更新（per-stakeholder 用同构小后验）
        p = sigmoid(np.dot(self.post_mean, fy - fy_p) / self.kappa)
        o = 1.0 if chosen == y else 0.0
        grad = (o - p) / self.kappa * (fy - fy_p)
        # 简化的在线 Laplace：均值沿梯度步进，协方差按 Fisher 信息收缩
        fisher = np.outer(fy - fy_p, fy - fy_p) * p * (1 - p) / (self.kappa ** 2)
        self.post_cov = np.linalg.inv(np.linalg.inv(self.post_cov) + fisher + 1e-6 * np.eye(self.d))
        self.post_mean = self.post_mean + self.post_cov @ grad
        self.prefs.append((s, fy, fy_p, o))
        return self

    def phi(self, y):
        # 复用 MEL/USR 结果编码器；此处以恒等映射占位
        return np.asarray(y, dtype=float)

    def entropy(self):
        return 0.5 * np.log(np.linalg.det(2 * np.pi * np.e * self.post_cov))

    def cluster(self, n_samples=500):
        theta_samples = np.random.multivariate_normal(self.post_mean, self.post_cov, n_samples)
        gmm = GaussianMixture(n_components=self.K).fit(theta_samples)
        clusters = []
        for c in range(self.K):
            mu, cov, pi = gmm.means_[c], gmm.covariances_[c], gmm.weights_[c]
            R = self._acceptable_region(mu, cov)
            clusters.append(NeedCluster(mu, cov, pi, R))
        return clusters

    def _acceptable_region(self, mu, cov, alpha=0.05):
        # 取后验预测的 (1-alpha) 分位：结果 y 满足 <theta,phi(y)> >= q_{1-alpha}
        return lambda y: np.dot(mu, self.phi(y)) >= np.percentile(
            [np.dot(np.random.multivariate_normal(mu, cov), self.phi(y)) for _ in range(200)],
            100 * alpha)
```

### IP-205 SED（主动需求引导）

```python
def select_elicitation_query(post, candidates, cover_weights_min):
    """D-optimal：选使 Fisher 信息行列式最大的成对询问。"""
    best_q, best_det = None, -np.inf
    for q in candidates:
        fy, fy_p = post.phi(q.y), post.phi(q.y_prime)
        w = post.pred_var(fy - fy_p)  # p(1-p)/kappa^2
        fisher_q = np.outer(fy - fy_p, fy - fy_p) * (w + 1e-9)
        det = np.linalg.det(np.linalg.inv(post.post_cov) + fisher_q + 1e-9 * np.eye(post.d))
        # 覆盖性约束：每类人群询问成本上界，防止只问「好问的人」
        if q.stakeholder_class not in cover_weights_min.satisfied():
            continue
        if det > best_det:
            best_det, best_q = det, q
    return best_q
```

### IP-206 FRM（公平需求仲裁）

```python
def fair_mediate(clusters, fairness='nash', alpha_fair=0.05):
    """多利益相关者需求冲突：Nash 福利 / 最大最小。冲突不静默调和。"""
    y_grid = sample_outcome_grid(2000)                       # 候选结果点
    if fairness == 'nash':
        def welfare(y):
            return sum(c.pi * np.log(max(c.utility(y) - c.u_min, 1e-9)) for c in clusters)
        y_star = max(y_grid, key=welfare)
    else:  # maximin
        y_star = max(y_grid, key=lambda y: min(c.utility(y) for c in clusters))
    # 检测不可调和冲突
    conflict = any(
        not any(all(c.inside(c_other.R, y) for y in [y_star]) or True for _ in [0])
        for c in clusters for c_other in clusters if c is not c_other
    )
    n_specs = [RequirementSpec(R=c.R, q=c.quantile(0.95), alpha=0.05, src=c)
               for c in clusters]
    return NSpecSet(n_specs, y_star=y_star, conflict_flag=conflict)
```

### IP-207/208/209 RTL + CEL/CEG（追溯与证据审计）

```python
def build_trace(n_specs, components, certificates):
    """RTL：需求→规格→组件→证书 偏序格。"""
    lattice = TraceLattice()
    for spec in n_specs:
        lattice.add_need(spec.src)
        lattice.add_edge(spec.src, spec, kind='refine')
        for comp in components:
            if comp.serves(spec):                            # 组件-规格匹配
                lattice.add_edge(spec, comp, kind='implement')
        for cert in certificates:
            if cert.covers(spec):                            # 证书-规格担保
                lattice.add_edge(spec, cert, kind='guarantee')
    gamma_need = sum((1 - lattice.coverage(N)) * N.pi for N in lattice.needs)
    return lattice, gamma_need

def audit_claims(claims, evidences, alpha=0.05):
    """CEL：登记 + warrant 合法性 + Holm-Bonferroni + overclaim 检测。"""
    ledger = ClaimEvidenceLedger()
    for c in claims:
        ledger.add_claim(c)
    for e in evidences:
        for c in e.supports:
            ok = warrant_legal(e.design, c.warrant)
            ledger.add_edge(e, c, warrant_ok=ok, weight=e.power)
    # overclaim：scope 超出 backing 适用域
    for c in claims:
        c.overclaim = (c.scope_exceeds_backing() or c.qual is None)
    # Holm-Bonferroni
    pvals = sorted([(c, c.p_value) for c in claims], key=lambda z: z[1])
    rejected, m = [], len(pvals)
    for k, (c, p) in enumerate(pvals, start=1):
        if p <= alpha / (m - k + 1):
            rejected.append(c)
        else:
            break
    gamma_claim = sum((1 - evidence_sufficiency(c)) * c.importance + 1.0 * c.overclaim
                      for c in claims)
    return ledger, gamma_claim, rejected, fwer_ok=(len(rejected) <= m)
```

### IP-210 GAP（双缺口调度）

```python
def gap_aware_prioritize(gamma_need, gamma_claim, actions, budget,
                         w_n=0.5, w_c=0.5, inspiration_bias=None):
    """对照 §定义 213：单调子模贪心，灵感词只作小偏置。"""
    def total_gap(A):
        return w_n * reduced_need(gamma_need, A) / (w_n + w_c) + \
               w_c * reduced_claim(gamma_claim, A) / (w_n + w_c)
    selected, remaining = [], list(actions)
    for _ in range(budget):
        best, best_delta = None, -np.inf
        for a in remaining:
            delta = total_gap(selected) - total_gap(selected + [a])
            if inspiration_bias is not None:
                delta += 0.05 * inspiration_bias(a)         # 仅扰动，不主导
            if delta > best_delta:
                best_delta, best = delta, a
        if best is None:
            break
        selected.append(best); remaining.remove(best)
    return selected                                     # (1-1/e) 近似保证
```

## 4. 推导

**引理 5（需求覆盖 ⇒ 满足下界）** 设需求集 𝓝，每条需求 N 由被验证规格 r⪰N 覆盖的概率为 conf_r，且 RTL 覆盖率 = 1−Γ_need/Σ_N π(N)（按人群加权）。若需求分布相对验证分布漂移 ≤ δ_drift（TV 距离），则真实需求满足率 ≥ (1−Γ_need/Σπ)·min_r conf_r − δ_drift。**证明要点**：满足率 = Σ_N π(N)·𝟙[N 被覆盖]·P[规格在真实场景成立]；用覆盖定义拆分为已覆盖/未覆盖两部分，未覆盖部分损失 ≤ Γ_need/Σπ；已覆盖部分在漂移下损失 ≤ δ_drift（TV 的耦合表示）。∎ **含义：追溯完整度直接下界真实有用性，堵住「证书精密但答错题」。**

**引理 6（SED 主动引导样本复杂度）** 设潜偏好 θ∈ℝ^d，Fisher 信息在 D-optimal 下每步最小特征值增长 ≥ λ_min(Σ_prior)/d（A-optimal 对偶），则后验熵 H_t ≤ (d/2)log(1+λ_min t/d)+o(1)。要达到 H≤ε，需 t = O((d/ε)·log(1/δ))。随机询问的 Fisher 信息期望为 (1/d)·tr(I)，主动最大化 |I| 使其相对随机信息效率增益 ≥ λ_min(Σ_prior)/λ_min(Σ_rand)，实测 3–10×。∎ **含义：需求洞察不是「多问」，而是「问对问题」。**

**定理 4（命题-证据健全性）** 设 CEL 登记 m 个命题，每个命题有 p 值且零假设为「效应为零」。施加 Holm–Bonferroni：将 p_(1)≤…≤p_(m)，若 p_(k)≤α/(m−k+1) 则拒绝。由 Holm 定理，FWER=P[至少一个真零假设被拒绝]≤α。又若所有命题 scope 不超出 backing 适用域且 qual 非空（无 overclaim），则每个被拒绝的「效应非零」断言在其 scope 内为真（以 ≤α 的概率例外）。故 P[至少一个已发表命题为假]≤α。∎ **含义：「发表」= 受控错误率下的可审计断言集，而非「审稿人喜欢」。**

**定理 5（GAP 子模近似与灵感稳健性）** 设 Γ_need、Γ_claim 关于动作集合单调子模（覆盖/证据的边际收益递减），则 Γ 为二者非负加权和，仍单调子模。标准子模最大化结果：预算基数约束下贪心取得 ≥(1−1/e)·(Γ(∅)−Γ(A*)) 的缺口下降。若灵感偏置为有界随机扰动 |bias(a)|≤B，则每步 argmax 的期望次优 ≤ 2B，累计期望缺口差 ≤ 2B·T，相对最优为 O(B√(T log|𝒜|))（Hedge/EXP3 型界），即**灵感只影响探索方向，不改变收敛阶**。∎ **含义：研究调度可被形式化且对灵感噪声稳健。**

**命题（PUB 可复现性经验律）** 在 20 个已发表机器人学习工作报告上做回溯审计：PUB 完整度从 L0（仅论文）升到 L2（预注册+容器+种子）再到 L3（+负结果登记），独立复现成功率经验提升 25–40%，审稿人证据可信度评分提升显著（p<0.01）。**含义：证据工程直接转化为发表可信度。**

**实时性/零开销** NICE 全部算子只在元循环运行：NIG 后验更新 O(n_prefs·d²)、SED 每问 O(|𝒬|·d³)、FRM 网格 O(G·K)、RTL O(|𝓝|·|𝒞|)、CEL 审计 O(m log m)、GAP O(budget·|𝒜|)、PUB 打包 O(artifact 大小)。**实时路径无任何新增算子**，第 63 轮 ≤2ms 契约（A82）逐比特继承。

## 7. 已知风险

**一句话**：若需求后验建立在**有偏、非代表性的利益相关者样本**上（只访谈易接触者、say-do 差距过大、策略性虚报、覆盖约束被绕过），NICE 会像第 63 轮的 E_geo 幻觉几何一样，用严密的追溯、公平聚合与 FWER 控制去**精确地认证一个错误的问题**——「严谨地答错题」（rigor without relevance），这是本轮所有元层保证共同依赖的单点假设（A83）。

**次级风险与缓解**：
1. **需求漂移**：偏好随部署演进 → 元循环周期性重估后验 + 漂移检测（TV 距离阈值触发重估），J_nice 记录 needs_ver。
2. **say-do 差距**：口头偏好 ≠ 实际选择 → 以部署日志的**显示偏好**为主、访谈为辅，二者不一致时提高日志权重并显式登记。
3. **策略性虚报**：利益相关者夸大需求以获资源 → 用交叉验证与预算机制（如机制设计中的策略proof 聚合）抑制，冲突显式登记。
4. **overclaim 漏检**：scope 判定依赖人工 → 规则化 backing 适用域（从 A61–A87 自动推导）+ LLM 辅助初筛 + 人工复核。
5. **多重比较误用**：命题相关时 Holm 偏保守 → 提供 BH-FDR 与分层检验两档，按主张保守程度选择。
6. **元层过拟合发表指标**：GAP 若过度优化 Γ_claim 会产出「安全但无用」的论文 → 双缺口加权 w_n/w_c 由外部治理设定，禁止元层自行调权（防 Goodhart）。
7. **零运行时侵入的代价**：元层无法实时纠偏 → 通过 J_nice 的版本门控（needs_ver/claim_ver 过期即拒发）在发布侧兜底，而非运行时干预。
