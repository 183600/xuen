# 第 14 轮（新灵感循环第 5 轮；本轮灵感：「用户画像」×「视觉伺服」）

> **基线**：第 13 轮产物 MetricVoiceGauge-NCD-HUTDH-v15（技能扩散版；SCD/DSD/DCA/EDC；定义 607–626；引理 125–130；实验 E661–E670）。
> 本轮纪律：**画像只缩不放 + 画像有效性先于使用 + 视觉伺服只可否决 + 条件与验证同相**。不推倒 v15：v13 的 AIO/CPD/DDL/RTCR、v14/v15 的 SCD/DSD/DCA/EDC、v12 的 USG/TGC/BAA/GAGP/UC、v11 的 HAS/HCC/HATD/HDT、v10 的 NGE/DSL/CC/CWM/CAE/NCP、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 与九不变式全部保留。三个新组件——PCP（画像条件证书）、PVG（画像有效性守卫，含 PDC 表演性漂移证书）、CVS（可证视觉伺服，含 ISM 图像伺服裕度）——一律以**中立元**接入，失效即严格退回 v15，再沿 v15 退化链退回 v14/v13/v12/…/v6。本轮只做三件事：把"画像"从推荐特征改写为**共形证书的条件变量**、把"视觉伺服"从控制器改写为**证书的高频否证器**、再把二者合成"条件—验证"双层闭环。

## 0. 直觉与动机

**灵感 1（用户画像 → 把画像从推荐特征降格为共形证书的条件变量）**

直觉：在推荐系统里，用户画像用来"多给一点"；在安全关键机器人里必须反过来——画像是用来"少给一点、但给得更准"的。v15 的证书是任务级的：它必须同时对所有可能的操作者、意图、房间布局成立，因此只能取最保守的交集 `Acc_0 = ∩_ψ Acc(ψ)`。这个交集对具体用户是过度保守的：新手需要更大间距、更慢速度、更早求助，熟练用户不需要。画像的真正价值不是新增权限，而是把"对所有人安全"的交集**恢复**成"对这类人安全"的条件集。

反直觉点有二。其一：画像越细，条件集越贴身，但每个画像组的校准样本越少，群体条件覆盖的有限样本间隙越大——**细化画像本身在消耗安全预算**。其二：画像是**表演性（performative）**的：系统按画像行动，用户会适应、会迎合或反抗画像，于是校准分布随部署一起漂移，i.i.d. 共形保证从根上失效。核心创新：**画像条件证书（Profile-Conditioned Certificate, PCP）+ 画像条件覆盖 + 层级回退**：细组样本不足就退回粗组或全局；画像只能施加额外约束 `β(ψ) ≥ 0`，绝不放宽 v15 的任何阈值。

**灵感 2（视觉伺服 → 把视觉伺服从控制器降格为证书的高频否证器）**

直觉：决策层即使做到逐帧可证，也是在 50Hz 的离散帧上做"关于未来的断言"；两帧之间机器人仍在动，人也在动。视觉伺服恰好是相机率的高频闭环，它真正的用处不是"把末端再挪准一点"，而是**用图像误差持续检验证书所依赖的假设是否仍然成立**：目标可见吗？特征交互矩阵还良态吗？当前点还在已验证的吸引域里吗？核心创新：**可证视觉伺服（Certified Visual Servoing, CVS）+ 图像伺服裕度（Image-Servo Margin, ISM）**：把图像误差经交互矩阵伪逆转成任务空间误差上界 `Δx_bound`，再与安全半径 `R_safe` 相减得到 `m_vis`；`m_vis<0`、特征丢失、交互矩阵接近奇异、或可见性不足，任一成立就**否决**当前帧的计划。

反直觉点：视觉伺服的价值与"更准"无关，甚至**越准越危险**——一个过于激进的伺服增益会让误差更快收敛，却把系统推到视野边缘与奇异位形附近，反而缩短了证书的有效半径。因此 CVS 必须与"保守增益 + 硬性否决"绑定，而不是与"高性能跟踪"绑定。

**灵感 3（画像×视觉伺服 → "条件—验证"双层闭环与波普尔式否证）**

直觉：画像是一个**可被否证的断言**："这个用户属于这类、在这个工况下，`Acc(ψ)` 内的动作是安全的。"视觉伺服则是高频的**否证尝试**：它不断用图像证据检查该断言的前提（人在预期区域、目标可见、误差在吸引域内）。二者正好构成一对：画像负责**收紧先验**，视觉伺服负责**及时推翻先验**。核心创新：**画像—伺服路由器（Profile-Servo Router, PSR）**：正常时执行 `Acc(ψ) ∩ {m_vis≥0}`；画像失效时冻结画像并退回 v15 的画像无关证书；视觉余量为负或不同步时先 hold/abort，绝不"用上一帧的余量给这一帧放行"。这把安全从"一次性的离线证书"变成"每帧都在被否证、且否证失败才继续"的在线过程。

**三者如何统一**

统一为 **v15 之上的"条件—验证层"**：v15 回答"哪些技能/组合在任务级被允许"（`Exec_v15`），v16 回答"对当前画像的用户，这些允许里哪些仍被条件证书授权、且此刻是否被视觉证据确认"（`Exec_v16`）。PCP 把画像变成证书的条件变量；PVG 保证画像本身仍在支撑内且未被表演性反馈带偏；CVS 把图像误差变成高频否决信号；PSR 在同一帧内把"条件"与"验证"按同一时钟对齐。共享状态 `ζ_ps=(b_t, ψ_t, C_δ, Acc(ψ_t), PVC, m_vis, τ_sync, mode)`。四者不是四个模块，而是一条**"画像收紧 → 证书授权 → 视觉否证 → 失效即退化"**的链。

## 1. 研究问题（轮次升级版）

- **Q1（画像条件化的可证语义）**：如何定义画像条件证书 `Acc(ψ)`，使 `Acc_0⊆Acc(ψ)⊆Acc_v15` 同时成立？"画像只缩不放"在组合技能（v15 的 SCD 阶梯）上是否保持？层级回退（细组→粗组→全局）如何给出可证的覆盖保证，而不是靠调参？
- **Q2（表演性画像的可证边界）**：当用户会因被画像而改变行为时，共形校准的 i.i.d. 前提如何修补？表演性漂移半径 `r_perf` 如何估计并进入证书？在 `L≥1`（画像反馈不稳定）或稀有组样本不足时，冻结画像/退回 v15 是否仍能保持活动性与安全？
- **Q3（视觉伺服作为否证器的可证性）**：图像误差到任务空间误差的单侧界在深度误差、标定误差、局部线性化失效时还能保吗？可证吸引域 `ROA_cert`、交互矩阵条件数、可见性三者如何联合定义一个可在线判定的否决条件？相机率与决策率的时钟不同步如何不产生"用旧余量放行"的缝隙？
- **Q4（联合与兼容）**：画像条件证书与 v15 的 SCD/DSD 阶梯、v13 的 DGC/RTIC 如何合取而不互相抵消？画像 OOD 与视觉 OOD 同时发生是否会共同低估风险？新增层能否守住 50Hz/p99≤22ms，并严格退回 v15 再沿退化链退回？

## 2. 设计原则（在 P22–P24 基础上新增 P25–P28）

**P25 画像只缩不放律（Profiling Narrows, Never Grants）**
对支撑内任意画像 `ψ`，必须满足 `Acc_0 ⊆ Acc(ψ) ⊆ Acc_v15`，其中 `Acc_0 = ∩_ψ Acc(ψ)` 是画像无关的最坏情形交集。画像只能通过附加阈值 `β(ψ)≥0` 收紧 v15 证书，**不得放宽任何 v15 阈值、不得合成新的动作、不得绕过 SCD 的技能嵌套**。画像买到的是"相对于最坏情形交集的活动性恢复"，不是"超出任务级证书的权限"。

**P26 画像有效性先于使用律（Validity Before Use）**
画像只有在三条同时成立时才可条件化证书：(i) `ψ` 落在校准支撑内；(ii) 所在画像组（或其层级回退组）样本量 `≥ n_min`；(iii) 表演性反馈映射满足 `L<1` 且漂移半径 `r_perf ≤ r_max`。任一不成立即**冻结画像**：`β(ψ)` 膨胀到最坏情形或直接取 `Acc_v15` 的画像无关子集；不得用"更精细但未验证"的画像赌安全。

**P27 视觉伺服只可否决律（Visual Servo Vetoes, Never Authorizes）**
CVS 的授权集定义为 `Acc_vis(ψ) = Acc(ψ) ∩ {a : m_vis(a) ≥ 0}`，是纯收缩。它不能把任意外动作加入可行集；其输出只有 `(m_vis, mode_vis∈{ok,hold,abort}, age)` 三件套。`m_vis<0`、`κ(L_s)>κ_max`、可见性 `<v_min`、或 `age>h_max` 任一成立即 `hold/abort`；**没有余量就没有放行**。

**P28 条件—验证同相律（Condition and Verification Share a Clock）**
每个被执行的条件化动作必须在**同一帧、同一时钟域**内携带 `(ψ_t, Acc(ψ_t), m_vis, τ_sync)`；`τ_sync` 超出新鲜度视界 `h_max` 的余量一律作废。视觉时间戳与决策时间戳必须显式对齐（含相机曝光、传输、处理延迟），禁止"用上一帧的视觉余量给这一帧的画像证书背书"。

## 3. 与基线的接口（如何退化）

- PCP 失效 ⇒ 令 `β(ψ)≡0`、`Acc(ψ)≡Acc_v15`，画像不参与证书，**等价 v15 证书路径**；
- PVG 失效 ⇒ 画像冻结为最近一次有效值并只使用全局组，**等价"v15 证书 + 一个粗画像"**；
- CVS 失效 ⇒ 关闭高频否决，退回 v15 的决策率守卫，**等价 v15 开环执行**；
- PSR 失效 ⇒ 静态选择"画像无关证书 + 不启用伺服否决"，**等价 v15 调度路径**；
- 四者全失效 ⇒ MetricVoiceGauge-NCD-HUTDH v15，再沿 v15 退化链退回 v14/v13/v12/…/v6；
- **安全继承**：PCP 只取交、PVG 只冻结/膨胀、CVS 只否决、PSR 只对齐。四端口均不能新增授权或放宽阈值，`Exec_v16⊆Exec_v15` 由引理 135 保证。

## 4. 预期贡献

1. **画像条件化安全**：把"用户画像"从推荐特征改写为共形证书的条件变量，给出 `Acc_0⊆Acc(ψ)⊆Acc_v15` 的窄化语义、群体条件覆盖的有限样本间隙、以及细组样本不足时的层级回退；
2. **表演性画像证书**：显式建模"系统按画像行动 → 用户适应 → 画像漂移"的反馈，给出收缩型反馈下的漂移界与冻结/退回判据，填补"画像在闭环中被自己的行动污染"这一空白；
3. **视觉伺服否证器**：把图像误差、交互矩阵条件数、可见性与新鲜度合成为一个可在线判定的单侧任务空间界，使视觉伺服从"控制器"变成"证书的高频否证器"；
4. **条件—验证双层闭环**：v15 管"任务级允许什么"，v16 管"对该画像、此刻是否仍被视觉证据确认"，用 `Exec_v16⊆Exec_v15` 把画像收益与权限扩张解耦；E671–E680 覆盖群体覆盖、表演性漂移、视觉裕度、同步、消融与端到端。

## 5. 本轮最大风险

**一句话**：画像在闭环中是表演性的——系统越按画像去伺服，用户越会被塑造成符合画像的样子，校准集于是"越用越准"，而视觉伺服因为一直在成功收敛、余量一直为正，也持续给出"前提成立"的证据，最终在**条件覆盖成立、视觉余量为正、每帧都按时**的表象下，系统自信地服务了一个被自己塑造出来的、并非用户真实意图的画像——即**自证预言式的、处处合格却彻底错位的安全决定**。

## 1. 形式定义（627–642）

**定义 627（画像空间与信念）** 画像 `ψ=(ψ_cap, ψ_int, ψ_env, ψ_pref) ∈ Ψ`，`Ψ` 为紧度量空间；`b_t ∈ Δ(Ψ)` 由交互日志递推，`ψ_t = argmax b_t`，可信集 `C_δ(b_t) = {ψ : b_t(ψ) ≥ δ}`。只有 `C_δ` 内的画像可用于条件化。

**定义 628（画像条件证书）** 给定 v15 证书 `Acc_v15` 与画像 `ψ`，
```
Acc(ψ) = Acc_v15 ∩ { a ∈ ActionSpace : m_v15(a) ≥ β(ψ) } ,
```
其中 `m_v15(a)` 为 v15 的边界余量，`β(ψ)≥0` 由画像组共形分位给出。等价地定义收缩算子 `Π_ψ`，`Acc(ψ)=Π_ψ(Acc_v15)`。

**定义 629（画像无关交集与活动恢复）** `Acc_0 = ∩_{ψ∈C_δ} Acc(ψ)`；画像活动增益
```
ActGain(ψ) = |Acc(ψ)| / max(1, |Acc_0|) − 1 ≥ 0 .
```
画像的收益只体现在 `ActGain`，不体现在 `Acc(ψ)` 超出 `Acc_v15` 的部分（不存在）。

**定义 630（群体条件覆盖与间隙）** 对画像组 `g`，
```
Cov_g = P( Y ∈ C_ψ(X) | Ψ ∈ g ) ,   g_grp = max_g (1−α−Cov_g) .
```
经验覆盖 `Cov̂_g` 由该组校准样本估计。

**定义 631（层级回退）** 画像空间预置多分辨率划分 `G_0 ⊃ G_1 ⊃ …`（从粗到细）。给定 `ψ`，选最细且 `n_g ≥ n_min` 的组；若该层不存在，逐级上退到粗组，最后回退到全局组 `G_*`。回退不改变 `β` 的保守方向：粗组只会令 `β` 更大或相等。

**定义 632（表演性画像映射与漂移半径）** 用户行为随系统动作演化：
```
ψ_{t+1} = F(ψ_t, a_t, ξ_t),  a_t = π(ψ_t),  ||ξ_t|| ≤ ε_f .
```
设复合映射 `G(ψ)=F(ψ, π(ψ), ξ)` 的 Lipschitz 常数为 `L`。若 `L<1`，则存在唯一不动点 `ψ*`，且
```
r_perf := limsup_t ||ψ_t − ψ*|| ≤ ε_f / (1−L) .
```
若 `L≥1`，不存在一致漂移界，画像证书失效。

**定义 633（画像有效性证书 PVC）** `PVC = (in_supp, n_ok, L_hat, r_perf, valid)`，其中 `in_supp` 为支撑距离检验通过、`n_ok` 为 `n_g≥n_min`、`valid = in_supp ∧ n_ok ∧ (L_hat<1) ∧ (r_perf≤r_max)`。`valid=false` 时只能使用 `Acc_0` 或 `Acc_v15` 的画像无关子集。

**定义 634（视觉误差与交互矩阵）** 图像特征误差 `e = s(x) − s*`；在局部线性化邻域内
```
e = L_s (x − x*) + η ,   ||η|| ≤ ε_det + ε_model ,
```
`L_s ∈ R^{k×6}` 为交互矩阵，`κ(L_s)` 为条件数，可见性 `v(x)∈[0,1]`。

**定义 635（图像伺服裕度 ISM）** 在 `L_s` 列满秩时
```
Δx_bound = ||L_s^+|| · ( ||e|| + ε_det ) + ε_model ,
m_vis    = R_safe − Δx_bound .
```
`L_s` 秩亏或 `κ(L_s)>κ_max` 时令 `m_vis = −∞`。

**定义 636（可证吸引域）** `ROA_cert = { (x,s) : m_vis(x,s) ≥ 0 ∧ κ(L_s) ≤ κ_max ∧ v(x) ≥ v_min }`。这是**局部**集合：超出采样邻域或线性化失效时不予认证。

**定义 637（视觉伺服守卫输出）** `CVS.guard` 输出 `(m_vis, mode_vis, age, κ, v)`，`mode_vis∈{ok,hold,abort}`；`age = now − t_capture`。`age>h_max` 强制 `abort`。

**定义 638（条件—验证联合状态与同步）** `ζ_ps=(b_t, ψ_t, C_δ, Acc(ψ_t), PVC, m_vis, τ_sync, mode)`；`τ_sync = now − t_capture` 必须 `≤h_max`，且 `Acc(ψ_t)` 与 `m_vis` 必须引用同一 `(obs, ψ)` 快照。

**定义 639（联合退化模式）**
```
mode = normal      若 PVC.valid ∧ mode_vis=ok ∧ τ_sync≤h_max
     = prof_freeze 若 ¬PVC.valid 而 mode_vis=ok
     = vis_hold    若 PVC.valid ∧ mode_vis=hold
     = collapse    若 mode_vis=abort ∨ τ_sync>h_max
```

**定义 640（画像粒度三难指标）** 画像划分数 `G`、单组样本 `n_g`、群体间隙 `ε`、活动增益 `ΔAct`。`G` 增大一般提升可达 `ΔAct` 上界，但由定义 630 与引理 132 会同时抬高 `n_min` 与可证 `ε` 的下界。

**定义 641（条件化执行集）** `Exec_v16 = { a : a∈Acc(ψ_t), PVC.valid, m_vis(a)≥0, τ_sync≤h_max, mode=normal }`；任一不满足时由 PSR 输出 v15 回退动作。

**定义 642（回退动作）** `Fallback_16(x) = Fallback_v15(x)`，即 v15 的物理保守动作（停/柔顺/`a_ask`）；v16 不定义任何新的回退动作，只复用 v15。

```python
# IP-382 Profile-Conditioned Certificate：画像条件证书
class ProfileConditionedCertificate:
    def __init__(self, base_v15, profile_belief, hierarchical_cal,
                 alpha=0.05, n_min=200):
        self.base = base_v15
        self.belief = profile_belief
        self.cal = hierarchical_cal      # 多分辨率校准集
        self.alpha = alpha
        self.n_min = n_min

    def _resolve(self, psi):
        # 从细到粗，返回第一个 n_g >= n_min 的组；否则全局组
        for level in reversed(self.cal.levels):
            g = level.group_of(psi)
            if self.cal.size(g) >= self.n_min:
                return g
        return self.cal.global_group

    def _beta(self, psi, group):
        # 组条件共形分位 + 有限样本修正
        q = self.cal.conformal_quantile(group, 1 - self.alpha)
        bonus = self.cal.finite_sample_bonus(group, delta=1e-3)
        return max(0.0, q + bonus)

    def conditional_set(self, psi):
        group = self._resolve(psi)
        beta = self._beta(psi, group)
        base = self.base.certified_actions()
        acc = {a for a in base if self.base.margin(a) >= beta}
        assert acc <= base                 # 定义 628：只缩不放
        return acc, beta, group

    def profile_agnostic_intersection(self):
        # 仅在离线/回退时计算：所有组条件集的交集
        acc = self.base.certified_actions()
        for g in self.cal.all_groups():
            acc &= {a for a in acc if self.base.margin(a) >= self._beta_group(g)}
        return acc


# IP-383 Profile Validity Guard：画像有效性守卫（含 PDC）
class ProfileValidityGuard:
    def __init__(self, cal, n_min, r_perf_max, eps_f, lip_estimator):
        self.cal = cal
        self.n_min = n_min
        self.r_perf_max = r_perf_max
        self.eps_f = eps_f
        self.lip = lip_estimator

    def certificate(self, b_t, psi, action_hist, obs_hist):
        in_supp = self.cal.support_distance(psi) <= self.cal.r_support
        group = self.cal.resolve(psi)
        n_ok = self.cal.size(group) >= self.n_min
        L_hat = self.lip.estimate(action_hist, obs_hist)
        r_perf = self.eps_f / (1 - L_hat) if L_hat < 1 else float('inf')
        valid = in_supp and n_ok and (L_hat < 1) and (r_perf <= self.r_perf_max)
        return PVC(in_supp, n_ok, L_hat, r_perf, valid)


# IP-384 Certified Visual Servoing：可证视觉伺服（含 ISM）
class CertifiedVisualServoing:
    def __init__(self, feature_fn, R_safe, kappa_max, v_min,
                 eps_det, eps_model, h_max):
        self.feature_fn = feature_fn
        self.R_safe = R_safe
        self.kappa_max = kappa_max
        self.v_min = v_min
        self.eps_det = eps_det
        self.eps_model = eps_model
        self.h_max = h_max

    def guard(self, obs, target, t_capture):
        e, L_s, vis = self.feature_fn(obs, target)
        age = now() - t_capture

        if age > self.h_max:
            return -float('inf'), 'abort', age, float('inf'), vis

        kappa = cond(L_s)
        if (not full_column_rank(L_s)) or kappa > self.kappa_max or vis < self.v_min:
            return -float('inf'), 'hold', age, kappa, vis

        dx_bound = norm(pinv(L_s)) * (norm(e) + self.eps_det) + self.eps_model
        m_vis = self.R_safe - dx_bound
        mode = 'ok' if m_vis >= 0 else 'abort'
        return m_vis, mode, age, kappa, vis

    def margin_for(self, a, obs, target):
        # 逐候选动作检查该动作执行后是否仍在 ROA_cert 内
        m_vis, mode, _, _, _ = self.guard(obs, target, obs.t_capture)
        return m_vis if mode == 'ok' else -float('inf')


# IP-385 Profile-Servo Router：条件—验证路由器
class ProfileServoRouter:
    def __init__(self, pcp, pvg, cvs, h_max):
        self.pcp = pcp
        self.pvg = pvg
        self.cvs = cvs
        self.h_max = h_max

    def route(self, b_t, psi, obs, target):
        acc, beta, group = self.pcp.conditional_set(psi)
        pvc = self.pvg.certificate(b_t, psi, obs.action_hist, obs.hist)

        m_vis, mode_vis, age, kappa, vis = self.cvs.guard(
            obs, target, obs.t_capture)

        if (not pvc.valid) and (mode_vis == 'ok'):
            # 画像冻结：退回画像无关交集，而不是退回整个 v15
            return self.pcp.profile_agnostic_intersection(), 'prof_freeze', m_vis

        if mode_vis == 'hold':
            return self.hold_current(), 'vis_hold', m_vis

        if (mode_vis == 'abort') or (age > self.h_max):
            return None, 'collapse', -float('inf')

        # normal：条件集与视觉可行集的交集；两者都是纯收缩
        feasible = [a for a in acc if self.cvs.margin_for(a, obs, target) >= 0]
        if not feasible:
            return None, 'collapse', m_vis
        return self.select(acc, feasible, beta), 'normal', m_vis

    def hold_current(self):
        # 保持上一已验证动作（低速/零空间保持），不产生新决策
        return self.last_certified_action


# 主闭环集成：MetricVoiceGauge-NCD-HUTDH-v16（画像条件 × 视觉伺服）
def metricvoicegauge_round_16_profile_servo(M, s, obs, belief=None,
                                             profile_cal=None, target=None, ...):
    # ---- v15 主路径原样保留（MW→NGE→HCC→HDT→HATD→NCP→SCD/DSD/DCA/EDC→守卫）----
    results = middleware.run_cycle(runners={...}, ctx=ctx)
    nge.update_belief(obs)
    hcc.update_identification(obs.motor_enc, obs.joint_enc, obs.current)

    # ---- 画像信念更新（低频/异步，不阻塞关键路径）----
    if belief is not None:
        belief.update(obs.interaction_log)
    psi_t = belief.map() if belief is not None else ctx.default_profile
    C_delta = belief.credible_set(delta=ctx.delta_profile) if belief else None

    # ---- PCP：画像条件证书 ----
    pcp = ProfileConditionedCertificate(
        base_v15=ctx.v15_certificate,
        profile_belief=belief,
        hierarchical_cal=profile_cal,
        alpha=ctx.alpha_profile,
        n_min=ctx.n_min
    )
    acc_psi, beta_psi, group = pcp.conditional_set(psi_t)

    # ---- PVG：画像有效性（含表演性漂移）----
    pvg = ProfileValidityGuard(
        cal=profile_cal,
        n_min=ctx.n_min,
        r_perf_max=ctx.r_perf_max,
        eps_f=ctx.eps_f,
        lip_estimator=ctx.lip_estimator
    )
    pvc = pvg.certificate(belief, psi_t, obs.action_hist, obs.hist)

    # ---- CVS：高频视觉伺服守卫 ----
    cvs = CertifiedVisualServoing(
        feature_fn=ctx.visual_features,
        R_safe=ctx.R_safe,
        kappa_max=ctx.kappa_max,
        v_min=ctx.v_min,
        eps_det=ctx.eps_det,
        eps_model=ctx.eps_model,
        h_max=ctx.h_max
    )

    # ---- PSR：条件—验证路由 ----
    psr = ProfileServoRouter(pcp, pvg, cvs, ctx.h_max)
    feasible, mode, m_vis = psr.route(belief, psi_t, obs, target)

    if mode == 'collapse':
        # 严格退回 v15 的认证回退动作；不执行任何条件化动作
        a_exec = ctx.v15_certificate.fallback(obs)
        execute(a_exec)
    elif mode == 'vis_hold':
        # 保持上一已验证动作，等待下一帧新鲜视觉证据
        execute(psr.hold_current())
    elif mode == 'prof_freeze':
        # 画像无效：使用画像无关交集，仍走 v15 证书与守卫
        a_exec = ctx.v15_certificate.select(feasible, obs)
        execute(a_exec)
    else:
        # normal：feasible 已由 PCP 与 CVS 双重收缩
        a_exec = psr.select(acc_psi, feasible, beta_psi)
        execute(a_exec)

    # ---- 低频异步：重校准与表演性漂移监控 ----
    if cycle_idx % T_profile == 0:
        profile_cal.calibrate(new_interaction_buffer)
        ctx.lip_estimator.update(new_interaction_buffer)
        ctx.r_perf_max = min(ctx.r_perf_max,
                             1.2 * pvg.certificate(...).r_perf)
        if pvc.L_hat >= 1:
            belief.freeze()

    # ---- v15 继承路径 ----
    C, spatial_cert, claims, metrics, rewards = M.inherited_v15_path(ctx)
    metrics['mode'] = mode
    metrics['m_vis'] = m_vis
    metrics['beta_profile'] = beta_psi
    return C, spatial_cert, claims, metrics, rewards
```

## 3. 推导

**引理 131（画像只缩不放与活动恢复）** 设 `Acc(ψ)=Acc_v15∩{a:m(a)≥β(ψ)}`、`Acc_0=∩_{ψ∈C_δ}Acc(ψ)`。则对任意支撑内 `ψ`，
```
Acc_0 ⊆ Acc(ψ) ⊆ Acc_v15 ,
```
且 `ActGain(ψ)≥0`。证明：`Acc_0` 是交集，故含于每一项；`Acc(ψ)` 是 `Acc_v15` 与另一集合的交，故含于 `Acc_v15`。活动增益由定义 629 直接得非负。∎ 推论：**画像不能扩张权限，只能把"对所有人安全"的交集恢复为"对这类人安全"的条件集**；`β(ψ)≡0` 时 `Acc(ψ)=Acc_v15`，退回 v15。

**引理 132（群体条件覆盖的有限样本间隙）** 设画像组数 `G`、每组 `n_g` 个 i.i.d. 校准样本、置信度 `1−δ`。则
```
P( max_g |Cov̂_g − Cov_g| > ε ) ≤ 2G·exp(−2 n_min ε²) .
```
因此若要求 `g_grp≤ε` 以概率 `1−δ`，需
```
n_min ≥ log(2G/δ) / (2ε²) .
```
证明：对每组用 Hoeffding 不等式 `P(|Cov̂_g−Cov_g|>ε)≤2exp(−2n_gε²)`，再对 `G` 组做 union bound，取 `n_min` 为最小样本量。∎ 推论：**细化画像（`G↑`）会同时抬高每组所需样本量与可证间隙的下界**；样本不足必须层级回退（定义 631），否则条件覆盖失效。

**引理 133（表演性画像的漂移半径）** 设复合反馈映射 `G(ψ)=F(ψ,π(ψ),ξ)` 为 `L`-Lipschitz，`L<1`，外生噪声 `||ξ||≤ε_f`。则 `G` 有唯一不动点 `ψ*`，且对任意初值
```
||ψ_t − ψ*|| ≤ L^t ||ψ_0 − ψ*|| + ε_f/(1−L) ,
```
故 `r_perf ≤ ε_f/(1−L)`。若 `L≥1`，不存在与初值无关的一致漂移界。证明：Banach 不动点定理 + 三角不等式；噪声项按几何级数放大 `Σ L^k ε_f`。∎ 推论：**画像在闭环中会被系统自己的动作"塑造"**；只有当反馈是收缩的且漂移半径小于阈值时，画像校准才可继续使用。`L≥1` 或 `r_perf>r_max` 时必须冻结画像（定义 633）。

**引理 134（图像—任务空间裕度的单侧可靠性）** 若 `L_s` 列满秩、`e=L_s(x−x*)+η`、`||η||≤ε_det+ε_model`，则
```
||x−x*|| ≤ ||L_s^+|| (||e||+ε_det) + ε_model =: Δx_bound .
```
进一步，若 `m_vis=R_safe−Δx_bound≥0`、`κ(L_s)≤κ_max`、`v(x)≥v_min`，则当前伺服步仍位于 `ROA_cert` 内。证明：`x−x*=L_s^+(e−η)`，取算子范数并三角不等式；`ROA_cert` 由定义 636 的三条件直接给出。∎ 注意：这是**局部**结论，依赖线性化邻域与列满秩；秩亏、可见性不足或超出邻域时 `m_vis=−∞`，转 `hold/abort`。推论：视觉余量只提供**否决**，不提供新的授权；它是证书的否证器，不是扩权器。

**引理 135（条件—验证层的安全继承）** 若 PSR 在 `mode≠normal` 时只输出 v15 回退动作、在 `mode=normal` 时只输出 `Acc(ψ)∩{m_vis≥0}` 内的动作，且 `Acc(ψ)⊆Acc_v15`，则
```
Exec_v16 ⊆ Exec_v15 .
```
证明：分四种模式。`normal` 由定义 628 与定义 635 得 `a∈Acc_v15`；`prof_freeze` 使用 `Acc_0⊆Acc_v15`；`vis_hold` 输出上一已验证动作，属于此前 `Exec_v15`；`collapse` 输出 `Fallback_v15∈Exec_v15`。故任意执行动作均含于 `Exec_v15`。∎ 推论：**要突破 v16 必须同时伪造一个支撑内的有效画像、一个虚假的正视觉余量、且绕过新鲜度检查，或直接攻破 v15 本身**；三者中任一被 PVG/CVS 截获即退化。

**引理 136（画像粒度—群体覆盖—校准预算三难）** 对任意画像划分 `{G_1,…,G_G}` 与群体覆盖目标 `g_grp≤ε`，若要求以概率 `1−δ` 成立，则总校准样本量满足
```
N = Σ_g n_g ≥ G · log(2G/δ)/(2ε²) = Ω( G log(G/δ)/ε² ) .
```
因此"更细画像（`G↑`）× 更小群体间隙（`ε↓`）× 更小校准预算（`N↓`）"三者不可同时取得；只能显式放弃其中一个，或使用层级回退把有效 `G` 降到样本支持的范围内。证明：由引理 132 的每组下界对 `g` 求和。∎ 推论：**画像的收益不是免费的**；每一档画像细化都要用校准样本、或用一个更宽的群体定义、或用更保守的 `β` 来支付。

## 7. 已知风险与失效模式

1. **稀有画像组覆盖不足**：细画像组样本稀少，群体间隙被低估。缓解：层级回退、分层采样、`n_min` 硬门槛、对小组合并后再校准。
2. **表演性反馈与 Goodhart 效应**：系统按画像行动改变用户，使画像"越用越准"却越来越偏离真实意图。缓解：周期性主动探询（`a_ask`）、冻结机制、反事实校准集、把 `r_perf` 纳入证书。
3. **画像标签泄漏与自我实现**：画像来自系统自己的历史动作，存在选择偏差。缓解：记录动作前/后的用户状态、使用倾向得分加权、保留随机化探询样本。
4. **深度/标定误差使 ISM 失效**：`ε_det+ε_model` 低估，单侧界不再 sound。缓解：在线深度不确定性、保守余量、标定漂移检测、必要时退到位置型视觉伺服。
5. **局部线性化失效**：大位移或强透视时 `e=L_s(x−x*)` 不成立。缓解：限制单步幅值、邻域重采样、超出邻域即 `hold`。
6. **秩亏、遮挡与视野边缘**：交互矩阵近奇异或特征丢失，伪逆范数爆炸。缓解：`κ_max` 与 `v_min` 硬门槛、特征冗余、主动视野规划、`hold/abort`。
7. **视觉与决策时钟不同步**：用过期图像余量给新决策背书。缓解：硬件时间戳、`τ_sync` 硬门槛、流水线延迟建模、`h_max` 收紧。
8. **画像条件集过度收缩**：`β(ψ)` 过大导致活动性塌缩、频繁 `a_ask`。缓解：非对称代价只影响选择不影响证书、增加常见组、把假拒绝计入预算。
9. **画像 OOD 与视觉 OOD 同时发生**：新用户进入新场景，`PVC` 与 `m_vis` 同向低估。缓解：双重漂移检测、任一失效即 `collapse`、联合三角界与保留 `B_safe`。
10. **共享骨干/共享特征的相关失效**：画像模型与视觉特征共享上游时，一个结构性缺陷同时击穿两者。缓解：异构骨干、教师影子抽查、关键场景保留纯 v15 路径。
11. **隐私与画像存储**：用户画像包含敏感行为数据。缓解：端侧推理、最小化存储、差分隐私或聚合画像、可删除机制。
12. **校准集随时间陈旧**：季节、家具布局、用户习惯变化使支撑漂移。缓解：滑动窗口重校准、支撑距离监控、过期即冻结。

## 8. 本轮最大风险

**一句话**：画像在闭环中是表演性的——系统越按画像去伺服，用户越会被塑造成符合画像的样子，校准集于是"越用越准"，而视觉伺服因为一直在成功收敛、余量一直为正，也持续给出"前提成立"的证据，最终在**条件覆盖成立、视觉余量为正、每帧都按时**的表象下，系统自信地服务了一个被自己塑造出来的、并非用户真实意图的画像——即**自证预言式的、处处合格却彻底错位的安全决定**。
