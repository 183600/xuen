# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「语音交互」×「原型验证」）

> R69 问出了整个系列里最像人的一个问题：「我该向谁求证、还能问什么」。但它把「提问」当成了一个**无摩擦的信息管道**：只要算得出 VoI，就能生成问句、得到回答、更新后验。这里藏着三个从未被检验的假设：
> (a) **指称假设**：我问的那个模态，真的对应人心里一个可分辨的概念吗？——流模型可能幻觉出一个「幻影模态」，而人会顺着问句去编一个答案；
> (b) **提问中立假设**：问句只是「取样」，不会改变被问者的信念。但「你想让我走左边还是右边？」这句话本身已经把「这是一个二选一」甚至「我倾向于左边」塞进了对方先验。所有证据源共享同一个问句，于是 R69 引理 18 的「k 源独立」在因果上就不成立；
> (c) **内容即全部假设**：回答只有文本内容有用。可人说话时带着停顿、升调、气声、自我修正——这些副语言信息恰是「我有多确定」的廉价通道，R69 把它们全丢了。
>
> 本轮两个灵感正好戳在这三处：
> - **语音交互**：一句话同时携带 **内容（lexical）** 与 **姿态（prosodic stance）** 两条通道；更关键的是，语音让「指称游戏（reference game）」成为可运行的原语——系统可以描述、人可以命名、双方可以核对「我们说的是不是同一个东西」。
> - **原型验证**：原型在认知科学里是「范畴的典型样本」，在工程里是「部署前的样机」；两者是同一件事的两面——**原型是一个待验证的指称假设**。一个模态原型在驱动提问之前，必须先在「人能否用语言稳定地指到它」这件事上通过验证；这正是 R69 最大风险（追问幻影）缺的那道闸。
>
> 核心命题：**指称先于提问（grounding precedes questioning）**。只有当模态原型通过双向命名/参考游戏、问句被证明非诱导（低 leadingness）、副语言通道被校准且只能否决不能背书、并且交互以异步方式接入时，语音消歧才被允许；否则退回 R69，再退回 R68。命名 **VIVA-RAS**（Voice-grounded Interactive Validation of Action prototypes）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我问的那个东西真的存在吗？我们说的是同一件事吗？**」——不确定性不仅可以是一句提问，提问本身也需要被验证。

## 0. 直觉与动机

**灵感 1（语音 = 内容 + 姿态；姿态天然廉价、也天然可伪造）**
直觉：文本里「我不知道」和「嗯……应该是左边？」都可能被记成「左边」。但语音里的 1.4 秒停顿、句尾升调、气声、自我修正（「左边——不对，是你左边还是我左边？」）都在说「我不确定 / 我没听懂 / 我们的参考系不一样」。这是一个几乎免费的可靠性信号。
反过来：想骗你的回答者可以用最坚定的语气说错话，也可以用犹豫语气说真话。**所以副语言只能用来「踩刹车」，不能用来「踩油门」**：它可以把决策拉回保守兜底，但不能把系统推得比纯文本证据更自信。这个不对称（veto-only）是语音通道能被安全使用的关键——它把「可能被伪装的增益」换成了「不会被伪装击穿的下界」。

**灵感 2（指称游戏 → 把幻影模态挡在提问之前）**
直觉：人怎么避免问一个不存在的东西？先确认对方能不能指到它。我说「那个斜着放的、有缺口的」，你指给我看；你说「左边那个」，我确认是不是我理解的那个左边。**双向可命名性**就是原型的接地分。
一个特别具体、特别致命的例子：**左右是相对谁而言**。机器人说「向左避让」，人理解成「我的左边」，机器人理解成「自车左侧」——两边都「确认」了，灾难却已注定。所以指称验证必须包含**参考系一致性（frame agreement）**，而不只是「能不能命名」。这也是为什么语音不是可选项：只有自然语言能廉价地把参考系说清楚。

**灵感 3（原型既是认知范畴，也是工程样机）**
直觉：认知科学里的 prototype 是范畴典型；工程里的 prototype 是部署前样机。两者共享一个结构：**原型是一个假设，验证是把假设放回「指称/使用」中检验**。所以本轮把「原型验证」做成**分级协议 P0–P3**：离线指称游戏 → 仿真影子交互 → 小预算真人在环 → 全量。每一级晋升要证书，漂移时降级。这把 R69 的「离线训完就上线」改成「像放样机一样放交互能力」。

**灵感 4（对 R69 引理 18 的反转：共享问句会放大偏差）**
直觉：R69 的证据纪律是「k 个正交源多数一致」。但所有源都听到了**同一个问句**。若问句把「二选一」甚至「我倾向左边」塞进对方先验，则每个源的证据里都混进同一个偏移 δ。独立证据按 √k 增长，共享偏差却按 k 增长——**源越多，错得越自信**。这不是 R69 的实现 bug，而是「正交」定义漏掉了「相对于问句的条件独立」。所以本轮把「k 源」升级为「相对问句的条件独立 / 有效证据数 k_eff」，并把 leadingness 直接写进证据公式。

**灵感 5（异步：语音不可能塞进 2.6ms 控制环）**
直觉：人说一句话要几百毫秒到几秒，ASR 又要几十到上百毫秒。R69 伪代码把 `execute(g)` 放在一个控制周期里同步返回，在语音上物理不可能。正确做法是 **anytime/异步**：提问挂起期间，系统一直按 R68 保守策略飞；答案回来时带时间戳与有效期，过期就丢弃；resolution bonus 只在下一次重规划兑现。这样「会提问」既不让控制环变慢，也不让安全包络在等待期间裸奔——**一个尚未到达的回答，永远不能成为当前动作的前提**。

**灵感 6（隐私是新约束，不是附录）**
直觉：语音是生物特征，原始音频落盘就是长期风险。VIVA 只在端侧提取副语言特征与词置信，原始音频即用即弃；证书里必须能证明「no raw audio」。否则为了消一个 epistemic 歧义，换来一个永久的隐私漏洞，是拿小风险换大风险。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（VIVA-RAS 总览）** VIVA-RAS = (FMP, AUD, MINT, CIA, FMA, VLT, PGV, GG, NLQ, QID, VVP, RAS-WM†)。五不变式：
(i) 继承 R69 定义 293 的三不变式（零学习写操作、交互预算硬约束、证据纪律）；
(ii) **指称门**：只有通过 PGV 验证的模态原型才可成为问句对象；
(iii) **提问中立与问句条件独立**：L(q) ≤ τ_lead，且证据计数用 k_eff（定义 316）而非原始 k；
(iv) **姿态否决（veto-only）**：副语言信任 r(y) ≤ r_lex(y_lex)，只能把决策拉向保守兜底；
(v) **异步 anytime**：控制环从不同步等待语音；挂起期按 R68 保守，答案带时间戳与有效期。

**定义 311（语音回答对象）** y = (y_lex, y_pros)。y_lex 为 ASR 文本与词级置信；y_pros = (τ_lat, F0 轮廓统计, 能量/气声比, 犹豫标记, 自我修正事件, 语速)。副语言特征在端侧提取，原始音频不落盘（隐私不变式），只保留特征与加盐哈希。

**定义 312（原型指称验证 PGV）** 对每个模态原型 ξ̄_k，在参考游戏 𝒢_ref 中做双向命名：
- 系统→人：系统给出**不含答案名**的描述 d(ξ̄_k)，人从候选集指出/选出目标，命中率 p_{S→H}；
- 人→系统：人用自己的词命名该模态，系统经冻结 LLM 的受限词表映射回指，命中率 p_{H→S}；
- 参考系一致性：左右/前后/远近等相对谓词必须显式绑定 f ∈ {ego, viewer, world}，测得一致率 p_frame。
接地分 G_k = κ(p_{S→H}, p_{H→S}, p_frame)，κ 为对随机猜测做校正的 Cohen's κ 型统计量（机会水平由候选数与词表大小决定）。

**定义 313（指称门 GG）** 交互可用集 𝔊_elig = { k : Ĝ_k ≥ τ_g 且 κ 的置信下界 ≥ τ_κ }。未接地模态的 epistemic 质量 U_epi^{ung} 不得进入 VoI，直接并入 R68 兜底项。**幻影模态的第一拦截点在提问之前，而不是在回答之后。**

**定义 314（语音信任模型 VLT）** r_lex(y_lex) ∈ [0,1] 由词置信与多源后验一致性给出；v(y_pros) ∈ [0,1] 为姿态可信度，需校准（ECE ≤ τ_v）；文本 MAP 策略 π_lex，R68 保守策略 π_safe。最终策略用**凸混合**：
π_final = r(y)·π_lex + (1 − r(y))·π_safe，r(y) = r_lex · v(y_pros) ≤ r_lex。
因期望代价对策略混合是线性的，Risk(π_final) ≤ max(Risk(π_lex), Risk(π_safe))——姿态再离谱也只能把系统拉回已经认证过的保守策略，不能把风险推高到两者之上。

**定义 315（问句 leadingness）** 设 q_ref 为不含模态信息的开放参考问句，则
L(q) = max_m KL( P(Y | q, M=m) ‖ P(Y | q_ref, M=m) )。
它度量「即便真模态已知，问句框架本身把回答分布推离多远」。要求 L(q) ≤ τ_lead。生成约束：不得命名系统偏好模态 m̂、不得用穷举二选一提示、不得使用「你是不是觉得……」式预设、不得不经请求就给出系统建议。

**定义 316（问句条件独立与有效证据数）** 证据源 {y_i} 关于问句 q 条件独立，当且仅当 y_i ⊥ q | M（给定真模态后，问句不再额外影响回答）。此时 k_eff = k。若存在共享框架偏移 δ(q)（定义 319 的机制），则
k_eff = k · max(0, 1 − δ(q)/a)²，
其中 a 为单源对真模态的平均对数似然优势。δ(q) ≥ a 时 k_eff = 0：更多源只会放大偏差。纪律：只用 k_eff ≥ 2 的证据定案，否则视为单源，不得触发 resolution bonus。

**定义 317（韵律反欺骗门）** 训练 spoof 检测器 s(y_pros) ∈ [0,1]；若 s > τ_spoof，置 v ≡ 1（姿态信号作废，退化为纯文本信任）。因为姿态不能背书，作废它不损失安全性，只损失效率。

**定义 318（分级原型验证协议 VVP）** 四阶段：
- **P0 离线参考游戏**：G_k、κ 下界、p_frame 达标；
- **P1 影子交互**：仿真中运行完整语音消歧但不执行其建议，度量「若采纳」的后悔；
- **P2 小预算真人在环**：交互预算 ≤ β_2，每次交互带见证（witness）与可回滚动作；
- **P3 全量**：J_VIVA 通过且连续 N 轮无严重指称事件。
晋升需证书；任一阶段 G_k 跌破阈值或出现指称事故即降一级；重验证由漂移调度器安排（定义 319）。

**定义 319（接地漂移与重验证调度）** 人口、语言、场景漂移会使接地分衰减，估计 G_k(t) = G_k(0)·e^{−γ_k t}（或分段常数）。设漂移上界 γ、风险对 G 的 Lipschitz 常数 L_risk，则重验证间隔 Δ 应满足 L_risk·γ·Δ ≤ margin。调度器在预算内优先重验证「Ĝ_k 接近阈值 × 使用频率高」的原型。

**定义 320（语音交互控制器 VINT）** 在 R69 MINT 上加入语音成本与接地约束：
g* = argmax_{g∈𝒜_info} [ VoI_𝔊(g) − c_phys(g) − c_social(g) − c_attn(g) ]，
s.t. risk(g) ≤ ε_int，L(q(g)) ≤ τ_lead，且 q(g) 只引用 𝔊_elig 中的模态。VoI_𝔊 只在接地集上积分；未接地质量不进 VoI。无利可图（≤0）则不交互。

**定义 321（异步证据更新）** 交互提交时刻 t_s，回答到达 t_a，有效期 [t_s, t_s + W_v]。若 t_a > t_s + W_v，或期间 WM 漂移（R67 VISTA 度量）超过阈值，则答案作废。挂起期控制策略为 R68 保守（λ = λ_floor(U_ale + U_epi)）；答案到达后的**下一次重规划**才兑现 resolution bonus。

**定义 322（威胁模型 ℰ_REF）** 在 R69 ℰ_FLUID 上增加：
- **诱导性共谋**：人顺着问句框架编答案，所有源同向偏差（对应引理 19）；
- **假接地**：人故意用系统词表里的词去「命名」一个不存在的东西，制造假 G_k；
- **参考系诈骗**：用「左」诱导 ego/viewer 参考系错配；
- **副语言伪装**：自信语气说错话，或犹豫语气说真话以诱发过度保守（后者只损失效率，前者由 veto-only 封死）；
- **语音隐私攻击**：声纹、环境音泄漏。
记 ℰ_VIVA = ℰ_FLUID × ℰ_REF。

**定义 323（证书 J_VIVA）** J_VIVA = (J_FLUID, {G_k, κ_k, p_frame}_k, τ_lead 合规, ECE_pros, spoof_rate, k_eff_min, P-stage, revalidation_due, no_raw_audio)。Valid ⇔ Valid(J_FLUID) ∧ 所有被引用模态接地达标 ∧ L(q) ≤ τ_lead ∧ k_eff ≥ 2 ∧ 未触发降级。

**定义 324（退化链与两级风险缩放）** 若接地门关、或 VoI_𝔊 ≤ c、或 L(q) 不可满足、或 spoof 越界：不进行语音交互。此时若 R69 的非语音信息动作（注视/探针）可用则退到 R69；否则退到 R68。统一写为
λ = λ_floor( U_ale + U_epi^{ung} + U_epi^{gnd,未消解} )。
⇒ **R68 ⊂ R69 ⊂ VIVA** 的退化链，安全侧逐级不让步。

## 2. 关键算法骨架

```python
# IP-264 VLT：内容信任 × 姿态否决（乘性收缩 = 温度退火）
class VoiceTrust:
    def __init__(self, lex_model, pros_model, spoof_model, tau_spoof=0.7):
        self.lex, self.pros, self.spoof = lex_model, pros_model, spoof_model
        self.tau_spoof = tau_spoof

    def r(self, y):
        r_lex = self.lex(y.y_lex)                       # ∈[0,1]
        if self.spoof(y.y_pros) > self.tau_spoof:
            return r_lex                                # 姿态作废，绝不背书
        return r_lex * min(1.0, self.pros(y.y_pros))     # 只减不增

# IP-265 PGV：双向指称游戏 + 参考系一致
class PrototypeGroundingValidator:
    def validate(self, proto, humans, vocab, n=30):
        p_sh = self.sys_describe_human_pick(proto, humans, n, hide_name=True)
        p_hs = self.human_name_sys_backref(proto, humans, vocab, n)
        p_fr = self.frame_agreement(proto, humans, n)    # ego/viewer/world
        G  = cohen_kappa(p_sh, p_hs, p_fr, chance=self.chance(vocab))
        lo = bootstrap_lower_bound(G, n, alpha=0.05)
        return G, lo

# IP-267 NLQ：在接地词表上生成低诱导问句
def make_question(modes_elig, o_t, tau_lead):
    cands = []
    for m in modes_elig:
        q = llm.decode(neutral_prompt(m), forbid_name=True,
                       forbid_binary_hint=True, forbid_suggestion=True)
        if leadingness(q, m, o_t) <= tau_lead:           # 定义 315
            cands.append((q, m))
    return max(cands, key=lambda qm: information_gain(*qm), default=None)

# IP-268 QID：问句条件独立下的有效证据数
def effective_k(sources, q, a_hat):
    delta = framing_bias(q)                              # 共享框架偏移 δ(q)
    return len(sources) * max(0.0, 1.0 - delta / a_hat) ** 2

# IP-274 主闭环：控制环与交互环分离（anytime）
def control_tick(M, obs):                                # 严格实时路径
    lam, k, mode = M.r68_conservative(obs)               # 先保守飞，不等语音
    if M.pending and M.pending.ready():
        y, t_s = M.pending.pop()
        if (now() - t_s) <= M.W_v and not M.vista.drift_exceeded(t_s):
            r = M.vlt.r(y)
            M.cia.integrate(y, weight=r,
                            k_eff=M.qid.effective_k(y.sources, y.q, M.a_hat))
        else:
            M.vqa_v.log_stale(y)                         # 过期答案作废，仅审计
    if M.aud.U_epi > TAU_EPI and M.gg.eligible(M.modes) \
       and not M.fma.slow_fault_suspect:
        q = M.nlq.make_question(M.gg.eligible(M.modes), obs, TAU_LEAD)
        if q and M.vint.net_value(q) > 0 and M.budget.allow(q):
            M.pending = M.vint.submit_async(q)           # 立即返回，不阻塞
    lam2 = M.efs.apply_resolution_bonus(lam, M.cia.posterior)  # 下一次重规划
    return lam2, k, M.select_mode(M.modes, M.cia.posterior, lam2)
```

## 3. 推导

**引理 19（共享问句偏差的 k 源放大）** 设各源对偏好模态 m̂ 的对数似然比为 ℓ_i = s_i + δ(q)，其中真模态为 m*，s_i 独立、E[s_i] = −a < 0（单源倾向真相）、Var(s_i) = σ²，δ(q) 为所有源共享的框架偏移（它们听到同一个 q）。则 k 源总 LLR 为 L_k = Σ_i s_i + kδ。于是 E[L_k | m*] = k(δ − a)。**当 δ ≥ a 时，P(采纳 m̂) → 1（k→∞）**：源越多，错得越确信。即便 δ < a，错误指数由 a_eff = a − δ 而非 a 决定，等价于 k_eff = k·(a_eff/a)²（定义 316）。系：R69「k 源正交」只在 δ=0 时成立；语音问句使 δ>0，因此**问句条件独立是证据计数的前置条件**，不是修辞。

**引理 20（姿态否决的安全凸性）** 由定义 314，π_final 是 π_lex 与 π_safe 的凸组合，混合系数 r ≤ r_lex ≤ 1。期望代价 J(π) 对 π 线性，故 J(π_final) = r·J(π_lex) + (1−r)·J(π_safe) ≤ max(J(π_lex), J(π_safe))。对手控制 y_pros 最多把 r 压低（→ 更靠近 π_safe），无法把 r 抬高到 r_lex 之上；因此姿态伪装的最坏后果是「退化为纯文本或退化为 R68」，**不可能比两者更差**。这与 R69 的对称信任形成对照：对称信任允许对手用「自信」抬高权重，从而把错误放大。

**引理 21（指称门对幻影提问的拦截）** 设真实接地分 G_k ∈ [0,1]，由 n 次参考游戏得到估计 Ĝ_k，Hoeffding 给出 P(|Ĝ_k − G_k| ≤ ε) ≥ 1 − δ_0，ε = √(log(2/δ_0)/(2n))。幻影模态的真实接地分 G ≤ τ_p，而门限 τ_g 满足 τ_p + 2ε < τ_g。则
P(幻影通过指称门) ≤ P(Ĝ ≥ τ_g) ≤ P(Ĝ ≥ G + ε + (τ_g−τ_p−ε)) ≤ δ_0。
即幻影被成规模地挡在提问之前；剩余风险来自「真模态被误判为未接地」（损失效率，不损失安全）。系：这正是 R69 最大风险「追问幻影」的结构性缓解——不是靠回答后的证据纪律去补救，而是让问题根本不发出去。

**定理 18（VIVA 严格包含 R69 与 R68）** 在 A95–A98 及定义 310 五不变式下：
(i) 当指称门全关、或所有候选问句 L(q) > τ_lead、或姿态门不可用 ⇒ 无语音交互，VIVA 逐指令退化为 R69 的非语音路径；若 R69 的非语音动作也无利可图 ⇒ 逐指令退化为 R68；
(ii) 指称门只从动作集中**删除**动作（不新增），veto-only 只把策略向 π_safe 收缩（引理 20），低 leadingness 只减少偏差（引理 19）⇒ 在 R69 的威胁模型下期望风险 ≤ R69；在 ℰ_REF 下严格更低；
(iii) 因此安全侧不让步，效率侧仅在「接地 ∧ 中立 ∧ 异步有效」时获得 resolution bonus。

**定理 19（分级验证的 PAC 上界与漂移降级）** 在 P_j 阶段执行 n_j 次交互、观测经验错误率 ê_j，则真实风险 ≤ ê_j + √(log(2/δ)/(2n_j))（Hoeffding）。晋升 P_j→P_{j+1} 要求该上界 ≤ 目标风险 τ_j；降级在重验证 G_k 跌破 τ_g 或连续严重事件时触发。若接地分以速率 γ 漂移、风险对 G Lipschitz 常数为 L_risk，则选择 Δ ≤ margin/(L_risk·γ) 的重验证间隔即可保证阶段内瞬时风险上界不被漂移击穿。系：这把「交互能力上线」从一次性部署变成**可回退、带见证、带到期日的样机验证流程**。

**推论 19.1（语音的净价值主要来自方差而非均值）** 条件互信息 I(M; Y_lex, Y_pros) ≥ I(M; Y_lex) 恒成立，但经 veto-only 后，语音在「平均情形」上的信息增益被刻意限制；它真正可认证的收益是**坏情形下的方差压缩**（少一次自信的错误采纳、少一次幻影追问）。这解释了为什么 VIVA 的收益指标应看 P95 事故率与后悔分布尾部，而不只是平均成功率。

## 6. 本轮最大风险

**一句话**：VIVA 的安全性全部押在「参考游戏是真实部署指称关系的忠实代理」上——**若验证人群、语言、参考系与部署分布不同，或指称游戏本身被反向利用（用系统词表制造假接地），那么指称门会为一套仅仅「局部成立」的共识签发证书；系统于是自信地问向一个错误的世界，而且这次错误还盖着验证过的章——验证过的错误，比未经验证的错误更难被发现。**

**次级风险与缓解**：
1. **假接地/词表反向利用** → 参考游戏加入反事实探针与「不存在候选」；假接地识别（E315）+ 降级；
2. **参考系诈骗** → 定义 312 显式绑定 ego/viewer/world，交叉复核；
3. **诱导性共谋** → 定义 315 低 leadingness + 定义 316 k_eff 纪律 + 引理 19 上界；
4. **副语言伪装/跨文化韵律差异** → veto-only（引理 20）+ 反欺骗门 + 分文化校准；
5. **隐私** → 端侧特征、原始音频不落盘、证书 no_raw_audio；
6. **交互疲劳与延迟** → 异步 + 有效期 + 预算 + E313 人类研究；
7. **验证成本** → 只在少数高风险模态上做 PGV，P0 自动筛选优先重验证对象。

```python
class VoiceTrust:

def make_question(modes_elig, o_t, tau_lead):

                       forbid_binary_hint=True, forbid_suggestion=True)

    return len(sources) * max(0.0, 1.0 - delta / a_hat) ** 2
```

## 4. 推导

**引理 19（共享问句偏差的 k 源放大）** 设各源对偏好模态 m̂ 的 LLR 为 `ℓ_i = s_i + δ(q)`，真模态 m*，`s_i` 独立、`E[s_i]=−a<0`、`Var=σ²`，δ(q) 为所有源共享的框架偏移。则 `L_k=Σs_i+kδ`，`E[L_k|m*]=k(δ−a)`。**δ≥a 时 P(采纳 m̂)→1（k→∞）**；即便 δ<a，错误指数由 `a_eff=a−δ` 决定，等价于 `k_eff=k·(a_eff/a)²`。系：R69 的 k 源正交仅在 δ=0 时成立，**问句条件独立是证据计数的前置条件**。

**引理 20（姿态否决的安全凸性）** `π_final = r·π_lex+(1−r)·π_safe`，`r≤r_lex≤1`；期望代价对策略线性，故 `J(π_final) ≤ max(J(π_lex), J(π_safe))`。对手只能压低 r（更靠近已认证的 π_safe），无法抬高到 r_lex 之上 ⇒ 姿态伪装最坏退化为纯文本或 R68，**不可能更差**。

**引理 21（指称门拦截幻影）** 由 n 次参考游戏得 `Ĝ_k`，Hoeffding：`P(|Ĝ−G|≤ε) ≥ 1−δ_0`，`ε=√(log(2/δ_0)/(2n))`。幻影真实接地 `G≤τ_p`，门限满足 `τ_p+2ε<τ_g`，则 `P(幻影过门) ≤ δ_0`。系：R69 最大风险被**结构性**缓解——问题根本不发出去，而不是回答后再补救。

**定理 18（严格包含 R69 与 R68）** (i) 指称门全关 / `L(q)>τ_lead` / 姿态门不可用 ⇒ 无语音交互，逐指令退化为 R69；R69 非语音动作也无利可图 ⇒ 逐指令退化为 R68。(ii) 指称门只删除动作，veto-only 只向 π_safe 收缩，低 leadingness 只减少偏差 ⇒ 在 R69 威胁模型下风险 ≤ R69，在 ℰ_REF 下严格更低。(iii) 安全不让步，效率侧仅在「接地 ∧ 中立 ∧ 异步有效」时获 resolution bonus。

**定理 19（分级验证 PAC 上界与漂移降级）** P_j 阶段执行 n_j 次，真实风险 `≤ ê_j+√(log(2/δ)/(2n_j))`；晋升要求上界 ≤ τ_j。接地分以 γ 漂移、风险对 G 的 Lipschitz 常数为 L_risk 时，取 `Δ≤margin/(L_risk·γ)` 保证阶段内上界不被漂移击穿。系：交互能力上线 = 可回退、带见证、带到期日的样机验证。

**推论 19.1（语音净价值来自方差而非均值）** `I(M;Y_lex,Y_pros) ≥ I(M;Y_lex)` 恒成立，但 veto-only 刻意限制平均增益；可认证收益是**尾部方差压缩**（少一次自信错误、少一次幻影追问）。故收益指标看 P95 事故率与后悔尾部，而非平均成功率。

## 7. 本轮最大风险

**一句话**：VIVA 的安全性全部押在「参考游戏是真实部署指称关系的忠实代理」上——**若验证人群、语言、参考系与部署分布不同，或指称游戏本身被反向利用（用系统词表制造假接地），指称门就会为一套仅「局部成立」的共识签发证书；系统于是自信地问向一个错误的世界，而且这次错误还盖着验证过的章——验证过的错误，比未经验证的错误更难被发现。**

**次级风险与缓解**：假接地/词表反向利用（反事实探针 + 「不存在候选」+ E315 + 降级）；参考系诈骗（显式绑定 ego/viewer/world + 交叉复核）；诱导性共谋（低 leadingness + k_eff 纪律 + 引理 19）；副语言伪装/跨文化差异（veto-only + 反欺骗门 + 分文化校准）；隐私（端侧特征 + 原始音频不落盘 + no_raw_audio）；交互疲劳/延迟（异步 + 有效期 + 预算 + E313）；验证成本（仅对高风险模态做 PGV）。
