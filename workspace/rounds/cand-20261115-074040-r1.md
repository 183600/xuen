# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；本轮灵感：「域随机化」×「论文发表」）

> R69 给系统装上了「嘴」：看不清就问、就凑近、就等。但 R66–R69 一路下来，所有证书都压在一个未经审视的假设上：**我们是在「一个世界」里认证安全**——用标定后的点估计 θ̂ 代表现实，用一次实验的结果盖章。可现实只是某个环境分布 P* 的一次抽样；在 θ̂ 上成立的证书，在 θ̂+Δ 上可能失效。R68 的标定把 gap「吸收」进参数，却没有把 gap「覆盖」进合同——于是安全被**过拟合到名义世界**。
>
> 更隐蔽的是第二层：R69 的证据纪律管的是**观测**（k 个模态互相印证），却不管**主张**（claim）。系统自己决定测哪个指标、跑哪些世界、什么时候停；它会报告通过的世界、隐去失败的世界、把阈值调到刚好通过、把随机化分布收窄到刚好覆盖。这在科学里叫 p-hacking / HARKing / 发表偏倚 / 可选停止，在安全里叫**自己给自己发论文**。一个只会报告成功的安全系统，比一个诚实的保守系统更危险。
>
> 本轮两个灵感正好各补一刀：
> - **域随机化**把「一个世界」换成「一个世界族群」：安全不是名义点上的一个数，而是对**预先承诺**的 P_Θ 的高置信下界；证书必须对分布成立，而不是对样本成立。
> - **论文发表**给「主张」装上科研纪律：预注册（先承诺假设/指标/样本量/停止规则）、复制（独立世界流复现）、同行评审（留出世界族做对抗性证伪）、多重比较校正、撤稿与引用传播。随机化的每个世界都是一位审稿人，而「审稿人 2」就是族群里的最坏世界。
>
> 核心命题：**把环境的点估计升级为预先承诺的世界族群，把每条安全证书升级为一篇必须经过预注册、复制、统计显著性与对抗评审才能「发表」的主张；实时环路只信任已发表（或降级的预印本）证书，未覆盖的现实差距一律弃权并退回 R68 的保守界。** 命名 **PAPER-RAS**（Population-Adversarial Pre-registered Evidence Review for Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我这句话是对哪个世界说的，它经得起复现和审稿吗**」——安全不是一个测一次的数，而是一篇要能被复现、被证伪、也会被撤稿的论文。

## 0. 直觉与动机

**灵感 1（域随机化 → 世界是族群，不是点）**
直觉：R68 花整轮把观测校准到「真实参数」，然后在这个 θ̂ 上证明安全。这是把「现实」当成一个可估的常数。但现实的正确画像是 **θ ~ P\***：地面摩擦、负载、通信延迟、传感器偏置、人的配合度，每一次部署都是从同一个分布里重新抽一次。点估计的危险在于它把方差记成了偏差——标定能对齐均值，却对「下一次抽到尾巴」毫无保证。域随机化给出另一条路：不去猜那一个 θ，而是**承诺一个 θ 的分布 P_Θ**，要求策略在 P_Θ 的整个支撑上工作。于是安全从「在这个点上不撞」变成「在这个族群上以高概率不撞」。更关键的是：随机化把「现实差距」从不可见的敌人变成了**可采样、可审计、可对抗的审稿人集合**。

**灵感 2（论文发表 → 主张需要纪律，而不只是数据）**
直觉：R69 说「单次交互不能定案，要 k 个正交证据」，这条纪律很好，但它只约束**证据**，不约束**主张**。真正让科学可信的不是「做了实验」，而是：先注册要检验什么（否则就是 HARKing）；按注册的指标和停止规则跑（否则就是 p-hacking / 可选停止）；在独立数据上复现（否则就是过拟合）；让敌对的人来找反例（否则就是确认偏误）；报告全部结果而不是只报告通过的那些（否则就是发表偏倚）；并且当反例出现时**撤稿**，让引用它的结论一起失效。把这套纪律搬到系统内部，就得到一个尖锐的判据：**一条安全证书不是「跑出来通过」，而是「经得起被推翻」。**

**灵感 3（两个灵感咬合 → 随机化世界就是审稿人）**
直觉：域随机化的样本天然构成一个**对抗评审委员会**：训练/调参用的世界族是「作者」，留出的世界族是「审稿人」，最坏世界是「审稿人 2」。预注册承诺 P_Θ（防止收窄分布 = 移动球门），复制要求独立世界流（防止记住审稿人），多重比较校正（防止在几十个指标里挑一个好看的就发表），撤稿传播（防止一篇坏论文毒化整个引用网络）。于是「域随机化」提供**证据从哪来**，「论文发表」提供**证据怎样才能变成可信主张**——两者缺一不可。

**灵感 4（现实差距不可自证 → 必须弃权）**
直觉：无论 P_Θ 多宽，真实的 P\* 都可能在支撑之外。**你无法只从内部证明你的随机化覆盖了现实**——这是没有免费午餐的统计版。因此 PAPER-RAS 必须显式带一个**残余现实差距** ρ：所有证书都是「相对于假设的 ρ-球」成立。一旦 OOD 检测器报告 P\* 逃出了这个球，唯一诚实的动作不是继续用旧证书，而是**弃权**：退回 R68 的纯保守界，并把相关证书标为「不再覆盖当前部署」。承认「我没资格说」，比自信地错要好。

**灵感 5（自己给自己发论文 → 新的威胁模型）**
直觉：一旦系统能「发表」证书，就有了新的攻击面，而且攻击者可能就是系统自己（或其优化压力）：收窄 P_Θ 直到通过（**随机化作弊 / DR-hacking**）、在评审集上反复调参（**数据泄漏**）、看到结果再选指标（**指标购物**）、好看就停（**可选停止**）、只记录通过的世界（**发表偏倚**）、让审稿人与作者共享种子/特征（**评审合谋**）、伪造世界日志（**数据伪造**）。**一个可被自己欺骗的认证机制，会把「诚实的不知道」升级成「有公信力的错误」**。所以本轮必须同时交付：承诺哈希、留出世界族、anytime-valid 统计、多重比较控制、来源存证与撤稿传播——否则 PAPER-RAS 只是给 R68 的保守主义印了一张假文凭。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（PAPER-RAS 总览）** PAPER-RAS = (DRP, SCC, PRR, ARB, DRH, MCC, RCR, RAS-WM‡)。四条不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **分布承诺不可回退**：一次部署周期内 P_Θ 的承诺哈希固定，任何收窄/放宽都需重新注册并作废旧证书；
(iii) **主张纪律**：任何证书必须在评估前完成预注册（假设、指标、检验、样本量/停止规则），且单次实验不得单独发表，需独立世界流复制 + 留出族评审；
(iv) **撤稿单调性**：撤稿只允许收紧（λ 不降、可用动作集不增），且沿依赖 DAG 传播，不得有活跃证书依赖已撤稿主张。

**定义 311（世界族群与承诺）** 环境参数 θ ∈ Θ（摩擦、质量、延迟、传感器偏置、人类策略等），预注册分布 P_Θ，承诺 c_Θ = H(P_Θ, seed_policy, 指标集, 停止规则)。部署期只允许从承诺的 P_Θ 采样；采样器日志带来源证明（provenance）以防伪造。

**定义 312（分布安全合同）** 单回合成功/无违规指示 S(θ) ∈ {0,1}。族群安全概率 p_safe = P_{θ~P_Θ}(S(θ)=1)。证书不报点估计，而报**置信下界** LCB_{1−α}(p_safe)（Clopper–Pearson 或 anytime-valid e-value）。安全约束作用在 LCB 上：只有 LCB ≥ 1−δ 才可「发表」。

**定义 313（现实差距与弃权）** 真实分布 P\* 与 P_Θ 的距离以 Wasserstein / f-散度度量；证书只在模糊球 B_ρ(P_Θ) 内有效：certified risk = sup_{P∈B_ρ(P_Θ)} risk(P)。ρ 是**显式假设**，不可由系统自证。若 OOD 分数 d(P\*,P_Θ) > ρ（或不可估），触发弃权：禁用已发表证书，退回 R68 保守界。

**定义 314（主张对象与预注册记录）** 主张 C = (假设 H, 指标 m, 检验统计量 T, 阈值 τ, 样本量 n 或停止规则 𝒮, 世界族划分)。预注册记录 R(C) 在见到任何评估世界前写入只追加日志并哈希；事后修改即视为新主张、需重新注册。

**定义 315（主张生命周期）** C 的状态机：draft → registered → replicated → reviewed → published（或 rejected / retracted）。只有 published 进入受信证书库；provisional（见定义 322）是受限的中间态。

**定义 316（anytime-valid 证书）** 用 e-value / 置信序列替代固定 n 的 p 值：E_t 满足 P_{H_0}(∃t: E_t ≥ 1/α) ≤ α（Ville 不等式）。这样实时监控、可选停止、连续评估都不会抬高假阳性——正好匹配 R69 的实时环路。

**定义 317（对抗评审 ARB）** 世界族划分为调参族 𝒜、留出族 ℬ（ℬ ∩ 𝒜 = ∅，且划分在预注册中固定）。评审器在 ℬ 内做**证伪搜索**：找 θ 使 S(θ)=0（或风险超阈），并可围绕 P_Θ 的 ρ-球做最坏情形搜索。找到反例 ⇒ reject/retract；找不到不等于证明，只是未证伪。

**定义 318（复制协议）** 独立世界流 = 不同种子 + 不同世界族 + 不同遥测通道。主张需在 ≥2 条独立流上均通过（同一预注册检验），否则不得 published。独立性由种子承诺与来源证明共同保证。

**定义 319（DR-hacking 检测 DRH）** 监测四类作弊：(a) P_Θ 相对承诺收窄（分布漂移）；(b) 评估世界与调参世界重叠（泄漏）；(c) 指标/阈值/停止规则事后变更（指标购物/可选停止）；(d) 只登记成功世界（发表偏倚）。任一命中 ⇒ 主张降级为 rejected，并记入审计。

**定义 320（多重比较控制 MCC）** 一个证书含 m 条子主张。控制族错误率 FWER ≤ α（Bonferroni α/m）或 FDR ≤ q（Benjamini–Hochberg）。证书必须声明校正方式，未声明者按最保守处理。

**定义 321（撤稿与依赖传播 RCR）** 证书间构成依赖 DAG（如 J_PAPER 依赖 J_CALM 的标定主张）。撤稿节点 taint 沿出边传播；拓扑序保证所有后代被标为 invalid。RCR 不变式：活跃证书集内不存在被撤稿祖先。

**定义 322（预印本/正式发表分级 PPC）** provisional 证书：小样本、宽 LCB、允许有限自主（λ 较大、动作集受限）；published 证书：复制 + 评审通过、LCB 更紧、允许更大自主。相当于「预印本可读但别全信，正式发表才进教材」。

**定义 323（证书 J_PAPER）** J_PAPER = (J_FLUID, c_Θ, ρ_assumed, LCB_safe, α/FWER, replication_ids, reviewer_ids, claim_log_hash, drh_flags, tier, paper_ver)。Valid ⇔ Valid(J_FLUID) ∧ LCB_safe ≥ 1−δ ∧ 预注册完整 ∧ 复制与评审通过 ∧ 无 DRH 命中 ∧ 未撤稿。

**定义 324（实时接口与降级）** 实时控制环（<2.6ms）只读**当前有效证书**，不参与认证/复制/评审（这些在离线/异步流水线）。证书有**新鲜度**：过期、撤稿、或 d(P\*,P_Θ)>ρ ⇒ 当轮立即降级为 R68 保守界（λ=λ_floor(U_ale+U_epi)），且不中断控制（继承 R68 定理 15 换装不变式）。

# IP-264 DRP：世界族群采样与承诺（采样器带来源证明）
class DomainRandomizedPopulation:
    def __init__(self, P_theta, seed_policy, metrics, stopping_rule):
        self.commit = sha256(canonical(P_theta, seed_policy, metrics, stopping_rule))

    def sample(self, family, n, stream_id):
        assert sha256(canonical(self.P_theta, family)) == self.commit  # 承诺未变
        thetas = self.P_theta.sample(n, seed=derive(stream_id, family))
        return [(th, provenance(th, stream_id)) for th in thetas]      # 来源存证

# IP-265 SCC：统计证书编译器（anytime-valid 下界）
def compile_certificate(successes, n, alpha, claims_m, method="cp"):
    alpha_adj = alpha / claims_m                       # IP-269 多重比较校正
    if method == "cp":
        lcb = clopper_pearson_lower(successes, n, alpha_adj)
    else:
        lcb = e_value_confidence_sequence(successes, n, alpha_adj)  # 可选停止安全
    return lcb                                          # 只发表 LCB，不发表点估计

# IP-266 PRR：预注册 + 复制注册表（只追加）
def preregister(claim):
    assert claim not in registry                        # 见到数据前登记
    registry.append(hash_record(claim)); return claim.id

def replicate(claim, streams):
    results = [evaluate(claim, s) for s in streams]     # 独立种子/族/遥测
    return len(results) >= 2 and all(r.passed for r in results)

# IP-267 ARB：留出世界族的对抗证伪
def adversarial_review(claim, holdout_families, budget, rho):
    for fam in holdout_families:                        # 评审集与调参集不相交
        for theta in worst_case_search(claim.P_theta, fam, rho, budget):
            if not claim.policy.safe(theta):            # 找到反例
                return Reject(counterexample=theta)
    return Pass(not_refuted=True)                       # 未证伪 ≠ 已证明

# IP-268 DRH：随机化作弊 / 泄漏 / 指标购物检测
def audit_claim(claim, log):
    flags = []
    if log.P_theta_effective != claim.commit_theta:  flags.append("distribution_narrowing")
    if overlaps(log.eval_worlds, log.tune_worlds):   flags.append("leakage")
    if log.metric != claim.registered_metric:        flags.append("metric_shopping")
    if log.stopped_at != claim.registered_stop:      flags.append("optional_stopping")
    if log.success_only:                             flags.append("publication_bias")
    return flags

# IP-270 RCR：撤稿沿依赖 DAG 传播
def retract(claim_id, reason):
    stack = [claim_id]
    while stack:
        c = stack.pop()
        c.status = "retracted"
        stack.extend(c.dependents)                      # taint 后代
    assert no_active_has_retracted_ancestor()           # 定义 321 不变式

# IP-274 主闭环（实时环只读证书；认证在离线流水线）
def PAPER_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    # 0) 实时：只读当前有效证书，不跑认证
    cert = M.cert_store.current()
    if cert is None or cert.stale or cert.retracted or M.ood.dist(o) > cert.rho:

    # 1) 正常 FLUID 路径，但安全约束用证书的 LCB

    lam = max(M.efs.risk_scale(...), lam_floor_from_lcb(cert.lcb, U_ale + U_epi))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(modes, U_epi, lam)
    M.vqa_i.submit_async(...)                            # 审计（含证书 tier）
    return k, lam, mode

# 离线/异步：预注册 → 族群采样 → 统计编译 → 复制 → 对抗评审 → 发表/撤稿
def paper_pipeline(claim):
    cid = M.prr.preregister(claim)
    for stream in M.prr.independent_streams():
        worlds = M.drp.sample(family=stream.family, n=claim.n, stream_id=stream.id)
        stats  = evaluate_on(claim, worlds)
        lcb    = M.scc.compile_certificate(stats.k, claim.n, claim.alpha, claim.m)
    if M.drh.audit_claim(claim, log):        return M.rcr.retract(cid, "DR-hacking")
    if not M.prr.replicate(claim, M.prr.streams):  return Reject(cid)
    if M.arb.adversarial_review(claim, M.arb.holdout, M.budget, M.rho).rejected:

    return M.cert_store.publish(claim, lcb, tier="published")

## 3. 推导

**引理 19（族群覆盖 ⇒ 点安全的置信保证）** 若在 n 个 i.i.d. 世界（θ~P_Θ）中观测到 k 次成功，则单侧 Clopper–Pearson 下界 LCB 满足 P_{P_Θ}(p_safe ≥ LCB) ≥ 1−α。特例（k=n，零失败）：p_safe ≥ α^{1/n}，故要认证失败率 ≤ ε 需 n ≥ ln α / ln(1−ε) ≈ (1/ε)ln(1/α)；95% 置信的「三法则」给出 n ≥ 3/ε。系：**证书的样本量由目标 δ 与置信度反推，而不是由算力决定**——「跑了多少」不再是论据，「能保证多坏」才是。

**引理 20（现实差距不可自证）** 仅凭 P_Θ 上的有限样本，无法判定真实 P\* 是否属于 B_ρ(P_Θ)；任何「P_Θ 已覆盖现实」的断言都等价于对 ρ 的先验假设。故 PAPER-RAS 的每条证书都必须携带 ρ_assumed，且 OOD 一旦越界只能弃权。要点：**这不是工程缺陷，而是可证明的边界**；把它写进证书，比假装它不存在更安全。

**引理 21（预注册 + 复制压低假发表率）** 对 m 条子主张做 Bonferroni 校正后，单条假阳性率 ≤ α/m，FWER ≤ α。若一条假主张在两条独立世界流上均通过、每流假阳性率 ≤ α'，则其被「发表」的概率 ≤ α'^2（独立性下）；再用留出族评审，反例漏检率 ≤ δ_rev。故假发表率 ≤ α'^2 + δ_rev。系：**复制不是形式主义，它把「碰巧好看」压成平方级的小概率**。

**引理 22（撤稿传播的可靠性）** 若依赖图为 DAG 且撤稿按拓扑序传播，则撤稿结束后活跃证书集与「所有祖先均未撤稿」的证书集相同；故不存在活跃证书依赖已撤稿主张。系：撤稿只收紧（λ 不降、可用动作集不增），与 R68 定理 15 的换装不变式兼容 ⇒ 无控制突变。

**定理 18（PAPER-RAS 严格包含 R68/R69）** 取 P_Θ = δ_{θ̂}（点质量）、不做复制、tier=provisional 且 LCB→点估计，则 PAPER-RAS 逐指令退化为 R68（R69 为其交互分支）。反之，PAPER-RAS 的安全约束作用在 LCB 上，而 LCB ≤ 点估计，故其安全保证不弱于 R68；效率侧仅在「已发表且复制通过」时获得 **certification bonus**（可在 LCB 允许范围内放宽 λ）。因此 R68/R69 是 PAPER-RAS 在「单世界、不发表」边界上的退化。

**定理 19（评审可靠性 + 单调安全）** 若 P_Θ 承诺未被篡改、世界采样可验证、复制流独立，则任何 published 证书对应的真实族群安全概率 ≥ 1−δ 以置信度 1−α 成立；且撤稿/过期/OOD 越界只会使 λ 单调不降。要点：**发表的不是「通过」，而是「以 1−α 置信度不低于 1−δ」**；系统宁可少发表，也不许把未复现的通过当成安全。

**定理 20（评审合谋上界）** 若评审器与策略共享盲区、反例漏检相关为 ρ_c < 1，则 k 个正交留出族的漏检率 ≤ ρ_c^{k} + ε_σ；当 ρ_c→1（合谋）时评审失效，故必须由外部权威固定世界族划分与种子。系：**留出族必须是「别人的世界」，不能是作者自己挑的世界**。

## 6. 本轮最大风险

**一句话**：PAPER-RAS 把「谁来决定什么叫安全」交给了系统自己的认证流水线——**它同时是作者、审稿人和编辑**：只要预注册承诺、世界族划分与采样来源不由**外部可验证的权威**固定，它就能收窄 P_Θ、在评审集上调参、看到结果再选指标、好看就停，然后「发表」一张统计上无懈可击、事实上毫无意义的证书；而实时环信任已发表证书，于是一篇坏论文可以一次性授权整个机队的冒险——**自己给自己发论文，比不发论文更危险**。

1. **分布承诺被回退/收窄**（移动球门）→ 承诺哈希 + 定义 310-ii 不可回退 + E304；

6. **撤稿滞后/级联失效** → RCR 拓扑传播 + 定义 321 不变式 + E308/E315。

## 4. 推导

**引理 19（族群覆盖 ⇒ 点安全的置信保证）** n 个 i.i.d. 世界中 k 次成功，单侧 Clopper–Pearson 下界满足 `P(p_safe ≥ LCB) ≥ 1−α`。零失败（k=n）时 `p_safe ≥ α^{1/n}`，故认证失败率 ≤ ε 需 `n ≥ ln α / ln(1−ε) ≈ (1/ε)ln(1/α)`；95% 三法则 `n ≥ 3/ε`。系：**样本量由 δ 与置信度反推，而非算力**。

**引理 20（现实差距不可自证）** 仅凭 P_Θ 上的有限样本无法判定 P\* ∈ B_ρ(P_Θ)；任何「已覆盖现实」的断言等价于对 ρ 的先验假设。故证书必须携带 `ρ_assumed`，OOD 越界只能弃权。这是可证明的边界，不是工程缺陷。

**引理 21（预注册 + 复制压低假发表率）** Bonferroni 后单条假阳性 ≤ α/m，FWER ≤ α；一条假主张在两条独立流均通过的概率 ≤ α'^2；留出族反例漏检 ≤ δ_rev ⇒ 假发表率 ≤ `α'^2 + δ_rev`。系：**复制把「碰巧好看」压成平方级小概率**。

**引理 22（撤稿传播可靠性）** 依赖图为 DAG 且按拓扑序传播时，撤稿后活跃证书集 = 「所有祖先未撤稿」的集合；撤稿只收紧（λ 不降、动作集不增），与 R68 定理 15 换装不变式兼容 ⇒ 无控制突变。

**定理 18（PAPER-RAS 严格包含 R68/R69）** 取 `P_Θ=δ_{θ̂}`、不复制、tier=provisional 且 LCB→点估计，则逐指令退化为 R68（R69 为其交互分支）。PAPER-RAS 的安全约束作用于 LCB，而 LCB ≤ 点估计 ⇒ 安全保证不弱于 R68；效率侧仅在「已发表且复制通过」时获得 certification bonus（在 LCB 允许范围内放宽 λ）。R68/R69 = 「单世界、不发表」边界。

**定理 19（评审可靠性 + 单调安全）** 承诺未篡改、采样可验证、复制流独立时，published 证书对应真实族群安全概率 ≥ 1−δ 以置信度 1−α 成立；撤稿/过期/OOD 越界只使 λ 单调不降。发表的不是「通过」，而是「以 1−α 置信不低于 1−δ」。

**定理 20（评审合谋上界）** 评审器与策略共享盲区、漏检相关 ρ_c<1 时，k 个正交留出族漏检率 ≤ `ρ_c^k + ε_σ`；ρ_c→1（合谋）评审失效，故世界族划分与种子必须由外部权威固定。留出族必须是「别人的世界」。

## 7. 本轮最大风险

**一句话**：PAPER-RAS 把「谁来决定什么叫安全」交给了系统自己的认证流水线——**它同时是作者、审稿人和编辑**：只要预注册承诺、世界族划分与采样来源不由外部可验证的权威固定，它就能收窄 P_Θ、在评审集上调参、看到结果再选指标、好看就停，然后「发表」一张统计上无懈可击、事实上毫无意义的证书；而实时环信任已发表证书，于是一篇坏论文可一次性授权整个机队的冒险——**自己给自己发论文，比不发论文更危险**。

**次级风险与缓解**：分布承诺被回退/收窄（承诺哈希 + 定义 310-ii + E304）；评估/调参世界泄漏（预注册固定族划分 + provenance + DRH）；可选停止/指标购物（anytime-valid e-value + 预注册指标/停止规则）；评审合谋（外部固定留出族与种子 + 定理 20 + 正交多族）；现实差距被高估覆盖（ρ_assumed 入证 + OOD 弃权 + E303/E314）；撤稿滞后/级联失效（RCR 拓扑传播 + 定义 321 不变式 + E308/E315）。
