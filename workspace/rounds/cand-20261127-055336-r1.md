### 第 1 轮灵感驱动研究记录

**灵感词**：具身智能、视觉-语言-动作模型

**直觉与动机**：
现有 SRC-USC（v25）已把「结构-力学-语义-重构-协同」七证编织成链，但其全部证书都默认「策略 π 由可分解的规划器生成」。VLA 模型（RT-2 / OpenVLA / π0 类）打破了这一前提：它把视觉、语言、动作压进一个端到端网络，动作不再来自显式规划，而是来自高维参数化策略的采样。具身智能进一步提醒我们：智能不是「看—说」，而是「看—说—做」在物理身体与环境中闭环涌现；证书必须覆盖 VLA 特有的「语义接地—动作生成—闭环稳定」因果通路。核心洞见：**VLA 的可信性不是输出像不像专家，而是动作是否被指令与场景因果接地、动作分布是否被物理安全集约束、闭环是否在具身偏差下保持收缩**——三者分别回答「为什么这么做」「能不能这么做」「做完会不会失控」。

**形式化目标**：
1. 定义具身接地证书（EGC）：VLA 策略 π_VLA 在任务相关指令干预下动作敏感 d(π(o,ℓ),π(o,ℓ'))≥δ_sens，在任务无关视觉干预下动作不变 d(π(o,ℓ),π(o',ℓ))≤δ_inv，且 affordance 区域 IoU(A_pred,A*)≥τ_aff
2. 定义 VLA 动作证书（VAC）：动作 conformal 集 ℙ(a*∈C_a(s))≥1-α_a、Lipschitz 平滑 ‖π(s₁)-π(s₂)‖≤L_π‖s₁-s₂‖、动作支撑 π(s)∈A_safe、动作块时序一致 ‖chunk_t[:H-1]-chunk_{t+1}[1:]‖≤δ_chunk
3. 定义闭环具身证书（CLC）：闭环系统 ISS 收缩 V(f(s,π))-V(s)≤-κV(s)+σ‖w‖（CEGIS 采样反例验证），具身形态偏差 ‖Δℳ‖≤δ_morph 下证书可传递，部署分布漂移用 ACI 维持覆盖
4. 构建具身-VLA 统一准入门（EVUC）：SRC-USC ∪ EGC ∪ VAC ∪ CLC 十证一体，Exec_v26 = Exec_v25 ∩ Fil_ground ∩ Fil_action ∩ Fil_loop ⊆ Exec_v25
5. 证明 VLA 幻觉接地 / 动作分布漂移 / 闭环失稳三重退化路径下，单调退化链仍保持

**与既有工作的差异**：v25 把「语义」当作地图属性（SMC），v26 把「语义」推进到「语义→动作」的因果接地；v25 把「协同」当作多机轨迹一致性（MCC），v26 把「具身」当作单机策略-身体-环境的闭环收缩。二者正交：SMC 管「世界是什么」，EGC/VAC/CLC 管「策略凭什么在世界里动」。

```python
# ============================================================
# IP-448 Embodied Grounding Certificate (EGC) — 具身接地证书
# ============================================================
@dataclass
class EmbodiedGroundingCertificate:
    """指令敏感性 + 视觉不变性 + affordance 对齐，双侧干预证书"""
    policy: 'VLAPolicy'
    tau_aff: float = 0.70
    delta_sens: float = 0.10        # 指令干预后动作最小变化
    delta_inv: float = 0.05         # 视觉干预后动作最大变化
    n_interventions: int = 64

    def verify_affordance_grounding(self, samples: list) -> bool:
        """IoU(A_aff^pred(o,ℓ), A_aff^gt) ≥ τ_aff"""
        for (o, ell, A_gt) in samples:
            A_pred = self.policy.affordance(o, ell)
            if iou(A_pred, A_gt) < self.tau_aff:
                return False
        return True

    def verify_instruction_sensitivity(self, samples: list) -> bool:
        """do(ℓ→ℓ')：任务相关干预必须改变动作 d_a(π(o,ℓ),π(o,ℓ')) ≥ δ_sens"""
        for (o, ell, ell_alt) in samples:
            a = self.policy.act(o, ell)
            a_alt = self.policy.act(o, ell_alt)
            if action_distance(a, a_alt) < self.delta_sens:
                return False
        return True

    def verify_visual_invariance(self, samples: list) -> bool:
        """do(o→o')：任务无关干预（纹理/光照/背景）动作必须不变 d_a ≤ δ_inv"""
        for (o, o_alt, ell) in samples:
            a = self.policy.act(o, ell)
            a_alt = self.policy.act(o_alt, ell)
            if action_distance(a, a_alt) > self.delta_inv:
                return False
        return True

    def verify_all(self, samples: list) -> bool:
        return (self.verify_affordance_grounding(samples) and
                self.verify_instruction_sensitivity(samples) and
                self.verify_visual_invariance(samples))


# ============================================================
# IP-449 VLA Action Certificate (VAC) — VLA 动作证书
# ============================================================
@dataclass
class VLAActionCertificate:
    """conformal 动作覆盖 + Lipschitz 平滑 + 安全支撑 + 动作块一致"""
    policy: 'VLAPolicy'
    calibrator: 'ActionConformalCalibrator'
    alpha_a: float = 0.05
    L_pi: float = 2.0
    delta_chunk: float = 0.02
    A_safe: 'SafeActionSet' = None

    def verify_action_coverage(self, states, expert_actions) -> bool:
        """ℙ(a* ∈ C_a(s)) ≥ 1-α_a：split-conformal 校准，覆盖专家动作"""
        if self.calibrator is None:
            return False
        sets = self.calibrator.predict(self.policy, states)
        for a_star, C_a in zip(expert_actions, sets):
            if not C_a.contains(a_star):
                return False
        return True

    def verify_lipschitz(self, pairs) -> bool:
        """‖π(s₁)-π(s₂)‖ ≤ L_π‖s₁-s₂‖：限制动作抖动与跳变"""
        for (s1, s2) in pairs:
            lhs = torch.norm(self.policy.act(s1, None) - self.policy.act(s2, None))
            rhs = self.L_pi * torch.norm(s1 - s2)
            if lhs > rhs:
                return False
        return True

    def verify_safety_support(self, states) -> bool:
        """π(s) ∈ A_safe：关节限位/力矩限/自碰撞禁止"""
        if self.A_safe is None:
            return False
        for s in states:
            if not self.A_safe.contains(self.policy.act(s, None)):
                return False
        return True

    def verify_chunk_consistency(self, states) -> bool:
        """相邻动作块重叠段一致：‖chunk_t[1:H]-chunk_{t+1}[:H-1]‖ ≤ δ_chunk"""
        for s in states:
            c_t = self.policy.predict_chunk(s)
            s_next = self.policy.rollout_one(s, c_t[0])
            c_next = self.policy.predict_chunk(s_next)
            if torch.norm(c_t[1:] - c_next[:-1]) > self.delta_chunk:
                return False
        return True

    def verify_all(self, states, expert_actions, pairs) -> bool:
        return (self.verify_action_coverage(states, expert_actions) and
                self.verify_lipschitz(pairs) and
                self.verify_safety_support(states) and
                self.verify_chunk_consistency(states))


# ============================================================
# IP-450 Closed-loop Embodiment Certificate (CLC) — 闭环具身证书
# ============================================================
@dataclass
class ClosedLoopEmbodimentCertificate:
    """ISS 收缩 + CEGIS 反例验证 + 形态偏差传递 + ACI 漂移覆盖"""
    V: 'NeuralLyapunov'
    kappa: float = 0.05
    sigma: float = 0.10
    delta_morph: float = 0.02
    morphology_sim: 'MorphologySpec' = None
    aci_state: 'ACIState' = None

    def verify_iss(self, closed_loop, domain, disturbances) -> bool:
        """V(f(s,π))-V(s) ≤ -κV(s)+σ‖w‖：采样 + 反例引导（CEGIS）"""
        for s in sample_domain(domain):
            for w in disturbances:
                s_next = closed_loop(s, w)
                decay = -self.kappa * self.V(s) + self.sigma * torch.norm(w)
                if self.V(s_next) - self.V(s) > decay:
                    # 找到反例：尝试修复或直接拒证
                    if not self.V.repair_with_counterexample(s, w):
                        return False
        return True

    def verify_morphology_transfer(self, real_morph) -> bool:
        """‖ℳ_real - ℳ_sim‖ ≤ δ_morph：形态偏差下证书可传递"""
        if self.morphology_sim is None or real_morph is None:
            return False
        return morphology_distance(self.morphology_sim, real_morph) <= self.delta_morph

    def verify_shift_coverage(self, residuals, scores) -> bool:
        """ACI：部署分布漂移下维持 ℙ(e_t ≤ q_t) ≥ 1-α_a"""
        if self.aci_state is None:
            return False
        return self.aci_state.update_and_check(residuals, scores)

    def verify_all(self, closed_loop, domain, disturbances,
                   real_morph, residuals, scores) -> bool:
        return (self.verify_iss(closed_loop, domain, disturbances) and
                self.verify_morphology_transfer(real_morph) and
                self.verify_shift_coverage(residuals, scores))


# ============================================================
# IP-451 EVUC 具身-VLA 统一准入门（十证）
# ============================================================
@dataclass
class EmbodiedVLAUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'  # v25 七证
    egc: EmbodiedGroundingCertificate
    vac: VLAActionCertificate
    clc: ClosedLoopEmbodimentCertificate

    def admits(self, plan, sensor_data, grounding_samples,
               expert_actions, state_pairs, closed_loop, domain,
               disturbances, real_morph, residuals, scores) -> bool:
        # 1. v25 七证（结构/力学/语义/重构/协同）
        if not self.src_usc.admits(plan, sensor_data,
                                   sensor_data.get('gt_entities'),
                                   sensor_data.get('queries'),
                                   sensor_data.get('retrieved')):
            return False
        # 2. 具身接地（为什么这么做）
        if not self.egc.verify_all(grounding_samples):
            return False
        # 3. 动作分布（能不能这么做）
        if not self.vac.verify_all(sensor_data['states'], expert_actions, state_pairs):
            return False
        # 4. 闭环具身（做完会不会失控）
        if not self.clc.verify_all(closed_loop, domain, disturbances,
                                   real_morph, residuals, scores):
            return False
        return True


# ============================================================
# 端到端流水线：在 v25 多机流水线上挂 VLA 证书链
# ============================================================
class EmbodiedVLAPipeline:
    def __init__(self, config: dict):
        self.evuc = EmbodiedVLAUnifiedCertificate(
            src_usc=config['src_usc'],
            egc=EmbodiedGroundingCertificate(
                policy=config['policy'],
                tau_aff=config['tau_aff'],
                delta_sens=config['delta_sens'],
                delta_inv=config['delta_inv'],
            ),
            vac=VLAActionCertificate(
                policy=config['policy'],
                calibrator=config['action_calibrator'],
                alpha_a=config['alpha_a'],
                L_pi=config['L_pi'],
                A_safe=config['A_safe'],
            ),
            clc=ClosedLoopEmbodimentCertificate(
                V=config['lyapunov'],
                kappa=config['kappa'],
                sigma=config['sigma'],
                delta_morph=config['delta_morph'],
                morphology_sim=config['morphology_sim'],
                aci_state=config['aci_state'],
            ),
        )
        self.ipam.register_module("egc", ["IP-448"],
            ["instruction_sensitivity", "visual_invariance", "affordance_grounding"])
        self.ipam.register_module("vac", ["IP-449"],
            ["conformal_action_set", "lipschitz_smoothness", "safe_support", "chunk_consistency"])
        self.ipam.register_module("clc", ["IP-450"],
            ["iss_contraction", "cegis_lyapunov", "morphology_transfer", "aci_shift_coverage"])
        self.ipam.register_module("evuc", ["IP-451"],
            ["decuple_certificate_gate", "ground_action_loop_monotonic_chain"])

    def step(self, vla_sensor_data: dict) -> tuple[bool, dict]:
        # 1. 复用 v25 七证流水线
        admitted_v25, info_v25 = self._src_usc_step(vla_sensor_data)
        if not admitted_v25:
            return False, {'stage': 'src_usc', 'details': info_v25}

        # 2. EGC：接地检验（指令/视觉干预样本由场景生成器给出）
        egc_ok = self.evuc.egc.verify_all(vla_sensor_data['grounding_samples'])
        if not egc_ok:
            return False, {'stage': 'egc', 'reason': 'grounding_reject'}

        # 3. VAC：动作覆盖/平滑/安全/块一致
        vac_ok = self.evuc.vac.verify_all(
            vla_sensor_data['states'],
            vla_sensor_data['expert_actions'],
            vla_sensor_data['state_pairs'],
        )
        if not vac_ok:
            return False, {'stage': 'vac', 'reason': 'action_reject'}

        # 4. CLC：闭环 ISS/形态/漂移
        clc_ok = self.evuc.clc.verify_all(
            vla_sensor_data['closed_loop'],
            vla_sensor_data['domain'],
            vla_sensor_data['disturbances'],
            vla_sensor_data['real_morph'],
            vla_sensor_data['residuals'],
            vla_sensor_data['scores'],
        )
        if not clc_ok:
            return False, {'stage': 'clc', 'reason': 'loop_reject'}

        return True, {'admitted': True, 'v25': info_v25,
                      'egc': True, 'vac': True, 'clc': True}

    def _src_usc_step(self, data):
        return self.src_usc_pipeline.step(data['multi_sensor_data'], data.get('cloud_update'))


# 辅助
def iou(A_pred, A_gt) -> float:
    inter = (A_pred & A_gt).sum().item()
    union = (A_pred | A_gt).sum().item()
    return inter / union if union > 0 else 0.0

def action_distance(a1, a2) -> float:
    """关节角加权 + 末端位姿测地线（与 v25 pose_distance 同构）"""
    return float(torch.norm(a1 - a2))

def morphology_distance(m1, m2) -> float:
    return float(torch.norm(m1.vector() - m2.vector()))
```

## 2. 复杂度分析（增量）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| EGC affordance 对齐 | O(N_g · P) 体素/点集 IoU | O(P) 区域 | N_g≤128, P=4096 |
| EGC 指令敏感性 | O(N_g · C_fwd) 前向 | O(1) | 64 组干预，单次 VLA 前向 |
| EGC 视觉不变性 | O(N_g · C_fwd) 前向 | O(1) | 同上 |
| VAC 动作覆盖 | O(N_s · d_a) 查集 | O(N_s · d_a) 动作集 | N_s≤256 |
| VAC Lipschitz | O(N_p · C_fwd) | O(1) | N_p≤64 状态对 |
| VAC 动作块一致 | O(N_s · H · d_a) | O(H · d_a) | H≤16 动作块 |
| CLC ISS 采样验证 | O(N_cegis · N_d · (C_fwd + C_V)) | O(N_cegis) 反例池 | N_cegis≤10³, N_d≤16 |
| CLC 形态传递 | O(d_m) | O(d_m) | d_m≤32 形态参数 |
| CLC ACI 覆盖 | O(N_r) 滑动更新 | O(N_r) 残差窗 | N_r≤1000 |
| EVUC 准入 | v25 关键路径 + O(N_g·C_fwd) | v25 + O(N_s·d_a) | 关键路径为 VLA 前向 |
| 端到端单步（增量） | +O(N_g·C_fwd + N_cegis·N_d·C_V) | +O(N_s·d_a) | C_fwd≈5–20ms（VLA） |

**实时性保证**：EGC/VAC 的干预样本与状态对可由场景生成器离线批量构造，在线只做查表与前向复用（同一批前向结果共享）；CLC 的 CEGIS 在部署前离线完成，在线只做形态偏差与 ACI 残差检查 O(N_r)。因此在线增量主要是 VLA 单次前向的常数倍，满足 10–30Hz 感知-动作环；若 VLA 前向 >33ms，则强制降级为「慢策略 + 快反射环」的双频架构。

## 3. 正确性论证（增量）

### 引理 13（EGC 的双侧因果接地保证）
**陈述**：`EGC.verify_all = True` ⟹ 策略 π 同时满足：(1) affordance 对齐 IoU≥τ_aff；(2) 任务相关指令干预敏感 d_a≥δ_sens；(3) 任务无关视觉干预不变 d_a≤δ_inv。三者联合排除「无视指令」与「死记场景」两类退化策略。

**证明**：
1. affordance 对齐由 `verify_affordance_grounding` 直接检查，保证动作意图锚定在可操作区域。
2. 若 π 忽略指令，则 do(ℓ→ℓ') 后动作不变，d_a<δ_sens，被 (2) 拒绝——排除「语言无关」策略。
3. 若 π 死记场景（spurious correlation），则 do(o→o')（纹理/光照/背景）后动作改变，d_a>δ_inv，被 (3) 拒绝——排除「视觉捷径」策略。
4. (2)(3) 构成双侧检验：只满足单侧仍可退化（如对一切输入输出常量满足不变性但不满足敏感性），故必须双侧同时成立。
∎

### 引理 14（VAC 的覆盖-平滑-安全-时序四重保证）
**陈述**：`VAC.verify_all = True` ⟹ (1) ℙ(a*∈C_a(s))≥1-α_a（边际覆盖）；(2) ‖π(s₁)-π(s₂)‖≤L_π‖s₁-s₂‖（平滑）；(3) π(s)∈A_safe（物理可行）；(4) 相邻动作块重叠段一致 ≤δ_chunk（无重规划跳变）。

**证明**：
1. split-conformal 的可交换性假设下，边际覆盖由分位数校准保证（Vovk et al. 2005）；α_a 为可调风险预算。
2. Lipschitz 条件限制动作对状态扰动的放大倍数，直接界定抖动上界 ‖δa‖≤L_π‖δs‖。
3. A_safe 由关节限位、力矩限、自碰撞几何构造为闭集，`contains` 为确定性谓词。
4. 动作块一致性把 chunked policy 的「边界跳变」纳入证书；否则再规划会在块边界产生不受 Lipschitz 约束的瞬时大动作。
∎

### 引理 15（CLC 的闭环 ISS 与形态传递）
**陈述**：若 `CLC.verify_all = True` 且神经 Lyapunov V 在采样域上满足 Lipschitz 正则，则闭环系统在扰动 w 下 ISS，跟踪误差满足 limsup‖e_t‖ ≤ σ·sup‖w‖/κ；且在 ‖ℳ_real-ℳ_sim‖≤δ_morph 时证书可传递（带 O(δ_morph) 的裕度收缩）。

**证明**：
1. ISS 不等式 V(f(s,π))-V(s) ≤ -κV(s)+σ‖w‖ 由 CEGIS 采样 + 反例修复保证；V 的 Lipschitz 正则把采样间的违例上界化为 O(采样分辨率)，构成采样级可靠证书。
2. 对 ISS 不等式做标准比较引理（comparison lemma）迭代，得 V(s_t) ≤ (1-κ)^t V(s_0) + σ/(κ)·sup‖w‖，进而误差有界。
3. 形态偏差经机器人动力学的 Lipschitz 常数传播，证书裕度按 δ_morph 收缩；若收缩后仍满足 κ'>0，则传递成立。
4. ACI 在线更新分位数，使部署漂移下经验覆盖回落到 1-α_a（Gibbs & Candès 2021）。
∎

### 引理 16（十位一体单调退化链）
**陈述**：任意单点/组合失效下，`Exec_v26 ⊆ Exec_v25 ⊆ ... ⊆ Exec_v18` 恒成立。

**证明**：在引理 12 基础上增加三条退化路径：
- 接地失效（幻觉接地/捷径学习）→ `EGC.verify_all=false` → EVUC 拒证 → 退回 `Exec_v25`（保留七证，但 VLA 策略降级为「显式规划器 + 视觉伺服」，失去语言泛化）。
- 动作分布漂移（OOD 动作越界/块跳变）→ `VAC.verify_all=false` → EVUC 拒证 → 退回 `Exec_v25`（VLA 降级为「保守动作裁剪 + 专家接管」，保留安全但不保证任务泛化）。
- 闭环失稳（形态偏差超限/扰动发散）→ `CLC.verify_all=false` → EVUC 拒证 → 退回 `Exec_v25`（切换固定增益阻抗控制，冻结 VLA 高层，保留单机/多机安全）。
- 组合失效：取交集，单调性由集合交的单调性保持。
∎

### 定理（EVUC 十证准入门：物理-合规-结构-语义-重构-协同-接地-动作-闭环完备性）
**陈述**：对任意策略-计划对 (π, Π)，`EVUC.admits(π, Π)=True` ⟺ 同时满足 v25 的十项条件与：(11) 具身接地三重达标（affordance/敏感性/不变性），(12) 动作四重达标（覆盖/平滑/安全/块一致），(13) 闭环三重达标（ISS/形态传递/漂移覆盖）。

**证明**：由 `EVUC.admits` 的连言结构与引理 1–3、5–7、9–11、13–15 直接可得。必要性：任一条件缺失即拒证，对应十类风险之一未被缓解；充分性：全条件满足时，由引理 4、8、12、16 保证执行集单调链与统计覆盖，构成从单机物理、结构力学、语义建图、重构协同到 VLA 接地-动作-闭环的完整闭环。
∎
