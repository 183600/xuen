# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；本轮灵感：「灵巧操作」×「人机交互」）

> R69 让闭环第一次学会了「问」：把 epistemic 歧义交给看、问、触，用 VoI 决定值不值得问。但它有一个未言明的前提——**不确定性是可以被"说出来"的**。灵巧操作恰好击穿这个前提：人手知道怎么拧开一个太紧的瓶盖、怎么在指尖把钥匙转正、怎么在打滑前一瞬加力，但人**说不出**接触点、法向力、粘滑判据与切换时刻。这是 Polanyi 意义上的 **tacit knowledge（默会知识）**：可示而不可言。R69 的 `g_ask` 对这类不确定性几乎零信息，却会得到一个「听起来很合理」的答案，然后把它当作证据——**问不到，比不问更危险**。
>
> 灵巧操作还击穿了 R69 的另外两个隐含假设：
> - **平滑性**：R69 的流匹配是单一连续速度场；而接触丰富操作是**混杂动力学**——接触建立/断开、粘滞/滑移、抓稳/掉落，轨迹在事件处近似连续而接触模式突变。用轨迹空间聚类会把「任务意图歧义」与「接触模式歧义」混为一谈，且 R69 的流似然第二意见会在接触事件处误报。
> - **信息动作可逆**：R69 默认 gaze/probe/ask 低风险、可撤回；但灵巧操作里「摸一下」可能推倒、捏碎、掉落。**一次不可逆的物理探询不是询问，而是承诺。**
>
> 人机交互补上最后一块：人不是只读 oracle，而是**物理共同持有者**。R69 的交互成本是一个标量 `c(g)`；真实共享操作里，还有人的**舒适包络、信任、可读性、接管延迟与责任归属**。当机器人「边做边问」时，人必须能看懂它在干什么、知道何时该接手、并且**没有一刻是双方都以为对方在负责**。
>
> 核心命题：**把 epistemic 按「可获取性（answerability）」而非「可约性」重新分类：可问的 intent 交给语言，可示的 skill 交给示范/物理引导，不可问也不可示的 embodiment 只能在线自辨识；每一类绑定唯一合法 oracle 通道，信息动作必须可逆，权限转移必须显式握手。** 命名 **TACIT-RAS**（Tacit-contact Aware Cooperative Interactive Transfer）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**有些事根本问不出来，我能不能用一次可撤回的接触、一次示范、一次交接去学会它，并且让人始终知道现在是谁在负责**」。

## 0. 直觉与动机

**灵感 1（灵巧操作 → 接触是第三种不确定性，也是第三种证据）**
直觉：R69 把 U 拆成 aleatoric 与 epistemic，默认 epistemic 都能被观测/回答消解。但灵巧操作里至少有三类本质不同的「不知道」：
1. **意图不知道**（要拧开还是拧紧？要不要保留原包装？）——人可以回答；
2. **接触模式不知道**（现在是粘住还是微滑？指尖还是指腹承力？）——人往往说不清，但**摸一下、示一次**就能传递；
3. **自身具身不知道**（自己的摩擦系数、连杆柔顺、工具磨损、负载偏置）——**问人没用、看人示范也没用**，只能靠自己激励/辨识。
把这三类都塞进 R69 的单一 U_epi，会导致「用提问去解决摩擦参数」「用示范去解决任务意图」这类**通道错配**；更糟的是，错配通道会返回一个高置信但零信息的答案，污染证据链。

**灵感 2（人机交互 → 人不是 oracle，是共同持有者）**
直觉：R69 的交互模型是「机器人问，人答」。但灵巧操作常是**共享物理权限**：人扶着物体、机器人拧；机器人托着、人调整；或机器人把手张开说「你来」。这时「问」不只是语言，而是一组**物理对话动作**——保持（HOLD）、让权（YIELD）、递交（OFFER）、轻推（NUDGE）、预告（SIGNAL）。每一次权限变化都必须可被对方察觉、可被拒绝、可被追责；否则会出现 HRI 里最危险的失效：**权限震荡与责任扩散**——人以为机器人在控，机器人以为人接管了，中间 200ms 没人负责。

**灵感 3（混杂接触 → 流匹配需要"换挡"，而不是更多采样）**
直觉：R69 用 K 条平滑轨迹聚类。但在接触事件附近，两个接触模式（例如「先滑后抓」与「先抓后滑」）在轨迹空间可能几乎重合，直到某一时刻才分叉；K 再多也分不开，因为**差异不在连续轨迹里，而在离散接触调度里**。正确的表示是 `η = (ξ, σ)`：连续动作块 `ξ` + 离散接触调度 `σ`（何时建立/断开哪个接触、何时粘/滑）。流匹配应当在**每个接触模式内部**做连续生成，在模式之间用事件头切换。否则 R69 的「模态」是任务歧义与接触歧义的混合物，既不可解释也不可认证。

**灵感 4（可逆性 → 信息动作与承诺动作必须分开）**
直觉：R69 的探针默认安全，因为「探」只是获取信息。但真实接触里，探头可能把直立物体推倒、把软物体压坏、把已对准的零件碰偏。信息论上 VoI 为正，物理上却已越过不可逆边界。因此本轮引入**可逆性裕度 R(g)**：只有能保证最坏结果仍落在可恢复集内的动作，才配叫「信息动作」；否则它是承诺动作，必须走独立的授权/安全通道。**不能撤回的实验不叫实验。**

**灵感 5（示范证据 → tacit 知识可示，但示范不是 ground truth）**
直觉：对说不出的技能，人类最自然的传递方式是**示范与物理引导**。但示范有两个偏差：其一，人的示范是**其具身**下的最优，不是机器人具身下的可行解（embodiment gap）；其二，人可能示范错、示范的是理想化动作、或在被观察时改变策略。因此示范必须被当作**有偏、需折扣的证据**：用迁移有效性 `TV(D)` 给示范加权，并且**单次示范不得单独认证不可逆接触策略**——这与 R69 的「单次交互不得定案」是同一条纪律的物理版。

**灵感 6（理论姿态 → 新层必须是旧层的严格泛化）**
直觉：R70 不应推翻 R69。当接触模式只有一个（M=1）、示范通道关闭、权限始终在机器人侧时，TACIT-RAS 必须逐指令退化为 FLUID-RAS；再关闭交互即退化为 R68。这样每加一层，安全侧只增不减，效率侧只在「可逆 + 通道匹配 + 证据一致」时获得 bonus。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（TACIT-RAS 总览）** TACIT-RAS = (HCF, ACU, OCM, PQG, PDL, LGC, DTE, CCA, RAS-WM‡)。五不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i、R69 定义 293-i）；
(ii) **信息动作可逆性**：任何被当作信息动作的 `g` 必须满足 `R(g) ≥ ε_rev`，否则降级为承诺动作，需显式授权；
(iii) **通道匹配纪律**：每类不确定性只能由可问性 `α(u, ch) ≥ α_min` 的合法通道消解，跨通道答案按 `α` 折扣，不得以语言回答冒充接触知识；
(iv) **权限不静默转移**：共享权限的任何变化必须经过两阶段握手；超时未确认则退回安全 HOLD；
(v) **证据纪律†**：单次语言回答、单次示范或单次触觉探询均不得单独认证不可逆接触策略，需正交证据一致或迁移有效性达标。

**定义 311（混杂接触动作）** 离散接触模式 `m ∈ ℳ`（如 free / contact / stick / slip / grasp / drop），接触调度 `σ = {(τ_i, m_i)}`（事件时刻与模式），连续动作块 `ξ = (a, g)`（R69 定义 294）。混杂轨迹 `η = (ξ, σ) ∈ ℋ = 𝒜_+ × Σ`。接触模式是**离散潜变量**，不是轨迹聚类的结果。

**定义 312（混杂接触流 HCF）** 分解生成
`p_θ(η | o) = p_φ(σ | o) · ∏_k p_θ(a_{[τ_k, τ_{k+1})} | m_k, o)`，
其中模式转移头 `p_φ(σ|o)` 预测事件序列，模式内流 `p_θ(a|m,o)` 由 rectified flow 给出（`x_s=(1−s)x_0+s x_1`，`N_step=2`，条件编码复用 R68 trunk 的 `z_t`）。训练目标
`L_HCF = L_FM(within-mode) + λ_ev·L_event(σ) + λ_mode·CE(m, m̂)`。
模式内似然仍用瞬时变分 `log p_θ(a|m,o)=log p_0(x_0) − ∫_0^1 ∇·v_θ(x_s,s|m,o) ds`；**模式条件化**是修正 R69 在接触事件处误报的关键。

**定义 313（四分解不确定性）** 给定 `η` 的后验样本：
- `U_ale = Σ_k ŵ_k tr(Σ_k)`：模式内连续噪声（不可约，进 λ floor）；
- `U_intent = H(Z | o)`：任务意图/偏好熵（epistemic，**可问**）；
- `U_contact = H(σ | o, Z)`：接触调度/模式熵（epistemic，**可示/可触**）；
- `U_emb = tr(Cov(θ_emb | o))`：摩擦、柔顺、工具磨损、负载偏置的后验方差（**结构性 epistemic**，任何外部 oracle 都不能直接消除，只能在线辨识）。
四者语义不同，**不求和**，分别进入不同通道；R69 的 `U_epi` 是 `U_intent + U_contact` 在「无接触模式、无具身参数」边界上的退化。

**定义 314（可问性图 ACU）** 对不确定性分量 `u` 与通道 `ch ∈ {ask, demo, probe, self}`，定义可问性
`α(u, ch) = I(u ; Y_ch) / H(u) ∈ [0,1]`，
即在通道观测 `Y_ch` 下可解释的熵比例。经验估计用留出集上的条件熵：`α̂ = 1 − E[H(u|Y_ch)]/H(u)`。合法性集合 `Ch(u) = {ch : α(u,ch) ≥ α_min}`。设计事实（本轮建模假设）：`α(U_intent, ask)` 高而 `α(U_intent, demo)` 仅部分；`α(U_contact, ask) ≈ 0` 而 `α(U_contact, probe/demo)` 高；`α(U_emb, ask)=α(U_emb, demo)=0`，仅 `self` 非零。

**定义 315（有效 VoI 与通道匹配 OCM）** 对候选信息动作 `g`，其所属通道 `ch(g)`，有效信息增益
`VoI_eff(g) = α(û, ch(g)) · [H(û|o) − E_{y~p(·|g,o)} H(û|o,y)]`，
其中 `û` 是 `g` 声称要消解的不确定性分量。选择
`g* = argmax_g [VoI_eff(g) − c_phys(g) − c_social(g) − λ_irr·(1−R(g))]`
s.t. `ch(g) ∈ Ch(û)`、`R(g) ≥ ε_rev`（除非显式标记为承诺）、`L(g) ≥ ℓ_min`（或附带 SIGNAL）、预算未超。若最优值 ≤ 0：不查询；优先请求**示范/交接**，否则走 R69→R68 兜底。

**定义 316（可逆性裕度与信息-承诺分离）** 设执行 `g` 后最坏可达状态集合为 `𝒮_g`，可恢复安全集为 `𝒮_rec`。定义
`R(g) = min_{s∈𝒮_g} dist(s, 𝒮_rec)`。
`R(g) < ε_rev` ⇒ `g` 是**承诺动作**（commitment），不得计入信息动作；若它是消歧的唯一途径，必须经人类授权/监督，或改为更弱的可逆探询。承诺动作的风险不计入 VoI，而计入安全包络。

**定义 317（物理对话动作 PDL）** `g_pdl ∈ {HOLD, YIELD, OFFER, NUDGE, SIGNAL}`，每个动作携带阻抗/力/时长参数。语义：HOLD=维持当前抓持并承担稳定责任；YIELD=降低阻抗、把局部权限让给人；OFFER=把物体呈现到人的可达域并等待接管；NUDGE=沿某方向施加有界引导力；SIGNAL=在动作前显式预告（注视/语音/力脉冲），用于提升可读性。PDL 动作与任务动作拼进同一动作块，但**权限语义单独认证**。

**定义 318（权限路由与握手 URA/AH）** 设接触子空间 `𝒲` 上的权限变量 `α_t ∈ [0,1]`（1=机器人全权，0=人类全权）。按不确定性路由：
`α*_t = argmax_α [E[utility | α, U_intent, U_contact, U_emb] − ρ·H(α)]`，
其中 `H(α)` 惩罚权限模糊。任何 `|α_{t+1} − α_t| > δ_α` 的转移必须走两阶段握手：`PROPOSE(α') → ACK(human/robot) within τ_h`；超时或拒绝 ⇒ 保持上一安全态（默认 HOLD）。握手日志 `authority_log_hash` 进入证书，用于责任归属审计。

**定义 319（可读性约束 LGC）** 可读性 `L(g) = I(Z_true ; Ẑ_human | obs(g))`，即人通过观察 `g` 对机器人意图推断的互信息（或等价的预测动作与真实意图一致性）。约束：`L(g) ≥ ℓ_min`，或 `g` 前必须插入 `SIGNAL` 使 `L(g ⊕ SIGNAL) ≥ ℓ_min`。目的是防止「为了消歧而做出人看不懂的探索动作」，从而诱发人的错误干预。定义**惊异预算**：单位时间内可接受的非预期动作 ≤ `s_max`。

**定义 320（示范证据与迁移有效性 DTE）** 示范 `D = {s_t, a_t^h}` 来自人类具身 `E_h`。定义迁移有效性
`TV(D) = E_{s~ρ_D}[ D_KL(π_h(·|s) ‖ π_θ(·|s)) ]`（或训练一个具身判别器估计），证据权重 `w_D = exp(−κ·TV(D))`。示范似然按 `w_D` 折扣。约束：`TV(D) > τ_TV` ⇒ 示范不得作为不可逆接触策略的认证证据，只能作为先验/初始化，必须经**协同验证**（在可逆包络内复现并用触觉残差检验）。

**定义 321（接触感知标定 CCA）** 把 R68/R69 的标定残差拆成两部分：`r_res = r_nuis + r_mode`。`r_nuis` 是摩擦/软度/偏置等**可被标定吸收**的缓变项；`r_mode` 是接触模式误判（如实际滑移被读成粘滞）。标定只能吸收 `r_nuis`，不能吸收 `r_mode`。定义接触模式校准误差 `ECE_mode = E[|q_φ(m|o) − 1[m=m_true]|]`。

**定义 322（模式条件异常分与接触模式幻觉）** 模式条件似然分 `a_score(m) = −log p_θ(a_obs | m, o)`；模式条件对偶差 `Δa_mode = min_m |a_score(m|o) − a_score(m|o_cal)|`。**接触模式幻觉**判据：`r_res` 低（标定说"没问题"）、`Δa_mode` 高（某个模式下的行为密度异常）、且模式后验 `q_φ(m|o)` 与触觉导出的滑移/力率证据 `q_tac(m)` 的 KL 散度 `D_KL(q_φ ‖ q_tac)` 高。三者联合才判为「模式级缓变故障」，避免 R69 在接触事件处的单通道误报。

**定义 323（结构性 epistemic 与自适应包络 SEE）** `θ_emb`（摩擦系数、阻尼、工具磨损、负载偏置）不可被问/示消除，只能由在线激励辨识。维护后验 `p(θ_emb|o)` 与方差 `U_emb`；控制律使用鲁棒阻抗 `K_t = K_0/(1+γ U_emb)`，安全包络随 `U_emb` 单调扩大（速度上限、力上限、抓持裕度）。**U_emb 不进入交互预算，也不允许被语言答案"清零"**；它只通过自身激励与观测降低。

**定义 324（证据纪律†）** 证据源 `ℰ = {y_ask, D_demo, τ_tac, s_self}`，要求：
(a) 任何不可逆接触策略的认证需 ≥2 个正交源一致，或单源但 `TV/ECE` 达标且 `R(g) ≥ ε_rev`；
(b) 语言回答对接触/具身不确定性的权重按 `α` 折扣，`α_ask(U_contact) < α_min` 时**不得计入**；
(c) 示范证据按 `w_D` 折扣，单次示范不得单独定案；
(d) 同一人类在同一会话中的重复回答不构成独立源。
满足则 `U` 可标为已消解，否则保持未消解并走兜底。

**定义 325（证书 J_TACIT）** `J_TACIT = (J_FLUID, answerability_map_hash, reversibility_min, legibility_min, authority_log_hash, demo_transfer_validity, contact_mode_ece, tacit_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ R_min ≥ ε_rev ∧ ECE_mode ≤ τ_mode ∧ 证据纪律† 满足 ∧ 权限握手完整`。

**定义 326（两级退避†）** 令 `U_unres = U_intent + U_contact` 中未消解部分。若 `U_unres` 在预算内由合法通道消解：`λ = λ_floor(U_ale + U_emb)`（**resolution bonus**，比 R68/R69 更不保守但不降安全）；若未消解/超时/通道不合法/被投毒：`λ = λ_floor(U_ale + U_emb + U_unres)`。`U_emb` 始终计入保守项，任何外部回答都不能把它移出。⇒ R69 是「无接触模式、示范通道关闭、权限恒在机器人侧」的边界；R68 是再关闭一切交互的边界。

## 2. 关键算法骨架

```python
# IP-264 HCF：混杂接触流（模式条件化的流匹配）
class HybridContactFlow:
    def __init__(self, trunk, v_within, event_head, mode_head, N_step=2):
        self.trunk, self.v = trunk, v_within       # v(x_s, s, m, z)
        self.event, self.mode = event_head, mode_head
    def sample(self, o_t, K, N_step=2):
        z = self.trunk(o_t)
        sigmas = self.event.sample_schedules(z, K)          # 离散接触调度
        out = []
        for sigma in sigmas:
            for m in sigma.modes:                            # 模式内连续流
                xs = randn(1, D)
                for i in range(N_step):
                    xs = xs + (1.0/N_step) * self.v(xs, i/N_step, m, z)
                out.append((xs, sigma))
        return out                                           # η = (ξ, σ)

# IP-265/266 ACU+OCM：可问性折扣后的通道匹配（不对 tacit 问语言）
def match_channel(u_type, candidates, acu, budget):
    best = None
    for g in candidates:
        ch = channel_of(g)
        if acu.alpha(u_type, ch) < ALPHA_MIN:      continue   # 通道不合法
        if not budget.allow(g):                    continue
        if not pqg.reversible(g):                  continue   # 见 IP-267
        if not lgc.legible_or_signaled(g):         continue   # 见 IP-269
        voi = acu.alpha(u_type, ch) * vo_raw(g, u_type)
        score = voi - cost_phys(g) - cost_social(g)
        if best is None or score > best.score:     best = (g, score)
    return best if best and best.score > 0 else None

# IP-267 PQG：可逆性门（信息动作 vs 承诺动作）
def reversible(g):
    worst = worst_case_reachable(g)                 # 最坏结果集合
    R = min(dist(s, SAFE_RECOVERABLE) for s in worst)
    return R >= EPS_REV, R

# IP-268 PDL+URA：物理对话与权限握手（无静默转移）
def authority_step(alpha_robot, target, human_state, deadline):
    if abs(target - alpha_robot) <= DELTA_ALPHA:
        return alpha_robot
    propose(target)                                 # PROPOSE
    if wait_ack(human_state, timeout=deadline):     # ACK 或显式拒绝
        log_authority(alpha_robot, target)
        return target
    return safe_hold(alpha_robot)                   # 超时 → HOLD，不静默转移

# IP-270 DTE：示范证据折扣
def demo_weight(policy, demo, human_policy):
    tv = expected_kl(policy, human_policy, demo.states)   # 具身/策略差异
    w  = exp(-KAPPA * tv)
    return w, tv

# IP-271/272 CCA+SEE：接触模式校准与结构 epistemic
def contact_anomaly(hcf, eta, o, o_cal, q_tac):
    per_mode = [abs(-hcf.loglik(eta, m, o) + hcf.loglik(eta, m, o_cal))
                for m in hcf.modes]
    illusion = (min(per_mode) > TAU_MODE) and \
               (kl(hcf.mode_posterior(o), q_tac) > TAU_KL)
    return min(per_mode), illusion
def robust_impedance(K0, U_emb):  return K0 / (1.0 + GAMMA * U_emb)

# IP-275 主闭环（继承 FLUID/R68，仅替换不确定性层）
def TACIT_RAS_round(M, obs):
    z, o = M.mtm.forward(obs)
    c, U_cal, thr = M.cof.step(...)                       # R68 标定
    # 1) 混杂接触采样：先模式，后模式内连续流
    eta = M.hcf.sample(o, K=4 if M.mode_head(z) > TAU_MODE else 1)
    U_ale, U_int, U_con, U_emb = M.acu.decompose(eta, o)  # 定义 313
    # 2) 通道匹配：intent→ask，contact→probe/demo，emb→self（禁止提问）

    g_c = M.ocm.match(U_con,   channels=['probe','demo'],      o)
    g   = M.pqg.arbitrate([g_i, g_c])                     # 可逆性/预算/可读性

    alpha = M.ura.route(U_int, U_con, U_emb, M.human.state)
    if M.pdl.wants_demo(g) and M.human.available:
        g = M.pdl.request_demo()                           # 不越过可逆性门
    alpha = M.ura.handshake(alpha, M.human.state, M.tau_h)
    # 4) 执行 + 证据纪律（语言/示范/触觉按 α 与 w_D 加权）

    U_con_after = M.acu.update(U_con, ev, discipline='k_orthogonal')

    a_m, illusion = M.cca.contact_anomaly(M.hcf, M.last_eta, o, o_cal, M.q_tac)
    K_imp = M.see.robust_impedance(K0, U_emb)
    # 6) 两级退避（U_emb 永远在保守项里）
    U_unres = U_con_after + (U_int if ev is None else 0.0)

    A = M.ach.propose(x_prime, H=M.vista.H)

    M.vqa_i.submit_async(g, ev, U_int, U_con, U_emb, alpha, a_m)
```

## 3. 推导

**引理 19（可问性缺口）** 设 tacit 分量 `u`（如接触策略）的可问性 `α_ask(u) = α < 1`。即便问答过程无噪声，提问后的残余熵下界为 `(1−α)·H(u)`；因此无论问多少次，`U_contact` 都不能被语言通道降到 `(1−α)H(u)` 以下。系：当 `α_ask(U_contact) < α_min` 时，语言回答的**有效** VoI ≈ 0，却可能因语言模型的流畅性被误当作高置信证据——通道错配比不交互更危险。

**引理 20（混杂模式的可辨识性）** 若两个接触模式 `m_1, m_2` 在事件时刻 `τ` 之前的连续轨迹分布相同（`p(a|m_1,o)=p(a|m_2,o)` on `t<τ`），则任何仅依赖轨迹空间聚类的模态分解（R69 定义 296）在该段上的互信息 `I(M; clusters) = 0`；而 HCF 的事件头以 `σ` 为显式变量，只要事件时刻可观测或可由力率/滑移线索估计，则 `I(σ; o) > 0`。系：**差异不在轨迹里，在调度里**；提高 K 不能替代接触模式表示。

**引理 21（可逆查询的安全增益）** 若 `R(g) ≥ ε_rev`，则执行 `g` 后最坏状态仍在可恢复集内，故信息增益可在不降低安全包络的前提下获得，`risk(g) ≤ risk(HOLD)`；若 `R(g) < ε_rev`，则存在正概率进入不可恢复集，`E[risk(g)] > risk(HOLD)`，其超出部分不被 `VoI_eff` 抵消。系：**信息-承诺分离是 VoI 可加性的前提**；不可逆探询必须先获得授权。

**引理 22（示范迁移折扣）** 设人类策略 `π_h` 与机器人策略 `π_θ` 在示范状态分布上的 KL 为 `TV(D)`，则直接行为克隆的期望性能差满足 `J(π_h) − J(π_θ) ≤ L_J·TV(D) + ε_emb`（`L_J` 为性能对策略扰动的 Lipschitz 常数）。故 `w_D = exp(−κ·TV)` 的折扣是必要的；`TV > τ_TV` 时示范不足以认证不可逆策略。

**定理 18（TACIT 严格包含 FLUID 与 R68）** 在 A99–A101 下，TACIT 的期望风险 ≤ FLUID ≤ R68；当 `ℳ={1}`（无接触模式）、`α_demo=0`、权限恒在机器人侧时，TACIT 逐指令退化为 FLUID；当进一步 `VoI_eff ≤ 成本` 时逐指令退化为 R68。安全侧只增不减，效率侧仅在「通道合法 + 可逆 + 证据一致」时获得 resolution bonus。

**定理 19（共享权限的安全性与无责任真空）** 若所有 `|Δα|>δ_α` 的权限转移都经两阶段握手且超时回退到 HOLD，则任意时刻至少一方持有明确权限（无真空）；在人类反应延迟 `≤ τ_h` 时，权限震荡次数有界；执行动作同时满足双方安全包络交集，物理风险 ≤ `min(ε_h, ε_r) + ε_int`。

**定理 20（接触模式幻觉的判别性）** 若标定只吸收 `r_nuis` 而不吸收 `r_mode`（定义 321），则 `(r_res↓, Δa_mode↑, D_KL(q_φ‖q_tac)↑)` 对模式级缓变故障的判别 AUC 严格高于 R69 的单通道 `(r_res↓, Δa↑)`；代价是需触觉率证据，故在无触觉时须退回 R69 判据并降低置信。

## 6. 本轮最大风险

**一句话**：TACIT-RAS 的全部收益押在两个前提上——**「tacit 技能可以经示范/物理引导跨具身迁移」**与**「共享权限始终被双方正确理解」**；若二者之一不成立，系统会把人**具身特定**的接触技巧固化成机器人自信却错误的策略，而权限握手又只保证「有人负责」、不保证「负责的人知道自己在负责什么」——**最终风险不是学不会，而是学错之后，人类和机器人都以为对方在兜底**。

**次级风险与缓解**：
1. **示范本身不安全/不可行**（人示范的是其具身最优）→ DTE 折扣 + 可逆包络内协同验证 + E304/E315；
2. **接触模式不可辨识**（事件被触觉噪声淹没）→ 保持未消解、走 R69 单通道判据并降低置信 + E308；
3. **权限震荡/责任扩散** → 两阶段握手 + 超时 HOLD + authority_log 审计 + E306；
4. **可逆性估计过于乐观**（最坏可达集被低估）→ 保守内层近似 + 人类授权门 + E305；
5. **语言/示范通道混用导致证据污染** → ACU 折扣 + 证据纪律† + E303；
6. **结构 epistemic 被误当可问** → U_emb 永不进入交互预算，只允许在线辨识 + 鲁棒阻抗 + E309。

**定义 311–312（混杂动作与 HCF）** `η=(ξ,σ)`，`m∈ℳ` 为离散接触模式；`p(η|o)=p_φ(σ|o)∏_k p_θ(a|[m_k],o)`；模式内 rectified flow `N_step=2`，事件头预测 `σ`，训练 `L_HCF=L_FM+λ_ev L_event+λ_mode CE`。模式条件化修正在接触事件处的似然误报。

**定义 313（四分解）** `U_ale=Σŵ trΣ`；`U_intent=H(Z|o)`；`U_contact=H(σ|o,Z)`；`U_emb=tr(Cov(θ_emb|o))`。四者不求和、分通道处置；R69 的 `U_epi` 是 `U_intent+U_contact` 在无接触模式、无具身参数边界上的退化。

**定义 314–315（ACU/OCM）** `α(u,ch)=I(u;Y_ch)/H(u)∈[0,1]`；`Ch(u)={ch:α≥α_min}`；`VoI_eff(g)=α(û,ch(g))·[H(û|o)−E H(û|o,y)]`；`g*=argmax[VoI_eff−c_phys−c_social−λ_irr(1−R)]`，s.t. 通道合法、可逆、可读、预算。最优值 ≤0 则不查询，优先请求示范/交接，否则 R69→R68 兜底。

**定义 316（可逆性门 PQG）** `R(g)=min_{s∈𝒮_g} dist(s,𝒮_rec)`；`R<ε_rev` ⇒ 承诺动作，不计入信息动作；不可逆探询需人类授权或改弱探询。引理 21：可逆查询不降低安全包络，不可逆查询的风险不能被 VoI 抵消。

**定义 317–318（PDL/URA）** `g_pdl∈{HOLD,YIELD,OFFER,NUDGE,SIGNAL}`；权限 `α_t` 按不确定性路由 `α*=argmax_α[E[utility|α,U]−ρH(α)]`；`|Δα|>δ_α` 必须 `PROPOSE→ACK within τ_h`，超时/拒绝 ⇒ HOLD；日志入证书。

**定义 319（LGC 可读性）** `L(g)=I(Z_true;Ẑ_human|obs(g))`；要求 `L≥ℓ_min` 或插入 SIGNAL；惊异预算 `s_max` 限制非预期探索。

**定义 320（DTE 示范证据）** `TV(D)=E_{s~ρ_D} D_KL(π_h‖π_θ)`，`w_D=e^{−κTV}`；`TV>τ_TV` ⇒ 示范只作先验，需在可逆包络内协同验证；单次示范不得认证不可逆策略。

**定义 321–322（CCA 与模式幻觉）** `r_res=r_nuis+r_mode`；标定只吸收 `r_nuis`；`ECE_mode=E|q_φ(m|o)−1[m=m_true]|`；模式幻觉判据：`r_res↓ ∧ Δa_mode↑ ∧ D_KL(q_φ‖q_tac)↑`。避免 R69 单通道在接触事件处误报。

**定义 323（SEE 结构 epistemic）** `θ_emb`（摩擦/阻尼/磨损/负载）不可问不可示；维护后验与 `U_emb`，`K_t=K_0/(1+γU_emb)`，安全包络随 `U_emb` 单调扩大；`U_emb` 永不进入交互预算，也不允许被语言答案清零。

**定义 324（证据纪律†）** 四源 `{y_ask,D_demo,τ_tac,s_self}`；不可逆策略认证需 ≥2 正交源一致，或单源但 `TV/ECE` 达标且 `R≥ε_rev`；`α_ask(U_contact)<α_min` 时语言回答不得计入；示范按 `w_D` 折扣；同一人重复回答不独立。

**定义 325–326（证书与两级退避†）** `J_TACIT=(J_FLUID, answerability_map_hash, reversibility_min, legibility_min, authority_log_hash, demo_transfer_validity, contact_mode_ece)`；`U_unres=U_intent+U_contact` 未消解部分；消解成功 `λ=λ_floor(U_ale+U_emb)`（resolution bonus），失败/超时/投毒 `λ=λ_floor(U_ale+U_emb+U_unres)`；`U_emb` 始终保守。

## 3. 关键算法伪代码

```python
# IP-264 HCF：混杂接触流（模式条件化）
class HybridContactFlow:
    def sample(self, o_t, K, N_step=2):
        z = self.trunk(o_t)
        out = []
        for sigma in self.event.sample_schedules(z, K):        # 离散接触调度
            for m in sigma.modes:
                xs = randn(1, D)
                for i in range(N_step):
                    xs = xs + (1.0/N_step) * self.v(xs, i/N_step, m, z)
                out.append((xs, sigma))                        # η=(ξ,σ)
        return out

# IP-265/266 ACU+OCM：可问性折扣后的通道匹配
def match_channel(u_type, candidates, acu, budget):
    best = None
    for g in candidates:
        ch = channel_of(g)
        if acu.alpha(u_type, ch) < ALPHA_MIN:   continue   # tacit 不问语言
        if not budget.allow(g):                 continue
        if not pqg.reversible(g):               continue
        if not lgc.legible_or_signaled(g):      continue
        score = acu.alpha(u_type, ch) * vo_raw(g, u_type) \
                - cost_phys(g) - cost_social(g)
        if best is None or score > best.score:  best = (g, score)
    return best if best and best.score > 0 else None

# IP-267 PQG：信息动作 vs 承诺动作
def reversible(g):
    R = min(dist(s, SAFE_RECOVERABLE) for s in worst_case_reachable(g))
    return R >= EPS_REV, R

# IP-268 PDL+URA：物理对话与权限握手（无静默转移）
def authority_step(alpha_robot, target, human_state, deadline):
    if abs(target - alpha_robot) <= DELTA_ALPHA: return alpha_robot
    propose(target)
    if wait_ack(human_state, timeout=deadline):
        log_authority(alpha_robot, target); return target
    return safe_hold(alpha_robot)              # 超时 → HOLD

# IP-270 DTE：示范证据折扣
def demo_weight(policy, demo, human_policy):
    tv = expected_kl(policy, human_policy, demo.states)
    return exp(-KAPPA * tv), tv

# IP-271/272 CCA+SEE：模式级异常与鲁棒阻抗
def contact_anomaly(hcf, eta, o, o_cal, q_tac):
    per_mode = [abs(-hcf.loglik(eta, m, o) + hcf.loglik(eta, m, o_cal))
                for m in hcf.modes]
    illusion = min(per_mode) > TAU_MODE and \
               kl(hcf.mode_posterior(o), q_tac) > TAU_KL
    return min(per_mode), illusion
def robust_impedance(K0, U_emb): return K0 / (1.0 + GAMMA * U_emb)

# IP-275 主闭环（继承 FLUID/R68）
def TACIT_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    eta = M.hcf.sample(o, K=4 if M.mode_head(z) > TAU_MODE else 1)
    U_ale, U_int, U_con, U_emb = M.acu.decompose(eta, o)
    g_i = M.ocm.match(U_int, ['ask','demo','probe'], o)   # intent → 可问
    g_c = M.ocm.match(U_con, ['probe','demo'],      o)   # contact → 可示/可触
    g   = M.pqg.arbitrate([g_i, g_c])                    # 可逆/预算/可读
    alpha = M.ura.route(U_int, U_con, U_emb, M.human.state)
    if M.pdl.wants_demo(g) and M.human.available: g = M.pdl.request_demo()
    alpha = M.ura.handshake(alpha, M.human.state, M.tau_h)
    ev = M.pdl.execute(g, alpha, o) if g is not None else None
    U_con = M.acu.update(U_con, ev, discipline='k_orthogonal')
    a_m, illusion = M.cca.contact_anomaly(M.hcf, M.last_eta, o, o_cal, M.q_tac)
    K_imp = M.see.robust_impedance(K0, U_emb)
    U_unres = U_con + (U_int if ev is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_emb + U_unres))
    if illusion: lam = max(lam, 0.8); K_imp = min(K_imp, K_conservative)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H),
                                    ..., wm_preds, authority=alpha)
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam * K_imp / K0
    M.vqa_i.submit_async(g, ev, U_int, U_con, U_emb, alpha, a_m)
    return k, lam, alpha, (U_ale, U_int, U_con, U_emb)
```

## 4. 推导

**引理 19（可问性缺口）** 设 tacit 分量 `u` 的可问性 `α_ask(u)=α<1`。即使问答无噪声，提问后残余熵下界为 `(1−α)H(u)`；问多少次都不能再降。系：`α_ask(U_contact)<α_min` 时语言回答的有效 VoI≈0，却可能因语言模型流畅而被误当高置信证据——通道错配比不交互更危险。

**引理 20（混杂模式可辨识性）** 若 `m_1,m_2` 在事件 `τ` 前的连续轨迹分布相同，则仅依赖轨迹聚类的 R69 分解在该段 `I(M;clusters)=0`；而 HCF 以 `σ` 为显式变量，事件可由力率/滑移线索估计时 `I(σ;o)>0`。系：差异不在轨迹里而在调度里，提高 K 不能替代接触模式表示。

**引理 21（可逆查询的安全增益）** `R(g)≥ε_rev` ⇒ 最坏结果仍在可恢复集内，`risk(g)≤risk(HOLD)`，信息增益不降低安全包络；`R(g)<ε_rev` ⇒ 存在正概率进入不可恢复集，`E[risk(g)]>risk(HOLD)` 且超出部分不被 VoI 抵消。系：信息-承诺分离是 VoI 可加性的前提。

**引理 22（示范迁移折扣）** 人类与机器人在示范状态分布上的策略 KL 为 `TV(D)`，则行为克隆性能差 `J(π_h)−J(π_θ) ≤ L_J·TV(D)+ε_emb`。故 `w_D=e^{−κTV}` 必要；`TV>τ_TV` 时示范不足以认证不可逆策略。

**定理 18（TACIT 严格包含 FLUID 与 R68）** A99–A101 下，TACIT 期望风险 ≤ FLUID ≤ R68；无接触模式、`α_demo=0`、权限恒在机器人侧时逐指令退化为 FLUID；再 `VoI_eff≤成本` 时逐指令退化为 R68。安全侧只增不减，效率侧仅在合法通道 + 可逆 + 证据一致时获 resolution bonus。

**定理 19（共享权限无责任真空）** 若所有 `|Δα|>δ_α` 的转移经两阶段握手且超时回退 HOLD，则任意时刻至少一方持有明确权限；人类反应延迟 `≤τ_h` 时权限震荡次数有界；动作满足双方安全包络交集，物理风险 ≤ `min(ε_h,ε_r)+ε_int`。

**定理 20（接触模式幻觉判别性）** 当标定只吸收 `r_nuis` 不吸收 `r_mode` 时，`(r_res↓,Δa_mode↑,D_KL(q_φ‖q_tac)↑)` 对模式级缓变故障的 AUC 严格高于 R69 单通道 `(r_res↓,Δa↑)`；无触觉时退回 R69 判据并降低置信。

## 7. 本轮最大风险

**一句话**：TACIT-RAS 的收益押在「tacit 技能可经示范/物理引导跨具身迁移」与「共享权限始终被双方正确理解」两个前提上；若其一不成立，系统会把人**具身特定**的接触技巧固化成机器人自信却错误的策略，而权限握手只保证「有人负责」、不保证「负责的人知道自己在负责什么」——**最终风险不是学不会，而是学错之后，人类和机器人都以为对方在兜底**。

**次级风险与缓解**：示范不可行/不安全（DTE 折扣 + 可逆包络内协同验证 + E304/E315）；接触模式不可辨识（保持未消解、退回 R69 判据并降置信 + E308）；权限震荡/责任扩散（两阶段握手 + 超时 HOLD + authority_log + E306）；可逆性估计过乐观（保守内层近似 + 人类授权门 + E305）；通道混用污染证据（ACU 折扣 + 证据纪律† + E303）；结构 epistemic 被误当可问（U_emb 永不入交互预算，只在线辨识 + 鲁棒阻抗 + E309）。
