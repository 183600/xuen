# 第 1 轮（新灵感循环第 1 轮；基线 v20；本轮灵感：「多轮对话」×「社会影响」）

> **基线**：v20 产出 MetricVoiceGauge-NCD-HUTDH-v20 + IP-420–424（感知层：PCA/CTS/CFC/HPC/CFCtrl；定义 767–820；引理 151–156；实验 E751–E770）。
> 本轮纪律：**社会影响只扩"责任危险域"，多轮对话只做"有同意的责任再分配"，几何/感知底线不可撤**。不推倒 v20：v17 的 CLP/S2C/HCG/PSV/APS/AMC、v19 的 DCM/OGCC/CCV/DRS/OGC、v20 的 PCA/CTS/CFC/HPC/CFCtrl 全部保留。本轮只做一件事：**把"碰撞安全"从个体私有物升级为带外部性的公共物，并用多轮协商在不扩张任何个体安全域的前提下，选出社会可接受的联合计划**。

## 0. 直觉与动机

### 灵感 1（多轮对话 → 协商不是聊天，而是"联合可行域上的价格发现"）

直觉：通常把多轮对话理解为意图澄清、槽位填充、状态跟踪，目标是"听懂用户"。但在多机器人/人机共享空间里，多轮对话真正解决的是一个**机制设计问题**：每个 agent 只知道自己私有的安全域与代价，没人知道全局的"谁该让、让多少、让多久"。单轮广播"我要走这里"会退化成先到先得或死锁；无限轮协商会活锁。更反直觉的是：**对话不能创造安全，只能重新分配"谁承担保守"**。因此多轮对话的正确抽象不是"传递意图"，而是**在联合安全域的乘积空间里，通过报价—质疑—让步—承诺—撤销，迭代发现一组影子价格，使外部性被内化、让步可互惠、失败可关闭**。

严谨定义（本轮先用，产物区展开）：
- 每个 agent n 的私有安全集 `S_n = Exec_v20(n)`（来自 v20，硬约束，协商不可扩张）。
- 联合候选 `S = Π_n S_n`；联合计划 `π = (π_1,…,π_N) ∈ S`。
- 共享资源 `r(π) = (space, time, attention, egress, energy) ∈ R_+^d`；社会价格 `λ ∈ R_+^d`。
- 社会成本 `J_soc(π; λ) = Σ_n C_n(π_n) + λ·(Σ_n r(π_n)) + Σ_{n≠m} κ_m·R_{n→m}(π_n)`，其中 `R_{n→m}` 是 n 的计划诱导到 m 的外部风险上界。
- 第 t 轮对话 `u_t = (PROPOSE, QUOTE, CHALLENGE, CONCEDE, COMMIT, REVOKE)`；公开信念 `B_t`（已达成一致的联合安全子集）满足 `B_{t+1} ⊆ B_t`。
- 协商收敛：`t ≤ T_max` 且 `||λ_{t+1} − λ_t|| ≤ ε_λ` 且无未决质疑且所有外部性有有效同意 `Consent_{n→m}`。
- 失败关闭：不收敛 ⇒ 回退 v20 的字典序最保守联合计划。

### 灵感 2（社会影响 → 外部性不是附加罚项，而是证书的对偶变量）

直觉：通常把"社会影响"当成事后评估：碰撞率、投诉数、公众接受度。但在线安全控制里，事后指标无法进入 50Hz 决策环。更反直觉的是：**社会影响的本质是"一个 agent 的安全计划把风险/成本推给了别人"**——机器人靠边停车保护了自己，却堵住了盲人的无障碍通道；A 机器人抢行，迫使 B 机器人急停并侵入人行道。这种**风险外部化**无法用个体碰撞证书表达，因为每个个体都"零碰撞"。核心创新：把社会影响写成**共享资源的影子价格 + 外部风险上限 + 可撤销同意**：`λ` 是"占用一平方米公共空间/一秒通行权/一单位人类注意力"的边际社会成本；任何计划若使 `R_{n→m} > B_pair` 且无 m 的同意，则被移出社会可接受集。社会影响因此不是"额外扣分"，而是让**私有证书可组合成公共品**的对偶变量。

严谨定义（本轮先用，产物区展开）：
- 社会危险域 `H_soc = {π ∈ S : (∃m, R_{n→m}(π) > B_pair) ∨ (λ·r(π) > B_res) ∨ (¬Fair(L))}`。
- 严格社会集 `Exec_v21^strict = {π ∈ S : R_{n→m}(π) = 0 ∀n≠m, J_soc(π;λ) ≤ B_soc}`。
- 社会可接受集 `Exec_v21 = Exec_v21^strict ∪ {π ∈ S : 外部性被有效同意覆盖, J_soc(π;λ*) ≤ B_soc, Fair(L_T)}`。
- 同意 `Consent_{n→m}(π_n) = (m 明确接受 n 在区域/时段的外部性) ∧ (可撤销) ∧ (未过期)`。
- 公平账本 `L_m(t) = Σ_{s≤t} (Burden_m(s) − Benefit_m(s))`，约束 `|L_m(t)| ≤ Φ`（长期互惠，不许永久搭便车）。
- 关键：`Exec_v21 ⊆ S = Π_n Exec_v20(n)`，社会层只会**删计划**，不会**造安全**。

### 灵感 3（统一 → 社会协商证书：个体证书 + 价格 + 账本 + 对话证明）

直觉：v20 回答"这个 agent 自己会不会撞"；v21 回答"这一组 agent 的联合计划，是否在**不把风险推给第三方**的前提下、经过**可收敛可审计的多轮协商**达成"。把两者拼起来不是简单叠加，而是三层权限的分离：**个体层拥有否决权（v20 硬约束）**，**社会层拥有定价权（外部性内化）**，**对话层拥有再分配权（让步与互惠）**。任何一层失效都只能让可执行集收缩，绝不能让它扩张。关键反直觉点：**多轮对话的收益不是"更敢走"，而是"在严格无外部性的保守底线上，通过可撤销同意把被误伤的活性要回来"，但永远不越过 v20 的个体安全包络**。

严谨定义：
- `SNC = (Π_n cert_n^v20, λ*, B_T, D_T, L_T, ConsentSet, transcript_root, τ_neg, mode_soc)`，`mode_soc ∈ {NORMAL, PRICE_FROZEN, NEGOTIATION_EXPIRED, FAIL_CLOSED}`。
- 接口：`π ∈ Exec_v21` 当且仅当 `∀n, π_n ∈ Exec_v20(n)`、`π ∈ B_T`、`J_soc(π;λ*) ≤ B_soc`、`Fair(L_T)`、`SNC` 新鲜且 Merkle 可验证。
- 对话只改 `B_T`（单调收缩）与 `L_T`（单调记账），**永不修改** `Exec_v20(n)`。

### 三者如何统一

v20 回答"给定几何与感知快照，节点 n 在参数 θ 下是否零碰撞"（`Exec_v20`）；v21 回答"给定社会外部性与多轮协商，联合计划 π 是否在不伤害未同意第三方的条件下社会可接受"（`Exec_v21`）。SIA 是定价侧（外部性→影子价格与风险上界），MTD 是协商侧（多轮报价→质疑→让步→承诺），SIL 是公平侧（互惠账本→防搭便车），SNC 是证书侧（个体证书+价格+账本+对话证明），RFG 是守卫侧（在线否决越界与合谋），NFC 是时序侧（价格冻结→失败关闭）。统一状态 `ζ_soc = (S_n, r, λ, B_t, L_t, ConsentSet, τ_neg, mode_soc)`。SIA 回答"这个计划把多少风险推给了谁"，MTD 回答"能否通过协商把外部性内化"，SIL 回答"让步是否长期互惠"，RFG 回答"是否有人在合谋牺牲第三方"。

## 1. 研究问题（轮次升级版）

- **Q1（社会外部性的可测性与可证伪性）**：如何给出 `R_{n→m}(π)` 的**保守上界**（而非点估计），使其在遮挡/人因/多模态不确定性下不漏掉外部风险？`λ` 的量纲、标定与漂移如何界定？当"社会影响"本身不可观测时，证书如何保持可证伪而不是变成不可反驳的价值断言？

- **Q2（多轮协商的收敛性、激励兼容与抗策略性）**：在非凸的机器人运动代价与外部风险下，tâtonnement 价格发现何时收敛？agent 是否会通过虚报私有安全域/代价来抬高他人价格、换取优先权？如何用账本转移、交叉核验与悔价惩罚逼近激励兼容？`T_max`、`ε_λ`、让步步长 `η` 如何与任务时限对齐？

- **Q3（公平账本与第三方保护）**：`L_m(t)` 如何防止"按回合切分"的搭便车与永久牺牲某一方？当被外部化的第三方（行人、非参与机器人、残障用户）不在协商桌上时，`B_pair` 与 `Φ` 由谁设定、如何审计？合谋（多方互相背书、把风险集中推给沉默第三方）如何被几何与因果一致性识别？

- **Q4（协商时序与控制的协调）**：多轮协商的延迟（数十至数百毫秒）如何与 50Hz 控制、v20 的 APS/CFCtrl 新鲜度阶梯对齐？"价格冻结但未失败""协商过期但计划仍在执行"如何分级回退？如何保证控制环永不被协商阻塞，且失败关闭不引入新的急停风险？

## 2. 设计原则（在 P31–P33 基础上新增 P37–P40）

**P37 社会外部性内化律（Social Externality Internalization Law）**
每个联合计划必须携带 `(r(π), {R_{n→m}}, λ, ConsentSet, τ_soc)`。外部风险取**保守上界**，并计入社会成本 `J_soc(π;λ)`。**无有效同意的外部性一律视为社会危险**；有同意也只允许在 `R_{n→m} ≤ B_pair` 且 `J_soc ≤ B_soc` 内。社会层只能把计划移出 `S`，不能把任何计划加入 `S`。

**P38 协商单调律（Deliberation Monotonicity Law）**
每轮对话只允许两类操作：**收缩公开信念** `B_{t+1} ⊆ B_t`，或**追加账本记录** `L_{t+1} ⊇ L_t`。任何 agent 的 `PROPOSE` 必须落在自己的 `S_n` 内；任何 `COMMIT` 必须引用已验证的证据与未过期的同意。**对话不创造安全，只重新分配保守**；若一轮无法收缩也无法记账，则视为空转并计入 `T_max`。

**P39 互惠公平律（Reciprocity Fairness Law）**
账本必须满足 `|L_m(t)| ≤ Φ` 且 `max_m L_m(t) − min_m L_m(t) ≤ Δ`。任何使某 agent 的负担超出 `Φ` 或使极差超出 `Δ` 的计划被 RFG 否决；连续 `k` 轮净负担的 agent 获得下一轮优先报价权（互惠补偿）。**公平是硬约束，不是软惩罚**：宁可回退 v20，也不执行长期剥削性计划。

**P40 协商失败关闭律（Negotiation Fail-Closed Law）**
若 `t > T_max`、`||λ_{t+1}−λ_t|| > ε_λ`、存在未决质疑、同意过期或通信分区，则进入 `PRICE_FROZEN` 或 `NEGOTIATION_EXPIRED`：冻结 `λ`、把 `B` 收缩到严格社会集 `Exec_v21^strict`；若仍不满足新鲜度或公平，则回退 v20 的字典序最保守联合计划。**沉默与超时是保守的，不是放行**。

## 3. 与基线的接口（如何退化）

- SIA 失效（外部风险模型不可用/校准失败）⇒ 所有 `R_{n→m}` 取上界 `+∞`，只允许严格社会集 ⇒ 比 v20 更保守；
- MTD 失效（协商不可用/分区）⇒ 不进行任何同意，`Exec_v21 = Exec_v21^strict` ⇒ 比 v20 更保守；
- SIL 失效（账本不可写/校验失败）⇒ `Fair` 恒为假，拒绝一切有外部性的计划 ⇒ 比 v20 更保守；
- SNC 失效（证书不可验证）⇒ 拒绝执行，回退 v20 ⇒ 等价 v20；
- RFG 失效（守卫不可用）⇒ 保守地视为"存在合谋"，禁止有外部性的计划 ⇒ 比 v20 更保守；
- NFC 失效（时钟/新鲜度不可用）⇒ 进入 `FAIL_CLOSED`，冻结价格并撤销同意 ⇒ 比 v20 更保守；
- 全部失效 ⇒ 完全回退 v20 的 PCA/CTS/CFC/HPC/CFCtrl + 几何 CCV ⇒ 等价 v20；
- **安全继承**：SIA 只加外部风险、MTD 只收缩信念与记账、SIL 只加公平约束、SNC 只验证不授权、RFG 只否决、NFC 只冻结/回退；任意失效都使可执行集收缩，`Exec_v21 ⊆ Exec_v20` 由引理 162 保证。

## 4. 预期贡献

1. **社会外部性证书化**：首次把"一个机器人的安全计划把风险推给别人"形式化为保守外部风险上界 + 共享资源影子价格 + 可撤销同意，使碰撞安全从个体私有物变成可组合的公共品；
2. **多轮协商即价格发现**：把多轮对话从"意图澄清"重写为联合安全域上的 tâtonnement 协商，给出收缩单调、收敛判据、激励兼容的近似与失败关闭规则；
3. **互惠公平账本**：给出跨回合的负担/收益记账、`Φ`/`Δ` 硬约束与合谋检测，防止"少数 agent 永久承担保守、第三方被系统性外部化"；
4. **社会协商证书（SNC）**：把个体 v20 证书、影子价格、公平账本、对话 Merkle 证明打包为可机械验证的证书，供控制环在线查询；
5. **社会-几何双层安全格**：`Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`，实现"个体不撞、群体不推责、协商可审计"的闭环。

## 5. 本轮最大风险

**一句话**：社会成本的价格 `λ`、外部风险上限 `B_pair` 与公平预算 `Φ` 本质上都是**价值判断**，而被外部化的第三方（行人、非参与机器人、残障用户）往往**不在协商桌上**；若参与者能通过多轮对话操纵影子价格、互相背书并把风险集中推给沉默第三方，证书就会"程序上公平、分配上致命"——即**协商合法化的外部性**。

# IP-425 Social Impact Assessor (SIA)
class SocialImpactAssessor:
    """
    外部风险一律取保守上界；不可观测时取区间上端。
    任何无法界定上界的量一律取 1.0（最坏），保证只多判危险。
    """
    def __init__(self, v20, risk_model, resource_model, caps):
        self.v20 = v20                      # v20 感知/几何证书，用于硬约束
        self.risk_model = risk_model        # 外部风险上界模型（区间输出）
        self.resource_model = resource_model
        self.caps = caps                    # B_pair, B_soc, R_cap
        self.unobservable_upper = 1.0       # 不可观测时的最坏上界

    def assess(self, joint_plan, state, lam):
        # 0. 硬约束：每个个体计划必须仍在 v20 安全集内
        for n, pi_n in joint_plan.items():
            if not self.v20.member(n, pi_n):
                return SocialAssessment(admissible=False, reason="V20_VIOLATION")

        # 1. 共享资源向量（上界）
        r_total = sum(self.resource_model.upper(pi_n, state)
                      for pi_n in joint_plan.values())

        # 2. 外部风险上界 R_{n->m}，含对 A_ext 的沉默第三方
        R_ext = {}
        for n, pi_n in joint_plan.items():
            for m in (set(joint_plan) | state.A_ext):
                if m == n:
                    continue
                lo, hi = self.risk_model.interval(n, m, pi_n, state)
                R_ext[(n, m)] = hi if hi is not None else self.unobservable_upper

        # 3. 外部风险项：未同意的外部性按最坏加权；已同意仍受 B_pair 限制
        ext_cost = 0.0
        for (n, m), R in R_ext.items():
            consent = state.consent_set.get((n, m))
            if consent is None or not consent.valid(state.time):
                ext_cost += self.caps.kappa_m.get(m, 1.0) * R
                if R > self.caps.B_pair:
                    return SocialAssessment(admissible=False, reason="UNCONSENTED_EXTERNALITY")
            else:
                if R > consent.max_R:
                    return SocialAssessment(admissible=False, reason="CONSENT_EXCEEDED")
                ext_cost += self.caps.kappa_m.get(m, 1.0) * R

        # 4. 社会成本
        private = sum(self.v20.private_cost(n, pi_n) for n, pi_n in joint_plan.items())
        J_soc = private + dot(lam, r_total) + ext_cost

        # 5. 资源与预算硬约束
        if any(r_total[i] > self.caps.R_cap[i] for i in range(len(r_total))):
            return SocialAssessment(admissible=False, reason="RESOURCE_OVERFLOW")
        if J_soc > self.caps.B_soc:
            return SocialAssessment(admissible=False, reason="SOCIAL_BUDGET_EXCEEDED")

        return SocialAssessment(
            admissible=True, J_soc=J_soc, r=r_total, R_ext=R_ext,
            risk_interval_upper=ext_cost
        )


# IP-427 Social Impact Ledger (SIL)
@dataclass
class LedgerEntry:
    t: int
    agent: int
    burden: float
    benefit: float
    cause: str
    evidence_hash: str

class SocialImpactLedger:
    def __init__(self, agents, Phi, Delta):
        self.agents = list(agents)
        self.Phi = Phi
        self.Delta = Delta
        self.entries = []
        self.L = {a: 0.0 for a in agents}

    def update(self, t, plan, assessment):
        """按计划把负担/收益记入账本；负担只增不减，收益用于抵扣。"""
        for a in self.agents:
            burden = assessment.burden(a, plan)
            benefit = assessment.benefit(a, plan)
            self.L[a] += burden - benefit
            self.entries.append(LedgerEntry(
                t=t, agent=a, burden=burden, benefit=benefit,
                cause=assessment.cause(a), evidence_hash=assessment.hash(a)
            ))
        return self

    def fair(self):
        if any(abs(v) > self.Phi for v in self.L.values()):
            return False
        return (max(self.L.values()) - min(self.L.values())) <= self.Delta

    def would_violate(self, t, plan, assessment):
        """RFG 用：预测更新后是否越界，不落账。"""
        probe = dict(self.L)
        for a in self.agents:
            probe[a] += assessment.burden(a, plan) - assessment.benefit(a, plan)
            if abs(probe[a]) > self.Phi:
                return True
        return (max(probe.values()) - min(probe.values())) > self.Delta

    def transfer(self, src, dst, amount, t):
        """互惠补偿：把 src 的已获收益转给 dst，用于纠正长期失衡。"""
        amount = min(amount, max(0.0, self.L[src]))
        self.L[src] -= amount
        self.L[dst] += amount
        self.entries.append(LedgerEntry(t, src, 0.0, amount, "TRANSFER_OUT", ""))
        self.entries.append(LedgerEntry(t, dst, amount, 0.0, "TRANSFER_IN", ""))

    def priority(self):
        """负担越重，下一轮越先报价（互惠补偿的对称面）。"""
        return sorted(self.agents, key=lambda a: self.L[a], reverse=True)


# IP-426 Multi-Turn Deliberation (MTD)
class MultiTurnDeliberation:
    def __init__(self, sia, ledger, T_max=8, eps_lambda=1e-2, eta=0.1):
        self.sia = sia
        self.ledger = ledger
        self.T_max = T_max
        self.eps_lambda = eps_lambda
        self.eta = eta

    def negotiate(self, agents, state, lam0):
        # 初始公开信念 = v20 联合安全域（只减不增）
        B = JointSafeSet.product([a.safe_set for a in agents])
        lam = project_nonneg(lam0)
        D = set()                     # 未决质疑
        consents = ConsentSet()
        transcript = MerkleLog()

        for t in range(self.T_max):
            # 1. 报价：负担重的 agent 优先，提交 PROPOSE + QUOTE
            proposals = {}
            for a in self.ledger.priority():
                pi_a = a.propose(lam, B, self.ledger.L[a])
                if not a.safe_set.contains(pi_a):
                    pi_a = a.most_conservative()      # 越界即退回私有最保守
                proposals[a.id] = pi_a
                transcript.append(t, a.id, "PROPOSE", hash(pi_a))

            # 2. 评估：社会成本、外部风险、资源超需
            assessment = self.sia.assess(proposals, state, lam)
            excess = assessment.r - self.sia.caps.R_cap

            # 3. 质疑：任何 agent 可对未同意外部性/资源占用发起 CHALLENGE
            D = self.collect_challenges(agents, proposals, assessment, state)
            for (challenger, target, region) in D:
                transcript.append(t, challenger, "CHALLENGE", hash((target, region)))

            # 4. 单调收缩：被质疑且未被证据反驳的计划移出 B
            if D:
                B = B.filter(lambda pi: not challenged(pi, D, assessment))
            # 5. 同意：只允许在 B_pair 内、可撤销、带证据的 CONSENT
            consents = self.update_consents(agents, proposals, assessment, state, consents)
            # 6. 公平：会越界则要求 CONCEDE / 转移
            if self.ledger.would_violate(t, proposals, assessment):
                proposals = self.force_concession(agents, proposals, self.ledger)
                assessment = self.sia.assess(proposals, state, lam)

            # 7. 收敛判据：价格稳定 + 无未决质疑 + 全部外部性有同意 + 公平
            lam_new = project_nonneg(lam + self.eta * excess)
            converged = (
                norm(lam_new - lam) <= self.eps_lambda
                and not D
                and self.all_externalities_consented(assessment, consents, state)
                and self.ledger.fair()
            )
            transcript.append(t, "SYSTEM", "QUOTE", hash(lam_new))
            lam = lam_new
            if converged:
                self.ledger.update(t, proposals, assessment)
                return SocialNegotiationCertificate(
                    v20_certs=[a.safe_set.cert for a in agents],
                    lam=lam, B=B, D=D, ledger=self.ledger.snapshot(),
                    consents=consents, transcript_root=transcript.root(),
                    tau_neg=state.time, mode_soc="NORMAL"
                )

        # 8. 失败关闭：冻结价格，收缩到严格社会集，再不行回退 v20
        strict = B.filter(lambda pi: self.sia.assess(pi, state, lam).strict_ok())
        if strict.nonempty():
            return SocialNegotiationCertificate(
                v20_certs=[a.safe_set.cert for a in agents],
                lam=lam, B=strict, D=D, ledger=self.ledger.snapshot(),
                consents=ConsentSet(), transcript_root=transcript.root(),
                tau_neg=state.time, mode_soc="NEGOTIATION_EXPIRED"
            )
        return self.v20_fallback(agents, state, transcript)

    def collect_challenges(self, agents, proposals, assessment, state):
        D = set()
        for (n, m), R in assessment.R_ext.items():
            if R > self.sia.caps.B_pair and not state.consent_set.has(n, m, state.time):
                D.add((m if m in agents else "THIRD_PARTY", n, "EXTERNALITY"))
            if m in agents and agents[m].ledger_exceeded():
                D.add((m, n, "FAIRNESS"))
        return D

    def v20_fallback(self, agents, state, transcript):
        # v20 字典序最保守：最短步长 / 最大间隔 / 最小占用
        plan = {a.id: a.most_conservative() for a in agents}
        return SocialNegotiationCertificate(
            v20_certs=[a.safe_set.cert for a in agents],
            lam=zeros_like(state.lam), B=JointSafeSet.singleton(plan),
            D=set(), ledger=self.ledger.snapshot(), consents=ConsentSet(),
            transcript_root=transcript.root(), tau_neg=state.time,
            mode_soc="FAIL_CLOSED"
        )


# IP-429 Reciprocity & Fairness Guard (RFG)
class ReciprocityFairnessGuard:
    def __init__(self, sia, ledger, collusion_detector):
        self.sia = sia
        self.ledger = ledger
        self.collusion = collusion_detector

    def check(self, snc, joint_plan, state):
        # 1. 证书必须新鲜且可验证
        if not snc.verify() or not snc.fresh(state.time):
            return False, "STALE_OR_INVALID_SNC"
        # 2. 个体硬约束不可被协商绕过
        for n, pi_n in joint_plan.items():
            if not self.sia.v20.member(n, pi_n):
                return False, "V20_VIOLATION"
        # 3. 计划必须在协商达成的一致集内
        if not snc.B.contains(joint_plan):
            return False, "OUTSIDE_AGREED_SET"
        # 4. 公平硬约束（预测而非事后）
        a = self.sia.assess(joint_plan, state, snc.lam)
        if self.ledger.would_violate(snc.tau_neg, joint_plan, a):
            return False, "FAIRNESS_BUDGET"
        # 5. 合谋检测：多方同意把风险集中到沉默第三方
        if self.collusion.detect(joint_plan, a, snc.consents, state):
            return False, "COLLUSION_ON_THIRD_PARTY"
        return True, "OK"


# IP-428 Social Negotiation Certificate (SNC)
@dataclass
class SocialNegotiationCertificate:
    v20_certs: list            # 每个 agent 的 v20 证书
    lam: Vector                # 协商出的影子价格
    B: JointSafeSet            # 一致联合安全子集
    D: set                     # 未决质疑
    ledger: LedgerSnapshot     # 公平账本快照
    consents: ConsentSet       # 有效同意集合
    transcript_root: str       # 对话 Merkle 根
    tau_neg: float             # 协商完成时间
    mode_soc: str              # NORMAL / PRICE_FROZEN / ...

    def verify(self):
        # 逐项机械验证：证书链、价格非负、账本平衡、同意未过期、Merkle 根
        return (
            all(c.verify() for c in self.v20_certs)
            and all(x >= 0 for x in self.lam)
            and self.ledger.balanced()
            and self.consents.all_valid(self.tau_neg)
            and self.transcript_root == self.consents.root_of_evidence()
        )

    def fresh(self, now):
        return (self.mode_soc == "NORMAL") and (now - self.tau_neg <= TTL_neg)


# IP-430 Negotiation Freshness Controller (NFC)
class NegotiationFreshnessController:
    def __init__(self, aps, cfc, ttl_neg=1.0, ttl_consent=3.0):
        self.aps = aps
        self.cfc = cfc                 # v20 的 CFCtrl
        self.ttl_neg = ttl_neg
        self.ttl_consent = ttl_consent

    def gate(self, snc, state):
        age = state.time - snc.tau_neg
        if age > self.ttl_consent:
            return "FAIL_CLOSED"
        if age > self.ttl_neg:
            # 价格冻结：撤销全部同意，只保留严格社会集
            return "PRICE_FROZEN"
        if snc.mode_soc != "NORMAL":
            return snc.mode_soc
        return "NORMAL"

    def integrate(self, plan, snc, state):
        mode = self.gate(snc, state)
        if mode == "FAIL_CLOSED":
            return self.aps.activate_freshness_ladder(
                plan, force_mode="V20", drop_consents=True)
        if mode == "PRICE_FROZEN":
            # 只执行严格社会集内的计划；不阻塞控制环
            return self.aps.update_plan_risk(
                plan, margin_col_fed=self.cfc.margin(snc), restrict="STRICT_SOC")
        # 正常：把社会风险折入 v20 的动态 margin
        return self.aps.update_plan_risk(
            plan, margin_col_fed=self.cfc.margin(snc) * (1.0 + snc.social_risk()))

## 3. 推导

**引理 157（社会可接受集的保守性）**
`Exec_v21 ⊆ S = Π_n Exec_v20(n)`。证明：`Exec_v21` 的每个成员先要求 `∀n, π_n ∈ Exec_v20(n)`（SIA 与 RFG 的硬约束），再叠加资源、预算、外部性与公平过滤；所有过滤都是删除操作，故不会引入 `S` 之外的计划。∎

**引理 158（协商单调性）**
若对话只执行 `B ← B.filter(¬challenged)` 与 `L ← L ∪ {entry}`，则 `B_{t+1} ⊆ B_t` 且 `L_t` 单调增长。故 `B_t` 是一个嵌套下降链，长度受 `|S|` 与 `T_max` 约束；不存在通过对话"新增"联合计划的轮次。∎ 推论：对话不能把计划从社会危险域移入可接受集，除非该计划本来就在 `S` 内且满足同意的上界。

**引理 159（价格发现的支持性，凸情形）**
设 `C_n` 与 `r` 关于 `π_n` 凸，`R_{n→m}` 凸，则 tâtonnement 的收敛点 `λ*` 满足：在固定 `λ*` 下，每个 agent 的提案是其拉格朗日代价的极小点（无单边有利偏离），且 `z(λ*) = Σ r − R_cap ≤ 0`（互补松弛）。故 `(π*, λ*)` 是凸社会成本问题的 Walrasian 均衡。**非凸情形只保证局部支持性**，需以 `T_max` 与失败关闭兜底。∎

**引理 160（公平账本有界性）**
RFG 在执行前用 `would_violate` 预测更新后的 `L`；若 `∃m, |L_m| > Φ` 或 `max L − min L > Δ`，则否决该计划并要求 `CONCEDE`/转移。因此对任意已执行回合，`|L_m(t)| ≤ Φ` 且极差 `≤ Δ`。∎ 推论：任何 agent 的累计净负担有界，不存在无限期搭便车或永久牺牲。

**引理 161（协商失败关闭）**
若 `t > T_max` 或 `||λ_{t+1}−λ_t|| > ε_λ` 或 `D ≠ ∅` 或同意过期，MTD 进入 `NEGOTIATION_EXPIRED`，把 `B` 收缩到 `Exec_v21^strict`；若严格集为空，则返回 `FAIL_CLOSED` 的 v20 字典序最保守计划。两条路径都在 `Exec_v20` 内，故失败不会扩张可执行集。∎

**引理 162（v21 整体安全继承）**
在同一几何/感知快照与同一 agent 集合下，`Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。证明：个体层由引理 157 否决越界；社会层只删计划；协商层由引理 158 单调收缩；公平层由引理 160 只加约束；时序层由引理 161 失败回退。五者叠加只能产生子集。∎

**引理 163（合谋-第三方保护，条件性）**
若 RFG 的合谋检测器满足：对任意 `π` 与任意 `S ⊆ A`，当 `S` 内互相同意把风险集中到 `m ∈ A_ext` 且 `R_{n→m} > B_pair` 时，`detect` 返回真；则不存在仅靠 `S` 内部同意就把外部风险转移给沉默第三方的可执行计划。**该引理依赖检测器的完备性，是 v21 最脆弱的假设。**∎

## 7. 已知风险与失效模式

1. **价值判断被技术化**：`λ`、`B_pair`、`Φ`、`Δ` 都是人为设定的规范性参数，证书会把"谁的出行更重要""谁的风险可接受"编码成看似中立的数字。缓解：参数须由独立治理机构预注册、公开审计、定期重标定；证书显式记录参数来源与版本。

2. **外部风险不可观测导致的乐观上界**：`R_{n→m}` 是反事实量，难以验证；若风险模型系统性低估，则"保守上界"名不副实。缓解：区间化 + 不可观测默认最坏 + 事后碰撞/投诉回灌校准 + 保形预测式覆盖保证。

3. **策略性虚报与价格操纵**：agent 可通过虚报私有代价或安全域抬高他人价格、换取优先权；tâtonnement 只在凸且真实报告下支持均衡。缓解：账本悔价惩罚、物理观测交叉核验、随机化报价顺序、限制单轮让步幅度。

4. **合谋与"同意"通胀**：多方互相背书可把风险集中推给沉默第三方；`Consent` 也可能被轻率或批量签署。缓解：RFG 合谋检测、同意必须绑定证据与区域、可撤销、对 `A_ext` 一律不承认代理同意。

5. **公平账本的跨回合套利**：按回合切分、拆分任务或延迟记账可规避 `Φ`；极差约束也可能压制必要的临时让步。缓解：滑动窗口 + 长程账本、任务级而非回合级结算、`Φ` 与 `Δ` 的分段线性。

6. **非凸性破坏价格均衡**：机器人运动代价与外部风险通常非凸，tâtonement 可能震荡或陷入局部。缓解：多起点、粗网格初始化、`T_max` 失败关闭、必要时退回 v20。

7. **协商延迟与活锁**：多轮协商在动态人群中可能永远追不上环境变化。缓解：异步协商 + 价格冻结 + 分级新鲜度 + 失败关闭，控制环只读缓存 SNC。

8. **第三方无代理的合法性缺口**：`A_ext` 不在桌上，任何"保护"都是家长式的；证书能限制外部性，却无法赋予第三方真正的同意权。缓解：把不可交易硬约束（无障碍、疏散、人身安全距离）置于协商之外，仅允许治理层修改。

## 8. 本轮最大风险

**一句话**：社会成本的价格 `λ`、外部风险上限 `B_pair` 与公平预算 `Φ` 本质上是**价值判断**，而被外部化的第三方（行人、非参与机器人、残障用户）往往**不在协商桌上**；若参与者能通过多轮对话操纵影子价格、互相背书并把风险集中推给沉默第三方，证书就会"程序上公平、分配上致命"——即**协商合法化的外部性**。
