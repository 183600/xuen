灵感驱动研究循环·本轮灵感：「最小可行产品」×「比赛策略」（在 v23 之上）

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v23（IP-436–439：CESC 云边版本证书 / FSVC 少样本有效证书 / IPAM 知识产权认证 / HPC-E+ 四证准入门；其上承 v22 的 PGEV/ACSC/DCSC 三层能量-机械臂-深度感知，以及 v21 的 SDC/CAC/DCL/GIC 语义-规范-意图层）。
> 本轮纪律：**安全地基不可延后，活性上限可以最小；竞争只能发生在已认证集合内部，绝不能反向修改地基**。不推倒 v23：v18–v23 的全部模块、全部安全继承链保留。本轮只增加一个"取舍与竞争"的元层——**把一座不可交付的大教堂，改造成"可上门的安全地基 + 逐级加盖的活性楼层 + 场内比赛规则"**。

## 0. 直觉与动机

**灵感 1（最小可行产品 → 把"可证的全体"切成"安全地基 + 活性阶梯"）**
直觉：v23 有 400 多个模块、四证合一、云边同步、少样本适应、专利认证——它是一份**可证的最大方案**，却不是一张**可交付的最小方案**。安全系统的价值函数不是"模块数"，而是 `已部署时间 × 现场证据量`。MVP 的直觉正是：**先用一条端到端的最小切片跑起来，拿到真实数据，再逐级加能力**。
但这里有一个必须立刻纠正的误读：在安全关键系统里，"MVP = 先上线不安全版本、以后补安全"是**反模式**。因此我们把系统沿另一条轴切开：**安全是不可延后的（safety-complete），活性才是可以最小化的（liveness-minimal）**。由此得到 **最小可行证书 (Minimum Viable Certificate, MVC)**：在模块全集 M 中，找出一个代价最小的子集 `K*`，使 (a) 认证执行集仍落在真实安全集内，(b) 在目标任务分布上达到一个"值得部署"的活性下限 `L_min`。`K*` 之外的一切模块都降级为**能力 (capability)**，不是需求 (requirement)，沿 **能力阶梯 (Capability Ladder)** 逐级加入。
关键反直觉点：**MVP 不是"更小的 v23"，而是"v23 的一个已证安全的保守子系统，然后逐级长回 v23"**。即 `E_{K0} ⊆ E_{K1} ⊆ … ⊆ E_M = Exec_v23`——活性逐级变大，安全地基全程不变。加模块不是为了"更安全"（地基已经安全），而是为了"在安全里活得更好"。

**灵感 2（比赛策略 → 竞争是认证集内的排序，不是准入）**
直觉："比赛策略"有两层。第一层是**研发/市场比赛**：你赢不了靠"模块最多"，只能靠**单位安全开销换来的活性（竞争比 CR）最高**、以及**现场证据飞轮转得最快**；算法本身会被商品化，真正护城河是可由第三方机械复核的证书-审计链与它沉淀的数据。第二层是**多智能体共享赛场的资源之争**：路权、充电位、升降梯、任务槽都是稀缺资源，机器人（甚至不同厂商）必然要竞争。
于是核心问题变成：**竞争会不会侵蚀安全？** 我们的回答是一条结构性纪律：**一个能被出价买通的"安全证书"根本不是证书**。因此竞争必须被关进已认证集合的内部——竞价/优先级只能在 `E_i` 里排序计划，**永远不能把某个计划"加进" `E_i`**。输了竞价只损失活性（退回 `E_i` 内的保守计划），绝不损失安全裕度。我们把它称为 **竞争不变安全 (Competition-Invariant Safety)**。
第二个反直觉点（对抗面）：**外来竞争者提供的证据只能让你更保守，不能让你更激进**。对手说"那块区域没人"时，我们绝不据此扩张自由空间；只有自己感知链签发的缺席证书才能赎回自由空间，外来证据一律只做"收缩算子"（可能有人→加约束）。这是对"投毒式缺席"与"诱导碰撞"的结构性防御，也顺带把 v20 的"众口铄金"风险在竞争语境下再封一次。

**二者如何统一**
统一为一个 **取舍-竞争元层 (Triaging & Contest Meta-Layer, TCM)**：
- **MVP/MVC + 能力阶梯**回答"先造什么、后造什么、什么时候值得造"——它定义**赛场的边界与地板**（安全地基）和**可用的活动范围**（活性下限）。
- **比赛策略**回答"在既定赛场内如何分配有限资源去赢"——研发预算在阶梯各级间下注（组合 bandit），多机在认证集内竞价稀缺资源（竞争分配证书）。
- 共享同一个不变量：**竞争只能消费认证集，不能生产认证集**。形式化即 `Exec_v24 = E_{K_active} ∩ Fil_contest ∩ Fil_fair ⊆ E_{K_active} ⊆ Exec_v23`。MVP 让 `E_{K_active}` 可能远小于 `Exec_v23`（少即是稳），阶梯让它逐级长回去（少即是快），竞争只在其上再做收缩（赢要有序）。

## 1. 研究问题（轮次升级版）

- **Q1（删除证书的完备性）**：给定模块全集 M 与运行域 Ω，如何用"删除测试"判定模块 `m` 是**安全承重 (load-bearing safety)**、**活性承重 (load-bearing liveness)** 还是**可选 (optional)**？删除测试必须覆盖 Ω 的哪些角落（儿童/轮椅/逆光/低电量/通信抖动）才能声称完备？"未证明承重"与"证明可选"之间的空档如何不变成安全漏洞？
- **Q2（MVC 的最小性）**：如何在代价函数（部署成本、运行时开销、认证人力）下求 `argmin Cost(K)` 使 `E_K ⊆ Safe(Ω)` 且 `Live(E_K) ≥ L_min`？MVC 是否唯一？非唯一时如何给出一族 Pareto 最小解而不假装唯一？
- **Q3（能力阶梯的单调、滞回与回滚）**：每一级 rung 如何保证"安全不变、活性单调、可独立回滚"？级间如何加滞回（hysteresis）避免分布漂移下反复升降造成振荡？某级在线验证失败时，如何在不打断当前任务的前提下冻结在上一级？
- **Q4（研发组合策略）**：预算/时间有限时，如何在阶梯各级间下注以最大化期望竞争比 `CR` 而非模块数？如何预注册"杀死标准 (kill criteria)"，使 MVP 的快速失败不被沉没成本绑架？
- **Q5（多机竞争与投毒）**：认证集合内的资源分配机制如何做到**策略无关安全**（任意报价下结果都在认证集内）、**防投毒**（外来证据单向收缩）、**防饥饿**（有界等待 `T_starve` 与公平下界 `L_fair`）？容量真不可行时如何签发"不可行证书"而不是静默死锁或超卖？
- **Q6（指标抗刷）**：竞争比 `CR` 如何定义才能既激励活性又不鼓励"砍安全换指标"？如何用留出任务/红队注入防止 Goodhart？

## 2. 设计原则（在 P37–P42 基础上新增 P43–P46）

**P43 安全地基不可延后律（Safety-Floor Non-Deferrability）**
任何部署 `D` 的活动模块集 `K_D` 必须满足 `R_floor ⊆ K_D`，其中 `R_floor` 是安全地基（v18 保守几何 + v20 HPC + v23 的强制约束器闭包）。MVP 允许"活性最小"，但**不允许"安全待办 (safety TODO)"**：若 `K_D` 无法证明 `E_{K_D} ⊆ Safe(Ω)`，则不得部署，只能退到更小的 `K_floor`。安全是唯一不能靠迭代补上的部分。

**P44 最小可行证书律（Minimum Viable Certificate）**
存在代价最小的 `K*`（`R_floor ⊆ K* ⊆ M`）满足：(a) 在运行域 Ω 上 `E_{K*} ⊆ Safe(Ω)`；(b) 在任务分布 `D_task` 上 `max_{π∈E_{K*}} Live(π) ≥ L_min`。`K*` 之外模块是能力而非需求。能力沿阶梯 `K* = K_0 ⊂ K_1 ⊂ … ⊂ K_r = M` 逐级加入，满足 `E_{K_i} ⊆ Safe(Ω)` 且 `Live(E_{K_i}) ≤ Live(E_{K_{i+1}})`，且 `E_{K_r} = Exec_v23`。故活性逐级长回 v23，安全地基全程不变：`E_{K*} ⊆ … ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`。

**P45 竞争不变安全律（Competition-Invariant Safety）**
任何竞争机制 `A` 的输出必须满足：对每个智能体 `i`，`π_i ∈ E_{K_active}^i`，且全局资源约束 `Σ_i d(π_i) ≤ C`。机制可以是二价拍卖、老化优先级、保留配额或混合策略，但**没有任何报价/策略能让 `π_i ∉ E^i`**。外来证据 `ev` 只允许作为**收缩算子**：`E ← E ∩ Contract(ev)`，恒有 `E_after ⊆ E_before`；只有本地感知链签发的缺席证书可扩张自由空间。竞争失败回退到 `E^i` 内的保守计划（含 SafeStop），只损活性不损安全。

**P46 能力阶梯择优与可回滚律（Ladder Prioritization & Rollback）**
研发预算按"边际竞争比" `ΔCR / ΔCost` 择优投入阶梯（组合 bandit + 滞回），并以留出任务度量增益。每一级 rung 都携带独立证书与版本号，可原子回滚到上一级；在线验证失败即冻结在最后有效级，禁止"半级生效"。杀死标准（KC1–KC4）在设计期预注册，触发即停损，不得事后改写。

## 3. 与基线的接口（如何退化）

- **MVC 抽取失败/删除证书不可判定** ⇒ 不猜"可选"，直接取 `K_floor`（`R_floor` 加最保守假设）⇒ 比 v23 更保守，安全方向不变；
- **能力阶梯某级在线验证失败** ⇒ 冻结在上一有效级并回滚工件 ⇒ `E` 单调不增，`Exec_v24 ⊆ Exec_v23` 保持；
- **竞争机制 (CSL-M) 失效** ⇒ 无竞价，按固定静态优先级分配，但仍只从认证集选取 ⇒ 等价于更保守的确定性调度；
- **CAED 外来证据通道失效** ⇒ 拒绝一切外来证据（只用自身感知，忽略他机缺席与障碍申报）⇒ 自由空间只能更小；
- **SGF 公平守卫失效** ⇒ 停用共享资源竞争，退化为单机保守模式 ⇒ 活性下降、安全不变；
- **组合 bandit (CSL-P) 失效** ⇒ 按固定阶梯顺序前进，不做自适应下注 ⇒ 最坏多花预算，不破坏安全；
- **全部元层失效** ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。
- **安全继承**：MVC 只做"删除可选模块 + 保守兜底"，阶梯只做"逐级释放且每级复核"，竞争只做"认证集内取子集"，外来证据只做"取交"。四类操作**全部是收缩或已证安全的等价替换**，任意失效都向更保守方向退化。

## 4. 预期贡献

1. **最小可行证书 (MVC)**：首次把"部署优先"从工程口号变成可证的取舍问题——沿"安全地基 / 活性上限"轴分解，给出 `safety-complete, liveness-minimal` 的最小证书及其最小性证明，拒绝"先不安全后补"的反模式；
2. **删除证书与承重分类**：给出模块级 load-bearing/optional 的可机械复核判定（SMT/可执行检查 + 运行域覆盖），把"不敢删"变成"删得起且有据"；
3. **能力阶梯**：给出 `E_{K0} ⊆ … ⊆ E_M = Exec_v23` 的单调活性阶梯，每级独立可回滚、带滞回，把 400+ 模块的大教堂变成可分期的产品路线图；
4. **竞争不变安全**：证明"安全不可竞得"——任意报价/策略下机制输出都在认证集内，失败只损活性；并把"外来证据只能收缩"形式化为对抗投毒的单调性；
5. **资源竞争的公平下界**：给出带老化/保留配额的有界饥饿机制（`T_starve`, `L_fair`）与容量不可行时的"不可行证书"，把竞争从"赢者通吃"约束为"安全内可竞争"；
6. **研发组合策略**：把阶梯下注建成带预注册 kill criteria 的预算约束 bandit，用竞争比 `CR` 而非模块数做目标，直接对抗 Goodhart 与沉没成本。

## 5. 本轮最大风险

**一句话**：删除证书的"可选"判定本身依赖对运行域 Ω 的覆盖完备性，而竞争压力（抢先上线、抢预算、抢资源）会系统性地奖励"把尚未证明承重的模块当成可选删掉"——一旦 Ω 有未覆盖的角落，"最小可行"就会悄悄退化为"最小可撞"。

                 L_min: float, omega, task_dist) -> str:
        if m in U.hard_floor:
            return "load_bearing_safety"          # 地基不可删
        K2 = U.closure(K - {m})
        if not U.is_sound(K2, omega):
            return "load_bearing_safety"          # 删了会在 Ω 某处破 sound
        if U.max_live(K2, task_dist) < L_min:
            return "load_bearing_liveness"        # 删了跌破活性下限
        return "optional"                         # 可删，代价下降、安全不动

    def certificate(self, U, K, m, verdict, omega) -> dict:
        return {"module": m, "verdict": verdict,
                "witness": U.witness_for(K, m) if verdict != "optional" else None,
                "omega_hash": omega.hash(), "v23_chain": U.chain_hash()}


# ============================================================
# IP-440 Minimum Viable Certificate Extractor (MVCE)
# ============================================================
class MinimumViableCertificate:
    def __init__(self, U: ModuleUniverse, sfdc: DeletionCertificate):
        self.U, self.sfdc = U, sfdc

    def extract(self, L_min: float, omega, task_dist) -> frozenset[str]:
        K = set(self.U.closure(set(self.U.hard_floor)))
        if not self.U.is_sound(K, omega):
            raise Infeasible("safety floor itself unsound -> refuse deploy")

        # 若地基已够活性，K* 就是地基（宁可少，不可多）
        if self.U.max_live(K, task_dist) >= L_min:
            return frozenset(K)

        # 贪心加释放器：按边际活性/代价比，且每步复核 sound
        remaining = [m for m in self.U.modules.values() if m.kind == "release"]
        while self.U.max_live(K, task_dist) < L_min:
            base_live = self.U.max_live(K, task_dist)
            best, best_ratio = None, float("-inf")
            for m in remaining:
                if m.name in K:
                    continue
                K2 = self.U.closure(K | {m.name})
                if not self.U.is_sound(K2, omega):
                    continue
                gain = self.U.max_live(K2, task_dist) - base_live
                ratio = gain / max(m.cost, 1e-9)
                if ratio > best_ratio:
                    best, best_ratio = m, ratio
            if best is None:
                raise Infeasible("cannot reach L_min inside safe envelope")
            K = self.U.closure(K | {best.name})
            remaining.remove(best)

        # 最小性清理：删掉一切被 SFDC 判 optional 的模块（从贵到便宜）
        for m in sorted((K - set(self.U.hard_floor)),
                        key=lambda x: -self.U.modules[x].cost):
            if self.sfdc.classify(self.U, K, m, L_min, omega, task_dist) == "optional":
                K.remove(m)
        return frozenset(K)


# ============================================================
# IP-442 Capability Ladder Manager (CLM)
# ============================================================
@dataclass
class Rung:
    level: int
    modules: frozenset[str]
    certificate: bytes          # 该级的 soundness + liveness 证据
    activated_at: float
    min_dwell: float = 60.0     # 滞回：最短驻留，防抖动升降

class CapabilityLadder:
    def build(self, K_star, U, omega, task_dist, eps=1e-9) -> list[Rung]:
        rungs = [Rung(0, frozenset(K_star), b"", 0.0)]
        K = set(K_star)
        remaining = set(U.modules) - K
        level = 1
        while remaining:
            base_live = U.max_live(K, task_dist)
            best, best_ratio = None, float("-inf")
            for m in remaining:
                K2 = U.closure(K | {m.name})
                if not U.is_sound(K2, omega):
                    continue
                dl = U.max_live(K2, task_dist) - base_live
                dc = sum(U.modules[n].cost for n in (K2 - K))
                ratio = dl / max(dc, eps)
                if ratio > best_ratio:
                    best, best_ratio = K2, ratio
            if best is None:
                break                       # 剩余模块在 Omega 上不能安全加入
            K = best
            remaining -= K
            rungs.append(Rung(level, frozenset(K), b"", 0.0))
            level += 1
        return rungs

    def advance(self, rungs, active: int, now: float,
                validate) -> int:
        """带滞回升级：仅在预言机复核通过且驻留够久时前进一级"""
        if active + 1 >= len(rungs):
            return active
        nxt = rungs[active + 1]
        if now - rungs[active].activated_at < rungs[active].min_dwell:
            return active
        if not validate(nxt.modules):
            return active                    # 冻结在最后有效级，绝不半级生效
        nxt.activated_at = now
        return active + 1

    def rollback(self, active: int) -> int:
        return max(0, active - 1)


# ============================================================
# IP-443 Competitive Portfolio Bandit (CPB / CSL-P)
# ============================================================
class CompetitivePortfolio:
    """预算约束下在阶梯各级下注；奖励 = 留出任务上的 ΔCR"""
    def __init__(self, rungs, budget: float, kc: dict):
        self.rungs, self.budget, self.kc = rungs, budget, kc
        self.stats = {i: {"pulls": 0, "reward": 0.0, "cost": 0.0}
                      for i in range(1, len(rungs))}
        self.spent = 0.0

    def choose(self) -> int:
        # Thompson 采样（Beta 近似归一奖励）；先验偏保守
        import random
        best, best_sample = None, float("-inf")
        for i in self.stats:
            s = self.stats[i]
            mean = (s["reward"] + 1.0) / (s["pulls"] + 2.0)
            sample = random.betavariate(mean * 4, (1 - mean) * 4 + 1e-9)
            if sample > best_sample:
                best, best_sample = i, sample
        return best

    def register_pull(self, i: int, delta_cr: float, cost: float):
        self.stats[i]["pulls"] += 1
        self.stats[i]["reward"] += delta_cr
        self.stats[i]["cost"] += cost
        self.spent += cost

    def kill_check(self, metrics: dict) -> str | None:
        if metrics["mvc_live"] < self.kc["L_min"] and self.spent > self.kc["B0"]:
            return "KC1: MVC 无法在预算内达到 L_min"
        if metrics["absence_hallucination"] > self.kc["eps_abs"]:
            return "KC2: 缺席幻觉超阈，撤销 CAC rung"
        if metrics["overhead_ratio"] > self.kc["rho"]:
            return "KC3: 证书开销比超阈"
        if metrics["max_starve"] > self.kc["T_starve"]:
            return "KC4: 饥饿超界，切换分配机制"
        return None

# IP-445 Cross-Agent Evidence Discount (CAED)
# ============================================================
class CrossAgentEvidenceDiscount:
    """外来证据只收缩、不扩张；外来缺席声明不得赎回自由空间"""
    def __init__(self, self_id: str, trust):
        self.self_id, self.trust = self_id, trust

    def contract(self, E_own: 'ExecSet', foreign_evidence) -> 'ExecSet':
        E = E_own
        for ev in foreign_evidence:
            if ev.source == self.self_id:
                continue
            if ev.claims_absence:
                # 关键：外来"无人"声明 NO-OP，绝不扩张
                continue
            # 障碍/风险声明：取交，只能更保守
            E = E.intersect(ev.as_avoidance_constraint())
        return E          # 恒有 E ⊆ E_own


# ============================================================
# IP-446 Starvation Guard & Fairness Floor (SGF)
# ============================================================
class StarvationGuard:
    def __init__(self, T_starve: float, quota_frac: float = 0.1,
                 aging: float = 1.0):
        self.T_starve, self.quota_frac, self.aging = T_starve, quota_frac, aging
        self.last_grant: dict[str, float] = {}
        self.infeasible = False

    def priority(self, agent: str, now: float, base: float) -> float:
        return base + self.aging * (now - self.last_grant.get(agent, 0.0))

    def reserved(self, capacity: float) -> float:
        return self.quota_frac * capacity

    def on_grant(self, allocations, now: float):
        for a in allocations:
            self.last_grant[a] = now

    def fair(self, agent: str, now: float) -> bool:
        return now - self.last_grant.get(agent, 0.0) <= self.T_starve

    def check_infeasible(self, agents, min_demand: dict, capacity: float) -> bool:
        if sum(min_demand[a] for a in agents) > capacity:
            self.infeasible = True
            return True
        return False


# ============================================================
# IP-447 MVP Gate (HPC-M)
# ============================================================
class HPCM:
    def __init__(self, hpc_e_plus, ladder, sfdc, sgf, casc):
        self.hpc_e_plus, self.ladder = hpc_e_plus, ladder
        self.sfdc, self.sgf, self.casc = sfdc, sgf, casc
        self.active = 0
        self.K_star = frozenset()

    def admits(self, agent, plan, contest_out, now, env) -> bool:
        rung = self.ladder[self.active]
        E = rung.exec_set[agent]
        return (
            self.hpc_e_plus.admits(plan, env)                    # v23 全链
            and self.K_star <= set(rung.modules)                 # MVP 地基在位
            and self.sfdc.floor_intact(rung.modules)             # 删除证书仍有效
            and plan in E                                        # 计划已认证
            and contest_out[agent] in E                          # 竞争输出已认证
            and (self.sgf.fair(agent, now) or self.sgf.infeasible)
        )

## 3. 正确性论证

### 引理 1（SFDC 判定的可靠性，相对运行域 Ω）
**陈述**：若 `SFDC.classify(K, m) = optional`，则在运行域 Ω 与任务分布 `D_task` 上，`E_{closure(K-m)}` 仍 sound 且 `max Live ≥ L_min`；故删除 m 不破坏安全地基与部署可行性。

**证明**：由 `classify` 定义，`optional` 当且仅当 `is_sound(closure(K-m), Ω)` 为真且 `max_live(closure(K-m), D_task) ≥ L_min`。前者直接给出认证集落在 `Safe(Ω)` 内，后者给出活性不跌破下限。删除只减少模块、不引入新的自由空间（release 模块被删只会缩小 `E`），故单调方向安全。∎
> **诚实边界**：该引理只对"Ω 所覆盖的角角"成立；Ω 覆盖不完备时，`optional` 可能是假阴性——这正是本轮最大风险，不在证明里被掩盖。

### 引理 2（MVC 的最小性）
**陈述**：MVCE 返回的 `K*` 满足 `R_floor ⊆ K*`、`E_{K*} ⊆ Safe(Ω)`、`Live(E_{K*}) ≥ L_min`，且对任意 `m ∈ K* \ R_floor`，删除 m 会破坏 soundness 或跌破 L_min（即 `m` 为活性承重）。

**证明**：(1) 初始化取 `R_floor` 的依赖闭包，保证地基在位；(2) 循环每步仅加入通过 `is_sound` 的 release 模块，故终态 sound；(3) 循环条件保证终态 `Live ≥ L_min`；(4) 收尾对每个非地基模块调用 `classify`，仅当返回 `optional` 才删除，故留下的每个非地基模块要么 safety 承重、要么 liveness 承重；(5) 贪心按 `ΔLive/ΔCost` 选模块，配合收尾删除，给出在给定测试口径下的代价最小可行解（非全局最优时可能有多个 Pareto 最小解，算法返回其一）。∎

### 引理 3（能力阶梯的单调与安全不变）
**陈述**：对阶梯 `K_0 ⊂ K_1 ⊂ … ⊂ K_r = M`，恒有 `E_{K_0} ⊆ E_{K_1} ⊆ … ⊆ E_{K_r} = Exec_v23`，且每级 `E_{K_i} ⊆ Safe(Ω)`。

**证明**：归纳。基例 `K_0 = K*` 由引理 2 sound。归纳步：`K_{i+1} = closure(K_i ∪ {m})`，构建时强制 `is_sound(K_{i+1}, Ω)`，故 sound；又 `K_i ⊆ K_{i+1}` 且 release 模块只扩张、restrictor 已在 `R_floor` 中不变，故 `E_{K_i} ⊆ E_{K_{i+1}}`。终级含全 M 即 `Exec_v23`。升级带 `min_dwell` 与在线复核，失败则不前进、回滚到上一有效级，`E` 单调不增，故任何时刻 `Exec_v24 ⊆ E_{K_active} ⊆ Exec_v23`。∎

### 引理 4（竞争不变安全 / 安全不可竞得）
**陈述**：对任意智能体集合、任意报价剖面（含恶意/合谋/虚假报价），`CASC.allocate` 的输出满足 `out[i] ∈ ℰ_i`；因此联合执行安全，且竞价失败者的安全裕度不受影响。

**证明**：`allocate` 第一步过滤 `o.plan ∈ E[a]` 且签名有效，把认证集外的任何 offer 直接丢弃；第二步 `_solve` 只在 `menu` 上做容量可行选择；第三步无分配者取 `fallback(a) ∈ E[a]`（由 P43 保证 SafeStop/hold 在认证集内）。故无论报价如何，输出逐元素落在 `ℰ_i` 中。安全性是**每个计划自带的证书属性**（v23 HPC-E+），与谁赢无关；输赢只改变 `Live`，不改变 `Safe`。签名不可转让（no proxy）阻断"借他人证书竞价"。∎
> 这是**无条件**命题，强于"诚实报价是纳什均衡"：即使参与者完全不诚实，也拿不到安全集之外的执行。

### 引理 5（外来证据单向收缩 / 防投毒）
**陈述**：`CAED.contract(E_own, foreign)` 恒返回 `E ⊆ E_own`；因此外来证据（含伪造的缺席声明）永远无法扩大执行集，只能在最坏情况下缩小它。

**证明**：对每条外来 `ev`：若 `claims_absence`，直接 `continue`（no-op）；否则 `E ← E ∩ Constraint(ev)`。交运算单调递减，故每一步 `E` 只减不增；本地证据是唯一扩张来源。特别地，恶意对手伪造"该区域无人"不能赎回自由空间，伪造"该区域有障碍"最多让我们更保守（活性损失，安全不损）。∎

### 引理 6（有界饥饿与公平下界）
**陈述**：若容量对最小需求可行，则老化机制保证任一智能体在 `T_starve` 内至少获得一次认证分配；若不可行，则签发不可行证书并回退 SafeStop，安全保持。

**证明**：老化优先级 `priority = base + aging·(now - last_grant)` 随等待时间线性增长；对有限个智能体与有限基础优先级，等待足够久者优先级必超过他人，故在有可行分配时最终获配；`T_starve` 取保守上界。保留配额 `quota_frac·C` 进一步保证每类智能体不被完全挤出。若 `Σ min_demand > C`，`check_infeasible` 置位并签发证书，系统回退到认证集内的 SafeStop，安全不受影响、活性诚实归零。∎

### 定理（v24 的完整单调链）
**陈述**：对任意运行时刻，`Exec_v24 = E_{K_active} ∩ Fil_contest ∩ Fil_fair ⊆ E_{K_active} ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`；任意元层失效均向更保守退化。

**证明**：`Fil_contest` 由引理 4 保证是 `∏ℰ_i` 的子集；`Fil_fair` 由引理 6 只做进一步限制；`E_{K_active}` 由引理 3 是 `Exec_v23` 的子集；v23 自身的继承链由 v23 引理 4 给出。失效路径：MVC 失败→`K_floor`（更小）；阶梯失败→冻结/回滚（更小）；CASC 失败→固定优先级（更小）；CAED 失败→拒绝外来证据（更小）；SGF 失败→单机保守（更小）；全失效→v23。∎

## 6. 本轮最大风险（最终确认）

**一句话**：整套 v24 把"能否删"托付给删除证书，而删除证书的完备性又托付给运行域 Ω 的覆盖；竞争压力恰好系统性奖励"在覆盖不足时仍宣布可选"——于是最大的失败不是算错某个阈值，而是**用一个看似严谨的形式化流程，把"还没证明承重"洗成"已证明可选"，让最小可行证书在未建模的角角里悄悄变成最小可撞证书**。
