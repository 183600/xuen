# 第 1 轮（研究线累计；本轮灵感循环第 1 轮）· OPEN-RAPID-DISTILL：从「模型蒸馏」「开源软件」「快速原型」出发，构建一个「模块化、可组合、社区驱动」的快速蒸馏原型系统，实现「分钟级配置、小时级收敛、版本化复现」的蒸馏研发范式

## 0. 先给直觉：为什么蒸馏依然是「炼丹」而非「工程」

当前模型蒸馏面临三个结构性痛点，像三座大山横亘在「大模型落地」与「小模型部署」之间：

> **模型蒸馏**：蒸馏超参数空间极大（Temperature τ、Loss 权重 λ、数据增强策略、课程学习节奏、教师模型选择），且相互强耦合。论文报告的「最佳配置」往往在换数据集、换学生架构、换教师模型时失效。研究者陷入「调 τ → 跑实验 → 等 24h → 看指标 → 改 λ → 重来」的循环，**反馈周期以天计，搜索空间以指数计**。

> **开源软件**：优秀的蒸馏代码散落在 GitHub、HuggingFace、个人主页，**缺乏统一接口、版本化配方、可复现性保障**。一个蒸馏配方包含：教师检查点、学生架构、数据切分、超参数、训练脚本、评测指标、硬件环境。缺少「配方注册表」，导致「别人的 SOTA 跑不起来、自己的改动合不回去、社区经验沉淀不下来」。

> **快速原型**：蒸馏实验需要「完整训练」才能得到反馈，**缺乏「多保真度」的快速验证机制**。若能在 1% 数据、1 个 epoch、小模型代理上 5 分钟得到「相关性指标」，再决定是否投入完整训练，研发效率将提升 10-100 倍。现有框架（如 DistilKit、TextBrewer、KnowledgeDistillation）要么只提供固定配方，要么只做单点实验，**无「配置→原型→评估→迭代」的闭环**。

一句话先给押注：

> **本轮提出 OPEN-RAPID-DISTILL (ORD)：** 以「开源软件工程范式」重构蒸馏研发流程——**模块化蒸馏管线** 实现组件级复用与热插拔，**多保真度贝叶斯优化** 实现分钟级超参数原型验证，**版本化配方注册表** 实现社区级经验沉淀与复现。三大支柱：**可组合管线**、**快速原型引擎**、**开源配方生态**。

三个可验证创新点：

1. **可组合蒸馏管线（Composable Distillation Pipeline, CDP）**：将蒸馏拆解为 6 类标准组件 —— `Teacher`、`Student`、`Data`、`Loss`、`Scheduler`、`Evaluator`，定义统一的 `ComponentSpec` 接口与 `PipelineIR` 中间表示。支持「配置即代码」：一个 YAML 配置完整描述蒸馏实验，组件可独立版本化、独立测试、独立替换。
2. **多保真度快速原型引擎（Multi-Fidelity Rapid Prototyping Engine, MF-RPE）**：引入「保真度阶梯」—— `F0: 代理模型(1%数据, 1epoch, Tiny学生)` → `F1: 小规模(10%数据, 5epoch)` → `F2: 全量`。用**多保真度贝叶斯优化（MF-BO）** 在 F0/F1 上快速筛选超参数，仅对 Top-K 配置投入 F2 完整训练。引入「早停代理指标」：知识迁移率、Logits 相关性、梯度余弦相似度，5 分钟预测最终性能相关性 ρ > 0.85。
3. **版本化配方注册表（Versioned Recipe Registry, VRR）**：蒸馏配方作为「一等公民」纳入版本控制 —— `Recipe = (PipelineIR, Hyperparams, Artifacts, Metrics, Environment)`。支持语义化版本、依赖锁定、复现性哈希、社区评分。集成 Git/GitHub：`ord push recipe` 自动生成复现报告、`ord pull recipe` 一键拉取含环境锁定的完整复现包。

三个词怎么落地：

| 词 | 落地 | 不做什么 |
|---|---|---|
| **模型蒸馏** | CDP 标准化蒸馏组件；MF-RPE 加速超参搜索；VRR 沉淀最佳实践 | 不发明新的蒸馏损失函数；不训练基础模型 |
| **开源软件** | 组件接口标准化；配方版本化；CLI 工具链；社区治理模型 | 不建立中心化平台；不托管模型权重 |
| **快速原型** | 多保真度阶梯；代理指标；早停决策；增量验证 | 不牺牲最终模型质量；不引入近似训练 |

## 1. 研究日志：从「炼丹」到「工程」的范式迁移

### 1.1 当前蒸馏研发的三个「反模式」

```text
A1. 硬编码耦合：教师模型、学生架构、损失函数、数据加载器、训练循环写死在同一个 train.py 中。
A2. 超参盲搜：τ ∈ {1,2,5,10,20}，λ ∈ {0.1,0.5,1,2,5}，数据增强 {无, 强, RandAug} —— 全排列跑，单次 24h，组合爆炸。
A3. 经验流失：最佳配置藏在实验日志、W&B 仪表盘、私有 Notion 里；换人、换环境、换需求即失效。
```

这些反模式的本质：**缺乏「蒸馏研发的软件工程抽象层」**。

### 1.2 三个新的判断

1. **蒸馏管线可标准化为「组件图」**：任何蒸馏实验 = `Teacher → Logits` + `Student → Logits` + `Loss(Teacher_Logits, Student_Logits, GroundTruth)` + `DataIterator` + `Scheduler` + `Evaluator`。这 6 类组件有清晰的输入输出契约，可独立开发、测试、版本化、替换。**CDP 就是这层抽象**。

2. **蒸馏超参数搜索天然适合「多保真度」**：蒸馏的最终指标（如学生模型在验证集上的 Acc/BLEU/F1）与早期代理指标（Logits 相关性、梯度一致性、中间层特征相似度）高度相关。**MF-RPE 利用这种相关性，用廉价低保真评估指引昂贵高保真搜索**。

3. **配方应当像代码一样被管理**：一个蒸馏配方包含：管线结构（IR）、超参数、数据切分哈希、教师检查点引用、学生初始化、训练脚本版本、依赖锁文件、评测指标、硬件环境。**VRR 让配方成为「可版本化、可复现、可组合、可评分」的一等资产**。

### 1.3 与现有工作的关系

| 维度 | 现有框架 | OPEN-RAPID-DISTILL |
|---|---|---|
| 核心抽象 | 固定配方 / 单体训练脚本 | **可组合管线 + 多保真原型 + 版本化配方** |
| 超参搜索 | 手工 / 网格 / 单保真 BO | **多保真 BO + 代理指标早停** |
| 复现性 | 依赖 README / requirements.txt | **配方哈希 + 环境锁定 + 一键复现** |
| 社区协作 | 星标 / Fork / Issue | **配方注册表 + 语义版本 + 依赖图** |
| 研发周期 | 天-周 | **分钟-小时** |

**保留**：PyTorch/HuggingFace 生态、标准蒸馏损失（KL、MSE、Cosine）、标准评测指标。
**升级**：从「写脚本跑实验」升级为「配管线、跑原型、推配方、共享复现」。
**剪枝**：去掉「手工调参」、「环境手工复现」、「经验口口相传」。

## 2. 直觉深化：为什么「开源软件工程」能治愈「蒸馏炼丹」

软件工程三大支柱 —— **模块化**、**版本控制**、**自动化测试** —— 精准对应蒸馏三大痛点：

- **模块化** → CDP：把「教师模型加载方式」、「温度缩放策略」、「损失函数组合」、「数据增强管线」都做成可插拔组件。想换教师？改一行配置。想试新 Loss？写一个 `LossComponent` 子类，注册即用。
- **版本控制** → VRR：配方 = 代码 + 数据 + 环境 + 产物。`ord recipe version 1.2.0` 语义化版本；`ord recipe lock` 生成 `recipe.lock`（含依赖哈希、数据哈希、教师权重哈希）；`ord recipe reproduce 1.2.0` 一键复现。
- **自动化测试** → MF-RPE：每个组件有单元测试；每个管线有集成测试；每个配方有「回归测试」（跑 F0/F1 验证性能不退化）。CI/CD 流水线：`push → lint → unit-test → prototype(F0) → integration-test → publish`。

**核心洞见**：蒸馏不是「训练一个模型」，而是「构建一个可复现、可迭代、可组合的知识转移流水线」。把蒸馏当软件工程做，**才是模型蒸馏走向大规模落地的必经之路**。

## 3. 形式化：OPEN-RAPID-DISTILL 的符号定义

### 3.1 可组合蒸馏管线 CDP

**组件规范**：每个组件 `C` 是一个五元组：
```math
C = (name, version, input_spec, output_spec, implementation)
```
其中 `input_spec`、`output_spec` 为 Pydantic 模型，定义输入输出的张量形状、类型、语义标签。

**六大标准组件类**：
| 组件类 | 语义 | 标准输入 | 标准输出 |
|---|---|---|---|
| `Teacher` | 教师模型前向 | `Batch[Input]` | `Batch[Logits]`, `Batch[HiddenStates]` |
| `Student` | 学生模型前向 | `Batch[Input]` | `Batch[Logits]`, `Batch[HiddenStates]` |
| `Data` | 数据管线 | `SplitSpec` | `DataLoader[Batch[Input, Target]]` |
| `Loss` | 蒸馏损失计算 | `TeacherOut`, `StudentOut`, `Target` | `Scalar[Loss]`, `Dict[AuxMetrics]` |
| `Scheduler` | 训练调度 | `Epoch`, `Step`, `Metrics` | `Dict[Hyperparams]` (lr, τ, λ...) |
| `Evaluator` | 评测指标 | `Model`, `DataLoader` | `Dict[Metrics]` |

**管线中间表示 (PipelineIR)**：有向无环图 `G = (V, E)`，`V` 为组件实例，`E` 为张量流依赖。
```math
PipelineIR = (components: List[ComponentInstance], connections: List[Connection])
```
其中 `Connection = (src_component, src_output, dst_component, dst_input)`。

**实例化与执行**：`PipelineIR` 经 `Compiler` 编译为可执行的 `RunnablePipeline`，支持：
- 拓扑排序执行
- 梯度检查点自动插入
- 分布式并行策略注入（DDP/FSDP/TP）
- 混合精度自动转换

### 3.2 多保真度快速原型引擎 MF-RPE

**保真度阶梯**：定义保真度 `f ∈ {0, 1, ..., F}`，`f=0` 最低（最快），`f=F` 最高（完整训练）。
每个保真度 `f` 对应资源配置 `r_f = (data_frac, epochs, student_size, teacher_precision)`：
```math
r_0 = (0.01, 1, \text{Tiny}, \text{FP16}), \quad
r_1 = (0.1, 5, \text{Small}, \text{FP16}), \quad
r_F = (1.0, 100, \text{Full}, \text{BF16})
```

**代理指标族**：低保真度下计算的「早期信号」，与高保真度最终指标高相关：
```math
\phi_f(\theta) = \{
    \rho_{logits}: \text{Corr}(Teacher\_Logits, Student\_Logits), \\
    \rho_{grad}: \text{CosineSim}(\nabla_\theta L_{teacher}, \nabla_\theta L_{student}), \\
    \rho_{feat}: \text{CKA}(Teacher\_Hidden, Student\_Hidden), \\
    \text{TransferRate}: \frac{Acc_{student} - Acc_{scratch}}{Acc_{teacher} - Acc_{scratch}}
\}
```

**多保真度贝叶斯优化 (MF-BO)**：
- 超参数空间 `Θ`（连续：τ, λ, lr；离散：数据增强策略、Loss 类型）
- 目标：`max_{θ∈Θ} y_F(θ)`，其中 `y_f(θ)` 为保真度 `f` 下的验证指标
- 高斯过程代理：`y_f(θ) ~ GP(μ_f(θ), k_f(θ, θ'))`，核函数建模保真度间相关性：
  ```math
  k_f(θ, θ') = k_{base}(θ, θ') · ρ^{|f-f'|}  （自相关核）
  ```
- 采集函数：`MF-EI(θ, f) = EI_f(θ) / cost(f)`，单位成本期望提升
- 优化循环：每轮选择 `(θ*, f*) = argmax MF-EI`，评估 `y_{f*}(θ*)`，更新 GP

**早停决策规则**：在保真度 `f` 运行 `t` 步后，若代理指标 `ϕ_f(θ)` 满足：
```math
P( y_F(θ) > y_{best} | ϕ_f(θ), D_{1:t} ) < δ  （δ=0.1）
```
则提前终止该配置，释放资源。该概率由 GP 后验预测分布给出。

### 3.3 版本化配方注册表 VRR

**配方实体**：
```math
Recipe = (metadata, pipeline_ir, hyperparams, artifacts, metrics, environment, lineage)
```
- `metadata`：`name`, `version` (SemVer), `description`, `tags`, `authors`, `license`
- `pipeline_ir`：`PipelineIR` 序列化（JSON/YAML），含组件版本引用
- `hyperparams`：完整超参数字典（含保真度阶梯配置）
- `artifacts`：`{teacher_ckpt: hash, student_init: hash, checkpoints: [hash], final_model: hash}`
- `metrics`：`{fidelity: {metric: value}}` 多保真度评测结果
- `environment`：`requirements.lock` (pip), `conda-lock.yml`, `docker.digest`, `cuda_version`, `gpu_type`
- `lineage`：`parent_recipes: [RecipeRef]`, `forked_from: RecipeRef`, `experiments: [ExpRef]`

**配方哈希（复现性指纹）**：
```math
H(Recipe) = SHA256( pipeline_ir || hyperparams || data_split_hash || teacher_ckpt_hash || environment_lock_hash )
```
两个配方 `H` 相同 ⇔ 位级复现。

**注册表操作语义**：
| 操作 | 语义 |
|---|---|
| `ord recipe init` | 交互式创建 `recipe.yaml` 骨架 |
| `ord recipe validate` | 类型检查 IR、依赖解析、环境一致性校验 |
| `ord recipe run [--fidelity f]` | 编译 IR → 执行管线 → 产出 artifacts/metrics |
| `ord recipe lock` | 生成 `recipe.lock`（锁定所有传递依赖哈希） |
| `ord recipe push [--registry]` | 推送到注册表（Git 仓库 / OCI Registry / 本地） |
| `ord recipe pull <name>@<version>` | 拉取配方 + `recipe.lock` + 可选 artifacts |
| `ord recipe reproduce <name>@<version>` | 一键复现：建环境 → 拉数据 → 跑完整流程 → 校验哈希 |

**社区治理模型**：
- 配方采用 **语义化版本**：`MAJOR`（破坏性接口变更）、`MINOR`（新增组件/指标兼容）、`PATCH`（Bugfix/超参微调）
- **依赖图**：`ord recipe deps <name>@<version>` 可视化上下游依赖
- **评分系统**：社区对配方打分（复现性、性能、文档质量），Top 配方进入「官方精选」

### 4.1 CDP 组件开发规范与编译器

```python
# cdp/component.py
from abc import ABC, abstractmethod
from pydantic import BaseModel
from typing import Generic, TypeVar

T_In = TypeVar('T_In')
T_Out = TypeVar('T_Out')

class ComponentSpec(BaseModel):
    name: str
    version: str
    input_spec: type  # Pydantic model
    output_spec: type
    config_schema: type  # Pydantic model for hyperparams

class Component(ABC, Generic[T_In, T_Out]):
    spec: ComponentSpec
    
    @abstractmethod
    def forward(self, input: T_In, config: dict) -> T_Out:
        pass
    
    @abstractmethod
    def get_parameters(self) -> Iterator[nn.Parameter]:
        pass

# 标准组件基类
class TeacherComponent(Component[BatchInput, TeacherOutput]):
    def forward(self, batch: BatchInput, config: dict) -> TeacherOutput:
        with torch.no_grad():
            logits = self.model(batch.input_ids, **batch.kwargs)
            hidden = self.model.get_hidden_states() if config.get('output_hidden') else None
        return TeacherOutput(logits=logits, hidden_states=hidden)

class LossComponent(Component[LossInput, LossOutput]):
    def forward(self, input: LossInput, config: dict) -> LossOutput:
        # config 包含：temperature, alpha_ce, alpha_kl, alpha_mse, loss_type
        loss_kl = F.kl_div(
            F.log_softmax(input.student_logits / config['temperature'], dim=-1),
            F.softmax(input.teacher_logits / config['temperature'], dim=-1),
            reduction='batchmean'
        ) * (config['temperature'] ** 2)
        loss_ce = F.cross_entropy(input.student_logits, input.targets)
        total = config['alpha_kl'] * loss_kl + config['alpha_ce'] * loss_ce
        return LossOutput(loss=total, aux={'kl': loss_kl, 'ce': loss_ce})
```

```python
# cdp/compiler.py
class PipelineCompiler:
    def compile(self, ir: PipelineIR) -> RunnablePipeline:
        # 1. 拓扑排序
        topo_order = self._topological_sort(ir.components, ir.connections)
        # 2. 构建执行图：节点 = 组件实例，边 = 张量传递
        exec_graph = ExecutionGraph()
        for comp_spec in topo_order:
            comp_instance = self._instantiate_component(comp_spec)
            exec_graph.add_node(comp_spec.name, comp_instance)
        for conn in ir.connections:
            exec_graph.add_edge(conn.src, conn.dst, conn.src_output, conn.dst_input)
        # 3. 注入运行时优化：梯度检查点、混合精度、分布式包装
        exec_graph = self._inject_optimizations(exec_graph)
        return RunnablePipeline(exec_graph)
```

### 4.2 MF-RPE 多保真度贝叶斯优化核心

```python
# mfrpe/optimizer.py
import numpy as np
from sklearn.gaussian_process import GaussianProcessRegressor
from sklearn.gaussian_process.kernels import Matern, WhiteKernel

class MultiFidelityBO:
    def __init__(self, param_space: ParamSpace, fidelity_configs: List[FidelityConfig],
                 proxy_metrics: List[str], cost_model: Callable[[int], float]):
        self.param_space = param_space
        self.fidelity_configs = fidelity_configs  # List[FidelityConfig]
        self.proxy_metrics = proxy_metrics
        self.cost_model = cost_model
        self.F = len(fidelity_configs) - 1
        
        # 多保真度 GP：每个保真度一个 GP，共享核参数
        self.gps = [self._make_gp() for _ in range(self.F + 1)]
        self.history = []  # List[(theta, fidelity, y, proxies)]
    
    def _make_gp(self):
        kernel = Matern(nu=2.5) * ConstantKernel() + WhiteKernel()
        return GaussianProcessRegressor(kernel=kernel, normalize_y=True, n_restarts_optimizer=5)
    
    def suggest(self, n_suggestions: int = 1) -> List[Tuple[Dict, int]]:
        """返回 (theta, fidelity) 对，最大化单位成本 EI"""
        candidates = self.param_space.sample(1000)  # 随机采样候选
        best = []
        for theta in candidates:
            for f in range(self.F + 1):
                ei = self._expected_improvement(theta, f)
                cost = self.cost_model(f)
                mf_ei = ei / cost if cost > 0 else 0
                best.append((mf_ei, theta, f))
        best.sort(reverse=True)
        return [(theta, f) for _, theta, f in best[:n_suggestions]]
    
    def _expected_improvement(self, theta: Dict, f: int) -> float:
        # 使用 GP 后验预测最高保真度 F 的分布
        # 这里简化：用保真度 f 的 GP 直接预测，实际应用中用协同核
        gp = self.gps[f]
        X = np.array([self._theta_to_vec(t) for t, _, _, _ in self.history if _ == f])
        y = np.array([y for _, _, y, _ in self.history if _ == f])
        if len(X) < 2:
            return 1.0  # 无数据时鼓励探索
        gp.fit(X, y)
        mu, sigma = gp.predict(self._theta_to_vec(theta).reshape(1, -1), return_std=True)
        y_best = max(y) if len(y) > 0 else 0
        if sigma == 0:
            return 0.0
        z = (mu - y_best) / sigma
        ei = sigma * (z * norm.cdf(z) + norm.pdf(z))
        return float(ei)
    
    def update(self, theta: Dict, fidelity: int, y: float, proxies: Dict[str, float]):
        self.history.append((theta, fidelity, y, proxies))
        # 定期重拟合所有 GP
        if len(self.history) % 10 == 0:
            self._refit_all()
    
    def should_early_stop(self, theta: Dict, fidelity: int, proxies: Dict, 
                          y_best_global: float, delta: float = 0.1) -> bool:
        """基于代理指标预测最终性能是否可能超越当前最优"""
        if fidelity == self.F:
            return False
        # 简单规则：若代理指标均低于阈值，提前停止
        proxy_score = np.mean([proxies.get(p, 0) for p in self.proxy_metrics])
        # 校准：从历史数据拟合 proxy_score -> y_F 的回归
        if hasattr(self, '_proxy_calibrator') and self._proxy_calibrator is not None:
            pred_yF, pred_std = self._proxy_calibrator.predict(proxy_score)
            prob_better = 1 - norm.cdf((y_best_global - pred_yF) / pred_std)
            return prob_better < delta
        return proxy_score < 0.3  # 启发式阈值
```

```python
        recipe, lock = self.pull(name, version)
```

## 5. 性质、复杂度与正确性

### 5.1 CDP 编译正确性

**命题（管线等价性）**：对任意合法 `PipelineIR`，`Compiler.compile(IR)` 产出的 `RunnablePipeline` 在数学上等价于按拓扑顺序显式执行各组件的 `forward`。

**证明**：编译器仅做三件事：(1) 拓扑排序 —— 保证数据依赖顺序不变；(2) 张量传递重写 —— 将显式变量传递改为图边传递，语义不变；(3) 运行时优化注入 —— 梯度检查点、混合精度、分布式包装均为数学等价变换（梯度检查点利用重计算交换显存与算力，混合精度利用 FP32 累加保证数值稳定性，分布式包装利用 AllReduce 保证梯度一致性）。故编译前后计算图同构，前向与反向传播数学等价。∎

### 5.2 MF-BO 收敛性

**命题（多保真度 BO 无遗憾收敛）**：设目标函数 `y_F(θ)` 在紧致域 `Θ` 上连续，代理函数 `y_f(θ)` 满足 `|y_f(θ) - y_F(θ)| ≤ ε_f` 且 `ε_f → 0` 随 `f → F`。MF-BO 使用协同核 GP 与 `MF-EI` 采集函数，则累积遗憾 `R_T = O(√(T γ_T))`，其中 `γ_T` 为最大信息增益。

**证明**：将多保真度 BO 归约为带成本的单保真度 BO。定义增广空间 `Θ' = Θ × {0,...,F}`，目标 `y'(θ,f) = y_f(θ)`，成本 `c(θ,f) = cost(f)`。`MF-EI(θ,f) = EI_f(θ)/c(θ,f)` 等价于单位成本 EI。由 [Kandasamy et al., 2016] 多保真度 BO 理论，若核函数建模保真度间相关性（自相关核 `k((θ,f),(θ',f')) = k_base(θ,θ')·ρ^{|f-f'|}`），且 `ρ > 0`，则 GP 后验在增广空间上一致收敛。累积遗憾界遵循标准 BO 分析。∎

### 5.3 VRR 复现性保证

**命题（位级复现）**：若两次执行 `ord recipe reproduce name@version` 使用相同的 `recipe.lock`，且硬件确定性计算（CUDA 确定性模式、固定随机种子），则产出的最终模型权重逐比特相同。

**证明**：`recipe.lock` 锁定：(1) 传递依赖版本哈希 → 代码位级相同；(2) 数据切分哈希 → 训练数据顺序位级相同；(3) 教师检查点哈希 → 教师权重位级相同；(4) 学生初始化哈希 → 初始权重位级相同；(5) 超参数字典 → 训练动态位级相同。在确定性计算模式下（`torch.use_deterministic_algorithms=True`，`CUBLAS_WORKSPACE_CONFIG=:4096:8`），PyTorch 保证相同输入产生相同输出。故全流程位级复现。∎

### 1.3 MF-RPE 多保真度贝叶斯优化

**保真度阶梯**：
```
f=0 (F0): data_frac=0.01, epochs=1, student=Tiny, precision=FP16  → ~5 min
f=1 (F1): data_frac=0.10, epochs=5, student=Small, precision=FP16  → ~30 min
f=2 (F2): data_frac=1.00, epochs=50, student=Full, precision=BF16  → ~4 hours
```

**协同核高斯过程**：
```math
k((θ, f), (θ', f')) = k_{Matern}(θ, θ') · ρ^{|f-f'|} + δ_{f,f'} · σ^2_{noise}
```
其中 `ρ ∈ (0,1)` 为保真度间相关性超参数。

**单位成本期望提升 (MF-EI)**：
```math
α_{MF-EI}(θ, f) = \frac{EI_f(θ)}{cost(f)} = \frac{σ_f(θ) · (z Φ(z) + φ(z))}{cost(f)}
```
其中 `z = (μ_f(θ) - y_{best}) / σ_f(θ)`，`cost(f)` 为保真度 `f` 的预估 GPU 小时数。

**早停判据**：
```math
\text{Stop}(θ, f) \iff P(y_F(θ) > y_{best} | ϕ_f(θ), D) < δ \quad (δ=0.1)
```
由代理指标回归模型 `y_F | ϕ_f ~ N(μ_{cal}(ϕ_f), σ^2_{cal}(ϕ_f))` 给出。

```python
            loss=total,
```

```python
    name: str
    component: Component
    config: Dict
    inputs: Dict[str, Any] = field(default_factory=dict)
    outputs: Dict[str, Any] = field(default_factory=dict)

class PipelineCompiler:
    def __init__(self, component_registry: 'ComponentRegistry'):
        self.registry = component_registry
    
    def compile(self, ir: PipelineIR) -> 'RunnablePipeline':
        # 1. 实例化组件
        nodes = {}
        for name, spec, config in ir.components:
            comp_cls = self.registry.get(spec.name, spec.version)
            component = comp_cls(**config.get('init_args', {}))
            component.spec = spec
            nodes[name] = ExecutionNode(name, component, config)
        
        # 2. 构建依赖图
        in_degree = defaultdict(int)
        adj = defaultdict(list)
        for conn in ir.connections:
            adj[conn.src].append((conn.dst, conn.src_output, conn.dst_input))
            in_degree[conn.dst] += 1
        
        # 3. 拓扑排序
        queue = deque([n for n in nodes if in_degree[n] == 0])
        topo_order = []
        while queue:
            u = queue.popleft()
            topo_order.append(u)
            for v, src_out, dst_in in adj[u]:
                in_degree[v] -= 1
                if in_degree[v] == 0:
                    queue.append(v)
        
        if len(topo_order) != len(nodes):
            raise ValueError("PipelineIR contains cycle")
        
        # 4. 注入运行时优化
        optimized_nodes = self._inject_optimizations(nodes, topo_order)
        
        return RunnablePipeline(optimized_nodes, topo_order, adj)
    
    def _inject_optimizations(self, nodes: Dict, topo_order: List) -> Dict:
        """注入梯度检查点、混合精度、分布式包装"""
        optimized = {}
        for name in topo_order:
            node = nodes[name]
            comp = node.component
            
            # 梯度检查点：针对大模型组件
            if hasattr(comp, 'enable_gradient_checkpointing'):
                comp.enable_gradient_checkpointing()
            
            # 混合精度：自动包装 forward
            if node.config.get('amp', True):
                original_forward = comp.forward
                @torch.autocast(device_type='cuda', dtype=torch.bfloat16)
                def amp_forward(self, inp, cfg):
                    return original_forward(inp, cfg)
                comp.forward = amp_forward.__get__(comp, type(comp))
            
            optimized[name] = node
        return optimized

class RunnablePipeline:
    def __init__(self, nodes: Dict[str, ExecutionNode], topo_order: List[str], adj: Dict):
        self.nodes = nodes
        self.topo_order = topo_order
        self.adj = adj
    
    def forward(self, batch: BatchInput, global_config: Dict) -> Dict[str, Any]:
        """执行完整前向传播"""
        # 初始化输入
        self.nodes[self.topo_order[0]].inputs['batch'] = batch
        
        for name in self.topo_order:
            node = self.nodes[name]
            # 准备组件输入
            comp_input = self._prepare_component_input(node)
            # 前向
            output = node.component.forward(comp_input, node.config)
            node.outputs = output.dict() if hasattr(output, 'dict') else {'out': output}
            # 传递给下游
            for dst, src_out, dst_in in self.adj[name]:
                self.nodes[dst].inputs[dst_in] = node.outputs[src_out]
        
        return {name: node.outputs for name, node in self.nodes.items()}
    
    def _prepare_component_input(self, node: ExecutionNode):
        """根据组件 input_spec 组装输入"""
        spec = node.component.spec.input_spec
        fields = spec.__fields__ if hasattr(spec, '__fields__') else {}
        kwargs = {}
        for field_name, field_info in fields.items():
            if field_name in node.inputs:
                kwargs[field_name] = node.inputs[field_name]
        return spec(**kwargs)
```

```python
# mfrpe/optimizer.py
import numpy as np
from typing import Dict, List, Tuple, Callable, Optional, Any
from dataclasses import dataclass
from sklearn.gaussian_process import GaussianProcessRegressor
from sklearn.gaussian_process.kernels import Matern, ConstantKernel, WhiteKernel
from scipy.stats import norm
import torch

@dataclass
class FidelityConfig:
    name: str
    data_frac: float
    epochs: int
    student_size: str  # 'tiny', 'small', 'full'
    precision: str     # 'fp16', 'bf16'
    estimated_gpu_hours: float

@dataclass
class ParamSpace:
    continuous: Dict[str, Tuple[float, float]]  # name -> (low, high)
    categorical: Dict[str, List[Any]]           # name -> [choices]
    
    def sample(self, n: int) -> List[Dict]:
        samples = []
        for _ in range(n):
            theta = {}
            for name, (low, high) in self.continuous.items():
                theta[name] = np.random.uniform(low, high)
            for name, choices in self.categorical.items():
                theta[name] = np.random.choice(choices)
            samples.append(theta)
        return samples
    
    def to_vec(self, theta: Dict) -> np.ndarray:
        vec = []
        for name in sorted(self.continuous.keys()):
            vec.append(theta[name])
        for name in sorted(self.categorical.keys()):
            choices = self.categorical[name]
            vec.append(choices.index(theta[name]))
        return np.array(vec)
    
    def from_vec(self, vec: np.ndarray) -> Dict:
        theta = {}
        idx = 0
        for name in sorted(self.continuous.keys()):
            theta[name] = float(vec[idx]); idx += 1
        for name in sorted(self.categorical.keys()):
            choices = self.categorical[name]
            theta[name] = choices[int(vec[idx])]; idx += 1
        return theta

class MultiFidelityBO:
    def __init__(self, 
                 param_space: ParamSpace,
                 fidelity_configs: List[FidelityConfig],
                 proxy_metrics: List[str],
                 cost_model: Callable[[int], float],
                 rho_init: float = 0.8):
        self.param_space = param_space
        self.fidelity_configs = fidelity_configs
        self.F = len(fidelity_configs) - 1
        self.proxy_metrics = proxy_metrics
        self.cost_model = cost_model
        
        # 多保真度 GP：每个保真度一个 GP
        self.gps = [self._make_gp() for _ in range(self.F + 1)]
        self.history = []  # List[(theta_vec, fidelity, y, proxies_dict)]
        self.rho = rho_init
        self._proxy_calibrator = None
    
    def _make_gp(self):
        kernel = ConstantKernel() * Matern(nu=2.5) + WhiteKernel(noise_level=1e-6)
        return GaussianProcessRegressor(
            kernel=kernel, normalize_y=True, 
            n_restarts_optimizer=5, random_state=42
        )
    
    def suggest(self, n_suggestions: int = 1) -> List[Tuple[Dict, int]]:
        candidates = self.param_space.sample(2000)
        scored = []
        for theta in candidates:
            theta_vec = self.param_space.to_vec(theta)
            for f in range(self.F + 1):
                ei = self._expected_improvement(theta_vec, f)
                cost = self.cost_model(f)
                mf_ei = ei / cost if cost > 0 else 0
                scored.append((mf_ei, theta, f))
        scored.sort(reverse=True, key=lambda x: x[0])
        return [(theta, f) for _, theta, f in scored[:n_suggestions]]
    
    def _expected_improvement(self, theta_vec: np.ndarray, f: int) -> float:
        gp = self.gps[f]
        X_f = np.array([h[0] for h in self.history if h[1] == f])
        y_f = np.array([h[2] for h in self.history if h[1] == f])
        if len(X_f) < 2:
            return 1.0
        gp.fit(X_f, y_f)
        mu, sigma = gp.predict(theta_vec.reshape(1, -1), return_std=True)
        y_best = max(y_f) if len(y_f) > 0 else 0
        if sigma[0] < 1e-8:
            return 0.0
        z = (mu[0] - y_best) / sigma[0]
        ei = sigma[0] * (z * norm.cdf(z) + norm.pdf(z))
        return float(ei)
    
    def update(self, theta: Dict, fidelity: int, y: float, proxies: Dict[str, float]):
        theta_vec = self.param_space.to_vec(theta)
        self.history.append((theta_vec, fidelity, y, proxies))
        # 定期重拟合并更新代理校准器
        if len(self.history) % 5 == 0:
            self._refit_all()
            self._update_proxy_calibrator()
    
    def _refit_all(self):
        for f in range(self.F + 1):
            X_f = np.array([h[0] for h in self.history if h[1] == f])
            y_f = np.array([h[2] for h in self.history if h[1] == f])
            if len(X_f) >= 2:
                self.gps[f].fit(X_f, y_f)
    
    def _update_proxy_calibrator(self):
        """拟合 proxy_metrics -> y_F 的回归模型"""
        # 收集所有已完成 F2 的数据点
        X_proxy = []
        y_F = []
        for h in self.history:
            if h[1] == self.F:
                proxies = h[3]
                proxy_vec = [proxies.get(p, 0) for p in self.proxy_metrics]
                X_proxy.append(proxy_vec)
                y_F.append(h[2])
        if len(X_proxy) >= 3:
            from sklearn.linear_model import BayesianRidge
            self._proxy_calibrator = BayesianRidge()
            self._proxy_calibrator.fit(X_proxy, y_F)
    
    def should_early_stop(self, theta: Dict, fidelity: int, proxies: Dict[str, float],
                          y_best_global: float, delta: float = 0.1) -> bool:
        if fidelity == self.F:
            return False
        if self._proxy_calibrator is None:
            # 启发式：代理指标均值过低则停止
            proxy_score = np.mean([proxies.get(p, 0) for p in self.proxy_metrics])
            return proxy_score < 0.25
        proxy_vec = np.array([[proxies.get(p, 0) for p in self.proxy_metrics]])
        pred_yF, pred_std = self._proxy_calibrator.predict(proxy_vec, return_std=True)
        prob_better = 1 - norm.cdf((y_best_global - pred_yF[0]) / max(pred_std[0], 1e-6))
        return prob_better < delta
```

```python
# vrr/recipe.py
from dataclasses import dataclass, field, asdict
from typing import Dict, List, Optional, Any
from pathlib import Path
import hashlib, yaml, json, subprocess, dataclasses

class Recipe:

    pipeline_ir: Dict  # PipelineIR 序列化为 dict
    hyperparams: Dict[str, Any]
    artifacts: Artifacts = field(default_factory=Artifacts)
    metrics: Dict[int, Dict[str, float]] = field(default_factory=dict)  # fidelity -> metrics

        parts = [
            yaml.dump(self.pipeline_ir, sort_keys=True, Dumper=yaml.SafeDumper),
            json.dumps(self.hyperparams, sort_keys=True, separators=(',', ':')),
            self.environment.data_split_hash,
            self.artifacts.teacher_ckpt_hash,
            self.environment.lock_hash
        ]
        content = '|'.join(parts)
        return hashlib.sha256(content.encode()).hexdigest()[:16]

            hyperparams=data['hyperparams'],

class RecipeRegistry:
    def __init__(self, root: Path, remote: Optional[str] = None):
        self.root = Path(root)
        self.root.mkdir(parents=True, exist_ok=True)
        self.remote = remote
    
    def _recipe_path(self, name: str, version: str) -> Path:
        return self.root / name / version
    
    def validate(self, recipe: Recipe) -> List[str]:
        errors = []
        # 1. 版本格式检查
        import re
        if not re.match(r'^\d+\.\d+\.\d+(-[a-zA-Z0-9.-]+)?$', recipe.metadata.version):
            errors.append(f"Invalid version format: {recipe.metadata.version}")
        # 2. 必填字段
        if not recipe.pipeline_ir:
            errors.append("Missing pipeline_ir")
        if not recipe.hyperparams:
            errors.append("Missing hyperparams")
        if not recipe.environment.data_split_hash:
            errors.append("Missing data_split_hash")
        if not recipe.artifacts.teacher_ckpt_hash:
            errors.append("Missing teacher_ckpt_hash")
        return errors
    
    def _generate_lock(self, recipe: Recipe) -> LockFile:
        # 1. 读取 requirements.lock
        req_lock = Path('requirements.lock').read_text() if Path('requirements.lock').exists() else ''
        req_hash = hashlib.sha256(req_lock.encode()).hexdigest()
        
        # 2. 读取 conda-lock.yml
        conda_lock = Path('conda-lock.yml').read_text() if Path('conda-lock.yml').exists() else ''
        conda_hash = hashlib.sha256(conda_lock.encode()).hexdigest()
        
        # 3. 解析依赖版本
        deps = {}
        for line in req_lock.split('\n'):
            if '==' in line:
                pkg, ver = line.split('==', 1)
                deps[pkg.strip()] = ver.strip()
        
        # 4. 计算环境组合哈希
        env_parts = [req_hash, conda_hash, recipe.environment.data_split_hash]
        lock_hash = hashlib.sha256('|'.join(env_parts).encode()).hexdigest()[:16]
        
        return LockFile(
            recipe_hash=recipe.compute_hash(),
            dependencies=deps,
            conda_lock=conda_hash,
            pip_lock=req_hash,
            generated_at=datetime.utcnow().isoformat()
        )
    
    def push(self, recipe: Recipe, remote: Optional[str] = None):
        errors = self.validate(recipe)
        if errors:
            raise ValueError(f"Recipe validation failed: {errors}")
        
        lock = self._generate_lock(recipe)
        path = self._recipe_path(recipe.metadata.name, recipe.metadata.version)
        path.mkdir(parents=True, exist_ok=True)
        
        (path / 'recipe.yaml').write_text(recipe.to_yaml())
        (path / 'recipe.lock').write_text(lock.to_yaml())
        
        # 更新索引
        self._update_index(recipe.metadata.name, recipe.metadata.version, recipe.compute_hash())
        
        # 可选推送到远程
        target_remote = remote or self.remote
        if target_remote:
            self._push_to_remote(path, target_remote)
    
    def pull(self, name: str, version: str) -> Tuple[Recipe, LockFile]:
        path = self._recipe_path(name, version)
        if not path.exists():
            # 尝试从远程拉取
            if self.remote:
                self._pull_from_remote(name, version, self.remote)
            else:
                raise FileNotFoundError(f"Recipe {name}@{version} not found locally")
        
        recipe = Recipe.from_yaml((path / 'recipe.yaml').read_text())
        lock = LockFile.from_yaml((path / 'recipe.lock').read_text())
        return recipe, lock
    
    def reproduce(self, name: str, version: str, fidelity: int = -1) -> Dict[str, float]:
        recipe, lock = self.pull(name, version)
        
        # 1. 校验环境
        self._verify_environment(lock)
        
        # 2. 编译管线
        from cdp.compiler import PipelineCompiler, PipelineIR
        ir = PipelineIR(**recipe.pipeline_ir)
        pipeline = PipelineCompiler(ComponentRegistry.global_registry()).compile(ir)
        
        # 3. 运行
        from cdp.runner import PipelineRunner
        runner = PipelineRunner(pipeline, recipe.hyperparams, lock)
        target_fidelity = fidelity if fidelity >= 0 else len(recipe.hyperparams.get('fidelity_ladder', [])) - 1
        metrics = runner.run(fidelity=target_fidelity)
        
        # 4. 校验产物哈希
        if target_fidelity == len(recipe.hyperparams.get('fidelity_ladder', [])) - 1:
            final_hash = self._compute_model_hash(runner.final_model_path)
            if final_hash != recipe.artifacts.final_model_hash:
                raise RuntimeError(f"Reproduction hash mismatch: got {final_hash}, expected {recipe.artifacts.final_model_hash}")
        
        return metrics
    
    def _verify_environment(self, lock: LockFile):
        """校验当前环境与 lock 一致"""
        # 检查 pip 依赖
        import pkg_resources
        for pkg, expected_ver in lock.dependencies.items():
            try:
                installed = pkg_resources.get_distribution(pkg).version
                if installed != expected_ver:
                    raise RuntimeError(f"Dependency mismatch: {pkg} installed={installed}, locked={expected_ver}")
            except pkg_resources.DistributionNotFound:
                raise RuntimeError(f"Missing dependency: {pkg}")
        # 检查 CUDA
        import torch
        if torch.version.cuda != lock.cuda_version.split('.')[0] + '.' + lock.cuda_version.split('.')[1]:
            print(f"Warning: CUDA version mismatch (locked={lock.cuda_version}, current={torch.version.cuda})")
    
    def _update_index(self, name: str, version: str, recipe_hash: str):
        index_path = self.root / 'index.yaml'
        index = {}
        if index_path.exists():
            index = yaml.safe_load(index_path.read_text()) or {}
        if name not in index:
            index[name] = {}
        index[name][version] = {'hash': recipe_hash, 'pushed_at': datetime.utcnow().isoformat()}
        index_path.write_text(yaml.dump(index, sort_keys=True))
    
    def _push_to_remote(self, local_path: Path, remote: str):
        if remote.startswith('git:'):
            repo_url = remote[4:]
            subprocess.run(['git', 'add', str(local_path.relative_to(self.root))], cwd=self.root, check=True)
            subprocess.run(['git', 'commit', '-m', f'Add recipe {local_path.name}'], cwd=self.root, check=True)
            subprocess.run(['git', 'push', repo_url], cwd=self.root, check=True)
        elif remote.startswith('s3:') or remote.startswith('oss:'):
            # AWS S3 / 阿里云 OSS 上传
            pass
    
    def _pull_from_remote(self, name: str, version: str, remote: str):
        if remote.startswith('git:'):
            repo_url = remote[4:]
            subprocess.run(['git', 'clone', '--depth', '1', '--branch', 'main', repo_url, str(self.root)], check=False)
```

### 2.4 端到端运行器与代理指标计算

```python
# cdp/runner.py
from dataclasses import dataclass
from typing import Dict, List, Any, Optional
import torch
import torch.nn as nn
from torch.utils.data import DataLoader
import numpy as np

@dataclass
class FidelityRunner:
    pipeline: 'RunnablePipeline'
    hyperparams: Dict
    lock: 'LockFile'
    fidelity_configs: List['FidelityConfig']
    
    def run(self, fidelity: int) -> Dict[str, float]:
        fc = self.fidelity_configs[fidelity]
        
        # 1. 构建数据加载器（按 data_frac 采样）
        train_loader = self._build_dataloader('train', fc.data_frac)
        val_loader = self._build_dataloader('val', 1.0)
        
        # 2. 获取学生模型（按 student_size）
        student = self._get_student_model(fc.student_size)
        
        # 3. 精度设置
        dtype = torch.float16 if fc.precision == 'fp16' else torch.bfloat16
        
        # 4. 优化器与调度器
        optimizer = torch.optim.AdamW(student.parameters(), lr=self.hyperparams.get('lr', 2e-5))
        scheduler = self._build_scheduler(optimizer, fc.epochs)
        
        # 5. 训练循环
        best_val = 0
        for epoch in range(fc.epochs):
            train_metrics = self._train_epoch(student, train_loader, optimizer, scheduler, dtype, epoch, fc)
            val_metrics = self._evaluate(student, val_loader, dtype)
            
            # 计算代理指标（仅 F0/F1）
            if fidelity < len(self.fidelity_configs) - 1:
                proxies = self._compute_proxy_metrics(student, val_loader, dtype)
                train_metrics.update(proxies)
            
            if val_metrics.get('acc', 0) > best_val:
                best_val = val_metrics['acc']
                self._save_checkpoint(student, f'best_f{fidelity}.pt')
        
        # 6. 最终评测
        final_metrics = self._evaluate(student, val_loader, dtype)
        if fidelity == len(self.fidelity_configs) - 1:
            self.final_model_path = self._save_final(student)
            final_metrics['model_hash'] = self._compute_model_hash(self.final_model_path)
        
        return final_metrics
    
    def _compute_proxy_metrics(self, student: nn.Module, val_loader: DataLoader, dtype: torch.dtype) -> Dict[str, float]:
        """计算 Logits 相关性、梯度余弦、CKA、迁移率"""
        student.eval()
        teacher = self._get_teacher_model()
        teacher.eval()
        
        logits_corrs = []
        grad_coss = []
        ckas = []
        
        for batch in val_loader:
            batch = {k: v.cuda() for k, v in batch.items()}
            
            with torch.no_grad():
                t_out = teacher(**batch)
                t_logits = t_out.logits.float()
            
            s_out = student(**batch)
            s_logits = s_out.logits.float()
            
            # Logits 相关性
            corr = torch.corrcoef(torch.stack([t_logits.flatten(), s_logits.flatten()]))[0,1]
            logits_corrs.append(corr.item())
            
            # CKA (最后一层隐藏状态)
            if hasattr(t_out, 'hidden_states') and hasattr(s_out, 'hidden_states'):
                t_h = t_out.hidden_states[-1].float()
                s_h = s_out.hidden_states[-1].float()
                cka = self._linear_cka(t_h, s_h)
                ckas.append(cka)
            
            # 梯度余弦（需反向传播）
            loss = F.kl_div(F.log_softmax(s_logits, dim=-1), F.softmax(t_logits, dim=-1), reduction='batchmean')
            loss.backward()
            t_grad = torch.cat([p.grad.flatten() for p in teacher.parameters() if p.grad is not None])
            s_grad = torch.cat([p.grad.flatten() for p in student.parameters() if p.grad is not None])
            if t_grad.numel() > 0 and s_grad.numel() > 0:
                cos = F.cosine_similarity(t_grad.unsqueeze(0), s_grad.unsqueeze(0)).item()
                grad_coss.append(cos)
            teacher.zero_grad()
            student.zero_grad()
        
        return {
            'logits_corr': float(np.mean(logits_corrs)),
            'grad_cos': float(np.mean(grad_coss)) if grad_coss else 0.0,
            'cka': float(np.mean(ckas)) if ckas else 0.0
        }
    
    def _linear_cka(self, X: torch.Tensor, Y: torch.Tensor) -> float:
        """线性 CKA：中心化后的 HSIC 归一化"""
        X = X - X.mean(0, keepdim=True)
        Y = Y - Y.mean(0, keepdim=True)
        XX = X @ X.T
        YY = Y @ Y.T
        XY = X @ Y.T
        hsic = (XY * XY).sum()
        var_x = (XX * XX).sum()
        var_y = (YY * YY).sum()
        return (hsic / (var_x.sqrt() * var_y.sqrt())).item()
```

## 4. 风险与缓解

| 风险 | 影响 | 缓解方案 |
|---|---|---|
| **代理指标相关性失效** | MF-BO 选错超参数，浪费完整训练算力 | ① 领域自适应代理选择 (NLP用 logits_corr，视觉用 CKA，生成用 perplexity_gap)；② 在线相关性监控：每 10 个 F2 试验重算 ρ，ρ<0.7 报警并回退单保真 BO；③ 保守早停阈值 (δ=0.1→0.05) |
| **组件接口不兼容** | 管线编译失败、运行时报错 | ① 严格的 Pydantic 契约验证 (compile-time)；② 组件版本语义化：MAJOR 变更自动标记不兼容；③ 组件适配器模式：`AdapterComponent` 自动转换张量形状/语义 |
| **环境复现失败** | 无法位级复现，信任度崩塌 | ① 强制 Docker 复现模式：`ord recipe reproduce --docker`；② 硬件指纹记录：GPU 型号、CUDA、cuDNN 版本纳入 lock；③ 数值容差模式：`--tolerance 1e-3` 允许非确定性硬件的近似复现 |
| **注册表中心化风险** | 单点故障、审查、数据丢失 | ① 去中心化设计：本地注册表 = Git 仓库，支持多远程 (GitHub/GitLab/S3/IPFS)；② 配方内容寻址：`hash` 为主键，名称可变；③ 镜像同步：`ord registry mirror` 自动同步到多节点 |
| **超参数空间定义不全** | MF-BO 无法搜索关键维度 | ① 组件 `config_schema` 强制声明可调参数；② `ord recipe analyze` 静态分析未声明的硬编码超参；③ 社区贡献 `ParamSpace` 扩展包 |

## 5. 本轮最大的风险

**代理指标的「相关性失效」风险：F0/F1 代理指标（Logits 相关性、梯度余弦、迁移率）与最终任务指标的相关性可能在特定域（如长文本生成、多模态对齐、强推理任务）系统性失效。若代理指标给出错误排序，MF-BO 会将资源分配给错误的超参数区域，导致「快速原型误导全量训练」**。缓解：领域自适应代理指标选择、在线相关性校准、保守早停阈值。
