# 第 1 轮（新灵感循环；本轮灵感：「共情表达」×「论文发表」）

> **基线**：第 8 轮 MetricVoiceGauge-DA-SPR-Cal v8（定义 493–531；引理 77–81；实验 E531–E550）。
> 本轮纪律：**把「机器人如何回应人」与「研究如何被同行接受」并置**。前者要求一个可证伪的共情表达闭环，后者要求同一闭环具备可复现、可消融、可预注册的发表级证据结构。两者共用一条「适配—约束—证据」主线。

## 0. 直觉与动机

**灵感 1（共情表达 → 从单向读人到双向闭环）**
直觉：v7/v8 的情感模块（ER）只做了「读人」——把操作员情绪映射成奖励权重 `w'_i(s)`，是一条**单向、开环**的管道：人影响机器人，机器人从不回应人。而真实人机协作里，人也在「读机器人」：一句恰当的口头确认、一个放慢的动作、一次把主导权交还对方的停顿，会显著降低人的焦虑并改善后续指令质量。但共情表达有代价——它占用时间与注意力，紧急场景里「过度共情」反而危险。所以问题不是「要不要共情」，而是「在什么 slack 窗口、以多大强度、用哪种模态表达，才既有效又得体」。

核心转向：ER 从「权重调节器」升级为 **Empathy-Expressive 表达策略**，并被 M₀/M₁（安全）与社交得体性双重约束。

**灵感 2（论文发表 → 发表的约束，而非写作任务）**
直觉：只靠「我们的系统更好」叙事的方案，在审稿里最先死。发表级研究的标志是：声明可证伪、基线可复现、消融可归因、统计有功效、威胁到有效性有台账。因此本轮不把「论文发表」当成事后写作，而当成**设计约束**：每个新增模块在诞生时就绑定一条可被数据否证的 claim，以及对应的预注册检验。

一句话动机：**让「共情表达」成为一个可以被审稿人杀死、也可以被数据救活的研究对象。**

## 1. 研究问题（本轮）

- **Q1（得体性约束）**：如何形式化「共情表达何时可说、说多少、用哪一模态」，使表达既不抢占安全关键动作，又不退化为机械复读？
- **Q2（因果可识别）**：如何在人因噪声与个体差异下识别「表达 → 人的状态变化」的因果效应，而不是把相关当因果？
- **Q3（发表级可复现）**：如何让整套主张具备预注册、消融矩阵、统计功效与 artifact 复现路径？

## 2. 设计原则（在 P7–P9 基础上升级为 P10–P12）

**P10 表达预算与 slack 窗口（Expression Budget & Slack Window）**
共情表达只能在 `slack(t)=1` 的窗口内触发：系统保守裕度足够、无在途安全关键动作、操作员未处于高负荷。每分钟表达预算 `β_E` 限制总时长，防止「共情过载」。

**P11 得体性护栏（Appropriateness Guard）**
表达候选 `e` 先过双层护栏：规则层硬拒（紧急、危险、隐私、否定指令语义），学习层给出得体性分数 `a(e,c)∈[0,1]`，低于阈值 `τ_appr` 不出。规则层的否决权不可被学习层覆盖。

**P12 表达-证据同构（Claim–Evidence Isomorphism）**
每个模块附带 `Claim`（可证伪陈述）、`Ablation`（关闭后应回到哪个基线）、`Metric`（效应量与检验）、`Threat`（威胁到有效性）。**没有证据槽的模块不得进入主方案**。

## 3. 与基线的接口（如何退化）

- 表达策略失效 ⇒ 静默（mute），等价于 MetricVoiceGauge-DA-SPR-Cal v8；
- 得体性护栏失效 ⇒ 只允许 `generic-safe` 低风险模板表达；
- 人因响应观测失效 ⇒ 开环脚本化共情（open-loop），不更新人的内部状态估计；
- 证据管线失效 ⇒ 不改变运行时行为，但所有主张降级为 exploratory，按最保守阈值报告。

## 4. 预期贡献

1. 首个把「共情表达」写成**安全约束下表达策略**的框架（`M_emp` + slack 调度 + 得体性护栏）；
2. 一个**因果可识别**的人因评估协议（slack 内随机化触发 + 混合效应 + 等价检验）；
3. 一套**发表级证据结构**（claim–evidence 台账、消融矩阵、预注册、artifact）；
4. 完整闭环：感知—表达—反馈—证据，覆盖 E551–E580。

## 5. 本轮最大风险

**一句话**：共情表达的「有效性」高度依赖主观人因测量——阈值过保守会退化为静默，过激进会引发厌烦并干扰安全；而人因样本量与个体差异可能使因果效应始终无法在预注册功效下被检出，于是「论文发表」所要求的可证伪性反而暴露该方向效应量过小。

**新增定义 532（共情表达空间 EmpathicExpressionSpace）**
表达是四元组，模态 m ∈ {speech, prosody, text, motion, pause}，内容 c 来自受控模板库 ∪ 生成候选（生成候选必须经护栏），时序 τ 为相对任务事件的偏移，强度 ρ 控制韵律/幅度/用词软化程度。同一语义可有多种 (m,c,τ,ρ) 实现，构成表达候选集 `E_cand(c)`。

**新增定义 533（slack 窗口 SlackWindow）**
```
slack(t) = 1[ margin(t) ≥ m_min
            ∧ ¬inflight_safety_critical(t)
            ∧ load_operator(t) ≤ L_max ]
```
其中 `margin(t)` 为当前构型到硬约束 M₀ 的保守裕度（复用 SpatialCert 的 `σ`），`inflight_safety_critical` 覆盖在途抓取/避障动作，`load_operator` 来自 `ê_H` 的负荷分量。

**新增定义 534（表达预算 ExpressionBudget）**
滑动 60s 窗口内累计表达时长 `T_E(t)` 满足 `T_E(t) ≤ β_E`；超预算时策略按 ρ 从低价值表达开始裁剪（优先级：安全确认 > 任务反馈 > 社交寒暄）。

**新增定义 535（得体性护栏 AppropriatenessGuard）**
```
admit(e,c) = (R_hard(e,c)=0) ∧ (a(e,c) ≥ τ_appr)
```
规则层硬拒集合包含：紧急/危险语义、隐私探询、与否定指令冲突、文化禁忌模板。硬拒是否决制，学习层不能覆盖。

**新增定义 536（共情效能 EmpathyEfficacy，因果版）**
```
Δ_H = E[ H_{after} − H_{before} | do(E=e) ] − E[ H_{after} − H_{before} | do(E=∅) ]
```
`do` 表示干预；在 slack 内随机化表达触发，使 `E ⊥ (潜在结果)` 条件可交换，从而识别 ATE。

**新增定义 537（人的内部状态 POMDP HumanStatePOMDP）**
`ê_H(t)` 由信念 `b(s_H)` 维护：`b' ∝ O(o|s_H,a_E)·Σ T(s_H'|s_H,a_E,action)b(s_H)`，观测 `o` 含韵律、节奏、任务指标；不确定度 `tr(Σ_H)` 大时表达强度自动下调（保守优先）。

**新增定义 538（共情闭环 EmpathicClosedLoop）**
五步：感知 `o` → 归因 `ê_H` → 选择 `E`（受 slack/预算/护栏约束）→ 执行表达 → 观测响应并更新 `b`。闭环增益受限：单轮 `ρ` 变化 ≤ Δρ_max，防止自激振荡。

**新增定义 539（主张-证据台账 ClaimEvidenceLedger）**
```
L = { (C_k, A_k, M_k, T_k, Th_k) }_{k=1..K}
```
`C_k` 可证伪陈述（含方向与阈值），`A_k` 关闭哪一模块后应回到哪个基线，`M_k` 主要度量与效应量，`T_k` 统计检验（含等价检验），`Th_k` 威胁到有效性条目。**准入规则：`L` 中不存在对应条目的模块，禁止进入主方案。**

**新增定义 540（预注册协议 PreRegistration）**
冻结 `(H1..H8, 主要终点, 次要终点, 样本量/功效, 停止规则, 排除标准, 分析脚本哈希)`。任何事后改动需在 artifact 中留 diff 与理由。

**新增定义 541（消融矩阵 AblationMatrix）**
`A[i][j] ∈ {equivalent, better, worse, undetermined}`；要求每个新增模块至少一条「关闭 ⇒ 等价基线」的判定，否则视为不可归因。

**新增定义 542（功效与等价 StatisticalPower & Equivalence）**
给定 SESOI `δ_min`，显著性 `α`，功效 `1−β_pow`，估计所需样本 `n`；当真实效应 `< δ_min` 时，用 TOST 等价检验主张「无有意义共情效应」，避免把「未检出」当成「无效」。

**新增定义 543（威胁到有效性台账 ThreatLedger）**
构造（construct：共情用何代理度量）、内部（顺序/习惯化效应）、外部（单实验室/单文化）、结论（多重比较/选择性报告）四类威胁，逐条绑定缓解措施。

**新增定义 544（复现包 ReproductionPackage）**
`Pkg = {seeds, configs, ROS bags, Dockerfile, lockfile, analysis scripts, prereg hash}`；独立第三方仅凭 `Pkg` 可重建主要结果表。

**新增定义 545（表达安全不变式 ExpressionSafetyInvariant）**
对任意时刻 t：`E(t)≠∅ ⇒ slack(t)=1`，且 `E` 的调度不在安全关键路径上；故表达对 M₀/M₁ 的最坏额外延迟为 0。

```python
# IP-361 ExpressionSlackScheduler：slack 判定 + 预算
class ExpressionSlackScheduler:
    def __init__(self, m_min=0.15, L_max=0.8, beta_E=15.0, window_s=60.0):
        self.m_min, self.L_max = m_min, L_max
        self.beta_E, self.window_s = beta_E, window_s
        self.spent = []  # [(timestamp, duration)]

    def _spent_in_window(self, t):
        self.spent = [(ts, d) for ts, d in self.spent if t - ts <= self.window_s]
        return sum(d for _, d in self.spent)

    def slack(self, margin, inflight_safety_critical, load_operator,
              t, planned_duration=0.0):
        has_budget = self._spent_in_window(t) + planned_duration <= self.beta_E
        return int(margin >= self.m_min
                   and not inflight_safety_critical
                   and load_operator <= self.L_max
                   and has_budget)

    def commit(self, t, duration):
        self.spent.append((t, duration))


# IP-362 AppropriatenessGuard：规则硬拒 + 学习打分
class AppropriatenessGuard:
    def __init__(self, tau_appr=0.6, scorer=None, hard_rules=None):
        self.tau_appr = tau_appr
        self.scorer = scorer          # a(e,c) -> [0,1]
        self.hard_rules = hard_rules or [
            lambda e, c: c.emergency,          # 紧急场景
            lambda e, c: c.asks_private_info,  # 隐私
            lambda e, c: c.negates_command,    # 与否定指令冲突
            lambda e, c: e.template in c.taboo_templates,
        ]

    def admit(self, e, c):
        if any(rule(e, c) for rule in self.hard_rules):  # 硬否决不可覆盖
            return False
        if self.scorer is None:
            return e.template in getattr(c, 'generic_safe_templates', set())
        return self.scorer(e, c) >= self.tau_appr


# IP-360 EmpathicExpressionPolicy：在约束下选表达
class EmpathicExpressionPolicy:
    def __init__(self, guard, scheduler, rho_max=1.0, delta_rho_max=0.3):
        self.guard, self.scheduler = guard, scheduler
        self.rho_max, self.delta_rho_max = rho_max, delta_rho_max
        self.last_rho = 0.0

    def select(self, E_cand, context, margin, inflight, load, t):
        approved = [e for e in E_cand if self.guard.admit(e, context)]
        if not approved:
            return None  # mute ⇒ 等价 v8
        # 价值 = 预期效能 − 注意力税；受 slack 与预算约束
        def value(e):
            return e.expected_efficacy - context.attention_tax * e.duration
        ranked = sorted(approved, key=value, reverse=True)
        for e in ranked:
            rho = min(e.intensity, self.last_rho + self.delta_rho_max)
            e2 = e.with_intensity(rho)
            if self.scheduler.slack(margin, inflight, load, t, e2.duration):
                self.scheduler.commit(t, e2.duration)
                self.last_rho = rho
                return e2
        return None


# IP-364/IP-363 HumanStateObserver + EmpathyClosedLoop
class EmpathyClosedLoop:
    def __init__(self, observer, policy, rho_update=0.1):
        self.observer = observer
        self.policy = policy
        self.belief = None
        self.rho_update = rho_update

    def step(self, obs, context, margin, inflight, t, E_cand):
        e_H, cov_H = self.observer.update(obs)          # ê_H, Σ_H
        load = e_H.load
        if cov_H.trace() > context.cov_threshold:       # 不确定 ⇒ 强度下调
            E_cand = [e.damped(self.rho_update) for e in E_cand]
        e = self.policy.select(E_cand, context, margin, inflight, load, t)
        return e


# IP-365 CausalEmpathyEstimator：随机化触发 + ATE
class CausalEmpathyEstimator:
    def __init__(self, delta_min=0.2, alpha=0.05, power=0.8):
        self.delta_min, self.alpha, self.power = delta_min, alpha, power
        self.log = []  # (arm, pre_state, post_state, operator_id, context)

    def randomize(self, rng):
        return rng.random() < 0.5   # slack 内 50/50 触发表达

    def record(self, arm, pre, post, operator_id, context):
        self.log.append((arm, pre, post, operator_id, context))

    def estimate_ate(self):
        # 混合效应：post-pre ~ arm + (1|operator) + covariates
        import numpy as np
        treated = np.array([p - q for (a, q, p, _, _) in self.log if a])
        control = np.array([p - q for (a, q, p, _, _) in self.log if not a])
        if len(treated) == 0 or len(control) == 0:
            return {"ate": None, "note": "insufficient arms"}
        ate = treated.mean() - control.mean()
        # 等价检验（TOST）与功效见定义 542
        return {"ate": float(ate), "n_t": len(treated), "n_c": len(control)}


# IP-369 主闭环集成关键片段：MetricVoiceGauge-EE-PubGrade
def metricvoicegauge_round_9(M, s, obs, audio_stream=None, ell=None,
                             scheduler=None, guard=None, ee_policy=None,
                             human_observer=None, causal_est=None,
                             ledger=None, rng=None):
    """决策路径保持 v8 的 50Hz WCET；表达走后台通信线程，不占决策预算。"""
    # --- 0. 继承 v8：DA-ML / SPR / Calib-FI / GCT / ER 全部前处理 ---
    C, spatial_cert, claims, metrics, rewards = M.metricvoicegauge_round_8(
        M, s, obs, audio_stream, ell=ell)

    # --- 1. slack 判定（读取 v8 的保守裕度与在途状态，只读不改） ---
    margin = spatial_cert.get('margin', 1.0)
    inflight = bool(getattr(M, 'inflight_safety_critical', False))
    load = 0.0
    if human_observer is not None:
        _, cov_H, e_H = human_observer.peek(obs)
        load = e_H.load

    # --- 2. 表达选择（受 slack/预算/护栏三重约束） ---
    expression = None
    if ee_policy is not None and scheduler is not None:
        E_cand = ee_policy.propose(M, s, metrics)  # 生成候选表达
        expression = ee_policy.select(E_cand, M.context, margin,
                                      inflight, load, s.t)
    # --- 3. 表达异步执行，绝不阻塞决策；失败则静默（退化 L1） ---
    if expression is not None:
        try:
            M.comm_thread.submit(expression)   # 后台线程
        except Exception:
            expression = None                  # mute ⇒ 等价 v8

    # --- 4. 证据记录（不改变运行时行为） ---
    if causal_est is not None and expression is not None:
        causal_est.record(arm=True, pre=load, post=None,
                          operator_id=getattr(M, 'operator_id', 0),
                          context=M.context)
    # --- 5. 主张-证据台账自检：缺证据槽的模块禁止启用 ---
    if ledger is not None:
        ledger.assert_admissible({'EE': ee_policy is not None,
                                  'Guard': guard is not None})
    return C, spatial_cert, claims, metrics, rewards, expression
```

## 4. 推导

**引理 82（表达不抢占安全关键路径）** 由定义 545，`E(t)≠∅ ⇒ slack(t)=1`，且表达经 `comm_thread` 异步提交，不在 `metricvoicegauge_round_8` 的同步调用链上。故表达对 M₀/M₁ 的最坏额外延迟为 0，`slack` 判定只读 v8 证书字段，不改变其值。

**引理 83（表达预算有界 ⇒ 注意力税有界）** 定义 534 限定任意 60s 窗口内 `T_E(t) ≤ β_E`。若单位时长注意力税为 `k_att ≥ 0`，则任意窗口内总税 ≤ `k_att·β_E`，与任务时长无关，故共情不会随运行时间累积成无界干扰。

**引理 84（护栏可靠性）** 定义 535 中硬拒为否决制：`admit(e,c)=0` 当任一 `R_hard=1`。故紧急/危险/隐私/否定冲突四类表达恒被拒绝，学习层无法覆盖；在 `scorer` 失效（退化 L2）时，`admit` 退化为模板白名单，仍保证只出 `generic-safe`。

**引理 85（随机化下因果可识别）** 在 `slack=1` 子集内以 50/50 随机化表达触发，则 `E` 与潜在结果独立（ignorability），`E[Y|arm]−E[Y|¬arm] = ATE`。混合效应吸收操作员随机截距，故 `Δ_H` 的估计在给定协变量下无偏。注意：该结论只对**进入 slack 的子群**成立，外推到全体需额外假设。

**引理 86（四级退化正确性）** L1：`ee_policy` 失效 ⇒ `expression=None` ⇒ 与 v8 的 `round_8` 返回值一致；L2：护栏失效 ⇒ `admit` 仅白名单；L3：观测失效 ⇒ `load` 常量化、`ê_H` 不更新 ⇒ 开环脚本；L4：`ledger` 失效 ⇒ 运行时不变，仅主张降级。各模块接口正交（策略只改表达、护栏只改准入、观测只改 `ê_H`、台账只读），无级联副作用。

**引理 87（证据完备性）** 定义 539 的准入规则要求每个启用模块在 `L` 中存在对应条目。若 `ledger.assert_admissible` 检测到某模块无证据槽，则拒绝启用并将其置为失效路径（走对应退化级）。故主方案中不存在「无 claim 模块」。

**引理 88（等价检验的单向安全）** 若真实效应 `< δ_min` 且功效 `1−β_pow`，则 TOST 在 `α` 下以概率 `≥ 1−β_pow` 拒绝「存在有意义效应」。因此「报告无效」不会把大效应误判为无效（该风险由功效保证），但**不能**反过来把「未检出」自动等同于「绝对零效应」——外部有效性仍受 `Th` 台账约束。

## 8. 本轮最大风险

**一句话**：共情表达的有效性依赖主观且高方差的人因测量——护栏过保守会退化为静默、过激进会引发厌烦并干扰安全，而个体差异与样本量可能使真实效应低于 `δ_min`，届时「论文发表」所要求的因果可证伪性会得到**阴性结论**（该方向效应量过小），这既是科学上诚实的结局，也是本轮方案在传播意义上的最大失败模式。
