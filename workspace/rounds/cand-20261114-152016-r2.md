# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「末端位姿」×「开源生态」）

> R69 让系统学会了「问」，但它有一个从未言明的前提：**这个会问的系统是一个单一、可信、封闭的模型**——流速度场、模态权重、标定器、冻结 LLM 都出自同一条训练管线、同一个版本、同一个信任域。R69 自陈的最大风险（「流模态分布不可信 → 自信地追问一个幻影」）正是这个前提破裂时的样子。
>
> 本轮两个灵感把前提本身变成研究对象：
> - **末端位姿**：不管内部表示多复杂，机器人对世界真正「兑现」的只有末端位姿（SE(3) 轨迹 + 速度/力）。它低维、可测、跨实现不变，是一个可以把认证钉上去的物理接口——**信任不该锚在不可审计的模型内部，而应锚在可测量的末端位姿上**。
> - **开源生态**：真实部署很少是单一体，而是由 ROS2 包、预训练 checkpoint、VLA/流头、冻结 LLM、标定器拼装起来的**供应链**；组件会被 fork、升级、替换、由第三方贡献，甚至被投毒。信任于是从「模型可信」变成「供应链可证」。
>
> 核心命题：**不再要求内部模型可信，而是要求它的可观测输出在末端位姿空间通过一个与实现无关的安全包络 + 签名金丝雀 + 跨实现差分认证；用独立的关节编码器正运动学作为信任根，把末端位姿变成具身智能的 ABI 与引用监控点。** 命名 **ANCHOR-RAS**（Anchored N-component Certificate for Heterogeneous Open-source Robotics）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我凭什么相信这整套拼起来的东西**」——答案不是相信模型，而是把信任钉在末端位姿这块物理地面上。

## 0. 直觉与动机

**灵感 1（末端位姿 = 具身智能的 ABI / 引用监控点）**
直觉：我们可以完全不信任何一段开源代码，但可以拿尺子量末端执行器在哪。位置、姿态、速度、接触力是封闭世界里的「事实」，而 latent、注意力图、模态权重都只是「说法」。R68–R69 的认证（C-RAS-WM、J_FLUID）都建立在模型内部自洽之上，一旦某个组件被替换/投毒，内部自洽可以整体造假；但末端位姿要真的让机械臂动起来，骗不过独立正运动学。于是把认证从「模型输出」下移到「执行器边界的位姿轨迹」，就得到一个**与组件实现无关、可被第三方复算的信任根**：像操作系统用系统调用做安全边界，机器人用末端位姿做安全边界。

**灵感 2（位姿商空间 → 把「假歧义」从 epistemic 里剔出去）**
直觉：R69 在原始动作空间里做模态聚类与间距度量，会把两类**不改变任务**的差异误当成需要交互的歧义：一是冗余自由度（7 轴臂的肘部自运动，末端位姿一模一样），二是接近奇异位形时「关节差很小、位姿差很大」的相反情形。前者让系统白问一次，后者让系统低估真实歧义。末端位姿给出一个天然商映射 π_ee：把动作轨迹投到任务空间，只保留**改变任务**的模态；零空间里的散开不再算 epistemic，而是可自由优化舒适度的冗余。这样 R69 的交互预算就被花在刀刃上。

**灵感 3（开源生态 = 组件级缓变漂移，需要几何 oracle 的回归测试）**
直觉：开源供应链最危险的不是显式崩溃，而是**无声语义漂移**——依赖小版本升级、checkpoint 被重新发布、fork 合并上游、tokenizer/归一化层改动、四元数顺序从 xyzw 变 wxyz、单位从 m 变 mm。没有异常日志，行为却变了。标签回归太贵且覆盖不到，但末端位姿提供一个**几何 oracle**：固定一组探针输入，比对签名过的金标准位姿输出；偏差即漂移。这是「可复现构建 + SBOM」在**行为层**的对应物，且 oracle 是几何而非人工标注，成本极低。它正好接住 R68 的慢变故障主题，只是把「传感器被标定吸收」升级为「整条供应链被版本吸收」。

**灵感 4（开源是双刃剑 → 公开包络会被优化到边界）**
直觉：把安全包络与金丝雀公开，能让社区复算、能更快发现漏洞；但同一个公开物也是攻击者的地图。对手可以在**完全合规**的前提下把轨迹推到包络边界去做任务上错误的事（抓错物体、交给错的人），也可以针对公开金丝雀做「过拟合」。于是「开源可验证」与「开源可攻击」是一枚硬币：必须引入隐藏金丝雀池、随机化安全裕度、跨独立实现的 N 版本差分，并把「位姿合规但任务错误」明确列为**不可由本层消除的残余风险**。

**灵感 5（严格包含 → 新层必须是 R69 的无损外壳）**
直觉：ANCHOR 不应是一个与 FLUID 并列、需要独立信任的新黑箱，而应是套在它外面的**引用监控外壳**：认证通过时逐指令等价于 FLUID（位姿层直通）；认证软失败时冻结并回滚到上一个已签名栈，风险缩放的 λ 单调不降地退化为 R68；位姿硬越界时直接急停/安全撤离。这样 R69 成为「单一已签名栈 + 恒等位姿映射」的边界情形，安全侧永不变弱。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（ANCHOR-RAS 总览）** ANCHOR-RAS = (AUD-EE, PSC, PROV, IFC, CANARY, DAP, NVD, RAS-WM‡)。四不变式：
(i) **执行路径被中介**：任何学习组件的输出都必须经由 PSC（位姿引用监控器）才能到达执行器，无旁路；
(ii) **信任根外置**：PSC 使用独立的关节编码器正运动学 FK 与环境包络，二者不在开源组件的信任域内、且可被最简实现审计；
(iii) **可证供应链**：在线栈的每个组件都有签名 provenance 记录与哈希锁；
(iv) **严格包含**：认证通过 ⇒ 逐指令等价 FLUID；任一失败 ⇒ λ 单调不降地退化为 R68。

**定义 311（末端位姿映射 π_ee）** 动作轨迹 ξ ∈ 𝒜_+（R69 定义 294）。对长度 H 的轨迹，π_ee(ξ) = {(p_t, R_t, ṗ_t, ω_t, f_t)}_{t≤H} ∈ (SE(3)×ℝ⁶)^H，其中 (p,R) 为末端位置与姿态、ṗ/ω 为线/角速度、f 为（若有）接触力。实现上由独立正运动学 + 数值微分给出；π_ee 与策略网络完全解耦。

**定义 312（位姿商度量与任务可分性）** 定义等价关系 ξ ~ ξ′ ⇔ π_ee(ξ) = π_ee(ξ′)。商空间 𝒜_+/~ 上的伪度量 d_ee(ξ,ξ′) = max_t d_SE3(π_ee(ξ)_t, π_ee(ξ′)_t)，d_SE3 取位置欧氏距离与测地姿态角的加权。模态 i,j **任务可分** ⇔ d_ee(ξ̄_i, ξ̄_j) ≥ δ_task；否则视为同一任务模态类别并合并。

**定义 313（AUD-EE 三分分解）** 继承 R69 定义 296–297 的聚类 {m_k, ŵ_k, Σ_k}。经运动学雅可比 J_ee 传播位姿协方差 Σ_k^ee = J_ee Σ_k J_eeᵀ。定义
- U_ale^ee = Σ_k ŵ_k tr(Σ_k^ee)（任务空间内不可约噪声）；
- 按定义 312 合并等价模态得类别 {c}、权重 w_c^ee、最小间距 Δ_min^ee，U_epi^ee = H(w^ee)·g(Δ_min^ee)（**任务相关**可约歧义）；
- U_null = Σ_k ŵ_k tr(Σ_k) − Σ_k ŵ_k tr(Σ_k^ee)（零空间冗余散度，**不入安全通道**，仅用于舒适度优化）。
约束 U_ale^ee + U_null ≤ Σ_k ŵ_k tr(Σ_k)（投影不增迹）。**只有 U_ale^ee 与未消解的 U_epi^ee 进入 λ_floor；U_null 不触发交互、不收紧。**

**定义 314（位姿安全包络与引用监控器 PSC）** 包络 ℰ_pose = {位姿轨迹 | 位置 ∈ 𝒲、姿态 ∈ 𝒪、‖ṗ‖,‖ω‖ ≤ v_max、力 f ∈ ℱ、无自碰撞、时间窗有效}。Cert_pose(π_ee(ξ), q_meas, ℰ_pose) ∈ {OK, TrackingFault, Violation}：用独立 FK(q_meas) 与实际执行位姿比对包络；命令位姿与实际位姿偏差 > τ_track 记 TrackingFault；实际位姿越界记 Violation。PSC 位于执行器边界，是最后一道、也是唯一不可绕过的门。

**定义 315（开源组件与 provenance 记录）** 组件 comp = (id, role, version, code_hash, weight_hash, parent_fork, upstream_commit, interface_id, license, signed_by, deps)。在线栈的清单 manifest 构成 DAG；锁定文件 ℒ 固定每个组件的哈希与依赖闭包。provenance 完整 ⇔ manifest 中每个节点都可验签、哈希匹配、依赖闭包已锁定、许可与角色声明一致。

**定义 316（位姿级技能接口与框架代数 IFC）** 每个组件按 role 声明接口契约 C_role = (frame_id, unit, rotation_order, rate, dim, limits, semantics)。位姿级技能以 π_ee 轨迹为交换格式——社区组件无需暴露内部表示即可互操作。兼容关系 Comp(C_1, C_2) 要求坐标框架、单位、旋转顺序、频率、语义逐项一致；不一致即判为帧/单位错配（例如 mm/m、xyzw/wxyz、手腕/工具坐标系混淆），由定义 317 的金丝雀给出特征化检测。

**定义 317（签名金丝雀套件 CANARY）** 固定探针集 P = {(s_i, a_i)}_{i=1..N}，金标准 g_i = π_ee(π_{θ_signed}(s_i,a_i))，随锁文件由维护者签名。漂移分 d_canary = max_i d_ee(π_ee(π_θ(s_i,a_i)), g_i)。金丝雀分公开池 P_pub 与隐藏池 P_hid（按部署采样、定期轮换），隐藏池结果以加盐承诺形式回灌证书而不泄露内容。

**定义 318（差分认证 DAP）** 对当前栈与已签名参考栈在 P_pub ∪ P_hid 上做差分。判定：d_canary ≤ τ_canary ⇒ 通过；τ_canary < d_canary ≤ τ_soft ⇒ 软失败（冻结当前栈、回滚到 last-signed、升 λ）；d_canary > τ_soft 或 provenance 不完整 ⇒ 硬失败（拒绝该栈上线，回退 R68 最保守）。

**定义 319（N 版本差分 NVD）** 取 K 个**来源可区分**的实现（不同维护方 / 不同上游分支），同一探针输入下比较位姿输出；逐点容差 τ_nvd 下多数一致为正常，分歧聚簇为异常证据。以 provenance 距离 ρ_prov 折扣独立性：同上游 fork 的失败相关按 ρ_prov 上修。

**定义 320（开源生态威胁模型 ℰ_open）** 恶意组件（权重后门 / 只在特定状态触发的位姿偏置）、金丝雀泄漏与过拟合、共享基准投毒、依赖替换与 typosquatting、框架/单位木马（训练与日常输入正常、特定工具坐标系翻转）、锁文件静默改写。并入 AIC：ℰ_ANCHOR = ℰ_FLUID × ℰ_open。

**定义 321（合规但错误 / 包络过拟合）** 残余任务风险 R_cw = sup_{π_ee(ξ) ∈ ℰ_pose} D_task(ξ)，其中 D_task 是任务级损失。R_cw > 0 当且仅当「任务风险可因子化为位姿」假设（A100）失效或包络欠约束。公开 ℰ_pose 与公开金丝雀会降低对手构造越界轨迹的成本，但**不能降低 R_cw 本身**，只能靠收紧 ℰ_pose 与扩展隐藏探针来压。

**定义 322（证书 J_ANCHOR）** J_ANCHOR = (J_FLUID, prov_lock_hash, comp_hash_set, canary_commit, canary_result, dap_verdict, nvd_agreement, env_margin, replay_nonce, open_ver)。Valid ⇔ Valid(J_FLUID) ∧ provenance 完整 ∧ canary 通过 ∧ (DAP 通过 ∨ 已回滚到 last-signed) ∧ NVD 无未解释分歧 ∧ ℰ_pose 余量 ≥ m_min。

**定义 323（三级保守退避，含严格包含）** ① 全通过：λ 与模态选择完全同 FLUID（resolution bonus 保留）；② 软失败（漂移/帧错配/NVD 分歧但位姿仍在包络内）：冻结并回滚 last-signed，λ = λ_floor(U_ale^ee + U_epi^ee)，前缀 k 收缩；③ 硬失败（Violation / provenance 破缺）：急停或安全撤离，λ 取 R68 最大值。⇒ R69 是「单一已签名栈 + 恒等位姿映射 + 永不回滚」的边界情形，安全侧永不弱于 R69。

**定义 324（隐藏金丝雀与轮换）** 隐藏池 H 的采样、轮换周期与承诺方案由部署方持有；公开可见比例 ρ_pub。隐藏池用于在对手已知公开池时仍能检出漂移；承诺保证「可验证而不泄露」。ρ_pub 越高，社区可复算性越强、但对手过拟合空间越大——这是可调的开放度旋钮。

**定义 325（可复现回放与社区审计 OCG）** 状态快照 + 锁文件 ℒ + 公开金丝雀 + J_ANCHOR 允许任何第三方离线重放并独立验证。隐藏池以承诺绑定，回放只验证承诺一致性。开放贡献需过签名 CI：provenance 完整、公开金丝雀通过、NVD 一致，才允许进入可部署注册表。

**定义 326（位姿锚定模态选择）** 在证据纪律（继承 R69 定义 293-iii）与 ℰ_pose 约束下，选择使期望任务损失最小的任务模态：mode* = argmin_c E[D_task | c, evidence] s.t. π_ee(mode*) ∈ ℰ_pose；同任务位姿下用 U_null 的自由度做舒适度/可达性次优选择。**位姿决定安不安全，零空间决定舒不舒服。**

```python
# IP-264 AUD-EE：位姿商空间的不确定性三分（假歧义不再烧交互预算）
def pose_quotient_decompose(samples, z, J_ee, delta_task):
    modes = cluster_trajectories(samples)              # 继承 R69
    w     = mode_weights(modes)
    for m in modes:
        m.xi_ee   = pi_ee(m.prototype)                 # 投影到末端位姿
        m.Sigma_ee = J_ee @ m.Sigma @ J_ee.T           # 雅可比传播
    classes = merge_by_pose(modes, d_ee, tol=delta_task)  # 零空间等价类合并
    w_ee    = class_weights(classes)
    U_ale   = sum(w[k] * trace(modes[k].Sigma_ee) for k in modes)
    U_epi   = entropy(w_ee) * sep_factor(classes)      # 仅任务可分歧义
    U_null  = sum(w[k] * trace(modes[k].Sigma)) - U_ale  # 冗余散度，不入安全通道
    return U_ale, U_epi, U_null, classes

# IP-265 PSC：位姿引用监控器（信任根 = 独立 FK，不在开源栈内）
def cert_pose(pose_cmd, q_meas, env):
    pose_meas = fk_independent(q_meas)                 # 可审计的最简实现
    if not env.contains(pose_meas):  return Violation(pose_meas)
    if d_ee(pose_cmd, pose_meas) > TAU_TRACK:
        return TrackingFault()                         # 命令/执行分叉 = 组件可疑
    return OK()

# IP-268/269 CANARY + DAP：几何 oracle 的供应链回归
def attest(stack, lockfile, canaries, hidden_pool):
    if not verify_manifest(stack.manifest, lockfile.signed):
        return HardFail("provenance")
    probes = canaries.public + sample(hidden_pool, canaries.n_hidden)
    d = max(d_ee(pi_ee(stack.run(s, a)), g) for (s, a, g) in probes)
    if d <= TAU_CANARY: return Pass(d)
    if d <= TAU_SOFT:   return SoftFail(d)              # 冻结 + 回滚 last-signed
    return HardFail(d)

# IP-270 NVD：跨独立实现差分，抵御单供应商投毒
def n_version_check(implementations, probes, tau_nvd):
    votes = [impl.run(p) for impl in implementations for p in probes]
    clusters = cluster_by_pose(votes, tau_nvd)
    majority = max(clusters, key=len)
    dissent  = [c for c in clusters if c is not majority]
    return consistency_score(len(majority), len(votes)), dissent

# IP-274 ANCHOR-RAS 主闭环：R69 外挂引用监控外壳
def ANCHOR_RAS_round(M, obs, q_meas):
    stack = M.registry.active()
    # 1) 供应链先认证，失败先回滚（不进入决策）
    att = M.dap.attest(stack, M.lockfile, M.canaries, M.hidden)
    if isinstance(att, HardFail):  return emergency_stop(att)
    if isinstance(att, SoftFail):
        stack = M.registry.last_signed()
        soft  = True
    else:
        soft  = False
    # 2) R69 决策核心（AUD 换成位姿商分解）
    z, o = stack.trunk(obs); c, U_cal, thr = stack.cof.step(...)
    K = 1 if stack.fmp.mode_head(z) < TAU_MODE else 4
    samples = stack.fmp.sample(o, K)
    U_ale, U_epi, U_null, classes = pose_quotient_decompose(
        samples, z, stack.J_ee, DELTA_TASK)
    a_hat = stack.fma.flow_anomaly(...)                # 继承 R69 第二意见
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    g = (M.mint.choose_interaction(classes, o, M.budget)
         if (U_epi > TAU_EPI and not slow) else None)
    if g is not None: U_epi = M.cia.update_belief(classes, M.cia.execute(g))
    U_floor = U_ale + (U_epi if g is None else 0.0)    # U_null 不进入！
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    # 3) 位姿锚定模态选择 + 引用监控
    mode = min(classes, key=lambda c: expected_task_loss(c, lam))
    pose_cmd = mode.xi_ee[:H]                          # 只下发给定位姿轨迹
    if soft: lam = max(lam, 0.8); pose_cmd = shrink_prefix(pose_cmd, U_cal)
    verdict = M.psc.cert_pose(pose_cmd, q_meas, M.env)
    if isinstance(verdict, Violation):    return emergency_stop(verdict)

    # 4) 审计 + 可复算证书
    M.vqa_i.submit_async(g, U_epi, a_hat, att, M.canary_commit)
    return dispatch(pose_cmd * lam), J_ANCHOR(...)
```

## 3. 推导

**假设** A100：任务风险可因子化为末端位姿轨迹，即 D_task(ξ) = D_task^ee(π_ee(ξ))（否则见定义 321 的残余风险）。A101：独立 FK 与 ℰ_pose 监控器在开源信任域外、执行路径被中介无旁路。A102：组件行为对状态-动作 L-Lipschitz，金丝雀在可达集上 ε-覆盖。A103：继承 R69 的 A95–A98。

**引理 19（位姿商不膨胀任务相关熵）** 在 A100 下，设按定义 312 合并等价模态后的任务类别熵为 H(w^ee)、原始动作模态熵为 H(w)，则 U_epi^ee ≤ U_epi，且被剔除的质量恰为「投影到同一任务位姿」的零空间分量。故基于 U_epi^ee 的 VoI 决策不会比 R69 更频繁地发起交互，却不会漏掉真实任务歧义；被省下的交互预算可转投真正可分的歧义。系：冗余机械臂上，R69 的假交互率与 U_null/H(w) 成正比，ANCHOR 将其归零。

**引理 20（金丝雀漂移可检性）** 设漂移栈在可达状态上相对参考栈的位姿偏差为 δ，金丝雀对可达状态-动作集的覆盖半径为 ε_cover，组件 L-Lipschitz。则存在金丝雀使 d_ee 偏差 ≥ δ − 2L·ε_cover；当 δ > τ_canary + 2L·ε_cover 时，DAP 以至少 1 − exp(−N·c) 的概率检出（N 为探针数）。系：**检测分辨率由覆盖半径而非标签质量决定**——这正是几何 oracle 比行为克隆回归便宜的原因。

**定理 18（引用监控的组件无关安全性）** 在 A101 下，若 Cert_pose 对每步执行位姿返回 OK，则无论开源栈内部发生何种故障或投毒，实际执行轨迹满足 π_ee(ξ_exec) ∈ ℰ_pose。证明要点：学习组件的输出只能经 PSC 到达执行器；PSC 的判定依据是独立 FK 测得的实际位姿而非组件自述；Violation 被替换为急停/撤离，而撤离策略本身是 ℰ_pose 闭包内的。故安全性只依赖 ℰ_pose 的正确性与 FK 的可信度，**不依赖任何组件内部**。这是把 R68–R69 的「模型自洽认证」升级为「输出事实认证」的关键一步。

**定理 19（ANCHOR 严格包含 FLUID/R68）** 在 A100–A103 下：① 若 DAP 通过、无模态合并、J_ee 局部满秩，则 d_ee ∝ d_action（局部等距），U_epi^ee = U_epi，ANCHOR 与 FLUID 逐指令相同；② 任一认证失败时 λ 单调不降地退化为 R68 的 λ_floor(U_ale + U_epi) 并收缩前缀；③ 硬失败时退化为急停。故对任意状态，ANCHOR 的期望安全风险 ≤ R69 ≤ R68，而效率侧在「栈可信且位姿充分」时获得 resolution bonus。R69 恰是「单一已签名栈 + 恒等位姿映射」的边界。

**引理 21（开放度双刃上界）** 设对手可见公开金丝雀比例 ρ_pub 并据此优化其在公开池上的偏差，隐藏池覆盖不可见方向。则漂移检出概率 ≥ (1 − ρ_pub)·(1 − exp(−N_hid·c))；而被公开包络「引导」到边界附近的合规错误风险满足 R_cw ≥ (A100 的违反度)。系：开源提高的是**可靠性**（更多眼睛复算），不自动提高**安全性**（更多眼睛也给对手）；必须以隐藏池 + 随机化裕度把 ρ_pub 的有效攻击面压回可接受区间。

**定理 20（N 版本差分上界）** 设 K 个来源可区分实现各自独立失败概率 p、同上游相关 ρ_prov。K 版本多数决的失败概率 ≤ Σ_{j>K/2} C(K,j) p_eff^j(1−p_eff)^{K−j}，其中 p_eff = p·(1 + (K−1)ρ_prov)/K 近似有效相关失败率（ρ_prov=0 时退化为独立多数决）。系：NVD 的价值完全取决于**来源独立性**；同一 fork 的 K 个副本不能算 N 个版本，provenance 距离必须进入证书。

## 6. 本轮最大风险

**一句话**：ANCHOR 的全部安全性都押在「任务风险可因子化为末端位姿」这一假设（A100）上——**一个组件完全可以做到位姿处处合规、却干着任务上错误的事（抓错物体、交给错误的人、在不该接触时轻触）；而开源生态让攻击者能读到同一份公开包络与金丝雀，把恶意轨迹精确优化到包络边界**，于是系统获得一种「有证书的错误」：位姿对了，任务错了，而且是被公开验证过的错。

**次级风险与缓解**：
1. **信任根被腐蚀**（独立 FK/包络监控器本身被替换）→ 最小化实现 + 形式化审计 + 将其置于开源栈之外的只读域（A101、定理 18）；
2. **隐藏池泄漏** → 加盐承诺 + 定期轮换 + 分部署采样（定义 317/324、引理 21）；
3. **伪独立性**（同一 fork 声称多个实现）→ provenance 距离进入证书，ρ_prov 上修（定义 319、定理 20）；
4. **包络过粗 → 合规但错误** → 收紧 ℰ_pose + 任务级隐藏探针 + 明确记录 R_cw（定义 321、E315）；
5. **认证开销击穿实时** → 在线只抽样、离线全量、异步摊销（复杂度表）。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** 执行路径被中介（无旁路到执行器）、信任根外置（独立 FK + 包络）、可证供应链（签名 provenance 与锁）、严格包含（全通过 ≡ FLUID，失败单调退化 R68）。

**定义 311–312（位姿映射与商度量）** `π_ee` 由独立正运动学给出；`ξ~ξ′ ⇔ π_ee(ξ)=π_ee(ξ′)`；`d_ee` 取 SE(3) 轨迹最大距离；`d_ee ≥ δ_task` 才任务可分。

**定义 316（IFC）** 组件按 role 声明接口契约；位姿轨迹即交换格式；`Comp(C1,C2)` 要求 frame/unit/rotation_order/rate/semantics 一致；错配由金丝雀特征化检测。

```python
def pose_quotient_decompose(samples, z, J_ee, delta_task):
    modes = cluster_trajectories(samples); w = mode_weights(modes)
    for m in modes:
        m.xi_ee, m.Sigma_ee = pi_ee(m.prototype), J_ee @ m.Sigma @ J_ee.T
    classes = merge_by_pose(modes, d_ee, tol=delta_task)
    w_ee = class_weights(classes)
    U_ale  = sum(w[k]*trace(modes[k].Sigma_ee) for k in modes)
    U_epi  = entropy(w_ee) * sep_factor(classes)
    U_null = sum(w[k]*trace(modes[k].Sigma)) - U_ale   # 仅舒适度，不入 λ
    return U_ale, U_epi, U_null, classes

    samples = stack.fmp.sample(o, K)
    U_ale, U_epi, U_null, classes = pose_quotient_decompose(
        samples, z, stack.J_ee, DELTA_TASK)
    a_hat = stack.fma.flow_anomaly(...)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    g = (M.mint.choose_interaction(classes, o, M.budget)
         if (U_epi > TAU_EPI and not slow) else None)
    if g is not None: U_epi = M.cia.update_belief(classes, M.cia.execute(g))
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (U_epi if g is None else 0.0)))
    mode = min(classes, key=lambda c: expected_task_loss(c, lam))
    pose_cmd = mode.xi_ee[:H]
    if soft: lam = max(lam, 0.8); pose_cmd = shrink_prefix(pose_cmd, U_cal)
    v = M.psc.cert_pose(pose_cmd, q_meas, M.env)       # 唯一通往执行器的门
    if isinstance(v, Violation):     return emergency_stop(v)
    if isinstance(v, TrackingFault): return rollback_and_replan(v)
    M.vqa_i.submit_async(g, U_epi, a_hat, att, M.canary_commit)
    return dispatch(pose_cmd * lam), J_ANCHOR(...)
```

## 4. 推导

**引理 19（位姿商不膨胀任务相关熵）** A100 下，按位姿等价类合并后的 `U_epi^ee ≤ U_epi`，被剔除的质量恰为投影到同一任务位姿的零空间分量；冗余臂的假交互率与 `U_null/H(w)` 成正比，ANCHOR 将其归零。系：交互预算从「关节怎么动」转向「任务往哪走」。

**引理 20（金丝雀漂移可检性）** 漂移位姿偏差 δ、覆盖半径 ε_cover、L-Lipschitz 下，存在金丝雀使 `d_ee ≥ δ−2Lε_cover`；当 `δ>τ_canary+2Lε_cover` 时 DAP 以 ≥`1−exp(−Nc)` 检出。系：检测分辨率由覆盖而非标签决定——几何 oracle 比行为回归便宜。

**定理 18（引用监控组件无关安全性）** A101 下，若每步 `Cert_pose=OK`，则任何组件故障/投毒下实际执行轨迹均满足 `π_ee(ξ_exec)∈ℰ_pose`。学习输出只能经 PSC 到达执行器，PSC 依据独立 FK 实测而非组件自述，Violation 被替换为急停/撤离且撤离在 `ℰ_pose` 闭包内。故安全只依赖 `ℰ_pose` 与 FK，不依赖组件内部。

**定理 19（ANCHOR 严格包含 FLUID/R68）** A100–A103 下：① 全通过且 J_ee 局部满秩、无合并时 `d_ee∝d_action`，两者逐指令相同；② 认证失败时 λ 单调不降退化为 R68 的 `λ_floor(U_ale+U_epi)`；③ 硬失败急停。故期望安全风险 ≤ R69 ≤ R68，效率侧保留 resolution bonus；R69 = 「单一已签名栈 + 恒等位姿映射」边界。

**引理 21（开放度双刃上界）** 对手可见公开金丝雀比例 ρ_pub 并据此过拟合时，检出概率 ≥`(1−ρ_pub)(1−e^{−N_hid c})`；公开包络无法降低 `R_cw`，只能靠收紧 `ℰ_pose` 与扩展隐藏探针。系：开源提升可靠性，不自动提升安全性。

**定理 20（N 版本差分上界）** K 个独立实现各失败率 p、相关 ρ_prov，多数决失败率 ≤`Σ_{j>K/2} C(K,j)p_eff^j(1−p_eff)^{K−j}`，`p_eff≈p(1+(K−1)ρ_prov)/K`。系：同一 fork 的 K 个副本不算 K 个版本，provenance 距离必须入证书。

## 7. 本轮最大风险

**一句话**：ANCHOR 的安全性全押在「任务风险可因子化为末端位姿」（A100）上——**组件可以位姿处处合规却任务错误（抓错物、交给错的人、不该触时轻触），而开源让攻击者读到同一份公开包络与金丝雀、把恶意轨迹精确优化到边界**，系统于是得到「有证书的错误」：位姿对了，任务错了，还是被公开验证过的错。

**次级风险与缓解**：信任根被腐蚀（最简实现 + 形式化审计 + 只读域）；隐藏池泄漏（加盐承诺 + 轮换 + 分部署采样）；伪独立性（provenance 距离入证书）；包络过粗（收紧 ℰ_pose + 任务级隐藏探针 + 显式记录 R_cw）；认证开销（在线抽样、离线全量、异步摊销）。
