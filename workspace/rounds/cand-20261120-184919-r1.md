# 第 1 轮（新灵感循环：Gazebo × 仿真训练；基线 v16）

> **基线**：第 14 轮 MetricVoiceGauge-NCD-HUTDH-v16（定义 627–656；引理 131–136；实验 E671–E690）。
> 本轮纪律：**仿真不是证书，仿真只是证书的有界预言机**。不推倒 v16：BTS/TRM/WBC/CSC、NCS/MCA/WCB 与 v15→v14→v13→v12→v11→v10→v9→v8→v7→v6 全部保留。五个新组件——GST（Gazebo 仿真孪生）、FTM（保真度阶层管理器）、SGC（仿真—现实间隙证书）、SCC（场景覆盖证书）、STC（仿真训练链）——一律以**中立元**接入，失效即严格退回 v16（引理 142），再沿 v16→v15→…→v6 退化链退回。本轮只做三件事：把"Gazebo"改写为**带保真度阶层与区域间隙上界的证书预言机**、把"仿真训练"改写为**必须由实机锚点偿还的证书贷款**、把"仿真到现实的迁移"改写为**按区域、按预算、单调收紧的证书结算**。

## 0. 直觉与动机

**灵感 1（Gazebo → 有保真度阶层的证书预言机）**
直觉：Gazebo 能给出刚体动力学、接触、摩擦、传感器噪声、控制时延和 ROS 接口，于是很容易把"在仿真里跑通"误当成"证书成立"。但仿真不是现实，它只是一个**有偏的、可配置的、会过期的预言机**。核心创新：**Gazebo 仿真孪生（Gazebo Simulation Twin, GST）+ 保真度阶层（Fidelity Tier, F_i）+ 仿真—现实间隙证书（Sim-Real Gap Certificate, SGC）**。每次 Gazebo 查询返回的不是一个布尔安全值，而是 `(rollout, Cert_sim(F_i,R), Cov_sim(R), Gap_upper(F_i,R), provenance, expiry)`；任何仿真证书只有**减去独立估计的间隙上界**、并限定在**有实机锚点覆盖的区域 R** 之后，才允许被 v16 的 NC/MC 接受。关键反直觉点：**更高保真度不一定更小间隙**——高保真接触求解器可能更不稳定，参数误辨识可能被放大，执行器/时延建模可能反而引入新的偏差。因此保真度阶层只能是**经验验证过的偏序**，不能是想当然的全序；"保真度反转"必须被检测，而不是被假设不存在。

**灵感 2（仿真训练 → 证书贷款，而不是免费证书）**
直觉：仿真训练便宜，于是很容易把"训练损失下降 / 仿真成功率上升"当成"证书下界上升"。但训练只证明了**策略与仿真器的一致性**，没有证明**仿真器与现实的一致性**。核心创新：**仿真训练链（Simulation Training Chain, STC）+ 证书贷款 / 托管 / 偿还（Loan / Escrow / Ratification）**。每次训练带来的证书增益先记为**贷款** `L=(Δcert, q_real, T_due, λ)`，放入托管账本 `E`，**不得**用于推进里程碑 `m*`、提升 WBC 阶层 `h*`、或放宽任何 NC/MC 阈值；只有实机锚点按区域偿还后，托管增益才转为**已批准证书**。关键反直觉点：**仿真训练的产物不是"更强的策略"，而是"待偿还的证书债权"**——训练可以领先于部署，但绝不能领先于证书结算；训练越激进，未结算债权越大，系统反而越保守。

**灵感 3（Gazebo × 仿真训练 × v16 → 区域化证书结算与联合退化）**
直觉：v16 的 BTS 按节点证书推进、TRM 按里程碑推进、WBC 按模型阶层推进；加入 Gazebo 后多出第四维：**保真度阶层 F_i 与训练预算 B_train**。四者联立后，调度问题变成：在 `(B_tick, B_train, B_sim, m*, h*, F_i)` 下，选择"可被实机锚点覆盖的区域 R"内、证书已经结算的行为树节点。核心创新：**区域化证书结算（Regional Certificate Settlement, RCS）**：不把间隙当成全局标量，而是定义在场景区域 R 上；没有锚点覆盖的区域，间隙上界为 `+∞`，仿真证书一律不可接受。退化顺序固定为：先停训练（`B_train→0`），再降保真度（`F_i↓`），再缩场景集（`R↓`），再令间隙上界 `Gap→+∞`（仿真完全不可信），最后退回 v16 纯实机路径。**仿真只能让证书更便宜，不能让它更宽。**

**三者如何统一**
统一为 **v16 行为层之下的仿真证据层**：v16 回答"当前证书下能安全执行哪个行为序列"（`Exec_v16`），v17 回答"这些证书中，哪些可以用 Gazebo 证据以更低成本**结算**，哪些必须等待实机锚点"（`Exec_v17`）。GST 产生带保真度标签的轨迹；FTM 维护保真度偏序与间隙边界；SGC 用实机锚点估计区域化间隙上界；SCC 给出场景覆盖下界；STC 把训练增益记成贷款并托管。共享状态 `ζ_sim=(F_i, R, Gap_upper, Cov_lower, E, B_sim, B_train, B_real, expiry, drift_sim)`。**GST 回答"仿真说了什么"，SGC 回答"仿真的话能信多少"，SCC 回答"这些话覆盖了哪里"，STC 回答"训练出来的增益什么时候能算数"**。四者不是四个补丁，而是"证据—间隙—覆盖—结算"的仿真证据链。

## 1. 研究问题（轮次升级版）

- **Q1（保真度阶层与间隙）**：`F_i` 如何定义才能使 `Cert_sim(F_i,R) ⊆ Cert_sim(F_j,R)` 与 `Gap(F_j,R) ⊆ Gap(F_i,R)` 只在**经验可验证**时成立？如何检测"保真度反转"（更高保真度反而更大间隙）？阶层切换的瞬态证书如何定义？
- **Q2（区域化间隙与覆盖）**：如何用少量实机锚点给出区域 `R` 上的间隙上界？共形预测的交换性假设在"仿真—现实配对样本"上是否成立？域随机化如何避免"参数覆盖很广、分布覆盖很窄"的覆盖幻觉？覆盖证书如何在分布漂移下保持有效？
- **Q3（训练贷款与偿还）**：贷款 `L` 的额度、到期、利息如何定义才能保证 `Exec_v17⊆Exec_v16`？实机配额如何在区域间分配以最小化未结算债权？训练导致的灾难性遗忘、奖励黑客、仿真过拟合如何记为负增益？
- **Q4（联合退化与活性）**：`(B_tick,B_train,B_sim,m*,h*,F_i)` 六维预算下如何单调退化？仿真完全不可信时如何严格退回 v16？频繁的仿真—现实切换如何避免行为抖动？

## 2. 设计原则（在 P25–P27 基础上新增 P28–P30）

**P28 仿真即有界预言机律（Simulation as Gap-Bounded Oracle）**
任何 Gazebo 查询必须返回**证书四元组** `(Cert_sim, Gap_upper, R, expiry)`，而不是裸的成功率。仿真证书只有经过**独立于该仿真器**的实机锚点校准后，才可进入 v16 的 NC/MC：`Cert_real(F_i,R) = Cert_sim(F_i,R) ⊖ Gap_upper(F_i,R; A, δ)`，其中 `A` 是覆盖 `R` 的实机锚点集。若 `R` 没有锚点覆盖，则 `Gap_upper=+∞`，`Cert_real=∅`。**禁止用同一 Gazebo 配置生成的数据估计该配置的间隙**（自证循环）。

**P29 保真度—覆盖双维准入律（Fidelity–Coverage Two-Axis Admission）**
保真度阶层 `F_0 ⊂ F_1 ⊂ … ⊂ F_L` 必须同时维护两个独立维度：(1) **保真强度**，即 `Cert_sim(F_i,R) ⊆ Cert_sim(F_j,R)` 与 `Gap_upper(F_j,R) ⊆ Gap_upper(F_i,R)` 是否经实验验证；(2) **覆盖范围**，即 `Cov_lower(F_i) ≥ 1−δ` 的场景集 `R_i`。二者不可互相替代：高保真阶层往往覆盖窄，低保真阶层往往覆盖宽。准入门槛是 `F_i` 的**保真强度通过**且 `R ⊆ R_i` 且 `Cov_lower(R) ≥ Cov_min`；任一维不满足即拒绝。域随机化只能扩大参数覆盖，不能自动扩大分布覆盖；分布差异必须由 `ε`-覆盖证书单独给出。

**P30 仿真训练即证书贷款律（Simulation Training as Certificate Loan）**
每次训练产生的证书增益 `Δcert` 先记入**贷款账本** `L=(Δcert, q_real, T_due, λ)`，并冻结在托管 `E` 中；托管增益**不参与** `m*`、`h*`、`NC/MC` 阈值计算。只有实机偿还 `q_real` 个覆盖该区域的锚点、并通过间隙扣除后，托管增益才释放为已批准证书。贷款到期未偿还则**自动减记**（write-off），策略退回上一版已批准证书。训练可以领先部署一个课程窗口 `L_ahead`，但**不得**领先证书结算。

## 3. 与基线的接口（如何退化）

- **GST 失效** ⇒ 关闭 Gazebo，只使用 v16 的实机日志与已有校准集，等价 v16 路径；
- **FTM 失效** ⇒ 固定最低保真阶层 `F_0` 且 `Gap_upper=+∞`，仿真证书全部不可接受，只允许回放已结算轨迹；
- **SGC 失效** ⇒ `Gap_upper≡+∞`，所有仿真证书不可接受，等价 v16；
- **SCC 失效** ⇒ `R≡∅`，覆盖证书为空，仿真只能复现实机已验证场景，不能探索新区域；
- **STC 失效** ⇒ 训练停止，托管账本冻结，未结算债权全部减记，等价 v16（+只读 GST）；
- **五者全失效** ⇒ MetricVoiceGauge-NCD-HUTDH-v16，再沿 v16→v15→…→v6 退化链退回；
- **安全继承**：GST 只产生证据，FTM 只收紧保真度偏序，SGC 只做间隙扣除，SCC 只缩小场景集，STC 只做托管与减记。五端口均不能新增授权、不能放宽阈值、不能直接推进 `m*`/`h*`；`Exec_v17⊆Exec_v16` 由引理 139 保证。

## 4. 预期贡献

1. **保真度阶层化的仿真证书理论**：把 Gazebo 从"测试工具"改写为"带偏序、间隙、过期语义的证书预言机"，给出保真度反转检测与阶层切换的瞬态证书；
2. **区域化仿真—现实间隙证书**：用实机锚点 + 共形分位数给出区域级间隙上界，明确"无锚点即无证书"，解决仿真证据不可迁移的空白；
3. **仿真训练贷款/托管/偿还机制**：把训练增益从"免费证书"改写为"待偿还债权"，给出托管不变量与实机偿还样本复杂度，堵住训练自我授权；
4. **覆盖证书与反覆盖幻觉**：区分参数覆盖与分布覆盖，给出域随机化下的覆盖下界与对抗场景挖掘，避免"覆盖很广、盲区很大"；
5. **Gazebo→v16 端到端证据流水线**：把 GST/FTM/SGC/SCC/STC 作为中立元接入 v16 的 NC/MC/BTS/CSC，固定退化顺序，用 `Exec_v17⊆Exec_v16` 保持全栈安全继承；E691–E710 覆盖保真度嵌套、间隙反单调、自证不可辨识、覆盖下界、托管不变量、偿还收敛、联合退化、消融与端到端。

## 5. 本轮最大风险

**一句话**：仿真—现实间隙的证书本身仍是用 Gazebo 生成的数据估计的，一旦缺少独立实机锚点或锚点只覆盖"容易场景"，就会形成**自证循环**——系统在"保真度更高、覆盖更广、训练更充分、每一步证书都合法"的表象下，系统性地低估间隙，最终放行一个在 Gazebo 中完美、在 v16 证书栈内处处合法、却在真实接触/执行器/时延效应下**绝对不安全**的策略。

# IP-416 Gazebo Simulation Twin：把 Gazebo 查询封装为带出处与过期的证书预言机
class GazeboSimulationTwin:
    def __init__(self, world, robot, plugins, physics_cfg, sensor_cfg, version):
        self.world = world
        self.robot = robot
        self.plugins = plugins
        self.physics = physics_cfg
        self.sensors = sensor_cfg
        self.version = version
        self.provenance = self._hash_all()

    def query(self, policy, scenario, fidelity_tier, max_steps):
        """返回带保真度标签的 rollout 与仿真证书；不返回裸成功率。"""
        # 1. 装载保真度配置（物理/接触/执行器/传感器/时延）
        cfg = fidelity_tier.apply_to(self.physics, self.sensors)
        # 2. 运行 Gazebo（无头模式），采集轨迹与传感器流
        rollout = self._run_headless(policy, scenario, cfg, max_steps)
        # 3. 由轨迹计算仿真证书与覆盖标签
        cert_sim = self._certificate_from_rollout(rollout, fidelity_tier)
        cov_tag = self._coverage_tag(rollout, scenario)
        return SimEvidence(
            rollout=rollout,
            cert_sim=cert_sim,
            coverage_tag=cov_tag,
            tier_id=fidelity_tier.id,
            provenance=self.provenance,
            expiry=self._expiry(),
        )

    def _hash_all(self):
        return sha256(json.dumps({
            "world": self.world, "robot": self.robot,
            "plugins": self.plugins, "physics": self.physics,
            "sensors": self.sensors, "version": self.version,
        }, sort_keys=True))


# IP-417 Fidelity Tier Manager：保真度偏序、嵌套验证与反转检测
class FidelityTierManager:
    def __init__(self, tiers, validation_log):
        self.tiers = tiers                    # {i: F_i}
        self.order = self._build_certified_order(validation_log)
        self.inversion_flags = {}             # {(i,j): bool}

    def _build_certified_order(self, log):
        """只把实验验证过的 (i,j) 放入偏序；未验证的默认不可比。"""
        order = {}
        for (i, j), rec in log.items():
            nesting_ok = rec.cert_subset_violations == 0
            gap_ok = rec.gap_antitonic_violations == 0
            order[(i, j)] = nesting_ok and gap_ok
        return order

    def is_refinement(self, i, j):
        return self.order.get((i, j), False)

    def check_inversion(self, i, j, new_anchor_stats):
        """若更高阶 F_j 在已测区域出现更大间隙，标记保真度反转。"""
        if new_anchor_stats.gap(F_j)
           > new_anchor_stats.gap(F_i) + self.margin:
            self.inversion_flags[(i, j)] = True
            self.order[(i, j)] = False
            return True
        return False

    def select_tier(self, B_sim, required_R, certified_order):
        """在预算内选择最高且仍与 required_R 可比的已认证阶层。"""
        for i in sorted(self.tiers, reverse=True):
            if self.tiers[i].cost(required_R) <= B_sim and \
               all(self.is_refinement(i, k) for k in self.tiers if k < i):
                return self.tiers[i]
        return self.tiers[0]              # ⊥_FTM 的最低阶层


# IP-418 Sim-Real Gap Certificate：区域化间隙上界（实机锚点 + 共形分位数）
class SimRealGapCertificate:
    def __init__(self, anchor_store, delta=0.05):
        self.anchors = anchor_store       # {region: [(sim_rollout, real_rollout), ...]}
        self.delta = delta

    def gap_scores(self, tier_id, region):
        """每个锚点对给出一个单侧间隙分数：仿真高估了多少。"""
        scores = []
        for sim, real in self.anchors.get(region, []):
            cert_sim = sim.cert_sim
            cert_real = self._real_certificate(real)
            scores.append(one_sided_inflation(cert_sim, cert_real))
        return scores

    def upper(self, tier_id, region, delta=None):
        """区域 R 的 (1−δ) 共形间隙上界；无锚点则为 +∞。"""
        scores = self.gap_scores(tier_id, region)
        if len(scores) == 0:
            return float("inf")          # 无锚点即无证书
        d = self.delta if delta is None else delta
        q = conformal_quantile(scores, 1 - d)
        return q

    def real_certificate(self, tier_id, region):
        g = self.upper(tier_id, region)
        if g == float("inf"):
            return empty_certificate()
        return shrink(sim_certificate(tier_id, region), g)


# IP-419 Scenario Coverage Certificate：参数覆盖 vs 分布覆盖
class ScenarioCoverageCertificate:
    def __init__(self, descriptor_space, delta=0.05, cov_min=0.9):
        self.space = descriptor_space
        self.delta = delta
        self.cov_min = cov_min

    def coverage_lower(self, R, anchors):
        """Clopper-Pearson 覆盖率下界（保守）。"""
        n = len(anchors.get(R, []))
        hits = sum(1 for a in anchors.get(R, []) if a.in_region)
        return clopper_pearson_lower(hits, n, self.delta) if n else 0.0

    def distribution_gap(self, D_train, D_real_samples):
        """训练/部署分布差异上界（MMD 或 Wasserstein 自举上界）。"""
        return mmd_upper_bound(D_train, D_real_samples, self.delta)

    def certificate(self, R, anchors, max_tv=0.1):
        cov = self.coverage_lower(R, anchors)
        eps = self.distribution_gap(R.train_dist, R.real_samples)
        ok = (cov >= self.cov_min) and (eps <= max_tv)
        return CoverageCertificate(R=R, cov_lower=cov, eps_tv=eps,
                                   accepted=ok, expiry=now() + T_COV)


# IP-420 Simulation Training Chain：训练产生贷款，而不是免费证书
class SimulationTrainingChain:
    def __init__(self, gst, ftm, sgc, scc, escrow, asm):
        self.gst = gst
        self.ftm = ftm
        self.sgc = sgc
        self.scc = scc
        self.escrow = escrow
        self.asm = asm
        self.curriculum = []

    def train_stage(self, stage, policy, B_train, B_sim):
        """执行一个训练阶段，返回贷款 L；任何增益先入托管。"""
        if B_train <= 0 or B_sim <= 0:
            return None
        F = self.ftm.select_tier(B_sim, stage.R, self.ftm.order)
        cov = self.scc.certificate(stage.R, self.sgc.anchors)
        if not cov.accepted:
            return None                  # 覆盖不足，不允许探索新区域
        # 1. 仿真训练（域随机化 + 对抗场景）
        policy_new, sim_stats = self._run_training(policy, stage, F, B_train)
        # 2. 仿真增益估计（仅作贷款额度，不作授权）
        delta_cert = sim_stats.cert_gain
        # 3. 负增益检测：遗忘、奖励黑客、过拟合
        neg = self._detect_regression(policy, policy_new, stage)
        principal = max(0.0, delta_cert - neg)
        if principal == 0.0:
            return None
        # 4. 记录贷款：必须在覆盖区域内、必须有到期与偿还配额
        loan = CertificateLoan(
            delta_cert=principal,
            q_real=self._quota(principal, stage.R),
            T_due=now() + T_LOAN,
            lam=LAMBDA,
            region=stage.R,
            tier_id=F.id,
        )
        self.escrow.book(loan)
        return loan

    def _detect_regression(self, old, new, stage):
        """用保留集与负向场景估计训练回归，直接扣减本金。"""
        forget = eval_forgetting(old, new, stage.holdout)
        hack = reward_hacking_score(new, stage.reward_model)
        overfit = sim_overfit_gap(new, stage.holdout)
        return max(0.0, forget + hack + overfit)


# IP-421 Certificate Loan Escrow：未结算增益的托管账本
class CertificateLoanEscrow:
    def __init__(self):
        self.loans = []
        self.settled = {}

    def book(self, loan):
        self.loans.append(loan)

    def release(self, loan, ratified_gain):
        """只有实机偿还后才释放，且释放量不得超过已批准增益。"""
        loan.settled_gain = min(loan.delta_cert, ratified_gain)
        loan.status = "settled"
        self.settled[loan.id] = loan.settled_gain
        return loan.settled_gain

    def touch(self, now):
        """到期未偿还：按 λ 减记，并把状态标记为违约。"""
        for loan in self.loans:
            if loan.status == "open" and now > loan.T_due:
                loan.delta_cert *= (1 - loan.lam)
                loan.status = "written_off"

    def usable_gain(self, region):
        """只有已结算增益可参与证书计算；托管本金一律不计。"""
        return sum(g for loan, g in self.settled.items()
                   if loan.region == region and loan.status == "settled")


# IP-422 Real-Validation Quota Manager：稀缺实机配额的分配
class RealValidationQuotaManager:
    def __init__(self, sgc, escrow):
        self.sgc = sgc
        self.escrow = escrow

    def allocate(self, B_real, regions):
        """按"未结算本金 × 间隙敏感度 / 锚点边际收益"分配实机试验。"""
        score = {}
        for R in regions:
            open_loans = [l for l in self.escrow.loans
                          if l.region == R and l.status == "open"]
            principal = sum(l.delta_cert for l in open_loans)
            gap_sens = self.sgc.gap_sensitivity(R)
            n = len(self.sgc.anchors.get(R, []))
            score[R] = principal * gap_sens / (1 + n)
        total = sum(score.values()) or 1.0
        return {R: int(B_real * s / total) for R, s in score.items()}


# IP-423 Regional Certificate Settlement：把仿真证据结算进 v16
class RegionalCertificateSettlement:
    def __init__(self, sgc, scc, escrow):
        self.sgc = sgc
        self.scc = scc
        self.escrow = escrow

    def settle(self, tier_id, region, v16_cert):
        """返回 v17 可接受证书；只做交集与扣除，永不扩张。"""
        gap = self.sgc.upper(tier_id, region)
        if gap == float("inf"):
            return empty_certificate()        # ⊥_SGC
        cov = self.scc.certificate(region, self.sgc.anchors)
        if not cov.accepted:
            return empty_certificate()        # ⊥_SCC
        sim_cert = sim_certificate(tier_id, region)
        real_cert = shrink(sim_cert, gap)
        ratified = self.escrow.usable_gain(region)
        # 关键：ratified 也只用于"更便宜地达到同一阈值"，不改变阈值
        return intersect(v16_cert, real_cert, ratified)


# 主闭环集成：MetricVoiceGauge-NCD-HUTDH-v17（Gazebo 仿真证据层）
def metricvoicegauge_round_17_gazebo(M, s, obs, anchors, milestones,
                                     wbc_tiers, gazebo_cfg, ...):
    # ---- v16 主路径原样保留（BTS→TRM→WBC→CSC→守卫）----
    # ---- 构造仿真证据层（全部为中立元，可独立失效）----
    gst = GazeboSimulationTwin(**gazebo_cfg) if gazebo_available else None
    ftm = FidelityTierManager(ctx.fidelity_tiers, ctx.validation_log)
    sgc = SimRealGapCertificate(anchor_store=anchors, delta=ctx.delta_sim)
    scc = ScenarioCoverageCertificate(ctx.scenario_space, delta=ctx.delta_cov)
    escrow = CertificateLoanEscrow()
    stc = SimulationTrainingChain(gst, ftm, sgc, scc, escrow, ctx.asm)
    rvq = RealValidationQuotaManager(sgc, escrow)
    rcs = RegionalCertificateSettlement(sgc, scc, escrow)

    # ---- 1. 选择保真度阶层与可结算区域（受预算约束）----
    F = ftm.select_tier(ctx.B_sim, required_R=ctx.target_region,
                        certified_order=ftm.order)
    R = ctx.target_region
    gap = sgc.upper(F.id, R)
    if gap == float("inf"):
        # 无锚点：仿真完全不可信，严格退回 v16 实机路径
        return metricvoicegauge_round_16_humanoid_behavior(M, s, obs, ...)

    # ---- 2. 仿真训练：只产生贷款，不推进 m*/h* ----
    if ctx.B_train > 0 and ctx.B_sim > 0:
        loan = stc.train_stage(ctx.stage, ctx.policy, ctx.B_train, ctx.B_sim)
        # 训练期间不得改变 m*、h*；托管账本与部署闸门隔离
        assert ctx.m_star == ctx.m_star_before_training
        assert ctx.h_star == ctx.h_star_before_training

    # ---- 3. 实机偿还：按区域分配稀缺配额 ----
    if ctx.B_real > 0:
        alloc = rvq.allocate(ctx.B_real, regions=[R])
        for region, n in alloc.items():
            new_anchors = run_real_trials(ctx.policy, region, n)
            sgc.add_anchors(region, new_anchors)
            for loan in list(escrow.loans):
                if loan.region == region and loan.status == "open":
                    ratified = ratify(loan, new_anchors, sgc, ctx.delta_sim)
                    escrow.release(loan, ratified)

    # ---- 4. 到期减记与漂移审计 ----
    escrow.touch(now())
    if ctx.sda.drift_exceeded(gst, ctx.gazebo_baseline):
        # Gazebo 版本/插件/物理参数漂移：所有仿真证书立即过期
        sgc.invalidate_all()
        escrow.write_off_all()
        return metricvoicegauge_round_16_humanoid_behavior(M, s, obs, ...)

    # ---- 5. 区域化结算：只收紧 v16 证书，不放宽 ----
    v16_cert = ctx.v16_bundle.certificates_for(R)
    settled = rcs.settle(F.id, R, v16_cert)
    ctx.node_certificates = intersect(ctx.node_certificates, settled.node_certs)
    ctx.milestone_certs = intersect(ctx.milestone_certs, settled.milestone_certs)
    # 注意：m* 与 h* 仍由 v16 的 TRM/CSC 决定；仿真不得提升它们
    ctx.v16_bundle = rebind(ctx.v16_bundle, ctx.node_certificates,
                            ctx.milestone_certs)

    # ---- 6. 回到 v16 执行链（BTS/TRM/WBC/CSC）----
    return metricvoicegauge_round_16_humanoid_behavior(M, s, obs, ...)


# IP-424 Curriculum-Milestone Aligner：训练课程与里程碑 DAG 对齐
class CurriculumMilestoneAligner:
    def __init__(self, milestone_dag, lookahead=1):
        self.dag = milestone_dag
        self.lookahead = lookahead

    def stage_allowed(self, stage, m_star):
        """训练可领先 m* 至多 lookahead，但部署闸门仍由已结算证书控制。"""
        target = stage.target_milestone
        if target > m_star + self.lookahead:
            return False
        for prereq in stage.prereqs:
            if prereq.target_milestone > target:
                return False          # 课程边必须与里程碑 DAG 同向
        return True

    def project(self, stage):
        """训练只投影到 NC/MC 的证据字段，不投影到授权字段。"""
        return EvidenceProjection(stage.R, stage.F_i, stage.expected_gain)


# IP-425 Adversarial Scenario Miner：反覆盖幻觉
class AdversarialScenarioMiner:
    def __init__(self, gst, sgc, search_space):
        self.gst = gst
        self.sgc = sgc
        self.search_space = search_space

    def mine(self, policy, tier, budget):
        """搜索 Cert_sim 高但 Cert_real 低（或未知）的场景。"""
        candidates = []
        for s in self.search_space.sample(budget):
            sim = self.gst.query(policy, s, tier, max_steps=T_SIM)
            real_gap = self.sgc.upper(tier.id, s.region)
            if real_gap == float("inf") or real_gap > self.threshold:
                candidates.append((s, sim.cert_sim, real_gap))
        return sorted(candidates, key=lambda x: x[1] - x[2], reverse=True)


# IP-426 Simulation Drift Auditor：版本/插件/物理漂移
class SimulationDriftAuditor:
    def __init__(self, baseline_provenance, max_drift=0.02):
        self.baseline = baseline_provenance
        self.max_drift = max_drift

    def drift_exceeded(self, gst, baseline):
        if gst is None:
            return True
        cur = gst.provenance
        # 版本哈希变化或关键物理参数相对漂移超阈值

                relative_parameter_drift(cur.physics, self.baseline.physics)
                > self.max_drift)

## 2. 推导

**引理 137（经验保真序下的证书包含与间隙反单调）** 设保真度偏序 `F_i ⪯ F_j` 已在区域 `R` 上通过实验验证，即 `Cert_sim(F_i,R) ⊆ Cert_sim(F_j,R)` 且 `Gap_upper(F_j,R) ⊆ Gap_upper(F_i,R)`。则 `Cert_real(F_i,R) ⊆ Cert_real(F_j,R)`。证明：由定义 `Cert_real(F,R) = Cert_sim(F,R) ⊖ Gap_upper(F,R)`。`⊖` 对第一个参数单调增、对第二个参数单调减；由前提得 `Cert_sim(F_i) ⊖ Gap(F_i) ⊆ Cert_sim(F_j) ⊖ Gap(F_j)`。∎ 推论：**保真度只有经过验证才能被当作"更强"**；未验证的 `F_i ⪯ F_j` 不得用于任何证书推导，这正是 `FTM` 只维护"已认证偏序"的原因。

**引理 138（区域化间隙的共形有效性）** 设区域 `R` 的实机锚点对给出间隙分数 `{g_1,…,g_n}`，新场景 `s` 与锚点在该区域内可交换，且 `Gap_upper` 取 `{g_k}` 的 `(1−δ)` 共形分位数。则 `P(g(s) > Gap_upper) ≤ δ`。若交换性被破坏（锚点只来自易场景、或部署分布已漂移），则不存在任何有限样本保证。证明：标准共形预测的分位数覆盖定理；交换性破坏时，分位数不再对应部署分布的上分位点，构造反例即可。∎ 推论：**间隙证书是区域局部的**；`R` 外无锚点则 `Gap_upper=+∞`，这不是保守，而是唯一诚实的取值。

**引理 139（托管不变量与不扩张授权）** 定义 `Exec_v17 = {a ∈ Exec_v16 : a 位于有限间隙区域 R，且 Cert_real(F_i,R) 达到 v16 的准入阈值}`，其中 `Cert_real` 只使用已结算增益，托管本金不参与。则无论仿真训练多少轮、仿真成功率多高，恒有 `Exec_v17 ⊆ Exec_v16`。证明：对训练轮次归纳。初始时托管为空，`Exec_v17 ⊆ Exec_v16`。每轮训练只向托管写入贷款 `L`；`L` 不改变 `m*`、`h*`、`NC/MC` 阈值，也不改变 `Exec_v16` 的定义；`RCS` 只对证书做交集与收缩，`⊖` 与 `∩` 都不会增加元素。实机偿还后，`Rat` 释放的增益不超过实机锚点支持的下界，因此新证书仍是 `Cert_real` 的子集。归纳得证。∎ 推论：**仿真训练永远不能自我授权**；它只能把 v16 已允许的行为变得"更便宜地可证"，不能把 v16 不允许的行为变进来。

**引理 140（偿还样本复杂度）** 设贷款在区域 `R` 上要求间隙容忍 `γ`、置信度 `1−δ`。若用 Hoeffding 型单侧界，则至少需要 `q_real ≥ (1/(2γ²)) ln(1/δ)` 个独立实机锚点；若用分布无关的边际共形覆盖，则至少需要 `q_real ≥ ⌈1/δ⌉` 个锚点。因此实机总成本按**区域数 × 1/γ²** 增长，而不按仿真回合数增长。证明：Hoeffding 不等式令 `exp(−2qγ²) ≤ δ` 即得第一式；共形分位数的边际覆盖需要至少 `1/δ` 个校准点才能达到 `1−δ` 分位。∎ 推论：**仿真把实机样本从"场景×试验"降到"区域/γ²"，但永远降不到零**；声称"零实机样本即可迁移"的方案必然违反引理 143。

**引理 141（课程—里程碑对齐的单调性）** 设训练阶段 `T_j` 的目标里程碑为 `k(j)`，课程 DAG 满足 `T_j → T_l ⇒ k(j) ≤ k(l)`，且部署闸门只读取已结算证书。则：(1) 训练推进不改变 `m*` 与 `h*`；(2) 在退化事件下，`m*`、`h*`、`F_i`、`R` 均单调非增；(3) 固定退化顺序 `B_train → F_i → R → Gap → v16` 下，系统不会出现"训练升级、部署降级"的交叉跳变。证明：(1) 由部署闸门定义，`m*`/`h*` 只由 v16 的 TRM/CSC 与已结算证书决定，训练阶段不在其中；(2) 退化顺序是全序，任一步只减少预算/缩小区域/增大间隙，故各量单调；(3) 顺序固定排除交叉跳变。∎ 推论：**仿真训练可以领先，但只能领先在"证据生产"上，不能领先在"授权"上**。

**引理 142（五中立元退化安全）** 若 GST/FTM/SGC/SCC/STC 中任一失效，按定义 685 替换为中立元，则 `Exec_v17` 只减不增；五者全失效时系统严格退化为 v16，再沿 v16→v15→…→v6 退化。证明：逐项检查中立元：`⊥_GST` 移除仿真证据；`⊥_FTM` 令 `F=F_0` 且间隙 `+∞`；`⊥_SGC` 令间隙 `+∞`；`⊥_SCC` 令 `R=∅`；`⊥_STC` 停止训练并冻结托管。每个中立元都对应 `RCS` 中的空证书或收缩操作，故只减不增。全失效时 `RCS` 返回空证书，主路径等价 v16。∎ 推论：**仿真是可选加速器，不是安全依赖**；拆掉 Gazebo 不会让系统比 v16 更危险。

**引理 143（自证间隙的不可辨识性）** 若 `Gap_upper` 只使用同一 Gazebo 配置 `GST` 生成的数据估计（无外部实机锚点），则对任意有限 `g`，存在两个真实动力学 `E` 与 `E'`，它们在所有仿真场景上产生完全相同的 Gazebo 观测，但在某个区域 `R` 上有 `Gap(E,R) ≤ g` 而 `Gap(E',R) = +∞`。因此不存在仅凭仿真数据可证的有限间隙上界。证明：Gazebo 观测只依赖其自身转移核 `P_GST`。取 `E` 为与 `P_GST` 接近的真实系统；构造 `E'`：在仿真支撑集（被 `P_GST` 赋予正概率的场景）上与 `E` 完全一致，在仿真支撑的零测集或未建模工况（如特定接触刚度、执行器死区、通信时延尖峰）上取任意大的偏差。由于仿真从不采样这些工况，`E` 与 `E'` 的仿真观测分布相同，但真实间隙在 `R` 上可任意大。∎ 推论：**"仿真自证"在数学上无效**；至少需要一类独立实机锚点，且锚点必须覆盖被认证的区域。这正是 `SGC` 强制"无锚点即 `+∞`"、`ASM` 专门挖掘仿真盲区的理由。

## 6. 已知风险与失效模式

1. **自证循环的残余**：即使引入实机锚点，锚点也可能由同一团队、同一批场景、同一套安全员采集，形成"社会性自证"。缓解：独立锚点审计、跨团队/跨场地锚点、锚点覆盖矩阵、盲区强制标 `+∞`。

2. **区域划分的粒度风险**：区域 `R` 划得太粗，间隙上界被少数难场景拉高，导致活动性塌缩；划得太细，锚点不足，绝大多数区域 `Gap=+∞`。缓解：自适应区域合并/分裂、层次化区域、按间隙敏感度分配锚点、最小区域样本数约束。

3. **保真度反转**：更高保真度的 Gazebo 配置在接触求解、执行器建模或时延上反而更偏离真实，导致 `Cert_sim` 变大但 `Gap` 也变大。缓解：`FTM` 只维护经验偏序、在线反转检测、按区域而非全局比较、保守取交集。

4. **共形交换性破坏**：实机锚点与部署场景不交换（例如只在实验室平地采锚点，却要部署到粗糙地形），共形分位数不再有效。缓解：分层共形、加权共形、按区域校准、分布漂移检测触发重新校准。

5. **覆盖幻觉**：域随机化覆盖了很宽的参数空间，但没有覆盖真实的接触模式/负载/时延组合。缓解：参数覆盖与分布覆盖分离、ASM 最大化证书差、对抗采样、拒绝"只报参数范围"的覆盖声明。

6. **训练回归与奖励黑客**：仿真训练可能过拟合仿真器伪影，或在仿真奖励上刷分，导致 `Δcert` 为假。缓解：负增益检测、保留集、跨保真度一致性、真实锚点偿还、训练前后证书回归测试。

7. **实机配额饥饿**：`B_real` 太小，贷款长期无法偿还，托管膨胀后集中减记，造成"训练很多、能力突然回退"。缓解：按到期时间排序、限制未结算本金上限、训练速率与偿还速率耦合、提前预警。

8. **间隙上界的乐观偏差**：锚点样本少时共形分位数方差大；若锚点采集偏向安全场景，上界仍可能低估。缓解：保守分位数、Clopper-Pearson、主动选择高间隙场景、独立审计。

9. **Gazebo 版本/插件漂移**：升级 Gazebo、替换物理插件或修改世界文件会改变仿真分布，旧证书失效。缓解：内容哈希、版本锁、漂移审计、证书 TTL、升级后强制重验证。

10. **仿真—现实时序错配**：Gazebo 的时延、传感器采样与真实控制器不同步，导致仿真中学到的时序策略在实机上失效。缓解：时延/抖动注入、实时因子校准、硬件在环、时间戳一致性检查。

11. **多区域证书冲突**：同一策略在区域 `R_1` 已结算、在 `R_2` 未结算，切换时可能把已结算区域的增益错误地用于 `R_2`。缓解：区域标签随证书传播、禁止跨区域转移托管增益、区域切换时重新结算。

12. **v17 与 v16 证书栈的累积保守性**：间隙扣除 + 覆盖限制 + 托管隔离会进一步收缩证书，可能让系统长期只能跑 v16 的 Fallback。缓解：按区域结算、优先偿还高价值区域、证书价值加权、动态分配实机预算、监控活动性下限。

## 7. 本轮最大风险

**一句话**：当实机锚点缺失、稀少或只覆盖"容易场景"时，`Gap_upper` 会退化为一个看似有限、实则系统偏低的估计；于是 Gazebo 训练出的策略在"保真度已认证、覆盖已达标、贷款已部分偿还、每一步都满足 v16 证书"的表象下被放行，而真实世界的未建模接触/执行器/时延效应恰恰落在仿真零测集里——这就是**自证间隙导致的、证书自洽的、却绝对不安全的仿真到现实迁移**。
