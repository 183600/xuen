# 第 58 轮（承接第 57 轮「少样本元推断×跨模态对账×个性化有界信任」IP-133~138；灵感循环第 4 轮；本轮灵感：「单模型多任务」×「机器人」）

> 第 57 轮用三个机制把"证据说可信"补成少样本可校准、跨模态可对账、个性化有界；但它的全部安全性都建立在一组**分离假设**上：元先验与共形保底分离、视觉/触探/本体/声学四路证据分离、操作者信任与决策本分离。本轮两个灵感恰好从架构层抽掉这组分离：**单模型多任务**让一个共享主干同时产出导航风险、探针后验、接触承诺与解释——效率与泛化来自共享，失效也随之共享；**机器人**提醒这个共享主干不是离线批处理，而是嵌在实时闭环里，安全任务必须与其他任务争夺同一份算力与同一层表征。于是第 57 轮的"物理共谋"升级为"**架构共谋**"：不是某个物理性质同时骗过两个模态，而是同一个表征错误同时点亮所有任务头；"跨模态一致"可能退化为"同一个错误潜变量的多个投影"。本轮命题升级为 **"可分离、可回退、任务分账的单模型多任务机器人安全"**：效率押在共享上，安全押在"共享可被检测地拆开"与"安全任务可退回独立通道"上。

核心矛盾：
- **H29（共享 vs 共模失效）**：单主干让误差跨任务相关，EV-xmodal/XTC 所依赖的"独立证据"被架构级相关性稀释；独立性从物理假设变成需要被证明、且可能证不出来的性质。
- **H30（多任务 vs 安全任务稀释）**：联合训练里安全相关任务只占损失的一小项，梯度冲突与容量竞争可能让"最不该退化的任务"最先退化；多任务的正则收益不能替代对安全任务校准的单独守界。
- **H31（泛化广度 vs 权限隔离）**：通用机器人模型天然诱导"一个任务上攒的信任/授权迁移到另一个任务"；信任若是标量，任务 A 的严谨记录会被任务 B 的不可逆接触借用。

## 0. 直觉与动机

**灵感 1（单模型多任务 → 共享表征的效率账与共模账）**
直觉：一个主干干十件事，样本效率、跨任务泛化、部署成本都变好——这是所有统一机器人模型的卖点。但安全账要反过来算：**共享表征把原来"多买一份保险"的冗余，换成了"一次写错、处处读错"的杠杆**。第 57 轮说"同一模态重复五遍只是把同一个错误问五遍"；本轮更狠：**不同任务读同一个潜变量，也可能只是同一个错误的多个投影**。所以共享不是罪，**"共享而不可分离"才是罪**：能用残差独立性证书证明各任务在给定 z 后仍条件独立，才允许把跨任务一致当证据；证不出就只允许它做警报，不允许它做承诺证据。

**灵感 2（机器人 → 单主干在实时闭环里的资源与回退）**
直觉：机器人不是一次前向就结束——感知、探针、步态、解释都挂在同一个节拍上。单模型省下的算力如果不做**安全任务优先级分区**，就会被解释渲染或新任务推理挤占，安全任务反而最先超时。真正可部署的形态是"**共享求效率、隔离保底线**"：日常走共享主干；一旦共模门报警、或安全任务 p99 逼近 τ_sla，就切到**独立安全通道**（单任务安全头/不共享编码器的窄模型），宁可慢、宁可丑，绝不与无关任务共享最后一次判断。

**灵感 3（合流 → 任务分账的证据与信任）**
直觉：第 57 轮把证据按模态分账；本轮把证据、权限、不确定性都**按任务分账**：证据类必须声明"由哪个任务头、哪份残差独立性证书产生"；操作者信任从标量 auth 变成按任务/风险类别的向量 a_o[τ]；**信任不可跨任务迁移，尤其不可迁移到不可逆接触**——在"导航标注"上攒的信用，不能给"冰面首次踩踏"背书。任务广度增加的是能力，不是授权。

**灵感 4（合流 → 证据门五类 → 六类，新增 EV-xtask 且限 L1）**
直觉：跨任务一致 EV-xtask 是便宜的新证据，但它的独立性比跨模态更可疑（共享主干）。因此只允许它在 L1 非不可逆接触上顶替一次佐证，且必须过**共模门**（残差独立性 + 单潜变量翻转测试）。不可逆接触必要证据集仍只认 EV-probe*/EV-margin + 独立佐证，绝不接受"两个任务头都这么觉得"。

**灵感 5（PCE++ → 任务调度、任务级 VOI 与安全降级序）**
直觉：每检查点先分配预算：安全任务固定切片 B_s 与优先级，其余任务（解释、建图刷新）用剩余预算且可降级；VOI 以"共享表征下的悲观后验"计算；若共模门失败，先做**拆分歧探针**（强制不同任务的独立通道复算），再决定承诺/绕行/降档；安全通道切换本身计入证书。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（多任务共享表征 MTSC）** 任务集 𝒯=𝒯_s∪𝒯_o，安全任务 𝒯_s={probe_est, nav_risk, contact_commit}，其他任务 𝒯_o={explain, map_refresh, …}；共享编码器 E_ψ:o→z，任务头 h_τ(z)。任务误差相关矩阵 K_ττ'=corr_r(err_τ(r),err_τ'(r)|context)，有效独立数 n_eff=(Σ_iλ_i(K))²/Σ_iλ_i(K)²。声明：(C1) 安全任务切片 B_s 与 p99 时延界 τ_sla；(C2) 对每个需要独立性的证据类，给出**给定 z 后的残差独立证书** ρ_res≤ρ_0；(C3) 单潜变量翻转测试：跨任务同时翻转率 max_δ∈Δ ||Δh_τ(δ)|| 同时过阈的比例 ≤δ_cmf。

**定义 140（共模失效门 CMG）** 对任意依赖"多通道独立"的证据类（EV-xmodal、EV-xtask、多任务投票），共模门：pass ⇔ n_eff≥n_min ∧ ρ_res≤ρ_0 ∧ 翻转测试通过 ∧ max K_ττ'≤θ_K。pass 才允许该证据类按原级使用；fail ⇒ 该证据类**降级为警报**（只能加宽后验、触发探询/降档，不能充当承诺证据）。定义"拆分歧探针"：强制用独立窄通道（不共享 E_ψ）复算分歧最大的 τ，成本 k_split。

**定义 141（安全任务负迁移护栏 NTG）** 联合训练约束：min Σ_τ L_τ s.t. ECE_safety(θ_joint)≤ECE_safety(θ_single)+δ_nt ∧ 安全回归套件通过率≥1−δ_reg ∧ 安全头梯度冲突经投影/隔离适配器消解。安全头允许**低秩隔离适配器**与冻结安全关键层；在线更新若使安全回归超过 δ_nt 即回滚。安全任务对联合目标有**否决权**（safety veto）。

**定义 142（跨任务对账 XTC）** 任务条件信念 {b_r^τ}，D_T(r)=Σ_{τ<τ'} d(b_r^τ,b_r^τ')（标签 TV + 关键分位差）。规则：(T1) D_T>θ_T ⇒ P_fail 以跨任务加宽混合计算（分歧即不确定性下限）；(T2) EV-xtask ⇔ D_T≤θ_T ∧ CMG.pass(τ,τ') ∧ 与融合同侧，仅可替代 L1 一次佐证，禁入不可逆必要证据集；(T3) 任务头事后证伪 ⇒ 该任务证据回溯降权，并触发对共享表征的**归因审计**（任务头错还是 z 错；若多任务同时证伪则判共模事件，冻结该 z 邻域并全局降权）。

**定义 143（任务条件化信任 TCT）** 操作者状态 s_o=(cal_o,vig_o,a_o[τ],auth_hist)，a_o[τ]∈{A0,A1,A2} 按任务/风险类别。升级只作用于被证实的那一类任务；**迁移矩阵 M_tr 强制块对角保守**：跨任务迁移仅允许更保守方向（A2→A1），永不允许跨类别升级，且不可逆接触任务只认其自身的 n_verify 记录。w_h,τ=min(w_max^g,w0·cal_o,τ)；全局硬界与决策规则本体不变。

**定义 144（多任务证据门 MTE 与证书 J_t）** 证据类 EV-probe*/EV-visit/EV-margin/EV-xmodal/EV-xtask/EV-human，每个证据携带 (τ 来源, CMG 证书, 残差独立证书, 任务可信域)。门规则：依赖独立的证据必须有 CMG.pass；EV-xtask 硬限 L1；安全任务证据必须由 τ∈𝒯_s 且 p99≤τ_sla 的通道产生。J_t=(M_core,C_core,K_margin,ρ_sem,δ_s,probe_log,consent_log,evidence,meta_cal_log,xmodal_log,xtask_log,cmg_log,auth_log,ood_registry,safety_reg_log,resource_log)，继承 J_p 全检。

## 2. 关键算法伪代码（完整版见产物区）

```python
def multitask_infer(E, heads, o, task, budget):     # IP-139/140
    z = E(o)
    if not budget.admit_safety(task):               # 安全任务优先级
        return fallback_isolated(o, task)           # 独立窄通道
    b = heads[task](z)
    return b, z

def common_mode_gate(K, resid, flip_rate, thresholds):
    n_eff = (sum(eig(K)))**2 / sum(e**2 for e in eig(K))
    ok = n_eff >= thresholds.n_min and resid <= thresholds.rho0 \
         and flip_rate <= thresholds.delta_cmf and max(K) <= thresholds.theta_K
    return ('pass' if ok else 'alert_only')         # 失败只降级为警报

def cross_task_evidence(bs, K, cmg, level):         # IP-142
    D = sum(dist(bs[a], bs[b]) for a, b in pairs(bs))
    if cmg == 'pass' and D <= theta_T and level == 'L1':
        return 'EV-xtask'
    return None                                      # 不可逆接触永不用
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| MTSC | O(d_ψ)+O(d_τ)/任务；回退 O(d_iso) | O(\|ψ\|+\|τ\|·d_τ) | 安全切片与 p99 界、残差独立证书诚实 |
| CMG | O(\|𝒯\|²) 离线 + O(1) 查表 | O(\|𝒯\|²) | n_eff/翻转测试/阈值、失败只降级 |
| NTG | O(1)/步 + O(N_reg) 回归 | O(\|θ_safety\|) 隔离 | 安全回归≤δ_nt、安全否决 |
| XTC | O(\|𝒯\|²·d_b)/区域 | O(\|V\|·\|𝒯\|·d_b) | 仅 L1、CMG.pass、共模事件归因 |
| TCT | O(1)+O(\|𝒯_s\|) | O(\|操作者\|·\|𝒯\|) | 块对角迁移、不可逆任务不借权 |
| MTE | O(\|σ\|) | O(\|σ\|) | 独立证据必挂 CMG、无证书即拒 |

**正确性定理（Separable Multi-Task Soundness, SMTS 概要）**：在 A37–A40 上加 (A41) 共模门诚实：CMG.pass 的类残差独立 ρ_res≤ρ_0 且翻转率≤δ_cmf，fail 类只作警报；(A42) 安全任务护栏：ECE_safety 退化≤δ_nt 且安全回归≤δ_reg，在线更新不越过；(A43) 任务条件信任不可跨类升级、不可逆任务只认自身记录；(A44) 安全任务实时切片保证 p99≤τ_sla，资源不足先降非安全任务。则：(i) 承诺失效率 ≤δ_f+ε_meta(k)+δ_probe+ε_h+δ_ood·α_conf+δ_xm·1[L1∧CMG.pass]+δ_xt·1[L1∧CMG.pass]+δ_cmf；(ii) 分离单调性：共享只允许经"CMG.pass 的窄证据"或"更保守资源/权限"提高效率，任何共模报警只降不升；(iii) PCE++ 在 k_probes+k_cons+k_split 内终止，安全通道切换可数且计入证书。

## 6. 本轮最大风险

**一句话**：本轮的赌注从"坏先验普遍"进一步变成"**共模失效普遍**"——单主干一旦在新材质上形成错误的共享潜变量，导航、探针、承诺与解释会同时犯错，而跨任务一致（EV-xtask）恰恰把这种"同一个错误的多个投影"包装成独立证据；必须坚持"证不出残差独立就只让一致性当警报"、任务条件信任绝不跨任务迁移到不可逆接触、并保留一条可随时接管的安全独立通道，否则省下的算力会以相关性风险的形式一次性还回来。

# 第 58 轮产物 · 创新点清单 v34：OneModel-MultiTask-Safe（单模型多任务的共模门×安全任务护栏×跨任务对账×任务条件信任，MTSC×CMG×NTG×XTC×TCT×MTE）

## 2. 关键算法伪代码

### IP-139 MTSC（多任务共享表征与安全资源分区）

```python
def multitask_infer(E, heads, o, task, budget):
    if task in SAFETY_TASKS:
        if not budget.reserve(B_s=budget.safety_slice, deadline=tau_sla):  # C1
            return fallback_isolated(o, task)        # 独立窄通道先保底
    z = E(o)
    b = heads[task](z)
    budget.charge(task, z)                           # 记录共享主干占用
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MTSC | O(d_ψ)+O(d_τ)/任务；回退 O(d_iso) | O(\|ψ\|+\|τ\|·d_τ) | 安全切片与 p99 界、残差证书诚实（A41/A44） |
| CMG | O(\|𝒯\|²) 离线 + O(1) 查表 | O(\|𝒯\|²) | n_eff/翻转/耦合阈值；fail 只降级 |
| NTG | O(1)/步 + O(N_reg) 回归 | O(\|θ_safety\|) 隔离 | 安全 ECE 退化≤δ_nt、安全回归≤δ_reg（A42） |
| XTC | O(\|𝒯\|²·d_b)/区域 | O(\|V\|·\|𝒯\|·d_b) | 仅 L1、CMG.pass、共模事件归因（A41） |
| TCT | O(1)+O(\|𝒯_s\|) | O(\|操作者\|·\|𝒯\|) | 块对角迁移、不可逆不借权（A43） |
| MTE | O(\|σ\|) | O(\|σ\|) | 独立证据必挂 CMG、无证书即拒 |
| PCE++ | O(\|CP\|·(k_p+k_c+k_s)·(C_VOI+d_ψ)+\|CP\|·A\*) | O(\|V\|+\|σ\|) | 悲观元 VOI、三预算终止、安全降级序 |

**正确性定理（Separable Multi-Task Soundness, SMTS）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；**(A41)** 共模门诚实：CMG.pass 的类满足残差独立 ρ_res≤ρ_0、翻转率≤δ_cmf、n_eff≥n_min，fail 类只作警报；**(A42)** 安全任务护栏：联合训练的 ECE_safety 退化≤δ_nt 且安全回归套件通过率≥1−δ_reg，在线更新越界即回滚；**(A43)** 任务条件信任：升级只作用于被证实任务类、M_tr 块对角且只向保守、不可逆任务只认自身记录；**(A44)** 安全任务实时切片 B_s 保证 p99≤τ_sla，资源不足先降非安全任务。则：

1. **承诺健全性**：\(P(\text{fail}) \le \delta_f+\varepsilon_{meta}(k)+\delta_{probe}+\varepsilon_h+\delta_{ood}\alpha_{conf}+\delta_{xm}\mathbf{1}[L1\wedge CMG]+\delta_{xt}\mathbf{1}[L1\wedge CMG]+\delta_{cmf}\)。
2. **分离单调性**：共享主干只能经 (a) 通过 CMG 的窄证据或 (b) 更保守的资源/权限参数影响系统；任何共模报警、安全回归、SLA 逼近都只产生降级，不存在升险路径。
3. **信任不迁移**：跨任务借权最多把授权降到二者较保守值，且对不可逆接触无效；任务广度不产生授权通胀。
4. **终止性与降级完备**：PCE++ 在 k_probes+k_cons+k_split 内终止于 {承诺, 绕行, L2 协商, 安全停}；安全通道切换可数并计入证书。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf
                  + (δ_xm+δ_xt)·1[L1∧CMG.pass] + δ_cmf)
             − P(𝓜 陈旧未检出) − P(护盾回退失败) − P(安全通道切换失败)
             − P(安全任务 p99>τ_sla ∧ 降级失效) − P(安全回归未检出)
```

关键：**共享给效率、可分性给证据、隔离给底线**；EV-xtask 只是 L1 的廉价佐证，且"证不出独立就只当警报"；任务条件信任让能力增长不自动变成授权增长；安全独立通道是单主干架构的最后保险。

## 6. 本轮最大风险

**一句话**：本轮的赌注从"坏先验普遍"进一步变成"**共模失效普遍**"——单主干一旦在新材质上形成错误的共享潜变量，导航、探针、承诺与解释会同时犯错，而跨任务一致（EV-xtask）恰恰把这种"同一个错误的多个投影"包装成独立证据；若再允许任务间信任迁移，单次表征错误就会同时穿过证据门与授权门。必须以残差独立证书（证不出只当警报）、安全任务独立通道与安全回归门、任务条件不可迁移信任三重护栏，宁可回退到又慢又窄的独立模型，也不让一个共享潜变量替所有任务签字。
