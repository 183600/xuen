# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环第 1 轮；本轮灵感：「物体泛化」×「轨迹优化」）

> R69 学会了「问」：看不清就看、拿不准就问、摸不透就触。但它问的都是**动作模态**和**测量可信度**，并默默预支了一个危险前提——**物体的物理属性已知**。真实世界的「物体泛化」恰恰死在这里：杯子看起来一样，却重了三倍；盒子看起来能拿，其实被胶粘住；水果看起来完好，一捏就烂；同一把剪刀，有的铰链松得能自己张开，有的紧得掰不动。这些属性**在接触之前几乎不可见**，任何视觉不变性、外观数据增强、语义 OOD 检测都读不出质量、摩擦、质心、柔顺、脆性与关节阻尼。
>
> 本轮两个灵感正好从两端把缺口补上：
> - **物体泛化**不是「对物体外观不变」，而是「对新物体的物理参数快速辨识 + 在参数后验上稳健决策」；
> - **轨迹优化**不只是「找一条完成任务的路」，而是**唯一能主动读出物理参数的传感器**——轨迹是接触的调度表：抬升读出质量与质心，滑动读出摩擦，加载读出刚度，挤压读出脆性；而这条轨迹本来就要执行。
>
> 核心命题：**把「物体泛化」重述为一个「可辨识性 + 覆盖」问题：让任务轨迹本身充当物理探针（双重控制），在安全/损伤预算内最大化任务相关子空间的可辨识度；在物体参数后验上做风险敏感轨迹优化；用留出接触预测而非在线拟合来检测模型类错配；用参数覆盖半径与 Lipschitz 后悔界来「证明」泛化，而不是用留出物体的成功率来「宣称」泛化。** 命名 **PIVOT-RAS**（Physical Identification Via Optimized Trajectories）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这个我没见过的物体，我能不能在不弄坏它的前提下，边做边把它摸清楚，并证明我对它的泛化不是运气？**」

## 0. 直觉与动机

**灵感 1（物体泛化 → 真正的泛化差距是「物理不可见性」，不是外观相似度）**
直觉：现代 VLA/流策略的泛化叙事几乎都围绕「见过的形状/语义」展开：换颜色、换纹理、换实例、换背景。但部署时最致命的是**同形异质**：外观在训练分布内，物理参数却在分布外。视觉编码器对这个差距近乎失明，因为质量、摩擦、质心、柔顺度不是像素的函数（它们最多通过材质、反光、阴影给出极弱的先验）。于是系统会「自信地泛化」——动作分布仍然高似然，失败却发生在第一次接触。R69 的 FMA 也抓不到这类失败：策略并不是「不确定」，而是「在错误的物理模型上很确定」。**物体泛化首先是一个物理辨识问题，其次才是一个感知问题。**

**灵感 2（轨迹优化 → 轨迹即探针，「边做边称重」是双重控制的天然形态）**
直觉：想称一个东西，不一定要把它放到秤上；抱起它、感受加速度与关节力矩，就能估质量。想测摩擦，不一定要专门的摩擦仪；让它滑一下就知道。想测质心，转一下就知道。**任务的执行轨迹本身，往往已经包含了对物体参数最自然的激励**：抓取—抬升激励质量/质心/夹持摩擦，推—滑激励库仑摩擦与法向力，插入—卡阻激励柔顺与间隙，开合—旋转激励关节阻尼与行程。于是「辨识」不是额外加一段探测动作，而是**在任务轨迹的零空间中注入一点激励**：不改变任务意图，只改变可辨识性。这就是控制论里的双重控制（dual control）——动作同时服务于「达成目标」和「减少模型不确定」。轨迹优化因此获得第二重目标：**安全性 × 任务代价 × 信息增益**，而三者可以用同一份执行预算支付。

**灵感 3（泛化要可证 → 从「留出物体成功率」升级为「参数覆盖 + 后悔界」）**
直觉：在 100 个留出物体上成功率 92%，并不告诉你第 101 个物体会怎样，更不告诉你失败时有多惨。真正可迁移的陈述应是：**该物体的物理参数离训练支撑有多远、任务代价对该参数的敏感度有多大、不可辨识方向是否恰好是任务无关方向。** 若任务代价对 ω 的 Lipschitz 常数为 L_J、参数覆盖半径为 r，则最坏后悔有一个形如 2·L_J·r 的界；于是「泛化」变成一个可以随证书发布的 (r, L_J, ρ_task) 三元组，而不是一个点估计。更进一步：**若某参数不可辨识（Fisher 信息为零），那么任何声称「已泛化到该参数」的结论都是空的**——这正是 Cramér–Rao 下界给出的硬约束。这让我们能把「泛化」从营销词变回可反驳的科学陈述。

**灵感 4（组合性 → 新物体多半是旧原语的重新组合，泛化应发生在原语参数空间）**
直觉：现实中「没见过的物体」很少是全新的物理定律，更常见的是已知原语的重新组合：刚性块 + 抽屉滑轨 + 软垫 + 容器 + 铰链。因此与其在外观空间做不变性，不如把物体表示为**带参数的物理原语图**（rigid / joint / deformable / container / tool），泛化 = 在原语参数空间里覆盖 + 组合合法性判定。这样「新物体」的误差可以分解为「各原语参数误差之和 + 组合模型误差」，泛化证书也就能写成可加界。组合视角还有一个安全收益：**当组合合法性无法确认时（比如怀疑有隐藏铰链），系统知道自己处在组合外推区，而不是把它误当成一个普通刚体。**

**灵感 5（对偶通道 → 正面回应 R69 的最大风险，并警惕新的「辨识吸收」）**
直觉：R69 最怕「流模型的模态分布不可信」，于是用 FMA 做行为似然第二意见。但「同形异质物」可以被行为似然完全放过：策略在错误物理模型上照样高似然地生成动作。所以 R70 必须再加一条**物理通道**：用接触力/位姿的**留出预测残差**来问「我估出来的物体参数，能不能预测我还没见过的接触？」。更关键的是，必须警惕 R68 老毛病的翻版——**在线辨识会把模型错配吸收掉**：用整段接触史拟合 ω̂，当然能把残差拟合到很小（就像标定层吸收缓变故障）。因此物理通道必须做「前缀辨识、后缀验证」的留出检验，并且跨接触模式交叉验证；否则「已辨识」只是一个更精致的自欺。**轨迹既是探针，也会成为共犯——它能把错误物理解释成一组刚好合适的参数。**

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PIVOT-RAS 总览）** PIVOT-RAS = (OPG, PTO, AID, SPM, GCC, PCM, MRC, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **探测预算硬约束**：探针力/速度/位移不得越过物体安全包络，累计损伤 ≤ D_max，且探针与 R69 的信息动作共享同一份预算；所有探针都必须通过与任务动作相同的 C-RAS-WM 认证；
(iii) **可辨识性纪律**：未在任务相关子空间达到 ρ_task ≥ ρ_min 时，不得在证书中声称「已识别/已泛化」；不得把模型类错配吸收进 ω̂；无法安全探测时进入最小后悔保底（MRC），而非编造参数。

**定义 311（物体物理参数化）** 物体 𝒪 = (e, G_𝒪, ω)。e ∈ ℝ^{d_e} 为语义/外观嵌入；G_𝒪 为物理原语组合图（节点：rigid / joint / deformable / container / tool，边：固定/铰接/接触）；ω ∈ Ω ⊆ ℝ^{d_ω} 为物理参数（质量、质心、惯量、库仑/粘性摩擦、恢复系数、刚度、阻尼、脆性阈值、关节行程与阻尼）。每个原语 i 有参数子向量 ω_i，Ω = ∏ Ω_i。

**定义 312（物体属性后验 OPG）** 给定交互史 H_t（视觉、本体感知、接触力/位姿、滑移事件），物体物理后验 b_t(ω) = p(ω | e, G_𝒪, H_t)。不假设单峰；实现为粒子/混合模型，并显式维护「已激励方向」与「未激励方向」。

**定义 313（接触 Fisher 可辨识度）** 接触观测模型 y_t = h(ξ_t, ω) + ε_t，ε_t 为次高斯噪声。轨迹 ξ 的 Fisher 信息
F(ξ; ω) = Σ_{t=0}^{H} Φ_tᵀ Σ_y^{-1} Φ_t，Φ_t = ∂h(ξ_t, ω)/∂ω。
令 P_task 为「改变任务最优代价超过 ε_J 的参数方向」的正交投影，任务相关可辨识度
ρ_task(ξ) = λ_min(P_task F(ξ; ω) P_task) / λ_max(Σ_y)。
ker F 中的方向为**不可辨识方向**：沿该方向的任何无偏估计方差无界（引理 19）。

**定义 314（物理感知轨迹优化 PTO）** 对候选轨迹 ξ，
ξ* = argmin_ξ E_{ω~b_t}[J(ξ; ω)] + λ_r CVaR_α[J(ξ; ω)] + λ_s Risk_safe(ξ) − λ_i IG(ξ)
s.t. ∀ω ∈ Ω_{1−δ}: ξ ∈ Ξ_safe(ω)，D(ξ) ≤ D_max。
其中 J 为任务代价，CVaR 度量为参数不确定性下的尾部风险，Risk_safe 为几何/碰撞/伤害风险，IG 为按定义 315 的信息增益。实时实现采用「标称 MPPI + 在不确定子空间注入激励」的两段式，而非在线求解完整 POMDP。

**定义 315（AID：轨迹作为实验 / 双重控制）** 信息增益
IG(ξ) = H(b_t) − E_{y~p(·|ξ,b_t)}[H(b_{t+1})]。
完整轨迹分解为 ξ = ξ_task ⊕ ξ_probe，其中 ξ_probe 只沿 b_t 的不确定方向注入激励，且一阶不改变任务路径的同伦类。探针选择
ξ_probe* = argmax_{ξ_probe} IG(ξ_task ⊕ ξ_probe) / (c_risk + c_damage + c_time)
s.t. 定义 316 的安全包络。若分母为正而 IG 恒为 0，则该任务在安全包络内**不可辨识**（引理 21）。

**定义 316（安全探针包络 SPM）** 探针 p = (力曲线, 速度, 位移, 时长)。约束：F ≤ F_obj(d_max)、v ≤ v_max、Δx ≤ ε_p、累计损伤
D(p) = Σ_t (F_t / F_crit)^{γ} ≤ D_max，γ > 1。
脆性物体的探针方向沿最不脆弱主轴；若不存在「正信息增益且不越损伤预算」的探针方向，则标记为**不可探**。探针本身是轨迹，必须过 C-RAS-WM 前缀认证。

**定义 317（组合泛化算子）** 组合 c = ⊕_{i} primitive_i(ω_i)，合法性谓词 ValidComp(G_𝒪)。泛化到新物体要求在**原语参数支撑** S = ∪_i supp(b_i) 上覆盖，并且组合图有效。定义参数到训练支撑的距离 d_Ω(ω, S) = min_{ω'∈S} ‖ω − ω'‖_{Σ^{-1}}。

**定义 318（泛化证书 GCC）** GCC = (coverage, r_δ, ρ_task, L_J, regret_bound, split_hash)。其中 coverage 为参数支撑覆盖率，r_δ 为 d_Ω 的 δ 分位，L_J = sup_ω ‖∂J*/∂ω‖，regret_bound 由引理 20 给出。GCC 有效 ⇔ coverage ≥ 1−δ ∧ ρ_task ≥ ρ_min ∧ regret_bound ≤ ε_gen。**证书发布的是 (r_δ, L_J, ρ_task)，不是一个成功率。**

**定义 319（物理一致性监测 PCM：留出接触预测）** 把接触史分为辨识前缀 H_id 与验证后缀 H_val，ω̂ = MAP(H_id)，物理残差
r_phys = ‖ y_{t+1:t+W} − h(ξ, ω̂) ‖_{H_val, Σ_y^{-1}}。
跨接触模式再做留一验证（如用抬升段拟合、用滑移段验证）。**只有留出预测残差才可作为物理通道的证据；在线拟合残差不算。**

**定义 320（辨识吸收与模型类错配）** 若真实物体不在模型类 ℳ 内（如把粘弹性物体当刚体、把锁死的关节当自由铰链），在线辨识可通过过度拟合 H_id 把错配吸收，使训练残差趋零而留出残差仍高。定义吸收指数
κ_id = I(ω̂; mismatch | H_id) / H(ω̂)，
并要求证据纪律：κ_id 越界或跨模式留出残差高 ⇒ 「已辨识」判定作废，标记为模型类错配。

**定义 321（三重 OOD 判别）** 联合三个正交信号：语义新奇 s_e（e 空间密度/距离）、行为异常 a_score（R69 FMA）、物理错配 r_phys（定义 319）。关键判别区：
| 模式 | s_e | a_score | r_phys | 解释 |
|---|---|---|---|---|
| 安全新物体 | 高 | 低 | 低 | 外观新、物理在支撑内 |
| 险恶的熟悉物 | 低 | 低 | **高** | 外观熟悉、行为高似然、物理错配——R69 的盲区 |
| 已知但当前不可辨识 | 低 | 低 | 中 | 参数未激励（如未滑动即测摩擦） |
| 模型类错配 | 任意 | 任意 | 高且 κ_id 高 | 物体不在 ℳ 内 |
只有 r_phys 与 s_e、a_score 同时低时才允许宣称「已泛化」。

**定义 322（最小后悔保底 MRC）** 若参数不可辨识或不可安全探测，选择
ξ_mrc = argmin_ξ max_{ω∈Ω_δ} Regret(ξ; ω)，s.t. 安全/损伤约束；
或等价的 CVaR 版本。MRC 只保证「不因错误猜测而灾难」，不承诺高效率；当 b_t 退化到单点且辨识完成时，MRC 与 PTO 一致。

**定义 323（泛化–探测共享预算）** 总预算 B_gen 在 R69 的信息动作（看/问/触）与 R70 的物理探针（力/位移/时间）之间共享，按「单位成本 VoI/IG」排序分配，禁止重复支付；任一项超预算即冻结该项并回退。

**定义 324（对抗物体干扰集 ℰ_obj）** 欺骗性质量/质心分布、摩擦伪装（表面处理使视觉/初始触感误判）、隐藏脆性、探针反应性刚度（越探越硬）、铰链锁死伪装、以及**证书博弈型物体流**（专门针对评测物体拆分过拟合）。并入 AIC：ℰ_PIVOT = ℰ_FLUID × ℰ_obj。

**定义 325（证书 J_PIVOT）** J_PIVOT = (J_FLUID, coverage, r_δ, ρ_task, L_J, r_phys_p95, κ_id, regret_bound, object_split_hash, probe_log_hash, pivot_ver)。
Valid ⇔ Valid(J_FLUID) ∧ GCC 有效 ∧ 可辨识性纪律满足 ∧ 探测预算未越界。

**定义 326（层级包含与退化）** 当物体参数已知（b_t 退化为单点）且不触发探针时，PIVOT 的轨迹与 FLUID-RAS 逐指令相同；当同时不触发交互时退化为 R68。安全侧 λ_floor 额外计入未辨识的 U_obj ≥ 0，但在已辨识时为 0，故永不强于 R69。

```python
# IP-264 OPG：物体物理原语图与参数后验（粒子/混合，显式区分已激励/未激励方向）
class ObjectPropertyBelief:
    def __init__(self, primitives, n_particles=256):
        self.G, self.particles = primitives, init_particles(primitives, n_particles)

    def update(self, contact_hist, obs):
        self.particles = particle_filter(self.particles, contact_hist, obs)
        return self                                    # b_t(ω)

    def fisher(self, traj, omega):
        return sum(phi(traj, t, omega).T @ inv(self.Sigma_y) @ phi(traj, t, omega)
                   for t in range(traj.H))             # 定义 313

    def task_relevant_subspace(self, traj):
        return project_dirs(self.particles, traj, eps_J=TAU_J)   # P_task

    def identified(self, traj):
        F = self.task_relevant_subspace(traj).T @ self.fisher(traj, self.mean()) \
            @ self.task_relevant_subspace(traj)
        return cond_number(F) <= 1.0 / RHO_MIN          # ρ_task ≥ ρ_min

# IP-265/266 PTO + AID：风险敏感轨迹优化 + 安全探针注入（双重控制）
def PTO_solve(task, belief, budget, novelty_trigger):
    xi = mppi(task, belief, cost=CVaR(alpha) + risk_safe)      # 标称：任务 + 尾部风险
    if novelty_trigger:
        F    = belief.fisher(xi, belief.mean())
        U    = null_space(F)                          # 未激励方向
        best = None
        for p in probe_candidates(xi, U):             # 抬升/滑动/加载/旋转
            if not SPM.allow(p, budget):        continue
            if not c_ras_wm.certify_probe(p):   continue
            score = expected_info_gain(belief, xi, p) / (risk(p) + damage(p) + time(p))
            if best is None or score > best.score: best = (p, score)
        if best and best.score > 0:
            xi = compose_probe(xi, best.p)             # ξ_task ⊕ ξ_probe
    return xi

# IP-267 SPM：安全探针包络（力/速度/位移/损伤）
def SPM_allow(p, budget):
    return (p.F <= F_obj(p.d_max) and p.v <= V_MAX and p.dx <= EPS_P
            and cumulative_damage(p) <= D_MAX and budget.allow(p))

# IP-269/270 PCM：留出接触预测 + 辨识吸收检测（跨接触模式）
def physical_consistency(contact_hist, belief, xi):
    H_id, H_val = split_prefix_suffix(contact_hist)
    omega_hat   = belief.fit(H_id)
    r_held      = heldout_residual(H_val, omega_hat, xi)
    r_cross     = leave_one_contact_mode_out(contact_hist, belief)
    kappa_id    = absorption_index(omega_hat, H_id)
    return max(r_held, r_cross), kappa_id              # 定义 319–320

# IP-268 GCC：泛化证书（覆盖 + 可辨识 + Lipschitz 后悔界）
def generalization_certificate(belief, xi, train_support):
    r_delta = quantile(distance_to_support(belief, train_support), DELTA)
    L_J     = lipschitz_task_cost(xi, belief)
    bound   = 2.0 * L_J * r_delta + noise_term(len(belief))
    return GCC(coverage(belief, train_support), r_delta,
               rho_task(belief, xi), L_J, bound, SPLIT_HASH)

def PIVOT_RAS_round(M, obs):
    z, o = M.mtm.forward(...)
    b    = M.opg.update(M.contact_hist, o)             # 物体物理后验
    # R69：动作模态不确定性 + 行为似然第二意见
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_cal)
    # R70：物理通道（语义 / 行为 / 物理三重判别）
    s_e   = M.opg.semantic_novelty(o)
    r_phys, kappa = M.pcm.physical_consistency(M.contact_hist, b, M.last_xi)
    physics_suspect = (r_phys > TAU_PHYS and M.last_r_res < TAU_RES)
    model_mismatch  = kappa > TAU_ABSORB
    # 轨迹优化：任务 + 条件性探针
    trigger = (s_e > TAU_NOV) or physics_suspect or (U_epi > TAU_EPI)
    xi = M.pto.solve(M.task, b, M.budget, trigger and not model_mismatch)
    # R69 交互仅在可辨识性纪律允许时进行
    g = M.mint.choose_interaction(modes, o, M.budget) \
        if (U_epi > TAU_EPI and not physics_suspect and not model_mismatch) else None
    if g is not None:
        U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    # 未辨识/模型类错配 → 最小后悔保底；否则只对 aleatoric + 未消解项收紧
    U_obj = b.residual_entropy_on_task_subspace()
    if model_mismatch or not b.identified(xi):
        xi = M.mrc.select(xi, b, mode='worst_case_omega')
        U_obj = max(U_obj, U_OBJ_HIGH)
    U_floor = U_ale + (U_epi if g is None else 0.0) + U_obj
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(xi, ..., wm_preds)
    tau = M.pi_sigma.prefix_dispatch(xi[:k]) * lam
    # 证书：泛化声明只在 GCC 有效时发布
    cert = M.gcc.build(b, xi, M.train_support) if b.identified(xi) else None
    M.vqa_i.submit_async(g, cert, r_phys, kappa)
    return k, lam, xi, (U_ale, U_epi, U_obj), cert
```

## 3. 推导

**引理 19（接触 Fisher 与不可辨识方向）** 设接触观测 y_t = h(ξ_t, ω) + ε_t，h 对 ω 可微，噪声次高斯。若单位向量 v ∈ ker F(ξ; ω)，则从该轨迹不存在对 vᵀω 的有限方差无偏估计；若 v 对应特征值 λ > 0，则任意无偏估计方差 ≥ 1/(Tλ)。系：**质量需要竖直加速度/抬升才能读，摩擦需要切向滑移才能读，刚度需要加载才能读**——任务轨迹若不在这些方向激励，参数就永远不可辨识；反之，轨迹优化可以把「激励」塞进任务本来就要做的动作里，以近零额外时间获得辨识。

**引理 20（参数覆盖–后悔界）** 设任务代价 J(ξ; ω) 对 ω 为 L_J-Lipschitz，训练参数支撑为 S，object 参数到 S 的 Σ-范数距离为 r。则以概率 1−δ，
Regret(π_PIVOT) ≤ 2 L_J r + O(√(log(1/δ)/n))。
系：**泛化声明应发布 (r, L_J)，而不是单个留出成功率**；当 r 大而 L_J 大时，即使平均成功率高，最坏后悔也可能不可接受；当 L_J ≈ 0（参数不影响任务）时，物理外推是免费的吗？不是——它意味着任务对该参数不敏感，此时才可安全忽略，但必须由 P_task 证明。

**引理 21（安全–信息 Pareto 与不可探任务）** 在正则条件下，安全包络内的最大信息增益 IG_max(ε_p, D_max) 关于探测风险/损伤预算单调不减且凹。若任务相关不确定方向所需的激励必然违反物体损伤预算（如测摩擦必须滑动，而物体一滑就碎），则 IG_max = 0，参数在该任务下**不可探**；此时唯一诚实的选择是 MRC，而不是「试探性猜测」。

**定理 18（PIVOT 严格包含 R69/R68）** 当物体参数已知（b_t 退化为单点）且不触发探针时，PTO 的 ξ_task 与 FLUID-RAS 的动作逐指令相同；当进一步不触发交互时退化为 R68。U_obj 在已辨识时为 0，故 λ_floor 与 R69 相同；在未辨识时 U_obj > 0 只会使策略更保守。安全侧永不让步。

**定理 19（物理通道互补与辨识吸收免疫）** 在 A99–A102 下，若一个「同形异质物」满足：s_e 低、a_score 低（行为高似然），但任务相关方向上的真实参数与 b_t 的预测偏差超过 δ_phys，则只要该方向被轨迹激励（ρ_task ≥ ρ_min），r_phys(H_val) > τ 的概率 ≥ 1−δ，而 R69 的 FMA 仍保持低值。因此 PIVOT 的可检测集严格包含 R69。进一步，若真实物体不在模型类 ℳ 内且错配方向不在 span{Φ_t} 内，则任何在线拟合都不能使留出残差归零，故定义 320 的 κ_id 纪律可阻断「辨识吸收」——这是 R68 反吸收引理在物体物理侧的镜像。

**定理 20（组合泛化误差界）** 对组合物体 𝒪 = ⊕_i primitive_i(ω_i)，若各原语参数估计误差 ≤ ε_i、组合模型误差 ≤ ε_c、任务代价对参数 Lipschitz，则
E[Regret] ≤ Σ_i 2 L_J ε_i + L_J ε_c。
系：**泛化应发生在原语参数空间，而不是物体实例空间**；只要原语覆盖 + ValidComp 成立，未见过的组合也可获得可加误差界；若 ValidComp 不成立（如怀疑隐藏铰链），则进入 MRC 而非强行套用刚体模型。

**定理 21（探测安全与无突变）** 探针经 SPM 与 C-RAS-WM 认证后，累计损伤 ≤ D_max、物理风险 ≤ ε_int；探针只改变参数后验与轨迹的激励分量，不改变任务路径的同伦类与安全包络；探测失败/超时/超损伤时 λ 单调不降地退化为 MRC，再退化为 R69/R68；提交/换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变。

## 6. 本轮最大风险

**一句话**：PIVOT-RAS 的全部泛化声明押在两个前提上——**物体的关键物理参数确实能在安全/损伤预算内被任务轨迹激励并辨识，且评测物体分布覆盖了声称的参数支撑**；一旦物体用「探针反应性刚度/隐藏脆性/摩擦伪装」把物理藏到安全包络之外，或评测集发生物体拆分泄漏，系统就会**对恰好处理不了的物体发出一张「已泛化」的证书**——这比 R69 的「问错」更危险，因为它把「未知物体」升级成了「已被证明安全」，即**用可辨识性的语言包装不可辨识的无知**。

## 2. 形式化定义（要点版）

**定义 310（总览与三不变式）** PIVOT-RAS = (OPG, PTO, AID, SPM, GCC, PCM, MRC, RAS-WM†)；实时零学习写操作继承；探测力/速度/位移/损伤硬约束，探针与 R69 信息动作共享预算且过 C-RAS-WM；可辨识性纪律——未达 ρ_task ≥ ρ_min 不得声称已识别/已泛化，不得把模型类错配吸收进 ω̂，不可安全探则走 MRC。

**定义 311–312（物体参数化与 OPG）** `𝒪=(e,G_𝒪,ω)`；ω 含质量/质心/惯量/摩擦/恢复/刚度/阻尼/脆性/关节参数；`b_t(ω)` 为粒子/混合后验，显式维护未激励方向。

**定义 313（Fisher 可辨识度）** `F(ξ;ω)=Σ_t Φ_tᵀΣ_y^{-1}Φ_t`；`ρ_task(ξ)=λ_min(P_task F P_task)/λ_max(Σ_y)`；ker F 为不可辨识方向（引理 19）。

**定义 314–315（PTO 与 AID）** `ξ*=argmin E_b[J]+λ_r CVaR_α[J]+λ_s Risk_safe−λ_i IG`，s.t. 鲁棒安全与损伤约束；`IG(ξ)=H(b_t)−E_y[H(b_{t+1})]`；`ξ=ξ_task⊕ξ_probe`，按 IG/(风险+损伤+时间) 选探针。

**定义 316（SPM）** 探针约束 `F≤F_obj(d_max), v≤v_max, Δx≤ε_p, D(p)≤D_max`；脆性物体沿最不脆弱主轴；无正信息增益的安全探针 ⇒ 不可探。

**定义 317–318（组合泛化与 GCC）** `c=⊕ primitive_i(ω_i)`，ValidComp；泛化要求原语参数覆盖 + 组合合法；`GCC=(coverage,r_δ,ρ_task,L_J,regret_bound,split_hash)`，有效 ⇔ coverage≥1−δ ∧ ρ_task≥ρ_min ∧ regret_bound≤ε_gen。

**定义 319–320（PCM 与辨识吸收）** 前缀 H_id 拟合 ω̂，后缀 H_val 计算 `r_phys`；跨接触模式留一验证；吸收指数 `κ_id=I(ω̂;mismatch|H_id)/H(ω̂)`；κ_id 越界或留出残差高 ⇒ 「已辨识」作废。

**定义 321（三重 OOD）** 联合 `s_e, a_score, r_phys`；「险恶的熟悉物」= s_e 低 ∧ a_score 低 ∧ r_phys 高，是 R69 的盲区；只有三者同时低才允许宣称已泛化。

**定义 322–323（MRC 与共享预算）** 不可辨识/不可探/模型错配 ⇒ `argmin_ξ max_{ω∈Ω_δ} Regret`（或 CVaR）；B_gen 在 R69 信息动作与 R70 探针间按单位成本 IG/VoI 共享，禁止重复支付。

**定义 324–326（威胁/证书/包含）** `ℰ_PIVOT=ℰ_FLUID×ℰ_obj`（欺骗质量、摩擦伪装、隐藏脆性、反应性刚度、铰链锁死、证书博弈）；`J_PIVOT=(J_FLUID,coverage,r_δ,ρ_task,L_J,r_phys_p95,κ_id,regret_bound,object_split_hash,probe_log_hash,pivot_ver)`；已知参数且不探测时逐指令退化为 R69，再不交互退化为 R68，安全侧永不强于 R69。

## 3. 关键算法伪代码

```python
# IP-264 OPG：物体物理原语图与参数后验
class ObjectPropertyBelief:
    def update(self, contact_hist, obs):
        self.particles = particle_filter(self.particles, contact_hist, obs)
        return self                                     # b_t(ω)

    def fisher(self, traj):
        return sum(phi(traj, t, self.mean()).T @ inv(self.Sigma_y)
                   @ phi(traj, t, self.mean()) for t in range(traj.H))

    def identified(self, traj):
        P = self.task_relevant_subspace(traj)            # P_task
        F = P.T @ self.fisher(traj) @ P
        return cond_number(F) <= 1.0 / RHO_MIN

# IP-265/266 PTO + AID：风险敏感轨迹优化 + 安全探针注入
def PTO_solve(task, belief, budget, novelty_trigger):
    xi = mppi(task, belief, cost=CVaR(alpha) + risk_safe)     # 标称：任务 + 尾部风险
    if not novelty_trigger:
        return xi
    U = null_space(belief.fisher(xi))                  # 未激励方向
    best = max((p for p in probe_candidates(xi, U)
                if SPM_allow(p, budget) and c_ras_wm.certify_probe(p)),
               key=lambda p: IG(belief, xi, p) / (risk(p) + damage(p) + time(p)),
               default=None)
    return compose_probe(xi, best) if best else xi     # ξ_task ⊕ ξ_probe

# IP-269/270 PCM：留出接触预测 + 跨模式验证 + 吸收指数
def physical_consistency(contact_hist, belief, xi):
    H_id, H_val = split_prefix_suffix(contact_hist)
    omega_hat   = belief.fit(H_id)
    r_held      = heldout_residual(H_val, omega_hat, xi)
    r_cross     = leave_one_contact_mode_out(contact_hist, belief)
    return max(r_held, r_cross), absorption_index(omega_hat, H_id)

# IP-268 GCC：覆盖 + 可辨识 + Lipschitz 后悔界
def generalization_certificate(belief, xi, train_support):
    r_delta = quantile(distance_to_support(belief, train_support), DELTA)
    L_J     = lipschitz_task_cost(xi, belief)
    return GCC(coverage(belief, train_support), r_delta, rho_task(belief, xi),
               L_J, 2.0 * L_J * r_delta + noise_term(len(belief)), SPLIT_HASH)

# IP-274 主闭环（继承 R69）
def PIVOT_RAS_round(M, obs):
    z, o = M.mtm.forward(...)
    b    = M.opg.update(M.contact_hist, o)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_cal)
    s_e   = M.opg.semantic_novelty(o)
    r_phys, kappa = M.pcm.physical_consistency(M.contact_hist, b, M.last_xi)
    physics_suspect = (r_phys > TAU_PHYS and M.last_r_res < TAU_RES)
    model_mismatch  = kappa > TAU_ABSORB
    trigger = (s_e > TAU_NOV) or physics_suspect or (U_epi > TAU_EPI)
    xi = M.pto.solve(M.task, b, M.budget, trigger and not model_mismatch)
    g = M.mint.choose_interaction(modes, o, M.budget) \
        if (U_epi > TAU_EPI and not physics_suspect and not model_mismatch) else None
    if g is not None:
        U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    U_obj = b.residual_entropy_on_task_subspace()
    if model_mismatch or not b.identified(xi):
        xi = M.mrc.select(xi, b, mode='worst_case_omega')
        U_obj = max(U_obj, U_OBJ_HIGH)
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (U_epi if g is None else 0.0) + U_obj))
    k = M.c_ras_wm.certified_prefix(xi, ..., wm_preds)
    tau = M.pi_sigma.prefix_dispatch(xi[:k]) * lam
    cert = M.gcc.build(b, xi, M.train_support) if b.identified(xi) else None
    M.vqa_i.submit_async(g, cert, r_phys, kappa)
    return k, lam, xi, (U_ale, U_epi, U_obj), cert
```

## 4. 推导

**引理 19（接触 Fisher 与不可辨识方向）** `y_t=h(ξ_t,ω)+ε_t`。若 `v∈ker F(ξ;ω)`，则从该轨迹不存在对 `vᵀω` 的有限方差无偏估计；若特征值 λ>0，则方差下界 `≥1/(Tλ)`。系：质量需竖直加速度/抬升、摩擦需切向滑移、刚度需加载；未激励即不可辨识，而任务轨迹可把这些激励「顺带」做掉。

**引理 20（覆盖–后悔界）** `J(ξ;ω)` 为 `L_J`-Lipschitz、训练支撑 S、参数距离 r，则以概率 1−δ，`Regret ≤ 2 L_J r + O(√(log(1/δ)/n))`。系：泛化应发布 `(r,L_J)`；`L_J≈0` 时参数可安全忽略，但须由 `P_task` 证明。

**引理 21（安全–信息 Pareto）** `IG_max(ε_p,D_max)` 单调不减且凹；若任务相关方向的激励必然违反损伤预算（测摩擦要滑动而物体一滑就碎），则 `IG_max=0`，该任务下不可探，唯一诚实选择是 MRC。

**定理 18（PIVOT 严格包含 R69/R68）** 参数已知且不探测时，`ξ_task` 与 FLUID-RAS 逐指令相同；再不交互时退化为 R68；`U_obj` 已辨识时为 0，故 λ_floor 与 R69 相同，未辨识时只会更保守。

**定理 19（物理通道互补与辨识吸收免疫）** A99–A102 下，若「同形异质物」`s_e` 低、`a_score` 低但任务相关方向物理偏差超 δ_phys，且该方向被激励（ρ_task≥ρ_min），则 `r_phys(H_val)>τ` 的概率 ≥1−δ，而 R69 FMA 仍低 ⇒ 可检测集严格增大。若真实物体不在模型类 ℳ 内且错配方向不在 `span{Φ_t}` 内，在线拟合无法使留出残差归零 ⇒ κ_id 纪律阻断「辨识吸收」（R68 反吸收引理的物体物理镜像）。

**定理 20（组合泛化误差界）** 对 `𝒪=⊕ primitive_i(ω_i)`，原语误差 `ε_i`、组合误差 `ε_c`、代价 Lipschitz，则 `E[Regret] ≤ Σ_i 2 L_J ε_i + L_J ε_c`。系：泛化应发生在原语参数空间；ValidComp 不成立（疑隐藏铰链）时进入 MRC，而非套用刚体模型。

**定理 21（探测安全与无突变）** 探针经 SPM + C-RAS-WM 认证后 `D≤D_max`、物理风险 ≤ ε_int；探针只改参数后验与激励分量，不改任务路径同伦类与安全包络；失败/超时/超损伤时 λ 单调不降地退化为 MRC→R69→R68；换装不变式（R68 定理 15）保持。

## 7. 本轮最大风险

**一句话**：PIVOT-RAS 的全部泛化声明押在「关键物理参数能在安全/损伤预算内被任务轨迹激励辨识，且评测物体分布覆盖声称的参数支撑」上——一旦物体用**反应性刚度/隐藏脆性/摩擦伪装**把物理藏到安全包络之外，或评测集发生**物体拆分泄漏**，系统就会对恰好处理不了的物体发出「已泛化」证书；这比 R69 的「问错」更危险，因为它把「未知物体」升级成「已被证明安全」——**用可辨识性的语言包装不可辨识的无知**。

**次级风险与缓解**：探针损伤（SPM 力/位移/累计损伤 + C-RAS-WM + 定理 21）；辨识吸收（前缀/后缀留出 + 跨接触模式 + κ_id 纪律，定义 319–320）；Fisher/辨识不可靠（ρ_task 门控 + 不可探即 MRC，引理 21）；参数覆盖造假（原语参数覆盖证书 + 拆分哈希，定义 318）；实时预算被 PTO 击穿（条件触发 + 热启动 MPPI + 异步 GCC，复杂度表）；组合模型外推（ValidComp + 定理 20 可加界 + MRC 兜底）。
