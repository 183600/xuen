# 第 1 轮（新灵感循环第 1 轮；本轮灵感：「碰撞避免」×「力矩传感」）

> **基线**：沿用上一循环的 MetricVoiceGauge-NCD-HUTDH-v20（PCA/CTS/CFC/HPC/CFCtrl 感知层）。本轮不推倒 v20，只做一件事：**把力矩传感这一本体感知通道，作为"碰撞见证"注入碰撞避免证书**，让"几何预测"与"动力学见证"形成跨模态闭环。

## 0. 直觉与动机

### 灵感 1（力矩传感 → 碰撞是动力学残差，而非纯几何相交）

**直觉**：几何法回答"两个形状会不会重叠"，但真实碰撞是**动量交换事件**。深度相机看不见透明杯、薄壁、反光面与遮挡后的物体；而关节力矩在接触发生的瞬间**必然**出现残差。于是把力矩当作"碰撞见证器"：在正常动力学模型预测的力矩之外，多出来的那部分就是外部接触。核心创新：**力矩残差碰撞见证器（Torque-Residual Collision Witness, TRCW）**。用广义动量观测器估计外部关节力矩 `τ_ext`，以经认证的模型误差包络 `δ_M` 为阈值；残差超阈值即"见证到接触"。

**严谨定义**：碰撞见证是一个**单边检验**。设 `r` 为观测器残差，触发阈值为 `η = δ_M + κσ`（σ 为噪声标准差，κ 为置信倍数）。则
- 若 `|r| > η`，可断言 `|τ_ext| > κσ`（确有超出噪声的外部力矩）；
- 若 `|τ_ext| > 2δ_M + κσ`，则必有 `|r| > η`，即**大的碰撞不会被漏检**；
- 反之 `|r| ≤ η` 只能给出**有界**结论 `|τ_ext| ≤ 2δ_M + κσ`，**不能**宣称绝对零接触。

这个单边性是后续所有安全继承的根基：力矩只能"否决"，不能单独"扩张无界安全域"。

### 灵感 2（碰撞避免 → 从"禁止接触"到"冲量预算内的接触管理"）

**直觉**：二值避碰对接触密集任务过于保守；更糟的是，为了绝对不碰，系统会做出剧烈规避动作，而剧烈加速本身危险。改为"接触可以发生，但交换的冲量必须落在预算内"。核心创新：**接触冲量预算（Contact Impulse Budget, CIB）**。由执行器饱和、结构强度与危害模型给出每连杆的冲量上限 `J_max`，把累计外部冲量当作"预算消耗"。

**反直觉点**：允许**有界接触**反而可能更安全，因为它把"碰撞"变成可度量、可预算、且单调于危害的量，消除了"为了零接触而做危险机动"的激励。

**严谨定义**：安全判据从"无接触"变为"累计冲量上界 ≤ `J_max` 且危害模型 `h` 单调非减"。关键是冲量估计必须是**上界**而非点估计：
`J_est^+ = ∫ (|r| + δ_M) dt ≥ ∫ |τ_ext| dt`。
只有上界才能支撑"有界危害"的可靠性；点估计在冲击瞬态会系统性偏低。

### 灵感 3（碰撞避免 × 力矩传感 → 跨模态碰撞证书）

**直觉**：几何负责"预测哪里可能碰"，力矩负责"见证是否真的碰、碰得多重"，冲量预算负责"这次接触可不可接受"。三者组成**跨模态碰撞证书（Cross-Modal Collision Certificate, CMCC）**。

**严谨定义**：证书显式区分两种契约——
- **避碰契约（AVOID，默认）**：`plan ∈ Θ_v20 ∧ ¬contact ∧ budget_ok`，严格继承 v20，`Exec_v21^avoid ⊆ Exec_v20`；
- **有界接触契约（CONTACT，需显式开启并审计）**：`J_est^+ ≤ J_max`，由危害模型担保。它**不是** v20 的子集，而是另一条"有界危害"安全契约，二者不可混淆。

同时把几何裕度升级为**冲量感知裕度（Impulse-Aware Safety Margin, IASM）**：所需间距随接近速度与有效惯量增大，
`d_req = max(margin_col_base, v·T_reflex + v²/(2a_brake))`，
从源头减少高冲量碰撞。取 `max(margin_col_base, ·)` 保证 AVOID 模式下裕度只收紧不放松。

### 三者如何统一

共享状态 `ζ_cm = (r_residual, δ_M, B_impulse, mode, d_req, cert)`。TRCW 回答"是否见证到接触、多强"；CIB 回答"累计冲量是否越界"；IASM 回答"几何上要留多大间距才不至于撞出超预算冲量"；CMCC 把三者合成 verdict：`SAFE / CONTACT_SAFE / UNSAFE / EMERGENCY`。任一环节不可信即 fail-safe 回退。

## 1. 研究问题

- **Q1（残差见证的可靠性）**：如何在负载、摩擦、关节柔性、传感器噪声下**认证** `δ_M`？观测器瞬态是否会漏检冲击？如何用单边检验给出"不遗漏大碰撞"的定量保证，而不是把"残差小"误读成"无接触"？

- **Q2（冲量上界与危害模型）**：如何构造在冲击瞬态也成立的冲量上界 `J_est^+`？危害模型 `h(J)` 如何做到单调、可标定、可区分接触部位与持续时间？单一标量预算是否足够，何时需要向量预算？

- **Q3（跨模态证书的组合）**：如何让几何证书与力矩证书组合而不破坏 AVOID 子集性？CONTACT 模式的开启、审计与退出如何治理？两条契约如何无歧义切换，避免"借接触模式绕过避碰"？

- **Q4（时序与误报）**：力矩 1kHz、控制 50Hz、几何证书更低频，如何在反射窗口内完成"见证→制动"？如何把加速/惯性尖峰与真实接触区分，抑制误报？

## 2. 设计原则（在 P31–P33 基础上新增 P34–P36）

**P34 残差见证律（Residual Witness）**
外部力矩 `τ_ext` 由广义动量观测器估计，触发阈值 `η = δ_M + κσ`。检测是**单边**的：只保证"大碰撞不漏"（`|τ_ext| > 2δ_M + κσ ⇒ 触发`），不宣称"小残差 = 无接触"。力矩通道在 AVOID 契约中**只能否决（veto）**，不能单独扩张无界安全域。

**P35 冲量预算律（Impulse Budget）**
安全 = 累计上界冲量 `J_est^+ = ∫(|r| + δ_M)dt ≤ J_max` 且危害模型 `h` 单调非减。接触期间持续记账；越界立即进入 `EMERGENCY` 并切换力矩限幅/柔顺制动。`J_est^+` 必须是上界，禁止用点估计。

**P36 跨模态继承律（Cross-Modal Inheritance）**
AVOID 契约下 `Exec_v21^avoid ⊆ Exec_v20`（IASM 只收紧裕度，且要求 `d_req ≥ margin_col_base`）。CONTACT 契约必须显式 opt-in、危害模型认证、审计链可追溯，**不得静默开启**。力矩通道失效（`δ_M` 超界或标定失效）即回退几何 v20。

## 3. 与基线的接口（如何退化）

- TRCW 失效（力矩传感故障/标定超界）⇒ 只用几何 v20，AVOID 更保守；
- CIB 未启用 ⇒ CONTACT 模式禁用，仅保留 AVOID；
- IASM 失效 ⇒ 用固定 `margin_col` ⇒ 等价 v20；
- RCDM 判定 `δ_M > δ_max` ⇒ 力矩通道不可信 ⇒ 回退 v20；
- 全失效 ⇒ 完全回退 v20；
- **安全继承**：AVOID 子集性由引理 159 保证；CONTACT 由引理 160 单独担保（有界危害，而非零接触）。

## 4. 预期贡献

1. **碰撞的动力学重述**：首次把碰撞从"几何相交"重述为"动力学残差见证"，并给出单边检测的定量保证，使透明/薄壁/遮挡物体的碰撞也能被见证；
2. **有界接触管理**：用冲量预算把避碰从二值约束升级为可度量、单调于危害的连续约束，兼顾接触密集任务的活性与安全；
3. **冲量感知裕度**：把接近速度与有效惯量耦合进几何间距，从源头抑制高冲量碰撞，而非事后检测；
4. **跨模态证书双契约**：给出"避碰子集性 + 有界接触可靠性"两条互不混淆的安全契约，并明确切换与治理；
5. **可信度认证**：给出 `δ_M` 的在线认证与漂移监测，使力矩通道具备可审计的可信度，而非盲目信任传感器。

## 5. 本轮最大风险

**一句话**：整个方案依赖"模型误差包络 `δ_M` 与危害模型 `h` 都可靠"；若 `δ_M` 被低估（关节柔性、传感器饱和、冲击瞬态滞后）或 `h` 误设，则 `J_est^+` 会低估真实冲量，把真正有害的接触认证为 `CONTACT_SAFE`——力矩通道沦为"静默少报的见证者"。

# IP-425 Torque-Residual Collision Witness
class TorqueResidualObserver:
    def __init__(self, dyn, K_o=1000.0, delta_model=0.5, kappa=3.0):
        self.dyn = dyn                    # 提供 M(q), CT(q,qdot), g(q)
        self.K_o = K_o                    # 观测器增益，1kHz 采样下可取 500~2000
        self.delta_model = delta_model    # 经 RCDM 认证的模型误差包络
        self.kappa = kappa
        self.r = zeros(dyn.n)
        self.p_hat = None

    def update(self, q, qdot, tau, dt):
        p = self.dyn.M(q) @ qdot
        if self.p_hat is None:
            self.p_hat = p.copy()
        tau_gen = tau + self.dyn.CT(q, qdot) @ qdot - self.dyn.g(q)
        # 广义动量观测器：r = K_o (p - ∫(tau_gen + r) dt)
        self.p_hat += (tau_gen + self.r) * dt
        self.r = self.K_o * (p - self.p_hat)
        return self.r

    def threshold(self, sigma):
        return self.delta_model + self.kappa * sigma

    def detect(self, sigma):
        eta = self.threshold(sigma)
        return norm(self.r) > eta, eta


# IP-426 Contact Impulse Budget
class ContactImpulseBudget:
    def __init__(self, J_max, harm_model, safety_factor=1.25):
        self.J_max = J_max
        self.harm_model = harm_model      # 单调非减
        self.safety_factor = safety_factor
        self.B = 0.0

    def upper_increment(self, r, delta_model, dt):
        # |tau_ext| <= |r| + delta_M  => 上界冲量增量
        return (norm(r) + delta_model) * dt * self.safety_factor

    def update(self, r, delta_model, dt):
        self.B += self.upper_increment(r, delta_model, dt)
        return self.B

    def within_budget(self):
        return (self.B <= self.J_max
                and self.harm_model(self.B) <= self.harm_model(self.J_max))

    def reset(self):
        self.B = 0.0


# IP-427 Impulse-Aware Safety Margin
class ImpulseAwareMargin:
    def __init__(self, margin_col_base=0.01, T_reflex=0.02):
        self.margin_col_base = margin_col_base
        self.T_reflex = T_reflex

    def required_clearance(self, v, m_eff, a_brake):
        v = max(0.0, v)
        d_stop = v * self.T_reflex + v * v / (2.0 * max(1e-9, a_brake))
        # 关键：下限为 v20 固定裕度，AVOID 下只收紧不放松
        return max(self.margin_col_base, d_stop)

    def check(self, seg):
        return seg.clearance >= self.required_clearance(
            seg.v, seg.m_eff, seg.a_brake)


# IP-428 Cross-Modal Collision Certificate
class CrossModalCollisionCertificate:
    def __init__(self, ccv, tro, cib, iasm, mode="AVOID"):
        self.ccv = ccv
        self.tro = tro
        self.cib = cib
        self.iasm = iasm
        self.mode = mode                  # AVOID | CONTACT（CONTACT 需显式 opt-in）

    def certify(self, plan, node, obj, sigma, dt):
        # 1) 几何证书（v20 基线）
        geom_ok = self.ccv.certifies(plan, node, obj)
        # 2) 冲量感知裕度预筛
        iasm_ok = all(self.iasm.check(seg) for seg in plan.segments)
        # 3) 力矩见证与预算记账
        r = self.tro.r
        contact, eta = self.tro.detect(sigma)
        self.cib.update(r, self.tro.delta_model, dt)
        budget_ok = self.cib.within_budget()

        if self.mode == "AVOID":
            # 避碰契约：严格继承 v20，力矩只能否决
            if contact:
                return CertVerdict("EMERGENCY", "AVOID", eta, self.cib.B)
            if geom_ok and iasm_ok and budget_ok:
                return CertVerdict("SAFE", "AVOID", eta, self.cib.B)
            return CertVerdict("UNSAFE", "AVOID", eta, self.cib.B)

        # CONTACT 契约：有界危害（非 v20 子集，需 opt-in + 审计）
        predicted_ok = plan.worst_case_impulse <= self.cib.J_max
        if not budget_ok:
            return CertVerdict("EMERGENCY", "CONTACT", eta, self.cib.B)
        if predicted_ok:
            return CertVerdict("CONTACT_SAFE", "CONTACT", eta, self.cib.B)
        return CertVerdict("UNSAFE", "CONTACT", eta, self.cib.B)


# IP-429 Residual Calibration & Drift Monitor
class ResidualCalibrationMonitor:
    def __init__(self, delta_max=1.0, window=200):
        self.delta_max = delta_max
        self.window = window
        self.bias_hist = deque(maxlen=window)

    def update(self, r_free):
        # 仅在已知无接触的自由运动段采样
        self.bias_hist.append(r_free.copy())

    def certified_bound(self, sigma):
        if len(self.bias_hist) < 10:
            return float("inf")           # 未标定 => 力矩通道不可信
        bias = mean(self.bias_hist, axis=0)
        spread = 3.0 * std(self.bias_hist, axis=0) + sigma
        return norm(bias) + norm(spread)

    def valid(self, delta_model):
        return delta_model <= self.delta_max

## 2. 推导

**引理 157（动量观测器残差收敛与单边检测）**
刚体动力学 `M(q)q̈ + C(q,q̇)q̇ + g(q) = τ + τ_ext + τ_err`，`‖τ_err‖ ≤ δ_M`。令 `p = M(q)q̇`，则 `ṗ = τ + Cᵀq̇ − g + τ_ext + τ_err`。观测器 `r = K_o(p − ∫(τ + Cᵀq̇ − g + r)dt)` 满足
`ṙ = K_o(τ_ext + τ_err − r)`。
故稳态 `r → τ_ext + τ_err`，从而 `‖r − τ_ext‖ ≤ δ_M`。取 `η = δ_M + κσ`：
- 若 `‖r‖ > η`，则 `‖τ_ext‖ ≥ ‖r‖ − δ_M > κσ`；
- 若 `‖τ_ext‖ > 2δ_M + κσ`，则 `‖r‖ ≥ ‖τ_ext‖ − δ_M > η`，**必然触发**。
即"大的外部碰撞不会被漏检"；但 `‖r‖ ≤ η` 只能给出 `‖τ_ext‖ ≤ 2δ_M + κσ` 的**有界**结论。∎

**引理 158（冲量上界可靠性）**
由引理 157 的 `‖τ_ext‖ ≤ ‖r‖ + δ_M`，对任意接触窗口 `[t0,t1]` 有
`∫_{t0}^{t1} ‖τ_ext‖ dt ≤ ∫_{t0}^{t1} (‖r‖ + δ_M) dt = J_est^+`。
故 `J_est^+` 是真实累计冲量的**上界**。若危害模型 `h` 单调非减且 `J_est^+ ≤ J_max`，则 `h(∫‖τ_ext‖dt) ≤ h(J_max)`。∎
（注：冲击瞬态观测器存在滞后，需以高增益 `K_o`、短窗口与安全系数 `1.25` 补偿；RCDM 负责认证瞬态包络。）

**引理 159（AVOID 契约的零接触继承）**
AVOID 模式下证书通过需同时满足：`plan ∈ Θ_v20`（`geom_ok ∧ iasm_ok`）、`¬contact`、`budget_ok`。其中 `iasm_ok` 因 `d_req ≥ margin_col_base` 只会收紧 v20 的几何裕度；`¬contact ∧ budget_ok` 是额外否决条件。故任何被 v21 接纳的 AVOID 计划必被 v20 接纳，即 `Exec_v21^avoid ⊆ Exec_v20`。∎

**引理 160（CONTACT 契约的有界危害可靠性）**
CONTACT 模式需显式 opt-in、`plan.worst_case_impulse ≤ J_max` 且运行期 `J_est^+ ≤ J_max`。由引理 158，真实累计冲量不超过 `J_max`，故 `h ≤ h(J_max)`。此契约**不**蕴含 `⊆ Exec_v20`，而是独立的"有界危害"安全断言。∎

**引理 161（降级安全）**
若 RCDM 判定 `δ_M > δ_max`、力矩传感器掉线或标定失效，则强制 `mode = AVOID` 且吊销力矩通道，退回 v20 纯几何证书。故系统不依赖未经验证的力矩通道，最坏情形等价 v20（更保守）。∎

**引理 162（跨模态证书组合可靠性）**
CMCC 的 `SAFE` 需要几何证书通过（引理 159）与残差未触发（引理 157）；`CONTACT_SAFE` 需要冲量上界不越界（引理 160）。组合不引入新的无界接纳：AVOID 的接纳是 v20 的子集，CONTACT 的接纳受上界约束。故在几何证书、观测器、危害模型三者各自可靠的条件下，CMCC 的断言可靠。∎

**引理 163（IASM 的冲量单调性）**
`d_req(v) = max(margin_col_base, v·T_reflex + v²/(2a_brake))` 关于 `v` 单调非减。给定制动能力，允许的接触速度 `v` 越小，可交换冲量上界 `m_eff·v` 越小。故在几何上提高间距等价于降低潜在接触冲量，与 CIB 的预算方向一致。∎

## 6. 已知风险与失效模式

1. **危害模型误设**：冲量到伤害的映射依赖接触面积、部位、持续时间与人体/工件特性；单一标量 `J_max` 可能严重失真。缓解：分部位/分接触类型向量预算、实验标定、保守安全系数。

2. **模型误差低估**：关节柔性、间隙、摩擦、未建模负载会使 `δ_M` 偏小，导致 `J_est^+` 低估、漏检或误报。缓解：在线参数辨识、RCDM 漂移监测、`δ_M` 只允许被高估。

3. **冲击瞬态滞后**：观测器在极短冲击内来不及收敛，残差可能滞后于真实 `τ_ext`，使上界暂时失效。缓解：高 `K_o`、动量平衡直接核算、瞬态包络项与安全系数。

4. **传感器饱和/削顶**：硬碰撞使力矩传感器饱和，读数被截断，冲量被低估。缓解：饱和检测即触发 EMERGENCY、冗余量程、电流/关节力矩交叉校验。

5. **接触定位缺失**：关节力矩只能感知"多强"，难以直接给出"在哪里"。缓解：与几何证书/接触雅可比联合定位，接触点仅在几何候选域内搜索。

6. **自碰撞与外部碰撞混淆**：自碰撞同样产生残差。缓解：几何自碰撞检测交叉验证、模式区分。

7. **CONTACT 模式被滥用**：操作者可能以"有界接触"为名绕过避碰。缓解：显式 opt-in、审计链、按任务白名单、默认关闭。

8. **仿真到现实差距**：摩擦、背隙、传动柔度在仿真中难精确建模，导致 `δ_M` 迁移失效。缓解：域随机化、真机标定、保守回退。

## 7. 本轮最大风险

**一句话**：方案的有界危害契约完全建立在"`δ_M` 可信 + `h` 正确"之上；若 `δ_M` 被低估（关节柔性、传感器饱和、冲击瞬态滞后）或 `h` 误设，则 `J_est^+` 会低估真实冲量，把有害接触认证为 `CONTACT_SAFE`——力矩通道成为"静默少报的见证者"，这是比"漏检碰撞"更隐蔽的系统性风险。
