# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「语音合成」×「运动学」）

> 第 57 轮把安全的赌注从"模型置信"换到"证据承诺"，再用元少样本先验 + 跨模态对账 + 个性化有界信任把承诺做得更省、更准、更懂人；但它自陈的最大风险是 **"坏先验普遍"**：元推断器在语料盲区之外给出高度自信的错误后验，而 OOD 门只能识别它"学会识别"的分布外模式。换句话说，前 57 轮的所有判据都共享同一个软肋——**它们都要求某个模型（元先验、似然、ρ、人的权重）在分布外仍然正确**。本轮两个灵感各提供一条"不押注模型正确性"的旁路：**运动学**把信念/承诺看成一条随时间演化的轨迹，用 jerk（信念的急动度）、证据-决策雅可比的**条件数/奇异位形**、零空间冗余与逆运动学规划，检测"物理上不合理的信念动力学"和"对证据过敏的脆弱决策"——这些是**免模型（model-free）的稳定性诊断**，不要求先验对，只要求"信念不能瞬移、决策不能病态敏感"；**语音合成**把解释看成 text-to-speech 管线：前端归一化、韵律（该强调哪个风险）、声码器（渲染模态）、MOS 式可懂度、**反欺骗/活体检测**（识别复读、被胁迫、脚本化的"假确认"）、以及**带前瞻的流式合成**（先异步吐部分解释，但不可逆指令的"承诺句"必须等风险片段被前瞻窗口覆盖后才发声）。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为 **"证据承诺还必须运动学稳定、决策良条件、解释可信且防伪"**；同时明确一条否定性结论：**光滑性只证稳定，不证正确**。

核心矛盾：
- **H29（稳定 vs 正确）**：低 jerk、良条件数、平滑轨迹是最容易伪造的"健康信号"——一个恒定系统偏差给出的是全场最光滑、条件数最好的错误信念。免模型诊断能抓"瞬移"和"过敏"，抓不到"平稳地错"。
- **H30（可懂 vs 可信）**：语音合成式的自然韵律会提升可懂度，但说服力与正确性正交；越流畅、越贴合听者偏好的解释，越可能把错误结论包装得更加可信（over-persuasion），并给"授权养成/复读确认"提供更顺滑的入口。
- **H31（冗余 vs 可达）**：零空间冗余探针假设"存在不改变决策的自由度"，但二阶曲率与约束耦合会把"零空间"变成"慢空间"；而且证据工作空间（当前区域/接触级别下可达的证据类型）可能为空——此时逆运动学无解，只能退回保守动作。

## 0. 直觉与动机

**灵感 1（运动学 → 信念轨迹的微分约束与"信念急动度"）**
直觉：一条轨迹好不好，不只看终点，还看它拐得急不急。前 57 轮只看"当前信念点"，不看"信念是怎么走到这里的"。给信念加微分学：速度 v=Δφ/Δτ、加速度 a、**急动度 j=da/dτ**。物理直觉是——**真实的信念更新应当连续、可解释**：一次探针带来的信念跳变如果超过 θ_jump，却没有任何"已声明的模型切换"（OOD 进出、ρ_m 阶跃、元模型版本更替、授权变更）作解释，那它多半是隐藏的模态冲突、缓存错配或元模型突变，而不是新证据。于是 jerk/跳变成为**免模型的异常探针**：不要求先验对，只要求"信念不能瞬移"。

**灵感 2（运动学 → 证据-决策雅可比、条件数与奇异位形）**
直觉：机械臂靠近奇异位形时，关节动一点、末端飞很远——不是力不够，是**映射病态**。决策也有雅可比 J=∂d/∂e（证据 e 对决策 d：步态/裕度/风险）。**条件数 κ(J)=σ_max/σ_min 度量"决策对证据的过敏程度"**：κ 大 ⇒ 证据里一点未建模误差被放大成巨大决策变化。这类决策不许进 L2 不可逆层，必须沿"最能提升 σ_min 的方向"补一次**条件化探针**（对 σ_min 做最速上升）。这是**局部 Lipschitz 稳健性证书**，与先验是否正确无关。

**灵感 3（运动学 → 零空间冗余与逆运动学证据规划）**
直觉：冗余机械臂用零空间做次级目标而不动末端。证据也有冗余自由度：在不改变当前决策的一阶零空间 N(J) 里做**校准探针**（提升 ρ_m、cal、压低不确定性），等于"顺手把系统调好"。反过来，给定目标裕度 d\*，求**最小证据集**是逆运动学问题：解不唯一，按条件数挑最良态的解；在线用**分解速率控制** Δe=J⁺(d\*−d)+(I−J⁺J)z。注意：零空间只是一阶的，二阶曲率 ½ΔeᵀHΔe 必须被界住，否则"零空间"会偷偷变成"慢空间"。

**灵感 4（语音合成 → 解释的韵律、MOS 与反欺骗）**
直觉：解释不是"把五元组念出来"，而是一次合成：**前端归一化**（区域/上下文/单位别念错，否则垃圾进垃圾出）、**韵律**（把注意力预算按"最可能被违反的约束 × 后果"分配，Σs_k=1）、**声码器**（选渲染模态 m_E）、**MOS 式可懂度**（Ê[理解正确] 的置信下界 ≥ MOS_min 才放行）。更关键的是**反欺骗/活体**：语音反欺骗（ASVspoof）教我们识别"重放/合成/被胁迫"的声音；对应地，人的"确认"也可能是**复读、脚本化、橡皮章、授权养成**——用延迟分布、随机挑战-应答、跨通道一致性、回答熵做**确认活体检测**，不过关就当作"没有同意"，并触发第 57 轮 PTM 的实时降级。

**灵感 5（语音合成 → 带前瞻的流式解释）**
直觉：实时 TTS 不能等整句写完才发声，它用前瞻窗口先吐音；但**不可逆的"承诺句"**（"现在踩下去"）不能提前合成。对应到控制：L1 通知可异步流式输出（不阻塞节拍），L2 不可逆指令必须等**风险片段被前瞻窗口 L≥L_min 完整覆盖**、且延迟 τ_render≤τ_int 后才发声；否则安全停。这把"解释/协商"也纳入实时性契约。

**灵感 6（合流 → 免模型诊断层，作为第 57 轮的旁路而非替代）**
直觉：第 57 轮所有判据都押在"某个模型在分布外仍对"；本轮新增的 jerk/条件数/零空间/活体是**免模型或弱模型**的：它们只断言"信念动力学物理上合理""决策局部良态""人真的在同意"。它们**不能**替代先验正确性（H29），但能在先验错时多一层独立的失败信号。于是安全纵深从"五层证据"再加两层**正交**护栏：**动力学层**与**交互活体层**。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（信念运动学 KBD）** 对区域 r 的信念序列 b_r^{(0..t)} 取标量泛函 φ(b)（如 P_fail 或裕度）。以不等间隔 Δτ_t 定义离散微分：v_t=(φ_t−φ_{t−1})/Δτ_t，a_t=(v_t−v_{t−1})/Δτ_t，j_t=(a_t−a_{t−1})/Δτ_t。**信念急动度** J_e(r,t)=||j_{t−W+1..t}||_∞。**声明切换集** S_t={OOD 进出, |Δρ_m|>δ_ρ, 元模型版本更替, auth 变更}。**未声明跳变** U(r,t)⇔∃t'∈[t−W,t]: |φ_{t'}−φ_{t'−1}|>θ_jump ∧ s_{t'}∉S_t。**运动学承诺条件** KC(r,t)⇔J_e≤J_max ∧ ¬U(r,t)。J_e 与 U 进审计日志，作为免模型异常信号（不改变证据类语义）。

**定义 140（证据-决策雅可比与条件化 EJC）** 决策泛函 d(e)∈ℝ^p（步态/裕度/风险的光滑松弛），证据 e∈ℝ^q。雅可比 J=∂d/∂e=(∂d/∂b)(∂b/∂e)，其中 ∂b/∂e 由得分函数/影响函数估计。奇异值 σ_1≥…≥σ_min，条件数 κ(J)=σ_1/σ_min。**脆弱决策** Frag(r)⇔σ_min<σ_min^\* ∨ κ>κ_max。规则：(C1) Frag(r)⇒禁止 L2 不可逆承诺，必须先做**条件化探针**；(C2) 条件化方向 u\*=argmax_{||u||=1} ∂σ_min/∂e·u，执行 e←e+αu\*（对 σ_min 最速上升）；(C3) 若证据工作空间内无法使 ¬Frag，则降档/绕行。κ 的估计误差须诚实声明（A42）。

**定义 141（零空间冗余校准 NRD）** 一阶零空间 N(J)={Δe:JΔe=0}。**零空间校准探针** Δe\*=argmax_{Δe∈N(J)∩E_ws} IG(Δe;ρ,cal) s.t. ½ΔeᵀHΔe≤ε_curv（二阶曲率界）且 ||Δe||≤ε_step（防止"慢空间"冒充零空间）。E_ws=证据工作空间（当前区域/接触级别/预算下可达证据类型集合）。E_ws=∅ ⇒ 逆运动学无解，直接退保守动作。零空间探针不得计入不可逆承诺的必要证据（只做次级目标）。

**定义 142（合成式韵律解释 SXP）** 解释内容五元组 Exp 不变（第 57 轮定义 136）。**韵律策略** π_p 给每个约束/违反项分配显著度 s_k∈[0,1]，Σs_k=1，s_k∝P(违反_k|b_r)·consequence_k；渲染 R=(m_E,π_p)。**可懂度门** Ê_lb[理解正确|R,s_o]≥MOS_min（下界估计，带校准）。**确认活体** A(c)=f(延迟分布,挑战-应答正确率,跨通道一致,回答熵)，A(c)>θ_spoof ⇒ 判"无同意"并触发 PTM 降级；挑战问题不可预测（A43）。**流式**：解释按块输出，前瞻 L；不可逆指令的承诺句仅在风险片段被 L≥L_min 覆盖且 τ_render≤τ_int 后合成，否则安全停。韵律不得改变语义（A44）。

**定义 143（证据逆运动学 IKS）** 给定目标裕度 d\*，求 e\*=argmin cost(e) s.t. d(e)≥d\*, e∈E_ws, 证据门约束。解集多解时按 argmin κ(J(e)) 取最良态解。在线分解速率控制：Δe=J⁺(d\*−d)+(I−J⁺J)z，z 为次级目标（校准/降低不确定性）在零空间的投影。与第 57 轮 PCE+ 的 VOI 贪婪相比，IKS 是**轨迹级**规划：VOI 选"下一步最值钱"，IKS 选"到目标裕度最短且最良态的整条证据路径"。

**定义 144（运动学-合成证书 KSC / J_k）** J_k=(J_p, jerk_log, jump_log, declared_switch_log, cond_log(κ,σ_min), nullspace_log, prosody_log(s_k), mos_log, spoof_log(A(c)), stream_latency_log)。L2 不可逆承诺的**附加硬条件**：KC(r,t) ∧ ¬Frag(r) ∧ 活体通过 ∧ 前瞻满足；与第 57 轮证据门（EV-probe\*/visit/margin/xmodal/human）取交集，任一不满足即拒。J_k 继承 J_p 全检。

## 2. 关键算法伪代码（完整版见产物区）

```python
def kinematic_gate(r, b_hist, declared, W):          # IP-139
    phi = [scalar_risk(b) for b in b_hist[-W-2:]]
    j = discrete_jerk(phi)                            # v,a,j from Δτ
    J_e = max(abs(j))
    U = any(abs(phi[i]-phi[i-1]) > theta_jump and
            declared[i] is None for i in range(1, len(phi)))
    return (J_e <= J_max and not U), J_e, U

def conditioning_probe(r, d, e, M):                  # IP-140
    J = estimate_jacobian(d, e, M)                    # ∂d/∂e via influence
    kappa, smin = cond_number(J)
    if smin >= smin_star and kappa <= kappa_max:
        return 'well_posed', None
    u = steepest_ascent_direction_smin(J)             # argmax ∂σmin/∂e·u
    return 'fragile', probe_along(r, e, u, alpha=step) # 条件化探针

def nullspace_calibrate(r, J, M, E_ws):              # IP-141
    N = null_space(J)
    if not feasible(E_ws): return 'no_solution'      # 工作空间空 → 保守
    de = argmax(N, key=lambda x: info_gain(x, M.rho, M.cal)
                if curvature(x, M) <= eps_curv and norm(x) <= eps_step else -inf)
    return apply_calibration_probe(r, de)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| KBD | O(W·d_b)/检查点 | O(W) | Δτ 采样诚实、声明切换集完备（A41） |
| EJC | O(p·q²)/区域（估 J+奇异值） | O(p·q) | κ 估计误差 ≤δ_J（A42） |
| NRD | O(q³)（零空间基） | O(q²) | 二阶曲率界、工作空间可达 |
| SXP | O(\|Exp\|+\|chunks\|) | O(\|Exp\|) | 语义不变、MOS 校准、活体不可预测（A43/A44） |
| IKS | O(q³) 离线；O(q²)/在线步 | O(q²) | 良态解优先、E_ws 非空 |
| KSC | O(\|σ\|) | O(\|σ\|) | 与第 57 轮证据门取交集 |

**正确性定理（Kinematic-Synthetic Soundness, KSS 概要）**：在 A37–A40 上加 **(A41)** 信念标量化与 Δτ 采样诚实、声明切换集覆盖全部已知模型变更；(**A42**) 雅可比估计误差 ≤δ_J 且条件数声明诚实；(**A43**) 活体检测假接受 ≤δ_spoof、挑战不可预测；(**A44**) 韵律渲染语义不变、MOS 估计校准、不可逆指令前瞻 L≥L_min。则：
(i) **局部脆弱性界**：若 κ(J)≤κ_max 且 ||δe||≤δ_e，则决策误差 ||δd||≤κ_max·δ_e + O(δ_J)——这是**不依赖先验正确性**的局部 Lipschitz 证书；
(ii) **动力学异常覆盖**：任何未声明跳变 U 或 J_e>J_max 都被 KC 拒绝；但**恒定偏差的平滑错误信念满足 KC**（否定性结论，H29）；
(iii) **交互活体**：确认健全性新增 ≤δ_spoof，复读/脚本化确认在假接受率内被隔离；
(iv) **流式安全**：L2 承诺句在 L<L_min 或 τ_render>τ_int 时不发声，退安全停；
(v) **终止性**：条件化探针 ≤k_cond/检查点，零空间探针 ≤k_null，IKS 分解速率步 ≤k_ik，总预算有限。

## 6. 本轮最大风险

**一句话**：本轮新增的两层护栏都是"稳定/可信"信号而非"正确"信号——**一个恒定系统偏差给出的是全场最光滑（J_e≈0）、条件数最好（κ≈1）、韵律最自然、解释最可懂的信念，它能同时通过运动学门、条件数门与可懂度门，而语音合成式的流畅韵律反而让这个错误结论更可信、更容易骗到活体确认**；因此必须把 jerk/条件数/活体严格定位为"必要非充分"的正交旁路，与第 57 轮的证据类与先验校准取交集，并用定期注入恒定偏差的红队实验持续证明它们抓不到"平稳地错"——否则本轮会把"坏先验普遍"升级为"坏先验普遍且看起来无懈可击"。

## 2. 关键算法伪代码

### IP-139 KBD（信念运动学：急动度与未声明跳变）

```python
def kinematic_gate(r, b_hist, declared, tau, W=3):
    # b_hist: 最近信念序列；declared[i]: 第 i 次更新对应的已声明切换或 None
    phi = [scalar_risk(b) for b in b_hist[-(W + 2):]]
    v = [(phi[i] - phi[i-1]) / tau[i] for i in range(1, len(phi))]
    a = [(v[i] - v[i-1]) / tau[i] for i in range(1, len(v))]
    j = [(a[i] - a[i-1]) / tau[i] for i in range(1, len(a))]
    J_e = max(abs(x) for x in j) if j else 0.0
    U = any(abs(phi[i] - phi[i-1]) > theta_jump and declared[i] is None
            for i in range(1, len(phi)))
    return {'ok': (J_e <= J_max and not U), 'jerk': J_e, 'undeclared': U}

def declare_switch(kind, detail, audit):
    # 任何模型切换必须显式声明，否则在 KBD 中视为未声明跳变
    audit.log(('declared_switch', kind, detail, t_now))
```

### IP-140 EJC（证据-决策雅可比、条件数与条件化探针）

```python
def evidence_decision_analysis(r, d, e, M):
    J = estimate_jacobian(d, e, M)          # (∂d/∂b)(∂b/∂e)，影响函数估计
    sv = singular_values(J)
    smin, kappa = min(sv), max(sv) / max(min(sv), 1e-12)
    fragile = (smin < smin_star) or (kappa > kappa_max)
    return {'J': J, 'smin': smin, 'kappa': kappa, 'fragile': fragile}

def conditioning_probe(r, e, M, step=0.1, k_cond=2):
    st = evidence_decision_analysis(r, decision_of(r, M), e, M)
    if not st['fragile']:
        return 'well_posed', st
    for _ in range(k_cond):
        u = steepest_ascent_direction_smin(st['J'])   # argmax ∂σmin/∂e · u
        e = probe_along(r, e, u, alpha=step)          # 条件化探针
        st = evidence_decision_analysis(r, decision_of(r, M), e, M)
        if not st['fragile']:
            return 'conditioned', st
    return 'still_fragile', st                        # 禁止 L2，降档/绕行
```

### IP-141 NRD（零空间冗余校准）

```python
def nullspace_calibration(r, e, M, E_ws, k_null=1):
    st = evidence_decision_analysis(r, decision_of(r, M), e, M)
    N = null_space(st['J'])                            # 一阶零空间基
    if not E_ws or not feasible_in_workspace(N, E_ws):
        return 'no_solution', M                        # 工作空间空 → 保守
    best, best_ig = None, -inf
    for _ in range(k_null):
        for de in basis_combinations(N):
            if curvature(de, M) > eps_curv: continue   # 二阶曲率界
            if norm(de) > eps_step: continue
            ig = info_gain(de, M.rho, M.cal)           # 对 ρ/cal 的信息增益
            if ig > best_ig:
                best, best_ig = de, ig
        if best is None: break
        M = apply_calibration_probe(r, best, M)        # 不动一阶决策
    return 'calibrated', M
```

### IP-142 SXP（合成式韵律解释 + 确认活体 + 流式前瞻）

```python
def synthesis_explanation(exp, b_r, persona):
    # 1) 前端归一化：区域/单位/上下文，防垃圾进垃圾出
    exp = frontend_normalize(exp, b_r)
    # 2) 韵律：按"违反概率 × 后果"分配显著度
    s = {k: P(violate_k | b_r) * consequence(k) for k in constraints(exp)}
    s = normalize(s)                                   # Σ s_k = 1
    # 3) 声码器：选渲染模态
    m_E = argmax(['map', 'haptic', 'voice', 'text'],
                 key=lambda m: persona.understanding[m])
    R = render(exp, m_E, prosody=s)
    # 4) 可懂度门（下界估计，带校准）
    if mos_lower_bound(R, persona) < MOS_min:
        R = render(exp, 'text', prosody=s)             # 文本回退
    return R

def liveness_check(c, persona, audit):
    A = (latency_score(c) + challenge_response_score(c)
         + cross_channel_consistency(c) + response_entropy(c)) / 4
    if A > theta_spoof:
        audit.log(('spoof', persona.op, A, t_now))
        persona.auth = demote(persona.auth)            # 触发第 57 轮 PTM 降级
        return False
    return True

def streaming_consent(exp, R, persona, risk_span):
    emit_partial(R, async_=True)                       # L1：异步、不阻塞节拍
    if risk_span.covered_by_lookahead < L_min or \
       estimate_render_latency(R) > tau_int(persona.auth):
        return False                                   # 不可逆指令不发声 → 安全停
    return confirm_multimodal(exp, R, persona)
```

### IP-143 IKS（证据逆运动学 + 分解速率控制）

```python
def inverse_evidence_plan(r, d_star, M, E_ws):
    sols = solve_min_cost(r, d_star, M, E_ws)          # 多解
    if not sols: return None                           # 工作空间内无解 → 保守
    return min(sols, key=lambda e: condition_number(estimate_jacobian(e, M)))

def resolved_rate_evidence(r, e, d_star, M, k_ik=5):
    for _ in range(k_ik):
        d = decision_of(r, M)
        J = estimate_jacobian(decision_of, e, M)
        Jp = pinv(J)
        z = secondary_objective_grad(M.rho, M.cal)     # 校准/降不确定
        de = Jp @ (d_star - d) + (np.eye(len(e)) - Jp @ J) @ z
        e = clamp_to_workspace(e + alpha * de, E_ws)
        M = execute_evidence(r, e)
        if norm(d_star - decision_of(r, M)) <= eps_d:
            break
    return e, M
```

### IP-144 KSC（运动学-合成证书与 L2 附加硬条件）

```python
def kinematic_synthetic_gate(c, r, b_hist, declared, M, persona, audit):
    kc = kinematic_gate(r, b_hist, declared, tau=timestamps(b_hist))
    ed = evidence_decision_analysis(r, decision_of(r, M), evidence_of(c), M)
    lv = liveness_check(c.confirmation, persona, audit) if c.has_consent else True
    stream = c.stream_ok                              # 前瞻/延迟已满足
    if c.level == 'L2' and c.irreversible:
        if not kc['ok']:        return ('reject', 'belief_jerk_or_jump', c)
        if ed['fragile']:       return ('reject', 'decision_singular', c)
        if not lv:              return ('reject', 'consent_spoofed', c)
        if not stream:          return ('reject', 'stream_lookahead', c)
    return round57_evidence_gate(c, M, persona)       # 与第 57 轮证据门取交集

def kinematic_synthetic_certificate(sched, log, M, consent_log, auth_log,
                                    ood_reg, kbd_log, cond_log, null_log,
                                    prosody_log, mos_log, spoof_log, stream_log):
    base = map_evidence_certificate_p(sched, log, M, consent_log, auth_log, ood_reg)
    if base[0] != 'ok': return base
    for c in contacts(sched):
        st = kinematic_synthetic_gate(c, c.region, c.b_hist, c.declared, M,
                                      persona_of(c), audit)
        if st[0] != 'ok': return st
    return ('ok', Jk(base[1], kbd_log, cond_log, null_log,
                     prosody_log, mos_log, spoof_log, stream_log))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| KBD | O(W·d_b)/检查点 | O(W) | Δτ 采样诚实、声明切换完备（A41） |
| EJC | O(p·q²)/区域（估 J + SVD） | O(p·q) | κ 估计误差 ≤δ_J（A42） |
| NRD | O(q³)（零空间基）+ O(k_null·q²) | O(q²) | 二阶曲率界、E_ws 可达 |
| SXP | O(\|Exp\|+\|chunks\|) | O(\|Exp\|) | 语义不变、MOS 校准、活体不可预测（A43/A44） |
| IKS | O(q³) 离线；O(k_ik·q²) 在线 | O(q²) | 良态解优先、E_ws 非空 |
| KSC | O(\|σ\|·(W+p·q²)) | O(\|σ\|+q²) | 与第 57 轮证据门取交集 |

**正确性定理（Kinematic-Synthetic Soundness, KSS）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；**(A41)** 信念标量化 φ 与 Δτ 采样诚实，声明切换集 S_t 覆盖全部已知模型变更（OOD/ρ/元版本/auth）；**(A42)** 雅可比估计误差 ≤δ_J，σ_min/κ 声明诚实；**(A43)** 活体检测假接受率 ≤δ_spoof 且挑战不可预测；**(A44)** 韵律渲染语义不变、MOS 估计校准、不可逆指令前瞻 L≥L_min。则：

1. **局部脆弱性界（免模型）**：若 κ(J)≤κ_max 且证据误差 ||δe||≤δ_e，则决策误差 ||δd||≤κ_max·δ_e+O(δ_J)。该界不依赖元先验是否正确，仅依赖局部良态。
2. **动力学异常覆盖**：任何未声明跳变 U 或 J_e>J_max 均被 KC 拒绝，L2 不承诺。
3. **否定性结论（H29）**：存在恒定系统偏差 b^err 使 J_e≈0、U=false、κ≈1、MOS 高——**KC/条件数/可懂度全过，但信念是错的**。故本轮护栏必要非充分，必须与第 57 轮证据门/元校准取交集。
4. **确认健全性**：活体把复读/脚本/胁迫确认的假接受压到 ≤δ_spoof，并触发 PTM 实时降级。
5. **流式安全**：L2 承诺句在 L<L_min 或 τ_render>τ_int 时不合成，退安全停；不存在"解释未覆盖风险片段即下不可逆指令"的路径。
6. **终止性**：每检查点条件化探针 ≤k_cond、零空间探针 ≤k_null、IKS 步 ≤k_ik，叠加第 57 轮预算有限。
7. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp ( δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                    + κ_max·δ_e + δ_spoof + δ_J
                    + P(未声明跳变漏检) + P(二阶零空间漂移>ε_curv) )
             − P(𝓜 陈旧未检出) − P(护盾回退失败) − P(τ_int ∧ τ_render 超时 ∧ 安全停失效)
```

关键：**运动学门给"稳定"，条件数给"局部良态"，活体给"真同意"——三者都与先验正确性正交，所以能与第 57 轮取交集而非替代**；**平滑性是可伪造的健康信号**（否定性结论已写入定理），因此新增护栏全部定位为必要非充分；**流式前瞻把"解释/协商"也纳入实时性契约**。

## 6. 本轮最大风险

**一句话**：本轮新增的两层护栏都是"稳定/可信"信号而非"正确"信号——**一个恒定系统偏差给出的是全场最光滑（J_e≈0）、条件数最好（κ≈1）、韵律最自然、解释最可懂的信念，它能同时通过运动学门、条件数门与可懂度门，而语音合成式的流畅韵律反而让这个错误结论更可信、更容易骗到活体确认**；因此必须把 jerk/条件数/活体严格定位为"必要非充分"的正交旁路，与第 57 轮的证据类与先验校准取交集，并用定期注入恒定偏差的红队实验持续证明它们抓不到"平稳地错"——否则本轮会把"坏先验普遍"升级为"坏先验普遍且看起来无懈可击"。
