# 第 68 轮（承接第 67 轮「SimRAS 仿真增强风险闭环」IP-233~242；灵感循环新周期第 1 轮；本轮灵感：「碰撞检测」×「无刷电机」）

> 第 67 轮 SimRAS 把 RAS 的「当下风险」外推到「未来风险」，并试图用世界模型 + 视觉问答为风险给出来路。但它与 VISTA/RAS 共享一个更底层的默认前提：**机器人在被碰到的瞬间，能分辨「这是外部世界碰了我」还是「我自己的身体与驱动在制造异常」。** 对无刷电机驱动的机器人，这个前提非常危险：无刷电机既是最灵敏的接触传感器（相电流/反电动势对力矩扰动极其敏感），也是最大的「自体噪声源」（换相误差、无感转子位置估计误差、齿槽转矩、参数漂移都会伪造出碰撞波形）。
>
> 核心命题：
>
> **把「碰撞检测」从「残差是否超阈值」重构为「自-他残差归因」：用无刷电机的电气签名构造高带宽接触观测面，在「相位锁定自子空间 × 接触子空间 × 电气故障子空间 × 慢变扰动子空间」中做结构分解，用主动电激励提升自模型可辨识性，并对每个接触判定给出带自模型不确定性的安全证书。记为 CoBRA（Collision-aware Brushless Residual Attribution）。**
>
> 如果说 VISTA 问「世界是否如我所测」、RAS 问「谁该控制、控制多少」、SimRAS 问「未来风险如何演化」，那么 CoBRA 问的是最原始的一问：**「此刻，是别人碰了我，还是我自己在骗自己？」**

## 0. 直觉与动机

**灵感 1（无刷电机 → 电机即传感器）**
直觉：无刷电机的 FOC 环路里，`(i_d, i_q, v_d, v_q, v_dc)` 本身就是一组高带宽的力矩/位置观测：`τ_e ≈ (3/2)pλ_m i_q` 是内生力矩计，反电动势 `e = ω_e λ_m` 是内生编码器，相电流对突变负载的响应是内生应变片。碰撞不需要额外的力矩传感器去「看见」，它已经以力矩扰动的形式写进了电机方程。缺的不是信号，而是**从信号里把「外部接触」与「电机自身」分开的解释框架**。

**灵感 2（碰撞检测 → 自-他归因，而非阈值检测）**
直觉：传统碰撞检测把「残差大」等同「有碰撞」。但换相角误差、无感位置观测误差、死区、齿槽转矩同样让残差大——它们会制造「幽灵碰撞（ghost collision）」。误报的代价不只是停一下：协作场景里频繁急停会让操作者产生 alarm fatigue，最终连真碰撞也被忽略。因此核心指标应从 TPR 迁移到**归因后验的校准度**：给定残差，`P(contact | r)` 是否可信，以及在自模型不确定时是否会「把真碰撞解释掉」。

**灵感 3（结构可辨识性 → 四个子空间）**
直觉：不同原因在残差空间里留下的「形状」不同：
- **自子空间 S**：与转子电角度 `θ_e` 相位锁定的谐波（换相、齿槽、死区、位置误差），逐关节独立、在电机停转时消失；
- **接触子空间 C**：多关节残差落在外力经接触雅可比 `J_c^T` 映射的子空间，并伴随系统动量/能量的外部注入；
- **故障子空间 F**：负序/零序、相电阻不对称、匝间短路等电气故障，零速时仍存在；
- **慢变子空间 D**：热漂移、负载/重力变化，时间尺度秒级、与温度或任务相关。
只要 `S, C, F, D` 的主夹角（principal angle）有下界，归因误差就会随信噪比指数下降。这把「调阈值」换成了「做子空间几何」。

**灵感 4（主动电激励 → 主动提升自模型可辨识性）**
直觉：低速/静止时无感无刷电机对转子位置几乎不可观，碰撞与换相误差在观测上近乎不可分。可以注入安全的 **d 轴高频小电流**（不产生平均力矩）辨识 `R, L_d, L_q`，再用小幅 q 轴激励辨识 `λ_m` 与位置偏移 `δθ`；用 D-optimal 实验设计最大化 Fisher 信息。这与第 66 轮 RAS 的「主动表情探针」同构：不是被动等一个够大的信号，而是**主动制造信息**。关键约束是注入不得触发接触、不得引入可感知抖动。

**灵感 5（因果签名 → 接触证据三元组）**
直觉：单帧幅值永远不够，需要三个因果判据：
1. **相位锁定零假设**：自误差在 `θ_e` 的整数阶谐波上、跨周期可重复；真碰撞不具备这种锁定。
2. **动量/能量一致性**：外部接触向系统注入动量/能量；自误差只改变「电机力矩的估计」，不能改变浮动基动量或总能量收支。
3. **因果起点与持续性**：碰撞有与任务/视觉事件对齐的外部起点，随后可能是冲激或持续接触；电气故障是零速也在的慢偏差；热漂移是单调慢变。
三者构成「接触证据三元组」，缺一不可。

**灵感 6（合流 → CoBRA 六层架构）**
1. **EOS Electrical Observation Surface**：同步采集 20 kHz 相电流/相电压/母线电压/温度与 `θ̂, ω̂`，构造电机方程残差；
2. **PLD Phase-Locked Decomposition**：把残差分解为 `θ_e` 锁定自子空间 + 其余部分；
3. **SMB Self-Model Bank**：在可容许自模型集合 `Θ_adm` 上做贝叶斯模型平均，任何「能被某个合法自模型解释」的残差都先归为 self；
4. **CSI Contact Subspace & Momentum Identification**：用 `J_c^T` 子空间 + 浮动基动量观测做接触一致性检验与力定位；
5. **APD Active Probe Design**：按 Fisher 信息选择 d/q 轴安全激励，压缩 `Θ_adm`；
6. **CAA Contact Attribution Arbiter + C-Contact 证书**：输出四类后验与证书（检测延迟、误报界、力上界、自模型不确定度）；不可辨识时**保守判为 contact**，绝不「幽灵放行」。

## 1. 形式化定义（增量：定义 266–285）

- **定义 266（CoBRA 总览）**：`CoBRA = (EOS, PLD, SMB, CSI, APD, CAA, C-Contact)`。定位：VISTA/RAS/SimRAS 之下的「接触层」——它不预测未来，只回答「当前这个残差是谁造成的」。不变式：20 kHz 电气原始流只做观测、残差与控制，不写学习参数；自模型更新、子空间基更新、证书构建只在语义流（≤1 kHz）。
- **定义 267（电气观测面 EOS）**：`o_t = (i_abc(t), v_abc(t), v_dc(t), T_w(t), θ̂(t), ω̂(t))`，采样 `f_s = 20 kHz`，与 PWM 载波同步；由 `o_t` 计算 `i_dq, v_dq` 与电机方程残差。EOS 同时输出「电周期相位」`φ_e = θ_e mod 2π`，作为自子空间基的自变量。
- **定义 268（无刷电机 dq 模型）**：
```
v_d = R i_d + L_d di_d/dt − ω_e L_q i_q
v_q = R i_q + L_q di_q/dt + ω_e (L_d i_d + λ_m)
τ_e = (3/2) p [ λ_m i_q + (L_d − L_q) i_d i_q ]
J dω/dt = τ_e − τ_L − τ_c − bω − τ_cog(θ)
```
其中 `τ_c` 为外部接触力矩，`τ_cog(θ)` 为已知空间周期的齿槽转矩，`p` 为极对数，`ω_e = pω`。测量/估计位置 `θ̂`，定义换相偏移 `δθ = θ − θ̂`。
- **定义 269（电机残差）**：以电流残差为主、力矩等效：
```
ε_d(t) = v_d − [R̂ i_d + L̂_d di_d/dt − ω̂_e L̂_q i_q]
ε_q(t) = v_q − [R̂ i_q + L̂_q di_q/dt + ω̂_e (L̂_d i_d + λ̂_m)]
r_t = k_t · ε_q(t) + k_rel · ε_d(t) i_q(t),   k_t = (3/2)pλ̂_m
```
`r_t` 单位化为关节力矩残差；多关节时 `r_t = (r_t^1, …, r_t^n) ∈ ℝ^n`。
- **定义 270（相位锁定自子空间 S）**：给定 `φ_e`，自子空间
```
S(φ_e) = span{ e_j ⊗ φ_k(φ_e) : j=1..n, k ∈ K_self }
φ_k(φ_e) ∈ {1, cos(mφ_e), sin(mφ_e) : m = 1..M}
```
`K_self` 由换相、齿槽、死区、位置偏移的已知阶次组成；`e_j` 是第 j 关节的单位向量。
- **定义 271（接触子空间 C）**：对候选接触点集 `𝒞`（末端、已知护壳、连杆采样点），
```
C = ∪_{c∈𝒞} range(J_c^T),   J_c = ∂x_c/∂q ∈ ℝ^{3×n}
```
并附加物理约束：存在 `F ∈ ℝ^3` 使 `r_perp = J_c^T F` 且 `‖F‖ ≤ F_max`；浮动基时还要求动量观测一致。
- **定义 272（可容许自模型集合 Θ_adm）**：`Θ_adm = { (R, L_d, L_q, λ_m, δθ, τ_cog) : 参数在标定区间内，且 d/q 方程与机械方程同时自洽 }`。SMB 在 `Θ_adm` 上维护后验 `w(Θ)`。
- **定义 273（幽灵碰撞）**：若 `∃ Θ ∈ Θ_adm` 使整段残差窗口 `r_{t−W:t}` 的似然高于接触假设，则称该残差为 ghost collision（自模型可解释）。
- **定义 274（自-他归因后验）**：假设集 `A = {a_self, a_contact, a_elec, a_drift, a_load}`，
```
P(a | r) ∝ p(r | a) · P(a) · 1[Θ_adm 能解释 a_self]
```
其中 `p(r | a_contact)` 用 `C` 上的低维投影残差建模，`p(r | a_self)` 用 `Θ_adm` 上的模型平均。
- **定义 275（PLD 分解与主夹角）**：`r = P_S r + P_C⊥ r + r_⊥`，其中 `P_S` 为 `S(φ_e)` 正交投影，`P_C⊥` 为「去 S 后投到 C」的投影。定义子空间主夹角 `φ_SC = ∠(S, C)`，`φ_min = min_t ∠(S_t, C)`。
- **定义 276（结构可辨识条件）**：若 `φ_min ≥ φ_0 > 0` 且 `rank([P_S; P_C]) = dim S + dim C`，则称该关节/接触点组合是 `φ_0`-可辨识的。可辨识度定义为 `κ_C = sin φ_min`。
- **定义 277（主动探针与 Fisher 信息）**：探针 `u_probe = (i_d^p(t), i_q^p(t))`，`|i_d^p| ≤ i_d^max`，`∫ i_q^p dt = 0`（零净力矩）。Fisher 信息矩阵 `F(Θ; u) = E[ (∂ log p(o|Θ,u)/∂Θ)(·)^T ]`，选择 `u* = argmax_u log det F(Θ; u)`（D-optimal），并满足接触/抖动约束。
- **定义 278（接触起始 CUSUM 统计量）**：`g_t = max(0, g_{t−1} + ℓ_t − k)`，`ℓ_t = log p(r_t | a_contact) − log p(r_t | a_self)`；告警时刻 `t_d = inf{t : g_t ≥ h}`。`h` 由误报平均运行长度 `ARL_0` 标定。
- **定义 279（接触力估计）**：在候选点 `c*` 上 `F̂ = (J_{c*} J_{c*}^T + μI)^{-1} J_{c*} r_perp`；点 `c*` 由 `argmin_c ‖(I − J_c^T (J_c J_c^T)^+ J_c) r_perp‖` 选出。
- **定义 280（C-Contact 证书）**：`J_CoBRA = (attribution_posterior, t_d, force_est, force_upper, self_model_unc, φ_min, probe_used, eos_hash)`。Valid ⇔ `P(a_contact|r) ≥ τ_c` 或不可辨识时保守置位，且 `force_upper ≤ F_max`。
- **定义 281（接触认证前缀）**：`k_contact = max{k' ≤ m : ∀s ≤ k', P(a_contact | r_{t+s}) < τ_c 或 τ_cmd 已按 F̂ 限幅}`；最终 `k* = min(k_VISTA, k_emo, k_wm, k_contact)`。
- **定义 282（接触感知风险缩放）**：`λ_contact(t) = clip(1 − α_c·P(a_contact|r) − β_c·(F̂/F_max), 0.3, 1.0)`。与 RAS 的 `λ_risk` 相乘，接触证据只能收紧、不能放宽本轮安全裕度。
- **定义 283（AIC-CoBRA 干扰集）**：`ℰ_CoBRA = ℰ_SimRAS × ℰ_ghost × ℰ_probe × ℰ_sync`，其中 `ℰ_ghost` = {换相误差、无感位置误差、齿槽、死区}，`ℰ_probe` = {注入被负载淹没、注入诱发接触}，`ℰ_sync` = {电流/位置采样失步、PWM 混叠}。
- **定义 284（CoBRA-Sim 耦合）**：SimEngine 增加「电气层」：用 dq 方程 + 换相/PWM 模型渲染相电流；WorldModel 增加 contact head `P(a_contact | z_t)`；coBRA 的归因后验作为接触头的物理监督，接触审计写入 `ContactBuf[scene_hash]`。
- **定义 285（无幽灵放行不变式）**：对任一残差，若 `S, C, F, D` 的解释同时不成立（后验熵 `H(a|r) > τ_H` 且最大后验 `< τ_c`），则系统必须执行保守动作 `a = a_contact` 或降速至 `λ_contact ≤ 0.5`；绝不以「可能只是换相误差」为由继续原速运行。

```python
class ElectricalObservationSurface:
    """IP-243：20kHz 同步采样，只在实时流做残差，不写学习参数"""
    def sample(self):
        i_abc, v_abc = self.adc.read_abc()
        v_dc, T_w = self.dc_bus.read(), self.temp.read()
        theta_hat, omega_hat = self.encoder_or_observer()
        i_dq, v_dq = clarke_park(i_abc, v_abc, theta_hat)
        return {'i_dq': i_dq, 'v_dq': v_dq, 'v_dc': v_dc,
                'T_w': T_w, 'theta': theta_hat, 'omega': omega_hat,
                'phi_e': (self.p * theta_hat) % (2*pi)}

    def residual(self, o, params):
        # 定义 269：电机方程残差 → 关节力矩单位
        eps_d = o['v_dq'][0] - (params.R*o['i_dq'][0]
                + params.Ld*self.di_d - o['omega']*self.p*params.Lq*o['i_dq'][1])
        eps_q = o['v_dq'][1] - (params.R*o['i_dq'][1]
                + params.Lq*self.di_q + o['omega']*self.p*(params.Ld*o['i_dq'][0] + params.lam))
        k_t = 1.5 * self.p * params.lam
        return k_t*eps_q + 0.1*eps_d*o['i_dq'][1]


class SelfModelBank:
    """IP-245：可容许自模型集合上的贝叶斯模型平均"""
    def __init__(self, n_particles=256):
        self.particles = sample_theta_adm(n_particles)
        self.w = ones(n_particles) / n_particles

    def update(self, r_window, phi_window):
        # 每个粒子预测 S(phi) 上的自残差，按似然重加权
        for i, th in enumerate(self.particles):
            pred = self.render_self_residual(th, phi_window)
            self.w[i] *= exp(-0.5 * norm(r_window - pred)**2 / self.sigma**2)
        self.w /= self.w.sum()
        return self.w, self.self_likelihood(r_window)

    def self_likelihood(self, r_window):
        # 用核密度/高斯混合给出 p(r | a_self)
        return sum(wi * gaussian(r_window - self.render_self_residual(th, ...))
                   for wi, th in zip(self.w, self.particles))


class PhaseLockedDecomposer:
    """IP-244：相位锁定分解，返回去自后的残差"""
    def decompose(self, r, phi_e, theta_bank):
        B = build_harmonic_basis(phi_e, orders=theta_bank.K_self)  # n×m
        a_self, *_ = lstsq(B, r)
        r_perp = r - B @ a_self
        return r_perp, a_self


class ContactSubspaceIdentifier:
    """IP-246：接触子空间 + 动量一致性 + 力定位"""
    def identify(self, r_perp, q, momentum_err=None):
        best = None
        for c in self.candidates:           # 末端 + 护壳 + 连杆采样
            J = self.jacobian(c, q)
            r_hat = J.T @ pinv(J @ J.T + 1e-6*np.eye(3)) @ r_perp
            score = norm(r_perp - r_hat)
            if best is None or score < best.score:
                F = pinv(J @ J.T + 1e-6*np.eye(3)) @ (J @ r_perp)
                best = ContactCandidate(c, F, score)
        # 动量/能量一致性（浮动基）
        if momentum_err is not None:
            best.momentum_consistent = norm(momentum_err) > self.tau_mom
        return best


class ActiveProbeDesigner:
    """IP-247：D-optimal 安全电激励"""
    def design(self, theta_post, constraints):
        best_u, best_info = None, -inf
        for w_p in self.probe_frequencies:
            for amp in self.safe_amplitudes:
                u = make_probe(w_p, amp)          # d 轴为主，q 轴零净力矩
                if not self.safe(u, constraints): continue
                F = fisher_information(theta_post, u)
                info = log_det(F + 1e-9*np.eye(F.shape[0]))
                if info > best_info:
                    best_u, best_info = u, info
        return best_u, best_info


class ContactAttributionArbiter:
    """IP-248：四类贝叶斯归因 + CUSUM"""
    def attribute(self, r, r_perp, self_bank, contact, elec, drift):
        l_self = self_bank.self_likelihood(r)
        l_contact = likelihood_contact(r_perp, contact)
        l_elec = likelihood_electrical_fault(r, self.elec_model)
        l_drift = likelihood_drift(r, self.thermal_model)
        logits = np.log([l_self, l_contact, l_elec, l_drift] + 1e-12) + self.log_prior
        post = softmax(logits)
        self.cusum.update(np.log(post[1] + 1e-9) - np.log(post[0] + 1e-9), k=self.k)
        return post, self.cusum.alarm(self.h)


class ContactSafetyCertificate:
    """IP-249：接触证书"""
    def certify(self, post, contact, t_d, self_unc, phi_min):
        p_c = post[1]
        force_upper = contact.F_norm * (1 + self_unc) / max(sin(phi_min), 1e-3)
        valid = (p_c >= self.tau_c or self.unidentifiable(post, phi_min))
        return J_CoBRA(post=post, t_d=t_d, force_est=contact.F,
                       force_upper=force_upper, self_model_unc=self_unc,
                       phi_min=phi_min, valid=valid)


def CoBRA_round(M, obs):
    # 实时流：电气观测 + 残差
    o = M.eos.sample()
    r = M.eos.residual(o, M.self_bank.map_params())
    # 自子空间分解
    r_perp, a_self = M.pld.decompose(r, o['phi_e'], M.self_bank)
    # 自模型模型平均
    w, l_self = M.self_bank.update(r, o['phi_e'])
    # 接触子空间 + 动量一致性
    contact = M.csi.identify(r_perp, M.q, M.momentum_observer.error())
    # 主动探针：仅当后验歧义且运动学允许
    if M.ambiguous(l_self, contact) and M.probe_safe():
        u, info = M.apd.design(M.self_bank.theta_post(), M.constraints())
        M.apply_probe(u); M.self_bank.update(r, o['phi_e'])
    # 归因 + 证书
    post, t_d = M.caa.attribute(r, r_perp, M.self_bank, contact,
                                 M.elec_model, M.thermal_model)
    cert = M.csc.certify(post, contact, t_d,
                         M.self_bank.uncertainty(), M.phi_min())
    # 接触感知风险缩放（只收紧不放宽）
    lambda_contact = clip(1 - 0.6*post[1] - 0.4*contact.F_norm/M.F_max, 0.3, 1.0)
    return post, cert, lambda_contact
```

## 3. 推导

**引理 13（自子空间与接触子空间的可分性）** 设 `r = s + c + n`，`s ∈ S`，`c ∈ C`，`n ~ N(0, σ²I)`，且 `S ∩ C = {0}`、主夹角 `φ_SC ≥ φ_0`。则把 `c` 误判为 `s` 的投影误差满足
```
E‖P_S c‖² = ‖c‖² cos²φ_SC ≤ ‖c‖² cos²φ_0
```
于是基于投影的归因错误率 `≤ exp(−‖c‖² sin²φ_0 / (2σ²))`；`φ_0 → 0` 时任何有限 SNR 都无法可靠分辨。这是「低速/零速不可观」在几何上的精确表述。

**引理 14（检测延迟-带宽下界）** 设电流环带宽 `f_c`、采样率 `f_s`，碰撞冲量 `Δp = ∫τ_c dt`。在自模型误差 `δself` 下，CUSUM 的最短可检测冲量满足
```
Δp_min ≈ (h + k·W) · T_s · σ_r / ‖J_c^T‖
t_d ≥ 1/f_s + 1/(2πf_c)
```
即检测延迟下界由采样与电流环共同决定；提高 `f_s` 只消除采样项，无法突破电流环物理带宽。这一界应在证书中显式给出，而不是宣称「微秒级碰撞检测」。

**引理 15（主动探针的信息增益）** 注入 d 轴小幅正弦 `i_d^p(t) = A_p sin(ω_p t)` 时，`R` 与 `L_d` 的 Fisher 信息近似为
```
F_RR ≈ A_p² T / (2σ_v²),   F_LdLd ≈ A_p² ω_p² T / (2σ_v²)
```
故 `ω_p` 应靠近 `R/L_d` 的拐点频率以同时辨识两者；q 轴零净力矩探针不改变平均接触力，但会通过 `ω_e L_q i_q` 交叉项影响 `δθ` 的可辨识性。D-optimal 设计等价于最大化 `log det F`，可把 `Θ_adm` 的体积压缩 `exp(−½ log det F)` 倍。

**定理 14（CoBRA 端到端归因一致性）** 在 A92–A96、引理 13–15 下，CoBRA 输出满足：
1. `P(误归因) ≤ α_self + α_contact + α_elec + α_drift`，其中各项由子空间夹角、SNR 与探针信息量给出；
2. `P(漏检碰撞) ≤ exp(−g_t) + P(Θ_adm 过完备)`；后者由 `Θ_adm` 的复杂度惩罚控制；
3. 若 `φ_min < φ_0` 或后验熵超阈，则触发定义 285 的保守动作，**不存在「幽灵放行」**；
4. `λ_contact ≤ 1` 恒成立，接触证据只能收紧 VISTA/RAS/SimRAS 的既有安全裕度。

**定理 15（接触力上界与定位误差）** 设 `J_c` 的最小奇异值 `σ_min(J_c)`，自残差泄漏 `δs = ‖P_C s‖`，位置误差 `δθ`。则
```
‖F̂ − F‖ ≤ (‖r_perp − J_c^T F‖ + δs) / σ_min(J_c) + L_J·δθ
```
因此接触力上界 `F_upper = (‖r_perp‖ + δs_max)/σ_min(J_c) + L_J δθ_max` 可用于安全限幅；当 `σ_min` 小（接近奇异位形）时，力估计不可靠，证书应降级为「仅报警、不精确限力」。

**定理 16（CoBRA-Sim 的接触迁移界）** 设 SimEngine 的电气层与真实电机的分布差异 `TV(P_sim^elec ‖ P_real^elec) ≤ δ_e`。则接触头 `P(a_contact | z)` 的在线校准误差满足
```
E|P̂_contact − P_contact| ≤ (1 − Acc_sim) + C_e·δ_e
```
`δ_e` 主要来自换相/PWM 未建模谐波与温度漂移；CoBRA 的物理自模型正是用来把 `δ_e` 从「接触头」中剥离，避免 SimRAS 的接触先验把 ghost collision 学成真接触。

## 6. 本轮最大风险

**一句话**：CoBRA 的「自子空间 + 可容许自模型集合」本身是由标定数据与模型假设定义的，一旦 `Θ_adm` 过完备（例如把未建模摩擦、连杆柔性、装配间隙都塞进「自模型」），它就会把真实碰撞解释成「合法的自体残差」，从而在**最需要停机的一刻选择继续运行**——这是本轮所有推导依赖的核心假设：**自模型集合的复杂度可控，且接触与自误差在子空间几何上始终留有正夹角。**

**次级风险与缓解**：
1. **低速度/零速不可观**：无感位置误差与碰撞在观测上近乎简并 → 强制 `φ_min < φ_0` 时保守判 contact 或降速，绝不依赖精确力估计；
2. **自模型过完备**：用最小描述长度（MDL）惩罚 `Θ_adm` 复杂度，并在标定集上做「碰撞注入留出测试」；
3. **主动探针副作用**：d 轴注入可能被负载淹没或诱发接触 → 限制幅值/频率，探针前后做安全包络检查；
4. **采样同步与混叠**：20 kHz 与 PWM 载波失步会造成伪谐波 → 与 PWM 同步采样 + 抗混叠滤波；
5. **算法只覆盖电机可观测的接触**：基座/被动轮/柔性护壳接触可能不进入电机残差 → 与外部触觉/视觉做冗余，CoBRA 只声明「电机可观测接触」的证书。

**定义 282（接触感知风险缩放）**
```
λ_contact(t) = clip(1 − α_c·P(a_contact | r) − β_c·(F̂/F_max), 0.3, 1.0)
```
与 RAS 的 `λ_risk` 相乘；接触证据只能收紧，不能放宽本轮安全裕度。

**定义 283（AIC-CoBRA 干扰集）**
```
ℰ_CoBRA = ℰ_SimRAS × ℰ_ghost × ℰ_probe × ℰ_sync
ℰ_ghost = {换相误差, 无感位置误差, 齿槽, 死区}
ℰ_probe = {注入被负载淹没, 注入诱发接触}
ℰ_sync  = {电流/位置采样失步, PWM 混叠}
```

**定义 284（CoBRA-Sim 耦合）** SimEngine 增加电气层（dq 方程 + 换相/PWM 渲染相电流）；WorldModel 增加 contact head `P(a_contact | z_t)`；CoBRA 归因后验作为接触头的物理监督；接触审计写入 `ContactBuf[scene_hash]`。

**定义 285（无幽灵放行不变式）** 若 `S, C, F, D` 的解释同时不成立（后验熵 `H(a|r) > τ_H` 且最大后验 `< τ_c`），系统必须执行保守动作 `a = a_contact` 或降速至 `λ_contact ≤ 0.5`；绝不以「可能只是换相误差」为由继续原速运行。

```python
# IP-243 EOS：电气观测面
class ElectricalObservationSurface:
    def sample(self):
        i_abc, v_abc = self.adc.read_abc()
        v_dc, T_w = self.dc_bus.read(), self.temp.read()
        theta_hat, omega_hat = self.encoder_or_observer()
        i_dq, v_dq = clarke_park(i_abc, v_abc, theta_hat)
        return {'i_dq': i_dq, 'v_dq': v_dq, 'v_dc': v_dc, 'T_w': T_w,
                'theta': theta_hat, 'omega': omega_hat,
                'phi_e': (self.p * theta_hat) % (2*pi)}

    def residual(self, o, p):
        eps_d = o['v_dq'][0] - (p.R*o['i_dq'][0] + p.Ld*self.di_d
                - o['omega']*self.p*p.Lq*o['i_dq'][1])
        eps_q = o['v_dq'][1] - (p.R*o['i_dq'][1] + p.Lq*self.di_q
                + o['omega']*self.p*(p.Ld*o['i_dq'][0] + p.lam))
        return 1.5*self.p*p.lam*eps_q + 0.1*eps_d*o['i_dq'][1]


# IP-244 PLD：相位锁定分解
def phase_locked_decompose(r, phi_e, K_self, M):
    B = build_harmonic_basis(phi_e, K_self, M)  # n×m，含 cos/sin(mφ)
    a_self, *_ = np.linalg.lstsq(B, r, rcond=None)
    return r - B @ a_self, a_self


# IP-245 SMB：自模型库的贝叶斯模型平均
class SelfModelBank:
    def __init__(self, n_particles=256):
        self.particles = sample_theta_adm(n_particles)
        self.w = np.ones(n_particles) / n_particles

    def update(self, r_window, phi_window):
        for i, th in enumerate(self.particles):
            pred = self.render_self_residual(th, phi_window)
            self.w[i] *= np.exp(-0.5*np.linalg.norm(r_window-pred)**2/self.sigma**2)
        self.w /= self.w.sum()

    def self_likelihood(self, r_window, phi_window):
        return sum(wi * self.kernel(r_window - self.render_self_residual(th, phi_window))
                   for wi, th in zip(self.w, self.particles))

    def map_params(self):
        return self.particles[np.argmax(self.w)]

    def uncertainty(self):
        return entropy(self.w) / np.log(len(self.w))


# IP-246 CSI：接触子空间 + 动量一致性 + 力定位
class ContactSubspaceIdentifier:
    def identify(self, r_perp, q, momentum_err=None):
        best = None
        for c in self.candidates:
            J = self.jacobian(c, q)
            F = np.linalg.pinv(J @ J.T + 1e-6*np.eye(3)) @ (J @ r_perp)
            r_hat = J.T @ F
            score = np.linalg.norm(r_perp - r_hat)
            if best is None or score < best.score:
                best = ContactCandidate(c, F, score)
        if momentum_err is not None:
            best.momentum_consistent = np.linalg.norm(momentum_err) > self.tau_mom
        return best


# IP-247 APD：D-optimal 主动电激励
def design_probe(theta_post, constraints, freqs, amps):
    best_u, best_info = None, -np.inf
    for w_p in freqs:
        for A in amps:
            u = make_probe(w_p, A)          # d 轴正弦，q 轴零净力矩
            if not safe_probe(u, constraints): continue
            info = np.log(np.linalg.det(fisher_information(theta_post, u)
                                        + 1e-9*np.eye(6)))
            if info > best_info:
                best_u, best_info = u, info
    return best_u, best_info


# IP-248 CAA：四类归因 + CUSUM
class ContactAttributionArbiter:
    def attribute(self, r, r_perp, self_bank, contact, elec, drift):
        l = np.array([
            self_bank.self_likelihood(r, ...),
            likelihood_contact(r_perp, contact),
            likelihood_electrical_fault(r, elec),
            likelihood_drift(r, drift)])
        post = softmax(np.log(l + 1e-12) + self.log_prior)
        self.cusum.update(np.log(post[1]+1e-9) - np.log(post[0]+1e-9), self.k)
        return post, self.cusum.alarm(self.h)


# IP-249 C-Contact：证书
def certify(post, contact, t_d, self_unc, phi_min, F_max, tau_c):
    force_upper = contact.F_norm * (1 + self_unc) / max(np.sin(phi_min), 1e-3)
    unidentifiable = (phi_min < PHI0) or (entropy(post) > TAU_H)
    valid = (post[1] >= tau_c or unidentifiable) and force_upper <= F_max
    return J_CoBRA(post, t_d, contact.F, force_upper, self_unc,
                   phi_min, self.probe_used, hash_eos(self.eos), valid)


# IP-250/252 CoBRA 闭环（嵌入 SimRAS_round 的接触层）
def CoBRA_round(M, obs):
    o = M.eos.sample()
    r = M.eos.residual(o, M.self_bank.map_params())
    r_perp, a_self = phase_locked_decompose(r, o['phi_e'], M.K_self, M.M_harm)
    M.self_bank.update(r, o['phi_e'])
    contact = M.csi.identify(r_perp, M.q, M.momentum_observer.error())

    if M.ambiguous(r_perp, contact) and M.probe_safe():
        u, info = design_probe(M.self_bank.theta_post(), M.constraints(),
                               M.probe_freqs, M.probe_amps)
        M.apply_probe(u)
        M.self_bank.update(r, o['phi_e'])

    post, t_d = M.caa.attribute(r, r_perp, M.self_bank, contact,
                                M.elec_model, M.thermal_model)
    cert = certify(post, contact, t_d, M.self_bank.uncertainty(),
                   M.phi_min(), M.F_max, M.tau_c)
    lam_contact = np.clip(1 - 0.6*post[1] - 0.4*contact.F_norm/M.F_max, 0.3, 1.0)

    # 与 SimRAS 接口：接触证据只收紧，不放宽
    lam_total = lam_contact * M.simras.lambda_risk
    k_star = min(M.simras.k_ras, M.contact_prefix(cert))
    M.simras.dispatch(k_star, lam_total)
    M.contact_buf.write(scene_hash(M.q, post), cert)
    return post, cert, lam_contact
```

## 4. 推导

**引理 13（自子空间与接触子空间可分性）** 设 `r = s + c + n`，`s ∈ S`，`c ∈ C`，`n ~ N(0, σ²I)`，`S ∩ C = {0}`，主夹角 `φ_SC ≥ φ_0`。把 `c` 误判为 `s` 的投影能量满足
```
E‖P_S c‖² = ‖c‖² cos²φ_SC ≤ ‖c‖² cos²φ_0
P(误归因) ≤ exp(−‖c‖² sin²φ_0 / (2σ²))
```
`φ_0 → 0` 时任何有限 SNR 都无法可靠分辨：这正是零速/低速无感电机不可观的几何表述。

**引理 14（检测延迟-带宽下界）** 电流环带宽 `f_c`、采样率 `f_s`，碰撞冲量 `Δp = ∫τ_c dt`。CUSUM 最短可检测冲量与延迟满足
```
Δp_min ≈ (h + k·W)·T_s·σ_r / ‖J_c^T‖
t_d ≥ 1/f_s + 1/(2πf_c)
```
提高采样只消除第一项；证书必须显式报告该下界，不能宣称突破电流环带宽。

**引理 15（主动探针信息增益）** 注入 `i_d^p(t) = A_p sin(ω_p t)` 时
```
F_RR ≈ A_p²T/(2σ_v²),   F_LdLd ≈ A_p²ω_p²T/(2σ_v²)
```
`ω_p` 取 `R/L_d` 拐点附近可同时辨识 `R, L_d`；q 轴零净力矩探针不改变平均接触力，但通过 `ω_e L_q i_q` 交叉项提升 `δθ` 可辨识性。D-optimal 使 `Θ_adm` 体积压缩 `exp(−½ log det F)` 倍。

**定理 14（CoBRA 端到端归因一致性）** 在 A92–A96、引理 13–15 下：
1. `P(误归因) ≤ α_self + α_contact + α_elec + α_drift`；
2. `P(漏检碰撞) ≤ exp(−g_t) + P(Θ_adm 过完备)`；
3. `φ_min < φ_0` 或后验熵超阈 ⇒ 触发定义 285 的保守动作，**无幽灵放行**；
4. `λ_contact ≤ 1` 恒成立：接触证据只能收紧既有安全裕度。

**定理 15（接触力上界与定位误差）**
```
‖F̂ − F‖ ≤ (‖r_perp − J_c^T F‖ + δs)/σ_min(J_c) + L_J·δθ
F_upper = (‖r_perp‖ + δs_max)/σ_min(J_c) + L_J·δθ_max
```
`σ_min(J_c)` 小（接近奇异位形）时力估计不可靠，证书降级为「仅报警、不精确限力」。

**定理 16（CoBRA-Sim 接触迁移界）** 设 SimEngine 电气层与真实电机 `TV(P_sim^elec ‖ P_real^elec) ≤ δ_e`，则 contact head 的在线校准误差
```
E|P̂_contact − P_contact| ≤ (1 − Acc_sim) + C_e·δ_e
```
`δ_e` 主要来自换相/PWM 未建模谐波与温漂；CoBRA 的物理自模型把 `δ_e` 从 contact head 中剥离，防止 SimRAS 把 ghost collision 学成真接触。

## 7. 本轮最大风险

**一句话**：CoBRA 的「自子空间 + 可容许自模型集合」由标定数据与模型假设定义，一旦 `Θ_adm` 过完备（把未建模摩擦、连杆柔性、装配间隙都塞进「自模型」），它就会把真实碰撞解释成「合法的自体残差」，在最需要停机的一刻选择继续运行——本轮所有推导依赖的核心假设是：**自模型集合复杂度可控，且接触与自误差在子空间几何上始终留有正夹角。**
