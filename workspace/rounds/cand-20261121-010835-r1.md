# 第 1 轮（新灵感循环第 1 轮；本轮灵感：「少样本学习」×「自适应控制」）

> **基线**：上一轮（灵感「大语言模型」×「机器人」×「智能体」）MetricVoiceGauge-NCD-HUTDH-v17（定义 657–686；引理 137–142；实验 E691–E710）。
> 本轮纪律：**学习只扩表征、不扩授权；自适应只在安全包络内、越界即冻结；证据只买活性、不买安全**。不推倒 v17：v17 的 CLP/S2C/HCG/PSV/APS/AMC、v16 的 BTS/TRM/WBC/CSC/NCS/MCA/WCB、v13 的 AIO/RTIC/CPD/DGC/DDL/RTCR、v14 的 SCD/DSD/DCA/EDC、v12 的 USG/TGC/BAA/GAGP/UC、v11 的 HAS/HCC/HATD/HDT、v10 的 NGE/DSL/CC/CWM/CAE/NCP、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 与历轮不变式全部保留。六个新组件——FSA（少样本锚诱导器）、CAC（组合锚认证器）、SHP（阴影晋升协议）、ECL（证据校准阶梯）、CCAT（证书保守自适应调谐器）、PEG（持续激励守卫）——一律以**中立元接入 v17 语言层之下/之侧**，失效即严格退回 v17（引理 143），再沿 v17→v16→…→v8 退化链退回。本轮只做三件事：把"少样本学习"改写为**表征层的锚诱导**、把"新锚信任"改写为**闭包证书 + 阴影晋升**、把"自适应控制"改写为**安全包络内的保守调谐**。

## 0. 直觉与动机

**灵感 1（少样本学习 → 不是学会新动作，而是学会新说法）**
直觉：v17 中语言层最常见的失败不是"幻觉"，而是 **⊥ 落空**——用户说"把马克杯放到沥水架上"，而锚集里只有"杯子""架子"，S2C 投影失败，整计划回退 v16，活性骤降（v17 风险 7）。少样本学习要解决的正是这个：给 k 个演示，让系统"认识"新词、新组合、新参数。关键反直觉点：**我们故意不允许少样本学习创造新的可执行动作**。新锚的语义原型 μ_new 只能是被认证锚原型 μ_n 的加权凸组合，其参数域只能是被认证参数域的凸包与投影——**新锚只是给"已有动作"起了一个新名字**。于是少样本学习扩大的是 `Anchors`（表征/分辨率），不是 `Exec`（授权）：它把 ⊥ 变成命中、把活性找回来，但每一次命中仍指向一个 v17 早已认证的节点。总括为一句：**学习扩展表征，不扩展授权**。

**灵感 2（少样本的边界 → 新锚必须先"影子"再"转正"）**
直觉：即便新锚是组合，它也可能在真实分布边角更脆——原节点各自在标称域内被认证，新锚把多个节点域拼起来，拼接处（又是缝！）的暂态可能未被校准覆盖。核心创新：**组合锚认证器（Compositional Anchor Certifier, CAC）+ 阴影晋升协议（Shadow Promotion Protocol, SHP）+ 证据校准阶梯（Evidence-Calibrated Ladder, ECL）**。CAC 要求新锚的每个可达参数都落在既有认证闭包 `Cl(Anchors)` 内，并构造性地签发合成证书 `NC^syn`（首节点 Pre、末节点 Post、中间用 v17 的 SC 串联）；包含性失败则**连影子层都进不去**。SHP 把通过者放进**影子层**：安全余量收紧 ρ 倍、TTL 缩短、无任何覆盖权，先实跑 N 次；ECL 用 Clopper–Pearson 下界 `LCB_k` 决定是否转正。反直觉点：**转正与否只影响"敢不敢用"，不影响"能不能安全用"**——安全已由 CAC 的闭包证明买断；证据只决定活性预算。若一个"看起来新"的锚其实越出闭包，它根本不会被授权，而不是"先用了再说"。

**灵感 3（自适应控制 → 只许减少保守，不许增加授权）**
直觉：v17 的三重求交（节点 NC ∩ 缝 SC ∩ 语义共形）非常保守，常把通过率压到接近零、系统长期退回 v16 默认（v17 风险 11）。直觉上想"把 τ_compile 放宽、margin_sc 降点、α 调大点"，但阈值一放宽就可能越过安全边界。核心创新：**证书保守自适应调谐器（Certificate-Conservative Adaptive Tuner, CCAT）+ 安全包络 E_safe + 持续激励守卫（Persistent Excitation Guard, PEG）**。CCAT 只在一个**先验安全包络**内调参；E_safe 的定义就是"任何 θ∈E_safe 的接受域都不超出 v17 的证书边界，且每个安全相关余量不低于 v17 下限"。于是**自适应动力学本身与安全无关**——无论调参怎么抖、对手怎么诱导，只要 θ_t∈E_safe，执行集仍是 v17 的子集。PEG 借自适应控制的经典"持续激励"条件：用校准流协方差最小特征值检测激励是否充分，不足即冻结 θ、切回 v17 阈值。反直觉点：**自适应控制的正确目标不是"更激进地探索"，而是"在不越过安全边界的前提下，把保守余量花在刀刃上"**；它不是让系统变强，而是让系统"少无谓地退回 v16"。

**三者如何统一**
v17 回答"哪些语言计划能被安全编译与调度"（`Exec_v17`）；v18 回答"如何用极少演示与在线观测，**在不改变授权边界的前提下**，提高语言→证书映射的分辨率与活性"（`Exec_v18 ⊆ Exec_v17`、`Live_v18 ⊇ Live_v17`）。FSA 提表征，CAC 给闭包证书，SHP/ECL 管信任的时序，CCAT/PEG 管阈值的时序。共享状态 `ζ_fs=(draft_anchors, shadow_pool, evidence, k_fs, θ_promo)`、`ζ_ac=(θ_t, E_safe, Φ, PE_window)`。**FSA 回答"新词能叫什么名字"，CAC 回答"这个名字指向的动作是否仍在闭包内"，SHP/ECL 回答"这个新名字现在敢不敢多用"，CCAT/PEG 回答"阈值这一帧该收还是该放、放的时候有没有持续激励"**。四问全部只作用于"提议/表征/容差"，从不作用于"证书本身"。

## 1. 研究问题（轮次升级版）

- **Q1（少样本锚的包含性）**：如何定义 FSA 的 induce 使"演示只能被解释为已认证锚的组合"？凸组合原型与凸包参数域在多大程度上是充分的？高维下 CAC 的包含性检查是采样近似还是符号/区间证明？边界演示（最有价值也最危险）如何不靠外推通过？

- **Q3（安全包络与自适应动力学）**：E_safe 如何做到"接受域 ⊆ v17 证书边界"且仍能提高活性？哪些旋钮是"安全旋钮"（只许更保守）、哪些是"活性旋钮"（可在包络内双向）？势函数 Φ 如何构造才能在无模型下仍保证非增？PEG 的 ε_PE 如何标定？
- **Q4（学习×自适应的联合稳定性）**：FSA 与 CCAT 同时在线时，新增表征会不会改变校准流分布、从而破坏 PEG 的激励判据与 HCG 的可交换性？如何证明"两个各自单调的算子，其复合不产生越界放大"？

## 2. 设计原则（在 P28–P30 基础上新增 P31–P33）

**P31 表征可扩、授权不可扩律（Learning Expands Representation, Never Authority）**
新锚的每个可达动作必须落在既有认证闭包内：`∀a∈Anchors_new, ∀x: Actions(a,x) ⊆ Cl(Anchors_v17)`。原型 `μ_new` 只能是认证原型的凸组合，参数域只能取认证域的凸包/投影；**新锚不得引入新的节点族、不得修改任何 NC/SC、不得改变 HCG 分位数或 PSV 余量下限**。少样本学习只允许把 ⊥ 变命中，不允许把"不可执行"变"可执行"。

**P32 阴影先于信任律（Shadow Before Trust）**
任何新锚在获得常规执行权前，必须先进入影子层：安全余量 `ρ·margin_v17`（ρ≤1）、TTL 缩短、无覆盖权、无仲裁优先权。晋升条件为 `LCB_k ≥ θ_promo ∧ 影子期违规数 = 0`；一次缝违规即 `QUARANTINE`。**晋升/隔离只改变活性，不改变安全**（安全由 P31 的闭包证书负责）。

**P33 包络自适应律（Adapt Inside the Safe Envelope, Freeze on Excitation Loss）**
自适应阈值 `θ_t` 必须始终落在先验安全包络 `E_safe` 内；安全相关旋钮（`α`、`margin_sc`）只许更保守（`α≤α_v17`、`margin_sc≥margin_v17`），活性相关旋钮（`τ_compile`、`TTL`、`ρ`）可在包络内双向但受语义风险预算 `τ_max` 约束。每次更新必须被投影回 E_safe 且势函数 `Φ` 非增；PEG 检测到持续激励不足即冻结 θ 并切回 v17 阈值。**自适应不得新增任何接受项、不得放宽任何安全余量**。

## 3. 与基线的接口（如何退化）

- FSA 失效（演示不足 k_min / 投影失败）⇒ 不产生新锚，⊥ 照旧回退——**等价 v17**；
- CAC 失效（包含性检查不可用）⇒ 所有 draft 拒绝，锚集不扩——**等价 v17（活性下降）**；
- SHP/ECL 失效（证据日志损坏）⇒ 全部新锚停在影子层（或直接丢弃）——**等价 v17（新词不转正）**；
- CCAT 失效 ⇒ 阈值冻结在 v17 默认——**等价 v17**；
- PEG 失效 ⇒ 判定为激励不足，冻结并切 v17 阈值——**等价 v17（保守）**；
- 六者全失效 ⇒ MetricVoiceGauge-NCD-HUTDH-v17，再沿 v17→v16→…→v8 退化链退回；
- **安全继承**：FSA 只扩表征、CAC 只签闭包证书、SHP 只收紧余量、ECL 只决定活性、CCAT 只在包络内投影、PEG 只冻结。六端口互不相交，均不能新增授权或放宽安全边界；`Exec_v18(t) ⊆ Exec_v17` 对所有 t 与所有学习/自适应轨迹由引理 143/145 保证。

## 4. 预期贡献

1. **少样本=表征诱导而非能力扩张**：首次把"少样本学习进机器人"改写为"向认证闭包内插值"，证明新词可以提升活性而授权基数恒增量为零，正面修补 v17 风险 7；
2. **组合锚闭包证书**：给出 `NC^syn` 的构造式定义（首 Pre、末 Post、中间 SC 串联）与 CAC 包含性判据，使"新锚安全"成为可检查的静态性质而非经验观察；
3. **阴影晋升 + 证据下界**：把"要不要相信新锚"降格为纯活性决策，安全与统计彻底解耦；给出 k 极小时的转正门槛；
4. **包络式自适应控制**：把"阈值该放还是该收"改写为 E_safe 内带势函数下降的投影调谐，证明自适应轨迹不影响执行集，正面修补 v17 风险 11 的过度保守；
5. **持续激励门控**：把自适应控制的经典可辨识性条件移植为"校准流必须持续激励"，使漂移下自动冻结而非盲目调参；
6. **学习×自适应无反馈放大**：证明两个各自非扩张的算子复合后仍非扩张，用 `Exec_v18 ⊆ Exec_v17` 把语言、学习、自适应三层与安全层彻底解耦；E711–E730 覆盖锚诱导精度、包含性、影子晋升、包络调谐、激励冻结、联合稳定性、端到端与消融。

## 5. 本轮最大风险

**一句话**：整套安全性挂在"CAC 能证明新锚落在认证闭包内"与"CCAT 能把 θ 投进 E_safe"这两条**外推**上——但少样本学习最有价值的场景恰恰是演示落在闭包边界（"新"就是"接近越界"），此时凸包包含性检查与高维采样近似最不可靠；一旦"边界演示"被 CAC 误判为包含、同时 CCAT 把活性旋钮推到包络边缘，两个各自单调的外推相乘，可能把一个事实上越界的新锚送进影子层并最终转正，而全程每一步都"看起来满足单调性"。

## 1. 关键算法骨架

```python
# IP-415 Few-Shot Anchor Inducer：演示→表征锚（绝不新增动作）
class FewShotAnchorInducer:
    def __init__(self, anchors, s2c, min_demos=1, tau_max=None):
        self.anchors = anchors          # v17 认证锚集 [(n, mu, NC, m, h, Theta)]
        self.s2c = s2c
        self.min_demos = min_demos
        self.tau_max = tau_max

    def induce(self, demos, x, m_star, h_star):
        if len(demos) < self.min_demos:
            return []                   # 证据不足：不诱导，⊥ 照旧回退
        compiled = []
        for d in demos:
            nodes = self.s2c.compile_plan(d.plan, x, m_star, h_star)
            if nodes is None:
                return []               # 任一演示无法投影 ⇒ 放弃（不硬凑）
            compiled.append(nodes)
        # 原型：只做认证锚的凸组合 —— 新锚只是"已有动作的新名字"
        proto, w = [], []
        for d, seq in zip(demos, compiled):
            for n in seq:
                proto.append(self.anchors[n].mu)
                w.append(d.weight)
        mu_new = weighted_convex_combine(proto, w)
        # 参数域：认证域的凸包；若不可定义则放弃
        dom = convex_hull_of_certified_domains(
            [self.anchors[n].Theta for seq in compiled for n in seq])
        if dom is None:
            return []
        return [DraftAnchor(mu=mu_new, dom=dom, provenance=compiled,
                            k=len(demos))]


# IP-416 Compositional Anchor Certifier：闭包包含性 + 合成证书
class CompositionalAnchorCertifier:
    def __init__(self, anchors, psv, margin_v17, B_contain=4096):
        self.anchors, self.psv = anchors, psv
        self.margin_v17, self.B = margin_v17, B_contain

    def contain(self, draft):
        # 只需在参数域上验证"任意可达参数都指向认证节点域"
        for theta in boundary_samples(draft.dom, budget=self.B):
            n = project_to_certified(self.anchors, theta)
            if n is None:
                return False, None      # 越出闭包 ⇒ 连影子都进不去
        cert = self.synthesize_nc(draft)
        return (cert is not None), cert

    def synthesize_nc(self, draft):
        # 首节点 Pre + 末节点 Post + 中间缝 SC 串联（复用 v17 的 PC/PSV）
        head = draft.provenance[0][0]
        tail = draft.provenance[-1][-1]
        seams = []
        for seq in draft.provenance:
            for i in range(len(seq) - 1):
                sc = self.psv.seam(seq[i], seq[i + 1])
                if sc is None or sc.volume() < self.margin_v17:
                    return None
                seams.append(sc)
        return SynthNC(Pre=self.anchors[head].Pre,
                       Post=self.anchors[tail].Post,
                       Run=Composition(draft.provenance),
                       Fallback=self.anchors[head].Fallback,
                       seams=seams)


# IP-417/418 Shadow Promotion Protocol + Evidence-Calibrated Ladder
class ShadowPromotionProtocol:
    def __init__(self, margin_v17, rho=0.5, short_ttl=1.0,
                 delta=0.1, theta_promo=0.95):
        self.margin_v17, self.rho, self.short_ttl = margin_v17, rho, short_ttl
        self.delta, self.theta_promo = delta, theta_promo

    def enter(self, anchor, cert):
        anchor.NC = cert               # 闭包证书：安全已买断
        anchor.tier = 'SHADOW'
        anchor.margin = self.rho * self.margin_v17   # 更紧，不是更松
        anchor.ttl = self.short_ttl
        anchor.evidence = []

    def record(self, anchor, outcome, violated_seam=False):
        if violated_seam:
            anchor.tier = 'QUARANTINE' # 一次缝违规即隔离
            return
        anchor.evidence.append(outcome)

    def maybe_promote(self, anchor):
        if anchor.tier != 'SHADOW':
            return anchor.tier
        lcb = clopper_pearson_lcb(anchor.evidence, self.delta)
        if lcb >= self.theta_promo:
            anchor.tier = 'FULL'
            anchor.margin = self.margin_v17   # 余量永远回落 v17 下限
        return anchor.tier


# IP-419/420 Certificate-Conservative Adaptive Tuner + Persistent Excitation Guard
class CertificateConservativeAdaptiveTuner:
    def __init__(self, env, alpha_v17, margin_v17, eta=0.05, eps=1e-3):
        self.env, self.eta, self.eps = env, eta, eps
        self.alpha_v17, self.margin_v17 = alpha_v17, margin_v17

    def project(self, theta):
        return Thresholds(
            alpha=min(theta.alpha, self.alpha_v17),          # 安全旋钮只许更严
            margin_sc=max(theta.margin_sc, self.margin_v17), # 安全旋钮只许更大
            tau_compile=min(theta.tau_compile, self.env.tau_max),  # 活性旋钮受预算
            ttl=clip(theta.ttl, *self.env.ttl_range),        # 活性旋钮
            rho=min(theta.rho, 1.0))                         # 余量收紧系数

    def step(self, theta, grad, potential):
        cand = self.project(sub(theta, mul(self.eta, grad)))
        if potential(cand) > potential(theta) + self.eps:
            return theta, 'REJECT'    # 势函数不降 ⇒ 拒绝本步
        return cand, 'STEP'


class PersistentExcitationGuard:
    def __init__(self, eps_PE, window):
        self.eps_PE, self.window = eps_PE, window

    def gate(self, theta, calib, tuner, theta_v17, potential):
        if lambda_min(cov(calib[-self.window:])) < self.eps_PE:
            return theta_v17, None, 'FROZEN'   # 激励不足：冻结 + 回 v17
        cand, mode = tuner.step(theta, grad(theta, calib), potential)
        return cand, potential, mode
```

## 3. 推导

**引理 143（少样本锚的表征性安全）** 若 FSA 的原型仅为认证锚原型的凸组合、参数域仅为认证参数域的凸包/投影，且 CAC 要求 `Contain(a)`，则对任意演示集（含对抗演示），`Actions(a) ⊆ Cl(Anchors_v17)`，故 `Exec_v18 ⊆ Exec_v17`；语言层新增授权基数 `|NewAuth| = 0`。证明：FSA 的值域是"原型 + 参数域"，不含节点族；S2C 编译结果恒为某个认证节点 `n∈Anchors_v17` 与参数 `θ∈Θ_n`，故任一执行动作都是 v17 已有动作（或其组合，由 v17 引理 139 的 PC 覆盖）。CAC 的 `Contain` 进一步排除越出闭包的参数；S2C 的 `compile(t)∈Anchors∪{⊥}`（v17 P28）与 APS 的整体替换（v17 P30）原样保留。因此新锚只改变"哪个 token 命中哪个既有节点"，不改变可达动作集。∎ 推论：**新锚的全部价值体现在 `⊥→命中`，即 `Live_v18 ⊇ Live_v17`，而 `Exec` 严格不扩**。

**引理 144（阴影晋升只影响活性）** 若所有新锚在执行前都满足 `Contain(a)` 并持有 `NC^syn`，则 SHP 的 `enter/record/maybe_promote` 只改变锚的可用频次与 TTL，不改变 `Exec_v18`；晋升规则 `Push` 的真实性只影响"新锚被使用的概率"。证明：影子层对安全的作用仅为两类——(a) 余量收紧 `ρ·margin_v17 ≤ margin_v17`，只会使缝接受更严；(b) TTL 缩短，只会更早前缀截断。二者都是 v17 执行集的子集操作（引理 140 单调）。晋升把余量恢复到 v17 下限、把 TTL 恢复为常规值，仍不超出引理 143 的闭包边界。`QUARANTINE` 是进一步移除。故 SHP 全程在 `Exec_v18` 的同一安全边界内移动活性坐标。∎ 推论：**证据不足的最坏后果是新词始终停在影子层（活性损失），绝不是不安全**。

**引理 145（包络自适应的保守性）** 设 `E_safe` 满足：`∀θ∈E_safe: α≤α_v17 ∧ margin_sc≥margin_v17 ∧ τ_compile≤τ_max`，且 CCAT 每步都投影回 `E_safe`，则对任意自适应轨迹 `{θ_t}`（含对抗梯度），`Exec_v18(t) ⊆ Exec_v17` 对所有 t 成立，与 Φ 的收敛性无关。证明：接受域对 `α` 与 `margin_sc` 单调——`α` 越小、共形接受越严；`margin_sc` 越大、缝接受越严；`τ_compile` 只改变"哪些 token 命中"，而任一命中都在 `Anchors_v17` 内（引理 143），较大的 `τ_compile` 至多把更多本就认证的节点纳入候选，不新增动作。TTL 与 ρ 只影响前缀截断时机与余量收紧，均为子集操作。因此每个 t 的决策都落在 v17 证书边界内；自适应动力学本身不进入安全证明。∎ 推论：**自适应不是"让系统更强"，而是"让系统在安全边界内少退回 v16"；即使 Φ 估计错误、调参震荡，安全也不受影响**。

**引理 146（持续激励失配的冻结安全）** 若 PEG 在 `PE(W)` 失败时令 `θ := θ_v17` 并停止更新，则此后 `Exec_v18(t) = Exec_v17`；且在恢复激励前，自适应带来的活性增益为零。证明：冻结即常数 `θ_v17∈E_safe`；由引理 145 得 `Exec_v18(t)⊆Exec_v17`；又 v17 路径原样保留，故等号成立。活跃性方面，冻结取消 `τ_compile` 等活性旋钮的放宽，只保留 v17 的 ⊥ 行为，故增量增益为 0。∎ 推论：**漂移下系统自动降级为"冻结的 v17"，而不是"盲目调参的 v18"**。

**引理 147（学习×自适应无反馈放大）** 记 `T = CCAT ∘ SHP ∘ CAC ∘ FSA`。若 FSA/CAC/SHP 不改变 `Exec`（引理 143/144）、CCAT 不改变 `Exec`（引理 145），则 `T` 在 `Exec` 坐标上是恒等映射，在活性坐标上是非扩张的正则算子，故对任意交替/并发轨迹 `{T^t}`，`Exec_v18(t) = Exec_v17`，且不存在"学习改变校准分布 → 自适应误判 → 学习再放大"的正反馈越界。证明：`Exec` 坐标上每个算子都是恒等（或子集），复合仍为恒等（子集）；活性坐标上 FSA 只增加候选、SHP 只收紧、CCAT 只做包络内投影、PEG 只冻结，均不放大证书边界。即使 FSA 改变校准流分布，PEG 的激励判据会先触发冻结（引理 146），切断反馈路径。故无放大。∎ 推论：**两个各自单调的机制不会因复合而越界——因为它们的单调方向都在"活性"上，而"安全"坐标被钉死**。

**引理 148（极小样本的证据-活性边界）** 设影子期证据 i.i.d.、成功概率 p，则 `LCB_k` 由 Clopper–Pearson 给出；若 `k < k_min(δ, θ_promo) := ⌈ln(1/δ) / (1−θ_promo)⌉`（Hoeffding 近似），则 `Push(a)` 不可满足，新锚无法转正，`Live_v18` 不因该锚增加。证明：Hoeffding 下界 `LCB_k ≤ p̂ − sqrt(ln(1/δ)/(2k))`；要 `LCB_k ≥ θ_promo` 至少需 `sqrt(ln(1/δ)/(2k)) ≤ 1−θ_promo`，即 `k ≥ ln(1/δ)/(2(1−θ_promo)^2)`；取保守的 `⌈ln(1/δ)/(1−θ_promo)⌉` 即得。故 k 极小时晋升不可能，锚只能留在影子层或丢弃。∎ 推论：**"少样本"能买到的只是"更少 ⊥"，买不到"更强授权"；转正所需的额外证据是显式的、可预算的**。

## 7. 已知风险与失效模式

1. **凸包包含性只是充分非必要**：真实可达域未必是凸的，凸包会把"越界"的缝隙一起包进来。缓解：以区间/符号证明替代采样、按证书族独立凸包、边界演示强制人工复核。
2. **高维采样近似漏检**：CAC 的 `boundary_samples` 有限，可能漏掉测度极小的越界方向。缓解：对抗采样、区间算术、保守增大 B、把包含性检查降级为"仅允许单节点"。
3. **极小样本证据不可靠**：LCB_k 在 k=1–5 时极宽，晋升几乎不可能，活性回升慢。缓解：先验/层次贝叶斯、跨任务迁移证据、保守 θ_promo 配合更长影子期。
4. **漂移破坏 HCG 可交换性**：学习/自适应改变输入分布，共形分位数失效。缓解：滑动窗重校准、PEG 冻结时同步冻结 HCG、把学习触发与重校准解耦。
5. **势函数 Φ 的模型误差**：Φ 估计错误会使 CCAT 朝错误方向调参（虽不出包络，但可能降低活性）。缓解：多模型集成、保守 ε、设置安全旋钮硬边界。
6. **活性旋钮的语义风险**：放宽 `τ_compile` 不损害安全，却可能把"推"投影成"戳"（语义错、证书对）。缓解：语义风险预算 τ_max、以证书族为对比的嵌入微调、任务成功率监控。
7. **学习触发被对手利用**：对手可制造大量 ⊥ 迫使系统学习、消耗算力或诱导边界锚。缓解：学习频率上限、演示来源认证、对抗演示过滤、学习预算。
8. **新锚与 BT 热更新交互**：热更新使 `NC^syn` 的来源节点失效。缓解：锚携带节点版本号、版本不符整体失效、热更新仅在无新锚窗执行。
9. **影子层的统计污染**：影子执行本身改变分布，使后续证据不再 i.i.d.。缓解：影子预算隔离、按上下文分层证据、置换检验。
10. **PEG 的 ε_PE 标定困难**：过大导致永不自适应、过小导致漂移下仍调参。缓解：离线标定 + 在线分位监控、双阈值迟滞。
11. **合成宏锚的证书膨胀**：长宏锚把多段 SC 串起来，任何一个缝失败都会整段失效，活性反而下降。缓解：宏锚长度上限、失败局部降级、宏锚复用 v17 前缀截断。
12. **过度保守的回退螺旋**：CAC 拒绝率高 + PEG 频繁冻结 → 长期等价 v17，学习/自适应投入白费。缓解：活性监视报警、保守包络放宽的离线再认证、分阶段启用。

## 8. 本轮最大风险

**一句话**：整套安全性挂在"CAC 能证明新锚落在认证闭包内"与"CCAT 能把 θ 投进 E_safe"这两条**外推**上——但少样本学习最有价值的场景恰恰是演示落在闭包边界（"新"就是"接近越界"），此时凸包包含性检查与高维采样近似最不可靠；一旦"边界演示"被 CAC 误判为包含、同时 CCAT 把活性旋钮推到包络边缘，两个各自单调的外推相乘，可能把一个事实上越界的新锚送进影子层并最终转正，而全程每一步都"看起来满足单调性"。
