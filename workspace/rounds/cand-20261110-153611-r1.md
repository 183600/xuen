# 第 46 轮（承接第 45 轮 v10；本轮灵感：并发推理 × 传感器融合） · Concurrent-Fusion-Cert：并发异构推理束 × 融合感知证书 × 跨模态证伪（四层架构 v11）

> 承接第 45 轮 v10 Energy-Context-Depth。v10 用能量租约与上下文预测驱动深度门控，但两条根假设从未被打开：**H5a 上下文只有一个推理器**——单点预测一旦出错就会静默关掉深度（v10 自陈的最大风险），系统没有任何独立通道去证伪它；**H5b 融合只等于降噪**——把 RGB/双目/深度当成独立信息源去投票或求交，忽略了它们共享共因失效（同一束强光、同一红外干扰、同一镜头污渍、同一标定漂移会同时污染所有相机），使"多模态证书求交"在相关性下并不 sound。两个灵感词精确命中：**并发推理**把单点预测升级为 K 个异构推理头并行给出的假设束，让分歧本身成为可观测的认知不确定性证据，而非被 softmax 平均成虚假自信；**传感器融合**把模态集升级为带融合图 F、共因载荷 a、相关性 ρ 的融合算子，并给出一条硬结论——融合增益有**共同因地板**，永远不能把共同因误差平均掉。二者耦合出新问题：**并发推理头并不独立（共享骨干/训练分布 → 可能"一致地错"），融合证书必须有相关性感知的半径膨胀，且必须用与推理头正交的跨模态残差去证伪上下文主张；如何在这种"一致但错"与"共同因失效"的双重威胁下签发 sound 的并发-融合联合证书，否则 fail-closed**。

## 0. 直觉与动机

**灵感 1（并发推理 → 假设束与"分歧即证据"）**
直觉：与其赌一个预测，不如让几个"性格不同"的推理头同时猜：一个看 VLM 语义、一个看时序运动、一个看几何一致性、一个看历史任务先验。它们一致时认知不确定性低；它们分歧时，分歧幅度本身就是"我现在不知道"的度量，应该触发保守或加采样，而不是被平均成一个看似自信的分布。这把 v10 的 think→act 单线流程改成 speculate→verify 的并行流程。

**灵感 2（传感器融合 → 共同因地板与相关性感知证书）**
直觉：融合不是免费的降噪。若所有相机被同一束强光打爆，求平均/求交只会把同一个错误复制 n 遍。用单因子共因模型把误差拆成"共享潜变量 a_i·u_0 + 各自独立 ε_i"：独立部分按 1/√n 抵消，但共享部分在加权融合后**原样穿过**（权重归一后仍等于 u_0）。于是存在**共同因地板** r_F ≥ σ_0，相关性 ρ 越高地板越高；证书半径绝不能降到地板以下，否则就是"表面更窄、实则更假"。

**灵感 3（二者耦合 → 正交证伪，而非投票）**
直觉：真正救命的不是"几个头都同意"，而是"有一个和推理头不共享失效模式的通道不同意"。跨模态残差（RGB 光度重投影 vs 双目/深度几何残差）恰是这种正交证据：它不依赖语言先验，只依赖物理一致性。于是架构变为：K 个推理头各自提出 (假设, 融合配置)，证伪器对当选假设做物理一致性检验，只有"证据多样性足够 + 残差通过 + 能量可行"才签发证书。

**架构升级**：v11 在 v10 上新增横切的**并发-融合认证面 CFC**。根信任层增加证据多样性契约与共因失效表；L1 几何层输出融合配置条件化半径 r_ω(F;ρ)；L2 上下文层由单预测器升级为并发推理束；L3 CAR 守卫增加共识与证伪检查；L4 DCL 采集加入"共因注入样本"与"高分歧样本"两类主动采集；ECPS 的调度对象从单模态升级为 (推理头, 融合配置) 二元组。

## 1. 形式化定义（增量：定义 54–58）

**定义 54（并发异构推理束）**
K 个推理头 R_k:(c_t, 历史, m)→Cat(θ_k(ω))，各自给出假设分布与自报置信；假设 c_t^{(k)}=argmax_ω P_k。束证书 {J_t^{(k)}}。
分歧度 D_t = max_{i,j} d_TV(P_i, P_j)（两两总变差直径）。
**并发语义**：廉价头每周期并行，昂贵头由触发（D_t 高或租约将过期或上次证伪失败）拉起，构成 speculate-then-verify 的分层并发。

**定义 55（单因子共因融合模型与共同因地板）**
模态 i 的误差 e_i = a_i u_0 + ε_i，u_0~N(0,σ_0²) 为共享共因（强光/红外/污渍/标定漂移），ε_i~N(0,σ_i²) 相互独立，载荷 a_i∈[0,1]。最优线性融合
e_F = (Σ_i a_i/σ_i²)^{-1} Σ_i (a_i u_0 + ε_i)/σ_i² = u_0 + ε_F，
即共享分量不衰减地穿过融合。故
r_ω(F;ρ) ≥ σ_0(ω) ≡ r_common(ω)，且 r_ω(F;ρ) ≈ sqrt( σ_0² + (Σ_{i∈F} 1/σ_i²)^{-1} )。
**推论（融合增益饱和）**：σ_0 越大，继续增加模态的边际半径缩减越接近 0。

**定义 56（融合感知分层半径与共因失效表）**
共因失效模式集 Φ={强光, 红外干扰, 运动模糊, 镜头污渍, 标定漂移}，模态 m 的失效覆盖 C_m⊆Φ。
分层共形半径 r_ω(F,φ) 按 (ω, 融合配置 F, 共因模式 φ) 分别校准；部署半径取
r_ω(F)=max_{φ∈C_active} r_ω(F,φ)（按当前生效共因模式取最坏）。
证书求交/融合必须用上式，禁止使用独立性假设下的 r_indep。

**定义 57（证据多样性与有效头数）**
头对相似度 s_{ij}∈[0,1]（共享骨干/训练集/提示模板 + 审计集上残差相关）。有效头数
K_eff=(Σ_i w_i)² / (Σ_{i,j} w_i w_j s_{ij})。
**多样性契约**：K_eff≥K_min 且 min_{i≠j} s_{ij}≤s_max，且至少存在一个头与其余头在信息源/共因上不共享。仅"投票一致"不构成证据。

**定义 58（并发-融合共识证书与 soundness）**
共识谓词 Cons_t = (D_t≤τ_agree) ∧ (K_eff≥K_min) ∧ (Verify_t≤τ_verify) ∧ EnergyOK。
当选证书取兼容头证书的**交集** P_t^∩=∩_{k∈K_agree}P_t^{(k)}；若 D_t>τ_agree 则取并集凸包 P_t^∪（保守外扩）。
**soundness 声明**：若每头在融合感知校准下覆盖 ≥1-α_k，且正交证伪器假接受率 ≤β，则
P(truth∈P_t^∩ ∧ 未误关深度) ≥ 1 - Σ_k α_k - β，仅在 Cons_t 为真时成立；否则级联 fail-closed。

## 2. 新增产出与既有 IP 升级

**IP-66 CFE（Concurrent Fusion Engine，并发融合推理引擎）**
- 分层并发调度：廉价头（几何一致性、运动学先验）每周期；昂贵头（VLM、长程规划）触发式拉起
- 每个头携带融合配置 F_k（信任哪些传感器、各自预估 σ_i 与共因载荷 a_i）
- 分歧监控 D_t、有效头数 K_eff、触发拉起与算力预算回收
- 能量感知：并发额外算力计入 v10 的 ℓ_e，超预算即降级为单头并触发保守证书

**IP-67 FUSION-CERT ADAPTER（融合证书适配器）**
- 单因子共因在线估计：从多模态残差估计 u_0、a_i、σ_i
- 共因失效表与最坏模式半径 r_ω(F,φ)
- 共同因地板检查：拒绝任何低于 r_common 的"虚假收窄"
- 相关性 ρ 接入 v10 IP-64，替换其隐含的独立性假设

**IP-68 CROSS-MODAL VERIFIER（跨模态证伪器）**
- 光度-几何一致性残差：RGB 重投影 vs 双目/深度几何
- 上下文主张证伪：若头声称"无退化"但残差跳变 → 否决
- 独立性守卫：证伪通道不得与推理头共享骨干/共因，否则标记为无效证伪
- 假接受率 β 在独立审计集上校准并回灌 DCL

**既有 IP 升级**
IP-63 ECPS：调度对象由模态 m 升级为 (头 k, 配置 F_k)，效用含并发算力与共因风险
IP-64 DEPTH-CERT ADAPTER：半径查表改为 r_ω(F;ρ)，含共同因地板
IP-65 CONTEXT PREDICTOR：由单预测器降为并发推理束中的一员，保留其分层校准
IP-62 CCA：新增证据多样性审计、共因注入红队、agreement-but-wrong 测试
IP-61 DCL：新增高分歧样本、共因注入样本采集；护照记录 head/fusion-config
IP-51 CAR：守卫增加 Cons_t 与证伪检查，失败即 fail-closed
IP-45 总线：新增 hypothesis-ensemble / fusion-config / disagreement / verification-residual 话题

## 3. 算法骨架

CFC 每控制周期：
1. 并行跑廉价头，得 {P_k}、D_t、K_eff
2. 若 D_t>τ_agree 或租约将过期或上次证伪失败 → 拉起昂贵头，重算束
3. 对每头估计共因 (u_0,a_i,σ_i)，算 r_ω(F_k;ρ)（含共同因地板）
4. 跨模态证伪器对当选/少数假设做物理一致性检验，得 Verify_t
5. 若 Cons_t 为真：取交集证书，交 ECPS 做能量可行性校验
6. 否则：取并集凸包（保守）或直接 fail-closed；把高分歧样本写入 DCL

## 4. 本轮最大风险

**一句话**：并发推理头因共享骨干/训练分布/传感器共因而高度相关，极可能在错误时"一致地同意"（agreement-but-wrong），此时交集证书看似更窄更自信，实则在共因失效（如同时打爆 RGB 与深度的强光）下静默失效；因此必须强制证据多样性契约（K_eff、非共享证伪通道）、注入共因红队、并用共同因地板拒绝虚假收窄，否则默认 fail-closed。

## 2. 关键算法 伪代码

### IP-66 CFE
```
def concurrent_step(c_t, hist, t, lease_e):
    heads = cheap_heads()
    if trigger(D_prev, t, verify_prev):
        heads += expensive_heads(t)          # speculate-then-verify
    dists = {k: R_k.prob(c_t, hist) for k in heads}
    D = max_tv(dists)
    K_eff = effective_heads(heads)           # 由 s_ij 计算
    F = {k: R_k.fusion_config() for k in heads}   # 每头信任的传感器子集+σ,a
    return dists, D, K_eff, F

def trigger(D_prev, t, verify_prev):
    return D_prev > tau_agree or lease_expiring(t) or verify_prev > tau_verify

def effective_heads(heads):
    num = sum(w[k] for k in heads) ** 2
    den = sum(w[i]*w[j]*S[i][j] for i in heads for j in heads)
    return num / max(den, EPS)
```

### IP-67 Fusion-Cert Adapter
```
def estimate_common_cause(residuals):
    # residuals_i = a_i*u0 + eps_i  -> 单因子分析（rank-1 因子）
    u0, a, sig = factor_analysis(residuals, rank=1)
    return CommonCause(sigma0=std(u0), load=a, sig=sig)

def fusion_radius(omega, F, common, active_failures, calib):
    sig0 = common.sigma0[omega]
    idio = 1.0 / sum(1.0 / common.sig[omega][i]**2 for i in F)
    r = sqrt(sig0**2 + idio)
    r = max(r, sig0)                         # 共同因地板：禁止被融合收窄
    for phi in active_failures:              # 共因失效表取最坏
        r = max(r, calib.r[omega][F][phi])
    return r

def reject_false_narrowing(r_reported, r_common):
    return r_reported < r_common - EPS        # 低于地板即判为虚假收窄
```

def cross_modal_residual(rgb, stereo, depth):
    photo = photometric_reproj_residual(rgb, depth)   # 光度通道
    geom  = stereo_geometric_residual(stereo, depth)  # 几何通道

def cross_modal_verify(claim, res, calib):
    if shares_common_cause(verifier, claim.head):
        return Verdict.INVALID               # 非正交证伪，不构成证据
    if res <= calib.tau_verify:
        return Verdict.PASS
    return Verdict.REJECT                    # 上下文主张被物理证伪

### IP-58 并发-融合共识证书
```
def cfc_certify(dists, D, K_eff, F, res, lease_e, t):
    if K_eff < K_min:
        return FailClosed('diversity')       # 同质头不构成证据
    if not energy_lease_valid(lease_e, t, E_min):
        return FailClosed('energy')
    claim = argmax(dists)
    ver = cross_modal_verify(claim, res, calib)
    if ver == Verdict.INVALID:
        return FailClosed('non_orthogonal_verifier')
    if D <= tau_agree and ver == Verdict.PASS:
        P = intersect([P_k for k in agreed(dists)])
        return Cert(P, alpha=sum(alpha[k] for k in agreed(dists)) + beta,
                    mode='intersection', F=F)
    return Cert(convex_hull(dists), mode='conservative')   # 分歧→外扩，或 FailClosed
```

def car_guard_v7(e, x, cert, persona, lease_p, lease_e, cons, t):
    if not pose_lease_valid(lease_p, t) or not energy_lease_valid(lease_e, t, E_min(e)):
        cascade_invalidate('pose_energy'); return FailClosed()
    if not cons.ok:
        cascade_invalidate('consensus'); return FailClosed()

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CFE 并发束 | O(K·|Ω|) 每周期，昂贵头触发 amortized | O(K·|Ω|) | K_eff≥K_min ⇒ 分歧可解释为认知不确定性 |
| 共因估计 | O(|F|·d_res) rank-1 分解 | O(|F|²) | 单因子模型下 u_0 可辨识 |
| Fusion-Cert Adapter | O(|F|+|Φ|) 查表 | O(|Ω|·|F|·|Φ|) | r≥σ_0 且取最坏失效 ⇒ 相关性下覆盖仍成立 |
| Cross-Modal Verifier | O(1) 残差评估 | O(1) | 正交通道假接受率≤β ⇒ 错误主张漏过概率≤β |
| 共识证书 J_t | O(K) 求交/凸包 | O(K) | 并集界 ⇒ 覆盖≥1-Σα_k-β |
| CAR v7 | O(1) | - | 任一前件失效 ⇒ fail-closed |

**正确性定理（并发-融合 soundness）**：若 (i) 每个头在融合感知校准下满足 P(truth∈P^{(k)} | ω, F_k) ≥ 1-α_k；(ii) 证伪器与推理头不共享共因（正交通道），假接受率 ≤ β；(iii) Cons_t 为真（K_eff≥K_min、D_t≤τ_agree、Verify_t≤τ_verify）；(iv) 能量租约 ℓ_e 与姿态租约 ℓ_p 均有效——则交集证书覆盖真值的概率 ≥ 1 - Σ_k α_k - β，且任何会导致错误关闭深度的上下文主张必须以 ≤β 的概率穿过证伪器；任一前件不成立则级联 fail-closed。

**关键告诫**：该界对 K 个头的 α 求和，故 K 不能无成本滥用；当 K_eff 下降时 Σα_k 与相关失效概率同时上升——这正是"并发越多越安全"幻觉的数学来源。

## 4. 实验设计 E109–E114

| 实验 | 指标 | 门槛 |
|---|---|---|
| E109 分歧-错误前兆 | D_t 预测上下文错误的 AUROC；提前量 | AUROC≥0.85；提前≥200ms |
| E110 融合相关性校准 | 注入共因后覆盖率 vs 独立性基线覆盖缺口 | 覆盖≥1-α；基线缺口≥10% |
| E111 跨模态证伪 | 错误头假接受率降幅；正交通道 vs 共享骨干通道 | 降≥80%；正交通道显著更低 |
| E112 证据多样性 | 同质头 vs 异构头 agreement-but-wrong 率；K_eff 与真实错误相关性 | 降≥3×；正相关显著 |
| E113 并发能量开销 | 分层触发额外功耗；v10 节能保持 | 额外<10%；节能≥20% 保持 |
| E114 100h 共因注入闭环 | 实机安全违例；最坏层覆盖；fail-closed 响应时延 | 0 起；覆盖≥1-α_p；<100ms |

回退：E110 相关性模型失配 → 放弃融合收窄，全部模态按最坏单模态半径；E111 证伪假接受超阈 → 禁用该证伪通道并 fail-closed；E112 多样性不达标 → 冻结并发、回退 v10 单预测器 + 默认开深度；E114 违例 → 回退 v10 无并发融合。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 并发头相关 → agreement-but-wrong | 高 | K_eff 多样性契约 + 异构骨干/信息源 + 共因注入红队 + 独立审计 |
| 共因模型低估 σ_0 → 半径虚假收窄 | 高 | 共同因地板硬约束 + 在线残差监测 + 最坏失效表 + 拒绝 r<r_common |
| 证伪器与推理头共享失效模式 → 假自信 | 高 | 正交通道独立性守卫；一旦检出共享即判 INVALID 并 fail-closed |
| 并发算力/能量与 v10 能量租约冲突 | 中 | 分层触发（廉价常驻、昂贵按需）+ 预算回收 + 超预算降级单头 |
| 昂贵头拉起延迟导致证书空窗 | 中 | 租约冻结窗口 + 廉价头保守维持 + 预热 |
| 一致时交集虽窄但依赖并集界，K 增大反而抬高 Σα | 中 | 限制 K、动态裁剪低多样性头、按 K_eff 调整 α 预算 |

## 6. 本轮最大风险

**一句话**：并发推理头因共享骨干/训练分布/传感器共因而高度相关，极可能在错误时"一致地同意"（agreement-but-wrong），此时交集证书看似更窄更自信，实则在共因失效（如同时打爆 RGB 与深度的强光）下静默失效；因此必须强制证据多样性契约、注入共因红队、并用共同因地板拒绝虚假收窄，否则默认 fail-closed。
