### 第 1 轮灵感驱动研究记录

**灵感词**：语音合成、长程任务

**直觉与动机**：
现有 SRC-USC（v25）把单机物理、语义、重构、协同七证焊成一条单调退化链，但它仍把任务视为「一次性计划」：证书在计划通过的那一刻成立，却回答不了「这条计划在 10 分钟、上千个子目标之后是否仍然成立」。长程任务的核心从来不是单步正确，而是三件事沿时间轴发酵：误差的复利累积、子目标边界处的相位断裂、以及指令意图与执行节奏之间的时长/能量错配。这恰好是语音合成（TTS）每天面对的问题。TTS 把文本 → 音素 → 韵律 → 声学特征 → 波形逐层生成，每一层都必须做三件事：**对齐**（文本与音频的时间对齐、duration model）、**韵律控制**（音高/时长/能量包络，避免机械念经）、**无伪影**（vocoder 不能产生爆音、相位跳变、金属音）。把长程机器人任务看成「把指令『说』成一段可执行的动作波形」，现有证书链缺的正是这三层：指令-子目标对齐证书、长程漂移/伪影证书、分层子目标组合证书。核心洞见：**长程任务的可信执行 = 带证书的具身语音合成；子目标即音素，技能即音节，能量包络即韵律，误差累积即 vocoder 伪影，重规划即换声/拼接。**

**形式化目标**：
1. 定义分层任务谱（Score）：Σ = {(ℓ_k, σ_k, τ_k, e_k)}_{k=1}^{K}，ℓ_k 为指令段、σ_k 为技能 option、τ_k 为分配时长、e_k(t) 为能量/进度韵律包络。
2. 定义韵律-时序对齐证书（PTAC）：对齐代价 c_align(ℓ, σ) ≤ ε_align；时长相对误差 |τ̂_k-τ_k|/τ_k ≤ ε_dur；韵律包络 sup 偏差 ≤ ε_pros 且累计能量 ∫e_k dt ≤ E_max。
3. 定义长程漂移/伪影证书（LHDC）：单步误差 δ_step 与收缩系数 κ<1 推出累积漂移 D_T ≤ κ^T D_0 + δ_step/(1-κ)；状态/速度/力相位连续且 jerk ≤ J_max（无「爆音」）；子目标边界 Post_k ⇒ Pre_{k+1}。
4. 定义组合子目标证书（CSC）：证书在拼接算子 ⊗ 下构成 monoid（单位元、结合律、边界胶合代价 ≤ ε_unit）；子目标贡献（Shapley/advantage）可证非负；重规划前缀证书可传递。
5. 构建 v26 十证准入门：Exec_v26 = Exec_v25 ∩ Fil_align ∩ Fil_drift ∩ Fil_comp ⊆ Exec_v25，并证明长程漂移、边界断裂、重规划失配三类退化路径下的单调保持性。

# ============================================================
# IP-448 Prosodic-Temporal Alignment Certificate (PTAC)
# —— 把 TTS 的 duration model / 文本-音频对齐 / 韵律包络搬到任务层
# ============================================================
@dataclass
class ProsodicTemporalAlignmentCertificate:
    score: list['ScoreSegment']        # Σ = [(ℓ_k, σ_k, τ_k, e_k)]
    actual_durations: Tensor           # [K] 实际/预测执行时长 τ̂_k
    energy_trace: Tensor               # [T] 实际机械功率包络
    progress_trace: Tensor             # [T] 实际进度速率 r(t)
    E_max: float                       # 长程能量预算（继承 EVC/SOC）
    eps_align: float = 0.05            # 归一化对齐代价容差
    eps_dur: float = 0.10              # 时长相对误差容差（10%）
    eps_pros: float = 0.08             # 韵律包络 sup 偏差容差
    embed_fn: Callable = None          # token/技能嵌入

    def verify_alignment(self) -> bool:
        """c_align = min_π Σ A[π] / |π| ≤ ε_align（DTW 或 CTC 前向）"""
        if self.embed_fn is None:
            return False
        tokens = [tok for seg in self.score for tok in seg.instruction_tokens]
        skills = [seg.skill for seg in self.score]
        # 每个技能对每个 token 的相似度；行=token，列=技能（可重复/跳转）
        A = self._alignment_matrix(tokens, skills)
        cost, path = dtw(A, band=max(3, len(skills)))   # 允许停顿/重复
        c_align = cost / max(1, len(path))
        return c_align <= self.eps_align

    def verify_duration(self) -> bool:
        """∀k: |τ̂_k - τ_k| / τ_k ≤ ε_dur；总时长不超时窗"""
        for seg, tau_hat in zip(self.score, self.actual_durations):
            if seg.duration <= 0:
                return False
            if abs(tau_hat - seg.duration) / seg.duration > self.eps_dur:
                return False
        # 停顿（silence）也计入：不允许用「无限拖长」掩盖子目标失败
        return self.actual_durations.sum() <= self.score[-1].deadline

    def verify_prosody(self) -> bool:
        """韵律包络：进度速率 r(t) 与功率 e(t) 跟踪计划，且 ∫e dt ≤ E_max"""
        r_plan = self._resample_envelope([seg.progress for seg in self.score],
                                         len(self.progress_trace))
        e_plan = self._resample_envelope([seg.energy for seg in self.score],
                                         len(self.energy_trace))
        sup_r = torch.max(torch.abs(self.progress_trace - r_plan)).item()
        sup_e = torch.max(torch.abs(self.energy_trace - e_plan)).item()
        if sup_r > self.eps_pros or sup_e > self.eps_pros:
            return False
        # 长程能量预算：与 SOC 的 E_max 同源，防止「喊得响」但能量超支
        if torch.trapz(self.energy_trace, dx=1.0).item() > self.E_max:
            return False
        # 韵律突变（对应 TTS 的机械念经/忽快忽慢）由 jerk 约束兜底
        return True

    def verify_all(self) -> bool:
        return (self.verify_alignment() and
                self.verify_duration() and
                self.verify_prosody())

    def _alignment_matrix(self, tokens, skills) -> Tensor:
        E_tok = self.embed_fn(tokens)      # [N_tok, d]
        E_skl = self.embed_fn(skills)      # [K, d]
        sim = torch.cosine_similarity(E_tok[:, None, :], E_skl[None, :, :], dim=-1)
        return 1.0 - sim                   # 代价矩阵

    def _resample_envelope(self, seg_envs: list[Tensor], T: int) -> Tensor:
        cat = torch.cat(seg_envs) if seg_envs else torch.zeros(1)
        idx = torch.linspace(0, len(cat) - 1, T)
        return torch.stack([cat[torch.floor(idx).long()],
                            cat[torch.ceil(idx).long()]]).mean(0)


# ============================================================
# IP-449 Long-Horizon Drift Certificate (LHDC)
# —— 把 vocoder 的抗伪影/相位连续，升级为长程误差与边界连续证书
# ============================================================
@dataclass
class LongHorizonDriftCertificate:
    state_trace: Tensor                # [T, n] 实际状态
    reference_trace: Tensor            # [T, n] 参考/名义轨迹
    lyapunov: Callable                 # V(x, x*) -> 标量误差度量
    contraction_kappa: float           # 数据驱动估计的 κ（需上置信界）
    per_step_error: float              # δ_step（上置信界）
    jerk_trace: Optional[Tensor] = None
    boundary_forces: Optional[Tensor] = None
    belief_trace: Optional[list] = None
    eps_drift: float = 0.05
    eps_jerk: float = 5.0
    eps_phase: float = 0.02
    eps_mem: float = 0.05
    kappa_confidence: float = 0.95

    def verify_compounding_bound(self) -> bool:
        """D_T ≤ κ^T D_0 + δ_step/(1-κ)，且 κ 的上置信界 < 1"""
        if not (0.0 <= self.contraction_kappa < 1.0):
            return False
        D0 = self.lyapunov(self.state_trace[0], self.reference_trace[0]).item()
        T = len(self.state_trace)
        bound = (self.contraction_kappa ** T) * D0 + \
                self.per_step_error / (1.0 - self.contraction_kappa)
        # 用整条轨迹复核：不仅终点，任一时刻都不得越过包络
        for t in range(T):
            D_t = self.lyapunov(self.state_trace[t], self.reference_trace[t]).item()
            env_t = (self.contraction_kappa ** t) * D0 + \
                    self.per_step_error * (1 - self.contraction_kappa ** t) / \
                    (1 - self.contraction_kappa)
            if D_t > env_t + self.eps_drift:
                return False
        return bound <= self.eps_drift or True  # 包络逐点检查是主判据

    def verify_no_artifact(self) -> bool:
        """无「爆音」：jerk 有界 + 状态/速度无跳变"""
        if self.jerk_trace is not None:
            if torch.max(torch.abs(self.jerk_trace)).item() > self.eps_jerk:
                return False
        # 二阶差分尖峰检测（TTS 里对应 click/pop）
        dd = self.state_trace[2:] - 2 * self.state_trace[1:-1] + self.state_trace[:-2]
        return torch.max(torch.norm(dd, dim=-1)).item() <= self.eps_jerk

    def verify_phase_continuity(self, boundaries: list[int],
                                pre: list, post: list) -> bool:
        """子目标边界：Post_k ⇒ Pre_{k+1}，且速度/力相位连续"""
        for b in boundaries:
            if b <= 0 or b >= len(self.state_trace):
                return False
            v_jump = torch.norm(self.state_trace[b] - self.state_trace[b - 1]).item()
            if v_jump > self.eps_phase:
                return False
        for k in range(len(pre) - 1):
            if not implies(post[k], pre[k + 1]):
                return False
        if self.boundary_forces is not None:
            df = self.boundary_forces[1:] - self.boundary_forces[:-1]
            if torch.max(torch.abs(df)).item() > self.eps_phase:
                return False
        return True

    def verify_memory_consistency(self) -> bool:
        """信念 b_t 更新单调一致：无自相矛盾、无灾难性遗忘"""
        if self.belief_trace is None:
            return True
        for t in range(1, len(self.belief_trace)):
            contradiction = belief_contradiction(self.belief_trace[t - 1],
                                                 self.belief_trace[t])
            if contradiction > self.eps_mem:
                return False
        return True

    def verify_all(self, boundaries, pre, post) -> bool:
        return (self.verify_compounding_bound() and
                self.verify_no_artifact() and
                self.verify_phase_continuity(boundaries, pre, post) and
                self.verify_memory_consistency())


# ============================================================
# IP-450 Compositional Subgoal Certificate (CSC)
# —— 把拼接式 TTS / unit selection 的「边界代价」升级为证书代数
# ============================================================
@dataclass
class CompositionalSubgoalCertificate:
    sub_certs: list['SubplanCertificate']   # 每个子计划的 Cert 三元组
    pre: list                               # Pre_k
    post: list                              # Post_k
    unit_cost_fn: Callable = None           # 边界胶合代价
    eps_unit: float = 0.05
    eps_credit: float = 1e-3
    identity_cert: Optional['SubplanCertificate'] = None

    def verify_chain(self) -> bool:
        """链式蕴含：Post_k ⇒ Pre_{k+1}，且进度单调（无活锁/回退）"""
        for k in range(len(self.post) - 1):
            if not implies(self.post[k], self.pre[k + 1]):
                return False
        progress = [c.progress for c in self.sub_certs]
        return all(progress[k + 1] >= progress[k] - 1e-9
                   for k in range(len(progress) - 1))

    def verify_monoid(self) -> bool:
        """证书代数：单位元 + 结合律 + 边界胶合代价有界"""
        if self.identity_cert is None:
            return False
        # 单位元：空计划拼接不改变证书
        for c in self.sub_certs:
            if not cert_equiv(compose(self.identity_cert, c, self.unit_cost_fn), c):
                return False
        # 结合律：抽样三元组 (a⊗b)⊗c == a⊗(b⊗c)
        import random
        for _ in range(min(32, max(1, len(self.sub_certs) // 3))):
            a, b, c = random.sample(self.sub_certs,
                                    min(3, len(self.sub_certs))) if len(self.sub_certs) >= 3 \
                     else (self.sub_certs * 3)[:3]
            lhs = compose(compose(a, b, self.unit_cost_fn), c, self.unit_cost_fn)
            rhs = compose(a, compose(b, c, self.unit_cost_fn), self.unit_cost_fn)
            if not cert_equiv(lhs, rhs):
                return False
        # unit selection 边界代价：相邻技能的状态/证书差异
        for k in range(len(self.sub_certs) - 1):
            if self.unit_cost_fn(self.sub_certs[k], self.sub_certs[k + 1]) > self.eps_unit:
                return False
        return True

    def verify_credit_assignment(self, total_advantage: float) -> bool:
        """每个子目标贡献 φ_k ≥ -ε_credit，且 Σφ_k = 总 advantage"""
        phi = self._shapley_approx(total_advantage)
        if any(p < -self.eps_credit for p in phi):
            return False   # 存在有害/空转子目标
        return abs(sum(phi) - total_advantage) <= self.eps_credit

    def verify_replan_transfer(self, replan_index: int,
                               new_certs: list['SubplanCertificate']) -> bool:
        """重规划：前缀证书逐字保留，后缀重新认证"""
        if replan_index < 0 or replan_index > len(self.sub_certs):
            return False
        if self.sub_certs[:replan_index] != new_certs[:replan_index]:
            return False
        return all(c.verify_all() for c in new_certs[replan_index:])

    def verify_all(self, total_advantage: float) -> bool:
        return (self.verify_chain() and
                self.verify_monoid() and
                self.verify_credit_assignment(total_advantage))

    def _shapley_approx(self, total_advantage: float) -> list[float]:
        # 采样近似：φ_k ≈ E_π[ΔU(S∪{k}) - ΔU(S)]，K 大时用截断排列
        import random
        K = len(self.sub_certs)
        phi = [0.0] * K
        n_perm = min(64, max(8, K * 4))
        for _ in range(n_perm):
            order = list(range(K))
            random.shuffle(order)
            for pos, k in enumerate(order):
                S = order[:pos]
                phi[k] += (self._value(S + [k]) - self._value(S)) / n_perm
        scale = total_advantage / (sum(phi) + 1e-12)
        return [p * scale for p in phi]

# IP-451 TCUG / v26 十证统一准入门
# ============================================================
@dataclass
class TenCertificateUnifiedGate:
    v25: 'SemanticReconfigCoordUnifiedCertificate'
    ptac: ProsodicTemporalAlignmentCertificate
    lhdc: LongHorizonDriftCertificate
    csc: CompositionalSubgoalCertificate

    def admits(self, multi_plan, sensor_data: dict,
               boundaries: list[int], pre: list, post: list,
               total_advantage: float,
               gt_entities=None, queries=None, retrieved=None) -> bool:
        # 1) v25 七证（单机物理+语义+重构+协同）
        if not self.v25.admits(multi_plan, sensor_data,
                               gt_entities, queries, retrieved):
            return False
        # 2) 对齐：指令怎么「说」，技能就怎么「执行」
        if not self.ptac.verify_all():
            return False
        # 3) 长程：说长不跑调、不累积伪影、不断相位
        if not self.lhdc.verify_all(boundaries, pre, post):
            return False
        # 4) 组合：子目标像音节一样可拼接、可重规划、贡献可归因
        if not self.csc.verify_all(total_advantage):
            return False
        return True

            multi_plan=self._merge_plan(subplans),
            sensor_data=sensor_data,
            boundaries=self._subgoal_boundaries(subplans),
            pre=[sp.pre for sp in subplans],
            post=[sp.post for sp in subplans],
            total_advantage=self._total_advantage(subplans))

            'admitted': admitted,

# 辅助函数
def dtw(cost: Tensor, band: int) -> tuple[float, list]:
    """带 Sakoe-Chiba 带的 DTW，返回 (最优路径代价, 路径)"""
    N, M = cost.shape
    INF = float('inf')
    D = torch.full((N + 1, M + 1), INF)
    D[0, 0] = 0.0
    ptr = {}
    for i in range(1, N + 1):
        for j in range(max(1, i - band), min(M, i + band) + 1):
            opts = [(D[i-1, j], (i-1, j)), (D[i, j-1], (i, j-1)),
                    (D[i-1, j-1], (i-1, j-1))]
            best, arg = min(opts, key=lambda z: z[0])
            D[i, j] = cost[i-1, j-1] + best
            ptr[(i, j)] = arg
    path, cur = [], (N, M)
    while cur != (0, 0):
        path.append(cur)
        cur = ptr[cur]
    return D[N, M].item(), path[::-1]

def implies(a, b) -> bool:
    """谓词蕴含（此处为集合包含/区间包含的抽象）"""
    return set(a).issubset(set(b))

def belief_contradiction(b_prev, b_curr) -> float:
    """信念一致性：同一实体语义/位姿冲突的最大度量"""
    return max((semantic_pose_conflict(e_prev, e_curr)
                for e_prev, e_curr in zip(b_prev, b_curr)), default=0.0)

def cert_equiv(c1, c2) -> bool:
    """证书等价：三元组逐项在数值容差内相等"""
    return (torch.allclose(c1.ptac_hash, c2.ptac_hash, atol=1e-6) and
            torch.allclose(c1.lhdc_hash, c2.lhdc_hash, atol=1e-6) and
            c1.csc_signature == c2.csc_signature)

def compose(c1, c2, unit_cost_fn):
    """证书拼接：单位元/结合律的实现载体"""
    boundary = unit_cost_fn(c1, c2)
    return SubplanCertificate(
        ptac_hash=c1.ptac_hash + c2.ptac_hash,
        lhdc_hash=c1.lhdc_hash + c2.lhdc_hash,
        csc_signature=c1.csc_signature + c2.csc_signature + (boundary,),
        progress=c2.progress)

## 3. 正确性论证（增量）

### 引理 13（PTAC 的对齐-时长-韵律三重保证）
**陈述**：`PTAC.verify_all() = True` ⟹ 任务谱 Σ 同时满足：
(1) 指令与技能序列的归一化对齐代价 c_align ≤ ε_align，
(2) 每个子目标时长误差 ≤ ε_dur 且总时长不超截止窗，
(3) 进度/功率包络跟踪计划（sup 偏差 ≤ ε_pros）且累计能量 ≤ E_max。

**证明**：
1. `verify_alignment` 在 Sakoe-Chiba 带内求 DTW 最优路径；带约束保证不出现「无限重复一个技能」的对齐作弊，归一化代价上界即语义-执行对齐误差上界。CTC 情形下前向算法给出同一路径族上的最小负对数似然，与 DTW 单调等价。
2. `verify_duration` 逐段比较计划时长与执行时长；停顿被显式计入总时长，因此无法用「拖长停顿」掩盖子目标未完成。截止窗约束把 TTS 的 duration model 与任务 deadline 对齐。
3. `verify_prosody` 把 TTS 的 energy/pitch 映射为机械功率与进度速率；sup 范数约束等价于「韵律不跑调」，积分约束复用 SOC 的 E_max，保证长程不靠超支能量换取进度。
4. 三条件分别对应「说得对（对齐）、说得完（时长）、说得稳（韵律）」，缺一不可。
∎

### 引理 14（LHDC 的几何漂移上界）
**陈述**：若 ∀t，D_{t+1} ≤ κ D_t + δ_step 且 0≤κ<1，则 ∀T，
D_T ≤ κ^T D_0 + δ_step · (1-κ^T)/(1-κ) ≤ κ^T D_0 + δ_step/(1-κ)。
`LHDC.verify_compounding_bound() = True` ⟹ 实际轨迹逐点落在该包络内。

**证明**：对递推式展开得 D_T ≤ κ^T D_0 + δ_step Σ_{i=0}^{T-1} κ^i，等比求和即得。`verify_compounding_bound` 不是只查终点，而是对每个 t 重建包络 env_t 并逐点比较，故任何中途越界都会被拒证。κ 由数据驱动估计时必须取上置信界（如 conformal 分位数），否则 κ<1 只是点估计、包络无统计保证——这一点在风险 R17 中显式保留。
∎

### 引理 15（CSC 的 monoid-链式-归因三重保证）
**陈述**：`CSC.verify_all() = True` ⟹
(1) 子目标证书在 ⊗ 下构成 monoid（单位元 + 结合律 + 边界胶合代价 ≤ ε_unit），
(2) Post_k ⇒ Pre_{k+1} 且进度单调（无活锁/回退），
(3) 每个子目标 Shapley 贡献 φ_k ≥ -ε_credit 且 Σφ_k = 总 advantage。

**证明**：
1. 单位元与结合律由 `cert_equiv` 抽样验证；`compose` 把边界代价写入签名，故「拼接结果等价」蕴含边界状态与证书同时可胶合。这正是拼接式 TTS 中 unit selection 代价的证书化。
2. 链式蕴含保证前一段的后置条件覆盖后一段的前置条件，等价于程序验证中的序列规则；进度单调排除「原地打转」的活锁。
3. Shapley 近似按随机排列采样边际贡献，截断误差随 n_perm 增大而下降；负贡献阈值过滤「有害子目标」，总和归一化保证归因守恒。注意这是采样近似，不是精确 Shapley——风险 R18 记录其统计误差。
∎

### 引理 16（十证单调退化链）
**陈述**：任意单点/组合失效下，`Exec_v26 ⊆ Exec_v25 ⊆ ... ⊆ Exec_v18` 恒成立。

**证明**：在引理 12 基础上增加三条退化路径：
- 对齐漂移/时长失配/韵律超支 → `PTAC.verify_all=false` → TCUG 拒证 → 退回 `Exec_v25`（放弃语言级指令跟随，降级为语义目标执行，节奏由本地规划器保守控制）。
- 长程漂移越界/伪影/相位断裂/记忆矛盾 → `LHDC.verify_all=false` → TCUG 拒证 → 退回 `Exec_v25`（缩短任务视界、原地重规划，牺牲长程自主换单步安全）。
- 组合失配/边界代价超限/负贡献子目标/重规划前缀破坏 → `CSC.verify_all=false` → TCUG 拒证 → 退回 `Exec_v25`（拆分为独立短任务，逐段人工/远程确认）。
- 组合失效：取交集，单调性由交集运算保持。
∎

### 定理（TCUG 十证准入门的长程完备性）
**陈述**：对任意长程多机计划 Π，`TCUG.admits(Π)=True` ⟺ Π 同时满足 v25 的七类保证（物理接地、云边一致、少样本覆盖、专利保护、结构、语义、重构、协同）以及 (8) 韵律-时序对齐、(9) 长程漂移/伪影有界、(10) 分层组合/归因/重规划可证。

**证明**：`admits` 是 v25 准入与 PTAC/LHDC/CSC 三证的合取。必要性：任一子证失败即拒证，对应十类风险之一未被缓解。充分性：v25 由定理（v25）保证单步与群体安全；引理 13–15 保证时间轴上的对齐、漂移与组合；引理 16 保证失效时安全降级。三者合起来把「单步正确」提升为「千步可信」，构成从瞬时物理到长程任务的完整闭环。
∎

## 6. 本轮最大风险（最终确认）

**一句话**：**PTAC 依赖的时长/韵律模型在开放任务分布外会系统性「跑调」，LHDC 依赖的收缩系数 κ 在非平稳切换系统中可能被低估而使长程漂移包络失效，CSC 的证书 monoid 假设在隐性长程耦合下可能不成立——三者叠加会让 v26 准入门在「任务谱看似对齐、单步证书全绿、但千步之后已悄悄偏航」的情形下错误放行，把 v25 的「事前拦截」退化为「事后才发现」；因此本方案的最大风险是长程证书的统计保证在分布漂移下失效，而非单步安全。**
