# 第 1 轮：从「证书堆叠」到「成本感知的 SLAM 证书底座」

## 0. 直觉解释（先讲人话）

前几轮我们把系统做成了证书的层层叠加：几何证书、能量证书、云边同步证书、少样本证书、专利证书。这套东西有一个被默认掉的前提——**位姿是给定的、地图是静态的**。真实机器人里：

- 位姿来自 SLAM，它不是加性噪声，而是会**漂移**，会在长走廊、玻璃幕墙、隧道、动态人群中**突然发散**；
- 地图会**过期**：早上标定的自由空间，中午可能站了人、堆了货；
- 每签一张证书都要花**电、算力、带宽、人工标注**，预算永远是紧的。

把「同步定位与建图」和「成本控制」两个灵感词拼在一起，本轮的核心命题是：

> **SLAM 既是安全证书的输入，也必须被当作证书本身来审计；成本控制不是削减安全，而是决定「在给定预算下，安全可以承诺到什么分辨率」。**

一句话直觉：**地图不是事实，是带保质期的声明；预算不是削减安全，是选择安全的粒度。**

## 1. 严谨定义（把直觉钉死）

### 1.1 SLAM 状态与保真证书

设时刻 t 的位姿估计与协方差为

  ξ_t = (p̂_t, Σ̂_t),   p̂_t ∈ SE(3), Σ̂_t ⪰ 0,

锚点集合 A_t = {回环闭合、已知地标、GNSS/信标}。真实位姿 p*_t 未知。定义定位误差与漂移界：

  e_loc(t) = ‖p*_t ⊖ p̂_t‖,   ε_loc(t) 为 (1-α) 置信上界。

**SLAM Fidelity Certificate（SFC）谓词**：

  SFC(ξ_t, M_t) ≜
    (1) 保守协方差：Σ̂_t ⪰ Σ_true(t)（含漂移模型膨胀）
    (2) 回环残差：∀ loop ℓ ∈ A_t, ‖r_ℓ‖ ≤ δ_loop
    (3) 地图一致性：局部地图与全局地图在重叠区的占据残差 ≤ δ_map
    (4) 非退化：Hessian 条件数 κ(H_t) ≥ κ_min

其中 (4) 是退化检测：长走廊里沿轴向几乎没有约束，κ 会塌掉，此时必须令 ε_loc → ∞（即拒绝签发），而不是「乐观地给一个小误差」。

### 1.2 地图的时效与熵

地图单元 k 记作 (o_k, H_k, τ_k)：占据概率、占用熵、最后一次观测时间。

  H_k = −o_k log o_k − (1−o_k) log(1−o_k),   s_k = t − τ_k（陈旧度）。

**Map Temporal-Validity Certificate（MTVC）谓词**：

  MTVC(M_t, π) ≜ ∀k ∈ Cells(π): s_k ≤ T_fresh ∨ o_k ← max(o_k, o_occupied)

即：计划用到的地图单元，要么足够新鲜，要么被**保守提升为占据**。后者会损失可用性（自由空间变小），但绝不会产生「假自由空间」——这是安全的正确方向。

### 1.3 成本预算与成本台账

预算向量 B_t = (B_E, B_C, B_L, B_H)：能量 / 算力 / 时延 / 人工。每个证书模块 i 有成本向量 c_i 与「运行收益」u_i（运行后能多放行多少计划，即可用性增益）。

**Cost Ledger Certificate（CLC）**：能量/算力/带宽/人工四本账，逐条 Merkle 链式追加，任何一条支出可审计、不可抵赖；与既有 EVC（能量证书）对接，能量账不得重复计。

### 1.4 预算调度与「缺证即拒绝」

对计划 π，定义其**必需证据集** Req(π)（它依赖哪些证书模块）。运行集合 Run(z) ⊆ Modules，z_i ∈ {0,1}。

**Budgeted Certificate Scheduler（BCS）**：

  max_z  Σ_i z_i · u_i
  s.t.   Σ_i z_i · c_i ≤ B_t（逐维）
         z_i = 1, ∀i ∈ M0（强制模块：SFC 的回环/重定位、能量、DCL）

**准入语义（关键）**：计划 π 通过当且仅当

  Req(π) ⊆ Run(z)  且  ∀i ∈ Req(π), P_i(π) = true。

未运行的模块**不提供证据**，依赖它的计划一律拒绝（fail-closed）。于是

  Run(z') ⊆ Run(z)  ⇒  Exec(z') ⊆ Exec(z)。

**成本控制的正确姿势由此得到：删模块只能收缩可用性，绝不能放宽安全性。** 预算是拿可用性换的，不是拿安全换的。

### 1.5 成本—精度曲线

定义 C(ε) = 维持定位误差上界 ≤ ε 所需的最小成本。C 关于 ε 单调不增（要求越严越贵）。给定预算 B，可达精度

  ε*(B) = sup{ ε : C(ε) ≤ B }。

这就是「安全的分辨率」：**预算决定你能承诺多细的安全，而不是决定安全是否存在。**

### 1.6 认证主动 SLAM

主动探索的候选视角 v 有信息增益 IG(v) 与代价 cost(v)（移动能耗 + 算力）。只在**已认证自由前沿** F_cert（已认证自由空间与未知的边界）上选择：

  v* = argmax_{v ∈ F_cert} IG(v) / cost(v)，

且移动到 v 的动作本身必须先通过准入（安全边界内才允许动）。传感器可以「看向未知」，但机体不能「走进未知」。

### 1.7 统一准入门

  Exec_v24 = Exec_v23 ∩ {π : SFC ∧ MTVC(M,π) ∧ CLC_feasible ∧ Req(π) ⊆ Run(z)}。

## 2. 三个核心洞察

1. **地图即证书**：地图的自由/占据不是事实，是带时效和熵的声明。任何用图做安全判断的地方，都必须附带「这张图有多新、有多确定」。
2. **缺证即拒绝**：成本调度只能收缩可用性，不能放宽安全性。这是成本控制不破坏安全单调性的唯一正确语义。
3. **成本是安全的分辨率**：预算不改变真值，只改变证书粒度。降到粗粒度证书时，系统应更保守（更多拒绝），而不是更冒险。

## 3. 与既有框架的接口

- SFC 把 ε_loc 注入 ACSC / CertBox（IP-432），**替代固定膨胀半径**：位姿越不确定，膨胀越大。
- MTVC 把过期地图单元提升为占据，喂给 CAC 缺席证书（IP-426），保证「假自由空间」不出现。
- CLC 与 EVC（IP-434）对接能量账，四本账合并审计。
- BCS 决定本轮哪些过滤器生效，是 HPC-E++ 的「预算前置」。
- ACD 把预算收缩映射为预定义降级层级 L0 ⊃ L1 ⊃ …，保证 Exec 单调不增。

## 4. 本轮最大风险

**一句话**：SLAM 的协方差在退化场景（长走廊/玻璃幕墙/动态人群）会系统性低估漂移，使 SFC「乐观通过」；而预算紧张时 BCS 恰好优先削减最昂贵的回环检测与重定位——「省成本」于是变成「省掉纠偏」，证书边界在真实漂移下失效。

```python
# ============================================================
# IP-440 SLAM Fidelity Certificate (SFC)
# ============================================================
@dataclass
class PoseEstimate:
    p: np.ndarray          # SE(3) 位姿
    Sigma: np.ndarray      # 6x6 协方差（须保守，Σ̂ ⪰ Σ_true）
    H: np.ndarray          # 位姿图信息矩阵（Hessian）
    anchors: list          # 回环/地标/信标残差 r_ℓ

class SLAMFidelityCertificate:
    def __init__(self, alpha=0.01, delta_loop=0.05, delta_map=0.10,
                 kappa_min=50.0, drift_rate=0.01):
        self.alpha = alpha
        self.delta_loop = delta_loop
        self.delta_map = delta_map
        self.kappa_min = kappa_min
        self.drift_rate = drift_rate   # 每米/每秒漂移膨胀系数

    def inflate_drift(self, xi: PoseEstimate, travel: float) -> np.ndarray:
        """按运动量膨胀协方差：漂移随里程累积，避免过乐观。"""
        return xi.Sigma + (self.drift_rate * travel) ** 2 * np.eye(6)

    def degenerate(self, xi: PoseEstimate) -> bool:
        """退化检测：条件数塌陷 → 该方向无约束 → 必须拒绝签发。"""
        return np.linalg.cond(xi.H) < self.kappa_min

    def epsilon_loc(self, xi: PoseEstimate, travel: float) -> float:
        """(1-α) 置信的定位误差上界；退化时返回 +inf（fail-closed）。"""
        if self.degenerate(xi):
            return float('inf')
        Sigma_c = self.inflate_drift(xi, travel)
        # 3σ 椭球长轴作为保守标量界（可替换为卡方分位数）
        return 3.0 * math.sqrt(np.linalg.eigvalsh(Sigma_c).max())

    def certify(self, xi: PoseEstimate, M: 'Map', travel: float) -> tuple[bool, float]:
        eps = self.epsilon_loc(xi, travel)
        if not math.isfinite(eps):
            return False, eps                       # 退化 → 拒绝
        if max((np.linalg.norm(r) for r in xi.anchors), default=0.0) > self.delta_loop:
            return False, eps                       # 回环残差超限 → 拒绝
        if self.map_consistency(xi, M) > self.delta_map:
            return False, eps                       # 地图不一致 → 拒绝
        return True, eps

    def map_consistency(self, xi, M) -> float:
        """局部地图与全局地图在重叠区的占据残差（实现略）。"""
        return 0.0

# IP-441 Map Temporal-Validity Certificate (MTVC)
# ============================================================
@dataclass
class MapCell:
    o: float        # 占据概率
    H: float        # 占用熵
    tau: float      # 最后观测时间

class MapTemporalValidity:
    def __init__(self, T_fresh=2.0, o_occupied=0.9):
        self.T_fresh = T_fresh
        self.o_occupied = o_occupied

    def entropy(self, o: float) -> float:
        if o <= 0.0 or o >= 1.0:
            return 0.0
        return -o * math.log(o) - (1 - o) * math.log(1 - o)

    def stale_cells(self, M: dict, t: float, cells) -> list:
        return [k for k in cells if (t - M[k].tau) > self.T_fresh]

    def certify(self, M: dict, t: float, cells) -> tuple[bool, dict]:
        """陈旧单元被保守提升为占据：损失可用性，绝不制造假自由。"""
        promoted = {}
        for k in cells:
            if (t - M[k].tau) > self.T_fresh or M[k].H > 0.5:
                promoted[k] = self.o_occupied
        # 提升后的地图对下游 CAC / CertBox 可见
        return True, promoted

# IP-443 Cost Ledger Certificate (CLC)
# ============================================================
class CostLedger:
    def __init__(self, EVC):
        self.EVC = EVC
        self.chain: list[dict] = []
        self.prev_hash = b'\x00' * 32
        self.spent = {'E': 0.0, 'C': 0.0, 'L': 0.0, 'H': 0.0}

    def append(self, module: str, cost: dict, energy_from_evc: float | None = None):
        """四本账追加一条；能量以 EVC 为准，禁止重复计账。"""
        if energy_from_evc is not None:
            if abs(cost['E'] - energy_from_evc) > 1e-6:
                raise ValueError('energy ledger mismatch with EVC')
        entry = {'module': module, 'cost': cost,
                 'prev': self.prev_hash, 't': time.now()}
        entry['hash'] = sha256(canonical(entry))
        self.chain.append(entry)
        self.prev_hash = entry['hash']
        for k in self.spent:
            self.spent[k] += cost[k]

    def feasible(self, B_t: dict) -> bool:
        return all(self.spent[k] <= B_t[k] for k in self.spent)

    def audit_proof(self, idx: int) -> list:
        """Merkle 链式审计路径（实现略）。"""
        return []

# IP-442 Budgeted Certificate Scheduler (BCS)
# ============================================================
class BudgetedCertificateScheduler:
    def __init__(self, mandatory: set, modules: dict, ledger: CostLedger):
        self.M0 = mandatory                 # 强制模块：不可裁
        self.modules = modules              # name -> (cost_vector, u_ema)
        self.ledger = ledger

    def schedule(self, B_t: dict, required: set) -> tuple[set, bool]:
        """返回 (Run, ok)。ok=False 表示强制模块都放不下 → 全面拒证。"""
        Run = set(self.M0)
        spent = sum_cost(Run, self.modules)
        if not within(spent, B_t):
            return set(), False             # fail-closed：Exec = ∅
        # 先满足本步必需证据（若必需模块预算不足 → 拒绝本步）
        for m in required - Run:
            if not within(spent + self.modules[m].cost, B_t):
                return set(), False
            Run.add(m); spent = spent + self.modules[m].cost
        # 剩余预算按 u_i / cost 贪心填（次模目标下 1-1/e 近似）
        cand = [m for m in self.modules
                if m not in Run and within(spent + self.modules[m].cost, B_t)]
        cand.sort(key=lambda m: efficiency(m, self.modules), reverse=True)
        for m in cand:
            c = self.modules[m].cost
            if within(spent + c, B_t):
                Run.add(m); spent = spent + c
        return Run, True

    def update_utility(self, module: str, realized_gain: float, beta=0.05):
        """在线 EMA 估计可用性增益 u_i。"""
        self.modules[module].u_ema = (1 - beta) * self.modules[module].u_ema + beta * realized_gain

# IP-444 Certified Active SLAM (CAS)
# ============================================================
class CertifiedActiveSLAM:
    def __init__(self, gate: 'HPCEPlusPlus', energy_model):
        self.gate = gate
        self.energy_model = energy_model

    def certified_frontier(self, M: dict, free_cert: set, unknown: set) -> set:
        """已认证自由空间与未知的边界；只在这条边界上探索。"""
        return {k for k in free_cert if any(n in unknown for n in neighbors(k))}

    def choose_view(self, F_cert: set, candidates: list) -> object | None:
        best, best_ratio = None, -1.0
        for v in candidates:
            if v.cell not in F_cert:
                continue                       # 只允许沿认证前沿看
            ig = self.info_gain(v, F_cert)
            cost = self.energy_model(v) + self.compute_cost(v)
            ratio = ig / max(cost, 1e-9)
            if ratio > best_ratio:
                best, best_ratio = v, ratio
        return best

    def step(self, v) -> bool:
        """移动动作本身必须先过准入：不得走进未知。"""
        return self.gate.admits_motion(v)

# IP-445 Anytime Certificate Degradation (ACD)
# ============================================================
class AnytimeDegradation:
    """预定义层级，越低级模块越少、越保守；Exec 严格单调不增。"""
    LEVELS = [
        {'sdc', 'cac', 'dcl', 'gic', 'pgev', 'acsc', 'dcsc',
         'cesc', 'fsvc', 'hpc_e_plus', 'sfc', 'mtvc', 'clc', 'cas'},   # L0
        {'sdc', 'cac', 'dcl', 'pgev', 'acsc', 'dcsc', 'sfc', 'mtvc', 'clc'},  # L1
        {'cac', 'dcl', 'pgev', 'acsc', 'sfc', 'mtvc', 'clc'},          # L2
        {'dcl', 'pgev', 'acsc', 'sfc', 'mtvc'},                        # L3
        {'dcl', 'acsc', 'sfc'},                                        # L4 最小安全核
    ]

    def level_for(self, B_t: dict, ledger: CostLedger, modules: dict) -> int:
        for lvl, mods in enumerate(self.LEVELS):
            need = sum_cost(mods, modules)
            if within(need, B_t) and within_after(ledger.spent, need, B_t):
                return lvl
        return len(self.LEVELS)  # 连最小核都放不下 → 全拒

               t: float, travel: float, B_t: dict) -> tuple[bool, dict]:
        # 1) 预算前置：决定本轮运行集合（缺证即拒绝）
        Run, ok = self.bcs.schedule(B_t, required=req)
        if not ok:
            return False, {'reason': 'budget_infeasible', 'run': set()}
        # 2) 本步必需证据必须全部在运行集合内
        if not req.issubset(Run):
            return False, {'reason': 'missing_evidence', 'run': Run}
        # 3) 定位保真
        sfc_ok, eps = self.sfc.certify(xi, M, travel)
        if not sfc_ok:
            return False, {'reason': 'slam_degenerate_or_drift', 'eps': eps}
        # 4) 地图时效（陈旧单元已提升为占据）
        mtvc_ok, promoted = self.mtvc.certify(M, t, cells_of(plan))
        # 5) 基础 HPC-E+（几何/能量/云边/少样本/IP），ε_loc 注入 CertBox
        if not self.hpc_e_plus.admits(plan, eps=eps, promoted=promoted):
            return False, {'reason': 'hpc_e_plus', 'run': Run}
        # 6) 成本台账（防超支、可审计）
        if not self.ledger.feasible(B_t):
            return False, {'reason': 'ledger_over_budget', 'run': Run}
        return True, {'run': Run, 'eps': eps, 'promoted': promoted}


# ============================================================
# 端到端：感知 → SLAM 证书 → 预算调度 → 降级 → 准入
# ============================================================
class CostAwareSLAMPipeline:
    def __init__(self, config):
        self.slam = SLAMFrontend(config)          # 位姿图 + 回环
        self.sfc = SLAMFidelityCertificate()
        self.mtvc = MapTemporalValidity()
        self.ledger = CostLedger(config['evc'])
        self.bcs = BudgetedCertificateScheduler(
            mandatory={'sfc', 'pgev', 'dcl'}, modules=config['modules'],
            ledger=self.ledger)
        self.acd = AnytimeDegradation()
        self.cas = CertifiedActiveSLAM(config['gate'], config['energy_model'])
        self.gate = HPCEPlusPlus(
            hpc_e_plus=config['hpc_e_plus'], sfc=self.sfc, mtvc=self.mtvc,
            bcs=self.bcs, acd=self.acd, ledger=self.ledger)

    def step(self, sensors, B_t):
        # 1) SLAM 前端：位姿 + 回环 + 地图更新
        xi, M = self.slam.update(sensors)
        # 2) 退化/漂移 → SFC 可能直接拒绝
        sfc_ok, eps = self.sfc.certify(xi, M, self.slam.travel)
        # 3) 预算决定层级（可用性随预算单调）
        lvl = self.acd.level_for(B_t, self.ledger, self.bcs.modules)
        # 4) 主动探索（仅认证前沿）
        F = self.cas.certified_frontier(M, self.slam.free_cert, self.slam.unknown)
        view = self.cas.choose_view(F, sensors['candidate_views'])
        # 5) 生成计划并过统一门
        plan, req = self.plan(sensors, view)
        admitted, info = self.gate.admits(
            plan, req, xi, M, time.now(), self.slam.travel, B_t)
        # 6) 记账（仅记实际执行消耗）
        if admitted:
            self.ledger.append('exec', self.measure_cost(plan), self.evc_energy())
        return admitted, {'level': lvl, 'eps': eps, 'sfc': sfc_ok, **info}
```

## 2. 复杂度分析

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| SFC 证书 | O(\|A_t\| + \|V\|) 增量（iSAM2 增量更新 amortized O(log\|V\|)） | O(\|V\|+\|E\|) | δ_loop=0.05, κ_min=50 |
| MTVC 时效检查 | O(\|Cells(π)\|)（陈旧单元用最小堆懒更新） | O(\|M_active\|) | T_fresh=2s, o_occupied=0.9 |
| BCS 调度 | O(n log n) 贪心；n≤20 | O(n) | 次模目标 1−1/e 近似 |
| CLC 追加/审计 | O(1) 追加 / O(log N) Merkle 证明 | O(N) 链 | 四本账 |
| CAS 选视角 | O(\|F_cert\|·\|candidates\|) | O(\|F_cert\|) | IG/cost |
| ACD 选级 | O(L·\|modules\|)，L=5 | O(1) | 预定义层级 |
| 端到端单步 | O(\|V\| 增量 + \|Cells\| + n log n + \|F_cert\|·V) | O(\|V\|+\|E\|+\|M\|) | 关键路径需 <20ms |

**实时性**：SFC 用增量位姿图（iSAM2），回环检测异步；BCS 是 O(n log n) 且 n≤20；MTVC 用最小堆只处理过期单元。关键路径无阻塞 I/O，满足 50Hz。

## 3. 正确性论证

### 假设 A1（保守协方差）
Σ̂_t ⪰ Σ_true(t)。这是 SFC 健全性的唯一外部假设，也是本轮最大风险的来源；退化检测与漂移膨胀是维持 A1 的工程手段，但不能从数学上保证。

### 引理 1（SFC 健全性）
**陈述**：若 SFC(ξ_t,M_t) 成立且 A1 成立，则 p*_t ∈ p̂_t ⊕ B(ε_loc) 以概率 ≥ 1−α；因而以 ε_loc 膨胀的 CertBox/ACSC 是几何健全的。

**证明**：A1 给出真实误差落在 Σ̂ 的 (1−α) 置信椭球内（标准卡方界）；ε_loc 取椭球长轴，故包含真实位姿。回环残差 ≤ δ_loop 与地图一致性 ≤ δ_map 保证锚点与地图未把系统「锁错」。非退化条件保证 ε_loc 有限，退化时 ε_loc=∞ ⇒ 拒绝，不产生虚假有限界。∎

### 引理 2（MTVC 保守性 / 无假自由）
**陈述**：MTVC 处理后，被下游使用的自由空间集合 F_cert ⊆ 真实自由空间 F*，以概率 ≥ 1−α_map。

**证明**：对每个计划所用单元，要么 s_k ≤ T_fresh（新观测，占据概率由当前观测给出），要么 o_k 被提升到 o_occupied。提升只会减少自由空间，故 F_cert 是真实自由空间的子集；陈旧/高熵单元不再被声明为自由，假自由空间（假阴性→可通行）不会出现。∎

### 引理 3（BCS 单调性 / 缺证即拒绝）
**陈述**：设准入语义为「Req(π) ⊆ Run(z) ∧ ∀i∈Req(π), P_i(π)」。若 Run(z') ⊆ Run(z)，则 Exec(z') ⊆ Exec(z)。特别地，任意降级层级 L_{k+1} ⊆ L_k 满足 Exec(L_{k+1}) ⊆ Exec(L_k)。

**证明**：π ∈ Exec(z') ⇒ Req(π) ⊆ Run(z') ⊆ Run(z) 且各 P_i 为真 ⇒ π ∈ Exec(z)。谓词 P_i 只依赖模块自身证据，不随运行集合变化。因此删模块只减少可满足 Req(π) 的计划数，绝不新增计划。∎

> 注：若把「未运行」错误地当作「豁免（pass）」而非「拒绝（deny）」，则删模块会**放大** Exec，安全性被预算击穿。这正是本框架把缺证语义钉死为 fail-closed 的原因。

### 引理 4（CLC 预算健全性）
**陈述**：若 BCS 返回 ok=True，则本轮支出逐维 ≤ B_t；若强制模块 M0 已超预算，则返回 Run=∅，Exec=∅（全面拒证）。

**证明**：schedule 每次加入模块前都检查 within(spent+c, B_t)，故不变式 spent ≤ B_t 保持；M0 初始即检查，放不下直接返回空集。能量账与 EVC 对账，避免重复计账导致的虚假余额。∎

### 引理 5（成本—精度单调性）
**陈述**：ε*(B) 关于 B 单调不增；即预算越大，可达定位精度越高（ε 越小）。

**证明**：C(ε) 关于 ε 单调不增。B 增大时集合 {ε : C(ε) ≤ B} 单调扩张，其上确界 ε*(B) 单调不增。∎

### 定理（HPC-E++ 成本感知准入门的安全—可用性可分离性）
**陈述**：对任意计划 π，`HPCEPlusPlus.admits(π)=True` ⟺
(1) 预算可行且 Req(π) ⊆ Run(z)（成本可负担、证据齐备）；
(2) SFC 成立（定位健全，含退化拒绝）；
(3) MTVC 成立（地图无假自由）；
(4) HPC-E+ 全部基础条件成立（几何/能量/云边/少样本/IP）。
且 Exec_v24 ⊆ Exec_v23 ⊆ … 恒成立。**预算只影响可用性（Exec 的大小），不影响安全性（Exec 的每个元素都仍健全）。**

**证明**：由 admits 的连言结构与引理 1–4 直接得到；单调链由引理 3 与既有 Exec_v23 ⊆ Exec_v22 递推得到。安全—可用性可分离性来自引理 3：任何 Run 的收缩只删计划、不改谓词。∎

## 4. 已知风险与缓解

| 编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| R1 | 退化场景下协方差过乐观（违反 A1），SFC 乐观通过 | 最高 | 1) 退化检测 κ(H)<κ_min 直接令 ε=∞；2) 按里程漂移膨胀 Σ；3) 多模态锚点（视觉+轮速+IMU+UWB）交叉校验；4) 定期注入已知地标做在线校准 | 玻璃幕墙/长隧道等长期退化仍可能使膨胀不足 |
| R2 | 预算压力优先裁掉最贵的回环/重定位，恰是纠偏关键 | 高 | 把 SFC 的回环/重定位、EVC、DCL 列入强制模块 M0，预算不足则全面拒证而非静默降级 | 强制模块成本高，低预算下可用性可能归零 |
| R3 | 陈旧地图保守提升为占据 → 自由空间塌缩，可用性骤降 | 中 | 1) 主动重观测高价值陈旧单元；2) 分级 T_fresh（关键通道更严）；3) 提升仅作用于计划所用单元，不全局膨胀 | 动态场景中 T_fresh 难调，过严则寸步难行 |
| R4 | 成本台账本身的开销与被「做账」博弈 | 中 | 1) 能量以 EVC 硬件计量为准，禁止软件自报；2) Merkle 链防篡改；3) 台账开销计入预算上限而非隐藏 | 计量硬件故障或被旁路 |
| R5 | 主动 SLAM 探索越过认证前沿进入未知 | 中 | 移动动作强制过 admits_motion；传感器可看未知、机体不得进未知；前沿探索带急停半径 | 高速动态障碍可能瞬间吞掉急停半径 |

## 6. 本轮最大风险（最终确认）

**一句话**：SLAM 的协方差在退化场景（长走廊/玻璃幕墙/动态人群）会系统性低估漂移，使 SFC 以「乐观的有限 ε_loc」通过；而预算紧张时 BCS 恰好优先削减最昂贵的回环检测与重定位——「省成本」于是变成「省掉纠偏」，两者叠加会让证书边界在真实漂移下失效，这是**成本控制与定位保真在退化场景下的共振失效**。
