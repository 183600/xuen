# 第 44 轮（新循环第 4 轮） · GenTask-Cert × MonoModel-Cert：把「通用机器人」与「单模型多任务」纳入可验证证书闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形边际覆盖 + 多用户契约空集」，但在它之下仍压着两个未言明的单点假设：**(H1) 任务是外生且无歧义的**——证书默认条件在一个已知、稳定的任务/目标上，任务切换被当成一次安全模式切换；**(H2) 任务之间的证书是相互独立的**——策略按任务隔离，任务 i 的证书不受任务 j 的训练/更新影响。真实「通用机器人」恰好同时击穿这两条：**通用**意味着任务来自开放分布、必须从指令与场景中推断，且机器人不可能事先知道自己能力的边界；**单模型多任务**意味着所有任务共享同一套参数，为任务 j 做一次更新可以在没有任何显式告警的情况下侵蚀任务 i 的证书。本轮灵感词「通用机器人」「单模型多任务」精确命中：**通用机器人**迫使我们把「通用性」从营销词变成**可审计的已证任务集合 + 能力包络**；**单模型多任务**迫使我们把「共享参数」从实现细节升级为**证书之间的显式耦合**。二者耦合处（任务歧义 × 证书侵蚀）才是真正的新问题：机器人最危险的时刻不是做错动作，而是**拿着一张任务认错、或模型版本已过期、却仍然显示为合法的证书**去执行。

## 0. 直觉与动机

**灵感 1（通用机器人 → 通用性不是「一个什么都会的策略」，而是「一个可审计的持证任务组合」）**：直觉上「通用机器人」像一个万能工人，但工程上它更应像**一家有资质清单的事务所**：每项业务有执照、有适用范围、有有效期，超出范围必须拒接或转介。因此把通用性定义为**能力包络 + 已证任务集合 G**：对每个任务 τ，能力证书 K_τ 回答「我在什么状态域内、以多大成功概率做得成」，安全证书 C_τ 回答「我在做 τ 时不会越界」；二者都带模型版本与有效期。**通用宣称 = G 中每一项都可查、可复验、可撤销**。机器人还必须会「知道自己不会」：任务落在 K_τ 的定义域外或任务后验不集中时，正确动作不是硬做，而是询问、分解成已证子任务、或安全停机。一句话：**通用性是被审计出来的，不是被声明出来的。**

**灵感 2（单模型多任务 → 共享参数把「证书」变成了耦合变量）**：直觉上多任务学习是「一个模型学很多本事」，但安全视角下它是一个**隐式的共享写集**：为任务 j 更新参数 Δθ_j，会同时改写任务 i 的能力边际与安全边际。正向迁移是红利，**负向迁移是 soundness bug**——旧任务仍然挂着「已认证」，真实边际却已跌破阈值。这与第 43 轮并发中的「陈旧读/撕裂读」同构，只是陈旧源从时间戳变成了模型版本。于是需要三件套：**(a) 干扰矩阵 E**——显式测量任务 j 的更新对任务 i 证书的侵蚀；**(b) 证书非回归闸门**——任何更新必须证明不把保留任务的证书推过其下限，否则重认证、回滚或迁移到隔离适配器；**(c) 脆弱任务冻结 + 共享核门控的混合隔离**——把最贴近阈值或最高关键级的任务放进只读适配器，其余共享主干但逐次过闸。一句话：**单模型不是免费的：它用共享参数换样本效率，代价是证书之间多了一张必须申报的耦合图。**

**灵感 3（耦合 → 任务歧义 × 证书侵蚀 = 两类「静默失效」）**：通用机器人会同时遭遇两种静默失效：**任务认错**——把 τ₂ 的指令当成 τ₁，于是套用了错误的证书；**版本过期**——模型已被为某个新任务更新过，旧任务的证书却还按旧版本被使用。二者都不是「动作算错」，而是**证书与真实条件脱钩**。因此需要**二维信任**：任务信任（任务后验/能力包络/分布外检测）× 模型信任（证书-版本绑定/非回归/新鲜度）。任一维失效都必须回退到交集证书、询问、或安全停机。二者耦合还给出一个非平凡结论：**任务歧义集会放大干扰风险**——因为不同候选任务可能依赖不同的任务头/适配器，错误任务会选到未维护的那一支。压力测试必须按「任务 × 更新序 × 交错」组合枚举，而不是分别测。

**耦合升级**：TCC（任务能力证书引擎）把开放指令编译成任务后验、能力包络与任务条件证书；MCG（单模型多任务证书闸门）用干扰矩阵、非回归闸门与混合隔离保证跨版本证书不被静默侵蚀；TMV（任务混合验证器）用任务歧义、干扰序、切换/组合对抗把反例回灌 CKB 与 SCV。四层架构由 v8 的「仿真-检索-边缘飞轮 + 人格/并发层」升级为 v9 的「**任务能力与会话证书层**」。

## 1. 形式化定义（增量：定义 44–50）

**定义 44（任务空间、任务后验与歧义集）**：任务 τ=(g_τ, c_τ, φ_τ, ρ_τ)：目标、上下文前提、成功谓词、风险画像。给定指令 o 与状态 x，任务推断给出后验 p(τ|x,o)。**歧义集** T_ε(x,o) 是满足 P(τ*∈T_ε) ≥ 1−ε 的最小后验质量集（credible set，用分层共形/温度标定校准）。**任务可分辨** iff |T_ε|=1，或虽 |T_ε|>1 但存在一个对 T_ε 全体都合法的动作/策略。**注**：任务身份是潜变量而非输入标签；把 p(τ|x,o) 当 one-hot 用，正是通用机器人最典型的静默失效来源。

**定义 45（任务能力证书与能力包络）**：K_τ=(D_τ, β_τ, η_τ, v)。D_τ⊆(X×O) 为标定覆盖的能力域；在 x∈D_τ 上，以置信度 1−η_τ 有 P(success | τ, x) ≥ 1−β_τ；v 为模型版本。配套分布外判据 g_τ(x)≤γ，否则 K_τ 不适用。**能力包络** D_τ 是「我确实会做 τ」的区域，与安全证书 C_τ（「做 τ 时不越界」）正交：会做且安全才进入 G；会做但不安全可做保守子任务；不会做则必须先询问/分解/拒接。

**定义 46（任务条件安全证书与歧义集求交）**：任务条件证书 C_τ = C_global ∩ Π_u ∩ Φ_τ，其中 Φ_τ 是任务特异的守卫谓词（速度/接触/区域/工具约束）。歧义集上的证书 C_{T_ε} = ⋂_{τ∈T_ε} C_τ。**命题（歧义 sound 性）**：若真实 τ*∈T_ε 且每个 C_τ sound，则任何停留在 C_{T_ε} 内的轨迹对 τ* sound。**推论**：C_{T_ε}=∅ 时不得静默择一，必须走「询问消歧 / 已证子任务 / 安全停机」三选一；消歧动作本身也要有证书。

**定义 47（多任务干扰矩阵与证书侵蚀）**：设共享参数为 θ，为任务 j 的更新为 Δθ_j。定义对保留任务 i 的**证书侵蚀** e_{ij}=max(0, m_i(θ) − m_i(θ+Δθ_j))，其中 m_i 是任务 i 的认证边际下界（由任务探针集上的 LCB 估计）；能力侵蚀 d_{ij}=max(0, β 界的增量)。**干扰矩阵** E=[e_{ij}]、D=[d_{ij}]。**注**：e_{ij}<0 表示正向迁移，是红利而非义务；证书只对 e_{ij}>0 设预算。干扰矩阵必须在**同一任务探针集**上测，且探针集本身要按任务分层，否则会重蹈「边际覆盖被平均掉」的覆辙。

**定义 48（单模型多任务证书非回归闸门与混合隔离）**：把已证任务分为冻结集 F（只读适配器/任务头，更新不写）与共享集 S（共享主干，更新可写）。更新 Δθ_j 被接受，当且仅当：
(1) **新任务可证**：K_{τ_j} 有效且 C_{τ_j}≠∅；
(2) **冻结不变**：∀i∈F，θ_i 不变（结构上不可写）；
(3) **共享非回归**：∀i∈S，m_i(θ+Δθ_j) ≥ max(θ_i, m_i(θ)−b_i)，其中 b_i 为任务 i 的侵蚀预算，θ_i 为守卫下限。
否则必须显式选择：对 i 重认证、把 i 迁入 F、回滚 Δθ_j。**非静默失效定理**：在 (a) 标定/LCB sound、(b) 探针集覆盖被写任务的前提下，任意被接受的更新序列都不会让任何保留任务在「仍标记为 certified」时跌破其下限；任何跌破都必须以重认证/迁移/撤销事件显式出现。**证明要点**：对更新序列归纳；F 不变，S 每次被闸门检查，新任务仅在双证通过后入 G；版本哈希变更使未复验证书失效，故不存在「旧证书 + 新模型」的合法组合。**混合隔离策略**：F 取「边际最接近阈值 + 最高关键级 + 历史上被侵蚀过」的任务，S 为其余；这给出零静默失效、近似满采纳、适配器数量可控的折中（见产物区机制检验）。

**定义 49（任务切换与组合的证书连续性）**：从 τ₁ 切到 τ₂ 的**交班集** H_{12}=C_{τ₁}∩C_{τ₂}；合法切换要求在执行切换原语时始终位于 H_{12}，否则走安全停机或询问。**组合任务** τ₁∘τ₂ 的证书定义为 C_{τ₁∘τ₂}=C_{τ₁} ∩ pre_{τ₁}^{-1}(C_{τ₂})（先满足 τ₁ 的守卫，再到达 τ₂ 可接管的状态集）。**命题（组合 sound 性）**：若 C_{τ₁}、C_{τ₂} 各自 sound，且切换瞬间在 H_{12} 内，则顺序组合 sound；H_{12}=∅ 时组合必须被拒绝或插入已证的桥接任务。这把「任务切换」从调度事件变成必须持证的接口。

**定义 50（通用性账本与无静默撤销）**：通用性账本 L 对每个任务 τ 记录 (v, hash_θ, K_τ, C_τ, 干扰预算 b_τ, 探针集版本, 最近复验时刻, 状态∈{certified, degraded, revoked, pending})。**无静默撤销不变式**：账本中状态转换只允许经显式事件（新证、降级、撤销、迁移），且任何 revoked 任务不得再被路由；版本变更时，未复验任务自动转 pending 而非默认 certified。**推论**：G(θ)={τ: L 中 certified 且版本匹配} 是可审计集合；「通用性增长」就是一次带闸门的 G 扩张，任何收缩都有账可查。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 TASK-COMPETENCE-CERT（TCC）任务能力证书引擎
1. **任务推断 + 歧义集**：开放指令/场景 → 任务后验 p(τ|x,o) → credible set T_ε；低质量/分布外时显式返回「未分辨」而非 argmax。
2. **能力包络标定**：按任务分层做 PAC/共形风险控制，得到 D_τ、β_τ、OOD 判据 g_τ；能力域外一律 abstain。
3. **任务条件证书编译**：把 Φ_τ 编译为 IP-51 守卫谓词、IP-53 监控器阈值表；证书绑定任务签名与模型版本。
4. **歧义求交与消歧**：输出 C_{T_ε}；空集时生成最小消歧询问/已证子任务/安全停机三选一，绝不静默择一。
5. **通用性账本**：维护定义 50 的 L，导出 G 与 pending/revoked 列表，供路由与审计消费。

### 2.2 IP-61 MULTITASK-CERT-GATE（MCG）单模型多任务证书闸门
1. **干扰测量**：更新前后在同一分层任务探针集上测 m_i、β_i，得到 E/D；用 Fisher/梯度投影等廉价代理做预筛，再用探针复核，代理只用于排序不用于放行。
2. **证书非回归闸门**：实现定义 48 的三条件；接受/重认证/迁移/回滚四选一，所有决策写账本。
3. **混合隔离**：脆弱任务进只读适配器（F），其余共享主干（S）；适配器容量作为显式预算，优先级 = 关键级 × 边际脆弱度。
4. **版本化证书与失效**：证书哈希绑定 (model_hash, task_signature, probe_version)；模型一变，未复验证书立即 pending。
5. **持续学习管线**：支持回放/正则/低秩适配，但**安全不依赖学习算法**——算法只影响「能否通过闸门」，不影响「闸门是否 sound」。

### 2.3 IP-62 TASK-MIX-VALIDATOR（TMV）任务混合验证器
1. **任务歧义对抗**：近义改写、复合指令、两个证书冲突的任务、执行中改任务；测任务认错导致的越界。
2. **更新序 fuzz**：任务顺序/排列/重复/回滚的对抗序列，测静默侵蚀与闸门捕获率；重点覆盖「先学 A 再学 B 破坏 A」。
3. **切换/组合 fuzz**：交班集为空、部分可观测、任务重入、桥接任务缺失。
4. **账本审计**：跨版本回放检查无静默撤销、无「新模型 + 旧证书」、无 pending 被路由。

## 5. 本轮最大风险

**一句话**：非回归闸门的 soundness 完全建立在「任务探针集的标定/LCB 有效、且干扰矩阵覆盖真实更新分布」之上——一个未被探针覆盖的任务、或一次分布漂移的更新，仍可能让证书在账本上「看起来合法」却已静默侵蚀，因此 E97/E98 必须是红线，且默认回退到「冻结主干 + 每任务只读适配器 + 显式撤销」这条永不静默的底线。

### IP-60 TCC：任务推断、能力包络与歧义求交
```
def infer_task(o, x, calib):
    p = calibrate(task_posterior(o, x), calib)      # 温度/集成/共形
    T = credible_set(p, epsilon)                    # P(tau* in T) >= 1-eps
    return p, T                                     # 低质量时不返回 argmax

def competence_cert(tau, x, model, delta):
    if not inside_domain(x, model.D[tau]):
        return None                                 # 能力域外 => abstain
    if ood_score(tau, x) > gamma[tau]:
        return None                                 # OOD => 重询/分解
    beta = pac_risk_upper_bound(calib[tau], delta)  # PAC / 共形风险控制
    return CompetenceCert(D=model.D[tau], beta=beta,
                          eta=delta, v=model.hash)  # 绑定模型版本

def task_conditioned_cert(T, persona, C_global):
    C = intersect(C_global, persona.contract)
    for tau in T:
        C = intersect(C, Phi[tau], geometric_cert(tau))
        if empty(C):
            return Negotiation(disambiguate(T) or certified_subtask(T)
                               or safe_stop())        # 绝不静默择一
    return C

def plan_with_competence(o, x, model, persona):
    p, T = infer_task(o, x, calib)
    if not resolved(T):
        return ask_or_decompose(T, p)               # 先消歧，再做
    C = task_conditioned_cert(T, persona, C_global)
    for tau in T:
        if competence_cert(tau, x, model, delta) is None:
            return abstain_or_reask(tau)            # 会做 ≠ 安全
    return planner(C, task=T, version=model.hash)   # 规划消费双证
```

### IP-61 MCG：干扰测量、非回归闸门与混合隔离
```
def interference_probe(model, cand, tasks, probe_sets):
    E, D = {}, {}
    for i in tasks:                                 # 分层任务探针集
        m_old = lcb_margin(model,    i, probe_sets[i])
        m_new = lcb_margin(cand,     i, probe_sets[i])
        E[i] = max(0.0, m_old - m_new)              # 负值为正向迁移
        D[i] = max(0.0, beta_old(model, i) - beta_new(cand, i))
    return E, D

def admit_update(model, dtheta, j, F, S, probe_sets, budgets):
    cand = apply_update(model, dtheta, j)
    # (1) 新任务必须双证可证
    if competence_cert(j, x_probe, cand, delta) is None:
        return Reject("new-task-not-competent")
    if empty(safe_cert(cand, j)):
        return Reject("new-task-unsafe")
    # (2) 冻结集结构上不可写（适配器只读）
    assert write_set(cand, F) == set()
    # (3) 共享集非回归
    for i in S:
        m_old = lcb_margin(model, i, probe_sets[i])
        m_new = lcb_margin(cand,  i, probe_sets[i])
        if m_new < max(theta[i], m_old - budgets[i]):
            return escalate(i, cand)                # 重认证/迁移/回滚
    return Accept(cand, version=cand.hash)          # 写账本

def choose_isolation(tasks, margins, criticality, adapter_budget):
    # 脆弱度 = 边际接近阈值；关键级加权；历史侵蚀加分
    score = {i: criticality[i] / (margins[i] - theta[i] + eps)
             + erosion_history[i] for i in tasks}
    F = top_k(score, adapter_budget)                # 冻结最脆弱/最高关键级
    return F, set(tasks) - F

def escalate(i, cand, model):
    if competence_cert(i, x_probe, cand, delta) and \
       not empty(safe_cert(cand, i)):
        return recertify(i, cand)                   # 显式重认证（可降级）
    if adapter_budget_left():
        F.add(i)
        return migrate_to_adapter(i, cand)          # 迁入只读适配器
    return rollback(model)                          # 最后回滚

def certify_and_version(model, task_certs):
    h = model.hash
    for tau, cert in task_certs.items():
        cert.bind(model_hash=h, task_sig=sig(tau),
                  probe_version=probe_sets[tau].version)
        ledger.put(tau, cert, status="certified")
    return ledger
```

### IP-62 TMV：歧义、更新序、切换/组合与账本审计

```
def task_ambiguity_fuzz(suite, calib):
    for s in suite:                                 # 近义/复合/冲突/中途改任务
        p, T = infer_task(s.o, s.x, calib)
        C = task_conditioned_cert(T, s.persona, C_global)
        if not empty(C) and s.true_tau not in T:
            report("ambiguity-miss", s)             # 覆盖漏报
        if not empty(C):
            run_and_check(s, C)                     # 真实执行越界

def update_order_fuzz(base, tasks, orders, probe_sets):
    for order in orders:                            # 排列/重复/回滚序列
        model = base
        for j in order:
            model, ev = admit_update(model, dtheta_j, j, F, S,
                                     probe_sets, budgets)
            if ev.kind not in {ACCEPT, RECERT, MIGRATE, ROLLBACK}:
                report("illegal-gate-event", j)
            assert_no_silent_erosion(model, probe_sets, ledger)

def switch_compose_fuzz(tasks, pairs):
    for (t1, t2) in pairs:
        H = intersect(C[t1], C[t2])                 # 交班集
        if empty(H) and not safe_stop_available(t1):
            report("unsafe-switch", (t1, t2))
        comp = compose_cert(C[t1], C[t2])           # pre^{-1}(C[t2])
        if not subset(comp, C[t1]) or not subset(comp, C[t2]):
            report("composition-unsound", (t1, t2))

def ledger_audit(L, current_hash):
    for tau, rec in L.items():
        if rec.status == "certified" and rec.model_hash != current_hash:
            report("stale-cert-in-use", tau)        # 新模型 + 旧证书
        if rec.status == "pending" and routed(tau):
            report("pending-routed", tau)           # 未复验被路由
        if rec.status == "revoked" and routed(tau):
            report("revoked-routed", tau)
```

**核心定理（非静默失效）**：在 (i) 任务探针集上的 LCB/PAC 界 sound、(ii) 探针集覆盖被写任务、(iii) 证书与 (model_hash, task_sig, probe_ver) 绑定 的前提下，按定义 48 接受的任意更新序列都满足：任何仍标记为 certified 的任务，其证书在对应模型版本上 sound；任何失效都以 recertify/migrate/revoke 事件显式出现在账本。**证明**：对更新序列归纳。基础情形由初始双证成立；归纳步中 F 结构不可写，S 每个任务被 m_new ≥ max(θ_i, m_old−b_i) 检查，新任务仅在 K/C 双证后入 G；版本哈希变更使未复验证书转 pending（定义 50），故不存在「旧证书被当作新模型证书使用」的路径。因此不存在静默保留的失效证书。**注**：该定理是**条件定理**——前提 (i)(ii) 不成立时只退化为经验保证，这正是本轮最大风险。

| isolate（全量冻结适配器） | 117.10 | 50.25 | ≈0.1 | 0% | 117.1 |
| **hybrid（本文 IP-61）** | **86.30** | **49.25** | **≈0.1** | **0%** | **26.2** |

**解读**：naive 的「已认证」任务中约 32% 实际已跌破守卫下限——这正是单模型多任务最危险的静默侵蚀；只做重认证剔除会把可用任务从 ~117 砍到 ~66（可用性崩塌）；「一丝侵蚀即回滚」几乎冻结学习（60 次只采纳 9.75 个新任务，进度崩塌）；全量适配器隔离安全但适配器数量爆炸（117 个）。**hybrid 把最脆弱的 40% 任务冻结、其余共享核逐次过闸**，在零静默失效下保留 86.3 个已证任务、采纳 49.25 个新任务，且只用 26.2 个适配器（约为全量隔离的 1/4.5）。这为 IP-61 的「脆弱任务冻结 + 共享核门控」提供了机制层面的实证动机。**注意**：这是合成 toy，只检验机制方向，不代表真实机器人比率；真实硬门槛仍由 E97/E98 在仿真 + 实机上判定。

**回退**：E95 失守 → 强制操作员确认任务身份（放弃自主消歧）；E96 失守 → 只运行最高置信任务，其余拒接；E97/E98 失守 → 冻结主干，全部任务改只读适配器（放弃共享学习收益，保 sound）；E99 失守 → 禁止无安全停机的任务切换；E100 失守 → 回滚上一已证模型版本并全量重验；任何红线失败 → 全链路熔断回退 v20。

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 探针集不覆盖真实更新分布，闸门对未探任务失效（静默侵蚀） | 高 | E97/E98 红线；探针集按任务分层且版本化；默认冻结主干 + 适配器；保守 LCB；未探任务不得 certified |
| 任务后验/歧义集标定失准，认错任务却套用「合法」证书 | 高 | E95 红线；credible set 共形校准；低后验质量强制询问；歧义求交为空必协商停机 |
| 能力包络与安全证书混为一谈，把「会做」当「安全」 | 高 | K_τ 与 C_τ 分离双证；能力域外/OOD 一律 abstain；G 只收双证任务 |
| 干扰代理（Fisher/梯度）排序失真，漏掉真实侵蚀 | 中-高 | 代理只用于预筛排序，不用于放行；探针复核裁决；E97 测代理排序相关性 |

## 6. 本轮最大风险

**一句话**：非回归闸门的 soundness 完全建立在「任务探针集的标定/LCB 有效、且干扰矩阵覆盖真实更新分布」之上——一个未被探针覆盖的任务、或一次分布漂移的更新，仍可能让证书在账本上「看起来合法」却已静默侵蚀，因此 E97/E98 必须是红线，且默认回退到「冻结主干 + 每任务只读适配器 + 显式撤销」这条永不静默的底线。
