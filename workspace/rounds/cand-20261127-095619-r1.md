### 第 1 轮灵感驱动研究记录（语言—桌面维度，v25→v26）

**灵感词**：桌面操作、自然语言指令

**直觉与动机**：
前序 v18→v25 的证书塔已经把「感知—合规—能量—结构—语义—重构—协同—成本—记忆—规模」逐一形式化，但它默认任务目标已经是一个良构的几何/语义目标。真实桌面场景的第一性问题恰恰发生在目标之前：用户说「把左边那个杯子放进托盘，小心别碰倒水壶」。这句话同时包含指代消解（左边那个）、空间关系（左/放进/碰倒）、动作意图（放、避免）与安全偏好（小心）。语言是组合的、欠定的、上下文相关的；桌面是杂乱的、遮挡的、带支撑/容纳/铰接关系的、接触丰富的。二者之间缺一座桥：从「语言谓词」到「物理谓词」的保序映射。

核心洞见：**自然语言指令是证书系统的查询语言，桌面操作是它的物理解释器；指令接地的本质是构造一个从语言蕴涵代数到物理谓词代数的证书同态（certificate homomorphism），从而把「逐句联合验证」降为「逐原子验证 + 保序组合」。** 但同态只在受限文法内成立，因此证书必须显式标注自己的定义域，越界即拒绝走捷径。

**形式化目标**：
1. 定义指令接地证书（IGC）：u ↦ τ=(O,R,A,≺)。用 conformal 非一致性分数 s(u,τ) 控制「正确计划被误拒」，用负样本 PAC 上界控制「错误计划被误收」，使 ℙ(τ⊭u | accept)≤α_lang 且 ℙ(reject | τ correct)≤α_rej；对每个指代表达给出唯一消解或显式歧义集。
2. 定义桌面可供性—可达性证书（TARC）：对每个接地动作 a@o，验证 Aff(o,a)、稳健可达（IK 成功率 + 可操作度）、抓取力闭包裕度、支撑/容纳/遮挡一致性、无碰撞运输、以及执行后置条件。
3. 定义语言—物理同态 φ:(L,⊓,⊔,⊨)→(P,∧,∨,⇒)，证明受限指令文法下 φ 保序，使组合指令的证书可由原子证书线性合成；越界文法一律拒绝同态捷径。
4. 构建语言—桌面统一准入门（LTUC）：Exec_v26 = Exec_v25 ∩ Fil_lang ∩ Fil_afford ⊆ Exec_v25；歧义→澄清暂停，不可达→重规划，不可接地→拒绝并解释，全部 fail-closed 回退到 Exec_v25。
5. 证明单调退化链在「语言误接地 / 可供性失配 / 组合歧义」三类失效下的保持性。

**本轮最大风险（一句话）**：语言—物理同态只在受限文法内成立，而 LLM 解析器是整个证书链的「信任根」；一旦自由语言越过文法边界，系统可能给出形式合法却语义错误、且物理上确实可执行的证书，把「事前拦截」变成「合法地做错事」。

## 2. 关键算法骨架（在 IP-450 骨架上扩展）

```python
# ============================================================
# IP-451 Instruction Grounding Certificate (IGC) — 指令接地证书
# ============================================================
@dataclass
class InstructionGroundingCertificate:
    alpha_lang: float = 0.05          # 误收风险上界
    alpha_rej: float = 0.10           # 误拒风险上界（conformal）
    lambda_s: float = 0.2             # 结构违规惩罚权重
    eps_ref: float = 0.05             # 指代歧义裕度
    grammar: 'RestrictedGrammar' = None      # 受限时序/动作文法 Γ
    parser: 'LLMParser' = None               # 受约束解码（typed schema）
    entailment: 'EntailmentVerifier' = None  # 蕴含/NLI + 反译校验
    q_hat: float = None               # 正样本 conformal 分位数
    q_neg: float = None               # 负样本误收阈值

    def ground(self, u: str, scene: 'SceneGraph') -> 'GroundedTask':
        # 受约束解码：只允许 schema 内的对象/关系/动作，降低幻觉面
        return self.parser.parse(u, scene, schema=TASK_SCHEMA)

    def nonconformity(self, u: str, tau: 'GroundedTask') -> float:
        ent = self.entailment.score(u, tau)          # ∈[0,1]
        return (1.0 - ent) + self.lambda_s * self._structural_violation(tau)

    def calibrate(self,
                  positives: list[tuple[str, 'GroundedTask']],
                  negatives: list[tuple[str, 'GroundedTask']],
                  delta: float = 0.05) -> None:
        """双向校准：正样本给 conformal 分位；负样本给误收 PAC 上界"""
        pos_scores = torch.tensor([self.nonconformity(u, t) for u, t in positives])
        n = len(pos_scores)
        # 有限样本、无分布假设的 split-conformal 分位
        self.q_hat = torch.quantile(pos_scores, min(1.0, (1 - self.alpha_rej) * (1 + 1 / n))).item()
        neg_scores = torch.tensor([self.nonconformity(u, t) for u, t in negatives])
        self.q_neg = clopper_pearson_upper_threshold(neg_scores, self.alpha_lang, delta)

    def verify_grounding(self, u: str, tau: 'GroundedTask') -> bool:
        if self.q_hat is None or self.q_neg is None:
            return False
        s = self.nonconformity(u, tau)
        # 同时低于「误收阈值」；若过于宽松地低于正样本分位也仅为必要条件
        return s <= min(self.q_hat, self.q_neg)

    def verify_reference_resolution(self, u: str, tau: 'GroundedTask'
                                    ) -> tuple[bool, list]:
        unresolved = []
        for r in extract_referring_expressions(u):
            cand = self._resolve(r, tau, tau.scene_graph)
            if len(cand) == 0:
                unresolved.append((r, 'no_referent'))
            elif len(cand) > 1 and self._ambiguity_margin(cand) > self.eps_ref:
                unresolved.append((r, tuple(cand)))   # 触发澄清
        return (len(unresolved) == 0, unresolved)

    def verify_compositionality(self, u: str, tau: 'GroundedTask') -> bool:
        if not self.grammar.membership(u):        # ¬Γ(u)
            return False                          # 禁止同态捷径，交回联合验证
        clauses = self.grammar.decompose(u)
        for c in clauses:
            tau_c = tau.restrict_to(c)
            if not self.verify_grounding(c, tau_c):
                return False
        return self._compose_consistent(clauses, tau)

    def _structural_violation(self, tau: 'GroundedTask') -> float:
        # 未绑定对象、悬空关系、不可拓扑排序的偏序 ≺ 等
        v = 0.0
        v += float(any(o not in tau.scene_graph.objects for o in tau.O))
        v += float(any(not relation_well_typed(r, tau) for r in tau.R))
        v += float(not is_dag(tau.precedence))
        return v

    def _resolve(self, r, tau, scene):
        return match_referring_expression(r, scene, context=tau.context)

    def _ambiguity_margin(self, cand) -> float:
        scores = sorted((c.score for c in cand), reverse=True)
        return scores[0] - scores[1] if len(scores) > 1 else 1.0


# ============================================================
# IP-452 Tabletop Affordance-Reachability Certificate (TARC)
# ============================================================
@dataclass
class TabletopAffordanceCertificate:
    eps_reach: float = 0.01           # 稳健可达失败容忍
    mu_min: float = 0.05              # 可操作度下界
    grasp_margin_min: float = 0.10    # 抓取闭包裕度下界
    delta_place: float = 0.005        # 放置容差 (m)
    n_pose_samples: int = 32

    def verify_action(self, a: 'GroundedAction', robot: 'RobotModel',
                      scene: 'SceneGraph') -> tuple[bool, str]:
        if not self.verify_affordance(a, scene):
            return False, 'affordance'
        if not self.verify_reachability(a, robot, scene):
            return False, 'reachability'
        if not self.verify_grasp(a, scene):
            return False, 'grasp'
        if not self.verify_transport(a, robot, scene):
            return False, 'transport'
        return True, 'ok'

    def verify_affordance(self, a, scene) -> bool:
        o = scene.objects[a.object_id]
        if a.primitive == 'pick':
            return o.gripper_width_ok and o.has_antipodal_grasp
        if a.primitive == 'place':
            return scene.support_available(a.target_id) and not scene.occupied(a.target_id)
        if a.primitive == 'open':
            return o.is_articulated and o.handle_reachable and not o.is_locked
        if a.primitive == 'pour':
            return o.is_container and o.open_top
        if a.primitive == 'push':
            return o.is_movable
        return False

    def verify_reachability(self, a, robot, scene) -> bool:
        """ℙ(IK ∧ 无碰 ∧ μ≥μ_min) ≥ 1-ε_reach，对对象位姿不确定性采样"""
        poses = scene.object_pose_distribution(a.object_id).sample(self.n_pose_samples)
        ok = 0
        for p in poses:
            q = robot.ik(a.approach_pose @ p, seed=a.seed)
            if (q is not None and robot.collision_free(q, scene)
                    and robot.manipulability(q) >= self.mu_min):
                ok += 1
        return ok / self.n_pose_samples >= 1.0 - self.eps_reach

    def verify_grasp(self, a, scene) -> bool:
        if a.grasp is None:
            return False
        return force_closure_margin(a.grasp, scene.friction) >= self.grasp_margin_min

    def verify_transport(self, a, robot, scene) -> bool:
        return robot.path_collision_free(a.pre_grasp, a.place_pose, scene)

    def verify_support_containment(self, scene_after: 'SceneGraph') -> bool:
        g = scene_after.support_graph()
        return is_dag(g) and all(scene_after.is_supported(o) for o in scene_after.objects)

    def verify_postcondition(self, a, scene_after) -> bool:
        return a.post_predicate(scene_after)    # 如 on(cup, tray) ∧ in(cup, tray)

    def verify_plan(self, tau, robot, scene) -> tuple[bool, str]:
        # 准静态假设 A1：已知刚体/已知铰接模型/确定性仿真
        scene_cur = scene
        for a in tau.actions:                     # 已按 ≺ 拓扑排序
            ok, why = self.verify_action(a, robot, scene_cur)
            if not ok:
                return False, f'{a.id}:{why}'
            scene_cur = simulate(a, scene_cur)    # 推进中间场景
            if not self.verify_support_containment(scene_cur):
                return False, f'{a.id}:support'
        for a in tau.actions:
            if not self.verify_postcondition(a, scene_cur):
                return False, f'{a.id}:postcondition'
        return True, 'ok'


# ============================================================
# IP-453 Language-Tabletop Unified Certificate (LTUC) — v26 准入门
# ============================================================
@dataclass
class LanguageTabletopUnifiedCertificate:
    base: 'CostMemoryScalableUnifiedCertificate'   # v25 八证门
    igc: InstructionGroundingCertificate
    tarc: TabletopAffordanceCertificate

    def admits(self, u: str, scene: 'SceneGraph', robot: 'RobotModel',
               base_plan: 'MultiRobotPlan') -> tuple[bool, dict]:
        tau = self.igc.ground(u, scene)

        # 1) 语言层：先澄清，再接地，再组合
        ref_ok, amb = self.igc.verify_reference_resolution(u, tau)
        if not ref_ok:
            return False, {'status': 'clarify', 'ambiguity': amb}
        if not self.igc.verify_grounding(u, tau):
            return False, {'status': 'reject', 'reason': 'ungrounded'}
        if not self.igc.verify_compositionality(u, tau):
            return False, {'status': 'reject', 'reason': 'grammar_out_of_domain'}

        # 2) 物理层：逐动作可供性/可达/抓取/运输/后置条件
        ok, why = self.tarc.verify_plan(tau, robot, scene)
        if not ok:
            return False, {'status': 'replan', 'reason': why}

        # 3) 基础 v25 证书：语言层只能收窄，不能旁路
        if not self.base.admits(base_plan):
            return False, {'status': 'reject', 'reason': 'base_certificate'}

        return True, {'status': 'admit', 'task': tau}

    def fallback(self, status: str) -> str:
        return {'clarify': 'pause_and_ask',
                'reject': 'refuse_with_explanation',
                'replan': 'invoke_geometric_replanner',
                'admit': 'execute'}.get(status, 'refuse')


# ============================================================
# 语言—物理同态：受限文法下的组合证书（避免 O(2^|A|) 联合验证）
# ============================================================
@dataclass
class LanguagePhysicalHomomorphism:
    def is_homomorphism(self, clauses, tau) -> bool:
        # φ(c1 ⊓ c2) = φ(c1) ∧ φ(c2)，且 ⊔/⊨ 保持
        return (self._meet_preserving(clauses) and
                self._join_preserving(clauses) and
                self._entailment_preserving(clauses, tau))

    def compose(self, clauses, atom_oks: list[bool]) -> bool:
        # 仅当 grammar.membership 为真时被调用
        return all(atom_oks)
```

## 4. 正确性论证（增量）

### 引理 16（IGC 的双向接地可靠性）
**陈述**：设正/负校准样本与测试样本可交换。取 q̂_α 为 conformal 分位、q̂_neg 为负样本上界阈值，并令 accept ⇔ s(u,τ)≤min(q̂_α, q̂_neg)。则：
(1) ℙ(reject｜τ 为正确计划) ≤ α_rej；
(2) 以置信度 1−δ，ℙ(τ⊭u｜accept) ≤ α_lang。
**证明**：正样本上用 split-conformal 的有限样本覆盖定理（Vovk et al. 2005；Angelopoulos & Bates 2021）直接得 (1)。负样本上用 Clopper–Pearson 二项上界给出误收率的一侧置信上界，取对应阈值得 (2)。二者是不同的错误方向，必须分别校准；仅用正样本 conformal 只能控制误拒，不能控制误收。∎

### 引理 17（TARC 的局部到整体可靠性）
**陈述**：在假设 A1（已知刚体/铰接模型、确定性准静态仿真、动作序列已按 ≺ 拓扑排序）下，若 `verify_plan` 对每个动作通过且对每个中间场景通过支撑/容纳检查、对每个动作通过后置条件，则执行 τ 不会破坏 v25 的基础安全证书，且达到 τ 的目标关系。
**证明**：对动作序列做归纳。基例：初始场景合法。归纳步：`verify_action` 覆盖可供性、稳健可达、抓取闭包与运输；`simulate` 在 A1 下确定性地给出中间场景；`verify_support_containment` 排除悬空与支撑环；`verify_postcondition` 保证该步的语义目标。由 A1 的确定性，局部不变量沿序列传递。若任一检查失败则 fail-closed，不执行该后缀。∎（注：A1 被违反——如形变、透明、未知铰接——即引理不适用，见 R20。）

### 引理 18（受限文法同态的组合性与单调链）
**陈述**：若 Γ(u) 成立，则 φ 是 (L,⊓,⊔,⊨) 到 (P,∧,∨,⇒) 的同态，组合指令的证书可由原子证书合成；且任意子证书失效时 LTUC 拒证并回退到 Exec_v25，故 Exec_v26 ⊆ Exec_v25。
**证明**：
1. Γ(u) 将自由语言限制为类型化子句并可分解为 u=c₁⊓…⊓cₖ；同态性由 φ 的定义逐项检查（meet/join/entailment 保持）得证。
2. 组合证书 = ⋀ᵢ φ(cᵢ) = φ(⋀ᵢ cᵢ)，故原子通过 ⇒ 组合通过（在 Γ 内），避免指数联合验证。
3. 拒证路径：¬Ref、¬grounding、¬Γ、TARC 失败、base 失败，任一为真则 `admits=False`；而 `accept` 额外要求 `base.admits`，故 Exec_v26 = Exec_v25 ∩ Fil_lang ∩ Fil_afford。
4. 单调性：交集运算对集合单调，且所有分支 fail-closed。∎

### 定理（语言—桌面九维准入门完备性）
**陈述**：对任意指令 u 与多机计划 Π，`LTUC.admits(u,Π)=True` ⟺ Π 同时满足：(1) v25 的全部八证条件；(2) 指代消解唯一或已澄清；(3) 话语—计划接地 s(u,τ) 同时低于误收与误拒阈值；(4) Γ(u) 成立且组合一致；(5) 每个动作可供性成立；(6) 稳健可达；(7) 抓取力闭包；(8) 支撑/容纳/运输安全；(9) 后置条件达成。
**证明**：由 `admits` 的连言结构与引理 16–18 直接可得。必要性：任一条件失败即走对应失败分支（clarify/reject/replan），不会返回 admit。充分性：九条同时成立时，语言层给出语义正确且文法内可组合的 τ，物理层在 A1 下保证可执行且保持基础证书，故可安全执行。∎

## 7. 本轮最大风险（最终确认）

**一句话**：LLM 解析器是整个语言—桌面证书链的「信任根」，而语言—物理同态只在受限文法内成立——一旦真实指令越过文法边界或以隐含意图表达，系统可能签发一条形式合法、物理可执行、却语义错误的证书，使 v26 的「事前拦截」在语言维度退化为「合法地做错事」，这比 v25 的物理失效更难被残差监控发现。
