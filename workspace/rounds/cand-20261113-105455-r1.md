# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因闭环」IP-214~223；灵感循环第 1 轮；本轮灵感：「四足机器人」×「多机器人协作」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险正是下一轮必须接住的球：**VISTA 的归因能力依赖「故障属于有限假设集」与「视觉、几何、力觉的失效相互独立」；真实故障常是未知类型的复合，且透明、镜面、对抗 patch 会让多个通道共享同一个分布外失效源，此时 FIR 会把未知复合故障强行归入最近假设、只膨胀错误的球——系统还因为「已经归因」而更自信地继续执行。** 第 65 轮把独立性当成了论证的**隐藏前提（A88）**；本轮把它拉出来，变成一个必须被**测量、认证、并在失效时显式弃权**的对象。本轮核心命题是：
>
> **把「单机内、被假设独立的故障归因」升级为「跨足-跨机的多样性认证归因」：用四足机器人的四条腿与步态相位，把身体接触拆成组内物理冗余与可设计的受控激励；用多机器人协作把「独立失效」从假设变成资源，并用多样性证书与共因感知融合证明这份资源真的存在；当证书失效时，系统必须把「一致」判为无信息，而不是把票数当真理。**

## 0. 直觉与动机

**灵感 1（四足机器人 → 四条腿是「组内物理冗余」，步态是「可设计的激励器」）**
直觉：四足机器人有一个被 VISTA 完全没用上的结构——**它同时拥有四条彼此独立的接触链**。每条腿有自己的关节编码器、足端接触/力、支撑状态与运动学链；行走时四足在 stance/swing 间轮换，于是同一时刻总有「已接地的腿」可以给「正在接地的腿」当参照。这天然提供了两样东西：(i) **组内冗余**——单腿 F/T 偏置只会污染那一条腿的 stance 段，而质心/惯量误差会以对角线反对称的方式同时污染所有腿的载荷分配，二者的错误结构不同；(ii) **受控激励**——步态本身就是激励设计变量：**站立**几乎没有激励（静态下「单腿力偏置」与「质心估计误差」在载荷分配上共线、不可辨识），**小跑（trot）**让对角腿成对支撑、能把前后/左右解耦，**行走（walk）**提供单腿支撑窗口、可逐腿隔离，**踏步/轻点/重心转移**则制造已知的接触事件。VISTA 把「接近→轻触→承载」当作时间阶段；四足把这条时间轴扩成「**步态相位 × 支撑模式 × 腿**」的张量，使可辨识性第一次成为**可主动选择的**，而不是碰运气等出来的。但必须同样诚实：腿也会错——足端打滑、地形起伏、腿运动学标定误差、负载导致的质心偏移都会污染这条通道，而且四足做探针会**摔**。所以腿不是新的接地真值，而是**组内第三条可错证据 + 一个带摔倒风险的可控激励源**。

**灵感 2（多机器人协作 → 独立失效是资源，但必须被认证，不能被假设）**
直觉：第 65 轮最大的病是「共因失效」——视觉与几何可能被同一个透明/镜面/对抗物体一起骗过。多机器人看似是解药：不同视角、不同模态、不同接触史、不同本体，若它们都同意，OOD 物体要同时骗过所有机器人就难得多。但这个「解药」有一个致命前提：**它们的失效真的独立吗？** 现实是，三个机器人可能共享同一个预训练主干（同一个对抗 patch 可迁移）、同一张地图/同一套重定位（一起漂）、同一个时钟/同一套规划器（一起错拍）、同一片光照与同一个操作员（一起被误导）。此时**票数增加，独立信息却不增加**；朴素的独立似然乘积 `Π_i p(e_i|H)` 会把「相关的一致」当成「独立的一致」，得到虚假的、随机器人数指数增长的置信度——这就是**共识羊群（herding）**。所以本轮的关键不是「多加几个机器人」，而是把「独立」变成**可度量的资源**：估计故障相关矩阵，折算**有效独立通道数 n_eff**，并只在 n_eff 足够、且没有共享单点故障（shared single point of failure）时，才允许把一致性当证据；否则输出 `diversity_unobservable` 或 `consensus_uninformative`，退回保守单机。**「一致」本身不是真值，只是「独立票足够多」时的弱证据。**

**灵感 3（多机器人协作 → 观察者-扰动者的物理去相关）**
直觉：多机器人最独特的能力不是「多看几眼」，而是**物理分工**：让机器人 B 去移动、去换个视角、去轻推/轻踏制造激励，而机器人 A 停在接地状态、用自己未被扰动的传感器去测量。此时「执行器」与「传感器」被分到不同本体上，错误结构在物理上被拉开——B 的定位漂移不会直接改写 A 的接触读数，A 的力偏置也不会伪装成 B 的运动。这叫**观察者-扰动者（observer–mover）物理去相关**。但代价是：协作动作会引入新的共因——通信延迟、相对定位漂移、遮挡、以及「一起去撞同一件东西」。所以协作探针必须同时最大化「故障假设的互信息」与「有效独立性的增益」，并受团队安全包络约束；不能为了诊断把两机一起送进不可逆点。

**灵感 4（合流 → QUORUM：只有够数的「独立票」才构成证据）**
闭环：四足组内证据分解（LEG-CH，按腿×步态相位）→ 步态条件化签名与激励秩（GEF）→ 多样性/共因证书（CDC：估计相关矩阵、n_eff、共享单点故障）→ 共因感知分布式归因（D-FIR：用 n_eff 加权的对数意见池替代朴素乘积）→ 归因模糊时做足式/跨机主动判别探针（LBP：观察者-扰动者配对，互信息按相关性折算）→ 团队安全证书与认证共识前缀（TSC：定位协方差 + 消息陈旧度 + 摔倒围堵 + 通信中断降级）→ 归因定向球 RSC-Q / 团队搜索域 WCV-Q / 团队块技能 CSP-Q / 跨具身对抗认证 AIC-Q → J_quorum。第 65 轮是「几何-技能-干扰-接触-归因」五层；QUORUM 加的是第六层「**群体/多样性**」，并把「独立」从证明的假设变成证明的对象。命名取「法定人数」之意：**凑不齐真正独立的票，共识就不算数。**

**灵感 5（VISTA 组件的原位升级）**
- **FIR → D-FIR**：从单机后验升级为「本地后验 + 相关感知融合」；朴素 `Π p_i` 改为 `n_eff` 加权对数意见池，相关证据自动降权，冲突则判 ambiguous。
- **VCV → VCV-Q**：视觉接触验证扩展为「跨视角接触验证」；两个视角若共享同一相机/同一光照则不计为独立票。
- **AFA → LBP**：探针集加入足式动作（stand/trot/walk/step/tap/weight-shift）与跨机动作（observe/mover/relay/viewpoint/standoff/cross-touch），目标从「故障假设互信息」升级为「**扣除了相关性折扣的**故障假设互信息」。
- **CSC → TSC**：单机认证前缀扩为「团队认证前缀 k_team*」，显式计入相对定位协方差、消息陈旧度 Δ_stale、通信中断与摔倒围堵。
- **RSC-V → RSC-Q**：不确定半径增 r_leg（腿/足端）、r_comm（通信/相对定位）；只膨胀被归因者；单机几何正确时不被队友的错误连坐。
- **WCV-V → WCV-Q**：搜索域由「证书有效的机器人」交集构成；被隔离/证书失效的机器人不得参与收缩。
- **CSP-V → CSP-Q**：新增团队技能 `observe`/`mover`/`relay`/`handoff`/`quarantine`/`fall_contain`，每条团队块边需 Valid(J_quorum)。
- **AIC-V → AIC-Q**：干扰集增共享主干迁移对抗、共享地图投毒、时钟失步、通信重放/丢弃、拜占庭机器人、足端打滑/地形/负载突变。
- **J_vista → J_quorum**：证书增 team_posterior、n_eff、diversity_cert_hash、agreement_kl、quarantined_set、k_team*、comm_staleness、fall_margin、common_cause_posterior。

## 1. 形式化定义（增量：定义 233–245）

- **定义 233（QUORUM 闭环）**：QUORUM = (VISTA, LEG-CH, GEF, CDC, D-FIR, LBP, TSC, RSC-Q, WCV-Q, CSP-Q, AIC-Q, J_quorum)。定位：VISTA 的「组内冗余 + 跨机多样性认证 + 团队安全」升级。不变式：**本地世界模型/归因/探针/证书在语义流；跨机融合、多样性认证、团队证书在低频线程；实时流只做本地残差、陈旧度有界的团队前缀执行、摔倒反射与早停，零学习写操作。且：没有有效多样性证书时，禁止把多机一致性并入归因。**
- **定义 234（足端证据分解 LEG-CH）**：四足腿集 𝓛={FL,FR,RL,RR}，步态相位 g_t∈{stance,swing}。每条腿的足端证据 z_ℓ=[b_ℓ 接触, f_n^ℓ 法向力, s_ℓ 切向滑移, v_ℓ^res 运动学残差, p_ℓ 载荷份额]ᵀ；载荷份额 p_ℓ=f_n^ℓ/Σ_ℓ f_n^ℓ，几何预测 p̂_ℓ(q) 由质心投影与支撑多边形决定。载荷转移残差 r_lt=‖p−p̂(q)‖²_Σ⁻¹。**单腿失效与全身惯性失效的签名在「对角线反对称性」上不同**：单腿偏置只改一条腿，质心/惯量误差改一对对角腿。
- **定义 235（步态条件化签名与激励秩 GEF）**：整块签名 ρ_Q=vec_{p,g,ℓ}(ρ_{p,g,ℓ})，其中 ρ_{p,g,ℓ}=[ē_vis,ē_force,ē_torque,d̄_chunk,ū_chunk,z_ℓ,r_lt]ᵀ；线性化 E[ρ_Q|θ]=S_Qθ。**步态激励秩** rank_g=rank(S_Q) 取决于步态：static 下 H_single-leg-force 与 H_body-com 的列在载荷分配上共线、秩亏；trot 把对角对分开；walk 的摆动腿窗口给出逐腿隔离；step/tap 注入已知接触事件。定义 κ_g=λ_min(S_QᵀΣ⁻¹S_Q)/λ_max(·)。
- **定义 236（共因失效模型与有效独立数 n_eff）**：设机器人 i 的归因错误事件 E_i，审计集上估计两两故障相关 ρ_ij；等相情形记 ρ̄。有效独立通道数
  **n_eff = n / (1 + (n−1)ρ̄)**，
  满足 n_eff→1/ρ̄（n→∞）。等价地，用共享潜变量 Z∈{0,1}（1=共因主导）写生成模型：Z=0 时各机证据在 H 下条件独立，Z=1 时各机共享同一被污染证据源。则关于 H 的信息不随 n 线性增长，而是被 H(Z) 与 p_Z 截断。**归因置信度是 n_eff 的函数，不是 n 的函数。**
- **定义 237（多样性证书 CDC）**：CDC 在审计分布上输出 (ρ_ij, n_eff, struct)。struct 检查共享单点故障：同一模型哈希、同一地图/重定位、同一时钟源、同一相机外参/同一光照、同一通信链路、同一操作员策略。**Valid(CDC) ⇔ max ρ_ij≤ρ_max ∧ n_eff≥n_min ∧ 无共享单点故障**；否则输出 `diversity_unobservable`，且其票数在 D-FIR 中不计入证据，只计入风险预算。
- **定义 238（D-FIR 共因感知分布式归因）**：各机本地后验 p_i(H)=P(H|ρ_Q,i)。融合用**对数意见池（log-opinion pool）**
  log P(H|e_{1:n}) ∝ Σ_i w_i log p_i(H) − (Σ_i w_i − 1) log p_0(H)，
  权重 w_i≥0、Σ_i w_i = n_eff，w_i ∝ 1/σ_i²。当 n_eff≈1 时退化为单机；当 n_eff 高时趋近独立融合。定义团队分歧 d_team=mean_{i,j} JS(p_i‖p_j)；若 d_team>τ_dis 或 max_H P(H|·)<1−δ_fi → `ambiguous`，进入 LBP，**不强行归因**。
- **定义 239（LBP 足式/跨机主动判别探针）**：探针集 A_Q={stand,trot,walk,step,tap,weight_shift,observe,mover,relay,viewpoint,standoff,cross_touch}。选择
  a*=argmax_{a∈A_Q} (1−ρ̄(a))·I(ℋ_Q;ρ_new(a)|ρ) / risk(a)，
  s.t. 每机 ZMP/支撑多边形、滑移、摔倒裕度、力/形变安全、保接触条件。关键是**相关性折扣 (1−ρ̄(a))**：与当前信念高相关的探针，即使名义互信息大也被折价；优先选能提高步态激励秩或降低共因不确定度的探针。
- **定义 240（团队安全证书与认证共识前缀 TSC）**：对团队计划与各机前缀 k_i，验证：(i) 本机安全（VISTA/CSC）；(ii) 机器人间分离
  ‖p_i−p_j‖ ≥ r_i+r_j+λ√λ_max(Σ_i)+λ√λ_max(Σ_j)+v_max·Δ_stale+m_safe，
  其中 Σ_i 为相对定位协方差、Δ_stale 为消息最大陈旧度；(iii) 共享工作区互斥/路权；(iv) 摔倒围堵：任一机支撑裕度<0 的预测触发降质心/伸腿/他机让距；(v) 通信中断即各机进入独立安全模式。输出 k_team*=min_i k_i* 与 m_team；执行到 k_team* 或首次陈旧度越界即强制重规划。
- **定义 241（RSC-Q / WCV-Q 归因定向与团队搜索域）**：不确定半径拆为 r_geo,r_force,r_model,r_vis,r_leg,r_comm，只膨胀被归因者；融合 r=√(Σr_·²)。WCV-Q 的搜索域只由 `Valid(CDC)` 的机器人交集构成，被隔离机（quarantined）不得参与收缩；碰撞间隙用相对定位协方差膨胀。
- **定义 242（CSP-Q 团队块级技能规划）**：团队技能 σ∈{observe,mover,relay,handoff,co_carry,escort,standoff,quarantine,fall_contain}；每条团队块边需 Valid(J_quorum) 且 k_team*≥1；技能绑定团队块签名分布 𝒟_σ，实际签名 Mahalanobis 距离>τ_team 即判 OOD、不入图；成本增 λ_fi·H(P(H|ρ)) + λ_div·(n_min−n_eff)_+。
- **定义 243（AIC-Q 跨具身对抗认证）**：ℰ_Q=ℰ_V×ℰ_leg×ℰ_team。ℰ_leg 含足端打滑、地形起伏、负载/质心突变、腿运动学标定误差、单腿传感器失效、步态切换暂态；ℰ_team 含通信延迟/丢弃/重放、时钟失步、相对定位漂移、共享地图投毒、**共享主干可迁移对抗 patch**、拜占庭机器人、同步的操作员错误。共因下**不要求归因正确，只要求判 `ambiguous`/`diversity_unobservable` 并进入 `quarantine + fall_contain + safe_idle`**。
- **定义 244（QUORUM 证书 J_quorum）**：(J_vista^(1..n), team_posterior, n_eff, diversity_cert_hash, agreement_kl, quarantined_set, k_team*, comm_staleness, fall_margin, common_cause_posterior, aic_q_ver)。Valid ⇔ 各机 Valid(J_vista) ∧ (归因确定 ∨ 已执行 LBP) ∧ k_team*≥1 ∧ (CDC 有效 ∨ 已显式弃权并退保守) ∧ 团队签名一致 ∧ 摔倒裕度与陈旧度在界内。
- **定义 245（QUORUM 算子）**：语义流 [各机 LiDAR/视觉→LSF→VISTA 本机归因→LEG-CH/GEF 步态签名→CDC→D-FIR 共因感知融合→LBP 跨机探针→WCV-Q/CSP-Q 团队规划→TSC 团队认证前缀→执行]；实时流 [本地残差+足端证据采集→步态相位判定→陈旧度监测→TSC 早停/摔倒反射→前缀派发→J_quorum 构建]。

## 2. 关键算法骨架

```python
# CDC：多样性不是假设，是证书
def effective_independence(n, rho_bar):
    return n / (1.0 + (n - 1.0) * rho_bar)     # n→∞ 时饱和到 1/rho_bar

def certify_diversity(robots, audit):
    rho = pairwise_failure_corr(robots, audit)  # 审计集故障相关，不是残差相关
    n_eff = effective_independence(len(robots), rho.mean_offdiag())
    shared = structural_spof(robots)            # 主干/地图/时钟/相机/链路/操作员
    ok = rho.max_offdiag() <= RHO_MAX and n_eff >= N_MIN and not shared.any()
    return Cert(ok, n_eff, rho, shared,
                reason=None if ok else 'diversity_unobservable')

# D-FIR：共因感知融合，绝不朴素连乘
def dfir_fuse(local_posts, prior, cert):
    if not cert.valid:
        return None, 'diversity_unobservable'   # 不融合，退回最保守单机
    w = cert.n_eff * softmax([-v for v in local_variances(local_posts)])
    logp = {h: sum(wi * log(pi[h]) for wi, pi in zip(w, local_posts))
               - (sum(w) - 1.0) * log(prior[h]) for h in HYP}
    post = softmax(logp)
    ambiguous = (mean_pairwise_js(local_posts) > TAU_DIS
                 or max(post.values()) < 1.0 - DELTA_FI)
    return post, ('ambiguous' if ambiguous else None)

# LBP：相关性折扣后的互信息
def choose_probe(A_Q, post, rho_hat, safety):
    best, best_score = None, -np.inf
    for a in A_Q:
        traj = predict_probe(a)                 # 足式/跨机轨迹
        if not safety.feasible(traj):           # ZMP/滑移/摔倒/力/形变
            continue
        ig = expected_mutual_info(post, a)      # I(H; rho_new)
        score = (1.0 - rho_hat(a)) * ig / safety.risk(traj)
        if score > best_score:
            best, best_score = a, score
    return best if best_score > DELTA_FI else None

# TSC：团队认证前缀（分离 + 陈旧度 + 摔倒围堵）
def team_certified_prefix(plans, certs, comm):
    ks = [min(csc.certified_prefix(P, post=c, ...),
              horizon_before_stale(comm, i)) for i, (P, c) in enumerate(zip(plans, certs))]
    k_team = min(ks)
    while k_team > 0 and not team_safe(plans, k_team, comm):  # 分离/互斥/围堵
        k_team -= 1
    return k_team
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（共因下的信息饱和）**：等相相关 ρ̄ 下，n 个证据的平均估计算子方差 ∝ (1+(n−1)ρ̄)/n = 1/n_eff；故 n→∞ 时方差→ρ̄σ²，置信度饱和在 1/ρ̄，**增加机器人不能突破共因给出的天花板**。朴素独立乘积把 ρ̄ 当 0，会在 p_Z>0 时给出虚假的指数级置信度。
- **引理 10（步态激励可辨识性）**：static 下 H_single-leg-force 与 H_body-com 的签名列在载荷分配上共线，S_Q 秩亏；trot 利用对角对反对称性、walk 利用单腿支撑窗口，可使对应列分开，κ_g>0。因此**可辨识性是可选择的**，不是静态属性。
- **定理 9（QUORUM 端到端）**：在 A94–A99 下，若 CDC 有效且 n_eff≥n_min，则归因后验错误率随 n_eff 指数集中，且只膨胀被归因的球；若 CDC 失效或 d_team 过高，则系统判 `diversity_unobservable`/`ambiguous`、退回保守单机或执行 LBP，**不会把相关一致当作独立证据**；团队前缀满足分离、陈旧度、摔倒围堵与通信中断降级。
- **定理 10（团队前缀的执行安全）**：若 k_team*≤m_team 且对每机、每个后验支持假设验证了本地与团队约束，则单块内团队越界概率 ≤ α_chunk+δ_fi+α_vis+α_comm+α_leg。故协作不引入超过单机的不可逆风险。

## 2. 形式化定义（完整版）

**定义 233（QUORUM 闭环）** QUORUM 是 VISTA 的「组内冗余 + 跨机多样性认证 + 团队安全」升级：保留每台机器人本地的 VISTA 闭环，挂载 LEG-CH（足端证据分解）、GEF（步态激励）、CDC（多样性证书）、D-FIR（共因感知分布式归因）、LBP（足式/跨机探针）、TSC（团队安全证书），并原位升级 RSC、WCV、CSP、AIC 与证书。不变式：**本地世界模型/归因/探针/证书在语义流；跨机融合、多样性认证、团队证书在低频线程；实时路径只做本地残差、足端证据、步态相位、陈旧度监测、团队前缀执行与摔倒反射，零学习写操作。没有有效多样性证书时，多机一致性不得并入归因。**

**定义 234（足端证据分解 LEG-CH）** 四足腿集 𝓛={FL,FR,RL,RR}，步态相位 g_t∈{stance,swing}。单腿证据
z_ℓ=[b_ℓ（接触指示）, f_n^ℓ（法向力）, s_ℓ（切向滑移）, v_ℓ^res（足端运动学残差）, p_ℓ（载荷份额）]ᵀ，
其中 p_ℓ=f_n^ℓ/Σ_{ℓ'}f_n^{ℓ'}，几何预测 p̂_ℓ(q) 由质心在支撑多边形上的投影与步态支撑模式决定；载荷转移残差 r_lt=‖p−p̂(q)‖²_Σ⁻¹。**错误结构分离**：(i) 单腿 F/T 偏置只在该腿 stance 段改变 f_n^ℓ 与 p_ℓ；(ii) 全身质心/惯量误差以**对角腿成对、而且前后/左右反对称**的方式改变 p；(iii) 足端打滑表现为 s_ℓ 与 v_ℓ^res 在 stance 段的不同步；(iv) 几何幻觉表现为足端落点/接触斑与视觉足迹冲突。四者不在同一低维子空间。

**定义 235（步态条件化签名与激励秩 GEF）** 对阶段 p∈{approach,touch,load}、步态相位 g、腿 ℓ，证据向量
ρ_{p,g,ℓ}=[ē_vis,ē_force,ē_torque,d̄_chunk,ū_chunk,z_ℓ,r_lt]ᵀ，
整块签名 ρ_Q=vec_{p,g,ℓ}(ρ_{p,g,ℓ})。线性化 E[ρ_Q|θ]=S_Qθ、ρ∼N(S_Qθ,Σ)。**步态激励秩** rank_g=rank(S_Q) 与可辨识裕度 κ_g=λ_min(S_QᵀΣ⁻¹S_Q)/λ_max(·) 依赖步态：
- `static`：载荷分配几乎不随运动变化，H_single-leg-force 与 H_body-com 的列在 p_ℓ 上共线，rank_g 亏缺；
- `trot`：对角腿成对支撑，前后/左右载荷的反对称组合可分；
- `walk`：存在单腿摆动窗口，可逐腿隔离；
- `step/tap/weight_shift`：注入已知足-地接触事件，直接激励单腿通道。
因此可辨识性是**可主动选择的变量**：`g* = argmax_g κ_g` 受团队安全约束。

**定义 236（共因失效模型与有效独立数 n_eff）** 设机器人 i 的归因错误事件 E_i。在审计分布 𝒟_audit 上估计两两故障相关 ρ_ij=Corr(1[E_i],1[E_j])，等相时为 ρ̄。有效独立通道数
n_eff = n / (1 + (n−1) ρ̄)，
当 n→∞ 时 n_eff→1/ρ̄。等价生成视角：共享潜变量 Z∈{0,1}，`Z=0`（独立）时 p(e_{1:n}|H)=Π_i p(e_i|H)；`Z=1`（共因）时各机观测到同一被污染源，Π_i p(e_i|H) 退化为单份证据。则
I(H; e_{1:n}) ≤ H(Z) + (1−p_Z)·Σ_i I(H;e_i|Z=0)，
额外信息被 p_Z 截断。**归因置信度是 n_eff 的函数，不是 n 的函数；一致性只有在 Z=0 的后验质量足够大时才可入账。**

**定义 237（多样性证书 CDC）** CDC 在审计分布上计算 (ρ_ij,n_eff,struct)，struct 显式检查共享单点故障：同一模型哈希/预训练主干、同一地图或重定位系统、同一时钟源、同一相机外参与同一光照、同一通信链路或同一操作员策略。**Valid(CDC) ⇔ max_{i≠j}ρ_ij≤ρ_max ∧ n_eff≥n_min ∧ struct 无共享单点故障**；否则输出 `diversity_unobservable`，其票在 D-FIR 中不计入证据，只计入风险预算，并要求各机退回本地 VISTA 保守模式。

**定义 238（D-FIR 共因感知分布式归因）** 各机本地后验 p_i(H)=P(H|ρ_Q,i)。融合用对数意见池（log-opinion pool）：
log P(H|e_{1:n}) ∝ Σ_i w_i log p_i(H) − (Σ_i w_i − 1) log p_0(H)，
w_i≥0、Σ_i w_i=n_eff、w_i∝1/σ_i²（σ_i² 为本地证据方差）。性质：n_eff=1 时退化为单机；n_eff=n 且无相关时趋近独立贝叶斯融合；中间值实现「相关证据降权」。团队分歧 d_team=mean_{i,j}JS(p_i‖p_j)；若 d_team>τ_dis 或 max_H P(H|·)<1−δ_fi，判 `ambiguous`，进入 LBP，**不强行归因**。若某机本地后验与其余机持续冲突，则进入候选隔离集。

**定义 239（LBP 足式/跨机主动判别探针）** 探针集
A_Q={stand,trot,walk,step,tap,weight_shift,observe,mover,relay,viewpoint,standoff,cross_touch}。
选择
a*=argmax_{a∈A_Q} (1−ρ̄(a))·I(ℋ_Q;ρ_new(a)|ρ) / risk(a)，
s.t. 每机 ZMP/支撑多边形、滑移率、摔倒裕度、接触力/形变安全、保接触条件。**相关性折扣 (1−ρ̄(a))** 惩罚与当前信念高相关的探针；`observe/mover` 由不同本体承担传感与扰动，`cross_touch` 让一机接触、另一机观测力/视觉，从而在物理上制造去相关。若最优探针的名义互信息高但折扣后低于 δ_fi，则拒绝探针，走保守观测。

**定义 240（团队安全证书与认证共识前缀 TSC）** 对团队计划与各机前缀 k_i，验证：
1. 本机安全：沿用 VISTA 的 CSC；
2. 机器人间分离：
   ‖p_i−p_j‖ ≥ r_i+r_j+λ√λ_max(Σ_i)+λ√λ_max(Σ_j)+v_max·Δ_stale+m_safe；
3. 共享工作区互斥/路权（同一自由空间块不得被两机同时占用）；
4. 摔倒围堵：任一机预测支撑裕度<0 时，先降质心/伸腿/减速，他机让出摔倒可能落区；
5. 通信中断或消息陈旧度 >Δ_stale：各机自动进入独立安全模式（停/站/回退），不再执行需要他机在场的技能。
用 conformal 选 k_team*=min_i k_i* 满足 P[前缀内违反(1–5)]≤α_team，并约束 k_team*≤m_team（团队不可逆视界，由制动距离、摔倒不可逆点与最小安全间距反解）。执行到 k_team* 即强制重规划与重归因。

**定义 241（RSC-Q / WCV-Q 归因定向与团队搜索域）** 不确定半径拆为 r_geo,r_force,r_model,r_vis,r_leg,r_comm，融合 r=√(r_geo²+r_force²+r_model²+r_vis²+r_leg²+r_comm²)。RSC-Q 只膨胀**被归因**者：H_geo→r_geo，H_force→r_force，H_model→r_model，H_vis→r_vis，H_leg→r_leg，H_comm→r_comm。WCV-Q 的搜索域由 `Valid(CDC)` 的机器人可行集交集构成；被隔离机（quarantined）不参与收缩；碰撞间隙用相对定位协方差膨胀；交集为空则 `quarantine` 冲突机并回退本地 WCV。

**定义 242（CSP-Q 团队块级技能规划）** 团队技能 σ∈{observe,mover,relay,handoff,co_carry,escort,standoff,quarantine,fall_contain}；每条团队块边需 Valid(J_quorum) 且 k_team*≥1。技能 σ 绑定团队块签名分布 𝒟_σ；实际签名到 𝒟_σ 的 Mahalanobis 距离>τ_team 即判 OOD，不入图。边成本增 λ_fi·H(P(H|ρ)) + λ_div·(n_min−n_eff)_+ + λ_k·Σ hinge(k_i*−k_req)，即**归因熵越高、独立票越少、可执行前缀越短，代价越大**。

**定义 243（AIC-Q 跨具身对抗认证）** ℰ_Q=ℰ_V×ℰ_leg×ℰ_team：
- ℰ_leg：足端打滑、地形起伏、负载/质心突变、腿运动学标定误差、单腿传感器失效、步态切换暂态；
- ℰ_team：通信延迟/丢弃/重放、时钟失步、相对定位漂移、共享地图投毒、**共享预训练主干上的可迁移对抗 patch**、拜占庭机器人、同步的操作员错误、同一光照/反光。
ρ_dir 在 ℰ_Q 上重算（n_cert 128→192，其中 32 给足式、32 给团队/共因）；共因项取最坏。J_dir 增 leg_calib_ver、team_sync_ver、diversity_audit_ver。**共因下不要求归因正确，只要求判 `ambiguous`/`diversity_unobservable` 并进入 `quarantine + fall_contain + safe_idle`。**

**定义 244（QUORUM 证书 J_quorum）**
J_quorum=(J_vista^(1..n), team_posterior, n_eff, diversity_cert_hash, agreement_kl, quarantined_set, k_team*, comm_staleness, fall_margin, common_cause_posterior, aic_q_ver)。
验证规则：
Valid(J_quorum) ⇔ 各机 Valid(J_vista)
∧ (归因确定 ∨ 已执行 LBP)
∧ (Valid(CDC) ∨ (已显式弃权 ∧ 各机退保守))
∧ d_team 在界内 ∧ k_team*≥1 ∧ 团队块签名与执行前缀一致
∧ fall_margin≥0 ∧ comm_staleness≤Δ_stale ∧ aic_q_ver 为当前版本。

### IP-225 CDC（多样性证书）

```python
class DiversityCertificate:
    """独立不是假设。审计集估相关 → 折算 n_eff → 检查共享单点故障。"""

    def __init__(self, rho_max=0.3, n_min=2.0, lambda_sep=3.0):
        self.rho_max, self.n_min, self.lambda_sep = rho_max, n_min, lambda_sep

    def effective_independence(self, n, rho_bar):
        return n / (1.0 + (n - 1.0) * rho_bar)      # n→∞ 饱和到 1/rho_bar

    def certify(self, robots, audit):
        rho = self._pairwise_failure_corr(robots, audit)   # 故障相关，非残差相关
        rho_bar = float(rho[np.triu_indices(len(robots), 1)].mean())
        n_eff = self.effective_independence(len(robots), rho_bar)
        shared = self._structural_spof(robots)     # backbone/map/clock/camera/link/operator
        valid = (rho.max(initial=0.0) <= self.rho_max
                 and n_eff >= self.n_min
                 and not shared.any())
        return Cert(valid=valid, n_eff=n_eff, rho=rho, rho_bar=rho_bar,
                    shared=shared,
                    reason=None if valid else 'diversity_unobservable')

    def _pairwise_failure_corr(self, robots, audit):
        # 对审计样本做故障注入/重放，记录每机是否归因错误
        fails = np.array([[robot.attribution_error(x) for x in audit] for robot in robots])
        return np.corrcoef(fails.astype(float))
```

### IP-226 D-FIR（共因感知融合）

```python
class DistributedFaultIsolation:
    HYP = ('H0', 'H_geo', 'H_force', 'H_model', 'H_vis', 'H_policy',
           'H_leg', 'H_comm')

    def local_posterior(self, rho_Q, lik, prior):
        logp = {h: np.log(lik[h](rho_Q) + 1e-12) + np.log(prior[h]) for h in self.HYP}
        z = np.array(list(logp.values())); z -= z.max()
        return {h: float(np.exp(v) / np.exp(z).sum()) for h, v in logp.items()}

    def fuse(self, local_posts, prior, cert, delta_fi=0.15, tau_dis=0.5):
        if not cert.valid:
            return None, 'diversity_unobservable'          # 不融合，退保守单机
        variances = np.array([self._post_var(p) for p in local_posts])
        w = cert.n_eff * softmax(-variances)               # Σw = n_eff
        logp = {}
        for h in self.HYP:
            logp[h] = (sum(wi * np.log(pi[h] + 1e-12)
                           for wi, pi in zip(w, local_posts))
                       - (w.sum() - 1.0) * np.log(prior[h] + 1e-12))
        z = np.array(list(logp.values())); z -= z.max()
        post = {h: float(np.exp(v) / np.exp(z).sum()) for h, v in logp.items()}
        d_team = self._mean_pairwise_js(local_posts)
        if d_team > tau_dis or max(post.values()) < 1.0 - delta_fi:
            return post, 'ambiguous'
        return post, None

    def _post_var(self, p):
        vals = np.array(list(p.values()))
        return float(-(vals * np.log(vals + 1e-12)).sum())   # 熵代理方差

    def _mean_pairwise_js(self, posts):
        js, m = 0.0, 0
        for i in range(len(posts)):
            for j in range(i + 1, len(posts)):
                js += js_divergence(posts[i], posts[j]); m += 1
        return js / max(m, 1)
```

### IP-224 LEG-CH / IP-235 GEF（足端与步态）

```python
class LeggedChannels:
    LEGS = ('FL', 'FR', 'RL', 'RR')

    def evidence(self, foot_state):
        z = {}
        total = sum(max(f.f_n, 0.0) for f in foot_state.values()) + 1e-9
        for leg in self.LEGS:
            f = foot_state[leg]
            z[leg] = np.array([float(f.contact), f.f_n, f.slip,
                               f.kin_residual, max(f.f_n, 0.0) / total])
        p = np.array([z[l][4] for l in self.LEGS])
        p_hat = self._predicted_load_share(foot_state)   # CoM × 支撑模式
        r_lt = float((p - p_hat) @ self._inv_cov() @ (p - p_hat))
        return z, r_lt

    def gait_excitation_rank(self, S_Q):
        J = S_Q.T @ self._inv_cov() @ S_Q
        return int(np.linalg.matrix_rank(S_Q)), float(np.linalg.eigvalsh(J)[0]
                                                      / max(np.linalg.eigvalsh(J)[-1], 1e-9))

    def choose_gait(self, S_Q_by_gait, safety):
        best = max((g for g in S_Q_by_gait if safety.feasible_gait(g)),
                   key=lambda g: self.gait_excitation_rank(S_Q_by_gait[g])[1])
        return best
```

class LeggedTeamProber:
    PROBES = ('stand', 'trot', 'walk', 'step', 'tap', 'weight_shift',
              'observe', 'mover', 'relay', 'viewpoint', 'standoff', 'cross_touch')

    def choose(self, A_Q, post, rho_hat, safety, phi_hat, f_safe):
        best, best_score = None, -np.inf
        for a in A_Q:
            traj = predict_probe(a, phi_hat)             # 含足式/跨机轨迹
            if not safety.feasible(traj):                # ZMP/滑移/摔倒/力/形变/分离
                continue

                best, best_score = a, score
        return (best, best_score) if best_score > DELTA_FI else (None, best_score)

### IP-228 TSC（团队认证前缀）

```python
class TeamSafetyCertificate:
    def __init__(self, alpha_team=0.01, lambda_sep=3.0, m_team=0.5):
        self.alpha_team, self.lambda_sep, self.m_team = alpha_team, lambda_sep, m_team

    def certified_prefix(self, plans, certs, comm, cov):
        ks = []
        for i, (plan, cert) in enumerate(zip(plans, certs)):
            k_local = csc.certified_prefix(plan.A, cert.post, m=self.m_team,
                                           alpha_chunk=self.alpha_team)
            k_stale = horizon_before_stale(comm, i, self.lambda_sep, cov[i])
            ks.append(min(k_local, k_stale))
        k_team = min(ks) if ks else 0
        while k_team > 0 and not self._team_safe(plans, k_team, comm, cov):
            k_team -= 1
        return k_team

    def _team_safe(self, plans, k, comm, cov):
        for i, j in combinations(range(len(plans)), 2):
            for s in range(k):
                gap = np.linalg.norm(plans[i].p[s] - plans[j].p[s])
                need = (plans[i].r + plans[j].r
                        + self.lambda_sep * (np.sqrt(eigmax(cov[i])) + np.sqrt(eigmax(cov[j])))
                        + plans[i].v_max * comm.staleness + M_SAFE)
                if gap < need:
                    return False
                if shares_exclusive_block(plans[i], plans[j], s):
                    return False
                if in_fall_landing_zone(plans[i], plans[j], s):
                    return False
        return True

    def fall_reflex(self, robot, support_margin):
        if support_margin < 0:
            return ('lower_com', 'extend_leg', ('others', 'yield_fall_zone'))
        return None
```

### IP-232 QUORUM 算子（整合）

```python
def QUORUM_round(team, obs_all, delta_f_req):
    # ———— 各机本地语义流 ————
    locals_ = []
    for robot, obs in zip(team.robots, obs_all):
        M, obs = robot.step_local(obs)                  # 复用 VISTA 语义流
        z_leg, r_lt = M.leg_ch.evidence(obs.foot_state)
        gait = M.leg_ch.choose_gait(M.S_Q_by_gait, M.safety)
        rho_Q = M.leg_ch.signature(M.residual_log, z_leg, gait, r_lt)
        post_i = M.dfir.local_posterior(rho_Q, M.lik, M.prior)
        locals_.append(LocalState(M, rho_Q, post_i, gait))

    # ———— 低频团队语义流 ————
    cert = team.cdc.certify(team.robots, team.audit)
    team_post, flag = team.dfir.fuse([l.post for l in locals_], team.prior, cert)
    if flag is not None:                                 # ambiguous / diversity_unobservable
        a, score = team.lbp.choose(team.A_Q, team_post or team.prior,
                                   team.rho_hat, team.safety,
                                   phi_hat=team.phi_hat, f_safe=team.f_safe)
        if a is not None:
            team.execute_probe(a)                        # 观察者-扰动者配对
            return QUORUM_round(team, team.observe(), delta_f_req)  # 重新归因
        team.quarantine_conflicts()                      # 冲突机隔离，退保守
        team_post = team.conservative_merge(locals_)

    # ———— 归因定向 + 团队规划 + 团队证书 ————
    for l in locals_:
        l.M.balls = l.M.rsc_q.update(l.post_i, team_post, l.rho_Q)
    plans = [l.M.csp_q.plan_chunks(goal, l.M.x_prime, team_post, l.M.balls)
             for l in locals_]
    k_team = team.tsc.certified_prefix([p.A for p in plans],
                                       [l.M.cert for l in locals_],
                                       team.comm, team.cov)
    # ———— 实时执行 + 摔倒/陈旧早停 ————
    results = team.execute_prefix(plans, k_team, delta_f_req)
    return results, build_j_quorum(results, locals_, team_post, cert,
                                   k_team, team.comm, team.cov)
```

## 4. 推导

**引理 9（共因下的信息饱和）** 设 n 个证据对同一标量参数的无偏估计等相相关为 ρ̄，则平均估计的方差
Var(x̄)=σ²/n·(1+(n−1)ρ̄)=σ²/n_eff。
当 n→∞，Var→ρ̄σ²，等价独立样本数饱和在 n_eff→1/ρ̄；后验精度与归因置信度随 n_eff 而非 n 增长。若把 ρ̄ 误当 0 做独立乘积，则在 p_Z>0 时名义置信度按 n 指数增长，而真实信息被 H(Z) 截断——**这就是多机器人「票多但独立信息不增」的羊群效应。** ∎

**引理 10（步态激励可辨识性）** 在 static 步态下，载荷份额 p_ℓ 不随运动变化，单腿力偏置 δ_ℓ 与质心偏移 δ_com 对 p 的一阶影响均落在同一常向量张成的子空间（都表现为固定载荷再分配），故 H_single-leg-force 与 H_body-com 的签名列共线，S_Q 秩亏、κ_g=0。trot 下对角腿成对支撑，δ_com 引起对角对载荷的反对称变化而单腿偏置只改一条腿，两列在 p 上线性无关；walk 的单腿摆动窗口进一步提供逐腿隔离；step/tap 注入已知接触事件，等价于对单腿通道做直接激励。故存在步态使 rank(S_Q)=dim θ、κ_g>0。∎

**定理 9（QUORUM 端到端归因-安全）** 在 A94–A99 下：
1. **组内可分离**：选择 g*=argmax_g κ_g 后，S_Q 满秩，足端通道把单腿偏置/质心误差/打滑/几何幻觉分别投影到不同子空间（引理 10）。
2. **跨机可信但有条件**：若 Valid(CDC) 且 n_eff≥n_min，则 D-FIR 的意见池权重和为 n_eff，归因误差以 O(exp(−n_eff·κ/2)) 集中；若 CDC 失效或 d_team>τ_dis，则输出 `diversity_unobservable`/`ambiguous`，退回本地保守或执行 LBP（引理 9），**绝不把相关一致当独立证据**。
3. **定向处置**：RSC-Q 只膨胀被归因者，单机几何正确时不因队友错误被连坐。
4. **团队安全**：TSC 的 k_team* 同时满足本地安全、机器人间分离（含协方差与陈旧度）、共享工作区互斥与摔倒围堵；通信中断即独立安全模式。
5. **优雅降级**：视觉失效→r_vis↑；力失效→r_force↑；足端失效→r_leg↑；通信/相对定位失效→r_comm↑ 且退本地；共因嫌疑→`quarantine + fall_contain + safe_idle`；未知故障→判 ambiguous。∎

**定理 10（团队前缀的执行安全）** 设 k_team*≤m_team，且对每个后验支持假设、每台 CDC 有效机器人、每步 s≤k_team* 都验证了本地与团队约束。由联合界，单块内团队越界（碰撞/摔倒/互斥/力/滑移）概率
P[越界] ≤ α_chunk + δ_fi + α_vis + α_comm + α_leg。
由于 k_team*≤m_team，即使故障在块首激活，检出或强制重规划也发生在越过团队不可逆点之前。故协作前缀不引入超出单机的不可逆风险。∎

**命题（更多机器人可能更糟）** 朴素独立融合的置信度随 n 指数增长；QUORUM 的置信度随 n_eff=n/(1+(n−1)ρ̄) 增长并饱和在 1/ρ̄。当 ρ̄→1（全共因）时 n_eff→1，QUORUM 的额外置信度→0，而朴素融合仍报高置信。故「增加机器人」在共因环境下不仅无益，还会把系统推入**更自信的错误**；QUORUM 的证书机制正是为了在这种情形下弃权。∎

## 7. 已知风险

**一句话**：QUORUM 的全部安全性都压在「多样性证书能在分布内预测分布外的共因」这一条上；但 ρ̄ 只能从有限的审计集估出来，而真正致命的共因（共享主干的可迁移对抗 patch、共享地图一起漂、同一操作员的系统性误判、同一片光照）恰恰是审计集里**没被采样过**的那部分——此时 CDC 会报告一个虚高的 n_eff，D-FIR 会对着「相关的一致」给出高置信度，系统把「凑够票」误当成「独立」，**多样性本身于是变成新的、且从系统内部结构上无法被察觉的单点故障**。

**次级风险与缓解**：
1. **相关估计的分布外失效**：审计集无法穷尽共因；缓解：在线相关监测（残差同步跳变、误差同向漂移即降权）、结构性去相关（异构主干/模态/时钟）、把 p_Z 作为显式潜变量并在漂移时抬升其先验、n_eff 设保守上限。
2. **共识羊群与拜占庭**：多数一致可能是共同错；缓解：D-FIR 用 n_eff 折扣、LBP 主动制造去相关、隔离持续冲突机、要求结构性独立而非仅统计独立；拜占庭下优先安全降级而非追求正确归因。
3. **四足探针导致摔倒**：踏步/重心转移/跨机协作不可逆；缓解：TSC 的 m_team、ZMP/支撑/滑移/摔倒围堵约束、易损/近人场景禁用大动作探针、优先 `observe/standoff` 等低风险探针。
4. **步态切换暂态污染签名**：切换瞬间载荷与接触状态剧烈变化；缓解：切换窗口不计入签名、用相位锁定与稳定段采样、GEF 只在稳态段估计。
5. **团队通信单点故障**：共享链路/时钟是结构性共因；缓解：通信中断即独立安全模式、时钟失步检测、关键安全不依赖跨机实时同步、消息陈旧度进入 TSC。
6. **D-FIR 权重选择敏感**：意见池权重影响后验；缓解：用协方差交叉兜底、对权重做敏感性分析、归一化到 n_eff 并设上限。
7. **足端模型标定误差**：腿运动学/足端半径误差会伪装成几何幻觉；缓解：把 H_leg 单列为假设、零速/静止段在线重标定、与视觉落点交叉验证。
8. **审计成本与可扩展性**：n² 相关估计与故障注入昂贵；缓解：利用仿真/回放、稀疏相关图、只在机队变更时重认证、缓存证书哈希。
