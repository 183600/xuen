# 第 4 轮（接续 InstructGauge；本轮灵感：「比赛策略」×「时空推理」）

> **轮次说明**：这是新一轮灵感循环的第 1 轮，但为保持基线连续，技术编号接续第 3 轮（定义 448 起、引理 59 起、实验 E457 起、IP-328 起）。
> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。MODGAUGE / LeanGauge / ToolGauge 骨架继续继承不变。
> **本轮纪律**：**时空化 + 对抗化 + 严格退化**。把“静态快照标定”升级为“时空管道上的追逃博弈”；任一新增组件不可用都可退回 InstructGauge，再退回 ToolGauge / LeanGauge / MODGAUGE。

## 0. 直觉与动机

**灵感 1（比赛策略 → 探针不是规划一条路，而是和一个会躲的目标比赛）**
直觉：静态标定的隐含假设是“我走到那里，东西还在那里”。真实盲区修复更像守门员扑点球：缺陷/遮挡/反光点在动，探针也在动，谁先到谁赢。因此正确的对象不是“一条最优探测路径”，而是一个**有限时域追逃博弈**：探针选择探测计划 π，缺陷在速度界内选择逃逸轨迹 ξ，探针要保证在时域内至少观测到一次。更关键的是，单条确定性计划会被对手（或分布外场景）利用；所以战术层必须是**混合策略**，并用对手联盟与 no-regret 选择逼近不可利用的均衡，而不是押注一个“最强启发式”。

**灵感 2（时空推理 → 盲区是一条会移动的缝，不是图上的一个洞）**
直觉：一个点在 t 时刻被遮挡，不等于它在 t+1 时刻还可观测。给定缺陷速度上界 `v_max`、探针速度上界 `v_p`、视场与遮挡模型，真正该传播的是**时空可达管**：缺陷可能在哪里（`D_h`）与探针可能看到哪里（`O_π`）。于是“能不能看到”变成一个几何问题：`D_h` 与 `O_π` 在时空中的捕获域是否覆盖了所有可行轨迹。只检查 `D_t ∩ O_t ≠ ∅` 是不够的——相交只说明“看见了一部分”，对手仍可能从没被覆盖的那条缝里逃出整个时域。

**灵感 3（耦合 → 语义置信度决定“想干多久”，几何拦截决定“还能看多久”）**
直觉：第 3 轮的块长上界 `K_MAX(ι)` 由指令歧义 `κ_sem` 决定；本轮再叠加一个**几何跟踪时域** `K_track`：目标若在 3 步后可能永久离开探针的观测能力，再高的指令置信度也不能支撑 `K>3`。取 `K_eff = min(K_MAX(ι), K_track, K_budget)`，把“语义陈旧”和“几何跟丢”拆成两个正交的否决轴；另用取证时域 `τ_cap` 判断该块能否顺带给出“必然捕获”的回执。与此同时，覆盖保证也必须时空化：移动场景破坏共形校准的交换性，必须用**任意序列下仍成立的长期覆盖界**（ACI）与 **anytime-valid 误报控制**（e-process）替换单次边际覆盖。

## 1. 研究问题（本轮要回答什么）

- **Q1（博弈可解性与证书）**：探针—缺陷的时空拦截能否写成可求解的追逃博弈，并给出可审计的“必然捕获 / 仅可跟踪 / 逃逸见证”三分证书？
- **Q2（块长的几何夹紧）**：几何跟踪时域 `K_track` 能否与语义块长 `K_MAX(ι)` 干净复合，且在目标静止/完全可观测时严格退回第 3 轮？
- **Q3（无交换性的覆盖）**：在时空非平稳下，能否给出不依赖 i.i.d./交换性的长期覆盖界，同时保留 anytime-valid 的误报控制？
- **Q4（不可利用的战术）**：混合战术 + 对手联盟 + no-regret/racing，能否在有限探测预算下优于任何固定战术，并把“对未见过对手的可利用度”压到可界？

## 2. 设计原则（雏形，正式化见产物区定义 448–463）

**P4 双核优先（Dual-Kernel First）**
对任何待提交的块，先在时空栅格上反向传播两个核：**捕获核** `L_t`（从这里出发存在一条全程避开观测管的轨迹）与**逃逸核** `E_t`（在尚未被观测的前提下，从这里出发可以进入永久不可观测区域）。恒有 `E_t ⊆ L_t`：`L_0 = ∅` 才允许“必然捕获”；`E_0 = ∅` 才允许“块内不会跟丢（仅可跟踪）”；`E_0 ≠ ∅` 则输出**逃逸见证**并截断/放弃。相交不是保证，空核才是。

**P5 复合块长（Composed Chunk Length）**
`K_eff = min(K_MAX(ι), K_track, K_budget)`，其中 `K_track` 是“最早可能跟丢时刻之前的可开环步数”；`τ_cap ≤ K_eff` 时该块还顺带给出“必然捕获”的回执，否则只承诺“跟踪进展”。语义、几何、预算三者取最紧；任何一项无法计算都退回 `K=1`。

**P6 混合与联盟（Mixed, Non-Exploitable Tactics）**
战术集合 `𝒯` 上的收益矩阵用 LP/CFR 求混合均衡；对手联盟持续加入当前策略的最佳响应，防止对静态基准过拟合。选择阶段用 racing 逐轮淘汰，预算只花在仍有希望的战术上。

**P7 任意时序列证书（Anytime-Valid, Exchangeability-Free）**
覆盖用 ACI 维护长期缺口 `O(1/(γT))`，误报用 e-process + Ville 不等式控制；两者都不要求交换性。可交换且样本充足时才回退 SC-Cal，以获得更紧的有限样本区间。

**P8 保守离散化（Conservative Discretization）**
栅格上的 `D` 只能**过近似**、`O` 只能**欠近似**；这样 `L_grid = ∅ ⇒ L_true = ∅` 且 `E_grid = ∅ ⇒ E_true = ∅`，离散化误差只会让系统更保守，不会制造假“必然捕获/必然跟踪”。

## 3. 与基线的接口（如何退化）

- 目标静止 `v_max = 0` 且探针覆盖缺陷 ⇒ `D_h` 退化为点集、`E_t` 恒空 ⇒ `K_track = T`，`K_eff = K_MAX`，等价于 InstructGauge 的块长；
- 探针完全覆盖、捕获核与逃逸核皆空 ⇒ IPC 恒 `CAPTURE`，等价于第 3 轮 CVC；
- 博弈求解超时/栅格不可用 ⇒ 使用缓存均衡或贪心最大覆盖，并强制 `K=1`，等价于 ToolGauge 逐步执行；
- 战术联盟/racing 不可用 ⇒ 单一默认战术 `τ₀`，等价于 IAC；
- 序列可交换且校准样本充足 ⇒ ACI 退回 SC-Cal 目标水平；e-process 仅作监控；
- 时空管失效/速度界被回执违反 ⇒ 立即加宽管道或 `K=1`，退回 ToolGauge；
- ToolGauge 失效 ⇒ LeanGauge 纯数值路径；LeanGauge 失效 ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个**时空追逃口径**：把盲区修复从静态覆盖升级为“缺陷可达管 × 探针观测管”的双核问题，并给出“必然捕获 / 仅可跟踪 / 逃逸见证”的三分证书；
2. 一个**复合块长定理**：`K_eff = min(K_MAX(ι), K_track, K_budget)`，把语义歧义、几何跟丢与预算分开夹紧，静止/完全可观测时严格退回 InstructGauge；
3. 一个**不可利用战术层**：混合矩阵博弈 + 对手联盟 + racing/no-regret，在有限预算下给出可利用度与 regret 界；
4. 一个**无交换性覆盖层**：ACI 的任意序列长期覆盖缺口界 + e-process 的 anytime-valid 误报控制 + 空间多重性校正；
5. 一条完整可证伪路径：E457–E472 覆盖管道可靠性、双核正确性、块长复合、战术可利用度、联盟泛化、覆盖缺口、误报延迟、50Hz 时序与 sim→real。

## 5. 本轮最大风险

**一句话**：整套“必然捕获/必然跟踪”的安全性都条件于时空管 `D_h` 的正确性——一旦速度界、遮挡模型或共形半径失准，空的捕获核/逃逸核就只是一张**假证书**，系统会以“已证明看见”的姿态放过真实目标。

## 2. 形式化定义（要点）

**定义 448（时空轨迹与缺陷假设）** 工作空间 `W ⊂ ℝ³`，时间栅格 `t = 0..T`、步长 `Δt`。缺陷假设 `h` 的轨迹 `ξ_h = (x_0^h,…,x_T^h)`，`x_t ∈ W`。可行轨迹集
`Ξ_h = { ξ : ‖x_{t+1}−x_t‖ ≤ v_max Δt, x_0 ∈ B(x̂_0^h, ε_0) }`。
探针计划 `π` 产生探针位形 `p_t^π` 与观测管 `O_π(t)`（定义 450）。

**定义 449（缺陷时空可达管 D_h）** `R_h(0) = B(x̂_0^h, ε_0)`，
`R_h(t+1) = R_h(t) ⊕ B(0, v_max Δt) ⊕ B(0, ε_{t+1})`，
`D_h = { (x,t) : x ∈ R_h(t) }`。若速度界由数据估计，取上置信界；`ε_t` 取共形/鲁棒半径。称 `D_h` 为 `(1−α_tube)`-sound，若 `P(ξ_h ⊂ D_h) ≥ 1−α_tube`。**约定**：栅格实现必须对 `D` 过近似（膨胀 `Δx`）。

**定义 450（探针可达与观测管 O_π）** 给定探针速度界 `v_p`、传感器半径 `r_s`、视场锥与遮挡模型 `vis(p,x) ∈ {0,1}`，可达位形集 `P_π(t)` 由 `π` 与 `v_p` 前向传播。观测管
`O_π(t) = { x ∈ W : ∃ p ∈ P_π(t), ‖x−p‖ ≤ r_s, vis(p,x)=1 }`。
`q_det` 为标定给出的“落在观测管内即可检测”的最坏概率下界。栅格实现必须对 `O` 欠近似（腐蚀 `Δx`），以保证 `L_grid = ∅ ⇒ L_true = ∅` 且 `E_grid = ∅ ⇒ E_true = ∅`。

**定义 451（捕获核 `L_t`、逃逸核 `E_t` 与捕获域 `C_t`）** 固定 `π`、`h`、`T`，记未来可观测集 `S_t = ∪_{s=t}^T O_π(s)`。反向递归定义两个核：
`L_T = D_h(T) \ O_π(T)`，
`L_t = (D_h(t) \ O_π(t)) ∩ Pre_evade(L_{t+1})`；
`E_T = D_h(T) \ S_T`，
`E_t = [ D_h(t) \ S_t ] ∪ [ (D_h(t) ∩ (S_t \ O_π(t))) ∩ Pre_evade(E_{t+1}) ]`，
其中 `Pre_evade(S) = { x ∈ W : ∃ x' ∈ S, ‖x'−x‖ ≤ v_max Δt }`。`C_t = D_h(t) \ L_t` 为捕获域。直观：`L_t` 是“从这里出发可以全程不被看见”的位置；`E_t` 是“在尚未被观测的前提下，从这里出发可以在某个未来时刻进入永久不可观测区域”的位置。恒有 `E_t ⊆ L_t`：永久逃逸必是全程未被看见，故 `L_0=∅`（必然捕获）比 `E_0=∅`（仅可跟踪）更强。`L_0 = ∅` 是“必然捕获”，`E_0 = ∅` 是“块内不会跟丢”。

**定义 452（捕获失败见证、逃逸见证与 IPC 三值证书）** 轨迹 `ξ` 是**捕获失败见证**，若 `x_t ∈ L_t` 对所有 `t`；是**逃逸见证**，若 `x_0 ∈ E_0`（`E_t` 的递归已排除中途被观测，故沿 `Pre_evade` 回溯即得一条“取证前永久跟丢”的轨迹）。拦截证书 `IPC(C,π,h)`：
- `CAPTURE`：`L_0 = ∅` 且 `q_det ≥ q_min`（块内必然捕获）；
- `TRACK`：`E_0 = ∅` 且（`L_0 ≠ ∅` 或 `q_det < q_min`）（块内不会跟丢，但不保证捕获）；
- `FAIL`：`E_0 ≠ ∅`，输出一条逃逸见证与**可逃逸测度** `μ(E_0)/μ(D_0)`。
概率模式：`CAPTURE` 可放宽为 `c·q_det·μ(C_0)/μ(D_0) ≥ 1−β`；`TRACK` 可放宽为 `μ(E_0)/μ(D_0) ≤ β`。
**关键区分**：`D_t ∩ O_t ≠ ∅` 只是必要条件；只有 `E_0 = ∅` 才是“不跟丢”的充分证书；只有 `L_0 = ∅` 才是“必然捕获”。

**定义 453（跟踪时域 `K_track`、取证时域 `τ_cap` 与复合块长 `K_eff`）** 固定规划时域 `T`。定义**最早可能逃逸时刻**
`τ_esc(π,h) = min{ t ∈ [0,T] : E_t ≠ ∅ }`（若对所有 `t` 都有 `E_t = ∅`，令 `τ_esc = T+1`），
以及**跟踪时域** `K_track = min(T, τ_esc)`（即“在目标可能跟丢之前还能开环执行多少步”）。定义**取证时域**
`τ_cap(π,h) = min{ k ≤ T : L_0^{(k)} = ∅ }`（以 `k` 为时域重算捕获核；不存在则 `τ_cap = ⊥`）。复合块长
`K_eff = min( K_MAX(ι), K_track, K_budget )`。
若 `τ_cap ≤ K_eff`，该块同时给出必然捕获回执；否则该块只承诺“跟踪进展”，到 `K_eff` 必须重规划。`K_MAX(ι)` 沿用第 3 轮定义 440。

**定义 454（追逃博弈 G_ST 与价值 V_ST）** `G_ST = (D_h, O_π, Ξ_h, A_π, payoff)`。两种信息结构：
- **Stackelberg（对手知道计划）**：`V_ST(π) = min_{ξ∈Ξ_h} 1{ξ 被捕获}`；由定义 451/452，`V_ST(π)=1 ⇔ L_0=∅`。测度版本 `V_ST^μ(π,ξ) = μ({x_0∈D_0 : 从 x_0 出发的 ξ 被捕获}) / μ(D_0)`，即“捕获域占可达管的比例”。
- **同时行动**：探针对计划混合 `p ∈ Δ(𝒯)`，缺陷对轨迹混合 `q`，`v_ST = max_p min_q E_{π∼p, ξ∼q}[1{ξ 被捕获}]`，由定义 455 的矩阵博弈求解。
**用途区分**：`V_ST^μ` 是平均意义下的战术排序分数；硬安全保证只认 `L_0=∅`（必然捕获）或 `E_0=∅`（块内不跟丢）。两者不可互相替代。

**定义 455（战术矩阵博弈与可利用度）** 战术集 `𝒯 = {τ_1,…,τ_n}`（移动方向、倾角、变焦、偏振、等待等）；对手抽象 `Ξ_ℓ = {ξ_1,…,ξ_m}`（由联盟给出）。收益
`M_{τ,ξ} = V_ST^μ(π_τ, ξ) − λ_cost · c(τ)`。
混合策略 `p ∈ Δ(𝒯)`，价值 `v_ST = max_p min_{ξ∈Ξ_ℓ} Σ_τ p_τ M_{τ,ξ}`。可利用度
`ε_exp(p) = v_ST − min_{ξ∈Ξ_ℓ} Σ_τ p_τ M_{τ,ξ}`。
小规模用 LP 精确求解；大规模/扩展式用 CFR，利用度按 `O(1/√N)` 衰减。

**定义 456（对手联盟与虚构自博弈）** 联盟 `ℒ = {(ξ_j,w_j)}`，`w_j` 为优先级权重。最佳响应 `ξ_BR(p) ∈ argmin_{ξ∈Ξ} Σ_τ p_τ M_{τ,ξ}`；周期性把 `ξ_BR(p)` 以优先级权重插入 `ℒ`（priority fictitious self-play）。评测使用**留出对手集** `ℒ_test`，`ε_ℒ(p) = max_{ξ∈ℒ_test} …` 是真实可利用度的下界（当 `ℒ_test ⊂ Ξ`）。联盟的用途是压力测试与填充 `Ξ_ℓ`，不是把安全性押在训练分布上。

**定义 457（无 regret 战术选择与 racing）** 每轮 `t` 由 Hedge/EXP3 选 `p_t`，观察对手 `ξ_t`，损失 `ℓ_t(τ) = −M_{τ,ξ_t}`。Hedge 的 regret `R_T = max_τ Σ_t ℓ_t(τ) − Σ_t ℓ_t(τ_t) ≤ O(√(T log n))`，平均策略可利用度 `≤ O(√(log n / T))`。**Racing**：successive halving 分阶段保留置信上界不低于当前最优下界的战术，总探测预算 `≤ B⌈log₂ n⌉`，以概率 `≥ 1−δ` 返回 `ε`-最优战术。这把“比赛”从一次性评测变成有预算证书的锦标赛。

**定义 458（轨迹级覆盖事件）** 对契约序列与时域窗 `W`，定义
`e_t = 1{ ∃ τ ∈ [t, t+W] : h*_τ ∉ H_τ }`，
即“该契约在窗口内任一时刻漏掉真值”的轨迹级错误。这样把空间/时间相关性聚合成一个事件，避免逐帧 i.i.d. 假设。`H_t` 由校准分位或模型区间给出。

**定义 459（ACI 自适应阈值）** `α_{t+1} = Π_{[0,1]}( α_t + γ(α − e_t) )`，阈值 `q_t` 由滑动校准窗在水平 `1−α_t` 给出。对任意错误序列，长期错覆盖率满足
`| (1/T) Σ_{t=1}^T e_t − α | = O( 1/(γT) )`
（未投影版本有精确 telescoping 恒等式；投影实现为标准 ACI 同阶界）。不要求交换性；`γ` 控制“跟踪速度 vs 缺口”的权衡。

**定义 460（e-process 与 anytime-valid 告警）** 取可预测 `λ_t ∈ [0,1)`，资本
`K_t = ∏_{s=1}^t (1 + λ_s (e_s − α))`。
在零假设 `H₀: E[e_s | F_{s-1}] ≤ α` 下，`K_t` 是非负超鞅；Ville 不等式给出
`P( ∃ t : K_t ≥ 1/α ) ≤ α`。
因此可以无限期监控而不膨胀误报。若持续偏移 `E[e_t] ≥ α+Δ`，取 `λ≈Δ`，检测延迟约 `O(log(1/α)/Δ²)`。触发后重新接地或退回 `K=1`。

**定义 461（空间多重性控制）** 将 `W` 划分为单元 `𝒞`。逐单元运行 e-process，分配 `α_c = α·w_c` 且 `Σ_c w_c=1`（Bonferroni），或使用在线 FDR 水平 `α_t = α·γ_t`。覆盖侧逐单元跑 ACI 并以 `w_c` 加权汇总。该层保证“空间扫描”不会因为单元数增多而把误报率放大。

**定义 462（时空修复证书 RepairCert″）** `RepairCert″(s) = (ι, C, ChunkCert, IPC, TubeCert, GameCert, ACIState, receipts, claims)`。审计链为：指令 `ι` → 时空管 `TubeCert` → 博弈价值/策略 `GameCert` → 块 `C` 与 `IPC` → 逐步回执 `receipts` → 语言主张 `claims`。若 `IPC=FAIL`，证书内附**逃逸见证**，让人类能直接看到“机器为什么放弃”。

**定义 463（预算准入与实时性）** `B_probe = Σ_i c(a_i) + c_verify(C) + c_solve`。仅当预期捕获增益 `ΔV_ST ≥ λ_B · B_probe` 且 `c_solve < budget_slack` 时准入。求解超时则使用缓存均衡（IP-333 的策略窃取，引理 66），主循环不得等待。

# IP-328 STT：时空管构建（D 过近似，O 欠近似）
class STT:
    def build(self, h, x0, v_max, eps, T, dt):
        R = [ball(x0, eps[0])]
        for t in range(1, T + 1):
            R.append(dilate(R[-1], v_max * dt) + ball(eps[t]))   # 过近似
        return Tube(R)

    def observe_tube(self, plan, v_p, r_s, vis, T, dt):
        O = []
        for t in range(T + 1):
            P = reachable_poses(plan, t, v_p, dt)
            O.append(erode(union(FOV(p, r_s) for p in P), DX))  # 欠近似
        return O

    def build_pair(self, h, plan, T):
        return self.build(h, T), self.observe_tube(plan, T)

# IP-329 PEG：双核 + 矩阵博弈 + 跟踪/取证时域
class PEG:
    def capture_kernel(self, D, O, v_max, dt):
        L = [None] * len(D)
        L[-1] = D[-1].difference(O[-1])
        for t in range(len(D) - 2, -1, -1):
            L[t] = D[t].difference(O[t]).intersect(
                       pre_evade(L[t+1], v_max * dt))
        return L

    def escape_kernel(self, D, O, v_max, dt):
        S = future_observable(O)              # S[t] = union(O[t:])
        E = [None] * len(D)
        E[-1] = D[-1].difference(S[-1])
        for t in range(len(D) - 2, -1, -1):
            E[t] = (D[t].difference(S[t])) | (
                   D[t].intersect(S[t]).intersect(
                       pre_evade(E[t+1], v_max * dt)))
        return E

    def tracking_horizon(self, h, plan, T):
        D, O = self.stt.build(h, T), self.stt.observe_tube(plan, T)
        E = self.escape_kernel(D, O, V_MAX, DT)
        tau_esc = next((t for t in range(T + 1) if not E[t].is_empty()),
                       T + 1)
        return tau_esc - 1

    def capture_time(self, h, plan, T):
        for k in range(1, T + 1):
            D, O = self.stt.build(h, k), self.stt.observe_tube(plan, k)
            if self.capture_kernel(D, O, V_MAX, DT)[0].is_empty():
                return k
        return None

    def solve(self, h, tactics, league, budget):
        M = {(tau, xi): capture_measure(tau, xi) - COST * cost(tau)
             for tau in tactics for xi in league}
        p, v = lp_matrix_game(M)          # 小规模精确；大规模用 CFR
        K_track = min(self.tracking_horizon(h, tau, T_H)
                      for tau in tactics)
        tau_cap = min(filter(None, (self.capture_time(h, tau, T_H)
                                    for tau in tactics)), default=None)
        return p, v, K_track, tau_cap

# IP-330 IPC：三值证书（不跟丢 / 必然捕获 / 逃逸见证）
class IPC:
    def certify(self, C, plan, h):
        D, O = self.stt.build_pair(h, plan, len(C))
        L = self.peg.capture_kernel(D, O, V_MAX, DT)
        E = self.peg.escape_kernel(D, O, V_MAX, DT)
        if not E[0].is_empty():
            first = next(t for t in range(len(E)) if not E[t].is_empty())
            return FAIL(witness=extract_escape_path(E, first),
                        uncovered=measure(E[0]) / max(measure(D[0]), EPS),
                        first_fail=first)
        if not L[0].is_empty():
            return TRACK(capture_deficit=measure(L[0]) / max(measure(D[0]), EPS))
        return CAPTURE(q_det=self.q_det, capture=1.0)

# IP-331 TPL：racing + no-regret
class TPL:
    def race(self, tactics, budget):
        alive, level = list(tactics), 0
        while len(alive) > 1 and budget.used < budget.total:
            scores = {tau: evaluate(tau, n=2**level) for tau in alive}
            alive = successive_halving(alive, scores, keep=len(alive)//2)
            level += 1
        return best_ucb(alive)

    def no_regret(self, T):
        w = ones(n_tactics)
        for t in range(T):
            p = w / w.sum()
            tau = sample(p); xi = adversary_response(tau)
            loss = -M[tau, xi]
            w *= exp(-ETA * loss)             # Hedge
        return p

# IP-332 ATUC：ACI + e-process + 空间多重性
class ATUC:
    def update(self, e_t, cell):
        a = self.alpha[cell]
        self.alpha[cell] = clip(a + GAMMA * (self.alpha0 - e_t), 0, 1)
        self.K[cell] *= (1 + self.lam[cell] * (e_t - self.alpha0))
        if self.K[cell] >= 1 / (self.alpha0 * self.w[cell]):
            return ALARM(cell)               # Ville：anytime-valid
        return OK

# IP-333 SSG：策略窃取热启动（带迁移界）

## 4. 推导

**引理 59（时空管可靠性）** 若每一时刻 `x_t^h ∈ B(x̂_t, ε_t)` 以概率 `≥ 1−α_t` 成立，且速度界 `‖x_{t+1}−x_t‖ ≤ v_max Δt` 成立，则 `P(ξ_h ⊂ D_h) ≥ 1 − Σ_t α_t`。若用 anytime-valid 的 e-process 监控速度界（定义 460），则可去掉逐时刻联合界，直接得到时间一致包含。
*证明骨架*：对 `t` 归纳。基础情形由初始球给出；归纳步由 `R_h(t+1)` 的膨胀包含所有速度可行后继与噪声球。概率部分用 union bound；e-process 版本用 Ville 不等式。

**引理 60（双核的精确性）** 定义 451 的反向递归精确刻画两个集合：
(i) `L_t` = 从 `(x,t)` 出发存在一条速度可行、且对 `s≥t` 全程避开 `O_π(s)` 的轨迹的位置集合；
(ii) `E_t` = 从 `(x,t)` 出发、在 `t` 之后未被观测的前提下，存在某个未来时刻进入 `W\S_s`（永久不可观测区域）的轨迹的位置集合。
推论：`L_0=∅ ⇔` 所有 `ξ∈Ξ_h` 都至少在某一时刻被观测（必然捕获）；`E_0=∅ ⇔` 不存在“取证前永久跟丢”的轨迹（块内仅可跟踪）；`E_0≠∅ ⇔` 存在一条可构造的逃逸见证。且 `E_t⊆L_t`，故 `CAPTURE ⇒ TRACK`。
*证明*：对时域反向归纳。`t=T` 时 `L_T=D_T\O_T`、`E_T=D_T\S_T` 显然。设 `L_{t+1},E_{t+1}` 正确。`x∈L_t` 当且仅当 `x∉O_t` 且存在速度可行后继 `x'∈L_{t+1}`。`x∈E_t` 当且仅当 `x∉S_t`（已永久不可观测且 `x∉O_t`），或 `x∈S_t\O_t` 且存在速度可行后继 `x'∈E_{t+1}`；第二个分支的 `x∉O_t` 保证当前拍未被观测。取 `x_0∈L_0`（或 `E_0`）并沿 `Pre_evade` 回溯即得对应见证。

**引理 61（复合块长与退化）** 令 `K_eff = min(K_MAX(ι), K_track, K_budget)`，其中 `K_track = min(T, τ_esc)`。则任何提交的块同时满足：语义陈旧界（第 3 轮引理 52/53）、几何跟踪界（引理 60）与预算准入（定义 463）。`K_track` 对 `v_max` 单调不增（`D_h` 对速度单调膨胀，`E_t` 的 loss 区域随之扩大）；对探针能力的单调性依赖具体几何，本文不作全局断言，由 E460 实测。特别地：
- `v_max=0` 且 `O` 覆盖 `D` ⇒ `E_t=∅` 对所有 `t` ⇒ `τ_esc=T+1`、`K_track=T`，`K_eff=K_MAX`，严格退回 InstructGauge；
- 目标速度快到第一步就可能离开可观测能力 ⇒ `E_0≠∅`、`τ_esc=0`、`K_track=0` ⇒ 放弃（或 `K=1` 的逐步 ToolGauge）；
- 若 `τ_cap ≤ K_eff`，块内保证捕获；否则只保证“不跟丢”，到 `K_eff` 重规划。
*证明*：`v_max` 增大使 `D_h` 逐点膨胀，`E_t` 的 loss 区域随之扩大，故 `τ_esc` 不增、`K_track` 不增。探针能力方向因 `E_t` 同时含 `D\S` 与 `S\O` 两项，不保证全局单调，故不作断言。`v_max=0` 时 `D` 退化为点集，若该点在 `S_t` 中则无法进入 `E_{t+1}`，故 `E_t=∅` 对所有 `t`，`K_track=T`。

**引理 62（保守离散化的可靠性）** 若栅格对 `D` 过近似、对 `O` 欠近似，则 `L_grid ⊇ L_true`，故 `L_grid = ∅ ⇒ L_true = ∅`。对 `E` 使用保守的 loss-region 过近似：`D^+` 过近似、`O^-` 欠近似，并在 `D\S` 项用 `S^- = ∪ O_grid`、在 `S\O` 项用 `S^+ ⊇ ∪ O_true`（两个方向都取保守侧），则 `E_grid ⊇ E_true`，故 `E_grid = ∅ ⇒ E_true = ∅`。因此 IPC 的 `CAPTURE`/`TRACK` 都不会漏报真实的捕获失败/跟丢轨迹。价值误差对 Lipschitz 收益满足 `|V_grid − V_true| ≤ L·(c_1 Δt + c_2 Δx)`。
*证明*：`D` 变大、`O` 变小都只会增加 `L`。对 `E`，`D\S` 项需要 `S` 变小、`S\O` 项需要 `S` 变大，故分别保留 `S^-` 与 `S^+` 两个保守版本；每一项都是真实集合的超集，递归的 `Pre_evade` 单调，故 `E_grid ⊇ E_true`。Hausdorff 距离界给出价值误差。

**引理 63（矩阵博弈与 no-regret 战术）** 有限战术博弈用 LP 可精确求 `v_ST` 与均衡。Hedge 的 regret `R_T ≤ O(√(T log n))`，其平均策略可利用度 `≤ O(√(log n / T))`；racing 用 `O(B log n)` 探测预算即可以高概率返回 `ε`-最优战术。
*证明*：Hedge 的标准指数权重分析；racing 的 successive-halving 置信界分析；联盟最佳响应保证 `Ξ_ℓ` 逐步逼近真实对手集。

**引理 64（ACI 的任意序列覆盖缺口）** 对任意 `e_t∈{0,1}`，未投影 ACI 满足精确恒等式
`Σ_{t=1}^T (e_t − α) = (α_1 − α_{T+1}) / γ`，
故 `| (1/T)Σ e_t − α | ≤ (|α_1−α| + 1)/(γT)`。投影实现有同阶界。特别地，不需要交换性；当 `γ = Θ(T^{-1/2})` 时缺口为 `O(T^{-1/2})`。
*证明*：把更新式改写为 `α_{t+1}−α = (α_t−α) − γ(e_t−α)`，对 `t` 求和并整理。`α_t∈[0,1]` 给出分子界。

**引理 65（e-process 的 anytime-valid 误报与检测延迟）** 在 `H₀: E[e_t|F_{t-1}]≤α` 下，`K_t` 为非负超鞅，Ville 给出 `P(∃t: K_t ≥ 1/α) ≤ α`，无需固定样本量或交换性。若持续偏移 `Δ>0`，取 `λ≈Δ` 时 `log K_t` 以约 `tΔ²/2` 增长，检测延迟 `O(log(1/α)/Δ²)`。
*证明*：`E[1+λ(e_t−α)|F_{t-1}] ≤ 1`，故 `K_t` 超鞅；Ville 不等式；偏移下的对数增长率由二阶展开。

**引理 66（策略窃取的迁移下界）** 设收益对对手轨迹满足 `L`-Lipschitz（w.r.t. `W_1`），战术迁移误差为 `δ_φ`。则把旧均衡 `p_prev` 搬到新博弈的价值满足
`V_new(p_prev) ≥ V_prev − L·W_1(Ξ_prev, Ξ_new) − δ_φ`。
该下界可作为热启动的**可行性证书**：高于回退值才复用，否则冷启动。
*证明*：对任意 `ξ_new`，取 `ξ_prev` 使 `W_1` 接近，收益差由 Lipschitz 控制；再对 `p_prev` 取最小。

**引理 67（三轴证书的复合安全性）** 若在提交点同时满足 CVC（第 3 轮）、IPC（定义 452）与 ATUC（定义 459/460），则执行前缀满足：硬不变量 `Inv` 保持（CVC/引理 52）；时域内不存在逃逸见证（IPC/引理 60）；契约误报在 anytime 意义下 `≤ α`（e-process/引理 65）；长期覆盖缺口 `O(1/(γT))`（ACI/引理 64）。任一失败触发截断/重接地/回退，仍保持 `Inv`。三条轴——语义、几何、统计——互相独立，没有单点承重。
*证明*：各引理给出各自结论；失败分支按定义 452/459/463 的安全性转换执行；对块内步数归纳即可。

**引理 68（任意时实时性）** PEG 的重求解在异步线程完成；超时则使用缓存均衡 `p_prev`（引理 66 给出其可行性下界）并强制 `K=1`。IPC 在预计算 `L,E` 后为 `O(K)`，ACI/e-process 为 `O(1)`。因此主循环新增周期 `< 0.2ms`，继承第 3 轮引理 58 的 50Hz 结论。
*证明*：把复杂度拆成关键路径与非关键路径；关键路径只含查表、`O(K)` 核检查与 `O(1)` 统计更新；超时分支退化为已知安全路径。

## 8. 本轮最大风险

**一句话**：所有“必然捕获/仅可跟踪”都条件于时空管 `D_h` 与速度界/遮挡模型的正确性——模型一旦失准，空的捕获核/逃逸核就是一张**假证书**，系统会以“已证明看见”的姿态放过真实目标，而这是任何后续统计校准都无法追回的。
