# 第 4 轮（灵感循环第 4 轮；本轮灵感：「文化适应性」×「安全对齐」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架全部继承不变。
> 本轮纪律：**增量升级 + 严格退化**。文化适配只允许改「测量约定、偏好排序、校准阈值」，**绝不允许改安全核**；安全对齐不是一句约束，而是一条可隔离、可记账、可冻结、可审计的边界。任一文化模块不可用 ⇒ 一键退回 InstructGauge。

## 0. 直觉与动机

**灵感 1（文化适应性 → 改「约定与偏好」，不改「底线」）**
直觉：同一台计量机器人在德国车间、日本产线、美国维修站、东南亚小厂工作，差异是真实存在的：单位（mm/inch）、公差标准（ISO GPS vs ASME Y14.5）、表面处理与材料惯例、对「停线」的风险姿态、人机交互礼节、对误差的叙事方式。若把「文化适应性」实现成「整条策略随地区漂移」，就等于把**地方惯例**偷偷当成**安全许可**——这是最典型的对齐失效。正确的切口是：把文化拆成**可类型化的约定层**（单位、标准、命名、礼节、风险姿态带），让它只改变「怎么表达、怎么排序、怎么校准」，不改变「什么绝对不允许」。一句话：**安全对齐对齐的是不变量，文化适配适配的是实现与偏好。**

**灵感 2（安全对齐 → 持续、可审计、可回退，而不是一次性的提示词）**
直觉：安全对齐不是给系统写一句「要安全」，而是三件事：(a) 一条**文化无关的安全核**（任何 locale 下都成立）；(b) 一本**对齐债**账本（累计偏离参考对齐策略多少，超预算就冻结适配）；(c) 一个**规范冲突仲裁器**：地方规范与安全核冲突时安全核优先；地方规范彼此只是价值多元、没有可判定对错时，系统应**弃权 / 有界询问**，而不是把某一文化偏好伪装成普适规则。这样既避免「文化帝国主义」，也避免「相对主义导致的安全漂移」。

**灵感 3（两者耦合 → 适配会自证安全，必须打断反馈回路）**
直觉：第 3 轮已指出指令条件化破坏共形可交换性，需要分层校准；文化适配把这个洞放大——按 locale 分层后每层样本更少、层间协变量漂移更大。更危险的是**适配反馈回路**：系统越适应某地，越少触发安全事件，监测器就越相信「这里安全」，形成「用适应性证明安全性」的循环论证。解法：安全核与适配层**信息流隔离**；跨文化校准必须携带**传输证书**（不可迁移即退回保守全局阈值）；对齐债与新颖度做**双闸门**；安全事件率只由**独立审计/红队样本**评估，绝不用部署反馈自证。

## 1. 研究问题（本轮要回答什么）

- **Q1（可适配边界）**：文化维度中哪些可以合法改变系统行为，哪些必须文化不变？能否给出类型级与证明级的分离，而不是靠人写规则？
- **Q2（保证迁移）**：按文化分层 / 条件化后，覆盖与风险保证如何跨站点迁移？在什么漂移条件下可迁移，不可迁移时如何优雅退化而不虚假声称 `1−α`？
- **Q3（规范冲突与多元）**：地方规范与安全核、或地方规范彼此冲突时如何仲裁、何时弃权 / 询问？能否证明「零强加不安全偏好」与「零强加未获同意的文化偏好」，并守住询问预算？
- **Q4（对齐漂移）**：文化适配会不会通过反馈回路自我合法化？如何度量并夹住「对齐债」，使长期偏离有界、可冻结、可回退？

## 2. 五条设计原则（雏形，正式化见产物区定义 448–463）

**P1 安全核文化不变（Culture-Invariant Safety Kernel, CISK）**
存在不依赖 `κ` 的安全不变量 `I_safe` 与安全动作集；任何 `π_κ` 必须满足 `Safe(π_κ) ⊇ I_safe`。实现上用**信息流隔离**保证：`κ` 的污点不得流入安全盾判定，文化层只能在盾之后做等价类内重排。

**P2 文化闭包（Culture Closure）**
`κ` 只能从预注册「约定包」`C₀`（单位制、公差标准、材料惯例、交互礼节、风险姿态带）中选择；不得自由文本直达执行器或校准器；风险姿态不得低于 `ρ_min`。任一越权槽位输出 `⊥`，退回 `κ₀`（无文化条件）。

**P3 传输或退化（Transport-or-Degrade）**
跨文化校准必须携带**传输证书**：记录密度比界 `M`、新颖度 `ν`、源层样本量。只要 `M` 或 `ν` 越界、或样本不足，就回退全局保守阈值——**绝不在覆盖已失效时继续声称 `1−α`**。保证可以降级，但不能撒谎。

**P4 多元弃权（Pluralistic Abstention）**
把每个偏好对分成三类：安全可判、文化可判、价值欠定。欠定时系统弃权或有界询问，**零强加**：既不把地方惯例抬成安全规则，也不把某地偏好强加给另一地。

**P5 对齐债预算（Alignment-Debt Budget）**
适配带来的策略偏离要记账：`D_align(t)` 累计、`B_align` 封顶。超预算即冻结适配并回退参考策略 `π_ref`；配合 anytime-valid 漂移监测，使「越适配越安全」的自证回路无法闭环。

## 3. 与基线的接口（如何退化）

- `κ` 不可接地 / 超出约定包 / 风险姿态低于下界 ⇒ 使用 `κ₀`，等价于 InstructGauge 的无文化条件路径；
- 传输证书失效 / 新颖度越界 / 分层样本不足 ⇒ 回退全局校准（即第 3 轮 SC-Cal 再退一步）；
- 规范冲突不可由安全核消解 ⇒ 弃权 + 有界询问，动作退回默认安全策略；
- 对齐债超预算 / 漂移 tripwire 触发 ⇒ 冻结适配，回退 `π_ref`；
- 文化模块整体失效 ⇒ InstructGauge ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE 原样。

文化适配是增强项，不是依赖项：关掉 `κ` 不会丢失任何安全性质，只会丢失「本地表达与偏好」的收益。

## 4. 预期贡献

1. 一个「可适配 / 文化不变」的**类型化分离**（CCC + CISK），把文化注入面压到可静态检查的约定包内，并给出信息流非干扰式的安全论证；
2. 一套**带传输证书的跨文化共形校准（SACT）**，给出可迁移/不可迁移判据与覆盖降级界，修正「条件化破坏可交换性 + 层间漂移」的双重失效；
3. 一个**规范冲突仲裁 + 多元弃权（NCA）**框架，证明不安全偏好强加数为 0、欠定偏好强加数为 0，且询问次数有界；
4. 一个**对齐债 + 漂移 tripwire（ADM）**，给出长期偏离的随机界，并阻断「适应性自证安全」的反馈回路；
5. 一条完整可证伪路径：E457–E472 覆盖文化闭包、单位/标准安全、跨站点覆盖、传输失效、冲突仲裁、多元弃权、对齐债、漂移检测、适配深度最优、多站点现场、跨文化红队、收缩校准、消融、50Hz 时序、sim→real 迁移与审计复现。

## 5. 本轮最大风险

**一句话**：文化适配最危险的不是「适配错了」，而是「适配得太成功」——系统把地方惯例学成默认、把部署反馈当成安全证据，于是对齐债在无人察觉中累积；一旦 CISK 的信息流隔离有实现漏洞，文化层就会从「改偏好」悄悄变成「改底线」，而所有统计指标仍会显示一切正常。

## 2. 形式化定义（要点）

**定义 448（文化上下文卡 `κ`）**
`κ = (loc, unit, std, mat, comm, ρ) ∈ K_ctx`，各槽位均有类型与白名单值域：`unit ∈ U₀`（SI/英制等）、`std ∈ S₀`（ISO GPS / ASME Y14.5 等）、`mat ∈ Mat₀`（表面处理与材料惯例）、`comm ∈ Comm₀`（交互礼节与语言）、`ρ ∈ [ρ_min, ρ_max]`（风险姿态带）。`κ` 是**类型化对象**，不是自由文本；其任何字段都不直接进入执行器。

**定义 449（文化接地 `Γ_c` 与文化闭包 `CC_c`）**
`Γ_c: Context × C₀ → (κ, CultureCert) ∪ {⊥}`。文化闭包公理：
`convention(κ) ⊆ C₀ ∧ ρ(κ) ∈ [ρ_min, ρ_max] ∧ ¬∃ free-text → (actuator ∨ calibrator)`。
任一槽位类型/白名单检查失败、风险姿态低于 `ρ_min`、或出现未注册约定 ⇒ 输出 `⊥`（退回 `κ₀`）。`CultureCert` 逐槽记录取值、来源与置信度，供审计。

**定义 450（约定映射 `Conv_κ` 与转换安全）**
`Conv_κ` 在单位、公差标准与取整规则之间做可逆映射，要求：`Conv_κ^{-1} ∘ Conv_κ = id`（在可采纳定义域上）、强制单位量纲标签、转换误差 `≤ ε_conv`、禁止无量纲标签的裸数值跨单位传递。缺失单位标签是**静态类型错误**，直接 `⊥`。

**定义 451（文化无关安全核 CISK 与 `κ`-独立性）**
策略族 `{π_κ}_{κ∈K_ctx}`，安全不变量 `Inv(σ, a)` 与安全动作集 `A_safe(σ)` **其表达式不引用 `κ`**。要求：
`∀κ: Safe(π_κ) ⊇ I_safe ∧ (a ∉ A_safe(σ) ⇒ π_κ(·|σ) 不给 a 正概率)`。
进一步要求**信息流非干扰**：`κ` 的污点不得出现在安全盾的判定依赖中（类型/污点分析可静态检查），故文化层在原理上无法改变 `A_safe`。`π_ref` 是不含文化条件的参考对齐策略，作为对齐债的零点。

**定义 452（文化偏好序 `≻_κ` 与安全等价类）**
`≻_κ` 只定义在安全等价类 `[a]∼safe = {a' : A_safe 判定与安全后果等价}` 内；且必须延拓系统安全序：`a ≻_safe b ⇒ ¬(b ≻_κ a)`。即文化可以重排等价类内部，**不能反转任何安全优先级**。

**定义 453（文化分层与校准集）**
`stratum(κ, ι) = s_c = (loc, std, goal 类型)`（可再细分为 `(loc, std, goal, 指代个数)`）。每层校准集 `C_cal^{s_c}`；采用**分层收缩**：`q_s = λ_s q_local + (1−λ_s) q_global`，`λ_s = n_s/(n_s + n₀)`。`n_s < n_min` ⇒ `λ_s ≈ 0`，自动回退全局。

**定义 454（跨文化重要性权重与传输证书）**
设源层分数分布 `P_s`、目标站点 `P_t`。权重 `w(x) = p_t(x)/p_s(x)`，截断到 `[1/M, M]`。`TransportCert = (s→t, M, ν, n_s, δ_w, q_t)`，其中 `δ_w` 为权重估计误差界。**传输准入**：
`n_s ≥ n_min ∧ M ≤ M_max ∧ ν ≤ ν_max ∧ Lip_w·δ_w ≤ Δ_budget`。
不满足 ⇒ 证书标 `REJECT`，使用全局阈值。

**定义 455（SACT 传输分位）**
令分数 `S_i`（校准残差）与权重 `w_i`。传输分位
`q_t = inf{ q : Σ_i w_i·1[S_i ≤ q] / Σ_i w_i ≥ 1−α }`。
若权重精确且支撑重叠，目标边际覆盖 `≥ 1−α`；权重估计误差与截断使覆盖按引理 61 降级。`q_t` 只在 `TransportCert.ACCEPT` 时生效。

**定义 456（文化新颖度 `ν`）**
`ν = d_Mahalanobis(φ(x_t), μ_s, Σ_s)` 或 `kNN` 距离，度量目标站点输入相对源校准集的分布外程度；`ν > ν_max` 视为「该文化情境没有可迁移证据」，强制回退全局。

**定义 457（规范冲突仲裁 NCA）**
对每个待决偏好对 `(a, b)`，按序分类：
1. **安全可判（SR）**：若 `a, b` 不在同一安全等价类，按 `≻_safe` 决策；
2. **文化可判（CR）**：若 `a ∼safe b` 且本地 `≻_κ` 严格可判，按 `≻_κ` 决策；
3. **价值欠定（UD）**：若 `a ∼safe b` 且 `≻_κ` 不可比 / 与其它层冲突，标记欠定。
UD 对**不得**由系统单方面选择任一方；只能询问或弃权。

**定义 458（有界询问与弃权）**
每回合询问预算 `Q_max`（次数与延迟双重上限）。每次 UD 调用消耗一次；预算耗尽 ⇒ 执行 `π_abs`（默认安全中性动作或延后），并记录未决项。弃权不是失败，而是**拒绝强加**的可审计行为。

**定义 459（对齐债 `D_align` 与预算 `B_align`）**
`D_align(t) = Σ_{τ≤t} d(π_κ(·|x_τ), π_ref(·|x_τ))`，`d` 取截断 TV / KL（单步 `d_τ ∈ [0, d_max]`）。仅当 `D_align(t) + E[d_{t+1}] ≤ B_align` 时允许继续适配；否则冻结适配、回退 `π_ref`。

**定义 460（对齐漂移监测 ADM）**
维护 anytime-valid e-process `e_t = Π_{τ≤t} (1 + λ_τ (d_τ − μ₀))`（或 betting e-value），在「无漂移」零假设下 `P(sup_t e_t ≥ 1/β) ≤ β`。触发条件：`e_t ≥ 1/β` 或 `D_align > B_align`。审计样本必须**独立于部署反馈**（红队 / 留出站点 / 人工抽检），以打断「越适配越安全」的自证回路。

**定义 461（双闸门准入）**
一次文化适配被接纳当且仅当：
`TransportACCEPT ∧ (D_align + ΔD ≤ B_align) ∧ ν ≤ ν_max ∧ CultureCert 有效`。
两个闸门是**与**关系：统计可迁移不等于对齐可接受，对齐可接受也不等于统计可迁移。

**定义 462（适配深度 `κ_adapt` 与收益-风险曲线）**
令本地先验 `p_local`、全局先验 `p_global`，插值 `p(κ_adapt) = (1−κ_adapt) p_global + κ_adapt p_local`（阈值同理）。定义净效用 `U(κ_adapt) = b(κ_adapt) − r(κ_adapt)`：`b` 为本地任务收益（凹、边际递减），`r` 为对齐风险（凸、边际递增，跨过安全边界后超线性）。这是一条**可实测**的曲线（E465）。

**定义 463（文化适配证书 `CultiCert` 与审计链 `RepairCert″`）**
`CultiCert = (κ, CultureCert, TransportCert, NCA 记录, D_align, ADM 判定)`；
`RepairCert″(s) = (κ, ι, C, ChunkCert, receipts, claims, CultiCert, 冲突/弃权日志)`。
审计者可沿「文化卡 → 约定转换 → 指令 → 块 → 逐步回执 → 主张 → 冲突裁决」七级证据链复现一次决策，并检查每一级是否越权。

class CultureCard:
    def ground(self, ctx, packs):

            return None

# IP-329 CISK：安全核不引用 κ；文化只能在盾之后重排
class CISK:
    def gate(self, state, action):                     # 无 κ 参数，静态可查
        return Inv(state, action) and action in A_safe(state)

    def wrap(self, policy_kappa):
        def pi(state):
            a = policy_kappa(state)                    # 文化可做等价类内重排
            if not self.gate(state, a):
                self.log_taint_violation(a)             # κ 试图越界：拒绝并告警
                return self.safe_default(state)
            return a
        return pi                                      # 污点分析：κ 不流入 gate

# IP-330 SACT：传输准入 + 加权共形（不可迁移即退化）
class SACT:
    def transport(self, kappa, cal, target):
        s   = stratum(kappa)
        src = cal.get(s, [])
        nu  = novelty(target, src)
        w, M = clipped_density_ratio(target, src, M_MAX)
        cert = TransportCert(s, M=M, nu=nu, n=len(src))
        if len(src) < N_MIN or M > M_MAX or nu > NU_MAX:
            return self.global_quantile(cal), cert.reject()
        q = weighted_conformal_quantile(src, w, alpha=ALPHA)
        return q, cert.accept()

# IP-331 NCA：三分类仲裁（零强加）
def arbitrate(a, b, kappa, budget):
    if not same_safety_class(a, b):                    # SR：安全可判
        return safe_preferred(a, b)
    if comparable(kappa.order, a, b):                  # CR：文化可判
        return kappa.order.preferred(a, b)
    if budget.spend():                                 # UD：有界询问
        return query_human(a, b)
    return ABSTAIN                                     # 零强加

# IP-332 ADM：对齐债 + anytime-valid 漂移检验
class AlignmentMonitor:
    def observe(self, x, a_kappa):
        d = divergence(self.pi_ref(x), a_kappa)
        self.debt += d
        self.evalue *= (1.0 + self.lam * (d - MU0))
        if self.debt > B_ALIGN or self.evalue >= 1.0 / BETA:
            self.freeze_adaptation()                   # 回退 π_ref，冻结 κ_adapt
            return "freeze"
        return "ok"

# IP-333 8C 闭环
def cultigauge_8c(M, s, ell, ctx):
    out   = M.ccc.ground(ctx, M.packs)
    kappa = out[0] if out else M.kappa0                # ⊥ ⇒ 无文化条件
    out   = M.nlib.ground(ell, M.scene, M.ontology, kappa)
    iota  = out[0] if out else M.default_iota

    C     = M.iac.plan_chunk(iota, H, M.tools, M.budget_left(s), M.drift_bound(s))
    C     = M.cisk.filter_chunk(C)                     # 文化不能增删/改安全动作
    if not M.tcv.verify(C.as_program(), M.budget_left(s))[0]:
        C = M.numeric_fallback(H)
    cert     = M.cvc.commit(C, M.env, iota)
    receipts = cert.receipts
    if len(receipts) < n_min(s):
        return stub_and_red(s, "insufficient")
    mu, Sig = M.apcal.calibrate(receipts, H, s)
    q, tcert = M.sact.transport(kappa, M.cal, M.target_stats)
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
        return stub_and_red(s, "cross_failed")
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s, q)   # 仅传输准入时用 q
    if not contract_regression(new_ec):
        return stub_and_red(s, "regression")
    M.mreg.hot_replace_at_quiescence(M.dpe, new_ec, cert.boundary)
    bind_claims(cert, iota, receipts)
    action = M.nca.arbitrate(cert.next_action, cert.alt_action, kappa, M.qbudget)
    verdict = M.adm.observe(M.scene, action)
    if verdict == "freeze":

## 4. 推导

**引理 59（文化闭包下的安全核不变性）**
若 `Γ_c` 满足文化闭包 `CC_c`、`Conv_κ` 量纲安全、`≻_κ` 延拓 `≻_safe`，且安全盾不读取 `κ`（`κ`-非干扰），则对任意 `κ ∈ K_ctx`：`Safe(π_κ) ⊇ I_safe`，且 `Inv` 沿执行保持。
*证明骨架*：策略的动作来源仍受第 3 轮引理 51 约束（`Plan(ι) ⊆ Plan_ToolGauge`）；文化层只能对 `[a]∼safe` 内元素重排（定义 452），重排不改变集合、不反转安全序；`Γ_c` 的闭包使 `κ` 无法引入新约定、新工具或更低的 `ρ`；安全盾在文化重排之后执行且其判定不含 `κ`（定义 451 的非干扰），故任一越界动作被 `A_safe` 拦截。对时间归纳即得 `Inv` 保持。文化层因此**不能降低安全底线**，只能改变等价类内的偏好与表达。

**引理 60（约定转换的语义安全）**
在强制单位标签、量纲检查与可逆性条件下，`Conv_κ` 在可采纳定义域上把任一公差谓词 `P` 映射为 `P'`，满足 `|P'(x) − P(Conv_κ x)| ≤ ε_conv`；且不存在「静默单位错配」——缺失/冲突标签必为静态错误 `⊥`。
*证明*：量纲分析保证单位换算的齐次性；可逆性给出双射；对不等式谓词用三角不等式即得误差界 `ε_conv`。标签缺失使类型检查失败，按定义 450 直接 `⊥`，故错误不可能静默进入数值路径。

**引理 61（跨文化传输覆盖界）**
设源/目标分数分布为 `P_s, P_t`，密度比 `w` 截断于 `[1/M, M]`，权重估计误差 `δ_w`。当 `TransportCert.ACCEPT` 时，目标覆盖
`P(h* ∈ H_t) ≥ 1−α − Δ_n − Lip_w·δ_w − Δ_clip`，
其中 `Δ_n = O(√(log(1/δ)/n_s))`，`Δ_clip` 由截断引入且随 `M` 单调。若 `REJECT` 并回退全局，则由第 3 轮引理 55 的退化结论得覆盖 `≥ 1−α − 2η_global`。故「传输或退化」保证覆盖**只会降级、不会虚假**。
*证明骨架*：加权共形在权重精确时给边际覆盖 `≥1−α`（加权分位的中位无偏性）；权重误差经 `Lip_w` 放大、有限样本经 DKW 型界给出 `Δ_n`；截断改变尾部权重，其偏差由 `Δ_clip(M)` 控制。`REJECT` 分支直接引用全局共形的已知退化界。

**引理 62（NCA 的健全性、完备性与零强加）**
每个偏好对必落入 `SR / CR / UD` 之一（三分类完备）；若落入 `SR`，决策与 `≻_safe` 一致；若落入 `CR`，决策不越出 `[a]∼safe`；若落入 `UD`，系统不单方面选择任一方。因此：**强加不安全偏好数 = 0**，**强加未同意的文化偏好数 = 0**，且每回合询问次数 `≤ Q_max`。
*证明*：按定义 457 的分类互斥且穷尽；`SR` 分支直接调用安全序；`CR` 分支由定义 452 限定在等价类内；`UD` 分支仅允许询问/弃权（定义 458），预算计数器单调递增，故询问数有界。对决策序列归纳即得两类强加计数恒为 0。

**引理 63（对齐债的有界性与冻结保证）**
若单步偏离 `d_τ ∈ [0, d_max]`，则适配活跃期间 `D_align(t) ≤ B_align + d_max`；一旦越界即在下一步冻结，长期偏离被 `B_align + d_max` 夹住。ADM 的 e-process 在无漂移零假设下满足 `P(sup_t e_t ≥ 1/β) ≤ β`（Ville 不等式），故误冻结概率 `≤ β`；在真实漂移下冻结时间几乎必然有限。
*证明*：债是带预算的单调累加，超预算即触发定义 459 的冻结分支；e-process 的非负上鞅性与 Ville 不等式给出 anytime-valid 误报界；正漂移使对数 e-value 有正漂移，由鞅收敛/可选停止得有限期望命中时间。

**引理 64（适配深度的比较静态）**
若 `b` 凹增、`r` 凸增且 `r` 在安全边界附近超线性，则 `U(κ_adapt)=b−r` 单峰，最优深度 `κ*_adapt` 满足 `b'(κ*) = r'(κ*)`，且 `κ*` 随本地样本量 `n_s` 与传输质量（`M` 小、`ν` 小）递增，随安全边界收紧（`ρ_min` 提高、`B_align` 减小）递减。过度适配（`κ_adapt > κ*`）的净损失超线性增长。
*证明*：凹−凸的净函数严格拟凹，一阶条件给唯一内点；比较静态由隐函数定理对 `b', r'` 的参数依赖给出；超线性风险项使 `U` 在 `κ*` 右侧以快于线性的速率下降。E465 直接检验该曲线的峰位与斜率。

**引理 65（分层收缩校准的覆盖与优雅退化）**
在层内可交换且收缩系数 `λ_s = n_s/(n_s+n₀)` 下，分层收缩估计的覆盖
`P(h* ∈ H_s) ≥ 1−α − 2η_s`，其中 `η_s = O(λ_s·bias_local + (1−λ_s)·η_global + √(log(1/δ)/n_s))`。当 `n_s → 0` 时 `λ_s → 0`，覆盖连续退化为全局界 `1−α−2η_global`。
*证明*：收缩估计的偏差-方差分解；层内共形给 `1−α` 基础覆盖，收缩引入的偏差按 `λ_s` 加权，全局项按 `1−λ_s` 加权；`n_s→0` 时 `λ_s→0`，即为第 3 轮引理 55 的全局退化情形，故无覆盖悬崖。

**引理 66（8C 闭环的严格退化与 50Hz 保全）**
当 `CCC` 返回 `⊥`（`κ=κ₀`）、`SACT` 回退全局、无 `UD` 冲突、`ADM` 关闭时，CultiGauge-8C 与 InstructGauge-7C 逐指令等价；`CultiCert` 与冲突日志只是序列化投影，不改变数值行为。主闭环 50Hz 路径不新增同步工作，继承第 3 轮引理 57/58 与 ToolGauge 引理 50 的硬实时结论。
*证明*：逐分支对照 7C：`κ₀` 下 `Γ_c` 与 `Γ` 的目标一致、`filter_chunk` 为恒等、`q` 取全局即 SC-Cal、`ADM` 关闭即无冻结；所有新增量仅进入证书。时延由「文化路径全异步 + 块静默点热替换」保证，与 7C 相同。
