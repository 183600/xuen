# 第 1 轮（承接 v17 / 原第 40 轮）· 快速原型 × 人机协作：人机共创技能工坊 —— 渐进担保阶梯 × 干预即契约（四层架构 v6）

> 承接 v17（原第 40 轮：可认证流匹配执行 × 度量语义几何锚定 × 证书驱动课程引擎）。本轮灵感词「快速原型、人机协作」不再往证书体系上再叠一层证明，而是反过来问：**证书能不能成为加速原型的脚手架，而不是原型结束后的验收税？** 答案是把技能开发重写成一场「人给先验、机器给证据」的共写过程：首个演示即生成可执行影子原型，人的每次纠偏被编译成带类型的契约补丁，临时证书随证据增长而收紧，技能沿一条可降级的担保阶梯逐级晋升。

## 0. 直觉与动机

**灵感 1（快速原型 → 把证书从「终点验收」变成「沿途脚手架」）**：在机器人竞赛里，真正拖慢原型的通常不是写不出算法，而是「有一个想法」到「有一个可信、可演示、可回滚的技能」之间的验证回路太长。v17 的证书体系极强，但它天然是终点式的：先把策略练好，再由 RCA 一次性颁发 CertBundle。对快速原型而言，这是把最贵的工作押在最后一步。本轮把这个顺序倒过来：**第一次人类演示就产出一个立刻能跑影子模式的技能原型，并附一份「诚实但宽松」的临时证书**；之后每一次仿真测试、真实回放、人类纠偏，都只做两件事——缩小证书宽度、抬高担保等级。于是「快」不是靠跳过验证获得，而是靠把验证切碎、前移、并和人的交互交织。可度量的「快」是原型半衰期 T½（从 L0 意图到 L2 经验闭合）与人类总投入 H（分钟/技能）。

**灵感 2（人机协作 → 人是最便宜的「先验源」，机器人是最便宜的「验证器」）**：协作不只是运行期的共享自治，更是开发期的分工。人有三样机器昂贵的东西：任务意图、常识先验、对「哪里不对」的即时判断；机器人有三样人昂贵的东西：可重复执行、可累积统计证据、可形式化验证的安全包络。因此理想的协作不是「人盯着机器人做」，而是**把人的注意力当作稀缺查询预算，只在证书赤字最大、且一次回答能最大幅降低风险的时刻请求介入**；请求还必须以「最小反事实」呈现（「走 A 有 3% 碰倒风险，绕 B 多花 2 秒，你要哪个？」），把开放式调试变成一次低成本选择。人给出的纠偏不应是散落的数据，而应被编译成**带类型的契约补丁**，先过硬不变量检查，再进入证据账本。

**两个灵感的耦合**：快速原型提供「回路」，人机协作提供「查询」，渐进担保阶梯提供「晋升规则」。三者咬合后，证书第一次有了明确的**作者协议**：人写意图与约束，机器写证据与边界，二者共同签署每一级晋升。它也直接回应 v17 自己点出的最大风险——「装饰性证书」：如果证书的每一步增长都必须对应一次可审计的人类交互或一次可复现的测试，证书就不可能在无人注意时悄悄失真；反过来，如果人类交互没有被类型检查与物理证据三角校验，它也可能把「人以为对」的偏差固化成「看似正式」的证书。这正是本轮最需要守门的地方。

## 1. 形式化定义

**定义 27（可执行技能原型 ESP）**：原型 Π = (I, D, K, π, C, L, E)。
- I ∈ IntentLang：带类型意图（目标谓词、对象、空间关系、节拍/韵律偏好）；
- D：演示集（遥操/VR/动捕），K：人类干预集；
- π：当前策略（可直接复用 IP-48 流匹配骨干，或最近技能 + 适配器）；
- C = (Pre, Post, Cert, Assumps)：技能契约，Post 用 C_ms（定义 25），Cert 可为临时证书（定义 29）；
- L ∈ {0,1,2,3,4}：担保等级（定义 28）；
- E：证据账本（测试结果、边际估计、补丁来源、覆盖计数）。
- **可执行性不变式**：任意时刻 π 至少能在影子模式或仿真沙箱中执行；原型永远不是一个「只有文档」的规格。

**定义 28（渐进担保阶梯 PAL）**：五级格 L0 ≺ L1 ≺ L2 ≺ L3 ≺ L4。
- L0 意图草图：仅有 I 与自动生成的测试草案；不可驱动本体；
- L1 可执行影子：π 在仿真/回放中运行，可产出差异报告，但不驱动物理执行器；
- L2 经验闭合：机器人可在低速/安全笼内执行；以置信下界保证成功率与硬约束违约率；
- L3 证书闭合：CertBundle（IP-46）全量成立，ValidRegion(C) 非空（IP-49）；
- L4 服务发布：进入 IP-45 总线，带金丝雀流量、RCA 监控与自动回滚。
- **门控谓词** G_k(Π) = [覆盖 Cov≥ρ_k] ∧ [样本 n≥n_k] ∧ [成功率 LCB≥τ_k] ∧ [违约率 UCB≤ε_k] ∧ [所有补丁类型检查通过] ∧ [k≥3 ⇒ 硬不变量与 ValidRegion 成立]。
- **晋升/降级自动机**：仅当 G_k 成立才允许 L_k → L_{k+1}；RCA 检出漂移或硬不变量失败则立即降级（至少回到 L2，保留证据）。ε_0 ≥ ε_1 ≥ … ≥ ε_4，证据账本单调增长（降级不删除证据）。
- **定理 1（阶梯可靠性）**：若每次晋升都通过 G_k，且统计界取 (1−δ_k) 置信，则处于 L_k 的原型满足 P(违约率 ≤ ε_k) ≥ 1−δ_k；处于 L3 及以上的原型在 ValidRegion 内硬安全不变量以概率 1 成立。证明：L2 由 Clopper–Pearson/Hoeffding 类的单侧界直接给出；L3 复用 IP-46/IP-49 的证书合取与几何有效域；晋升门控排除了未覆盖的合取项。

**定义 29（临时证书 CertProv）**：CertProv = (m̂₁…m̂₆, lcb, ucb, n, δ, coverage)，把 v17 的点估计边距替换为单侧置信界：成功率用 Clopper–Pearson 下界，硬约束违约率用 Clopper–Pearson/经验 Bernstein 上界，Lipschitz 与漂移界用重采样或集中不等式给出保守界。定义证书宽度 W = Σᵢ (ucbᵢ−lcbᵢ)/cᵢ 与证书赤字 D = Σᵢ wᵢ·max(0, 1−lcbᵢ/cᵢ)（复用定义 26 的形式）。临时证书的「诚实」体现为：n 小则 W 大、等级上限低，绝不把宽区间伪装成紧证书。

**定义 30（干预即契约 IaC）**：补丁语言
Δ ::= AddPre(φ) | ConstrainAction(U) | Tighten(mᵢ, δ) | AddDemo(D′) | SetProsody(s) | AddAssumption(α) | Confirm(ψ)。
类型判定 C ⊢ Δ : safe/unsafe：
- 若 C⊕Δ 不削弱任何硬不变量、不放宽 Post、不缩小 ValidRegion，则 Δ 为 safe；
- 若 Δ 试图放宽 Pre、弱化安全边界或删除证据，则为 unsafe，必须强制降级到 L2 重验；
- safe 补丁保持当前等级的担保；unsafe 补丁不允许直接晋升。
- **定理 2（补丁合成）**：作用在不同契约字段上的 safe 补丁可交换（CRDT 式合并）；作用于同一字段且互斥的补丁不自动合并，进入人工仲裁；合并结果构成补丁偏序上的 join。
- **最小补丁原则**：对一次纠偏，优先选取能解释该纠偏的最小约束修改（类似于最小反事实解释），以降低契约漂移与人类认知负担。

**定义 31（求助价值与主动交接 VoI）**：设隐意图 θ（约束、参考轨迹、韵律、优先级）有后验 p(θ|E)，策略风险 R(π,θ)。一次查询 q = (状态 x, 最小反事实对 (a₁,a₂)) 的求助价值
VoI(q) = [ E_p(θ|E) R(π,θ) − E_{y∼p(y|q)} E_{p(θ|E,q,y)} R(π,θ) ] / (c_h(q) + λ·ℓ(q))，
其中 c_h 为人类回答成本、ℓ 为交接延迟。查询选择 q* = argmax VoI(q)，受人类预算 B_h 约束。
- **定理 3（贪心近优，条件性）**：若查询带来的风险下降关于已选查询集是自适应次模的，则贪心 VoI 选择达到 (1−1/e) 近似；若人类标签有噪声（正确率 1−η），则只有当 η < η_max（由晋升门控的 δ、ε 反解）时，定理 1 的可靠性仍成立；否则必须用仿真/物理证据做三角校验。
- 工程含义：机器人不是「遇事就问」，而是「只在问一次能改变晋升结论时问」。

## 2. 三大产出设计

### 2.1 IP-51 PROTOTYPE-FOUNDRY（人机共创技能工坊）
1. **四通道输入**：自然语言意图、少量演示、时空标注（点云/图像上的抓取点、禁入区）、规则片段；统一解析为带类型的任务图（复用 IP-47）。
2. **一键编译**：意图 + 演示 → 最近技能/流匹配策略 + 初始契约；缺失技能自动走「最近邻 + 适配器」，先产出 L0/L1 可运行原型。
3. **自动测试生成**：由 Pre/Post 与 C_ms 反推场景分布，生成仿真用例与对抗扰动；测试用例同时作为证据账本的初始条目。
4. **影子优先**：先在回放/数字孪生中运行，输出「人预期 vs 机器执行」差异报告；差异即下一轮查询候选。
5. **原型半衰期仪表**：记录 L0→L2 的时间、人类分钟数、证书宽度收缩曲线，作为工坊的核心 KPI。

### 2.2 IP-52 ASSURANCE-LADDER（渐进担保阶梯）
1. 五级门控与升降级自动机（定义 28）；每级有独立的覆盖/样本/成功率/违约率阈值。
2. 临时证书的统计引擎：CP 下界、经验 Bernstein 上界、边际重采样；把「证书宽度」作为显式优化目标。
3. **担保预算分配**：把有限测试与人类查询视为预算，用多臂bandit/贪心 VoI 在六类证书赤字间分配，优先补最影响晋升结论的短板。
4. 金丝雀与回滚：L4 按流量比例放量；RCA 漂移、硬不变量失败、或人类否决率突增 → 自动降级并热更新契约（复用 IP-45/46）。

### 2.3 IP-53 INTERVENTION-CONTRACT（干预即契约）
1. **干预采集**：纠偏（执行中改动作）、声明（说规则）、示范（再演示一段）、批准/否决（对反事实对投票）统一成事件流。
2. **补丁编译与类型检查**：事件 → 最小补丁 → safe/unsafe 判定 → 契约 diff；unsafe 触发降级与解释，而不是静默接受。
3. **来源账本与多人合并**：每个补丁带人 ID、时间、证据引用；不同字段 CRDT 合并，同字段冲突进入仲裁视图。
4. **最小反事实交接**：把「求助」渲染成一两个风险-代价可比的选项，降低人类认知负荷；交接语言直接复用 IP-43 的韵律/节拍通道。
5. **回流训练**：人类纠偏按证书赤字加权进入 IP-50 课程回放，并作为 IP-44 少样本蒸馏的高价值样本。

## 3. 四层架构 v6

```
L0（新增）人机共创层：意图/演示/标注/规则 → IP-51 FOUNDRY（自动测试 + 影子）
          ↕  IP-52 担保阶梯（L0→L4 门控、升降级、金丝雀）  ↕ IP-53 干预契约（补丁/合并/VoI 交接）
L1: TRI-FUSE + IP-49 LIO/点云语义融合 → 度量语义图 C_ms + 漂移界 B_t
L2: CTC + VLM + IP-35 仲裁 → R_φ(w₁~w₆) + 几何残差证书
L3: IP-47 任务代数（C_ms 类型检查）→ IP-39 规划（几何 CBF）→ IP-45 总线（草稿/金丝雀通道）
    → IP-48 认证流匹配执行 + IP-43 韵律条件速度场 → RCA 监控（流证书+几何证书）
L4: IP-44 蒸馏 + IP-50 课程引擎闭环 → RCA 重颁证书 → 契约热更新
运行期：技能总线 + 区域化 RCA + TAE + MetaAdapter + 自适应步数流采样 + LIO/ESDF + 课程带自适应
         + 人机共享工作空间安全包络 + 主动交接（VoI 查询）
```

## 4. 实验设计（E73-E78 硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E73 原型半衰期 | 10 个新技能 L0→L2 的中位时间 vs v17 手工流水线 | ≥5x 加速，中位 ≤45 min |
| E74 人类负担/证书产出 | 每个 L3 技能的人类分钟数；每人类分钟降低的证书赤字 | ≤1/3 v17；单分钟产出 ≥2x |
| E75 纠偏样本效率 | 达 85% 成功率所需纠偏数 vs HG-DAgger；采集期硬违约 | 纠偏数 ↓≥40%；硬违约 = 0 |
| E76 求助质量 | 每次查询的成功率提升/违约率下降 vs 随机与不确定性采样；交接延迟 | ≥2x；≤20 次/技能；<1.5 s |
| E77 阶梯可靠性 | 100 次晋升中不可靠晋升数；各级实测违约率；降级检出时延 | 0 次；≤ε_k；≤1 个 episode |
| E78 端到端人机协作 | 共享工作空间任务成功率、信任校准误差、近碰撞率 | ≥90%；≤0.1；不劣于 v17 |

回退路径：E77 或 E75 不达标 → 回退 v17 的终点式证书流水线（保留 IP-51 仅作离线原型工具，禁用 L3/L4 自动晋升）；E73 不达标但安全性达标 → 保留阶梯，仅作「验证前移」而非「快速晋升」。

## 5. 本轮最大风险

**一句话**：本方案最致命的失败不是原型不够快，而是「人在环」退化为「人在盖章」——当人类监督稀疏、有偏且被平滑的演示误导时，临时证书的形式感会制造自动化偏置，让阶梯把从未被采样过的失效模式「认证」成安全，因此必须以 E77 的零不可靠晋升与三角校验作为第一守门条件。

## 2. 关键算法

```
def foundry_compile(intent, demos, annotations, rules):
    phi  = parse_intent(intent)                         # 带类型目标
    G    = task_algebra.plan(phi)                       # IP-47
    pi0  = nearest_skill_or_adapter(G, demos)           # 默认 IP-48 流策略

                    Post  = phi,
                    Cert  = provisional_cert(pi0, demos),
                    Assumps = surface_assumptions(G))
    E    = Evidence(demos=demos, tests=auto_gen_tests(C), patches=[])
    L    = L1 if shadow_ok(pi0, E) else L0
    return ESP(intent=intent, policy=pi0, contract=C, level=L, evidence=E)

def shadow_report(proto, replay_buffer):
    diffs = []
    for x in replay_buffer:
        a_human = x.action if x.has_human else None
        a_robot = proto.policy(x.obs)
        if a_human and divergence(a_human, a_robot) > tau:
            diffs.append((x, a_robot, a_human))         # 下一轮查询候选
    return diffs
```

### IP-52 阶梯推进（伪代码）
```
def pal_step(proto, budget):
    while budget > 0:
        k = proto.level
        if k < 3:
            q = argmax_voi(candidate_queries(proto, budget))
            if q and voi(q) > 1.0:
                y = human.respond(q)                    # 一次最小反事实选择
                proto = apply_patch(proto, compile_patch(q, y))
        E = run_tests(proto, sim=True, shadow=True)     # CP/Bernstein 更新
        proto.evidence.merge(E)
        if gate(k + 1, proto):                          # 定义 28 的 G_k
            proto.level = k + 1
            if k + 1 == 4: mesh.publish_canary(proto)
        if rca.drift(proto) or not invariant_ok(proto):
            proto.level = min(proto.level, 2)           # 降级但保留证据
        budget -= cost(E)
    return proto

def gate(k, proto):
    return (coverage(proto.E) >= rho[k]
            and n(proto.E) >= n_min[k]
            and lcb_success(proto.E) >= tau[k]
            and ucb_violation(proto.E) <= eps[k]
            and all(typecheck(proto.C, d).safe for d in proto.K)
            and (k < 3 or hard_invariant_ok(proto) and valid_region_nonempty(proto)))
```

### IP-53 干预即契约（伪代码）

```
def compile_patch(query, response):
    if response.kind == 'corrective':
        return Patch.ConstrainAction(minimal_action_constraint(query.x, response.a))
    if response.kind == 'declarative':
        return Patch.AddPre(parse_rule(response.rule))
    if response.kind == 'demo':
        return Patch.AddDemo(response.trajectory)
    if response.kind == 'approve':
        return Patch.Confirm(query.counterfactual)
    if response.kind == 'veto':
        return Patch.ConstrainAction(complement(query.counterfactual))

def typecheck(C, patch):
    C2 = C.apply(patch)
    if weakens_hard_invariant(C, C2) or not C_ms_implies(C2.Assumps, C.Assumps):
        return Verdict(UNSAFE, demote_to=2, explain=diff(C, C2))
    return Verdict(SAFE, contract=C2)

def minimal_counterfactual(x, posterior):
    pairs = enumerate_counterfactual_pairs(x)
    return max(pairs, key=lambda p: (entropy_reduction(p) / (cost_h(p) + lam*latency(p))))
```

### 证书统计（临时证书到正式证书）

```
def provisional_cert(policy, demos, delta=0.05):
    trials = rollouts(policy, demos)                    # 初始极小样本
    p_lcb  = clopper_pearson_lower(successes(trials), n(trials), delta)
    v_ucb  = clopper_pearson_upper(violations(trials), n(trials), delta)
    margins = {m: bootstrap_lcb(estimate_margin(m), trials, delta) for m in MARGINS}
    return CertProv(margins, p_lcb, v_ucb, n=len(trials), delta=delta,
                    coverage=scenario_coverage(trials))

def cert_width(cert):
    return sum((cert.ucb[i] - cert.lcb[i]) / c[i] for i in MARGINS)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 正确性保证 |
|---|---|---|
| 原型编译 | 解析 O(|I|)；检索 O(log N_skill)；适配器前向 O(1) | 输出必为可执行或影子可执行（可执行性不变式） |
| 自动测试生成 | 每场景 O(|Pre|+|Post|)；批量可并行 | 覆盖 Pre/Post 的边界与 C_ms 容差 |
| 临时证书 | CP/Bernstein O(n)；bootstrap O(B·n) | 单侧 (1−δ) 置信；宽度随 n 收缩 |
| 阶梯晋升 | 每步 O(|tests| + 补丁检查) | **定理 1**：P(违约≤ε_k)≥1−δ_k；L3 硬安全 |
| 补丁类型检查 | O(|C|+|Δ|)；合并 O(|fields|) | **定理 2**：safe 保持不变量；unsafe 强制降级 |
| VoI 查询 | 候选 O(|Q|·|θ|)；贪心 O(|Q| log |Q|) | **定理 3**：自适应次模下 (1−1/e) 近似 |
| 多人补丁合并 | 不同字段 O(1)；同字段 O(k log k) | 冲突必显式仲裁，不静默覆盖 |

## 6. 本轮最大风险

**一句话**：最大风险是「人在环」退化为「人在盖章」——稀疏、有偏的人类监督加上形式感十足的临时证书会制造自动化偏置，使阶梯把从未被采样过的失效模式认证为安全；因此 E77 的零不可靠晋升与「人类标签 × 仿真 × 物理不变量」三角校验是本轮成败判据。
