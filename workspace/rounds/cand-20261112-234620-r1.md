# 第 3 轮迭代（新灵感：平衡控制 × 视觉伺服）—— 从"检测撤回→重做"升级到"估计扰动→解耦校正"

> 承接上一版 UIP v2（Gazebo × 实时性 × 模块化）。本轮不推倒重来，而是补上 v2 最薄的一层：**控制**。v2 能"发现进度被撤回"，但发现之后主要靠"重做"；重做既消耗步骤分，又可能在"底座被人挪动"时把正常画面变化误判成撤回。**平衡控制**回答"我在哪、我稳不稳"，**视觉伺服**回答"目标相对我偏了多少"；两者必须先**解耦**再**校正**，否则会互相污染。

## 0. 一句话直觉

想象 T25「放第一个杯子后，评测者马上把底座挪一下」。开环策略看到整幅画面平移，会以为杯子动了；朴素的视觉伺服也会去追这个"假目标"，越追越偏。正确的反应是：

1. **平衡/世界帧层**：从背景光流与腿部关节估计"是底座被挪了"，把世界锚点（桌面）重新对齐；
2. **视觉伺服层**：在**已对齐的世界帧/桌面帧**里计算杯子相对夹爪的误差，只修正物体相对运动；
3. **采样层**：因为 `get_action` 是开环动作块，反馈只在块边界发生，所以这不是连续伺服，而是**采样数据伺服 + 短时域几何 MPC**；块长 `T_a` 是握手时固定的采样周期，不能在运行期随便改。

把这三层合起来，就是本轮旗舰 **UIP-16 · BVD（Balance-Visual Decoupled）**。

### 1.1 接口级纠错（本轮最重要的"修剪"）

- **UIP-13 的自适应块长不成立。** README §3 明确每次动作形状为 `(T_a,…)`，`T_a` 在握手时固定。运行期既不能变短也不能变长；返回不同长度有被评测端拒绝的风险。v3 用 **UIP-20 · TAS** 替代：离线在"反应性—延迟/调用率"帕累托前沿上选一个全局 `T_a`，块内只做动作内容调度（纠正前缀 + 保持/制动后缀）。
- **UIP-01′ 的"每 k 步核验"应改为"每 T_a 步核验"。** 反馈只发生在块边界；所谓 rolling horizon 就是固定的 `T_a` 步。若需要更高频核验，只能全局减小 `T_a`，代价是调用率、JPEG 传输与延迟暴露面上升。
- **UIP-08′ 的"主动削减载荷"应改为握手期配置。** `obs_delta_indices`/`image_resize` 不能运行期改；只能在提交前选好"少叠帧、低分辨率、只声明必要键"。
- **UIP-11 的 Gazebo 固定底座假设与平衡控制冲突。** 平衡/自运动需要浮动基座动力学；Gazebo 继续做**固定底座接触/计分步**裁判，浮动基座部分改用 Isaac Lab / MuJoCo（Unitree 的 `unitree_sim_isaaclab` 与 `unitree_mujoco` 都更合适）。

## 3. 两个灵感词的解读：先直觉，再严谨

### 3.1 平衡控制

**直觉**：这里不是让 G1 走路，而是让它在"桌面操作 + 被人推底座"时保持**世界帧稳定**和**质心/支撑裕度**。`action.pivot` 已经暴露了底座速度/高度/腰部通道；但观测里没有世界系 base 位姿。于是"平衡"有两个层面：

1. **物理平衡**：质心 `c(q)` 不越出支撑多边形 `P(q)`，动态时用捕获点 `ξ = c + ċ/ω₀` 约束；底座/腰部动作不能把机器人推到翻倒边缘。
2. **参考系平衡**：底座被挪时，`T_WB` 变了；所有"base 系下的目标位姿"都要重新表达。**不平衡的不是身体，而是坐标系。**

**严谨定义**：设世界锚点 `W`（桌面）、base `B`、质心 `c(q)`、支撑多边形 `P(q)`。定义静态裕度

`m(q) = min_{p ∈ ∂P(q)} || c_xy(q) − p ||`，

动态裕度用捕获点 `ξ = c_xy + ċ_xy/ω₀`（`ω₀ = sqrt(g/h)`）。平衡安全集

`S = { (q, q̇) | m(q) ≥ m_min, ||ξ − p_center|| ≤ ρ }`。

pivot 指令 `u_p = [vx, vy, ω_z, h]`（外加腰部 `pivot_3..5`）经投影 `u_p* = Π_{U∩S}(u_p^n)` 后才下发。外部推底座时，`T_WB` 的外生变化用 `ΔT` 估计，**不把它当成需要用力对抗的误差**；策略进入"随动 + 重锚定"模式。

### 3.2 视觉伺服

**直觉**：VLA 的开环动作块在接触密集步（插网线、合盖、拉链、倒药）会累积几毫米到几厘米的漂移；块边界上的图像正好可以用来算"目标相对夹爪还差多少"，把这个误差补进下一块。它不是替代 VLA，而是给 VLA 加一个**低频、几何、可解释的残差校正器**。

**严谨定义**：设图像特征 `s_t ∈ R^k`（目标关键点/边缘/孔洞中心/夹爪中心），期望 `s*`。图像雅可比 `L_s(s,Z)` 满足 `ṡ = L_s v_C`。IBVS 律

`v_C* = −λ \hat{L}_s^+ (s_t − s*)`，

再经 `T_EC` 转到末端 twist，积分成末端位姿修正。由于反馈只在块边界发生，实际是**采样数据伺服**：

`e_{n+1} = (1 − λ) e_n + O(T_c²)`，`T_c = T_a · Δt`。

`0 < λ < 2` 是一阶稳定条件；存在推理/网络延迟 `τ` 时稳定域收缩。因此 `T_a` 不只是"延迟"，它是**视觉伺服的控制周期**。

### 3.3 两词合流：先解耦，再校正

底座运动与物体运动在图像上都会产生像素位移。若不区分，视觉伺服会把"底座被推"误当成"目标在动"。用刚体运动学把两者分开：

`v_{E|W} = v_{E|B} + v_{B|W} + ω_{B|W} × (p_E − p_B)`。

视觉伺服在**世界帧/桌面帧**算出 `v_{E|W}*`；下发前减掉估计的底座运动：

`v_{E|B}* = v_{E|W}* − \hat{v}_{B|W} − \hat{ω}_{B|W} × (p_E − p_B)`。

这就是 **Balance-Visual Decoupling**：平衡层提供 `\hat{v}_{B|W}` 与安全约束，视觉层提供 `v_{E|W}*`，执行层只负责 `v_{E|B}*`。两者不互相污染。

## 4. 瓶颈假设（更新）

- **H1（最高杠杆）**：人为干扰下的主要失败不是"不知道该做什么"，而是**把原因归错**——底座动、物体动、真回归三者混为一谈。谁能先解耦，谁就能用最小动作恢复，而不是盲目重做。
- **H2**：反馈带宽被 `T_a` 锁死。`T_a` 太大 → 块内近似开环，视觉/平衡环实际失效；`T_a` 太小 → 调用率、JPEG 传输、推理延迟暴露面上升，可信度指标变差。`T_a` 必须按"任务扰动带宽 + 推理时延"离线选。
- **H3**：接触密集步需要亚厘米级修正；纯开环 VLA 不够，纯视觉伺服在未见物体/遮挡下也不稳。最稳的是"VLA 名义轨迹 + 低增益视觉残差 + 置信度门控"。
- **H4**：`pivot` 是双刃剑。用它伸够/配重可以提高可达性，但激进底座运动会与外部推搡对抗、恶化平衡；默认应保守（零底座速度、固定高度），只在明确需要时用腰部/高度微调。
- **H5**：合成扰动数据能训练估计器，但不能替代真机锚点；GSO 仍只做"结构/顺序"裁判，不做像素级成败裁判。

## 5. 候选与合并 → v3 清单（详见产物区）

围绕两词发散 8 个草案，合并后得到 v3：**旗舰 UIP-16 BVD**，由 **UIP-18 EMD（解耦估计）+ UIP-17 BAM（平衡护栏）+ UIP-21 BVE（双证据验证）+ UIP-20 TAS（采样周期选择）** 四条腿支撑；UIP-01″/11′/12″/15′/08″ 做接口级升级，UIP-02′/05/14 保留，UIP-09′/13 合并，UIP-04/10 继续封存。

**→ 本轮最值得押注：UIP-16 BVD × UIP-18 EMD × UIP-21 BVE 组成的"平衡-视觉解耦校正层"**——它把 v2 的"发现撤回→重做"升级为"分清底座动/物体动→最小校正"，正好覆盖规则里白纸黑字、公开数据却零覆盖的 `human_*` 轴，且全部落在选手 API 与离线算力之内。

## 6. 本轮最大风险（一句话）

**最大风险：`T_a` 在握手时固定、`pivot` 的语义与是否真正驱动底座尚未确认——若评测端不按预期执行底座指令，或固定块长撑不起扰动带宽，BVD 会退化成开环计划，平衡/视觉闭环的收益全部落空。**

## 1. 旗舰深潜：UIP-16 · BVD（Balance-Visual Decoupled）

### 1.1 问题拆解

`human_*` 干扰至少有三类，v2 把它们都压成 `regressed`：

| 干扰类型 | 例子 | 画面表现 | 正确反应 |
|---|---|---|---|
| 底座移动（ego-motion） | T11 抓电池前动底座；T25 放第一个后挪底座 | 整幅背景平移/旋转 | 估计 `T_WB`，重锚定世界帧；**不要**把目标当成在动 |
| 物体/插口移动（target-motion） | T05 移动道具手；T26 插口移开 | 局部目标位移，背景基本不动 | 更新目标位姿，视觉伺服重新对准 |
| 反向撤回（state regression） | T14 拧回、T16 翻开、T19 拉开、T27 拿下第二个 | 子目标状态从 done 回退 | 真重做，但只在双证据确认后 |

BVD 的三层结构：

1. **世界锚定/平衡层（慢）**：估计 `T_WB`、`T_WO`、`m(q)`；对 pivot 做安全投影；底座被推时进入"随动 + 重锚定"。
2. **视觉伺服层（块边界）**：在稳定化特征上算 IBVS 残差；预测未来 `T_a` 步的误差演化。
3. **块级几何 MPC（块边界）**：以 VLA 名义块为参考，求解满足视觉/平衡约束的最短时域修正；只在块边界重规划。

### 1.2 与 v2 的差异

- v2：`regressed` → 重做同一子目标。重做成本高，且在底座运动时容易误触发。
- v3：先**归因**（ego / target / regression），再**最小校正**：
  - ego → 重锚定 + 视觉伺服补偿底座运动；
  - target → 更新目标位姿 + 视觉伺服；
  - regression → 双证据确认后，用 BVD 生成恢复轨迹（而不是简单重复上一块）。
- v3 明确：反馈只在块边界，`T_a` 固定；不再假装"每 k 步验证"或"运行期变块长"。

### 1.3 可行性

- **相机已标定**：HF `meta/info.json` 给出 head stereo 与 wrist 的内参/畸变/外参，IBVS 和自运动估计可直接离线标定。
- **不需要第二个学习模型**：EMD/BAM/BVE 可用经典几何、光流、腿运动学实现；若用学习式关键点头，从主 VLA 骨干蒸馏，保持"单模型"合规。
- **计算量可控**：ORB/光流 + 小 QP 可在 CPU 侧完成；主 VLA 仍是唯一重模型。
- **离线可验证**：用 32 个公开数据集回放，先验证 `T_WB` 估计、特征跟踪、稳定化误差，再接真机。

### 1.4 资源

- 1 张推理卡（主 VLA）；CPU 侧视觉/平衡模块；离线 Gazebo（固定底座接触）+ Isaac Lab/MuJoCo（浮动底座平衡）；公开 32 数据集做标定与回放。

### 1.5 落地步骤

1. 用数据集相机参数标定 head/wrist 与 EE 的外参；拟合桌面平面作为世界锚点。
2. 在回放数据上训练/调试 EMD（背景光流 + 腿/腰运动学融合），输出 `T_WB` 与置信度。
3. 实现 wrist/head 的 IBVS 残差；先在"物体移动"任务上验证。
4. 实现 BAM 的 CoM/捕获点安全投影；先在"底座移动"任务上验证。
5. 用 BVE 接 UIP-01″ 的状态机；用 BVD 生成恢复块。
6. 用 DRF-V 合成扰动数据做消融；最后真机校准。
7. 用 TAS 做 `T_a` 全局扫描，选帕累托点。

### 1.6 风险

- 未见物体/低纹理/遮挡会让特征跟踪与光流同时失效；必须置信度门控 + 回退到名义块。
- `pivot` 语义未确认；默认保守，先观测真机是否响应底座指令。
- `T_a` 固定导致块内无法反馈；块级 MPC 必须对最坏情况扰动留裕度。

## 2. 形式化定义

### 2.1 坐标系与观测量

`W`：桌面/世界锚点；`B`：机器人 base；`E`：末端；`C`：相机；`O`：目标物体。
`T_AB ∈ SE(3)` 表示 B 在 A 中的位姿。

块边界时刻 `t_n` 的观测：

`o_n = ( I_n^{headL}, I_n^{headR}, I_n^{wristL}, I_n^{wristR}, q_n^{arm}, q_n^{lower}, T_{B E_n}, l )`。

**关键隐变量**：`T_{W B_n}` 不在观测里。它只能由视觉自运动 + 腿/腰运动学估计：

`\hat{T}_{W B_n} = fuse( \hat{T}_{W B_n}^{vis}, \hat{T}_{W B_n}^{leg} )`。

### 2.2 自运动与稳定化特征

相邻块边界的自运动：

`ΔT_n = T_{W B_n} · T_{W B_{n-1}}^{-1}`。

对桌面/背景平面估计单应 `H_n`，把当前图像 warp 到参考帧：

`s_n^{stab} = W(s_n; \hat{ΔT}_n)`。

视觉伺服误差：

`e_n = s_n^{stab} − s*`。

若不做稳定化，底座移动会被误当成目标移动；这是 EMD 的核心。

### 2.3 平衡约束

质心 `c(q)`，支撑多边形 `P(q)`，静态裕度

`m(q) = min_{p ∈ ∂P(q)} || c_xy(q) − p ||`。

动态裕度用捕获点：

`ξ = c_xy + ċ_xy / ω₀`，`ω₀ = sqrt(g/h)`。

安全集

`S = { (q, q̇) | m(q) ≥ m_min, ||ξ − p_center|| ≤ ρ }`。

pivot 指令 `u_p = [vx, vy, ω_z, h]`（外加腰部 `pivot_3..5`）经投影：

`u_p* = Π_{U∩S}(u_p^n)`。

外部推底座时，估计 `\hat{v}_{B|W}`，但**不把它当成需要用力抵消的误差**；进入"随动 + 重锚定"模式。

### 2.4 解耦方程

视觉伺服在世界帧给出 `v_{E|W}*`；刚体运动学：

`v_{E|W} = v_{E|B} + v_{B|W} + ω_{B|W} × (p_E − p_B)`。

因此下发到 base 系的末端速度应为：

`v_{E|B}* = v_{E|W}* − \hat{v}_{B|W} − \hat{ω}_{B|W} × (p_E − p_B)`。

这就是"平衡-视觉解耦"：平衡层提供 `\hat{v}_{B|W}` 与安全集，视觉层提供 `v_{E|W}*`。

### 2.5 块级几何 MPC

在块边界 `t_n`，以 VLA 名义块 `A_n^{nom} = (a_0^{nom},…,a_{T_a-1}^{nom})` 为参考，求解：

```
min_{a_0..a_{T_a-1}}  Σ_t [ ||e_t||_Q² + ||a_t − a_t^{nom}||_R² + μ·max(0, m_min − m_t)² ]
s.t.  a_t ∈ A,
      m_t ≥ m_min,                     (预测平衡裕度)
      |v_t| ≤ v_max, |ω_t| ≤ ω_max,
      e_{T_a} 满足进度/对准阈值.
```

其中 `e_t` 用当前图像 + 名义动作的预测模型展开；不要求块内真实反馈。
该优化可退化为三种低开销实现：

1. **残差前缀**：只修正前 `r` 步（`r ≤ T_a`），后 `T_a−r` 步保持名义/制动。
2. **pivot 投影**：只投影 pivot 通道，双臂保持名义。
3. **事件触发**：仅当 `||e_n||` 或平衡裕度越界时解 QP，否则直接放行名义块。

### 2.6 采样数据稳定性

一阶离散误差：

`e_{n+1} = (1 − λ) e_n`，`0 < λ < 2` 稳定。

块周期 `T_c = T_a · Δt`。存在推理/网络延迟 `τ` 时，稳定域收缩；速度限幅给出有效增益：

`λ_eff = min( λ, u_max·T_c / ||\hat{L}_s^+ e_n|| )`。

工程结论：`T_a` 大 → `T_c` 大 → 视觉伺服增益受限、扰动抑制变慢；`T_a` 小 → 调用率高、JPEG/推理延迟暴露面大。`T_a` 必须离线选。

### 2.7 `T_a` 选择目标

在验证任务集上离线优化：

`J(T_a) = E[step_score] − α·E[latency] − β·Var[latency] − γ·E[redo]`，

约束 `T_a·Δt > τ_infer + τ_network`（否则评测端会等推理）且 `T_a·Δt` 小于主要扰动的时间尺度。取帕累托点，而不是拍脑袋。

### 2.8 双证据回归判定（BVE）

`regressed` 仅当三个条件同时成立：

1. 稳定化世界帧里目标状态回退：`Δ_o^{stab} < −δ`；
2. 机器人相对证据也回退（EE-目标几何、夹爪开合、接触/插入深度代理）：`Δ_r^{rel} < −δ`；
3. 两个置信度都过门限：`min(conf_o, conf_r) > c_min`。

这样底座移动只会改变 `T_WB`，不会同时让机器人相对几何回退，从而避免"假回归→反复重做"。

## 3. 新增 UIP 细节

### UIP-17 · BAM（Balance-Aware pivot Governor）

- **机制**：维护 `m(q)` 与捕获点裕度；对 pivot 的 `vx, vy, ω_z, height` 做安全投影。默认"零底座速度 + 固定高度"；只有在目标超出舒适工作空间时，才用腰部/高度小幅调整。
- **被推时**：检测到外生 `ΔT_WB` → 底座速度指令置零/随动，避免与人对抗；下一块重锚定目标。
- **双腕负载平衡（可选）**：双臂持物时用视觉水平仪保持物体水平，分配两腕高度；无六维力传感器，不承诺力控。
- **权限**：`action.pivot` 在接口内；但语义待手册确认。
- **风险**：若评测端不启用底座运动，激进 pivot 可能造成异常；默认保守即可。

### UIP-18 · EMD（Ego-Motion-Decoupled estimator）

- **机制**：
  1. head stereo/背景特征做鲁棒单应，分解出相机旋转/平移；
  2. 腿/腰关节运动学给 `ΔT_leg` 先验；
  3. EKF/加权融合得 `\hat{ΔT}_n` 与置信度；
  4. 用补偿后的残差流分类：全局残差=底座动；局部残差=物体动；两者同时=复合扰动。
- **失败检测**：低纹理、动态背景、特征点不足、单应退化 → 置信度下降，回退到"只做小步修正/名义块"。
- **与视觉伺服的关系**：EMD 是 EMD-servo 的前置；没有它，IBVS 会把 ego-motion 当目标运动。

### UIP-20 · TAS（`T_a` Selection + intra-chunk Action Scheduling）

- **机制**：
  - 握手期在验证集上扫 `T_a ∈ {1,2,4,6,8,12}`，按 §2.7 的 `J(T_a)` 选全局 `T_a`；
  - 块内不改变数组长度，只改变动作内容：`corrective prefix + hold/brake suffix`；
  - 若块首误差大，前几步做视觉伺服修正，后几步保持/减速；若误差小，整块执行名义轨迹；
  - 用动作平滑/限幅避免"统计规律性异常"。
- **纠正 v2**：不再声称"运行时返回 ≤k 步"；`T_a` 是 fixed。
- **风险**：块内无反馈；MPC 预测误差大时，纠正前缀可能过度。

### UIP-21 · BVE（Balance-Visual Evidence verifier）

- **机制**：双证据回归判定（§2.8），把"世界帧状态"与"机器人相对几何"分开算；两者一致才判 `regressed`。
- **收益**：底座移动时避免假回归；物体移动时仍能正确识别"目标跑了"（不是回归，而是 target-motion）；真撤回时两者同时回退。
- **成本**：一次几何检查 + 一次特征比对；CPU 级。

### UIP-11′ · GSO+（双 oracle）

- **固定底座接触 oracle**：Gazebo + G1/Dex1，判计分步的几何谓词（插深、堆叠、闭合、接触）。只做"结构/顺序"裁判。
- **浮动底座平衡 oracle**：Isaac Lab / MuJoCo（`unitree_sim_isaaclab`、`unitree_mujoco`）做 base 动力学、推搡、CoM/支撑裕度；验证 BAM/EMD。
- **校准锚点**：真机预约时段，用真实 step score 校准两个 oracle 的偏差；不把仿真当成败裁判。

### UIP-12″ · DRF-V（Disturb-Recover-Visual data factory）

- **机制**：脚本化三类扰动：
  - 底座推/挪（模拟 human_* 的 T11/T25）；
  - 物体/插口移动（T05/T26/T08/T27）；
  - 反向撤回（T14/T16/T17/T19/T24/T27）。
- 生成 `(扰动前 → 扰动 → 恢复)` 三元组，并记录视觉伺服恢复轨迹与 `T_WB` 标签。
- 随机化时机、速度、方向、遮挡；用真实数据做域校准。
- **与 v2 DRF 差异**：不仅补"撤回"，还补"ego-motion vs target-motion"的判别标签。

### UIP-15′ · CSG+（四重护栏）

- 延迟预算、抖动上限、最大重做次数、**平衡裕度下限**、**视觉置信度下限**。
- 任一不满足 → 回退到保守动作（保持/减速/名义块），而不是继续纠正。
- 动作形态平滑，避免可信度判定异常。

### UIP-08″ · LAT-ENG+（握手期）

- `obs_delta_indices`/`image_resize` 在握手期一次性选好；少叠帧、低分辨率、只声明必要键（每张图=一张 JPEG）。
- 共享骨干 + 请求批处理 + 每端口 KV/历史隔离；N 端口独立状态。
- 运行时只做推理与轻量 CV，不改变载荷配置。

## 5. 修订/保留项

### UIP-01″ · BVE-R（双证据进度核验-恢复）

- **机制**：只在块边界核验（`T_a` 固定）。当前子目标 `g` 的状态 ∈ `{done, ongoing, target_moved, regressed, fail}`。
  - `target_moved`：物体/插口移动，但机器人自身进度未回退 → 更新目标，视觉伺服重对准；
  - `regressed`：世界帧 + 机器人相对双证据都回退 → 真撤回，生成恢复块；
  - `fail`：动作执行失败（滑脱、未接触）→ 重试；
  - `done`：推进 `g`，清零重做计数。
- **与 v2 差异**：v2 只有 `regressed`；v3 增加 `target_moved`，并把核验频率改成块边界。
- **恢复**：不是简单重复上一块，而是用 BVD 在 `g` 的目标位姿上重新规划；优先保住前置步骤分。

### UIP-02′ · SSG（计分步安全网）

- 保留 v2：按 32 任务计分点有序推进；保前置、搏末步；末步分值 ≥ 前序。
- 新增：恢复时优先重做"已得分且被撤回"的前置步，避免为了末步丢掉已锁定的分。

### UIP-14 · MSGR（模块化技能图）

- 保留：32 任务≈10 技能；单骨干 + 参数高效技能头。
- 新增：技能节点上标注"接触密集/需要视觉伺服/需要平衡约束"属性；BVD 作为共享控制层挂在所有技能下，而不是每个技能单独一套控制器。

### UIP-05 · LCAG（语言→可供性）

- 保留：未见物品/背景靠语义条件化；为视觉伺服提供"该跟踪什么特征"的语言先验（例如"插口""拉链头""瓶盖"）。

```python
class BVDChunkPolicy:
    def __init__(self, vla, emd, servo, bal, bve, T_A=6,
                 max_redo=2, conf_thr=0.6):
        self.vla = vla          # 唯一学习式模型（单模型合规）
        self.emd = emd          # 经典几何/光流 + 腿运动学
        self.servo = servo      # IBVS/PBVS 残差
        self.bal = bal          # CoM/捕获点投影
        self.bve = bve          # 双证据验证
        self.T_A = T_A          # 握手期固定，运行期不变
        self.max_redo = max_redo
        self.conf_thr = conf_thr

    def reset(self):
        self.vla.reset()
        self.T_WB = None
        self.T_WO = None
        self.g = 0
        self.redo = 0
        self.prev = None

    def get_action(self, obs):
        q, imgs, T_BE = unpack(obs)

        # 1) 自运动 + 世界帧重锚定（EMD）
        dT, conf_ego = self.emd.estimate(self.prev, imgs, q)
        self.T_WB = update_pose(self.T_WB, dT)
        self.T_WO, conf_obj = self.emd.object_pose(imgs, self.T_WB)

        # 2) 扰动归因：底座动 / 物体动 / 复合
        kind = self.emd.classify(dT, self.T_WO, self.prev)

        # 3) 双证据进度核验（BVE）
        state = self.bve.verify(obs, self.g, self.T_WB, self.T_WO,
                                conf_ego, conf_obj)
        if state == "done":
            self.g += 1
            self.redo = 0
        if state == "regressed" and self.redo < self.max_redo:
            self.redo += 1
            mode = "recover"
        elif state == "target_moved":
            mode = "servo_reacquire"
        else:
            mode = "nominal"

        # 4) VLA 名义块（T_A 固定）
        A_nom = self.vla.plan(obs, self.T_A)       # (T_A, d)

        # 5) 视觉伺服残差（世界帧 -> base 系解耦）
        e, conf_s = self.servo.error(imgs, self.T_WB, self.T_WO)
        A = self.servo.correct(A_nom, e, conf_s,
                               mode=mode, dT=dT)

        # 6) 平衡安全投影（BAM）
        A = self.bal.project(A, q, dT)

        # 7) 块内动作调度（TAS）：纠正前缀 + 保持/制动后缀
        A = self.schedule(A, e, conf_s, kind,
                          self.T_A, conf_thr=self.conf_thr)

        self.prev = (imgs, q, T_BE)
        return pack(A, self.T_A)                   # 严格 (T_A, ...)
```

```python
def estimate_ego_motion(prev, imgs, q):
```

```python
def balance_project(A, q, dT):
    for t in range(len(A)):
        q_pred = rollout_low_level(q, A[:t+1])
        c, P = com_and_support(q_pred)
        m = margin(c, P)
        if m < M_MIN:
            A[t].pivot.vx *= 0.5
            A[t].pivot.vy *= 0.5
            A[t].pivot.height = clamp_height(A[t].pivot.height)
        if external_push_detected(dT):
            # 随动，不对抗
            A[t].pivot.vx = 0.0
            A[t].pivot.vy = 0.0
            A[t].pivot.angle_z = 0.0
    return A
```

```python
def bve_verify(obs, g, T_WB, T_WO, conf_ego, conf_obj):
    # 证据 1：稳定化世界帧中的目标状态
    d_obj, c_obj = progress_delta_world(T_WO, g)
    # 证据 2：机器人相对几何（EE-目标、夹爪开合、插入深度代理）
    d_rel, c_rel = progress_delta_relative(obs, g)
    c_min = min(c_obj, c_rel, conf_ego, conf_obj)
    if c_min < C_MIN:
        return "ongoing"                 # 置信度不够，不轻易判回归
    if d_obj < -DELTA and d_rel < -DELTA:
        return "regressed"               # 真撤回：双证据一致
    if d_obj < -DELTA and abs(d_rel) < DELTA:
        return "target_moved"            # 物体动了，但机器人进度没回退
    if d_obj > DELTA:
        return "done"
    return "ongoing"
```

```python
def choose_T_A(validation_tasks):
    # 离线帕累托：反应性 vs 延迟/调用率
    best = None
    for T_A in [1, 2, 4, 6, 8, 12]:
        if T_A * DT <= TAU_INFER + TAU_NET:
            continue                     # 评测端会等推理，排除
        score = evaluate_offline(T_A, validation_tasks)
        latency = measure_latency(T_A, validation_tasks)
        J = score - ALPHA * mean(latency) - BETA * var(latency) \
                  - GAMMA * redo_rate(T_A, validation_tasks)
        best = max(best, (J, T_A))
    return best[1]
```

## 8. 合规与风险

- **单模型合规**：`vla` 是唯一学习式模型；EMD/BAM/BVE/视觉伺服是经典几何与控制模块。任何学习式关键点/分割头必须共享 `vla` 骨干（蒸馏），不接外部 VLM/API。
- **`pivot` 语义未确认**：字段名像"底座速度+腰部+高度"，但可能是目标值、也可能评测端不启用。默认保守（零底座速度、固定高度）；真机第一轮先观测响应，再决定是否启用 BAM 的主动底座动作。
- **`T_a` 固定**：不再声称运行期变块长；`T_a` 是全局设计变量。`T_a` 过大→块内开环、扰动抑制差；过小→调用率高、延迟/带宽压力大。用 E201 离线选。
- **视觉伺服失败模式**：未见物体、低纹理、遮挡、动态背景、反光；置信度门控 + 回退到名义块 + 只做小步修正。
- **仿真过拟合**：GSO+ 只做结构/顺序与平衡趋势；真机锚点不可省。
- **可信度**：轻量 CV 的延迟/抖动要纳入 E201/E210；避免动作统计异常。
- **手册仍缺**：`pivot` 语义、评测轮次/时限/控制频率、5 轴中的位置/干扰物/背景细节，仍待飞书手册公开后核实。
