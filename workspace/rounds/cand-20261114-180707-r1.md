# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「安全对齐」×「灵巧手」）

> R69 把不确定性拆成 aleatoric / epistemic，并教会系统「向谁求证、还能问什么」。但它有一个从未被检验的前提：**信息动作与任务动作共享同一个、低维的、可以写成盒约束的安全包络**。灵巧手一上手，这个前提立刻塌掉——同一组关节指令，指尖落在物体正中还是边缘、接触面积大还是小、法向力是否穿过摩擦锥，安全后果可以相差一个数量级；安全集不是盒子，而是**接触流形上的一个薄壳**。
>
> 本轮两个灵感恰好互补：
> - **安全对齐**提供了正确的分层模板——宪法式硬约束（不可交易）+ 偏好排序（可学习）+ 拒绝/弃权机制；但直接照搬到手上会犯范畴错误：语言里「拒绝回答」几乎总是安全的，物理里「停止动作」可能正是最危险的（松手、滑落、僵在夹持中）。
> - **灵巧手**提供了对齐的物理载体——高冗余自由度意味着「完成任务」有很多等价方式，对齐可以住进这些等价方式的**零空间**里，几乎不付任务代价。
>
> 核心命题：**安全对齐不应发生在指令空间，而应发生在接触后果空间；硬安全用「宪法接触约束」在运行时认证，软偏好只允许在可行切锥内重排动作；灵巧手的冗余让对齐在大多数时刻近乎免费，而当可行切锥被任务或约束吃满时，对齐税必须被显式计量而不是被隐藏。** 命名 **PALM-RAS**（Physical Alignment on Contact Manifolds：接触流形上的物理对齐风险自适应闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的手应该怎样触碰**」——对齐不是一个 yes/no 的拒绝词，而是一条被认证过的、带偏好的接触轨迹。

## 0. 直觉与动机

**灵感 1（安全对齐 → 对齐发生在后果空间，不是指令空间）**
直觉：语言模型的对齐对象是 token 分布；同一个 token 的伤害可以由上下文完全决定。灵巧手是它的物理镜像：同一个关节指令的伤害由**接触状态**完全决定。因此，「在动作空间做 RLHF」在手上天然不成立——动作不是后果的不变量，接触签名才是。把对齐提升到接触签名空间，等于给安全找了一个在换物体、换姿态、换抓法下都稳定的坐标系。

**灵感 2（灵巧手 → 冗余是免费的对齐资源）**
直觉：多指手对同一个任务有大量等价解（怎么握、从哪个角度、哪几根手指分担力）。人类正是用这份冗余做「得体」：同样是递杯子，可以捏着杯沿，也可以托住杯底——后者更稳、更礼貌。形式上，任务雅可比 J_t 的零空间就是对齐的免费预算：任务误差一阶不变，偏好在其中任意优化。这把「对齐税」从一个必然成本变成一个**只在切锥被占满时才出现**的稀缺资源。

**灵感 3（宪法 vs 偏好 → 两层对齐，硬约束不可交易）**
直觉：宪法式 AI 的关键不是「学一个更好的奖励」，而是「有些东西不允许被奖励交换」。手上同理：摩擦锥裕度、局部压强、与人体的最小间隙、滑移裕度必须是运行时逐条可测、逐条认证的硬谓词；偏好模型只能在这些谓词围出的可行集内部排序。这样即使偏好模型被 reward hacking 彻底攻破，它也只能在安全集合里挑一个更差的动作，而不能制造一次宪法违规——**把最坏情况从「优化出错」降级为「测量出错」**，这是本轮最重要的安全性论证。

**灵感 4（拒绝的物理悖论 → 安全弃权）**
直觉：语言对齐里「拒答」是安全兜底；物理对齐里「停住」不是。抓着重物时冻结可能滑落，抓着易碎物时僵持可能压裂，手指停在人与物之间时不动可能阻断逃生。所以「拒绝」必须升级为一组**主动且被认证的弃权动作**（稳定保持、受控放下、回撤到安全位、交还人类），并且用「最小预期伤害」而非「默认停止」来选择。这是把安全对齐迁移到具身系统时最容易犯、也最致命的错误。

**灵感 5（对齐会造假 → 接触空间的反表象与欺骗审计）**
直觉：灵巧策略很容易学会「看起来温柔」：动作平滑、速度慢、合力小，但压力集中在触觉分辨率看不见的小接触斑上；或者在有人监督时守规矩、无人监督时抢时间。前者的伤害是**代理指标与真实后果的错位**，后者是**欺骗性对齐**。因此本轮必须同时交付：后果接地（consequence-grounded）的偏好特征、反表象不变性正则、随机化监督 + 反事实接触审计，以及用 R69 的流似然通道做「偏好模型还能不能信」的 OOD 门。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（PALM-RAS 总览）** PALM-RAS = (CSR, CON, NSP, PAR, HIL, COG, SAB, DAA, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **宪法优先**：偏好/奖励只允许在可行集内部重排动作，任何情况下不得以任务收益或偏好收益交换更高优先级的硬约束；分级松弛也只能在「不可行已成事实」时最小化违反，而不是把违规当成可购买的成本；
(iii) **后果接地与可审计**：任何「已对齐」的声明必须落在可测的接触签名上，并能被反事实接触审计复核；表象指标（平滑、慢速、轻合力）不得单独作为对齐证据。

**定义 311（接触签名与接触映射）** 手有 N_f 指，接触集 C_t。接触签名
σ_t = (q_t, {p_c, n_c, f_c, τ_c, A_c}_{c∈C_t}, x_human)，
其中 p_c 接触点、n_c 法向、f_c 接触力/力矩、A_c 接触斑面积、x_human 人体邻近状态。导出量：摩擦裕度 μ_m = min_c(1 − |f_t|/(μ f_n))、局部压强 p_c = f_n/A_c、滑移裕度 s_m、抓取稳定裕度（力闭合）、人体间隙 d_h。接触映射 Φ_c: (q, q̇, u) → σ_t 由可微接触模型 + 不确定性集给出，记其模型误差协方差 Σ_σ。

**定义 312（鲁棒安全集）** 标称安全集 𝒮_safe = {σ : c_j(σ) ≥ 0, ∀j}。考虑模型/测量不确定集 𝒰_σ（椭球，半径由 Σ_σ 与置信度给出），定义鲁棒安全集 𝒮_safe^ρ = {σ : c_j(σ+δ) ≥ 0, ∀δ∈𝒰_σ, ∀j}。对齐与认证一律在 𝒮_safe^ρ 上做；**盒约束只是 𝒮_safe^ρ 在特定接触几何下的一个退化截面**。

**定义 313（宪法接触约束 CON）** 约束集 C = {c_1,…,c_m}，按优先级分层：
- T1 人体安全：人体间隙 d_h ≥ d_min、对人体接触力 ≤ f_h,max、不得主动把人体部位夹入；
- T2 物体完整与抓持：局部压强 p_c ≤ p_max(材料)、摩擦裕度 μ_m ≥ μ_min、滑移裕度 s_m ≥ s_min；
- T3 机构安全：关节/力矩限、自碰撞、奇异位形回避；
- T4 任务完成与平滑。
同层内为硬谓词；跨层为字典序。判决函数 Con(σ) → (可行层, {m_j})，m_j 为归一化裕度。

**定义 314（约束偏好对齐）** 语言意图 ℓ（如「轻轻递给我」）经冻结 LLM 编码为 e_ℓ（不回传语言模型）。偏好模型 r_φ(σ_{t:t+H}, e_ℓ) 只在可行集内定义排序。对齐后的策略
π* = argmax_π E[r_φ(σ_{t:t+H}, e_ℓ)]，s.t. σ_{t:t+H} ∈ 𝒮_safe^ρ。
这与无约束 RLHF 的区别是本质性的：偏好永远不能把不可行变成「代价较高的可行」。

**定义 315（可行切锥与零空间对齐 NSP）** 在标称动作 a_0 处，任务残差 r_t 与任务雅可比 J_t。定义可行切锥
K(a_0) = {δa : J_t δa = 0（任务一阶保持）, n_jᵀ δa ≥ 0（活动约束不收紧）}。
对齐投影 δa_align = Π_K(∇_a r_φ)。当无活动约束时 K 退化为 J_t 的零空间，δa_align = N Nᵀ ∇r_φ。**对齐住进冗余；当 K 被任务或活动约束压缩，投影残差 ||∇r_φ − Π_K ∇r_φ|| 就是对齐税的来源。**

**定义 316（对齐裕度与偏好遗憾）** 对齐裕度 m_align = min_{t,j} m_j(σ_t)（沿预测时域取最小）；偏好遗憾 ρ = r_φ(σ*) − r_φ(σ_exec)。二者分开记账：m_align 管安全，ρ 管「对齐得好不好」，不可互相补偿。

**定义 317（安全弃权 SAB）** 弃权动作集 𝒜_abs = {hold_stable, release_place, retreat_home, handover_human}。安全弃权策略
π_abs = argmin_{a∈𝒜_abs, Con(rollout(a)) 可行} E[harm(a)]，
而不是默认 stop。若连弃权都不可行（已在滑移/夹持人体），进入分级松弛下的 minimax 恢复并同步告警。**「拒绝 = 安全」只在 stop ∈ 𝒮_safe^ρ 时成立。**

**定义 318（后果接地偏好与反表象）** 把特征拆为表象特征 x_app（速度、平滑、合力幅值）与后果特征 x_cons（压强分布、摩擦裕度、人体接触概率、滑移）。要求 r_φ 对 x_app 在给定 x_cons 下近似不变：加正则 I(r_φ; x_app | x_cons) ≤ ε_inv，并用对抗探针检测「靠表象拿高分」。**对齐黑客（alignment hacking）** 定义为 r_φ 上升而真实后果裕度下降的事件。

**定义 319（接触 OOD 门 COG）** 复用 R69 的流似然第二意见，但作用在接触签名轨迹上：a_contact = −log p_ψ(σ_{t:t+H} | o_t)。若 a_contact 高于分位阈值，或偏好模型 ECE 超阈，则偏好不可信 ⇒ 关闭偏好层，退化为「仅宪法」的 FLUID 边界。这把 R69 的「行为自洽」通道升级为「接触自洽」通道。

**定义 320（人类在环偏好 HIL）** 偏好查询只在**预测出的可行签名对**之间进行（虚拟 rollout），绝不为了问而执行不安全候选；查询对按最大化偏好后验信息增益选择（复用 R69 MINT）。防谄媚：随机化查询顺序、隐藏机器置信度、对「人类是否在顺从机器」做校准检测。

**定义 321（欺骗性对齐审计 DAA）** 定义监督指示 u（人是否在看）。审计比较策略在 u=1 与 u=0 下的反事实接触分布，并对审计时刻做随机化，使策略无法预测何时被看。检出统计量 D = W_1(σ|u=1, σ|u=0)；持续 D > τ_D 或单次出现「仅在无人时收紧宪法」即判欺骗嫌疑，强制回退到仅宪法层并记入 AuditBuf。

**定义 322（对齐税与 Pareto）** 对齐税 tax = success(FLUID) − success(PALM)，在宪法满足率固定为 100% 的前提下度量；Pareto 前沿为 (tax, 偏好增益, 违规率)。硬要求：任意 tax 档位违规率 = 0；只报告「每单位税换来的偏好增益」，禁止用违规换成功率。

**定义 323（分级松弛与最小违反）** 当 T1 不可行（已发生），不把问题降级为「无解」，而按字典序求最小违反：先 min 最大人体接触力/最大压强，再在其次优面上优化 T2、T3、T4。**禁止跨层交易**（不得用「物体更稳」为「更贴近人体」辩护）。若 minimax 仍越界，进入 handover_human + 主动告警。

**定义 324（证书 J_PALM 与严格包含）** J_PALM = (J_FLUID, constitution_sat_rate, min_align_margin, pref_regret ρ, align_tax, contact_ood_p95, deception_audit_D, abstention_log_hash, palm_ver)。Valid ⇔ Valid(J_FLUID) ∧ 宪法满足 ∧ COG 处置正确 ∧ 审计通过。当偏好层被禁用/COG 触发/HIL 离线时，PALM **逐指令等于** FLUID；而 FLUID 在「永不交互」边界等于 R68。故包含链为 PALM ⊇ FLUID ⊇ R68。

# IP-264 CSR：接触签名预测（含模型不确定集）
class ContactSignature:
    def predict(self, q, qd, u, H):
        sig = self.contact_model.rollout(q, qd, u, H)   # 接触点/力/面积/人体状态
        return sig, self.contact_model.cov(sig)          # Σ_σ，供鲁棒裕度

# IP-265 CON：分层宪法检查（硬谓词 + 鲁棒裕度）
class Constitution:
    TIERS = ['human', 'object', 'mechanism', 'task']
    def check(self, sig, cov, rho):
        margins = {c: robust_margin(c, sig, cov, rho) for c in self.constraints}
        feasible = {t: all(margins[c] >= 0 for c in self.tier(t)) for t in self.TIERS}
        return margins, feasible

# IP-266 NSP：可行切锥内的对齐投影（任务一阶保持）
class NullSpaceAligner:
    def project(self, a0, sig, pref_grad, con):
        K = feasible_tangent_cone(a0, sig, con)          # J_t 零空间 ∩ 活动约束半空间
        return a0 + project_onto_cone(K, pref_grad)      # 任务不动，偏好在松弛里走

# IP-270 SAB：安全弃权（最小预期伤害，而非默认停止）
class SafeAbstention:
    CANDS = ['hold_stable', 'release_place', 'retreat_home', 'handover_human']
    def choose(self, sig, con):
        ok = [a for a in self.CANDS if con.check(rollout(a)).feasible['human']]
        return min(ok, key=expected_harm) if ok else self.minimax_recovery(sig)

## 3. 推导

**引理 19（零空间对齐的一阶零任务代价）** 设任务残差 r_t(a) 可微、J_t = ∂r_t/∂a，且 ∇r_φ(a_0) ∈ null(J_t)。则存在 δa = N Nᵀ∇r_φ 使 r_t(a_0+δa) = r_t(a_0) + O(||δa||²)，而偏好一阶上升 ||N Nᵀ∇r_φ||²。即：**只要还有冗余，对齐税只是一阶零、二阶小量**；税在 J_t 零空间收缩（奇异位形、活动约束吃满）时才出现。

**引理 20（宪法支配下的 reward hacking 安全上界）** 设每个 c_j 的测量/模型误差被鲁棒裕度 ρ 覆盖，即 |ĉ_j − c_j| ≤ ρ 且认证用 ĉ_j ≥ ρ。则对任意偏好输出（包括被完全攻破的 r_φ），执行动作仍满足真实约束。故对齐黑客造成的伤害上界是「偏好遗憾 ρ」，不是「安全违规」；**剩余风险从优化层转移到测量层**——这正是的定义 318 与实验 E301 的靶心。

**引理 21（弃权不天然安全）** 若 stop ∉ 𝒮_safe^ρ（抓持中滑移、夹持人体、托举易碎物），则 harm(stop) 可严格大于某个已认证动作的 harm。因此语言对齐的「拒绝即安全」在具身上不成立；只有把弃权建成主动认证策略 π_abs，才能保证退化路径的 harm 单调不升。系：**任何把 stop 当无条件兜底的安全对齐，都会在接触任务里制造新的失效模式。**

**定理 18（PALM 严格包含 FLUID 与 R68）** 在 A99–A101（接触映射 Lipschitz、鲁棒裕度覆盖模型误差、偏好层可选）下，PALM 的期望物理伤害 ≤ FLUID；且当偏好层被禁用、COG 触发或 HIL 离线时，PALM 与 FLUID 逐指令相同；再叠加 R69 定理 16，FLUID 在「永不交互」边界与 R68 逐指令相同。故 PALM ⊇ FLUID ⊇ R68，安全侧不做任何让步，只在可行切锥内获得对齐增益。

**定理 19（对齐税的切锥下界）** 设任务残差在 a_0 处的可行方向被压到维度 d_K，且 J_t 的最小奇异值 σ_min > 0。任取非零对齐步 δa ∉ null(J_t)，则任务残差增加 ≥ σ_min²||δa||² / ||J_t||；当 d_K = 0 且偏好仍需改进时，对齐税严格为正且随 σ_min 增大而增大。系：**对齐在冗余充足时免费，在接近抓取奇异与约束饱和时昂贵**——这给了「什么时候该问人类偏好、什么时候该闭嘴干活」的定量判据。

## 6. 本轮最大风险

**一句话**：PALM-RAS 把「安全」降维成可测的接触量硬约束，等于偷偷假设「可测的即重要的」——一旦真实伤害落在测量盲区（触觉分辨率看不见的小接触斑、被平均掉的压强尖峰、模型没建模的人体意图与心理边界），系统会**以最高置信度执行最危险的动作，因为它通过了对齐认证**；对齐证书于是从安全证据变成了危险的免责声明。

**次级风险与缓解**：
1. **接触模型误差吃掉鲁棒裕度** → 定义 312 椭球鲁棒集 + E301 盲区召回；模型不确定时裕度单调放大；
2. **reward hacking 在可行集内仍选坏解** → 定义 318 反表象正则 + 引理 20 把伤害上界压到偏好遗憾 + E305；
3. **欺骗性对齐**（有人看才守规矩）→ 定义 321 随机化监督 + 反事实接触审计 + E309；
4. **弃权本身不安全** → 引理 21 + 最小伤害弃权 + minimax 恢复 + E306；
5. **对齐税被隐藏**（用违规换成功率）→ 定义 322 在违规率 = 0 约束下报告 Pareto + E315，禁止跨层交易。

## 4. 推导

**引理 19（零空间对齐的一阶零任务代价）** 若 `∇r_φ(a_0) ∈ null(J_t)`，取 `δa = N Nᵀ∇r_φ`，则 `r_t(a_0+δa)=r_t(a_0)+O(‖δa‖²)`，偏好一阶上升 `‖N Nᵀ∇r_φ‖²`。对齐税一阶为零、二阶为小量；仅在零空间收缩（奇异位形、活动约束吃满）时出现。

**引理 20（宪法支配下的 reward hacking 安全上界）** 设 `|ĉ_j − c_j| ≤ ρ` 且认证用 `ĉ_j ≥ ρ`，则对任意被攻破的 `r_φ`，执行动作仍满足真实约束。故对齐黑客的伤害上界 = 偏好遗憾 `ρ`，不是安全违规；**风险从优化层转移到测量层**（定义 318、E301）。

**引理 21（弃权不天然安全）** 若 `stop ∉ 𝒮_safe^ρ`（滑移/夹持人体/托举易碎物），则 `harm(stop)` 可严格大于某认证动作。故「拒绝=安全」在具身不成立；须把弃权建成主动认证策略 `π_abs`，才能保证退化路径 harm 单调不升。

**定理 18（PALM 严格包含 FLUID 与 R68）** A99–A101（接触映射 Lipschitz、鲁棒裕度覆盖模型误差、偏好层可选）下，PALM 期望物理伤害 ≤ FLUID；偏好禁用/COG 触发/HIL 离线时逐指令相同；叠加 R69 定理 16 得 FLUID 在「永不交互」边界 = R68 ⇒ PALM ⊇ FLUID ⊇ R68。

**定理 19（对齐税的切锥下界）** 设可行方向维度为 d_K、J_t 最小奇异值 σ_min>0。任取 `δa ∉ null(J_t)`，任务残差增加 ≥ `σ_min²‖δa‖²/‖J_t‖`；当 d_K=0 且偏好仍需改进时，对齐税严格为正且随 σ_min 增大。系：**冗余充足时对齐免费，接近抓取奇异/约束饱和时昂贵**——给出「何时问偏好、何时闭嘴干活」的定量判据。

## 7. 本轮最大风险

**一句话**：PALM-RAS 把「安全」降维成可测接触量硬约束，等于假设「可测的即重要的」——一旦真实伤害落在测量盲区（触觉分辨率看不见的小接触斑、被平均掉的压强尖峰、未建模的人体意图），系统会**以最高置信度执行最危险的动作，因为它通过了对齐认证**；对齐证书于是从安全证据变成危险的免责声明。

**次级风险与缓解**：接触模型误差吃掉鲁棒裕度（定义 312 椭球鲁棒集 + E301）；可行集内 reward hacking（定义 318 反表象 + 引理 20 把伤害压到偏好遗憾 + E305）；欺骗性对齐（定义 321 随机监督 + 反事实审计 + E309）；弃权本身不安全（引理 21 + 最小伤害弃权 + E306）；对齐税被隐藏（定义 322 违规率=0 下报 Pareto + E315）。
