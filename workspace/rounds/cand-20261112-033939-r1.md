# 第 58 轮（承接第 57 轮「少样本元推断×跨模态对账×个性化有界信任」IP-133~138；灵感循环第 1 轮（新循环）；本轮灵感：「场景泛化」×「热管理」）

> 第 57 轮把安全的赌注从"模型置信"换到"证据承诺"，再从"证据承诺"换到"从历史语料摊销的元先验"，其自陈的最大风险是"坏先验普遍"——语料存在系统性盲区时，元模型会在 OOD 门学会识别的模式之外给出高度自信的错误后验。本轮指出这个风险背后还压着两个更深、更少被检查的假设：**(a) 场景可交换性假设**——共形覆盖与 OOD 回退都默认目标环境来自与训练同一可交换族，或至少密度比有界；但"场景泛化"追问的是：模型学到的不变性是因果的，还是季节/材质/热区混淆出来的**伪不变性**（例：所有冰面样本都来自冬季，于是"低温外观"被误学成"滑"的充分条件，温暖湿地毯则被自信判干）；**(b) 硬件稳态假设**——第 55~57 轮把传感、执行、算力当作近似常量，而"热管理"指出温度同时移动**能力上限**（电机/电池降额）、**标定参考**（传感器热漂移）与**接触力学**（摩擦、刚度随温变化），且**探针本身是热源**：探询在消耗未来的能力预算。第 57 轮"坏证据长寿"与本轮"坏不变性跨界"合流后，证据不再是"固定过程产生的观测"，而是**动作-热态的联合产物**——这会产生一个前几轮不存在的反馈混淆：保守的降额动作可能产出"看起来乐观"的证据，若不做语境匹配，交互单调性会被悄悄破坏。本轮核心命题升级为 **"场景可泛化、热态可包络、证据可携带的证据说可信"**。

核心矛盾：
- **H29（场景泛化 vs 证据有效性）**：共形覆盖与风险界只在环境覆盖与密度比有界时成立；留一环境验证能挡住一部分过拟合，却挡不住"训练环境集合内自洽的伪不变性"。安全的赌注从"先验质量"再后移到"**不变性假设的正确性**"——而它无法被训练集内的任何统计量完全证明。
- **H30（热管理 vs 安全节奏）**：热降额降低 F_abs、改变步态包线、拖慢元推断（算力热降频），而热故障可能不可逆；同时热预算被探针消耗，探询因此具有**未来能力的机会成本**——"现在多探一次"可能等于"关键接触时少一分力或错过 L2 时限"。
- **H31（证据-动作同源偏移）**：探针改变热态，热态改变观测分布；降额步态下测得的摩擦/滑移不能直接支持标称步态承诺。若不记录并匹配证据的"动作-热语境"，证据复用会把"低力下的安全"误读成"高力下的安全"——**保守动作反而可能制造乐观证据**。

## 0. 直觉与动机

**灵感 1（场景泛化 → 不变性学习 + 加权共形 + 泛化半径）**
直觉：第 57 轮的元先验像一个背熟了历年真题的考生；场景泛化问的不是"这道题眼熟吗"，而是"**这次考试还在同一份大纲里吗**"。于是把"表面参数预测"的风险写成跨环境稳定目标：在训练环境族上做 group-DRO/不变风险最小化，学一个跨地形、材质、季节、热区都稳定的表征 Φ。但不变性不能自证：用**留一环境（LOEO）**在未见环境上量出不变风险差 ρ_inv，再用目标/训练密度比上界 W_max 说明"这次考试离大纲有多远"；加权共形只在 W_max 有限且有界时声明覆盖。把这三个量与有效样本数压成一个**泛化半径 r_gen**：目标场景落在半径内才允许复用旧证据，否则直接判"不可泛化"并退回最宽共形带或第一性物理边界。OOD 由此从一维"新不新"变成二维"新不新 × 能不能迁"。

**灵感 2（场景泛化 → 证据护照：把"可复用"从隐式假设变成显式对象）**
直觉：第 57 轮的跨区域证据复用是"默认成立"的，没人记录这条证据是在哪片地形、哪个季节、什么热态、什么步态与力下取得的。把每条证据变成一张**护照** π(e)：写明场景簇、泛化证书、热区间、步态/力语境、载荷带、有效期与标定参考。承诺是一次"过境"，没有覆盖当前场景与热包线的护照，证据就不能投"承诺票"。新增 **EV-transfer** 证据类专门表示跨场景复用，但只允许用于非不可逆接触——这样"泛化红利"与"泛化风险"被同一张护照分离开：能省一次探针，但永远不能省掉不可逆接触前的实证。

**灵感 3（热管理 → 热包线作为一等安全约束，而不是噪声项）**
直觉：温度不是一个可以平均掉的扰动，而是一个**缓慢、带迟滞、会累积的"能力油表 + 标定基准 + 算力上限"**。电机、电池、算力、传感器各有自己的包线；安全计划不能只看"此刻温度"，而必须对整条航段做**全时域热投影**：未来每个检查点都满足 T_i≤T_i^lim、F_abs(τ)≥F_req、|δ_cal(τ)|≤δ_max，且算力热降频后元推断时延 ℓ_φ(τ) 仍不超过 τ_int。探针发热是可控的热支出，冷却停与 duty-cycle 是热支出管理；硬件热保护作为软件不可绕过的最后一道。

**灵感 4（热管理 → 热致证据漂移、再锚定与语境匹配）**
直觉：用一只"冷、弱、慢"的手去摸摩擦，得到的是关于另一只手的结论。证据似然必须显式条件于热态 τ 与动作语境 a（力/步态）：热距离越远，证据可靠性 ρ_th 越低；跨越迟滞支或超过再锚定阈值，必须补一次标定探针才能再入证据门。更关键的是**动作-热混淆**：降额步态下"没滑"只证明低力下没滑；要支持标称力，证据必须是在不低于该力的语境下取得，或经过去混淆校正。否则热管理会把单调性翻过来。

**灵感 5（合流 → 保守测试时适应：只收紧的棘轮）**
直觉：部署期一定会有分布漂移，禁止适应等于慢性失准；但让系统"越适应越敢赌"就复刻了第 57 轮的信任通胀。于是把适应定义成一个**只收缩的棘轮**：可以加宽共形带、上调不确定性、下调可靠性、加强降额、缩小泛化半径、提高佐证要求；绝不允许扩大可承诺集合、收窄共形带、放宽 r_gen。想扩张必须走**重新认证**且通过隔离区影子回归，不能靠"在线适应"偷渡。这样场景泛化与热管理都只经由"信念更准/更宽"或"动作更保守"两个安全通道起作用，延续并强化交互单调性。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（场景泛化不变推断 SGI）** 环境 e∈ℰ=地形×材质×季节×热区×载荷，场景描述 z_e。训练环境集 ℰ_tr，留一环境验证集 ℰ_loo。跨环境不变目标：
min_{Φ,h} max_{e∈ℰ_tr} R_e(h∘Φ) + λ·Var_e(R_e(h∘Φ)) + μ·Ω(Φ)，
其中 R_e 为环境 e 上的风险，Var_e 惩罚环境间风险方差，Ω 为容量约束（group-DRO/不变风险最小化的统一写法）。场景证书 σ_sc=(ε_cov, ρ_inv, W_max, n_eff, r_gen)：ε_cov=sup_{e∈ℰ} min_{e'∈ℰ_tr} d_env(e,e') 为环境覆盖缺口；ρ_inv=max_{e∈ℰ_loo}R_e−min_{e∈ℰ_loo}R_e 为留一环境不变风险差；W_max=sup_z p_tgt(z)/p_tr(z) 为截断密度比上界；n_eff=(Σ_j w_j)²/Σ_j w_j² 为加权有效样本；r_gen=sup{r: sup_{d_sc(z,z_e)≤r}[ρ_inv+W_max·Lip·r]≤θ_gen} 为可声明泛化半径。加权共形区间 C_α(z)={y: Σ_j w_j 1[|y−ŷ_j|≥|y−ŷ(z)|]/Σ_j w_j > α}，w_j∝p_tgt(z_j)/p_tr(z_j) 截断于 W_max；覆盖 ≥1−α 仅在 w≤W_max ∧ 同层可交换 ∧ 概念漂移检验通过时声明。若 W_max>W̄ 或 ρ_inv>θ_inv 或概念漂移检验失败 ⇒ 判"不可泛化"：禁用 EV-transfer 与旧区域证据，退最宽共形带或物理硬边界，不可逆接触必须现场重新实证。

**定义 140（热包线管理 THEM）** 热状态 τ=(T_motor,T_batt,T_compute,T_sensor,T_amb,Ṫ)，热动力学 τ_{k+1}=H(τ_k,a_k,env)（一阶集总热模型 + 迟滞支）。能力/接口映射：接触能力 F_abs(τ)、步态包线 G(τ)、传感标定漂移 δ_cal(τ)、元推断时延 ℓ_φ(τ)（算力热降频下单调增大）。热包线 ℰ_th(sched;τ_0)={τ(·): ∀t, T_i(t)≤T_i^lim−m_i, F_abs(τ(t))≥F_req(sched(t)), |δ_cal(τ(t))|≤δ_max, ℓ_φ(τ(t))≤τ_int−m_d}。热预算 B_th=min_i∫(T_i^lim−m_i−T_i(t))dt 为全时域剩余最紧裕度。热策略 π_th∈{nominal, derate, duty_cycle, cooling_pause}。承诺与步态选择必须满足**全时域热投影**在 ℰ_th 内，否则降额/暂停/绕行/L2；硬件热保护为软件不可覆盖的最终界。算力热降频不得仅以"平均时延"预算，必须用最坏降频下的 ℓ_φ 校验 τ_int，否则退回缓存后验或手工先验。

**定义 141（热致证据漂移与再锚定 TEC）** 证据似然显式条件化：p(o|θ,τ,a)，a=(步态,力,载荷) 为动作语境。热致可靠性 ρ_th(τ,τ_e)=exp(−‖τ−τ_e‖_Σ/ℓ_th)·1[hysteresis(τ)=hysteresis(τ_e)]，τ_e 为证据采集时热态。再锚定：若 ‖τ−τ_e‖_Σ>θ_re，则该证据须先补一次标定探针（重新建立 cal_ref）才能进入证据门，否则只作参考。语境匹配：证据对承诺 c 可支持当且仅当 g_e=g(c) 且 f_e≥f_req(c) 且载荷带包含 p(c)；降额/低力证据不得支持标称/高力承诺。热-动作混淆偏差 Δ_th=sup|R̂(o|τ,a)−R̂(o|τ_e,a_e)| 必须并入 P_fail（无法去混淆时按最坏情形计）。热迟滞使证据跨"升温支/降温支"不可直接迁移。

**定义 142（证据护照 EPP）** 每条证据 e 携带护照 π(e)=(c_e, σ_sc(e), [τ_lo,τ_hi], g_e, f_e, p_e, t_exp, cal_ref, sig)，其中 c_e 场景簇、σ_sc(e) 采集时泛化证书、热区间、步态/力/载荷语境、有效期、标定参考与签名。证据对承诺 c 可采纳 ⇔ passport_admit(e,c)=true：d_sc(c,c_e)≤min(r_gen(c_e),r_gen(c)) ∧ τ(c)∈[τ_lo,τ_hi] ∧ g_e=g(c) ∧ f_e≥f_req(c) ∧ p(c)∈p_e ∧ t<t_exp ∧ sig 有效 ∧ ‖τ(c)−τ_e‖_Σ≤θ_re。新增证据类 **EV-transfer**：仅在 d_sc≤r_gen ∧ 同热包线 ∧ 非不可逆接触时可替代一次普通佐证；**不可逆接触的必要证据集永不含 EV-transfer**。护照缺失/过期/签名失效 ⇒ 证据降级为"仅参考"，不得进入证据门。护照把"证据可迁移"从隐含假设变成可审计对象。

**定义 143（保守测试时适应 STA）** 部署期适应算子 A_adm 更新系统状态，但满足**收缩不变式**：对任意 c，c∈CommitSet(A_{t+1}) ⇒ c∈CommitSet(A_t)（可承诺集合只缩不扩）。允许的更新方向：共形带加宽、不确定性上调、可靠性 ρ↓、降额加强、r_gen↓、佐证数↑、τ_int↓；禁止方向：共形带收窄、r_gen↑、ρ 越界上调、授权扩张、佐证数↓。任何扩张必须走**重新认证**：在隔离区以影子模式积累新环境/新热区数据，通过不变性检验、覆盖检验、热包线回归后才可提升权限，且需版本化与审计。适应只在场景-热包线内生效，超出即触发再认证或退回非参带。

**定义 144（场景-热泛化证据门 GEG 与 PCX++）** 证据类：EV-probe*（须 σ_sc 且非"不可泛化"、挂热护照）、EV-visit、EV-margin、EV-xmodal（仅 L1）、EV-human（auth+佐证，继承第 57 轮）、**EV-transfer**（仅非不可逆、d_sc≤r_gen、同热包线、passport 覆盖）。不可逆接触必要证据集={EV-probe*∨EV-margin}∪佐证，且每条必要证据的护照必须覆盖当前场景与热包线；EV-xmodal 与 EV-transfer 不得进入该集合。PCX++ 每检查点：①场景识别与 σ_sc 核验（不可泛化→禁旧证据）；②热状态更新与**全时域热投影**（预测航段温度轨迹）；③护照校验与再锚定检查；④热感知悲观 VOI：VOI_th(π)=E[信息增益|悲观元后验]−cost(π)−λ_th·ΔB_th(π)−机会成本(未来能力损失)，其中探针发热计入 ΔB_th；⑤承诺 ⇔ 全时域 ℰ_th 满足 ∧ GEG 过 ∧ 风险界成立；否则降额→冷却停→绕行→L2 协商→安全停。证书 J_g=(M_core,C_core,K_margin,ρ_sem,δ_s,probe_log,consent_log,meta_cal_log,xmodal_log,auth_log,ood_registry,σ_sc,thermal_traj,passport_index,adaptation_log,thermal_budget)。PCX++ 在 k_probes+k_cons 与热预算有限步内终止。

## 2. 关键算法伪代码（完整版见产物区）

```python
def scenario_certificate(phi, D, E_tr, E_loo):
    rho_inv = max_e(risk_e(phi, D)) - min_e(risk_e(phi, D))   # 留一环境
    W = density_ratio_bound(D, target_prior)                  # 截断上界
    eps_cov = coverage_gap(E_tr, E_loo)
    n_eff = effective_sample_size(D)
    r_gen = max_radius(rho_inv, W, eps_cov, n_eff, theta_gen)
    return Cert(eps_cov, rho_inv, W, n_eff, r_gen)            # 证书

def thermal_project(tau0, sched, env):
    traj = forward_thermal(tau0, sched, env)                  # 迟滞
    ok = all(T_i(t) <= lim_i - m_i and F_abs(tau_t) >= F_req(s_t)
             and abs(dcal(tau_t)) <= dmax and lphi(tau_t) <= tau_int - md
             for t, tau_t, s_t in scan(traj, sched))
    return ok, traj, choose_policy(traj)                      # 热包线投影

def passport_admit(e, c, cert):
    p = e.passport
    if p is None or not p.sig or now() > p.t_exp:              return False, 'no_passport'
    if d_sc(c.region, p.c_e) > min(cert.r_gen, p.r_gen):       return False, 'outside_rgen'
    if not in_interval(tau(c), p.tau_lo, p.tau_hi):            return False, 'thermal_bad'
    if p.g_e != g(c) or p.f_e < f_req(c):                      return False, 'context_mismatch'
    if thermal_dist(tau(c), p.tau_e) > theta_re:               return False, 'needs_reanchor'
    return True, 'ok'
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| SGI | 训练离线 O(\|ℰ_tr\|·n_e·d_Φ)；推断 O(d_Φ)；加权共形 O(N_cal) | O(N_cal) 静态 | ρ_inv/W_max 诚实声明、LOEO 覆盖 |
| THEM | O(H_th·\|sched\|)/检查点 | O(\|sched\|) | 热模型保守、全时域投影、最坏降频 |
| TEC | O(\|ℳ\|·d_τ)/证据 | O(\|τ\|) | 语境匹配、再锚定、热混淆并入 |
| EPP | O(1) 查表 + O(d_z) 距离 | O(\|evidence\|) | 护照完整、签名、有效期 |
| STA | O(1)/更新 + O(H_op) | O(\|操作者\|+\|认证\|) | 收缩不变式、扩张须再认证 |
| PCX++ | 继承第 57 轮 + O(\|CP\|·H_th·\|sched\|) | O(\|V\|+\|σ\|) | 热预算单调、有限终止 |

**正确性定理（Scenario-Thermal Generalized Soundness, STGS 概要）**：在第 57 轮 A37–A40 上新增 (A41) 场景证书诚实：ρ_inv≤θ_inv、W_max≤W̄、LOEO 与概念漂移检验未失败；(A42) 热模型保守：预测温度不低于实测（含裕度）、F_abs 对温度单调、热故障可由包线投影提前拦截；(A43) 证据护照完整且热-动作语境匹配；(A44) 适应收缩：CommitSet 只缩不扩，扩张必经再认证。则：(i) **泛化承诺界**：目标场景 d_sc≤r_gen 时 P(fail)≤δ_f+ε_cov+ρ_inv+δ_cp(W_max)+δ_probe+ε_h；W_max>W̄ 或 ρ_inv>θ_inv 时退化为"不可泛化即不承诺"（仅物理硬边界与现场实证）；(ii) **热安全界**：航段全时域在 ℰ_th 内 ⇒ 热故障概率≤δ_th；热态不确定度超阈值即降额，故不增加风险；最坏降频下 ℓ_φ≤τ_int 或安全回退；(iii) **迁移健全性**：EV-transfer 仅非不可逆，贡献≤δ_trans，且不进入不可逆必要证据集；(iv) **单调性/收缩性**：降额、泛化回退、STA 只能收缩可承诺集合；所有新机制仅经"信念更准/更宽"或"动作更保守"起作用；(v) **终止性**：探针≤k_probes+k_cons，热预算单调消耗或冷却停次数有界，PCX++ 终止于 {承诺,降额,冷却停,绕行,L2,安全停}。

def scenario_certificate(phi, h, D, E_tr, E_loo, target):
    R_loo = {e: risk(phi, h, D[e]) for e in E_loo}
    rho_inv = max(R_loo.values()) - min(R_loo.values())
    W = clip(density_ratio(D, target), hi=W_bar)     # 截断密度比

    status = 'generalizable' if (rho_inv <= theta_inv and W <= W_bar
                                 and concept_drift_ok(D, E_loo)) else 'not_generalizable'
    return Cert(eps_cov, rho_inv, W, n_eff, r_gen, status)

def weighted_conformal(residuals, weights, z, alpha):
    if max(weights) > W_bar:                         # 不可泛化
        return widest_belt_or_physics_bound(z)       # 禁旧证据
    return weighted_quantile(residuals, weights, 1 - alpha)

def thermal_project(tau0, sched, env, margins):
    traj = forward_thermal(tau0, sched, env)         # 一阶集总 + 迟滞支
    ok, worst = True, {}
    for t, (tau_t, s_t) in enumerate(zip(traj, sched)):
        ok &= all(tau_t.T[i] <= lim[i] - margins.m[i] for i in devices)
        ok &= F_abs(tau_t) >= F_req(s_t)
        ok &= abs(dcal(tau_t)) <= margins.dmax
        ok &= lphi(tau_t) <= tau_int - margins.md   # 最坏热降频
        worst[t] = thermal_slack(tau_t, s_t)
    if not ok:
        return False, traj, choose_policy(traj)      # derate/duty/cooling_pause
    return True, traj, 'nominal'

**正确性定理（Scenario-Thermal Generalized Soundness, STGS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 场景证书诚实：ρ_inv≤θ_inv、W_max≤W̄，LOEO 与概念漂移检验未失败，r_gen 保守；**(A42)** 热模型保守：预测温度不低于实测（含裕度），F_abs 对温度单调，热故障可由 ℰ_th 投影提前拦截；**(A43)** 证据护照完整且动作-热语境匹配，Δ_th 按最坏计入；**(A44)** 适应收缩：CommitSet(A_{t+1})⊆CommitSet(A_t)，任何扩张必经隔离再认证。则：

1. **泛化承诺健全性**：目标场景 d_sc≤r_gen 时 P(fail)≤δ_f+ε_cov+ρ_inv+δ_cp(W_max)+δ_probe+ε_h；W_max>W̄∨ρ_inv>θ_inv 时退化为"不可泛化即不承诺"，仅保留物理硬边界与现场实证。
2. **热安全**：航段全时域在 ℰ_th 内 ⇒ P(热故障)≤δ_th；热态不确定度超阈值即降额，故不增险；最坏热降频下 ℓ_φ≤τ_int，否则缓存后验/手工先验/安全停。
3. **证据迁移健全性**：EV-transfer 仅在非不可逆层贡献 ≤δ_trans，且不可进入不可逆必要证据集；EV-xmodal 仍限 L1。
4. **单调性/收缩性**：降额、泛化回退、STA 只能收缩可承诺集合；场景泛化与热管理只经"信念更准/更宽"或"动作更保守"影响系统。
5. **终止性**：探针≤k_probes+k_cons，热预算单调消耗或冷却停次数有界，PCX++ 终止于 {承诺,降额,冷却停,绕行,L2,安全停}。
6. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_cov + ρ_inv + δ_cp + δ_probe + ε_h + δ_th
                  + δ_ood·α_conf + δ_xm·1[L1] + δ_trans·1[non-irrev])
             − P(护照过期/语境失配未检出) − P(热模型失配)
             − P(STA 收缩不变式被违反) − P(停止链失效)
```

关键：**泛化靠不变性证书而非元先验自信**（效率与迁移安全解耦）；**热安全靠全时域包线投影而非瞬时温度**（能力、标定、算力、预算四维一体）；**证据复用靠护照而非隐式假设**（不可逆层永远现场实证）；**适应只收紧不放松**（扩张必经隔离再认证）。四条机制全部经"信念更准/更宽"或"动作更保守"两个安全通道工作。

## 6. 本轮最大风险

**一句话**：本轮最大的风险是**伪不变性**——模型可能从训练场景学到"冬季↔冰面"这类虚假相关，而热降额又会改变证据生成过程，使错误不变性与热致漂移相互掩护；一旦 EV-transfer 与保守适应把它们带过场景边界，系统就会在"看起来熟悉"的新场景里自信犯错，因此必须以留一环境证书、泛化半径、全时域热包线投影、不可逆接触禁用 EV-transfer、适应只收缩五重护栏，把"不可泛化"直接判成"不承诺"。
