## 双轴映射（在 ToolGauge 上叠加，而非重写）

**核心命题**：把 ToolGauge 的
「语义假设 → 契约化工具调用 → 摊销校准 → 交叉验证后局部热替换」
升级为
「**价值契约下的记忆条件化摊销 → 纵向验证 → 可逆热替换 → 可审计遗忘**」：
- 价值层只做三件事：**约束**（硬约束不可交易）、**审计**（代理是否仍与价值同向）、**升级**（判例跨版本必须重新裁决）；
- 记忆层只做三件事：**提议**（先验/假设/程序模板）、**证明**（溯源与信任）、**遗忘**（TTL/衰减/反例保留）；
- **价值与记忆都不进入数值通道**：数值真值仍由当前回执与 V 阶段独占。

**新增两条不变式（五不变式之上）**：
6. **价值地板（value floor）**：退化只能降低能力，不能放宽硬约束；价值审计不可用时必须弃权，而不是退回无约束修复；
7. **记忆非干涉（memory non-interference）**：记忆只 condition 提议/先验，永不直接写数值；剥离记忆是纯投影，写入必须可回滚。

## 0. 直觉与动机

### 0.1 价值对齐：计量系统也会 reward hacking

直觉：ToolGauge 把「修复」定义成「把后验方差压到 ε、让覆盖矩阵变绿」。这是一个**代理目标**。
对计量层来说，它几乎总是正确的；但对部署者来说，它可能完全错误：

- 一个盲区在镜面走廊。信息增益最大的探测是**强光扫描**；但在夜间人流量大的区域，强光可能晃到人——
  这是硬约束，不能用「探测收益更高」来交易。
- 一个修复可以通过「假设该区域长期空置」把 σ 降下来；但任务价值包含**碰撞规避**，方差下降不等于风险下降。
- 一个修复可以通过「只相信低噪声传感器」把 σ 降下来；但该传感器可能正好对某类材质失明，价值因此下降。

这就是计量层的 reward hacking：**优化了可测量的代理，牺牲了不可测量但真正重要的价值**。
ToolGauge 的 P-Quarantine 只看「预测收缩 vs 实际收缩」的符号，看不到价值层面的解耦；
V 阶段只检查数值一致性，不检查「这个修复是否被允许」。

因此需要一层显式的价值契约（VC）：把**硬约束**（安全、法律、隐私、可逆性）与**软偏好**
（任务成功率、精度、时延、能耗、人工负担）分开；硬约束永远不能被权重交易；
软偏好用利益相关者权重加 **max-min 地板**，防止「总效用最大」牺牲少数人。
价值门不是一个更大的损失函数，而是一个**否决权**：不可估计即弃权，而不是猜一个数。

### 0.2 长期记忆：经验是资产，也是负债

直觉：ToolGauge 每个会话都从冷启动开始。同一类镜面盲区在 A 楼修过，到 B 楼还要重新探测；
上一次修复为什么被允许、被谁批准、在什么价值版本下允许，会话结束就丢了。
这既浪费样本，也让系统无法保持一致性，更无法做纵向审计。

但「记住」不是免费午餐：
- 一次错误修复写进长期记忆，会在所有后续会话里被反复检索、反复引用，**局部错误变成全局先验**；
- 一条被投毒的情节（伪造回执/伪造结果）如果进入长期记忆，等于给攻击者一个**跨会话持久化**的写入口；
- 一条旧价值版本下的判例（例如「夜间强光可以接受」）如果被自动沿用，在新安全规范下就是**价值锁定**；
- 记忆越多，检索越慢、隐私面越大、过时经验越容易主导。

因此记忆必须是**有来源、有信任、有版本、有寿命、可回滚**的：
情节记忆（episode）记录一次修复的完整证据；语义记忆（semantic）只保存跨情节归纳出的模式/指纹/先验；
程序记忆（procedural）保存可复用的探测模板；负记忆（negative）保存失败与事故教训，衰减最慢；
隔离记忆（quarantine）保存未验证/可疑情节，只能审计、不能检索。
**记忆不是事实库，而是「带证据的经验库」；每次检索都只是提出假设，不是宣告真理。**

### 0.3 交叉风险：最危险的不是遗忘，而是记住了一个过时的价值

价值对齐需要记忆：没有记忆，系统无法保持一致性、无法复用人类裁决、无法纵向审计。
记忆也需要价值对齐：没有价值约束，记忆会固化偏见、放大投毒、把「上次这么做没出事」当成「这次也可以」。
二者交叉处有一个特别隐蔽的失败模式：**价值锁定（value lock-in）**。
系统检索到旧判例 → 生成语言证书「与历史裁决一致」→ 审计者看到一致性 → 批准；
但当前价值版本/部署域已经变化，系统其实是在用**记忆 laundering** 把价值漂移包装成稳定性。
因此本轮把「判例」与「政策」严格分离：**判例只进入审议上下文，不构成许可；
跨价值版本的判例必须重新裁决，禁止自动沿用。**

### 0.4 一个贯穿全文的例子

镜面走廊盲区 s：
1. ToolGauge 的 T-Box 选出「强光扫描」；V-Box 的硬门发现该区域当前有人，强光违反 VC 的 C_hard，
   且价值盾无法给出「零伤害」的置信上界 ⇒ **弃权**，改用低强度 IR 或排队人工；
2. 人工批准低强度 IR 修复，生成 VCert，写入 L1 记忆；语义记忆归纳出「镜面材质 M 在低照度下用 IR 更稳」；
3. 同一盲区在另一栋楼出现；检索到 A 楼判例，但当前 κ 已从 1 升到 2（新安全规范）⇒ **必须重新裁决**，
   不得自动沿用；
4. 攻击者注入一条「该镜面无需探测、直接标为已覆盖」的伪造情节；写入门因缺少有效回执/VCert/法定人数而拒绝，
   进入隔离记忆；
5. 某次修复通过「假设走廊空置」把 σ 降下来，但审计集上的任务价值下降；VDM 检出代理-价值解耦，
   冻结修复并按 provenance 回滚。
这个例子同时覆盖了价值门、记忆写入门、版本治理、投毒防御和代理解耦监控。

## 1. 形式化定义（增量：定义 432–446）

**定义 432（价值契约 VC）**
VC = (C_hard, U, w, u_min, S, κ, T_V)：
- C_hard：状态-动作-结果三元组的硬约束谓词集合（安全、法律、隐私、可逆性）；要求 P(¬C_hard) ≤ δ_hard（默认 δ_hard = 0）；
- U = (U_1,…,U_k)：k 个结果属性（任务成功率、精度、时延、能耗、可逆性、人工负担）；
- w ∈ Δ^{k−1}：利益相关者权重；u_min：每个利益相关者的效用下界（max-min 地板）；
- S：利益相关者集合与司法/部署域；κ：价值版本号；T_V：有效期/复审周期。
**VC 不是奖励函数**：w 只用于软偏好排序；C_hard 不可被写成大罚项，也不可被权重交易。

**定义 433（价值泛函与对齐间隙）**
对修复策略 π 产生的轨迹 τ，U(τ) ∈ R^k；V_w(π) = E_{τ∼P_π}[Σ_i w_i U_i(τ)]。
可行策略集 Π_adm = {π : P(¬C_hard) ≤ δ_hard, E[U_i] ≥ u_min ∀i}。
对齐间隙 Δ_V(π) = sup_{π'∈Π_adm} V_w(π') − V_w(π)。
π 是 (ε_V, δ_hard)-对齐的，若 Δ_V(π) ≤ ε_V 且硬约束满足。
若 Π_adm = ∅ ⇒ 系统必须**弃权**，不得选择「次优但违规」的动作。

**定义 434（价值证据与价值证书 VCert）**
VCert(s) = (κ, C_hard 检查记录, 价值证据 E_V, 审计集版本 D_audit, 反事实对照, 回滚 id, 签名, 异议记录)。
E_V 只能由三类证据组成：有效回执、预注册审计集上的统计检验、独立价值盾（定义 435）的输出。
价值主张（「安全」「合规」「公平」）若未绑定 E_V，则在序列化时剥离，且 A 阶段不得引用
（推广第 2 轮定义 423 的「主张-回执绑定」）。

**定义 435（独立价值盾与 A 阶段价值门）**
价值盾是一个与 MP-Φ/VLA **不共享参数**的独立评估器（规则/物理模型/人类审计），
在审计分布 D_audit 上给出硬约束违反概率上界与软价值估计。
A 阶段（Align）对候选修复 a 依次检查四门：
1. **硬门**：UCB_{1−δ_hard}(violation | a) ≤ δ_hard；不可估计 ⇒ 弃权；
2. **软门**：Δ̂_V(a) ≤ ε_V（置信上界）；
3. **判例门**：所有被检索的判例必须满足 κ 相同且司法域兼容；否则转人工再裁决；
4. **可逆门**：存在已演练的回滚路径，回滚代价 ≤ B_rollback。
四门全过才允许 U 阶段热替换；任一失败 ⇒ 弃权/升级人工，不进入「先替换再说」的路径。

**定义 436（代理-价值解耦监控 VDM）**
代理 P(a)（如 σ 收缩量、覆盖增益）与价值 V(a) 在 D_audit 上的关系用序贯检验监控：
维护 (P_t, V_t) 的滑动窗口，估计秩相关 ρ_t 与校准残差；
若 ρ_t < ρ_min 或连续 q 个窗口出现「V_t 下降而 P_t 上升」⇒ 判定代理解耦（reward hacking 信号）。
触发后：暂停自主修复，冻结当前 κ，转人工审计；已热替换的子图按 provenance 回滚。
D_audit 与长期记忆**物理隔离**，不可写入 M-Box（防止审计集泄漏/过拟合）。

**定义 437（长期计量记忆 LTMM / M-Box）**
M = (E, S, P, N, Q, G, prov, TTL)：
- E 情节记忆：e = (id, s, H_s, Π_s, receipts, VCert, outcome, env_version, κ, ts, trust, ttl)；
- S 语义记忆：跨情节归纳的模式/指纹/先验统计（如「材质 X ⇒ 镜面残差模式 F_X」），带置信与适用范围；
- P 程序记忆：可复用的探测程序模板及成功统计；
- N 负记忆：失败指纹、黑名单参数组合、事故教训（保留期最长，衰减最慢）；
- Q 隔离记忆：未验证/可疑情节，只读用于审计，不进入检索；
- G 溯源图：每条记忆指向其证据与派生条目，用于失效传播；
- prov/TTL：来源与生存期。

**定义 438（记忆写入门 MWG）**
工作记忆 L0 → 局部验证 L1 → 全局巩固 L2 的晋升条件：
1. 有效回执 + VCert + V 阶段交叉验证通过；
2. 无未关闭事故；κ 与 env_version 完整；
3. 法定人数 k 个独立回执/会话一致；否则进 Q；
4. 写入必须带 tombstone（可撤销）与溯源边；**无回滚路径不写入**。
写入门把「一次错误」限制在 L0/Q，防止污染长期先验。

**定义 439（记忆检索与信任）**
检索分数 score(e|s) = sim(s,e) · trust(e) · compat(env_version_e, env_t) · decay(Δt; λ)；
返回 top-k 及**校准后的信任分布**，不返回点值。
记忆只作为先验/假设/程序模板；**记忆永不直接写 u_s、χ_R 或 M_ver**（记忆非干涉公理）；
所有数值影响必须经过当前回执与 V 阶段重新验证。
若 max trust < τ_m 或 compat = 0 ⇒ 忽略记忆，回退 AP-Cal（冷启动）。

**定义 440（RA-Cal：检索增强摊销校准）**
q_θ(u_s | h, receipts, R(M,s))，其中 R 是 top-k 记忆。训练目标：
预测损失 + β_KL·KL(q_θ‖p_phys) + β_CF·反事实一致性 + β_abs·记忆弃权正则。
- **反事实一致性**：当 R 与当前回执不相关（随机替换/遮蔽检验）时，q_θ 应与无记忆的 AP-Cal 输出在容差内一致；
- **记忆弃权**：模型输出 gate g ∈ [0,1]，g = 0 时严格退化为 AP-Cal；
- **稳健聚合**：语义记忆统计量用截尾均值/中位数，每条记忆带签名与溯源。
高斯近似下的收缩形式：
Σ_mem 按 staleness/poisoning 膨胀，û = (Σ_mem^{-1} + Σ_ctx^{-1})^{-1}(Σ_mem^{-1} μ_mem + Σ_ctx^{-1} μ_ctx)。
当记忆信任低时 Σ_mem → ∞，自动退化为当前回执的后验。

**定义 441（记忆投毒与稳健聚合）**
设检索集大小 n，其中 ≤ ν 条被投毒；坐标截尾均值（trim γ > ν）的偏差
≤ (ν/(1−2ν))·B + O(√(log(1/δ)/n))，崩溃点 < 1/2。
签名/溯源 + 写入门 k-法定人数把投毒概率从单条 ν_0 降到 ν_0^k（独立妥协假设）；
不独立时按相关妥协上界处理。
**记忆投毒是新的攻击面**：ToolGauge 防的是「伪造回执」，StewardGauge 还要防「伪造历史」。

**定义 442（价值版本与判例-政策分离）**
判例 e 带 κ_e；当前 κ_t。跨版本检索：
- κ_e = κ_t：可作为先验/判例；
- κ_e ≠ κ_t：只能作为「历史参考」，必须重新裁决（人工或独立价值盾），**禁止自动沿用**；
- 司法域 S_e 与 S_t 不兼容：直接拒绝。
判例不是政策：检索结果只进入 A 阶段的审议上下文，不构成许可。

**定义 443（价值地板与安全优先退化链）**
系统层级：S_3 = StewardGauge ⊃ S_2 = ToolGauge+VC ⊃ S_1 = LeanGauge+VC ⊃ S_0 = MODGAUGE+monitor。
退化算子 D_i 只允许移除能力模块，不允许移除 C_hard；且对任意相邻层，
Allowed(S_{i−1}) ⊆ Allowed(S_i)，硬约束违反概率不增。
若价值审计（A 阶段/价值盾）不可用 ⇒ **不得退化到无价值约束的自主修复**；
只能进入「只监控、不修复、排队人工」的 S_0 安全态。
这修正 ToolGauge 的「能力优先」退化链：安全约束是单调下传的，不是可选的。

**定义 444（记忆非干涉与可逆写入）**
(a) 记忆通道与数值通道分离：M-Box 只能输出先验、假设、程序模板、信任分数；不能直接写 u_s/χ_R/M_ver。
(b) 记忆剥离投影 strip_M：移除 M 后重新用当前回执校准；若热替换子图的数值行为变化超过 ε_num，
则该记忆写入非法，整条回滚。
(c) 每条 L1/L2 写入带 tombstone 和 provenance 边；失效/回滚沿 G 传播，且不依赖被撤销条目的派生值。
这三条保证「记忆是增强项，不是依赖项」，并把 ToolGauge 的引理 49/50 推广到纵向。

**定义 445（纵向审计与遗忘）**
- 审计集 D_audit 按时间轮换，按时间外推留出（time-held-out），不可写入 M；
- 遗忘曲线：语义记忆半衰期 h_S，程序记忆按 env_version 作用域失效，负记忆半衰期 h_N ≫ h_S；
- 巩固：同类情节合并为语义条目，保留溯源与反例；**巩固不是多数投票**，独立 provenance 不足时不得合并；
- 容量 C_M 与检索延迟 τ_ret 由 MB-Contract 约束；超限时优先遗忘低 trust、低使用、旧版本条目，
  **永不遗忘负记忆中的硬约束事故**；
- 每次遗忘/巩固都要写审计日志，保证可复现。

**定义 446（MB-Contract 与 8C 时序）**
MB = (C_M, τ_ret, h_S, h_N, B_consolidate, recovery)。
8C = H→C→E→C→V→A→U→M：
- A 阶段在异步修复路径内，硬门必须同步完成；软门可用预注册采样；
- M 阶段全部异步（写入门、巩固、遗忘）；
- 50Hz 计量路径只保留继承的 O(1) 回执验证与只读记忆路由（无锁），不等待 A/M；
- 预算/时延失败 ⇒ 安全弃权，不降级为无约束修复。

## 3. 推导

**引理 51（代理-价值对齐的遗憾界）**
在审计分布 D_audit 上假设：
(A1) **局部 ρ-可观测**：对修复邻域内任意 a,a′，|V(a)−V(a′)| ≤ ρ^{-1}|P(a)−P(a′)| + b；
(A2) 代理优化误差：P(â) ≥ sup_a P(a) − η_P；
(A3) 审计估计误差：|V̂−V| ≤ ε_V^audit、|P̂−P| ≤ ε_P（概率 1−δ）。
则 Δ_V(â) ≤ ρ^{-1}(η_P + 2ε_P) + b + 2ε_V^audit。
证明：设 a* 为价值最优；由 A2，|P(a*)−P(â)| ≤ η_P；由 A1 得价值差 ≤ ρ^{-1}η_P + b；
再用 A3 把真实量替换为审计估计量，误差各加 2ε。证毕。
**系 51.1**：ρ → 0（代理与价值解耦）时界发散；VDM 监控 ρ_t 就是监控这个界的分母。
**系 51.2**：当 ρ 高且审计误差小时，优化代理是价值对齐的充分近似；这解释了 ToolGauge 在多数场景有效，
但不能把「有效」当成「总是对齐」。

**引理 52（记忆条件化校准的偏差-方差界）**
设当前回执给出 μ_ctx、Σ_ctx；记忆先验 μ_mem、Σ_mem；目标 u* 满足 ‖u*−μ_ctx‖ ≤ B_s（staleness 偏差上界）。
采用定义 440 的收缩估计 û，则
E‖û−u*‖² ≤ B_s² + tr((Σ_mem^{-1} + Σ_ctx^{-1})^{-1}) ≤ B_s² + min(tr Σ_mem, tr Σ_ctx)。
证明：偏差项由收缩算子对 μ_mem−μ_ctx 的加权给出，权重谱范数 ≤ 1，故 ≤ B_s；
方差项是后验协方差的迹。证毕。
**系 52.1（同环境）**：B_s = 0 时记忆是纯方差缩减；若记忆提供 m 条同环境有效样本，
方差项从 tr Σ_ctx 降到 O(σ²/(m+N_bl))——这就是「长期记忆买样本效率」的定量版本。
**系 52.2（跨环境）**：B_s ≥ √(tr Σ_ctx) 时冷启动严格更优；RA-Cal 的 gate 必须在 B_s 大时把记忆权重压到 0。
这给出「记忆不是越多越好」的可操作判据，也是负迁移防御的理论依据。

**引理 53（记忆投毒的稳健界）**
检索集 n 条、≤ν 条被投毒，坐标截尾均值 trim γ > ν：
|μ̂−μ| ≤ B·ν/(1−2γ) + O(σ√(log(1/δ)/n))；γ ≥ 1/2 时崩溃。
若写入门要求 k 个独立签名/会话一致，且每次独立被妥协概率 ≤ ν_0，则一条投毒情节进入 L2 的概率 ≤ ν_0^k。
**系 53.1**：k=3、ν_0=0.1 ⇒ 有效投毒率 ≤ 10^{-3}，低于常用 trim 阈值。
**系 53.2**：若攻击者能伪造签名或同时妥协 k 个会话，则回到「相关妥协」模型，必须靠 provenance 图与人工审计兜底。
**系 53.3**：巩固阶段不能做多数投票；否则 k 条同源投毒会被「巩固」成一条高信任语义记忆。

**引理 54（记忆非干涉与价值地板保持）**
(a) 若 M-Box 只输出 (先验, 假设, 程序模板, 信任)，且 RA-Cal 在 gate=0 时严格等于 AP-Cal，
则 strip_M(StewardGauge) 与 ToolGauge 在热替换子图上数值等价（至多 ε_num）；
因此第 2 轮引理 49（语言层不破坏等价性）推广到记忆层。
(b) 若退化算子 D_i 满足：只移除能力模块，且 Allowed(S_{i−1}) = Allowed(S_i) ∩ C_hard，
则 Allowed(S_{i−1}) ⊆ Allowed(S_i)，硬约束违反概率不增；A 阶段不可用时取 Allowed = ∅（不修复）是最小元。
证明：(a) 由 gate=0 的严格退化与「记忆不直接写数值」得；(b) 由集合包含的归纳与 C_hard 的合取单调性得。证毕。
**系 54.1**：价值地板是**单调下传**的：越弱的系统，允许的动作集越小，而不是越大。
这直接修复了 ToolGauge「VLA 失效就退回 LeanGauge」可能绕过新安全约束的缺陷。

**引理 55（价值漂移的可检测性与价值锁定下界）**
(a) 若每会话价值漂移幅度 ≥ δ，审计噪声方差 σ²，则 CUSUM/e-test 在
O((σ²/δ²)·log(1/α)) 个会话内检测，误报 ≤ α。
(b) 存在漂移序列 δ_t = δ_min/2，使检验统计量在 T 个会话内始终低于阈值，而累计价值损失 = Ω(T·δ_min)。
因此任何有限样本检验都无法同时保证低误报与检测任意慢漂移；**TTL/周期复审不可省**。
(c) 若跨版本判例的自动权重为 w_old > 0，真实价值最优偏移 Δ_κ，
则对齐间隙 ≥ w_old·Δ_κ − ε_rejudge；令 w_old = 0（跨版本不自动沿用）可消除锁定项，
代价是更多人工裁决。
证明：(a) 标准序贯检验；(b) 构造恒定低于阈值的漂移序列；(c) 对加权判例的线性展开。证毕。
**系 55.1**：VDM 负责「快漂移」，TTL/周期复审负责「慢漂移」；二者缺一不可。
**系 55.2**：判例-政策分离不是保守，而是价值锁定下界为 0 的唯一方式。

**引理 56（8C 时序与预算保持）**
A 阶段硬门的同步开销 ≤ N_audit·c_eval；取 N_audit 使该开销 ≤ τ_A。
M 阶段（写入门、巩固、遗忘）全部异步，且写入门只做 O(k) 签名校验；
50Hz 路径不新增等待，只保留继承的 O(1) 回执验证与只读记忆路由。
若 τ_A 或 τ_ret 超预算 ⇒ 安全弃权（不修复），而不是跳过价值门。
因此第 2 轮引理 50 的硬实时与预算结论保持。

## 6. 本轮最大风险（一句话）

**一句话**：长期记忆会把一次局部的价值误判（或一条被投毒的判例）固化为跨会话的「制度性先验」，
而价值证书、判例检索与一致性叙事会把它包装成「经过审计的稳定价值」——系统越用越显得可信，
却可能在价值版本/部署域变化后仍沿用陈旧偏好，形成**价值锁定（value lock-in）**；
这是比「遗忘」更隐蔽、也更难通过单轮审计发现的失败模式。

**次级风险与缓解**：
1. **记忆投毒/溯源伪造** → 写入门 k-法定人数 + 签名 + 截尾均值 + 隔离记忆（定义 438/441）；
2. **价值锁定/过时判例** → κ 版本化 + 跨版本禁止自动沿用 + TTL + 周期复审（定义 442/445、引理 55）；
3. **代理解耦/reward hacking** → 独立价值盾 + 审计集隔离 + VDM + 反事实对照（定义 435/436、引理 51）；
4. **审计集泄漏/过拟合** → D_audit 与记忆物理隔离、时间外推留出、轮换（定义 436/445）；
5. **记忆负迁移** → RA-Cal gate + staleness 膨胀 + 冷启动回退（定义 440、引理 52）；
6. **巩固放大偏见** → 独立 provenance + 反例保留 + 禁止多数投票式巩固（定义 445、引理 53）；
7. **隐私/被遗忘权** → 记忆最小化 + TTL + 脱敏 + 硬约束；语义记忆不存可识别个体数据；
8. **退化绕过安全** → 价值地板 + 审计不可用即弃权（定义 443、引理 54）；
9. **人工裁决瓶颈/自动化偏见** → 只在不可估计/跨版本时升级；保留异议记录；监控人工 override 率；
10. **价值规范不完整** → VC 版本化且可争议；缺失值默认保守，触发弃权而非静默假设。

> 背景：第 2 轮 ToolGauge（IP-315–320）解决了「数据稀缺下盲区的发现与修复」，但留下两个治理缺口：
> **目标错置**（只优化 σ/覆盖，未定义「哪些修复可接受」）与 **跨会话失忆**（经验不积累、证书短命、记忆是新攻击面）。
> 本轮以「价值对齐 × 长期记忆」为灵感，在 ToolGauge 之上叠加 **V-Box（价值契约）** 与 **M-Box（长期记忆）**，
> 把 6C 扩为 **8C**，并把退化链从「能力优先」修正为「安全优先」。
>
> **集成链（修正第 2 轮记号方向）**：**MODGAUGE ⊂ LeanGauge ⊂ ToolGauge ⊂ StewardGauge**（模块/能力包含）；
> 退化方向相反：StewardGauge → ToolGauge+VC → LeanGauge+VC → MODGAUGE+monitor。
> IP 编号：IP-321–326（共 6 个）；定义增量 432–446；引理增量 51–56；实验增量 E441–E454。
> 理论姿态：五不变式全部保留，新增两条治理不变式（价值地板、记忆非干涉），不改变数值内核。

## 2. 形式化定义（要点）

**定义 432（价值契约 VC）** 硬约束 C_hard、结果属性 U、利益相关者权重 w 与 max-min 地板 u_min、司法域 S、价值版本 κ、有效期 T_V 的七元组。**VC 不是奖励函数**：硬约束不可被写成罚项，不可被权重交易。

**定义 433（价值泛函与对齐间隙）** V_w(π)=E[Σ_i w_i U_i]；Π_adm 为满足硬约束与利益相关者地板的策略集；Δ_V(π)=sup_{π'∈Π_adm} V_w(π')−V_w(π)。Π_adm 为空时必须弃权。

**定义 434（价值证据与 VCert）** 价值主张（安全/合规/公平）必须绑定三类证据：有效回执、预注册审计集检验、独立价值盾输出；否则序列化时剥离，A 阶段不得引用。推广第 2 轮定义 423 的主张-回执绑定。

**定义 435（独立价值盾与 A 阶段四门）** 硬门（UCB 违约概率 ≤ δ_hard，不可估计即弃权）、软门（Δ̂_V ≤ ε_V 的上置信界）、判例门（κ 相同且司法域兼容，否则转人工）、可逆门（已演练回滚且代价 ≤ B_rollback）。四门全过才允许热替换。

**定义 436（VDM 代理解耦监控）** 在 D_audit 上维护 (P_t,V_t)，估计秩相关 ρ_t；ρ_t<ρ_min 或连续 q 窗「V 降 P 升」⇒ 冻结修复、冻结 κ、按 provenance 回滚。D_audit 与长期记忆物理隔离，不可写入 M。

**定义 437（LTMM）** E 情节记忆（完整证据链）、S 语义记忆（跨情节模式/指纹/先验）、P 程序记忆（探测模板）、N 负记忆（失败/事故，衰减最慢）、Q 隔离记忆（不可检索）、G 溯源图（失效传播）。

**定义 438（MWG 写入门）** L0→L1→L2 晋升需：有效回执 + VCert + V 阶段通过 + 无未关闭事故 + κ/env_version 完整 + k 个独立法定人数 + tombstone/回滚路径；否则进 Q。**无回滚路径不写入**。

**定义 439（检索与信任）** score = sim·trust·compat·decay；返回 top-k 信任分布而非点值；记忆只输出先验/假设/程序模板，永不直接写 u_s/χ_R/M_ver；max trust<τ_m 或 compat=0 ⇒ 回退 AP-Cal。

**定义 440（RA-Cal）** q_θ(u_s|h,receipts,R)；训练含预测损失 + KL 物理锚 + 反事实一致性 + 记忆弃权正则；gate=0 严格退化为 AP-Cal；高斯收缩 û=(Σ_mem^{-1}+Σ_ctx^{-1})^{-1}(Σ_mem^{-1}μ_mem+Σ_ctx^{-1}μ_ctx)，staleness/poisoning 通过膨胀 Σ_mem 实现自动弃权。

**定义 441（投毒与稳健聚合）** 检索集 ≤ν 投毒、trim γ>ν 时偏差 ≤ B·ν/(1−2ν)+O(√(log(1/δ)/n))；k-法定人数把独立投毒率从 ν_0 降到 ν_0^k；巩固禁止多数投票。

**定义 442（价值版本与判例-政策分离）** 跨 κ 检索只能作为历史参考，必须重新裁决；司法域不兼容直接拒绝；判例只进入审议上下文，不构成许可。

**定义 443（价值地板）** S_3=StewardGauge ⊃ S_2=ToolGauge+VC ⊃ S_1=LeanGauge+VC ⊃ S_0=MODGAUGE+monitor；退化只移除能力、不移除 C_hard，Allowed(S_{i−1})⊆Allowed(S_i)；价值审计不可用 ⇒ Allowed=∅（不修复）。

**定义 444（记忆非干涉与可逆写入）** 记忆通道与数值通道分离；strip_M 后热替换子图数值变化 ≤ ε_num；每条写入带 tombstone 与 provenance 边，失效沿 G 传播且不依赖被撤销条目的派生值。

**定义 445（纵向审计与遗忘）** D_audit 时间外推留出且不可写入 M；h_N≫h_S；巩固需独立 provenance 且保留反例；超容量优先遗忘低 trust/低使用/旧版本条目，**永不遗忘负记忆中的硬约束事故**。

**定义 446（MB-Contract 与 8C 时序）** 8C = H→C→E→C→V→A→U→M；A 硬门同步、软门可采样；M 全异步；50Hz 路径只保留 O(1) 回执验证与无锁只读记忆路由；超预算 ⇒ 安全弃权。

## 3. 关键算法骨架

```python
# IP-321 V-Box：A 阶段四门
class VBox:
    def align(self, a, vc, audit, precedents, rollback):
        if not self.shield.violation_ucb(a, audit) <= vc.delta_hard:
            return "abstain"                      # 不可估计也弃权
        if self.alignment_gap_ub(a, vc, audit) > vc.eps_V:
            return "abstain"
        if any(p.kappa != vc.kappa or not jurisdiction_ok(p, vc)
               for p in precedents):
            return "escalate_human"               # 判例≠政策
        if not rollback.tested or rollback.cost > vc.B_rollback:
            return "abstain"
        return "aligned"

# IP-322 M-Box：检索 + 写入门
class MBox:
    def retrieve(self, s, env_version, kappa, k=8):
        cand = self.index.search(s, 4 * k)
        ok = [e for e in cand if compatible(e, env_version, kappa)
              and not e.tombstone]
        return sorted(ok, key=lambda e: score(e, s), reverse=True)[:k]

    def write_gate(self, ep, quorum=3):
        if not (valid_receipts(ep) and ep.vcert and ep.no_incident):
            self.quarantine.append(ep); return False
        if len(independent_votes(ep)) < quorum:
            self.quarantine.append(ep); return False
        if not ep.rollback_id:
            self.quarantine.append(ep); return False
        self.L1.append(ep); self.provenance.add(ep); return True

# IP-323 RA-Cal：记忆条件化，gate=0 严格退化为 AP-Cal
class RACal(APCal):
    def calibrate(self, receipts, H, s, memory):
        R = memory.retrieve(s, self.env.version, self.vc.kappa)
        g = self.gate(featurize(receipts, H, s, R))
        if g < self.g_min or not R:
            return super().calibrate(receipts, H, s)
        mu_m, Sig_m = self.semantic_prior(R)       # 稳健聚合 + staleness 膨胀
        mu_c, Sig_c = super().calibrate(receipts, H, s)
        Sig = inv(inv(Sig_m) + inv(Sig_c))
        mu = Sig @ (inv(Sig_m) @ mu_m + inv(Sig_c) @ mu_c)
        return mu, clamp_min(Sig, KAPPA_PHYS)

# IP-325 8C：6C + A + M；IP-326 主闭环：安全优先退化
def steward_8c(M, s):
    H = M.lbox.hypothesize(s, M.dbox.R[s])                     # H
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s))   # C
    receipts = M.tcv.execute(prog, M.env)                       # E
    if len(receipts) < n_min(s): return stub_and_red(s, "insufficient")
    mu, Sig = M.racal.calibrate(receipts, H, s, M.mbox)         # C
    if not cross_validate(mu, Sig, M.cross_receipt(s)):         # V
        mu, Sig = M.racal.calibrate(receipts, ["UNKNOWN"], s, M.mbox)
        if not cross_validate(mu, Sig, M.cross_receipt(s)):
            return stub_and_red(s, "cross_failed")
    vcert = M.vbox.build_cert(s, mu, Sig, receipts, M.audit)    # A 证据
    verdict = M.vbox.align(s, M.vc, M.audit,
                           M.mbox.precedents(s), M.rollback)
    if verdict != "aligned":
        return abstain_or_escalate(s, verdict)                  # 安全弃权
    new_ec = M.racal.update_contract(M.dpe, mu, Sig, s)
    if not contract_regression(new_ec): return stub_and_red(s, "regression")
    rid = M.mreg.hot_replace(M.dpe, new_ec)                     # U，可回滚
    M.dbox.update_from_posterior(s, mu, Sig)
    bind_claims(new_ec, H, prog, receipts, vcert)               # 价值主张绑定
    ep = M.make_episode(s, H, prog, receipts, vcert, rid)
    M.mbox.write_gate(ep, quorum=3)                             # M（异步）
    M.vdm.record(proxy_gain(receipts), audit_value(s), vcert)
    return True

def StewardGauge_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s); submit_async(steward_8c, M, s)
    if M.vdm.triggered():
        M.freeze_repairs(); M.rollback_since(M.vdm.window_start)
        M.queue_human("proxy_value_decoupling")
    if M.mbox.untrusted() or M.mbox.unavailable():
        M.racal.use_memory = False             # ToolGauge+VC，硬约束不丢
    if M.vbox.audit_unavailable():
        M.freeze_repairs()                     # S_0 安全态：只监控
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 51（代理-价值遗憾界）** 在 D_audit 上，若 (A1) |V(a)−V(a′)| ≤ ρ^{-1}|P(a)−P(a′)| + b；(A2) P(â) ≥ sup P − η_P；(A3) 审计误差 ≤ ε。则 Δ_V(â) ≤ ρ^{-1}(η_P+2ε_P)+b+2ε_V^audit。ρ→0 时界发散，故 VDM 监控 ρ_t 就是在监控这个界的分母。

**引理 52（记忆条件化偏差-方差界）** 设 ‖u*−μ_ctx‖ ≤ B_s，收缩估计 û 满足 E‖û−u*‖² ≤ B_s² + tr((Σ_mem^{-1}+Σ_ctx^{-1})^{-1}) ≤ B_s² + min(tr Σ_mem, tr Σ_ctx)。
- 同环境 B_s=0：记忆是纯方差缩减，m 条有效记忆把方差从 tr Σ_ctx 降到 O(σ²/(m+N_bl))；
- 跨环境 B_s ≥ √(tr Σ_ctx)：冷启动严格更优，RA-Cal 的 gate 必须把记忆权重压到 0。
这是「记忆买样本效率」与「记忆负迁移」的同一个界的两侧。

**引理 53（投毒稳健界）** ≤ν 投毒、trim γ>ν 时 |μ̂−μ| ≤ B·ν/(1−2ν)+O(σ√(log(1/δ)/n))；k-法定人数把独立投毒率降到 ν_0^k；巩固若做多数投票，k 条同源投毒会被「巩固」成高信任语义记忆，故必须保留独立 provenance 与反例。

**引理 54（非干涉与价值地板）** (a) 若 M-Box 只输出先验/假设/程序/信任，且 RA-Cal 在 gate=0 时严格等于 AP-Cal，则 strip_M(StewardGauge) 与 ToolGauge 在热替换子图上数值等价（≤ ε_num），第 2 轮引理 49 推广到记忆层。(b) 若退化只移除能力且 Allowed(S_{i−1})=Allowed(S_i)∩C_hard，则允许动作集单调不增、硬约束违反概率不增；A 阶段不可用时 Allowed=∅ 是最小元。

**引理 55（漂移可检测性与价值锁定下界）** (a) 每会话漂移 ≥δ 时，CUSUM/e-test 在 O((σ²/δ²)log(1/α)) 会话内检测，误报 ≤α。(b) 存在 δ_t=δ_min/2 的慢漂移，使检验在 T 会话内始终低于阈值，而累计损失 Ω(Tδ_min)——任何有限样本检验都无法同时保证低误报与检测任意慢漂移，故 TTL/周期复审不可省。(c) 跨版本判例自动权重 w_old>0 时，对齐间隙 ≥ w_old·Δ_κ−ε_rejudge；令 w_old=0 可消除锁定项，代价是更多人工裁决。

**引理 56（8C 时序与预算）** A 硬门同步开销 ≤ N_audit·c_eval ≤ τ_A；M 阶段全异步且写入门只做 O(k) 签名校验；50Hz 路径不新增等待；超预算 ⇒ 安全弃权而非跳过价值门。第 2 轮引理 50 保持。

### 6.1 解析玩具例（可手算的预注册 sanity check，非实验测量）

取一维高斯、Σ_ctx=1（当前回执）、Σ_mem=4（较弱的记忆先验）、B_s=0（同环境）：
- 冷启动 MSE = 1；
- 记忆收缩后验方差 = (1/4 + 1/1)^{-1} = 0.8，MSE 降低 20%；
- 若记忆等价于 m=4 条同环境样本（Σ_mem=0.25），后验方差 = (4+1)^{-1} = 0.2，MSE 降低 80%；
- 跨环境令 B_s=0.5、Σ_mem=0.25：MSE 上界 = 0.25+0.2 = 0.45 < 1，记忆仍有益；
- 令 B_s=1.0：MSE 上界 = 1.0+0.2 = 1.2 > 1，冷启动更优；阈值 B_s < √(0.8) ≈ 0.894。
这个玩具例给出 RA-Cal gate 的解析校准点：**记忆只有在 staleness 偏差小于当前后验标准差量级时才应被采用**。

## 8. 本轮最大风险

**一句话**：长期记忆会把一次局部的价值误判（或一条被投毒的判例）固化为跨会话的「制度性先验」，
而价值证书、判例检索与一致性叙事会把它包装成「经过审计的稳定价值」——系统越用越显得可信，
却可能在价值版本/部署域变化后仍沿用陈旧偏好，形成**价值锁定（value lock-in）**；
这是比「遗忘」更隐蔽、也更难通过单轮审计发现的失败模式。

**三重兜底**：独立价值盾 + VDM（快漂移）/ TTL 与周期复审（慢漂移），
以及 κ 版本化下的判例-政策分离（引理 55：跨版本不自动沿用是价值锁定项为 0 的唯一方式）。
