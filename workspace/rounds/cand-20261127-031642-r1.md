# 第 1 轮 · 灵感碰撞：灵巧手 × 数字孪生

## 0. 直觉先行

灵巧手是「接触的艺术」：20+ 自由度、多指协同、力闭合、滑动与指尖形变。它的危险不在于「看不见」，而在于「看得见却抓不稳」——既有证书体系擅长回答「路径是否撞到障碍」（ACSC/几何），却回答不了「这个抓取在真实摩擦、接触位置误差、软指尖形变下是否仍然稳定」。

数字孪生是「可反复预演的影子世界」：它让我们在执行前把计划在虚拟物理里跑一千遍。但它有一个致命诱惑——影子越像，我们越容易相信它；而影子与真身的偏差（sim-to-real gap）恰恰在接触瞬态、软体、摩擦突变处最大。

把两者放在一起，得到一个自然又危险的念头：**让数字孪生为灵巧手抓取签发证书**。问题不在于「能不能签」，而在于「这张证书的效力边界在哪里」。

## 1. 核心命题

> 证书不应由孪生直接签发，而应由「孪生的预测」与「孪生自身有效性的证书」共同签发。

任何来自孪生的安全断言，都必须携带一个可机械复核的**孪生有效性证书（Twin Validity Certificate）**，它给出当前分布下 sim-to-real 偏差的有限样本上界 δ_α。只有当 `孪生预测的安全裕度 − L·δ_α ≥ 要求裕度` 时，断言才成立。这样，孪生的乐观偏差被显式计入安全预算，而不是被默认忽略。

一句话概括本轮方法论：**把影子当成一个需要自带体检报告的证人，而不是一个权威。**

## 2. 关键概念（直觉 → 定义）

- **接触裕度 m_fc**：直觉是「还能承受多大的外部扰动」。定义：力闭合 ε-裕度，即最大 ε，使任意 ‖w_ext‖≤ε 都能由摩擦锥内接触力平衡。
- **接触不确定半径 ρ**：直觉是「指尖到底在哪、法向到底朝哪」。定义：由触觉/视觉校准集经 conformal 得到的接触位置与法向误差分位数。
- **孪生偏差 g**：直觉是「影子与真身差多远」。定义：单回合最大状态偏差 g_i = max_t d(z_t, ẑ_t)。
- **δ_α**：conformal 偏差分位数，覆盖 P(g_new ≤ δ_α) ≥ 1-α（前提：校准与部署回合可交换）。
- **Lipschitz 裕度迁移**：直觉是「状态差一点，裕度也差一点，差多少由 L 决定」。定义：若 m 关于状态 L-Lipschitz，则 m(z_real) ≥ m(ẑ) − L·δ。
- **TwinValid**：孪生有效性谓词——δ_α 有限、偏差看门狗未报警、校准集与当前分布未漂移。
- **空泛率（Vacuousness Rate）**：直觉是「证书因为偏差预算吃掉全部裕度而根本发不出来」。定义：在候选计划集中，满足 `L·δ_α ≥ m̂_min` 的比例。它是接触非光滑性对证书实用性的直接度量。

## 3. 三个可能的研究问题

1. **接触瞬态下 L 是否有限？** 若否，能否用「分段 Lipschitz + 接触模式切换证书」把无界问题化为有限个有界子问题（每种接触模式单独给 L）？
2. **可交换性在「同一台手、同一类物体、不同表面」之间成立吗？** 能否用分层 conformal（按物体/表面/速度分层）恢复条件覆盖，避免全局分位数被少数模式绑架？
3. **孪生作为共识中的一个「虚拟投票者」，会不会与真实投票者强相关，从而虚增共识？** 如何度量并扣除这种相关性（有效样本量 N_eff），防止「影子附和真身」被误判为独立共识？

## 4. 本轮落点

把上述直觉落成 IP-440–445 六个模块，核心是 **TGSC（孪生接地安全证书）** 与 **TGEG（HPC-E++ 五证门）**，并证明 `Exec_v24 ⊆ Exec_v23` 的单调退化链。本轮不追求解决接触非光滑性，而是把它标成最大风险，并给出「空泛率」这一可测量指标来量化它。延续性上，v22 的 IP-434 里 RGC（reality gap certificate）一直只是占位符，本轮用 DTRC 把它具体化、孪生接地化。

## 5. 与既有体系的接口

- 复用 `HPC-E+` 的几何/规范/能量/差距四证作为底座，新增接触与孪生两层，构成五证门。
- 复用 `CESC` 的版本原子切换思想：孪生模型本身也带版本五元组，孪生失效等价于「孪生离线模式」，退化为纯实机证书（Exec_v23）。
- 复用 `FSVC` 的 conformal 覆盖纪律：δ_α 的有限样本保证与 FSVC 同源，避免两套统计口径打架。
- 与 `CFC+++` 的接口：孪生投票者必须带 provenance 标签，参与去相关降权。

```python
# ============================================================
# IP-440 Hand Contact Certificate (HCC) — 灵巧手接触证书
# ============================================================
class HandContactCertificate:
    def __init__(self, mu: float, alpha: float, m_req: float,
                 k_cone: int = 8):
        self.mu = mu                 # 摩擦系数
        self.alpha = alpha           # 接触不确定 conformal 尾部
        self.m_req = m_req           # 要求的最小力闭合裕度
        self.k_cone = k_cone
        self.rho = float("inf")      # 接触不确定半径，校准前不可用

    def calibrate_contact_uncertainty(self, paired_contacts):
        """paired_contacts: [(p_hat, n_hat, p_gt, n_gt)] 触觉/视觉配对"""
        errs = [max(norm(p_hat - p_gt), ang(n_hat, n_gt))
                for p_hat, n_hat, p_gt, n_gt in paired_contacts]
        self.rho = conformal_quantile(errs, self.alpha)  # 见引理 5

    def _grasp_map(self, q, contacts):
        # 每个接触点构造 6x3 扳手贡献，拼成 G
        return torch.cat([self._wrench_basis(q, p, n) for p, n, _ in contacts], dim=1)

    def epsilon_margin(self, q, contacts):
        """线性规划求力闭合 ε-裕度（摩擦锥线性化后）"""
        G = self._grasp_map(q, contacts)
        # maximize eps s.t. 单位扳手球内任一 w 均可由 FC 内 f 平衡
        return self._lp_epsilon(G, self.mu, self.k_cone)

    def robust_margin(self, q, contacts):
        """接触位置/法向不确定球下的鲁棒裕度（Lipschitz 下界）"""
        return self.epsilon_margin(q, contacts) - self.L_C * self.rho

    def certifies(self, q, contacts):
        if not math.isfinite(self.rho):
            return False, "contact_uncertainty_uncalibrated"
        m = self.robust_margin(q, contacts)
        return (m >= self.m_req), {"robust_margin": m, "rho": self.rho}

# IP-441 Digital Twin Reconciliation Certificate (DTRC)
# ============================================================
class DigitalTwinReconciliationCertificate:
    def __init__(self, alpha_gap: float = 0.01, delta_max: float = 0.05,
                 window: int = 200, min_calib: int = 30):
        self.alpha = alpha_gap
        self.delta_max = delta_max      # 超过则孪生不可用于发证
        self.window = window
        self.min_calib = min_calib
        self.gaps = deque(maxlen=window)   # 成对回合偏差 g_i
        self.delta_alpha = float("inf")
        self.valid = False
        self._baseline_quantiles = None    # 漂移检验基线

    def calibrate(self, paired_episodes):
        """paired_episodes: [(traj_real, traj_twin)]，要求与部署可交换"""
        for traj_real, traj_twin in paired_episodes:
            self.gaps.append(max_state_dist(traj_real, traj_twin))
        self._recompute()
        self._baseline_quantiles = self._quantile_snapshot()

    def _recompute(self):
        n = len(self.gaps)
        if n < self.min_calib:
            self.delta_alpha, self.valid = float("inf"), False
            return
        ordered = sorted(self.gaps)
        # conformal 分位：第 ceil((n+1)(1-alpha)) 小
        k = min(math.ceil((n + 1) * (1 - self.alpha)), n)
        self.delta_alpha = ordered[k - 1]
        self.valid = self.delta_alpha <= self.delta_max

    def observe(self, z_real, z_twin):
        """在线对账：每个控制周期调用，喂入偏差看门狗"""
        g = state_dist(z_real, z_twin)
        self.gaps.append(g)
        self._recompute()
        if not self._drift_test():
            self.valid = False
        return g <= self.delta_alpha

    def _drift_test(self):
        """分位数漂移检验：当前窗口高分量显著高于校准基线则判漂移"""
        if self._baseline_quantiles is None or len(self.gaps) < self.min_calib:
            return True
        q_now = self._quantile_snapshot()
        return all(now <= base * 1.5 + 1e-6
                   for now, base in zip(q_now, self._baseline_quantiles))

    def _quantile_snapshot(self):
        xs = sorted(self.gaps)
        n = len(xs)
        return [xs[min(int(p * (n - 1)), n - 1)] for p in (0.5, 0.9, 0.99)]

    def twin_valid(self) -> bool:
        return self.valid and math.isfinite(self.delta_alpha)

    def invalidate(self, reason: str):
        self.valid = False
        self.last_invalidation = reason

# IP-442 Twin-Grounded Safety Certificate (TGSC)
# ============================================================
class TwinGroundedSafetyCertificate:
    def __init__(self, dtrc: DigitalTwinReconciliationCertificate,
                 L_m: float, m_req: float, p_req: float,
                 alpha_gap: float = 0.01, beta: float = 0.05,
                 M: int = 200):
        self.dtrc = dtrc
        self.L_m = L_m
        self.m_req = m_req
        self.p_req = p_req
        self.alpha_gap = alpha_gap
        self.beta = beta
        self.M = M

    def certify(self, plan, twin) -> tuple[bool, dict]:
        if not self.dtrc.twin_valid():
            return False, {"reason": "twin_invalid"}
        if not math.isfinite(self.L_m):
            # 接触瞬态下 L_m 无界 → 证书空泛，拒绝而非假装安全
            return False, {"reason": "non_lipschitz_contact", "vacuous": True}

        margins = twin.rollout_margins(plan, self.M)   # 孪生蒙特卡洛
        m_hat_min = min(margins)

        # (A) Lipschitz 裕度迁移：把孪生偏差计入安全预算
        robust_margin = m_hat_min - self.L_m * self.dtrc.delta_alpha
        if robust_margin < self.m_req:
            return False, {"reason": "margin_eaten_by_gap",
                           "robust_margin": robust_margin,
                           "gap_budget": self.L_m * self.dtrc.delta_alpha}

        # (B) 失败概率联合界：P(real fail) ≤ alpha_gap + p_U
        F = sum(1 for m in margins if m < self.m_req)
        p_U = clopper_pearson_upper(F, self.M, self.beta)
        if self.alpha_gap + p_U > self.p_req:
            return False, {"reason": "failure_budget_exceeded",
                           "p_U": p_U, "alpha_gap": self.alpha_gap}

        return True, {"robust_margin": robust_margin,
                      "delta_alpha": self.dtrc.delta_alpha,
                      "p_U": p_U, "F": F}

# IP-443 Hand Configuration Space Certificate (HCSC)
# ============================================================
class HandConfigurationSpaceCertificate:
    def __init__(self, synergy_basis, n_synergy: int = 4,
                 eps_arm: float = 0.01):
        self.B = synergy_basis          # q ≈ B·σ + q0，σ∈R^{n_synergy}
        self.n_synergy = n_synergy
        self.eps = eps_arm
        self.obstacles = []             # 指侧障碍（含物体）

    def project(self, q):
        """把手配空间投影到低维协同子空间，降低证书维度灾难"""
        sigma = torch.linalg.lstsq(self.B, q - self.q0).solution
        return sigma

    def forward_kinematics_box(self, sigma):
        """协同子空间下的指尖/指节包围盒（含 eps 膨胀）"""
        q = self.B @ sigma + self.q0
        return self._link_boxes(q).inflate(self.eps)

    def certifies(self, sigma, contact_manifold):
        """配空间证书：协同轨迹避障 ∧ 接触流形约束满足"""
        boxes = self.forward_kinematics_box(sigma)
        clear = all(not box.intersects(o) for box in boxes for o in self.obstacles)
        on_manifold = contact_manifold.contains(boxes)
        return clear and on_manifold, {"clear": clear, "on_manifold": on_manifold}

@dataclass
class HPCEPlusPlus:
    hpc_e_plus: "HPCEPlus"          # v23 四证门
    hcc: HandContactCertificate
    hcsc: HandConfigurationSpaceCertificate
    dtrc: DigitalTwinReconciliationCertificate
    tgsc: TwinGroundedSafetyCertificate

    def admits(self, plan, ctx, modules) -> tuple[bool, dict]:
        # 1. v23 基础四证（几何∧规范∧能量∧差距∧云边∧少样本∧IP）
        if not self.hpc_e_plus.admits(plan, ctx.x, ctx.v, ctx.z,
                                      ctx.E_res, ctx.margin_req, modules):
            return False, {"reason": "hpc_e_plus"}

        # 2. 灵巧手接触证书
        ok, info = self.hcc.certifies(ctx.q, ctx.contacts)
        if not ok:
            return False, {"reason": "hand_contact", **info}

        # 3. 手配空间证书（协同子空间 + 接触流形）
        ok, info = self.hcsc.certifies(ctx.sigma, ctx.contact_manifold)
        if not ok:
            return False, {"reason": "hand_config_space", **info}

        # 4. 孪生对账 + 孪生接地安全证书
        if not self.dtrc.twin_valid():
            return False, {"reason": "twin_invalid"}
        ok, info = self.tgsc.certify(plan, ctx.twin)
        if not ok:
            return False, {"reason": "tgsc", **info}

        return True, {"robust_margin": info.get("robust_margin")}

# IP-445 Twin-Consensus with Provenance (CFC++++)
# ============================================================
class TwinConsensusWithProvenance(CertificateFederatedConsensusPlusPlusHierarchical):
    """在 CFC+++ 上加入孪生投票者，并按 provenance 去相关降权。"""

    def effective_sample_size(self, votes):
        # 按 (模型族, 传感器族) 聚类；同簇共享 1 票，避免影子附和真身
        clusters = defaultdict(int)
        for v in votes.values():
            clusters[(v.model_family, v.sensor_family)] += 1
        return sum(1.0 / n for n in clusters.values())

    def consensus_round(self, timeout=5.0):
        results = {}
        for key, votes in self.votes.items():
            n_eff = self.effective_sample_size(votes)
            count_ok = n_eff >= (self.N - self.F)
            modalities = {v.modality for v in votes.values()}
            modality_ok = len(modalities) >= self.M_MIN_MODALITIES
            layer_ok = self._check_layer_consistency(votes)
            twin_ok = all(v.twin_valid for v in votes.values() if v.is_twin_voter)
            # 孪生投票者不得单独凑数：至少 2 个真实独立簇
            real_clusters = len({(v.model_family, v.sensor_family)
                                 for v in votes.values() if not v.is_twin_voter})
            provenance_ok = real_clusters >= 2

            if all([count_ok, modality_ok, layer_ok, twin_ok, provenance_ok]):
                results[key] = self._majority_with_outlier_filter(votes)
            else:
                results[key] = "CI"
        return results

        if admitted:
            ctx.execute(ctx.plan)
        # 3. 在线对账：无论是否执行都更新偏差看门狗
        self.dtrc.observe(ctx.z_real, ctx.z_twin)
        return admitted, {**info, "delta_alpha": self.dtrc.delta_alpha,
                          "twin_valid": self.dtrc.twin_valid()}
```

## 2. 复杂度分析

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| HCC 力闭合 LP | O((k_cone·k)^3) / 抓取 | O(k_cone·k) | k≤5 指，k_cone=8 |
| HCC 鲁棒裕度 | O(1)（在 LP 解上减 L_C·ρ） | O(1) | ρ 由校准缓存 |
| DTRC 校准/在线更新 | O(n log n) 排序 / O(window) | O(window) | window=200 |
| DTRC 漂移检验 | O(window) / 周期 | O(1) | 3 个分位点 |
| TGSC 认证 | O(M·T·c_sim) 离线 | O(M·T) | M=200, T=回合步数 |
| HCSC 投影 + 包围盒 | O(n_h·n_synergy + |links|·|obs|) | O(n_synergy) | n_synergy=4 |
| TGEG 在线关键路径 | O(1)（读缓存 δ_α + TwinValid） | O(1) | 控制环 50Hz |
| CFC++++ 去相关 | O(N log N) 聚类 | O(N) | N=投票者数 |

**实时性保证**：孪生蒙特卡洛（TGSC）与 HCC 的 LP 都在离线/异步阶段完成，结果缓存为证书；控制环内只做 O(1) 的 `TwinValid` 读取、偏差对账和阈值比较，满足 50Hz（<20ms）。

## 3. 正确性论证

### 引理 5（接触不确定下的鲁棒力闭合）
**陈述**：若 `m_fc(q,C) − L_C·ρ ≥ m_req`，则对任意接触扰动 ΔC 满足 ‖ΔC‖ ≤ ρ，仍有 `m_fc(q,C+ΔC) ≥ m_req`。

**证明**：由 m_fc 关于接触位置 L_C-Lipschitz，`|m_fc(C+ΔC) − m_fc(C)| ≤ L_C‖ΔC‖ ≤ L_C·ρ`，故 `m_fc(C+ΔC) ≥ m_fc(C) − L_C·ρ ≥ m_req`。∎

### 引理 6（Lipschitz 裕度迁移）
**陈述**：若安全裕度函数 m 关于状态 z 是 L_m-Lipschitz，且真实与孪生状态满足 `d(z_real, ẑ) ≤ δ`，则 `m(z_real) ≥ m(ẑ) − L_m·δ`。

**证明**：由 Lipschitz 定义 `|m(z_real) − m(ẑ)| ≤ L_m·d(z_real,ẑ) ≤ L_m·δ`，移项即得。∎

### 引理 7（孪生偏差的有限样本覆盖）
**陈述**：若校准回合与部署回合可交换，则 `P(g_new ≤ δ_α) ≥ 1−α`，其中 δ_α 为 conformal 分位。

**证明**：标准 split-conformal 结果（Vovk et al. 2005）；`g_1..g_n, g_new` 可交换 ⇒ 秩均匀 ⇒ 分位覆盖成立。∎

### 引理 8（真实失败概率的联合界）
**陈述**：在引理 6、7 下，`P(real fail) ≤ α_gap + p_U`。

**证明**：失败仅可能来自 (i) 偏差超界 `g > δ_α`（概率 ≤ α_gap），或 (ii) 偏差在界内但孪生本身失败。后者在引理 6 下意味着 `m̂ < m_req`，其概率由 M 次独立回合的 Clopper–Pearson 上界 `p_U` 控制。由联合界相加得证。∎

### 引理 9（孪生失效的单调退化）
**陈述**：若 `TwinValid = false`（看门狗报警/漂移/δ_α 超上限），则 `Exec_v24` 退化为 `Exec_v23`，且 `Exec_v24 ⊆ Exec_v23` 恒成立。

**证明**：TGEG 的 admit 在 `TwinValid=false` 时直接拒绝所有依赖孪生的计划，执行集回到不含孪生层的 v23；所有 v24 计划都额外通过 HCC/TGSC 连言，故必为 v23 的子集。∎

### 定理（TGEG 五证门的可靠性与保守性）
**陈述**：`HPCEPlusPlus.admits(π)=True` ⟹ 在置信 1−α_gap−β 下，π 在真实世界的失败概率 ≤ p_req，且接触力闭合、手配空间、云边/少样本/IP 约束均满足；反之任一条件缺失即拒证。

**证明**：可靠性由引理 5–8 逐条合成：HCC 给接触鲁棒裕度，TGSC 给真实失败上界，v23 四证给其余约束。保守性由各 `certify` 的连言结构直接可得（拒绝是安全的默认）。∎

### 命题 10（空泛率是接触非光滑性的可测代价）
**陈述**：`VR = Pr[L_m·δ_α ≥ m̂_min]`；当接触瞬态使 `L_m → ∞` 时 `VR → 1`，证书退化为恒拒绝。

**证明**：由 TGSC 的条件 (A)，偏差预算 `L_m·δ_α` 单调吞掉裕度；L_m 无界则对任意正裕度预算超限，认证必失败。∎

## 6. 本轮最大风险（最终确认）

**一句话**：灵巧手的接触瞬态让安全裕度函数既不光滑（L_m 爆炸使 `L_m·δ_α` 吞掉全部裕度、证书空泛）又破坏校准/部署可交换性（δ_α 覆盖失效），于是「孪生接地证书」在最需要它的接触富集区恰恰最不可靠——**数字孪生在接触瞬态处既不可微也不可交换，导致证书要么空泛、要么失效**。
