# 第 66 轮（承接第 65 轮「VISTA 视觉知情故障归因闭环」IP-214~223；灵感循环第 2 轮；本轮灵感：「评测指标」×「可重构机构」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述最大风险仍然成立：**归因依赖「故障属于有限假设集、视觉与几何失效相互独立」；未知复合故障会让 FIR 把错因塞进最近假设、只膨胀错误的球，而系统因「已经归因」更自信地继续执行。** 但我想先追问一个比归因更靠前、也更少被检查的问题：VISTA 用**自己定义的**故障假设集、**自己标定的**似然、**自己选择的**阶段去证明「归因正确」，再用「违规 = 0」证明「安全」——这是一条自证链。与此同时，从 GRIP 到 VISTA，所有证书都默默假设「机器人是同一台、标定不变、形态固定」。可重构机构把这个默认直接掀翻：证书不是常量，而是**形态的函数**。于是本轮的核心命题是：
>
> **把「证书」升级为「以形态为索引、以外部评测为证据、可迁移或必须重认证的承诺」；并把可重构机构从「执行器」同时升级为「实验装置」与「安全修复手段」。**

## 0. 直觉与动机

### 灵感 1（评测指标 → 证书不是真值，只是一个受功效约束的测量）

直觉：我们常说「100 次实验 0 违规，所以安全」。但统计上，100 次零失败只能以 95% 置信说失败率 **≲3%**（零失败规则 n ≥ ln(1/δ)/p）；要证明 0.1% 需要约 3000 次。也就是说，此前 E 表里大量「违规 = 0」并不是「风险 = 0」，而是「试验次数还不够看见它」。更麻烦的是 Goodhart：当指标被写进优化目标，系统会找到让指标好看但不让任务变好的行为。VISTA 的「归因准确率」尤其危险——它的故障假设集、似然与阶段切分都来自同一套模型，**用模型评价模型**，高分可能只证明模型自洽。

严格地说，评测是一个测量仪器，需要三件事：**构造效度**（指标是否真的测量了我们关心的因果量）、**统计功效**（在给定样本量下能分辨多大的效应）、**不可被被评者改写**（评测契约必须先于部署冻结）。所以本轮第一条设计原则是：**评测契约外置、只读、带功效；证书必须报告「我们凭什么相信」，而不是只报告「通过」。**

### 灵感 2（可重构机构 → 被控对象是变量，证书是形态的函数）

直觉：固定形态的机器人，证书可以是一次性的；可重构机器人换了工具、锁了关节、改了连杆长度或刚度之后，运动学、惯量、接触几何、传感器外参、学习模型的支持域全都变了。拿旧证书直接执行，等于用上一台机器的体检报告给这一台机器开刀。反过来，形态变化也给了一个**已知结构的物理干预**：换对称模块，结果应当镜像；连杆缩放 λ，可达域与惯量应按已知规律变化；锁一个关节，可达集应当收缩。**这些「应当」就是无需标签的变形关系（metamorphic relations）。**

但必须诚实：重构本身是新的单点故障。过渡过程可能自碰撞、掉载、标定跳变、电缆牵扯；而且形态会同时影响几何与视觉，直接打破 VISTA 的「共因独立」假设（A88）。所以可重构机构既是威胁，也是资源：**威胁在于证书失效与瞬态风险，资源在于它是机器人唯一能对自己做的随机对照实验。**

### 灵感 3（合流 → 可重构机构是机器人唯一能对自己做的随机对照实验）

直觉：一台固定机器人无法随机化自己的「身体」，所以它的评测永远是观察性的：成功率高，可能只是因为任务简单、配置恰好合适，无法回答「换一种形态会不会更好/更安全」。可重构机器人可以对自己的形态做**配对/随机干预**：同一任务、同一批种子，在随机化的若干配置下重复，估计形态对风险/能力的**因果效应**，而不是被配置选择偏差污染的观测相关。这是本轮真正的「新东西」——**用换形态来检验评测本身**，而不只是换一个末端执行器。

### 灵感 4（合流 → METAMORPH：指标治理的形态迁移评估与认证）

闭环：形态状态模型 MSM 给出 c 与形态映射 M(c) → 评测契约 EC 冻结「测什么、怎么测、要多少样本、什么算改进」 → 分层保形风险控制 SCRC 给出**逐配置**而非边际的覆盖 → 变形关系 MET 做无标签的「体检」并捕捉未知复合故障 → 主动评测分配 AEA 把有限试验预算花在最不确定的声明上 → 重构即修复 RAR 把形态当作安全动作 → 重构过渡证书 RTC 保证「换的过程中也安全」 → 配置索引证书 J_meta 把「证书对哪台机器有效、凭什么有效」写清楚 → 抗 Goodhart 审计 AIC-M 检查指标改进能否在独立因果终点上复现。

一句话：**VISTA 负责「机器觉得自己哪里坏了」，METAMORPH 负责「外部凭什么相信这台机器、这个形态、这次评测」。**

### 灵感 5（与 VISTA 的关系：不是替代，是给它一个外部参照系）

- **FIR → 保留，但不再独自承担未知故障**：MET 的变形关系违反是一个**无标签、不依赖有限假设集**的「有问题」检测器；它只回答「系统不自洽」，不强行回答「谁坏了」。二者组合成「内省 + 体检」。
- **CSC → 保留，但证书要加形态索引**：J_vista 的结论只对它被验证时的 c 有效；跨形态必须走迁移上界或重认证。
- **AFA → AEA**：探针目标从「降低故障假设熵」升级为「降低**声明有效性**的熵」；试验预算同时受安全与统计功效约束。
- **RSC-V → 不再只是膨胀球**：RAR 允许「换一个能安全完成任务的形态」，而不是在错误形态上无限保守化。
- **AIC-V → AIC-M**：对抗集加入「评测对手」——指标游戏、基准泄漏、配置选择偏差、分布漂移与重构瞬态。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（METAMORPH 闭环）**：METAMORPH=(VISTA, MSM, EC, EEC, SCRC, MET, AEA, RAR, RTC, AIC-M, J_meta)。定位：VISTA 的「形态索引 + 外部评测」层。不变式：**评测契约、等价类定义、变形关系库版本化且对在线策略只读；统计评测、迁移判定、重认证、审计只在语义流；实时流只做形态状态读取、RTC 看门狗、J_meta 查表与执行，零学习写操作。**
- **定义 234（形态状态与形态映射 MSM）**：c=(G,q,θ_s)∈C，G 为模块图（节点/端口/连接），q 为连续参数（连杆长度、关节限位、刚度、减速比），θ_s 为传感/驱动标定；形态映射 M(c) 给出运动学、惯量/摩擦/刚度、传感器外参、可达集与力限。形态度量 d_C(c,c')=w_G·d_edit(G,G')+w_q‖q−q'‖_{Σ_q}+w_s·drift(θ_s,θ_s')。重构算子 ρ:c→c'，带时间成本与瞬态风险。
- **定义 235（配置索引风险与能力）**：任务分布 D_c；风险 R(c)=P_{(x,ξ)~D_c}[unsafe∨fail]，能力 Cap(c)=E[score]。声明（claim）是「在形态类上 R(c)≤ε_risk 且 Cap(c)≥ε_cap」的命题。**证书是声明的证据包，不是声明本身。**
- **定义 236（评测契约 EC）**：EC=(e,m,S,α,β,n_min,strata,causal_endpoint,audit,hash,ver)，其中 e 为因果估计量（如形态对风险的配对 ATE），m 为 proper scoring rule，S 为采样/盲化/顺序协议，α 为风险水平，β 为功效，n_min 由功效分析给出，strata 为 EEC 单元，causal_endpoint 为未参与策略选择的独立终点。EC 在部署前冻结、哈希钉住、仅可追加修订且修订要求重认证；在线策略只读。
- **定义 237（评测等价类 EEC 与迁移包络 T）**：精确 EEC：c~c' 当且仅当 (i) 存在对称群元 g 使 M_kin(c')=g·M_kin(c) 且任务/障碍在 g 下不变；(ii) c' 的力/速/惯量包络包含于 c；(iii) 标定漂移 ≤q_cal(α)；(iv) 学习模型支持域的漂移统计量 ≤q_shift(α)。近似情形定义**认证迁移包络** T(c0)={c: R̂(c0)+q(α)+L̂·d_C(c0,c)≤ε_risk，且能力侧同理}。EEC 用于无标签变形测试；T 用于带界迁移；EEC⊆T 在 Lipschitz 与标定假设下成立。
- **定义 238（Lipschitz 迁移上界）**：设 R 在 C 上对 d_C 为 L-Lipschitz，L̂ 为其置信上界；在已验证 c0 上有保形上界 R̂(c0)+q(α)。则对任意 c：R(c)≤R̂(c0)+q(α)+L̂·d_C(c0,c)。右侧 ≤ε_risk 才允许迁移，否则必须重认证。L̂ 由配对形态实验估计；若存在未建模的重构不连续点（自碰撞、标定跳变），不等式失效，必须走 RTC 或重认证。
- **定义 239（分层保形风险控制 SCRC）**：对 EC 的每个 stratum s，用该层标定试验的非一致性分数取 Mondrian 保形分位数 q_s(α)，保证 P[R_s≤q_s(α)]≥1−α（逐层，而非边际）。未见配置用加权保形与密度比修正；有效样本量 n_eff<n_min 时不给保证，标记 underpowered 并禁止声明。
- **定义 240（变形关系 MET）**：关系 MR=(g,h)，g 为形态/输入变换，h 为预测输出变换；真实系统应满足 (c',x')=g(c,x) ⇒ y'=h(y)。违反度 v=‖y'−h(y)‖，容差 τ 由已知良好配对标定。关系库含：对称（镜像模块互换）、缩放（连杆 λ ⇒ 可达/惯量按已知律）、置换（模块重排）、组合（锁关节 ⇒ 可达集收缩）、守恒（质量/力平衡）、不变性（对称任务结果不变）。
- **定义 241（无标签未知故障检测）**：给定关系库 ℛ 与配置转移 c→c'，统计量 V=max_{MR∈ℛ} v_MR/τ_MR；V>1 且标定 p<α_met 即判「变形违反」（metamorphic violation）——**只声明系统不自洽，不把它塞进 VISTA 的有限假设集**。当关系库对行为变化是分离族（separating family）时，任何改变行为的故障必触发至少一条关系；否则只能检测关系敏感的那部分故障（明确的适用域）。
- **定义 242（主动评测分配 AEA）**：声明集 K、配置集 C、试验预算 B、单次风险预算 ε_eval。自适应选择 (k,c,x) 使期望信息增益 I(validity_k; outcome)/cost 最大，s.t. 预测风险 ≤ε_eval 且 RTC 安全；目标在自适应子模性下贪心达 1−1/e。后验熵 ≤δ_eval 或预算耗尽即停；未解决者标 underpowered，不得写成 valid。
- **定义 243（功效与零失败下界）**：Bernoulli 安全试验中，零失败下要证失败率 ≤p、置信 1−δ，需 n≥ln(1/δ)/p；有 f 次失败时用 Clopper–Pearson 上界 U(f,n,δ)，只有 U≤p 才可声明。任何「n 次 0 违规」必须同时报告 (n,U,power)，否则在证书中降级。**这把「实验结果」从叙事变成可复核的统计量。**
- **定义 244（配置索引证书 J_meta）**：J_meta=(J_vista, config_id, T/EEC_id, ec_hash, transfer_bound, power, worst_stratum_cov, met_status, rtc_id, goodhart_audit, aic_m_ver)。Valid ⇔ Valid(J_vista) ∧ (c∈T(c0) 且界 ≤ε_risk，或已按 EC 重认证且功效 ≥1−β) ∧ 逐层覆盖 ≥1−α ∧ 无未解释的变形违反 ∧ RTC(c_prev→c) 有效 ∧ 抗 Goodhart 审计通过。审计链新增：**为什么相信这个迁移（d_C、L̂、界）、为什么这个形态安全（RTC）、这次评测测了什么（EC 哈希、n、功效）。**
- **定义 245（重构过渡证书 RTC）**：重构路径 ξ:[0,1]→C，ξ(0)=c，ξ(1)=c'。瞬态约束：无自碰撞、支撑/夹持稳定、载荷要么夹牢要么在安全位姿释放、驱动/热限、标定连续或显式重标定。RTC(ξ) 有效 ⇔ ∀t 安全裕度 ≥0 且互锁顺序（先锁后动、先卸后换）满足；不存在有效路径则禁止重构。
- **定义 246（重构即修复 RAR）**：动作空间 A=A_cont×A_morph，A_morph={lock_joint, swap_tool, set_stiffness, set_gear, move_sensor}。选择 (a_cont,c') 最大化任务进度，s.t. R(c')≤ε_risk、RTC(c→c') 有效、切换成本/磨损 ≤预算、且 c' 的评测证据满足 J_meta（否则进入受限 probation）。加迟滞与最小驻留时间，防重构抖动。
- **定义 247（抗 Goodhart 评测审计 AIC-M）**：评测对手 ℰ_eval={指标游戏, 基准泄漏, 配置选择偏差, 分布漂移, 对抗任务, 形态漂移}×VISTA 的 ℰ_V。审计规则：任何「改进」必须 (i) 在冻结 EC 下测得；(ii) 在独立 causal_endpoint 上复现，且预注册效应量的 CI 排除 0；(iii) 至少通过一条变形关系与一个配置层迁移；(iv) 不能被「任务/配置变简单」解释。失败则在声明格中降级；反复失败触发**人类**修订 EC，策略无权改写。
- **定义 248（METAMORPH 闭环算子）**：语义流 [VISTA→MSM→EC/EEC→SCRC→MET→AEA→RAR→RTC→J_meta→AIC-M]；实时流 [形态状态读取→RTC 看门狗→J_meta 查表→执行/禁止重构]。VISTA 的内部归因与 METAMORPH 的外部评测互为对照：内部说「谁坏了」，外部说「这台机器、这个形态、这次评测是否值得信」。

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（Lipschitz 迁移上界）**：R 为 L-Lipschitz、c0 上有保形上界，则 R(c)≤R̂(c0)+q(α)+L̂ d_C(c0,c)；取 L̂ 为置信上界并对保形事件取并界，迁移声明以 ≥1−α−α_L 成立。这把「旧证书能不能用」从直觉变成一个可计算的不等式。
- **引理 10（变形检测的假阳性与功效）**：零假设下由配对标定保证 P[V>1]≤α_met；备择下若某关系对该故障的敏感度 s>τ，则检测功效随关系数与重复数上升；若关系库是分离族，则任何改变行为的故障必被某条关系捕获。未知复合故障因此有了一个**不要求归因正确**的出口。
- **引理 11（零失败功效界）**：零失败下 n≥ln(1/δ)/p；等价地，n 次零失败只能证 p≲ln(1/δ)/n。推论：此前「100 次 0 违规」只支持约 3% 的失败率上界，不能写成「安全」；「归因准确率 90%」也必须给置信区间与分层结果。
- **定理 9（METAMORPH 端到端有效性与安全）**：在 A94–A101 下，Valid(J_meta) ⇒ 声明被正确索引到形态（迁移有界或已重认证）、逐层覆盖成立、未知复合故障被 MET 以「不自洽」捕获而非强行归类、重构瞬态由 RTC 覆盖、指标改进通过独立因果终点审计；VISTA 的安全保证在 c 上保留。失效时优雅降级：未知故障→安全重构/停机；形态漂移→重认证；评测预算不足→underpowered，不冒充 valid。
- **定理 10（评测-重构联合近最优）**：在自适应子模目标与基数/预算约束下，AEA 的贪心期望信息增益 ≥(1−1/e) 最优；RAR 在切换成本可加、收益子模时同样有常数因子近似。代价是必须诚实建模切换成本与瞬态风险，否则「重构即修复」会退化为形态抖动。
- **命题（边际覆盖不够）**：两个配置层权重 0.9/0.1，前者覆盖 1.0、后者 0.0，则边际覆盖 0.9 可满足 1−α（α=0.1）而最差层完全未覆盖。故必须用 SCRC 的逐层覆盖，否则一个坏配置会被好配置平均掉。
- **命题（形态 Goodhart）**：若配置由被评策略选择、且指标在依赖配置的任务集上计算，则对任意指标都存在一个「指标最优但因果能力不高」的配置；除非评测契约外部冻结、任务分布与配置选择解耦（随机化或留出配置集）。这是 EC 与 AIC-M 必须外置的根本原因。

## 5. 本轮最大风险

**一句话**：METAMORPH 的全部保证依赖两个无法自证的前提——**风险对形态是 L-Lipschitz 的、且评测契约真正外在于被评系统**；但重构恰恰是同一个学习系统为了通过评测而选择的动作，于是 Goodhart 从策略转移到评测协议本身，而一个未被建模的重构瞬态（自碰撞、掉载、标定跳变）就足以让迁移上界失效、证书却仍然显示「有效」。

## 2. 形式化定义（完整版）

**定义 233（METAMORPH 闭环）** METAMORPH 是 VISTA 的「形态索引 + 外部评测」层：在 VISTA 的「语义流 ∘ 实时流」骨架上挂载 MSM（形态状态）、EC（评测契约）、EEC/T（迁移等价类与包络）、SCRC（逐层保形）、MET（变形体检）、AEA（主动评测）、RAR/RTC（重构即修复与过渡证书）、AIC-M（评测对抗），并原位升级 J_vista→J_meta。不变式：**评测契约、等价类定义、变形关系库均版本化、哈希钉住、对在线策略只读；统计评测、迁移判定、重认证与审计只发生在语义流；实时流只做形态状态读取、RTC 看门狗、J_meta 查表与执行，零学习写操作。**

**定义 234（形态状态与形态映射 MSM）** 形态状态
c=(G,q,θ_s)∈C，
其中 G 为模块图（节点=模块，边=连接，含端口类型与锁紧状态），q 为连续参数（连杆长度、关节限位、刚度、减速比），θ_s 为传感/驱动标定。形态映射
M(c)=(M_kin(c), M_dyn(c), M_stiff(c), M_sens(c), Reach(c), F_lim(c))
给出运动学、惯量/摩擦、刚度、传感器外参、可达集与力限。形态度量
d_C(c,c')=w_G·d_edit(G,G')+w_q‖q−q'‖_{Σ_q}+w_s·drift(θ_s,θ_s')，
其中 d_edit 为带端口类型约束的图编辑距离。重构算子 ρ:c→c' 带时间成本 C_re(ρ) 与瞬态风险 R_trans(ρ)，后者由 RTC 约束（定义 245）。**c 既是控制对象的一部分，也是评测的分层变量。**

**定义 235（配置索引风险与能力）** 对形态 c，任务分布 D_c（只含 c 下可达且在支持域内的任务），
R(c)=P_{(x,ξ)~D_c}[unsafe(x,π,c)∨fail(x,π,c)]，
Cap(c)=E_{(x,ξ)~D_c}[score(x,π,c)]，
score 为 proper scoring rule（如 Brier/log score 或任务定义的连续得分）。一个**声明**是命题「在形态类 S⊆C 上 R≤ε_risk 且 Cap≥ε_cap」。证书是声明的证据包，不是声明本身；没有样本量、功效与分层的「通过」不构成声明。

**定义 236（评测契约 EC）** 评测契约
EC=(e,m,S,α,β,n_min,strata,causal_endpoint,audit,hash,ver)，
其中 e 为因果估计量（如「形态对风险的配对平均处理效应」），m 为 proper scoring rule，S 为采样协议（任务抽取、种子、顺序、盲化、配置随机化），α 为风险水平，β 为功效，n_min 由定义 243 的功效分析给出，strata 为 EEC 单元，causal_endpoint 为未参与策略选择与超参选择的独立终点，audit 为变形+不变性检查，hash/ver 为内容哈希与版本。**EC 在部署前冻结、仅可追加修订；修订要求对受影响声明重认证；在线策略对 EC 只读。** 声明格 PCL 由 EC 定义：L0 未测、L1 单配置通过、L2 分层通过、L3 迁移通过且独立审计通过；证书只能引用其所处层级。

**定义 237（评测等价类 EEC 与认证迁移包络 T）** 精确 EEC：
c~c' ⇔
(i) ∃ 对称群元 g，使 M_kin(c')=g·M_kin(c) 且任务/障碍集在 g 下不变；
(ii) c' 的力/速/惯量包络 ⊆ c 的包络；
(iii) ‖θ_s'−θ_s‖_{Σ_s}≤q_cal(α)；
(iv) 观测分布漂移统计量 ≤q_shift(α)。
EEC 用于**无标签变形测试**（同一条关系在等价类内应精确成立）。近似情形定义**认证迁移包络**
T(c0)={c∈C : R̂(c0)+q(α)+L̂·d_C(c0,c)≤ε_risk，且 Cap 侧下界 ≥ε_cap}。
在 Lipschitz 与标定假设下 EEC⊆T；实践中 EEC 提供强证据，T 提供弱但可计算的证据。**注意：近似 EEC 未必传递；T 不要求传递，只要求逐点不等式。**

**定义 238（Lipschitz 迁移上界）** 设风险泛函 R 在 C 上对 d_C 为 L-Lipschitz，L̂ 为其置信上界；在已验证配置 c0 上有保形上界 R̂(c0)+q(α)。则对任意 c：
R(c) ≤ R̂(c0)+q(α)+L̂·d_C(c0,c)。
右侧 ≤ε_risk 时才允许迁移，否则必须按 EC 重认证。**若 c0→c 经过未建模的不连续点（自碰撞、标定跳变、电缆牵扯、锁紧冲击），Lipschitz 假设失效，不等式无效，必须走 RTC 或重认证。** L̂ 由配对形态实验（同一任务、随机化配置）估计，并取置信上界而非点估计；L̂ 的不确定性以 α_L 计入总风险。

**定义 239（分层保形风险控制 SCRC）** 对 EC 的每个 stratum s∈strata(EC)，取该层标定试验的非一致性分数，按 Mondrian 保形取
q_s(α)=Quantile_{⌈(n_s+1)(1−α)⌉/n_s}(scores_s)，
保证 P[R_s≤q_s(α)]≥1−α（**逐层**）。对未见配置用加权保形与密度比 w(c) 修正；有效样本量
n_eff=(Σw)²/Σw²<n_min
时不给保证，标记 `underpowered` 并禁止 L2/L3 声明。SCRC 直接对冲定义 236 的 PCL：**一个坏配置不能被好配置平均掉。**

**定义 240（变形关系 MET）** 变形关系 MR=(g,h)：g 为形态/输入变换，h 为预测输出变换；真实系统满足
(c',x')=g(c,x) ⇒ y'=h(y)。
违反度 v=‖y'−h(y)‖，容差 τ 由已知良好配对（null pairs）标定。关系库 ℛ 含：
- **对称**：镜像模块互换 ⇒ 输出镜像；
- **缩放**：连杆长度 ×λ（质量按几何相似 ×λ³）⇒ 可达域 ×λ、惯量按已知律；
- **置换**：模块重排 ⇒ 任务结果在置换语义下不变；
- **组合**：锁一个关节 ⇒ 可达集收缩为子集；
- **守恒**：质量/力平衡关系在任意 c 下成立；
- **不变性**：对称任务在对称形态交换下结果不变。
**关系库是评测的一部分，不是策略的一部分；其版本与容差全部写入 EC 哈希。**

**定义 241（无标签未知故障检测）** 给定关系库 ℛ 与配置转移 c→c'，统计量
V=max_{MR∈ℛ} v_MR/τ_MR。
V>1 且由 null 标定得 p<α_met 时，判「变形违反」（metamorphic violation）。它**只声明系统不自洽，不把它塞进 VISTA 的有限假设集**：若关系库是分离族（separating family，任意两种不同行为都被某条关系的预测区分），则任何改变行为的故障必触发至少一条关系；否则只能检测关系敏感的那部分故障，适用域必须显式写入 J_meta。与 FIR 的分工：FIR 回答「最像谁坏了」，MET 回答「有没有不自洽」；二者冲突时**以 MET 的报警触发保守降级/安全重构**，不强行归因。

**定义 242（主动评测分配 AEA）** 声明集 K、配置集 C、试验预算 B、单次风险预算 ε_eval。自适应选择
(k,c,x)*=argmax_{k,c,x} I(validity_k; outcome_{c,x}|history)/cost(c,x)，
s.t. 预测风险 ≤ε_eval 且 RTC(c_prev→c) 有效。
在自适应子模目标与基数预算下，贪心达到最优的 1−1/e；后验熵 ≤δ_eval 或预算耗尽即停。未解决者标记 `underpowered`，不得写成 valid。与 AFA 的区别：AFA 买「谁坏了」的信息，AEA 买「这条声明值不值得信」的信息。

**定义 243（功效与零失败下界）** Bernoulli 安全试验中，零失败下要证失败率 ≤p、置信 1−δ，需
n ≥ ln(1/δ)/p。
有 f>0 次失败时，用 Clopper–Pearson 精确上界 U(f,n,δ)；只有 U≤p 才可声明。任何「n 次 0 违规」必须同时报告 (n,U,power)，否则在 PCL 中降级。**这把「实验结果」从叙事变成可复核的统计量，也直接指出此前 E 表的功效不足。**

**定义 244（配置索引证书 J_meta）** 
J_meta=(J_vista, config_id, T/EEC_id, ec_hash, transfer_bound, power, worst_stratum_cov, met_status, rtc_id, goodhart_audit, aic_m_ver)。
验证规则：
Valid(J_meta) ⇔ Valid(J_vista)
∧ (c∈T(c0) 且 transfer_bound≤ε_risk，或已按 EC 重认证且 power≥1−β)
∧ worst_stratum_cov≥1−α
∧ (met_status=ok ∨ 未解释违反已升级处置)
∧ RTC(c_prev→c) 有效
∧ goodhart_audit=pass
∧ aic_m_ver 为当前版本。
审计链新增：**为什么相信这个迁移（c0、d_C、L̂、界）、为什么这个形态安全（RTC）、这次评测测了什么（EC 哈希、n、功效、分层覆盖）。**

**定义 245（重构过渡证书 RTC）** 重构路径 ξ:[0,1]→C，ξ(0)=c，ξ(1)=c'。瞬态约束：
(i) 无自碰撞（含电缆/工具/环境）；
(ii) 支撑/夹持稳定（COM 在支撑域内或由夹具/另一臂持有）；
(iii) 载荷要么夹牢、要么在安全位姿释放（不许在运动中掉载）；
(iv) 驱动/热/速度限；
(v) 标定连续，或显式重标定并在重标定完成前禁止高精度任务；
(vi) 互锁顺序：先锁后动、先卸后换、先断电后插拔。
RTC(ξ) 有效 ⇔ ∀t 安全裕度 ≥0 且互锁满足。不存在有效路径则**禁止重构**，退回 VISTA 的保守动作。

**定义 246（重构即修复 RAR）** 动作空间 A=A_cont×A_morph，A_morph={lock_joint, unlock_joint, swap_tool, set_stiffness, set_gear, move_sensor}。选择
(a_cont,c')*=argmax Cap(c') s.t. R(c')≤ε_risk，RTC(c→c') 有效，switch_cost(c,c')≤B_morph，且 J_meta(c') 有效（否则进入受限 probation：更低的力限、更短的 k*）。
加迟滞 h 与最小驻留时间 T_dwell，防重构抖动与磨损。**RAR 把「换一个能安全完成任务的形态」纳入安全策略，直接对冲 VISTA 的「在错误形态上无限保守化」。**

**定义 247（抗 Goodhart 评测审计 AIC-M）** 评测对手
ℰ_eval={metric gaming, benchmark leakage, config selection bias, distribution shift, adversarial task, morphology drift}×ℰ_V。
审计规则：任何「改进」必须
(i) 在冻结 EC 下测得；
(ii) 在独立 causal_endpoint 上复现，且预注册效应量的置信区间排除 0；
(iii) 至少通过一条变形关系与一个配置层迁移；
(iv) 不能被「任务/配置变简单」解释（难度匹配检查）。
失败则在 PCL 中降级；反复失败触发**人类**修订 EC，策略无权改写。AIC-M 还要求配置选择在评测中随机化或留出一个未参与选择的配置集，以切断「策略选配置→指标好看」的后门。

**定义 248（METAMORPH 闭环算子）** 语义流：[VISTA→MSM 更新 c→EC/EEC/T 迁移判定→SCRC 逐层覆盖→MET 变形体检→AEA 主动评测→RAR 形态决策→RTC 过渡验证→J_meta 构建→AIC-M 审计]；实时流：[形态状态读取→RTC 看门狗→J_meta 查表→执行/禁止重构→异常早停]。VISTA 的内部归因与 METAMORPH 的外部评测互为对照：**内部说「谁坏了」，外部说「这台机器、这个形态、这次评测是否值得信」。**

```python
class MorphologyState:
    def __init__(self, graph, q, calib):
        self.G, self.q, self.theta_s = graph, q, calib
    def map(self):
        return dict(kin=forward_kin(self.G, self.q),
                    dyn=inertia_model(self.G, self.q),
                    stiff=stiffness_model(self.G, self.q),
                    sens=sensor_frames(self.G, self.theta_s),
                    reach=reachable_set(self.G, self.q),
                    f_lim=force_limits(self.G, self.q))
    def distance(self, other):
        return (W_G * graph_edit(self.G, other.G)
                + W_Q * np.linalg.norm(self.q - other.q, ord='mahalanobis')
                + W_S * calib_drift(self.theta_s, other.theta_s))


def certify_transfer(c0, c, risk_hat, q_alpha, L_hat, eps_risk):
    d = c0.distance(c)
    bound = risk_hat + q_alpha + L_hat * d
    if bound <= eps_risk:
        return True, {'bound': bound, 'd_C': d, 'L_hat': L_hat, 'mode': 'transfer'}
    return False, {'reason': 'outside transfer envelope',
                   'bound': bound, 'd_C': d, 'mode': 'recertify'}


class StratifiedConformal:
    def __init__(self, n_min, alpha):
        self.scores, self.n_min, self.alpha = {}, n_min, alpha
    def update(self, stratum, score):
        self.scores.setdefault(stratum, []).append(score)
    def upper(self, stratum):
        s = self.scores.get(stratum, [])
        if len(s) < self.n_min:
            return np.inf, 'underpowered'
        n = len(s)
        k = int(np.ceil((n + 1) * (1 - self.alpha)))
        return float(np.sort(s)[min(k, n) - 1]), 'ok'
```

```python
class MetamorphicAudit:
    def __init__(self, relations, alpha_met=0.05):
        self.relations, self.alpha_met = relations, alpha_met  # (name, g, h, tau, applicable)
    def test(self, c, c_prime, x, y, y_prime):
        viol = {}
        for name, g, h, tau, applicable in self.relations:
            if not applicable(c, c_prime, x):
                continue
            _, x2 = g(c, x)
            viol[name] = float(np.linalg.norm(y_prime - h(y)) / max(tau, 1e-9))
        if not viol:

        p = self.null_survival(V)          # 由已知良好配对标定的零分布
        return {'status': 'violation' if p < self.alpha_met else 'ok',
                'V': V, 'p': p, 'by_relation': viol}
```

## 4. 推导

**引理 9（Lipschitz 迁移上界）** 设 R:C→[0,1] 对 d_C 为 L-Lipschitz，即 |R(c)−R(c')|≤L·d_C(c,c')。在 c0 上由 SCRC 得保形上界 P[R(c0)≤R̂(c0)+q(α)]≥1−α。若 L̂≥L 以概率 ≥1−α_L 成立，则对任意 c：
R(c) ≤ R(c0)+L·d_C(c0,c) ≤ R̂(c0)+q(α)+L̂·d_C(c0,c)，
以概率 ≥1−α−α_L 成立。故迁移判定 `bound≤ε_risk` 是保守的。若 c0→c 经过不连续点，则存在 δ 使 |R(c)−R(c0)| 不随 d_C→0 而→0，Lipschitz 假设不成立，必须由 RTC 覆盖或重认证。∎

**引理 10（变形检测的假阳性与功效）** 零假设（无故障、标定一致）下，由 null pairs 标定 τ 使 P[v>τ]≤α_met/|ℛ|；对 |ℛ| 条关系取并界得 P[V>1]≤α_met。备择下，若存在关系 MR 对该故障的敏感度 s=E[v|fault]>τ，则单次检测概率 p_det≥P[v>τ|fault]，重复 m 次独立测试后 1−(1−p_det)^m。若 ℛ 是分离族，则任意改变行为的故障 f 与健康系统 g 在某 (c,x) 上输出不同，于是存在 MR 的预测 h 不能同时匹配两者，故必触发违反。若 ℛ 不是分离族，存在不可检测的行为变化，必须在 J_meta 中显式标注适用域。∎

**引理 11（零失败功效界）** 设 n 次独立试验零失败，真实失败率 p。则 P[0 failures]=(1−p)^n；要在 1−δ 置信下排除 p，需 (1−p)^n≤δ，即 n≥ln(1/δ)/ln(1/(1−p))≈ln(1/δ)/p（小 p）。有 f 次失败时，Clopper–Pearson 上界 U(f,n,δ) 是精确的 1−δ 上置信界；只有 U≤p 才能声明。推论：n=100、f=0、δ=0.05 时 U≈1−0.05^{1/101}≈2.95%，即只能证「≲3%」；要证 0.1% 需约 2996 次。∎

**定理 9（METAMORPH 端到端有效性与安全）** 在 A94–A101 下：
1. **形态索引**：Valid(J_meta) 要求 c∈T(c0)（带引理 9 的界）或按 EC 重认证（带引理 11 的功效）；证书不再被错误地跨形态复用。
2. **逐层有效**：SCRC 的 Mondrian/加权保形给出逐层覆盖；由命题「边际覆盖不够」，这避免了坏配置被平均掉。
3. **未知复合故障有出口**：MET 以无标签违反检测「不自洽」，不强行归入 VISTA 的有限 ℋ；冲突时触发保守降级/安全重构（引理 10）。
4. **重构瞬态安全**：RAR 只在 RTC 有效的路径上执行；CSC 的前缀安全在重构期间被暂停，重构完成后按新 c 重新认证。
5. **抗 Goodhart**：AIC-M 要求改进在独立因果终点复现、效应量 CI 排除 0、通过变形与分层迁移；否则 PCL 降级（命题「形态 Goodhart」）。
6. **优雅降级**：未知故障→安全重构或停机；形态漂移→重认证；预算不足→underpowered；MET 不可用（透明/无纹理等）→退回 VISTA 的保守动作并标注 `met_unavailable`。
7. **实时性**：实时路径仅增形态读取、RTC 看门狗与 J_meta 查表，≤0.5ms（A101）。∎

**定理 10（评测-重构联合近最优）** 设 AEA 的目标 f(S)=I(validity; outcome_S) 在自适应策略类上自适应子模且单调，|S|≤B。则贪心策略的期望信息增益 ≥(1−1/e)OPT。RAR 的收益 g(S)=Cap(c_S)−λ·switch_cost(S) 若为单调子模且预算为基数约束，则贪心同样 ≥(1−1/e)OPT。若切换成本不可加或存在互锁耦合，子模性破坏，近似保证失效，必须显式求解小规模 MILP 或退回枚举。∎

**命题（边际覆盖不够）** 设两个配置层权重 w1=0.9,w2=0.1，覆盖分别 1.0 与 0.0。边际覆盖 =0.9≥1−α（α=0.1），但第 2 层完全未覆盖。故仅报告边际保形覆盖会掩盖一个配置上的系统性失败；必须用 SCRC 的逐层覆盖。∎

**命题（形态 Goodhart）** 设策略可选择 c，指标 m 在依赖 c 的任务集 D_c 上计算。对任意 m，若存在 c_bad 使 D_{c_bad} 的任务显著更简单，则策略可令 m(c_bad) 很高而 R(c_bad) 仍高。除非 (i) EC 外部冻结且策略只读，(ii) 任务分布 D 与 c 解耦（固定任务集或随机化配置），(iii) 在未参与选择的配置集上复核，否则观测到的指标改进不能识别因果能力。故 EC 与 AIC-M 必须外置。∎

## 7. 已知风险

**一句话**：METAMORPH 的全部保证依赖两个无法自证的前提——**风险对形态是 L-Lipschitz 的、且评测契约真正外在于被评系统**；但重构恰恰是同一个学习系统为了通过评测而选择的动作，于是 Goodhart 从策略转移到评测协议本身，而一个未被建模的重构瞬态（自碰撞、掉载、标定跳变）就足以让迁移上界失效、证书却仍然显示「有效」。

**次级风险与缓解**：
1. **Lipschitz 常数被低估**：L̂ 由有限配对实验估计，形态空间中存在未采样区域；缓解：取置信上界、按 EEC 分层估计、对未覆盖区域拒绝迁移而非外推；不连续点显式列入 RTC。
2. **变形关系库不完备**：非分离族下存在不可检测的行为变化；缓解：在 J_meta 中显式写适用域，持续扩充关系库，把 MET 的「未检测」与「安全」区分开，未知故障默认保守。
3. **评测契约仍可能被研究人员/策略共同影响**：EC 由人设计，存在研究者自由度；缓解：预注册、哈希钉住、独立 causal_endpoint、留出配置集、第三方复现；策略只读。
4. **统计功效不足**：真实机器人试验昂贵，n 远小于证明 0.1% 所需；缓解：报告 U(f,n,δ) 与 underpowered，分层合并时用层级模型，不把「0 违规」写成「安全」。
5. **重构抖动与磨损**：RAR 可能频繁换形态以躲避难任务；缓解：切换成本、迟滞、最小驻留、磨损预算，并把切换次数写入 J_meta 审计。
6. **共因失效升级**：形态同时影响几何与视觉，可能让 VISTA 的独立性假设更不成立；缓解：MET 不要求独立，只要求关系成立；共因下优先报警与安全重构，而非归因。
7. **过渡瞬态建模不足**：RTC 的检查集可能漏掉电缆、柔性、摩擦自锁等；缓解：保守采样、物理互锁、低速重构、硬件急停，RTC 只作必要非充分条件之一。
8. **评测对抗的军备竞赛**：AIC-M 与策略的指标游戏会演进；缓解：独立审计、隐藏测试集、定期人类复核、把「评测协议本身」纳入版本与威胁模型。
9. **sim2real 与形态参数辨识误差**：M(c) 的参数可能不准；缓解：在线辨识 + 标定漂移检测，参数不确定计入 d_C 与 L̂。
