# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环重启第 1 轮；本轮灵感：「开源软件」×「比赛策略」）· OpenSkill-Arena：把技能做成可复现的开源包，把比赛做成相对排名的策略博弈

> 第 54 轮已把技能组合推进到动作剖面 `α_S`、组合图 `G_S`、云边映射 `γ_ce` 与联合证书 `J`。但它默认了两件事：技能库是**静态、内部生产、单任务部署**的；参赛目标是**绝对成功率最大化**。本轮用「开源软件」拆掉第一个默认，用「比赛策略」拆掉第二个。核心矛盾：**H22（供应链失配）**：真实技能会像开源包一样被 fork、打补丁、共享感知/控制依赖，版本偏移与跨任务回归会让一张对某组合 sound 的证书在另一组合**静默失效**；**H23（羊群失配）**：公开基线会让赛场同质化，在排名制下「公共能力」的边际收益被对手同步采用所抵消，真正决定名次的是**与赛场去相关的私有能力**。

## 0. 直觉与动机

### 0.1 本轮思考轨迹

1. 回看第 54 轮：`α_S`、`G_S`、`J` 都默认「技能版本固定、证书永久有效」。但 UniBot 的 32 项桌面任务会迫使同一个抓取/放置/感知技能被反复修改；改一个共享感知模块，可能同时改变多个任务的 `α` 与 `ρ`。证书没有版本号，这是 H22。
2. 再看比赛：32 项任务不是 32 个独立抽奖。它们共享技能、共享真机时间、共享失败代价；而且名次是相对的，不是绝对分。把每项任务独立优化，会忽略「练一个技能、涨多项任务」的迁移外部性，也会忽略「大家都抄公开基线」的羊群风险。这是 H23。
3. 把两个灵感词钉到机制上：开源软件 → 版本、依赖、锁文件、fork/merge、回归 CI、CVE 式撤销；比赛策略 → 有限预算、共享技能的老虎机、相对排名、反羊群、披露时机。
4. 找到缺口：第 54 轮能回答「这个组合能不能工作」，但不能回答「这个组合在**这个版本、这个赛场、这个预算**下值不值得部署」。于是把技术证书 `J` 扩展为**战略部署证书 `S_cert`**：它同时锁版本、锁回归证据、锁相对收益与羊群暴露。
5. 先做玩具推导：在排名制里，若所有对手都采用同一个公开改进，公共分量的提升对名次没有一阶贡献；私有分量的提升才有。这不是「为反而反」，而是排名博弈的边际价值结论。它决定了 HEDGE 不是装饰，而是必要条件。

## 1. 五个直觉

**灵感 1（开源软件 → 技能是带「行为语义版本」的包，不是裸函数）**
直觉：开源生态之所以能协作，不是因为代码免费，而是因为**版本、依赖、锁文件、复现构建**把「谁和谁一起工作」变成了可判定问题。机器人技能也应如此：一个技能包不仅包含权重，还包含动作剖面 `α_P`、鲁棒性谱 `ρ_P`、依赖的感知/控制器/标定、许可证与来源哈希。版本号不能只标代码，必须标**行为**：动作支撑集变了就是 major，动作支撑扩张但旧行为保持是 minor，只提升鲁棒性是 patch。没有行为版本，`J` 就是一张没有绑定对象的证书。

**灵感 2（fork/merge → 边端适配必须能向上游回灌，但回灌要过回归 CI）**
直觉：边端为某个任务 fork 一个技能、修好后，最自然的想法是「合并回主库，让其他任务也受益」。但开源软件最痛的教训是：一个局部补丁可能修好 A、弄坏 B。机器人更严重，因为 B 的失败可能是物理的、不可逆的。于是 fork/merge 必须带**跨任务回归预算**：补丁在目标任务上要有增益，在所有其他任务上的下降不能超过各自预算；冲突区域 `A_conf` 是两版动作支撑的差集，未被标定覆盖的冲突区必须拒绝合并。失败解释 `Explain` 变成可复现的 issue（带仿真种子），补丁变成 PR，回归 CI 是合并门槛。

**灵感 3（比赛策略 → 32 项任务是共享技能的「组合老虎机」，不是 32 个独立臂）**
直觉：练习一个「抓取」技能，会同时提高多个含抓取的任务；真机尝试一次「插拔」，会同时更新对「对准」「力控」「视觉伺服」的判断。把它们当独立老虎机，会重复探索同一个潜在技能，浪费有限真机预算。正确抽象是**任务-技能二部迁移图** `B=(T,S,E,W)`：每个任务的成功率由一组共享技能潜变量决定。仿真提供便宜先验，真机提供昂贵证据，证据沿图传播。这就是**共享技能 factored bandit**。

**灵感 4（开源软件 × 比赛策略 → 公开基线制造羊群，排名制下公共改进的边际价值被抵消）**
直觉：开源让所有人看到同一个强基线；于是赛场会收敛到相似策略。若评分是排名制，当大家都采用同一个公开改进时，所有人的公共分量一起上升，**相对名次不变**；真正拉开差距的是别人没有的私有分量。因此策略不应最大化「绝对成功率」，而应最大化**赛场相对效用**，并对「与公开基线的高相关」收税。反羊群不是故意不同，而是把有限资源投到**公开证据最弱、自己私有证据最强**的任务/技能上——这是一种信息套利。

**灵感 5（统一 → 从技术证书 `J` 到战略部署证书 `S_cert`）**
直觉：第 54 轮的 `J` 回答「组合是否 sound」；本轮要回答「在这个版本、这个赛场、这个预算下，是否值得把真机时间押上去」。`S_cert` 同时包含：锁文件与可复现性、跨任务回归证据、技术证书 `J`、相对效用 `U_rel`、羊群暴露 `ρ_herd`、披露状态 `γ_disc` 与有效期。技术可行但战略被支配的组合不部署；战略诱人但技术未认证的组合也不部署。**两张证书都过，才允许占用真机预算。**

## 2. 形式化定义（增量：定义 121–126）

**定义 121（技能包与行为语义版本）**
技能包 `P = (id, v, α_P, ρ_P, deps, lic, h, prov)`，其中 `v=(M,m,p)`，`h` 为制品哈希，`prov` 为来源/训练/标定护照，`deps` 为依赖的感知、控制器、标定与技能包。**安全升级** `P' ⪰_safe P` 当且仅当：
```
M'=M,  supp α_P ⊆ supp α_{P'},
α_{P'}(a) ≥ α_P(a) − ε_a  ∀a∈supp α_P,
ρ_{P'}(d) ≥ ρ_P(d) − ε_ρ  ∀d,
deps(P') 可在同一 lock 下解析
```
若 `supp α_{P'} ⊉ supp α_P` 或旧支撑上的行为下降超过 `ε_a`，则必须 bump major，记为 `break(P,P')`。`compat_v(P,P')` 为真当且仅当二者可在一个 major 内安全升级或完全一致。

**定义 122（技能锁与可复现组合）**
技能锁 `SkillLock = {(P_i, h_i, v_i, α_i, ρ_i, deps_i)}`。组合 `C` **可复现** `Repro(C)=1` 当且仅当从锁重建得到相同哈希，且
```
‖α_C − α̂_C‖∞ ≤ ε_rep,   ‖ρ_C − ρ̂_C‖∞ ≤ ε_rep
```
部署守卫使用安全裕度：`cover(C,A_T) ≥ θ_cov + k·(ε_a + ε_rep)`，其中 `k` 为组合技能数。**锁定不是不更新，而是每次更新都必须显式改变 lock 并重签证书。**

**定义 123（跨任务回归干扰与合并预算）**
对技能 `P` 的补丁 `p`，在任务集 `T` 上定义
```
Δ_{p→t} = succ_t(P+p) − succ_t(P)
```
补丁可合并当且仅当
```
min_{t∈T} Δ_{p→t} ≥ −β_t,   mean_t Δ_{p→t} ≥ 0,   Δ_{p→target} ≥ δ_p
```
且冲突区 `A_conf(p)=supp α_{P+p} Δ supp α_P` 被标定集覆盖。记 `RegBudget(p)=1` 为通过。目标任务的增益不能以任意其他任务的灾难性下降为代价；`β_t` 对安全相关任务取 0。

**定义 124（任务-技能迁移图与共享技能老虎机）**
二部图 `B=(T,S,E,W)`，`W_{t,s}∈[0,1]` 表示技能 `s` 对任务 `t` 的影响权重（按行归一化）。设技能潜变量 `θ_s`，任务成功概率
```
p_t(θ) = σ( Σ_s W_{t,s} θ_s + b_t )
```
真机预算 `B`，任务 `t` 的单次成本 `c_t`，策略 `π` 依次选择任务并观测 `r_t∼Bernoulli(p_t)`。目标不是最大化单任务，而是最大化预算内的**已解决任务数/加权得分**。由于 `θ` 共享，任务 `t` 的证据会更新其邻接技能，再传播到其他任务。

**定义 125（赛场相对效用与羊群暴露）**
赛场 `F={π_1,...,π_n}`，评分函数 `s_rank(π;F)`（排名制或分位数制）。定义
```
U_rel(π) = E_F[ s_rank(π;F) − s_rank(π_pub;F) ]
ρ_herd(π) = corr( s(π), s(π_pub) )
```
`π_pub` 为公开基线策略。`U_rel` 衡量「比抄公开基线多赢多少」，`ρ_herd` 衡量「与公开基线一起崩的风险」。HEDGE 目标为
```
max_π  U_rel(π) − λ·ρ_herd(π) − μ·Var_F(s_rank(π;F))
```
`λ,μ≥0` 由风险偏好给定；当 `λ=0` 退化为纯相对收益。

**定义 126（战略部署证书）**
`S_cert = (SkillLock, Repro, RegEvidence, J, U_rel, ρ_herd, γ_disc, T_valid)`：
- `SkillLock/Repro`：版本与可复现性；
- `RegEvidence`：回归套件、覆盖分层与拒绝记录；
- `J`：第 54 轮动作-鲁棒性联合证书；
- `U_rel`、`ρ_herd`：相对收益与羊群暴露；
- `γ_disc ∈ {closed, delayed-open, open}`：披露/释放状态，带泄漏惩罚 `ℓ(γ_disc)`；
- `T_valid`：有效期，漂移或版本变更即失效。
部署谓词：
```
Deploy(C) = Repro(C) ∧ RegBudget(C) ∧ Valid(J) ∧ U_rel(C) ≥ U_min
            ∧ ρ_herd(C) ≤ ρ_max ∧ RulesAllow(γ_disc)
```

## 3. 关键算法 伪代码

### IP-121 BSV（Behavior Semantic Versioning）

```python
def safe_upgrade(p, base, eps_a=0.02, eps_r=0.01):
    if p.major != base.major:
        return False
    if not set(base.alpha).issubset(set(p.alpha)):
        return False
    if any(p.alpha[a] < base.alpha[a] - eps_a for a in base.alpha):
        return False
    if any(p.rho[d] < base.rho[d] - eps_r for d in base.rho):
        return False
    return deps_unifiable(p.deps, base.deps)

def resolve_lock(pkgs, req):
    lock = {}
    for name, base in topo_order(req):
        cands = [p for p in pkgs[name]
                 if safe_upgrade(p, base) and cover(p.alpha, req[name].A_req)]
        if not cands:
            raise NoSafeVersion(name)
        lock[name] = max(cands, key=lambda p: (p.minor, p.patch))
    return lock
```

### IP-122 LOCK（Reproducible SkillLock）

```python
def verify_lock(lock, rebuild, eps_rep=1e-3):
    for p in lock:
        q = rebuild[p.id]
        if q.hash != p.hash:
            return ('reject', 'hash_mismatch', p.id)
        if norm_inf(q.alpha, p.alpha) > eps_rep:
            return ('reject', 'alpha_drift', p.id)
        if norm_inf(q.rho, p.rho) > eps_rep:
            return ('reject', 'rho_drift', p.id)
        if q.deps != p.deps:
            return ('reject', 'dep_drift', p.id)
    return ('ok', lock)
```

### IP-123 RAMP（Regression-Aware Merge Protocol）

```python
def admit_patch(patch, base, suite, beta, delta_target):
    before = evaluate(base, suite)
    after  = evaluate(base.apply(patch), suite)
    delta  = {t: after[t] - before[t] for t in suite}
    conf   = symdiff(patch.alpha.support, base.alpha.support)
    if conf and not calib_covers(conf):
        return ('reject', 'uncovered_action_conflict', conf)
    if min(delta.values()) < -max_beta(beta, suite):
        return ('reject', 'regression', delta)
    if delta[patch.target] < delta_target:
        return ('reject', 'insufficient_target_gain')
    return ('merge', delta, issue_bundle(patch, suite))
```

### IP-124 CAP（Competition-Aware Portfolio）

```python
def cap_allocate(tasks, skills, W, budget, cost, prior):
    theta = prior.sample()
    solved = set()
    while budget > 0:
        p = {t: sigmoid(sum(W[t][s]*theta[s] for s in skills) + b[t])
             for t in tasks}
        gain = {t: (p[t] - p_ref[t]) / cost[t]
                   + beta_info * info_gain(t, W, prior)
                for t in tasks if t not in solved}
        t = max(gain, key=gain.get)
        r = real_rollout(t)
        budget -= cost[t]
        if r: solved.add(t)
        theta = posterior_update(theta, t, r, W)   # shared-skill propagation
    return solved
```

### IP-125 HEDGE（Herding-Aware Diversification）

```python
def hedge_select(portfolio, field_model, public_baseline, lam, mu):
    best = None
    for pi in portfolio:
        u = field_relative_utility(pi, field_model)
        c = herd_exposure(pi, public_baseline)   # corr / cosine
        v = rank_variance(pi, field_model)
        z = u - lam*c - mu*v
        if best is None or z > best.z:
            best = Candidate(pi, z, u, c, v)
    return best
```

### IP-126 SDC（Strategic Deployment Certificate）

```python
def strategic_cert(comp, lock, suite, J, field, baseline, cfg, rules):
    if verify_lock(lock, rebuild(comp)) != ('ok', lock):
        return ('reject', 'not_reproducible')
    reg = regression_evidence(comp, suite)
    if not reg.admissible:
        return ('reject', 'regression', reg)
    if not J.valid:
        return ('reject', 'technical', J)
    U = field_relative_utility(comp, field)
    rho = herd_exposure(comp, baseline)
    if U < cfg.U_min or rho > cfg.rho_max:
        return ('reject', 'strategy', U, rho)
    if not rules.allows(comp.disc):
        return ('reject', 'disclosure', comp.disc)
    return ('ok', S_cert(lock, reg, J, U, rho, comp.disc,
                         T_valid=now() + cfg.horizon))
```

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| BSV | O(|P|·|deps|·|A|) | O(|P|) | safe-upgrade 可传递、major/minor 边界 sound |
| LOCK | O(|C|·|A|) | O(|C|) | 哈希绑定、漂移上界、fail-closed |
| RAMP | O(|T|·|suite| + |A|) | O(|T|) | 回归预算 sound、冲突区被覆盖 |
| CAP | O(B·(|T|+|E|)) | O(|T|+|S|) | 迁移图正确、后验可传播 |
| HEDGE | O(|Π|·|F|) | O(|Π|) | 相关性估计误差有界、非单纯反叛 |
| SDC | O(|C|·|A| + |T|) | O(|C|+|T|) | 各守卫合取、任一失败即拒绝 |

**定理 1（版本偏移的覆盖界）**
假设组合覆盖函数 `cover(·,A_T)` 对每个 `α_i` 是 1-Lipschitz 的（交集/Jaccard 满足此性质），每个包锁校验漂移 ≤ `ε_rep`，每个安全升级的剖面漂移 ≤ `ε_a`。则对 `k` 个技能的组合 `C` 与其重建 `Ĉ`：
```
|cover(C,A_T) − cover(Ĉ,A_T)| ≤ k·(ε_a + ε_rep)
```
因此若部署前满足 `cover(C,A_T) ≥ θ_cov + k·(ε_a + ε_rep)`，则重建/升级后的组合仍覆盖任务动作序列。
*证明*：`cover` 对单个剖面的 Lipschitz 常数为 1，逐项三角不等式相加；动作支撑的交集与 Jaccard 对 `L∞` 扰动均为 1-Lipschitz。

**定理 2（公共分量折扣 / 反羊群）**
考虑 `n` 个对手，得分 `S_i = c + x_i`，其中 `c` 为公共分量，`x_i` 为私有分量，`F` 为 `x` 的 CDF。若赛场以概率 `α` 采用某个公开改进，则公共改进 `δc` 对本方期望名次的一阶影响为 `(1−α)·Δ_pub`，而私有改进 `δx` 的影响为 `Δ_priv`；当 `α→1` 时 `∂E[rank]/∂c→0`，而 `∂E[rank]/∂x_0>0`。因此在排名制下，把资源投入被广泛采用的公开技能，其边际排名价值被羊群抵消；投入私有/去相关技能才有一阶收益。
*证明*：`E[rank]=(1/n)Σ_j P(S_j<S_0)`；对所有采用者的公共项同时平移时，成对比较中的 `c` 相消，只有未采用者贡献差额，比例恰为 `1−α`。

**定理 3（共享技能样本效率）**
若 `p_t = σ(⟨W_t,θ⟩)`，`θ∈ℝ^d`，`d≪|T|`，则 CAP 是一个随机线性 bandit；在正确指定的 `W` 下，其 Bayesian regret 为 `O(d√(T log T))`，而把 32 个任务当独立臂的探索下界为 `Ω(√(|T|T))`。当 `d<|T|` 时共享迁移严格更省样本；若 `W` 有误，额外 regret 与 `‖Ŵ−W‖` 成正比。
*证明*：线性 bandit 的标准 regret 界 + 独立臂分解下界；误指定项由奖励函数对 `W` 的 Lipschitz 性给出。

## 6. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|

## 2. 关键算法 伪代码

### IP-121 BSV：解析安全版本并生成锁

```python
def safe_upgrade(p, base, eps_a=0.02, eps_r=0.01):
    same_major = p.major == base.major
    keeps_support = set(base.alpha).issubset(set(p.alpha))
    old_behavior_ok = all(
        p.alpha[a] >= base.alpha[a] - eps_a for a in base.alpha)
    robust_ok = all(
        p.rho[d] >= base.rho[d] - eps_r for d in base.rho)
    return same_major and keeps_support and old_behavior_ok \
           and robust_ok and deps_unifiable(p.deps, base.deps)

def resolve_lock(pkgs, req):
    lock = {}
    for name, base in topo_order(req):
        cands = [p for p in pkgs[name]
                 if safe_upgrade(p, base)
                 and cover(p.alpha, req[name].A_req)]
        if not cands:
            raise NoSafeVersion(name)          # fail-closed
        lock[name] = max(cands, key=lambda p: (p.minor, p.patch))
    return lock
```

### IP-122 LOCK：部署前复现校验

```python
def verify_lock(lock, rebuild, eps_rep=1e-3):
    for p in lock:
        q = rebuild[p.id]
        if q.hash != p.hash:                      return ('reject','hash')
        if norm_inf(q.alpha, p.alpha) > eps_rep:   return ('reject','alpha')
        if norm_inf(q.rho, p.rho) > eps_rep:       return ('reject','rho')
        if q.deps != p.deps:                       return ('reject','deps')
    return ('ok', lock)
```

### IP-123 RAMP：回归感知的 fork/merge

```python
def admit_patch(patch, base, suite, beta, delta_target):
    before = evaluate(base, suite)
    after  = evaluate(base.apply(patch), suite)
    delta  = {t: after[t] - before[t] for t in suite}
    conf   = symdiff(patch.alpha.support, base.alpha.support)
    if conf and not calib_covers(conf):
        return ('reject', 'uncovered_action_conflict', conf)
    if min(delta.values()) < -max_beta(beta, suite):
        return ('reject', 'regression', delta)
    if delta[patch.target] < delta_target:
        return ('reject', 'insufficient_target_gain')
    return ('merge', delta, issue_bundle(patch, suite))
```

### IP-124 CAP：共享技能预算分配

```python
def cap_allocate(tasks, skills, W, budget, cost, prior):
    theta = prior.sample()
    solved = set()
    while budget > 0:
        p = {t: sigmoid(sum(W[t][s]*theta[s] for s in skills) + b[t])
             for t in tasks}
        gain = {t: (p[t] - p_ref[t]) / cost[t]
                   + beta_info * info_gain(t, W, prior)
                for t in tasks if t not in solved}
        t = max(gain, key=gain.get)
        r = real_rollout(t)
        budget -= cost[t]
        if r:
            solved.add(t)
        theta = posterior_update(theta, t, r, W)   # 沿图传播证据
    return solved
```

### IP-125 HEDGE：相对效用与羊群暴露

```python
def hedge_select(portfolio, field_model, public_baseline, lam, mu):
    best = None
    for pi in portfolio:
        u = field_relative_utility(pi, field_model)
        c = herd_exposure(pi, public_baseline)   # corr / cosine
        v = rank_variance(pi, field_model)
        z = u - lam*c - mu*v
        if best is None or z > best.z:
            best = Candidate(pi, z, u, c, v)
    return best
```

### IP-126 SDC：战略部署门

```python
def strategic_cert(comp, lock, suite, J, field, baseline, cfg, rules):
    if verify_lock(lock, rebuild(comp)) != ('ok', lock):
        return ('reject', 'not_reproducible')
    reg = regression_evidence(comp, suite)
    if not reg.admissible:
        return ('reject', 'regression', reg)
    if not J.valid:
        return ('reject', 'technical', J)
    U   = field_relative_utility(comp, field)
    rho = herd_exposure(comp, baseline)
    if U < cfg.U_min or rho > cfg.rho_max:
        return ('reject', 'strategy', U, rho)
    if not rules.allows(comp.disc):
        return ('reject', 'disclosure', comp.disc)
    return ('ok', S_cert(lock, reg, J, U, rho, comp.disc,
                         T_valid=now() + cfg.horizon))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| BSV | O(|P|·|deps|·|A|) | O(|P|) | safe-upgrade 可传递；major/minor 边界 sound |
| LOCK | O(|C|·|A|) | O(|C|) | 哈希绑定、漂移上界、fail-closed |
| RAMP | O(|T|·|suite| + |A|) | O(|T|) | 回归预算 sound；冲突区必须被标定覆盖 |
| CAP | O(B·(|T|+|E|)) | O(|T|+|S|) | 迁移图正确时证据可传播；保守探索有界 |
| HEDGE | O(|Π|·|F|) | O(|Π|) | 相关性估计误差有界；非单纯反叛 |
| SDC | O(|C|·|A| + |T|) | O(|C|+|T|) | 六项守卫合取；任一失败即拒绝 |

**定理 1（版本偏移覆盖界）**
若 `cover(·,A_T)` 对每个 `α_i` 是 1-Lipschitz，锁重建漂移 ≤ `ε_rep`，安全升级剖面漂移 ≤ `ε_a`，则对 `k` 技能组合：
```
|cover(C,A_T) − cover(Ĉ,A_T)| ≤ k·(ε_a + ε_rep)
```
故 `cover(C,A_T) ≥ θ_cov + k(ε_a+ε_rep)` 时，重建/升级后仍覆盖 `A_T`。
*证明*：逐项三角不等式；交集与 Jaccard 对 `L∞` 扰动均为 1-Lipschitz。

**定理 2（公共分量折扣）**
设 `S_i=c+x_i`，`c` 为公共分量，`x_i` 私有且 iid。若赛场以概率 `α` 采用公开改进，则公共改进的一阶名次收益为 `(1−α)`，私有改进为 1；`α→1` 时 `∂E[rank]/∂c→0`。
*证明*：`E[rank]=(1/n)Σ_j P(S_j<S_0)`，采用者的 `c` 在成对比较中相消，仅未采用者贡献差额。

**定理 3（共享技能样本效率）**
若 `p_t=σ(⟨W_t,θ⟩)`，`θ∈ℝ^d`，`d≪|T|`，CAP 为随机线性 bandit，Bayesian regret `O(d√(T log T))`，优于独立臂的 `Ω(√(|T|T))`；误指定 `W` 的额外 regret 与 `‖Ŵ−W‖` 同阶。
*证明*：线性 bandit 标准界 + 独立臂分解下界 + 奖励 Lipschitz 性。

### 3.1 玩具推导：为什么「抄公开基线」在排名制里会失效

设 8 个对手，公共分量 `c=0`，私有分量 `x_i∼N(0,1)`，本方私有分量 `x_0=0`。若本方投入 `δ=0.5` 到公共分量，且 7/8 的对手也采用（`α=0.875`），则本方只超过 1 个未采用者，名次提升约 `1/8`；若同样 `δ=0.5` 投入私有分量，则按正态 CDF 超过约 `Φ(0.5)=0.691` 的对手，名次提升约 `5.5/8`。该比值随 `α→1` 进一步扩大，说明 **HEDGE 的 `ρ_herd` 惩罚不是风格选择，而是排名制的一阶条件**。实际比赛中 `α` 无法精确观测，故用公开证据覆盖率与策略余弦相似度做保守估计。
