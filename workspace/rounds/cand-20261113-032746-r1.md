# 第 64 轮（承接第 63 轮「LIRO」IP-193~203；灵感循环 III 第 1 轮；本轮灵感：「用户测试」×「可靠性」）

> 第 63 轮 LIRO 把 ROSE 升级为「几何 × 技能 × 干扰」三层闭环，并给出单回合证书 J_liro。但它在两个维度上是空的：
> 1. **时间维度（可靠性）**：J_liro 是「单回合、最坏情况、纯物理」的鲁棒证书。**鲁棒 ≠ 可靠**——它不回答「部署 10⁴ 回合后的累计失效概率是多少」「MTBF 是否在增长」「哪个失效模式贡献了最大风险」，也没有故障分类、可靠性分配、冗余降级与可靠性增长。最坏情况有界（ρ_rob、ρ_dir）不代表长时失效率低。
> 2. **人维度（用户测试）**：Shield-Skill 的 ask_clarify 是临时兜底，没有用户模型，不测量澄清负担 / 信任 / 工作负荷，也没有把人类当作闭环中**随机、非平稳、会犯错**的组件。人类既可能是可靠性的贡献者，也可能是最大的失效源之一。
> 3. **第 63 轮最大风险（OOD 几何幻觉）恰恰只能靠测试发现**，但 E211–E220 是离线、静态、一次性的，缺少**统计功效驱动的在线微测试**与**可靠性引导的测试调度**，无法把「测试证据」转化为「可靠性结论」。

## 0. 直觉与动机

**灵感 1（用户测试 → UTH：User Test Harness 在线用户测试运行时）**
直觉：第 63 轮的测试是「研发阶段在固定测试集上跑一遍」。用户测试的真正价值不在「过一遍」，而在于**把用户当作闭环里的语义传感器**：他们能看到系统看不到的错误（拿错物体、误解意图、不方便时接管），并在系统过度自信时提供反证。UTH 把用户测试从「阶段」变成**与部署并行的在线微测试运行时**：在真实任务中注入可随机化的微探针（任务细微变体、澄清问题、轻量故障注入、影子模式对照），用序贯检验（SPRT / e-process）在最少样本下判断性能是否退化。测试不再是阶段，而是**常驻的统计监测器**。

**灵感 2（用户测试 → BUM + ACI：贝叶斯用户模型 + 主动澄清接口）**
直觉：Shield-Skill 的 ask_clarify 是「违规就发问」的临时兜底——既不知道用户会不会答对，也不计澄清的认知负担。**人类本身是随机、非平稳、会犯错的组件**：信任会过冲（over-trust）或不足（under-trust），工作负荷会改变响应质量，疲劳会造成漂移。BUM 用贝叶斯滤波维护隐状态 u_t=(信任、负荷、专长、意图一致性、疲劳)，输出人类可靠度 R_H(u)。ACI 由**价值信息（VoI）/ 单位负担**选择澄清问题，把「发问」从安全兜底升级为**可靠性最优的交互投资**：用最少的问题换取最大的决策熵下降。

**灵感 3（可靠性 → RCL：Reliability-Centered Loop 可靠性中心闭环）**
直觉：J_liro 是单回合最坏情况证书——它保证「这一回合在球和干扰集内安全」，却不回答「1 万回合后累计失效概率」「失效率是否随时间下降」「哪个部件贡献最大风险」。可靠性工程给出一整套成熟语言：**故障树 / FMEA**（失败如何组合）、**时变失效率 / 生存函数**（失败随时间的分布）、**可靠性分配**（把总失效预算分给部件）、**可靠性增长 Duane / Crow-AMSAA**（MTBF 是否在变好）、**冗余与恢复块**（失效后如何降级）。RCL 把这套语言架在 LIRO 之上，把「鲁棒」升级为「可证明的长时可靠」。

**灵感 4（合流 → HURL：Human-in-the-loop User-Reliability Loop）**
直觉：用户测试提供**证据流**（含人类失误、澄清结果、信任漂移），可靠性模型提供**测试优先级**（哪个失效模式最该测）。二者构成正反馈：可靠性模型用故障树重要度指出「最脆弱的失效模式」→ UTH 生成针对性的用户微测试 → 证据回流更新用户模型与失效率 → 可靠性预算重新分配。**不是「先测试后认证」，而是「测试即可靠性增长、可靠性引导测试」**。核心不变量：任何一次部署都要同时满足 ① 单回合安全 J_liro；② 长时可靠性下界 MTBF_L ≥ 要求；③ 人机协同可靠度 R_H 校准在带内。

**灵感 5（LIRO 组件的原位升级）**
- **Shield-Skill → ACI**：固定 ask_clarify 升级为 VoI/负担最优的澄清查询，只在「问得值」时发问。
- **AIC → AIC-R**：干扰集扩展人类干扰 η_H（误操作、响应延迟、指令歧义），ρ 认证加入人因项 R_H 与信任校准误差。
- **SSB → RLB (Reliability Ledger)**：场景银行同时是**失效账本**，每次险情按故障树基本事件归因，供 FTA/HRM 使用。
- **OCB-Skill → TSR**：预算老虎机从「算力臂」扩展到「测试臂」，按故障树重要度调度测试预算。
- **J_liro → J_hurl**：证书追加 MTBF 置信下界、任务时域生存概率、信任校准误差、逐部件失效预算。

## 1. 形式化定义（增量：定义 201–216）

- **定义 201（HURL 闭环）**：HURL = (LIRO, UTH, BUM, ACI, FTA, HRM, RBA, RGM, RSP, TSR, J_hurl)。三时间尺度：实时（1–10kHz，完全不改）、语义（10–100Hz）、**可靠性（每 N=100 回合或 1 小时批处理）**。不变式：可靠性线程只写阈值/分配，实时线程只读，零学习写操作。
- **定义 202（UTH 用户测试运行时）**：UST = (𝒯, 𝒰, ℱ, Ω, P, B_test)。微测试 m_k ~ P = (task t~𝒯, user u~𝒰 分层抽样, fault f~ℱ, probe 类型)；观测 y_k（成功/时延/错误/接管）与 o_k^H（话语、响应时延、NASA-TLX 负荷、信任量表 TII）。区分影子测试（不影响执行）与交互测试（用户可见）。
- **定义 203（序贯检验证据）**：用 e-process E_t = Π_k (1 + λ_k(X_k − μ_0))（H0 下为超鞅）或 SPRT(α_t, β_t) 做 anytime-valid 监测；E_t ≥ 1/α_t 即拒绝「无退化」。测试功效 1−β 与最小可检测效应 MDE 决定预算 B_test。
- **定义 204（BUM 用户状态模型）**：u_t = (τ_t 信任, w_t 负荷, e_t 专长, ι_t 意图一致性, f_t 疲劳) ∈ [0,1]^5；转移 u_{t+1}=f_u(u_t,c_t)+ω_t，观测 a_t^H=π_H(u_t,c_t,task)+ν_t；p(u_t|h_t) ∝ p(a_t^H|u_t,c_t)∫p(u_t|u_{t−1},c_{t−1})p(u_{t−1}|h_{t−1})。人类可靠度 R_H(u)=E_task[𝟙(correct)|u]。
- **定义 205（信任校准）**：客观可靠度 τ_t^* = P(success | context)（由 HRM 估计）；校准误差 e_τ=|τ_t−τ_t^*|，L_cal=E[(τ_t−τ_t^*)²]。over-trust 𝟙[τ_t>τ_t^*+δ_τ]，under-trust 𝟙[τ_t<τ_t^*−δ_τ]；依赖动作（接受/核验/接管）由 τ_t 决定。部署门槛 L_cal ≤ δ_cal。
- **定义 206（ACI 主动澄清）**：候选查询 Q(x,θ)；VoI(q)=H(decision|h)−E_a[H(decision|h,a)]；负担 b(q)=β₁E[t_resp]+β₂w_load+β₃privacy_risk；q^*=argmax_q VoI(q)/b(q)。当 Shield-Skill 投影距离 > δ_skill 时，ACI 用查询替代固定 default_theta。
- **定义 207（FTA 失效分类与故障树）**：基本事件 B 为组件失效模式；相干故障树 T 的顶事件为系统失效；最小割集 MCS。FMEA 项 (mode, S, O, D)，RPN=S·O·D；RLB 将每次险情归因到基本事件。
- **定义 208（HRM 时变失效率）**：λ(t|z_t)=λ₀(t)exp(βᵀz_t)（Cox）或 Weibull λ(t)=(k/η)(t/η)^{k−1}；协变量 z_t=[1/ρ_rob, 1/ρ_dir, geo_conf, e_τ, w_t, ood_score, skill_switch_rate, clarification_count]。Λ(t)=∫₀^t λ，S(t)=e^{−Λ(t)}。
- **定义 209（累积风险预算）**：全局预算 α_total = P[failure within T_mission]；按定义 210 分解为逐基本事件预算 α_i，并保留 α_res=20%·α_total 给未建模失效（unknown-unknown）。
- **定义 210（RBA 可靠性分配）**：Birnbaum 重要度 I_i=∂P[top]/∂P[B_i]；α_i=α_total·I_i/Σ_j I_j，约束 α_i∈[α_i^min, α_i^max]；相干系统一阶近似 P[top]≈Σ_i I_i P[B_i]。
- **定义 211（RGM 可靠性增长）**：Duane：MTBF_cum(T)=aT^b（0<b<1）；Crow-AMSAA：E[N(T)]=λ₀T^β（β<1）。演示下界（定时截尾）MTBF_L=2T/χ²_{1−α,2N+2}；部署门槛 MTBF_L ≥ MTBF_req。
- **定义 212（RSP 可靠性监督与恢复）**：状态机 {nominal, watch, degraded, safe_stop}；触发条件 λ̂(t)>λ_max、J_hurl 失效、e_τ>δ、geo_conf、S(t)<S_min。恢复块：主 LIRO → 独立验收检查 → 降级到安全技能 / 缓存技能 / ACI 求助 / 安全停机；N-version（CSP vs 贪心规划）分歧 > δ_vote 进入 watch；记录 MTTR。
- **定义 213（TSR 测试调度）**：臂 = (失效模式 j, 严重度层 s)；失效率先验 Gamma-Poisson；奖励 = log MTBF 后验方差下降 + 新失效发现 + I_j；Thompson 采样 / EXP3。目标逼近 oracle 分配 r^*=argmax_j I_j·uncertainty_j。
- **定义 214（J_hurl 证书）**：J_hurl=(J_liro, R_H, L_cal, λ̂(t), S(T_mission), {α_i}, MTBF_L, FTA_ver, UTH_ver, BUM_ver, hurl_hash)；Valid ⇔ Valid(J_liro) ∧ MTBF_L≥MTBF_req ∧ L_cal≤δ_cal ∧ S(T_mission)≥1−α_total ∧ 无开放 S 级 FMEA 项 ∧ UTH 功效≥1−β。
- **定义 215（演示可靠性）**：在置信度 1−α 下的 MTBF 下界（定时/定数截尾），以及 Gamma 后验的贝叶斯可信下界；两者取小作为部署判据。
- **定义 216（用户测试协议）**：预注册假设、按「专长 × 基线信任 × 语言文化」分层抽样、随机化微探针、必要盲法、知情同意与隐私（日志差分隐私）、功效分析 n≥n_min(α,β,MDE)；外部效度要求用户分布覆盖 ≥1−γ。

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 5（可靠性分配保守性）**：相干故障树的并集界 P[top] ≤ Σ_i P[B_i] = Σ_i α_i；Birnbaum 一阶分配 α_i ∝ I_i 在保持一阶等号下最小化总预算，故 P[top] ≤ α_total + o(α_total²)，再叠加 20% 未建模保留 → 证书对未建模失效有显式余量。
- **引理 6（人机串联可靠度）**：若技能序列需要 k 次人工确认、每次在给定 u 下正确概率 R_H，则 R_sys = R_auto·R_H^k；ACI 在保持决策误差 ≤ε 的前提下把 k 降到 k'≤k，则 R_sys' / R_sys = R_H^{k'−k} ≥ 1，且澄清负担 ∝ k'。
- **定理 4（ACI 负担-可靠性前沿）**：把澄清决策视为对决策相关隐状态的贝叶斯假设检验，由 Chernoff/Wald 序贯分析，达到误差 ε 所需期望查询数 k(ε)=⌈log(1/ε)/D⌉（D 为两假设 KL 散度）；ACI 选 VoI/负担最大者，故在同等负担预算下 k_ACI ≤ k_fixed 且 R_sys 不降，R(B) 前沿为凹、斜率等于 Lagrange 乘子。
- **定理 5（可靠性增长可检测性）**：定时截尾演示需测试时长 T ≥ M·χ²_{1−α,2r+2}/2（r 个失效）才能以置信 1−α 宣称 MTBF≥M；检测 Duane 增长率 b 的功效分析给出 N ≥ ((z_{1−α}+z_{1−β})/(b ln(T₂/T₁)))²。
- **定理 6（测试调度遗憾界）**：对 K 个失效模式的 Gamma-Poisson 后验做 Thompson 采样，随机遗憾 O(Σ_j log T/Δ_j)（Δ_j 为与最优臂的差距）；对抗情形 EXP3 遗憾 O(√(KT log K))；相对均匀分配，测试效率提升 ≥ 1+η_corr。
- **实时性**：UTH/BUM/FTA/HRM/RBA/RGM/TSR 全在可靠性线程（每 N 回合或离线），实时路径零新增；RSP 仅 O(1) 阈值比较，仍满足第 63 轮 ≤2ms 契约（A88）。

## 5. 本轮最大风险

**一句话**：若用户样本有偏（只测合作型专家用户）、测试分布被 TSR 自我强化（只测已知失效模式）、而 1e-6 级可靠性的演示需要天量样本，HURL 就会用**被污染且有选择偏差的测试证据**给出虚高的 MTBF 下界与「良好」的信任校准——可靠性证书退化为「测过即可靠」的自我确认，真实部署中的**罕见事件长尾与陌生用户群体**恰恰落在测试分布之外，这是本轮所有统计论证共同依赖的单点假设。

## 2. 形式化定义（完整版）

**定义 201（HURL 闭环）** HURL 是 LIRO 的「时间维度 + 人维度」升级：在保留第 63 轮实时/语义两时间尺度之上，新增**可靠性线程**（每 N=100 回合或 1 小时，或在险情触发时提前执行）。可靠性线程执行 [UTH 证据聚合 → BUM 用户状态更新 → FTA 失败归因 → HRM 失效率/生存更新 → RBA 预算重分配 → RGM 增长与演示下界 → TSR 测试重调度 → J_hurl 重认证]；语义线程执行 [ACI 澄清 → Shield-Skill → CSP/ERTC → LIRO 主链]；实时线程执行 [LIRO 实时路径 + RSP 的 O(1) 阈值检查]。**不变式**：可靠性线程只写阈值、分配与证书，不写实时路径的任何控制量；实时路径仍零学习写操作、≤2ms（A88）。

**定义 202（UTH 用户测试运行时）** UTH = (𝒯, 𝒰, ℱ, Ω, P, B_test)，其中 P 为**预注册**协议：假设集合、分层抽样、随机化、停止规则、盲法。微测试 m_k = (t~𝒯, u~𝒰, f~ℱ, probe)，probe ∈ {task_variant, clarification, silent_shadow, fault_injection}；观测 y_k ∈ {success, time, error_type, takeover, override} 与 o_k^H ∈ {utterance, response_latency, NASA_TLX, TII_trust, SUS}。微测试分**影子**（不改变执行，仅记录系统与用户的并行判断）与**交互**（用户可见，用于澄清/接管）两类；交互测试须经定义 216 的协议与同意流程。

**定义 203（序贯检验证据）** 对每个被监测指标（成功率、澄清正确率、接管率、信任误差），维护 e-process：
E_t = Π_{k≤t}(1 + λ_k(X_k − μ₀))，其中 X_k ∈ [0,1] 为第 k 次观测、μ₀ 为 H0 基线、λ_k 为可预测的赌注（|λ_k| ≤ 1）。H0 下 E_t 为非负超鞅，故事件 {∃t: E_t ≥ 1/α_t} 的概率 ≤ α_t（Ville 不等式），实现**随时可看、随时可停**的 anytime-valid 退化监测。备选：SPRT(α_t, β_t) 用于固定假设对。测试预算 B_test 由功效分析确定：n_min ≈ (z_{1−α}+z_{1−β})²σ²/MDE²。

**定义 204（BUM 用户状态模型）** 隐状态 u_t=(τ_t, w_t, e_t, ι_t, f_t)∈[0,1]^5，转移 u_{t+1}=f_u(u_t, c_t)+ω_t（c_t 为系统动作/澄清），观测 a_t^H=π_H(u_t, c_t, task)+ν_t（话语、响应、采纳/拒绝、接管）。贝叶斯滤波：
p(u_t|h_t) ∝ p(a_t^H|u_t,c_t) ∫ p(u_t|u_{t−1},c_{t−1}) p(u_{t−1}|h_{t−1}) du_{t−1}。
人类可靠度 R_H(u)=E_task[𝟙(correct)|u]，由离线用户研究 + 在线证据联合校准；BUM 用粒子滤波实现（|particles|=256，可靠性线程）。

**定义 205（信任校准与依赖策略）** 客观可靠度 τ_t^* = P(success | context) 由 HRM 的生存/成功模型给出。校准误差 e_τ=|τ_t−τ_t^*|，校准损失 L_cal=E[e_τ²]。定义 over-trust 事件 𝟙[τ_t>τ_t^*+δ_τ] 与 under-trust 事件 𝟙[τ_t<τ_t^*−δ_τ]（δ_τ=0.1）。依赖动作集合 {accept, verify, override}；依赖策略 π_rel(τ_t, τ_t^*) 的期望损失 L_rel = E[ℓ(accept, fail)𝟙(accept) + ℓ(verify, cost)𝟙(verify) + …]。部署门槛 L_cal ≤ δ_cal（δ_cal=0.02）。

**定义 206（ACI 主动澄清）** 候选查询 Q(x, θ)（如「是这个物体吗」「需要我轻一点吗」「继续还是停下」）。价值信息 VoI(q)=H(decision|h)−E_{a~q}[H(decision|h,a)]，负担 b(q)=β₁E[t_resp]+β₂w_load+β₃privacy_risk（β=(0.5,0.3,0.2)）。选择 q^*=argmax_{q∈Q_feas} VoI(q)/b(q)，其中 Q_feas 需满足 Shield-Skill 的 pre 约束可行性检查。当 Shield-Skill 的投影距离 ‖θ^*−θ‖_∞>δ_skill 时，ACI 用 q^* 替代固定的 default_theta 兜底；若 VoI(q^*)/b(q^*) 低于阈值 γ_ask，则直接安全停机而非打扰用户（避免「澄清疲劳」）。

**定义 207（FTA 失效分类与故障树）** 失效模式集合 FM 覆盖五层：感知 {geo_hallucination, occlusion, sensor_dropout, adversarial_pointcloud}、规划 {skill_infeasible, csp_timeout, predicate_misparse}、控制 {impedance_saturation, actuator_disturbance, tracking_error}、交互 {intent_misunderstanding, clarification_failure, trust_miscalibration, over_override}、环境 {ood_geometry, dynamic_obstacle, slippage}。相干故障树 T 的顶事件为「任务失败或安全违规」；基本事件 B 为 FM 的实例化，最小割集 MCS 由下行法计算。FMEA 项 (mode, S, O, D)，RPN=S·O·D，S/O/D∈[1,10]。RLB 将每次险情 EV_exec 归因为 (basic_event, severity, evidence_hash)。

**定义 208（HRM 时变失效率）** 采用 Cox 比例风险：λ(t|z_t)=λ₀(t)exp(βᵀz_t)，基线 λ₀ 用 Breslow 估计；协变量 z_t=[1/ρ_rob, 1/ρ_dir, geo_conf, e_τ, w_t, ood_score, skill_switch_rate, clarification_count, takeover_rate]。累积风险 Λ(t)=∫₀^t λ(s|z_s)ds，生存 S(t)=exp(−Λ(t))。以偏似然 + 贝叶斯正则（β 的 horseshoe 先验）拟合；对非比例风险用时间依赖系数 β(t) 或分层模型。非参数交叉检验：Kaplan-Meier + log-rank。

**定义 209（累积风险预算）** 目标 α_total 为任务时域 T_mission 内的允许失效概率（如 1e-4/1000h）。预算分解 α_total = Σ_i α_i + α_res，其中 α_res=0.2α_total 显式保留给未建模失效（unknown-unknown），并要求 α_res 在证书 J_hurl 中**不可被挪用**。监测：若观测失效数超过预算对应的泊松上界（Poisson 尾概率 ≤ α_alarm），RSP 进入 watch。

**定义 210（RBA 可靠性分配）** 相干系统下 P[top] ≈ Σ_i I_i·P[B_i]（一阶），I_i 为 Birnbaum 重要度。分配：α_i = α_total·(1−r_res)·I_i/Σ_j I_j，并截断到 [α_i^min, α_i^max]（α_i^min 保证每个部件都有最低监测预算，防止「从未测过」）。分配的后验不确定性用 bootstrap 故障树（1000 次重采样 MCS）给出 α_i 的置信带。重要度每轮随 FTA/HRM 更新，ΔI_i/I_i > 20% 触发重分配。

**定义 211（RGM 可靠性增长）** Duane 模型：MTBF_cum(T)=aT^b（0<b<1 表示增长）；Crow-AMSAA：E[N(T)]=λ₀T^β（β<1 表示增长）。用 MLE 估计 (a,b)/(λ₀,β)。演示下界：
- 定时截尾（N 个失效、总测试时长 T）：MTBF_L = 2T/χ²_{1−α, 2N+2}；
- 定数截尾（第 r 个失效停止于 T）：MTBF_L = 2T/χ²_{1−α, 2r}。
部署门槛 MTBF_L ≥ MTBF_req；跨轮增长判据 b>0 且 90% 置信区间不含 0；若 b≤0 则触发可靠性回归调查（对接 FTA 新增割集检查）。

**定义 212（RSP 可靠性监督与恢复）** 状态机 Q={nominal, watch, degraded, safe_stop}。迁移触发：
- nominal→watch：λ̂(t)>λ_max 或 e_τ>δ_τ 或 S(t)<S_min 或 CUSUM 检测到用户状态变点；
- watch→degraded：连续 3 次 J_hurl 校验失败，或 N-version 分歧 > δ_vote（CSP 与贪心规划器输出技能序列的编辑距离/代价差）；
- degraded→safe_stop：恢复块验收失败，或安全裕度 ρ_rob<0。
恢复块（recovery block）：主 LIRO 计算 → 独立验收检查（用 ERTC 与 J_liro 的轻量校验器，不复用主路径状态）→ 失败则 fallback ∈ {low_gain_impedance, cached_skill, ACI_ask_human, safe_stop}。N-version：CSP 与贪心规划器并行，分歧大则降级；记录 MTTR 与恢复成功率，回灌 RGM。

**定义 213（TSR 测试调度）** 臂 = (失效模式 j, 严重度层 s)。对每个 j 维护失效率后验 Gamma(α_j, β_j)（泊松观测失效数）。奖励 r_j = 后验 log MTBF 方差下降 + κ_new·𝟙(发现新失效模式) + κ_I·I_j；Thompson 采样按 θ_j~Gamma 选臂，或 EXP3 处理对抗性测试环境。与 oracle 分配 r^*=argmax_j I_j·uncertainty_j 比较遗憾。测试预算约束 Σ_k b(m_k) ≤ B_test；高严重度模式有强制最低采样（安全下界），不受 bandit 探索影响。

**定义 214（J_hurl 证书）** J_hurl=(J_liro, R_H, L_cal, λ̂(t), S(T_mission), {α_i}, MTBF_L, FTA_ver, UTH_ver, BUM_ver, test_cov, hurl_hash)。
Valid(J_hurl) ⇔ Valid(J_liro) ∧ MTBF_L ≥ MTBF_req ∧ L_cal ≤ δ_cal ∧ S(T_mission) ≥ 1−α_total ∧ (无开放 severity≥8 的 FMEA 项) ∧ (UTH 功效 ≥ 1−β) ∧ (test_cov ≥ 1−γ) ∧ (hurl_hash 与 FTA/UTH/BUM 版本一致)。
审计链：J_liro 追溯到单回合闭环；FTA_ver 追溯到故障树与割集；test_cov 追溯到用户分层覆盖；MTBF_L 追溯到测试截尾方式与失败计数。

**定义 215（演示可靠性）** 在置信度 1−α 下：
- 经典（频率学派）下界：定义 211 的 MTBF_L；
- 贝叶斯下界：Gamma(α_post, β_post) 后验的 α 分位数对应的 MTBF 下界；
- 取两者较小值作为部署判据（保守原则）。同时报告点估计与区间宽度；区间宽度 > W_max 表示证据不足，不得部署（防止「点估计达标、证据不足」）。

**定义 216（用户测试协议与外部效度）** 协议 P 须满足：
1. **预注册**：假设、主要指标、样本量、停止规则、分析计划在测试前固定；
2. **分层抽样**：用户分层 = 专长（novice/intermediate/expert）× 基线信任（low/medium/high）× 语言文化；每层 n_s ≥ n_min；
3. **随机化**：微探针在任务内随机分配，降低顺序/选择偏差；
4. **盲法**：影子测试对用户不可见；交互测试中评分者对条件盲；
5. **伦理与隐私**：知情同意、可退出、日志差分隐私（ε_dp=1.0）、本地 BUM 推断；
6. **外部效度**：用户分布覆盖 test_cov ≥ 1−γ（γ=0.1），用 importance weighting 校正分层比例偏差。
若任一条不满足，UTH 证据标记 `invalid_protocol`，不得进入 J_hurl 的 MTBF_L。

### IP-204 UTH（用户测试运行时）

```python
class UserTestHarness:
    """与部署并行的在线微测试 + anytime-valid 退化监测。"""
    def __init__(self, protocol, budget_per_hour=20, alpha=0.05):
        self.protocol = protocol                 # 预注册协议 P
        self.budget = budget_per_hour
        self.eprocess = {}                       # metric -> E_t
        self.alpha = alpha
        self.ledger = ReliabilityLedger()

    def sample_micro_test(self, arm_weights):
        # 可靠性引导：TSR 给出的 (failure_mode, severity) 权重
        fm = weighted_choice(self.protocol.failure_modes, arm_weights)
        task = sample_task(self.protocol.T, condition=fm)
        user = stratified_sample(self.protocol.U, task.user_stratum)
        probe = self._choose_probe(fm, user)
        return MicroTest(task, user, fm, probe)

    def _choose_probe(self, fm, user):
        # 已知高风险的失效模式用故障注入；交互风险用澄清探针；
        # 未知风险保留 10% 预算做 silent_shadow 随机探索（防自我强化）
        if random() < 0.10:
            return 'silent_shadow'
        if fm.layer in ('interaction', 'perception'):
            return 'clarification' if random() < 0.5 else 'task_variant'
        return 'fault_injection'

    def record(self, m, evidence):
        for metric, x in evidence.metrics.items():
            self._update_eprocess(metric, x)
        self.ledger.append(m, evidence)
        if any(E >= 1 / self.alpha for E in self.eprocess.values()):
            return {'regression': True, 'metrics': self._violating_metrics()}
        return {'regression': False}

    def _update_eprocess(self, metric, x, mu0=None, lam=None):
        mu0 = mu0 if mu0 is not None else self.protocol.baseline[metric]
        lam = lam if lam is not None else self._predictable_bet(metric)
        E = self.eprocess.get(metric, 1.0) * (1.0 + lam * (x - mu0))
        self.eprocess[metric] = max(E, 1e-12)

    def statistical_power(self, metric, mde):
        sigma = self.protocol.sigma[metric]
        n_min = ((norm_ppf(1 - self.alpha) + norm_ppf(1 - self.protocol.beta))
                 * sigma / mde) ** 2
        return n_min
```

### IP-205 BUM（贝叶斯用户模型）

```python
class BayesianUserModel:
    """粒子滤波维护 u_t=(tau,w,e,iota,fatigue)，输出人类可靠度 R_H。"""
    def __init__(self, n_particles=256, dim=5):
        self.particles = np.random.uniform(0, 1, (n_particles, dim))
        self.weights = np.ones(n_particles) / n_particles
        self.R_H_table = load_offline_user_study()   # R_H(u) 查表/回归

    def filter(self, a_H, c_t):
        # 转移
        self.particles = self._transition(self.particles, c_t)
        # 观测似然 p(a_H | u, c_t)
        lik = self._observation_likelihood(self.particles, a_H, c_t)
        self.weights = self._normalize(self.weights * lik)
        if self._ess() < len(self.particles) / 2:
            self._resample()
        return self._posterior_mean()

    def human_reliability(self, u):
        return self.R_H_table.predict(u)             # R_H(u) in [0,1]

    def trust_calibration(self, u, hrm):
        tau_star = hrm.objective_success_prob()      # P(success | context)
        e_tau = abs(u['tau'] - tau_star)
        return e_tau, e_tau ** 2, tau_star

    def change_point_score(self, a_H_history):
        # CUSUM 检测用户非平稳（疲劳/信任漂移）
        return cusum(a_H_history, self.particles.mean(axis=0))
```

### IP-206 ACI（主动澄清接口）

```python
def active_clarification(theta_prop, skill, x_prime, u, phi_hat, r,
                          beta_burden=(0.5, 0.3, 0.2), gamma_ask=0.05):
    """q* = argmax_q VoI(q)/b(q)；低 VoI 时不打扰用户，直接安全停机。"""
    candidates = build_candidate_queries(skill, x_prime, phi_hat, r)
    best, best_score = None, -np.inf
    for q in candidates:
        if not q.feasible(phi_hat, r):
            continue
        voi = expected_information_gain(q, u, skill, x_prime)   # decision entropy drop
        t_resp = predict_response_time(q, u)
        burden = (beta_burden[0] * t_resp
                  + beta_burden[1] * u['workload']
                  + beta_burden[2] * q.privacy_risk)
        score = voi / max(burden, 1e-6)
        if score > best_score:
            best, best_score = q, score
    if best is None or best_score < gamma_ask:
        return ACIAction('do_not_disturb_safe_stop')
    return ACIAction('ask', query=best, expected_voi=best_score)
```

### IP-207 FTA / RLB（故障树与失效账本）

```python
class FaultTreeAnalyzer:
    def __init__(self, fta_spec, fmea_table):
        self.tree = build_coherent_tree(fta_spec)    # 基本事件 -> 顶事件
        self.mcs = minimal_cut_sets(self.tree)       # 下行法
        self.fmea = fmea_table

    def attribute(self, evidence):
        # 将一次险情归因到基本事件（规则 + 学习分类器，输出证据链）
        probs = self.failure_classifier(evidence.features)
        basic = argmax(probs)
        return Attribution(basic_event=basic,
                           mcs=[c for c in self.mcs if basic in c],
                           severity=self.fmea[basic].S,
                           confidence=probs[basic])

    def rpn(self, mode):
        f = self.fmea[mode]
        return f.S * f.O * f.D

    def birnbaum(self, p_basic):
        # 一阶重要度：P[top | B_i=1] - P[top | B_i=0]
        return {b: self._conditional_prob(b, 1, p_basic)
                   - self._conditional_prob(b, 0, p_basic)
                for b in self.tree.basic_events}
```

### IP-208 HRM（时变失效率）

```python
class HazardRateModel:
    """Cox PH + Weibull 基线；协变量接 LIRO 的鲁棒裕度与人因指标。"""
    def __init__(self, model='cox', regularization='horseshoe'):
        self.beta = None
        self.baseline = None

    def covariates(self, M, u, hrm_ctx):
        return np.array([
            1.0 / max(M.rho_rob, 1e-3),
            1.0 / max(M.rho_dir, 1e-3),
            float(M.geo_conflict),
            hrm_ctx.e_tau,
            u['workload'],
            hrm_ctx.ood_score,
            hrm_ctx.skill_switch_rate,
            hrm_ctx.clarification_count,
            hrm_ctx.takeover_rate,
        ])

    def fit(self, ledger):
        durations, events, Z = ledger.to_survival_data()
        self.beta = cox_partial_likelihood(durations, events, Z,
                                           penalty=self.beta_prior())
        self.baseline = breslow_baseline(durations, events, Z, self.beta)

    def hazard(self, t, z):
        return self.baseline(t) * np.exp(self.beta @ z)

    def survival(self, t, z, dt=0.01):
        grid = np.arange(0, t + dt, dt)
        return np.exp(-np.sum([self.hazard(s, z) * dt for s in grid]))

    def objective_success_prob(self):
        return 1.0 - self.survival(T_mission, self.current_z)
```

### IP-209 RBA（可靠性分配）

```python
def birnbaum_allocate(alpha_total, fta, p_basic, reserve=0.20,
                      alpha_min=None, alpha_max=None):
    """alpha_i = (1-reserve)*alpha_total * I_i / sum(I)；含最低监测预算。"""
    I = fta.birnbaum(p_basic)
    budget = (1.0 - reserve) * alpha_total
    tot = sum(max(v, 0.0) for v in I.values())
    alpha = {b: budget * max(I[b], 0.0) / max(tot, 1e-12) for b in I}
    if alpha_min is not None:
        for b in alpha:
            alpha[b] = max(alpha[b], alpha_min)
    if alpha_max is not None:
        for b in alpha:
            alpha[b] = min(alpha[b], alpha_max)
    # 归一化回预算（截断后）
    scale = budget / sum(alpha.values())
    alpha = {b: v * scale for b, v in alpha.items()}
    alpha['__unmodeled__'] = reserve * alpha_total
    return alpha
```

### IP-210 RGM（可靠性增长）

```python
class ReliabilityGrowthMonitor:
    def __init__(self, mtbf_req, confidence=0.90):
        self.mtbf_req = mtbf_req
        self.conf = confidence
        self.history = []       # (T_cum, N_failures, censoring_type)

    def duane_fit(self):
        T = np.array([h.T for h in self.history])
        N = np.array([h.N for h in self.history])
        b, log_a = np.polyfit(np.log(T), np.log(T / np.maximum(N, 1)), 1)
        return np.exp(log_a), b          # a, growth rate b

    def demonstrated_mtbf(self, T, N, censoring='time'):
        # 定时截尾: 2T / chi2(1-conf, 2N+2); 定数截尾: 2T / chi2(1-conf, 2N)
        df = 2 * N + 2 if censoring == 'time' else 2 * N
        return 2 * T / chi2.ppf(1 - self.conf, df)

    def deployment_gate(self, T, N, censoring='time', width_max=None):
        lb = self.demonstrated_mtbf(T, N, censoring)
        width = self._interval_width(T, N, censoring)
        return (lb >= self.mtbf_req
                and (width_max is None or width <= width_max)), lb, width
```

```python
class ReliabilitySupervisor:
    def __init__(self, lam_max, delta_tau, s_min, delta_vote):
```

### IP-212 TSR（测试调度）

```python
class TestScheduler:
    """测试臂 = (failure_mode, severity)；Thompson 采样 + 硬性安全下界。"""
    def __init__(self, failure_modes, importance, min_samples, budget):
        self.posterior = {fm: GammaPrior(alpha=1, beta=1) for fm in failure_modes}
        self.importance = importance
        self.min_samples = min_samples
        self.budget = budget
        self.counts = defaultdict(int)

    def choose(self):
        for fm, n in self.counts.items():
            if n < self.min_samples[fm]:
                return fm                       # 高严重度强制最低采样
        samples = {fm: self.posterior[fm].sample() for fm in self.posterior}
        # 重要度加权：优先降低高重要度模式的后验不确定性
        return max(samples, key=lambda fm: self.importance[fm] * samples[fm])

    def update(self, fm, observed_failures, n_tests, new_mode=False):
        self.posterior[fm].update(observed_failures, n_tests)
        self.counts[fm] += n_tests
        reward = (self.posterior[fm].log_mtbf_variance_reduction()
                  + K_NEW * float(new_mode) + K_I * self.importance[fm])
        return reward
```

## 4. 推导

**引理 5（可靠性分配保守性）** 设故障树相干，基本事件失效集合为 {B_i}。由并集界：
P[top] = P(∪_i B_i) ≤ Σ_i P[B_i] = Σ_i α_i ≤ α_total。
由相干系统的一阶可靠性近似 P[top] ≈ Σ_i I_i P[B_i]，其中 I_i=∂P[top]/∂P[B_i]。在固定 Σα_i 下最小化 P[top] 的线性规划解为 α_i ∝ I_i，即 Birnbaum 分配。故 P[top] ≤ α_total + O(α_total²)·Σ_i I_i²/α_total = α_total + o(α_total)。再叠加未建模保留 α_res=0.2α_total，证书对未建模失效有显式余量。∎

**引理 6（人机串联可靠度）** 将每个需要人工确认的技能步骤视为串联组件，给定用户状态 u 时其正确概率为 R_H(u)。若一个任务需要 k 次人工确认、机器部分可靠度为 R_auto（由 J_liro 的 ρ 下界给出），则
R_sys(u) = R_auto · R_H(u)^k。
ACI 在保持决策误差 ≤ε 下把确认次数从 k 降到 k'（定义 206 / 定理 4），则
R_sys'/R_sys = R_H^{k'−k} ≥ 1（因 R_H≤1 且 k'≤k），且澄清负担 ∝ k'。∎

**定理 4（ACI 负担-可靠性前沿）** 设澄清针对两个决策相关假设 H₀/H₁（如「该物体可抓」vs「不可抓」），其观测分布 KL 散度为 D。由 Wald 序贯概率比检验，达到错误概率 ε 的期望样本数为 k(ε)≈log(1/ε)/D。ACI 在候选查询中选择 D/b(q) 最大者，故在负担预算 B=Σb(q_k) 下达到的最大 D 满足 D_max(B) = B·max_q(D(q)/b(q))。对偶地，达到目标 ε 所需负担 B(ε) = b(q*)·log(1/ε)/D(q*)，严格小于固定 ask_clarify（其 D 由单一固定问题给定，且可能不针对当前决策）。因此 R(B) 前沿为凹，其斜率等于 max_q D(q)/b(q)；当 VoI/b 低于 γ_ask 时最优策略是「不打扰」而非发问，解释了 ACI 的 do_not_disturb 分支。∎

**定理 5（可靠性增长可检测性）** 定时截尾试验中，若失效过程为齐次泊松、MTBF 真值为 M，则 MTBF 的 (1−α) 置信下界为 MTBF_L=2T/χ²_{1−α,2N+2}。要保证 MTBF_L ≥ M_req，需
T ≥ M_req·χ²_{1−α,2N+2}/2，
随失败数 N 增大而收紧。对于增长检测：Duane 模型 ln MTBF_cum(T)=ln a + b ln T，观测区间 [T₁,T₂] 内 MTBF 估计的对数方差 ≈ σ²/N；检验 b>0 的功效
1−β = Φ( b ln(T₂/T₁)·√N / σ − z_{1−α} )，
故 N ≥ ((z_{1−α}+z_{1−β})σ / (b ln(T₂/T₁)))²。这说明**可靠性增长的可宣称性由测试样本量决定**，不能仅凭「没有出事」宣称可靠。∎

**定理 6（测试调度遗憾界）** TSR 对 K 个失效模式的失效率维护 Gamma 后验，采用 Thompson 采样选择臂。随机（平稳）情形下，若 Δ_j 为臂 j 与最优臂的期望奖励差，则 E[R_T] = O(Σ_{j:Δ_j>0} Δ_j^{-1} log T)；对抗情形改用 EXP3，伪遗憾 O(√(KT log K))。相对均匀分配的效率增益来自重要度加权：在相同预算下，单位测试带来的 log MTBF 后验方差下降为 Σ_j I_j·Δvar_j，故最优分配把测试集中到 I_j·uncertainty_j 最大处，增长速率满足 d ln MTBF/dT ∝ Σ_j I_j Δ_j ≥ 均匀分配。∎

**命题（测试-增长耦合）** 由 RGM 的 Duane 关系 ln MTBF = ln a + b ln T，若 TSR 把测试预算从低重要度模式重分配到高重要度模式，使有效失效发现率提升因子 η_corr≥1，则演示 MTBF 下界以 O(η_corr) 的速度收紧：MTBF_L^{-1} ∝ χ²_{2N+2}/T，而 N/T 提升 η_corr。因此**测试调度直接改变可靠性增长的斜率**，这是 HURL 把「测试」与「可靠性」耦合的定量基础。∎

## 7. 已知风险

**一句话**：若用户样本有偏（只测合作型专家用户）、测试分布被 TSR 自我强化（只测已知失效模式）、而 1e-6 级可靠性的演示需要天量样本，HURL 就会用**被污染且有选择偏差的测试证据**给出虚高的 MTBF 下界与「良好」的信任校准——可靠性证书退化为「测过即可靠」的自我确认，真实部署中的**罕见事件长尾与陌生用户群体**恰恰落在测试分布之外，这是本轮所有统计论证共同依赖的单点假设（A83/A84/A87）。

**次级风险与缓解**：
1. **用户样本选择偏差**：分层抽样 + importance weighting + 每轮保留 20% 从未参与建模的 held-out 用户簇做外部效度检验；偏差超阈值则拒绝认证。
2. **罕见事件盲区**：1e-6 级失效用重要性采样 / 子集模拟（subset simulation）/ 加速寿命试验补足；α_res=20% 显式保留给未建模失效；报告区间宽度，证据不足拒绝部署。
3. **Goodhart / 测试过拟合**：预注册 + anytime-valid e-process + 盲测批次 + 测试集轮换；禁止用同一批测试既调参又认证。
4. **TSR 自我强化**：强制 10% 预算用于 silent_shadow 随机探索；新失效模式发现奖励 κ_new；定期均匀测试审计。
5. **用户非平稳（疲劳/信任漂移）**：BUM 的 CUSUM 变点检测 + 周期性重校准 + 疲劳触发的会话长度限制。
6. **风险模型设定错误**：Cox 与 Weibull 双模型 + Kaplan-Meier 非参数交叉检验 + 后验预测检查；校准失败则退回保守上界（不认证）。
7. **测试伦理与隐私**：知情同意、可退出、日志差分隐私（ε_dp=1.0）、BUM 本地推断不上传原始交互；交互测试仅在高风险场景启用，避免打扰用户。
