# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感驱动研究循环本轮——灵感：「动作分块」×「基线复现」）

> 第 59 轮把「执行」接上了物理与时间：BUQ 在线辨识电机结构性不确定性、ERTC 把实时性契约化、EEIS 把 δ_f 编译成带证书的阻抗参数。但它仍默认：**一次承诺 = 一个原子动作 / 一次接触**。本轮两个灵感恰好击中这个「分析单元」假设：**动作分块**说明真实部署执行的是**一段开环或半开环的动作序列**（ACT / Diffusion Policy 的 chunk + temporal ensembling + receding horizon），承诺天然是**时间上的一个块**；**基线复现**说明任何「更安全 / 更好」的结论都必须在**同一实验架、配对种子、预注册协议**下可重复，单次证据不足以支撑结论。二者把「分析单元」从**单步 / 单次**上移到**分块 / 复现**。核心数学后果是**聚合单元内部的相关性**：块内各步共享同一环境隐变量、同一策略与同一状态漂移；复现内各 run 共享种子、硬件与数据切分。因此子集内 i.i.d. / 可交换假设——联合界、共形校准、t 检验——会同时失效。本轮命题：**把承诺与证据的单元上移为「分块 / 复现」，并显式建模单元内相关性；用可达管保证块级安全，用块共形保证校准，用安全滤波时序集成保证边界，用复现证书与基线金丝雀保证结论与环境漂移可检出。**

核心矛盾：
- **H32（分块风险相关·联合界的两难）**：单步 δ_k 直接相乘 / 按 `1-(1-δ)^K` 聚合，隐含**步间独立**；但块内各步共享环境隐变量、策略状态、执行器温升与 ξ_exec，失效事件通常正相关。正相关下简单乘积极可能**低估**块失效概率（危险）；而联合界 `Σδ_k` 虽绝对安全却**过保守**（机器人又慢又笨）。必须在「硬联合界」与「校准界（块共形）」之间显式切换，并给出可交换性检验与回退规则，而不是二选一后假装安全。
- **H33（开环陈旧与边界突变）**：块是开环执行的，t 时刻的证书在 t+k 时刻未必仍成立：环境变化、证据过期、契约违例、证书版本失效都会让「继续跑完剩余块」变成默认不安全。跨块拼接若直接换动作，会产生力/加加速度尖峰；若用 temporal ensembling 平滑，又可能把「安全动作 + 不安全动作」平均成一个**未认证的中间动作**。需要失效谓词、≤1 周期中止、边界混合约束与**安全滤波**集成。
- **H34（复现危机·证据本身不可复现）**：宣称的改进可能是种子彩票、调参泄漏、测试集污染或选择性报告；单次运行的安全估计方差极大。若系统用不可复现的证据去**放松安全**（减少探针 / 加宽可承诺范围），本质是「对安全做 p-hacking」。需要预注册、配对种子、块 bootstrap 置信区间、多重比较校正、污染审计；并且需要运行时**基线金丝雀**来检测环境漂移与固件回归。复现证据只能让系统更保守，绝不能减少证据需求。

## 0. 直觉与动机

**灵感 1（动作分块 → 分块承诺证书 CCC）**
直觉：动作分块的本质不是「一次预测 K 个动作」，而是**在不再观测的前提下，对一段时域下注**。单点证书只覆盖 t 时刻的一个状态；开环执行 K 步，状态会走出证书点。安全的最小单元因此不是点，而是**管（tube）**：在 ξ_exec 后验与实时契约给出的有界扰动集 W 下，把可达集向前传播 K 步；只要整条管都留在已认证安全集 S_safe 内，这个块才可承诺。于是**块长 K 成为决策变量**：K 大则摊销推理延迟、减少重规划抖动、提升时序一致性，但管更粗、风险更大、反应更慢；K 小则反应快，但边界抖动与重规划开销上升。K 应由不确定性、相关性、漂移率与延迟预算共同决定，而不是手设超参。

**灵感 1'（块边界 → 安全滤波时序集成 STE）**
直觉：相邻块在重叠区往往给出不同动作，直接拼接会出现力尖峰；ACT 的 temporal ensembling 用指数权重平滑，但它默认「平均后的动作仍然安全」，这在带证书的系统里不成立——两个各自安全的动作，其加权平均可能落在安全集之外（安全集非凸）。正确做法是**先集成、再认证**：若集成结果不满足认证（或局部管检验失败），投影到各块安全动作集的交集；交集为空则退回最新认证块，再退安全保持。块间分歧本身是有用信号：它类似跨模态分歧，表明「时序模态」内部不一致，应触发减速、缩短 K 或补探针。

**灵感 2（基线复现 → 复现证书 RepCert 与基线金丝雀 BCP）**
直觉：如果「新策略更安全」没有在同一 harness、同一组配对种子上复现基线，这个结论没有意义。更进一步，复现可以是**在线传感器**：保留一个归档基线策略与参考遥测分布，定期影子重放或比较固定校准例程；若基线行为分布发生漂移，说明**世界或平台本身变了**（负载、温度、固件、传感器），那么所有历史共形校准与证书都可能失效。这把「可复现性」从论文里的元要求，变成运行时安全链的一环：离线用复现证书约束「改进」声明，在线用金丝雀约束「世界没变」假设。

**灵感 3（合流 → 分块-复现证据 CRE）**
直觉：两个灵感统一为「聚合单元相关性」问题：块内相关破坏逐点校准与联合界，复现内相关破坏独立同分布统计。应对是三条同构策略：**(a) 时间维**用管 + 块共形；**(b) 动作维**用安全滤波集成；**(c) 证据维**用配对/块统计 + 金丝雀。再叠加预算：分块预算 B_chunk 与复现预算 B_rep 进入 PCE++++，块长与探针数联合优化。所有新通道保持**单向保守**：EV-rep / D_chunk 只能触发加宽、重校准或降级，不能减少探针与佐证需求。

## 1. 形式化定义（增量：定义 153–160）

**定义 153（分块承诺证书 CCC）** 分块承诺 π_chunk = (s_t, K, {a_{t+k}}_{k=0}^{K-1}, C_tube, Cert_chunk)。离散动力学 x_{k+1} = f(x_k, a_{t+k}) + w_k，w_k ∈ W(ξ_exec)（由 BUQ 后验与 ERTC 契约给出有界扰动集）。鲁棒可达管 R_0 = {s_t}，R_{k+1} = f(R_k, a_{t+k}) ⊕ W。可承诺条件：R_k ⊆ S_safe(lv)（∀k=0..K−1），且边界条件 B(π_chunk) 成立（见定义 155/156）。块失效事件 F_chunk = ∃k≤K：x_k ∉ S_safe ∨ 力/速度越界。证书 Cert_chunk = (K, δ_chunk, {δ_k}_{k=0}^{K−1}, ρ̄, tube_hash, blend_params, version)，其中 ρ̄ 为块内平均失效相关性估计。**K 是决策变量，而非超参数。**

**定义 154（块级风险聚合与块共形 CRA）** 给定每步失效概率 δ_k。
- **硬界（无需任何独立性假设）**：δ_chunk^hard = min(1, Σ_k δ_k)（联合界）。
- **校准界（需要块可交换假设 A-CRA）**：块非一致性分数 S_i = max_{k≤K} score(x^{(i)}_{t+k}, a^{(i)}_{t+k})；用 N 个历史块校准 q̂ = Quantile_{⌈(N+1)(1−α)⌉/N}({S_i})，则新块覆盖率 P(S_new ≤ q̂) ≥ 1−α（块共形，块为交换单位，块内无需独立）。
- **相关性刻画（仅用于预算与解释，不作安全界）**：ρ̄ = (1/(K−1))·Σ_{l=1}^{K−1} ρ_l，有效步数 K_eff = 1 + (K−1)ρ̄。
- **禁止项**：不得把 `δ_chunk = 1−(1−δ)^K` 当作安全界（隐式独立 / 指数尾部假设）；它只能作为效率模式的粗估，且必须通过**块可交换性检验**（块置换检验 / 双样本 KS，p > 0.05）才允许使用校准界。
- **双模式**：SAFE 模式只用 δ_chunk^hard；EFF 模式可用 min(δ_chunk^hard, 校准界)。检测到漂移 / 检验失败 / 契约违例 ⇒ **立即切回 SAFE**（单向）。

**定义 155（分块执行不变量与失效中止 CEI）** 运行时观测 x̂_k。失效谓词
`Inv_k = (x̂_k ∉ R_k) ∨ (t−t_0 > τ_chunk_max) ∨ (¬contract_ok) ∨ (τ_evidence > Renewal_period) ∨ (D⁺ > θ_D) ∨ (Cert expired)`。
触发 Inv ⇒ 立即中止剩余块、冻结并回退到最近认证安全动作（safe hold），在 ≤1 个控制周期内完成切换，记录 abort_cause。跨块边界用混合系数 λ∈[0,1]：a_blend = (1−λ)a_old + λa_new，约束 ‖a_blend − a_old‖ ≤ v_maxΔt 且 |ΔF| ≤ ΔF_max；无可行的 λ ⇒ 保持 / 停。**禁止「带病续跑剩余块」。**

**定义 156（安全滤波时序集成 STE）** 重叠块 {π_i} 的权重 w_i（新近度与证据质量），候选 a_t^ens = Σ_i w_i a_{t,i} / Σ_i w_i。安全滤波：若 a_t^ens ∉ ∩_i A_i^safe 或局部管检验失败，则投影到交集；交集为空 ⇒ 回退到最新认证块 a_{t,newest}；再不可行 ⇒ safe hold。块间分歧 D_chunk = max_{i,j}(‖a_{t,i} − a_{t,j}‖ / a_scale + TV(lbl_i, lbl_j))。D_chunk 作为「时序模态」进入 XMC+：高分歧 ⇒ 缩短 K、降低速度、增加探针；**不得用集成的一致性减少证据需求**。

**定义 157（基线与复现证书 RepCert）** 预注册哈希 h_pre（指标集 M、阈值 δ_min、种子集 S、分析计划、停止规则）。配对设计：基线 π_base 与处理 π_treat 在相同种子 / 场景下运行（common random numbers）。效应 Δ = E[m_treat] − E[m_base]，用配对块 bootstrap（块 = episode，处理 episode 内相关）得单侧 (1−α) 置信区间 [L, U]；多重比较用 Holm 校正。**可复现改进** iff L > δ_min。种子敏感度 SI = std_seeds(m) / |mean_seeds(m)|；污染审计覆盖测试集重叠、调参泄漏、选择性报告。RepCert = (h_pre, S, M, Δ, [L,U], SI, contamination_ok, power, version)。

**定义 158（复现证据 EV-rep 与基线金丝雀 BCP）** 归档基线 π_base 及参考遥测分布 P_ref。金丝雀统计量用 MMD / 能量距离 / e-value；漂移判定控制误报 ≤ α_drift，在漂移强度 ≥ ε_drift 时检测延迟 ≤ τ_detect。回归探针：在当前固件 / 参数栈上**影子重放**归档基线，若指标低于历史置信下界 ⇒ regression_flag。EV-rep = (repro_ok, drift_flag, regression_flag, SI, τ_rep)。规则：**(R1-rep)** EV-rep 只能加宽后验 / 触发重校准 / 降级；**(R2-rep)** 不得作为 EV-xmodal / EV-human 的替代佐证，也不得减少探针或证据门要求；**(R3-rep)** 漂移或回归 ⇒ CRA 立即从 EFF 切回 SAFE、缩短 K*、重新校准共形集。

**定义 159（分块-复现预算 PCE++++ 与自适应块长）** B_chunk = (K_max, tube_slack, stale_slack)，B_rep = (canary_budget, repro_compute)。分块 VOI：
`VOI_chunk(π) = EIG(π; M) − λ_risk·δ_chunk(π) − λ_stale·τ_chunk(π) − cost_rep(π)`，
K* = argmax_{K ≤ K_max} VOI_chunk，且随 ξ_exec 不确定度、ρ̄、漂移率、延迟预算自适应；检测到漂移 ⇒ K* ← min(K*, K_drift_safe)。六重预算（B_probe, B_ft, B_ux, B_exec, B_chunk, B_rep）单调消耗、互不挪用；任一耗尽 ⇒ 更保守（缩短块 / 绕行 / 降级 / 停）。

**定义 160（分块执行证书 J_chunk 与 JCPS+++）** J_chunk = (tube_traj, per_step_cert, invalidation_log, blend_log, RepCert_chain, canary_log, budget_snapshots, version)。JCPS+++ 在 JCPS++ 输出上追加：(K*, δ_chunk, ρ̄, tube_id, D_chunk, Inv_log, RepCert, EV_rep_latest, drift_state, B_chunk_snapshot, J_chunk)。

```python
@dataclass
class ChunkCertificate:
    K: int
    delta_chunk_hard: float
    delta_chunk_cal: float
    mode: str                  # 'SAFE' | 'EFF'
    rho_bar: float
    tube_hash: int
    per_step_delta: list
    version: int

class ChunkCommitmentCompiler:
    def compile(self, s_t, policy, delta_chunk_req, K_max):
        best = None
        for K in range(1, K_max + 1):
            A = policy.propose(s_t, K)                 # 分块动作提议
            tube = self.propagate_tube(s_t, A)         # R_0..R_{K-1}，鲁棒可达集
            if not all(self.S_safe.contains(R) for R in tube):
                break                                  # 管出安全集，更长 K 只会更差
            delta_step = delta_chunk_req / K           # 风险分配
            d_hard = min(1.0, K * delta_step)          # 联合界，恒等于需求
            mode = 'SAFE'
            d_cal = float('inf')
            if self.block_calib.exchangeability_ok():  # 块可交换性检验通过才允许 EFF
                mode = 'EFF'
                d_cal = self.block_calib.quantile(alpha=delta_chunk_req)
            cert = ChunkCertificate(
                K=K, delta_chunk_hard=d_hard, delta_chunk_cal=d_cal,
                mode=mode, rho_bar=self.estimate_rho(A),
                tube_hash=hash(tube),
                per_step_delta=[delta_step] * K, version=self.version + 1)
            # 目标：安全前提下最大化 K（摊销延迟/减少抖动），次选更柔顺
            best = cert if (best is None or cert.K > best.K) else best
        return best

class BlockConformalCalibrator:
    def __init__(self, alpha):
        self.alpha, self.scores, self.ref_scores = alpha, [], []

    def add_block(self, block_score):
        self.scores.append(block_score)

    def quantile(self):
        N = len(self.scores)
        if N == 0:
            return float('inf')
        level = math.ceil((N + 1) * (1 - self.alpha)) / N
        return np.quantile(self.scores, min(level, 1.0), method='higher')

    def exchangeability_ok(self, window=30):
        if len(self.scores) < window or len(self.ref_scores) < window:
            return False                           # 样本不足 ⇒ 退回 SAFE
        return permutation_test(self.scores[-window:],
                                self.ref_scores[-window:]) > 0.05
```

```python
class BaselineCanary:
    def __init__(self, baseline_policy, ref_dist, alpha_drift=1e-3, eps_drift=0.05):
        self.pi_base = baseline_policy
        self.ref_dist = ref_dist
        self.alpha_drift, self.eps_drift = alpha_drift, eps_drift

    def probe(self, live_telemetry):
        stat = mmd(self.ref_dist, live_telemetry)       # 或能量距离 / e-value
        thr = self.calibrate_threshold(self.alpha_drift)  # 参考期置换校准

        return EVRep(drift_flag=drift, regression_flag=regression,
                     tau_rep=now() - self.last_probe)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CCC | O(K·(n_x³ + 集合运算))；线性动力学 O(K·n_x²) | O(K·n_x) | 可达管过近似音完备；管 ⊆ S_safe ⇒ 块内安全 |
| CRA | 硬界 O(K)；块共形校准 O(N·K)，查询 O(1) | O(N) | 联合界免假设；块共形在 A-CRA 下覆盖 ≥1−α；检验失败回退 |
| CEI | O(1)/步（管成员检验 O(n_x)） | O(K) | 任何管越界 ≤1 周期内中止，禁止续跑 |
| STE | O(M·d_a)/步（M 个重叠块） | O(M·d_a) | 集成结果未认证 ⇒ 投影 / 回退 / 保持，绝不发未认证动作 |
| RepCert | 离线 O(N_seed·N_ep·T) | O(N_seed·N_ep) | 预注册 + 配对块 bootstrap，类型 I 误差 ≤α |
| BCP | MMD O(n_ref·n_live·d)；e-value O(n·d) | O(n_ref) | 误报 ≤α_drift；漂移 ≥ε_drift 时延迟 ≤τ_detect |
| PCE++++ | O(\|CP\|·(k_p+k_c+k_ft+k_ux+k_exec+k_chunk)·(C_VOI+tube)) | 复用各层 | 预算单调、互不挪用、耗尽即保守 |

**正确性定理（Chunked Reproducible Evidence Soundness, CRES）**
假设 A22–A55 成立；新增：
**(A56)** 块动力学与扰动集 W(ξ_exec) 诚实包住真实执行；**(A57)** 可达管传播为音完备过近似；**(A58)** EFF 模式下块可交换性检验有效，否则失败即回退 SAFE；**(A59)** CEI 对任何管越界 / 陈旧 / 契约违例 ≤1 控制周期内检出；**(A60)** STE 的安全滤波音完备：不可认证即投影或回退；**(A61)** RepCert 协议预注册、配对、无污染，块 bootstrap CI 有效；**(A62)** BCP 误报与检测延迟满足 (α_drift, τ_detect)。则：

1. **块安全**：SAFE 模式 P(F_chunk) ≤ Σ_k δ_k（联合界，免独立假设）；EFF 模式在 A-CRA/A58 下 P(F_chunk) ≤ α + δ_tube，且任何时候漂移/检验失败自动回退 SAFE。
2. **中止及时性**：管越界、证据过期、契约违例或证书失效后，剩余块不再被派发；中止延迟 ≤1 周期。
3. **集成安全**：派发的动作要么通过认证，要么是经投影的认证集合成员，要么是 safe hold；不存在「平均出未认证动作」的路径。
4. **复现健全性**：通过 RepCert 的「可复现改进」在预注册分析下类型 I 误差 ≤α；SI 超阈值或污染审计失败 ⇒ 声明降级为「未复现」。
5. **漂移健全性**：BCP 误报 ≤α_drift；检测到漂移 ⇒ 立即切 SAFE、缩短 K*、重校准共形集，所有旧证书标记为「待复核」，而非继续使用。
6. **单向性**：EV-rep / D_chunk / SI 只能加宽后验、触发重校准或降级；不能减少探针、证据门或佐证需求。

### IP-152 CCC（分块承诺编译器）

```python
from dataclasses import dataclass, field

@dataclass
class ChunkCertificate:
    K: int
    delta_chunk_hard: float
    delta_chunk_cal: float
    mode: str                       # 'SAFE' | 'EFF'
    rho_bar: float
    tube_hash: int
    per_step_delta: list
    blend_params: dict = field(default_factory=dict)
    version: int = 0

class ChunkCommitmentCompiler:
    def __init__(self, dynamics, safe_set, block_calibrator, version=0):
        self.f = dynamics.f
        self.W = dynamics.disturbance_set      # 由 ξ_exec 后验 + ERTC 契约给出
        self.S_safe = safe_set
        self.calib = block_calibrator
        self.version = version

    def propagate_tube(self, s_t, actions):
        """鲁棒可达管：R_{k+1} = f(R_k, a_k) ⊕ W（音完备过近似）"""
        tube = [self.S_safe.singleton(s_t)]
        for a in actions:
            tube.append(self.W.minkowski_sum(self.f(tube[-1], a)))
        return tube

    def boundary_feasible(self, s_t, actions, prev_action):
        if prev_action is None:
            return True
        # 首步与上一块末动作的连续性：速度/力变化有界
        return (self.speed(actions[0], prev_action) <= self.v_max * self.dt and
                self.force_delta(actions[0], prev_action) <= self.dF_max)

    def compile(self, s_t, policy, delta_chunk_req, K_max, prev_action=None):
        best = None
        for K in range(1, K_max + 1):
            A = policy.propose(s_t, K)
            if not self.boundary_feasible(s_t, A, prev_action):
                break                        # 更长 K 不会修复首步边界
            tube = self.propagate_tube(s_t, A)
            if not all(self.S_safe.contains(R) for R in tube):
                break                        # 管出安全集：块不可承诺
            delta_step = delta_chunk_req / K # 风险分配（硬界）
            d_hard = min(1.0, K * delta_step)
            mode, d_cal = 'SAFE', float('inf')
            if self.calib.exchangeability_ok():
                mode = 'EFF'
                d_cal = self.calib.quantile(alpha=delta_chunk_req)
            cert = ChunkCertificate(
                K=K, delta_chunk_hard=d_hard, delta_chunk_cal=d_cal,
                mode=mode, rho_bar=self.estimate_rho(A), tube_hash=hash(tuple(map(str, tube))),
                per_step_delta=[delta_step] * K,
                blend_params=self.solve_blend(A, prev_action),
                version=self.version + 1)
            if best is None or cert.K > best.K:
                best = cert
        if best is not None:
            self.version += 1
        return best
```

### IP-153 CRA（块级风险聚合与块共形）

```python
class BlockRiskAggregator:
    def __init__(self, alpha):
        self.alpha = alpha
        self.scores, self.ref_scores = [], []

    def add_calibration_block(self, block_score, is_reference=False):
        (self.ref_scores if is_reference else self.scores).append(block_score)

    def hard_bound(self, per_step_delta):
        return min(1.0, sum(per_step_delta))

    def calibrated_quantile(self):
        N = len(self.scores)
        if N == 0:
            return float('inf')
        level = math.ceil((N + 1) * (1 - self.alpha)) / N
        return np.quantile(self.scores, min(level, 1.0), method='higher')

    def exchangeability_ok(self, window=30):
        if len(self.scores) < window or len(self.ref_scores) < window:
            return False
        # 块置换检验：近期块分数是否仍与参考块同分布
        return permutation_test(self.scores[-window:],
                                self.ref_scores[-window:]) > 0.05

    def effective_steps(self, K, rho_bar):
        return 1 + (K - 1) * rho_bar

    def deployment_bound(self, per_step_delta, K, mode):
        d_hard = self.hard_bound(per_step_delta)
        if mode == 'SAFE' or not self.exchangeability_ok():
            return d_hard, 'SAFE'
        return min(d_hard, self.calibrated_quantile()), 'EFF'
```

```python
        dispatch_safe_hold(prev_safe_action)       # 冻结剩余块，≤1 周期
        return M, 'aborted'

    def blend_boundary(self, a_old, a_new, dt):
        lo, hi = 0.0, 1.0
        # 求满足 ‖(1−λ)a_old+λa_new − a_old‖≤v_max·dt 且 |ΔF|≤ΔF_max 的 λ
        for _ in range(20):
            lam = (lo + hi) / 2
            a = (1 - lam) * a_old + lam * a_new
            if (np.linalg.norm(a - a_old) <= self.cfg.v_max * dt and
                    force_delta(a, a_old) <= self.cfg.dF_max):
                lo = lam
            else:
                hi = lam
        return lo if lo > 0 else None            # None ⇒ 保持/停
```

### IP-155 STE（安全滤波时序集成）

```python
class SafetyFilteredTemporalEnsembler:
    def __init__(self, certifier, a_scale):
        self.certifier = certifier
        self.a_scale = a_scale

    def combine(self, active_chunks, t):
        num, den = 0.0, 0.0
        for pi in active_chunks:
            a = pi.action_at(t)
            if a is None:
                continue
            w = pi.weight(t)                   # 新近度 × 证据质量
            num += w * a
            den += w
        if den == 0:
            return None, float('inf')
        a_ens = num / den
        # 先集成、再认证：不安全就投影到各块安全集交集
        if not self.certifier.certifies(a_ens, t):
            safe_sets = [pi.safe_action_set(t) for pi in active_chunks]
            a_proj = project_to_intersection(a_ens, safe_sets)
            if a_proj is not None:
                a_ens = a_proj
            else:
                newest = max(active_chunks, key=lambda p: p.start_time)
                a_ens = newest.action_at(t)   # 回退最新认证块
                if not self.certifier.certifies(a_ens, t):
                    return None, float('inf')  # 再退 safe hold
        D_chunk = self.disagreement(active_chunks, t)
        return a_ens, D_chunk

    def disagreement(self, chunks, t):
        acts = [(pi.action_at(t), pi.label) for pi in chunks if pi.action_at(t) is not None]
        if len(acts) < 2:
            return 0.0
        d = 0.0
        for i in range(len(acts)):
            for j in range(i + 1, len(acts)):
                d = max(d, np.linalg.norm(acts[i][0] - acts[j][0]) / self.a_scale +
                           tv_distance(acts[i][1], acts[j][1]))
        return d
```

```python
class ReproductionAuditor:
    def __init__(self, metrics, alpha=0.05, delta_min=0.0, n_boot=10000):
        self.metrics = metrics
        self.alpha = alpha
        self.delta_min = delta_min
        self.n_boot = n_boot

    def preregister(self, seeds, stopping_rule, analysis_plan, thresholds):
        payload = json.dumps({'seeds': seeds, 'stopping': stopping_rule,
                              'analysis': analysis_plan, 'thresholds': thresholds,
                              'metrics': self.metrics}, sort_keys=True)
        return hashlib.sha256(payload.encode()).hexdigest()

    def paired_block_bootstrap_ci(self, treat, base, block_id, seeds):
        # block_id: episode 分组；episode 内相关，避免把步当独立样本
        deltas = []
        rng = np.random.default_rng(seeds)
        for _ in range(self.n_boot):
            blocks = rng.choice(np.unique(block_id), size=len(np.unique(block_id)), replace=True)
            idx = np.concatenate([np.where(block_id == b)[0] for b in blocks])
            deltas.append(treat[idx].mean() - base[idx].mean())
        lo = np.quantile(deltas, self.alpha)          # 单侧
        return float(np.mean(deltas)), (float(lo), float(np.quantile(deltas, 1 - self.alpha)))

    def audit(self, treat_runs, base_runs, seed_labels, block_ids, h_pre):
        # 多重比较：Holm 校正每个指标
        raw = [self.paired_block_bootstrap_ci(treat_runs[m], base_runs[m], block_ids, 0)
               for m in self.metrics]
        corrected = holm_correct([ci[0] for ci in raw], self.alpha)
        reproduced = {m: (ci[1][0] > self.delta_min and corr_ok)
                      for m, ci, corr_ok in zip(self.metrics, raw, corrected)}
        SI = {m: np.std(treat_runs[m]) / (abs(np.mean(treat_runs[m])) + 1e-9)
              for m in self.metrics}
        contamination_ok = self.contamination_audit(treat_runs, base_runs)
        return RepCert(h_pre=h_pre, S=seed_labels, M=list(self.metrics),
                       delta={m: raw[i][0] for i, m in enumerate(self.metrics)},
                       CI={m: raw[i][1] for i, m in enumerate(self.metrics)},
                       SI=SI, contamination_ok=contamination_ok,
                       power=self.power_estimate(raw), version=self.version)

    def contamination_audit(self, treat, base):
        # 测试集重叠 / 调参泄漏 / 选择性报告（接口占位）
        return (not has_test_overlap(treat, base) and
                not has_tuning_leakage(treat) and
                is_preregistered(treat))
```

```python
class BaselineCanaryProbe:
    def __init__(self, baseline_policy, ref_dist, alpha_drift=1e-3,
                 eps_drift=0.05, tau_detect=10):
        self.pi_base = baseline_policy
        self.ref_dist = ref_dist
        self.alpha_drift = alpha_drift
        self.eps_drift = eps_drift
        self.tau_detect = tau_detect
        self.last_probe = time_now()
        self.ref_archive = None

    def calibrate_threshold(self):
        # 参考期自助 / 置换校准，保证误报 ≤ alpha_drift
        stats = [mmd(self.ref_dist[i], self.ref_dist[j])
                 for i in range(len(self.ref_dist)) for j in range(i + 1, len(self.ref_dist))]
        return np.quantile(stats, 1 - self.alpha_drift)

    def probe(self, live_telemetry):
        stat = mmd(self.ref_dist[-1], live_telemetry)
        drift = stat > self.calibrate_threshold()
        regression = self.shadow_replay(self.pi_base)
        ev = EVRep(repro_ok=not drift and not regression,
                   drift_flag=bool(drift), regression_flag=bool(regression),
                   SI=self.seed_sensitivity(), tau_rep=time_now() - self.last_probe)
        self.last_probe = time_now()
        return ev

    def shadow_replay(self, policy):
        # 在当前固件/参数栈上影子重放归档基线，比较指标与历史 CI 下界
```

```python
        best_K, best_v = 0, -float('inf')
        for K in range(1, K_hi + 1):
            cert = compiler.compile(s_t, policy, delta_req, K)
            if cert is None or cert.K < K:
                break
            v = self.voi_chunk(cert, eig_estimate(K), cert.delta_chunk_hard,
                               K * self.dt, self.repro_cost(K))
            if v > best_v:
                best_v, best_K = v, K
        return best_K

@dataclass
class ChunkExecutionCertificate:
    tube_traj: list
    per_step_cert: list
    invalidation_log: list
    blend_log: list
    RepCert_chain: list
    canary_log: list
    budget_snapshots: list
    version: int
    timestamp: float

    def verify_chain(self):
        if any(b.version <= a.version for a, b in zip(self.RepCert_chain, self.RepCert_chain[1:])):
            return False
        if any(e['cause'] is None for e in self.invalidation_log):
            return False
        return all(c.mu_verified < 1.0 for c in self.per_step_cert if hasattr(c, 'mu_verified'))
```

**正确性定理（Chunked Reproducible Evidence Soundness, CRES）**
假设 A22–A55 成立；新增 **(A56)** 块动力学与 W(ξ_exec) 诚实包住真实执行；**(A57)** 管传播音完备过近似；**(A58)** EFF 下块可交换性检验有效，失败即回退 SAFE；**(A59)** CEI 对任何管越界/陈旧/契约违例 ≤1 控制周期检出；**(A60)** STE 安全滤波音完备（不可认证即投影或回退）；**(A61)** RepCert 预注册、配对、无污染，块 bootstrap CI 有效；**(A62)** BCP 满足 (α_drift, τ_detect)。则：

1. **块安全**：SAFE 模式下 P(F_chunk) ≤ Σ_k δ_k（联合界，免独立假设）；EFF 模式下在 A-CRA/A58 成立时 P(F_chunk) ≤ α + δ_tube，漂移/检验失败自动回退 SAFE。
2. **中止及时性**：管越界、证据过期、契约违例或证书失效后剩余块不再派发；中止延迟 ≤1 周期。
3. **集成安全**：派发动作 ∈ 认证集合，或经投影，或为 safe hold；不存在「平均出未认证动作」的路径。
4. **复现健全性**：通过 RepCert 的「可复现改进」在预注册分析下类型 I 误差 ≤α；SI 超阈或污染审计失败 ⇒ 声明降级为「未复现」。
5. **漂移健全性**：BCP 误报 ≤α_drift；检测到漂移 ⇒ 切 SAFE、缩短 K*、重校准共形集、旧证书待复核。
6. **单向性**：EV-rep / D_chunk / SI 只加宽后验、触发重校准或降级，不能减少探针、证据门或佐证需求。
7. **终止性与部署界**：PCE++++ 有限预算内终止于 {承诺(带 Cert_chunk), 绕行, 降档, L2 协商, 安全停, 执行降级停, 复现降级停}；对检查点取联合界：
```
P_safe ≥ 1 − Σ_cp (δ_chunk + δ_inv + δ_blend + δ_rep + δ_drift + δ_eeis + δ_ertc + ...)
         − P(结构性错误未检出) − P(金丝雀漏检) − P(固件回滚失败)
```

关键：**CCC 把「一次动作」升级为「一条可认证的时域管」**——承诺的原子是块，块长由风险与延迟共同决定；**CRA 把「块内相关」显式化**——硬联合界保安全、块共形提效率、可交换性检验决定能否用效率界；**CEI/STE 把「开环与边界」变成可中止、可滤波的运行时约束**；**RAE/BCP 把「复现」从论文元要求变成运行时安全链**——结论要复现，世界也要「复现」；**PCE++++/J_chunk** 保证预算与审计闭环。三条单向安全通道延续：**信念更准、不确定性更大、动作更保守**。

## 6. 本轮最大风险

**一句话**：本轮把「分块」与「复现」都建立在**可交换 / 配对 / 平稳**假设上——块内相关、复现内相关、环境漂移中任何一项被静默违反，都会让块共形界与复现置信区间**更紧却无效**，使系统恰在世界变化时最自信；因此必须默认站在联合硬界一侧，任何可交换性检验失败、漂移检出或污染审计异常都立即回退 SAFE 并缩短块长，**宁可频繁降级为「短块 + 多探针 + 硬界」的笨办法，也绝不允许用「看起来更紧的统计界」去换取更少的安全冗余**。
