# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环第 6 轮；本轮灵感：「机械臂抓取」×「多模态大模型」）

> 第 59 轮把安全论证链一路压到电机电流环与阻抗证书，解决了「执行是否可信」。但它默认了另一个更上游的前提：**待验证的假设（这是什么、抓哪里、怎么抓）是给定的**。多模态大模型恰好在这个位置以「开放世界先验」的身份介入——它能说出「这是马克杯的把手」「应该从侧面捏握」，却无法保证这句话在摩擦锥、质心、夹爪开度、接触力上限的世界里成立。机械臂抓取是检验这句话的硬标准：语义错一寸，物理上就是打滑、压碎、碰撞或掉落。本轮核心命题：**把 MLLM 的语义输出降格为「可证伪的抓取假设」，把每一次抓取失败升格为「对语义先验的反证证据」，让开放世界语义第一次接受物理证伪。** 这一层称为**语义先验可证伪接地层（SPFG, Semantic Prior Falsification & Grounding）**。

核心矛盾：
- **H32（语义-物理鸿沟）**：MLLM 的置信度是语料似然，不是抓取成功率。它不知道摩擦系数 μ、质心 CoM、夹爪净开度、力限位，也不理解 force closure。语义合理 ≠ 物理可抓。若把 c_sem 直接当成功率用，证据门会被「语言上很像对」的假设骗过。
- **H33（相关证据伪独立）**：MLLM 与视觉模块共享输入像素、共享（或同源）视觉编码器与互联网预训练分布。把语义当成 XMC 第 6 个「独立模态」累加证据，会把同一份像素数两遍，系统性过度自信——这是第 59 轮「EV-exec 仅作对账」原则在语义侧的镜像问题。
- **H34（开放词表 OOD 与自洽幻觉）**：面对从未见过的物体，MLLM 被迫作答；多次采样可以高度自洽却一致地错（mode collapse），自洽性不能当正确性。必须显式检测「语义 OOD」并弃权，退回纯几何/可供性抓取。
- **H35（反证浪费）**：现有系统把抓取失败当噪声，重试同一语义假设；但失败恰恰是最贵、最有信息量的反证。缺乏「失败归因（标签错？位姿错？力错？摩擦估计错？）」与「语义-抓取记忆更新」，同样的错误会被重复付费。

## 0. 直觉与动机

**灵感 1（机械臂抓取 → 抓取即物理证伪实验）**
直觉：一次抓取不是「执行一个动作」，而是「对一组语义-几何-物理假设做一次可观测实验」。假设 h 应包含可被传感器直接反驳的预测：接触力落在哪个区间、何时开始打滑、触觉阵列哪个区域受压、腕部力矩是否超过质心裕度。抓取成功 = 假设未被反驳（并非证明为真）；抓取失败 = 某条子假设被反驳，且可通过失败模式定位是哪一条。这把抓取从开环技能变成**假设检验**：可证伪性来自「写进假设的预测」，而不是事后解释。

**灵感 2（多模态大模型 → 语义先验必须分解与校准）**
直觉：MLLM 的一个标量 confidence 混合了三件不同的事：语义识别（杯子还是碗）、几何定位（把手在哪、朝向如何）、物理可行性（这个握法会不会滑）。三者可用完全不同的证据校准：语义用开放词表识别准确率，几何用 6-DoF 位姿误差/分割 IoU，物理用真实抓取成功率。把三者拆开、分别做温度标定 + 共形校准，才能得到「可用于证据门」的 c_phy，而不是把语言置信度冒充成功率。

**灵感 3（相关证据 → 语义模态的独立性折扣）**
直觉：XMC 的证据累加隐含独立性假设，但 MLLM 与视觉共享像素与编码器，条件独立不成立。正确做法不是「不用语义」，而是**先扣除相关性再计入证据**：用共享来源矩阵 + 留出集上「超出偶然的一致率（Cohen's κ）」估计依赖，把语义模态有效权重压到 w_sem^eff = w_sem·(1−ρ_max)，并规定**语义模态永远不能单独构成 EV-xmodal 佐证，只能加宽或触发弃权**——与第 59 轮 EV-exec 的单向性完全同构。

**灵感 4（抓取失败 → 反证、归因与语义-抓取记忆）**
直觉：失败模式是可分类的：滑移（摩擦/力/表面）、压碎（力控/刚度）、未接触（位姿/几何）、碰撞（接近向量/碰撞体）、掉落（质心/夹持点）。建立「失败模式 → 子假设」因果图，用后验做信用分配，把结果写入以 (语义标签, 物体特征, 上下文) 为键的 Beta 后验记忆。下次遇到同类物体，优先用记忆中的先验而非重新问 MLLM——语义先验因此获得**跨回合的物理校准**。

**灵感 5（S-VOI → 何时值得问模型、何时值得动手）**
直觉：问一次 MLLM 有延迟/费用/版本漂移成本，抓一次有物理风险与时间成本。把「问模型」「问人」「直接抓」「换几何策略」放进同一 VOI 框架：只有当语义查询的期望信息增益超过其成本、且物理证伪的期望代价可接受时才执行。语义 OOD 时，物理试探的价值可能高于继续追问模型。

## 1. 形式化定义（增量：定义 153–160）

**定义 153（语义先验 S）** S=(ℓ, A, z_g, c_sem, c_geo, c_phy, src)，其中 ℓ 为开放词表标签分布，A 为可供性集合（handle/rim/body/...），z_g 为抓取类型（power/precision/suction/dexterous），c_sem/c_geo/c_phy∈[0,1] 为分解后的语义/几何/物理置信度，src=(model_id, version, prompt_hash, temperature, timestamp) 为来源指纹。

**定义 154（可证伪抓取假设 h）** h=(T_g∈SE(3), δ_a, F_des, v_app, 𝒲̂, τ̂_slip, Σ̂_tac, π̂_phy)。T_g 为夹爪位姿，δ_a 为净开度，F_des 为期望夹持力，v_app 为接近向量，𝒲̂ 为预测接触力旋量分布，τ̂_slip 为预测滑移起始时间分布，Σ̂_tac 为预测触觉阵列协方差，π̂_phy 为预测物理成功率。h 由 SGHC 从 S 编译得到（定义 157）。

**定义 155（语义-物理置信分解与校准 MCAL）** 对每个分量 j∈{sem,geo,phy} 定义校准映射 φ_j，满足在留出集上 P(成功 | φ_phy(c_phy)=p) ∈ [p−ε_cal, p+ε_cal]（共形校准带）；几何用位姿/分割误差分位数；语义用开放词表 top-k 与 OOD 判别。语义 OOD 分数 s_ood = F(entropy, self-consistency, geometric-support, memory-novelty)，s_ood > q_{1−α_ood} ⇒ 弃权。

**定义 156（抓取证伪证据 EV-grasp）** 谓词集 𝒫={P_slip, P_force, P_tac, P_com}：
- P_slip：实测滑移起始早于 τ̂_slip 的低分位，或滑移冲量超阈 ⇒ 反驳「稳定夹持」；
- P_force：接触力落在 𝒲̂ 的 (α/2,1−α/2) 分位带外 ⇒ 反驳「力模型」；
- P_tac：实测触觉对 Σ̂_tac 的似然比低于阈值 ⇒ 反驳「接触几何」；
- P_com：腕部力矩/质心裕度越界 ⇒ 反驳「负载分布」。

EV-grasp=(verdict∈{confirmed,falsified,inconclusive}, failed_predicates, cause_posterior, τ_slip_obs, force_quantiles, tactile_lr, h_id)。

**定义 157（语义→抓取假设编译器 SGHC）** SGHC(S, ξ_exec, b_r)={h_i}，并对每个 h_i 做**最坏情形可行性预检**：在 μ∈[μ_lo,μ_hi]、质心椭球、夹爪开度约束下，存在接触力 f_i 满足摩擦锥与力限位、且 G f=−w_ext（G 为抓取矩阵）。通过预检者才允许执行；全部失败 ⇒ 语义不可执行，弃权。

**定义 158（相关性感知语义融合 XMC⁺⁺）** 语义模态 s 与已有模态 m 的相关性 ρ_sm 由共享来源矩阵与留出集 κ 估计；有效权重 w_s^eff=w_s·(1−max_m ρ_sm)。融合采用证据稀释形式：logit(p_fused) ≤ logit(p_prior)+Σ_{m≠s} λ_m Δ_m + λ_s^eff Δ_s。硬规则：(S1) 语义模态不得单独构成 EV-xmodal/EV-human 佐证；(S2) 语义分歧只能加宽后验或触发弃权；(S3) s_ood 触发 ⇒ w_s^eff=0。

**定义 159（语义证据预算与 S-VOI）** B_sem=(query_left, query_latency_budget, grasp_attempt_left)。S-VOI(π)=EIG_sem(π) − λ_q·cost_query(π) − λ_g·E[cost_grasp(π)]，其中 EIG 用校准后的 c_phy 与当前抓取记忆后验计算；π 覆盖 {ask_mllm, ask_human, geometric_grasp, counterfactual_requery, abstain}。B_sem 耗尽 ⇒ 只能弃权或几何保底。

**定义 160（语义接地证书 J_sem）** J_sem=(S_log, h_chain, EV_grasp_log, cause_posterior_log, calibration_version, correlation_matrix, ρ_sem^eff, ood_state, memory_updates, model_provenance)。证书要求：每个下发的 h 可追溯到某个 S 与某次校准版本；每次失败可追溯到被反驳的谓词与归因后验。

## 2. 关键算法伪代码（骨架）

```python
def SPFG(scene, M, delta_f_req, budget):
    S = mllm_query(scene)                      # ① 语义先验 + 来源指纹
    S = M.mcal.calibrate(S)
    if M.mcal.is_semantic_ood(S, scene):       # ② 语义 OOD ⇒ 弃权
        return geometric_fallback(scene, M, reason="semantic_ood")
    hyps = M.sghc.compile(S, M.xi_exec, M.b_r) # ③ 编译 + 最坏情形可行性预检
    while budget.grasp_attempt_left > 0 and hyps:
        h = max(hyps, key=lambda x: x.pi_phy)
        if S_VOI(h, M, budget) < theta_svoi:
            break
        telem = execute_grasp_via_CLEP(h, M)   # ④ 复用第 59 轮阻抗/力控执行
        ev = M.gfet.test(h, telem)             # ⑤ 物理证伪
        M = update_memory_and_calibration(M, S, h, ev)
        if ev.verdict == "confirmed":
            return commit(h, ev, M, budget)
        hyps = M.sghc.replan(S, ev.cause_posterior, M)
        budget.grasp_attempt_left -= 1
    return abstain_or_geometric(scene, M, hyps)
```

## 3. 正确性定理（Semantic-Grounded Falsification Soundness, SGFS）

假设 A56（MCAL 校准在留出分布上满足共形覆盖率 ≥1−α_cal）、A57（语义 OOD 打分漏检率 ≤δ_sem_ood）、A58（GFET 证伪谓词对目标子假设的检验功效 ≥1−β_f）、A59（相关性矩阵估计的上界 ρ̂ ≥ ρ_true，即折扣不过度乐观）、A60（归因因果图在给定失败模式下局部 Markov，信用分配无偏）。则：

1. **语义校准健全性**：对任意被下发且非弃权的 h，P(grasp success | π̂_phy=p) ∈ [p−ε_cal−δ_sem_ood, p+ε_cal+δ_sem_ood]。
2. **无语义单独承诺**：在缺少 EV-grasp 或 EV-xmodal 的情况下，语义先验只能通过「加宽后验 / 降低 π̂_phy / 触发弃权」影响动作，不能单独抬升任何证据门。
3. **相关证据上界**：融合后对数几率增量不超过 Σ_m λ_m Δ_m + λ_s(1−ρ_max)Δ_s；当 ρ_max→1 时语义模态退化为零证据。
4. **反证单调性**：一次 falsified 的抓取使对应子假设后验不升（在 A58/A60 下严格下降至少 β_f 的 KL 下界），且同键记忆的 Beta 后验向失败侧移动。
5. **终止性**：SPFG 在 query_left+grasp_attempt_left 内终止于 {confirmed, abstain→几何保底, budget_exhausted→安全停, human_handover}。

**部署界**：
```
P_safe ≥ 1 − Σ_cp (δ_f + δ_exec + δ_ertc + δ_eeis
                   + δ_cal·1[语义参与] + δ_sem_ood·1[OOD漏检]
                   + δ_gfet·1[证伪漏报] + δ_corr·1[ρ低估]
                   + δ_cause·1[归因错误])
         − P(语义 OOD 未触发 ∧ 物理不可行) − P(记忆污染 ∧ 无回滚)
```

## 5. 本轮最大风险

**一句话**：本轮把开放世界语义纳入物理证伪链，但「证伪」本身依赖预测模型（力/滑移/触觉/质心）与归因因果图，**一旦证伪谓词检验功效不足或归因错误，系统会把「语义对但执行/建模错」误判成「语义错」，从而污染语义-抓取记忆并系统性丢弃正确的开放世界先验**——必须以「证伪仅降低不直接删除」「归因多假设后验 + 人工可审计」「记忆带版本与回滚」「相关性折扣只紧不松」四重护栏，宁可多问一次、多弃权一次，也不让错误反证把正确的语义先验永久写死。

### IP-152 SGHC（语义→抓取假设编译器）

```python
@dataclass
class GraspHypothesis:
    T_g: np.ndarray            # 4x4 grasp pose
    aperture: float            # 净开度
    F_des: float               # 期望夹持力
    v_app: np.ndarray          # 接近向量
    wrench_pred: WrenchDist    # 预测接触力旋量分布
    slip_pred: TimeDist        # 预测滑移起始时间
    tactile_pred: PatchDist    # 预测触觉阵列
    pi_phy: float              # 校准后物理成功率
    hyp_id: str

class SemanticGraspCompiler:
    def __init__(self, mu_interval, com_ellipsoid, gripper, motor):
        self.mu_lo, self.mu_hi = mu_interval
        self.com = com_ellipsoid
        self.g = gripper
        self.motor = motor

    def compile(self, S, xi_exec, b_r, K=5):
        hyps = []
        for z_g, T_g, ap in self.grasp_proposer(S, b_r):     # 6-DoF 候选
            if not self.worst_case_force_closure(T_g, ap, S, xi_exec, b_r):
                continue                                       # 最坏情形不可行直接丢弃
            w = self.wrench_model(T_g, ap, S, xi_exec, b_r)
            hyps.append(GraspHypothesis(
                T_g=T_g, aperture=ap, F_des=self.force_law(w),
                v_app=self.approach(T_g, b_r), wrench_pred=w,
                slip_pred=self.slip_model(w, xi_exec),
                tactile_pred=self.tactile_model(T_g, ap, S),
                pi_phy=self.phy_prob(w, xi_exec, b_r),
                hyp_id=hash((S.src, T_g.tobytes(), ap))))
        return sorted(hyps, key=lambda h: -h.pi_phy)[:K]

    def worst_case_force_closure(self, T_g, ap, S, xi_exec, b_r):
        """在 μ∈[μ_lo,μ_hi] 与质心椭球上求最坏情形：是否存在满足摩擦锥+力限位的 G f = -w_ext"""
        G = self.grasp_matrix(T_g, ap, S)
        for mu in (self.mu_lo, self.mu_hi):
            for com in self.com.corners():
                w_ext = self.external_wrench(com, b_r)
                lp = self.solve_friction_cone_lp(G, w_ext, mu,
                                                 f_max=self.motor.F_abs,
                                                 f_min=self.motor.F_min)
                if lp.infeasible:
                    return False
        return True

    def replan(self, S, cause_posterior, M):
        """根据归因后验重编译：若摩擦/质心归因高，则收紧 μ/CoM 假设或换抓取类型"""
        z_bias = self.grasp_type_from_causes(cause_posterior)
        return self.compile(S.with_grasp_bias(z_bias), M.xi_exec, M.b_r)
```

```python
class SemanticCalibrator:
    def __init__(self, cal_set):
        self.temp_sem = TemperatureScaler.fit(cal_set.sem)
        self.conformal_geo = ConformalQuantile.fit(cal_set.geo)
        self.conformal_phy = ConformalCalibrator.fit(cal_set.phy, alpha=0.05)
        self.q_ood = ConformalQuantile.fit(cal_set.ood_scores, alpha=0.03)

    def decompose(self, raw):
        """只把可校准的量暴露为置信；未知项保持高熵而非硬填"""
        return SemanticPrior(
            label=raw.label_dist,
            affordance=raw.affordances,
            grasp_type=raw.grasp_type,
            c_sem=raw.sem_logit, c_geo=raw.geo_logit, c_phy=raw.phy_logit,
            src=raw.provenance)

    def calibrate(self, S):
        S.c_sem = self.temp_sem(S.c_sem)
        S.c_geo = self.conformal_geo.map(S.c_geo)
        S.c_phy = self.conformal_phy.map(S.c_phy)      # 输出可直接当成功率用
        return S

    def is_semantic_ood(self, S, scene):
        ent = entropy(S.label)
        sc = self.self_consistency(S, paraphrases=8)   # 改写/温度采样语义熵
        gs = self.geometric_support(scene, S)          # 是否存在可行抓取假设
        nov = self.memory.novelty(S.label, scene)
        score = self.combine(ent, sc, gs, nov)         # 单调加权
        return score > self.q_ood
```

### IP-154 XMC⁺⁺（相关性感知语义融合）

```python
def correlation_discount(sem, modalities, shared_source_matrix, holdout):
    rho = {}
    for m in modalities:
        rho[m] = max(shared_source_matrix.overlap(sem, m),
                     cohens_kappa_excess(sem, m, holdout))  # 超出偶然的一致
    rho_max = max(rho.values(), default=0.0)
    return sem.w * (1.0 - rho_max), rho_max

def xmodal_fuse_sem(M, region, inf, S, EV_grasp):
    # 标准模态照旧
    for m in ['vis', 'tap', 'prop', 'acou', 'exec']:
        M.b[region][m] = bayes_update(M.b[region][m], inf.likelihood[m], w=M.rho[m])
    # 语义模态：先折扣，再限幅，不允许单独佐证
    w_eff, rho_max = correlation_discount(S, M.active_modalities, M.src_matrix, M.holdout)
    M.rho_sem_eff[region] = w_eff
    if M.mcal.is_semantic_ood(S, M.scene[region]) or EV_grasp.verdict == 'falsified':
        w_eff = 0.0
    base = sum(M.rho[m] * logit_delta(M.b[region][m]) for m in M.active_modalities)
    sem_delta = w_eff * logit_delta(S.as_likelihood())
    # 证据稀释上界：语义项不得突破按 rho 计算的上界
    fused_logit = M.b[region].prior_logit + clip(base + sem_delta, upper=base + w_eff * LOGIT_CAP)
    return Fuse(logit_to_dist(fused_logit)), rho_max
```

```python
def grasp_falsification_test(h, telemetry, mu_est):
    failed, lrs = [], {}
    # P_slip
    if telemetry.slip_time < h.slip_pred.q(0.05) or telemetry.slip_impulse > SLIP_IMPULSE_MAX:
        failed.append('P_slip')
    # P_force
    if not (h.wrench_pred.q(0.05) <= telemetry.force <= h.wrench_pred.q(0.95)):
        failed.append('P_force')
    # P_tac
    lr = tactile_likelihood_ratio(telemetry.tactile, h.tactile_pred)
    if lr < TACTILE_LR_MIN:
        failed.append('P_tac')
    # P_com
    if telemetry.wrist_torque > h.com_margin(mu_est):
        failed.append('P_com')
    if not failed:
        verdict = 'confirmed'
    elif len(failed) < len(PREDICATES):
        verdict = 'falsified'
    else:
        verdict = 'inconclusive'
    cause_post = cause_posterior(failed, telemetry, h, mu_est)  # 因果图后验
    return ExecGraspEvidence(verdict, tuple(failed), cause_post,
                             telemetry.slip_time, telemetry.force, lr, h.hyp_id)

def cause_posterior(failed, telemetry, h, mu_est):
    """失败模式→子假设因果图：label / pose / force / friction / com"""
    priors = {'label': 0.2, 'pose': 0.25, 'force': 0.2, 'friction': 0.2, 'com': 0.15}
    lik = {
        'label':    likelihood_label(failed, telemetry),
        'pose':     likelihood_pose(failed, telemetry),
        'force':    likelihood_force(failed, telemetry, h),
        'friction': likelihood_friction(failed, mu_est, h),
        'com':      likelihood_com(failed, telemetry, h),
    }
    return normalize({k: priors[k] * lik[k] for k in priors})
```

### IP-156 SPFG（语义先验可证伪接地算子）

```python
def semantic_prior_falsification_grounding(scene, M, budget, operators):
    # ① 语义先验（缓存/版本校验）
    S = M.sem_cache.get(scene) or mllm_query(scene, temperature=M.temp)
    S = M.mcal.calibrate(S)

    # ② 语义 OOD ⇒ 弃权到几何保底
    if M.mcal.is_semantic_ood(S, scene):
        return geometric_fallback(scene, M, reason='semantic_ood', cert=J_sem.open(S))

    # ③ 编译 + 最坏情形可行性预检
    hyps = M.sghc.compile(S, M.xi_exec, M.b_r)
    if not hyps:
        return geometric_fallback(scene, M, reason='no_force_closure', cert=J_sem.open(S))

    while budget.grasp_attempt_left > 0 and hyps:
        h = max(hyps, key=lambda x: x.pi_phy)

        # ④ 语义 VOI：值不值得抓/问/弃权
        if S_VOI(h, M, budget) < THETA_SVOI:
            choice = best_alternative(S_VOI_table(S, M, budget))
            if choice == 'ask_human':
                return ask_human(scene, S, h, operators)
            return abstain_or_geometric(scene, M, cert=J_sem.open(S))

        # ⑤ 执行（复用第 59 轮 CLEP：阻抗证书 + 实时契约 + 执行证据）
        telemetry = execute_grasp_via_CLEP(h, M)

        # ⑥ 物理证伪 + 归因
        ev = M.gfet.test(h, telemetry)

        # ⑦ 更新记忆 / 校准；只有必要时才污染语义先验
        M.sem_memory.update(scene, S, h, ev)          # Beta 后验
        M.mcal.online_update(ev)                       # 有界学习率
        M.EV_grasp_log.append(ev)

        if ev.verdict == 'confirmed':
            return commit_grasp(h, ev, M, cert=J_sem.close(S, h, ev))

        # ⑧ 反事实重问 / 重编译
        if budget.query_left > 0 and ev.cause_top in ('label', 'pose'):
            S = mllm_query(scene, counterfactual=ev.cause_posterior)
            S = M.mcal.calibrate(S)
            budget.query_left -= 1
        hyps = M.sghc.replan(S, ev.cause_posterior, M)
        budget.grasp_attempt_left -= 1

    return abstain_or_geometric(scene, M, cert=J_sem.open(S))
```

### IP-157 S-VOI（语义价值信息）

```python
def S_VOI(h, M, budget):
    # 期望信息增益：抓取结果对「语义标签/抓取类型」后验的互信息
    eig = expected_information_gain(
        outcome_dist=h.pi_phy,            # confirmed/falsified 概率
        hypothesis_posterior=M.sem_memory.posterior(h),
        observation_model=M.gfet.observation_model(h))
    # 查询成本：延迟 + 云调用 + 版本漂移风险
    cost_q = (M.query_latency * LAMBDA_LAT +
              M.query_price * LAMBDA_PRICE +
              M.sem_version_drift * LAMBDA_DRIFT)
    # 抓取成本：时间 + 碰撞风险 + 物体损伤期望
    cost_g = (M.avg_grasp_time * LAMBDA_TIME +
              M.collision_risk(h) * LAMBDA_COLL +
              M.damage_risk(h) * LAMBDA_DMG)
    return eig - cost_q - cost_g
```

### IP-158 J_sem（语义接地证书）

```python
@dataclass
class SemanticGroundingCertificate:
    S_log: list                 # 每次语义先验 + 来源指纹
    h_chain: list               # 假设链（含被否证的）
    EV_grasp_log: list          # 证伪证据日志
    cause_posterior_log: list   # 归因后验序列
    calibration_version: int
    correlation_matrix: dict
    rho_sem_eff: dict
    ood_state: dict
    memory_updates: list
    provenance: dict            # model_id/version/prompt_hash/temperature/timestamp
    version: int
    timestamp: float

    def verify_chain(self):
        # 1) 每个下发 h 可追溯到一个 S 与一个校准版本
        for h in self.h_chain:
            if not any(s.src.hash == h.src_hash for s in self.S_log):
                return False
            if h.cal_version != self.calibration_version:
                return False
        # 2) 每次失败可追溯到被反驳谓词与归因后验
        for ev in self.EV_grasp_log:
            if ev.verdict == 'falsified' and not ev.failed_predicates:
                return False
            if ev.verdict == 'falsified' and ev.cause_posterior is None:
                return False
        # 3) 语义 OOD 期间 rho_sem_eff 必须为 0
        for t, ood in self.ood_state.items():
            if ood and self.rho_sem_eff.get(t, 0) != 0:
                return False
        return True
```

**正确性定理（Semantic-Grounded Falsification Soundness, SGFS）**
假设 A56–A60（见想法区）成立，且沿用 A22–A55。则：

1. **语义校准健全性**：对任意被下发且非弃权的 h，`P(grasp success | π̂_phy=p) ∈ [p−ε_cal−δ_sem_ood, p+ε_cal+δ_sem_ood]`。
2. **无语义单独承诺**：在缺少 EV-grasp 或 EV-xmodal 的情况下，语义先验只能通过「加宽后验 / 降低 π̂_phy / 触发弃权」影响动作，不能单独抬升任何证据门。
3. **相关证据上界**：融合后对数几率增量 ≤ `Σ_m λ_m Δ_m + λ_s(1−ρ_max)Δ_s`；ρ_max→1 时语义模态退化为零证据。
4. **反证单调性**：一次 falsified 抓取使对应子假设后验不升；在 A58/A60 下严格下降至少 β_f 的 KL 下界，且同键记忆 Beta 后验向失败侧移动。
5. **终止性**：SPFG 在 `query_left+grasp_attempt_left` 内终止于 `{confirmed, abstain→几何保底, budget_exhausted→安全停, human_handover}`。
6. **部署界**：

```
P_safe ≥ 1 − Σ_cp (δ_f + δ_exec + δ_ertc + δ_eeis
                   + δ_cal·1[语义参与] + δ_sem_ood·1[OOD漏检]
                   + δ_gfet·1[证伪漏报] + δ_corr·1[ρ低估]
                   + δ_cause·1[归因错误])
         − P(语义 OOD 未触发 ∧ 物理不可行) − P(记忆污染 ∧ 无回滚)
```

关键：**语义不是「事实」，而是「假设」**——MLLM 只负责产出可被物理反驳的预测；**置信不是「一个标量」，而是「三种可分别校准的量」**——只有校准后的 c_phy 才能进证据门；**语义不是「独立模态」，而是「与视觉共享像素的相关模态」**——必须折扣、只能加宽、不能单独佐证；**失败不是「噪声」，而是「反证」**——归因后写入带版本的语义-抓取记忆，形成跨回合物理校准。
