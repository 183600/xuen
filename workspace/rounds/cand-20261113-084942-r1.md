# 第 3 轮迭代 · v3 灵感循环（第 1 轮：「演示方案」×「数据规模」）—— 把「数据」从常量升格为可优化组合

> 承接 v2（UIP-01′~15）。前两轮把杠杆押在**推理期纠错**（RHPVD-D）与**离线裁判/造数据**（GSO/DRF）。本轮换一个更少人盯、但可能更根本的变量：**策略在赛前看到的那批演示本身**。直觉一句话：**如果评测分布有 5 条泛化轴、而公开数据几乎只铺满 1 条，那么"再多数据"也可能只是同一条轴上的重复；真正的规模问题不是"多少条"，而是"哪条轴上多一条值多少分"。**
>
> 术语约定：本轮把「演示方案」读作**示教/演示数据的构造方案**（来源 × 覆盖轴 × 表示 × 顺序 × 质量 × 成本），而非答辩用 demo 脚本；若评审语境需要，后者可作附带的"对外演示脚本"，但不进入技术主线。

---

## 0. 直觉解释：为什么现在必须谈数据规模

三个直觉，层层收紧：

1. **"1000 条/任务"是错觉。** 32 任务约 3.2 万 episodes，摊到 `任务 × 计分步 × 泛化轴` 的格子上并不厚：若平均 3 个计分步、5 条泛化轴，名义上约 480 个格子，平均每格约 67 条；且高度集中在 nominal 轴，其余轴接近 0。
2. **分数更像"覆盖率"的函数，而不是"条数"的函数。** 评测会抽到未见物品、人为撤回、位置变化；这些轴上 0 覆盖 ⇒ 无论 nominal 堆到多少，期望分都被"看不见的轴"按住。存在一个**覆盖优先**的相变。
3. **数据有成本，也有负作用。** 冗余 nominal 会稀释混合比、诱发捷径（相机位/光照/桌面纹理），并吃掉本可用于尾部的训练预算。所以"数据规模"应被建模为**预算约束下的投资组合**，而不是一个越大越好的标量。

一句话：v2 造的是"纠错回路"，v3 要造的是"给这个回路上料的配比器"。

## 1. 严谨定义

**定义 1（数据分层 / stratum）**：\(\sigma=(\tau,a,s)\)，其中 \(\tau\in\{T01..T32\}\)，\(a\in\{\text{nominal},\text{unseen-object},\text{human-disturb},\text{position},\text{distractor},\text{background}\}\)，\(s\in\) 演示方案阶梯（§2 / 产物区 §2）。\(D_\sigma\) 为该层演示，\(n_\sigma=|D_\sigma|\)。

**定义 2（缩放曲线）**：固定其余层，\(S_\sigma(n)=\mathbb{E}[\text{综合分}\mid n]\)，采用饱和幂律
\[
S_\sigma(n)=S^\infty_\sigma-A_\sigma n^{-\beta_\sigma},\qquad A_\sigma,\beta_\sigma>0.
\]
边际收益 \(MV_\sigma(n)=A_\sigma\beta_\sigma n^{-\beta_\sigma-1}\) 单调递减（凹）。\(\beta\) 大 = 还远未饱和 = 值得投。

**定义 3（单位成本边际收益）**：\(\rho_\sigma(n)=MV_\sigma(n)/c_{s(\sigma)}\)，\(c_s\) 为方案 \(s\) 的单条成本（归一化 GPU·h / 人工 h / 存储）。**分配只看 \(\rho\)，不看 \(n\) 或 \(|D|\)。**

**定义 4（有效数据规模）**：把每条演示映射为特征 \(z(d)\)（状态–动作轨迹摘要），\(\varepsilon\)-覆盖/coreset 大小 \(n_{\text{eff}}(D)\) 为"不可再删而不损失覆盖"的条数；冗余率 \(R=|D|/n_{\text{eff}}\)。**工作假设：\(S\) 主要由 \(n_{\text{eff}}\) 决定，而非 \(|D|\)。**

**定义 5（数据组合问题）**：
\[
\max_{x\ge 0}\ \sum_\sigma\big[S_\sigma(n_\sigma+x_\sigma)-S_\sigma(n_\sigma)\big]
\quad\text{s.t.}\quad \sum_\sigma c_{s(\sigma)}x_\sigma\le B,\ x_\sigma\in\mathbb{Z}_{\ge0}.
\]
每层 \(S\) 凹且可分 ⇒ 目标近似 submodular ⇒ 按 \(\rho\) 的贪心达到 \((1-1/e)\) 近似。这把"该采什么数据"变成**可计算问题**，而非品味问题。

**定义 6（演示方案阶梯 DSL）**：\(s\) 按单位成本与可覆盖轴排成 L0→L7（产物区 §2），原则：**能用更便宜的一级覆盖某轴，就不上升到更贵一级**。

**定义 7（验证器断点）**：RHPVD-D 的 `regressed` 检测并非免费。设真实撤回率 \(r\)、召回 \(q\)、误报 \(f\)、正确重做收益 \(G\)、错误重做损失 \(L\)，则
\[
r\,q\,G>(1-r)\,f\,L
\]
时重做期望为正。给定 \((r,G,L)\)，该式在 ROC 上确定一个**断点 AUC**；验证器数据量不足时，端到端会"越纠越差"。这把 UIP-21（VDS）变成 UIP-01′ 的**前置条件**。

**定义 8（评测权重未知性）**：评测分布 \(P_{\text{eval}}\) 在 5 轴上的权重 \(\omega_a\) 未知。因此所有 \(\rho\) 都是**代理 \(\rho\)**，必须做稳健化（max-min / 悲观重加权），否则"最优配比"只是"代理最优"。

## 2. 对 v2 的重新排序（不是推翻，而是换主轴）

- **RHPVD-D（UIP-01′）**：保留为**部署期消费端**——它决定"要不要重做"，但它的上限由 VDS（UIP-21）的数据规模决定。
- **GSO（UIP-11）**：角色升级为**缩放曲线的测量仪**——对同一策略在 \(n\in\{25,50,\dots,2000\}\) 的子集上打分并拟合曲线；没有 GSO 就无法估计 \(\rho\)。
- **DRF（UIP-12）**：降为 DSL 的 **L5 一级**（脚本化仿真），不再是唯一造数据手段，被更便宜的 L1–L4、L6 挤压。
- **MSGR（UIP-14）/ ACS（UIP-13）**：保留，但数据侧优先级下调——它们只在"数据已覆盖该轴"时才有增益；否则是给空油箱换更好的发动机。

## 3. 两个灵感词的解读

1. **演示方案**：不是"录更多视频"，而是在六个维度上做设计——来源（公开/仿真/反向播放/逆操作合成/自生成/无标签视频）、覆盖轴、表示（joint vs ee、块长、动作分词）、顺序（课程/子目标分段）、质量（平滑/成功过滤/去捷径）、成本。最被低估的一维是**可逆性与顺序**：把成功演示**反向播放**，就免费得到一条"进度被撤回"的负向演示（UIP-20）。
2. **数据规模**：不是标量，而是**分层向量 \(n=(n_\sigma)\)**。真正要回答三件事：① 每轴曲线何时饱和（\(\beta,S^\infty\)）；② 当前组合的有效规模 \(n_{\text{eff}}\) 与冗余 \(R\)；③ 预算 \(B\) 下下一条数据投哪层（\(\rho\) 最大）。**规模的科学 = 边际收益的科学。**

## 4. 瓶颈假设（可证伪）

- **H1（覆盖优先）**：nominal 轴已近似饱和（\(\beta\) 小、\(S^\infty\) 高），人为干扰/未见物品轴上 \(n\approx0\) 且 \(\beta\) 大 ⇒ 边际收益高 1–2 个数量级。证伪方式：拟合出 \(\rho_{\text{nominal}}\ge\rho_{\text{tail}}\)。
- **H2（冗余巨大）**：公开数据有效规模远小于名义规模（\(R\ge2\)），去冗可释放 \(\ge30\%\) 预算而 \(\Delta S<1\%\)。证伪方式：coreset 后同预算性能显著下降。
- **H3（方案阶梯有结构）**：不同轴的最便宜足够方案不同——干扰轴最便宜是"反向/逆操作合成（L3–L4）+ 仿真（L5）"，未见物品轴最便宜是"重标注/视角合成（L2–L3）"。证伪方式：某单一方案在所有轴上 \(\rho\) 都最高。
- **H4（验证器断点）**：端到端重做收益对验证器质量呈**阈值型**，低于断点 AUC 时重做为负；VDS 是 RHPVD 的前置条件。
- **H5（过量为害）**：nominal:tail 混合比过高会同时降低尾部分数与样本效率；存在内部最优混合比（数据混合律）。

## 5. 候选 → v3 清单

新增 6 项：**UIP-16 DSP**（缩放探针）、**UIP-17 DSL**（方案阶梯）、**UIP-18 EDS**（有效规模/去冗/规范化）、**UIP-19 DPA**（组合配比器，本轮旗舰候选）、**UIP-20 IOC**（逆操作/反向合成演示，次旗舰）、**UIP-21 VDS**（验证器数据规模与断点 AUC）。旗舰从"推理期 RHPVD"暂时迁移到"数据组合引擎 DSP×EDS×DPA"，但对外部署骨架仍是 RHPVD。详见产物区。

## 6. 本轮最大风险

**一句话**：评测五轴的**真实权重未知**，而我们的 \(\rho\) 全部由 GSO/离线代理估出——一旦把预算押在"仿真里好看、真机不加权"的伪尾部，就会得到代理最优、实测不涨的结果。

## 1. 旗舰：UIP-16 DSP × UIP-19 DPA

### 1.1 DSP（缩放探针）

**目的**：把"数据够不够"从直觉变成**每层一条曲线**。

- **嵌套子集**：对每层 \(\sigma\) 构造 \(n\in\{0,25,50,100,250,500,1000,2000\}\) 的 i.i.d. 嵌套子集（seed 固定，防泄漏）。
- **等算力 vs 等轮次**：两种协议都跑——① *iso-epoch*（每子集训同样 epoch，测"数据受限"曲线）；② *iso-compute*（固定总步数，测"预算受限"实际收益）。二者差即"重复数据的浪费"。
- **测量器**：用 UIP-11 GSO 给每子集策略打**计分步代理分**（结构裁判，不作成败裁判）。
- **拟合**：三参数非线性最小二乘 \(S(n)=S^\infty-A n^{-\beta}\)；报 \(\beta\)、\(S^\infty\)、饱和比 \(S(1000)/S^\infty\)、当前 \(MV\)、单位成本 \(\rho\)。
- **防混淆**：小 \(n\) 易过拟合 ⇒ 早停于 held-out；不同层用同一骨干/同超参，避免"数据效应"混入"调参效应"。

> 关键产出不是某个数，而是**一张 \(\rho\) 地图**：它直接告诉 DPA"下一百条数据投哪里"。

### 1.2 DPA（组合配比器）

**机制**：输入 DSP 的曲线与 DSL 的成本表，输出"下一批生成/标注清单"。

**贪心伪代码**

```python
# UIP-19 DPA: budgeted marginal-value allocation
def allocate(curves, costs, budget, n0, max_iter=10**6):
    # curves[sigma] = (S_inf, A, beta); costs[s] = c_s
    n = dict(n0)                      # 当前每层条数
    plan = []                         # [(sigma, scheme, count)]
    spent = 0.0
    while spent < budget and len(plan) < max_iter:
        best = None
        for sigma, (S_inf, A, beta) in curves.items():
            if n[sigma] <= 0 and beta <= 0:      # 该层尚未定义
                continue
            nn = max(n[sigma], 1)
            mv = A * beta * nn ** (-beta - 1)    # 边际收益
            for s, c in costs[sigma].items():    # 该层可用的方案
                if c <= 0:
                    continue
                rho = mv / c                     # 单位成本边际收益
                if best is None or rho > best[0]:
                    best = (rho, sigma, s, c, mv)
        if best is None:
            break
        _, sigma, s, c, mv = best
        n[sigma] += 1
        spent += c
        plan.append((sigma, s, 1))
    return plan, spent, n
# 因每层 S 凹、目标可分 ⇒ 贪心 = (1-1/e) 近似；实践中直接可用
```

**稳健化（应对定义 8 的权重未知）**：对 \(\omega_a\) 取不确定集合，做 max-min：\(\max_x \min_{\omega\in\Omega}\sum_a\omega_a\Delta S_a(x)\)。若某尾部轴在悲观权重下仍被选中，才是"值得押"的尾部。否则先做**低成本的探测性覆盖**（少量 L3/L4），再决定是否放大。

**产出物**：一张"数据采购单"——`(任务, 轴, 方案, 条数, 预估 Δ分/成本, 悲观 Δ分)`，可直接排进生成流水线。

## 2. UIP-17 DSL：演示方案阶梯

原则：**用更便宜的一级覆盖某轴，就不上升到更贵一级**；每级都要过"单模型"合规。

| 级 | 方案 | 单条成本 | 主要覆盖轴 | 可用性 | 关键风险 |
|---|---|---|---|---|---|
| L0 | 公开数据复用 | ≈0 | nominal | 高 | 已饱和、冗余 |
| L1 | 去冗 / coreset（EDS） | ≈0 | 全轴（提升 \(n_{\text{eff}}\)） | 高 | 选样偏差 |
| L2 | 规范化（视角/光照/裁剪/去背景捷径） | 极低 | background / position | 高 | 语义信息损失 |
| L3 | 重标注 + **反向播放**（IOC） | 极低 | human-disturb（运动学可逆类）/ position | 高 | 物理不可逆（倒水/剪/折痕） |
| L4 | 视角/光照合成（view + photometric DR） | 低 | unseen-object / background / position | 中高 | 合成伪影 |
| L5 | 脚本化仿真（DRF/Gazebo/Isaac） | 中 | human-disturb / 接触密集 / 未见物 | 中 | sim-to-real gap |
| L6 | 无标签视频/跨数据集预训练 | 低–中 | unseen-object / background | 中 | 需要强表征、可能违规（外部大模型标注） |
| L7 | 真机示教/干预 | 高 | 全轴（尤其接触） | 低（可能无设备） | 成本与可获得性 |

**阶梯决策规则**
1. 先用 L1 把冗余换成预算；
2. 运动学可逆的干扰轴先用 L3（反向/逆操作），不可逆的用 L5；
3. 未见物品优先 L2/L4/L6，最后才 L7；
4. **禁止**：L7 教 L5 能教的东西；L5 教 L3 能教的东西。

**合规注**：L6 若用外部 VLM 自动打标签，可能被判"非单模型"；优先用主骨干内部头或几何谓词自标。

## 3. UIP-18 EDS：有效数据规模

### 3.1 定义与估计

- 特征 \(z(d)\)：`concat(pooled_vision_embedding, action_stats, language_embedding)`。
- **coreset**：在 \(z\) 上做 \(k\)-center / DPP，取 \(\varepsilon\)-覆盖集；\(n_{\text{eff}}=|\text{coreset}|\)，冗余 \(R=|D|/n_{\text{eff}}\)。
- **容量下界（粗估，待校准）**：若每 `任务×计分步` 只需约 50 条即可接近饱和，则 32 任务 × 3 步 × 50 ≈ **4,800** 条 nominal 已够；对比公开约 3.2 万 ⇒ **粗略 \(R\approx6.7\)**。这意味着 nominal 可能被压缩 5–6 倍而性能几乎不掉。**此数仅为假想阈值，必须由 DSP 实测替换。**

### 3.2 去冗目标

- **目标**：prune 50–80% nominal，\(\Delta S<1\%\)，释放预算转投尾部。
- **防陷阱**：coreset 只按覆盖选样，可能丢掉"高质量但相似"的关键示范；用"覆盖 + 可学性"双准则（可学性 = 小代理模型上的 loss 降低量）。

### 3.3 规范化 / 去捷径

- 对齐相机外参、归一化光照/桌面纹理、随机化背景 ⇒ 降低 nuisance 方差，等效提高 \(n_{\text{eff}}\)。
- **度量**：规范化前后在同一 held-out（跨背景）上测 \(S\)，差值即"捷径税"。

## 5. UIP-20 IOC：逆操作 / 反向合成演示

### 5.1 技能逆代数

把任务的计分步分解为技能序列；每个技能 \(\kappa\) 有前置/后置谓词，定义逆 \(\kappa^{-1}\) 使
\[
\text{post}(\kappa^{-1}\!\circ\kappa)=\text{pre}(\kappa).
\]
官网 `human_*` 里的干扰大量正是某个技能的逆：合上→打开（\(\kappa^{-1}\)）、拉上→拉开、叠好→翻开、放入→拿走、拧开→拧回。因此
\[
\text{干扰}\ \delta=\kappa^{-1}\ (\text{或空间位移}\ \Pi),\qquad
\text{恢复}=(\kappa,\ \delta,\ \kappa)\ \text{三元组}.
\]

### 5.2 可逆性分级（决定用反向播放还是仿真）

| 技能类 | 可逆? | 最便宜方案 |
|---|---|---|
| 开/合、拉链、堆叠/拆叠、插入/拔出、拧/松、盖/揭 | 运动学可逆 | L3 反向播放/重标注 |
| 折叠（有折痕）、放置（重定位） | 部分可逆 | L3 + L5 校正 |
| 倒液、剪、破碎、针管推注 | 不可逆 | L5 仿真（物理合法） |

### 5.3 数据规模效应

- **×2 免费**：每条成功演示反向即得一条"回退"演示（近零成本）。
- **自动标签**：反向转移天然是 `post→pre`，**可直接作为 `regressed` 正样本**，正好补 VDS 的标签空白。
- **三元组合成**：\(\kappa\to\kappa^{-1}\to\kappa\) 生成"做→被撤回→重做"训练序列，教 RHPVD 的 `replace` 分支。
- **注意**：反向播放会违反接触/抓握物理（反向时夹爪在"松开"却仍闭合），因此**只用于表征/验证器学习**（L3），物理合法的训练数据仍回落到 L5 仿真。

```python
# UIP-20 IOC: 从成功演示合成回退/恢复样本
def synth_recovery(demo, skill_segments):
    # demo: (o_0..o_T, a_0..a_{T-1}); skill_segments 标出每个 kappa 的起止
    triads = []
    for (t0, t1, kappa) in skill_segments:
        fwd = demo[t0:t1]                 # kappa 成功执行
        rev = reverse(fwd)                # kappa^{-1} 近似（运动学可逆时）
        label = "regressed"               # 反向转移=进度回退
        triads.append((fwd, rev, fwd, label))   # 做 -> 撤回 -> 重做
    return triads
```

## 6. UIP-21 VDS：验证器数据规模与断点 AUC

### 6.1 断点条件推导

设 `regressed` 真实率 \(r\)，检测召回 \(q\)、误报 \(f\)；正确重做挽回步骤分 \(G\)，错误重做损失 \(L\)（时间/引入新回退）。期望净收益
\[
\mathbb{E}[\Delta]=r\,q\,G-(1-r)\,f\,L.
\]
令 \(>0\) 得
\[
f<\frac{r\,q\,G}{(1-r)\,L}.
\]
在 ROC 上取满足此式且 \(q\) 最大的工作点；若不存在，则**重做应关闭**。若用等方差 binormal 近似，\(\mathrm{AUC}=\Phi(d/\sqrt2)\)，可解出**断点 AUC** \(\mathrm{AUC}^\*\)。低于它的验证器，即使准确率看似不低，也会"越纠越差"。

### 6.2 标签预算

- 标签来源：GSO 几何谓词**自动标注**（结构真值）+ 反向合成（UIP-20）自动正样本 + 少量真机锚点。
- 拟合验证器缩放 \(AUC(n)=AUC^\infty-A_v n^{-\beta_v}\)；求最小 \(n\) 使 \(AUC(n)\ge AUC^\*\)。
- **结论形式**：VDS 输出"启用量化门槛"——`RHPVD 仅在验证器 AUC≥X 时开启 regressed 分支，否则只做 done/fail`。

## 8. 合规与红线

- **单模型**：所有技能头/验证器头共享一条骨干；**外部 VLM 自动标注可能被判非单模型** ⇒ 改用几何谓词或内部头。
- **反向播放的合法性**：只作表征/验证器学习，不宣称物理合法训练数据；物理合法性由 L5 仿真负责。
- **代理≠真机**：DSL/DPA 的所有 \(\rho\) 都是代理值；E208 是唯一真机闸门；未过闸不得写"真机结论"。
- **数据污染**：嵌套子集必须严格 i.i.d. 且与 held-out 分离，防"缩放曲线"被泄漏抬高。
- **过量为害**：把 H5 当作默认怀疑——任何"再加 nominal"的提案都必须先给出 \(\rho\) 估计。
