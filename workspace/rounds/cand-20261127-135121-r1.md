## 1. 直觉与动机（两个灵感的碰撞）

**灵感 1（状态估计 → 这场考试是 POMDP，但 v1.1 把它当成了 MDP）**

直觉：机器人本体状态几乎是全知的（F20：关节、末端位姿、夹爪、下半身），真正隐藏的是**世界状态**：物体在哪、有没有接触、夹住没有、任务进行到哪一步。v1.1 的 I3（关键点伺服）、I4（干预检测）、I5（进度头）、I9（检索）其实都是**状态估计器**，但它们是四个各自为政的估计器：各自有延迟、各自有置信度、彼此不共享一个「信念」。这带来两个反直觉点：

1. **没有触觉不等于没有接触观测**。本体感知里的**跟踪误差**（指令末端位姿 vs 实测末端位姿）、**夹爪开度差**（指令 vs 实测）、**腕部光流残差**（相机随末端运动的预期流 vs 实测流）在接触/滑移/被推的瞬间会同时跳变——这是一个**零额外模型、亚毫秒的本体创新通道**，可以当作触觉代理。它比再加一个视觉模型更便宜，也更接近「接触」这件事的物理本质。
2. **状态估计的正确目标不是「估得准」，而是「动作执行时估得准，且只估动作在乎的分量」**。观测时刻的估计误差不是分数；执行时刻的误差才是。一个在观测时刻很准、但延迟 80ms 的估计器，可能不如一个在观测时刻略糙、但延迟 5ms 的估计器。更进一步：如果某个状态分量对动作没有影响（动作雅可比为零），估计它纯属浪费延迟。

**灵感 2（推理延迟 → 延迟不是部署指标，而是状态估计误差与分数预算）**

直觉：F21 说观测没有时间戳，F22 说 chunk 长度握手期固定，F24 说参考客户端逐步测延迟——这三条事实把「延迟」从一个工程 KPI 变成了两个直接计分项：

1. **延迟 = 状态陈旧 = 有偏估计**。动作在 `t_a` 执行，用的却是 `τ_t` 时刻的观测；中间的状态漂移就是延迟项。接触密集阶段状态变化最快，同样的延迟伤害最大。所以延迟预算应当**按阶段分配**，而不是全局一个数。
2. **延迟 = 时间预算消耗 = 步数/尝试次数减少**。在固定评测时限内，每步慢 20ms，能完成的步骤数就少一截；步骤分（F17）是按步给的。事件触发推理（世界没变化就复用上一 chunk、几乎零延迟；世界跳变就全量重估）把延迟花在「状态真的变了」的地方，这是延迟与状态估计的统一。

**灵感 3（碰撞与统一 → 信念总线：便宜估计常开，昂贵估计按需，延迟按信息量分配）**

直觉：把 v1.1 的四个估计器统一成一条**信念总线（Belief Bus）**：维护一个带不确定性的信念 `b_t=(x_t,Σ_t,phase_t,progress_t)`；E0 本体创新每步常开（亚毫秒）；E1 关键点、E2 多视图位姿、E3 VLM 语义核验按「任务相关不确定性 × 截止时间余量」逐级唤醒；每步把信念前推到执行时刻再交给策略；当创新小时复用上一 chunk，创新大时才全量重算。核心统一：**状态估计回答「现在世界是什么样」，推理延迟回答「你有多久来回答、以及世界变了没有」；两者在「事件触发」处汇合——只在世界跳变时花延迟重估，其余时间用本体创新维持信念。**

## 2. 对前两轮痛点的增量修订

- P4（无触觉）**实质性缓解**：本体创新提供接触/滑移/被推的廉价代理信号（H2），不再只依赖 I3 的视觉关键点。
- P5（时间压力）细化：延迟直接消耗步骤分预算（F17/F24），事件触发推理是新的时间杠杆。
- P6（部署延迟）升级：从「服务器 p99」升级为「执行时刻状态误差 + 观测载荷 + 复用率」三件套。
- P2（泛化缺口）补充：估计器必须在与策略相同的 5 轴上校准（PR9），否则「看不见的新物体」会先杀死估计器再杀死策略。
- **修正 P12（接口约束）**：F22 推翻了 v1.1 I4「逐调用自适应 chunk」的接口假设——chunk 长度固定，自适应只能做「提交前缀 + 安全尾段」。这是本轮对旧清单的**硬修剪**。
- **新增 P13（估计器延迟债）**：估计器级联若没有零延迟回退（E0），会在最需要它的接触阶段成为新的延迟瓶颈。
- **新增 P14（不确定性的可操作性）**：未校准的置信度不能用于「重观测/中止/让位」决策；它只是装饰，甚至会主动误导。

## 3. 研究问题（本轮立项 Q9–Q12，Q1–Q8 保留）

- **Q9（任务相关最小信念）**：32 任务各自真正影响动作/分数的隐藏状态分量是什么？能否用「动作雅可比 × 分数敏感度」筛出一个每任务的最小信念，使估计成本大幅下降而不掉分？
- **Q10（随时估计调度）**：在硬每步截止时间下，如何按「信息价值/延迟成本」调度 E0–E3，使执行时刻的任务相关不确定性最小？何时应当放弃估计、直接复用或保守停持？
- **Q11（创新作为触觉）**：本体创新（跟踪误差、夹爪差、光流残差）对接触起始、滑移、人手干预的检测 ROC 有多高？与视觉关键点融合后的增益与误报代价？
- **Q12（校准与跨轴覆盖）**：按「阶段 × 泛化轴」分组的 conformal 校准，能否在位置/干扰物/背景/未见物品四轴上维持名义覆盖率？覆盖率破防时如何降级到保守策略？

## 4. 设计原则（新增 PR6–PR9，PR1–PR5 保留）

- **PR6 时间戳律**：任何观测/估计/动作都必须带（显式或推断的）时间戳；融合与补偿一律按时间对齐，动作必须针对**执行时刻**的预测状态计算，而不是观测时刻。F21 没有显式时间戳，就用步计数 × 控制周期 + 实测 RTT 推断，并显式记录其不确定度。
- **PR7 不确定性可操作律**：不确定性必须校准，并且绑定到一个决策（重观测 / 缩短提交前缀 / 中止重试 / 让位）。不可操作或未校准的不确定性不得进入决策。
- **PR8 截止时间优先律**：任何可能进入计分路径的组件，必须证明最坏情况延迟 ≤ 预算；否则要么做成 anytime（可中断、有回退），要么移出关键路径。E0 是永远可用的零延迟回退。
- **PR9 估计器同轴律**：估计器与策略在同一 5 条泛化轴上训练、校准、消融；估计器鲁棒性是泛化的一部分，不是另一个项目。
- PR1–PR5 保留。

## 1. 严谨定义（先直觉，后定义；定义供实现与消融共用）

### 1.1 执行时刻状态误差

**直觉**：动作在 `t_a` 执行，观测在 `τ_t` 采集；中间隔了网络、计算、排队。分数只关心动作执行那一刻的状态估得准不准。

**定义 1**：设隐藏状态 `s_t`，估计 `ŝ`，分数敏感度权重 `W`，执行时刻 `t_a`：
`ε_exec = E[ (ŝ - s_{t_a})^T W (ŝ - s_{t_a}) ]`。
它可分解为观测噪声 + 过程漂移 `D(t_a-τ_t)` + 模型偏差 + 离散化误差。延迟补偿的目标是消掉过程漂移的一阶项。

### 1.2 信念与任务相关不确定性

**直觉**：不是所有状态都值得估；只估动作在乎的。

**定义 2**：信念 `b_t = (x_t, Σ_t, p_t, g_t)`，其中 `x` 为连续状态（物体位姿/速度、接触模式、夹爪—物体耦合），`Σ` 为协方差，`p` 为离散阶段，`g` 为进度。令名义动作 `a*=π(b)`，动作雅可比 `J=∂a*/∂x`，动作权重 `W_a`：
`U_rel = tr(J^T W_a J Σ)`。
调度器最小化 `U_rel`，而不是 `tr(Σ)`。

### 1.3 Anytime 估计器级联

**直觉**：便宜的先算，贵的按需；任何时候被打断都能给出当前最好估计。

**定义 3**：级联 `E_0, E_1, …, E_m`，每级返回 `(x_i, Σ_i)`，成本 `c_i`（最坏情况时间），误差单调不增。`E_0` = 本体创新（亚毫秒，永远可运行）。调度器在截止时间 `D` 与信息价值 `VoC` 约束下选择停止层级：
`i* = max{ i : Σ_{j≤i} c_j ≤ slack 且 VoC(i) ≥ 0 }`。
`VoC(i) ≈ κ·(U_rel(i-1) - U_rel(i)) - λ·c_i`，`λ` 由时间-分数模型给出。

### 1.4 本体创新（触觉代理）

**直觉**：接触/滑移/被推时，本体信号会同时「不对劲」。

**定义 4**：`ν_t = (e_track, e_grip, e_flow)`：
- `e_track = q_t - q_{t}^{cmd}`（跟踪误差；接触/碰撞/人手）；
- `e_grip = g_t - g_t^{cmd}`（夹爪实际开度 vs 指令；抓空/滑移）；
- `e_flow = OF(wrist_t) - ÔF(ee motion)`（腕部光流残差；物体滑移/外部推动）。

`E_0` 输出 `x_0`（接触模式、抓取状态、干预标志）与 `Σ_0`。阈值由留出集 ROC/conformal 标定。

### 1.5 事件触发推理与提交前缀

**直觉**：世界没变就别重算；变了才花延迟。

**定义 5**：维护上一 chunk `A_{t-1}` 与预测状态轨迹。新观测的创新范数 `||ν_t||_M`：
- `≤θ_1` 且开环年龄 `≤K_max` → **复用**（平移 chunk，尾段安全保持），延迟 ≈0；
- `(θ_1, θ_2]` → **部分重估**（E0+E1），短提交前缀；
- `>θ_2` → **全量重估**（E0–E2/E3），短前缀 + 可能中止/重试。

提交前缀 `k_t ∈ [1, T_a]`：前 `k_t` 步为承诺执行，其余为「安全尾段」（保持/回退到已知安全位姿）。`T_a` 由 F22 固定；自适应体现在 `k_t` 与触发层级，而非 `T_a`。

### 1.6 跨轴 conformal 校准

**直觉**：置信度要在「位置/干扰物/背景/未见物品」各轴上分别可信，不能只在平均上可信。

**定义 6**：非一致性分数 `r(x,z)`（如 Mahalanobis 距离），按组 `g=(phase, axis)` 在留出集上标定阈值 `q_g`，使每组覆盖率 `≥1-α`。评测期只读，不更新（PR7）。覆盖率破防 → 降级到保守前缀/停持。

### 2.1 信念总线主循环

```python
class BeliefBusPolicy:
    def __init__(self, policy, cascade, dynamics, conformal):
        self.policy, self.cascade = policy, cascade
        self.dyn, self.cal = dynamics, conformal
        self.reset()

    def reset(self):
        self.belief = None          # (x, Σ, phase, progress)
        self.chunk = None
        self.open_age = 0           # 开环步数
        self.step_idx = 0

    def get_action(self, obs):
        t_recv = now()
        nu, x0, S0 = self.cascade.E0(obs)          # 亚毫秒，常开
        level = self.trigger(nu, self.open_age)

        if level == 0 and self.chunk is not None:
            self.open_age += 1
            return self.shift_hold(self.chunk, self.open_age)   # 复用，~0 延迟

        x, S = x0, S0
        deadline = t_recv + self.budget            # 每步预算（如 40ms）
        for i in range(1, level + 1):
            est = self.cascade[i]
            if now() + est.worst_case > deadline: break
            if self.voc(i, S) < 0: break
            x, S = est.update(x, S, obs)

        age = self.estimate_age(t_recv)             # 步计数×周期 + RTT/2
        x_exec = self.dyn.propagate(x, self.chunk, age)   # 前推到执行时刻
        S_exec = self.dyn.inflate(S, age)
        x_exec, S_exec = self.fuse_prior(x_exec, S_exec, self.retrieval_prior)
        self.belief = (x_exec, S_exec, self.phase(x), self.progress(x))

        chunk = self.policy.propose(obs, belief=self.belief)
        k = self.commit_prefix(S_exec, self.belief[2])     # 任务相关不确定性
        self.chunk = self.make_safe_tail(chunk, k)
        self.open_age = 0
        return self.chunk

    def trigger(self, nu, age):
        n = norm_M(nu)
        if self.chunk is not None and n <= self.th1 and age < self.K_max:
            return 0
        return 1 if n <= self.th2 else 2

    def voc(self, i, S):
        return (self.kappa * (self.U_rel(S, i - 1) - self.U_rel(S, i))
                - self.lam * self.cascade[i].mean_cost)
```

### 2.2 本体创新 E0

```python
def E0(obs):
    q      = obs["observation.state.left_arm"][-1]      # 及右臂
    q_cmd  = cmd_timeline[obs_step]                      # 与观测同一步的指令
    e_trk  = norm(q - q_cmd)
    e_grip = abs(obs["observation.state.left_gripper"][-1] - grip_cmd)
    e_flow = flow_residual(obs["observation.images.cam_left_wrist"][-1],
                           obs["observation.state.left_ee_pose_gripper_base"])
    nu = stack([e_trk, e_grip, e_flow])
    contact  = e_trk  > cal.tau_track[phase]
    grasped  = e_grip < cal.tau_grip[phase]
    external = e_flow > cal.tau_flow[phase]
    x0 = dict(contact=contact, grasped=grasped, human=external)
    S0 = cal.covariance(x0)                              # 由留出集标定
    return nu, x0, S0
```

### 2.3 延迟补偿（只前推，不做决策 rollout）

```python
def propagate(x, last_chunk, age):
    # 机器人：用实测 q,qdot + 指令轨迹的一阶滞后模型
    x_robot = lag_model(x.robot, last_chunk, age, tau=cal.lag_tau)

    x_obj   = x.obj + x.obj_vel * age
```

### 2.4 提交前缀与安全尾段

```python
def commit_prefix(S, phase):
    u = U_rel(S)                                # 动作敏感不确定性
    k = clip(int(T_a * exp(-u / u0)), 1, T_a)   # 越不确定，前缀越短
    if phase in CONTACT_PHASES: k = min(k, K_CONTACT)
    return k

def make_safe_tail(chunk, k):
    tail = chunk.copy()
    tail[k:] = hold_pose(chunk[k-1])            # 保持已知安全位姿
    return tail
```

### 2.5 跨轴 conformal 校准（离线）

```python
def calibrate(groups, heldout, alpha=0.1):
    q = {}
    for g in groups:                            # g = (phase, axis)
        scores = [mahalanobis(x, z) for (x, z) in heldout[g]]
        q[g] = quantile(scores, 1 - alpha)      # 分组阈值
    return q
```

```python
def shift_hold(chunk, age):
```

## 3. 实验设计（v4：延迟-精度-分数联合）

| 级别 | 内容 | 通道/成本 | 通过判据 |
|---|---|---|---|
| L0-a | 估计器级联精度-延迟 Pareto（E0 / E0+E1 / E0+E1+E2） | 离线 | 在 `ε_exec` 不升的前提下，延迟降 ≥30% |
| L0-b | 陈旧度注入：人为延迟 0/1/2/4 个控制周期，比较有/无补偿 | 离线回放 | 补偿后 `Δaction` 降 ≥50% |
| L0-c | 本体创新 ROC：接触起始/滑移/干预 | 离线 | ROC-AUC ≥0.85（接触）、≥0.8（滑移） |
| L0-d | 事件触发复用：复用率 vs 漂移越界率 | 离线 | 越界率 ≤1%（含 K_max 看门狗） |
| L0-e | conformal 覆盖率：按 phase×axis | 离线 | 每组覆盖率 ≥1-α-0.03 |
| L1 | 2^(k-p)：{E0, E0+E1, E0+E1+E2} × {无补偿, 补偿} × {固定, 事件触发} | 离线 + 少量真机 | 主效应显著的 ≤3 组进 L2 |
| L2 | 2–3 任务真机：成功率、步骤分、p50/p99、time-to-complete | 单任务通道 | 步骤分/成功率 ≥ v1.1 基线，且 p99 不升 |

**指标注册表新增字段**：`ε_exec`（代理）、`U_rel`、`staleness Δ`、`reuse_rate`、`drift_violation`、`coverage`、`innovation_AUC`、`p50/p99`、`time_to_complete`。

**首批 L2 排队**：①I10 E0 本体创新（PlugCharger / PourOutMedicine / ZipUp，接触密集）→ ②I6 事件触发复用（自由空间任务 StackBowls / OrganizeTools）→ ③I9 先验协方差融合（未见物品轴）。

## 4. 创新点详细条目（本轮变更）

### I10 信念总线 + 本体创新触觉代理（新）★★★★★
- **动机**：世界状态不可直接观测（F20），无触觉（F8），延迟无时间戳（F21）且直接消耗步骤分（F17/F24）；v1.1 的估计器各自为政、无共享信念、无延迟意识。

- **落地步骤**：①E0 离线 ROC；②级联 + 调度器 + 截止时间；③延迟补偿；④事件触发复用 + K_max；⑤conformal 分组校准；⑥L0→L1→L2。
