### 第 1 轮灵感驱动研究记录（开放词汇 × 状态隔离）

**灵感词**：开放词汇、状态隔离

**直觉与动机**：
前几轮的七证一体（SRC-USC v25）隐含一个未被言明的前提——**标签空间是闭集**。SMC 的 conformal 语义覆盖、R@K 检索证书，本质上都是在一个可枚举、可离线校准的类别集合上的统计承诺。而「开放词汇」击穿的正是这个前提：真实任务的查询空间是无限且持续增长的（"把那个像杯子、但更红的物体递给我"），既不能预先枚举，也不能对任意新词给出普遍覆盖。开放词汇不是"多认几个类"，而是**认识论上的开集**：语义假设空间会膨胀，且膨胀方向不可预知。

「状态隔离」给出了架构层面的回答：既然语义假设空间必然开放，就不应把它的不确定性直接耦合进安全关键状态。**把开放的部分关进隔离域，把安全的部分锁在闭世界证书边界内**。核心洞见一句话：**开放的是语义假设空间，隔离的是安全证书边界；开放词汇决定"能做多少任务"，状态隔离决定"错误最多传播多远"。**

因此本轮不是再叠一张证书，而是引入**隔离中介的准入结构（isolation-mediated admission）**：语义域可以任意开放、任意犯错，但它对控制域只能通过一个经闭世界复核的准入端口写入。即使开放词汇证书完全失效，安全不变量也不会被污染——从"概率上更可能对"升级为"结构上错不进去"。

**形式化目标**：
1. 定义开放词汇扎根证书（OVGC）：在查询分布 P 上，开集 conformal 风险控制保证 `P[gt(q) ∉ G_K(x,q)] ≤ α_open + Δ_shift`；支持域外查询强制**弃权**而非幻觉扎根；语法组合树每个节点的扎根集合须落在子节点组合包络的 Hausdorff 容差内。
2. 定义状态隔离证书（SIC）：状态划分 `S = ⊎ S_i`，域间仅经带类型接口通信；要求分区无别名、接口良类型、非干扰 `A ⊥_I B`（含隐蔽通道排除）、语义域→安全关键域的写可达集 ≤ blast_bound、证书版本向量单调防回滚。
3. 定义隔离中介准入端口（GAP）：语义域产出"推测性扎根"→ 端口做几何/物理/USMC 闭世界复核 → 通过后才打 certified 污点并写入控制域。
4. 构建开放词汇-状态隔离统一准入门（OVSI-UC，v26）：`Exec_v26 = Exec_v25 ∩ Fil_ov ∩ Safe_Iso ⊆ Exec_v25`。
5. 用 rely-guarantee 证明：任意语义故障下控制域不变量保持，且故障爆炸半径 ≤ blast_bound；给出 v26 的"开放语义 + 封闭安全"对偶完备性。

## 1. 关键算法骨架（在 IP-444–447 骨架上扩展）

```python
# ============================================================
# IP-448 Open-Vocabulary Grounding Certificate (OVGC)
# ============================================================
@dataclass
class OpenVocabularyGroundingCertificate:
    """开集扎根 + 弃权 + 组合一致性 + 版本锁"""
    vocab_version: str
    alpha_open: float = 0.05
    delta_shift: float = 0.02
    K: int = 5
    support_radius: float = 0.35          # 嵌入空间支持域半径
    calibrator: 'OpenSetConformalCalibrator' = None
    grammar: 'CompositionalGrammar' = None

    def verify_query_coverage(self, scenes, queries, ground_truth) -> bool:
        """P[gt(q) ∉ G_K(x,q)] ≤ α_open + Δ_shift（仅对支持域内查询计承诺）"""
        if self.calibrator is None:
            return False
        losses = []
        for x, q, gt in zip(scenes, queries, ground_truth):
            if not self._in_support(q):
                continue  # 支持域外查询由 abstain 规则处理，不计入覆盖
            cand = self.calibrator.rank(x, q, K=self.K)
            miss = not any(self._match(c, gt) for c in cand)
            losses.append(float(miss))
        if not losses:
            return True
        n = len(losses)
        empirical = sum(losses) / n
        # Hoeffding 上界（有限样本 → 对查询分布 P 的高概率保证）
        ucbf = empirical + math.sqrt(math.log(1 / 0.05) / (2 * n))
        return ucbf <= self.alpha_open + self.delta_shift

    def verify_novelty_abstention(self, queries, outputs) -> bool:
        """支持域外查询必须弃权，禁止幻觉式扎根"""
        for q, out in zip(queries, outputs):
            if not self._in_support(q) and out.grounded:
                return False
        return True

    def verify_compositional_consistency(self, query, grounding, tol=0.05) -> bool:
        """组合语法树逐节点：‖G(node) ⊖ env(children)‖_H ≤ tol"""
        if self.grammar is None:
            return False
        tree = self.grammar.parse(query)
        if tree is None:
            return False
        node_sets = self._bottom_up_ground(tree, grounding)
        for node in tree.postorder():
            if node.is_combinator():
                envelope = node.combine([node_sets[c] for c in node.children])
                if hausdorff_distance(node_sets[node], envelope) > tol:
                    return False
        return True

    def verify_vocabulary_lock(self, current_version: str) -> bool:
        """嵌入/索引/校准器必须同版本，禁止跨版本污染"""
        return (current_version == self.vocab_version == self.calibrator.version)

    def verify_all(self, scenes, queries, gt, outputs,
                   current_version, tol=0.05) -> bool:
        return (self.verify_vocabulary_lock(current_version)
                and self.verify_query_coverage(scenes, queries, gt)
                and self.verify_novelty_abstention(queries, outputs)
                and all(self.verify_compositional_consistency(q, o, tol)
                        for q, o in zip(queries, outputs)))

    def _in_support(self, q) -> bool:
        return self.calibrator.distance_to_support(q) <= self.support_radius

# IP-449 State Isolation Certificate (SIC)
# ============================================================
@dataclass
class StateIsolationCertificate:
    """分区 + 接口良类型 + 非干扰 + 爆炸半径 + 版本向量"""
    domains: list['DomainSpec']            # id / invariant / capabilities
    interfaces: list['InterfacePort']      # 有向端口 source->sink + 契约类型
    blast_bound: int = 1
    safety_critical: set[str] = field(default_factory=lambda: {"ctrl", "usmc"})
    version_vector: dict[str, int] = field(default_factory=dict)

    def verify_partition(self) -> bool:
        """S = ⊎ S_i ⊎ S_shared；域内状态不可别名共享"""
        ids = [d.id for d in self.domains]
        if len(ids) != len(set(ids)):
            return False
        return all(d.invariant is not None for d in self.domains)

    def verify_interface_typing(self) -> bool:
        """每条边须携带可验证证书类型与良类型契约"""
        ids = {d.id for d in self.domains}
        for p in self.interfaces:
            if p.source not in ids or p.sink not in ids:
                return False
            if not p.has_certificate_type() or not p.contract.well_typed():
                return False
        return True

    def verify_non_interference(self, low: str, high: str,
                                traces: list['ExecutionTrace']) -> bool:
        """A ⊥_I B：固定 low 的 I-可观测投影，high 的内部状态不改变其可观测行为。
        采用双执行差分 + 信息流污点证明。"""
        ports = [p for p in self.interfaces
                 if p.source == high and p.sink == low]
        for tr in traces:
            proj_low = tr.project(low)
            for alt in tr.variants(high):
                if not self._same_observable(proj_low, alt.project(low)):
                    return False
            if tr.has_covert_channel(high, low):  # 时序/共享缓存/日志侧信道
                return False
            if not tr.port_values_declared(ports):
                return False
        return True

    def verify_blast_radius(self) -> bool:
        """语义域经写端口可达的安全关键域数 ≤ blast_bound"""
        adj = defaultdict(set)
        for p in self.interfaces:
            if p.is_write():
                adj[p.source].add(p.sink)
        reach = self._reachable("sem", adj)
        return len(reach & self.safety_critical) <= self.blast_bound

    def verify_provenance(self, required: dict[str, int]) -> bool:
        """证书版本向量支配；过期/回滚证书不得穿越端口"""
        return all(self.version_vector.get(k, -1) >= v
                   for k, v in required.items())

    def verify_all(self, traces, required_versions) -> bool:
        return (self.verify_partition()
                and self.verify_interface_typing()
                and self.verify_non_interference("ctrl", "sem", traces)
                and self.verify_blast_radius()
                and self.verify_provenance(required_versions))


# ============================================================
# IP-450 隔离中介准入端口 + 隔离内核 + OVSI-UC (v26)
# ============================================================
class GroundingAdmissionPort:
    """语义域 → 控制域的唯一写通道；所有扎根必须闭世界复核"""
    def __init__(self, semantic_model, closed_world_verifier, usmc):
        self.semantic_model = semantic_model
        self.verify_closed = closed_world_verifier   # 几何/物理可行性
        self.usmc = usmc

    def speculative_ground(self, q, x) -> 'Hypothesis':
        h = self.semantic_model.ground(q, x)
        h.taint = 'speculative'
        h.provenance = self.semantic_model.vocab_version
        return h

    def commit(self, h: 'Hypothesis') -> bool:
        """闭世界复核通过才允许写入控制域"""
        if h.taint != 'speculative':
            return False
        if not self.verify_closed(h):          # 几何/接触/可达性复核
            return False
        if not self.usmc.admits_hypothesis(h): # 结构-力-能量可行性
            return False
        h.taint = 'certified'
        return True


class IsolationKernel:
    """运行时隔离：语义平面 speculate，控制平面只接受 certified"""
    def __init__(self, port: GroundingAdmissionPort):
        self.port = port

    def run(self, queries, scenes) -> tuple[list, list]:
        committed, quarantined = [], []
        for q, x in zip(queries, scenes):
            h = self.port.speculative_ground(q, x)
            if self.port.commit(h):
                committed.append(h)
            else:
                quarantined.append(h)   # 隔离，不得影响 ctrl 域
        return committed, quarantined


@dataclass
class OpenVocabStateIsolationUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'
    ovgc: OpenVocabularyGroundingCertificate
    sic: StateIsolationCertificate
    isolation_kernel: IsolationKernel

    def admits(self, multi_plan, sensor_data, queries, gt_entities,
               outputs, trace) -> bool:
        # 1. 闭世界安全基线不可绕过（v25）
        if not self.src_usc.admits(multi_plan, sensor_data,
                                   gt_entities=gt_entities):
            return False
        # 2. 开放词汇仅在隔离语义域内评估
        if not self.ovgc.verify_all(
                sensor_data['scenes'], queries, gt_entities, outputs,
                sensor_data['vocab_version']):
            return False
        # 3. 隔离性：语义域对控制域非干扰 + 爆炸半径有界 + 版本单调
        if not self.sic.verify_all([trace], sensor_data['required_versions']):
            return False
        # 4. 只有经闭世界复核的扎根可进入计划
        committed, _ = self.isolation_kernel.run(queries, sensor_data['scenes'])
        admitted_ids = {h.id for h in committed}
        if not all(getattr(h, 'id', None) in admitted_ids
                   for h in outputs if getattr(h, 'grounded', False)):
            return False
        return True
```

## 2. 复杂度分析（增量）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |

## 3. 正确性论证（增量）

### 引理 13（开放词汇三重保证：覆盖-弃权-组合）
**陈述**：`OVGC.verify_all(...) = True` ⇒ 对支持域内查询分布 P：(1) 漏检风险 ≤ α_open+Δ_shift；(2) 支持域外查询全部弃权；(3) 组合查询的扎根落在子节点组合包络的 Hausdorff 容差内。
**证明**：`verify_query_coverage` 用有限样本上的 Hoeffding 上界控制经验漏检率，给出对 P 的高概率保证；Δ_shift 吸收校准-部署分布漂移。`verify_novelty_abstention` 强制支持域外 `grounded=False`，把"未知"转为显式弃权，避免 conformal 假设外推。`verify_compositional_consistency` 自底向上计算每个语法节点的组合包络并逐节点比对，阻断"词对但关系错"的幻觉组合。三者分别对应统计正确性、开集安全性、结构正确性。∎

### 引理 14（状态隔离的非干扰与有界爆炸半径）
**陈述**：`SIC.verify_all(...) = True` ⇒ 语义域内部状态变化不改变控制域的可观测轨迹，且语义故障经写端口可达的安全关键域数 ≤ blast_bound。
**证明**：`verify_non_interference` 对每对执行变体固定控制域接口投影、替换语义域内部状态，要求控制域投影不变（双执行差分），并排除时序/共享缓存等隐蔽通道；这即是标准非干扰。`verify_blast_radius` 在有向写端口图上做 BFS，可达安全关键域受 blast_bound 硬约束。`verify_provenance` 用版本向量支配关系阻断回滚/过期证书穿越端口。∎

### 引理 15（隔离中介准入保持闭世界不变量）
**陈述**：设语义域 `D_sem` 任意（可含幻觉），控制域 `D_ctrl` 的不变量 `Inv_ctrl` 在 v25 下成立；若 `D_sem` 对 `D_ctrl` 的唯一写通道是 GAP，且 GAP 每次写入前重新建立 `Inv_ctrl`，则任意语义故障下 `Inv_ctrl` 仍成立。
**证明**：采用 rely-guarantee：`D_sem` 的 guarantee 仅为"经 GAP 写且携带 OVGC 证书"，`D_ctrl` 的 rely 为"所有 GAP 写入满足闭世界复核"。GAP.commit 先做几何/物理复核再做 USMC 可行性验证，即每次写入前恢复 `Inv_ctrl`。由 rely-guarantee 组合规则，`D_sem ‖ D_ctrl` 保持 `Inv_ctrl`，与 `D_sem` 内部是否幻觉无关。∎

### 引理 16（v26 单调退化 + 有界爆炸半径）
**陈述**：`Exec_v26 ⊆ Exec_v25` 恒成立；且在任意语义漂移/幻觉下，受影响的安全关键域集合 ⊆ 语义域写可达集，大小 ≤ blast_bound。
**证明**：`Exec_v26 = Exec_v25 ∩ Fil_ov ∩ Safe_Iso`，交集必为子集，单调性直接成立。爆炸半径由引理 14 的 BFS 可达界与引理 15 的非干扰共同给出：语义域无法经未声明通道影响 ctrl，故影响范围被限制在写可达集内，且其与安全关键域交集大小 ≤ blast_bound。∎

### 定理（OVSI-UC 的开放语义-闭安全对偶完备性）
**陈述**：对任意多机计划 Π，`OVSI-UC.admits(Π)=True` ⟺ Π 满足：(1) v25 全部十项闭世界条件；(2) 开放词汇覆盖/弃权/组合三重保证；(3) 状态隔离的非干扰/接口/爆炸半径/版本四重保证；(4) 所有进入计划的扎根均经 GAP 闭世界复核。
**证明**：充分性由 `admits` 的四个连言分支与引理 13–15 直接可得；必要性为任一分支失败即拒证，对应开放词汇统计失效、隔离被穿透或未复核扎根越界三类风险之一未被缓解。结合引理 16，v26 同时获得单调退化与有界爆炸半径——这正是"语义开放、证书封闭"的对偶：开放词汇扩展任务可达集，隔离机制保证不安全集不扩张。∎

## 6. 本轮最大风险（最终确认）

**一句话**：**状态隔离可能制造虚假安全感——开放词汇的扎根错误能经时序、共享嵌入缓存、日志等未声明侧信道泄漏进安全域，而 conformal 覆盖在开放世界分布漂移下本就不成立；于是框架证明了"已隔离"，但语义错误其实早已越界，真实爆炸半径无界。**
