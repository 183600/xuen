# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮（新周期）；本轮灵感：「抓取规划」×「小样本学习」）

> 前 57 轮把"承诺"从信念推进到证据、从证据推进到少样本校准、跨模态对账、个性化信任。但这套体系始终站在"脚"和"地图"的尺度上：接触是可撤退的、地面是连续的、失败通常是"停住"。**抓取把它推到第一个真正低容错、半不可逆的物理边界**：手一旦闭合、物体一旦离台，失败就不再是"绕行"，而是"掉落 / 破碎 / 伤人"。本轮两个灵感正好在这里相撞：**小样本学习**回答"没见过的新物体怎么抓"，**抓取规划**提醒我们"抓取本身就是一次物理实验"。于是核心命题升级为 **"少样本可估、微试可逆、鲁棒可证、不可逆需授权的抓取承诺"**。关键转向：把一次大赌注（全抬升）拆成一串可撤退的小赌注（可逆微试阶梯），再用**反事实抓取证书**把"成功"与"鲁棒成功（不是幸运抓取）"分开。

核心矛盾：

- **H35（少样本泛化 vs 抓取低容错）**：抓取对质心、摩擦、形变、表面状态极度敏感；少样本先验在类别流形内可摊销，但新物体的 OOD 先验会"看起来对、物理上不稳"，而抓取的错误不是慢一点，是掉了 / 碎了。
- **H36（试探即样本 vs 试探即风险）**：想靠接触获得样本，但最有信息量的接触往往最接近不可逆；"好样本"与"高风险样本"高度重叠，必须用可逆性成本显式约束样本选择。
- **H37（成功 vs 鲁棒成功）**：一次偶然闭合的成功会强化错误先验；只有"在合理扰动下仍成功"才算证据，否则就是**幸运抓取**——把运气当成能力，是抓取里最危险的过拟合。

## 0. 直觉与动机

**灵感 1（小样本学习 → 抓取先验从物体流形摊销，但不托付给先验）**
直觉：人抓新杯子不需要一千次示范，因为抓取知识沿"形状—功能—材质"流形平滑迁移；这正是小样本学习擅长的。但第 57 轮的教训必须原样搬过来：**先验给效率，共形给保底**。元先验只决定"先试哪几个抓法、按什么顺序试"，一旦物体描述子落在语料盲区（新奇形状、隐藏质心、液态/颗粒内容物、超大摩擦不确定性），OOD 门立刻把系统切到又宽又慢的非参保底，绝不让"语料里没有的世界"获得高置信抓取。

**灵感 2（抓取规划 → 抓取本身是最好的探针，把大赌注拆成微试阶梯）**
直觉：非要把一次全抬升当成"抓 / 不抓"的二元赌注，是这场博弈里最笨的下注方式。真实抓取天然分层：悬停 → 预成形接近 → 零净力触碰 → 轻捏 → 部分抬升 → 完全搬运。每一层都是**一次可撤退的物理实验**：轻捏能估摩擦锥，部分抬升能估质心偏置与滑移，且都还能松手退回。于是"抓取规划"从"选一个最优抓取位姿"变成"**选一条可逆性递减、信息量递增的微试路径**"——把不可逆的大失败摊薄成一串可承受的小误差。

**灵感 3（反事实鲁棒证书 → 把"成功"与"幸运成功"分开）**
直觉：一次成功有三种解释：抓法真稳、扰动恰巧有利、传感器标定恰好抵消了误差。只看名义成功就是在奖励幸运。**反事实抓取证书（CGC）**问的不是"这次成没成"，而是"把物体位姿抖一下、质心挪一点、摩擦降一档、质量加一点、手标定偏一点，它**最坏**还成不成"。名义成功但最坏裕度很低的，是幸运抓取，必须拒绝或换抓法；这正是把第 57/58 轮的"证伪回溯"从地图与语料搬到抓取力旋量空间。

**灵感 4（主动样本选择 → 每单位不可逆性买到的信息量）**
直觉：微试不是越多越好，每升一级都在消耗可逆性。正确的排序不是"信息量最大优先"，而是"**信息量 / 不可逆性成本**最大优先"：先用最便宜的零净力触碰把候选砍半，再用轻捏区分摩擦假设，最后才用部分抬升验证质心——绝不为了多拿一点信息就提前跨进不可逆层。VOI 沿用第 57 轮的悲观元估计，但分母加上不可逆性惩罚，这条改动保证"少样本"永远不能变成"更敢赌"。

**灵感 5（合流 → 抓取证据门把"提议"与"接触授权"焊死）**
直觉：少样本先验再准，也只能**提议**抓取候选；真正授权手闭合的是物理微试证据与鲁棒证书。全抬升（ℓ≥4）的必要证据集固定为 {物理微试证据 ∧ 鲁棒证书 ∧ 接触裕度}，**仅凭 EV-affordance\* 不得进入接触**。击穿安全需要：元先验错 ∧ OOD 漏检 ∧ 微试信号错 ∧ 证书漏扰动 ∧ 无人类兜底——纵深从"证据五层"再加"物理可逆层"与"鲁棒认证层"。

**灵感 6（与既有体系衔接 → 语义给目标、ROS 给出处、回放给可挑战性、本轮给可逆物理）**
直觉：若上一轮已经有了"语言规约—运行时溯源—可回放承诺"，本轮不另起炉灶，而是把抓取作为**最末端的物理不可逆层**接进去：语义编译回答"抓什么 / 放哪 / 多轻"，ROS 溯源回答"这条视觉/触觉观测可不可信"，回放回答"这次抓取能不能被复核"，而本轮新增的可逆微试与反事实证书回答"**手到底该不该现在闭合**"。四者都只能否决或收窄，不能放宽。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（抓取可供性元先验 GAM）** 元训练集 `𝒟_g={(o_j,c_j,D_j^{1:k},y_j)}`：物体（点云/网格/材质）、上下文 `c`（任务、手型、载荷、精度要求）、k 次演示或历史尝试、结果 `y`（成功、鲁棒裕度、失效模式）。摊销先验 `q_φ(θ_g|P_o,c,D_{1:k})`，`θ_g=(grasp 成功分布, 质心后验, 摩擦后验, 刚度/形变, 抓取族先验)`；抓取候选空间 `𝒢=SE(3) 位姿 × 预成形 × 力曲线`。校准契约：`ECE_k(q_φ)≤ε_g(k)` 且随 k 单调不增；样本效率证书 `k*_g(w*)=min{k:E[|C_k|]≤w*}`。OOD 门 `n_g(o)=−Σ log p̂_φ(·|P_o,c)`，`n_g>θ_ood^g ⇒` 退共形带 `C_cf^g`（覆盖 `≥1−α_g`）。**硬规则：ID 先验只进"提议与排序"，不进"接触授权"。**

**定义 140（可逆微试阶梯 RMTL）** 接触层级 `ℓ∈{0..5}`：0 视觉/悬停；1 预成形接近（无接触）；2 零净力触碰；3 轻捏（`F≤F_lt`）；4 部分抬升（载荷 `≤m_lt·g`、高度 `≤h_lt`）；5 完全搬运。每级带：可逆性 `rev(ℓ)` 单调不增、退回动作 `abort(ℓ)`、证据 `E_ℓ`（接触位姿、法向力、滑移、形变、摩擦锥、质心线索）。微试 `m=(ℓ, 动作序列)` 的可逆性 `rev(m)=min_{path} rev`；可逆探测集 `ℛ={m:ℓ(m)≤ℓ_safe}`，`ℓ_safe` 由脆弱性/材质/任务决定。退回保证（A42）：`ℓ≤3` 的微试在 `τ_abort` 内退回且**零净位姿改变、无力致损伤**。`ℓ≥4` 必须通过抓取证据门。

**定义 141（反事实抓取证书 CGC）** 候选 `G`、名义成功 `success(G)`、物理合理扰动集 `Δ=Δ_pose×Δ_com×Δ_μ×Δ_mass×Δ_calib`。鲁棒裕度 `ρ_G=min_{δ∈Δ} margin(G,δ)`，`margin` 取力旋量空间 `ε` 度量 / 接触稳定裕度。灾难性失效 `cata(G,δ)∈{跌落高度>h_d, 易碎物破碎, 失稳抛射}`，`P(cata)≤δ_cata` 为硬约束。证书通过 ⇔ `success(G) ∧ ρ_G≥θ_g ∧ P(cata)≤δ_cata`。**幸运抓取**定义：`success(G)=1` 但 `ρ_G<θ_g` ⇒ 拒绝/换抓法/补证。共形版：`P(ρ_G≥θ_g)≥1−α_rob`，用留出扰动残差校准。

**定义 142（抓取证据门 GEG）** 证据类：`EV-affordance*`（须 ID 校准或 OOD 共形带，**仅可提议**）、`EV-microtrial`（`ℓ∈{2,3}` 可逆微试证据）、`EV-robust`（CGC 通过）、`EV-contact-margin`（力/滑移裕度在阈内）、`EV-human`（澄清或 L2 授权）。全抬升（`ℓ≥4`）必要证据集 `={EV-microtrial ∧ EV-robust ∧ EV-contact-margin} ∪ 不可逆接触额外佐证`；脆弱/易碎物体额外禁止灾难性失效模式。**仅 `EV-affordance*` 不得进入任何接触层级。** 与 IP-137 FSE 集成：`EV-affordance*` 复用其 `EV-probe*` 校准检查。

**定义 143（主动抓取样本选择 AGSS）** 抓取相关潜变量 `z=(CoM, μ, k_stiff, 表面粗糙度)`，后验 `b(z)`。下一微试
`m*=argmax_{m∈admissible} VOI_m(b) / (cost_risk(m) + λ·(1−rev(m)))`，
`s.t. m∈ℛ` 或已获 `EV-human` 授权；`VOI_m=E[H(b)−H(b'|m)]` 取**元悲观后验**（继承 PCE+）。停止条件：CGC 通过 ∧ GEG 过 ⇒ 全抬升；预算耗尽或无可行可逆候选 ⇒ 换抓取族 / 重定向 / 人类协商 / 安全停。关键不变式：**VOI 必须除以不可逆性成本**，故信息再大也不能把系统"买"进不可逆层。

**定义 144（抓取-承诺-演化算子 GCE，升级 SVCR / PCE+）** 每检查点：
① **感知与少样本提议**：GAM 给 ID 后验或 OOD 共形带，生成并排序候选（只增候选）；
② **微试规划**：AGSS 选可逆性递减路径（只增证据、不授权）；
③ **执行微试**：RMTL 逐级接触，退回保证生效，更新 `b(z)`；
④ **鲁棒认证**：CGC 对当前最佳候选做反事实最坏裕度与灾难性失效检查（只收窄）；
⑤ **证据门**：GEG 判定是否允许 `ℓ≥4`（只否决）；
⑥ **出口**：全抬升 / 换抓法 / 人类协商 / 安全停。
与 SVCR 串联：语义编译给目标与力度约束，ROS 溯源给观测出处，REC 给可挑战性，GCE 给"手该不该闭合"。

## 2. 关键算法伪代码（完整版见产物区）

```python
def grasp_meta_propose(o, c, demos, gmeta):          # IP-139：只提议，不授权
    if gmeta.ood_score(o, c) > gmeta.theta_ood:
        return Proposal(cls='OOD', belt=gmeta.conformal_belt(o, alpha=alpha_g))
    post = gmeta.q_phi(o, c, demos[:gmeta.k_star])
    return Proposal(cls='ID', post=post, ece=gmeta.ece_decl[len(demos)],
                    cands=rank_robust(post, o, c))

def reversible_probe_plan(o, c, cands, b, budget):   # IP-143：信息/不可逆性
    while budget.left and not certified(b):
        m = argmax(admissible(cands) & reversible_set(o, c),
                   key=lambda x: voi_meta(b, x) / (risk_cost(x) + lam*(1-rev(x))))
        if voi_meta(b, m) < theta_voi: break
        b = condition(b, run_microtrial(m, abort=RMTL.abort(m)))   # IP-140
        budget.spend(m)
    return b, best(cands, b)

def counterfactual_certificate(G, b, delta_set):     # IP-141：幸运抓取检测
    margins = [grasp_margin(G, perturb(sample_object(b), d)) for d in delta_set]
    rho = min(margins)                               # 最坏情形，不是期望
    cata = max(catastrophic_prob(G, d) for d in delta_set)
    return Certificate(ok=(rho >= theta_g and cata <= delta_cata),
                       rho=rho, lucky=(rho < theta_g), cata=cata)

def grasp_evidence_gate(G, cert, micro, margin, persona, level):  # IP-142
    if level < 4:                                    # 可逆层：微试即可
        return 'ok' if micro.reversible else 'reject'
    necessary = micro.ok and cert.ok and (margin <= theta_margin)
    if not necessary:                     return 'reject', 'insufficient'
    if is_fragile(G) and cert.cata > delta_cata: return 'reject', 'catastrophic'
    return 'ok'

def grasp_commit_evolve(cp, M, persona, budget, consent):  # IP-144
    prop = grasp_meta_propose(cp.o, cp.c, cp.demos, gmeta)
    if prop.cls == 'OOD' and not prop.belt.certified: return safe_stop(prop)
    b, G = reversible_probe_plan(cp.o, cp.c, prop.cands, b0, budget)
    cert = counterfactual_certificate(G, b, delta_set(cp.o))
    if grasp_evidence_gate(G, cert, micro_of(b), margin_of(b), persona, 5)[0] != 'ok':
        return regrasp_or_negotiate(G, cert, b, consent, tau_int(persona.auth))
    return full_lift(G, cert)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| GAM | O(d_φ)/候选；OOD 回退 O(N_cal^g) | O(\|𝒟_g\|) 静态 | ε_g 声明诚实、OOD 漏检 ≤δ_ood^g |
| RMTL | O(ℓmax) 步/微试 | O(\|E_ℓ\|) | ℓ≤3 退回保证、力/滑觉校准（A42） |
| CGC | O(\|Δ\|·C_margin) | O(\|Δ\|) | 最坏情形而非期望、灾难性失效硬约束（A43） |
| GEG | O(\|σ\|) | O(\|σ\|) | 仅先验不接触、全抬升必要集不可替代 |
| AGSS | O(k_micro·\|cands\|·C_VOI) | O(\|cands\|) | 比值准则、可逆性递减、悲观 VOI |
| GCE | O(k_micro·(C_VOI+C_margin)+C_meta) | O(\|𝒢\|+\|σ\|) | 六段单调、有界不可逆、四态完备 |

**正确性定理（Few-shot Certified Robust Grasping, FCRG，概要）**
在 A33–A40（第 56–57 轮）之上增加：**(A41)** 抓取元校准与 OOD 门：ID `ECE_k≤ε_g(k)` 且声明诚实，OOD 漏检 `≤δ_ood^g`，共形带覆盖 `≥1−α_g`；**(A42)** 微试可逆性：`ℓ≤3` 微试在 `τ_abort` 内零净位姿退回且无力致损伤，力/滑觉经校准；**(A43)** 反事实证书健全性：`Δ` 覆盖物理合理变化 `≥1−α_rob`，裕度可计算，灾难性失效检测无误漏；**(A44)** 抓取证据门健全：全抬升必要集不可被 `EV-affordance*` 替代，授权只增证据不降门槛。则：

1. **抓取承诺健全性**：ID 路径 `P(全抬升失败) ≤ δ_f+ε_g(k)+δ_probe+ε_h(w_max)+δ_cata`；OOD 漏检路径额外贡献 `≤δ_ood^g·α_g`。
2. **幸运抓取可证伪性**：`ρ_G<θ_g` 的抓取通过概率 `≤α_rob+P(Δ 未覆盖真实扰动)`；"多次名义成功"不能替代"扰动下成功"。
3. **交互单调性强化**：少样本先验只增候选/排序，微试只增证据，证书只收窄，证据门只否决；不存在"样本更少 ⇒ 更敢抓"的升险通道。
4. **有界不可逆性与终止性**：每检查点 `≤k_micro` 次可逆微试、至多一次全抬升，终止于 {全抬升, 换抓法, 人类协商, 安全停}。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp [ δ_f + ε_g(k) + δ_probe + δ_cata + δ_ood^g·α_g + ε_h + δ_prov + δ_rep ]
          − P(Δ 漏掉真实扰动) − P(abort 失效) − P(脆弱性误判)
```

关键：**先验给候选、微试给证据、证书给鲁棒、证据门给授权**——效率与安全再次解耦，赌注不押在少样本模型上，而是押在"每一步都可撤退、每一次成功都要过最坏情形"上。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 未建模扰动（内部液体、暗裂、涂层）使"鲁棒"证书失效 | 高 | Δ 显式含隐藏属性场景；未知一律按脆弱处理；力/速度硬限幅独立于学习模型 |
| 微试"可逆"是幻觉（轻捏已造成塑性变形/滑落） | 高 | 硬件级力限幅+柔顺+快速释放；`ℓ_safe` 由材质保守设定；退回保证做型式试验 |

## 6. 本轮最大风险

**一句话**：本轮最大的风险是"**把证书当成物理**"——反事实鲁棒只对已建模扰动集成立，未建模的隐藏属性（内部液体晃动、暗裂、涂层、温变摩擦）可以让一个"鲁棒认证"的抓取在真实世界第一次就灾难性失败；因此必须让硬件级力/速度限幅、保守的脆弱性判定（未知即脆弱）与人类兜底独立于任何学习模型与证书存在，宁可抓得又慢又保守，也绝不把"证书通过"当作"物理已安全"。

### IP-139 GAM（抓取可供性元先验，含 OOD 共形保底）

```python
def grasp_meta_propose(o, c, demos, gmeta):
    z = object_context(o, c)                          # 形状/材质/尺度/手型
    n = gmeta.ood_score(o, c, z)                      # 描述子分布外分数
    if n > gmeta.theta_ood:                           # 盲区 → 只给共形带
        belt = conformal_belt_g(gmeta.residuals, sim=z,
                                alpha=gmeta.alpha_g)  # 覆盖 ≥1-α_g
        return Proposal(cls='OOD', belt=belt,
                        cands=conservative_grasp_family(o, c))
    k = min(len(demos), gmeta.k_star)                 # 样本效率证书
    post = gmeta.q_phi(o, c, demos[:k])
    cands = rank_by_robust_prior(post, o, c)          # 只排序，不授权
    return Proposal(cls='ID', post=post, cands=cands,
                    ece=gmeta.ece_decl[k], kstar=gmeta.k_star)

def rank_by_robust_prior(post, o, c):
    return sorted(post.candidates, key=lambda G: (
        -post.mean_success(G),
        -post.robust_margin_prior(G),                 # 先验只影响顺序
         G.irreversibility_estimate))
```

### IP-141 CGC（反事实抓取证书与幸运抓取检测）

```python
def counterfactual_certificate(G, b, delta_set):
    margins, catas = [], []
    for d in delta_set:                              # 姿位/质心/摩擦/质量/标定
        G_d = perturb_grasp(G, d, b)
        margins.append(grasp_margin(G_d))            # 力旋量 ε 度量/接触裕度
        catas.append(catastrophic_prob(G_d, d))      # 跌落/破碎/抛射
    rho  = min(margins)                             # 最坏情形，不是期望
    cata = max(catas)
    return Certificate(ok=(rho >= THETA_G and cata <= DELTA_CATA),
                       rho=rho, cata=cata,
                       lucky=(rho < THETA_G))        # 名义成但最坏不稳

def grasp_margin(G_d):
    return epsilon_metric(grasp_wrench_space(G_d))   # Ferrari-Canny 类裕度

def catastrophic_prob(G_d, d):
    if is_fragile(G_d.object):
        return P(drop_or_crush(G_d, d))              # 易碎物硬约束
    return P(escape_or_throw(G_d, d))
```

### IP-143 AGSS（主动抓取样本选择）

```python
def select_microtrial(cands, b, budget, o, c):
    best, best_score = None, -inf
    for m in admissible(cands) & reversible_set(o, c):
        voi = voi_meta_pessimistic(b, m)             # 悲观元 VOI（继承 PCE+）
        cost = risk_cost(m) + LAMBDA * (1.0 - rev(m))# 不可逆性进分母
        if voi < THETA_VOI:                          # 信息不值这一步
            continue
        score = voi / cost
        if score > best_score:
            best, best_score = m, score
    return best

def reversible_first(cands, b):
    # 同 VOI 下高可逆优先；否则按 VOI/不可逆性比降序
    return sorted(cands, key=lambda m: (
        -voi_meta_pessimistic(b, m) / (risk_cost(m) + 1e-9),
        rev(m)))
```

### IP-144 GCE（抓取-承诺-演化，升级 SVCR/PCE+）

```python
def grasp_commit_evolve(cp, M, persona, budget, consent, gmeta):
    prop = grasp_meta_propose(cp.o, cp.c, cp.demos, gmeta)   # ① 只提议
    if prop.cls == 'OOD' and not certified(prop.belt):
        return safe_stop(prop, reason='ood_uncertified')
    if prop.cls == 'ID' and prop.ece > EPS_G[len(cp.demos)]:
        return safe_stop(prop, reason='meta_calibration_violated')

    b = prior_from(prop)                                     # ② 初始后验
    micros, G = [], None
    while budget.left and not certified(b):
        m = select_microtrial(prop.cands, b, budget, cp.o, cp.c)
        if m is None: break                                  # 无可逆候选
        micros.append(run_microtrial(m, RMTL.abort, cp.o))   # ③ 可逆微试
        b = condition(b, micros[-1].evidence)
        budget.spend(m)
        G = best(prop.cands, b)

    if G is None: return regrasp_or_human(cp, prop, persona, consent)

    cert = counterfactual_certificate(G, b, delta_set(cp.o, b))  # ④ 鲁棒认证
    st = grasp_evidence_gate(G, cert, micro_of(micros), margin_of(micros),
                             persona, level=5)                   # ⑤ 证据门
    if st[0] != 'ok':
        if cert.lucky and budget.left:                       # 幸运 → 补微试/换抓
            return retry_with_new_family(G, cert, b, budget)
        return regrasp_or_negotiate(G, cert, micros, consent,
                                    tau_int=tau_int(persona.auth))
    return full_lift(G, cert, certificate=Jg(cert, micros))   # ⑥ 全抬升
```

**正确性定理（FCRG: Few-shot Certified Robust Grasping）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立，并增加：
**(A41)** 抓取元校准与 OOD 门：ID 区域 `ECE_k≤ε_g(k)` 且声明诚实，OOD 漏检率 `≤δ_ood^g`，共形带覆盖 `≥1−α_g`；
**(A42)** 微试可逆性：`ℓ≤3` 的微试在 `τ_abort` 内零净位姿退回、无力致损伤，力/滑觉经校准；
**(A43)** 反事实证书健全性：`Δ` 覆盖物理合理变化 `≥1−α_rob`，`margin` 可计算，灾难性失效检测无误漏；
**(A44)** 抓取证据门健全：全抬升必要集不可被 `EV-affordance*` 替代，个性化授权只增证据不降门槛。则：

1. **抓取承诺健全性**：ID 路径 `P(全抬升失败) ≤ δ_f+ε_g(k)+δ_probe+ε_h(w_max)+δ_cata`；OOD 漏检路径额外贡献 `≤δ_ood^g·α_g`。
2. **幸运抓取可证伪性**：`ρ_G<θ_g` 的抓取通过概率 `≤α_rob+P(Δ 未覆盖真实扰动)`。
3. **交互单调性强化**：少样本先验只增候选/排序，微试只增证据，证书只收窄，证据门只否决；不存在"样本更少 ⇒ 更敢抓"的升险通道。
4. **有界不可逆性与终止性**：每检查点 `≤k_micro` 次可逆微试、至多一次全抬升，终止于 {全抬升, 换抓法, 人类协商, 安全停}。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp [ δ_f + ε_g(k) + δ_probe + δ_cata + δ_ood^g·α_g
                   + ε_h + δ_prov + δ_rep ]
          − P(Δ 漏掉真实扰动) − P(abort 失效) − P(脆弱性误判)
```

**命题 1（可逆优先不劣性）** 在任何"不可逆动作一旦失败即终止本轮"的决策过程中，若两次微试 VOI 相同而可逆性不同，则先执行高可逆性者可弱支配先执行低可逆性者（前者保留后者作为后续选项，反之不成立）。故 `VOI/(cost+λ(1−rev))` 在 VOI 相同时退化为可逆优先，且不减少可达证据集。

**命题 2（名义成功不能替代鲁棒成功）** 设扰动集 `Δ` 中存在使 `margin` 由正翻负的扰动，其占比为 `p_flip`。则只用名义成功训练的成功率估计至少高估 `p_flip`；CGC 以最坏情形替代期望，在 A43 下对该类翻转扰动免疫。这解释了为什么"多试几次都成了"不能替代"扰动下仍成功"——重复的是同一个幸运，不是能力。

关键：**先验给候选、微试给证据、证书给鲁棒、证据门给授权**；效率与安全再次解耦，赌注不押在少样本模型上，而押在"每一步都可撤退、每一次成功都要过最坏情形"上。第 57 轮"一切判定器走隔离"在本轮落成 **"一切物理不可逆动作必须可退、可证伪、可授权"**。

云边协议 CEB++ → **CEB-Grasp**：
- 云端下发的抓取先验/策略增量必须先进入**提案影子区**，无直接驱动权限；只有经边端真实微试流回归（ECE 不劣化 ∧ OOD 检出率不降 ∧ 幸运抓取拒绝率不降 ∧ 退回保证不破）才允许获得提议权；
- **提议权、微试权、全抬升权三者分离**：云更新最多提升提议质量，永远不能获得全抬升授权；全抬升始终由边端 GEG + 人类兜底；
- 边端回传微试证据、`ρ_G` 分布、abort 失效事件与灾难性失效窗口，作为云端先验补盲与硬限幅参数校准依据；含 abort 失效或未认证的窗口禁止进入训练集。

## 6. 本轮最大风险

**一句话**：本轮最大的风险是"**把证书当成物理**"——反事实鲁棒只对已建模扰动集 `Δ` 成立，未建模的隐藏属性（内部液体晃动、暗裂、涂层、温变摩擦）可以让一个"鲁棒认证"的抓取在真实世界第一次就灾难性失败；因此必须让硬件级力/速度限幅、保守的脆弱性判定（未知即脆弱）与人类兜底独立于任何学习模型与证书存在，宁可抓得又慢又保守，也绝不把"证书通过"当作"物理已安全"。
