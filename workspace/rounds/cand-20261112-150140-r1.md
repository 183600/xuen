# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「场景落地」×「仿真到现实迁移」）

> 第 60 轮实现了「认知驱动的场景-执行闭环」：SSM 把场景转成阻抗先验、CIEC 把意图锁成实时约束、EPIR 保证 ROS 消息丢失下证据链完整、SERC 统一闭环、PCE++++ 管理四维认知预算。但**三个落地级漏洞**仍未解决：
> 1. **场景先验的来源不可信**：π_scene(K|z) 的 μ/Σ 来自仿真或实验室标定；真实场景的摩擦、柔顺、传感噪声、通信抖动发生**域漂移**，导致「仿真里安全的 K_safe 在现实中不安全」——这是典型的 sim-to-real gap。
> 2. **置信度是自证的**：第 60 轮的 scene_conf 是模型自身的后验置信，**不是对现实有效性的证据**。模型可以在错误场景上给出高置信（calibrated-in-sim, wrong-in-real），SIC 三元校验因而可能被“自信地欺骗”。
> 3. **落地是一个过程而非开关**：SERC 默认系统一上来就拥有全权限执行；真实部署必须**分级放权**（仿真→硬件在环→影子→限权→全自主），并在物理漂移后**可撤销**；否则迁移证书一旦过期，旧权限仍会驱动真实电机。

## 0. 直觉与动机

**灵感 1（场景落地 → 运行设计域 ODD + 场景契约）**
直觉：场景落地不是「把算法搬上机器人」，而是「把机器人放进一个被明确承认的**运行设计域 ODD**」。ODD = (地面材质集、坡度范围、负载范围、光照/噪声、网络时延分布、人机交互模式)。关键洞见：**每个场景阻抗先验必须携带一个 ODD 标签**——π_scene(K|z, ODD)。离开 ODD 不是「置信度下降」，而是「**许可失效**」：K_safe 必须立即退回保守域。这把「场景识别」升级为「**场景-许可联合识别**」。

**灵感 2（仿真到现实迁移 → 残差迁移算子 RTOM）**
直觉：不要迁移参数，迁移**参数的修正算子**。仿真给出先验 K_sim，现实给出少量接触证据；令 K_real = K_sim + Δ(x)，把 Δ 建成以物理特征 x（摩擦、温度、负载、速度）为输入的高斯过程残差模型，用**few-shot 贝叶斯校准**在 3~5 次真实接触内给出带置信椭球的 K_real。关键洞见：**误差的界比误差的点估计更重要**——K_safe 的收缩应当由 Δ 的置信上界 δ_K 驱动，而不是由 Δ 的均值驱动；这直接给出「迁移鲁棒安全边际」ρ = z_{1−α}·σ_Δ。

**灵感 3（仿真到现实迁移 → 仿真支撑域与真实性差距监测 RGMon）**
直觉：仿真永远只能覆盖有限分布。若真实观测 x_r 落在仿真支撑集 S_sim 之外（密度 p_s(x_r) < ε 或 Mahalanobis 距离超阈值），那么所有基于仿真的先验都**不可外推**。关键洞见：**检测「不认识的现实」比提升「已知现实」的精度更安全**——RGMon 输出 out-of-support 报警，触发权限降级，而不是继续用高置信的仿真先验。

**灵感 4（三灵感合流 → 分级场景落地协议 SDP + 迁移证书 T-Cert）**
直觉：把落地写成**带证据门禁的状态机**：g0 纯仿真 → g1 硬件在环 → g2 影子模式（只读真实遥测）→ g3 限权 rollout（限速/限力/有人监督）→ g4 全自主；每一级晋升需要**迁移证书 T-Cert**（域差 δ_TV、残差界 δ_K、ODD 覆盖率、越界率、影子一致率、回退可验证性、有效期 TTL）。关键洞见：**证书是有保质期的**（物理会漂移、场景会磨损），过期自动降权。

**灵感 5（合流 → 迁移感知的 SERC-T）**
直觉：把第 60 轮 SERC 闭环中的 K_safe 编译换成**对抗残差界的鲁棒编译**：K_safe^T = {K | K∈K_safe^scene 且 ∀Δ: ||Δ||≤δ_K, K+Δ 仍满足接触力/稳定性约束}。同时 scene_conf 必须乘以迁移可信度 γ_T ∈ [0,1]（由 T-Cert 与 RGMon 联合给出），得到**有效置信度** γ_eff = scene_conf·γ_T，用于 SIC 判定。关键洞见：**仿真置信 ≠ 现实可信**，必须乘上迁移折扣。

**灵感 6（PCE+++++ → 迁移预算与权限感知 VOI）**
直觉：迁移不是免费的：校准接触、影子运行、门禁评审都消耗资源。把 B_transfer = (B_calib, B_shadow, B_gate, B_ttl) 纳入预算，并引入**权限等级 a∈{0, 0.25, 0.5, 0.75, 1}**。VOI 变为「权限感知」：只有当一个探针带来的**迁移不确定度下降**足以跨过下一道门禁阈值时，才值得消耗校准预算。关键洞见：**不是信息越多越好，而是「刚好够升一级权限」的信息最值钱**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（场景-许可联合域与运行设计域 ODD）** 场景落地模型 D = (ODD, Π_scene, L)。其中：
- **运行设计域** ODD = (M_mat, Θ_slope, W_load, E_noise, N_net, H_human) 为六元组（材质、坡度、负载、噪声、时延、人机模式）。
- **场景-许可先验** π_scene(K|z, o) = N(K; μ(z,o), Σ(z,o))，o ∈ ODD；先验的支撑随 ODD 切片而变。
- **许可函数** L(z,o) ∈ {GRANT, RESTRICT, REVOKE}：仅 L=GRANT 时允许在完整 K_safe 域内编译；RESTRICT 只允许限权子域；REVOKE 强制保守域。
- **越界判定** o_t ∉ ODD ⇒ L=REVOKE，K_safe ← K_conservative，并记一次 ODD 违约。

**定义 162（残差迁移算子 RTOM）** 令仿真先验给出 K_sim(z)，真实阻抗建模为
```
K_real = K_sim(z) + Δ(x; θ) + ε,   Δ(·) ~ GP(0, k_θ(·,·)),   ε ~ N(0, σ²I)
```
- **物理特征** x = (μ_friction, T, payload, v, surface_roughness)。
- **few-shot 后验**：给定 n 次真实接触 D_n={(x_i, K_i)}，
  ```
  μ_Δ(x*) = k_*ᵀ (K_n + σ²I)⁻¹ y_n
  σ_Δ²(x*) = k(x*,x*) − k_*ᵀ (K_n + σ²I)⁻¹ k_*
  ```
  其中 y_n = K_real,n − K_sim,n，K_n 为核矩阵。
- **残差上界** δ_K(x*) = z_{1−α}·σ_Δ(x*) 作为单侧置信上界，即鲁棒安全边际。
- **迁移折扣** γ_T = exp(−δ_K/δ_0)·1[OOS=false] ∈ [0,1]。

**定义 163（仿真支撑域与真实性差距监测 RGMon）**
- **仿真支撑集** S_sim = {x | p_s(x) ≥ ε}，由域随机化样本的密度模型估计。
- **越界分数** oos(x) = max(0, D_M(x; μ_s, Σ_s) − τ_M)，D_M 为 Mahalanobis 距离；亦可取 −log p_s(x) − τ_p。
- **三级报警** NOMINAL（oos=0）、WARN（0 < oos ≤ τ_w）、ALARM（oos > τ_w）。
- ALARM ⇒ γ_T←0，L←RESTRICT/REVOKE，触发 T-Cert 复核与 SDP 降级。

**定义 164（分级场景落地协议 SDP）** 部署状态机 G = ({g0..g4}, Trans, Gate)：
- **等级**：g0 纯仿真、g1 硬件在环、g2 影子（只读真实遥测、不驱动）、g3 限权（v≤v_g, F≤F_g, 人在环）、g4 全自主。
- **门禁** Gate(g_i→g_{i+1}) = TC_valid ∧ (coverage ≥ τ_cov) ∧ (OOS_rate ≤ τ_oos) ∧ (shadow_agree ≥ τ_shadow) ∧ fallback_verified。
- **晋升/降级**：晋升需门禁全通过且权限感知 VOI ≥ 0；降级可由 ALARM、TC 过期、连续 k 次 D⁺ 超阈任一触发，且允许跨级回退。

**定义 165（迁移证书 T-Cert）** TC = (δ_TV, δ_K, coverage, oos_rate, shadow_agree, fallback_proof, ttl)。有效性：
```
TC_valid = (δ_TV ≤ τ_TV) ∧ (δ_K ≤ τ_K) ∧ (coverage ≥ τ_cov)
         ∧ (oos_rate ≤ τ_oos) ∧ (now ≤ t_issue + ttl) ∧ (fallback_proof = VERIFIED)
```
- **可撤销性**：任一门禁失败或 RGMon ALARM ⇒ TC.revoke()，权限立即降级；证书不可“继承”，每次物理改动/维护后必须重签。

**定义 166（迁移感知的 SERC-T）** 在第 60 轮 SERC 之上，每步替换为：
```
① π_scene^T ← RTOM.transfer(π_scene^sim, D_n, ODD)
② γ_eff ← scene_conf · γ_T
③ K_safe^T ← {K∈K_safe^scene | ∀||Δ||≤δ_K: safe(K+Δ)}
④ 若 γ_eff < τ_eff 或 L ≠ GRANT: K ← K_conservative
⑤ TC ← T-Cert.build(δ_TV, δ_K, coverage, oos_rate, shadow_agree)
⑥ SDP.gate(TC)；执行；EV-exec 回写并触发 RTOM.calibrate
```

**定义 167（PCE+++++ 迁移预算与权限感知 VOI）** B = (B_scene, B_intent, B_ros, B_exec, B_calib, B_shadow, B_gate, B_ttl)，权限集 A={0,0.25,0.5,0.75,1}。
```
voi_auth(π) = VOI_meta(π) − cost_cog(π) − cost_exec(π) − cost_transfer(π)
cost_transfer = λ_calib·E_calib(π) + λ_shadow·T_shadow(π) + λ_gate·C_gate
a*(π) = max{ a∈A : TC_valid(a,π) ∧ voi_auth(π) ≥ 0 }
```
- B_calib 耗尽 ⇒ 冻结当前 TC 并保持权限，不再晋升；
- B_gate 耗尽 ⇒ 只可维持不可晋升；TC 过期 ⇒ a ← a−1。

**定义 168（迁移-安全联合判定 TSD）** 给定部署等级 g、有效置信 γ_eff、残差界 δ_K：
```
if L=REVOKE or γ_eff < τ_eff or ¬TC_valid:  g ← g−1;  K ← K_conservative
elif Gate(g→g+1) and voi_auth(π) ≥ 0:       g ← g+1
else:                                        g ← g
```
其不动点语义：**仅当「证书有效 ∧ 残差鲁棒 ∧ 预算充足」三者同时成立时才晋升**；任一不成立则停留在当前等级或降级，绝不“带病放权”。

### IP-161 ODD/许可（Scene-License Joint Domain）

```python
class ODDConstraint:
    def __init__(self, materials, slope_range, load_range,
                 noise_range, net_delay_range, human_modes):
        self.materials = set(materials)
        self.slope = slope_range
        self.load = load_range
        self.noise = noise_range
        self.net = net_delay_range
        self.humans = set(human_modes)

    def contains(self, o):
        return (o.material in self.materials
                and self.slope[0] <= o.slope <= self.slope[1]
                and self.load[0] <= o.payload <= self.load[1]
                and self.noise[0] <= o.noise <= self.noise[1]
                and self.net[0] <= o.delay <= self.net[1]
                and o.human_mode in self.humans)

    def license(self, o):
        if self.contains(o):
            return 'GRANT'
        if self._near_boundary(o, margin=0.1):
            return 'RESTRICT'
        return 'REVOKE'
```

### IP-162 RTOM（残差迁移算子）

```python
class ResidualTransferOperator:
    def __init__(self, kernel, sigma_n=0.05, alpha=0.05, delta_0=0.2):
        self.k = kernel
        self.sigma_n = sigma_n
        self.z = norm.ppf(1 - alpha)
        self.delta_0 = delta_0
        self.X, self.y = [], []

    def calibrate(self, x_real, K_real, K_sim):
        self.X.append(np.asarray(x_real, float))
        self.y.append(float(K_real) - float(K_sim))

    def _kstar(self, x):
        return np.array([self.k(x, xi) for xi in self.X])

    def posterior(self, x):
        if not self.X:
            return 0.0, self.delta_0 / self.z
        K = self.k(np.array(self.X), np.array(self.X)) + self.sigma_n**2 * np.eye(len(self.X))
        ks = self._kstar(x)
        mu = ks @ np.linalg.solve(K, np.array(self.y))
        s2 = self.k(x, x) - ks @ np.linalg.solve(K, ks)
        return mu, max(s2, 1e-9)

    def delta_bound(self, x):
        _, s2 = self.posterior(x)
        return self.z * np.sqrt(s2)

    def transfer(self, pi_sim, x, ODD):
        mu_d, _ = self.posterior(x)
        dK = self.delta_bound(x)
        return {
            'mu': pi_sim['mu'] + mu_d,
            'sigma': np.sqrt(pi_sim['sigma']**2 + (dK / self.z)**2),
            'delta_K': dK,
            'gamma_T': float(np.exp(-dK / self.delta_0))
        }
```

### IP-163 RGMon（真实性差距监测）

```python
class RealityGapMonitor:
    def __init__(self, mu_s, Sigma_s, tau_M=3.0, tau_w=1.0):
        self.mu_s, self.Sigma_s = mu_s, Sigma_s
        self.Sigma_inv = np.linalg.pinv(Sigma_s)
        self.tau_M, self.tau_w = tau_M, tau_w

    def oos_score(self, x):
        d = float((x - self.mu_s) @ self.Sigma_inv @ (x - self.mu_s)) ** 0.5
        return max(0.0, d - self.tau_M)

    def level(self, x):
        s = self.oos_score(x)
        if s <= 0.0:
            return 'NOMINAL'
        if s <= self.tau_w:
            return 'WARN'
        return 'ALARM'
```

### IP-164 SDP（分级场景落地协议）

```python
class StagedDeploymentProtocol:
    STAGES = ['g0_sim', 'g1_hil', 'g2_shadow', 'g3_limited', 'g4_full']

    def __init__(self, tau_cov=0.9, tau_oos=0.01, tau_shadow=0.95):
        self.tau_cov, self.tau_oos, self.tau_shadow = tau_cov, tau_oos, tau_shadow
        self.g = 0

    def gate(self, tc, m):
        return (tc.valid() and tc.coverage >= self.tau_cov
                and m['oos_rate'] <= self.tau_oos
                and m['shadow_agree'] >= self.tau_shadow
                and tc.fallback_verified)

    def step(self, tc, metrics, voi_auth):
        if (not tc.valid()) or metrics['alarm'] or metrics['dplus_streak'] >= 3:
            self.g = max(0, self.g - 1)
        elif self.gate(tc, metrics) and voi_auth >= 0 and self.g < len(self.STAGES) - 1:
            self.g += 1
        return self.STAGES[self.g]
```

### IP-165 T-Cert（迁移证书）

```python
class TransferCertificate:
    def __init__(self, d_TV, d_K, coverage, oos_rate,
                 shadow_agree, fallback_verified, ttl):
        self.d_TV, self.d_K = d_TV, d_K
        self.coverage, self.oos_rate = coverage, oos_rate
        self.shadow_agree, self.fallback_verified = shadow_agree, fallback_verified
        self.ttl, self.issued = ttl, time.time()
        self.revoked = False

    def valid(self, now=None):
        now = now or time.time()
        return (not self.revoked
                and self.d_TV <= TAU_TV and self.d_K <= TAU_K
                and self.coverage >= TAU_COV and self.oos_rate <= TAU_OOS
                and now <= self.issued + self.ttl
                and self.fallback_verified)

    def revoke(self):
        self.revoked = True
```

### IP-167 PCE+++++（迁移预算与权限感知 VOI）

```python
class TransferBudget:
    A = [0.0, 0.25, 0.5, 0.75, 1.0]

    def __init__(self, calib=5, shadow=120.0, gate=10, ttl=3600.0):
        self.B_calib, self.B_shadow = calib, shadow
        self.B_gate, self.B_ttl = gate, ttl
        self.used_calib = self.used_shadow = self.used_gate = 0

    def cost_transfer(self, pi, lam=(1.0, 0.2, 0.5)):
        return (lam[0] * self._calib_cost(pi) + lam[1] * self._shadow_cost(pi)
                + lam[2] * self._gate_cost(pi))

    def voi_auth(self, pi, a, model):
        return (model.voi_meta(pi) - model.cost_cog(pi) - model.cost_exec(pi)
                - self.cost_transfer(pi) - model.authority_penalty(a))

    def next_authority(self, pi, tc, model):
        for a in sorted(self.A, reverse=True):
            if tc.valid_for(a) and self.voi_auth(pi, a, model) >= 0:
                return a
        return 0.0
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ODD/许可 | O(1) 区间判定 | O(1) | 越界必 REVOKE，保守域可编译 |
| RTOM | O(n²)+O(n) 推断（n≤5 时可忽略） | O(n·d) | δ_K 为 1−α 置信上界 |
| RGMon | O(d²) 距离计算 | O(d²) | ALARM 时 OOS_rate 单调可测 |
| SDP | O(1)/步 | O(1) | 无证书不晋升；ALARM 必降级 |
| SERC-T | 复用闭环 | 复用 | γ_eff 与鲁棒 K 联合约束 |
| PCE+++++ | O(|A|) 决策 | O(1) | 预算耗尽冻结权限 |

**正确性定理（SGRT: Sim-to-Real Transfer Safety）**：
假设 A66–A70 成立：
- **(A66)** RTOM 的 GP 后验校准良好：真实 Δ 以概率 ≥ 1−α 落在 [μ_Δ−δ_K, μ_Δ+δ_K] 内；
- **(A67)** RGMon 的支撑集 S_sim 与阈值 τ_M 给出 OOS 检测，OOS 事件在 τ_w 窗口内不漏报（或漏报率 ≤ ε_oos）；
- **(A68)** SDP 门禁谓词 Gate 只能在前述证据全部成立时为真，且降级转移全序可达；
- **(A69)** EEIS 的鲁棒编译在 ||Δ||≤δ_K 下保持接触力/稳定性约束；
- **(A70)** T-Cert 的 ttl 有限且撤销即刻生效。

则：
1. **迁移安全**：若 TC_valid ∧ γ_eff ≥ τ_eff ∧ L=GRANT，则真实执行满足 force/stability 约束的概率 ≥ 1−α−ε_oos。

4. **预算安全**：B_calib/B_gate 耗尽 ⇒ 权限冻结，不发生“无证据晋升”。

### IP-161 ODD/许可（Scene-License Joint Domain）

```python
class ODDConstraint:
    def __init__(self, materials, slope_range, load_range,
                 noise_range, net_delay_range, human_modes):
        self.materials = set(materials)
        self.slope, self.load = slope_range, load_range
        self.noise, self.net = noise_range, net_delay_range
        self.humans = set(human_modes)

    def contains(self, o):
        return (o.material in self.materials
                and self.slope[0] <= o.slope <= self.slope[1]
                and self.load[0] <= o.payload <= self.load[1]
                and self.noise[0] <= o.noise <= self.noise[1]
                and self.net[0] <= o.delay <= self.net[1]
                and o.human_mode in self.humans)

    def license(self, o):
        if self.contains(o):
            return 'GRANT'
        if self._near_boundary(o, margin=0.1):
            return 'RESTRICT'
        return 'REVOKE'
```

### IP-162 RTOM（残差迁移算子）

```python
class ResidualTransferOperator:
    def __init__(self, kernel, sigma_n=0.05, alpha=0.05, delta_0=0.2):
        self.k, self.sigma_n = kernel, sigma_n
        self.z, self.delta_0 = norm.ppf(1 - alpha), delta_0
        self.X, self.y = [], []

    def calibrate(self, x_real, K_real, K_sim):
        self.X.append(np.asarray(x_real, float))
        self.y.append(float(K_real) - float(K_sim))

    def posterior(self, x):
        if not self.X:
            return 0.0, self.delta_0 / self.z
        K = self.k(np.array(self.X), np.array(self.X)) + self.sigma_n**2 * np.eye(len(self.X))
        ks = np.array([self.k(x, xi) for xi in self.X])
        mu = ks @ np.linalg.solve(K, np.array(self.y))
        s2 = self.k(x, x) - ks @ np.linalg.solve(K, ks)
        return mu, max(s2, 1e-9)

    def delta_bound(self, x):
        _, s2 = self.posterior(x)
        return self.z * np.sqrt(s2)

    def transfer(self, pi_sim, x, ODD):
        mu_d, _ = self.posterior(x)
        dK = self.delta_bound(x)
        return {'mu': pi_sim['mu'] + mu_d,
                'sigma': np.sqrt(pi_sim['sigma']**2 + (dK / self.z)**2),
                'delta_K': dK,
                'gamma_T': float(np.exp(-dK / self.delta_0))}
```

### IP-163 RGMon（真实性差距监测）

```python
class RealityGapMonitor:
    def __init__(self, mu_s, Sigma_s, tau_M=3.0, tau_w=1.0):
        self.mu_s, self.Sigma_s = mu_s, Sigma_s
        self.Sigma_inv = np.linalg.pinv(Sigma_s)
        self.tau_M, self.tau_w = tau_M, tau_w

    def oos_score(self, x):
        d = float((x - self.mu_s) @ self.Sigma_inv @ (x - self.mu_s)) ** 0.5
        return max(0.0, d - self.tau_M)

    def level(self, x):
        s = self.oos_score(x)
        return 'NOMINAL' if s <= 0 else ('WARN' if s <= self.tau_w else 'ALARM')
```

### IP-164 SDP（分级场景落地协议）

```python
class StagedDeploymentProtocol:
    STAGES = ['g0_sim', 'g1_hil', 'g2_shadow', 'g3_limited', 'g4_full']

    def __init__(self, tau_cov=0.9, tau_oos=0.01, tau_shadow=0.95):
        self.tau_cov, self.tau_oos, self.tau_shadow = tau_cov, tau_oos, tau_shadow
        self.g = 0

    def gate(self, tc, m):
        return (tc.valid() and tc.coverage >= self.tau_cov
                and m['oos_rate'] <= self.tau_oos
                and m['shadow_agree'] >= self.tau_shadow
                and tc.fallback_verified)

    def step(self, tc, metrics, voi_auth):
        if (not tc.valid()) or metrics['alarm'] or metrics['dplus_streak'] >= 3:
            self.g = max(0, self.g - 1)
        elif self.gate(tc, metrics) and voi_auth >= 0 and self.g < len(self.STAGES) - 1:
            self.g += 1
        return self.STAGES[self.g]
```

### IP-167 PCE+++++（迁移预算与权限感知 VOI）

```python
class TransferBudget:
    A = [0.0, 0.25, 0.5, 0.75, 1.0]

    def __init__(self, calib=5, shadow=120.0, gate=10, ttl=3600.0):
        self.B_calib, self.B_shadow = calib, shadow
        self.B_gate, self.B_ttl = gate, ttl
        self.used_calib = self.used_shadow = self.used_gate = 0

    def cost_transfer(self, pi, lam=(1.0, 0.2, 0.5)):
        return (lam[0] * self._calib_cost(pi) + lam[1] * self._shadow_cost(pi)
                + lam[2] * self._gate_cost(pi))

    def voi_auth(self, pi, a, model):
        return (model.voi_meta(pi) - model.cost_cog(pi) - model.cost_exec(pi)
                - self.cost_transfer(pi) - model.authority_penalty(a))

    def next_authority(self, pi, tc, model):
        for a in sorted(self.A, reverse=True):
            if tc.valid_for(a) and self.voi_auth(pi, a, model) >= 0:
                return a
        return 0.0
```
