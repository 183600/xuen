# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环第 1 轮；本轮灵感：「阻抗控制」×「避障控制」）

> 第 59 轮把安全论证链一路压到电机电流环与阻抗证书：BUQ 在线辨识无刷电机的结构性不确定性，ERTC 把嵌入式时序契约化，EEIS 把高层 δ_f 编译成阻抗参数与不可篡改证书，CLEP 把执行实测回传成第 5 个模态。它回答的是「**这一次接触**执行得可不可信」。但它默认了一个更强的隐含前提：**避障与接触是两个互不干扰的层**——规划器在自由空间里避障，控制器在接触时调阻抗。真实系统里这两套语义是**互相拆台**的：避障要往力/阻抗回路里注入虚拟排斥力，而阻抗与力证据恰恰靠这同一个回路测量；避障改变机械臂构型与零空间，而 EEIS 证书是在某个构型下签发的；阻抗的阻尼既决定刹车距离又决定接触冲击力，二者方向相反。本轮核心命题：**「避障与阻抗不是两层，而是一个统一安全流形上的两个约束；力必须带上『来源标签』，『没碰到』只能收缩自由空间、绝不能冒充接触证据」**——把这一层称为**避障-阻抗统一安全层（OISL, Obstacle-Impedance Safety Layer）**。

核心矛盾：

- **H32（力证据污染·虚拟力混叠）**：势场/APF/反应式 CBF 为了避障，会向阻抗回路注入虚拟排斥力 `f_vir`。对力传感器而言，`f_vir` 与真实环境接触力 `f_env` 同量纲、同通道、同时刻出现，**物理上不可分**。若直接沿用第 59 轮的 EV-exec（force_tracking_q99、τ_est、ξ_exec 辨识），避障产生的力会被系统性误判为「接触了物体」或「力跟踪超差」，证据层后验校准被污染。更隐蔽的是：避障动作越激进，污染越大，而系统恰恰在「危险时」最需要正确的力证据。
- **H33（证书失效·构型与零空间耦合）**：EEIS 下发的是笛卡尔阻抗 `(K_p,K_d)` 与证书 `Cert_eeis`，但冗余机械臂的有效阻抗 `Z_eff(q)` 依赖雅可比 `J(q)`、零空间投影与条件数。避障会主动改变 `q`、占用零空间自由度；当 `J` 接近奇异，`K_eff` 会被 `κ_J` 放大或塌陷——**同一张证书在不同构型下代表不同的物理刚度**。第 59 轮假设证书是构型无关的，这是一个未被审计的抽象泄漏。
- **H34（时间-力不可兼得·刹车距离 vs 接触刚度）**：近似制动距离 `d_brake ∝ v·m/K_d`，增大阻尼缩短刹车距离（利于避障），却也增大接触瞬间的冲击力与力超限概率（不利于接触安全）。同一组阻抗参数**无法同时最优**满足「碰撞时间 TTC 约束」与「接触力上限约束」。分层各自优化必然在交界处打架，必须把两条约束放进同一个可行域，显式暴露 Pareto 冲突。
- **H35（负证据误用·无接触 ≠ 无属性）**：避障成功只说明「这条轨迹在其感知/预测误差范围内未与障碍相交」，它关于**自由空间**是正信息，关于**物体属性**（可否抓取、刚度、位置是否为空）几乎正交。若把「没碰到」塞进证据门当作正面佐证，会系统性低估风险——这是比第 59 轮「自洽幻觉」更隐蔽的**负证据通胀**。
- **H36（反应式避障的死锁与硬挤）**：APF/CBF 在凹形障碍、狭窄通道、动态障碍夹缝中产生局部极小；为脱离局部极小而「加大排斥增益」，等价于把机器人推向高接触风险区，直接与阻抗安全约束冲突。脱离死锁不能靠更大的虚拟力，只能靠**用负证据建局部自由空间图**并主动探询。

## 0. 直觉与动机

**灵感 1（阻抗控制 → 力-运动统一语义，但也暴露了「力从哪来」的问题）**
直觉：Hogan 的阻抗控制不是「控制位置再限制力」，而是**直接规定机器人与环境之间的动态关系** `M_d ẍ + D_d ẋ + K_d x = f_ext`。一旦接受这个语义，就必须承认：控制器自己注入的广义力（重力补偿、摩擦补偿、零空间避障力、虚拟排斥力）与外部接触力在动力学方程里是**同一类项**。第 59 轮只做了「外部接触力」的证据化，没有给内部广义力「贴来源标签」。因此本轮的第一步不是加新约束，而是**做力的来源分解（FPD）**：`f_meas = f_env + f_vir + f_in + f_fric + ε`，只有可归因为 `f_env` 的分量才有资格进入证据链；`f_vir` 必须前馈已知、可减、且其模型残差被显式计入协方差。阻抗控制真正的贡献是提供了一套**力与位移的可微关系**，让我们能用「残差是否与某个接触阻抗模型一致」来做归因，而不只是比阈值。

**灵感 2（避障控制 → 约束而非力，安全流形而非排斥场）**
直觉：把避障理解成「加一个排斥力」是工程近似，不是安全保证；排斥力可以被饱和、被延迟、被局部极小击败。更严谨的做法是**控制障碍函数（CBF）/安全流形**：定义障碍有符号距离 `h(q) ≥ 0`，要求闭环轨迹前向不变。因为阻抗控制是二阶系统，位置约束的相对阶为 2，必须用**指数 CBF（ECBF）**：`ḧ + k1 ḣ + k0 h ≥ 0`。关键洞见：**避障不是「额外加力」，而是「对允许控制集合的约束」**；阻抗不是「额外模式」，而是「被约束的动力学」。二者天然可以写进同一个二次规划（QP）：在满足碰撞 ECBF、接触力上限、阻抗证书有效性、执行器限幅的前提下，**最小修改**标称运动/阻抗。这样避障与阻抗不再互相拆台，而是共享同一个可行域；可行域为空时不是「硬挤」，而是**有界时间内的安全停**。

**灵感 3（合流 → 统一安全流形 UMCS + 力来源标签）**
直觉：把每个控制周期看成一次「带约束的最小修改」：标称策略给出 `u_nom`（来自第 59/58 轮的探针-承诺-演化），OISL 求解
`u* = argmin ||u − u_nom||²_W  s.t. 碰撞ECBF ∧ |f_env|≤F_max ∧ (K_p,K_d)∈K_safe(q) ∧ 执行器/跟踪约束`。
同时，力证据只在「无避障污染」的窗口内有效：避障后需要等待 `τ_settle` 让虚拟力与瞬态衰减；接触任务期间要求避障力在接触任务子空间上**透明**（`T_v ≤ ε_T`）。于是「避障」与「接触」通过**时间复用 + 子空间透明**共存，而不是靠调参硬叠。

**灵感 4（负证据代数 NEA）**
直觉：避障产生的是「负观测」——「这段管状邻域里没有障碍」。它在自由空间信念上是**正**的（可以标为空闲），在物体属性信念上是**零**（不能更新材质/可抓性）。更严格地说，负观测算子必须在物体属性边缘分布上是**恒等**的：`p(θ | a_avoid) = p(θ)`；它只能收缩占用栅格、只能让不确定性变小在「空间」维度、绝不能抬高任何「属性」后验。碰撞则是另一种特殊情况：它证明「这里有东西」（占用正证据），但因为发生在**未经接触认证的控制器模式**下，力估计不可信，所以只能给占用的宽后验，不能给刚度/材质推断。这个「证据类型代数」是防止负证据通胀的关键。

**灵感 5（避障-探询预算耦合 AEC）**
直觉：避障不仅花执行预算 `B_exec`，还**消耗证据窗口**：一次避障之后 `τ_settle` 内的所有力证据都作废。频繁避障会让「能用的探针窗口」变少，使某些区域实际上不可探。因此 VOI 必须包含**证据机会成本**：`voi_ois(π) = VOI_meta_pessimistic(π) − cost_exec(π) − cost_evidence_window(π)`。这带来一个反直觉但正确的结论：**有时「绕远路」比「贴着障碍走」更省**，因为绕远路保留了干净的接触证据窗口；反之，一条更短但需要频繁反应式避障的路径，可能让关键接触永远无法被可信测量。

**灵感 6（证书的构型语义 CAIC）**
直觉：证书不是「参数包」，而是「参数包 × 有效域」。`Cert_eeis` 必须附带 `Q_cert = {q | σ_min(JJᵀ) ≥ σ_min^req ∧ κ_J ≤ κ_max ∧ T_v ≤ ε_T ∧ ||J N_null||_F ≤ ε_null}`。一旦避障把构型推出 `Q_cert`，证书立即失效，必须重编译、降刚度或在关节空间重签。这不是保守，而是把第 59 轮隐含的「构型无关」假设显式化——**证书是关于构型的局部真理，不是全局常量**。

## 1. 形式化定义（增量：定义 153–161）

**定义 153（力来源分解 FPD）** 设笛卡尔测量力 `f_meas(t) ∈ ℝ³`。定义分解
```
f_meas = f_env + f_vir + f_in + f_fric + ε_s
```
其中 `f_vir = J^{-T} N^T τ_avoid` 为避障/零空间注入的已知广义力经雅可比映射；`f_in = Λ(q) ẍ + Λ(q) J̇ q̇`（`Λ=(J M^{-1} J^T)^{-1}`）为惯性项；`f_fric = J^{-T} τ_fric(q̇)` 为摩擦补偿残差；`ε_s` 为传感器噪声。定义**接触残差** `r_f = f_meas − f_vir − f_in − f_fric`，其协方差
```
Σ_r = Σ_s + σ_vir² I + σ_in² I,   σ_vir = sup_t ||f_vir(t) − f̂_vir(t)||
```
归因检验：仅当 `Λ_f = r_fᵀ Σ_r^{-1} r_f > χ²_3(1−α_f)` 且 `r_f` 与某个接触阻抗模型 `f_env = K_c x + D_c ẋ` 的残差一致时，才宣称「接触」。定义**避障透明指数**
```
T_v = ||Π_contact f_vir|| / (||f_vir|| + ε)
```
其中 `Π_contact` 为接触任务子空间投影。接触任务进行中要求 `T_v ≤ ε_T`；否则必须时间复用（避障与接触不同时）。定义**力证据污染界**：任何力证据的协方差必须满足 `Σ_contact ⪰ Σ_r`，禁止在 `σ_vir` 未计入时使用原始 `f_meas`。

**定义 154（构型感知阻抗证书 CAIC）** 冗余机械臂（关节数 `n > m` 任务维）的关节力矩阻抗实现
```
τ = Jᵀ(K_x e + D_x ė) + (I − Jᵀ J^{T†}) τ_null
```
有效任务刚度 `K_eff(q)` 随构型变化，其误差放大受条件数控制。定义证书有效域
```
Q_cert = { q | σ_min(J Jᵀ) ≥ σ_min^req,  κ_J = σ_max/σ_min ≤ κ_max,
              T_v(q) ≤ ε_T,  ||J N_null||_F ≤ ε_null }
```
`Cert_eeis` 仅在 `q ∈ Q_cert` 且 `(K_p,K_d,F_max,ω_traj) ∈ K_safe` 时有效。若 `q ∉ Q_cert`，证书标记 `invalid(q)`，触发重编译（降 `K_x`、冻结零空间避障、或转关节空间阻抗），禁止以旧证书执行接触。

**定义 155（统一运动-接触安全流形 UMCS）** 状态 `x=(q,q̇)`。记障碍有符号距离 `h_obs(q)`、感知不确定性半径 `ρ_unc`、反应延迟上界 `τ_react`。定义约束集
```
C1 碰撞:   ḧ_obs + k1 ḣ_obs + k0 (h_obs − ρ_unc − v_max τ_react) ≥ 0      (ECBF, 相对阶 2)
C2 力:     |nᵀ f_env| ≤ F_max  ∧  Pr[|f_env|>F_max] ≤ δ_force
C3 证书:   (K_p,K_d,F_max,ω_traj) ∈ K_safe(q)  ∧  q ∈ Q_cert
C4 执行器: τ ∈ [τ_min,τ_max],  q̇ ∈ [q̇_min,q̇_max]
C5 跟踪:   ||e|| ≤ ε_traj
C6 透明:   (接触任务进行 ⇒ T_v ≤ ε_T)，否则避障与接触时间复用
```
统一可行集 `U(x) = C1∩C2∩C3∩C4∩C5∩C6`。安全滤波器在 `U(x)` 上求解最小修改：
```
u* = argmin_{u} ||u − u_nom||²_W
     s.t.  u ∈ U(x)
```
`U(x)=∅` ⇒ 触发**有界时间安全停**（在 `τ_stop` 内减速到零），而非加大虚拟力硬挤。

**定义 156（负证据代数 NEA）** 负观测 `a = (τ_traj, c_min, δ_perc, t)`：轨迹 `τ_traj` 的 `c_min − δ_perc` 邻域内无障碍。定义算子 `⊗`：
```
O' = O ⊖ K(a)              # 占用栅格：把该管状邻域标为空闲（收缩自由空间的不确定性）
Θ' = Θ                      # 物体属性：边缘分布恒等（无更新）
```
形式要求：`Π_Θ(a) = id`，即负观测**不得抬高任何物体属性后验**；只允许在占用子空间内做 Bayes 更新。若 `c_min < 0`（发生未预期接触），则产生**占用正证据**（该点有障碍）但**属性不可推断**（因控制器未处于接触认证模式，力估计不可信），记为碰撞证据 `EV-collision`，其属性似然取无信息宽分布。

**定义 157（避障-探询窗口耦合 AEC）** 定义最近避障时刻 `t_avoid`、镇定时间
```
τ_settle = min{ t | ∀t'∈[t_avoid, t_avoid+t]: ||f_vir(t')||<δ_v ∧ ||ḟ_vir(t')||<δ_dv
                       ∧ ||r_f(t')||<δ_r }
```
接触探针在时刻 `t` 力证据有效当且仅当 `t − t_avoid ≥ τ_settle` 且 `T_v ≤ ε_T` 且无 `EV-collision`。否则 `EV-exec.valid=false`，不得进入证据门。定义证据机会成本
```
cost_window(π) = λ_win · max(0, τ_settle(π) + τ_probe − W_clean(t))
```
其中 `W_clean(t)` 为当前剩余的干净证据时间窗。

**定义 158（证据类型扩展 XMC+++）** 模态/证据类扩展
```
ℳ⁺⁺ = ℳ⁺ ∪ {avoid, collision}
```
规则：
- (R1⁺⁺) `EV-avoid` 为负证据：只能更新占用栅格，不能进入 `EV-probe*/EV-xmodal/EV-human` 正面门。
- (R2⁺⁺) `EV-collision` 为占用正证据、属性零信息；触发区域风险标记与保守绕行，不得作为抓取/接触佐证。
- (R3⁺⁺) `T_v > ε_T` 或探针落在 `τ_settle` 内 ⇒ `EV-exec` 标注 `contaminated=true`，`ρ_exec ← ρ_exec·(1−T_v)` 并仅作分歧对账。
- (R4⁺⁺) 负证据与正证据冲突（路径标为空闲但接触发生）⇒ 占用后验加宽，触发回退与地图重估。
扩展分歧 `D⁺⁺(r) = D⁺(r) + w_neg·TV(lbl_avoid, lbl_fused) + w_col·1[collision ∧ free]`。

**定义 159（OISL 统一算子）**
```
OISL(M, cp, δ_f^req):
  ① O ← occupancy_update(M.O, M.percept)                 # 感知/负证据
  ② K_safe, Cert ← EEIS.compile(δ_f^req, fused, ξ_exec, b_r); q ∈ Q_cert?
  ③ u_nom ← PCE+++.nominal(cp)                            # 探针/承诺名义动作
  ④ u*, τ* ← ISF_CBF_QP(u_nom; C1..C6)
       if U(x)=∅: return SAFE_STOP(τ_stop)
  ⑤ dispatch(τ*, T_v-schedule)                            # 透明或时间复用
  ⑥ execute & collect(f_meas, q, q̇, f_vir, t_avoid)
  ⑦ r_f ← FPD(f_meas); classify:
       if contact_certified: EV-contact → Θ 更新
       elif collision: EV-collision → 占用宽更新 + 区域风险
       else: EV-avoid → 占用负更新
  ⑧ if q ∉ Q_cert: Cert ← recompile_or_downgrade()
  ⑨ B_exec ← update; 返回 (M, fused, D⁺⁺, EV-*, Cert)
```

**定义 160（统一证书 J_ois）**
```
J_ois = (FPD_log, Q_cert_trace, CBF_QP_log, NEA_log, AEC_window_log,
         T_v_log, collision_log, Cert_chain, B_exec_snapshot, version)
```
`J_ois.verify()` 检查：`Cert` 在每次接触时 `q ∈ Q_cert`；`T_v ≤ ε_T` 或已时间复用；`EV-exec` 无 `contaminated`；`collision` 均有区域风险记录；负证据未进入正面门。

**定义 161（统一安全单调性）** 对任意新增避障动作或负证据，系统必须满足：
```
PositivePosterior_new(θ_object) ≤ PositivePosterior_old(θ_object)     # 属性后验不因避障升高
FreeSpace_new ⊆ FreeSpace_old 的补集扩张方向                          # 自由空间只按证据收缩
K_safe_new ⊆ K_safe_old 当且仅当 q 进入更差构型                        # 证书有效域只随构型收紧
```
即**避障只能让系统更保守或更了解空间，绝不能让系统对物体更自信**。

## 2. 关键算法伪代码

### IP-152 FPD（力来源分解与污染抑制）

```python
class ForceProvenanceDecomposer:
    def __init__(self, robot_model, sensor_cov, sigma_vir, sigma_in):
        self.robot = robot_model
        self.Sigma_s = sensor_cov
        self.sigma_vir = sigma_vir      # 虚拟力模型残差上界
        self.sigma_in = sigma_in        # 惯性项模型残差上界
        self.contact_models = []        # 候选接触阻抗模型

    def decompose(self, f_meas, q, qd, qdd, tau_avoid, tau_fric):
        J = self.robot.jacobian(q)
        # 虚拟力与惯性项：前馈已知，显式扣除
        f_vir = J.T_inv() @ tau_avoid
        Lambda = self.robot.task_inertia(q)              # (J M^-1 J^T)^-1
        f_in = Lambda @ (qdd_tcp(q, qd, qdd) ) + Lambda @ self.robot.jdot_qd(q, qd)
        f_fric = J.T_inv() @ tau_fric
        r_f = f_meas - f_vir - f_in - f_fric

        Sigma_r = self.Sigma_s + self.sigma_vir**2 * np.eye(3) \
                  + self.sigma_in**2 * np.eye(3)
        return r_f, Sigma_r, f_vir

    def transparency_index(self, f_vir, contact_task_normal):
        # 虚拟力在接触任务子空间上的投影占比
        n = contact_task_normal / (np.linalg.norm(contact_task_normal) + 1e-9)
        proj = abs(n @ f_vir)
        return proj / (np.linalg.norm(f_vir) + 1e-9)

    def attribute(self, r_f, Sigma_r, alpha_f=0.01):
        # 是否接触（马氏距离）
        maha = r_f @ np.linalg.inv(Sigma_r) @ r_f
        if maha <= chi2.ppf(1 - alpha_f, df=3):
            return 'no_contact', maha
        # 与候选接触阻抗模型的一致性（残差的残差）
        best = min(self.contact_models,
                   key=lambda m: m.residual(r_f))
        if best.residual(r_f) < chi2.ppf(1 - alpha_f, df=3):
            return 'contact', maha
        return 'unexplained_contact', maha   # 可能是碰撞/建模缺陷

    def inflate_evidence_cov(self, Sigma_probe):
        # 任何进入证据层的力协方差都必须含污染界
        return Sigma_probe + self.sigma_vir**2 * np.eye(3)
```

### IP-153 CAIC（构型感知证书）

```python
class ConfigurationAwareCertificate:
    def __init__(self, sigma_min_req=1e-3, kappa_max=50.0,
                 eps_T=0.05, eps_null=0.1):
        self.sigma_min_req = sigma_min_req
        self.kappa_max = kappa_max
        self.eps_T = eps_T
        self.eps_null = eps_null

    def conditioning(self, J):
        s = np.linalg.svd(J, compute_uv=False)
        return s.min(), s.max() / (s.min() + 1e-12)

    def valid_domain(self, q, J, N_null, f_vir, contact_normal):
        s_min, kappa = self.conditioning(J)
        T_v = transparency(f_vir, contact_normal)
        null_leak = np.linalg.norm(J @ N_null)
        return (s_min >= self.sigma_min_req and kappa <= self.kappa_max
                and T_v <= self.eps_T and null_leak <= self.eps_null)

    def check_or_downgrade(self, cert, q, J, N_null, f_vir, contact_normal, eeis):
        if self.valid_domain(q, J, N_null, f_vir, contact_normal):
            return cert, 'valid'
        # 退出 Q_cert：优先冻结零空间避障，其次降刚度，最后转关节空间
        if np.linalg.norm(J @ N_null) > self.eps_null:
            return eeis.recompile(cert, freeze_nullspace=True), 'freeze_null'
        if self.conditioning(J)[1] > self.kappa_max:
            return eeis.recompile(cert, K_scale=0.5), 'soften'
        return eeis.recompile_joint_space(cert), 'joint_space'
```

### IP-154 ISF-CBF（统一安全滤波器）

```python
class ImpedanceSafetyFilter:
    def __init__(self, k1=10.0, k0=25.0, F_max=50.0, W=None):
        self.k1, self.k0, self.F_max = k1, k0, F_max
        self.W = W or np.eye(3)

    def solve(self, u_nom, q, qd, h_obs, hdot_obs, rho_unc, v_max, tau_react,
              f_env_hat, K_safe_q, tau_bounds, qd_bounds):
        # 决策变量 u = 任务空间期望加速度（或等价的阻抗修正量）
        # C1: ECBF 二阶约束
        # h_tilde = h_obs - rho_unc - v_max*tau_react
        h_t = h_obs - rho_unc - v_max * tau_react
        A1, b1 = self._ecbf_terms(q, qd, h_t, hdot_obs)
        # C2: 接触力上限（保守用 f_env_hat + 3σ）
        A2, b2 = self._force_bound(f_env_hat)
        # C3: 阻抗证书（线性化 K_safe(q) 的局部多面体近似）
        A3, b3 = self._certificate_polytope(K_safe_q)
        # C4/C5: 执行器与跟踪
        A4, b4 = self._actuator_bounds(tau_bounds, qd_bounds)
        # QP: min ||u - u_nom||^2_W
        A = np.vstack([A1, A2, A3, A4]); b = np.concatenate([b1, b2, b3, b4])
        u = solve_qp(np.eye(3), -self.W @ u_nom, A, b)
        if u is None:
            return None, 'infeasible'          # -> SAFE_STOP
        return u, 'ok'

    def _ecbf_terms(self, q, qd, h_t, hdot):
        # ḧ >= -k1*hdot - k0*h_t  =>  A1 u <= b1（由 h 的海森与雅可比展开）
        # 简化：A1 = -J_n，b1 = -k1*hdot - k0*h_t + 非线性补偿项
        J_n = self._distance_jacobian(q)       # ∂h/∂q
        # 任务空间加速度到 h 的二阶映射由 robot_model 提供
        return -J_n, -self.k1 * hdot - self.k0 * h_t + self._bias(q, qd)

    def _force_bound(self, f_hat):
        upper = f_hat + 3.0 * self._force_sigma()
        return np.eye(3), (self.F_max - upper) * np.ones(3)

    def _certificate_polytope(self, K_safe_q):
        # K_safe(q) 的局部线性化边界：A3 u <= b3
        return K_safe_q.local_polytope()

    def _actuator_bounds(self, tau_b, qd_b):
        return self._bounds_matrix(), self._bounds_vector(tau_b, qd_b)
```

```python
        u_nom, M.q, M.qd, M.h_obs, M.hdot_obs, M.rho_unc,

        tel.f_meas, tel.q, tel.qd, tel.qdd, tel.tau_avoid, tel.tau_fric)

        M.fused = update_object_beliefs(M.fused, EV)     # 属性更新
    elif cls == 'unexplained_contact' or M.collision_detected(tel):
        M.O, M.fused, info = M.nea.apply_collision(
            M.O, M.fused, tel.contact_point, M.percept_unc)
        EV = build_collision_evidence(info)
        M.region_risk[cp.region] = 'high'
    else:

            M.O, M.fused, tel.traj, tel.c_min)
        EV = build_avoidance_evidence(info)
    # ⑧ 构型复核与预算
    if M.q not in M.caic.valid_domain(M.q, M.J, M.N_null, M.f_vir, cp.contact_normal):
        M.eeis.recompile_or_downgrade(cert)

    M.J_ois.append(EV)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| FPD | O(m³)（3×3 求逆）+ O(n·m)（雅可比映射） | O(m²) | 力来源可加分解、污染协方差下界 `Σ_contact ⪰ Σ_r` |

| AEC | O(1)/窗口查询 | O(1) | `τ_settle` 内证据不可用、窗口成本诚实 |
| OISL | O(FPD+CAIC+QP)/控制周期 | 复用各模块 | 单一可行域、证据分型互斥、证书随构型收紧 |

**正确性定理（Obstacle-Impedance Safety Soundness, OISS）**
假设 A51–A55（第 59 轮）成立；**(A56)** FPD：虚拟力与惯性项前馈精确可减，模型残差界 `σ_vir, σ_in` 诚实；`T_v` 可在线计算；**(A57)** CAIC：`Q_cert` 覆盖判据音完备（无漏判奇异/零空间泄漏）；证书失效必触发重编译或降级；**(A58)** UMCS：ECBF 离散化保持前向不变；QP 可行 ⇒ `C1–C6` 满足；不可行 ⇒ 安全停在 `τ_stop` 内；**(A59)** NEA：负观测算子 `Π_Θ=id`，负证据不可进入正面门；碰撞只给占用宽后验、属性零信息；**(A60)** AEC：`τ_settle` 为上界、干净窗口判定诚实、证据机会成本不为负；**(A61)** XMC+++：`EV-avoid/EV-collision` 仅作空间/分歧证据，不替代 `EV-contact/EV-xmodal/EV-human`。则：

1. **力证据接地性**：凡进入证据层的接触力满足 `‖r_f − f_env‖ ≤ ε_s + σ_vir + σ_in`；避障污染不抬高接触后验；错误接触率由 `α_f` 与 `σ_vir` 联合界控制。
2. **统一安全性**：若 `U(x)≠∅`，闭环轨迹满足碰撞 ECBF 前向不变、`|f_env|≤F_max`、证书有效、执行器与跟踪约束；若 `U(x)=∅`，在 `τ_stop` 内进入安全停，且停过程仍满足碰撞 ECBF。
3. **证书可迁移性**：任何被 `Cert_eeis` 认证的接触满足 `q∈Q_cert`；`q∉Q_cert` 时不存在未重签的接触执行；有效刚度误差被 `κ_J` 与 `σ_min` 联合界定。
4. **负证据非放大性**：对任意避障/负观测序列，物体属性后验不升（`p_new(θ) ≤ p_old(θ)` 在 KL 意义下不增），自由空间只按证据扩张；碰撞证据只增加占用不确定性而不伪装为属性证据。
5. **终止性**：OISL 单周期内终止于 `{dispatch, time_multiplex, safe_stop, downgrade, detour}`；跨周期由 PCE+++ 预算保证有限步终止。
6. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
```

关键：**阻抗控制给了力-位移的可微关系，让「力从哪来」可被归因；避障控制给了约束语义，让「不许去哪」可被形式化。二者合流后，安全不再是两个控制器各自调参的产物，而是同一个可行域上的最小修改；证据不再是「测到力就信」，而是「先减去自己注入的力、再问残差是否像接触」。** 三条单向通道延续并强化：**信念更准（FPD 去污染）、不确定性更大（负证据只加宽空间、证书随构型收紧）、动作更保守（统一 QP 不可行即安全停）**。

> IP 编号：IP-152~IP-158（共 7 个），新增避障-阻抗统一安全层 7 项核心能力。

## 2. 关键算法伪代码

### IP-152 FPD（力来源分解与污染抑制）

```python
class ForceProvenanceDecomposer:
    def __init__(self, robot_model, sensor_cov, sigma_vir, sigma_in):
        self.robot = robot_model
        self.Sigma_s = sensor_cov
        self.sigma_vir = sigma_vir      # f_vir 模型残差上界
        self.sigma_in = sigma_in        # 惯性项模型残差上界
        self.contact_models = []        # 候选接触阻抗模型

    def decompose(self, f_meas, q, qd, qdd, tau_avoid, tau_fric):
        J = self.robot.jacobian(q)
        J_inv_T = np.linalg.pinv(J).T
        f_vir = J_inv_T @ tau_avoid
        Lambda = self.robot.task_inertia(q)              # (J M^-1 J^T)^-1
        f_in = Lambda @ self.robot.task_accel(q, qd, qdd) \
             + Lambda @ self.robot.jdot_qd(q, qd)
        f_fric = J_inv_T @ tau_fric
        r_f = f_meas - f_vir - f_in - f_fric
        Sigma_r = self.Sigma_s \
                  + self.sigma_vir**2 * np.eye(3) \
                  + self.sigma_in**2 * np.eye(3)
        return r_f, Sigma_r, f_vir

    def transparency_index(self, f_vir, contact_normal):
        n = contact_normal / (np.linalg.norm(contact_normal) + 1e-12)
        return abs(n @ f_vir) / (np.linalg.norm(f_vir) + 1e-12)

    def attribute(self, r_f, Sigma_r, alpha_f=0.01):
        maha = r_f @ np.linalg.inv(Sigma_r) @ r_f
        if maha <= chi2.ppf(1 - alpha_f, df=3):
            return 'no_contact', maha
        best = min(self.contact_models, key=lambda m: m.residual(r_f))
        if best.residual(r_f) <= chi2.ppf(1 - alpha_f, df=best.dof):
            return 'contact', maha
        return 'unexplained_contact', maha       # 疑似碰撞或建模缺陷

    def inflate_evidence_cov(self, Sigma_probe):
        # 进入证据层的力协方差必须含污染界，禁止“裸力”直接入证
        return Sigma_probe + self.sigma_vir**2 * np.eye(3)
```

### IP-153 CAIC（构型感知阻抗证书）

```python
class ConfigurationAwareCertificate:
    def __init__(self, sigma_min_req=1e-3, kappa_max=50.0,
                 eps_T=0.05, eps_null=0.1):
        self.sigma_min_req = sigma_min_req
        self.kappa_max = kappa_max
        self.eps_T = eps_T
        self.eps_null = eps_null

    def conditioning(self, J):
        s = np.linalg.svd(J, compute_uv=False)
        return float(s.min()), float(s.max() / (s.min() + 1e-12))

    def valid_domain(self, q, J, N_null, f_vir, contact_normal):
        s_min, kappa = self.conditioning(J)
        T_v = ForceProvenanceDecomposer.transparency_index(None, f_vir, contact_normal)
        null_leak = float(np.linalg.norm(J @ N_null))
        return (s_min >= self.sigma_min_req and kappa <= self.kappa_max
                and T_v <= self.eps_T and null_leak <= self.eps_null)

    def check_or_downgrade(self, cert, q, J, N_null, f_vir,
                           contact_normal, eeis):
        if self.valid_domain(q, J, N_null, f_vir, contact_normal):
            return cert, 'valid'
        s_min, kappa = self.conditioning(J)
        # 三级降级：冻结零空间避障 → 降刚度 → 转关节空间
        if np.linalg.norm(J @ N_null) > self.eps_null:
            return eeis.recompile(cert, freeze_nullspace=True), 'freeze_null'
        if kappa > self.kappa_max:
            return eeis.recompile(cert, K_scale=0.5), 'soften'
        return eeis.recompile_joint_space(cert), 'joint_space'
```

### IP-154/155 UMCS + ISF-CBF（统一安全滤波器）

```python
class ImpedanceSafetyFilter:
    def __init__(self, k1=10.0, k0=25.0, F_max=50.0, W=None):
        self.k1, self.k0, self.F_max = k1, k0, F_max
        self.W = W if W is not None else np.eye(3)

    def solve(self, u_nom, q, qd, h_obs, hdot_obs, rho_unc,
              v_max, tau_react, f_env_hat, K_safe_q,
              tau_bounds, qd_bounds, contact_task):
        # C1: 碰撞 ECBF（相对阶 2）
        h_t = h_obs - rho_unc - v_max * tau_react
        A1, b1 = self._ecbf(q, qd, h_t, hdot_obs)
        # C2: 接触力上限（用 f_env_hat + 3σ 保守）
        A2, b2 = self._force(f_env_hat)
        # C3: 证书局部多面体 K_safe(q)
        A3, b3 = K_safe_q.local_polytope()
        # C4/C5: 执行器与跟踪
        A4, b4 = self._limits(tau_bounds, qd_bounds)
        A = np.vstack([A1, A2, A3, A4]); b = np.concatenate([b1, b2, b3, b4])

        u = solve_qp(H=np.eye(3), f=-self.W @ u_nom, A=A, b=b)
        if u is None:
            return None, 'infeasible'      # -> SAFE_STOP(τ_stop)
        # C6: 透明性检查（接触任务时避障力不得污染接触子空间）
        if contact_task:
            T_v = self._transparency(f_env_hat, contact_task.normal)
            if T_v > self._eps_T:
                return u, 'time_multiplex'  # 先避障、后接触
        return u, 'ok'

    def _ecbf(self, q, qd, h_t, hdot):
        J_n = self._distance_jacobian(q)         # ∂h/∂q
        bias = self._ecbf_bias(q, qd)             # 二阶展开的非线性补偿
        return -J_n, -self.k1 * hdot - self.k0 * h_t + bias

    def _force(self, f_hat):
        sigma = self._force_sigma()
        return np.eye(3), (self.F_max - (f_hat + 3.0 * sigma)) * np.ones(3)

    def _limits(self, tau_b, qd_b):
        return self._bounds_matrix(), self._bounds_vector(tau_b, qd_b)

def safe_stop(M, reason, tau_stop=0.1):
    """有界时间安全停：仍满足碰撞 ECBF，只减不增"""
    u_stop = M.isf.braking_control(M.q, M.qd, M.h_obs, tau_stop)
    dispatch(M.q, u_stop, cert=None)              # 无接触认证
    M.safety_log.append({'type': 'safe_stop', 'reason': reason})
    return M, None, null_certificate()
```

### IP-156 NEA（负证据代数）

```python
class NegativeEvidenceAlgebra:
    def __init__(self, delta_perc):
        self.delta_perc = delta_perc

    def apply_avoidance(self, O, Theta, traj, c_min):
        radius = max(0.0, c_min - self.delta_perc)
        O_new = O.mark_free_tube(traj, radius)     # 只收缩自由空间
        Theta_new = Theta                          # Π_Θ = id
        return O_new, Theta_new, {
            'type': 'avoid', 'radius': radius,
            'property_updated': False
        }

    def apply_collision(self, O, Theta, contact_point, uncertainty):
        O_new = O.mark_occupied(contact_point, width=uncertainty)
        Theta_new = Theta                          # 不推断刚度/材质
        return O_new, Theta_new, {
            'type': 'collision', 'occupancy_positive': True,
            'property_updated': False
        }

    def can_enter_positive_gate(self, ev_type):
        return ev_type in ('EV-contact', 'EV-xmodal', 'EV-human',
                           'EV-ft', 'EV-ux', 'EV-probe*')
```

### IP-157 AEC（避障-探询窗口耦合）

```python
class AvoidanceExplorationCoupling:
    def __init__(self, delta_v=1.0, delta_dv=5.0, delta_r=0.5, lambda_win=0.5):
        self.delta_v, self.delta_dv, self.delta_r = delta_v, delta_dv, delta_r
        self.lambda_win = lambda_win
        self.last_avoid_t = -np.inf
        self.window_start = 0.0

    def on_avoidance(self, t):
        self.last_avoid_t = t

    def settling_time(self, f_vir_hist, r_f_hist):
        # 反向扫描：从最近避障时刻起，找到连续满足衰减条件的时长
        tau = 0.0
        for fv, rf, dt in reversed(zip(f_vir_hist, r_f_hist, self._dts)):
            if np.linalg.norm(fv) < self.delta_v and \
               np.linalg.norm(rf) < self.delta_r:
                tau += dt
            else:
                break
        return tau

    def clean_window(self, t, tau_settle):
        if t - self.last_avoid_t < tau_settle:
            return 0.0
        return t - max(self.last_avoid_t + tau_settle, self.window_start)

    def cost_window(self, tau_settle, tau_probe, w_clean):
        return self.lambda_win * max(0.0, tau_settle + tau_probe - w_clean)

    def voi_ois(self, voi_meta, cost_exec, tau_settle, tau_probe, w_clean):
        return voi_meta - cost_exec - self.cost_window(
            tau_settle, tau_probe, w_clean)
```

### IP-158 OISL（统一算子）

```python
def obstacle_impedance_safety_loop(M, cp, delta_f_req, budget):
    # ① 感知 -> 占用
    M.O = M.O.update_from_perception(M.percept)
    # ② 阻抗证书（构型感知）
    K_safe, cert = M.eeis.compile(delta_f_req, M.fused, M.xi_exec,
                                  M.b_r[cp.region])
    cert, status = M.caic.check_or_downgrade(
        cert, M.q, M.J, M.N_null, M.f_vir, cp.contact_normal, M.eeis)
    if cert is None:
        return safe_stop(M, 'certificate_infeasible')
    # ③ 名义动作（来自 PCE+++）
    u_nom = M.pce.nominal(cp)
    # ④ 统一安全滤波
    u_star, qp_status = M.isf.solve(
        u_nom, M.q, M.qd, M.h_obs, M.hdot_obs, M.rho_unc,
        M.v_max, M.tau_react, M.f_env_hat, K_safe,
        M.tau_bounds, M.qd_bounds, cp if cp.is_contact else None)
    if qp_status == 'infeasible':
        return safe_stop(M, 'umcs_infeasible')
    if qp_status == 'time_multiplex':
        return time_multiplex_probe(M, cp, u_star, cert)
    dispatch(M.q, u_star, cert)
    # ⑤ 执行与力分解
    tel = execute(M, cp, timeout=M.contact_timeout)
    r_f, Sigma_r, f_vir = M.fpd.decompose(
        tel.f_meas, tel.q, tel.qd, tel.qdd, tel.tau_avoid, tel.tau_fric)
    cls, maha = M.fpd.attribute(r_f, Sigma_r)
    # ⑥ 证据分型（互斥）
    if cp.is_contact and cls == 'contact' and M.aec.clean_window(tel.t, M.tau_settle) > 0:
        EV = build_contact_evidence(r_f, Sigma_r, cert, M)
        M.fused = update_object_beliefs(M.fused, EV)          # 属性更新
    elif cls == 'unexplained_contact' or M.collision_detected(tel):
        M.O, M.fused, info = M.nea.apply_collision(
            M.O, M.fused, tel.contact_point, M.percept_unc)
        EV = build_collision_evidence(info)
        M.region_risk[cp.region] = 'high'
    else:
        M.O, M.fused, info = M.nea.apply_avoidance(
            M.O, M.fused, tel.traj, tel.c_min)
        EV = build_avoidance_evidence(info)
    # ⑦ 构型复核与预算
    if not M.caic.valid_domain(M.q, M.J, M.N_null, M.f_vir, cp.contact_normal):
        cert = M.eeis.recompile_or_downgrade(cert)
    budget.update_window(M.aec.clean_window(tel.t, M.tau_settle))
    M.J_ois.append(EV)
    return M, M.fused, EV, cert

def build_contact_evidence(r_f, Sigma_r, cert, M):
    return ContactEvidence(
        force_mean=r_f, force_cov=Sigma_r,           # 已去污染
        contract_ok=cert.contract_ok,
        q_in_cert=(M.q in cert.Q_cert),
        T_v=M.fpd.transparency_index(M.f_vir, cert.contact_normal),
        clean_window=M.aec.clean_window(M.t, M.tau_settle),
        contaminated=(M.fpd.transparency_index(M.f_vir, cert.contact_normal)
                      > M.eps_T)
    )
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| FPD | O(m³)+O(n·m)，m=3 | O(m²) | 力可加分解、`Σ_contact ⪰ Σ_r`、归因检验功效由 `α_f, σ_vir` 界定 |
| CAIC | O(n·m²)（SVD）+ O(1) 查表 | O(n·m) | 证书仅在 `Q_cert` 内有效、奇异/零空间泄漏音判 |
| UMCS+ISF-CBF | O((n_c+m)³)（QP） | O((n_c+m)²) | ECBF 前向不变、可行即安全、不可行即安全停 |
| NEA | O(\|tube\|·d_grid) | O(\|O\|) | `Π_Θ=id`、自由空间只收缩、碰撞只给占用宽证据 |
| AEC | O(1)/窗口查询 | O(1) | `τ_settle` 内证据不可用、窗口成本诚实 |
| XMC+++ | O(6²·d_b)/区域 | O(\|V\|·6·d_b) | `avoid/collision` 仅空间/分歧证据、不进正面门 |
| OISL | O(FPD+CAIC+QP)/控制周期 | 复用各模块 | 单一可行域、证据分型互斥、证书随构型收紧 |
| J_ois | O(1)/接触追加 | O(接触数) | 证书链/透明/窗口/碰撞/负证据全程可审计 |

**正确性定理（Obstacle-Impedance Safety Soundness, OISS）**
假设 A51–A55（第 59 轮）成立；**(A56)** FPD 的前馈扣除精确到 `σ_vir,σ_in`，`T_v` 可在线计算；**(A57)** CAIC 的 `Q_cert` 判据音完备（不漏判奇异/零空间泄漏），失效必触发重编译/降级；**(A58)** UMCS 的 ECBF 离散化保持前向不变，QP 不可行必有界时间安全停；**(A59)** NEA 的负观测 `Π_Θ=id`，碰撞只给占用宽后验，负/碰撞证据不可进正面门；**(A60)** AEC 的 `τ_settle` 为上界、干净窗口判定诚实、机会成本非负；**(A61)** XMC+++ 证据类互斥且负证据不得替代接触/跨模态/人类佐证。则：

1. **力证据接地性**：进入证据层的接触力满足 `‖r_f−f_env‖ ≤ ε_s+σ_vir+σ_in`；避障污染不抬高接触后验；错误接触率受 `α_f` 与 `σ_vir` 联合界约束。
2. **统一安全性**：`U(x)≠∅` ⇒ 碰撞 ECBF 前向不变、`|f_env|≤F_max`、证书有效、执行器/跟踪约束满足；`U(x)=∅` ⇒ 在 `τ_stop` 内安全停且停过程仍满足碰撞 ECBF。
3. **证书可迁移性**：所有被认证接触满足 `q∈Q_cert`；`q∉Q_cert` 时不存在未重签接触；有效刚度误差被 `κ_J` 与 `σ_min` 联合界定。
4. **负证据非放大性**：避障/负观测不抬高物体属性后验（`Π_Θ=id`），自由空间只按证据扩张；碰撞只增加占用不确定性而不伪装为属性证据。
5. **终止性**：OISL 单周期终止于 `{dispatch, time_multiplex, safe_stop, downgrade, detour}`；跨周期由 PCE+++ 预算保证有限步终止。
6. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                   + δ_ft·1[回滚] + δ_kg·1[检索失败] + δ_ux·1[μ_mis>θ]
                   + δ_exec·1[ξ_exec漂移] + δ_ertc·1[契约违例] + δ_eeis·1[μ漏报]
                   + δ_fpd·1[虚拟力污染] + δ_caic·1[q∉Q_cert]

```

关键：**FPD 把「力」从一个标量还原成「带来源的分解」，让避障不再污染接触证据；CAIC 把「证书」从全局常量还原成「构型局部真理」，让阻抗在上奇异/零空间时不再静默失效；UMCS/ISF-CBF 把「避障 + 接触」从两套互相拆台的控制器还原成「一个可行域上的最小修改」；NEA 把「没碰到」从「正面证据」还原成「只收缩空间的负证据」。** 三条单向通道延续：**信念更准（去污染力）、不确定性更大（证书随构型收紧、负证据只加宽空间）、动作更保守（QP 不可行即安全停）**。

## 6. 本轮最大风险

**一句话**：本轮用「力来源分解 + 统一安全流形 + 负证据代数」修补了避障与阻抗的耦合，但**正确性压在三处易碎的建模假设上——虚拟力/惯性项可精确前馈相减、`Q_cert` 能音完备捕获奇异与零空间泄漏、负观测在感知相关误差下仍满足 `Π_Θ=id`**——任何一处失效，都会让系统在「避障时误把自注入力当接触」「证书在奇异构型下静默失效」「负证据悄悄抬高属性后验」的路径上重新长出更隐蔽的抽象泄漏；必须以「FPD 污染协方差硬下界」「离开 `Q_cert` 立即冻结接触」「负/碰撞证据只入占用子空间、绝不进正面门」「统一 QP 不可行即安全停」四重护栏兜底，宁可多停一次、多绕一段，也绝不接受「避障看起来安全、证据其实已被污染」。
