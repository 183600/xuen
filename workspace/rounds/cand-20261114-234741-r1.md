> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440），
> 上承 **LeanGauge**（IP-310–314；定义 398–415）与 **MODGAUGE** 五不变式。

## 双轴映射（升级而非重写）

| 灵感词 | 第 2 轮对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| 成功率 | 定义 421.V 的二元“交叉验证通过/失败”；P-Quarantine 只看残差符号 | **S-Box + SRC**：带分母、删失、观测策略与 anytime 有效的成功率契约 | “修好了”不是布尔值；它必须回答：在哪些单位、以什么分母、在多长时间内、被谁观测到 |
| 开源软件 | 回执签名、单条独立回执、进程内热替换 | **CPR + EDG + Fork-Merge**：把每个先验/工具/回执/修复做成可复现、可 fork、可撤销的版本化包 | 信任来自可重放而不是权威；共享依赖一旦被投毒，必须沿依赖图精确撤销 |

**核心命题**：把 ToolGauge 的「局部二元修复成功 + 进程内不可变契约」升级为
「**分母显式、删失感知、anytime 有效、Goodhart 抗性的成功率契约 + 可复现/可 fork/可撤销的证据供应链**」。
一句话：**成功率不是模型的输出，而是证据图的属性；开源不是把代码放出去，而是让每条证据都能被独立重放、被 fork、被撤销。**

**不变式保持声明**：
- MODGAUGE 五不变式全部保留；
- 新增两条**横切不变式**（都只作用于元数据层，不进入数值通道）：
  - **度量可审计**：任何成功率主张必须携带 SRC（估计量、分母台账、观测策略、删失规则、e-process 状态、EDG 支撑集），禁止“裸成功率”；
  - **证据可撤销**：任何已部署证书 C 必须满足 `support(C) ∩ Revoked* = ∅`，否则回滚或 stub。
- **退化链修正并延长**：OpenGauge（包/图/合并失效）⇒ ToolGauge（单包、无 fork、SRC=局部指示）⇒ LeanGauge（纯数值探测）⇒ MODGAUGE。
  注意第 2 轮产物把包含关系写反了；本轮明确：`OpenGauge ⊃ ToolGauge ⊃ LeanGauge ⊃ MODGAUGE`，退化箭头反向。

## 0. 直觉与动机

### 灵感 1（成功率：从“这次修好了”到“在这个分母上、这段时间内，成功率是多少”）

直觉：ToolGauge 的 V 阶段只回答一个二元问题——“这一条修复是否通过了交叉验证与回归测试”。
但部署方真正关心的是**总体成功率**：在所有**应当被修复**的盲区里，有多少真的被修复、并且在一段时间后仍然保持修复。
这两者之间隔着四个此前没有被显式声明的选择：

1. **分母**：哪些盲区算“应修”？未探测的、探测失败的、被人工跳过的、被 VLA 判为 UNKNOWN 的，算不算失败？
2. **观测策略**：哪些盲区会被实际探测？如果系统倾向于探测“容易修”的盲区，观测样本就不是总体的随机样本。
3. **删失**：修复尚未完成、部署已结束、或盲区在观察期内消失，这些单位如何处理？
4. **时域**：成功是在修复完成那一刻判定，还是在 1 小时、1 天、1 周后仍然有效？

这四个选择一旦不被预注册，成功率就可以被“做漂亮”：只探测简单盲区、把难例标成 excluded、提前停止、把 V 通过当作成功。
这就是典型的 **Goodhart**——**当成功率成为目标，它就不再是好的成功率**。
统计学的解药不是“再算一个点估计”，而是把成功率升级成一份**契约**：
声明估计量、保留每个单位的处置台账、用逆概率加权（IPW/IPCW）纠正观测与删失偏差、
用 **e-process / 置信序列**保证“随时偷看、随时停止”仍然有效，并把**覆盖率与分母完整性**和成功率绑定成联合验收条件。

关键洞察：**局部修复成功率是任务成功率的上界**。若 `E^M ⊆ E^T ⊆ E^R`（任务成功 ⇒ 修复成功），
则 `θ_M ≤ θ_T ≤ θ_R`。ToolGauge 报告的只是 `θ_R` 的一个被选择过的样本均值；
把它当成 `θ_M` 是第 2 轮最深的一个未言明跳跃。

### 灵感 2（开源软件：信任来自可重放、可 fork、可撤销的产物，而不是来自权威）

直觉：ToolGauge 已经给回执加了签名与单调序号，但签名只证明“这条回执来自工具 t”，
它不证明：这个先验是在什么数据上训练的、构建环境是什么、依赖了哪些工具契约、许可证是否允许当前部署、
以及**换一台机器能否复现**。开源软件真正成熟的不是“免费”，而是：

- **可检查的 diff**：每个修复是一个可审阅的补丁，而不是一次不可见的覆盖；
- **可复现的构建（reproducible build）**：同一 manifest 能重建同一产物；
- **SBOM / 供应链**：依赖闭包、数据谱系、构建环境、签名与时间戳；
- **语义版本**：major/minor/patch 的兼容性是可机器检查的偏序，而不是口头承诺；
- **fork**：有争议时保留多个并行版本，而不是让一个自信的分支静默获胜；
- **security advisory / yank / revocation**：发现问题依赖时，沿依赖图撤销所有下游证书，而不是只发一条告警。

把这套范式搬到“校准证据”上，就得到本轮的治理层：
**先验、工具、回执、假设、修复、评估结果全部是包**；修复是 pull request；
V 阶段是 CI；热替换是 merge；P-Quarantine 是 advisory；严格退化链是“构建失败则不发布”。
最关键的转变是：**信任的根从“模型/维护者的权威”换成“独立可重放的产物”**。

### 合流：开源依赖图同时是共同模式失效图和成功率的有效样本量图

这是本轮最想在概念上钉死的一点：
第 2 轮的最大风险是“一个错误的摊销先验同时污染所有含该材质的盲区”。
用开源的视角看，这不是一句风险描述，而是一张**证据依赖图（EDG）**：
被投毒的先验是图上的一个节点，它的后代就是爆炸半径，撤销（revocation）就是沿图传播。
同时，从统计的视角看，这些共享依赖的后代**不是独立样本**：
100 条回执若只来自 10 个共享依赖分量，有效样本量是 10 而不是 100；
用 100 去算置信区间会系统性低估不确定性（后文引理 55 与合成实验给出具体数字）。
于是“成功率”和“开源软件”不是两个并列的装饰，而是同一个结构的两个面：
**依赖图决定证据的独立性，独立性决定成功率的有效分母，撤销决定这个分母何时作废。**

## 1. 形式化定义（增量：定义 432–443）

**定义 432（成功事件代数与成功率估计量）**
设 t 时刻的**评估总体**为 `𝓢_t`，评估分布为 `P_t`（显式声明，**不是**实际观测分布）。
对每个单位 s 与层级 `ℓ ∈ {probe, repair, retention, task, mission}`，定义成功事件 `E_s^ℓ` 与 `Y_s^ℓ = 1[E_s^ℓ]`：
`θ_ℓ(t) = E_{s∼P_t}[Y_s^ℓ]`。
层级满足 `E^M ⊆ E^T ⊆ E^R`，故 `θ_M ≤ θ_T ≤ θ_R`。
一份成功率主张必须携带六元组
`(ℓ, P_t, H_ℓ, 分母策略, 观测策略, 删失规则)`，缺一即不可审计。
“修复成功率”不是“任务成功率”；ToolGauge 的 V 通过只是 `θ_R` 的一个带选择偏差的样本。

**定义 433（分母台账与处置）**
每个合格单位 s 在时刻 t 必须恰有一个处置：
`succ / fail / censored / void / pending / excluded(reason)`。
分母 `D_t` 为所有未被 `excluded` 的单位；**禁止静默排除**：每个 excluded 必须带预注册原因码并进入审计台账。
定义分母完整性 `δ_t = |{succ,fail,censored,void}| / |D_t|`（pending 越少越完整），
观测覆盖率 `cov_t = Σ_s w_s O_s / Σ_s w_s`（w_s 为风险权重）。
一份主张若不报告 `(δ_t, cov_t, exclusion 分布)`，视为无效。

**定义 434（观测策略与 IPW/IPCW 估计）**
`O_s ∈ {0,1}` 表示单位 s 是否被观测/探测，`π(s) = P(O_s=1 | s)` 为设计概率或交叉拟合估计。
在正性 `π(s) ≥ π_min > 0` 与正确 π 下：
`θ̂_HT = (1/|D|) Σ_{s∈D} O_s Y_s / π_s`，`θ̂_Hajek = Σ O_s Y_s/π_s / Σ O_s/π_s`。
若使用估计 `π̂` 且 `π/π̂ ∈ [1−ε, 1+ε]`，则 `|E θ̂ − θ| ≤ ε·E[Y]`。
对右删失的时间-事件成功，用 IPCW Kaplan–Meier / Aalen–Johansen；
对不可忽略缺失（MNAR），不声称无偏，改为报告 **E-value 灵敏度**：
要解释掉观测到的风险比 r，未观测选择强度至少要有 r。

**定义 435（成功率证书 SRC 与 anytime 有效下界）**
`SRC = (claim, {K_t(θ0)}, LCB_t, denom_hash, policy_hash, support_hash)`。
对取值 `Y ∈ [0,1]` 的序列，检验 `H0: θ ≤ θ0`：
`K_t(θ0) = Π_{i=1..t} (1 + λ_i (Y_i − θ0))`，其中 `λ_i` 可预测且
`λ_i ∈ [−1/(1−θ0), 1/θ0]`。则 `K_t(θ0)` 在 H0 下为非负上鞅，Ville 不等式给出
`P_{H0}(sup_t K_t ≥ 1/α) ≤ α`。
置信序列 `CS_t = {θ0 : K_t(θ0) < 1/α}`，下界 `LCB_t = inf CS_t`。
于是**任意可选停止、任意监控频率**下，`LCB_t` 的误报率都不超过 α。
非平稳时使用分段 e-process（带切换预算 `Σ 1[restart] ≤ R_max`）或自适应下注；
切换预算耗尽即降级为 ToolGauge 的局部指示，并标记 SRC 为“未认证”。

**定义 436（Goodhart 护栏：成功率-覆盖-分母联合契约）**
一份主张可被接受当且仅当四条件同时成立：
`LCB_t ≥ θ_req`，`cov_t ≥ κ`，`δ_t ≥ δ_req`，`shopping_alarm = 0`。
其中 `shopping_alarm` 由一个预注册的 e-process 维护：检验“实际观测分布 = 声明的观测策略”，
若拒绝则说明系统正在通过改变探测对象来美化成功率。
**命题（裸成功率不可审计）**：若移除覆盖与分母约束，则对任意观测到的成功率 r<1，
都存在一个排除策略使报告值变为 1（只保留成功单位）；故联合契约不是“更严格”，而是**必要**。

**定义 437（校准包 CP）**
包 `P = (uid, semver, type, manifest, payload, deps, provenance, license, sig)`：
- `type ∈ {prior, tool, receipt-bundle, hypothesis, repair, eval}`；
- `manifest = (merkle(payload), build_recipe, env_digest, data_lineage, parent_commit, created_at, author)`；
- `verify(P)` 检查 payload 哈希、签名、依赖已注册且兼容、许可证允许当前部署上下文、provenance 非空。
**未通过 verify 的包不得进入任何数值路径**；它只能作为被隔离的 fork 存在。

**定义 438（语义版本与兼容偏序）**
`P ≺ Q`（Q 可替换 P）按三档定义：
- patch：仅参数变化，行为在重放容差 `ε_rep` 内等价；
- minor：增加能力但保留旧保证（`Guarantees(P) ⊆ Guarantees(Q)`）；
- major：接口、物理包络或**估计量**变化，必须重新建立 SRC 并重新验收。
`compatible(P,Q)` 是偏序；一次解析是一个极大兼容集。
契约组合还要求 `Out(P) ⊆ In(Q)`（精化关系），否则组合为 `⊥`。
这条定义堵住“minor 升级悄悄改变安全包络、却仍复用旧证书”的漏洞。

**定义 439（证据依赖图 EDG 与传递撤销）**
`EDG = (V,E)`，`V = packages ∪ certificates`，边 `u→v` 表示 v 的支撑使用了 u。
`support(C) = Reach^{-1}(C)`（传递祖先）。撤销集 `Revoked` 的闭包
`Revoked* = TC_rev(Revoked)` 包含所有直接或间接依赖被撤销节点的证书。
**证据可撤销不变式**：已部署证书 C 必须满足 `support(C) ∩ Revoked* = ∅`。
`revoke(v, reason, advisory_id)` 后，回滚到最新的、支撑集与 `Revoked*` 不交的已部署证书；
若无，则 `stub + RED`。爆炸半径 `|descendants(v)|` 是撤销前必须报告的审计量。
数据谱系被投毒、工具契约有 bug、先验 checkpoint 被替换，都走同一条传播路径。

**定义 440（Fork-Merge 治理）**
同一盲区/契约的竞争性修复形成 fork 集 `F = {C_1,…,C_k}`。
证据未齐时，**实际部署最悲观分支** `C_wc = argmin_{C∈F} LCB_θ(C)`；
不允许“先合并最乐观分支、等以后再验证”。
合并 `C*` 需同时满足：
(i) 重放门通过；(ii) `LCB_θ(C*) ≥ max_{C∈F∪{base}} LCB_θ(C) + margin`（带多重性修正）；
(iii) `support(C*) ∩ Revoked* = ∅`；(iv) 许可证/同意约束满足；(v) 与已部署组合无契约冲突。
合并在图中生成一个双亲 merge 节点，保留完整审计历史；不通过则保留 fork 或回滚。

**定义 441（可复现重放门 RG）**
`RG(P) ∈ {REPRODUCED, STAT-REPRODUCED, FAILED}`。
确定性 payload：重算哈希，逐字节一致才算 `REPRODUCED`。
随机 payload：按 manifest 的种子/环境重放，用预注册的等价性检验（两样本 e-test 或置信区间）
要求 `|θ_replay − θ_orig| ≤ ε_rep`，通过则为 `STAT-REPRODUCED`。
高风险 major 变更需要 k 个**独立审计者**的签名重放证明（many eyes 的可执行版本）；
证明本身也是包，进入 EDG。**可复现性是唯一的信任根；声誉与作者身份不作为证据。**

**定义 442（OpenGauge 8C 闭环）**
`8C = H → C → E → C → V → P → M → U`，外加带外 `R`：
H 假设 → C 编译 → E 执行 → C 校准 → V 验证/重放 → P 打包 → M 合并决策 → U 热替换；
R（Revocation Monitor）持续消费 advisory 并触发回滚。
每个阶段都产出包；V 同时更新 SRC；U 只替换已验证子图；50Hz 主路径不变。
**没有 SRC 或支撑集被撤销的包，不得进入 U。**

**定义 443（继承与退化约定）**
令单包、无 fork、无撤销、`SRC` 退化为局部 V 指示、IPW/删失关闭，则 OpenGauge ≡ ToolGauge；
再令 VLA=∅、工具库退化为被动观测，则 ≡ LeanGauge；再关闭计量层，则 ≡ MODGAUGE。
包含关系：`OpenGauge ⊃ ToolGauge ⊃ LeanGauge ⊃ MODGAUGE`；退化箭头反向。
所有新增字段都是元数据，**不进入数值通道**；任一新增组件失效，退回 ToolGauge，而不是进入未认证状态。

## 2. 关键算法骨架

```python
from dataclasses import dataclass
from typing import Literal

# ---------- 定义 432–436：成功率契约 ----------
@dataclass(frozen=True)
class Claim:
    level: Literal["probe","repair","retention","task","mission"]
    eval_dist: str          # P_t 的声明标识（不是观测分布）
    horizon: float          # H_l
    denom_policy: str
    obs_policy: str
    censor_rule: str

@dataclass
class SRC:
    claim: Claim
    lcb: float              # anytime-valid lower bound（定义 435）
    denom_hash: str
    policy_hash: str
    support_hash: str       # support(C) 的 Merkle 根
    e_state: dict           # θ0 网格 -> K_t(θ0)

class DenominatorLedger:
    def __init__(self):
        self.disp = {}      # s -> (status, reason)
    def put(self, s, status, reason=None):
        assert status in {"succ","fail","censored","void","pending","excluded"}
        if status == "excluded":
            assert reason in REASONS       # 定义 433：无静默排除
        self.disp[s] = (status, reason)
    def completeness(self):
        d = len(self.disp)
        return sum(1 for st,_ in self.disp.values() if st != "pending") / max(d,1)
    def audit(self):
        return {st: sum(1 for x,_ in self.disp.values() if x == st)
                for st in {"succ","fail","censored","void","pending","excluded"}}

class SuccessMonitor:
    """IPW/IPCW + e-process + anytime LCB（定义 434/435）。"""
    def __init__(self, grid, alpha=0.05, lam=1.0):
        self.grid, self.alpha, self.lam = grid, alpha, lam
        self.K = {th: 1.0 for th in grid}
        self.ht = 0.0; self.w = 0.0
        self.cov_num = 0.0; self.w_sum = 0.0
    def observe(self, y, pi_s, w_s=1.0):
        self.ht += y / pi_s; self.w += 1.0 / pi_s
        self.cov_num += w_s; self.w_sum += w_s / pi_s
        for th in self.grid:                       # 逐 θ0 更新
            self.K[th] *= 1.0 + self.lam * (y - th)
    def lcb(self):
        ok = [th for th in self.grid if self.K[th] < 1.0/self.alpha]
        return min(ok) if ok else 0.0
    def coverage(self):
        return self.cov_num / max(self.w_sum, 1e-12)

class GoodhartGuard:
    def __init__(self, theta_req, kappa, delta):

class EDG:
    def __init__(self):
        self.up, self.down = {}, {}
        self.revoked = set()
    def add(self, v, deps):
        self.up[v] = set(deps)
        for d in deps: self.down.setdefault(d, set()).add(v)
    def support(self, c):
        seen, stack = set(), [c]
        while stack:
            v = stack.pop()
            for p in self.up.get(v, ()):
                if p not in seen: seen.add(p); stack.append(p)
        return seen
    def revoke(self, v, reason):
        self.revoked.add(v)
        # Revoked* = 所有直接/间接依赖被撤销节点的证书；爆炸半径 = descendants(v)
    def rollback_target(self, history):
        clean = [c for c in history if not (self.support(c) & self.revoked)]
        return max(clean, key=lambda c: c.manifest["created_at"], default=None)

class ForkMerge:

def opengauge_8c(M, s):

    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s))     # C
    receipts = M.tcv.execute(prog, M.env)                         # E
    mu, Sig = M.apcal.calibrate(receipts, H, s)                   # C
    if not M.vgate(receipts, mu, Sig):                            # V：交叉验证 + replay

    pkg = M.cpr.package_repair(s, H, prog, receipts, mu, Sig)     # P：打包
    if not M.cpr.verify(pkg): return M.rollback_or_stub(s)
    src = M.smon.update(pkg, M.ledger, M.obs_policy)              # SRC
    if not M.guard.admissible(src, M.smon.coverage(),
                              M.ledger.completeness(), M.shopping_alarm()):
        return M.keep_fork(s)                                     # 不合并，保留最悲观分支
    merged = M.forkmerge.merge(M.deployed[s], M.forks[s], pkg, M.edg)

    M.edg.add(merged, deps=pkg.deps); M.cpr.commit(pkg)
```

## 3. 推导

**引理 51（anytime 有效的成功率下界）**
在定义 435 的可预测下注与有界 `Y∈[0,1]` 下，对任意（可数据依赖的）停止时刻 τ，
`P_{θ≤θ0}(∃t≤τ : LCB_t > θ0) ≤ α`。
证明：`K_t(θ0)` 在 `H0: θ≤θ0` 下为非负上鞅，Ville 不等式直接给出
`P(sup_t K_t ≥ 1/α) ≤ α`；`LCB_t > θ0` 蕴含 `sup K_t ≥ 1/α`。
系：监控频率与停止规则不影响误报率；这正是固定样本 Wald 区间在“反复偷看”下失效的对照（见 §6 合成实验）。
非平稳时，分段 e-process 的误报率 ≤ α + P(切换预算耗尽)，故必须把“切换预算耗尽”作为降级事件显式记录。

**引理 52（观测/删失偏差与灵敏度）**
在正性与正确 `π` 下，`E[θ̂_HT] = θ`；若 `π/π̂ ∈ [1−ε,1+ε]`，则 `|E θ̂_HT − θ| ≤ ε·E[Y]`。
右删失下 IPCW 估计在删失可忽略（或删失模型正确）时一致。
对 MNAR，不存在无假设的无偏估计；E-value 给出可审计的灵敏度下界。
**系（Goodhart 不可能性）**：去掉覆盖/分母约束后，成功率可被排除策略操纵到任意接近 1；
因此定义 436 的联合契约是任何“成功率”主张的必要条件，而不是可选的稳健性装饰。

**引理 53（撤销可靠性与回滚安全）**
设 t 时刻已部署证书 C 满足 `support(C) ∩ Revoked*_t = ∅`，且 `Revoked` 单调增长。
撤销事件后，回滚目标 C' 若存在，则按定义 `support(C') ∩ Revoked*_{t+1} = ∅`；
若不存在，`stub + RED` 使系统进入不依赖任何被撤销证据的安全态。
故“证据可撤销不变式”在每次撤销/回滚后保持。
爆炸半径 `|descendants(v)|` 是撤销代价的上界；EDG 的 DAG 结构保证传播终止。

**引理 54（fork-merge 安全性）**
证据未齐时部署 `C_wc = argmin LCB`，故对任意 fork j，
`LCB_θ(C_wc) ≤ LCB_θ(C_j)`——实际部署的分支是**最悲观**的，乐观分支不会先上线。
合并条件 (ii) 在 `k` 个分支上用 Bonferroni 校正 `α/k` 后，
`P(∃C∈F∪{base}: θ(C) < LCB(C)) ≤ α`；若 `LCB(C*) ≥ max LCB + margin`，
则真实 θ(C*) 以至少 `1−α` 的概率不低于基线加 margin。
无 fork 时退化为 ToolGauge 的 U 阶段；有 fork 时，“分歧”被显式保留而不是被平均掉。

**引理 55（依赖图决定有效样本量）**
设回执被 EDG 分成 `G` 个独立共同模式分量，每个分量内 `m` 条回执完全相关（ρ=1）。
则 `n_eff = G = n/m`，`Var(θ̂) = θ(1−θ)/n_eff`。
若误用 n 计算 Wald 区间，标准误被低估 `√m` 倍；
正态近似下名义 `1−α` 区间的实际覆盖约为
`2Φ(z_{1−α/2}/√m) − 1`（m=10 时约 0.46），小样本/偏态下可更低（本轮合成实验为 0.31）。
故 SRC 的样本量必须使用 `n_eff`，或直接在分量级做 e-process。
系：串联任务的成功率不能由边际成功率的乘积给出；必须按 EDG 分量联合重放，
否则共同模式失效会被“独立性假设”静默漏计。

**引理 56（时序与预算保持）**
SRC 的 e-process 更新为每条回执 O(k)（k=θ0 网格，典型 ≤ 100），可在异步校准线程完成；
IPW/IPCW 为批处理 O(n)；包验证/重放/EDG 撤销/合并决策均在 50Hz 路径之外。
50Hz 内联只增加一次缓存证书与撤销位的检查，O(1) < 0.1ms；
撤销事件最坏 O(|V|+|E|)，事件驱动且稀疏。
故第 2 轮的硬实时（引理 45）、TB-Contract 预算与严格退化链保持；
任何新组件不可用 ⇒ 退回 ToolGauge，而不是降低 50Hz 安全性。

## 6. 本轮最大风险（一句话）

**成功率一旦成为可合并的证书，优化压力就会从“修得更好”转向“把分母做小、把难例删失、把观测策略改窄”（Goodhart），
而开源式共享依赖会让一次被投毒/有缺陷的公共先验沿 EDG 同时污染大量下游证书——
度量越是被优化得漂亮，越可能不再度量真实能力。**

**次级风险与缓解**：
1. **Goodhart / 成功率高估** → 联合契约（成功率 + 覆盖 + 分母完整性）+ 预注册观测策略 + shopping e-process + 外部审计。
2. **共同模式污染 / 供应链投毒** → EDG + 重放门 + 独立审计证明 + 最悲观分支 + 传递撤销 + 爆炸半径上限。
3. **e-process 过于保守 / 功效不足** → 自适应下注、分段重启、按风险分层报告 LCB；点估计只作展示，不作合并依据。
4. **删失/MNAR** → 预注册删失规则 + E-value 灵敏度 + 缺失机制审计；不可忽略缺失不得声称无偏。
5. **依赖地狱 / 包图爆炸** → lockfile + 极大兼容集 + major 变更强制新 SRC + 依赖解析超时降级。
6. **重放不可复现** → manifest 捕获种子/环境；随机过程用统计等价；失败即不合并。
7. **许可证/同意不匹配** → 作为合并硬约束，而不是事后合规检查。
8. **“many eyes”变成“没人真看”** → 独立重放证明是签名的包，进入 EDG；高风险变更要求 k 个独立审计者。
9. **治理层拖慢修复** → 全部异步/离线；50Hz 路径不动；不可用时严格退回 ToolGauge。

# 第 3 轮产物 · 创新点清单 v3：**OpenGauge**（Open, Reproducible, Revocable Success-Rate Metrology with Package-Level Evidence Governance）

## 2. 形式化定义（要点）

**定义 432（成功率估计量）** 成功率必须声明
`(层级 ℓ, 评估分布 P_t, 时域 H_ℓ, 分母策略, 观测策略, 删失规则)` 六元组；
`θ_ℓ(t)=E_{s∼P_t}[Y_s^ℓ]`。层级满足 `E^M⊆E^T⊆E^R`，故 `θ_M≤θ_T≤θ_R`。
ToolGauge 的 V 通过只是 `θ_R` 的一个带选择偏差的样本，不能直接外推为任务成功率。

**定义 433（分母台账）** 每个合格单位恰有一个处置：
`succ/fail/censored/void/pending/excluded(reason)`；禁止静默排除。
`δ_t` 为分母完整性，`cov_t` 为风险加权覆盖率；二者必须与成功率一起报告。

**定义 434（观测/删失校正）** 在正性与正确 `π` 下 HT 无偏；
`π/π̂ ∈ [1−ε,1+ε]` 时偏差 ≤ `ε·E[Y]`；右删失用 IPCW Kaplan–Meier/Aalen–Johansen；
MNAR 不做无偏声称，报告 E-value 灵敏度。

**定义 435（SRC 与 anytime 有效下界）** `K_t(θ0)=Π(1+λ_i(Y_i−θ0))`，可预测
`λ_i∈[−1/(1−θ0),1/θ0]`；Ville 保证 `P(sup_t K_t≥1/α)≤α`；
`CS_t={θ0:K_t(θ0)<1/α}`，`LCB_t=inf CS_t`。可选停止/任意监控频率下误报率 ≤ α。

**定义 436（Goodhart 联合契约）** 主张可接受 iff
`LCB_t≥θ_req ∧ cov_t≥κ ∧ δ_t≥δ_req ∧ shopping_alarm=0`。
**命题**：无覆盖/分母约束时，成功率可被排除策略操纵到任意接近 1；联合契约是必要条件。

**定义 437（校准包）** `P=(uid,semver,type,manifest,payload,deps,provenance,license,sig)`；
`verify(P)` 检查哈希、签名、依赖注册与兼容、许可证、provenance。
未通过 verify 的包不得进入数值路径。

**定义 438（语义版本兼容）** patch=参数级行为等价（容差 `ε_rep`）；
minor=增加能力且保留旧保证；major=接口/物理包络/估计量变化，必须重建 SRC。
契约组合要求 `Out(P)⊆In(Q)`，否则 `⊥`。

**定义 439（EDG 与传递撤销）** `support(C)` 为传递祖先；
`Revoked*=TC_rev(Revoked)`；部署证书必须满足 `support(C)∩Revoked*=∅`。
撤销后回滚到最新支撑干净的证书，无则 `stub+RED`；爆炸半径 `|descendants(v)|` 进入审计。

**定义 440（Fork-Merge）** 证据未齐时部署 `C_wc=argmin LCB`；
合并需重放门通过、`LCB(C*)≥max LCB+margin`（多重性修正）、支撑干净、许可证满足、无契约冲突。
merge 生成双亲节点，保留完整历史。

**定义 441（重放门）** 确定性包要求逐字节哈希一致；随机包要求预注册等价性检验
`|θ_replay−θ_orig|≤ε_rep`；高风险 major 变更需 k 个独立审计者的签名重放证明。
**可复现性是唯一信任根，作者声誉不是证据。**

**定义 442（OpenGauge 8C）** `H→C→E→C→V→P→M→U + R`；
每阶段产包；V 更新 SRC；M 做 fork/merge 与 EDG 更新；U 只替换已验证子图；R 消费 advisory 并回滚。

**定义 443（继承与退化）** 单包、无 fork、无撤销、SRC=局部 V 指示 ⇒ ToolGauge；
再 VLA=∅、被动工具 ⇒ LeanGauge；再关闭计量层 ⇒ MODGAUGE。
`OpenGauge ⊃ ToolGauge ⊃ LeanGauge ⊃ MODGAUGE`。

```python
# IP-321/322：分母台账 + IPW/IPCW + e-process + 联合护栏
@dataclass(frozen=True)
class Claim:
    level: str; eval_dist: str; horizon: float
    denom_policy: str; obs_policy: str; censor_rule: str

@dataclass
class SRC:
    claim: Claim; lcb: float
    denom_hash: str; policy_hash: str; support_hash: str
    e_state: dict                      # θ0 grid -> K_t(θ0)

class DenominatorLedger:
    def put(self, s, status, reason=None):
        assert status in {"succ","fail","censored","void","pending","excluded"}
        if status == "excluded": assert reason in REASONS   # 无静默排除
        self.disp[s] = (status, reason)
    def completeness(self):
        return sum(st != "pending" for st,_ in self.disp.values()) / max(len(self.disp),1)

class SuccessMonitor:
    def __init__(self, grid, alpha=0.05, lam=1.0):
        self.grid, self.alpha, self.lam = grid, alpha, lam
        self.K = {th: 1.0 for th in grid}
        self.ht = self.w = self.cov_num = self.w_sum = 0.0
    def observe(self, y, pi_s, w_s=1.0):
        self.ht += y/pi_s; self.w += 1.0/pi_s
        self.cov_num += w_s; self.w_sum += w_s/pi_s
        for th in self.grid: self.K[th] *= 1.0 + self.lam*(y-th)
    def lcb(self):
        ok = [th for th in self.grid if self.K[th] < 1.0/self.alpha]
        return min(ok) if ok else 0.0
    def coverage(self): return self.cov_num / max(self.w_sum, 1e-12)

class GoodhartGuard:
    def admissible(self, src, coverage, denom_complete, shopping_alarm):
        return (src.lcb >= self.theta_req and coverage >= self.kappa
                and denom_complete >= self.delta and not shopping_alarm)

# IP-323/324：包 + EDG 传递撤销
@dataclass
class Package:
    uid: str; semver: str; typ: str
    manifest: dict; payload: bytes; deps: list[str]
    provenance: dict; license: str; sig: str

class CPR:
    def verify(self, p):
        return (merkle(p.payload) == p.manifest["root"] and verify_sig(p)
                and all(dep_registered(d) for d in p.deps)
                and license_ok(p.license, DEPLOY_CONTEXT))

class EDG:
    def support(self, c):
        seen, stack = set(), [c]
        while stack:
            v = stack.pop()
            for p in self.up.get(v, ()):
                if p not in seen: seen.add(p); stack.append(p)
        return seen
    def revoke(self, v, reason):
        self.revoked.add(v)            # Revoked* = 依赖被撤销节点的全部后代
    def rollback_target(self, history):
        clean = [c for c in history if not (self.support(c) & self.revoked)]
        return max(clean, key=lambda c: c.manifest["created_at"], default=None)

# IP-325/326：fork-merge + 8C
class ForkMerge:
    def deploy_worst_case(self, forks):
        return min(forks, key=lambda c: c.src.lcb)          # 最悲观分支
    def merge(self, base, forks, star, edg):
        if not replay_gate(star): return None
        if star.src.lcb < max([base.src.lcb] + [c.src.lcb for c in forks]) + MARGIN:
            return None
        if edg.support(star) & edg.revoked: return None
        if not license_ok(star.license, DEPLOY_CONTEXT): return None
        return merge_commit(base, star)                      # 双亲节点

def opengauge_8c(M, s):
    H = M.lbox.hypothesize(s, M.dbox.R[s])                   # H
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s)) # C
    receipts = M.tcv.execute(prog, M.env)                     # E
    mu, Sig = M.apcal.calibrate(receipts, H, s)               # C
    if not M.vgate(receipts, mu, Sig): return M.rollback_or_stub(s)   # V
    pkg = M.cpr.package_repair(s, H, prog, receipts, mu, Sig) # P
    if not M.cpr.verify(pkg): return M.rollback_or_stub(s)
    src = M.smon.update(pkg, M.ledger, M.obs_policy)          # SRC
    if not M.guard.admissible(src, M.smon.coverage(),
                              M.ledger.completeness(), M.shopping_alarm()):
        return M.keep_fork(s)
    merged = M.forkmerge.merge(M.deployed[s], M.forks[s], pkg, M.edg)
    if merged is None: return M.keep_fork(s)
    M.mreg.hot_replace(M.dpe, merged)                         # U
    M.edg.add(merged, deps=pkg.deps); M.cpr.commit(pkg)
    return True

def revocation_watchdog(M):
    for adv in M.cpr.advisories():
        M.edg.revoke(adv.uid, adv.reason)
        for s in M.deployed:
            if M.edg.support(M.deployed[s]) & M.edg.revoked:
                tgt = M.edg.rollback_target(M.history[s])
                M.mreg.hot_replace(M.dpe, tgt) if tgt else stub_and_red(s, "revoked")
```

## 4. 推导

**引理 51（anytime 有效成功率下界）** 在定义 435 的可预测下注、有界 `Y∈[0,1]` 下，
`P_{θ≤θ0}(∃t≤τ:LCB_t>θ0)≤α`（非负上鞅 + Ville）。系：监控频率与停止规则不改变误报率；
固定样本 Wald 区间在反复偷看下会严重失效（§6 合成实验：误报率 83.7% vs e-process 4.55%）。
非平稳时用分段 e-process，切换预算耗尽即标记 SRC 未认证并降级。

**引理 52（观测/删失偏差与灵敏度）** 正性 + 正确 π 下 HT 无偏；
`π/π̂∈[1−ε,1+ε]` ⇒ 偏差 ≤ `ε·E[Y]`；IPCW 在删失可忽略/模型正确时一致；
MNAR 用 E-value 报告灵敏度。**系（Goodhart 不可能性）**：去掉覆盖与分母约束，
成功率可被排除策略操纵到接近 1；联合契约是必要条件。

**引理 53（撤销可靠性）** 单调增长的 `Revoked` 下，回滚目标 C' 满足
`support(C')∩Revoked*=∅`；无目标则 stub+RED 进入不依赖被撤销证据的安全态。
不变式按撤销事件归纳保持；爆炸半径是撤销代价上界，DAG 保证传播终止。

**引理 54（fork-merge 安全）** 未决时部署 `C_wc=argmin LCB` ⇒ 实际部署分支最悲观；
合并条件用 Bonferroni `α/k` 校正后，`P(∃C:θ(C)<LCB(C))≤α`；
`LCB(C*)≥max LCB+margin` ⇒ 真实 θ(C*) 以 ≥1−α 概率不低于基线加裕度。
无 fork 时退化为 ToolGauge U。

**引理 55（依赖图决定有效样本量）** EDG 分成 G 个独立共同模式分量、每分量 m 条完全相关回执时，
`n_eff=G=n/m`，`Var(θ̂)=θ(1−θ)/n_eff`；误用 n 计算 Wald 区间会把标准误低估 √m 倍，
m=10 时正态近似覆盖约 `2Φ(1.96/√10)−1≈0.46`，小样本/偏态可更低（合成实验 0.31）。
系：串联任务成功率不能由边际乘积给出，必须按 EDG 分量联合重放。

**引理 56（时序预算保持）** e-process O(k)/回执（异步），IPW O(n) 批处理，
包验证/重放/撤销/合并全部在 50Hz 路径外；内联只查缓存证书与撤销位 O(1)<0.1ms，
撤销最坏 O(|V|+|E|) 事件驱动。硬实时、TB-Contract 与严格退化链保持。

## 9. 本轮最大风险

**一句话**：成功率一旦成为可合并的证书，优化压力就会从“修得更好”转向
“把分母做小、把难例删失、把观测策略改窄”（Goodhart），
而开源式共享依赖会让一次被投毒/有缺陷的公共先验沿 EDG 同时污染大量下游证书——
度量越是被优化得漂亮，越可能不再度量真实能力。

**三重兜底**：
1. **统计兜底**：SRC 的 anytime LCB + 分母/覆盖联合契约 + shopping e-process + E-value 灵敏度；
2. **结构兜底**：EDG 传递撤销 + 最悲观 fork + 重放门 + 独立审计证明 + 爆炸半径上限；
3. **退化兜底**：SRC/包/图/合并任一不可用 ⇒ 严格退回 ToolGauge 的进程内 6C ⇒ LeanGauge ⇒ MODGAUGE；
   50Hz 路径与 MODGAUGE 五不变式始终不动。
