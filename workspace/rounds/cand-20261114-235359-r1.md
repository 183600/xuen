# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环第 3 轮；本轮灵感：「自监督学习」×「指令泛化」）

> R69 把不确定性一分为二（aleatoric / epistemic），并让系统学会「问」。但它悄悄假设了一件最上游的事：**它已经听懂了问题**——所有 epistemic 都是「世界状态的歧义」（绕左还是绕右），所有交互都是「向世界求证」（看/摸/看表情）。R69 从未质疑更上游的量：**我是否理解了这条指令、这个任务，以及我有没有能力做它**。当用户说「小心地把它放到左边那个『差不多』的位置」时，危险的不是动作模态歧义，而是系统根本不知道「小心」「差不多」在它的技能空间里对应什么。R69 会自信地用 VoI 去消除一个**它自己编造出来的世界歧义**，把宝贵的交互预算花在错误的问题上——问得越多，错得越深。
>
> 本轮两个灵感正好补上两个缺口：
> - **指令泛化**给出「任务层的可组合性」——把指令分解为 **基元技能 × 修饰子**（快/慢、轻/重、否定、顺序、并列、空间参照），使新指令由已会技能组合而来，并在**组合不出来时知道自己不会**；
> - **自监督学习**给出「无标签的接地与校准」——在没有人工标签的情况下，从无标注轨迹里长出技能流形，用预测自洽性检验「我理解的任务」是否与「世界实际怎么走」一致，并在表征坍缩时提前叫停。
>
> 核心命题：**在 R69 的「世界级 epistemic」之上再分出「任务级 epistemic」（我是否听懂、我是否会做）；两级不确定性按字典序处置——先确认任务身份，再消解世界状态。任务身份不确定时，R69 的一切世界级交互必须被挂起，系统只能澄清意图或安全拒答/降级；任务身份确认后，逐指令退化为 R69。自监督是让这一切无需人工标签即可运行、并能在线自检表征健康的引擎。** 命名 **SIGMA-RAS**（Self-supervised Instruction-Grounded Mode Arbitration）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我到底被要求做什么、我配做吗、我怎么在没人贴标签时知道自己懂了**」。

## 0. 直觉与动机

**灵感 1（指令泛化 → 指令不是标签，是一段可组合的程序）**
直觉：把指令当作一个原子标签去分类，是过拟合的根源；真实指令是**组合**——「把红色方块放进左边盒子」= 基元(抓取) × 修饰(红色) × 基元(放置) × 修饰(左侧) × 时序(先抓后放)。人之所以能听懂没听过的句子，是因为掌握的是**组合规则**而不是句子列表。于是「听不懂」被精确化：不是「没匹配到标签」，而是**「无法用受支持的基元与修饰子组合出这个程序」**。这把 R69 的「不确定就多采样/去问」升级为「先检查我能否组合出这个任务」，并给出一个可判定的能力边界。

**灵感 2（自监督学习 → 技能与校准都可以不要标签）**
直觉：R69 的模态权重校准（ECE）需要标签，但机器人在线运行时几乎没有标签；若等标注，MCG 永远闭着。然而无标签轨迹里塞满了信号：**时间顺序、前后一致性、动作与观测的互预测**。自监督能从中长出三样东西：(a) 可复用的技能流形（哪些动作块反复出现、可被拼装）；(b) 预测自洽性（我选的那个模态，是否真的预测对了接下来发生的事）——一个**无需人工标签的模态可靠性评分**；(c) 表征健康度（有效秩、均匀性），能在「模式坍缩」的上游根因（表征坍缩）刚露头时报警。自监督因此不是锦上添花，而是把 R69 最脆弱的前提「模态分布可信」变成可在运行时自检的量。

**灵感 3（两级字典序 → 任务不确定性优先于世界不确定性）**
直觉：解错题比算错数更致命。R69 的所有 VoI 都在「任务正确」前提下才成立；一旦任务理解错了，VoI 会精确而殷勤地把系统引向**错误问题的最优解**。所以安全顺序必须是字典序的：**先任务、后世界**。这不是加一个模块，而是给 R69 的所有交互加了一个**执行前置门**：任务身份置信度不足，就不得启动世界级探询（因为你不知道在给哪个任务探询），更不能执行任务动作。这是本轮最重要的安全姿态：**R69 是新系统在「任务已确证」边界上的退化**。

**灵感 4（自监督的双刃剑 → 自我确认的自信）**
直觉：自监督能把「不知道」变成「看起来自洽」，这既是解药也是毒药。如果预测模型与策略共享同一个盲点，错误的理解会**自我验证**：系统预测「这样做会发生 A」，做了果然（因为观测和模型一起错）像 A，于是它给自己盖上「已验证」的章，还因为「更自信」而**减少**了本该有的澄清。R69 最大的风险是「问错」；R70 最大的风险是「**以为自己懂了**」——自监督让错误理解获得一种廉价的正当性。所以本轮必须交付：正交自监督视图（避免自证）、自监督数据卫生（防投毒），以及「校准只提供似然、不单独定案」的证据纪律。

**灵感 5（指令层的新攻击面 → 提示注入与指令投毒）**
直觉：一旦「指令」成为一等公民，攻击就从「让传感器读错」升级为「让任务理解错」——对抗性指令、提示注入、欠定/自相矛盾指令、分布外指令、以及污染无标签流来毒化技能库。指令级错误会**合法地**通过所有底层安全认证：动作本身完全合规，只是做的是错事。因此必须把 ℰ_instr 并入 AIC，并让拒答/澄清成为可审计的一等安全动作。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（SIGMA-RAS 总览）** SIGMA-RAS = (FLUID-RAS, SIG, TUR, SSMC, RCS, IGG, AIC-SIGMA)。四不变式：
(i) 继承 R69 的实时流零学习写操作（异步学习更新全部离线、版本化、可回滚）；
(ii) **任务身份优先（字典序安全）**：U_task 未降到 τ_task 以下前，禁止执行任何任务动作与世界级信息动作，只允许意图澄清或安全拒答/降级；
(iii) **无标签校准**：模态/接地校准在运行时必须由自监督预测自洽性检验，人工标签只用于离线复核；
(iv) **可审计接地**：每次执行必须能给出「技能组合 + 支持距离 + 证据源」的可核验记录。

**定义 311（技能流形与能力边界）** 无标签轨迹语料 𝒟_u={τ_i}，自监督技能编码 E_skill: τ↦s∈ℝ^d。技能库 𝒮={s_1,…,s_L} 为嵌入空间聚类中心。支持距离 d_supp(s*)=min_l‖s*−s_l‖；能力边界 ρ_comp 由 𝒮 的距离分位数校准。d_supp>ρ_comp ⇒ 越出能力，不得自主执行。

**定义 312（自监督技能表示目标）** L_SSL = L_MTM + α·L_TC + β·(L_fwd + L_inv)；L_MTM 为掩码轨迹重建，L_TC 为时间对比（相邻窗为正、远窗为负的 InfoNCE），L_fwd/L_inv 为前向/逆向动力学一致性。该目标不依赖人工标签，为 R68 的 MTM trunk 提供同源训练范式（R70 直接复用 R69 的条件编码器作为 E_skill 骨干，零重复训练）。

**定义 313（指令代数与修饰子等变）** 指令 ℓ 解析为组合 b_1∘μ_1∘…∘b_n，其中基元 b∈ℬ（技能），修饰子 μ∈G（速度、力度、否定、顺序、并列、空间参照）。修饰子群 G 在技能嵌入上以 ρ(μ) 作用：s↦ρ(μ)s。自监督等变损失 L_eq = E_{ℓ,μ}‖E_instr(μ·ℓ) − ρ(μ)E_instr(ℓ)‖²，样本对由**无标签改述/修饰生成**（同义改述、插入/删除修饰词）构造，无需人工对齐。组合外推：ℓ*=μ'·b' 经 ρ 的组合作用映射；若 ρ(μ') 落在已学群元素支撑内则可泛化，否则报「不支持」。

**定义 314（指令-技能接地后验与任务不确定性）** p(s|ℓ,o) ∝ p(ℓ|s)p(s|o)；H_ground=H(S|ℓ,o)。任务级 epistemic：U_task = H_ground + κ·max(0, d_supp(E_skill(s*)) − ρ_comp) + λ_amb·Amb(ℓ)，其中 Amb(ℓ) 为解析歧义度（多个合法解析之间的组合距离）。它与 R69 的 (U_ale,U_epi) 语义正交，单独走 TUR。

**定义 315（能力边界与安全拒答 DFR）** 拒答/降级是一等动作 a_∅：若 U_task>τ_task 且意图澄清也不可行（预算耗尽/不可信），执行 a_∅：冻结任务动作、保持安全姿态、声明未理解，并请求人类接管或给出受支持的最近组合作为**显式保守替代**（在 λ_floor 下执行且标注「非原指令」）。绝不允许「静默外推」。

**定义 316（两级不确定性路由 TUR）** 输入 U_task 与 R69 的 (U_ale,U_epi)：
- U_task>τ_task ⇒ **意图通道**：只允许意图澄清 g_intent 或 a_∅；R69 的一切世界级交互被**挂起**（不是禁止观察，而是禁止据此消耗消歧预算或据此定案）；
- U_task≤τ_task ⇒ **状态通道**：逐指令运行 R69 的 FLUID 全流程。
字典序安全序：拒答 ≻ R68 保守 ≻ R69 消歧增益。

**定义 317（意图澄清动作 ICR）** 扩展 R69 的 𝒜_info 增 g_intent ∈ 候选解析集 𝒞(ℓ)（由指令代数生成的、有限、可组合的候选），问句形式为「你是指 C_i 还是 C_j」。硬约束：候选必须**来自支持集**、不得开放式诱导、单次澄清不得单独定案（需与后续观测或第二次正交澄清一致）。与 R69 的 IBG 共享预算，但意图澄清有优先支取权。

**定义 318（自监督模态标定 SSMC）** 对每个模态 m_k，定义预测自洽分 PSC_k=E_Δ[ℓ_fwd(ξ̄_k, o_{t:t+Δ})]（执行该模态原型后、自监督前向模型对真实未来的预测损失）。若模态权重 ŵ_k 校准良好，则高 ŵ 的模态应有低期望 PSC（可靠性单调）。用无标签 (ŵ_k,PSC_k) 对做保序回归重标定 ŵ'_k=Iso(ŵ_k;PSC)，并定义无标签 ECE 代理 ECE_ssl=Σ_b|acc_b(PSC)−conf_b(ŵ')|。ECE_ssl>τ ⇒ 触发 MCG 等价门，禁用 VoI、退回 R68。

**定义 319（表征坍缩监测 RCS）** 自监督几何指标：有效秩 r_eff=exp(H(σ_i/Σσ))、均匀性 U=log E_{i≠j}e^{−2‖s_i−s_j‖²}、对齐性 A=E‖s_i−s_i^+‖²。若 r_eff<ρ_rank 或 U 低于下界 ⇒ 判定表征坍缩，冻结 SIGMA 的接地与 VoI 决策，退回 R68 纯保守。这是 R69「模式分布不可信」的**上游根因监控**。

**定义 320（指令泛化风险与证书）** 设指令分布 𝒫、组合假设类复杂度 C、有效样本 n_eff、未见修饰子群的传输代价 W_G，则指令泛化风险 R_gen ≤ O(√((C+log(1/δ))/n_eff)) + W_G·Lip(ρ)。证书报告 R̂_gen、技能覆盖 coverage、以及「本次执行所用组合的支持距离」。

**定义 321（组合外推的安全降级）** 对需要未见组合的指令，系统不得认证；必须：(a) 分解到最近受支持组合并请求确认；或 (b) 在 λ_floor 下执行**最保守的受支持变体**并显式披露「这不是原指令」。两种情况都必须写入审计。

**定义 322（指令投毒与干扰集）** ℰ_instr={对抗性指令, 提示注入, 欠定/歧义意图, 自相矛盾指令, 分布外指令, 改述投毒}；ℰ_ssl={无标签流投毒, 技能库污染, 自证偏置诱导}。AIC-SIGMA = AIC-FLUID × ℰ_instr × ℰ_ssl。SSL 数据卫生：鲁棒离群过滤 + 认证干净比例下限 + 分视图训练。

**定义 323（指令级审计 VQAuditor-S）** 审计：接地是否落到受支持组合、澄清候选是否诱导、是否发生静默外推、无标签校准是否自证、技能库更新是否可回溯。结论回灌技能库策展与 TUR 阈值。

**定义 324（证书 J_SIGMA）** J_SIGMA=(J_FLUID, U_task, grounding_map_hash, d_supp, R̂_gen, ECE_ssl, r_eff, refusal_rate, ssl_view_hash, sigma_ver)。Valid ⇔ Valid(J_FLUID) ∧ (U_task≤τ_task ∨ 记录了显式拒答/澄清) ∧ ECE_ssl≤τ_e ∧ r_eff≥ρ_rank ∧ 无静默外推。

**定义 325（自监督在线适应与遗忘防护）** 技能库与接地映射的更新只能异步、离线批、版本化：EMA 目标编码器 + 回放缓冲 + 漂移检测；若更新使 r_eff 下降或 ECE_ssl 上升超过阈值，自动回滚到上一版（OAA）。实时控制路径仍零学习写操作（定义 310-i）。

```python
# IP-264/265 SIG：自监督技能接地（复用 R69 条件编码器作骨干）
class SkillGrounder:
    def __init__(self, trunk, E_instr, rho, skill_lib, rho_comp):
        self.trunk, self.E_instr = trunk, E_instr   # SSL 训练，无标签
        self.rho, self.lib, self.rho_comp = rho, skill_lib, rho_comp

    def support(self, s):
        return min(norm(s - c) for c in self.lib)   # d_supp 到技能流形

    def ground(self, ell, o):
        b  = parse_composition(ell)                 # 基元 × 修饰子程序
        s  = compose(self.rho, b)                   # 修饰子群作用于技能嵌入
        post = bayes_ground(s, self.E_instr, o)     # p(s|ell,o)
        U_task = (entropy(post)
                  + KAPPA * max(0.0, self.support(s) - self.rho_comp)
                  + LAM_AMB * ambiguity(b))
        return post, U_task, b, self.support(s)

# IP-267/268/269 TUR + ICR + DFR：两级字典序路由
def route(M, ell, o, budget):
    post, U_task, b, d = M.grounder.ground(ell, o)
    if U_task > TAU_TASK:                           # 任务身份未确证
        cands = supported_parses(b, M.grounder.lib) # 仅支持集内的候选
        if budget.allow_intent() and len(cands) >= 2:
            g   = make_clarification(cands)         # 有限、非诱导
            ans = M.icr.execute(g)
            post, U_task, b, d = M.grounder.update(post, ans)  # 单次不定案
        if U_task > TAU_TASK:
            M.audit.submit('defer', ell, post, d)
            return M.dfr.freeze_and_declare()       # 拒答/降级
    return ('state', post, b)                       # 任务确证 → R69

# IP-270 SSMC：无标签模态标定（预测自洽性）
def ssmc_calibrate(modes, w, o_future, fwd_model):
    psc = {k: fwd_model.loss(modes[k].proto, o_future) for k in modes}
    w2  = isotonic_regress(w, psc)                  # 高权重 ↔ 低损失
    return w2, ssl_ece(w2, psc)

# IP-271 RCS：表征坍缩监测
def representation_health(Z):
    return effective_rank(Z) >= RHO_RANK and uniformity(Z) >= U_MIN

# IP-276 SIGMA 主闭环（任务确证后逐指令退化 R69）
def SIGMA_round(M, ell, obs):
    if not representation_health(M.ssl.embed(obs)):
        return M.r68_round(obs)                     # 表征坍缩 → R68 纯保守
    post, U_task, b, d = M.grounder.ground(ell, obs)
    if U_task > TAU_TASK:
        g = M.icr.choose(post, b, M.budget)
        if g is not None:
            post, U_task, b, d = M.icr.execute_and_update(g)
        if U_task > TAU_TASK:
            M.audit.submit('defer', ell, post, d)
            return M.dfr.freeze_and_declare()       # 只澄清/拒答，不执行
    w2, ece = M.ssmc.calibrate(M.fluid.modes, M.fluid.w, obs.future, M.fwd)
    if ece > TAU_E:
        return M.r68_round(obs)                     # 自监督校准不过 → R68
    return M.fluid.round(obs, task=b, grounding=post, mode_weights=w2)
```

## 3. 推导

**引理 19（任务身份优先的必要性）** 存在状态 s 使 U_task>0 时，R69 的 VoI-最优世界级交互的期望任务效用为负：它把预算花在按 p(s|ℓ) 加权的**错误任务**的歧义上，期望残差随任务混淆度单调上升。故字典序优先（先任务后世界）不是风格选择，而是 R69 有效性的前提。反例：把「轻放」误读为「放下」时，越精确地消解「放哪」，动作越快越狠、越危险。

**引理 20（无标签校准的自证偏置界）** 设自监督前向模型损失误差 e_f，策略与预测器共享偏置 b_shared。PSC 标定对真实模态可靠性的估计偏差 ≤ 2(‖e_f‖+‖b_shared‖)；当且仅当 b_shared=0（正交视图）时无偏。系：SSMC 必须使用**与策略不同来源的观测视图**（如仅用本体感知预测视觉后果），否则退化为自证；这给出 E306 的可检验假设。

**引理 21（组合泛化的表示充分条件）** 若等变损失 L_eq≤ε 且技能库覆盖全部基元，则对任意受支持修饰子组合，接地误差 ≤ ε·Σ‖ρ(μ_i)‖ + Lip(compose)·W_G；对未见组合，误差额外含群元素传输代价 W_G。系：**指令泛化 = 技能覆盖 × 修饰子等变质量**，两者都可自监督优化、都可审计。

**定理 18（SIGMA 严格包含 FLUID/R68）** 当 U_task≤τ_task 且 SSMC/RCS 门通过时，SIGMA 与 R69 逐指令相同；当 U_task>τ_task 时，SIGMA 只执行澄清/拒答，风险严格不大于任何执行动作。故沿 拒答 ≻ R68 ≻ R69 的安全序，风险单调不增；安全侧永不让步，效率侧在任务确证时完整回收 R69 的 resolution bonus。

**定理 19（路由安全与无突变）** TUR 的通道切换只改变「是否/如何处置不确定性」，不改变安全包络；拒答是安全姿态的保持；意图澄清作为信息动作同受 C-RAS-WM 认证与 IBG 预算约束；表征坍缩触发 R68 退化时，提交/换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变。

## 3. 关键算法伪代码

```python
# IP-264/265/266 SIG：自监督技能接地 + 指令代数
class SkillGrounder:
    def support(self, s): return min(norm(s - c) for c in self.lib)

    def ground(self, ell, o):
        b = parse_composition(ell)                  # 基元 × 修饰子程序
        s = compose(self.rho, b)                    # 修饰子群作用于技能嵌入
        post = bayes_ground(s, self.E_instr, o)     # p(s|ell,o)
        U_task = (entropy(post)
                  + KAPPA * max(0.0, self.support(s) - self.rho_comp)
                  + LAM_AMB * ambiguity(b))
        return post, U_task, b, self.support(s)

# IP-267/268/269 TUR + ICR + DFR：字典序路由
def route(M, ell, o, budget):
    post, U_task, b, d = M.grounder.ground(ell, o)
    if U_task > TAU_TASK:
        cands = supported_parses(b, M.grounder.lib)  # 只取支持集候选
        if budget.allow_intent() and len(cands) >= 2:
            ans = M.icr.execute(make_clarification(cands))
            post, U_task, b, d = M.grounder.update(post, ans)
        if U_task > TAU_TASK:
            M.audit.submit('defer', ell, post, d)
            return M.dfr.freeze_and_declare()        # 拒答/降级
    return ('state', post, b)                        # 任务确证 → R69

# IP-270 SSMC：无标签模态校准（预测自洽性伪标签）
def ssmc_calibrate(modes, w, o_future, fwd_model):
    psc = {k: fwd_model.loss(modes[k].proto, o_future) for k in modes}
    w2  = isotonic_regress(w, psc)                   # 高权重 ↔ 低预测损失
    return w2, ssl_ece(w2, psc)

# IP-271 RCS：表征坍缩监测
def representation_health(Z):
    return effective_rank(Z) >= RHO_RANK and uniformity(Z) >= U_MIN

# IP-276 主闭环（任务确证后逐指令退化 R69）
def SIGMA_round(M, ell, obs):
    if not representation_health(M.ssl.embed(obs)):
        return M.r68_round(obs)                      # 表征坍缩 → R68
    post, U_task, b, d = M.grounder.ground(ell, obs)
    if U_task > TAU_TASK:
        g = M.icr.choose(post, b, M.budget)
        if g is not None:
            post, U_task, b, d = M.icr.execute_and_update(g)
        if U_task > TAU_TASK:
            M.audit.submit('defer', ell, post, d)
            return M.dfr.freeze_and_declare()        # 只澄清/拒答
    w2, ece = M.ssmc.calibrate(M.fluid.modes, M.fluid.w, obs.future, M.fwd)
    if ece > TAU_E:
        return M.r68_round(obs)                      # 无标签校准不过 → R68
    return M.fluid.round(obs, task=b, grounding=post, mode_weights=w2)
```

## 4. 推导

**引理 19（任务身份优先的必要性）** U_task>0 时，R69 的 VoI-最优世界级交互期望任务效用可为负：预算被花在错误任务的歧义上，残差随任务混淆度单调上升。故「先任务后世界」是 R69 有效性的前提，而非风格选择。

**引理 20（无标签校准的自证偏置界）** PSC 标定对真实模态可靠性的估计偏差 ≤ `2(‖e_f‖+‖b_shared‖)`；当且仅当预测器与策略正交（`b_shared=0`）时无偏。系：SSMC 必须用与策略不同来源的观测视图，否则退化为自证。

**引理 21（组合泛化的表示充分条件）** 若 `L_eq≤ε` 且技能库覆盖全部基元，则受支持组合的接地误差 ≤ `ε·Σ‖ρ(μ_i)‖ + Lip(compose)·W_G`；未见组合额外含 `W_G`。系：指令泛化 = 技能覆盖 × 修饰子等变质量，二者皆可自监督优化且可审计。

**定理 18（SIGMA 严格包含 FLUID/R68）** 当 `U_task≤τ_task` 且 SSMC/RCS 门通过时，SIGMA 与 R69 逐指令相同；当 `U_task>τ_task` 时只执行澄清/拒答，风险不大于任何执行动作。沿 拒答 ≻ R68 ≻ R69 安全序风险单调不增；安全不让步，任务确证时完整回收 R69 的 resolution bonus。

**定理 19（路由安全与无突变）** TUR 通道切换只改变不确定性的处置方式、不改变安全包络；拒答保持安全姿态；意图澄清同受 C-RAS-WM 认证与 IBG 预算约束；表征坍缩触发 R68 退化时提交/换装不变式保持 ⇒ 控制连续、无突变。

## 7. 本轮最大风险

**一句话**：SIGMA 的安全与效率都押在「自监督信号无偏且未被污染」上——若前向/预测模型与策略共享盲点（自证）或无标签流被投毒，错误的任务理解会被自监督**自我验证**，从而合法通过所有底层认证并**减少**本该有的澄清；系统不是「问错」，而是「自信地以为自己没问错」，这比 R69 的公开不确定更隐蔽、更危险。

**次级风险与缓解**：指令注入/对抗指令（ℰ_instr + 非诱导澄清 + VQAuditor-S）；无标签流投毒（SSL 数据卫生 + 认证干净比例 + OAA 回滚）；自证偏置（正交视图 + 引理 20 可检验假设 + E306）；组合外推静默越界（定义 321 显式披露 + 拒答门）；实时预算被接地层击穿（嵌入缓存 + 异步 SSMC/RCS）。
