# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「续航能力」×「差异化定位」）

> 第 54 轮把技能组合表征为「动作占用 α_S + 鲁棒性谱 ρ」的双证书，并建立云边闭环。但该体系隐含两个静态假设：**证书发生在满电/热稳态的瞬时切片上**；**技能库被视为同质可替换的能力集合**。本轮把这两个假设打开：续航让证书从「瞬时断言」变成「沿能量轴衰减的过程断言」（H24）；差异化让组合目标从「最大重叠」转为「互补覆盖」，避免技能同质化与组合图爆炸（H25）。核心问题：一个在 t=0、满电、单技能上 sound 的证书，凭什么在 30 分钟任务末端、低电量、差异化技能组合下仍然 sound？

## 0. 直觉与动机

**灵感 1（续航不是电量，而是证书的第四根轴）**
直觉：续航能力不是「跑得久」，而是「能力随能量状态连续退化」的函数。满电时能跳 20cm 的技能，电量 20% 时可能只能跳 12cm；边端算力还会因散热降频，使 `γ_ce` 的映射延迟上升。因此 `ρ`、`α_S`、`A_cert` 都不应是常数，而应成为能量状态 `b∈[0,1]` 与温度 `θ` 的函数：`ρ_S(d; b, θ)`。动作可行性不是二值，而是随 `b` 收缩的「能力包络」。

**灵感 2（续航剖面与任务级能量预算）**
直觉：给技能 S 定义能量剖面 `ε_S(a,b,θ)`＝在电量 b 下执行动作 a 的能耗率，以及耐久视界 `H_S(a; b_0,θ)`＝从 `b_0` 起重复执行 a 直到能力跌破 `ρ_min` 的时长。组合的技能序列必须满足 `Σ E(S_i) ≤ B_task`，且每个中间点 `b_k ≥ b_crit`；否则任务中途证书失效。这样，组合图上的边权从 `c_trans` 扩展为（时间，能量，退化）三维资源。

**灵感 3（差异化定位：从「重叠兼容」到「互补差异化」）**
直觉：第 54 轮用 Jaccard 交并比 `compat` 判断可组合，隐含偏好「动作空间越像越容易组合」。但技能库若全是相似技能，组合图会冗余爆炸，且没有备份多样性。差异化定位把每个技能映射为能力生态位向量 `ν_S = (任务分布, 动作核, 能量档, 鲁棒谱, 定位条件)`，定义差异度 `div(S_i,S_j)=1-cos(ν_i,ν_j)`。组合不仅要求 `compat` 够高以衔接，还要求路径的生态位覆盖 `Cov(ν_path)` 够大以抗单点失效；于是目标从「最短重叠路径」变成「差异化覆盖下的可行路径」。

**灵感 4（差异化不是越不同越好：冗余-覆盖 Pareto）**
直觉：完全差异化的技能可能根本无法衔接；完全同质的技能又没有备份。必须显式区分 **衔接兼容**（动作交集/转换成本，硬约束）与 **功能差异**（生态位覆盖，软目标）。前者决定「能不能接上」，后者决定「接上后是否还有第二条路」。引入 `div` 作为多样性奖励，同时保留一条「安全重叠带」，避免为差异化牺牲 fallback。

**灵感 5（续航-差异化联合证书 J⁺）**
直觉：部署前证书应同时回答三个问题：动作能不能做（`A_cert`）、做了有多鲁棒（`ρ`）、能持续做多久且是否具有不可替代性（`E_cert + D_cert`）。联合证书 `J⁺ = (ρ, A_cert, γ_ce, δ_a, E_cert, D_cert, lease)`：`E_cert` 记录能量起点、耐久视界、热裕度；`D_cert` 记录生态位、差异化覆盖与 fallback 对。证书带「续航租约」：任务时长超过 `H_eff` 或能量跌破 `b_crit` 即失效。

**灵感 6（金字塔再叠「可持续-差异化」层 𝕊 与 𝔻）**
直觉：在 𝕃（鲁棒性）与 𝔸（动作协同）之上叠加：
- `𝕊_0` 能量/热物理极限；
- `𝕊_1` 技能续航剖面与耐久视界；
- `𝔻_1` 技能生态位与差异化矩阵；
- `𝕊𝔻_2` 任务级能量-覆盖联合规划。
跨层证书必须同时携带 `ρ`、`A_cert`、`E_cert`、`D_cert`，形成 **动作-鲁棒-续航-差异四元证书**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（续航剖面与耐久视界）**
设能量状态 `b∈[0,1]`、热状态 `θ`。技能 S 的能量剖面 `ε_S(a,b,θ) ≥ 0` 为执行动作 a 的能耗率；能力包络 `ρ_S(d;b,θ)` 为能量 b 下维度 d 的鲁棒性。耐久视界
```
H_S(a;b_0,θ) = max n·Δt
s.t. b_k = b_0 - Σ_{i<k} ε_S(a,b_i,θ)·Δt ≥ b_crit
     ∧ ρ_S(d;b_k,θ) ≥ ρ_min  ∀d, ∀k≤n
```
若 `n=0` 则 `H_S=0`，表示该动作在当前能量下不可持续。

**定义 122（续航感知动作剖面）**
```
α_S(a;b,θ) = α_S^0(a) · 1[ρ_S(·;b,θ) ≥ ρ_min] · 1[ε_S(a,b,θ) ≤ ε_max]
```
动作 a 在能量 b 下「可用」当且仅当 `α_S(a;b,θ) ≥ θ_cov`。因此动作可行域随能量单调收缩：`b' ≤ b ⇒ supp(α_S(·;b',θ)) ⊆ supp(α_S(·;b,θ))`（在能力包络单调假设下）。

**定义 123（生态位与差异化矩阵）**
技能 S 的生态位向量 `ν_S = (p_S, φ_S, e_S, ρ_S, ℓ_S) ∈ ℝ^d`，其中 `p_S` 为任务分布签名、`φ_S` 为动作核签名、`e_S` 为能量档签名、`ρ_S` 为鲁棒谱签名、`ℓ_S` 为定位条件签名。差异化矩阵
```
D_ij = div(S_i,S_j) = 1 - <ν_i,ν_j> / (||ν_i||·||ν_j||)
```
路径生态位覆盖 `Cov(P) = 1 - ∏_{c∈cells} (1 - coverage_c(P))`，为次模函数。`D_min(P)=min_{i≠j∈P} D_ij` 衡量「最同质的一对」。

**定义 124（续航-差异化组合图）**
在技能组合图 `G_S` 上，边 `(i→j)` 除第 54 轮的 `compat ≥ θ_a`、`c_trans ≤ τ_e` 外，还须满足能量转移可行：
```
b_j = b_i - E(S_i; b_i, θ) ≥ b_crit  ∧  H_{S_i}(b_i,θ) ≥ h_min
```
边权为向量 `w_ij = (c_trans, E(S_i), -λ_div·(D_ij - θ_div)_+)`。组合问题变为 **带能量、时间、覆盖三重资源的约束最短路（RCSP）**。

**定义 125（续航租约）**
设任务时长 `T_task`，能量估计 `b̂` 与误差上界 `δ_b`。有效耐久视界
```
H_eff = min( H_chain, (b̂ - δ_b - b_crit)/P_avg, H_thermal )
```
证书新鲜度 `lease = exp(-T_task/H_eff)`。仅当 `T_task ≤ H_eff` 且 `lease ≥ F_min` 时证书在任务全程有效；否则触发 `re-certify` 或能量感知重规划。

**定义 126（续航-差异化联合证书 J⁺）**
```
J⁺ = (ρ, A_cert, E_cert, D_cert, γ_ce, δ_a, evidence, lease)
E_cert = (b_0, H_chain, θ, ε_profile, thermal_margin)
D_cert = (ν_path, D_min, Cov_path, fallback_pairs)
```
部署条件：
```
dom_J(T)=in  ∧  δ_a ≤ Θ_a  ∧  T_task ≤ H_eff
∧ Cov_path ≥ θ_cov  ∧  (D_min ≥ θ_div ∨ fallback_pairs ≠ ∅)
```
即：动作对齐、能量可持续、生态位覆盖充分，且要么足够差异化，要么保留显式 fallback。

## 2. 关键算法 伪代码

### IP-121 EPE（Endurance Profile Estimator）

```python
def endurance_profile(skill, A, b_grid, theta_grid, battery_model, sim):
    eps, H = {}, {}
    for b0 in b_grid:
        for th in theta_grid:
            for a in A:
                b, n = b0, 0
                samples = []
                while b >= b_crit:
                    rho = sim.robustness(skill, a, b, th)
                    if min(rho.values()) < rho_min:
                        break
                    e = battery_model.energy_rate(skill, a, b, th)
                    samples.append(e)
                    b -= e * skill.dt
                    n += 1
                # 保序回归 + 保守下界，避免非单调采样高估续航
                eps[(a, b0, th)] = isotonic_decreasing(samples)
                H[(a, b0, th)] = conservative_lower(n * skill.dt)
    return EnduranceCert(eps, H, theta_grid, margin=delta_e)
```

### IP-122 EAC（Endurance-Aware Composition）

```python
def endurance_aware_compose(G, task, B_task, b0, theta, cov_min, lambda_div):
    open_set = PriorityQueue()
    open_set.push(Label(node='root', b=b0, t=0.0, cost=0.0, cover=frozenset(), path=[]))
    labels = {'root': [open_set.peek()]}
    while open_set:
        lab = open_set.pop()
        if lab.node == task.goal:
            if lab.b >= b_crit and coverage(lab.cover) >= cov_min:
                return ('ok', lab.path, lab)
            continue
        for (u, v, edge) in G.out_edges(lab.node):
            if edge.compat < theta_a or edge.c_trans > tau_e:
                continue
            e_need = energy_estimate(edge.skill, lab.b, theta)
            b_next = lab.b - e_need
            if b_next < b_crit:
                continue
            if H_edge(edge.skill, lab.b, theta) < edge.duration:
                continue
            gain = diversity_gain(lab.cover, niche_cells(v))
            new = Label(v, b_next, lab.t + edge.duration,
                        lab.cost + edge.c_trans + e_need - lambda_div * gain,
                        lab.cover | niche_cells(v), lab.path + [v])
            if any(dominates(old, new) for old in labels.get(v, [])):
                continue
            labels[v] = [old for old in labels.get(v, []) if not dominates(new, old)]
            labels[v].append(new)
            open_set.push(new)
    return ('infeasible', explain_energy_gap(labels, task))
```

### IP-123 DNP（Differentiated Niche Positioning）

```python
def build_niche(skills, task_dist, epsilon, rho, localizability):
    nu = {}
    for s in skills:
        nu[s.id] = normalize(concat([
            task_signature(s, task_dist),
            action_kernel(s.alpha),
            energy_signature(s.epsilon),
            robustness_signature(s.rho),
            localization_signature(localizability(s))
        ]))
    D = 1.0 - cosine_matrix(nu)          # 对称差异化矩阵
    return nu, D

def select_portfolio(skills, budget, cov_min, theta_div, theta_fb):
    P = greedy_submodular(skills, budget, cov_min)   # 覆盖优先
    P = local_swap(P, objective=lambda Q: coverage(Q) - cost(Q))
    front = pareto_front(P, [coverage, energy_cost, -D_min])
    for Q in front:
        if D_min(Q) >= theta_div:
            return ('ok', Q, 'differentiated')
        if has_fallback_pair(Q, D, theta_fb):
            return ('ok', Q, 'fallback_overlap')
    return ('reject', 'homogeneous_no_fallback', D_min(P))
```

### IP-124 SLC（Sustainability Lease Certificate）

```python
def sustainability_lease(E_cert, T_task, b_hat, delta_b, theta, F_min=0.8):
    b_worst = max(0.0, b_hat - delta_b)
    H_eff = min(
        E_cert.H_chain,
        (b_worst - b_crit) / max(E_cert.avg_power, eps_floor),
        thermal_horizon(theta, E_cert.thermal_margin)
    )
    if H_eff < T_task:
        return ('reject', 'endurance_shortfall', H_eff, T_task)
    lease = exp(-T_task / max(H_eff, eps_floor))
    if lease < F_min:
        return ('reject', 'lease_expired', lease)
    return ('ok', Lease(H_eff, lease, recheck_at=0.8 * H_eff))
```

### IP-125 EDR（Energy-aware Diagnostic Replanning）

```python
def energy_diagnose_replan(sim, P_e, b_hat, theta, task):
    b = b_hat
    for (s, a_e, rho_e) in P_e:
        exp = explain_failure(sim.run(s, a_e, b, theta), sim)
        if exp.type in ('voltage_sag', 'thermal_derate', 'torque_limit'):
            patch = repair_action(a_e, exp)          # 收缩动作 / 降速 / 间歇
            if H_edge(s, b, theta) < task.remaining:
                patch = interleave_rest(patch, cool_or_charge=True)
            reroute = energy_aware_reroute(P_e, task, b, exp.cost)
            return ('replan', exp, patch, reroute)
        b -= sim.energy_used(s, a_e, b, theta)
    return ('ok', P_e)
```

### IP-126 UTC（Unified Tetra Certificate）

```python
def unified_tetra_certificate(skill_seq, J54, task, b0, theta,
                              delta_a_budget, delta_b, cov_min, theta_div):
    E_cert = aggregate_endurance(skill_seq, b0, theta)
    D_cert = portfolio_differentiation(skill_seq, task.dist, J54.rho)
    if E_cert.H_chain < task.duration:
        return ('reject', 'endurance_fail', E_cert)
    if D_cert.Cov_path < cov_min:
        return ('reject', 'coverage_fail', D_cert)
    if D_cert.D_min < theta_div and not D_cert.fallback_pairs:
        return ('reject', 'homogeneous_no_fallback', D_cert)
    lease = sustainability_lease(E_cert, task.duration, b0, delta_b, theta)
    if lease.status != 'ok':
        return ('reject', lease.reason, lease)
    return ('ok', TetraCert(
        rho=J54.rho, A_cert=J54.A_cert, E_cert=E_cert, D_cert=D_cert,
        gamma_ce=J54.gamma_ce, delta_a=J54.delta_a, lease=lease,
        evidence=J54.evidence + [('energy_profile', E_cert), ('niche', D_cert)]))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| EPE | O(|S|·|A|·|B|·|Θ|·H_max/Δt) | O(|S|·|A|·|B|·|Θ|) | 能量采样覆盖、保序单调、保守下界 |
| EAC | O(|E|·|B|·|C|·log(...))（标号支配剪枝后） | O(|V|·|B|·|C|) | 资源非负、支配关系 sound |
| DNP | O(|S|²·d + |S|·|C|·iter) | O(|S|²+|C|) | 生态位嵌入稳定、覆盖次模 |
| SLC | O(|P|+|Θ|) | O(1) | 能量误差上界、热裕度保守 |
| EDR | O(|P|·|A|) | O(|P|) | Explain 根因可归因 |
| UTC | O(|S|·(|A|+|B|+|C|)) | O(|S|·d) | 四元条件联合 sound |

**正确性定理（Endurance-Differentiation Composition Soundness）**
假设第 54 轮 (A22)–(A28) 成立；并新增：
- **(A29)** `ε_S` 与 `H_S` 由结构化负载测试校准，且在 `b` 上保序、取保守下界；
- **(A30)** 能量观测误差 `|b̂-b| ≤ δ_b`，热状态误差 `|θ̂-θ| ≤ δ_θ`；
- **(A31)** 生态位嵌入 `φ` 满足 `||φ(S)-φ(S')|| ≤ L_φ·d_S`，且 `Cov(·)` 为次模；
- **(A32)** 重认证/Explain 回传延迟 `≤ τ_lease`，且 fallback 对的动作重叠 `≥ θ_fb`。

则任务成功概率下界为：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a > Θ_a)
            - P(b_true < b_crit on path)
            - P(Cov_path < θ_cov)
            - P(D_min < θ_div ∧ fallback_pairs = ∅)
```
其中最后三项分别由续航租约、差异化覆盖、fallback 冗余各自否决；四项为「证书否决事件」的并集界。关键：**续航与差异化不是附加指标，而是与鲁棒性同级的否决条件**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 能量/热模型非单调、耦合强 | 高 | 保序回归 + 保守下界 + 在线电池观测器 |
| 差异化过度剪枝导致无 fallback | 高 | 安全重叠带 + Pareto 前沿 + 显式 fallback 对 |
| RCSP 状态（能量×时间×覆盖）爆炸 | 中 | 标号支配剪枝 + 能量离散化 + 可采纳启发式 |

| 租约抖动与重认证风暴 | 中 | 迟滞 + 最小租约 + 批量重认证 |

## 6. 本轮最大风险

**一句话**：续航-差异化把证书从静态双证书升级为「沿能量轴衰减、沿生态位互补」的四元证书，但其 soundness 同时依赖能量/热模型的保守单调、生态位嵌入的稳定、以及租约到期重认证的及时；一旦电量估计漂移或差异化过度剪枝，系统会在任务末段同时失去能力裕度与 fallback 冗余，出现「证书仍有效但机器人已经做不动、也无人可替换」的复合失效，因此必须以 **能量观测器 + 差异化 Pareto 而非单点最优 + 强制 fallback 重叠带** 三重护栏，宁可保留冗余，不把续航末端与差异化覆盖的乐观估计当作部署前提。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（EPE×EAC×DNP×SLC×EDR×UTC）

> 承接第 54 轮产物 v31。本轮在「动作-鲁棒性双证书 + 云边闭环」之上，增加 **续航剖面、能量约束组合、差异化生态位、续航租约、能量感知重规划、四元联合证书** 六个算子：

> - **EDR（Energy-aware Diagnostic Replanning）**：Explain 根因驱动的能量重规划；
> - **UTC（Unified Tetra Certificate）**：`ρ × A_cert × E_cert × D_cert` 四元联合证书。

### 0.1 与既有工作的差异化定位

| 维度 | 常规能耗规划 | v31 双证书 | 本轮 v32 |
|---|---|---|---|
| 能量 | 作为成本项，事后规划 | 不建模 | 作为**证书轴**，能力包络随 `b` 收缩 |
| 技能库 | 同质可替换 | 动作交集兼容 | **生态位差异化** + fallback 冗余约束 |
| 证书时效 | 无 | 静态快照 | **续航租约**，到期重认证 |
| 失败解释 | 能量不足即停机 | 动作/鲁棒根因 | 电压/热/扭矩根因 → 动作修补或重路由 |

**一句话差异化**：别人把电量当「预算」，我们把电量当「证书的定义域」；别人把技能多样性当「采样技巧」，我们把差异化当「可验证的部署前提」。

## 1. 符号体系增量（新增定义 121–126）

## 2. 关键算法 伪代码

### IP-121 EPE

```python
def endurance_profile(skill, A, b_grid, theta_grid, battery_model, sim,
                      b_crit, rho_min, delta_e):
    eps, H = {}, {}
    for b0 in b_grid:
        for th in theta_grid:
            for a in A:
                b, n, samples = b0, 0, []
                while b >= b_crit:
                    rho = sim.robustness(skill, a, b, th)
                    if min(rho.values()) < rho_min:
                        break
                    e = battery_model.energy_rate(skill, a, b, th)
                    samples.append(e)
                    b -= e * skill.dt
                    n += 1
                eps[(a, b0, th)] = isotonic_decreasing(samples)
                H[(a, b0, th)] = conservative_lower(n * skill.dt, delta_e)
    return EnduranceCert(eps, H, b_grid, theta_grid, b_crit, margin=delta_e)
```

### IP-122 EAC

```python
def endurance_aware_compose(G, task, B_task, b0, theta, cov_min, lambda_div):
    open_set = PriorityQueue()
    root = Label(node='root', b=b0, t=0.0, cost=0.0, cover=frozenset(), path=[])
    open_set.push(root)
    labels = {'root': [root]}
    while open_set:
        lab = open_set.pop()
        if lab.node == task.goal:
            if lab.b >= b_crit and coverage(lab.cover) >= cov_min:
                return ('ok', lab.path, lab)
            continue
        for (u, v, edge) in G.out_edges(lab.node):
            if edge.compat < theta_a or edge.c_trans > tau_e:
                continue
            e_need = energy_estimate(edge.skill, lab.b, theta)
            b_next = lab.b - e_need
            if b_next < b_crit:
                continue
            if H_edge(edge.skill, lab.b, theta) < edge.duration:
                continue
            gain = diversity_gain(lab.cover, niche_cells(v))
            new = Label(v, b_next, lab.t + edge.duration,
                        lab.cost + edge.c_trans + e_need - lambda_div * gain,
                        lab.cover | niche_cells(v), lab.path + [v])
            if any(dominates(old, new) for old in labels.get(v, [])):
                continue
            labels[v] = [old for old in labels.get(v, []) if not dominates(new, old)]
            labels[v].append(new)
            open_set.push(new)
    return ('infeasible', explain_energy_gap(labels, task))
```

### IP-123 DNP

```python
def build_niche(skills, task_dist, localizability):
    nu = {}
    for s in skills:
        nu[s.id] = normalize(concat([
            task_signature(s, task_dist),
            action_kernel(s.alpha),
            energy_signature(s.epsilon),
            robustness_signature(s.rho),
            localization_signature(localizability(s))
        ]))
    D = 1.0 - cosine_matrix(nu)
    return nu, D

def select_portfolio(skills, budget, cov_min, theta_div, theta_fb):
    P = greedy_submodular(skills, budget, cov_min)
    P = local_swap(P, objective=lambda Q: coverage(Q) - cost(Q))
    front = pareto_front(P, [coverage, energy_cost, -D_min])
    for Q in front:
        if D_min(Q) >= theta_div:
            return ('ok', Q, 'differentiated')
        if has_fallback_pair(Q, D, theta_fb):
            return ('ok', Q, 'fallback_overlap')
    return ('reject', 'homogeneous_no_fallback', D_min(P))
```

### IP-124 SLC

```python
def sustainability_lease(E_cert, T_task, b_hat, delta_b, theta, F_min=0.8):
    b_worst = max(0.0, b_hat - delta_b)
    H_eff = min(
        E_cert.H_chain,
        (b_worst - b_crit) / max(E_cert.avg_power, eps_floor),
        thermal_horizon(theta, E_cert.thermal_margin)
    )
    if H_eff < T_task:
        return ('reject', 'endurance_shortfall', H_eff, T_task)
    lease = exp(-T_task / max(H_eff, eps_floor))
    if lease < F_min:
        return ('reject', 'lease_expired', lease)
    return ('ok', Lease(H_eff, lease, recheck_at=0.8 * H_eff))
```

### IP-125 EDR

```python
def energy_diagnose_replan(sim, P_e, b_hat, theta, task):
    b = b_hat
    for (s, a_e, rho_e) in P_e:
        exp = explain_failure(sim.run(s, a_e, b, theta), sim)
        if exp.type in ('voltage_sag', 'thermal_derate', 'torque_limit'):
            patch = repair_action(a_e, exp)
            if H_edge(s, b, theta) < task.remaining:
                patch = interleave_rest(patch, cool_or_charge=True)
            reroute = energy_aware_reroute(P_e, task, b, exp.cost)
            return ('replan', exp, patch, reroute)
        b -= sim.energy_used(s, a_e, b, theta)
    return ('ok', P_e)
```

### IP-126 UTC

```python
def unified_tetra_certificate(skill_seq, J54, task, b0, theta,
                              delta_a_budget, delta_b, cov_min, theta_div):
    E_cert = aggregate_endurance(skill_seq, b0, theta)
    D_cert = portfolio_differentiation(skill_seq, task.dist, J54.rho)
    if E_cert.H_chain < task.duration:
        return ('reject', 'endurance_fail', E_cert)
    if D_cert.Cov_path < cov_min:
        return ('reject', 'coverage_fail', D_cert)
    if D_cert.D_min < theta_div and not D_cert.fallback_pairs:
        return ('reject', 'homogeneous_no_fallback', D_cert)
    lease = sustainability_lease(E_cert, task.duration, b0, delta_b, theta)
    if lease.status != 'ok':
        return ('reject', lease.reason, lease)
    return ('ok', TetraCert(
        rho=J54.rho, A_cert=J54.A_cert, E_cert=E_cert, D_cert=D_cert,
        gamma_ce=J54.gamma_ce, delta_a=J54.delta_a, lease=lease,
        evidence=J54.evidence + [('energy_profile', E_cert), ('niche', D_cert)]))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| EPE | O(|S|·|A|·|B|·|Θ|·H_max/Δt) | O(|S|·|A|·|B|·|Θ|) | 采样覆盖、保序单调、保守下界 |
| EAC | O(|E|·|B|·|C|·log|V|) 剪枝后 | O(|V|·|B|·|C|) | 资源非负、支配 sound、路径可行 |
| DNP | O(|S|²·d + |S|·|C|·iter) | O(|S|²+|C|) | 嵌入稳定、覆盖次模、Pareto 完整 |
| SLC | O(|P|+|Θ|) | O(1) | 能量误差上界、热裕度保守、租约单调 |
| EDR | O(|P|·|A|) | O(|P|) | 根因可归因、修补保持动作可行 |
| UTC | O(|S|·(|A|+|B|+|C|)) | O(|S|·d) | 四元否决条件联合 sound |

**正确性定理（Endurance-Differentiation Composition Soundness）**
假设第 54 轮 (A22)–(A28) 成立；新增：
- **(A29)** `ε_S`、`H_S` 由结构化负载测试校准，在 `b` 上保序且取保守下界；
- **(A30)** `|b̂-b| ≤ δ_b`，`|θ̂-θ| ≤ δ_θ`；
- **(A31)** 生态位嵌入 `φ` 满足 `||φ(S)-φ(S')|| ≤ L_φ·d_S`，`Cov(·)` 次模；
- **(A32)** 重认证/Explain 延迟 `≤ τ_lease`，fallback 对动作重叠 `≥ θ_fb`。

则：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a > Θ_a)
            - P(b_true < b_crit on path)
            - P(Cov_path < θ_cov)
            - P(D_min < θ_div ∧ fallback_pairs = ∅)
```
四项否决事件取并集界；**续航与差异化与鲁棒性同级，不是软指标**。

## 5. 本轮最大风险

**一句话**：续航-差异化把证书从静态双证书升级为「沿能量轴衰减、沿生态位互补」的四元证书，但其 soundness 同时依赖能量/热模型的保守单调、生态位嵌入的稳定、以及租约到期重认证的及时；一旦电量估计漂移或差异化过度剪枝，系统会在任务末段同时失去能力裕度与 fallback 冗余，出现「证书仍有效但机器人已经做不动、也无人可替换」的复合失效，因此必须以 **能量观测器 + 差异化 Pareto 而非单点最优 + 强制 fallback 重叠带** 三重护栏，宁可保留冗余，不把续航末端与差异化覆盖的乐观估计当作部署前提。
