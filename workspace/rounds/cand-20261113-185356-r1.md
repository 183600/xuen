# 第 69 轮（承接第 68 轮「CALM-RAS 标定感知风险自适应闭环」IP-243~252；本轮灵感：「抗干扰」×「四足机器人」）

> 第 68 轮把「标定」升级为在线潜变量，用自监督与单模型多任务补齐了计量层，但它的自陈风险是一句判决书：**若真实故障落在标定带宽之内，COF 会把它当漂移「标好」——标定能力越强，缓变故障越隐形。** 这不是实现缺陷，而是「被动观测」范式的结构性盲区：只靠残差流，扰动与参数漂移在数学上就是同一个东西（ρ = YΔθ + w），没有外部激励就无法把它们分开。
>
> 本轮的两个灵感恰好提供了破局的两个物理事实：
> 1. **四足机器人**：它的接触时序 α_i(t) 是一个已知的开关信号——落地腿是天然的运动学约束（腿式里程计），腾空腿则完全不提供约束。这既给了「何时可标定」一个可观测性门控，也给了「外扰 vs 参数」一个结构分解，还让「步态多样性」成为免费的跨条件实验设计。
> 2. **抗干扰**：抗干扰的正确姿势不是「把扰动估出来抵消掉」就完了——ESO/扰动观测器本身就是一个吸收器，会把慢故障一起吞掉。真正的抗干扰必须同时是**主动辨识**：用机器人自己的驱动器注入已知激励（持久激励 PE），让参数在残差里留下可分指纹；同时，被抵消的扰动必须原样上报，否则「抗干扰」会退化成「反检测」。
>
> 核心命题：**把「标定」从被动观测升级为「主动辨识 + 接触门控 + 双重用途扰动估计」——同一份扰动估计既用于低层物理抵消（抗干扰），又用于高层风险归因（抗误判）；用四足的接触时序与步态多样性把「外扰 / 地形 / 传感干扰 / 参数漂移」四分——AIR-RAS（Active Interference-Rejecting Risk-Adaptive System）。**
>
> 一句话定位：R68 问「我的测量还准吗」，R69 问「**这个不准，是外面推了我，还是我自己坏了**」——并且用一次安全探针把答案问出来。

## 0. 直觉与动机

**灵感 1（四足 → 接触时序是免费的开关观测器）**
直觉：四足运动是「间歇接触」的：每条腿在 stance 相位是地面的一条运动学约束，在 swing 相位什么都不是。传统标定把所有数据一视同仁，等于把「有约束的高信息样本」和「无约束的纯噪声样本」混在一起回归。更关键的是，接触力 f_i 只在 stance 相位可观测：一旦接触时序估错（漏检触地），扰动观测器会把地面反力当成「外部推力」去抵消——**抗干扰系统会主动制造失稳**。所以接触时序必须是第一等公民：它既是标定的门控 σ_contact，也是扰动估计的开关，还是风险层的独立不确定源 κ_contact。

**灵感 2（抗干扰 → 扰动观测器是双刃剑，也是双重用途）**
直觉：ADRC/ESO 的扩展状态 z_{n+1} 把「所有未建模的东西」压成一个总扰动并抵消，工程上极其有效；但它和 R68 的 COF 是同一类吸收器：**只要扰动足够慢，它就会被当成总扰动的一部分消化掉，包括真正的缓变故障。** 破局点在于用途分离：ESO 只负责**快干扰的物理抵消**（高频、瞬态、可逆），参数辨识只负责**慢漂移的显式建模**（低频、持续、不可逆），两者用频带 + 激励条件分开。并且，被抵消的扰动量本身是有价值的证据——不能「抵消即遗忘」，必须原样上报风险层（reject-then-report 不变式）。

**灵感 3（抗干扰 → 主动激励是唯一能打破混淆的物理手段）**
直觉：被动观测下，残差 ρ = Y(q,q̇,q̈)Δθ + w 中 Δθ（参数漂移）与 w（外扰）在数学上不可分，除非回归矩阵 Y 在 Δθ 的方向上有能量（持久激励 PE）。平地匀速 trot 时 Y 的某些列几乎为零（足端刚度、某些惯量方向、执行器增益），这些方向就是**盲子空间**——R68 的缓变故障正躲在这里。解决办法不是更强的滤波器，而是**让机器人问一个安全的问题**：在低风险相位注入小幅、多频、已知的探针 τ_probe，或主动选择地形/步态制造自然激励（terrain-as-excitation），把盲子空间填满。辨识理论给得出硬保证：PE 成立 ⇒ 参数误差 ≤ ‖ρ‖/√λ_min(YᵀY)。

**灵感 4（四足 → 步态多样性是天然的多条件实验设计）**
直觉：同一台机器人在 trot / pace / bound / 不同地形下，参数漂移 Δθ 是**不变的**，而地形扰动与接触噪声是**随条件变的**。这等价于做了一次多环境对齐：对条件取平均，不变的成分留下来（参数），变的成分被平均掉（扰动）。这把 R68 的「单流残差」升级为「跨步态残差张量」，用不变性做无标签的因果分离——不需要任何外扰标签。

**灵感 5（合流 → AIR-RAS 七组件与对 R68 风险的对症下药）**
1. **LIP Legged Interference Prior**：浮动基动力学 + 接触时序 + 每腿回归器 Y_i；
2. **CDO Contact-consistent Disturbance Observer**：动量观测器估计每腿外扰，接触门控；
3. **ESO Extended State Observer**：关节级总扰动，快干扰低层抵消（ADRC）；
4. **PEW Persistent-Excitation Watchdog**：在线监控 μ = λ_min(YᵀY)，检测激励赤字；
5. **AEG Active Excitation Governor**：风险预算约束下的最小探针 / 步态选择（含 terrain-as-excitation）；
6. **DDA Dual-use Disturbance Attribution**：同一扰动估计，一路抵消、一路归因；四分 {外推, 地形, 传感干扰, 参数漂移}；
7. **CG-COF Contact-Gated Calibration Filter**：R68 COF 升级——接触门控 + PE 门控 + 盲子空间冻结（不可辨识就绝不吸收）。
- 对 R68 风险：**盲子空间冻结**把「标定吸收缓变故障」从默认行为改成「只有在 PE 证明可辨识时才允许吸收」；
- 对 R66/R67 风险：外扰不再被误报成传感故障（E272 误报进一步下降），WM 前瞻在强扰动下由 CDO 提供前馈而非瞎猜；
- 新增统一纪律：**λ_floor^AIR = max(0.6, 0.8·1[PE 赤字 ∨ 接触不确定 ∨ U_cal 高])**，且探针期间风险阈值临时收紧。

## 1. 形式化定义（增量：定义 293–306）

**定义 293（AIR-RAS 总览）** AIR-RAS = (LIP, CDO, ESO, PEW, AEG, DDA, CG-COF, RAS††)。三条新不变式：
(i) **reject-then-report**：被低层抵消的扰动估计 ŵ_ext 必须原样写入 AuditBuf，抵消不得减少归因证据；
(ii) **blind-subspace freeze**：回归矩阵不可辨识方向上的参数漂移禁止被标定吸收，一律冻结并按最坏情况归因；
(iii) **probe safety**：主动探针只在风险预算内、且满足稳定裕度时注入；探针期间 λ_risk 下限抬升。

**定义 294（四足浮动基模型与接触时序）**
M(q)q̈ + C(q,q̇)q̇ + g(q) = Sᵀτ + Σ_i α_i(t)·J_iᵀ(q)·f_i + w_ext，
q ∈ ℝ^{n+6}，α_i(t) ∈ {0,1} 为足 i 的接触时序（足端力、关节力矩、IMU 融合估计）。stance 相位满足 J_i q̈ + J̇_i q̇ = 0（运动学约束）；swing 相位无约束。接触不确定度 κ_contact(t) 由 α_i 的后验熵给出。

**定义 295（接触一致动量观测器 CDO）**
广义动量 p = M(q)q̇，其导数为 ṗ = Sᵀτ − Cq̇ − g + Σ_i α_i J_iᵀ f_i + w_ext。定义残差
ṙ_o = −K_o r_o + K_o·(ṗ − ∫[Sᵀτ − Cq̇ − g + Σ_i α_i J_iᵀ f̂_i] dτ − p(0))，
则 r_o → w_ext（一阶收敛，带宽 K_o）。逐腿解出 f̂_i，聚合外扰 ŵ_ext = Σ_i α_i J_iᵀ f̂_i。**门控语义**：α_i=0 的腿不进入观测器，否则地面反力会被误当外扰。

**定义 296（回归形式与盲子空间）**
关节力矩回归：τ = Y(q,q̇,q̈)θ + Jᵀf + ε，θ ∈ ℝ^{n_θ}（连杆质量/惯量/质心、摩擦、执行器增益、足端刚度）。令参数漂移 Δθ 与外部扰动 w 同时存在，残差
ρ = YΔθ + w + ε。
在窗口 T 上堆叠 Y_T = [Y_t]_{t∈T}。**盲子空间** B = null(Y_T)；**PE 裕度** μ = λ_min(Y_TᵀY_T)；dim B = n_θ − rank(Y_T)。

**定义 297（持久激励看门狗 PEW）**
μ(t) = λ_min(∫_{t−T}^{t} Y(τ)ᵀY(τ) dτ)。若 μ(t) < μ_PE，判为**激励赤字**，赤字方向 V_def = {v : Y_T v ≈ 0}。PEW 输出 (μ, dim B, V_def)，并驱动 AEG 与 CG-COF。

**定义 298（主动激励调速器 AEG）**
探针 τ_probe = Σ_k A_k sin(ω_k t)·v_k，其中 v_k 取 V_def 的特征向量、ω_k ∈ [ω_min, ω_max] 且避开步态谐波。安全约束：‖τ_probe‖ ≤ A_max(risk_budget)，仅在 stance 且任务风险 < B_task 时注入。若自然地形已提供足够激励（terrain-as-excitation，μ ≥ μ_PE），则 A_k = 0，**不注入任何人工探针**。

**定义 299（跨条件不变性 DDA）**
在条件集 C（步态 × 地形 × 速度）上得到残差张量 {ρ_c}。不变参数估计
Δθ̂ = argmin_Δθ Σ_{c∈C} ‖ρ_c − Y_c Δθ‖²，
逐条件扰动 ŵ_c = ρ_c − Y_c Δθ̂。参数分量跨条件不变，扰动分量随条件变化——这是无标签的因果分离。四分归因后验 P(cause | ρ, α, μ, c) 定义在 {ext, terrain, sensor, param-fault} 上，似然由时域签名（瞬态/持续）、步态不变性、接触一致性、频带四个特征给出。

**定义 300（双重用途扰动估计）**
同一 ŵ_ext 两用：低层抵消 u_reject = −ŵ_ext（前馈/ADRC 补偿）；高层证据 e_attrib = ρ + ŵ_ext（原始残差 + 被抵消量）。**reject-then-report 不变式**保证：抵消只改变物理，不改变可观测性。

**定义 301（CG-COF 接触/PE 门控标定滤波）**
R68 COF 的升级：仅当 α_i=1、σ_stat 高、且 μ > μ_PE 时才执行 update；否则冻结。若漂移方向落在 B 内，标记 **unidentifiable**，禁止吸收，该方向 U = ∞。速率限制器与标定红线（定义 276-ii）保留。

**定义 302（λ_floor^AIR 与探针安全）**
λ_floor^AIR = max(0.6, 0.8·1[μ < μ_PE ∨ κ_contact > τ_contact ∨ U_cal > τ_cal])。探针期间 λ_risk ← min(1, λ_risk + Δ_probe)，且 k 前缀收缩至 k_probe = max(1, ⌊k·(1−β_probe)⌋)。

**定义 303（AIR 干扰集）** ℰ_AIR = ℰ_CALM × ℰ_dist × ℰ_contact × ℰ_pe；ℰ_dist = {外推、足滑、地形突变、传感 EMI}；ℰ_contact = {触地漏检、接触时序抖动}；ℰ_pe = {激励赤字、探针诱发失稳、探针被误判为外扰}。

**定义 304（J_AIR 证书）**
J_AIR = (J_CALM, contact_hash, μ, dim B, probe_budget_used, dda_verdict, air_ver)。
Valid ⇔ Valid(J_CALM) ∧ [μ ≥ μ_PE^hard ∨ (B 已冻结且按最坏情况归因)] ∧ reject-then-report 已入 AuditBuf。

**定义 305（管线）**
离线：富激励系统辨识（多步态/多地形）→ 先验 θ0 与 μ 标定。在线双环：1 kHz 低层环做 CDO + ESO + 抵消；100–200 Hz 风险环做 PEW → AEG → CG-COF → DDA → RAS††。探针由 AEG 在风险环裁决、低层环执行。

**定义 306（四分归因的顺序性）**
先接触门控（排除 swing 伪残差）→ 再 PE 门控（判断参数方向是否可辨识）→ 再跨条件分离（不变 vs 变化）→ 最后落入 R68 的 CFA 后验。顺序性保证：任何前置门控失败都只能导向保守，不能导向放宽。

```python
# IP-253/294 LIP：四足接触时序 + 浮动基先验
class LeggedInterferencePrior:
    def contact_schedule(self, foot_force, tau, imu):
        alpha = fuse_contact(foot_force, tau, imu)      # 每腿 {0,1} + 后验
        kappa = entropy(alpha)
        return alpha, kappa

    def regressor(self, q, dq, ddq):
        return Y_of(q, dq, ddq)                          # τ = Yθ + Jᵀf + ε


# IP-254/295 CDO：接触一致动量观测器（1 kHz）
class ContactDisturbanceObserver:
    def __init__(self, K_o):
        self.K_o, self.p = K_o, None

    def step(self, q, dq, tau, alpha, f_hat):
        p = mass_matrix(q) @ dq
        if self.p is None: self.p = p
        gen = S_T @ tau - coriolis(q, dq) @ dq - gravity(q)
        gen += sum(alpha[i] * J_i(q).T @ f_hat[i] for i in range(4))
        self.r = self.r + self.K_o * ((p - self.p) - self.r)
        self.p = p
        w_hat = self.r                                    # → w_ext
        return w_hat


# IP-255/296 ESO：关节级总扰动，只抵快扰
class JointESO:
    def step(self, q, dq, tau):
        e = q - self.z1
        self.z1 += self.dt * (self.z2 + 3 * self.wo * e)
        self.z2 += self.dt * (self.z3 + 3 * self.wo**2 * e + b0 * tau)
        self.z3 += self.dt * (self.wo**3 * e)
        return self.z3                                    # 快干扰补偿


# IP-256/297 PEW：持久激励看门狗
class PersistentExcitationWatchdog:
    def step(self, Y_window):
        G = Y_window.T @ Y_window
        lam, V = eigh(G)
        mu, B_dim = lam.min(), int((lam < MU_PE).sum())
        return mu, B_dim, V[:, lam < MU_PE]


# IP-257/298 AEG：风险预算下的最小探针
class ActiveExcitationGovernor:
    def probe(self, V_def, risk_budget, natural_mu, alpha):
        if natural_mu >= MU_PE or not alpha.any():
            return zeros(n_theta)                         # terrain-as-excitation，不注入
        A = min(A_MAX, kappa * sqrt(risk_budget))
        return sum(A * sin(w_k * t) * V_def[:, k] for k in range(V_def.shape[1]))


# IP-258/299 DDA：跨条件不变性四分归因
class DualUseDisturbanceAttribution:
    def attribute(self, rho_by_cond, Y_by_cond, alpha, mu):
        dtheta = argmin(sum(norm(rho - Y @ dtheta)**2
                             for rho, Y in zip(rho_by_cond, Y_by_cond)))
        w_by_cond = [rho - Y @ dtheta for rho, Y in zip(rho_by_cond, Y_by_cond)]
        feats = signature(rho_by_cond, w_by_cond, alpha, mu)   # 瞬态/不变/接触/频带
        return softmax(classifier(feats))                       # {ext,terrain,sensor,param}


# IP-259/301 CG-COF：接触 + PE 门控标定（R68 COF 升级）
class ContactGatedCalibrationFilter:
    def step(self, z_cal, r, sigma_stat, alpha, mu, B_basis):
        self.predict()
        if (not alpha.any()) or sigma_stat <= 0.9 or mu <= MU_PE:
            return self.c, np.inf, self.frozen_thr()      # 冻结，最坏情况
        self.update(cat([z_cal, r]), R_static if sigma_stat > 0.9 else R_dynamic)
        self.rate_limit()
        if project(r, B_basis) > tau_blind:
            return self.c, np.inf, self.frozen_thr()      # 盲子空间：绝不吸收
        U = np.trace(self.S)
        return self.c, U, self.reparam_thr(U)


# IP-262 AIR-RAS 主闭环（双环）
def AIR_RAS_round(M, obs):
    # ---- 1 kHz 低层环（每 tick） ----
    alpha, kappa = M.lip.contact_schedule(obs.foot_force, obs.tau, obs.imu)
    w_hat = M.cdo.step(obs.q, obs.dq, obs.tau, alpha, M.f_hat)
    z3 = M.eso.step(obs.q, obs.dq, obs.tau)
    tau_cmd = M.ctrl(obs.q, obs.dq) - w_hat - z3 + M.aeg.current_probe()

    # ---- 100–200 Hz 风险环 ----
    Y = M.lip.regressor(obs.q, obs.dq, obs.ddq)
    mu, B_dim, V_def = M.pew.step(Y)
    M.aeg.set_probe(M.aeg.probe(V_def, M.risk_budget, mu, alpha))
    c, U, thr = M.cg_cof.step(obs.z_cal, obs.rho, obs.sigma_stat, alpha, mu, V_def)
    cause = M.dda.attribute(M.rho_by_cond, M.Y_by_cond, alpha, mu)

    # ---- 继承 R68/R67：CFA + WM 前瞻 + 风险缩放 ----
    joint_post = M.cfa(obs.rho, obs.face, c, U, cause)
    wm_preds = M.mtm.rollout(obs.z, M.ach.propose_actions(obs.x_prime, 5))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(obs.x_prime, M.vista.H),
                                    joint_post, min(M.vista.m, M.m_emo),
                                    M.alpha_chunk, wm_preds)
    if mu < MU_PE or kappa > TAU_CONTACT or U > TAU_CAL:
        k = min(k, k_probe)
    lam = max(M.efs.risk_scale(joint_post), thr['lam_floor'],
              0.8 if (obs.face_quality < 0.8 or mu < MU_PE or kappa > TAU_CONTACT) else 0.6)

    # ---- reject-then-report + 异步审计 ----
    M.audit.record_raw(obs.rho, w_hat, cause, alpha, mu)
    M.vqa_a.submit_async(wm_preds, {'dist': w_hat, 'cause': cause, 'mu': mu})
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)
    return tau_cmd, k, lam, joint_post, cause
```

## 3. 推导

**引理 16（被动不可分性——R68 风险的充要条件）** 对任意仅依赖残差 ρ 的被动估计器，存在两组不同的 (Δθ, w) 与 (Δθ′, w′) 产生完全相同的观测，当且仅当 Δθ − Δθ′ ∈ B 且 w − w′ = −Y_T(Δθ − Δθ′)。故 dim B > 0 ⇒ 落在盲子空间内的缓变故障对任何被动观测器不可检出。**这解释了 R68 的风险不是工程疏漏，而是可辨识性定理的直接推论。**

**引理 17（接触门控的可观测性）** stance 相位提供 J_i 约束，f_i 可观测；swing 相位 J_i 不提供约束，f_i 不可观测，任何用 swing 数据更新 f_i 或标定的做法引入非零偏差 E[Δf] ≠ 0。故接触门控不是启发式，而是可观测性的必要条件；漏检触地（α_i 假阴性）会把地面反力注入外扰估计，造成正反馈失稳。

**引理 18（PE 主动辨识界）** 若探针使 μ = λ_min(∫_T YᵀY) ≥ μ_PE，则参数估计误差 ‖Δθ̂ − Δθ‖ ≤ ‖ε + w⊥‖/√μ_PE（w⊥ 为落在 range(Y) 内的扰动分量）。若探针只沿盲子空间方向注入能量，则所需能量与 dim B 成正比，且对任务轨迹的扰动可加性可控。

**引理 19（步态不变性分离）** 在 n_C 个条件、参数不变假设下，跨条件平均把地形/接触扰动方差降为 σ_w²/n_C，而参数信号不变；分离误差 ≤ σ_w/√(n_C·μ)。故步态多样性是零成本的「多环境对齐」。

**定理 16（AIR-RAS 端到端风险一致性）** 在 A87–A94 与 A95–A98（接触时序可观测、PE 可注入、探针稳定裕度有界）下：
1. P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + **α_dist + α_contact + α_pe**；
2. μ < μ_PE ⇒ λ_risk ≥ 0.8 ∧ 盲子空间冻结 ∧ 禁止任何基于标定的放宽 ∧ k ≤ k_probe；
3. 外扰经 CDO 抵消后残余 ≤ (1−G_cdo)‖w_ext‖，且原始估计必被上报（reject-then-report）；
4. 探针期间任务风险 ≤ B_task，探针对稳定裕度的影响 ≤ δ_stab，探针能量 E_probe ∝ dim B。

**定理 17（双重用途不干扰性）** 抵消通路与归因通路共享同一 ŵ_ext 但作用于不同层；只要归因层读取的是 ρ + ŵ_ext（而非仅抵消后残余），低层抵消不改变高层可观测性。即 reject-then-report 使 anti-interference 不退化为 anti-detection。

**定理 18（缓变故障检出下界）** 对带宽 ω_f < ω_cal 的缓变故障，若其参数方向 v 满足 v ∉ B（PE 可辨识），则主动辨识后的检出概率 ≥ 1 − Φ((τ_det − ‖Y v‖·‖Δθ‖)/σ_eff)；若 v ∈ B 且 AEG 无法在预算内激发 v，则检出概率退化为被动基线——**主动抗干扰的能力边界由可激发的盲子空间维数精确刻画**。

## 6. 本轮最大风险

**一句话**：AIR-RAS 的安全性同时押在「接触时序正确」与「持久激励足够」两块基石上——在准静态、无纹理、匀速平地上回归矩阵秩亏，缓变故障仍躲在盲子空间里，而主动探针为了填满它又必须注入扰动，这份扰动可能被误判为地形或外推、并侵蚀稳定裕度；**当激励不足时，抗干扰的「探针」本身就成了新的干扰源，治病的药可能变成致病因子。**

**次级风险与缓解**：
1. **接触误判正反馈**：α_i 假阴性 → 地面反力被当外扰抵消 → 失稳 → 更差的接触估计；缓解为 α_i 后验 + κ_contact 直接抬高 λ 下限 + 接触与扰动联合估计；
2. **探针-扰动自指**：探针频率若落入 DDA 的外扰频带会被误归类；缓解为已知探针信号先验扣除（probe-aware DDA）+ E300 专项审计；
3. **ESO 与 COF 双重吸收**：两者都可能吞掉慢故障；缓解为频带分离 + 盲子空间冻结 + 定理 17 的 reject-then-report；
4. **步态多样性不足**：某些场地只允许单一平坦步态；缓解为 AEG 最小探针 + 明确暴露 dim B 于 J_AIR，不可辨识即保守；
5. **计算双环耦合**：1 kHz 环与 200 Hz 环共享状态可能竞态；缓解为无锁快照 + 版本号校验。

## 2. 形式化定义（要点版）

**定义 293（总览与三不变式）** reject-then-report（抵消必上报）；blind-subspace freeze（不可辨识不吸收）；probe safety（探针受风险预算与稳定裕度约束）。

**定义 294（浮动基 + 接触时序）** `M q̈ + Cq̇ + g = Sᵀτ + Σ α_i J_iᵀ f_i + w_ext`；stance 满足 `J_i q̈ + J̇_i q̇ = 0`；swing 无约束。

**定义 295（CDO）** 动量残差 `ṙ_o = −K_o r_o + K_o(ṗ − ∫(Sᵀτ − Cq̇ − g + Σ α_i J_iᵀ f̂_i)dτ − p(0))`，`r_o → w_ext`；swing 腿不入门控。

**定义 296（回归与盲子空间）** `τ = Yθ + Jᵀf + ε`，`ρ = YΔθ + w + ε`；`B = null(Y_T)`，`μ = λ_min(Y_TᵀY_T)`。

**定义 297（PEW）** `μ(t) = λ_min(∫_{t−T}^t YᵀY dτ)`；`μ<μ_PE` 判激励赤字，输出 `V_def`。

**定义 298（AEG）** `τ_probe = Σ A_k sin(ω_k t) v_k`，沿 `V_def`、避步态谐波；自然激励足够则 `A_k=0`（terrain-as-excitation）。

**定义 299（DDA）** `Δθ̂ = argmin Σ_c ‖ρ_c − Y_c Δθ‖²`，`ŵ_c = ρ_c − Y_c Δθ̂`；参数跨条件不变、扰动随条件变 → 无标签分离；四分后验由瞬态/不变性/接触/频带特征给出。

**定义 300（双重用途）** `u_reject = −ŵ_ext`（低层），`e_attrib = ρ + ŵ_ext`（高层）；抵消不改可观测性。

**定义 301（CG-COF）** 仅 `α_i=1 ∧ σ_stat 高 ∧ μ>μ_PE` 才 update；漂移落在 B 内则 unidentifiable、U=∞、禁止吸收；保留速率限制与标定红线。

**定义 302（λ_floor^AIR / 探针安全）** 任一不确定源 → λ ≥ 0.8；探针期 `λ += Δ_probe`、`k ≤ k_probe`。

**定义 303（干扰集）** `ℰ_AIR = ℰ_CALM × ℰ_dist × ℰ_contact × ℰ_pe`。

**定义 304（J_AIR）** Valid ⇔ `Valid(J_CALM) ∧ [μ≥μ_PE^hard ∨ B 冻结] ∧ reject-then-report 入 AuditBuf`。

**定义 305（双环管线）** 1 kHz：CDO+ESO+抵消；200 Hz：PEW→AEG→CG-COF→DDA→RAS††；离线富激励辨识先验 θ0。

**定义 306（归因顺序性）** 接触门控 → PE 门控 → 跨条件分离 → CFA；任一前置失败只能导向保守。

```python
class ContactDisturbanceObserver:
    def step(self, q, dq, tau, alpha, f_hat):
        p = mass_matrix(q) @ dq
        gen = S_T @ tau - coriolis(q, dq) @ dq - gravity(q)
        gen += sum(alpha[i] * J_i(q).T @ f_hat[i] for i in range(4))
        self.r += self.K_o * ((p - self.p) - self.r); self.p = p
        return self.r                                   # ŵ_ext

class JointESO:
    def step(self, q, dq, tau):

        self.z1 += self.dt * (self.z2 + 3*self.wo*e)
        self.z2 += self.dt * (self.z3 + 3*self.wo**2*e + b0*tau)
        self.z3 += self.dt * (self.wo**3*e)
        return self.z3

    M.vqa_a.submit_async(wm_preds, {'dist': w_hat, 'cause': cause, 'mu': mu})
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)
    return tau_cmd, k, lam, joint_post, cause
```

## 4. 推导

**引理 16（被动不可分性）** 仅依赖 ρ 的估计器无法区分 (Δθ,w) 与 (Δθ′,w′)，当且仅当 Δθ−Δθ′∈B 且 w−w′=−Y_T(Δθ−Δθ′)。dim B>0 ⇒ 盲子空间内缓变故障不可检出——R68 风险的充要条件。

**引理 17（接触门控可观测性）** stance 提供 J_i 约束、f_i 可观测；swing 不可观测，用 swing 数据更新引入 E[Δf]≠0；漏检触地 → 地面反力误入外扰 → 正反馈失稳。

**引理 18（PE 主动辨识界）** μ≥μ_PE ⇒ `‖Δθ̂−Δθ‖ ≤ ‖ε+w⊥‖/√μ_PE`；沿盲方向注入能量时所需能量 ∝ dim B。

**引理 19（步态不变性分离）** n_C 条件下地形/接触扰动方差降为 σ_w²/n_C，参数信号不变；分离误差 ≤ σ_w/√(n_Cμ)。

**定理 16（端到端风险一致性）** A87–A98 下：
1. `P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_dist+α_contact+α_pe`；
2. `μ<μ_PE ⇒ λ≥0.8 ∧ B 冻结 ∧ 禁止标定放宽 ∧ k≤k_probe`；
3. CDO 抵消残余 ≤ (1−G_cdo)‖w_ext‖，原始估计必上报；
4. 探针任务风险 ≤ B_task、稳定裕度损失 ≤ δ_stab、能量 ∝ dim B。

**定理 17（双重用途不干扰性）** 归因层读 `ρ+ŵ_ext` 而非仅残余 ⇒ 低层抵消不改变高层可观测性，anti-interference 不退化为 anti-detection。

**定理 18（缓变故障检出下界）** 方向 v∉B 时检出概率 ≥ `1−Φ((τ_det−‖Yv‖‖Δθ‖)/σ_eff)`；v∈B 且预算内不可激发则退化为被动基线——能力边界由可激发盲维数精确刻画。

## 7. 本轮最大风险

**一句话**：AIR-RAS 的安全性同时押在「接触时序正确」与「持久激励足够」两块基石上——在准静态、无纹理、匀速平地上回归矩阵秩亏，缓变故障仍躲在盲子空间里，而主动探针为了填满它又必须注入扰动，这份扰动可能被误判为地形或外推、并侵蚀稳定裕度；**当激励不足时，抗干扰的「探针」本身就成了新的干扰源，治病的药可能变成致病因子。**

**次级风险与缓解**：接触误判正反馈（α 后验 + κ_contact 抬高 λ + 接触/扰动联合估计）；探针-扰动自指（probe-aware DDA + E300 审计）；ESO/COF 双重吸收（频带分离 + 盲子空间冻结 + reject-then-report）；步态多样性不足（AEG 最小探针 + J_AIR 显式暴露 dim B）；双环竞态（无锁快照 + 版本号校验）。
