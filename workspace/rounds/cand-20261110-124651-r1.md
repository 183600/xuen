# 第 44 轮（新循环第 4 轮） · World-Cert × Aug-Cert：把「Gazebo 世界契约」与「数据增强的测度迁移」纳入可验证证书闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 用契约、rely-guarantee、租约与混合关键级把「个性化」和「并发」纳入证书，但它仍压在两个未言明的**本体论假设**上：**(H1) 仿真是单一标称世界**——SCV 只把 Gazebo/Isaac 当作验证场地，却从未把 world/SDF、物理引擎、传感器插件、随机种子、实时因子当作证书的**前提**；于是「仿真里没有违例」被悄悄读成「世界里没有违例」。**(H2) 数据增强是免费扩容**——增强被当作训练技巧，从未回答「增强后的分布凭什么覆盖真实部署分布」「增强是否保持安全谓词不变」。本轮灵感词「Gazebo」「数据增强」正好刺中这两点：**Gazebo** 把世界从背景变成一份可版本化、可指纹化、但自带模型偏差与重放噪声的**契约**；**数据增强**把数据从独立同分布样本变成一次**测度变换**，能扩训练支撑却扩不了真实支撑。核心新问题因此是：**world-conditioned soundness（世界条件可靠性）与 augmentation-certified expansion（增强持证扩张）**——证书不仅要问「状态是否安全」，还要问「你在一张多可信的世界上、用一次多可信的增强证明的」。

## 0. 直觉与动机

**灵感 1（Gazebo → 世界是「代码 + 噪声预言机」，不是真值）**：直觉上，一张在 Gazebo 里跑通的速度证书，换个物理引擎、把求解器迭代次数减半、把摩擦系数从 world 文件里改一行，就可能不再安全；更隐蔽的是，Gazebo 的实时因子、接触求解顺序、传感器噪声种子会让**同一份 world 的两次重放都不完全一致**。因此不能把「仿真通过」当结论，只能把它当**在某个世界契约内、高于某个噪声地板的有效证据**。定义 **Gazebo 世界契约** W=(SDF 几何/材质, Θ_phys, Θ_sens, seed, engine_fp, ρ_W)，证书携带世界指纹 h_W 与参数盒 Θ_box，并按世界参数不确定度**内缩**有效域：m_world = m_spatial − L_θ·diam(Θ_box) − L_x·δ_x。一句话：**世界越不确定，证书越收缩**；且任何小于仿真重放噪声 ε_rep 的边际都不可测量，必须拒绝。

**灵感 2（数据增强 → 改变测度，而不是增加支撑）**：直觉上，「在增强集上零违例」几乎不能推出「在真实世界里零违例」：颜色抖动可能改变红绿灯语义，随机裁剪可能删掉障碍物，copy-paste 可能造出物理上不可能的接触，点云抖动可能抹掉细杆。数学上，增强给出的是 P_aug，部署是 P_real；重要性加权 E_real[f]=E_aug[(dP_real/dP_aug)f] 只在 **P_real ≪ P_aug（支撑覆盖）** 时成立。增强可以把 P_aug 变宽，但**不能创造真实支撑**。因此把增强分成两类：**仅训练增强**（可以任意，不进入证书）与**可认证增强**（必须通过安全交换性 Δ_g、支撑覆盖、权重/DRO 半径、捷径检测四道闸门）。一句话：**增强可以扩训练，不能免费扩证书**。

**灵感 3（耦合 → 世界级增强是唯一可认证的增强）**：像素级增强只扰动观测，不改变动力学、几何与传感器物理，因此对证书而言通常**不足以证明**新工况；真正能进入证书闭环的是**世界级增强**——对 SDF 的物体位姿/材质、Θ_phys 的摩擦/质量/阻尼、Θ_sens 的噪声/延迟/视场、以及人类行为脚本做带种子的反事实采样。这把「数据增强」从图像技巧提升为**世界测度上的重要性采样**：每个增强世界都是一次可重放的仿真，每条证书都带增强谱系与真实锚点覆盖证据。代价是仿真算力，收益是「扩一张证书」而不是「多一堆图片」。

**耦合升级**：WCC（世界契约证书）负责把 Gazebo 世界编译成指纹、参数盒与重放等价类；AMC（增强测度证书）负责把增强算子编译成安全交换性证明、支撑覆盖与 DRO 半径；SFR（仿真-现实保真运行时）用**保真租约 + 残差栅栏**在部署期监测「真实世界是否还在契约与增强支撑内」，一旦越界即原子失效相关证书。四层架构从 v8 的「仿真-检索-边缘-人格-并发」升级为 v9 的「+ 世界保真层（world-fidelity layer）」：**任何证书都必须回答「你在哪份 Gazebo 世界契约上、由哪一族可认证增强背书、现实残差是否仍然小」。**

## 1. 形式化定义（增量：定义 44–49）

**定义 44（Gazebo 世界契约 W）**：W = (G, M, Θ_phys, Θ_sens, s, e, ρ_W)。G 为 SDF 几何与场景图，M 为语义/材质/光照，Θ_phys 为物理参数盒（摩擦、质量、阻尼、接触刚度、求解器迭代），Θ_sens 为传感器参数盒（噪声、延迟、视场、分辨率），s 为随机种子，e 为引擎指纹（Gazebo 版本 + ODE/Bullet/DART + 插件哈希），ρ_W 为世界修订号。**世界指纹** h_W = H(canonicalize(W))，其中 canonicalize 消除无关浮点表示但不消除任何影响动力学的参数。**世界距离** d_W 在参数盒上取加权 L∞/Wasserstein 混合度量。**命题**：若两份 world 仅光照纹理不同而 Θ_phys/Θ_sens/G 相同，则它们属于同一动力学等价类；若 e 不同，则即使 h_W 相同也必须重标定——**引擎指纹是证书的一等前提，不是元数据**。

**定义 45（世界条件证书 WCC）**：证书 c = (φ, X_D, Θ_box, η, h_W, ℓ_f)，其中 φ 为安全谓词，X_D⊆X 为状态域，Θ_box⊆Θ_phys×Θ_sens 为被证明覆盖的世界参数盒，η 为鲁棒半径，ℓ_f 为保真租约（定义 49）。**世界条件边际**：m_world = m_spatial − L_θ·diam(Θ_box) − L_x·δ_x，其中 L_θ、L_x 分别为谓词对世界参数与状态扰动的 Lipschitz 常数。**世界条件 soundness 定理**：若真实世界参数 θ*∈Θ_box、真实状态 x 与估计 x̂ 满足 ‖x−x̂‖≤δ_x、且 x∈X_D⊖δ_x，则当 m_world≥θ_guard 时 c 所守卫的动作在真实世界 sound。**推论（收缩免费）**：Θ_box 越大、δ_x 越大，m_world 越小、有效域越收缩；收缩不会新增违例，因此对 soundness 免费，但会复发可用性崩塌，必须用重标定/回环/重证而非静默放宽。

**定义 46（重放等价与仿真噪声地板）**：固定 W 与种子 s，重复 n 次重放得到轨迹族 {τ_i}；定义重放等价 τ_i ≈_ε τ_j 当且仅当所有证书相关统计量的偏差 ≤ε。**仿真噪声地板** ε_rep(W, e) = 该轨迹族在证书统计量上的上分位偏差。**噪声地板命题**：若证书边际 m_world ≤ L_m·ε_rep，则该证书的「通过/失败」在仿真自身噪声内不可区分，必须拒绝或增大 n/改用锁步确定性重放；**任何低于噪声地板的「仿真零违例」都不构成证据**。**注**：Gazebo 的实时因子、接触求解顺序、传感器插件异步发布是 ε_rep 的三个主要来源，必须在 world 契约里显式记录，而非藏在实验日志里。

**定义 47（增强算子与安全交换性）**：增强算子 A_g: D→D（像素/点云级）或 A_g: W→W（世界级），带参数 g，构成一个含恒等元的算子幺半群。**安全交换性**：A_g 与谓词 φ 交换，当且仅当 ∀x∈D，|φ(A_g(x)) − φ(x)| ≤ Δ_g；**增强泄漏** Δ_g 是「增强改变了安全标签」的上界。**可认证增强**要求 Δ_g 可估且有限，并在边际中扣除 L_φ·Δ_g；若 Δ_g 不可界（如随机裁剪可删除障碍），则该算子只能作**仅训练增强**，禁止进入证书闭环。**命题**：两个安全交换算子复合仍安全交换，但两个仅训练算子复合不因「复合后看起来合理」而变得可认证——交换性必须逐算子证明，不能靠端到端准确率反推。

**定义 48（增强测度迁移与支撑覆盖证书）**：设增强分布 P_aug（由世界/数据增强族诱导），真实部署分布 P_real 未知，真实锚点集 D_real 为少量带标签或可判定安全性的真实样本。**迁移证书**成立当且仅当：(i) **支撑覆盖**：D_real 中至少 1−α 比例的锚点落在 P_aug 的 η-支撑邻域内（用共形 p 值或两样本检验给出下界）；(ii) **权重有界**：密度比 dP_real/dP_aug 的估计或 DRO 半径 ε_W 有有限上界；(iii) **无捷径**：安全交换性 Δ_g 与真实锚点上的残差一致，未出现「增强集变好、真实锚点变差」的泄漏缺口。**测度迁移界**：若 (i)(ii) 成立，则对任意有界安全损失 f∈[0,M]，E_real[f] ≤ E_aug[w·f] + L·ε_W + M·δ_support，其中 δ_support 为支撑覆盖失败率。**支撑不可能定理**：仅凭有限增强样本无法证明任意 P_real 的支撑覆盖；支撑覆盖必须由**真实锚点**外证，这是本架构不可自证的唯一假设。

**定义 49（保真租约与残差栅栏）**：每条世界条件证书携带保真租约 ℓ_f = (ε_sr, τ, λ_f, h_W)。运行时用 Gazebo 世界契约对当前动作做**前向预测** ŷ_t = Gazebo(W, x̂_t, a_t)，并与真实观测 y_t 在证书相关统计量上比较，残差 e_t = d_stat(ŷ_t, y_t)。**新鲜度判据**：e_t − λ_f·(t−τ) ≤ ε_sr 且 h_W = h_current 且 ρ_W = ρ_current 时，保真租约有效；否则原子失效所有依赖 h_W 的证书，触发重证/降级/安全停机。**残差栅栏定理**：若 (i) 世界指纹与修订号在取租约时原子校验，(ii) 失效先于新世界可见，(iii) 残差统计量对证书谓词 Lipschitz，则任意交错下不存在「用旧世界证书守卫新世界动作」的撕裂读。**注**：残差必须在**证书相关统计量**上算（如障碍距离、可通行间隙、接触力上界），不能在原始像素 L2 上算——后者会被光照/纹理噪声淹没，导致既漏报又误报。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 WORLD-CONTRACT-CERTIFICATE（世界契约证书 WCC）
1. **世界契约编译器**：把 Gazebo world/SDF + 物理/传感器插件参数 + 种子 + 引擎指纹规范化成 W 与 h_W；导出参数盒 Θ_box、动力学等价类与不可变字段清单。
2. **重放噪声标定器**：对每个 world 跑 n 次同种子/跨引擎重放，估计 ε_rep；证书边际低于 L_m·ε_rep 时拒绝签发，并建议锁步或增大 n。
3. **世界条件边际 m_world**：按 Θ_box 直径与状态误差内缩有效域；把「世界不确定性」折算成可审计的保守边际。
4. **修订栅栏与指纹绑定**：证书与 h_W、ρ_W 强绑定；世界文件、引擎版本或插件哈希变化即原子失效，禁止「拿旧世界证书跑新世界」。

### 2.2 IP-61 AUGMENTATION-MEASURE-CERTIFICATE（增强测度证书 AMC）
1. **增强代数与分级**：把增强算子分为「仅训练」「可认证」两类；可认证算子必须给出安全交换性 Δ_g 的估计与适用域。
2. **支撑覆盖证书**：用真实锚点集 D_real 做共形 p 值/两样本检验，给出 P_real 落在 P_aug η-邻域内的下界；支撑不覆盖则禁止扩张。
3. **权重/DRO 迁移证书**：估计密度比或 Wasserstein 半径 ε_W；输出风险迁移上界，超过阈值即拒绝把增强结论带入证书。
4. **捷径/泄漏检测器**：构造「增强集 vs 真实锚点」的对照探针，检测「增强变好、真实变差」的缺口；把泄漏缺口回灌 SCV 与 CKB。
5. **稀有事件增强**：对安全关键稀有事件用带已知提议分布的重要性采样，输出带置信区间的发生概率，避免「生成 N 个世界没看到违例」的零事件谬误。

### 2.3 IP-62 SIM-REAL-FIDELITY-RUNTIME（仿真-现实保真运行时 SFR）
1. **保真租约表**：按证书维护 ℓ_f=(ε_sr, τ, λ_f, h_W)，硬件单调时间戳；与世界修订、增强谱系绑定。
2. **证书相关残差监控**：用 Gazebo 前向预测与真实观测在障碍距离/可通行间隙/接触力等统计量上算残差，而非原始像素差。
3. **残差栅栏与单调降级**：残差越界即失效相关证书，触发重证、缩短租约或退回「仅真实锚点 + 纯收缩」的保守基线。
4. **跨世界可移植税**：证书在动力学等价类间迁移分三档——同指纹免验、参数盒包含降级复用、跨引擎重证；禁止无档迁移。

def compile_world_contract(gazebo_world, engine_fp):
    W = canonicalize(
        sdf      = gazebo_world.sdf,

def calibrate_replay_noise(W, n=32):
    stats = [run_gazebo(W, W.seed) .cert_statistics for _ in range(n)]
    return upper_quantile([deviation(stats) for s in stats], q=0.99)
    # 低于 L_m*eps_rep 的证书一律拒绝，见定义 46

def world_conditioned_cert(phi, X_D, Theta_box, h_W, eps_rep):

    m_world   = m_spatial - L_theta*diam(Theta_box) - L_x*delta_x
    if m_world <= L_m * eps_rep:

### IP-61 AMC：增强代数、支撑覆盖、DRO 迁移与泄漏检测

def classify_augmentation(A_g, phi):
    delta_g = estimate_label_shift(A_g, phi)       # |phi(A_g x)-phi(x)| 上界
    if delta_g is None or not finite(delta_g):

def support_coverage_certificate(P_aug, D_real, eta, alpha=0.05):
    pvals = [conformal_pvalue(dist_to_aug_support(x, P_aug), eta) for x in D_real]
    cover = lower_confidence_bound(pvals, 1-alpha)
    delta_support = 1 - cover
    return Coverage(cover, delta_support, eta)

def measure_transfer_certificate(P_aug, D_real, f_loss, M):
    cov = support_coverage_certificate(P_aug, D_real, eta)
    if cov.cover < 1 - alpha:
        return REJECT("support not covered: augmentation cannot create support")
    eps_W = estimate_dro_radius(P_aug, D_real)     # Wasserstein 或密度比界
    w     = estimate_density_ratio(P_aug, D_real)  # 仅在 eps_W 有限时
    bound = expectation_aug(w * f_loss) + L*eps_W + M*cov.delta_support
    return Transfer(bound, eps_W, cov)

def leakage_probe(P_aug, D_real, augmentations):
    # 增强集变好、真实锚点变坏 => 捷径/泄漏
    gap = risk_aug(augmentations) - risk_real(D_real)
    return Leakage(gap, shortcut=gap > tau_leak)

def rare_event_probability(P_aug, event, n, proposal):
    # 重要性采样；提议分布已知，返回带置信区间的概率，而非「零事件」
    samples = [sample_world(proposal) for _ in range(n)]
    weights = [density_ratio(proposal, P_aug, s) for s in samples]
    return weighted_ci([event(s) for s in samples], weights, confidence=0.95)
