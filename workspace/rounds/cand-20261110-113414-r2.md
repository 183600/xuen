# 第 43 轮（新循环第 3 轮） · 通用操作 × 跨物体泛化：把证书从「任务级模板」抬升为「操作-物体乘积流形上的可粘合证书丛」（四层架构 v8）

> 承接第 42 轮 v19（Sim-Cert-RAG 飞轮）。v19 把证书变成了可进化的资产，但资产的组织方式仍是「任务级」的：KB 的键是 (φ, ψ)，每个新任务仍要检索模板 + 只在差集上补全一整张证书。它自陈的最大风险是「仿真偏差累积 + 检索幻觉」。本轮两个灵感词精准补上 v19 缺失的两根轴：**「通用操作」补上操作轴**——证书不应按任务重算，而应建立在一个小的、带契约的**接触操作基**上，任务 = 基元的词，证书 = 局部截面沿接口粘合；**「跨物体泛化」补上物体轴**——证书不应按物体实例重算，而应参数化为物体证书充分统计量 z(o) 的条件场，用 Lipschitz 界合法外推。两轴相乘得到本轮主张：**通用性 = 在「操作参数 × 物体」乘积流形上的覆盖；组合安全 = 接口上的粘合残差闭合**。这把 v19 的「经验碎片库」升级为「可组合、可外推、可拒答的证书丛」。

## 0. 直觉与动机

**灵感 1（通用操作 → 不是更大的模型，而是一个可认证的接触基）**：人类会用少数几种接触模式（捏取、包络抓、推、拉、旋、插、倒、交接）覆盖绝大多数操作；遇到新任务时是在这些模式上「造句」，而不是从零学一条策略。v19 的 KB 没有这个「词法层」：φ 是任务指纹，于是「把杯子放进抽屉」和「把盒子放进抽屉」被当成两个任务，冷启动重复计算，且任务一多，KB 只是线性膨胀的经验碎片。直觉方案：显式定义一个**通用操作基** A = {a_k(u)}_{k=1..K}，每个基元带契约 (Pre, Eff, Inv, Guard, Abort) 和连续参数 u（抓取宽度、推点高度、插入角度、倾倒角速度……）。任务 τ 被分解为一个词 w = a_{i1}(u₁);…;a_{in}(u_n)。证书合成因此拆成两件更小的事：(i) 基元证书只需认证一次，并在参数流形 U_k 上外推；(ii) 组合只需检查相邻基元的接口。VLA/LLM 可以继续当「词的提议者」，但**只有通过契约检查的词才能进入执行**——这把「通用操作」从一句模型能力口号，变成一套可审计的代数。

**灵感 2（跨物体泛化 → 迁移的是证书充分统计量，不是外观）**：人抓过一百个杯子后抓新杯子不需要重测，因为他迁移的是「接触流形拓扑、曲率谱、质量/惯量比、摩擦锥、柔顺性」这类与证书相关的量，而不是某个具体杯子。v19 把物体隐式压进 φ/ψ，物体一变检索命中率就断崖。直觉方案：定义 z(o) ∈ Z（只保留证书相关信息），把证书写成 z 的条件场 C(x; a, u, z)，并用**物体边际 Lipschitz 常数 L_Z^a** 把锚点物体的证书合法外推到 z 邻域；邻域外一律**新颖性拒绝**，绝不外推。跨物体泛化于是变成物体空间里的覆盖问题，而不是逐物体重算。

**灵感 3（两者耦合 → 乘积流形上的证书丛 + 接口粘合）**：只有物体轴还不够：即使每个物体上的「抓」都安全，「抓完再插」仍可能因为抓取姿态给插入留下的接口不匹配而失败。反之只有操作轴也不够：同一个「插」在不同柔顺性/摩擦的物体上有效域完全不同。把两轴相乘，得到**操作-物体证书丛**：底空间是 P = ⊔_k (U_k × Z)，纤维是状态空间中的有效安全集；每个已认证的 (a,u,z) 格点存一个**局部截面**。组合一个词时，把相邻截面的接口变量（物体位姿/速度、接触力旋量、抓取状态、不确定性、时序余量）对齐：若残差 ≤ τ_glue 且所有三重叠满足 1-上闭链条件，则局部截面**粘合成全局证书**；否则 `CompositionalReject`。这一步把「组合安全」从「局部都安全所以整体安全」的直觉，升级为一个可数值检查的闭合条件。

**耦合升级**：通用操作给「横向」（基元代数与组合），跨物体泛化给「纵向」（物体纤维与外推），证书丛把二者缝合。v19 的 Sim→RAG→Edge→Sim 飞轮被改造成 **「基元/物体主动覆盖 → 局部截面签发 → 接口粘合 → 组合反例回灌 → 扩基/扩域」** 的 v8 飞轮。特别地，组合反例是最有价值的数据：它指出的往往不是某个基元错，而是**接口变量集不完备**——这正是本轮最想暴露、也最容易被平均指标掩盖的失效。

## 1. 形式化定义（增量：定义 38–45）

**定义 38（通用操作基元与契约）**：基元 a_k(u) = (π_k(·;u), Pre_k(u), Eff_k(u), Inv_k(u), Guard_k(u), Abort_k(u))，其中 u ∈ U_k ⊆ ℝ^{d_U,k} 为连续参数，π_k 为参数化控制器/策略。基元证书 Cert_k(u) := {x ∈ Pre_k(u) : m_k(x;u) ≥ θ_k(u)}。**基元 sound** 指：从任意 x ∈ Cert_k(u) 出发执行 π_k，在 T_hold 内要么保持 Inv_k(u)，要么在越过 Guard_k(u) 之前触发 Abort_k(u)。任务 τ 被表示为一个词 w = a_{i1}(u₁);…;a_{in}(u_n)，其语义由契约代数给出（见定义 42–43）。

**定义 39（操作-物体证书丛）**：底空间 P = ⊔_{k} (U_k × Z)，投影 π_P : P → (k, Z)。每个认证格点 (k,u,z) 带一个**局部截面** σ_{k}(u,z) = C_k(u,z) ⊆ X（该 (基元, 参数, 物体) 下的有效安全集）与信任半径 (r_U, r_Z)。**全局证书**是定义在区域 R ⊆ P 上的一个截面，满足在重叠处与局部截面一致（定义 42 的粘合条件）。v19 的 KB 从「任务模板库」变为「局部截面库」。

**定义 40（物体证书充分统计量与纤维内传输界）**：物体 o 的证书相关特征 z(o) = (𝒯_contact, Σ_curv, ρ_mass, β_fric, χ_comp) ∈ Z ⊆ ℝ^{d_Z}，分别表示接触流形拓扑类、曲率谱、质量/惯量比、摩擦锥半角、柔顺性；取加权马氏距离 d_Z。**物体边际 Lipschitz 常数** L_Z^a := sup_{x,u,z₁≠z₂} |m(x;a,u,z₁) − m(x;a,u,z₂)| / d_Z(z₁,z₂)。**命题 40.1（纤维内物体迁移界）**：m(x;a,u,z₂) ≥ m(x;a,u,z₁) − L_Z^a·d_Z(z₁,z₂)。故锚点 (u,z_i) 的信任半径 r_Z,i = (m_lo − θ)/L_Z^a，半径内证书外推**保 sound**，半径外弃权。**证书场下界** m_lo(x;a,u,z) := max_i [ m(x;a,u,z_i) − L_Z^a·d_Z(z,z_i) ]（每个锚点给一个合法下界，取最紧者）。

**定义 41（原语参数传输界与乘积数据杠杆）**：**参数边际 Lipschitz 常数** L_U^a := sup_{x,z,u₁≠u₂} |m(x;a,u₁,z) − m(x;a,u₂,z)| / ‖u₁−u₂‖。**命题 41.1（乘积迁移界）**：m(x;a,u₂,z₂) ≥ m(x;a,u₁,z₁) − L_U^a‖u₁−u₂‖ − L_Z^a d_Z(z₁,z₂)。信任域是以 (u_i,z_i) 为中心、半径 r_U=(m−θ)/L_U、r_Z=(m−θ)/L_Z 的各向异性椭球，其体积即**数据杠杆** Λ_k = V_{d_U+d_Z}·r_U^{d_U}·r_Z^{d_Z}。**推论 41.2**：内蕴维 d_U + d_Z 主导杠杆；L_U 或 L_Z 翻倍、裕度减半，Λ 按 2^{−(d_U+d_Z)} 衰减。

**定义 42（接口、粘合残差与上闭链）**：相邻基元 a→a′ 的**接口变量集** I_{a,a′} = (ξ_o, v_o, w_contact, g_grasp, σ_unc, τ_time)，分别是物体位姿、速度、接触力旋量、抓取状态、不确定性摘要、剩余时序。令 proj_I 为到接口空间的投影。**粘合残差** ρ(a,a′) := max_{y ∈ Eff_a} dist_I( proj_I y , proj_I Pre_{a′} ) + λ_inv·dist(Inv_a, Inv_{a′})，各项按接口量程归一化。对含环/并行的词，对每个三重叠 (i,j,k) 定义**上闭链残差** δ_{ijk} := ‖T_{ij}∘T_{jk}∘T_{ki} − Id‖，T 为沿接口搬运局部截面的传输算子。**粘合兼容**：ρ ≤ τ_glue 且 δ ≤ τ_cocycle。这里只做 1-上闭链的数值闭合检查，不计算层上同调。

**定义 43（组合证书与组合 soundness 定理）**：给定词 w 与每个 (a_i,u_i,z) 格点上的局部证书。若 (i) 每个局部证书 sound；(ii) 每个相邻接口 ρ ≤ τ_glue；(iii) 所有三重叠 δ ≤ τ_cocycle，则称 w **组合 sound**：执行 w 要么到达 Eff_{a_n}，要么在越过任一 Guard 之前安全 Abort，且不同粘合顺序得到的全局截面在 τ_glue 内一致（路径无关）。**证明思路**：沿词做归纳；每一步用定义 40/41 的界把前一步的后置条件推移到下一步的前置条件，三角不等式吸收残差；上闭链条件保证环上不同搬运路径不产生互相矛盾的截面，故可整体粘合。**推论 43.1**：任一条件失败 → `CompositionalReject`，不签发组合证书，退回单体证书或 SafeStop/人在环。

**定义 44（通用泛化覆盖率与通用性证书）**：锚点集 A = {(k,u_i,z_i,σ_i,r_U,i,r_Z,i)}。**通用泛化覆盖率** Gen(A) := P_{(u,z)~D_P}[ ∃i : d_U(u,u_i) ≤ r_U,i ∧ d_Z(z,z_i) ≤ r_Z,i ]。若锚点在 P 上按体积 V_P 均匀独立撒点、每点覆盖椭球体积 Λ，则未覆盖比例的精确期望为 (1−Λ/V_P)^N，故 **Cov(N) ≈ 1 − exp(−N·Λ/V_P) = 1 − exp(−N_eff)**，N_eff = N·Λ/V_P。对任务 τ 的任务相关区域 R_τ ⊆ P，**通用性证书**给分 G(τ) := measure(Certified ∩ R_τ) / measure(R_τ)，并同时报告**最坏基元**与**最坏物体组**的覆盖，而非只报平均。

**定义 45（三态签发、拒答与统计账本）**：每个格点签发状态为 {CERTIFIED, EMPIRICAL_ONLY, REJECT}。**拒答** = 物体新颖性（d_Z 越界）∨ 基元/参数新颖性（u 不在支撑集或该基元无证书）∨ 粘合失败 ∨ 统计不足。**统计账本**：对每个物体组 g 与基元 k 用 DKW 不等式与 Bonferroni 给出尾风险置信界，记录 (N, Λ, N_eff, 界, 分组)；N_eff 不达标者只能标 EMPIRICAL_ONLY，禁止声称 sound。**命题 45.1（结构即压缩）**：纯均匀采样 Λ=1 时，证尾风险 ε（置信 1−δ）需 N ≥ ln(2G/δ)/(2ε²)；有证书丛结构时只需 N ≥ ln(2G/δ)/(2ε²)·(V_P/Λ)。数据规模只有在「低内蕴维 + 有界 Lipschitz + 有界粘合残差」下才产生杠杆。

## 2. 产出设计（新增 IP-57/58/59 + 升级 IP-51/52/54/55/56/49/50/45/47）

### 2.1 IP-57 UNIV-OPS-BASIS（UOB，通用操作基与契约代数）
1. **基元挖掘**：从人类示教 + VLA 提议的轨迹里按**接触模式**聚类（接触点数量/几何、法向力方向、是否滚动/滑动），归并成 K 个基元族；目标是**证书覆盖**而不是动作多样性。
2. **契约合成**：每个基元的 Pre/Eff/Inv/Guard/Abort 由 IP-49 几何证书 + IP-54 SCV 仿真压力测试联合给出；Pre/Eff 用可检查的集合表达式（接触流形邻域、抓取力锥、位姿容差盒）表示，便于定义 42 的接口距离。
3. **参数流形标定**：在 U_k 上估 L_U^a 的经验上界，给出信任椭球；参数外推与物体外推用同一套 Lipschitz 账本。
4. **词法/语法层**：VLA/LLM 提议任务分解为词 w 与参数 u；只接受契约可满足的词；未知基元或超参数一律 `REJECT` 并请求示教，而不是强行用最近邻。

### 2.2 IP-58 X-OBJ CERT-FIELD（XCF，跨物体证书场）
1. **物体充分统计量嵌入**：z(o) 由多视图几何 + 物理先验联合估计（接触拓扑、曲率谱、质量惯量比、摩擦锥、柔顺性），用对比学习 + 物理正则训练，目标是**证书相关**而非外观相似。
2. **场外推与查询**：每个锚点存 (k,u,z_i,σ_i,r)；查询取 max_i [m − L_U d_U − L_Z d_Z] 得保守下界，O(k) 近邻 + 一次外推。
3. **新颖性门**：d_Z 越出最近锚点信任半径即 `REJECT`（SafeStop/人在环 + 数据回灌），禁止外推。
4. **物体条件运行时**：把 z 摘要并入 IP-56 ECR 的 L0 键与 L1 输入，使边缘查表/INT8 监控器直接以 (u,z) 条件化。

### 2.3 IP-59 CERT-GLUING-ENGINE（CGS，证书粘合与组合合成引擎）
1. **接口抽取与归一化**：从契约自动抽取 I_{a,a′}，对每个接口量定义量程与度量，避免「单位不同导致残差无意义」。
2. **残差计算**：在 Eff_a 上采样（含边界与对抗样本）投影到接口空间，量测到 Pre_{a′} 的距离；对环/并行计算三重叠上闭链残差。
3. **组合 CEGAR**：若 ρ > τ_glue，优先**补接口变量**（把漏掉的耦合显式化）或插入**适配基元**（如重新抓取/对齐），再不行才降参/拒答；绝不通过放宽 τ_glue 来「修好」证书。
4. **组合反例归因**：把失败切片归因为「基元不安全 / 接口不完备 / 物体外推失效 / 统计不足」，分别回灌 UOB、CGS、XCF、账本。
5. **组合拒答与回退**：`CompositionalReject` 时退回单体证书（只执行被单独认证的基元）、或 SafeStop；组合证书绝不「部分签发」。

```
    → IP-47/CGS 组合模板检索 → IP-39 规划(CBF margin = 乘积场下界 m_lo(x;a,u,z))
    → IP-45 总线(模式感知 + 乘积指纹 + 粘合/账本心跳) → IP-48 + IP-43 → IP-53 CMC(看门狗)

    → IP-57 UOB(契约代数) + IP-58 XCF(物体场) + IP-59 CGS(粘合/组合 CEGAR)
    → IP-50 课程(基元/物体双轴) → RCA 重颁证书(含 (u,z) 有效域 + 信任椭球) → 契约热更新
运行期：(u,z) 在线估计 → 乘积场查表/外推 → 三态签发；组合在离线粘合，闭合才下发；未闭合 → SafeStop/人在环 → 反例回灌
```

```
def interface_residual(Eff_a, Pre_b, I, metric):
    # 在 Eff 的边界 + 对抗样本上采样，投影到接口空间测距
    pts = boundary_samples(Eff_a) + adversarial_samples(Eff_a, I)
    return max(metric(proj(I, y), proj(I, Pre_b)) for y in pts)

def cocycle_residual(cycle, sections, transports):
    # 沿环搬运局部截面，检查回到起点是否一致（路径无关）
    worst = 0.0
    for (i, j, k) in triple_overlaps(cycle):
        T = compose(transports[(i, j)], transports[(j, k)], transports[(k, i)])
        worst = max(worst, operator_norm(T - Identity()))
    return worst

def compose_certificate(word, cells, tau_glue, tau_cocycle):
    for (a, b) in adjacent_pairs(word):
        rho = interface_residual(cells[a].Eff, cells[b].Pre,
                                 interface(a, b), metric_I)
        if rho > tau_glue:
            # 优先补接口/插适配基元，绝不放宽 tau_glue
            patched = try_refine_interface(a, b) or try_insert_adapter(a, b)

            cells = patched
    delta = cocycle_residual(word.cycle, cells, transports_of(cells))
    if delta > tau_cocycle:
        return 'CompositionalReject', {'cycle': word.cycle, 'delta': delta}
    return 'CERTIFIED', glue_sections(cells)   # 局部截面粘成全局证书
```

- **P2（反例集中）**：若主要失效来自接口不完备，则 E89 的组合反例应集中在少数接口变量（力旋量重分配、抓取内力、时延）上；若均匀分散，则更可能是基元本身不 sound，应回 UOB。
- **P3（杠杆随维度）**：Λ 应由内蕴维 d_U+d_Z 解释；若实测 Λ 对 d 不敏感，说明 L_U/L_Z 标定被高估，Lipschitz 结构不成立，E91 失败。

回退：E87 覆盖不足 → 增基元或退回任务级模板；E88 迁移界失效 → 收紧 L_U/L_Z、缩小椭球，退回逐物体/逐参数证书；E89 粘合不可靠 → 关闭组合签发，只允许单基元 + SafeStop；E91 标度律不成立 → 停用规模外推、只报经验覆盖；E92 尾组崩溃 → 尾组强制人在环/弃权；E93 超预算 → 只保 L0 查表 + SafeStop 双态。

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 接口不完备：漏掉跨原语耦合 → 假粘合 | 高 | E89 红线 + 接口完备性审计（消融隐藏变量）；组合反例自动归因到「缺哪个接口」；宁可拒答不粘合 |
| 基元划分错误：把不同接触物理硬并成一族 | 高 | 按接触模式而非外观聚类；契约含接触模式前置；held-out 基元覆盖检验；基元可分裂回灌 |
| 物体嵌入坍缩：z 近而动力学远 → 假迁移 | 高 | 物理先验正则 + 多距离（拓扑/曲率/摩擦）联合门控；L_Z 实测上界；反例回灌 |
| 标度律外推过自信：支撑集外指数律失效 | 高 | 只在支撑集内报告；外推输出区间并降级 EMPIRICAL_ONLY；E91 红线 |
| 组合 CEGAR 组合爆炸 | 中 | 仅在线下、仅在失败接口上补全；限量预算 + 超限即拒答；优先插适配基元而非穷举 |
| 任务分解幻觉：VLA 提议看似合理但契约不可满足 | 中 | 词法层强制契约检查；未知/超参一律拒答；拒答样本作为示教请求 |
| 三态签发被误用为二态（把 EMPIRICAL 当 CERTIFIED） | 中 | 总线字段强制带 claim 标签；部署清单校验；运行期只认 CERTIFIED |

## 6. 本轮最大风险

**一句话**：把「通用操作」误当成「基元可自由组合」——一旦接口变量集漏掉跨原语的真实耦合（残余接触力、物体形变、抓取内力的重分配、执行时序），1-上闭链会在一个**不完整的接口**上「假闭合」，局部 sound 的基元组合出全局不 sound 的行为，而单基元测试与平均覆盖率都看不出来；因此 E89（组合反例搜索）与接口完备性审计必须作为红线，任一不达标即禁止组合签发、退回单体证书或 SafeStop。
