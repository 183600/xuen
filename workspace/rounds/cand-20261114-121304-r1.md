# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互的不确定性二分」IP-253~263；本轮灵感：「竞品分析」×「微调」）

> R69 教会系统在测试时提问，却没有教会它在部署之间学习。它是「会举手、不会复习」的考生：把 aleatoric 与 epistemic 分开，用流匹配采样暴露模态，用注视/探针/问句消解 epistemic；一旦消解失败就退回 R68。但 R69 有两个与学习有关的盲点。
>
> 第一，**内部不确定性没有参照系**。一个被数据坍缩掉的模式，在模型里概率为零，既不贡献 H_mode，也不进入 ECE；R69 的 MCG 用同分布留出集校准，考题与答案同源，坍缩与幻影都看不见。模型无法从内部知道自己「没学过什么」——你无法从自己的词汇表里发现一个从未听过的词。
>
> 第二，**交互数据被浪费了**。每一次提问都产生「状态—问句—回答—结果」记录，这是宝贵的改进信号；但 R69 只把它当审计证据，不当学习材料。原因也合理：回答可能是幻觉、误导、投毒——直接拿它微调，等于把「诚实的不知道」蒸馏成「被证实的错误」。
>
> 本轮两个灵感正好补上：
> - **竞品分析**提供一个外部参照系：不是抄竞品的功能表，而是构造一组异质、可核验的「对手策略」，用**差异化**定位自己看不见的空白；对手既是镜子，也是证人，还可能撒谎。
> - **微调**提供把差异化结论**固化为能力**的唯一通道；但微调是「写」，会破坏 R69 的零学习写操作不变式，也会让证书失效。因此必须把微调从「一次梯度更新」改造成「一次带证书的实验」：可归因、可验收、可回退、有最小必要编辑的缰绳。
>
> 核心命题：**用「竞品分析」构造外部盲区探针与差异化证据，用「带证书的微调」把经多源验证的能力缺口固化为可回退的适配器；对手只是证人不是真理，微调只是假设检验不是信仰。** 命名 **RIVAL-RAS**（Rival-Informed Verified Adaptation with Leash）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我凭什么知道自己不会什么？谁有资格当我的镜子？学到的东西怎样才算真的学到、且随时能退回去？**」——不确定性不只是一脚刹车或一句提问，它还是一面**对手之镜**和一条**可回退的学习缰绳**。

## 0. 直觉与动机

**灵感 1（竞品分析 = 外部参照系：盲区只能从外部看见）**
直觉：你无法通过内省发现自己没听过一个词。R69 的不确定性全部是 `p_θ` 的泛函（模态熵、流似然、ECE），而一个坍缩模式的 `p_θ` 质量恰好为零，任何连续的内部泛函都对它不敏感。竞品分析的价值不在于排名，而在于**构造对照集**：当一组异质对手在某个区域一致地成功，而我们连一个对应模态都采样不出来，这就不是「我们不确定」，而是「我们的假设空间里根本没有这块」。这是差分诊断（differential diagnosis），不是排行榜。

**灵感 2（竞品分析要区分「能力缺口」与「风格差异」）**
直觉：对手能做到而我们做不到，有两种完全不同的情况。一种是**能力缺口**——它有一个我们没有的模式（绕左 vs 绕右、抓取 vs 推走），补上它是真进步；另一种是**风格差异**——它只是换了个等价动作，模仿它既无收益又抹杀多样性。更危险的是第三种：**幻影**——我们有一个模式，对手都没有，外部探针也证伪，那该做的是剪枝而不是学习。竞品分析若只会「向最强的抄」，就会把风格当能力、把幻影当目标。因此必须先把缺口分成坍缩/幻影/精度/风格四类，只有前两类中的「可验证子集」才允许进入微调。

**灵感 3（微调 = 有缰绳的写入：观察者效应 + 遗忘 + 证书失效）**
直觉：R69 的核心不变式是「实时流零学习写操作」，因为在线写会破坏可复现性与安全证书。微调是离线写，但它同时制造三个问题：(i) **观察者效应**——微调改变了那个用来计算不确定性与证书的模型本身，旧证书不能自动续期；(ii) **灾难性遗忘**——补一个缺口可能弄坏一片已认证区域；(iii) **负迁移**——向对手学习可能连对手的幻觉一起学来。所以微调必须是**外科手术**：冻结底座、只加一个低秩适配器、在锚点集上做回归约束、用最小必要编辑闭合缺口、并且以「验收失败就整块丢弃」为默认。没有证书，就没有权重。

**灵感 4（竞品的独立性是证据的汇率：克隆面板只算一个证人）**
直觉：R69 已经用「k 个正交证据源一致」对抗交互投毒。R70 把同一条纪律搬到对手身上：十个同源、同架构、同训练集的竞品，意见一致并不比一个证人更有信息量——它们共享盲区。因此「对手数量」不是证据量，**有效独立对手数 R_eff** 才是。我们必须用重叠探针估计对手之间的错误相关性，对共谋/共享数据源降权；对会撒谎的对手，外部探针是唯一仲裁者。相关性不估计，竞品分析就会把「一群克隆的共识」误当成「外部真理」。

**灵感 5（外部探针 = 第三方仲裁，但也有可验证域）**
直觉：对手和我们可能一起错。需要一个既不在训练集、也不参与对手筛选的**外生对比探针**，它在稀有层上刻意加权，用来裁决「这个缺口是真的吗」。但探针不是上帝：它只在自身有统计功效的区域有发言权。于是定义**可验证域**——探针没覆盖的地方，缺口一律标为 unknown，保守地不学。否则竞品分析会退化成「探针剧场」：只在会做的题上宣称发现了新能力。

**灵感 6（竞品分析的 Goodhart：对手跑步机）**
直觉：如果长期只对固定面板优化，我们最终学会的是面板的怪癖，不是能力。对手也在更新，排行榜会被污染，预注册的阈值会被事后修改。防御是双重的：**影子对手**（不参与微调目标、只用于验收，且定期轮换）+ **预注册**（先锁指标与阈值，再看结果）。地图不是疆域，排行榜不是能力。

**灵感 7（交互日志不是标签，只是候选证据）**
直觉：R69 的对话记录里既有真信息也有毒。把它变成训练数据前，必须做来源验证：一条回答只有在「至少 k 个正交来源一致，且外部探针覆盖该区域」时才升级为标签；单源回答永远只进似然与审计。事后再被结果推翻的回答要反向标注。**一次对话不是一张标签。**

## 1. 形式化定义（增量：定义 310–324）

**定义 310（竞品面板与血统）** 面板 Π = {π_0 = 本机策略, π_1, …, π_R}。每个对手 π_r = (θ_r, A_r, h_r, v_r)：参数/架构、访问级别 A_r ∈ {black, gray, white}、血统哈希 h_r（训练数据与版本）、验证状态 v_r ∈ {verified, unknown, adversarial}。信任权重 w_r ∈ [0,1] 由血统独立性与外部探针重叠度给出；共享训练源、同架构、同检查点族的对手权重下调。面板可包含历史检查点、异构架构、开源策略与红队策略；**对手不保证诚实**。

**定义 311（差异化场与能力缺口）** 在区域 x 上，对本机 π_0 与对手 π_r 定义三元组：
- 优势 `A_r(x) = E[success | x, π_r] − E[success | x, π_0]`；
- 新颖度 `N_r(x) = mass{ m_r ∈ M_r(x) : ∀ m_0 ∈ M_0(x), W_2(m_r, m_0) > δ_match }`，即对手有、我们匹配不上的模态质量；
- 精度差 `Q_r(x)`：在已匹配模态上的代价/误差差。
差异化场 `D(x) = robust_agg_r{(A_r, N_r, Q_r)}`，聚合用截尾均值/中位数以抗单个撒谎者。能力缺口是 `N_r > 0`（坍缩型）或 `A_r < −margin ∧ 支持已匹配`（精度型）的**可验证**区域。

**定义 312（竞品可靠性与有效独立性）** 在重叠探针 Ω 上定义对手错误指示 `e_r(z) = 1[π_r 在 z 上错误或不被支持]`，两两错误相关 `ρ_{ij} = corr(e_i, e_j)`。有效独立对手数
`R_eff = (Σ_i w_i)² / (Σ_{i,j} w_i w_j ρ_{ij})`，其中 `ρ_{ii} = 1`。
`R_eff ≤ R`，等号当且仅当两两独立。**十个克隆面板的 R_eff ≈ 1**。`R_eff` 是竞品证据的「汇率」：后续 k-一致纪律按 R_eff 而非 R 计。

**定义 313（缺口四分类）**
- **坍缩 C**：本机在该区域几乎没有模态支撑，`∃ ≥ k` 个独立对手有支撑，且外部探针确认该区域存在可实现的模式；
- **幻影 P**：本机有模态，对手普遍无支撑，且外部探针证伪（或无法支持）；
- **精度 Q**：双方模态匹配，对手在代价/误差上显著更优，且探针确认；
- **风格 S**：双方成功率差在 ε_style 内，只是轨迹不同。
只有 C、Q 是「可学习缺口」；P 触发剪枝/降权；S 不是缺口，**不模仿、保留多样性**。无法判定者记为 unknown，保守不学。

**定义 314（差异化证据纪律）** 一条缺口可执行（actionable）当且仅当：
(i) 至少 k 个 `w_r ≥ w_min` 且两两 `ρ ≤ ρ_max` 的对手一致报告该缺口（按 R_eff 折算）；
(ii) 外生探针在该区域的检验功效 `≥ 1 − β`；
(iii) 任何单源对手、单次交互都不得单独定案（继承 R69 定义 293-iii）；
(iv) 存在 adversarial 标记的对手被直接排除或强降权。
形式化：**k-正交一致 + 探针仲裁**；缺一即 unknown。

**定义 315（外生对比探针与可验证域）** 探针集 𝒫_ext 来自独立托管、血统隔离、稀有层加权的数据集，**不参与训练、不参与面板筛选、不参与阈值调参**。可验证域 `V(𝒫_ext) = {x : 𝒫_ext 在 x 上的有效质量与检验功效 ≥ 1 − β}`。缺口落在 V 外一律 unknown；这使得「探针没覆盖就宣称发现新能力」在流程上不可能。

**定义 316（带证书微调 CPFT）** 底座参数 θ 冻结，只训练适配器 δθ（LoRA/前置层），目标
`L_CPFT = L_task + λ_g·L_gap + λ_a·L_anchor + λ_f·Ω_forget`
约束 `KL(π_{θ+δ} ‖ π_θ) ≤ ε_leash`、`‖δ‖ ≤ Δ_leash`；训练数据只用定义 319 的已验证集 D_ver。**验收条件**（全部满足才接受）：在影子对手上缺口闭合 `≥ Δ_gap`；锚点/回归退化 `≤ ε_reg`；重新测得的 `J_FLUID` 在有效域内仍 Valid；探针分数不降；编辑在缰绳内；独立审计通过。任一不满足 ⇒ 丢弃适配器，版本不变。

**定义 317（最小必要编辑与遗忘上界）** 选择 `δ* = argmin_δ R(δ)`，s.t. 缺口闭合 ≥ Δ_gap 且满足定义 316 约束，其中 R 为 Fisher 度量或参数范数。局部二次近似下遗忘 `≈ ½ δᵀ F δ`；故最小范数解在「闭合同一缺口」的编辑中使最坏遗忘最小。这是「微调缰绳」的定量含义：**不是不能学，而是学得越少越好，只要够用**。

**定义 318（证书保持验收与版本血统）** 每个版本 `v = (parent_hash, base_hash, adapter_hash, D_ver_hash, panel_snapshot_hash, J_RIVAL, ℛ_v, timestamp)`。部署仅当当前 `(w, q) ∈ ℛ_v` 且 `J_RIVAL` 有效。回滚 = 把适配器切回祖先，`O(1)`，不覆盖任何权重。**没有证书，就没有权重；证书可撤销，权重可退回。**

**定义 319（交互日志的来源验证与去毒）** R69 交互记录 `r = (o, g, y, outcome)`。标签信任 `T(r)` 由正交来源数、外部探针覆盖与事后结果共同决定；只有 `T(r) ≥ τ_T` 且来源数 `≥ k` 的记录进入 D_ver。单源回答只许进入似然/审计，不许进入监督目标；事后被结果推翻的回答做反向标注。**一次对话不是一张标签。**

**定义 320（反 Goodhart：影子对手与预注册）** 用于微调目标的可见面板 Π_vis 与用于验收的影子对手 π_shadow 严格分离；π_shadow 不参与任何梯度、目标或阈值选择，并定期轮换。微调开始前把（指标定义、阈值、面板快照、分析计划）的哈希预注册；任何修改都触发重新审计而非直接晋升。泛化差 `GG = gap(Π_vis) − gap(π_shadow)`；`GG > τ_gg` 判为面板过拟合，拒绝该次微调。

**定义 321（竞品跑步机与协同演化稳定性）** 面板与分布按 `Π_{t+1} = U(Π_t)`、`w_{t+1} = F(w_t, Π_t)` 演化。阻尼更新 `w_{t+1} = (1−η)w_t + η F(w_t, Π_t)` 在 `η·L_F < 1` 且面板漂移率有界时收敛；否则出现振荡或模式追逐。保留「新奇储备」（固定比例的历史对手不被替换）以打破闭环。

**定义 322（双环与不变式）** 实时环 = R69 原样：零学习写操作、`< 2.6ms`、交互预算与证据纪律不变。慢环（离线/运维节律）= 差异化场 → 缺口四分类 → 证据纪律 → 去毒 → CPFT → 影子验收 → 证书签发 → 部署/回滚。**R69 是本轮「无竞品、无探针、适配器为恒等、慢环关闭」的边界情形。**

**定义 323（RIVAL 审计器 VQAuditor-R）** 审计对象：缺口证据的血统与独立性、面板是否被污染/共谋、探针是否泄漏进训练、是否把幻影当目标蒸馏、证书作用域是否被越界、回滚演练是否通过、微调目标是否预注册。结论回灌 AuditBuf，成为下一轮面板信任与探针预算的先验。

**定义 324（证书 J_RIVAL）** `J_RIVAL = (J_FLUID, panel_snapshot_hash, R_eff, gap_class, probe_hash/power, D_ver_hash, adapter_hash, edit_leash, shadow_gap, rollback_drill_hash, rival_ver)`。Valid ⇔ `Valid(J_FLUID)` ∧ 证据纪律满足 ∧ 影子验收通过 ∧ 探针未泄漏 ∧ 独立审计通过 ∧ 版本血统完整。

```python
# IP-264 RDP：竞品差异化场（离线；面板与部署解耦）
class RivalDifferential:
    def __init__(self, panel, probe):
        self.panel, self.probe = panel, probe

    def field(self, regions, self_policy):
        out = {}
        for x in regions:
            my_modes = self_policy.modes(x)
            rec = []
            for r in self.panel.rivals:
                if not r.can_access(x):
                    continue
                A = r.success(x) - self_policy.success(x)
                N = unmatched_mass(r.modes(x), my_modes, delta_match=DELTA)
                Q = precision_gap(r, self_policy, x)
                rec.append((r.id, A, N, Q))
            out[x] = robust_aggregate(rec, self.panel.trust)  # 截尾/中位数
        return out

# IP-265 GCM：缺口四分类（坍缩 / 幻影 / 精度 / 风格）
def classify_gap(rec, my_modes, probe):
    if rec.N > N_TAU and probe.supports(rec.region, power=1 - BETA):
        return 'collapse'            # 可微调目标
    if rec.N > N_TAU and probe.rejects(rec.region):
        return 'phantom'             # 剪枝，绝不微调
    if rec.Q > Q_TAU and probe.supports(rec.region, power=1 - BETA):
        return 'precision'           # 可微调目标
    if abs(rec.A) <= STYLE_TAU:
        return 'style'               # 不模仿，保留多样性
    return 'unknown'                 # 超出可验证域，保守不学

# IP-266 RIR：有效独立性（克隆面板只算一个证人）
def effective_independence(panel, probe):
    errs = {r.id: r.error_vector(probe) for r in panel.rivals}
    rho  = pairwise_corr(errs)
    w    = panel.trust
    R_eff = (sum(w.values()) ** 2 /
             sum(w[i] * w[j] * rho[i][j] for i in errs for j in errs))
    return R_eff, rho

# IP-267/268 证据纪律 + 外生探针（探针是仲裁者）
def actionable(gap, panel, probe, rho):
    witnesses = [r for r in panel.rivals
                 if r.agrees(gap) and panel.trust[r.id] >= W_MIN]
    indep = [r for r in witnesses
             if all(rho[r.id][s.id] <= RHO_MAX
                    for s in witnesses if s is not r)]
    return (len(indep) >= K
            and probe.power(gap.region) >= 1 - BETA
            and gap.region in probe.verifiable_region)   # 单源永不定案

# IP-269/270 CPFT + 缰绳：最小必要编辑，带证书验收
def cpft(base, gap, D_ver, anchors, leash, panel, probe):
    delta = train_adapter(base, gap, D_ver, anchors,
                          lam_g=LAM_G, lam_a=LAM_A, lam_f=LAM_F,
                          kl_budget=leash.kl, l2_budget=leash.l2)
    cand = base.with_adapter(delta)
    ok = (gap_closure(cand, gap, panel.shadow) >= DELTA_GAP
          and anchor_regression(cand, anchors) <= EPS_REG
          and recertify(cand, gap.valid_region).valid
          and probe.score(cand) >= probe.score(base) - EPS_PROBE
          and delta.kl <= leash.kl and delta.norm <= leash.l2
          and auditor.passed(cand, gap))
    return delta if ok else None        # 没有证书，就没有权重

# IP-271 PVD：交互日志 → 可训练数据（一次对话不是标签）
def to_training_data(interaction_log, panel, probe):
    D = []
    for r in interaction_log:
        sources = independent_sources(r, panel)      # 至少 k 个正交来源
        if len(sources) >= K and agree(sources) and probe.covers(r.region):
            D.append(r.with_trust(min_trust(sources)))
        # 单源回答只进似然/审计，不进监督标签
    return D

# IP-272 GGE：影子对手 + 预注册（防止教到考卷上）
def shadow_accept(cand, gap, shadow, prereg):
    if not prereg.matches(current_metric(), current_threshold()):
        return False                    # 改考题 = 重审，不是晋升
    return gap_closure(cand, gap, shadow) >= DELTA_GAP_SHADOW

# IP-275 慢环主流程（实时环完全复用 R69）
def RIVAL_slow_loop(M):
    field = RDP.field(M.regions, M.policy)
    R_eff, rho = RIR.estimate(M.panel, M.probe)
    for region, rec in field.items():

        if gap not in ('collapse', 'precision'):
            continue

            continue

                         M.leash, M.panel, M.probe)

            M.deploy(cand, J)           # 否则保留旧版本
    if M.auditor.flags_panel_contamination(M.panel):
        M.revoke(M.deployed.cert)
        M.rollback()                    # 证书撤销 → 回到祖先适配器

# IP-275 实时环：R69 逐指令复用，零学习写

    return M.fluid.step(obs)            # k, lam, mode, (U_ale, U_epi)
```

## 3. 推导

**假设** A99（面板有效性）：存在至少 k 个血统隔离、两两错误相关 `ρ ≤ ρ_max` 的对手，且探针在目标区域有功效 ≥ 1−β；A100（证书可靠性）：验收测试与 J_FLUID 复核在有效域内是可靠的，回滚是精确的；A101（局部光滑）：策略损失在底座附近可二次近似，Fisher 矩阵良定；A102（探针隔离）：外生探针不泄漏进训练或面板选择，且在可验证域上有可分性。

**引理 19（内部盲区的不可观测性）** 令 U 为任意连续依赖于 `p_θ` 的不确定性泛函（模态熵、流似然、ECE、MCG 均属此类）。若真实模式 m 在本机模型下的支撑为零 `p_θ(m|x) = 0`，则 U 对 m 的存在不敏感；更形式化地，两个在训练支撑上一致、但一个缺 m 的模型可以给出相同的 U 值。故**坍缩只能由外部对照（对手或探针）揭示**，内部校准无法自证。系：R69 的 MCG 越「漂亮」，越可能只是证明了考题与答案同源。

**引理 20（竞品相关性汇率）** 设每个对手独立误报缺口的概率为 δ，两两错误相关为 ρ。k 个对手全部误报的概率在正相关下满足 `P(all wrong) ≥ δ·ρ^{k−1}`（ρ=0 时退化为 δ^k）。故以面板人数 R 代替有效独立数 R_eff 会系统性高估证据强度；用定义 312 的 R_eff 折算后，错误接受率才回到 `δ·ρ^{R_eff−1}` 量级。系：**共享数据源/同架构的竞品必须先降权，再计数。**

**引理 21（幻影蒸馏上界）** 若某「缺口」实为幻影，探针以概率 `1−β` 正确拒绝它，微调目标权重为 λ_g。则未经验收的微调使幻影质量期望增加 `≥ λ_g·(1−β)·L_g`（L_g 为缺口损失的 Lipschitz 常数）；经过定义 314 的探针仲裁后，幻影进入训练的概率不超过 β，故期望污染 `≤ λ_g·β·L_g + ε_σ`。系：**探针功效是把「向对手学习」与「向对手的幻觉学习」分开的那道闸门。**

**引理 22（最小充分编辑的遗忘上界）** 在 A101 与局部二次近似下，适配器 δ 引起的锚点性能退化满足 `forget(δ) ≤ ½·δᵀFδ + O(‖δ‖³)`。因此在闭合同一缺口的所有编辑中，定义 317 的最小 Fisher 范数解使最坏遗忘最小；低秩适配器（仅更新低曲率子空间）是该界的一个可实现近似。系：**微调的风险不主要来自「学了什么」，而来自「顺带改了多少」。**

**定理 18（CPFT 的单调安全与严格包含 R69）** 在 A99–A102 下，若每次部署都通过定义 316 的验收与定义 318 的血统检查，则任意被接受的版本在有效域 ℛ_v 上的认证风险不高于其父版本；被拒绝的版本不改变部署；面板污染时证书撤销并回滚到祖先。且当面板为空、探针为空、适配器为恒等（δ=0）、慢环关闭时，RIVAL 与 FLUID-RAS **逐指令相同**。故 R68/R69 是本轮在「不竞品、不微调」边界上的严格退化，安全侧不做任何让步。

**定理 19（影子对手与竞品过拟合）** 固定可见面板 Π_vis 反复微调时，`gap(Π_vis)` 可随轮次趋于零，但若 Π_vis 与真实能力（由影子对手/外部探针代表）存在不相交盲区，则 `gap(π_shadow)` 可保持 `≥ g* > 0`；于是「面板上的进步」与「能力上的进步」分离。加入定义 320 的影子验收与预注册后，报告增益在影子对手上是无偏估计，泛化差 `GG` 可被检测；轮换影子对手使检测功效随轮次累积。系：**没有影子对手的竞品分析，最终只会教会模型通过竞品分析的考试。**

**定理 20（竞品跑步机的收敛与振荡）** 对定义 321 的阻尼更新，若 `η·L_F < 1` 且每轮面板漂移 `D(Π_t, Π_{t+1}) ≤ ρ_p`，则缺口估计序列收敛到不动点邻域，半径 `O(ρ_p/(1−ηL_F))`；若 `η·L_F ≥ 1`，存在参数区间使序列进入极限环（模式追逐）。保留新奇储备相当于给 `F` 加一个收缩的历史项，可消除极限环。系：**竞品面板必须慢慢换、且永远留一部分旧对手，否则系统会在两个「最新潮流」之间来回横跳。**

## 6. 本轮最大风险

**一句话**：RIVAL-RAS 把「能力进步」押在「竞品面板是可信的外部参照系」上——**一旦面板共享盲区、被污染、或策略性撒谎，竞品分析就会制造一个假缺口，微调再把这个假缺口固化成带证书的「能力」；系统于是从 R69 的「问错」升级为「照错镜子还学以致用」——照错镜子，比不看镜子更危险。**

**次级风险与缓解**：
1. **面板相关性被低估**（克隆/同源/共谋）→ 定义 312 的 R_eff + 重叠探针 + 血统降权，绝不按人数计证据；
2. **探针泄漏/探针剧场** → 探针独立托管、血统隔离、定义 315 的可验证域，V 外一律不学；
3. **幻影被蒸馏** → 定义 314 探针仲裁 + 引理 21 上界 + E306 对抗测试，单源/无探针缺口永不微调；
4. **证书失效与遗忘** → 定义 316–318 的验收 + 最小必要编辑 + O(1) 回滚，验收不过整块丢弃；
5. **竞品跑步机/Goodhart** → 定义 320 影子对手 + 预注册 + 定义 321 阻尼与新奇储备；
6. **交互日志投毒** → 定义 319 来源验证，单源回答只进似然不进标签，事后结果反向标注。

## 2. 形式化定义（要点版）

**定义 310（竞品面板与血统）** `Π={π_0,…,π_R}`；每个对手带访问级别、血统哈希与验证状态；共享训练源/同架构降权；**对手不保证诚实**，可含 adversarial 对手。

**定义 311（差异化场与能力缺口）** `A_r(x)=E[succ|π_r]−E[succ|π_0]`；`N_r(x)` 为对手有、本机匹配不上的模态质量；`Q_r(x)` 为已匹配模态上的精度差。差异化场用截尾均值/中位数抵抗单个撒谎者；能力缺口是 `N_r>0` 或 `A_r<−margin ∧ 支持已匹配` 的可验证区域。

**定义 312（有效独立性）** 用重叠探针估计错误相关 `ρ_ij`；`R_eff=(Σw)²/(Σ w_i w_j ρ_ij)`，`ρ_ii=1`。十个克隆面板的 `R_eff≈1`；k-一致纪律按 R_eff 而非人数计。

**定义 313（缺口四分类）** 坍缩 C：本机无支撑、≥k 独立对手有支撑且探针确认；幻影 P：本机有、对手无且探针证伪；精度 Q：双方匹配但对手显著更优且探针确认；风格 S：成功率相当、轨迹不同。仅 C、Q 可学；P 剪枝；S 不模仿；无法判定记 unknown。

**定义 314（差异化证据纪律）** actionable ⇔ ≥k 个 `w_r≥w_min`、两两 `ρ≤ρ_max` 的对手一致 + 探针功效 `≥1−β` + 单源/单次不定案 + adversarial 对手排除。即「k-正交一致 + 探针仲裁」。

**定义 315（外生探针与可验证域）** `𝒫_ext` 独立托管、血统隔离、稀有层加权，不参与训练/面板筛选/调参；`V={x: 探针功效≥1−β}`。V 外缺口一律 unknown，禁止「探针没覆盖就宣称发现新能力」。

**定义 316（CPFT）** 冻结底座，只训适配器；`L_CPFT=L_task+λ_g L_gap+λ_a L_anchor+λ_f Ω_forget`，约束 `KL≤ε_leash`、`‖δ‖≤Δ_leash`；验收：影子缺口闭合达标、锚点退化 ≤ε_reg、J_FLUID 复核有效、探针不降、编辑在缰绳内、审计通过。任一失败 ⇒ 丢弃。

**定义 317（最小必要编辑）** `δ*=argmin R(δ)` s.t. 缺口闭合 ≥Δ_gap；局部二次下遗忘 `≈½δᵀFδ`，故最小范数解使最坏遗忘最小。微调的风险不主要来自「学了什么」，而来自「顺带改了多少」。

**定义 318（证书保持与版本血统）** 版本 `(parent, base, adapter, D_ver, panel, J_RIVAL, ℛ_v)`；部署要求当前 `(w,q)∈ℛ_v` 且证书有效；回滚 = 切回祖先适配器，`O(1)`；**没有证书，就没有权重；证书可撤销，权重可退回**。

**定义 319（交互日志来源验证与去毒）** 记录 `(o,g,y,outcome)`；标签信任由正交来源数、探针覆盖、事后结果决定；只有 `T(r)≥τ_T ∧ 来源数≥k` 进入 D_ver；单源回答只进似然/审计；被结果推翻的回答反向标注。**一次对话不是一张标签。**

**定义 320（反 Goodhart）** 可见面板 Π_vis 只用于微调目标；影子对手 π_shadow 只用于验收并定期轮换；微调前预注册指标/阈值/面板快照；`GG=gap(Π_vis)−gap(π_shadow)>τ_gg` 判为面板过拟合并拒绝。

**定义 321（竞品跑步机）** 面板与分布演化；阻尼更新 `w_{t+1}=(1−η)w_t+ηF`，`ηL_F<1` 且漂移有界时收敛，否则极限环；保留新奇储备（历史对手）消除振荡。

**定义 322（双环与不变式）** 实时环 = R69 原样（零学习写、<2.6ms、交互预算与证据纪律不变）；慢环离线完成差异化→分类→证据→去毒→CPFT→影子验收→证书/回滚。R69 = 无竞品、无探针、δ=0、慢环关闭的退化情形。

**定义 323（RVA 审计器）** 审计面板独立性/污染、探针泄漏、幻影蒸馏、证书作用域、回滚演练、预注册一致性；结论回灌 AuditBuf 作为下一轮面板信任与探针预算的先验。

**定义 324（证书 J_RIVAL）** `J_RIVAL=(J_FLUID, panel_hash, R_eff, gap_class, probe_hash/power, D_ver_hash, adapter_hash, edit_leash, shadow_gap, rollback_drill_hash, rival_ver)`。Valid ⇔ J_FLUID 有效 ∧ 证据纪律 ∧ 影子验收 ∧ 探针未泄漏 ∧ 审计通过 ∧ 血统完整。

## 3. 关键算法伪代码

```python
# IP-264 RDP：竞品差异化场（离线）
class RivalDifferential:
    def field(self, regions, self_policy):
        out = {}
        for x in regions:
            my_modes = self_policy.modes(x)
            rec = []
            for r in self.panel.rivals:
                if not r.can_access(x):
                    continue
                A = r.success(x) - self_policy.success(x)
                N = unmatched_mass(r.modes(x), my_modes, delta_match=DELTA)
                Q = precision_gap(r, self_policy, x)
                rec.append((r.id, A, N, Q))
            out[x] = robust_aggregate(rec, self.panel.trust)  # 截尾/中位数
        return out

# IP-265 GCM：缺口四分类
def classify_gap(rec, my_modes, probe):
    if rec.N > N_TAU and probe.supports(rec.region, power=1 - BETA):
        return 'collapse'            # 可微调目标
    if rec.N > N_TAU and probe.rejects(rec.region):
        return 'phantom'             # 剪枝，绝不微调
    if rec.Q > Q_TAU and probe.supports(rec.region, power=1 - BETA):
        return 'precision'           # 可微调目标
    if abs(rec.A) <= STYLE_TAU:
        return 'style'               # 不模仿，保留多样性
    return 'unknown'                 # 超出可验证域，保守不学

# IP-266 RIR：有效独立性（克隆面板只算一个证人）
def effective_independence(panel, probe):
    errs = {r.id: r.error_vector(probe) for r in panel.rivals}
    rho  = pairwise_corr(errs)
    w    = panel.trust
    R_eff = (sum(w.values()) ** 2 /
             sum(w[i] * w[j] * rho[i][j] for i in errs for j in errs))
    return R_eff, rho

# IP-267/268 差异化证据纪律 + 外生探针仲裁
def actionable(gap, panel, probe, rho):
    witnesses = [r for r in panel.rivals
                 if r.agrees(gap) and panel.trust[r.id] >= W_MIN]
    indep = [r for r in witnesses
             if all(rho[r.id][s.id] <= RHO_MAX
                    for s in witnesses if s is not r)]
    return (len(indep) >= K
            and probe.power(gap.region) >= 1 - BETA
            and gap.region in probe.verifiable_region)   # 单源永不定案

# IP-269/270 CPFT + 缰绳：最小必要编辑，带证书验收
def cpft(base, gap, D_ver, anchors, leash, panel, probe):
    delta = train_adapter(base, gap, D_ver, anchors,
                          lam_g=LAM_G, lam_a=LAM_A, lam_f=LAM_F,
                          kl_budget=leash.kl, l2_budget=leash.l2)
    cand = base.with_adapter(delta)
    ok = (gap_closure(cand, gap, panel.shadow) >= DELTA_GAP
          and anchor_regression(cand, anchors) <= EPS_REG
          and recertify(cand, gap.valid_region).valid
          and probe.score(cand) >= probe.score(base) - EPS_PROBE
          and delta.kl <= leash.kl and delta.norm <= leash.l2
          and auditor.passed(cand, gap))
    return delta if ok else None        # 没有证书，就没有权重

# IP-271 PVD：交互日志 → 可训练数据（一次对话不是标签）
def to_training_data(interaction_log, panel, probe):
    D = []
    for r in interaction_log:
        sources = independent_sources(r, panel)      # 至少 k 个正交来源
        if len(sources) >= K and agree(sources) and probe.covers(r.region):
            D.append(r.with_trust(min_trust(sources)))
        # 单源回答只进似然/审计，不进监督标签
    return D

# IP-272 GGE：影子对手 + 预注册
def shadow_accept(cand, gap, shadow, prereg):
    if not prereg.matches(current_metric(), current_threshold()):
        return False                    # 改考题 = 重审，不是晋升
    return gap_closure(cand, gap, shadow) >= DELTA_GAP_SHADOW

# IP-275 慢环主流程（实时环完全复用 R69）
def RIVAL_slow_loop(M):
    field = RDP.field(M.regions, M.policy)
    R_eff, rho = RIR.estimate(M.panel, M.probe)
    for region, rec in field.items():
        gap = GCM.classify(rec, M.policy.modes(region), M.probe)
        if gap not in ('collapse', 'precision'):
            continue
        if not DED.actionable(rec, M.panel, M.probe, rho):
            continue
        D_ver = PVD.to_training_data(M.interaction_log, M.panel, M.probe)
        delta = CPFT.fit(M.policy, rec, D_ver, M.anchors,
                         M.leash, M.panel, M.probe)
        if delta is None:
            continue
        cand = M.policy.with_adapter(delta)
        if not GGE.shadow_accept(cand, rec, M.panel.shadow, M.prereg):
            continue
        J = issue_certificate(cand, M.panel, M.probe, delta, M.auditor)
        if J.valid:
            M.deploy(cand, J)           # 否则保留旧版本
    if M.auditor.flags_panel_contamination(M.panel):
        M.revoke(M.deployed.cert)
        M.rollback()                    # 证书撤销 → 回到祖先适配器

# IP-275 实时环：R69 逐指令复用，零学习写
def RIVAL_round(M, obs):
    return M.fluid.step(obs)            # k, lam, mode, (U_ale, U_epi)
```

## 4. 推导

**假设** A99（面板有效性）：至少 k 个血统隔离、两两错误相关 `ρ≤ρ_max` 的对手，探针功效 ≥1−β；A100（证书可靠性）：验收与 J_FLUID 复核在有效域内可靠，回滚精确；A101（局部光滑）：策略损失在底座附近可二次近似，Fisher 良定；A102（探针隔离）：探针不泄漏进训练/面板选择，且在可验证域可分。

**引理 19（内部盲区的不可观测性）** 任意连续依赖 `p_θ` 的不确定性泛函 U（模态熵、流似然、ECE、MCG）对「支撑为零的真实模式」不敏感；两个在训练支撑上一致、但一个缺该模式的模型可给出相同 U。故**坍缩只能由外部对照揭示**。系：R69 的 MCG 越漂亮，越可能只证明考题与答案同源。

**引理 20（竞品相关性汇率）** 对手独立误报概率 δ、两两错误相关 ρ 时，k 个全误报概率在正相关下 `≥δ·ρ^{k−1}`（ρ=0 退化为 δ^k）。用人数 R 代替 R_eff 会系统性高估证据；按定义 312 折算后才回到 `δ·ρ^{R_eff−1}` 量级。系：共享数据源/同架构竞品必须先降权再计数。

**引理 21（幻影蒸馏上界）** 若「缺口」实为幻影，探针以 `1−β` 正确拒绝，微调权重 λ_g；未经验收的微调使幻影质量期望增加 `≥λ_g(1−β)L_g`；经探针仲裁后进入训练的概率 ≤β，期望污染 `≤λ_g β L_g+ε_σ`。系：探针功效是「向对手学习」与「向对手幻觉学习」之间的闸门。

**引理 22（最小充分编辑的遗忘上界）** 局部二次近似下 `forget(δ)≤½δᵀFδ+O(‖δ‖³)`；最小 Fisher 范数解在闭合同一缺口的编辑中使最坏遗忘最小；低秩适配器是其在低曲率子空间上的可实现近似。系：风险主要来自「顺带改了多少」。

**定理 18（CPFT 单调安全与严格包含 R69）** A99–A102 下，通过定义 316 验收与 318 血统检查的版本在 ℛ_v 上认证风险不高于父版本；被拒版本不改变部署；面板污染则撤销并回滚。当面板/探针为空、δ=0、慢环关闭时，RIVAL 与 FLUID-RAS 逐指令相同。故 R68/R69 是本轮「不竞品、不微调」边界上的严格退化，安全侧不让步。

**定理 19（影子对手与竞品过拟合）** 固定 Π_vis 反复微调可使 `gap(Π_vis)→0`，但若 Π_vis 与真实能力（影子/探针代表）存在不相交盲区，则 `gap(π_shadow)≥g*>0` 可保持，面板进步与能力进步分离。加入影子验收与预注册后，影子上的增益是无偏估计，GG 可检测；轮换影子使检测功效随轮次累积。系：没有影子对手的竞品分析，只会教会模型通过竞品分析的考试。

**定理 20（竞品跑步机的收敛与振荡）** 阻尼更新下，若 `ηL_F<1` 且面板漂移 `D(Π_t,Π_{t+1})≤ρ_p`，缺口估计收敛到半径 `O(ρ_p/(1−ηL_F))` 的不动点邻域；若 `ηL_F≥1`，存在参数区间进入极限环（模式追逐）。新奇储备等价于给 F 加收缩历史项，可消除极限环。系：面板要慢慢换且永远留一部分旧对手。

## 7. 本轮最大风险

**一句话**：RIVAL-RAS 把「能力进步」押在「竞品面板是可信的外部参照系」上——**一旦面板共享盲区、被污染或策略性撒谎，竞品分析就会制造假缺口，微调再把它固化成带证书的「能力」；系统从 R69 的「问错」升级为「照错镜子还学以致用」——照错镜子，比不看镜子更危险。**

**次级风险与缓解**：面板相关性被低估（R_eff + 重叠探针 + 血统降权）；探针泄漏/探针剧场（独立托管 + 血统隔离 + 可验证域，V 外不学）；幻影被蒸馏（探针仲裁 + 引理 21 + E306，单源缺口永不微调）；证书失效与遗忘（CPFT 验收 + 最小必要编辑 + O(1) 回滚）；竞品跑步机/Goodhart（影子对手 + 预注册 + 阻尼更新 + 新奇储备）；交互日志投毒（来源验证，单源只进似然不进标签，事后结果反向标注）。
