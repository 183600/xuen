# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「自然语言指令」×「轻量化结构」）

> 第 60 轮用 SGEC 打通了「场景→意图→约束→阻抗→执行→EV-exec→场景更新」闭环：SSM 给出场景-阻抗先验，CIEC 用固定意图字典把「慢点/轻触」映射为约束，EPIR 用序列号+哈希保证 ROS 证据链完整，PCE++++ 记账四维认知预算。但它在真实人机协作中暴露了**三个结构性局限**：
> 1. **自然语言指令的开放性与组合性缺失**：CIEC 只有 5 个硬编码意图（slow_down / speed_up / light_touch / stable / danger）。真实指令是「稍微慢一点，但别太软」「接触后保持 3 秒」「如果打滑就立刻停」——含强度修饰、否定、条件、时序、指代与省略。字典查表既无法表达组合语义，更无法证明「执行轨迹是否真的满足了这句话」。一个「不要抓紧」被漏掉否定词，执行层就会灾难性加紧。
> 2. **认知层的轻量化缺失**：SGEC 把场景滤波器、意图控制器、EPIR 影子副本、四维预算、SIC 三元组全部堆到边缘端；若再接一个大语言模型做理解，延迟与内存都不可接受。第 60 轮的 `B_cog` 只是「记账」，**没有「瘦身」**——它约束了花多少，却没定义结构本身有多轻。
> 3. **接地正确性无证书**：意图→约束是开环映射。CIEC 锁定了 ERTC 契约，却没有任何机制验证「锁定的约束在执行轨迹上满足原句语义」。语言层的错误没有任何执行层证据可以反驳。

## 0. 直觉与动机

**灵感 1（自然语言指令 → 组合式约束表达式树 CET）**
直觉：一句指令不是标签，而是一棵**带类型的算子树**。「稍微」是作用在阈值上的单调修饰函数；「抓紧」是 `F_min ↑` 的原子算子；「但」是 AND 组合子；「如果打滑就停」是 `⇒` 条件子；「接触后保持 3 秒」是 `U`（until）时序子。关键洞见：**只要把接地函数定义成对组合子同态**（`g(Γ₁∧Γ₂)=g(Γ₁)∩g(Γ₂)`），就能从少量原子算子的语义推出无限组合指令的语义，并让「语言→约束」第一次具备可证明性。

**灵感 2（轻量化结构 → 双层结构压缩）**
直觉：轻量化不是「少算几个数」，而是**换一种更省的表示**，分两层：
- **语义结构轻量化**：不接大模型，而用「短语原型库 P + ≤50 条产生式的微型依存文法 + Matryoshka 嵌套编码器」；解析按预算逐级展开，能早退就早退。绝大多数指令（「慢点」「轻触」）只需 1~2 次原型查找。
- **阻抗结构轻量化**：完整对称阻抗矩阵有 21 个独立自由度，但物理上阻抗通常是「任务框架对角主项 + 少量低秩耦合」。用 `K = B diag(λ) Bᵀ + Σ_{j=1}^r σ_j u_j u_jᵀ`（r≤2）表示，语言只允许修改**活跃坐标集 A（|A|≤9）**。关键洞见：**语言作用在低维结构坐标上，而不是完整矩阵上**——这既省算力，又让「语义改动对稳定性/无源性的影响」可以被一个小 LMI 区域界定。

**灵感 3（接地正确性 → STL 接地证书 IGC）**
直觉：说「保持 3 秒」，就用信号时序逻辑（STL）写 `G[0,3](hold)`；说「别太软」，就写 `G(F ≥ F_min)`。执行轨迹 τ 的 STL 鲁棒度 `ρ_φ(τ)` 是一个**有符号的满足程度**：ρ≥0 即满足，ρ<0 可量化违反多深。关键洞见：**把自然语言指令变成可被 EV-exec 检验的证书 J_nl**，让第 60 轮的执行证据链第一次能够「反证语言」。

**灵感 4（冲突与歧义 → 约束格 + 歧义感知澄清）**
直觉：语言天然自相矛盾（「快点但轻点」有时可行、有时不可行）。把语言约束 `C_ℓ`、场景先验 `C_scene`、实时契约 `C_rt` 放进同一个**约束格**取交：`C* = C_ℓ ⊓ C_scene ⊓ C_rt`。若交集为空，**只在安全域内松弛语言**（语言可退让，安全不可退让）。若解析熵过高（「它」指谁？「抓紧」多紧？），用 VOI 判断是否值得问一句澄清。关键洞见：**歧义不是错误，是需要定价的不确定性**。

**灵感 5（三灵感合流 → LGS 语言接地轻量结构闭环）**
直觉：形成闭环 **指令→轻量解析→CET→约束格→结构化阻抗→执行→STL 证书→原型库/场景信念更新**。语言改结构坐标、执行证据校准语言置信度、场景先验约束语言的安全性。再以「轻量化契约」保证：相对 SGEC，延迟 ≤0.3×、内存 ≤0.5×，同时接地证书有效率 ≥1−δ。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（组合式指令语义 CET）** 指令语义形式 `s = ⟨Γ, T, ρ_anchor⟩`，其中：
- **约束表达式树** Γ 由叶子算子与组合子递归构成：
  - 叶子 `o = (d, ⊵, θ_o, μ)`：维度 `d ∈ D`，关系 `⊵ ∈ {≤, ≥, ≈}`，阈值 `θ_o`，强度修饰 `μ`；
  - 修饰函数 `m_μ: R→R` 单调（如 `m_轻微(x)=0.75x`、`m_稍(x)=0.6x`、`m_明显(x)=0.35x`、`m_大幅(x)=0.15x`，作用于目标值）；
  - 组合子 `∘ ∈ {∧, ∨, ;(时序), U(until), ⇒(条件), ¬(否定/松弛)}`；
- **时间域** `T`：`instant`、区间 `[t_s,t_e]`、事件锚 `until(event)`；
- **指代锚** `ρ_anchor`：解析「它/刚才/再/保持」时绑定的历史状态或场景实体。
- **接地函数** `g_θ: s → C_ℓ ⊆ R^d`，满足组合同态：
  ```
  g_θ(Γ₁ ∧ Γ₂) = g_θ(Γ₁) ∩ g_θ(Γ₂)
  g_θ(Γ₁ ∨ Γ₂) = conv(g_θ(Γ₁) ∪ g_θ(Γ₂))
  g_θ(¬Γ)       = 安全域 C_rt 内的松弛算子（不允许越过安全域取补）
  g_θ(Γ₁ ; Γ₂)  = 时序拼接约束（先 Γ₁ 后 Γ₂）
  ```
  例：ℓ=「稍微慢一点但抓紧，接触后保持 3 秒」⇒
  `Γ = (v_max ≤ m_稍(v_nom)) ∧ (F_min ≥ m_稍^{-1}(F_nom)) ; U(contact) ; G[0,3](hold)`。

**定义 162（轻量原型编译器 LPC）** `LPC = (E_φ, P, G_grammar)`：
- **轻量编码器** `E_φ`：蒸馏/量化后的短语编码器，参数量 ≤ 200K 或 ≤ teacher 的 1%；Matryoshka 嵌套表征 `E_φ(x) = [e^{(1)} | e^{(2)} | … | e^{(L)}]`，可在第 l 级早退；
- **原型库** `P = {(e_i, o_i, c_i)}_{i=1}^{M}`：短语原型嵌入、原子算子、置信半径；
- **微型文法** `G_grammar`：≤50 条产生式，把原型序列组装为 CET；
- 解析规则：`o* = argmin_i ||E_φ(p) − e_i||`；若 `min_i d_i > c_i` 则判为未覆盖（走澄清）；复杂度 `O(L·M·d_e)`，常指令 1~2 级早退。

**定义 163（结构化阻抗 SIR）** 阻抗表示为
```
K = B diag(λ) Bᵀ + Σ_{j=1}^{r} σ_j u_j u_jᵀ,   λ∈R^6, σ_j≥0, r≤2
```
- `B` 为任务框架基（固定，不学习）；`u_j` 为耦合方向。
- **活跃坐标集** `A ⊆ {1,…,6+r}`，`|A| ≤ m_max = 9`；语言只生成 `Δθ_K`（仅 A 上非零）。
- 投影算子 `Π_S(K)` 与逼近误差 `ε_K = sup_K ||K − Π_S(K)||_F`。
- **轻量化契约**：`|θ_K| ≤ 0.5·|K_sym|`，编译时延 `L_compile ≤ 0.3·L_compile^SGEC`。

**定义 164（约束格接地 CLG）** 约束格 `(C, ⊑, ⊓, ⊔, ⊥, ⊤)`，元素为凸约束域（盒/椭球/多面体之交）：
```
C* = C_ℓ ⊓ C_scene ⊓ C_rt
```
- `C_ℓ` 来自 CET 接地；`C_scene` 来自 SSM 场景先验；`C_rt` 来自 ERTC 实时契约。
- 若 `C* = ∅`：不允许扩大 `C_rt`/`C_scene`，只在安全域内对语言做最近投影
  `C* = argmin_{C ⊆ C_rt∩C_scene} dist(C, C_ℓ)`，
  其中 `dist` 用区间/支撑函数距离；同时记录**松弛证书** `J_relax = (dist, 被松弛维度)`。
- **安全优先序**：`C_rt ∩ C_scene` 是硬边界，语言约束是可退让的软边界。

**定义 165（歧义感知澄清 AMB）** 给定解析候选 `{(o_i,p_i)}`：
- 解析熵 `H(ℓ) = −Σ_i p_i log p_i`，`p_i ∝ exp(−d_i² / 2c_i²)`；
- 澄清策略 `π_clar`：
  - 若 `C_ℓ` 与 `C_rt` 冲突 ⇒ **必须澄清**（不可默认）；
  - 若 `H(ℓ) > τ_H` 且存在保守交集 ⇒ 计算澄清收益
    `VOI_clar = E[ΔC_error] − λ_turn·cost(turn)`，仅当 `VOI_clar > 0` 才发问；
  - 否则用保守默认（取 `μ` 的最小强度）。
- 澄清轮数受 `B_clar` 约束。

**定义 166（指令接地证书 IGC）** 将 CET 编译为 STL 公式 `φ_ℓ`：
- 阈值约束 `x_d ⊵ θ` ⇒ `G[t_s,t_e](x_d ⊵ θ)`；
- 时序 `;` / `U` ⇒ `Until` / `Since`；条件 `⇒` ⇒ `G(cond ⇒ ψ)`；
- 执行轨迹 τ 的鲁棒度 `ρ_φ(τ)`（有符号满足度）；
- **证书** `J_nl = (ρ_min, p_sound, T_scope, C*)`，`p_sound` 由解析置信度经校准映射；
- **有效判定**：`J_nl valid ⇔ ρ_min ≥ −ε_ρ ∧ p_sound ≥ τ_p`；
- 无效 ⇒ 触发重接地或回退保守约束，并把 `(ℓ, τ, ρ)` 写入原型库做在线校准。

**定义 167（LGS 闭环）** 算子 `LGS(M, ℓ, scene, δ_f_req)`：
```
① E_φ(ℓ)（Matryoshka，按预算逐级）
② Γ ← G_grammar.parse(E_φ(ℓ));  H ← AMB.entropy(ℓ)
③ if H > τ_H or uncovered: AMB.clarify()（受 B_clar 约束）
④ C_ℓ ← g_θ(Γ)
⑤ C_scene ← SSM.scene_prior();  C_rt ← ERTC.contract()
⑥ C* ← CLG(C_ℓ, C_scene, C_rt)
⑦ Δθ_K ← SIR.project(C*);  K_safe ← SIR.reconstruct(Δθ_K)
⑧ dispatch(K_safe);  τ ← wait_contact()
⑨ J_nl ← IGC(φ_ℓ, τ)
⑩ if not J_nl.valid: re_ground()/relax();  P.update(...)
⑪ XMC++ / EPIR 复用；return (K_safe, C*, J_nl, P.status)
```

**定义 168（PCE+++++ 与轻量化契约）** `B_lgs = (B_lang, B_struct, B_exec)`：
- `B_lang = (parse_ops, prototype_lookups, clarification_turns)`
- `B_struct = (active_coords, rank_budget, quant_bits)`
- **轻量化契约（不可协商）**：
  ```
  L_lgs(ℓ) ≤ 0.3·L_sgec(ℓ)  ∧  Mem_lgs ≤ 0.5·M_sgec
  ∧  rate(J_nl valid) ≥ 1 − δ_nl
  ```
- **VOI 扩展**：
  ```
  voi_lgs(π) = VOI_meta_pessimistic(π) − cost_lang(π) − cost_struct(π) − cost_exec(π)
  ```
  若轻量化契约违反 ⇒ 拒绝该认知动作并回退到 SGEC 保守路径；若 `B_lang` 耗尽 ⇒ 仅用原型级解析；若 `B_struct` 耗尽 ⇒ 冻结结构坐标、仅做对角调节；若 `B_exec` 耗尽 ⇒ 原有降级。

### IP-161 CET（组合式指令语义）

```python
@dataclass
class Leaf:
    dim: str; rel: str; theta: float; modifier: str = 'none'

@dataclass
class Node:
    op: str                     # AND / OR / SEQ / UNTIL / IF / NOT
    children: list
    scope: tuple = None         # (t_start, t_end) or ('until', event)

def ground(expr, modifiers):
    if isinstance(expr, Leaf):
        m = modifiers.get(expr.modifier, lambda x: x)
        return ConstraintBox(dim=expr.dim, rel=expr.rel, bound=m(expr.theta))
    if expr.op == 'AND':
        return meet([ground(c, modifiers) for c in expr.children])
    if expr.op == 'OR':
        return hull([ground(c, modifiers) for c in expr.children])
    if expr.op == 'NOT':
        return relax(ground(expr.children[0], modifiers), safe_domain=C_rt)
    return temporal_wrap(expr, ground_children(expr, modifiers))
```

### IP-162 LPC（轻量原型编译器）

```python
class LightweightPrototypeCompiler:
    def __init__(self, prototypes, grammar, max_level=4):
        self.P = prototypes            # [(e_i, op_i, radius_i)]
        self.G = grammar
        self.L = max_level

    def parse(self, text, budget):
        for level in range(1, self.L + 1):
            e = E_phi(text, level)     # Matryoshka 早退
            ops, conf = [], []
            for phrase in segment(text):
                d, i = nearest(e[phrase], self.P)
                if d > self.P[i].radius:
                    return None, {'uncovered': phrase}
                ops.append(self.P[i].op); conf.append(exp(-d**2 / 2))
                budget.prototype_lookups -= 1
                if budget.prototype_lookups <= 0:
                    return self.G.assemble(ops), {'early': level}
            cet = self.G.assemble(ops)
            if self._stable(cet) or level == self.L:
                return cet, {'level': level, 'conf': mean(conf)}
            budget.parse_ops -= 1
        return None, {'uncovered': 'depth'}
```

### IP-163 SIR（结构化阻抗）

```python
class StructuredImpedance:
    def __init__(self, B, rank=2, active_max=9):
        self.B = B                 # 6x6 task-frame basis
        self.r = rank
        self.active_max = active_max

    def project(self, C_star):
        active = select_active_coords(C_star, self.active_max)
        lam = solve_diag(C_star, self.B)[active]          # 6
        U = solve_lowrank(C_star, self.B, rank=self.r)    # 6 x r
        return {'active': active, 'lam': lam, 'U': U}

    def reconstruct(self, dtheta):
        K = self.B @ np.diag(dtheta['lam']) @ self.B.T
        K += dtheta['U'] @ dtheta['U'].T
        return symmetrize(K)

    def passivity_ok(self, dtheta, lmi_region):
        return max_eig(self.reconstruct(dtheta) - lmi_region.lower) <= 1e-9
```

### IP-164 CLG（约束格接地）

```python
def constraint_lattice_ground(C_lang, C_scene, C_rt):
    C_star = meet_all([C_lang, C_scene, C_rt])
    if C_star.is_empty():
        hard = meet_all([C_scene, C_rt])
        if hard.is_empty():
            return None, {'error': 'safe_domain_empty'}   # 不可用语言修补
        C_star = project_onto(hard, C_lang)               # 只在硬域内松弛语言
        return C_star, {'relaxed': True, 'dist': dist(C_star, C_lang)}
    return C_star, {'relaxed': False}
```

```python
def maybe_clarify(parse_dist, C_lang, C_rt, budget):
    H = entropy(parse_dist)
    if conflict(C_lang, C_rt):
        return 'must_clarify'
    if H > TAU_H:
```

### IP-166 IGC（指令接地证书）

```python
def instruction_grounding_certificate(phi, trajectory, p_sound):
    rho = stl_robustness(phi, trajectory)      # 有符号满足度
    valid = (rho >= -EPS_RHO) and (p_sound >= TAU_P)
    return {'rho_min': rho, 'p_sound': p_sound,
            'scope': phi.scope, 'valid': valid}

def stl_robustness(phi, tau):
    if phi.kind == 'ATOM':
        return signed_margin(phi, tau)
    if phi.kind == 'G':
        return min(stl_robustness(phi.body, tau[t] ) for t in phi.window)
    if phi.kind == 'U':
        return max(min(stl_robustness(phi.a, tau, t),
                       min(stl_robustness(phi.b, tau, s) for s in range(t, end)))
                   for t in phi.window)
    if phi.kind == 'IMPLIES':
        return max(-stl_robustness(phi.cond, tau), stl_robustness(phi.body, tau))
```

### IP-167 LGS（闭环）

```python
def language_grounded_structure_loop(M, instruction, delta_f_req):
    cet, meta = M.lpc.parse(instruction, M.budget.lang)
    action = maybe_clarify(meta.get('dist'), ground(cet, M.modifiers),
                           M.ertc.contract(), M.budget.lang)
    if action == 'must_clarify':
        return None, {'status': 'await_clarification'}
    if cet is None or action == 'conservative_default':
        return M.sgec_fallback(delta_f_req), {'status': 'fallback'}

    C_lang = ground(cet, M.modifiers)
    C_star, relax = constraint_lattice_ground(
        C_lang, M.scene_model.scene_prior(), M.ertc.contract())
    if C_star is None:
        return M.sgec_fallback(delta_f_req), {'status': 'safe_domain_empty'}

    dtheta = M.sir.project(C_star)
    if not M.sir.passivity_ok(dtheta, M.lmi_region):
        return M.sgec_fallback(delta_f_req), {'status': 'passivity_violation'}

    K_safe = M.sir.reconstruct(dtheta)
    dispatch_impedance_params(K_safe, cert)
    tau = wait_contact()
    J_nl = instruction_grounding_certificate(
        compile_stl(cet), tau, meta.get('conf', 0.0))
    if not J_nl['valid']:
        M.lpc.update_from_failure(instruction, tau, J_nl)
        return M.sgec_fallback(delta_f_req), {'status': 'grounding_failed', 'J_nl': J_nl}
    return K_safe, {'status': 'ok', 'C_star': C_star, 'J_nl': J_nl, 'relax': relax}
```

```python
class LGSBudget:
```

6. **结构稳定**：SIR 通过无源性 LMI，语言改动不破坏闭环稳定性。

### IP-161 CET（组合式指令语义）

```python
@dataclass
class Leaf:
    dim: str; rel: str; theta: float; modifier: str = 'none'

@dataclass
class Node:
    op: str                     # AND / OR / SEQ / UNTIL / IF / NOT
    children: list
    scope: tuple = None

def ground(expr, modifiers, C_rt):
    if isinstance(expr, Leaf):
        m = modifiers.get(expr.modifier, lambda x: x)
        return ConstraintBox(expr.dim, expr.rel, m(expr.theta))
    if expr.op == 'AND':
        return meet([ground(c, modifiers, C_rt) for c in expr.children])
    if expr.op == 'OR':
        return hull([ground(c, modifiers, C_rt) for c in expr.children])
    if expr.op == 'NOT':
        return relax(ground(expr.children[0], modifiers, C_rt), safe_domain=C_rt)
    return temporal_wrap(expr, [ground(c, modifiers, C_rt) for c in expr.children])
```

### IP-162 LPC（轻量原型编译器）

```python
class LightweightPrototypeCompiler:
    def __init__(self, prototypes, grammar, max_level=4):
        self.P, self.G, self.L = prototypes, grammar, max_level

    def parse(self, text, budget):
        for level in range(1, self.L + 1):
            e = E_phi(text, level)                 # Matryoshka 逐级展开
            ops, conf = [], []
            for phrase in segment(text):
                d, i = nearest(e[phrase], self.P)
                if d > self.P[i].radius:
                    return None, {'uncovered': phrase}
                ops.append(self.P[i].op)
                conf.append(exp(-d**2 / 2))
                budget.prototype_lookups -= 1
                if budget.prototype_lookups <= 0:
                    return self.G.assemble(ops), {'early': level}
            cet = self.G.assemble(ops)
            if self._stable(cet) or level == self.L:
                return cet, {'level': level, 'conf': mean(conf)}
            budget.parse_ops -= 1
        return None, {'uncovered': 'depth'}
```

### IP-163 SIR（结构化阻抗）

```python
class StructuredImpedance:
    def __init__(self, B, rank=2, active_max=9):
        self.B, self.r, self.active_max = B, rank, active_max

    def project(self, C_star):
        active = select_active_coords(C_star, self.active_max)
        lam = solve_diag(C_star, self.B)[active]
        U = solve_lowrank(C_star, self.B, rank=self.r)
        return {'active': active, 'lam': lam, 'U': U}

    def reconstruct(self, dtheta):
        K = self.B @ np.diag(dtheta['lam']) @ self.B.T
        K += dtheta['U'] @ dtheta['U'].T
        return symmetrize(K)

    def passivity_ok(self, dtheta, lmi_region):
        return max_eig(self.reconstruct(dtheta) - lmi_region.lower) <= 1e-9
```

### IP-164 CLG（约束格接地）

```python
def constraint_lattice_ground(C_lang, C_scene, C_rt):
    C_star = meet_all([C_lang, C_scene, C_rt])
    if C_star.is_empty():
        hard = meet_all([C_scene, C_rt])          # 安全硬边界
        if hard.is_empty():
            return None, {'error': 'safe_domain_empty'}
        C_star = project_onto(hard, C_lang)       # 只在硬域内松弛语言
        return C_star, {'relaxed': True, 'dist': dist(C_star, C_lang)}
    return C_star, {'relaxed': False}
```

### IP-166 IGC（指令接地证书）

```python
def instruction_grounding_certificate(phi, trajectory, p_sound):
    rho = stl_robustness(phi, trajectory)
    valid = (rho >= -EPS_RHO) and (p_sound >= TAU_P)
    return {'rho_min': rho, 'p_sound': p_sound,
            'scope': phi.scope, 'valid': valid}

def stl_robustness(phi, tau):
    if phi.kind == 'ATOM':
        return signed_margin(phi, tau)
    if phi.kind == 'G':
        return min(stl_robustness(phi.body, tau[t]) for t in phi.window)
    if phi.kind == 'U':
        return max(min(stl_robustness(phi.a, tau, t),
                       min(stl_robustness(phi.b, tau, s) for s in range(t, end)))
                   for t in phi.window)
    if phi.kind == 'IMPLIES':
        return max(-stl_robustness(phi.cond, tau), stl_robustness(phi.body, tau))
```

```python
def language_grounded_structure_loop(M, instruction, delta_f_req):
    cet, meta = M.lpc.parse(instruction, M.budget.lang)
    action = maybe_clarify(meta.get('dist'), ground(cet, M.modifiers, M.ertc.contract()),
                           M.ertc.contract(), M.budget.lang)
    if action == 'must_clarify':
        return None, {'status': 'await_clarification'}
    if cet is None or action == 'conservative_default':
        return M.sgec_fallback(delta_f_req), {'status': 'fallback'}

    C_lang = ground(cet, M.modifiers, M.ertc.contract())
    C_star, relax = constraint_lattice_ground(
        C_lang, M.scene_model.scene_prior(), M.ertc.contract())
    if C_star is None:
        return M.sgec_fallback(delta_f_req), {'status': 'safe_domain_empty'}

    dtheta = M.sir.project(C_star)
    if not M.sir.passivity_ok(dtheta, M.lmi_region):
        return M.sgec_fallback(delta_f_req), {'status': 'passivity_violation'}

    K_safe = M.sir.reconstruct(dtheta)
    dispatch_impedance_params(K_safe, cert)
    tau = wait_contact()
    J_nl = instruction_grounding_certificate(
        compile_stl(cet), tau, meta.get('conf', 0.0))
    if not J_nl['valid']:
        M.lpc.update_from_failure(instruction, tau, J_nl)
        return M.sgec_fallback(delta_f_req), {'status': 'grounding_failed', 'J_nl': J_nl}
    return K_safe, {'status': 'ok', 'C_star': C_star, 'J_nl': J_nl, 'relax': relax}
```
