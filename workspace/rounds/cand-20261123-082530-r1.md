# 第 4 轮（灵感驱动研究循环·新灵感二元组第 1 轮；本轮灵感：「能耗优化」×「MuJoCo」）

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v21 + IP-425–430（SDC/CAC/DCL/GIC/HPC+/CFC+ 语义-合规层；其上承 v20 联邦感知证书 PCA/CTS/CFC/HPC/CFCtrl、v19 DCM/OGCC/CCV/DRS/OGC、v17 CLP/S2C/HCG/PSV/APS/AMC）。
> 本轮纪律：**能量不是要省的成本，而是"安全能力的有限燃料"；仿真不是"真值背书"，而是"单向的证书杀手"**。不推倒 v21：SDC/CAC/DCL/GIC/HPC+/CFC+ 与 v20/v19/v17 全部保留。本轮只做一件事：**在 v21 的"几何-规范-负信息"证书之上加一层"能量可行 + 物理接地"层（PGEV），把准入门从"碰不碰 / 该不该 / 有无负信息"扩展为"… ∧ 能量撑不撑得住 ∧ 物理上是否已被尽力证伪"，并正面处理 v21 完全未触及的物理失配面**。

## 0. 直觉与动机

**灵感 1（能耗优化 → 能量不是成本函数，而是"安全能力的有限燃料"与不可交易的储备不变量）**
直觉：v21 的所有安全动作——减速、绕行、让位、急停——都不是免费的：它们消耗电池能量，而"能不能刹住 / 让开"本身就受**剩余电量与峰值功率**约束。最朴素的能耗优化是"在安全约束下最小化焦耳"（min ∫P dt），但这会犯一个致命错误：把能量当成纯目标函数，优化器便会**把安全裕度当成可交易的成本**去省（"少留 5cm 裕度省 3% 电"）。真正的转念是：**能量要同时被优化（目标）和被认证（约束）**——机器人必须始终持有足以执行"最坏情形认证安全停机 + 抵达已认证安全/充电状态"的能量储备 `E_res ≥ E_fallback(x,v,z) + E_reach_safe(x) + E_margin`，这条**能量储备不变量**是不可被优化器交易的硬约束。更反直觉的是**安全悖论**：过度的保守（永远爬行、原地悬停、反复停车重启）本身会耗光能量，甚至把机器人耗尽在错误地点——所以在有限能量下，"越保守 = 越安全"的单调假设**失效**，安全是 (几何证书 ∧ 能量可行核) 联合刻画的可行域，其可行度对保守度呈**倒 U 形**，存在内点最优。第三个反直觉点：**能量只能是"已计账"的**——任何依赖"未来充电 / 再生制动回收"的证书都无效，除非该回收已在当前能量账户中被认证入账；故能量账户的更新是**单调的**（除认证充电点），与 v21 的"障碍只增、自由有偿赎回"同构，正是这一同构让安全继承得以保持。

**灵感 2（MuJoCo → 仿真只能证伪、不能证明，故是最强的"证书杀手"而非"证书背书者"）**
直觉：MuJoCo 给出接触力、摩擦锥、执行器力矩、能量耗散的真实物理（`qfrc_actuator`、`data.contact`、`geom.friction`/`condim`/`solref`），看起来像 ground truth，于是极易滑向"仿真通过 = 安全"。但 sim-to-real gap 意味着仿真通过**永远不能**证明现实安全，它只在模型有效域内提供证据。真正有价值的用法是**波普尔式不对称**：用一个够狠的 MuJoCo 神谕去**搜索反例**（推挤、打滑、负载突变、传感/通信延迟、参数漂移、人体碰撞模型），一旦某条 rollout 违反 v21 的几何裕度、或违反我们的能量/平衡预算，就产出一个**反例见证 (counterexample witness)**，直接**否决**该证书。即仿真是一个**单调的证书杀手**：它只能移除计划、不能新增计划——这恰好从结构上保住 `Exec_v22 ⊆ Exec_v21`。MuJoCo 的第二个妙用是**校准能量模型**：`P = Σ|τᵢq̇ᵢ| + P_contact + P_thermal + P_comp`，把解析能量模型对齐到仿真，误差进入现实差距证书 (RGC) 的膨胀项。第三个妙用是**可微仿真 (MJX / MuJoCo-XLA) 的梯度最坏情形搜索**：不做盲目随机采样，而是沿"最小裕度"的梯度上升、再投影回不确定性集 U，快速逼到证书边界；此外 MuJoCo 的 `rangefinder` 光线投射可在仿真中对 CAC 的 `Cov_t` **几何覆盖**做机械复核（但明确不覆盖学习检测器的召回——那是 v21 的 `κ_c` 风险，仿真不能替它背书）。

**二者如何统一**
统一为 **v21 之上的"物理接地-能量可行层"（Physics-Grounded & Energy-Viable Layer, PGEV）**：EVC 回答"我凭什么相信它撑得到安全态"，EOCP 回答"在安全可行集内怎样最省能"，APTE 回答"没电 / 过热时它还刹不刹得住"，PGFO 回答"物理上我尽力找过了、有没有反例"，RGC 回答"仿真证据到底能兑现多少"。共享状态扩展为 **ζ_pgev = ζ_sem ∪ (E_res, SoC, T_act, ∏_energy, W_sim, d_gap)**。统一准入门升级为 **HPC-E = (HPC+, EVC, RGC)**：几何 SAFE ∧ 规范允许 ∧ 负信息可靠 ∧ **能量可持续** ∧ **现实差距内的证伪未命中**。任何失效都向保守退化（详见 §3）。关键守恒点：能量层只加"储备下界约束"与"制动能力降额"，不新增任何自由空间；能耗只做目标；仿真只删不增——故 `Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18` 由构造保持（引理 168）。

## 2. 设计原则（在 P34–P36 基础上新增 P37–P39）

**P37 能量可行律（Energy Viability）**
任何准入计划须满足**能量储备不变量**：沿整条轨迹 `E_res(t) ≥ E_fallback(x,v,z) + E_reach_safe(x) + E_margin`，其中功率取最坏情形上界；能量记账**单调**（除认证充电点），严禁预支未来能量 / 再生回收。低电时只允许降速、收缩、提前返航 / 充电，绝不"透支换活性"。

**P38 目标-约束分离律（Objective–Constraint Separation）**
能耗仅作**目标** `J_E = ∫P dt`，绝不进入安全约束的松弛项；安全约束（v21 证书集 ∧ 能量可行核 `K_energy`）为**硬约束**。最优化只在可行集内选择，绝不扩张可行集，故 `Exec_v22^energy = Feas(v21) ∩ K_energy ⊆ Exec_v21`。

**P39 证伪单向律（One-Sided Falsification）**
仿真只可**否决**、不可**背书**：`Cert_v22(π) = Cert_v21(π) ∧ EVC(π) ∧ (W_sim(π)=∅)`。RGC 支撑不足则仿真信用为零；"未被证伪"永不计为"已证明"，且通过仿真不得新增任何计划。

## 3. 与基线的接口（如何退化）

- EVC 失效（能量模型 / 库仑计不可信）⇒ 假设最大能耗、限速、提前返航 ⇒ 更保守；
- EOCP 失效 ⇒ 退回 v21 速度上限（能耗非最优但安全）；
- APTE 失效（降额曲线不可信）⇒ `a_max / P_max` 取静态最保守值 ⇒ 更慢、更早停；
- PGFO 失效（仿真不可用）⇒ 无证伪，解析 v21 证书仍在 ⇒ 等价 v21；
- RGC 失效 / 支撑外 ⇒ `d_gap = ∞`、仿真信用 = 0 ⇒ 等价 v21；
- 五者全失效 ⇒ 完全回退 v21 ⇒ `Exec_v22 ⊆ Exec_v21 ⊆ … ⊆ Exec_v18`（引理 168）。
- **安全继承**：能量只加储备下界、能耗只做目标、包络只降额、证伪只删、差距只否证；任意失效都向保守方向退化，并与 v21 的 `τ_consensus` / APS 新鲜度 / `τ_rule` 通过事件化时间戳对齐。

## 4. 预期贡献

1. **能量可行证书 (EVC)**：把"能耗优化"从成本函数升级为"安全能力的储备不变量"，给出 `E_fallback + E_reach_safe` 的物理夹逼与单调审计记账；
2. **目标-约束分离**：证明能耗最优化在硬约束下不扩张安全集，杜绝"以裕度换能量"；
3. **安全悖论形式化**：给出保守度-能量-安全的倒 U 形非单调性，安全只能在 (几何证书 ∧ 能量可行核) 的 Pareto 可行段上定义；
4. **单向证伪神谕 (PGFO)**：把 MuJoCo / MJX 形式化为波普尔式证书杀手——梯度最坏情形搜索 + 反例见证，只删不增；
5. **现实差距证书 (RGC)**：仿真信用只在可证有效域内兑现，支撑外 fail-safe 归零，封堵"仿真背书幻觉"的误用面；
6. **HPC-E 一体与继承闭环**：`Exec_v22 ⊆ Exec_v21 ⊆ …`，能量 / 物理层全链可机械复核。

## 5. 本轮最大风险

**一句话**：证伪神谕只能"找到反例"、不能"证明无例"，其保证完全由对抗分布 U 与 MuJoCo 模型有效域共同界定；一旦真实扰动落在 U 或模型支撑之外，"没有见证"会被审计误读为"已证明安全"，这正是 v21「合规的缺席幻觉」在物理层的翻版——**「证伪的缺席幻觉」**。

# IP-431 Energy Viability Certificate
class EnergyViabilityCertificate:
    def __init__(self, power_model, fallback_policy, charger_map, margin=0.05):
        self.power = power_model            # P = Σ|τ·q̇| + contact + thermal + comp（MuJoCo 校准）
        self.fallback = fallback_policy     # 认证安全停机（v21 SafeStop 的物理版）
        self.chargers = charger_map         # 多备选安全/充电状态
        self.margin = margin

    def reserve_required(self, x, v, z):
        e_fb = self.fallback.worst_case_energy(x, v, z)   # 含让位/制动/通信
        e_reach = self.chargers.min_energy_to_safe(x)     # 取多备选最小
        return (e_fb + e_reach) * (1.0 + self.margin)

    def viable(self, x, v, z, E_res):
        # P37 储备不变量（硬约束）
        return E_res >= self.reserve_required(x, v, z)

    def worst_case_drain(self, plan, uncertainty):
        # 区间/对抗功率积分：每时段取 P_upper，而非标称功率
        return integrate_upper(self.power, plan, uncertainty)

    def update_account(self, E_res, plan, dt, charge_cert=None):
        # 单调记账：未在认证充电点不得入账（严禁预支未来再生制动）
        drain = integrate(self.power, plan, dt)
        credit = charge_cert.credit if (charge_cert and charge_cert.valid()) else 0.0
        return E_res - drain + credit


# IP-432 Energy-Optimal Constrained Planner
class EnergyOptimalConstrainedPlanner:
    def __init__(self, evc, theta_v21, margin_req):
        self.evc, self.theta_v21, self.margin_req = evc, theta_v21, margin_req

    def plan(self, x0, goal, E_res):
        # 目标：min J_E = ∫P dt；约束：v21 证书 ∧ 能量可行核（硬约束，不是软惩罚）
        def feasible(pi):
            if not self.theta_v21.contains(pi):
                return False
            spent = 0.0
            for s in pi.trajectory:                        # 全轨迹逐时刻校验
                if not self.evc.viable(s.x, s.v, s.z, E_res - spent):
                    return False
                spent += self.evc.worst_case_drain_step(s)
            return True

        cands = [pi for pi in self.candidates(x0, goal) if feasible(pi)]
        if not cands:
            return None, "ENERGY_INFEASIBLE->ControlledStop+Recharge"
        # 只在可行集内挑，不扩张可行集（P38 / 引理 164）
        return min(cands, key=lambda pi: self.cost_J(pi)), "OK"

class ActuatorEnvelope:
    def __init__(self, mujoco_model, t_latency):

    def a_max(self, soc, temp):
        # 制动能力随 SoC / 温度降额——"越没电越刹不住"
        return self.a0 * derate_soc(soc) * derate_temp(temp)

            m_sim, e_sim, b_sim = self.rollout(plan, u)
            if m_sim < margin_req or e_sim < 0 or b_sim < 0:
                witnesses.append(Witness(u=u, m_sim=m_sim,
                                         e_sim=e_sim, b_sim=b_sim))
        return witnesses   # 只能否决，不能背书（引理 165）

    def rollout(self, plan, u):
        # MuJoCo: mj_step；读取 data.contact / qfrc_actuator / qvel 计算裕度与能耗
        return simulate(self.sim, plan, u)


# IP-435 Reality-Gap Certificate
class RealityGapCertificate:
    def __init__(self, calibrator, delta_g=0.01):
        self.calib, self.delta_g = calibrator, delta_g

    def bound(self, domain):
        # 从 sim-real 配对数据估分位上界；支撑不足返回 +∞（不兑现仿真信用）
        if not self.calib.support_covers(domain):
            return float("inf")
        return self.calib.quantile_upper(self.delta_g)

    def admits_sim_credit(self, m_sim, d_gap, margin_req):
        # 引理 166：仿真裕度须扣除现实差距膨胀后才可兑现
        return m_sim >= margin_req + d_gap


# IP-436 HPC-E 统一准入门（HPC+ 原样保留，只加门）
@dataclass
class HPCE:
    hpc_plus: HPCPlus
    evc_ok: bool
    rgc: RealityGapCertificate
    witnesses: list

    def admits(self, plan, x, v, z, E_res, margin_req):
        return (self.hpc_plus.admits(plan.theta)                    # v21：几何∧规范∧负信息
                and self.evc_ok                                     # 能量可持续
                and len(self.witnesses) == 0                        # 差距有效域内未证伪
                and self.rgc.admits_sim_credit(plan.m_sim,          # 现实差距内兑现
                                               self.rgc.bound(plan.domain),
                                               margin_req))

## 3. 推导

**引理 163（能量可行证书的可靠性）** 若沿计划每时刻 `E_res(t) ≥ E_fallback(x,v,z) + E_reach_safe(x) + E_margin`，功率积分取最坏情形上界，且记账单调（除认证充电点），则机器人任意时刻都能执行认证安全停机并抵达认证安全态；模型 / 传感误差由 `E_margin` 与 `RGC` 膨胀项吸收。若某时刻不满足，则进入受控停机 + 返航，而非继续执行。∎

**引理 164（能耗最优的约束保持）** EOCP 以 `J_E = ∫P dt` 为目标、以 `Feas(v21) ∧ K_energy` 为**硬约束**。目标函数只在可行集内做选择（`min` over feasible），既不修改也不扩张可行集，故 `Exec_v22^energy = Feas(v21) ∩ K_energy ⊆ Exec_v21`。若把能量写成软惩罚则此引理不成立——这正是 P38 禁止的事。∎

**引理 165（证伪单向性 / 单调证书杀手）** 仿真神谕仅在被证伪时否决，通过不新增计划：`Cert_v22(π) = Cert_v21(π) ∧ EVC(π) ∧ (W_sim(π)=∅)`。后两项为合取，任一为假只会移除 `π`；故对任意 `W_sim` 有 `Exec_v22 ⊆ Exec_v21`。这是"波普尔式不对称"的形式化：仿真可以否证、不能证实。∎

**引理 166（现实差距膨胀）** 设有效域内 `sup|M_real − M_sim| ≤ d_gap` 以概率 ≥`1-δ_g`，则 `M_sim ≥ margin_req + d_gap ⇒ M_real ≥ margin_req`（概率 ≥`1-δ_g`）；对 N 次 rollout 用 union bound 修正为 `1 - N·δ_g`。若 `support` 不覆盖该域则 `d_gap = +∞`，`admits_sim_credit` 恒假、仿真信用归零、退回 v21。∎

**引理 167（安全悖论 / 保守度的非单调性）** 令保守度 c 增大：动作集 `S(c)` 单调收缩（更少速度/更小步），但驻留/悬停/反复启停能耗使 `E(c)` 先降后升，进而能量可行核 `K_energy(c)` 也可能收缩。于是总可行域 `S(c) ∩ K_energy(c)` 对 c 可呈**倒 U 形**，存在内点 `c*` 而非端点。"越保守越安全"在有限能量下不成立；EVC 以**储备下界**（而非速度下界）约束、EOCP 在其内最小化能耗，故方案落在 Pareto 前沿的可行段。∎

**引理 168（v22 整体安全继承）** 同一几何快照、v21 语义-规范层与机器人集合下：能量层只加储备下界（163）、EOCP 只在可行内选（164）、APTE 只降额、PGFO 只删（165）、RGC 支撑不足退回（166）。故 `Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。∎

## 7. 已知风险与失效模式

1. **证伪覆盖不足（最大风险，见第 8 节）**：U 与模型有效域之外的真实扰动不可见，"未被证伪"被误读为"已证明"。缓解：MJX 梯度 + 重要采样 + 对抗课程、显式审计"覆盖"而非"通过"、文档与界面强制标注"未证伪≠已证明"。
2. **sim-to-real 差距失界**：软地面、湿滑、非刚体人体使 `d_gap` 无界。缓解：RGC 支撑检查 + 支撑外归零退回、在线配对标定、保守膨胀。
3. **能量模型 / 包络标定误差**：账户高估导致形式可行而事实透支。缓解：功率取最坏上界、库仑计在线校正、低电提前返航（E818）。
4. **能量-活性悖论调参**：过度保守耗能、内点最优难寻。缓解：EVC 用储备下界而非速度下界、EOCP 在 Pareto 前沿搜索（E807）。
5. **售后安全态假设失效**：充电桩被占/断电/被阻断。缓解：`E_reach_safe` 取多备选、断电时收缩至最低速返航。
6. **计算/内存开销**：MJX 大规模 rollout。缓解：离线摊销、并行、预算封顶，绝不侵入 50Hz（E828）。
7. **仿真模型的道德风险**：MuJoCo 人体/碰撞参数被"调好看"以通过证伪。缓解：参数版本化入 merkle 审计、外部标定冻结、见证与模型哈希绑定。

## 8. 本轮最大风险

**一句话**：证伪神谕只能"找到反例"、不能"证明无例"，其保证完全由对抗分布 U 与 MuJoCo 模型有效域共同界定；一旦真实扰动落在 U 或模型支撑之外，"没有见证"会被审计误读为"已证明安全"，这正是 v21「合规的缺席幻觉」在物理层的翻版——**「证伪的缺席幻觉」**。
