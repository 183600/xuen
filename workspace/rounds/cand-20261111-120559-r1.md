# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；本轮灵感：「仿真到现实」×「成功率」）

> 第 54 轮把技能组合推进到动作空间剖面 `α_S`、技能组合图 SCOM、云边联合证书 `J`，解决了“动作上能不能对齐”的问题。本轮回答一个更贴近部署的问题：**部署到现实后，成功率到底是多少，能否给出可置信的下界？** 核心矛盾：H24：仿真成功率与真实成功率的差异不是全局常数偏置，而是随任务/动作/接触条件变化的 **间隙谱 `g(π;d)`**，用单一 sim2real 系数校正会在技能组合链上系统性高估；H25：真实样本稀缺且昂贵，成功率点估计没有置信保证，而组合会把“估计误差 + 间隙误差”逐级放大，导致“实验室 95% → 现场 60%”的成功率坍塌。

## 0. 直觉与动机

**灵感 1（间隙是谱，不是标量）**
直觉：我们常说“仿真到现实有 gap”，仿佛它是一个数。但只要做过实验就知道：同一策略在平整地面几乎无 gap，在反光/软地面/强扰动下 gap 可能是灾难性的；同一技能在单步执行时 gap 很小，进入接触密集阶段后 gap 突然变大。因此正确的对象是 `g(π;d) = p_sim(π|d) - p_real(π|d)`，定义在条件 `d`（地形、光照、材质、负载、接触模式）上的**函数**。把 gap 分解为观测 gap、动力学 gap、驱动 gap、任务分布 gap 与交互项，才能知道该修仿真器的哪一部分。**仿真器的价值不是“更准”，而是“gap 可被局部估计并可被回写收缩”。**

**灵感 2（成功率是决策量，必须给置信下界）**
直觉：运维不关心 `p̂_real = 0.87`，只关心“`p_real ≥ p_req` 能否被证成”。点估计在真实样本只有几十次时毫无意义。于是需要 **成功率证书 `C_succ`**：用真实锚点做无条件覆盖的置信下界 `p_lo`，用大量仿真样本做控制变量降方差，并显式报告有效样本量 `n_eff` 与支持度 `s_ov`。证书回答的是“在 `1-α` 置信下，真实成功率至少是多少”，而不是“平均看起来是多少”。**宁可给出窄而可信的区间，也不给宽而无根据的乐观值。**

**灵感 3（间隙在组合链上被放大）**
直觉：若单技能真实成功率为 0.95，看似 10 个技能串联仍有 0.60；更糟的是组合会引入新的 gap（切换瞬态、接触模式切换、误差累积），使实际成功率低于朴素乘积。定义 **间隙放大因子 `A_g(π) = g(π) / Σ_i g(S_i)`**，并给出可计算的组合下界 `p_real(π) ≥ Π p_lo(S_i) - A_g Σ ĝ_i^+ - β_ct(k)`。这把“长链成功率坍塌”从经验感叹变成可预算、可规划的量；必要时用 checkpoints/重试把成功率买回来，但重试要计入时间预算。

**灵感 4（真实试验是稀缺资源 → 主动校准）**
直觉：现实试验一次可能几十秒、甚至损坏设备，不能均匀撒点。应该把有限的真实预算花在**最可能改变部署决策**的试验上：某个条件 `d` 的 `p_lo` 恰好在 `p_req` 附近，或该技能的间隙上界主导了整条链的失败风险。以 **校准价值 `VoC(e)`**（单位成本带来的决策风险下降）选择试验，而不是按覆盖率平均采样。仿真在这里当代理模型，只负责“推荐去哪里做真实试验”，不负责替代真实证据。

**灵感 5（Real2Sim 回写让间隙单调收缩）**
直觉：第 53 轮的 `Explain` 已经能给出真实失败的根因维度。把真实失败簇回传给仿真器做系统辨识，更新动力学/接触/传感参数 `θ_sim`，再用留出真实锚点验证 gap 是否真的下降；只有“gap 下降 + 留出损失下降”才接受，否则回滚。受控的回写把 sim2real 从一次性迁移变成 **gap 单调收缩的闭环**，避免“越调越像训练集、越不像现实”的过拟合。

**灵感 6（证书金字塔再加一层：成功率层）**
直觉：在第 54 轮的动作-协同层之上叠加 **成功率证书层 `𝕊`**：`𝕊_0` 真实试验证据，`𝕊_1` 间隙谱，`𝕊_2` 成功率证书，`𝕊_3` 组合成功率界，`𝕊_4` 部署决策。跨层只传递“带置信与版本的证书”，不传递裸成功率；任何一层证据过期（分布漂移、仿真器改版、技能升级）都必须使证书失效并重校准。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（仿真-现实成功率间隙谱，SRGS）**
对策略/技能 `π` 与条件 `d ∈ 𝔇`，令
```
p_sim(π|d) = E_{ξ~P_sim(·|d)}[1{success(π,ξ)}]
p_real(π|d) = E_{ξ~P_real(·|d)}[1{success(π,ξ)}]
g(π|d) = p_sim(π|d) - p_real(π|d)
```
间隙谱分解为
```
g = g_obs ⊕ g_dyn ⊕ g_act ⊕ g_task ⊕ g_int
```
其中 `g_obs` 为观测/感知 gap，`g_dyn` 为动力学/接触 gap，`g_act` 为驱动/延迟/执行器 gap，`g_task` 为任务分布 gap，`g_int` 为交互项。若各分量上界为 `ε_i(d)`，则
```
|g(π|d)| ≤ Σ_{i∈{obs,dyn,act,task}} ε_i(d) + ε_int(d) =: ĝ^+(d)
```
`g` 在 `d` 上允许非单调（例如软地面在低负载时更好、高负载时更差），因此每个 `d` 独立估计，不做全局线性假设。

**定义 122（成功率证书，SRC）**
成功率证书
```
C_succ = (π, p_lo, p_hi, α, n_eff, s_ov, ĝ^+, ver, evidence)
```
- `p_lo, p_hi` 为真实成功率的单侧/双侧置信界，满足覆盖保证
  `P_{P_real}(p_real(π) ≥ p_lo) ≥ 1-α`；
- `α` 为总置信预算，按联合界在“真实锚点估计”和“gap 估计”间分配 `α = α_r + α_g`；
- `n_eff = (Σ_i w_i)² / Σ_i w_i²` 为加权有效样本量，`w_i` 为密度比权重；
- `s_ov = n_eff / n` 或密度比的最小支持度，用于拒绝“无重叠”的外推；
- `ver` 绑定技能版本、仿真器版本与校准集哈希，防止证书跨版本复用；
- `evidence` 至少包含真实锚点、配对仿真回放、漂移检验与失败记录。

**构造（锚定控制变量下界）**：
```
p_lo = max( p_lo^real ,  p̂_sim - e_sim(α_sim) - ĝ^+(α_g) )
```
其中 `p_lo^real` 为真实锚点的 Clopper–Pearson 下界，`p̂_sim - e_sim` 为仿真成功率的置信下界。两项都是有效下界时取最大值以提高紧致度；若 `s_ov < θ_ov` 则证书判为 `unsupported`，不得部署。

**定义 123（间隙放大与组合成功率界）**
对技能链 `π = S_1 ⊗ … ⊗ S_k`，定义间隙放大因子
```
A_g(π) = g(π|d) / ( Σ_{i=1}^k g(S_i|d)^+ + ε ),  g^+ = max(g,0)
```
在“间隙次可乘”假设 (A31) 下 `A_g(π) ≤ 1 + ζ(k-1)`。组合真实成功率下界为
```
p_real(π) ≥ Π_{i=1}^k p_lo(S_i) - A_g · Σ_{i=1}^k ĝ_i^+ - β_ct(k)
β_ct(k) = λ_c · C(k,2) · max_{i<j} |corr(1{success_i}, 1{success_j})|
```
`β_ct` 处理技能间共享失败模式（正相关时该项保守、负相关时必须计入）。若允许每步最多 `r` 次重试，则有效成功率为
```
p_eff(p, r) = 1 - (1-p)^r,  cost_eff = r · c_skill
```
重试在“成功率不够但时间有富余”时可把 `p_eff` 买回，但必须满足总时延预算 `Σ cost_eff ≤ τ_task`。

**定义 124（校准价值，VoC）**
对一次候选真实试验 `e`（条件 `d`、技能 `S`、重复次数 `m`），校准价值
```
VoC(e) = ( E_z[ R(π | C_succ) - R(π | C_succ ⊕ e(z)) ] ) / cost(e)
```
其中 `R` 为部署决策风险（如“误放行导致的现场失败代价 + 误拒绝导致的可用性损失”），`z` 为试验结果，`cost(e)` 含时间、损耗与安全扰动。主动校准在预算 `B` 下选择
```
e* = argmax_{e: cost(e) ≤ B} VoC(e)
```
并强制安全门：只有证书 `p_lo ≥ p_req` 且 `s_ov ≥ θ_ov` 时才允许部署，绝不用“再试一次可能更好”替代证明。

**定义 125（Real2Sim 回写契约，R2S）**
回写契约
```
R2S = (Δθ_sim, Δĝ, anchors, rollback, ver, evidence)
```
其中 `Δθ_sim` 为仿真器参数更新量，`Δĝ` 为回写前后在留出真实锚点上的间隙变化，`anchors` 为未参与拟合的验证锚点。接受条件：
```
Δĝ^+ < -η  ∧  L_holdout(θ_sim') < L_holdout(θ_sim)  ∧  C_succ' 不违反安全下界
```
否则 `rollback` 到旧版本。理想收缩率满足 `g_{t+1} ≤ γ_g · g_t + ν_t`，`0<γ_g<1`，`ν_t` 为不可约噪声；若连续 `m` 轮不降则冻结回写并转人工诊断。

**定义 126（成功率-鲁棒性-动作联合证书，J+）**
在第 54 轮 `J = (ρ, A_cert, γ_ce, δ_a, evidence)` 上增加成功率维：
```
J+ = (ρ, A_cert, γ_ce, δ_a, C_succ, ĝ^+, domain, ver, evidence)
```
部署判据为**合取否决**：
```
deploy(π) ⇔ dom_J(π)=in
          ∧ p_lo(π) ≥ p_req
          ∧ s_ov ≥ θ_ov
          ∧ δ_a ≤ Θ_a
          ∧ ∀d: ρ(d) ≥ ρ_min(d)
          ∧ ver 与当前技能/仿真器版本一致
```
任何一项不满足即拒绝；**不允许用高成功率抵消鲁棒性缺口，也不允许用高鲁棒性抵消未证成的成功率。**

## 2. 关键算法 伪代码

### IP-121 SGE（Sim2Real Gap Estimator）

```python
def estimate_gap_spectrum(policy, dims, sim, real_anchor_db):
    G = {}
    for d in dims:
        pairs = match_rollouts(real_anchor_db, d)   # 同任务/同初始条件配对
        sim_succ  = mean(success(sim.run(policy, t)) for t, _ in pairs)
        real_succ = mean(success(r) for _, r in pairs)
        G[d] = sim_succ - real_succ
        G[d].ci = bootstrap_ci(pairs, B=1000, alpha=0.05)
    # 分维度拟合；仅做单调/保序校准，不强行线性外推
    return GapSpectrum(G, ver=hash_versions(sim, policy))
```

### IP-122 SRC（Success-Rate Certificate）

```python
def success_certificate(policy, real_anchors, sim_rollouts, gap, alpha):
    alpha_r, alpha_g = split_alpha(alpha)          # 联合界
    n = len(real_anchors)
    # 支持度检查：真实锚点是否落在仿真分布的可加权支撑内
    w = density_ratio(sim_rollouts, real_anchors)
    n_eff = (w.sum()**2) / (w**2).sum()
    s_ov = n_eff / n
    if s_ov < THETA_OV:
        return ('unsupported', s_ov)
    # 真实锚点的 Clopper-Pearson 下界
    k = sum(success(r) for r in real_anchors)
    p_lo_real = clopper_pearson_lower(k, n, alpha_r)
    # 仿真 + 间隙的锚定下界
    p_sim_hat = mean(success(s) for s in sim_rollouts)
    e_sim = hoeffding_radius(len(sim_rollouts), alpha_r)
    g_hi  = gap.upper_confidence(alpha_g)
    p_lo_sim = p_sim_hat - e_sim - g_hi
    p_lo = max(p_lo_real, p_lo_sim)
    return SuccessCert(p_lo=p_lo, alpha=alpha, n_eff=n_eff, s_ov=s_ov,
                       g_hi=g_hi, ver=...)
```

### IP-123 SAB（Success-Aware Bound / Composition）

```python
def success_aware_plan(G_skill, task, p_req, tau_task, Kmax, zeta, lambda_c):
    best = None
    for k in 1..Kmax:
        for path in bounded_paths(G_skill, task, k):
            p_lo = prod(cert[s].p_lo for s in path)
            g_amp = min(1 + zeta*(k-1), measured_amp(path))
            eq    = g_amp * sum(gap_plus[s] for s in path)
            beta  = lambda_c * comb(k,2) * max_pairwise_corr(path)
            p_lb  = p_lo - eq - beta
            # 重试把成功率买回，但受时延预算约束
            r = optimal_retries(p_lb, p_req, tau_task, path)
            p_eff = 1 - (1-p_lb)**r
            if p_eff >= p_req and cost(path, r) <= tau_task:
                best = max(best, (p_eff, cost(path, r), path, r))
    return best    # None 表示“未证成可部署”，而非“不可行”
```

### IP-124 VoC（Value-of-Calibration）

```python
def active_calibrate(cert, candidates, B, p_req):
    while B > 0 and decision_margin(cert, p_req) > SAFE_MARGIN:
        for e in candidates:
            e.voi = expected_risk_reduction(cert, e) / cost(e)
        e = argmax(candidates, key=lambda x: x.voi)
        if e.voi <= 0: break
        z = run_real_trial(e)                  # 受安全围栏保护
        cert = bayes_update(cert, e, z)
        B -= cost(e)
    return cert
```

### IP-125 R2S（Real2Sim Repair）

```python
def real2sim_repair(sim, real_failures, anchors, gamma_g, eta):
    grad = system_id_gradient(sim, real_failures)     # 由 Explain 维度对齐
    sim2 = sim.step(grad)
    gap_old = estimate_gap_spectrum(sim,  anchors)
    gap_new = estimate_gap_spectrum(sim2, anchors)
    if (max(gap_new.max() , 0) < max(gap_old.max(), 0) - eta
        and heldout_loss(sim2, anchors) < heldout_loss(sim, anchors)):
        return ('accept', sim2, R2S_contract(grad, gap_new - gap_old, anchors))
    return ('rollback', sim)
```

### IP-126 SJC（Success-Joint Certificate）

```python
def success_joint_certificate(J, C_succ, gap, p_req, theta_ov, Theta_a):
    if J.domain != 'in':                       return ('reject','domain')
    if C_succ.s_ov < theta_ov:                 return ('reject','no_overlap')
    if C_succ.p_lo < p_req:                    return ('reject','success_unproven')
    if J.delta_a > Theta_a:                    return ('reject','action_mismatch')
    if any(rho < rho_min[d] for d,rho in J.rho.items()):
                                               return ('reject','robustness')
    if not versions_consistent(J, C_succ, gap):
                                               return ('reject','stale_cert')
    return ('ok', Jplus(J.rho, J.A_cert, J.gamma_ce, J.delta_a, C_succ, gap))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SGE | O(\|𝔇\|·N_pair·T_sim + B·N_pair log N_pair) | O(\|𝔇\|·N_pair) | 配对回放、分维非单调、bootstrap 覆盖 |
| SRC | O(N_sim + N_real log N_real) | O(N_sim + N_real) | 支持度 `s_ov`、联合界 α 拆分、版本绑定 |
| SAB | O(K·\|E\|·\|S\|)（DP/A* 剪枝） | O(\|S\|·K) | 放大因子可测、相关项保守、重试预算闭合 |
| VoC | O(B·\|C\|·(N_sim+N_real)) | O(\|C\|) | 风险单调、安全门不放松 |
| R2S | O(N_fail·dim θ + N_anchor) | O(dim θ) | 留出锚点、回滚门、版本一致性 |
| SJC | O(\|D_ρ\| + \|𝔇\|) | O(1) 额外 | 合取否决、无补偿逻辑 |

**正确性定理（Certified Sim2Real Success Soundness）**
假设第 54 轮 (A22)–(A28) 成立；新增 **(A29)** 真实锚点相对部署分布可交换（或经密度比校正后近似可交换）；**(A30)** 支持重叠 `s_ov ≥ θ_ov`，且间隙分解上界 `|g| ≤ ĝ^+` 成立；**(A31)** 组合间隙次可乘 `A_g(π) ≤ 1+ζ(k-1)` 且相关项由 `β_ct` 保守界定。则对任意技能链 `π`：
```
P_{P_real}( p_real(π) ≥ p_lo(π) ) ≥ 1 - α
```
且若 `p_lo(π) ≥ p_req`，则按 `J+` 部署的真实成功率满足 `p_real(π) ≥ p_req`（以 `1-α` 概率）。组合情形
```
p_real(π) ≥ Π_i p_lo(S_i) - A_g Σ_i ĝ_i^+ - β_ct(k)
```
**样本复杂度**：在置信 `1-α` 下把证书半宽压到 `ε`，真实等效样本量需 `n_eff = O(ε^{-2} log(1/α))`；仿真只能降低方差（通过控制变量），**不能修复偏差**，因此真实锚点不可被仿真替代——这是与“纯 sim 训练”最本质的分界。

## 4. 实验设计 E162–E167

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 间隙谱估计（SGE） | 分维度 `\|ĝ - g_real\|` | MAE ≤ 0.05，交互项不过拟合 |
| E163 证书覆盖与紧致度（SRC） | 经验覆盖率 / 半宽 | 覆盖 ≥ 1-α，半宽 ≤ 0.10 @ n=50 |
| E164 间隙放大与长链坍塌（SAB） | 拟合 `A_g(k)` vs 界、k=1..10 成功率 | 界不低估计真值，长链预测误差 ≤ 5% |
| E165 主动校准样本效率（VoC） | 同预算下证书半宽、决策正确率 | 半宽降 ≥ 30%，决策正确率 ≥ 95% |
| E166 Real2Sim 回写（R2S） | 每轮 gap 收缩率、留出损失 | `γ_g < 1`，无“越调越差”回滚率 ≤ 10% |
| E167 联合部署（J+） | 真实成功率 / 误放行率 / 误拒绝率 | 成功率 +≥12%（vs 仅 ρ 或仅 sim），误放行 ≤ 5% |

**消融基线**：(a) 仅 sim 成功率点估计；(b) 单一全局 sim2real 系数；(c) 仅真实锚点 Clopper–Pearson；(d) 第 54 轮 `J` 不含成功率。E167 必须报告“误放行”和“误拒绝”两侧，避免用保守换虚假安全。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 间隙谱非平稳、真实分布漂移 | 高 | 在线漂移检验 + 滚动重校准 + gap 通胀 + 证书过期机制 |
| 密度比支持不足、外推失效 | 高 | `s_ov` 硬门 + 真实-only 回退 + 拒部署而非硬猜 |
| 组合界过保守或过乐观 | 高 | 实测 `A_g` 校准 + 长链压力测试 + checkpoint 分段持证 |
| 真实试验预算与安全 | 中 | VoC 贪心 + 安全围栏 + 仿真代理推荐 + 早停 |
| Real2Sim 过拟合/回路震荡 | 中 | 留出锚点 + 回滚门 + `γ_g<1` 收缩检验 + 连续不降冻结 |
| 成功率证书与 ρ/动作证书冲突 | 中 | `J+` 合取否决，禁止互相抵消；冲突即重校准 |

## 6. 本轮最大风险

**一句话**：把成功率证书化的最大风险是 **“证书的乐观偏差”**——`p_lo` 的 soundness 依赖真实锚点可交换、密度比有支撑、间隙谱在部署期平稳；一旦出现分布漂移或支持缺失，证书仍会输出一个看似严谨的乐观下界，而组合的间隙放大又会把它在长链上逐级放大，最终比没有证书更危险，因此必须以 **支持度硬门 + 漂移告警 + 证书过期/回滚** 三重护栏，默认拒绝而非默认放行。

### IP-121 SGE

```python
def estimate_gap_spectrum(policy, dims, sim, real_anchor_db, B=1000):
    G = {}
    for d in dims:
        pairs = match_rollouts(real_anchor_db, d)      # 同任务、同初始条件
        sim_succ  = mean(success(sim.run(policy, t)) for t, _ in pairs)
        real_succ = mean(success(r) for _, r in pairs)
        g = sim_succ - real_succ
        G[d] = GapPoint(g, ci=bootstrap_ci(pairs, B, alpha=0.05))
    # 分维度保序校准；禁止用全局线性系数外推到未见条件
    return GapSpectrum(G, ver=hash_versions(sim, policy))
```

### IP-122 SRC

```python
def success_certificate(policy, real_anchors, sim_rollouts, gap, alpha):
    alpha_r, alpha_g = split_alpha(alpha)              # 联合界 α = α_r + α_g
    n = len(real_anchors)
    w = density_ratio(sim_rollouts, real_anchors)
    n_eff = (w.sum()**2) / (w**2).sum()
    s_ov  = n_eff / n
    if s_ov < THETA_OV:
        return ('unsupported', s_ov)                   # 硬门：拒绝外推
    k = sum(success(r) for r in real_anchors)
    p_lo_real = clopper_pearson_lower(k, n, alpha_r)
    p_sim_hat = mean(success(s) for s in sim_rollouts)
    e_sim     = hoeffding_radius(len(sim_rollouts), alpha_r)
    g_hi      = gap.upper_confidence(alpha_g)
    p_lo_sim  = p_sim_hat - e_sim - g_hi
    p_lo      = max(p_lo_real, p_lo_sim)               # 两个有效下界取大
    return SuccessCert(p_lo, alpha=alpha, n_eff=n_eff, s_ov=s_ov,
                       g_hi=g_hi, ver=...)
```

### IP-123 SAB

```python
def success_aware_plan(G_skill, task, p_req, tau_task, Kmax, zeta, lambda_c):
    best = None
    for k in 1..Kmax:
        for path in bounded_paths(G_skill, task, k):
            p_lo  = prod(cert[s].p_lo for s in path)
            g_amp = min(1 + zeta*(k-1), measured_amp(path))
            eq    = g_amp * sum(gap_plus[s] for s in path)
            beta  = lambda_c * comb(k,2) * max_pairwise_corr(path)
            p_lb  = p_lo - eq - beta
            r     = optimal_retries(p_lb, p_req, tau_task, path)
            p_eff = 1 - (1 - p_lb)**r
            if p_eff >= p_req and cost(path, r) <= tau_task:
                best = max(best, (p_eff, cost(path, r), path, r))
    return best        # None = 未证成可部署（不是“物理不可行”）
```

```python
def active_calibrate(cert, candidates, budget, p_req):
    while budget > 0 and decision_margin(cert, p_req) > SAFE_MARGIN:
        for e in candidates:
            e.voi = expected_risk_reduction(cert, e) / cost(e)
        e = max(candidates, key=lambda x: x.voi)
        if e.voi <= 0:
            break
        z = run_real_trial(e)                  # 安全围栏 + 可回滚
        cert = bayes_update(cert, e, z)
        budget -= cost(e)
    return cert
```

## 3. 关键推导

**命题 1（成功率下界）** 设 `p_sim ≥ p_sim_hat - e_sim` 且 `g ≤ g_hi` 同时成立（概率 ≥ 1-α，联合界）。由 `p_real = p_sim - g`：
```
p_real ≥ p_sim_hat - e_sim - g_hi = p_lo^sim
```
又 `p_lo^real` 为真实锚点的 Clopper–Pearson 下界，故 `p_real ≥ max(p_lo^real, p_lo^sim) = p_lo`。

**命题 2（组合下界）** 在条件独立近似下 `p_sim(π) = Π_i p_sim(S_i)`，且 `p_sim(S_i) ≥ p_lo(S_i)`，`g(π) ≤ A_g Σ_i g_i^+ + β_ct`：
```
p_real(π) = p_sim(π) - g(π)
          ≥ Π_i p_lo(S_i) - A_g Σ_i ĝ_i^+ - β_ct(k)
```
相关项 `β_ct` 负责吸收条件独立被破坏时的误差：正相关使真实成功率高于乘积（该项保守），负相关必须显式扣除。

**命题 3（真实样本不可被仿真替代）** 记偏差 `bias = p_sim - p_real = g`、方差 `Var[p̂]`。增加仿真样本只降低 `Var[p̂_sim]`，不改变 `E[p̂_sim] - p_real = g`。因此若 `g` 未知，`p_lo → p_sim - ĝ` 的极限误差由 `|g - ĝ|` 决定；没有真实锚点时任何证书都无法 sound。此命题是 SRC 强制 `s_ov` 与证据版本的根据。

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SGE | O(\|𝔇\|·N_pair·T_sim + B·N_pair log N_pair) | O(\|𝔇\|·N_pair) | 配对回放、分维非单调、bootstrap 覆盖 |

| R2S | O(N_fail·dim θ + N_anchor) | O(dim θ) | 留出锚点、回滚门、收缩率检验 |
| SJC | O(\|D_ρ\| + \|𝔇\|) | O(1) 额外 | 合取否决、无补偿逻辑、版本一致 |

**正确性定理（Certified Sim2Real Success Soundness）**
假设第 54 轮 (A22)–(A28) 成立；新增 **(A29)** 真实锚点相对部署分布可交换（或经密度比校正后近似可交换）；**(A30)** 支持重叠 `s_ov ≥ θ_ov` 且间隙上界成立；**(A31)** `A_g(π) ≤ 1+ζ(k-1)` 且 `β_ct` 保守。则对任意技能链 `π`：
```
P_{P_real}(p_real(π) ≥ p_lo(π)) ≥ 1-α
p_real(π) ≥ Π_i p_lo(S_i) - A_g Σ_i ĝ_i^+ - β_ct(k)
```
若 `J+` 判定 `deploy`，则真实部署成功率 `p_real(π) ≥ p_req`（以 `1-α` 概率成立）。
