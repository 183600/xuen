# 第 1 轮 · SAJR：把 VLA 的 EE 意图重定向成「场景锚定 + 关节空间 + 扰动柔顺」的执行层

> 检索/复核日期：**2026-11-02（UTC）**。本轮先搜索核实赛事身份：`unibot.unitree.com` 的标题是 **UniBot World Challenge**，规则/任务/G1 平台与用户描述一致，未发现更可能的其他 UniBot。赛事身份：宇树 **UniBot 世界挑战赛**（G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API）。本轮承接状态文件第 12 轮 CHUNK-SERVO，不推倒它，而是把「EE 空间的 5 步视觉伺服」推进到「关节空间的场景自适应执行」；三个灵感词是「场景泛化」「关节驱动」「抗干扰」。

## 0. 先给结论：榜首不到 30%，共享瓶颈在 VLA 与 G1 关节之间的执行接口

截至 2026-11-02，官网榜单仍是 8 个模型：MolmoAct2 29.7%、WALL-OSS-0.5 28.5%、DreamZero 27.9%、Spirit-v1.5 25.9%、DM0 23.5%、π0.5 22.8%、GigaBrain-0 22.6%、GR00T N1.5 20.5%。但本轮重新核实的三个事实，把问题从「谁的 VLA 更大」改成了「谁的意图能落到 G1 的关节上」：

1. **榜单不是实测 SOTA，而是预览/合成信号**。`leaderboard_data.json` 的 `generated_from` 是 `gen_leaderboard.py`；8 个模型 ×32 任务做 `step ~ success` 回归，R² 均 >0.999999，最大残差 <0.006；256 个任务成功率里 232 个不是 10% 的整数倍（10 次 trial 只可能是 0/10…10/10）；详情页 32 个视频仍是「测试视频占位」。所以 29.7% 只能当难度/上限信号，不能当失败分布。
2. **数据集不是只有 EE 动作，它原生带关节动作**。本轮逐数据集读取 `meta/info.json`：32 个数据集共 **33,276 episodes / 18,282,246 frames / 169.28 h**，除 `action.left_ee_pose_gripper_base` 外，还有 `action.left_arm[7]`、`action.right_arm[7]`、`action.lower_body[15]`、`action.waist_action_joint[3]`、`action.pivot[7]`。也就是说，**挑战赛的 joint 控制模式在数据里有直接监督**，而官方 WLA 的 `unitree.yaml` 只把 EE、waist、base、legs 映射进 54 维动作，**没有手臂关节槽**。这是一个被低估的接口错位。
3. **上一轮关于腕部相机「没有内参」的判断需要修正**。2026-10-14 版本的 `meta/info.json` 里，`camera_params.wrist_left.color.camera_matrix` 和 `wrist_right` 都在（HangCup：fx≈436.4, fy≈435.9, cx≈323.9, cy≈242.9；PlugInEthernet：fx≈435.5, fy≈434.8）。G0 可以从「必须先标定」降级为「验证内参/畸变」；腕部 IBVS 和最后 1–2 cm 的闭环比上一轮更可行。

所以本轮的押注不是「再训一个更大的 VLA」，而是 **SAJR（Scene-Adaptive Joint Retargeting，场景自适应关节重定向）**：

> 用官方 WLA 做 EE 空间的长程意图规划；用场景锚定把意图平移到当前物体/受器；用约束 IK 把 EE 轨迹重定向成 G1 的关节轨迹（含关节限位、速度/加速度、冗余姿态）；用视觉编辑检测 + 跟踪误差扰动观测器在人为干扰时主动柔顺、重锚定、重规划。**唯一学习模型仍是 VLA；SAJR 全部是确定性控制器。**

一句话：**把「预测 1 秒的 EE 动作」改成「预测 1 秒的意图，落到可执行的 167 ms 关节块，并在被推/被移动时先柔顺再重锚定」。**

三个灵感词怎么落到方案里：

| 灵感词 | 落到哪里 | 不做什么 |
|---|---|---|
| **场景泛化** | 场景锚定（物体/受器相对位姿）+ 约束 IK 的冗余/可达性 + ROI 规范化；背景/干扰物/未见物品交给 VLA 与受控数据增强 | 不假设关节层能解决语义/外观泛化；不做第二个检测大模型 |
| **关节驱动** | `control_space="joint"`；7-DoF 臂 + waist/pivot 的约束 IK；关节限位/速度/加速度/抖动整形；用 33k 演示的 joint–EE 配对做系统辨识 | 不做 torque/力控闭环（API 没有）；不重训 6B 主干 |
| **抗干扰** | 视觉编辑检测（物体被移动）+ 一步跟踪误差扰动观测器（被推/被按住）+ admittance 柔顺 + 重锚定/重规划状态机 | 不做 30 Hz 广域网高增益伺服；不把「检测到人」当作必要条件 |

## 1. 三个灵感词怎么变成一个问题

### 1.1 场景泛化：5 条轴里只有 2 条是执行层能直接吃的

官方手册明确：每任务 10 次，5 类泛化各 2 次——位置、干扰物、桌面背景、未见物品、人为干扰。按 trial 权重，每条轴都是 20%。我的拆分是：

- **位置 + 人为干扰 = 40%**：这两条轴的核心是「目标/受器相对机器人变了，或执行中被移动了」。只要我们能估计当前物体/受器位姿并重定向轨迹，就有直接杠杆。
- **干扰物 + 背景 + 未见物品 = 60%**：这三条更偏感知/语义/数据覆盖。关节层只能通过「局部 ROI、相对目标、少依赖全局背景」间接帮忙；主战场仍是 VLA 的预训练与受控数据增强。

所以本轮不把「场景泛化」写成一个大而全的模型故事，而是先吃 40% 的可执行部分，再把 60% 拆成独立的数据工作流（P4），避免把所有希望押在关节层。

### 1.2 关节驱动：EE 空间的动作在 G1 上不一定「关节可行」

EE 空间策略的隐含假设是：只要 Cartesian 轨迹合理，IK 总能解出来。但 G1 的 7-DoF 臂 + waist 有硬限位、奇异位形、速度/加速度约束；挑战赛的 evaluator 还会用自己的 IK/控制器执行。我们在数据里能看到两个直接证据：

- 演示的 `action.left_arm` 与 `observation.state.left_arm` 只差约 0.01–0.02 rad/帧，说明关节动作是**下一帧的绝对关节目标**，不是抽象量；
- `action.pivot` 的 `height` 在演示中从 0.654 到 0.740 m 变化（约 9 cm），说明 G1 确实会用 pivot/height 调整工作高度；但 `lower_body`/waist 的 std 很小（多数任务 waist pitch std <0.06 rad），说明**手臂冗余是主战场，waist 是辅助**。

这意味着：把 EE 轨迹重定向到关节空间时，不能只做「逐点 IK」，还要做**冗余姿态选择**（肘部朝哪、腕部留多少余量）和**限位/速度整形**。这正是「关节驱动」能带来的、EE 模式拿不到的控制权。

### 1.3 抗干扰：人为干扰很可能不是「推机器人」，而是「移动物体」

手册对人为干扰的描述是「如临时改变物品位置等」。所以抗干扰要分两层：

1. **物体被移动**：视觉编辑检测 → 重估物体/受器位姿 → 更新场景锚 → 重定向轨迹；这一层不依赖力。
2. **机器人被推/被按住/接触卡住**：一步跟踪误差扰动观测器 → admittance 柔顺（目标向实测状态让一点）→ 停/重锚/重规划；这一层不需要力传感器，但需要标定低层控制器的跟踪特性。

上一轮的 GEO-RESIDUAL 已经给了「机器人动作解释不了的三维残差」；本轮把它接到「重锚定」而不是只做标注。DART 则是新增的、纯本体感觉的第二道保险。

## 2. 本轮核实/修正的事实（只列会改变方案的）

### 2.1 规则与接口（A 级：官方手册、提交 README、示例代码）

本轮重新抓取官网/规则/README：任务清单仍是 T01–T32，规则未变；数据集 `lastModified` 为 2026-10-14；排行榜 JSON 的 `Published Time` 为 2026-10-08。未发现新版本规则、任务或榜单更新。

- 32 任务，每任务 10 次；5 类泛化各 2 次；单次真机上限 **180 s**；只设通才单模型赛道；另有**不计分的单任务测试通道**；按 32 任务总平均成功率排序，同分看总平均步骤分，再同分看更早提交；评测跨 N 台机器人，提交须从 **8765** 起暴露 N 个连续端口，每端口独立、`reset()` 隔离。
- 观测：`cam_left_high`、`cam_right_high`、`cam_left_wrist`、`cam_right_wrist` 四路 RGB 480×640；双臂关节 `[7]`、EE 位姿 `[6]`（xyz+rpy，base 系）、夹爪 `[1]`、`lower_body[15]`、语言 `str`。**没有 depth、camera_info、force/torque、tactile。**
- 动作：`control_space` 只能 `"joint"` 或 `"ee"`，二者互斥；joint 模式是 `action.left_arm[7]`、`action.right_arm[7]` 的**目标关节位置**；ee 模式是 base 系绝对 `xyz+rpy`；共享 `action.left_gripper`、`action.right_gripper`、`action.pivot[7]`；`action_chunk_size` 固定，chunk 内不重新看世界，也没有打断机制；每次 `get_action` 都要带 `meta.token`。
- **WLA 与挑战赛的动作契约错位**：WLA 的 `unitree.yaml` 用 `action.base_command` + `action.waist_action_joint` 表达 base/waist，而挑战赛 API 用 `action.pivot[7]`；WLA 没有手臂关节槽，挑战赛 joint 模式却要 `action.left_arm/right_arm`。SAJR 的 adapter 必须先把这三件事对齐，PIVOT-PROBE 是第一步。
- 评测端逐调用记录延迟、波动和动作统计规律，作为结果可信度的一部分。**chunk size 是控制参数，不是推理参数。**

### 2.4 头部方案的做法与共享瓶颈（A+B 级）

| 模型家族 | 公开路线 | 优势 | 与本轮相关的瓶颈 |
|---|---|---|---|
| **MolmoAct2** | Ai2 的 action reasoning model；Molmo 2-ER + action expert + adaptive depth reasoning；大规模双臂数据 | 3D/空间语义强；推理快；双臂 | 仍是 EE 空间开环 chunk；最后插入/挂/拉链的关节可行性与接触精度 |
| **WALL-OSS-0.5** | X Square 的 4B VLA（3B VLM + action expert） | 预训练直接可用；progress 高 | progress ≠ success；最后一步失败就 0 分；4B 实时性 |
| **DreamZero** | 14B Wan2.1 video-diffusion world-action model | 长程预测/规划 | 14B 推理重；世界模型不直接解决接触力/毫米级对齐；1 秒 chunk 更危险 |
| **π0.5** | Physical Intelligence 的开放世界泛化 VLA | 语义/新场景泛化 | 接触密集任务的精度；远程部署延迟 |
| **GigaBrain-0** | 世界模型生成数据 + VLA | 数据效率/泛化 | 生成数据的物理保真度；最后 3 厘米 |
| **GR00T N1.5** | NVIDIA 通用人形 VLA | 生态/embodiment | 任务特定精度；数据覆盖 |

共同点：

- 都是 **EE 空间 + action chunk 开环执行**；chunk 内不看新图，接触事件发生在 chunk 内部时只能等下一个 chunk。
- 模型越大，chunk 往往越长，越不反应；长 chunk 与接触精度直接冲突。
- 世界模型解决「想象未来」，不解决「现在偏了 2 mm / 关节快到限位」。
- 单模型规则让「再加一个学习残差」危险；但「确定性关节控制器」不是第二个模型。

### 2.5 近期工作：三条线都在往「执行层/本体感觉」走（A 级：arXiv 摘要，2026-10-30 前后）

- **2610.37801, An Empirical Study of Wrist-Target Construction and Joint-Angle Limits in Humanoid Arm Retargeting**：在 Unitree H1-2 上，重建的腕部目标会让 20 次前伸中的 10 次碰到关节限位；reach-normalized 目标则 0 次。直接证明「EE 目标 → 关节」不是免费的，关节限位是实际失败源。
- **2610.35862, Learning Force-Reactive Humanoid Loco-Manipulation (FLORE)**：用双手力传感 UMI + 可穿戴追踪，扩散策略输出动作与每手力命令，混合柔顺全身控制器跟踪力。说明「力反应 + 全身柔顺」是 2026 年的活跃方向；但它需要 F/T 传感器，我们只能用本体感觉代理。
- **2610.35075, Zero-HLM: Generalizable Humanoid Loco-Manipulation without Real Robot Data**：手机采集 + 真实到仿真 + 4,800 条物理验证演示，GR00T N1.7 在 3 个 G1 任务上 66.7% 全任务成功率，vs 真实数据 46.7%。说明「受控的场景/数据生成」对泛化有真实杠杆，但也说明仿真保真度是门槛。
- **2610.26584, HAF-VLA: Hierarchical Action Flow Framework for Humanoid VLA Control**：人形必须协调 locomotion、posture、gaze、双臂；单次生成整段 action chunk 容易导致不稳定的上身补偿。说明「分层/分阶段动作流」是必要方向；我们的 SAJR 是更轻的「执行层分层」。
- **2610.33565, WorldFailBench** 与 **2610.28431, TaskWAM**：世界模型能评估结果，但不一定忠实模拟「怎么失败/在哪一步失败」；世界动作模型会出现 stage confusion。支持我们「不把世界模型当接触精度解药」的判断。
- **2610.34519, TRIAGE**：VLA 推理的视觉 token 重用/剪枝是实时性的重要方向；对我们意味着「不要把所有算力压在更大的主干上」。

这些工作共同指向一个空白：**把「EE 意图 → 关节可行轨迹 → 本体感觉抗扰」做成一个单模型合规、可远程部署的确定性执行层。** 这正是 SAJR。

## 3. 诊断：三个「最后」和一条隐藏的接口裂缝

把一次失败拆开：

```text
t0: 观测 → VLA 推理 (100–300 ms) → 返回 30 步 EE chunk
t0+0.1s: evaluator 用自己的 IK/控制器开始执行
t0+0.1s … t0+1.1s: 机器人开环执行 30 步
        ↑ 接触/滑移/人移动物体/关节接近限位都发生在这一段
t0+1.1s: 才看到下一帧 → 已经晚了
```

三个「最后」：

1. **最后 3 cm**：插入/挂/叠/拉链/锁/拧的接触精度。
2. **最后 0.3 s**：接触事件发生在 chunk 内部，等下一个 chunk 已经晚了。
3. **最后 1–2 个关节自由度**：EE 轨迹在 Cartesian 空间没问题，但肘/腕/waist 到了限位或奇异位形，执行器只能饱和/抖动。

隐藏裂缝：**VLA 输出 EE，evaluator 做 IK，选手既看不到 evaluator 的 IK 参数，也控制不了关节冗余。** 如果改用 `control_space="joint"`，选手自己拥有 IK/冗余/限位/柔顺的控制权；代价是要自己保证 IK 精度和关节语义正确。数据集恰好提供了 joint–EE 配对，给了我们校准 FK/IK 的条件。

## 4. 方法：SAJR

### 4.1 总架构

```text
                    ┌─────────────────────────────────────┐
                    │  Evaluator (N ports 8765..8765+N-1) │
                    └──────────────┬──────────────────────┘
                                   │ obs / joint chunk
                                   ▼
                    ┌─────────────────────────────────────┐
                    │  Per-port SAJR (CPU, deterministic) │
                    │  ├─ visual edit / anchor observer   │
                    │  ├─ scene anchor T_anchor           │
                    │  ├─ constrained IK + nullspace      │
                    │  ├─ joint safety / shaping          │
                    │  ├─ disturbance observer + admit.   │
                    │  └─ plan cache (30-step VLA plan)   │
                    └──────────────┬──────────────────────┘
                                   │ async, batched
                                   ▼
                    ┌─────────────────────────────────────┐
                    │  Shared VLA server (GPU)            │
                    │  UnifoLM-WLA-1.0, EE-relative 30步  │
                    └─────────────────────────────────────┘
```

- **唯一学习模型**：WLA（EE 意图）。SAJR 不含学习权重。
- **数据资产**：33k 演示的 joint–EE 配对 → FK/IK 标定、关节跟踪模型、姿态先验、场景锚定参考。
- **数字孪生**：只做 IK/柔顺/延迟/扰动风洞，不训策略。
- **每端口独立**：SAJR 是 CPU 轻量；VLA 服务共享，session 隔离。

### 4.2 场景锚定（SCENE-ANCHOR）

不要把「目标」定义成一张绝对图片，而定义成**物体/受器相对位姿**：

```text
离线：对每个任务/阶段取成功演示关键帧 k
  T_B_O* = 受器/目标在 base 系的参考位姿
  T_B_E*(k) = 演示夹爪位姿
  T_O_E* = inv(T_B_O*) · T_B_E*(k)      # 受器→夹爪的相对目标
  I_wrist*(k) = 腕部目标图

在线：
  T_B_O(t) = 头双目 + 局部几何/模板估计的当前受器位姿
  T_anchor = T_B_O(t) · inv(T_B_O*)
  T_B_E^des = T_anchor · T_B_E^plan      # 把 VLA 的 EE 计划平移到当前场景
```

- **位置泛化**：受器移动 → `T_B_O(t)` 变 → 计划跟着变。
- **人为干扰（移动物体）**：视觉编辑检测触发重估 → `T_anchor` 更新。
- **背景/干扰物**：只用局部 ROI/物体几何，不用全局背景。
- **未见物品**：只要受器/任务几何不变，`T_O_E*` 不变；外观由 VLA 处理；锚定置信度低就回退原计划。

### 4.3 约束 IK / 关节重定向

给定 `T_B_E^des[k]`，解 7-DoF 臂（+ waist/pivot，如果语义确认）的关节目标：

```text
e = log(T_B_E(q)^{-1} T_B_E^des)          # 6D 位姿误差
J = ∂e/∂q
Δq = J^T (J J^T + λ²I)^{-1} e
     + (I - J^T (J J^T + λ²I)^{-1} J) z   # 零空间
z = k_p (q_nom - q) + k_m ∇μ(q)            # 姿态先验 + 可操作度
q ← clamp(q + Δq, q_min, q_max)
```

- `q_nom`：同任务/同阶段最近演示的关节均值，或「肘下、腕中」的通用姿态。
- `μ(q)=sqrt(det(J J^T))`：避免奇异；只做轻量梯度/采样，不引入学习模型。
- 每帧最多 1 cm / 0.05 rad 的修正；超出就分多帧，避免跳变。
- 用数据集的 joint–EE 配对做系统辨识：连杆长度、关节零位、TCP 偏移、相机外参；目标是重投影/位姿误差 ≤5 mm/1°。**如果 IK 误差 >1 cm/3°，回退 EE 模式**，不要把整场比赛押在标定上。

### 4.4 扰动观测器 + 柔顺（DART）

没有力传感器，就用「命令 vs 实测」的跟踪残差做代理：

```text
一步预测：q_pred(t+1) = f_id(q_meas(t), q_cmd(t))   # 每关节一阶模型
残差：    r_t = q_meas(t+1) - q_pred(t+1)
分数：    d_t = ||W r_t||₂                          # W 用演示自由空间 std 归一化
柔顺：    β_t = clip((d_t - θ)/θ, 0, β_max)
命令：    q_cmd'(t) = q_cmd(t) + β_t (q_meas(t) - q_cmd(t))
```

- 自由空间 `β=0`；预接触 `β≈0.2`；接触 `β≈0.4`；人为推/按住 `β→0.8`。
- `d_t` 连续 K 帧超阈值 → 进入 `RECOVER`：停 → 重估 `T_B_O` → 可见则更新锚，不可见则 VLA 重规划 → 保守增益恢复。
- 这是「让一点」而不是「力控」；不声称能估计真实力。低层控制器很硬时，目标偏移仍能产生柔顺效果；很软时，阈值要重标。
- **人为干扰若只是移动物体，视觉编辑检测是主检测器；DART 是接触/推压的副检测器。** 两者互补，不互相替代。

### 4.5 双频 chunk

```text
VLA:   每 30 步（1 s）产出一个 30 步 EE plan；后台线程；不阻塞 get_action
SAJR:  每 5 步（167 ms）做一次锚定/IK/柔顺；返回 5 步 joint chunk
API:   metadata.action_chunk_size = 5；evaluator 执行 5 步后再次调用
```

- 5 步 @30 Hz = 167 ms；含 RTT 约 200–320 ms，足够接触段的 1–2 次修正。
- VLA 推理摊薄到 6 个执行块；CPU 只做 IK/锚定/柔顺，不抢 GPU。
- `action_chunk_size` 在 metadata 里固定，不能运行时动态改；所以「短 chunk + 异步长 plan」是唯一可行的双频方式。

### 4.6 可选升级：J-ACT（原生关节动作头）

如果 SAJR 的 IK 成为瓶颈，再做 J-ACT：把 WLA 的动作布局扩展 14 维手臂关节槽，用数据集的 `action.left_arm/right_arm` 直接监督，冻结 VLM、只训 action expert，输出关节块，彻底绕过 IK。它是**单模型**（同一个 action head 的扩展），但风险是关节空间过拟合、丢失 VLM 的 EE 泛化。做法是 A/B：J-ACT vs EE+SAJR，只在接触任务赢且语义任务不回归时采用。

### 5.2 每个点的动机、差异、可行性、资源、步骤、风险

#### P0 · SAJR（本轮主押注）

- **动机**：EE 策略把 IK/限位/冗余留给 evaluator；位置+人为干扰占 40% trial；接触任务占 19/32；最后 1–2 个关节自由度是隐藏失败源。
- **与现有方案的差异**：大多数队伍用 `control_space="ee"` + evaluator IK + 30 步 chunk；SAJR 改用 `joint` 模式，自己拥有 IK/冗余/限位/柔顺，且把 chunk 降到 5 步。它不是第二个模型，是确定性执行层。
- **技术可行性**：G1 URDF + 33k 演示的 joint–EE 配对 + 30 Hz 本体状态 + CPU；WLA 仍做 EE 规划；官方仿真可做风洞。
- **所需资源**：1 名控制/几何工程师 ×3 周；1×24GB GPU 做标定/仿真；每端口 <1 CPU 核。
- **落地步骤**：G0 FK/IK/TCP 标定 → G2 仿真收敛/延迟 → G3 单任务 A/B → G6 32 任务干跑。
- **风险**：IK/TCP 标定误差、pivot 语义不符、低层控制器未知、关节顺序/符号错误。**任一不过门就回退 EE 模式**。

#### P1 · DART（抗干扰主模块）

- **动机**：人为干扰 20%；接触任务没有力传感器；低层控制器在外部推/按住时会产生可测的跟踪残差。
- **与现有方案的差异**：不训残差策略、不假设有力传感器；用一步预测残差做扰动分数，用 admittance 目标偏移实现柔顺，用状态机恢复。
- **技术可行性**：joint 命令/实测 30 Hz；演示可标定每关节自由空间 std；仿真可注入推/延迟。
- **所需资源**：1 名工程师 ×2 周；CPU；仿真 1 GPU 周。
- **落地步骤**：G4 检测延迟/恢复率 → 单任务人为干扰 A/B → 全量。
- **风险**：误报/漏报、低层控制器太硬导致柔顺无效、延迟下振荡。**视觉编辑检测作为主检测器，DART 只做副检测器**。

#### P2 · SCENE-ANCHOR（场景泛化主模块）

- **动机**：位置 20%；人为干扰移动物体；背景/干扰物；绝对轨迹在场景变化下失效。
- **与现有方案的差异**：不是「再检测一个 6D 位姿网络」，而是用受器相对位姿 + 局部几何/模板 + 在线重锚定；锚定作用在 EE 计划上，再由 SAJR 落到关节。
- **技术可行性**：头双目已标定（fx≈282, baseline 58.25 mm）；腕部内参本轮确认可用；33k 演示可建目标库。
- **所需资源**：1 名工程师 ×3 周；CPU/轻量 GPU；存储 <1 GB（关键帧/目标图）。
- **落地步骤**：G1 目标检索/位姿误差 → G3 位置 A/B → G4 人为移动恢复。
- **风险**：透明/反光/遮挡导致深度失败；未见物体无模板；锚定误差 >2 cm 时不稳定。**置信度低就回退 VLA 原计划。**

#### P3 · J-ACT（可选升级，门控）

- **动机**：数据原生有 `action.left_arm/right_arm`；EE 头在单 embodiment 上会丢姿态信息；IK 是误差源。
- **与现有方案的差异**：扩展 WLA 动作布局（+14 维手臂关节），冻结 VLM、只训 action expert；输出关节块，不经 IK。仍是单模型。
- **技术可行性**：33k 演示有直接监督；官方 fine-tune 代码支持冻结 VLM/24GB/LoRA；需改 `action_mapping`/`SLICES`/model server 协议。
- **所需资源**：2–4 GPU 周；1 名工程师 ×4 周。
- **落地步骤**：数据配置/布局扩展 → 训练 → 离线 joint MAE/FK 误差 → G3 A/B（vs EE+SAJR）。
- **风险**：关节空间过拟合、丢 VLM 泛化、server 协议改动大。**只在 SAJR 的 IK 被证明是瓶颈时启动。**

#### P4 · SCENE-CANON（数据/感知线）

- **动机**：背景/干扰物/未见物品占 60% trial；VLA 对全局外观敏感。
- **与现有方案的差异**：Tier 1 用 ROI 裁剪/规范化 + 背景/干扰物图像增强 + LoRA 一致性微调；Tier 2 用官方仿真/真实到仿真生成受控场景。都是同一个模型，不引入第二个策略。
- **技术可行性**：官方 IsaacLab/MuJoCo + 33k 演示；Zero-HLM 路线证明受控数据有效；但资产/保真度是门槛。
- **所需资源**：Tier 1 1–2 GPU 周；Tier 2 4+ GPU 周 + 3D 资产；1 名工程师 ×4 周。
- **落地步骤**：G8 单任务分轴测试 → Tier 1 → 只有 Tier 1 涨点才做 Tier 2。
- **风险**：sim-to-real gap、分布外伪影、算力/资产成本。**不把仿真成功率当真机成功率。**

#### P5 · PORTFOLIO（竞赛策略）

- **动机**：320 trials 是投资组合；5 条轴各 20%；单任务通道是唯一敢做 A/B 的地方。
- **与现有方案的差异**：按 `q_t × Δ_axis / cost_t` 分配工程；先锁安全基线，再逐层加 SAJR/DART/锚定；不把预览榜单当真实难度表。
- **技术可行性**：规则允许单任务通道；无需额外算力。
- **所需资源**：评测时间；1 名工程师 ×1 周。
- **落地步骤**：选 5 个代表任务 → 配对 A/B → 更新优先级 → 全量。
- **风险**：评测噪声（320 trials SE≈2.4pp）；单任务通道与全量分布不同。**用配对 bootstrap，不把 +1–2pp 当结论。**

#### P6 · PIVOT-PROBE（接口标定，必做）

- **动机**：API 的 `action.pivot[7]` 只写「Lower-body / pivot target」；数据集里是 `[vx, vy, angle_z, ?, ?, ?, height]`；中间 3 维语义不明；joint 顺序/符号也可能有坑。
- **与现有方案的差异**：不猜；在单任务通道发小 delta，记录 `lower_body[15]`/EE 位姿响应，拟合映射；同时验证 joint 模式是绝对目标还是增量。
- **技术可行性**：API + 单任务通道即可；1 周。
- **所需资源**：评测时间；无额外算力。
- **落地步骤**：G0 的一部分；先零 pivot + 只控双臂，再逐步加 height/waist。
- **风险**：探测动作可能触发安全/失败；用小幅度、限速、可回退。

### 5.3 剪枝（明确不投）

- **从零训 VLA/World Model**：官方 WLA 已开源 6B，算力边际收益低。
- **完整 sim-to-real 策略训练**：仿真只做控制器风洞；不假设 sim 成功率预测真机。
- **30 Hz 广域网视觉伺服**：RTT 不允许；用 5 步 chunk + 异步 plan。
- **第二个学习残差策略**：单模型风险；DART 是确定性控制器。
- **6D 物体位姿网络**：透明/变形不可靠；用相对目标 + 局部几何。
- **力/触觉闭环**：API 没有；DART 用跟踪残差代理，不声称真力控。
- **32 个任务各训一个策略**：规则禁止，且不泛化。
- **运行时动态改 chunk size**：metadata 固定；只能固定 5 步 + 异步长 plan。
- **把预览榜单的任务排名当难度表**：已证伪；只当弱先验。

## 7. 竞赛策略：先吃 40%，再谈 60%

### 7.1 算术

- 总分 `S = (1/32) Σ_t p_t`；每条泛化轴权重 0.2。
- 位置轴 +15pp → `0.2×15 = +3.0pp`；人为干扰轴 +15pp → 再 +3.0pp；两项合计 **+6pp**（未计重叠）。
- 背景/干扰物/未见物品各 +5pp → `0.2×5×3 = +3.0pp`。
- 保守合计 **+4–6pp**；乐观 +8–9pp；320 trials 的 SE≈2.4pp，必须配对 A/B + bootstrap。
- 目标：把 29.7% 的预览上限推到 **34–38%**（设计目标，不是承诺）。

### 7.2 任务组合（先验，待单任务通道更新）

- **A 档：关节/接触优先（19 个）**：HangCup、DisconnectEthernet、ToolboxStorage、PlugCharger、Unlock、ArrangeTestTubes、OpenPillBottle、OrganizeStationery、PackBag、ZipUp、PaperCupStacking、StoreRacket、StackCups、PlugInEthernet、StackBowls、StoreEarphones、PackPhone、OrganizePencilCase、SyringeWaterTransfer。
- **B 档：VLA/语义优先（13 个）**：FruitCollection、PackDoll、FruitSorting、ColorArrangement、PlacePhotoFrame、OrganizeBookshelf、PickOutBatteries、OrganizeTools、FoldTowel、ArrangePlates、SpellRobot、ConveyorSorting、RemovePinnedNote。
- **C 档：低投入/观察**：单任务通道里 `p_t` 接近 0 且失败在早期感知/抓取的任务；保留 VLA 基线。

优先级：

```text
priority_t = q_t × Δ_t / cost_t
q_t   = 失败发生在最后 3 cm / 关节限位 / 被干扰的比例（先验，单任务后更新）
Δ_t   = SAJR/DART 的条件增益（配对 A/B）
cost_t = 标定/目标库/评测成本
```

先做 A 档中 `q_t` 最高、`cost_t` 最低的 3–5 个：**PlugInEthernet（预览榜最难）、HangCup、ZipUp、StackBowls、FoldTowel（负对照）**。再加一个 **人为干扰 A/B**（HangCup 或 PlugInEthernet）。

### 7.3 单任务通道协议

| 项 | 设计 |
|---|---|
| 任务 | PlugInEthernet、HangCup、ZipUp、StackBowls、FoldTowel |
| 次数 | 每任务 5 次 A/B（EE 基线 vs SAJR；SAJR vs SAJR+DART） |
| 初始条件 | 同一位置/背景；尽量配对 |
| 指标 | 成功率、步骤分、耗时、p99 延迟、恢复次数、碰撞 |
| chunk | 先固定 5；通过后扫 3/8 |
| 通过 | ≥3/5 任务 +10pp；FoldTowel 不回归 >5pp |
| 统计 | 配对差值 + bootstrap 95% CI；CI 跨 0 就扩样本或放弃 |

### 7.4 提交节奏

1. **W0**：WLA + API adapter + `control_space="joint"` 基线；PIVOT-PROBE；单任务跑通。
2. **W1**：安全基线（若允许多次提交）锁「更早提交」tie-break。
3. **W2–W3**：FK/IK/TCP 标定；SAJR 关节层；仿真收敛。
4. **W4–W5**：SCENE-ANCHOR + DART；单任务 A/B。
5. **W6**：chunk/gain 扫描；32×10 干跑；最终提交。
6. 若只允许一次提交：跳过 W1，W5 后再交；不要用正式 320 trials 做未验证的 A/B。

## 8. 风险与合规

| 风险 | 影响 | 缓解 |
|---|---|---|
| 单模型解释 | 被判定为第二个模型 | SAJR/DART/锚定全为确定性控制器；J-ACT 是同一模型的动作头扩展；提交材料写清楚 |
| joint 语义/顺序/符号错误 | 动作被拒/机器人乱动 | PIVOT-PROBE + `example_env.py` + 单任务小幅度测试；保留 EE 回退 |
| pivot 7 维语义不明 | waist/height 不可控 | 先零 pivot + 只控双臂；用数据集 pivot 均值；逐步探测 |
| IK/TCP 标定误差 | 最后 3 cm 偏差 | joint–EE 配对最小二乘；误差 >1 cm/3° 回退 EE |
| 低层控制器未知 | DART 阈值/柔顺失效 | 一步系统辨识；仿真扫延迟/增益；保守 β |
| API 图像与数据集相机不同源 | 深度/锚定偏差 | 用已知图案/重投影验证；必要时自标定；置信度低回退 |
| 人为干扰是移动物体而非推机器人 | DART 漏检 | 视觉编辑检测为主；DART 只做副检测器 |
| 透明/反光/遮挡 | 锚定/深度失败 | 局部几何 + 腕部 IBVS；置信度低回退 |
| 远程 RTT 高 | 5 步块仍不够 | 测 RTT；加阻尼/预测；必要时 chunk 8 |
| 评测噪声 | +1–2pp 假阳性 | 配对 A/B、bootstrap、重复实验；320 trials SE≈2.4pp |
| 数据泄漏 | 离线指标虚高 | 按 session/物体/背景分组划分；相邻帧不跨 split |
| 安全 | 柔顺/重抓碰撞 | 限速/限幅/最大重试；扰动即停；不追求高增益 |

## 9. 一句话押注

**用官方 WLA 做 EE 意图规划，用受器相对位姿把意图锚到当前场景，用约束 IK 把它重定向成 G1 的关节轨迹，再用视觉编辑检测 + 跟踪误差扰动观测器在人为干扰时先柔顺再重锚定；不新增学习模型，先吃下位置泛化与人为干扰这 40% 的 trial。**

# 第 1 轮产物 · SAJR 技术报告

> 检索/复核日期：**2026-11-02（UTC）**。对象：宇树 **UniBot 世界挑战赛**（G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API）。本报告是想法区「SAJR」的工程化产物；承接第 12 轮 CHUNK-SERVO，不替换它，而是把「EE 空间 5 步视觉伺服」推进到「关节空间场景自适应执行」。

## 0. 结论与边界

### 0.1 一句话结论

官方 WLA 的 EE 相对动作 + 30 步 chunk 是吞吐优势，也是关节可行性与接触精度的结构性弱点；把执行改成 `control_space="joint"`，用场景锚定把 EE 意图平移到当前受器、用约束 IK 重定向成 G1 关节轨迹、用一步跟踪误差观测器做柔顺，可以在**不新增学习模型**的前提下，主要改善位置泛化与人为干扰这 40% 的 trial，并把最后 3 cm 的反馈周期从 1 s 降到 167 ms 执行块（含 RTT 约 200–320 ms）。

| 等级 | 含义 | 本报告中的例子 |
|---|---|---|
| A | 官方文档、提交模板、数据集元数据、排行榜 JSON 直接核实 | 32 任务/10 次/5 轴；API 四路 RGB、joint/EE；33,276 eps；WLA chunk 30@30 Hz |

### 0.3 本轮不做什么

- 不从零训 VLA/World Model；官方 WLA 已开源 6B 基座。
- 不做完整 sim-to-real 策略训练；数字孪生只做控制器风洞。

## 2. 问题形式化

### 2.1 评分与不确定性

```math
S = \frac{1}{32}\sum_{t=1}^{32} p_t,\qquad
p_t = \frac{1}{10}\sum_{j=1}^{10} y_{t,j},\quad y_{t,j}\in\{0,1\}.
```

320 trials、`p≈0.25` 时：

```math
\mathrm{SE}(S)\approx \sqrt{\frac{p(1-p)}{320}}\approx 0.0242.
```

每条泛化轴权重 0.2：

```math
\Delta S_{\text{pos}} = 0.2\,\Delta p_{\text{pos}},\qquad
\Delta S_{\text{human}} = 0.2\,\Delta p_{\text{human}}.
```

位置 +15pp、人为干扰 +15pp → 合计 `+6pp`（未计重叠）；背景/干扰物/未见物品各 +5pp → 再 `+3pp`。保守目标 +4–6pp。

### 2.2 接口时间模型

```math
T_{\mathrm{fb}} \approx \frac{H_c}{f_c} + \tau.
```

| 场景 | `H_c` | `f_c` | `τ` | `T_fb` | 评价 |
|---|---:|---:|---:|---:|---|
| WLA 默认 | 30 | 30 | 50 ms | **1050 ms** | 接触段基本开环 |
| SAJR 保守 | 5 | 30 | 50 ms | **217 ms** | 可做 1–2 次接触修正 |
| SAJR 低延迟 | 5 | 30 | 20 ms | **187 ms** | 需低 RTT |
| SAJR 高延迟 | 5 | 30 | 150 ms | **317 ms** | 增益降档 |
| 低控制频率 | 5 | 10 | 50 ms | **550 ms** | 改 `H_c=3` 或只做 PBVS |
| 极低延迟 | 3 | 30 | 20 ms | **120 ms** | 动态任务可用 |

`action_chunk_size` 在 metadata 固定，不能运行时动态改；因此「固定 5 步 + 后台 30 步 plan」是唯一可行的双频。

### 2.3 坐标与变量

- `B`：机器人 base 系；`E_L/E_R`：左右夹爪 TCP；`O`：受器/目标；`C`：头相机。
- `q_L,q_R ∈ R^7`：手臂关节；`w ∈ R^3`：waist；`p ∈ R^7`：pivot。
- `T_B_E`：EE 位姿，来自 `observation.state.*_ee_pose_gripper_base`（xyz+rpy）。
- `T_B_O*`：演示/参考受器位姿；`T_B_O(t)`：当前估计。
- `T_O_E* = T_B_O*^{-1} T_B_E*(k)`：受器→夹爪相对目标。
- `T_anchor = T_B_O(t) T_B_O*^{-1}`；`T_B_E^des = T_anchor T_B_E^plan`。

### 2.4 扰动模型

没有力/力矩，只有关节位置。设低层控制器在自由空间的跟踪可用一阶模型近似：

```math
q_{t+1} = q_t + \alpha (q^{cmd}_t - q_t) + \beta + \epsilon_t,
```

`α,β` 每关节从演示最小二乘；`ε_t` 自由空间残差。外部扰动使 `ε_t` 偏离：

```math
r_t = q^{\mathrm{meas}}_{t+1} - \big(q^{\mathrm{meas}}_t + \alpha(q^{cmd}_t - q^{\mathrm{meas}}_t) + \beta\big),
\qquad d_t = \|W r_t\|_2.
```

`W = diag(1/σ_j)`，`σ_j` 为演示自由空间残差 std。`d_t > θ` 连续 K 帧 → 扰动/接触。

## 3. SAJR 设计

### 3.1 进程/端口拓扑

```text
                    ┌─────────────────────────────────────┐
                    │  Evaluator (N ports 8765..8765+N-1) │
                    └──────────────┬──────────────────────┘
                                   │ obs / joint chunk
                                   ▼
                    ┌─────────────────────────────────────┐
                    │  Per-port SAJR (CPU)                │
                    │  ├─ edit/anchor observer            │
                    │  ├─ T_anchor estimation             │
                    │  ├─ constrained IK + nullspace      │
                    │  ├─ joint safety / shaping          │
                    │  ├─ disturbance observer + admit.   │
```

### 3.3 `get_action` 伪代码

```python
class SAJRPolicy:
    def get_action(self, obs):
        self._tick(obs)                 # 保存 q_meas, EE, images, 时间戳
        self._maybe_request_plan(obs)   # 异步 VLA，不阻塞

        if self.plan is None:
            self.plan = self.vla.predict(obs)   # 冷启动；超时则 hold
            self.plan_idx = 0

        # 1) 场景锚定
        T_anchor, c = self.anchor.estimate(obs, self.task)
        if c < self.c_min:
            T_anchor = np.eye(4)

        # 2) 取 5 步 EE 计划，锚定后转绝对
        ee_rel = self.plan[self.plan_idx : self.plan_idx + self.H_c]
        T_ee_des = self.anchor.apply(T_anchor, ee_rel, obs)

        # 3) 约束 IK + 关节安全
        q_des = self.ik.solve(T_ee_des, obs)
        q_des = self.safety.shape(q_des, obs)

        # 4) 扰动观测 + 柔顺
        d = self.dart.score(obs)
        if d > self.theta:
            q_des = self.dart.admit(q_des, obs, d)
        if self.dart.should_recover(obs):
            self.state = "RECOVER"
            q_des = self.dart.hold(obs)

        self.plan_idx += self.H_c
        if self.plan_idx >= len(self.plan):
            self.plan = None

        return self.adapter.to_api(q_des, obs, self.token)
```

`_maybe_request_plan`：

```python
def _maybe_request_plan(self, obs):
    if self._future is not None and not self._future.done():
        return
    if self._future is not None:
        self.plan = self._future.result()
        self.plan_idx = 0
        self._future = None
    if self.plan is None or self.plan_age > self.plan_ttl:
        snapshot = copy_obs(obs)
        self._future = self.executor.submit(self.vla.predict, snapshot)
```

规则：

- VLA 永远不阻塞 `get_action`（除冷启动）；plan 过期就用旧 plan + 锚定/柔顺。
- 任何异常 → 返回上一组合法 chunk 或安全 hold；绝不返回 NaN/错误形状。
- 每个 chunk 只做一次 IK/柔顺；求解失败 → 回退上一组关节目标或 EE 模式（如果 evaluator 允许切换；metadata 固定，所以只能回退到 hold）。

### 3.4 FK/IK/QP 推导

先把 WLA 的相对 EE 动作 compose 成绝对计划：`T_B_E^plan[k] = T_B_E(t) exp(Δξ_k)`（`Δξ_k` 为 xyz+rotvec），再经 `T_anchor` 得到 `T_B_E^des`。给定 `T_B_E^des` 和当前 `q`：

```math
T_{err} = T_B_E(q)^{-1} T_B_E^{des},\qquad
e = \begin{bmatrix} t_{err} \\ \log(R_{err}) \end{bmatrix}\in\mathbb R^6.
```

雅可比 `J = ∂e/∂q`。阻尼最小二乘：

```math
\Delta q = J^\top (J J^\top + \lambda^2 I)^{-1} e
        + \big(I - J^\top (J J^\top + \lambda^2 I)^{-1} J\big) z,
```

```math
z = k_p (q_{nom} - q) + k_m \nabla \mu(q),\qquad
\mu(q)=\sqrt{\det(J J^\top)}.
```

- `λ`：阻尼，接近奇异时增大；`λ^2 = λ_0^2 (1 + (μ_0/μ)^2)`。
- `q_nom`：同任务/阶段最近演示的关节均值；或「肘下、腕中」的通用姿态。
- 每次迭代 `q ← clamp(q + Δq, q_min, q_max)`；`||Δq||∞ ≤ 0.05 rad`；外层 5–10 次。
- 速度/加速度整形：`|q_{k+1}-q_k| ≤ v_max/f_c`；`|q_{k+1}-2q_k+q_{k-1}| ≤ a_max/f_c^2`；jerk 低通。
- 如果 `T_B_E` 误差 >1 cm/3°，回退 EE 模式；不要用错误的 IK 硬跑。

### 3.5 关节系统辨识

用 33k 演示的 `(q_meas(t), q_cmd(t), q_meas(t+1))` 拟合每关节一阶模型：

```math
q_{t+1} = a_j q_t + b_j q^{cmd}_t + c_j + \epsilon_t.
```

最小二乘得到 `a_j,b_j,c_j`；自由空间残差 std `σ_j`。用途：

- DART 的一步预测 `q_pred`；
- 前馈超前：对期望轨迹 `q_des(t)`，命令 `q_cmd(t) = q_des(t+1) + ((1-a_j)/b_j)(q_des(t+1)-q_des(t))` 的简化 lead（按实际拟合调整）；
- 判断低层控制器是「位置跟踪」还是「速度/增量」语义；如果拟合残差很大，说明模型不对，DART 只用相对阈值。

注意：这不是学习策略，是系统辨识；不违反单模型。

### 3.6 DART：扰动观测 + 柔顺 + 恢复

```math
r_t = q^{meas}_{t+1} - q^{pred}_{t+1},\qquad
d_t = \|W r_t\|_2,\qquad
\beta_t = \mathrm{clip}\!\left(\frac{d_t-\theta}{\theta},0,\beta_{max}\right).
```

```math
q^{cmd\prime}_t = q^{cmd}_t + \beta_t (q^{meas}_t - q^{cmd}_t).
```

- 自由空间 `β=0`；预接触 `β≈0.2`；接触 `β≈0.4`；人为推/按住 `β→0.8`。
- `d_t > θ` 连续 K 帧 → `RECOVER`：停 → 重估 `T_B_O` → 可见则更新锚，不可见则 VLA 重规划 → 保守增益恢复。
- 死区/限幅：`β_t` 变化率 ≤0.2/帧；`q^{cmd\prime}` 与 `q^{cmd}` 差 ≤0.1 rad/帧；避免振荡。
- 这是「让一点」而不是「力控」；不声称估计真实力。低层控制器很硬时，目标偏移仍能产生柔顺；很软时，阈值要重标。
- **人为干扰若只是移动物体，视觉编辑检测是主检测器；DART 是接触/推压的副检测器。**

### 3.7 场景锚定

离线：

```text
for each episode:
    phases = segment(episode)                 # FACT-VLA CPT / GEO-RESIDUAL
    for each phase:
        k = select_keyframe(phase)            # 接触前 1-3 帧 / 目标进入腕部视野
        T_B_O* = estimate_target(episode, k)  # 头双目 + 局部几何/模板
        T_B_E* = episode.state[k].ee_pose
        T_O_E* = inv(T_B_O*) @ T_B_E*
        I_wrist* = episode.wrist[k]
        index.add(task, phase, T_O_E*, I_wrist*, quality)
```

在线：

```text
T_B_O(t) = estimate_target(obs)               # 头双目 + 局部几何/模板
T_anchor = T_B_O(t) @ inv(T_B_O*)
T_B_E^des = T_anchor @ T_B_E^plan
```

- 位置泛化：受器移动 → `T_B_O(t)` 变 → 计划跟着变。
- 人为干扰（移动物体）：视觉编辑检测触发重估 → 更新 `T_anchor`。
- 背景/干扰物：只用局部 ROI/物体几何，不用全局背景。
- 未见物品：受器/任务几何不变，`T_O_E*` 不变；外观由 VLA 处理；置信度低回退原计划。

深度分辨率（头双目）：

```math
\Delta Z \approx \frac{Z^2 \Delta d}{f b}.
```

`f≈282`、`b=58.25 mm`、`Δd≈0.5 px`：`Z=0.6 m` → `ΔZ≈1.1 cm`；`Z=1.0 m` → `ΔZ≈3.1 cm`。头双目适合 3–5 cm 级锚定；最后 1–2 cm 用腕部 IBVS（内参本轮已确认）或夹爪滞止兜底。

视觉编辑检测（保留第 11 轮 GEO-RESIDUAL）：

```text
预测机器人自身运动造成的场景流/残差
if 残差 > θ_e for K frames and 不能由 q_cmd/EE 运动解释:
    edit = True
```

不识别「人」，只识别「场景动了，而且不是我的动作解释的」。

### 3.8 状态机

```text
INIT ──first obs──▶ PLAN ──plan ready──▶ SERVO
  ▲                   ▲                    │
  │                   │                    ├─ d_t < d_c ──▶ CONTACT
  │                   │                    │                 │
  │                   │                    │                 └─ contact released ──▶ SERVO
  │                   │                    │
  │                   └── replan ◀── RECOVER ◀── edit_score > θ_e or d_t > θ
  │                                      │
  └──────────────────────────────────────┘
任意状态 ──task success / max steps──▶ DONE
```

- `SERVO`：正常接近；IK + 锚定；DART 低增益。
- `CONTACT`：`d_t` 升高或相位=接触；法向缩幅、切向保留；`β` 提高。
- `RECOVER`：编辑/扰动触发；停 → 重定位 → 更新锚或重规划；最大重试 2–3 次。
- `DONE`：成功/超时；清理状态，等待 `reset()`。

## 4. 可选 J-ACT：原生关节动作头

### 4.1 动作布局

挑战赛 joint 动作：`[q_L^7, q_R^7, g_L, g_R, p^7]`（23 维）。数据集的 `action.left_arm/right_arm` 是绝对目标；也可以转成相对当前关节的增量（更抗初始位姿变化）。

WLA 现有 54 维布局没有手臂关节槽。J-ACT 的做法：

```text
扩展 action_mapping.SLICES：
  left_arm_joint   [7]
  right_arm_joint  [7]
  （保留原有 EE/gripper/waist/base/legs 槽做辅助监督）
新动作维度 = 54 + 14 = 68
```

或者更简单：把 EE 槽替换成手臂关节槽，保留 gripper/waist/base/legs；输出 54 维但语义改为关节。前一种更稳（保留 EE 辅助），后一种更省。

### 4.2 训练/推理

- 冻结 VLM；训练 action expert + robot-state projector；24 GB；LoRA 可选。
- 损失：

```math
L = \|a - a^*\|_1 + \lambda_s \|\Delta a - \Delta a^*\|_1
  + \lambda_{fk} \|FK(a_{arm}) - T^*_{B,E}\|_1.
```

`FK` 一致性项让关节输出与 EE 监督对齐；`λ_fk` 小（0.1–0.3），避免压过关节点监督。

- 归一化：每关节 minmax 或 z-score；gripper 单独 minmax；pivot 单独。
- 推理：输出关节块 → 安全整形 → DART → API；不经 IK。
- 场景锚定：如果输出关节，锚定需要 residual IK：`q' = IK(T_anchor FK(q))`；或者直接训练时用锚定增强。

### 4.3 A/B

- 基线：WLA EE + SAJR（IK）。
- 实验：J-ACT（joint head）+ 安全/DART。
- 指标：joint MAE、FK 位姿误差、单任务成功率、接触任务步骤分、语义任务回归。
- 采用条件：接触任务 +10pp 且语义任务不回归 >5pp；否则保留 EE+SAJR。

## 5. 场景泛化数据工作流（P4）

### 5.1 ROI 规范化（Tier 1，便宜）

- 用锚定估计的任务区域，从头双目图裁剪/缩放出一个 canonical ROI（例如 336×448），送给 VLA；腕部图保留。
- 目的：减少背景/干扰物占用的像素，提升有效分辨率。
- 风险：VLA 训练时看的是全图，ROI 可能是 OOD；先做推理时 A/B，不涨点就只用于锚定，不改 VLA 输入。
- 若有效，用 LoRA 在 ROI 图上微调 action head；仍是一个模型。

### 5.2 受控场景增强（Tier 2，贵）

- 背景：换桌布颜色/纹理；用分割掩码做图像合成。
- 干扰物：在桌面区域插入 3D 资产；确保不遮挡目标。
- 未见物品：替换同类物体（不同颜色/形状/材质）；优先用官方仿真/真实到仿真（Zero-HLM 路线）。
- 数据预算：32 任务 × 50 变体 × 10 s ≈ 16k episodes；渲染 480×640；on-the-fly 生成省存储。
- 资源：Tier 1 1–2 GPU 周；Tier 2 4+ GPU 周 + 3D 资产。

### 5.3 一致性损失

外观只变、动作不变时：

```math
L = L_{action} + \lambda_c \|\phi(o) - \phi(o')\|_2^2
```

`φ` 用同一 VLM 的特征（C3 合规），不加载第二个编码器。位置变时用锚定，不用一致性硬拉；物体替换时用弱一致性/仅动作监督。

8. ROI 规范化 on/off。
9. 一致性微调 on/off。

### 6.6 门 G0–G9

| 门 | 问题 | 通过标准 | 失败动作 |
|---|---|---|---|
| G0 | FK/IK/pivot/joint 语义/相机是否标定？ | joint–EE 重投影 ≤5 mm/1°；pivot 映射可解释；joint 顺序/符号正确；API 图像与数据集相机同源或可自标定 | 回退 EE 模式；只做锚定+视觉伺服 |
| G1 | 场景锚定是否可信？ | 物体/受器位姿 ≤10 mm/5°；锚定有效 ≥80%；重锚定 ≤300 ms | 只用任务级固定相对目标；降低锚定权重 |
| G2 | 仿真中 SAJR 是否收敛？ | 横向 ≤2 mm、深度 ≤3 mm、2 s 内 ≥95%；RTT 0–150 ms 稳定 | 降增益/加阻尼；只做 PBVS；回退 EE |
| G3 | 真机单任务是否涨点？ | ≥3/5 任务 +10pp；FoldTowel 不回归 >5pp | 不提交 SAJR 版本；保留离线分析 |
| G4 | 人为干扰能否恢复？ | 检测 ≤200 ms；仿真恢复 ≥70%；无碰撞 | 只做视觉编辑检测；不线上触发 DART |
| G5 | 延迟是否可接受？ | p99 ≤150 ms；timeout 不升；CPU <1 核/端口 | 加 chunk/降分辨率/关柔顺 |
| G6 | 32 任务干跑是否稳定？ | N 端口隔离、reset 干净、内存不涨 | 回退基线；减少并发 |
| G7 | 消融是否支持因果？ | joint > EE；锚定 > 无锚定；DART > 无 DART；5 步 > 30 步 | 保留有效部分，砍掉无效部分 |
| G8 | 场景泛化是否真的涨？ | 背景/干扰物/未见物品至少 2 轴 +5pp | 砍掉 Tier 2；保留 ROI |
| G9 | 统计是否可信？ | 配对 bootstrap 95% CI 不跨 0；重复实验方向一致 | 不宣称涨点；扩大样本 |

## 7. 竞赛策略

### 7.1 失败模式分诊

| 失败模式 | 典型任务 | 该投什么 | 不该投什么 |
|---|---|---|---|
| 最后接触/插入/挂/叠/拉链/锁 | PlugInEthernet、HangCup、ZipUp、StackBowls、Unlock、ArrangeTestTubes、ToolboxStorage | SAJR 关节层 + 锚定 + DART | 更大 VLA、更多语义数据 |
| 位置/人为干扰 | 5 轴；human 2/10 | 重锚定 + 柔顺 + 恢复 | 固定轨迹、开环 chunk |
| 背景/干扰物/未见物品 | FruitSorting、ColorArrangement、OrganizeTools | VLA 数据增强/ROI + 一致性 | 纯几何伺服 |
| 变形/语义/长程 | FoldTowel、PackBag、SpellRobot、ConveyorSorting | VLA 基座 + 任务数据 | 6D 物体位姿网络 |

### 7.2 任务组合（先验）

- **A 档：关节/接触优先（19 个）**：HangCup、DisconnectEthernet、ToolboxStorage、PlugCharger、Unlock、ArrangeTestTubes、OpenPillBottle、OrganizeStationery、PackBag、ZipUp、PaperCupStacking、StoreRacket、StackCups、PlugInEthernet、StackBowls、StoreEarphones、PackPhone、OrganizePencilCase、SyringeWaterTransfer。
- **B 档：VLA/语义优先（13 个）**：FruitCollection、PackDoll、FruitSorting、ColorArrangement、PlacePhotoFrame、OrganizeBookshelf、PickOutBatteries、OrganizeTools、FoldTowel、ArrangePlates、SpellRobot、ConveyorSorting、RemovePinnedNote。
- **C 档：低投入/观察**：单任务通道 `p_t` 接近 0 且失败在早期感知/抓取的任务。

```text
priority_t = q_t × Δ_t / cost_t
```

先做 A 档中 `q_t` 最高、`cost_t` 最低的 3–5 个；不要一次铺 19 个。

### 7.3 单任务协议

见 §6.3。补充：

- 每个任务先跑 5 次 A/B 看方向；如果 CI 跨 0，扩到 10 次。
- 人为干扰轴单独加 5 次：在任务中段移动物体/按住夹爪；记录恢复时间/成功率。
- 记录每次的 p99 延迟；如果 SAJR 让 p99 >150 ms，先降分辨率/关柔顺，不要硬上。

### 7.4 边际收益（设计目标，不是承诺）

| 方案 | 成本（估算） | 预期收益 | 建议 |
|---|---|---|---|
| WLA 直接适配 | 1–2 人周 | 基线；可能 20–30% | 必做；先锁基线 |
| SAJR（IK+锚定） | 3–4 人周 + 1 GPU 周 | 位置 +10–15pp → 全局 +2–3pp；接触任务 +5–10pp | 主投 |
| DART | 1–2 人周 | 人为干扰 +10–20pp → 全局 +2–4pp | 主投 |
| J-ACT | 2–4 GPU 周 | 不确定；接触任务可能 +5–10pp | 门控 |
| SCENE-CANON Tier 1 | 1–2 GPU 周 | 背景/干扰物 +3–5pp → 全局 +1–2pp | 次投 |
| 完整世界模型 | 8+ GPU 周 | 不确定；延迟更差 | 不做 |
| 32 任务各训策略 | 规则禁止 | — | 不做 |

保守合计 **+4–6pp**；乐观 +8–9pp。目标把 29.7% 的预览上限推到 **34–38%**。

## 9. 风险与合规

### 9.1 单模型合规

| 模式 | 做法 | 风险 | 建议 |
|---|---|---|---|
| C1 离线标注 | 视觉编辑/相位只离线生成标签；线上只有 VLA | 最低 | 保守首选 |
| C2 确定性控制器 | SAJR/DART/锚定是几何/控制律，无学习权重；VLA 是唯一学习模型 | 低；需说明 | 主推 |
| C3 同 checkpoint 特征 | 锚定描述子用 VLA 同一 checkpoint 的 encoder，不加载第二个模型 | 低–中 | 需要强描述子时用 |

禁止：加载第二个学习策略/残差网络/独立视觉编码器做在线决策。

### 9.2 风险表

| 风险 | 影响 | 缓解 |
|---|---|---|
| 单模型解释 | 被判定为第二个模型 | C1/C2/C3；提交材料写清楚；SAJR 无学习权重 |
| joint 语义/顺序/符号错误 | 动作被拒/机器人乱动 | PIVOT-PROBE + `example_env.py` + 单任务小幅度；保留 EE 回退 |
| pivot 7 维语义不明 | waist/height 不可控 | 先零 pivot + 只控双臂；用数据集 pivot 均值；逐步探测 |
| IK/TCP 标定误差 | 最后 3 cm 偏差 | joint–EE 配对最小二乘；误差 >1 cm/3° 回退 EE |
| 低层控制器未知 | DART 阈值/柔顺失效 | 一步系统辨识；仿真扫延迟/增益；保守 β |
| API 图像与数据集相机不同源 | 深度/锚定偏差 | 用已知图案/重投影验证；必要时自标定；置信度低回退 |
| 人为干扰是移动物体 | DART 漏检 | 视觉编辑检测为主；DART 副检测 |
| 透明/反光/遮挡 | 锚定/深度失败 | 局部几何 + 腕部 IBVS；置信度低回退 |
| 远程 RTT 高 | 5 步块仍不够 | 测 RTT；加阻尼/预测；必要时 chunk 8 |
| 评测噪声 | +1–2pp 假阳性 | 配对 A/B、bootstrap、重复实验；320 trials SE≈2.4pp |
| 数据泄漏 | 离线指标虚高 | 按 session/物体/背景分组划分；相邻帧不跨 split |
| 安全 | 柔顺/重抓碰撞 | 限速/限幅/最大重试；扰动即停；不追求高增益 |
