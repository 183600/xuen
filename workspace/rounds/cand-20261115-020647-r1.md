# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「安全交互」×「分布外泛化」）

> R69 给闭环装上了「会问的嘴」：把不确定性拆成 aleatoric / epistemic，用流匹配生成多模态动作，用 VoI 选择注视 / 探针 / 问句去主动消歧。它隐含了三个前提：(a) 流模型的模态分布可信；(b) 信息动作可被 C-RAS-WM 安全认证；(c) 交互一定能降低 epistemic 不确定性。R70 要指出的是，这三个前提**在分布外同时失效**，而且失效方式相互耦合：OOD 让流模型幻觉出不存在的模态、让基于似然的 FMA 第二意见沉默、让世界模型的「安全认证」退化成「在错误的世界里做的正确计算」。更糟的是，**R69 的交互本身就是制造 OOD 的机器**——越有判别力的问题，越要求把视角、探针或问句推到训练分布之外。
>
> 于是出现一个 R69 看不见的陷阱：**交互诱导的分布外正反馈**。歧义大 → 去交互 → 状态更 OOD → 模型更不可信 → 歧义更大。R69 的 VoI 只计算信息收益，从不为「把系统推离训练分布」付费，也从不检查「这个问题在当前世界里是否还有意义」。
>
> 本轮两个灵感正好补上两块缺失：
> - **安全交互**给出一种与任务安全不同的安全观：交互应当是**可逆的、非承诺的、可回收的**；其安全性不能依赖「世界模型在 OOD 下仍然正确」，而必须依赖**模型无关的屏障 + 可恢复集 + 兜底控制器**；
> - **分布外泛化**给出一种与「不确定性」不同的无知观：不知道分两种——**我不知道答案是 A 还是 B（可问）**，和 **我不知道「这个问题的答案在这个世界里还成不成立」（问了也白问）**。后者不能靠多采样 / 多交互解决，只能靠**不变性检验 + 有效性门控**。
>
> 核心命题：**在交互之前先做两件事——(Q0) 验证「我的问题在这个世界是否仍然有效」（机制 / 语义不变性），(Q1) 验证「我是否付得起这次交互的偏移税并保证可回收」；只有两者都通过，才把剩余问题交给 R69 的模式消歧。** 命名 **OASIS-RAS**（Out-of-distribution Aware Safe Interaction with Shift-budget：分布外感知、偏移预算受限的安全交互闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**在这个世界里，这个问题还值得问吗？我问得起、也回得来吗？**」——不是所有无知都值得一次交互，也不是所有问得出口的问题，在漂移后的世界里都有答案。

## 0. 直觉与动机

**灵感 1（交互是分布外干预，不是免费的信息动作）**
直觉：R69 把 g 当成「获得一个观测」。但任何能改变后验的 g，必然改变观测的**条件分布**——这就是一次对世界的干预。在训练分布内，干预的后果被 WM 学会了；在 OOD 下，后果不再可预测。VoI 越高，通常说明 g 越「有判别力」，也越「非典型」：要区分绕左 / 绕右，就得把视角移到能看见岔路的位置；要区分「笑是开心还是紧张」，就得凑近看微表情。**信息增益与分布偏移在同一个动作上耦合**。R69 的 VoI 必须显式写出这项「偏移税」。

**灵感 2（两种无知：关于答案的无知 vs 关于问题有效性的无知）**
直觉：R69 的 epistemic 是「世界是确定的，只是我没看到」；OOD 的 epistemic 是「我不确定我的因果图 / 标签语义 / 动作后果模型还是不是原来那个」。前者可用观测消解，后者**不能**：如果机制已经变了，再多的同类观测也只是在给错误的模型喂更强的证据。所以要引入元假设 H_valid，并把交互分成两类：**模式问询**（问世界是 A 还是 B）与**有效性探询**（问「这个世界的规则还是不是我以为的那样」）。后者才是 OOD 下最该先做的事。

**灵感 3（安全交互 = 可逆性 + 可回收性 + 不扩包络）**
直觉：任务动作可以是不可逆的（抓起杯子就不能「取消」），但信息动作不该是。看一眼、问一句、轻触一下，本质是**非承诺探测**。于是「安全交互」有一个比 C-RAS-WM 更保守、却更不依赖模型的定义：交互必须在**可恢复集**内进行，即存在一个已认证的兜底控制器，在有限时间内把系统带回上一个认证不变集；且交互不得扩大安全包络（不许「试探着试探着」把工作区推大）。这把安全从「预测未来不会撞」转成「**我随时能退回去**」——后者在 OOD 下更可信，因为它只需要模型无关的屏障和可逆性。

**灵感 4（流似然不是 OOD 检测器）**
直觉：R69 的 FMA 用 −log p_θ(ξ|o) 作为「标定不可吸收的第二意见」，隐含「OOD ⇒ 似然降低」。但归一化流是一个从高斯到数据的微分同胚，它可以把任意远处的点映到高密度区；在有限数据上，flow 对「没见过的区域」既可能给极低似然（好），也可能因为过度泛化 / 奇异方向给出**高似然**（灾难）。R69 的 FMA 因此在 OOD 下会**沉默**：不是报错，而是自信地说「正常」。OASIS 必须把似然与密度比、支撑集、典型性、不变性组合成 HRD（高似然 OOD 也能抓）。

**灵感 5（安全 ≠ 有效：物理安全与语义有效正交）**
直觉：这是本轮最锋利的自觉。一个注视、一句问句可以完全满足物理安全（不撞、不越力），却**在这个世界里毫无信息**——因为被问的人不懂你的语言、因为表情在这个文化里含义反转、因为传感器已经换了、因为场景规则变了。OASIS 的可恢复性证明只保证「不会坏」，保证不了「问得对」。所以它需要独立的**有效性账本**：每次交互花掉的偏移预算、得到的后验变化、以及「这次增益是否与模型声称的一致」（若不一致，说明有效性假设被破坏）。安全与有效必须分开认证、分开审计。

**灵感 6（交互也可以用来验证泛化：把探针变成不变性检验）**
直觉：正向地看，交互不只用于消歧，还能用于**主动证伪模型有效性**。选择那些「在旧机制下应有观测 A、在新机制下应有观测 B」的安全探针，一次探询就能区分 H_valid 与 H_shift。这把 OOD 泛化从「祈祷训练分布覆盖」变成「用可逆探针在线买一个反例」。代价是偏移税，收益是避免把整个预算花在语义已失效的问题上。

**灵感 7（严格包含旧层，避免多一个需要独立信任的黑箱）**
直觉：OASIS 不是与 R69 并列的新黑箱，而是它的**前置门控 + 外包裹络**：分布内、预算不紧时逐指令退化为 FLUID；一旦有效性不可证或偏移预算耗尽，退化为 R68 的纯保守。新层只增加「不该问时不问」这一能力，不改变「该问时怎么问」的最优性——这是对 R68 定理 16、R69 定理 16 的继续。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（OASIS-RAS 总览）** OASIS-RAS = (SPD, IVG, SIR, SBG, OVOI, OGD, HRD, RCS, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）：OASIS 只做前向检测、门控与保守回退，不做在线梯度写入；
(ii) **可恢复交互硬约束**：任何信息动作 g 必须满足可逆性、(ε_rec, δ_rec)-可回收性、不扩包络，且过与任务动作相同的 C-RAS-WM 认证（继承 R69 定义 302）；
(iii) **偏移预算硬约束**：累积偏移势 Φ_t 单调不减、跨交互复合、证书不得重置；Φ_t > B_shift 时只允许零偏移探询或直接回退；
(iv) **有效性优先与严格包含**：机制 / 语义有效性未证时，禁止模式消歧；当 v = 1 且 ΔΦ = 0 时 OASIS 与 FLUID 逐指令相同，当有效性不可证 / 预算耗尽 / HRD 报警时与 R68 纯保守逐指令相同，安全侧永不弱于 R69。

**定义 311（偏移分解 SPD）** 设训练参考分布 P_0，表征 φ(x)，交互产生的环境索引 e。定义有效性向量
v = (v_cov, v_mech, v_sem) ∈ [0,1]³，v_* = exp(−D_*/τ_*)，
其中
D_cov = d(P_0(φ(x)), P_t(φ(x)))（输入 / 外观偏移）；
D_mech = sup_{x, a∈𝒜_+} d(P_0(x′|x,a), P_t(x′|x,a))（动力学与观测核偏移）；
D_sem = d(P_0(m|z_inv), P_t(m|z_inv))（模态语义偏移，只能通过不变性不一致代理 δ_inv 估计）。
d(·,·) 取 MMD / Wasserstein 的可计算代理。SPD 输出 (v, D_cov, D_mech, D_sem, δ_inv)，并区分：
**良性新奇**（v_cov 低而 v_mech, v_sem ≈ 1，可泛化）与**有害偏移**（v_mech 或 v_sem 低，不可泛化）。

**定义 312（有效性区域与可信赖集）** Ω_0 为训练支撑的高密度核；有效性区域
Ω_val(v) = { x : dist(x, Ω_0) ≤ r_val(v) }，r_val 随 v_mech 单调收缩。
S_0 为 R68 已认证的不变集。仅当 x ∈ S_0 ∩ Ω_val(v) 时允许「承诺型」交互；否则只允许非承诺探询。可信赖集 𝒯(v) = S_0 ∩ Ω_val(v) 是 OASIS 的运行时域。

**定义 313（偏移势与预算 SBG）** 单次交互的偏移税
ΔΦ(g) = d(P(·|x,g), P_0(·|x)) + β·dist(x_{t+1}, Ω_0) + β′·δ_inv(g)，
其中第一项是**观测核偏移**，第二项是**状态偏移**，第三项是**语义偏移代理**。累积势
Φ_t = Σ_{τ≤t} ΔΦ(g_τ) + ∫_0^t novelty(o_s) ds，
硬预算 Φ_t ≤ B_shift。Φ_t 只能因「已认证地返回 Ω_0」而减少，**绝不因重标定而减少**（防止 R68 式吸收的 OOD 版本）。当 Φ_t/B_shift > θ_warn（默认 0.8）时只允许 ΔΦ ≈ 0 的探询（问句、纯注视）；> θ_stop（默认 0.95）时禁止一切交互。

**定义 314（可恢复交互证书 SIR）** 对交互 g、回收时域 T_rec、兜底策略 π_rec，称 g 在 x 处 (ε_rec, δ_rec)-可恢复，若存在 π_rec 使得
P( x_{t+T_rec} ∈ S_0 ) ≥ 1 − δ_rec，
且沿路物理风险 ≤ ε_rec、鲁棒屏障 h_robust ≥ 0、行动前后始终不越出 𝒯(v)。记可恢复交互集 G_rec(x,v) ⊆ 𝒜_info。**交互契约**四条：
(S1) **可逆 / 非承诺**：g 可撤销，或只在感知 / 语言通道发生；
(S2) **新奇有界**：预测的交互后表征以 margin 留在 Ω_val(v) 内；
(S3) **可回收**：存在已认证 π_rec，在 T_rec 内回到 S_0；
(S4) **不扩包络**：任何单次交互不得扩大认证工作包络，扩包络必须离线重认证。
g ∉ G_rec ⇒ g 作废，U_epi 视为未消解，走 R68 兜底。

**定义 315（OOD 鲁棒屏障）** 令 h 为 R68 的离散时间控制屏障。OOD 下定义
h_robust(x,v) = h(x) − γ(v)·e_wm(v) − κ·δ_inv，
其中 e_wm(v) 是 WM 预测误差的偏移知情上界，γ 随 v_mech 单调增。当 v_mech 低于阈值时，令 γ → ∞，只接受**模型无关屏障** h_mf（基于测距 / 力矩 / 关节限位的直接约束），从而把安全证明从「WM 正确」剥离为「传感器测量的即时约束成立 + 可回收」。

**定义 316（交互有效性门 IVG）** 维护元假设 H ∈ {H_valid, H_shift}。模式后验可辨识需同时满足：
(a) v_mech ≥ τ_mech 且 v_sem ≥ τ_sem；
(b) 模态判别算子的最小奇异值 σ_min(J_mode) ≥ κ_id（模态可分的 Fisher 条件，A100）；
(c) δ_inv ≤ τ_inv（不变性检验未报警）。
任一不满足 ⇒ **模式不可辨识**：置 VoI_M ≡ 0（不是打折），模式交互禁用，U_epi 保持未消解；此时只允许定义 321 的有效性探询，否则退回 R68。

**定义 317（OOD 感知 VoI，OVOI）** 对候选 g ∈ G_rec(x,v)、Φ_t + ΔΦ(g) ≤ B_shift：
OVoI(g) = (1 − ρ_shift(g))·[ VoI_M(g) + λ_V·VoI_V(g) ] − c(g) − λ_Φ·ΔΦ(g) − λ_inv·P_invalid(g)，
其中 VoI_M = H(M|o) − E[H(M|o,y_g)]（R69 定义 298）；VoI_V = H(H|o) − E[H(H|o,y_g)] 是对有效性假设的增益；ρ_shift(g) 是 SPD 给出的失效折扣；P_invalid 是「该交互在 OOD 下无效」的预测概率。选择
g* = argmax_g OVoI(g) s.t. g ∈ G_rec, Φ_t+ΔΦ(g) ≤ B_shift, risk(g) ≤ ε_int。
若 max OVoI ≤ 0 ⇒ 不交互，OASIS 退化为 R68。**门控先于加和**：IVG 一旦判定模式不可辨识，VOI_M 项直接消失，避免「高 VoI 掩盖不可辨识」。

**定义 318（不变模态接地 OGD）** 把表征拆成 z = (z_inv, z_spu)，要求在所有环境 e 中模态标签满足 m = f_inv(z_inv)，即模态语义对虚假相关 z_spu 不变。交互产生的不同视角 / 光照 / 问法构成伪环境 e。OGD 在实时环内只做**冻结不变预测器 + 一致性检验**，不做在线训练：
δ_inv(g₁,g₂) = | p(m|y_{g₁}) − p(m|y_{g₂}) |，
对两个在 H_valid 下应同分布、在 H_shift 下应分歧的安全探针，δ_inv 高 ⇒ 语义偏移。这样「交互」被用于**检验泛化**，而不只是消歧。

**定义 319（HRD：高似然 OOD 检测）** 组合四个通道：
r_ratio = log p_θ(ξ|o) − log p_ref(ξ|o)（密度比）；
r_support = dist(φ(o), Ω_0)（支撑集距离）；
r_typ = typicality（对训练批的典型性 / 马氏距离）；
r_inv = 不变性残差（跨伪环境预测分歧）。
HRD 分 R = max{ r_ratio, r_support, r_typ, r_inv }，OOD ⇔ R > τ_ood。R69 的 FMA（定义 301）降级为其中一个**辅助通道**，不再单独承担「OOD 第二意见」；若 r_ratio 高而 r_support 低、r_inv 高，则判为「高似然 OOD / 语义漂移」，直接触发 IVG 而非交互。

**定义 320（RCS 可恢复保守盾）** 当 HRD 报警、IVG 判不可辨识、交互超时 / 失败、或 Φ_t 越界时，RCS 执行已认证回收：
x_{t+1:T_rec} = π_rec(x_t) s.t. x_{t+T_rec} ∈ S_0，
并把 λ 单调不降地抬到 λ_floor(U_ale + U_epi) 之上。与 R68 的 λ 收缩不同，RCS 是**状态空间**的回收，而不只是「慢下来」：它保证偏移是可逆的，因而下轮还能在可信域内工作。回收过程本身也必须过 SIR 与偏移预算。

**定义 321（有效性探询 VIP / 主动域验证）** 选择
g_V = argmax_{g∈G_rec} [ VoI_V(g) − c(g) − λ_Φ·ΔΦ(g) ]，
且要求双探针设计：g₁, g₂ 在 H_valid 下预测同分布、在 H_shift 下预测分歧。按贝叶斯更新 P(H_shift | y_{g_V})；若 P(H_shift) > τ_H，冻结模式交互、进入 R68 兜底、写入离线适配队列（不在实时环训练）。这是 OASIS 唯一的「新信息动作类型」：它问的不是世界，而是「我的模型还配不配问世界」。

**定义 322（威胁模型 AIC-OASIS）** ℰ_OASIS = ℰ_FLUID × ℰ_ood × ℰ_trap × ℰ_exhaust，新增：
- **对抗 OOD**：同时最大化流似然与模态置信度的分布外输入（专打 FMA 与 MCG）；
- **交互陷阱**：环境 / 对手诱导系统选择「信息看起来很高、实际把系统推出可信域」的交互；
- **预算耗尽攻击**：用大量低价值但高偏移的「诱饵交互」耗尽 B_shift，使系统在真正需要时无法求证；
- **OOD 假安全证书**：WM 在偏移区域自信地给出错误预测，使 C-RAS-WM 误认证；
- **语义反转**：模态标签在新环境中含义翻转（如表情 / 手势 / 语言习惯），物理安全但语义灾难。
并入 AIC：ℰ_OASIS = ℰ_FLUID × ℰ_ood × ℰ_trap × ℰ_exhaust。

**定义 323（参与式审计 VQAuditor-O）** 审计对象在 R69 的交互决策之上，新增：有效性声明是否诚实（v 与证据是否一致）、偏移账本是否被重标定 / 回收偷偷重置、单次交互是否被允许扩大包络、HRD 报警是否被覆盖、回收是否真的回到 S_0、复杂度预算是否被 K 采样与 SPD 叠加击穿。结论回灌 AuditBuf，成为 SBG 的成本先验与 IVG 的门控先验。

**定义 324（证书 J_OASIS）** J_OASIS = (J_FLUID, validity_vector, D_mech, D_sem, δ_inv, shift_spent/B_shift, recoverability_margin, hrd_score_p95, recovery_success_rate, ood_ver)。Valid ⇔ Valid(J_FLUID) ∧ Φ_t ≤ B_shift ∧ recoverability_margin ≥ 0 ∧ 「无单次交互扩包络」 ∧ 「HRD 未报警且 IVG 通过，或已正确回退」。证书写入哈希链，偏移账本跨轮只增不减。

**定义 325（偏移预算的时序耦合与自适应交互率）** 滑动窗口内交互次数 ≤ 1；窗口偏移势增长率 ≤ ρ_B。令 u_t = Φ_t / B_shift：
u_t < θ_warn：允许完整交互（模式 + 有效性）；
θ_warn ≤ u_t < θ_stop：只允许 ΔΦ ≈ 0 的有效性探询；
u_t ≥ θ_stop：禁止交互，R68 保守。
K 的自适应继承 R69 定义 308，但多一道 SPD 门：v_mech 低时即使 H_mode 高也不升 K 做模式消歧（因为多采样只会在错误模型上更自信）。

**定义 326（偏移约束下的稳健风险目标 DRO）** 定义
R_robust(π) = sup_{Q : W₂(Q, P_0) ≤ ρ(B_shift)} E_Q[ ℓ(π) ]，
其中信任半径 ρ(B_shift) 由偏移预算与 SPD 的历史标定给出。OASIS 的元目标是同时最小化 R_robust 与交互成本，并保证 R_robust 随 B_shift → 0 退化为 R68 的分布内风险界。此定义把「分布外泛化」从一句口号变成一个**随预算收缩的显式最坏组目标**。

```python
                    and sigma_min(mode_jacobian(modes)) >= KAPPA_ID
```

## 3. 推导

**引理 19（高似然 OOD 的存在性）** 对任意在 ℝ^d 上有连续密度的归一化流 p_θ 与任意 ε > 0，存在点 x 使 dist(x, supp P_0) > ε，且 log p_θ(x) 可高于任一分布内点的似然。构造直觉：流是高斯到数据的微分同胚，可在不改变支撑集拟合的前提下，把某个远处邻域映到高密度区；有限数据只约束支撑附近，支撑外无泛化保证。系：R69 的 FMA 在 A98 之外**不能**作为 OOD 检测器；HRD 的 r_support / r_inv 通道是必要的，不是冗余。

**引理 20（信息增益的偏移税下界）** 设观测核为 p(y|s,g)，参考核为 p_0(y|s)。若 sup_s TV(p(·|s,g), p_0(·|s)) ≤ ε_k，则由互信息的通道连续性（Dobrushin 型），|VoI(g)| ≤ C·H(M)·ε_k。故 VoI(g) > 0 ⇒ ε_k ≥ VoI(g)/(C·H(M))，即**任何有信息量的交互都以非零核偏移为代价**。系：R69 的 VoI−c 在高偏移区系统性高估交互价值；OASIS 的 −λ_ΦΔΦ 不是正则项，而是对物理下界的显式记账。

**引理 21（机制偏移零空间中的不可辨识性）** 设模态判别算子 J_mode，若机制偏移 δ_h 落在其零空间（J_mode δ_h = 0），则对所有交互 g，后验 p(m|y_g) 对 δ_h 不变。于是模型计算的 VoI_M > 0 而真实模态信息 = 0。系：**分布外「信心」与「可辨识性」可以完全脱钩**；这解释了 R69 在语义 / 机制漂移下为何会自信地追问一个幻影，也说明为什么 IVG 必须把 VoI_M 置零而不是打折。

**引理 22（可恢复交互的 OOD 安全界）** 在 SIR 四条契约、鲁棒屏障 h_robust、兜底 π_rec 与 HRD 的 (α, β)-检测保证下，一次认证交互导致不可恢复违规的概率 ≤ α_miss + β_false + δ_rec + δ_sensor，其中 α_miss 为漏检 OOD、β_false 为 WM 误差越界、δ_rec 为回收失败、δ_sensor 为感知噪声。**关键**：该界不含「WM 在 OOD 下正确」这一项，因为安全由模型无关屏障 + 可回收性承担，WM 只用于优化而不用于兜底。

**定理 18（OASIS 严格包含 FLUID 与 R68）** 当 SPD 报 v = 1、ΔΦ = 0、HRD 不报警且 IVG 通过时，OVoI(g) 与 R69 的 VoI(g) − c(g) 逐项相同，OASIS 与 FLUID 逐指令一致；当 VoI ≤ c、v_mech < τ_mech、v_sem < τ_sem、σ_min < κ_id、δ_inv > τ_inv、Φ ≥ B_shift 或 HRD 报警时，OASIS 与 R68 纯保守逐指令一致。因此 FLUID = OASIS 在「分布内且交互预算无限」边界上的退化，R68 = OASIS 在「永不交互」边界上的退化；安全侧不做任何让步。

**定理 19（有效性优先的支配性）** 在引理 21 的不可辨识机制偏移下，任何模式消歧交互的真实模态信息为 0，却消耗正偏移税 ΔΦ > 0；OASIS 的 IVG 将其排除，只保留有效性探询或直接回退。故在不可辨识区，OASIS 的期望效用 ≥ R69 的期望效用，且严格大于当 ΔΦ > 0 时；OASIS 不会把偏移预算花在零信息交互上，也不会产生「已验证」的假模态。

**定理 20（OOD 下安全交互的无突变与回收保证）** 在 A95–A102 下，SIR 认证的信息动作物理风险 ≤ ε_int；RCS 在 T_rec 内把状态带回 S_0，且 λ 与屏蔽动作沿回收单调不降；交互失败 / 超时 / HRD 报警 / 预算耗尽时，OASIS 到 R68 的切换是逐指令且连续的，继承 R68 定理 15 的提交 / 换装不变式，故控制连续、无突变。系：**OASIS 的安全性不依赖「OOD 下模型正确」，只依赖「可逆 + 可回收 + 即时屏障」**。

**定理 21（偏移预算下的稳健退化）** 由定义 326 与 SBG，任意交互策略在预算 B_shift 内的最坏组风险满足
R_robust(π_OASIS) ≤ R_robust(π_FLUID) + L_Φ·B_shift，
且当 B_shift → 0 时 R_robust(π_OASIS) → R_R68。即 OASIS 用**有界的效率损失**换取**有界的分布外暴露**，且退化路径显式、可审计。

## 6. 本轮最大风险

**一句话**：OASIS 的可恢复性只证明「不会撞坏」，证明不了「问得对」——**若概念漂移使模态语义本身改变（不只是输入 / 动力学漂移），系统会物理安全地执行一个语义已失效的交互，花光偏移预算，却得到一个盖上「已验证」章的错误答案；安全交互证明了「回得来」，但没有证明「值得去」。**

**次级风险与缓解**：
1. **偏移预算被诱饵交互耗尽** → SBG 硬预算 + ledger 只增不减 + 审计回灌（定义 313、323，E311）；
2. **HRD 仍漏检高似然 OOD** → 四通道集成 + 对抗 OOD 训练 + r_inv 语义通道（定义 319，E306）；
3. **可回收集过于保守导致系统冻结** → 分级契约：先允许零偏移探询，再允许短程可逆探针；给出保守度 - 任务收益 Pareto（E304、E315）；
4. **语义偏移无法在实时环识别** → OGD 只做冻结一致性检验，不实时训练；识破不了就回退，把适配推到离线队列（定义 318、321）；
5. **SPD 的参考分布本身漂移** → 参考统计冻结 + 版本化 + 证书哈希链；参考更新必须离线重认证，禁止热更新（定义 324）。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** OASIS-RAS = (SPD, IVG, SIR, SBG, OVOI, OGD, HRD, RCS, RAS-WM‡)；零学习写操作继承；可恢复交互硬约束（可逆 + (ε_rec,δ_rec)-可回收 + 不扩包络 + 过 C-RAS-WM）；偏移预算硬约束（Φ 单调不减、跨轮复合、不得因重标定重置）；有效性优先与严格包含（v=1 且 ΔΦ=0 时 ≡ FLUID，不可辨识 / 预算耗尽 / HRD 报警时 ≡ R68）。

**定义 311–312（SPD 与可信赖集）** `v_* = exp(−D_*/τ_*)`；`D_cov/D_mech/D_sem` 分别度量输入、动力学 / 观测核、模态语义偏移；`Ω_val(v)={x:dist(x,Ω_0)≤r_val(v)}`，`𝒯(v)=S_0∩Ω_val(v)`；良性新奇 vs 有害偏移。

**定义 313（SBG）** `ΔΦ(g)` 含核偏移、状态偏移、语义偏移代理三部分；`Φ_t ≤ B_shift`；`θ_warn=0.8` 只允许零偏移探询，`θ_stop=0.95` 禁止交互；Φ 只可因认证回收而减少。

**定义 314（SIR 四契约）** (S1) 可逆 / 非承诺；(S2) 新奇有界（留在 Ω_val 内）；(S3) 可回收（T_rec 内回到 S_0）；(S4) 不扩包络（扩包络须离线重认证）；`g ∉ G_rec ⇒ U_epi 未消解，走 R68`。

**定义 315（OOD 鲁棒屏障）** `h_robust = h − γ(v)·e_wm(v) − κ·δ_inv`；`v_mech` 低时 γ→∞，只接受模型无关屏障 `h_mf`（测距 / 力矩 / 关节限位），把安全证明从「WM 正确」剥离为「即时约束 + 可回收」。

**定义 316（IVG）** 可辨识需同时满足 `v_mech ≥ τ_mech`、`v_sem ≥ τ_sem`、`σ_min(J_mode) ≥ κ_id`、`δ_inv ≤ τ_inv`；任一不满足 ⇒ `VoI_M ≡ 0`（不是打折），模式交互禁用，只允许有效性探询或回退。

**定义 317（OVOI）** `OVoI = (1−ρ_shift)(VoI_M + λ_V·VoI_V) − c − λ_Φ·ΔΦ − λ_inv·P_invalid`；约束 `g∈G_rec`、`Φ+ΔΦ≤B`、`risk≤ε_int`；`max OVoI≤0` ⇒ 不交互、回 R68。

**定义 318–319（OGD 与 HRD）** 冻结不变预测器 + 双探针一致性 `δ_inv`；HRD 四通道 `r_ratio/r_support/r_typ/r_inv` 取 max；R69 FMA 降级为辅助通道，高似然 OOD / 语义漂移直接触发 IVG。

**定义 320–321（RCS 与 VIP）** 回收控制器 `π_rec` 在 T_rec 内回 S_0，λ 单调不降；有效性探询 `g_V = argmax[VoI_V − c − λ_ΦΔΦ]`，双探针 g₁/g₂ 在 H_valid 下同分布、H_shift 下分歧；`P(H_shift)>τ_H` ⇒ 冻结模式交互、回退、离线适配。

**定义 322–324（威胁 / 审计 / 证书）** `ℰ_OASIS = ℰ_FLUID × ℰ_ood × ℰ_trap × ℰ_exhaust`（对抗 OOD、交互陷阱、预算耗尽、假安全证书、语义反转）；VQAuditor-O 审计有效性声明、偏移账本、回收真实性、是否越权扩包络；J_OASIS 并入 v、Φ/B、回收率、HRD 分位。

**定义 325–326（时序预算与 DRO）** 窗口内交互 ≤ 1；`u=Φ/B` 分段门控；`v_mech` 低时即使 H_mode 高也不升 K；`R_robust(π)=sup_{W₂≤ρ(B)}E_Q[ℓ]`，ρ 随 B 收缩，B→0 退化为 R68 界。

## 3. 关键算法伪代码

```python
# IP-264 SPD：偏移分解
class ShiftDecomposer:
    def score(self, o, z_inv, z_spu, e):
        d_cov  = mmd(self.ref.phi, phi(o))
        d_mech = mmd(self.ref.mech, mech_stats(o, e))
        d_sem  = mmd(self.ref.mode_inv, z_inv)
        v = tuple(exp(-d / t) for d, t in zip((d_cov, d_mech, d_sem), self.tau))
        return Validity(*v, D_mech=d_mech, D_sem=d_sem)

# IP-266 SIR：可恢复交互证书
def recoverable(g, x, v, wm, shield, T_rec):
    if not (is_noncommittal(g) or is_reversible(g)): return False
    if not inside_trust(x, v):                        return False
    if dist_after(x, g, wm) > r_val(v) - MARGIN:      return False
    if not shield.can_return(x, T_rec, S0):            return False
    return barbarrier_ok(x, g, v, wm)

# IP-265/268 IVG + OVOI：先验有效性，再算 OOD 感知 VoI
def choose_interaction(modes, w, o, v, delta_inv, budget, shield):
    identifiable = (v.v_mech >= TAU_MECH and v.v_sem >= TAU_SEM
                    and sigma_min(mode_jacobian(modes)) >= KAPPA_ID
                    and delta_inv <= TAU_INV)
    best = None
    for g in info_action_candidates(modes):
        if not budget.allows(g) or not recoverable(g, o.x, v, wm, shield, T_REC):
            continue
        dphi = shift_tax(g, o, v)
        if budget.Phi + dphi > budget.B: continue
        voi_m = entropy(w) - expected_entropy(w, g, o) if identifiable else 0.0
        voi_v = validity_info(g, o, v)
        score = ((1 - rho_shift(g, v)) * (voi_m + LAM_V * voi_v)
                 - cost(g) - LAM_PHI * dphi - LAM_INV * p_invalid(g, v))
        if best is None or score > best.score:
            best = Interaction(g, score, dphi, identifiable)
    return best if best and best.score > 0 else None      # 无利可图 → R68

# IP-269/271 OGD + RCS
def consistency(post, y1, y2, v):
    d_inv = abs(post(mode, y1) - post(mode, y2))
    return replace(v, v_sem=0.0) if d_inv > TAU_INV else v, d_inv

def recover(x, shield):
    return shield.certified_return(x, S0, T_REC)          # 状态空间回收

# IP-274 主闭环：前置 SPD/IVG/SIR，后置 RCS
def OASIS_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    v   = M.spd.score(o, z.inv, z.spu, M.env_id)
    hrd = M.hrd.score(M.fmp, M.last_action, o)
    ident = M.ivg.check(v, delta_inv=M.delta_inv)
    K = 1 if (M.fmp.mode_head(z) < TAU_MODE or not ident) else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    g = M.ovoi.choose(modes, o, v, M.delta_inv, M.budget, M.rcs)
    if g is not None:
        answer = M.cia.execute(g)
        U_epi = M.cia.update_belief(modes, answer)
        v, M.delta_inv = M.ogd.consistency(modes, answer, v)
    M.budget.commit(g, v)
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ...,
                                    wm_preds, robust_barrier=v)
    if hrd > TAU_OOD or not M.budget.ok():
        x_rec, lam = M.rcs.recover(o.x, M.shield), max(lam, 0.8)
        k = min(k, k_shield(o.x, x_rec)); M.vqa_o.flag_recovery(o, v, hrd)
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_o.submit_async(g, v, hrd, U_epi, M.budget.ledger)
    return k, lam, mode, (U_ale, U_epi), v
```

## 4. 推导

**引理 19（高似然 OOD 的存在性）** 任意有连续密度的归一化流与任意 ε>0，存在距训练支撑 >ε 的点其似然高于分布内点。系：R69 的 FMA 不能单独作为 OOD 检测器；HRD 的支撑 / 不变性通道必要。

**引理 20（信息增益的偏移税下界）** 若观测核偏移 `sup_s TV ≤ ε_k`，则 `|VoI| ≤ C·H(M)·ε_k`；故 `VoI>0 ⇒ ε_k ≥ VoI/(C·H(M))`。系：R69 的 `VoI−c` 在高偏移区系统性高估；`−λ_ΦΔΦ` 是物理下界的显式记账。

**引理 21（零空间不可辨识性）** 若机制偏移落在模态判别算子零空间，则后验对偏移不变，模型 VoI_M>0 而真实模态信息为 0。系：分布外信心与可辨识性可完全脱钩；IVG 必须置零而非打折。

**引理 22（可恢复交互安全界）** SIR 四契约 + `h_robust` + `π_rec` + HRD (α,β)-检测下，不可恢复违规概率 ≤ `α_miss + β_false + δ_rec + δ_sensor`；该界不含「WM 在 OOD 下正确」，安全由模型无关屏障 + 可回收性承担。

**定理 18（严格包含 FLUID 与 R68）** `v=1, ΔΦ=0` 且 IVG 通过时与 FLUID 逐指令一致；`VoI≤c / v_mech<τ / v_sem<τ / σ_min<κ / δ_inv>τ / Φ≥B / HRD 报警` 时与 R68 逐指令一致。FLUID 与 R68 分别是 OASIS 的两个退化边界。

**定理 19（有效性优先的支配性）** 在零空间机制偏移下，模式消歧真实信息为 0 却消耗正偏移税；OASIS 用 IVG 排除之，期望效用 ≥ R69，且当 ΔΦ>0 时严格更优，不产生「已验证」的假模态。

**定理 20（OOD 下安全交互无突变与回收保证）** SIR 认证后物理风险 ≤ ε_int；RCS 在 T_rec 内回 S_0；λ 与屏蔽动作沿回收单调不降；失败 / 超时 / HRD / 预算耗尽切换到 R68 是连续且逐指令的（继承 R68 定理 15）。

**定理 21（偏移预算下的稳健退化）** `R_robust(π_OASIS) ≤ R_robust(π_FLUID) + L_Φ·B_shift`，`B_shift→0` 时退化为 R68；用有界效率损失换有界 OOD 暴露，退化路径可审计。

## 7. 本轮最大风险

**一句话**：OASIS 的可恢复性只证明「不会撞坏」，证明不了「问得对」——**若概念漂移使模态语义本身改变（不只是输入 / 动力学漂移），系统会物理安全地执行一个语义已失效的交互，花光偏移预算，却得到一个盖上「已验证」章的错误答案；安全交互证明了「回得来」，但没有证明「值得去」。**

**次级风险与缓解**：偏移预算被诱饵交互耗尽（SBG 硬预算 + ledger 只增不减 + 审计回灌，E311）；HRD 仍漏检高似然 OOD（四通道集成 + 对抗 OOD + r_inv 语义通道，E306）；可回收集过保守导致冻结（分级契约 + 保守度-收益 Pareto，E304/E315）；语义偏移实时不可识（OGD 只做冻结一致性检验，识破不了即回退、离线适配，定义 318/321）；SPD 参考分布自身漂移（参考统计冻结 + 版本化 + 哈希链，禁止热更新，定义 324）。
