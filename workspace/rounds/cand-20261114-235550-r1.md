# 第 3 轮（灵感循环第 3 轮；本轮灵感：「闭环控制」×「消融实验」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440）。
> 本轮纪律：**继续在前人基础上改进，而不是推倒重来**——ToolGauge 的 6C 骨架、工具契约层、摊销校准层、
> 语言审计层与 MODGAUGE 五不变式全部保留；本轮只做两件事：
> (1) 把「伪闭环」的 6C 升级为**有参考、有误差、有稳定性证书的真闭环**（ServoGauge）；
> (2) 把第 2 轮 E439 的**消融清单**升级为**可识别、可复现、可审计的干预实验科学**（A-Box + 消融证书）。
>
> **核心判断**：第 2 轮把系统从「开环修复」推进到「带反馈的修复流水线」，但 6C 每个盲区仍只执行一次，
> P-Quarantine 只是符号计数启发式，热替换是「一次性全量写入」。因此它没有参考跟踪、没有稳定性证明、
> 没有抗积分饱和、没有纯延迟补偿，也没有回答「哪个模块真正贡献了什么」。
> 本轮把修复过程显式建模为离散时间反馈系统，并把消融实验作为**受控扰动/系统辨识**接入该反馈系统。

## 三位一体映射（两条灵感轴 + 一条耦合轴）

| 灵感词 | 第 2 轮对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| 闭环控制 | 6C 一次性流水线 + P-Quarantine 符号计数 | **ServoGauge**：R-Box 参考/误差 + C-Box 受限控制器 + P-Box 分级晋升 + Q-Box 偏差检测 | 「会反馈」不等于「稳定」；没有参考、Lyapunov 势与抗饱和的闭环只是把开环失败模式藏得更深 |
| 消融实验 | E439 单行「去 MP-Φ / 去 TCV / …」清单 | **A-Box**：析因/Shapley 干预估计 + 数字孪生重放 + 消融证书 | 消融不是「关掉一个模块看指标」，而是带交互项、顺序依赖与安全包络的因果估计问题 |
| 耦合轴（本轮新增） | 控制与消融互不相干 | **闭环消融（closed-loop ablation）**：消融是系统辨识的受控激励；控制证书是消融安全的前提 | 控制需要植物模型，消融提供干预数据；消融会改变闭环动力学，必须用孪生/影子模式隔离 |

**统一命题**：
> **控制提供「如何安全地持续修正」，消融提供「凭什么相信每个修正部件」；二者共用同一套干预/证书语言。**

**不变式保持声明**：
- MODGAUGE 五不变式（契约完整性、组合单调性、反作用通道完备、主张绑定、严格退化链）全部保留；
- **契约完整性扩展**：热替换契约新增「伺服稳定性证书」字段；无证书不晋升（定义 439/444）；
- **主张绑定扩展**：关于「某模块贡献」的语言主张必须引用有效**消融证书**，否则序列化时剥离（定义 442）；
- **严格退化链再延长**：ServoGauge（闭环控制）失效 ⇒ ToolGauge（开环 6C）⇒ LeanGauge（纯数值）⇒ MODGAUGE。
  控制层是增强项，不是依赖项；**A-Box 永远只在影子/孪生/非关键路径运行**，不得进入 50Hz 关键路径。

## 0. 直觉与动机

### 灵感 1（闭环控制 → 修复不是「做完一次」，而是「把误差压进不变集」）

第 2 轮 6C 的隐含叙事是：发现盲区 → 提假设 → 探测 → 校准 → 交叉验证 → 热替换，然后结束。
但从控制视角看，这恰恰是**开环**：没有定义参考输入 r，没有定义误差 e = r − y，没有证明误差会收敛，
也没有处理执行器饱和（预算）、纯延迟（异步修复）、模型失配（sim→real）与积分饱和（先验偏差累积）。
P-Quarantine 的「连续 3 次同向」是一个没有虚警率/检测延迟保证的符号计数，不能称为控制器。

闭环控制的直觉是：**把「修复」看成受约束的反馈调节**。
- 参考 r：目标不确定度 ε、目标覆盖率 1−α、共享先验偏差 b=0、主张债务=0；
- 状态 x：不确定度场 σ、共享偏差 b、预算 B、在飞集合 I；
- 控制 u：探测程序 Π、契约增量 Δu、晋升/回滚决策；
- 扰动 d：分布漂移、传感器漂移、对抗注入；
- 输出 y：有效回执、交叉验证残差、契约回归结果、覆盖率估计。
控制目标不是「这一次修好」，而是 **V_t（风险势）一致最终有界（UUB）且误差进入不变集**。
为此需要四件工程上缺一不可的东西：受限执行（rate limit）、抗积分饱和（anti-windup）、
纯延迟补偿（dead-time compensation）、可观测/可控性门控（不能对不可控盲区赌预算）。

### 灵感 2（消融实验 → 从「关模块看指标」到「干预因果估计 + 安全包络」）

第 2 轮 E439 说「去 MP-Φ / 去 TCV / 去 SNC / 去 P-Quarantine 各自贡献量化」，这是**清单思维**：
它默认 (a) 模块效应可加；(b) 消融顺序无关；(c) 关掉模块后系统仍可安全运行；(d) 一次实验即可代表部署分布。
四条都不成立。模块间存在强交互（TCV 与 SNC 共同决定假设是否进入；Q-Box 与 MP-Φ 共同决定偏差是否累积），
顺序消融的边际效应依赖顺序，关掉安全模块本身可能违反五不变式，而部署分布会因消融后的控制行为而改变。

消融实验的直觉是：**消融是 do-算子，不是「删除代码」**。
- 我们要估计的是干预分布 P(Y | do(module=off)) 下的效应，而不是条件分布 P(Y | module 未被触发)；
- 必须用析因设计估计主效应 + 交互项，用 Shapley 值给出与顺序无关的归因；
- 安全关键模块（TCV、风险门、PROBING、契约回归、Q-Box）**禁止现场消融**，只能在数字孪生/影子模式重放；
- 每个消融结论必须携带效应量、置信区间、交互矩阵、有效性包络、孪生-现场差距与预注册哈希，
  否则不得进入语言主张（把 E439 从「表格」升级为「证书」）。

### 灵感 3（耦合：闭环消融 → 控制与实验互为前提）

闭环保证书需要植物增益 γ_met、γ_prior、收缩率 ρ、纯延迟 D；这些量无法从被动日志中可靠辨识，
需要**受控激励**——消融正是最安全的受控激励（在孪生中把模块置 off/on，观察闭环响应）。
反过来，消融必须运行在受控系统上：若控制器本身不稳定，消融效应会被轨迹漂移污染；
若消融会改变未来数据分布，则单步 ATE 不再是部署效应，必须报告**H 步轨迹效应**。
因此本轮把 A-Box 定义为「影子模式下的干预辨识器」，其输出经变更控制后才允许更新控制器增益，
形成「消融 → 辨识 → 证书 → 受控更新 → 再消融」的**元闭环**；同时用预注册与留出场景防止 Goodhart。

## 1. 形式化定义（增量：定义 432–444）

**定义 432（修复植物与离散时间状态）** 在修复纪元 t∈ℕ（事件驱动，非 50Hz 节拍）定义
x_t = (μ_t, σ_t, b_t, B_t, I_t, d_t^claim)：
- μ_t, σ_t：R 上的后验均值/标准差场；
- b_t ∈ ℝ^{d_u}：跨盲区**共享先验偏差**（第 2 轮最大风险的显式状态化）；
- B_t：剩余工具预算；I_t：在飞盲区集合；d_t^claim：未绑定证书的主张债务。
植物模型 x_{t+1} = F(x_t, u_t, d_t) + w_t，观测 y_t = G(x_t) + v_t；
F 至少包含：探测后的方差收缩、契约热替换对 σ_pred 的改变、环境漂移对 b 的注入、预算消耗。
F 是**显式模型**，不是对真实世界的断言；其失配由定义 439 的证书与定义 436 的延迟守卫兜底。

**定义 433（参考、误差与风险势）** 参考 r = (ε, 1−α, 0, 0)，误差
e_t = (σ_t/ε − 1, cov_t − (1−α), b_t/b_max, d_t^claim)。
风险势
V_t = Σ_{s∈R} w_s·(σ_t(s)/ε)² + λ_b·‖b_t‖²/b_max² + λ_c·d_t^claim + λ_B·max(0, B_min−B_t)/B_min，
其中 w_s 为盲区风险权重。控制目标：存在 ρ∈(0,1)、c_0,c_1<∞ 使
V_{t+1} ≤ ρ·V_t + c_0‖d_t‖² + c_1（一致最终有界），且稳态误差进入不变集 Ω = {V ≤ V_max}。
V 同时作为 50Hz 路径的**只读监控量**，不参与实时控制。

**定义 434（受限执行与分级晋升 P-Box）** 契约更新 Δu 满足
‖Δu‖_G ≤ δ_max（G 为契约参数度量），每次只晋升 k 个 canary 盲区，观察 T_canary；
晋升规则为 k-of-n 或 SPRT，任一 canary 的 V 上升超过 η_c 或交叉验证失败 ⇒ 立即回滚全部未晋升更新。
热替换从「全量写入」变为「速率受限 + 分级晋升 + 可回滚」，直接限制第 2 轮相关性污染的传播半径。

**定义 435（积分偏差估计与抗饱和）** 共享偏差估计
b̂_{t+1} = Proj_{B_b}( b̂_t + η·e_t )，当执行器饱和（B_t < B_sat 或触发 δ_max）或 Q-Box 报警时**冻结积分**，
并对 AP-Cal 均值做 b̂ 补偿：μ_corrected = μ_AP − b̂。
抗饱和条件：0 < η < 2/L_g（L_g 为植物小信号增益估计）；投影保证 ‖b̂‖ ≤ b_max。
这是对第 2 轮「跨盲区相关偏差只能事后断路」的正面修复：偏差先被**估计并补偿**，再被**检测**。

**定义 436（纯延迟补偿与延迟歧义守卫）** 修复异步延迟 τ_d ≤ D_max。控制器用预测器
x̂_{t+τ_d|t} = F^{τ_d}(x_t, u_t) 预测完成时刻状态；若实测-预测残差 ‖y_{t+τ_d} − ŷ‖ > ε_dt，
标记 **delay-ambiguous**：不晋升，按 τ_d·κ_d 膨胀 Σ，并要求额外一次独立回执后再验证。
这是 Smith 预测器思想在异步修复上的离散化；避免「用过期状态做热替换」。

**定义 437（可观测性/可控性与控制权限）** 盲区 s 的**控制权限**
A(s) = max_{t∈T₀, h∈H_s} (Ĝ_t(h) − c_t)，且仅在风险门 λ ≥ γ 下取。
- 若 A(s) < γ_B：UNCONTROLLABLE，任何预算都无法带来正增益 ⇒ 禁止探测，直接 stub+RED；
- 若所有工具对 u_s 的敏感度低于 ε_obs：UNOBSERVABLE ⇒ 标记并转人工，不消耗预算。
这把第 2 轮「预算赌博循环」从「靠 TCV 拒绝重复调用」升级为「先证明有控制权限再下注」。

**定义 438（Q-Box 先验偏差检测器）** 交叉验证标准化残差 z_t 进入双侧 CUSUM：
S_t^+ = max(0, S_{t−1}^+ + z_t − ν)，S_t^- = max(0, S_{t−1}^- − z_t − ν)；
报警当 max(S_t^+, S_t^-) > h。按 ARL₀ ≥ A、检测延迟 ≤ D（对漂移 δ_b）选取 (ν,h)。
报警 ⇒ 冻结积分、暂停 AP-Cal、回退第 1 轮 BP-Cal，并触发定义 439 证书重审。
第 2 轮 P-Quarantine 的符号计数是本定义在 ν=0、h=q 时的特例；Q-Box 首次给出虚警率/检测延迟语义。

**定义 439（伺服稳定性证书）** Cert_Servo = (ρ̂, c_0, γ_met, γ_prior, δ_max, D, 假设集, η_ab, 监控残差, 有效期)。
仅在以下条件同时成立时签发：
(i) 小增益条件 γ_met·γ_prior ≤ 1−c（c>0）；
(ii) 实测 V 收缩率 ρ̂ ≤ ρ_max；
(iii) canary 晋升无回滚或回滚率 ≤ r_max；
(iv) 孪生-现场差距 η_ab ≤ η_max。
证书绑定进 EC；过期、漂移超限或 Q-Box 报警 ⇒ 证书失效 ⇒ 退化到 ToolGauge 开环 6C。
证书是「契约完整性」不变式的控制层扩展：**无证书不晋升**。

**定义 440（消融单元与干预估计量）** 模块集 N = {MP-Φ, TCV, SNC, Q-Box, Servo, Canary}。
干预 do(off S), S⊆N；结果 Y ∈ ℝ^k = (风险, 覆盖率, 代价, 时延, 安全违规)。
单步效应 τ_S = E[Y | do(off S)] − E[Y | do(∅)]；
闭环下改用 H 步轨迹泛函 Y_H = Σ_{t=0..H} γ^t ℓ(V_t, cost_t)（折扣回报），报告**轨迹效应**而非单步 ATE。
Shapley 归因 φ_i = Σ_{S⊆N\{i}} |S|!(n−|S|−1)!/n! · [τ_{S∪{i}} − τ_S]；
交互指标 I_S 由函数方差分解（functional ANOVA / Sobol）给出，显式报告二阶及以上交互。

**定义 441（消融设计与可采纳性）** 设计 D = (析因或分辨度 ≥ V 的部分析因, 配对公共随机数, 分层 bootstrap,
多重性控制 Holm/BH, 预注册主终点与非劣界)。消融**可采纳**当且仅当：
① 消融后五不变式仍成立；② 未越过安全包络；③ 预算/时延约束满足；
④ 干预矩阵满秩（可识别性，定义 441 的秩条件）；⑤ 预注册哈希存在。
任一不满足 ⇒ 判为 **invalid ablation**，只报告不解释，禁止进入主张。

**定义 442（消融证书与主张扩展）** Cert_Abl = (id, 估计量, 设计, n, seeds, 场景分布, 效应量+CI,
交互矩阵, 有效性包络, 孪生差距 η_ab, 负对照, 代码哈希, 预注册哈希, 审计者)。
任何关于「模块贡献」的语言主张必须引用有效 Cert_Abl，否则契约序列化时剥离；
剥离仍是纯投影，不改变数值行为（扩展定义 423）。

**定义 443（安全消融与孪生重放）** 关键集 S_crit = {TCV, 风险门, PROBING, 契约回归, Q-Box}。
- S_crit **禁止现场消融**，只允许数字孪生/影子模式重放；
- 非关键模块现场消融必须带硬守卫、预算上限与 kill switch；
- 孪生-现场差距 η_ab 超过 η_max 时，孪生结论不得外推为现场结论。
消融是研究工具，不是运行时优化器；A-Box 的输出必须经变更控制，禁止直接改安全关键增益。

**定义 444（集成与退化链，继承编号）** ServoGauge 的闭环外壳为
R（参考/误差/势）→ 6C（继承定义 421）→ P（分级晋升，定义 434）→ Q（偏差检测，定义 438）→ 反馈。
令 Servo=∅、P=全量晋升、Q=符号计数、A-Box=∅ ⇒ ServoGauge ≡ ToolGauge。
未被本轮重定义的第 2 轮记号（R、s、λ、γ、M_ver、N_bl、EC、MReg、T-Box、AP-Cal 等）沿用定义 416–431。
严格退化链：**ServoGauge ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE**；控制层与消融层均为增强项。

## 2. 关键算法骨架

```python
# IP-321 R-Box：参考、误差、风险势与控制权限
class RBox:
    def error(self, M, s):
        e = (M.sigma[s]/M.eps - 1, M.coverage - (1-M.alpha),
             norm(M.b_hat)/M.b_max, M.claim_debt)
        return e
    def potential(self, M):
        return (sum(w*(M.sigma[s]/M.eps)**2 for s,w in M.risk_w.items())
                + M.lam_b*norm(M.b_hat)**2/M.b_max**2
                + M.lam_c*M.claim_debt
                + M.lam_B*max(0, M.B_min-M.budget)/M.B_min)
    def authority(self, s, H_s, tools):
        vals = [t.info_gain(h, M.mp_phi)-t.cost
                for t in tools for h in H_s if M.risk_gate(t, s)]
        return max(vals, default=-inf)          # < γ_B ⇒ UNCONTROLLABLE

# IP-322 C-Box：受限伺服控制器（速率限制 + 抗饱和 + 纯延迟补偿）
class ServoController:
    def step(self, M, s):
        if M.rbox.authority(s, M.H[s], M.tools) < M.gamma_B:
            return stub_and_red(s, "uncontrollable")       # 定义 437
        u = M.tbox.select(M.H[s], M.tools, M.tcv, M.budget_left(s))
        u = self.deadtime_guard(M, u)                      # 定义 436
        du = self.rate_limit(u, M.last_u[s], M.delta_max)  # 定义 434
        if self.saturated(M, du) or M.qbox.alarm:
            M.b_hat = M.b_hat                              # 冻结积分（抗饱和，定义 435）
        else:
            M.b_hat = project(M.b_hat + M.eta*M.rbox.error(M, s), M.b_max)
        return du

# IP-323 Q-Box：CUSUM 偏差检测 + 小增益在线估计
class QBox:
    def update(self, z):
        self.Sp = max(0, self.Sp + z - self.nu)
        self.Sm = max(0, self.Sm - z - self.nu)
        self.alarm = max(self.Sp, self.Sm) > self.h
        return self.alarm
    def small_gain_ok(self, gamma_met, gamma_prior):
        return gamma_met*gamma_prior <= 1 - self.c      # 定义 439(i)

# IP-324 P-Box：分级晋升与回滚
class PBox:
    def promote(self, M, new_ec, k=1, n=3):
        canaries = sample(M.dbox.blind_spots(), k)
        for s in canaries:
            M.mreg.hot_replace(M.dpe, new_ec, s)
            if M.potential() > M.potential_before + M.eta_c:
                M.mreg.rollback(s); return False         # 污染半径受限
        return M.k_of_n_success(canaries, n)             # 定义 434

# IP-325 ServoGauge 主闭环（异步，50Hz 路径只读）
def servogauge_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight and M.B_t > 0:
            M.inflight.add(s)
            submit_async(servo_repair, M, s)             # R→6C→P→Q
    if M.qbox.alarm or not M.qbox.small_gain_ok(M.gamma_met, M.gamma_prior):
        M.servo_freeze = True                             # 退化到 ToolGauge 开环
    return MODGAUGE_round(M, obs, audio, tac, depth, det)

# IP-326 A-Box：闭环消融（孪生优先 + 析因/Shapley + 证书）
class ABox:
    def run(self, M, modules, scenarios):
        if not self.preregistered(): return None          # 定义 441⑤
        cells = factorial(modules) if n<=5 else fractional(modules, res=5)
        Y = [self.twin_replay(M, do(off=S), scenarios) for S in cells]  # 定义 443
        eff = self.interventional_effects(Y)              # 定义 440
        shap = self.shapley(eff); inter = self.anova(eff) # 交互矩阵
        cert = Cert_Abl(eff, shap, inter, self.envelope(),
                        eta_ab=self.twin_gap(), n=len(scenarios))
        return cert if self.admissible(cert) else invalid(cert)
```

## 3. 推导

**引理 51（伺服环一致最终有界，ISS 型）** 在定义 419 双闸门、定义 434 速率限制、定义 435 抗饱和、
定义 438 Q-Box 以及小增益条件 γ_met·γ_prior ≤ 1−c 下，存在 ρ∈(0,1)、c_0,c_1<∞ 使
V_{t+1} ≤ ρ V_t + c_0‖d_t‖² + c_1。
证明思路：把 ΔV 分为三块——计量环的方差收缩项（双闸门保证每次有效探测降低 σ/ε）、
先验偏差项（积分补偿 + Q-Box 冻结使其不累积）、耦合项（小增益把交叉项吸收进 (1−c)V）；
速率限制保证单步 Δu 有界，故局部 Lipschitz 常数可被 δ_max 控制。系：V 最终进入不变集 Ω；
若小增益失败，Q-Box 冻结先验并退化，系统仍有 ToolGauge 的局部界。

**引理 52（异步收缩与污染半径）** 若单次修复算子 T 在 V-范数下为 ρ-压缩，延迟 ≤ D，
且速率限制满足 δ_max < (1−ρ)/L_T，则异步迭代收敛到唯一不动点；
在 k-of-n canary 下，单个错误先验污染超过 k 个子图的概率 ≤ p_bad^k（独立回执交叉验证失败率 p_bad）。
证明思路：异步迭代的标准收缩映射 + 延迟不变性；canary 把「全量写入」分解为「k 个独立门」，
污染必须连续通过 k 道门，故呈指数衰减。这是对第 2 轮「一次错误先验污染所有子图」的直接修复。

**引理 53（抗饱和与常值偏差消除）** 对常值共享偏差 b∈B_b，积分估计器（定义 435）在
0<η<2/L_g 且未触发冻结时满足 ‖b̂_t − b‖ 单调有界并收敛到 0 的邻域；
执行器饱和时冻结积分保证无 windup，饱和解除后超调 ≤ η·‖e‖·τ_sat。
证明思路：标准投影积分 + 饱和冻结的分段 Lyapunov 论证。

**引理 54（Q-Box 检测性能）** 残差 i.i.d. 高斯、漂移 δ_b>ν 时，CUSUM 的
E_0[T] ≥ exp(2hν/σ²)（ARL₀ 下界）且 E_δ[T] ≤ h/(δ_b−ν)+O(1)。
符号计数（第 2 轮 P-Quarantine）是 ν=0 的特例，在相同 ARL₀ 下检测延迟更差；
故 Q-Box 在虚警-延迟曲线上严格占优（在同分布假设内）。

**引理 55（消融的可识别性与方差分解）** 若干预矩阵在预注册场景上列满秩，则所有
f_T（T⊆N）可识别，Y 的方差可分解为 Σ_T f_T；Shapley 满足
φ_i = f_{i} + ½Σ_{j≠i} f_{ij} + ⅓Σ_{j<k, j,k≠i} f_{ijk} + …。
若秩亏，则至少存在一组 f_T 不可识别，任何单一顺序的 leave-one-out 都不能作为因果贡献。
证明思路：干预设计矩阵的秩条件 + functional ANOVA 的正交分解。

**引理 56（闭环消融的顺序非交换性）** 顺序消融效应
Δ_i^{seq} = τ_{{i}}（若 i 先）与 τ_{{i,j}}−τ_{{j}}（若 i 后）之差等于交互项 I_{ij}。
因此单顺序 LOO 的归因一般不等于 Shapley；报告 Shapley/顺序平均是识别交互下的唯一对称归因。
系：若所有交互项为 0，则 Shapley = LOO = 可加归因。

**引理 57（消融安全包络）** 在孪生中消融非关键模块，且孪生-现场差距 ≤ η_ab 时，
现场效应满足 |τ_field − τ_twin| ≤ L_η·η_ab；若 η_ab ≤ η_max 且不越过安全包络，
则五不变式保持。关键集 S_crit 的现场消融无此保证，故定义 443 一律禁止。
证明思路：模型差距的 Lipschitz 外推 + 安全包络的可行性约束。

## 6. 本轮最大风险（一句话）

**一句话**：伺服稳定性证书只在「局部线性化 + 平稳扰动 + 小偏差」的植物模型下成立，
而真实系统是非线性、非平稳且**消融本身会改变植物**的——于是 ServoGauge 可能在模型上证明收缩、
在现实中缓慢漂移或振荡，而消融证书又给这种假稳定披上「可审计」的外衣。

**次级风险与缓解**：
1. **模型失配** → 定义 439 的 η_ab 与有效期 + 定义 436 delay-ambiguous + 在线 V 监控；证书失效即退化；
2. **增益调参脆弱** → 小增益在线估计 + 保守 δ_max + canary 回滚；禁止一次性全量晋升；
3. **Q-Box 虚警/漏检** → ARL₀ 预注册 + 与符号计数双轨对照 + 报警只冻结不删除数据；
4. **消融多重比较/顺序依赖** → 预注册主终点 + Holm/BH + Shapley/ANOVA 交互项 + 负对照；
5. **Goodhart（消融被用于调参后再次消融）** → 预注册 + 留出场景 + 变更控制 + 独立审计；
6. **孪生-现场差距** → η_ab 实测上限；超限则孪生结论不得外推（定义 443）；
7. **消融变成攻击面** → A-Box 仅影子模式 + S_crit 禁现场 + kill switch + 证书哈希；
8. **控制层拖慢修复** → 全异步 + 50Hz 只读势；控制失效按严格退化链回 ToolGauge。

> **本轮最大风险（一句话收束）**：伺服稳定性证书只在局部线性化、平稳扰动、小偏差的植物模型下成立，
> 而真实系统非线性、非平稳且消融会改变植物本身——ServoGauge 可能在模型上证明收缩、在现实中缓慢漂移或振荡，
> 消融证书又会让这种假稳定显得「可审计可信」。

## 2. 形式化定义（要点）

**定义 432（修复植物）** 离散修复纪元 t 的状态 x_t 含 μ/σ 场、共享偏差 b、预算 B、在飞集 I、主张债务；
x_{t+1}=F(x_t,u_t,d_t)+w_t，y_t=G(x_t)+v_t。F 显式建模方差收缩、热替换、漂移与预算消耗。

**定义 433（参考/误差/风险势）** r=(ε,1−α,0,0)，e_t=(σ_t/ε−1, cov_t−(1−α), b_t/b_max, debt)；
V_t=Σ w_s(σ_s/ε)²+λ_b‖b‖²/b_max²+λ_c·debt+λ_B·预算屏障。目标：V_{t+1}≤ρV_t+c_0‖d‖²+c_1，最终进入不变集 Ω。

**定义 434（受限执行/分级晋升）** ‖Δu‖_G≤δ_max；k-of-n canary 晋升；V 上升超 η_c 或交叉验证失败 ⇒ 全量回滚。
污染半径 ≤ k，而非全子图。

**定义 435（积分偏差估计/抗饱和）** b̂←Proj_{B_b}(b̂+ηe)；饱和或 Q-Box 报警时冻结积分；AP-Cal 均值减 b̂。
稳态常值偏差消除，且无 windup（0<η<2/L_g）。

**定义 436（纯延迟补偿）** 预测 x̂_{t+τ_d|t}=F^{τ_d}(x_t,u_t)；残差>ε_dt ⇒ delay-ambiguous，不晋升，
Σ 膨胀 τ_d·κ_d，并要求额外独立回执后再验证。

**定义 437（可观测/可控性）** A(s)=max_{t,h}(Ĝ_t(h)−c_t)（风险门内）；A<γ_B ⇒ UNCONTROLLABLE ⇒ stub+RED；
所有工具敏感度<ε_obs ⇒ UNOBSERVABLE ⇒ 转人工，不消耗预算。

**定义 438（Q-Box）** z_t 进入双侧 CUSUM：S^±=max(0,S^±∓z_t−ν)，max>h 报警；
按 ARL₀≥A、检测延迟≤D 选 (ν,h)。报警 ⇒ 冻结积分 + 暂停 AP-Cal + 回退 BP-Cal + 证书重审。

**定义 439（伺服稳定性证书）** Cert_Servo 需同时满足：小增益 γ_met·γ_prior≤1−c、实测 ρ̂≤ρ_max、
canary 回滚率≤r_max、η_ab≤η_max。证书绑定 EC；过期/漂移/Q-Box 报警即失效 ⇒ 退化。

**定义 440（消融估计量）** N={MP-Φ,TCV,SNC,Q-Box,Servo,Canary}；τ_S=E[Y|do(off S)]−E[Y|do(∅)]；
闭环用 H 步轨迹泛函 Y_H=Σγ^tℓ(V_t,cost_t)；Shapley φ_i 与交互 I_S（functional ANOVA/Sobol）。

**定义 441（消融设计与可采纳性）** 析因/分辨度≥V 的部分析因、配对公共随机数、分层 bootstrap、
Holm/BH、预注册主终点与非劣界。可采纳 iff 五不变式成立 ∧ 安全包络内 ∧ 预算满足 ∧ 干预矩阵满秩 ∧ 预注册哈希存在；
否则 invalid ablation，只报告不解释。

**定义 442（消融证书/主张扩展）** Cert_Abl=(id,估计量,设计,n,seeds,场景,效应+CI,交互矩阵,包络,η_ab,负对照,
代码哈希,预注册哈希,审计者)。模块贡献主张必须引用有效证书，否则剥离（纯投影，不改数值行为）。

**定义 443（安全消融/孪生重放）** S_crit={TCV,风险门,PROBING,契约回归,Q-Box} 禁止现场消融；
非关键模块现场消融需硬守卫+预算上限+kill switch；η_ab>η_max 时孪生结论不得外推。
A-Box 输出经变更控制，禁止直接改安全关键增益。

**定义 444（集成/退化链）** Servo 壳：R→6C→P→Q→反馈；令 Servo=∅、P=全量、Q=符号计数、A-Box=∅ ⇒ ServoGauge≡ToolGauge。
未重定义记号沿用定义 416–431。退化链：ServoGauge ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。

## 3. 关键算法骨架

```python
# IP-321 R-Box
class RBox:
    def potential(self, M):
        return (sum(w*(M.sigma[s]/M.eps)**2 for s,w in M.risk_w.items())
                + M.lam_b*norm(M.b_hat)**2/M.b_max**2
                + M.lam_c*M.claim_debt
                + M.lam_B*max(0, M.B_min-M.budget)/M.B_min)
    def authority(self, s, H_s, tools):
        return max((t.info_gain(h, M.mp_phi)-t.cost
                    for t in tools for h in H_s
                    if M.risk_gate(t, s)), default=-inf)

# IP-322 C-Box：速率限制 + 抗饱和 + 纯延迟守卫
class ServoController:
    def step(self, M, s):
        if M.rbox.authority(s, M.H[s], M.tools) < M.gamma_B:
            return stub_and_red(s, "uncontrollable")
        u  = M.tbox.select(M.H[s], M.tools, M.tcv, M.budget_left(s))
        u  = self.deadtime_guard(M, u)
        du = self.rate_limit(u, M.last_u[s], M.delta_max)
        if self.saturated(M) or M.qbox.alarm:
            pass                                     # 冻结积分
        else:
            M.b_hat = project(M.b_hat + M.eta*M.rbox.error(M, s), M.b_max)
        return du

# IP-323 Q-Box
class QBox:
    def update(self, z):
        self.Sp = max(0, self.Sp + z - self.nu)
        self.Sm = max(0, self.Sm - z - self.nu)
        self.alarm = max(self.Sp, self.Sm) > self.h
        return self.alarm
    def small_gain_ok(self, gm, gp): return gm*gp <= 1 - self.c

# IP-324 P-Box
class PBox:
    def promote(self, M, new_ec, k=1, n=3):
        canaries = sample(M.dbox.blind_spots(), k)
        for s in canaries:
            M.mreg.hot_replace(M.dpe, new_ec, s)
            if M.potential() > M.potential_before + M.eta_c:
                M.mreg.rollback(s); return False
        return M.k_of_n_success(canaries, n)

# IP-325 ServoGauge 主闭环
def servogauge_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight and M.B_t > 0:
            M.inflight.add(s); submit_async(servo_repair, M, s)
    if M.qbox.alarm or not M.qbox.small_gain_ok(M.gamma_met, M.gamma_prior):
        M.servo_freeze = True
    return MODGAUGE_round(M, obs, audio, tac, depth, det)

# IP-326 A-Box：孪生优先的析因/Shapley 消融
class ABox:
    def run(self, M, modules, scenarios):
        if not self.preregistered(): return None
        cells = factorial(modules) if len(modules) <= 5 else fractional(modules, 5)
        Y = [self.twin_replay(M, do(off=S), scenarios) for S in cells]
        eff = self.interventional_effects(Y)
        cert = Cert_Abl(eff, self.shapley(eff), self.anova(eff),
                        self.envelope(), eta_ab=self.twin_gap(),
                        n=len(scenarios), neg_control=self.placebo())
        return cert if self.admissible(cert) else invalid(cert)
```

## 4. 推导

**引理 51（伺服环 ISS/UUB）** 双闸门 + δ_max + 抗饱和 + Q-Box + 小增益 γ_met·γ_prior≤1−c 下，
V_{t+1}≤ρV_t+c_0‖d_t‖²+c_1（ρ∈(0,1)）。证明：ΔV 分解为方差收缩项、偏差项、耦合项；
双闸门保证每次有效探测降 σ/ε，积分+Q-Box 保证 b 不累积，小增益吸收交叉项；速率限制控制局部 Lipschitz。
系：V 进入不变集 Ω；小增益失败 ⇒ Q-Box 冻结 + 退化，仍有 ToolGauge 局部界。

**引理 52（异步收缩/污染半径）** T 为 ρ-压缩、延迟≤D、δ_max<(1−ρ)/L_T ⇒ 异步迭代收敛；
k-of-n canary 下单个坏先验污染 >k 个子图的概率 ≤ p_bad^k。
证明：收缩映射 + 延迟不变性；每个 canary 为独立门，污染需连续过 k 门。

**引理 53（抗饱和偏差消除）** 常值 b∈B_b，0<η<2/L_g 且未冻结 ⇒ ‖b̂_t−b‖ 有界收敛到 0 邻域；
饱和冻结无 windup，解除后超调 ≤ η‖e‖τ_sat。证明：投影积分 + 分段 Lyapunov。

**引理 54（Q-Box 检测）** 高斯 i.i.d. 残差、漂移 δ_b>ν 时，E₀[T]≥exp(2hν/σ²)，
E_δ[T]≤h/(δ_b−ν)+O(1)。符号计数为 ν=0 特例，同 ARL₀ 下检测延迟更差 ⇒ Q-Box 在同假设内占优。

**引理 55（消融可识别性）** 干预矩阵列满秩 ⇒ 所有 f_T 可识别，Y 方差分解为 Σ_T f_T；
Shapley φ_i=f_i+½Σ f_ij+⅓Σ f_ijk+…。秩亏 ⇒ 存在不可识别 f_T，单顺序 LOO 不能作因果贡献。

**引理 56（顺序非交换）** Δ_i^{seq} 在先/后两种顺序之差 = 交互项 I_ij；
故单顺序 LOO ≠ Shapley；Shapley/顺序平均是交互下唯一对称归因。全交互为 0 时三者相等。

**引理 57（消融安全包络）** 孪生消融非关键模块且 η_ab≤η_max ⇒ |τ_field−τ_twin|≤L_η·η_ab；
包络内五不变式保持。S_crit 现场消融无此保证 ⇒ 定义 443 禁止。

## 8. 本轮最大风险

**一句话**：伺服稳定性证书只在局部线性化、平稳扰动、小偏差的植物模型下成立，
而真实系统非线性、非平稳且消融会改变植物本身——ServoGauge 可能在模型上证明收缩、在现实中缓慢漂移或振荡，
消融证书又会让这种假稳定显得「可审计可信」。

**次级风险与缓解**：
1. **模型失配** → η_ab 实测上限 + 证书有效期 + 在线 V 监控；失效即退化到 ToolGauge；
2. **增益脆弱** → 小增益在线估计 + 保守 δ_max + canary 回滚；禁止一次性全量晋升；
3. **Q-Box 虚警/漏检** → ARL₀ 预注册 + 与符号计数双轨 + 报警只冻结不删数据；
4. **消融多重比较/顺序依赖** → 预注册主终点 + Holm/BH + Shapley/ANOVA + 负对照；
5. **Goodhart** → 预注册 + 留出场景 + 变更控制 + 独立审计；
6. **孪生差距** → η_ab > η_max 时禁止外推（定义 443）；
7. **消融攻击面** → A-Box 仅影子/孪生 + S_crit 禁现场 + kill switch + 证书哈希；
8. **控制时延** → 全异步 + 50Hz 只读势；控制失效按严格退化链回 ToolGauge。

> **本轮最大风险（一句话收束）**：伺服稳定性证书只在局部线性化、平稳扰动、小偏差的植物模型下成立，
> 而真实系统非线性、非平稳且消融会改变植物本身——ServoGauge 可能在模型上证明收缩、在现实中缓慢漂移或振荡，
> 消融证书又会让这种假稳定显得「可审计可信」。
