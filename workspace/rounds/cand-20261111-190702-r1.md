# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；新一轮灵感循环第 1 轮；本轮灵感：「深度相机」×「多机评测」）

> 第 54 轮把技能组合从能力匹配推进到动作-鲁棒性双证书（`α_S, A_cert, γ_ce, δ_a`）。本轮追问两个被隐含假设掉的前提：**(i) 动作前提的几何是“真”的**——但真实机器人靠深度相机获得几何，深度本身有结构化失效；**(ii) 证书在一台机器上成立即可信**——但真实部署是多机、异构、分布式的，单机证据只是一个样本。核心矛盾：H22：深度几何证据的可靠性随材质/光照/视角剧烈变化，导致 `α_S` 在真实场景中系统性虚高；H23：多机评测把“证书有效性”变成总体统计问题，单机 P95 不能替代跨机最坏情形，且机器指纹相关失效会击穿独立同分布假设。

## 0. 直觉与动机

**灵感 1（深度相机 = 有结构的几何证据场，而非点云黑箱）**
直觉：深度相机给出的不是“真值点云”，而是一张带**空间相关误差**的证据图。镜面、透明、低纹理、逆光、超量程会让整片区域输出“数值合法但几何错误”的深度。因此技能 S 的可执行性不应再写成 `α_S(a)`，而应写成条件于深度证据的动作剖面 `α_S(a | D, β_D)`：只有当动作 a 的几何前提投影到图像支撑区域上的**证据置信度**均超过阈值，a 才可执行。这把“感知”从预处理变成**证书的第一类前提**。

**灵感 2（深度退化即动作空间收缩）**
直觉：把每一类深度失效建模为退化算子 `T_δ`（透明、镜面、暗光、过曝、运动模糊、无纹理）。在退化下，技能的动作集收缩为 `A_δ = {a | α_S(a | T_δ D) ≥ θ_cov}`，**收缩比 `κ_δ = |A_δ| / |A|`** 就是可测的感知鲁棒性。第 54 轮的动作空间不再是常量，而是一个随退化族变化的族 `{A_δ}`；组合与云边映射都必须在这个族上成立。

**灵感 3（多机评测 = 评估者总体，而不是跑分均值）**
直觉：一台机器只是从机器总体 `P_M` 中的一次抽样。不同深度模组的内参、基线、噪声、量程、驱动延迟，会让同一份证书在不同机器上系统性漂移。多机评测的目标不是“平均分更高”，而是给出**跨机分位数或最坏情形 + 置信区间**：`ρ_M(d; q) = Quantile_q({ρ_m(d)})_{m∈M}`。只有 `q` 分位满足下界，证书才对“这一批机器”可宣称。

**灵感 4（证书的可移植半径）**
直觉：机器指纹 `φ_m`（内参、噪声谱、基线、量程、算力、延迟）定义一个度量空间。证书不是全局真，而是**在指纹空间的一个球内成立**：若目标机 `φ_t` 到标定机 `φ_c` 的距离 `d_φ ≤ r_transfer`，则证书按 Lipschitz 界退化后仍成立；若超出半径，必须重测而不是外推。这把“多机复现”变成**带半径的证书迁移**。

**灵感 5（深度-总体双层金字塔）**
直觉：在既有鲁棒性层 `𝕃` 与动作-协同层 `𝔸` 之上再叠两层：`𝔻`（深度证据层：`𝔻_0` 传感器物理、`𝔻_1` 证据场 `β_D`、`𝔻_2` 退化族 `{T_δ}`）与 `𝕄`（机器总体层：`𝕄_0` 单机指纹、`𝕄_1` 跨机分布、`𝕄_2` 可移植半径）。跨层证书必须同时携带 `J`、`G_cert`、`E_cert` 与 `r_transfer`，形成**可移植联合证书 `Π`**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（深度证据场）**
深度图 `D: Ω → ℝ_+`，`Ω` 为像素域。证据场 `β_D: Ω → [0,1]` 由四类局部一致性融合：
```
β_D(x) = σ( w_g·g(x) + w_s·s(x) + w_i·i(x) + w_r·r(x) )
```
其中 `g` 为局部平面/法向拟合残差一致性，`s` 为左右/多视角重投影一致性，`i` 为纹理与反射先验，`r` 为量程裕度；`σ` 为校准函数。要求 `β_D` **校准**：`|P(correct | β_D=u) - u| ≤ ε_cal`。

**定义 122（深度条件动作剖面）**
设 `π(a) ⊆ Ω` 为动作 a 的几何前提在图像上的支撑区。深度条件动作剖面
```
α_S(a | D, β_D) = α_S(a) · 𝟙[ min_{x∈π(a)} β_D(x) ≥ θ_D ]
```
`cover_D(S, A_T) = 1` 当且仅当 `∀ a∈A_T, α_S(a|D,β_D) ≥ θ_cov`。注意这里用 **min** 而非均值：支撑区里任一像素的证据崩塌都可能让动作前提失效。

**定义 123（深度退化算子与收缩比）**
退化族 `𝒯 = {T_δ}_{δ∈Δ}`，每个 `T_δ` 作用于深度图。技能在退化下的可执行动作集
```
A_δ = { a ∈ A | α_S(a | T_δ D, β_{T_δ D}) ≥ θ_cov }
```
**收缩比** `κ_δ(S) = |A_δ| / |A|`；**深度鲁棒谱** `κ(S) = { κ_δ(S) }_{δ∈Δ}`。若 `∃δ: κ_δ < κ_min`，则该技能不允许进入对安全关键任务的组合。

**定义 124（机器指纹与总体）**
机器 `m` 的指纹 `φ_m = (K_m, b_m, σ_m, [d_min,d_max], c_m, ℓ_m)`：内参、基线、噪声谱、量程、算力、端到端延迟。机器总体 `P_M` 为指纹空间上的分布。**跨机鲁棒谱**
```
ρ_M(d; q) = Quantile_q( { ρ_m(d) }_{m ∼ P_M} )
```
多机评测只对该总体在分位 `q` 上作声明，不允许把单机结果当作总体真值。

**定义 125（多机评测证书）**
`E_cert = (M_eval, n, q, CI_{1-α}, Ŵ_1(P_M, P_eval), protocol)`：
- `M_eval` 参与评测的机器集合，`n = |M_eval|`；
- `q` 声明的分位数（默认 `q=0.05` 下分位）；
- `CI` 为分位数的自助法置信区间；
- `Ŵ_1` 为评测集与目标总体之间的一阶 Wasserstein 距离估计；
- `protocol` 固定采样、随机种子、深度退化矩阵与数据划分，保证可复现。
声称“证书对 `P_M` 的 `q` 分位成立”当且仅当 `CI` 下界仍满足下界目标且 `Ŵ_1 ≤ W_max`。

**定义 126（可移植联合证书）**
```
Π = ( J, G_cert, E_cert, r_transfer, evidence )
```
其中 `J` 为第 54 轮动作-鲁棒性联合证书；`G_cert = (π_core, β_min, ε_occ, σ_n)` 为深度几何接地证书（核心支撑区、最低证据、遮挡裕度、噪声包络）；`E_cert` 为定义 125；`r_transfer` 为可移植半径。部署判定：
```
deploy(Π, m_t) = 1  ⟺  d_φ(φ_t, φ_c) ≤ r_transfer
                     ∧  G_cert 约束在 T_δ D 下成立
                     ∧  ρ_{m_t}(d) ≥ ρ_M(d; q) ∀d
```

## 2. 关键算法 伪代码

### IP-121 DGF（Depth Grounding Field）

```python
def depth_evidence(D, K, stereo_pair=None, sensor_spec=None):
    g = plane_fit_residual_consistency(D, k=5)
    s = reprojection_consistency(D, stereo_pair) if stereo_pair else 1.0
    i = texture_reflection_prior(D)
    r = range_margin(D, sensor_spec.d_min, sensor_spec.d_max)
    beta = calibrate(sigmoid(w_g*g + w_s*s + w_i*i + w_r*r))
    return beta

def project_action_support(a, K, T_world_cam):
    return rasterize(project(action_precondition(a), K, T_world_cam))

def cover_depth(alpha_S, a, D, beta, theta_D=0.6, theta_cov=0.8):
    support = project_action_support(a, K, T_world_cam)
    if min(beta[x] for x in support) < theta_D:
        return 0.0
    return alpha_S(a) if alpha_S(a) >= theta_cov else 0.0
```

### IP-122 DCAP（Depth-Conditioned Action Profile）

```python
def depth_conditioned_profile(skill, D, beta, A_T):
    alpha_D = {a: cover_depth(skill.alpha[a], a, D, beta) for a in skill.A}
    feasible = [a for a,v in alpha_D.items() if v >= theta_cov]
    return alpha_D, cover_check(alpha_D, A_T)

def degradation_spectrum(skill, D, family=TRANSPARENT,MIRROR,DARK,OVEREXPOSE,BLUR,TEXTLESS):
    kappa = {}
    for name, T_delta in family:
        D2 = T_delta(D)
        beta2 = depth_evidence(D2, skill.K, skill.stereo, skill.sensor)
        alpha2, _ = depth_conditioned_profile(skill, D2, beta2, skill.A)
        A_delta = [a for a,v in alpha2.items() if v >= theta_cov]
        kappa[name] = len(A_delta) / max(1, len(skill.A))
    return kappa
```

### IP-123 DST（Depth Stress Test）

```python
def stress_certify(skill, scenes, family):
    certs = {}
    for scene in scenes:
        D = scene.depth
        kappa = degradation_spectrum(skill, D, family)
        worst = min(kappa.values())
        certs[scene.id] = (kappa, worst)
        if worst < kappa_min:
            certs[scene.id] += ('reject', argmin(kappa), explain_depth_failure(scene))
    return certs
```

### IP-124 MMEP（Multi-Machine Evaluation Protocol）

```python
def multi_machine_eval(cert_fn, machines, tasks, q=0.05, B=1000, seed=0):
    per_machine = {}
    for m in machines:
        per_machine[m.id] = [cert_fn(m, t) for t in tasks]   # 逐任务成功率/鲁棒谱
    pooled = bootstrap_quantile(per_machine, q=q, B=B, seed=seed)
    W1 = wasserstein1(fingerprints(machines), target_population_fingerprints)
    if pooled.ci_low < rho_target or W1 > W_max:
        return ('insufficient_evidence', pooled, W1)
    return ('ok', E_cert(machines, len(machines), q, pooled.ci, W1, protocol='MMEP-v1'))
```

### IP-125 CMT（Cross-Machine Transfer）

```python
def transfer_radius(cert, m_cal, machines, L_phi=0.3):
    # 用标定机与评测机之间的证书退化拟合指纹距离的 Lipschitz 常数
    dists, drops = [], []
    for m in machines:
        dists.append(fingerprint_distance(m_cal.phi, m.phi))
        drops.append(cert_degradation(cert, m_cal, m))
    L_hat = lipschitz_upper_bound(dists, drops, confidence=0.95)
    r = cert.delta_budget / max(L_hat, eps)
    return min(r, L_phi_cap), L_hat

def portable_deploy(Pi, m_target):
    if fingerprint_distance(Pi.phi_c, m_target.phi) > Pi.r_transfer:
        return ('reject', 'outside_transfer_radius')
    if not depth_envelope_ok(Pi.G_cert, m_target.depth_conditions):
        return ('reject', 'depth_envelope_violated')
    if Pi.rho_target_min < Pi.E_cert.q_lower:
        return ('reject', 'population_quantile_unmet')
    return ('ok', Pi)
```

### IP-126 PJC（Portable Joint Certificate）

```python
def portable_joint_certificate(J, G_cert, E_cert, machines, m_cal, budget):
    r_transfer, L_hat = transfer_radius(J, m_cal, machines)
    rho_q = E_cert.q_lower
    if min(J.rho.values()) < rho_q:
        return ('reject', 'robustness_below_population_quantile', rho_q)
    if G_cert.beta_min < theta_D or G_cert.occ_margin < eps_occ:
        return ('reject', 'depth_grounding_insufficient')
    if r_transfer < budget.min_radius:
        return ('reject', 'transfer_radius_too_small', r_transfer)
    return ('ok', PortableCert(J, G_cert, E_cert, r_transfer, L_hat))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| DGF | O(|Ω|·k) | O(|Ω|) | 证据场校准 ECE ≤ ε_cal |
| DCAP | O(|A|·|π|+|Ω|) | O(|A|+|Ω|) | 支撑区 min 传播、退化族完备 |
| DST | O(|𝒯|·|A|·|π|·|scenes|) | O(|A|) | 退化算子可复现、最坏情形覆盖 |
| MMEP | O(n·|T| + B·n) | O(n·|T|) | 抽样代表性 `Ŵ_1 ≤ W_max`、分位 CI 有效 |
| CMT | O(n·|φ|) | O(n) | 指纹度量、Lipschitz 上界置信 |
| PJC | O(|𝔇_ρ| + n·|φ|) | O(n) | 三前提合取、半径外不外推 |

**正确性定理（Depth-Grounded Population-Sound Deployment）**
承接第 54 轮 (A26)–(A28)；新增 **(A29)** `β_D` 已校准且对退化族 `𝒯` 闭合；**(A30)** 机器样本相对 `P_M` 的 `Ŵ_1 ≤ W_max` 且 `n` 足以使分位 CI 有效；**(A31)** 证书退化对指纹距离满足 Lipschitz 常数 `L`，且 `r_transfer = δ_a / L`。
则对目标机 `m_t` 与深度条件 `D_t`：
```
P_success(m_t, D_t) ≥ ρ_M(q) - L·d_φ(φ_t, φ_c) - ECE(β_D) - β_E - P(compat<θ_a)
```
**解读**：成功率的置信下界由三件事共同扣减——**我们只对总体 q 分位负责**、**机器越远证书越退化**、**深度证据本身有校准误差**。任何一项超界都必须拒绝部署，而不是“再跑一次看看”。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 深度失效长尾未被退化族覆盖 | 高 | 真实材质库 + 对抗深度扰动 + 失效区主动采集 |
| 机器总体样本少导致分位不可信 | 高 | 分层抽样 + 指纹匹配 + 报告 CI 而非点估计 |
| 指纹距离与证书退化的 Lipschitz 界过松 | 高 | 分位数回归拟合 + 保守上界 + 半径外强制重测 |
| 深度证据校准在跨模态（ToF/结构光/双目）漂移 | 中 | 分模态校准 + 在线温度/曝光补偿 |
| 证书合并（J∧G∧E）过度保守导致不可用 | 中 | 分层放松 + 按任务关键度分级阈值 |

## 6. 本轮最大风险

**一句话**：把深度证据场与多机总体引入证书体系，使“可部署”从单机单场景的判断升级为**对深度退化族与机器总体的分位数承诺**，但其 soundness **三重依赖 `β_D` 的跨模态校准、退化族对真实长尾的覆盖、以及机器样本对目标总体的代表性**；只要有一类未建模的深度失效（如低反射率远距离）或机器总体偏移超出 `W_max`，证书就会在“统计上正确、实例上翻车”的方式下失效，故必须以 **长尾退化主动采集 + 指纹分层抽样 + 半径外强制重测** 三道闸门守住，宁可在评测阶段多拒一批机器，也不把总体分位当成任意单机的保证。

### IP-121 DGF

```python
def depth_evidence(D, K, stereo_pair=None, sensor_spec=None):
    g = plane_fit_residual_consistency(D, k=5)          # 局部平面一致性
    s = reprojection_consistency(D, stereo_pair) if stereo_pair else 1.0
    i = texture_reflection_prior(D)                     # 纹理/反射先验
    r = range_margin(D, sensor_spec.d_min, sensor_spec.d_max)
    return calibrate(sigmoid(w_g*g + w_s*s + w_i*i + w_r*r))

def project_action_support(a, K, T_world_cam):
    return rasterize(project(action_precondition(a), K, T_world_cam))

def cover_depth(alpha_S, a, D, beta, theta_D=0.6, theta_cov=0.8):
    support = project_action_support(a, K, T_world_cam)
    if min(beta[x] for x in support) < theta_D:   # 支撑区最弱像素决定成败
        return 0.0
    return alpha_S(a) if alpha_S(a) >= theta_cov else 0.0
```

### IP-122 DCAP

```python
def depth_conditioned_profile(skill, D, beta, A_T):
    alpha_D = {a: cover_depth(skill.alpha[a], a, D, beta) for a in skill.A}
    return alpha_D, cover_check(alpha_D, A_T)

def degradation_spectrum(skill, D, family):
    kappa = {}
    for name, T_delta in family:              # TRANSPARENT,MIRROR,DARK,...
        D2 = T_delta(D)
        beta2 = depth_evidence(D2, skill.K, skill.stereo, skill.sensor)
        alpha2, _ = depth_conditioned_profile(skill, D2, beta2, skill.A)
        A_delta = [a for a,v in alpha2.items() if v >= theta_cov]
        kappa[name] = len(A_delta) / max(1, len(skill.A))
    return kappa
```

### IP-123 DST

```python
def stress_certify(skill, scenes, family):
    certs = {}
    for scene in scenes:
        kappa = degradation_spectrum(skill, scene.depth, family)
        worst = min(kappa.values())
        certs[scene.id] = (kappa, worst)
        if worst < kappa_min:
            certs[scene.id] += ('reject', argmin(kappa),
                                explain_depth_failure(scene, argmin(kappa)))
    return certs
```

```python
def multi_machine_eval(cert_fn, machines, tasks, q=0.05, B=1000, seed=0):
```

### IP-125 CMT

```python
def transfer_radius(cert, m_cal, machines, L_cap=0.5):
    dists, drops = [], []
    for m in machines:
        dists.append(fingerprint_distance(m_cal.phi, m.phi))
        drops.append(cert_degradation(cert, m_cal, m))
    L_hat = lipschitz_upper_bound(dists, drops, confidence=0.95)
    return min(cert.delta_budget / max(L_hat, eps), L_cap), L_hat

def portable_deploy(Pi, m_target):
    if fingerprint_distance(Pi.phi_c, m_target.phi) > Pi.r_transfer:
        return ('reject', 'outside_transfer_radius')
    if not depth_envelope_ok(Pi.G_cert, m_target.depth_conditions):
        return ('reject', 'depth_envelope_violated')
    if Pi.rho_target_min < Pi.E_cert.q_lower:
        return ('reject', 'population_quantile_unmet')
    return ('ok', Pi)
```

### IP-126 PJC

```python
def portable_joint_certificate(J, G_cert, E_cert, machines, m_cal, budget):
    r_transfer, L_hat = transfer_radius(J, m_cal, machines)
    rho_q = E_cert.q_lower
    if min(J.rho.values()) < rho_q:
        return ('reject', 'robustness_below_population_quantile', rho_q)
    if G_cert.beta_min < theta_D or G_cert.occ_margin < eps_occ:

    if r_transfer < budget.min_radius:
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DGF | O(\|Ω\|·k) | O(\|Ω\|) | 证据场校准 ECE ≤ ε_cal |
| DCAP | O(\|A\|·\|π\|+\|Ω\|) | O(\|A\|+\|Ω\|) | 支撑区 min 传播、退化族闭合 |
| DST | O(\|𝒯\|·\|A\|·\|π\|·\|scenes\|) | O(\|A\|) | 退化可复现、最坏情形覆盖 |
| MMEP | O(n·\|T\| + B·n) | O(n·\|T\|) | `Ŵ_1 ≤ W_max`、分位 CI 覆盖率 |
| CMT | O(n·\|φ\|) | O(n) | 指纹度量 + Lipschitz 上界置信 |
| PJC | O(\|𝔇_ρ\| + n·\|φ\|) | O(n) | 三前提合取、半径外不外推 |

**正确性定理（Depth-Grounded Population-Sound Deployment）**
承第 54 轮 (A26)–(A28)；**(A29)** `β_D` 已校准且对退化族 `𝒯` 闭合；**(A30)** 评测集相对 `P_M` 满足 `Ŵ_1 ≤ W_max`，且 `n` 足以使分位 CI 有效；**(A31)** 证书退化对指纹距离满足 Lipschitz 常数 `L`，`r_transfer = δ_a / L`。
则对目标机 `m_t` 与深度条件 `D_t`：
```
P_success(m_t, D_t) ≥ ρ_M(q) - L·d_φ(φ_t, φ_c) - ECE(β_D) - β_E - P(compat<θ_a)
```
关键：**只对总体 q 分位负责**、**机器越远证书退化越多**、**深度证据有校准上限**。三项任一超界即拒绝部署。

## 5. 本轮最大风险

**一句话**：深度证据场与多机总体把“可部署”从单机单场景判断升级为**对深度退化族与机器总体的分位数承诺**，但其 soundness **三重依赖 `β_D` 的跨模态校准、退化族对真实长尾的覆盖、以及机器样本对目标总体的代表性**；只要有一类未建模的深度失效（如低反射率远距离）或总体偏移超出 `W_max`，证书就会以“统计上正确、实例上翻车”的方式失效，故必须以 **长尾退化主动采集 + 指纹分层抽样 + 半径外强制重测** 三道闸门守住，宁可在评测阶段多拒一批机器，也不把总体分位当成任意单机的保证。
