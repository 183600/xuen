# 第 2 轮（UniBot 线 · 第 2 轮；本轮灵感：「价值对齐」×「地形适应」）

> **承接关系**：本轮承接第 1 轮 **UniBot-SAGE**（接地层 / 技能层 / 适应层 / 工程层），不推倒重来。
> **编号纪律**：定义续用 **U13 起**、引理 **L8 起**、实验 **E619 起**；第 1 轮 U1–U12 / L1–L7 / E601–E618 保留有效。
> **数据纪律**：第 1 轮所有榜单数字来自 `leaderboard_data.json`（teaser / 占位表）。本轮把它**降级为结构先验**，不再当作效应量；所有"预期涨点"一律标为**预注册目标**而非已知事实。

## 0. 先纠偏：上一轮有三处必须修

**纠偏 1（最重要）· 我们在对一个可能"幻觉"的评分函数做优化。**
teaser 榜由 `gen_leaderboard.py` 生成且被"排行榜即将公开"遮罩。若它的 success_rate 是占位/合成值，那么第 1 轮的 `oracle +4.26`、`Kendall τ=0.064` 只是**结构假设**，不是可兑现的效应量。对一个不可信的榜做优化，本身就是一次 **reward hacking / 价值对齐失败**。所以本轮的第一动作不是"再压一个创新点"，而是**先对齐"评分函数是否可信"**：把 teaser 数字只用于提出机制，把真正的监督信号换回官方 32 数据集的自带成功定义 + 真机 rollout。

> 本轮仍对 teaser 做一次可复核的结构分析（n=256）：双向方差分解得 **task 主效应 65.8% / model 主效应 5.8% / task×model 交互 28.4%**；在 iid 零假设下三者期望约为 12.2% / 2.7% / 85.1%。观测到的任务难度结构远强于随机、交互远小于随机 ⇒ 表**不是纯 iid 噪声**，但"模型专长"与"生成器伪影"仍无法区分。结论：**借结构、不借数字**；正式榜发布后用同一脚本重算。

**纠偏 2 · "适应"被窄化成了视觉域偏移。**
第 1 轮把"地形"几乎等同于背景/光照/干扰物。但最难任务集中在**插入 / 旋转 / 细粒度放置**（Plug In Ethernet 17.7、Unlock 20.1、Open Pill Bottle 22.7），其主导变量是**接触动力学**（摩擦、柔顺、间隙、卡滞、滑移），不是背景。视觉域随机化已是公共做法、收益被摊薄；真正没被建模的是"接触地形"。

**纠偏 3 · 抓握确认的伪标签在泛化场景最不可信。**
第 1 轮把"抓住没有"做成独立分类器，但真值只能靠"抬起后物体随动"这类间接代理，未见物品上会漂移。本轮用**价值停滞**把它一般化：抓握失败只是"价值不再上升"的一个特例，不需要单独的抓握真值。

## 1. 直觉解释（先直觉，后定义）

### 1.1 「价值对齐」的直觉

行为克隆（BC）策略内隐的价值是"**像不像示范**"；评测器的价值是"**最后成没成**"。二者在最后一环系统性错位：模型"觉得自己快成了"就松劲，评测器要的是插进去 / 拧开 / 放稳——这正好解释了"能推进大半程、却死在最后对齐/插入/释放"的共同断点。

所以"价值对齐"在这里不是伦理口号，而是一个可操作的建模选择：**学一个显式的、与评测器同定义的终态价值 `V`（以及动作块价值 `Q`），用它来做三件事——选择（test-time 选动作块）、门控（何时恢复）、进度（何时停滞）。** 它同时把第 1 轮最脆的"VLM 六因子阶段标签"替换成**沿成功轨迹单调的进度函数**：若 `V` 单调上升，则"停滞 / 回退"就是失败信号，抓握失败只是其中一个特例。

但价值对齐最容易死于 **Goodhart**：若 `V` 在"看起来像成功"的状态虚高，best-of-N 会自信地选中最像成功的失败，恢复逻辑会"朝着幻觉成功"适配。

### 1.2 「地形适应」的直觉

桌面任务的"地形"= 接触面的物理性状（摩擦、柔顺、间隙、台面高度、质量分布）+ 由动作引起的**接触模式**（自由 / 稳定接触 / 滑移 / 卡滞 / 碰撞）。

观测里没有力/触觉，只有 1 维夹爪、EE 位姿、图像；但接触会通过**"动作—响应残差"显形**：命令动了多少 vs 实际动了多少、夹爪命令 vs 实际、腕部图像流。于是地形适应 = **用残差在线辨识接触模式，再在冻结 VLA 的接口内做有界的动作整形**（柔顺 / 微搜索 / 减力 / 增握 / 减速），而不是改网络权重。

危险在于：无力的观测下接触模式可能不可辨识；误判会把本来能成的轨迹搅乱。

### 1.3 合成：双环架构（不变的价值 / 可变的地形）

- **外环（价值环，慢）**：对齐的终态价值 / 进度 → 决定"要不要、往哪"（选 chunk、门控恢复、判停滞）。
- **内环（地形环，快）**：接触模式辨识 → 决定"怎么动"（柔顺、搜索、握力、减速）。

保留第 1 轮的接地层（抓握确认）作为外环的**特例**、技能层作为**候选生成器**、工程层作为**执行底座**。
一句话：**价值不随地形漂移，地形不随价值撒谎**（互为约束）。

## 2. 严谨定义（本轮新增；完整符号见产物区 §4）

- **U13 对齐终态价值**：`V_φ(o,ℓ) ≈ P(S=1 | o,ℓ)`，`S` 为评测器终态成功；BCE + 校准训练，标签只来自官方数据成功定义与真机 rollout（**U23 可审计标签来源**）。
- **U14 进度价值**：`V_prog(o,ℓ) ∈ [0,1]`，成功末帧为 1、起始为 0；用成功轨迹内的**成对排序损失** + 归一化 time-to-go 回归训练，**不需要失败标签**。
- **U15 动作块价值**：`Q_ψ(o, a_{t:t+H}) ≈ E[S | 执行该 chunk 后接基线策略]`；离线 IQL/TD，样本来自基线策略自身分布。
- **U16 支持约束选择**：`a* = argmax_{k≤K} Q_ψ(o, a^(k))`，其中 `a^(k) ~ π_base(·|o)`；**只采样、不对 Q 做梯度上升**（防 OOD reward hacking）。
- **U17 价值停滞**：`stall_t = 1` 当窗口内 `V_prog` 不再上升（`< ε`）且未接近成功（`< ν`），或出现回退（`> ρ`）；触发恢复。
- **U18 接触残差**：`r_t = [ẋ_EE^obs − ẋ_EE^cmd, ġrip^obs − ġrip^cmd, 光流残差]`。
- **U19 接触模式**：`m_t ∈ {free, contact, slip, jam, collision}`，由 `r_{t-k:t}` + 腕部图像流分类。
- **U20 有界地形整形**：`a'_t = a_t + δ_t`，`‖δ_t‖ ≤ δ_max`，且仅在**价值门控**（停滞或 `m∈{slip,jam}`）时启用。
- **U21 双环仲裁**：外环在 chunk 边界决策 enable/disable 与恢复目标；内环步级整形；价值在升则抑制整形，价值停滞且接触报卡滞则升级为退避重来。
- **U22 地形条件化价值**：`V_φ(o, m)`（或 `V_φ(o, ξ)`）——价值必须"知道"接触模式，避免"看着对齐其实卡死"时被欺骗。

- **T1'** 价值目标唯一：终态成功；`V_prog` 只是它的稠密化，不是新目标。

- **T3'** 断点在**接触最后一环** ⇒ 价值停滞 + 接触模式 + 有界整形，三者对准同一批任务。

## 4. 研究问题（本轮）

- **Q6（价值目标可信性）**：在官方榜仍是 teaser 的前提下，如何构造可审计、可校准、不依赖榜单的终态价值标签？官方 32 数据集 + 自采失败 rollout 够不够？
- **Q7（价值=进度）**：能否用排序/时序距离学出沿成功轨迹单调的 `V_prog`，替代 VLM 阶段标签，并让"停滞"同时覆盖抓握失败、对齐失败、卡滞？
- **Q8（价值引导选择）**：在策略自身分布内采样 K 个 chunk、用 Q/V 选一个，能否以合规方式兑现一部分"路由上界"？K 的延迟代价与收益如何权衡？
- **Q9（接触可辨识性）**：仅用 EE 位姿残差 + 夹爪标量 + 腕部图像流，`{free, contact, slip, jam, collision}` 的可分性有多高？跨物体/跨任务漂移多大？
- **Q10（双环耦合）**：价值门控 + 有界整形的组合，是否比单独任一者更稳？会不会互相打架（价值说继续、地形说卡住）？
- **Q11（合规与可信度）**：价值头/接触头是否仍算"单模型"？采样选择是否被视为"多策略"？如何用审计报告自证"动作良构、延迟稳定"？

## 5. 设计原则（在第 1 轮 P1–P6 上增补）

- **P7 价值目标可审计**：任何"成功"标签必须可追溯到官方定义或真机 rollout；**禁止用 teaser 榜单数字当监督**。
- **P8 支持约束优先于价值最大化**：test-time 选择只在策略自身采样分布内做（sampling, not optimization），避免 OOD reward hacking。
- **P9 适应有界且可回滚**：`‖δ‖ ≤ δ_max`，价值下降即撤销；不改主干权重。
- **P10 双环时间尺度分离**：外环在 chunk 边界（~0.5–1 s），内环步级；外环不逐帧抖动。
- **P11 失败信号优先于成功信号**：价值停滞检测宁可多报失败（可恢复），不可漏报失败（会一路执行到超时）。

**MVP = 第 1 轮 IP-06（代理评测）+ IP-03（工程）+ 本轮 IP-09（价值/进度头）+ IP-12（接触模式）+ IP-13（有界整形）+ 基线 VLA。**

- 价值不可校准 ⇒ 退回第 1 轮"只优化终态成功 + 抓握确认"；

- 接触模式不可辨识 ⇒ 只保留 `jam/slip` 两模式 + 极小幅整形；
- 整形导致价值下降 ⇒ 当 episode 关闭内环，回退开环；
- 全链路失效 ⇒ 纯基线（永远保留一份能跑通、可信度合规的最小提交）。

## 0. 本轮结论摘要

**一句话路线**：把「价值对齐」编译成**外环**——一个与评测器同定义、可校准、可审计的终态价值/进度 `V/Q`，负责"要不要、往哪"（选择、门控、停滞恢复）；把「地形适应」编译成**内环**——从"动作—响应残差"在线辨识接触模式，在冻结 VLA 接口内做**有界**动作整形，负责"怎么动"（柔顺、微搜索、增握、减速）。两环用时间尺度分离耦合：**价值不随地形漂移，地形不随价值撒谎**。

**与第 1 轮的三点增量**：

| 第 1 轮 | 第 2 轮 | 为什么 |
|---|---|---|
| 代理评测靠 VLM 打 reach/grasp/… 六因子阶段标签 | 用**单调进度价值 `V_prog`** 当稠密信号，阶段标签退为可选项 | 阶段标签是最脆的伪标签；排序/时序距离只需成功示范即可训练 |
| 抓握确认是独立分类器，靠"抬起随动"伪标签 | 抓握失败成为**价值停滞**的特例（U17） | 免去未见物品上的抓握伪标签漂移 |
| "适应"≈视觉域偏移（背景/干扰物） | "适应"=**接触地形**（滑移/卡滞/碰撞/柔顺/间隙） | 最难任务全是插入/旋转/细粒度；主导变量是接触动力学 |
| 技能路由 oracle +4.26（teaser 上界） | 改为**支持约束的 test-time 选择**（V-BoN），并明确 teaser 不可作效应量 | 单模型合规；避免对占位榜做 reward hacking |
| 工程层（chunk 缝合/延迟） | 保留，并新增**双环调度 + 审计**（价值/模式/整形能量可导出） | 对齐官方"延迟与动作规律性"的可信度口径 |

**合规红线（P5/P7/P8）**：单 checkpoint、单 API；价值/接触头是同服务内的辅助头；test-time 选择只从**本策略自身采样**中挑，不做 Q 梯度上升、不读评测侧私有信息、不用 teaser 数字当监督。

## 3. 创新点详述

### IP-09 · ValueAlign：终态价值 + 进度价值 + 校准（P0）

- **动机**：BC 优化"像不像示范"，评测器优化"最后成没成"；两者在最后一环错位。第 1 轮的六因子阶段标签靠 VLM 批量打标，噪声大且不可校准。需要一个**与评测器同定义、可校准、可审计**的价值信号。
- **与现有方案的差异**：多数提交只做"更大 VLA + 更多数据"；我们把"成功"显式化为可学习的价值函数，并用它做选择/门控/进度，而不是当辅助 loss 点缀。
- **技术可行性**：高。官方 32 数据集全部是成功示范 ⇒ 进度标签免费；终态负样本用"跨任务帧 + 基线失败 rollout"构造；失败 rollout 可在代理评测与真机时段采集。
- **训练配方**：
  1. **`V_prog`（稠密、无需失败标签）**：对每条成功轨迹采样 `(o_t, o_{t'})`，`t<t'`，最小化 `max(0, V(o_t) − V(o_{t'}) + m)`；同时回归归一化 time-to-go `τ_t = (T−t)/T`（Huber）。两项联合 ⇒ 单调 + 有界。
  2. **`V_term`（终态）**：末帧/末段为正，跨任务帧与失败 rollout 为负，BCE + focal；温度缩放校准。
  3. **`Q`（动作块，阶段二）**：IQL/TD，`Q(o, a_{t:t+H})` 以 `V_prog(o_{t+H})` 为 bootstrap；样本全部来自基线策略自身分布（支持约束）。
- **所需资源**：`V_prog/V_term` 用小头接冻结 VLA 特征（单卡数小时）；`Q` 需要失败 rollout（代理评测 + 真机 2–3 时段）。
- **落地步骤**：①统一下载/解码 + 键名对齐（沿用 IP-06）；②训练 `V_prog` 并出可靠性图与单调性曲线；③训练 `V_term` 并校准；④跨任务留出（24 训 / 8 测）；⑤`Q` 仅在失败样本 ≥ 每任务 50 条后启动；⑥全部产出可审计标签来源报告（U23）。
- **风险**：①**价值虚高/Goodhart**（最高）；②末帧正样本在未见物品上分布漂移；③`Q` 的外推误差。缓解：支持约束选择（U16）、保守门控（L8）、跨任务留出、校准温度。

### IP-10 · V-BoN：支持约束的候选选择（P1）

- **动机**：teaser 结构上每任务 oracle 比最好单模型高 +4.26；即便只做"两候选选一"也有空间。单模型赛道下，最合规的兑现方式是**同一策略的多次随机采样 + 价值重排**，而不是多模型集成。
- **与现有方案的差异**：常见是"固定温度采样一次"；我们把 test-time compute 花在**关键相位**（align/insert/grasp），用 `Q` 选最可能成功的 chunk。
- **技术可行性**：中。瓶颈是延迟：6B 主干单次 35–70 ms，K=4 串行会超预算。对策：①只在关键相位开（占步数比例小）；②K 个候选**批量前向**（次线性）；③默认 `K_max=2`，K=4 仅在离线/代理评测验证收益后上线；④超预算立即退回 K=1。
- **与合规**：候选全部来自**同一 checkpoint 的采样**，不是多个模型；但需向组委会确认"采样重排"不被视为多策略（Q11）。预备"关闭 V-BoN"的降级形态。
- **落地步骤**：①离线用 `Q` 对已采样的 K 个 chunk 重排，测"选择 vs 随机"的收益差；②代理评测测 K=1/2/4 的成功率—延迟曲线；③关键相位门控；④审计"选择是否增加 OOD 状态访问"（E626）。
- **风险**：①`Q` 误差被 max 放大 ⇒ 用**校准 + 保守 margin**（只在 `ΔQ > γ` 时覆盖基线，L8/L9）；②延迟；③选择偏差导致动作分布异常 ⇒ 保留基线采样温度，不做"拟人化"噪声。

### IP-11 · ValueStall：价值停滞检测与恢复（P0）

- **动机**：最后一环失败的共同形态是"不再有进展"：空夹爪继续走、卡住继续推、滑了继续搬。用 `V_prog` 的窗口停滞/回退统一检测，比"抓握二值分类"更一般、更少伪标签。
- **与现有方案的差异**：第 1 轮 IP-02 需要抓握真值；这里只需要"价值是否还在涨"。抓握失败、对齐失败、卡滞都表现为停滞，**一个检测器覆盖多类失败**。
- **判据（U17）**：`stall_t = 1` 当 `max_{s∈[t−w,t]} V_prog(o_s) − V_prog(o_t) < ε` 且 `V_prog(o_t) < ν`；或 `V_prog` 单步下降 `> ρ`。恢复动作按接触模式选：`slip→增握/重抓`、`jam→退避/微搜索`、`free→重接近`、`unknown→重抓`。
- **所需资源**：纯推理逻辑 + `V_prog`；无新数据。
- **落地步骤**：①离线在成功/失败轨迹上标定 `w, ε, ν, ρ`；②出 ROC 与阈值敏感性（E629）；③与第 1 轮抓握专用器做头对头（E622）；④最大恢复次数 ≤3，恢复后仍停滞则安全退出。
- **风险**：①`V_prog` 平台期（如长距离搬运）被误判为停滞 ⇒ 用"相位条件阈值"（搬运相位 `ε` 更小）+ 接触模式佐证；②恢复动作破坏场景 ⇒ 只在单物体/明确目标下启用。

### IP-12 · ContactTerrain：接触模式在线辨识（P0）

- **动机**：最难任务是插入/旋转/细粒度，主导变量是接触动力学；但观测没有力/触觉。接触会通过"动作—响应残差"显形。
- **与现有方案的差异**：现有策略把"执行动作"当开环；我们把"执行后的残差"当**传感器**，在线辨识接触模式。
- **定义（U18/U19）**：`r_t = [ẋ_EE^obs − ẋ_EE^cmd, ġrip^obs − ġrip^cmd, 光流残差]`；`m_t ∈ {free, contact, slip, jam, collision}`，用小型时序卷积/GRU 分类。
  - `free`：残差小、有运动；
  - `contact`：残差小、运动慢、物体随动；
  - `slip`：物体相对夹爪位移（腕部光流 + 夹爪）≠0；
  - `jam`：命令有位移、观测几乎不动（高残差、低速度）；
  - `collision`：残差突增（尖峰）。
- **技术可行性**：中–高。`obs_delta_indices` 已给 `[-2,0]` 的 EE 位姿 ⇒ 观测速度可直接算；命令速度由动作差分（EE 空间直接可比；joint 空间需 FK，依赖 Q5 的接口实测）。
- **所需资源**：官方数据回放 + 代理评测；小分类器单卡数小时。
- **落地步骤**：①从官方数据自动生成模式伪标签（残差规则 + 人工抽检 5%）；②训练分类器并出混淆矩阵；③跨物体/跨任务留出测可分性（E623）；④只把高置信模式送进整形（低置信当 `unknown`，不整形）。
- **风险**：①无力观测下 `contact` 与 `jam` 可能不可分 ⇒ 先只做 `slip/jam` 两模式；②伪标签噪声 ⇒ 双标注器一致性 + 真机抽检；③命令速度估计误差 ⇒ 用滤波后的残差，不用瞬时差分。

### IP-13 · TerrainShaping：有界地形自适应整形（P0）

- **动机**：识别出接触模式后，要有**不改主干权重**的"怎么动"的调节手段；官方接口只给关节/EE 位置，没有力矩，所以只能整形轨迹。
- **与现有方案的差异**：不是再训练一个"接触策略"，而是在冻结 VLA 输出上加**有界、可回滚**的整形，天然兼容单模型与低延迟。
- **整形算子（U20）**：
  - `jam`：沿插入轴降速 + 垂直轴小圆/锯齿搜索 + 柔顺化（`a' = a + K(x_obs − a)`，小 `K` 等效降低刚度）；
  - `slip`：夹爪继续闭合（未饱和时）+ 降加速度；饱和仍滑 ⇒ 交给 IP-11 重抓；
  - `collision`：沿接近轴退避 + 低速重接近；
  - `free` 且价值停滞：重接近 / 小范围探索。
  - 统一约束：`‖δ_t‖ ≤ δ_max`；`δ_t` 低通滤波（动作良构）；仅价值门控时启用；累计整形能量 ≤ `E_max`。
- **所需资源**：纯推理；无训练（`δ_max, K, E_max` 由数据/真机调）。
- **落地步骤**：①在官方数据回放上验证整形不破坏成功轨迹；②代理评测做 jam/slip 注入测试；③真机 A/B：Plug In Ethernet / Unlock / Open Pill Bottle；④审计整形能量与 jerk。
- **风险**：①误判导致搅乱轨迹 ⇒ 有界 + 低通 + 价值回滚；②柔顺化让位置跟踪变差 ⇒ `K` 上限 + 只在 `jam` 时开；③搜索动作改变物体位姿 ⇒ 只在目标明确、单物体时用。

### IP-14 · DualLoop：双环调度 + 审计（P1）

- **动机**：价值环（慢）与地形环（快）若同频会抖；官方明确看延迟与动作规律性。
- **机制（U21）**：外环在 chunk 边界算 `V_prog` 与模式摘要，决定 `continue / shape / recover / abort`；内环步级整形。冲突规则：价值在升 ⇒ 抑制激进整形；价值停滞且 `jam/slip` 连续 `n` 步 ⇒ 升级退避重来。滞回：`ε_abort > ε_resume`，防抖。
- **审计产物**：`V_prog` 轨迹、模式序列、整形能量、恢复事件、延迟 p50/p99、jerk 分布、chunk 边界失配计数；对齐官方"可信度"口径。
- **风险**：双环互相打架 ⇒ 滞回 + 时间尺度分离（L12/L13）；审计过度平滑压低成功率 ⇒ 整形只作用残差、限幅阈值由数据分布定。

## 4. 符号与定义（U13–U22，续第 1 轮）

| 符号 | 含义 |
|---|---|
| `V_term(o,ℓ)` | 对齐终态价值 `≈ P(S=1)` |
| `V_prog(o,ℓ)` | 进度价值，成功末帧 1、起始 0 |
| `Q_ψ(o, a_{t:t+H})` | 动作块价值（执行后接基线的期望成功） |
| `K` | 候选 chunk 数（`K ≤ K_max`） |
| `stall_t` | 价值停滞指示 |
| `r_t` | 接触残差（EE/夹爪/光流） |
| `m_t` | 接触模式 ∈ {free, contact, slip, jam, collision, unknown} |
| `δ_t` | 有界整形量 |
| `E_max` | 每 episode 累计整形能量上限 |
| `ε, ν, ρ, γ` | 停滞阈值 / 近成功阈值 / 回退阈值 / 选择 margin |

**定义 U13（对齐终态价值）** `V_term(o,ℓ) = P(S=1 | o,ℓ)`，`S` 为评测器终态成功；训练标签只来自官方成功定义与真机 rollout（U23）。
**定义 U14（进度价值）** `V_prog(o_t,ℓ) ≈ 1 − τ_t/T`，并满足沿成功轨迹的 `m`-单调性：`V_prog(o_{t'}) ≥ V_prog(o_t) + m`（`t<t'`，按采样间隔归一）。
**定义 U15（动作块价值）** `Q_ψ(o, a_{t:t+H}) ≈ E[V_prog(o_{t+H}) | a_{t:t+H}, π_base]`；离线 IQL/TD，样本来自 `π_base` 自身分布。
**定义 U16（支持约束选择）** `a* = argmax_{k=1..K} Q_ψ(o, a^(k))`，`a^(k) ~ π_base(·|o)`，且仅当 `Q(a*) − Q(a_base) > γ` 才覆盖；**禁止**对 `Q` 做梯度上升。
**定义 U17（价值停滞）** `stall_t = 1[ (max_{s∈[t−w,t]} V_prog(o_s) − V_prog(o_t) < ε) ∧ (V_prog(o_t) < ν) ] ∨ 1[ V_prog(o_t) − V_prog(o_{t−1}) < −ρ ]`。
**定义 U18（接触残差）** `r_t = [ẋ_EE^obs − ẋ_EE^cmd, ġrip^obs − ġrip^cmd, F_flow]`，其中 `F_flow` 为腕部光流相对夹爪的残差。
**定义 U19（接触模式）** `m_t = argmax_m P(m | r_{t−k:t}, o_t^{wrist})`；低置信归 `unknown`。
**定义 U20（有界整形）** `a'_t = a_t + δ_t`，`δ_t = g(a_t, m_t, V_prog)`，`‖δ_t‖ ≤ δ_max`，`δ_t` 低通，且 `δ_t=0` 除非价值门控开启。
**定义 U21（双环仲裁）** 外环周期 `T_out` ≥ 5×内环调节时间；`abort` 阈值严格大于 `resume` 阈值（滞回）。
**定义 U22（地形条件化价值）** `V_term(o, m)`：价值输入包含接触模式，避免"看着对齐其实卡死"时被视觉欺骗。
**定义 U23（可审计标签来源）** 每个训练标签带来源 `∈ {official_success, real_rollout, counterfactual}`；禁止 `teaser` 来源。
**定义 U24（信任域回滚）** 若整形后 `V_prog` 相对整形前基线下降 `> η`，本 episode 关闭内环并回退开环。

## 5. 算法骨架

```python
# ===== UniBot-VATA：单 checkpoint、单 API、双环 =====
class UniBotVATAPolicy:
    def __init__(self, ckpt, K_max=2, tau_ms=105):
        self.model   = load_single_checkpoint(ckpt)   # 主干 + 价值头 + 模式头（同一 ckpt）
        self.v       = ValueHead()                    # IP-09: V_term / V_prog
        self.q       = QHead()                        # IP-09: 动作块价值
        self.ct      = ContactModeHead()              # IP-12
        self.shape   = TerrainShaper()                # IP-13
        self.stitch  = Stitcher()                     # IP-03
        self.audit   = AuditLog()                     # IP-14
        self.sessions = {}                            # 每端口状态隔离

    def get_action(self, obs, port):
        s = self.sessions[port]
        v_now = self.v.progress(obs)                  # U14
        m_now = self.ct.predict(obs, s.residual_hist) # U19
        s.v_hist.append(v_now); s.m_hist.append(m_now)

        # ---------- 外环：价值门控（chunk 边界） ----------
        if s.at_chunk_boundary():
            if stall(s.v_hist, eps=s.eps, nu=0.2, rho=0.15):   # U17
                s.mode = "recover"
            elif m_now in ("jam", "slip", "collision"):
                s.mode = "shape"
            else:
                s.mode = "continue"

        # ---------- 候选生成：V-BoN（可选，IP-10） ----------
        if s.mode != "recover" and self.vbon_enabled(s, m_now):
            cands = [self.model.sample_chunk(obs) for _ in range(K_max)]
            a = max(cands, key=lambda c: self.q(obs, c))       # U16
            if self.q(obs, a) - self.q(obs, cands[0]) <= s.gamma:
                a = cands[0]                                    # 保守：不显著更优就不覆盖
        else:
            a = self.model.sample_chunk(obs)

        # ---------- 内环：有界地形整形（IP-13） ----------
        if s.mode == "shape":
            delta = self.shape.delta(a, m_now, v_now, s)       # U20
            a = a + clip_norm(delta, s.delta_max)
            s.energy += norm(delta)

        # ---------- 恢复（IP-11） ----------
        if s.mode == "recover" and s.n_retry < 3:
            a = self.recover(obs, m_now)                        # 重抓/重对齐/退避
            s.n_retry += 1
        elif s.n_retry >= 3:
            a = self.safe_hold(obs)                             # 安全退出，避免硬失败

        # ---------- 工程层：缝合 + 延迟 + 审计 ----------
        a = self.stitch.stitch(a, s.last_action)                # IP-03
        a = self.audit.clamp_and_log(a, obs, v_now, m_now, s)  # IP-14
        s.last_action = a[-1]
        return self.pack(a)
```

```python
# ===== IP-09：进度价值（无需失败标签） =====
def train_progress(trajs, f_theta):
    for tau in trajs:                       # 每条成功轨迹
        for (t, t2) in sample_pairs(tau):
            # 单调排序：后帧价值不低于前帧 + margin
            loss_rank = relu(f_theta(o[t]) - f_theta(o[t2]) + m)
            # 归一化 time-to-go 回归
            loss_reg  = huber(f_theta(o[t]), 1 - t / T)
            loss += loss_rank + lam * loss_reg
    return loss
```

# ===== IP-13：有界整形 =====
class TerrainShaper:
    def delta(self, a, m, v, s):
        if m == "jam":
            d =  s.k_soft * (s.x_obs - a)          # 柔顺化
            d += s.amp * search_pattern(s.t, axis=s.insert_axis)  # 微搜索
            d -= s.slow * s.approach_dir           # 降速
        elif m == "slip":
            d =  s.grip_dir * s.grip_step          # 增握
            d -= s.acc_slow * s.vel_dir            # 降加速度
        elif m == "collision":
            d = -s.backoff * s.approach_dir        # 退避
        else:
            d = 0.0
        return lowpass(d, s.alpha)                 # 动作良构

## 6. 推导（L8–L13）

**引理 L8（校准决定选择的下界，K 只放大上行）** 设 `Q` 在候选集上 `ε`-校准：`|Q(a) − Q*(a)| ≤ ε`。令 `a* = argmax_k Q(a_k)`，`a° = argmax_k Q*(a_k)`，则
`Q*(a*) ≥ Q(a*) − ε ≥ Q(a°) − ε ≥ Q*(a°) − 2ε`。
即**选择遗憾 ≤ 2ε，与 K 无关**；增大 K 只可能抬高 `Q*(a°)`，不会放大下行。⇒ 安全地增加候选的前提是**校准**，不是更多采样。∎

**引理 L9（支持约束排除 OOD reward hacking）** 若候选 `a^(k) ~ π_base(·|o)` 且 `Q` 在 `π_base` 的状态-动作分布上训练，则选择是对**有限个同分布样本**取 max，不产生对 `Q` 的梯度上升，因此不会访问 `Q` 外推的 OOD 区域；唯一误差是 in-distribution 的 `Q` 误差，已由 L8 界定。⇒ "采样+重排"比"对价值做优化"安全。∎

**引理 L10（单调进度 ⇒ 停滞检测可分）** 若 `V_prog` 在成功轨迹上满足 `m`-单调，且失败过程导致长度 `>w` 的平台/回退，则取 `ε<m` 的窗口检测器在训练分布上把两类分开；其假阳性率由排序损失的 margin 违反率上界（违反 `m` 的对数 / 总对数）。⇒ 检测器的可靠性可直接由 E620 的成对准确率读出。∎

**引理 L11（接触可辨识 ⇒ 整形损失有界）** 若接触模式诱导的残差分布两两总变差距离 `≥ d`，则二类 Bayes 错误 `≤ (1−d)/2`，多类由并集界 `≤ (|M|−1)(1−d)/2`。若错误模式下的整形代价 `≤ Δ_max`，则期望损失 `≤ e·Δ_max`；又 `‖δ‖≤δ_max` ⇒ 轨迹相对无整形偏差 `≤ H·δ_max·L`（`L` 为系统 Lipschitz 常数）。⇒ 整形既不会无界发散，错误代价也可预算。∎

**引理 L12（双环稳定的时间尺度条件）** 若内环在 `T_in` 内收敛（收缩率 `κ<1`），外环仅在 `T_out ≥ 5·T_in/(1−κ)` 时改变设定点，则由奇异摄动/两时间尺度论证，复合系统保持内环的稳定性。⇒ 外环只在 chunk 边界动作，内环步级动作。∎

**引理 L13（滞回消除仲裁抖振）** 若 `abort` 阈值 `ε_abort > resume` 阈值 `ε_resume`，则"停滞→退避→恢复"的状态机不存在长度为 1 的极限环；切换次数上界由价值轨迹的总变差 / (`ε_abort−ε_resume`) 界定。⇒ 双环不会在同一相位反复横跳。∎

## 12. 本轮最值得押注的创新点（一句话）

**押注 IP-09 + IP-11 + IP-12/13 这条"价值—停滞—接触"链：它把第 1 轮最脆的两个伪标签（VLM 阶段标签、抓握真值）替换成一个可校准的进度价值，再用"动作—响应残差"把最后一环的接触失败变成可在线观测、可有限度干预的信号——正好打在 teaser 与 RoboDojo 共同暴露的同一个断点上，且不需要新传感器、不改主干、不破坏单模型合规。**

**本轮最大风险（一句话）**：我们押注的"对齐价值"可能只是"看起来像成功"——`V` 若在最关键的最后一环系统性虚高，best-of-N 与恢复逻辑会一起放大"像成功的失败"，而真机失败分布恰是我们最少、最难验证的数据，于是最需要它的地方正是它最不可信的地方。
