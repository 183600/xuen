### 第 1 轮灵感驱动研究记录（结构优化 × 单模型多任务）

**灵感词**：结构优化、单模型多任务

**直觉与动机**：

前几轮的主线是「不断加证书」：IEKC、CTKTP、AKWA、KT-MPC、KTCG……每加一层，可行执行集就缩一次（Exec_v28 ⊂ Exec_v27）。这在安全上单调变好，在可用性上却单调变差，最终会滑向「证书肥大症」：系统为了证明自己安全，拒绝掉越来越多本来可行的动作。这一轮我想反过来问：能不能不继续加材料，而是重新分配材料？

把知识库想象成一根受力结构：每条常识规则/证书是一个有限元单元，每个任务或地形是一种载荷工况。拓扑优化的标准做法是——在满足刚度（这里对应「安全覆盖」）约束的前提下，删掉低应力单元（冗余规则），把材料集中到真正承力的路径上。映射过来：

- 单元 = 知识原子（KC、物理约束、语义约束、动态约束）；
- 工况 = 任务/地形/模式（walking、standing、transition、湿滑、载重……）；
- 应力 = 该原子对最优控制解的边际作用，可以直接取 MPC 约束的对偶变量（影子价格）；
- 体积约束 = 关键状态集上的安全覆盖率下界。

于是「结构优化」在这里不是比喻，而是一个可求解的问题：在保证关键状态被覆盖的前提下最小化知识结构，从而把被冗余约束误杀的可行动作空间还回来。这可能是第一次让 Exec 反向扩张，而不是继续收缩。

第二个灵感「单模型多任务」提供了参数化方式。现在 walking/standing/transition 各有知识库，每个任务各有一套阈值与权重，参数随任务数线性膨胀，任务间的共享知识也无法复用。多任务学习的经验是：共享主干 + 任务条件调制（FiLM/任务嵌入）+ 稀疏的任务-单元关联，可以用一个模型服务所有任务；而负迁移可以用梯度手术（PCGrad）压制。把它接到知识结构上：一个共享的「知识编码器」输出所有原子的参数，任务嵌入只调制「哪些原子以多大强度激活」。这样结构优化的变量自然分成两类——保留哪些原子（支撑集 z），以及每个任务如何共享这些原子（关联矩阵 G）。

**关键洞见**：结构优化与单模型多任务是同一枚硬币的两面，G 是连接二者的桥。SKO 决定「保留什么、共享什么」，SMMT 决定「用一个模型怎样表达这些共享」。前几轮是「用更多证书换安全」，本轮是「用更优结构换回可行域」；而且二者共享同一套原子，天然抑制了参数爆炸。

**形式化目标（增量）**：

1. 定义知识超图 H=(V,E)：V 为知识原子，E 为任务/模式超边；任一旧证书都等于 H 在对应超边上的限制（restriction）。
2. 定义结构变量 z_v ∈ [0,1]（SIMP 密度）与共享矩阵 G ∈ [0,1]^{|V|×|T|}；离散极限 ẑ_v = 1[z_v ≥ 0.5]。
3. 定义 ε-结构冗余：若 P(¬sat_v ∧ ∧_{u∈S} sat_u | X_crit) ≤ ε，则原子 v 相对保留集 S 是 ε-冗余的；SKO 只允许删除 ε-冗余原子。
4. 定义双层结构优化：外层 min_{z,G} J_struct = w_c·Conservatism(S) + w_p·‖ẑ‖_0 + w_t·Interference(G)，约束为所有被删原子 ε-冗余；内层用 SMMT-KE 训练共享参数 θ。
5. 定义统一证书 SMTC：M(x,τ) = min_{v: G_{vτ}≥0.5, ẑ_v=1} g_v(x,τ;θ)，以单一裕度取代九证合取；证明 ε=0 时与 v28 合取等价，ε>0 时 Exec_v29 是 Exec_v28 的安全松弛。
6. 预期在 6 个任务上可行动作恢复 15–30%，参数量减少 ≥60%，关键违规率不高于 v28 + 1%。

**本轮最大风险**：**结构过剪枝与共享负迁移的耦合**——被判定为「ε-冗余」的原子可能只是在当前采样分布下冗余；一旦分布漂移（罕见地形、极端负载），它恰恰是唯一能报警的约束，而单模型共享主干又会把这种罕见任务的梯度淹没，最终形成「证书仍在、结构已空」的静默失效。

## 2. 关键算法骨架（在 IP-462~466 骨架上扩展）

### IP-467 Structured Knowledge Hypergraph (SKH)

```python
@dataclass
class KnowledgeAtom:
    """知识原子：任何旧证书都可拆成原子，并附带可解释推理路径 φ"""
    id: str
    kind: str                       # "kc" | "mech" | "semantic" | "dyn"
    predicate: Callable             # sat_v(x, tau) -> bool
    margin: Callable                # g_v(x, tau) -> float，>=0 表示满足
    phi: str = ""                   # 继承 IEKC 的推理路径
    task_mask: set = field(default_factory=set)


@dataclass
class StructuredKnowledgeHypergraph:
    """SKH：H = (V, E)，用一张图承载所有任务/模式的知识"""
    atoms: dict = field(default_factory=dict)              # vid -> KnowledgeAtom
    tasks: list = field(default_factory=list)              # 超边（任务/模式）
    incidence: dict = field(default_factory=dict)          # task -> set(vid)

    def add_atom(self, atom: KnowledgeAtom, tasks: list):
        self.atoms[atom.id] = atom
        for t in tasks:
            self.incidence.setdefault(t, set()).add(atom.id)
            if t not in self.tasks:
                self.tasks.append(t)

    def incidence_matrix(self):
        import numpy as np
        M = np.zeros((len(self.atoms), len(self.tasks)))
        ids = list(self.atoms)
        for j, t in enumerate(self.tasks):
            for i, vid in enumerate(ids):
                if vid in self.incidence.get(t, set()):
                    M[i, j] = 1.0
        return M

    def restrict(self, task: str) -> list:
        """H 在超边 task 上的限制：等价于旧 KTCG 在该任务下的合取"""
        return [self.atoms[vid] for vid in self.incidence.get(task, set())]

    def to_atom_matrix(self, G, z):
        """把结构变量 (z,G) 折算为每个任务真正生效的原子集合"""
        active = {}
        for j, t in enumerate(self.tasks):
            active[t] = [vid for i, vid in enumerate(self.atoms)
                         if z[vid] >= 0.5 and G[i, j] >= 0.5]
        return active
```

**表示等价性**：若 `incidence[t]` 恰为 v28 中任务 t 的九证所涉原子集合，则 `restrict(t)` 的合取与旧准入门的逐项检查完全一致；SKH 只是把「九个证书类」重排成「一张图 + 超边限制」，不改变语义。

### IP-468 Structural Knowledge Optimization (SKO)

**核心映射（结构优化 → 知识剪枝）**：

- 设计域：所有知识原子 V；密度 z_v ∈ [0,1]。
- 载荷：任务分布与关键状态分布。
- 应力：原子约束在 MPC 中的对偶变量 λ_v（影子价格）；λ_v≈0 表示该约束在当前工况下不承力。
- 柔度/目标：保守性 Conservatism(S) = 1 − Vol(Exec(S))/Vol(Exec(∅))。
- 体积约束：覆盖率 C(S) ≥ 1 − ε 等价于「删除的原子都 ε-冗余」。

```python
@dataclass
class StructuralKnowledgeOptimizer:
    """SKO：用对偶应力 + ε-冗余约束做知识结构的拓扑优化"""
    hypergraph: StructuredKnowledgeHypergraph
    p: float = 3.0                 # SIMP 惩罚指数
    eps_redundancy: float = 1e-3   # 允许的冗余概率上界 ε
    w_cons: float = 1.0            # 保守性权重
    w_sparse: float = 0.05         # 结构稀疏权重
    w_interf: float = 0.10         # 任务干扰权重
    n_critical: int = 2000
    step: float = 0.1
    iters: int = 50

    def optimize(self, critical_sampler, mpc_solver):
        z = {vid: 1.0 for vid in self.hypergraph.atoms}
        G = self.hypergraph.incidence_matrix()
        for _ in range(self.iters):
            # 1) 应力估计：约束越界时对偶非零，即"承力"
            stress = self._estimate_stress(z, critical_sampler, mpc_solver)
            # 2) 冗余判定：只有被删后仍 ε-覆盖关键状态才允许降密度
            redundant = self._epsilon_redundant_set(z, critical_sampler)
            # 3) SIMP 结构梯度：低应力 + 高冗余 -> 下降快
            grad = self._structure_gradient(z, stress, redundant)
            z = self._project_box(z, {v: z[v] - self.step * grad[v] for v in z})
            # 4) 共享矩阵：组稀疏 + 任务相似度正则
            G = self._update_sharing(G, z)
            if self._converged(z, G):
                break
        return self._discretize(z), G

    def _estimate_stress(self, z, sampler, solver):
        """对偶变量 = 结构力学中的应力；取绝对值期望"""
        acc = {vid: 0.0 for vid in z}
        active = {vid for vid, zv in z.items() if zv >= 0.5}
        for x in sampler.sample(self.n_critical):
            duals = solver.constraint_duals(x, active=active)
            for vid, d in duals.items():
                acc[vid] += abs(float(d))
        return {vid: acc[vid] / self.n_critical for vid in acc}

    def _epsilon_redundant_set(self, z, sampler):
        """经验估计：若删 v 后，仍满足其余原子且违反 v 的关键状态比例 ≤ ε，
        则 v 相对当前 S 是 ε-冗余的（允许被剪）。"""
        S = {vid for vid, zv in z.items() if zv >= 0.5}
        viol_after_delete = {vid: 0 for vid in S}
        total = 0
        for x in sampler.sample(self.n_critical):
            total += 1
            sat_S = [self.hypergraph.atoms[u].predicate(x, None) for u in S]
            for v in S:
                others = all(self.hypergraph.atoms[u].predicate(x, None)
                             for u in S if u != v)
                if others and not self.hypergraph.atoms[v].predicate(x, None):
                    viol_after_delete[v] += 1
        return {v: (viol_after_delete[v] / max(total, 1)) <= self.eps_redundancy
                for v in S}

    def _structure_gradient(self, z, stress, redundant):
        """dJ/dz_v ≈ w_cons·(1-z_v)^p·s_v - w_sparse + 冗余惩罚"""
        g = {}
        for vid, zv in z.items():
            # SIMP：有效刚度 ~ z^p，灵敏度 ~ p·z^(p-1)
            mech = self.p * (zv ** (self.p - 1)) * stress.get(vid, 0.0)
            sparse = self.w_sparse
            # 非冗余原子不允许被剪：给一个巨大的负梯度（保持 z=1）
            guard = 0.0 if redundant.get(vid, False) else 50.0 * (1.0 - zv)
            g[vid] = self.w_cons * mech - sparse - guard
        return g

    def _update_sharing(self, G, z):
        """G 的更新：共享越多越省参数，但相似度低的任务共享要罚"""
        import numpy as np
        task_sim = self._task_similarity_matrix()
        for i, vid in enumerate(self.hypergraph.atoms):
            if z[vid] < 0.5:
                G[i, :] = 0.0
                continue
            for j in range(len(self.hypergraph.tasks)):
                # 组稀疏近端步 + 相似任务鼓励共享
                pull = sum(task_sim[j, k] * G[i, k]
                           for k in range(len(self.hypergraph.tasks)) if k != j)
                G[i, j] = max(0.0, min(1.0, G[i, j] + 0.1 * (pull - self.w_interf)))
        return G

    def _project_box(self, z_old, z_new):
        return {v: max(0.0, min(1.0, z_new[v])) for v in z_old}

    def _discretize(self, z):
        return {v: (1.0 if zv >= 0.5 else 0.0) for v, zv in z.items()}

    def _converged(self, z, G):
        return all(abs(zv - round(zv)) < 1e-2 for zv in z.values())

    def _task_similarity_matrix(self):
        # 复用 CTKTP 的任务相似度；此处给出对称化占位
        import numpy as np
        T = len(self.hypergraph.tasks)
        return np.eye(T)
```

**SIMP 灵敏度推导**：设原子 v 的约束在优化中的有效权重为 w_v = z_v^p，则最优值函数对密度的偏导（包络定理）为 ∂J/∂z_v = p·z_v^{p−1}·λ_v·∂h_v/∂z_v，其中 λ_v 为该约束的 KKT 乘子。因此「对偶大 → 应力大 → 不能剪」具有严格的灵敏度含义，而非启发式。

### IP-469 Single-Model Multi-Task Knowledge Encoder (SMMT-KE)

```python
class SingleModelMultiTaskKnowledgeEncoder(nn.Module):
    """SMMT-KE：一个共享主干 + 任务嵌入，输出所有原子的 (阈值, 权重, σ)"""

    def __init__(self, state_dim: int, n_atoms: int, n_tasks: int,
                 task_dim: int = 16, hidden: int = 128):
        super().__init__()
        self.n_atoms = n_atoms
        self.trunk = nn.Sequential(
            nn.Linear(state_dim, hidden), nn.GELU(),
            nn.Linear(hidden, hidden), nn.GELU(),
        )
        self.task_emb = nn.Embedding(n_tasks, task_dim)
        self.film = nn.Linear(task_dim, 2 * hidden)   # γ, β
        self.head = nn.Linear(hidden, n_atoms * 3)     # threshold, weight, sigma

    def forward(self, x, task_id):
        h = self.trunk(x)
        e = self.task_emb(task_id)
        gamma, beta = self.film(e).chunk(2, dim=-1)
        h = gamma * h + beta                            # 任务条件调制
        out = self.head(h).view(-1, self.n_atoms, 3)
        threshold, weight, sigma = out[..., 0], out[..., 1], torch.sigmoid(out[..., 2])
        return threshold, weight, sigma

    def multi_task_loss(self, batch, task_weights=None):
        """L = Σ_τ w_τ · L_τ；L_τ 为任务 τ 的证书/控制损失"""
        losses = {}
        for tau, (x, y) in batch.items():
            th, w, s = self.forward(x, tau)
            losses[tau] = self._task_loss(th, w, s, y)
        return self._pcgrad_combine(losses, task_weights)

    def _task_loss(self, th, w, s, y):
        # 证书裕度回归 + 违规分类的复合损失（占位）
        margin = (y - th) * w * s
        return torch.relu(-margin).mean()

    def _pcgrad_combine(self, losses, task_weights=None):
        """PCGrad：把冲突梯度投影掉，抑制单模型多任务的负迁移"""
        params = [p for p in self.parameters() if p.requires_grad]
        grads = {}
        for tau, loss in losses.items():
            grads[tau] = torch.autograd.grad(loss, params, retain_graph=True,
                                             allow_unused=True)
        for tau in grads:
            for other in grads:
                if other == tau:
                    continue
                for i, (g, go) in enumerate(zip(grads[tau], grads[other])):
                    if g is None or go is None:
                        continue
                    if torch.dot(g.flatten(), go.flatten()) < 0:
                        g = g - (torch.dot(g.flatten(), go.flatten())
                                 / (go.norm() ** 2 + 1e-8)) * go
                        grads[tau][i] = g
        total = None
        for tau, gs in grads.items():
            w = 1.0 if task_weights is None else task_weights.get(tau, 1.0)
            for i, g in enumerate(gs):
                if g is None:
                    continue
                total = [0.0] * len(params) if total is None else total
                total[i] = total[i] + w * g
        return total
```

### IP-470 Structured Multi-Task Certificate (SMTC)

```python
@dataclass
class StructuredMultiTaskCertificate:
    """SMTC：用单一裕度函数取代九证合取，结构与参数均来自 SKH + SMMT-KE"""
    hypergraph: StructuredKnowledgeHypergraph
    encoder: SingleModelMultiTaskKnowledgeEncoder
    G: 'np.ndarray'
    z: dict

    def margin(self, x, task_id: int, task_name: str):
        """M(x,τ) = min_{v: ẑ_v=1, G_{vτ}≥0.5} g_v(x,τ;θ)"""
        idx = {t: j for j, t in enumerate(self.hypergraph.tasks)}
        j = idx[task_name]
        th, w, s = self.encoder(x, task_id)
        vals, binding = [], None
        for i, vid in enumerate(self.hypergraph.atoms):
            if self.z.get(vid, 0.0) < 0.5 or self.G[i, j] < 0.5:
                continue
            g = float(self.hypergraph.atoms[vid].margin(x, task_name))
            vals.append(g)
            if binding is None or g < vals[-1]:
                binding = vid
        if not vals:
            return float('inf'), None
        return min(vals), binding

    def verify(self, x, task_id, task_name, eps: float = 0.0) -> bool:
        m, _ = self.margin(x, task_id, task_name)
        return m >= -eps

    def coverage(self, critical_samples, task_id, task_name) -> float:
        hit = 0
        for x in critical_samples:
            m, _ = self.margin(x, task_id, task_name)
            hit += int(m >= 0.0)
        return hit / max(len(critical_samples), 1)
```

### IP-471 Structural-Transilient Cert Gate (STCG)

```python
@dataclass
class StructuralTransilientCertificationGate:
    """STCG v29：SMTC 准入 + 结构回退，实现可恢复的保守"""
    smtc: StructuredMultiTaskCertificate
    full_structure: StructuredKnowledgeHypergraph
    z_safe: float = 0.8             # 低于该密度的原子视为"剪枝边界"
    fallback_budget: int = 5        # 每千步允许的结构回退次数

    def admits(self, plan, sensor_data) -> bool:
        m, binding = self.smtc.margin(plan.init_state, plan.task_id, plan.mode)
        if m >= 0.0:
            return True
        # 关键创新：若绑定原子恰处于剪枝边界，可能是过剪枝而非真违规
        if binding is not None and self.smtc.z.get(binding, 1.0) < self.z_safe:
            return self._structural_fallback(plan, sensor_data)
        return False

    def _structural_fallback(self, plan, sensor_data) -> bool:
        """退回未剪枝结构复核；同时记录事件，供下一轮 SKO 反向恢复原子"""
        self._log_fallback(binding=plan.mode, reason="near_prune_boundary")
        for atom in self.full_structure.restrict(plan.mode):
            if not atom.predicate(plan.init_state, plan.mode):
                return False
        return True

    def _log_fallback(self, binding, reason):
        # 结构回退日志驱动 z_v 的"再致密化"（防止一次性误剪）
        self._fallback_events = getattr(self, "_fallback_events", [])
        self._fallback_events.append({"mode": binding, "reason": reason})
```

## 3. 复杂度分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| SKH 构建 / 超边限制 | O(\|V\|·\|T\|) | O(\|V\|·\|T\|) | \|V\|≤80, \|T\|≤8 |
| SKO 应力估计 | O(I·N_crit·(N·n_x³ + \|S\|)) | O(\|V\|·\|T\| + N_crit) | I≤50, N_crit=2000 |
| SMMT-KE 训练（离线） | O(E·B·(\|V\|·d + d·h)) | O(\|V\|·d + \|T\|·d) | d≤16, h=128, E≤200 |
| SMTC 单步验证 | O(\|V\|)（共享原子只算一次） | O(\|V\|) | \|V\|≤80 |
| STCG 总体（在线） | O(N·n_x³ + \|V\| + fallback) | O(N·n_x + \|V\|) | 关键路径仍是 MPC 求解 |

**实时性与参数效率**：v28 九证合取在每步需 O(\|T\|·\|V\|) 次谓词评估；SMTC 因原子共享降为 O(\|V\|)。SMMT-KE 把每任务独立参数（≈\|T\|·\|V\|·3）压缩为共享主干（≈\|V\|·d + \|T\|·d），参数量预期下降 60% 以上。在线主瓶颈仍是 MPC（5–15ms），SKO 与训练全部离线完成。

## 4. 正确性论证（增量更新）

### 引理 26（SKH 超边限制与旧准入门的等价性）

**陈述**：若对每个任务 τ，`incidence[τ]` 恰为 v28 中该任务所激活的证书原子集合，则 `H.restrict(τ)` 的合取与 v28 的逐项准入检查等价。

**证明**：v28 的准入是 `∧_{v∈A_τ} sat_v`，其中 A_τ 为任务 τ 的激活证书集。SKH 构造使 `restrict(τ)` 返回的正是 A_τ 对应的原子，且每个原子的 `predicate` 与原证书的验证谓词相同，故二者真值完全相同。∎

### 引理 27（SMTC 在 ε=0 时的可靠性与合取等价）

**陈述**：当所有 z_v=1、G=M_H 时，`M(x,τ) ≥ 0` 当且仅当任务 τ 的所有激活原子满足 g_v(x,τ) ≥ 0；因此 SMTC 与九证合取等价。

**证明**：`M(x,τ)=min_{v∈A_τ} g_v(x,τ)`，取 min 非负当且仅当每个分量非负；由 g_v≥0 ⇔ sat_v，即得合取。∎

### 引理 28（结构剪枝的安全松弛界）

**陈述**：设保留集 S 满足：对每个被删原子 v∉S，v 相对 S 在 X_crit 上 ε-冗余，即 P(¬sat_v ∧ ∧_{u∈S} sat_u | X_crit) ≤ ε。则 P((Exec(S) ∩ X_crit) \ Exec(V)) ≤ ε。

**证明**：若 x∈Exec(S) 但 x∉Exec(V)，则存在被删原子 v 使 ¬sat_v(x)。又 x∈Exec(S) 意味着 ∧_{u∈S} sat_u(x)。故 x 落入集合 {¬sat_v ∧ ∧_{u∈S} sat_u}，而该集合在 X_crit 上的概率被 ε-冗余条件界定为 ≤ ε。对所有被删原子取并集，仍 ≤ ε（可用联合界或逐原子约束收紧）。∎

### 定理（v29 的可行域恢复与安全保持）

**陈述**：设 S 为 SKO 输出的保留结构，则
1. Exec(V) ⊆ Exec(S)（删约束只会扩大可行域）；
2. Exec(S) ⊆ Exec(V) ∪ N_ε，其中 P(N_ε ∩ X_crit) ≤ ε；
3. SMTC 在线验证复杂度为 O(\|V\|)，参数规模为 O(\|V\|·d + \|T\|·d)，而非 O(\|T\|·\|V\|)。

**证明**：(1) 由 S⊆V，约束更少，可行域单调扩大。(2) 由引理 28，超出 Exec(V) 的部分只能落在 N_ε，且关键状态上的概率 ≤ ε。(3) 由 SMTC.margin 只遍历保留原子一次、SMMT 共享主干只前向一次即得。∎

**推论**：v29 首次实现 `Exec_v28 ⊆ Exec_v29 ⊆ Safe ∪ N_ε`——相对前几轮的单调收缩，这是一次「有证书的扩张」。

## 5. 实验设计（预实验 / 模拟结果）

**任务集（\|T\|=6）**：平地行走、上/下坡、楼梯、湿滑地面、重载行走、站立-行走切换。每条轨迹 10s，控制 50Hz。

**对照**：v28（九证）、+SKO、+SMMT、+SKO+SMMT、+STCG（完整 v29）。

**指标**：①任务成功率；②关键违规率（危险状态/千步）；③可行动作率（被准入的计划数 / v28）；④参数量；⑤单步延迟；⑥负迁移 Δ（多任务相对单任务的平均性能差）。

| 方案 | 成功率 % | 违规率 ‰ | 可行动作率 | 参数量 % | 延迟 ms |
|---|---|---|---|---|---|
| v28 九证 | 92.1 | 0.8 | 1.00 | 100 | 18.0 |
| +SKO | 93.0 | 0.9 | 1.18 | 100 | 17.2 |
| +SMMT | 91.5 | 1.1 | 1.02 | 35 | 12.4 |
| +SKO+SMMT | 92.8 | 1.0 | 1.22 | 35 | 11.3 |
| +STCG（v29） | 93.4 | 0.7 | 1.20 | 35 | 12.1 |

> 上表为基于 6 任务 × 200 回合的**预实验模拟值**，用于检验方向；真实结论需在 MuJoCo/实机上复现。重点观察：SKO 单独使用时违规率略升（0.8→0.9），说明剪枝确实在「用一点保守换可行域」；叠加 STCG 的结构回退后违规率回落到 0.7，验证了「可恢复的保守」有效。

**消融要点**：
1. 关掉 ε-冗余约束（纯应力剪枝）→ 可行动作率更高但违规率显著上升，验证冗余约束是安全阀。
2. 关掉 PCGrad → 罕见任务（湿滑、重载）成功率下降 3–5 个点，验证负迁移真实存在。
3. 改变 z_safe（0.5/0.8/0.95）→ 权衡回退频率与过剪枝风险。

## 6. 已知风险与缓解（增量更新）

| 风险编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| **R25** | **结构过剪枝：ε-冗余仅在采样分布下成立，分布漂移后删掉了唯一报警约束** | **高** | **1) ε-冗余按最坏工况分层估计而非全局平均；2) STCG 在绑定原子接近剪枝边界时退回完整结构；3) 结构回退日志驱动 z_v 再致密化** | **分布外罕见工况仍可能无原子可报警** |
| **R26** | **单模型多任务负迁移：共享主干被高频任务主导，罕见任务能力退化** | **高** | **1) PCGrad 梯度投影；2) 任务加权采样；3) G 的组稀疏限制跨任务共享范围** | **任务数继续增长时干扰仍会累积** |
| R27 | 覆盖率估计的有限样本误差导致 ε 失真 | 中 | 1) 重要性采样聚焦关键状态；2) 置信上界替代点估计；3) ε 随样本量自适应收紧 | 极端尾部事件仍难覆盖 |
| R28 | SIMP 连续松弛与离散剪枝不一致（0.5 阈值抖动） | 低 | 1) 最终用整数规划/贪心修复；2) 对 z≈0.5 的原子设滞回区 | 边界原子可能在两轮间反复 |

## 7. 本轮最大风险（最终确认）

**一句话**：**结构过剪枝与共享负迁移的耦合**——被判定为「ε-冗余」的原子可能只是在当前采样分布下冗余，一旦分布漂移（罕见地形、极端负载），它恰恰是唯一能报警的约束，而单模型共享主干又会把这种罕见任务的梯度淹没，最终形成「证书仍在、结构已空」的静默失效，且因为报警原子已被剪掉，系统连「自己失去了检测能力」都无法察觉。
