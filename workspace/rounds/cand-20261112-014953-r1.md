# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「时空推理」×「力矩控制」）

> 第 57 轮把承诺的前提升级为"少样本可校准、跨模态可对账、个性化有界的证据承诺"：先验从手工变为跨区域摊销并带共形保底，证据按模态分账对账，人从静态权重变为单向有界的信任状态机。但它的最大风险自陈恰好指出两个更深的结构性缺口：**(a) 时间缺席**——𝓜 与证据本质上是静态快照，时间只以 age(e) 的临时衰减出现；可真实世界的材质属性是随 (r,t) 演化的（冰会融、沙会移、雨会湿、雪会堆），"证据能活多久"是一个物理问题而非时钟问题；更关键的是，第 57 轮用来兜底的 OOD 门仍是从同一语料学出来的——语料没有的世界，门也认不出来，所谓"独立证伪"并不独立。**(b) 后果缺席**——整条安全论证都停在决策层（信念→承诺），但一次错误承诺的真实代价是在执行层兑现的；无论证据多好，只要对不可逆接触的信念错了，后果就可能是灾难性的——除非接触本身被约束成有界的。本轮两个灵感各补一个结构性维度：**时空推理**把地图从静态快照变成带演化先验的物理场 θ(r,t)，让证据拥有物理时效视界，并让"时空连续性"成为独立于语料的第二证伪器（世界不会瞬移）；**力矩控制**把承诺的后果从"由信念正确性决定"变成"由力矩包络决定"——即使信念错了，接触力/能量/穿透/滑移也被约束在可恢复界内，且力矩响应本身成为最难伪造的证据模态与非破坏主动探针。核心命题由"证据说可信"升级为 **"时空自洽、后果有界的证据说可信"**。

核心矛盾：
- **H29（平滑先验 vs 真实突变）**：时空推理以连续/平滑为先验，但危险恰恰住在不连续处——台阶边缘、暗裂缝、局部黑冰。先验越平滑，越会把真正的"边"当作噪声抹平；那个用来兜底"语料盲区"的独立证伪器，可能恰在最要命的地方自信地错。
- **H30（时效视界 vs 探测预算）**：时空预测给证据一个物理过期时刻，但"何时会变"本身是未知的部分可观测状态；过期前刷新浪费探针、过期后才刷新可能太迟，最优刷新是一个 POMDP，而不是固定半衰期。
- **H31（后果有界 vs 任务能力）**：把后果压进可恢复界需要限制力/阻抗/速度，这会直接削弱攀爬与跨越能力；若界按"最坏信念误差"设定，机器人会弱到走不动；若按乐观设定，界就名存实亡。安全不能靠把能力阉割成静止。

## 0. 直觉与动机

**灵感 1（时空推理 → 物理场、时效视界、连续性证伪）**
直觉：地图不该是"某年某月拍的一张照片"，而该是一部"会自己往前推演的电影"。材质属性 θ(r,t) 沿时间按物理规律缓慢演化（融化、干燥、沉积、压实），沿空间按地形连续性相关（相邻区域的摩擦/承重不会突变，除非有边）。于是三件事同时成立：**证据有物理保质期**——不是过了 3 天就衰减，而是"预测状态变化超过阈值或预测方差超过阈值"才过期，一块冬天实测的冰面在春天地表温度上升后应自动作废；**连续性是免费的第二证伪器**——新观测若同时违背空间邻居与时间演化（残差超过共形分位），即使这种材质从未进过语料，也会被"世界不该在这里跳变"抓住；**刷新变成预测驱动的调度**——在证据即将过期的检查点前主动补探，而不是平均地每隔几次探一次。这把第 57 轮"坏先验普遍"的风险从"语料覆盖"部分转移到"物理连续"，但请记住：连续先验自己也会在真实的边处失效，这正是本轮的核心矛盾 H29。

**灵感 2（力矩控制 → 后果界、被动兜底、力矩即证据）**
直觉：再好的证据也可能错，而错一次不可逆接触就可能是灾难。与其把全部赌注押在"让信念不错"上，不如再押一条**与信念无关的物理通道**：把每次接触的力矩/力/阻抗参数约束起来，使最坏情况下的注入能量、穿透深度、切向滑移都落在"可恢复"范围内——摔一跤可以，掉下去不行。这就是**有界后果承诺（BCC）**：把"不可逆接触"重新分类为"有界接触"，安全不再要求证据正确，只要求后果有界。更妙的是，力矩响应本身就是最难被视觉欺骗伪造的证据——透明冰面能骗过眼睛，却骗不过足端测得的接触刚度与力-位移曲线；因此可以在低力下做**柔顺抖动探针**（compliance dithering），用可控的力矩激励换取高信息量、非破坏的物理证据。第 57 轮的"跨模态一致"在此获得一个近乎地面的锚：**力矩是那个不容易共谋的模态**。

**灵感 3（两灵感合流 → 双通道安全、证据门六类、L2→L1 有界重分类）**
直觉：第 56–57 轮建的是**认识论通道**（让信念更准）；本轮加的是**物理通道**（让错也不致命）。两条通道相乘而非相加：承诺的灾难概率不再等于"信念错误概率"，而是"信念错误 ∧ 后果无界"的联合概率。落到证据门上：新增 **EV-torque**（有界力矩下的力-位移证据）与 **BCC 证书**；不可逆接触若满足 BCC，就从 L2 降格为 L1（"有界可恢复接触"），但力矩包络是**全局硬界，个性化永远不能放宽**——这为第 57 轮的单向有界信任补上最后一道不可协商的地板。时空推理则给证据门加上时效检查：过期证据不得进入 certified 集，只能以先验身份参与。

**灵感 4（PCE++ → 探针预算按"预测过期"而非"固定节拍"分配）**
直觉：VOI 现在有两个新来源：一是"现在探能防止未来哪次承诺踩到过期证据"（时效 VOI），二是"低力矩抖动探针能以极小后果换高信息"（柔顺探针的性价比）。承诺前插入时空对账检查点：ST 残差异常 ⇒ 先补一次局部探针并登记 ST-OOD；证据临近过期 ⇒ 强制刷新或降档。所有新机制仍只经"信念更准（含加宽/作废）"或"动作更保守（力更小、更慢、更柔顺）"两个安全通道起作用。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（时空证据场 STF）** 材质属性场 θ(r,t)=(μ,κ,F_bear,c)，以时空过程建模：θ(r,t+Δ)=A θ(r,t)+η_t（演化先验）+ 空间核 k_s(r,r') 的相关先验。观测 o_i=(r_i,t_i,y_i) 经贝叶斯/GP 更新得后验 θ̂(r,t)、方差 σ²(r,t)。空间残差 ρ_s(o)=|y−θ̂(r,t)|/σ；时间残差 ρ_t=变化点统计量（CUSUM/贝叶斯在线变点）。STF 输出预测三元组 (θ̂,σ²,τ_valid)。

**定义 140（时效视界 TVH 与物理过期）** τ_valid(r,t)=min{Δ>0 : ‖θ̂(r,t+Δ)−θ̂(r,t)‖>θ_change ∨ σ²(r,t+Δ)>θ_σ}。证据 e 在 t_e 的**物理有效期**为 t_e+τ_valid；超过则状态由 certified 降为 prior_only，禁止进入证据门 certified 集，只可作先验。刷新调度：在 t_e+τ_valid−Δ_lead 前必须补探或降档；区分"按时钟过期"与"按物理过期"，并以后者为准。

**定义 141（时空对账 STR）** 新观测的 ST 残差 z_ST=max(ρ_s,ρ_t)；以共形分位 q_ST(α_st) 判定：z_ST>q_ST ⇒ 时空异常，触发三件事：(R1) 区域后验强制加宽（与第 57 轮 D(r) 同级）；(R2) 登记 ST-OOD 并优先补局部探针；(R3) 若异常来自变点则**作废**该区域受影响的全部历史证据并重估。关键：该证伪器不依赖 𝒟_meta，仅依赖"世界连续"这一物理先验；其失效模式是真实的突变（边、洞、局部异物），故必须配变点检测与重尾核。

**定义 142（力矩后果界 TCB）** 接触动作 a=(阻抗参数,τ_max,F_max,v_max)。在最坏信念支撑 Θ_wc（由后验支撑集给出，含对刚度下界/摩擦上界的最坏取值）上计算后果集：E_inj(a)=∫F·v dt（注入能量）、d_pen(a)（最大穿透）、s_slip(a)（最大切向滑移）。可恢复谓词 Rec(a) ⇔ E_inj≤E_rec ∧ d_pen≤d_rec ∧ s_slip≤s_rec。称满足 Rec 的接触为**有界后果接触 BCC**。执行层由力矩饱和+阻抗控制保证 a 不被跟踪误差 δ_τ 破坏。

**定义 143（力矩证据与柔顺探针 TCP）** 在 BCC 下执行的低力"抖动/斜坡"激励，其力-位移/力矩-角度响应给出局部刚度与摩擦的直接估计。证据类 EV-torque ⇔ 响应落在后验预测带内且激励全程满足 Rec 与 τ≤τ_probe。TCP 作为可执行探针类型并入 admissible_probes；其欺骗抗性来自"测量对象即物理交互本身"，但受传感器噪声与迟滞限制，需带误差模型。

**定义 144（后果界证据门 CBE 与证书 J_st）** 证据类扩展为六类：EV-probe\*/visit/margin/xmodal(限 L1)/human/**torque**；不可逆接触必要证据集 = {EV-probe\*∨EV-margin∨EV-torque} ∪ 佐证，且必须附 **BCC 证书**；若接触满足 Rec 且 EV 足够，则由 L2 重分类为 L1-bounded。力矩包络 (τ_max,E_rec,d_rec,s_rec) 为全局硬界，任何 auth/个性化不得放宽（覆盖 A39）。J_st 在 J_p 基础上增补：STF 快照与版本、τ_valid、z_ST 与变点记录、TCB 参数与后果上界、TCP 原始力矩轨迹、Rec 判定。继承 J_p 全检。

## 2. 关键算法伪代码（完整版见产物区）

```python
def st_update_and_check(M, o, t, stf, alpha_st):        # IP-139/141
    M.theta, M.sigma = stf.bayes_update(M.theta, o, t)
    z = max(spatial_resid(o, M), changepoint_stat(M, t))
    if z > stf.q_st(alpha_st):
        M = widen_region(M, o.r); ood_reg.add('ST', o.r)
        if changepoint(M, t): M = invalidate_history(M, o.r)
        return M, 'ST_anomaly', z
    return M, 'ok', z

def validity(M, r, t, stf):                              # IP-140
    d = 0
    while stf.pred_change(M, r, t, d) <= theta_change \
          and stf.pred_var(M, r, t, d) <= theta_sigma:
        d += dt
    return d                                              # tau_valid

def consequence_bound(a, belief_support):                # IP-142
    wc = worst_case(belief_support)
    return Bounds(E_inj(a, wc), d_pen(a, wc), s_slip(a, wc))

def torque_commit(c, M, t):                              # IP-142/143
    b = consequence_bound(c.a, support(M, c.r))
    if not Rec(b):
        c.a = shrink_envelope(c.a, target=Rec)           # 只能更保守
        b = consequence_bound(c.a, support(M, c.r))
    if not Rec(b): return ('reject', 'consequence_unbounded', c)
    return ('ok', BCC(c, b))
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| STF | O(N_obs·d) 更新；O(1) 查询（稀疏 GP） | O(N_obs) | 演化先验诚实、变点漏检 ≤δ_st |
| TVH | O(H/Δt) 预测 | O(1) | 过期即降级、无时钟替代 |
| STR | O(1)/观测 + 变点 O(w) | O(w) | 独立于语料、重尾核 |
| TCB | O(d_a) 后果上界 | O(1) | 最坏支撑 + 跟踪误差 δ_τ |
| TCP | O(H_probe) | O(H_probe) | 全程 Rec、噪声模型 |
| CBE/PCE++ | 继承 + O(\|CP\|·d_a) | O(\|V\|+\|σ\|) | 力矩硬界、L2→L1 有界 |

**正确性定理（STB 概要）**：在 A33–A40 上加 (A41) 时空场与时效诚实（τ_valid 预测、ST 共形覆盖 ≥1−α_st）；(A42) 变点/突变漏检 ≤δ_st；(A43) 力矩后果界在跟踪误差 δ_τ 内成立、Rec 上界对最坏支撑有效；(A44) TCP 激励全程满足 Rec、传感器误差诚实。则：(i) **后果有界性（与信念解耦）**：任一承诺若满足 Rec，则即使信念完全错误，其后果仍 ≤(E_rec,d_rec,s_rec)，灾难概率 ≤δ_τ+δ_rec，**不随证据错误率增长**；(ii) **时效健全性**：certified 证据为物理未过期的概率 ≥1−(δ_st+α_st)；(iii) **独立证伪**：语料外材质经 ST 残差被检出（漏检 ≤δ_st），且异常只导致加宽/作废/降档；(iv) 交互单调性延续：ST 异常、过期、个性化均只能经"信念更准（含作废/加宽）"或"动作更保守（力更小/更慢/更柔顺）"起作用，力矩包络不可被 auth 放宽；(v) PCE++ 在 k_probes+k_cons+k_tcp 内终止。

## 6. 本轮最大风险

**一句话**：本轮把安全的最终兜底押在"力矩后果界"上，但后果界本身是从信念的支撑集算出来的——若真实材质比支撑集允许的更软/更滑（又一次"语料里没有的世界"），有界后果承诺会在最需要它的地方悄悄失效；因此真正的最后一道地板必须是不依赖任何模型与信念的**被动柔顺与机械限位**，力矩包络只能作为第二层而非唯一层。

def st_update(M, o, t, stf, alpha_st):
    M.theta, M.sigma = stf.bayes_update(M.theta, o, t)      # 演化先验 + 空间核
    rho_s = abs(o.y - stf.predict(M.theta, o.r, t)) / stf.std(M.sigma, o.r, t)
    rho_t = stf.changepoint_stat(M.hist[o.r], t)            # CUSUM/贝叶斯变点
    z = max(rho_s, rho_t)
    if z > stf.q_st(alpha_st):
        M = widen_region(M, o.r)                            # R1: 强制加宽
        ood_reg.add('ST', o.r)                              # R2: 登记 ST-OOD
        if stf.is_changepoint(M.hist[o.r], t):
            M = invalidate_history(M, o.r)                  # R3: 作废受影响历史
        return M, 'ST_anomaly', z
    return M, 'ok', z

def consequence_bound(a, support):
    wc = support.worst_case()                               # 刚度下界/摩擦上界
    return Bounds(E_inj=integral_force_vel(a, wc),
                  d_pen=penetration(a, wc),

def bounded_commit(c, M):
    b = consequence_bound(c.a, support(M, c.r))
    while not Rec(b):                                       # 只允许更保守
        c.a = shrink_envelope(c.a)                          # 降 τ_max/力/速度，增柔顺
        b = consequence_bound(c.a, support(M, c.r))
        if c.a.at_floor: return ('reject', 'consequence_unbounded', c)
    return ('ok', BCC(c, b))                                # 有界后果证书

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| STF | O(N_obs·d) 更新；O(1) 稀疏 GP 查询 | O(N_obs) | 演化先验诚实、变点漏检 ≤δ_st（A41/A42） |
| TVH | O(H/Δt) 预测 | O(1) | 过期即降级、无时钟替代（A41） |
| STR | O(1)/观测 + 变点 O(w) | O(w) | 独立于语料、重尾核（A42） |
| TCB | O(d_a) 后果上界 | O(1) | 最坏支撑 + 跟踪误差 δ_τ（A43） |
| TCP | O(H_probe) | O(H_probe) | 全程 Rec、噪声模型（A44） |
| CBE | O(\|σ\|) | O(\|σ\|) | 力矩硬界、L2→L1 有界 |
| PCE++ | O(\|CP\|·(k_p+k_c+k_tcp)·(C_VOI+d_φ)+\|CP\|·A\*) | O(\|V\|+\|σ\|) | 时效 VOI、三预算终止、四态完备 |

**正确性定理（SpatioTemporal Boundedness, STB）**
假设 A22–A40（第 53–57 轮）成立；**(A41)** 时空场与时效诚实：θ(r,t) 演化先验与空间核声明诚实，τ_valid 预测误差有界，ST 残差共形覆盖 ≥1−α_st；**(A42)** 突变/变点漏检率 ≤δ_st（平滑先验在真实边处的失效被显式计入）；**(A43)** 力矩后果界：执行层在跟踪误差 δ_τ 内保证 τ≤τ_max、F≤F_max、v≤v_max，且 E_inj/d_pen/s_slip 上界对最坏支撑 Θ_wc 有效，Rec 判定可靠；**(A44)** TCP 激励全程满足 Rec 且力矩 ≤τ_probe，传感器误差模型诚实。则：

1. **后果有界性（与信念解耦）**：若承诺满足 Rec，则即使信念完全错误，后果仍 ≤(E_rec,d_rec,s_rec)；灾难率 ≤δ_τ+δ_rec，**不随证据错误率线性增长**——这是本轮相对第 57 轮的关键解耦。
2. **时效健全性**：进入 certified 集的证据为物理未过期的概率 ≥1−(δ_st+α_st)；过期证据只能以先验身份影响后验。
3. **独立证伪**：语料外材质经 ST 残差被检出（漏检 ≤δ_st），且异常只触发加宽/作废/降档，不产生升险路径。
4. **交互单调性延续**：ST 异常、过期、个性化均只能经"信念更准（含作废/加宽）"或"动作更保守（力更小/更慢/更柔顺）"起作用；力矩包络为全局硬界，auth 不可放宽（强化 A39）。
5. **终止性**：PCE++ 在 k_probes+k_cons+k_tcp 内终止于 {承诺, 绕行, L2 协商, 安全停}。
6. **部署界**：

```
P_catastrophe ≤ P(Rec 失效) + P(Rec 成立但后果超界)
             ≤ δ_τ + δ_rec + Σ_cp [δ_st + α_st]·1[使用过期证据]
P_safe ≥ 1 − (δ_τ + δ_rec) − Σ_cp (δ_st + α_st) − P(被动兜底失效)
```

关键：**认识论通道让机器人敢走，物理通道让机器人错了也不死**；**时空推理让证据有物理保质期、让连续性成为语料之外的独立证伪器**；**力矩既是后果界也是证据（TCP/EV-torque），且是最难被视觉欺骗共谋的模态**。

## 6. 本轮最大风险

**一句话**：本轮把安全的最终兜底押在"力矩后果界"上，但后果界本身是从信念的支撑集算出来的——若真实材质比支撑集允许的更软/更滑（又一次"语料里没有的世界"），有界后果承诺会在最需要它的地方悄悄失效；因此真正的最后一道地板必须是不依赖任何模型与信念的**被动柔顺与机械限位**，力矩包络只能作为第二层而非唯一层。
