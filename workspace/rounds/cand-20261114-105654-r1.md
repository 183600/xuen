# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「比赛策略」×「视觉定位」）

> R69 把不确定性一分为二，并给出一个漂亮的动作：**派一个信息动作去把它消解掉**。但它默认了两个前提：**(A) 歧义只发生在「我该做什么」（动作模态）上；(B) 世界是合作的——我问，它答；我看，它现。** 这两个前提在真实竞争场景里会同时崩塌。
>
> - **视觉定位**提醒：在「我该做什么」之前，还有一个更上游、更致命的问题——**「我在哪、我看到的是不是我以为的那个地方」**。对称走廊、重复纹理、镜面与动态遮挡会让位姿后验天然多峰（perceptual aliasing）。R69 的流似然虽能发现「行为不自洽」，但它本身条件在一个可能错误的定位帧上：**帧错，则一切证书都建立在错误的坐标系里**——这不是动作歧义，而是参考系歧义。
> - **比赛策略**提醒：竞争中的不确定性是**双向的**。你收集信息会暴露不确定性，你消解歧义会让对手更容易预测你；有时「保持混合/模糊」才是均衡（石头剪刀布），「把一切问清楚」反而被反制。R69 的 VoI 只结算物理与社交成本，**漏掉了最大的一项：信息泄漏成本**。
>
> 核心命题：**把不确定性再切一刀，沿「安全性」与「策略性」分层。参考系（位姿/地点）歧义是安全攸关的，必须用几何证据保守地「证伪并取交集」，绝不允许被期望意义平均掉；意图/动作模态歧义是策略攸关的，可以在「帧鲁棒安全集」之内被有意识地混合、甚至放大，以最小化可被对手利用的程度。两条账本分开记：安全账本用最坏情形（intersection over frames），策略账本用可被利用度（exploitability）。** 命名 **DUEL-RAS**（Dual-ledger Uncertainty, Exploitability-aware Localization for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我在哪个世界、谁在看我**」——在竞争里，不确定性既是刹车，也是可以被隐藏、被释放、被对手利用的**信号**。

## 0. 直觉与动机

**灵感 1（比赛策略 → 不确定性是双向信号，不是单向刹车）**
直觉：R68/R69 把不确定性当成「内部状态」：越不确定越慢、越不确定越问。但在比赛里，你的不确定会被对手读取，你的求证动作会暴露意图；你「把歧义问清楚」的那一刻，也把「你会怎么打」交给了对手。石头剪刀布的均衡恰恰要求**随机、不可预测**；一个把每个歧义都消解到确定动作的选手，是最容易被读牌的人。所以竞争中的最优目标不是「最小化不确定性」，而是「最小化**可被利用度**（exploitability）」——有对手时这两个目标是**不同的**。这就是本轮对 R69 的第一处根本修正：**VoI 必须减去信息泄漏成本**。

**灵感 2（视觉定位 → 在「做什么」之下还有「在哪」）**
直觉：R69 的歧义是「我该绕左还是绕右」。但若我根本不知道自己在走廊的哪一端，「绕左」这件事本身就没有定义。视觉定位里的感知别名（对称走廊、重复门牌、镜面、动态人群）让位姿后验天然多峰；更糟的是，**一个自信的错误定位会让 R69 的流似然也失效**——策略在「错误的世界」里依然可能生成高似然、几何自洽的动作。帧错误不是动作歧义的一个分量，而是动作歧义所处的**坐标系**。所以安全门必须上移一层：先证「我在哪个帧」，再谈「我该怎么做」。

**灵感 3（分层 → 安全账本与策略账本必须分开）**
直觉：绝不能说「有 60% 概率我在 A 点，所以 40% 的风险可以接受」——如果那 40% 会撞墙，期望值再低也没意义。参考系歧义必须用**最坏情形/交集**算：只做「在每一个仍可信的位姿假设下都安全」的动作。反过来，意图歧义可以用**期望/均衡**算：只要都在安全集内，故意让对手猜不透你走左还是走右，是收益，不是缺陷。一句话原则：**可以对对手隐藏意图，不可以对自己隐藏位置。**

**灵感 4（对偶 → R69 是 DUEL 的「合作且已知帧」边界）**
直觉：若只有一个位姿假设（|ℋ_ε|=1）、没有对手（泄漏与可被利用度为 0）、且禁止意图混合，那么策略性 VoI 退化为 R69 的 VoI，帧鲁棒安全集退化为普通安全包络，DUEL 逐指令等于 FLUID。于是 R70 不是给 R69 再加一个并列黑箱，而是把它放进一个更大的、能解释「为什么 R69 在竞争里会输」的框架。

**灵感 5（新攻击面 → 定位也可被武器化）**
直觉：一旦「位置」成为安全的基础，攻击者就有了新的杠杆：伪造路标/二维码、制造重复纹理把人引进别名陷阱、用动态遮挡制造假回环、用假「我在这」的回答做社会工程。R69 只防「回答投毒」，R70 必须防「**世界投毒**」——不是答案在骗你，而是**证据的生成过程**在骗你。主动定位因此要从「证实」转向「证伪」：优先选能**推翻**当前最强假设的观测，而不是能「再确认一次」的观测。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（DUEL-RAS 总览与四不变式）** DUEL-RAS = (VLB, HAL, FRG, ALX, GOM, SVO, IMX, ACE, DLR, J_DUEL, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **帧优先（frame-first）**：任何任务动作与证书必须先通过帧鲁棒安全门；帧歧义未收敛时不得以期望意义放行；
(iii) **双账本分离**：安全账本（最坏情形 / 交集）与策略账本（期望收益 / 可被利用度）不得混算，安全账本永远是否决权；
(iv) **策略性模糊仅限意图层**：只允许对「我要做什么」保持混合；禁止对「我在哪」保持混合来博取收益。

**定义 311（多峰位姿信念 VLB）** 地点/位姿假设 h ∈ ℋ = 𝒫 × SE(3)（地点 × 度量位姿），地图 m。观测似然 p(o|h,m)；信念
b_t(h) ∝ p(o_t | h, m) · Σ_{h'} T(h | h', a_{t-1}) b_{t-1}(h')。
候选由地点识别召回（top-k place），再经几何验证（PnP / 对极 / 点云配准内点率）复核；**多峰性显式保留，禁止塌缩为均值**。

**定义 312（感知别名度与帧歧义质量）** 对 h_i ≠ h_j，可分性
S_ij = D_KL( p(o|h_i) ‖ p(o|h_j) ) / d_SE(3)(h_i, h_j)；
别名度 A_ij = exp(−S_ij)。帧歧义质量取「在度量上远离、在观测上相似」的可信对：
alias_mass = Σ_{i≠j, d(h_i,h_j) > d0} b(h_i) b(h_j) A_ij。
S_ij 越低，越需要主动定位；当两个假设观测几乎不可分时，任何「问一次」都无益（呼应 R69 引理 16 的系）。

**定义 313（层级不确定性三分）** U = (U_frame, U_intent, U_ale)：
- U_frame = H(b_t)（位姿后验熵）+ alias_mass；
- U_intent = R69 的 U_epi（动作模态间歧义），但**条件于帧**：U_intent|h；
- U_ale = R69 的模态内不可约噪声。
三者沿「帧 → 意图 → 噪声」形成条件链，**不做简单加和**；分别进入不同账本（定义 314、322）。

**定义 314（帧鲁棒安全集与证书覆盖率）** 对每个 h 定义安全包络 Safe(h)。可信帧集 ℋ_ε = {h : b(h) ≥ ε}。帧鲁棒安全集
Safe_∩ = ⋂_{h ∈ ℋ_ε} Safe(h)。
证书 J 的覆盖率 Cov(J) = b({h : J(h) valid})。合法要求 **Safe_∩ ≠ ∅ 且 Cov(J) ≥ 1 − δ**。若 Safe_∩ = ∅：只允许纯定位动作或停车；若 Cov 不足：不得把「部分帧下的安全」当作安全。

**定义 315（对手模型、博弈值与可被利用度）** 对手策略 π_o ∈ Π_o，我方策略 π，收益 G(π, π_o)（任务收益 − 风险）。零和情形 minimax 值 v*；可被利用度
Exp(π) = max_{π_o ∈ Π_o} G(π, π_o) − v*。
一般和情形用对最佳响应的 regret。治理器要求 Exp(π) ≤ κ。

**定义 316（信息泄漏算子）** 任何动作 ξ（含信息动作 g）都产生可观察信号 s = S(ξ, g, b)（注视、探针、迟疑、问句都泄漏你对帧/意图的信念）。对手据此更新对我方模式的信念 b_o。泄漏成本
L(g) = max_{π_o} [ G(π_o | s(g)) − G(π_o | s(∅)) ]_+，
即「因为被看到，对手多赚的部分」。

**定义 317（策略性 value-of-information）** S-VoI(g) = VoI(g) − L(g) − c_phys/social(g)。选择 g* = argmax S-VoI，s.t. g ∈ Safe_∩、预算与泄漏预算未超；若 max S-VoI ≤ 0 **不交互**。注意：可以出现 VoI > c 但 S-VoI ≤ 0 的情形——**信息值钱，但获取信息的过程更值钱地暴露了你**，此时应放弃求证，这是对 R69 决策规则的直接反转。

**定义 318（可被利用度治理 EXP）** π* = argmin_{π ∈ Π_safe} Exp(π)，s.t. E[G(π)] ≥ ρ，其中 Π_safe 为动作始终落在 Safe_∩ 内的策略类。小规模博弈（支持集 ≤ 5）用线性规划求 minimax/均衡；在线用虚拟博弈/最佳响应迭代。

**定义 319（意图混合与佯攻 IMX）** 在 Safe_∩ 内允许意图分布 w 保持非退化：选择混合策略，support ⊆ {m : m 在每个 h ∈ ℋ_ε 下均安全}。佯攻（feint）定义为「生成一组高似然但低承诺的任务动作序列，使对手误判 committed mode」，约束：
(a) 佯攻轨迹本身 ∈ Safe_∩；
(b) 在反应时间 τ_r 内可逆；
(c) 不改变安全包络，只改变对手对意图的推断。
即：**安全集内允许欺骗对手，安全集边界上不允许欺骗自己**。

**定义 320（对抗性证据与几何优先）** 证据源集合 ℰ，每源 e 有可信度博弈（对手可能控制/污染 e）。把证据分为**低可欺骗**源（地图配准内点、回环、PnP/ICP 残差、IMU/轮速等本体几何）与**高可欺骗**源（人类回答、语言、纯外观匹配、路标 ID）。采纳规则：几何证据与软证据冲突时以几何为准；软源**单独不得更新帧信念**；帧级更新要求至少两个几何独立模态一致（视觉 + 本体/深度）。

**定义 321（证伪式主动定位 ALX）** 定位动作 g_loc ∈ {转向、步进、注视显著地标、回环}。价值
F(g) = E[ H(b) − H(b | o') ] + β · [ b(cluster_top) − E b(cluster_top | o') ]，
第二项是**证伪奖励**：优先降低当前最强假设簇的质量，而不是继续确认它（对抗别名陷阱与「确认偏误」）。选择 argmax [F(g) − L(g) − c(g)]，s.t. g ∈ Safe_∩。

**定义 322（双账本风险缩放 DLR）** 两账本分别计算再取否决：
λ = max( λ_floor(U_ale + U_intent_unresolved), λ_frame(Cov, Safe_∩) )，
其中 λ_frame = 1（全力收紧/停车）当 Safe_∩ = ∅ 或 Cov < 1−δ，否则不额外收紧。
关键：**策略性混合不抬高 λ**（它是策略层的自由度），**帧不确定性永远抬高 λ**。由此 R69 的 resolution bonus 只在帧可信时才发放。

**定义 323（参与式审计 VQAuditor-D）** 审计对象新增：是否用「期望」掩盖了帧歧义（average-over-frames cheat）；是否为了不可预测性牺牲了证据质量；佯攻是否越出 Safe_∩；是否单源采纳软证据；是否把「问出来的答案」当作帧级真值。结论回灌 ACE 可信度与 MINT/SVO 的成本先验。

**定义 324（证书 J_DUEL）** J_DUEL = (J_FLUID, frame_coverage, alias_mass, exp_budget_used, leak_budget_used, feint_log_hash, geo_inlier_p95, dual_ledger_ok, duel_ver)。
Valid ⇔ Valid(J_FLUID) ∧ Safe_∩ ≠ ∅ ∧ Cov ≥ 1−δ ∧ Exp ≤ κ ∧ dual_ledger_ok。

**定义 325（边界与严格包含）** 当 (|ℋ_ε| = 1) ∧ (L ≡ 0 ∧ Exp ≡ 0) ∧ (禁止意图混合) 时：Safe_∩ = Safe(h)，S-VoI = VoI，λ_frame 不激活，DUEL 逐指令退化为 FLUID；再叠加 R69 的退化条件即退回 R68。故 R68 ≺ R69 ≺ R70 为严格包含链。

```python
def frame_robust_guard(b, policy, eps, delta):
    H_eps = {h for h in b if b[h] >= eps}                    # 可信帧集
    safe  = intersect(safe_envelope(h) for h in H_eps)       # ⋂ Safe(h)
    if not safe or certificate_coverage(policy, H_eps) < 1 - delta:
        return None                                          # 禁止任务动作
    return safe

# IP-267 ALX：证伪式主动定位（优先推翻最强假设）
def choose_localization(b, mp, budget):
    best = None

        if best is None or score > best.score: best = (g, score)

# IP-269 SVO：泄漏感知的策略性 VoI（R69 的 VoI 是 L=0 特例）
def strategic_voi(g, b_intent, opponent):

    leak = opponent.advantage_from_signal(S(g))               # 被看到多赚多少
    return voi - leak - cost(g)

# IP-268/270 GOM+IMX：安全集内求可被利用度最小的意图混合

    return solve_zero_sum_lp(support, opponent.payoff)        # 支持集<=5，在线最佳响应
```

## 3. 推导

**引理 19（帧歧义的期望乐观性）** 设帧后验 b 有两个度量远离的假设 h₁, h₂。若存在动作 a 使 R(h₁,a) ≤ ε 而 R(h₂,a) ≥ M，则 E_{h~b}[R(h,a)] ≤ (1−b(h₂))ε + b(h₂)·E[R|h₂] 可任意小，而 max_{h∈supp b} R(h,a) ≥ M。故任何基于**期望帧风险**的证书都不 sound；必须用 Safe_∩ 或 worst-case。系：当两个假设的安全集不相交时，Safe_∩ = ∅，此时「期望安全」的动作在物理上不存在——**R69 的 FMA 若条件在错误帧上，会给出高似然却致命的动作**。

**引理 20（泄漏感知 VoI 的双向性）** 因 L(g) ≥ 0，S-VoI(g) ≤ VoI(g)。且存在博弈使 L(g) > VoI(g)：构造「观察你的注视即可读出你选左还是选右」的匹配博弈，读取后对手最佳响应，收益下降可超过熵下降带来的收益。故 R69 的判据「VoI > c ⇒ 求证」在对抗下不成立；**信息值钱不等于获取信息划算**。系：存在状态使最优决策是「明明很想知道，但忍住不问」。

**引理 21（歧义—可被利用度权衡）** 在有限零和子博弈中，纯策略的可被利用度等于其相对 minimax 值的 gap；混合 minimax 策略可被利用度为 0。故存在状态使 R69 的「消解歧义 / resolution bonus」（把 U_intent 压到 0）**提高** Exp（把可预测性送给对手），均衡的意图熵 H* > 0。反向也成立：当某模态严格占优（对手最佳响应不随模态改变）时，混合只损失收益，应直接消解。判据：**混合只在「对手最佳响应随模态而变」时有正收益**，即 predictability rent > 0。

**定理 18（DUEL 严格包含 FLUID/R68）** 在定义 325 的边界上，S-VoI = VoI、Safe_∩ = Safe(h)、λ_frame 不激活、Exp = 0，故 DUEL 与 FLUID 逐指令相同；再叠加 R69 的退化条件退回 R68。安全侧与效率侧在边界上不做任何让步。

**定理 19（双账本的单调安全）** 在帧信念校准（b 真实反映证据）且审计禁止 average-over-frames 的前提下，任何策略性混合若满足 support ⊆ Safe_∩，则执行动作在**每个**可信帧下都安全；因此其最坏情形物理风险不超过 R69 在相同 U_ale + U_intent 下的风险，且 λ_frame 只会抬不降 λ。故**策略层无论如何博弈，都不能使系统比 R68/R69 更不安全**——除非帧信念本身错（这是本轮最大风险）。

**命题 1（有限博弈的实时可解性）** 支持集 ≤ 5 的零和博弈，minimax 可由线性规划在 < 0.1ms 内求解；在线非平稳对手用虚拟博弈/最佳响应迭代近似，误差随迭代指数收敛（有限博弈）。故策略层不破坏实时预算。

## 6. 本轮最大风险

**一句话**：DUEL-RAS 把不确定性从「敌人」改造成「可交易的策略资源」，但这一切建立在**对手模型与帧信念都校准正确**之上——**一旦对手模型错，佯攻就是自欺；一旦帧先验错，「交集安全集」要么空得让系统安全地瘫痪，要么假得让系统带着全套证书撞墙**；而「故意保持模糊」还可能被审计系统误读为合理的策略多样性，从而掩盖真正的定位错误。

**次级风险与缓解**：
1. **安全集坍塌导致过度保守/瘫痪** → ALX 证伪式定位 + 明确的停车退化 + E303/E313 监控；
2. **帧信念被世界投毒带偏** → 几何优先 + 双几何模态一致 + ℰ_world（伪造路标/别名陷阱）对抗集；
3. **对手模型非平稳/缺失** → 用 minimax/regret 而非最佳响应，Exp 预算 + self-play（E309/E315）；
4. **策略性模糊被滥用为「不解释错误」的借口** → 定义 310-iv 硬约束 + VQAuditor-D 的 dual_ledger_ok 审计；
5. **实时预算被帧重入击穿** → 一次重入上限 + 帧门缓存 + E311 的 P99 约束。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** `DUEL-RAS = (VLB, HAL, FRG, ALX, GOM, SVO, IMX, ACE, DLR, J_DUEL, RAS-WM‡)`；零学习写操作继承；**帧优先**（帧歧义未收敛不得期望放行）；**双账本分离**（安全账本有否决权）；**策略性模糊仅限意图层**（禁止对「我在哪」混合博收益）。

**定义 311–312（VLB 与别名度）** `b_t(h) ∝ p(o|h,m)·Σ T(h|h',a)b_{t-1}(h')`；地点召回 + PnP/ICP 几何复核，保留多峰；`S_ij = D_KL(p(o|h_i)‖p(o|h_j)) / d_SE3(h_i,h_j)`，`A_ij = exp(−S_ij)`，`alias_mass` 为度量远离但观测相似的可信对质量。

**定义 313（层级三分）** `U_frame = H(b) + alias_mass`；`U_intent = U_epi|h`（R69 动作模态歧义，条件于帧）；`U_ale`（R69 模态内噪声）；三层为条件链，分别进不同账本。

**定义 314（帧鲁棒安全集与覆盖率）** `ℋ_ε={h:b(h)≥ε}`，`Safe_∩=⋂_{h∈ℋ_ε}Safe(h)`，`Cov(J)=b({h:J(h) valid})`；合法要求 `Safe_∩≠∅ ∧ Cov≥1−δ`；空集只允许纯定位或停车。

**定义 315（对手与可被利用度）** 收益 `G(π,π_o)`，零和 minimax 值 `v*`，`Exp(π)=max_{π_o}G(π,π_o)−v*`，治理要求 `Exp≤κ`；一般和用 best-response regret。

**定义 316–317（泄漏与策略性 VoI）** 动作产生可观察信号 `s=S(ξ,g,b)`；`L(g)=max_{π_o}[G(π_o|s(g))−G(π_o|s(∅))]_+`；`S-VoI=VoI−L−c`，`max S-VoI≤0` 则不交互。可发生 `VoI>c` 但 `S-VoI≤0`（想知道但忍住不问最优）。

**定义 318–319（治理与意图混合）** `π*=argmin_{π∈Π_safe}Exp(π) s.t. E[G]≥ρ`；小博弈 LP 求解。意图混合 `support⊆{m: ∀h∈ℋ_ε, m 在 h 下安全}`；佯攻约束：本轨迹 ∈ Safe_∩、τ_r 内可逆、只改变对手对意图的推断，不改安全包络。

**定义 320（证据可信度与几何优先）** 证据分**低可欺骗**（配准内点、回环、PnP/ICP、IMU/轮速）与**高可欺骗**（人类回答、语言、纯外观、路标 ID）；冲突以几何为准，软源不得单独更新帧信念，帧更新需两几何独立模态一致。

**定义 321（证伪式主动定位）** `F(g)=E[ΔH(b)] + β·[b(top)−E b(top|o')]`，`g*=argmax[F−L−c] s.t. g∈Safe_∩`；优先推翻最强假设（证伪），而非再确认（防别名陷阱）。

**定义 322（双账本缩放）** `λ=max(λ_floor(U_ale+U_intent_unresolved), λ_frame(Cov,Safe_∩))`；`Safe_∩=∅` 或 `Cov<1−δ` 时 `λ_frame=1`（停车），否则不额外收紧。**策略混合不抬 λ，帧歧义永远抬 λ。**

**定义 323–325（审计/证书/包含）** VQAuditor-D 审 average-over-frames、单源软证据、佯攻越界、以模糊掩盖定位错误；`J_DUEL=(J_FLUID, frame_coverage, alias_mass, exp/leak budget, feint_log_hash, geo_inlier_p95, dual_ledger_ok, duel_ver)`；边界 `|ℋ_ε|=1 ∧ L≡0 ∧ 禁止混合` 时 `Safe_∩=Safe(h)`、`S-VoI=VoI`、DUEL≡FLUID，故 `R68 ≺ R69 ≺ R70`。

```python
    g = M.svo.choose(modes, o, M.gom, M.budget) if U_intent > TAU_EPI else None
    if g is not None: U_intent = M.cia.update_belief(modes, M.cia.execute(g))
    w   = M.imx.minimax_intent(modes, safe, M.gom)          # 允许故意含糊
    lam = M.dlr.scale(U_ale, U_intent, coverage=M.frg.coverage())
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H),
                                      ..., wm_preds, safe=safe)
    mode = select_mixed_mode(modes, w, U_intent, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_d.submit_async(g, w, b, U_intent, lam, safe)
    return k, lam, mode, (U_ale, U_intent, b)
```

## 4. 推导

**引理 19（帧歧义的期望乐观性）** 若两度量远离的帧 h₁,h₂ 上存在动作 a 使 `R(h₁,a)≤ε`、`R(h₂,a)≥M`，则 `E_b[R]` 可随 `b(h₂)` 小到任意，而 `max_{h∈supp b}R(h,a)≥M`。故基于**期望帧风险**的证书不 sound；必须 `Safe_∩`/worst-case。系：当两假设安全集不相交时 `Safe_∩=∅`，「期望安全」的动作物理上不存在——R69 的 FMA 若条件在错误帧上，会给出高似然却致命的动作。

**引理 20（泄漏感知 VoI 的双向性）** `L(g)≥0 ⇒ S-VoI≤VoI`；且存在博弈使 `L(g)>VoI(g)`（对手读注视即知模态并最佳响应）。故 R69「VoI>c ⇒ 求证」在对抗下不成立：**信息值钱 ≠ 获取信息划算**；存在状态使最优是「很想知道但忍住不问」。

**引理 21（歧义—可被利用度权衡）** 有限零和子博弈中纯策略 Exp 等于相对 minimax 的 gap，混合 minimax 的 Exp 为 0；故存在状态使 R69 的「消解歧义 / resolution bonus」反而**提高** Exp，均衡意图熵 `H*>0`。反向：当某模态严格占优（对手最佳响应不随模态变）时混合只损收益，应直接消解。判据：**仅当 predictability rent > 0 时混合有正收益。**

**定理 18（DUEL 严格包含 FLUID/R68）** 边界 `|ℋ_ε|=1 ∧ L≡0 ∧ Exp≡0 ∧ 禁止混合` 下 `S-VoI=VoI`、`Safe_∩=Safe(h)`、`λ_frame` 不激活，DUEL 与 FLUID 逐指令相同；叠加 R69 退化条件退回 R68。安全与效率在边界上不让步。

**定理 19（双账本的单调安全）** 帧信念校准且审计禁止 average-over-frames 时，任何 `support⊆Safe_∩` 的意图混合所执行动作在**每个可信帧**下都安全，其最坏情形物理风险不超过 R69 在相同 `U_ale+U_intent` 下的风险；`λ_frame` 只抬不降 λ。故**策略层无论怎么博弈，都不会比 R68/R69 更不安全**（除非帧信念本身错——本轮最大风险）。

**命题 1（有限博弈实时可解）** 支持集 ≤5 的零和博弈 minimax 由 LP 在 <0.1ms 求得；非平稳对手用虚拟博弈/最佳响应迭代，有限博弈下误差随迭代指数收敛。策略层不破坏实时预算。

## 7. 本轮最大风险

**一句话**：DUEL-RAS 把不确定性从「敌人」改造成「可交易的策略资源」，但这一切建立在**对手模型与帧信念都校准正确**之上——**一旦对手模型错，佯攻就是自欺；一旦帧先验错，「交集安全集」要么空得让系统安全地瘫痪，要么假得让系统带着全套证书撞墙**；而「故意保持模糊」还可能被审计系统误读为合理的策略多样性，从而掩盖真正的定位错误。

**次级风险与缓解**：安全集坍塌导致过度保守/瘫痪（ALX 证伪式定位 + 明确停车退化 + E303/E313）；帧信念被世界投毒带偏（几何优先 + 双几何模态一致 + ℰ_world 对抗集）；对手模型非平稳/缺失（minimax/regret + Exp 预算 + self-play，E309/E315）；策略性模糊被滥用为「不解释错误」的借口（定义 310-iv 硬约束 + VQAuditor-D 的 dual_ledger_ok 审计）；实时预算被帧重入击穿（一次重入上限 + 帧门缓存 + E311 的 P99 约束）。
