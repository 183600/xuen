> R68 把「测量可信度」升为在线潜变量，但其自陈风险直指一个更底层的元失败：慢变故障落在标定带宽内会被 COF「标好」，而 CAC 的金标/canary 集若未覆盖该模式便放行。**这不是模型不够好，而是证据基础（数据集）从未被建模。** R65–R68 一路升级模型、滤波器、证书，却始终把数据集当作给定的、静态的、无限的、可信的常量。R69 的命题：
>
> **数据集不是输入，而是被制造出来的材料——有规格书、有疲劳寿命、有杂质上限、有产地溯源，需要进厂检验、FMEA 排产、定期复检；安全证书只能与其证据材料一样强。**

>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我的证据还够用吗**」——证据不足、过期、被污染时，证书失效、放行自动收缩。

## 0. 直觉与动机

**灵感 1（数据集 → 证据是会疲劳的消耗品，不是常量）**
直觉：R68 的 CAC 有五关，但五关的基准（D_gold）、攻击样本（canary）、审计池（AuditBuf）全是静态资产。工程与材料科学的常识是：任何承受载荷的材料都会**疲劳**——在漂移的世界里，一份三周前采集的分布外金标集，其「证明力」早已衰减，却仍被当作满值使用。数据集有三个被忽略的属性：(i) **覆盖度有限**（它只能证明它见过的模式）；(ii) **半衰期有限**（分布漂移让它逐日失真）；(iii) **产地决定证词强度**（真机人工金标 ≫ 仿真 ≫ 自监督伪标签）。不建模这三点，「认证」就是**用一张未检验的试纸去发合格证**。

**灵感 2（材料选型 → 数据合金的 Ashby 性能指数）**
直觉：选材料从不是「强度最大最好」，而是在强度/韧性/密度/成本/寿命之间做多目标 Pareto；Ashby 的关键洞察是把多个物性组合成**性能指数** P = σ^a·E^b/ρ^c，再在约束下取极值。数据选材同理：每个数据源/分片是一块「材料」，其属性是 (安全覆盖 C_safe、时效 freshness、标签可信度 ℓ、成本 c、衰减率 λ_d)。训练不是「用全部数据」，而是**为当前任务锻造一块数据合金**——在预算约束下最大化最坏覆盖，这正是一个子模覆盖最大化问题（贪心可证 1−1/e 近似）。

**灵感 3（材料疲劳 → 数据认证半衰期与到期制）**
直觉：金属有 S–N 曲线与疲劳极限；数据有「漂移–证明力」曲线。设漂移率 λ_d（特征空间 MMD 增长率），则认证证明力 V(t)=V₀·e^{−λ_d t}，半衰期 T½=ln2/λ_d。于是每个数据集条目都应带**到期时间** t_exp，证书在证据过期时自动降级。这把 R68 里「静态金标集永远有效」的隐含假设，替换为可调度的**复检制**：到期前必须重新采集/复核，否则 λ 下限抬升、前缀收缩（复用 R68 的 CAR 纪律）。

**灵感 4（进货检验 + FMEA → 数据验收与补盲排序）**
直觉：材料进厂要按批抽检（杂质、批次一致性、溯源），设计阶段要做 FMEA，用严重度 S×发生率 O×难检度 D 的 RPN 排序改进优先级。数据同理：任何分片进训练/进证书前必须过五检（溯源完整 / 标签噪声 / 污染筛查 / 分布有效 / canary 判别力保持）；而**未被覆盖的故障模式**用 RPN 排序——R68 的慢变故障带正是「难检度 D 极高、发生 O 中、严重 S 极高」的高 RPN 盲区，必须被**定向制造样本**（变形注入）补上，而不是被动等它出现。

**灵感 5（合流 → DAMS-RAS 七组件，对症 R68 残余风险）**
1. **DDS Data Datasheet & Spec**：每个数据分片一张规格书（产地/时间/覆盖向量/纯度/衰减率/血缘）；
2. **DSA Data Selection Alloy**：Ashby 性能指数 + 预算约束子模贪心，锻造成本轮训练合金；
3. **DFL Data Fatigue Life**：漂移率估计 + 认证半衰期 + 到期调度器；
4. **CGA Coverage-Gap Auditor**：残差/表征新颖性检测发现未覆盖模式，算 RPN；
5. **MFS Metamorphic Fault Specimen**：对盲区定向生成物理可信的变形故障样本（尤其 ω_f ≤ ω_cal 的慢故障带）；
6. **DAC Data Acceptance**：进货五检 + 只追加内容寻址材料库；
7. **J_DATUM + RAS-WM‡**：证书升级为「证据证书 × 模型证书」双证耦合，Valid 需覆盖达标且证据未过期；RAS-WM 继承核全部保留。
核心对症：R68「标定能力越强、缓变故障越隐形」的根因被改写成「**该故障带的样本密度不足**」——这是一个**可测量、可补采、可验收**的工程问题（引理 16、定理 17），而不再是一个只能祈祷的模型黑箱。

## 1. 形式化定义（增量：定义 293–309）

**定义 293（DAMS-RAS 总览）** DAMS-RAS = (DDS, DSA, DFL, CGA, MFS, DAC, DML, J_DATUM, RAS-WM‡)。三条不变式：
(i) **无规格不入训**：任何分片进入训练或证书前，必须持有规格书 S(d) 且通过 DAC 验收；
(ii) **双证耦合**：模型证书 J_CALM 仅在证据证书 J_DATUM 有效时有效——证据失效即模型降级；
(iii) **到期即降级**：证据疲劳到期或覆盖下限被击穿时，不冒险放行，而是自动升 λ 下限、收缩前缀（复用定义 284–285）。

**定义 294（数据规格书）** 每个最小数据单元（分片）d 附带 S(d) = (prov, τ_collect, src ∈ {human-gold, real, sim, ssl-pseudo}, label_quality q_ℓ ∈ [0,1], cov_vec, decay_rate λ_d, contam_bound ε_c, lineage_root)。规格书本身受内容哈希保护，篡改即失效。

**定义 295（安全覆盖度）** 设安全相关故障模式集合 {M_k}_{k=1}^K。分片集合 D 在模式 k 上的覆盖 cov_k(D) ∈ [0,1] 由支持集测度（核密度/一致性预测）估计。定义**最坏覆盖** C_safe(D) = min_k cov_k(D)，或风险敏感版 C_safe^α(D) = CVaR_α({cov_k})——只惩罚尾部最差模式，与 RAS 的「只收紧不放宽」同构。**证书只认最差模式，不认平均覆盖。**

**定义 296（数据疲劳与认证半衰期）** 设特征分布漂移率 λ_d 由 P(z_t) 与 P(z_{t−Δ}) 的 MMD 增长率估计。认证证明力 V_D(t) = V_D(0)·e^{−λ_d·t}，半衰期 T½ = ln2/λ_d。安全保守到期 t_exp = t_0 + T½/κ_safe（κ_safe ≥ 2，按西格玛纪律折减）。到期后 C_safe 的有效值按 C_safe·V(t)/V(0) 折算。

**定义 297（Ashby 数据性能指数）** 对候选数据源/合金 m，属性 (C_safe, freshness f, label trust ℓ, cost c)。性能指数 I(m) = C_safe^a · f^b · ℓ^g / c^d（a,b,g,d>0 由任务定），选材取 m* = argmax I(m) s.t. C_safe ≥ C_req ∧ ℓ ≥ ℓ_min ∧ c ≤ B。其 Pareto 前沿即「同等预算下能达到的最坏覆盖—时效组合」。

**定义 298（数据合金选择）** 给定分片集合与预算 B、每片成本 c_i、覆盖增量 Δ_i(S)=C_safe(S∪{i})−C_safe(S)，求解 max_S C_safe(S) s.t. Σ_{i∈S} c_i ≤ B。C_safe 关于 S 单调子模 ⇒ 贪心按 Δ_i/c_i 排序可达 (1−1/e)·OPT（引理 18）。

**定义 299（数据 FMEA / 补盲优先级）** 对证据薄弱或缺失的模式 k，定义 RPN_k = S_k·O_k·D_k：S_k 严重度（该故障后果）、O_k 发生率（漂移/工况先验）、D_k 难检度（当前检出裕度之倒数）。补盲顺序按 RPN 降序——R68 的慢故障带因 D_k 极大而天然排在最前。

**定义 300（覆盖缺口审计器 CGA）** 在线对残差 r_t 与潜状态 z_t 做新颖性检测（密度比/马氏距离/一致性 p 值），把落入低覆盖区的事件聚类并与模式库匹配；未知簇进入「候选新模式」，算 RPN 并触发 MFS + 采集。CGA 的输出是**证据缺口清单**，不是控制指令。

**定义 301（变形故障样本生成 MFS）** 对目标模式 k 与目标频带 ω_target，沿物理可信的参数轨迹注入（力零偏斜坡 b_F(t)、外参慢旋 δR(t)、时延漂移 Δt(t)、曝光漂移、力泄漏），生成满足变形关系（同一几何在不同模态的独立测量在无故障时应一致）的样本对。特别地，**慢故障样本的注入频率必须覆盖 ω_f ≤ ω_cal 的标定带宽**——这是 R68 盲区的直接填埋。

**定义 302（数据验收 DAC 五检）** 分片/批次进材料库前需全过：
1. 溯源链完整（lineage_root 可追到采集与标注）；
2. 标签噪声 ≤ ε_ℓ（金标抽检 + 交叉一致性）；
3. 污染筛查阴性（后门/投毒/分布伪装）；
4. 分布有效（在运行包络内，非越界伪造）；
5. **canary 判别力保持**（该批不得削弱对已注入真故障的区分度）。
任一不过 → 隔离区，不参与训练与发证。

**定义 303（数据材料库 DML）** 内容寻址、只追加、带墓碑的版本化分片库；每个分片存 S(d) 与验收记录。训练合金是**引用组合**而非拷贝，任何 alloy 可复现为 (manifest_hash, weights)。废弃用 tombstone，绝不原地改写（保可审计性）。

**定义 304（复检调度器）** 每个分片/证书有 t_exp；调度器保证在 t_exp 前完成复采或复核；逾期未复检 ⇒ 该分片有效覆盖按定义 296 折算并触发 λ 下限/前缀收缩。以「最小化期望失效风险 × 复检成本」排程（可视为带截止期的加权覆盖问题，贪心 EDF 近似）。

**定义 305（J_DATUM 证据证书）** J_DATUM = (data_manifest_hash, coverage_vec, C_safe^α, fatigue_age, acceptance_verdicts, provenance_root, datum_ver)。Valid ⇔ C_safe^α ≥ C_req ∧ age < t_exp ∧ 所有 acceptance = PASS ∧ 溯源与训练集见证独立（定义 306）。

**定义 306（证据–模型耦合与见证独立性）** 用于**发证**的数据必须与用于**训练**的数据在产地/时间/血缘上可证不交叠：independence defect fraction ≤ ε_ind（由 provenance_root 的集合差证明）。否则证书自证循环失效。见证集（witness set）作为第三方「留样」，训练侧不可见。

**定义 307（盲区覆盖下界）** 对带宽 ω 的故障模式，设该带内样本密度为 ρ(ω)。若 ρ(ω) < ρ_min(ω)（ρ_min 由检出裕度与目标漏检率反推），则任意模型在该带的覆盖上界 C_safe(ω) ≤ 1 − e^{−ρ(ω)/ρ_min(ω)} 量级受限——**模型再好，也不能证明它没见过的慢故障**。这是 R68 风险的形式化，也给出补盲的定量目标。

**定义 308（在线数据食谱循环）** 每 T_diet 周期：CGA 采缺口 → DFA 排 RPN → MFS 补样/定向采集 → DAC 验收 → DSA 重锻合金 → 影子训练 → CAC 提交 → J_DATUM 复检发证。与 R68 的 60s 适配器提交正交：**证据周期（分钟–天）≫ 参数周期（秒–分）**，二者不共享实时流写操作。

**定义 309（数据威胁模型）** ℰ_data = {标签投毒、后门植入、分布伪装、溯源伪造、疲劳掩盖（用陈旧数据冒充新鲜）、覆盖虚报}；总干扰集 ℰ_DAMS = ℰ_CALM × ℰ_data。J_DATUM 必须对每一项给出可检验的否决条件。

# IP-253 DDS：数据规格书 + 覆盖向量（内容寻址）
class DataDatasheet:
    def __init__(self, prov, t0, src, label_q, cov_vec, lam_d, contam_eps):
        self.spec = dict(prov=prov, t0=t0, src=src, q=label_q,
                         cov=cov_vec, lam=lam_d, eps=contam_eps)
        self.h = content_hash(self.spec)

    def effective_coverage(self, now, k_safe=2.0):
        V = math.exp(-self.spec['lam'] * (now - self.spec['t0']))
        return self.spec['cov'] * (V ** (1.0 / k_safe))   # 疲劳折算


# IP-254 DSA：Ashby 性能指数 + 预算约束子模贪心（数据合金）
def forge_alloy(shards, budget, C_req, l_min,
                a=1.0, b=0.5, g=1.0, d=1.0):
    cand = [s for s in shards if s.q >= l_min and s.cost > 0]
    def index(s):                                     # 材料选型性能指数
        return (s.cov ** a) * (s.fresh ** b) * (s.q ** g) / (s.cost ** d)
    cand.sort(key=index, reverse=True)
    alloy, cost = [], 0.0
    while True:                                       # 子模覆盖贪心
        best, best_gain = None, 0.0
        for s in cand:
            if s in alloy or cost + s.cost > budget:
                continue
            gain = (cvar_cov(alloy + [s]) - cvar_cov(alloy)) / s.cost
            if gain > best_gain:
                best, best_gain = s, gain
        if best is None or cvar_cov(alloy) >= C_req:
            break
        alloy.append(best); cost += best.cost
    return alloy, cvar_cov(alloy), cost


# IP-255 DFL：漂移率估计 + 认证半衰期 + 到期调度
class FatigueLifeModel:
    def update(self, z_hist):
        self.lam = mmd_growth_rate(z_hist, window=self.W)  # 漂移率 λ_d
        self.half_life = math.log(2) / max(self.lam, 1e-9)

    def expiry(self, t_collect, k_safe=2.0):
        return t_collect + self.half_life / k_safe


# IP-257 MFS：针对盲区（尤其慢故障带）的变形样本生成
def metamorphic_specimens(mode_k, omega_lo, omega_hi, n):
    out = []
    for _ in range(n):
        w = sample_band(omega_lo, omega_hi)          # 频率落在标定带内/外
        T = fault_transform(mode_k, w)               # 物理可信故障变换
        pair = make_pair(T)                          # 无故障时应模态一致的样本对
        out.append(pair)
    return out


# IP-258 DFA：FMEA 补盲优先级
def rpn_priority(gaps, severity, occurrence):
    return sorted(
        ({**g, 'rpn': severity[g['mode']] * occurrence[g['mode']] * g['detect_difficulty']}
         for g in gaps),
        key=lambda g: g['rpn'], reverse=True)


# IP-259 DAC：进货五检
def acceptance(batch, witness):
    return all([
        provenance_complete(batch),
        label_noise(batch) <= EPS_L,
        not contamination_screen(batch),
        in_operating_envelope(batch),
        canary_discrimination_kept(batch, witness),   # 不得削弱对真故障的区分
    ])


# IP-261 J_DATUM：证据证书 + 与模型证书双证耦合
def certify_evidence(manifest, alloy, now):
    cov = cvar_cov(alloy)
    age_ok = all(s.t_collect + s.half_life / K_SAFE > now for s in alloy)
    indep = witness_independence(manifest, TRAIN_MANIFEST)   # 见证独立性
    return dict(coverage=cov, age_ok=age_ok, indep=indep,
                valid=(cov >= C_REQ and age_ok and indep))


# IP-252 + IP-262：CALM-RAS 主闭环接入数据食谱（不干扰实时流写操作）
def DAMS_RAS_round(M, obs):
    # ---- 实时流：只读双证，不写数据、不训练 ----
    j_datum = M.j_datum.current()
    if not j_datum['valid']:                          # 证据失效 ⇒ 保守降级
        M.efs.raise_lambda_floor(0.8)
        M.c_ras_wm.shrink_prefix(k_min=1)

    k, lam, joint_post, (c, U) = CALM_RAS_round(M, obs)   # R68 继承核

    # ---- 证据流：异步、周期 T_diet ----
    if M.diet_due():
        gaps = M.cga.detect_gaps(M.residual_log, M.z_cache)   # 新颖性 → 缺口
        prio = rpn_priority(gaps, M.severity, M.occurrence)   # FMEA 排序
        for g in prio[:M.top_q]:
            spec = M.mfs.metamorphic_specimens(g['mode'], g['w_lo'], g['w_hi'], n=64)
            if acceptance(spec, M.witness):                   # DAC 进货检验
                M.dml.admit(spec, datasheet_of(spec))         # 只追加材料库
        alloy, cov, cost = forge_alloy(M.dml.shards(), M.budget, C_REQ, L_MIN)
        M.shadow.train(alloy)                                 # 影子流
        if M.cac.maybe_commit(M.shadow, M.dt_since_commit) == 'PASS':
            M.j_datum.refresh(certify_evidence(alloy, alloy, M.now))
    return k, lam, joint_post, (c, U), j_datum

## 3. 推导

**引理 16（覆盖度–漏检界：证据不足直接等于漏检）** 若见证集 D 对模式 k 的覆盖为 cov_k(D)，则在该模式上「未见样本」导致的漏检概率下界约 1 − cov_k(D)（一致性预测意义下，覆盖率与边际误覆盖率的对偶）。故 R68 的慢故障风险可精确写成 **P(漏检慢故障) ≥ 1 − cov_slow(D)**：它不取决于模型容量，只取决于该带样本密度。**把不可名状的「标定吸收」风险，还原为可测量的覆盖缺口。**

**引理 17（认证疲劳到期界）** 设漂移率 λ_d 恒定，依据定义 296 的折算，证明力 V(t)=V₀e^{−λ_d t}。为保持误放行概率 ≤ δ，需 V(t)/V₀ ≥ 1−δ ⇒ **复检周期 T ≤ −ln(1−δ)/λ_d ≈ δ/λ_d**。系：任何静态金标集都有硬到期时间，R68 的「一次性 canary 集」在漂移下必然失效，且失效速度由 λ_d 显式给出——这使得「多久复检」第一次成为可计算的量。

**引理 18（数据合金贪心近似最优）** C_safe^α(S)=CVaR_α({cov_k(S)}) 关于 S 单调且子模（覆盖函数的标准性质，CVaR 为单调子模的保序组合），预算约束下最大化子模函数用贪心按边际增益/成本排序，得 C_safe^α ≥ (1−1/e)·OPT。故数据选材可在多项式时间内做到近最优，无需枚举。

**定理 16（证据条件化端到端安全）** 在 A87–A94 与新增 A95–A97（漂移率可估、覆盖可一致估计、见证独立）下，R68 定理 14 的第 1 项须增补一个**此前被漏掉的证据项**：
P(未检出的不安全放行) ≤ (1 − C_safe^α) + 1[age ≥ t_exp] + α_cal + α_chunk + δ_fi + α_emotion + α_wm + α_vqa。
含义：(i) R68 证书隐含假设前两项为 0，DAMS-RAS 首次把它们显式化并纳入 Valid；(ii) 双证耦合保证证据失效时 λ 下限抬升、前缀收缩，故**证据不足只会收紧，绝不放宽**；(iii) 覆盖度和疲劳年龄均可在线估计与审计，故该上界是可监控的，而非纸面假设。

**定理 17（盲区材料充分性）** 对慢故障带 ω_f ≤ ω_cal，若该带样本密度 ρ(ω) ≥ ρ_min，则 MFS 注入的变形样本使该带覆盖达到 C_safe(ω) ≥ 1 − ε_det（由引理 16 反解），从而 R68 的「标定吸收慢故障」残余风险被压到 ≤ ε_det；反之若 ρ(ω) < ρ_min，则任何模型都无法给出该带的覆盖保证，证书必须显式拒绝颁发（而非默认通过）。**这把 R68 的「原罪」变成了一个可满足的验收条件。**

## 6. 本轮最大风险

**一句话**：DAMS-RAS 把安全性寄托在「用有限模式库定义的覆盖度 C_safe 能代表真实世界的证据充分性」上——但**未知的未知无法被覆盖度度量**：一旦运行中出现连模式库都未枚举的故障，CGA 只会把它归为「新颖但无标签」，C_safe 仍显示达标，系统将以「证据合格」的假安全感关闭最后的探索与保守回退——**这是「数据即材料」范式的原罪：覆盖度越像一张完备的合格证，越容易让人忘记合格证只覆盖了它自己列出的检验项。**

**次级风险与缓解**：
1. **覆盖度估计偏差**（一致性预测在分布外失准）→ 双估计器（核密度 + conformal）+ 估计器不一致即降级；
2. **疲劳模型过简**（指数衰减假设在突变/工况切换下失效）→ 变点检测 + 非指数回退 + 突变即强制复检；
3. **见证独立性难证**（血缘/时间耦合泄漏）→ 内容哈希 + 集合差证明 + 第三方留样隔离；
4. **补样成本爆炸 / 主动采集扰民**→ RPN 排序 + 预算约束 + 仿真优先；
5. **证书体系自身成为单点**（J_DATUM 被伪造或过期未检）→ 哈希链 + 到期强制降级 + 定期第三方见证复核。

# IP-253 DDS：规格书 + 疲劳折算后的有效覆盖
class DataDatasheet:
    def __init__(self, prov, t0, src, label_q, cov_vec, lam_d, contam_eps):
        self.spec = dict(prov=prov, t0=t0, src=src, q=label_q,
                         cov=cov_vec, lam=lam_d, eps=contam_eps)
        self.h = content_hash(self.spec)
    def effective_coverage(self, now, k_safe=2.0):
        V = math.exp(-self.spec['lam'] * (now - self.spec['t0']))
        return self.spec['cov'] * (V ** (1.0 / k_safe))

# IP-254 DSA：Ashby 指数 + 预算约束子模贪心
def forge_alloy(shards, budget, C_req, l_min, a=1.0, b=0.5, g=1.0, d=1.0):
    cand = [s for s in shards if s.q >= l_min and s.cost > 0]
    cand.sort(key=lambda s: (s.cov**a)*(s.fresh**b)*(s.q**g)/(s.cost**d), reverse=True)
    alloy, cost = [], 0.0
    while True:
        best, best_gain = None, 0.0
        for s in cand:
            if s in alloy or cost + s.cost > budget: continue
            gain = (cvar_cov(alloy + [s]) - cvar_cov(alloy)) / s.cost
            if gain > best_gain: best, best_gain = s, gain
        if best is None or cvar_cov(alloy) >= C_req: break
        alloy.append(best); cost += best.cost
    return alloy, cvar_cov(alloy), cost

# IP-255 DFL：漂移率 → 半衰期 → 到期
class FatigueLifeModel:
    def update(self, z_hist):
        self.lam = mmd_growth_rate(z_hist, window=self.W)
        self.half_life = math.log(2) / max(self.lam, 1e-9)
    def expiry(self, t_collect, k_safe=2.0):
        return t_collect + self.half_life / k_safe

## 4. 推导

**引理 16（覆盖度–漏检界）** 覆盖 cov_k(D) 与边际误覆盖率的对偶关系给出：该模式漏检概率下界约 1 − cov_k(D)。故 R68 慢故障风险可精确写成 P(漏检) ≥ 1 − cov_slow(D)——**只取决于该带样本密度，不取决于模型容量**；把「标定吸收」的黑箱风险还原为可测量的覆盖缺口。

**引理 17（认证疲劳到期界）** V(t)=V₀e^{−λ_d t}。保持误放行 ≤ δ 需复检周期 T ≤ −ln(1−δ)/λ_d ≈ δ/λ_d。系：静态金标集必有硬到期，R68 的一次性 canary 集在漂移下必然失效，失效速度由 λ_d 显式给出。

**引理 18（数据合金贪心近似最优）** C_safe^α(S)=CVaR_α({cov_k(S)}) 单调子模；预算约束下按边际增益/成本贪心得 C_safe^α ≥ (1−1/e)·OPT。

**定理 16（证据条件化端到端安全）** 在 A87–A94 与 A95–A97 下：
`P(未检出不安全放行) ≤ (1 − C_safe^α) + 1[age ≥ t_exp] + α_cal + α_chunk + δ_fi + α_emotion + α_wm + α_vqa`。
R68 证书隐含前两项为 0；DAMS-RAS 首次显式化并纳入 Valid，且证据失效时 λ 下限升、前缀收缩（**只收紧不放宽**）。

**定理 17（盲区材料充分性）** 慢故障带 ρ(ω) ≥ ρ_min ⇒ MFS 补样使 C_safe(ω) ≥ 1 − ε_det，R68 残余慢故障风险 ≤ ε_det；反之 ρ(ω) < ρ_min 时任何模型都无覆盖保证，证书必须显式拒发而非默认通过。**R68 的「原罪」被改写为可满足的验收条件。**

## 7. 本轮最大风险

**一句话**：DAMS-RAS 把安全性寄托在「用有限模式库定义的覆盖度 C_safe 能代表真实世界的证据充分性」上——但**未知的未知无法被覆盖度度量**：一旦出现连模式库都未枚举的故障，CGA 只会把它归为「新颖但无标签」，C_safe 仍显示达标，系统将以「证据合格」的假安全感关闭最后的探索与保守回退——**这是「数据即材料」范式的原罪：覆盖度越像一张完备的合格证，越容易让人忘记合格证只覆盖了它自己列出的检验项。**

**次级风险与缓解**：覆盖度估计偏差（双估计器 + 不一致即降级）；疲劳模型过简（变点检测 + 非指数回退 + 突变强制复检）；见证独立性难证（哈希 + 集合差证明 + 第三方留样）；补样成本爆炸（RPN 排序 + 预算约束 + 仿真优先）；证书体系单点（哈希链 + 到期强制降级 + 定期第三方复核）。
