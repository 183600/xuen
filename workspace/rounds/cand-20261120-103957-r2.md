# 第 2 轮（新灵感循环第 2 轮；本轮灵感：「谐波减速器」×「大语言模型」）

> **基线**：第 1 轮 MetricVoiceGauge-NCD-HUTDH-v16（定义 627–656；引理 131–136；实验 E671–E690）。本轮纪律：**谐波减速器为信道、语言模型为发生器、证书为语法**。不推倒 v16：BTS/TRM/WBC/CSC/NCS/MCA/WCB 与 v15 及历轮不变式全部保留。新增六个组件——TCE（传动证书估计器）、MGP（机械语法解析器）、PT-HLM（本体感受分词器 + 迟滞语言模型）、AQC（别名商证书器）、IDG（意图变形治理器）、PSD（双齿奇偶滑移检测器），辅以 TAS（传动感知调度器）、RDP（再归位/抖动过程）、TCIC（受证意图编译器）、WLF（磨损语言预测器），一律以中立元接入，失效即严格退回 v16（引理 143），再沿 v16→v15→v14→v13→v12→v11→v10→v9→v8→v7→v6 退化链退回。本轮只做三件事：把“谐波减速器”改写为**有语法的、迟滞的、非可逆的机械传输信道**、把“大语言模型”改写为**只在柔性包络内变形意图的发生器 + 迟滞状态的自回归预测器**、把“意图→关节力矩”改写为**在机械语法与传动证书下的可解析句子生成**。

## 0. 直觉与动机

**灵感 1（谐波减速器 → 机械传输是一门外语）**
直觉：谐波减速器的本质不是“齿轮”，而是一个**高比、柔顺、迟滞、非可逆的传输信道**：波发生器以高频小幅输入，经柔轮的弹性变形，驱动刚轮输出低频大扭矩；它的齿差（通常 2 齿）既给出减速比，也给出一种天然的“冗余奇偶”。它对输入做的不是恒等放大，而是**带记忆的压缩**——同一力矩指令，正行程与反行程的输出角不同（迟滞），小于某个阈值的指令根本传不过去（空回/丢失运动），传动误差随啮合相位周期变化（运动学误差），扭转刚度随力矩分段非线性。核心创新：**把谐波减速器看成一门“机械语言”**——可分辨的输出力矩/角度构成**机械字母表 A_mech**，迟滞回线定义**可传输的转移关系 G_mech**（哪些跳变能直接传、哪些必须先驻留/抖动），空回与编码器分辨率定义**字母表的分辨率 δ**。于是“给关节发一条力矩指令序列”＝“在机械语言里说一句话”；**不能传输的指令不是“执行偏差”，而是“语法错误”**。关键反直觉点：**安全性不该定义在语义指令上，而该定义在机械等价类上**——“轻推”与“重推”两个语义不同的 token 可能落在同一个空回死区里，产生完全相同的力矩；若证书按语义 token 发放，就存在**别名攻击（aliasing attack）**。

**灵感 2（大语言模型 → 波发生器，而非执行器）**
直觉：LLM 与波发生器在结构上同构：LLM 以高频、低承诺的 token 流“扰动”上下文，波发生器以高频、低扭矩的偏心运动“扰动”柔轮；LLM 的输出只有在 grounding（接地）后才获得权威，波发生器的运动只有在柔轮啮合后才获得扭矩。因此 LLM 的正确位置是**波发生器**：它只能**在柔性包络 F 内变形意图**，绝不能直接驱动**刚轮（刚性安全集 S）**。核心创新：**意图变形治理器（IDG）+ 本体感受分词器与迟滞语言模型（PT-HLM）**。IDG 强制 `Exec = S ∩ deform_F(intent)`，LLM 对 S 无写权限；PT-HLM 把关节力矩/角度/温度历史分词为离散 token，用自回归下一 token 预测来估计**迟滞状态**（相当于给机械信道维护一份“KV cache”），并给出共形校准的预测证书。关键反直觉点：**LLM 在安全关键控制里最危险的不是“它算错力矩”，而是“它以为自己算对了”**——即语义上自洽、但机械语法上不可解析的指令（transmission hallucination）。

**灵感 3（两者相乘 → 传输幻觉与双齿奇偶）**
直觉：语义幻觉（token 看似合理但未接地）与机械丢失运动（指令已发但未传出）是**两级串联的损失信道**，它们的误差不是简单相加，而是**在死区边界上相乘放大**：LLM 认为“已经推到位”，减速器却因空回没传过去，编码器读到的又是电机侧而非输出侧——三方各自“自洽”，端到端却错。核心创新：**传动证书（TC）+ 机械语法解析器（MGP）+ 双齿奇偶滑移检测（PSD）**。TC 给出 `(δ, h, ε_kin, κ, B_dwell)`：分辨率、迟滞宽度、运动学误差界、刚度包络、驻留预算；MGP 把 LLM 的意图句子解析到 G_mech，返回最小编辑距离 `d_edit`（“传输幻觉距离”）；PSD 用谐波减速器“2 齿差”的隐喻维护**语义证书与机械证书的奇偶差** `P=|cert_sem − cert_mech|`，超过 margin 即判“齿滑”（engagement 丢失）。关键反直觉点：**端到端安全 = “句子能被机械语法以有界编辑距离接受” ∧ “奇偶差在 margin 内” ∧ “迟滞来源未中断”**，三者缺一不可。

**三者如何统一**
统一为 **v16 行为层之下的传输层**：v16 回答“当前里程碑/模型阶层/预算下能安全执行哪个行为序列”（`Exec_v16`），v17 回答“这条行为序列对应的意图句子，能否被当前谐波减速器的机械语法解析、能否在迟滞与空回下被忠实传输、LLM 的语义证书与机械证书是否奇偶一致”（`Exec_v17`）。共享状态 `ζ_tx = (TC, G_mech, H_state, d_edit, P_parity, B_dwell, B_trans, ctx_len, amnesia, mode_tx)`。**TCE 回答“这条信道现在能传什么”，MGP 回答“这句话是不是合法句子”，PT-HLM 回答“迟滞状态在哪、下一步会到哪”，AQC 回答“语义同效类是否被正确合并”，IDG 回答“LLM 有没有越权”，PSD 回答“语义与机械是否还对得上”，TAS 回答“这一帧该不该为传输牺牲任务进度”**。七者不是补丁，而是“语法—信道—状态—等价—权限—一致性—调度”的传输实现链。

## 1. 研究问题（轮次升级版）

- **Q1（机械语法与别名商）**：如何从迟滞、空回、运动学误差、编码器分辨率构造机械字母表 `A_mech` 与转移语法 `G_mech`？语义 token 到机械 token 的映射 `~_mech` 如何计算？证书如何在商空间 `A_sem/~_mech` 上良定义，使别名攻击不可能？
- **Q2（迟滞状态与来源）**：PT-HLM 的 token 化与上下文窗口如何覆盖迟滞的长程依赖？当 LLM 上下文截断或控制器复位时，“传输失忆”如何检测、TC 如何膨胀、RDP（抖动再归位）如何以有限代价重建迟滞来源？共形覆盖率如何保证？
- **Q3（意图变形与权限分离）**：IDG 如何形式化“LLM 只能在柔性包络 F 内变形、对刚性集 S 无写权限”？`S ∩ deform_F(intent)` 与 v16 的 BTS 节点证书、WBC 力矩证书如何合成？编辑距离 `d_edit` 与证书下界如何联动？
- **Q4（传动感知的单调退化与活性）**：TAS 在 `(tick 预算, 里程碑, WBC 阶层, 传动余量)` 四重预算下如何保持帕累托最优？退化到“更慢、更小步、更长驻留”是否会与 v16 的时限证书冲突？全失效时能否严格退回 v16/v15？

## 2. 设计原则（在 P25–P27 基础上新增 P28–P30）

**P28 机械语法律（Mechanical Grammar Law）**
每条由 LLM/上层生成的意图句子 `s=(a_{i1},…,a_{ik})` 必须在机械语法 `G_mech` 下以有界编辑距离被接受：`d_edit(s, L(G_mech)) ≤ d_max(TC)`。证书必须定义在**机械等价类**上：若 `a ~_mech a'`（同一机械效果），则 `cert(a)=cert(a')`。任何按语义 token 而非机械等价类发放的证书一律视为不可靠。

**P29 迟滞来源律（Hysteresis Provenance Law）**
传动证书 TC 仅在迟滞状态来源完整时有效：历史长度 `≥ L_settle`、上下文未被截断、控制器未复位、温度/磨损估计未过期。来源中断即“传输失忆”，TC 必须膨胀 `+h_max`（迟滞最大环宽），且在执行前必须经 RDP（抖动再归位）重建，否则只能执行 `Fallback`。

**P30 意图变形分离律（Intent–Deformation Separation Law）**
LLM 只拥有柔性包络 F 的变形权，刚性安全集 S 的写权限恒为零：`Exec = S ∩ deform_F(intent)`，且 `deform_F(intent) ⊆ F`。语义证书与机械证书必须满足**双齿奇偶约束**：`P=|cert_sem − cert_mech| ≤ margin_parity`，否则判“齿滑”并回退。两证书的“齿差”即安全余量，不得单方面扩大。

## 3. 与基线的接口（如何退化）

- TCE 失效 ⇒ 常数保守 TC：`(δ, h_max, ε_kin_max, κ_min, B_dwell_max)`，等价 v16 的 WBC 力矩证书；
- MGP 失效 ⇒ 恒等解析：所有句子 `d_edit=0`，退化为 v16 的 BTS 节点执行，**等价 v16（+TCE）路径**；
- PT-HLM 失效 ⇒ 无迟滞预测：TC 膨胀到 `h_max` 且强制低频小步，**等价 v16（+TCE+MGP）保守路径**；
- AQC 失效 ⇒ 关闭别名合并，退化为按语义 token 发证的 v16 路径，**等价 v16（+TCE+MGP+PT-HLM）路径**（并触发引理 138 的旁路告警）；
- IDG 失效 ⇒ 关闭 LLM 直写通道，仅用 v16 BTS，**等价 v16（+TCE+MGP+PT-HLM+AQC）路径**；
- PSD 失效 ⇒ 奇偶约束恒真，但保守回退到 v16 WBC 证书，**等价 v16 路径**；
- TAS 失效 ⇒ 静态优先级调度，无传动感知退化，**等价 v16 CSC 调度路径**；
- 全失效 ⇒ MetricVoiceGauge-NCD-HUTDH-v16，再沿 v16→v15→…→v6 退化链退回；
- **安全继承**：TCE 只收紧力矩/速率边界，MGP 只删减非法转移，PT-HLM 只膨胀证书，AQC 只合并同效类（不新增授权），IDG 只收缩权限，PSD 只触发回退，TAS 只做单调退化。七端口互不相交，均不能新增授权或放宽阈值；`Exec_v17⊆Exec_v16` 由引理 143 保证。

## 4. 预期贡献

1. **机械语言/机械语法**：首次把谐波减速器的迟滞、空回、运动学误差形式化为一门有字母表与转移语法的“机械语言”，把“执行偏差”重写为“语法错误”，给出可解析性判据；
2. **别名商证书**：发现并形式化“语义别名攻击”——语义不同、机械同效的 token 若按语义发证会绕过安全边界；给出商空间证书与别名不变性的充要条件；
3. **迟滞来源与传输失忆**：把减速器的迟滞状态建模为需要“来源证明”的长程上下文（机械 KV cache），给出上下文截断/控制器复位下的证书膨胀与 RDP 再归位；
4. **LLM 作为波发生器**：提出意图变形治理器，把 LLM 的权限严格限制在柔性包络内，给出“语义证书 × 机械证书”的双齿奇偶滑移检测；
5. **四重单调退化**：在 v16 的三重退化上增加“传动余量”轴，实现“更慢/更小步/更长驻留”的传动感知退化，保持帕累托最优；
6. **语义—行为—动力学—传输—实现五层分离**：v12 管“允许什么”，v13 管“时限内实现多少”，v15 管“技能如何扩散”，v16 管“行为如何按里程碑执行”，v17 管“意图如何被机械信道忠实传输”，用 `Exec_v17⊆Exec_v16⊆…` 全解耦；E691–E710 覆盖机械语法、别名、迟滞来源、失忆、奇偶滑移、四重退化、端到端与消融。

## 5. 本轮最大风险

**一句话**：机械语法 `G_mech` 与别名商 `~_mech` 都建立在“减速器的迟滞/空回参数在标定窗口内平稳”这一假设上，但谐波减速器的柔轮疲劳、润滑退化、温升与磨损会让 `G_mech` 与 `~_mech` **缓慢漂移**——当语法本身在漂移时，昨天合法的句子今天可能是语法错误，昨天同效的别名今天可能分叉；若 TC 与 PT-HLM 用过期参数发证，系统会在“每句话都通过昨天语法、每个证书都在昨天商空间内自洽”的表象下，执行一个**语义与机械昨天对齐、今天却已错位**的动作。

## 0. 核心符号体系（定义 657–686）

| 符号 | 含义 |
|---|---|
| `A_mech = {a_1,…,a_M}` | 机械字母表：在分辨率 δ 下可分辨的输出力矩/角度级别 |
| `δ = lost + h + enc_res` | 机械分辨率：空回 + 迟滞宽度 + 编码器分辨率合成的可分辨下限 |
| `G_mech = (A_mech, →)` | 机械语法：转移 `a_i→a_j` 可传当且仅当满足迟滞驻留/速率条件 |
| `L(G_mech)` | 合法传输句子集合 |
| `s = (a_{i1},…,a_{ik})` | 意图句子（TCIC/LLM 生成） |
| `d_edit(s, L)` | s 到 L 的加权最小编辑距离（替换/插入/删除） |
| `~_mech` | 机械等价关系：`a ~_mech a'` 当且仅当在 TC 下产生同一可观测输出 |
| `[a] = A_sem/~_mech` | 机械等价类（别名商） |
| `TC = (δ, h, ε_kin, κ, B_dwell)` | 传动证书 |
| `h` | 迟滞环宽（力矩-扭转回线的最大宽度） |
| `ε_kin` | 运动学误差界（啮合相位周期函数的上界） |
| `κ` | 扭转刚度包络（分段非线性，含 `κ.rate_max` 力矩速率上界） |

| `S` | 刚性安全集（证书硬约束） |
| `deform_F(intent)` | 在 F 内的意图变形结果 |

| `B_trans` | 传输预算（本帧可传的有效扭矩量子数） |

| `τ_cmd, τ_ach` | 指令力矩与达成力矩 |
| `θ_m, θ_o` | 电机侧角与输出侧角 |
| `cert_sem, cert_mech` | 语义证书与机械证书（下界） |

from dataclasses import dataclass
from collections import deque
import numpy as np

@dataclass
class TransmissionCertificate:
    delta: float        # 机械分辨率
    h: float            # 迟滞环宽
    eps_kin: float      # 运动学误差界
    kappa: object       # 刚度包络（含 rate_max）
    B_dwell: int        # 驻留预算
    def cert_mech(self):
        return max(0.0, 1.0 - (self.h / 2 + self.eps_kin + self.delta))

@dataclass
class HysteresisState:
    L_hist: int
    sign: int           # 正/反行程
    loop_pos: float     # 环内归一化位置 [0,1]
    temp: float


# IP-416 Transmission Certificate Estimator：历史相关传动证书
class TransmissionCertificateEstimator:
    def __init__(self, reducer_spec, telemetry, wear_forecaster):
        self.spec = reducer_spec              # 齿数/刚度/空回标称/encoder_res/L_settle
        self.tel = telemetry                  # (tau_cmd, tau_ach, theta_m, theta_o, temp)
        self.wlf = wear_forecaster            # IP-425：磨损/RUL 漂移告警
        self.history = deque(maxlen=reducer_spec.L_hist_max)
        self.controller_reset = False

    def estimate(self, x, ctx_len):
        self.history.append(self.tel.snapshot())

        # 1) 分辨率 δ = 空回 + 迟滞宽度 + 编码器分辨率
        lost = self._lost_motion(self.history)
        hyst = self._hysteresis_width(self.history)
        delta = lost + hyst + self.spec.encoder_res

        # 2) 迟滞状态与收敛性
        h_state, settled = self._hysteresis_state(self.history)

        # 3) 传输失忆：历史不足 / 上下文过短 / 控制器复位
        amnesia = ((len(self.history) < self.spec.L_settle)
                   or (ctx_len < self.spec.ctx_min)
                   or self.controller_reset)

        # 4) 磨损漂移告警（慢变量）
        wear_alert = self.wlf.drift_alert()   # 0 表示无告警

        # 5) 证书：失忆或磨损漂移时单调膨胀（只增不减）
        h = hyst if not amnesia else self.spec.h_max
        if wear_alert > 0:
            h = max(h, self.spec.h_max * (1.0 + wear_alert))
        eps_kin = self._kinematic_error_bound(self.history)
        kappa = self._stiffness_envelope(self.history)
        B_dwell = self.spec.B_dwell_max if amnesia else self._dwell_budget(h)

        tc = TransmissionCertificate(delta, h, eps_kin, kappa, B_dwell)
        return tc, h_state, amnesia


# IP-417 Mechanical Grammar Parser：机械语法与编辑距离
class MechanicalGrammarParser:
    def __init__(self, tc, spec):
        self.tc = tc
        self.spec = spec
        self.A = self._build_alphabet(tc.delta)     # 机械字母表
        self.G = self._build_grammar(tc)            # 转移关系（含驻留/速率约束）

    def parse(self, sentence):
        """返回 (accepted, d_edit, repaired_sentence)"""
        d, path = self._min_edit(sentence, self.G)  # 动态规划到 L(G_mech)
        accepted = d <= self._d_max(self.tc)
        repaired = self._repair(sentence, path) if accepted else None
        return accepted, d, repaired

    def _transition_ok(self, a, b):
        rate_ok = abs(b - a) <= self.tc.kappa.rate_max
        dwell_ok = self._dwell_needed(a, b) <= self.tc.B_dwell
        return rate_ok and dwell_ok

    def _min_edit(self, s, G):
        # 替换为最近合法字母、插入驻留符号、删除不可传转移，均计入加权距离
        # 返回最小距离及修复路径（略去 DP 细节）
        return self._dp(s, G)

    def _d_max(self, tc):
        return max(0, int(tc.B_dwell // self.spec.tick_per_dwell))


# IP-418 Proprioceptive Tokenizer + Hysteresis Language Model
class HysteresisLanguageModel:
    def __init__(self, tokenizer, model, calibrator, ctx_len):
        self.tok = tokenizer          # 连续量 → 离散 token（力矩/角度/温度分桶）
        self.model = model            # 自回归下一 token 预测（LLM 式注意力）
        self.cal = calibrator         # 共形校准
        self.ctx_len = ctx_len
        self.kv = {}                  # 机械 KV cache：H_state 的低维投影

    def predict(self, history):
        tokens = self.tok.encode(history)
        ctx = tokens[-self.ctx_len:]
        logits = self.model(ctx, kv_cache=self.kv)      # 下一 token 分布
        h_next = self.tok.decode_hysteresis(logits)     # 迟滞状态预测
        lower = self.cal.lower(logits, alpha=0.05)      # 共形下界
        coverage = self.cal.coverage()
        return h_next, lower, coverage

    def commit(self, h_next):
        self.kv = self.tok.to_kv(h_next)                # 更新机械 KV cache


# IP-419 Aliasing Quotient Certifier：别名商证书
class AliasingQuotientCertifier:
    def __init__(self, tc, tol=1e-6):
        self.tc = tc
        self.tol = tol
        self.registry = {}            # mech_signature -> cert

    def mech_signature(self, token):
        # 在 TC 下把语义 token 投影为可观测输出签名（量化到 δ）
        tau = self._semantic_to_torque(token)
        return round(tau / max(self.tc.delta, 1e-9))

    def quotient(self, semantic_tokens):
        classes = {}
        for t in semantic_tokens:
            classes.setdefault(self.mech_signature(t), []).append(t)
        return classes

    def certify(self, token, cert):
        sig = self.mech_signature(token)
        if sig in self.registry and abs(self.registry[sig] - cert) > self.tol:
            raise AliasingViolation(token, sig)         # 同效类证书不一致 → 阻断
        self.registry[sig] = cert
        return cert


# IP-420 Intent Deformation Governor：意图变形治理
class IntentDeformationGovernor:
    def __init__(self, F, S):
        self.F = F       # 柔性包络（LLM 可变形）
        self.S = S       # 刚性安全集（LLM 只读）

    def govern(self, intent):
        if not self.F.contains(intent):
            intent = self.F.project(intent)             # 只能拉回 F，不能扩 F
        deformed = self.F.deform(intent)                # 在 F 内变形
        exec_set = self.S.intersect(deformed)           # 刚性集不可写
        return exec_set, deformed


# IP-421 Parity Slip Detector：双齿奇偶滑移检测
class ParitySlipDetector:
    def __init__(self, margin):
        self.margin = margin

    def check(self, cert_sem, cert_mech):
        P = abs(cert_sem - cert_mech)
        slip = P > self.margin
        return (not slip), P


# IP-422 Transmission-Aware Scheduler：四重单调退化
class TransmissionAwareScheduler:
    def __init__(self, csc_v16, tce, mgp, psd, B_max):
        self.csc = csc_v16
        self.tce = tce
        self.mgp = mgp
        self.psd = psd
        self.B_max = B_max

    def schedule(self, x, hw, sw, data, intent, cert_sem, ctx_len, drift=False):
        tc, h_state, amnesia = self.tce.estimate(x, ctx_len)

        # 传输失忆：先 RDP 再降级
        if amnesia:
            return self._rdp_then_degrade(x, tc, intent)

        accepted, d_edit, repaired = self.mgp.parse(intent)
        if not accepted:
            return self._fallback(x, 'grammar')          # 语法错误 → 回退

        parity_ok, P = self.psd.check(cert_sem, tc.cert_mech())
        if not parity_ok:
            return self._fallback(x, 'slip')             # 齿滑 → 回退

        # 四重预算：(B_tick, m, h, 传动余量 g = d_max - d_edit)
        plan = self._solve4(x, tc, d_edit, drift)
        return self._execute(plan, repaired)

    def _solve4(self, x, tc, d_edit, drift):
        if drift:
            return {'m': 1, 'h': 0, 'g': 0, 'dwell': tc.B_dwell, 'nodes': []}
        # 贪心回溯：从 (m*, h_max, g_max, B_dwell_max) 向下枚举
        # 价值 val 关于各轴单调，退化只允许逐轴下降
        return self._greedy_backtrack(x, tc, d_edit)

    def _execute(self, plan, repaired):
        # 把修复句按驻留预算拆分为 tick 序列，交给 v16 BTS/WBC 执行
        return self.csc.execute_with_dwell(plan, repaired)


# IP-423 Re-homing/Dithering Procedure：抖动再归位
class RehomingDitheringProcedure:
    def __init__(self, amp, freq, cycles, tce):
        self.amp, self.freq, self.cycles = amp, freq, cycles
        self.tce = tce

    def run(self, x, ctx_len):
        # 小振幅往返遍历迟滞回线，重建 H_state 来源
        for k in range(self.cycles):
            tau = self.amp * np.sin(2 * np.pi * self.freq * k)
            execute(tau)
            self.tce.history.append(self.tce.tel.snapshot())
        self.tce.controller_reset = False
        return self.tce.estimate(x, ctx_len)


# IP-424 Transmission-Certified Intent Compiler（LLM 侧）
class TransmissionCertifiedIntentCompiler:
    def __init__(self, llm, mgp, idg):
        self.llm = llm
        self.mgp = mgp
        self.idg = idg

    def compile(self, task_nl):
        draft = self.llm.generate_intent(task_nl)       # 自然语言 → 意图句子草稿
        accepted, d_edit, repaired = self.mgp.parse(draft)
        if not accepted:
            draft = self.llm.repair(draft, self.mgp.feedback(d_edit))
        exec_set, _ = self.idg.govern(repaired or draft)
        return exec_set, d_edit


# IP-425 Wear-Language Forecaster：遥测 token 序列 → 磨损/RUL
class WearLanguageForecaster:
    def __init__(self, model, window):
        self.model = model
        self.window = window

    def drift_alert(self):
        tokens = self.model.encode_recent(self.window)
        rul = self.model.predict_rul(tokens)
        # RUL 越低，告警越大；返回 [0,1] 的膨胀系数
        return float(np.clip(1.0 - rul / self.model.nominal_life, 0.0, 1.0))


# 主闭环集成：MetricVoiceGauge-NCD-HUTDH-v17（机械传输层）
def metricvoicegauge_round_17_transmission(M, s, obs, intent=None, ...):

    # ---- 低频异步：TC 重标定、语法重建、磨损告警 ----
    if cycle_idx % T_tc_calib == 0:

    return C, spatial_cert, claims, metrics, rewards

## 2. 推导（引理 137–144）

**引理 137（两级损失信道的误差次可加性）** 设语义接地误差为 `ε_sem`，机械传输误差由 `(h, ε_kin, δ)` 界定，别名折叠误差为 `ε_alias`。则端到端“意图—达成关节状态”误差满足
`‖θ_ach − θ_intent‖ ≤ ε_sem + h/2 + ε_kin + δ + ε_alias`。
证明：按三角不等式把链路分解为“语义→指令→机械 token→输出”三段。迟滞贡献不超过半环宽（最坏方向未知，取对称上界）；运动学误差与分辨率按定义相加；别名折叠把语义差异映射到同一机械 token，其不可恢复部分计入 `ε_alias`。∎
推论：**两级串联信道的证书不能各自独立发放**，必须至少有一方承担 `h/2 + ε_alias` 的公共余量。

**引理 138（别名不变性的必要性）** 若证书 `cert(·)` 不满足 `a ~_mech a' ⇒ cert(a)=cert(a')`，则存在两条语义可区分、机械同效的指令 `a, a'`，使得 `cert(a) ≠ cert(a')`，从而攻击者可选择语义收益更大的 token 而绕过针对另一 token 的安全约束。
证明：由 `~_mech` 定义，两者产生同一可观测输出；若证书不同，则一条宽松一条严格，执行结果物理等价而安全判定不同，构成证书旁路。∎
推论：**别名商上的证书是唯一可靠的安全对象**；语义 token 级证书必然存在旁路。

**引理 139（迟滞来源与失忆膨胀）** 若历史长度 `< L_settle`，或 `ctx_len < ctx_min`，或控制器复位，则迟滞状态 `H_state` 不确定，TC 的真实环宽可达成 `h_max`；此时若仍用 `h < h_max` 发证，则存在一条在真实迟滞下输出偏离超过 `h` 的合法句子。
证明：迟滞回线的当前分支由历史决定；历史不足时任一分支都可能，故上界必须取 `h_max`。∎
推论：**传输失忆必须膨胀证书并触发 RDP**；RDP 用幅值 `≥ δ`、周期 `≥ 2π/ω_settle` 的抖动遍历回线，重建 `H_state` 后再收缩证书。

**引理 140（语法约束的意图可靠性）** 若 `d_edit(s, L(G_mech)) ≤ d_max(TC)` 且 `s` 经 MGP 修复为 `s*∈L(G_mech)`，则修复引入的额外力矩偏差 `≤ d_max(TC)·δ`，且执行动作落在 v16 证书集内。
证明：每次编辑最多改变一个机械 token，其力矩差 `≤ δ`；MGP 只做删除/驻留插入/最近合法替换，不新增超出 `G_mech` 的转移；因此 `s*` 的物理轨迹仍在 v16 WBC 证书包络内。∎
推论：**`d_max(TC)` 是“允许说错几个字”的预算**，与 `B_dwell` 共同决定传输保真度。

**引理 141（双齿奇偶滑移检测）** 设无滑移时 `|cert_sem − cert_mech| ≤ margin_parity`。若发生齿滑（柔轮/刚轮啮合丢失或空回突增），则 `P` 以至少 `1-α` 概率超过 `margin_parity`，其中 `α` 为共形校准误报率。
证明：滑移使机械证书下界至少下降 `Δ_slip`，而语义证书不变，故 `P` 增加 `Δ_slip`；共形校准保证名义分布外 `P` 的尾部被 `α` 界定。∎
推论：**2 齿差既是减速比来源，也是“两证书必须同步”的物理隐喻**；奇偶差即安全余量。

**引理 142（四重单调退化的帕累托保持）** 在 v16 的三重预算 `(B_tick,m,h)` 上增加传动余量轴 `g = d_max − d_edit ≥ 0` 与驻留预算 `B_dwell`，且退化只允许 `g↓, B_dwell↓, h↓, m↓, B_tick↓`，则 TAS 的贪心回溯在 `val` 关于各轴单调时仍返回帕累托最优解。
证明：新增轴只缩小可行域，不改变 v16 引理 134 的单调性前提；枚举顺序加入 `(g, B_dwell)` 的字典序，子域最优性沿归纳保持。∎
推论：**传动退化 = “说得更慢、更小步、等更久”**，与时限退化同构，不需要新的求解器。

**引理 143（v17 对 v16 的安全包含）** 若 TCE/MGP/PT-HLM/AQC/IDG/PSD/TAS 均满足各自中立元条件，则 `Exec_v17 ⊆ Exec_v16`；任一组件失效时，其余组件仍不能新增授权或放宽阈值，故全失效时严格退回 v16，再沿退化链退回 v15→…→v6。
证明：各组件作用分别是收紧力矩/速率（TCE）、删减转移（MGP）、膨胀证书（PT-HLM）、合并同效类（AQC，不增授权）、收缩权限（IDG）、触发回退（PSD）、单调降轴（TAS），均为交/减运算，无并/增运算；由引理 137–142，组合仍保持子集关系。∎

**引理 144（传输幻觉的联合界）** 设 `R_conf` 为 PT-HLM 的共形风险、`μ_alias` 为别名商未区分的语义差异测度、`μ_amnesia` 为失忆事件概率。则“通过证书但物理非意图”的传输幻觉概率满足
`P(hallucination) ≤ R_conf + μ_alias + μ_amnesia`。
证明：事件可分解为三类——预测越界（共形尾部）、别名折叠（商空间丢失的语义差异）、来源中断（失忆）；由概率次可加性得界。∎
推论：**降低传输幻觉不能只靠更大的 LLM**，必须同时压低 `μ_alias`（更细的机械分辨率/更好的标定）与 `μ_amnesia`（更长的上下文/更稳的控制器）。

## 6. 已知风险与失效模式

1. **机械语法与别名商的缓慢漂移**：柔轮疲劳、润滑退化、温升使 `G_mech` 与 `~_mech` 随时间变化，昨日合法的句子今日可能非法、昨日同效的别名今日可能分叉。缓解：WLF 漂移告警、TC 参数在线重标定、语法版本化与金丝雀验证、保守取上界。

2. **别名商的测度估计偏差**：`μ_alias` 依赖对语义 token 空间的采样，采样偏差会低估别名质量。缓解：主动边界采样、对抗近义 token、Clopper-Pearson 保守下界。

3. **PT-HLM 的分布外泛化**：磨损/换件/极端温度下的迟滞回线可能超出训练分布，共形覆盖率失效。缓解：在线微调、分布漂移检测、超出即膨胀到 `h_max`、按工况分簇校准。

4. **RDP 抖动本身的安全代价**：再归位需要小振幅往返运动，在狭窄/接触环境中可能碰撞或扰动负载。缓解：幅值/周期按环境间隙自适应、RDP 前做碰撞检查、优先选择无接触时段。

5. **编辑距离修复的累积偏差**：连续多帧 `d_edit` 接近 `d_max` 时，修复偏差沿时间累积，可能超出单帧证书。缓解：跨帧偏差预算、修复偏差计入 TC、连续修复触发语法重编译。

6. **双齿奇偶的共模失效**：`cert_sem` 与 `cert_mech` 可能共享同一路错误遥测，导致奇偶差为零却同时错误。缓解：双通道独立遥测（电机侧/输出侧）、共模故障注入测试、奇偶余量随磨损收紧。

7. **上下文窗口与实时性的冲突**：PT-HLM 需要长上下文覆盖迟滞，但长上下文增加时延。缓解：分块 KV cache、只保留迟滞充分统计量、离线蒸馏短上下文模型。

8. **慢变量与快变量的时间尺度失配**：磨损是小时级慢变量，证书是毫秒级快变量；WLF 告警滞后时 TC 可能已高估。缓解：多尺度滤波、保守包络、按累计转角而非仅时间触发重标定。

9. **LLM 意图编译器的语义歧义**：同一自然语言任务可编译出多条机械语法上合法但任务语义不同的句子。缓解：任务级证书、意图多样性检查、人工确认高风险任务、受限解码。

10. **机械字母表与编码器量化的混叠**：δ 若小于编码器分辨率，字母表会虚增可分辨级别，导致“假精细”。缓解：δ 取 `max(lost+h, enc_res)`、输出侧编码器校验、量化误差入证书。

11. **多关节耦合下的 TC 组合爆炸**：全身多关节的语法/证书需联合验证，维度升高导致组合爆炸。缓解：按运动链分解、证书投影到任务子空间、只对耦合强的关节联合验证。

12. **v17 与 v16/v15 证书栈的累积保守性**：传动层再取交集与减间隙，可能使可用证书下界衰减到接近零。缓解：证书价值加权、选择性放宽（需形式化证明）、动态 α、元认证监控余量。

## 7. 本轮最大风险

**一句话**：机械语法 `G_mech` 与别名商 `~_mech` 都建立在“减速器的迟滞/空回参数在标定窗口内平稳”这一假设上，但柔轮疲劳、润滑退化、温升与磨损会让语法本身缓慢漂移——当语法在漂移时，昨天合法的句子今天可能是语法错误，昨天同效的别名今天可能分叉；若 TC 与 PT-HLM 用过期参数发证，系统会在“每句话都通过昨天语法、每个证书都在昨天商空间内自洽”的表象下，执行一个**语义与机械昨天对齐、今天却已错位**的动作——即**语法自洽、奇偶自洽、来源自洽，却因语法本身漂移而绝对不安全**的传输决定。
