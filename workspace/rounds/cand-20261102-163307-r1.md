# 第 16 轮（研究线累计；本轮灵感循环第 2 轮）· ZEST-VLA/REAL：把「合成实验」搬到真机，用自校准残差、认证原语、工具调用内核跨越 Sim-to-Real 鸿沟

> 检索/复核日期：**2026-11-02（UTC）**。赛事身份不变：宇树 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API。本轮三个词是「仿真到现实」「痛点分析」「工具调用」。**不推倒**第 15 轮 ZEST-VLA；本轮在其之上加一个**实机桥接层**：把合成实验里的「标量代理残差」换成真实几何前端、把「手工原语」换成带 CBF 证书的认证原语、把「单体 PolicyService」拆成声明式工具调用内核。

## 0. 先给直觉：第 15 轮在合成实验里跑通了，但真机上有三道「鸿沟」

第 15 轮 ZEST-VLA 的合成实验（`exp/zest_sim.py`）做了一个关键简化：**残差是标量代理，VLA 是每步伯努利成功率，fallback 原语有固定成功率/成本**。真实 G1 + Dex1 上，这三个假设全破裂：

| 假设 | 合成实验 | 真实痛点 |
|---|---|---|
| 残差计算 | 标量噪声模型 | 头双目深度在透明/反光/遮挡下极噪；光流需要 GPU、延迟 10–30ms；FK 累积误差；无腕部相机内参 |
| VLA 行为 | 独立同分布成功率 | 30 步块内强时序相关；远程 API 延迟 50–200ms、抖动、偶发超时；冷启动 2–3s |
| Fallback 原语 | 固定 `g_true`、`c_f` | 真实接触阻尼/摩擦不确定；几何原语会卡死、碰撞、超力；需要安全证书 |

**痛点分析的核心结论**：第 15 轮的信任门在「残差可信」时有效；但真机上**残差本身不可信**，且 **fallback 原语无安全兜底**。如果直接把合成实验的阈值 `α=0.12, k=0.05, h=2.5` 烧到真机，会得到两种灾难：
1. **残差虚高** → 信任门频繁误触发 → 过度 fallback → 任务超时、效率崩塌
2. **残差虚低** → 信任门漏报 → VLA 自信执行错误动作 → 碰撞/损坏

所以本轮的直觉是：**把 Sim-to-Real 不是当部署问题，当建模问题**。给每个残差通道建立「真实噪声模型 + 在线校准器」；给每个 fallback 原语建立「CBF 安全证书 + 可达性包络」；把整个 PolicyService 重构为**工具调用内核**，每个组件是纯函数工具，带 SLO（延迟上界、内存上界、失败模式），支持热替换和形式化延迟分析。

一句话先给押注：

> **第 15 轮在合成实验里证明了「自监督信任门 + 几何降级」的机制可行；本轮把它变成真机可部署的系统：三个残差通道各自带「噪声感知归一化 + 自校准 conformal」；每个 fallback 原语带 CBF 证书与可达性前置检查；PolicyService 变成声明式工具 DAG，端到端 p99 < 150ms 可证明。零样本泛化在真机上不是「跑通合成实验」，而是「残差、原语、调度三件套各自通过实机门 G13–G16」。**

三个可验证创新点：

1. **自校准残差通道（self-calibrating residual channels）**：每个通道维护「在线噪声模型 + 置信度加权 conformal」，用信任门自己判定的高置信 TRUST 段做滑动校准，消除 Sim-to-Real 的分布漂移；透明/反光/遮挡时自动降权或禁用通道。
2. **认证几何原语库（certified primitive library）**：每个原语附带 Control Barrier Function (CBF) 证书，给出前向不变集与最大允许干扰；运行时做「可达性前置检查」，不通过则原语不可用，避免「盲目降级撞环境」。
3. **工具调用策略内核（tool-calling policy kernel）**：把 PolicyService 拆为 `ResidualCalculator`、`TrustGate`、`VOIScheduler`、`PrimitiveExecutor`、`VLAClient` 五类纯函数工具，带类型签名、SLO、失败模式；调度器按 DAG 编排，支持形式化 WCET 分析、热替换、单模型合规审计。

三个词怎么落地：

| 词 | 落地 | 不做什么 |
|---|---|---|
| **仿真到现实** | 不是 domain randomization，而是**残差通道在线校准 + 原语 CBF 认证 + 内核 WCET 证明**；用 G13 残差校准门、G14 原语认证门、G15 延迟门 | 不做 sim-only 训练；不假设 sim 和 real 残差分布对齐；不把「跑通仿真」当证据 |
| **痛点分析** | 显性列出 12 个真机痛点（深度噪声、API 抖动、接触不确定、校准漂移…），每个痛点对应一个工程对策和一个验证门 | 不做泛泛而谈；不把痛点藏在脚注；每个痛点必须有对应的代码模块和测试用例 |
| **工具调用** | PolicyService = 工具 DAG；每个工具是纯函数、带 SLO、可热替换；VLAClient 是异步工具、有熔断/重试/降级 | 不引入 LLM 工具调用；不做动态规划；工具集在评测前冻结，运行时只做编排 |

## 1. 研究日志：为什么是这一层

### 1.1 第 15 轮留下的四个「实机未付费假设」

```text
B1. 残差分布对齐：合成实验的标量噪声模型 ≈ 真实几何前端的残差分布。
B2. VLA 延迟确定：VLA 推理 + 网络延迟 ≪ 5 步块周期（100ms），不阻塞控制环。
B3. 原语成功率常数：fallback 原语有固定 `g_true`，不依赖接触状态/环境几何。
B4. 单体部署可行：PolicyService 单进程、单线程、无 GC 抖动、p99 < 150ms。
```

第 15 轮合成实验**全假设了 B1–B4**。本轮要一个个付账。

### 1.2 三个新判断

1. **残差通道必须「自带噪声模型 + 自校准」**。头双目深度在透明物体上方差可达 ID 的 10 倍；光流在纹理少区域退化。不能用一个全局 `σ_k`；要把「观测质量」显性建模进归一化：`z_k = r_k / (σ_k · q_k)`，其中 `q_k ∈ [0,1]` 是质量因子（视差置信度、图像梯度、目标可见性）。conformal 分位数 `q_α` 也要**在线滑动更新**：只用信任门判定为「高置信 TRUST」的块做校准，实现分布漂移下的自适应覆盖。
2. **几何原语必须「带证书」**。手写原语在仿真里 `g_true=0.8`；真机上 `REACH` 可能因遮挡规划失败，`GRASP` 可能因摩擦不足滑落，`INSERT` 可能因公差卡死。每个原语必须给出：
   - **CBF 证书**：`h(x) ≥ 0` 定义安全集，证明在控制律下前向不变；
   - **可达性包络**：从当前状态出发，在时限 `T` 内能否到达目标集（HJ reachability 或凸近似）；
   - **最大允许干扰**：接触力/位姿误差的上界，超界则原语标记 `UNSAFE`。
   调度器只在「证书通过 + 可达性通过」时把 `FALLBACK` 加入可选动作集。
3. **策略内核必须「工具化」**。第 15 轮的 `ZestPolicy` 类把残差、门控、调度、原语执行、VLA 通信全耦在一起；真机上这会导致：GC 抖动、延迟不可分析、无法热替换单个模块、单模型合规审计困难。拆成**纯函数工具 + 声明式 DAG**，每个工具：
   - 类型签名：`Input → Output`（无副作用，或副作用显性建模为 `State → (Output, State')`）
   - SLO：`latency_p99 ≤ X ms, mem ≤ Y MB, failure_modes = {...}`
   - 熔断/重试/降级策略内置
   调度器按拓扑序执行 DAG，总 WCET = Σ 工具 WCET + 编排开销，可形式化验证。

### 1.3 与第 15 轮的分层关系（升级版）


**保留**：第 15 轮的全部数学结构（残差定义、conformal/CUSUM、调度规则、失败模式分类）。
**升级**：
- 残差通道：固定权重 + 固定校准 → **质量加权 + 在线自校准 conformal**

## 2. 机制草图（形式化见产物区）

### 2.1 质量感知的自校准残差通道

每个通道 `k ∈ {tmp, geo, goal, dyn}` 维护：

```text
r_k          : 原始残差（第 15 轮定义）
q_k ∈ [0,1]  : 质量因子，实时计算
  - tmp: 重叠时域长度 / 标准长度
  - geo: 视差置信度中位数 × 目标可见性 × (1 - 透明度分数)
  - goal: 目标后验熵倒数 × 接触阶段指示
  - dyn: 1（确定性信号，无质量衰减）
σ_k          : 滑动 MAD，仅在 q_k > τ_q 的块上更新
z_k = r_k / (σ_k · max(q_k, ε_q))   # 质量归一化
```

**自校准 conformal**：
- 维护滑动校准窗口 `C = {s_b | mode=TRUST ∧ c_b > τ_c ∧ q_min > τ_q}`，大小 `N_cal`。
- `q_α = Quantile_{1-α}(C)`；窗口不足时回退到离线校准值。
- 这把「ID 可交换性假设」局部化：只假设**近期高置信 TRUST 块**与当前块可交换，而非全局 ID 分布不变。

### 2.2 CBF 认证的几何原语

每个原语 `π_prim` 附带三元组 `(h, R, d_max)`：

- **CBF `h: X → ℝ`**：安全集 `C = {x | h(x) ≥ 0}`。控制律 `u = π_prim(x)` 满足 `ḣ(x) ≥ -γ h(x)`（指数 CBF），证书在离线用区间运算/和松弛验证。
- **可达性包络 `R ⊆ X`**：从 `x ∈ R` 出发，在时限 `T` 内能到达目标集 `G` 且全程保持 `h(x) ≥ 0`。用 Hamilton-Jacobi 反向可达性或凸近似（线性化 + 多面体外包）离线计算；运行时只做 `x ∈ R` 判定。
- **最大允许干扰 `d_max`**：满足 `h(x) ≥ 0` 的最大接触力/位姿扰动范数。运行时用力传感器/视觉估计当前干扰 `d̂`，若 `d̂ > d_max` 则原语 `UNSAFE`。

**域检查升级**（第 15 轮 `domain_check` → 本轮 `certified_domain_check`）：

```text
certified_domain_check(schema, M, x_current):
    for prim in plan_primitives(schema, M):
        if not (x_current ∈ prim.R):
            return "unreachable"
        if not (estimate_disturbance() ≤ prim.d_max):
            return "disturbance_exceeds"
        if not (verify_cbf(prim.h, x_current)):
            return "cbf_violated"
    return "geometric"
```

只有 `"geometric"` 允许 `FALLBACK`；其他情况回退到 VLA/LOOK/HOLD。

### 2.3 工具调用策略内核

**工具类型签名**（示例）：

```python
# 残差计算工具：纯函数，无副作用，p99 < 5ms
ResidualCalculator: (obs_before, obs_after, plan, prev_plan, M, phase) 
    -> ResidualVector{r_tmp, r_geo, r_goal, r_dyn, quality_factors}

# 信任门工具：纯函数 + 状态更新，p99 < 1ms
TrustGate: (residuals, cal_window, cusum_state, params) 
    -> (mode, cusum_state', soft_competence, surprise)

# VOI 调度工具：纯函数，p99 < 2ms
VOIScheduler: (mode, belief, progress, budget, competence, primitive_certs) 
    -> Action{SERVO|LOOK|VLA|FALLBACK|COMMIT|HOLD}

# 原语执行工具：带副作用（发送关节指令），p99 < 3ms
PrimitiveExecutor: (primitive, args, M, x_current) 
    -> (chunk, cert_status{CBF_OK|CBF_VIOLATED|UNREACHABLE})

# VLA 客户端工具：异步、带熔断、p99 < 200ms（网络主导）
VLAClient: (obs, instruction) 
    -> AsyncResult{plan | timeout | error | circuit_open}
```

**DAG 编排**（每个 5 步块周期）：

```text
[ResidualCalculator] → [TrustGate] → [VOIScheduler] → [ActionDispatcher]
                                                         │
                              [PrimitiveExecutor] ←────┤ (若 FALLBACK)
                              [VLAClient] ←────────────┤ (若 VLA/重规划)
                              [LOOKController] ←───────┤ (若 LOOK)
                              [WAVE_SERVO] ←───────────┤ (若 SERVO/COMMIT)
```

- 所有工具**无共享可变状态**；状态显性传递（`cusum_state`, `cal_window`, `primitive_certs`）。
- 编排器是确定性的拓扑序执行器；总 WCET = Σ WCET_i + 编排开销（< 0.5ms）。
- **单模型合规**：VLAClient 是唯一调用学习模型的工具；其他工具全是确定性几何/统计计算。

### 2.4 Sim-to-Real 的三个「实机门」

| 门 | 痛点 | 验证指标 | 通过标准 |
|---|---|---|---|
| **G13-R** 残差校准门 | 真实残差分布漂移、透明/反光失效 | ID 惊讶率 ≤15%（α=0.1）、OOD-E/OOD-S AUROC ≥0.8、通道质量因子与真实误差相关性 ≥0.7 | 否 → 禁用对应通道、回退固定阈值 |
| **G14-R** 原语认证门 | fallback 原语碰撞/卡死/超力 | CBF 证书覆盖率 100%、可达性前置检查通过率 ≥90%、运行时 CBF 违例 0 次 | 否 → 缩减原语库、仅保留认证通过子集 |
| **G15-R** 延迟门 | 端到端 p99 > 150ms、GC 抖动、网络抖动 | 纯 CPU 链路 p99 < 30ms、VLAClient 熔断触发率 < 5%、全链路 p99 < 150ms | 否 → 降采样残差、缩减 DAG、强制 VLA 异步 |

## 3. 可证伪假设（新增/修改）

| 编号 | 假设 | 证伪条件 | 级别 |
|---|---|---|---|
| H1-R | 质量加权 + 自校准 conformal 在真机上把 ID 假警报控制在 ≤15% | ID 惊讶率 >20% 或 OOD-E AUROC <0.65 | 主 |
| H2-R | CBF 认证原语在几何可分解任务上成功率 ≥ VLA，且零碰撞 | 碰撞 >0 次 或 成功率 < VLA - 5pp | 主 |
| H3-R | 工具内核端到端 p99 < 150ms，且单工具热替换不破坏安全 | p99 > 150ms 或 热替换导致状态不一致 | 主 |
| H4-R | 自校准 conformal 在分布漂移下优于固定校准 | 分布漂移实验中固定校准不劣于自校准 | 次 |
| H5-R | 认证域检查不误判语义任务为 geometric | 语义任务被判为 geometric > 0 次 | 主 |

H4-R 是刻意写成「可能失败」的：如果自校准带来的方差大于偏差收益，就退回固定校准。**复杂度必须自证其值。**

## 4. 什么情况下放弃这条线

- G13-R 失败且无法通过降采样/禁用通道修复 → 退回第 15 轮固定校准 + 固定阈值门，只保留监控不降级。
- G14-R 失败且原语库缩减到 <3 个可用原语 → 砍掉 fallback，只保留信任门作为监控 + VLA 重规划。
- G15-R 失败且无法通过工具拆分/异步化修复 → 把残差计算移出关键路径（降频到 10Hz）、VLAClient 强制异步、退回单体 PolicyService。
- 真机上 OOD-G 占比 >40% 且无独立语义信号 → 承认自监督降级上限，转向 grounding/语言一致性/任务清单约束。

## 5. 一句话押注

**第 15 轮在合成实验里跑通了机制；本轮把它变成真机可部署的系统：残差通道自带噪声模型与自校准 conformal、fallback 原语自带 CBF 证书与可达性前置检查、PolicyService 重构为声明式工具 DAG 带 SLO 与 WCET 证明。Sim-to-Real 不是部署问题，是建模问题——每个鸿沟都要在代码里显性建模、在门里显性验证。**

## 6. 本轮最大的风险

**CBF 证书的保守性可能把可用原语判为 UNSAFE，导致 fallback 库在真机上几乎不可用。** 真实接触的摩擦、柔顺、建模误差会让 CBF 条件 `ḣ ≥ -γh` 很难满足，除非 γ 取得很大（极其保守）或安全集 `C` 很小（极其受限）。如果 G14-R 通过的代价是「原语库只剩 REACH/RELEASE」，那零样本降级的承诺就兑现不了。这是本轮必须在 G14-R 实测里直面的硬约束。

# 第 16 轮产物 · ZEST-VLA/REAL 技术报告

> 检索/复核日期：**2026-11-02（UTC）**。对象：宇树 **UniBot 世界挑战赛**（G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API）。本报告是研究线累计第 16 轮、也是新一轮灵感循环第 2 轮「仿真到现实 / 痛点分析 / 工具调用」的工程化产物。它在第 15 轮 **ZEST-VLA** 之上加一个**实机桥接层**，不替换第 10–15 轮任何算法组件。

## 0. 结论与边界

### 0.1 一句话结论

第 15 轮在合成实验里证明了「自监督信任门 + 几何降级」的机制可行；本轮把它变成真机可部署的系统：三个残差通道各自带「噪声感知归一化 + 自校准 conformal」；每个 fallback 原语带 CBF 证书与可达性前置检查；PolicyService 变成声明式工具 DAG，端到端 p99 < 150ms 可证明。零样本泛化在真机上不是「跑通合成实验」，而是「残差、原语、调度三件套各自通过实机门 G13-R–G16-R」。

## 2. 符号与形式化（增量）

### 2.1 质量感知残差通道

在第 15 轮残差定义基础上，增加质量因子 `q_k ∈ [0,1]`：

**时序残差质量**：
```math
q^{\mathrm{tmp}}_b = \frac{H_o}{H_{\mathrm{std}}} \in [0,1]
```
其中 `H_o` 是实际重叠时域长度，`H_std = 5`（标准 5 步重叠）。

**几何残差质量**：
```math
q^{\mathrm{geo}}_b = \underbrace{\mathrm{median}(\mathrm{disparity\_conf})}_{\text{视差置信度}}
\cdot \underbrace{\mathbb 1[\text{target visible}]}_{\text{目标可见性}}
\cdot \underbrace{(1 - \mathrm{transparency\_score})}_{\text{反透明度}}
```
`transparency_score ∈ [0,1]` 由图像梯度稀疏度 + 视差一致性启发式计算；透明/反光区域趋近 1。

**目标进度残差质量**：
```math
q^{\mathrm{goal}}_b = \underbrace{(1 - H(b_t)/H_{\max})}_{\text{目标后验确定性}}
\cdot \underbrace{\mathbb 1[\text{phase} \in \{\mathrm{APPR},\mathrm{PREC}\}] + 0.5 \mathbb 1[\text{phase} \in \{\mathrm{CONT},\mathrm{CARRY}\}]}_{\text{阶段可靠性}}
```

**动力学残差质量**：
```math
q^{\mathrm{dyn}}_b = 1 \quad \text{(确定性硬信号)}
```

**质量归一化融合**：
```math
z^k_b = \frac{r^k_b}{\sigma_{k,b} \cdot \max(q^k_b, \epsilon_q)},\qquad
s_b = \frac{\sum_k w_k q^k_b z^k_b}{\sum_k w_k q^k_b}
```
其中 `σ_{k,b}` 是滑动 MAD，**仅在 `q^k_b > τ_q` 的块上更新**（默认 `τ_q = 0.3`）。这实现了「坏观测不污染尺度估计」。

### 2.2 自校准 Conformal

维护滑动校准窗口：
```math
\mathcal C_b = \{ s_i \mid i \in [b-N_{\mathrm{cal}}+1, b],\;
\mathrm{mode}_i=\mathrm{TRUST},\; c_i > \tau_c,\; \min_k q^k_i > \tau_q \}
```
其中 `c_i = 1 - \text{surprise\_rate}` 是软胜任力，`τ_c = 0.9`，`N_cal = 200`。

校准分位数：
```math
q_{\alpha,b} = 
\begin{cases}
\mathrm{Quantile}_{1-\alpha}(\mathcal C_b) & |\mathcal C_b| \ge N_{\min} \\
q_{\alpha}^{\mathrm{offline}} & \text{otherwise}
\end{cases}
```
`N_min = 50`。这把「全局 ID 可交换性」弱化为「近期高置信 TRUST 与当前块局部可交换」。

### 2.3 CBF 认证原语形式化

每个原语 `π` 定义为三元组 `(h_π, R_π, d_{\max,π})`：

**指数 CBF 条件**（离线验证）：
```math
\forall x \in C_π = \{x \mid h_π(x) \ge 0\}:
\frac{\partial h_π}{\partial x} f(x, π(x)) \ge -\gamma_π h_π(x)
```
其中 `f` 是系统动力学（含 WAVE-SERVO 虚拟力闭环）。用区间运算 / 和松弛（SOS/矩松弛）在离线验证；`γ_π > 0` 越大越保守。

**可达性包络**（离线计算）：
```math
R_π = \{ x_0 \mid \exists u(\cdot),\; x(T) \in G_π,\; \forall t \in [0,T]: h_π(x(t)) \ge 0 \}
```
用 Hamilton-Jacobi 反向可达性方程求解，或线性化动力学 + 多面体外包近似。运行时只做集合成员判定 `x_current ∈ R_π`。

**最大允许干扰**：
```math
d_{\max,π} = \sup \{ \|d\| \mid \forall x \in C_π: \frac{\partial h_π}{\partial x} (f(x,π(x)) + d) \ge -\gamma_π h_π(x) \}
```
运行时用电流/力估计当前干扰 `d̂`，若 `d̂ > d_max` 则原语 `UNSAFE`。

**原语库（第 15 轮语法 + 证书字段）**：

| 原语 | CBF `h(x)` | 可达性 `R` | `d_max` | 典型任务 |
|---|---|---|---|---|
| `REACH` | `h = d_safe - \|x - x_obs\|`（障碍物距离） | 全工作空间凸包 | 5N / 5° | 所有接近段 |
| `GRASP` | `h = F_max - \|F_contact\|`（夹爪力上限） | 目标抓取位姿邻域 | 2N | Pick、Hang、Open |
| `LIFT` | `h = z_min - z_ee`（最小高度） | 目标上方垂直柱体 | 3N | Pick、Stack |
| `PLACE` | `h = d_safe - \|x - x_obs\|` | 目标位姿邻域 | 3N | Stack、Place、Hang |
| `INSERT` | `h = \min(\text{chamfer}, F_max - \|F\|)` | 插座轴向对齐锥体 | 8N | PlugInEthernet、Insert |
| `PUSH/PULL` | `h = F_max - \|F\|` | 接触面法向柱体 | 10N | Open/Close drawer |
| `PRESS` | `h = F_target - \|F\|` | 按钮位姿邻域 | 5N | Button、Switch |

### 2.6 DAG 编排与 WCET 分析

**每块周期（5 步 = 100ms）的执行 DAG**：

```text
┌─────────────────────────────────────────────────────────────────┐
│ Block Cycle (100ms budget)                                      │
├─────────────────────────────────────────────────────────────────┤
│ T0:  获取观测 obs_t                                             │
│ T1:  residual_calculator(obs_{t-1}, obs_t, ...) → residuals     │  ← WCET 5ms
│ T2:  trust_gate(residuals, cal_window, cusum) → mode, c, surprise│  ← WCET 1ms
│ T3:  voi_scheduler(mode, belief, progress, budget, c, certs) → act│  ← WCET 2ms
│ T4:  action_dispatcher(act, ctx) → chunk                        │  ← WCET 0.5ms
│       ├── act=SERVO:      wave_servo_executor(...)              │  ← WCET 2ms
│       ├── act=FALLBACK:   primitive_executor(...)               │  ← WCET 3ms
│       ├── act=LOOK:       look_controller(...)                  │  ← WCET 1ms
│       ├── act=VLA:        vla_client.request_plan(...) (async)  │  ← 非阻塞
│       ├── act=COMMIT:     wave_servo_executor(...)              │  ← WCET 2ms
│       └── act=HOLD:       safe_hold_chunk()                     │  ← WCET 0.1ms
│ T5:  发送 chunk，更新状态                                       │
└─────────────────────────────────────────────────────────────────┘
```

**总 WCET（不含 VLA 网络）**：`5 + 1 + 2 + 0.5 + 3 = 11.5ms` << 100ms 周期。

**VLA 异步流水线**：
- `VLAClient` 在后台线程/协程运行，不阻塞主控制环
- 主环收到 `VLA` 动作时，若新 plan 未就绪，**继续执行旧 plan + 伺服**（不 HOLD）
- 熔断器开启时，`VOIScheduler` 自动不选 `VLA`，改选 `LOOK`/`FALLBACK`/`COMMIT`

**内存模型**：所有工具无堆分配热路径；观测/计划/残差用预分配数组池；单端口 < 5MB。

### 3.1 主循环（工具内核版）

```python
class ZestRealPolicy:
    def __init__(self, calib_scores_offline: list[float]):
        # 状态（显性、可序列化、无隐式共享）
        self.M = SemanticMap()
        self.plan = None
        self.prev_plan = None
        self.obs_prev = None
        
        # 信任门状态
        self.cusum_state = CUSUMState(S=0.0, surprise_window=deque(maxlen=W))
        self.cal_window = deque(maxlen=N_CAL)  # 滑动校准窗口
        
        # 原语证书缓存（离线计算，运行时只查表）
        self.primitive_certs = load_primitive_certificates()
        
        # 工具实例（不可变、可热替换）
        self.residual_calc = ResidualCalculator()
        self.trust_gate = TrustGate(params=TRUST_PARAMS)
        self.voi_scheduler = VOIScheduler()
        self.primitive_exec = PrimitiveExecutor(self.primitive_certs)
        self.vla_client = VLAClient(endpoint=VLA_ENDPOINT)
        self.look_ctrl = LookController()
        self.wave_servo = WaveServoExecutor()
        self.dispatcher = ActionDispatcher()
        
        # 离线校准备用
        self.q_alpha_offline = conformal_quantile(calib_scores_offline, alpha=ALPHA)

    def get_action(self, obs: Obs) -> ActionChunk:
        # 0. 更新地图/相位（第 11/14 轮逻辑，纯函数）
        self.M = update_map(self.M, obs, self.plan)
        phase = observe_phase(self.M, obs)
        if edit_detected(obs):
            phase = Phase.RECOVER
        
        # 1. 残差计算（若有前一观测且执行了 SERVO/FALLBACK）
        residuals = None
        if self.obs_prev is not None and self.last_executed in ('SERVO', 'FALLBACK', 'PROBE'):
            residuals = self.residual_calc(
                self.obs_prev, obs, self.plan, self.prev_plan, self.M, phase
            )
            # 2. 信任门更新
            mode, self.cusum_state, competence, surprise = self.trust_gate(
                residuals, list(self.cal_window), self.cusum_state, TRUST_PARAMS
            )
            self.mode = mode
            self.competence = competence
            
            # 3. 自校准：高置信 TRUST 块进入校准窗口
            if mode == 'TRUST' and competence > TAU_C and min(residuals.quality_factors) > TAU_Q:
                s = self._normalized_score(residuals)
                self.cal_window.append(s)
            
            # 4. 更新在线分位数
            if len(self.cal_window) >= N_MIN:
                self.q_alpha = quantile(list(self.cal_window), 1 - ALPHA)
            else:
                self.q_alpha = self.q_alpha_offline
        
        # 5. 编译当前可用原语证书状态
        cert_status = {}
        if self.mode == 'FALLBACK':
            for prim_name in self.current_primitive_queue:
                cert = self.primitive_certs[prim_name]
                reachable = self._check_reachable(cert, obs)
                disturbance_ok = self._check_disturbance(cert, obs)
                cbf_ok = self._check_cbf(cert, obs)
                cert_status[prim_name] = PrimitiveCertStatus(
                    reachable, disturbance_ok, cbf_ok
                )
        
        # 6. VOI 调度
        action = self.voi_scheduler(
            mode=self.mode,
            belief=self.M.target_belief,
            progress=self.progress,
            budget=self.budget,
            competence=self.competence,
            primitive_certs=cert_status
        )
        
        # 7. 动作分发
        chunk = self.dispatcher(action, DispatchContext(
            obs=obs, plan=self.plan, M=self.M, phase=phase,
            primitive_queue=self.current_primitive_queue,
            vla_client=self.vla_client,
            wave_servo=self.wave_servo,
            look_ctrl=self.look_ctrl,
            primitive_exec=self.primitive_exec
        ))
        
        # 8. 记录用于下一块残差计算
        self.obs_prev = obs
        self.last_executed = action
        if action == 'SERVO':
            self.prev_plan = self.plan
        
        return chunk

    def _normalized_score(self, r: ResidualVec) -> float:
        # 质量加权融合
        z = {}
        weights = {}
        for k in ['tmp', 'geo', 'goal', 'dyn']:
            q = getattr(r, f'q_{k}')
            sigma = self._get_mad(k)  # 滑动 MAD，仅 q > TAU_Q 更新
            z[k] = getattr(r, f'r_{k}') / (sigma * max(q, EPS_Q))
            weights[k] = BASE_WEIGHTS[k] * q
        total_w = sum(weights.values())
        return sum(weights[k] * z[k] for k in z) / total_w if total_w > 0 else 0.0
```

### 3.2 信任门（自校准版）

```python
@dataclass
class TrustParams:
    alpha: float = 0.12
    k: float = 0.05
    h: float = 2.5
    W: int = 5
    recheck_every: int = 3

@dataclass
class CUSUMState:
    S: float
    surprise_window: deque[int]

def trust_gate(
    residuals: ResidualVec,
    cal_window: list[float],
    cusum: CUSUMState,
    params: TrustParams
) -> tuple[str, CUSUMState, float, bool]:
    # 1. 计算分数
    s = normalized_score_with_quality(residuals, cal_window)  # 使用质量加权
    
    # 2. 分位数
    q_alpha = quantile(cal_window, 1 - params.alpha) if len(cal_window) >= N_MIN else Q_ALPHA_OFFLINE
    
    # 3. 惊讶指示
    surprise = int(s > q_alpha)
    cusum.surprise_window.append(surprise)
    
    # 4. CUSUM 更新
    cusum.S = max(0.0, cusum.S + surprise - params.alpha - params.k)
    
    # 5. 模式迁移
    mode = cusum.mode  # 保持上一模式
    if mode == 'TRUST':
        if cusum.S > params.h:
            mode = 'FALLBACK'
            cusum.S = 0.0  # 进入 fallback 重置 CUSUM
    elif mode == 'FALLBACK':
        cusum.fallback_dwell += 1
        if cusum.fallback_dwell >= params.recheck_every:
            mode = 'PROBE'
            cusum.fallback_dwell = 0
    elif mode == 'PROBE':
        if not surprise:
            mode = 'TRUST'
            cusum.S = 0.0
        else:
            mode = 'FALLBACK'
            cusum.fallback_dwell = 0
    
    # 6. 软胜任力
    competence = 1.0 - (sum(cusum.surprise_window) / len(cusum.surprise_window))
    
    return mode, cusum, competence, surprise
```

### 3.3 VOI 调度器（认证感知版）

```python
def voi_scheduler(
    mode: str,
    belief: BeliefDist,
    progress: float,
    budget: float,
    competence: float,
    primitive_certs: dict[str, PrimitiveCertStatus]
) -> str:
    # 允许动作集（硬约束）
    allowed = allowed_actions(mode, primitive_certs)
    if not allowed:
        return 'HOLD'
    
    bmax = max(belief.values()) if belief else 0.0
    p = progress
    
    # 增益/成本计算
    options = []
    
    if 'SERVO' in allowed:
        gain = competence * bmax * (f(p + DELTA) - f(p))
        options.append(('SERVO', gain, C_SERVO))
    
    if 'LOOK' in allowed and mode == 'TRUST':
        gain = look_gain(belief, M, phase)
        options.append(('LOOK', gain, C_LOOK))
    
    if 'VLA' in allowed and budget >= C_VLA:
        # 熔断器检查在 VLAClient 内部
        c_after = competence + (1 - competence) * Q_VLA_RECOVER
        gain = (c_after - competence) * bmax * f(p) + DELTA_PLAN
        options.append(('VLA', gain, C_VLA))
    
    if 'FALLBACK' in allowed:
        # 只考虑证书全通过的原语
        viable_prims = [p for p, cert in primitive_certs.items() 
                       if cert.reachable and cert.disturbance_ok and cert.cbf_ok]
        if viable_prims:
            g = min(cert.historical_success for cert in viable_prims)  # 保守取最小
            gain = bmax * g * (f_geo(p + DELTA) - f_geo(p))
            options.append(('FALLBACK', gain, C_FALLBACK))
    
    if not options:
        return 'HOLD'
    
    # 选增益/成本最大
    action, gain, cost = max(options, key=lambda o: o[1] / o[2])
    if gain / cost < LAMBDA_OPPORTUNITY or cost > budget:
        return 'COMMIT' if 'COMMIT' in allowed else 'HOLD'
    return action

def allowed_actions(mode: str, primitive_certs: dict) -> set[str]:
    if mode == 'TRUST':
        return {'SERVO', 'LOOK', 'VLA', 'COMMIT'}
    if mode == 'FALLBACK':
        acts = {'LOOK', 'VLA', 'HOLD'}
        # 只有所有待执行原语证书全通过，才允许 FALLBACK
        if all(c.reachable and c.disturbance_ok and c.cbf_ok for c in primitive_certs.values()):
            acts.add('FALLBACK')
        return acts
    return {'HOLD'}
```

### 3.4 原语执行器（CBF 运行时检查）

```python
def primitive_executor(
    primitive: str,
    args: PrimitiveArgs,
    M: SemanticMap,
    x_current: State
) -> tuple[ActionChunk, CertStatus]:
    cert = PRIMITIVE_CERTIFICATES[primitive]
    
    # 运行时 CBF 检查：在当前状态下，控制律是否满足 ḣ ≥ -γh
    h_val = cert.h(x_current)
    h_dot = cert.h_dot(x_current, cert.controller(x_current))
    cbf_ok = (h_dot >= -cert.gamma * h_val - 1e-6)
    
    # 可达性检查：当前状态是否在包络内
    reachable = x_current in cert.R
    
    # 干扰检查：电流估计的接触力是否在 d_max 内
    disturbance = estimate_disturbance_from_current(x_current)
    disturbance_ok = disturbance <= cert.d_max
    
    status = CertStatus(
        cbf_ok=cbf_ok,
        reachable=reachable,
        disturbance_ok=disturbance_ok
    )
    
    if not (cbf_ok and reachable and disturbance_ok):
        # 证书失败：返回安全 HOLD chunk，上层会切回 TRUST/VLA
        return safe_hold_chunk(), status
    
    # 证书通过：执行原语控制律（通过 WAVE-SERVO 发送）
    chunk = cert.controller.generate_chunk(x_current, args, M)
    return chunk, status
```

### 3.5 VLA 客户端（异步 + 熔断）

```python
class CircuitBreaker:
    def __init__(self, failure_threshold=5, recovery_timeout=30.0):
        self.failures = 0
        self.failure_threshold = failure_threshold
        self.recovery_timeout = recovery_timeout
        self.last_failure_time = 0
        self.state = 'CLOSED'  # CLOSED | OPEN | HALF_OPEN
    
    def call(self, func, *args, **kwargs):
        if self.state == 'OPEN':
            if time.time() - self.last_failure_time > self.recovery_timeout:
                self.state = 'HALF_OPEN'
            else:
                raise CircuitOpenError()
        try:
            result = func(*args, **kwargs)
            self.on_success()
            return result
        except Exception as e:
            self.on_failure()
            raise
    
    def on_success(self):
        self.failures = 0
        self.state = 'CLOSED'
    
    def on_failure(self):
        self.failures += 1
        self.last_failure_time = time.time()
        if self.failures >= self.failure_threshold:
            self.state = 'OPEN'

class VLAClient:
    def __init__(self, endpoint: str, timeout: float = 2.0):
        self.endpoint = endpoint
        self.timeout = timeout
        self.circuit = CircuitBreaker()
        self.last_plan = None
        self.pending_future = None
    
    async def request_plan(self, obs: Obs, instruction: str) -> AsyncResult[Plan]:
        if self.circuit.state == 'OPEN':
            return AsyncResult(circuit_open=True, fallback_plan=self.last_plan)
        
        # 异步发起，不等待
        self.pending_future = asyncio.create_task(self._do_request(obs, instruction))
        return AsyncResult(pending=True)
    
    async def _do_request(self, obs, instruction) -> Plan:
        # 实际 HTTP/websocket 调用
        async with aiohttp.ClientSession() as session:
            async with session.post(self.endpoint, json={...}, timeout=self.timeout) as resp:
                data = await resp.json()
                return parse_plan(data)
    
    def poll(self) -> Optional[Plan]:
        # 非阻塞轮询，供主环调用
        if self.pending_future and self.pending_future.done():
            try:
                plan = self.pending_future.result()
                self.last_plan = plan
                self.circuit.on_success()
                return plan
            except Exception:
                self.circuit.on_failure()
                return None
        return None
```

## 4. 性质、复杂度与正确性（增量）

### 4.1 自校准 Conformal 的覆盖保证（近似）

**命题 1-R（局部覆盖）**：设近期高置信 TRUST 块集合 `C_b` 与当前块在残差分布上局部可交换，且 `|C_b| ≥ N_min`。则自校准分位数 `q_{α,b}` 满足：
```math
\Pr(s_{b+1} > q_{\alpha,b} \mid \mathcal F_b) \le \alpha + O(1/\sqrt{|C_b|})
```
其中 `\mathcal F_b` 是到第 `b` 块的历史。

**证明草图**：条件在 `\mathcal F_b` 上，`C_b` 是固定的（由 `mode, competence, quality` 确定）。在局部可交换假设下，标准 split conformal 给出条件覆盖；误差项来自分位数估计的有限样本误差。∎

**边界**：局部可交换是假设，不是定理。真实分布漂移时，`C_b` 可能包含已漂移的块。工程上用 `τ_c, τ_q` 提高门槛，并监控 `|C_b|` 和惊讶率；异常时回退离线校准。

### 4.2 CBF 证书的安全保证

**命题 2-R（前向不变性）**：若离线验证了 `∀x ∈ C_π: ḣ(x) ≥ -γ h(x)`，且运行时初始状态 `x_0 ∈ C_π`，且干扰 `d(t)` 满足 `\|d(t)\| ≤ d_{\max,π}`，则在控制律 `u = π(x)` 下，轨迹满足 `h(x(t)) ≥ 0` 对所有 `t ≥ 0`。

**证明**：标准指数 CBF 结果。干扰上界 `d_max` 的定义正是保证扰动系统仍满足 CBF 条件的最大干扰。∎

**命题 3-R（可达性）**：若 `x_0 ∈ R_π`，则存在控制输入使系统在时限 `T` 内到达目标集 `G_π` 且全程保持 `h(x) ≥ 0`。

**证明**：`R_π` 的定义即反向可达集。∎

**边界**：离线验证用模型 `f`；真实动力学有建模误差。`d_max` 的留余量需覆盖建模误差 + 估计误差。若 `d_max` 过小导致原语不可用，是保守性代价，不是安全漏洞。

### 4.3 工具内核的确定性与 WCET

**命题 4-R（无隐式共享状态）**：所有工具函数签名为 `Input → Output` 或 `(Input, State) → (Output, State')`，无全局可变变量。主循环按拓扑序显性传递状态。

**证明**：由代码构造直接得到。∎

**命题 5-R（WCET 界）**：设每个工具的 WCET 已知（通过静态分析/测量得到），编排开销为常数 `O(1)`。则单块周期 WCET = Σ WCET_i + O(1) < 30ms。

**证明**：DAG 无循环，拓扑序执行，总时间为各节点 WCET 之和加编排开销。∎

**边界**：Python GC 可能引入抖动。工程上用内存池、预分配、关闭 GC（或用 PyPy/编译扩展）消除；或迁移热路径到 C++/Rust。

### 4.4 单模型合规

**命题 6-R（唯一学习模型）**：工具集中仅 `VLAClient` 调用外部学习模型（UnifoLM-WLA-1.0）；其余工具（残差计算、信任门、VOI 调度、原语执行、LOOK、WAVE-SERVO）均为确定性几何/统计/控制算法，无可学习参数。

**证明**：由工具签名与实现直接核实。∎

**边界**：若评审认为「在线更新校准分位数」属于学习，可退化为**固定离线校准 + 固定 CUSUM 参数**，牺牲自适应性保持合规。
