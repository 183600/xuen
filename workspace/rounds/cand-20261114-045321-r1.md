# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「数据质量」×「动作空间」）

> R69 教会系统「不确定就去问」，但它把两个前提当成了空气：**（a）数据质量是全局的、已知的**——FMP 的模态权重、ECE、VoI 的期望、k 源一致性，全部默认训练/标定数据「足够好」，却从不问「好」是相对谁、相对哪个动作；**（b）动作空间是固定的、全可用的**——𝒜_+ 被当作一个静态集合，策略在其上生成动作，仿佛数据天然覆盖它。真实部署里，数据是稀疏、选择偏置、非平稳、可被投毒的；动作空间是分片、受限、随技能/构型/接触模式变化的。**数据只支持它见过的动作子空间；策略的「自信」常常只是「没见过别的选择」。**
>
> 两个灵感把 R69 的两个隐含假设翻成两个可计算对象：
> - **数据质量**不是数据集的一个标量分数，而是三元关系 q(D; o, A)——**同一批数据，对某个状态-动作邻域是许可证，对另一个邻域是伪造的自信**；
> - **动作空间**不是给定的舞台，而是可以被**收缩（contract）/扩张（expand）/许可（license）**的合同——安全不是把动作做慢，而是**只在数据许可的子空间里做动作**。
>
> 核心命题：**在 R69 的 (U_ale, U_epi) 之上加第三层 U_data（对不确定性估计本身的不确定性）；把「问不问」升级为「许可 → 采集 → 收缩」三选一；所有执行动作必须在「数据许可动作空间」𝒜_L 内，R69 恰为 U_data≤τ 且 𝒜_L=𝒜 的边界。** 命名 **CALIPER-RAS**（Calibrated Action-space Licensing with Influence, Provenance, and Evidence Reliability）——卡尺量的是「数据支撑」与「动作需求」之间的缝。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的数据凭什么允许我做这个动作**」——数据质量不是分数，是许可证；动作空间不是背景，是合同。

## 0. 直觉与动机

**灵感 1（数据质量 → 全局质量分是幻觉，质量是局部的、决策相关的）**
直觉：数据集统计（样本数、标注准确率、平均覆盖率）都是边缘化后的量；真正决定当下决策的，是状态-动作邻域 N(o, A) 内的有效样本数、动作覆盖半径、反事实对比、漂移与来源独立性。一个百万级的「高质量」数据集，在某个窄动作子空间里可能完全空白；一个「低质量」含噪数据集，若只需支撑低维安全动作，反而可能足够。把质量压成一个标量，等于把「哪里有洞」平均掉了。**质量必须局部化到「这次决策要用的动作」上。**

**灵感 2（动作空间 → 数据只支持它见过的动作子空间）**
直觉：R69 的 U_epi 从流模型的多模态采样里估出来，但流模型的模态权重又来自数据。如果行为策略从未在 o 附近尝试过第二个模态，流模型对它输出的高置信是外推幻觉——**不是「没有歧义」，而是「数据里没有第二种选择」**。这是 R69 自陈最大风险的根：模态分布可信度不能靠模态分布自证。动作空间提供了正确的切口：数据在动作流形上的**支撑**决定了哪些动作可被评估，哪些动作只是外推；而动作空间可以按技能单元分片，许可可以逐片签发。

**灵感 3（第三层不确定性 → U_data 是「对不确定性的不确定性」）**
直觉：R69 用全局 ECE 校准模态权重（MCG），但 ECE 本身也是数据估计的；若数据被选择偏置、漂移或投毒，ECE 会自信地错。于是必须有第三层：**U_data = 对 (Û_ale, Û_epi, ŵ) 估计误差的上界**。当 U_data 大时，连「该不该问」的符号都不可信——问一个幻影比不问更危险。R69 不是被替代，而是被收编为 U_data≤τ、许可全覆盖的边界情形。

**灵感 4（许可而非刹车 → 许可 / 采集 / 收缩 三选一）**
直觉：R68 收缩速度 λ，R69 增加信息动作 g，R70 改变**可行动作集合**。在一个不被数据支持的区域内，慢速通过仍然是未被建模的：慢不等于有支撑。正确的动作只有三种：**许可**（数据够，按 R69 做）、**采集**（数据不够但可以获得，执行安全的数据动作）、**收缩**（数据不够也拿不到，退到已认证子空间或降级控制器）。这比「不确定就减速」更接近人类的谨慎：看不清就不走那条路，而不是闭着眼慢慢走。

**灵感 5（数据也是动作 → 但会奖励黑客与自许）**
直觉：主动采集、安全自实验、请求标注 d ∈ 𝒜_data 都可以提升未来数据质量。它与 R69 的 VoI 不同：VoI 降低模态熵，VoDQ 降低元不确定性/覆盖缺口。有时 VoI≤0 但 VoDQ>0（先补数据再问）；有时 VoI>0 但 U_data 高，问了也白问。但「数据动作」打开了新攻击面：为拿许可而刷数据（self-licensing）、探索越界、投毒伪造高质量、Goodhart。因此必须同时交付：数据预算、数据动作认证、「数据不能为自己发许可证」的纪律、provenance 审计。

**灵感 6（对偶不动点 → 数据质量与动作空间互相定义）**
直觉：数据质量决定哪些动作被许可；被许可的动作又决定下一次会采到什么数据，从而改写数据质量。这不是一次性的过滤，而是一个**不动点**：𝒜* = E_d(C_ε(𝒜))。R70 的理论姿态不是「在 R69 上再加一个质量检查」，而是承认**质量与动作空间是同一枚硬币的两面**——数据决定你能做什么，你做什么又决定你明天知道什么。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（CALIPER-RAS 总览）** CALIPER-RAS = (DQC, MUG, LAS, DAA, AST, DPR, QoQ)，叠加在 R69 的 (FMP, AUD, MINT, CIA, FMA) 之上。三不变式：
(i) **继承不变式**：R69 的实时零学习写操作、交互预算、证据纪律全部保留；
(ii) **动作许可不变式**：每个提交执行的动作 ξ 必须满足 ξ ∈ 𝒜_L(o)（或其显式降级控制器），𝒜_L 由 DQC 与风险认证共同签发，且许可有有效期；
(iii) **数据溯源不变式**：影响决策的每个数据片携带 provenance 与使用许可；R69 的 k 个「正交源」按 provenance 独立性折算为 k_eff，k_eff<k_min 时不得单独定案。

**定义 311（局部数据质量谱 DQC）** 对决策上下文 o 与候选动作模态/技能单元 m（对子集 A 取逐维最差），
q_D(o,m) = (n_eff, r_cov, κ_ctr, τ_drift, ρ_prov, ε_lab)：
- **有效样本** n_eff = (Σ_i w_i)² / Σ_i w_i²，w_i = K_h((o,ξ̄_m),(o_i,ξ_i))，h 为局部带宽；
- **覆盖半径** r_cov = sup_{ξ∈m} min_i d_M((o,ξ),(o_i,ξ_i))（动作流形上的最大空洞半径）；
- **反事实对比** κ_ctr = I(A; Y | o, A∈N(m))，即邻域内「动作选择」对结果的可识别信息量；行为策略从不换动作时 κ_ctr=0；
- **漂移** τ_drift = MMD²(𝒟_train∩N(m), 𝒟_recent∩N(m))；
- **来源独立度** ρ_prov = k_eff = (Σ_s p_s)² / (Σ_s p_s² + 2Σ_{s<s'} p_s p_{s'} ρ_{ss'})，当来源两两独立时等于 m，完全共谋时等于 1；
- **标注/测量噪声界** ε_lab，由重复测量或标定残差给出。

**定义 312（元不确定性 U_data）** 对 q_D 与模态数 K，定义可计算的误差上界
U_data(o,m) ≤ c₁√(K log(2/δ) / (2 n_eff)) + c₂ r_cov + c₃ τ_drift + c₄ ε_lab + c₅ (1/ρ_prov − 1/m)_+。
第一项是熵/权重估计的有限样本误差，第二项是外推误差，第三项是分布漂移，第四项是标签噪声，第五项是来源相关导致的「伪独立」。U_data 不是 U 的加项，而是「U 的估计有多可信」的标量上界。

**定义 313（许可算子与许可动作空间）** 
L_τ(o,m) = 1[ n_eff ≥ n_min ∧ r_cov ≤ r_max ∧ κ_ctr ≥ κ_min ∧ τ_drift ≤ τ_max ∧ ρ_prov ≥ ρ_min ∧ ε_lab ≤ ε_max ∧ U_data ≤ τ_data ∧ R_upper(m) ≤ ε_L ]。
𝒜_L(o) = ⋃{ m : L_τ(o,m)=1 且证书有效 }，实现为若干「已认证技能单元」的并集。若 𝒜_L=∅，退到显式降级控制器 π_fb 并置 fallback 标志。

**定义 314（许可证书与有效期）** cert(m) = (q_D, R_upper^{1−α}, D_hash/Merkle root, provenance_set, issued_at, expires_at, drift_witness, qoq_ece, caliper_ver)。Valid(m,t) ⇔ t<expires_at ∧ 漂移检验通过 ∧ 未被撤销 ∧ QoQ 校准门通过。**许可不是永久执照**，新数据/漂移/撤销都会触发重认证。

**定义 315（许可投影策略）** π_L(ξ|o) = π_θ(ξ|o)·1[ξ∈𝒜_L(o)] / Z，Z=∫_{𝒜_L}π_θ；若 Z=0 则用 π_fb。实现上采用「技能单元头 + 约束流采样」：先按单元许可重加权/掩码，再在单元内做约束投影或拒绝采样。被许可的模态集合记为 M_L，未许可模态不参与执行，但保留为「未知」而非「已确认」。

**定义 316（数据动作与 VoDQ）** 数据动作 d ∈ 𝒜_data = {probe, self-experiment, request-label, query, replay}。其数据价值
VoDQ(d) = E[U_data(o, A_target) − U_data(o, A_target | d)] − c_data(d)，
选择 d* = argmax_d VoDQ(d)，s.t. d 通过 RAS-WM‡ 认证、预算未超、目标区域可达。注意：VoDQ 与 R69 的 VoI 是两种价值；VoI 只在 U_data≤τ_data 时有意义，而 VoDQ 恰在 U_data 大时最有用。

**定义 317（数据动作的安全、预算与「不自许」）** 数据预算 B_data=(时间, 能量, 隐私, 社交打扰)，硬约束。数据动作必须通过与任务动作相同的 C-RAS-WM 前缀认证，探索不得越出已认证安全包络。**不自许纪律**：d 产生的数据不得成为许可 d 自身目标区域的唯一证据；许可该区域还需独立 provenance 源或独立留出集/延迟二次确认。每次数据动作产生可审计的数据收据（data receipt）。

**定义 318（三级不确定性与决策级联）** 状态扩展为 (U_ale, U_epi, U_data)。决策顺序：
1) **元门**：若 U_data>τ_data，不信任 VoI 与模态分解，禁止据此追问；
2) **许可门**：计算 𝒜_L；若 R69 选出的动作不在 𝒜_L，改用许可动作或收缩；
3) **认知门**：若 U_epi>τ_epi 且动作被许可，走 R69 的 MINT/VoI；
4) **风险地板**：λ = λ_floor(U_ale + 未消解 U_epi + η·U_data)，η 为数据不确定性到风险的换算系数。
R69 恰为 U_data≤τ_data 且 𝒜_L=𝒜 的边界情形。

**定义 319（动作空间代数）** 收缩算子 C_ε：在已认证技能单元图上，选择满足风险上界的最小/最大连通许可子集（按任务效用与风险偏好）；扩张算子 E_d：执行数据动作 d 后重认证并更新单元图。不动点 𝒜* = E_d(C_ε(𝒜))。若一次迭代后许可集不增大且任务效用不升，停止采集，避免「为数据而数据」。

**定义 320（反事实支撑标记）** 对每个模态 m，若 κ_ctr(m)<κ_min 或 p_D(N(m)|o)<p_min，标记 m 为 **unknown**；unknown 不得被当作「已确认的低歧义」，只能被许可为「未知但安全」或直接收缩。此标记是对 R69「U_epi 可被选择偏置伪造」的正面修复。

**定义 321（鲁棒 DQC 与投毒）** DQC 的各维用截尾/中位数均值（median-of-means）估计，按 provenance 加权；用影响函数剪除高杠杆数据片。设污染比例 ε 小于估计器崩溃点 β，则 |q̂−q| ≤ C(√(log(1/δ)/n_eff) + ε)。许可的误接受率 ≤ exp(−n_eff·ψ(ε)) + g(ε, ρ_prov)。要伪造许可，至少需 k_min 个相互独立的 provenance 源同时被污染。

**定义 322（DQC 元校准 QoQ）** 证书本身也要校准：在独立留出 provenance 上，比较「预测的许可有效」与「实际执行后的有效」的校准误差 ECE_qoq。若 ECE_qoq>τ_qoq，暂停签发新许可（不是暂停执行已有许可），并回退到更保守的证书。**这是「质量的度量本身的质量」的第三层校准，专门对付 R69 MCG 的循环自证。**

**定义 323（参与式审计 VQAuditor-D）** 审计对象新增：数据谱是否被正确局部化、许可是否越界发放、数据动作是否越出安全包络、是否存在为拿许可而刷数据（self-licensing/Goodhart）、provenance 是否真的独立。结论回灌 AuditBuf，成为下一轮 DQC 先验与数据预算的约束。

**定义 324（证书 J_CALIPER）** J_CALIPER = (J_FLUID, q_D 向量, license_map_hash, k_eff_min, U_data_p95, data_budget_usage, data_receipt_root, license_ttl_min, ECE_qoq, caliper_ver)。Valid ⇔ Valid(J_FLUID) ∧ 所有执行动作被许可 ∧ 溯源纪律满足 ∧ QoQ 未越界 ∧ 数据预算未越界。

**定义 325（降级阶梯与连续性）** 许可失效/撤销/过期时按预计算阶梯降级：C1 最近已认证单元 → C2 缩小技能子集 → C3 π_fb 保守控制器 → C4 安全停机。降级过程中 λ 单调不降、动作连续插值，继承 R68/R69 的无突变不变式。

**定义 326（对 R69 的严格退化边界）** 当 U_data≤τ_data、𝒜_L=𝒜、κ_ctr≥κ_min、ρ_prov≥ρ_min 且不触发任何数据动作时，CALIPER 的第 2–4 步退化为 R69 的 MINT/VoI/λ_floor，逐指令相同。故 R69 是 CALIPER 在「数据无限好、动作空间全许可」边界上的严格特例。

```python
# IP-264 DQC：局部数据质量谱（证书按技能单元缓存，漂移/新数据时重算）
class LocalDQC:
    def profile(self, o, cells, ledger):
        q = {}
        for c in cells:                                   # 候选技能单元，通常 ≤16
            cert = self.cache.get((c.id, ledger.version))
            if cert is None or self.drift.expired(cert, o):
                cert = self.recompute(o, c, ledger)       # n_eff / r_cov / kappa / drift / prov
                self.cache[(c.id, ledger.version)] = cert
            q[c.id] = cert
        return q

    def recompute(self, o, c, ledger):
        w    = local_kernel_weights(o, c, ledger, h=self.h)
        n_eff = (w.sum() ** 2) / (w ** 2).sum()
        r_cov = covering_radius(o, c, ledger, metric=self.d)
        kappa = identifiable_action_info(o, c, ledger)    # I(A;Y|o) 的局部估计
        drift = mmd2(ledger.train_local(c, o), ledger.recent_local(c, o))
        k_eff = provenance_effective_count(ledger.sources(c), ledger.corr)
        return DQCert(n_eff, r_cov, kappa, drift, k_eff, ledger.label_noise(c))

# IP-265 MUG：元不确定性上界 + 元门
def meta_uncertainty(cert, K, delta):
    return (c1 * sqrt(K * log(2 / delta) / (2 * cert.n_eff))
            + c2 * cert.r_cov + c3 * cert.drift + c4 * cert.eps_lab
            + c5 * max(0.0, 1.0 / cert.k_eff - 1.0 / K))

def meta_gate(cert, K, tau_data, delta):
    return meta_uncertainty(cert, K, delta) <= tau_data

# IP-266 LAS：许可、约束投影、TTL 与降级
class LicensedActionSpace:
    def license(self, o, q):
        cells = [c for c in q if self.qoq_ok() and self.cert_valid(c)
                 and self.risk_upper(c) <= self.eps_L
                 and q[c].n_eff >= N_MIN and q[c].r_cov <= R_MAX
                 and q[c].kappa >= KAPPA_MIN and q[c].drift <= TAU_MAX
                 and q[c].k_eff >= K_MIN and q[c].eps_lab <= EPS_MAX
                 and meta_gate(q[c], self.K, self.tau_data, self.delta)]
        return SkillCellSet(cells)

    def project(self, policy, o, A_L, K):
        if A_L.empty: return self.fallback.sample(o)
        modes = policy.sample_cells(o, K)                  # 单元头 + 流匹配
        keep  = [m for m in modes if m.cell in A_L]
        if not keep: return self.fallback.sample(o)
        return constrained_flow_resample(keep, A_L)        # 单元内约束投影/拒绝采样

# IP-267 DAA：数据动作与 VoDQ
def choose_data_action(o, q, budget, ledger):
    best = None
    for d in data_action_candidates(o, q):                # probe / self-exp / ask / label
        if not budget.allow(d) or not ras_wm.certify_data(d, o): continue
        vodq = expected_meta_reduction(d, q) - data_cost(d)
        if best is None or vodq > best.vodq: best = (d, vodq)
    return best if best and best.vodq > 0 else None

# IP-274 主闭环：元门 → 许可门 → 认知门 → 风险地板
def CALIPER_round(M, obs):

    if g is not None:
        U_epi = M.cia.update_belief(modes, M.cia.execute(g))

    # 3) 认知门 + 风险地板：只对 aleatoric + 未消解 epistemic + 数据元不确定性收紧
    A_exec = M.las.project(M.fmp, o, A_L, K)
    U_floor = U_ale + (U_epi if g is None else 0.0) + ETA * u_data
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))

    # 4) 认证、审计、数据收据
    k = M.c_ras_wm.certified_prefix(A_exec, ..., wm_preds)
    if u_data > TAU_DATA or not M.las.all_licensed(A_exec):
        lam = max(lam, 0.85); k = min(k, M.las.certified_horizon(A_exec))
    M.vqa_d.submit_async(q, A_L, g, u_data, data_receipt(o, A_exec))
    return k, lam, A_exec, (U_ale, U_epi, u_data)
```

## 3. 推导

**引理 19（支撑-泛化风险界）** 设损失 ℓ 为 L_ℓ-Lipschitz、有界 B；动作子集 A 的局部内禀维数为 d_A，有效样本 n_eff，覆盖半径 r_cov。则以概率 ≥1−δ，
|R(A) − R̂(A)| ≤ C·√((d_A log n_eff + log(1/δ))/n_eff) + 2L_ℓ·r_cov。
要点：用数据动作点给 A 做半径 r_cov 的覆盖，球内用 Lipschitz 控制，球间用 d_A 维局部图的均匀收敛。系：**收缩动作空间同时降低 d_A、增大 n_eff、减小 r_cov，因而单调收紧可认证风险界**——这是「收缩」而非「减速」有理论依据的原因；在不被支撑的区域里，减速不改变 r_cov。

**引理 20（反事实不可识别与 U_epi 幻觉）** 设行为策略在 o 附近以概率 0 选择模态 m，即 p_D(N(m)|o)=0。则仅由 D 构造的任何离策略估计，对 m 的真实价值不可识别：存在两个只在 m 的结果上不同、却与 D 完全一致的世界，故偏差下界为两世界的价值差；同时 κ_ctr(m)=0。系：**R69 的 Û_epi 可以在真实歧义很大时显得很小（把「没见过」误读成「没歧义」），也可以在数据稀疏时显得很大**；没有 DQC 的 U_epi 不是可识别的量。

**引理 21（元不确定性门控）** 设模态权重估计误差由 U_data 控制，VoI 对权重是 L_V-Lipschitz 的，则 |V̂oI − VoI| ≤ L_V·U_data。若 U_data > (VoI−c)/L_V，则 V̂oI−c 的符号不可认证：存在两个与数据一致的世界，其最优决策分别是「问」与「不问」。故元门不是保守装饰，而是**防止在错误信念上计算 VoI 的必要条件**。R69 的全局 ECE 门（MCG）只覆盖平均校准，不覆盖局部选择偏置与漂移，是本文的特例。

**引理 22（鲁棒 DQC 的投毒界）** 采用中位数均值/截尾估计与 provenance 加权，若污染比例 ε 小于崩溃点 β，则 |q̂−q| ≤ C(√(log(1/δ)/n_eff) + ε)。进一步，许可误接受要求被污染的数据同时满足覆盖、对比、漂移与来源独立四类条件；在 k_min 个独立 provenance 源下，至少需 k_min 源共谋才可伪造，误接受率 ≤ exp(−n_eff·ψ(ε)) + g(ε, ρ_prov)。系：**「k 源一致」必须按 provenance 折算成 k_eff**，否则共谋源只是同一个先验的 k 个投影。

**定理 18（CALIPER 严格包含 R69）** 在 A99–A104 下，当 U_data≤τ_data、𝒜_L=𝒜、κ_ctr≥κ_min、ρ_prov≥ρ_min 且不触发数据动作时，CALIPER 的第 2–4 步与 R69 的 MINT/VoI/λ_floor 逐指令相同；一般情形下，每个执行动作要么在已认证许可单元内、要么是认证过的数据动作、要么是 π_fb，因此安全侧的可认证风险不劣于 R69。R69 是「数据无限好、动作空间全许可」的边界；效率侧在数据充分处获得 **licensing bonus**（比 R69 更少无谓收紧），安全侧不做让步。

**定理 19（许可安全与无突变）** 若每个许可单元的 conformal 风险上界 ≤ ε_L（覆盖率 1−α），则执行动作的期望风险 ≤ ε_L + αB；许可 TTL 到期按 C1→C4 阶梯降级，λ 单调不降、动作连续插值，继承 R68/R69 的换装/提交不变式，故无突变。信息动作与数据动作均过 C-RAS-WM 认证；失败/超时/撤销时回退，不改变安全包络。

**定理 20（数据动作不自许）** 在「不自许」纪律下，单次数据动作对其自身目标区域许可的证据贡献至多 1/k_min；许可需 k_min 个独立 provenance 源或独立留出确认。因此数据采集不能形成自支撑的许可循环，Goodhart 优化也不能单靠提高 DQC 分数获得许可；伪造许可的代价随 k_min 指数上升（引理 22）。系：**先有独立证据，才有资格把数据变成许可证。**

**定理 21（收缩的 Pareto 性）** 许可收缩问题 max_𝒜 U_task(𝒜) s.t. R_upper(𝒜)≤ε_L 的解位于 (任务效用, −可认证风险) 的下凸包上；当 r_cov 大时，任何保留未支撑动作的方案都以严格更差的「单位效用风险」占优。故收缩不是失败，而是把不可认证的效用换成可认证的效用。

## 6. 本轮最大风险

**一句话**：CALIPER 的全部安全性都押在「数据质量证书本身可信」上——**若 DQC 的参照系与许可证都由同一批可能被选择偏置、漂移或投毒的数据生成，系统就会拿着一份看似合法的许可证，在最缺数据支撑的动作子空间里做最自信的动作，把 R69 的「问错」升级为「合法地做错」**。

**次级风险与缓解**：
1. **证书循环自证**（DQC 用同一批数据校准自己）→ QoQ 独立留出 provenance + 元校准门（定义 322）；
2. **许可过度收缩导致任务不可用** → 收缩的 Pareto 前沿（定理 21）+ 数据动作恢复覆盖（E305）；
3. **数据动作越界或刷数据** → RAS-WM‡ 认证 + 不自许纪律 + 数据预算（定义 317、定理 20）；
4. **provenance 伪造与共谋** → k_eff 折算 + 鲁棒 DQC + 多源独立留出（定义 321、引理 22）；
5. **实时预算被 DQC 击穿** → 单元级证书缓存 + 漂移触发重算 + 热路径查表（复杂度表）。

## 3. 关键算法伪代码

```python
# IP-264 DQC：局部质量谱（单元级证书缓存；仅漂移/新数据重算）
class LocalDQC:
    def profile(self, o, cells, ledger):
        q = {}
        for c in cells:                                   # ≤16 个候选技能单元
            cert = self.cache.get((c.id, ledger.version))
            if cert is None or self.drift.expired(cert, o):
                cert = self.recompute(o, c, ledger)       # n_eff/r_cov/kappa/drift/k_eff
                self.cache[(c.id, ledger.version)] = cert
            q[c.id] = cert
        return q

    def recompute(self, o, c, ledger):
        w      = local_kernel_weights(o, c, ledger, self.h)
        n_eff  = (w.sum() ** 2) / (w ** 2).sum()
        r_cov  = covering_radius(o, c, ledger, self.d)
        kappa  = identifiable_action_info(o, c, ledger)    # I(A;Y|o)
        drift  = mmd2(ledger.train_local(c, o), ledger.recent_local(c, o))
        k_eff  = provenance_effective_count(ledger.sources(c), ledger.corr)
        return DQCert(n_eff, r_cov, kappa, drift, k_eff, ledger.label_noise(c))

# IP-265 MUG：第三层不确定性 + 元门
def meta_uncertainty(cert, K, delta):
    return (c1 * sqrt(K * log(2 / delta) / (2 * cert.n_eff))
            + c2 * cert.r_cov + c3 * cert.drift + c4 * cert.eps_lab
            + c5 * max(0.0, 1.0 / cert.k_eff - 1.0 / K))

def meta_gate(cert, K, tau_data, delta):
    return meta_uncertainty(cert, K, delta) <= tau_data

# IP-266 LAS：许可 + 约束投影 + TTL/降级
class LicensedActionSpace:
    def license(self, o, q):
        return SkillCellSet([
            c for c in q
            if self.qoq_ok() and self.cert_valid(c)
            and self.risk_upper(c) <= self.eps_L
            and q[c].n_eff >= N_MIN and q[c].r_cov <= R_MAX
            and q[c].kappa >= KAPPA_MIN and q[c].drift <= TAU_MAX
            and q[c].k_eff >= K_MIN and q[c].eps_lab <= EPS_MAX
            and meta_gate(q[c], self.K, self.tau_data, self.delta)
        ])

    def project(self, policy, o, A_L, K):
        if A_L.empty:
            return self.fallback.sample(o)
        modes = policy.sample_cells(o, K)                  # 技能单元头 + 流匹配
        keep  = [m for m in modes if m.cell in A_L]
        if not keep:
            return self.fallback.sample(o)
        return constrained_flow_resample(keep, A_L)        # 单元内约束投影/拒绝采样

# IP-267 DAA：数据动作与 VoDQ（与 R69 的 VoI 区分）
def choose_data_action(o, q, budget, ledger):
    best = None
    for d in data_action_candidates(o, q):                # probe/self-exp/ask/label/replay
        if not budget.allow(d) or not ras_wm.certify_data(d, o):
            continue
        vodq = expected_meta_reduction(d, q) - data_cost(d)
        if best is None or vodq > best.vodq:
            best = (d, vodq)
    return best if best and best.vodq > 0 else None

# IP-274 主闭环：元门 → 许可门 → 认知门 → 风险地板
def CALIPER_round(M, obs):
    z, o = M.mtm.forward(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes = M.aud.decompose(samples, z)
    q = M.dqc.profile(o, M.skill_cells(modes), M.ledger)
    A_L = M.las.license(o, q)
    u_data = max(M.mug.meta_uncertainty(q[c.id], K, M.delta) for c in A_L or q)

    # 1) 元门：U_data 高 → 不信 VoI；先安全采集，或收缩到许可子空间
    if u_data > TAU_DATA:
        d = M.daa.choose_data_action(o, q, M.budget_data, M.ledger)
        if d is not None and M.c_ras_wm.certify_data(d, o):
            return M.execute_data_action(d)               # 采集，不在此刻定案
        mode, lam = M.las.degrade(o, modes, A_L, u_data)
        return M.execute(mode, lam, reason="data_contract")

    # 2) 许可门：R69 的候选动作/信息动作也要被许可
    g = (M.mint.choose_interaction(modes, o, M.budget)
         if U_epi > TAU_EPI else None)
    if g is not None and not M.las.licensed_info(g, A_L):
        g = None                                           # 未许可的「问」也不许问
    if g is not None:
        U_epi = M.cia.update_belief(modes, M.cia.execute(g))

    # 3) 认知门 + 风险地板：aleatoric + 未消解 epistemic + 数据元不确定性
    A_exec = M.las.project(M.fmp, o, A_L, K)
    U_floor = U_ale + (U_epi if g is None else 0.0) + ETA * u_data
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))

    # 4) 认证、审计、数据收据
    k = M.c_ras_wm.certified_prefix(A_exec, ..., wm_preds)
    if u_data > TAU_DATA or not M.las.all_licensed(A_exec):
        lam = max(lam, 0.85)
        k = min(k, M.las.certified_horizon(A_exec))
    M.vqa_d.submit_async(q, A_L, g, u_data, data_receipt(o, A_exec))
    return k, lam, A_exec, (U_ale, U_epi, u_data)
```

## 4. 推导

**引理 19（支撑-泛化风险界）** 设损失 ℓ 为 L_ℓ-Lipschitz、有界 B；动作子集 A 的局部内禀维数 d_A、有效样本 n_eff、覆盖半径 r_cov。则以概率 ≥1−δ，
`|R(A) − R̂(A)| ≤ C·√((d_A log n_eff + log(1/δ))/n_eff) + 2L_ℓ·r_cov`。
证明要点：用数据动作点给 A 做半径 r_cov 的覆盖，球内用 Lipschitz，球间用 d_A 维局部图的均匀收敛。系：收缩动作空间同时降低 d_A、增大 n_eff、减小 r_cov，单调收紧可认证风险界；**收缩比减速更强，因为减速不改变 r_cov**。

**引理 20（反事实不可识别与 U_epi 幻觉）** 若行为策略在 o 附近以概率 0 选择模态 m（p_D(N(m)|o)=0），则仅由 D 构造的任何离策略估计对 m 的价值不可识别：存在两个只在 m 的结果上不同、却与 D 完全一致的世界，偏差下界为正；同时 κ_ctr(m)=0。系：R69 的 Û_epi 可把「没见过」误读成「没歧义」；没有 DQC 的 U_epi 不是可识别量。

**引理 21（元不确定性门控）** 若 VoI 对模态权重是 L_V-Lipschitz 的，则 `|V̂oI−VoI| ≤ L_V·U_data`。当 `U_data > (VoI−c)/L_V` 时，`V̂oI−c` 的符号不可认证：存在两个与数据一致、最优决策相反的世界。故元门是防止在错误信念上计算 VoI 的必要条件；R69 的全局 ECE 门只覆盖平均校准，是本文特例。

**引理 22（鲁棒 DQC 与投毒界）** 截尾/中位数均值 + provenance 加权下，若污染比例 ε<β，则 `|q̂−q| ≤ C(√(log(1/δ)/n_eff)+ε)`；伪造许可需同时满足覆盖、对比、漂移、来源独立四类条件，k_min 个独立 provenance 源下误接受率 ≤ `exp(−n_eff·ψ(ε)) + g(ε,ρ_prov)`。系：R69 的「k 源一致」必须按 provenance 折算成 k_eff。

**定理 18（CALIPER 严格包含 R69）** A99–A104 下，当 `U_data≤τ_data`、`𝒜_L=𝒜`、`κ_ctr≥κ_min`、`ρ_prov≥ρ_min` 且不触发数据动作时，CALIPER 的决策与 R69 的 MINT/VoI/λ_floor 逐指令相同；一般情形下每个执行动作要么在已认证许可单元内、要么是认证过的数据动作、要么是 π_fb，故安全侧可认证风险不劣于 R69。R69 = 「数据无限好、动作空间全许可」边界；效率侧获 licensing bonus，安全侧不让步。

**定理 19（许可安全与无突变）** 每个许可单元的 conformal 风险上界 ≤ ε_L（覆盖率 1−α）⇒ 执行期望风险 ≤ ε_L+αB；TTL 到期按 C1→C4 阶梯降级，λ 单调不降、动作连续插值，继承 R68/R69 的换装/提交不变式 ⇒ 无突变；信息/数据动作均过 C-RAS-WM 认证，失败/超时/撤销回退不改变安全包络。

**定理 20（数据动作不自许）** 在「不自许」纪律下，单次数据动作对其自身目标区域许可的证据贡献至多 1/k_min；许可需 k_min 个独立 provenance 源或独立留出确认。故数据采集不能自支撑许可循环，Goodhart 不能单靠刷 DQC 分数获许可；伪造代价随 k_min 指数上升（引理 22）。

**定理 21（收缩的 Pareto 性）** `max_𝒜 U_task(𝒜) s.t. R_upper(𝒜)≤ε_L` 的解位于 (任务效用, −可认证风险) 的下凸包；当 r_cov 大时，保留未支撑动作的方案在「单位效用风险」上严格劣势。故收缩是把不可认证的效用换成可认证的效用。

## 7. 本轮最大风险

**一句话**：CALIPER 的全部安全性都押在「数据质量证书本身可信」上——**若 DQC 的参照系与许可证都由同一批可能被选择偏置、漂移或投毒的数据生成，系统就会拿着一份看似合法的许可证，在最缺数据支撑的动作子空间里做最自信的动作，把 R69 的「问错」升级为「合法地做错」**。

**次级风险与缓解**：证书循环自证（QoQ 独立留出 provenance + 元校准门）；许可过度收缩导致任务不可用（Pareto 前沿 + 数据动作恢复覆盖）；数据动作越界/刷数据（RAS-WM‡ 认证 + 不自许纪律 + 数据预算）；provenance 伪造与共谋（k_eff 折算 + 鲁棒 DQC + 多源独立留出）；实时预算被 DQC 击穿（单元级证书缓存 + 漂移触发重算 + 热路径查表）。
