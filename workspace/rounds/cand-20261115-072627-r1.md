# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；本轮灵感：「激光雷达」×「意图理解」）

> R69 把不确定性一分为二，并给了 epistemic 一条出路：看不清就问、就凑近、就等。但它默认「答案」是一个**静止的、被问就老实回答的隐变量**。现实里最贵的不确定性不是「我该选哪个动作」，而是「**对面那个人到底想干什么**」——他会不会让、是不是没看见我、他下一步是直行还是突然横穿。这个隐变量有三个 R69 没处理的性质：
> 1. **它被遮挡**：任何单一视角都只看得到世界「朝向我的那一面」，而意图恰恰更多写在背面与远处；「没看到」不等于「不存在」。
> 2. **它有二阶结构**：对方的行为取决于**他以为我在干什么**；两只智能体互相看不见，才最容易出事。「不让路」可能不是敌意，而是**他根本没看见我**。
> 3. **它会被主动伪造**：LiDAR 可被注入假点云（phantom），也可被「擦除」真目标（removal）；一个幻影点云就是一条幻影意图，而**擦除与遮挡在单视角下不可区分**。
>
> 本轮两个灵感正好咬合：
> - **激光雷达**是唯一「知道自己看不见什么」的传感器——点云里物体背后的角度空扇区就是可测量的遮挡；它还能给 FMCW 径向速度、强度/材质、点分布/步态等意图证据；
> - **意图理解**要求**视角采择（perspective-taking）**：不仅推断对方的目标，还要推断对方的**知识状态**——他能不能看见我。
>
> 核心命题：**把「他者意图」建模成一个带可见性算子的二阶隐变量（目标 × 觉察），用遮挡一致的似然去推断，用因果 VoI 去选择「换个视角看」还是「主动让他看见我」，并用 CVaR 在「可信意图支撑集」上做最坏情况安全；只有当 R69 的交互收益为负、意图校准失效或物理认证失败时，才退化为 R69 的纯保守。** 命名 **LUCID-RAS**（LiDAR-grounded, Uncertainty-aware, Causal Intent Disambiguation）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**他看见我了吗、他想要什么、我怎样让他看懂我**」——意图不是一个待估计的标量，而是一个由**互相可见性**构成的对局。

## 0. 直觉与动机

**灵感 1（LiDAR 的「自知无知」→ 遮挡是可测量的）**
直觉：相机给我一张图，但我很难说清「图外/被挡住的部分本来会是什么」；LiDAR 是主动测距，**每条射线的空返与命中都在显式地描绘遮挡边界**——物体背后的角度扇区就是它投下的「几何阴影」。于是「没观测到某条线索」可以被拆成三种互不相同的状态：**看得见但没采到（稀疏/采样）、看不见（遮挡/视场外）、低于分辨率**。只有第一种是「缺失数据」，后两种是「结构性不可观测」。把三者混为一谈，就会把「他没打手势」误读成「他不打算转弯」。这正是缺失非随机（MNAR）问题：**看不见的概率本身依赖于意图**（想隐藏、想抢行的人更会待在遮挡后）。

**灵感 2（意图 = 目标 × 觉察 → 理论心智）**
直觉：一个行人站在路边不动，可能是「让我先过（友善）」，也可能是「他没看见我（无知）」，还可能是「他在等同伴（与我无关）」。同样的运动学，三种意图。区分它们的关键不是轨迹，而是**他能不能看见我**：他的头朝向、身体朝向、以及我和他之间有没有遮挡物。这就是认知科学里的**错误信念/视角采择**：要预测他，必须模拟**他的观测**。LiDAR 能给出他所在位置的第一手几何，从而估计「从他那条射线出去，我是否在他的可见集里」——即**二阶可见性**。忽略二阶可见性，系统会把「未被看见」系统性误判成「敌意」，进而过度保守或做出错误博弈。

**灵感 3（LiDAR 的意图证据不止位置）**
直觉：我们平时靠「他朝哪走、走多快、身体朝向、有没有回头、手里拿没拿东西」读意图。LiDAR 其实能提供相当一部分：
- **FMCW 径向速度**：瞬时接近/远离速度，比帧间差分早一个节拍，尤其对「减速让行」与「加速抢行」的区分；
- **微多普勒**：肢体摆动/步态节律，可区分「正常行走」与「起跑/转身」；
- **强度/回波**：反光衣、车牌、路面材质，提供身份与可预测性线索；
- **点分布与法向**：躯干/头部朝向、步幅、是否推车/拄杖；
- **时序轨迹**：横摆率、加速度、与路缘的接近速率。
所以意图证据是一个**多物理通道的集合**，而不是「把轨迹外推 0.5 秒」。但这些通道**各自有不同的可见性与伪造难度**——这正是下面认证层的抓手。

**灵感 4（看他 ≠ 动他 → 因果 VoI）**
直觉：R69 的「问」假设回答是一个固定隐变量，问了就拿到。但对物理世界里的他者，**你观察他的方式会改变他**：你往前蹭一点去「看清」，行人可能因此停下、后退或加速；你闪一下灯，他可能让、也可能被激怒。观测与干预在这里不可分离（因果推断里的 observational vs interventional）。于是「值不值得看」不能只用互信息算，还要减去**你这次动作诱发的意图漂移与风险**。更微妙的是：有些歧义**看多久都解不开**（让行与「停下系鞋带」在完全可见下也产生相同证据），只能靠「等」或「设计一个对两种意图都安全的动作」——**时间/机动本身就是探针**。

**灵感 5（意图也会被伪造，且擦除躲进遮挡里）**
直觉：LiDAR 的注入攻击可以在空中造出一个不存在的「行人」，擦除攻击可以让一个真实行人从点云里消失。对意图系统而言，前者是**幻影意图源**（会诱发无谓的让行/追问），后者更阴险：**「消失」与「被挡住」在单视角下是同一个观测**，于是攻击者可以永远躲在遮挡歧义里。这与 R69 的「幻影模态」同构，但发生在物理层：**你无法只靠一个视角证明「那里本来有人」**。所以认证不能只看单帧几何，必须有**冗余视角/多物理通道一致性**，并且安全策略要在「最坏可信意图」上成立，而不是在平均意图上。

## 1. 形式化定义（增量：定义 310–329）

**定义 310（LUCID-RAS 总览）** LUCID-RAS = (ToM-IB, VOP, MNAR-L, IUD, CVoI, CRA, LPA, ISV, LEG, ICG, RAS-WM‡)。五条不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **二阶可见性先于意图推断**：任何他者证据入信念前，必须先由 VOP 标注其可见状态（可见/遮挡/视场外/欠分辨率）；
(iii) **绝不把「不可见」当作「不存在」**：隐藏证据一律边缘化，不做负向填补；
(iv) **安全在支撑集上成立**：风险用 CVaR_α 在意图信念的可信支撑集上评估，α 由安全等级给定；
(v) **物理认证与冗余**：未通过 LPA 的点云不得产生意图假设；对「擦除 vs 遮挡」必须由 ISV 保证至少一个冗余视角，否则按「可能存在未见的智能体」处理。

**定义 311（意图假设空间：目标 × 觉察）** 对每个他者 j，意图 m_j = (g_j, α_j)，其中 g_j ∈ 𝒢_j 为目标/行为模式（让行、抢行、直行、横穿、转向、停驻、跟随…），α_j ∈ {A, U, ?} 为**觉察状态**：A = 他看见了我，U = 他看不见我（遮挡/视场外/分心），? = 不确定。联合意图 M = (m_1,…,m_n)。保留一个**开放假设** m_⊥（「未知/新意图/欺骗性意图」），其余假设构成闭集 ℳ_0，ℳ = ℳ_0 ∪ {m_⊥}。**m_⊥ 的信念不得被压到 0**（否则就是闭世界幻觉）。

**定义 312（LiDAR 意图证据元组）** 对 j 的单帧证据 e_j = (P_j, Ī_j, v̂_{r,j}, φ_j, τ)，其中 P_j 为落在 j 上的点集（含法向），Ī_j 为回波强度统计，v̂_{r,j} 为 FMCW 径向速度（或不可用 ⊥），φ_j 为点分布导出的形状/朝向/步态特征，τ 为时间戳。多帧构成证据序列 e_{j,1:t}。**关键：e_j 的每个分量都带一个可见性标签（定义 313），且可能整段缺失。**

**定义 313（一阶可见性算子 VOP-ego）** 给定自车传感器位姿 x_s、占据栅格 O 与他者几何 Ĝ_j，VOP 做射线投射得到 V^{ego}_j ∈ {VIS, OCC, OOF, SUB}^d，逐证据通道标注：VIS = 有有效回波且非遮挡；OCC = 被 O 遮挡（含他者自遮挡，即背面）；OOF = 视场外；SUB = 低于角分辨率/距离分辨率。定义可见率 ρ_j = |VIS|/d。**OCC 与 OOF 是结构性缺失，只能通过换视角/换传感器消除；SUB 只能通过驻留/累积消除。**

**定义 314（二阶可见性 / 理论心智算子 VOP-other）** 由 j 的估计位姿与朝向 (p̂_j, R̂_j)、其感官视场模型 F_j（人：头-眼视场；车：传感器 FOV），从 j 的「眼睛」向自车做射线投射，得到 V^{j→ego} ∈ {VIS, OCC, OOF, SUB}，即**他是否看得见我、看得见我哪一部分**。定义觉察先验 p(α_j | V^{j→ego})：V^{j→ego}=VIS ⇒ α=A 概率高；OCC/OOF ⇒ α=U 概率高；SUB/朝向不确定 ⇒ α=?。**注意 V^{j→ego} 本身是估计，需带不确定度并随后验边缘化。**

**定义 315（遮挡一致的意图似然 MNAR-L）** 对可见通道取似然，对不可见通道**边缘化而非置零**：
p(e^{obs}_j | m_j, V) = ∫ p(e^{obs}_j, e^{hid}_j | m_j) de^{hid}_j = E_{e^{hid}~p(·|m_j)}[p(e^{obs}_j | e^{hid}, m_j)]。
在通道条件独立近似下：不可见通道对似然只贡献因子 1（不提供证据）；可见但未采到则按采样模型（SUB/稀疏）加权，而非按「不存在」。若 V 与 m 独立（MAR），该式无偏；若 V 依赖 m（MNAR），用敏感度参数 Γ 做敏感度分析（定义 319、引理 19）。**禁止使用 p(e_κ=∅|m) 作为「无线索」证据。**

**定义 316（ToM 条件信念更新，含意图漂移）** 
b_{t+1}(m) ∝ [ p(e_t | m, V_t) · p(V_t | m)^{λ_V} ] · (T_κ b_t)(m)，
其中 T_κ = (1−κ)·I + κ·π_0 为**意图漂移核**（κ 为单位时间「改主意」风险，意图半衰期 τ_{1/2}=ln2/κ），π_0 为无信息先验；p(V_t|m) 捕获「看不见本身也是线索」（MNAR 部分，λ_V 由敏感度分析给出，默认 0 表示只用 MAR 主估计）。对 m_⊥ 单独更新并设下限 b(m_⊥) ≥ b_min。

**定义 317（意图不确定性三分）** 
- **可换视角消解 R** = H(b) − E_{V'}[H(b | e^{V'})]，V' 取当前机动/扫描允许的视角集；
- **观测等价不可约 I** = E_{V_full}[H(b | e^{full})]，即在**完全可见**下仍无法区分的意图类（如「让行」vs「停下系鞋带」都表现为减速）；
- **觉察歧义 A** = H(α | e)，主要由 V^{j→ego} 的不确定度决定。
三者语义不同、不做简单加和：R 值得主动观测，I 只能靠**时间**或**设计对两类都安全的动作**，A 值得用「让他看见我」的动作去消解（定义 323）。

**定义 318（因果 VoI 控制器 CVoI）** 把信息动作分成两类：
- **观测型** g_obs（换车道偏移、扫描 ROI、驻留、绕行以获得新视角）：p(y|do(g_obs), b) ≈ p(y|g_obs, b)，不改他者意图；
- **干预型** g_int（前蹭、闪灯、鸣笛、驶入其视野、减速示让）：**会改变他者意图/觉察**，必须用响应模型 p(m'|do(g), b, V^{j→ego})，即定义 319 的介入核。
定义
CVoI(g) = H(b) − E_{y~p(·|do(g),b)}[H(b|y)] − E[ΔRisk_induced(g)] − c(g)，
选择 g* = argmax CVoI(g)，且要求 g 通过 C-RAS-WM 认证、预算允许、CVoI > 0；否则不动作，走 R69/R68 兜底。**观测型是 g_int 的特例（介入核恒等）；R69 的「问」是 g_int 在信息源为人类回答时的退化。**

**定义 319（社会响应 / 介入核）** 
p(m'_j, α'_j | do(g), b, V^{j→ego}) = R_g[ b ]，R_g 由三类先验构成：(a) **觉察更新**：g 若使自车进入 j 的可见集，则 α': U→A 的转移概率上升；(b) **行为响应**：g 的类型（示让/逼近/鸣笛）按社会规范先验改变 g_j；(c) **反事实风险**：若 g 使 j 产生「必须抢行」的后验，该分支计入 induced risk。R_g 参数须**在线可辨识或带保守包络**，不得假设对方一定合作（否则就是 R69「互动投毒」的物理版）。

**定义 320（CVaR 支撑鲁棒安全 CRA）** 对候选策略 π 与意图信念 b，定义意图条件风险 R(π|m)（碰撞/急刹/违规的加权）。安全风险取**条件风险价值**：
Risk_α(π; b) = CVaR_α{ R(π|m) : m ~ b }，
即最坏 (1−α) 质量上的条件期望。α→1 退化为「可信支撑集上的最坏情况」，α→0 退化为 R68/R69 的期望风险。定义鲁棒缩放 λ_rob = λ_floor(Risk_α)。**决策规则：λ = max(λ_floor(U_ale + 未消解 U_epi), λ_rob)，安全等级越高 α 越大。** 对 m_⊥ 赋一个不小于 b_min 的风险上界 R_⊥，保证开放世界不被忽略。

**定义 321（LiDAR 物理认证 LPA）** 对每个点云/航迹给出一致性分 c_phys ∈ [0,1]，由六项检验的加权与门组成：
1. **ToF/距离合理性**：距离在传感器量程与场景几何内；
2. **强度-几何一致**：回波强度与法向/入射角/材质先验相容（掠射角异常亮 ⇒ 可疑）；
3. **多普勒-几何一致**：FMCW v̂_r 与航迹微分一致；注入假点常给出不连贯的多普勒场；
4. **局部结构连贯**：真实表面产生稠密、法向一致的邻域；注入常呈稀疏/闪烁/单层「鬼点」；
5. **多径/鬼影签名**：真实多径在时间上随几何连续漂移，注入常跳变；
6. **跨模态一致**：雷达径向速度/相机外观（若有）与点云一致。
c_phys < τ_phys ⇒ 该证据被**隔离**（不进入意图信念，生成审计记录），并按「可能存在被擦除的智能体」进入 ISV 的冗余需求。**LPA 只降低被欺骗概率，不能证明真实性**（引理 22）。

**定义 322（擦除-遮挡不可区分与冗余需求 ISV）** 给定单视角 V，称攻击 a_rem（擦除真实智能体 j）与遮挡配置 o_occ **观测等价**，若二者产生相同的 (P, Ī, v̂_r) 分布。ISV 要求：对每个可能承载智能体的区域，至少存在两个**视角差异足够大或物理通道不同**的观测源，使 a_rem 与 o_occ 的可观测分布可分（分离度 ≥ δ_sep）；否则该区域的意图状态置为「未知且可能有智能体」，风险按 R_⊥ 计。视角由 g_obs 或自车机动获得，受预算约束。

**定义 323（可读性与唤醒动作 LEG：对偶通道）** R69 只问「我如何降低我对世界的不确定」；LEG 增加「**我如何降低世界对我的不确定**」。增广动作再加 g_leg = (g_signal, g_alert, g_glance)：
- g_signal：轨迹微调（轻微减速、横向偏移、转向灯时序），使其**可读**而不显著改变可行域；
- g_alert：灯光/声音/主动进入对方可见集，目的把对方的 α: U→A；
- g_glance：可被感知的注视/让行姿态（对人类有效）。
定义可读性收益 LegVoI(g_leg) = E[ H(b^{¬ego}(m_ego)) − H(b^{¬ego}(m_ego) | y) ]，其中 b^{¬ego} 为他者对我的意图信念；并以「他者的最坏响应风险」下降为最终判据。**只有对方 α=A 时 g_leg 才可能有效；α=U 时唯一有效的是 g_alert 或进入其视野。**

**定义 324（意图校准门 ICG）** 意图信念需校准：可靠图与 ECE_int（按 g 与 α 分层）。ECE_int > τ_int ⇒ 禁用点估计意图与 CVoI，改为**全支撑最坏情况**（ℳ_0 上均匀支撑 + m_⊥ 上限），等价于「所有意图都可能」的 R68 纯保守。类比 R69 的 MCG：**不可信的意图分布不得驱动交互或让行决策。**

**定义 325（两级鲁棒退避，含 ToM 收益）** 
- 若 R 被消解、A 被唤醒、物理认证通过且 ECE_int ≤ τ_int：λ = max(λ_floor(U_ale + I), λ_rob(窄支撑))（获得 **ToM resolution bonus**：只对观测等价类 I 保守）；
- 若任一失败（不可观测/校准越界/认证失败/超预算/介入核不可信）：λ = max(λ_floor(U_ale + U_epi + I), λ_rob(全支撑 ∪ m_⊥))，且 ISV 未满足时再叠加 R_⊥。
⇒ R69 是「单视角、α 已知、无攻击、意图静止」的边界；安全侧永不弱于 R69。

**定义 326（主动视角/扫描分配）** 在预算内选择 g_obs 使 R 的期望下降最大：g_obs* = argmax_{g_obs} [ E_{V'}[H(b) − H(b|e^{V'})] − c(g_obs) ]，s.t. 机动安全认证。对 LiDAR 具体化为：扫描 ROI 分配、驻留时间、自车横向偏移/减速以获得视差。**没有新视角时，R 的估计必须按当前 V 截断，不得假装可消解。**

J_LUCID = (J_FLUID, intent_ece, occlusion_coverage, vis_audit_hash, phys_auth_rate, removal_ambiguity_mass, cvar_alpha, robust_margin, legibility_gain, intent_half_life, lucid_ver)。

**定义 328（威胁集 AIC-LUCID）** ℰ_LUCID = ℰ_FLUID × ℰ_spoof × ℰ_strategic × ℰ_occ，其中 ℰ_spoof = {点云注入（幻影）、擦除（隐身）、多普勒/强度伪造、重放}；ℰ_strategic = {利用让行习惯的博弈性抢行、以遮挡为掩护的突然横穿、伪装成 unaware 的欺骗}；ℰ_occ = {自然遮挡、自遮挡、传感器 FOV 盲区、天气导致的稀疏化}。**注意 ℰ_occ 与环境是同一件事，不可当纯攻击处理，否则会过度保守。**

## 2. 关键算法骨架

```python
# IP-264 ToM-IB: 意图 = 目标 × 觉察；带漂移核与开放假设
class ToMBelief:
    def __init__(self, goals, hazards, b_min):
        self.M = [(g, a) for g in goals for a in ('A', 'U', '?')] + [('bot', '?')]
        self.kappa, self.b_min = hazards, b_min

    def update(self, b, e, V, v_other):
        lik = occlusion_consistent_likelihood(e, V, self.M)      # 不可见通道边缘化
        lik *= awareness_prior(v_other)                          # 二阶可见性 -> alpha
        b = normalize(lik * ((1 - self.kappa) * b + self.kappa * self.prior))
        b[('bot', '?')] = max(b[('bot', '?')], self.b_min)       # 开放世界下限
        return b

# IP-265/266 VOP + MNAR-L: 先标可见性，再算似然
def visibility_maps(x_s, occupancy, agent_pose, ego_pose, other_fov):
    V_ego   = raycast(x_s, occupancy, agent_pose)                # 我看他
    V_other = raycast(agent_eye(agent_pose), occupancy,
                      ego_body(ego_pose), fov=other_fov)         # 他看我
    return V_ego, V_other

def occlusion_consistent_likelihood(e, V, hypotheses):
    out = {}
    for m in hypotheses:
        p = 1.0
        for ch, st in V.items():
            if st == 'VIS':        p *= emission(ch, e, m)       # 只对可见通道计似然
            elif st in ('OCC', 'OOF'): p *= 1.0                  # 结构性不可见不提供证据
            else:                  p *= sampling_weight(ch, m)   # SUB 按采样模型加权
        out[m] = p
    return out

# IP-267/268 CVoI: 观测型 vs 干预型；扣掉诱发的风险
def causal_voi(b, action, V_other, model):
    if action.kind == 'obs':
        y_dist, induced = model.observe(action, b), 0.0      # 不改意图
    else:
        y_dist, induced = model.do(action, b, V_other), \
                          model.induced_risk(action, b, V_other)  # 介入核 R_g
    return entropy(b) - expected_entropy(b, y_dist) - induced - action.cost

# IP-269 CRA: 在可信支撑上取 CVaR，m_bot 给上限
def robust_lambda(policy, b, alpha, R_bot):
    risks = [(b[m], risk(policy, m)) for m in support(b, alpha)]
    risks.append((b_bot_floor, R_bot))                           # 开放世界兜底
    return lam_floor(cvar(risks, alpha))

# IP-270 LPA: 物理一致性认证（只降概率，不证真）
def physical_auth(cloud, track, radar=None, cam=None):
    checks = [tof_plausible(cloud), intensity_geometry(cloud),
              doppler_geometry(cloud, track, radar), local_structure(cloud),
              multipath_signature(cloud, track), cross_modal(cloud, radar, cam)]
    return weighted_and(checks)

# IP-271 ISV: 擦除 vs 遮挡的可分性；不够就按「可能有未见智能体」
def vantage_sufficiency(region, views, delta_sep):
    if separation(removal_model(region), occlusion_model(region), views) < delta_sep:
        return False, R_bot
    return True, 0.0

# IP-275 主闭环（继承 R69 闭环）
def LUCID_RAS_round(M, obs, other_agents):
    z, o = M.mtm.forward(obs)
    c, U_cal, _ = M.cof.step(z)
    V_ego, V_other = M.vop.maps(M.pose, M.occupancy, other_agents)
    ok, c_phys = M.lpa.authenticate(obs.cloud, other_agents)     # 1) 物理认证
    b = M.tomib.update(M.tomib.b, obs.evidence, V_ego, V_other)  # 2) 遮挡一致信念
    if not ok:
        b = M.tomib.widen(b)                                     # 认证失败 -> 支撑变宽
    suffic, R_bot = M.isv.assess(other_agents, M.views)
    R, I, A = M.iud.decompose(b, M.views)                        # 3) 三分
    if M.icg.ece(b) > TAU_INT:                                   # 校准越界 -> 全支撑最坏
        lam_rob, g = M.cra.full_support(M.planner, R_bot), None
    else:
        g = M.cvoi.choose(b, V_other, M.budget, M.responder)     # 4) 因果 VoI
        if g and g.kind == 'obs':
            M.views = M.vop.apply(g)                             # 换视角后可再观测
        lam_rob = M.cra.robust(M.planner, b, M.alpha, R_bot)
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + R + I),
              lam_rob, R_bot if not suffic else 0.0)             # 5) 鲁棒退避
    A = M.ach.propose(M.planner, b, H=M.vista.H)
    if g is not None:
        A = A.with_info(g)
    leg = M.leg.choose(b, other_agents, M.budget)                # 6) 对偶通道
    if leg is not None:
        A = A.with_legibility(leg)
    k = M.c_ras_wm.certified_prefix(A, ..., M.wm_preds)          # 含 g / leg
    tau = M.pi_sigma.prefix_dispatch(A.task[:k]) * lam
    M.vqa_i.submit_async(g, leg, b, V_ego, V_other, c_phys)      # 审计含可见性与认证
    return k, lam, b, (R, I, A)
```

## 3. 推导

**引理 19（遮挡下的负向填补偏差）** 设通道 κ 在意图 m 下以概率 q_κ(m) 存在、以概率 ρ_κ(V,m) 可见。若用「未观测到 ⇒ 不存在」的朴素似然，则对 q_κ>0 的意图，其后验被系统性压低；当 ρ 与 m 独立（MAR）时，偏差可被 1/ρ 的逆概率权重完全校正；当 ρ 依赖 m（MNAR，例如「隐藏型」意图更常处于遮挡后）时，朴素后验的 KL 偏差 ≥ (1−ρ̄)·D(q(·)‖δ_0) − O(ρ̄)，且**不可由单视角数据辨识**，必须显式给出敏感度上界 Γ。系：**「没看见手势」不能被当作「不打算转弯」的证据**——这是 R69 把「未消解」视同「噪声」在感知侧的同构错误。

**引理 20（观测 VoI 与因果 VoI 的差）** 若干预 g 使对方产生「抢行」响应的概率为 η(g)，则该分支的意图熵与风险上升。于是 CVoI(g) = VoI_obs(g) − η(g)·ΔH_response − E[ΔRisk_ind] − c。存在 η(g)>0 使 VoI_obs > 0 而 CVoI < 0：**「看清了，但把他逼成了抢行」**。故任何以互信息为唯一准则的主动感知，在有人场景下都会系统性高估「看」的价值。系：R69 的 MINT 在信息源为物理他者时不是 VoI 最优，必须换成 CVoI。

**引理 21（CVaR 的相干性与支撑界定）** Risk_α 关于 π 单调、次可加、正齐次、平移不变（相干风险度量），且 α=1 时等于支撑集上最坏值、α=0 时期望值。若真实意图以概率 ≥ 1−δ 落在所用支撑集内，则对任意 π，R(π|m) 超过 Risk_α 的概率被 (1−α) 与 δ 共同界定。系：R68/R69 的「期望风险 + λ_floor」是 α=0 的边界；意图这种**策略性/对抗性**不确定性必须用大 α。

**引理 22（擦除-遮挡的不可区分性）** 对单视角 V，存在遮挡配置 o_occ 与擦除攻击 a_rem 使二者观测分布完全相同（把「被墙挡住」与「被攻击者抹掉」映射到同一空扇区）。因此在单视角下任何检测器的 AUC ≤ 0.5 + o(1)。只有当存在视角差/通道差使两假设的可观测分布 TV 距离 ≥ δ_sep 时，才可分辨。系：**「没看见有人」在单视角下永远不能作为「没有人」的证据**；ISV 的冗余需求是安全性的必要条件，而非工程优化。

**引理 23（可读性降低联合最坏风险）** 若对方对我意图的信念为 b^{¬ego}，且其响应在最坏信念上取值（不确定性厌恶），则 LegVoI>0 的动作使其最坏响应风险弱下降；但当 α=U（他看不见我）时，轨迹微调的可读性收益为 0，唯一有效的是把 α 推向 A 的 g_alert。系：**「我表达清楚」只在对方看得见时有用**——这解释了为什么对分心行人的礼让经常失效。

**定理 18（LUCID 严格包含 R69/FLUID）** 在「单视角完全可见、α 已知、意图静止、无攻击、无策略性」的退化条件下，VOP 全 VIS、MNAR-L 退化为普通似然、CVaR_α 取 α=0、ISV 恒满足，LUCID 的决策与 FLUID 逐指令相同；在一般条件下，LUCID 的安全风险（CVaR）≤ FLUID 的期望风险 + 支撑外质量上界，且当 R=I=A=0 时效率不低于 FLUID。故 R69 是 LUCID 在「全可见 + 无二阶结构」边界上的退化。

**定理 19（校准意图下的鲁棒安全裕度）** 若意图信念在 TV 距离 ε 内校准、且物理认证的漏检率 ≤ δ_p，则使用 CVaR_{1−δ} 与 R_⊥ 兜底的策略，其真实最坏风险 ≤ Risk_α + L·(ε+δ_p) + (1−α) 项，其中 L 为风险对意图分布的 Lipschitz 常数。系：**校准误差与伪造漏检可以直接折算成安全裕度的线性损耗**，这给了 ICG 阈值 τ_int 与认证阈值 τ_phys 一个可计算的安全解释，而不是拍脑袋。

**定理 20（交互/视角切换的无突变）** 意图假设切换带迟滞、λ 在切换时单调不降、RAS-WM‡ 对 g_obs/g_int/g_leg 与任务动作做统一前缀认证 ⇒ 控制量连续、无突变；R69 的换装/提交不变式保持。系：**「多看一眼」和「让他看见我」都不能成为安全包络的漏洞**。

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** `LUCID-RAS`；零学习写操作继承；二阶可见性先于意图推断；绝不把不可见当不存在；安全在 CVaR 可信支撑上成立；未过 LPA 的点云不得产生意图，擦除/遮挡须由 ISV 冗余可分否则按 `R_⊥` 保守。

**定义 311–312（意图空间与证据）** 意图 `m=(g,α)`，α∈{A,U,?}，保留 `m_⊥` 且 `b(m_⊥)≥b_min`；证据 `e=(P,Ī,v̂_r,φ,τ)`，每分量带可见性标签，可整段缺失。

**定义 313–314（双可见性 VOP）** 一阶：自车向他者射线投射得 `V^{ego}`；二阶：由他者位姿/朝向与其感官 FOV 向自车投射得 `V^{j→ego}`——**他是否看得见我**。`p(α|V^{j→ego})` 把「看不见」映射为「unaware」而非「敌意」。

**定义 315（MNAR-L）** `p(e^{obs}|m,V)=∫p(e^{obs},e^{hid}|m)de^{hid}`；不可见通道贡献 1，可见未采按采样模型加权；MAR 用 1/ρ 逆概率校正，MNAR 用敏感度 Γ；**禁止 `p(e=∅|m)` 作负证据**。

**定义 316（ToM 信念更新）** `b_{t+1} ∝ [p(e|m,V)·p(V|m)^{λ_V}]·T_κ b_t`，`T_κ=(1−κ)I+κπ_0`；意图非平稳，半衰期 `ln2/κ`。

**定义 317（三分）** `R`（换视角可消解）、`I`（完全可见仍不可分，如让行 vs 系鞋带）、`A`（觉察歧义）；分别对应「看/换视角」「等/设计安全动作」「唤醒/让他看见我」。

**定义 318–319（CVoI 与介入核）** `g_obs` 不改意图；`g_int` 须用 `p(m'|do(g),b,V^{j→ego})=R_g[b]` 建模觉察更新、行为响应、反事实风险。`CVoI = 信息增益 − 诱发风险 − 成本`，`CVoI≤0` 即不动。

**定义 320（CVaR 鲁棒安全）** `Risk_α(π;b)=CVaR_α{R(π|m)}`；`λ=max(λ_floor(U_ale+未消解 U_epi), λ_rob)`；`m_⊥` 赋 `R_⊥` 上界，开放世界不被忽略。

**定义 321–322（LPA 与 ISV）** 六项物理一致性认证 `c_phys<τ_phys` 即隔离；单视角下擦除与遮挡观测等价（AUC≤0.5+o(1)），故须冗余视角使 TV 距离 ≥ `δ_sep`，否则按「可能有未见智能体」处理。

**定义 323（LEG 对偶）** `g_signal`（轨迹可读）、`g_alert`（把 α: U→A）、`g_glance`（可被感知的让行/注视）；`LegVoI` 只在对方 `α=A` 时非零，否则唯一有效的是 `g_alert`。

**定义 324–325（ICG 与两级退避）** `ECE_int>τ_int` ⇒ 禁用点估计与 CVoI，全支撑最坏；消解成功且认证通过 ⇒ `λ=max(λ_floor(U_ale+I), λ_rob(窄支撑))`（ToM resolution bonus）；任一失败 ⇒ 全支撑 ∪ `m_⊥` 并叠加 `R_⊥`。R69 是「单视角全可见、α 已知、无攻击、静止意图」边界。

**定义 326–329（视角分配/证书/威胁/迟滞）** `g_obs*=argmax[E[H(b)−H(b|e^{V'})]−c]`，无新视角则 R 按当前 V 截断；`J_LUCID` 并入 ECE_int、遮挡覆盖、认证率、擦除歧义、CVaR α、鲁棒裕度、可读性收益；`ℰ_LUCID=ℰ_FLUID×ℰ_spoof×ℰ_strategic×ℰ_occ`；意图切换带迟滞且 λ 单调不降，`g_obs/g_int/g_leg` 与任务动作统一过 RAS-WM‡ 认证。

```python
# IP-264 ToM-IB
class ToMBelief:
    def update(self, b, e, V, v_other):
        lik = occlusion_consistent_likelihood(e, V, self.M)
        lik *= awareness_prior(v_other)                       # 二阶可见性 -> alpha
        b = normalize(lik * ((1-self.kappa)*b + self.kappa*self.prior))
        b[OPEN] = max(b[OPEN], self.b_min)                    # 开放世界下限
        return b

# IP-265/266 VOP + MNAR-L
def visibility_maps(x_s, occ, agent_pose, ego_pose, other_fov):
    return (raycast(x_s, occ, agent_pose),                  # 我看他
            raycast(agent_eye(agent_pose), occ,
                    ego_body(ego_pose), fov=other_fov))      # 他看我

def occlusion_consistent_likelihood(e, V, H):
    out = {}
    for m in H:
        p = 1.0
        for ch, st in V.items():
            if st == 'VIS':          p *= emission(ch, e, m)
            elif st in ('OCC','OOF'): p *= 1.0                 # 不可见不提供证据
            else:                    p *= sampling_weight(ch, m)
        out[m] = p
    return out

# IP-268 CVoI
def causal_voi(b, a, V_other, model):
    if a.kind == 'obs': y, induced = model.observe(a, b), 0.0
    else:               y, induced = model.do(a, b, V_other), \
                                     model.induced_risk(a, b, V_other)
    return entropy(b) - expected_entropy(b, y) - induced - a.cost

# IP-269 CRA
def robust_lambda(policy, b, alpha, R_bot):
    risks = [(b[m], risk(policy, m)) for m in support(b, alpha)]
    risks.append((b_bot_floor, R_bot))
    return lam_floor(cvar(risks, alpha))

# IP-270 LPA
def physical_auth(cloud, track, radar=None, cam=None):
    return weighted_and([tof_plausible(cloud), intensity_geometry(cloud),
                         doppler_geometry(cloud, track, radar),
                         local_structure(cloud), multipath_signature(cloud, track),
                         cross_modal(cloud, radar, cam)])

# IP-275 主闭环
def LUCID_RAS_round(M, obs, others):
    z, o = M.mtm.forward(obs); c, U_cal, _ = M.cof.step(z)
    V_ego, V_other = M.vop.maps(M.pose, M.occupancy, others)
    ok, c_phys = M.lpa.authenticate(obs.cloud, others)
    b = M.tomib.update(M.tomib.b, obs.evidence, V_ego, V_other)
    if not ok: b = M.tomib.widen(b)                          # 认证失败 -> 支撑变宽
    suffic, R_bot = M.isv.assess(others, M.views)
    R, I, A = M.iud.decompose(b, M.views)
    if M.icg.ece(b) > TAU_INT:
        lam_rob, g = M.cra.full_support(M.planner, R_bot), None
    else:
        g = M.cvoi.choose(b, V_other, M.budget, M.responder)
        if g and g.kind == 'obs': M.views = M.vop.apply(g)
        lam_rob = M.cra.robust(M.planner, b, M.alpha, R_bot)
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + R + I),
              lam_rob, R_bot if not suffic else 0.0)
    A = M.ach.propose(M.planner, b, H=M.vista.H)
    if g is not None: A = A.with_info(g)
    leg = M.leg.choose(b, others, M.budget)
    if leg is not None: A = A.with_legibility(leg)
    k = M.c_ras_wm.certified_prefix(A, ..., M.wm_preds)
    tau = M.pi_sigma.prefix_dispatch(A.task[:k]) * lam
    M.vqa_i.submit_async(g, leg, b, V_ego, V_other, c_phys)
    return k, lam, b, (R, I, A)
```

## 4. 推导

**引理 19（遮挡下的负向填补偏差）** 通道 κ 在意图 m 下以 q_κ(m) 存在、以 ρ_κ(V,m) 可见。朴素「未观测⇒不存在」系统性压低 q_κ>0 的后验；MAR 下 1/ρ 逆概率权重完全校正；MNAR 下 KL 偏差 ≥ `(1−ρ̄)·D(q(·)‖δ_0) − O(ρ̄)` 且单视角不可辨识，须给敏感度界 Γ。系：**「没看见手势」不是「不打算转弯」的证据**。

**引理 20（观测 VoI vs 因果 VoI）** `CVoI = VoI_obs − η(g)·ΔH_response − E[ΔRisk_ind] − c`；存在 η>0 使 `VoI_obs>0` 而 `CVoI<0`——**看清了却把他逼成抢行**。故 R69 的 MINT 在信息源为物理他者时须换成 CVoI。

**引理 21（CVaR 相干性）** Risk_α 单调、次可加、正齐次、平移不变；α=1 为支撑最坏、α=0 为期望。若真意图以 ≥1−δ 落在支撑内，越界概率由 `(1−α)` 与 δ 共同界定。系：R68/R69 是 α=0 的边界；策略性意图须用大 α。

**引理 22（擦除-遮挡不可区分）** 单视角下存在遮挡配置与擦除攻击观测分布完全相同，任何检测器 `AUC≤0.5+o(1)`；仅当视角差/通道差使 TV 距离 ≥ δ_sep 才可分。系：**单视角「没看见有人」永远不能证明「没有人」**，ISV 冗余是安全必要条件。

**引理 23（可读性降低联合最坏风险）** 对方响应在最坏信念上取值时，`LegVoI>0` 使其最坏响应风险弱下降；但 `α=U` 时轨迹可读性收益为 0，唯一有效的是 `g_alert`。系：**「我表达清楚」只在对方看得见时有用**——解释了分心场景下礼让失效。

**定理 18（LUCID 严格包含 R69/FLUID）** 退化条件（单视角全可见、α 已知、意图静止、无攻击、无策略性）下 VOP 全 VIS、MNAR-L 退化为普通似然、α_CVaR=0、ISV 恒满足，决策与 FLUID 逐指令相同；一般条件下 CVaR 安全风险 ≤ FLUID 期望风险 + 支撑外质量上界；`R=I=A=0` 时效率不低于 FLUID。

**定理 19（校准意图的鲁棒裕度）** 若意图信念 TV 距离 ≤ ε、认证漏检率 ≤ δ_p，则 `CVaR_{1−δ}+R_⊥` 策略的真实最坏风险 ≤ `Risk_α + L·(ε+δ_p) + (1−α) 项`，L 为风险对意图分布的 Lipschitz 常数。系：**校准误差与伪造漏检可折算成安全裕度的线性损耗**，为 τ_int、τ_phys 提供可计算解释。

**定理 20（交互/视角切换无突变）** 迟滞 + λ 切换时单调不降 + RAS-WM‡ 统一前缀认证（含 g_obs/g_int/g_leg）⇒ 控制连续、无突变；R69 换装/提交不变式保持。系：**「多看一眼」「让他看见我」都不能成为安全包络的漏洞**。

## 7. 本轮最大风险

**一句话**：LUCID-RAS 的全部安全论证都押在「意图假设空间闭合、可见性算子准确」这一前提上——**一旦真实意图落在 ℳ 之外（新颖/欺骗/恶意），或二阶可见性把「他其实看得见」估成「看不见」，一个校准良好、认证通过、CVaR 有界的系统就会以形式上的安全感，对一个它从未表示过的威胁给出「已确认安全」的结论**；而擦除攻击恰好躲进遮挡歧义里，让「没有人」与「看不见有人」继续不可区分——**最危险的不是幻觉出一个敌人，而是把敌人藏进自己的盲区并证明那里安全。**

**次级风险与缓解**：可见性算子误差（不确定度进信念 + ISV 冗余 + E303/E308）；介入核不可辨识（保守包络、不假设合作、E305/E314）；CVaR 过度保守导致死锁/冻结（α 分级 + 支撑预算 + E306/E315）；认证误报导致瘫痪（隔离而非丢弃 + 审计回灌）；意图快速漂移（漂移核 + 迟滞 + E312）；实时预算（复用占据栅格 + 缓存视角对 + E313）。
