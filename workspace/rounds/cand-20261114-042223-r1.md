# 第 71 轮（承接第 70 轮「BELIEF-RAS 贝叶斯状态估计 + 基线复现 + 原型验证」IP-264~274；灵感循环第 3 轮；本轮灵感：「记忆检索」×「人机协作」）

> R70 把 FLUID 的「动作模态 epistemic」升级为显式世界状态后验 b_t(s)，并交付了基线协议与原型验收。但它留下的最大风险极其尖锐：**b_t 会「自信地错」**——当观测模型（流似然 / 交互回答 / 标定残差）失配时，H[b_t] 变小而真实风险变大；而 R70 的全部检测通道（r_res、Δa、H[b_t]）都来自**当前 episode、当前模型**，系统没有任何「跨 episode 的经验」来质疑自己。
>
> 本轮两个灵感正好各自补一半：
> - **记忆检索**：把「单 episode 的信念」接上「跨 episode 的先例」——如果当前情境与历史上某次模型失配/缓变故障高度相似，那么「我现在很自信」本身就是可疑的。记忆给出一条**独立于当前观测模型**的经验通道。
> - **人机协作**：记忆不应是系统自说自话的数据库，而应是**人与机器共同维护、可追溯、可纠正、可撤销**的经验资产；人类不只是「被问一次的 oracle」，而是记忆的共同作者与审计者。
>
> 核心命题：**让「先例」成为第四类证据（与观测、交互、标定并列），但先例只能用于「收紧」，或在通过认证后换取有界松弛；检索的相似性绝不等于因果相关性，因此每次使用记忆都要过「记忆安全门」，且记忆可被投毒、会过时、必须可撤销。** 命名 **MNEMO-RAS**（Memory-grounded, huMaN-in-the-loop Epistemic safety for Risk-Aware Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「测量还准吗」，R69 问「向谁求证」，R70 问「我处于什么状态」，R71 问「**我见过这种情况吗，谁和我一起记得**」——安全不只是当下的判断，也是对经验的治理。

## 0. 直觉与动机

**灵感 1（记忆检索 → 先例是独立于当前模型的第四类证据）**
直觉：R70 的所有通道都在问「当前模型是否自洽」。标定残差可被标定吸收（R68 自陈风险），流似然在 OOD 上也可能过度自信（R70 自陈风险）。但人不是这样判断的：一个熟练工人觉得「这场景我见过，上次就是这么出事的」，他的警觉不来自当前传感器，而来自**经验**。跨 episode 记忆因此提供一条**不依赖当前观测模型**的证据：把当前情境放进历史先例里对照。若先例说「这种情境下模型曾系统性地错」，那么「当前很自信」反而成为警报。这把 R70 的「自信地错」从不可检测，变成一个可检验的**模型-经验不一致**。

**灵感 2（人机协作 → 记忆的共同作者、纠正者与审计者）**
直觉：记忆不是系统偷偷写的小本子。安全关键系统里，记忆必须可追责：谁提供的、何时有效、谁确认过、谁有权撤销。人类不只是被问一次的 oracle（R69 假设固定欺骗率 δ_p），而是有**履历**的来源——可以基于其历史可靠性校准信任；也是**纠错者**——可以推翻一条错误先例；还是**审计者**——要求系统给出「我为什么引用这条先例」。这就是从「人机交互」升级为「人机共同治理记忆」：协作的产物不是一句回答，而是一份双方都能质证的经验。

**灵感 3（相似性陷阱 → 表面相似不等于因果相关）**
直觉：检索的默认假设是「上下文近 ⇒ 结果近」。在安全关键场景这是最危险的假设：两个场景在视觉/语言嵌入上几乎相同（都在厨房、都拿着刀、都有个模糊的人影），但因果结构不同（一个是切菜、一个是滑倒）。若系统拿「切菜」的先例去处理「滑倒」，会**自信地做错**。所以记忆不能只按相似度使用，必须过**类比有效性**：因果标签一致 + 动作不变性检验 + 当前模型一致性。否则记忆只能做解释，不能做控制。

**灵感 4（记忆是持久攻击面 → 投毒一次、长期复用）**
直觉：R69 的交互投毒只影响一次决策；记忆投毒会影响**所有未来相似情境**。一条精心伪造的先例（「这种情况历史上就该加速通过」）可以像慢性毒药一样，在每次检索时都拿到高相似度、高权重。更糟的是，攻击者可以污染「纠错」通道本身，或用滞后撤销制造窗口。因此记忆层必须假设最坏情况：来源可伪造、共识可制造、撤销可滞后；安全门必须默认「记忆不可信」，只有通过认证的先例才获得极小权限。

**灵感 5（严格包含 → 记忆不得扩张安全包络）**
直觉：新增一层最怕「多一个需要信任的黑箱」。所以记忆层的权力必须是不对称的：它可以**收紧**（先例警告 ⇒ 更保守），只有在通过认证后才允许**有界松弛**（resolution bonus），且松弛量由验证预算控制。检索为空、门控失败、过期、撤销、超时 ⇒ 逐指令退化为 BELIEF-RAS。这样 R70 不被推翻，而是被包含为「没有可用记忆」的边界。

## 1. 形式化定义（增量：定义 331–350）

**定义 331（MNEMO-RAS 总览与四不变式）** MNEMO-RAS = (EMS, CRR, AVS, MBP, RVoI, STR, CMP, MSG, AGE, BELIEF-RAS†)。四不变式：
(i) **实时流零学习写**（继承 R68 定义 276-i）：控制环内只读冻结记忆快照，索引构建在离线完成，原子换装；
(ii) **只追加 + 哈希链**：原始 episode 只 append，纠正以 `supersedes` 边表达，绝不原地改写；
(iii) **安全非扩张**：记忆只能收紧风险，或经 MSG 认证后给予有界松弛；任何情况下不得绕过 C-RAS-WM 认证与证据纪律；
(iv) **可撤销与可追溯**：任一记录可被来源/人类撤销，撤销必须在有界延迟内对所有在线检索生效。

**定义 332（情景记忆记录 EMR）** 一条记录 e = (id, φ(o), a, y, τ_cal, log_int, prov, v, tags, h_prev)。φ 为上下文编码；a/y 为动作与结果；τ_cal 为标定轨迹摘要；log_int 为交互日志摘要；prov ∈ 𝕃 为来源格；v = [t_0,t_1) 为有效区间并绑定分布版本；tags 为因果标签（可含反事实/干预标记）；h_prev 为前驱哈希。记录不可变。

**定义 333（来源格与信任 STR）** 来源格 𝕃 = {self, human_verified, human_unverified, external, adversarial}，按可信度偏序。每个来源 h 维护 Beta 可靠性 θ_h ~ Beta(α_h,β_h)，由事后可验证结果回灌；决策只用**下置信界** θ_h^LCB = Quantile_δ(Beta(α_h,β_h))，并对非平稳作指数折减。**永不使用均值信任。**

**定义 334（记忆库与冻结快照）** EMS 为 append-only 哈希链 + WAL；索引 I_k 由离线任务在历史记录上构建（ANN + 元数据倒排 + 撤销索引 + 有效期索引），实时侧仅持有冻结快照。换装为原子指针切换，沿用 R68 提交/换装不变式：控制环永不 mutating 索引。

**定义 335（认证检索 CRR）** 给定 φ(o_t)，候选 N_k = top-k_{I_k}(φ(o_t))，依次过滤：
(a) 有效期：t_now ∈ v；
(b) 撤销/污染：id ∉ 撤销索引 R；
(c) 来源：θ_{prov(e)}^LCB ≥ τ_trust。
保留集合 S_ret(o)。检索半径 r_α 由 split-conformal 在校准集上选取，使真实结果落入检索预测集的覆盖率 ≥ 1−α（依赖 A102 的窗口内可交换性）。

**定义 336（类比有效性 AVS）** 对 e ∈ S_ret，定义因果支持 cs(e) = 1[tags 与当前因果图查询一致] · 1[action-invariance 检验通过]；模型-记忆一致性 κ(e) = 1 − d(y_e, ŷ_{b_t}(a_e))/scale；AVS(e) = cs(e)·κ(e)·θ_{prov(e)}^LCB。仅 AVS ≥ τ_ana 的记忆可进入决策；其余只可进入解释。

**定义 337（记忆残差 r_mem 与「自信地错」判据 CWS）** r_mem = W_2(P_ret(y|o), P_{b_t}(y|o))，即认证先例的经验结果分布与当前后验预测分布之间的 2-Wasserstein 距离。当 **H[b_t] 低（自信）∧ r_mem 高（先例反对）∧ S_ret 通过认证** 时，判为 confidently-wrong suspect（CWS）。这是 R70 三元组 (r_res, Δa, H[b_t]) 之外的**第四通道**，专测「模型自信但经验反对」。

**定义 338（记忆条件先验 MBP）** b_t^mem(s) ∝ b_t(s) · exp(−β·r_mem(s)) · Π_{e∈S_ret^valid} p(y_e|s)^{w_e}，w_e ∝ AVS(e)。语义：把认证先例当作伪观测（power prior）。无有效先例时 b_t^mem = b_t（严格退化）。

**定义 339（检索即动作与 RVoI）** 检索动作 q ∈ 𝒜_mem（不同 k / 半径 / 模态子集），成本 c_mem(q) 为延迟与算力。RVoI(q) = H[b_t] − E_{S_ret∼P(·|q)}[H[b_t^mem]]。q* = argmax_q [RVoI(q) − c_mem(q)]，s.t. 预算 allow_mem(q) 且预测覆盖率 ≥ 1−α。若 ≤ 0：不检索，直接走 BELIEF-RAS。同步检索超时必须走不检索分支（fail-safe）。

**定义 340（记忆安全门 MSG）** 记忆进入控制需**同时**满足：
(G1) 认证检索：S_ret 非空且覆盖率达标；
(G2) 类比有效：≥1 条 AVS ≥ τ_ana，或 k 条弱证据一致；
(G3) 来源独立：有效证据来自 ≥2 个非共谋来源（或单一 self 来源 + 模型一致性）；
(G4) 无污染告警：撤销/污染检测未命中；
(G5) 安全非扩张：记忆所致松弛 Δλ ≤ Δλ_max(verification)。
任一项失败 ⇒ 记忆降级为「只读解释」，不参与控制；U_epi 按 BELIEF 兜底。

**定义 341（记忆松弛预算与两级退避）** 仅当 MSG 全通过且非 CWS 时允许 resolution bonus：λ = λ_floor(U_ale + α·H[b_t^mem])，α = 0；否则 α = 1（BELIEF 边界）。镜像 R69/R70 的两级退避，且记忆层放松的每一分都必须由 verification 付费。

**定义 342（记忆老化与漂移失效 AGE）** 记录权重按半衰期 T_{1/2} 衰减；上下文分布与结果分布的漂移检测触发离线重建 I_k。年龄 > T_stale 或漂移超阈值的记录进入「历史层」：只可解释，不可控制。

**定义 343（交互成本先验）** 从 EMS 的 log_int 中检索相似交互，得到 c(g) 的经验分布；MINT 使用其**保守分位数**（而非均值），避免「历史上问得便宜 ⇒ 永远问」。这是 R70「审计回灌成本先验」的具体化与可证伪化。

**定义 344（协作记忆协议 CMP）** 四步：Propose（机器给出动作 + 先例证书）→ Confirm/Correct/Veto（人类三选一）→ Supersede（纠正生成带 `supersedes` 边的新记录，旧记录失效但保留）→ Revoke（来源撤销，触发撤销索引传播）。**安全包络不可被人类确认覆盖**：人类只能否决或修正语义，不能授权越界动作。

**定义 345（先例证书与可解释）** 每个使用记忆的决策输出 PrecedentCert = (S_ret 的 id 列表, AVS, r_mem, 来源与信任 LCB, 快照版本/哈希)。无证书的记忆使用视为违规；审计可复算。

**定义 346（记忆投毒威胁 ℰ_memo）** 植入伪造先例、污染来源、制造假共识、用「看起来合理」的先例诱导松弛、通过纠错通道反向注入、以及「撤销滞后」窗口攻击。ℰ_MNEMO = ℰ_BELIEF × ℰ_memo。

**定义 347（证书 J_MNEMO）** J_MNEMO = (J_BELIEF, retrieval_cov, avs_p50, cws_rate, provenance_mix, revocation_latency_p99, memory_hash, drift_stat, mnem_ver)。Valid ⇔ Valid(J_BELIEF) ∧ 覆盖率 ≥ 1−α−ε ∧ MSG 满足 ∧ 撤销延迟 ≤ τ_rev。

**定义 348（退化边界）** S_ret = ∅ / MSG 任一门失败 / RVoI ≤ c_mem / 记忆过期或被撤销 ⇒ MNEMO 逐指令等于 BELIEF-RAS。因此 BELIEF ⊂ MNEMO，安全侧永不更弱。

**定义 349（混合主动仲裁）** 权限偏序：C-RAS-WM 安全认证 > 人类否决 > 机器建议。人类可提升保守度（追加约束）、可否决动作、可纠正记忆，但不能降低认证要求；机器对人类确认的动作仍保留**安全拒绝权**。

**定义 350（隐私、同意与遗忘）** 记录携带主体同意范围 consent 与保留期 retention；撤销/到期删除原始字段，但保留不可逆指纹用于审计（可验证删除）。检索必须尊重 consent；跨主体共享需去标识化。

```python
# IP-275 EMS：append-only 哈希链（控制环只读，写为 WAL）
class EpisodicMemoryStore:
    def append(self, e):
        e.id, e.h_prev = hash_event(e), self.head
        self.head = e.id
        self.wal.write(e)                      # 只追加，绝不原地改
    def freeze_and_build(self):                # 离线；不在控制环内
        live = [e for e in self.wal if not self.is_revoked(e)]
        return MemorySnapshot(build_ann(live), revoked=self.revoked,
                              version=self.version)   # 原子换装

# IP-276 CRR：认证检索（有效期/撤销/信任过滤 + 共形半径）
def certified_retrieve(snap, phi_o, alpha):
    cands = snap.ann.search(phi_o, k=K_RET)
    cands = [e for e in cands
             if e.in_validity() and not snap.is_revoked(e)
             and trust_lcb(e.prov) >= TAU_TRUST]
    r = snap.conformal_radius(alpha)           # split-conformal，覆盖 >= 1-alpha
    return [e for e in cands if dist(e.phi, phi_o) <= r]

# IP-277 AVS：类比有效性（因果 × 动作不变性 × 模型一致 × 来源）
def analogy_validity(e, o_t, b_t):
    causal = causal_tag_match(e.tags, query_causal_graph(o_t))
    invar  = action_invariance_test(e, o_t)    # 同动作 -> 同结果？
    kappa  = 1.0 - outcome_distance(e.y, predict_outcome(b_t, e.a)) / SCALE
    return causal * invar * max(0.0, kappa) * trust_lcb(e.prov)

# IP-278 MBP：记忆条件先验 + CWS 第四通道
def memory_prior(b_t, S_ret):
    valid = [e for e in S_ret if e.avs >= TAU_ANA]
    if not valid:
        return b_t, 0.0, False                 # 严格退化到 BELIEF
    b_mem = bayes_power_prior(b_t, valid, w=[e.avs for e in valid])
    r_mem = wasserstein(predictive(b_t), empirical(valid))
    cws   = (entropy(b_t) < TAU_CONF) and (r_mem > TAU_MEM)
    return b_mem, r_mem, cws

# IP-279 RVoI：检索本身也是动作（无利可图则不检索）
def choose_retrieval(b_t, snap, budget):
    best = None
    for q in retrieval_queries(b_t):           # 不同 k / 半径 / 模态子集
        if not budget.allow_mem(q):            continue
        if predicted_coverage(snap, q) < 1 - ALPHA: continue
        voi   = entropy(b_t) - expected_entropy_after(b_t, q, snap)
        score = voi - cost_mem(q) - risk_spurious(q, snap)
        if best is None or score > best[1]: best = (q, score)
    return best[0] if best and best[1] > 0 else None

# IP-280 STR：来源信任（Beta-LCB + 折减）
def update_trust(registry, source, verified):
    registry[source].a += 1 if verified else 0
    registry[source].b += 0 if verified else 1
    return registry[source].lcb(tau=0.05) * decay(source)

# IP-281 CMP：协作记忆协议（人类只能收紧/否决/纠正，不能扩张）
def collaborative_step(precedent_cert, human_op, op_arg):
    if human_op == 'veto':     return Veto(precedent_cert.action)
    if human_op == 'correct':  return Supersede(precedent_cert.ids, op_arg)  # 新记录
    if human_op == 'revoke':   return Revoke(op_arg)
    return Confirm(precedent_cert)             # 确认不改变安全包络

# IP-282 MSG：记忆安全门（五项全过才允许进入控制）
def memory_safety_gate(S_ret, b_mem, cws, verification_ok):
    return (len(S_ret) > 0
            and any(e.avs >= TAU_ANA for e in S_ret)
            and independent_sources(S_ret) >= 2
            and not revoked_or_poisoned(S_ret)
            and (not cws or verification_ok))   # CWS 下禁止松弛

    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if slow or cws:
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, U_cal))
    mode = select_mode_from_belief(project(b_mem), b_mem, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 审计 + 先例证书 + 记忆写入（WAL，不学习）
    M.vqa_iii.submit_async(b_t, b_mem, S_ret, r_mem, cws, g, y)
    M.ems.append(make_record(o, mode.a, observed_outcome(), M.cof.trace(),
                             M.log_int, prov='self', tags=M.tags))
    M.b_prev = b_mem
    return k, lam, mode, (U_ale, U_epi, r_mem, cws)
```

## 3. 推导

**引理 23（记忆的信息上限）** 设上下文编码 φ 与结果 Y 的互信息为 I(φ;Y)。任何仅依赖 (φ, S_ret) 的估计器对 H[Y|φ] 的降低量不超过 I(φ;Y)（数据处理不等式）。系：当 φ 只含**表面特征**而因果变量不在 φ 中时 I(φ;Y) ≈ 0，记忆再多也是安慰剂——这正是 AVS 必须显式引入因果标签与动作不变性检验的信息论理由。

**引理 24（共形覆盖与漂移折减）** 在 A102（校准集与当前 episode 在漂移窗口内可交换）下，split-conformal 检索结果集以概率 ≥ 1−α 覆盖真实结果。若两分布的总变差距离 ≤ δ_drift，则覆盖率 ≥ 1−α−δ_drift。系：老化/漂移必须显式进入覆盖率预算，否则「共形保证」在长时程上静默失效。

**引理 25（记忆投毒的影响半径）** 设单条毒记录被检索到的概率为 p_r，每步使用记忆的概率为 p_u，撤销延迟为 L_rev 步，则撤销前其期望影响决策数 ≤ p_r·p_u·L_rev。若 MSG 要求 ≥2 个独立来源一致且各来源污染相关 ρ<1，则单源毒记录单独通过 MSG 的概率 ≤ ρ^{k−1}。系：记忆投毒的危害不是「一次错误」，而是「撤销前被反复复用」，故撤销延迟必须成为一等安全指标（J_MNEMO 的 revocation_latency_p99）。

**引理 26（记忆松弛的安全补偿）** 若记忆只有在 verification（独立证据或模型一致）通过时才给予松弛 Δλ，则额外风险 ≤ ε_verify + Lip·Δλ_max；当 verification 失败时 Δλ = 0。故记忆对安全侧的贡献**非正**——它最多把「凭空自信」换成「有据自信」，从不凭空增加安全裕度。

**定理 20（MNEMO 严格包含 BELIEF）** 在 A99–A103 下，MNEMO 的期望风险 ≤ BELIEF-RAS；当 S_ret = ∅、MSG 失败、RVoI ≤ c_mem、记忆过期或撤销时，两者**逐指令相同**（定义 340、348）。因此 BELIEF 是 MNEMO 在「无可用记忆」边界上的退化：安全侧不做任何让步，效率侧获得先例带来的 resolution bonus 与更快的后验收敛。

**定理 21（协作纠错的单调安全性）** 在 A104（人类纠错只能撤销/降低记忆松弛，或提供可验证的语义修正；验证协议诚实）下，CMP 的任何 Correct/Veto/Revoke 操作都不会提高认证风险；且若来源可靠性平稳，Beta-LCB 信任依概率收敛到真实可靠性 θ_h。系：**人机协作在安全上是「只减不增」的**——这使「让人类参与」从风险源变成可控的降低风险手段，也把 R69「人类会撒谎」的单点假设升级为带履历与可撤销性的来源模型。

**定理 22（CWS 第四通道的判别力）** 若模型失配导致的信念偏移与真实状态偏移方向不一致（模型自信但先例反对），则 r_mem 的期望 ≥ 先例覆盖半径之外的质量，而 r_res、Δa 可同时很小；因此 **(H[b_t]↓, r_mem↑)** 能在 R70 三元组失效的区域检出「自信地错」。A105：先例结果分布对状态 Lipschitz，保证移情方向可辨。

## 6. 本轮最大风险

**一句话**：MNEMO-RAS 把安全性押在「检索到的先例与当前情境**因果相关**且**未被投毒**」上；但检索的相似性是表面的，而危害是深层的——**系统可能拿着一份看起来一模一样、实则因果不同（或被人类/攻击者悄悄种下）的旧经验，自信地跳过本该做的求解、求问与验证**，于是记忆把 R70 的「自信地错」升级为「有据地错」，而「有据」比「自信」更难被人类质疑。

**次级风险与缓解**：
1. **表面相似 / 因果错配** → AVS 因果标签 + 动作不变性检验 + 引理 23 信息上限；AVS 不达标只做解释；
2. **记忆投毒长期复用** → 来源格 + Beta-LCB + k 独立来源 + 引理 25 影响半径 + 撤销索引；
3. **共形覆盖在漂移下静默失效** → 引理 24 的 δ_drift 折减 + AGE 漂移检测 + 历史层只读；
4. **记忆膨胀与实时预算** → 离线构建 + 冻结快照原子换装 + RVoI 门控 + fail-safe 不检索分支；
5. **协作越权 / 隐私** → 定义 349 权限偏序 + 机器安全拒绝权 + 定义 350 同意/可验证删除。

**定义 350（隐私、同意与遗忘）** consent + retention 随记录携带；撤销/到期删除原字段、保留不可逆指纹以支持可验证删除。

```python
# ---------- IP-275 EMS：append-only + 哈希链 ----------
class EpisodicMemoryStore:
    def append(self, rec):                      # 控制环内只写 WAL，不重建索引
        rec.id = blake3(canonical(rec)); rec.h_prev = self.head
        self.head = rec.id; self.wal.append(rec)

    def build_snapshot_offline(self):           # 离线任务
        live = [e for e in self.wal if not self.revoked.is_revoked(e.id)]
        snap = MemorySnapshot(
            ann=HNSW(live), inverted=MetaIndex(live),
            revoked=self.revoked.snapshot(), valid=self.valid.snapshot(),
            conformal=self.calibrate_radius(live), version=self.version)
        self.next_snapshot = snap               # 原子换装，控制环零阻塞

# ---------- IP-276/277 CRR + AVS ----------
def certified_retrieve(snap, phi_o, alpha):
    cands = snap.ann.search(phi_o, k=K_RET)
    cands = [e for e in cands
             if snap.valid.contains(e, now())
             and not snap.revoked.contains(e.id)
             and STR.lcb(e.prov) >= TAU_TRUST]
    r = snap.conformal.radius(alpha)
    return [e for e in cands if dist(e.phi, phi_o) <= r]

def avs_score(e, o_t, b_t):
    causal = causal_tag_match(e.tags, query_causal_graph(o_t))       # 0/1
    invar  = action_invariance_test(e, o_t)                          # 0/1
    kappa  = max(0.0, 1.0 - outcome_distance(e.y, predict_outcome(b_t, e.a))/SCALE)
    return causal * invar * kappa * STR.lcb(e.prov)

# ---------- IP-278 MBP：记忆先验 + CWS ----------
def memory_prior(b_t, S_ret):
    valid = [e for e in S_ret if e.avs >= TAU_ANA]
    if not valid:
        return b_t, 0.0, False
    b_mem = bayes_power_prior(b_t, [(e.y, e.a, e.avs) for e in valid])
    r_mem = wasserstein2(predictive(b_t), empirical_outcomes(valid))
    cws   = (entropy(b_t) < TAU_CONF) and (r_mem > TAU_MEM)
    return b_mem, r_mem, cws

# ---------- IP-279 RVoI ----------
def choose_retrieval(b_t, snap, budget, alpha):
    best = None
    for q in retrieval_queries(b_t):
        if not budget.allow_mem(q): continue
        if snap.predicted_coverage(q) < 1 - alpha: continue
        score = (entropy(b_t) - expected_entropy_after(b_t, q, snap)
                 - cost_mem(q) - risk_spurious(q, snap))
        if best is None or score > best[1]: best = (q, score)
    return best[0] if best and best[1] > 0 else None

# ---------- IP-281 CMP：协作（人类只能收紧/否决/纠正） ----------
def collaborative_step(cert, op, arg=None):
    assert op in {'confirm', 'correct', 'veto', 'revoke'}
    if op == 'veto':    return Veto(cert.action_id)                 # 提升保守度
    if op == 'correct': return Supersede(cert.ids, arg)             # 新记录 + 旧记录失效
    if op == 'revoke':  return Revoke(arg)                          # 触发撤销索引
    return Confirm(cert)                                            # 不改变安全包络

# ---------- IP-282 MSG：记忆安全门 ----------
def memory_safety_gate(S_ret, b_mem, cws, verification_ok, lam_delta):
    return (len(S_ret) > 0
            and any(e.avs >= TAU_ANA for e in S_ret)
            and independent_sources(S_ret) >= 2
            and not revoked_or_poisoned(S_ret)
            and (not cws or verification_ok)
            and lam_delta <= DELTA_LAMBDA_MAX)

# ---------- IP-285 MNEMO-RAS 主闭环 ----------
def MNEMO_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    b_t = M.bse.step(M.b_prev, o, M.last_action, M.last_g, M.last_y)
    # 1) 检索即动作
    q = M.rvoi.choose_retrieval(b_t, M.ems.snapshot, M.budget, M.alpha)
    S_ret = M.crr.certified_retrieve(M.ems.snapshot, phi(o), M.alpha) if q else []
    for e in S_ret: e.avs = M.avs.score(e, o, b_t)
    # 2) 记忆先验 + 第四通道
    b_mem, r_mem, cws = M.mbp.memory_prior(b_t, S_ret)
    # 3) FMA 第二意见（边缘化到记忆后验）
    a_hat = M.fma.flow_anomaly_belief(M.fmp, M.last_action, o, o_cal, b_mem)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    # 4) 记忆门控
    msg_ok = M.msg.check(S_ret, b_mem, cws, verification_ok=not slow,
                         lam_delta=proposed_relaxation(b_t, b_mem))
    # 5) 交互（继承 R70；门控失败不做记忆驱动交互）
    g = (M.mint.choose_interaction_belief(b_mem, M.fmp, M.budget, M.c_ras_wm)
         if (entropy(b_mem) > TAU_EPI and msg_ok and not slow) else None)
    if g is not None:
        y = M.cia.execute(g)
        b_mem = M.bse.step(b_mem, o, M.last_action, g, y)
    # 6) 风险缩放：只有 MSG + 非 CWS 才有 resolution bonus
    alpha = 0.0 if (msg_ok and not cws) else 1.0
    lam = max(M.efs.risk_scale(...),
              lam_floor(M.aud.aleatoric(b_t) + alpha * entropy(b_mem)))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if slow or cws:
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, U_cal))
    mode = select_mode_from_belief(project_modes(b_mem), b_mem, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 7) 审计 + 证书 + 只追加记忆
    cert = PrecedentCert(S_ret, [e.avs for e in S_ret], r_mem,
                         provenance(S_ret), M.ems.snapshot.hash)
    M.vqa_iii.submit_async(b_t, b_mem, r_mem, cws, g, y, cert)
    M.ems.append(make_record(o, mode.a, observed_outcome(), M.cof.trace(),
                             M.log_int, prov='self', tags=M.tags))
    M.b_prev = b_mem
    return k, lam, mode, (M.aud.aleatoric(b_t), entropy(b_mem), r_mem, cws)
```

## 4. 推导

**引理 23（记忆信息上限）** 对任意仅依赖 (φ, S_ret) 的估计器，H[Y|φ] 的降低量 ≤ I(φ;Y)（数据处理不等式）。系：表面特征不携带因果信息时，先例再多也无用；AVS 是必要而非装饰。

**引理 24（共形覆盖与漂移折减）** A102 下 split-conformal 覆盖率 ≥ 1−α；两分布 TV 距离 ≤ δ_drift 时覆盖率 ≥ 1−α−δ_drift。系：漂移必须进入覆盖率预算，否则长时程保证静默失效。

**引理 25（投毒影响半径）** 单毒记录撤销前期望影响决策数 ≤ p_r·p_u·L_rev；MSG 要求 k 独立来源且相关 ρ<1 时，单源通过概率 ≤ ρ^{k−1}。系：撤销延迟是一等安全指标。

**引理 26（记忆松弛的安全补偿）** 仅在 verification 通过时允许松弛 Δλ ⇒ 额外风险 ≤ ε_verify + Lip·Δλ_max；失败时 Δλ=0。故记忆对安全侧贡献非正。

**定理 20（MNEMO 严格包含 BELIEF）** A99–A103 下，E[Risk(MNEMO)] ≤ E[Risk(BELIEF)]；且 S_ret=∅、MSG 失败、RVoI≤c_mem、过期/撤销时逐指令相同。安全侧不让步，效率侧得先例 resolution bonus。

**定理 21（协作纠错的单调安全性）** A104 下，Correct/Veto/Revoke 不提高认证风险；平稳来源下 Beta-LCB 信任依概率收敛到 θ_h。系：人机协作「只减不增」，人类从风险源变为可控降险手段。

**定理 22（CWS 第四通道判别力）** 当模型失配方向与真实状态偏移不一致时，r_mem 期望 ≥ 覆盖半径外质量，而 r_res、Δa 可同时很小；故 (H[b_t]↓, r_mem↑) 可在 R70 三元组失效区检出「自信地错」（A105 Lipschitz 保证方向可辨）。

**定理 23（记忆治理的审计完备性）** 若每个记忆驱动的决策都携带 PrecedentCert 且 J_MNEMO 校验通过，则任一决策可被独立复算到具体记录、来源、快照版本与 AVS；结合撤销索引，审计可判定「该决策是否使用了当时已失效/被撤销的记录」。系：把「记忆不可解释」转化为可追责的工程属性。

## 7. 本轮最大风险

**一句话**：MNEMO-RAS 把安全性押在「检索到的先例与当前情境**因果相关**且**未被投毒**」上；但检索的相似性是表面的，而危害是深层的——**系统可能拿着一份看起来一模一样、实则因果不同（或被人类/攻击者悄悄种下）的旧经验，自信地跳过本该做的求解、求问与验证**，于是记忆把 R70 的「自信地错」升级为「有据地错」，而「有据」比「自信」更难被人类质疑。
