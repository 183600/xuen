# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「视觉问答」×「预测性维护」）

> R69 教会系统「不确定就问」：把 U 拆成 aleatoric / epistemic，用流匹配多模态策略显式表示歧义，用主动多模态交互（看/问/触）去消解，并把「单次交互不得定案」写进证据纪律。但 R69 的交互是**一次性、语义无差别的**：它假设「问一句 → 得到一个关于世界状态的观测」，却从未追问三件事——
> **(a) 这个回答真的来自图像吗**（VQA 的语言先验会让模型不看图也答得很流利）；
> **(b) 「没发现异常」到底意味着什么**（漏检敏感度未知时，阴性发现是证据还是安慰剂）；
> **(c) 这次探询的收益该用什么度量**（降低模态熵 ≠ 降低维护成本，很多「更确定」根本不影响该不该停机检修）。
>
> 本轮两个灵感正好从两端夹住这三问：
> - **视觉问答**把「看」变成一个可计算、可审计、也会幻觉的**语言中介观测通道**；
> - **预测性维护**把决策目标从「识别当前状态」拉长到「在隐退化过程上估计剩余寿命并安排检修」，于是信息的价值必须落在 **RUL 的决策边界**上，而不是答案的置信度上。
>
> 核心命题：**预测性维护的瓶颈不是「看不见故障」，而是「把『看起来正常』误当成『确实健康』」。本轮把探询升级为对隐退化状态的一次带噪、带物理成本、带语言中介的测量：用视觉接地证书过滤语言先验，用漏检敏感度下界处理阴性发现，用删失/重置感知的 RUL 生存后验承载时间维度，最后用「决策价值探询 DVI」——只在后验质量跨越检修决策边界时才去看、去问。** 命名 **PIVOT-RAS**（Prognostic Inspection with Visual-grounded Observations and Timing）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我看到的『正常』，到底是健康，还是只是我没看见故障**」——从「主动求证」到「为决策而探询」，敌人不是误报，而是虚假的安心。

## 0. 直觉与动机

**灵感 1（视觉问答 → 「看」是一次语言中介的带噪测量，不是一次分类）**
直觉：R69 把注视 `g_gaze` 当成信息动作，但没有规定「看到什么」如何变成对世界状态的证据。真实维护场景里，人不是给图像打标签，而是**带着问题看**：「这条焊缝有裂纹吗？」「油窗液位在 MIN 以上吗？」「轴承座有没有渗油？」——同一个像素区域，问法不同，证据的判别力与可靠性完全不同。VQA 给出的不是一个标签，而是一个**条件于问题与区域的观测似然** `p(A | h, q, R)`：它在退化超过可见阈值时以敏感度 `p_d` 报阳，在健康时以误报率 `p_f` 报阳。于是「看」被还原成测量论里的一个信道，R69 的「交互」才第一次有了可计算的观测模型。

**灵感 2（预测性维护 → 信息只在决策边界附近值钱）**
直觉：预测性维护的目标不是把剩余寿命 RUL 估得越准越好，而是**在对的时间检修**。若后验已经告诉你「至少还能跑 6 个月」而检修窗口是 1 个月后，那么再精确 0.1 个月毫无价值；若后验恰好跨在「现在检修 vs 再跑一班」的边界上，一点点信息就能翻转决策、避免一次非计划停机。R69 的 VoI 是 **模态熵的下降**，它奖励「更确定」；但一个让系统对无关紧要的问题更确定的探询，DVI 为零甚至为负（花了探询成本）。因此本轮把 VoI 从「信念空间」搬到「决策损失空间」：**探询的价值 = 它使期望维护代价下降多少**。这把「为了知道而知道」改成「为了决定而知道」。

**灵感 3（阴性发现陷阱 → 「没发现」不是「不存在」）**
直觉：R69 的证据纪律要求「多源一致」，但预测性维护里最常见、最危险的证据恰恰是**阴性**——「这次巡检没看到裂纹」「VQA 回答 normal」。当检测敏感度 `p_d < 1` 时，「没看到」与「没有」是两件事；若系统默认 `p_d = 1`，一次漏检就会被读成一次健康证明，RUL 被系统性高估，检修被一再推迟，直到失效。更隐蔽的是：越是难看的部位（遮挡、油污、逆光），`p_d` 越低，而系统越是把它当成「干净」。所以本轮把阴性发现的处理写成一条铁律：**敏感度未知就当作零敏感度**——此时阴性观测对后验的似然为常数、不含信息；只有在受控试验中认证了下界 `p_d^L`，阴性发现才被允许更新信念，且只用下界，绝不用点估计。

**灵感 4（语言先验 → 流利不等于接地，需要视觉接地证书）**
直觉：VQA 的经典失败不是「答错」，而是「不看图也答对」——模型从问题频率、常见搭配、数据集偏置里学到了答案。这类回答在文本上无懈可击，在语义上却是**对图像无证据**的。R69 的交互投毒上界处理的是「人撒谎」，本轮要处理「模型自欺」：一个回答只有在满足**区域敏感**（遮住被指区域，答案概率显著下降）、**改述不变**（换个问法，答案不变）、**盲测有差**（把图像换成先验/空白，答案概率显著下降）三条时，才被认证为「接地证据」；否则视为无信息，绝不当作阴性的「正常」。这把「说得好」与「看得见」分开。

**灵感 5（时间维度 → 删失、重置与不完美维修）**
直觉：RUL 不是一个分类标签，而是一个**生存分布**，且维护数据天生带删失（到观测结束还没坏的单位，不能当没坏处理），检修还会**重置**退化时钟（甚至是不完美维修，只恢复到某个随机健康水平）。忽略删失会把寿命估长，忽略重置会把同一台设备的检修前后当成一条连续轨迹。因此 RUL 必须以「条件于维修历史的生存后验」出现；探询的观测模型、检修决策、证书都必须区分「同一寿命周期内」与「跨周期」。

**灵感 6（双刃剑 → 预测性维护版的投毒与漂移）**
直觉：一旦「看」能触发或取消检修，就有新的攻击面：**假健康图像**（贴一张正常的照片、在裂纹上贴标）、**选择性漏检**（只在系统会检查的角度遮挡）、**语义漂移**（换了供应商/油漆/相机/光照，外观→健康的映射悄悄变了）、以及**探询磨损**（内窥、拆检本身造成退化）。更糟的是「**探询洗白**」：反复做低成本、低敏感度的巡检，让日志看起来「一直在监控」，实际什么都没排除。所以本轮必须交付：接地证书（防语言先验与幻觉）、漏检敏感度下界（防阴性乐观）、语义漂移重标定（防映射过期）、探询物理成本与安全认证（防检查本身致损）、以及「阴性不得单独定案」的证据账本。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PIVOT-RAS 总览）** PIVOT-RAS = (HDP, RSP, VGC, NFS, DVI, SIP, REN, SDR, IPC, CSG, RAS-WM†)。三不变式：
(i) **快环零学习写操作**：控制率快环完全继承 R69 FLUID（定义 276-i 的实时约束不变）；
(ii) **探询预算与物理安全**：单位维护周期内探询次数 ≤ N_insp、拆检位移/力 ≤ ε_g、停机成本 ≤ c_max，且每次探询动作必须通过与任务动作相同的 C-RAS-WM 认证（定义 320）；
(iii) **证据纪律（阴性版）**：单次阴性/阳性发现不得单独定案，阴性发现只有在敏感度下界已认证时才参与更新，且必须与至少一个正交证据源（遥测退化趋势 / 历史失效 / 另一模态）相容，否则记为「未观测」而非「健康」。

**定义 311（隐退化过程 HDP）** 健康状态 `h_t ∈ ℝ^{d_h}` 依退化随机过程演化：
`d h_t = μ(h_t; θ) dt + σ(h_t) dW_t + dJ_t`，其中 `J_t` 为冲击/跳变过程，`θ ~ p(θ)` 为个体参数（退化速率、初始损伤、批次效应），失效阈值为 `H_fail`（多维时为边界 `∂F`）。RUL 定义为首次命中时刻 `τ = inf{t ≥ 0 : h_{t} ≥ H_fail}`。计量单位统一为「剩余可用时间」，便于与维护窗口对齐。

**定义 312（观测模型）** 存在两类观测：
- **遥测** `y_t = C h_t + ε_t`（廉价、高频，但可能被 R68/R69 的标定层偏置）；
- **探询** 在时刻 `t_m` 选区域 `R` 与问题 `q`，得到 VQA 回答 `A ∈ 𝒜_ans`。其观测似然为信道 `p(A | h_{t_m}, q, R) = Cat(π_A(h_{t_m}; q, R))`；二元症状情形下退化为敏感度 `p_d(h; q, R) = P(A=1 | 退化可见, q, R)` 与误报率 `p_f(q, R) = P(A=1 | 健康, q, R)`。「可见」由可见性阈值 `h_vis` 定义（`h < h_vis` 时症状不可见，`p_d = p_f`，探询无判别力）。

**定义 313（视觉接地证书 VGC）** 对回答 `A`、问题 `q`、图像 `I`、被引区域 `R`，定义三元证书：
- `S_reg = KL(p_VQA(·|I,q) ‖ p_VQA(·|I\R,q))`（区域敏感度，遮住 `R` 后的分布位移）；
- `S_par = max_{q' ∈ Paraphrase(q)} TV(p_VQA(·|I,q), p_VQA(·|I,q'))`（改述不稳定度）；
- `G_blind = log p_VQA(A|I,q) − log p_VQA(A|I_∅,q)`（盲测差，`I_∅` 为空白/均值/先验图像）。
`VGC(A;q,R) = 1` 当且仅当 `S_reg ≥ τ_reg ∧ S_par ≤ τ_par ∧ G_blind ≥ τ_blind`。未通过者映射为「无证据」观测 `A = ⊥`，其似然对所有 `h` 取常数（不更新后验，尤其不得被当作阴性/健康）。

**定义 314（接地门控观测）** 只有 `VGC = 1` 的回答进入贝叶斯更新：`b'(h) ∝ b(h) · p(A | h, q, R)`。被拒绝的回答进入证据账本（定义 326），用于估计长期语言先验污染率 `δ_prior`。R69 的「k 个正交证据源一致」在本轮成为「VGC 三项测试全过」的特例。

**定义 315（阴性发现敏感度 NFS）** 设退化可见时真实检测敏感度 `p_d(h)` 未知。定义认证下界 `p_d^L(h) ≤ p_d(h)`（由受控化验/带标注巡检得到，含置信修正）。阴性观测 `A=0` 的保守似然取
`p̄(A=0 | h) = 1 − p_d^L(h)`（退化）；`1 − p_f^U`（健康，`p_f^U` 为误报上界）。
**铁律**：若 `p_d^L` 未认证，则令 `p_d^L ≡ 0`，此时阴性与阳性对后验均无判别力，系统退化为「不看图像、只用遥测」的保守预测性维护。**阴性永不比遥测更乐观。**

**定义 316（RUL 生存后验 RSP）** 后验 `p(τ | ℋ_t)` 由粒子滤波/生存模型在退化过程上传播，`ℋ_t` 为截至 `t` 的遥测、接地探询与维修历史。对删失单位使用生存似然
`L = ∏_i f(τ_i)^{δ_i} S(τ_i)^{1−δ_i}`，`δ_i = 1{观测到失效}`，`S(t) = P(τ > t)`。
报告三件套：中位 RUL、预测区间（如 10/90 分位）、以及**检修决策分位** `τ_q`（由维护成本比确定，见定义 318）。

**定义 317（重置与不完美维修 REN）** 维修动作 `m` 把健康状态重置为 `h → h_0 + Δ_m`，`Δ_m ~ p_reset(· | m)`（完美维修为 `h_0`，不完美维修为随机残余损伤）。RUL 后验必须条件于维修历史 `ℋ_t^{maint}`，跨周期不得复用同一退化轨迹；每次维修开启新的「寿命周期」`c`，记 `τ^{(c)}`。忽略重置等价于把已修好的损伤重复计数（或反之），故列为证书必检项。

**定义 318（决策价值探询 DVI）** 设维护策略类 `π` 的期望代价泛函为 `J(b) = min_π E[Σ 探询成本 + 检修成本 + 失效成本 + 停机成本]`，其中检修阈值由成本比 `c_fail / (c_fail + c_maint)` 决定的决策分位 `τ*` 给出（「当 `P(τ ≤ τ* | b) ≥ η` 时立即检修」）。对候选探询 `g=(R,q)`，其决策价值为
`DVI(g) = J(b) − E_{A ~ p(·|b,g)}[J(b_A)] − c_insp(g)`。
仅当 `DVI(g) > 0` 才探询；`argmax_g DVI(g)` 为选定探询。**关键性质**：`DVI` 只由后验质量在决策边界 `τ*` 附近的移动决定——后验已远离边界时，探询再「降熵」也近乎无价值（引理 19）。

**定义 319（选择性探询规划 SIP）** 增广信息动作 `g = (R, q, t_insp)`：看哪里（区域/视角）、问什么（症状问题）、何时看（下一检修窗口或事件触发）。规划在慢环（定义 323）上求解 `g* = argmax_g DVI(g)`，约束：预算（定义 310-ii）、`IPC` 认证（定义 320）、`VGC` 预期通过率不低于 `ρ_min`（否则问了也白问）、以及「每次探询至少一个正交源可交叉验证」。若 `max_g DVI(g) ≤ 0` 或候选全部被门控，则不探询，走保守基线（定义 324）。

**定义 320（探询物理成本与安全 IPC）** 探询是真实动作：内窥/拆检/擦拭会带来磨损、泄压、热暴露、停机与人身风险。`IPC` 要求：探询位移/力在包络内、不触发危险状态、总停机时间预算不超、且不得使系统错过安全关键窗口。任一不过 ⇒ `g` 作废，`DVI` 置为 `−∞`（不是「高价值但危险」）。

**定义 321（语义漂移重标定 SDR）** 外观→健康的映射 `π_A(h; q, R)` 会因光照、相机、油漆、供应商、批次而漂移。用检修拆解得到的**真实健康标签**（稀疏、昂贵）定期重标定 `π_A`，并监控语义校准误差 `E_sem = E[ |P̂(A=1|h) − P(A=1|h)| ]`。`E_sem > τ_sem` ⇒ 暂停该 `(q,R)` 通道的 VQA 证据，仅用已认证通道或遥测（对应 R69 MCG 的「语义版」）。

**定义 322（删失生存校准门 CSG）** RUL 后验必须通过删失感知校准：PIT 直方图接近均匀、`α` 预测区间覆盖率 ≥ `α − ε_cov`、删失 CRPS 不超过基线。任一越界 ⇒ 后验区间膨胀到保守分位（`τ_q → τ_{q^−}`，更早检修），并禁止基于该后验的「延寿」决策。绝不使用未校准的乐观 RUL。

**定义 323（双环时序）** **快环**：R69 FLUID 以控制率运行（P99 < 2.6ms），负责即时动作安全与多模态消歧。**慢环**：PIVOT 以班次/事件触发的探询节拍运行（P99 < 100ms），负责遥测窗口更新、RSP 传播、DVI 规划、VGC 校验与检修调度。两环通过 `(z_t, b, τ_q)` 单向下传：快环可随时安全停车，慢环不得在快环内做学习式写操作。

**定义 324（保守退化与严格包含）** 若 `VGC` 全拒、`NFS` 无认证下界、`CSG` 越界、或 `max DVI ≤ 0`，PIVOT 不做任何探询，退化为**仅遥测的保守条件维护**（固定 + 状态混合基线，取保守 RUL 分位与更早检修），其安全侧不弱于「固定周期检修」；同时底层动作仍由 R69 FLUID 提供安全包络。故 PIVOT 是「R69 + 决策相关探询」的严格泛化：`DVI ≤ 0` 时逐决策退化为 R69 的「不交互」边界，且不增加失效风险。

**定义 325（证书 J_PIVOT）** `J_PIVOT = (J_FLUID, ece_mode, E_sem, p_d^L, cov_RUL, censored_CRPS, dvi_ratio, vgc_pass, n_insp_budget, ledger_hash, pivot_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ E_sem ≤ τ_sem ∧ cov_RUL ≥ α − ε_cov ∧ p_d^L 已认证（或用 ⊥ 通道）∧ 预算未越界 ∧ 探询均通过 IPC`。

**定义 326（威胁模型 AIC-PIVOT 与证据账本）** `ℰ_PIVOT = ℰ_FLUID × ℰ_visual × ℰ_neglect × ℰ_semantic`：假健康图像/遮挡/贴片（visual）、选择性漏检与阴性洗白（neglect）、外观→健康映射漂移与供应商换料（semantic）。证据账本 `Ledger` 单调记录每次探询的 `(g, VGC, A, 是否阴性, 是否改变决策, 维修结果)`，支持事后归因「这次延寿是被哪一次阴性发现误导的」。

```python
    def update_telemetry(self, y_window):              # 快/慢环共用，廉价
        for _ in range(steps):
            self.h = propagate(self.h, self.theta, dt, jump=True)
            self.h, w = weight_telemetry(self.h, y_window)
        return self.resample()

    def update_inspection(self, A, q, R, vgc, pd_lower):
        if vgc != 1 or A == REJECT:                    # 语言先验/无接地 -> 无证据
            return self.record_no_evidence(A, q, R)
        if A == NEG and pd_lower <= 0:                 # 阴性但敏感度未认证 -> 不更新
            return self.record_unobserved(A, q, R)     # 关键：绝不当作健康
        lh = symptom_likelihood(A, q, R, self.h, pd_lower)   # 用下界，不用点估计
        self.h, w = self.h, self.w * lh               # 贝叶斯更新
        return self.resample()

    def rul_samples(self):
        # 蒙特卡洛：每个粒子推进到 H_fail，处理删失与重置历史
        return first_passage_times(self.h, self.theta, H_fail, reset_history=self.reset)

    def quantile(self, q):                             # 决策分位（定义 318）
        return empirical_quantile(self.rul_samples(), q)


# IP-266 VGC：视觉接地证书（防语言先验/幻觉）
def visual_grounding_certificate(vqa, I, A, q, R, tau_reg, tau_par, tau_blind):
    s_reg   = kl_div(vqa(I, q), vqa(mask_region(I, R), q))
    s_par   = max(tv_div(vqa(I, q), vqa(I, qp)) for qp in paraphrase(q))
    g_blind = logprob(vqa, A, I, q) - logprob(vqa, A, blank_image(I), q)
    ok = (s_reg >= tau_reg) and (s_par <= tau_par) and (g_blind >= tau_blind)
    return ok, dict(s_reg=s_reg, s_par=s_par, g_blind=g_blind)


# IP-268 DVI：决策价值探询（只在跨决策边界时值钱）
def decision_value_of_inspection(b, g, J, policy):
    if not ipc.certify(g):                             # 信息动作也是物理动作
        return -inf
    if expected_vgc_pass(g) < RHO_MIN:                 # 问了也白问
        return -inf
    j0 = J(b, policy)
    outcomes = predictive_outcomes(b, g)               # 阳性/阴性/无证据
    j1 = sum(p * J(posterior_update(b, A, g), policy) for A, p in outcomes)
    return j0 - j1 - inspection_cost(g)


# IP-269 SIP：选择性探询规划（看哪里/问什么/何时看）
def plan_inspection(b, budget, J, policy):
    best = None
    for g in candidate_inspections(b):                 # R 来自后验高信息区, q 来自症状库
        if not budget.allow(g): continue
        val = decision_value_of_inspection(b, g, J, policy)
        if best is None or val > best.val: best = (g, val)
    return best if best and best.val > 0 else None     # 无利可图 -> 保守基线


# IP-272/273/276 慢环主闭环（快环仍走 R69 FLUID）
def PIVOT_slow_loop(M, telemetry_window, maybe_image):
    # 1) 场景理解与退化后验（删失/重置感知）
    M.rsp.update_telemetry(telemetry_window)
    if maybe_image is not None and not M.sdr.stale():
        for (q, R) in M.symptom_bank:
            A = M.vqa.ask(maybe_image, q, R)
            ok, vgc = visual_grounding_certificate(M.vqa, maybe_image, A, q, R, ...)
            M.rsp.update_inspection(A, q, R, ok, M.nfs.lower_bound(q, R))
            M.ledger.append(q, R, A, ok)
    # 2) 校准门：语义漂移 / 删失生存，任一越界只收紧
    if M.sdr.error() > TAU_SEM or not M.csg.calibrated(M.rsp):
        return conservative_baseline(M.rsp, reason='gate')   # 定义 324，严格含 R69
    # 3) 规划探询：决策价值，而非降熵
    g = plan_inspection(posterior=M.rsp, budget=M.budget, J=M.cost, policy=M.maint)
    if g is None:
        return schedule_maintenance(M.rsp, conservative=True) # 不探询 -> 保守基线
    # 4) 执行探询（物理认证 + 接地门控）
    obs = M.execute_inspection(g)                      # 可能新增 VQA 回答
    M.rsp.update_inspection(*obs, pd_lower=M.nfs.lower_bound(g.q, g.R))
    # 5) 检修决策：只用通过校准的后验与保守分位
    tau_q = M.rsp.quantile(M.rsp.decision_quantile())
    action = decide_maintenance(tau_q, M.cost, M.reset_model)
    # 6) 审计 + 证书
    M.ledger.seal()
    return action, M.rsp, M.j_pivot.build()
```

## 3. 推导

**引理 19（决策边界跨界才值钱）** 设维护策略为 RUL 决策分位 `τ*` 上的阈值规则，代价泛函 `J` 对后验的敏感支集落在 `τ ∈ [τ*−δ, τ*+δ]`。则对任意探询 `g`，
`DVI(g) ≤ L_J · P(τ ∈ [τ*−δ, τ*+δ] | b) · TV(b_g, b) − c_insp(g)`，
其中 `L_J` 为 `J` 在该带上的 Lipschitz 常数，`b_g` 为探询后的期望后验。**系**：当后验质量已全部远离决策边界（`P(τ∈带)→0`）时 `DVI→−c_insp`——再 informative 的探询也不该做。这解释了为什么 R69 的降熵式 VoI 会诱导「为了知道而知道」。

**引理 20（语言先验污染与 VGC 上界）** 设回答以概率 `γ` 来自图像接地、以 `1−γ` 来自语言先验，且先验主导回答满足 `G_blind` 集中在 0 附近（`P(G_blind > τ_blind | 先验) ≤ e^{−τ_blind}`）。则通过 VGC 的回答中，先验污染比例为
`δ_acc ≤ (1−γ) · e^{−τ_blind}`（当 `S_reg, S_par` 独立给出额外约束时进一步收紧）。
**系**：R69 的「k 源一致」把单源欺骗率按 `ρ^{k−1}` 压低；VGC 把「不看图的流利」按盲测差指数压低——两者是同一证据纪律在不同失效模式上的对偶。

**引理 21（阴性发现的乐观偏置）** 对退化可见事件 `D=1`，真实敏感度 `p_d`、系统采用 `p̂_d`。一次阴性观测后的后验把 `D=1` 的几率乘以 `(1−p̂_d)/(1−p_d)`。若 `p̂_d > p_d`，对数几率被低估 `log[(1−p_d)/(1−p̂_d)] > 0`，RUL 后验相应右移；右移量随 `(p̂_d − p_d)` 与 `P(D=1)` 单调增。取 `p_d^L ≤ p_d`（定义 315）可令该偏置 ≤ 0；若 `p_d^L = 0`，阴性观测似然恒为 1，后验不动——**「没看见」不再制造健康**。

**引理 22（删失与重置的双重偏置）** 忽略右删失会丢弃「尚未失效」单位的生存信息，使 `S(t)` 被低估（RUL 被估长）；忽略维修重置会把已修复的损伤继续计入，使 RUL 被估短。二者方向相反、不可相互抵消；必须以 `ℋ_t^{maint}` 条件化并同时用删失似然（定义 316–317），否则校准门 `CSG` 必然越界。

**定理 18（DVI 严格泛化 R69 的 VoI）** 当决策损失为「动作模态误选」、且各模态的决策边界等权时，`DVI` 退化为 R69 的模态信息增益 `VoI = H(M|o) − E[H(M|o,y)]` 减去探询成本；一般情形下 `DVI ≤ c·VoI`，且当信息不改变任何决策时 `DVI = 0` 而 `VoI > 0`。故 R69 是 PIVOT 在「决策边界均匀、探询成本为 0」处的特例；PIVOT 额外剪掉了「决策无关信息」。

**定理 19（PIVOT 的保守包含与无突发失效）** 在 `VGC` 门控、`NFS` 用下界、`CSG` 校准、`IPC` 认证下：(i) 任何被采纳的阴性证据都不会使 `P(τ ≤ τ*|b)` 低于真实值，故不会推迟应检修的决定；(ii) 当所有门控失败或 `max DVI ≤ 0` 时，PIVOT 逐决策等价于保守条件维护基线，且其失效风险不大于固定周期检修；(iii) 探询只改变「检修时机/是否再看」，不改变即时安全包络，底层动作仍由 R69 FLUID 认证，故控制连续、无突发失效。**系**：安全侧永不弱于 R69 与固定周期基线，收益全部来自「决策边界附近的精准探询」。

## 6. 本轮最大风险

**一句话**：PIVOT-RAS 的全部收益押在「视觉证据与漏检敏感度是被校准的」这一前提上——一旦 VQA 把「看起来正常」流畅地答成 normal、而系统又用未经认证的敏感度把阴性读成健康，**预测性维护就会退化为拖延性维护**：它省下的是探询次数，付出的是在真正失效前持续供应虚假安心。

**次级风险与缓解**：
1. **语言先验/幻觉** → VGC 三测门控（定义 313）+ 盲测差上界（引理 20），不接地即无证据；
2. **阴性洗白与选择性漏检** → NFS 敏感度下界铁律（定义 315、引理 21），未知敏感度按零处理；
3. **删失/重置偏置** → 生存后验 + `CSG` 校准门（定义 316–317、322、引理 22）；
4. **外观语义漂移/供应商换料** → `SDR` 重标定 + 越界停用该通道（定义 321）；
5. **视觉投毒/假健康图像** → 证据账本 + 正交源交叉验证 + `ℰ_visual` 对抗训练（定义 326）；
6. **探询本身致损/拖垮节拍** → `IPC` 物理认证 + 双环时序（定义 320、323）。

**定义 310（总览与三不变式）** PIVOT = (HDP,RSP,VGC,NFS,DVI,SIP,REN,SDR,IPC,CSG,RAS-WM†)。快环零学习写操作（继承 R69）；探询预算与物理安全认证；**阴性证据纪律**：单次阴性不得定案，敏感度未认证的阴性记为「未观测」而非「健康」。

**定义 311–312（隐退化与观测）** `dh_t = μ(h_t;θ)dt + σ(h_t)dW_t + dJ_t`，`τ = inf{t: h_t≥H_fail}`；遥测 `y_t = C h_t + ε_t`；探询观测 `p(A|h,q,R)`，退化可见时以敏感度 `p_d` 报阳、健康时以误报率 `p_f` 报阳。

**定义 313–314（VGC 与门控）** `VGC=1 ⇔ S_reg≥τ_reg ∧ S_par≤τ_par ∧ G_blind≥τ_blind`；未过者映射为「无证据」`⊥`，似然为常数、不更新后验、绝不当作阴性。R69 的「k 源一致」= VGC 三测全过的特例。

**定义 315（NFS 铁律）** 阴性只用 `p_d^L`：`p̄(A=0|退化)=1−p_d^L`。`p_d^L` 未认证 ⇒ 取 0 ⇒ 阴性无判别力，退化为「不看图、只用遥测」。**阴性永不比遥测更乐观。**

**定义 316–317（RSP 与 REN）** 删失生存似然 `L=∏ f(τ_i)^{δ_i}S(τ_i)^{1−δ_i}`；RUL 条件于维修历史，维修把 `h→h_0+Δ_m`，`Δ_m~p_reset`，每次维修开启新寿命周期，跨周期不得复用轨迹。

**定义 318–319（DVI 与 SIP）** `J(b)=min_π E[探询+检修+失效+停机]`，`τ*` 由成本比定；`DVI(g)=J(b)−E_A[J(b_A)]−c_insp(g)`，仅 `DVI>0` 才探询；`g*=(R,q,t_insp)` 约束预算/IPC/预期 VGC 通过率/正交源。无利可图 ⇒ 保守基线。

**定义 320（IPC）** 探询位移/力/热/停机在包络内且不触发危险状态、不错过安全窗口；任一不过 ⇒ `DVI=−∞`。

**定义 321（SDR）** 以检修拆解真值定期重标定 `π_A`；`E_sem>τ_sem` ⇒ 暂停该 `(q,R)` 的 VQA 证据，仅用认证通道/遥测（MCG 的语义版）。

**定义 322（CSG）** PIT 近均匀、区间覆盖率 ≥ α−ε_cov、删失 CRPS 不超基线；越界 ⇒ 区间膨胀到保守分位、更早检修，禁用「延寿」决策。

**定义 323（双环）** 快环 R69 FLUID < 2.6ms；慢环 PIVOT < 100ms/班次（事件触发 < 200ms），单向下传 `(z_t,b,τ_q)`，慢环不在快环内学习式写操作。

**定义 324–326（包含/证书/威胁）** 门控失败或 `max DVI≤0` ⇒ 仅遥测的保守条件维护，安全不弱于固定周期基线；`J_PIVOT` 并入 `J_FLUID` 与语义/敏感度/生存校准指标；`ℰ_PIVOT=ℰ_FLUID×ℰ_visual×ℰ_neglect×ℰ_semantic`，账本单调可归因。

## 3. 关键算法伪代码

```python
# IP-265 RSP：删失感知的 RUL 生存后验（粒子）
class RULSurvivalPosterior:
    def update_telemetry(self, y):
        for _ in range(T):
            self.h = propagate(self.h, self.theta, dt, jump=True)
            self.h, w = weight_telemetry(self.h, y)
        self.resample()

    def update_inspection(self, A, q, R, vgc, pd_lower):
        if vgc != 1 or A == REJECT: return self.record_no_evidence()   # 语言先验 -> 无证据
        if A == NEG and pd_lower <= 0: return self.record_unobserved()  # 阴性未认证 -> 不更新
        self.h, w = self.h, self.w * symptom_likelihood(A, q, R, self.h, pd_lower)
        self.resample()                                                 # 只用下界

    def rul_samples(self):  return first_passage(self.h, self.theta, H_fail, self.reset)
    def quantile(self, q):  return empirical_quantile(self.rul_samples(), q)

# IP-266 VGC：视觉接地证书
def vgc(vqa, I, A, q, R, tau):
    s_reg   = kl(vqa(I, q), vqa(mask_region(I, R), q))
    s_par   = max(tv(vqa(I, q), vqa(I, qp)) for qp in paraphrase(q))
    g_blind = logprob(vqa, A, I, q) - logprob(vqa, A, blank_image(I), q)
    return (s_reg >= tau.reg and s_par <= tau.par and g_blind >= tau.blind)

# IP-268 DVI：只在跨决策边界时值钱
def dvi(b, g, J, policy):
    if not ipc.certify(g) or expected_vgc_pass(g) < RHO_MIN: return -inf
    j0 = J(b, policy)
    j1 = sum(p * J(update(b, A, g), policy) for A, p in predictive_outcomes(b, g))
    return j0 - j1 - inspection_cost(g)

# IP-269 SIP：选择性探询规划
def plan(b, budget, J, policy):
    best = None
    for g in candidate_inspections(b):
        if not budget.allow(g): continue
        val = dvi(b, g, J, policy)
        if best is None or val > best.val: best = (g, val)
    return best if best and best.val > 0 else None          # 无利可图 -> 保守基线

# IP-276 慢环闭环（快环仍走 R69 FLUID）
def PIVOT_slow_loop(M, y_window, maybe_image):
    M.rsp.update_telemetry(y_window)
    if maybe_image is not None and not M.sdr.stale():
        for q, R in M.symptom_bank:
            A = M.vqa.ask(maybe_image, q, R)
            ok = vgc(M.vqa, maybe_image, A, q, R, M.tau)
            M.rsp.update_inspection(A, q, R, ok, M.nfs.lower_bound(q, R))
            M.ledger.append(q, R, A, ok)
    if M.sdr.error() > TAU_SEM or not M.csg.calibrated(M.rsp):
        return conservative_baseline(M.rsp, reason='gate')     # 定义 324
    g = plan(M.rsp, M.budget, M.cost, M.maint)
    if g is None: return schedule_maintenance(M.rsp, conservative=True)
    M.rsp.update_inspection(*M.execute_inspection(g),
                            pd_lower=M.nfs.lower_bound(g.q, g.R))
    tau_q = M.rsp.quantile(M.rsp.decision_quantile())
    action = decide_maintenance(tau_q, M.cost, M.reset_model)
    M.ledger.seal(); return action, M.rsp, M.j_pivot.build()
```

## 4. 推导

**引理 19（决策边界跨界才值钱）** 阈值规则下 `DVI(g) ≤ L_J·P(τ∈[τ*−δ,τ*+δ]|b)·TV(b_g,b) − c_insp(g)`。系：后验远离检修边界时 `DVI→−c_insp`——降熵式 VoI 会诱导「为了知道而知道」。

**引理 20（VGC 对语言先验的上界）** 承载地率 `γ` 时，通过 VGC 的回答中先验污染比例 `δ_acc ≤ (1−γ)e^{−τ_blind}`（加 `S_reg,S_par` 进一步收紧）。系：R69 的 `k 源一致` 压「人撒谎」，VGC 压「模型自欺」，二者对偶。

**引理 21（阴性发现的乐观偏置）** 采用 `p̂_d>p_d` 时，阴性观测把退化对数几率低估 `log[(1−p_d)/(1−p̂_d)]>0`，RUL 右移量随 `p̂_d−p_d` 与 `P(D=1)` 单调增；取 `p_d^L≤p_d` 使偏置 ≤0，`p_d^L=0` 时阴性似然恒 1、后验不动——「没看见」不再制造健康。

**引理 22（删失与重置的双重偏置）** 忽略右删失使 `S(t)` 低估、RUL 估长；忽略维修重置把已修损伤重复计入、RUL 估短。二者方向相反不可抵消；须以 `ℋ_t^{maint}` 条件化并用删失似然，否则 `CSG` 必越界。

**定理 18（DVI 严格泛化 R69 VoI）** 当损失为模态误选且决策边界等权时 `DVI` 退化为 R69 的 `VoI` 减探询成本；一般情形 `DVI ≤ c·VoI`，信息不改变决策时 `DVI=0` 而 `VoI>0`。故 R69 是 PIVOT 在「边界均匀、成本为 0」处的特例。

**定理 19（保守包含与无突发失效）** 在 VGC 门控 + NFS 下界 + CSG 校准 + IPC 认证下：(i) 采纳的阴性证据不使 `P(τ≤τ*|b)` 低于真值，不推迟应检修决定；(ii) 门控全败或 `max DVI≤0` 时逐决策等价保守基线，失效风险不高于固定周期检修；(iii) 探询不改即时安全包络，底层仍由 R69 FLUID 认证 ⇒ 控制连续、无突发失效。系：安全永不弱于 R69 与固定周期基线，收益全来自边界附近精准探询。

## 7. 本轮最大风险

**一句话**：PIVOT-RAS 的全部收益押在「视觉证据与漏检敏感度被校准」这一前提上——一旦 VQA 把「看起来正常」流畅地答成 normal、系统又用未经认证的敏感度把阴性读成健康，**预测性维护就退化为拖延性维护**：省下的是探询次数，付出的是在真正失效前持续供应虚假安心。

**次级风险与缓解**：语言先验/幻觉（VGC 三测 + 盲测差上界，引理 20）；阴性洗白/选择性漏检（NFS 下界铁律，引理 21）；删失/重置偏置（生存后验 + CSG，引理 22）；语义漂移/换料（SDR 越界停用）；视觉投毒/假健康图像（账本 + 正交源 + `ℰ_visual`）；探询致损/拖垮节拍（IPC + 双环时序）。
