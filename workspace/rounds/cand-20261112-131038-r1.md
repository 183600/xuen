# 第 61 轮（承接第 60 轮 SGEC「认知驱动场景闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「热管理」×「点云配准」）

> 第 60 轮把闭环升级为「场景→意图→约束→阻抗→执行→EV-exec→场景更新」，但**两个被忽视的物理层缺口**仍然存在：
> 1. **热是执行层被隐藏的状态**：SSM 的场景先验 π_scene(K|z) 与 EEIS 的 K_safe 都被当作「静态、可复现」的参数；而电机 K_p/K_d、最大持续力、WCET 都随结温漂移。第 60 轮的「场景适应」实际运行在一个**正在热漂移的执行器**上——热降额后 K_safe 可能物理不可达，SIC 的 execution_feasibility 却仍返回 true。这是抽象泄漏的新来源。
> 2. **几何证据缺席**：SSM 只吃力/位遥测，场景语义没有「几何锚点」。点云配准本可提供 SE(3) 级场景结构证据，但配准本身是**算力密集型**任务：它会加热计算单元、触发降频，导致配准延迟上升、几何证据变旧；同时热膨胀又**污染配准残差**，把「机器人热变形」误判为「场景改变」。第 60 轮恰好缺少区分这两种形变的机制。

## 0. 直觉与动机

**灵感 1（热管理 → 热执行状态 TES × 热感知阻抗编译 TIC）**
直觉：把执行器看成一个**有热记忆的器件**。持续接触力 F 产生耗散功率 P≈F·v+I²R，结温按一阶热网络上升，K_p、最大持续力、母线电流上限随温降额。关键洞见：**K_safe 不是常量集合，而是温度的函数 K_safe(T)**，且应受「热剂量」∫(F/F_max(T))²dt ≤ D_max 约束。第 60 轮编译出的「合规阻抗」若不经过热投影，在降额后**根本发不出来**——证书漂亮，物理撒谎。

**灵感 2（点云配准 → 几何配准证据 GRE）**
直觉：场景语义的物理锚点是几何。对扫描 P 与地图 M 做 GICP/NDT，得到 T∈SE(3)、残差 r、协方差 Σ_T；用信息矩阵的最小/最大特征值比做**退化检测**（平面、长走廊、玻璃）。关键洞见：**配准不只给位姿，还给「这个位姿有多可信」的退化度 d_deg**——它与第 60 轮 SIC 的 scene_conf 正交，二者相乘才是真正可用的场景置信。

**灵感 3（两灵感合流 → 热-几何耦合残差场 TGCR）【本轮核心洞见】**
直觉：机器人在热态下会膨胀/漂移，这种热变形在点云配准残差场里表现为**光滑、低频、可预测**的空间模式；而真实场景改变表现为**局部、跳变、不可预测**的残差。于是配准残差场 r(x) 可以**被反演成热应变**：r(x) ≈ Φ_T(x)·θ_T + Φ_S(x)·θ_S + ε。关键洞见：**点云配准残差是一个被忽视的分布式热变形传感器**——用「残差是否落在热变形子空间」来消歧「热变形」与「场景改变」，直接修复第 60 轮 SSM「湿滑地面误判为粗糙桌面」的失效模式。

**灵感 4（算力-热耦合 → 配准调度 RAS）**
直觉：配准越频繁、越精细，算力功耗 P_reg 越高，越容易把计算单元推到降频点；降频又拉长配准延迟 L_reg=C_reg(ρ)/f(T)，让几何证据变旧。这是一个**正反馈的「越算越慢」陷阱**。关键洞见：**把配准密度/频率作为热预算的受控变量**——热余量充足时稠密配准，接近上限时降为增量/稀疏配准 + 里程计死推，并显式记录几何证据时间戳，交给 TGE 做时效校验。

**灵感 5（合流 → 热-几何执行闭环 TGEL）**
直觉：TES 给 T→K_safe(T)→热剂量约束；GRE 给几何证据与退化度；TGCR 消歧热变形 vs 场景改变；RAS 控制配准的热-算力节奏；TGE 把 EV-thermal、EV-geo、EV-exec 按热时间常数 τ_th 拼成完整证据链；最终 TGEL 输出「温度有效的阻抗 + 时效有效的几何 + 因果完整的证据」，并把第 60 轮 CESC 升级为**热-几何联合决策**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（热执行状态 TES）** 热状态向量 τ = (T_j, T_d, T_a, R_th, C_th, D_acc)，其中 T_j 为结温、T_d 为驱动器温度、T_a 为环境温度、R_th/C_th 为热阻/热容、D_acc 为累计热剂量。热网络与降额：
```
C_th·dT_j/dt = P_diss(F, v) - (T_j - T_a)/R_th
P_diss(F, v) = F·v + I²R_m,  I ≈ F / K_f
η_T(T) = clip(1 - α_T·max(0, T_j - T_ref)/ΔT_rated, η_min, 1)
K_max(T) = η_T(T)·K_max0,  F_max(T) = η_T(T)·F_max0
D_acc(t) = ∫₀ᵗ (F(τ)/F_max(T(τ)))² dτ,  约束 D_acc ≤ D_max
```

**定义 162（热感知阻抗编译 TIC）** 在 EEIS 编译后做**热可行投影**：
```
K_safe^T = { K ∈ K_safe^base :
             K_p, K_d ≤ K_max(T_j)
             ∧ P_diss(K, F_req) ≤ P_limit(T)
             ∧ D_acc + ΔD(K, H) ≤ D_max(T) }
```
若 K_safe^T = ∅，TIC 返回 `THERMAL_DEGRADE`：降低 F_req、按占空比插冷却驻留（dwell），或等待降温。K_safe^T 与第 60 轮 K_safe^scene 的交集才是最终可下发集合。

**定义 163（几何配准证据 GRE）** 配准算子 R(P, M) → (T*, Σ_T, r, d_deg)：
- **位姿与协方差**：T* = argmin_T Σ_i ρ(‖T p_i − q_i‖)，Σ_T ≈ σ²(HᵀWH)⁻¹，H 为残差对 SE(3) 的雅可比
- **退化度**：d_deg = λ_min(HᵀWH) / λ_max(HᵀWH) ∈ [0,1]；平面/走廊/玻璃场景 d_deg→0
- **残差场**：r(x) = n(x)ᵀ(T* p(x) − q(x))，按空间格点聚合
- **证据**：EV-geo = (T*, Σ_T, r, d_deg, t_scan)；有效条件 valid_geo = r_rms≤τ_r ∧ d_deg≥τ_deg ∧ age(t)≤τ_geo。

**定义 164（热-几何耦合残差场 TGCR）** 把残差场分解到两个过完备基上：
```
r(x) = Φ_T(x)·θ_T + Φ_S(x)·θ_S + ε
  Φ_T : 热变形基（连杆热膨胀、基座热倾斜、关节零位漂移的解析 Jacobian）
  θ_T : 热应变幅值（待反演）
  Φ_S : 场景改变基（局部化原子：新增障碍、地面材质切换）
  θ_S : 场景改变幅值
min_{θ_T,θ_S} ‖r − Φ_Tθ_T − Φ_Sθ_S‖² + λ_T‖θ_T‖² + λ_S‖θ_S‖₁
```
判定规则：
```
if ‖θ_S‖₁ ≤ ε_S:                       # 光滑低频、可被热基解释
    classify = THERMAL_DOMINANT         # 机器人变形，纠正 T*/地图，不更新场景
elif ‖θ_T‖ small and ‖θ_S‖₁ > ε_S:      # 局部跳变
    classify = SCENE_CHANGE             # 交给 SSM 更新场景
else:
    classify = COMPOUND                 # 双通道，保守处理
```
反演出的 θ_T 回灌 TES，在线标定热膨胀系数 α_exp：θ_T ≈ α_exp·(T_j − T_ref)。

**定义 165（算力-热耦合配准调度 RAS）** 配准密度 ρ、频率 ν_reg，功耗 P_reg(ρ) 随 ρ 单调增，时钟 f(T)=f₀·clip(1−α_c·max(0,T_c−T_thr), f_min, 1)，延迟 L_reg = C_reg(ρ)/f(T)。调度器求解：
```
max_{ρ, ν_reg}  U = VOI_geo(ρ, ν_reg) − λ_E·E_reg − λ_L·L_reg − λ_T·ΔT_comp
s.t.  T_comp ≤ T_limit,  D_acc ≤ D_max
```
**降级阶梯**：dense GICP → incremental NDT → downsampled ICP → odometry dead-reckoning；每级显式输出 evidence_age 与 valid_geo，绝不以旧几何冒充新几何。

**定义 166（热-几何证据链 TGE）** 证据节点 EV-node = (EV-exec, EV-thermal, EV-geo)。三者时间常数不同：τ_exec ≪ τ_geo ≪ τ_th。因果拼接要求：
- **热证据有效**：t_exec 时刻的 T 由 EV-thermal 按热模型插值，age ≤ τ_th，且插值误差 ≤ δ_T
- **几何证据有效**：T* 在 t_scan 有效，经里程计传播到 t_exec，传播后协方差 ≤ Σ_max
- **交叉一致**：TGCR 判定不为 SCENE_CHANGE 的错配（即场景更新与热证据不冲突）
- **证书**：J_exec^TG 有效 ⇔ 三者皆有效；若 EV-thermal 缺失/过期（EPIR 丢包），K_safe(T) 无法被认证，J_exec^TG 降级为 `PROVISIONAL`，必须重新探测或降力执行。

**定义 167（热-几何执行闭环 TGEL）** 算子 TGEL(M, scene, intent, delta_f_req)：
```
① TES.update(telemetry, P_diss) → τ, η_T
② GE ← GRE.register(scan, M.map) ; valid_geo ← check(GE)
③ TGCR.decompose(GE.r) → (θ_T, θ_S, classify)
④ if classify == THERMAL_DOMINANT: M.map.correct(θ_T); TES.calibrate(θ_T)
   if classify == SCENE_CHANGE:     SSM.update_from_geometry(θ_S)
⑤ SSM → π_scene ; CESC 选 K_safe^scene
⑥ TIC: K_safe^T ← thermal_project(K_safe^scene, τ) ; if ∅ → THERMAL_DEGRADE
⑦ RAS.schedule(τ, ν_reg) → (ρ, ν_reg) ; (影响下一轮 GE 的密度与时效)
⑧ CLEP/SERC 执行 → EV-exec
⑨ TGE.join(EV-exec, EV-thermal, EV-geo) → J_exec^TG
⑩ XMC++/SIC 更新 ; Return (τ, GE, K_safe^T, EV-exec, J_exec^TG)
```

**定义 168（热-几何序贯决策 CESC-T）** 扩展定义 159：
```
if ∀z_i: SIC_valid ∧ valid_geo(z_i) ∧ K_safe^T(z_i) ≠ ∅
   ∧ ∀I_j: τ_response(I_j) ≤ τ_deadline:
       K = argmin_{K∈∩K_safe^scene(z_i) ∩ K_safe^T} (λ·ω_traj − (1−λ)·K_p)
elif 热约束不可行:
       返回 THERMAL_DEGRADE（降力/冷却驻留）并重排任务优先级
elif 几何退化:
```

### IP-161/162 TES + TIC（热状态与热感知阻抗编译）

```python
class ThermalExecutionState:
    def __init__(self, C_th=8.0, R_th=1.2, T_amb=25.0, T_ref=40.0,
                 alpha_T=0.01, eta_min=0.5, D_max=100.0):
        self.C_th, self.R_th, self.T_amb = C_th, R_th, T_amb
        self.T_ref, self.alpha_T, self.eta_min, self.D_max = T_ref, alpha_T, eta_min, D_max
        self.T_j = T_amb
        self.D_acc = 0.0

    def derate(self):
        eta = 1.0 - self.alpha_T * max(0.0, self.T_j - self.T_ref)
        return float(np.clip(eta, self.eta_min, 1.0))

    def update(self, F, v, K_f=1.0, R_m=0.2, dt=0.05):
        P = F * v + (F / K_f) ** 2 * R_m
        self.T_j += dt * (P - (self.T_j - self.T_amb) / self.R_th) / self.C_th
        eta = self.derate()
        self.D_acc += dt * (F / (self.eta_max * eta + 1e-9)) ** 2
        return self.T_j, eta

    def thermal_project(self, K_safe, F_req, horizon=5.0):
        eta = self.derate()
        K_proj = [K for K in K_safe
                  if K['K_p'] <= K['K_p0'] * eta
                  and K['K_d'] <= K['K_d0'] * eta
                  and self.D_acc + horizon * (F_req / (eta + 1e-9)) ** 2 <= self.D_max]
        if not K_proj:
            return None  # 触发 THERMAL_DEGRADE
        return K_proj
```

### IP-163/164 GRE + TGCR（几何证据与热-几何消歧）

```python
class ThermoGeometricResidual:
    def __init__(self, phi_T, phi_S, lam_T=0.1, lam_S=0.2, eps_S=0.05):
        self.phi_T, self.phi_S = phi_T, phi_S   # (N, m), (N, k)
        self.lam_T, self.lam_S, self.eps_S = lam_T, lam_S, eps_S

    def decompose(self, r):
        A = np.hstack([self.phi_T, self.phi_S])
        # 交替优化：θ_T 岭回归、θ_S 软阈值（ISTA）
        theta = np.zeros(A.shape[1])
        for _ in range(50):
            theta_T = np.linalg.solve(
                self.phi_T.T @ self.phi_T + self.lam_T * np.eye(self.phi_T.shape[1]),
                self.phi_T.T @ (r - self.phi_S @ theta[-self.phi_S.shape[1]:]))
            resid = r - self.phi_T @ theta_T
            z = self.phi_S.T @ resid / (np.linalg.norm(self.phi_S, axis=0) ** 2 + 1e-9)
            theta_S = np.sign(z) * np.maximum(np.abs(z) - self.lam_S, 0.0)
            theta = np.concatenate([theta_T, theta_S])
        l1_S = np.sum(np.abs(theta_S))
        if l1_S <= self.eps_S:
            return theta_T, theta_S, 'THERMAL_DOMINANT'
        if np.linalg.norm(theta_T) < self.eps_S:
            return theta_T, theta_S, 'SCENE_CHANGE'
        return theta_T, theta_S, 'COMPOUND'
```

### IP-165 RAS（算力-热耦合配准调度）

```python
class RegistrationThermalScheduler:
    LADDER = ['dense_gicp', 'incremental_ndt', 'downsampled_icp', 'odom_dead_reckon']

    def schedule(self, thermal, t_core, t_limit, voiof, budget):
        level = 0
        while level < len(self.LADDER) - 1:
            f = self._clock(t_core)
            L = voiof.latency(self.LADDER[level], f)
            dT = voiof.power(self.LADDER[level]) * L / thermal.C_th
            if t_core + dT <= t_limit and L <= budget.L_reg_max:
                break
            level += 1
        rho, nu = voiof.density(self.LADDER[level]), voiof.frequency(self.LADDER[level])
        return {'level': self.LADDER[level], 'rho': rho, 'nu': nu,
                'L_reg': voiof.latency(self.LADDER[level], self._clock(t_core)),
                'valid_geo_required': level < len(self.LADDER) - 1}

    @staticmethod
    def _clock(T):
        return 1.0 * np.clip(1.0 - 0.02 * max(0.0, T - 70.0), 0.3, 1.0)
```

```python
def tge_join(ev_exec, ev_thermal, ev_geo, tj_model, tau_th=30.0, tau_geo=2.0):
    age_th = ev_exec.t - ev_thermal.t
    age_geo = ev_exec.t - ev_geo.t
    th_ok = (age_th <= tau_th) and tj_model.interp_ok(ev_thermal, ev_exec.t)
    geo_ok = (age_geo <= tau_geo) and ev_geo.valid and \
             (ev_geo.propagate_cov(ev_exec.t) <= ev_geo.Sigma_max)
    if th_ok and geo_ok:
        return {'status': 'VALID', 'K_safe_T': tj_model.thermal_project(ev_exec.K_safe)}
    return {'status': 'PROVISIONAL', 'action': 'reprobe_or_reduce_force'}


def thermo_geometric_execution_loop(M, scene, intent, delta_f_req):
    M.thermal.update(M.telem.F, M.telem.v)
    geo = M.gre.register(M.scan, M.map)
    theta_T, theta_S, cls = M.tgcr.decompose(geo.r)
    if cls == 'THERMAL_DOMINANT':
        M.map.correct(theta_T); M.thermal.calibrate(theta_T)
    elif cls == 'SCENE_CHANGE':
        M.ssm.update_from_geometry(theta_S)
    K_scene = M.cesc.select(M.ssm, scene, delta_f_req)
    K_safe_T = M.thermal.thermal_project(K_scene, delta_f_req)
    if K_safe_T is None:
        return M, 'THERMAL_DEGRADE'
    plan = M.ras.schedule(M.thermal, M.t_core, M.t_limit, M.voi_geo, M.budget)
    M, fused, D_plus, ev_exec, cert = closed_loop_exec_probe(M, K_safe_T, delta_f_req, M.budget)
    jtg = tge_join(ev_exec, M.ev_thermal[-1], geo, M.thermal)
    M, fused, D_plus = xmodal_fuse_plus(M, M.current_cp.region, M.inf_latest, ev_exec)
    return M, jtg, geo, plan
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TES/TIC | O(\|K_safe\|) 投影/周期 | O(1) | 热网络误差 ≤ δ_T；热剂量约束恒满足 |
| GRE | O(iter·N_pts) | O(N_pts) | 残差 r_rms ≤ τ_r，退化度可检出 d_deg < τ_deg |
| TGCR | O(iter·(m+k)·N) | O(N·(m+k)) | 热/场景消歧准确率 ≥ 90%（基可分离时） |
| RAS | O(#ladder)=O(4) | O(1) | 证据时效 age ≤ τ_geo 或被显式标记失效 |
| TGE | O(1) 拼接 | O(1) | 证书完整性 ≥ 99.9%，过期必降级 |
| TGEL | O(闭环 + 配准) | 复用 | 热不可行必降级，绝不幻觉执行 |

**正确性定理（TGEL-Cert）**：
假设 A22–A70 成立（新增 **(A66)** 一阶热网络与降额单调；(A67) 热变形基 Φ_T 覆盖真实热应变；(A68) 退化度 d_deg 单调反映信息矩阵病态；(A69) 交叉消歧在基可分离时唯一；(A70) 证据时效严格标记）。

则：
1. **热可行性**：若 τ 被 TES 正确估计，则 K_safe^T 中任一 K 在热降额下物理可达，SIC 的 execution_feasibility 不再虚假为真。
2. **几何消歧**：若真实残差由热变形主导，则 TGCR 判为 THERMAL_DOMINANT，SSM 不被污染；反之场景改变的样本被正确路由到 SSM。
3. **证据完整性**：J_exec^TG 有效 ⇒ 热证据 age≤τ_th ∧ 几何证据 age≤τ_geo ∧ 交叉一致；任一不满足则降级 PROVISIONAL，不会被冒充为有效证书。
4. **调度安全**：RAS 输出必满足 T_comp≤T_limit 与热剂量约束，且低级别几何证据被显式标注失效而非静默使用。

```python
class ThermalExecutionState:
    def __init__(self, C_th=8.0, R_th=1.2, T_amb=25.0, T_ref=40.0,
                 alpha_T=0.01, eta_min=0.5, D_max=100.0):
        self.C_th, self.R_th, self.T_amb = C_th, R_th, T_amb
        self.T_ref, self.alpha_T, self.eta_min, self.D_max = T_ref, alpha_T, eta_min, D_max
        self.T_j = T_amb
        self.D_acc = 0.0
        self.eta_max = 1.0

    def derate(self):
        eta = 1.0 - self.alpha_T * max(0.0, self.T_j - self.T_ref)
        return float(np.clip(eta, self.eta_min, 1.0))

    def update(self, F, v, K_f=1.0, R_m=0.2, dt=0.05):
        P = F * v + (F / K_f) ** 2 * R_m
        self.T_j += dt * (P - (self.T_j - self.T_amb) / self.R_th) / self.C_th
        eta = self.derate()
        self.D_acc += dt * (F / (self.eta_max * eta + 1e-9)) ** 2
        return self.T_j, eta

    def thermal_project(self, K_safe, F_req, horizon=5.0):
        eta = self.derate()
        # 注意：用候选 K 自身的标称上限 K_p0/K_d0 做降额比较
        K_proj = [K for K in K_safe
                  if K['K_p'] <= K['K_p0'] * eta
                  and K['K_d'] <= K['K_d0'] * eta
                  and self.D_acc + horizon * (F_req / (eta + 1e-9)) ** 2 <= self.D_max]
        return K_proj if K_proj else None   # None ⇒ THERMAL_DEGRADE
```

### IP-163/164 GRE + TGCR（几何证据与热-几何消歧）

```python
class ThermoGeometricResidual:
    def __init__(self, phi_T, phi_S, lam_T=0.1, lam_S=0.2, eps_S=0.05):
        self.phi_T, self.phi_S = phi_T, phi_S   # (N, m), (N, k)
        self.lam_T, self.lam_S, self.eps_S = lam_T, lam_S, eps_S

    def decompose(self, r):
        # 交替优化：θ_T 岭回归；θ_S ISTA 软阈值
        theta_T = np.zeros(self.phi_T.shape[1])
        theta_S = np.zeros(self.phi_S.shape[1])
        for _ in range(50):
            theta_T = np.linalg.solve(
                self.phi_T.T @ self.phi_T + self.lam_T * np.eye(self.phi_T.shape[1]),
                self.phi_T.T @ (r - self.phi_S @ theta_S))
            resid = r - self.phi_T @ theta_T
            z = self.phi_S.T @ resid / (np.linalg.norm(self.phi_S, axis=0) ** 2 + 1e-9)
            theta_S = np.sign(z) * np.maximum(np.abs(z) - self.lam_S, 0.0)
        if np.sum(np.abs(theta_S)) <= self.eps_S:
            return theta_T, theta_S, 'THERMAL_DOMINANT'
        if np.linalg.norm(theta_T) < self.eps_S:
            return theta_T, theta_S, 'SCENE_CHANGE'
        return theta_T, theta_S, 'COMPOUND'

    def calibrate(self, theta_T, T_j, T_ref):
        # 若 θ_T 与 ΔT 线性一致，则更新 α_exp；否则标记基失配，禁止自动纠正
        dT = max(1e-6, T_j - T_ref)
        return float(np.dot(theta_T, np.ones_like(theta_T)) / (len(theta_T) * dT))
```

### IP-165 RAS（算力-热耦合配准调度）

```python
class RegistrationThermalScheduler:
    LADDER = ['dense_gicp', 'incremental_ndt', 'downsampled_icp', 'odom_dead_reckon']

    def schedule(self, thermal, t_core, t_limit, voiof, budget):
        level = 0
        while level < len(self.LADDER) - 1:
            f = self._clock(t_core)
            L = voiof.latency(self.LADDER[level], f)
            dT = voiof.power(self.LADDER[level]) * L / thermal.C_th
            if t_core + dT <= t_limit and L <= budget.L_reg_max:
                break
            level += 1
        return {'level': self.LADDER[level],
                'rho': voiof.density(self.LADDER[level]),
                'nu': voiof.frequency(self.LADDER[level]),
                'L_reg': voiof.latency(self.LADDER[level], self._clock(t_core)),
                'valid_geo_required': level < len(self.LADDER) - 1}

    @staticmethod
    def _clock(T):
        return float(np.clip(1.0 - 0.02 * max(0.0, T - 70.0), 0.3, 1.0))
```

```python
    age_geo = ev_exec.t - ev_geo.t
```
