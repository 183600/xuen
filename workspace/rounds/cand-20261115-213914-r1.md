# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「Gazebo」×「预训练」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**影子孪生 + 共形预训练 + 单调保守**。两个灵感合起来只做一件事：把 v9 末端点名的最大风险——"分块执行在最需要安全的时刻暴露最不可靠的证书"——从"把 β 赌大一点"改造成"可观测、可校准、可提前收缩"的工程闭环。硬纪律：影子世界（Gazebo）与预训练模型只能让系统更保守，绝不能放松 v9 的任何安全约束（P13 单调保守律）；任一新组件失效必须注入中立元、严格退回 v9（引理 91）。

## 0. 直觉与动机

**灵感 1（Gazebo → 影子孪生：把证书从"自证"变成"他证"）**
直觉：v9 的块证书由轻量前向模型 F̂ 给出，β 是手调常数——这本质上是"自己给自己发合格证"。Gazebo 的正确用法不是塞进 20ms 决策预算（它太重，一次高保真回放动辄几十到几百毫秒），而是作为**异步影子世界**：在独立进程里回放同一状态快照与候选块，用高保真物理回答"如果没有实时约束，这一步会怎样"。它提供两个 v9 拿不到的东西：(a) **孪生证书** Ĉ^G，在块边界对**下一个**块行使"只收紧"的否决权；(b) **孪生–真实分歧** d_G，它比 DA-ML 的 20 帧滑窗更早暴露"世界已经变了"。附加红利：反事实回放（在仿真里撞墙不心疼）可以替代 v9 拿真机安全换归因数据的在线消融。核心创新：**影子孪生验证器（ShadowTwinVerifier, SWV）** 与 **孪生分歧前哨（TwinDivergenceSentinel, TDS）**。

**灵感 2（预训练 → 共形证书：把 β 从常数变成分布无关的统计量）**
直觉：预训练世界模型的价值不在于"它更准"，而在于它见过更宽的动力学分布，能给分布外（OOD）一个可用先验；但预训练分布 ≠ 部署分布，模型在新域会"自信地错"。严谨的做法不是相信它，而是把它装进**共形预测**的壳：用一小撮校准残差给出分布无关的 β_t；再用自适应共形推断（ACI），当可交换性被打破（预训练先验失效）时让 β_t 自动膨胀而不是灾难性失效。核心创新：**预训练共形动力学（PretrainedConformalDynamics, PCD）**：β_t = split-conformal 分位数 + ACI 在线修正，附**可交换性监测器**。这使 v9"信任域内误差 ≤ β"的祈使句第一次变成可检验的统计命题。注意：共形是概率性的，v9 的停车不变式仍是确定性的最后防线——二者分工是"共形负责少留余量，停车守卫负责错了也能停"。

**灵感 3（Gazebo × 预训练 → 共享盲区必须被显式建模）**
直觉：如果影子与轻量模型源自同一预训练分布，它们在真正的新域会**一起错**——分歧信号 d_G 低估误差，共形残差也偏小，最危险的恰恰是"验证器与被验证对象共同自信地错"。本轮不假装消除它，而是把它抬到台面并量化：**孪生保真度证书（TFC）**用最近开环预测误差度量"影子到底有多像真实"，低保真时影子意见降权为中立元；同时把"同源盲区漏报率"写成预注册实验（E578）。核心创新：**孪生保真门控律（P15）** 与 **反事实归因回放（CRA）**。

## 1. 研究问题（轮次升级版）

- **Q1（影子时效与权威边界）**：异步影子必然滞后于 50Hz 控制；在什么条件下"只否决下一个块、只收紧不放松"的影子能带来净安全增益，而不会因一个坏影子制造新的不安全？影子作为"旁证"与作为"真值"的边界在哪里？
- **Q2（预训练证书的覆盖）**：当预训练先验与部署分布不一致时，split conformal + ACI 的 β_t 能否给出可证明的长期覆盖？覆盖失效时，系统行为能否被证明退化为"更保守"而非"更激进"？
- **Q3（同源盲区与归因）**：当影子与轻量模型共享预训练偏差时，如何用保真度证书与分歧信号区分"真安全"与"共同自信地错"？反事实归因在孪生保真度 δ 内的误差界是什么？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 影子只加保守律（Shadow-Monotone-Conservatism, SWV）**
影子与预训练的所有输出只能经**单调保守算子**进入系统：β_t ← max(β_const, β_conf)；偏移分数 ρ_t ← max(Δ_dom/τ_dom, d_G/τ_G, 可交换性破坏指示 X_t)；K_eff ← K_max·(1−min(1,ρ_t))；孪生否决 v_G 只能令 K_eff←1 或重采样。任何影子/预训练输出都不得放松 v9 约束、不得覆盖 M₀ 硬检查、不得增大 K_eff 或减小 β。

**P14 共形证书律（Conformal-Certificate, PCD）**
信任域内的模型误差界 β_t 不是常数，而是共形分位数：β_0 = Q_{⌈(n+1)(1−α)⌉}(校准残差)，随后按 ACI 更新 β_{t+1} = β_t + η(α − err_t)，并硬性截断 β_t ∈ [β_const, β_max]。共形保证在可交换性下分布无关成立；可交换性破坏时系统只能更保守。

**P15 孪生保真门控律（Twin-Fidelity-Gated Trust, SWV/TDS）**
影子意见的权重由其自身保真度证书 TFC 门控：开环保真度 δ_G 高于阈值时，影子证书降权为中立元、d_G 不参与前哨（退回仅 Δ_dom 门控）、否决失效。影子永远不是"权威真值"，只是"带保真标签的旁证"；一个坏影子最多让系统退回 v9，绝不能让系统比 v9 更激进。

## 3. 与基线的接口（如何退化）

- SWV 失效（Gazebo 进程崩溃 / 回放延迟超界 / TFC 低）⇒ d_G≡0、无否决、β_t 退回纯在线 ACI，最终等价 v9 的固定 β 路线（更弱但安全）；
- PCD 失效（预训练权重不可用 / 校准集丢失 / 可交换性监测器故障）⇒ β_t ← β_const（v9 常数），证书退回 v9 定义 533，逐位等价；
- TDS 失效 ⇒ 前哨项 d_G≡0、X_t≡0，K_eff 仅由 Δ_dom/risk_SLAM 门控，等价 v9 定义 539；
- CRA 失效 ⇒ 归因退回 v9 在线消融（定义 537），ID 语义不变；
- 全部失效 ⇒ 完整退回 v9 的 ACMD；再按 v9 引理 83 退回 v8/v7。

## 4. 预期贡献

1. **影子孪生验证 + 分歧前哨**：把 Gazebo 从"离线评测工具"升级为"在线旁证系统"，用 d_G 抢在 DA-ML 20 帧滑窗前收缩 K_eff；
2. **共形预训练证书**：β 从手调常数变为分布无关统计量（split conformal + ACI），附可交换性监测与失效退化证明；
3. **同源盲区的显式建模**：孪生保真度证书 + 单调保守律，使"验证器与被验证对象一起错"从暗礁变成可测、可降级的一等风险；
4. **反事实归因**：用 Gazebo 回放替代真机消融，降低归因的算力与安全代价，并给出保真度误差界；
5. **预算–安全–校准三闭环**：实验 E571–E592 覆盖影子时效、共形覆盖、同源盲区、反事实归因、单调性、退化等价与端到端任务。

## 5. 本轮最大风险

**一句话**：影子孪生的物理（Gazebo 刚体/接触假设）与预训练先验可能和真实世界**同向出错**——此时 d_G 与共形残差都低估误差，TFC 又只能在同一预训练分布内度量保真度，"验证器"会与"被验证对象"一起自信地错，即"我们用一个模型去担保另一个模型，却从未真正接触过真实"。

        self.ring.push((snap, chunk))     # 绝不进入 50Hz 决策预算

    def tick(self):                       # 每 T_G=200ms 执行一次
        item = self.ring.latest()
        if item is None:
            return
        snap, chunk = item
        Yhat = self.g.replay(snap, chunk)                 # Gazebo 高保真回放
        self.last_cert = self._cert(Yhat)                 # Ĉ^G
        err = open_loop_err(Yhat, recent_obs(snap))       # 最近 h 步开环误差
        self.delta_ema = ema(self.delta_ema, err, 0.2)    # 定义 544 TFC
        dG = wasserstein(Yhat.history, recent_obs(snap))
        self.sigma_ema = ema(self.sigma_ema, dG, 0.05)
        if self.tfc_valid():                              # δ_G ≤ δ_max
            self.last_div = dG
            self.last_veto = self._veto(self.last_cert)   # 定义 545
        else:                                             # 坏影子 → 中立元
            self.last_div, self.last_veto = 0.0, 0

    def tfc_valid(self):
        return self.delta_ema is not None and self.delta_ema <= self.delta_max

    def _veto(self, cert):
        return int(cert.g_min < D_SAFE or cert.e_max > TAU_EFF)


# IP-358 PretrainedConformalDynamics：预训练共形证书
class PretrainedConformalDynamics:
    def __init__(self, f_theta, calib_scores, alpha=0.05, eta=0.01,
                 beta_const=0.02, beta_max=0.20, alpha_ex=0.01):
        self.f, self.alpha, self.eta = f_theta, alpha, eta
        self.beta_const, self.beta_max = beta_const, beta_max
        n = len(calib_scores)
        k = min(n, math.ceil((n + 1) * (1 - alpha)))
        self.beta = max(beta_const, sorted(calib_scores)[k - 1])   # 定义 541
        self.monitor = ExchangeabilityMonitor(alpha_ex)           # 定义 542

    def residual(self, s, a, s_next):
        return max(abs(x - y) for x, y in zip(self.f(s, a), s_next))

    def observe(self, e):                                         # 每周期
        err = 1.0 if e > self.beta else 0.0
        self.beta = min(self.beta_max,
                        max(self.beta_const,
                            self.beta + self.eta * (self.alpha - err)))  # ACI
        self.monitor.update(e, self.beta)
        return self.beta

    def exchangeability_broken(self):
        return int(self.monitor.p_value() < self.monitor.alpha_ex)


# IP-359 TwinDivergenceSentinel：单调偏移分数
class TwinDivergenceSentinel:
    def __init__(self, tau_G=1.0, sigma_min=1e-3):
        self.tau_G, self.sigma_min = tau_G, sigma_min

    def shift_score(self, delta_dom, tau_dom, dG, sigma_G, X):
        d_norm = dG / max(sigma_G, self.sigma_min)
        rho = max(delta_dom / tau_dom, d_norm / self.tau_G, float(X))
        return min(1.0, rho)                     # 单调不减（定义 543）

    def effective_K(self, rho, K_max, trust_ok):
        if not trust_ok or rho >= 1.0:
            return 1
        return max(1, int(K_max * (1.0 - rho)))

## 4. 推导

**引理 87（共形边际覆盖）** 若 D_cal 与部署样本可交换、残差连续，则 split-conformal 满足 P(e_new ≤ β_0) ≥ 1−α。因此在事件 E={e_new ≤ β_t} 上，v9 引理 82(i) 以 β=β_t 成立，且 P(E) ≥ 1−α。**注意这是边际保证而非条件保证**；上下文桶只能近似条件化，桶内样本不足时逐级回退、最终回退 β_const。

**引理 88（ACI 任意序列的长期覆盖）** 设 e_t∈[0,B_e]，β_t∈[β_const,β_max]，err_t=1[e_t>β_t]，η>0。则
```
Σ_{t=1}^T err_t ≤ αT + (β_max − β_const)/η
(1/T)Σ err_t ≤ α + (β_max − β_const)/(ηT) → α
```
无需可交换性。结合 β_t ≥ β_const，长期覆盖率不劣于 v9 的固定 β；即预训练先验失效时系统**只会更保守**，不会更激进。∎

**引理 89（单调保守 ⇒ 安全性传递）** 由定义 547，F_10(s) ⊆ F_9(s)。v10 执行的每个块都落在 v9 可行集内，故 v9 引理 82(ii)（中止点安全）与引理 84（蒸馏安全）仍成立。影子/预训练的加入只能收紧可行集，不能产生 v9 未覆盖的行为。∎

**引理 90（前哨领先性，条件性）** 设 t0 发生真实偏移，残差分歧以速率 g 增长、影子延迟 L_G、检测阈 τ_G，DA-ML 滑窗宽 W=20、周期 Δt=20ms。则 TDS 首检时刻 ≈ t0+L_G+τ_G/g，DA-ML ≈ t0+WΔt+τ_det；若 L_G+τ_G/g < WΔt+τ_det，则 TDS 领先。**该不等式成立的前提是影子与真实世界不共享同一盲区**——这正是本轮最大风险，故 E578 专门测量共享偏差下的漏报率。∎

**引理 91（失效退化 ≡ v9）** 若 SWV 不可用，令 d_G≡0、v_G≡0、X≡0；若 PCD 不可用，令 β_t≡β_const；若 CRA 不可用，归因退回定义 537。则 ρ_t=Δ_dom/τ_dom、K_eff=定义 539、证书=定义 533，逐项等于 v9；由归纳，系统与 v9 ACMD 逐位等价，再经 v9 引理 83 退回 v8/v7。∎

**引理 92（反事实归因误差界）** 若影子在回放窗 H 上的保真度 δ_G ≤ δ，且得分 J 对轨迹 L-Lipschitz，则 |c_m^CRA − c_m^true| ≤ Lδ。故 CRA 归因只有在 TFC 有效（δ≤δ_max）时可信；TFC 失效即回退在线消融。∎
