# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC/IP-153~160；灵感循环第 1 轮；本轮灵感：「情感语音」×「UniBot世界挑战赛」）

> 第 60 轮 SGEC 已把「场景」升级为阻抗先验 π_scene(K|z)，用 SSM×CIEC×EPIR×SERC 实现了「场景先验提前收敛 K_safe、意图即时锁定约束、证据链防消息丢失」。但整条链路仍建立在两个未被审视的假设上：
> 1. **人声只被当作「命题」，没被当作「证据」**：CIEC 从语音中只抽取词面意图 I（「慢点」「轻触」），却丢弃了同一句话里的韵律-情感通道——音高抖动、能量骤升、语速、停顿、气息。一个颤抖着说「没事，继续」的操作者，与平静地说同一句话，风险含义完全相反。**情感不是又一类指令，而是关于「这条指令可不可信、这个人还能不能监督」的元观测**；第 60 轮把元观测当噪声丢掉了。
> 2. **安全声明只在「本场景族」内自证，无法跨任务/跨本体迁移**：UniBot 世界挑战赛的判据是**隐藏任务族、跨本体、限时、最差层不崩**；而 SGEC 的 SIC 置信度是自洽性的产物，越出训练分布时反而更自信（OOD 过度自信）。一个在实验室桌面 95% 成功的证书，在挑战赛的新物体/新本体上可能直接失效——**没有可撤销的迁移证书，就没有竞赛级安全**。
> 3. **缺少「二阶证据只许收紧」的结构约束**：情感、新颖性、迁移证书都是二阶（关于证据的证据）信号，本身噪声更大。若允许它们放松约束或提升自主性，系统就会被「错误的确信」劫持。必须有一条**单调性原则**：二阶信号只能使约束更紧、自主性更低、可用技能集更小，永不反向。

## 0. 直觉与动机

先给直觉，再给定义：本轮的核心不是再加一个感知模态，而是给第 60 轮的 SGEC 加一层**「关于证据的证据」**——情感语音刻画「人这条证据有多可靠」，挑战赛刻画「当前任务有多陌生、这张证书有多可迁移」。

**灵感 1（情感语音 → 情感元证据 AME）**
直觉：同一句「轻一点」，平静地说是在提要求；发抖地说是在恐惧；急促地说是在报警；迟疑地说可能自己也不确定。词面意图相同，但**指令的可信度、紧迫度与操作者的监督能力**完全不同。关键洞见：把韵律特征映射为**情感状态 E=(valence, arousal, dominance, certainty)** 及其**不确定度 u_aff**，并把 e_aff=(E,u_aff) 作为二阶证据：它不直接改 K_safe，而是改「我们该多相信 I」与「该让系统多自主」。

**灵感 2（UniBot 世界挑战赛 → 竞赛级新颖性 CGN 与迁移证书 CTC）**
直觉：挑战赛不是「在熟悉场景里跑高分」，而是「在没见过的任务、物体、本体、时间预算下不崩」。平均分高但最差层崩塌的方案会被隐藏测试直接淘汰。关键洞见：把「这条技能能不能迁移」写成一个**可撤销的统计证书**——用共形风险控制在隐藏校准族上给出风险上界，并显式维护**最差层下置信界**与**分数在险值 SAR**；一旦版更/分布漂移使证书失效，技能自动降级为「只能监督下使用」。同时用**开放集新颖性**在运行时识别「这题我没见过」，把 OOD 过度自信压回保守先验。

**灵感 3（情感 × 挑战赛 → 二阶接地闭环 MAGEC）**
直觉：情感回答「人靠不靠谱」，新颖性回答「题熟不熟」，证书回答「技能能不能用」。三者合流为 **MAGEC（Meta-Affective Grounded Execution Closure）**：场景仍由 SGEC 管，但**场景先验的信任度、人的信任度、技能的可迁移度**由二阶层统一裁决；二阶层只做减法（更紧的 K_safe、更低的自主性、更小的技能集），从不做加法。

**灵感 4（情感 → 监督信任包络 STE）**
直觉：操作者恐慌时，问题往往不是「他说错话」，而是「他已经没有余力监督系统」。此时正确的响应不是照单执行，也不是简单停机，而是：降低自主等级、提高证据阈值、对不可逆动作强制确认。关键洞见：把 (r, u_aff, novelty, 剩余时间) 映射为**监督信任包络** (自主等级 a, 证据阈值 τ_ev, 确认门 g_confirm)，并保证映射对「可靠性下降/不确定度上升」**单调保守**。

**灵感 5（挑战赛 → 竞赛时钟 CBC 与 PCE++++++）**
直觉：竞赛与实验室最大的差别是**时间不可逆、失败不可重来**。探索/适应是有成本的，必须在「继续探索可能涨分」与「超时/翻车直接零分」之间做元决策。关键洞见：新增 B_aff、B_transfer 两个预算，与原有 B_scene/B_intent/B_ros/B_exec 组成六维预算；当剩余时间低于安全储备或分数在险值越界时，**强制关闭探索、回退到已认证技能**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（情感元证据 AME）** 情感状态空间 E = V×A×D×C，其中 valence v∈[-1,1]、arousal a∈[0,1]、dominance d∈[-1,1]、certainty c∈[0,1]。韵律观测
x_aff = (F0_mean, F0_slope, F0_range, F0_jitter, energy_mean, energy_slope, shimmer, HNR, speech_rate, pause_ratio, ASR_nbest_entropy)。
情感估计器 q_φ(E|x_aff) 经温度标定，其预测熵归一化为 u_aff = H[q_φ] / log|E| ∈ [0,1]。**情感元证据** e_aff = (E, u_aff)，语义是「关于操作者指令可靠性与监督余力的二阶观测」，而**不是**一条新指令。

**定义 162（情感-意图可靠性 AIR）** 给定词面意图后验 q(I|x_asr)、意图条件下的情感核 N(E; μ_{E|I}, Σ_{E|I})，定义：
- **情感-意图矛盾度**：D_ai = (E−μ_{E|I})ᵀ Σ_{E|I}⁻¹ (E−μ_{E|I})；
- **指令可靠性**：r = σ(α₀ + α₁·log q(I) + α₂·c + α₃·(τ_c − D_ai) + α₄·h_hist)，其中 h_hist 为近期意图-执行一致率；
- **升级算子**：ℓ = 1[ D_ai > τ_c ∨ u_aff > τ_u ∨ r < τ_r ]，ℓ=1 表示「情感与词面冲突/人不可靠」；
- **元约束**：C_meta = (C_intent, r, ℓ)，且
  K_safe^aff = K_safe ∩ { (v_max,K_d,F_max) | v_max ≤ v_max·(0.5+0.5r)，K_d ≥ K_d·(1+(1−r)) }（ℓ=1 时），ℓ=0 时 K_safe^aff = K_safe。
  即情感只能**收紧**约束或要求确认，**永不放松**；「情感-意图矛盾」被提升为一等安全事件而非解析噪声。

**定义 163（监督信任包络 STE）** 包络 S = (a, τ_ev, g_confirm)，a∈{0,1,2,3} 为自主等级（0=仅建议，3=全自主），τ_ev 为进入下一步所需证据阈值，g_confirm∈{0,1} 为不可逆动作的确认门。映射 ψ_STE: (r, u_aff, s_nov, T_rem) → S 满足单调性：
- ∂a/∂r ≥ 0，∂a/∂u_aff ≤ 0，∂a/∂s_nov ≤ 0；
- ∂τ_ev/∂r ≤ 0，∂τ_ev/∂u_aff ≥ 0，∂τ_ev/∂s_nov ≥ 0；
- 若 a < a_min 且动作不可逆，则 g_confirm=1；若 T_rem < T_reserve，强制 a≤1。
  STE 把「人还能不能监督」显式建模为资源，而不是把情感当作命令。

**定义 164（竞赛级新颖性 CGN）** 任务-本体-场景指纹 φ = (object_desc, geometry_stats, dynamics_params, embodiment_sig, task_embedding)。已知分布密度 p_known(φ) 由归一化流或能量模型给出，新颖分数 s_nov(φ) = −log p_known(φ)。在已知校准集 {(φ_i, s_i)} 上定义共形 p 值
p_nov(φ) = (1 + #{i : s_i ≥ s_nov(φ)}) / (n+1)。
若 p_nov(φ) < α_nov，判为 OOD，并执行**单向保守化**：
- 场景先验协方差膨胀 Σ_scene ← Σ_scene·(1+β·s_nov)；
- τ_scene 提高、τ_ev 提高、自主等级 a 下调；
- 该次执行标记「证书不适用」，禁止其证据回写场景先验。

**定义 165（竞赛迁移证书 CTC）** 对技能/策略 π_λ 与任务分布 D（含本体集合 M 与难度分层 L₀…L₄），损失 L∈[0,1]（失败或安全违约）。用共形风险控制在校准族 D_cal 上选
λ̂ = inf{ λ : (n/(n+1))·R̂_n(λ) + 1/(n+1) ≤ α }，
证书 CTC = (skill_id, λ̂, α, δ, V_hash, cov_hat, LCB_ℓ for ℓ∈L, revoke_pred)。
其中**最差层下置信界** LCB_min = min_ℓ LCB_ℓ，**分数在险值** SAR = sup_ℓ E[score_loss | ℓ]。撤销谓词 revoke_pred 在基准版本 V′ 变更、污染审计失败、或任一层 LCB 跌破阈值时置真；一旦撤销，该技能**只能以 a≤1 使用**，且其证据不得签发迁移声明。

**定义 166（MAGEC 闭环与二阶接地单调性 SGM）** 算子 MAGEC(M, scene, speech, T_rem)：
```
① SGEC: z_scene, K_safe^scene ← scene_perception_evolution(...)
② AME: e_aff = (E, u_aff) ← affect_estimator(x_aff)
③ AIR: (C_intent, r, ℓ) ← affect_intent_reliability(q(I), e_aff)
④ CGN: (s_nov, p_nov) ← novelty(φ_task)
⑤ CTC: cert_ok ← transfer_certificate.check(skill, V_hash, s_nov)
⑥ STE: (a, τ_ev, g_confirm) ← trust_envelope(r, u_aff, s_nov, T_rem)
⑦ 若 p_nov<α_nov 或 ¬cert_ok：K_safe ← conservative_compile(...)；否则 K_safe ← K_safe^scene ∩ K_safe^aff
⑧ 若 g_confirm=1：请求确认 / 仅执行可逆子动作
⑨ Execute under autonomy a；EV-exec ← build_exec_evidence(...)
⑩ 仅当 cert_ok ∧ p_nov≥α_nov：用 EV-exec 更新场景/情感/新颖性模型；否则冻结学习
⑪ CBC 更新预算；Return (z_scene, K_safe, e_aff, r, s_nov, EV-exec, cert_status)
```
**二阶接地单调性（SGM）**：对任意二阶算子 O ∈ {O_aff, O_nov, O_cert}，其作用满足
O: (K_safe, A_allowed) ↦ (K_safe′, A_allowed′)，且 K_safe′ ⊆ K_safe，A_allowed′ ⊆ A_allowed。
即**所有元证据只做保守精化（conservative refinement），绝不做风险提升**。这是本轮的安全公理：二阶信号可以「否决」，不能「授权」。

**定义 167（竞赛时钟 CBC）** 元动作集 A_meta = {EXPLORE, EXPLOIT, ASK, FALLBACK}，剩余时间 T_rem，分数在险值 SAR，风险预算 S_max，时间储备 T_reserve。元决策：
```
VOI_comp(a) = P(success|a)·ΔScore(a) − E[loss|a] − λ_t·Cost_time(a)
```
硬约束优先于收益：
- T_rem < T_reserve ⇒ FALLBACK；
- SAR > S_max ⇒ FALLBACK；
- ¬cert_ok ∧ a=EXPLORE ⇒ ASK（先要监督，不擅自探索）；
- 仅当 VOI_comp(EXPLORE) > 0 且风险预算允许时选择 EXPLORE。

**定义 168（六维预算 PCE++++++）** B_cog = (B_scene, B_intent, B_aff, B_ros, B_transfer, B_exec)，其中
- B_aff = (Affect_ops, Calibration_rate, Contradiction_check_budget)；
- B_transfer = (Novelty_ops, Cert_audit_budget, Hidden_layer_budget)；
- cost_meta = λ_aff·Affect_cost + λ_nov·Novelty_cost + λ_cert·Cert_cost。
耗尽策略：B_aff 耗尽 ⇒ 令 r=0.5、u_aff=1，走最保守包络；B_transfer 耗尽 ⇒ 关闭 EXPLORE、证书一律视为未验证、仅用 a≤1；B_scene/B_intent/B_ros/B_exec 沿用第 60 轮降级规则。

## 2. 关键算法伪代码

### IP-161 AME（情感元证据）

```python
class AffectMetaEvidence:
    def __init__(self, model, temperature=1.0):
        self.model = model
        self.T = temperature

    def infer(self, prosody, asr_nbest):
        x = self._featurize(prosody, asr_nbest)
        logits = self.model(x) / self.T
        q = softmax(logits)                    # q(E | x_aff)
        E = expectation(q)
        u_aff = entropy(q) / math.log(len(q))  # normalized
        return AffectState(E=E, u_aff=u_aff)
```

### IP-162 AIR（情感-意图可靠性）

```python
def affect_intent_reliability(q_intent, E, u_aff, history, cfg):
    mu, Sigma = cfg.affect_kernel[q_intent.argmax]
    D_ai = mahalanobis(E, mu, Sigma)
    r = sigmoid(cfg.a0 + cfg.a1*math.log(q_intent.max())
                + cfg.a2*E.certainty + cfg.a3*(cfg.tau_c - D_ai)
                + cfg.a4*history.consistency)
    escalate = (D_ai > cfg.tau_c) or (u_aff > cfg.tau_u) or (r < cfg.tau_r)
    return IntentDecision(C_intent=cfg.map_intent(q_intent),
                          r=r, escalate=escalate, D_ai=D_ai)
```

### IP-163 STE（监督信任包络）

```python
def trust_envelope(r, u_aff, s_nov, T_rem, cfg):
    if T_rem < cfg.T_reserve:
        return Envelope(a=min(1, cfg.a_max), tau_ev=cfg.tau_ev_hi, g_confirm=1)
    a = cfg.a_max - int(math.ceil(cfg.l1*(1-r) + cfg.l2*u_aff + cfg.l3*s_nov))
    a = max(0, a)
    tau_ev = cfg.tau_ev_lo + cfg.k1*(1-r) + cfg.k2*u_aff + cfg.k3*s_nov
    g_confirm = int(a < cfg.a_min or (u_aff > cfg.tau_u))
    return Envelope(a=a, tau_ev=min(tau_ev, 1.0), g_confirm=g_confirm)
```

### IP-164 CGN（竞赛级新颖性）

```python
class ChallengeNovelty:
    def __init__(self, density_model, calib_scores, alpha_nov=0.05):
        self.density = density_model
        self.calib = np.sort(calib_scores)
        self.alpha = alpha_nov

    def score(self, phi):
        return -self.density.log_prob(phi)

    def p_value(self, phi):
        s = self.score(phi)
        return (1 + np.sum(self.calib >= s)) / (len(self.calib) + 1)

    def check(self, phi):
        s, p = self.score(phi), self.p_value(phi)
        return NoveltyResult(s=s, p=p, ood=(p < self.alpha))
```

### IP-165 CTC（竞赛迁移证书）

```python
def fit_transfer_certificate(skill, D_cal, alpha=0.1, delta=0.05):
    best = None
    for lam in skill.lambda_grid:
        risks = [loss(skill.policy(lam), task) for task in D_cal.tasks]
        r_hat = np.mean(risks)
        ucb = conformal_risk_ucb(r_hat, len(risks), delta)   # conservative
        if ucb <= alpha:
            best = lam
    if best is None:
        return Certificate.invalid(reason='no lambda meets conformal risk')
    layer_lcbs = {l: lcb([loss(skill.policy(best), t)
                          for t in D_cal.tasks_at(l)], delta) for l in D_cal.layers}
    return Certificate(skill=skill.id, lam=best, alpha=alpha, delta=delta,
                       lcb_min=min(layer_lcbs.values()), layer_lcbs=layer_lcbs,
                       sar=score_at_risk(layer_lcbs), version=D_cal.version)
```

### IP-166 MAGEC（二阶接地闭环）

```python
def mag_ec_loop(M, speech, T_rem):
    z, K_scene, _ = M.sgec.step(M.scene, M.telem)
    e_aff = M.ame.infer(speech.prosody, speech.nbest)
    d = affect_intent_reliability(speech.q_intent, e_aff.E, e_aff.u_aff,
                                  M.history, M.cfg)
    nov = M.cgn.check(M.fingerprint())
    cert_ok = M.ctc.check(M.skill, M.bench_version, nov.s)
    env = trust_envelope(d.r, e_aff.u_aff, nov.s, T_rem, M.cfg)

    if nov.ood or not cert_ok:
        K_safe = M.eeis.compile_conservative(M.delta_f, M.fused, M.Z_env)
    else:
        K_safe = M.eeis.intersect(K_scene, M.affine_tighten(d, env))

    if env.g_confirm and M.action.irreversible:
        return M, RequestConfirmation(K_safe, d, nov)

    M = execute(M, K_safe, autonomy=env.a)
    ev = build_exec_evidence(M.telemetry, K_safe, env)
    if cert_ok and not nov.ood:
        M = update_models(M, ev, e_aff, d)
    M = M.cbc.update(T_rem, nov, cert_ok, ev)
    return M, ev
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| AME | O(d_aff) / 帧 | O(d_aff) | 情感估计 ECE ≤ 0.05，u_aff 单调反映误差 |
| AIR | O(1) | O(1) | 矛盾检出一等安全事件；约束只收紧 |
| STE | O(1) | O(1) | 对 (r↑, u_aff↓, s_nov↓) 单调不保守劣化 |
| CGN | O(d_φ) 在线；O(n) 共形 | O(n) 校准集 | OOD 判定的共形误报率 ≤ α_nov |
| CTC | O(|λ|·n) 离线 | O(n) | 隐藏族风险 ≤ α（置信 1−δ），撤销即降级 |
| CBC | O(1) | O(1) | 硬约束优先，超时/险值越界必回退 |

**正确性定理（MAGEC）**
假设 A66–A70 成立：
**(A66)** AME 已标定：|P(E∈·|x) − q_φ(·|x)|_TV ≤ ε_aff，且 u_aff 单调于真实误差；
**(A67)** AIR 矛盾检测漏报率 P(D_ai≤τ_c, u_aff≤τ_u | 实际冲突) ≤ δ_air；
**(A68)** CGN 校准集与在线指纹在已知分布内可交换，故 P(p_nov<α_nov | 已知) ≤ α_nov；
**(A69)** CTC 的共形风险上界在隐藏任务族上成立，且最差层 LCB 为保守估计；
**(A70)** STE 与 CBC 均满足单调性与硬约束优先（SGM），且评分损失有界 L∈[0,1]。

则：
1. **情感误纳风险界**：P(接受不安全指令) ≤ δ_air + ε_aff + P(r<τ_r | 安全指令)（后者即误保守率，由实验 E193 约束）；
2. **OOD 过度自信界**：在已知分布上，OOD 误报率 ≤ α_nov；在 OOD 上，由于先验协方差膨胀与自主性下调，K_safe 的可行域只减不增（SGM）；
3. **迁移风险界**：任一通过 CTC 的技能，其隐藏任务族风险 ≤ α，且若 revoke_pred 为真则强制 a≤1；
4. **竞赛安全界**：若 T_rem<T_reserve 或 SAR>S_max，CBC 必选 FALLBACK，故不会以不可逆代价继续探索；
5. **二阶不增风险**：所有元算子满足 SGM，故「加入情感/新颖性/证书」不会使任一执行步骤的 K_safe 变大或自主等级变高——只会更保守。

### IP-161 AME（情感元证据）

```python
class AffectMetaEvidence:
    def __init__(self, model, temperature=1.0):
        self.model = model
        self.T = temperature

    def _featurize(self, prosody, asr_nbest):
        return np.array([
            prosody.f0_mean, prosody.f0_slope, prosody.f0_range,
            prosody.f0_jitter, prosody.energy_mean, prosody.energy_slope,
            prosody.shimmer, prosody.hnr, prosody.speech_rate,
            prosody.pause_ratio, asr_nbest.entropy,
        ])

    def infer(self, prosody, asr_nbest):
        x = self._featurize(prosody, asr_nbest)
        q = softmax(self.model(x) / self.T)          # q(E | x_aff)
        E = expectation(q)
        u_aff = entropy(q) / math.log(q.shape[0])    # normalized [0,1]
        return AffectState(E=E, u_aff=u_aff, q=q)
```

### IP-162 AIR（情感-意图可靠性）

```python
def affect_intent_reliability(q_intent, E, u_aff, history, cfg):
    mu, Sigma = cfg.affect_kernel[q_intent.argmax]
    D_ai = mahalanobis(E, mu, Sigma)
    r = sigmoid(cfg.a0 + cfg.a1 * math.log(q_intent.max())
                + cfg.a2 * E.certainty + cfg.a3 * (cfg.tau_c - D_ai)
                + cfg.a4 * history.consistency)
    escalate = (D_ai > cfg.tau_c) or (u_aff > cfg.tau_u) or (r < cfg.tau_r)
    return IntentDecision(C_intent=cfg.map_intent(q_intent),
                          r=r, escalate=escalate, D_ai=D_ai)

def affine_tighten(K_safe, decision):
    if not decision.escalate:
        return K_safe
    v_cap = K_safe.v_max * (0.5 + 0.5 * decision.r)
    kd_floor = K_safe.k_d * (1.0 + (1.0 - decision.r))
    return intersect(K_safe, Box(v_max=v_cap, k_d=kd_floor))   # 只收紧
```

### IP-163 STE（监督信任包络）

```python
def trust_envelope(r, u_aff, s_nov, T_rem, cfg):
    if T_rem < cfg.T_reserve:
        return Envelope(a=min(1, cfg.a_max), tau_ev=cfg.tau_ev_hi, g_confirm=1)
    a = cfg.a_max - int(math.ceil(cfg.l1 * (1 - r)
                                  + cfg.l2 * u_aff
                                  + cfg.l3 * s_nov))
    a = max(0, a)
    tau_ev = cfg.tau_ev_lo + cfg.k1 * (1 - r) + cfg.k2 * u_aff + cfg.k3 * s_nov
    g_confirm = int(a < cfg.a_min or u_aff > cfg.tau_u)
    return Envelope(a=a, tau_ev=min(tau_ev, 1.0), g_confirm=g_confirm)
```

### IP-164 CGN（竞赛级新颖性）

```python
class ChallengeNovelty:
    def __init__(self, density_model, calib_scores, alpha_nov=0.05):
        self.density = density_model
        self.calib = np.sort(np.asarray(calib_scores))
        self.alpha = alpha_nov

    def score(self, phi):
        return -self.density.log_prob(phi)

    def p_value(self, phi):
        s = self.score(phi)
        return (1 + np.sum(self.calib >= s)) / (len(self.calib) + 1)

    def check(self, phi):
        s = self.score(phi)
        p = self.p_value(phi)
        return NoveltyResult(s=s, p=p, ood=(p < self.alpha))
```

```python
def fit_transfer_certificate(skill, D_cal, alpha=0.1, delta=0.05):

    for lam in skill.lambda_grid:
```

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| AME | O(d_aff) / 帧 | O(d_aff) | 标定后 ECE ≤ 0.05；u_aff 单调于误差 |
| AIR | O(1) | O(1) | 矛盾检出一等安全事件；约束只收紧 |
| STE | O(1) | O(1) | 对 (r↑, u_aff↓, s_nov↓) 单调；硬约束优先 |
| CGN | O(d_φ) 在线 / O(n) 共形 | O(n) | 已知分布上 OOD 误报率 ≤ α_nov |
| CTC | O(|λ|·n) 离线 | O(n) | 隐藏族风险 ≤ α（置信 1−δ）；撤销即降级 |
| MAGEC | O(闭环) | 复用 | SGM：元算子只保守精化 |
| CBC | O(1) | O(1) | 超时/险值越界必 FALLBACK |

**正确性定理（MAGEC）**
若 A66–A70 成立：
**(A66)** AME 标定误差 ≤ ε_aff，u_aff 单调于真实误差；
**(A67)** AIR 对真实情感-意图冲突的漏报率 ≤ δ_air；
**(A68)** CGN 已知分布内校准集与在线指纹可交换，共形 p 值有效；
**(A69)** CTC 的共形风险上界在隐藏任务/本体族上成立，最差层 LCB 保守；
**(A70)** STE/CBC 满足 SGM 与硬约束优先，评分损失 L∈[0,1]。
则：

1. **情感误纳界**：P(接受不安全指令) ≤ δ_air + ε_aff + P(误保守 | 安全指令)；
2. **OOD 防过度自信**：已知分布上 P(p_nov<α_nov) ≤ α_nov；OOD 时 K_safe 可行域与自主等级只减不增（SGM）；
3. **迁移风险界**：通过 CTC 的技能，隐藏族风险 ≤ α；revoke_pred 为真时强制 a≤1；
4. **竞赛安全界**：T_rem<T_reserve 或 SAR>S_max ⇒ 必 FALLBACK，不以不可逆代价探索；
5. **二阶不增风险**：加入 AME/CGN/CTC 后，任一执行的 K_safe 与自主等级均不高于无元证据时。

**推导（命题 1 的展开）**：设 A=接受不安全指令，C=情感-意图真实冲突，M=冲突被漏检，F=情感估计失真。则
P(A) = P(A|M,F)P(M,F) + P(A|¬(M,F))P(¬(M,F))
     ≤ P(M) + P(F) + P(A|¬M,¬F)
     ≤ δ_air + ε_aff + P(r<τ_r | 安全指令)。
最后一项是「误保守率」，它由 STE 的 τ_r 与实验 E193 控制；这一项**不是安全代价，而是可用性代价**，因此可被显式预算化，而不是被隐藏。

**命题 2（单调性引理）**：若 O_aff 由定义 162 的 K_safe^aff 给出，O_nov 由定义 164 的协方差膨胀与 a 下调给出，O_cert 由定义 165 的 a≤1 给出，则对任意初始 (K_safe, A_allowed)，有 O(K_safe, A_allowed) ⊆ (K_safe, A_allowed)（逐分量集合包含）。证明：三者均只做交集、膨胀（使可行域收缩）、取小或置上限，无任何扩张/放行操作，故成立。

**统计与复现**：所有指标报告 95% bootstrap 置信区间；隐藏族按任务/本体/难度三层划分；CTC 的校准集与测试集用版本哈希隔离；情感数据区分「表演语料（IEMOCAP/CREMA-D）」与「自然操作语料（自采）」以检验域差。

## 6. 本轮最大风险

**一句话**：最大风险是「情感误读」与「新颖性漏检」的共振——把操作者的恐惧/犹豫读成平静自信、同时把隐藏任务族判成熟知分布，系统就会在错误的信任包络里以高自主等级执行，而竞赛中一次不可逆的灾难性失败即可清零；因此必须用「情感-意图矛盾即升级」「OOD 即先验膨胀+降自主」「证书撤销即 a≤1」「SGM 只收紧不放松」四道硬护栏，把二阶证据的不确定性挡在决策闭环之外。
