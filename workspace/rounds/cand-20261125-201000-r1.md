## 0. 直觉与动机

### 灵感 1（推理延迟 → 证书的第一等公民是"时间"，而非"精度"）

**直觉**：v23 反复声称关键路径 O(1)、满足 50Hz，但它把"推理到底花了多久"当成一个被隐藏的常数。真实系统里，DNN 前向、conformal 分位数查询、联邦共识、云边切换都可能吃掉几十到几百毫秒；而在这段时间里，人和机器人都**动了**。一张"感知时刻"正确、却在"执行时刻"过期的证书，和没有证书一样危险，甚至更危险——因为它看起来合法。核心创新：**时序有效证书 (Temporal Validity Certificate, TVC)** 与 **任意时刻可证 (Anytime Certification, AC)**。

**反直觉点 1**：延迟的代价不一定表现为"更不安全"，而可被**确定性膨胀**吸收——只要膨胀对时间单调不减、且证书有硬有效期。于是"变慢"自动等价于"更保守"，安全方向不变。
**反直觉点 2**：把推理组织成一条**认证阶梯 (Certification Ladder)**，第 0 级用最小模型给出最粗但立刻可用的包围盒，逐级用更多算力收紧；**子集守卫**保证 `CertBox_{ℓ+1} ⊆ CertBox_ℓ`，于是 `Exec_0 ⊆ Exec_1 ⊆ … ⊆ Exec_L ⊆ Exec_{v23 理想}`。任意时刻被打断就交出"最高已完成级"——安全永不下降，只损失活性。

**严谨定义（时域膨胀）**：设证书在感知时刻 `t_s` 签发、在 `t_u ≥ t_s` 使用，工作域内最大相对速度 `v_rel^max`、最大相对加速度 `a_max`，则

`ε_temp(Δt) = v_rel^max · Δt + ½ · a_max · Δt²`,  `Δt = t_u - t_s`,

`CertBox_k(t_u) = b_k ⊕ Ball( ε_loc(s_k) + ε_temp(Δt) + ε_dyn )`,

有效期 `τ_v(s) ≜ sup{Δt : ε_loc(s) + ε_temp(Δt) ≤ ε_budget ∧ 遮挡/可见性假设未变}`。证书在执行时刻**有效**当且仅当 `t_u - t_s ≤ τ_v`。所有碰撞检查一律用膨胀后的 `CertBox_k(t_u)`，绝不用 `t_s` 时刻的瞬时框。

### 灵感 2（UniBot世界挑战赛 → 证书必须可跨具身、可被第三方复核）

**直觉**："世界挑战赛"意味着两件 v23 没有认真对待的事：(a) **具身不同**——不同底盘、传感器、算力、延迟、动力学的机器人要在同一片场地协作/竞争；(b) **裁判与对手不信任你的内部状态**——证书必须能离开本机、在陌生硬件上重放、被第三方机械复核。核心创新：**具身相对证书重基 (Embodiment-Relative Certificate Rebase, ERCR)** 与 **竞赛级外审计追踪 (Competition-Grade Audit Trace, CGAT)**。

**反直觉点 3**：重基不是"拷贝"，而是**只增不减的保守化**。把 A 的世界系几何搬到 B，必须叠加 B 的定位误差、重基误差、跨机通信延迟与时钟偏斜；A 的证书在 B 上要么不成立（拒用），要么成立且其执行集 ⊆ B 本地证书的执行集。
**反直觉点 4**："通用机器人"的可移植性不是让证书在所有机器上等价成立，而是证明**越搬越保守**。多机联邦因此不再是"互相相信"，而是"互相只能收紧"。
**反直觉点 5**：挑战赛的隐藏测试集天然 OOD，正好充当 conformal 覆盖的**外部对抗分布**；排行榜把"安全违规率、P99 延迟、能耗"与"任务得分"并列，等价于要求 **safety–latency–score 三目标在硬约束下联合优化**，而非先刷分再补安全。

**严谨定义（具身重基）**：证书 `C_A = (G_world, U_A, t_A, τ_A, P_A)`，其中 `G_world` 为世界系几何、`U_A` 为 A 的不确定半径、`P_A` 为（传感器模型、延迟、时钟、签名）溯源。重基到 B：

`U_B(A→B) = U_A ⊕ ε_loc,B ⊕ ε_rebase ⊕ ε_transport ⊕ v_rel^max·(t_u - t_A) ⊕ v_rel^max·δ_clock`,

`CertBox_B = G_world ⊕ Ball(U_B)`,  `P_B = sign_B( P_A ∥ U_B ∥ t_u )`。

定义 **RebaseSafe(A→B)** ≜ 坐标系约定一致 ∧ `δ_clock` 有界 ∧ B 的传感器模型 ∈ 支持的保守模型集 ∪ 可回退 ∧ `P_A` 验签通过。只有 `RebaseSafe` 成立，`CertBox_B` 才被允许进入 B 的 HPC 检查；否则拒用。

### 两者如何统一

TVC/AC 让证书沿**时间轴**保守，ERCR/CGAT 让证书沿**具身轴**保守；二者都是"单调扩大不确定集、单调收缩执行集"的同一代数操作，只是膨胀项不同（时间膨胀 vs 具身/传输膨胀）。统一为 **时空可移植证书层 (Spatio-Temporal Portable Certificate Layer, STPC)**：

`ζ_stpc = ζ_ce ∪ (ℓ_t, age, ε_temp, τ_v, T_deadline, U_transport, δ_clock, portability_proof, audit_root)`。

统一准入门升级为 **HPC-E++**：`Exec_v24 = Exec_v23 ∩ Fil_temporal ∩ Fil_deadline ∩ Fil_portable ⊆ Exec_v23`。共识升级为 **截止期感知共识 CFC++++**：只对**同一有效期窗口内**的票计入法定人数，过期票一律作废——把"陈旧的一致"从根上排除。

## 1. 研究问题（在 Q1–Q11 基础上升级）

- **Q12（时间轴的可证性）**：如何在给定 `v_rel^max, a_max` 的保守界下选择 `ε_temp(Δt)` 与硬有效期 `τ_v`，使"时域膨胀后的包围盒以 ≥1-δ 概率含真物"？认证阶梯的**子集守卫**（`CertBox_{ℓ+1} ⊆ CertBox_ℓ`）在什么条件下可机械验证，而不退化为"只在尺度不变子集上收紧"的特例？被打断时"最高已完成级"是否永远是安全下界？

- **Q13（延迟条件化覆盖的最大隐患）**：认证阶梯的**选级规则由运行时延迟触发**，而延迟与场景难度强相关（难场景更慢）。这是一个**数据相关的选择偏置**：系统恰好在最难的场景上回落到最保守、但其校准集并非该场景分布的层级，从而破坏 conformal 的交换性。如何在"按级条件校准 + 难场景分层留出 + 在线 ACI 反馈"之间取得可证明的覆盖，而不堕入"延迟触发的覆盖穿孔"？

- **Q14（具身轴的可移植性代数）**：`RebaseSafe` 的坐标/时钟/传感器模型三条件的充分性边界是什么？多跳重基 `A→B→C` 的不确定度如何组合才不产生"可移植性洗白"（每跳各加一点 ε，累加却被夹断）？如何用签名溯源链与累计不确定度账本给出"越搬越保守"的归纳证明？

- **Q15（竞赛级外审计与双目标）**：证书轨迹的标准序列化（时间戳、传感器哈希、版本五元组、决策、merkle 根、签名）如何做到**第三方确定性重放**？在 UniBot 隐藏测试集与排行榜下，如何把"安全违规率 ≈ 0、P99 延迟 ≤ 控制周期、能耗有界"设为硬约束，并让任务得分成为其上的优化目标，而非相反？

## 2. 设计原则（在 P34–P42 基础上新增 P43–P46）

**P43 时间即不确定律（Time-as-Uncertainty）**
任何证书都携带 `(t_s, Δ_c, τ_v, ε_temp)`。碰撞检查在**执行时刻** `t_u` 用 `CertBox(t_u) = b ⊕ Ball(ε_loc + ε_temp(t_u - t_s) + ε_dyn)`；`ε_temp` 对 `Δt` 单调不减且凸（`v_rel^max, a_max > 0`）。超过 `τ_v` 的证书**一律作废**，不得被"续命"，只能重签或回退。故 `Exec_temporal(t) ⊆ Exec_v23` 且随 `age` 单调收缩。

**P44 任意可证 / 子集守卫律（Anytime Subset-Guarded Refinement）**
认证阶梯 `ℓ = 0..L`，每级独立 conformal 校准得到 `(ε_ℓ, Γ_ℓ)`；**仅当**几何上验证 `CertBox_{ℓ+1} ⊆ CertBox_ℓ` 才允许从 `ℓ` 晋升到 `ℓ+1`（子集守卫）；否则钳制回 `ℓ`。任意截止期 `T_deadline` 触发时，输出"最高已完成且通过守卫"的级。故 `Exec_0 ⊆ Exec_1 ⊆ … ⊆ Exec_L ⊆ Exec_v23`；中断只损失活性，不损害安全。

**P45 截止期法定人数律（Deadline Quorum）**
每张票携带 `(claim, t_i, modality, prov)`。法定人数只统计**同一有效期窗口**内的票：`Q(t, τ_vote) = {v_i : t - t_i ≤ τ_vote ∧ prov 有效}`。共识要求在控制截止 `T_ctrl - ε_reserve` 前完成；超时则取"最后已提交且在窗口内的共识"，仍超窗则判 `CI`（不足/冲突）。过期票不得与新鲜票混合计数——"陈旧的一致"不是一致。

**P46 可移植只增保守律（Portability Monotone Conservatism）**
重基 `A→B` 只允许**加性膨胀**：`U_B(A→B) = U_A ⊕ ε_loc,B ⊕ ε_rebase ⊕ ε_transport ⊕ v_rel^max(t_u - t_A + δ_clock)`，且 `U_B(A→B) ≥ U_A`。多跳重基用累计账本 `U_acc`，任一跳只增不减；签名溯源链把每一跳的输入输出与增量钉死，禁止"洗白"。仅 `RebaseSafe` 成立时可进入 HPC；故 `Exec_B(transported) ⊆ Exec_B(local)`，且 `Exec_v24 ⊆ Exec_v23`。

## 3. 与基线的接口（如何退化）

- TVC 过期 ⇒ 计划被 `Fil_temporal` 拒绝 ⇒ 停住/回退保守动作 ⇒ 子集；
- 认证阶梯只完成第 0 级（超时）⇒ 最粗包围盒 ⇒ 最保守但安全 ⇒ 子集；
- 子集守卫失败（细级框未能证明被粗级包含）⇒ 钳制回粗级 ⇒ 子集；
- DAC 超时 ⇒ 取最后已提交共识或 `CI` ⇒ 比 v23 的即时共识更保守 ⇒ 子集；
- ERCR 失败（时钟无界/坐标系未知/验签失败）⇒ 拒绝外来证书、只用本机证书 ⇒ 子集；
- CGAT 审计不可用 ⇒ 本地仍记录，但竞赛模式拒绝入榜 ⇒ 子集（无外部准入）；
- 全部失效 ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`。

## 1. 关键算法骨架（在 IP-436–439 骨架上扩展）

# ============================================================
@dataclass
class TemporalValidityCertificate:
    t_s: float
    compute_latency: float          # Δ_c
    epsilon_loc: float
    epsilon_budget: float
    v_rel_max: float
    a_max: float
    base_box: Box                  # b_k
    visible_assumption: Hash       # 可见性/遮挡假设指纹

    def epsilon_temp(self, dt: float) -> float:
        """时域膨胀：单调不减且凸"""
        return self.v_rel_max * dt + 0.5 * self.a_max * dt * dt

    def tau_v(self) -> float:
        """有效期上界：解析求解 epsilon_loc + epsilon_temp(Δt) ≤ epsilon_budget"""
        # 0.5*a*Δt² + v*Δt - (budget - loc) = 0
        rem = self.epsilon_budget - self.epsilon_loc
        if rem <= 0:
            return 0.0
        a, v = 0.5 * self.a_max, self.v_rel_max
        return (-v + math.sqrt(v * v + 4 * a * rem)) / (2 * a)

    def box_at(self, t_u: float, visibility_now: Hash) -> Optional[Box]:
        dt = t_u - self.t_s
        if dt < 0 or dt > self.tau_v() or visibility_now != self.visible_assumption:
            return None                      # 过期或可见性假设失效 → 作废
        eps = self.epsilon_loc + self.epsilon_temp(dt) + self.epsilon_dyn
        return self.base_box.inflate(eps)


# ============================================================
# IP-441 Anytime Certification Ladder (ACL) — 任意可证认证阶梯
# ============================================================
class AnytimeCertifier:
    def __init__(self, levels: list['Level'], subset_guard: bool = True):
        self.levels = levels            # 按 c_ℓ 递增排序
        self.subset_guard = subset_guard
        self._committed_level = 0

    def certify(self, obs, t_s: float, deadline: float) -> tuple[int, TVC]:
        """在截止期内尽量爬到更高级；失败/中断时返回最高合法已完成级"""
        best = 0
        best_cert = self.levels[0].build(obs, t_s)    # 第 0 级永远立即可用
        for ell in range(1, len(self.levels)):
            if time.now() + self.levels[ell].est_cost > deadline:
                break                                 # 算力预算耗尽 → 就地停止
            cand = self.levels[ell].build(obs, t_s)
            if self.subset_guard and not certbox_subset(cand.base_box,
                                                        best_cert.base_box):
                continue                               # 子集守卫失败 → 不允许晋升
            best, best_cert = ell, cand
        # 迟滞：避免控制周期内反复横跳
        self._committed_level = self._hysteresis(best, self._committed_level)
        return self._committed_level, best_cert

    def _hysteresis(self, new: int, old: int, dwell: int = 3) -> int:
        # 降级立即生效（保安全），升级需连续 dwell 个周期满足
        return new if new < old else (new if new - old >= 1 and self._stable else old)


# ============================================================
# IP-442 Embodiment-Relative Certificate Rebase (ERCR)
# ============================================================
@dataclass
class PortableCertificate:
    G_world: Geometry
    U: float
    t_A: float
    tau_A: float
    provenance: Provenance          # sensor/latency/clock/signature 溯源
    U_acc: float                    # 多跳累计账本

class EmbodimentRebaser:
    def __init__(self, supported_sensors: set[str], delta_clock: float,
                 eps_rebase: float, eps_transport: float):
        self.supported = supported_sensors
        self.delta_clock = delta_clock
        self.eps_rebase = eps_rebase
        self.eps_transport = eps_transport

    def rebase_safe(self, C_A: PortableCertificate, B: 'Embodiment',
                    pk_chain) -> bool:
        return (
            verify_chain(pk_chain, C_A.provenance)              # 验签
            and time_sync_bound(B, C_A.provenance) <= self.delta_clock
            and C_A.provenance.frame_convention == B.frame_convention
            and (B.sensor_model in self.supported
                 or B.has_conservative_fallback)
        )

    def rebase(self, C_A: PortableCertificate, B: 'Embodiment', t_u: float,
               pk_chain) -> Optional[PortableCertificate]:
        if not self.rebase_safe(C_A, B, pk_chain):
            return None                                    # 拒用，绝非静默降级
        U_B = (C_A.U + B.epsilon_loc + self.eps_rebase + self.eps_transport
               + B.v_rel_max * (t_u - C_A.t_A + self.delta_clock))
        if U_B < C_A.U or U_B < C_A.U_acc:
            return None                                    # 违反只增保守 → 拒用
        return PortableCertificate(
            G_world=C_A.G_world, U=U_B, t_A=C_A.t_A, tau_A=C_A.tau_A,
            provenance=C_A.provenance.extend(B, U_B, t_u),
            U_acc=max(C_A.U_acc, U_B),
        )


# ============================================================
# IP-444 Deadline-Aware Consensus (DAC / CFC++++) — 截止期法定人数
# ============================================================
class DeadlineAwareConsensus:
    def __init__(self, N, F, m_min, tau_vote, eps_reserve):
        self.N, self.F = N, F
        self.m_min, self.tau_vote = m_min, tau_vote
        self.eps_reserve = eps_reserve
        self.last_committed = None

    def temporal_quorum(self, votes, now):
        return {k: v for k, v in votes.items()
                if now - v.t_i <= self.tau_vote and v.prov is not None}

    def consensus_round(self, votes, now, t_ctrl):
        deadline = t_ctrl - self.eps_reserve
        Q = self.temporal_quorum(votes, now)
        by_key = group_by_claim(Q)
        results = {}
        for key, vs in by_key.items():
            modalities = {v.modality for v in vs.values()}
            ok = (len(vs) >= self.N - self.F
                  and len(modalities) >= self.m_min
                  and self._layer_and_sync_ok(vs))
            if ok and time.now() <= deadline:
                results[key] = self._majority_with_outlier_filter(vs)
            else:
                results[key] = "CI"
        if any(r != "CI" for r in results.values()):
            self.last_committed = results
            return results
        # 超时/不足：退回最后已提交且在窗口内的共识，否则 CI
        if self.last_committed is not None:
            return {k: v for k, v in self.last_committed.items()
                    if k in results and results[k] == "CI"}
        return results

@dataclass
class AuditTrace:
    t: float
    sensor_hash: Hash
    version: VersionTuple          # v23 的五元组
    cert_roots: list[Hash]         # 本周期所有证书的根
    decision: str

    energy: float

def AuditVerify(Tx_chain, pk_robot, task_ctx) -> bool:
    """第三方重放：只依赖公开输入 + 签名，不信任内部状态"""
    for tx in Tx_chain:
        if not verify_signature(pk_robot, tx.root, tx.sig):
            return False
        if tx.root != H(tx.prev_root, tx.t, tx.sensor_hash, tx.version,
                        tx.cert_roots, tx.decision, tx.rung, tx.energy):
            return False
        # 用公开 task_ctx 与 cert_roots 重放 HPC 判定
        if not replay_hpc(tx, task_ctx):
            return False
    return True

# IP-445 HPC-E++ 统一五证准入门
# ============================================================
@dataclass
class HPCEPlusPlus:
    hpc_e_plus: 'HPCEPlus'
    temporal: AnytimeCertifier
    rebaser: EmbodimentRebaser
    audit: 'AuditRecorder'

    def admits(self, plan, x, v, z, E_res, margin_req, modules,
               t_s, t_u, visibility_now, foreign_certs=()) -> bool:
        # 1. v23 四证（云边/少样本/IP/物理接地）
        if not self.hpc_e_plus.admits(plan, x, v, z, E_res, margin_req, modules):
            return False
        # 2. 时序有效：在当前时刻用膨胀框重新做碰撞检查
        rung, cert = self.temporal.certify(x, t_s, t_u)
        if cert.box_at(t_u, visibility_now) is None:
            return False                                   # 过期/可见性失效
        # 3. 可移植：外来证书必须 RebaseSafe 且只增保守
        for C in foreign_certs:
            if not self.rebaser.rebase_safe(C, self.rebaser.target, C.provenance.pk):
                return False
            if self.rebaser.rebase(C, self.rebaser.target, t_u, C.provenance.pk) is None:
                return False
        # 4. 外审计：本周期决策已入链且可重放
        if not self.audit.append(t_u, x, v, rung, plan, E_res):
            return False
        return True

class SpatioTemporalPortablePipeline(PerceptionComplianceEnergyPipeline):
    def step(self, sensor_data, cloud_update=None, foreign_certs=()):
        t_s = time.now()
        admitted, info = super().step(sensor_data, cloud_update)
        # v23 的准入被 HPC-E++ 重新包裹：
        info['rung'], info['age'] = self.hpc_e_plus.temporal._committed_level, 0.0
        info['portable_ok'] = all(
            self.hpc_e_plus.rebaser.rebase_safe(C, self.hpc_e_plus.rebaser.target,
                                                C.provenance.pk)
            for C in foreign_certs)
        info['audit_root'] = self.hpc_e_plus.audit.last_root
        return admitted, info

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| TVC 构造 + 到期判定 | O(1)（解析解 `τ_v`、一次膨胀） | O(1) | `v_rel^max, a_max, ε_budget` |

## 3. 正确性论证

### 引理 5（时域膨胀的单调保守性）
**陈述**：若 `v_rel^max ≥ 0, a_max ≥ 0`，则对 `t_u2 ≥ t_u1 ≥ t_s` 有 `CertBox(t_u2) ⊇ CertBox(t_u1)`；且对任意 `t_u`，`CertBox(t_u) ⊇ CertBox(t_s)`。故 `Exec_temporal(t_u2) ⊆ Exec_temporal(t_u1) ⊆ Exec_v23`。

**证明**：`ε_temp(Δt) = v_rel^max Δt + ½ a_max Δt²` 在 `Δt ≥ 0` 上非负、单调不减；膨胀半径为 `ε_loc + ε_temp + ε_dyn`，对 `Δt` 单调不减；同中心膨胀半径越大则盒越大。碰撞检查用更大的盒 ⇒ 可行的计划集单调收缩。`t_s` 处 `ε_temp=0`，故 `CertBox(t_u) ⊇ CertBox(t_s)`，即时域层相对 v23 的零延迟理想只会收缩执行集。∎

### 引理 6（任意可证与子集守卫嵌套）
**陈述**：在子集守卫下 `Exec_0 ⊆ Exec_1 ⊆ … ⊆ Exec_L ⊆ Exec_v23`；任意中断时刻返回的最高已完成级 `ℓ*` 给出的证书在该时刻有效，且 `Exec_{ℓ*} ⊆ Exec_v23`。

**证明**：守卫保证 `CertBox_{ℓ+1} ⊆ CertBox_ℓ`，即细级障碍区域不超过粗级，故在细级下可通过 HPC 的计划必在粗级下也可通过（粗级盒更大或相等，只会更保守），于是 `Exec_ℓ ⊆ Exec_{ℓ+1}`。第 0 级恒可用且 `Exec_0 ⊆ Exec_v23`（叠加时域膨胀）。中断只影响能爬到多高级，不影响已得级的有效性（该级证书在签发时刻 `t_s` 满足 conformal 覆盖，且 `t_u - t_s ≤ τ_v` 时经引理 5 仍有效）。∎

### 引理 7（具身重基只增保守，且多跳不洗白）
**陈述**：若 `RebaseSafe(A→B)` 成立，则 `U_B(A→B) ≥ U_A` 且 `Exec_B(transported) ⊆ Exec_B(local)`；多跳 `A→B→C` 满足 `U_acc` 单调不减，且若任一跳 `RebaseSafe` 失败则拒绝，不产生"越搬越小"。

**证明**：`U_B(A→B) = U_A + (ε_loc,B + ε_rebase + ε_transport + v_rel^max(t_u - t_A + δ_clock))`，各增量非负，故 `U_B ≥ U_A`。`rebase` 显式检查 `U_B ≥ U_A` 且 `U_B ≥ U_acc`，否则拒用。B 的 HPC 用半径为 `U_B ≥ U_A` 的盒，故在 B 上可行的计划必在"以 A 证书直接解释"时可行 ⇒ `Exec_B(transported) ⊆ Exec_B(local)`。多跳时 `U_acc ← max(U_acc, U_B)`，单调不减；每跳都需 `RebaseSafe`，任一失败即 `None`（拒用）。∎

### 引理 8（截止期法定人数排除陈旧一致）
**陈述**：`DAC` 的共识只依赖 `Q(t, τ_vote)` 内的票；任何 `age > τ_vote` 的票不改变结果。若在 `T_deadline` 前无法达成，结果退化为"最后已提交且在窗口内的共识"或 `CI`，且其执行集 ⊆ 若无延迟约束时的即时共识执行集。

**证明**：`temporal_quorum` 先按 `age ≤ τ_vote` 过滤，过期票从计数与模态集合中彻底移除，故不会与新鲜票混合形成伪多数。超时分支不引入新断言，只复用此前已通过检查的共识（其票当时在窗口内），或返回 `CI`（最保守）。两种退化都不放宽几何/规范/能量约束，故为子集。∎

### 定理（HPC-E++ 的时空可移植安全完备性）
**陈述**：对任意计划 `π`，`HPCEPlusPlus.admits(π) = True` ⟺ `π` 同时满足：(1) v23 四证（物理接地安全 ∧ 云边一致 ∧ 少样本覆盖 ∧ IP 认证）；(2) 在当前执行时刻按 `ε_temp` 膨胀后仍安全且证书未过期；(3) 所有外来证书均 `RebaseSafe` 且只增保守；(4) 本周期决策已入审计链且可被第三方重放。并且对所有失效/退化情形，`Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`。

**证明**：必要性由 `admits` 的四个连言分支直接给出（任一为假即拒证）。充分性：(1) 由 v23 定理；(2) 由引理 5–6；(3) 由引理 7；(4) 由 `AuditVerify` 的签名与 merkle 根一致性。单调链：时域层只膨胀（引理 5）、阶梯只嵌套（引理 6）、重基只增保守（引理 7）、共识只排除陈旧票（引理 8），各层均为"加约束/交过滤"，故任意单点或组合失效只能向更保守方向退化。∎

## 6. 本轮最大风险（最终确认）

**一句话**：认证阶梯的选级规则由**运行时延迟**触发，而延迟与场景难度相关，于是选级本身构成**数据相关的选择偏置**——系统恰好在最难的场景上回落到一个"看起来最保守、实则校准集来自不同分布"的层级，conformal 交换性被悄悄破坏，形成"**延迟触发的覆盖穿孔**"：证书形式合格，却在最危险处事实失效。
