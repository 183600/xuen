# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因」IP-214~223；灵感循环第 3 轮；本轮灵感：「快速原型」×「四足机器人」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险很清楚：**VISTA 的归因依赖"故障属于有限假设集、且视觉与几何的失效相互独立"；真实故障常是未知类型的组合，透明/镜面/对抗 patch 又会让视觉与几何共享同一个分布外失效源，此时 FIR 会把未知复合故障强行归入最近假设、只膨胀错误的球，系统反而因为"已经归因"而更自信地继续执行。** 但第 65 轮还有两个从未被审计的隐含前提：**(a) 本体是固定的，故障模型可以离线标定；(b) 安全等于"不发生故障"，所以任何一次接触失败都只能靠更保守的证书去防。** 本轮换到「快速原型 × 四足机器人」的场景，恰好同时击穿这两个前提：每两周换一版本体，没有时间给每个原型做故障注入；而四足有四条腿、可以抬起来重放，安全第一次可以建立在"可恢复"而不是"不出错"上。本轮核心命题是：
>
> **把"一次性、单原型、离线标定的安全证书"升级为"随原型族增量迁移、由步态周期自校准、以接触可恢复性为安全边界"的活证书：用形态描述子把设计变更变成可计算的证书信用衰减，用步态周期把行走本身变成免费的故障激励，用三腿支撑与抬腿重放把单腿故障从"事故"降级为"可恢复事件"。**

## 0. 直觉与动机

**灵感 1（快速原型 → 证书应该像代码一样可增量迁移，而不是每次重训）**
直觉：快速原型的瓶颈从来不是"造出来"，而是"敢不敢让它跑"。每改一次腿长、质量分布或执行器，旧的安全证书就作废，而重新做故障注入 + 标定要几天，迭代速度立刻被打回原形。但工程上我们其实一直在"迁移信任"：把上一版的测试结论按改动幅度打折后继续用。本轮把这种直觉形式化：安全裕度对形态描述子的敏感度若有上界 L_ρ，则设计移动距离 d_ED 只让证书"贬值" L_ρ·d_ED，而不是直接归零；只有当贬值吃光信用 C 时才需要"再充值"（少量步态 + 定向探针）。**证书因此从一次性结论变成会衰减、可摊销的资产。** 关键诚实：这只在安全裕度对 ED 连续（Lipschitz）时成立，而在稳定性分岔/接触冲击边界附近它恰恰不成立——这是本轮的头号风险。

**灵感 2（四足机器人 → 步态周期是免费的、周期性的故障激励）**
直觉：VISTA 为了可辨识性，要人为插入零力窗和轻触阶段（null_test / fi_probe），因为机械臂一旦抓住就不再有"零载"时刻。四足恰好相反：每个步态周期天然包含 **swing（零载窗）→ touchdown（冲击）→ stance（承载）→ liftoff（卸载）**。也就是说，行走本身就在持续地激励所有故障通道：swing 暴露力/电流偏置，touchdown 暴露地形高度/刚度，stance 暴露摩擦/滑移与接触模型。**不需要专用故障注入，N 个步态周期就是 N 次受控实验**；Fisher 信息随周期线性累积，估计误差按 1/√N 下降。新原型走几十步就能达到 VISTA 离线标定的可辨识度——这正是快速原型最缺的东西。

**灵感 3（四足机器人 → 接触可恢复性：安全边界从"不滑"改为"能抬起来重放"）**
直觉：机械臂抓取失败往往不可逆（掉了、碎了）；四足的脚滑了却可以**抬起来、重新落**。更关键的是，四足在任意时刻只要三条腿稳定支撑，第四条腿就是"自由"的：它可以去探地形、可以去试摩擦、也可以在被判定故障后立刻抬起。于是安全目标可以从"绝不发生单腿故障"放宽为"**始终停留在可恢复集 ℛ 内**"：只要 CoM 投影在剩余三腿的鲁棒支撑多边形内，任何单腿故障都能在一个相位内被抬腿重放吸收。这把单腿故障的跌倒率从 O(λ) 压到 O(λ²)+O(δλ)（λ 为故障率，δ 为漏检率），是四足相对机械臂的结构性安全红利。

**灵感 4（两者合流 → PROTO-GAIT：Prototype-Transferable Online Gait-Aware Incremental Trust，原型可迁移的步态周期自认证闭环）**
闭环：形态描述子 ED 与原型族先验（PFM）→ 步态周期签名 PGS → 周期自校准归因（GPA）→ 摆动腿免费探针（GIP）→ 迁移证书与信用再充值（TCC）→ 原型-地形定向球（RSC-P/WCV-P）→ 鲁棒支撑与可恢复检查（RCS）→ 相位级证书（CSC-P）→ 对抗认证（AIC-P）→ 活证书 J_proto。第 65 轮是"单原型上故障可归因"；PROTO-GAIT 把它扩展成"**跨原型、跨周期、可恢复**"：归因只是中间手段，真正被认证的是"当前原型当前步态仍落在可恢复集内，且迁移信用尚未透支"。

**灵感 5（VISTA 组件的原位升级）**
- **FIR → GPA（步态周期归因）**：假设集沿用 VISTA，但证据来自每个周期的四相位 × 四腿签名；归因在周期边界做，实时流只采相位证据。
- **AFA → GIP（摆动腿探针）**：探针目标从"故障假设互信息"扩展为"地形/摩擦/腿故障的联合信息"，且利用摆动腿本就抬起，"探针几乎零时间成本"。
- **RSC-V → RSC-P**：不确定球拆为 r_ed / r_terrain / r_friction / r_model；迁移信用只作用于 r_ed。
- **WCV-V → WCV-P**：搜索域增鲁棒支撑多边形与可恢复集约束；地形不可行时不是扩球，而是改落足点/降速。
- **CSC → CSC-P**：认证单位从"时间步前缀"改为"可恢复相位前缀"；承诺长度受一步相位的可恢复视界 m_rec 限制。
- **CSP-V → CSP-P**：技能声明"对 ED 的敏感度 / 影响哪些安全裕度"，规划器可插入 `probe_foot`、`recover_leg`、`recharge_cert` 元技能。
- **AIC-V → AIC-P**：干扰集增形态公差、执行器饱和/带宽下降、步态分岔、双支撑丢失，以及**族内共因**（同一设计缺陷贯穿整族）。
- **J_vista → J_proto**：证书增 ED/ed_hash、迁移信用 C、可恢复裕度、支撑裕度 ρ_sup、周期数 N、自校准状态。

## 1. 形式化定义（增量：定义 233–246）

- **定义 233（PROTO-GAIT 闭环）**：PROTO-GAIT = (VISTA, ED, PFM, PGS, GPA, TCC, RCS, GIP, RSC-P/WCV-P, CSC-P, CSP-P, AIC-P, J_proto)。定位：VISTA 的"原型族可迁移 + 四足步态自校准 + 接触可恢复"升级。不变式：**原型族推理、迁移标定、周期归因、探针规划与证书只在语义流/低频线程；实时流只做步态相位检测、支撑多边形裕度、可恢复性检查、相位前缀执行与早停，零学习写操作。**
- **定义 234（形态描述子与原型族 PFM）**：ED = (l_leg, h_com, m, I_diag, τ_max, ω_max, b_act, r_foot, k_foot, c_foot, τ_lat) ∈ ℝ^{d_e}，各维除以名义值/特征尺度做无量纲化后取度量 d_ED(·,·)=‖·‖_{W_e}。原型族 𝒫 为设计空间上的分布（设计参数先验 × 制造公差 × 历史原型经验）。每个物理原型 ED_i ~ 𝒫 是一个样本。证书只在球 B_e(ED, r_e) 上声明有效。
- **定义 235（原型条件残差与迁移 conformal）**：名义残差统计 μ(ED)、Σ(ED) 与安全裕度 ρ_safe(ED,x)。设 ρ_safe 在 ED 上 L_ρ-Lipschitz：|ρ_safe(ED₁,x)−ρ_safe(ED₂,x)| ≤ L_ρ d_ED(ED₁,ED₂)。在 ED₀ 上验证的裕度 m₀ 迁移到 ED 时给"证书信用" C(ED)=m₀−L_ρ d_ED(ED₀,ED)−L_t·u_terrain。用加权 split-conformal（权重 w(ED)=p_test(ED)/p_cal(ED) 截断到 w_max）给原型偏移下的分布无关覆盖 ≥1−α。
- **定义 236（步态周期签名 PGS）**：一个步态周期按足端接触状态切为 P_g={swing 零载窗, touchdown 冲击, stance 承载, liftoff 卸载}。对每条腿 ℓ∈{FL,FR,RL,RR} 与相位 p，残差 ρ_{ℓ,p}=[e_proprio, e_force, e_imu, e_vis, d_chunk]ᵀ；整周期签名 ρ_g∈ℝ^{4·4·5=80}。相位切分只依赖足端接触开关、关节电流/力矩阈值与 IMU 冲击检测，实时可得。
- **定义 237（步态周期可辨识性与自校准时间）**：第 n 个周期线性化 E[ρ_g|θ]=S_g θ、ρ_g∼N(S_gθ,Σ_g)。N 个弱相关周期累积 Fisher J_fi(N)=N_eff·S_gᵀΣ_g⁻¹S_g（N_eff=N/(1+2Σ_kρ_k)）。swing 识别力/电流偏置，touchdown 识别地形高度/刚度，stance 识别摩擦/滑移与接触模型，故四相位使 S_g 满秩。自校准时间 N₀(κ*)=min{N: κ_fi(N)≥κ*}。
- **定义 238（接触可恢复集 RCS）**：状态 x∈ℛ 当且仅当存在"抬腿-重放"恢复轨迹，使在一步相位内把 CoM 投影（或捕获点）带回剩余三腿的鲁棒支撑多边形，且对当前假设支持集内每个故障、每条候选抬腿 ℓ 均满足鲁棒裕度 ≥0。安全目标从"不滑"改为"保持在 ℛ 内"（不变集）。
- **定义 239（不确定地形/摩擦下的鲁棒支撑裕度）**：支撑区域 S_rob(μ,𝒯,ℱ) 为足端接触点在给定地形高度集 𝒯、摩擦锥集 ℱ、足端尺寸与柔顺不确定下的可达支撑凸包（或其保守内近似，如 zonotope 可达集）。裕度 ρ_sup(x)=signed_dist(CoM_proj(x), ∂S_rob)（或捕获点版本）。证书要求 P(ρ_sup≥0)≥1−α_sup。
- **定义 240（步态相位隔离探针 GIP）**：在静态稳定于三腿时，用摆动腿对候选落足点做低力探触（tap/press/scratch）。选择 a*=argmax_{a∈A} I(𝒯,ℱ,leg-fault; z(a)|history)，s.t. 冲击力≤f_light、形变/打滑≤ε、支撑裕度≥ε_sup、可恢复。探针集 A={tap,press,scratch,visual_probe,null_test}。因摆动腿本就要抬起，探针几乎无额外时间成本（probe-at-no-cost），伤害被限制在单腿且可立即抬起。
- **定义 241（原型迁移证书与信用再充值 TCC）**：迁移证书 𝒞(ED)=(m₀,L_ρ,r_e,α,N,C(ED))。Valid 当 C(ED)≥0 且迁移 conformal 覆盖成立。若 C<0 或 d_ED>r_e，进入"再充值"：用少量步态周期 + 定向 GIP 探针在当前原型上重估 μ(ED)、Σ(ED) 与 ρ_safe，更新 m₀ 与 L_ρ；重充值成本随 d_ED 单调增。证书是"会衰减的资产"，不是一次性结论。
- **定义 242（RSC-P/WCV-P 原型-地形定向球）**：不确定球拆为 r_ed（原型/形态）、r_terrain（高度/刚度）、r_friction、r_model。只膨胀被归因者；迁移信用 C 直接作用于 r_ed（C 越小 r_ed 越大）。融合半径 r=√(r_ed²+r_terrain²+r_friction²+r_model²)。搜索域增鲁棒支撑约束 S_rob 与可恢复约束 ℛ。
- **定义 243（CSC-P 相位级证书）**：不认证"固定步数"，而认证"可恢复相位前缀"：只要相位执行中 x(t)∈ℛ 且 ρ_sup≥0 就允许继续；一旦预测将离开 ℛ，立即切换三腿支撑/缩短 duty factor/抬腿重放。认证量是相位而非时间步，承诺长度受一步相位的可恢复视界 m_rec 限制。
- **定义 244（AIC-P 快速原型对抗认证）**：干扰集 ℰ_P=ℰ_V×ℰ_design×ℰ_gait：ℰ_design 含形态公差、质量/惯量偏移、执行器饱和/带宽下降、足端磨损；ℰ_gait 含相位错位、步态分岔、双支撑丢失、地形对抗；并含**族内共因**（同一 URDF/控制器/标定缺陷贯穿整族）。ρ_dir 在 ℰ_P 上重算；J_dir 增 ed_hash、transfer_credit、gait_sync_ver。
- **定义 245（J_proto 活证书）**：J_proto=(J_vista, ED, ed_hash, d_ED(ED₀,ED), transfer_credit C, recoverability_margin, support_margin ρ_sup, N_cycles, self_calib_status, probe_log, aic_p_ver)。Valid ⇔ Valid(J_vista) ∧ (C≥0 ∨ 已再充值) ∧ x∈ℛ ∧ ρ_sup≥0 ∧ (N≥N₀ ∨ 显式标 untrusted) ∧ aic_p_ver 当前。
- **定义 246（PROTO-GAIT 闭环算子）**：语义/低频流 [ED 读取→原型族先验→PGS 采集→周期归因→GIP 规划→迁移信用更新→RSC-P/WCV-P→CSP-P 步态规划→CSC-P 相位证书→AIC-P]；实时流 [足端接触/IMU/电流→相位判定→支撑裕度→可恢复检查→相位前缀派发→早停/抬腿重放→J_proto 构建]。

## 2. 关键算法骨架

```python
# 迁移证书：信用衰减 + 再充值判定（语义流）
C = margin0 - L_rho * d_ED(ed, ed0) - L_t * terrain_unc
if C < 0 or d_ED(ed, ed0) > r_e:
    recharge(ed)                       # 少量步态周期 + 定向 GIP 探针

# 步态周期归因：行走即标定
rho_g = gait_signature(last_cycle)     # swing/touchdown/stance/liftoff × 4 legs
J_fi += S.T @ inv(Sigma) @ S           # Fisher 信息随周期累积
post = bayes_update(post, rho_g)
if lambda_min(J_fi) >= kappa_star:
    self_calibrated = True

# 可恢复相位认证：安全 = 留在可恢复集
if not in_recoverable_set(x, post):
    lift_and_replace(fault_leg)        # 抬腿重放，而非继续硬撑
if support_margin(x, three_legs) < 0:
    abort_phase(); enter_tripod()

# 摆动腿免费探针
if gait.swinging and need_terrain_info():
    a = gip.choose(terrain_post, friction_post, support_margin)
    execute_swing_probe(a)             # tap/press/scratch，冲击力 ≤ f_light
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（迁移证书的信用衰减）**：若安全裕度 ρ_safe 对 ED 是 L_ρ-Lipschitz，则新原型的真实裕度 ≥ C(ED)=m₀−L_ρ d_ED−L_t u；C≥0 即保证迁移后仍安全。加权 conformal 给原型偏移下的覆盖 ≥1−α−P(d_ED>r_e)。**设计变更不再让证书归零，而是按可计算的信用贬值。**
- **引理 10（步态周期自校准）**：N 个弱相关周期的 Fisher 信息 J_fi(N)≈N_eff·S_gᵀΣ_g⁻¹S_g，故 κ_fi(N)=N_eff·κ_fi(1)、估计误差 ~1/√N；四相位使 S_g 满秩。自校准时间 N₀=⌈κ*/κ_fi(1)⌉。**行走本身就是故障注入。**
- **定理 9（单腿故障的接触可恢复性）**：若始终维持三腿鲁棒支撑裕度 ≥ε、单腿故障在一个相位内被 PGS 检出（漏检 δ）、且抬腿重放可在一步内完成，则单腿故障不导致跌倒；跌倒需漏检或同相位第二腿故障，Poisson 模型下跌倒率 ≈4λτδ+O((λτ)²)，即从 O(λ) 降到 O(λ²)+O(δλ)。**冗余把故障变成可恢复事件。**
- **定理 10（PROTO-GAIT 端到端）**：在迁移 Lipschitz、步态满秩、可恢复性三条件下，Valid(J_proto) ⇒ 迁移覆盖当前原型 ∧ 故障在 N₀ 周期内可辨识或显式 untrusted ∧ 单腿故障可恢复 ∧ 信用透支即再充值 ∧ 优雅降级。
- **命题（快速原型的证书经济学）**：设计步长尺度 σ_d 下，需全量重测的概率 p_retest≈P(d_ED>C/L_ρ)，随信用 C 指数下降；而 C 随累积周期 ~√N 增长，故每次迭代的期望认证成本递减。**快速迭代与安全认证并非天然对立，前提是改动小且裕度连续。**
- **实时性**：相位检测、支撑裕度、可恢复检查、CSC-P 早停全在实时流（合计 <0.5ms）；周期归因、GIP、迁移标定、AIC-P 全在语义流。

**定义 233（PROTO-GAIT 闭环）** PROTO-GAIT 是 VISTA 的"原型族可迁移 + 四足步态自校准 + 接触可恢复"升级：在 VISTA 的"语义流 ∘ 实时流"骨架上挂载 ED/PFM（形态描述与原型族先验）、PGS（步态周期签名）、GPA（周期归因）、TCC（迁移证书）、RCS（可恢复集）、GIP（摆动腿探针），并原位升级 RSC-V→RSC-P、WCV-V→WCV-P、CSC→CSC-P、CSP-V→CSP-P、AIC-V→AIC-P、J_vista→J_proto。不变式：**所有原型族推理、迁移标定、周期归因、探针规划、证书构建只发生在语义流与低频线程；实时路径只做步态相位检测、鲁棒支撑裕度、可恢复性检查、相位前缀执行与早停，零学习写操作。**

**定义 234（形态描述子与原型族 PFM）** 形态描述子
ED = (l_leg, h_com, m, I_diag, τ_max, ω_max, b_act, r_foot, k_foot, c_foot, τ_lat) ∈ ℝ^{d_e}，
各维除以名义值或特征尺度做无量纲化后，取加权欧氏度量 d_ED(ED₁,ED₂)=‖ED₁−ED₂‖_{W_e}。原型族 𝒫 是设计空间上的分布，由设计参数先验、制造公差与历史原型经验共同给出；每个物理原型 ED_i ~ 𝒫 是一个样本。证书只在球 B_e(ED,r_e) 上声明有效，**设计变更因此成为一个可度量、可预算的事件，而不是"证书作废"的二元事件。**

**定义 235（原型条件残差与迁移 conformal）** 名义残差统计 μ(ED)、Σ(ED) 与安全裕度 ρ_safe(ED,x) 随形态变化。假设 ρ_safe 在 ED 上 L_ρ-Lipschitz：
|ρ_safe(ED₁,x) − ρ_safe(ED₂,x)| ≤ L_ρ d_ED(ED₁,ED₂)。
在 ED₀ 上验证得到的裕度 m₀ 迁移到 ED 时，定义**证书信用**
C(ED) = m₀ − L_ρ d_ED(ED₀,ED) − L_t·u_terrain。
由于测试原型与标定原型不同分布，采用加权 split-conformal：以密度比 w(ED)=p_test(ED)/p_cal(ED) 截断到 w_max 后计算加权分位数，使原型偏移下的边际覆盖 ≥1−α（可交换性 + 有界权重）。**迁移不是"相信旧结论"，而是"用可计算的上界给旧结论打折"。**

**定义 236（步态周期签名 PGS）** 一个步态周期按足端接触状态切为四相位
P_g = {swing（f_n≈0，零载窗）, touchdown（冲击瞬态）, stance（承载）, liftoff（卸载）}。
对每条腿 ℓ∈{FL,FR,RL,RR} 与相位 p，聚合残差
ρ_{ℓ,p} = [ē_proprio, ē_force, ē_imu, ē_vis, d̄_chunk]ᵀ ∈ ℝ⁵，
整周期签名 ρ_g = (ρ_{ℓ,p})_{ℓ,p} ∈ ℝ^{80}。相位切分只依赖足端接触开关、关节电流/力矩阈值与 IMU 冲击检测，全部实时可得，**不依赖学习模型**。

**定义 237（步态周期可辨识性与自校准时间）** 第 n 个周期线性化 E[ρ_g|θ]=S_gθ、ρ_g∼N(S_gθ,Σ_g)。N 个弱相关周期（自相关 ρ_k）的累积 Fisher 信息
J_fi(N) = N_eff·S_gᵀΣ_g⁻¹S_g，N_eff = N/(1+2Σ_{k≥1}ρ_k)。
swing 零载窗识别力/电流偏置（且无视觉形变），touchdown 冲击识别地形高度/刚度，stance 识别摩擦/滑移与接触模型误差，liftoff 识别卸载滞后。四相位使 S_g 满秩，故
N₀(κ*) = min{N : λ_min(J_fi(N))/λ_max(J_fi(N)) ≥ κ*}。
**结论：不需要专用故障注入，行走本身就是 N 次受控实验；新原型的自校准时间只取决于步数。**

**定义 238（接触可恢复集 RCS）** 状态 x 属于可恢复集 ℛ，当且仅当存在"抬腿-重放"恢复轨迹，使在一步相位 m_rec 内把 CoM 投影（或捕获点）带回剩余三腿的鲁棒支撑多边形，且对当前假设支持集 supp_δ(post) 内每个故障、每条候选抬腿 ℓ 均满足鲁棒裕度 ≥0。安全目标从"不滑"改为**保持在 ℛ 内**（不变集）：
x_t∈ℛ ∧ u_t∈𝒰_rec ⇒ x_{t+1}∈ℛ。
这直接利用四足的结构性冗余：任意时刻三条腿支撑，第四条腿是可牺牲、可抬起、可重放的。

**定义 239（不确定地形/摩擦下的鲁棒支撑裕度）** 支撑区域
S_rob(μ,𝒯,ℱ)
为足端接触点在给定地形高度集 𝒯、摩擦锥集 ℱ、足端尺寸与柔顺不确定下的可达支撑凸包（或 zonotope 等保守内近似）。鲁棒支撑裕度
ρ_sup(x) = signed_dist(CoM_proj(x), ∂S_rob)（或捕获点版本）。
证书要求 P(ρ_sup≥0) ≥ 1−α_sup。地形/摩擦越不确定，S_rob 越向内收缩，裕度越小——**不确定性被显式转成"可站立的面积"。**

**定义 240（步态相位隔离探针 GIP）** 在静态稳定于三腿时，用摆动腿对候选落足点做低力探触。选择
a* = argmax_{a∈A} I(𝒯,ℱ,leg-fault; z(a) | history)，
s.t. 冲击力 ≤ f_light、形变/打滑 ≤ ε、支撑裕度 ≥ ε_sup、预测轨迹可恢复。
探针集 A={tap, press, scratch, visual_probe, null_test}。由于摆动腿本就要抬起，**探针几乎无额外时间成本（probe-at-no-cost）**，且伤害被限制在单腿、可立即抬起重放。这是 AFA 在四足上的结构红利：VISTA 需要专门插入探针，四足可以在正常步态里"顺手"完成。

**定义 241（原型迁移证书与信用再充值 TCC）** 迁移证书
𝒞(ED) = (m₀, L_ρ, r_e, α, N, C(ED))。
Valid 当 C(ED)≥0 且加权 conformal 覆盖成立。若 C<0 或 d_ED>r_e，进入**再充值**：用少量步态周期 + 定向 GIP 探针在当前原型上重估 μ(ED)、Σ(ED)、ρ_safe 与 L_ρ，更新 m₀。重充值成本随 d_ED 单调增。**证书是"会衰减的资产"：小改动近乎免费，大改动自动触发重测，而不是静默乐观。**

**定义 242（RSC-P/WCV-P 原型-地形定向球）** 不确定球拆为四个独立半径：r_ed（原型/形态）、r_terrain（高度/刚度）、r_friction（摩擦）、r_model（接触/动力学模型）。只膨胀被归因者；迁移信用 C 直接作用于 r_ed：C 越小 r_ed 越大。融合半径
r = √(r_ed² + r_terrain² + r_friction² + r_model²)。
搜索域增鲁棒支撑约束 S_rob 与可恢复约束 ℛ：
B(φ̂,r) ∩ 𝒢 ∩ K(μ̂) ∩ ℱ(f_lim) ∩ S_rob ∩ ℛ。
相比 VISTA"任何拒绝都膨胀同一个球"，RSC-P 在形态不确定时只扩 r_ed，不误伤已标定的地形/摩擦。

**定义 243（CSC-P 相位级证书）** 不认证"固定步数 k"，而认证**可恢复相位前缀**：只要相位执行过程中 x(t)∈ℛ 且 ρ_sup(t)≥0，就允许继续；一旦预测将离开 ℛ，立即切换三腿支撑 / 缩短 duty factor / 抬腿重放。认证量是相位而非时间步，承诺长度受一步相位的可恢复视界 m_rec 限制：
执行相位 p 当且仅当 ∀s≤p: x_s∈ℛ ∧ ρ_sup(x_s)≥0。
这把 VISTA 的"长预测、短执行"改写成"**长步态规划、短相位承诺**"。

**定义 244（AIC-P 快速原型对抗认证）** 干扰集
ℰ_P = ℰ_V × ℰ_design × ℰ_gait，
ℰ_design 含形态公差、质量/惯量偏移、执行器饱和/带宽下降、足端磨损；ℰ_gait 含相位错位、步态分岔、双支撑丢失、地形对抗；并新增**族内共因** ℰ_common（同一 URDF 错误、同一控制器 bug、同一 IMU 模型偏差贯穿整族）。ρ_dir 在 ℰ_P 上重算（n_cert 128→160，其中 32 给设计/步态/共因）；J_dir 增 ed_hash、transfer_credit、gait_sync_ver。**族内共因下不要求迁移正确，只要求能被判 untrusted 并停止复用证书。**

**定义 245（J_proto 活证书）** J_proto=(J_vista, ED, ed_hash, d_ED(ED₀,ED), transfer_credit C, recoverability_margin, support_margin ρ_sup, N_cycles, self_calib_status, probe_log, aic_p_ver)。验证规则：

### IP-227 TCC（迁移证书与信用再充值）

```python
class TransferCertificate:
    """证书 = 会衰减的资产。只做上界计算与覆盖校验，归因/标定在语义流。"""
    def __init__(self, ed0, margin0, L_rho, L_t, r_e, alpha, w_max=10.0):
        self.ed0, self.margin0 = ed0, margin0
        self.L_rho, self.L_t = L_rho, L_t
        self.r_e, self.alpha, self.w_max = r_e, alpha, w_max

    def credit(self, ed, terrain_unc):
        return self.margin0 - self.L_rho * d_ED(ed, self.ed0) - self.L_t * terrain_unc

    def valid(self, ed, terrain_unc, calib_scores, calib_weights):
        if d_ED(ed, self.ed0) > self.r_e:
            return False, self.credit(ed, terrain_unc)
        q = weighted_quantile(calib_scores, clip(calib_weights, 1.0 / self.w_max, self.w_max),
                              1.0 - self.alpha)
        return (self.credit(ed, terrain_unc) >= 0) and (q <= self.margin0), self.credit(ed, terrain_unc)

    def recharge(self, ed, gait_buffer, gip):
        # 再充值：少量步态周期 + 定向探针，重估 μ(ED)、Σ(ED)、ρ_safe、L_ρ
        for _ in range(RECHARGE_CYCLES):
            gip.maybe_probe(ed)
            gait_buffer.push_next_cycle()
        self.ed0, self.margin0 = ed, estimate_margin(ed, gait_buffer)
        self.L_rho = estimate_lipschitz(ed, gait_buffer)
        return self
```

```python
        self.S_g, self.Sigma_g = S_g, Sigma_g
        self.post, self.prior = dict(prior), dict(prior)
        self.J_fi = np.zeros_like(S_g.T @ np.linalg.inv(Sigma_g) @ S_g)
        self.N, self.N_eff = 0, 0.0
        self.kappa_star, self.delta_fi = kappa_star, delta_fi

    def update_cycle(self, phase_residuals):
        rho = np.concatenate([phase_residuals[(l, p)] for l in self.LEGS for p in self.PHASES])
        self.J_fi += self.S_g.T @ np.linalg.inv(self.Sigma_g) @ self.S_g
        self.N += 1
        self.N_eff = self.N / (1.0 + 2.0 * self._autocorr())
        self.post = bayes_update(self.post, rho, self.S_g, self.Sigma_g)
        return self.post

    def self_calibrated(self):
        ev = np.linalg.eigvalsh(self.J_fi)
        return ev.min() / max(ev.max(), 1e-12) >= self.kappa_star

    def attribute(self):
        h_star = max(self.post, key=self.post.get)
        return self.post, h_star, self.post[h_star] < 1.0 - self.delta_fi

    def _autocorr(self):
        return getattr(self, 'rho_k', 0.0)   # 由离线/在线估计的周期残差自相关
```

```python
    M.balls = M.rsc_p.update(post, credit, M.balls)

    M.dir.update(sample_batch_from_history(32))
```

## 4. 推导

**引理 9（迁移证书的信用衰减）** 设 ρ_safe(·,x) 在 ED 上 L_ρ-Lipschitz，地形不确定贡献上界 L_t·u_terrain。对任意新原型 ED 与状态 x，
ρ_safe(ED,x) ≥ ρ_safe(ED₀,x) − L_ρ d_ED(ED₀,ED) − L_t u_terrain
≥ m₀ − L_ρ d_ED(ED₀,ED) − L_t u_terrain = C(ED)。
故 C(ED)≥0 ⇒ 新原型上该状态的安全裕度非负。加权 split-conformal 在权重有界（≤w_max）与可交换性下给
P[ρ_safe(ED,X) ≥ 0] ≥ 1 − α − P[d_ED(ED₀,ED) > r_e]。
即证书的失效概率被显式拆成"统计覆盖失败"与"设计走出信任球"两项。∎

**引理 10（步态周期自校准）** 设 ρ_g^{(n)} = S_gθ + ε_n，ε_n 弱相关（自相关 ρ_k）。则累积 Fisher 信息
J_fi(N) = N_eff S_gᵀΣ_g⁻¹S_g，N_eff = N/(1+2Σ_kρ_k)，
MLE 误差协方差 ≈ J_fi(N)⁻¹，故 θ 的估计误差按 1/√N_eff 下降，可辨识裕度 κ_fi(N)=N_eff·κ_fi(1)。四相位结构使 S_g 列满秩：swing 零载窗只含力/电流偏置列，touchdown 只含地形高度/刚度列，stance 含摩擦/滑移与模型列，liftoff 含卸载滞后列。故 N₀(κ*) = ⌈κ*/(N_eff 每周期增量)⌉。若删除 swing，则力偏置与接触模型在 stance 上混叠，S_g 降秩，退化为 VISTA 的不可辨识。∎

**定理 9（单腿故障的接触可恢复性）** 设 (i) 任意时刻 CoM 投影位于剩余三腿鲁棒支撑多边形内且裕度 ≥ε；(ii) PGS 在一个相位内检出任意单腿故障，漏检概率 ≤δ；(iii) 抬腿-重放控制器可在一个相位 m_rec 内完成重放。则单腿故障不导致跌倒；跌倒需满足"漏检"或"同相位内第二腿故障"。设各腿故障为独立 Poisson 过程、单腿率 λ、相位时长 τ，则
P[跌倒 | 单腿故障] ≤ δ + P[N_leg(τ)≥2] ≈ δ + O((λτ)²)，
总跌倒率 ≈ 4λτδ + O((λτ)²)。当 δ 很小时从 O(λ) 降到 O(λ²)+O(δλ)。**接触冗余把单腿故障从"事故"变成"可恢复事件"，且安全随故障率二次而非线性退化。**∎

**定理 10（PROTO-GAIT 端到端）** 在 A94–A98（迁移 Lipschitz、步态满秩、可恢复性、加权 conformal 覆盖、族内共因可判 untrusted）下，Valid(J_proto) ⇒
1. **迁移安全**：C(ED)≥0 且加权 conformal 覆盖，故当前原型的安全裕度以 ≥1−α−P(d_ED>r_e) 非负（引理 9）；
2. **自校准**：N≥N₀ 时故障幅度可辨识，否则证书显式 untrusted（引理 10）；
3. **可恢复**：x∈ℛ ∧ ρ_sup≥0，单腿故障跌倒率 O(λ²)+O(δλ)（定理 9）；
4. **不静默乐观**：信用透支或走出 ED 球即触发再充值/停止复用，而非继续使用旧证书；
5. **优雅降级**：untrusted → 降速/三腿支撑/停止；地形不可行 → 改落足点而非扩球。
∎

**命题（快速原型的证书经济学）** 设每次设计迭代的 ED 步长服从尺度 σ_d 的分布，证书信用 C。需要全量重测的概率
p_retest = P[d_ED(ED₀,ED) > C/L_ρ]。
对高斯步长，p_retest ≈ exp(−(C/L_ρ)²/(2σ_d²))，随信用 C 指数下降。而引理 10 给出信用随累积周期以 ~√N 收紧（m₀ 的估计误差 ~1/√N），故 p_retest 随原型族积累而下降。每次迭代的期望认证成本
E[cost] = p_retest·c_retest + c_cycle
递减。**快速迭代与安全认证并非天然对立：前提是设计改动小、且安全裕度对 ED 连续。**∎

**命题（摆动腿探针的零时间成本）** 设正常步态中摆动相时长 τ_sw，探触在摆动相内完成，则探针的额外时间成本为 0；对比 VISTA 需专门停下插入 null_test/fi_probe（成本 τ_probe>0），GIP 的信息获取率（bit/时间）提升 τ_probe/τ_sw 倍。代价是探针力被限制在 f_light 且只能在摆动腿落点附近，信息带宽有限。∎

## 7. 已知风险

**一句话**：PROTO-GAIT 的证书迁移假设安全裕度对形态描述子 Lipschitz、且原型族内的故障近似独立；但快速原型的本质是同一设计谱系的快速变体，系统性设计缺陷（同一 URDF 错误、同一控制器 bug、同一 IMU 模型偏差）是跨原型的**共因故障**，且接触/冲击动力学在稳定边界附近会分岔、并不 Lipschitz——迁移会把"缺陷"连同"证书"一起继承，步态周期的重复采样只是以更高置信度重复同一个错误模型，于是系统会以越来越高的置信度、在整族原型上犯同一个错。

**次级风险与缓解**：
1. **Lipschitz 在分岔处失效**：稳定性边界/接触冲击处 ρ_safe 可能跳变；缓解：在线估计局部 L_ρ，检测到裕度对 ED 的敏感度突增即判 `near_bifurcation`，强制全量再测，禁止迁移。
2. **族内共因故障**：同一设计缺陷贯穿整族，独立冗余失效；缓解：AIC-P 显式建模 ℰ_common；引入跨谱系原型（不同设计分支）作为独立样本；共因下只要求判 untrusted，不要求迁移正确。
3. **原型族样本极少**：快速原型往往只有个位数样本，迁移 conformal 覆盖弱；缓解：用设计参数先验 + 仿真孪生扩充标定集（但孪生只作假设生成、不作真值），并给出小样本覆盖下界。
4. **步态周期不平稳**：变速、转向、打滑使周期不独立、相位切分污染；缓解：用 N_eff 折算自相关，相位切分加 IMU 冲击 + 电流双判据，必要时插入显式 null_test。
5. **可恢复性依赖地形**：陡坡/窄梁上三腿支撑多边形退化，ℛ 可能为空；缓解：ℛ 空即判地形不可行、改落足点/降速/求援，不硬走。
6. **探针信息带宽低**：摆动腿只能轻触落点附近；缓解：把探针视为"顺带信息"，不承担全部辨识，主要靠步态周期的被动激励。
7. **实时预算**：鲁棒支撑与可恢复检查逼近 1ms；缓解：zonotope 预编译、相位内复用、把归因/标定全部留在语义流。
8. **迁移信用被滥用**：工程上倾向于"信用还没耗尽就继续用"；缓解：J_proto 强制记录 d_ED 与 C，信用低于阈值即禁止跳过再测，审计链可追责。
